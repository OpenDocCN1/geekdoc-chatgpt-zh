(TwoDimensionalShape) , 也可以是一个三维形状 (ThreeDimensionalShape) 。同前面一样，我们能够从图的底部开始，沿着箭头通过几个“是”关系到达这个类层次结构最顶部的基类。例如，一个三角形（Triangle）是一个二维形状（TwoDimensionalShape），也是一个形状（Shape）；而一个球体（Sphere）是一个三维形状（ThreeDimensionalShape），也是一个形状（Shape）。这个层次结构也可以包含许多其他类。例如，椭圆和梯形也是二维形状（TwoDimensionalShape），而锥体和圆柱体也是三维形状（ThreeDimensionalShape）。

# “是”（is a）与“有”（has a）两种关系的区别

继承产生“是”关系，即一个子类类型的对象也可以被视作一个基类类型的对象。前面已经介绍了“有”（组合）关系，即一个类中可以包括一个或多个其他类对象的引用作为该类的成员。
