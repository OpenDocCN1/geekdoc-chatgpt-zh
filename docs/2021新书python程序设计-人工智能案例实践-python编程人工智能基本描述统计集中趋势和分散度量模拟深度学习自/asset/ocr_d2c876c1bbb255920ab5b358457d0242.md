# 4.7 math模块中的函数

math模块中定义了用于执行各种常见数学计算的函数。下面脚本中的import语句导入了math模块，然后就可以通过模块名加点（.）来使用模块中的函数：

```
In [1]: import math
```

例如，下面的代码段通过调用math模块的sqrt函数来计算900的平方根，该函数将结果作为浮点值返回：

```
In [2]: math.sqrt(900)
Out[2]: 30.0
```

类似地，下面的代码段通过调用math模块的fabs函数来计算-10的绝对值，该函数将结果作为float值返回：

```
In [3]: math.fabs(-10)
Out[3]: 10.0
```
