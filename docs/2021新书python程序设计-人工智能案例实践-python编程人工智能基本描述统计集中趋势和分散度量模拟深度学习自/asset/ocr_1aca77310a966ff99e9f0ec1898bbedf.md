都要使用原始问题的更简单版本调用自身，而逐渐变小的问题构成的序列必须收敛于基本问题。当函数识别到基本问题时，它会将结果返回到它的上一个副本。递归会依序进行一系列的返回，直到最初的函数调用将最终结果返回给调用者。

# 递归求阶乘

通过观察，我们可以将n!写成如下的递归形式：

```
n! = n · (n - 1)!
```

例如，5!等于5·4!，如下：

```
5! = 5 · 4 · 3 · 2 · 1
5! = 5 · (4 · 3 · 2 · 1)
5! = 5 · (4!)
```
