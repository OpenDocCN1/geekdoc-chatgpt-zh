# 卸载集群资源，避免产生额外费用

注意：请确保卸载集群及相关资源（如存储），避免额外付费。
在Azure门户网站中，单击“All resources”按钮查看资源，其中包
括之前设置的集群和存储账户。如果不卸载，两者都会产生费用。选
择每个资源并单击“Delete”按钮将其卸载，用户将被要求键入yes来
确认。详细信息请参见https://docs.microsoft.com/en-
us/azure/azure-resource-manager/resource-group-portal。
