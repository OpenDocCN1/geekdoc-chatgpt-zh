# 8.5 字符大小写转换

在前面的内容中，已经使用过字符串方法lower和upper将一个字符串转化为全小写或全大写。我们还可以使用capitalize和title方法来更改一个字符串的大小写情况。

# 只将字符串的首字母大写

capitalize方法对原来的字符串进行复制，然后返回一个只有首字母大写的新字符串（这种方式被称为句子大写）：

```
In [1]: 'happy birthday'.capitalize()
Out[1]: 'Happy birthday'
```

# 将字符串中的每个单词的首字母转为大写

title方法复制原来的字符串，然后返回一个仅大写每个单词的首字母的新字符串（这种方式就是所说的标题大写）：

```
In [2]: 'strings: a deeper look'.title()
Out[2]: 'Strings: A Deeper Look'
```
