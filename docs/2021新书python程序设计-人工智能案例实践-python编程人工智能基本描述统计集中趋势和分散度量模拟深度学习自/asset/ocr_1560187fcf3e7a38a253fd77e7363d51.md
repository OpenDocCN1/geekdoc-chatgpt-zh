# 14.1.4 典型的数据科学研究的步骤

典型的数据科学研究的步骤包括：

+   加载数据集。

+   使用pandas和可视化库探索数据。

+   转换数据（将非数值数据转换为数值数据，因为scikit-learn要求用数值数据。本章使用的数据集是处理好的，我们将在第15章中再次讨论这个问题）。

+   将数据划分为训练集和测试集。

+   创建模型。

+   训练和测试模型。

+   调整模型并评估其准确性。

+   对模型未见过的实时数据进行预测。
