# 访问Docker容器的命令行

每个Docker容器都有一个命令行界面，就像在本书中用来运行IPython的界面一样。通过此界面，可将Python软件包安装到Docker容器中，甚至可以像以前一样使用IPython。

打开单独的Anaconda命令提示符、终端或shell，并使用以下命令列出当前正在运行的Docker容器：

```
docker ps
```
