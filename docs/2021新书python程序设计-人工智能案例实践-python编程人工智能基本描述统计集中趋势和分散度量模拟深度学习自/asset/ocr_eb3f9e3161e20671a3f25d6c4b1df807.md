# 9.8 处理异常

当操作文件时，可能会遇到不同类型的异常，包括：

+   - 如果试图用'r'或'r+'模式打开一个不存在的文件进行读操作，则会引发`FileNotFoundError`异常。
+   - 如果试图执行一个没有权限的操作，则会引发`PermissionsError`异常。例如，试图打开一个没有访问权限的文件，或者试图在一个没有写权限的文件夹（如操作系统所在的文件夹）中创建一个文件。
+   - 如果试图向一个已经关闭的文件写数据，则会引发`ValueError`异常（同时产生“I/O operation on closed file.”这样的错误信息）。
