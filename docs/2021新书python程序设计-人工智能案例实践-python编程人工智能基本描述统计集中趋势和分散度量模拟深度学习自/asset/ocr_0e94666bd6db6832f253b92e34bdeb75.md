要将推文的JSON作为文档存储在MongoDB数据库中，必须首先通过pymongo的MongoClient方法连接到MongoDB Atlas集群，该方法使用集群的连接字符串作为其参数：

```
In [9]: from pymongo import MongoClient
In [10]: atlas_client = MongoClient(keys.mongo_connection_string)
```

现在，可以获得一个表示senator数据库的pymongo数据库对象。
如果数据库不存在，则用以下语句创建数据库：

```
In [11]: db = atlas_client.senators
```
