假设想获取一些关于生还者的统计数据，可以将survived列与'yes'进行比较，以获得包含True/False值的新Series，然后就可以使用describe来汇总结果：

```
In [9]: (titanic.survived == 'yes').describe()
Out[9]:
count    1309
unique      2
top     False
freq      809
Name: survived, dtype: object
```

对于非数值数据， describe显示了不同的描述性统计信息：

+   - count是结果中的项目总数。
+   - unique是结果中的唯一值（2）的数量，即True（生还）和False（死亡）。
+   - top是结果中最频繁出现的值。
+   - freq是结果中最频繁出现的值的出现次数。
