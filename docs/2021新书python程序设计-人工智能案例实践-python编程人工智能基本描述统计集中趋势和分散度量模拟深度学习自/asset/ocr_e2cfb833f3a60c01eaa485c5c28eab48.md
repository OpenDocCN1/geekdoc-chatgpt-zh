# 5.2 列表

在本节，我们将详细讨论列表，并介绍如何引用特定的列表元素。本节演示的许多功能适用于所有序列类型。

# 创建列表

列表通常存储同构数据，即相同数据类型的值。例如列表c，其中包含五个整数元素：

```
In [1]: c = [-45, 6, 0, 72, 1543]
In [2]: c
Out[2]: [-45, 6, 0, 72, 1543]
```

列表还可以存储异构数据，即多个不同类型的数据。例如，以下列表包含学生的名字（字符串）、姓氏（字符串）、平均绩点（浮点型）、毕业年份（整型）：

```
['Mary', 'Smith', 3.57, 2022]
```
