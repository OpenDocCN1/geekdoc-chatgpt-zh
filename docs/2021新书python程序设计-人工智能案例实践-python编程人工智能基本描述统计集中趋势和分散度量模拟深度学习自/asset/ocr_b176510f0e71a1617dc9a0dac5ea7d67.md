通过分类，我们发现预测值是与数据集中现有类别匹配的离散类别，而使用回归很难得到准确的预测，因为回归有连续的输出。\( x_1, x_2, \cdots, x_n \)的每个可能值

\( y = m_1x_1 + m_2x_2 + \cdots + m_nx_n + b \)

都能得到一个预测值。
