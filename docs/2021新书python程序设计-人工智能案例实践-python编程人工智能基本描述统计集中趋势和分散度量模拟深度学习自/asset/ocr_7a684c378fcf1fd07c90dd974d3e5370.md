# 除法（/）和整除（//）

除法（/）运算用分子除以分母，结果为带小数点的浮点数，如下所示：

![](bbox=[0.203, 0.203, 0.798, 0.233])

整除（//）用分子除以分母，得到不大于结果的最大整数。Python会直接截断（丢弃）小数部分：

![](bbox=[0.203, 0.321, 0.798, 0.409])

使用除法（/）时，-13除以4的结果为-3.25，如下：

![](bbox=[0.203, 0.475, 0.798, 0.505])

整除（//）的结果为不大于-3.25的最大整数，即-4，如下：

![](bbox=[0.203, 0.572, 0.798, 0.602])

# 异常和回溯

Python不允许使用“/”或“//”除以零，否则将导致异常，表示有问题发生：
