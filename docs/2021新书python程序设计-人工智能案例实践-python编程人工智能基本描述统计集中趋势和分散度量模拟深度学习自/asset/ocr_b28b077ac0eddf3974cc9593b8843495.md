# titles表

titles表存储了所有的书籍，共有四列：

+   - isbn—书的ISBN（字符串）是该表的主键。ISBN是“国际标准书号”的缩写，是出版商用来为每本书提供唯一标识号的编号方案。
+   - title—书名（一个字符串）。
+   - edition—书的版本号（整数）。
+   - copyright—书的版权年份（字符串）。

使用SQL和pandas来查看titles表的内容：

```
In [6]: pd.read_sql('SELECT * FROM titles', connection)
```
