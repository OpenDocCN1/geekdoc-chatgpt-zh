| 函 数 | 说 明 | 例 子 |
| :--- | :--- | :--- |
| ceil(x) | 将 x 向上取整 | ceil(9.2) 的值为 10.0<br>ceil(-9.8) 的值为 -9.0 |
| floor(x) | 将 x 向下取整 | floor(9.2) 的值为 9.0<br>floor(-9.8) 的值为 -10.0 |
| sin(x)<br>cos(x)<br>tan(x) | 求 x 的正弦（x 是弧度）<br>求 x 的余弦（x 是弧度）<br>求 x 的正切（x 是弧度） | sin(0.0) 的值为 0.0<br>cos(0.0) 的值为 1.0<br>tan(0.0) 的值为 0.0 |
| exp(x) | 指数函数 e^x | exp(1.0) 的值为 2.718282<br>exp(2.0) 的值为 7.389056 |
| log(x) | 求 x 的自然对数（底为 e） | log(2.718282) 的值为 1.0<br>log(7.389056) 的值为 2.0 |
| log10(x) | 求 x 的对数（底为 10） | log10(10.0) 的值为 1.0<br>log10(100.0) 的值为 2.0 |
| pow(x,y) | 求 x 的 y 次幂 (x^y) | pow(2.0, 7.0) 的值为 128.0<br>pow(9.0, .5) 的值为 3.0 |
| sqrt(x) | 求 x 的平方根 | sqrt(900) 的值为 30.0<br>sqrt(9.0) 的值为 3.0 |
| fabs(x) | 求 x 的绝对值——通常返回一个 float 值。<br>Python 还有一个内置的 abs 函数，这个函数会根据其参数返回 int 或 float 类型的值 | fabs(5.1) 的值为 5.1<br>fabs(-5.1) 的值为 5.1 |
| fmod(x,y) | x 除以 y 的余数，返回值为浮点数 | fmod(9.8, 4.0) 的值为 1.8 |
