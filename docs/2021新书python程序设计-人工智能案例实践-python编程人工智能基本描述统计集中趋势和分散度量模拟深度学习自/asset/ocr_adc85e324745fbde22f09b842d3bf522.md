# 添加新的键-值对

给不存在的键赋值会在字典中插入新的键-值对：

```
```python
In [6]: roman_numerals['L'] = 50

In [7]: roman_numerals
Out[7]: {'I': 1, 'II': 2, 'III': 3, 'V': 5, 'X': 10, 'L': 50}
```
```

键是区分大小写的。给不存在的键分配值会插入新的键-值对，可能是故意这么做的，但也可能是逻辑错误。

# 删除键-值对

可以使用下面的del语句从字典中删除键-值对：

```
```python
In [8]: del roman_numerals['III']

In [9]: roman_numerals
Out[9]: {'I': 1, 'II': 2, 'V': 5, 'X': 10, 'L': 50}
```
```

还可以使用字典的pop方法删除键-值对，该方法返回已删除键的值：

```
```python
In [10]: roman_numerals.pop('X')
Out[10]: 10

In [11]: roman_numerals
Out[11]: {'I': 1, 'II': 2, 'V': 5, 'L': 50}
```
```
