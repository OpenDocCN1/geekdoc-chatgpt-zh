# 3.7 增强赋值

当相同的变量名同时出现在赋值号 “=” 的左右两端，可以使用增强赋值对赋值表达式进行缩写，例如下面的代码中的变量total：

```
for number in [1, 2, 3, 4, 5]:
    total = total + number
```

代码段[2]使用加法增强赋值（+=）语句重写上面的代码，如下：

![](bbox=[0.203, 0.34, 0.798, 0.425])

代码段[2]中的“+=”表达式首先将number的值加到当前的total上，然后再将新值存储在total中。下表显示了增强赋值的示例。

| 增强赋值号 | 表达式举例 | 解释 | 赋值 |
|---|---|---|---|
| 假设：c = 3, d = 5, e = 4, f = 2, g = 9, h = 12 | | | |
| += | c += 7 | c = c + 7 | 10→c |
| -= | d -= 4 | d = d - 4 | 1→d |
| *= | e *= 5 | e = e + 5 | 20→e |
| **= | f **= 3 | f = f * 3 | 8→f |
| /= | g /= 2 | g = g / 2 | 4.5→g |
| //= | g //= 2 | g = g // 2 | 4→g |
| %= | h %= 9 | h = h % 9 | 3→h |
