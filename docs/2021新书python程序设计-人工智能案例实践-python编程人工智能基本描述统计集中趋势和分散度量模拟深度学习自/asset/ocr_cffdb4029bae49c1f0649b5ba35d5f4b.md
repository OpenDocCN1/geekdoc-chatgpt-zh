# ## 2.3 算术运算

下表总结了Python中的算术运算符，其中包括一些在代数中没有的符号。

| Python 运算 | 算术运算符 | 代数表达式 | Python 表达式 |
|---|---|---|---|
| 加法 | + | f+7 | f + 7 |
| 减法 | - | p-c | p - c |
| 乘法 | * | b · m | b * m |
| 求幂运算 | ** | x² | x ** y |
| 除法 | / | x/y 或 x/y 或 x÷y | x / y |
| 整除 | // | [x / y] 或 [x/y] 或 [x+y] | x // y |
| 取余（模） | % | r mod s | r % s |

# ### 乘法 (*)

Python将星号（*）作为乘法运算符，例如：

```
In [1]: 7 * 4
Out[1]: 28
```

# ### 求幂运算 (**)

求幂（**）运算符计算一个数的幂，例如：

```
In [2]: 2 ** 10
Out[2]: 1024
```

如需计算平方根，可以使用1/2（即0.5）作为指数：

```
In [3]: 9 ** (1 / 2)
Out[3]: 3.0
```
