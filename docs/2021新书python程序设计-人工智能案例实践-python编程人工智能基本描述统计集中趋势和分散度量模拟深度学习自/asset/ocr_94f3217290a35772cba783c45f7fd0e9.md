```
In [3]: c[0]
Out[3]: -45
In [4]: c[4]
Out[4]: 1543
```

# 列表的长度

使用内置函数len获取列表的长度：

```
In [5]: len(c)
Out[5]: 5
```

# 用负数索引访问列表末尾的元素

也可以使用负数索引从末尾访问列表元素，如下图所示。

![](bbox=[0.2, 0.45, 0.8, 0.51])

因此，列表c的最后一个元素（c[4]）也可以用c[-1]表示，第一个元素用c[-5]表示：

```
In [6]: c[-1]
Out[6]: 1543
In [7]: c[-5]
Out[7]: -45
```

# 索引必须是整数或整数表达式

索引必须是整数或整数表达式（或切片对象，我们很快就会看到）：

```
In [8]: a = 1
In [9]: b = 2
In [10]: c[a + b]
Out[10]: 72
```
