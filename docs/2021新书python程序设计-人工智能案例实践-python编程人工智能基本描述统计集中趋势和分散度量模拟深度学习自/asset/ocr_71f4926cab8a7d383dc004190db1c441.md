# 定义一个类

一个类的定义以class关键字开始（第5行），后面跟着类名和一个冒号（:），这行代码被称为类头。Style Guide for Python Code建议，应该将多单词类名中的每个单词的首字母大写（如CommissionEmployee）。类体中的每条语句都需要缩进。

```
# account.py
"""Account class definition."""
from decimal import Decimal

class Account:
    """Account class for maintaining a bank account balance."""
```
