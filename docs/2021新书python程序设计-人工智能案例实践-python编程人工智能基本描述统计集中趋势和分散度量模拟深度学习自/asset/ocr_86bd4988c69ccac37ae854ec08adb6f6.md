# 自然语言处理

NLTK（Natural Language Toolkit）—用于完成自然语言处理（NLP）任务。

TextBlob—一个面向对象的NLP文本处理库，基于NLTK和模式NLP库构建，简化了许多NLP任务。

Gensim—功能与NLTK类似。通常用于为文档合集构建索引，然后确定另一个文档与索引中每个文档的相似程度。
