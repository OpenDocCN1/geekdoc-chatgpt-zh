```
In [17]: tuple1 += (40, 50)

In [18]: tuple1
Out[18]: (10, 20, 30, 40, 50)

In [19]: tuple2
Out[19]: (10, 20, 30)
```

对于字符串或元组，+=右边的项必须分别是字符串或元组—混合类型会引发TypeError。

# 将元组添加到列表中

可以使用+=将元组附加到列表中：

```
In [20]: numbers = [1, 2, 3, 4, 5]

In [21]: numbers += (6, 7)

In [22]: numbers
Out[22]: [1, 2, 3, 4, 5, 6, 7]
```

# 元组可能包含可变对象

我们创建一个元组student_tuple，它包含名字、姓氏和成绩列表：

```
In [23]: student_tuple = ('Amanda', 'Blue', [98, 75, 87])
```

尽管元组是不可变的，但它的列表元素是可变的：

```
In [24]: student_tuple[2][1] = 85

In [25]: student_tuple
Out[25]: ('Amanda', 'Blue', [98, 85, 87])
```

student_tuple[2][1]是双下标名称，元组的元素student_tuple[2]包含列表[98, 75, 87]，下标[1]指向该列表的元素75，代码段[24]将该成绩替换为85。
