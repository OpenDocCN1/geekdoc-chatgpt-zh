+   - 街区经度。

每个样本有一个对应的房价中值作为其目标值，单位为10万美元，因此3.55代表355,000美元。在数据集中，此特征的最大值为5，表示500,000美元。可以预计，更多卧室数或更多房间数或更高收入就意味着更高的房价，通过组合这些特征来进行房价预测，更有可能获得更准确的预测。
