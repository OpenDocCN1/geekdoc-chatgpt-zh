+   如果需要输入并执行许多代码段，可以使用组合键Shift + Enter 代替组合键Ctrl + Enter（或Control + Enter），这样在执行完当前单元格后会在下面添加一个新单元格。

+   当学习到后面的章节时，将在Jupyter Notebook中输入的一些代码段会包含多行代码。此时，可以在JupyterLab的View菜单中选择Show line numbers在单元格中显示行号。
