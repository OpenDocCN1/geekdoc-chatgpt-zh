除了验证数据，正则表达式还经常被用于：

+   从文本中提取数据（我们一般称之为抓取）—例如，找到网页中的所有URL地址。一些人可能更喜欢使用BeautifulSoup、XPath和lxml这类工具；

+   数据清理—例如，删除不需要的或重复的数据、处理不完整的数据、修正错字、确保数据格式一致性、处理异常值等；

+   将数据转换为其他格式—例如，对于要求数据为CSV格式的应用程序，将原来以制表符或空格分隔的值收集起来，并重新格式化为由逗号分隔的值。

# 8. 12. 1 re模块与fullmatch函数

为了使用正则表达式，需要导入Python标准库的re模块：

```
In [1]: import re
```

最简单的正则表达式函数之一是fullmatch，它的作用是检查第二个参数传入的整个字符串是否与第一个参数传入的模式匹配。

# 匹配字面字符

首先来匹配字面字符，即那些与自身匹配的字符：

```
In [2]: pattern = '02215'
In [3]: 'Match' if re.fullmatch(pattern, '02215') else 'No match'
Out[3]: 'Match'
In [4]: 'Match' if re.fullmatch(pattern, '51220') else 'No match'
Out[4]: 'No match'
```

该函数的第一个参数是要匹配的正则表达式模式。任何字符串都可以是正则表达式。变量pattern的值'02215'仅包含能与自身按指定顺序匹配的字面数字。第二个参数是应该完全匹配模式的字符串。
