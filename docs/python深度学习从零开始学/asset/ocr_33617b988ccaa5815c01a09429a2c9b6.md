# 8.4.3 数据预处理

图片不能直接放入神经网络中进行学习，学习之前应该把数据格式化为经过预处理的浮点数张量。数据预处理大致分为 4 个步骤；

+   步骤 01 读取图像文件。
+   步骤 02 将 JPEG 文件解码为 RGB 像素网格。
+   步骤 03 将这些像素网格转换为浮点数张量。
+   步骤 04 将像素值 (0~255) 缩放到 [0,1] 区间（神经网络喜欢处理较小的数据输入值）。
