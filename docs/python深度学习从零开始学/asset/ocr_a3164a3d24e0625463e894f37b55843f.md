+   - shear_range: 随机错切变换的角度。
+   - zoom_range: 图像随机缩放的范围。
+   - horizontal_flip: 随机将一半图像水平翻转。如果没有水平不对称的假设（比如真实世界的图像），这种做法是有意义的。
