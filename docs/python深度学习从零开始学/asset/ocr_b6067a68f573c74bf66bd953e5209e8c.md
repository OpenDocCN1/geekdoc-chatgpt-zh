# 5.5 可视化工具 TensorBoard 的使用

TensorFlow 提供的 TensorBoard 可以让我们以可视化的方式来查看所建立的计算图。

TensorBoard 是一个非常有用的可视化工具，它对我们分析训练效果、理解训练框架和优化算法有很大的帮助。

首先，使用程序代码将要显示在 TensorBoard 的计算图写入 log 文件，代码如下：

```
merge_summary = tf.summary.merge_all()
writer = tf.summary.FileWriter("logs/", sess.graph)
```
