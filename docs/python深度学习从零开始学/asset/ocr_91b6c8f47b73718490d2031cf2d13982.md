# 1. 第一步：选择模型

Keras 的核心数据结构是模型，一种组织网络层的方式。最简单的模型是 Sequential 模型，由多个网络层线性堆叠。对于更复杂的结构，我们应该使用 Keras 函数式 API，它允许构建任意的神经网络图。

导入所需的模块，建立一个线性堆叠模型，即 Sequential 模型，代码如下：

```
from keras import models
from keras import layers
model = models.Sequential()
```

后续只需要使用 model.add() 方法将各个神经网络层加入模型即可。

# 2. 第二步：构建网络层

其实就是设计我们的网络结构，调用 Keras 神经网络的各个模块来组装我们的模型架构，通过 add 方法来叠加。这一步是最需要仔细考虑的地方，关乎我们的神经网络的复杂性和高效与否。Kearas 已经内建各种神经网络层（例如 Dense 层、Conv2d 层），这里使用 moddel. add 方法加入 Dense 层。
