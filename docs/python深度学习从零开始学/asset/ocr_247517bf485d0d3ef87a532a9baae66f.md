之后在 Jupyter Notebook 进行的所有操作，都必须保持终端处于打开状态，因为一旦关闭终端，就会导致与本地服务器的连接，我们就将无法在 Jupyter Notebook 中进行操作。

浏览器地址栏中将会默认显示 http://localhost:8888，如图 2-4 所示。其中，localhost 指的是本机，8888 则是端口号。启动界面显示了当前文件目录信息。Jupyter 保存文件的根目录，对应操作系统中登录用户的主目录。
