( Shape ) 为 \(n \times m\) 维； \(V\) 表示隐含层到输出层的权值矩阵，尺寸为 \(m \times r\) 维。前面这两个参数矩阵与普通的前馈神经网络完全一样，它们代表的是“现在”

那么，\(W\) 又是什么呢？ 通过前面的介绍，我们知道，\(W\) 表示用隐含层上一次的输出值作为本次输入的权值矩阵，尺寸为 \(m \times m\) 维，它代表的是“历史”

由图 8-4 可知，在理论上，这个模型可以扩展到无限维，也就是说，可以支撑无限时间序列。但实际上，并非如此，就如同人脑的记忆力是有限的。下面我们对 Elman 循环神经网络的结构和符号进行形式化定义。我们先用一个函数 \(f^{(t)}\) 演示经过 \(t\) 步展开后的循环，即

\(s^{(t)} = f^{(t)}(x^{(t)}, x^{(t-1)}, x^{(t-2)}, ..., x^{(2)}, x^{(1)}) = \begin{cases} 0, & t = -1 \\ \sigma(a^{(t-1)}, x^{(t)}; \theta) & t \ge 0 \end{cases}\)  
( 8-1 )

函数 \(f^{(t)}\) 将过去到现在的所有序列 \(X = (x^{(t)}, x^{(t-1)}, x^{(t-2)}, ..., x^{(2)}, x^{(1)})\) 作为输入，从而生成当前的状态，其中，\(\sigma\) 表示激活函数，\(\theta\) 表示激活函数中所有涉及的参数集合。\(x^{(t)}\) 表示序列中第 \(t\) 时刻或第 \(t\) 时间步的输入数据，它通常也是一个向量；向量 \(a^{(t)}\) 表示隐含层的值。

在式（8-1）中，激活函数 \(\sigma\) 是一个平滑的、非线性的有界函数，它可以是前面章节中提到的传统的 Sigmoid 函数、Tanh 函数，也可以是新兴的 ReLU 等。一般来讲，我们还需要设定一个特殊的初始隐含层 \(a^{(-1)}\)，表示初始的“记忆状态”，通常将其设置为零。

由式（8-1）可知，第 \(t\) 时刻的记忆信息有两个部分构成：（1）前(t-1)个时间步“沉淀”下来的历史信息 \(a^{(t-1)}\)；（2）当前的输入 \(x^{(t)}\)。它们两个共同“叠加”形成当前的记忆事实。这些信息保存在隐含层中，不断向后传递，跨越多个时间步，共同影响每个新输入信息的处理结果。
