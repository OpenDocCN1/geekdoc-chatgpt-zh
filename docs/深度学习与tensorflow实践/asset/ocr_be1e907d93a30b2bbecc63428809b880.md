若令其等于零，即 \(w_1x_1 + w_2x_2 + ... + w_nx_n = 0\)，该方程可视为一个在 \(n\) 维空间的超平面 \(P\)。那么感知机以向量的模式写出来就是 \(w \cdot x = 0\)，如图 2-10 所示，这里，\(w \cdot x\) 表示输入向量 \(x\) 和权值向量 \(w\) 的内积。

```
$f(x) = w_1x_1 + w_2x_2 + ... + w_ix_i + ... + w_nx_n - \theta = w_0x_0 + w_1x_1 + ... + w_ix_i + ... + w_nx_n = w \cdot x$
```

![](bbox=[0.72, 0.15, 0.97, 0.31])

图 2-10 感知机的超平面

这样一来，超平面一侧的实例 \(w \cdot x > 0\)，它表示点 \(x\) 落在超平面的正半空间，此时激活函数 \(\sigma(w \cdot x) = 1\)，即感知机的输出为 1（判定为正类）；而超平面的另外一侧实例 \(w \cdot x < 0\)，表示点 \(x\) 落在超平面的负半空间，此时激活函数 \(\sigma(w \cdot x) = 0\)，即感知机的输出为 0（判定为负类）。

> 亦有资料将输出为“1”表示正类，而输出“-1”表示负类。只受正负类的输出有区分度即可，无需拘泥于具体数字。

于是，感知机可看作一个由超平面划分空间位置的识别器。当特征数量 \(n\) 为两三个维度时，人们尚可利用它的几何空间来直观解释这个分类器，但当 \(n\) 更大时，人们很难再用它的几何意义来研究神经网络。

# 2.2.8 实战：基于 Python 的感知机实现

按照前文的描述，可将感知机描述为一个线性方程。完整的感知机算法如范例 2-1 所示。

# 例 2-1 感知机的构建 ( Perceptron.py )

```
class Perceptron(object):
    def __init__(self, input_para_num, acti_func):
        self.activator = acti_func
        self.weights = [0.0 for _ in range(input_para_num)]
        #对象的“非正式”字符串表示形式
    def __str__(self):
        return 'final weights\n\tw0 = {:.2f}\n\tw1 = {:.2f}\n\tw2 = {:.2f}'.format(self.weights[0], self.weights[1], self.weights[2])
    def predict(self, row_vec):
        act_values = 0.0
        for i in range(len(self.weights)):
            act_values += self.weights[i] * row_vec[i]
        return self.activator(act_values)
    #训练权值
    def train(self, dataset, iteration, rate):
        for i in range(iteration):
            for input_vec_label in dataset:
                prediction = self.predict(input_vec_label)
                self._update_weights(input_vec_label, prediction, rate)
```
