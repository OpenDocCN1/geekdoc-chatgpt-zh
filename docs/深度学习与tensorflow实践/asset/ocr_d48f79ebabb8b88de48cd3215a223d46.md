# 2.6.3 sklearn 搭建多层神经网络实现红酒分类

在 sklearn 中，内置了多种知名的数据集，其中一种就是自带的数据集（Packaged Dataset）。在成功安装 sklearn 软件包后，只需调用对应的数据导入方法，即可完成数据的加载。这些导入数据方法的命名规则是 sklearn.datasets.load_<name>，而这里的<name>就是对应的数据集名称。常用的数据集名称如表 2-2 所示。

| 导入数据的函数名称 | 对应的数据集 |
|---|---|
| load_boston() | 波士顿房价数据集 |
| load_breast_cancer() | 乳腺癌数据集 |
| load_iris() | 鸢尾花数据集 |
| load_diabetes() | 糖尿病数据集 |
| load_digits() | 手写数字数据集 |
| load_linnerud() | 体能训练数据集 |
| load_wine() | 葡萄酒分类数据集 |

下面我们基于 Jupyter 的 Notebook 作为交互平台，来分步骤讲解如何利用 sklearn 搭建神经网络。
