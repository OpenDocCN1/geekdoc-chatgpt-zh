In [15]处代码的功能是创建均值为 10，标准差为 2 的正态分布张量，其尺寸为 3 行 2 列。TensorFlow 除可以创建正态分布外，还提供了创建均匀分布的方法。通过 tf.random.uniform(shape, minval=0, maxval=None, dtype=tf.float32)方法，可以创建采样区间[minval, maxval]均匀分布的张量。

```
In [17]: uni_tensor = tf.random.uniform([2,2])
In [18]: print(uni_tensor)
Out[18]:
tf.Tensor(
[[0.10641289 0.6318289 ]
 [0.4701332 0.17339122]], shape=(2, 2), dtype=float32)
```

上述代码完成功能是，创建采样区间为[0,1)、尺寸为[2,2]，即 2 行 2 列的张量。这个采样区间是可以自定义的，若不指定取值区间，则默认的采样区间为[0,1)。需要注意的是，均匀分布指定的上限区间和下限区间是左闭右开的，即最大值是取不到的。例如，下面的代码实现的功能就是生成采样区间为[1,10)，即尺寸为[2,3]的整型张量。

```
In [19]: uni_tensor2 = tf.random.uniform([2,3],
              minval = 1,
              maxval = 10,
              dtype = tf.int32)
In [20]: tf.print(uni_tensor2)
[[1 8 6]
 [4 8 7]]
```
