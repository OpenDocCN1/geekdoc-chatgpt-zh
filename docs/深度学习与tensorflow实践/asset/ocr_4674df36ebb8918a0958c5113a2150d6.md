(1) 将 $y$、$z$ 视为常量，求 $x$ 的局部导数，即

$$\frac{\partial f}{\partial x} = 2x + 3y$$

(2) 然后将 $x$、$z$ 视为常量，求 $y$ 的局部导数，即

$$\frac{\partial f}{\partial y} = 3x + 2y$$

(3) 最后将 $x$、$y$ 视为常量，求 $z$ 的局部导数，即

$$\frac{\partial f}{\partial z} = 3z^2$$

于是，函数 $f$ 的梯度可表示为

$$\nabla f = \text{grad}(f) = (2x + 3y, 3x + 2y, 3z^2)$$

针对某个特定点，如向量量 $A(1, 2, 3)$，代入对应的值即可得到该点的梯度，如图 5-2 所示。

$$\nabla f = \text{grad}(f) = (2x + 3y, 3x + 2y, 3z^2)|_{x=1, y=2, z=3} = (8, 7, 27)$$

对于函数的某个特定点，它的梯度表示从该点出发，函数值增长最快的方向。对于如图 5-2 所示的案例，梯度可理解为：在向量点 $A(1, 2, 3)$，若想让函数 $f$ 的值增长得最快，则它的下一个前进的方向就是朝着向量量 $B (8, 7, 27)$ 方向进发。
