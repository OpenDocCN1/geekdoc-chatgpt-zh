类似地，经过激活函数（阶跃函数）处理后，实际输出结果 y' = f = 0，判定也正确，误差 ε 为 0。

在这个示例中，仅仅经过一轮“试错法”，我们就完成了参数的训练，但我们需要知道，这只是一个“Hello World!”版本的神经网络！事实上，在有监督的学习规则中，我们需要根据输出与期望值的“落差”，经过多轮重试，反复调整神经网络的权值，直至这个“落差”收敛到我们能够忍受的范围内，训练才宣告结束。
