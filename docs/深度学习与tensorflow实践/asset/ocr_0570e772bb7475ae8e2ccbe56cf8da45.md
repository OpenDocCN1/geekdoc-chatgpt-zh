# 代码解析

由于实验数据来自于经典的数据集合，因此数据读取部分的代码和第 6 章的代码类似，而不同的是，这里将数据的加载与一些必要的预处理打包“封装”成一个数据读取的类。我们知道，封装是面向对象编程的一个重要特征，良好的封装性，能提供更为简捷的应用界面。

第 06 行为 datasets.mnist.load_data()配置了数据加载路径，它会从本地设置好的路径加载数据。

对于具备上网条件的读者，可将第 05 ~ 06 行代码，用如下一行代码代替。

```
(x_train, y_train), (x_test, y_test) = load_data ()
```

这是因为，若不设置数据读取路径，则会从国外的一些云平台上自动下载，然而国内下载这些数据集的速度，可能会非常缓慢。
