# 7.5.5 权值共享

卷积层涉及的另外一个核心概念是权值共享（Shared Weights）。那么为什么要实现权值共享机制呢？其实也是无奈之举。前文我们提到，通过局部连接处理后，神经元之间的连接个数已经有所减少。但如果卷积核比较多，那么整体上的下降幅度并不大，还是无法满足高效训练的需求。而权值共享就是来解决这个问题的。该如何理解权值共享呢？
