为了说明问题，假设我们有如图 5-12 所示的三层神经网络。在该网络中，假设输入层的信号向量为[1, -1]，输出层的目标向量为[1, 0]，学习率 $\eta$ 为 0.1，权值是随机给的，这里为了演示方便，分别将权值赋值为“1”或“-1”。下面我们详细讲解 BP 算法是如何运作的。

在正向传播过程中，对于 $f_1(e)$ 神经元的更新如图 5-13 所示，其计算过程如下。

```
f_1(e) = f_1(w_{11}x_1 + w_{21}x_2)
= f_1((-1)\times1 + 1\times(-1))
= f_1(-2)
= \frac{1}{1+e^{-(-2)}}
= 0.12
```

接着，更新在同一层的 $f_2(e)$（见图 5-14），过程和计算步骤与 $f_1(e)$ 类似。

```
f_2(e) = f_2(w_{12}x_1 + w_{22}x_2)
= f_2(1\times1 + 1\times(-1))
= f_2(0)
= \frac{1}{1+e^0}
= 0.5
```
