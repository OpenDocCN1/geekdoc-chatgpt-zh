# 图 32 数据偏差

“Scalable k-Means Clustering via Lightweight Coresets” 是 Google Brain 团队在 KDD Research Track 上的一篇文章，这是 Google 在瑞士的团队作品，瑞士这帮忙还是比较喜欢理论的，这篇文章也是和社会网络中比较喜欢理论研究的、瑞士理工的 Andreas Krause 教授合作的文章。基本思想就是做一个快速 K-means 算法或者说适用于大规模数据的 K-means 算法，具体思路是利用抽样的方法从原始数据中抽样出一个足够小的子集（称为 Coresets），然后在这个 Coresets 上进行训练，最后得到的结果和在大规模数据上的结果相当。文章理论证明了保证精度的情况下 Coreset 大小和数据集的特征个数 d 以及聚类个数据 k 的乘积成正
