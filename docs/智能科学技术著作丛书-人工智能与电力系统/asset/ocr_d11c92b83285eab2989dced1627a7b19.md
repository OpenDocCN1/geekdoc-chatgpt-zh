# 2. 风电功率的概率区间预测结果

针对风电功率的概率区间预测研究，有研究者将功率点的分布情况作为研究对象，选择一组样本数据，先根据历史数据情况或一般规律产生经验分布，后结合相关的方法去求解基于该数据的分布参数。这种做法虽然对某个风电场具有一定的可行性，但由于全国各地风电场的地理、气象信息都有一定差异，无法保证相同的风电功率分布，因此缺乏一定的通用性。

不同于功率点的分布，功率预测误差的分布情况受风电场地理信息、气象因素等客观条件影响相对较小。此外，非参数核密度估计不需要对预测功率误差的分布情况做出一定的假设，依靠核函数和窗宽的形式即可实现拟合，不仅通用性强，而且拟合出的概率密度函数更逼近真实信息。因此，以风电历史功率预测误差作为功率密度分布的研究对象，基于最优窗宽和随机窗宽非参数核密度估计方法的风电功率预测误差概率密度分布，以及假定风电功率预测误差服从高斯分布的参数估计方法的概率密度函数如图 4.5 所示，其中，高斯分布模型的均值为 10.21，标准差为 90.50。
