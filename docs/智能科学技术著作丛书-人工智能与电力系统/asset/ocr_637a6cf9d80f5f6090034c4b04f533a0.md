因此优化算法中应对浓度过高的个体进行抑制，保证个体的多样性。

抗体浓度通常定义为

den(ab_i) = 1/N Σ_{i=1}^{N} S(ab_i, ab_j)  (2.3)

# 3)激励度计算算子

抗体激励度是对抗体质量的最终评价结果，需要综合考虑抗体亲和度和抗体浓度。通常抗体亲和度大、浓度低的抗体<|message|>会得到较大的激励度，抗体激励度的计算通常可以利用抗体亲和度和抗体浓度的评价结果进行简单的数学运算得到，如

sim(ab_i) = a · aff(ab_i) − b · den(ab_i)  (2.4)

或

sim(ab_i) = aff(ab_i) e^{−a·den(ab_i)}  (2.5)

式中，sim(ab_i)为抗体激励度，计算参数a、b_i根据实际情况确定；aff为抗体亲和度；den为抗体浓度。

# 4)免疫选择算子

免疫选择算子根据抗体的激励度确定选择哪些抗体进入克隆选择操作，在抗体群中激励度高的抗体个体具有更好的质量，更有可能被选中进行克隆选择操作，在搜索空间中更有搜索价值。

# 2.2.2 免疫算法的特点

免疫算法与其他算法相比有如下特点：

+   (1) 有记忆功能，即能加快搜索速度，更迅速敏捷地在记忆单元基础之上进行，确保快速收敛于全局的最优解。\n(2) 具有自然调节的功能，即维持平衡、抑制和促进个体浓度，提高局部搜索能力。\n(3) 提高抗体的多样性，即有计算亲和度的程序，抗体和抗原的匹配程度即解和目标的匹配程度体现全局搜索的能力。
