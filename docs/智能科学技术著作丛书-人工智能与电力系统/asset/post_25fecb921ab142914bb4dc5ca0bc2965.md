## 6.1.2 优化配置模型的算法

选取 APSO 对所构建的优化模型进行求解，APSO 的模型如下：

v_{id}^{k+1} = w v_{id}^{k} + c_1 r_1 (p_{id}^{k} - x_{id}^{k}) + c_2 r_2 (p_{gd}^{k} - x_{gd}^{k})  (6.22)

x_{id}^{k+1} = round(x_{id}^{k} + v_{id}^{k})  (6.23)

w = w_{min} + (w_{max} - w_{min}) (f - f_{min}) / (f_{avg} - f_{min})  (6.24)

式中，v_{id}^{k+1} 为第 i 个粒子在第 k+1 次迭代中的速度；w 为惯性权重；c₁、c₂ 为学习因子；r₁、r₂ 为[0,1]内的随机数；round(x_{id}^{k}+v_{id}^{k}) 为对第 i 个粒子在第 k 次迭代中的位置取整数；w_{max}、w_{min} 分别为惯性权重的最大值、最小值；f 为粒子在本次迭代中的目标函数值；f_{avg}、f_{min} 分别为本次迭代中所有粒子的平均目标函数值及最小函数值。

- 1. 基于 APSO 对不同优化目标模型下的电源容量配置求解

基于 APSO 对不同优化目标模型下电源容量配置求解的具体流程如图 6.3 所示，步骤如下：

(1) 对粒子进行初始化。设定粒子的种群规模为 100 个，迭代次数为 100 次，c₁ = c₂ = 1.49445，粒子维数为 4，即优化变量有 4 个，x = [N_{PV}, N_{WT}, N_{DG}, N_{BESS}]。

(2) 选择出力模式。对孤网模式下的微电网进行四种不同优化目标模型的电源容量优化配置，孤岛运行的微电网分布式电源的出力顺序一般可以分为风-光 (wind-light, WL)、风-光-储 (wind-light-storage, WLS)、风-光-储-柴 (wind-light-storage-diesel, WLSD) 三种方式，其能量控制策略如下。

![](img/2160aa82ffab89ad09fb1b4e167a298b_181_0.png)

图 6.3 基于 APSO 对不同优化目标模型下电源容量配置求解流程

首先由清洁型电源出力，即 PV 和 WT 出力为负载供应电能，设 PV 和 WT 提供的电能分别为 P_PV、P_WT，那么清洁型发电单元出力与负载需求电能的差值为

ΔP(t) = P_WT(t) + P_PV(t) - P_LD(t)  (6.25)

若 ΔP(t) > 0，即清洁型电源在能够满足负载电能需求的同时，还有电能盈余，在储能电池荷电状态未达上限的情况下，对其进行充电，若电能盈余小于储能电池允许的充电功率，则储能电池吸收电能为

P_BESS(t) = ΔP(t)  (6.26)

反之，若盈余电能超过储能电池的荷电状态，则储能电池应充电以达到其荷电状态上限的电能，多余电能通过备用负载或其他方式进行消纳。

若ΔP(t)<0，即清洁型电源出力无法满足负载的电能需求，则优先由储能电池释放电能；若其能完全弥补负载电能缺少量，则储能电池释放的电能为

P_{BESS}(t)=|-ΔP(t)|  (6.27)

反之，BESS 释放最大电能直至达到荷电状态的下限，若仍未满足电能需求则由 DE 进行电能供应，DE 出力大小为

P_{DG}(t)=P_{L}(t)-P_{WT}(t)-P_{PV}(t)-P_{BESS}(t)  (6.28)

若 BESS 和 DE 联合出力均无法满足负载电能缺额，即

P_{L}(t)-P_{WT}(t)-P_{PV}(t)-P_{BESS}(t)-P_{DG}(t)<0  (6.29)

则将负载缺电量计入系统 PR 约束中。

(3)基于 APSO 的优化迭代。在确定各个粒子对应的出力后，将其代入适应度函数 C_{INVE}=C_{GE}+C_{FU}+C_{OM} 中，运用 APSO 求解每个粒子的适应度值，也就是对应的目标函数值，直至满足迭代次数 100 次。

(4)输出结果。对于四种不同的优化目标模型，分别对其进行容量优化配置，对结果进行统计分析，并给出关于微电网电源容量配置的相关建议。

### 2. 基于 APSO 对不同能量控制策略下的电源容量配置求解

基于 APSO 对不同能量控制策略下的电源容量配置求解流程如图 6.4 所示。孤网运行微电网的能量控制策略比较单一且相对简单，因此本部分研究并网运行情况下不同能量控制策略对电源容量优化配置的影响。

基于 APSO 对不同能量控制策略下的电源容量配置的求解与基于 APSO 对不同优化目标模型下的电源容量配置求解相似，此处不再赘述，只将不同之处加以具体说明，存在的不同之处为：

(1)适应度函数不同。并网型微电网在适应度函数中引入与大电网进行功率交换的成本/收益 C_{Grid}，适应度函数具体修正为

C_{INVE}=C_{GE}+C_{FU}+C_{OM}+C_{Grid}  (6.30)

C_{Grid}=∑_{t=1}^{T}c_{Grid}(t)P_{Grid}(t)  (6.31)

式中，c_{Grid}(t)为 t 时刻微电网与大电网进行功率交换时的实时电价。P_{Grid}(t)为 t 时刻微电网与大电网交换的功率，若大于零，则表示从大电网购买电能；若小于零，则表示向大电网出售电能。

(2)供电 PR 约束不同。在孤网运行的微电网中，由于没有大电网的支撑，可能会出现系统的分布式电源无法完全满足负载需求，导致出现负载缺电的现象，而并网运行的微电网，当微电网系统内分布式电源不能满足负载需求时，可向大电网购买电能，所以不存在负载缺电的现象，因此将此约束条件修正为
