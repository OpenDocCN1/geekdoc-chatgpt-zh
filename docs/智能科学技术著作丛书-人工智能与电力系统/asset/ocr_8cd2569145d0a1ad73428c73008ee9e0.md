利用负荷未供应期望和能量未供应期望来衡量能量枢纽系统出力的可靠性，当系统可靠性较低时，即当能量枢纽不能满足负荷的供应需求时，本节定义能量缺额部分产生的损失成本为能量枢纽的可靠性惩罚成本。能量枢纽包含电、热两种负荷，因此与可靠性相对应的失负荷惩罚成本可用式(6.44)~式(6.46)表示，即

PC_t = PC_t^e + PC_t^h  (6.44)
PC_t^e = EENS^e · VOLL^e  (6.45)
PC_t^h = EENS^h · VOLL^h  (6.46)

式中，PC_t^e、PC_t^h 分别为电、热失负荷惩罚成本；VOLL^e、VOLL^h 分别为电、热失负荷价值。

EENS_{jty} = p_s ES_{jty} du_t  (6.47)

式中，EENS_{jty} 为 t 时刻满足第 j 种负荷需求时组件 γ 发生故障的能量未供应期望；p_s 为第 s 个场景负荷未供应概率；ES_{jty} 为 t 时刻满足第 j 种负荷需求时组件 γ 发生故障的能量供应期望；du_t 为相应的时间段。

将惩罚成本这一目标函数线性化，如下：

PC_t = VOLL × Σ_{γ} Σ_{t}^{NT} Σ_{j=e,h} p_k ES_{jty} du_t
= VOLL × Σ_{γ} Σ_{t}^{NT} Σ_{j=e,h} I_γ FOR_γ (1-FOR_γ)^{-1} p_0 ES_{jty} du_t
= VOLL × p_0 × { Σ_{γ} I_γ [ FOR_γ (1-FOR_γ)^{-1} Σ_{t}^{NT} Σ_{j=e,h} ES_{jty} du_t ] }
= VOLL × p_0 × ( Σ_{γ} I_γ λ_γ )  (6.48)

λ_γ = FOR_γ (1-FOR_γ)^{-1} Σ_{t}^{NT} Σ_{j=e,h} ES_{jty} du_t  (6.49)

式中，FOR_γ 为设备的可靠性指标数值。

综上，可以得到惩罚成本的线性化表述为

PC = VOLL × μ^{N+1}  (6.50)
