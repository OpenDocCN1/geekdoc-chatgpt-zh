## 3. 非侵入式负荷监测的卷积神经网络架构

在这项研究中，以 VGG-16 为基础的卷积神经网络架构旨在解决非侵入式负荷监测和识别问题。提出的体系结构由 13 个卷积层、5 个池化层、3 个全连接层和 1 个 softmax 层组成，具有小卷积核和出色生成性能的特征。卷积神经网络体系结构的主要结构用于 320×320 灰度图像。

卷积层被设计用于通过具有一定大小的卷积滤波器来提取家用电器的特征，因此卷积层是卷积神经网络的基本运算符号。新的卷积层特征图可以在上一层卷积内核之后获得，基于激励函数的处理如下：

$$Y_j^l = f\left(\sum_{s \in M_{j(l-1)}} \sum_{(u,v) \in K^{(l)}} w_{js}^l(u,v) x_s^{(l-1)}(c+u, r+v) + b_j^{(l)}\right) \tag{5.5}$$

式中， $K^{(l)} = \{(u,v) \in N^2 | 0 < u < K_w, 0 < v < K_h \}$， $K_w$ 和 $K_h$ 分别为卷积核的宽度和高度； $l$ 为当前层数； $b_j^{(l)}$ 为卷积层第 $j$ 个特征图的神经元偏置； $s \in M_{j(l-1)}$ 为先前特征图的集合。

在卷积层之后，使用池化层进行下采样，抗过度拟合并保持特征不变。在本节中，最大池操作用于池化层，详细过程如下：

$$Y_j^l = \text{down}(Y_j^{l-1}) \tag{5.6}$$

式中，down 为下采样。在最大池模式下，可以选择大小为 n×n 的滤波器最大值，用以重新构造新的特征图。经过几次卷积和池化操作后，利用全连接层来增强非线性映射功能并限制网络的大小。全连接层的操作可以表示为

$$o_j^l = f\left(\sum_{i=1}^{n} x_i^{(l-1)} w_{ji}^{(l)} + b_j^{(l)}\right)\tag{5.7}$$

式中，n 为先前各层的神经元数量；l 为当前层数；w_{ji}^{(l)} 为当前层 j 和最后一层中神经元 i 之间的连接强度；b_j^{(l)} 为神经元偏置；f(·) 为激励函数。

最后，softmax 层充当分类器。在 softmax 层的训练过程中，利用随机梯度下降来最小化交叉熵损失函数，损失函数表示如下：

$$J(\theta) = -\frac{1}{N} \left[ \sum_{i=1}^{N} \sum_{c=1}^{C} t_{iC} \log \frac{e^{\theta_i^T x_i}}{\sum_{l=1}^{C} e^{\theta_l^T x_i}} \right]\tag{5.8}$$

式中，当第 i 个样本属于 C 类负荷时，t_{iC}=1；\sum_{l=1}^{C} e^{\theta_l^T x_i} 为归一化输出概率。

## 5.2 基于马尔可夫模型的负荷辨识

针对低频采样下负荷辨识准确率低和辨识精度低的问题，本节提出基于多特征融合的家用负荷辨识算法：首先建立整数规划模型求解负荷存在的可能性，以降低负荷辨识的计算维度；然后基于滑动时间窗口算法获得组合功率序列和原始功率序列，提取两者功率序列的统计特征值和奇异值，以弥补描述负荷特征信息不足的情况，并利用概率神经网络 (probabilistic neural network, PNN) 与 D-S 证据理论进行多特征融合，并将融合结果作为隐马尔可夫模型 (hidden Markov model, HMM) 的观察值序列，最后基于 HMM 的序列信息融合完成家用负荷的再辨识，并获得各个负荷耗电量的估计值。HMM 的建立主要考虑到各个负荷在运行过程中不仅与该时刻的功率值有关，还受上一时刻功率状态的间接影响，仅基于负荷

特征值进行负荷辨识而不考虑负荷各个时刻状态的情况将会降低负荷辨识准确率，因此 HMM 的引入将会大大提高辨识算法的准确率和辨识精度[22]。

### 5.2.1 多特征序列融合的负荷辨识原理

非侵入式负荷辨识技术是在用户入口处安装监测设备获得总用电信息，从而辨识用户各用电负荷类型和工作状态并上传到客户终端，最终获得用户的用电行为、各负荷工作状态和耗能情况。

负荷总用电信息包括电流、电压、有功功率和无功功率等参量，而有功功率是用电负荷耗电时最直接的电气特征，同时也是用户最关心的特征，本节基于多特征序列融合的非侵入式负荷辨识技术框架如图 5.3 所示。

![](img/2160aa82ffab89ad09fb1b4e167a298b_134_0.png)

图 5.3 基于多特征序列融合的非侵入式负荷辨识技术框架

在图 5.3 中，通过采集装置获得负荷总用有功功率，负荷有功功率通过时间滑动窗口算法获得功率序列，其辨识框架主要包括如下内容：

- (1) 负荷初辨识，即通过整数规划求解可能存在的负荷工作状态组合。
- (2) 负荷特征提取，即通过组合功率序列和原始功率序列计算统计特征和奇异值特征。
- (3) 多特征融合，即利用 PNN 分别对统计特征和功率序列奇异值特征进行特征信度赋值，并通过 D-S 证据理论进行信息融合。
- (4) 功率序列信息融合，即通过对功率序列进行 HMM 建模，并以相似度最大值的负荷组合为负荷辨识结果。

### 1. 负荷初辨识与负荷特征提取

各个负荷在使用过程中，使用者开启负荷种类不同导致用电功率也不同。通过用电功率实现用电负荷的辨识，假设某时刻家庭用户入口总表检测家庭用电总功率为 P(t)，用电负荷使用时可能存在的组合负荷启停状态向量为 S。根据能量守恒定律可得

S ∈ { S | | ΔP = P(t) − X^T S | ≤ θ_max }  (5.9)

式中，负荷启停状态向量 S 的元素的取值限定在 0 和 1 两个数值，1 和 0 分别为该用电负荷开启和关闭； X_i (X 中的元素) 为第 i 个用电负荷的功率状况， X_min i ≤ X_i ≤ X_max i ， X_min i 和 X_max i 分别为负荷的最小运行功率和最大运行功率； θ_max 为负荷功率允许的最大误差，主要考虑负荷待机功率和线路损耗等因素。通过上述整数规划方法可求出该时刻家庭所用负荷可能存在的工作状态组合。

需要对负荷特征进行提取，用电负荷功率序列特征主要包括功率序列统计特征和功率序列奇异值特征，主要采用滑动时间窗口算法来提取各负荷功率序列，分别对负荷功率序列进行统计特征提取和奇异值提取，对节能灯、台式电脑和微波炉随机抽取 5 组样本，并提取不同采样样本的奇异值。

### 2. 多特征融合

对于负荷特征的融合，首先将负荷功率序列统计特征和功率序列奇异值特征作为特征向量输入 PNN 中，以进行特征信度赋值，然后通过 D-S 证据理论将两者的特征信度赋值矩阵进行融合。

PNN 是一种基于径向基神经网络与经典概率密度的前馈型神经网络，通过 PNN 可以对负荷功率序列统计特征和功率序列奇异值特征进行特征信度赋值，具体步骤如下。

假设负荷功率序列的统计特征为 φ_k ，奇异值特征向量 ψ 的维数为 n_i (i=1, 2,⋯)；初辨识后判断每个可能存在的负荷组合，每组提取 k 个训练样本、 m 个分类层， m 为初辨识得到的可能存在的负荷组合数。

本节以负荷功率序列统计特征向量 φ_k 和奇异值特征向量 ψ 分别作为 PNN 的输入层，输入层将各个特征向量进行归一化后输入隐含层，同时根据分析可知隐含神经元的数目为 n×k 个，最后通过响应函数 (5.10) 得到输出层，即为信度赋值矩阵 M，输出层神经元的数目与最终辨识负荷组合数目相关，即输出层的神经元数目为 m 个：

$$Y_{m,j}(X)=\exp\left(\frac{x^{\mathrm{T}}x_{m,j}-1}{\sigma^{2}}\right)\tag{5.10}$$

式中， x_{m,j} 包含统计特征向量 φ_k 和奇异值特征向量 ψ ，为第 m 种负荷组合的第 j 个训练样本向量， j=1,2,⋯,w ， w 为训练样本总数； σ 为平滑参数。

D-S 证据理论在多特征融合中得到广泛应用。根据 D-S 证据理论，针对多特征序列融合，基本的处理步骤为，假设 m1(a) 和 m2(b) 分别为一组可能存在负荷的基础负荷功率序列统计特征和功率序列奇异值特征的基本信度赋值，分别为 a1,a2,⋯,ai 和 b1,b2,⋯,bj ，组合结果 m(c) 为

m(c)=\frac{\sum_{a_i\cap b_j} m_1(a_i)m_2(b_j)}{1-\xi}\qquad(5.11)

\xi=\sum_{a_i\cap b_j} m_1(a_i)m_2(b_j)<1\qquad(5.12)

### 3. 功率序列信息融合

通过大量实验计算，基于 PNN 与 D-S 证据理论基本可以解决负荷辨识问题，但对于多负荷多状态存在准确率较低的问题，本节考虑负荷运行功率序列之间存在的联系以增加负荷辨识的准确率。各个负荷运行功率序列之间的联系体现在各个功率负荷在运行过程中，由于负荷使用者和负荷本身的特性，将导致负荷在不同时刻具有不同的运行状态，但是各负荷工作状态存在一定的联系。对于在连续时间内启停时序不同的负荷用电功率状态，利用功率序列信息和负荷辨识结果相结合的方法，可以很好地提高负荷的辨识准确率和辨识的鲁棒性。本节利用 HMM 对各个负荷功率序列的状态信息进行融合。

在负荷识别过程中，准确判断各个负荷的启停及工作状态是负荷辨识成功的关键点，对负荷存在的可能集合建立一个 HMM，考虑到当负荷种类过多时，维度也相应增加，本节利用整数规划对负荷进行初辨识以降低维度。

根据负荷存在的组合建立 HMM，具体建模方法如下。

### 1) 负荷状态建模

将用电负荷分为单状态、多变化和多状态三大类，把负荷运行过程中存在的状态作为 HMM 的状态。单状态负荷是指当负荷开启时，负荷运行功率与额定功率范围基本相同，且基本保持不变；多变化负荷是指由于用户使用情况的不同导致负荷运行功率不断变化的负荷；多状态负荷是指负荷由于本身的使用特点而导致多个工作状态，如冰箱属于间歇性工作，有制冷、正常工作和停止工作三种状态。

### 2) 负荷观察值建模

本节采用的构建方法与上述负荷状态的构建方法相似，把每个负荷的每个状态作为观察值。观察值通过多特征融合的结果获得，即对于长度为 2N 的功率序列，首先提取负荷功率序列统计特征和功率序列奇异值特征，运用 PNN 对其进行概率值向量的输出，获得特征信度赋值矩阵。然后利用 D-S 证据理论对两个特征向量进行特征融合，获得 HMM 的观察值序列。最后通过计算观察值序列和各个负荷组合之间的相似概率值，取最大值对应的类别作为最终负荷辨识结果[23]。

### 5.2.2 多特征序列融合的负荷辨识流程

### 1. 识别算法流程

首先，对于在某一时刻需辨识的负荷或者负荷组合，采用滑动时间窗口算法得到功率序列，并对该序列进行特征提取，获得负荷功率序列统计特征和功率序列奇异值特征。然后，利用两个训练好的 PNN 对负荷功率序列统计特征和功率序列奇异值特征进行基本信度赋值，并归一化处理，再利用 D-S 证据理论对基本信度赋值矩阵进行序列融合，完成负荷多特征序列融合过程，从而得到观测值序列。最后，计算前向变量为

$$\Omega_{t}(i)=P_{r}(o_{1},o_{2},\cdots,o_{t},q_{t}=s_{i}\,|\,\lambda),\quad -N\leqslant t\leqslant N-1\tag{5.13}$$

$$P_{r}(o_{2N}\,|\,\lambda)=\sum_{s_{i}}P_{r}(o_{-N},o_{-N+1},\cdots,o_{N-1},q_{2N}=s_{i}\,|\,\lambda)=\sum_{i=1}^{N}\Omega_{2N}(i)\tag{5.14}$$

通过前向算法计算该观测值序列 $o_{2N}$ 和各负荷 HMM 之间的相似度 $P_{r}(o_{2N}\,|\,\lambda)$，$i=1,2,\cdots,c$，$c$ 为负荷辨识的类别数。利用极大似然值思想，通过相似度的比较，判定其最大值对应的负荷类别为辨识结果，记为 $\tau$，其数学表达式为

$$\tau=\arg\max_{1\leqslant i\leqslant c}(o\,|\,\lambda_{i})\tag{5.15}$$

### 2. 算法合理性量度

基于多特征序列融合的负荷辨识算法的量度需要从多个角度进行评判，这里主要从负荷辨识的准确率和辨识精度两个方面对算法的合理性进行量度。准确率表示整个负荷辨识结果的准确率，这是一个相当严格的量度标准，要求辨识出的负荷启停状态集合和实际集合完全重合，定义如下：

$$A=\frac{1}{M}\sum_{i=1}^{M}I(X_{i}=Y_{i})\tag{5.16}$$

式中，$M$ 为辨识负荷的样本数；$X_{i}$、$Y_{i}$ 分别为第 $i$ 次负荷辨识结果和实际运行负荷；$I$ 为一个映射，是符号函数，当 $X_{i}$ 与 $Y_{i}$ 完全相同时，$I(X_{i}=Y_{i})=1$，反之 $I(X_{i}=Y_{i})=0$。辨识精度为辨识负荷正确的个数和辨识负荷集合个数的比值，其表达式为 $$P_{\text{pre}}=\frac{1}{M}\sum_{i=1}^{M}\frac{|X_{i}\cap Y_{i}|}{|Y_{i}|}\tag{5.17}$$
