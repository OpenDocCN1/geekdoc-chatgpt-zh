将系统供电 PR 折算成缺电补偿成本考虑到目标函数中时，与 EE 优化目标模型和 EE-EP 优化目标模型相比，EE-PR 优化目标模型和 EE-EP-PR 优化目标模型的负载缺电补偿成本和负载缺电率均降低，这表明，将 PR 指标折算成缺电补偿成本考虑到目标函数中比将 PR 指标考虑到约束条件中更能降低系统的负载缺电率，使得系统供电 PR 升高。

同理，通过表 6.2 可以得出，当将系统 EP 指标折算成治污成本考虑到目标函数中时，将 EE 优化目标模型与 EE-PR 优化目标模型相比，EE-EP 优化目标模型与 EE-EP-PR 优化目标模型相比，治污成本减少，但是减少的幅度较小，分别为 1623 元、1456 元，但是由不同目标模型下的分布式电源容量配置结果中分析知，治污成本在系统总成本中占比较大，因此其对提高系统 EP 具有较大的作用。

（2）微电网系统的 PR 指标和 EP 指标之间的相互关系。通过表 6.2 可以看出，将治污成本引入经济性目标函数后，EE-EP 优化目标模型的治污成本比 EE 优化目标模型降低，EE-EP-PR 优化目标模型比 EE-PR 优化目标模型降低，此外，EE-EP 优化目标模型的负载缺电率较 EE 优化目标模型的负载缺电率、EE-EP-PR 优化目标模型的负载缺电率较 EE-PR 优化目标模型的负载缺电率也降低，出现上述现象的原因是为了降低治污成本，系统尽可能增加清洁型电源的出力情况，从而使其配置的容量上升，由于负载电能需求量一定，从而使得 DE 的出力降低，减少了燃料的消耗量，同时污染物的排放量减少，最终使得治污成本降低；此外，清洁型电源容量的增多，使得其出力增多，从而使得系统负载缺电率降低，最终提升了系统的供电可靠性。

综上所述，在优化目标中引入治污成本和负载缺电补偿成本，均可以在不同程度上增加清洁型发电单元的配置容量，从而增加了彼此的性能，治污成本的引入能够使得系统的负载缺电补偿成本降低，即使得系统的供电环保性升高，而负载缺电补偿成本的引入能够使得系统的治污成本减少，即系统的可靠性得以提升[34]。

总之，要使配置的微电网中各分布式单元的容量更加科学合理，必须要依据实现的目标，比较目标的侧重点、各种成本指标等之间的关系来制定合理的目标函数和约束条件，上述模型对于并网型微电网仍然适用，只需要增加与大电网功率交换的成本/收益等指标即可。
