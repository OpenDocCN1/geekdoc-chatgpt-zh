# 4. PSO-LSSVM 预测过程

采用粒子群优化算法优化最小二乘支持向量机的参数γ和σ²。粒子群优化算法是一种非常简单的算法，可以有效地优化各种功能，具有易于实现和快速收敛等优点。

预测过程首先对海水淡化的特征量数据进行处理；其次，采用灰色关联分析方法从 90 天中选取关联度最大的 30 天作为待预测日的相似日，相似日的负荷数据和特征量数据共同构成了最小二乘支持向量机模型的训练样本和测试样本，并输入到模型中；再次，基于粒子群优化算法优化模型参数γ和σ²；最后，利用最小二乘支持向量机模型进行海水淡化负荷的预测。PSO-LSSVM 预测流程如图 4.12 所示。
