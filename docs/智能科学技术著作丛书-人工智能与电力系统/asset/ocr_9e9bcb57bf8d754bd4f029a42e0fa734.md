# ③ 利用箱形图分析法识别异常值。

按时间顺序以 35 天（5 周）为时间窗口遍历用户数据（节假日负荷数据一般偏低较多，故不作处理），将窗口内数据从大到小排列，取排列后第 9 位数据作为该窗口上值，记为 du；取排列后第 27 位数据作为该窗口下值，记为 dl；上值与下值的差为上下差值，记为 dul，公式如下：

dul = du − dl  (4.33)

将 du 与 1.5 倍的 dul 相加作为该窗口的上界，记为 dum，计算公式如下：

dum = du + 1.5 dul  (4.34)

将 dl 与 1.5 倍的 dul 相减作为该窗口的下界，记为 dlm，计算公式如下：

dlm = dl − 1.5 dul  (4.35)

将该窗口内的负荷数据与该窗口上界（dum）和该窗口下界（dlm）进行比较，若负荷数据大于上界或小于下界，则将该数据识别为异常值。

# ④ 异常值替换。

将识别为异常值的数据用相邻日负荷插值进行替换，替换公式同式（4.32）。

# （2）识别并分离重负荷企业。

将单一企业日均负荷大于所有企业整体日均负荷 100 倍的企业识别为重负荷企业，将重负荷企业数据分离以便后续单独处理，剩余企业识别为轻负荷企业另做处理。

# （3）合并弱相关性轻负荷企业。

计算轻负荷企业负荷数据间的 Pearson 相关系数，设用户间弱相关性的阈值为 δ₁，用户中与其他所有用户的 Pearson 相关系数最大值小于 δ₁ 的用户被识别为弱相关性轻负荷企业，将弱相关性轻负荷企业按日相加，作为一个新的用户便于后续进行特殊处理。

# （4）确定初始聚类中心。

① 计算去除重负荷企业、弱相关性轻负荷企业后样本数据的相关系数矩阵，并记作 Q。从 Q 中选取相关系数最大值所对应的两个企业为第一类，并筛选与第一类两个企业相关系数均大于 0.9 的企业加入第一类，计算第一类企业的负荷均值，并将负荷均值作为该类的初始聚类中心。

② 删除 Q 中已分类的企业所对应的相关系数，再从剩余的系数矩阵中选取最大值所对应的两个企业作为新一类，筛选与新一类两个企业相关系数均大于 0.9 的企业，并加入新一类，计算新一类企业的负荷均值，并将负荷均值作为该类初始聚类中心。
