注，许多研究结果表明，直接应用支持向量机进行电力系统负荷预测，具有精度高、速度快等优点，并且明显改善了负荷预测的效果。

采用支持向量机预测电力系统的短期负荷，以负荷、温度等数据为训练样本，并与多层反向传播神经网络进行比较实验，可实现较好的短期预测效果。同样，将支持向量机应用于船舶电力负荷的短期预测也具有较好的预测效果。

# 2) 支持向量机在电力系统故障识别、定位中的应用

现阶段支持向量机常用在电力变压器故障识别、汽轮发电机组故障诊断、高压输电线上的故障定位和精细线路参数的故障定位等方面。

其中多级支持向量机在分类器的电力变压器故障识别的应用中表现出三个显著优点，即识别正确率高、训练时间短以及不存在局部极小值。将支持向量机应用到汽轮发电机组故障诊断中，可以正确有效地诊断多类汽轮机故障。支持向量机算法在处理高压传输线上的故障定位问题时，根据测量数据中的基本电压和电流构造支持向量机预测网络，并得到大致的故障位置，通过分析故障位置邻近区域系统的高频特性，来修正初值。

# 3) 支持向量机在电力系统暂态稳定评估中的应用

电力系统暂态稳定评估在保证电力系统安全稳定运行中具有重要作用，有学者提出了一种暂态稳定评估模型，利用装袋和近似推理相结合的策略，对未知样本进行精确推理。IEEE 39 节点测试系统中的应用结果证明了该方法对暂态稳定评估的有效性，该方法与广义回归神经网络相比，具有较高的稳定性和预测精度。同样有学者设计了一个用于暂态稳定分类的支持向量机，并将样本划分为三类，即稳定类、不稳定类和边界区类，与传统的反向传播神经网络相比，减少了误分类，提高了稳定评估的可靠性。

# 3.3 深度学习

深度学习 (deep learning, DL) 是机器学习领域中一个新的研究方向，它被引入机器学习使其更接近于最初的目标——人工智能。深度学习的概念源于人工神经网络的研究，含多个隐含层的多层感知器就是一种深度学习结构。深度学习通过组合低层特征形成更加抽象的高层表示展示属性类别或特征，以发现数据的分布式特征。研究深度学习的动机在于建立模拟人脑并进行分析学习的神经网络，它模仿人脑的机制来解释数据，如图像、声音和文本等。

早期的电力系统负荷预测常采用多元线性回归等方法，此方法虽能有效预测负荷出力，但电力负荷变化受天气情况、人类社会活动等诸多因素的影响，且存在大量非线性关系，故会造成预测精度不够、训练样本过拟合现象等问题，针对这一问题，人工神经网络作为一个分析工具，已经成功地应用到电力系统负荷预测
