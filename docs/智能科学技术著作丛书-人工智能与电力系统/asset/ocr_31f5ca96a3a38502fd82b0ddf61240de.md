# 5.6 本章小结

本章主要介绍了人工智能技术在电力系统监测辨识与故障诊断中的应用。5.1节提出了一种基于卷积神经网络的智能事件驱动非侵入式负荷监测方法，以描述居民的消费行为，该方法侧重于现有非侵入式负荷监测技术的有限适用性和低识别精度，深层卷积神经网络结构提高了负荷监测程序的性能，并根据各种特征将其应用范围扩展到监测过程，同时，执行事件驱动程序能够准确找到设备的启停时间和状态变化；5.2节针对低频采样下负荷辨识准确率低和辨识精度低的问题，提出了基于多特征融合的家用负荷辨识技术算法，仅基于负荷特征值进行负荷辨识而不考虑负荷各个时刻状态情况将会降低负荷辨识准确率，隐马尔可夫模型的引入大大提高了辨识算法的准确率和辨识精度；5.3节针对高压输电线路的故障定位，通过基于行波法的双端不同步测距技术，搭建故障模型建立测距方程组，利用模拟退火算法求取初步解作为牛顿迭代法的初始值，再利用牛顿迭代法获得最终解，在提高运算准确率的同时有效降低了智能算法中计算量较大的问题；5.4节针对目前不论是基于机理模型还是基于信号分析的故障诊断方法都存在故障阈值不容易确定的问题以及传统基于人工智能方法的故障诊断方法没有考虑快速性的问题，提出了基于并联卷积神经网络的 MTDC 线路故障诊断方法，该方法可以迅速、准确地定位故障；5.5节应用深度学习中的卷积神经网络和改进卷积神经网络算法实现快速、精准的变压器故障的诊断与定位。上述方法对人工智能技术在电力系统监测辨识与故障诊断中的应用具有重要的理论参考意义和工程应用价值。
