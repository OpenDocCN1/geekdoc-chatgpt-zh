在 1980 年之前，这些机器学习算法都是零碎化、不成体系的，但它们对整个机器学习的发展所起的作用不容忽视；而从 1980 年开始，机器学习才真正成为一个独立的方向，在这之后，各种机器学习算法被大量提出，并得到了快速发展。

# 2. 机器学习算法中期

20 世纪 80 年代到 90 年代初期，机器学习算法取得了重要成果，其中决策树算法诞生有三种典型实现，即 CART、ID3 和 C4.5，虽然简单，但可解释性强，这使得决策树算法至今在一些问题上仍被使用。

1990 年出现了支持向量机 (support vector machine, SVM)，它是一种通过隐式将输入向量映射到高维空间中，使得原本非线性问题能得到很好的处理的思想；Adaboost 代表了集成学习算法的发展高峰，即通过将一些简单的弱分类器集成起来使用，从而达到较高的精度。

贝叶斯网络诞生于 1985 年，是概率推理的强大工具，其发明者是概率图模型中的重量级人物 Judea Pearl，后来获得了图灵奖；条件随机场是概率图模型中相对年轻的成员，已成功地用于中文分词等自然语言处理以及其他领域，同样也是序列标注问题的有力建模工具。

# 3. 机器学习算法现期

近年来深度学习及强化学习在电力系统中的应用也十分广泛，神经网络在非侵入式负荷监控、风电概率预测及故障诊断方面具有突出贡献；马尔可夫算法在负荷辨识方面有重要应用，会在 3.2 节和 3.3 节进行详细介绍。

# 3.2.1 贝叶斯算法

贝叶斯算法是机器学习领域的一种分类方法，它是以贝叶斯定理为理论基础进行分类的算法。该算法能运用到大型数据库中，具有简单、分类准确率高、速度快等优点，在机器学习领域中广泛应用[9]。
