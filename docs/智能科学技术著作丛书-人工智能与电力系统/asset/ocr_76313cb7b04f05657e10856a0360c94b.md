x_{id}(t+1)=x_{id}(t)+v_{id}(t)  (2.18)

式中，t为迭代次数；v_{id}(t)为第i个粒子的速度；x_{id}(t)为第i个粒子的位置；w为惯性权重；c1、c2为学习因子，也称为加速度系数；r1、r2为内随机生成的两个向量；p_{id}(t)为第i个粒子迄今为止搜索到的最优的位置，称为个体极值，即pbest；p_{gd}(t)为整个粒子群迄今为止搜索到的最优位置，称为全局极值，即gbest。

式(2.17)右边由以下三个部分组成：

+   - (1) “惯性” 部分，反映了粒子运动的 “习惯”，代表粒子有维持自己先前速度的趋势。
+   - (2) “认知” 部分，反映了粒子对自身历史经验的记忆或回忆，代表粒子有向自身历史最佳位置逼近的趋势。
+   - (3) “社会” 部分，反映了粒子间协同合作与知识共享的群体历史经验，代表粒子有向群体或邻域历史最佳位置逼近的趋势。

由于粒子群优化算法具有较好的搜索能力，有利于得到多目标意义下的最优解；通过代表整个解集种群，按并行方式同时搜索多个非劣解，即搜索到多Pareto最优解。

但单独使用粒子群优化算法时，通过改变迭代次数，且迭代次数越大，获得的解的精度不一定越高，因为粒子群优化算法是一种随机算法，保持相同参数时也会算出不同的结果。而当改变粒子群规模时，粒子群规模越大，获得的解的精度也不一定越高。因此，在粒子群优化算法中，想要获得精度高的解，关键要使各参数间搭配合适。

粒子群优化算法求解流程如图2.7所示，具体如下所述。

+   - (1) 初始化一个规模为n的粒子群，确定初始位置和速度，过程如下：
+     - ① 设定种群规模n。
+     - ② 对于任意的i、d，在[-x_max,x_max]内服从均匀分布产生x_id。
+     - ③ 对于任意的i，设v_i = x_i。
+   - (2) 计算每个粒子的适应度值。
+   - (3) 对每个粒子，将其适应度值和个体极值p_id的适应度值相比较，若较好，则将其作为个体极值。
+   - (4) 对每个粒子，将其适应度值与全局极值p_gd的适应度值相比较，若较好，则将其作为全局极值。
+   - (5) 根据式(2.12)和式(2.13)，对粒子进行位置和速度的更新。
+   - (6) 如果满足终止条件，则输出解，否则返回步骤(2)。
