# 图 6.3 基于 APSO 对不同优化目标模型下电源容量配置求解流程

首先由清洁型电源出力，即 PV 和 WT 出力为负载供应电能，设 PV 和 WT 提供的电能分别为 P_PV、P_WT，那么清洁型发电单元出力与负载需求电能的差值为

ΔP(t) = P_WT(t) + P_PV(t) - P_LD(t)  (6.25)

若 ΔP(t) > 0，即清洁型电源在能够满足负载电能需求的同时，还有电能盈余，在储能电池荷电状态未达上限的情况下，对其进行充电，若电能盈余小于储能电池允许的充电功率，则储能电池吸收电能为

P_BESS(t) = ΔP(t)  (6.26)

反之，若盈余电能超过储能电池的荷电状态，则储能电池应充电以达到其荷
