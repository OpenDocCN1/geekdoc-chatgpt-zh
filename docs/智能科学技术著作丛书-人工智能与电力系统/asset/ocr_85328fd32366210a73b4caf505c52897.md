# 4.3.2 基于用户负荷曲线的特征选择

特征工程是构建负荷预测策略的关键组成部分，其处理过程主要包括特征构建、特征提取和特征选择。负荷预测的现有工作大多集中在预测方法上，然而预测过程中对输入特征的选择通常是根据用户的经验或试错过程来完成的，当存在大量候选输入时，特征选择是构建可靠预测策略的关键。通过剔除无效的候选特征，减少输入集合的数量，预测模型可以更好地发挥学习过程的输入输出映射功能，从而提高预测精度。

特征选择是数据挖掘和机器学习中的一项重要任务，它可以降低数据的维数，提高分类算法的性能。在许多机器学习任务中，如在分类、聚类、回归和时间序列预测中，特征选择用来提高特征集的质量，然而，由于搜索空间较大，特征选择一般耗时较长，结果难以评估。特征选择是一种通过剔除冗余性和非重要性的特征来实现数据降维的方法，其能有效提升预测方法的计算效率和预测结果的泛化性能。

特征选择的目的是剔除原始特征中的冗余信息，保留特征集所携带的重要信息，从而得到原始特征集的最小子集，使得学习算法输入数据的维数降低，以提高计算效率。不重要的输入特征通常不仅不会提供较大的价值，而且还会使数据的分析和建模复杂化，所以在分析时冗余特征可以忽略，即把它从原始特征集中剔除。特征选择算法可以分为过滤式、封装式和嵌入式三种。

本节基于过滤式方法计算效率高和嵌入式方法筛选效果好的特性提出一种基于用户负荷曲线特性的考虑冗余性、关联性和重要性的混合 Filter-Embedded 特征选择方法。该方法首先利用 Pearson 相关系数分析法识别并剔除强线性相关特征，减少特征冗余性的同时避免了预测时可能存在的多重共线性问题，然后利用互信息 (mutual information, MI) 法剔除弱关联性特征，使筛选后的特征与目标值具有强关联性，最后结合 LightGBM 算法内嵌的特征重要性分析对特征重要性程度进行打分，剔除不重要的特征，通过筛选并得到最小特征子集。本节提出的混合 Filter-Embedded 特征选择方法流程如图 4.19 所示。
