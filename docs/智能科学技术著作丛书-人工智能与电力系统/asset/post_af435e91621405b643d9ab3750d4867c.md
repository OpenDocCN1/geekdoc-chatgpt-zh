## 2. 基于故障信号的幅值、频率特征提取

当 MTDC 系统发生故障时，电气量波形的幅值变化能比较明显地区分出各个故障，然而实际系统故障距离的变化不能明显地反映在幅值上，使得仅仅依靠幅值变化不能可靠地区分故障的类别和位置。所以本节引入频率分析的小波包分析方法对数据进行预处理，同时给神经网络输入幅值特征和频率特征，全面捕捉故障特征。

### 1) 幅值特征提取

故障时，电流和电压会产生波动，最终稳定到新值，若稳定的新值与正常运行时的稳定值不同，则称电气量发生了变化，反之则无变化。通过观测电气量幅值是否发生变化和变化情况，可以分辨故障类型。故障的幅值特征在于确定电气量幅值变化信息，即确定故障波形与正常波形的不同之处。所以，本节在引用信号波形进行 MTDC 线路故障诊断时，需要采用如式 (5.28) 所示的方法，即把故障信号波形和正常信号波形首尾相连排列成新信号。如此，实现了新信号波形前后幅值变化特征的提取。

```
x(i) = [x_{T-1}, x_{T-1+Δt}, x_{T-1+2Δt}, ..., x_{T-1+mΔt}, x_T, x_{T+Δt}, x_{T+2Δt}, ..., x_{T+mΔt}]  (5.28)
```

式中，x(i) 为合成后的数据；T 为发生故障的时刻；Δt 为采样点时间间隔，Δt = 10^{-4} s；m 为采样点的个数。

### 2) 频率特征提取

当 MTDC 系统发生短路故障时，线路电流、电压会产生高频分量，通过检测这些信息可以实现故障分类和定位。相比于小波分析，小波包分析将频带进行多层次划分，对多分辨分析没有细分的高频部分进一步分解，并能够根据分析信号的特征，自适应地选择相应的频带，使其与信号频谱相匹配，从而提高时频分辨率。本节采用小波包分析的方法，对直流端两极电压、正极电流、负极电流、正极电压和负极电压 5 种电气量进行 3 层小波包重构，提取各频段频率特征，实现频率特征提取。式 (5.29) 为小波包分解算法和小波包重构算法：

```
⎧ d_{j,l,2n} = √2 Σ_k h_{0,k-2l} d_{j+1,k,n}
⎨ d_{j,l,2n+1} = √2 Σ_k h_{1,k-2l} d_{j+1,k,n}
⎩ d_{j+1,l,n} = Σ_k h_{0,k-2l} d_{j,k,2n} + h_{1,k-2l} d_{j,l,2n+1}
(5.29)
```

式中，d_{j+1,k,n} 为上一层小波包分解的结果；d_{j,k,2n}、d_{j,l,2n+1} 为下一级的小波包分解结果；j 为尺度指标；n 为频率指标；l 为位置指标；k 为变量；h_{0,k-2l}、h_{1,k-2l} 为分解采用的第 k-2l 个多分辨率滤波器系数。

### 3. 基于迁移学习的 P-CNN 训练

P-CNN 的双支路结构可以让故障诊断过程更加有序和快速。两条支路分别提取 MTDC 故障分类特征和故障定位特征，并且依靠 P-CNN 的特殊性质同时进行计算，以提高故障诊断的快速性。因为 P-CNN 的两条支路故障特征提取的目的不同，所以神经网络的训练过程也分别进行[26]。

![](img/2160aa82ffab89ad09fb1b4e167a298b_150_0.png)

图 5.10 P-CNN 模型

P-CNN 训练过程如图 5.11 所示，分别进行故障分类神经网络和故障定位神经网络的单独训练。由于只是单独做故障分类和故障定位的特征提取，神经网络的训练过程比较迅速，效果也很好。将训练完成的神经网络的隐含层权重和偏置提取出来赋给 P-CNN 的双支路。最后在训练微调后的 P-CNN 时，保持隐含层各层权重和偏置不更新，直至其他层神经网络全部训练完成。

![](img/2160aa82ffab89ad09fb1b4e167a298b_151_0.png)

图 5.11 P-CNN 训练过程

将预训练的模型参数迁移到新的神经网络模型中。重新训练分类器的方法实际上属于迁移学习。迁移学习包括基于实例的迁移学习、基于特征的迁移学习、基于模型的迁移学习和基于关系的迁移学习[27]。本节应用的是基于模型的迁移学习思想，利用预训练模型的方法可减少 P-CNN 的训练时间，同时充分利用了模型之间存在的相似性。

迁移学习是实现 P-CNN 训练过程的一个重要环节。运用迁移学习实现了将两个单独训练的特有功能的神经网络的参数迁移到一个具有并联结构的神经网络上，从而实现 P-CNN 每个支路具有特定作用的特殊结构。

## 5.5 基于深度学习的电力变压器故障诊断与定位

智能配电网的飞速发展，对电力设备的安全稳定运行提出了更高的要求，如何快速、准确地对电力变压器故障进行在线诊断和定位是电力领域亟待解决的问题。在电力变压器发生故障时，往往可将故障一分为二进行考虑，即变压器电气故障和变压器机械故障，前者可通过判断故障类型达到故障诊断的目的，后者则是通过判断故障发生的部件和位置达到故障定位的效果。在线诊断和定位往往需要较高的时效性，深度学习的发展为其带来了生机，其中卷积神经网络具有较强的特征学习能力，可有效提高判断准确率；离线训练、在线诊断的方式也使在线诊断和定位效率大大提高。本节将应用深度学习中的卷积神经网络和改进卷积神经网络算法进行变压器故障的诊断与定位[28,29]。

## 5.5.1 基于卷积神经网络的变压器故障在线诊断技术

变压器油中溶解气体离线分析不需要设备停电，是迄今为止变压器设备状态检修工作中较为有效的故障诊断方法。在线监测是离线分析的一种补充形式，能够克服常规离线油色谱实验中干扰因素多、数据有效性欠缺等弊端，真正实现了对变压器运行状况的实时分析，并进行色谱数据在线传输。通过在线装置可以缩短特征气体监测周期，并且在设备故障初期可以及时发现、及时诊断，在诊断设备故障时减少人力成本。同时，利用较高的数据采集量并配合深度学习中的卷积神经网络算法进行智能在线故障诊断，不仅大大增强了分析结果的可靠性，而且还很大程度上提高了故障诊断的时效性。

### 2. 基于卷积神经网络的变压器故障诊断模型

电力变压器故障诊断过程分为以下 8 个步骤，诊断流程如图 5.14 所示：

- (1) 变压器故障数据采集。
- (2) 将故障数据转变为二维灰度图并归一化。
- (3) 建立网络并初始化网络参数。根据样本和要求，构建合适的网络模型，确定网络参数。
- (4) 网络训练。将训练样本输入到网络中，通过前向传播算法求得网络输出与预期目标的误差。
- (5) 判断网络是否达到收敛要求，若收敛，则执行(7)，否则执行(6)。
- (6) 利用反向传播算法更新权重，利用反向传播算法将(5)求得的误差反向逐层传播到每个节点，并更新权重，循环执行(4)～(6)，直至网络收敛。
- (7)根据测试样本的精确度判断网络是否满足实际要求，若满足则执行(8)，否则跳转到(3)，并修改网络参数。
- (8)输出网络，并将网络应用于变压器故障诊断。

### 1) 变压器故障诊断模型架构

卷积神经网络具有很多种类模型，LeNet-5 作为卷积神经网络的一种经典实现，因其在学习算法和匹配算法中具有较好的性能，并且运行效率较高，因此本节选取 LeNet-5 来解决变压器故障诊断问题。

除了输入层外，LeNet-5 还包含 7 层，每层都包含可训练的参数，每层有多个特征图，每个特征图通过一种卷积核提取输入的一种特征。具体网络参数如表 5.11 所示。

### 表 5.11 LeNet-5 具体网络参数

| 网络层类型 | 具体参数 | 输出特征图大小 |
|---|---|---|
| 输入层 | 输入二值灰度图像 | 32×32 |
| 卷积层 C1 | 6 个 5×5 卷积核，步长取 1 | 6×28×28 |
| 池化层 S2 | Max-pooling，采样区域 2×2，步长取 2 | 6×14×14 |
| 卷积层 C3 | 3 个 5×5 卷积核，步长取 1；S2 层中前 3 个相邻的特征图为第 1 组输入，S2 中后 4 个相邻特征图为第 2 组输入，S2 中所有特征图为第 3 组输入 | 16×10×10 |
