# 4) 深度强化学习算法原理

深度强化学习与 Q 学习相似，都是基于值的迭代算法，普通 Q 学习算法适用于解决状态和动作空间是离散而且维数不高的問題，而当状态和动作空间维数高且连续时，使用 Q 学习算法求解复杂且困难。通过结合深度神经网络对复杂特征进行提取，用拟合函数来代替 Q 值，进而进行最优策略的寻找，这就是深度强化学习[16]。

在实际应用中，当环境状态较多时，Q 值表可能会很大，通过神经网络、输入环境状态可以输出不同动作下的 Q 值，来简化 Q 值表，其简化过程如图 3.26 所示，通过简化可得到深度强化学习算法的 Q 值网络，如图 3.27 所示。
