# 第 5 章 基于人工智能技术的电力
系统监测辨识与故障诊断

本章主要介绍人工智能技术在电力系统监测辨识与故障诊断中的应用，包括基于卷积神经网络的非侵入式负荷监测、基于马尔可夫模型的负荷辨识、基于模拟退火算法的高压输电线路故障定位、基于卷积神经网络的多端直流输电线路故障诊断、基于深度学习的电力变压器故障诊断与定位，分别在 5.1 节～5.5 节中介绍。

# 5.1 基于卷积神经网络的非侵入式负荷监测

如今，对智能电网利用和需求侧管理的需要不断增长，加速了非侵入式负荷监测 (no-intrusive load monitoring, NILM) 的发展。因此，本节提出一种基于卷积神经网络的非侵入式负荷监测方法，用以描述居民的消费行为，该方法侧重于现有非侵入式负荷监测技术的有限适用性和低识别精度。深层卷积神经网络结构提高了负荷监测程序的性能，并根据各种特征将其应用范围扩展到监测过程。同时，执行事件驱动程序以准确找到设备的启停时间和状态变化，包括过零检测、电流相似性检测、阈值评估和事件电流获取、执行电流到图像的转换，表示作为卷积神经网络输入的住宅设备的特性，并提出了卷积神经网络结构，用以识别功耗和工作条件。
