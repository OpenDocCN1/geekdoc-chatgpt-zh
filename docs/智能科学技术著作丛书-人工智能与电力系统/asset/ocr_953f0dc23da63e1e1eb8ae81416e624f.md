术不同，非侵入式负荷监测技术仅需要在主电源服务入口处进行测量即可有效地进行功率负荷监测和识别，这种方式的安装和维护成本更低，并且对负载的接受程度更高，同时保护了消费者的隐私和便利性。现有非侵入式负荷监测系统的框架是通过数据预处理、特征提取和负荷识别构建的，从大量且复杂的电信号中提取出代表性的特征，然后将其用于模式识别算法或训练机器学习模型中。但是，现有的发达的智能非侵入式负荷监测系统仍然存在如下缺点[21]：

+   (1) 传统非侵入式负荷监测技术的“分而治之”思想缺乏普遍性和全局最优性，可能无法从最佳特征提取器和最佳分类器中得出最高准确率的识别结果。
+   (2) 其识别精度很大程度上取决于适当的人工制作特征。一方面，根据对先验知识的全面理解，以经验方式设计人工制作的特征是一项艰巨的任务；另一方面，在特征选择过程中降维会损失很多时域信息。
+   (3) 在实际应用中，采集的电数据由多个负荷运行的各种状态变化组成，对于传统的非侵入式负荷监测方法，解决在扰动情况下具有混合负荷特性的非平稳信号混杂问题极具挑战性。

随着图形处理单元的飞速发展，深度学习已被证明是一种基础的集成框架，可以解决上述问题。受深度学习端到端方式的启发，本节提出一种基于原始电流信号的事件驱动卷积神经网络架构，用于非侵入式负荷监测。

# 2. 非侵入式负荷监测的检测方法

非侵入式负荷监测的检测方法分为四个部分，即过零检测、电流相似度检测、阈值评估和当前事件采集，具体描述如下。

# 1) 过零检测

考虑到有功和无功的检测方向和计算的复杂性，电流波形作为描述家用电器运行变化的最直接电气参数，被选为这项研究的特征参数。通常，由于电力电子设备的存在，居民用电并不是纯电阻负载，并且不同设备之间的相位滞后角也不相同。因此，过零检测需要电流波形的单个周期，以便收集电流变化并估计事件的发生。
