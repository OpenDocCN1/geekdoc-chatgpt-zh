优化 A：电网运行在谷、平时段，储能电池系统的荷电状态大于等于最大荷电状态，储能电池处于可放电的情况。利用储能电池输出功率调节系统功率平衡，优化系统中可控源 CHP 单元的出力、多能源系统和大电网交换功率。

优化 B：电网运行在谷、平时段，储能电池系统的荷电状态小于最大荷电状态，储能电池处于可充电和可放电的情况。在这种情况下，通过对储能电池系统的充放电功率、可控源 CHP 单元的出力、多能源系统和大电网交换功率进行优化，达到系统安全稳定、经济运行的目的。

优化 C：电网运行在峰时段，储能电池的荷电状态小于最小荷电状态，储能电池系统处于可放电情况。在这种情况下尽可能通过储能电池和可控源实现系统的稳定运行，同时优化可控源 CHP 单元的出力、多能源系统和大电网交换功率。

优化 D：电网运行在峰时段，储能电池的荷电状态大于等于最小荷电状态，储能电池系统处于以恒定功率充电的情况。在这种情况下为了保证储能电池的调节作用，需要对储能电池进行充电，使其荷电状态大于等于最小荷电状态，并优化储能电池充电功率、可控 CHP 单元的出力、多能源系统和大电网交换功率。

# 6.4.2 多能源系统并网模式下优化模型

多能源系统并网模式下的安全稳定运行首先要保证供电、供热的安全性和可靠性，其次在保证稳定运行的条件下，运行的经济性、环境的污染程度也很重要。故需要制定多能源系统中各能源出力的优化控制策略。多能源系统并网模式下运行原则如下：

+   (1) 优先保证满足混合能源热电联供系统电、热负荷需求。\n(2) 优先使用清洁能源为系统供能，若不能满足系统的热、电负荷需求，再使用电网或一次能源供能。\n(3) 光伏和风机工作在最大功率点跟踪模式。\n(4) CHP 工作在 “以热定电” 模式。\n(5) 各分布式电源必须工作在其安全模式下。

# 1. 多能源系统经济优化模型

多能源系统包括风力发电机组(风机)、光伏发电机组、CHP 单元、直热电锅炉、储能电池，其中风机、光伏发电机组、CHP 单元、储能电池为系统提供了所需的电能，直热电锅炉、CHP 单元为系统提供了所需热能。多能源系统的运行费用由燃料费用、机组维护费用、系统与大电网之间的电量交易费用三大部分组成，将各机组的输出功率作为优化变量，使系统运行费用最低，建立多能源系统和大电网并网时系统优化运行模型。
