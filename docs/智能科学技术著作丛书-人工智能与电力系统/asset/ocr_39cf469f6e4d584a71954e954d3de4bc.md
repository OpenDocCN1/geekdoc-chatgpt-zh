机保留最好的一半，重复变异选择的过程直至满足终止条件，找到最优解。

# 2. 进化规划算法的实现

进化规划算法的实现步骤如下：

+   (1) 确定问题方案。寻找实值 n 维矢量 x，使得函数 F(x) 取极值。不失一般性，设此程序为极小化过程。
+   (2) 对种群进行初始化。从各维的可行范围内随机选取亲本 x_i (i=1,2,⋯,p) 的初始值。
+   (3) 亲本繁殖。将随机选取的亲本 x_i (i=1,2,⋯,p) 进行复制产生 x_i'。
