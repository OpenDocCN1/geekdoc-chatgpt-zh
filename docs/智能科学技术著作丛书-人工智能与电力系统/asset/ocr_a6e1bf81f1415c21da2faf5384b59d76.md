I_M(λ)、I_N(λ) 分别为 M 和 N 处的电压与电流；γ_(λ)、Z_c(λ) 分别为对应任意序分量的线路传播系数和波阻抗。

由于采用不同步定位方法，即 M、N 两端存在非同步角，记为 δ。利用线路故障前的 信息及故障发生后的正序、负序信息建立故障方程组，即

⎧ U_M(1)k l cosh γ_(1) − I_M(1)Z_c(1)k l sinh γ_(1) = [U_N(1)(1−k)l cosh γ_(1) − I_N(1)Z_c(1)(1−k)l sinh γ_(1)] e^{jδ}
⎨ U_M(2)k l cosh γ_(2) − I_M(2)Z_c(2)k l sinh γ_(2) = [U_N(2)(1−k)l cosh γ_(2) − I_N(2)Z_c(2)(1−k)l sinh γ_(2)] e^{jδ}
⎪ U_N^{e jδ} = U_M k l cosh γ − I_M Z_c l sinh γ
⎩ U_M = (U_N l cosh γ − I_M Z_c l sinh γ) e^{jδ}  (5.21)

为简化模型的表达形式，特将 δ、γ、Z_c 在[0,1]内用 5 个变量 k0、k1、k2、k3、k4 进行表示：

⎧ δ = (2k0 −1)Δδ
⎨ γ = (1 + 2k1Δk1 − Δk1)γ_a + j(1 + 2k2Δk2 − Δk2)γ_b
⎩ Z_c = (1 + 2k3Δk3 − Δk3)Z_a + j(1 + 2k4Δk4 − Δk4)Z_b  (5.22)

式中，Δδ 为所估计的最大非同步角；γ_a、γ_b、Z_a、Z_b 分别为线路传播常数和波阻抗参数的实部及虚部；Δk1、Δk2、Δk3、Δk4 为线路参数的估计最大偏差。依据式(5.21)以 k、k0、k1、k2、k3、k4 为待观测进行归一化，得到

F1(x)= [ real[G1(x)] ; ... ; real[G4(x)] ] = 0,  F2(x)= [ imag[G1(x)] ; ... ; imag[G4(x)] ] = 0  (5.23)

将上述模型转化为最优解问题，有

min |F(x)| ,  x = [k, k0, k1, k2, k3, k4]^T  (5.24)
