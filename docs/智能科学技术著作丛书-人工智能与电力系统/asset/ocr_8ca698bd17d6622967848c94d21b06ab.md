# 3) 逆向强化学习

强化学习是求累计赏赏期望最大时的一种策略，求解过程中的赏赏函数是人为给定的，但在很多复杂的任务中，赏赏函数往往难以直接给定，而赏赏函数的好坏对学习结果有着非常重要的影响。吴恩达等提出逆向强化学习来解决该问题，专家在完成某项任务时，其决策往往是最优或接近最优的，当赏赏函数难以给定时，可以从专家示例中来学习赏赏函数。

经典的逆向强化学习算法包括基于学徒学习、最大边际规划、结构化分类和概率模型形式化的方法。Abbeel 等提出基于学徒学习的方法，使用函数逼近的方法从专家示例中学习赏赏函数，使得在该赏赏函数下所得到的最佳策略在专家示例策略附近，其主要用来解决退化解和赏赏函数歧义性问题。最大边际规划法的目标是找到使专家示例策略具有比其他策略更大累计赏赏的状态到赏赏的映射，在这个映射下，最优策略能够逼近专家示例策略。Klein 等提出结构化分类方法，用分类的思想考虑最优的策略，并将估计的专家期望特征作为赏赏函数，这种方法避免了多次迭代计算的过程。最大边际规划法和结构化分类方法往往会产生歧义，很多不同的赏赏函数会导致相同的专家策略。Ziebart 等提出基于最大熵和交叉熵两类概率模型来解决该问题。

经典的逆向强化学习算法不能很好地扩展到状态空间维数很高的系统中，与深度学习相结合便能够发挥更大的作用。将模型中的状态和动作使用深度神经网络替代，算法可以在大型复杂的系统中取得良好的效果，如基于最大边际法的深度逆向强化学习、基于深度 Q 网络的深度学习和基于最大熵模型的深度逆向强化学习。
