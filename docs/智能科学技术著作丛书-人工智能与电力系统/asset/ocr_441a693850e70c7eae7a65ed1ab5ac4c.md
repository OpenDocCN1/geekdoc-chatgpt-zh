# 5.2.2 多特征序列融合的负荷辨识流程

# 1. 识别算法流程

首先，对于在某一时刻需辨识的负荷或者负荷组合，采用滑动时间窗口算法得到功率序列，并对该序列进行特征提取，获得负荷功率序列统计特征和功率序列奇异值特征。然后，利用两个训练好的 PNN 对负荷功率序列统计特征和功率序列奇异值特征进行基本信度赋值，并归一化处理，再利用 D-S 证据理论对基本信度赋值矩阵进行序列融合，完成负荷多特征序列融合过程，从而得到观测值序列。最后，计算前向变量为

$$\Omega_{t}(i)=P_{r}(o_{1},o_{2},\cdots,o_{t},q_{t}=s_{i}\,|\,\lambda),\quad -N\leqslant t\leqslant N-1\tag{5.13}$$

$$P_{r}(o_{2N}\,|\,\lambda)=\sum_{s_{i}}P_{r}(o_{-N},o_{-N+1},\cdots,o_{N-1},q_{2N}=s_{i}\,|\,\lambda)=\sum_{i=1}^{N}\Omega_{2N}(i)\tag{5.14}$$

通过前向算法计算该观测值序列 $o_{2N}$ 和各负荷 HMM 之间的相似度 $P_{r}(o_{2N}\,|\,\lambda)$，$i=1,2,\cdots,c$，$c$ 为负荷辨识的类别数。利用极大似然值思想，通过相似度的比较，判定其最大值对应的负荷类别为辨识结果，记为 $\tau$，其数学表达式为

$$\tau=\arg\max_{1\leqslant i\leqslant c}(o\,|\,\lambda_{i})\tag{5.15}$$

# 2. 算法合理性量度

基于多特征序列融合的负荷辨识算法的量度需要从多个角度进行评判，这里主要从负荷辨识的准确率和辨识精度两个方面对算法的合理性进行量度。准确率表示整个负荷辨识结果的准确率，这是一个相当严格的量度标准，要求辨识出的负荷启停状态集合和实际集合完全重合，定义如下：

$$A=\frac{1}{M}\sum_{i=1}^{M}I(X_{i}=Y_{i})\tag{5.16}$$

式中，$M$ 为辨识负荷的样本数；$X_{i}$、$Y_{i}$ 分别为第 $i$ 次负荷辨识结果和实际运行负荷；$I$ 为一个映射，是符号函数，当 $X_{i}$ 与 $Y_{i}$ 完全相同时，$I(X_{i}=Y_{i})=1$，反之 $I(X_{i}=Y_{i})=0$。辨识精度为辨识负荷正确的个数和辨识负荷集合个数的比值，其表达式为 $$P_{\text{pre}}=\frac{1}{M}\sum_{i=1}^{M}\frac{|X_{i}\cap Y_{i}|}{|Y_{i}|}\tag{5.17}$$
