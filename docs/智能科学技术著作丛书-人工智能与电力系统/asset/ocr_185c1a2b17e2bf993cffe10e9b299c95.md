式中，τ_is(t) 为此时的信息素含量； η_is(t) 为启发因子，又称能见度因子； α 为信息素比例； β 为启发信息比例； J_k(i)={1,2,⋯,m}−τ_k 为下一步允许选择的节点集合。

列表 τ_k 记录了蚂蚁 k 在本次迭代中走过的节点，不允许蚂蚁在本次循环中再经过这个节点。

当所有蚂蚁完成一次循环后，根据式(2.7)进行信息素的更新：

τ_ij(t+n) = (1 - ρ) τ_ij(t) + Δτ_ij(t)   (2.7)

Δτ_ij(t) = Σ_{k=1}^{m} Δτ_ij^k   (2.8)

式中，ρ 为信息素的挥发系数，其范围是 0～1； 1-ρ 为信息素的持久系数； Δτ_ij(t) 为本次迭代边 (ij) 上信息素的增量； Δτ_ij^k 为第 k 只蚂蚁在本次迭代边 (ij) 上信息素的增量。

当蚂蚁 k 没有经过迭代边 (ij) 时，Δτ_ij^k 表示为

Δτ_ij^k = { Q / L_k , 蚂蚁k在本次周游中经过边(ij) ; 0 , 其他 }   (2.9)

式中，Q 为正常数； L_k 为第 k 只蚂蚁在本次周游中走过路径的长度。

蚁群算法根据痕迹更新方式可以分为蚁周算法(ant-cycle algorithm)、蚁量算法(ant-quantity algorithm)、蚁密算法(ant-density algorithm)。上述介绍的是蚁周算法，下面介绍蚁量算法和蚁密算法。

蚁量算法的模型为

Δτ_ij^k = { Q / d_ij , 蚂蚁k在本次周游中经过边(ij) ; 0 , 其他 }   (2.10)

蚁密算法的模型为

Δτ_ij^k = { Q , 蚂蚁k在本次周游中经过边(ij) ; 0 , 其他 }   (2.11)

蚁周算法搜索使用的反馈信息是全局的，而蚁量算法、蚁密算法使用的反馈信息是局部的。
