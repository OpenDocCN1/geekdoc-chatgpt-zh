
## 第 6 章 基于人工智能技术的电力系统优化

本章主要介绍人工智能技术在电力系统优化中的应用，包括基于粒子群优化算法的微电网容量优化配置、基于遗传算法的多能源系统能量枢纽优化配置、基于遗传算法的沿海水电系统优化运行、基于粒子群优化算法的多能源系统优化运行、基于免疫算法的水火电联合优化调度，以及基于蚁群算法的风电集群输电系统拓扑优化。

### 6.1 基于粒子群优化算法的微电网容量优化配置

本节讨论粒子群优化算法在微电网容量优化配置中的应用。微电网中采用科学合理的调控方案能够实现对系统中的分布式机组和大电网、用户侧间的电能交换与运行方式进行相对科学且有效的控制，能够较为有效地减少将不确定性和间歇性分布式电源并入大电网时导致的大电网的电能波动，同时可以增强微电网系统的电能供应的可靠性，使得其孤岛能力增强，还可以较好地保证用户对电能波动范围小和供电可靠性高等的要求。微电网的许多优点均建立在其合理的容量配置和科学的优化运行基础上，如何对含有大量清洁型电源的微电网进行多种类型能源容量和储能装置的合理配置，是保证清洁型能源利用率上升至较大占比，以及使微电网系统的全生命周期支出降低至较小数值的主要依据。在微电网容量优化配置的基础上，如何对微电网中含有的繁多能源、负载进行优化调度，是确保微电网良好运行的主要问题。因此，探讨和研究包括多类型清洁型可再生分布式发电单元的微电网容量优化配置以及微电网中各类分布式电源和储能电池的优化运行调度具有重要的理论参考意义和工程应用价值。

微电网的容量配置优化是一个复杂的非线性优化问题，可采用粒子群优化算法求解，在求解过程中，为了改善粒子群优化算法不能适应复杂非线性优化过程的问题，本节采用自适应粒子群优化 (adaptive particle swarm optimization, APSO) 算法，通过利用群粒子的位置分布情况控制粒子飞行的惯性权重，借助个体最优位置和全局最优位置的平均作用避免粒子陷入局部最优，相对于粒子群优化算法，自适应粒子群优化算法在收敛速度、最优解精度等方面获得了大幅提升，并且适用于微电网容量的优化配置[31]。

### 6.1.1 微电网的容量优化配置模型

微电网系统可以看成集发、输、变、配、用为一体的一个独立完整型系统。其中风电和光电的出力都具有不确定的特点，然而此类电源的间歇性和不确定性的特点违背了电网中要求电能可以控制的原则，使得此类清洁能源的消纳能力受到了很大的束缚。因此，风力涡轮机 (wind turbine, WT)、光伏发电 (photovoltaic, PV)、柴油发电机 (diesel engine, DE) 和电池储能系统 (battery energy storage system, BESS) 的最佳组合对降低负载缺电量、提高可再生能源利用率和增加系统经济性具有重要的意义，也是后续研究微电网优化运行的重要基础。因此，在计及系统成本投入和收益、供电负载可靠性和环境保护的基础上，构建了包括 WT、PV、DE 和 BESS 的微电网系统，以年均等值成本最低为求解目标，提出了考虑四种不同优化目标模型的微电网电源容量优化配置方法，目前从能量控制策略方面考虑微电网电源容量配置问题的研究文献相对较少，针对这类问题，提出了微电网经济性最大化能量控制策略和环保性最大化能量控制策略，完善了微电网容量优化配置方法，并通过仿真证明其能够降低负载缺电量，并且最大限度地实现了系统对可再生能源的消纳和经济性。

#### 1. 微电网分布式供电单元容量配置优化目标模型

微电网系统作为一种包含大量可再生清洁能源的自治系统，其能够为用户提供稳定可靠与灵活经济的电能服务，其最显著的优势为降低污染物的排放，充分利用可再生清洁能源，可保证系统供电稳定性，同时提高系统的经济效益。因此，为了充分发挥微电网系统的优势，本节计及经济性 (economical efficiency, EE)、环保性 (environmental protection, EP) 和供电可靠性 (power supply reliability, PR) 三个指标，其具体代指系统投运成本、污染物排放量和负载缺电量，构建了包括 WT、PV、DE 和 BESS 的微电网系统电源容量配置模型，以系统的年均等值经济性最大化为优化求解目标，构建了四种计及不同因素的目标和限制条件的组合问题，以探究不同待求目标和限制条件对微电网电源容量组合方案的具体影响。

##### 1) EE 优化目标模型

EE 优化目标模型只计及系统的经济性指标，而将系统 PR 指标和 EP 指标计入限制条件中。微电网的电源容量配置评价函数通常是系统年均等值成本，系统年均等值成本包括年均初始投资成本、年运行维护成本、年机组燃料购买成本等，其中年均初始投资成本即将系统全寿命周期内的各分布式发电单元的购置成本运用等值年值法折算成年平均初始投资成本。因此，微电网的系统年均等值成本可以用如下公式计算：

$C_{\mathrm{INVE}} = C_{\mathrm{GE}} + C_{\mathrm{FU}} + C_{\mathrm{OM}}$  (6.1)

式中，C_INVE 为微电网的系统年均等值成本；C_GE 为系统中 PV、WT、DE 和 BESS 的年平均初始投资成本；C_FU 为系统年机组燃料购买成本；C_OM 为 PV、WT、DE 和 BESS 的年运行维护成本。

EE 优化目标模型的约束条件主要由以下部分组成：分布式发电单元机组容量约束、分布式发电单元数量约束、BESS 单元充放电约束、负载缺电量约束以及污染物排放量约束。

###### (1) 分布式发电单元机组容量约束。

微电网系统分布式发电单元在容量优化配置过程中，为保证系统的经济性，机组容量应低于依据负载需求和外界环境条件而设定的容量上限：

0 ≤ P_WT ≤ P_WT,max  (6.2)
0 ≤ P_PV ≤ P_PV,max  (6.3)
0 ≤ P_BESS ≤ P_BESS,max  (6.4)
0 ≤ P_DE ≤ P_DE,max  (6.5)

式中，P_WT,max、P_PV,max、P_BESS,max、P_DE,max 分别为 WT、PV、BESS 和 DE 机组在满足负载电能供应和外界环境条件下设定的额定容量最大值约束。

###### (2) 分布式发电单元数量约束。

WT、PV、BESS 和 DE 的个数需要限制在允许的合理约束上下限内，其数量最大值可基于预算的投资成本和微电网发电单元安装场地实际规划需求获得：

0 ≤ N_WT ≤ N_WT,max  (6.6)
0 ≤ N_PV ≤ N_PV,max  (6.7)
0 ≤ N_BESS ≤ N_BESS,max  (6.8)
0 ≤ N_DE ≤ N_DE,max  (6.9)

式中，N_WT,max、N_PV,max、N_BESS,max、N_DE,max 分别为 WT、PV、BESS 和 DE 机组基于预算的投资成本和微电网发电单元安装场地实际规划需求获得的上限值。

###### (3) BESS 单元充放电约束。

BESS 单元使用年限的长短与电池单元的充放电深度、充放电功率和充放电次数等因素有关，为了使 BESS 单元的损耗减小，同时增加 BESS 的使用年限，制定了 BESS 单元吸收和释放电能的上下限约束，规定 BESS 在放电时荷电状态的最小值为 0.2，最大充放电功率是其额定功率的 1/2，可表示如下：

$$\begin{cases}P_{\text{Dis}}\leqslant 0.2\text{BESS}_{\text{rate}}/\Delta t\\P_{\text{Cha}}\leqslant 0.2\text{BESS}_{\text{rate}}/\Delta t\\\text{SOC}_{\min}\leqslant\text{SOC}_t\leqslant\text{SOC}_{\max}\end{cases}\tag{6.10}$$

式中，$P_{\text{Dis}}$、$P_{\text{Cha}}$ 分别为单位小时内的 BESS 充、放电功率，kW；$\Delta t$ 为时间间隔，本节取 1h； $\text{BESS}_{\text{rate}}$ 为 BESS 的额定容量，kWh；$\text{SOC}_t$ 为 $t$ 时刻 BESS 的荷电状态；$\text{SOC}_{\min}$、$\text{SOC}_{\max}$ 分别为 BESS 的荷电状态下限和上限，分别取 20%和 100%。

###### (4) 负载缺电量约束：

$$\text{LPOR}\leqslant\text{LPOR}_{\max}\tag{6.11}$$

式中，$\text{LPOR}_{\max}$ 为容许出现负载缺电量的最大概率；LPOR 为负载缺电量，表示在一定的运行周期范围内，该微电网系统提供的电能无法满足系统负载电能需求的概率，即在该周期内负载总缺电量占负载电能总需求的比值，可表示为

$$\text{LPOR}=\frac{\sum_{t=1}^{T}\text{LPO}(t)}{E_{\text{LOAD-U}}}\tag{6.12}$$

式中，$\text{LPO}(t)$ 为 $t$ 时刻微电网系统中的负载需求未满足量；$E_{\text{LOAD-U}}$ 为负载全年所需求的电能。

$$\text{LPO}(t)=\begin{cases}E_{\text{LOAD-U}}-E_{\text{MG,max}(t)},&E_{\text{MG,max}(t)}<E_{\text{LOAD-U}}\\0,&E_{\text{MG,max}(t)}\geqslant E_{\text{LOAD-U}}\end{cases}\tag{6.13}$$ $$E_{\text{MG,max}(t)}=E_{\text{WT}}(t)+E_{\text{PV}}(t)+E_{\text{DE}}(t)+\eta\big(E_{\text{BESS}}(t)-E_{\text{BESS,min}}\big)\tag{6.14}$$

式中，$E_{\text{MG,max}(t)}$ 为 $t$ 时刻微电网系统分布式发电单元提供电能的最大值；$E_{\text{WT}}(t)$、$E_{\text{PV}}(t)$、$E_{\text{DE}}(t)$ 分别为 $t$ 时刻 WT、PV、DE 的出力；$E_{\text{BESS}}(t)$ 为 $t$ 时刻 BESS 的荷电状态；$E_{\text{BESS,min}}$ 为 BESS 的最小荷电状态；$\eta$ 为 BESS 的充放电效率。

###### (5) 污染物排放量约束。

由于 DE 机组在发电过程中排放的污染物和温室效应气体主要包括 $\text{NO}_x$、$\text{SO}_2$、$\text{CO}_2$ 等，其排放量分别为 4.33g/kWh、0.464g/kWh、232g/kWh，因此本节选用 $\text{CO}_2$ 的排放量作为污染物排放量约束，即

$$M_{\text{CO}_2}\leqslant M_{\text{CO}_2,\max}\tag{6.15}$$

式中，$M_{CO_2,max}$ 为允许 $CO_2$ 排放量的上限值，g/kWh； $M_{CO_2}$ 为 $CO_2$ 的排放量，定义为特定周期内 $CO_2$ 的排放总量，g/kWh，可表示为

$M_{CO_2}=\sum_{m=1}^{N_{DE}}M_{m,CO_2}\sum_{t=1}^{T}P_{m,CO_2}(t)$  (6.16)

##### 2) EE 和 EP 优化目标模型

EE 和 EP 优化目标模型是在 EE 优化目标模型的目标函数的基础上，同时引入系统的 EP 指标，并将其转化成系统治污成本，而将系统 PR 指标计入约束条件中，为便于描述，以下将 EE 和 EP 优化目标模型简称为 EE-EP 优化目标模型，EE-EP 优化目标模型的目标函数和约束条件如下：

$C_{INVE}=C_{GE}+C_{FU}+C_{OM}+C_{PE}$  (6.17)

式中，$C_{PE}$ 为年污染物治理成本，微电网系统年治污成本计算公式如下：

$C_{PE}=\sum_{m=1}^{N_{DE}}\sum_{t=1}^{T}(\varepsilon_1\delta_1\theta_{SO_2}+\varepsilon_2\delta_2\theta_{NO_x}+\varepsilon_3\delta_3\theta_{CO}+\varepsilon_4\delta_4\theta_{CO_2})P_{DE,m}(t)$  (6.18)

式中，$\varepsilon_1$、$\varepsilon_2$、$\varepsilon_3$、$\varepsilon_4$ 分别为污染物和温室效应气体 $NO_x$、$SO_2$、$CO$、$CO_2$ 的单位治理成本，元/kg；$\delta_1$、$\delta_2$、$\delta_3$、$\delta_4$ 分别为污染物和温室效应气体 $NO_x$、$SO_2$、$CO$、$CO_2$ 的排放系数，%；$\theta_{SO_2}$、$\theta_{NO_x}$、$\theta_{CO}$、$\theta_{CO_2}$ 分别为污染物和温室效应气体 $SO_2$、$NO_x$、$CO$、$CO_2$ 的单位排放量，kg/L。

EE-EP 优化目标模型的约束条件为 EE 优化目标模型的约束条件中去除 EP 条件限制，即去掉污染物排放量约束，其他约束条件相同。

##### 3) EE 和 PR 优化目标模型

EE 和 PR 优化目标模型中的目标函数是在 EE 优化目标模型中的目标函数的基础上，引入了系统的 PR 指标，并将其转化成负荷缺电量补偿成本，而系统的 EP 指标只计入约束条件，为便于描述，将 EE 和 PR 优化目标模型简化为 EE-PR 优化目标模型，EE-PR 优化目标模型的目标函数和约束条件表示如下：

$C_{INVE}=C_{GE}+C_{FU}+C_{OM}+C_{LS}$  (6.19)

式中，$C_{LS}$ 为年负荷缺电量补偿成本，单位为元，可表示为

$C_{LS}=\sum_{t=1}^{T}c_l LPO(t)$  (6.20)

式中，$c_l$ 为单位负荷缺电量的补偿成本，元/kWh。

EE-PR 优化目标模型的约束条件为从 EE 优化目标模型的约束条件中去除 PR 条件限制，即去掉负荷缺电量约束，其他约束条件相同。

##### 4) EE、EP 和 PR 优化目标模型

EE、EP 和 PR 优化目标模型中的目标函数是在 EE 优化目标模型中目标函数的基础上，引入了系统的 EP 和 PR 指标，分别将其转化成治污成本和负荷缺电量补偿成本，为便于描述，将 EE、EP 和 PR 优化目标模型简化为 EE-EP-PR 优化目标模型，EE-EP-PR 优化目标模型的目标函数和约束条件可表示如下：

$C_{INVE} = C_{GE} + C_{FU} + C_{OM} + C_{LS} + C_{PE}$ (6.21)

EE-EP-PR 优化目标模型的约束条件为从 EE 优化目标模型的约束条件中去除 EP 条件限制和 PR 条件限制，即去掉污染物排放量约束和负荷缺电量约束，其他约束条件相同。

#### 2. 微电网的电源容量优化配置策略

微电网中分布式电源容量配置的本质为建立恰当的优化模型，并选择适当的优化算法对其进行求解，从而求得使优化模型中的目标函数取得最佳值时的分布式电源容量组合。微电网中分布式电源的出力大小及负载的电能需求决定了分布式电源的容量配置方案。目前从能量控制策略的角度对电源容量进行配置的研究文献首先大多考虑由清洁型发电单元供电，当不能满足负载电能需求时，由储能电池提供电能，而将大电网作为备用电源，这将使得大电网中的电能得不到充分利用，且 BESS 充放电次数多，会使其寿命缩短，且由于其成本较高，使得系统的 EE 降低。然而，在不同能量控制策略下微电网电源容量优化配置也存在着差异，由于微电网的发展动力是具有较好的经济性和环保性特点，本节提出经济性最大化能量控制策略和环保性最大化能量控制策略，并讨论其对微电网电源配置的影响，由于孤岛型微电网的能量控制策略比较单一且相对比较简单，本节仅对并网型微电网的能量控制策略进行研究，下面将详细介绍经济性最大化能量控制策略和环保性最大化能量控制策略的具体内容。

##### 1) 经济性最大化能量控制策略

微电网系统经济性最大化能量控制策略的本质是最小化系统的运行投入成本，由于清洁型可再生能源的运行维护成本低，且不排放污染物，为实现微电网系统经济性最大化，需最大限度地配置清洁型分布式发电单元，当仍不能满足负载电能需求时，再通过对比其他分布式发电单元的出力费用和从大电网购买电能费用的高低关系，使系统的运行费用达到最小值，以实现经济性最大化。经济性最大化能量控制策略流程如图 6.1 所示，具体内容如下：

(1)使得 PV 单元和 WT 机组依据自然情况按照最大出力方式为负载提供电能供应。

(2)当 PV 和 WT 的出力无法满足负载电能需求时，选择 DE 出力或从大电网购买电能为负载提供电能，将 DE 投运情况下的支出费用及相同时间段从大电网购买电能的支出费用进行比较，选择支出费用较小的电源进行出力为负载提供电能。由于 DE 在较低负载情况下出力时，其供能的效率比较低，将导致燃料消耗大，使得其运行不够经济，因此应制定 DE 出力的下限约束，使其在系统负载电能需求大于其出力下限约束时才投入运行。若 DE 在小于其出力上限约束的情况下运行，则能够为负载提供足够的电能，比较 DE 出力支出费用的大小和其出力进行并网时的电价，若出力支出费用较同时段内向电网销售电能的价格低，则允许 DE 多出力，并将多余的电能销售给大电网以获取更高的经济效益；若出力支出费用较同时段内向电网销售电能的价格高，则只允许 DE 出力以满足负载电能需求，而不进行多发电。

(3)由于储能装置的运行费用较高，将其作为微电网系统的备用电源，其主要用于当其他形式的电源出力无法满足电能需求时，才进行放电为负载提供电能；当 BESS 中储存的电能小于允许值，并且清洁型发电单元出力较多，大于负载电能需求，出现电能盈余时，则为 BESS 充电，若仍未到达 BESS 储存电能上限制，则依据 (2) 中电源出力为 BESS 充电，以获得较多的电能用于高峰期为负载提供电能。

##### 2) 环保性最大化能量控制策略
