# 4.2.2 海水淡化负荷求解方法建立

# 1. 特征量分析

目前，海水淡化技术主要应用在生活海岛、旅游海岛、渔业、军事海岛、沿海工业园区、沿海居民区以及沿海商业区等多种场景中。不同场景中海水淡化负荷的特征量主要为用户用水需求及温度等。例如，生活海岛中海水淡化负荷与岛上居民的生活习惯、温度条件息息相关，而旅游海岛中的海水淡化负荷与岛上气候条件、旅游季节有关。因此，本节着重分析温度、用户用水需求对海水淡化负荷的影响。

以温度的归一化值，日用水量的映射值，海水淡化装置给水泵、高压泵和升压泵的时序用电功率序列对给水泵海水流速数据序列的映射值，海水淡化装置回水泵的时序用电功率序列对淡水回水流速数据序列的映射值以及海水淡化装置的高浓度盐水流速数据对淡水回水流速数据的映射值为特征量选取相似日。特征量综合反映了海水淡化负荷对环境温度、日用水量需求、海水用量、淡水产量、用电功率和海水淡化效率等方面的指标性能，温度的归一化处理公式如下：

$$T = \frac{T_i - T_{\min}}{T_{\max} - T_{\min}} \tag{4.22}$$

式中，$i=1,2,\cdots,n$，$n$为历史日期天数；$T_i$为第$i$日的温度；$T_{\min}$为历史日期最低温度；$T_{\max}$为历史日期最高温度。
