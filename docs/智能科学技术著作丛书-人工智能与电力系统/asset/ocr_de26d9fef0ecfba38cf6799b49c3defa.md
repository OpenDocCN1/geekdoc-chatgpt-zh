Q 表，适用于状态空间非常复杂的场景。将当前状态值作为神经网络的输入，输出端输出所要采取的动作，对神经网络的参数进行更新，利用经验回放机制减小了数据之间的相关性，缩短了训练时间。

深度 Q 网络算法在进行优化时，每次都会选取下一个状态最大 Q 值所对应的动作，这会带来过估计的问题，van Hasselt 等在双 Q 学习算法的研究基础上提出了深度双 Q 网络算法。在深度双 Q 网络算法中有两套不同的参数网络，分别是当前值网络和目标值网络，当前值网络用来选取动作，目标值网络用来对动作做出评估，这样动作选择和策略评估得以分离，有效降低了 Q 值过估计的风险。

在深度 Q 网络取得成功后，DeepMind 团队中的 Timothy 等又将深度神经网络与确定性策略相结合，提出了深度确定性策略梯度算法。深度确定性策略梯度算法使用深度神经网络来表示策略，并采用策略梯度的方式来更新策略。深度确定性策略梯度算法同时具备确定性策略算法和深度学习的优点，在实际运用中，这种学习方式往往能够带来更加有效的学习过程[14]。

# 2) 元强化学习

元学习的目标是学会学习，从一系列学习任务中训练一个模型，这个模型在面对新的学习任务时只需要少量的样本便可以实现快速学习。元学习的思想是将同一系列任务的内在特征分成两类，一类是通用特征，另一类是灵敏度较高的特征。在实验过程中，通过求最小方差的方式得到通用特征，当面对新任务时只需少量样本就可以学习到具体任务中其他灵敏度较高的特征。

深度学习对大数据的过度依赖也在一定程度上制约了深度强化学习的发展，为了实现小样本学习，元强化学习研究开始受到关注。元强化学习框架最早由 Schmidhuber 等提出。Jane X Wang 等将深度学习与元强化学习相结合提出深度元强化学习概念，并使用神经网络实现了对强化学习任务的快速学习。

大部分关于强化学习的研究都基于环境不变的假设，但现实世界中的环境常常是不断变化的，强化学习的策略也需要不断学习调整以适应不断变化的环境。Chelsea 等提出一种模型未知的元学习算法，这种算法不针对某种特定的模型，采用梯度下降方式进行更新，在面对新任务时，模型微调之后便可以获得较好的泛
