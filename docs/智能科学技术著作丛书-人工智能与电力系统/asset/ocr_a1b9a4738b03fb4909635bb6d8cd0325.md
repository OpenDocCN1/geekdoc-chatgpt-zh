# 2) 应用循环神经网络的电力系统短期负荷预测

以往的负荷预测技术，多采用前馈人工神经网络、支持向量机等进行短期的电力负荷预测，网络中没有记忆单元，缺少对时序数据时间相关性的考虑，长短期记忆网络可以学习时间序列长短期依赖信息，包含时间记忆单元，适用于处理和预测时间序列中的间隔和延迟事件。有学者在进行短期电力负荷预测时，考虑到时序数据的时间相关性，应用张量流深度学习框架构建了长短期记忆网络模型，对电力负荷时序数据进行回归预测，可使调度人员更好地了解未来负荷的变化波动，更有针对性地进行电力调度。

# 3) 应用循环神经网络的电力系统稳定性评估

随着电网规模的扩大，电力系统的稳定性愈加难以掌控。一方面，跨区域电网的互联可以合理利用整体资源，带来巨大的经济效益；但另一方面，电网结构的变化，呈现出更加复杂的非线性特性。

世界上已经发生的多次数电网故障表明，输电电压等级的提高、联网规模的扩大以及传输容量的增加，都会增大电网故障带来的危害，故障原因和过程也更为复杂。开展对运行电网的实时在线监测、分析和控制，是各国电力行业的迫切需求。传统的时域评估方法计算量大、耗时长，不适合电力系统在线稳定性评估。人工神经网络具有良好的处理复杂未知非线性系统的能力，能够很好地捕捉电力系统的动态特性，当前循环神经网络被广泛地用于非线性系统的处理，当电网结构发生变化时，电网稳定性的分析可有效提高精度与效率。
