# 1. 单负荷辨识

单负荷辨识主要针对家庭在某段时间内只开启一个负荷的情况，为了判断算法的准确性，分别在固定时间内单独启停各用电负荷，采集周期为 1s。在本实验中，先用训练样本对模型进行训练，然后随机选择 100 组单负荷作为辨识负荷数据，因为是单个负荷启停，其辨识准确率和精度相同，结果如图 5.4 所示。

![](bbox=[0.18, 0.25, 0.86, 0.55])

图 5.4 单个负荷的辨识准确率

实验结果表明，基于多特征序列融合的负荷辨识算法，对单个负荷的辨识准确率达到 92%及以上，可以很好地处理单负荷的辨识问题。同时可以看出，单状态负荷和多状态负荷的辨识准确率与精度较高，原因在于单状态负荷功率变化不大，而多状态负荷功率的变化较其他负荷功率变化大，用整数规划即可准确判断。而对于多变化负荷，功率值与用户使用情况有关，辨识的时候可能产生误判，辨识准确率和精度较其他负荷低。
