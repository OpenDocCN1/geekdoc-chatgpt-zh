征选择方法对各类工业用户负荷构建的初始特征进行特征冗余性分析、特征关联性分析和特征重要性分析得到各类最终的最优特征子集。

（4）分类预测、模型融合和预测结果分析。各类工业用户负荷利用唯一相对应的 LightGBM 模型对该类工业用户负荷及其特征进行训练与预测，然后将各类学习器进行线性组合并得到最终预测结果，最后与其他传统和前沿预测模型进行比较以验证本节所提出的工业用户中期负荷预测模型的有效性。

将利用工业用户形态聚类算法和特征过程处理后的各类工业用户负荷数据利用其对应的 LightGBM 模型进行训练和预测，然后通过模型融合得到最终预测结果。模型融合的计算公式如下：

Pre = Σ_{i=1}^{n} pre_i  (4.46)

式中，Pre 为最终预测结果；n 为单一模型的数目；pre_i 为第 i 个模型的预测结果。

# 4.3.4 仿真与验证

本算例通过预测精度和计算效率两方面评价指标来评估预测结果的有效性。预测精度采用三种评价指标，分别是平均绝对百分比误差 (mean absolute percentage error, MAPE)、平均绝对误差 (mean absolute error, MAE) 和均方根误差 (root mean square error, RMSE)。模型计算效率采用预测过程的计算时间来评价，预测精度所采用的三种评价指标公式为

MAPE = (1/n) Σ_{i=1}^{n} |y_i - ŷ_i| / |y_i| × 100%  (4.47)

MAE = (1/n) Σ_{i=1}^{n} |y_i - ŷ_i|  (4.48)

RMSE = sqrt( (1/n) Σ_{i=1}^{n} (y_i - ŷ_i)^2 )  (4.49)

式中，n 为预测点个数；y_i 为第 i 个预测点的真实值；ŷ_i 为第 i 个预测点的预测值。
