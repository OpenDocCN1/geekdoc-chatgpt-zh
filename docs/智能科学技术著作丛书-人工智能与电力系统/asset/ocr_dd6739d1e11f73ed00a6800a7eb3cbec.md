# 2. 基于灰色关联分析的相似日选取方法

基于支持向量机的海水淡化负荷预测模型需要应用数据样本对模型进行训练。信息冗余的训练样本不仅增加了训练时间，还降低了海水淡化负荷预测的精度，不利于模型使用。此问题可通过相似日选取方法加以解决。早期相似日的选取方法人工经验法，现有常用的方法主要有聚类分析法、证据理论法、趋势相似度法、灰色关联分析法等。本节采用灰色关联分析法进行相似日的选取。

将海水淡化负荷特征量数据分为历史数据和待预测数据。计算历史日 n 天的特征量序列 X_m = (x_m(1), x_m(2), …, x_m(t)) 与待预测日的特征量序列 X_0 = (x_0(1), x_0(2), …, x_0(t)) 之间的关联度。其中，m = 1,2,⋯,n；t 是海水淡化负荷特征量的个数。

首先求历史日特征量序列与待预测日特征量序列的差序列 Δ = [Δ_4_0, …, Δ_4_m0, …, Δ_4_n0]，其中 Δ_m0 = (|x_m(1)−x_0(1)|, …, |x_m(t)−x_0(t)|)，再求取两级序列的最大差和最小差，即

Δ_max = max_n max_t (Δ)
Δ_min = min_n min_t (Δ)  (4.23)

最后计算 X_0 对 X_m 的灰色关联度如下：

γ(X_0, X_m) = (1/t) Σ_{k=1}^t [Δ_min + ρ Δ_max] / [Δ_m0(k) + ρ Δ_max]  (4.24)

式中，Δ_m0(k) = |x_m(k)−x_0(k)|；ρ 为分辨率系数，取 0.5。

# 3. 最小二乘支持向量机模型

最小二乘支持向量机模型基于支持向量机理论，将优化中的不等式约束转化为等式约束，因此二次规划问题变成了线性方程组的求解问题，减少了计算量，提高了解决速度。给定一组数据点集 {(x_i, y_i)}_{i=1}^l，其中，x_i 是输入向量，包括日用水量映射值，温度，海水淡化装置给水泵、高压泵和升压泵的时序用电功率序列对给水泵海水流速数据序列的映射值，海水淡化装置回水泵的时序用电功率序列对淡水回水流速数据序列的映射值，海水淡化装置的高浓度盐水流速数据对淡水回水流速数据的映射值和相似日海水淡化负荷时序用电功率向量；y_i 是输出向量；l 为样本点数。

海水淡化负荷是非线性电动机负荷，其一般预测模型为
