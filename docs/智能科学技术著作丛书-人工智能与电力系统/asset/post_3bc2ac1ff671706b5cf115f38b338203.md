
式中，τ_is(t) 为此时的信息素含量； η_is(t) 为启发因子，又称能见度因子； α 为信息素比例； β 为启发信息比例； J_k(i)={1,2,⋯,m}−τ_k 为下一步允许选择的节点集合。

列表 τ_k 记录了蚂蚁 k 在本次迭代中走过的节点，不允许蚂蚁在本次循环中再经过这个节点。

当所有蚂蚁完成一次循环后，根据式(2.7)进行信息素的更新：

τ_ij(t+1) = (1 - ρ) τ_ij(t) + Δτ_ij(t)   (2.7)

Δτ_ij(t) = Σ_{k=1}^{m} Δτ_ij^k   (2.8)

式中，ρ 为信息素的挥发系数，其范围是 0～1； 1-ρ 为信息素的持久系数； Δτ_ij(t) 为本次迭代边 (ij) 上信息素的增量； Δτ_ij^k 为第 k 只蚂蚁在本次迭代边 (ij) 上信息素的增量。

当蚂蚁 k 经过迭代边 (ij) 时，Δτ_ij^k 表示为

Δτ_ij^k = { Q / L_k , 蚂蚁k在本次周游中经过边(ij) ; 0 , 其他 }   (2.9)

式中，Q 为正常数； L_k 为第 k 只蚂蚁在本次周游中走过路径的长度。

蚁群算法根据痕迹更新方式可以分为蚁周算法(ant-cycle algorithm)、蚁量算法(ant-quantity algorithm)、蚁密算法(ant-density algorithm)。上述介绍的是蚁周算法，下面介绍蚁量算法和蚁密算法。

蚁量算法的模型为

Δτ_ij^k = { Q / d_ij , 蚂蚁k在本次周游中经过边(ij) ; 0 , 其他 }   (2.10)

蚁密算法的模型为

Δτ_ij^k = { Q , 蚂蚁k在本次周游中经过边(ij) ; 0 , 其他 }   (2.11)

蚁周算法搜索使用的反馈信息是全局的，而蚁量算法、蚁密算法使用的反馈信息是局部的。

信息是局部的，所以蚁周算法要优于其他两种算法。

一般情况下蚁群的蚂蚁数量不超过 TSP 的节点个数，其终止条件为给定一个外循环的最大数目，表明已经有足够的蚂蚁工作；如果最优解连续 K 次相同，则停止计算，其中 K 是一个给定的整数，表示算法已经收敛，不需要继续循环。

## 2.3.2 蚁群算法的特点及应用场景

与其他优化算法相比，蚁群算法具有以下几个特点：

- （1）采用正反馈机制，使得搜索过程不断收敛，最终逼近最优解。
- （2）每个个体可以通过释放信息素来改变周围的环境，且每个个体能够感知周围环境的实时变化，个体间通过环境进行间接的通信。
- （3）搜索过程采用分布式计算方式，多个个体同时进行并行计算，大大提高了算法的计算能力和运行效率。
- （4）启发式的概率搜索方式不容易陷入局部最优，易于寻找到全局最优解。

自从蚁群算法在一些经典的组合规划问题（如 TSP 和二次分配问题（quadratic assignment problem, QAP）等）NP 的组合优化问题上取得成功以来，目前已陆续渗透到许多新的实际工程领域：

- （1）蚁群算法在工程和工业生产中的应用，如采用蚁群算法的思想来求解大规模集成电路综合布线问题。在布线过程中，各个引脚对“蚂蚁”的引力可根据引力函数来计算，各个线网智能体根据启发策略，像蚂蚁群一样在开关盒网格上爬行，所经之处便布上一条金属线，历经一个线网的所有引脚之后，线网便布通了。
- （2）蚁群算法在规划问题中的应用，如在机器人路径规划的应用。机器人作为一种智能体，在复杂工作环境下的路径规划问题、多机器人之间的协作策略问题，在很大程度上类似于蚂蚁觅食选路径以及蚂蚁群体中个体之间通过信息素形成协作。路径规划算法是实现机器人控制和导航的基础之一，实验证明蚁群算法解决该问题有很大的优越性。
- （3）蚁群算法在动态优化组合问题中的应用，包括在有向连接的网络路由和无向连接网络系统路由中的应用，还包括蚂蚁人工神经网络、车辆路线问题（vehicle routing problem, VRP）、图像处理和模式识别领域的应用等。

## 2.4 粒子群优化算法

1995 年美国电气工程师 Eberhart 和社会心理学家 Kennedy 基于鸟群觅食行为提出了粒子群优化 (particle swarm optimization, PSO) 算法。1998 年 Russell Eberhart 发表了学术论文，首次对基本粒子群优化算法引入惯性权重修正了速度更新公式，修正后的公式已经被多数研究者所使用。2001 年，第一部关于粒子群优化算法的专著 Swarm Intelligence 在美国旧金山出版。2003 年，第一届群智能研讨会在美国的印第安纳波利斯召开，此后每年召开一次。粒子群优化算法作为一种新兴的智能仿生算法，目前还没有完备的数学理论基础，但已在诸多领域得到广泛应用。

由于其在动态多目标寻优问题中的简单快速、全局寻优能力和收敛性好的明显优势以及在函数优化等领域的广阔应用前景，此算法一经提出就引起了研究人员的浓厚兴趣，之后的诸多学者对于基本粒子群优化算法又进行了进一步的研究，提出了许多改进算法并且应用于工程领域当中。本书主要介绍粒子群优化算法的基本概念、模型、特点及应用场景[6]。

### 2.4.1 粒子群优化算法的基本概念及模型

### 1. 粒子群优化算法的生物学原理

粒子群优化算法是模拟鸟类随机搜索食物捕食行为的算法。假设一个鸟群在一定空间范围内搜索一块食物，在找到这块食物之前所有的 小鸟都不知道食物的具体位置，但是小鸟之间可以相互交流信息。在寻找食物的过程中，每只小鸟都能感受到当前位置与食物之间的距离，搜索目前离食物最近的鸟的周围区域是找到食物最简单有效的方法，通过小鸟之间的集体协作最终找到食物。在飞行的过程中每只小鸟都遵守三条规则：①避免与其他小鸟发生碰撞；②尽量与其他小鸟的速度保持一致；③尽量向自己认为正确的群体靠近。

粒子群优化算法通过鸟类随机搜索食物的模型得到启发。在粒子群优化算法中每一个优化问题潜在的解都可以看作空间中的一只鸟，称为“粒子”，所有的粒子都有一个由被优化函数决定的适应度值 (fitness value)，它们的速度决定每个粒子飞行的方向和距离。粒子通过追随当前的最优粒子在解空间中进行搜索。

在每一次的迭代过程中，粒子通过两个“极值”来进行位置的变化，一个是个体极值，即粒子个体本身所找到的历史最优解，通常表示为 pbest；另一个是全局极值，即群体所有粒子目前所找到的历史最优解，通常表示为 gbest。粒子通过自己和同伴的经验决定下一步的运动轨迹。

### 2. 粒子群优化算法的基本模型

假设一个 D 维的空间中有 n 个粒子，那么第 i 个粒子的位置的 D 维向量表示为

$X_i = (x_{i1}, x_{i2}, \dots, x_{iD}),\ i=1,2,\dots,N$  (2.12)

第 i 个粒子的飞行速度的 D 维向量表示为

$V_i = (v_{i1}, v_{i2}, \dots, v_{iD}),\ i=1,2,\dots,N$  (2.13)

第 i 个粒子迄今为止搜索到的个体极值(pbest)的 D 维向量表示为

$p_i = (p_{i1}, p_{i2}, \dots, p_{iD}),\ i=1,2,\dots,N$  (2.14)

整个粒子群迄今为止搜索到的全局极值(gbest)的 D 维向量表示为

$g_i = (p_{g1}, p_{g2}, \dots, p_{gD})$  (2.15)

不妨设 $f(x)$ 为目标函数，则由式 (2.16) 决定粒子 i 的当前最好位置：

$p_i(t+1)=\begin{cases}p_i(t), & f(x_i(t+1))\ge f(p_i(t))\\x_i(t+1), & f(x_i(t+1))< f(p_i(t))\end{cases}$  (2.16)

在找到这两个最优位置时，粒子群更新自己的速度和位置的表达式为

$v_{id}(t+1)=w v_{id}(t)+c_1 r_1\big(p_{id}(t)-x_{id}(t)\big)+c_2 r_2\big(p_{gd}(t)-x_{id}(t)\big)$  (2.17)

x_{id}(t+1)=x_{id}(t)+v_{id}(t)  (2.18)

式中，t为迭代次数；v_{id}(t)为第i个粒子的速度；x_{id}(t)为第i个粒子的位置；w为惯性权重；c1、c2为学习因子，也称为加速度系数；r1、r2为内随机生成的两个向量；p_{id}(t)为第i个粒子迄今为止搜索到的最优的位置，称为个体极值，即pbest；p_{gd}(t)为整个粒子群迄今为止搜索到的最优位置，称为全局极值，即gbest。

式(2.17)右边由以下三个部分组成：

- (1) “惯性” 部分，反映了粒子运动的 “习惯”，代表粒子有维持自己先前速度的趋势。
- (2) “认知” 部分，反映了粒子对自身历史经验的记忆或回忆，代表粒子有向自身历史最佳位置逼近的趋势。
- (3) “社会” 部分，反映了粒子间协同合作与知识共享的群体历史经验，代表粒子有向群体或邻域历史最佳位置逼近的趋势。

由于粒子群优化算法具有较好的搜索能力，有利于得到多目标意义下的最优解；通过代表整个解集种群，按并行方式同时搜索多个非劣解，即搜索到多Pareto最优解。

但单独使用粒子群优化算法时，通过改变迭代次数，且迭代次数越大，获得的解的精度不一定越高，因为粒子群优化算法是一种随机算法，保持相同参数时也会算出不同的结果。而当改变粒子群规模时，粒子群规模越大，获得的解的精度也不一定越高。因此，在粒子群优化算法中，想要获得精度高的解，关键要使各参数间搭配合适。

粒子群优化算法求解流程如图2.7所示，具体如下所述。

- (1) 初始化一个规模为n的粒子群，确定初始位置和速度，过程如下：
  - ① 设定种群规模n。
  - ② 对于任意的i、d，在[-x_max,x_max]内服从均匀分布产生x_id。
  - ③ 对于任意的i，设v_i = x_i。

- (3) 对每个粒子，将其适应度值和个体极值p_id的适应度值相比较，若较好，则将其作为个体极值。

## 2.4.2 粒子群优化算法的特点及应用场景

粒子群优化算法具有以下特点：

- (1) 是一类不确定算法。不确定性体现了自然界生物的生物机制，并且在求解某些特定问题方面优于确定性算法。
- (2) 是一类概率型的全局优化算法。非确定算法的优点在于算法能有更多机会求解全局最优解。
- (3) 不依赖于优化问题本身的严格数学性质。
- (4) 是一类基于多个智能体的仿生优化算法。粒子群优化算法中的各个智能体之间通过相互协作来更好地适应环境，表现出与环境交互的能力。
- (5) 具有本质并行性。包括内在并行性和内含并行性。
- (6) 具有突出性。粒子群优化算法总目标的完成是在多个智能体个体行为的运动过程中突现出来的。
- (7) 具有自组织、进化性及记忆功能，所有粒子都保存最优解的相关知识。
- (8) 具有稳健性。稳健性是指在不同条件和环境下算法的实用性和有效性，但是现在粒子群优化算法的数学理论基础还不够牢固，算法的收敛性还需讨论。

可以看出粒子群优化算法具有很大的发展价值和发展空间，算法能够用于多个领域，并且在群智能算法中具有重要的地位，同时也能够在相关产业创造价值、发挥作用，具体可应用在如下领域：

- (1) 模式识别和图像处理。粒子群优化算法已在图像分割、图像配准、图像融合、图像识别、图像压缩和图像合成等方面发挥作用。
- (2) 神经网络训练。粒子群优化算法可完成人工神经网络中的连接权重的训练、结构设计、学习规则调整、特征选择、连接权重的初始化和规则提取等。但是速度没有梯度下降优化得好，需要较多的计算资源。
- (3) 电力系统设计。例如，日本的 Fuji 电力公司的研究人员将电力企业某个著名的无功电压控制 (reactive power and voltage control, RPVC) 问题简化为函数的最小值问题，并使用改进的粒子群优化算法进行优化求解。
- (4) 半导体器件综合。半导体器件综合是在给定的搜索空间内根据期望得到的器件特性来设计相应的参数。
- (5) 其他相关产业。包括在自动目标检测、生物信号识别、决策调度、系统识别以及游戏训练等方面也取得了一定的研究成果。

## 2.5 模拟退火算法

在介绍模拟退火 (simulated annealing, SA) 算法之前，首先介绍爬山算法。爬山算法每次从当前解的邻近解空间中选择一个最优解作为当前解，直到达到一个局部最优解。爬山算法的原理如图 2.8 所示。假设 C 点为当前解，爬山算法沿 C 点搜索到附近的 A 点这个最优解，就会停止搜索，然而从 A 点出发，无论向哪个方向小幅度移动，都不能得到更优解，只能得到 A 点这个局部最优解[7]。

![](img/2160aa82ffab89ad09fb1b4e167a298b_39_0.png)

图 2.8 爬山算法原理示意图

模拟退火其实也是一种贪婪搜索算法，但是与爬山算法不同的是，它在搜索过程中引入了随机因素，并以一定的概率接受一个比当前解要差的解，因此有可能跳出当前这个局部的最优解，达到全局的最优解。以图 2.8 为例，模拟退火算法在搜索到局部最优解 A 点后，会以一定的概率接受到 D 点的移动，经过几次这样的不是局部最优的移动后，会到达 B 点，于是就跳出了局部最大值 A 点，从而实现全局最大值的搜索。

相比之下，模拟退火算法能够实现全局最大值的搜索，而爬山算法只能实现局部最大值的搜索，本节主要介绍模拟退火算法的基本概念、模型、特点及应用场景。

### 2.5.1 模拟退火算法的基本概念及模型

模拟退火算法是由 N. Metropolis 等于 1953 年基于 Monte-Carlo 迭代求解策略提出的一种随机寻优算法，基于物理中固体物质的退火过程，从某一较高初始温度出发，伴随温度参数的不断下降，结合概率突跳特性在解空间中随机寻找目标函数，以有效避免陷入局部极小并最终趋于全局最优。

### 1. 模拟退火算法的物理学原理

在热力学中，退火现象是指物体缓慢地逐渐降温的物理现象。在高温下，液体间大量分子之间进行相对自由移动，随着液体慢慢冷却，原子的可动性则会消失，大量原子自行排列成行，形成一个纯净的晶体。对该系统来说，在结晶状态时，系统的能量状态最低。若液体冷却过程过快，则系统只能达到一种只有较高能量的多晶体状态或非结晶状态，而非晶体状态。因此，退火过程的关键在于缓慢冷却。一般来说，退火过程由三部分组成：升温过程、等温过程和冷却过程。

升温过程通过增强物体中粒子的热运动，使其偏离平衡位置变为无序状态，当温度足够高时，固体将会溶解为液体，从而消除系统原来可能存在的非均匀态，以确保随后的冷却过程以某一平衡点为起点。升温过程与系统的熵增过程相关，系统的能量随温度升高而增大。

等温过程为在物理学中，对于与周围环境交换热量而温度不变的封闭系统，系统状态的自发变化总是朝自由能减小的方向进行，当自由能达到最小时，系统达到平衡。

冷却过程与升温过程相反，随着温度的降低，物体中粒子的热运动逐渐减弱，直至逐渐趋于有序。系统能量随温度降低而下降，得到低能量的晶体结构。

物理退火的过程如图 2.9 所示，在温度较低时(图 2.9(a))物体呈现非晶体状态。将固体加热，使其温度至充分高(图 2.9(b))，物体中粒子呈现无序状态。再将其缓慢冷却(图 2.9(c))，此时物体中粒子渐趋有序，当内能减为最小时，物体以晶体形态呈现。

1953 年，Metropolis 提出重要性采样，用于模拟固体在恒温下达到热平衡的过程，这是模拟退火算法的基础。其基本思想是从固体系统倾向于能量较低的状态，而热运动又阻碍其准确地落入最低态的基本思想出发，采样时着重提取那些具有重要贡献的状态，则可以较快地得到较好的结果。

设粒子相对位置表征的初始状态 i 为固体的当前状态，该状态的能量为 E_i。用摄动状态使随机选取的某个粒子的位移随机地产生一个微小的变化，得到一个新状态 j，其能量为 E_j。若 E_j < E_i，则该新状态就作为“重要”的状态；若 E_j > E_i，则需考虑热运动的影响。该状态是否为“重要”状态，要依据固体处于该状态的概率来判断，即

$p = \exp\left(\frac{E_i - E_j}{\kappa T}\right)$  (2.19)

式中，T 为热力学温度；κ 为玻尔兹曼常量。

因此，p ∈ [0,1], p 越大，状态是重要状态的概率就越大。如果新状态 j 是重要状态，就取代i成为当前状态，否则仍以i为当前状态，再重复以上新状态的产生过程。在大量迁移(固体状态的变换称为迁移)后，系统趋于能量较低的平衡状态，固体状态的概率分布服从吉布斯正态分布，即

$$P = \frac{1}{Z} \exp\left(-\frac{E_i}{\kappa T}\right)\tag{2.20}$$

以上为 Metropolis 准则，其核心思想是当能量增加时以一定的概率接受，而不是一味地拒绝。

模拟退火算法将热力学的理论套用到优化问题上，如表 2.2 所示。将搜寻空间内每一点想象成空气内的分子，分子的能量就是它本身的动能，而搜索空间内的每一点也像空气分子一样带有能量，以表示该点对该问题的合适程度。

模拟退火算法先以搜寻空间内一个任意点为起点，每一步先选择一个“邻居”，再计算从现有位置到达“邻居”位置的概率。算法基本原理的流程如图 2.10 所示，步骤如下：

- 1. 初始化。初始化参数包括初始温度 $T$(充分大)、初始解状态 $S$(算法迭代的起点)、每个温度 $T$ 下的迭代次数 $L$。
- 2. 当 $k=1,2,\cdots,L$ 时，进行步骤(3)～(6)。
- 3. 对当前解进行变换得到新解 $S'$ (如对某些解中的元素进行互换、置换)。
- 4. 计算增量 $\Delta t = C(S') - C(S)$，其中 $C(S)$ 为评价函数。
- 5. 若 $\Delta t < 0$，则接受 $S'$ 作为新的当前解，否则以概率 $\exp(\Delta t' / (\kappa T))$ 接受 $S'$ 作为新的当前解。
- 6. 若满足终止条件，则输出当前解作为最优解，结束程序。
- 7. 当连续若干个新解都没有被接受时终止算法。$T$ 逐渐减小，转到步骤(2)，直到 $T$ 小于初始设定的阈值。
