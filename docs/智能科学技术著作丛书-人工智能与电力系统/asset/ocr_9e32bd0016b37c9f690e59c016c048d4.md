# 2) 数据预处理

通常利用数据预处理方法使原始数据的特征显现得更为明显，更适合卷积神经网络识别，数据预处理分为数据灰度图转换和归一化两个步骤。这里采用如图 5.15 所示的数据灰度图转换方法，将数据表转变为二维图像。

如图 5.15 所示，数据灰度图转换后得到尺寸为 m×m (m=32)。令 L(i) 表示数据灰度图转换生成的片段信号值，其中 i=1,2,…,m²；P(j,k)(j=1,2,…,m；k=1,2,…,m) 表示图像像素强度，具体计算方法如下：

P(j,k) = round{ [ L(j-1)×m + k - min(L) ] / [ max(L) - min(L) ] × 255 }  (5.31)

式中，round 函数为循环函数；max(L) 为第一个灰度图中的最大元素；min(L) 为第一个灰度图中的最小元素。循环函数使所有的像素值标准化到 0～255。数据灰度图转换后得到的灰度图如图 5.16 所示。
