电状态上限的电能，多余电能通过备用负载或其他方式进行消纳。

若ΔP(t)<0，即清洁型电源出力无法满足负载的电能需求，则优先由储能电池释放电能；若其能完全弥补负载电能缺少量，则储能电池释放的电能为

P_{BESS}(t)=|-ΔP(t)|  (6.27)

反之，BESS 释放最大电能直至达到荷电状态的下限，若仍未满足电能需求则由 DE 进行电能供应，DE 出力大小为

P_{DG}(t)=P_{L}(t)-P_{WT}(t)-P_{PV}(t)-P_{BESS}(t)  (6.28)

若 BESS 和 DE 联合出力均无法满足负载电能缺额，即

P_{L}(t)-P_{WT}(t)-P_{PV}(t)-P_{BESS}(t)-P_{DG}(t)<0  (6.29)

则将负载缺电量计入系统 PR 约束中。

# 2. 基于 APSO 对不同能量控制策略下的电源容量配置求解

基于 APSO 对不同能量控制策略下的电源容量配置求解流程如图 6.4 所示。孤网运行微电网的能量控制策略比较单一且相对简单，因此本部分研究并网运行情况下不同能量控制策略对电源容量优化配置的影响。

基于 APSO 对不同能量控制策略下的电源容量配置的求解与基于 APSO 对不同优化目标模型下的电源容量配置求解相似，此处不再赘述，只将不同之处加以具体说明，存在的不同之处为：

(1)适应度函数不同。并网型微电网在适应度函数中引入与大电网进行功率交换的成本/收益 C_{Grid}，适应度函数具体修正为

C_{INVE}=C_{GE}+C_{FU}+C_{OM}+C_{Grid}  (6.30)

C_{Grid}=∑_{t=1}^{T}c_{Grid}(t)P_{Grid}(t)  (6.31)

式中，c_{Grid}(t)为 t 时刻微电网与大电网进行功率交换时的实时电价。P_{Grid}(t)为 t 时刻微电网与大电网交换的功率，若大于零，则表示从大电网购买电能；若小于零，则表示向大电网出售电能。
