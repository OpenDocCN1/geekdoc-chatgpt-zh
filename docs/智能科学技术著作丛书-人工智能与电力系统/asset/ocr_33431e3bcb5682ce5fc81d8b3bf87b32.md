要状态，就取代i成为当前状态，否则仍以i为当前状态，再重复以上新状态的产生过程。在大量迁移(固体状态的变换称为迁移)后，系统趋于能量较低的平衡状态，固体状态的概率分布服从吉布斯正态分布，即

$$P = \frac{1}{Z} \exp\left(-\frac{E_i}{\kappa T}\right)\tag{2.20}$$

以上为 Metropolis 准则，其核心思想是当能量增加时以一定的概率接受，而不是一味地拒绝。

模拟退火算法将热力学的理论套用到优化问题上，如表 2.2 所示。将搜寻空间内每一点想象成空气内的分子，分子的能量就是它本身的动能，而搜索空间内的每一点也像空气分子一样带有能量，以表示该点对该问题的合适程度。

模拟退火算法先以搜寻空间内一个任意点为起点，每一步先选择一个“邻居”，再计算从现有位置到达“邻居”位置的概率。算法基本原理的流程如图 2.10 所示，步骤如下：

+   1. 初始化。初始化参数包括初始温度 $T$(充分大)、初始解状态 $S$(算法迭代的起点)、每个温度 $T$ 下的迭代次数 $L$。
+   2. 当 $k=1,2,\cdots,L$ 时，进行步骤(3)～(6)。
+   3. 对当前解进行变换得到新解 $S'$ (如对某些解中的元素进行互换、置换)。
+   4. 计算增量 $\Delta t = C(S') - C(S)$，其中 $C(S)$ 为评价函数。
+   5. 若 $\Delta t < 0$，则接受 $S'$ 作为新的当前解，否则以概率 $\exp(\Delta t' / (\kappa T))$ 接受 $S'$ 作为新的当前解。
+   6. 若满足终止条件，则输出当前解作为最优解，结束程序。
+   7. 当连续若干个新解都没有被接受时终止算法。$T$ 逐渐减小，转到步骤(2)，直到 $T$ 小于初始设定的阈值。
