# 第 6 章 基于人工智能技术的电力系统优化

本章主要介绍人工智能技术在电力系统优化中的应用，包括基于粒子群优化算法的微电网容量优化配置、基于遗传算法的多能源系统能量枢纽优化配置、基于遗传算法的沿海水电系统优化运行、基于粒子群优化算法的多能源系统优化运行、基于免疫算法的水火电联合优化调度，以及基于蚁群算法的风电集群输电系统拓扑优化。

# 6.1 基于粒子群优化算法的微电网容量优化配置

本节讨论粒子群优化算法在微电网容量优化配置中的应用。微电网中采用科学合理的调控方案能够实现对系统中的分布式机组和大电网、用户侧间的电能交换与运行方式进行相对科学且有效的控制，能够较为有效地减少将不确定性和间歇性分布式电源并入大电网时导致的大电网的电能波动，同时可以增强微电网系统的电能供应的可靠性，使得其孤岛能力增强，还可以较好地保证用户对电能波动范围小和供电可靠性高等的要求。微电网的许多优点均建立在其合理的容量配置和科学的优化运行基础上，如何对含有大量清洁型电源的微电网进行多种类型能源容量和储能装置的合理配置，是保证清洁型能源利用率上升至较大占比，以及使微电网系统的全生命周期支出降低至较小数值的主要依据。在微电网容量优化配置的基础上，如何对微电网中含有的繁多能源、负载进行优化调度，是确保微电网良好运行的主要问题。因此，探讨和研究包括多类型清洁型可再生分布式发电单元的微电网容量优化配置以及微电网中各类分布式电源和储能电池的优化运行调度具有重要的理论参考意义和工程应用价值。

微电网的容量配置优化是一个复杂的非线性优化问题，可采用粒子群优化算法求解，在求解过程中，为了改善粒子群优化算法不能适应复杂非线性优化过程的问题，本节采用自适应粒子群优化 (adaptive particle swarm optimization, APSO) 算法，通过利用群粒子的位置分布情况控制粒子飞行的惯性权重，借助个体最优位置和全局最优位置的平均作用避免粒子陷入局部最优，相对于粒子群优化算法，自适应粒子群优化算法在收敛速度、最优解精度等方面获得了大幅提升，并且适用于微电网容量的优化配置[31]。
