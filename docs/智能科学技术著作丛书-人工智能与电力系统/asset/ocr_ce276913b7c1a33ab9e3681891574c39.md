蚂蚁选择路径的方式都是随机的。

（2）在一个状态下每当蚂蚁到达不同的节点，蚂蚁从初始点到这些节点会在路径中留下信息素，已经到达终点的蚂蚁开始返回，与此同时下一批蚂蚁出动，并根据路径上信息素的浓度选择信息素浓度最高的路径出发（包括一些蚂蚁随机性选择）。

（3）没有更多蚂蚁经过路线上的信息素会不同程度地挥发掉，而有更多蚂蚁经过路线上的信息素会增强，再出动下一批蚂蚁重复上述过程，直到满足终止条件，找到从原点到目标节点的最近路径。

# 2.3.2 蚁群算法的特点及应用场景

与其他优化算法相比，蚁群算法具有以下几个特点：

+   （1）采用正反馈机制，使得搜索过程不断收敛，最终逼近最优解。\n（2）每个个体可以通过释放信息素来改变周围的环境，且每个个体能够感知周围环境的实时变化，个体间通过环境进行间接的通信。\n（3）搜索过程采用分布式计算方式，多个个体同时进行并行计算，大大提高了算法的计算能力和运行效率。\n（4）启发式的概率搜索方式不容易陷入局部最优，易于寻找到全局最优解。

自从蚁群算法在一些经典的组合规划问题（如 TSP 和二次分配问题（quadratic assignment problem, QAP）等）NP 的组合优化问题上取得成功以来，目前已陆续渗透到许多新的实际工程领域：

+   （1）蚁群算法在工程和工业生产中的应用，如采用蚁群算法的思想来求解大规模集成电路综合布线问题。在布线过程中，各个引脚对“蚂蚁”的引力可根据引力函数来计算，各个线网智能体根据启发策略，像蚂蚁群一样在开关盒网格上爬行，所经之处便布上一条金属线，历经一个线网的所有引脚之后，线网便布通了。\n（2）蚁群算法在规划问题中的应用，如在机器人路径规划的应用。机器人作为一种智能体，在复杂工作环境下的路径规划问题、多机器人之间的协作策略问题，在很大程度上类似于蚂蚁觅食选路径以及蚂蚁群体中个体之间通过信息素形成协作。路径规划算法是实现机器人控制和导航的基础之一，实验证明蚁群算法解决该问题有很大的优越性。\n（3）蚁群算法在动态优化组合问题中的应用，包括在有向连接的网络路由和无向连接网络系统路由中的应用，还包括蚂蚁人工神经网络、车辆路线问题（vehicle routine problem, VRP）、图像处理和模式识别领域的应用等。
