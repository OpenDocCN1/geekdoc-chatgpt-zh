# 图 4.4 四种模型的预测风电功率值

准进行对比，即平均绝对误差、平均绝对误差百分比及均方根误差，具体数学表达式为

$$M_{AE}=\frac{1}{n}\sum_{t=1}^{n}|\hat{y}_t - y_t| \tag{4.19}$$ $$M_{APE}=\frac{1}{n}\sum_{t=1}^{n}\left|\frac{\hat{y}_t - y_t}{y_t}\right|\times100\% \tag{4.20}$$ $$R_{MSE}=\sqrt{\frac{1}{n}\sum_{t=1}^{n}(\hat{y}_t - y_t)^2} \tag{4.21}$$

式中，n 为预测样本的数目；\hat{y}_t、y_t 分别为第 t 个样本所对应的风电功率预测值和真实值。

各种预测误差如表 4.1 所示。从表 4.1 中可以看出，无论是 M_AE、M_APE 还是 R_MSE 的预测误差，长短期记忆网络的预测误差都是最小的。此外，反向传播神经网络和 Elman 神经网络在训练过程中往往会陷入局部最优，而基于结构风险最小化思想的支持向量机训练，受到风电功率点与影响因素所构成的多维空间数据集的高维宽度影响，高维宽度过大则很难找到一个最佳的超平面去满足整体数据在多维空间中的分布，因此在实验中的效果并不是十分理想。由此可见，将长短期记忆网络引入风电功率预测的效果也是相当显著的。
