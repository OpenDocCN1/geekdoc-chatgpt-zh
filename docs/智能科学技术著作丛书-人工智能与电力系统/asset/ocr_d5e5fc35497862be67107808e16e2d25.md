# 2. P-CNN 结构

本节提出的 P-CNN 模型如图 5.10 所示。

该 P-CNN 模型具有两条支路，支路 1 为故障分类支路，主要任务是提取故障特征完成故障分类；支路 2 为故障定位支路，主要任务是判定故障发生在 MTDC 系统的具体位置。两条支路各有 5 个卷积层，每两个卷积层之间要经过批归一化、最大池化和 ReLU 激活函数（如图中箭头所示）。其中，第 3～5 层之后进行了 2 次 dropout 操作，以避免神经网络过拟合。

# 3. 基于迁移学习的 P-CNN 训练

P-CNN 的双支路结构可以让故障诊断过程更加有序和快速。两条支路分别提取 MTDC 故障分类特征和故障定位特征，并且依靠 P-CNN 的特殊性质同时进行计算，以提高故障诊断的快速性。因为 P-CNN 的两条支路故障特征提取的目的不同，所以神经网络的训练过程也分别进行[26]。
