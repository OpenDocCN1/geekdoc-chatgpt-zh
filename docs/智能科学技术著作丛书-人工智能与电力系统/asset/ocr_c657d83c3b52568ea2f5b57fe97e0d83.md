# 4.4 本章小结

本章主要介绍了人工智能技术在用电系统负荷及发电预测中的应用。4.1 节针对典型负荷特性提出了一种基于最小二乘支持向量机的海水淡化的负荷预测方法，借鉴了基于历史负荷数据及其影响因素的电力系统日负荷预测算法，确定了影响海水淡化负荷的若干特征量因素，通过灰色关联分析选取典型负荷相似日，从而建立最小二乘支持向量机模型的小样本输入数据集，并提出了基于粒子群优化改进的最小二乘支持向量机海水淡化负荷预测算法；4.2 节结合 Pearson 相关系数聚类与工业用户负荷曲线提出了一种基于 Pearson 相关系数的工业用户形态聚类算法，在聚类分析过程中同时考虑了重负荷企业在总体负荷中占比较大，以及弱相关性轻负荷企业会破坏分类后负荷曲线特性的影响，与传统聚类算法进行比较的结果表明，该算法鲁棒性强，结果有较好的聚类有效性。上述应用对于人工智能技术在负荷及发电预测中的应用具有重要的理论参考意义和工程应用价值。
