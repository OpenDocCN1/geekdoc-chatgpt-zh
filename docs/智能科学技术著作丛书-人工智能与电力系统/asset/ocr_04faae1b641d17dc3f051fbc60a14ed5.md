# 3. 采样时间变化窗口

对于低频采样的负荷辨识，采样时间的长短决定了负荷辨识的准确率和精度，采样时间越短，负荷辨识精度越高，但随着算法的时间复杂度增加，负荷辨识计算时间会增加，不利于居民即时负荷监测。为此这里讨论采样时间为 1s、5s、10s、1min、15min、30min、1h 对负荷辨识结果的影响，结果如图 5.5 所示。

实验结果表明，随着采样时间的增加，负荷辨识的准确率和辨识精度均在逐渐下降，而电量误差均值在逐渐增加。同时，当采样时间大于或等于 15min 时，辨识的准确率低于 70%，不满足辨识要求，而当采样时间为 1s 时，辨识时间复杂度较大，计算时间较长，综合考虑 10s 为基于多特征序列融合算法的最佳采样时间。
