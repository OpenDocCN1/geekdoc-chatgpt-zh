## 4.2 基于 PSO-LSVM 的海水淡化系统负荷预测

随着全球人口的增长以及气候的不断变化，全球淡水资源严重短缺，这已成为制约经济社会发展的瓶颈之一。作为解决淡水资源紧缺的可选方法，海水淡化在解决全球缺水问题上发挥着越来越重要的作用，尤其是沿海缺水地区和海岛对海水淡化的需求十分迫切。早在“十二五”期间，我国就将海水淡化作为战略性新兴产业进行重点培育发展。当前海水淡化系统整个过程耗电量巨大且设备成本较高，因此市场化利用率较低。但是，海水淡化负荷具有可调控性，如果将其与分布式可再生能源或电网结合，通过零边际成本的可再生能源提供电能，可有效降低海水淡化的成本[20]。

本节针对海水淡化典型负荷特性提出一种基于最小二乘支持向量机 (least squares support vector machine, LSSVM) 的海水淡化负荷预测方法，借鉴了基于历史负荷数据及其影响因素的电力系统日负荷预测算法，其是一种计及多维海水淡化负荷特性、环境特性和用水需求特征量的海水淡化负荷预测方法。基于粒子群优化算法优化最小二乘支持向量机模型预测模型的 γ 和 σ² 参数，可提高模型在小样本条件下的预测精度，确定影响海水淡化负荷的若干特征量因素，通过灰色关联分析 (grey relational analysis, GRA) 选取典型负荷相似日，从而建立最小二乘支持向量机模型的小样本输入数据集；并且提出基于粒子群优化算法改进的最小二乘支持向量机 (PSO-LSSVM) 模型海水淡化负荷预测算法。

### 1. 特征量分析

目前，海水淡化技术主要应用在生活海岛、旅游海岛、渔业、军事海岛、沿海工业园区、沿海居民区以及沿海商业区等多种场景中。不同场景中海水淡化负荷的特征量主要为用户用水需求及温度等。例如，生活海岛中海水淡化负荷与岛上居民的生活习惯、温度条件息息相关，而旅游海岛中的海水淡化负荷与岛上气候条件、旅游季节有关。因此，本节着重分析温度、用户用水需求对海水淡化负荷的影响。

以温度的归一化值，日用水量的映射值，海水淡化装置给水泵、高压泵和升压泵的时序用电功率序列对给水泵海水流速数据序列的映射值，海水淡化装置回水泵的时序用电功率序列对淡水回水流速数据序列的映射值以及海水淡化装置的高浓度盐水流速数据对淡水回水流速数据的映射值为特征量选取相似日。特征量综合反映了海水淡化负荷对环境温度、日用水量需求、海水用量、淡水产量、用电功率和海水淡化效率等方面的指标性能，温度的归一化处理公式如下：

式中，$i=1,2,\cdots,n$，$n$为历史日期天数；$T_i$为第$i$日的温度；$T_{\min}$为历史日期最低温度；$T_{\max}$为历史日期最高温度。

### 2. 基于灰色关联分析的相似日选取方法

基于支持向量机的海水淡化负荷预测模型需要应用数据样本对模型进行训练。信息冗余的训练样本不仅增加了训练时间，还降低了海水淡化负荷预测的精度，不利于模型使用。此问题可通过相似日选取方法加以解决。早期相似日的选取方法人工经验法，现有常用的方法主要有聚类分析法、证据理论法、趋势相似度法、灰色关联分析法等。本节采用灰色关联分析法进行相似日的选取。

将海水淡化负荷特征量数据分为历史数据和待预测数据。计算历史日 n 天的特征量序列 X_m = (x_m(1), x_m(2), …, x_m(t)) 与待预测日的特征量序列 X_0 = (x_0(1), x_0(2), …, x_0(t)) 之间的关联度。其中，m = 1,2,⋯,n；t 是海水淡化负荷特征量的个数。

首先求历史日特征量序列与待预测日特征量序列的差序列 Δ = [Δ_m0, …, Δ_m0, …, Δ_n0]，其中 Δ_m0 = (|x_m(1)−x_0(1)|, …, |x_m(t)−x_0(t)|)，再求取两级序列的最大差和最小差，即

Δ_max = max_n max_t (Δ)
Δ_min = min_n min_t (Δ)  (4.23)

最后计算 X_0 对 X_m 的灰色关联度如下：

γ(X_0, X_m) = (1/t) Σ_{k=1}^t [Δ_min + ρ Δ_max] / [Δ_m0(k) + ρ Δ_max]  (4.24)

式中，Δ_m0(k) = |x_m(k)−x_0(k)|；ρ 为分辨率系数，取 0.5。

### 3. 最小二乘支持向量机模型

最小二乘支持向量机模型基于支持向量机理论，将优化中的不等式约束转化为等式约束，因此二次规划问题变成了线性方程组的求解问题，减少了计算量，提高了解决速度。给定一组数据点集 {(x_i, y_i)}_{i=1}^l，其中，x_i 是输入向量，包括日用水量映射值，温度，海水淡化装置给水泵、高压泵和升压泵的时序用电功率序列对给水泵海水流速数据序列的映射值，海水淡化装置回水泵的时序用电功率序列对淡水回水流速数据序列的映射值，海水淡化装置的高浓度盐水流速数据对淡水回水流速数据的映射值和相似日海水淡化负荷时序用电功率向量；y_i 是输出向量；l 为样本点数。

海水淡化负荷是非线性电动机负荷，其一般预测模型为

f(x) = (W, φ(x)) + b  (4.25)

式中，W为可调权重向量；b为偏置，是超平面相对原点的偏移。

根据统计理论，最小二乘支持向量机通过对如下目标数极小化确定回归函数，即

$$J = \frac{1}{2}||W||^2 + \frac{1}{2}\gamma\sum_{i=1}^{l}e_i^2$$  
 s.t. $W^T\varphi(x_i)+b+e_i = y_i$  
 $i=1,2,\cdots,l$  
 (4.26)

式中，γ为正则化参数；e_i为误差，受正则化参数限制。

式(4.26)引入拉格朗日乘子，可得

$$\min J = \frac{1}{2}||W||^2 + \frac{1}{2}\gamma\sum_{i=1}^{l}e_i^2 - \sum_{i=1}^{l}\lambda_i\left(W^T\varphi(x_i)+b+e_i-y_i\right)$$  
 (4.27)

对式(4.27)各变量取偏导数为零，得

$$\begin{cases}\frac{\partial J}{\partial W}=0 \rightarrow W = \sum_{i=1}^{l}\lambda_i\varphi(x_i)\\\frac{\partial J}{\partial b}=0 \rightarrow \sum_{i=1}^{l}\lambda_i =0\\\frac{\partial J}{\partial e_i}=0 \rightarrow \lambda_i = \gamma e_i,\ i=1,2,\cdots,l\\\frac{\partial J}{\partial \lambda_i}=0 \rightarrow W^T\varphi(x_i)+b+e_i-y_i=0,\ i=1,2,\cdots,l\end{cases}$$  
 (4.28)

消去W和e后，最小二乘支持向量机的极小化问题变成一个线性优化问题，求解式(4.28)可得λ_i和b。因此，海水淡化负荷的线性预测模型如下：

$$y = \sum_{i=1}^{l}\lambda_i K(x_i,x)+b$$  
 (4.29)

式中，K(x_i,x)=φ^T(x_i)φ(x)为核函数。

选用常用的径向基函数(radial basis function，RBF)计算。核函数的等式为

$$K(x_i,x)=\exp\left\{\frac{-||x_i - x||^2}{2\sigma^2}\right\}$$  
 (4.30)

式中，σ²为径向基函数内核调整参数，表示径向基函数内核宽度。

### 4. PSO-LSSVM 预测过程

采用粒子群优化算法优化最小二乘支持向量机的参数γ和σ²。粒子群优化算法是一种非常简单的算法，可以有效地优化各种功能，具有易于实现和快速收敛等优点。

预测过程首先对海水淡化的特征量数据进行处理；其次，采用灰色关联分析方法从 90 天中选取关联度最大的 30 天作为待预测日的相似日，相似日的负荷数据和特征量数据共同构成了最小二乘支持向量机模型的训练样本和测试样本，并输入到模型中；再次，基于粒子群优化算法优化模型参数γ和σ²；最后，利用最小二乘支持向量机模型进行海水淡化负荷的预测。PSO-LSSVM 预测流程如图 4.12 所示。

## 4.3 基于形态聚类的 LightGBM 的工业用户负荷预测

电能不可大量存储，电能的发、变、输、配、用同时进行，因此在电力系统正常运行中，合理的负荷预测是发输配电与合理配置资源的重要保障。近年来，有许多应用于工业用户负荷的预测理论和方法。例如，时间序列法经过多年的改进和实践，目前已相对成熟，其原理简单、实现方便、预测效率高，但由于考虑影响特征较少，所以预测精度较低。灰色预测法所需负荷数据较少，并且无须计算相关特征，可应用于任意非线性变化的负荷预测任务，具有方便快速的特点，但是存在没有考虑其他影响因素的缺陷，尤其是在负荷变化规律不具有指数性，且数据离散程度较大时，其预测结果精度会很低。人工神经网络具有较强的鲁棒性、自适应性、较好的信息综合能力和容错能力，但缺点也比较明显，神经网络算法中的权重是沿局部改善方向逐渐改善的，训练时间长且易使算法陷入局部最优。

传统负荷预测的研究工作大多集中于所使用的预测算法上，而预测过程所使用的特征通常是根据经验或试错得到的，限制了模型最终预测结果精度的提升。传统预测方法采用的学习模型计算效率较低，难以满足日益繁杂的负荷数据处理与日益迅速的实时控制需求。因此，本节采用预测精度佳、计算效率高的基于形态聚类的 LightGBM 的工业用户中期负荷预测的方法。

### 4.3.1 工业用户负荷形态聚类算法

本节结合 Pearson 相关系数聚类与工业用户负荷曲线提出一种基于 Pearson 相关系数的工业用户形态聚类 (industrial user morphological clustering, IUMC) 算法。聚类分析过程同时考虑了重负荷企业在总体负荷中占比比较大，以及弱相关性轻负荷企业会破坏分类后负荷曲线特性的影响，与传统聚类算法进行比较的结果表明，该算法鲁棒性强，结果有较好的聚类有效性。

工业用户形态聚类算法具体步骤如下。

- (1) 数据预处理。
  - ① 对存在大量缺失值的数据进行处理，剔除明显为不良数据的样本。
  - 采集数据的过程中因设备或人为的失误会导致数据文件存在缺失值的问题，本方法将缺失值数量大于用户数据总长度十分之一的用户数据标识为坏数据，在执行下一步操作前将此类用户数据剔除。
  - ② 其余缺失值数据利用相邻日插值进行填充处理。
  - 设用户数据为 X = (x₁, x₂, …, xᵢ₋₁, xᵢ₊₁, …, xₙ)，缺失值为 xᵢ，则填充公式如下：
  - xᵢ = (xᵢ₋₁ + xᵢ₊₁) / 2  (4.32)
  - ③ 利用箱形图分析法识别异常值。
  - 按时间顺序以 35 天（5 周）为时间窗口遍历用户数据（节假日负荷数据一般偏低较多，故不作处理），将窗口内数据从大到小排列，取排列后第 9 位数据作为该窗口上值，记为 du；取排列后第 27 位数据作为该窗口下值，记为 dl；上值与下值的差为上下差值，记为 dul，公式如下：
  - dul = du − dl  (4.33)
  - 将 du 与 1.5 倍的 dul 相加作为该窗口的上界，记为 dum，计算公式如下：
  - dum = du + 1.5 dul  (4.34)
  - 将 dl 与 1.5 倍的 dul 相减作为该窗口的下界，记为 dlm，计算公式如下：
  - dlm = dl − 1.5 dul  (4.35)
  - 将该窗口内的负荷数据与该窗口上界（dum）和该窗口下界（dlm）进行比较，若负荷数据大于上界或小于下界，则将该数据识别为异常值。
  - ④ 异常值替换。
  - 将识别为异常值的数据用相邻日负荷插值进行替换，替换公式同式（4.32）。
- (2) 识别并分离重负荷企业。
  - 将单一企业日均负荷大于所有企业整体日均负荷 100 倍的企业识别为重负荷企业，将重负荷企业数据分离以便后续单独处理，剩余企业识别为轻负荷企业另做处理。
- (3) 合并弱相关性轻负荷企业。
  - 计算轻负荷企业负荷数据间的 Pearson 相关系数，设用户间弱相关性的阈值为 δ₁，用户中与其他所有用户的 Pearson 相关系数最大值小于 δ₁ 的用户被识别为弱相关性轻负荷企业，将弱相关性轻负荷企业按日相加，作为一个新的用户便于后续进行特殊处理。
- (4) 确定初始聚类中心。
  - ① 计算去除重负荷企业、弱相关性轻负荷企业后样本数据的相关系数矩阵，并记作 Q。从 Q 中选取相关系数最大值所对应的两个企业为第一类，并筛选与第一类两个企业相关系数均大于 0.9 的企业加入第一类，计算第一类企业的负荷均值，并将负荷均值作为该类的初始聚类中心。
  - ② 删除 Q 中已分类的企业所对应的相关系数，再从剩余的系数矩阵中选取最大值所对应的两个企业作为新一类，筛选与新一类两个企业相关系数均大于 0.9 的企业，并加入新一类，计算新一类企业的负荷均值，并将负荷均值作为该类初始聚类中心。
  - ③ 循环②直至类数达到设定的 K_max，然后将分离出的每个重负荷企业、弱相关性轻负荷企业
