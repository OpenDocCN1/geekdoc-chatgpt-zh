# 2. 基于故障信号的幅值、频率特征提取

当 MTDC 系统发生故障时，电气量波形的幅值变化能比较明显地区分出各个故障，然而实际系统故障距离的变化不能明显地反映在幅值上，使得仅仅依靠幅值变化不能可靠地区分故障的类别和位置。所以本节引入频率分析的小波包分析方法对数据进行预处理，同时给神经网络输入幅值特征和频率特征，全面捕捉故障特征。

# 1) 幅值特征提取

故障时，电流和电压会产生波动，最终稳定到新值，若稳定的新值与正常运行时的稳定值不同，则称电气量发生了变化，反之则无变化。通过观测电气量幅值是否发生变化和变化情况，可以分辨故障类型。故障的幅值特征在于确定电气量幅值变化信息，即确定故障波形与正常波形的不同之处。所以，本节在引用信号波形进行 MTDC 线路故障诊断时，需要采用如式 (5.28) 所示的方法，即把故障信号波形和正常信号波形首尾相连排列成新信号。如此，实现了新信号波形前后幅值变化特征的提取。

```
x(i) = [x_{T-1}, x_{T-1+Δt}, x_{T-1+2Δt}, ..., x_{T-1+mΔt}, x_T, x_{T+Δt}, x_{T+2Δt}, ..., x_{T+mΔt}]  (5.28)
```

式中，x(i) 为合成后的数据；T 为发生故障的时刻；Δt 为采样点时间间隔，Δt = 10^{-4} s；m 为采样点的个数。
