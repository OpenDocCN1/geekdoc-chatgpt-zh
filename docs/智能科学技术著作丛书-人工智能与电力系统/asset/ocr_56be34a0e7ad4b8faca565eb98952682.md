# 2. 模拟退火算法的基本模型

模拟退火算法求解流程如图 2.11 所示，具体步骤如下。

+   (1) 初始化粒子的位置和速度。
+   (2) 计算每个粒子的目标函数值。
+   (3) 更新粒子的 pbest 和 gbest。
+   (4) 重复执行下列步骤：
+   ① 对粒子的 pbest 进行模拟退火邻域搜索。
+   ② 更新各粒子的 pbest。
+   ③ 执行最优选择操作，更新种群 gbest。
+   ④ gbest 满足算法终止条件，转到步骤⑤，否则转到步骤(3)。
