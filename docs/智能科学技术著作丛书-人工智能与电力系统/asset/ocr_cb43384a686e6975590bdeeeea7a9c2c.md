# 2. 基于机组类型的抗体片段变异

变异是免疫算法的主要算子，合适的变异率直接影响到算法的效率和精度。在电力系统的运行中，不同的机组往往承担的负荷种类也不同。根据运行经验，启停费用高、机组容量大、煤耗量小的常规机组通常承担基本负荷，如核电机组和高温高压火电机组；而启停费用低、机组容量小、煤耗量大的机组通常担任调峰任务，如小型燃气机组和抽水蓄能机组等。考虑以上工程因素，在免疫算法的变异过程中，本节对参数相同的机组和属于同一类型的运行机组采用了相同的变异率。对承担基本负荷的稳定机组，设置小的变异率；对充当调峰作用的灵活机组，设置相对较大的变异率，使其具有相对较大的搜索空间，从而提高寻优速度。图 6.42 为考虑集合的抗体片段、抗体和抗体片段记忆库。
