从表 5.2 可以明显看出，多个负荷同时运行，识别准确率和识别精度可以达到 80%以上。当所有负荷同时运行时，准确率为 79%，识别精度为 85%。但是，根据对 100 户家庭的用电量调查，发现同时打开 7 个负荷的居民用户的概率低于 3%。因此，所提出的方法可以在实际条件下识别多负荷情况。

# 3. 实际应用

为了使所提出的方法能够付诸实践，使用非侵入式负荷监测设备。所提出的设备包括用于控制和计算的主板、通用无线分组业务 (general packet radio service, GPRS) 通信模块、用于高速采样和模拟的数据采集-数字转换模块以及用于深度计算的英特尔 Movidius 神经计算棒。英特尔 Movidius 神经计算棒与 Windows 操作系统兼容，并且能够运行 Python 3.5 编写的拟议算法，用于边缘计算以保证实时结果。目前，本节提出的非侵入式负荷监测装置和非侵入式负荷监测算法已尝试应用到国家电网葫芦岛供电公司塔山电厂的实际试点项目中。监视对象包括办公室、营业厅、餐厅和全电厨房。家用电器包括计算机、饮水机、电视机、灯具、空调、电饭锅、热水器、热水壶、冰箱、微波炉和消毒柜。截至目前，该试点项目仍处于初期阶段，未来将关注从该项目中识别住宅设备的实现。
