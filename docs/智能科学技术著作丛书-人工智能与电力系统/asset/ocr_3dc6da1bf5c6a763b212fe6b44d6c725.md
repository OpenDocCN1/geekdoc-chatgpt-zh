# 4.1.4 仿真与验证

以美国国家可再生能源实验室提供的华盛顿地区风电历史数据为例，该套数据采集了 2012 年 12 个月的完整数据，数据点的时间间隔为 5min，其中包含了风速、风向、大气密度、气温、湿度和风电功率值，经过去除异常样本后，数据集的样本数为 105019。按照前述 8:2 的比例，将数据集划分为训练数据集和备用数据集，备用数据集中测试数据集的样本数 M 取 150，其余的则用作误差生成数据。仿真实验平台所用处理器为 Intel Core i5-7300HQ、8GB 运行内存，基于 Windows 系统的 Python 编译环境，搭建了 Keras 框架下的长短期记忆网络预测模型[19]。
