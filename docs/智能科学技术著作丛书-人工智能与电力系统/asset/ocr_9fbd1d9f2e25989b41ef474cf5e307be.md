# 5.3 基于模拟退火算法的高压输电线路故障定位

高压输电线路发生故障，会造成重大的经济损失并严重影响工业生产及居民生活。因此，需要帮助抢修人员及时确定故障位置，减少输电线路故障造成的停电损失与影响。最初的线路故障定位方法是由美国学者 Allen 和 Gross 于 20 世纪初提出的，随着技术的不断改进，利用故障行波判断故障点的技术被提出。目前应用最广泛的是基于行波法的双端不同时测距技术。该方法的实质是通过搭建故障模型建立测距方程组，其核心是对方程组的求解。传统牛顿法存在求解速度慢且对初始值选取要求高的缺点，因此在人工智能算法充分发展的今天，利用模拟退火法求取初步解作为牛顿法的初始值，再利用牛顿法获得最终解，在提高运算准确率的同时能有效降低智能算法较大的计算量问题[24]。
