# 3) 全连接层

在多个卷积层和池化层之后通常会连接一个或者多个全连接层。在卷积神经网络中，全连接层起到“分类器”的作用。其作用是将从卷积层和池化层的“分布式特征表示”映射到样本标记空间。全连接层可以整合卷积层和池化层中具有类别区分性的局部信息。

在全连接层中每个神经元的激励函数通常采用 ReLU 函数。在其最后一层的输出的分类方式一般会采用 softmax 逻辑回归，因此也可称该层为 softmax 层。但全连接层由于其参数量过大，降低了训练的速度，且很容易出现过拟合等缺点，现在很多卷积神经网络废弃了全连接层。
