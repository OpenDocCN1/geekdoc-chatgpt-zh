相同时间段的从大电网购买电能时的污染物和温室效应气体排放量进行比较，选择污染物和温室效应气体排放量较小的电源进行出力，并为负载提供电能。

(3) 当储能电池中储存的电能小于允许值时，需要对储能电池进行充电，依据 (2) 中的方式确定电源的出力顺序，即首先由污染物和温室效应气体排放量较小的电源为储能电池进行充电。

此外，当清洁型发电单元的出力不能满足负载电能需求时，若某时段内 DE 出力值小于出力上限，则保证了负载的电能供应，此时 DE 不会发出额外的电能，以保证 EP 最大化，这是与经济性最大化能量控制策略的差别之处[32]。

# 6.1.2 优化配置模型的算法

选取 APSO 对所构建的优化模型进行求解，APSO 的模型如下：

v_{id}^{k+1} = w v_{id}^{k} + c_1 r_1 (p_{id}^{k} - x_{id}^{k}) + c_2 r_2 (p_{gd}^{k} - x_{gd}^{k})  (6.22)

x_{id}^{k+1} = round(x_{id}^{k} + v_{id}^{k})  (6.23)

w = w_{min} + (w_{max} - w_{min}) (f - f_{min}) / (f_{avg} - f_{min})  (6.24)

式中，v_{id}^{k+1} 为第 i 个粒子在第 k+1 次迭代中的速度；w 为惯性权重；c₁、c₂ 为学习因子；r₁、r₂ 为[0,1]内的随机数；round(x_{id}^{k}+v_{id}^{k}) 为对第 i 个粒子在第 k 次迭代中的位置取整数；w_{max}、w_{min} 分别为惯性权重的最大值、最小值；f 为粒子在本次迭代中的目标函数值；f_{avg}、f_{min} 分别为本次迭代中所有粒子的平均目标函数值及最小函数值。
