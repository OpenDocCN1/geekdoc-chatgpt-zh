
(3)反馈神经网络：反馈神经网络是一种将输出经过一步时移再接入输入层的神经网络系统，如图 3.11 所示。在这种网络中，每个神经元同时将自身的输出信号作为输入信号反馈给其他神经元，它需要工作一段时间才能达到稳定。

## 3.3.2 卷积神经网络

卷积神经网络是一类包含卷积计算且具有深度结构的前馈神经网络，是深度学习的代表算法之一。卷积神经网络具有表征学习的能力，能够按其阶层结构对输入信息进行平移不变分类。

### 1. 卷积神经网络的理论基础

卷积神经网络由三个部分组成，分别是卷积层、池化层和全连接层，原始图像从输入端输入后经过卷积层和池化层处理后到达全连接层最后得以输出，下面是对这一过程的分步介绍。

1) 卷积层

卷积层的目的是从输入图像中提取重要的特征，卷积核是卷积层中的重要部分，在数据处理的过程中起到了扫描仪的作用，输入的数据通过卷积核的多次扫描后图像中的重要特征就被提取出来了。

假设有一幅像素为 32×32×3 的图像，这里的 32×32 表示图像的长度和宽度都为 32，而 3 表示该图像具有 3 个色彩通道，通常情况下为红色(R)、绿色(G)、蓝色(B)。将卷积核定义为一个像素为 3×3×3 的区域，与之前所述类似，前面的两个 3 表示该区域的长度和宽度都为 3，最后一个 3 表示具有 3 个色彩通道，
分别为 R、G、B。在这里将卷积过程简化，用一个像素为 5×5×1 的单通道的图像进行卷积操作，其过程如图 3.12 所示。

![](img/2160aa82ffab89ad09fb1b4e167a298b_73_0.png)

图 3.12 卷积过程

一般会用一个正方形的卷积核扫描图像上的每一个像素点，图像区域内相对应的每一个像素值乘以卷积核内相对应点的权重求和再加上偏置值。卷积层的计算公式为

$X_j^l = f\left(\sum_{i\in M_j} X_i^{l-1} * K_{ij}^l + b_j^l\right)\quad(3.32)$

式中，$X_j^l$ 为第 $l$ 层的第 $j$ 个值；$K_{ij}^l$ 为卷积核函数；$*$ 为一维卷积运算；$b_j^l$ 为偏置参数；$M_j$ 为选择输入特征值集合，可以从这个集合中选取某个组合作为输出特征图；$f(\cdot)$ 为激励函数。

卷积核每滑动一次会计算得到输出图像中的一个值，从输入图像的左上角开始滑动到输入图像的右下角结束，输出图像边长的计算公式为

输出图像边长 = $\frac{\text{输入图像边长} - \text{卷积核边长} + 1}{\text{步长}}$\quad(3.33)

为了保证输出图像的尺寸与输入图像的尺寸一致，通常会将输入图像的外围进行全零填充 (padding)，这样做是为了使卷积核能够扫描到输入图像的全部像素，其过程如图 3.13 所示。

![](img/2160aa82ffab89ad09fb1b4e167a298b_73_1.png)

图 3.13 全零填充卷积过程

padding { same 输入图像边长 / 步长 ; valid (输入图像边长 - 卷积核边长 + 1) / 步长 }, 向上取整 (3.34)

式中，same 表示全零填充；valid 表示不使用全零填充。

当色彩通道为 3 时，卷积过程如图 3.14 所示。

![](img/2160aa82ffab89ad09fb1b4e167a298b_74_0.png)

图 3.14 三通道卷积过程

三通道卷积计算方法与单通道相似，每个通道的输入图像都匹配一个对应的卷积核，把三层卷积核套在三个对应颜色的图像上，重合的 27 个像素点进行加权求和运算，得到的数据加上偏移值 b，最终得到的就是输出图像中的数据。

2) 池化层

通常状况下输入图像中含有大量的像素点，所以通过卷积进行特征提取所得到的数据的数量仍然很庞大，池化层通过去掉特征图像中不重要的样本可以有效地缩小特征图像的尺寸。一般使用的池化方法有两种，分别为最大池化和均值池化。最大池化可以对图像的纹理进行很好的提取，均值池化则对原始图像的背景特征进行保留。

与卷积层类似，池化的过程中也需要一个 2×2 的池化核来提取原特征图像的特征，但与卷积核不同的是，这个 2×2 的池化核并没有参数能够与输入图像进行
卷积计算，如果用 2×2 的池化核对输入图像进行以 2 为步长的池化，则输出图像的大小就变成原来图像的四分之一。最大池化就是每个 2×2 部分最大的数作为该部分的输出结果，如图 3.15 (a) 所示。均值池化与最大池化相似，将每个部分的平均数作为该部分的输出结果，如图 3.15 (b) 所示。

(b) 均值池化过程

3) 全连接层

在多个卷积层和池化层之后通常会连接一个或者多个全连接层。在卷积神经网络中，全连接层起到“分类器”的作用。其作用是将从卷积层和池化层的“分布式特征表示”映射到样本标记空间。全连接层可以整合卷积层和池化层中具有类别区分性的局部信息。

在全连接层中每个神经元的激励函数通常采用 ReLU 函数。在其最后一层的输出的分类方式一般会采用 softmax 逻辑回归，因此也可称该层为 softmax 层。但全连接层由于其参数量过大，降低了训练的速度，且很容易出现过拟合等缺点，现在很多卷积神经网络废弃了全连接层。

### 2. 卷积神经网络在电力系统中的应用场景

- 1) 应用卷积神经网络的电力系统短期负荷预测

短期负荷变化可认为是一个平稳随机过程，长期负荷预测与国家或地区的政治、经济政策等因素密切相关，通常会有一些大的波动，而并非一个平稳随机过程，
同时电力负荷变化受天气情况和人类社会活动等诸多因素的影响，存在大量非线性关系，卷积神经网络适用于解决此类非线性问题，并具有预测精度高、避免过拟合现象等特点，因此卷积神经网络应用于短期负荷预测要比中长期负荷预测更为适宜[12]。

- 2) 应用卷积神经网络的电力设备识别

电力设备的正常运行是一个电力系统能够长期安全稳定工作的基础，因此对电力设备进行定期巡检就显得十分重要。以往的巡检方法都存在着不同的缺点，造成人力、物力上的浪费且效果也有待提升。近年来随着人工智能技术以及图像处理等技术的逐渐发展与成熟，将卷积神经网络应用于电力设备运行状态的检测中，通过对数据集进行训练测试，很好地弥补了传统方法的不足，可自动对电力设备的位置进行检测，对指针式仪表进行自动读数，以及对其运行状态进行判别。

- 3) 应用卷积神经网络的电力系统小干扰稳定评估

随着电力系统规模的增大，通过传统数值方法计算系统特征值来进行小干扰稳定评估已无法满足实时分析的要求，当前有学者提出一种基于深度学习卷积神经网络的电力系统小干扰稳定评估方法，以广域测量系统可监测变量作为模型的输入，关键特征值为输出，对输入数据和输出数据进行相应处理后，利用深层架构对其映射关系进行分析，针对大系统维数较高、训练速度较慢的问题采用了离散余弦变换和图形处理器并行技术，在不考虑控制参数变化的情况下经过历史数据的离线训练后，能够较准确地计算出系统的关键特征值。

## 3.3.3 循环神经网络

循环神经网络 (recurrent neural network, RNN) 是一类以序列数据为输入、在序列的演进方向进行递归且所有节点 (循环单元) 按链式连接的递归神经网络。对循环神经网络的研究始于 20 世纪，并在 21 世纪初发展为深度学习算法之一。

循环神经网络具有记忆性、参数共享和图灵完备的特点，因此在对序列的非线性特征进行学习时具有一定优势。循环神经网络在机器翻译、语音识别等领域有着广泛的应用，在电力系统中，循环神经网络常常应用于电力系统的负荷预测。

### 1. 循环神经网络的理论基础

标准循环神经网络和长短期记忆网络 (long short-term memory network, LSTM) 是常见的循环神经网络，下面对这两种网络进行详细介绍。

1) 标准循环神经网络

相比传统的神经网络，标准循环神经网络的结构要更加复杂一些，为了增加时间序列的相关性，标准循环神经网络在隐含层增加了循环单元，如图 3.16 所示。

![](img/2160aa82ffab89ad09fb1b4e167a298b_77_0.png)

图 3.16 标准循环神经网络

根据图 3.16 的标准循环神经网络可得如下公式：

$h_t = f(W_{xh}x_t + h_{t-1})$  (3.35)

$y_t = g(W_{hy}h_t)$  (3.36)

式中，$x_t$ 为 $t$ 时刻的输入向量；$y_t$ 为 $t$ 时刻的输出向量；$h_{t-1}$ 为 $t-1$ 时刻的状态向量；$W_{xh}$ 为输入层到隐含层的权重矩阵；$W_{hy}$ 为隐含层到输出层的权重矩阵；$f(\cdot)$ 为隐含层的激励函数；$g(\cdot)$ 为输出层的激励函数。

对于神经网络，不同的激励函数会影响模型的性能。隐含层常用的激励函数有 sigmoid、tanh 和修正线性单元。输出层常用的输出函数主要为 linear 和 softmax，公式如下：

linear$(x) = a x$, $a \neq 0$  (3.37)

softmax$(x_i) = \frac{e^{x_i}}{\sum_{k=1}^{K} e^{x_k}}$  (3.38)

式中，$x_i$ 为 $x$ 的第 $i$ 个分量，$i$ 与 $k$ 的取值范围是 $\{1,2,\cdots,K\}$，$K$ 为输出神经元的个数。

2) 长短期记忆网络

长短期记忆网络于 1997 年由 Hochreiter 和 Schmidhuber 提出，是循环神经网络的一种，但长短期记忆网络的隐含层比循环神经网络的更加复杂。由于传统的循环神经网络的每个隐含单元内只是一个简单的 tanh 或 ReLU 的操作，在对参数的学习过程中容易出现梯度消失或梯度爆炸的问题，会影响其长期时间序列的相关性能力，为了克服传统循环神经网络的这一缺陷，经过长时间的研究，引入了长短期记忆网络。当不再需要时间较为久远的信息时，长短期记忆单元可以让网络忘记旧的单元状态，然后将新的数据流入下一单元进行状态更新，通过调节权重使时间序列上的部分时间节点对当前的时间节点产生影响。这样可以提高循环神经网络对较长时间延迟的灵敏度，进而可以捕获任意时间状态之间的相关信息[13]。

长短期记忆网络的神经元内部结构如图 3.17 所示。由图中可以看出，长短期记忆网络的输入有三个，分别为当前网络的输入值 x_t、上一时刻的输出值 h_{t-1} 和上一时刻的单元状态 C_{t-1}。而长短期记忆网络的输出有两个，即当前时刻的输出值 h_t 和当前时刻的状态 C_t。

![](img/2160aa82ffab89ad09fb1b4e167a298b_78_0.png)

图 3.17 长短期记忆网络的神经元内部结构

长短期记忆网络引入了三个门结构对单元状态进行控制，分别是遗忘门、输入门和输出门。门的作用就是让信息有选择性地通过，来删除或者增加信息到单元状态，下面对长短期记忆网络的结构进行详细的介绍。

长短期记忆网络的门结构可以表示如下：

g(x)=σ(Wx+b)  (3.39)

式中，W 为门的权重矩阵；b 为偏置；σ 为 sigmoid 函数，其输出为 0～1 的一个概率值，用来描述有多少信息可以通过，输出为 0 表示信息无法通过，输出为 1 表示信息可以全部通过。

- (1) 遗忘门。

遗忘门用来判断是否将继续保持上一时刻细胞状态，这就意味着在传输的过程中需要决定在细胞状态中丢弃什么信息。把 h_{t-1} 和 x_t 拼接起来传给一个 sigmoid 函数将得到一个在 0～1 的值，这个值为遗忘因子，再将细胞状态值 C_{t-1} 与遗忘因子相乘，这一过程为遗忘门的数学原理。

遗忘门的公式为

$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$
(3.40)

式中，σ为 sigmoid 函数；W_f为遗忘门的权重矩阵；[h_{t-1}, x_t]为两个向量的连接；b_f为遗忘门偏置；h_{t-1}为前一时刻的输出值；x_t为当前时刻的输入值。

遗忘门的位置及结构如图 3.18 所示。

![](img/2160aa82ffab89ad09fb1b4e167a298b_79_0.png)

图 3.18 遗忘门的位置及结构

- (2)输入门。

输入门的作用是把即时状态输入为长期状态，它包括两个部分，分别为更新单元状态和生成新的单元状态。

更新单元状态是决定将什么样的新信息放入单元状态中，这一 部分由一个 sigmoid 层和一个 tanh 层构成。首先 sigmoid 层决定什么值需要更新，然后 tanh 层会创建一个新的候选值向量 C_t。在极端状态下 sigmoid 输出为零，单元状态不更新。

更新单元状态的公式为
$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$
(3.41)

式中，W_i为输入门的权重矩阵；b_i为输入门的偏置。

生成新的单元状态的公式为
$C'_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$
(3.42)

生成新的单元状态是将旧单元状态 C_{t-1} 更新为新的单元状态 C'_t，其过程是将 C_{t-1} 与 f_t 相乘，丢弃掉需要丢弃的那部分信息，然后加上需要更新的部分 i_t C'_t。这就是新的单元状态值，根据需要决定每个状态的更新程度。

更新单元状态的公式为
$C_t = f_t C_{t-1} + i_t C'_t$
(3.43)

输入门结构如图 3.19 所示。

![](img/2160aa82ffab89ad09fb1b4e167a298b_80_0.png)

图 3.19 输入门结构

- (3)输出门。

长短期记忆网络结构在计算得到新的状态产生当前时刻的输出过程是由输出门完成的。输出的值与单元状态有关。首先运行一个 sigmoid 层来确定输出的部分，然后将单元状态 $C_t$ 输送到 tanh 层，最后将两者相加得到最终的输出。

输出门的公式为

$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$  (3.44)

长短期记忆网络的最终输出为

$h_t = o_t \tanh(C_t)$  (3.45)

长短期记忆网络具有如下特点：

- ① 对序列的本机支持。长短期记忆网络将序列数据作为输入，之后观察必须作为网络的数据特征。
- ② 多变量输入。长短期记忆网络直接支持多变量输入的多个并行输入序列。
- ③ 矢量输出。与其他神经网络一样，长短期记忆网络能够将输入数据直接映射到可以表示多个输出时间步长的输出向量。

### 2. 循环神经网络在电力系统中的应用场景

1) 应用循环神经网络的电力系统负荷辨识

针对负荷模型难以精确建立的问题以及负荷非线性动态仿真的复杂性问题，有学者提出了基于径向基循环神经网络的负荷建模方法，将循环神经网络和径向基网络相结合，利用循环神经网络对时间序列的学习能力和径向基网络具有的结
构自适应确定快速收敛的优点建立新的电力系统综合负荷模型，将该模型应用于典型新英格兰测试系统，证明了该模型对电力系统负荷模型辨识的有效性和准确性。

2) 应用循环神经网络的电力系统短期负荷预测

以往的负荷预测技术，多采用前馈人工神经网络、支持向量机等进行短期的电力负荷预测，网络中没有记忆单元，缺少对时序数据时间相关性的考虑，长短期记忆网络可以学习时间序列长短期依赖信息，包含时间记忆单元，适用于处理和预测时间序列中的间隔和延迟事件。有学者在进行短期电力负荷预测时，考虑到时序数据的时间相关性，应用张量流深度学习框架构建了长短期记忆网络模型，对电力负荷时序数据进行回归预测，可使调度人员更好地了解未来负荷的变化波动，更有针对性地进行电力调度。

3) 应用循环神经网络的电力系统稳定性评估

随着电网规模的扩大，电力系统的稳定性愈加难以掌控。一方面，跨区域电网的互联可以合理利用整体资源，带来巨大的经济效益；但另一方面，电网结构的变化，呈现出更加复杂的非线性特性。

世界上已经发生的多次数电网故障表明，输电电压等级的提高、联网规模的扩大以及传输容量的增加，都会增大电网故障带来的危害，故障原因和过程也更为复杂。开展对运行电网的实时在线监测、分析和控制，是各国电力行业的迫切需求。传统的时域评估方法计算量大、耗时长，不适合电力系统在线稳定性评估。人工神经网络具有良好的处理复杂未知非线性系统的能力，能够很好地捕捉电力系统的动态特性，当前循环神经网络被广泛地用于非线性系统的处理，当电网结构发生变化时，电网稳定性的分析可有效提高精度与效率。

## 3.4 强化学习

强化学习又称再励学习、评价学习或增强学习，是机器学习领域的研究热点，目前强化学习应用较多的领域有对弈、决策和控制等，主要用来实现决策优化。3.4.1 节介绍强化学习的基本概念及主要研究方向，3.4.2 节和 3.4.3 节分别介绍马尔可夫算法和 Q 学习算法，并讨论各算法的实现方法。

### 3.4.1 强化学习的基本概念及主要研究方向

### 1. 强化学习的基本概念

强化学习从动物学习、参数扰动自适应控制等理论发展而来，是智能体以“试错”的方式进行学习，通过与环境进行交互获得的奖赏指导行为。强化学习的目标是动态地调整参数，以得到最大的强化信号。学习从环境状态到行为的映射，
使得智能体选择的行为能够获得环境最大的奖励，外部环境对学习系统在某种意义下的评价(或整个系统的运行性能)为最佳，其基本原理框图如图 3.20 所示。

图 3.20 强化学习基本原理框图

由强化学习基本原理图可知，强化学习把学习看作试探评价过程，智能体选择一个动作用于环境，环境接受该动作后状态发生变化，同时产生一个强化信号(奖或惩)反馈给智能体，智能体根据强化信号和环境当前状态再选择下一个动作，选择的原则是使受到正强化(奖)的概率增大。选择的动作不仅影响立即强化值，而且影响环境下一时刻的状态及最终的强化值。

强化学习不同于连接主义学习中的监督学习，其主要表现在强化信号上，强化学习中由环境提供的强化信号是对产生动作好坏的一种评价(通常为标量信号)，而不是告诉强化学习系统如何产生正确的动作。由于外部环境提供的信息很少，强化学习系统必须靠自身的经历进行学习。通过这种方式，强化学习系统在行动-评价的环境中获得知识，改进行动方案以适应环境。

### 2. 强化学习的主要研究方向

- 1) 深度强化学习

传统强化学习在模型较为简单的场景下取得了较好的效果，但现实中的问题往往都比较复杂，状态空间和动作空间的维数很高，此时传统的表格型强化学习不再适用。近年来，随着深度学习的兴起，深度学习与强化学习的结合研究也受到了很多关注。DeepMind 团队创新地将具有强大感知能力及表征能力的深度学习与具有决策能力的强化学习相结合，形成了人工智能领域新的研究热点。深度强化学习的原理框架如图 3.21 所示。
