# 4.1.3 误差数据库的生成及预测流程

风电功率的概率区间预测一般基于风电功率的预测误差，但是由于不同风电场采用的风电功率单点值预测方法及数据信息各不相同，采用自行给定的预测方法，从历史数据集中获取误差分布的方法是欠妥的。为此，本节为了生成合理的风电功率预测误差数据，基于长短期记忆网络模型，将风电场历史数据集按照 8:2 的比例划分为训练数据集和备用数据集，从备用数据集中预留出 M 个样本作为测试数据集，其他样本当作误差生成集，用来产生风电功率的预测误差数据库，具体的流程如图 4.2 所示。

由于风电功率及其影响因子的物理意义不同，数值上差异较大，因此为了加快模型训练，提高预测效果，对各类数据采取如下标准化处理，即

$$v' = \frac{v - v_{\min}}{v_{\max} - v_{\min}} \tag{4.16}$$

式中，v 和 v' 分别为某类数据的原始数值和标准化处理后的数值；v_max 和 v_min 分别为该类数据原始值中的最大值和最小值。

风电功率的单点值预测及概率区间预测流程如图 4.3 所示。

针对一组风电历史数据集，样本数据被划分为训练数据集和备用数据集，经过标准化处理后，训练数据集用来训练长短期记忆网络，备用数据集中所预留的测试数据集用来进行效果检验，即可得到风电功率单点预测值 p^pre。对由误差生成集所产生的预测误差数据，采用所提出的非参数核密度估计方法得到风电功率预测误差的概率密度函数和累积分布函数 (cumulative distribution function, CDF)，设置一定百分比的置信度，即可得到该置信度下误差波动区间 [F_{α/2}, F_{1-α/2}]。基于此，风电功率的上限 U^α 和下限 L^α 可表示为

$$U^{\alpha} = p^{\mathrm{pre}} + F_{\alpha/2} \tag{4.17}$$
