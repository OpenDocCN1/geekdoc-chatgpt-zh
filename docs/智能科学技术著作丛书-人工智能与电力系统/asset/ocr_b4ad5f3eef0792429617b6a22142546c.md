渐减小。传统的优化算法在两个搜索点之间的转移，往往有确定的转移方法和关系，但这种确定性使得搜索点往往达不到最优点，对算法的应用范围有一定的限制，而模拟退火算法有一定的接受概率，增加了搜索的灵活性。

# 2. 引进了算法控制参数

模拟退火算法参考物理退火过程的物理值，引入了算法控制参数，将优化过程分成若干阶段，给各个阶段随机状态的取舍设定不同的标准，接受函数由 Metropolis 算法给出一个简单的数学模型。模拟退火算法有两个重要的步骤：①在每个控制参数下，由前一个迭代点出发，产生邻近的随机状态，按照控制参数的接受准则，决定对新状态的取舍；②缓慢降低控制参数，提高接受准则，直至控制参数趋于零，找到优化问题的最优状态，从而提高模拟退火算法全局最优解的可靠性。

# 3. 对目标函数要求不高

传统搜索算法既需要利用目标函数值，又需要知道目标函数值的导数值等辅助信息才能确定搜索方向，而当这些信息不存在时，算法就不能实现。模拟退火算法不需要其他辅助信息，只是定义邻域结构，在其邻域结构内选取相邻解，再用目标函数进行评估即可。

模拟退火算法作为一种通用的随机搜索算法，现已广泛用于大规模集成电路设计、神经网络计算机、图像处理和组合优化的研究。模拟退火算法的具体应用如下。

+   1) 模拟退火算法在超大规模集成电路设计中的应用
+   利用模拟退火算法进行超大规模集成电路的最优设计，是目前模拟退火算法最成功的应用实例之一，用模拟退火算法可以很好地完成所有超大规模集成电路的优化设计工作，如全局布线、布板、布局和逻辑最小化等。
+   
+   2) 模拟退火算法在神经网络计算机中的应用
+   模拟退火算法具有跳出局部最优解的能力，在玻尔兹曼机中，即使系统落入了局部最优解，经过一段时间后，它还能再跳出来，最终向全局最优解的方向收敛。
+   
+   3) 模拟退火算法在图像处理中的应用
+   模拟退火算法可用来进行图像恢复等工作，即把一幅被污染的图像重新恢复成清晰的原图，滤掉其中啮变的部分，其在图像处理方面有广阔的应用前景。
+   
+   4) 模拟退火算法在组合优化中的应用
+   模拟退火算法还用于其他各种组合优化问题，如旅行商问题和背包问题等。大量的模拟实验表明，模拟退火算法在求解这些问题时能产生令人满意的近似最优解，而且所用的时间较短。
