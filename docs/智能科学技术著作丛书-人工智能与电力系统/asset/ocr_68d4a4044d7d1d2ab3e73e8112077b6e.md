式中，down 为下采样。在最大池模式下，可以选择大小为 n×n 的滤波器最大值，用以重新构造新的特性图。经过几次卷积和池化操作后，利用全连接层来增强非线性映射功能并限制网络的大小。全连接层的操作可以表示为

$$o_j^l = f\left(\sum_{i=1}^{n} x_i^{(l-1)} w_{ji}^{(l)} + b_j^{(l)}\right)\tag{5.7}$$

式中，n 为先前各层的神经元数量；l 为当前层数；w_{ji}^{(l)} 为当前层 j 和最后一层中神经元 i 之间的连接强度；b_j^{(l)} 为神经元偏向；f(·) 为激励函数。

最后，softmax 层充当分类器。在 softmax 层的训练过程中，利用随机梯度下降来最小化互熵损失函数，损失函数表示如下：

$$J(\theta) = -\frac{1}{N} \left[ \sum_{i=1}^{N} \sum_{i=1}^{C} t_{iC} \log \frac{e^{\theta_i^T x_i}}{\sum_{l=1}^{T} e^{\theta_l^T x_i}} \right]\tag{5.8}$$

式中，当第 i 个样本属于 C 类负荷时，t_{iC}=1；\sum_{l=1}^{T} e^{\theta_l^T x_i} 为归一化输出概率。
