# 6.5 基于免疫算法的水火电联合优化调度

水电作为一种清洁环保、费用低廉的可再生能源，近年来在电力系统中的应用比重日益增加。尤其当下能源日益枯竭，水电资源优化利用的社会效益日益凸显，由于水火电联合调度具有显著的经济效益而受到普遍的关注。梯级水电站的各个电站受到上游来水的制约，故其核心是各级水库的调度优化。免疫算法是一个具有记忆机制、调节机制、评价机制和有导向性产生某种特异性抗体等特点的人工智能算法。通过记忆库保留优秀解，免疫算法以抗体表示变量，可方便地处理离散变量，能够有效地避免早熟，使得求解效率更高。近年来，免疫算法由于其强大的信息处理能力，尤其是在完全并行和分布式下实现复杂计算的能力，在电力系统等许多领域，取得了广泛应用。由于梯级水电站的一系列电站间水能联系紧密，本节提出一种以集合形式处理梯级水电站的机组组合免疫算法，利用免疫算法具有记忆、调节机制和便于处理离散变量的优势，将存在水能联系的梯级水电站机组看作一个集合进行统一编码，精简含梯级水电站的水火电联合调度机组组合的有效寻优空间，以提高求解效率[49]。
