# 2.6.2 进化策略算法

进化策略算法是一种基于进化理论的算法，通过适者生存的自然法则来淘汰和筛选样本，目的是获得更好的样本，与遗传算法相似，通过参数扰动来探索更好的解。进化策略算法在遗传信息上的表达更加丰富，而且还可以遗传变异强度，是遗传算法的一种扩展。

# 1. 进化策略算法的基本原理

进化策略算法将优化问题的解视为个体，首先随机产生初始群体，并按照某种重组方式产生新个体，然后通过某种变异规则对群体进行变异操作产生新个体，再根据某种选择规则选择组成新群体的个体，重复变异选择的过程直至满足终止条件，找到最优解。

# 2. 进化策略算法的实现

进化策略算法基本原理流程如图 2.13 所示，实现步骤如下：

+   (1) 确定问题方案。寻找实数 $n$ 维矢量 $x$，使得函数 $F(x)$ 取极值。
+   (2) 对种群进行初始化。从各维的可行范围内采用概率选择的方法随机选取亲本 $x_i (i=1,2,\cdots,p)$ 的初始值。
+   (3) 对两个个体进行交叉重组。通过对 $x$ 的每个分量增加零均值和预先选定的标准差的高斯随机变量，从每个亲本 $x_i$ 中产生子代 $x_i'$。
