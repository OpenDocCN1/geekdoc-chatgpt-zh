# (2)斜坡约束：

$|P_M^{I+1,M} - P_M^{I,M}| \leqslant R_M \Delta t \tag{6.70}$

式中，$P_M$为热力、柴油和抽蓄机组的输出功率；$R_M$为机组爬坡限制。

# (3)抽蓄机组运行约束：

$P_{PG}^{I,N} \cdot P_{PH}^{I,N} = 0 \tag{6.71}$

式中，$P_{PG}$为泵送模式功率；$P_{PH}$为发电模式功率。这是一个非线性约束，表明抽蓄机组不能在一个时间步长内同时抽水和发电。

# (4)启停约束：

$N_{\min} \leqslant N_X \leqslant N_{\max} \tag{6.72}$

式中，$N_X$为热力、柴油和抽蓄机组的启动次数，热力、柴油和抽蓄机组的启动和停止时间不应超过各自的限制。

# (5)蓄水池约束：

$E_{\min} \leqslant E_{S,X} \leqslant E_{\max} \tag{6.73}$

式中，$E_{\min}$、$E_{\max}$分别为上储层和下储层的储蓄量，为了与其他约束条件相一致，减少输入变量，将水库蓄水量约束转化为水库储能约束。

# (6)海水淡化机组-虚拟储能系统约束：

$P_{VESS-} \leqslant P_{VESS} \leqslant P_{VESS~} \tag{6.74}$

$Q_{VESS-} \leqslant Q_{VESS} \leqslant Q_{VESS~} \tag{6.75}$

式中，$P_{VESS}$为第一时间段充放电功率，皆应大于最小功率，小于允许最大功率；$Q_{VESS}$为第一时间段储能。
此外，本节案例中不考虑线损和其他损耗。
