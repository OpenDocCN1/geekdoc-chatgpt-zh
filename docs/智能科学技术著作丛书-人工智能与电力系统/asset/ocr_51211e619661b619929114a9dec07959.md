# 2) 应用 Q 学习算法的电力通信网故障恢复

大规模的自然灾害或恶意攻击会引发智能电网中电力通信网的严重故障，如果不能及时恢复将会给电力系统的安全稳定运行带来极大的风险。为解决电力通信网大规模故障后的恢复问题，在通信链路恢复资源有限的约束下，建立以失效业务数量恢复最大化为目标的电力通信网大规模故障后的链路恢复模型。为此，有学者针对该模型提出了一种基于强化学习的 Q 学习算法，该算法利用链路恢复资源和故障链路在失效业务中的重要程度，设置奖励函数和选择规则，并累计奖励最大值，得到最优链路恢复组合，恢复较多的失效业务。
