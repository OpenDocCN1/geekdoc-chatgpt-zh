# 三、基于生物医学检测的智能诊断发展

随着纳米技术、电子工程、人工智能等现代技术的不断发展，生物医学检测逐渐向自动化、集成化、智能化发展，在保障高特异性前提下，不断提升检测的灵敏性和操作的便捷性，减少医务人员经验等主观因素带来的诊断误差，从而克服医疗资源分布不均衡带来的诊断局限性，最终实现智能诊断目标。本章最后部分将人工智能、微流控和柔性可穿戴设备等相结合，来了解当前智能诊断的发展趋势。
