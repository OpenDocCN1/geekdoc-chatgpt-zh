# # 第十一章 药物智造：
人工智能与药物研制

# ### 本章学习目标

通过本章的学习，你应该能够：

+   1. 了解药物设计的基本原理和流程。
+   2. 了解人工智能技术在药物研制方面的发展和应用。
+   3. 了解人工智能技术对未来药物设计开发的重要性。
