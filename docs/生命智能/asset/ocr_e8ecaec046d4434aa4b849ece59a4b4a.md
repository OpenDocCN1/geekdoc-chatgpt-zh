# 四、高通量代谢组学中的数据处理

生物体内的代谢物变化复杂，其产生的代谢组学数据呈现出高维度、小样本、多干扰等特点，常规分析方法存在着诸多风险。因而，如何正确分析代谢组学数据，从代谢组学数据中提取有价值的重要信息、筛选潜在的生物标志物是代谢组学数据分析处理中亟须解决的关键问题。
