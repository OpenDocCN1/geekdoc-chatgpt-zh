# # 3-5 K-maen 演算法 (1) : 概要

K-means 演算法（又稱 K-means Clustering），K-means 是非監督式學習。換言之不會預先整理數據，而是完全交給程式進行分類，而 K-means 演算法的意義就是將數據分類，將多個數據點分為 K 個群集，K 為使用者給定的參數，參考圖 1、2。K-means 可以替我們做好分類，如身高與體重。
