# 第一单元　人工智能从哪里来？（下）

## 1. 模仿人类的逻辑思维能力

上册我们已学过让计算机显出“智能”的两种思路：复刻神经网络的结构与运转机制、模仿人类感知与适应环境的能力。还有第三种思路：学习人类逻辑推演与思维方式。

### 逻辑思维能力的一种表现——搜索

假如家里的小猫不见了，你会先检查门窗确认它没跑出去，再逐间房间排查。把所有房间都查完就能找到。假如爸爸说冰激凌放在家里，你不会从阳台开始找，而是直接奔向冰箱。因为你了解冰激凌的存放规律，也熟悉家里的格局，结合经验和推理就能制定出找猫和找冰激凌的最优方案。

![img](img/txt002_1.jpg)
AI专家系统借鉴人类逻辑推理的路径

前面两种找东西的方法可以分别叫做“盲目搜索”和“启发式搜索”。人们用这两类思路指导计算机解决复杂难题。例如AI下围棋时在几百万种可能性里筛选最优着法；电子地图为你计算从家到机场的最短路径等。AI玩电子游戏也会用到搜索策略。

### 逻辑思维能力的另一种表现——解决问题

生活中我们常把擅长某一类问题的称作“专家”。科研人员模仿专家的知识积累和解题思路，让计算机在特定领域发挥专家作用，这就是AI“专家系统”。比如疾病诊断、财务管理、工程设计等。要让机器成为专家，需要把人类知识整理成机器可读的“知识库”，并编写程序教它进行逻辑推演。

知识窗

国内某医科大学联合知名中医团队开发了一类疾病诊治专家系统。中医大量医案里的症状与中药处方构成了知识库。程序员用中医一生积累案例的70%训练机器形成推理能力，剩余30%用来检验智力水平。系统“坐诊”时，病人陈述症状，系统会在医案库里检索最相似的病例及对应方案。随着医案库和方案持续更新，系统的诊疗水平会越来越接近真人中医。

### 小贴士
二分法
你是乱猜还是有策略？数学里有种搜索方法叫二分法，也叫折半法。比如随机数是 65，先猜 50，提示偏小，范围缩到 50～100，再猜 75，提示偏大，范围变 50～75，再次折半。循环下来一定能找到。

![img](img/txt011_3.jpg)

### 想一想
1. 怎么让电脑自动记数？
借助学过的变量运算来实现自增。在生成随机数前插入积木指令 ![img](img/txt011_4.jpg)，变量命名为“次数”，保证每次运行都清零。每次执行输入积木指令 ![img](img/txt011_5.jpg) 后接上 ![img](img/txt011_6.jpg)，变量名仍是“次数”，每猜一次加 1。
程序末尾语音播报“恭喜答对，你一共猜了（实际次数）次。”

2. 怎么让播报更有趣？可加一段，根据次数给出不同点评。比如“两次就对了，你是学霸”“五次才对，表现还行”等。

3. 用同样二分法原理，做一个反向猜数游戏。你心里想一个数，让电脑猜。这个游戏模拟了人二分法的思考逻辑，可算一个很简易的 AI 程序。
