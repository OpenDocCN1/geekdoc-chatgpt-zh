DI := min { min_{1≤i≤k} ( D_y^{min} / max_{1≤l≤k} Diam_{C_l} )_{i≠j} }

显然，DBI 指数越小越好，DI 指数越大越好。

# 9.2 原型聚类

原型聚类（prototype-based clustering），此类算法假设聚类结构能够通过一组原型求解。原型聚类在现实任务中应用广泛，代表性的算法有 k 均值（k-means）、学习向量量化、高斯混合聚类等，本节只讨论 k 均值。

# 9.2.1 k 均值

k 均值是原型聚类的典型代表，其主要思想为：在给定要构建的类别数 k 时，首先选定 k 个初始类别中心，并依据数据集中每个样本与初始聚类中心的距离创建一个初始划分；然后，利用均值重新计算类别中心，再把对象调整到最近聚类中心对应的类别中；迭代上述过程，直至达到某些条件时结束聚类。

假设通过 k 均值聚类算法将样本 D 划分为 k 个不相交的类，C = { C_l | l = 1,2,⋯,k }，其中 C_i ∩ C_l' = ∅ (l≠l')，且 ∪_{l=1}^k C_l = D。记 x̄_l 为类别 C_l 的样本中心。k 均值聚类算法的策略是通过最小化损失函数选取最优划分。

首先，恰当选取距离定义。一般选取欧氏距离平方作为样本之间的距离；

d(x_i, x_j) := Σ_{i=1}^n |x_{i i} - x_{j i}|^2 = ||x_i - x_j||^2

然后，将样本与所属类别的中心的距离总和作为损失函数；

Loss(C) = Σ_{l=1}^k Σ_{x_i ∈ C_l} ||x_i - x̄_l||^2   (9-6)

k 均值聚类就是求解最优化问题：

arg min_C Loss(C) = arg min_C Σ_{l=1}^k Σ_{x_i ∈ C_l} ||x_i - x̄_l||^2

但是，此问题为 NP 难题。现实中采用迭代的方法求解。首先，给定 k 个初始类别中心 (x̄_1, x̄_2, ..., x̄_k)，通过极小化式（9-6）得到一个划分 C。即在类别中心给定时，将每个样本指派到与其距离最近的中心所在的类别中。然后，对于得到的划分 C，计算其各个类别的中心。迭代这两个步骤，直到划分不再改变，聚类过程结束。基本算法流程如下：

+   1) 初始化。令 t=0。设置类别数 k，初始化 k 个初始类别中心 (x̄_1^0, x̄_2^0, ..., x̄_k^0)，其中 1<k≤m。初始类别中心可以随机生成，也可以从 D 中随机或依照某种特定策略选取。\n2) 聚类。对于确定的类别中心 (x̄_1^t, x̄_2^t, ..., x̄_k^t)，其中 x̄_l^t 表示第 t 次迭代产生的 C_l' 类别的中心，计算每一个样本到每一个聚类中心的距离，依次比较每一个样本到每一个类别中心的距离，将样本分派到距离最近的类别中心的类别中，得到新的分类 C' = { C_l | l=1,2,⋯,k }。\n3) 更新类别中心。当所有样本都归类完毕后，对于分类 C' = { C_l | l=1,2,⋯,k }，计算各类别的均值，得到新的类别中心 (x̄_1^{t+1}, x̄_2^{t+1}, ..., x̄_k^{t+1})。\n4) 重复以上 2)~3) 步，直至类别中心不再发生变化或者达到结束条件。
