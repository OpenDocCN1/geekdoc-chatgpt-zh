```
sklearn.metrics.accuracy_score(y_true, y_pred, normalize=True, sample_weight=None)
```

其主要参数如下。

+   1) y_true：样本集的真实标签集合。\n2) y_pred：分类器对样本集的预测标签值。\n3) normalize：选择计算分类正确的比例或数量，数据类型为布尔型。若不指定该参数值，则自动使用默认参数值 True。如果设置为 True，则返回分类正确的比例（准确率），为一个浮点数。否则返回分类正确的数量，为一个整数。\n4) sample_weight：样本权重。若不指定该参数值，则自动使用默认参数值 None，此时每个样本的权重均为 1。

# 2. precision_score

Scikit-learn 提供的 precision_score 函数用于计算分类结果的查准率，返回值即预测结果为正类的那些样本中真正正类的比例。其函数原型如下：

```
sklearn.metrics.precision_score(y_true, y_pred, labels=None, pos_label=1, average='binary', sample_weight=None)
```

其主要参数如下。

+   1) y_true：样本集的真实标签集合。\n2) y_pred：分类器对样本集的预测标签值。\n3) labels：用于指定要计算精确度的标签或类别。默认情况下，labels = None，表示计算所有唯一的标签或类别的精确度。也就是说，它将基于预测值和真实值中出现的所有不同类别来计算精确度。\n4) pos_label：指定属于正类的标签，数据类型为字符串型或整型。\n5) average：多分类时评价指标平均值的计算方式，数据类型为字符串型。其可选值如下。\n6) sample_weight：样本权重。若不指定该参数值，则自动使用默认参数值 None，此时每个样本的权重均为 1。

+   ① micro：通过计算全部类别的总 TP、FN 和 FP 来计算查准率。\n② macro：各类别的查准率求和除以类别数量，即各类别查准率的均值。不考虑类别的样本数量，不适用于类别样本不均衡的数据集。\n③ weighted：类别的查准率×该类别的样本数量（实际值而非预测值）/样本总数量，即各类别查准率的加权平均。\n④ binary：只适用于二分类，用正类 y=1 时的 TP、FN 和 FP 来计算查准率。

# 3. recall_score

Scikit-learn 提供的 recall_score 函数用于计算分类结果的查全率，即真正的正类中，被分类器正确划分的比例。其函数原型如下：

```
sklearn.metrics.recall_score(y_true, y_pred, labels=None, pos_label=1, average='binary', sample_weight=None)
```

其主要参数与 precision_score 相同。
