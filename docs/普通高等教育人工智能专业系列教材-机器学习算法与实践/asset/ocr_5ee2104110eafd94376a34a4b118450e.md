arg max_W J(W) := tr(W^T S_b W) / tr(W^T S_w W)

此问题可以利用拉格朗日乘子法求解。不失一般性，令 tr(W^T S_w W)=1。问题转化为以下约束优化问题：

min_W -tr(W^T S_b W)
 s.t. tr(W^T S_w W)=1

利用拉格朗日乘子法，上述问题可转化为以下问题的求解。

S_b W = λ S_w W

式中，λ 表示 S_w^{-1} S_b 的前 N-1 个最大特征值构成的向量，W 为对应的特征向量构成的矩阵。

我们也可以把目标函数改写为

arg max_W J(W) := [∏_diag W^T S_b W] / [∏_diag W^T S_w W] = ∏_{i=1}^{N-1} [w_i^T S_b w_i] / [w_i^T S_w w_i]

式中，∏_diag(·)表示矩阵主对角线上元素的乘积。因此我们希望右端项的每一项最大化，此问题又回归到广义 Rayleigh 商模型，因此我们只需要找到 S_w^{-1} S_b 的前 N-1 个最大特征值，以及对应的特征向量，将其按行排列构成矩阵 W。

# 10.3.2 LDA 对二分类问题降维

# 1. 算法步骤

由 10.3.1 节讨论知，对于给定的样本集，只要找到原样本的不同类别的均值，以及对应的间散度矩阵 S_w，投影方向也就找到了。因此对于二分类问题，其具体步骤如下：

+   (1) 设数据集 D=[(x1,y1),(x2,y2),...,(xm,ym)]，其中 xi ∈ R^n (i=1,2,...,m)，yi ∈ {0,1}。
+   (2) 分别输入两个类别的数据，记 X0=[x1,x2,...,xn1]^T，X1=[xn1+1,xn1+2,...,xm]^T。
+   (3) 计算每类样本的均值 uj(j=0,1)。
+   (4) 计算每个类别的协方差矩阵方差 Σj(j=0,1)，进而计算类内散度矩阵 S_w。
+   (5) 计算散度矩阵的逆矩阵 S_w^{-1}。
+   (6) 计算投影方向 w=S_w^{-1}(u0-u1)。
+   (7) 单位化投影方向 w，得到 w̄。
+   (8) 计算 w̄^T xi(i=1,2,...,m) 将样本投影在直线上，实现降维。
