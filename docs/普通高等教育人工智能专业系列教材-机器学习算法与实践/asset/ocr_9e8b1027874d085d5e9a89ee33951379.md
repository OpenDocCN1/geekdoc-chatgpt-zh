若每个弱学习器有 K 个输出，即弱学习器 $M_i$ 的输出 $d_i = \{d_{i1}, d_{i2}, \dots, d_{iK}\}$。一般可通过式（8-2）对输出进行组合，得到预测值 $y = \{y_1, y_2, \dots, y_K\}$，其中 $w_i$ 为弱学习器 $d_i$ 输出的权重且 $\sum_{i=1}^{L} w_i = 1$。

$$y_j = \sum_{i=1}^{L} w_i d_{ij},\, w_i \ge 0 \tag{8-2}$$

Handen 和 Salamon 在 1990 年给出了如下结论，对于成功概率高于 0.5（比随机猜测好）的一组独立的两类分类器，使用多数表决，预测准确率随投票分类器个数的增加而提高。

假定 $d_i$ 是独立同分布的，其期望值为 $E(d_i)$，方差为 $\mathrm{var}(d_i)$，那么当 $w_i = 1/L$ 时，输出的期望值和方差的计算公式见式（8-3）、式（8-4）。

$$E(y) = E\!\left(\sum_{i=1}^{L} \frac{1}{L} d_i\right) = \frac{1}{L} \times L \times E(d_i) = E(d_i) \tag{8-3}$$

$$\mathrm{var}(y) = E\!\left(\sum_{i=1}^{L} \frac{1}{L} d_i\right) = \frac{1}{L^2}\mathrm{var}\!\left(\sum_{i=1}^{L} d_i\right) = \frac{1}{L}\mathrm{var}(d_j) \tag{8-4}$$

从上述推导过程可以看到，期望值没有改变，但是方差随着独立投票数量的增加而下降。
