### 1. 算法步骤
由 10.2.1 节讨论知，利用 SVD 实现 PCA 算法与利用特征值和特征向量实现相似，为保持完整性，下面给出其基本步骤。

设样本有 n 个属性值，记为向量 a=(a₁,a₂,⋯,aₙ)，需要降到 k 维。具体步骤为：

- (1) 设数据集为 D={x₁,x₂,⋯,xₘ}，其中 xᵢ∈Rⁿ(i=1,2,⋯,m)。
- (2) 将 m 个样本按行写成矩阵形式 X=[x₁,x₂,⋯,xₘ]。
- (3) 对样本集进行中心化处理，即 X 的每一列减去该行均值，得到中心化的数据集 S。
- (4) 求解中心化矩阵 S 的 SVD，得到对应的左奇异矩阵和右奇异矩阵 U 和 V。
- (5) 取矩阵 Uᵀ 的前 k 行（或者 U 的前两列）构成矩阵 Uₖ。
- (6) Uₖ a 作为新的属性值，即为 k 个组成部分。
- (7) Yₖ=XUₖᵀ 为降低属性维度后的数据。
- (8) 计算降维后数据的贡献率 α = (∑ᵢ₌₁ᵏ σᵢ²)/(∑ᵢ₌₁ⁿ σᵢ²)。

## 10.3 线性判别分析
线性判别分析（linear discriminant analysis，LDA）是一种经典的线性学习方法。LDA 是一种重要的分类算法，也是一种有监督降维方法，其基本思想是将数据投影到低维空间上，并且希望投影后的数据点满足：同一类别尽可能“接近”，不同类别尽可能“远离”。例如，设任意样本为(x,y)，其中 x∈R^n 表示样本的属性特征，y∈R 表示样本的标记。对于二分类问题，LDA 将 x 投影到直线上，对于 N 分类问题，LDA 则将 x 投影到 N-1 维超平面（子空间）上。

### 10.3.1 LDA 算法原理
以二分类问题为例，如图 10-2、图 10-3 给出的二维空间示意图。如图所示，矩形和三角形分别代表不同类别。在图 10-2 中，l1（x1 坐标轴）和 l2 表示两条直线。两类别分别用样本中心（均值）u₁, u₂, 以及以它们为中心的椭圆表示。由图可以看出，投影到两个超平面上都可以将两类别区分开，但是投影到l₁时，同一类别的离散度更大，因此l₂更好一些。在图10-3中，l₃和l₄表示两条直线。由图可以看出，若将样本投影到l₃，则不同类别的样本会出现重合，这不是我们想要的。而投影到l₄时，两类别区分明显，效果比l₃好。LDA对“接近”和“远离”进行度量，并统一到同一模型下。

### 1. 二分类问题

### (1) 广义 Rayleigh 商
我们首先简单介绍需要用的矩阵分析模型——广义 Rayleigh 商。设 A, B 为 n×n 维的对称矩阵，且 B 为正定矩阵。矩阵束 (A, B) 的广义 Rayleigh 商为函数 f: Rⁿ→R (R 表示实数域)，定义为

f(x) := xᵀAx / xᵀBx, ∀x∈Rⁿ

由矩阵分析的数学知识知，f 取得最大值 f_max 和最小值 f_min 的条件为

f(x) = { λ_max, 当 Ax = λ_max Bx 时; λ_min, 当 Ax = λ_min Bx 时 }

式中，λ_max 和 λ_min 分别为 B⁻¹A 的最大特征值和最小特征值，也称为矩阵束 (A, B) 的最大广义特征值、最小广义特征值。x 为对应的特征向量。

### (2) 投影
设某直线的单位方向（基）向量为 w，如图 10-4 所示。那么由线性代数知识有任意 x∈Rⁿ 到上述（直线）超平面的投影为 x' = wᵀx，图 10-4 给出了二维空间示意图。

![](img/6ec6ebd34fae089d3107360695d7318a_254_2.png)

图 10-4 二维空间上到直线的投影

### (3) 类内散度
设数据集 D = [(x₁,y₁), (x₂,y₂), …, (x_m,y_m)], 其中 x_i ∈ Rⁿ(i=1,2,…,m), y_i ∈ {0,1}。记 X_j(j=0,1) 为第 j 类样本的集合，|X_j|(j=0,1) 表示第 j 类样本的个数，u_j(j=0,1) 为第 j 类样本的中心（均值），即

u_j = 1/|X_j| Σ_{x∈X_j} x (j=0,1)

那么投影后的样本中心为

$$\boldsymbol{u}'_j = \frac{1}{|X_j|} \sum_{x \in X_j} \boldsymbol{w}^T \boldsymbol{x} = \boldsymbol{w}^T \boldsymbol{u}_j\,(j = 0,1)$$

LDA 利用每个类别的样本方差度量同类别的 “接近” 程度，即同类别样本的离散程度。记 $\sigma_j^2(j=0,1)$ 表示第 $j$ 类样本投影后的方差，即

$$\sigma_j^2 = \frac{1}{|X_j|} \sum_{x \in X_j} \|\boldsymbol{w}^T \boldsymbol{x} - \boldsymbol{w}^T \boldsymbol{u}_j\|_2^2 = \frac{1}{|X_j|} \sum_{x \in X_j} (\boldsymbol{w}^T \boldsymbol{x} - \boldsymbol{w}^T \boldsymbol{u}_j)(\boldsymbol{w}^T \boldsymbol{x} - \boldsymbol{w}^T \boldsymbol{u}_j)^T$$ $$= \frac{1}{|X_j|} \boldsymbol{w}^T \sum_{x \in X_j} (\boldsymbol{x} - \boldsymbol{u}_j)(\boldsymbol{x} - \boldsymbol{u}_j)^T \boldsymbol{w}\,(j = 0,1)$$

记第 $j(j=0,1)$ 类样本的协方差矩阵为 $\boldsymbol{\Sigma}_j(j=0,1)$，即

$$\boldsymbol{\Sigma}_j = \frac{1}{|X_j|} \sum_{x \in X_j} (\boldsymbol{x} - \boldsymbol{u}_j)(\boldsymbol{x} - \boldsymbol{u}_j)^T\,(j = 0,1)$$

那么投影后的两类样本的方差和为 $$\sigma_0^2 + \sigma_1^2 = \boldsymbol{w}^T(\boldsymbol{\Sigma}_0 + \boldsymbol{\Sigma}_1)\boldsymbol{w}\,(j=0,1)$$

定义类内散度矩阵为 $$S_w := \boldsymbol{\Sigma}_0 + \boldsymbol{\Sigma}_1$$ 那么最小化投影后类间方差，即最小化 $\boldsymbol{w}^T S_w \boldsymbol{w}$。

### (4) 类间散度
LDA 利用类别中心的欧氏距离的平方刻画不同类别之间的 “远离” 程度，即 $$(\boldsymbol{w}^T \boldsymbol{u}_0 - \boldsymbol{w}^T \boldsymbol{u}_1)^2$$ 定义类间散度矩阵（between-class scatter matrix） $$S_b := (\boldsymbol{u}_0 - \boldsymbol{u}_1)(\boldsymbol{u}_0 - \boldsymbol{u}_1)^T$$

那么 $$(\boldsymbol{w}^T \boldsymbol{u}_0 - \boldsymbol{w}^T \boldsymbol{u}_1)^2 = (\boldsymbol{w}^T \boldsymbol{u}_0 - \boldsymbol{w}^T \boldsymbol{u}_1)(\boldsymbol{w}^T \boldsymbol{u}_0 - \boldsymbol{w}^T \boldsymbol{u}_1)^T = \boldsymbol{w}^T S_b \boldsymbol{w}$$ 因此，最大化投影后类间距离即最大化 $\boldsymbol{w}^T S_b \boldsymbol{w}$。

### (5) LDA 模型（二分类）
将上述类内散度与类间散度结合，得到 LDA 的目标函数 $$\arg\max_{\boldsymbol{w}} J(\boldsymbol{w}) := \frac{\boldsymbol{w}^T S_b \boldsymbol{w}}{\boldsymbol{w}^T S_w \boldsymbol{w}}$$ 由广义 Rayleigh 商知，此函数 $J$ 取得最大值的条件为 $$S_b \boldsymbol{w} = \lambda_{\max} S_w \boldsymbol{w}\tag{10-3}$$ 且其最大值为 $S_w^{-1} S_b$ 的最大特征值 $\lambda_{\max}$，$\boldsymbol{w}$ 为对应的特征向量。由 $S_b$ 的定义注意到 $$S_b \boldsymbol{w} = (\boldsymbol{u}_0 - \boldsymbol{u}_1)(\boldsymbol{u}_0 - \boldsymbol{u}_1)^T \boldsymbol{w} = \alpha (\boldsymbol{u}_0 - \boldsymbol{u}_1)\tag{10-4}$$ 式中，$\alpha = (\boldsymbol{u}_0 - \boldsymbol{u}_1)^T \boldsymbol{w}$，式（10-3）和式（10-4）结合可以得到 $$\boldsymbol{w} = \frac{\alpha}{\lambda_{\max}} S_w^{-1} (\boldsymbol{u}_0 - \boldsymbol{u}_1)$$

而在此模型中，$\boldsymbol{w}$ 表示投影方向，其范数大小对问题并没有什么影响，因此选取 $$\boldsymbol{w} = S_w^{-1} (\boldsymbol{u}_0 - \boldsymbol{u}_1)$$ 那么，只要找到原样本的不同类别的均值，以及对应的类间散度矩阵 $S_w$，投影方向也就找到了。
