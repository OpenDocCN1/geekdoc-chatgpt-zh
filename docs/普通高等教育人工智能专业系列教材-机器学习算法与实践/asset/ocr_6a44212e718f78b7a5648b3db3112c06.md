# 12.3 多层前馈神经网络

多层前馈神经网络中，每一层中的神经元负责接收前一层神经元的输出，并传递给下一层的神经元。整个神经网络的信息是朝一个方向传播，没有反向的传播，可以用一个有向无环图表示，如图 12-5b 所示。多层前馈神经网络也分为很多种，本节主要介绍全连接前馈神经网络。
