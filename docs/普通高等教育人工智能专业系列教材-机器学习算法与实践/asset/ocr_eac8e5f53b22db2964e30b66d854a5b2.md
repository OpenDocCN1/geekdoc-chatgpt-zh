式（6-50）和式（6-51）求得原始问题式（6-48）的解，进而得到超平面式（6-52），这种算法称为线性支持向量机回归的对偶算法，下面给出求解步骤：

设训练集 $D = \{(x_1,y_1),(x_2,y_2),\cdots,(x_N,y_N)\}$，其中 $x_i \in R^n$, $y_i \in \{-1,1\}$, $i=1,2,\cdots,N$。

+   1. 选取恰当的核函数，构造并求解对偶问题式（6-49）。
+   2. 利用式（6-50）和式（6-51）计算 $w^*$ 和 $b^*$。
+   3. 得到超平面为 $w^{*T}x + b^* = 0$。

# 6.5.2 非线性支持向量机回归

类似于非线性支持向量机分类，非线性支持向量机回归也通过核函数实现，这里不再赘述，直接给出其优化模型以及对偶算法。

# 1. 原始优化问题

设 $\phi$ 为原空间到新空间的映射，使得训练集在新空间呈线性变化趋势。

原始优化问题为

$$\begin{cases}\min_{w,b,\xi,\xi^*} \frac12\|w\|+C\sum_{i=1}^N(\xi_i+\xi_i^*)\\\text{s.t.}\quad y_i-w^T\phi(x_i)-b\le\epsilon+\xi_i,i=1,2,\cdots,N\\w^T\phi(x_i)+b-y_i\le\epsilon+\xi_i^*,i=1,2,\cdots,N\\\xi_i,\xi_i^*\ge0,i=1,2,\cdots,N\end{cases}\tag{6-53}$$

式中，$C>0$ 为惩罚参数。

# 2. 对偶算法

# （1）对偶问题

原始优化问题（6-53）的对偶问题为

$$\begin{cases}\min_{\lambda,\bar\lambda}\frac12\sum_{i=1}^N\sum_{j=1}^N(\lambda_i-\bar\lambda_i)(\lambda_j-\bar\lambda_j)\kappa(x_i,x_j)-\sum_{i=1}^N y_i(\lambda_i-\bar\lambda_i)+\sum_{i=1}^N\epsilon(\lambda_i+\bar\lambda_i)\\\text{s.t.}\quad\sum_{i=1}^N(\lambda_i-\bar\lambda_i)=0\\0\le\lambda_i,\bar\lambda_i\le C,i=1,2,\cdots,N\end{cases}\tag{6-54}$$

式中，$\kappa(\cdot,\cdot)$ 称为核函数。设对偶问题的解为 $\lambda^*=(\lambda_1^*,\lambda_2^*,\cdots,\lambda_N^*)$, $\bar\lambda^*=(\bar\lambda_1^*,\bar\lambda_2^*,\cdots,\bar\lambda_N^*)$, 则原问题的参数为

$$b^*=y_j-w^{*T}x_j-\epsilon=y_j-\sum_{i=1}^N(\lambda_i^*-\bar\lambda_i^*)\kappa(x_i,x_j)-\epsilon\tag{6-55}$$

式中，$j$ 为满足 $\lambda_j>0$ 或 $\bar\lambda_j>0$ 的指标。进而得到非线性模型为

$$y=w^{*T}\phi(x)+b^*=\sum_{i=1}^N(\lambda_i^*-\bar\lambda_i^*)\kappa(x_i,x)+y_j-\sum_{i=1}^N(\lambda_i^*-\bar\lambda_i^*)\kappa(x_i,x_j)-\epsilon\tag{6-56}$$
