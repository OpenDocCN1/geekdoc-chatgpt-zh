# 2. 步骤

下面直接给出 SMO 算法的步骤：

设训练集 $D = \{(\mathbf{x}_1, y_1), (\mathbf{x}_2, y_2), \cdots, (\mathbf{x}_N, y_N)\}$，其中 $\mathbf{x}_i \in \mathbf{R}^n$, $y_i \in \{-1,1\}$, $i=1,2,\cdots, N$，精度为 $\epsilon$, $k$ 表示迭代步数。

+   1. 初始化： $k=0$, $\lambda^k=0$。
+   2. 选取优化变量 $\lambda_1^k$, $\lambda_2^k$, 求解式（6-58）~式（6-60）的约束优化问题，对应的更新 $\lambda^k$ 为 $\lambda^{k+1}$。
+   3. 若在精度范围内满足停止条件
+      $$\sum_{i=1}^N \lambda_i y_i =0, 0\le \lambda_i \le C, i=1,2,\cdots,N$$
+      $$y_i g(x_i) \begin{cases} \ge1, & \{x_i \mid \lambda_i=0\} \\ =1, & \{x_i \mid 0<\lambda_i<C\} \\ \le1, & \{x_i \mid \lambda_i=C\} \end{cases}$$
+      其中
+      $$g(x_i)=\sum_{j=1}^N \lambda_j y_j \kappa_{ji}+b$$
+      则转 4)；否则令 $k=k+1$, 转 2)。
+   4. 取 $\lambda^* = \lambda^{k+1}$。

我们可以手动实现 SVM 算法，也可以借助 Scikit-learn 实现。Scikit-learn 中 SVM 算法的实现都包含在 sklearn.svm 里，包含分类封装类 SVC 和回归封装类 SVR。

SVC 类实现代码如下：

```
sklearn.svm.SVC(*, C=1.0, kernel='rbf', degree=3, gamma='scale', coef0=0.0, shrinking=True, probability=False, tol=0.001, cache_size=200, class_weight=None, verbose=False, max_iter=-1, decision_function_shape='ovr', break_ties=False, random_state=None)
```

SVR 类实现代码如下：

```
sklearn.svm.SVR(*, kernel='rbf', degree=3, gamma='scale', coef0=0.0, tol=0.001, C=1.0, epsilon=0.1, shrinking=True, cache_size=200, verbose=False, max_iter=-1)
```

其中各参数的格式与含义可参考 Python 帮助或者 CDA Scikit-learn 中文社区 SVM 模块。
