# （3）协方差矩阵对角化

代码 10-7 实现协方差矩阵 C 的对角化。首先，对左奇异矩阵 U 进行转置操作，得到转置后的矩阵 U_t。接着，通过 np.dot() 函数计算矩阵 D 等于左奇异矩阵 U 的转置乘以矩阵 C 再乘以左奇异矩阵 U。最后，我们输出矩阵 D 的结果。

# 代码 10-7 对协方差矩阵进行对角化

```
# 对左奇异矩阵 U 进行转置操作
U_t = np.transpose(U)

# 计算矩阵 D,D = U_t * C * U
D = np.dot(np.dot(U_t, C), U)

# 输出矩阵 D
print(D)
```

得到对角化的协方差矩阵（保留小数点后两位）：

\begin{bmatrix}11.41 & 0 & 0 \\ 0 & 2.86 & 0 \\ 0 & 0 & 0.03\end{bmatrix}
