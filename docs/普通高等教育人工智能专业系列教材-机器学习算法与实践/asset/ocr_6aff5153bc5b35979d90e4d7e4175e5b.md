T = { (x1, y1), (x2, y2), ..., (xN, yN) },

式中，x_i = (x_i^1, x_i^2, ..., x_i^n)^T ∈ R^n, y_i ∈ R, i = 1,2,...,N。一般线性回归的任务是找到一个超平面

y = w^T x + b   (6-39)

式中，w = (w^1, w^2, ..., w^n)^T ∈ R^n 为法向量，b 为截距。以尽可能准确地预测实际值 y = (y1, y2, ..., yN)，如下图 6-7 所示。

![](bbox=[0.57, 0.2, 0.88, 0.42])

参数估计通常采用最小二乘法，即预测值 ŷ = (ŷ1, ŷ2, ..., ŷN) 与实际值 y 之间的欧式距离的平方最小，即

min_{w,b} ||y - ŷ||^2 = Σ_{i=1}^N (y_i - ŷ_i)^2 = Σ_{i=1}^N (y_i - w^T x_i - b)^2   (6-40)

此模型将每个训练样本的误差平方都会计入损失函数。

# (2) 支持向量机回归

支持向量机回归与线性回归不同，只要样本的误差在一定范围内就不计入损失函数，设 ε>0 为模型容许的最大误差。即当

|y_i - w^T x_i - b| ≤ ε   (6-41)

或者

{ y_i - w^T x_i - b ≤ ε 
  w^T x_i + b - y_i ≤ ε }   (6-42)

时，不计损失。支持向量机回归如下图 6-8 所示。

将原线性回归模型的超平面分别向上和向下平移 ε 单位，得到两个新的超平面②、③。此时，当样本落在两条虚线内，则认为没有损失。两条虚线之间的距离为

2d = 2ε / sqrt(||w||^2 + 1)   (6-43)

那么两条虚线的距离越大，包含的样本越多，模型鲁棒性能也越好。当 ε 固定时，||w|| 的值越小，两条虚线的距离越大。为方便计算，一般取

1/2 ||w||^2   (6-44)

此时得到支持向量机回归的基本模型为

min_{w,b} 1/2 ||w||^2
s.t. |y_i - w^T x_i - b| ≤ ε, i = 1,2,...,N   (6-45)

![](bbox=[0.55, 0.57, 0.88, 0.8])
