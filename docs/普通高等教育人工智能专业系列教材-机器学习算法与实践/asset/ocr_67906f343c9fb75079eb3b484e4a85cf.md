# 10.3 线性判别分析

线性判别分析（linear discriminant analysis，LDA）是一种经典的线性学习方法。LDA 是一种重要的分类算法，也是一种有监督降维方法，其基本思想是将数据投影到低维空间上，并且希望投影后的数据点满足：同一类别尽可能“接近”，不同类别尽可能“远离”。例如，设任意样本为(x,y)，其中 x∈R^n 表示样本的属性特征，y∈R 表示样本的标记。对于二分类问题，LDA 将 x 投影到直线上，对于 N 分类问题，LDA 则将 x 投影到 N-1 维超平面（子空间）上。
