# 前 言

本書主要介紹了機器學習算法內容及其代表性算法，全書共12章，具體內容安排如下。
第1章：機器學習概述。主要包括機器學習的概念、機器學習工具和機器學習示例等內容。
第2章：機器學習基本理論。主要包括機器學習術語、實驗估計方法、算法性能度量、比較檢驗方法和參數調優方法等內容。
第3章：K-近鄰。主要包括算法原理、距離度量方法、搜索優化方法和算法實現等內容。
第4章：貝葉斯。主要包括貝葉斯算法概述、朴素貝葉斯算法、半朴素貝葉斯算法、貝葉斯網絡算法和EM算法等內容。
第5章：線性模型。主要包括線性回歸、邏輯回歸和模型正則化等內容。
第6章：支持向量機。主要包括算法概述、線性可分支持向量機及其對偶算法、線性支持向量機、非線性支持向量機、SMO算法等內容。
第7章：決策樹。主要包括決策樹概述、ID3算法、C4.5算法、分類與回歸樹和剪枝策略等內容。
第8章：集成學習。主要包括集成學習概述、投票法、裝袋法和提升法等內容。
第9章：聚類算法。主要包括聚類概述、原型聚類、密度聚類、層次聚類等內容。
第10章：數據降維。主要包括數據降維概述、主成分分析、線性判別分析等內容。
第11章：半監督學習。主要包括未標記樣本、半監督學習方法和半監督聚類等內容。
第12章：神經網絡。主要包括人工神經網絡概述、感知機、多層前饋神經網絡和其他神經網絡等內容。
