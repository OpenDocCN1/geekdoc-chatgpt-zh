N_e(a1) = {a1,a2,a3,a4}，令 Δ := N_e(a1) ∩ Γ = {a2,a3,a4}，更新当前类别样本集合 C1 = C1 ∪ Δ = {a1,a2,a3,a4}，更新未访问样本集合 Γ = Γ - Δ = {b1,b2,c1,c2}，更新 Ω_cur = Ω_cur ∪ (N_e(a1) ∩ Ω) = {a2,a3,a4}。

② 第二轮，由于 Ω_cur ≠ ∅，更新核心样本集合 Ω = Ω - C1 = ∅。在当前类别核心样本队列 Ω_cur 中取出一个核心样本 a2，并更新 Ω_cur = Ω_cur - {a2} = {a3,a4}。找到其 ε-邻域样本集 N_e(a2) = {a1,a2,a3,b1}，令 Δ := N_e(a2) ∩ Γ = {b1}，更新当前类别样本集合 C1 = C1 ∪ Δ = {a1,a2,a3,a4,b1}，更新未访问样本集合 Γ = Γ - Δ = {b2,c1,c2}，更新 Ω_cur = Ω_cur ∪ (N_e(a1) ∩ Ω) = {a3,a4}。

③ 第三轮，由于 Ω_cur ≠ ∅，更新核心样本集合 Ω = Ω - C1 = ∅。在当前类别核心样本队列 Ω_cur 中取出一个核心样本 a3，并更新 Ω_cur = Ω_cur - {a3} = {a4}。找到其 ε-邻域样本集 N_e(a3) = {a1,a2,a3,a4}，令 Δ := N_e(a3) ∩ Γ = ∅，更新当前类别样本集合 C1 = C1 ∪ Δ = {a1,a2,a3,a4,b1}，更新未访问样本集合 Γ = Γ - Δ = {b2,c1,c2}，更新 Ω_cur = Ω_cur ∪ (N_e(a1) ∩ Ω) = {a4}。

④ 第四轮，由于 Ω_cur ≠ ∅，更新核心样本集合 Ω = Ω - C1 = ∅。在当前类别核心样本队列 Ω_cur 中取出一个核心样本 a4，并更新 Ω_cur = Ω_cur - {a4} = ∅。找到其 ε-邻域样本集 N_e(a4) = {a1,a3,a4,b2}，令 Δ := N_e(a4) ∩ Γ = {b2}，更新当前类别样本集合 C1 = C1 ∪ Δ = {a1,a2,a3,a4,b1,b2}，更新 Ω_cur = Ω_cur ∪ (N_e(a1) ∩ Ω) = ∅。

由于 Ω_cur = ∅，则类别 C1 产生完成，初始化类别序号 k=2，更新类别划分 C = {C1}，更新核心样本集合 Ω = Ω - C1 = ∅，内循环结束。

2) 由于 Ω = ∅，外循环结束，算法结束。

最终聚类结果 C = {C1}，C1 = {a1,a2,a3,a4,b1,b2}，c1,c2为噪声点。

对于样本集 D = {x1,x2,...,xm}，邻域参数 (ε,Minpts)，DBSCAN 算法流程如下：

1) 初始化。设置核心样本集合 Ω = ∅，类别数 k=0，未访问样本集合 Γ = D，类别划分 C = ∅。

2) 遍历 D，找到核心点加入 Ω。通过距离度量方式，找到样本 x_i(i=1,2,...,m) 的 ε-邻域 N_e(x_i)。如果样本集样本个数满足 |N_e(x_j)| ≥ Minpts，则将样本 x_i 加入核心样本集合 Ω = Ω ∪ {x_i}。

3) 如果核心样本集合 Ω = ∅，则算法结束，否则转入步骤4)。

4) 在核心样本集合 Ω 中，随机选择一个核心样本 o，初始化当前类别核心样本队列 (“种子点”) Ω_cur = {o}，初始化当前类别样本集合 C_k = {o}，更新未访问样本集合 Γ = Γ - {o}。转入步骤5)。

5) 如果当前类别核心样本队列 Ω_cur = ∅，则当前类别 C_k 生产完毕，初始化类别序号 k = k+1，更新类别划分 C = {C1,C2,...,Ck}，更新核心样本集合 Ω = Ω - C_k，转入步骤3)。否则，更新核心样本集合 Ω = Ω - C_k，转入步骤6)。

6) 在当前类别核心样本队列 Ω_cur 中取出一个核心样本 o，并更新 Ω_cur = Ω_cur - {o}。找出其所有 ε-邻域样本集 N_e(o)，令 Δ = N_e(o) ∩ Γ，更新当前类别样本集合 C_k = C_k ∪ Δ，更新未访问样本集合 Γ = Γ - Δ，更新 Ω_cur = Ω_cur ∪ (N_e(o) ∩ Ω)，转步骤5)。

DBSCAN 的主要优点有：①可以对任意形状的稠密数据集进行聚类，而 k 均值之类的聚类算法一般只适用于凸数据集。②可以在聚类的同时发现异常点，对数据集中的异常点不敏感。③聚类结果没有偏倚，而 k 均值之类的聚类算法初始值对聚类结果有很大影响。
