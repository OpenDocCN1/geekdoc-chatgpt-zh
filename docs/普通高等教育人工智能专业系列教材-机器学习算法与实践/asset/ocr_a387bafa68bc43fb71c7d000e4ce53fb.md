# 1. 二分类问题

# (1) 广义 Rayleigh 商

我们首先简单介绍需要用的矩阵分析模型——广义 Rayleigh 商。设 A, B 为 n×n 维的对称矩阵，且 B 为正定矩阵。矩阵束 (A, B) 的广义 Rayleigh 商为函数 f: Rⁿ→R (R 表示实数域)，定义为

f(x) := xᵀAx / xᵀBx, ∀x∈Rⁿ

由矩阵分析的数学知识知，f 取得最大值 f_max 和最小值 f_min 的条件为

f(x) = { λ_max, 当 Ax = λ_max Bx 时; λ_min, 当 Ax = λ_min Bx 时 }

式中，λ_max 和 λ_min 分别为 B⁻¹A 的最大特征值和最小特征值，也称为矩阵束 (A, B) 的最大广义特征值、最小广义特征值。x 为对应的特征向量。
