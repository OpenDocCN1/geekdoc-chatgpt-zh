# 概念解析

# 反卷积层

我们知道卷积层具有自己的步长，当步长大于1的时候，输出的尺寸小于输入尺寸。而反卷积层则相反，当反卷积层的步长大于1的时候，输出的尺寸大于输入尺寸。反卷积层可以视作卷积层的一种逆向操作，其运算规则和卷积层相似。反卷积层首先在输入数据之间填充，使输入的尺寸扩大，然后再用卷积核进行卷积运算，得到的输出尺寸有可能比原本的输入更大。
