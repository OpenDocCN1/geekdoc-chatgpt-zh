# 二、初识强化学习

强化学习(Reinforcement Learning)考虑的是智能体与环境之间的交互问题。智能体是拥有行动能力的事物，常见的智能体有机器人、游戏AI、无人车等。以下图的无人车为例，在它前往目的地的过程中，车所在的车道、周围的其他车辆、路边的行人以及路口的红绿灯等组成了环境，无人车通过摄像头、传感器等设备来感知环境，然后通过决策如何操控方向、油门和刹车来实现安全行车这个任务。
