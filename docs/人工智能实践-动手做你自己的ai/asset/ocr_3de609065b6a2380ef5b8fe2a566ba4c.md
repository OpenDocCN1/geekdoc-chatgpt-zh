# ## 一、图像风格迁移简介

风格迁移的两个要素是内容与风格。我们希望达成的效果是，输入一张图像，程序可以把它转化为带有某种特定风格的图像，同时保留图像中原有的内容信息，而这种风格应该是由人工智能从该类风格的图像中学习得到。
