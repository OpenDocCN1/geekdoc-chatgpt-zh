## 5.5.1 与Arduino连接

Pixy存在的意义就是与微控制器连接并进行通信，因为这样才是一个合格的传感器。

Pixy2可随时与Arduino交互，以1MB/s的速率向Arduino发送块信息。这意味着Pixy每秒可以发送6000多个检测到的物体，也就是每帧就包含100多个物体（Pixy每秒可以处理60帧）。

现在就可以将提供的Arduino数据线将Pixy与Arduino连接了，以便于两者通信。

### Arduino API

Pixy与Arduino结合使用是非常简单的，只需要导入SPI和Pixy头文件即可：

```
#include <SPI.h>
#include <Pixy2.h>
```

然后在`setup()`和`loop()`函数外部创建一个Pixy的全局变量：

```
Pixy2 pixy;
```

Arduino库中最重要的方法是`getBlocks()`，它会返回Pixy检测到的物体数量。然后你可以在`pixy.ccc.blocks[]`数组中查看每个检测物体的详细信息（每个数组包含一个被检测到的物体）。该数组的第i个元素包含以下属性：

- `pixy.ccc.blocks[i].m_signature`：被检测物体的颜色标记的编号（普通标记编号为1~7）。
- `pixy.ccc.blocks[i].m_x`：被检测物体中心位置的x坐标（0~316）。
- `pixy.ccc.blocks[i].m_y`：被检测物体中心位置的y坐标（0~208）。
- `pixy.ccc.blocks[i].m_width`：被检测物体的宽度（1~316）。
- `pixy.ccc.blocks[i].m_height`：被检测物体的高度（1~208）。
- `pixy.ccc.blocks[i].m_angle`：当被检测物体可以构成颜色编码时，该属性表示被检测物体的旋转角度。
- `pixy.ccc.blocks[i].m_index`：当前块的跟踪索引。
- `pixy.ccc.blocks[i].m_age`：当前块的帧数。
- `pixy.ccc.blocks[i].print()`：成员函数，用于将被检测物体信息打印到串行端口。

由此看来实现Pixy2与Arduino通信也很简单。

## 5.5.3 与BeagleBone Black连接

接下来将介绍在Debian Linux发行版的BeagleBone Black上如何编译`hellopixy`样例程序。`hellopixy`演示了如何读取块信息，以及如何通过USB数据线向Pixy发送命令，如同PixyMon一样。

你需要具备以下条件：

- BBB与安装到eMMC的Debian Linux发行版。
- 至少3个端口的USB集线器。
- 将Pixy固件更新至1.0.2版。
- `libpixyusb`版本为0.2。

可以在BeagleBoard官网上下载BeagleBone Black的Debian Linux发行版，网址为`http://beagleboard.org/latest-images/`。

将BeagleBone Black进行闪存的步骤可以参考`https://learn.adafruit.com/beaglebone-black-installing-operating-systems/flashing-the-beaglebone-black`。

### 步骤01

Pixy2用以太网线将BeagleBone Black连接到互联网，用HDMI线将视频显示器连接到BeagleBone Black，使用USB数据线或5V桶形连接器为BeagleBone Black供电。

在主目录下打开LXTerminal终端应用，在终端输入：

```
sudo apt-get update
sudo apt-get install libusb-1.0-0.dev
sudo apt-get install libboost-all-dev
sudo apt-get install cmake
```

然后下载Pixy源码，在终端输入：

```
git clone https://github.com/charmedlabs/pixy.git
```

### 步骤02

编译和安装`libpixyusb`。

在终端输入：

```
cd pixy/scripts
./build_libpixyusb.sh
sudo ./install_libpixyusb.sh
```

### 步骤03

运行`hello_pixy`样例程序。

编译命令：

```
./build_hello_pixy.sh
```

运行命令：

```
cd ../build/hello_pixy
sudo ./hello_pixy
```

## 5.5.4 与其他微控制器连接

Pixy2目前拥有Arduino、LEGO Mindstorms EV3、roboRIO和树莓派及类似控制器的软件支持。

同样也可以让Pixy2与其他不同的控制器连接，Pixy2在这方面比Pixy要更强大。Pixy2通过以下3种接口进行通信：

- **串行接口**：包括SPI、I2C和UART接口。串行接口都使用简化的协议，代码量和内存占用都很少，且代码很容易移植到不同的微控制器。与Arduino通信就是使用串行接口。Pixy可使用串行协议发送有关其检测内容的完整信息，并接受设置云台伺服系统等的简单命令。
- **USB**：USB接口适用于内存资源（RAM和闪存）较多的微控制器。USB协议的代码占用较多内存。与树莓派和BeagleBone Black通信就是使用USB接口，PixyMon使用它来传输实时视频和读写配置信息。
- **逻辑/数字接口**：这是最简单的接口，甚至没有对应协议。

### 1. 确定如何与Pixy2通信

当Pixy2通过SPI与Arduino通信时速度可达2Mb/s，因为Arduino SPI的时钟速率为2MHz，而通过UART串口通信时通常只有19.2~115Kb/s。选择合适的接口，目的是保证可以接收到Pixy2每秒60帧的信息传出速率。

- 当控制器是基于Linux且有USB端口时，请使用`libpixyusb2`。USB是速度最快的接口，而且移植是相对容易的。
- 当控制器不支持USB而支持SPI时，那就使用SPI，它通常比I2C和UART快。
- 当控制器不支持以上接口而支持I2C时，那就使用I2C，它与UART串口速度相当，但是更为灵活。
- 当控制器不支持以上接口而支持UART时，就使用UART。
- 当控制器都不支持以上各种接口时，考虑使用数字或模拟输出，这是最简单的接口。

### 2. 使用USB通信

如果使用USB与Pixy2进行通信，可以参考`libpixyusb2`库。将程序载入控制器应该是比较容易的，特别是当控制器为Linux系统时。如果控制器为Linux系统，就参阅本指南，相信这会帮助你尽快上手。

旧版本的`libpixyusb`需要`libboost`和`libusb`库，而`libpixyusb2`只需要`libusb`。`libusb`还可用于除Linux之外的许多其他平台。因此，对于非Linux系统，首先需要找到适用于当前平台/操作系统的`libusb`端口，然后获取`libpixyusb2`并进行编译，接下来使用指南中提到的`get_blocks_cpp_demo`这样的简单示例进行测试。

本指南其余部分适用于其他（非USB）接口。

### 3. 设置非USB接口

输出接口的配置可以在PixyMon中完成，在接口（Interface）标签页中的数据输出接口（Data out port）标明了使用何种接口，如图5-73所示。

![](EPUB/images/image_281.jpg)

**图5-73**

- **Arduino ICSP SPI**：默认接口，是3线接口（I/O连接器的1、3和4号引脚），用于通过ICSP连接器与Arduino通信。此版本的SPI不使用片选信号。
- **SPI with SS**：基本与Arduino ICSP SPI相同，不同之处在于它通过引脚7（SPI SS）支持片选。也就是说，在发送/接收每个字节信息之前，需要将SPI SS驱动置为低电平。
- **I2C**：一个多点2线端口（I/O连接器的5、9号引脚），允许单个主设备与多达127个从设备（最多127个Pixy2）通信。你可以通过`I2C address`参数配置I2C地址。
- **UART**：这是常见的“串行端口”（I/O连接器的1、4号引脚）。Pixy通过引脚1（输入端口）接收数据，并通过引脚4（输出端口）将数据传出。你可以通过`UART baudrate`参数配置UART波特率。
- **analog/digital x**：通过引脚8以电压为0到3.3V的模拟信号的形式输出检测物体中最大的x值，同时以数字信号（I/O连接器的1号引脚）的形式输出是否检测到物体。
- **analog/digital y**：通过引脚8以电压为0到3.3V的模拟信号的形式输出检测物体中最大的y值，同时以数字信号（I/O连接器的1号引脚）的形式输出是否检测到物体。
- **LEGO I2C**：用于LEGO Mindstorms EV3的特殊协议。

**注意**

USB接口和协议是一直保持开启状态的，上述接口一次只能开启其中一个。

### 1. SPI

ICSP SPI接口用作SPI从器件。它是围绕Arduino的ICSP端口设计的，该端口没有片选信号，默认数据速率为2 MB/s，但可以通过修改Pixy2的Arduino库中`Pixy2.h`头文件的`PIXY_SPI_CLOCKRATE`值来增加。该协议通过校验和来处理位错误。Pixy2支持如下SPI特点：

- 首先发送最重要的数据。
- 闲置时SPI SCK值很低。
- 数据位在SPI SCK的下降沿锁存。
- 片选在低电平有效。
- 使用SPI模式3。
- 3.3V输出，5V耐压输入。

Pixy2还支持具有从机选择引脚的SPI（SPI with SS）。以下是将控制器的SPI连接到Pixy2的步骤（不使用Arduino及所提供数据线）：

- 引脚6 → 控制器的接地信号。
- 引脚1（SPI MISO） → 控制器的SPI MISO信号。
- 引脚4（SPI MOSI） → 控制器的SPI MOSI信号。
- 引脚3（SPI SCK） → 控制器的SPI SCK信号。
- 引脚7（SPI SS） → 控制器的SPI SS信号（如果选择的接口为SPI with SS）。

### 2. I2C

- I2C接口作为I2C的从机工作，需要轮询。
- 通过R14和R15，对SDA和SCL信号上的5V电压来说存在微弱的82KΩ上拉电阻。
- I2C信号具有5V容限。
- 可以在PixyMon的Configure对话框的Interface选项卡中配置I2C地址。
- Pixy2给出了在Arduino上使用I2C的示例。通过在Arduino IDE中选择`File → Examples → Pixy2 → ccci2cuart`运行该示例（确保已经定义了I2C）。

I2C需要特制的数据线支持。下面介绍如何将控制器的I2C接口连接到Pixy：

- 引脚6 → 控制器的接地信号。
- 引脚9（I2C SDA） → 控制器的I2C SDA信号。
- 引脚5（I2C SCL） → 控制器的I2C SCL信号。
