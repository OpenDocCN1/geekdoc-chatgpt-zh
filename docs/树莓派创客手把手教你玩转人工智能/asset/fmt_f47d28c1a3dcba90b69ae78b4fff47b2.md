## 4.2 准备软件环境

### 4.2.1 准备系统tf卡

这个Kit需要在`Raspbian`操作系统含有`AIY`软件的特殊版本下运行，因此首先刷写tf卡的系统。

虽然Kit中的`MicroSD`卡已经闪存进了`AIY`系统图片，但是这些图片很有可能并不是最新的版本。所以在开始组装之前，强烈推荐从网上下载并安装最新版本的系统图片，并把它们闪存到`MicroSD`卡里面，否则很有可能会遇到一些旧的`bug`，也可能其中的一些示范代码并不适用。

具体步骤如下：

**步骤 01** 在`GitHub`的发布页面上下载最新的`.img.xz`文件。

**步骤 02** 用转换器把`MicroSD`卡连接到电脑上。

**步骤 03** 用`Etcher`这样的程序把`.img.xz`文件闪存到`MicroSD`卡上。`Etcher`是一个能在`Windows`、`Mac`和`Linux`系统上运行的免费程序。

闪存这些系统图片可能需要几分钟的时间。趁这个时间，你可以开始组装Kit。当你组装好之后，就可以把`MicroSD`卡装到上面，继续下一步了！

将系统通电之后，首先要获得`Voice Kit`的`IP`地址。有两种方法可以把你的Kit连接到`Wi-Fi`上并得到一个`IP`地址：一种是用`AIY Projects APP`，另一种是用一个显示器、鼠标和键盘。

> **提示**
>
> **IP地址**：互联网协议地址，是用来在网络中确定设备身份的4个字节的数字。每一个在网络下的设备——你的电脑、手机和`Voice Kit`都有自己专属的`IP`地址。不同的设备之间可以通过`IP`地址互相连接。

## 4.3 启动Google Assistant

### 4.3.1 远程连接Voice Kit

**步骤 01** 检查`Wi-Fi`连接。

确保你的电脑和Kit处在同一个无线网中，下一步将通过`SSH`远程连接到你的Kit并进行设置，让它能够与`Google Assistant`连接。

**步骤 02** 准备终端。

如果你知道如何设置终端，就直接用`pi@192.168.0.0`来开启一个`SSH`模块，其中的数字用你刚刚记录下来的`IP`地址代替，然后直接跳到下面的第七步。

如果你不知道怎么使用终端，首先下载一个`Chrome`浏览器和`Secure Shell Extension`扩展包，然后进行下一步。

终端是一个能够给你的树莓派发送命令的窗口。`SSH`让你能够远程进行终端操作。`SSH`客户端有很多，`Windows`平台上一般可以使用`Putty`这款小巧、强大且免费的`SSH`客户端，如图4-52所示。

![](EPUB/images/image_150.jpg)

**图4-52**

**步骤 03** 打开下载的扩展包。

安装好后，就可以打开扩展包了，如图4-53所示。

![](EPUB/images/image_151.jpg)

**图4-53**

如果你是在`Windows`、`Mac`或者`Linux`系统下使用的`Chrome`，就可以在工具栏中看到该扩展包的图标（地址栏的右边）。单击图标并在弹出的目录中选择`Connect Dialog`。

如果你是在`Chromebook`上用的`Chrome`浏览器，就可以在`app`目录中输入”secure shell app extension”。

**步骤 04** 连接树莓派。

在图4-54所示最上面的框中，输入`pi@IP地址`（`IP地址`是你记录的树莓派真实的`IP`地址），然后单击`port`框，再单击亮起的`[Enter] Connect`按键。如果没有连接，检查一下你输入的`IP`地址是否正确、你的树莓派和电脑连接的是否是同一个`Wi-Fi`。如果你重写或者更换了`SD`卡，那么需要删除并重新安装`Secure Shell Extension`。你可以右击工具栏上的标志，然后选择`Remove`选项，再按照上面的指南重新安装。

![](EPUB/images/image_152.jpg)

**图4-54**

**步骤 05** 给予许可。

单击`Allow`按钮，允许这个`SSH`拓展连接到你的树莓派上，如图4-55所示。

![](EPUB/images/image_153.jpg)

**图4-55**

**步骤 06** 继续连接。

`SSH extension`会让你确认上面显示的密钥和树莓派上存储的密钥相同。由于这是你第一次打开树莓派，因此所有罗列的数据都是全新的，并且这个操作是安全的。

`SSH`的目标就是安全，所以它需要确认你目前正在连接的电脑就是你想连的那一台。为了让确认过程简单一点，电脑会产生一串长数字并报告给`SSH`。`SSH`会把这些数字保存在一个安全的地方，然后通过对比确认这是你连接的那一台电脑。

当你确认之后，`SSH extension`就会把这个信息存储到浏览器上。之后你每次连接到树莓派的时候，它都会再次进行确认。现在，输入`yes`，然后按`Enter`键进行下一步，如图4-56所示。

![](EPUB/images/image_154.jpg)

**图4-56**

**步骤 07** 输入树莓派的密码。

默认密码是`raspberry`。当你输入的时候，密码是不可见的，如图4-57所示。

![](EPUB/images/image_155.jpg)

**图4-57**

如果输错了，屏幕上就会出现`Permission denied, please try again`或者`connection closed`。这时你需要按`R`键来重启连接。这时也可能会出现警戒线，用来告诉你系统已经保存了密钥，并且下一次这个扩展包会自动进行密钥的比对。
