## 6.2.2 运行“笑脸检测器”

### 1. 尝试使用“笑脸检测器”

将Vision Kit对准某个人的脸（或者自己的脸）以运行“笑脸检测器”样例程序。当摄像头检测到人脸时，按钮会亮起。

可以尝试先让使用者微笑，然后让他大笑，最后让他皱眉头。

笑脸检测器使用机器学习来检测一个人是在微笑还是愁眉苦脸及其程度。微笑的时候按钮会变成黄色，而愁眉苦脸则会使按钮变成蓝色。

如果表情特别夸张，就会有声音响起。如果摄像头检测到不止一个人脸，就会对所有人脸进行检测，并将所有人脸的分数加起来。

如果不起作用，可尝试将摄像头移到距离被测人脸一臂距离以外。当摄像头距离被测物太近时，可能会在检测的时候遇到问题。同时请确保被测的人脸所在环境光线良好，在以后所有的测试过程中都需要注意这一点。

### 2. 拍摄照片

在笑脸检测器运行过程中，你可以通过按钮随时抓拍照片。

如果是在摄像头检测到人脸时（即按钮被点亮时）拍摄的照片，那么将会保存两个版本的照片，第二个版本是标有笑脸分数的。

这些照片将会保存在SD卡上的`~/Pictures/`目录下。当下一步连接Vision Kit后，你就会知道如何获取这些照片。

## 6.3.1 在树莓派上显示一张图片

如果已经将Vision Kit连接至显示器，就可以在显示器上看到你拍的图片。（如果不是将Vision Kit直接连到显示器上，就不能看到。）

为了显示笑脸检测器抓拍到的图片，需要首先通过`cd`命令进入`~/Pictures`目录中。因此，在终端输入以下命令，然后按Enter键：

```
cd ~/Pictures
```

接着输入`ls`再按Enter键，查看目录中的文件内容。（提示：是字母l，而不是数字1。）你会看到一系列.jpeg后缀的图片，可以试着查看其中的一张。

输入以下命令，然后按Enter键，将`<filename>`替换为你想要打开的图片文件名（比如`2018-06-22_15.09.13.jpeg`，见图6-89）：

```
DISPLAY=:0 gpicview <filename>
```

连接到Vision Kit的显示器会打开一个新窗口，以展示此图片。

![](EPUB/images/image_411.jpg)
*图6-89*

> **提示**
>
> 如果你是通过显示器、鼠标和键盘直接连接Vision Kit，那么命令中将不需要`DISPLAY=:0`。

在终端关闭该图片展示的窗口，只需要按`Ctrl+C`组合键。

什么是`gpicview`？它是一个用于展示图片的应用程序。当你通过SSH连接到树莓派时需要输入`DISPLAY=:0`来告诉`gpicview`如何展示图片。

想了解更多有关终端命令行的知识，可以参考一些树莓派相关的指南：Conquer the Command Line和Linux Commands。显示器上如果没有显示任何东西，看起来像是休眠状态，可以尝试着按`Ctrl+C`组合键来中断之前的命令，返回命令提示符。然后输入`DISPLAY=:0 xset s activate`并按Enter键，再使用上边的命令来重新尝试展示图片。

### 步骤01 开始使用摄像头做图像分类

使用实时摄像头做图像分类的样例程序利用一个目标检测模型来识别物体。
