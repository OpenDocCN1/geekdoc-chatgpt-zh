### 3.4 可能会出现的一些问题

**Q1: 严格按照本wiki操作，驱动还是安装失败，怎么办？**

**A1:** 如果按照上述方法安装驱动均失败，请单击下面的固件安装`https://v2.fangcloud.com/share/7395fd138a1cab496fd4792fe5?folder_id=188000207913`。执行下面的步骤：第一，烧写下载好的固件，烧了固件后，记得换源；第二，要使用交互功能之前请在命令行输入`alexa-auth`或`dueros-auth`申请授权，授权成功后会在`/home/pi`目录下生成`.avs.json`文件，这时才能使用交互功能；第三，`/home/pi`目录下会有`respeaker`的例程文件夹，可以根据mic而使用相应的例程。烧录系统后要在`respeaker`目录下更新例程（可以在`respeaker`目录下执行`git pull origin master`命令）。

**Q2：用aplay可以听到声音，但是运行alexa/dueros不能听到声音。**

**A2：** 有3个播放器可供使用，即`mpv`、`mpg123`和`gstreamer`。`SpeechSynthesizer`和`Alerts`更适应`mpg123`。`AudioPlayer`适合`gstreamer` > `mpv` > `mpg123`。`Gstreamer`支持更多的音频格式，并在树莓派上运行良好。也可以使用环境变量`PLAYER`来指定`AudioPlayer`的播放器。可以尝试下面的命令来启用语音：

```
sudo apt install mpg123 PLAYER=mpg123 python ns_kws_doa_alexa_with_light.py
```

**Q3：运行DOA，说snowboy的时候没有响应。**

**A3：** 运行`audacity`，检查4个麦克风是否都有数据，如果其中有一个麦克风没有数据，就会没有响应。

**Q4：安装snowboy时出现不适合该平台的警告提醒。**

**A4：** 目前`snowboy`只能兼容`Python2`，所以在安装python的虚拟环境时请确保是`Python2`。

**Q5：有时sudo python file.py时会出现依赖问题。**

**A5：** 测试时发现`sudo`执行时默认从系统环境执行，而wiki中用到的依赖都是装在`~/env`下的，可以通过`sudo ~/env/bin/python file.py`来解决。

**Q6：在运行kws_doa.py时喊snowboy无响应。**

**A6：** 运行`audacity`，以确保4个频道良好。只要有一个频道没有数据，说`snowboy`时就会没有回复。

### 4.1.1 Voice Kit简介

谷歌推出了一款AIY Voice Kit，也就是AIY语音套件。这套套件可以用来搭建语言处理器，在连接到Google Assistant或者是在线语音转文字服务后，你可以用这套套件来向程序发送语音命令或者是直接问问题。Voice Kit的所有元件都可以被放在一个小小的硬纸板盒子中，并由树莓派来驱动。

购买套件后，你无须再购买任何东西，甚至连树莓派都包含在这个Voice Kit套件中了。
