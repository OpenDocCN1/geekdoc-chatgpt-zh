## 6.3.6 使用RASPISTILL拍照

### 步骤01：拍摄照片

接下来的样例程序将会展示如何使用一张已有的图片作为输入（而不是使用摄像头的视频流作为实时输入），因此你需要首先使用摄像头拍摄一张照片（或者在同一个目录下保存一张图片）。

输入以下命令（见图6-101）然后按回车键，以拍摄一张名为`image.jpg`的照片：

```
raspistill -w 1640 -h 922 -o image.jpg
```

![](EPUB/images/image_423.jpg)

**图6-101**

摄像头会等待5秒钟，然后拍摄一张照片。

应该如何命名图片呢？`image.jpg`是用命令在图片的左侧写入的名字。你可以任意命名，只要名字中只包含字母、数字、短线和下划线即可。文件后缀名应为`.jpg`，因为这个命令将图片按照JPEG格式保存。

这个命令的意思是什么？`raspistill`是一个利用树莓派摄像头模块来抓拍照片的命令。其中，`-w`和`-h`参数指定了图片的宽度和高度，`-o`参数指定了文件名。更多信息可参考`raspistill`文档。

输入`ls`然后按回车键来验证图片生成，你将会在当前目录下看到之前提到的图片文件，如图6-102所示。

## 6.4 维护和二次开发

### 6.4.1 关机和开机

当Vision Kit使用完毕后，在拔掉电源之前正确地关闭是非常重要的，这样可以保证你不会损坏SD卡。

如果通过显示器、键盘和鼠标直接连接Vision Kit，可以打开应用目录（桌面左上角的树莓派图标）然后单击关机，以将其关闭。

如果是使用`SSH`连接的，输入以下命令然后按Enter键：

```
sudo poweroff
```

稍等一会，树莓派的绿色LED灯会熄灭（通过标有SD卡的孔可以看到），表示Vision Kit关机了。然后可以安全地将电源从Vision Kit上拔掉。

如果想要开机并重新连接Vision Kit，只需要将电源重新插上，然后等待其启动（大约两分钟）。

如果通过显示器、键盘和鼠标直接连接Vision Kit，请确保在你插上电源之前它们是连接好的。一旦Kit启动了，就可以打开终端继续使用了。

如果是使用`SSH`连接的，在进行`SSH`连接之前需要等到绿色LED停止闪烁。一旦Kit启动了，可以通过Secure Shell Extension重新连接（可以查看连接Vision Kit中的相关步骤）。注意，可能需要通过APP重新匹配Vision Kit。

### 6.4.2 Python API库

为了使Vision Kit支持各种不同的功能，创建了可以做很多杂事、具有导出功能的Python API库。因此，使用视觉模型来进行推理、在被检测物体的周围标出方框，以及使用按钮、LED灯及额外的GPIO引脚等外设，这些事情能变得更加简单。

这些API在一个名为`aiy`的Python包中，在Vision Kit的系统镜像中已经预安装好了，请确保你安装的是最新版本的系统镜像。

想要了解更多API相关信息，请参考API指南。以下API可能会在项目中经常用到：

- `aiy.toneplayer`：一个用于压电蜂鸣器的简单旋律音乐播放器。
- `aiy.trackplayer`：一个用于压电蜂鸣器的基于跟踪器的音乐播放器。
- `aiy.vision.annotator`：一个用于在树莓派的摄像头预览画面上作图的标注类库。
- `aiy.vision.inference`：一个用于从树莓派一端向Vision Bonnet建立连接的推理引擎。
- `aiy.vision.models`：利用特定的图像分类与目标检测模型进行机器学习推理过程的模型集合。
- `aiy.board`：一个利用连接到Vision Bonnet按钮连接器上的按钮API。
- `aiy.leds`：一个用于控制特定的LED灯的API，比如按钮中的LED与隐私LED等。
- `aiy.pins`：用于Bonnet额外GPIO引脚的引脚定义库，与`gpiozero`共同使用。

当你从一个已有的示例程序开始，然后按照自己的想法进行一定的修改后，学习`aiy` Python API就会变得更简单。

上面已经展示了一些示例，并且已经安装到了你的Vision Kit上，保存到`~/AIY-projects-python/src/examples/`目录下。你也可以在GitHub上浏览这些样例，看到所有样例的源代码以及更多相关信息。

例如，想要了解更多关于`aiy.vision.inference`和`face_detection`两个API的内容，可以运行`face_detection.py`：

```
cd ~/AIY-projects-python/src/examples/vision
./face_detection.py --input image.jpg --output result.jpg
```

对于在`image.jpg`中检测到的每一张人脸，程序都会打印出一些信息，比如人脸的置信度得分及愉悦度分数等，同时会创建输出图像文件。输出图像在原有图像的每张人脸上用方框标识其位置。

想要了解工作原理，在树莓派上打开这个文件，或者在此查看源代码，然后开始修改代码。

如果你对硬件编程更感兴趣，比如按钮和伺服器，可以参考6.4.4小节，这里会包含一些其他的样例代码。

```

```
