
注意，当通过`I2C`与多个`Pixy2`通信时，你需要为每个`Pixy2`配置不同的`I2C`地址，以保证彼此之间不会产生冲突。可以制作“多压接线”，即可以使用10芯带状数据线并将N个10引脚IDC连接器压接到其上并连接到N个`Pixy2`上。也就是说，当选择`I2C`接口时，`Pixy2`的I/O连接器上的所有信号都会进入高阻态，不会相互干扰、浪费电源等。

## 3. UART

- `UART`接口有8个数据位和1个停止位，无奇偶校验，无握手协议。
- 可以在`PixyMon`的`Configure`对话框的`Interface`选项卡中配置波特率。
- `RX`信号（`引脚1`）为5V容限输入。
- `TX`信号（`引脚4`）为0至3.3V信号输出。
- 支持高达230 kbaud的波特率。
- `Pixy2`给出一个在`Arduino`上使用`UART`串行接口的示例。在`Arduino IDE`中选择`File→Examples→Pixy2→ccci2cuart`以运行该示例。同样需要特制数据线来连接。

以下介绍如何将控制器的`UART`接口连接到`Pixy2`：

- `引脚6` → 控制器的接地信号。
- `引脚1`（`UART RX`） → 控制器的`UART TX`输出。
- `引脚4`（`UART TX`） → 控制器的`UART RX`输入。

## 4. 模拟和数字输出

- `Pixy2`具有单个模拟（`DAC`）输出，因此模拟／数字输出有两种模式。
- 将数据输出端口设置为`analog/digital x`，会将所检测到物体中心的最大x值输出到I/O连接器的`引脚8`。
- 将数据输出端口设置为`analog/digital y`，会将所检测到物体中心的最大y值输出到I/O连接器的`引脚8`。
- 检测到物体时，`引脚1`变为高电平（3.3V）；反之，未检测到物体时，`引脚1`变为低电平（0V）。
- `Pixy2`的数字输出为0至3.3V逻辑输出，拉电流／灌电流为5mA。
- `Pixy2`的模拟（`DAC`）输出范围在0到3.3V之间，阻抗约为200欧姆。
- `Pixy2`的模拟（`DAC`）输出电压与图像中的物体位置成直接的线性相关关系（取决于模式）。
- 在`analog/digital x`模式下，如果物体位于图像的最左侧，那么模拟输出电压为0V；如果物体位于图像的最右侧，那么输出电压为3.3V（`PixyMon`透视图中的图像）。
- 在`analog/digital y`模式下，如果物体位于图像的最下方，那么模拟输出电压为0V；如果物体位于图像的最上端，那么输出电压为3.3V（`PixyMon`透视图中的图像）。

以下介绍将控制器的`ADC`和数字I/O连接到`Pixy2`：

- `引脚6` → 控制器的接地信号。
- `引脚8`（`DAC OUT`） → 控制器的一个`ADC`输入信号。
- `引脚1`（`GPIO0`） → 控制器的一个数字输入信号。

注意，`Pixy2`上的所有数字输出信号都是3.3V `CMOS`逻辑输出，所有数字输入信号均为5V容限。

## 5. 串行协议

对于`SPI`、`I2C`以及`UART`串行接口，其通信协议都完全相同。

- 该协议可以高效传输数据，且由二进制编码（非`ASCII`文本）。
- 所有数字都采用小端法（`little-endian`）存储，表示为二进制补码。
- 该协议使用简单的请求／响应模式进行数据交换。
- 保证所有请求的响应延迟都小于100微秒。

对于请求与响应两个方向的数据通信，`Pixy2`通过“数据包”（packets）完成通信。在不使用校验和的情况下，数据包的结构如下：

- `no_checksum_sync`（`0xc1ae`）占2个字节。
- `packet_type`占1个字节。
- `data_length`占1个字节。
- 数据共占`data_length`个字节。

在使用校验和时结构如下：

- `checksum_sync`（`0xc1af`）占2个字节。
- `packet_type`占1个字节。
- `data_length`占1个字节。
- `data_checksum`（数据字节总和）占2个字节。
- 数据共占`data_length`个字节。

与`Pixy2`的通信开始于发送请求数据包。举例来说，一个请求硬件／固件版本数据块的数据包（通常情况下发送请求数据包不使用校验和）如下：
