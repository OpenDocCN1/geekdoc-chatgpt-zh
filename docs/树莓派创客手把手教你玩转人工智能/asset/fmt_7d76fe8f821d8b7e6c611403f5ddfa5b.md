
# 5.3.3 白平衡

某些照明灯（如白炽灯）会发出微红色调的光，而另外一些（如荧光灯）则会有偏蓝色的光，这些光照会影响颜色标记。例如，在白炽灯下教 Pixy2 学会一个物品，然后挪到荧光灯的环境下，颜色标记也有可能失效。此时只能重新教授所有颜色标记，或者调整白平衡。

首次给 Pixy2 通电时，它会花 5 秒左右确定要使用的正确白平衡，然后将禁用自动白平衡。如果你想重新调整白平衡，请按住按钮，直到 LED 变成白色再松开。这个过程很快，所以需要做好准备。这时 Pixy2 处于自动白平衡模式，你可以在 Pixy2 前面放一张白纸来让它调整白平衡。调整白平衡仅需 2 或 3 秒，之后可以按下并释放按钮（像单击鼠标那样）。LED 闪烁表示调整成功，Pixy2 这时处于“再平衡”模式。

# 5.4 巡线功能详解

该程序执行线跟踪算法，适用于巡线机器人，为巡线的核心算法。

## 5.4.1 PixyMon 的“视图（View）”和“微调（Tuning）”选项卡

“视图（View）”选项卡包含 PixyMon 中线跟踪程序的不同种类的视图。要打开此菜单，必须首先在“程序（Program）”菜单中单击运行线跟踪程序，然后在菜单栏中单击“视图（View）”菜单，如图 5-44 所示。

![](EPUB/images/image_249.jpg)

**图 5-44**

- **主要特征，无背景（Primary features, no backgound）**：这种视图显示黑色背景，然后向量、交点和条形码特征显示为单独的图层。这种视图展示最少的 Pixy2 所检测到的内容，优点是不会很大程度上降低 Pixy2 的图像处理速度，而且可以使 Pixy2 以 60 帧每秒的最大速率来处理帧。在此种视图下，PixyMon 也通常会以 60 帧每秒的速度来展示图像。
- **主要特征（Primary features）**：除了将向量、交点和条形码特征显示为单独的图层之外，所显示的背景是黑白的。这种视图通常会降低 Pixy2 的处理速度，因为背景层通过 USB 传输需要一定的时间。
- **全部特征（All features）**：这种视图与上面的“主要特征（Primary features）”是一样的，但是添加了所有检测到（已过滤）的线条和交叉点。这种视图实质上呈现了线跟踪 API 中的 `getAllFeatures()` 函数所返回的所有数据。由于背景层和额外特征通过 USB 传输都需要时间，因此这种视图进一步降低了 Pixy2 的处理速度。

“微调（Tuning）”选项卡包含用于“微调”线跟踪算法精度的所有最有效参数。要打开此选项卡，必须首先在“程序”菜单中单击运行线跟踪程序，然后打开“配置”对话框（单击齿轮图标或选择“文件（File）”→“配置（Configure）”），然后选择“Pixy Parameters”下的“微调（Tuning）”选项卡（这应该是你打开“配置（Configure）”对话框时默认看到的第一个窗口），如图 5-45 所示。

- **边缘阈值（Edge threshold）**：通过调整此参数可以表示线检测算法。如果边缘阈值减小，就将检测到更多潜在的线条；如果边缘阈值增大，那么检测到的潜在线条将变少。如果 Pixy2 没有检测到你想要检测的线条，那么你可能需要调整此参数。
- **最大线宽（Maximum line width）**：此参数可以调整检测到的线条的最大宽度（以像素为单位），不会检测到较宽的线条。
- **最小线宽（Minimum line width）**：此参数可以调整检测到的线条的最小宽度（以像素为单位），不会检测到较窄的线条。
- **白色线条（white line）**：启用此参数会将 Pixy2 的线条检测算法从在浅色背景上显示暗色线条更改为在深色背景上显示亮的线条。
- **摄像头亮度（Camera brightness）**：无论程序是否正在运行，此参数都会出现在“微调（Tuning）”选项卡中。该参数对 Pixy 进行曝光设置，控制图像的亮度。“摄像头亮度（Camera brightness）”设置很重要，因为正确的曝光设置将获得最佳检测精度。

## 5.4.2 PixyMon 的“专家（Expert）”和“条形码标签（Barcode Labels）”选项卡

“专家（Expert）”选项卡包含用于调整线跟踪算法更高级的参数。要打开此选项卡，必须首先在“程序（Program）”菜单中单击运行线跟踪程序，然后打开“配置（Configure）”对话框（单击齿轮图标或选择“文件（File）”→“配置（Configure）”），然后选择“Pixy Parameters”下的“专家（Expert）”选项卡，如图 5-46 所示。

> **警告**
>
> 本选项卡中的参数均为高级参数，部分用于测试或调试，某些值还可能导致线跟踪算法出现奇怪的现象。Pixy2 不会因此而产生冒烟故障，但是最好要谨慎对待！

![](EPUB/images/image_251.jpg)

**图 5-46**

- **边缘距离（Edge distance）**：此参数调整边缘检测器之间的距离（以像素为单位）。增大边缘距离将有助于检测不太明显（更模糊）的边缘，但是会影响条形码检测和解码，也就是说，会使最小条形码增大。
- **线提取距离（Line extraction distance）**：此参数用于测试或调试，目前是无效的。
- **最大线比较（Maximum line compare）**：此参数可被视为用于在两帧之间跟踪线条的最大线速度参数。例如，一条线在一个帧周期内从帧的一侧移动到帧的另一侧（线速度非常大），那么这可能不是同一条线，因此该参数实际上是对线跟踪算法的完整性检查。减小该值会使算法对线速度的限制性更强，而增大该值会使算法对线速度的限制性降低。
- **最大合并距离（Maximum merge distance）**：此参数确定线跟踪算法搜索附近可与之形成交叉点的线条的距离。如果需要跟踪的线条较宽，就应增加此参数，直到可以准确检测到与此较宽线条形成的交点。
- **最小线长度（Minmum line length）**：可以使算法丢弃长度小于此参数的线条。
- **线过滤（Line filtering）**：增大此参数会对结果做更多的过滤操作，并且可以减少线检测中的误报情况，但是在展示新检测到的线条时可能会有额外的延迟。
- **交叉点过滤（Intersection filtering）**：增大此参数会对结果做更多的过滤操作，并且可以减少交叉点检测中的误报情况，但是在展示新检测到的交叉点时可能会产生额外的延迟。
- **条形码过滤（Barcode filtering）**：增大此参数会对结果做更多的过滤操作，并且可以减少条形码检测中的误报情况，但是在展示新检测到的条形码时可能会产生额外的延迟。
- **默认转弯角度（Default turn angle）**：此参数设置算法在遇到交叉点时选择的路径，算法将选择最接近此参数指定角度的路径。转弯角度以度为单位，举例来说，`0` 表示笔直向前，左转弯为 `90`，右转弯为 `-90`，可以设置为任何有效的角度值（有效角度值介于 `-180` 和 `180` 之间）。此参数通常设置为 `0`，也就是说在没有其他指示的情况下，遇到交叉点时直接直行，可以通过 API 中的 `setNextTurn()` 函数来指示算法。
- **延迟转弯（Delayed turn）**：此参数使算法在遇到交叉点时停止自动选择路径。客户端程序在交叉点离开帧画面之前通过 API 中的 `setNextTurn()` 来指示前进的路径。这是一个额外的高级选择。当你在看到下一个交叉点（知道交叉点的支路数目或者角度等）之前不知道如何转弯时，可能需要这个参数。设置此参数也是很有用且有趣的，因为 PixyMon 会因为不知道如何转向而将交叉点标记为“3 路交叉口”“4 路交叉口”等。
- **手动向量选择（Manual vector select）**：当算法初始化时，需要确定将哪一条线作为“向量”，即你要跟踪的线。算法将根据它认为较有代表性的某些特征来自动选择向量，例如与帧底部相交的线或接近垂直的线。你可以通过启用此参数来绕过选择过程，然后算法通过 API 中的 `setVector()` 函数来设置向量。
- **默认程序（Default program）**：无论当前运行的程序如何，此参数都会显示在“专家”选项卡中。此参数将会设置通电启动时所运行的程序，可用的程序可以在下拉菜单中看到。
- **启动时程序选择（Program select on power-up）**：无论当前运行的程序如何，此参数都会显示在“专家”选项卡中。选择此参数将会在允许通电启动时通过按钮来选择运行的程序。
- **调试（Debug）**：无论当前运行的程序如何，此参数都会显示在“专家”选项卡中。此参数设置 Pixy2 中的调试等级，将该值设置为 `0` 表示不显示调试信息。
