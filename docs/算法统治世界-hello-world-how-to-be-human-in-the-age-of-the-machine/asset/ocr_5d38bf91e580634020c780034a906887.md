# 致谢

我想，对于有些人来说，写作从来不是难事。你知道的，就是那种人——天还没亮就起床，午饭之前能写完一整章内容，还经常忘记吃晚饭，因为文思泉涌，无阻阻挡，以至于连时间都忘了。

我肯定不是这类人。

在写这本书的过程中，我每天都在“打仗”：一边摒弃想要瘫坐在沙发上吃薯片看网飞的懒惰想法，一边抵御因攻读博士学位而对未来产生的担忧与恐惧。其实这本书不是写出来的，而是从我的身体里“抽”出来的，有时真的需要撕打和喊叫。

所以，我特别感谢一直以来帮助过我的人。我可遇不可求的出版团队，在过去的一年里无私奉献了大量时间和宝贵建议：苏珊娜·韦德森（Susanna Wadeson）、琼杜（Quynh Do）、克莱尔·康拉德（Claire Conrad）、艾玛·帕里（Emma Parry）、吉莉安·萨默斯凯尔斯（Gillian Somerscales）、艾玛·伯顿（Emma Burton）、苏菲·克里斯托弗（Sophie Christopher）、汉娜·布莱特（Hannah Bright）、卡罗琳·塞内（Caroline Saine），以及 Janklow&Nesbit 联合公司、Transworld 出版公司和 Norton 出版公司的所有人员，感谢你们的默默付出。同时，还有苏·里德尔（Sue Rider）、凯特·比（Kat Bee）
