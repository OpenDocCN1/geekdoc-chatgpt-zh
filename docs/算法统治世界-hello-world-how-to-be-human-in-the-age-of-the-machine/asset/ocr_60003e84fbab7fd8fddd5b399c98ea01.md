事物的人（虽然有时起些作用，但开会时弹出育儿套装广告，确实会让人抓狂）。

此类算法还能够自动分类和删除优兔中不适宜的内容，为照片贴上场景标签，以及扫描手写内容并将页面上的每一处标记以字母表的形式进行分类。

# 关联：找到联系

关联是指找出并标记不同事物之间的关系。用于交友的算法（比如 OkCupid）之核心就是关联；找出会员之间的联系，从而建立配对。亚马逊购物网的推荐功能采用了类似的概念——将你的购物喜好与过往顾客联系起来，进而导出比较有趣的导购建议。比如，红迪网（Reddit）用户 Kerbobocat 在亚马逊上订购了一支棒球棍，结果收到一条导购建议：“您可能会喜欢这个巴拉克拉法头套。”¹¹

# 筛选：留下最重要的内容

算法经常需要去除一些信息，以便突出重点，就像从嘈杂的环境中分辨出关键信号。实际生活中时常会出现这种情况；语音识别算法（比如 Siri、Alexa 和小娜所使用的算法）首先需要将你的语音从背景音中“过滤”出来，才能进一步破译语音内容。还有些情况则属于“深层次”筛选：脸书和推特（Twitter）会根据你的已知兴趣爱好，为你定做专属的信息推送。
