# 合同的概念

## 第十章

关于未来的欧盟数字经济法律框架：基于竞争视角对“所有权和获取权”辩论的回应

约瑟夫·德雷克斯尔[^((1))](#chapter5.xhtml#jz_01_1160)

### 一、引言

数字经济的商业模式不再局限于电子商务、搜索引擎和社交平台。嵌入在机器、车辆、家用设备和其他许多产品中的传感器以预见性维护、更高的安全性和舒适性以及节省成本的形式为客户提供了新的优势。此外，通过数据分析，传感器生成的数据可以帮助产生第三方（国家、其他经营者和客户）感兴趣的其他知识。总之，收集和处理此类数据有可能给几乎所有的经济部门带来根本性转变。下一步的数字化不仅会影响产品的制造方式以及未来车辆的运行方式，也会给个人和社会的福祉带来重大进步。

毋庸置疑，纯粹的国内法路径是不足以为这种新的数据经济建立法律框架的。[¹](#chapter5.xhtml#wz_01_0635)通过网络，可以在任何地方实时存储、处理和利用数据。尤其是在欧洲，自动驾驶必须实现跨国界驾驶。令人欣慰的是，欧盟委员会已主动探索了为数据经济创建欧盟法律框架的可能方法。

欧盟委员会于2015年5月首次宣布了其“数据自由流动”计划，这是其关于“数字单一市场”相关报告的一部分。[²](#chapter5.xhtml#wz_01_0636)为了使欧盟能够“保持竞争力，维持强大的工业基础并实现向智能工业和服务业经济的转型”。[³](#chapter5.xhtml#wz_01_0637)欧盟委员会表示将会尽力解决“正在出现的数据所有权和数据获取问题”。[⁴](#chapter5.xhtml#wz_01_0638)
