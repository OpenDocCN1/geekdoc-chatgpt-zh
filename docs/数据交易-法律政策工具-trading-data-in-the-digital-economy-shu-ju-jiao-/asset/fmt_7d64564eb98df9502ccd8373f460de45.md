
# 数据所有权、数据生产者权与数据获取权：欧盟竞争法视角的分析

这一表态在欧盟（特别是德国）引发了有关数据所有权问题的学术讨论和公共辩论。德国的政府、工业和研究结构已经在2011年建立了“工业4.0”平台，作为面对第四次工业革命挑战的联合倡议，包括在制造过程中整合信息和电信技术。[⁵](#chapter5.xhtml#wz_01_0639)辩论之所以如此集中于数据所有权而非数据获取权的原因主要体现在以下三个方面：首先，作为快速增长的公共利益的一部分，除了将数据描述为最有价值的资源和“21世纪的石油”之外，[⁶](#chapter5.xhtml#wz_01_0640)媒体已经开始询问“谁应该拥有数据”？因为购买和使用智能产品的人逐渐增多，因此这个问题引起了公众的广泛关注，所有作为“数据生产者”的公民都有资格成为数据的潜在所有者。其次，德国学者已经对数据所有权的可能设计进行了重大研究。[⁷](#chapter5.xhtml#wz_01_0641)最后，2016年年底之前一直负责数据自由流动计划的欧盟专员奥廷格（Oettinger）用德语发表公开声明，留下了一种欧盟委员会将认真考虑通过有关数据所有权立法的印象。[⁸](#chapter5.xhtml#wz_01_0642)然而，与此同时，越来越多的学者警告不要在数据中引入新的财产权。[⁹](#chapter5.xhtml#wz_01_0643)这些学者对这种权利的经济合理性及其对数据经济学的潜在负面影响表示怀疑。最引人注目的是，德国工业界很快对引入这种权利的需求提出了质疑。[^(10)](#chapter5.xhtml#wz_01_0644)

面对2015年发布相关报告之后引发的讨论，2017年1月10日欧盟委员会仍然在报告中提出应对数据所有权的问题。[^(11)](#chapter5.xhtml#wz_01_0645)然而，欧盟委员会采取了一种相当令人惊讶的方法。由于财产作为排他性权利的性质，通常认为这种权利会增加对数据获取的障碍，但欧盟委员会现在讨论承认潜在的“数据生产者权”是增加数据获取的一种手段，[^(12)](#chapter5.xhtml#wz_01_0646)从而将2015年的“所有权和使用权”辩论变成了关于“获取数据的所有权”议题。

委员会的观点依靠两个前提：一是数据的自由流通始终是好的；二是有必要为智能产品用户的利益解锁数据。本文将采用更具原则性的面向竞争的方法来分析这些前提，以及委员会对数据生产者权的考量。[^(13)](#chapter5.xhtml#wz_01_0647)这种方法的前提是，在市场经济中，竞争和交易通常会导致最有效的利用资源。因此，从经济的角度来看，干预措施，包括采用新的知识产权，只有当它有助于矫正一个可识别的市场失灵时，才被授权和合理化。就此而言，欧盟委员会假定某些情况下需要解锁数据的策略是正确的。然而，本文反对将数据生产者权作为具有物权属性的一种新的知识产权而提出，并建议考虑更有针对性，甚至更有效的数据获取权。[^(14)](#chapter5.xhtml#wz_01_0648)还应注意的是，数据的自由流动并不总是那么有效。因此，本文首先研究当前的竞争形势以及由此引起的竞争问题。然后讨论针对这些问题的可能解决方案，包括数据生产者权以及作为替代方案的数据获取权。最后对过多的数据流通引起竞争问题的情况进行分析。

## 二、当前的竞争形势和可能的竞争问题

一般而言，知识产权有望为创新提供动力。然而，似乎并不需要更多的动力来生成数据。由智能产品的传感器收集的数据，也是如此。当前，公司将大量投资用于开发嵌入式传感器的智能产品，因为他们将制造业和物联网的转型视为一种破坏性创新，迫使不适应该过程的公司退出市场。

然而，在这种竞争的环境中，制造商还需要说服客户购买其智能产品。在这方面，必须在工业客户和最终用户之间进行区分。

对于工业客户而言，第四次工业革命是工艺和产品创新方面的重要一步。一方面，嵌入在智能机器中的传感器可以进行预测性维护，从而帮助在其工厂中使用该机器的生产商避免遇到生产停顿。因此，智能机器降低了生产成本（工艺创新）。同时，机器传感器旨在识别甚至避免所制造产品的缺陷，从而提高产品质量（产品创新）。因此，在工厂中使用智能机器将有助于制造商在下游产品市场中更好的竞争。

当然，还存在这样一种担忧，即嵌入传感器的机器的供应商可能会窥探工业客户的商业秘密。但是，如果机器的供应商不是下游产品市场的竞争者，那么该供应商在盗用客户的商业秘密方面就不会有特殊的自身利益。反之，客户对供应商的信任以及供应商对客户商业秘密的尊重应该成为智能机器销售的一个重要竞争参数。同时，一个稳定和有效的商业秘密保护框架是新数据经济运作的关键。[^(15)](#chapter5.xhtml#wz_01_0649)

就最终用户接受智能产品而言，情况更加困难。他们需要使产品具有更高的实用性，例如，安全性（自动驾驶）、舒适性和节省成本（智能家居）。

此外，最终用户可能会担心敏感个人数据收集，包括在用药期间监测身体功能的可穿戴设备收集的健康数据以及汽车或家用设备收集的数据。因此，为了说服消费者购买产品，不能像搜索引擎或社交平台的运营商提供“免费服务”以获取大量消费者数据，智能消费产品的供应商应保证高水平的数据保护。因此，需要一个稳定有效的数据保护法律框架来建立最终消费者对数据经济的信任。同样，立法机构应考虑到收集数据的新法律义务对消费者购买智能产品的意愿可能产生的负面影响。[^(16)](#chapter5.xhtml#wz_01_0650)

总之，似乎不需要数据所有权来激励将智能产品推向市场。然而，也可能有其他原因，例如需要为利用传感器生成的数据而启用后续市场。仅当可以将第三方排除在获取和使用该数据之外时，数据许可市场才会出现。但是，这种独占性不一定取决于将数据所有权视为一种物权属性的权利。智能产品的制造商已经对此类产品生成的数据进行了事实控制，并可以通过技术保护措施保护其数据集免遭未经授权的获取。[^(17)](#chapter5.xhtml#wz_01_0651)这种情况使作为事实上数据持有者的制造商能够收取向第三方授予数据获取权的费用。根据数据许可合同，数据持有人能够规范被许可人以何种方式使用数据，包括对被许可人进一步授予第三者获取权限的限制。简而言之，事实控制将事实数据上的持有者置于与数据独占权人非常相似的位置，以实现数据交易。按照欧盟委员会的说法，如果确实无法充分利用现有的数据孤岛，[^(18)](#chapter5.xhtml#wz_01_0652)造成这种现象的原因很可能不是缺乏法律保护，而是当事方难以解决、评估数据集的效用和价值，从而无法确定获取[^(19)](#chapter5.xhtml#wz_01_0653)以及出现技术障碍（例如缺乏数据格式的互用性）时应支付的适当价格。[^(20)](#chapter5.xhtml#wz_01_0654)这并不排除需要额外的保护，特别是对侵权性规避行为的责任规定。[^(21)](#chapter5.xhtml#wz_01_0655)

如果对传感器生成的机器数据的事实控制足以缔结关于数据利用的合同，那么在讨论是否需要额外的数据产权之前，法律应该首先评估合同法的运作。从竞争政策的角度来看，这里的问题是相关的产品市场是否会发挥作用，或者反过来说，它们是否有可能受到反竞争行为的影响。

对相关产品市场运作的分析应该再次从智能产品制造商与此类产品购买者达成的协议开始。实际上，销售智能产品的合同与传统产品的合同确实有很大不同。产品的数字化从根本上改变了工业化商业模式的格局。虽然出售汽车的交易旨在为购买者提供汽车的所有权和财产，但也许还附有一些保护购买者免受损坏的额外保证，就自动驾驶和无人驾驶而言，进行汽车交易将不再或者不仅仅依靠纯粹的销售合同，而是包括制造商在预测性维护和与安全相关的服务，[^(22)](#chapter5.xhtml#wz_01_0656)或者可以说，是关于操作汽车的全面服务义务。同样，制造商也可以出售智能家居设备，将其作为更全局的基于软件的家庭管理系统的一部分，该系统通过计算机连接家庭的不同设备。每当需要重新装满洗衣机或冰箱时，该计算机甚至可以从与设备生产商合作的供应商处订购其他产品，例如洗衣粉和食品。电力、能源或水的提供商将开始提供他们的产品，作为基于数据的设施管理系统的组成部分，制药公司将通过智能穿戴设备监控患者的身体功能，从而在用药过程中转变为更全面的医疗保健服务的提供商。这表明，作为与智能产品相关的数据驱动型业务模型的一种表达，简单的商品销售合同将被捆绑大量商品和服务的“系统合同”所取代，并可能将客户锁定到此类系统的提供者。

因此，与智能产品有关的新商业模式具有将竞争对手排斥在市场之外的潜力。从经典竞争法评估的角度来看，第一个问题涉及相关产品。竞争法是否应将具有所有要素的“系统”本身视为相关产品，还是应从独特产品的意义上将不同要素区分开？在后一种情况下，这种依赖智能产品的数字系统的报价可被视为潜在的反竞争捆绑。

当然，与往常一样，竞争法必须适用于个案的具体事实。与冰箱相关的送货到家服务将被视为一种单独的产品，因为此类服务也是独立提供的，与智能家居设备无关。同样，如果提供了有预测性维护服务的智能产品销售合同，则在依赖维修者无法访问该产品中嵌入的传感器收集数据的情况下，可能会产生排他性影响。[^(23)](#chapter5.xhtml#wz_01_0657)在这些情况下，对反竞争的关注既涉及对竞争者的排他性影响，也涉及对客户的锁定，因为客户在进行了大量的投资之后，不太可能再从竞争者那里购买产品。

然而，潜在的反竞争影响不仅与智能产品市场的竞争以及此类产品的维修有关。智能产品制造商的商业模式也可能会将独立的数据分析服务提供商排除在市场之外。如果电力、能源和水的供应商将设施管理服务与此类供应联系在一起，那么数字设施管理服务的独立供应商将很难进入市场。特别是许多客户通常会更喜欢购买他们所购买的各种智能产品。不同制造商有不同的需求，但仍希望以数字方式连接这些设备并在内部进行整体数字管理，或者将其交给独立的数据服务提供商。例如，工厂的经营者从不同的制造商那里购买智能机器、农民使用不同品牌的农用机器、希望获得智能家居所有好处但仍重视更广泛意义上的智能家居的房主。最后，患者需要多种疾病的药物，并由其信任的医生或医院进行监控。显然，为了患者的利益，该医生需要获取任何控制患者身体健康的制药公司收集的数据。

确实，当为了“解锁数据”，讨论潜在的数据生产者权时，要考虑智能产品的购买者或用户的利益，[^(24)](#chapter5.xhtml#wz_01_0658)欧盟委员会对此已有所关注。

## 三、如何解锁数据：为什么数据获取权应优先于数据生产者权？

为了解决这些竞争问题，可以讨论不同的解决方案，部分解决方案也在欧盟委员会的考量范畴之内。

### （一）合同法路径的局限性

第一种方法是通过控制标准合同条款的规则为智能产品的购买者提供帮助。欧盟委员会也考虑了这种可能性，[^(25)](#chapter5.xhtml#wz_01_0659)倡导修改《不公平条款指令》。[^(26)](#chapter5.xhtml#wz_01_0660)智能产品（尤其是机器）的购买者通常是工业用户，但是，该指令的应用范围必须从B2C交易扩展到B2B交易。

然而，这依然不足以解决问题。该指令的运作还需要默示的合同规则，这些规则可以作为公平性标准的基准，但此类规则尚不完善。特别是，[^(27)](#chapter5.xhtml#wz_01_0661)欧盟委员会在数字内容指令提案中通过为消费者合同制定强制性合同规则，来保持欧盟法律在合同法中的经典做法。因此，本指令的适用范围需要扩大，也许可以增加另一条规则，根据这条规则，本指令的规则也可以作为非强制性规则适用。

此外，对于针对商品[^(28)](#chapter5.xhtml#wz_01_0662)的交付和销售，以及与该商品相关的服务的合同，数字内容指令提案的适用范围还不清楚。最后，必须怀疑欧盟委员会提出的规则是否能充分保护智能产品的购买者。数字内容指令提案仅在合同[^(29)](#chapter5.xhtml#wz_01_0663)终止的情况下才授予消费者数据可携带性权利，鉴于上述竞争问题，购买者在使用智能手机时尤其需要获取数据产品。

即使要在这方面进一步发展数字内容指令，依靠标准合同条款控制的一般方法也有其他缺点。尽管有关不公平合同条款的法律试图纠正议价能力分配不均的情况，而且在这方面非常灵活，[^(30)](#chapter5.xhtml#wz_01_0664)但它仅保护智能产品的直接购买者。因此，合同法路径面临以下障碍：用户通常不是直接从制造商那里购买智能产品，而是从零售商那里购买，甚至从将智能产品作为二手产品转售的人那里购买。此外，在某些情况下，智能产品从甚至没有通过合同链与原始制造商建立联系的人那里收集数据，但是这些人仍然对获取智能产品收集的数据具有合法利益。这种情况的一个例子是农民使用相关机器产生的土地数据是由独立的农业服务提供者的机器收集的。

这就产生了如下问题：被收集数据的人和对解锁数据有合法利益的人，如何能相对于制造商有权为自己或数据分析服务的第三方提供者获取这些数据。这似乎就是委员会正在考虑的数据生产者权的情况。

### （二）为什么数据生产者权无法促进数据获取？

除了“数据生产者”一词似乎是被误解的这个事实（毕竟，数据是根据商业模型和智能产品“生产”的，这两者都是由制造商实施和开发的），作为物权属性的数据生产者权，一方面不足以弥补议价能力分配不均的根本问题，另一方面又通过向数据生产者提供阻止生产者进行交易的权利，使得第三方可以获取其数据集。

关于第一个问题，委员会忽视了这样一个事实，即作为产权持有人的数据生产者将总是能够像这样指定数据权利，或者免费向智能产品的制造商免费授予专有许可。因此，在制造商拥有较高议价能力的情况下，数据生产者权将无法实现欧盟委员会创设该权利的预期目标。[^(31)](#chapter5.xhtml#wz_01_0665)

关于第二个问题，委员会忽略了这样一个事实，即并非在所有情况下，制造商都将拥有较强的市场支配力。例如，在一个强大的智能产品工业购买者的情况下，这个购买者很可能依靠其数据生产者的权利来限制供应商将其数据集商业化的能力，并限制第三方对这些数据集的获取。在这种情况下，应注意的是，由于该数据集的用途差异较大，出售给消费者的所有智能产品产生的，并且由制造商的数据集聚集的数据，必须被认为是一个独特的产品，从竞争法的角度来看，这是无法被智能产品的个人购买者控制的数据集所替代的。因此，欧盟立法机构应该特别避免对这些数据集形成障碍，它们通常会涉及特定的公共利益。

在任何情况下，引入数据生产者权都会产生复杂的权利清除问题。无论何时，只要获取数据，都会发现数据集包含的数据的持有者不是数据的生产者，例如，如果立法机关承认数据生产者对汽车持有人关于汽车传感器生成数据的权利，当第三方寻求获取汽车制造商享有的更大、更有价值的数据集时，将冒着侵犯此类权利的风险。这表明，这种权利的引入很容易成为建立一个自动驾驶功能系统的严重障碍，这在很大程度上依赖于许多制造商和许多其他数据提供者之间的数据共享。

### （三）支持不可撤销的数据获取权

实际上可以促进数据获取的数据生产者权的替代方法是承认不可放弃的数据获取权。[^(32)](#chapter5.xhtml#wz_01_0666)

这种权利的优点包括：第一，数据获取权更具针对性，因为它们可以响应潜在的市场失灵。与以物权形式构造的数据生产者权相比，它不会对下游数据市场中的数据商业化产生任何障碍。例如，数据获取权可以使农民有权连接不同品牌的不同农机收集的数据来经营其农场，而不会以任何方式限制这些机器的制造商从所有农机收集的汇总数据并将其商业化的能力。数据获取权将特别增加对公共机构数据的获取（例如出于环境保护的数据获取）。实际上，立法机关面临的也仅仅是数据获取问题，因此它没有理由通过采用新的财产权而超越获取权，这会在没有任何额外利益的情况下对市场产生额外的排他性影响。[^(33)](#chapter5.xhtml#wz_01_0667)

第二，这种使用权的不可撤销性将保证这种权利不会因农民和机器制造商之间的合同协议而被搁置。

第三，可以并且应该将数据获取权授予在数据获取方面具有合法利益的人。作为法定的非合同权利，它不一定必须归属于产品的直接购买者，也并不必然归属于产品的使用者。问题是谁直接关注数据收集并需要获取该数据，如果数据是由独立的农业服务提供者拥有的机器收集的，该主体也可能是农民。[^(34)](#chapter5.xhtml#wz_01_0668)这和特殊利益限制了数据获取权的范围，应将其限定于经营农场或家庭使用的目的之内，而不是出于向第三方进行商业化应用数据的目的。但是，数据获取权不应取决于有权获取数据的人是在内部进行数据分析还是将其外包给独立的数据分析机构。因此，数据获取权应包括要求制造商将直接获取权授予第三方以提供这种服务。[^(35)](#chapter5.xhtml#wz_01_0669)

第四，可以通过积极方式来规范数据获取权，即通过对授予此类权利设定具体要求的方式进行规范。从立法技术的角度来看，这是一个明显的优势。在讨论数据生产者权时，欧盟委员会意识到这种权利可能会走得太远，因此指出该权利的授予需要设定具体的例外和限制情形。[^(36)](#chapter5.xhtml#wz_01_0670)但是，这并不是一件容易的事，因为立法机关必须预见所有不同的情况，而物权化的权利显然不利于进行这种预见。相比之下，数据获取权可以避免过度保护的问题。[^(37)](#chapter5.xhtml#wz_01_0671)

第五，对获取权的承认也符合竞争法原则。它会针对制造商极有可能出于将竞争对手排除在市场之外的目的而拒绝授予数据获取权的强烈动机做出响应。当然，在任何情况下，竞争法的执行都可以作为一种替代选择。但是，鉴于在每个案例中都需要证明市场支配地位，私主体之间的竞争法执行通常会面临繁重的证明负担，在案件数量较大的情况下该问题会更加突出。[^(38)](#chapter5.xhtml#wz_01_0672)相反，如果制造商对锁闭市场竞争不感兴趣，数据获取权不会造成任何损害，因为在智能产品市场的竞争压力下，制造商无论如何都会愿意授予数据获取权，甚至可能免费授权。
