# 第五节 关于数据的财产权？

**丹尼尔·齐默**[^1]

## 一、概述

梅赛德斯新款E级轿车的驾驶员将享受到许多便利：该车配备了摄像头和雷达系统，使其能够根据相应的速度限制调整车速，并与前车保持预先设定的距离。路上的突然障碍物会触发紧急刹车或协助驾驶员小心躲避障碍物。当汽车内置的雨水传感器发出降水信号时，挡风玻璃上的雨刷会自动启动。[¹](#chapter3_1.xhtml#wz_01_0245)

这些操作都会生成数据，其中大部分数据通过加密链接发送给汽车制造商。加密是为了保护驾驶人信息不被泄露，例如，敏感的位置数据不被泄露给第三方。但这也符合制造商的利益，因为如果只有汽车制造商能够获取客户的数据，那么只有它才能将这些数据用于生产经营目的。

制造商与导航服务提供商TomTom合作，利用汽车移动的数据为驾驶员提供尽可能准确的路线建议，并在交通堵塞时发出警告。此外，戴姆勒公司希望利用其客户未来驾驶习惯的数据，允许其内部汽车保险公司在个人基础上计算保险费：那些小心驾驶的人付的钱比其他被保险人更少。[²](#chapter3_1.xhtml#wz_01_0246)此外，汽车制造商可以从汽车的维修状态信息中获利：当汽车需要保养时，制造商的内部车行可以向车主发送维修报价。来自整个车群的雨量传感器数据的分析在未来可能比最好的常规气象服务提供更准确的天气预报。

不少市场主体都对所谓的用户数据感兴趣：除了汽车制造商的保险公司之外，其他保险公司也可能希望向驾驶人提供个性化报价。只要制造商将收集到的数据保密，这种竞争性的报价是不可能的——除非第二家保险公司能够说服潜在客户在汽车上安装第二个数据传输器，或者通过驾驶人的智能手机发送永久性的移动数据流。此外，不受某个制造商约束的独立车行可能对获取汽车传输的数据有兴趣，以便提供自己的维修服务。

对于公司来说，控制收集到的数据变得越来越困难，因为这些数据通常是无线传输的，比如我们在前文第一个例子中提到的汽车数据。在“工业4.0”的发展过程中，越来越多的不同公司制造的技术仪器相互之间开始进行数字化通信。数据不是在收集数据的公司住所中保存，而是存储在“云端”。此外，许多公司引进外部服务提供商来处理他们的数据。由于第三方获取数据的可能性越来越大，业内人士开始呼吁对数据创设“财产权”。

## 二、讨论

最近几个月，专家们同行业协会及学术界在布鲁塞尔和柏林举行会议，就数据方面建立产权的利弊交换了意见。这种讨论不仅是为了找到最适当的方法以解决具有挑战性的法律困境。它还涉及有形的经济利益：由于数据在工业、贸易和服务业的潜在商业用途，许多评论员将其视为21世纪最重要的商品。[³](#chapter3_1.xhtml#wz_01_0247)
