# 专题讨论

## 第十三章

### 从错误中学习：欧盟委员会对数据库特殊权利和数据生产者权正当性论证的相似性

朱莉娅·雷达[^((1))](#chapter6.xhtml#jz_01_1163)

### 一、引言

在2017年1月发布的题为《打造欧洲数据经济》[¹](#chapter6.xhtml#wz_01_0818)的报告中，欧盟委员会考虑引入“数据生产者权”，并将其作为解决数据获取问题的六个政策选项之一。这种潜在的新型权利，在欧盟委员会附带的公众咨询[²](#chapter6.xhtml#wz_01_0819)中被描述为“一种特殊的知识产权”，已经成为很多学术讨论的主题。[³](#chapter6.xhtml#wz_01_0820)本文的目的既不是要回顾这些讨论，也不是要对新的特殊知识产权的潜在影响进行经验性评估。本文旨在对欧盟委员会在考虑此类政策干预时提出的论点进行比较研究，以揭示其在既往创设此类权利的分析中存在的缺陷，从而对引入新的独占性权利提供借鉴。
