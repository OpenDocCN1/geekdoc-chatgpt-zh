# 知识图谱选型与实施指南

| 指标体系 | 指标项（权重） | 指标子项 |
| :--- | :--- | :--- |
| 基础保障层面（20分） | 人员储备（4分） | • 研发人员<br>• 实施人员<br>• 运维人员<br>• 业务人员（建模人员等） |
| | 硬件资源储备（4分） | • 软硬件基础设施（运算设备、云、大数据设施等） |
| | 专业知识储备（4分） | • 前期预研情况（前期咨询、预研项目开展数量等）<br>• 业务人员对 IT 系统的理解 |
| | 信息化建设基础（5分） | • 信息化系统数量<br>• 信息化系统处理业务量占比<br>• 企业知识库建设情况<br>• 现有的基础环境<br>• 现有的软件基础工具（建模工具、图数据库等） |
| | 资格资质（3分） | • IT 实施资质<br>• 系统集成资质，如安全、管理等认证（可选） |
| 实施层面（25分） | 验证评估能力（5分） | • 专业知识<br>• 硬件资源评估<br>• 信息化建设能力评估<br>• 知识质量评估 |
| | 信息化系统建设能力（10分） | • 信息化系统规划能力<br>• 信息化系统开发能力<br>• 信息化系统管理能力 |
| | 系统集成能力（5分） | • 系统集成经验<br>• 系统集成和管理专业人员 |
| | 运维能力（3分） | • IT 系统运维能力<br>• 知识维护与管理能力 |
| | 风险管控能力（2分） | • 技术风险管控能力<br>• 系统风险管控能力<br>• 人员风险管控能力<br>• 外部风险管控能力 |
