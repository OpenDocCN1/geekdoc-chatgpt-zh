# (1) 定义评估准则

定义评估准则是系统评估与验收阶段的基础活动，主要包括确定评估范围、定义评估指标、确定验收文档、组织管理等四项任务。

+   确定评估范围要求业务人员确定系统评估的维度（如功能、性能、安全、集成、部署等），系统需在确定的评估维度下达到用户的预期。
