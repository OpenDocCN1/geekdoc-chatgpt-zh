# 表5-1 基础能力评估指标构成

| 指标体系 | 指标项（权重） | 指标子项 |
|---|---|---|
| 业务层面（10分） | 战略愿景（2分） | 时间成本估计<br>市场定位<br>战略规划<br>制度保障 |
| 业务层面（10分） | 业务需求（2分） | 现有业务中对数据/知识大量依赖的场景数量<br>知识沉淀情况<br>应用迫切性 |
| 业务层面（10分） | 资源安排（2分） | 经费投入规划<br>时间投入规划<br>人力投入规划 |
| 业务层面（10分） | 行业地位（2分） | 在行业内的水平和影响力 |
| 业务层面（10分） | 行业趋势和产业政策（2分） | 知识图谱应用趋势（行业国内外应用案例）<br>产业政策 |
| 数据层面（20分） | 数据储备（5分） | 数据维度<br>数据时效性<br>数据规模<br>已有数据库数量<br>非结构化数据占比、非结构化数据规范性程度<br>数据获取的渠道/能力 |
| 数据层面（20分） | 领域专业数据基础（5分） | 行业语料<br>专业术语<br>标准数据集<br>标准化的行业术语及术语集 |
| 数据层面（20分） | 数据治理能力（10分） | 数据治理水平<br>数据安全管理与保障能力 |
