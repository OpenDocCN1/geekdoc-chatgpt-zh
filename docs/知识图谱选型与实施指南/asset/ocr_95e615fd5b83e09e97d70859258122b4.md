# 3、智慧交通领域

| 典型应用 | 应用成效 |
| :--- | :--- |
| 交通设备故障溯源<br>交通行业的业务知识识种繁杂、数据分散，未能建立数据间关联，无法快速、直观、全面地获取数据。基于用户使用场景，可利用知识图谱开发智能分析应用，如设备全生命周期管理、故障溯源等。 | • 提升设备信息、故障、日志等业务数据的检索效率。<br>• 提升故障排查与解决的效率。 |

# 4、智慧政务领域

| 典型应用 | 应用成效 |
| :--- | :--- |
| 基于知识图谱实现智慧理政<br>为了畅通政务服务渠道，通过知识图谱将杂乱的社情民意数据进行知识梳理表示，利用知识获取、知识融合等技术，实现对公众真实诉求的掌握及办理结果的互联互通。此外，通过知识图谱技术，分析展示各地区公众关注的焦点热点领域及分布，结合投诉咨询件的办理情况，梳理政府管理中存在的薄弱环节。 | • 提高决策部署的科学性和合理性，打破区域和部门间的藩篱，优化政府资源配置；<br>• 促进及时发现异常，及时预警。 |
| 基于知识图谱的政务问答<br>在知识库中建立问题与答案的映射关系，将自然语言转化为知识图谱查询语句，并从知识图谱中获得答案，为政府智能客服机器人、12345 热线提供问答知识支撑。 | • 为政府机构与亿万用户提供直接沟通的桥梁，代替政府工作人员为民众提供权威官方的解答；<br>• 为广大社会民众在民生、安全、旅游等方面提供更加及时、更为优质的服务，推动社会服务事业的全面发展和进步。 |
| 利用知识图谱技术构建政务百科<br>利用知识图谱的能力对政府人物、机构、政务关键词、政策词条等内容进行百科式的知识抽取和知识表示，并利用图模型描述和梳理政务各知识间的关联关系，形成内容权威、解读全面、通俗易懂的政务知识百科。 | • 厘清梳理政务任务、政务机构和政务信息，帮助政府解读经济、社会发展与政府顶层设计之间的内在逻辑，提升政务决策水平；<br>• 为公众提供一个分门别类、可立体索引的“政务地图”和“政务动态档案馆”。 |
