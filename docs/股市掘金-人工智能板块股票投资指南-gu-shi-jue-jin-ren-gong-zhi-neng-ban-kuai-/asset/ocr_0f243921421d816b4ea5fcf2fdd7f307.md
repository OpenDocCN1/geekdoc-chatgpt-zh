# 2. 语音交互

目前，智能语音人机交互领域是整个人机交互产业中发展较为完善的一个细分领域。从核心技术开发、知识库提供以及终端应用服务，发展得都比较完善。该领域涵盖了智能语音人机交互技术、平台、机器人的研发厂商和设备供应商；数据、内容提供商；应用、服务提供商等。目前，涉足该领域的企业众多，比较有代表性的包括小I机器人、捷通华声、科大讯飞、中国移动、拓尔思等。在终端应用领域，华为、苹果、微软、创维、联想、联通、电信、移动等诸多企业均有涉足。

# 3. 体感交互

体感交互领域属于正在兴起的一个新兴领域。一些需要向用户展示，并且需要用户体验的场景就需要体感交互技术，比如一些展览馆、科技馆等。目前，从事该项研究的企业包括高德红外、雷柏科技、联创光电、数码视讯等。
