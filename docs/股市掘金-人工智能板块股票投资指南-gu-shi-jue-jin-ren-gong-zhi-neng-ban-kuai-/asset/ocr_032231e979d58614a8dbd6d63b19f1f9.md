# 4. 圣邦股份估值分析

针对圣邦股份的成长情况，可以考虑按照 PEG 估值法进行估值。按照该股的净利增速来看，该股 2020 年每股净利润为 1.86 元，若预测 2021 年保持 60% 的净利增速，则每股收益为 2.98 元。那么，按其 60 倍的市盈率来估值，则其股价为 178.80 元。也就是说，60 倍估值对应了 60% 的净利增速，其 PEG 值仅为 1，这是一个相当保守的估值。当然，未来该股的增速可能无法维持在 60% 的水平，那时则需要对估值进行调整。
