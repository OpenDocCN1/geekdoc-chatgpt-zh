# 4. 中芯国际估值分析

针对中芯国际的成长情况，可以考虑按照 PEG 估值法进行估值。按照该股的净利增速来看，该股在科创板中属于典型的成长股。该股 2020 年每股净利润为 0.67 元，其净利增速为 140%。若 2021 年能够达到 50% 的净利增速，其每股收益为 1.01 元，那么，按照 50 倍的市盈率来估值，则其股价为 50.50 元。也就是说，50 倍估值对应了 50% 的净利增速，其 PEG 值仅为 1，这是一个相当保守的估值。其实，考虑该股所处的赛道以及在国内的地位，将 PEG 放大至 2，也是可以接受的。不过，若考虑该股整体盘子较大，按照当前的估值，市值也已经将近 4000 亿元，而将 PEG 值提升至 2，则市值将逼近 8000 亿元，这显然是不科学的，因此，我们最多将 PEG 值调整至 1.5，对应股价为 75.75 元。
