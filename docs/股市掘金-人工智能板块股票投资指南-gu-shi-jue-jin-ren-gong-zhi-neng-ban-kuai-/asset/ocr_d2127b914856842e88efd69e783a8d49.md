# (3) 云系统集成商。

该领域内的企业负责为云服务运营商搭建完成云服务平台。他们负责将云计算硬件和相关软件进行连接，提供云计算平台建设的解决方案。该领域内的企业包括中科曙光、华胜天成、浪潮信息、神州信息、中国软件、东软集团、华为等。

# (4) 云服务运营商。

该领域内的企业依托 IDC（互联网数据中心）云平台作为支撑，通过与云系统集成商合作，开发能够满足用户需要的平台，并提供平台的维护和运营等工作。该领域内的企业包括阿里、腾讯、金山、用友、金蝶、鹏博士、网宿科技、世纪互联等。当然，该领域内的企业也包括几家电信运营商。

# 2. 云计算行业的整体竞争态势

云计算行业近年来出现了爆发性增长，行业整体呈现如下几个显著的竞争态势。

第一，众多企业入局云计算产业，但各家企业的实力仍十分有限，并未出现强有力的服务于其他企业的公司。尽管这是一个典型的机会遍地的行业，但随着大型企业的入局，中小型服务企业的生存将变得艰难。

第二，在云服务市场，全球整体竞争格局趋向于集中，亚马逊、微软、谷歌以及阿里云成为四大巨头。阿里云占据了国内 IaaS（基础设施即服务）领域市场的 40%，中国电信、腾讯紧随其后。在云计算领域，往往越贴近用户的企业盈利能力就越强；反之，提供基础设备的企业，由于竞争过于激烈，盈利能力相对有限。

第三，随着国内云计算产业的快速发展，越来越多的厂商不满足国内的市场，开始向海外拓展市场，积极推进国际化战略。
