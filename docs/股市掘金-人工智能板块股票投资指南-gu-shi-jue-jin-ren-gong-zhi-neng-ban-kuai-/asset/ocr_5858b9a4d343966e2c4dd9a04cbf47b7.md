# 1. 上游：零部件

在整个工业机器人零部件领域，最核心的零部件分别为控制系统、伺服系统和减速器。

（1）控制系统。

控制系统生产厂商包括埃斯顿、新时达、汇川技术、大族激光、科远股份、信捷电气、固高科技等。

（2）伺服系统。

伺服系统生产厂商包括日本的三菱、松下等，国内企业包括华中数控、汇川技术、科远股份、埃斯顿、新时达、信捷电气等。

（3）减速器。

国内减速器生产厂商包括秦川机床、中大力德、上海机电、双环传动等。

# 2. 中游：本体

本体生产厂商包括埃斯顿、拓斯达、机器人、新时达、华中数控、长盈精密等。

# 3. 下游：应用

主要针对用户的特定需求提供应用解决方案，如系统集成或具体的行业应用两类。生产厂商包括快克股份、科远股份、三丰智能、机器人、科大智能、哈工智能、永创智能、华昌达、智云股份等。

# 4. 全产业链

一些工业机器人领域内的企业是全产业链运作的，业务范围涵盖了机器人产业链的完整上游或下游，有的甚至达到了上中下全覆盖。比如，日本和欧美的四大工业机器人家族基本都是全产业链覆盖的，国内的埃斯顿、拓斯达、机器人、新时达、华中数控、埃夫特等也属于全产业链企业。
