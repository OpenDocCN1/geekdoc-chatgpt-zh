# 一、云计算行业竞争分析

相关统计数据显示，截至 2020 年底，我国云计算产业规模超过 1500 亿元，到 2030 年，将超过 3000 亿元的水平。我国企业上云率大约在 40% 左右，美国企业的上云率达到了 85%，欧盟企业的上云率也达到了 70%。也就是说，在云计算领域，未来几年内将迎来一个跨越式发展的浪潮。

从整体来看，云计算产业链的参与者主要包括设备提供商、软件开发商、系统集成商以及服务运营商等四类。如图 6-1 所示。

# ( 1 ) 硬件设备提供商。

该领域内的企业为云计算系统所需各类设备的生产厂商，包括服务器、存储器设备、网络设备、机房设备以及附属的元器件产品等，芯片、CPU 等又是其中拥有核心技术的元器件。该领域内的企业包括联想、浪潮信息、中科曙光、华东电脑、华为、中兴等。
