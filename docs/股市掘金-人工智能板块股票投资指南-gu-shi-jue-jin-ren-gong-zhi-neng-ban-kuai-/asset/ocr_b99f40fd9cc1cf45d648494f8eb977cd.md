+   (4) 大数据处理与分析。该领域内的企业为客户提供全套的大数据处理与应用解决方案。通常情况下，该领域内的企业会专注于某一细分领域，如医疗领域、公共安全领域、教育领域等，如东软集团、东方国信、宝信软件、天源迪科等。

+   (5) 大数据应用领域。该领域内的企业主要是一些直接面向终端客户或消费者的企业，如百度、腾讯、阿里巴巴、每日互动等。

+   (6) 大数据安全领域。该领域内的代表企业包括启明星辰、360 等。

# ## 2. 大数据行业整体竞争态势

大数据行业近年来出现了爆发性的增长，整体行业呈现如下几个显著的竞争态势。

第一，从整体上来看，大数据行业已经形成了相对完整的布局，产业链各层次都有企业在深耕。然而，从细分领域来看，大数据中游的平台搭建以及数据处理领域，竞争非常激烈，且外资企业占据较大的优势，如亚马逊、微软等。在大数据产业的下游应用领域，尽管阿里巴巴、腾讯、百度占有较高的市场份额，但由于该层面还有很多尚待挖掘的细分领域，因而也给其他企业留下了很多机会。

第二，互联网巨头加速跑马圈地，逐渐开始向打通整个大数据产业链的方向发展，中小企业在竞争中日趋弱势。寻找未被开发的细分领域并进行深耕细作，成为中小型大数据企业的当务之急。

第三，随着国内大数据产业的快速发展，越来越多的厂商不满足国内市场，还向海外拓展市场，积极推进国际化战略。

# ## 3. 大数据产业发展趋势

大数据属于典型的新兴产业，未来发展空间还十分广阔。目前，逐渐开始显露的趋势包括如下几点。

第一，我国在数据管理方面缺乏统一的标准，因而数据加工、处理的难度非常大，导致数据整体质量偏低。未来，随着大数据行业的发展，数据质量必然需要提升。
