# 2. 传感器中游

传感器中游产业主要包括传感器制造、封装以及各类传感器生产等。

# (1) 传感器制造。

传感器制造领域的参与厂商大多是人工智能与科技行业内的龙头企业，如格罗方德、爱普生、中芯国际、士兰微、高德红外、华虹集团、中航微电子、国高微电子等。
