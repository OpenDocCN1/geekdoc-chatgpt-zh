# 第六节 技术开发平台投资研究

技术开放平台主要为各大科技巨头所掌握，其他企业涉足相对较少。

# 一、技术开发平台领域竞争态势

技术开发平台领域的竞争态势，呈现以下几个特征。

+   1. 国内企业进入该领域时间较晚

目前，国外从事技术开放平台研究与开发的企业相对较多，且无论是代码还是数学模型方面，均拥有较为丰厚的储备，如谷歌、微软、亚马逊等。国内企业在这方面虽然起步较晚，但最近几年发展较为迅猛，百度、阿里巴巴、腾讯、金山、华为、京东等企业都建立了各自的 AI 开放平台。

+   2. 技术开放平台领域企业数量相对较少

在整个人工智能领域中，从事技术开放平台研发的企业数量还是相对较少的，尽管近年发展迅速，但该领域内的企业仅占整个人工智能领域企业数量的 4% 左右。我国人工智能技术开放平台与算法领域过于依赖开源代码和现有数学模型，导致专业性和针对性不足。

+   3. 行业集中度较高

目前，百度、阿里巴巴、腾讯与华为处于技术开放平台领域的第一集团。这四家企业的市场份额占比达到了 80% 以上，行业集中度非常高。

# 二、技术开发平台领域相关产业及构成

从产业链来看，技术开发平台产业的上游肯定需要覆盖基本的人工智能芯片、服务器等设备，还需要依托大数据、云计算等平台；技术开发平台的下游也连接各类应用场景。这与其他人工智能细分领域相似，这里不再赘述。
