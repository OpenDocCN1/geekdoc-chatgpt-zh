# 1. 上游：基础层

智能语音产业链的基础层主要包括基础研究支持、数据研究支持以及语音芯片等。

+   (1) 基础研究支持。

基础研究支持主要从事基础语音技术输出和语义数据采集处理等。主要支持机构包括清华大学、中国科学院、哈尔滨工业大学、北京大学、上海交通大学、中国科学技术大学等。

+   (2) 数据支持机构。

数据支持机构包括数据堂、慧听数据等。

+   (3) 语音芯片。

很多科技企业在语音芯片领域都有布局，如科大讯飞、云知声、出门问问、思必驰、中天微等。
