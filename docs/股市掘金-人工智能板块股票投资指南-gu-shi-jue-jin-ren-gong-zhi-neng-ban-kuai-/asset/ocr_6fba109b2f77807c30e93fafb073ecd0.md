# 第一节 计算机视觉领域投资研究

计算机视觉是使用计算机及相关设备对生物视觉的一种模拟，它的主要任务就是通过对采集的图片或视频进行处理，以获得相应场景的三维信息，就像人类和许多其他类生物每天所做的那样。计算机视觉赋予了各类拥有“大脑”（芯片）的物体以看清外部世界的能力，因此，也成为人工智能领域不可或缺的基础性技术。

由于计算机视觉技术在人工智能领域拥有极为重要的地位，最近几年很多科技巨头和初创型科技企业都将其看作突破的重要领域与方向。从投资的角度来看，该领域也将成为未来非常有潜力的一个投资方向。
