# 第五节 人机交互领域投资研究

人机交互、人机互动，是一门研究系统与用户之间交互关系的学问。系统可以是各种各样的机器，也可以是计算机化的系统和软件。

人机交互技术的最终目标是在不再需要依赖机器语言，在没有键盘、鼠标以及触摸屏等中间设备的情况下，实现随时随地人机的自由交流，进而实现人们的物质世界和虚拟网络的最终融合。

人机交互领域，是人工智能产业中非常重要和核心的领域，也是各大科技巨头竞相争夺的核心领域。
