# 3. 封装测试

芯片封装，是指将芯片制造企业生产出来的集成电路裸片放置在一块起承载作用的基板上，再把管脚引出来，然后固定包装成为一个整体。封装好的成品还要进行芯片功能和电参数测试。

从整个芯片封装测试行业来看，中国台湾的日月光集团位居行业首位，内地比较有代表性的企业包括通富微电、长电科技、华天科技等。

国内涉足芯片设计领域的企业很多，但各家企业涉足的深度、领域有所不同，其竞争能力也存在很大差异。

# 一、AI 芯片设计领域竞争形势

AI 芯片设计领域，包括 IP 核设计、芯片设计以及芯片设计代工等三类。不过，芯片设计代工企业也同样属于芯片设计企业范畴，具有代工能力的企业，必然具备设计能力。

# 1. IP 核设计企业

IP 核，即知识产权核。如果说 AI 芯片设计领域属于整个 AI 产业链的顶端，那么，IP 核设计就是 AI 芯片设计产业链的顶端，这也是整个人工智能产业中最顶层的领域。这类企业以收取 IP 核授权费为主要营收来源。

在行业排名上，ARM、新思、锘腾排名前三位，在整个市场份额中占比超过 65%。国内的 IP 核供应企业现在已经达到 50 余家，但整体规模较小，比如芯原股份也可以提供 IP 核，同时也进入了行业前十位，但与行业前三名相比，差距还非常大。
