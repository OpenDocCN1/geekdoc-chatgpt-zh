# ( 2 ) 动态市盈率。

动态市盈率是以静态市盈率为基准，经过动态调整获得的，其计算公式
如下。

动态市盈率 = 静态市盈率 x 动态系数
其中：动态系数 =1/ ( 1+i ) n
i 一每股收益的增长性比率；
n 一企业可持续发展的持续期。
