# 六、计算机视觉（ 工业制造领域 ）代表企业——天准科技

天准科技是精密检测领域内的先进企业，苹果公司玻璃及结构件检测设备的核心供应商，同时致力于以领先的人工智能技术推动工业转型升级。该公司以机器视觉为核心技术，专注服务于工业领域的客户。

苏州天准科技股份有限公司主营业务是精密测量仪器、智能检测装备、智能制造系统、无人物流车的生产及销售。

# 1. 基本产品线与盈利构成

天准科技作为一家以工业视觉装备为主要业务的企业，其主要产品销售与利润占比情况，如图 7-7 所示。

从图 7-7 中可以看出，天准科技的整个收入主要来自于消费类电子、光伏半导体、汽车以及其他产品。

其中，智能检测装备业务占到总营收的 85.24% 左右，毛利率为 43.33%，利润占比为 86.95%，是该公司名副其实的第一大业务。精密测量仪器业务占到总营收的 8.80% 左右，毛利率为 50.63%，利润占比为 10.49%。其他业务所占的营收和利润份额均较小，可以忽略不计。
