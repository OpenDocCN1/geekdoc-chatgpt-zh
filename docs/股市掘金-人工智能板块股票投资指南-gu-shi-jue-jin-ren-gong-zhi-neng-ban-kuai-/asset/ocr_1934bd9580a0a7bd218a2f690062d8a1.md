# 3. 四方光电整体分析

# 4. 四方光电估值分析

针对四方光电的成长状况，可以考虑按照 PEG 估值法进行估值。按照该股净利增速来看，该股 2020 年每股净利润为 1.61 元。若预测 2021 年保持 40% 的净利增速，则每股收益为 2.25 元。那么，按其 40 倍的市盈率来估值，则其股价为 90 元。也就是说，40 倍估值对应了 40% 的净利增速，其 PEG 值仅为 1，这是一个相当保守的估值。若将市盈率放大至 50 倍，其 PEG 值为 1.25，也是一个可以接受的水平，则其股价估值为 112.50 元。
