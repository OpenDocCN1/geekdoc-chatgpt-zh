# 1. 基础开源框架

目前，提供基础开源框架的多为外资企业所开发的系统。国内企业中，华为已经开始提供开源框架，未来可能会有更多的大企业拥抱开源。

# 2. 技术开放平台

最近几年从事技术开放平台研发的企业增多，包括百度、阿里巴巴、腾讯、金山、中科创达等。

# 三、技术开发平台领域投资逻辑

相比其他人工智能细分领域，技术开发平台领域内可选的投资标的可能会更少一些。投资者在投资过程中需要考虑以下几点。

第一，在技术开发平台领域中，华为属于非上市公司，而阿里巴巴、腾讯、金山等都属于港股上市企业。内地投资者除非开通港股通，否则无法直接购买港股。而且这些大型科技巨头的投资十分分散，我们不能因其在某一细分领域有投资或布局，就将其看成属于典型的某类企业。对这些科技巨头进行投资时，还要综合评估其估值水平以及其他业务的开展情况。

第二，在市场上，有些上市公司的部分业务可能会涉及技术开发平台领域，这些企业往往也就具有了技术开发平台概念。比较典型的企业如中科创达等。
