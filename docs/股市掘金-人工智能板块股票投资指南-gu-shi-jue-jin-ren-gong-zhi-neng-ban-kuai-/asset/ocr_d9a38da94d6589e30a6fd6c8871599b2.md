# 第二章 审视人工智能板块

随着科技的不断发展，我们所处的时代也将从万物互联逐渐过渡到万物智能化时代。人工智能正在与各行各业快速融合，助力传统行业转型升级。

# 第一节 人工智能投资研究

2016年3月，《中华人民共和国国民经济和社会发展第十三个五年规划纲要》出台。这份规划纲要提出：加快信息网络新技术开发应用，重点突破大数据和云计算关键技术、自主可控操作系统、高端工业和大型管理软件、新兴领域人工智能技术。人工智能技术首次被写入国家规划之中。
