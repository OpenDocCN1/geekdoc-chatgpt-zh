# 一、语音识别领域竞争形势

随着人工智能、智能家居产业的发展，加之资本的不断推动，促使整个智能语音产业进入了快速发展轨道。语音识别领域在发展过程中呈现如下几种竞争态势。

第一，随着科技的发展，语音识别产业进入快速发展周期。据相关专业机构预测，未来智能语音市场的规模将会达到数百亿美元以上。其中，AI 语音芯片将会成为最大的受益领域。

第二，各大科技巨头纷纷加大对语音识别领域的投资力度，谷歌、微软、亚马逊、华为、腾讯、百度、阿里巴巴等纷纷进入语音识别领域，致使该领域的竞争日趋激烈。

第三，从国内语音识别市场来看，科大讯飞占据了较大的市场份额，百度占据行业第二。各家小型语音识别企业则面临较为激烈的竞争，并且生存越发困难。
