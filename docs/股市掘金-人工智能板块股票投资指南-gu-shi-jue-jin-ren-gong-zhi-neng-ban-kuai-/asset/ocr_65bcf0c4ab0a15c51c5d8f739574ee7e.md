# 2. 负债表

与资产报表对应的就是负债与所有者权益，二者共同构成了资产负债表。
按照会计原则，资产恒等于负债加所有者权益。为了让投资者更容易理解这个报表，下面来看一下负债部分。

负债是企业所承担的能以货币计量、需以资产或劳务偿还的债务。负债是一种债务，是企业需要偿还的钱。就如同一个人欠了别人的钱，这笔债终究是要还的。资产负债表中的“负债”，就是告诉大家这家企业到底欠了多少外债。大家知道，如果一个人欠了其他人很多钱，那么他再出去借钱的时候，大家就会担心他能不能还上钱。企业也是如此，如果一家企业的负债过多，甚至出现资不抵债（资产小于负债）的情况，那这家企业就离破产不远了。

按照会计分类方法，可以将负债分为流动负债和非流动负债两类。
