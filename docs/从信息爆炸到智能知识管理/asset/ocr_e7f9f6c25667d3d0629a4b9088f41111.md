$G=<C, I, M>$

其中，C 是常数符号集(a set of constant symbols)，相当于属性；I 是 G 的交互界面(interface of G)，相当于属性值；M 是方法(method)。在此基础上定义了一些信息颗粒的运算。这种结构可以用 Agent 实现，从而适应信息和知识结构复杂性的需求，这跟可拓学的物元(蔡文, 1994)表示不谋而合。

# 3. 从过程环节上实现智能性

Hou 等(2005)提出了一个智能的知识管理的模型，主要采用文档关键词抽取(document keyword extraction)、文档自动分类、文件权限自动推理设定、知识审定过程决策(validation process decision)等模型对汽车制造相关的文档进行一定智能性的管理，提高知识构建、抽取和管理的效率，降低人的工作量。其智能知识管理的平台示意图如图 2.7 所示。

张建华(2005)研究了人工智能技术在知识管理过程中的应用，提出了基于人工智能的集成化知识管理系统模型，该模型以企业各种底层设施和信息与知识源为根基，以系统工程和协同工程的思想和方法为指导，以组合智能为依托，构筑起面向知识管理过程的初步智能化、集成化的协同系统架构，但其目标仍然以隐性知识的显性化管理为主，且实现机制有待深入研究。
