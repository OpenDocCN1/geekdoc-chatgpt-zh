# 5. 基于案例的推理(CBR)

是在遇到新的案例时，通过搜索案例库，寻找与之最相似的旧的训练集合的案例，其解决方案作为解决新案例的参考。如果对此案例不满意，还可以进行修改，修改后的案例作为一个新学习并存储到案例库中。该方法最后得到的结果是一个推荐的案例(Kolodner,1993;Riesbeck et al,1989)。该方法的挑战在于案例的表示、案例之间的相似性度量以及案例的检索和修改技术的精度和效率。

# 5.6.2 智能知识的推理机制

除了获取初始规则知识的困难，产生式规则推理在实际应用中还存在一些不足：

+   (1) 处理大型复杂问题的能力差。在解决复杂问题时，求解问题状态空间较大，操作数目多，操作序列会出现空前膨胀，导致组合爆炸的危险。
+   (2) 处理不确定性问题能力差。在生产实践中人类专家的知识往往是不确定的，即模糊的，这使得基于一值逻辑的产生式推理在处理这些问题时效果不理想。
+   (3) 缺乏自学习能力。所有的知识和推理规则都是由预置的，不能自动学习、不能自我完善、发展和创新。
+   (4) 推理方法单一。和人类不同，产生式规则的推理方式是固定的，它不会根据问题的不同而变换推理方式，致使思维僵化，智能化程度不高。

可拓性是事物固有的性质。客观世界中的事、物和关系可以用基元或复合元及其组合加以形式化表达，依据事、物和关系的可拓性，可以对基元进行可拓分析，从而产生一系列推理规则即基元拓展推理规则。基元拓展推理包括发散推理规则、蕴含推理规则、相关推理规则和可扩推理规则。这些规则可以辅助实现智能知识的推理机制。
