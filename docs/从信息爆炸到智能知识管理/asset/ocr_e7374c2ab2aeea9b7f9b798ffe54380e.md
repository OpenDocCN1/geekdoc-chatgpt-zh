紧密相关的条件、背景和环境称之为情境（或称为知识情境）。（知识）情境是与知识、知识活动等相关的条件、背景和环境等，既包括相关的物理、社会、业务等外部环境、背景因素，也包括知识主体的认知、经验、心理等内部因素，刻画了与知识、知识活动相关的情形特征（潘旭伟，2005）。如前所述，情境具有如下特点：

+   (1) 情境是客观、普遍存在的现象，它可能已经被人们认识，也可能还没有得到充分认识。

+   (2) 情境独立于知识和知识过程而存在，但知识和知识过程与情境紧密相关。

+   (3) 情境刻画知识、知识活动等相关的情形特征，这些情形特征是区分、识别不同知识、知识活动的重要因素；对知识主体而言，这些情形则刻画了他在从事知识活动时的个性化特征。

情境与知识和知识管理紧密相关，其相互关系主要有：

+   (1) 情境是完整理解知识的关键要素。没有合适的情境知识，知识将与情境和其他相关知识相互隔离，可能导致其含义不能得到完整地理解或被错误地理解（Goldkuhl, 2001）。

+   (2) 情境可转化为知识。当人们把知识和与它相关的情境结合成为一体时，情境就转化为了知识。

+   (3) 情境影响人们对知识价值的评价。同样的知识，在不同的情境下，人们对它的意义和价值的评价是不同的。

+   (4) 情境影响知识活动的特点和结果。同样的知识活动，在不同的情境下，其特点和结果会不同。

+   (5) 情境是知识共享和重用的重要基础。认知专家认为基于情境的“回想”是人类解决问题的一个基本方法。人们在某种情境下面对一个问题时，首先进行“回想”，看是否有相同或类似情境下解决此类问题的知识。知识的产生和应用在一定情境下发生，人们之所以需要并且能够共享和重用已有的知识，很大程度上是因为他们当前所处的情境与已有知识产生、应用的情境具有一致性或相似性。

+   (6) 情境是知识管理的一个重要构成要素。正是情境与知识、知识活动等紧密相关，情境逐渐地成为知识管理的一个重要构成要素。Despres 等（2000）在总结了若干知识管理的模型和框架之后，提取了知识管理的四个要素：知识过程、知识、知识主体和情境，认为情境是对周围事物的感知，知识及知识管理实践的意义只有在一定的情境、社会空间和时间的情况下才体现出来。

情境有利于减少知识过载。情境刻画了知识主体在从事知识活动时的个性化特征，根据这些个性化特征可以评判不同知识与当前情境的相关程度及其在当前情境下的意义和价值，从而只将最相关、最有价值的知识提供给知识主体。
