# 8.2 对后续研究的展望

把数据挖掘获取的知识明确引入知识管理领域进行智能化管理还处于刚刚起步阶段。在本书所做研究的基础上，作者认为可以从以下五个方面作进一步的研究：

+   (1) 对知识的智能性实现算法上做更深入的研究。本书只实现了两种算法，还有更多的智能算法有待研究，如智能关联规则的挖掘（如找出促使某类商品被另一人购买的策略）、可拓聚类（按用户转化的难易程度和转化方式进行聚类）等。挖掘对象上，可以拓展到文本信息、互联网信息和多媒体数据。

+   (2) 智能知识的自适应方面，情境识别和记忆信息的收集、集成存储有待进一步的研究。情境包含了大量不同方面的要素，而情境并非全是清晰的、明确的，大量的情境是模糊的、不确定的，识别获取这些模糊的、不确定的情境信息是智能知识自我审计和主动推送的基础。研究如何有效识别、获取和记录情境将是未来智能知识研究中的难点。

+   (3) 智能知识及知识管理平台和其他要素的相互作用与集成机理的评价指标研究。知识和业务流程、人员紧密相关，如何衡量它们之间的相互作用及作用机理等问题还需要较好的研究和认识。在智能知识的自动学习机制上，也还有很大的研究空间。

+   (4) 智能知识管理系统的设计已经初步完成，需要组织开发智能知识管理系统进行完整的实践应用，通过实践反馈进一步改进系统，并做智能知识管理模式全面的实证研究，从而形成一个正反馈循环，促进智能知识管理的发展。

+   (5) Agent 技术发展迅速，如何引入 Agent 技术改进智能知识管理系统，特别是各种挖掘算法的有效配合、自动根据数据集变化更新知识、实现更智能化的推理和审计等，这将是一个很有吸引力的研究领域。
