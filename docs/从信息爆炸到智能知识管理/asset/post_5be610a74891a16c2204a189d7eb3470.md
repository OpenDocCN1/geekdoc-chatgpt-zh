
管理实现框架，并定义了智能体的组成及它们之间合作、协调的操作机制及有关算法。该框架只是一个理念层面的初步研究，对具体实现技术未进行讨论。

以上这些研究大都是从管理功能上增加智能特色，局部提高知识管理环节的效率，管理的对象主要还是信息或传统的隐性知识的分享与显性化等，大都广泛地将知识视为隐性和显性的知识，没有具体地讨论如何有效管理由数据分析所产生的智能知识，缺乏针对数据挖掘获取知识的深入的科学研究，且概念和我们提出的智能知识不一致。

近年来，研究智能的知识管理方法的文章开始增加。归纳如下两大方面：

- 1）方案整体设计方面

Zhang 等(2009)将隐性知识与显性知识转化的过程引入智能知识管理，提出智能知识管理中的四个关键步骤：①从数据到粗糙知识；②从粗糙知识到智能知识；③从智能知识到行动知识；④从行动产生新的数据。形成一个循环的过程。鉴于隐性知识无法系统化存储，Yang 等(2007)利用模糊分层摘要提取(FAH)技术，建立智能模糊搜索框架，初步实现领域专家的智能查询、模糊匹配，根据需求帮助找到相关领域的知识。 Venkatasubramanian(2007)认为，伴随信息爆炸和知识爆炸的来临，通过智能软件系统有效地管理和获得决策信息是显然的，但这一需求还没有引起足够重视。实际上，数据、信息和过程中的信息流对决策同样重要，基于本体论构建了一个信息基础设施架构，对产品生产管理的全过程信息进行管理。文献(Li et al, 2009b; Nie et al, 2009)认识到数据挖掘获取的知识对商业智能的意义，分析了对之进行智能化管理的重要性，提出了一种与商业智能集成的方案及研究框架。 Fayoumi 等(2009)认识到对数据挖掘结果的智能化处理可以得到有价值的知识，提出一种基于 Web 语义技术的系统化方案框架，其输入是 PMML 语言描述背景知识，利用主题图形式，设计数据挖掘本体和关联规则挖掘的本体，集成内容管理系统和语义知识库，分析者可以输入新信息生成语义分析报告，进而重新审视挖掘结果。

- 2）智能性的具体实现方法

Chang 等(2008)使用智能体社区来有效地处理知识管理活动，即知识共享、知识分类、知识创造和知识的复苏。该系统的特点是：收集每个用户的上网习惯和通过数据挖掘找到隐藏的模式，进而推荐合适的文章，迅速为用户找出适当的文件；通过个人配置提供个性化服务。

Grundspenkis(2007)也发现知识管理与人工智能之间缺少连接的桥梁，提出基于 Agent 的组织和个人知识建模的框架。该框架包括两个模型：一个是描述智能企业记忆的模型，另一个描述智能的组织知识管理系统，从而构建基于 Agent 的支持个人和组织的知识管理的环境。其中智能企业记忆模型分为七层：知识源层、知识获取层、知识规范化层、知识表达层、知识处理层、知识应用层和专家服务层。分别利用沟通 Agent、协作 Agent、消息 Agent、团队 Agent、工作流 Agent、过滤 Agent、搜索 Agent、数据库 Agent 等实现相应功能。Luo 等(2009)基于语义连接网络(SLN)提出了一种生成相似知识流的方法。Zhang 等(2009c)设计了一种衡量知识与用户之间相似度的方法，通过计算、设定相似度数值，以实现知识在适当时机自动推送给合适的用户。Fayoumi 等(2009b)通过建立一套基于多智能体的智能分析系统，从社会网络环境中捕捉知识并进行模拟，最终形成自动的知识流。

可以看出，国内外很多学者已经认识到对数据挖掘获取的知识进行进一步处理的重要性，并开始着手这一领域的研究。同时，国外有些学者在仿真、模拟方面已经开始实验一些智能化的方法，说明智能知识管理研究已经引起关注。

## 2.4 本章 小结

本章对学者近年来在知识管理、数据挖掘、智能及智能知识管理技术和工具方面的研究进行了总结和分析，得到如下一些结论：

- (1) 知识管理领域目前研究的对象仍集中在个人或组织的隐性知识分享和显性化上，少量研究把数据挖掘作为获取知识的一种方式，但对数据挖掘获取的知识具有什么特点，如何纳入知识管理范畴进行有效的管理、利用没有引起重视。甚至认识上都相对缺乏。

- (2) 数据挖掘领域的研究主要集中在挖掘算法、挖掘对象范围的扩大上，数据挖掘本身的过程标准化已经引起企业的重视和参与，但在往往把模型或模式的获取作为数据挖掘项目的结束，如何对多种表现形式的知识进行整合，借助知识管理的研究成果提高数据挖掘获取的知识利用效果没有引起足够的重视。

- (3) 知识管理工具尽管很多，但目前还没有一个知识管理技术框架能很好地支持数据挖掘获取的知识的管理，这在一定程度上也说明了知识管理系统的研究还处于发展阶段，对数据挖掘获取的知识的管理还没有形成比较一致的认识。

- (4) 知识推送、知识门户等技术和工具试图解决知识不能及时获取和知识过载等问题，但是现有的知识推送和知识门户工具在实现知识获取应用的个性化方面没有实质性的技术和手段，缺乏这方面系统性的理论和方法支持，因此在知识及时获取和减少知识过载方面实际发挥的作用并不大。

- (5) 目前人工智能领域的研究已经取得了很多成果，从机械、电子、生物、计算机等学科的发展看，智能化是增强适应性和提高管理水平的必经之路。知识管理智能化是一种未来的趋势，目前，在管理智能化方面已经有一些策略和实现路径可供选择利用。

- (6) 智能知识管理已经引起一些学者的重视，有的学者开始从算法、过程、结构等方面进行研究，已有文献强调以 IT 为工具对现有知识的管理，研究对象是“智能的知识管理系统”，研究侧重于管理平台功能的智能性，缺乏对从大量数据和信息中获取知识并进行管理的系统研究和知识整合利用的方法的设计，忽视知识本身的智能化。当知识数量巨大时，这种智能的知识管理平台难以胜任，必须让知识自身具备一定的智能，进行自我管理。

因此，从知识本身入手，参考复杂性科学理论，研究数据挖掘获取的知识的特点和统一表达，使知识本身具备记忆、学习、识别等智能性，是减轻知识管理平台压力、降低知识过载的一条新路。这就是本书主要研究的智能知识管理模式。

## 第 3 章 智能知识管理的理论框架

本章在综合前述研究成果的基础上，提出智能知识的概念和智能知识管理模式研究的体系框架，为后续各章的进一步研究规划蓝图。

### 3.1 智能知识管理的相关概念

#### 3.1.1 基本概念

智能知识管理的研究涉及许多基本概念，如原始数据、信息、知识、智能知识、智能知识管理以及由此此关联到的几个重要概念：先天知识、经验知识、常识知识、情境知识等。为了使这一新的科学研究命题从一开始就走上比较规范和严谨的道路，有必要重新给出这些基本概念的定义。而且，解释这些概念的同时也进一步理解数据、信息、知识、智能知识的内在含义。本文结合信息论、人工智能领域学者对数据、信息、知识的相关定义，将智能知识管理相关定义界定如下(Zhang et al,2009；钟义信等，2007)。

##### 定义 3.1 原始数据。

某个客体(事物)的原始数据是该事物关于自身所处状态以及所处状态随时间而变化的方式的自我表述，是离散、互不关联的客观事实。原始数据的集合用集合 D0 表示。

原始数据是客体(事物)的事实上的存在，是各种客体事物运动状态及其变化方式的直接或间接的表述，是人们认识世界的原材料。它与是否有主体的存在无关，也与它是否被主体所感受到无关。原始数据是其他形态(如信息、衍生原始知识、智能知识及其他)加工物的源头。因此在获得原始数据后，需要通过适当的加工把它转换成为具有特定含义的信息。

这里的数据从形式上讲包括：文本、多媒体、网络、空间、时间序列数据等。

从结构上讲包括：结构化、非结构化以及半结构化的数据；目前 KDD 能够处理的多为结构化数据。

从数据的量上包括：海量数据，也包括一般数据和少量数据等。

##### 定义 3.2 信息。

信息是主体关于客体的运动状态及其变化方式的表述，包括状态及其变化方式的形态、含义和效用，后者分别称为语法信息、语义信息和语用信息，三者的综合则称为全信息(钟义信, 2007)。

主体按一定要求对数据进行预处理后得到的特定含义的内容表达即成为信息。信息具有时效性、内容性、效用性等特点。

##### 定义 3.3 知识。

知识是认识主体关于客体（事物）的运动状态及其变化规律的本质性表述。任何知识所表述的运动状态及其变化方式，都具有形式、内容、价值三个基本要素，能在一定范围内指导人们的实践。

##### 定义 3.3.1 经验知识。

经验是主体关于事物所处状态及其变化方式的总结性表述，是未经科学检验和证实的知识，因此可以称为“准知识”。人们在实践过程中可以学到一定的经验，一旦这些经验经过科学的检验而得到证实，这些经验就成为“经验知识”；如果不能被证实，就只能是“经验”、“信息”而不能成为“知识”；如果经验因出现反例而被证伪，就变成为某种“误解”。

经验性知识大量存在，是一类重要的知识形态。人工神经网络通过样本训练所获得的知识就属于经验性知识，人们在实践过程中积累的解决某些问题的知识通常也属于经验性知识。由归纳算法得出的结果在未经检验的确证之前，一般也属于经验性知识。

##### 定义 3.3.2 常识知识。

常识是众所周知而不须证明的知识，是知识被广泛普及的结果。常识性知识通常包含两种类型：一种是公理性知识；一种是主体（包括人类和生物）在进化与遗传过程中获得的先天具有的知识，是主体后天能获得各种知识的前提和基础性知识。它们的特点是无须学习、证明和推理。

##### 定义 3.3.3 规范知识。

是主体通过实验、实践、推理等对关于事物所处状态及其变化规律的规范性表述。这些表述不仅包括状态/规律的形式而且包括它们的内容以及它们相对主体目标而言的价值，分别称为形态性知识、内容性知识和价值性知识。其规范性表现在，只要满足一定的条件，结果就可以稳定出现，结论就必然可靠。

规范性知识一方面来源于经验性知识的确证，同时也来源于原有规范性知识的演绎推理。规范性知识是知识的主体。

##### 定义 3.3.4 情境知识。

情境是与知识、知识活动等相关的条件、背景和环境等，既包括相关的物理、社会、业务等外部环境、背景因素，也包括知识主体的认知、经验、心理等内部因素，刻画了与知识、知识活动相关的情形特征。

情境具有如下特点：

情境是客观、普遍存在的现象，它可能已经被人们认识，也可能还没有得到充分认识。

情境独立于知识和知识过程而存在，但知识和知识过程与情境紧密相关。

情境刻画知识、知识活动等相关的情形特征，这些情形特征是区分、识别不同知识、知识活动的重要因素;对知识主体而言,这些情形则刻画了他在从事知识活动时的个性化特征。

#### 3.1.2 数据挖掘新视角下的知识分类

首先,对知识比较经典的分类是从可表达性和可传递性上将知识分为隐性知识和显性知识(Nonaka, 1994;Polanyi, 1958),该分类文献很多,且已经达成共识,本书不再论述。

其次,国际经济合作与发展组织(OECD, 2003)从效能上将知识分为四种类型:

- (1) 知道什么的知识(know-what,即事实知识),关于事实方面的知识。
- (2) 知道为什么的知识(know-why,即原理知识),事物的客观原理和规律性的知识。
- (3) 知道怎样做的知识(know-how,即技能知识),用于改变世界的知识。
- (4) 知识是谁的知识(know-who,即人力知识),知道谁能做哪些事的知识。

再次,从知识应用的角度,知识分成两级:领域级知识和元级知识。

领域知识是关于具体领域的事实、规则、方程、实验对象等知识,元知识(meta knowledge)是说明如何运用领域知识的知识,是对领域知识进行描述、说明、处理的知识。

最后,从知识直接来源上划分,知识分为人的实践经验知识以及从数据和信息中挖掘得到的知识。

从数据和信息中挖掘得到的知识又分为原始知识(或粗糙知识)和有用知识。

##### 定义 3.4 原始知识。

原始知识是利用数据挖掘工具从数据和信息中直接发现的模式、规则、权重系数等原始结果,没有经过筛选的粗糙的知识。例如:

```
“Rule 1: (3989/1475,lift 1.9)
总共发信种类>0
W13PDWEB 登陆 IP 个数<=0
总共 WEB 登陆 IP 个数<=0
是否使用随身邮服务=1
➡ class 0 (0. 630)”
```

这是一条反映用户在过渡期内未缴费被冻结的特征。

```
“Rule 2: (4514/1177,lift 2.3)
总共发信种类<=0
POP3 登陆 PD 次数<=0
总共 WEB 登陆 IP 个数<=0
是否使用随身邮服务=0
买服务期 6 的比例<=0.4
➔ class – 1 (0.739)”
```

这是一条反映用户在过渡期结束后仍未缴费被删除的特征。未经筛选、评价的大量规则集就是一种原始知识。原始知识中只有一部分是有价值的，这部分知识称为有用知识(Shi et al, 2007)。

##### 定义 3.5 有用知识。

对原始知识进行筛选、过滤、审计得到对管理决策有价值的知识,称为有用知识。

上例中的 Rule 1 经业务人员和专家判断,对了解冻结用户和预防客户流失有参考价值,被认定为有用知识。原始知识、有用知识和人的经验知识的分类示意图如图 3.1 所示。

从来源上知识分为人的经验知识和来自数据挖掘的原始知识,原始知识中又包含对决策有价值的有用知识。本书研究的对象是从数据和信息中获取的模式、规则等原始知识及其转化为有用知识和智能知识的方法、技术与过程等。

传统的人类知识本身就是智能的,它们都隐含着知识的使用条件、背景、适宜人群等,拥有知识的主体也能根据环境变化自动调整。所以定语“智能”是多余的,智能知识的提出正是基于大量非智能知识的出现。这些非智能的知识就是通过数据挖掘得到的原始知识。

从原始知识到有用知识,知识的数量减少,但质量较高,此过程需要专家和经验丰富的业务人员进行人工筛选。如果原始知识的数量不大,人工审计、比较是可行的。当产生的原始知识数量很大或者表现形式可解释性差时,人工识别变得非常困难。有用知识随着时间的推移也会变得无效,同时新的知识也在不断产生,而且,应用过程中知识是被动地利用,不能主动提供给需要的人,而用户无法识别边界条件,人工审计大量的知识成本高、工作量大、周期长。

如何识别知识的有效性，提高智能程度？目前专家的做法是建立智能的知识管理系统，当知识数量剧增时，该方案将不能胜任，随着有用知识不断积累，越来越多的知识之间也会产生冲突等，因此必须对有用的知识进行智能化处理，使知识自身具备智能性。

智能知识首先是有用的知识；其次，它能够自我管理，有一个类似人类一样的出生、成长、结婚、生子、衰老、死亡等生命周期；另外，它具有环境识别能力，能够在正确的时间、适当的条件下把知识提供给需要它们的人。其特点除了具备有用知识的特点外，还具有如下独特的性质：

- (1) 价值性:作为有用的知识,对管理决策具有较高的参考价值。
- (2) 自适应性:能够自我管理,具有环境识别能力和一定的调整能力。
- (3) 主动性:能够在正确的时间、适当的条件下把知识提供给需要它们的人。
- (4) 社会性:有一个从产生到消亡的完整的生命周期;另外,具有和同类知识的社会交往能力,如派生、聚合、推理等。

以上原始知识和有用知识的特性及其管理过程交织在一起，构成了智能知识的复杂性。

#### 3.1.4 智能知识管理

不同的研究者从不同的角度理解和定义知识管理，可以归纳为以下几类：

- (1) 从目标角度定义，知识管理是运用集体的智慧提高应变和创新能力，为企业实现显性知识和隐性知识共享提供新途径(左美云,2000)。美国生产力与质量研究中心的定义,企业知识管理是指为提高企业竞争力而对知识的识别、获取以及充分发挥其作用的过程。
- (2) 从过程角度定义,知识管理是对企业知识的识别、获取、开发、分解、使用和存储(Abecker,1998);或是指为了增强组织的绩效而创造、获取和使用知识的过程(AMT,2003)。
- (3) 从资源管理角度定义,知识管理是利用组织的无形资产创造价值的艺术;或知识管理是对知识资产(智力资产)的管理(戚永红,2003)。
- (4) 从战略、组织等角度来定义,知识管理是帮助人们对拥有的知识进行反思,帮助发展支持人们进行知识交流的技术和企业内部结构,并帮助人们获得知识来源,促进他们之间进行知识的交流(艾莉,1998);或知识管理是组织一种有意识的战略,保证能够在最需要的时间将最需要的知识传送给最需要的人。这样可以帮助人们共享信息,进而将之通过不同的方式付诸实践,最终达到提高组织业绩的目的(王德禄,1999)。

概括来讲，知识管理指的是对企业(或组织)内所有与知识有关的活动、业务、计划及政策的系统管理。知识管理的过程包括对知识的识别、获取、开发、分解、使用和存储等。本书以数据挖掘得到的知识为对象,根据智能知识的特点,把智能知识管理定义为：
