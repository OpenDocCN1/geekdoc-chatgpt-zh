| 目标 | 有确定的商业目标,无合适的数据集 | 有确定的商业目标,有合适的数据集 |
| :--- | :--- | :--- |
| 选取情况 | 无确定的商业目标,也无合适的数据集 | 无确定的商业目标,有合适的数据集 |

对一、三象限“有确定的商业目标，有合适的数据集”和“无确定的商业目标，也无合适的数据集”比较容易处理；第二象限“无确定的商业目标，有合适的数据集”可以借助数据挖掘专家和运营管理专家的咨询，确定对应的商业目标进行挖掘；第四象限“有确定的商业目标，无合适的数据集”是很多企业所面临的，为了生存和发展的需要，企业迫切需要某一方面的决策支持，但没有合适的数据集提供挖掘分析，这时可以从外部资源如互联网、公共数据库等寻求数据集（李兴森等，2007b;李兴森等，2007d），根本的方法是转化组织内部的数据集。下面重点分析针对这种情况的可拓策略。

# 4.1.2 内部数据转换的可拓策略分析

任何数据集合包括目前的脏数据都是可拓的，通过变换都能挖掘出有价值的知识。关键是如何采取可持续的数据转换措施，减轻数据清洗的工作量，提高数据集利用的效率。

+   1. 数据集的物元集合分析

数据挖掘涉及三个多维物元和一个多维事元，用于数据挖掘的原始数据集可用多维物元 R₁ 表示，即

```
R₁(t) = [ N₁(t), c₁, v₁(t) 
         c₂, v₂(t) 
         ... ... 
         cₙ, vₙ(t) ] (4.1)
```

质量达到要求，可进行有效挖掘的数据集可用多维物元

```
R₂(t) = [ N₂(t), c₁, v₁(t) 
         c₂, v₂(t) 
         ... ... 
         cₙ, vₙ(t) ] (4.2)
```

表示，该物元为条件物元。数据挖掘过程可用多维事元

```
I = [ DataMining, b₁, u₁ 
     b₂, u₂ 
     ... ... 
     bₙ, uₙ ] (4.3)
```
