# 第 8 章 总结与展望

# 8.1 研究结论

本书结合国家自然科学基金项目“数据挖掘获取的知识的智能化管理研究”(70871111)、创新研究群体科学基金项目“数据挖掘与智能知识管理：理论与应用研究”,(70921061) 和“业务流程导向的知识管理研究”(70501030)等,对智能知识管理(IKM)的基本概念、原理、方法、关键技术和平台系统的设计进行了系统的研究,并结合某互联网公司的客户流失数据挖掘项目对 IKM 的理论、方法和获取的智能知识进行了应用实证研究。本书的主要研究内容有：

(1) 本书研究了数据挖掘获取的知识的智能应用。提出了智能知识管理的基本概念、原理和研究的体系框架。在阐明知识、智能知识、知识管理和智能知识管理定义的基础上，系统地分析了智能知识在知识管理中的意义、作用,明确了 IKM 的目标,建立了 IKM 研究的体系框架,阐述了智能知识实现的关键技术。

(2) 研究了智能知识的直接挖掘获取技术。引入可拓学理论,提出了基于可拓转化的决策树规则智能挖掘算法和基于 MCLP 的可拓分类算法,这两种算法获取的知识具有很强的目标关联性,提高了知识的智能性和有效性。

(3) 对智能知识管理的间接实现技术进行了系统的研究。在分析数据挖掘获取的知识表现形式和方法上,提出了智能知识的孵化方法。引入元知识、情景知识等,设计实现了智能知识的表达和存储,为后续功能的进一步研究和实现打下了基础。

(4) 在综合研究知识审计方法的基础上,提出了智能知识的自我审计方法,设计了智能知识的推理机制并初步实现了基于物元的推理算法,并提出了进一步应用 Agent 技术改进推理方法的设想。

(5) 对 IKMS 系统进行了研究。分析了 IKMS 系统的需求,建立了 IKMS 系统的体系结构,在此基础上详细进行了 IKM 系统的功能设计,讨论了系统原型的开发。

(6) 实证研究了智能知识在某互联网企业和服装企业的具体应用,验证了论文所提出的智能知识直接获取方法及智能知识的有效性,并分析了下一步研究和改进的方向。
