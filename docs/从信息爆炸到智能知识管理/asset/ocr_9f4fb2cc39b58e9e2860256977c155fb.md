# 5.3 智能知识的孵化过程

数据挖掘的原始知识转化成智能知识有两个主要步骤：首先设定初级筛选条件，通过软件过滤掉明显的没有价值的知识；其次通过人机交互的方式对过滤出来的知识进行审计、评分，得到有价值的知识；最后标识这些知识，通过增加元信息使知识具备记忆、识别、推理等功能。增加的记忆信息包括：产生知识的数据集、数据挖掘方法、创建人、知识的可信度、支持度、审计的分数、适用的部门、最后一次被检索或调用的时间、调用次数等。

这个过程就像鸡蛋的孵化，先选出受精的鸡蛋，然后提供适宜的温度、精心的照料，最后得到活泼可爱的雏鸡，所以我们称之为“知识孵化”，如图 5.2 所示。

智能知识的孵化分为四个阶段：

+   (1) 准备挖掘用数据集。过程和内容参见 4.1 节的描述。

+   (2) 获取原始知识。通过各种数据挖掘任务得到模式、规则、模型等原始知识。

+   (3) 获取有用知识。利用软件过滤工具，进行人机结合的选择、审计，从原始知识中筛选出认为有价值的知识。可以采用粗糙集理论和方法进行知识约简，在保持知识库分类能力不变的条件下，删除其中不相关或不重要的知识。
