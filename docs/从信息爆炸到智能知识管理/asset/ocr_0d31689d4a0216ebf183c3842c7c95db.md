在此基础上，智能知识管理系统的原型可以分为四个阶段开发：

第一阶段：核心模块原型开发。

选择智能知识管理引擎中的一个模块，如智能规则挖掘进行开发，其他系统模块开发成原型系统，测试整体技术路线的效率，制定基础构件的接口规范、技术规范，为后续的正式系统开发奠定基础。

第二阶段：基础组件开发。

实现基本构件的开发，如基元管理组件、智能变换组件、关联函数计算器、关联规则组件、分类函数、聚类函数、评价方法库、网络安全构件、原子服务构件等，为后续工作提供一个开发工具包；同时开发框架界面，定制服务接口规范，以便于进行组件的组装、测试。

第三阶段：应用软件配置。

根据不用的应用领域扩展开发领域通用构件，如智能分类软件、智能规则挖掘软件、智能聚类软件等，制定标准使用流程和 Web 接口规范。

第四阶段：Web 应用门户开发。

开发一个智能知识管理应用集成的网站，实现智能知识管理平台的功能，集成群体智慧促进智能知识的应用。对组织内部人员实现开源共享，集成智力资源，避免自成体系的开发模式，通过组件标准化及开源共享达到代码重用的目的，以标准化，规范化的方式不断完善系统功能。
