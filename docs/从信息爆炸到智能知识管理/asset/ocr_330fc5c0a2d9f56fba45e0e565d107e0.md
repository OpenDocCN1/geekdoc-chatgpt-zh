本书研究的知识对象主要指来源于数据和信息，通过数据挖掘方法产生的模式、规则、关系表达式等。这部分知识和数据、信息之间的关系是：

数据是对客观事物局部事实的记录，用数字、文字等符号表示，本身没有直接表达特定含义；信息是数据组合后所表示出的含义，是对数据做出的可理解的解释；知识是信息背后反映出的规律性的内涵，它一般表示为关系、表达式或模型（“知”），它具有产生行动的能力和应用的判断力，能指导行动、在实践中发挥作用（“识”）。信息的时效性较短，主要反映事物的表象；知识的时效性长，反映事物的本质规律。

# 2. 主体知识的特点

综合(潘旭伟，2005; 王众托，2004; 王德禄，2003; 魏江，2000)等的论述，知识具有下列特征：

+   (1) 知识具有静态的实体特性和动态的过程特性。知识的静态特性表现为一定结构的规则或实体，依赖于一定的载体而存在；知识的动态特性表现为知识是处于不断地产生、传递、使用和组合过程中。

+   (2) 知识的开放性。知识是一个开放的框架，通过知识的累积可以不断地评价和吸收新的知识，进而促进创新，知识开放的框架使得人们的知识越来越丰富。

+   (3) 有些知识是可以分享的，一个人掌握了某种知识，不排除其他人也可以同时掌握这些知识，而物质产品一般不具备这样的特征。

+   (4) 知识是可以穿越时空传递的，过去的知识可以流传到现在，一个地方的知识可以传递到其他地方。

+   (5) 知识是可以重复使用的，不存在损耗，并且在生产、传播和使用过程中，还会不断丰富和充实。

+   (6) 知识是可以再生的，具有无限复制扩散的能力。

其中特征(1)对知识的认识具有较强的指导意义。美国学者维娜·艾莉称之为知识的“波粒二相性”。作为实体的知识和作为过程的知识，“实体”和“过程”是统一的。

在对知识动态性的分析上，国内一些可拓学的研究者提出了变化的知识(可拓知识)(陈文伟等，2006)。

可拓学的传导原理表示为变换蕴含式，它是变化的知识：

```
(T_u u = u') \rightarrow (_u T_v v = v') \quad \text{简写为} \quad T_u \rightarrow {}_u T_v \quad (2.1)
```

在可拓学中，可拓变换 $T_u$ 可能由某个条件(原因)产生或者可拓变换会引起某个结果，与可拓变换有关的具有因果关系的规则式，称为变换蕴含式的可拓知识。变化的知识用关联函数衡量转化的程度(杨春燕等，2002)，当关联函数由正数变为负数，表明矛盾问题得到解决。
