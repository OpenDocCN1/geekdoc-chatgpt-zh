# 3. 从数据录入环节采取措施

系统应用环节涉及数据录入人员的价值观、心理状态，涉及信息系统实施、维护等的管理，主要措施包括：培训录入人员的数据价值意识，减少录入过程发生的人为错误；制定维护数据完整性、准确性的管理制度，包括流程、检查方式、奖罚措施；新旧系统更换时制定衔接措施和数据一致性方案；调整日志等数据的保留时间；实施数据的局部决策应用，如综合查询、报表、OLAP 分析等。

# 4. 从软件设计环节采取措施

基于数据挖掘需求调整数据结构、存储方式；设计增加应该采集的用于挖掘必需的数据字段；对数据字典进行统一的明确、一致的定义，如计量单位一致；不同系统、不同模块之间的命名规则、字段编码一致；数据存储格式一致等；校验下拉选择框等控件中的数据及可选择项的完整性等；将难以收集的数据设计成非必填字段；增加高级别的数据完整性约束及组件内嵌控制信息；对字段值是否合法（有效范围之内，符合逻辑）进行软件检验等；设计时对数据库存储格式进行强制转换、标准化。

# 5. 从需求分析环节采取措施

需求分析时把决策支持的需求和业务操作的需求结合，咨询数据挖掘专家，或请数据挖掘专家参与需求分析；从战略管理目标出发设计信息化战略规划，制定决策支持需求计划，制定数据挖掘进度规划等。

采取改进措施后，抽取数据样本对比数据差距，如果差距在不可用范围内，继续改进。如果数据达到可挖掘标准，就由咨询、试验阶段进入数据挖掘项目的正式实施阶段，一旦数据挖掘的结论为业务决策带来价值，公司管理层、业务人员就会更加重视信息系统数据的质量，也会采取一些促进信息化建设的措施，如增加投入、加强管理、重视数据分析、制定数据质量检验的标准、引入数据质量管理平台、加大数据误差的处罚力度、购买新技术和新软件等，对数据的需求增加，会促使更多的数据集成，新数据集成后又会发现质量问题，进入下一循环的数据挖掘咨询、项目实施。数据挖掘的实施又促进信息系统的进一步完善，并为数据挖掘咨询提供更好的经验、建议。
