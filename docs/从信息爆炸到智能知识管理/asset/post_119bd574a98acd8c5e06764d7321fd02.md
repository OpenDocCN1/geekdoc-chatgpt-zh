
原因在于现有的分类挖掘是基于经典集合论和模糊集合论为基础的，经典集合论要求数据论域中每一个对象关于某个集合，要么属于它，要么不属于它，两者必居其一，且只居其一。经典集合中是用值域{0,1}的特征函数定性地描述事物是否具有某种性质，相应的分类是“类内为同，类间为异”，用它无法定量地描述事物具有某种性质的程度；模糊集合中是用值域为(0,1)的隶属函数描述事物处于中介过渡的差异具有某种性质的程度，但对于论域中隶属度为0或1的对象也不加区别，仍是“类内为同”的表达(蔡文,1994)。无论是经典集合论还是模糊集合论，它们都不研究事物类别之间的变化，因而无法直接描述在一定条件下“非”与“是”类别间的转化(蔡文,1994)。客观而言，许多事物均可按某性质P一分为二，其中“不具有性质P”的又可分为在一定条件下“能转化为具有性质P”的和“不能转化为具有性质P”的两类。

近年来，可拓学理论在数据挖掘领域得到了初步的应用，并取得了很好的效果。李立希等(2004)对可拓学在数据挖掘中的应用做了展望式介绍，陈文伟等(2006b)提出了可拓知识的概念，认为可拓学的拓展式是可拓知识的基础知识，可拓学的传导原理的变换蕴含式是变化知识，可拓学引入关联函数将矛盾问题进行量化处理成为量化知识。张应利等(2001)利用物元的发散性、相关性、蕴含性探讨了相应的各种潜信息挖掘方法。黄金才等(2006)利用可拓变换，提出从变化的角度使假命题变为真命题，把不可知问题变为可知问题，把不可行问题转换为可行问题的思路，并给出了通过可拓变换，获取变化知识的概念和理论。上述文献为我们进一步的研究打下了基础。

决策树分类是最常用的数据挖掘方法之一(Han et al, 2006; Quinlan, 1986)，其分类规则的可解释性较强。本书拟从可拓集合的基本思想和方法出发，研究一种事物类别间转化知识的获取方法，在决策树方法获得的规则基础上，挖掘事物类别间转化的规则知识，并设计算法实现。

## 4.2.1 转化规则挖掘的理论分析

转化规则挖掘的可拓学理论基础有三：一是物元的可拓性理论(蔡文,1994)，任何事物都存在变化发展的可能性；二是可拓变换理论(蔡文等,2004)，通过一定的变换，事物的性质会发生变化；三是可拓集合理论，反映事物性质转化的程度。

可拓集合用(-∞, +∞)中间的数来描述事物具有某种性质的程度，并通过可拓变换来描述事物“是”与“非”的相互转化。它根据事物特征状态的关联函数值和可拓变换(包括论域的变换、关联函数的变换和元素的变换)把所讨论的论域分为三个部分，即稳定域、可拓域和拓界。

稳定域是在可拓变换下关联函数值符号不变的部分，表示在某变换下，其性质不产生质的变化的元素。事物的变化在稳定域内进行的，属于量变的范围。元素具有某种性质或符合某一要求的程度是可以变化的。根据变化的方向不同，可拓域又分为正可拓域和负可拓域。可拓集合的正可拓域表示集合外的一部分元素，它们不具有某种性质，但通过可拓变换而变为具有该性质；负可拓域表示集合内的一部分元素，它们具有某种性质，通过可拓变换后而变为不具有该性质；显然，不同的变换具有不同的可拓域。可拓域中的元素，经过变换产生了质变。同样，正稳定域和负稳定域表示在某变换下其性质不发生质的变化的元素；关联函数值为零的部分是零界。零界或拓界描述了质变点，超过它们，事物就产生质变。其示意图如图 4.2 所示。

![](img/5ca02fe6dafc13fdc40bf6907227ca5c_95_0.png)

图 4.2 可拓集合中关于元素变换的论域划分

元素的变换、关联函数的变换和论域的变换，统称为可拓变换。这样，通过可拓集合就把分类与变换联系起来，并以此为基础进一步挖掘类别转化的规则。

将数据挖掘得到的规则知识通过可拓变换，转换为事物类别转化的决策策略，称为规则挖掘，它是对数据挖掘的进一步扩展和延伸。针对不同的业务和领域需求，通过特定的可拓变换，一个集合中的物元可以变换到另一个集合。如流失客户在特定的变换条件下可以成为忠诚客户，现有正常客户在一定条件下也会成为流失客户。

决策树作为数据集分类器，在数据挖掘中有着广泛应用，但其结果是静态的分类数据子集，仅描述不同树枝上的树叶特点，处理复杂性的数据时，分支数非常多，从而产生的规则数量多而在结果中真正令人感兴趣的规则比例太小，仅凭分类规则难以采取有效的措施防止客户流失。将决策树挖掘的结果用物元可拓集表示，从而将传统的静态规则集转化为变化的、动态的可拓规则集，就可以变静态的描述性知识发现为动态的策略生成。下面阐述基于决策树的可拓转化策略的获取方法。

## 4.2.2 转化规则获取的方法

### 1. 决策树分类规则分析

决策树(decision tree)是一个类似于流程图的树结构，其中每个内部节点表示在一个属性上的测试，每个分枝代表一个测试的输出，而每个树叶节点代表一个类别。决策树主要是基于数据的属性值进行归纳分类，从树的最顶层节点（根节点）到存放该样本预测的叶节点遍历，就可以将判定树转换成“if-then”形式的分类规则。以 See5 方法得到的规则为例，其形式如下：

```
“Rule 2: (198/14, lift 2.7)
是否使用随身邮服务 = 0
POINTS <= 6
使用时间长短 > 92
Type = 6
--> class 0 (0.925)”
```

其中，Rule 2 中的 198 表示训练集中符合该规则的记录条数，14 表示训练集中不符合该规则的记录条数，预测准确率 = (198 - 14 + 1) / (198 + 2) = 0.925，提升度 lift = 预测准确率 / 训练集中该类出现的相对频率 = 0.925 / 0.343 = 2.7。

### 2. 转化规则挖掘的方法

在决策树分类规则的基础上，结合可拓集合理论，对规则做可拓变换的挖掘，以便获取类别转化的策略。下面以两种类别的转化为例：

设{A}为类别 A 的规则集合，设{B}为类别 B 的规则集合，其中对两类规则中相同的属性，对属性值做 A<->B 置换变换；对 B 中有而 A 中没有的规则，做增加变换；则必存在一个变换集合 $T_{AB}$，使得

$A \Rightarrow B$

称为转化规则知识，称

$T_{AB}B_i \to A_j \Rightarrow TB \to A$

为转化规则知识，称

$T_{AB}B_i \to A_j$

为规则知识的前件，称

$TB \to A$

为规则知识的后件。举例如下：

通过原始知识

```
是否使用随身邮服务 = 0
POINTS <= 6
使用时间长短 > 92
Type = 6
--> class B (0.925)
Rule 3:(6,lift 2.7)
是否使用随身邮服务 = 1
POINTS <= 6
使用时间长短 <= 795
--> class A (0.875)"
```

# 得到转化规则知识

```
'Rule6: (6/9) support:4.25% ID:240-235
Under:
POINTS<=6(same)
92 < 使用时间长短 <= 795(same)
Trans:
是否使用随身邮服务=1 to =0
Add: none
--> class A to B (61.70%)"'
```

其中，ID:240-235 是产生转化规则的源规则编号。

“Under:”下列出的是类别 A 中有而目标类别 B 中没有的规则和完全相同的规则(后面加 same 标识)。

“Trans:”下列出属性相同，数值不同的规则，并根据目标类别中的数值对条件类别中的前件值进行转换。

“Add:”中复制 B 中有而 A 中没有的规则作为附加转换条件。

“POINTS<=6”,“92<使用时间长短<=795”,和“是否使用随身邮服务=1”是规则知识的前件，“是否使用随身邮服务=0”和“none”是规则知识的后件。

### 3. 转化规则的评价指标

设数据库表中{A} U {B}的记录数为|D|，对某一转化规则，设{A}中符合该规则前件的记录条数为Fa，{A}中符合该规则后件的记录条数为Ra，{B}中符合规则Tab前件的记录条数为Fb，{B}中符合该规则后件的记录条数为Rb，所有满足规则集前件条件的记录数为F，所有满足规则集后件条件的记录数为R，{D}中符合规则集 A 的记录个数记为|D(A)|，{D}中符合规则集 B 的个数记为|D(B)|，为清楚起见，以表 4.2 表示如下。

| 类别数 | | 符合前件记录数 | 符合后件记录数 |
| :--- | :--- | :--- | :--- |
| A | \|D(A)\| | F_a | R_a |
| B | \|D(B)\| | F_b | R_b |
| 小计 | \|D\| | F | R |

则,规则的准确率
\(P_{iAB} = (R_b + 1)/(R_b + R_a + 2)\) (4.5)

预期的转化率
\(T_r = F_a/F\) (4.6)

该规则的支持度为
\(S = \frac{|F|}{|D(B)|}\) (4.7)

可信度为
\(R = \frac{|R_b|}{|R|}\) (4.8)

例如，“Rule6:(6/9)support:4.25% ID:240-235”中, 6 是符合转化条件的记录条数, 9 是符合 under 前件条件的 A 的记录条数。 support: 4.25% 是支持度, 61.70% 是可信度。

## 4.2.3 获取转化规则的挖掘算法及实现步骤

### 1. 转化规则的挖掘算法

转化策略挖掘的简要算法如下。

输入: 基于决策树数据挖掘生成的结果集(两类分别以 A,B 表示),以及二个集合中元素可以变换的最小相当记录数 n。

输出: A 中物元在 \(T_k K (T_r R)\) 条件下可变换到 B 中的变换策略。

算法实现如下。

- (1) 将 A,B 中元素分别以多维物元 \(W_1\) 和 \(W_2\) 表示, \(R_{1m}, R_{2m}\) 分别表示 \(W_1, W_2\) 中第 m 个物元;
- (2) for i=0 to A 集物元个数;
- (3) for j=0 to B 集物元个数;
- (4) 定义整数 total 等于 0;
- (5) 设 \(R_{1i}\) 的维数为 \(N_i\), \(R_{2j}\) 的维数为 \(N_j\);
- (6) for k=0 to \(N_i\);
- (7) for kk=0 to \(N_j\);
- (8) if \( R_{1i} \) 第 \( k \) 维特征、量值与 \( R_{2j} \) 第 \( kk \) 维特征、量值分别都相同；
- (9) total=total+1；
- (10) 结束 \( k,kk \) 循环；
- (11) if total 大于或等于系统输入值 \( n \), then 将 \( R_{1i} \) 与 \( R_{2j} \) 输出到一条变换策略；
- (12) 结束 \( i,j \) 循环；
- (13) 程序结束。

### 2. 转化规则的实现步骤

- 1) 读入原规则集  
  以 See5® 决策树软件为例，初始规则集以文本文件的形式保存在.out 文件中，规则格式如上面例子所示，其中，Rule 2 中的 198 表示训练集中符合该规则的记录条数，14 表示训练集中不符合该规则的记录条数，预测准确率 = (198-14+1)/(198+2)=0.925，提升度 lift 2.7=预测准确率/训练集中该类出现的相对频率。将分类规则依次读入数据库，存入规则表中。

- 2) 规则集预处理  
  剔除重复读入过程中产生的相同规则，建立关键词全文索引等。

- 3) 设定挖掘参数  
  由用户设定如下参数：
  - (1) “挖掘由 class ______ 向 class ______ 转化的规则”,如示例中的 class 0,class 1 等。
  - (2) “规则内容相同的条数>=______条”,如示例中 rule 2 和 rule 3 中有“POINTS<=6”,“92<使用时间长短<=795”2 条相同。
  - (3) “规则内容不相同的条数<=______条”,如示例中 rule 2 和 rule 3 中有“是否使用随身邮服务”1 条规则前件的值不相同。
  - (4) “可拓规则预期转化率>=______%”,应用可拓规则预期的转化率=规则集中符合转化规则的记录数/规则集中所有满足前件条件的记录数。

- 4) 规则挖掘  
  在规则库中寻找规则相同条数多，不相同条数少的规则，通过比较产生转化的规则输出。假如示例中设定：
  - (1) “挖掘由 class 0 向 class 1 转化的规则”
  - (2) “规则内容相同的条数>=2 条”
  - (3) “规则内容不相同的条数<=2 条”,

  则输出规则如前面例子中的 rule6 所示，其中，“Rule6 : (6/9) support: 4.25%

  ID:240-235”中，6 是符合转化条件的记录条数，9 是符合 under 前件条件的 class =0 的记录条数。 support:4.25%是支持度，ID:240-235 是产生转化规则的源规则编号。

  “Under:”下列出条件类别 class 0 中有而目标类别 class 1 中没有的规则和完全相同的规则(后面加 same 标识)。

  “Trans:”下列出属性相同，数值不同的规则，并根据目标类别中的数值对条件类别中的前件值进行转换。

  “Add:”中复制 class 1 中有而 class 0 中没有的规则作为附加转换条件。

  最后显示转换的结果：“—> class 0 to 1(61.70%)”，(61.70%)是规则预期转化率。

- 5) 规则评价指标计算  
  为评价可拓规则的实用性和新颖性，分别计算准确率、预期转化率、支持度和可信度等指标。

- 6) 显示结果报告  
  挖掘结束提供转化规则列表以及挖掘情况的总结报告。

## 4.3 获取智能知识的可拓分类算法

分类是最普遍的数据挖掘方法之一。目前，常用的分类方法包括贝叶斯分类、判定树归纳分类、神经网络分类、邻域分类、遗传算法分类、基于粗糙集理论的分类、模糊集分类、MCLP 分类等。本节基于 MCLP 分类方法提出一种新的分类算法，以获取智能知识。

### 4.3.1 MCLP 分类原理

MCLP 分类方法已在数据挖掘中得到较为广泛地应用(Li et al, 2006; Kou et al, 2003; Shi, 2001; Shi et al, 1989)，以典型的信用卡客户数据为例，模型解释如下：

对于一个信用卡持卡客户 \( i \), 可以用 \( r \) 个属性变量来刻画其行为, 这里不妨用 \( A_i = (A_{i1}, A_{i2}, \cdots, A_{ir}) \) 表示该持卡用户, \( i=1, 2, \cdots, n \) 为持卡用户的个数即为样本的总个数, 建模目的是想得到关于 \( r \) 个属性的系数 \( X = (x_1, x_2, \cdots, x_r)^T \) (或者称之为评分系数或者权重) 和边界 \( b \) 来划分信用卡客户, 在这里有违约或破产倾向的客户记为 \( B \) (坏人), 信用良好的客户记为 \( G \) (好人), 则信用客户数据集可以通过如下模型进行划分：

\( A_i X \leqslant b, \quad A_i \in B(\text{Bad}) \)
\( A_i X \geqslant b, \quad A_i \in G(\text{Good}) \) (4.9)

为了不失去一般性, 在下面的分析中, 假设正常分布下“坏人”集合 \( B \) 的评分在边界的左边, “好人”集合 \( G \) 的评分在边界的右边, 用符号 (\(\star\)) 记作“好人”, 用 (\(\cdot\)) 记作“坏人”, 则 MCLP 模型的思想可以由图 4.4 表示如下。

![](img/5ca02fe6dafc13fdc40bf6907227ca5c_101_0.png)

图 4.4 带有重叠部分的二分类问题示意图

通过求目标函数的最优值, 让两条边界靠的最近, 理想状态下成为一个分类边界。有重叠部分的思想优点在于: 可以较容易地利用线性规划技术来解决分类问题, 而不利的地方在于必须在两个最优目标之间寻求一个妥协解。Shi 等 (2005) 通过求解多目标线性规划的妥协解, 使错分距离最小化和对分距离最大化两个最优目标同时成立。

具体建模如下：

```
(M4) Minimize \(\sum_{i} \alpha_i\) and Maximize \(\sum_{i} \beta_i\)
Subject to:
\(A_i X = b + \alpha_i - \beta_i, \quad A_i \in B\)
\(A_i X = -b - \alpha_i + \beta_i, \quad A_i \in G\)
(4.10)
```

其中，\(A_i\) 为给定的属性变量矩阵，\(X\) 和 \(b\) 为无约束变量，而且 \(\alpha_i \geqslant 0, \beta_i \geqslant 0\)。

基于平衡训练集的多目标线性规划模型可以被训练成一个好的分类器。

以上介绍的分类方法都是基于历史数据的分析，用历史数据中静态的属性特征、权重等对未知数据集进行分类。评价分类效果的指标主要是准确率和 KS 值。有时，即使分类的准确率高于 80%，实践应用中也仍然存在误分和难以采取转化措施的困惑。原因可以用示意图 4.5 说明。

![](img/5ca02fe6dafc13fdc40bf6907227ca5c_102_0.png)

图 4.5 基于可拓域的 MCLP 分类方法示意图

因为正确分类的部分往往是图 4.4 分界虚线的两侧，所谓的特征明显的顽固派和忠诚派，这两类特征往往容易发现，利用分类结果实现金融风险的预防有一定的效果。但对客户流失分析而言，这种分类很难为预防客户流失提供措施上的支持。现实生活中，分类最容易出错的部分即图 4.4 中的交叉区域也是最有应用价值的部分，这类客户好坏的特征很不明显，实际生活中可能确实处于摇摆状态，一个很小的行动可能会导致其流失，另外一个措施可能促使其从即将流失状态转变为忠诚用户，故称之为动摇派。实践应用中的一个主要需求就是如何实现动摇派向忠诚派的转化，并预防动摇派转化成顽固派。
