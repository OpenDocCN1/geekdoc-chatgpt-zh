(4) 贡献评估。和其他智能知识通过结合、推理产生新的智能知识，且新知识被应用后反馈分数大于指定值的，增加评估分数。
(5) 序列评估。随着新数据集的挖掘产生了一系列新的智能知识，其中有的知识和原有知识类似，对原有知识具有印证、对比分析或在原有知识基础上扩展功能的，增加原有知识和新知识的评估分数。
(6) 聚集评估。新产生的智能知识带有某一特色的标识，能够使原有很多知识聚集成智能知识聚集体，为特定商业目标服务的，增加新知识的评估分数。
第四步，根据业务目标，设定初始的知识自我评估准则的权重如表 5.4 所示。

# 表 5.4 智能评估规则指标及权重表

| 序号 | 指标 | 权重 | 指标解释与评分标准 |
| :--- | :--- | :--- | :--- |
| 1 | 使用频率 | 25% | 使用次数×人数×部门数 |
| 2 | 质量等级 | 12% | 初评分数×100/连续未被使用的天数，分为 5 级 |
| 3 | 冲突次数 | 10% | 冲突中取胜的次数 |
| 4 | 派生度 | 15% | 产生有效新知识的数量 |
| 5 | 印证度 | 10% | 被其他知识印证的次数 |
| 6 | 聚集度 | 18% | 形成的知识聚集体中包含的最大知识条目数量 |
| 7 | 媒介度 | 10% | 作为中间载体形成知识聚集体的数量 |
| 小计 | | 100% | |

上述指标均做归一化处理后参与总分的计算。设知识的综合自我评估分数为 S，指标为 K，权重为 W，则计算知识运用过程中的分数公式为

```
s = \sum_{i=1}^{n} K_i \cdot W_i (5.1)
```

有用知识经前面论述的智能化处理后存入智能知识库，智能知识库的知识通过智能知识管理系统被业务管理系统和运营管理系统调用、检索、利用，称为执行系统。根据执行的效果，参照设定的初始规则，在被利用过程中不断加分或减分，称为信用评分。

第六步，实现知识的自我筛选、淘汰。业务目标的启动会迅速将智能知识组织起来，通过应用效果的正反馈，经验被积累了起来：强健的、经常被使用的知识会变得更强健，而弱小、不经常使用的知识会萎缩。被经常使用的知识强健到一定程度以后，这些分数高、有价值的知识逐渐形成知识聚集体，成为知识积木块，其本身包含成百上千条智能知识，可以在更大的范围内被检索利用。分数低的没有价值的知识则沉淀成为知识淤泥，被逐渐淘汰。
