# 3.7 本章小结

本章对智能知识管理的基本概念、原理和理论框架进行了研究，主要工作如下：

+   (1) 在综述知识、知识管理定义和分类的基础上，提出了智能知识的概念，并分析了智能知识的特点，进而给出了智能知识管理（IKM）和智能知识管理系统（IKMS）的概念，阐明并讨论了 IKM 的目标。

+   (2) 论述分析了智能知识管理的理论基础，认为智能知识及其管理是一个复杂性系统，其要素包括有用知识、智能知识和业务专家的经验，应综合利用认知心理学、人工智能、复杂性理论、系统科学理论和可拓学理论与方法等进行综合集成设计，人机结合。

+   (3) 提出了 IKMS 的体系框架，该体系框架由支撑条件层、技术层、方法层和应用层四个层次构成。支撑条件层为 IKM 准备数据环境和管理环境；技术层从具体的技术上探讨如何支持智能知识和智能管理模式的实现；方法层则讨论智能知识管理过程与综合集成的方法；应用层将 IKM 与业务流程集成，实现 IKM 的目标。

+   (4) 研究论述了支持智能知识管理的五项关键技术：获取智能知识的新的数据挖掘算法技术、具有记忆能力的智能知识表达技术、主动进化的智能知识的自我审计技术、具备社会性的智能知识通信与推理技术和基于情景识别的智能知识主动推送技术，分析了这些技术之间的相互联系，并选取了优先实现的技术。

+   (5) 论述了智能知识管理模式在组织中实施的支撑条件，主要是制度保障体系方面，理念上强调客户价值，管理制度上给出了具体的流程和方法。

本章的研究为后续章节的实现奠定了基础，并设定了深入研究的方向。
