的知识仓库体系结构(Nemati, 2002)。

为了避免专家知识流失，构建基于知识的系统（knowledge-based system, KBS)是有必要的。KBS 建立在人工智能基础上，其目的是让计算机理解并存储人们的知识（Wiig, 1994）。KBS 经过一二十年的发展，取得了巨大成绩，如提出了构建 KBS 的系统化方法：CommonKADS 方法（Schreiber, 2003），建立了大量的 KBS(McMeekin, 2002; Tian, 2002)。KBS 是知识工程过程的成果，应当被用于更大视野的知识管理(Schreiber, 2003)。近年来，一些学者（李兴森等, 2007d; 陈文伟等, 2006）提出用可拓学（蔡文, 1994）的基元（蔡文等, 2004）存储知识，使知识的表达内容更加丰富，详细内容见第 4 章。

# 3. 知识的传播共享技术和工具

知识管理的一个关键是知识的传播和共享：在员工之间、员工和管理者之间、各部门之间的知识传播共享等，让正确的知识在正确的时刻到达正确的人。知识的传播共享技术和工具主要实现隐性知识之间、显性知识之间以及将隐性知识转化为显性知识进行传播共享。

为实现隐性知识之间的传播共享，知识黄页（赵曙明，2000）以一种类似于传统电话号码黄页的工具，根据知识门类，将那些拥有知识的人的地址和电话号码标在知识黄页上，帮助企业了解组织内部知识分布的大致情况，以及帮助公司员工通过黄页，了解谁拥有自己所需的知识、经验和诀窍等。Desouza 等认为信息技术对隐性知识交流共享的主要作用是通过工具（如电子邮件、知识黄页）与目标人物建立联系（Desouza, 2003）。动态知识地图（dynamic knowledge map）（Woo, 2004）软件是一个基于 Web 的知识导航器，帮助人们重用专家的隐性知识，它能搜索专家并通过使用 Internet 技术方便地与这些专家进行交流。

实现知识传播共享的另一类重要技术和工具是基于互联网的论坛、新闻组以及称为群件的软件包。这类技术和工具的特点在于它能够提供虚拟的工作平台，在这个平台上，人们可以交流看法、协同工作。在人们交流的过程中，这类系统不仅保存交流形成的文档，还能捕捉交流和互动的线索，保留知识的情境。著名的群件工具有 IBM 的 Lotus Notes 和微软的 Exchange Server 等。Buckman 公司采用了一个称为 K’Netix 的在线论坛的知识共享知识管理系统（Stepanek, 2001），集中用于讨论造纸、水处理和皮革退色等过程中的化学问题。Koh 等开发了一个虚拟社区活动框架，在这个框架中，以一个电子商务模型把知识共享活动集成到商业活动中(Koh, 2004)。
