其他关系元。

关系程度的变化表达关系的建立、加深、中断、恶化等，它可以是正值、零或负值。在解决矛盾问题时，人们要面对数量众多、纷繁复杂的人、事、物和关系。决策者的一项基本任务就是要理清人与人、事与事、物与物、人与事、人与物、事与物之间的关系，并在此基础上进行创造性思考，使得这些要素间能够相互协调，相互促进，以实现目标。因此，如何去认识这些关系就显得尤为重要。因为从本质上去把握这些关系，需要经过一个去粗取精、去伪存真、由表及里的艰苦探索过程。

# 2. 信息的基元表示方法

可拓学从形式化的角度，利用基元和复合元，研究了信息的基元表示方法。以复合基元或其运算式表示的信息统称为复合信息元。根据语法信息的各种不同表述方式，可以用不同的基元形式表述之。

+   1) 用物元表达陈述型信息

陈述型信息指用陈述型的语法表达的信息，包括物、概念、命题等提供的信息，都可用物元形式化表达。例如，“A 经理是 B 公司一位出色的管理者”，是一条陈述型信息，可用物元形式化表示为

```
[A,    职务,    经理
    服务单位, B 公司
    职业,    管理者
    水平,    高]
```

+   2) 用事元表达行为型信息

行为型信息指用行为型的语法表达的信息，多指“作为过程的信息”，这种信息可以利用事元形式化表示。当某人获取这种信息后，可以知道某件事或某个过程。从这个意义上看，这种信息即“告知……的行为，某种事实或情况的知识或消息的传播，告知的行为或被告知的某事的事实”。

例如，“A 公司今天在俱乐部举行职工大会”，这是一条行为型信息，可用事元形式化表示为

```
A1 = [举行,    支配对象,    职工大会
      施动对象, A 公司
      时间,    今天
      地点,    篮球场]
```

+   3) 用关系元表达关系型信息

关系型信息指用关系型的语法表达的信息，这种信息可以利用关系元形式化表示。当某人获取这种信息后，可以知道某种关系。
