两个最优目标同时成立。

具体建模如下：

```
(M4) Minimize \(\sum_{i} \alpha_i\) and Maximize \(\sum_{i} \beta_i\)
Subject to:
\(A_i X = b + \alpha_i - \beta_i, \quad A_i \in B\)
\(A_i X = -b - \alpha_i + \beta_i, \quad A_i \in G\)
(4. 10)
```

其中，\(A_i\) 为给定的属性变量矩阵，\(X\) 和 \(b\) 为无约束变量，而且 \(\alpha_i \geqslant 0, \beta_i \geqslant 0\)。

基于平衡训练集的多目标线性规划模型可以被训练成一个好的分类器。

以上介绍的分类方法都是基于历史数据的分析，用历史数据中静态的属性特征、权重等对未知数据集进行分类。评价分类效果的指标主要是准确率和 KS 值。有时，即使分类的准确率高于 80%，实践应用中也仍然存在误分和难以采取转化措施的困惑。原因可以用示意图 4.5 说明。
