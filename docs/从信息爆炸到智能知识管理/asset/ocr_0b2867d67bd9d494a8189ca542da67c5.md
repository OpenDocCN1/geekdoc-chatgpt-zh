第一，自然科学的飞速发展产生了一系列新学科，20 世纪 50 年代以来，知识急速增长，无论是知识的广度还是深度，都远远超过了历史上任何时期。人类活动范围的扩展，增加了对知识的需求，也促进了新知识的产生。据计算，全世界的知识总量，平均 7～10 年翻一番。

第二，随着信息技术的迅速发展，管理信息系统、互联网、富媒体等正在不断改变人类社会的环境。互联网资源中、企业公开报表中、社会各组织的公共数据“库中，各类媒体中，充斥着大量的知识和信息。管理信息系统使管理的广度和深度都得到提高的同时，积累了大量的数据，数据挖掘技术应运而生。数据挖掘（data mining）作为商业智能的重要工具之一，是一种数学模型、人-机系统和管理科学相结合的新的信息技术方法。这种方法利用关联规则（association）、分类（classification）、聚类（clustering）、预测（prediction）、相随模式（sequential patterns）和时间序列（similar time sequences）等手段从大量的、不完全的、有噪声的、模糊的、随机的数据中，提取隐含在其中的、人们事先不知道的、但又是潜在有用的信息和知识，这些新的知识可以用来制定有效的商业战略去吸引新的顾客和维持已有的顾客、开发适销的产品等。近年来，数据挖掘在生物、金融、保险、零售等行业已得到较为广泛的应用，成为信息时代决策支持的关键技术之一，它会聚了数据库、人工智能、统计学、可视化、并行计算等不同学科和领域，近年来受到各界的广泛关注。

据 Gartner 公司的统计及预测，2009 年，由于缺乏有效的信息处理过程与工具，全球化的 5000 家企业中的 35％以上的企业无力面临商业与市场剧烈变化中做出有效的决策。至 2012 年，企业将在以数据挖掘为基础的数据分析上花费至少 40％的预算。

数据挖掘得到的知识主要表示为以下几种：关联规则、分类规则（包括决策树、网络权值、判别方程、概率图等）、聚类、公式和案例等。关联规则（association rules）是最常用的一种方法，它挖掘记录与属性间的关联性，发现记录之间的关联关系和相关关系，并将这些关系表示为规则形式。一个典型例子就是“啤酒和尿布的故事”。数据挖掘人员通过对超市销售交易数据的分析，发现啤酒和尿布同时购买的比例非常高。经进一步的调查发现，原来是有孩子的父亲在给刚出生不久的子女购买尿布时，也常会给自己购买啤酒。根据以上信息，超市人员便及时调整了物品的摆放结构，让客户的购买更加方便，从而提高了啤酒的销售量。
