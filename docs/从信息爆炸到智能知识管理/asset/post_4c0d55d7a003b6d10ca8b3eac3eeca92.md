
的参考作用非常有限。

上述特点给数据挖掘的应用带来了一定困难。

## 2.2.5 数据挖掘在应用中面临的问题

尽管数据挖掘技术已经得到普遍的认可和较为广泛的实施，但由于挖掘结果知识的特点，在实际应用中仍存在如下问题：

- (1) 在数据挖掘结果的评价上，大部分学者将注意力集中在如何获取准确的模型上，而很少对挖掘出的结果进行分类、评价或形式化，进而支持企业决策(Mcgarry, 2005)。数量繁多、质量粗糙导致其结果离实际的商业应用还有较大的距离。例如，某数据挖掘项目通过运用决策树分类算法，对用户分为“现用用户、冻结用户和流失用户”，并预测用户类型，得到了 245 条规则。但业务人员难以从这些规则中获取促使用户转化的知识。上述问题涉及数据挖掘中规则结果的评价问题，对于数据挖掘研究应用是很重要的，但目前对于这个问题的标准的、系统的研究离应用需求还相去甚远。

- (2) 数据挖掘获取的知识的表达和解释上，数据挖掘所获得的知识要以不同的形式来表示，并以容易理解的形式展现给用户，重要的是提供给用户能够理解的知识。这就要求知识的表达不仅限于数字或符号，而且要以更容易理解的方式，如图形、自然语言和可视化技术等以利于使用者理解使用，而目前数据挖掘在这方面的研究还不够深入。

- (3) 数据挖掘过程中的人机交互方面，由于知识结构的复杂性和认知过程的渐进性，要求知识发现技术在不同的抽象层次上要进行交互发掘。有效的决策过程往往需要经过多次人机交互和反复。在数据挖掘过程中保留必要的中间结果，通过人机交互、动态调整挖掘目标、用户的背景知识和指导作用可以加快挖掘的过程，并且保证了所获得知识的有效性。而目前的系统或工具则很少能真正让用户参与到挖掘过程尤其是对挖掘的结果的再处理之中。

- (4) 与知识应用情境的结合方面，数据挖掘产生的模式或规则要在实践中使用必须结合具体的情境，这里的情境既包括相关的物理、业务等外部环境因素、背景因素，又包括主体的认知、经验、心理等内部因素。它是完整理解知识的关键要素，影响人们对知识的评价。某一条规则在一种情境、某个决策者、时间点可能是有用的，但是换个情境可能就没有价值。知识是在各种不同的情境下产生创造的，没有合适的情境信息，知识将与其他相关知识相互隔离，不能完整地理解知识的含义或错误地理解知识含义。因此情境对于数据挖掘及数据挖掘结果的处理非常关键(潘旭伟, 2005; Goldkuhl, 2001)。

以上欠缺导致这一交叉学科的发展落后于其商业应用的现实需求。利用数据挖掘等工具，产生大量的模式和规则，一般只是初步的粗糙的知识，用户不能很好地理解它们，从而无法把精力集中在其中真正感兴趣的子集上，为决策提供支持。这就需要结合知识管理的研究成果，从人机结合的角度对产生的知识进行二次分析、挖掘以产生更好的决策支持效果。

## 2.2.6 本节小结

通过前面大量的文献分析可以看出，数据挖掘的研究主要集中在数据挖掘任务及其实现算法、数据挖掘本身的过程、理论方面。往往把挖掘出知识作为挖掘过程的结束，对数据挖掘获取的知识形式有所涉及，但缺乏对数据挖掘获取的各种知识如何真正为决策服务应用的研究，将数据挖掘和知识管理结合起来进行系统研究的文章更少，作者统计了 Web of Science, ISI Web of Knowledge, Ei Engineering Village, CNKI 中与知识管理和数据挖掘相关的文章共有 74451 篇，其中把数据挖掘和知识管理同时作为关键词或主题的文章只有 635 篇，占知识管理的 2.64%，占数据挖掘的 1.26%。（详见附录），且主要集中在文献综述（韩客松，2001）或数据挖掘作为知识的来源和应用上（罗锦珠，2005），基于数据挖掘的知识管理系统研究（钟英姿，2006）也是把数据挖掘作为获取知识的来源。基于数据挖掘获取的知识的复杂性，如何有效应用成为决策支持的难点和研究的空白点。只有解决了知识应用瓶颈的问题，数据挖掘的决策支持作用才能得到有效发挥。

## 2.3 智能知识管理的研究现状

认识到知识管理的难度，有些学者开始从商业智能等角度研究智能知识管理。本节从智能的研究开始，对目前智能知识管理方面的文献进行分析。

## 2.3.1 智能的概念及其实现途径

1956 年由 McCarthy、Minsky 等发起，联同美国的几位心理学家、数学家、计算机科学家和信息论学家把观察、学习、记忆和推理等与人类智能有关的问题引入计算机领域，正式提出人工智能的术语（Nilsson, 1999），使人工智能的研究成为一门能够理解人类智能并通过机器实现智能行为的新学科。蔡自兴等（1996）在《人工智能及其应用》中给出了人工智能的定义：人工智能是智能机器所执行的通常与人类智能有关的功能，如判断、推理、证明、识别、感知、理解、设计、思考、规划、学习和问题求解等思维活动。概括来讲，“智能”通常是指人们在认识与改造客观世界的运动中，由思维过程和脑力劳动所体现的能力，包括感知能力、思维能力和行为能力。人的智能的核心之一在于知识，因此智能常常表现为知识获取能力、知识处理能力和知识运用能力（刘毅，2004）。

40 多年来，人工智能获得很大发展，引起众多学科的日益重视，成为一门交叉学科和前沿学科。刘毅(2004)和徐心和等(2004)总结了人们对人工智能的观点和实现方法，将各类观点划分为符号主义（Symbolism）、连接主义（Connectionism）、和行为主义（Actionism）等，或者叫做逻辑学派（Logicism）、仿生学派（Bionics）和生理学派（Physiologism）。此外还有计算机学派、心理学派和语言学派等不同学派的研究方法、学术观点。

从较为成熟的技术层面看，人工智能的实现主要有三条途径：

- (1) 专家系统，是一种较为成熟的方法，文献较多。不一一列举。

- (2) 机器学习，是人工智能的核心技术，研究的目标是如何使机器通过识别和利用现有知识来获取新知识和新技能。后面进行较详细的回顾。

- (3) 智能体(Agent)方法，智能主体技术通过从感知外部环境到实施行动并最后对外部环境施加影响的过程，形成一个相互联系的整体，使主体成为一个具有智能行为概念的“人”，主体具有自治性、社会能力、反应能力和自发行为（史忠植，2000），结合李海刚等(2003)的研究，给出智能 Agent 的特性：

自治性：主体运行时不直接由人或其他东西控制，Agent 能自行控制其状态和行为，能在没有人或其他程序介入时操作和运作，它对自己的行为和内部状态有一定的控制权。

社会能力：或称可通信性，即 Agent 能用通信语言与其他实体交换信息和相互作用。

反应能力：即对环境的感知和影响，基于知识系统和外界环境的情况进行推理和规划，可以感知所处的环境，并通过行为解决自身或传递自身领域内的各类问题。

协作、合作、协调及协商能力：表现为协同完成任务，协调和合作解决复杂问题，协商执行某类行动等。基于这类行动，Agent 具有分布、自治和快速处理复杂问题的能力。

自发行为：主体的行为应该是主动的，或者说是自发的。

此外，主体还应具有学习能力，即根据过去的经验积累知识，并修改行为以适应新的环境，以及感知能力和反应性等。

近年来，有些学者已经开展对人工智能与知识管理结合的研究（蒋翠清等，2007；陈远等，2005；张建华，2005），认为今后知识管理理论与方法的创新，将会是智能化与因特网理论、技术融合的产物(陈远等，2005)。

## 2.3.2 机器学习的策略

作为人工智能的一个重要的研究领域，机器学习的研究主要围绕学习机理、学习方法、面向任务这三个基本方面展开。总结何斌(2005)、闫友彪等(2004)的研究成果，把机器学习的策略分为如下几种：

### 1. 机械式学习

机械式学习(rote learning)又称死记式学习，是一种最简单、最原始的学习策略。通过记忆和评价外部环境所提供的信息，把经过评价所获取的知识存储到知识库中，求解问题时就从知识库中检索出相应的知识用来求解问题。

### 2. 指导式学习

指导式学习(learning by being told)又称嘱咐式学习或教授式学习，由外部环境向系统提供一般性的指示或建议，系统把它们具体地转换为细节知识，送入知识库。在学习过程中要反复对形成的知识进行评价使其不断完善。

### 3. 归纳学习

归纳是指从个别到一般、从部分到整体的一类推论行为。归纳推理是从足够多的事例中归纳出一般性的知识，是一种从个别到一般的推理。归纳学习(inductive learning)是应用归纳推理进行学习的一类符号学习方法，它表示从例子设想出假设的过程。在进行归纳时，多数情况下不可能考察全部有关的事例，因而归纳出的结论不能绝对保证它的正确性，只能以某种程度相信它为真，这是归纳推理的一个重要特征。在进行归纳学习时，学习者从所提供的事实或观察到的假设进行归纳推理，获得某个概念。

### 4. 类比学习

类比是人认识世界的一种重要方法，类比推理指由新情况与记忆中的已知情况在某些方面类似，从而推出它们在其他方面也相似。类比学习(learning by analogy)是在类比推理基础上，通过对相似事物做比较进行学习的一种方法。

### 5. 基于解释的学习

基于解释的学习(explanation based learning, EBL)是通过运用相关领域知识，对当前的实例进行分析，从而构造解释并产生相应知识的一种学习方法。基于解释的学习通过运用相关领域知识及一个训练实例来对某一目标概念进行学习，并最终生成这个目标概念的一般描述。该描述是一个可形式化表示的一般性知识。

### 6. 基于神经网络的学习

人工神经网络(artificial neural networks, ANN)是对人脑神经元系统的模仿，可以用电子线路来实现，也可以用计算机程序模拟，它由一些简单的类似神经元的单元以及单元间带权的连接组成。每个单元具有一个状态，这个状态是由同这个单元相连接的其他单元的输入决定的。连接学习的目的是区分输入的模式的等价类。连接学习通过用各类的例子来训练网络，产生网络的内部表示，并用来识别其他输入例子。学习主要表现在调整网络中的连接权。连接学习是非符号的，并且具有高度并行分布式处理的能力。特别是它能处理任意类型的数据，能够从特定模式的大量的数据中发现其潜在的规律，克服了传统分析过程的复杂性及选择适当模型函数的困难，是一种自然非线性建模过程，给建模与分析带来了极大的方便。神经网络在对非平稳过程的建模中被发现其记忆特征与泛化能力具有良好的应用效果(Cheng et al, 1994; Anderson et al, 1988)，近年来获得极大的成功与发展。比较著名的学习算法有感知器(perceptron)，Hopfield 网络、Boltzmann 机和误差反向传播算法(back-propagation)等。

### 7. 支持向量机

考虑训练样本集$\{(x_i, y_i)\}_{i=1}^l$，其中 \(x_i\) 是输入模式的第 \(i\) 个例子，\(y_i\) 是对应的期望响应(目标输出)，假定由于子集 \(y_i = +1\) 代表的类和 \(y_i = -1\) 代表的类线性可分，那么用于分离的超平面的决策条件是 \(w^T x + b = 0\)，其中，\(x\) 是输入向量，\(w\) 是可调的权值向量，\(b\) 是偏置，调整 \(w\) 和 \(b\) 的值，总可以使式(2.2)和式(2.3)成立：

\(w_0 \cdot x + b_0 \geqslant 1, \quad \text{if } y_i = +1 \quad (2.2)\)
\(w_0 \cdot x + b_0 \leqslant 1, \quad \text{if } y_i = -1 \quad (2.3)\)

满足上式等号情况的特殊数据点\((x_i, y_i)\)称为支持向量。支持向量机(support vector machines, SVM)的目标是找到一个特殊的超平面，使得这些点与超平面之间的间隔 \(\rho\) 最大。支持向量机可以实现分类等的训练。

### 8. 基于遗传算法的学习

基于遗传的学习法是一种以竞争为原则的学习过程。遗传学习模拟了生物繁殖的突变(互换、倒位、点突变等)和达尔文的自然选择(在每一生态环境中适者生存)。它根据解决问题的规则在应用领域中作用的大小，对其优胜劣汰的“繁殖”。具体地，一个概念描述的变形对应于一个物种的个体，这些概念的诱导变化和重组用一个目标函数(相应于自然选择准则)来衡量，看其中哪些能够保留在基因库中。它把参加竞争的每一轮规则看做是一代。从某一代中选择优秀者进行交配，形成新一代规则，如此一代代地更新，理想的结果是得到一组高质量的规则。其应用领域通常是一个变化着的环境，规则为适应环境所作的一代代地更新，犹如生物为适应自然而更新后代。学习能力强的规则，适应变化的能力就强。

### 9. 强化学习

在 20 世纪 80 年代，基于试错方法、动态规划和瞬时误差方法形成了强化学习(reinforcement learning)理论。1984 年，Sutton 提出了基于 Markov 过程的强化学习；1996 年，Kaelbling 在总结强化学习的研究时指出，实现这种学习的手段就是自适应机制；1998 年，Sutton 和 Barto 将这些研究统称为适应性计算。它们需要建立一种基于反馈机制的学习理论（高阳等，2004）。

### 10. 多 Agent 学习

Agent 的基本思想是使软件能模拟人类的社会行为和认知，即人类社会的组织形式、协作关系、进化机制，以及认知、思维和解决问题的方式。和传统的对象概念相比，Agent 概念具有更多的知识性、主动性和协作性，具有更强的问题求解能力和自治能力。智能 Agent 是指在动态的多 Agent 领域采取灵活、自治活动的计算机实体，自然也带有 Agent 的普遍特性。

## 2.3.3 智能知识管理相关研究综述

现有智能知识管理的研究很少，本书以主题词（topic）“intelligent”和“knowledge management”进行检索，只得到 200 余篇文章，且很多文章的内容不符合期望要求。综合学者的研究，智能知识管理的策略主要分为如下几种类型：

### 1. 从知识获取算法上实现智能性

Kamrani 等（2001）将遗传算法引入数据挖掘，获取智能性较高的知识。Shim（2006）基于人类获取视觉图像时的选择性机制，提出知识管理应该有一套好的获取、保持和检索机制。信息技术的发展使数据和信息的复杂性提高、数量剧增，因此发展智能的知识获取系统是非常必要的。利用 BP 神经网络进行知识的学习，记忆情景知识，根据新环境证据的进入动态调整知识的关联，由于关键词的不可穷举性，用户输入的关键词有可能不是最佳的。代表性的关键词通过同义词网（结点、关系）自动取代用户输入的关键词，抽取更符合要求的知识。

### 2. 从存储结构上实现智能性

Nemati 等（2002）构造了知识仓库（knowledge warehouse）以集成知识进行管理。Shim（2005）则构造了知识仓（knowledge capsule），将知识管理、决策支持、人工智能和数据挖掘技术进行融合；基于大脑记忆理论，特别是情景记忆理论，提出的知识胶囊有一个分层次的结构和数据选择、学习、储存和提取数据等功能，从而可以辅助实现高效的数据挖掘。面向事件的虚拟记忆、检验学习和知识检索功能，其结构如图 2.6 所示。

### 4. 从知识管理平台整体结构上实现智能性

Staniszkis 等(2003)采用领域本体和 Agent 技术，设计了一个可以提取专家隐性知识，有效组织专家交互过程的知识管理门户，并将知识分为结构性知识（structural knowledge）、陈述性知识（declarative knowledge）和过程性知识（procedural knowledge）；Conteh 等(2003)提出了一种 Just-in-Time 知识管理的设想，让信息或知识在合适的时间，以合适的数量和正确的形式提供给需要它们的人，从而实现基于知识管理的智能的决策支持系统。Maté 等(2002)认为前人对知识管理系统的研究缺乏整体性，在总结 20 多家组织实施知识管理系统的基础上，提出了一个相对完整的知识管理系统方法论模型，该模型从系统结构计划、目标与风险分析、技术实现与应用实施四个方面对知识管理系统的设计方法进行了系统论述，通过整合、集成使功能之间的配合有所增强。

O'Leary(1998)在知识库中引入本体技术建立知识管理系统，使咨询公司可以高效地查询利用案例库。Gao 等(2002)从系统科学角度提出了知识管理研究的各个方面，包括：科学理论层面、技术层面、管理层面等，并分析了其子系统，是对知识管理分析较为全面的文献之一。

人们对知识的需求，基本上是为了引用知识、运用知识、传播知识、学习知识和发展知识，基于该认识，张景中(2000)提出了“智能知识平台”的概念：“在某一知识领域内一定层次上，能够满足人们引用知识、运用知识、传播知识、学习知识和发展知识需求的系统，称为一个智能知识平台”。这里设想的智能知识平台是面向学科领域的，并且是分层次的。在进一步研究的基础上，提出了智能知识平台的结构(张景中，2005)，如图 2.8 所示。
