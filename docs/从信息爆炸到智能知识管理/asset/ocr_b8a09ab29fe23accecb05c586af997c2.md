| 知识表示方式 | 优点 | 缺点 |
| :--- | :--- | :--- |
| 语义网络 | 表达层次关系能力很强；可以方便地追溯关系 | 实现比较复杂 |
| 产生式规则 | 语法简单，易于理解，易于修改 | 不能表达结构性知识；效率不高 |

在知识表示中，产生式规则是知识表示中最有代表性的、讨论最多的表示形式，其易于为人们所理解，非常适合辅助决策。从表示形式上来看，产生式规则主要由两部分组成：一系列的前件(if)和对应的结论(then)，如下所示：

```
if P then Q
```

其中，P 是条件，Q 是结论。即表示为：如果 P 成立则 Q 成立，简化为：P→Q。

每一个前件(condition)P 又由三部分组成：条件、操作符(“=”,“>”,“<>”,“<”)和值(value)，比如下述的规则：

IF 缴费点数 > 9 and 投诉次数 <= 5 and 收信次数 > 3 and 缴费方式 <=3 then状态 = 正常

随着神经网络技术和数据挖掘技术的发展，产生了一些新的知识表示方法。神经网络可以将隐藏在数据中的知识学习到，并且以其网络结构和权重、阈值的形式存在网络节点和连线中，但其学习到的知识很难被人直接理解，需要将其转化成其他人们可以理解的形式。同时，也有的学者提出将神经网络和规则相结合，以便同时发挥神经网络的学习能力和产生式规则易于理解的优点。虽然神经网络具有很强的学习能力，并且可以在存在噪声的情况下保持良好的学习效果，但是神经网络也存在一些缺点，例如，训练时间长、学习不稳定，尤其是在初始权重是随机的情况下，达到期望的网络精度所需要的训练次数相差很大。

基于 XML 的知识表示。XML (extended markup language)，即可扩展标签语言，是 SGML (Standard Generalized Markup Language) 的一个子集。XML 文档以树形结构包含和描述数据、数据类型(数据结构)以及文档结构。更重要的是 XML 可以包含语义，也就是说我们能够给一个标签(tag)赋予确定的语义。所以 XML 是一种元语言，完全可以用来描述具有良好结构的知识。同时，通过采用 DTD (document type definition)可以表示多种类型的信息，如字符、图片、数学公式等。但是基于 XML 的知识表示目前存在以下问题：第一，没有一套切实可行的框架规范；第二，难以实现非结构化和半结构化知识的表示(潘旭伟,2005)；第三，在将知识呈现给用户的时候，需要转化成适当的形式。
