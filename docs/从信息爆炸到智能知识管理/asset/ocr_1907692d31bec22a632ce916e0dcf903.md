知识是在一定领域得到公共认可的；“形式化”指概念表达是计算机可读的，即能被计算机软件处理；“明确”指概念及概念之间的约束都显性定义。所以，本体是某领域内公认的概念实体的有限集合，领域内公认的语义信息通过概念实体之间的关联关系来表达。本体由下列基本要素构成(Gomez-Perez, 1999)：

+   1) 类(classes)或概念(concepts)

类或概念指事物，如工作描述、功能、行为、策略和推理过程，从语义上讲，它表示的是对象/实例的集合。

+   2) 属性(properties 或 attributes)或槽(slots)

属性是通过类定义的二元关系，属性通常与特定的类和类集合关联在一起。通过属性，可以检查与特定本体相关的实例(集)是否是有效的。

+   3) 实例(instances)

类的一个元素，从语义上讲实例表示的就是对象。

+   4) 公理(axioms)

施加于概念与概念关系集合上的永真断言，主要用于推理和有效性检测。

# 5.4.2 元知识与情景知识

# 1. 元知识

元知识是描述知识本身的知识，一般有如下几类(陈文伟等, 2004)。

+   1) 指导规则的选择

它是对规则选择的元知识。为了提高系统的效率，把这些元知识整理出来，用它来指导推理。这样，推理机就更灵活些。变化或增加元知识也就改变了原来的推理或扩大原来推理的功能。

解决冲突(有一条以上规则的前提部分和当前事实匹配)的元知识。如：

+   MR1:如果某一规则的前提比另一规则的前提更专门，且两条规则冲突，则先选用更专门的规则。

+   MR2:按规则排列顺序，先选用前一条规则。

+   MR3:优先选用被满足的条件较多的规则。

如有两条规则 A →H, A ^ B →K, 若 A, B 成立，应先选第 2 条。

这种元知识是一种规则，可以称为元规则。

+   2) 记录与领域知识有关的事实

①记录某些处理方法的平均运行时间；②统计一个程序在运行过程中询问用户的次数；③统计规则的成功与失败的比率等，提供与领域知识有关的信息。
