例如，“坠机地在 A 市南边 30 公里”，“N₁ 在 1989 年是 N₂ 的学生。”这两条信息都是关系型信息，可用关系元形式化表示为

```
R₁ = [ 位置关系， 前项， 坠机地 ]
    [ 后项， A 市 ]
    [ 参照物， A 市 ]
    [ 方位， 南方 ]
    [ 距离， 30 公里 ]
```

```
R₂ = [ 师生关系， 前项， N₁ ]
    [ 后项， N₂ ]
    [ 时间， <x₁ 年, x₂ 年> ]
```

+   4) 用复合元表示复杂信息

很多信息都是复杂信息，既包含陈述型信息，又包含行为型信息，还可能包含关系型信息，此时就要用复合元来形式化表达。

例如，“2006 年 9 月企业 E 成功研制出一种新型抗癌药物 D”，是一条复杂信息，可用复合元表示为

```
A₁ = [ 研制， 支配对象， M ]
    [ 施动对象， 企业 E ]
    [ 时间， 2006 年 9 月 ]
    [ 程度， 成功 ]

M = [ 药物 D， 功能， 抗癌 ]
    [ 类型， 全新 ]
```

又如，“企业 E₁ 与企业 E₂ 进行了 2 年的密切合作，开发出了新产品 P”，也是一条复杂信息，可用事元和关系元的运算式表示为：A₃ ∧ R，其中

```
A₃ = [ 开发， 支配对象， 新产品 P ]
    [ 施动对象， 企业 E₁ ∧ 企业 E₂ ]
```

```
R = [ 合作关系， 前项， 企业 E₁ ]
    [ 后项， 企业 E₂ ]
    [ 程度， 密切 ]
    [ 时间， 2 年 ]
```

# 3. 智能知识的基元表达

通过对多种方法的比较，我们发现用基元表达知识格式可以统一，内容上便于扩充，同时便于利用可拓变换技术实现后续的知识推理、审计及自动推送应用。因此，我们采用可拓学的基元理论，用物元、事元和关系元来表达智能
