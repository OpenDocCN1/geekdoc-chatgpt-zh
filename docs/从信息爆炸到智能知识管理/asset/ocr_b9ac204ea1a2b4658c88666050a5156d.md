# # 第 4 章 智能知识的直接获取技术

# ## 4.1 智能知识获取的数据准备

数据挖掘项目成功与否在很大程度上取决于商业目标的选取、数据准备与挖掘方法的适用性。Crisp-DM 方法论(Shearer, 2000;http://www. crisp-dm. org/)将数据挖掘分为商业理解→数据理解→数据准备→建模→评估→发布六个过程，其中数据理解和数据准备大约占整个数据挖掘工作量的 70%～85%。

数据挖掘首先需要有完整准确的数据,数据本身的质量差造成数据挖掘结论的可信度低已经成为影响数据挖掘应用的重要因素。目前在数据清洗、格式转换等方面有很多的研究,但对数据如何从源头上进行质量转换的研究不多。李兴森等(2006)对企业数据建立物元可拓集合,通过可拓变换提出了基于可拓工程方法的数据挖掘企业应用方案。以数据挖掘所需的完备数据集作为条件物元,发现数据质量差距,以事元“数据挖掘咨询”促使物元集可拓域的发展变换,推出了以数据挖掘应用咨询带动数据质量改进的措施(李兴森等, 2007a),开辟了一条从根本上解决数据挖掘所需的数据质量问题的新途径。

数据转换有三个含义:一是数据格式的转换,取决于挖掘目标和采用的软件;二是用途的转换,由挖掘商业目标 A 转换为挖掘商业目标 B,一般由业务专家和数据挖掘专家共同商定;三是数据质量的转换,通过从根本上采取措施使数据集可以为某一商业目标的挖掘服务,它不同于数据清洗,数据清洗是只能清洗本次用于挖掘的数据,对后面重新抽取的数据起不到质量转换作用。在本节我们重点阐述第三个含义。
