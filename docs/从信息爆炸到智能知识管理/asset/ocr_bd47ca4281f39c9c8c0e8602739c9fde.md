# 3. 论域的变换

研究对象的全体称为论域，论域是一个集合。在经典的逻辑和模糊逻辑中，论域是固定不变的，这反映了人们的习惯思维：把问题涉及的对象局限于某一固定的范围内，其优点是便于在固定的范围内研究问题的解，但这也限制了人们的视野，特别在处理矛盾问题时，一种重要的方法就是跳出习惯领域形成的对象集。在客观世界中，一定范围内是矛盾问题，在另一论域中却可能是不矛盾的。

基元变换的五种基本形式是：

+   (1) 置换变换：将一种基元用另一种基元替换，或将基元的一种属性用另外一种属性替换，或将一种量值替换成另外的量值等。

+   (2) 增删变换：增加/删除基元或其属性、量值。

+   (3) 扩缩变换：对基元或其属性的量值进行扩大或缩小变换。

+   (4) 组分变换：将两个以上的基元或其属性、量值进行组合，或者把一个基元或其属性、量值分解成多个。

+   (5) 复制变换：将一个基元或其属性、量值复制成同样的多个基元、属性或量值。

上述变换方法可同样用于论域变换、准则变换等。从数据挖掘算法角度看，多种不同的变换本质上是一类映射，可定义一个距离函数，设定评价方法，将各种信息、知识、规则等用数学方式表达，融入到数据挖掘与知识变换算法中进行综合评判，得到决策参考价值更大的知识。
