这个单元相连接的其他单元的输入决定的。连接学习的目的是区分输入的模式的等价类。连接学习通过用各类的例子来训练网络，产生网络的内部表示，并用来识别其他输入例子。学习主要表现在调整网络中的连接权。连接学习是非符号的，并且具有高度并行分布式处理的能力。特别是它能处理任意类型的数据，能够从特定模式的大量的数据中发现其潜在的规律，克服了传统分析过程的复杂性及选择适当模型函数的困难，是一种自然非线性建模过程，给建模与分析带来了极大的方便。神经网络在对非平稳过程的建模中被发现其记忆特征与泛化能力具有良好的应用效果(Cheng et al, 1994; Anderson et al, 1988)，近年来获得极大的成功与发展。比较著名的学习算法有感知器(perceptron)，Hopfield 网络、Boltzmann 机和误差反向传播算法(back-propagation)等。

# 7. 支持向量机

考虑训练样本集$\{(x_i, y_i)\}_{i=1}^l$，其中 \(x_i\) 是输入模式的第 \(i\) 个例子，\(y_i\) 是对应的期望响应(目标输出)，假定由于子集 \(y_i = +1\) 代表的类和 \(y_i = -1\) 代表的类线性可分，那么用于分离的超平面的决策条件是 \(w^T x + b = 0\)，其中，\(x\) 是输入向量，\(w\) 是可调的权值向量，\(b\) 是偏置，调整 \(w\) 和 \(b\) 的值，总可以使式(2.2)和式(2.3)成立：

\(w_0 \cdot x + b_0 \geqslant 1, \quad \text{if } y_i = +1 \quad (2.2)\)
\(w_0 \cdot x + b_0 \leqslant 1, \quad \text{if } y_i = -1 \quad (2.3)\)

满足上式等号情况的特殊数据点\((x_i, y_i)\)称为支持向量。支持向量机(support vector machines, SVM)的目标是找到一个特殊的超平面，使得这些点与超平面之间的间隔 \(\rho\) 最大。支持向量机可以实现分类等的训练。

# 8. 基于遗传算法的学习

基于遗传的学习法是一种以竞争为原则的学习过程。遗传学习模拟了生物繁殖的突变(互换、倒位、点突变等)和达尔文的自然选择(在每一生态环境中适者生存)。它根据解决问题的规则在应用领域中作用的大小，对其优胜劣汰的“繁殖”。具体地，一个概念描述的变形对应于一个物种的个体，这些概念的诱导变化和重组用一个目标函数(相应于自然选择准则)来衡量，看其中哪些能够保留在基因库中。它把参加竞争的每一轮规则看做是一代。从某一代中选择优秀者进行交配，形成新一代规则，如此一代代地更新，理想的结果是得到一组高质量的规则。其应用领域通常是一个变化着的环境，规则为适应环境所作的一代代地更新，犹如生物为适应自然而更新后代。学习能力强的规则，适应变化的能力就强。
