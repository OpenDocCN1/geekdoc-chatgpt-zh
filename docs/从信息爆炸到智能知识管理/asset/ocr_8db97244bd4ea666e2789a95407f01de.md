供了条件。该方法和 4.2 节的方法配合使用效果更好。

# 4.4 小结与展望

本章论述了智能知识获取的数据准备策略，以数据挖掘咨询从系统环节提出了一套持续改进数据质量的方案。从知识和目标关联的智能性考虑，设计实现了两种智能知识的直接获取算法。转化规则的挖掘为规则知识的利用提供了更直观、有效的措施；可拓分类使我们更容易地把措施和适应对象关联考虑，提高知识的智能性和有效性。

直接获取智能知识的技术是一条捷径，本章仅仅举了两个典型的例子，算法的设计虽然得到初步验证，但仍然有很多有待改进的空间，如采用智能 Agent 技术等。另外，有更多的直接挖掘算法有待于进一步研究，如领域知识驱动的数据挖掘技术、关联规则的可拓挖掘、可拓聚类等。

其中，领域知识驱动的知识发现为深层知识发现提供了理论、方法和技术，是对传统数据挖掘的继承和发展。以综合集成系统方法论为基础理论，可以分析领域知识驱动的智能知识发现框架的功能与特点，从综合集成的视角进行研究，从定性定量相结合的模式抽取，从最后定性到定量智能知识挖掘的综合集成，实现定性与定量相结合、人机结合，以人为主的深层知识发现。这种模式将整个知识发现过程看是一个往复循环、不断精炼、逐步逼近、开放式的复杂过程，目的就是根据前一次挖掘反馈，不断调整领域知识、挖掘目的，并相应地重新选择预处理数据以及对挖掘算法和参数进行改进和调整。

智能知识的直接挖掘技术还包括基于多目标、多约束条件的分类模型、基于多目标的效用关联法、多目标多约束条件的回归法、复杂动态数据模式等。能反应数据有效性与实时性的数据挖掘技术，包括具有高性能和分布式计算环境的数据挖掘技术、金融或媒体等形式的数据流挖掘技术、与知识规划相关的多目标数据挖掘方法等。
