冻结客户的一组规则前件可用物元表示如下：

R₁ = [ C₀ 112, 周 2Pop3 登录次数 <= 0 ]
    [ 总共 Web 登录 IP 个数 <= 0 ]
    [ 买服务期 3 的比例 <= 0.3 ]
    [ 支付方式 3 的比例 > 0.75 ]
    [ 出生日期填写情况 0 ]
    [ limit = 33 ]

该规则可表示为：IF R₁ then C₀

希望将 R₁ 变换到 A₁ 中，即通过变换将某一冻结用户转换为现有正常缴费用户。
