# 表 5.3 智能知识的记忆信息一览表

| 类别 | 名称 | 内容 | 备注 |
| :--- | :--- | :--- | :--- |
| 元知识 | 知识主体的名称或编号 | 知识主体的名称或编号,其知识包含的内容单独存储在知识库的表中 | |
| | 标识(tagging) | 有选择地聚集知识使相同类别或协调性知识联结起来的描述特征 | |
| | 适用业务范围 | 适用的业务范围,如销售、产品设计 | |
| | 类型 | 知识的自定义分类,如客户转化知识、消费特征知识等 | 根据业务定义 |
| | 生产日期 | 产生智能知识的日期 | |
| | 来源 | 从哪个数据集产生的 | |
| | 审计方法 | 从原始知识到有用知识的审计方法 | |
| | 审计分数 | 有用知识审计时的分数 | 1-10 分制 |
| | 优先规则 i | 如:优先选用被满足的条件较多的规则 | |
| | 冲突规则 j | 如:如果某 n 条规则冲突,则先选用最后后产生的规则 | |
| | 原因 | 说明该知识有用的理由等 | |
| | ...... | | |
| 情景知识 | 使用部门 | 应用该知识的部门编号 | |
| | 使用人员 | 应用该知识的人员编号 | |
| | 人员技能级别 | 应用该知识的人员技能级别 | 自定义 1-5 |
| | 使用业务环节 | 应用该知识的业务流程编号 | |
| | 时间 | 应用该知识的时间 | 精确到分钟 |
| | 背景 | 如:应用该知识时的工作网页 | |
| | 环境 | 应用该知识的上一流程编号,下一流程编号 | |
| | 被检索次数 | 该知识总共被检索的次数 | |
| | ...... | | |
| 智能记忆信息 | 来源数据集规模 | 数据集的存储容量(M),记录数及属性数 | |
| | 数据集组成结构 | 组成数据集的子集名称,如销售+订单+投诉 | |
| | 数据集开始时间 | 数据集的最早开始日期 | |
| | 数据集结束时间 | 数据集的最后结束日期 | |
| | 数据质量 | 挖掘用数据集记录数/原始记录数 | 以%表示 |
| | 挖掘软件 | 软件名称,版本号 | |
| | 挖掘任务类别 | 如:MCLP 分类,决策树,聚类等 | |
| | 类似知识编号 | 与之相似的知识编号 | |
