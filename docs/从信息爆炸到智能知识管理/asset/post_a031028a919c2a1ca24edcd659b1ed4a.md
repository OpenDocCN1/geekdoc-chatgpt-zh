### 1. Web of Science 介绍

ISI Web of Science® 包括著名的三大引文索引：Science Citation Index Expanded® (SCIE, 1900 至今)、Social Sciences Citation Index® (SSCI, 1956 至今) 和 Arts & Humanities Citation Index® (A&HCI, 1975 至今) 及两大化学信息数据库 Current Chemical Reactions® (CCR, 1986 至今) 和 Index Chemicus® (IC, 1993 至今)。涵盖自然科学、工程技术、生物医学、社会科学、艺术与人文领域，来源于 9000 多种核心学术期刊。（网址：http://www.isiknowledge.com）

### 2. ISI Web of Knowledge 简介

ISI Web of Knowledge 是一个基于 Web 而构建的整合的数字研究环境，在内容上以 Web of Science 为核心，整合了学术期刊（ISI Web of Science, Current Contents Connect）、发明专利（Derwent Innovations Index）、会议录文献（ISI Proceedings）、化学反应（Current Chemical Reactions，Index Chemicus）、学术专著（Current Contents Connect）研究基金（ISi eSearch）、Internet 学术资源（External Collections）、学术分析与评价工具（Journal Citation Reports, Essential Science Indicators）、学术社区（ISIHighlyCited.com）及其他多个重要的学术信息资源（BIOSIS Previews, INSPEC, FSTA, PsycINFO）等，提供了自然科学、工程技术、生物医学、社会科学、艺术与人文等多个领域中高质量、可信赖的学术信息。

### 3. Ei Engineering Village 2 简介

《Ei》(工程索引)的网络版，内容包括原来的光盘版（Ei Compendex）和后来扩展的部分（Ei PageOne）。该数据库包含 1970 年以来的超过 700 万条的工程类期刊、会议论文和技术报告的题录，每年新增 25 万条工程类文献，数据来自 175 个学科的 5100 多种工程类期刊、会议论文和技术报告。Ei Compendex Web 收录的文献涵盖了所有的工程领域，该数据库侧重提供应用科学和工程领域的文摘索引信息。

### 4. CNKI 简介

国家知识基础设施（National Knowledge Infrastructure, CNKI），概念由世界银行于 1998 年提出。CNKI 是世界上全文信息量规模最大的数字图书馆，目前，中国期刊全文数据库来源期刊/杂志 8809 种，时间自 1915～2007，文章篇数超过 24960000 篇。
