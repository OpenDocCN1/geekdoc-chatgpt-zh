智能知识的应用环境可以看做是一个分布式的系统，其中的每个成员通过协作来完成他们的目标及实现组织的整体目标。在这种环境中，通信和协调的作用是至关重要的，涉及协商、信息共享和协调等。另外，还要求系统对参与成员及共享知识数量的增加具有可扩展性。Agent 作为一种智能的计算机硬件或软件系统，它具有自治性、社会性、反应性和主动性等特点。主要应用于一些动态的环境中，Agent 的行为和推理是由其对环境中实时情况的感知决定的。多 Agent 系统 (MAS) 可以通过多个自治 Agent 间的协作来共同完成复杂的任务。

利用 Agent 的反应性和主动性，系统可以具有足够的灵活性，能够及时响应外部环境的变化，及时主动地把握机会(蒋翠清等，2007)。因此，使用 Agent 作为知识评估实现工具的基本建模单元，在使用 MAS 中，将 Agent 定义一种自治的知识实体，具有灵活性、适应性和主动性，Agent 之间的交互具有高度的动态性。采用多智能体实现知识管理系统构架(李跃新等，2008)，定义好知识管理系统中智能体的组成及它们行为模式，设定构架中智能体之间的合作、协调的操作机制，设立共享事务管理 Agent 的模型及行为模式(Wooldridge et al，2005)，同时增加一套监控系统记录与评估指标相关的数据信息，进行统计分析、评估，评估结果反馈给 MAS 环境，并公布给每一个 Agent。Agent 技术和复杂性科学相结合，就在一定
