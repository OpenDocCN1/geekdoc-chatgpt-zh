以上这些研究大都是从管理功能上增加智能特色，局部提高知识管理环节的效率，管理的对象主要还是信息或传统的隐性知识的分享与显性化等，大都广泛地将知识视为隐性和显性的知识，没有具体地讨论如何有效管理由数量分析所产生的智能知识，缺乏针对数据挖掘获取知识的深入的科学研究，且概念和我们提出的智能知识不一致。

近年来，研究智能的知识管理方法的文章开始增加。归纳如下两大方面：

+   1）方案整体设计方面

Zhang 等(2009)将隐性知识与显性知识转化的过程引入智能知识管理，提出智能知识管理中的四个关键步骤：①从数据到粗糙知识；②从粗糙知识到智能知识；③从智能知识到行动知识；④从行动产生新的数据。形成一个循环的过程。鉴于隐性知识无法系统化存储，Yang 等(2007)利用模糊分层摘要提取(FAH)技术，建立智能模糊搜索框架，初步实现领域专家的智能查询、模糊匹配，根据需求帮助找到相关领域的知识。 Venkatasubramanian(2007)认为，伴随信息爆炸和知识爆炸的来临，通过智能软件系统有效地管理和获得决策信息是显然的，但这一需求还没有引起足够重视。实际上，数据、信息和过程中的信息流对决策同样重要，基于本体论构建了一个信息基础设施架构，对产品生产管理的全过程信息进行管理。文献(Li et al, 2009b; Nie et al, 2009)认识到数据挖掘获取的知识对商业智能的意义，分析了对之进行智能化管理的重要性，提出了一种与商业智能集成的方案及研究框架。 Fayoumi 等(2009)认识到对数据挖掘结果的智能化处理可以得到有价值的知识，提出一种基于 Web 语义技术的系统化方案框架，其输入是 PMML 语言描述背景知识，利用主题图形式，设计数据挖掘本体和关联规则挖掘的本体，集成内容管理系统和语义知识库，分析者可以输入新信息生成语义分析报告，进而重新审视挖掘结果。

+   2）智能性的具体实现方法

Chang 等(2008)使用智能体社区来有效地处理知识管理活动，即知识共享、知识分类、知识创造和知识的复苏。该系统的特点是：收集每个用户的上网习惯和通过数据挖掘找到隐藏的模式，进而推荐合适的文章，迅速为用户找出适当的文件；通过个人配置提供个性化服务。

Grundspenkis(2007)也发现知识管理与人工智能之间缺少连接的桥梁，提出基于 Agent 的组织和个人知识建模的框架。该框架包括两个模型：一个是描述智能企业记忆的模型，另一个描述智能的组织知识管理系统，从而构建基于 Agent 的支持个人和组织的知识管理的环境。其中智能企业记忆模型分为七层：知识源层、知识获取层、知识规范化层、知识表达层、知识处理层、知识应用层和专家服务
