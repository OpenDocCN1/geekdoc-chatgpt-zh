+   (5) 恋爱。两条以上的知识在某些方面有共同点，或成为前后件条件，加入匹配标志。等有匹配标志的知识达到一定数量，启动推理机制，产生新的知识，类似人类的结婚生子。

+   (6) 进化。在应用过程中融入专家的经验知识，使知识得到部分修正。或者挖掘出新的类似知识对原有知识予以修正，使知识更符合实际的需要。

+   (7) 衰老。随着时间的推移，有些知识被利用的次数越来越少，逐渐失效或者部分内容被新的知识取代。

+   (8) 死亡。长期(根据业务范围由用户定义，一般半年以上)未被使用，或者被新知识完全取代，经专家确认没有价值的知识，附加死亡标志，存入知识墓库。

+   (9) 孕育。死亡的知识积聚到一定数量，可以对死亡知识的特点进行挖掘分析，找出知识死亡背后的规律，反映的业务特点，有可能孕育出新的有价值的知识。孕育将是一个新的数据挖掘过程或者是知识的推理过程。

# 6.2 系统需求分析

IKMS 系统作为一个知识管理系统，应该具备知识管理系统的一般功能，这些功能包括：

+   (1) 知识提交和发布。支持用户将创造、更新的知识提交给系统，系统将发布这些知识，使企业内成员可以使用这些知识。

+   (2) 知识组织和管理。根据一定的分类规则，对各种知识进行分类组织，使知识有序化。

+   (3) 知识检索。为用户提供统一的知识检索，实现对企业范围内各种不同知识进行检索。用户可以选择执行检索的范围，支持多种检索方式，如主题词检索、内容检索，或提问交互式检索。

+   (4) 在线学习。通过课程设计者对知识管理系统中已有知识资源的重新整理，以多样化的形式为学员提供设计合理的培训课程。

+   (5) 决策支持。为企业高层决策人员、管理者和业务人员解决企业业务问题提供决策支持，提供与决策问题相关的数据、信息和知识，支持定性、定量分析，提高决策者的决策洞察力和决策效率。

+   (6) 知识地图。描述企业知识资源、知识员工和知识专家的分布，可以指引用户快速找到所需的知识或拥有该知识的人。

+   (7) 系统管理。包括系统设置、用户管理、日志管理、系统备份和权限管理等，具备动态的权限赋予功能，可以动态地管理用户的访问、阅读、发布、存储等各种权限，快速适应企业组织的变化；可以动态地进行系统参数的配置，支持用户的个性化要求。
