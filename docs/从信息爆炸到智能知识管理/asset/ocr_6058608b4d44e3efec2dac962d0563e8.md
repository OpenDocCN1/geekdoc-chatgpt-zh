对如何在业务过程中利用数据挖掘获取知识并有效利用挖掘出的大量知识没有引起足够的重视。同样,知识管理一旦独立于业务过程,往往被看做是额外的工作负担(李兴森等,2007;Kwan et al,2003),不易取得良好效果。因此,将数据挖掘、知识管理与业务过程集成,使业务过程与知识的产生创造、组织存储和智能应用等过程有机结合,为业务活动提供一个知识支持环境,支持业务过程中的推理、决策,提升业务效果,使数据挖掘和知识管理真正服务于业务决策。

# 2. 促进知识的集成和创新

数据挖掘得到的有用知识具有分散、异构、形式多样等特点,很难进行系统的集成和管理。目前以数据驱动的挖掘往往针对某一商业目标进行,从数据集的选取到得到的知识都局限在部门级应用或特定业务范围。而事物之间是普遍联系的,一个部门的问题可能是由其他部门某一环节的问题造成的,因此,需要加强知识与知识之间在业务过程、用途、时间、使用人员等其他诸方面存在的内在联系,提高知识的使用价值。另外,通过知识的集成和知识具有的智能特点,人们获得的知识就不再是孤立的,可以把某一知识与其他知识相互关联起来,理解它们之间的关系,从更大的视野来理解与运用知识,从而有利于促进产生新的知识,增强创新能力。

# 3. 基于智能的知识推送,减少知识过载

人们在从事业务活动时,如何快速有效地获取与业务相对应的知识是高效完成业务活动的关键因素之一。信息技术和互联网应用日益广泛的今天,人们在获取知识时,需要面对如何从海量的知识中找到所需知识,即知识过载问题。数据挖掘获得的规则知识多数是无用的,人们需要花费大量的时间和精力来浏览这些知识以确定哪些是自己所需的。通过智能知识管理系统,对这些知识进行过滤,只把那些适合用户当前智能的知识提供给用户,以减少知识过载。同时需要通过知识的自我记忆、环境识别等能力,实现知识的自动推送,把有用知识在最需要的时候提供给最需要的人。

本书基于上述目标,设计智能知识管理的研究框架。
