导智能知识的实现策略。在复杂性科学研究中已经有不少的新方法、新工具可供借鉴。

智能知识孵化出来以后，下一步的工作是如何让它生存，提供良好的生活环境，而生存环境的好坏取决于智能知识的表达方法。

对知识进行形式化描述（Frank, 2000）是知识存储、评价和智能化应用的前提，是智能知识管理的一项基础技术，在智能知识管理的整个过程中发挥着重要作用。

# 5.4 智能知识的表达与存储

# 5.4.1 常用的知识表达方式

从大量的数据中可发现不同种类的知识，既需要从不同的角度来检验发现的知识，也需要用不同的形式来表示这些知识，以便让挖掘发现的知识是容易理解的并且可以直接由用户来使用，这就要求具备适合的知识表达方法。

知识表示(knowledge representation)是将从各种方式如数据挖掘中得到的知识在计算机内以适当的方式表示出来，这样才能使知识在计算机中方便地存储、检索、推理、使用、修改。所以知识表示就是研究如何用最恰当的形式来表达所需要的各种知识。目前，人工智能领域中比较成熟的知识表示方式主要有如下几种：

+   (1) 谓词逻辑(predicate logic);
+   (2) 框架(frames);
+   (3) 语义网络(semantic nets);
+   (4) 产生式规则(rules);
+   (5) 面向对象的方式(object-oriented);
+   (6) 本体(ontology);
+   (7) 其他表示方式。

每种知识表示方式各有其优缺点，如表 5.2 所示。

# 表 5.2 几种常见知识表示方式的优缺点

| 知识表示方式 | 优点 | 缺点 |
|---|---|---|
| 谓词逻辑 | 精确、严密、容易实现 | 不能表示不确定性知识；容易产生组合爆炸；效率低 |
| 框架 | 表达能力强；容易添加属性，方便设置初始值 | 编程困难；不便于推理 |
