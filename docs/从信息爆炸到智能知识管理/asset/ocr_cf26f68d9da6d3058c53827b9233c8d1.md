学科和前沿学科。刘毅(2004)和徐心和等(2004)总结了人们对人工智能的观点和实现方法，将各类观点划分为符号主义（Symbolism）、连接主义（Connectionism）、和行为主义（Actionism）等，或者叫做逻辑学派（Logicism）、仿生学派（Bionics）和生理学派（Physiologism）。此外还有计算机学派、心理学派和语言学派等不同学派的研究方法、学术观点。

从较为成熟的技术层面看，人工智能的实现主要有三条途径：

+   (1) 专家系统，是一种较为成熟的方法，文献较多。不一一列举。

+   (2) 机器学习，是人工智能的核心技术，研究的目标是如何使机器通过识别和利用现有知识来获取新知识和新技能。后面进行较详细的回顾。

+   (3) 智能体(Agent)方法，智能主体技术通过从感知外部环境到实施行动并最后对外部环境施加影响的过程，形成一个相互联系的整体，使主体成为一个具有智能行为概念的“人”，主体具有自治性、社会能力、反应能力和自发行为（史忠植，2000），结合李海刚等(2003)的研究，给出智能 Agent 的特性：

自治性：主体运行时不直接由人或其他东西控制，Agent 能自行控制其状态和行为，能在没有人或其他程序介入时操作和运作，它对自己的行为和内部状态有一定的控制权。

社会能力：或称可通信性，即 Agent 能用通信语言与其他实体交换信息和相互作用。

反应能力：即对环境的感知和影响，基于知识系统和外界环境的情况进行推理和规划，可以感知所处的环境，并通过行为解决自身或传递自身领域内的各类问题。

协作、合作、协调及协商能力：表现为协同完成任务，协调和合作解决复杂问题，协商执行某类行动等。基于这类行动，Agent 具有分布、自治和快速处理复杂问题的能力。

自发行为：主体的行为应该是主动的，或者说是自发的。

此外，主体还应具有学习能力，即根据过去的经验积累知识，并修改行为以适应新的环境，以及感知能力和反应性等。

近年来，有些学者已经开展对人工智能与知识管理结合的研究（蒋翠清等，2007；陈远等，2005；张建华，2005），认为今后知识管理理论与方法的创新，将会是智能化与因特网理论、技术融合的产物(陈远等，2005)。
