应用到了对知识资产的管理中。对于知识审计的概念，不同的学者有不同的看法。

Wiig(1994)认为知识审计的目的是应对信息过量和信息缺乏，减少大量的重复工作，便于找到求助的具体领域的专家。Skyrme(1998)认为，知识审计集中回答如下问题：为了解决特定的问题，已经有了哪些知识、缺乏哪些知识、谁需要这些知识以及他们如何使用这些知识。Hylton(2002)认为，知识审计是对公司的知识资源(包括显性知识和隐性知识)进行系统的、科学的考察和评估，根据对公司知识状况的调查和分析出具诊断性和预测性的报告。冯静(2004)在总结了国外研究者的知识审计概念后得出认为，知识审计是一个动态的流程，它对公司知识资源进行系统的、科学的考察和评估，分析组织的知识基础和知识需求，提出诊断性和预测性的审计报告。

本书对知识审计的定义是，知识审计是对知识的价值进行评估以便有效利用的过程和方法。

# 5.5.2 知识审计的方法

HyA-K-Audit 方法(Hylton,2002)用于测量知识管理中一些核心因素的状况和它们之间的关系，这些因素包括：知识拥有者(人力资源或人力资本)，人们获取、传播和共享知识的流程，提高知识文档处理的速度、效率和安全性的技术，包含在文档与信息系统中的知识内容的质量和相关性。该方法强调以人为中心，并从效率和效果两方面来评估知识传播、使用和共享的水平。并使用了一系列的指标来衡量组织的知识状况和知识资产。具体的审计过程分三步进行。

+   (1) 知识调查。通过问卷调查和访谈两种方式来收集、比较、分析和评估公司知识数据和信息以及获得知识拥有者的想法。

+   (2) 知识清点。这个阶段对显性知识和隐性知识进行清点和评估，确定组织实际的和潜在的知识资产。

+   (3) 知识地图。对公司的知识结构和知识流绘制知识地图，并在地图中标明谁拥有哪些知识以及人们在公司环境中如何传播和共享这些知识。

Tiwana(2004)提出的知识审计方法，给出了一套知识评估工具。从基础设施、流程、技术、组织文化、声誉等多个角度进行知识审计。首先要组建一个审计团队，而知识审计团队需要包括公司多个部门的代表，这些代表分别是不同领域的专家，包括公司的战略制定专家，资深的管理者、财务专家、人力资源专家、知识分析家、技术人员等。
