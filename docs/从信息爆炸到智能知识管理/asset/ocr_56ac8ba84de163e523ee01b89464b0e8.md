# 10. 多 Agent 学习

Agent 的基本思想是使软件能模拟人类的社会行为和认知，即人类社会的组织形式、协作关系、进化机制，以及认知、思维和解决问题的方式。和传统的对象概念相比，Agent 概念具有更多的知识性、主动性和协作性，具有更强的问题求解能力和自治能力。智能 Agent 是指在动态的多 Agent 领域采取灵活、自治活动的计算机实体，自然也带有 Agent 的普遍特性。

# 2.3.3 智能知识管理相关研究综述

现有智能知识管理的研究很少，本书以主题词（topic）“intelligent”和“knowledge management”进行检索，只得到 200 余篇文章，且很多文章的内容不符合期望要求。综合学者的研究，智能知识管理的策略主要分为如下几种类型：

+   1. 从知识获取算法上实现智能性

Kamrani 等（2001）将遗传算法引入数据挖掘，获取智能性较高的知识。Shim（2006）基于人类获取视觉图像时的选择性机制，提出知识管理应该有一套好的获取、保持和检索机制。信息技术的发展使数据和信息的复杂性提高、数量剧增，因此发展智能的知识获取系统是非常必要的。利用 BP 神经网络进行知识的学习，记忆情景知识，根据新环境证据的进入动态调整知识的关联，由于关键词的不可穷举性，用户输入的关键词有可能不是最佳的。代表性的关键词通过同义词网（结点、关系）自动取代用户输入的关键词，抽取更符合要求的知识。

+   2. 从存储结构上实现智能性

Nemati 等（2002）构造了知识仓库（knowledge warehouse）以集成知识进行管理。Shim（2005）则构造了知识仓（knowledge capsule），将知识管理、决策支持、人工智能和数据挖掘技术进行融合；基于大脑记忆理论，特别是情景记忆理论，提出的知识胶囊有一个分层次的结构和数据选择、学习、储存和提取数据等功能，从而可以辅助实现高效的数据挖掘。面向事件的虚拟记忆、检验学习和知识检索功能，其结构如图 2.6 所示。
