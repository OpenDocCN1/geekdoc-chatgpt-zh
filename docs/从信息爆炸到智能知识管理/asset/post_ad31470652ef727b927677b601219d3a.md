## 5.5 智能知识的审计

### 5.5.1 知识审计的概念

知识审计的概念源于将知识作为组织的一项资产，因此传统的审计概念也被应用到了对知识资产的管理中。对于知识审计的概念，不同的学者有不同的看法。

Wiig(1994)认为知识审计的目的是应对信息过量和信息缺乏，减少大量的重复工作，便于找到求助的具体领域的专家。Skyrme(1998)认为，知识审计集中回答如下问题：为了解决特定的问题，已经有了哪些知识、缺乏哪些知识、谁需要这些知识以及他们如何使用这些知识。Hylton(2002)认为，知识审计是对公司的知识资源(包括显性知识和隐性知识)进行系统的、科学的考察和评估，根据对公司知识状况的调查和分析出具诊断性和预测性的报告。冯静(2004)在总结了国外研究者的知识审计概念后得出认为，知识审计是一个动态的流程，它对公司知识资源进行系统的、科学的考察和评估，分析组织的知识基础和知识需求，提出诊断性和预测性的审计报告。

本书对知识审计的定义是，知识审计是对知识的价值进行评估以便有效利用的过程和方法。

### 5.5.2 知识审计的方法

HyA-K-Audit 方法(Hylton,2002)用于测量知识管理中一些核心因素的状况和它们之间的关系，这些因素包括：知识拥有者(人力资源或人力资本)，人们获取、传播和共享知识的流程，提高知识文档处理的速度、效率和安全性的技术，包含在文档与信息系统中的知识内容的质量和相关性。该方法强调以人为中心，并从效率和效果两方面来评估知识传播、使用和共享的水平。并使用了一系列的指标来衡量组织的知识状况和知识资产。具体的审计过程分三步进行。

- (1) 知识调查。通过问卷调查和访谈两种方式来收集、比较、分析和评估公司知识数据和信息以及获得知识拥有者的想法。

- (2) 知识清点。这个阶段对显性知识和隐性知识进行清点和评估，确定组织实际的和潜在的知识资产。

- (3) 知识地图。对公司的知识结构和知识流绘制知识地图，并在地图中标明谁拥有哪些知识以及人们在公司环境中如何传播和共享这些知识。

Tiwana(2004)提出的知识审计方法，给出了一套知识评估工具。从基础设施、流程、技术、组织文化、声誉等多个角度进行知识审计。首先要组建一个审计团队，而知识审计团队需要包括公司多个部门的代表，这些代表分别是不同领域的专家，包括公司的战略制定专家，资深的管理者、财务专家、人力资源专家、知识分析家、技术人员等。

Delphi 集团的知识审计方法 KM² 是一套复杂的分析工具，可以对用户调查的反馈数据进行复杂的统计分析，Delphi 实施知识审计时，首先进行基于 Web 的问卷调查。回收之后由 Delphi 的高级分析人员使用 KM² 对这些反馈数据进行复杂的统计分析。KM² 能够得到反馈数据的频率分布情况，并且能够揭示反馈数据与问卷中问题的关系。在此基础上，Delphi 选择出一部分被调查者进行访谈，以便更深入的认识问题。

陈晓雨等(2005)在借鉴斯堪迪亚模型和打分卡(马小勇等, 2001)的基础上构建了一套知识审计模型及指标体系，力求对企业各类知识资本的存在方式及其存量、变动进行较为全面的衡量和评价。借鉴斯堪迪亚导航者对知识资本五大维度的划分，该模型的考核评价从财务、人力资源、结构、顾客、创新与发展五个方面进行，并通过德尔菲法完成对指标的遴选工作。最后的审计结果以打分卡的形式给出。使用该方法可以反映被审计企业相关知识资本的质量及薄弱环节，为管理提供了一定的参考意见。

上述的知识审计方法对企业知识状况的测度各有侧重，但都只是针对某些问题或某些领域孤立地进行知识审计，而缺乏与业务流程的结合和对数据挖掘得到的智能知识的审计。

### 5.5.3 智能知识的自我审计技术

知识智能化评估的理论基础是复杂自适应系统理论：系统中的成员是具有自适应性的主体，能够与环境及其他主体进行交互作用。主体在持续不断的交互作用过程中，不断学习或积累经验，并根据学到的经验改变自身的结构和行为方式。整个系统不断演化或进化，包括新层次的产生、分化和多样性的出现，以及交叉、聚合而成的更大的主体的出现等。“知识能够以类似规则的心智结构来表达：这些规则始终处于竞争之中，经验使得有用的规则越变越强，无用的规则越变越弱；具有说服力的规则产生于旧规则的组合之中”(米歇尔·沃尔德罗普, 1997)。借鉴学者的研究成果，我们设计了人机结合的智能知识审计方法。分为如下六大步骤。

第一步, 由专家和业务人员设定初始的规则，利用软件对原始知识进行过滤，审计产生有用知识。

第二步, 对选出的有用知识进行孵化，增加记忆信息后进入智能知识管理平台。记忆信息的内容参见书后文献。

第三步, 设定初始的评估准则。其中, 常用的智能知识的评估规则如下：

- (1) 数量评估。按使用频率排名, 使用频率偏低的知识自动降低评估分数; 按使用人员、部门数量评估, 被多人、多部门使用的知识评估分数增加等。

- (2) 质量评估。反馈评分较低的知识按分数幅度降低评估分数; 连续 60 天没有被使用而其他知识被大量使用的知识评估分数降低等。

- (3) 冲突评估。和其他知识冲突, 而其他知识质量较高的, 降低评估分数; 反之, 提高评估分数; 与新产生的智能知识冲突的, 降低分数等。

- (4) 贡献评估。和其他智能知识通过结合、推理产生新的智能知识，且新知识被应用后反馈分数大于指定值的，增加评估分数。

- (5) 序列评估。随着新数据集的挖掘产生了一系列新的智能知识，其中有的知识和原有知识类似，对原有知识具有印证、对比分析或在原有知识基础上扩展功能的，增加原有知识和新知识的评估分数。

- (6) 聚集评估。新产生的智能知识带有某一特色的标识，能够使原有很多知识聚集成智能知识聚集体，为特定商业目标服务的，增加新知识的评估分数。

第四步，根据业务目标，设定初始的知识自我评估准则的权重如表 5.4 所示。

智能知识的应用环境可以看做是一个分布式的系统，其中的每个成员通过协作来完成他们的目标及实现组织的整体目标。在这种环境中，通信和协调的作用是至关重要的，涉及协商、信息共享和协调等。另外，还要求系统对参与成员及共享知识数量的增加具有可扩展性。Agent 作为一种智能的计算机硬件或软件系统，它具有自治性、社会性、反应性和主动性等特点。主要应用于一些动态的环境中，Agent 的行为和推理是由其对环境中实时情况的感知决定的。多 Agent 系统 (MAS) 可以通过多个自治 Agent 间的协作来共同完成复杂的任务。

利用 Agent 的反应性和主动性，系统可以具有足够的灵活性，能够及时响应外部环境的变化，及时主动地把握机会(蒋翠清等，2007)。因此，使用 Agent 作为知识评估实现工具的基本建模单元，在使用 MAS 中，将 Agent 定义一种自治的知识实体，具有灵活性、适应性和主动性，Agent 之间的交互具有高度的动态性。采用多智能体实现知识管理系统构架(李跃新等，2008)，定义好知识管理系统中智能体的组成及它们行为模式，设定构架中智能体之间的合作、协调的操作机制，设立共享事务管理 Agent 的模型及行为模式(Wooldridge et al，2005)，同时增加一套监控系统记录与评估指标相关的数据信息，进行统计分析、评估，评估结果反馈给 MAS 环境，并公布给每一个 Agent。Agent 技术和复杂性科学相结合，就在一定程度上简化系统的设计复杂度，实现知识在运行过程中的自我评估。

## 5.6 智能知识的推理机制

智能知识的推理机制可以充分借鉴现有专家系统(李兴森等,2000)、知识推理(陈文伟等,2004)的研究成果,在此基础上借助智能 Agent 技术进一步完善。

### 5.6.1 知识推理方法

- 1. 产生式规则的推理

  常用的基于产生式规则的知识有正、逆(反)向两种推理方式。

  - 1) 正向推理

    逐条搜索规则库,对每一条规则的前提条件,检查事实库中是否存在。前提条件中各子项,若在事实库中不是全部存在,放弃该条规则。若在事实库中全部存在,则执行该条规则,把结论放入事实数据库中。反复循环执行上面过程,直至推出目标,并存入事实库中为止。

  - 2) 逆(反)向推理

    逆向推理用得较多,主要是目标明确、推理快。逆向推理是从目标开始,寻找以此目标为结论的规则,并对该规则的前提进行判断,若该规则的前提中某个子项是另一规则的结论时,再找以此结论的规则,重复以上过程,直到对某个规则的前提能够进行判断。按此规则前提判断(“是”或“否”)得出结论的判断,由此回溯上一个规则的推理,一直回溯到目标的判断。

- 2. 语义网络

  语义网络最初由 Quillian 和 Raphael 分别提出的。它是以网络形式把概念之间用弧线连接起来,构成知识的一种表示形式。

  语义网络把问题中的概念用节点表示。概念之间的关系用弧来表示。这样,语义网络把概念以及它们之间的关系表示成一种结构图形式。语义网络推理表现为对节点的访问以及节点间关系的检索。也即体现为对语义网络的联想过程。

- 3. 框架

  框架由一组描述物体的各个方面的槽(属性)所组成。每个槽(属性)又可包含若干侧面所组成,每个侧面都有自己的名字和填入的值。一般框架结构为：

  ```
  <框架名> frame
  ```

  ```
  <槽名 1> <侧面 11> 值 11
  slot <侧面 12> 值 12
  ... ...
  <槽名 2> <侧面 21> 值 2
  <侧面 22> 值 22
  ... ...
  ```

  没有侧面的框架简化为：

  ```
  <框架名>
  <槽名 1> 值 1
  <槽名 2> 值 2
  ... ...
  <槽名 n> 值 n
  ... ...
  ```

  其中，某些槽值可缺省。

  框架是一类事物的完整描述。事物之间匹配只能是部分相同槽的匹配。

### 5. 基于案例的推理(CBR)

是在遇到新的案例时，通过搜索案例库，寻找与之最相似的旧的训练集合的案例，其解决方案作为解决新案例的参考。如果对此案例不满意，还可以进行修改，修改后的案例作为一个新学习并存储到案例库中。该方法最后得到的结果是一个推荐的案例(Kolodner,1993;Riesbeck et al,1989)。该方法的挑战在于案例的表示、案例之间的相似性度量以及案例的检索和修改技术的精度和效率。

### 5.6.2 智能知识的推理机制

除了获取初始规则知识的困难，产生式规则推理在实际应用中还存在一些不足：

- (1) 处理大型复杂问题的能力差。在解决复杂问题时，求解问题状态空间较大，操作数目多，操作序列会出现空前膨胀，导致组合爆炸的危险。

- (2) 处理不确定性问题能力差。在生产实践中人类专家的知识往往是不确定的，即模糊的，这使得基于一值逻辑的产生式推理在处理这些问题时效果不理想。

- (3) 缺乏自学习能力。所有的知识和推理规则都是由预置的，不能自动学习、不能自我完善、发展和创新。

- (4) 推理方法单一。和人类不同，产生式规则的推理方式是固定的，它不会根据问题的不同而变换推理方式，致使思维僵化，智能化程度不高。

可拓性是事物固有的性质。客观世界中的事、物和关系可以用基元或复合元及其组合加以形式化表达，依据事、物和关系的可拓性，可以对基元进行可拓分析，从而产生一系列推理规则即基元拓展推理规则。基元拓展推理包括发散推理规则、蕴含推理规则、相关推理规则和可扩推理规则。这些规则可以辅助实现智能知识的推理机制。

对基元的变换会产生传导变换，传导变换的过程也可用推理规则来描述，即传导推理规则。传导推理是指前件为可拓变换，后件为它所引起的传导变换的推理。从内容上看，传导推理包括定性的部分和定量的逻辑值变化两个方面。从变换的主体和对象考虑，传导推理分为自传导推理和已传导推理两类，自传导推理又分为置换传导推理、增删传导推理、扩缩传导推理和分解传导推理。由物元内部的传导变换所引起的传导推理过程称为自传导推理。而基元变换引起其他相关基元的传导变换，引起相关物元的关联度的变化，这种推理过程简称为它传导推理。类似地，根据物的共轭性质，也可以得到一系列的推理规则，称为共轭推理。在一定条件下，物的某一共轭部的变化，会导致其相应的共轭部发生传导变换。

豆增发(2007)将可拓学和案例推理相结合，构建一种新型的基于可拓规则和案例推理的混合专家系统。这种混合专家系统克服了产生式规则专家系统的缺点，具有如下优点：

- (1) 知识表示更自然。用可拓基元来表示专家知识，不仅可以表示确定性知识，而且可以表示不确定性知识，解决了产生式规则专家系统中不确定性知识表示困难的问题。可拓表示方法贴近现实事物，使知识表示自然、形象。

- (2) 推理方式灵活。可拓逻辑中的可拓推理方法具有可拓性，符合人类专家的思维方式。可拓推理与案例推理的结合，使混合专家系统的推理方式更为完善，得出的结论也更为准确。

- (3) 可扩展性强。通过案例库的修正和案例知识的增加，可以去除过时的案例，添加新的案例，这样，不需专门的知识工程师就可以完成知识库的更新，这使专家系统的扩展性大大增强。

- (4) 智能化程度更高。可拓规则和案例推理相结合的混合专家系统，既能依赖专家知识来判断问题，又能依赖案例库来进行推理，一者互为补充，弥补了单一推理方式的不足，使整个系统的智能化程度大大提高。构建多种推理方式并存的混合专家系统，是专家系统真正实现智能化的方向之一。

智能知识主体的前件和后件都是用基元来表示的。根据基元的特性，对可拓规则的匹配方法有欧式距离匹配方法和可拓距匹配方法。对于基元属性取精确值的规则，要求证据与规则前件绝对相符，否则认为不匹配，因此采用欧式距离匹配方法。而对于基元属性取特定区间值的规则，要求证据的属性值落在特定区间内，因此采用距函数来计算匹配度。
