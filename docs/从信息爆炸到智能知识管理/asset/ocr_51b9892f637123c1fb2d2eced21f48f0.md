```
<槽名 1> <侧面 11> 值 11
slot <侧面 12> 值 12
... ...
<槽名 2> <侧面 21> 值 2
<侧面 22> 值 22
... ...
```

没有侧面的框架简化为：

```
<框架名>
<槽名 1> 值 1
<槽名 2> 值 2
... ...
<槽名 n> 值 n
... ...
```

其中，某些槽值可缺省。

框架是一类事物的完整描述。事物之间匹配只能是部分相同槽的匹配。
