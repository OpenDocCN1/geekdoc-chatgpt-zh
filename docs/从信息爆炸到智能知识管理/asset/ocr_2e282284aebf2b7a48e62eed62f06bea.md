基元具有置换、增删、扩缩、组分、复制五种基本变换：

(1) 置换变换，考虑是否可以用另一事物代替当前条件或目标中的事物、用某特征代替另一特征、用某量值代替另一量值。一般从以下方面辅助思考。

+   一物多征：一个事物可以具有很多特征。可以从事物的不同特征出发考虑问题。
+   一征多物：一个特征可以为多个事物所具有。
+   一征多值：一个特征可以具有很多个量值。
+   一值多物：一个量值可以为多个事物所拥有，可以是同征同值，也可以是异征同值。
+   一值多征：一个量值可以对应不同的特征。

另外还可以考虑事物的共轭性：实部—虚部、硬部—软部、潜部—显部、正部—负部等，详细说明可参考文献(杨春燕等, 2007)。

(2) 增加删除变换：考虑可否在条件(或目标)中增加或删除一些特征，或者增加或删除新的事物。

(3) 扩缩变换：考虑可否在条件、目标中把一些特征、量值，或者事物进行扩大或缩小。

(4) 组合分解变换：考虑可否在条件、目标或实现目标的过程中把一些特征、量值，或者事物组合在一起或者分解开处理。

(5) 复制变换：考虑把事物、特征由一份复制成多份。

对于一个基元的变换，会导致相关基元的变换，称后者为前者的传导变换，传导变换产生的传导效应是进行决策时必须考虑的问题，传导变换可以从以下六种形式考虑(何斌, 2005)：

+   (1) 一事物的置换引起相应属性值的带动变换。
+   (2) 一事物中某要素的变换引起该事物关于某些相关特征的量值变化。
+   (3) 一事物中某要素的变换使该事物变为他事物。
+   (4) 一事物的变换引起相关事物关于某些相关特征的量值变化。
+   (5) 一事物的变换引起相关事物向他事物变化。
+   (6) 共轭对中一方的变化引起另一方的变化。

同时，变换具有积、逆、或、与四种基本运算，三种基本类型：可拓元的变换、关联准则的变换和论域的变换，由此组成的变换体系概括了人们解决矛盾问题的多种方式(杨春燕等, 2007)。
