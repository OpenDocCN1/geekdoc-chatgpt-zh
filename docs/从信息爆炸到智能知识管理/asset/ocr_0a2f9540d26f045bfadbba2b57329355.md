好地理解它们，从而无法把精力集中在其中真正感兴趣的子集上，为决策提供支持。这就需要结合知识管理的研究成果，从人机结合的角度对产生的知识进行二次分析、挖掘以产生更好的决策支持效果。

# 2. 2. 6 本节小结

通过前面大量的文献分析可以看出，数据挖掘的研究主要集中在数据挖掘任务及其实现算法、数据挖掘本身的过程、理论方面。往往把挖掘出知识作为挖掘过程的结束，对数据挖掘获取的知识形式有所涉及，但缺乏对数据挖掘获取的各种知识如何真正为决策服务应用的研究，将数据挖掘和知识管理结合起来进行系统研究的文章更少，作者统计了 Web of Science, ISI Web of Knowledge, Ei Engineering Village, CNKI 中与知识管理和数据挖掘相关的文章共有 74451 篇，其中把数据挖掘和知识管理同时作为关键词或主题的文章只有 635 篇，占知识管理的 2. 64%，占数据挖掘的 1. 26%。（详见附录），且主要集中在文献综述（韩客松，2001）或数据挖掘作为知识的来源和应用上（罗锦珠，2005），基于数据挖掘的知识管理系统研究（钟英姿，2006）也是把数据挖掘作为获取知识的来源。基于数据挖掘获取的知识的复杂性，如何有效应用成为决策支持的难点和研究的空白点。只有解决了知识应用瓶颈的问题，数据挖掘的决策支持作用才能得到有效发挥。

# 2. 3 智能知识管理的研究现状

认识到知识管理的难度，有些学者开始从商业智能等角度研究智能知识管理。本节从智能的研究开始，对目前智能知识管理方面的文献进行分析。

# 2. 3. 1 智能的概念及其实现途径

1956 年由 McCarthy、Minsky 等发起，联同美国的几位心理学家、数学家、计算机科学家和信息论学家把观察、学习、记忆和推理等与人类智能有关的问题引入计算机领域，正式提出人工智能的术语（Nilsson, 1999），使人工智能的研究成为一门能够理解人类智能并通过机器实现智能行为的新学科。蔡自兴等（1996）在《人工智能及其应用》中给出了人工智能的定义：人工智能是智能机器所执行的通常与人类智能有关的功能，如判断、推理、证明、识别、感知、理解、设计、思考、规划、学习和问题求解等思维活动。概括来讲，“智能”通常是指人们在认识与改造客观世界的运动中，由思维过程和脑力劳动所体现的能力，包括感知能力、思维能力和行为能力。人的智能的核心之一在于知识，因此智能常常表现为知识获取能力、知识处理能力和知识运用能力（刘毅，2004）。
