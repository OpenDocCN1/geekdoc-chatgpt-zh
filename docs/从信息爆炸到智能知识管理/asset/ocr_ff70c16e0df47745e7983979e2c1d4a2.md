# 4. 从知识管理平台整体结构上实现智能性

Staniszkis 等(2003)采用领域本体和 Agent 技术，设计了一个可以提取专家隐性知识，有效组织专家交互过程的知识管理门户，并将知识分为结构性知识（structural knowledge）、陈述性知识（declarative knowledge）和过程性知识（procedural knowledge）；Conteh 等(2003)提出了一种 Just-in-Time 知识管理的设想，让信息或知识在合适的时间，以合适的数量和正确的形式提供给需要它们的人，从而实现基于知识管理的智能的决策支持系统。Maté 等(2002)认为前人对知识管理系统的研究缺乏整体性，在总结 20 多家组织实施知识管理系统的基础上，提出了一个相对完整的知识管理系统方法论模型，该模型从系统结构计划、目标与风险分析、技术实现与应用实施四个方面对知识管理系统的设计方法进行了系统论述，通过整合、集成使功能之间的配合有所增强。
