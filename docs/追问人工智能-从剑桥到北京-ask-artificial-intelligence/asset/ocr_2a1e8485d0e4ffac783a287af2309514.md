# 一、现代人与机

人机交互的研究始于第二次世界大战时期，当时主要研究因为各种不合理的设计导致的飞机故障，开始主要应用于航空航天领域，后来逐渐扩展到社会经济的方方面面。人机交互中有一个比较热点的领域——态势感知，其概念由曾任美国空军首席科学家的女科学家米卡·安德斯雷提出。态势感知或情景意识的提出，对整个人机交互领域产生了巨大的影响。米卡·安德斯雷对态势感知的定义是，在一定的时间和空间内，对环境中的各组成成分，进行感知、理解，进而预测这些成分的随后变化状况。可以看出，在整个人类的发展过程中，智能科学是一个交叉学科，涉及心理学、计算机科学、神经科学、哲学、语言学等，这些学科构成一个完整的学科体系，可以总称为认知科学。
