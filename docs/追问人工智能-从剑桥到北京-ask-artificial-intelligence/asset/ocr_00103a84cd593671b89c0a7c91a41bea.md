# （4）遗传算法

遗传算法是进化算法的一种，它模拟达尔文进化论的物竞天择原理，不断从种群中筛选最优个体，淘汰不良个体，使得系统不断自我改进。游戏的不同智能体通过遗传算法不断迭代进化，可以逐渐从不擅长游戏自主进化成为游戏高手，而无须依赖人类知识的参与。
