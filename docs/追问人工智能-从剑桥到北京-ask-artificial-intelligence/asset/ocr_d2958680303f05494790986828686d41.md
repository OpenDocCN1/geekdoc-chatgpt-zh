# 一、人机融合智能的思考

人类价值观的起源是伦理学，机器的起源是人类。现实中，人类的伦理道德困境就有不少，而人类给机器人“装”进去价值，恐怕会有更多的伦理范式之间的对冲突盾产生吧！无论如何，从中不难看出，人机融合的未来必将荆棘密布、困难重重。
