# 导读：通往自动驾驶之路

## （一）

如何借由机械实现“人的解放”，是人类自第一次工业革命以来，付出恒久努力却尚未找到最终答案的一项重大命题。对这个命题的解答，首先关乎的是生产力的提高与进步。在技术持续发展与机械广泛应用的共同推动之下，人类得以跨越第一次工业革命的“蒸汽洪流”，走向第三次科技革命通过信息技术所勾勒出的宏大图景。但在这一过程中，人们却发现：更巨大、更精密且更“全能”的机械不断被发明出来，反而导致人类无法逃脱机械的束缚，因为传统机械必须与人进行密切的交互，人类为此继续付出脑力劳动和体力劳动，还可能带来更加恶劣的工作环境以及更复杂的沟通成本与经营成本。由此，人类开启了增强机械智力的探索，第四次科技革命的到来，则加速了智能技术向日常生活的渗透。正如历史学家赫拉利在《未来简史：从智人到智神》中所指出的：“到目前为止，要增加人的力量，主要还是依靠改进外部工具。但在未来，则可能会着重于改进人的身心，或直接将人与工具结合起来。”汽车的发明及人车交互的发展，即为印证上述判断的典例之一。

自汽车发明以来，在日常生活中驾驶汽车的基本逻辑就是由担任“驾驶员”的自然人发布驾驶命令、执行驾驶操作，汽车只是作为一种辅助人类进行移动的工具而存在，因此汽车没有自主控制方向、速度或做出独立决断的能力，必须接受人的指令的约束。然而，受到身体条件的客观制约，人无法做到长时间和完整精力的驾驶；在人的绝对主导下，人的失控会直接引发车辆的失控，驾驶技术上的不足也可能引发交通事故；在高危和艰难环境下，人很难正常驾驶汽车以发挥其功用……在传统工业时代，以上问题是无解的；伴随着二十世纪以来机械自动化、集成化再到智能化的迭代，人机交互活动已经不再需要人类大量介入或者干预，尤其是在进入二十一世纪后，摩尔定律驱动下的算力快速增长和机器学习能力快速演进，使得人工智能正在逐步接近人类的认知水平，似乎为人类彻底改进传统驾驶的不足带来曙光。在人们对自动驾驶的丰富想象中，驾驶和出行都将有颠覆性的改变，例如，自动驾驶系统会基于对驾驶环境所展开的分析和判断来进行更加科学的驾驶决策，虽然无法比拟驾驶技术优异的车手，但足以降低事故发生的概率。当下，令人眼花缭乱的各类自动驾驶应用广泛落地，我们由此感到兴奋，并怀有更加广阔的期待；但这也为我们也带来了焦虑，人工智能深度介入人类生活的趋势已经不可逆转，如果我们无法感知人工智能演化的逻辑和隐藏的弱点，我们还能妥善地利用自动驾驶吗？

我们对于自动驾驶的焦虑，归根到底来源于对技术的不信任感以及对驾驶风险的不安感。2022 年3 月1 日正式实施的《汽车驾驶自动化分级》国家推荐标准（GB/T 40429-2021），依据动态驾驶任务、最小风险策略和设计运行范围等多个维度，将汽车驾驶自动化等级划分为0 至5 级，和国际上通行的自动驾驶分级方法相似。^([\[1\]](#fow004.html#footnote_content_fow004_1))依照该标准，现阶段在普通乘用车领域得以广泛应用的“智能驾驶系统”或“驾驶辅助系统”，仍属于1 级至2 级的自动驾驶，^([\[2\]](#fow004.html#footnote_content_fow004_2))这意味着驾驶员还需要和驾驶自动化系统共同执行全部的动态驾驶任务，自动化系统的决策相应地会受到驾驶员的监督，其自动化水平远未达到高度自动驾驶和完全自动驾驶的层次，却仍引发了数起受到社会广泛关注的驾驶事故，^([\[3\]](#fow004.html#footnote_content_fow004_3))并使得人们愈发关切自动驾驶的安全性与稳定性问题。可见，对驾驶自动化系统的信任度，将会极大地影响自动驾驶的接受度和依赖性。总之，人工智能这一项颠覆性技术将要如何影响汽车行业的发展，仍然是极富争议的技术话题，其影响也蔓延到了社会层面。一方面，人工智能经历技术积累、技术创新、技术演变的进程后，使得自动驾驶的畅想已在技术上成为可能。在汽车市场增长空间有限的前提下，自动驾驶成了新的竞争热点。另一方面，在“风险社会”的语境下，技术自主性的发展态势加剧了风险，自动驾驶是会“解放”人类还是会加害人类这一争论依然在继续。但必须承认，无论争论结果如何，自动驾驶及其应用的落地不会止步，如何精确地“校准”社会公众对自动驾驶的信任度以实现更加安全高效的人车交互，是在技术发展的同时，必须给予明确回应的议题。当前，3 级及以下的驾驶自动化系统已经量产，4 级自动驾驶在港口航运、矿产等场景下的一些应用也逐步开发，对于中国而言，面对人工智能技术提供的宝贵“超车”机会，当务之急仍然是依靠技术力量，补足和汽车工业发达国家之间的差距，此时更加需要一个新型的技术治理模式保障既存的先发优势，以推动人与人工智能融合的顺利实现。

作为秩序规范的提供者，法律法规必然不能在前述讨论中缺席。法律法规是全面（comprehensive）且至高无上（supreme）的行为规范体系，^([\[4\]](#fow004.html#footnote_content_fow004_4))即使自动驾驶致力于重塑人的驾驶活动，看似对传统法秩序中的诸多规则都构成了挑战，但基于法治的立场，对于自动驾驶等人工智能应用的规范，还是应当自觉遵循人类既有的科技规范路径，充分利用现有的科技法加以规范评价。^([\[5\]](#fow004.html#footnote_content_fow004_5))纵观全球，可以看到：出于促进技术发展、保障公众安全等各类目的，世界各国普遍重视自动驾驶立法工作，并充分发挥法政策的效用，平衡不同利益主体对技术的利益需求。此外，由于自动驾驶技术在建设智慧交通和智慧城市、推动能源革命和带动传统产业转型升级等多个方面有显著作用，各国政府也在广泛开展政策研究以争夺技术争锋的焦点，由此产生的战略规划、政府研究报告和政策文件，则可以从“行政机关理性化（bureaucratic rationality）”的视角展开观察，据此思考我们应当针对自动驾驶提出怎样妥当的监管思路。总而言之，学习和借鉴这些立法经验和制度构思，对于构建符合中国国情的自动驾驶法律制度而言具有很强的现实价值，为此，本书选取了数份在国际上具有代表性的自动驾驶立法文件和政府工作报告进行翻译和汇编；同时，为了达到比较研究的效果，本书也选编了中国的自动驾驶法规、国家规划和战略、产业标准、部门文件和典型的地方性立法，以此建立起了一套立足全球、完整全面的政策法规库，对于国内开展自动驾驶政策法规研究而言无疑是有启发性和开创性的。

## （二）

美国是培育自动驾驶技术，支持开展自动驾驶实验的一片沃土。首先，在联邦指导计划层面，美国目前有三个提供指导原则的联邦计划：《自动驾驶系统2.0：安全愿景》（2017 年）、《为未来交通做准备：自动驾驶汽车3.0》（2018 年）以及《确保美国在自动驾驶汽车技术中的领导地位：自动驾驶汽车4.0》（2020 年）。计划2.0 重在分析、识别和解决安全问题，给出了系统安全、运营设计安全、事件检测与响应等多个影响自动驾驶安全性的要素；同时阐明了联邦和州的自动驾驶监管框架，进一步明确各自角色和职能。计划3.0 则确定了自动驾驶的六项基本原则，并按照国际通行做法完成了驾驶自动化的级别划分。计划4.0 是最新发布的计划，其整合了38 个联邦部门、独立机构、委员会和总统行政办公室在自动驾驶领域的工作职能，并为州政府和地方政府、创新主体及所有利益攸关方提供美国政府有关自动驾驶汽车工作的指导。该计划还详细阐述了美国政府在自动驾驶领域的三项核心方面：保护用户和社区安全、促进市场有效创新和促进协同努力，并出台了十项标准化方法，以确保美国在自动驾驶领域的领导地位。但这些计划的性质属于“非强制自愿性指南”，实际上并不具有法律意义的强制约束力。

从法律的层级视之，以加利福尼亚州、内华达州以及佛罗里达州为代表，美国已经有多个州尝试为自动驾驶“量身打造”法律法规和配套政策，为其营造出了更加宽松的发展空间。^([\[6\]](#fow004.html#footnote_content_fow004_6))佛罗里达州充分尊重自动驾驶汽车的商业化运用，在2019 年修订《佛罗里达法令》时就允许自动驾驶车进行商业化运营，且允许企业决定是否带安全员，同时规定自动驾驶汽车基本适用与传统汽车相同的交通法规管理。亚利桑那州的法案则允许企业与个人申请在公开道路进行自动驾驶测试和商业化运营。本书选编了佛罗里达州、亚利桑那州等六个美国联邦州的自动驾驶法案，从立法变迁可以看出，美国一些州的立法和监管机关充分意识到了自动驾驶技术带来的巨大效益，通过在先立法获得了宝贵的发展机遇。但是，美国特色的自动驾驶立法也带来“立法割裂”的弊病，而转向构建单一性的国家性的法律框架，显然更有助于自动驾驶技术测试的标准化和普适化，这也是美国立法带给我们的重要经验。

以德国为代表的欧洲国家，在汽车设计、制造和生产方面具备深厚的发展底蕴和强大的技术优势，面对智能网联汽车和自动驾驶技术蓬勃发展的趋势，欧洲国家势必要进一步捍卫其汽车工业领先发展的主导地位，因此在法律法规和政策方面对自动驾驶及其应用也给予了充分的倾斜。本书也选取了欧盟、德国以及英国的相关法案和政府工作报告进行翻译。《通往自动交通的道路——欧盟的未来交通战略》发布于2018 年5 月，描绘了欧盟在自动驾驶上的机遇与挑战，并初步勾勒了发展自动驾驶的蓝图。《自动驾驶汽车许可豁免程序指南》的出台，是实施《通往自动交通的道路——欧盟的未来交通战略》的一个必要步骤，目的是促进欧盟各成员国在自动驾驶汽车的许可准入上实现一致，确保实现公平透明的市场竞争。该指南主要针对L3 和L4 级别的自动驾驶车辆，并提出了较为详尽的安全要求，具有很强的操作性和实践性。由此，通过欧盟的一体化行动，欧盟希望在内部实现技术发展和产品市场的双重整合。但是，欧盟内各国的经济社会发展水平存在难以弥合的差异，尤其是在自动驾驶等新兴领域，技术强国和弱国之间的差距不可忽视，也为欧盟发展自动驾驶的统一步伐埋下隐忧。德国属于汽车工业强国之一，早在2017 年5 月，德国就对本国《道路交通法》进行了修正，形成了德国《道路交通法（第八修正案）》，意在及时弥补针对自动驾驶的制度缺位。值得关注的是，在促进发展之余，德国政府没有忽视自动驾驶的伦理性问题。本书选取了德国政府的两份报告，阐述了德国政府对于规制自动驾驶伦理的基本立场和规则设想，尤其是着重讨论了自动驾驶面对两个真正生命的抉择问题。当人类通过自身判断都难以对这一问题达成“正解”时，能否在自动驾驶中进一步嵌入价值位阶的权衡，从而在伦理层面做出回应，德国为我们提供了极具思辨性的视角。

英国在“脱欧”后，不断推进自动驾驶领域的技术研发和基础设施测试，目的也在于提升自动驾驶技术商业化水平，保障本国能够广泛参与到技术的国际竞争中。英国的自动驾驶代表性立法是《2018 年自动及电动汽车法案》，本书也对这一法案进行了翻译。该法案的特色在于，非常重视有关自动驾驶汽车的保险和责任问题，在该法案开篇就进行了专门规定，并通过修法使自动驾驶汽车也能和传统车辆一样进行投保，缓解了责任承担的风险。自动驾驶的事故责任如何划分在各个国家都存有争议，实践证明：责任不明确，自动驾驶汽车就无法真正实现从生产到利用的良性循环，也无法获得社会的普遍信任。该法案明确了自动驾驶汽车造成的事故的责任承担，为我们提出了可资借鉴的定论。

《智能网联车辆的关键原则》和《无人驾驶汽车之路：自动驾驶技术法规详细审查》是英国政府发布的两篇非常重要的政府工作报告，前者关注自动驾驶车辆的安全原则，从系统设计的角度提出了保障安全的要求；后者全面研究了和自动驾驶车辆有关的法律问题，涵盖驾驶行为、产品责任、税收、保险、数据安全等方面，并提出了“为无人驾驶开辟道路”的五项举措和行动计划。这些报告总体秉持着柔性监管的思路，并以激励措施为主，引导自动驾驶产业安全有序发展。
