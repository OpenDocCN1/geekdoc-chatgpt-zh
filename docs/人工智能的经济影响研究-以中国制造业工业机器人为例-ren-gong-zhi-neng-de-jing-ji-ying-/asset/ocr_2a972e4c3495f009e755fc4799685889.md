# 5.4.2 建立模型

对以上变量建立在控制综合技术进步水平情况下，工业机器人对劳动力技能水平的影响的线性模型为
LSR_i = \alpha C + \beta_1 IR_i + \beta_2 Tech_i + \mu_i \quad (5-3)
式中，LSR_i为我国第 i 年的劳动力受教育结构；IR_i 为我国第 i 年工业机器人的销售量；Tech_i 为我国第 i 年的综合技术进步水平；\mu_i 为随机误差项；\alpha, \beta_1, \beta_2 为回归系数；C 为常数项。指标测量数据主要来源于《中国统计年鉴》、《中国工业统计年鉴》（2002 ~ 2017 年）、《中国劳动统计年鉴》（2002 ~ 2017 年）、Wind 公司数据库、IFR 发布的《工业机器人年度报告》等。
