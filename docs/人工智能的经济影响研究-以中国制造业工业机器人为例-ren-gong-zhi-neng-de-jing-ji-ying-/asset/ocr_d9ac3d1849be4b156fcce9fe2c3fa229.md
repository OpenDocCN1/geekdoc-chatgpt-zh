# 1.3 技术路线

首先明确研究范围，即以工业机器人作为人工智能在制造业中应用的具体体现。通过回顾几个典型国家工业机器人发展历程及相关政策，并从不同角度对全球工业机器人发展现状进行对比分析，归纳总结中国制造业工业机器人发展过程中的特点及问题。

然后根据现有数据分析制造业总体工业机器人规模同劳动力规模的关系，探讨我国工业机器人的发展在何种程度上弥补老龄化程度加重带来的劳动力缺口。在制造业细分行业背景下，计算工业机器人变化对各细分行业劳动力规模的影响，为 CGE 模型的情景设置提供参考。

通过运用时序全局主成分分析，从多维度对各工业机器人发展强国开展比较分析，并根据相关指标取值，从中挑选出适于我国参考借鉴的国家，形成 CGE 模型中工业机器人的不同发展情景。

以 CGE 模型系统模拟工业机器人发展对我国宏观经济发展的影响。利用所选国家的发展模式作为不同发展情景，根据细分行业工业机器人对劳动力规模的影响，计算不同情景下，各细分行业劳动力规模的变化，以及由此带来的宏观经济指标的变化。根据计算结果，总结出适合我国工业机器人发展的模式及特点，为制定相关产业政策提供实证依据。
