# (3) 多状态人口预测模型

多状态人口预测（population development environment，PDE）模型是由国际应用系统分析研究所（International Institute for Applied Systems Analysis，IIASA）开发的一个人口预测模型，该模型在一般人口预测模型的基础上加入了受教育水平，以及与受教育水平相应的生育水平，可以为我国未来人口提供更接近实际的预测结果。本书将主要用来估计未来的劳动力总体规模。在计算工业机器人替代的劳动力规模后，结合人口预测结果，即可得到新的劳动力规模。该计算结果可以应用到 CGE 模型中，为模拟劳动力规模在未来经济变动中的作用提供参数。

# (4) 时序全局主成分分析

主成分分析是一种常见的降维、建立指标体系的统计学方法。它利用相关变量间的共同作用关系，将各指标线性组合成为新的综合指标。在本书中，各国涉及工业机器人的指标较多，且具有一定的时间跨度，形成了面板数据。为了对包含时间变化的数据进行降维、分类，使用加入时间维度的时序全局主成分分析。

本书利用 SPSS 22.0 软件实现这一分析。SPSS 22.0 软件是社会科学研究中常用的分析软件。本书主要是进行时序全局主成分分析，对多国、多年的工业机器人相关数据降维，并根据结果得到主成分得分矩阵，从而计算各国在新的主成分上的得分，并进行比较排序。在此基础上，利用其自带的绘图功能，绘制各国在不同指标上的得分和排名。
