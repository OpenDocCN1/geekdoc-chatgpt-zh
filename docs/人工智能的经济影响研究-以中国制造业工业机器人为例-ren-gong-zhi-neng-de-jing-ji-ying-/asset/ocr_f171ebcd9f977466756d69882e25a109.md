其收入来源为劳动者报酬、居民资本收入、企业对居民的转移支付、政府对居民的转移支付、国外对居民的转移支付；纵列表示居民账户的总支出，其支出为居民对商品的消费、居民向政府缴纳的个人所得税，其收入和支出的差额为居民储蓄。居民账户满足居民总收入=居民总支出。

# (5) 企业账户收支均衡模块

企业账户收支均衡模块描述的是企业总收入与企业总支出之间的均衡关系。
SAM 表中的企业账户描述的是企业的收入支出状况。横行表示企业的总收入，
其收入来源为企业资本收入和政府给企业的转移支付（出口退税）；纵列表示企
业的总支出，其支出为企业向居民的转移支付、企业向政府缴纳的企业所得税，
其收入和支出的差额为企业储蓄。企业账户满足企业总收入=企业总支出。

# (6) 政府账户收支均衡模块

政府账户收支均衡模块描述的是政府总收入与政府总支出之间的均衡关系。
SAM 表中的政府账户描述的是政府的收入支出状况。横行表示政府的总收入，
其收入来源为进口关税、生产间接税、政府资本收入、居民所得税和企业所得
税；纵列表示政府账户的总支出，其支出为政府对商品的消费、政府对居民和企
业的转移支付，其收入与支出的差额为政府储蓄。政府账户满足政府总收入=政
府总支出。

# (7) 资本账户投资储蓄均衡模块

资本账户投资储蓄均衡模块描述的是总投资与总储蓄之间的均衡关系。SAM
表中的资本账户描述的是社会总投资的来源和去向。横行表示社会总储蓄，其来
源为居民储蓄、企业储蓄、政府储蓄和世界其他地区储蓄；纵列表示社会总投
资，包括对商品的投资需求和存货增加。资本账户满足社会总储蓄=社会总
投资。

# (8) 世界其他地区账户收支均衡模块

世界其他地区账户收支均衡模块描述的是外汇收入与外汇支出之间的均衡关
系。SAM 表中的世界其他地区账户（ROW）描述的是在世界其他地区的收入支
出状况。横行表示世界其他地区的总收入（外汇支出），其收入来源为国外其他
地区对我国的出口（即我国商品的进口）和国外投资者收益；纵列表示世界其
他地区的总支出（外汇收入），其支出为世界其他地区对我国商品的进口（即我
国商品的出口）、世界其他地区对居民的转移支付，其收入与支出的差额为国外
储蓄。世界其他地区账户满足世界其他地区总收入=世界其他地区总支出或外汇
支出=外汇收入。
