# 1.2 研究的关键问题

围绕“制造业工业机器人对劳动力及经济的影响”这一研究主题，需要研究以下两个关键问题。

一是制造业中工业机器人规模同劳动力规模的关系。这一问题是讨论技术进步与劳动力替代中的常见问题。以往不少的研究分析了新技术同劳动力规模之间的关系，不过涉及的新技术，多是现有技术的改进，具有较为明确的应用形式，应用领域范围较窄或者较为专业，比较容易计算因此带来的劳动力替代水平。人工智能是一种具有颠覆性的、应用形态各异、可与多种行业相结合的技术，其使用范围界定较为困难，应用领域较为广泛。因此，在本书中，首先面临的问题是如何界定人工智能在制造业中的应用方式，然后才能开展下一步的研究。本书通过已有模型及分析筛选后的模型，首先对制造业总体工业机器人规模同劳动力规模的关系进行分析，获得二者的相关系数，为估算未来可能有多少劳动力被替代奠定基础。然后分析不同行业的工业机器人规模同劳动力规模的关系，并得到制造业中不同行业内二者的相关系数，为在可计算一般均衡（computable general equilibrium，CGE）模型中计算各行业劳动力规模变化奠定基础。

二是工业机器人发展带来的劳动力替代，以及不同的发展模式对经济的影响。一方面是制造业劳动力规模的变化，包括总体规模和各行业被替代的规模。由于中国当前劳动年龄人口绝对数已出现拐点，从事制造业的劳动力人口也在下降，根据人口预测模型的结果，可估算未来的劳动年龄人口存在下降趋势。因此未来工业机器人替代的劳动力规模很可能在一定程度上弥补了制造业劳动力的缺口，并以此支撑中国制造业可持续发展。另一方面是在劳动力工资上涨的情况下，通过投资可批量制造的工业机器人降低生产成本，从而进一步提高制造业的效益和竞争力，并保持对经济的推动作用。在参考不同国家工业机器人的发展模式下，利用 CGE 模型，分析我国在不同的工业机器人发展情景下的宏观经济变化情况。

在分析国内人工智能同制造业劳动力规模的关系时，遇到的难点包括两方面：一是数据基础较为薄弱，二是需要选择合适的方法。我国工业机器人的大规模使用起步较晚，在 2008 年金融危机后进入快速增长期，而且统计数据相对国外有所不足，对于很好实现国外研究中对各行业的分析存在一定难度，需要从多种渠道获得数据。由于数据基础的不足，在方法选择上也异于国外。按行业统计
