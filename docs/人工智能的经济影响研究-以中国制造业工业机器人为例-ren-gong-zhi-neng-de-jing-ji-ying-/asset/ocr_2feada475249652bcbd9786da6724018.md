# 2.6.1 CGE 模型构成及条件

# 2.6.1.1 模型的构成

CGE 模型是用一系列方程组描述市场主体间的供需关系，考虑部门之间的生产投入关系，通过价格机制连接要素市场和产品市场，并对政策经济活动等外部变量因素对这些关系的影响进行描述、模拟和预测。常用于关税分析、工资调整、技术进步等政策对某个国家或地区经济发展、产业结构、进出口规模等变量造成的影响（柳青等，2016）。CGE 模型主要包含以下四方面：①经济主体，主要包括政府、企业、居民，有时还包括其他国家或经济体，而且可以根据需要再增加相应的主体；②经济制度结构，一方面是研究对象内部间资本、要素流动的方式，另一方面是同外部，如其他国家的经济交往方式；③主体的决策依据，各经济主体据此进行决策，就是根据不同的目标，如成本最小、利益最大，总体污染排放最小等，探索决策的最优解；④设定市场出清、宏观闭合等条件，使模型能够达到均衡的状态。

CGE 模型中的前三方面是在构建模型时，根据实践活动及实际数据提炼出来的模型组，而最后一方面则是 CGE 模型得以求解的理论基础。CGE 模型的核心是均衡，即产品供给与产品需求相当，而供需调节的机制是价格。Warlas 一般均衡理论则是 CGE 模型的理论基础，即模型中多个产品市场同时出清，可以得到最优解。

# 2.6.1.2 模型的条件假设

本节构建 CGE 模型，包含几点假设：①经济制度为开放型国家，即模型包括政府、企业、居民及世界其他地区四个经济主体，可以对我国当前经济体系进行模拟。②受冲击部门为制造业中的部门，其他部门被动变化。本书的微观分析为工业机器人对劳动力的影响，而工业机器人的主要使用部门是制造业中的部门，因此其他部门是根据制造业部门受到的冲击，为达到均衡状态而进行的变化。③将居民视作一个整体，储蓄率和消费函数不变。④在研究时间段内，各个部门的固定资产折旧率不变。
