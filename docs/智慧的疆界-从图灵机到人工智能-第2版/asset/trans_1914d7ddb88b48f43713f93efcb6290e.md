
深度学习和深度信念网络于2006年诞生后，经过6年的酝酿和准备，终于在2012年一鸣惊人，爆发了一件真正震撼产学研三界的大新闻——在2012年的`ImageNet`图像识别竞赛上，深度学习不仅击败了所有传统的浅层学习方法夺得冠军，而且是以碾压式的姿态战胜对手。

`ImageNet`是斯坦福大学华裔女科学家李飞飞(Fei-Fei Li, 1976—)和美国工程院院士、有着“华人教授首富”之称的普林斯顿大学华裔教授李凯(Likai, 1954—)联合开发的大型图像识别项目。自2010年以来，`ImageNet`每年都会举办一次“`ImageNet`大规模视觉识别挑战赛”(`ImageNet Large Scale Visual Recognition Challenge`, `ILSVRC`)，看看哪一款参赛程序能以最高的正确率对物体和场景进行分类与检测。这种能够量化并带有对抗性质的活动，除了人工智能学界关注外，也很受媒体欢迎，十分容易吸引公众的目光，因此它很快成为各团队展示实力的竞技场。

2012年，辛顿和他的两名学生伊尔亚·苏茨克维(Ilya Sutskever)和亚历克斯·克里切夫斯基(Alex Krizhevsky)（见图7-18）组成团队，设计了一款名为“`AlexNet`”的深度神经网络程序并参加了`ILSVRC` 2012。`AlexNet`犹如一匹惊人的黑马，首次参赛就一举夺得了当年的桂冠。

### 7.5.5 越深度越强大吗

今天我们还处于深度学习浪潮的顶峰，在深度学习不断攻城略地的同时，笔者也在思考几个问题：真的会是“越深度越强大”吗？神经网络会随着隐层数量的增加而继续无往不利吗？在深度不断发展的最后，是能够触碰到我们梦寐以求的机器智能，还是在一定深度之后，必然要与之前的浅层学习方法一样，触碰到天花板乃至拐点，仍然无法接触到智能的身影呢？

在一年之后的`ILSVRC` 2016中，获得冠军的程序依然比`ILSVRC` 2015的冠军有更深的网络层次，甚至在物体检测这些子项测试中，还夸张地出现了1207层的深度神经网络。可是笔者也注意到了，Facebook研究院新推出的“广残差网络”(`Wide Residual Network`)开始逐渐“返璞归真”，仅凭16层的网络深度就成功超越了前一年152层的残差网络所取得的成绩[^(143)](#fn143)

2014年，来自Facebook和微软研究院的两位研究员共同发表了一篇论文《深度网络真的需要那么深吗？》(“`Do Deep Nets Really Need to be Deep?`”)，他们使用模型压缩的方法，用浅层神经网络去模拟一个训练好的深度神经网络，论证了对特定深度的神经网络而言，模拟它们的浅层神经网络能够表现得和它们一样好。尽管在训练数据集上浅层神经网络可能无法直接达到同样优秀的表现，但是在测试集和实际应用中却完全不逊色于深度神经网络。

今天的深度学习的有效性能够被实践应用所验证，我们可以肯定地宣告它确实做对了某些事情，才会出现这个结果。可是，当今深度学习的各种模型、算法、技巧几乎都是靠“试错”来取得的，没有足够完备的理论支持，我们就不会知道它具体做对了哪一件或哪几件事情，才让我们向智能稍微靠近了一步。如果有一天学者从理论上真正掌握了智能的奥秘，反而有可能最后找到的是一个浅层的或者一个深度不太高的网络模型。现在说的深度神经网络越深越好，大概和“头大的人比较聪明”差不多，也许从宏观的角度来看，族群的脑容量确实有可能与智力水平有正相关关系，但并不等同于这就是通向最优的钥匙。《人工智能：一种现代方法》一书的作者彼得·诺维格(Peter Norvig, 1956—)曾写道：“当莱特兄弟和其他人不再模仿鸟类飞行，而是开始研究空气动力学的时候，人类对‘人工飞行’的探索才算是取得了成功。”希望我们这一代人能够在可见的未来，看到人类真正探索出智能的奥秘。深度学习在很多问题上确实获得了比浅层学习更好的效果，这一点是大家有目共睹的。不过，能否说深度学习就一定优于浅层学习？“多深”的深度神经网络才是“最优”的？距离这些问题有明确的答案还非常遥远。

### 7.5.6 越深度越困难吗

虽然“神经网络是否越深度越强大”这个问题的答案还不明确，但是，“神经网络的深度越高，训练难度就越大”这个结论可以暂时认为是正确的。神经网络的结构越复杂，层次越深，涉及的因素就越多，面临的挑战势必更多，这里笔者举一对最为经典的问题——“梯度消失”(`Gradient Vanishing`)和“梯度爆炸”(`Gradient Exploding`)来展开说明。

训练神经网络主要依靠迭代算法来优化，譬如第6章讲过的梯度下降优化算法，它的基本思路是每次迭代都以梯度向量为指导，按照梯度负反向和梯度的大小调整权值，逐步逼近，最后得到全局最优值，误差反向传播算法属于梯度下降优化算法的一种特定形式。在以上语境里，“梯度消失”问题是指从输出层开始，每经过一个隐层，指导更新权值的梯度向量就变小一些，这样，接近于输出层的权值更新相对正常，但在误差传播的远端，越靠近输入层的梯度越小，网络权值更新就会变得越慢。当隐层深度特别深时，经过若干次传递以后，梯度已变为一个接近于零的小数，导致这些隐层的权值几乎不会再发生改变，一直等于网络初始化时赋予的权值，此时的深层神经网络模型，其实等价于只有后几层在工作、其他层都在“偷懒摸鱼”的浅层神经网络模型。而“梯度爆炸”问题则与此相反，如果每经过一个隐层梯度向量都增大一些的话，在最接近输入层的那些靠前的隐层，每次权值更新都会发生很大的变化，这样带来的结果是轻则使得训练无法稳定收敛，重则导致数据越界溢出。

`Sigmoid`函数的解析式是，对这个函数求一阶导数后的图像如图7-22所示，可见在零值时函数取得最大值0.25，即的导数最大值为0.25。从函数图像上我们还能看到，只有中间围绕零值的一小撮值才有作为梯度的意义，零值两侧的所有导数值都无限接近于零。我们把这两侧导数接近于零的部分，称为激活函数的饱和范围，一旦`Sigmoid`函数的输入值落在这个饱和范围内，其输入的数值大小对激活函数的输出结果的影响就极小了，换言之，我们可以说在这个范围内的激活函数对输入数据不再敏感。

另外，误差反向传播算法在神经网络初始化的时候，其权值`w`通常会小于1，譬如常用均值为0、标准差为1的高斯分布来初始化网络权值。这样便使得整体将小于0.25，再结合前面推导的连乘公式，使用链式法则求导，层数越多，势必会使得的求导结果越小，这就引发了梯度消失问题的出现。类似地，梯度爆炸问题出现的原因就是出现了的情况。到这里，我们就明白了梯度不稳定问题（梯度消失和梯度爆炸统称为梯度不稳定问题）产生的原因：前面的隐层梯度是后面的各个隐层梯度的连乘积，在神经网络的深度过深时，梯度在反向传播中的连乘效应会导致网络权值更新不稳定。

神经网络深度增加带来的训练上的困难，是深度学习在诞生前几年里难以充分发挥深度优势的主要原因之一。针对梯度不稳定问题，人们想了很多方法来补救。有从神经网络权值初始化着手的，使得整体尽可能避免梯度逐层减小或者增大，除了前文讲的辛顿的无监督预训练方法外，近几年还出现了一些效果很好的随机初始化方法，如`Xavier`初始化方法、`MSRA`初始化方法等。也有从训练过程着手的，如谷歌在2015年提出的“批量规范化”(`Batch Normalization`)操作，这种方法是在训练过程中对隐层的数据进行规范化处理，避免训练过程里各网络层输入落入饱和区间进而导致梯度消失。还有一种易于操作的最简单方法，是直接从激活函数本身着手。既然梯度消失是由`Sigmoid`函数的导数最大值仅为0.25，且不饱和区间非常狭窄所导致的，那么就着手去寻找更好的代替函数。

`ReLU`函数虽然看起来非常简单，却是近几年在激活函数这方面取得的最大进步之一。相比`Sigmoid`函数，`ReLU`函数具备了诸多优秀的特性，如由于函数简单，不需要进行幂运算，所以计算速度非常快，训练时收敛速度远远快于`Sigmoid`函数，也超过了其他常见的激活函数，如`Tanh`等。在解决梯度消失这个问题时，很明显`ReLU`函数的导数要么是0要么是1，这样至少在正数区间上，就不会因为连乘效应导致梯度逐层减小了。

面对深度神经网络遇到的问题，解决得最彻底的，大概是辛顿给出的“解决方案”了。为什么要加上双引号呢？因为这个方案是推倒重来！辛顿是误差反向传播算法的提出人之一，是神经网络和深度学习的“教父”。然而，现在他又戏剧性地成为误差反向传播算法和经典神经网络结构的强大“反对者”。最近，辛顿居然在他的推特上置顶号召大家应该“摒弃误差反向传播算法，另起炉灶，重新开始”，一时间令业界惊诧，关于这件事情网上曾出现了一些大肆渲染“辛顿叛变”的文章，吸引了不少媒体进行炒作。

辛顿确实曾经表示误差反向传播算法并不是自然界生物大脑中存在的训练机制，也不相信人类大脑是通过生物方式完成求导，通过梯度来调节神经元权重和激活阈值的。从辛顿的成长经历我们就能看出他对模仿人类大脑的工作原理有多么执着。目前已有许多脑科学的研究证实，大脑皮层中普遍存在一种称为“微皮层柱”(`Cortical Minicolumn`)的柱状结构，如图7-24所示，它像一颗胶囊一般把数百个神经元封装在一起，每个微皮层柱里的神经元都记录、处理相同特征的同一种信号。由此看来，人类大脑并不像经典神经网络一样是由神经元直接连接的简单分层结构，而是具有更高的内部复杂性：先由神经元组成“微皮层柱”，再由“微皮层柱”组成“皮层柱”(`Cortical Column`)，由小到大逐步复杂化。

到了2017年，辛顿认为传统的神经网络分层结构虽然取得了很大成功，但已经遇到了瓶颈，因此他重新开始关注胶囊结构，希望从中寻找突破，一举解决之前深度学习里遗留的诸多问题。辛顿想要表达的其实是如果胶囊结构确实能够解决这些问题，那么他就有勇气完全抛弃之前的体系结构，完全抛弃之前的训练方法，一切推倒从来，重新开始。辛顿关于胶囊结构的论文《胶囊结构之间的动态路由》(“`Dynamic Routing between Capsules`”)已经被“2017年度神经信息处理系统进展大会”(`Neural Information Processing Systems`, `NIPS 2017`)所接受，据说其在`MNIST`训练集上非常成功，识别率达到了历史新高，并同时解决了卷积神经网络难以识别重叠图像等问题。到了笔者落笔的2024年，胶囊结构仍然不是神经网络的主流结构，从对胶囊结构目前只有一些论文摘要信息和辛顿的演讲记录就可以窥见一斑。胶囊结构能否被学术界接受，辛顿能否找到训练胶囊结构的新算法，这些都还存有很大疑问，这也正是科研的艰辛之处。

无论结果如何，辛顿在古稀之年仍然在尝试新的方法，这本身就非常值得敬佩。“先驱”“教父”这些头衔是世人对辛顿在深度学习领域的坚持以及那些开创性工作的认可，如果胶囊结构这项工作成功推翻了之前神经网络的结构和训练方法，那完全是他本人坚持自己的信仰和探索的结果，一个真正的大师并没有被以前的成就所束缚；如果辛顿晚年试图突破深度学习，如同爱因斯坦晚年试图统一电磁力和引力一样，是注定无法成功的，那我相信辛顿也依然愿意坚持下去，毕竟他在神经网络这个领域已经坚守了超过40年了。
