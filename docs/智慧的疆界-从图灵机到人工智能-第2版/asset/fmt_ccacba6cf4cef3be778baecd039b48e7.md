
# 范数与正则化

`w2 = (2, 3, -5, 7, -11, 13)`

不容易比较出结果吧？要解决这个问题，数学上已经有了成熟又严谨的办法可以参考。在机器学习领域，也使用了数学里“范数”(Norm)的概念来解决如何度量系数向量大小的问题，这直接关系到采用何种实现方式实现罚函数。

“范数”是一种具有“长度”概念的函数，广泛应用于线性代数、泛函分析等领域，它的作用是度量某个向量空间或矩阵中每个向量的长度或大小。范数必须满足非负性、齐次性和三角不等式，这方面的数学知识读者可以不去深究，只需要把它当作一种用于衡量向量大小的工具，知道我[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)们要用它来度量参数向量即可。

## p范数的几何意义

`L0`范数、`L1`范数、`L2`范数、迹范数、`Frobenius`范数和核范数等不同类型的范数，都是数学和人工智能领域可能用到的，其中的三个“p范数”特例，即`L0`范数、`L1`范数和`L2`范数在机器学习领域最为常用，笔者以这三个范数来介绍罚函数的内容。

`L0`范数、`L1`范数和`L2`范数都是派生自“p范数”的特例，为了稍后解释“正则化为什么能做特征选择”这个问题时有必要的知识储备，这里我们从几何意义的角度去了解p范数的含义：p范数的本质也是长度的度量，对于不同p取值的p范数，其几何含义可理解为描绘该取值下空间中单位球（Unit Ball，表示在空间中半径为1个单位的球面）的形状。最符合初等数学的直观认知是p取值为2时的情况，此时在二维平面上单位球是一个圆形，在三维空间上单位球是一个正球体，更高维度也是类似的，单位球都是到原点距离为一个单位的点的全集，p等于2时的距离称为欧氏距离。在p为其他值时单位球的变化如图6-23所示，请读者特别记住p取值为1和2的单位球形状：菱形和圆形。

从公式上看，`L1`范数是向量中各个元素的绝对值之和，`L2`范数是向量中所有元素的平方之和再开方。把`L0`范数的公式写出来，会发现由于p出现在分母上，零值是无意义的[\[1\]](../Text/Section0009.xhtml#b1)，而`L0`范数的真实含义是向量中非零元素的数量之和。

根据`L0`范数、`L1`范数和`L2`范数的公式，无论是非零计数、绝对值还是开平方，每一个参与公式计算的参数，无论其数值大小、正负都只会对计算结果产生非负的贡献，只是影响程度不同，所以这三个公式都符合“参数数量越多、参数值越大，输出结果就越大”这个特征，我们只要令罚函数“`Ω(w) = ||w||0`”“`Ω(w) = ||w||1`”或者“`Ω(w) = ||w||2`”，即可达到限制模型复杂度过高的目的。

不过，既然`L0`范数、`L1`范数、`L2`范数以及其他形式的范数是共存的，那说明它们在某些地方有自己的特长，这才有共存的意义，也从侧面说明罚函数使用不同的范数来实现，效果一定是有所差别的。下面我们就继续来看看这三个范数的使用场景和含义。

## 稀疏性与正则化应用

`L1`范数的作用是“参数稀疏化”，由于这个特性，`L1`范数还有个别名叫作“稀疏正则算子”(Lasso Regularization)。首先我们来解释什么叫“参数稀疏化”，数学上说一个向量“稀疏”是指它所包含的零元素的数量很多。`L0`范数的意义是计算非零参数的个数，所以它的稀疏性是最直接的，把`L0`范数作为目标函数的一部分，在最小化目标函数的过程中，其目标就自然带有尽可能获得零参数的倾向，但是由于最小化`L0`范数已被证明是一个NP完全问题，要付出极高的代价才有可能优化好，所以实践中并不适用。如果特别注重模型参数数量的话，可以用`L1`范数代替`L0`范数来实现稀疏化。`L0`范数的稀疏性从它的定义公式中就可以明显看出来，至于`L1`范数为什么也会有稀疏性，我们会在讲解完稀疏特性的意义之后，从几何意义的角度给出解释。

稀疏性在机器学习中是很令人趋之若鹜的特性，它天然地解决了机器学习中的一对大难题：“自动特征选择”(Auto Feature Selection)和模型的“可解释性”(Interpretability)。前面我们遗留了“如何自动做特征选择”这个问题没有回答。特征选择之所以重要，是因为一般来说样本的大部分特征都和最终的输出没有什么关系，不对结果提供任何信息或者只提供极少量的信息。如果在最小化目标函数的时候考虑了这些额外的特征，虽然可以获得更小的训练偏差，但在预测新的样本时，这些无用的信息反而会干扰对结果的正确评价。稀疏规则化算子能天然地将模型中对结果影响小的参数权值置为零，这样就去掉了这些没有提供信息的特征，自动完成了特征选择。另一个青睐稀疏的理由是，将无关的特征置零后得到的简单模型更容易解释。这一点也很容易理解，譬如，假设要统计患某种疾病的概率，且我们收集到的数据样本有1000个特征，换句话说，我们需要寻找这1000个特征到底是怎样影响病人患上这种疾病的。如果通过`L1`范数正则化之后，最后学习到的模型只有很少的非零元素，譬如只有5个非零的系数，那么我们就有理由相信，这些对应的特征在患病分析上面提供的信息是巨大的，是决定性的。也就是说，患不患这种病基本只和这五个因素有关，那医生就好分析多了。但如果1000个参数都不为零，医生面对这1000个致病因素是无法通过模型来寻找和解释致病原因的。

`L0`范数的定义本来就是零值越多，函数值便越小，它参与到目标函数之后，模型有稀疏性是很好理解的。而关于`L1`范数稀疏性的来源，我们就需要专门从几何角度去解释为什么它会具有这样的特性。

在角上相交就意味着其中一个参数为零，这就是`L1`范数稀疏性的来源，而在更高维的情况下，除了角点之外，还有很多边会发生与等值线的第一次相交，产生稀疏性。相比之下，`L2`范数就没有这样的性质，因为`p = 2`时p范数的单位球图像是个圆形，如图6-25所示。

由于没有菱形的角存在，所以第一次相交的地方出现在具有稀疏性的位置的概率就变得非常小了，这也从几何角度直观地解释了`L1`正则化能产生稀疏性而`L2`不能的原因。

`L2`范数是指向量各元素的平方和然后求平方根，它虽然没有稀疏性，却是一个比`L1`范数使用频率更高的范数，其应用场景不局限于机器学习，在各种科学领域都能看到它的身影。

![](Text/https:/res.weread.qq.com/wrepub/CB_3300153553_4vdAI83PO6L73H6Gw05Hhc3802.jpg)

图6-25　`L2`范数与损失函数等值线的交点

机器学习中，`L2`范数也有两个别称，有的资料把用它的回归算法称作“岭回归”(Ridge Regression)，有的资料叫它“权值衰减”(Weight Decay)。`L2`范数是用来解决机器学习中过拟合问题的主要手段之一，虽然`L1`范数也有一定的防止过拟合的作用，但如果以控制过拟合为目的，`L2`范数的效果要比`L1`范数的效果好，因为`L2`范数相对于`L1`范数更平滑，换句话说，它更“温和”一些。在模型预测中，`L2`范数往往比`L1`范数具有更好的预测特性，当遇到两个对预测有帮助的特征时，`L1`范数倾向于选择一个更大的特征，而`L2`范数倾向于把两者结合起来。

总之，`L1`范数、`L2`范数或者其他范数形式的正则化都是通过增加惩罚项，使得结果在偏差与方差之间取得平衡，从而使目标函数最小化来防止过拟合的。正则化是一种典型的、具有通用性的防止过拟合的方法，不过防止过拟合并不只有正则化这一种途径，不同的模型、策略中还有其他可行的办法，譬如神经网络中采用的Dropout就是根据神经网络特点设计的一种防止过拟合的技巧。

### 6.6.9 优化算法

目标函数一旦确定下来，就已经定下了采取何种模型的学习策略了，到这步，剩下的就是把模型中所有涉及的参数计算出来，归结为一个最优化的问题——求使得目标函数达到最小值时的参数数值解。机器学习中的优化算法就是为了求出这些参数数值解的算法。由于实践应用中，绝大多数情况下最优模型都是不存在解析解的，因此只能使用逐步逼近的计算方式来求数值解。同时，由于机器学习总是面对大量的训练样本，因此必须选择恰当的优化算法，才能确保找到全局的最优解，并且使得求解的过程足够高效。

在机器学习领域使用最广泛的优化算法是“梯度下降”(Gradient Descent)算法，它不仅广泛应用在传统的统计学习中，在神经网络和深度学习中也是一种常见的优化算法。在这一节，我们将以梯度下降算法为例，学习机器学习优化算法的原理和过程。

其他形式的损失函数还有很多种，无论选择何种损失函数，模型训练最终都要解决如何求损失函数达到最小值时的系数向量这个共同的问题。梯度下降算法是最常用的迭代求解算法。“梯度”一词是微积分中的概念，数学上，对多元函数的参数求偏导数，把求得的各个参数的偏导数以向量的形式写出来就是梯度。这里把微积分中导数、偏导数和梯度的概念简单复习一下：当函数定义域和取值都在实数域时，导数可以表示函数曲线上的切线斜率，这是导数的几何意义，同时也代表了该函数在该点的瞬时变化率，这是导数的物理意义。如图6-26所示，对于一元函数，`P`点的导数是当`x`变化一段很小的距离`Δx`后，`y`的变化量`Δy`与`Δx`的比值。

而对于多元函数，至少涉及两个自变量，也就是从曲线来到了曲面。曲线上的一点，其切线只有一条。但是曲面上的一点，其切线有无数条。偏导数是指多元函数沿坐标轴的变化率，如图6-27所示，在点(`x0`, `y0`)上对`x`的偏导数，就是指曲面被平面`y = y0`所截得的曲面`Tx`在点`M`处的切线对`x`轴的斜率。

如果考虑多元函数沿任意方向的变化率的话，也可以使用相应的三角变换来求得偏导数，这称为在点(`x0`, [EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)ic">`y0`)的某个方向上的方向导数。方向导数代表了函数沿这个方向变化的快慢，所有方向导数中最大的那一个，即函数值下降最快的那一个，被称为“梯度”，负梯度方向就是函数值上升最快的方向。

梯度有大小有方向，自然也是一个向量。依照梯度的定义，沿着梯度的正、负方向是最容易找到函数的最大值或者最小值的，因为这个方向的函数值变化最快。为求简单，前面的例子是一个简单的二维平面上的函数，对于三维或者更高维度的超平面，道理也是一样的。假如我们的函数定义在三维坐标系中，构成坐标轴的分别是参数`θ0`、`θ1`以及函数`J(θ0, θ1)`，会更贴合我们日常身处三维现实世界的空间观。此时，对于函数`J(θ0, θ1)`，在点(`θ0`, `θ1`)沿着正、负梯度向量的方向分别是函数值增大或者减小最快的地方，如图6-28所示，要寻找函数最小值，如同在一片凹凸不平的绵延深山中寻找那个地势最低的深谷谷底。

梯度下降算法就好比把我们随机传送到这片深山中的某处位置，我们的目的地是山下的深谷，由于我们并不知道下山的道路，因此决定走一步算一步，在每走到一个新位置的时候，先求得当前位置的梯度，以此作为行进的指导，然后沿着梯度的方向（这是当前位置最陡峭的方向），向下踏出下一步，到达下一个位置后继续求解这个新位置的梯度，再沿着最陡峭最快下山的方向踏出下一步。这样，保持固定的步长幅度，一步步地走下去，一直走到梯度值为零，从任何方向再踏一步都会比现在的位置更高的地方为止，这时就说明我们已经到了谷底了，这个过程可以用图6-29来直观表示。

还有一种需要考虑的场景，可能确实存在一个全局的极小值，但是同时有大量的局部极小值，形象地说就是函数图像可能是“坑坑洼洼”的，这可能会导致我们无法顺利走到山下，而是走到某一个局部的洼地处徘徊，此时由于所有的方向都会令函数值增加，因此无法使用梯度下降的方法再继续前进了，如图6-31所示的函数图像就非常容易陷入某个局部极小值中。
