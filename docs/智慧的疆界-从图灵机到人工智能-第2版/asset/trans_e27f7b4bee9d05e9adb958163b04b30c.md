

2014年，经过学术界和工业界几年时间的消化与酝酿，来到了深度学习在生成式领域迸发的临界点。生成式对抗网络诞生的所有前置条件都已经成熟，笔者认为即便没有那天晚上酒吧里古德费洛的灵光一现，生成式对抗网络也一定会在不久的将来换个作者、换个名字登上历史舞台。此观点可以通过现今最成功的三种图像生成式模型都是在2014年这个时间点前后同时被发现获得证明。除了生成式对抗网络以外，另外两种模型是2013年由迪德利克·金马(Diederik Kingma)提出的变分自编码器(`Variational Auto Encoder`, `VAE`)以及2015年由雅沙·索尔迪克斯坦(Jascha Sohl-Dickstein)提出的扩散模型(`Diffusion Model`)[^(155)](#fn155)

生成式对抗网络无疑是一项将来能写进人工智能教科书的经典工作，它虽然是深度学习向生成式领域拓展过程中“必然”会被发明的技术，但对于个人而言，能否在2014年这个时间点率先提出生成式对抗网络、名字是否叫作生成式对抗网络、作者能否被学术界认可为生成式对抗网络的发明人依然是无比重要的。学术也是一座江湖，仅本书写过的历史故事中就有纽厄尔和司马贺、明斯基和麦卡锡的人工智能发明人之争，明斯基与罗森布拉特的感知机前途之争，等等。在生成式对抗网络诞生的过程中，也出现了一场把学[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)术界的明争暗斗展露于明面之上的争吵。

2016年，古德费洛决定将生成式对抗网络的论文投稿到“神经信息处理系统大会”（Conference on Neural Information Processing Systems, `NIPS`[^(156)](#fn156)

拒稿的原因并非施密德胡伯看不到生成式对抗网络的巨大价值，根据他本人给出的评审意见[^(157)](#fn157)

虽然这场学术闹剧的中文信息寥寥，但在英文网络上的热度却不小，既有八卦也有严肃的学术讨论。古德费洛自己在推特上回应道：“点子一文不值，做出成果的人才有话语权。自己想到`GAN`的点子只花了30秒，做出来第一个可运行的`GAN`程序只花了一个多小时，撰写`GAN`论文只花了两个星期时间。”笔者理解这个回应的言外之意就是，施密德胡伯1992年提出`PM`模型的论文至今只有190多个引用量，对比他高达13万的个人论文总引用量来说，这个成果几乎没有被任何人注意到。既然生成式对抗网络就只有这么一点工作量，为啥你20多年时间都没有把它做出来，任它埋没在历史之中呢？

### 8.5 语言奇点

第7章曾讲到辛顿与两名学生苏茨克维和亚历克斯组队赢得`ILSVRC 2012`挑战赛冠军后，谷歌花费5000万美元收购了刚刚成立，没有任何实际产品或服务，就只有他们三名员工的“空壳公司”`DNNResearch`。当时这个新闻出来后，业界纷纷感慨谷歌重视学术的态度，称赞谷歌目光长远的人才战略。殊不知，这并非布局未来的战略，而是一笔实实在在的商业投资，真正体现了谷歌投资部门老辣独到的技术视野，等大家在短短三五年后重新审视这笔投资时，不得不承认无论从技术价值还是从商誉价值来衡量，仅投入5000万美元就能催生出一系列注定会载于人工智能甚至人类科技发展历史的发明，着实是惊人的回报。

#### 8.5.1 序列到序列模型

伊尔亚·苏茨克维（`Ilya Sutskever`, 1986—，见图8-7）是辛顿的学生，而且是真正意义上的“嫡传弟子”，他的本科、硕士研究生和博士研究生学位都是在辛顿的指导下获得的。要成为辛顿的学生并不是一件容易的事情，毕竟辛顿连本吉奥和吴恩达的老师迈克尔·乔丹(`Micheal Jordan`)的博士后申请都拒绝过。当时要作为辛顿的学生也不像是一个明智的选择，深度学习爆发之前，多伦多大学一直就流传着一句话：“不要去辛顿的实验室，那是没有前途的地方。”更多关于辛顿的内容可参见前面第7章。

图8-7　伊尔亚·苏茨克维

2003年，刚考入多伦多大学的苏茨克维来到了辛顿的办公室，他并没有提前预约，却理直气壮地直接提出希望加入辛顿的实验室[^(161)](#fn161)

十年光阴转瞬即逝，2012年，刚刚从辛顿手上获得博士学位的苏茨克维随`DNNResearch`收购案进入谷歌人工智能团队。在分配出售`DNNResearch`的收益时，苏茨克维和亚历克斯都认为他们的老师辛顿理所应当占大头，但辛顿断然拒绝，坚持认为5000万美元的收益应该由三人平分。所以苏茨克维虽然才刚刚毕业，但已经是身价千万美元的富翁了。经济上的宽裕并没有让苏茨克维选择“躺平”，只是给予了他不用为研究经费奔波、自由选择研究方向的权利。

苏茨克维决定将他的主要研究方向从原本的计算机图形学调整到自然语言处理(`Natural Language Processing`, `NLP`)。几年后苏茨克维本人在采访中解释过更换研究方向的原因，他认为：“图像是人类知识的源头，而语言是人类知识的压缩。”想办法让计算机理解人类自然语言也许是机器通往智能的一条捷径，因为对比视觉和声音，语言的信息压缩比例要高得多。我们不妨想象一下，人工智能像是一位初到陌生城市的旅者，最开始，这位旅者可能只懂得几个最基本的词汇和短语，类似于旅游手册里的内容。随着时间的推移，他开始学习当地的语言，在过程中也会了解当地的历史、文化和习俗，以便能更深入地理解这座城市，甚至能够与当地人进行深层次的交流。最后，这位旅者不仅学会了如何使用语言，也理解了当地人的想法、情感和行为方式。语言就像是一座桥梁，帮助一个陌生人逐渐融入新的城市，人工智能通过学习语言，也许会逐渐理解并参与到人类的世界中来。

苏茨克维最开始的研究是用神经网络处理不同类型的序列数据（如字符、单词、句子、声音等都是典型的序列数据）之间的转换。自然语言处理的应用几乎都是围绕着序列展开的，譬如：从一种语言的序列转换成另外一种语言的序列，这是机器翻译的场景；从一种含义的序列内容转换成有内容顺承关系的序列，这是自然语言对话的场景；等等。

以机器翻译为例，2012年以前的主流方法是统计机器翻译(`Statistical Machine Translation`, `SMT`)，希望能从大量相互对照的语料数据中学习，得到一个从源语言映射到目标语言的统计概率模型。进行翻译时，只要找到概率最大的目标语言映射结果便认为是对源语言的最佳翻译结果了。这种思想模仿了人类对语言学的研究方法论，譬如人类语言学家通过研究罗塞塔石碑（`Rosetta Stone`，见图8-8）上三种不同语言铭刻的古埃及法老托勒密五世诏书，利用映射关系成功解读出已经失传千余年的埃及象形文字，成为研究古埃及历史的重要里程碑。

但是统计机器翻译依靠映射概率的方法存在十分明显的局限性，且不说两种或两种以上语言描述同一内容可以相互映射的语料十分难得，只占所有语料数据很少的一部分，仅说建立两种语言之间相同含义的序列映射就很困难，这样的映射有可能是一对一、一对多、多对一或者多对多的，有一些词汇甚至找不到映射关系。譬如笔者[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)曾数次提到了“江湖”这个词，读者不妨想想它应该如何翻译为英文。类似的困难还有许多，这些困难大多并非无法解决，但问题是解决方案往往只能针对特定的源和目标语言来处理，不可避免地涉及大量的特征工程以及语言学专家知识，需要庞大的人力才能维护，这就导致了在很长时间内，只有几种主流语言之间的机器翻译能够给出差强人意的结果，其他小语种的机器翻译结果几乎无法被实际使用。

图8-8　罗塞塔石碑

引用上一节的生成式对抗网络作为对比，我们可以评价统计机器翻译是一种“深度依赖人工参与、深受人类能力限制的模型”。针对统计机器翻译的缺陷，2014年，苏茨克维在发表的论文“`Sequence to Sequence Learning with Neural Networks`”中提出了“神经机器翻译”(`Neural Machine Translation`, `NMT`)的概念。神经机器翻译的基本结构由一套名为“序列到序列”（`Sequence to Sequence`，一般简写为`Seq2Seq`）的两层循环神经网络构成，这两层循环神经网络分别称为“编码器”(`Encoder`)和“解码器”(`Decoder`)，如图8-9所示。

在编码器一侧的任务是对输入序列的上下文语义进行向量化，这个任务的通俗解释就是把含义相近的语言序列转换为向量空间（本书6.5.2节中有关于向量表示与向量空间的介绍）中距离相近的向量，含义差距较大的序列对应的向量距离较远。进行“词向量化”(`Word Vector`)的过程被称为“词嵌入”(`Word Embedding`)，该技术一揽子地解决了不同语言、语法中诸多充满不确定性的歧义问题。以中文为例，单独来看“胜”和“败”的向量距离很远，但“中国队大胜美国队”和“中国队大败美国队”的向量距离却很近；“How are you？”和“吃了没？”，虽然直译的结果看起来完全不相干，但它们的向量距离在大多数上下文中都是十分接近的。早在2000年，本吉奥在论文“`Neural Probabilistic Language Models`”中就提到了使用词嵌入技术产生词向量来表示语义远近关系的思想。在神经机器翻译提出的前一年（2013年），苏茨克维当时的同事、谷歌研究员托马斯·米科洛夫(`Tomas Mikolov`, 1982—)发表了两篇论文[^(162)](#fn162)

在解码器一侧的任务是对输出序列中下一个词的最大概率进行预测，这个任务同时接收两个输入，一个是编码器给出的上下文向量(`Context Vector`)，另一个是上一轮解码器刚刚输出的结果（否则就谈不上是“下一个”词了）。刚刚开始时，首个输入词固定为起始标志“`<Start>`”。笔者举个例子来说明解码器是如何工作的：假设当前进行的是机器翻译任务，上一阶段编码器已经对输入序列“好好学习”产生了上下文向量，这个上下文向量在论文中被称为“隐藏状态”(`Hidden Status`, `HS`)。当解码器接到隐藏状态`HS1`和第一个词“`<Start>`”后，产生的输出是“good”，每轮产生输出词的同时也会修正隐藏状态的内容，如将隐藏状态`HS1`修正成`HS2`。接下来，把上一轮输出的词“good”和`HS2`作为输入，本轮产生的输出同样是“good”并修改隐藏状态为`HS3`，然后第三轮根据第二个“good”产生了“study”，最后产生结束标记“`<End>`”，由此就生成了完整的翻译结果“`<Start>`”“good”“good”“study”“`<End>`”。训练不同的解码器，便能够满足不同的应用需要，假设当前的应用场景是自然语言对话，那各轮次产生的输出序列可能依次是“`<Start>`”“天”“天”“向”“上”“`<End>`”。

序列到序列模型的强大之处有两点，其一在于它彻底跳出了传统统计方法“从一种语言映射到另一种语言”的藩篱，可以使用单一语言的语料来训练出该语言的编码器和解码器，而不需要刻意地寻找两种语言相互对照的数据来训练出专门针对这两种语言的翻译任务的模型。其二是它完全摆脱了序列受映射关系对齐约束而导致的长度受限问题，序列到序列模型的输入和输出长度没有强制的关联关系，完全取决于编码器和解码器（主要是解码器）是如何设计的，因此输出序列长度可以做到与输入序列差异极大，即使用户只输入了一个十分简短的问题，解码器也可以生成洋洋洒洒上千字的回答。以上两个特点为使用序列到序列模型解决自然语言处理领域的众多经典问题带来了全新的可能性，无论是机器翻译、对话还是摘要等任务，均可胜任。

序列到序列模型的发明完全可视为语言爆发的奇点，自此以后，机器对人类语言的理解和处理能力，再延伸到机器对语言背后的知识汲取速度，都一改此前几十年平缓演进的曲线，以普通人难以想象的速度快速提升。

#### 8.5.2 注意力机制与Transformer架构

序列到序列模型的发明，就像生成式对抗网络给图像处理领域带来的震动一样，在自然语言里开辟了一条崭新大道，吸引了几乎该领域所有的研究者竞相参与。尽管如此，对序列到序列模型最重要的两项改进依然还是由谷歌人工智能团队做出的，这两项改进奠定了后续的主流大语言模型研究路线的共同基础。

第一项改进现在被称作“注意力机制”(`Attention Mechanism`)，是由谷歌研究员德米特里·巴赫达瑙(`Dzmitry Bahdanau`)在2014年提出的。苏茨克维的序列到序列模型最初采用传统的长短期记忆网络（就是施密德胡伯的`LSTM`）来处理序列中的长距离信息依赖，尽管长短期记忆网络本来就是为了这个目的而设计的，但它毕竟仍是一种循环神经网络，随着序列长度的增加，长短期记忆网络依然面临梯度消失或梯度爆炸的问题，这使它在捕捉长距离信息依赖时变得愈发困难，尤其是要处理的序列长度达到整个文档甚至成套的书籍时，传统的长短期记忆网络几乎就变得完全无法使用了。

巴赫达瑙发明[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)的注意力机制的核心思想是：在处理长序列数据时，并不是所有输入的信息都同等重要，模型应该根据本轮任务，自动和动态地决定在处理每个输出序列时应当重点关注哪部分输入。模型如何知道输入的哪些部分与任务的相关性更高呢？解决这个问题的不同方法就形成了不同的注意力机制。譬如巴赫达瑙给出的方法是首先将输入序列中的每一项元素都赋予一个注意力权重，用来表示当前任务中模型对输入序列中每个元素的关注程度，然后训练一个小型的前馈神经网络（通常只有一个隐层）来预测这个权重值[^(163)](#fn163)

当下更为流行的是在`Transformer`架构中广泛使用的“点积注意力”(`Dot-Product Attention`)，它将注意力机制的工作过程分解为“`Query`”“`Key`”和“`Value`”三部分，通过点积计算得到权重值。要从数学角度严谨地理解`Query`、`Key`和`Value`进行点积计算的含义非常烦琐枯燥，笔者举个生活中的例子来加以说明：请想象一位女士去婚介所购买相亲服务的场景，婚介所中有成千上万份候选档案，当然不可能让顾客逐一阅读每份材料来找出要相亲的对象，通常是先让女士描述一下她心中理想丈夫的特征，譬如身高、体重、工作、收入、房车状况、教育、家庭等，这些条件就是`Query`。接着婚介所拿着理想条件(`Query`)去和所有候选人的现实条件(`Key`)进行匹配，匹配程度越高，女士应投入的注意力权重就越大，然后根据注意力大小来决定要花多大精力去阅读候选人的档案材料(`Value`)。

依靠计算输入序列中每个元素的注意力权重，后续的神经网络层次得以直接访问和利用输入序列中最有价值的信息，因此注意力机制下的记忆访问是无视距离长短的，如此便能绕过处理长序列时的梯度消失或梯度爆炸问题。现在注意力机制的应用已经不限于序列到序列模型了，它已成为现代深度学习模型中的一个重要技巧，显著提高了各种自然语言处理任务的性能。

第二项改进是2017年谷歌著名论文“`Attention is All You Need`”里首次提出的`Transformer`架构，如图8-10所示。从这篇文章直白的标题“你只需要注意力”就能一窥究竟：既然已经使用注意力机制来解决长期记忆和输入序列利用效率这些问题了，那何不索性直接将序列到序列模型中的循环神经网络完全替换掉，用更加简单的前馈神经网络[^(164)](#fn164)

为何循环神经网络会如此不受欢迎呢？这是因为循环神经网络的原生设计就是依靠循环把前一次的输出作为下一次的输入来体现序列中的顺序关系，它天生就只能串行训练，在顺序的特性约束下它无法成批次地并行计算。因此，尽管在自然语言处理任务中序列到序列模型比传统统计学习的效果要好得多，只需要无标注的单一语言语料即可完成训练，也不会过分依赖专家知识，解除了模型训练中数据样本的限制和专家人力的限制，但是算力的限制仍没有解除，串行训练无法有效地利用现代计算机多核并行系统的优势，且训练时间的局限约束了语言模型的规模上限，直接影响了应用的最终效果。
