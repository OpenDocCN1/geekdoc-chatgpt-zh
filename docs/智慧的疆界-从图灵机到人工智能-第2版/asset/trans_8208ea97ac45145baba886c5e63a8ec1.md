

### 9.4.1 人工智能的威胁

第二种“人工智能的威胁”更为隐蔽，但是也已经不可逆转地发生了——来自人工智能对信息垄断控制的威胁。我们已经习惯了打开搜索引擎，找想要的信息；打开新闻客户端，看看每天的新闻资讯；打开微信朋友圈，了解朋友和同事的最新动态。我们的生活方式已经深度依赖上互联网这个人类历史上绝无仅有的信息平台。而现在，互联网上越来越多的信息是被人工智能所控制甚至是直接由人工智能创造的：你看到的那些搜索内容，是人工智能决定让你看到的，尽管搜索引擎可能为你提供了1000000000条结果，但你最多只会使用前面的50条或者100条，这是人工智能决定的搜索结果顺序；你上美团、饿了么App点外卖，上京东、淘宝App购买商品，也是人工智能根据你的消费习惯和个人喜好为你推荐的。这里面人工智能对庞大信息的筛选过滤确实提升了我们的工作、生活的效率，可是我们在享受数据的便利的同时，也渐渐失去了意外收获的机会。你上网易云音乐去听歌，如果平时喜欢摇滚乐，人工智能搞明白后，可能就听不到其他的音乐风格了，会错失跟它们邂逅的机会。如果没有意外的便捷生活就是我们想要的，那笔者摘录一段在网上[^(202)](#fn202)

“我们一出生，人工智能系统就会根据我们的基因选择最优的成长路径。我们会阅读最合适的读物、观看最合适的娱乐作品。衣食住行也都不用操心，全被安排妥当。到了适婚的年龄，智能系统会推荐最匹配的情侣，无论怎么算，我们的性格和其他个人条件都跟对方最搭。智能系统知道怎样让每个人开心，它会定时定量地给我们一些刺激。有时候是直接吃药，有时候是看一段有趣的视频，有时候是给我们推荐几个好玩的朋友。所有的痛苦都被抹杀。在这个乌托邦里我们只享受快乐。总之，每个人的一生都会高高兴兴地度过。根据智能系统的测算，这个时代的人类，在整个历史上都是最[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)幸福的……”

这样的未来并不全是凭空臆想出来的，在《必然》(The Inevitable)里，凯文·凯利(Kevin Kelly, 1952—)提到，所有的集体智能和机器都会融合为一个被他命名为“Holos”的整体，Holos包括了所有人的集体心智、所有机器的集体行为、自然界的智能相结合形成的整体，以及出现在这个整体中的任何行为。这个整体目前尚属不完美的初级阶段，以互联网的形态覆盖着510亿公顷的土地，触及150亿台计算机，占据40亿人类的心智，消耗地球5%的电能，它就是未来智能乌托邦的载体。

不知道会不会有人真的向往这样的生活，但是在笔者脑海中闪现出来的画面是图9-17这样的，即在电影《机器人总动员》中被人工智能和机器人抚养得极为妥帖的人类。笔者没有从画面中感受到幸福，反而有一种隐隐的不安。

![](Text/https:/res.weread.qq.com/wrepub/CB_3300153553_4vdAI83D26L73H6Gw05Hhe1909.jpg)

图9-17　电影《机器人总动员》里被抚养得妥帖的人类

令人感到更不安的是当前已存在的直接风险，即人工智能控制我们看到的数据，本身是没有目的性的，但其背后的人是有目的性的：你随手点了一家看似不错的餐厅的外卖时，也许不会意识到它是花了钱后才被系统推送到你的面前的；当你津津有味地阅读新闻客户端的推荐文章时，也不知道有些文章其实是软文或者公关文章。由于信息的垄断控制，商品和信息流转过程中增加了额外的隐性环节和成本，轻则会损害最终用户利益，这些成本最终都要转嫁到用户身上；重则会干扰最终用户的判断。在信息社会，人控制了人工智能作恶，比人工智能自己学会作恶的可能性要大得多。这种威胁与原始社会的火、封建社会的刀、现代社会的核能并无不同，它确实会给我们带来伤害，但也是机遇所在，具体取决于我们如何使用这项工具。

### 9.4.2 人工智能的机遇

说到机遇所在，我们不必去看多么遥远的将来，现在就能观察到无数人工智能带来的价值和机遇。“英伟达”(Nvidia)公司肯定是近十年最突出的人工智能带来商业价值的落地的代表，从这家公司身上可以看到整个硬件产业被人工智能带动前行的缩影。

根据这家全球领先的显卡制造商最新披露的财务数据（截至2024年6月），它已经超越了微软和苹果公司，成为全球市值最高的企业，如图9-18所示。本书第1版（2018年出版）曾经写到“英伟达公司的股价已经比2012年深度学习爆发前夕增长了20多倍”。比起这个10年翻20多倍的成绩，英伟达的市值在2023至2024财年只用了一年的时间就猛增了7倍之多。

英伟达毫不讳言自己市值快速增长的秘诀，这家以生产游戏显卡和显示芯片闻名的公司，早已把自己官网主页的标题改成了“英伟达，一家人工智能计算公司”。

2007年，英伟达非常有预见性地提出了“统一计算设备架构”(Compute Unified Device Architecture, CUDA)的概念，并将其实现在以代号G80为核心芯片的NVIDIA G[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)eForce 8系列显卡上，第一次让显卡上的“图形处理单元”(Graphics Processing Units, GPU)具备了可编程的能力，使得GPU的核心“流式处理器”(Streaming Processor, SP)既具有处理像素、顶点和图形等渲染能力，又具有通用的单精度浮点运算能力。英伟达将采用了CUDA架构的GPU称为“通用图形处理单元”(General Purpose GPU)，“通用”的目的很明确，就是想“染指”游戏图形之外的科学运算市场，让GPU既能做游戏和渲染，也能做并行度很高的通用计算任务。

![](Text/https:/res.weread.qq.com/wrepub/CB_3300153553_4vdAI83D26L93H6Gw05Hhe6c58.jpg)

图9-18　英伟达成为全球市值最高的企业（数据截至2024年6月）

英伟达提出CUDA架构开辟新的战场，既是自身发展的战略规划决定的，也有很大一部分原因是外部市场环境压力所迫。当时英特尔(Intel)公司已经把在计算机中央处理器(CPU)中集成的GPU单元的性能提升到能完全满足低端用户需求的程度，而超微半导体公司(Advanced Micro Devices, AMD)在竞争激烈的高端游戏显卡市场推出了游戏性能更强大并且功耗和散热更优的产品与英伟达直接竞争。一时间，行业龙头英伟达被围追堵截，颇有些四面楚歌的感觉。从2007年初起，短短一年多时间，英伟达的股价就从最高37美元跌落到最低不足6美元。

而CUDA架构的及时出现，不仅拯救了在游戏领域陷入竞争泥潭的英伟达，还正好击中了人工智能尤其是深度神经网络的痛点。可以说，整个深度神经网络技术在过去几年的崛起，除了得益于辛顿提出的深度学习理论、ImageNet大规模视觉识别挑战赛之外，CUDA架构提供的并行运算能力也功不可没。谷歌大脑训练神经网络在YouTube上识别猫，原本需要同时使用超过2000片CPU，后来只使用了12片GPU就完成了相同的任务。辛顿拿去参加ImageNet挑战赛的AlexNet，也是采用了两片GeForce显卡代替CPU来完成训练，后续参赛的残差网络(ResNet)等作品，全部都基于CUDA平台运行。如果没有英伟达的CUDA，科学界验证深度学习巨大潜力的时间不知道还要推迟多久。CUDA技术使得在普通个人计算机上进行高并行度、高性能运算的成本大幅降低，以至于一个普通科研人员的台式计算机都有可能部署上万个并行处理内核。这促使深度学习技术在科技界迅速地发展和普及开来。如果没有GPGPU和CUDA，也许坚持研究了30多年神经网络算法的辛顿，还得继续在学术界被埋没好些年。不仅仅人工智能、机器学习的崛起造就了英伟达，英伟达和它的CUDA架构也同样加速了人工智能和机器学习的发展进程，这也算是一个人类与人工智能共生双赢的代表案例。

由于深度学习的潮流日益鼎盛，现在各个传统的芯片厂商，还有以前并不涉及芯片的信息业巨头，都看好面向人工智能的专用处理器，认为这将是继CPU、GPU之后下一代的硬件核心，并不约而同地推出自己专门面向人工智能的处理器，意图抢占制高点。一时间“张量处理器”(Tensor Processing Unit, TPU)、“神经网络处理器”(Neural network Processing Unit, NPU)、“类脑处理器”(Brain Processing Unit, BPU)、“深度学习处[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)理器”(Deep learning Processing Unit, DPU)等形成群雄乱战的场面。

可以说英伟达是硬件行业被人工智能推动的一个缩影，硬件行业又是整个社会经济在人工智能影响下的一个缩影。随着人工智能理论和技术的日渐成熟，应用范围的不断扩大，潜在需求和商业模式的逐渐明确，人工智能核心产业的边界与范围将逐步扩展。通过人工智能核心产业发展所形成的辐射和扩散效应，获得新提升、新增长的国民经济其他行业集合，均可视为人工智能带动的相关产业。根据普华永道的研究预测，至2030年，人工智能将为世界经济贡献15.7万亿美元，这个数字甚至超过了我国2020年的GDP经济总量[^(203)](#fn203)

人工智能推动的不仅仅是经济发展，生产力决定生产关系，生产关系一定要适应生产力，这是人类社会运行的最基本规律之一。看看历史就知道：农业革命，铁器牛耕的出现，让封建地主战胜了奴隶主，地主阶级取代了奴隶阶级；工业革命，机器大规模生产的出现，让资本主义战胜了封建主义；信息革命，计算机、互联网和人工智能的出现，也将是下一次社会秩序变革的导火索。长期来看，人工智能会导致相同价值的经济生产所需的人力愈来愈少，资本主义社会的本质是劳动创造价值，价值用金钱来表现，金钱的交换就是劳动与劳动之间的交换，但是空前规模的生产效率提升，将促使社会资源从按劳分配转变为按需分配，因此必须建立与之配套的新的社会秩序，这是人工智能为人类带来的最大机遇，是生产力变革带来的社会秩序的变革。

## 9.5 本章小结

本章最后我们再来回顾开篇提出的问题：现在人工智能已经发展到什么程度了？读过众多应用案例，了解过人工智能取得的成就之后，各位读者心中是否已有了自己的答案？

人工智能是人类最复杂精巧的创造物，它带来机遇，也带来危险，但它肯定不会是“人类最后的发明”，相反，我们创造出来的东西让自己成为更好的人，这便是开始。本书结束的这一刻，笔者心中想起了英国首相温斯顿·丘吉尔(Winston Churchill, 1874—1965)在1942年阿拉曼战役胜利时讲的一句话：“现在并不是结束，结束甚至还没有开始，现在仅仅是序幕的尾声。”这也是笔者对现在人工智能发展的回答。

1931年　库尔特·哥德尔(Kurt Gödel)提出了著名的哥德尔不完备定理，证明了如果一个形式系统是不含矛盾的，那就不可能在该系统内部证明系统的不矛盾性。这个定理对机械智能的限制是它决定了无论人类造出多么复杂的机器，只要它是机器，就将对应一个形式系统，就能找到一个在该系统内不可证的公式而使之受到哥德尔不完备定理的打击，机器不能把这个公式作为定理推导出来，但是人却能看出公式是真的。因此这台机器不可能是承载思维的一个恰当模型。

![](Text/https:/res.weread.qq.com/wrepub/CB_3300153553_4vdAI83HA6L43H6Gw05Hh4d095.jpg)

1936年　图灵在他的论文《论可计算数及其在判定性问题上的应用》(“On Computable Numbers, with an Application to the Entscheidungs Problem”)中提出了图灵机的概念。图灵机是图灵一生中最重要的成就之一，这种计算机器实际上是一种理想的计算模型，它的基本思想是用机械操作来模拟人们用纸笔进行数学运算的过程。

1943年　心理学家沃伦·麦卡洛克(Warren McCulloch)和沃尔特·皮茨(Walter Pitts)在《数学生物物理学通报》上发表论文《神经活动中内在思想的逻辑演算》(“A Logical Calculus of Ideas Immanent in Nervous Activity”)，文中讨论了理想化、极简化的人工神经元网络，以及它们如何形成简单的逻辑功能，首次提到了人工神经元网络的概念及数学模型，从而开创了通过人工神经网络模拟人类大脑的研究时代。后来人们将这种最基础的神经元模型命名为“M-P神经元模型”。

1948年　诺伯特·维纳(Norbert Wiener)和克劳德·香农(Claude Shannon)分别发表了开创性的著作，创立了控制论和信息论。
