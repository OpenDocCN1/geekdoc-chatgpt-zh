# 后记

本书从各个角度浅谈了对思考上瘾的看法，但我最想告诉各位读者的是“享受思考”的重要性。

工作中“只做分派给你的任务”，有人要求你说说自己的想法、创意，才会极不情愿地进行思考，这些绝对不是令人开心的工作方式。

没人要求时也要自主进行思考，接连不断地提出想法、创意，越多越好，这样工作起来才会更开心。

我身边的成功人士都在不断思考。哪怕只是简单对话，他们也会不断地提出自己的想法，诸如“这样做比较好”“这样做的挑战如何”……并且，大家在坚持思考并提出自己的想法时无一例外都是非常开心且活力四射的。

因新冠肺炎离世的志村健说过，自己一直坚持思考如何做到幽默搞笑，因为是在做自己喜欢的事情，所以丝毫不觉得辛苦。

坚持思考甚至思考上瘾，是身心永葆青春的最佳方法。坚持思考的人说话、行动时的反应速度都非常快，无论形象还是思维都充满活力。

只要坚持思考，人生就会充实，虽然生理上会逐渐衰老，头脑却一定会永葆青春。

衷心地希望大家在工作与生活中都能心情愉悦、青春永驻！
