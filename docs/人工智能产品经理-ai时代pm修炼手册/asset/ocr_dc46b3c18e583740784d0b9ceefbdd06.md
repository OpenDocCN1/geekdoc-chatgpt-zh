# 表 5-1 常见的机器学习开发平台汇总

| 开源工具 | 研发机构 | 适用平台 | 开发语言 | 预训练模型 | 分布式联机功能 | 主要特点 |
|---|---|---|---|---|---|---|
| Caffe | BVLC | Ubuntu、OS X、AWS、Windows 等 | C++、Python | 有 | 不支持 | 主要针对卷积架构的网络提供解决方案，适用于图像分类、目标识别，图像分割等图像处理领域，高性能，配置简单，适用平台多。百度云台 |
| CNTK | Microsoft | Windows、Linux 等 | C++ | 无 | 支持 | 基于 C++并且跨平台的深度学习工具，部署简单，性能强大，但目前暂不支持在移动设备上部署 |
| DMTK | Microsoft | Windows、Linux 等 | C++ | 有 | 支持 | 机器学习算法与大数据处理深度融合，有丰富易用的 API 接口，其力度巨大高效，实用性强。属于简介而用级别（非研发目的）深度学习开源工具，以即插即用为目标，可与 Hadoop 和 Spark 深度集成，方便开发者在快速集成深度学习功能 |
| DL4J | Skymind | Linux、Ubuntu、Windows、OS X、Android | Java、Scala、C、C++ | 有 | 支持 | 具备丰富而高效、非研发目的）深度学习开源工具，以即插即用为目标，可与 Hadoop 和 Spark 深度集成，方便开发者在快速集成深度学习功能 |
| MXNet | DMLC | Ubuntu、OS X、Windows、AWS、Android、iOS、JavaScript | C++、Python、Julia、Matlab、Go、R、Scala 等 | 有 | 支持 | 允许用户自由地因图计算和过程计算混合，支持自动多卡调度，强调网内存使用效率，高使用性能 |
| OpenAI Gym | OpenAI | Linux、OS X 等 | Python 等 | 有 | 支持 | 专注非监督式学习和增强学习，具有完备的训练测试环境集成，乐趣并列利性。云端托管的分布式深度学习平台，以 Spark 并列计算平台为基础架构，对于序列输入、模糊输入和大规模数据的模型训练有着良好的支持，代码简洁、运行高效、支持拓展性强 |
| Paddle Paddle | 百度深度学习实验室 | Windows、Linux、OS X 等 | C++、Cuda 等 | 有 | 支持 | 以 Spark 并列计算平台为基础架构，对于序列输入、模糊输入和大规模数据的模型训练有着良好的支持，代码简洁、运行高效、支持拓展性强 |
| TensorFlow | Google Brain | Linux、OS X、Windows | C++、Python、Cuda 等 | 无 | 支持 | 有深度学习专用语言，易于混合使用多种不同模型进行训练，运行速度快、可扩展性、与产品可迁移性强 |
| Theano | 蒙特利尔理工学院 | Linux、Ubuntu、Windows 等 | Python | 有 | 不支持 | 可自行设计神经元单元和神经连接，支持 MLP、CNN、RNN-LSTM等多种深度神经网络，缺点是 C++代码的抽象过程过度的缓慢。 |
| Torchnet | Facebook FAIR | Linux、Android、OS X、IOS | C、Lua | 有 | 不支持 | 采用可抽象和公式化逻辑的开源课框架，提供快丰富的基本概念和代码块，可执行抽象和公式化代码，无需模块化编程和代码重复使用。 |
