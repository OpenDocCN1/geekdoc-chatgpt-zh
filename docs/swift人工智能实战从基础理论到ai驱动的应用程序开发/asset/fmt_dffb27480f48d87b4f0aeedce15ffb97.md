# 第3章　寻找或构建数据集

许多有关机器学习或AI的入门练习都提供了可供使用的数据集。当你面对自己的实现时，情况可能并非如此。寻找和转换输入数据使其可以建模以解决特定问题，这本身就是一个挑战。

数据科学中的一个常见习语是`GIGO`，它代表“垃圾进，垃圾出(garbage in, garbage out)”，这是指以下事实：模型只能和所训练的数据一样好。本章介绍了获取预制数据集，或者设计和构建你自己的数据集的可能选项。

请注意，此过程中的每个步骤都高度取决于你的个人数据和解决方案要求，因此在某些方面是比较高级的。许多数据整理的实践都是通过经验磨炼出来的。

## 3.1 规划和识别目标数据

有些人将数据集规划阶段称为一种设计过程，这一点都不夸张。机器学习过程中最容易犯的错误之一就是没有为任务选择合适的输入数据—不一定是指质量差或来源差的数据，也指与模型期望预测的结果没有充分关联的数据。

并不是所有的机器学习问题都能在技术层面之外得到解决。预测天气至少需要历史上的温度、湿度和展望数据，而这看起来似乎很直观。但是，其他问题可能不那么简单。

如果需要一个模型来预测人类行为，该怎样做呢？在一所本地大学的AI基础课上，首先提出的问题之一是如何设计一个模型，以预测儿童恶作剧者在学校的任何一天恶作剧的可能性。这是一个纯理论的练习，通常每个学期都会出现同样的想法。除了记录他们在某一天是否犯事了，还应该记录这是一周中的哪一天，他们早餐吃了什么，睡眠是否充足，他们是否被禁足，天气如何，他们最好的朋友那天是否在学校……清单还可以继续列下去。

但是，这个可能影响有感情生物的情绪或运动的因素列表究竟会在哪里结束呢？它不会结束，真的。

如果你试图为蝴蝶效应建模，很容易就会掉进无底洞。所以，训练模型之前的数据准备过程可以概括为如下内容：

获取数据→清洗数据→转换数据→训练

由于缺乏完美的解决方案，必须采用更灵活的流程。该流程大概是这样的：

调查可用数据源→获取数据→探索数据→清洗数据→探索数据→转换数据→探索数据→训练

在整个过程中，任何时候都可能重新开始。

对于真正的项目来说，在最终开始之前，往往会多次探索转换后的数据—使用获得的知识尝试不同的转换方法，或者意识到在每次迭代的数据中应该包含一些不同的变量。

这里没有明确的方法规定，建议你充分开启头脑风暴。然而，当涉及数据和问题的整体逻辑时，有一些你需要避免的常见错误：

• 否定即失败(negation as failure)

• 封闭世界假设(closed-world assumption)

### 3.1.1 否定即失败

这个术语用来描述如果一个问题不能证明为真，那么就会默认为假。

例如，使用`if/else`（为肯定情况定义捕获条件，否则默认为否定）和使用`if/else if`（定义两个捕获情况，`else`默认为不执行任何动作）之间的逻辑差异可能很小。但是，如果这个逻辑建模的问题没有清晰的定义，那么可能导致大量的问题。例如：

![](images/189ccdf4-3b1f-40e6-9d76-cb81e7f03ba4.jpeg)

如果只有两个按钮可以输入，这可能是安全的，但是这样的代码可能将任何输入注册为否。这意味着`y`可能是否，`yes`也将是否，任何其他字母或符号甚至换行符也可能是否。这个问题期待的答案是`Y`或者`N`，但是它所处的上下文并没有清晰的划分。

### 3.1.2 封闭世界假设

这个术语描述了不准确的假设，即所拥有的关于一个事物的信息封装或者表示了全部。例如，一个列表被视为完全穷举的：

![](images/fdca299d-674a-4e89-be20-68dd1ca34394.jpeg)

这是一个更好的方法吗？可能是。这是一个完美的方法吗？绝对不是。一个理想的系统应该是能够复制人类在听到口头上的“是”或“否”回答时的大脑反应：这个声音是否在某个已知的阈值内，而这个人以前听到过用于表示“是”或“否”的任何术语吗？如果是，假设这就是他们的意思，或者这是一个还不熟悉的俚语。另外，澄清一下，在回答“是”或“否”的问题时，他们的意思是其中一个。

###### 认罪

最近，一位作者在设计类似的东西时犯了一个错误，当时她正在为自己开发的macOS应用程序快速编写一个替代模型。在私人调查阶段，已经训练了一个健壮的图像分类模型来对艺术风格进行分类，但是由于在专有和私有数据集上进行了训练，因此必须在公开展示之前提取该模型。

这个问题的替代数据集很难找到，并且快速拼凑而成的结果与以前的版本相比准确度要低得多，因为看到的类都不存在，因为此输入数据并未涵盖原始数据集的所有类别。

一个快速的修改：如果模型对其分类的确定度小于`n` %，那么它将无法应用。但现在的问题是，如果一个图像公开地表示多个类，以至于弄不清应该选择哪个类，它仍然没有被分类。

好吧，作为演示已经足够好了。

除了简单的逻辑错误外，推理错误也有很大的不同。大多数解决方案的目的是为确保系统的设计和输入尽可能准确并完整地反映出你试图建模或预测的现象。这不是一件容易的事，但这是一件值得做的事。

记住，除了基于图像的数据（照片、光谱图、视频帧等），你将构建或使用的绝大多数数据集将要或需要转换为值表。想一想：如果问题空间中以前的所有观察结果都必须放在一个表中，那么列标题和类型是什么？

了解如何以及在何处查找要使用的数据集是很好的。在AI的广阔领域和它可以应用到的大量问题中，这两者都是非常主观的，但是存在一些通用的真理和建议。

### 3.2.1 去哪里找

对于常见问题，有很多地方可以开始你的搜索。

就像Google Scholar用于研究论文那样，Google Dataset Search用于数据集。谷歌搜索的应用是无处不在的。这是了解特定主题的绝佳起点。谷歌还管理自己的通用公共数据存储库，称为Google Public Data，亚马逊也拥有自己的AWS数据注册中心。

研究机构通常会发布科学数据供公众使用。如果你需要敏感的人类数据（如果可以确信已经适当匿名），这将特别有用。在澳大利亚，我们拥有诸如澳大利亚统计局、联邦科学与工业研究组织(CSIRO)之类的机构，甚至还有一个用于访问所有政府数据的在线门户，名为data.gov.au。

在世界其他地方，著名的机构包括NASA、NOAA NIST、CDC、WHO、UNICEF、CERN、Max Planck Institute、CNR、EPA等。

同样，许多国家或地区都有中央政府数据存储库，例如data.gov（美国）、open.canada.ca、data.govt.nz、data.europa.eu和data.gov.uk等。

一些具有非科学目的的公司，如果达到了自己能够进行内部研究或被要求进行内部研究的规模，甚至会发布数据存储库。世界银行和国际货币基金组织(IMF)就是一个很好的例子，它们已经成为开放的金融和大众数据的主要来源。

FiveThirtyEight和BuzzFeed这样的新闻网站，提供了从公众调查中获得的数据以及关键文章收集的数据，从可能涉及公众福祉的重要社会和政治数据（网络审查、政府监控、枪支、医疗保健等），到体育等一切内容的分数或民意测验。

Reddit的`/r/datasets`是一个信息共享的好地方。你可以浏览人们发布的有趣的东西，或者在特定的问题上寻求帮助。甚至还有一些很好的元信息，比如有人发布了一个详尽的每个开放数据门户的列表。当你浏览Reddit的时候，`/r/MachineLearning`也是一个好选择。

![](images/fbeba59b-5e98-482e-8e8d-c5bc6f84ca43.png)有时，随机发烧友也会真正为你服务。作者个人最喜欢的网站是Jonathan’s Space Home Page，其中一位来自哈佛大学史密森天体物理学中心的天体物理学家，在网站上保存着发射到太空的所有物体的广泛列表。只是作为附带项目，太奇妙了。

稍微不寻常的数据的另一个重要来源是整数数列在线大全(OEIS)，它是各种数字数列及其附加信息（例如图或用于生成数列的公式）的庞大集合。因此，如果你对卡塔兰数感到好奇或想了解忙碌的海狸问题，OEIS帮你排序了。

还有无数的网站致力于成为诸如开放政府、重要研究出版物中使用的学术数据等领域数据集的中央注册中心。

这或许说明了这一点：数据无处不在。我们每时每刻都在创造更多的东西，而且很多人和组织都致力于让这对我们所有人都有用。个人对数据源的喜好是靠时间和经验建立起来的，因此要广泛地进行探索和实验。

### 3.2.2 寻找什么

在开始搜索之前要有一个清晰的计划，知道你需要什么来对你要解决的问题建模。在要包括的潜在数据中，考虑以下因素：

• 数据中显示的值及其类型。
