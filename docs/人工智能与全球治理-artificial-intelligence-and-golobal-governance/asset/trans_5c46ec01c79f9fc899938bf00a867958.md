# 人工智能与网络安全

刘杨钺 王智勇[^(\[1\])](#chapter006.html#m1)

**摘要：**人工智能正日益成为影响网络安全态势发展的重要变量之一。人工智能相关技术在关键数据提取、智能分析决策、自动响应控制等方面不断取得进展，对网络空间安全互动的样式特点产生着深刻影响。本文从智能化算法在网络安全中的应用、人工智能对网络攻防对抗的影响、人工智能时代的网络空间威慑等方面分析了人工智能技术进步给网络安全带来的新问题、新挑战，并对如何辩证地看待人工智能的影响提出了思考。

**关键词：**人工智能 网络安全 网络空间威慑

自1956年在美国达特茅斯会议上“人工智能”概念问世后，人工智能技术历经六十多年发展，已成为时下最热门的颠覆性技术之一。在网络空间，人工智能的快速发展与应用给网络安全带来了新的变量。人工智能技术在关键数据提取、智能分析决策、自动响应控制等方面具有显著优势，从而与网络空间安全形成某种天然联系。美国消费者技术协会2019年4月公布的全球人工智能技术应用调查数据显示，网络安全领域内的人工智能应用频次遥遥领先于其他领域。用于网络安全入侵检测和防范的应用程序中，包含人工智能技术的应用占比高达44%。[^(\[2\])](#chapter006.html#m2)随着人工智能应用的加速发展，人工智能技术将对网络安全各领域产生持续性影响。

网络安全是指网络系统整体保持持续可靠运行状态，能为外界请求提供正常网络服务。系统内硬件、软件以及各项数据信息在物理空间和网络空间均处于受保护状态，避免遭受无授权更改、删除、泄露、破坏等行为。网络系统各项操作具有保密性、完整性、可用性、可控性、可审查性等特性。[^(\[3\])](#chapter006.html#m3)作为自互联网诞生时便与之俱来的传统信息产业，当今网络安全领域边界不断模糊，威胁逐渐泛化。网络安全与人工智能技术的联系愈加紧密，在人工智能时代呈现出许多新特点。究其本源，人工智能实质是实现“能以人类同样方式思考和行动”的计算机程序。[^(\[4\])](#chapter006.html#m4)网络安全是攻击方与防御方的博弈对抗。智能化的网络安全技术旨在将机器学习、深度学习、专家系统、自然语言处理、模式识别等人工智能技术应用于网络安全博弈对抗的各个环节。

人工智能与网络信息技术的耦合有其内在必然性。在软件漏洞挖掘、流量实时监控、入侵检测系统、恶意代码识别、智能防火墙等网络安全领域，蓬勃发展的人工智能技术表现出许多突出的“过人之处”。例如，在软件漏洞挖掘方面，将以往漏洞数据作为先验知识，训练人工智能自主学习模型可以提高漏洞挖掘准确率；通过对恶意程序的底层数据包数量、数据包头信息、接口调用序列、CPU占用率等关键特征信息进行自动检测，可以将恶意代码请求与正常程序请求加以区别，从而更好地识别恶意代码来源；采用人工智能技术的入侵检测系统能够有效节省人工成本、简化检测流程、降低未知风险，大大提高外部异常入侵行为判定响应的自动化、智能化程度。[^(\[5\])](#chapter006.html#m5)对比传统网络安全应对方式，人工智能技术改变了依赖安全人员手动提取数据特征、人工硬编码定义信息的低效模式。利用数据训练、特征提取、分类判定、自动响应等智能化模式为传统网络安全应对方式加码赋能，相互搭配高效完成相关网络安全任务。[^(\[6\])](#chapter006.html#m6)

## 一 算法成为人工智能时代网络安全的关键环节

算法是解决问题的一系列步骤，代表着用系统的方法描述解决问题的策略机制，其核心是创建抽象的问题模型和明确求解目标，之后可以根据具体的问题选择不同的模式和方法完成算法的设计。[^(\[7\])](#chapter006.html#m7)高效的人工智能算法与大规模的数据集、强大的计算能力共同构成了优秀人工智能技术的基础。这类能被用户广泛采用接纳的自主学习方法，是使各种场景下人工智能应用更加符合现实情况的关键因素。现阶段人工智能技术发展的主流是以深度学习为代表的各类人工智能算法的精进，通过改进算法力求实现快速精确计算，进而得到想要的结果。伴随着人工智能技术全面应用于网络安全各领域，有高性能算法的助力才能让安全人员从容应对并解决各类智能时代网络安全难题。

在军事领域，人工智能军事应用是实现智能决策、指挥和协同的关键因素以及智能化军事建设的制高点。人工智能算法在军事领域的应用主要表现为获取战场信息、预测战争走势、完成作战任务、提高装备性能等关键指标的计算机指令代码，在各类智能化军事应用相关底层设计中扮演着为各类装备系统注入“战争技术生命力”的关键角色。军事网络安全防务方面智能化程度的提高，则主要依靠人工智能算法的保障。控制和频谱分配系统的干扰协调算法，保证了在复杂电磁环境下各武器系统的频谱自主调配，提高了战场电磁频谱网络管理能力；大规模无人机集群内部网络利用蜂群算法实现规划航迹、避免碰撞、协同作战，提高了无人机网络的承载能力；军事网络安全应急响应系统底层的免疫算法，将人体免疫原理与网络完整性识别检测相结合，实现网络入侵快速检测并进行实时决策响应。智能化军事建设逐渐进入“快进”模式后，随之而来的便是算法在网络安全中军事效用的极致体现。[^(\[8\])](#chapter006.html#m8)尽管高性能人工智能算法足以给军事网络安全领域带来巨大优势，但其本身的特有属性以及潜在风险的影响同样无法忽视。

现代战争环境中，人工智能应用遍布陆、海、空、天、电各个战场空间，贯穿战略、战役、战术、战斗各个层次，通过大大小小各类网络进行连接。保证网络内各环节使用的算法不受内外部因素干扰、持续正常高效运行，才能有效支撑各类智能化军事应用在现实战争环境中实现预期功能。

如果在实际运用中意外选用了错误函数或偏差模型，算法在面对新情境的数据集时可能会出现与预期不符的结果，进而造成严重后果。攻击方利用对抗样本攻击也能导致算法错判漏判，以此“混淆视听”达到恶意攻击的目的。军用武器装备、训练平台、传感网络等系统在设计之初并非人工智能产品，当前的智能化军事建设主要是为各系统添加新功能而非改变主要功能。单兵作战系统等个体装备一旦组网运行，其内部算法等控制体系往往是攻击者的首要目标。“震网”病毒能够对离心机系统产生巨大破坏作用，这在一定程度上反映出工业控制系统中的原有算法，在面对可自主适应环境并调整行为模式的新型算法时的无能为力。[^(\[9\])](#chapter006.html#m9)

非战争环境下，很难收集到真实有效的大数据集充当样本。军事网络防火墙这类应用在训练数据十分有限时，必然无法充分发挥相关算法的军事效能。在复杂多变的战场环境中，同样很难保证算法模型与训练场景持续强相关，算法模型内部易出现漏洞，难以达到理想效果。功能/漏洞悖论是人工智能算法固有的特性，其功能容易受到其运行所需的大量数据输入源的攻击以及使用环境的影响，进而受到欺骗、降级或出现其他形式的颠覆。

除此之外，人工智能算法的“黑盒”性质在某些方面与军事应用要求的透明性严重冲突。有时即使是开发人员也无法详细解析算法行为依据，这显然不利于军事决策者进行详尽的战场风险分析。随着搭载人工智能算法的各类实体在战场上随处可见，算法产生的功能和过程都将在指挥官和作战人员没有注意的情况下发生。类似于蜂窝服务、智能设备功能等网络操作，使用算法功能本身不需要专门的开/关按钮，但当其失效停止运转而无法提供常规支撑保障时，人们才会恍然自觉对其依赖程度之深。在当前快速技术变革所定义的复杂安全环境下的多维安全领域中，军事网络中人工智能算法的持续、稳定、高效运行依旧面临各种未知考验。[^(\[10\])](#chapter006.html#m10)

综上所述，伴随着信息技术获取、大数据挖掘、超算能力、人工智能等新兴技术在军事领域的飞速发展和大规模使用，作为底层工具的算法技术也必将成为改变战争游戏规则的基础性、关键性、颠覆性技术。但正如已故物理学家霍金担忧人工智能的崛起可能带来人类文明的终结一样，算法技术同样可能为未来智能化战争埋下不少始料未及的难题。[^(\[11\])](#chapter006.html#m11)

在民用领域，人工智能算法在网络安全方面的应用场景更广、层次更多、参与技术更为复杂。算法渗透影响着民用网络安全的方方面面，呈现出全方位结合的趋势。腾讯基于神经网络算法自主研制的`TRP-AI`反病毒引擎，破除了传统反病毒查杀中人工处理环节过多，安全人员分析能力不敌新型病毒数量、类型快速增长的困局。支持向量算法通过对每条邮件内容的词汇提取、数据处理、降维归一并逐条确定向量值，实现对垃圾邮件的分类检测和拦截。网络威胁态势感知中通常存在大量不完整或噪声数据，利用贝叶斯算法能够对这类数据集进行有效降噪、提纯、过滤等预处理。结合域名生成算法的恶意`URL`（`Uniform Resource Locator`，统一资源定位符）检测模型能够对海量样本与地址库数据进行学习和识别，根据`URL`数据集的静态数据（主机IP、网页信息等）和动态数据（请求服务行为、网址跳转关系等）综合判断得出较高恶意`URL`检出率。人工智能算法应用贯穿民用网络安全中的网络防火墙设置、垃圾邮件拦截、入侵检测、恶意网站识别等重要环节，利用自身优势扮演着举足轻重的角色。[^(\[12\])](#chapter006.html#m12)

复杂网络空间的开放性与双向性也决定了算法同样可能成为网络空间安全的薄弱环节。网络黑客使用高性能算法，同样能够提高恶意脚本的编写效率。网络检测系统的内部算法检测逻辑一旦泄露，攻击者就可以通过插入实时对抗性样本数据等手段实现自动逃避检测。2017年3月一篇题为“基于GAN的黑盒攻击恶意软件对抗样本生成”的论文中，首次提出利用生成性对抗网络（`Generative Adversarial Network`，`GAN`）算法产生恶意黑盒攻击对抗样本。[^(\[13\])](#chapter006.html#m13)仅仅5个月后EndGame黑客服务公司便率先发布了基于`GAN`的入侵程序，通过该程序可以轻易让部分攻击（20%左右）绕过安全检测。基于神经网络算法构建的可扩展智能僵尸网络已经成为`DDoS`攻击的惯用手法之一，其前所未有的攻击规模和能力使网络攻防战场愈加激烈。[^(\[14\])](#chapter006.html#m14)利用系统外部应用程序接口（`Application Program Interface`，`API`）可以对内部算法模型进行逆向攻击，从而反向获取算法训练数据集，拓宽个人数据泄露另类渠道。融合人工智能算法的智能推荐功能可能被犯罪分子用于社会工程学攻击，通过精准用户画像定向投放钓鱼诈骗、暴力色情、蓄意煽动等恶意信息。这种具有针对性的隐蔽攻击的潜在目标人群虽少，但对网络风险甚至国家意识形态安全都有极大的负面影响。[^(\[15\])](#chapter006.html#m15)

总而言之，随着人工智能技术的加速发展，算法在网络安全领域的安全收益和风险呈现螺旋式动态演进的趋势。高性能算法对维护网络安全、促进社会稳定的作用毋庸置疑，但也亟须关注技术漏洞与恶意应用等负面问题。能否辩证地看待网络安全领域中的算法矛盾，进而破除困局建立平衡，将是未来迫切需要解决的主要问题。

## 二 人工智能推动智能化网络攻防对抗

网络空间攻防对抗是安全人员与网络黑客在网络空间进行的角力、博弈，人工智能运用已经成为其中最重要的技术手段之一。全球各类网络在数据信息传递、共享中实现彼此连接融合，创造了适合人工智能技术大显身手的应用场景。IDC国际数据公司2017年的预测报告显示，人工智能及其分支科学领域的市场规模在2020年将达到470亿美元以上。[^(\[16\])](#chapter006.html#m16)国际市场研究机构MarketsandMarkets知识库2018年发布的《人工智能安全市场》研究报告中，预计2025年人工智能在安全市场中的规模将以31.38%的年复合增长率达到348.1亿美元。但与此同时，网络安全中日益增多的人工智能应用也将使网络空间安全互动的可预见性和可控制性大大减弱。
