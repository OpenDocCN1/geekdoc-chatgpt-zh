# 项目六　猜字游戏

![](images/txt006_1.jpg "pagenumber_ebook=55,pagenumber_book=45")

我们拿一枚硬币或者一张扑克牌，向天上一扔，当硬币或者扑克落到地上的时候，会是正面朝上还是背面朝上？两种情况都有可能。像这样无法提前预测的事情，我们称之为“随机事件”。

Python 编程语言为我们提供了一个“随机模块”，名叫 `random`。这个英文单词的意思就是：随机的、任意的、无规律的。`random` 模块可以让我们生成随机的整数、随机的小数、随机的文字等等。通过这些随机生成的数字或者文字，我们就可以编写很多有趣的小游戏。

Python 编程语言本身非常简单，但要学习它那数以万计的常用模块却需要耐心、恒心！很多时候，人们将这些模块看成是“积木”，将 Python 语言看成是“胶水”，胶水的作用，就是将各种各样的积木组合在一起，形成各种各样的应用程序。所以人们为 Python 编程语言取了一个昵称：“胶水语言。”
