## ◎第一节　初识Python
同学们，人工智能（Artificial Intelligence）已经渗透到我们学习、生活、工作的方方面面。如交通导航、语音识别、智能机器人……在人工智能发展道路上，Python编程语言功不可没，我们可以通过它和计算机交流，指挥计算机做各种事情。

学习Python首先要认识“`IDLE`”编辑器。`IDLE`是我们与计算机交流的“翻译官”，可以方便地创建、运行和调试Python程序。

下面，让我们从认识`IDLE`编辑器开始吧！

在安装了Python开发环境的计算机上，点击“开始”菜单，找到`IDLE`（`Python 3.7 64-bit`）并打开它，打开后界面如下：

![](images/txt001_3.jpg "pagenumber_ebook=12,pagenumber_book=2")

图1-1-1　Python 3.7编辑器界面

下面介绍通过`IDLE`编辑器运行Python程序的两种方法。

### 方法一：在IDLE编辑器中运行
1．在图1-1-1的`>>>`后面，输入以下代码：

`print（"你好，代码世界！"）`

小心错误：代码中的括号与引号，要使用英文半角状态下的括号与引号，不能使用英文全角符号以及中文括号与引号。

输入完成后按回车键，观察运行结果。

2．继续在`>>>`后面输入：

`print（"你好，我是锦锦"）`

回车之后，你看到了什么？

![](images/txt001_4.jpg "pagenumber_ebook=13,pagenumber_book=3")

图1-1-2　`IDLE`编辑器

### 方法二：新建项目文件
如图1-1-2所示，`IDLE`可以在“`>>>`”后面输入代码进行测试，但如果要编写多行代码，可以新建一个“项目”进行编写，这样有利于保存我们编写的代码。

新建“项目”步骤如下。

1.点击`IDLE`界面左上角的`File`（文件）按钮，选择`New File`（新建），在编辑区输入：

`print（"大家好，我是某某"）`

2.选择运行（`Run`）菜单下的运行模块（`Run Module`）。根据提示保存项目（注意，要保存到你记得的地方，文件名可以任意。）并查看运行结果。

![](images/txt001_5.jpg "pagenumber_ebook=13,pagenumber_book=3")

图1-1-3　新建项目界面

3.测试完成后，点击窗口右上角的×，即可关闭退出。

上面步骤中，我们编写的代码已被保存到计算机上，如果需要重新打开这个代码文件，可以在`IDLE`编辑器中，点击左上角的`File`（文件）菜单，选择`Open`（打开），找到刚刚保存文件的位置，找到文件并打开它。

**小结：**

`print（）`函数是Python编程中的常用函数，原意是“打印”，在编程中可以将其理解为“输出”。

我们有两种方法编写与测试代码：

1.直接在`IDLE`的`>>>`后面书写代码并执行，多用于代码实时测试。

2.新建“项目”，将代码保存为一个文件，便于保存、修改和重复使用。

特别提醒：代码中的括号或引号，必须使用英文半角括号或引号。
