项目一　认识可爱的蟒蛇：Python

◎第一节　初识Python

同学们，人工智能（Artificial Intelligence）已经渗透到我们学习、生活、工作的方方面面。如交通导航、语音识别、智能机器人……在人工智能发展道路上，Python编程语言功不可没，我们可以通过它和计算机交流，指挥计算机做各种事情。

学习Python首先要认识“IDLE”编辑器。IDLE是我们与计算机交流的“翻译官”，可以方便地创建、运行和调试Python程序。

下面，让我们从认识IDLE编辑器开始吧！

在安装了Python开发环境的计算机上，点击“开始”菜单，找到IDLE（Python 3.7 64-bit）并打开它，打开后界面如下：

图1-1-1　Python 3.7编辑器界面

下面介绍通过IDLE编辑器运行Python程序的两种方法。

方法一：在IDLE编辑器中运行

1．在图1-1-1的">>>"后面，输入以下代码：

print（"你好，代码世界！"）

小心错误：代码中的括号与引号，要使用英文半角状态下的括号与引号，不能使用英文全角符号以及中文括号与引号。

输入完成后按回车键，观察运行结果。

2．继续在">>>"后面输入：

print（"你好，我是锦锦"）

回车之后，你看到了什么？

图1-1-2　IDLE编辑器

方法二：新建项目文件

如图1-1-2所示，IDLE可以在“>>>”后面输入代码进行测试，但如果要编写多行代码，可以新建一个“项目”进行编写，这样有利于保存我们编写的代码。

新建“项目”步骤如下。

1.点击IDLE界面左上角的File（文件）按钮，选择New File（新建），在编辑区输入：

print（"大家好，我是某某"）

2.选择运行（Run）菜单下的运行模块（Run Module）。根据提示保存项目（注意，要保存到你记得的地方，文件名可以任意。）并查看运行结果。

图1-1-3　新建项目界面

3.测试完成后，点击窗口右上角的×，即可关闭退出。

上面步骤中，我们编写的代码已被保存到计算机上，如果需要重新打开这个代码文件，可以在IDLE编辑器中，点击左上角的File（文件）菜单，选择Open（打开），找到刚刚保存文件的位置，找到文件并打开它。

小结：

print（）函数是Python编程中的常用函数，原意是“打印”，在编程中可以将其理解为“输出”。

我们有两种方法编写与测试代码：

1.直接在IDLE的>>>后面书写代码并执行，多用于代码实时测试。

2.新建“项目”，将代码保存为一个文件，便于保存、修改和重复使用。

特别提醒：代码中的括号或引号，必须使用英文半角括号或引号。

项目二　用Python语言与计算机对话

江江、锦锦，你们俩正在“对话”。

江江向锦锦提出问题，锦锦收到问题做了回答，并向江江也提出了一个问题。江江收到锦锦提出的问题，也做了回答。

我们与计算机之间的交流，本质上就是“对话”。比如用鼠标点击某个按钮，计算机收到操作指令后，会弹出某个窗口或界面，这就是对我们的“回答”。我们收到回答，就可以进行下一步操作。下一步的操作，可以看成是我们再次向计算机发出指令。整个过程，都是人与计算机的“对话”。

我们可以使用键盘或鼠标向计算机发出指令与计算机“对话”，也可以使用Python语言与计算机“对话”。

Python编程语言为我们提供了一个“随机模块”，名叫“random”。这个英文单词的意思就是：随机的、任意的、无规律的。random模块可以让我们生成随机的整数、随机的小数、随机的文字等等。通过这些随机生成的数字或者文字，我们就可以编写很多有趣的小游戏。

Python编程语言本身非常简单，但要学习它那数以万计的常用模块却需要耐心、恒心！很多时候，人们将这些模块看成是“积木”，将Python语言看成是“胶水”，胶水的作用，就是将各种各样的积木组合在一起，形成各种各样的应用程序。所以人们为Python编程语言取了一个昵称：“胶水语言。”
