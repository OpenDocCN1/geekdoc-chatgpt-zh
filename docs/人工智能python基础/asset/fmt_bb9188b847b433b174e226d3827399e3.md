### 活动二：使用 exec() 函数

在`Python`语言中，我们可以将写好的一段代码指定为一个字符串，使用的时候可以直接调用这个字符串对应的变量名，这样可以有效提高代码的逻辑性。

![](images/txt007_13.jpg "pagenumber_ebook=73,pagenumber_book=63")

在项目三的图3-1-1中，我们演示了如何使用三引号定义多行字符串。三引号的一个特点，是可以定义带“分段”的文本为字符串。在这里，我们可以将“猜数游戏”中的块④，用三引号定义成变量`游戏`；块⑤，用三引号定义成变量`评价`，如果用户选择继续玩，就用`exec()`函数调用`游戏`和`评价`。这样写，程序的逻辑会更清楚、更易读。

小结：
本节课我学会了：
1. `exec()`函数的格式是：`exec(变量名)`；
2. `exec()`函数的作用是运行括号中的变量。而这个变量的内容，其实是一段被定义成字符串的代码。

使用`exec()`函数，我们可以将代码写为一块儿、一块儿的字符串，然后使用`exec()`函数来调用并执行字符串变量。这些“块儿”如同积木，而`exec()`函数，是拼接积木的关键。在代码的行数较多的时候，用这种方法来理清程序的逻辑非常有效。
