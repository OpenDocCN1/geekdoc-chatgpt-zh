```
# 最大旋转速度
# 它应该小于最大的可能值，这样才能使转向更自然流畅
maxRotation: float
function getSteering() -> KinematicSteeringOutput:
result = new KinematicSteeringOutput()
# 从方向的向量形式获取速度
result.velocity = maxSpeed * character.orientation.asVector()
# 随机改变方向
result.rotation = randomBinomial() * maxRotation
return result
```
