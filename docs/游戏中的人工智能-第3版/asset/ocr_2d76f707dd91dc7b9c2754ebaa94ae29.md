# 1. 伪代码

回溯算法的伪代码如下：

```
function maze(level: Level, start: Location):
  # 可以产生分支的位置的堆栈
  locations = [start]
  level.startAt(start)

  while locations:
    current = locations.top()

    # 尝试连接到邻近的位置
    next = level.makeConnection(current)
    if next:
      # 如果成功，则使用它执行下一次迭代
      locations.push(next)
    else:
      locations.pop()
```

# 2. 数据结构

构建迷宫的环境具有以下结构：

```
class Level:
  function startAt(location: Location)
  function makeConnection(location: Location) -> Location
```

它可以实现为：

```
class Location:
  x: int
  y: int

class Connections:
  inMaze: bool = false
  directions: bool[4] = [false, false, false, false]

class GridLevel:
  # dx、dy 和索引都纳入 Connections.directions 数组
  NEIGHBORS = [(1, 0, 0), (0, 1, 1), (0, -1, 2), (-1, 0, 3)]

  width: int
```
