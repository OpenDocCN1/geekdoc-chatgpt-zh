```
# 遍历每一个行为
for behavior in behaviors:
    # 如果已经到期，则调度它
    if behavior.frequency % (frame + behavior.phase):
        runThese.append(behavior)
        totalPriority += behavior.priority

# 保存当前时间记录
currentTime: int = time()

# 遍历要运行的行为
numToRun: int = runThese.length()
for i in 0..numToRun:
    # 找到上一次迭代所用的时间
    lastTime = currentTime
    currentTime = time()
    timeUsed = currentTime - lastTime

# 基于优先级将剩余的时间分布给余下的行为
timeToRun -= timeUsed
availableTime =
    timeToRun * behavior.priority / totalPriority

# 运行行为
runThese[i].thingToRun(availableTime)
```

# 2. 性能

该算法与负载均衡调度程序具有相同的性能特征：在时间中为 O(n)，在内存中为 O(m)，不包括调度行为为使用的处理时间和内存。
