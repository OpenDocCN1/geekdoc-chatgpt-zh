```
class DirectAccessFrequencyScheduler:
    # 保存行为集的数据
    # 该行为集具有一个频率
    class BehaviorSet:
        functionLists: function[]
        frequency: int
    # 保存多个行为集，每个频率需要一个集合
    sets: BehaviorSet[]
    # 保存当前帧编号
    frame: int
    # 添加行为到列表中
    function addBehavior(func: function, frequency: int, phase: int):
        # 找到当前集合
        set: BehaviorSet = sets[frequency]
        # 添加函数到列表
        set.functionLists[phase] += func
    # 每帧调用一次
    function run():
        # 递增帧编号
        frame += 1
        # 遍历每个频率集合
        for set in sets:
            # 计算该频率的阶段
            phase: int = set.frequency % frame
            # 运行数组中
            # 恰当位置的行为
            for func in functionLists[phase]:
                func()
```

# 1）数据结构和接口

set 的数据成员包含 BehaviorSet 的实例。在最初的实现中，我们使用了 for...in...操作以任何顺序获取集合的元素。在此实现中，开发人员还可以使用 set 作为哈希表，通过其频率值查找条目。
