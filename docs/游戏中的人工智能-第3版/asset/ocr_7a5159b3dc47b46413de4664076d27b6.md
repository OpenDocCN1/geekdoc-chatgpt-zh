如果当前没有正在执行的动作（它们都已完成），则将最高优先级动作移出队列到活动集中。然后，如果可以同时执行，则管理器添加下一个最高优先级动作，以此类推，直到不再向当前活动集添加动作为止。

# 5.10.3 伪代码

动作管理器的实现如下：

```
class ActionManager:
    # 保存挂起动作的队列
    queue: Action[]
    # 当前正在执行的动作
    active: Action[]
    # 添加一个动作到队列中
    function scheduleAction(action: Action):
        # 将它添加到队列
        queue += action
    # 处理管理器
    function execute():
        currentTime = getTime()
        priorityCutoff = active.getHighestPriority()
        # 删除队列中已过期的动作
        for action in copy(queue):
            if action.expiryTime < currentTime:
                queue -= action
        # 遍历队列
        for action in copy(queue):
            # 如果优先级低于活动动作的优先级，则放弃
            if action.priority <= priorityCutoff:
                break
            # 如果有一个中断器，则执行
            if action.interrupt():
                queue -= action
        # 现在在中断器是唯一活动的
```
