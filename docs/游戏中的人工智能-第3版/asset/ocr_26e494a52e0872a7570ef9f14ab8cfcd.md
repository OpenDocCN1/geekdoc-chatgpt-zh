# 5.3.7 硬编码的 FSM

几年前，几乎所有的状态机都是硬编码的。转换规则和动作的执行是游戏代码的一部分。随着关卡设计师对构建状态机逻辑的更多控制，它变得不那么常见，但仍然是一种重要的方法。

# 1. 伪代码
