```
result.orientation /= numberOfAssignments
return result
# 计算槽位的位置
function getSlotLocation(slotNumber: int) -> Static:
# 基于槽位的数量，围绕圆圈放置槽位
angleAroundCircle = slotNumber / numberOfSlots * pi * 2
# 其半径将取决于角色的半径
# 以及圆圈中角色的数量
# 我们要让角色肩并肩，中间无缝隙
radius = characterRadius / sin(pi / numberOfSlots)
result = new Static()
result.position.x = radius * cos(angleAroundCircle)
result.position.z = radius * sin(angleAroundCircle)
# 角色应该面朝外
result.orientation = angleAroundCircle
return result
# 确认可以支持任意数量的槽位
function supportsSlots(slotCount) -> bool:
return true
```

如果开发人员已经知道（在上一个伪代码中给出的）使用中的分配算法，那么就可以知道：槽位的数量将与分配的数量相同（因为角色按顺序被分配给连续的槽位）。在这种情况下，calculateNumberOfSlots 方法可以简化：

```
function calculateNumberOfSlots(assignments) -> int:
    return assignments.length()
```

一般来说，如果使用的是更实用的分配算法，则情况可能并非如此，因此，虽然上面的长形式在所有情况下均可使用，但性能则会有所降低。

# 3.7.6 扩展到两个以上的级别

两级转向系统可以扩展到更多的层级，从而能够创建编队的阵型。这在拥有大量单位的军事模拟游戏中变得越来越重要。事实上，真正的军队也是以这种方式组织起来的。
