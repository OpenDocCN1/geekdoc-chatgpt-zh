若干个步骤之后，随机范围可能是±1，在这种情况下，第一个邻居绝无可能被选择。另一方面，在退火开始时，随机范围可能是±100，这样第一个邻居被选择的机会则很大。

# 1) 仿代码

开发人员可以将退火技术直接应用于之前的爬山算法。值得注意的是，optimizeParameters 函数将由 annealParameters 代替。

```
function annealParameters(parameters: float[], func, temp) -> float[]:
# 到目前为止的最佳参数修改
bestParameterIndex: int = -1
bestTweak: float = 0
# 最初的最佳值就是当前参数的值
# 没有必要改为更糟糕的集合
bestValue: float = func(parameters)
# 循环遍历每个参数
for i in 0..parameters.size():
# 存储当前参数值
currentParameter: float = parameters[i].value
# 从向上和向下两个方向进行调整
for tweak in in [-STEP, STEP]:
# 应用该调整
parameters[i].value += tweak
# 获得函数的值
value = func(parameters[i]) + randomBinomial() * temp
# 检查该值是否为最佳
# (请注意，现在是下坡算法)
if value < bestValue:
# 如果是最佳，则存储该值
bestValue = value
bestParameterIndex = i
bestTweak = tweak
# 重置参数到它以前的值
parameters[i].value = currentParameter
# 已经遍历完成每一个参数
# 检查是否已经找到一个最好的集合
```
