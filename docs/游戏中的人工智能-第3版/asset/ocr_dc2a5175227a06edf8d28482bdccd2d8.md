欧几里得距离只有两种可能：要么非常准确，要么低估。在墙壁或障碍物周围行进只能增加额外的距离。如果没有这样的障碍物，则启发式算法是准确的；否则，它就是低估的。

室外环境对移动的限制很少，欧几里得距离可以非常准确并提供快速路径发现。但是，在室内环境中，如图 4.17 所示，它可能会出现比较明显的低估算法，导致不太理想的路径发现。
