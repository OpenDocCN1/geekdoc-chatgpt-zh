```
# 获取目标的方向
direction = target.position - character.position
distance = direction.length()

# 如果已经到达，则不转向
if distance < targetRadius:
    return null

# 如果在 slowRadius 半径之外，则加速至最大速度
if distance > slowRadius:
    targetSpeed = maxSpeed
# 否则按比例计算速度
else:
    targetSpeed = maxSpeed * distance / slowRadius

# 目标速度将组合速率和方向
targetVelocity = direction
targetVelocity.normalize()
targetVelocity *= targetSpeed

# 加速以尝试达到目标速度
result.linear = targetVelocity - character.velocity
result.linear /= timeToTarget

# 检查加速是否太快
if result.linear.length() > maxAcceleration:
    result.linear.normalize()
    result.linear *= maxAcceleration

result.angular = 0
return result
```

# ## 2. 性能

与前面一样，算法在时间和内存上的性能都是 O(1)。

# ## 3. 实现说明

许多实现都不使用目标半径。因为角色会减速到达目标，所以它出现振荡的可能性和我们在运动学到达算法中看到的不一样。删除目标半径通常没有明显的区别。当然，如果帧速率较低或角色具有很高的速度而加速度很低，那么删除目标半径的区别还是很大的。一般来说，更好的做法是在任何目标周围给出误差范围，以避免恼人的不稳定性。
