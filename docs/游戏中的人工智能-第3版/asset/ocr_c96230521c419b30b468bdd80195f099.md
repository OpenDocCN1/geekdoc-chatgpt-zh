```
# 查找路径上的当前位置
currentParam = path.getParam(character.position, currentPos)
# 添加偏移量
targetParam = currentParam + pathOffset
# 获取目标位置
target.position = path.getPosition(targetParam)
# 2.委托给寻找行为
return Seek.getSteering()
```

开发人员也可以将此算法转换为预测性的版本，即先为 path.getParam 调用计算出一个未来位置。以下算法看起来几乎是一样的：

```
class FollowPath extends Seek:
    path: Path
    # 沿着路径以生成目标的距离
    # 如果角色沿着反方向移动，则该距离值可以是负数
    pathOffset: float
    # 路径的当前位置
    currentParam: float
    # 用来预测角色位置的预期时间
    predictTime: float = 0.1
    # ... 其他数据均从超类派生 ...
    function getSteering() -> SteeringOutput:
        # 1. 计算目标以委托给朝向行为
        # 查找预测的位置
        futurePos = character.position +
                    character.velocity * predictTime
        # 查找路径上的当前位置
        currentParam = path.getParam(futurePos, currentPos)
        # 添加偏移量
        targetParam = currentParam + pathOffset
```
