# 1）伪代码

可以通过以下方式实现玻尔兹曼（Boltzmann）优化步骤：

```
function boltzmannAnnealParameters(parameters, func, temp):
    # 存储初始值
    initialValue = func(parameters)
    # 循环遍历每一个参数
    for i in 0..parameters.size():
        # 存储当前参数值
        currentParameter = parameters[i].value
        # 从向上和向下两个方向进行调整
        for tweak in [-STEP, STEP]:
            # 应用该调整
            parameters[i].value += tweak
            # 获得函数的值
            value = func(parameters[i])
            # 检查该值是否为最佳
            if value < initialValue:
                # 返回该参数
                return parameters
            # 否则，检查是否应该无论如何都这样做
            else:
                # 计算获得的能量和系数
                energyGain = value - initialValue
                boltzmannCoeff = exp(-energyGain / temp)
                # 随机决定是否接受它
                if random() < boltzmannCoeff:
                    # 使用该修改，并返回它
                    return parameters
            # 重置参数到它以前的值
            parameters[i].value = currentParameter
    # 没有发现更好的参数，返回最开始的参数
    return parameters
```
