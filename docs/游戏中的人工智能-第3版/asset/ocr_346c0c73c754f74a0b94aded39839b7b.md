爬山算法是一种非常简单的参数优化技术。它运行速度快，通常可以产生非常好的效果。

# 1. 伪代码

使用以下实现可以运行算法的其中一个步骤：

```
function optimizeParameters(parameters: float[], func) -> float[]:
    # 到目前为止的最佳参数修改
    bestParameterIndex: int = -1
    bestTweak: float = 0

    # 最初的最佳值就是当前参数的值
    # 没有必要改为更糟糕的集合
    bestValue: float = func(parameters)

    # 循环遍历每个参数
    for i in 0..parameters.size():
        # 存储当前参数值
        currentParameter: float = parameters[i].value

        # 从向上和向下两个方向进行调整
        for tweak in [-STEP, STEP]:
            # 应用该调整
            parameters[i].value += tweak

            # 获得函数的值
            value: float = func(parameters[i])

            # 检查该值是否为最佳
            if value > bestValue:
                # 如果是最佳，则存储该值
                bestValue = value
                bestParameterIndex = i
                bestTweak = tweak

        # 重置参数到它以前的值
        parameters[i].value = currentParameter

    # 已经遍历完成每一个参数
    # 检查是否已经找到一个最好的集合
    if bestParameterIndex >= 0:
        # 如果已经找到，则永久改变参数
        parameters[bestParameterIndex] += bestTweak
```
