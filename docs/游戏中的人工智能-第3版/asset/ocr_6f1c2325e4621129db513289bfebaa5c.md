```
# 遍历状态中的每个转换
for transition in currentState.getTransitions():
    # 检查是否触发转换
    if transition.isTriggered():
        # 获取该转换的转换程度
        dot = transition.getDot()
        # 移动到所有目标状态中
        for endState in transition.getTargetStates():
            # 更新隶属程度
            end = currentStates.get(endState)
            end.dom = max(end.dom, min(state.dom, dot))
            # 检查该状态是否是新的
            if end.dom > 0 and not end in currentStates:
                currentStates.append(end)
        # 删除起始状态的隶属程度
        state.dom = min(state.dom, 1 - dot)
        # 检查是否需要删除起始状态
        if state.dom <= 0.0:
            currentStates.remove(state)
        # 对于该活动状态
        # 不需要查看其任何其他转换
        break
```

# 4. 数据结构和接口

currentStates 成员是 StateAndDom 实例的列表。除了正常的列表式操作（即迭代、删除元素、隶属关系测试、添加元素），它还支持此算法的两个特定操作。

sortByDecreasingDOM 方法返回按隶属程度值递减顺序排序的列表副本。它不会复制列表中的任何 StateAndDom 实例。这里之所以需要一个副本，是因为在迭代其内容时会对原始内容进行更改，这可能会导致出现问题或无限循环（尽管此算法本身不会导致无限循环），因此，应该保持良好的编程习惯来避免该问题。
