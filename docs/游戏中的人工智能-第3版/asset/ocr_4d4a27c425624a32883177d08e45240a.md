| 数据类型 | 决策 |
| :--- | :--- |
| 布尔值 | 值为 true |
| 权举值（即一组值中只有一个是可允许的） | 匹配一组给定值中的一个 |
| 数值（整数或浮点数） | 值在给定范围内 |
| 3D 向量 | 向量具有给定范围内的长度（例如，这可用于检查角色与敌人之间的距离） |

除原始类型外，在面向对象的游戏引擎中，通常允许决策树访问实例的方法。这允许决策树将更复杂的处理委托给优化的和已编译的代码，同时仍然将表 5.1 中的简单决策应用于返回值。
