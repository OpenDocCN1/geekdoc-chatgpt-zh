的情况下，目标将到达的位置。然后使用该新位置作为标准寻找行为的目标。

如果角色移动缓慢，或目标距离很远，那么预测时间可能会非常长。目标不太可能永远遵循相同的路径，因此我们可以适当限制自己的提前量。有鉴于此，该算法具有最大时间参数。如果预测时间超出此范围，则使用最大时间。

```
class Pursue extends Seek:
    # 最大预测时间
    maxPrediction: float

    # 请注意覆盖寻找算法中的目标数据
    # 换句话说，该类有两个数据位调用目标：
    # Seek.target 是超类目标，并且
    # 它将是自动计算的，不需要手动设置
    # Pursue.target 则是要追逐的目标
    target: Kinematic
```
