```
# 如果找到更好的集合则返回已修改的参数
# 否则，返回最开始的参数
return parameters
```

optimizeParameters 函数中的 STEP 常量决定了可以进行的每一次调整的大小。开发人员可以用数组替换它，如果参数需要不同的步长，则每个参数使用一个值。然后可以连续多次调用 optimizeParameters 函数以给出爬山算法。在每次迭代时，给出的参数是上一次调用 optimizeParameters 的结果。

```
function hillClimb(initial: float[], steps: int, func) -> float[]:
    # 设置初始参数
    parameters: float[] = initial

    # 找到初始参数最开始的值
    value: float = func(parameters)

    # 遍历一系列的步骤
    for i in 0..steps:
        # 获取新参数设置
        newParameters: float[] = optimizeParameters(parameters, func)

        # 获取新的值
        newValue: float = func(newParameters)

        # 如果不能改进，则结束
        if newValue <= value:
            break

        # 存储下一次迭代的新值
        value = newValue
        parameters = newParameters

    # 已经遍历完所有步骤，或者无法改进则返回参数
    return parameters
```
