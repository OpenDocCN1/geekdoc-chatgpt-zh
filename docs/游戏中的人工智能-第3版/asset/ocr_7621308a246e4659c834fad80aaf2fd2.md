# 2. 上下文敏感度

静态评估函数一词中的“静态”是指该函数对于相同的棋盘局面（位置）应返回相同的值。但是，这并不意味着相同的评估代码每次都以相同的方式运行。特别是当评估函数结合了更简单的函数时，这些组成部分的重要性会根据游戏中的发展程度而改变。
