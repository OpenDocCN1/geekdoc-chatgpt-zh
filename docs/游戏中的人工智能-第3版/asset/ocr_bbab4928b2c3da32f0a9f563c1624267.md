一个简单且非常常见的装饰器（它们有时被称为“过滤器”）类别决策是，装饰器是否允许其子项行为运行。如果它们允许子项行为运行，那么返回的任何状态代码都将用作过滤器的结果；如果它们不允许子项行为运行，那么它们通常会返回失败，由此选择器可以选择其他动作。

有几种标准过滤器很有用。例如，我们可以限制任务运行的次数：

```
class Limit extends Decorator:
    runLimit: int
    runSoFar: int = 0

    function run() -> bool:
        if runSoFar >= runLimit:
            return false
        runSoFar++
        return child.run()
```

这可以用来确保角色不会继续试图撞开玩家已经加强过的房门。

我们可以使用装饰器继续运行任务，直到它失败：

```
class UntilFail extends Decorator:
    function run() -> bool:
        while true:
            result: bool = child.run()
            if not result:
                break
        return true
```
