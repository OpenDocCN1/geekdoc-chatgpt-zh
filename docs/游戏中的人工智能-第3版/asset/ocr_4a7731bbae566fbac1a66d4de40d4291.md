class Rule2a:
    function matches(branch: Branch) -> bool:
        return true

    function rhs(branch: Branch) -> Branch[]:
        a = new Branch(
            branch.end(),
            branch.orientation - 45 * deg,
            branch.length * 2 / 3)
        b = new Branch(
            branch.end(),
            branch.orientation + 45 * deg,
            branch.length * 2 / 3)
        return [a, b]

class Rule2b:

当分支变得太小时应该终止，该规则的实现如下:

```
```cpp
class Rule3:
    function matches(branch: Branch) -> bool:
        return branch.length < 0.1

    function rhs(branch: Branch) -> Branch[]:
        return []
```
