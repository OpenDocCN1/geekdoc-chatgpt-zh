将实际终止代码放在 terminate 方法中。

使用合适的线程处理应用程序编程接口（Application Programming Interface，API），我们的并行任务如下：

```
class Parallel extends Task:
    children: Task[]

    # 保存当前运行的所有子任务
    runningChildren: Task[] = []

    # 保存运行方法的最终结果
    result: bool

    function run() -> bool:
        result = null

        # 内部函数，在 run 方法的本地定义
        function runChild(child):
            runningChildren += child
            returned = child.run()
            runningChildren -= child

            if returned == false:
                # 写入外部结果变量
                result = false

                # 停止所有正在运行的子任务
                terminate()

        else if runningChildren.length == 0:
            result = true

    function terminate():
        for child in runningChildren:
            child.terminate()
```
