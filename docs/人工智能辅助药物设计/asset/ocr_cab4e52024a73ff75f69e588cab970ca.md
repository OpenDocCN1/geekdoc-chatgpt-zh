# 10.2.5 配置PyCharm

安装较新的Python版本和PyCharm后，你就可以编写并运行自己的第一个Python程序了。这样做之前，需要配置PyCharm，确保它使用系统中正确的Python版本。之后，你就可以编写并运行程序了。

(1) 打开软件，依次单击菜单栏File→Settings，如图10-12所示，在弹出的Settings窗口中选择Project Project1→Python Interpreter，如图10-13所示。
