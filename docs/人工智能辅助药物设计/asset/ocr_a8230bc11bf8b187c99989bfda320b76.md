# 16.2.2 寃药设计

将两种药效基团之间通过共价键结合而连接起来的制剂称为 寃药。寃药不仅是先导化合物优化设计的一种方式，还是一种典型的新药设计方式。利用相结合生成寃药，如果寃药可以在体内裂解为原本的两种药物，则能够改变药学和药物代谢的动力学特性；如果寃药在体内并不裂解，但是以整个分子结构起作用，则能够产生完全不同的药理效应。

寃药的种类有两种，即相同寃药和相异寃药，拼合生产寃药的方式可以通过各种各样的连接基团连接，以调节两个药用作用团的空间距离。两个原子之间也可以不通过连接基团就直接相连，甚至经重叠成某种结构而键合。相同寃药指的是将两个相同基团或分子连接在一起的寃药。同生型寃药是在一个原子内，将很多个相同的元素或片段通过共价键结合而产生的新分子，主要目的是获得比单分子或单体药物拥有更高活性和选择性的药物。相异寃药是将两个不同基团或分子连接在一起的寃药。通过共价键将多个不同的分子或片段结合起来以形成新分子，当由多种酶或受体作介导的疾病存在时，这种异生型寃药能够同时刺激多个靶点，进而提高药物的疗效。
