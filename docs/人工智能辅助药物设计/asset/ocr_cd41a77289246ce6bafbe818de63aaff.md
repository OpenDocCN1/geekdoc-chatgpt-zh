(2) 安装。打开下载后的软件，按照步骤进行安装。在图10-2中单击Next按钮；在弹出的Select Installation Type对话框中选中All Users单选按钮，单击Next按钮，如图10-3所示；在弹出的Choose Install Location对话框中选择安装路径（可以选择C盘以外的分区），单击Next按钮，如图10-4所示；在弹出的Advanced Installation Options对话框中选中Register Anaconda as the system Python 3.7复选框，单击Install按钮，如图10-5所示。
