```
\(\boldsymbol{\omega}=\sum_{i=1}^m\left(\hat{\alpha}_i-\alpha_i\right)x_i\)
\(0=\sum_{i=1}^m\left(\hat{\alpha}_i-\alpha_i\right)\)
\(C=\alpha_i+\mu_i\)
\(C=\hat{\alpha}_i+\hat{\mu}_i\)
```

将式（3-34）代入式（3-33），即可得到SVR的对偶问题，如式（3-35）所示：

```
\(\max _{\alpha, \hat{\alpha}} \sum_{i=1}^m y_i\left(\hat{\alpha}_i-\alpha_i\right)-\zeta\left(\hat{\alpha}_i+\alpha_i\right)\)
\(-\frac{1}{2} \sum_{i=1}^m \sum_{j=1}^m\left(\hat{\alpha}_i-\alpha_i\right)\left(\hat{\alpha}_j-\alpha_j\right)x_i^{\mathrm{T}} x_j\)
\(\mathrm{s} . \mathrm{t} . \sum_{i=1}^m\left(\hat{\alpha}_i-\alpha_i\right)=0\)
\(0 \leqslant \alpha_i, \hat{\alpha}_i \leqslant C\)
（3-35）
```

上述过程满足KKT条件，即要求满足式（3-36）的约束：

```
\(\left\{\begin{array}{l} \alpha_i\left(f\left(x_i\right)-y_i-\zeta-\xi_i\right)=0 \\ \hat{\alpha}_i\left(y_i-f\left(x_i\right)-\zeta-\hat{\xi}_i\right)=0 \\ \alpha_i \hat{\alpha}_i=0, \quad \xi_i \hat{\xi}_i=0 \\ (C-\alpha_i) \xi_i=0, \quad(C-\hat{\alpha}_i) \hat{\xi}_i=0 \end{array}\right.\)
```

可以看出，当且仅当 \(f(x_i)-y_i-\zeta-\xi_i=0\) 时， \(\alpha_i\) 能取非零值；当且仅当 \(y_i-f(x_i)-\zeta-\hat{\xi}_i=0\) 时， \(\hat{\alpha}_i\) 能取非零值。换言之，仅当样本 \((x_i, y_i)\) 不落入 \(\zeta\) -间隔带中时，相应的 \(\alpha_i\) 和 \(\hat{\alpha}_i\) 才能取非零值。此外，约束 \(f(x_i)-y_i-\zeta-\xi_i=0\) 和 \(y_i-f(x_i)-\zeta-\hat{\xi}_i=0\) 不能同时成立，因此 \(\alpha_i\) 和 \(\hat{\alpha}_i\) 中至少有一个为0。

将式（3-34）中的第一个式子代入对偶公式，则SVR的解如式（3-37）所示：

```
\(f(x)=\sum_{i=1}^m\left(\hat{\alpha}_i-\alpha_i\right)x_i^{\mathrm{T}} x+b\)
```
