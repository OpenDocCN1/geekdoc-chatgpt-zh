| 类型 | 描述 |
|---|---|
| 氢键 | 氢键是氢原子与酰基之间相互作用的一种常见方式。生物分子中带氢子的部分有N-H或者CH键团，称为氢键的给体；带部分负电荷的氮或负性原子称为氢键的受体。例O-N，N-H等。氢键的相互作用通常很弱。氢键受体与给体之间的距离为3A左右，并具有方向性 |
| 离子键（盐桥） | 载体带电的酰基距与蛋白中带相反电荷的基团附近形成α螺旋相互作用。这种相互作用是静电相互作用引起的，在蛋白质-配体的复合物中，配体的结合是由这种离子相互作用决定的 |
| 金属离子配对 | 有些蛋白质中含有金属离子，这些金属中心可以稳定蛋白的结构或者参与催化反应。这些金属离子可以与酰基中的氢键给体（如酰胺）或者带相反电荷的基团（如羧酸基团）形成特定的全氟化合物。对配体与蛋白的结合形成关键性的影响 |
| 疏水 | 配体中的非偏性基团和蛋白中的非极性基团都相互影响可以形成疏水相互作用。亲脂性基团有酰胺基、芳香基、杂环等。疏水作用主要是由结合过程中两个疏水基团接近从而把水将缩短结合口进行排除以外所引起的。疏水作用又有分离性 |
| 正离子-∏ | 正电荷的离子基团可以与芳香环形成极强的相互作用。阳离子可以是载体中的带正电的氨基。也可以是蛋白中的阳离子。例如带一个正电荷的赖氨基 |
