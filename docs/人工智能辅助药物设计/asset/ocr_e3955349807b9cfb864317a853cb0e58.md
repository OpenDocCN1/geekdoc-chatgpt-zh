# 10.2.6 在PyCharm 中编写Python 脚本

编写第一个程序前，你需要在PyCharm中创建一个名为python_work的文件夹，用于存储所开发的项目。文件名和文件夹名最好使用小写字母，并用下画线代替空格，这是Python的命名约定。

接下来右击新创建的文件夹，在弹出的快捷菜单中选择New->Python File，将其命名为hello_world。通过文件扩展名.py来告诉PyCharm，文件中的代码是用Python编写的，这让它知道如何运行这个程序，并以有效的方式突出其中的代码。

文件创建完成后，即可在里面输入代码，如图10-17所示。
