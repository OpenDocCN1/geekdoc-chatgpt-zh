# 7.5.4 Leaky ReLU 函数

Leaky ReLU函数在输入 \( x < 0 \) 时，保持一个很小的梯度 \( \gamma \) 。这样当神经元非激活时也能有一个非零梯度可以更新参数，避免永远不能被激活。Leaky ReLU函数的表达式为

\(\sigma(x) = \begin{cases} x & x > 0 \\ \gamma x & x \leqslant 0 \end{cases} = \max(0, x) + \gamma \min(0, x)\)

其中， \( \gamma \) 是一个很小的常数，例如0.1。当 \( \gamma < 1 \) 时，Leaky ReLU函数也可以写作

\(\sigma(x) = \max(rx, x)\)
