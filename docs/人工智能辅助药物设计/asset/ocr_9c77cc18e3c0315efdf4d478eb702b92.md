# 提示

将random_state指定为一个数字，能够使程序在任何时候、任何机型上都能将数据集划分出相同的效果，即划分后的各个训练集和测试集是一致的。但当将random_state设置为不同的数字时，使用train_test_split方法划分数据集所产生的效果一定是不同的。由此可见，计算机中所谓的随机并不是真正的随机。
