# 图5-10 采用随机森林算法获得的特征重要性

对比图5-9和图5-10可以发现，决策树和随机森林的特征重要性有一些不同，虽然区别很小，但是可以让我们确定激酶抑制剂的分类和哪些特征相关，进而可以手动删除部分特征重要性比较低的特征，以提高模型的预测能力。
