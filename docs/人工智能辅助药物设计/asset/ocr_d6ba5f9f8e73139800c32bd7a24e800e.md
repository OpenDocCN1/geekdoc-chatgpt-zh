能使式 (3-37) 中的 \((\hat{\alpha}_i - \alpha_i) \neq 0\) 的样本即为SVR的支持向量，它们必落在 \(\zeta\) -间隔带之外。显然，SVR的支持向量仅是训练样本的一部分，即其解仍具有稀疏性。

由式 (3-36) 所示的KKT条件可以看出，对每个样本 \((x_i, y_i)\) 都有 \((C - \alpha_i)\xi_i = 0\) 且 \(\alpha_i(f(x_i) - y_i - \zeta - \xi_i) = 0\) 。于是，在得到 \(\alpha_i\) 后，若 \(0 < \alpha_i < C\) ，则必有 \(\xi_i = 0\) ，进而有

```
b = y_i + \zeta - \sum_{i=1}^m (\hat{\alpha}_i - \alpha_i)x_i^T x
```

因此，在求解式 (3-35) 得到 \(\alpha_i\) 后，理论上来说，可任意选取满足 \(0 < \alpha_i < C\) 的样本通过式 (3-38) 求得 b。实践中常采用一种鲁棒性更好的方法：选取多个（或所有）满足条件 \(0 < \alpha_i < C\) 的样本求解 b 后取平均值。

若考虑式 (3-7) 所示的特征映射形式，则式 (3-34) 中的第一个式子将如式 (3-39) 所示，即

```
\boldsymbol{\omega} = \sum_{i=1}^m (\hat{\alpha}_i - \alpha_i)\phi(x_i)
```

将式 (3-39) 代入式 (3-7) ，则SVR可表示为式 (3-40) ，即

```
f(x) = \sum_{i=1}^m (\hat{\alpha}_i - \alpha_i)\kappa(x, x_i) + b
```

其中， \(\kappa(x_i, x_j) = \phi(x_i)^T \phi(x_j)\) 为核函数。
