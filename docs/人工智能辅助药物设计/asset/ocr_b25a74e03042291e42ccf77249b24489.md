是正整数; 最后, 在classCount字典中提取出一个元组列表, 并使用itemgetter()方法, 按照第二个元素的次序对元组进行排序。此处的排序为逆序, 即按照从最大到最小的次序排序, 最后返回发生频率最高的元素标签。


输出结果应该是B, 你也可以将输入的[0, 0]改变为其他值, 测试程序的运行结果。
