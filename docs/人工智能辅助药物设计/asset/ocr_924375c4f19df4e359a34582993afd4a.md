# 表7-2 M-P神经元模型图中符号及含义

| 符号 | 含义 |
| :--- | :--- |
| \(x_1, x_2, ..., x_n\) | 第1~n个输入信号 |
| \(w_{1j}, w_{2j}, ..., w_{nj}\) | 第j个神经元上与第1~n个输入对应的权重值，模拟生物神经元之间的连接强度 |
| \(\Sigma\) | 加权信号值的累加求和 |
| \(b_j\) | 第j个神经元上的阈值（偏置），模拟生物神经元的兴奋阈值 |
| \(f()\) | 第j个神经元的激活函数，调整输出信号强度，具有归一化的作用 |
| \(y_j\) | 第j个神经元最终的输出信号 |

两边的箭头分别模拟生物神经元的树突（输入单元）和轴突（输出单元），中间的椭圆模拟生物神经元的细胞体（处理单元）。M-P模型的工作流程：神经元接收其他 n 个神经元的输入信号，这些输入信号经过加权后累加求和，将结果与阈值 b 比较，然后经过激活函数处理得到神经元输出 y j，其表达式为

```
\(y_j = f\left( \sum_{i=1}^{n} (w_{ji} x_i + b_j) \right)\)
```

通俗来讲，激活函数的作用是由激活函数计算决定是否从该神经元传出信息和决定传出多少信息。
