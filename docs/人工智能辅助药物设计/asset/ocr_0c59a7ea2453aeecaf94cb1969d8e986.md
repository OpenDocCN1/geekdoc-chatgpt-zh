# 8.2 卷积神经网络的相关计算

# 8.2.1 特征图

输入数组在经过卷积运算之后得到输出数组，我们称这样的输出数组为特征图（feature map）。假设输入数组的形状为 m×m×1，卷积核的形状为 n×n×1，那么特征图就是大小为 (m−n+1)×(m−n+1)×1 的形状。

提示
m × m × 1中的“1”为输入数组的层数，在图像处理中也称之为“通道数”。

特征图的计算公式为

```
\begin{cases}
height_{out} = \frac{height_{in} - height_{kernel} + 2 \times padding}{stride} + 1 \\
width_{out} = \frac{width_{in} - width_{kernel} + 2 \times padding}{stride} + 1
\end{cases}
```

其中， height_out 、 width_out 分别表示输出特征图的高和宽， height_in 、 width_in 分别代表输入数组的高和宽， height_kernel 、 width_kernel 是卷积核的高和宽， padding 为填充的外围层数， stride 为步长。

+   提示
+   （1）式 (8-4) 默认stride为1， padding为0（在8.2.3节中会对padding展开介绍）。
+   （2）卷积运算向下取整，池化运算向上取整。

特征图片代码部分通用格式为[batch_size, height, width, channels]，即为[b, h, w, c]。其中， batch_size为批大小，即一批数据中有多少张量；height为行；width为列；channels为通道数。例如， [b,h,w,1] 即为单通道的灰色图像； [b,h,w,3] 即为RGB三通道的图像； [b,h,w,c], c ≤ 4，即将未知维度抽象化。
