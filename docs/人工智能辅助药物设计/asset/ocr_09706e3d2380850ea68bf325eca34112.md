# 10.4.3 安装PyTorch

PyTorch主要用来进行深度学习算法的建模和推理。为了加快算法训练速度，一般情况下我们需要使用带GPU的计算机进行PyTorch安装，而为了能够在PyTorch中准确地使用GPU，首先需要安装GPU环境，包括CUDA和cuDNN。在确保正确安装GPU环境后再安装PyTorch。

# 1.安装CUDA

随着显卡的发展，GPU越来越强大，而且GPU为显示图像做了优化。在计算上，GPU已经超越了通用的CPU。如此强大的芯片如果只是作为显卡就太浪费了，因此NVIDIA推出CUDA，让显卡可以用于图像渲染和计算以外的目的。CUDA即Compute Unified Device Architecture，是NVIDIA利用GPU平台进行通用并行计算的一种架构，它包含了CUDA指令集架构（ISA）以及GPU内部的并行计算引擎。开发人员可以利用C、OpenCL、FORTRAN、C++等为CUDA编写程序。简单来理解，CUDA就是NVIDIA提供的可以将显卡进行并行运算的一种软件驱动。
