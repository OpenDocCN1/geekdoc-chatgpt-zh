# 10.4.2 安装TensorFlow

# 1.TensorFlow 的安装

在终端窗口中输入如下命令。

（1）创建虚拟环境：conda create -n tensorflow python=（版本号），如图10-18所示。

（2）进入虚拟环境：activate tensorflow，如图10-19所示。

![](bbox=[0.1309, 0.2453, 0.876, 0.3875])

图10-18 创建虚拟环境

![](bbox=[0.1309, 0.425, 0.6895, 0.5325])

图10-19 进入虚拟环境

（3）连接清华大学开源软件镜像站：conda config --add channels https://***/anaconda/
pkgs/free/conda config --set show_channel_urls yes，如图10-20所示。

![](bbox=[0.1309, 0.6153, 0.876, 0.6594])

图10-20 连接清华大学开源软件镜像站

（4）安装TensorFlow：pip install --upgrade --ignore-installed tensorflow，如图10-21所示。这个过
程需要的时间比较长，耐心等待即可。

![](bbox=[0.1309, 0.743, 0.876, 0.787])

图10-21 安装TensorFlow

# 2.检验是否安装成功

（1）进入TensorFlow环境：activate tensorflow。

（2）进入Python解释器：python。
