# 图2.18 900MHz & ETC开发平台

+   ◎ 两路RJ45工业接口，包含IO、DC 3.3 V、DC 5 V、UART、RS-485、两路继电器输出等功能，提供两路3.3 V、5 V、12 V电源输出。
