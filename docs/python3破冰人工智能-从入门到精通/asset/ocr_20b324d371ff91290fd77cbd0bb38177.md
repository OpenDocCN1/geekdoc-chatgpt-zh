# 2000 年 B 题 钢管订购和运输

要铺设一条 A1→A2→…→A5 的输送天然气的干主管道，如图 1-7 所示。经筛选后可以生 产这种主管道钢管的钢厂有 S1,S2,…,S7。图中粗线表示铁路，单细线表示公路，双细线表示要 铺设的管道（假设沿管道或者原来有公路，或者新建有施工公路），圆圈表示火车站，每段铁路、 公路和管道旁的阿拉伯数字表示里程（单位为 km）。
