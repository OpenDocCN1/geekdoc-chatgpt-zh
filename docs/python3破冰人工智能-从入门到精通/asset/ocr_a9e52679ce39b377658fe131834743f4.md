# 1. 通过列表或元组转化

在 Python 内建对象中，数组有 3 种形式：列表（list）、元组（tuple）、字典（dict）。具体形式如下。

+   - list: [1, 2, 3]
+   - tuple: (1, 2, 3)
+   - dict: {a:1, b:2}

在 NumPy 中，使用 numpy.array 将列表或元组转换为 ndarray 数组。其方法为：

```
numpy.array(object, dtype=None, copy=True, order=None, subok=False, ndmin=0)
```

相关参数如下。

+   - object: 输入对象列表、元组等。
