# 3. linspace 生成等差数列

linspace 方法也可以像 arange 方法一样，创建数值有规律的数组。linspace 用于在指定区间内返回间隔均匀的值，其方法为：

```
```
numpy.linspace(start, stop, num=50, endpoint=True, retstep=False, dtype=None)
```
```

+   - start：序列的起始值。
+   - stop：序列的结束值。
+   - num：生成的样本数，默认值为 50。
+   - endpoint：布尔值，如果为 True，则最后一个样本包含在序列内。
+   - retstep：布尔值，如果为 True，返回间距。
+   - dtype：数组的类型。
