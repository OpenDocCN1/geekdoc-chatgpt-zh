# 4.3 SciPy 科学计算库

# 4.3.1 初识 SciPy

SciPy 是在 NumPy 库的基础上增加了众多的数学、科学以及工程计算中常用函数的库。SciPy 库依赖于 NumPy，提供了便捷且快速的 n 维数组操作。SciPy 库的构建与 NumPy 数组一起工作，并提供了许多友好和高效的处理方法。它包括了统计、优化、整合以及线性代数模块、傅里叶变换、信号和图像图例，常微分方差的求解等，功能十分强大。
