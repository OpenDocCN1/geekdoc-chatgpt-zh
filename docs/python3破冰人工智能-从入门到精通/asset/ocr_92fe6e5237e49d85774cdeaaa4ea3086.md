同时也可以灵活地使用内置的 round()函数，其函数形式为：

```
round(number, ndigits)
```

参数如下。

+   - number: 为一个数字表达式。
+   - ndigits: 表示从小数点到最后四舍五入的位数，默认值为 0。

# 【例 2-5】浮点数输出

输入：

```
print("%f" % 3.1415926)
```

输出：

```
3.141593
```

输入：

```
print("%.2F" % 3.1415926)
```

输出：

```
3.14
```

输入：

```
print(round(3.1415926,2))
```

输出：

```
3.14
```
