在使用 NumPy 的过程中，可以通过 dtype 来指定数据类型，通常这个参数是可选的，或者通过 astype()来指定。同样，每一种数据类型均有对应的类型转换函数。在 Python 中，通常并不强制要求内存控制指定。NumPy 关于数据类型方面的操作见例 3-3 与例 3-4。

# 【例 3-3】NumPy 数据类型操作

输入：

```
#指定数据类型
print(np.array(5, dtype=int))
```

输出：

5

输入：

```
print(np.array(5).astype(float))
```

输出：

5.0

输入：

```
#转换数据类型
print(float(42))
```

输出：

42.0
