```
# 3）通过字典的 key

在 Python 中，字典的使用频率非常之高，其经常由 JSON 类型转化得到。同时随着人工智能的发展，越来越多的數據需要字典类型的支持，比如 MongoDB 数据的形式就可以看成一种字典类型，还有推荐算法中的图算法也经常应用 key-value 形式来描述数据。format 通过 key 形式输出，如例 2-8 所示。

# 【例 2-8】format 字典形式输出

输入：

```
```python
Tom = {'age':27, 'gender': 'M'}
print("{0[age]}".format(Tom))
print("{p[gender]}".format(p=Tom))
```
```

输出：

```
```
27
M
```
