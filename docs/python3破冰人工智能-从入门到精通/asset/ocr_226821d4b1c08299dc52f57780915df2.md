# 3. DataFrame 数据结构

DataFram 是表格型的数据结构，它含有有一组有序的列，每列可以是不同的值类型（数值、字符串、布尔值等）。DataFrame 既有行索引，也有列索引，它可以被看成由 Series 组成的字典（共用同一个索引）。

DataFrame 的基本创建方式为：

```
pd.DataFrame(data=None, index=None, columns=None)
```
