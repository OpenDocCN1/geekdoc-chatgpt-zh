# 6. 牛顿-莱布尼茨公式

定理：若 $f(x)$ 在 $[a,b]$ 上连续，$F(x)$ 是 $f(x)$ 的一个原函数，则 $\displaystyle\int_a^b f(x)dx = F(b)-F(a)$

证明：$F(x)$ 是 $f(x)$ 的一个原函数，$\Phi(x)=\int_a^x f(t)dt$ 也是 $f(x)$ 的一个原函数，同一个函数的两个原函数之间相差一个常数，于是有 $\displaystyle\int_a^x f(t)dt - F(x)=C \Rightarrow \int_a^x f(x)dx = F(x)+C$

$\Rightarrow egin{cases}\int_a^b f(x)dx = F(b)+C\ \int_a^a f(x)dx = F(a)+C =0 \Rightarrow C=-F(a)\end{cases}$
$\Rightarrow \int_a^b f(x)dx = F(b)-F(a)$

$\displaystyle\int_a^b f(x)dx = F(b)-F(a) = [F(x)]_a^b$ 记作 $[F(x)]_a^b$ $= \left.\int f(x)dxight|_a^b$ 记作 $\left.\int f(x)dxight|_a^b$

下面给出一个求解案例。

求解 $\int_2^{-1}\frac{1}{x}dx$。

解：$\int_2^{-1}\frac{1}{x}dx = [\ln|x|]_{-2}^{-1} = -\ln1 - \ln2 = 0 - \ln2 = -\ln2$

在一元函数情况下，求微分实际上是求一个已知函数的导数，而求积分是求已知导数的原函数，所以微分与积分互为逆运算。
