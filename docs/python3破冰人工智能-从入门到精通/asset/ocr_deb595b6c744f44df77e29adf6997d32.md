# 【例 2-16】while 循环语句的形式

```
while expression:
    statements
```

statements 可以是单个语句，也可以是语句块；expression 表示判断条件，如果为真，则执行循环体语句。

像 while 循环一样，for 循环也是一种编程语言语句，即迭代语句，它允许代码块重复一定次数。几乎所有编程语言中都存在 for 循环，但其风格各不相同，即语法和语义在不同的编程语言中都是不相同的。在 Python 中，for 循环语句的形式见例 2-17。
