# 2. 在 Linux 系统中安装 Anaconda

当前选取的 Linux 环境是 CentOS 6.5，其他环境安装方法仿照 Anaconda 官方操作进行安装。首先到下载 Linux 版本的 Anaconda3-5.2.0-Linux-x86_64.sh 界面，如图 2-5 所示。

下载完成之后进入文件下载目录，打开终端，根据版本输入下面的安装执行命令：

```
$ bash Anaconda3-5.2.0-Linux-x86_64.sh
```

输入完成之后得到的结果如下所示：

```
Welcome to Anaconda3 5.2.0
```
