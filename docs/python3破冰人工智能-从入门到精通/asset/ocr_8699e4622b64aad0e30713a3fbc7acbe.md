# 表 4-9 图像内部各个组件内容

| 组件 | 说明 |
|---|---|
| Figure | 整个图像 |
| Axes | 轴，灵活的子图 |
| Grid | 网格 |
| Title | 标题 |
| Legend | 图例 |
| line | 图像中的线 |
| markers | 图像中的点 |
| Spines | 连接轴刻度标记的线，而且标明了数据区域的边界 |
| Major tick | 主刻度 |
| Minor tick | 分刻度 |
| Major tick label | 主刻度标签 |
| Y axis label | y 轴标签 |
| Minor tick label | 分刻度标签 |
| X axis label | x 轴标签 |
