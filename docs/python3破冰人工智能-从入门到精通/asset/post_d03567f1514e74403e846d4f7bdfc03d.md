
Δy = f(x₀ + Δx) - f(x₀)

可表示为：

Δy = AΔx + o(Δx)

其中，A 是不依赖于 Δx 的常数，那么称函数 y = f(x) 在点 x₀ 是可微的，而 AΔx 叫作函数 y = f(x) 在点 x₀ 相对于自变量增量 Δx 的微分，记作：

dy|_{x=x₀} = AΔx 或 df(x₀) = AΔx

## 3. 微分与导数的关系

定理：函数 y = f(x) 在点 x₀ 可微的充要条件是函数 y = f(x) 在点 x₀ 可导，且当 y = f(x) 在点 x₀ 可微时，其微分一定是 dy|_{x=x₀} = f'(x₀)Δx。

根据微分的定义和上述定理可得以下结论。

- (1) 函数 y = f(x) 在点 x₀ 处的微分就是当自变量 x 产生增量 Δx 时，函数 y 的增量 Δy 的主要部分（此时 A = f'(x₀) ≠ 0）。由于 dy = AΔx 是 Δx 的线性函数，故称微分 dy 是 Δy 的线性主部。当 |Δx| 很微小时，o(Δx) 更加微小，从而有近似等式 Δy ≈ dy。
- (2) 函数 y = f(x) 的可导性与可微性是等价的，故求导法又称微分法。但导数与微分是两个不同的概念，导数 f'(x₀) 是函数 f(x) 在 x₀ 处的变化率，其值只与 x 有关；而微分 dy|_{x=x₀} 是函数 f(x) 在 x₀ 处增量 Δy 的线性主部，其值既与 x 有关，也与 Δx 有关。

函数 y = f(x) 在任意点 x 处的微分，称为函数的微分，记作 dy 或 df(x)，即： dy = df(x) = f'(x)Δx

通常把自变量 x 的增量 Δx 称为自变量的微分，记作 dx，即 dx = Δx。因此，函数 y = f(x) 的微分可以记作： dy = f'(x)dx 或 df(x) = f'(x)dx 从而有： dy/dx = f'(x) 或 df(x)/dx = f'(x) 因此，函数 y = f(x) 的微分 dy 与自变量的微分 dx 之商等于该函数的导数。 以上介绍的是一元函数微积分，相对于一元函数微积分，多元函数的情况要更加复杂，这里就不做过多介绍了。值得注意的是，偏微分和全微分的关系是，全微分等于偏微分之和。

## 4. 不定积分

不定积分的概念：有 f(x)，x∈I，若存在函数 F(x)，使得对任意 x∈I 均有 F'(x)=f(x) 或 dF(x)=f(x)dx，则称 F(x) 为 f(x) 的一个原函数。 f(x) 的全部原函数称为 f(x) 在区间 I 上的不定积分，记作：

∫f(x)dx = F(x) + C

注：

- (1) 若 f(x) 连续，则必可积。
- (2) 若 F(x) 和 G(x) 均为 f(x) 的原函数，则 F(x) = G(x) + C。故不定积分的表达式不唯一。

不定积分主要有以下 3 点性质，以方便计算求解。

- 性质 1： d/dx [∫f(x)dx] = f(x) 或 d[∫f(x)dx] = f(x)dx。
- 性质 2： ∫F'(x)dx = F(x) + C 或 ∫dF(x) = F(x) + C。
- 性质 3： ∫[αf(x) ± βg(x)]dx = α∫f(x)dx ± β∫g(x)dx，α 和 β 为非零常数。

不定积分的计算方法有换元法、部分积分法等，这里不做过多介绍。下面给出一个通过凑微分法求解过程，仅供参考。

求解 ∫e^{3t} dt。

解： ∫e^{3t} dt = 1/3 ∫e^{3t} d(3t) = 1/3 e^{3t} + C

## 5. 定积分

设函数 y = f(x) ∈ C[a, b]，且 y = f(x) > 0。由曲线 y = f(x), x = a, x = b, y = 0 围成的图形称为曲边梯形，如何定义曲边梯形的面积？

答：将曲边梯形分割为许多细长条，分割得越细，误差越小。第 i 个细长条面积 ΔS_i ≈ f(ξ_i)Δx_i （∀ξ_i ∈ [x_{i-1}, x_i]，Δx_i = x_i - x_{i-1}），曲边梯形面积为 S ≈ Σ_{i=1}^n f(ξ_i)Δx_i。

S = lim_{λ→0} Σ_{i=1}^n f(ξ_i)Δx_i （λ = max{Δx_i, i = 1, 2, …, n}）

抛开上述过程的几何意义，将其数学过程定义为定积分。如图 1-11 所示，设 y = f(x) 在 [a, b] 有定义，且有界。

- (1) 分割：用分点 a = x₀ < x₁ < … < xₙ = b 把 [a, b] 分割成 n 个小区间。
- [x_{i-1}, x_i]， i = 1, 2, …, n
- 记 Δx_i = x_i - x_{i-1}， λ = max{Δx_i, i = 1, 2, …, n}
- (2) 取点：在每个小区间 [x_{i-1}, x_i] 上任取一点 ξ_i，作为乘积 f(ξ_i)Δx_i。
- (3) 求和： Σ_{i=1}^n f(ξ_i)Δx_i。
- (4) 取极限： lim_{λ→0} Σ_{i=1}^n f(ξ_i)Δx_i。

若极限存在，则其为 $f(x)$ 在 $[a,b]$ 上的定积分，记作 $\int_a^b f(x)dx$，即 $\int_a^b f(x)dx = \lim_{\lambda\to0}\sum_{i=1}^n f(\xi_i)\Delta x_i$

$[a,b]$ 为积分区间，$a$ 为积分下限，$b$ 为积分上限，$\sum_{i=1}^n f(\xi_i)\Delta x_i$ 为积分和式。

## 6. 牛顿-莱布尼茨公式

定理：若 $f(x)$ 在 $[a,b]$ 上连续，$F(x)$ 是 $f(x)$ 的一个原函数，则 $\displaystyle\int_a^b f(x)dx = F(b)-F(a)$

证明：$F(x)$ 是 $f(x)$ 的一个原函数，$\Phi(x)=\int_a^x f(t)dt$ 也是 $f(x)$ 的一个原函数，同一个函数的两个原函数之间相差一个常数，于是有 $\displaystyle\int_a^x f(t)dt - F(x)=C \Rightarrow \int_a^x f(t)dt = F(x)+C$

$\Rightarrow \begin{cases}\int_a^b f(x)dx = F(b)+C\\ \int_a^a f(x)dx = F(a)+C =0 \Rightarrow C=-F(a)\end{cases}$
$\Rightarrow \int_a^b f(x)dx = F(b)-F(a)$

$\displaystyle\int_a^b f(x)dx = F(b)-F(a) = [F(x)]_a^b$ 记作 $[F(x)]_a^b$ $= \left.\int f(x)dx\right|_a^b$ 记作 $\left.\int f(x)dx\right|_a^b$

下面给出一个求解案例。

求解 $\int_2^{-1}\frac{1}{x}dx$。

解：$\int_2^{-1}\frac{1}{x}dx = [\ln|x|]_{-2}^{-1} = -\ln1 - \ln2 = 0 - \ln2 = -\ln2$

在一元函数情况下，求微分实际上是求一个已知函数的导数，而求积分是求已知导数的原函数，所以微分与积分互为逆运算。

示例代码学习时，这种方式尤其适合。

### 1. 注释

在大多数编程语言中，注释是一项很有用的功能。源代码的注释供人阅读，而不是供计算机执行，注释用自然语言告诉你某段代码的功能是什么。随着程序版本的更迭，程序越来越复杂，就应其中添加说明，对程序所解决问题的办法进行大致的阐述。

每种语言都有其特有注释形式，下面来介绍 Python 中程序的行内注释。

### (1) 单行注释

在 Python 中，单行注释以井号（#）开头标识，井号后面的内容都会被 Python 解释器忽略，如例 2-2 所示。
