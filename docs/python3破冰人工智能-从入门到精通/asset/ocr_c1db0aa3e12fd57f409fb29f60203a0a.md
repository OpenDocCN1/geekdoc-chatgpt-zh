### 表 4-4 df.loc[]规则
**df.loc[] 标签定位**
| 二维，先行后列 |
| 行维度 | 列维度 |
| 标签索引、标签切片、标签列表、布尔数组、Callable | 标签索引、标签切片、标签列表、布尔数组、Callable |

总结：在使用中括号[]选取数据时，只当出现以 columns 标签相关的检索时，为进行列检索，其他情况均为对行的处理
