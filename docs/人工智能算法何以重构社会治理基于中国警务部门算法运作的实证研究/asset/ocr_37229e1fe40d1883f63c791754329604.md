# 人工智能算法何以重构社会治理？*

# ——基于中国警务部门算法运作的实证研究

宋锘业 徐雅倩

提要：人工智能算法重构社会治理是一项重大时代性议题。本文基于对警务部门、平台企业、风险算法工程师的参与式观察和深度访谈，分析算法重构社会治理的逻辑与影响。研究发现，警务部门通过算法构建组织外部的关系结构，同时通过算法集约化实现组织内部的权力边界重塑，还借助算法提高对风险的全面感知能力。这带来的深层影响是，一方面，警务部门特别是基层警察的隐性知识和能力容易被算法替代，警务算法取代了其他更广泛的解决社会问题的方法；另一方面，算法的全面扩展带来“信息过描”，这在实践中容易转化为各种形式的优先排序。

关键词：人工智能 算法治理 警务部门 社会治理
