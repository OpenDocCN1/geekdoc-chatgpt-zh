# （一）算法蕴含的“权力冲突”限制社会问题的解决范畴

警务部门对算法的依赖与原有科层结构形冲突。对基层警务部门而言，其应对和处理犯罪方面的经验感知和空间记忆能力逐渐被算法替代。基层警务部门的工作转变为收集数据和风险预防，并按照上级的算法输出结果开展警务活动。由于算法常常被视为一种权威和科学，基层警务部门的隐性知识和经验直觉在算法扩张中逐渐弱化。由此，警务部门实施的算法作为一种事实上的替代品，取代了其他更广泛的解决社会问题的方法（Kennedy et al., 2018: 19），限制或缩小了基层警务部门可以解决的社会问题类型（如网络诈骗案件或刑事犯罪案件侦查权的上移）和能够考虑的解决方案范畴（如大规模警务数据信息的处置权上移）。原有社会治理机制发挥作用的双重基础——警务部门的专业知识和问责制被削弱（Busuioc, 2021）。基层警务部门花费相对较少的时间练习和发展他们的演绎推理技能，警察的经验知识也随之减少。我们在 D 市警务部门访谈时，市公安指挥中心的一位受访者指出：

以前公安队伍对人的素质要求不是很高，破案办案更多是靠传帮带，就是老民警带新民警。这里的“带”主要体现在公安长期的经验推理能力……哪怕写材料水平低也不要紧，会办什么案，问的什么话，能推理出来才重要。但现在 AI 算法、大数据的使用，需要的（警察）条件更高。掌握新技术的警察成了最稀缺的资源。过去处理案子可能十天、半个月、一个月、两个月，现在可能是三天、五天、八小时破案，这对警察的要求，特别是如何对大规模数据抽丝剥茧，要求很高。（访谈资料 24051301，D 市公安局指挥中心负责人）
