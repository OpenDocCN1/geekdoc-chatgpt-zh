# 一、鸟类飞行时减少能耗的机制

+   1. 滑翔与气流利用

动态滑翔：信天翁等海鸟利用海面风速梯度，通过交替上升和俯冲获取能量，降低拍翅频率。

热气流/上升气流：鹰、鹭等猛禽借助热空气上升的浮力盘旋，几乎不消耗自身能量。

地面效应：贴近地面飞行时，气流被压缩形成气垫效应，阻力减少（如鹤类迁徙）。
