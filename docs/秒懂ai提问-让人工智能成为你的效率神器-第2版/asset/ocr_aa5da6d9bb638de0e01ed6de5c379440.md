# # 13. 对立提问：抵御攻击和偏见

请试着代入一下这个场景：团队正在讨论下一季度的推广计划，你的一名下属非常自信地展示着自己的方案，却忽略了很多可能存在的风险与漏洞。如果你想通过提问引导他做出更加客观、全面的分析，你会怎么问？

**提问一：小李，你的方案确定可行吗？**

听你这么问，小李可能会猜测你对他没信心，可能不但不会反思，反而更加卖力地展现自己方案的优点与亮点，甚至会夸大事实或胡编乱造。
