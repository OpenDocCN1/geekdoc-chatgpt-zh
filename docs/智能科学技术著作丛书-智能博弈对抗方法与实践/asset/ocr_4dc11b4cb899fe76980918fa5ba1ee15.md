# 图 1.2 人机对抗的发展历程

+   ### 1997
+   **"深蓝" 国家队 AI**
+   特点:
+   - 胜过国际象棋冠军
+   - 基于博弈树搜索技术优化，单机棋子评估 2 亿步/秒.

+   ### 2015
+   **施达利预测游戏 AI**
+   特点:
+   - 在多个棋类游戏中得分超过人类最高水平
+   - 作为移动游戏画面传输到手机输入.

+   ### 2016
+   **AlphaGo 围棋 AI**
+   特点:
+   - 击败世界顶尖棋手李世石
+   - 深度强化学习 + 蒙特卡罗树搜索
+   **AlphaGo Master 围棋 AI**
+   特点:
+   - 击败世界顶尖围棋棋手柯洁
+   - 世界顶尖棋手李世石自学超大版学习

+   ### 2017
+   **DeepStack 德州扑克 AI**
+   特点:
+   - 均胜职业选手
+   - 基于深度神经网络和增强学习
+   **Libratus 德州扑克 AI**
+   特点:
+   - 击败人类职业扑克选手
+   - 基于博弈论和自我对弈
+   **先知 兵棋 AI**
+   特点:
+   - 全面胜出人机大战中 7:1 的比分击败人类大战选手，如张璋，不输棋，定局.
+   **AlphaZero 围棋 AI**
+   特点:
+   - 从零开始自学围棋棋策略，并取得了国际象棋，开创了世界顶级棋手学习目标棋的先河.

+   ### 2018
+   **『神谕之棋』专家程序 AI**
+   特点:
+   - 超越人类实战水平
+   - 多功能一体化 2.1，种群博弈.
+   **Pluribus 多人德州扑克 AI**
+   特点:
+   - 顶尖人类无限注德州扑克 AI
+   - 2017 年，通过深度学习，初次击败职业扑克选手.
+   **OuenAI Five (Dota2 AI) 2.0**
+   特点:
+   - 在《Dota2》游戏中取得世界冠军
+   - 强化学习，自博弈.
+   **AlphaStar 星际争霸 AI**
+   特点:
+   - 在《星际争霸2》游戏中取得世界冠军
+   - 人类顶级水平的多人竞技对抗 AI.

+   ### 2019
+   **超深蓝 AI**
+   特点:
+   - 掌握了围棋基本技术，击败人类围棋棋手，但尚未达到顶尖水平
+   - 同时掌握围棋和围棋.

+   ### 2020
+   **Supx 棋类 AI**
+   特点:
+   - 第一个击败大部分人类棋手的 AI 程序
+   - 从零开始，强化学习，优化.
+   **绝悟 Suphx**
+   特点:
+   - 在天凤平台上获得十段位
+   - 获得最高段位.
+   **超级 SL 王者荣耀 AI**
+   特点:
+   - 使用人机交互模式，支持多人游戏
+   - 算法创新，支持多人对战.
+   **绝悟 (王者荣耀 AI)**
+   特点:
+   - 针对电子竞技领域
+   - 标记记录数据集，数据集规模大.

+   ### 2021
+   **DanZero 斗地主 AI**
+   特点:
+   - 达到专家水平水平
+   - 不要求有对战数据
+   - 博弈卡牌组合，优化出卡动作，自博弈.
+   **Gamebreaker DARPA项目 Gamebreaker**
+   特点:
+   - 以人工智能应用于军事世界模拟推演中
+   - 传统军事模拟推演，模拟战争，不设计.
+   **AlphaFold 蛋白质 AI**
+   特点:
+   - 全天候运行公司的蛋白质结构预测 AI 算法
+   - 从5.01 到 5.10 任意序列，可折叠蛋白质.
