# 2. 博弈动力学

博弈原本就是描述个体之间的动态交互过程。对于一般的势博弈，从任意一个局势开始，最佳响应动力学可确保收敛到一个纯纳什均衡。最佳响应动力学过程十分直接，每个智能体可以通过连续性的单方策略改变来搜索博弈的纯纳什均衡。
