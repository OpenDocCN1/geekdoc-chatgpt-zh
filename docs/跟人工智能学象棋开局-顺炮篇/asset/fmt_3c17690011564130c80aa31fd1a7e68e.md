# 第七章　人工智能拆棋时代对顺炮布局的暴力拆解

到2022年5月为止，只在2006年举办过一次人和电脑象棋对战的“人机大战”，上半场以柳大华、徐天红、汪洋、卜凤波、张强组成的大师联队以2胜5和3负，总比分9比11输给了“浪潮天梭”计算机。下半场当时“象棋第一人”许银川出马艰难弈和两盘棋，比分2∶2战平了“浪潮天梭”计算机。

因此象棋界一般以2006年作为“纯人拆棋”和“人工智能拆棋”的分水岭，从2006年开始人类就下不过电脑象棋了。此后象棋界进入“人工智能拆棋时代”。无论是专业棋手，还是业余棋迷，只要有电脑端象棋软件，或者手机端象棋软件，都可以随时随地向电脑学棋、拆棋、练棋，这是科技的进步，也是时代的潮流。

顺炮布局就是在“人工智能拆棋时代”被暴力拆解、几乎穷尽所有布局变化的典型布局之一。在如今电脑精准的布局打分下，我们作为先手中炮方只要走出了“先手中炮直车”阵型，在默认双方都不弈出错漏的前提下，先手中炮方就可以稳持先手主动，后手顺炮只能下风顶和。
