# 前言

从2014年到2022年，笔者以“象棋爱好者”“骚老师”的笔名累计在各个自媒体平台发布了数百篇棋评文章、超过200局人机大战的解析、超过1500个的象棋解说视频。笔者一开始做象棋自媒体纯粹是为了好玩，顺便依靠文章阅读量和视频播放量赚点稿费，心里想着小打小闹玩个两三个月应该就会感到乏味而无法坚持了，真没想到自己却坚持了整整九年。

人生有多少个九年？如果这都不算爱，那我还有什么可期待？笔者目前最大的心愿就是：成为一名象棋棋谱作家。读者朋友们如果看到这段独白，说明笔者在成为象棋棋谱作家的道路上迈出了第一步。本书内容能否得到市场的认可，本书续集能否得到出版，这一切都是未知数。在成为象棋棋谱作家的万里长征路上，道阻且长，需要不断地成长和磨练，各位读者朋友的鼓励和支持将是笔者坚持前行的动力。

在正式说到象棋人工智能人机拆棋之前，先和各位亲爱的读者朋友们分享一下笔者的象棋经历。

在爷爷的教导下，笔者五六岁就学会了下象棋，但那时笔者根本没把注意力放在象棋上。小学期间也曾上过课外兴趣象棋学习班，也只是学了一点皮毛。真正激发笔者对于象棋的好奇心是在初中时期，班上一位同学在课间玩象棋时，兴致勃勃地说起中国象棋人机大战，也就是人和电脑下象棋。他说许银川顶和了超级电脑两盘棋，那两盘棋真是精彩。后来笔者在网上查到了许银川人机大战的新闻，自那时起笔者对象棋软件、象棋人机大战有了初步的认知，从此便迷上了象棋。

笔者人生中看过的第一本棋书是象棋古谱《橘中秘》。在初中的一个暑假，笔者硬着头皮把《橘中秘》的所有棋谱在棋盘上认认真真地打了一遍，自此笔者在初高中可以说打遍学校无敌手。用现在的眼光来看那时的象棋水平，应该是在天天象棋业4～业5水平。到了大学，加入了学校棋社棋队，大一整整一个学年，笔者利用课余时间把张强和阎文清合著的《布局三件套》啃了一遍，此后连续三年拿了本校象棋冠军，大学期间最好成绩是市大学生棋艺联赛亚军、省大学生棋艺联赛第十一名（亦或是第十三名，已记不清了）。用现在的眼光来看那时的象棋水平，已经达到了天天象棋业9水平。

大学毕业之后上班闲暇之余，又碰上了直播、短视频处在风口的时代，笔者思来想去，自媒体时代自己唯一能持续输出作品的只有象棋领域了，于是接下来的九年的时间里以“象棋爱好者”“骚老师”的笔名在象棋自媒体领域笔耕不辍，创作了千余件受棋迷朋友们喜爱的作品。而要持续高质量地输出优质的象棋拆棋、讲棋作品，就必须倒逼自己不断地去提高棋力，所以笔者又花了大量时间利用人工智能象棋软件来人机拆棋。时至今日，笔者拿到了广东地方大师象棋等级证书，在网上也有了“中国象棋人机拆棋第一人”的美誉。就棋力而言，目前应该是天天象棋业9-3接近神1的水平，对应现实棋力是象棋比赛成年组县冠军（稳拿前3）、中强市级水平（拿前8）。

笔者十几年前就已经系统地接触“人机拆棋”了。如今因为天天象棋、象棋微学堂等手机下棋平台的兴起，“人机拆棋”的理念已经深入人心，可在十几年前的“人机拆棋”和现在的“人机拆棋”完全不是一个概念。以前的“人机拆棋”，是以人为主体，电脑为辅助，操控者水平越高，人机拆棋也就越强。当时的电脑棋力构成：开局弱+中局强+残局弱，于是在具体操作时，开局和残局阶段以人脑为主，中局阶段以电脑为主。现在的“人机拆棋”，是以电脑为主体，人则成了学习电脑招法的学习者，电脑配置越高、人机理解越深，人机拆棋就越强。如今的电脑棋力构成：开局强+中局强+残局强，电脑开、中、残全方位碾压人类棋手，就是手机端的电脑象棋软件也可以在人类象棋特级大师面前立于不败，更加不用说电脑端实力更加恐怖的象棋旋风、象棋名手、小虫象棋、GGzero等新一代人工智能象棋软件。目前人类顶尖象棋特级大师如王天一、郑惟桐等，与人工智能象棋软件的差距为2～3先，且不论先手后手，人类在人工智能象棋软件面前都是难求一胜。

笔者从2017年开始，就系统拆解过中国计算机博弈锦标赛（象棋组）、旋风杯人工智能象棋大赛、独醉杯人工智能象棋大赛等人机大战的棋谱，累计制作超过200局的人机大战象棋解说拆解视频，在此期间有幸结交了以党晓阳为代表的诸多国内超一流顶尖人机高手。笔者也被粉丝们戏称为“中国象棋人机拆棋第一人”，除了诚惶诚恐之外，更多的是一份督促和责任。毕竟，目前国内从事象棋领域的人机拆棋、人机学棋的自媒体博主寥寥无几，而笔者是目前国内的先行者。从这一点来说，笔者确实也算是“中国象棋人机拆棋第一人”，这里的第一人就是指国内第一批先行者，而不是人机拆棋综合实力第一人。

本书有两大革命性创新：

第一：结合人工智能象棋软件精准无误的人机拆棋。

第二：目前市场上第一本有明确立场的象棋布局书籍。

过去仅凭人力拆解的象棋布局棋书，因其年代久远，与现今象棋布局的最新研究成果脱节、大量的新变例没有加进去，且存在大量的重复出版和不少人类在象棋分析判断上的错误和盲点，所以利用人机拆棋来纠正布局错漏、补充完善开局变化是非常有必要的。以顺炮布局为例，前人所著的棋书的观点都一致认为顺炮布局是常规布局、足可与先手中炮抗衡。但当今人工智能拆棋已成熟完善，陈旧的观点将被颠覆，笔者结合人工智能拆棋后得出的精确结论是：顺炮布局是一种先天略亏、尚可一战的布局。

在顺炮局对战中，站在先手立场红方该怎么占优，在此之前的棋书都没有给出明确的答案，但在本书《跟人工智能学象棋开局·顺炮篇》中，读者朋友们会得到明确的答案和对顺炮布局的全新认识。

最后本书得以顺利出版，感谢成都时代出版社（原蜀蓉棋艺出版社）所有的幕后编辑老师，感谢象棋微学堂宫易的赏识，感谢象棋人机高手党晓阳的技术支持，以及感谢多年来在微信、头条、b站等自媒体平台支持本人的所有家人、朋友和粉丝们。

由于水平有限，加之时间仓促，书中疏漏在所难免，欢迎广大读者朋友们提出批评建议，以便改进。

象棋爱好者R

# 第一部分　顺炮布局人机铺垫

## 第一章　顺炮布局人机结论

在人工智能象棋软件的暴力拆解下，笔者给顺炮布局得出以下清晰的定论：

面对先手中炮开局，后手顺炮布局是略亏可下的非必败开局，先天落后1.5先～2先。在下棋双方都没有犯错失误的情况下，先手中炮优势，后手顺炮只能劣势顶和。

这个结论颠覆了前人所有的棋书、棋评、棋战的结论，对于顺炮布局来说是一个残酷的结论，但在人工智能象棋软件的暴力拆解下，这就是一个事实，毋庸置疑。

我们可以从两个方面去验证以上结论：

第一，顺炮布局的使用现状。

第二，顺炮布局的电脑打分。

### 第一，顺炮布局的使用现状

在软件比赛中，智能软件面对先手中炮，后手顺炮的应法被淘汰，零出现。

在职业比赛中，职业棋手面对先手中炮，后手几乎“清一色的”起马应战。在大师、特大级别的职业比赛中，全年出现的顺炮对局不超过10盘棋。

曾经登上过象棋个人等级分第一高峰的两位冠军级特级大师许银川和蒋川，在纯人拆棋时代特别喜欢后手应以顺炮，但在高水平象棋软件出现后，他们也很少以后手顺炮应战了。

目前被棋迷誉为“象棋布局专家”“象棋布局第一人”的郑惟桐在正式比赛中面对先手中炮，后手全部屏风马，从不下后手顺炮。

目前顺炮布局大多出现在省、市、县等各级别业余比赛。

综上所述，目前水平越高的象棋棋手，越少下或者不下顺炮布局。为什么会出现这种现状？原因很简单，随着我们象棋水平的不断提高，随着我们对于顺炮布局的不断了解，在如今人工智能象棋软件的暴力拆解下，顺炮布局确实是一种“先天略亏”的布局，在水平越高的象棋实战中，后手顺炮想要赢棋的难度就越大，渐渐的顺炮布局就没人下了。

### 第二，顺炮布局的电脑打分

根据电脑配置或者手机配置的不同，还有不同人工智能象棋软件分析引擎的差异，一盘棋的具体局面在电脑打分也是不同的。一般来说，一盘棋的具体局面在电脑打分下的分数等价于：

正50分，相当于一个先手；

正100分，相当于棋局稍优；

正200分，相当于棋局优势；

正300分，相当于棋局大优；

正300～500分，相当于多一个大子的优胜；

正1000分，相当于多一个车的优胜。

那么，电脑对于顺炮布局的打分是多少分呢？

如图1，屏风马打分基本0分，也就是电脑打分认为：“后手屏风马足可抗衡先手中炮，弹性十足，丝毫不差。”

如图2，顺炮打分吃亏70～100分，先天吃亏1.5先～2先（50分一个先手），也就是电脑打分认为：“后手顺炮略亏可下，弹性一般，先天吃亏。”

以上，笔者从两个方面证明了前面的结论：

面对先手中炮开局，后手顺炮布局是略亏可下的非必败开局，先天落后1.5先～2先。也就是假设下棋双方都没有犯错失误的情况下，先手中炮优势，后手顺炮只能顶和。

那么，问题又来了，知道了顺炮布局是吃亏的开局，我们学棋者还有必要去研究顺炮布局吗？答案是肯定的，顺炮布局是学棋者永远不可能避开的一个开局。
