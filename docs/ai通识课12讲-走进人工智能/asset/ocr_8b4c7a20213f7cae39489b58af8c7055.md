这种通用性和可扩展性远超以往任何 AI 模型，使得大语言模型成为未来 AGI 的核心技术之一。

为什么大语言模型代表通向 AGI 的关键一步？因为大模型具备“类通用智能”的特性。与深蓝和阿尔法狗的单一任务能力相比，ChatGPT 展现出多个接近通用智能的特征。

+   ( 1 ) 语言理解（能阅读并推理）。
+   ( 2 ) 知识整合（可结合不同领域的信息进行回答）。
+   ( 3 ) 上下文学习（可以根据对话历史调整回应）。
+   ( 4 ) 多模态扩展（可以理解文本、图片、音频，未来还可能扩展到视频）。
