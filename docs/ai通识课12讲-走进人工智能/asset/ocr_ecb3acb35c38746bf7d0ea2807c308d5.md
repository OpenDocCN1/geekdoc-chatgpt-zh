# 2. 解决复杂问题

如果你想去动物园，但公交车停运了，你可能会改骑自行车或者打车。
普通 AI 可能会卡住，而 AGI 能像人一样思考，找出新的解决办法。

# 3. 适应不同的环境

如果你搬家了，那么你需要适应新学校、新朋友、新课程。

流程，而不需要人类重新教它。

# 4. 具备创造力

你可以写一首歌、画一幅画，或者想出一个新点子。
未来的 AGI 可以自己写小说，甚至发现新的科学理论。

# 9.1.3 AGI 能做什么

如果 AGI 真的被发明出来，它可以帮助我们完成很多事情。

# 1. 医疗：帮助医生治病

AGI 可以帮医生更快地发现疾病，并提供更好的治疗方案，比如通过
分析大量医学数据，发现新的治疗方案；远程诊断病人，让偏远地区的人
们也能享受更好的医疗服务。

# 2. 科学研究：加速科技发展

AGI 可以帮助科学家做实验、分析数据，甚至探索新的物理定律。例
如，开发更环保的能源；设计更强大的太空飞船，帮助人类探索宇宙。

# 3. 机器人助手：做家务、照顾老人

未来的 AGI 机器人可以帮人做饭、打扫房间、洗衣服；陪伴老人聊
天，提醒他们按时吃药。
