称数据集 T 线性不可分。

# 2. 感知器的学习策略

假设训练数据集是线性可分的，感知器学习的目标是求得一个能够将训练集中正实例点和负实例点完全正确分开的分离超平面。为了找出这样的超平面，即确定感知器模型参数 w 和 b，需要确定一个学习策略，即定义（经验）损失函数并将损失函数极小化。

制订损失函数的一个参数选择是误分类点的总数，但这样的损失函数不是参数 w 和 b 的连续可导函数，不易优化。损失函数的另一个选择是误分类点到超平面 S 的总距离，这是感知器所采用的。为此，首先写出输入空间 R^n 中任一点 x_0 到超平面 S 的距离 D_{x_0} 为

$$D_{x_0} = \frac{1}{\|w\|}|wx_0 + b|$$ (7.24)

式中，\|w\| 为 w 的 L_2 范数。

其次，对于误分类的数据 (x_i, y_i) 来说，公式

$$-y_i(wx_i + b) > 0$$ (7.25)

成立。因为当 wx_i + b > 0 时，y_i = -1；而当 wx_i + b < 0 时，y_i = +1。所以，误分类点 x_i 到超平面 S 的距离 D_{x_i} 为

$$D_{x_i} = -\frac{1}{\|w\|}y_i(wx_i + b)$$ (7.26)

这样，假设超平面 S 的误分类点集合为 M，那么所有误分类点到超平面 S 的总距离 D 为

$$D = -\frac{1}{\|w\|}\sum_{x_i \in M} y_i(wx_i + b)$$ (7.27)

不需要考虑 \frac{1}{\|w\|}，就能得到感知器学习的损失函数。

感知器 sign(wx + b) 学习的损失函数定义为

$$L(w, b) = -\sum_{x_i \in M} y_i(wx_i + b)$$ (7.28)

式中，M 为误分类点的集合。

该损失函数就是感知器学习的经验风险函数。

显然，损失函数 L(w, b) 是非负的。如果没有误分类点，损失函数的值是 0。误分类点越少，误分类点离超平面越近，损失函数值就越小。一个特定的样本点的损失函数是指，在误分类时是参数 w、b 的线性函数，在正确分类时是 0。因此，给定训练数据集 T，损失函数 L(w, b) 是 w 和 b 的连续可导函数。

感知器学习的策略是在假设空间中选取使损失函数[式 (7.28)]最小的模型参数，即为感知器模型。

# 7.3.3 感知器学习算法

感知器学习问题通过将其转换为求解损失函数式的最优化问题解决，其中最优化方法是随机梯度下降法。本小节叙述感知器学习的具体算法，包括原始形式和对偶形式，并证明在训练数据线性可分条件下感知器学习算法的收敛性。
