# 1.3 人工智能的三大流派及其发展

在人工智能 80 多年的研究历程中，由于人们对智能本质的理解和认识不同，因此形成了多种不同的研究途径。不同的研究途径具有不同的学术观点，采用不同的研究方法，形成了不同的研究学派。目前，主要的研究学派包括符号主义、联结主义和行为主义等。符号主义方法以物理符号系统假设和有限合理性原理为基础，联结主义方法以人工神经网络模型为核心，行为主义方法侧重研究感知-行动的反应机制。

# 1. 符号主义

符号主义学派也称为功能模拟学派，其主要观点是智能活动的基础是物理符号系统，思维过程是符号模式的处理过程。

纽厄尔和西蒙在 1976 年的美国计算机学会（American for computing Machinery，ACM）图灵奖演说中对物理符号系统假设进行了总结，指出出现一般智能行为的物理系统的必要和充分条件是它为一个物理符号系统。充分性表明智能可以通过任意合理组织的物理符号系统来得到，必要性表明一个有一般智能的主体必须是一个物理符号系统的一个实例。物理符号系统假设的必要性要求一个智能体，不管它是人、外星人还是计算机，都必须通过在符号结构上操作的物理实现来获得智能。

以符号主义的观点来看，知识表示是人工智能的核心，认知就是处理符号，推理就是采用启发式知识及启发式搜索对问题求解的过程，推理过程可以用某种形式化的语言来描述。符号主义主张用逻辑的方法建立人工智能的统一理论体系，但是存在“常识”问题及不确定性事物的表示和处理问题。因此，该学派受到其他学派的批评。
