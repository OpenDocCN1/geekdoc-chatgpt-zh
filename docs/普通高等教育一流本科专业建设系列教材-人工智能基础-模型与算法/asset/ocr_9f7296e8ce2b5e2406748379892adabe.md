# # 1. 学习系统的概念

学习系统是指能够在一定程度上实现机器学习的系统。1973 年，萨里斯（Saris）曾对学习系统给过如下定义：如果一个系统能够从某个过程和环境的未知特征中学到有关信息，并且能够把学到的信息用于未来的估计、分类、决策和控制，以便改进系统的性能，那么它就是学习系统。1977 年，史密斯（Smith）给出了类似定义：如果一个系统在与环境相互作用时，能利用过去与环境作用时得到的信息，并提高其性能，那么这样的系统就是学习系统。

# ## 2. 学习系统的基本要求

通常，一个学习系统应该满足如下基本要求。

+   1) 具有适当的学习环境。前面两个关于学习系统的定义中都使用了“环境”这个术语。学习系统中的环境并非指通常的物理条件，而是指学习系统进行学习时所需的信息来源。
+   
+   2) 具有一定的学习能力。环境只是为学习系统提供了相应的信息和条件。要从中学习到知识，还须具有适当的学习方法和一定的学习能力。
+   
+   3) 能用所学知识解决问题。学以致用是对人类学习的一种要求，机器学习系统也是如此。在萨里斯的定义中明确指出，学习系统应该把学到的信息用于未来的估计、分类、决策和控制，以便改进系统的性能。事实上，无论是人还是学习系统，如果不能用学到的知识解决实际问题，就失去了学习的作用和意义。
+   
+   4) 能通过学习提高系统的性能。提高系统的性能是学习系统的最终目标。通过学习，系统增长知识，提高解决问题的能力，甚至能够完成原本不能完成的任务。

# ## 3. 学习系统的基本模型

通过以上分析可以看出，一个学习系统至少应包括 4 部分：环境、学习环节、知识库和执行环节。典型的机器学习系统如美国俄勒冈州立大学计算机科学的荣誉退休教授托马斯·G·迪特里奇（Thomas G. Dietterich）的学习模型，如图 7.5 所示。环境向系统的学习环节提供某些信息，学习环节利用这些信息修改知识库，增进执行环节的效能；执行环节根据知识库完成任务，同时把获得的信息再反馈给学习环节。

# ### (1) 环境与学习环节

环境中信息的水平和质量是影响学习系统设计的第一个重要因素。

信息的水平是指信息的一般化程度，或者指信息适用范围的广泛性。信息的一般化程度又是相对于执行环节而言的。高水平信息的一般化程度比较高，能适应更广泛的问题；低水平信息的一般化程度比较低，只适应个别问题。无论环境中的信息水平是高还是低，这些信息与执行环节所需信息的水平往往会有差距，而学习环节的任务就是缩小这一差距。
