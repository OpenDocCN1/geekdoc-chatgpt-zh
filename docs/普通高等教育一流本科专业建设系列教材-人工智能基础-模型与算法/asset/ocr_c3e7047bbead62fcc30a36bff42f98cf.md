令。命令又包括低级命令（如将发动机的电压设定为某个数值）和高级命令（如令一个机器人进行某些运动，如“启动”“到 s3 处标处”或者“匀速沿 S 形移动”等）。执行器与传感器类似，都包含噪声。例如，机器人在物理规则下运动，因此具备动量，且信息传递需要时间，接收到“匀速沿 S 形移动”指令的机器人也许最终只是沿着大概的方向行进，而并非沿标准 S 形移动，且速度和方向都是不断波动的，甚至运动到某一指定位置的行为可能会由于各种原因而失败。

为解决复杂问题的缓慢推理与 Agent 所需的针对高级目标的快速反应之间的矛盾，分层控制被提出。图 4.8 中所示为分层控制结构，每一层都将其下层看作一个可从中获取感知及发出命令的虚拟主体。越低层，反应速度越快，适用于那些需要快速反应的情况，且能将对环境更简单直白的感知传给高层，隐藏不重要的信息。总的来说，不同时间的状态之间会有大量的特征在层与层之间传递。

对于每个时刻的每一层，存在如下 3 类输入。

+   1) 来自信念状态的特征，指的是这些特征所记住的或以前的状态值。
+   2) 从下层结构得到的感知的特征。
+   3) 从上层结构得到的命令的特征。

对于每个时刻的每一层，存在如下 3 类输出。

+   1) 对应上层的更高等级的感知。
+   2) 对应下层的低等级命令。
+   3) 信念状态特征的下一个值。

层级的实现方式决定了层的输出是如何由输入函数得出的。此函数的计算可以涉及任意计算，目的是使每层尽可能简单。

为了实现控制器，层上的任何输入必须有确切的赋值来源，每个感知或者命令输入应该源自与其相连的其他层的输出。其他的输入来源于记住的信念。每层上的输出不必有相连对象，或者可与多个输入相连接。高级推理在高层上给出，一般是离散的、定性的；而底层中给出的低级推理则是连续的和定量的。一个可推理产生离散和连续两种值的控制器
