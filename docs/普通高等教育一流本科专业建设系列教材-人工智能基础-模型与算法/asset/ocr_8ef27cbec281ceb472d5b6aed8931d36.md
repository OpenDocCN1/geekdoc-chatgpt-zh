若已知输入为 A，则输出为 B：若现在已知输入为 A'，则输出 B' 用合成规则求取：

B' = A' \circ R \quad (5.84)

式中，模糊关系 R 为 A 和 B 的模糊关系，其隶属函数为 \(\mu_R(x,y) = \min[\mu_A(x), \mu_B(y)]\)。

控制规则库的 N 条规则有 N 个模糊关系：\(R_1, R_2, \dots, R_n\)。对于整个系统的全部控制规则，其对应的模糊关系 R 为

R = R_1 \cup R_2 \cup \dots \cup R_n = \bigcup_{i=1}^n R_i \quad (5.85)
