# 图 5.4 Dempster 合成规则的空间解释

横条和竖条的交是一个小矩形，其测度为 \(m_1(A_i)m_2(B_j)\)。由于该小矩形是同时分配到 \(A_i\) 和 \(B_j\) 上的，因此 \(M_1\) 和 \(M_2\) 的联合作用就是把 \(m_1(A_i)m_2(B_j)\) 确切地分配到 \(A_i \cap B_j\) 上。对于给定的子集 \(A\)，确切地分配到 \(A\) 上的总概率为

\(\sum_{A_i \cap B_j = A} m_1(A_i)m_2(B_j)\) (5.65)

当分配到空集上的总概率不为 0 时，需对其他非空集合上的总概率进行归一化。

# 5. 基于证据理论的不确定性推理

基于证据理论的不确定性推理步骤如下。

+   1) 建立问题的识别框架 \(\Omega\)。
+   2) 给幂集 \(2^\Omega\) 定义基本概率分配函数，基本概率分配函数可由经验给出，或者由随机规则的可信度度量计算求得。
+   3) 计算所关心的子集 \(A \in 2^\Omega\) 的信任函数 Bel(\(A\)) 或似然函数 Pl(\(A\))。
+   4) 由信任函数 Bel(\(A\)) 和似然函数 Pl(\(A\)) 得出结论。
