“所有鸟都会飞”，这与企鹅不会飞的事实相矛盾；也可表示为“除了企鹅、鸵鸟等的所有鸟都会飞”，这要求规则指定出所有的例外。默认逻辑致力于形式化这样的推理规则，而不需要明确提及所有的例外。

默认推理通常被用作非单调逻辑系统的推理规则。一个默认理论可能有多于一个的增广，且对正常理论来说，两个增广的并集是不一致的。

# 2. 按推理时所用知识的确定性划分

按推理时所用知识的确定性划分，推理可分为确定性推理和不确定性推理。

# (1) 确定性推理

确定性推理是指推理时所用的知识与证据都是确定的，推出的结论也是确定的，如一个事件是否为真，其推理的结果只能是真或是假，绝对不可能出现第三种可能性。经常提到的确定性推理包括自然演绎推理、归结演绎推理和与/或型演绎推理等。自然演绎推理是从一组已知为真的事实出发，直接运用经典逻辑中的推理规则推出结论；归结演绎推理是基于鲁宾逊（Robinson）归结原理的推理过程；与/或型演绎推理将领域知识和已知事实分别用蕴涵式和与/或式表示，然后运用蕴涵式进行演绎推理，从而证明某个目标公式。

确定性推理的方法有图搜索策略、盲目搜索、启发式搜索、消解原理、规则演绎系统、产生式系统等。图搜索控制策略可以看成一种在图中寻找路径的方法。初始节点和目标节点分别代表初始数据库和满足终止条件的目标数据库。求把一个数据库变换为另一个数据库的规则序列问题就等价于求图中的一条路径问题。不需要重新安排 OPEN 表的搜索称为无信息搜索或盲目搜索，它包括宽度优先搜索、深度优先搜索和等代价搜索等。盲目搜索的效率低，且会消耗过多的计算空间和时间。如果能够找到一种方法用于排列待扩展节点的顺序，即选择最有希望的节点加以扩展，搜索效率将会大大提高。在许多情况下，能够通过检测来确定合理的顺序，这种方法就是启发式搜索。消解是一种可用于一定的子句公式的重要推理规则。子句定义为由文字的析取组成的公式，当消解可以使用时，消解过程被应用于子母体子句对，以产生一个导出子句。规则演绎系统使用 IF-THEN 形式的规则匹配断言，IF 部分称为前项，THEN 部分称为后项。产生式系统通过一组产生式的协同工作以求得问题的解。

# (2) 不确定性推理

不确定性推理所用的知识与证据有些是不确定的，因此它得到的是具有一定程度的不确定性，但却是合理或者近乎合理的结论。不确定性可以理解为在缺少足够信息的情况下做出判断，是智能问题的本质特征；推理是人类的思维过程。

不确定性推理采用数值表示和非数值语义表示两种方法来描述不确定性。在领域专家给出的规则强度和用户给出的原始证据不确定性的基础上，定义一组函数，求出结论的不确定性度量。为了获得新信息，推理过程中的不确定性的传递算法需要关注，即在每一步推理中，如何把证据和知识的不确定性传递给并融合到结论中。组合证据的不确定性方法包括最大最小法、概率方法和有界方法等。
