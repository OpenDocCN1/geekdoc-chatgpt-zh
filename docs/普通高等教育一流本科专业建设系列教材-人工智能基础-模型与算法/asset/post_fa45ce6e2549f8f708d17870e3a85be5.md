
$P \to Q, \neg Q \Rightarrow \neg P$

例如，由“如果下雨，那么会有人带伞”和“没有人带伞”可以推导出“没有下雨”的结论。

假言三段论表示由 $P \to Q$ 及 $Q \to R$ 为真，可以推出 $P \to R$ 为真，其一般形式为

$P \to Q, Q \to R \Rightarrow P \to R$

例如，由“如果今天下雨，那么今天要带伞”和“如果带了伞，那么不会淋雨”可以推导出“今天下雨，不会淋雨”的结论。

在自然演绎推理中要避免两种错误：肯定<后件>的错误及否定<前件>的错误。

肯定<后件>的错误是指当 $P \to Q$ 为真时，希望通过肯定<后件>$Q$ 为真来推出<前件>$P$ 为真，这是不允许的。主要原因是当 $P \to Q$ 及 $Q$ 为真时，<前件>$P$ 既可能为真，也可能为假。例如：

- P: 如果玩电脑游戏，则需要用电脑。
- Q: 他在用电脑。
- 所以，他在玩电脑游戏。
- 这就是使用了肯定<后件>的推理，显然是不正确的，因为用电脑不一定是在玩电脑游戏，还可能在干其他事情。

否定<前件>的错误是指当 $P \to Q$ 为真时，希望通过否定<前件>$P$ 为假来推出<后件>$Q$ 为假，这是不允许的。主要原因是当 $P \to Q$ 及 $P$ 为假时，<后件>$Q$ 既可能为真，也可能为假。例如：

- P: 如果看书，则能获得新知识。
- Q: 没有看书。
- 所以，没有获得新知识。
- 这就是使用了否定<前件>的推理，显然是不正确的，因为获得新知识的方式不止看书这一种，通过听老师讲课也能获得新知识。

下面通过例题说明自然演绎推理方法。

### 例 4.6 已知：

- 所有的英语老师小明都喜欢。
- 教英语写作的老师都是英语老师。
- 王老师是一名教英语写作的老师。
- 求证：小李喜欢王老师。

证明 首先定义谓词，得

- Eng (x), x 是英语老师。
- Like (x, y), x 喜欢 y。
- Write (x), x 是一名英语写作老师。

把已知事实及待求解的问题用谓词公式表示如下：

```
\(\forall_x [Eng(x) \to Like(Li, x)]\)
\(\forall_x [Write(x) \to Eng(x)]\)
Write(x)
Like(Li, Wang)
```

利用推理规则进行推理，得
Eng(y) → Like(Li, y) 全称固化
Write(z) → Eng(z) 全称固化
Write(Wang), Write(z) → Eng(z) ⇒ Eng(Wang) 假言推理
Eng(Wang), Eng(y) → Like(Li, y) ⇒ Like(Li, Wang) 假言推理

因此小李喜欢王老师。

一般来说，自然演绎推理由已知事实推出的结论可能有多个，只要包含了需要证明的结论，就认为问题得到了解决。

自然演绎推理是经典逻辑推理中的一种代表形式，也可以说是机械-自动定理证明中的一种代表形式。一方面，这种推理定理证明过程自然，容易理解，且其拥有丰富的推理规则，推理过程灵活，便于在它的推理规则中嵌入领域启发式知识；另一方面，自然演绎推理容易产生组合爆炸，推理过程中得到的中间结论一般呈指数形式递增，对于复杂问题的推理不利，甚至难以实现。

## 4.2.4 归结推理方法

归结推理方法是与自然演绎推理方法完全不同的逻辑演算算法，它是一阶逻辑中迄今为止最有效的半可判定算法，也是最适合计算机进行推理的逻辑演算方法。之所以称其为半可判定，是因为一阶逻辑中任意恒真公式使用归结原理，总可以在有限步内给予判定（证明其为永真式）；而当不知该公式是否为恒真时，使用归结原理不能得到任何结论。

### 1. 子句集

### (1) 子句集的化简

在谓词逻辑中有如下述定义。

定义 4.1 原子谓词公式及其否定统称为文字。
例如， P(x)、Q(x)、¬P(x)、¬Q(x) 等都是文字。

定义 4.2 任何文字的析取式称为子句。
例如， P(x) ∨ Q(x)、P[x, f(x)] ∨ Q[x, g(x)] 都是子句。

定义 4.3 不含任何文字的子句称为空子句。
由于空子句不含有任何文字，也就不能被任何解释所满足，因此空子句是永假的，不可满足的。空子句一般记为 NIL。

定义 4.4 由子句或空子句构成的集合称为子句集。
在谓词逻辑中，任何一个谓词公式都可以通过应用等价关系及推理规则化成相应的子句集，从而能够比较容易地判定谓词公式的不可满足性。其化简步骤如下。

1）消去谓词公式中的联结词 “ → ” “ ↔ ” 。使用以下公式即可消去联结词。

P → Q ⇔ ¬P ∨ Q (4.4)
P ↔ Q ⇔ (P ∧ Q) ∨ (¬P ∧ ¬Q) (4.5)

2）减少否定符号的辖域。用下列公式将否定符号移到紧靠谓词的位置上。

德·摩根定律：

¬(P ∨ Q) ⇔ ¬P ∧ ¬Q (4.6)
¬(P ∧ Q) ⇔ ¬P ∨ ¬Q (4.7)

### 双重否定定律：
\(\neg(\neg P) \Leftrightarrow P\) (4.8)

### 量词转换定律：
\(\neg(\exists x)P \Leftrightarrow (\forall x)\neg P\) (4.9)
\(\neg(\forall x)P \Leftrightarrow (\exists x)\neg P\) (4.10)

### 3) 变元标准化。

在一个量词的辖域内，把谓词公式中受该量词约束的变元全部用另外一个没有出现过的任意变元代替，使不同量词约束的变元有不同的名字。

```
(\forall x)P(x) \equiv (\forall y)P(y) (4.11)
(\exists x)P(x) \equiv (\exists y)P(y) (4.12)
```

### 4) 化为前束式。

前束式就是把所有的全称量词都移到公式的前面，并且在移动时不能改变其相对顺序，使每个量词的狭域都包括公式后的整个部分，即

```
前束式={全称量词串}{不含全称量词的式子}
```

### 5) 消去存在量词。

消去存在量词时，需要区分以下两种情况。若存在量词不出现在全称量词的辖域内（它的左边没有全称量词），则只用一个新的个体常量替换受该存在量词约束的变元，就可消去该存在量词；若存在量词位于一个或多个全称量词的辖域内，如：

```
(\forall x_1)(\forall x_2)\cdots(\forall x_n)(\exists y)P(x_1, x_2, \cdots, x_n, y)
```

则需先使用存在量词 y 的 Skolem 函数 \(y = f(x_1, x_2, \cdots, x_n)\) 替换该存在量词约束的变元 y，然后消去该存在量词。通常所说的 Skolem 化，就是用 Skolem 函数代替每个存在量词量化的过程。

### 6) 化为 Skolem 标准型。

Skolem 标准型的一般形式为

```
(\forall x_1)\cdots(\forall x_n)M(x_1, x_2, \cdots, x_n)
```

式中，\(M(x_1, x_2, \cdots, x_n)\) 是 Skolem 标准型的母式，它由子句的合取构成。

把谓词公式化为 Skolem 标准型需要使用以下等价关系：

```
\(P \lor (Q \land R) \Leftrightarrow (P \lor Q) \land (P \lor R)\) (4.13)
\(P \land (Q \lor R) \Leftrightarrow (P \land Q) \lor (P \land R)\) (4.14)
```

### 7) 消去全称量词。

由于子式中的全部变元均受全称量词的约束，并且全称量词的次序已无关紧要，因此可以省略全称量词。但剩下的子式仍假设其变元是被全称量词量化的，即全称量词串直接省略不写。

### 8) 消去合取词。

在子式中消去所有合取词，把子式用子句集的形式表示出来，子句集中的每一个元素都是一个子句。

### 9) 变量名称标准化。

对子句集中的某些变量重新命名，使任意两个子句中不出现相同的变量名。由于每个子句都对应着母式中的一个合取元，并且所有变元都是由全称量词量化的，因此任意两个不同子句的变量之间实际上不存在任何关系。这样，更换变量名是不会影响公式的真值的，即不同字母用不同的变元。

### [例 4.7] 化简子句集。

```
(\forall x)\{(\forall y)P(x, y) \rightarrow \neg(\forall y)[Q(x, y) \rightarrow R(x, y)]\}
```

### 1) 消去蕴涵符号。经等价变换后，得

```
(\forall x)\{\neg(\forall y)P(x, y) \lor \neg(\forall y)[\neg Q(x, y) \lor R(x, y)]\}
```

### 2) 减少否定符号的辖域，把否定符号移到每个谓词前面。上式经变换后，得

(\forall x)\{(\exists y)\neg P(x,y) \lor (\exists y)[Q(x,y) \land \neg R(x,y)]\}

3） 对变元标准化。上式经变换后，得

(\forall x)\{(\exists y)\neg P(x,y) \lor (\exists z)[Q(x,z) \land \neg R(x,z)]\}

4） 化为前束范式。上式经变换后，得

(\forall x)\{(\exists y)(\exists z)\neg P(x,y) \lor [Q(x,z) \land \neg R(x,z)]\}

5） 消去存在量词。上式中存在量词 \exists y 和 \exists z 都位于 \forall x 的辖域内，因此都需要用函数来替换。设 y 和 z 的 Skolem 函数分别为 f(x) 和 g(x)，有

(\forall x)\{\neg P[x, f(x)] \lor \{Q[x, g(x)] \land \neg R[x, g(x)]\}\)

6） 化为 Skolem 标准型。上式化为 Skolem 标准型后为

(\forall x)\{\neg P[x, f(x)] \lor Q[x, g(x)]\} \land \{\neg P[x, f(x)] \lor \neg R[x, g(x)]\}

7） 略去全称量词。

\{\neg P[x, f(x)] \lor Q[x, g(x)]\} \land \{\neg P[x, f(x)] \lor \neg R[x, g(x)]\}

8） 取消合取词。上式的子句集中包含以下两个子句：

\neg P[x, f(x)] \lor Q[x, g(x)]
\neg P[x, f(x)] \lor \neg R[x, g(x)]

9） 变量名称标准化。对于上面两个子句，可把第二个子句中的变元名 x 更换为 y，得到下列子句集：

\neg P[x, f(x)] \lor Q[x, g(x)]
\neg P[y, f(y)] \lor \neg R[y, g(y)]

### (2) 子句集的应用

在上述化简过程中，由于在消去存在量词时所用的 Skolem 函数可以不同，因此化简后的标准子句集是不唯一的。当原谓词公式为非永假时，它与其标准子句集并不等价；但当原谓词公式为永假（或不可满足）时，其标准子句集则一定是永假的，即 Skolem 化并不影响原谓词公式的永假性。

该结论很重要，是归结原理的主要依据，可用定理的形式来描述。

### 定理 4.1 谓词公式不可满足的充分必要条件是其子句集不可满足。

由此定理可知，要证明一个谓词公式是不可满足的，只要证明其相应的子句集是不可满足的即可。

### 2. 鲁滨逊归结原理

归结演绎推理是一种基于鲁滨逊归结原理的机器推理方法。鲁滨逊归结原理也称为消解原理，是鲁滨逊于 1965 年在海伯伦（Herbrand）理论的基础上提出的一种基于逻辑的“反证法”。专家学者在进行大量的探索后发现，对于前提 P 推导至结论 Q 这一过程的永真证明可以采用反证法的思想，把关于永真性的证明转换为关于不可满足性的证明。这方面最有成效的工作就是鲁滨逊归结原理，它使定理证明的机械化成为可能。

由谓词公式转换为子句集的方法可知，在子句集中子句之间是合取关系。其中，只要有一个子句为不可满足，则整个子句集就是不可满足的；另外，前面已经指出空子句是不可满足的。因此，一个子句集中如果包含有空子句，则此子句集就不可满足。

鲁滨逊归结原理就是基于上述认识提出来的，其基本思想是：首先把欲证明问题的结论否定，并加入子句集，得到一个扩充的子句集 S'；然后设法检验子集 S'是否含有空子句。若含有空子句，则表明 $S'$ 是不可满足的；若不含有空子句，则继续使用归结法，在子句集中选择合适的子句进行归结，直至导出空子句或不能继续归结为止。鲁滨逊归结原理可分为命题逻辑归结原理和谓词逻辑归结原理。

### (1) 命题逻辑归结原理

归结原理的核心是求两个子句的归结式，因此需要先讨论归结式的定义和性质，再讨论命题逻辑的归结过程。

**定义 4.5** 若 $P$ 是原子谓词公式，则称 $P$ 与 $\neg P$ 为互补文字。

**定义 4.6** 设 $C_1$ 和 $C_2$ 是子句集中的任意两个子句，如果 $C_1$ 中的文字 $L_1$ 和 $C_2$ 中的文字 $L_2$ 互补，那么可从 $C_1$ 和 $C_2$ 中分别消去 $L_1$ 和 $L_2$，并将 $C_1$ 和 $C_2$ 中余下的部分按析取关系构成一个新的子句 $C_{12}$，称这一过程为归结，称 $C_{12}$ 为 $C_1$ 和 $C_2$ 的归结式，称 $C_1$ 和 $C_2$ 为 $C_{12}$ 的亲本子句。

**例 4.8** 设 $C_1 = P \lor Q \lor R$，$C_2 = \neg P \lor S$，求 $C_1$ 和 $C_2$ 的归结式 $C_{12}$。

**解** 这里 $L_1 = P$，$L_2 = \neg P$，通过归结可以得到 $C_{12} = Q \lor R \lor S$。如果改变归结顺序，那么同样可以得到相同的结果，即其归结过程不是唯一的。

**定理 4.2** 归结式 $C_{12}$ 是亲本子句 $C_1$ 和 $C_2$ 的逻辑蕴含。

该定理是归结原理中的一个重要定理，由它可以得到如下两个推论。

**推论 4.1** 设 $C_1$ 和 $C_2$ 是子句集 $S$ 中的两个子句，$C_{12}$ 是 $C_1$ 和 $C_2$ 的归结式，若用 $C_{12}$ 代替 $C_1$ 和 $C_2$ 后得到新的子句集 $S_1$，则由 $S_1$ 的不可满足性可以推出原子句集 $S$ 的不可满足性，即
$S_1$ 的不可满足性 $\Rightarrow S$ 的不可满足性

**推论 4.2** 设 $C_1$ 和 $C_2$ 是子句集 $S$ 中的两个子句，$C_{12}$ 是 $C_1$ 和 $C_2$ 的归结式，若把 $C_{12}$ 加入 $S$ 中得到新的子句集 $S_2$，则 $S_2$ 与 $S$ 的不可满足性是等价的，即
$S_2$ 的不可满足性 $\Leftrightarrow S$ 的不可满足性

由此得到下列结论。

- 1) 为证明子句集 $S$ 的不可满足性，只要对其中可进行归结的子句进行归结，并把归结式加入子句集 $S$ 中；或者用归结式代替它的亲本子句，并对新的子句集证明其不可满足性即可。

- 2) 如果经归结得到空子句，根据空子句的不可满足性，即可得到原子句集 $S$ 是不可满足的结论。在命题逻辑中，对不可满足的子句集 $S$，其归结原理是完备的。这种不可满足性可用如下定理描述。

**定理 4.3** 子句集 $S$ 是不可满足的，当且仅当存在一个从 $S$ 到空子句的归结过程。

### (2) 命题逻辑的归结反演

归结的原理是，假设 $F$ 为已知前提，$G$ 为欲证明的结论，把证明 $G$ 为 $F$ 的逻辑结论转换为证明 $F \land \neg G$ 为不可满足。

由于在不可满足的意义上，公式集 $F \land \neg G$ 与其子句集是等价的，即把公式集上的不可满足转换为子句集上的不可满足。应用归结原理证明定理的过程称为归结反演。

以已知命题 $F$，证明命题 $G$ 为例，命题逻辑归结反演的过程如下。

- 1) 否定目标公式 $G$，得 $\neg G$。

- 2) 把 $\neg G$ 并入公式集 $F$ 中，得到 $\{F, \neg G\}$。

- 3) 把 $\{F, \neg G\}$ 化为子句集 $S$。

- 4) 应用归结原理对子句集 S 中的子句进行归结，并把每次得到的归结式并入 S 中。如此反复进行，若出现空子句，则停止归结，此时就证明了 G 为真。

### (3) 谓词逻辑归结原理

在谓词逻辑中，由于子句集中的谓词一般含有变元，因此不能像命题逻辑那样直接消去互补文字，而需要先用一个最一般合一对变元进行代换，然后才能进行归结。由此可见，谓词逻辑的归结要比命题逻辑的归结麻烦。

定义 4.7 C1 和 C2 是两个没有公共变元的子句，L1 和 L2 分别是 C1 和 C2 中的文字。如果 L1 和 L2 存在最一般合一 σ，则称

```
C12 = {(C1σ - {L1σ}) ∪ {(C2σ - {L2σ}) （4.15）
```

为 C1 和 C2 的二元归结式，而 L1 和 L2 为归结式上的文字。

例 4.9 设 C1 = P(a) ∨ R(x)，C2 = ¬P(y) ∨ Q(b)，求 C12。

解 取 L1 = P(a)，L2 = ¬P(y)，则 L1 和 L2 的最一般合一为 σ = {a/y}。

```
C12 = {(C1σ - {L1σ}) ∪ {(C2σ - {L2σ}) = {(P(a), R(x)) - {P(a))} ∪ {(¬P(a), Q(b)) - {¬P(a))} = {(R(x))} ∪ {(Q(b))} = {R(x), Q(b)} = R(x) ∨ Q(b)
```

例 4.10 设 C1 = P(x) ∨ Q(a)，C2 = ¬P(b) ∨ R(x)，求 C12。

解 由于 C1 和 C2 有相同的变元 x，因此不符合定义的要求。为了进行归结，需要修改 C2 中变元 x 的名字，令 C2 = ¬P(b) ∨ R(y)。此时 L1 = P(x)，L2 = ¬P(b)，L1 和 L2 的最一般合一是 σ = {b/x}，则有

```
C12 = {(C1σ - {L1σ}) ∪ {(C2σ - {L2σ}) = {(P(a), Q(x)) - {P(b))} ∪ {(¬P(b), R(y)) - {¬P(b))} = {(Q(a))} ∪ {(R(y))} = {Q(a), R(y)} = Q(a) ∨ R(y)
```

例 4.11 设 C1 = P(x) ∨ P[f(a)] ∨ Q(x)，C2 = ¬P(y) ∨ P(b)，求 C12。

解 对参加归结的某个子句，若其内部有可合一的文字，则在进行归结之前应先对这些文字进行合一。本例的 C1 中有可合一的文字 P(x) 与 P[f(a)]，若用它们的最一般合一 σ = {f(a)/x} 进行代换，可得到

```
C1σ = P[f(a)] ∨ Q[f(a)]
```

此时可对 C1σ 与 C2 进行归结。选 L1 = P[f(a)]，L2 = ¬P(y)，L1 和 L2 的最一般合一是 σ = {f(b)/y}，则可得到 C1 和 C2 的二元归结式为

```
C12 = R(b) ∨ Q[f(a)]
```

把 C1σ 称为 C1 的因子。一般来说，若子句 C 中有两个或两个以上的文字具有最一般合一 σ，则称 Cσ 为子句 C 的因子。如果 Cσ 是一个单文字，则称其为 C 的单元因子。
