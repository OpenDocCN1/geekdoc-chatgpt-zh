# 证明

$f^*(n') = g^*(n') + h^*(n')$
$= K(s, n') + \min K(n', g)$
$= \min K(n, g)$
$= C^* (\forall g \in G)$

从性质 3.1 可以得到下面的结论：① \(f^*(s) = C^*\) ； ② \(f^*(g) = C^*\) 。

性质 3.2 任何节点 n，如果不在任何一条最优路径上，则

\(f^*(n) > C^*\) （3.19）

证明 该性质可以直接从性质 3.1 得到。关于启发式函数，给出下面的定义。

定义 3.1 如果有 \(h(n) \leqslant h^*(n)\)，则启发式函数 h 称为可采纳的。

性质 3.3 在 \(A^*\) 算法结束之前，在 \(P'_{s \sim G}\) 上存在 Open 节点 \(n'\)，有 \(f^*(n') \leqslant C^*\)。

证明 考虑 \(P'_{s \sim G}\) 中的一条最优路径 \(P'_{s \sim g}\)。假设 \(P'_{s \sim g}\) 为 \(n_1, n_2, \cdots, n', \cdots, g\)，并令 \(n'\) 是 \(P'_{s \sim G}\) 上深度最浅的 Open 节点。由于在算法结束前 g 并不是 Close 节点，因此 \(n'\) 是 Open 节点。另外，由于 \(n'\) 的所有祖先都是 Close 节点，因此 \(s, n_1, n_2, \cdots, n'\) 是最优路径，指针一定是沿着路径 \(P'_{s \sim g}\) 的。因此，有 \(g(n') = g^*(n')\)。这样：

\(f(n') = g^*(n') + h(n')\)
\(\leqslant g^*(n') + h(n')\) （根据启发式函数可采纳性的定义）
\(= f^*(n')\)
\(= C^*\)

性质 3.4 \(A^*\) 算法是可采纳的。

证明 假设 \(A^*\) 算法终止在目标节点点 \(t \in G\) 上，并且 \(f(t) = g(t) = C^*\)，然而在 \(A^*\) 算法中，如果 \(t\) 被选作扩展节点，则对所有 Open 节点 n 有 \(f(t) \leqslant f(n)\)。这说明在算法终止之前，OPEN 表中任何节点 n 都有 \(f(t) > C^*\)。然而，这与性质 3.3 相矛盾，因此如果算法终止在节点 t，则一定有 \(g(t) = C^*\)，即 \(A^*\) 找到的是最优路径。

定义 3.2 对所有 \((n, n')\)，如果满足 \(h(n) \leqslant C(n, n') + h(n') \leqslant C\)，\(n'\) 是 n 的后继，则称该启发式函数是单调的。

性质 3.5 每个一致的启发式函数是可采纳的。

证明 由于 \(h(n)\) 是一致的，因此

\(h(n) \leqslant K(n, n') + h(n')\)

用 g 代替 \(n'\)，则

\(h(n) \leqslant K(n, g) + h(g)\)
\(\Rightarrow h(n) \leqslant h^*(n)\)

这就是可采纳性条件。

对于八数码游戏，从当前被扩展节点 x 到目标状态节点的最短路径——棋牌移动的最少次数必定不少于错位棋牌的个数（因为有些棋牌可能需要移动多于一次才能到达目标状态的相应位置），也必定不会少于错位棋牌不受阻挡情况下移动到目标状态相应位置的移动次数总和（因为有些棋牌的移动可能受阻挡），从而采用 w(x) 和 p(x) 作为评价函数时，A 算法都是可采纳的。
