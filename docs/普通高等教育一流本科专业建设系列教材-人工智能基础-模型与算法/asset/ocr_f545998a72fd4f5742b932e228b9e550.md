\(R^l_{MIMO} : (x \text{ is } A_i \text{ AND } \cdots \text{ AND } y \text{ is } B_i) \text{ THEN } (z_1 \text{ is } C_i)\)
\(\vdots\)
\(R^q_{MIMO} : (x \text{ is } A_i \text{ AND } \cdots \text{ AND } y \text{ is } B_i) \text{ THEN } (z_q \text{ is } D_i)\)

\(R_1\): IF x is \(A_1\) AND y is \(B_1\) THEN z is \(C_1\)

\(\vdots\)
also \(R_n\): IF x is \(A_n\) AND y is \(B_n\) THEN z is \(C_n\)

输入： \(x\) is \(A'\) AND \(y\) is \(B'\)
输出： \(z\) is \(C'\)

其模糊控制规则为

IF x is \(A_i\) AND y is \(B_i\) THEN z is \(C_i\)

其模糊蕴涵关系为

\(R_i = (A_i \text{ AND } B_i) \rightarrow C_i\)
\(\mu_{R_i} = [\mu_{A_i}(x) \text{ AND } \mu_{B_i}(y)] \rightarrow \mu_{C_i}(z)\)

\(N\) 条模糊控制规则的总的模糊蕴涵关系为

\(R = R_1 \cup R_2 \cup \cdots \cup R_n = \bigcup_{i=1}^n R_i\)

推理的结论为

\(C' = (A' \text{ AND } B') \circ R\)
\(\mu_{(A' \text{ AND } B')}(x,y) = \mu_{(A')}(x) \wedge \mu_{(B')}(y)\)
