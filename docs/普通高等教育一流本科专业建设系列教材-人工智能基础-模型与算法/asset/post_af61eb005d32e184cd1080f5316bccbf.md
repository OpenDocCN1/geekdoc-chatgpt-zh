
$$P(\neg H | E) = \frac{P(E|\neg H) \times P(\neg H)}{P(E)}$$

式（5.27）除以式（5.28）得

$$\frac{P(H|E)}{P(\neg H|E)} = \frac{P(E|H)}{P(E|\neg H)} \times \frac{P(H)}{P(\neg H)}$$

由充分性度量 LS 和几率函数 O(E) 的定义可得

$$O(H|E) = LS \times O(H)$$

即

$$P(H|E) = \frac{LS \times P(H)}{(LS-1) \times P(H) + 1}$$

对于知识

IF E THEN (LS,LN) H[P(H)]

当证据 E 肯定存在时，可以根据 LS 给出结论 H 的可信度 P(H|E)。

当 LS>1 时，O(H|E) = LS × O(H) > O(H)，相应地有 P(H|E) > P(H)，表明由于证据 E 的存在，可增强 H 为真的程度（有利证据）；当 LS=1 时，O(H|E) = LS × O(H) = O(H)，表明 E 与 H 无关（无关证据）；当 LS<1 时，O(H|E) = LS × O(H) < O(H)，表明由于证据 E 的存在，减小了 H 为真的程度（不利证据）；当 LS=0 时，O(H|E) = LS × O(H) = 0，表明由于证据 E 的存在，导致 H 为假（否定性的证据）。

2）证据肯定不存在。

当证据肯定不存在时 P(E) = P(E|S) = 0, \( P(\neg E) = 1 \)。

由贝叶斯公式得

$$P(H|\neg E) = \frac{P(\neg E|H) \times P(H)}{P(\neg E)}$$

$$P(\neg H|\neg E) = \frac{P(\neg E|\neg H) \times P(\neg H)}{P(\neg E)}$$

式（5.31）除以式（5.32）得

$$\frac{P(H|\neg E)}{P(\neg H|\neg E)} = \frac{P(\neg E|H)}{P(\neg E|\neg H)} \times \frac{P(H)}{P(\neg H)}$$

根据必要性度量 LN 和几率函数 O(E) 的定义，可得

$$O(H|\neg E) = LN \times O(H)$$

即

$$P(H|\neg E) = \frac{LN \times P(H)}{(LN-1) \times P(H) + 1}$$

对于知识

IF E THEN (LS,LN) H[P(H)]

当证据 E 肯定不存在时，可以根据 LN 给出结论 H 的可信度 P(H|\neg E)。

当 LN < 1 时，O(H|\neg E) = LN × O(H) < O(H)，表明由于证据 E 不存在，减小了 H 为真的程度（\neg E 为不利证据），一般情况下 LN < 1。

当 LN = 0 时，O(H|\neg E) = LN × O(H) = 0，表明由于证据 E 不存在，导致 H 为假（表明了证据 E 的必要性）。

当 LN = 1 时，O(H|\neg E) = LN × O(H) = O(H)，表明 \neg E 与 H 无关。

当 LN > 1 时，O(H | ¬E) = LN × O(H) > O(H)，相应有 P(H | ¬E) > P(H)，表明由于证据 E 不存在，增强了 H 为真的程度（ ¬E 为有利证据）。
所以，一般情况下，取 LS > 1， LN < 1。

### 3）证据不确定。

当 0 < P(E|S) < 1 时，可以证明

P(H|S) = P(H|E) × P(E|S) + P(H|¬E) × P(¬E|S) (5.35)

当 P(E|S) = 1 时，证据肯定存在，此时

P(H|S) = P(H|E) (5.36)

当 P(E|S) = 0 时，证据肯定不存在，此时

P(H|S) = P(H|¬E) (5.37)

当 P(E|S) = P(E) 时，证据 E 与观察 S 无关。由全概率公式得

P(H|S) = P(H|E) × P(E) + P(H|¬E) × P(¬E) = P(H) (5.38)

当 P(E|S) 为其他值时，通过分段线性插值计算 P(H|S)，即

P(H|S) = \begin{cases} P(H|¬E) + \frac{P(H) - P(H|¬E)}{P(E)} × P(E|S), 0 \leqslant P(E|S) < P(E) \\ P(H) + \frac{P(H|E) - P(H)}{1 - P(E)} × [P(E|S) - P(E)], P(E) \leqslant P(E|S) \leqslant 1 \end{cases} (5.39)

对于知识

IF E THEN(LS,LN) H[P(H)]

给定证据 E 的不确定性度量 P(E|S)，则结论的可信度可表示为

P(H|S) = \begin{cases} P(H|¬E) + \frac{P(H) - P(H|¬E)}{P(E)} × P(E|S), 0 \leqslant P(E|S) < P(E) \\ P(H) + \frac{P(H|E) - P(H)}{1 - P(E)} × [P(E|S) - P(E)], P(E) \leqslant P(E|S) \leqslant 1 \end{cases} (5.40)

该公式称为 EH 公式。用 C(E|S) 代替 P(E|S)，可得到等价的 CP 公式为

P(H|S) = \begin{cases} P(H|¬E) + [P(H) - P(H|¬E)] × [\frac{1}{5} C(E|S) + 1], C(E|S) \leqslant 0 \\ P(H) + [P(H|E) - P(H)] × \frac{1}{5} C(E|S), C(E|S) > 0 \end{cases} (5.41)

### (5) 结论不确定性的合成算法

若有 n 条知识都支持相同的结论，而且每条知识的前提条件所对应的证据 Ei(i = 1,2,...,n) 都有相应的观察 Ai 与之对应，此时只要先对每条知识分别求出几率函数 O(H | Ai)，即可运用下述公式求出 O(H | A1 ∩ A2 ∩ ... ∩ An)。这就是多因一果时，计算一果的不确定度的方法：

O(H | A1 ∩ A2 ∩ ... ∩ An) = \frac{O(H | A1)}{O(H)} × \frac{O(H | A2)}{O(H)} × ... × \frac{O(H | An)}{O(H)} × O(H) (5.42)

式中， A1 -> B, A2 -> B, ..., An -> B，且 A1, A2, ..., An 相互独立。

### 例 5.3 已知 P(A) = 1， P(B1) = 0.04， P(B2) = 0.02，规则如下：

- R1: A -> B1 LS = 20 LN = 0.1
- R2: B1 -> B2 LS = 300 LN = 0.001

要求计算 $P(B_2|A)$。

解 当使用规则 $R_2$ 时，证据 $B_1$ 并不是确定的发生了，即 $P(B_1) \neq 1$，因此要采用插值方法。

先依照 $A$ 必然发生，由定义和 $R_1$ 得

```
O(B_1) = \frac{0.04}{1-0.04} = 0.0417
O(B_1|A) = LS \times O(B_1) = 0.834
P(B_1|A) = \frac{0.834}{1+0.834} = 0.455
```

然后，由于 $P(B_1|A) = 0.455 > P(B_1)$，假设 $P(B_1|A) = 1$，计算

```
P(B_2|B_1) = 300 \times \frac{0.02}{300 \times 0.02 + 1} = 0.857
```

最后进行插值

```
P(B_2|A) = 0.02 + \frac{0.857 - 0.02}{1-0.04} \times (0.455 - 0.04) = 0.382
```

### 【例 5.4】已知证据 $A$ 必然发生，且有 $P(B_1)=0.03$， $P(B_2)=0.01$，规则如下：

- $R_1 : A \rightarrow B_1 \quad LS = 20 \quad LN = 0.1$
- $R_2 : B_1 \rightarrow B_2 \quad LS = 300 \quad LN = 0.0001$

求 $B_2$ 的更新值。

解 由于 $B_1$ 不确定，因此讨论其前项证据 $A$ 的影响时使用插值法。

当 $A$ 必然发生时，依据 $R_1$， $P(B_1) = 0.03$，

```
O(B_1) = \frac{P(B_1)}{1-P(B_1)} = \frac{0.03}{1-0.03} = 0.030928
O(B_1|A) = LS \times O(B_1) = 20 \times 0.030928 = 0.61856
P(B_1|A) = \frac{O(B_1|A)}{1+O(B_1|A)} = 0.382
```

当 $P(B_1|A)=1$ 时：

```
P(B_2|B_1) = P(B_2|A) = \frac{LS \times P(B_2)}{(LS-1) \times P(B_2) + 1} = \frac{300 \times 0.01}{(300-1) \times 0.01 + 1} = 0.75188
```

当 $A$ 对 $B_1$ 无影响时，假设 $P(B_1|A) = P(B_1) = 0.03$，又已知 $P(B_2) = 0.01$，根据以上 3 个值可进行插值运算。

由于 $P(B_1) = 0.03 < P(B_1|A) = 0.382$，因此：

```
P(B_2|A) = P(B_2) + \frac{P(B_2|B_1) - P(B_2)}{1-P(B_1)} \times [P(B_1|A) - P(B_1)]
= 0.01 + \frac{0.75188 - 0.01}{1-0.03} \times (0.382 - 0.03)
= 0.279
```

因此，$B_2$ 的概率为 0.279。

主观贝叶斯方法的优点是其计算公式大多是在概率论的基础上推导出来的，具有较坚实的理论基础。知识的静态强度 LS 及 LN 由领域专家给出，避免了大量的数据统计工作。主观贝叶斯方法不仅给出了证据肯定存在、肯定不存在时更新后验概率的方法，而且给出了证据不确定时的更新方法，实现了不确定性的逐级传递。

但是，该方法要求领域专家在给出知识的同时给出 H 的先验概率 P(H)，这比较困难。
同时，贝叶斯定理要求事件间独立，这使得主观贝叶斯方法的应用受到限制。

## 5.2.3 可信度方法

根据经验对一个事物和现象为真的相信程度称为可信度，也称为确定性因子。可信度带有较大的主观性和经验性。例如，张三昨天没有上课，他的理由是肚子疼，就此理由而言，听话的人可能完全相信，也可能完全不相信，也可能在某种程度上相信，这与张三平时的表现和人们对他的话的相信程度有关。

可信度方法是由美国斯坦福大学爱德华·肖特利夫（Edward Shortliffe）等在确定性理论的基础上，考察了非概率的和非形式化的推理过程后，于 1975 年提出的一种不确定性推理方法，并于 1976 年首次在血液病诊断专家系统 MYCIN 中得到了成功应用。该方法比较简单、直观，而且效果比较好。目前，有许多成功的专家系统都是基于这一方法建立起来的。

具有代表性的可信度模型 MYCIN 采用可信度 CF（certainty factor）作为不确定性测度，通过对 CF(H,E)的计算，探讨证据 E 对假设 H 的定量支持程度，因此该方法也称为 C-F 模型。其他可信度方法都是在此基础上发展起来的。

### 1. 知识不确定性的表示

在 C-F 模型中，知识以产生式规则表示：

```
IF E THEN H [CF(H,E)]
```

式中，E 为规则的前提条件；H 为规则的结论；CF(H,E) 为规则的可信度，也称为规则强度或知识强度。其中，前提和结论都可以是复合命题，可信度则描述的是知识的静态强度，反映了前提条件与结论的联系强度。

CF(H,E) 的取值范围一般为[-1,1]。当该值大于 0 时，值越大，说明证据的出现越是支持 H 为真，知识越接近于“真”；当其值小于 0 时，值越小，说明知识越接近于“假”；当该值等于 0 时，说明证据的出现与否与 H 无关。

例如，对于一个新冠患者而言，“IF 发热低于 38℃ AND 可自行退热 AND 无呼吸困难 THEN 轻症新冠患者 AND 居家隔离口服药物可控制病情 (0.8)”，表示病人如有上述症状，则有八成把握认为他是新冠轻症患者并且居家隔离口服药物即可控制病情。

规则强度 CF(H,E) 的计算公式如下：

```
CF(H,E) = MB(H,E) - MD(H,E), CF(H,E) \in [-1,1] (5.43)
```

式中，MB（measure belief）为信任增长度，表示因与 E 匹配的证据的出现，对 H 为真的信任增长度；MD（measure disbelief）为不信任增长度，表示因与 E 匹配的证据的出现，对 H 为真的不信任增长度。

MB 的定义为

```
MB(H,E) = \begin{cases} 1, & \text{若} P(H) = 1 \\ \frac{\max \{ P(H|E), P(H) \} - P(H)}{1 - P(H)}, & \text{若} P(H) \neq 1 \end{cases} (5.44)
```

MD 的定义为

MD(H,E) = \begin{cases} 1, & \text{若}P(H)=0 \\ \frac{\min\{P(H|E),P(H)\} - P(H)}{-P(H)}, & \text{若}P(H) \neq 0 \end{cases} (5.45)

它们的实际含义如下。
MB: 因 E 而对 H 信任的增长/不相信 H 的概率。
MD: 因 E 而对 H 信任的减少/相信 H 的概率。
同时， \( 0 \leqslant \text{MB}(H,E) \leqslant 1, 0 \leqslant \text{MD}(H,E) \leqslant 1 \)。
也就是说，当 \(\text{MB}(H,E) > 0\) 时， \( P(H|E) > P(H) \)，由于 E 的证据的出现增加了对 H 的信任程度；当 \(\text{MD}(H,E) > 0\) 时， \( P(H|E) < P(H) \)，由于 E 的证据的出现增加了对 H 的不信任程度。
同一个证据不可能既增加对 H 的信任程度，又增加对 H 的不信任程度，所以 \(\text{MB}(H,E)\) 与 \(\text{MD}(H,E)\) 是互斥的，即当 \(\text{MB}(H,E) > 0\) 时， \(\text{MD}(H,E) = 0\)；当 \(\text{MD}(H,E) > 0\) 时， \(\text{MB}(H,E) = 0\)。

根据 \(\text{CF}(H,E)\) 的定义及 \(\text{MB}(H,E)\) 和 \(\text{MD}(H,E)\) 的互斥性，可得到 \(\text{CF}(H,E)\) 的计算公式：

\(\text{CF}(H,E) = \begin{cases} \text{MB}(H,E) - 0 = \frac{P(H|E) - P(H)}{1 - P(H)}, & \text{若}P(H|E) > P(H) \\ 0, & \text{若}P(H|E) = P(H) \\ 0 - \text{MD}(H,E) = -\frac{P(H) - P(H|E)}{P(H)}, & \text{若}P(H|E) < P(H) \end{cases} (5.46)\)

由 \(\text{CF}(H,E)\) 的计算公式可知其意义。若 \(\text{CF}(H,E) > 0\)，则 \( P(H|E) > P(H) \)，\(\text{CF}(H,E)\) 越大 \( H \) 为真的可信度越大；若 \(\text{CF}(H,E) < 0\)，则 \( P(H|E) < P(H) \)，\(\text{CF}(H,E)\) 越小 \( H \) 为假的可信度越大；若 \(\text{CF}(H,E) = 0\)，则 \( P(H|E) = P(H) \)，即 \( H \) 与 \( E \) 独立，\( E \) 的证据的出现与否均对 \( H \) 没有影响。

### 2. 证据不确定性的表示

在 C-F 模型中，证据 E 的不确定性也用可信度因子表示，其取值范围同样是[-1,1]。例如， CF(E) = 0.5，表示 E 的可信度为 0.5。

由前面所描述的证据的不确定性表示可知，证据可信度值的来源分两种情况：初始证据和推理证据。初始证据的值由用户给出；推理证据则由先前推出的结论作为当前推理的证据，其值通过传递算法计算得到。

CF(E) 的值域及含义表示如下。

- 1）当 CF(E) = -1 时，证据 E 肯定为假；
- 2）当 -1 < CF(E) < 0 时，证据以某种程度为假；
- 3）当 CF(E) = 0 时，无法知道证据的真假；
- 4）当 0 < CF(E) < 1 时，证据以某种程度为真；
- 5）当 CF(E) = 1 时，证据 E 肯定为真。

CF(E) 描述的是证据的动态强度。尽管它和知识的静态强度在表示方法上类似，但所表示的意义却完全不同。知识的静态强度 CF(H,E) 表示规则的强度，即当 E 所对应的证据为真时对 H 的影响程度；而动态强度 CF(E) 表示证据 E 当前的不确定性程度。

### 3. 组合证据不确定性计算

对证据的组合形式可分为合取与析取两种基本情况。当组合证据是多个单一证据的合取时，即
\( E = E_1 \text{ AND } E_2 \text{ AND } \cdots \text{ AND } E_n \)

若已知 \( CF(E_1), CF(E_2), \cdots, CF(E_n) \)，则
\( CF(E) = \min \{ CF(E_1), CF(E_2), \cdots, CF(E_n) \} \) (5.47)

当组合证据是多个单一证据的析取时，即
\( E = E_1 \text{ OR } E_2 \text{ OR } \cdots \text{ OR } E_n \)

若已知 \( CF(E_1), CF(E_2), \cdots, CF(E_n) \)，则
\( CF(E) = \max \{ CF(E_1), CF(E_2), \cdots, CF(E_n) \} \) (5.48)

另外，规定 \( CF(-E) = -CF(E) \)。

### 4. 不确定性的传递算法

C-F 模型中的不确定性推理，实际上是从不确定性的初始证据出发，不断运用相关的不确定性知识，逐步推出最终结论和该结论的可信度的过程。每一次运用不确定性知识，都需要由证据的不确定性和知识的不确定性计算结论的不确定性。

- 1）证据肯定存在，即当 \( CF(E) = 1 \) 时，此时有 \( CF(H) = CF(H, E) \)，说明知识强度 \( CF(H, E) \) 实际上就是在前提条件对应的证据为真时结论 \( H \) 的可信度。

- 2）证据不一定存在，即当 \( CF(E) \neq 1 \) 时，结论 \( H \) 的可信度由下式计算：
  \( CF(H) = CF(H, E) \times \max \{ 0, CF(E) \} \) (5.49)

当 \( CF(E) < 0 \)，即相应证据以某种程度为假时，则 \( CF(H) = 0 \)，说明此时该模型中没有考虑证据为假时对结论 \( H \) 所产生的影响。

### 5. 结论不确定性的合成算法

当不同知识推出具有不同可信度的相同结论时，要将各结论 \( H \) 的可信度进行合成。由于对多条知识的综合可通过两两的合成实现，因此可以将下述合成过程推广应用到多条规则支持同一条结论，且规则前提可以包含多个证据的情况。合成过程是先把第一条与第二条合成，然后用该合成后的结论与第三条合成，依次进行，直到全部合成完为止。这里只考虑两条知识的情况。

设有如下规则：
IF \( E_1 \) THEN \( H \ [CF(H, E_1)] \)
IF \( E_2 \) THEN \( H \ [CF(H, E_2)] \)
则结论 \( H \) 的综合可信度可分以下两步计算。

第 1 步，分别对每条规则求出其 \( CF(H) \)，即
\( CF_1(H) = CF(H, E_1) \times \max \{ 0, CF(E_1) \} \) (5.50)
\( CF_2(H) = CF(H, E_2) \times \max \{ 0, CF(E_2) \} \) (5.51)

第 2 步，用下述公式求出 \( E_1 \) 和 \( E_2 \) 对 \( H \) 的综合影响所形成的可信度 \( CF_{1,2}(H) \)，即
