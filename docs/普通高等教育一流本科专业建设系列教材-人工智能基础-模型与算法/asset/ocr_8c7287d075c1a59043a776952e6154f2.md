比原概率容易得到，但是要想得到这些数据仍然是一项相对困难的工作。另外，贝叶斯公式的应用条件很严格，要求各事件相互独立，若证据间存在依赖关系，就不能直接使用该方法。

# 5.2.2 主观贝叶斯方法

在许多情况下，同类事件发生的频率不高，甚至很低，无法进行概率统计，通常是根据观测到的数据，依据领域专家的经验给出一些主观判断，称为主观概率。概率一般可以解释为对证据和规则的主观信任度。概率推理中起关键作用的是贝叶斯公式，是主观贝叶斯方法的基础。例如，随机事件 $A$ 的概率 $P(A)$ 可表示 $A$ 发生的可能性，因此可用概率方法表示和处理事件 $A$ 的确定性程度。

主观贝叶斯方法又称为主观概率论，是由美国圣何塞州立大学电气工程学教授理查德·杜达（Richard Duda）、美国计算机科学家彼得·哈特（Peter Hart）等于 1976 年提出的一种不确定性推理模型，并被成功应用于地质勘探专家系统 PROSPECTOR。主观贝叶斯方法是以概率统计理论为基础，将贝叶斯公式与专家及用户的主观经验相结合而建立的一种模型，以概率论中的全概率公式和贝叶斯公式为基础。

# 1. 概率基础

在介绍主观贝叶斯方法之前，先介绍概率论中的全概率公式和贝叶斯公式。

# (1) 全概率公式

设事件 $A_1, A_2, \cdots, A_n$ 满足：

+   1) 任意两个事件均互不相容，即当 $i \neq j$ 时，有 $A_i \cap A_j = \varnothing (i = 1, 2, \cdots, n; j = 1, 2, \cdots, n)$。

+   2) $P(A_i) > 0 (i = 1, 2, \cdots, n)$。

+   3) $A_1 \cup A_2 \cup \cdots \cup A_n = \Omega$。

则称事件组 $A_1, A_2, \cdots, A_n$ 是样本空间 $\Omega$ 的一个划分。那么对任何事件 $B$ 有下式成立：

$$P(B) = \sum_{i=1}^{\infty} P(A_i)P(B|A_i)$$ (5.10)

# (2) 贝叶斯公式

设事件 $A_1, A_2, \cdots, A_n$ 满足上述全概率公式规定的条件，则对任何事件 $B$ 有下式成立：

$$P(A_i | B) = \frac{P(A_i)P(B|A_i)}{\sum_{j=1}^n P(A_j)P(B|A_j)}$$ (5.11)

式中，$P(A_i)$ 为事件 $A$ 的先验概率；$P(B|A_i)$ 为在事件 $A_i$ 发生条件下事件 $B$ 的条件概率；$P(A_i|B)$ 为在事件 $B$ 发生条件下事件 $A$ 的条件概率。

在事件 $B$ 已经发生的条件下，贝叶斯公式可用来寻找导致事件 $B$ 发生的各种原因事件 $A_i$ 的概率。
