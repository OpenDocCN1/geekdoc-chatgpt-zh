# 3. 宽度优先搜索的时间复杂度

为了便于分析，考虑一棵树，其每个节点的分支系数为 $b$，最大深度为 $d$。其中，分支系数是指一个节点可以扩展的新的节点数目。因此，搜索树的根节点在第一层会产生 $b$ 个节点，每个节点又产生 $b$ 个新节点，这样在第二层会有 $b^2$ 个节点。所以，目标不会出现在深度为 $d-1$ 的层，失败搜索的最小节点数目为

```
$1 + b + b^2 + \\cdots + b^{d-1} = (b^d - 1) / (b - 1) \\quad (b \\gg 1)$
```

而在找到目标节点之前可能扩展的最大节点数目为

```
$1 + b + b^2 + \\cdots + b^{d-1} + b^d = (b^{d+1} - 1) / (b - 1)$
```

对于 d 层，目标节点可能是第一个状态，也可能是最后一个状态。因此，平均需要访问的 d 层节点数目为 $(1+b^d)/2$。所以，平均总的搜索的节点数目为

```
$(b^d - 1) / (b - 1) + (1 + b^d) / 2 \\approx b^d (b + 1) / [2(b - 1)]$
```

宽度优先搜索的时间复杂度是 b 的指数函数 $O(b^d)$，因此宽度优先搜索的时间复杂度与搜索的节点数目成正比。

# 4. 宽度优先搜索的空间复杂度

在宽度优先搜索中，空间复杂度和时间复杂度一样，需要很大空间，这是因为树的所有叶节点需要同时存储。根节点扩展后，队列中有 $b$ 个节点。第 1 层最左边节点扩展后，队列中有 $2b-1$ 个节点。当 $d$ 层最左边的节点正在检查是否是目标节点时，在队列中的节点数目最多，为 $b^d$。该算法的空间复杂度与队列长度有关，在最坏的情况下约为指数级 $O(b^d)$。
