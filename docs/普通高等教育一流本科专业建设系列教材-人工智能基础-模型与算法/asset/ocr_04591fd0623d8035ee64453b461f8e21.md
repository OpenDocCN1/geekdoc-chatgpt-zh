+   2) Q: 人工智能是计算机专业的课程之一。
+   3) R: 今天有小雨。

一些哲学家，如在加州大学伯克利分校执教的哲学教授约翰·瑟尔（John Searle），认为其他形式的语言或行为也是判定命题。例如，是非疑问句可单用疑问语调或者用疑问语调兼句尾疑问语气词来表达语气，一般只要求对方做肯定或否定的回答。是非疑问句的提问针对的是整个命题，是对命题真值的询问，是非疑问句也表达了命题。道路交通标志不通过语言和文字也表达了命题。使用陈述句也可能给出一个命题而不判定它的真假。例如，在当老师请学生对某个引用发表意见时，这个引用就是一个命题（它有语义），而这个老师并没有判定它。

# 2. 联结词

设 P、Q 是命题，常用的联结词如下。

+   1) 否定 ¬，如 ¬P 。
+   2) 合取 ∧，如 P ∧ Q 。
+   3) 析取 ∨，如 P ∨ Q 。
+   4) 条件 →，如 P → Q，当且仅当 P 的真值为 T，Q 的真值为 F 时，P → Q 的真值为 F。
+   5) 双条件 ↔，如 P ↔ Q，当且仅当 P、Q 的真值相同，其真值为 T。

上述 5 种命题联结词的真值表如表 2.1 所示。

# 表 2.1 真值表

| P | Q | ¬P | P∧Q | P∨Q | P→Q | P↔Q |
|---|---|---|---|---|---|---|
| T | T | F | T | T | T | T |
| T | F | F | F | T | F | F |
| F | T | T | F | T | T | F |
| F | F | T | F | F | T | T |

# 3. 等价与蕴涵

# (1) 等价

对于两个命题公式 A、B，设 p₁, p₂, ⋯, pₙ 为出现于 A、B 中的所有变元，若对于任何一组真值 p₁, p₂, ⋯, pₙ，A 和 B 的真值都相同，则称 A 和 B 等价，记为 A ⇔ B 。

# (2) 蕴涵

当且仅当 P → Q 是永真式时，称 P 蕴涵 Q，记为 P ⇒ Q 。

# 4. 常用定理

有关复合命题的常用定理如下。

双重否定：

```
¬¬P ⇔ P
```

分配律：

```
P ∨ (Q ∧ R) ⇔ (P ∨ Q) ∧ (P ∨ R)
P ∧ (Q ∨ R) ⇔ (P ∧ Q) ∨ (P ∧ R)
```
