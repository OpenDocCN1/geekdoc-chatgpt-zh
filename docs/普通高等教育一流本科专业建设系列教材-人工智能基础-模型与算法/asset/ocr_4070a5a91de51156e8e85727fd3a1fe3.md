问题求解的效率。将推理机和知识库相结合也不失为一种可选方法。

+   3) 综合数据库也称为动态库或工作存储器，是反映当前问题求解状态的集合，用于存放系统运行过程中产生的所有信息，以及需要的原始数据，包括用户输入的信息、推理的中间结果、推理过程的记录等。综合数据库中由各种事实、命题和关系组成的状态，既是推理机选用知识的依据，也是解释机制获得推理路径的来源。

+   4) 知识获取负责建立、修改和扩充知识库，是专家系统中把问题求解的各种专门知识从人类专家的头脑中或其他知识源那里转换到知识库中的一个重要机构。知识获取可以是手工的，也可以采用半自动知识获取方法或自动知识获取方法。

+   5) 解释器能够向用户解释专家系统的行为方法，包括解释推理结论的正确性和系统输出其他候选结果的原因等。人工智能中的知识表示形式有产生式、框架、语音网络等，在专家系统中运用的较为普通的知识是产生式规则。产生式规则以 IF-THEN 形式出现，IF 后面是条件，THEN 后面是结论，条件和结论均可以通过逻辑运算 AND、OR、NOT 等进行复合。解释机制涉及程序的透明性，它让用户理解程序正在做什么和为什么这样做，向用户提供了关于系统的一个认识窗口。为了回答“为什么”得到某个结论的询问，系统通常需要反向跟踪动态库中保存的推理路径，并把它翻译成用户能接受的自然语言表达方式。

+   6) 人机交互界面是实现用户和专家系统之间交流的途径，通过人机交互界面，用户输入基本信息、回答系统提出的相关问题，系统输出推理结果及相关的解释。

现有的专家系统类型有很多，常用的有解释专家系统、预测专家系统、诊断专家系统等。根据用户需求，专家系统还可以进行设计规划、监视、控制、调试、修理甚至教学等工作。

# (2) 专家系统的特点

专家系统主要具有以下 3 个特点。

+   1) 启发性。专家系统提供最高水平的专业知识，为解决特定领域的具体问题，除了需要一些公共的常识之外，还需要大量与所研究领域密切相关的知识，从而能够有效地给出准确性和富有想象力的问题解决方案。

+   2) 透明性。专家系统必须有一个有效的机制来管理其中现有知识的汇编，并且它需要对自身的工作过程进行推理（自推理或解释）。

+   3) 灵活性。保持灵活性对专家系统来说至关重要，如在解题过程中除了用演绎方法外，有时还要根据情况使用归纳方法和抽象方法。

专家系统在当前及未来都将是人类值得信赖的高水平智能助手，是将人工智能技术运用到实际的重要手段。

# (3) 经典专家系统类型

基于规则的专家系统和基于框架的专家系统是两种经典的专家系统类型，在早期的研究和应用中起着非常重要的作用。自人工智能发展以来，有一种观点认为人工智能是对各种定性模型的获得、表达及使用的计算方法进行研究的学问，基于该观点人们又提出了基于模型的专家系统。
