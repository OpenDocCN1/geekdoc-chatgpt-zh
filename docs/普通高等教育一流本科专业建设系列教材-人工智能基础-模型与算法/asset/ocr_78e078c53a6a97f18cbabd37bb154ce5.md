更好(X, Y) <- 色泽更深(X, Y) (8.28)

该规则仍覆盖 2 个反例，即 “更好(15,1)” 与 “更好(15,6)” 。于是，FOIL 像命题规则学习那样继续增加规则体长度，最终生成合适的单条规则加入规则集。此后，FOIL 使用后剪枝对规则集进行优化。

若允许将目标谓词词作为候选文字加入规则体，则 FOIL 能学出递归规则；若允许将否定形式的文字 ￢f 作为候选，则能得到更简洁的规则集。

FOIL 可大致看作命题规则学习与归纳逻辑程序设计之间的过渡，其自顶向下的规则生成过程不能支持函数和逻辑表达式嵌套，因此规则表达能力仍有不足；但它是把命题规则学习过程通过变量替换等操作直接转化为一阶规则学习，因此比一般归纳逻辑程序设计技术更高效。

关联规则有以下几种常见分类。根据关联规则所处理的值的类型，如果考虑关联规则中的数据项是否出现，则这种关联规则是布尔关联规则（Boolean association rules）；如果关联规则中的数据项是数量型的，则这种关联规则是数量关联规则（quantitative association rules）。例如，年龄（“20～25”）购买（“网球拍”），年龄是一个数量型的数据项。在这种关联规则中，一般将数量离散化（discretize）为区间。

根据关联规则所涉及的数据维度，如果关联规则各项只涉及一个维度，则它是单维（single-dimensional）关联规则，如购买（“网球拍”）购买（“网球”）只涉及“购买”一个维度；如果关联规则涉及两个或两个以上维度，则它是多维（multi-dimensional）关联规则，如年龄（“20～25”）购买（“网球拍”）涉及“年龄”和“购买”两个维度。

根据关联规则所涉及的抽象层次，如果不涉及不同层次的数据项，则得到的是单层（single-level）关联规则。在不同抽象层次中挖掘出的关联规则称为广义（generalized）关联规则。例如，年龄（“20～25”）购买（“HEAD 网球拍”）和年龄（“20～25”）购买（“网球拍”）是广义关联规则，因为“HEAD 网球拍”和“网球拍”属于不同的抽象层次。

可以执行关联规则学习的常用算法有 Apriori 算法、FP-Growth/FP-tree（frequent pattern mining，频繁模式挖掘）、Eclat 算法、AIS 算法、SETM 算法和序列模式挖掘等。

# 8.3 基于数据统计的机器学习

基于数据统计的机器学习是指计算机基于数据构建概率统计模型并运用模型对数据进行预测与分析。基于数据统计的机器学习三要素为模型、策略和算法。模型，即所要学习的条件概率分布或决策函数，模型的假设空间包含所有可能的条件概率分布或决策函数；统计机器学习的目标在于从模型的假设空间中选取最优模型，那么策略就是需要考虑选取什么样的准则来学习或选择最优模型，具体的策略有经验风险最小化和结构风险最小化；算法是指学习模型的具体计算方法，主要包括支持向量机、浅层神经网络及贝叶斯分类器。

# 8.3.1 支持向量机

传统识别理论认为，算法模型性能可用从训练样本集得到的经验风险（empirical risk）来衡量。经验风险指算法模型在训练样本集中所有数据上所得误差的累加。很显然，经验风险越小，算法模型对训练数据拟合程度越好。在实际上，一味要求经验风险小，往往会造成过学习问题（over-fitting）。
