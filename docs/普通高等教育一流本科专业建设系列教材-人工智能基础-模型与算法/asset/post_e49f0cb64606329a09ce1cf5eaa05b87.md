
因而被中断了，这时就不能推断何雨是否付了账等情节。但是，仍然可以推出他看了菜单，这是因为看菜单事件发生在中断之前。从该例子还可以看出，利用脚本可以将事情的注意力集中在“因为久等，何雨生气了”这样一些特殊事件的发生上。

### 2.5.4 脚本表示法的特点

脚本表示法具有以下优点。

- 1）自然性。脚本表示法体现了人们在观察事物时的思维活动，组织形式类似于日常生活中的电影脚本，对于表达预先构思好的特定知识，如理解故事情节等，非常有效。

- 2）结构性。作为一种特殊的框架表示法，脚本表示法具有框架表示法善于表达结构性知识的特点。也就是说，它能够把知识的内部结构关系及知识间的联系表示出来，是一种结构化的知识表示方法。一个脚本也可以由多个槽组成，槽又可分为若干侧面，这样就能把知识的内部结构显式地表示出来。

脚本表示法具有以下缺点：脚本结构与框架结构相比要呆板得多，知识表示的范围也比较窄，因此脚本无法有效地表示生活中多种多样的知识。

## 2.6 过程表示法

在人工智能的发展史中，关于知识的表示方法曾存在两种不同的观点：一种观点认为，知识主要是陈述性的，其方法应着重其静态特性，即事物的属性及事物间的关系表示，这种观点表示知识的方法称为陈述式或说明性表示方法；另一种观点认为，知识主要是过程性的，其表示方法应将知识及如何使用这些知识的控制策略均表示为求解问题的过程，这种观点表示知识的方法称为过程表示法。

### 2.6.1 知识表示方法及过程规则

说明性表示方法是一种静态表示知识的方法，其主要特征是把领域内的过程性知识与控制性知识（问题求解策略）分离开来。

过程表示法着重于对知识的利用，它把与问题有关的知识及如何运用这些知识求解问题的控制策略表述为一个或多个求解问题的过程，每一个过程是一段程序，用于完成对一个具体事件或情况的处理。在问题求解过程中，当需要使用某个过程时就调用相应的程序并执行。在以这种方法表示知识的系统中，知识库是一组过程的集合，当需要对知识库进行增加、删除、修改时，则相应地增加、删除及修改有关的过程。

一般来说，一个过程规则由以下 4 部分组成。

- 1）激发条件。激发条件由推理方向和调用模式两部分组成。其中，推理方向用于指出推理是正向推理（forward reasoning，FR）还是逆向推理（backward reasoning，BR）。若为正向推理，则只有当综合数据库中的已有事实可以与其“调用模式”匹配时，该过程规则才能被激活；若为逆向推理，则只有当“调用模式”与查询目标或子目标匹配时，该过程规则才能被激活。

- 2）演绎操作。演绎操作由一系列子目标构成。当前面的激发条件满足时将执行这里列出的演绎操作。在应用推理求解问题时，当启动知识库中某个过程的激发条件被满足时，该过程即被启动，其中的每一个操作将被依次执行。

3) 状态转换。状态转换操作用来完成对综合数据库的增加、删除、修改操作。

4) 返回。过程规则的最后一个语句是返回语句，用于指出将控制权返回到调用该过程规则的上一级过程规则中去。

【例 2.12】下面是一个关于同学问题的过程表示。设有如下知识：“如果 x 与 y 是同班同学，且 z 是 x 的老师，则 z 也是 y 的老师。”可用过程规则表示如下：

```
BR(Teacher?z?y)
GOAL(Classmate?x y)
GOAL(Teacher z x)
INSERT(Teacher z y)
RETURN
```

其中，BR 为是逆向推理标志；GOAL 为求解子目标，即进行过程调用；INSERT 为对数据库进行插入操作；RETURN 为结束标志；带“？”的变量表示其值将在该过程中求得。
显然，这种知识表示法与程序设计语言中的过程表示有些相似，对每一个过程，RETURN 语句都标志着该过程的结束，并把控制权返回到调用它的过程中去。

### 2.6.2 过程表示的问题求解过程

在用过程规则表示知识的系统中，问题求解的基本过程如下：每当有一个新的目标时，就从可以匹配的过程规则中选择一个执行。在该规则的执行过程中可能会产生新的目标，此时就调用相应的过程规则并执行它。反复进行这一过程，直至执行到 RETURN 语句，这时将控制权返回给调用当前过程的上一级过程规则，并依次按照调用时的相反次序逐级返回。在这一过程中，如果某过程规则运行失败，就另选择一个同层的可匹配的过程规则执行；如果不存在这样的过程规则，则返回失败标志，并将执行的控制权移交给上一级过程规则。下面说明采用正向推理的问题求解过程。

【例 2.13】设综合数据库中有以下已知事实：

```
(Classmate 王涛 赵晔)
(Teacher 林海 王涛)
```

其中，第一个事实表示王涛与赵晔是同班同学；第二个事实表示林海是王涛的老师。

假设需要求解的问题是：找出两个人 w 及 v，其中，w 是 v 的老师。该问题可表示为

```
GOAL(Teacher? w? v)
```

求解该问题的过程如下。

1) 在过程规则库中找出对于问题 GOAL(Teacher? w? v)而言，其激发条件可以满足的过程规则。显然，BR(Teacher? z? y)经变量代换 w/z 和 v/y 之后可以匹配，因此选用该过程规则。

2) 执行该过程规则中的第一个语句 GOAL(Classmate? x y)。此时，其中的 y 已被 v 代换。经与已知事实匹配，分别求得变量 x 及 v 的值，即 x=王涛，v=赵晔。

3) 执行该过程规则中的第二个语句 GOAL(Teacher z x)。此时，x 的值已经知道，z 已被 w 代换。经与已知事实（Teacher 林海 王涛）匹配，求得了变量 w 的值，即 w=林海。

4) 执行该过程规则中的第三个语句 INSERT(Teacher z y)。此时，z 与 y 的值均已知，分别是林海和王涛，因此此时插入数据库的事实是（Teacher 林海 赵晔）。
这表明“林海也是赵晔的老师”，求得了问题的解。

### 2.6.3 过程表示法的特点

过程表示法的知识表示效率高且控制系统容易实现。过程表示法是用程序表示知识，而程序能准确地表明先做什么、后做什么及怎样做，并直接嵌入一些启发式的控制信息。因此，过程表示法可以避免选择及匹配那些无关的知识，也不需要跟踪那些不必要的路径，从而提高了系统的运行效率；同时，由于控制性质已嵌入程序中，因此控制系统就比较容易设计。

过程表示法的主要缺点是知识库不易维护及其使用的表示范围较窄。由于过程表示法是一种将知识蕴涵于程序中的表示法，因此不易对知识库进行修改或更新。另外，当要对知识库中的某一过程进行修改时，可能又会影响该过程调用的其他过程，所以对知识库的维护极不方便。同时，由于某些知识并不适于用程序表示，因此过程表示法适用的范围相当有限。

### 2.6.4 过程性与说明性表示方法的比较

说明性表示方法是对知识和事实的一种静态描述，是对知识的一种显式表达形式。过程表示法则是将有关某一问题领域的知识，连同如何使用这些知识的方法，都隐式地表达为一个求解问题的过程。它强调的是知识的动态方面，即如何发现相关的知识并进行推理，因此过程能够更好地体现知识的行为。过程表示法是将知识包含在若干过程之中，过程是一小段程序，它处理某些特殊事件或特殊状况。每个过程都包含说明客体和事件的知识，以及在说明完好的情况下的运行知识等。过程通常用子程序或模块实现。知识库是一组过程集合，知识库的修改即为增加/删除子程序，或修改子程序及访问条件。

与说明性表示方法相比，过程表示法更有利于表示启发式知识，能实现扩充逻辑推理（如缺省推理等），具有高度模块化的优点，能够通过类比进行推理。然而，过程表示方法本身的适用范围比较窄，但是研究说明性表示与过程性表示相结合的高效、易维护、可理解的知识表示方法却是很有意义的。

如何将说明性知识表示与过程性知识表示相结合来表示知识，以便在系统的可维护性、可理解性及运行效率等方面取得较好的效果是今后的发展方向。

## 2.7 语义网络表示法

在计算史上，剑桥语言研究部的理查德·胡克·里奇斯（Richard Hook Richens）在 1956 年首先意识到语义网络逻辑的重要性，并将该思想应用于自然语言机器翻译。1968 年，语义网络在奎廉（Quillian）研究人类联想记忆时作为一种心理学模型被提出，他认为记忆是由概念间的联系实现的。随后，奎廉又把语义网络用作知识表示。1975 年，得克萨斯大学的亨德里克斯（Hendrix）又对全称量词的表示提出了语义网络分区技术。发展至今，语义网络已经成为人工智能中应用较多的一种知识表示方法，尤其是在自然语言处理方面的应用。

### 2. 基本的语义关系

由语义网络结构的特点可以看出，语义网络不仅可以表示事物的属性、状态、行为等，而且更适合于表示事物之间的关系和联系。表示一个事物的层次、状态、行为的语义网络，也可以看作该事物与其属性、状态或行为的一种关系。抽象地说，语义网络可以表示事物之间的关系。

### (1) 类属关系

语义网络中的事物通常有对应的类别关系，常用的类属关系有以下几种。

- 1) 实例关系是 ISA，体现的是“具体与抽象”的概念，含义为“是一个”，表示一个事物是另一个事物的一个实例，如图 2.7 所示。

- 2) 分类关系是 AKO，也称泛化关系，体现的是“子类与超类”的概念，含义为“是一种”，表示一个事物是另一个事物的一种类型，如图 2.8 所示。

- 3) 成员关系是 A-Member-of，体现的是“个体与集体”的关系，含义为“是一员”，表示一个事物是另一个事物的一个成员，如图 2.9 所示。

### (2) 属性关系

属性关系是指事物和其属性之间的关系。常用的属性关系有 Have、Age、Can 等。

- 1) Have 的含义为“有”，表示一个节点具有另一个节点所描述的属性。例如，“鸵鸟有翅膀”的关系表示如图 2.10 所示。

- 3) Age 的含义为“年龄”，表示一个节点是另一个节点在年龄方面的属性。例如，“小利 15 岁”的关系表示如图 2.12 所示。

时间关系是指不同事件在其发生时间方面的先后次序关系。常用的时间关系有 Before、After 等。

### 2.7.2 语义网络的推理过程

用语义网络表示知识的问题求解系统主要由两大部分组成，一部分是由语义网络构成的知识库，另一部分是用于问题求解的推理机。语义网络的推理过程主要有两种，一种是继承，另一种是匹配。

### 1. 继承

语义网络中，具有类属关系的概念间属性具有继承性，即下层节点或实例节点可以从上层节点（或概念节点）继承一些属性。例如，青砖是一种砖，而砖的形状是长方体，由此可以推断，青砖的形状也是长方体。这种推理过程比较符合人的思维过程。继承一般有值继承和过程继承两种。

### (1) 值继承

值继承也称为属性继承，一般适用于语义联系 ISA 和 AKO 等之间的语义推理。在这些语义联系下的推理是一种直接继承，如 A→B，B→C，便有 A→C。再如刚才举的例子，青砖是一种砖，而砖的形状是长方体，由此可以推断，青砖的形状也是长方体，青砖在“形状”这个属性的值就是从砖的“形状”继承下来的。

### (2) 过程继承

过程继承又称为方法继承，它所继承的是有关某属性值的计算过程或计算方法，即语义网络中下层节点的某些属性值并不是从上层节点直接继承下来的，而是需要通过计算才能得到。例如，空心砖是一种砖，空心砖的“形状”属性值可以从砖的“形状”直接继承，但是空心砖的“重量”属性却不能从砖的“重量”属性直接继承，它继承的只是计算砖的重量的过程——长×高×宽×密度。

### 2. 匹配

匹配是指在知识库的语义网络中寻找与待求解问题相符的语义网络模式。匹配的主要过程如下。

- 1) 根据待求解问题的要求构造一个网络片段，该网络片段中有些节点或弧的标识是空的，称为询问处，它反映的是待求解的问题。
- 2) 根据该语义片段到知识库中寻找所需要的信息。
- 3) 当待求解问题的网络片段与知识库中的某语义网络片段相匹配时，则与询问处相匹配的事实就是问题的解。

【例 2.14】 假设语义网络已在知识库中，问张飞在哪个公司工作。

### 例 2.15 用语义网络表示下列命题。

- 1) 树和草都是植物。
- 2) 树和草是有根有叶的。
- 3) 水草是草，且长在水中。
- 4) 果树是树，且会结果。

### 解

对其进行解题分析。
1) 问题涉及的对象有植物、树、草、水草、果树、桃树，共 6 个对象。各对象的属性分别如下。
树和草的属性：有根、有叶；
水草的属性：长在水中；
果树的属性：会结果；

### 2.7.3 语义网络表示法的特点

语义网络表示法具有以下优点。

- 1) 结构性：把事物的属性及事物间的各种语义联系显式地表示出来，是一种结构化的知识表示方法。在这种方法中，下层节点可以继承、新增、变异上层节点的属性。
- 2) 联想性：本来是作为人类联想记忆模型提出来的，它着重强调事物间的语义联系，体现了人类的联想思维过程。
- 3) 自索引性：把各节点之间的联系以明确、简洁的方式表示出来，通过与某一节点连接的弧可以很容易地找出与该节点有关的信息，而不必查找整个知识库。这种自索引能力有效地避免了搜索时遇到的组合爆炸问题。
- 4) 自然性：这种带有标识的有向图可以比较直观地把知识表示出来，符合人们表达事物之间关系的习惯，并且与自然语言语义网络之间的转换也比较容易实现。
