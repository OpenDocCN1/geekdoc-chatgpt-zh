```
S_3 是 P
...
S_n 是 P
(S_1、S_2、S_3、⋯、S_n 是 S 类中的全部对象)
S 都是 P
```

运用完全归纳推理得到的结论知识绝不是前提知识的简单重复，而是人们对事物认识的概括和深化，能使认识从个别上升到一般，具有认识作用和论证作用。例如，在科学史上，科学家通过这个考察太阳系的所有大行星，即水星、金星、地球、火星、木星、土星、天王星、海王星，了解到它们都是沿椭圆轨道绕太阳运行的，从而推出结论：太阳系所有大行星都是沿椭圆轨道绕太阳运行的。

+   2) 不完全归纳推理。

与完全归纳推理相对的，不完全归纳推理是根据一类事物中的部分对象具有（或不具有）某种属性，从而推出该类对象全体都具有（或不具有）某种属性的推理。其各个前提只是涵盖了结论的部分范围而不是全部，适用于样本数量比较多的情况。

不完全归纳推理方法主要分为简单枚举归纳法和科学归纳法。

+   ① 简单枚举归纳法是根据某类事物的若干个别对象具有或不具有某种属性，并且没有遇到相反的情况，从而推出该类事物的全部对象都具有或都不具有这种属性的全称性结论的推理。其逻辑结构表达式为

```
S_1 是（或不是）P
S_2 是（或不是）P
S_3 是（或不是）P
...
S_n 是（或不是）P
(S_1、S_2、S_3、⋯、S_n 是 S 类中的部分对象，且没有出现反例)
所以，所有的 S 都是（或不是）P
```

简单枚举归纳法是一种最直接的经验归纳，直观性最强。当研究对象无法穷尽不能进行完全归纳推理时，简单枚举归纳法对事物所进行的概括或扩展是人类探求科学规律和获取新知识的重要手段。但是，这种方法的依据是不充分的，可靠性较低。在简单枚举归纳法中，各个前提都是满足于结论的。但是，结论所指的范围比它的前提加起来还要大，因此并不能排除有些客观存在的反例没有被发现，如果继续进行简单枚举，也不能排除遇到反例，从而不满足之前推出的结论，那么原来所得的结论就被推翻。

简单枚举归纳法是一种或然性推理，它的结论可能是错误的。因此，在运用简单枚举归纳法时，应尽量增加枚举数量，扩大考察范围，才能尽可能地增加结论的可靠性，避免出现“以偏概全”的情况。以偏概全是指以不具有代表性的样本为根据，概括出一类对象的总体都具有某种属性的结论。下面是一个简单枚举归纳法的例子。

+   【例 4.2】现有如下对象：
+   小李的成绩为 95 分；
+   小王的成绩为 92 分；
+   小张的成绩为 91 分；
+   小赵的成绩为 96 分；
