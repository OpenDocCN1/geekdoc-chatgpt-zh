# 第 6 章 计算智能

计算智能（computational intelligence, CI）是根据人类组织、生物界及有关学科内部规律和原理求解复杂问题的方法。计算智能蕴涵算法的范围很广，主要包括神经网络、机器学习、遗传算法、模糊计算等类型繁多、各具特色的算法。这些智能算法有一个共同的特点，就是通过模仿生物智能设计出最优算法，进行计算机程序化的算法实现，并解决实际问题。如图 6.1 所示，人类根据自然界中的现象，提炼出算法思想，将这些算法思想投入机器中，大大提高了解决问题的效率。

计算智能、人工智能、生物智能（biological intelligence, BI）之间有什么区别和联系呢？人工智能一般解释为用人工的方法在计算机上实现的智能，或称为机器智能。它是一门研究如何构造智能机器或智能系统，以模拟、延伸和扩展人类智能的学科。人工智能是自然科学与社会科学的交叉学科，是一个独特的学科体系，它的核心是思维与智能。人工智能的基础学科包括数学、思维科学和计算机等。

计算智能、人工智能、生物智能的输入数据不同，但输入的复杂度却是递增的。计算智能的输入是计算与感知器，人工智能的输入是知识与传感数据，生物智能的输入则是人类知识与传感输入。计算智能、人工智能、生物智能之间的对照关系如图 6.2 所示。
