变量 $\alpha_i$ 和 $\mu_i$ 的函数，然后控制乘子变量，对函数取最大值：

$$ \max_{\alpha} \sum_i \alpha_i - \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \alpha_i \alpha_j y_i y_j \mathbf{x}_i^{\mathrm{T}} \mathbf{x}_j $$ (8.45)

s.t. $\sum_{i=1}^n \alpha_i y_i = 0$ (8.46)

$0 \leqslant \alpha_i \leqslant c, i=1, 2, \cdots, n$ (8.47)

求解上述带约束的优化问题，可得到拉格朗日乘子 $\alpha_i$ 的计算结果，根据 $\alpha_i$ 的结果计算 $w$ 和 $b$ 的值。支持向量机的对偶问题与原问题拥有相同的解，其中：

$$ w = \sum_i \alpha_i y_i \mathbf{x}_i $$ (8.48)

而 $b$ 的求解方法将在接下来进行讨论。

原问题的解需满足 KKT（Karush-Kuhn-Tucker）条件，因此原问题（和对偶问题）取得最优解时有以下关系：

$$ \begin{cases} \alpha_i [1 - \xi_i - y_i (\mathbf{w}^T \mathbf{x}_i + b)] = 0 \\ \mu_i \xi_i = 0 \\ \xi_i, \mu_i, \alpha_i \geqslant 0 \end{cases} $$ (8.49)

因此，当 $0 < \alpha_i < c$ 时，有 $\mu_i > 0, \xi_i = 0$，同时 $1 - \xi_i - y_i (\mathbf{w}^T \mathbf{x}_i + b) = 0$，此时样本刚好落在间隔边界上；当 $\alpha_i = 0$ 时，有 $\mu_i = c, \xi_i = 0$，同时 $1 - \xi_i - y_i (\mathbf{w}^T \mathbf{x}_i + b) = 0$，此时样本可能在间隔边界上，也可能在间隔边界外；当 $\alpha_i = c$ 时，有 $\mu_i = 0, \xi_i \geqslant 0$，同时 $1 - \xi_i - y_i (\mathbf{w}^T \mathbf{x}_i + b) = 0$，此时样本可能在分类平面和间隔平面之间，也可能在分类平面误分的一侧。根据以上性质，只需找到样本 $j$ 满足 $0 < \alpha_j < c$，即可求解参数 $b$：

$$ b = y_i - \mathbf{w}^T \mathbf{x}_j $$ (8.50)

注意到当 $\alpha_i = 0$ 时，第 $i$ 个样本对 $w$ 和 $b$ 的解并没有任何贡献，因此即使去除第 $i$ 个样本，支持向量机的解也不会发生变化；反之，当 $\alpha_i > 0$ 时，该样本对构造解平面做出了贡献，因此被称为一个“支持向量”。由此可导出支持向量机的一个重要性质：训练完成后，大部分训练样本可以舍去，最终模型仅与若干支持向量有关。

$\alpha$ 可以采用 SMO（sequential minimal optimization）算法进行求解。SMO 先固定除 $\alpha_i$ 之外的所有参数，在此基础上求解 $\alpha_i$。由于存在约束 $\sum_{i=1}^n \alpha_i y_i = 0$，若固定 $\alpha_i$ 之外的其他变量，则 $\alpha_i$ 可以由其他变量推算出来，因此 SMO 每次选择两个变量 $\alpha_i$ 和 $\alpha_j$，并固定其他参数，不断执行如下步骤直至收敛。

+   1) 选取一对需更新的变量 $\alpha_i$ 和 $\alpha_j$。

+   2) 固定除 $\alpha_i$ 和 $\alpha_j$ 之外的所有参数，简化约束得到 $\alpha_i y_i + \alpha_j y_j - \sum_{k \neq i,j} \alpha_k y_k = \text{常数}$。

+   3) 计算使目标函数最大的 $\alpha_i$ 和 $\alpha_j$ 并更新。

关于 $\alpha_i$ 和 $\alpha_j$ 的选取有多种方式，比较简单常用的方式是选取两个对应样本间隔最大的 $\alpha_i$ 和 $\alpha_j$。在 $\alpha$ 收敛后，通过 $w = \sum_{i=1}^n \alpha_i y_i x_i$ 求解分类超平面 $w$。理论上可以使用任意支持向量借助 $y_i f(x_i) = 1$ 计算偏移量 $b$，现实中也常将所有支持向量代入进行求解的结果去取平
