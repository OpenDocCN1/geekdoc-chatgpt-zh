概率分配函数与概率不同。例如，设 \( M(\{小鸡\}) = 0.2 \), \( M(\{小狗\}) = 0.1 \), \( M(\{小猫\}) = 0.1 \), \( M(\{小鸡, 小狗\}) = 0.2 \), \( M(\{小鸡, 小猫\}) = 0.2 \), \( M(\{小猫, 小狗\}) = 0.1 \), \( M(\{小鸡, 小猫, 小狗\}) = 0.1 \), \( M(\emptyset) = 0 \)。显然，\( M \) 符合概率分配函数的定义，但是 \( M(\{小鸡\}) + M(\{小狗\}) + M(\{小猫\}) = 0.4 \)，若按概率的要求，这三者的和应等于 1。
事实上，基本概率分配数值一般由人主观观给出。

# 2. 信任函数

定义 5.2 命题的信任函数 Bel:\( 2^\Omega \rightarrow [0,1] \) 满足
\(\text{Bel}(A) = \sum_{B \subseteq A} M(B), \forall A \subseteq \Omega\) (5.59)

式中，\( 2^\Omega \) 为 \(\Omega\) 的所有子集；\(\text{Bel}(A)\) 为对命题 \( A \) 为真的总的信任程度。
由信任函数和概率分配函数的定义可以推出：

\(\text{Bel}(\varphi) = M(\varphi) = 0\) (5.60)
\(\text{Bel}(\Omega) = \sum_{B \subseteq \Omega} M(B) = 1\) (5.61)

【例 5.6】设 \(\Omega=\{a,b,c\}\)，其基本概率分配函数为
\( M(\{a\}) = 0.3, M(\{b\}) = 0.2, M(\{c\}) = 0, M(\{a,b\}) = 0.1 \),
\( M(\{b,c\}) = 0.1, M(\{a,c\}) = 0, M(\{a,b,c\}) = 0.2, M(\emptyset) = 0.1 \)
求 \(\text{Bel}(\{a\})\)、\(\text{Bel}(\{b,c\})\)、\(\text{Bel}(\{a,b,c\})\)。

解
\(\text{Bel}(\{a\}) = M(\{a\}) = 0.3\)
\(\text{Bel}(\{b,c\}) = M(\{b\}) + M(\{c\}) = 0.2 + 0 = 0.2\)
\(\text{Bel}(\{a,b,c\}) = M(\{a\}) + M(\{b\}) + M(\{c\}) + M(\{a,b\}) + M(\{b,c\}) + M(\{a,c\}) + M(\{a,b,c\}) + M(\emptyset) = 1\)

# 3. 似然函数

似然函数又称为不可驳斥函数或上限函数。
定义 5.3 似然函数 Pl:\( 2^\Omega \rightarrow [0,1] \)，且满足
\(\text{Pl}(A) = 1 - \text{Bel}(\neg A), \forall A \subseteq \Omega\) (5.62)

由于 \(\text{Bel}(A)\) 表示对 \( A \) 为真的信任程度，因此 \(\text{Bel}(\neg A)\) 表示对 \(\neg A\) 为真，即 \( A \) 为假的信任程度，由此 \(\text{Pl}(A)\) 表示对 \( A \) 为非假的信任程度。
似然函数 \(\text{Pl}(A)\) 的另一种表达形式为
\(\text{Pl}(A) = \sum_{A \cap B \neq \emptyset} M(B)\) (5.63)

证明
\(\text{Pl}(A) - \sum_{A \cap B \neq \emptyset} M(B) = 1 - \text{Bel}(\neg A) - \sum_{A \cap B \neq \emptyset} M(B)\)
\(= 1 - \left( \text{Bel}(\neg A) + \sum_{A \cap B \neq \emptyset} M(B) \right)\)
\(= 1 - \left( \sum_{C \subseteq \neg A} M(C) + \sum_{A \cap B \neq \emptyset} M(B) \right)\)
