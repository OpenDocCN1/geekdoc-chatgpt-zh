生式规则形式可表示为

```
IF E THEN(LS,LN) H[P(H)]
```

式中，E 为前提（称为证据）；H 为结论（称为假设）；P(H) 为结论 H 为真的先验概率，由专家根据经验给出。

LS 称为充分性度量（充分似然性因子），表示规则或证据成立的充分性量度，用于指出 E 对 H 的支持程度，取值范围为[0,∞)。其定义为

LS = \frac{P(E|H)}{P(E|\neg H)} \tag{5.12}

LN 称为必要性度量（必要似然性因子），用于指出 ¬E 对 H 的支持程度，取值范围为[0,∞)。LN 的定义为

LN = \frac{P(\neg E|H)}{P(\neg E|\neg H)} = \frac{1-P(E|H)}{1-P(E|\neg H)} \tag{5.13}

在实际应用中，概率值不可能求出，采用的 LS 和 LN 的值由领域专家给出，相当于知识的静态强度。

为了方便讨论，另引入几率函数：

O(X) = \frac{P(X)}{P(\neg X)} = \frac{P(X)}{1-P(X)} \tag{5.14}

P(X) = \frac{O(X)}{1+O(X)} \tag{5.15}

式中，O(X) 为证据 X 出现的概率和不出现的概率之比，显然 O(X) 是 P(X) 的增函数。

P(X) = 0，O(X) = 0 \n P(X) = 0.5，O(X) = 1 \n P(X) = 1，O(X) = ∞

根据贝叶斯公式和几率函数，可以做如下推导：

P(E|H) = \frac{P(H|E)P(E)}{P(H)} \tag{5.16}

P(E|\neg H) = \frac{P(H|\neg E)P(E)}{P(\neg H)} \tag{5.17}

LS = \frac{P(E|H)}{P(E|\neg H)} = \frac{P(\neg H|E)}{P(H)} = \frac{O(H|E)}{O(H)} \tag{5.18}

O(H|E) = LS \times O(H) \tag{5.19}

式（5.19）称为贝叶斯公式的几率似然性形式。

对于 LS 有以下几点说明。

+   1）LS 的取值范围为[0,+∞)。

+   2）LS 称为充分似然因子。

+   3）LS = ∞ 时，P(¬H|E) = 0，P(H|E) = 1。

+   4）当 LS > 1 时，P(H|E) > P(H)，即 E 支持 H，E 导致 H 为真的可能性增加；当 LS → ∞ 时，表示证据 E 将使 H 为真；当 LS = 1 时，表示 E 对 H 没有影响，与 H 无关；当 LS < 1 时，说明 E 不支持 H，E 导致 H 为真的可能性下降；当 LS = 0 时，E 的存在使得 H 为假。
