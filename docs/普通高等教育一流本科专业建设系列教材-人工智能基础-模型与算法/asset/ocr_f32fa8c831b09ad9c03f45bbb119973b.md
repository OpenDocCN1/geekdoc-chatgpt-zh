# 第 2 章 知识表示

知识表示是建立各种知识系统的重要环节，也是人工智能研究的基础。知识表示与知识本身的性质和类型等相关，涉及知识的逻辑结构研究与设计。就形式而言，知识可分为显式知识和隐式知识。显式知识是指可用语言、文字、符号、形象、声音及其他人能直接识别和处理的形式来表达的知识；隐式知识则是不能用上述形式表达的知识，如游泳、表演的某些知识就是隐式知识。隐式知识只可用神经网络进行存储和表示。本章主要介绍显式知识的表示方法。

# 2.1 知识与知识表示的概念

人类的智能活动主要是获得并运用知识。知识是智能的基础。为了使计算机具有智能，能模拟人类的智能行为，就必须使其具有知识。知识需要用适当的模式表示出来才能存储到计算机中，因此知识表示是人工智能的一个十分重要的基础性研究问题。

# 2.1.1 知识

客观世界中，知识是事物某些方面的属性及事物之间相互关系的反映，不同事物或者相同事物间的不同关系形成了不同的知识，这些事物及其属性的反映就是信息。

知识处理中的数据与通常意义上的“数”不同，它不仅指狭义上的数字，其含义还可以更广泛，颜色、属性、长度、宽度等都可以记录为数据。这里，数据可以定义为“客观事物的数量、属性、位置及其相互关系等的抽象表示”。在计算机科学中，数据是用于输入计算机进行处理、具有一定意义的数字、字母、符号和模拟量等的通称。计算机存储和处理的对象十分广泛，表示这些对象的数据也随之变得越来越复杂。

数据是信息的载体和表示，而信息是对数据的解释。信息是“数据所表示的含义”。例如，“3 棵树”“3 个人”“3 本书”都是数据“3”的使用场合，但其表示的含义是不同的，也就产生了不同的信息。一般来说，一个信息可用一组描述词及其值来描述：<描述词 1：值 1；…；描述词 n：值 n>
