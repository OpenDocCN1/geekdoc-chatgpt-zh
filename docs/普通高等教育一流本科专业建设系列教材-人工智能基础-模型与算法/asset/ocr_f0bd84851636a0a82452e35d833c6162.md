# 3. 松弛变量、软间隔与 Hinge 损失函数

先前介绍中假设所有训练样本数据线性可分，即存在一个线性超平面，能将不同类别的样本完全隔开，这种情况称为硬间隔（hard margin）。与硬间隔相对的是软间隔（soft margin），软间隔是指允许部分错分给定的训练样本。

在软间隔情况下，算法在使得每个类别中距离超平面最近样本到超平面的最小距离最大的同时，还应使不满足约束条件的样本数目尽可能少，因此目标函数可表示如下：

$$\min_{w,b} \frac{1}{2} \boldsymbol{w}^T \boldsymbol{w} + c \times \sum_{i=1}^n [y_i \neq \text{sign}(\boldsymbol{w}^T \boldsymbol{x}_i + b)] \quad (8.34)$$ $$\text{s.t. } y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b) \geqslant 1 \text{ for correct } \boldsymbol{x}_i \quad (8.35)$$ $$y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b) \geqslant -\infty \text{ for incorrect } \boldsymbol{x}_i \quad (8.36)$$

式中，$c$ 为一个常数；$[y_i \neq \text{sign}(\boldsymbol{w}^T \boldsymbol{x}_i + b)]$ 为指示（indicator）函数，表示对 $\boldsymbol{x}_i$ 的分类结果与其正确类别标签 $y_i$ 是否一致，如果不一致则指示函数输出为 1，否则输出为 0。

然而，上述目标函数难以直接求解。为此，引入 Hinge 损失函数，即有

$$\min_{w,b} \frac{1}{2} \boldsymbol{w}^T \boldsymbol{w} + c \times \sum_{i=1}^n \max[0, 1 - y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b)] \quad (8.37)$$

很显然，所有被正确分类的数据存在 $y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b) \geqslant 1$，因此在 Hinge 损失函数作用下，这些被正确分类数据的 Hinge 损失 $\max[0, 1 - y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b)] = 0$。于是，Hinge 函数只会记录分类错误数据的损失。

记 $\xi_i = \max[0, 1 - y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b)] [\xi_i 称为第 i 个变量的松弛变量（slack variables）]，显然 $\xi_i \geqslant 0$。每一个样本对应一个松弛变量，用来表示该样本被分类错误所产生的损失。于是，可将式（8.37）重写为

$$\min_{\boldsymbol{w}, b} \frac{1}{2} \boldsymbol{w}^T \boldsymbol{w} + c \times \sum_{i=1}^n \xi_i \quad (8.38)$$ $$\text{s.t. } y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b) \geqslant 1 - \xi_i \quad (8.39)$$ $$\xi_i \geqslant 0, \quad i = 1, 2, \cdots, n \quad (8.40)$$

这就是最常见的软间隔支持向量机需要优化的目标函数（也称为原问题）。

对于上述目标函数，通过拉格朗日乘子法可得到拉格朗日函数：

$$L(\boldsymbol{w}, b, \boldsymbol{\alpha}, \boldsymbol{\xi}, \boldsymbol{\mu}) = \frac{1}{2} \boldsymbol{w}^T \boldsymbol{w} + c \times \sum_{i=1}^n \xi_i + \sum_{i=1}^n \alpha_i [1 - \xi_i - y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b)] - \sum_{i=1}^n \mu_i \xi_i \quad (8.41)$$

式中，$\alpha_i \geqslant 0$、$\mu_i \geqslant 0$ 为拉格朗日乘子。

先固定拉格朗日乘子 $\alpha_i$ 和 $\mu_i$，将上述问题转换成对偶问题；然后对 $\boldsymbol{w}$、$b$ 和 $\xi_i$ 求偏导，并令导数为 0，可得

$$\boldsymbol{w} = \sum_{i=1}^n \alpha_i y_i \boldsymbol{x}_i \quad (8.42)$$ $$0 = \sum_{i=1}^n \alpha_i y_i \quad (8.43)$$ $$\alpha_i + \mu_i = c \quad (8.44)$$
