如果环境提供的是高水平信息，学习环节就要补充遗漏的细节，以便执行环节能将其用于更具体的情况；如果环境提供的是低水平信息，学习环节则会将这些具体实例归纳出适合一般情况的规则，以便执行环节将其用于更广泛的任务。

信息的质量是指信息的正确性和信息在组织上的合理性等。环境中的信息质量对学习难度有明显影响。例如，如果环境的示例中有干扰，或示例的次序不合理，那么学习环节很难对其进行归纳。

# (2) 知识库

知识库的形式和内容是影响学习系统设计的第二个因素。知识库的形式与知识表示方法直接相关，常用的知识表示方法有谓词逻辑、产生式、语义网络、框架等。选择知识表示方法的准则有可表达性、可推理性、可修改性和可扩充性等。

知识库的初始知识非常重要，学习系统不可能在没有任何知识的情况下凭空获取知识。通常，先利用初始知识理解环境提供的信息，然后逐步进行学习。学习系统的学习过程实质上是对原有知识库的扩充和完善的过程。

# (3) 执行环节

执行环节是整个学习系统的核心，与学习环节相互联系。其目的是改善执行环节的行为，而执行环节的复杂度、反馈及透明性又会对学习环节产生一定的影响。

+   1) 复杂度。不同复杂度的任务所需的知识不一样，一般来说，一个任务越复杂，所需的知识就会越多。

+   2) 反馈。所有的学习系统都必须有从执行环节到学习环节的反馈信息。反馈信息是根据执行环节的执行情况，对学习环节所获知识的评价。学习环节根据反馈信息决定是否需要从环境中进一步获取信息，以修改、完善知识库中的知识。

目前，学习系统采取的评价方式主要有两种：一种是由系统自动进行评价，另一种是由人协助完成评价。由系统自动完成评价是指将评价时所需要的性能指标直接建立在学习系统中，由系统自动对执行环节得到的结果进行评价；由人协助完成评价是指由人提出外部执行标准，观察执行环节相对这个标准的执行情况，并将比较结果反馈给学习环节。

+   3) 透明性。透明性是指从系统执行部分的动作效果可以容易地对知识库的规则进行评价。由此可见，执行环节的透明性应该越高越好。

# 7.2.3 神经网络的结构与工作方式

# 1. 神经网络的结构

神经网络是一个由众多简单的神经元连接而成的网络。尽管每个神经元结构、功能都不复杂，但神经网络的行为并不是各单元行为的简单相加，网络的整体动态行为为极为复杂，可以组成高度非线性动力学系统，从而描述很多复杂的物理系统，表现出不可预测性、不可逆性、多吸引子、可能出现混沌现象等一般复杂非线性系统的特性和作为神经网络系统的各种性质。神经网络具有大规模并行处理和分布式存储能力，也有自适应、自组织、自学习的特点，在许多领域得到了成功的应用，展现了非常广阔的应用前景。

众多神经元的轴突和其他神经元或者自身的树突相连接，构成复杂的神经网络。根据神经网络中神经元的连接方式，神经网络可以划分为不同类型的结构。目前，人工神经网络主要有前馈型和反馈型两大类，如图 7.6 所示。
