通过上面的变换可以看出，问题规约的实质是从目标（要解决的问题）出发逆向推理，建立子问题及子问题的子问题，直至最后把初始问题规约为一个平凡的本原问题集合。

在简单问题的规约过程中，各子问题相互独立，所以子问题的进一步规约和本原问题的求解无交互作用，可按任意次序进行。然而对于许多复杂问题，子问题仅相对独立，它们之间仍存在一定的交互作用。在这种情况下，正确安排子问题求解的先后次序，甚至子子问题求解的次序是非常重要的。

例如，以汉诺塔问题为例，其问题描述如下：有编号为 1、2、3 的 3 根柱子和标识为 A、B、C 的尺寸依次为小、中、大的 3 个中心有孔的圆盘。初始状态下，3 个圆盘按 A、B、C 顺序堆放在 1 号柱子上，目标状态下 3 个圆盘以同样次序顺序堆放在 3 号柱子上。圆盘的搬移须遵守以下规则：每次只能搬一个圆盘，且较大圆盘不能压放在较小圆盘之上，如图 3.15 所示。

![](bbox=[0.26, 0.32, 0.74, 0.38])

图 3.15 汉诺塔问题

以三元素列表作为数据结构描述问题状态，3 个元素依次指示圆盘 A、B、C 所在的柱子编号。例如，汉诺塔问题可描述为(1, 1, 1)=>(3, 3, 3)。该问题可以规约为 3 个子问题 (1, 1, 1)=>(2, 2, 1)、(2, 2, 1)=>(2, 2, 3)和(2, 2, 3)=>(3, 3, 3)，即先把 A、B 圆盘搬到柱子 2，再把 C 圆盘搬到柱子 3，最后把 A、B 圆盘搬到柱子 3。第 1、3 两个子问题再分别规约为子子问题，如下：(1, 1, 1)=>(3, 1, 1)、(3, 1, 1)=>(3, 2, 1)、(3, 2, 1)=>(2, 2, 1)，即依次搬 A 圆盘到柱子 3、B 圆盘到柱子 2、A 圆盘到柱子 2；(2, 2, 3)=>(1, 2, 3)、(1, 2, 3)=>(1, 3, 3)、(1, 3, 3)=>(3, 3, 3)，即依次搬 A 圆盘到柱子 1、B 圆盘到柱子 3、A 圆盘到柱子 3。现在所有子问题均为本原问题，只要依次解决就可到达目标状态。汉诺塔问题的子问题与子子问题之间有交互作用，必须注意正确的排序。其状态空间如图 3.16 所示，其中已标出正确的节点生成顺序。

![](bbox=[0.18, 0.625, 0.8, 0.79])

可以看出，应用问题规约策略求解问题的原理很简单，方法也很有效，因此其得到了广泛和深入的研究及应用。
