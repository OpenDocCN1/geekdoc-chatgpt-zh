随机锦标赛模型的好处在于它不用考虑适应值比例选择和基于排名的选择，在群体规模很大时，不用考虑算法的计算总体适应值或排序占用大量资源的问题。它常常比轮盘赌选择更容易得到多样化的群体。随机锦标赛模型使得适应值好的个体具有更大的生存机会。同时，由于它只是用适应值的相对值作为选择的标准，而与适应值的数值大小不成直接比例，从而也能避免超级个体的影响，从一定程度上避免了过早收敛和停滞现象的发生。

# (2) 参数设置

遗传算法中的参数对算法性能起到了十分重要的作用。遗传算法涉及的主要控制参数有群体规模 N、染色体体长度 L、变异概率 Pm、交配概率 Pc、基因的取值范围 R、终止条件、适应值评价等。

# 1) 群体规模 N。

群体规模 N 对算法的搜索能力和运行效率有很大的影响。若 N 设置较大，一次进化所覆盖的模式较多，则可以保证群体的多样性，从而提高算法的搜索能力；但是由于群体中染色体的个数较多，这势必增加算法的计算量，从而降低算法的运行效率。若 N 设置较小，虽然降低了计算量，但是是同时降低了每次进化中群体包含更多较好染色体的能力。一般来说，N 设置的范围为 20~100。

# 2) 染色体长度 L。

染色体长度 L 影响算法的计算量和交配变异操作的效果。L 的设置与优化问题密切相关，一般由问题定义的解的形式和选择的编码方法决定。对于浮点数编码方法，染色体长度 L 与问题定义的解的维数 D 相同；对于二进制编码方法，染色体长度 L 根据解的取值范围和规定精度要求选择大小。
