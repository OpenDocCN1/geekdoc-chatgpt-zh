# 2.6.3 过程表示法的特点

过程表示法的知识表示效率高且控制系统容易实现。过程表示法是用程序表示知识，而程序能准确地表明先做什么、后做什么及怎样做，并直接嵌入一些启发式的控制信息。因此，过程表示法可以避免选择及匹配那些无关的知识，也不需要跟踪那些不必要的路径，从而提高了系统的运行效率；同时，由于控制性质已嵌入程序中，因此控制系统就比较容易设计。

过程表示法的主要缺点是知识库不易维护及其使用的表示范围较窄。由于过程表示法是一种将知识蕴涵于程序中的表示法，因此不易对知识库进行修改或更新。另外，当要对知识库中的某一过程进行修改时，可能又会影响该过程调用的其他过程，所以对知识库的维护极不方便。同时，由于某些知识并不适于用程序表示，因此过程表示法适用的范围相当有限。

# 2.6.4 过程性与说明性表示方法的比较

说明性表示方法是对知识和事实的一种静态描述，是对知识的一种显式表达形式。过程表示法则是将有关某一问题领域的知识，连同如何使用这些知识的方法，都隐式地表达为一个求解问题的过程。它强调的是知识的动态方面，即如何发现相关的知识并进行推理，因此过程能够更好地体现知识的行为。过程表示法是将知识包含在若干过程之中，过程是一小段程序，它处理某些特殊事件或特殊状况。每个过程都包含说明客体和事件的知识，以及在说明完好的情况下的运行知识等。过程通常用子程序或模块实现。知识库是一组过程集合，知识库的修改即为增加/删除子程序，或修改子程序及访问条件。

与说明性表示方法相比，过程表示法更有利于表示启发式知识，能实现扩充逻辑推理（如缺省推理等），具有高度模块化的优点，能够通过类比进行推理。然而，过程表示方法本身的适用范围比较窄，但是研究说明性表示与过程性表示相结合的高效、易维护、可理解的知识表示方法却是很有意义的。

如何将说明性知识表示与过程性知识表示相结合来表示知识，以便在系统的可维护性、可理解性及运行效率等方面取得较好的效果是今后的发展方向。

# 2.7 语义网络表示法

在计算史上，剑桥语言研究部的理查德·胡克·里奇斯（Richard Hook RIchens）在 1956 年首先意识到语义网络逻辑的重要性，并将该思想应用于自然语言机器翻译。1968 年，语义网络在奎廉（Quillian）研究人类联想记忆时作为一种心理学模型被提出，他认为记忆是由概念间的联系实现的。随后，奎廉又把语义网络用作知识表示。1975 年，得克萨斯大学的亨德里克斯（Hendrix）又对全称量词的表示提出了语义网络分区技术。发展至今，语义网络已经成为人工智能中应用较多的一种知识表示方法，尤其是在自然语言处理方面的应用。
