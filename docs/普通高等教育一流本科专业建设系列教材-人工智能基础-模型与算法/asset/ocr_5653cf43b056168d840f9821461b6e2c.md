+   $R_4$: 如果头疼发烧，则大概是患了感冒。
+   $R_5$: 小王是高个子。
+   $R_6$: 张三和李四是好朋友。

在例 4.4 中，命题 $R_1$ 和 $R_2$ 是确定性推理，因为推理所用的知识和证据是确定的，得到的结论也是确定的；命题 $R_3$、$R_4$、$R_5$ 和 $R_6$ 是不确定性推理，其中命题 $R_3$、$R_4$ 的真实性不能完全肯定，只能对其为真的可能性给出某种估计；命题 $R_5$、$R_6$ 中某些言语含义不够确切，从概念角度讲，其代表的概念的内涵没有硬性的标准或条件，外延没有硬性的边界，这种含义不确切的言辞所代表的概念称为模糊概念。

# 3. 按推理过程中所得结论的目标性划分

按推理过程中所得结论的目标性划分，推理可分为单调推理（monotonic reasoning）和非单调推理（non-monotonic reasoning）。

# (1) 单调推理

一般来说，经典逻辑主要是指形式逻辑或演绎逻辑。经典逻辑的推理形式是演绎和单调的，其演绎性和单调性表现在，推理以已有知识为前提必然能得到新的知识，或者说在保证已有知识为真的前提下，由推理所得的新知识必定为真。单调推理是指在推理过程中随着推理向前推进及新知识的加入，推出的结论越来越接近最终目标。加进系统的新知识要求必须与已有的知识相一致。随着运行时间的推移，系统内所含的知识有增无减。由此可知，经典逻辑的优点在于语法上保证推理的严格性，语义上保证推理的有效性，只需要确保前提部分的真就可以获取真的新知识。

多数形式逻辑有单调性的推论关系，即如果一个句子可以从集合 $T$ 中推理出来，集合 $T$ 是任意集合 $S$ 的子集，那么这个句子也可以从集合 $S$ 中推理出来，这意味着向理论中增加一个公式永不引起其推论集合的减小。单调性在直觉上表现为，学习一些新知识不会减少已知知识的集合。

单调逻辑不能处理默认推理、溯因推理、关于知识的推理和信念修正等推理任务。其中，默认推理的事实可以是已知的，但是缺乏反例证据；溯因推理的事实只按最合适的解释演绎出来；关于知识的推理是在事实变成已知时，对一个事实的无知必须被撤销；信念修正指的是新知识可以和旧信念矛盾。日常语境下，经常出现的情况是新知识与已有知识之间发生冲突，在必要时人们会修改已有知识，以适应对新情况的解释，这就体现出单调推理的局限性。为解决这一难题，满足常识推理的要求，非单调推理便应运而生。

# (2) 非单调推理

与单调推理相对，非单调推理是指在知识库加入新知识之后，原有的推论会被推翻的逻辑。也就是说，知识库的推论不一定随着知识增长而增长，新知识的加入不仅没有加强已推出的结论，反而要否定它，使推理退回到前面的某一步，重新开始。这时，必须使用某种正确的维持机制，确保推理继续进行。非单调推理给由单调推理所得出的结论上标了一个问号，随着对前提集中所包含的已知信息和未知信息的确定，结论的问号会暂时消除，或者修改结论。非单调推理多是在知识不完全的情况下发生的，如默认推理。

非单调推理的最终目标是实现推理的合理性，这里的合理性主要是指合乎常识的一般情况，或者能合乎情理地解释现实状况等。这不同于单调推理所要求的有效性，推理的合理性往往带有时效性和主观性，这种时效性与主观性体现出模态的特征。
