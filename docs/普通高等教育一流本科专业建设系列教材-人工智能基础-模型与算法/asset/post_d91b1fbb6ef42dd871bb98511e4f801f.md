
更好(X, Y) <- 色泽更深(X, Y) (8.28)

该规则仍覆盖 2 个反例，即“更好(15,1)”与“更好(15,6)”。于是，FOIL 像命题规则学习那样继续增加规则体长度，最终生成合适的单条规则加入规则集。此后，FOIL 使用后剪枝对规则集进行优化。

若允许将目标谓词词作为候选文字加入规则体，则 FOIL 能学出递归规则；若允许将否定形式的文字 ¬f 作为候选，则能得到更简洁的规则集。

FOIL 可大致看作命题规则学习与归纳逻辑程序设计之间的过渡，其自顶向下的规则生成过程不能支持函数和逻辑表达式嵌套，因此规则表达能力仍有不足；但它是把命题规则学习过程通过变量替换等操作直接转化为一阶规则学习，因此比一般归纳逻辑程序设计技术更高效。

关联规则有以下几种常见分类。根据关联规则所处理的值的类型，如果考虑关联规则中的数据项是否出现，则这种关联规则是布尔关联规则（Boolean association rules）；如果关联规则中的数据项是数量型的，则这种关联规则是数量关联规则（quantitative association rules）。例如，年龄（“20～25”）购买（“网球拍”），年龄是一个数量型的数据项。在这种关联规则中，一般将数量离散化（discretize）为区间。

根据关联规则所涉及的数据维度，如果关联规则各项只涉及一个维度，则它是单维（single-dimensional）关联规则，如购买（“网球拍”）购买（“网球”）只涉及“购买”一个维度；如果关联规则涉及两个或两个以上维度，则它是多维（multi-dimensional）关联规则，如年龄（“20～25”）购买（“网球拍”）涉及“年龄”和“购买”两个维度。

根据关联规则所涉及的抽象层次，如果不涉及不同层次的数据项，则得到的是单层（single-level）关联规则。在不同抽象层次中挖掘出的关联规则称为广义（generalized）关联规则。例如，年龄（“20～25”）购买（“HEAD 网球拍”）和年龄（“20～25”）购买（“网球拍”）是广义关联规则，因为“HEAD 网球拍”和“网球拍”属于不同的抽象层次。

可以执行关联规则学习的常用算法有 Apriori 算法、FP-Growth/FP-tree（frequent pattern mining，频繁模式挖掘）、Eclat 算法、AIS 算法、SETM 算法和序列模式挖掘等。

## 8.3 基于数据统计的机器学习

基于数据统计的机器学习是指计算机基于数据构建概率统计模型并运用模型对数据进行预测与分析。基于数据统计的机器学习三要素为模型、策略和算法。模型，即所要学习的条件概率分布或决策函数，模型的假设空间包含所有可能的条件概率分布或决策函数；统计机器学习的目标在于从模型的假设空间中选取最优模型，那么策略就是需要考虑选取什么样的准则来学习或选择最优模型，具体的策略有经验风险最小化和结构风险最小化；算法是指学习模型的具体计算方法，主要包括支持向量机、浅层神经网络及贝叶斯分类器。

### 8.3.1 支持向量机

传统识别理论认为，算法模型性能可用从训练样本集得到的经验风险（empirical risk）来衡量。经验风险指算法模型在训练样本集中所有数据上所得误差的累加。很明显，经验风险越小，算法模型对训练数据拟合程度越好。在实际上，一味要求经验风险小，往往会造成过学习问题（over-fitting）。

支持向量机通过结构风险最小化（structural risk minimization）来解决过学习问题。图 8.9 给出了一个两分类问题，图中存在多个可将样本分开的超平面（hyper-plane），支持向量机学习算法会寻找一个最佳超平面，使得每个类别中距离超平面最近的样本点到超平面的最小距离最大。

### 1. VC 维与结构风险最小化

在理论上，支持向量机认为分类器对未知数据（测试数据）进行分类时所产生的期望风险（expected risk，真实风险）不是由经验风险单独决定的，而是由以下两部分组成：①从训练集合数据所得经验风险（如果经验风险小、期望风险很大，则是过学习）；②置信（confidence）风险，它与分类器的 VC（Vapnik Chervonenkis）维及训练样本数目有关。如果 \(0 \leqslant \eta \leqslant 1\)，则 VC 理论推导出的期望风险 \(\mathcal{R}\) 和经验风险 \(\mathcal{R}_{\text{emp}}\) 以 \(1-\eta\) 的概率满足如下关系：

\(\mathcal{R} \leqslant \mathcal{R}_{\text{emp}} + \sqrt{\frac{h \left[ \log \left( \frac{2n}{h} \right) + 1 \right] - \log \left( \frac{\eta}{4} \right)}{n}}\) (8.29)

式中，\(\sqrt{\frac{h \left[ \log \left( \frac{2n}{h} \right) + 1 \right] - \log \left( \frac{\eta}{4} \right)}{n}}\) 为 VC 置信值；\(n\) 为训练样本个数；\(h\) 为反映学习机复杂程度的 VC 维。

因为期望风险 \(\mathcal{R}\) 代表分类器对未知数据分类推广的能力，所以 \(\mathcal{R}\) 越小越好。在不等式（8.29）中，VC 置信值是 \(h\) 的增函数，\(\mathcal{R}_{\text{emp}}\) 是 \(h\) 的减函数，于是选择一个折中的 \(h\) 值可以使期望风险 \(\mathcal{R}\) 达到最小。支持向量机使用结构风险最小化准则来选取 VC 维 \(h\)，使每一类别数据之间的分类间隔（margin）最大，最终使期望风险 \(\mathcal{R}\) 最小。

### (1) 假设空间的 VC 维

将 \(n\) 个数据分为两类，可以有 \(2^n\) 种分法，即可理解成有 \(2^n\) 个学习问题。若存在一个假设 \(\mathcal{H}\)，能准确无误地将 \(2^n\) 种问题进行分类，那么 \(n\) 就是 \(\mathcal{H}\) 的 VC 维。

一般地，在 \(r\) 维空间中，线性决策面的 VC 维为 \(r+1\)。VC 维就是对假设空间 \(\mathcal{H}\) 复杂度的一种度量。当样本数 \(n\) 固定时，如果 VC 维越高，则算法模型的复杂性越高。VC 维越大，通常推广能力越差，置信风险会变大。如果算法模型一味降低经验风险，则会提高模型复杂度，导致 VC 维很高，置信风险大，使得期望风险就大，如图 8.10 所示。

图 8.10 经验风险、期望风险、VC 置信度、VC 维、过学习和欠学习的关系

### (2) 结构风险最小化

通过 VC 理论，可以认识到期望风险（真实风险）R 与经验风险 R_emp 之间是有差别的，该差别项称为置信风险，它与训练样本个数和模型复杂度都有密切关系。用复杂度高的模型拟合小样本，往往会导致过拟合，因此需要给经验风险 R_emp 加上一个惩罚项或者正则化项，以同时考虑经验风险与置信风险。这一思路被称为结构风险最小化。这样，在小样本情况下可取得较好性能。在保证分类精度高（经验风险小）的同时，有效降低算法模型 VC 维，可使算法模型在整个样本集上的期望风险得到控制。当训练样本给定时，分类间隔越大，对应的分类超平面集合的 VC 维就越小。

### 2. 线性可分支持向量机

对于 n 个训练数据 \((x_i, y_i) \in D(i = 1, 2, \cdots, n)\)，记其类别标签为 1 或 -1 (\(y_i = 1\) 或 \(y_i = -1\))，分别代表正样本或负样本。支持向量机从这些训练数据出发，寻找一个最优的超平面，其方程为 \(w^T x + b = 0\)。这里 \(w = (w_1, w_2, \cdots, w_d)\) 为超平面的法向量，与超平面的方向有关；\(b\) 为偏置项，是一个标量，其决定了超平面与原点之间的距离。

显然，为了保证每个样本都被正确分类，对于正样本要求满足 \(w^T x + b \geqslant 0\)，对于负样本要求满足 \(w^T x + b < 0\)。

样本空间中任意样本 \(x\) 到该平面距离可表示为

\(r = d(w,b,x) = \frac{|w^T x + b|}{\|w\|_2}\) (8.30)

式中，\(\|w\|_2 = \sqrt{w^T w}\)。

由于法向量 \(w\) 中的值可按比例任意缩放而不改变法向量方向，使得分类平面不唯一，因此，对 \(w\) 和 \(b\) 添加如下约束：

\(r_{\min}|w^T x_i + b| = 1\) (8.31)

即离超平面最近的正负样本代入超平面方程后其绝对值为 1。于是对超平面的约束变为 \(y_i(w^T x_i + b) \ge 1\)。两类样本中离分类超平面最近的数据之间的距离可用下式计算：

\(\begin{aligned} d(w,b) &= \min_{(x_k, y_k=1)} d(w,b, x_k) + \min_{(x_m, y_m=-1)} d(w,b, x_m) \\ &= \min_{(x_k, y_k=1)} \frac{|w^T x_k + b|}{\|w\|_2} + \min_{(x_m, y_m=-1)} \frac{|w^T x_m + b|}{\|w\|_2} \\ &= \frac{1}{\|w\|_2}[\min_{(x_k, y_k=1)} |w^T x_k + b| + \min_{(x_m, y_m=-1)} |w^T x_m + b|] \\ &= \frac{2}{\|w\|_2} \end{aligned}\)

支持向量机的基本形式就是最大化分类间隔，即在满足约束的条件下找到参数 \(w\) 和 \(b\)，使得 \(\gamma\) 最大，即等价于：

\(\min_{w,b} \frac{\|w\|_2^2}{2} = \min_{w,b} \frac{1}{2} w^T w\) (8.32)

\(\text{s.t. } y_i(w^T x_i + b) \ge 1, i = 1, 2, \cdots, n\) (8.33)

上面带约束条件的最值优化问题是一个凸二次规划（convex quadratic）问题，可通过构造拉格朗日函数及将其转换成对偶（dual）问题求解。

图 8.11 所示为线性分类超平面及其支持向量。可见，正负类别中距离超平面最近的样本点到超平面的距离被约束为 1。如果 \(x_i\) 为正样本，则 \(w^T x_i + b \ge 1\)；反之，\(w^T x_i + b \le -1\)。考虑到正样本的标签为 1，负样本的标签为 -1，因此有 \(y_i(w^T x_i + b) \ge 1\)。距离超平面最近的几个训练样本点使得该公式等号成立，它们被称为支持向量。

![](img/01b3dd63f105ee2f61ade787bae553f5_267_0.png)

图 8.11 线性分类超平面及其支持向量

支持向量机的主要优点是：可以解决高维问题，即大型特征空间；可以解决小样本下的机器学习问题；能够处理非线性特征的相互作用，克服局部极小值问题；无须依赖整个数据；泛化能力比较强。其缺点是：当观测样本很多时，效率并不是很高；对非线性问题没有通用的解决方案。支持向量机目前已成功应用于文本分类、图像识别等领域，尤其是在二分类领域最为常用。

### 3. 松弛变量、软间隔与 Hinge 损失函数

先前介绍中假设所有训练样本数据线性可分，即存在一个线性超平面，能将不同类别的样本完全隔开，这种情况称为硬间隔（hard margin）。与硬间隔相对的是软间隔（soft margin），软间隔是指允许部分错分给定的训练样本。

在软间隔情况下，算法在使得每个类别中距离超平面最近样本到超平面的最小距离最大的同时，还应使不满足约束条件的样本数目尽可能少，因此目标函数可表示如下：

\(\min_{w,b} \frac{1}{2} \boldsymbol{w}^T \boldsymbol{w} + c \times \sum_{i=1}^n [y_i \neq \text{sign}(\boldsymbol{w}^T \boldsymbol{x}_i + b)]\) (8.34)

\(\text{s.t. } y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b) \geqslant 1 \text{ for correct } \boldsymbol{x}_i\) (8.35)

\(y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b) \geqslant -\infty \text{ for incorrect } \boldsymbol{x}_i\) (8.36)

式中，\(c\) 为一个常数；\([y_i \neq \text{sign}(\boldsymbol{w}^T \boldsymbol{x}_i + b)]\) 为指示（indicator）函数，表示对 \(\boldsymbol{x}_i\) 的分类结果与其正确类别标签 \(y_i\) 是否一致，如果不一致则指示函数输出为 1，否则输出为 0。

然而，上述目标函数难以直接求解。为此，引入 Hinge 损失函数，即有

\(\min_{w,b} \frac{1}{2} \boldsymbol{w}^T \boldsymbol{w} + c \times \sum_{i=1}^n \max[0, 1 - y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b)]\) (8.37)

很显然，所有被正确分类的数据存在 \(y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b) \geqslant 1\)，因此在 Hinge 损失函数作用下，这些被正确分类数据的 Hinge 损失 \(\max[0, 1 - y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b)] = 0\)。于是，Hinge 函数只会记录分类错误数据的损失。

记 \(\xi_i = \max[0, 1 - y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b)]\) [\(\xi_i\) 称为第 i 个变量的松弛变量（slack variables）]，显然 \(\xi_i \geqslant 0\)。每一个样本对应一个松弛变量，用来表示该样本被分类错误所产生的损失。于是，可将式（8.37）重写为

\(\min_{\boldsymbol{w}, b} \frac{1}{2} \boldsymbol{w}^T \boldsymbol{w} + c \times \sum_{i=1}^n \xi_i\) (8.38)

\(\text{s.t. } y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b) \geqslant 1 - \xi_i\) (8.39)

\(\xi_i \geqslant 0, \quad i = 1, 2, \cdots, n\) (8.40)

这就是最常见的软间隔支持向量机需要优化的目标函数（也称为原问题）。

对于上述目标函数，通过拉格朗日乘子法可得到拉格朗日函数：

\(L(\boldsymbol{w}, b, \boldsymbol{\alpha}, \boldsymbol{\xi}, \boldsymbol{\mu}) = \frac{1}{2} \boldsymbol{w}^T \boldsymbol{w} + c \times \sum_{i=1}^n \xi_i + \sum_{i=1}^n \alpha_i [1 - \xi_i - y_i (\boldsymbol{w}^T \boldsymbol{x}_i + b)] - \sum_{i=1}^n \mu_i \xi_i\) (8.41)

式中，\(\alpha_i \geqslant 0\)、\(\mu_i \geqslant 0\) 为拉格朗日乘子。

先固定拉格朗日乘子 \(\alpha_i\) 和 \(\mu_i\)，将上述问题转换成对偶问题；然后对 \(\boldsymbol{w}\)、\(b\) 和 \(\xi_i\) 求偏导，并令导数为 0，可得

\(\boldsymbol{w} = \sum_{i=1}^n \alpha_i y_i \boldsymbol{x}_i\) (8.42)

\(0 = \sum_{i=1}^n \alpha_i y_i\) (8.43)

\(\alpha_i + \mu_i = c\) (8.44)

将上述结果代入拉格朗日函数中，消除 \(\boldsymbol{w}\)、\(b\) 和 \(\xi_i\) 这些变量，得到关于拉格朗日乘子变量 \(\alpha_i\) 和 \(\mu_i\) 的函数，然后控制乘子变量，对函数取最大值：

\(\max_{\alpha} \sum_i \alpha_i - \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \alpha_i \alpha_j y_i y_j \mathbf{x}_i^{\mathrm{T}} \mathbf{x}_j\) (8.45)

\(\text{s.t. } \sum_{i=1}^n \alpha_i y_i = 0\) (8.46)

\(0 \leqslant \alpha_i \leqslant c, i=1, 2, \cdots, n\) (8.47)

求解上述带约束的优化问题，可得到拉格朗日乘子 \(\alpha_i\) 的计算结果，根据 \(\alpha_i\) 的结果计算 \(w\) 和 \(b\) 的值。支持向量机的对偶问题与原问题拥有相同的解，其中：

\(w = \sum_i \alpha_i y_i \mathbf{x}_i\) (8.48)

而 \(b\) 的求解方法将在接下来进行讨论。

原问题的解需满足 KKT（Karush-Kuhn-Tucker）条件，因此原问题（和对偶问题）取得最优解时有以下关系：

\(\begin{cases} \alpha_i [1 - \xi_i - y_i (\mathbf{w}^T \mathbf{x}_i + b)] = 0 \\ \mu_i \xi_i = 0 \\ \xi_i, \mu_i, \alpha_i \geqslant 0 \end{cases}\) (8.49)

因此，当 \(0 < \alpha_i < c\) 时，有 \(\mu_i > 0, \xi_i = 0\)，同时 \(1 - \xi_i - y_i (\mathbf{w}^T \mathbf{x}_i + b) = 0\)，此时样本刚好落在间隔边界上；当 \(\alpha_i = 0\) 时，有 \(\mu_i = c, \xi_i = 0\)，同时 \(1 - \xi_i - y_i (\mathbf{w}^T \mathbf{x}_i + b) = 0\)，此时样本可能在间隔边界上，也可能在间隔边界外；当 \(\alpha_i = c\) 时，有 \(\mu_i = 0, \xi_i \geqslant 0\)，同时 \(1 - \xi_i - y_i (\mathbf{w}^T \mathbf{x}_i + b) = 0\)，此时样本可能在分类平面和间隔平面之间，也可能在分类平面误分的一侧。根据以上性质，只需找到样本 \(j\) 满足 \(0 < \alpha_j < c\)，即可求解参数 \(b\)：

\(b = y_i - \mathbf{w}^T \mathbf{x}_j\) (8.50)

注意到当 \(\alpha_i = 0\) 时，第 \(i\) 个样本对 \(w\) 和 \(b\) 的解并没有任何贡献，因此即使去除第 \(i\) 个样本，支持向量机的解也不会发生变化；反之，当 \(\alpha_i > 0\) 时，该样本对构造解平面做出了贡献，因此被称为一个“支持向量”。由此可导出支持向量机的一个重要性质：训练完成后，大部分训练样本可以舍去，最终模型仅与若干支持向量有关。

\(\alpha\) 可以采用 SMO（sequential minimal optimization）算法进行求解。SMO 先固定除 \(\alpha_i\) 之外的所有参数，在此基础上求解 \(\alpha_i\)。由于存在约束 \(\sum_{i=1}^n \alpha_i y_i = 0\)，若固定 \(\alpha_i\) 之外的其他变量，则 \(\alpha_i\) 可以由其他变量推算出来，因此 SMO 每次选择两个变量 \(\alpha_i\) 和 \(\alpha_j\)，并固定其他参数，不断执行如下步骤直至收敛。

- 1) 选取一对需更新的变量 \(\alpha_i\) 和 \(\alpha_j\)。
- 2) 固定除 \(\alpha_i\) 和 \(\alpha_j\) 之外的所有参数，简化约束得到 \(\alpha_i y_i + \alpha_j y_j - \sum_{k \neq i,j} \alpha_k y_k = \text{常数}\)。
- 3) 计算使目标函数最大的 \(\alpha_i\) 和 \(\alpha_j\) 并更新。

关于 \(\alpha_i\) 和 \(\alpha_j\) 的选取有多种方式，比较简单常用的方式是选取两个对应样本间隔最大的 \(\alpha_i\) 和 \(\alpha_j\)。在 \(\alpha\) 收敛后，通过 \(w = \sum_{i=1}^n \alpha_i y_i x_i\) 求解分类超平面 \(w\)。理论上可以使用任意支持向量借助 \(y_i f(x_i) = 1\) 计算偏移量 \(b\)，现实中也常将所有支持向量代入进行求解的结果去取平均
