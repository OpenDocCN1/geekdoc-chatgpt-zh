# (5) 其他改进的遗传算法

混合遗传算法（hybrid genetic algorithm，HGA）结合了多种优化算法，可以得到性能更优的算法，提高算法求解问题的能力。在局部搜索能力方面，遗传算法搜索效果偏弱，而其他搜索算法，如爬山法（hill-climbing algorithm）、最速下降法（steepest descent method）、局部搜索算法（local search algorithm）和模拟退火算法等，在局部搜索方面具有得天独厚的优势，将这些优化方法融入遗传算法可以成为改进遗传算法局部搜索能力的有效途径。虽然遗传算法对问题应用求解具有很强的普适性，但是应用于特定的专门领域问题时，遗传算法可能不是解决问题的最佳方法，并不能保证最佳的求解性能；而在遗传算法中加入专门领域特定知识时，遗传算法的性能可能会明显改善。

CHC 算法是埃舍尔曼（Eshelman）于 1991 年提出的一种改进的遗传算法的缩称，第一个 C 代表跨世代精英选择（cross generational elitist selection）策略，H 代表异物种重组（heterogeneous recombination），第二个 C 代表突变（cataclysmic mutation）。不同于传统的遗传算法依据个体的适应度复制个体完成选择操作，CHC 遗传算法将上世代种群与通过新的交叉方法产生的个体群混合起来，从中按一定概率选择较优的个体，这一策略称为跨世代精英选择。此外，CHC 算法对变异算子和交叉算子也进行了一些改进，使得 CHC 遗传算法具有更好的遗传多样性和健壮性。

并行遗传算法在传统遗传算法的基础上引入了并行计算技术。并行遗传算法分为标准型并行算法和分解型并行算法两种。标准型并行算法没有改变传统遗传算法的串行计算结构，只是在适应值计算、选择算子、交叉算子、变异算子中使用了并行计算技术，在一定程度上提高了遗传算法的计算效率。分解型并行算法更加贴合自然界生物进化的过程，它是将种群分成几个部分，分别独立地使用原有的遗传算法进化。独立进化的各个生物群体面临的环境不同，它们所处的进化阶段也不尽相同。围绕并行遗传算法的信息交换操作，研究人员提出了岛屿模型（island model）、踏脚石模型（stepping-stone model）、邻居模型（neighborhood model）等，这些模型各有所长，大大提高了遗传算法的运行效率。

# 4. 遗传算法的应用

遗传算法的主要应用领域包括组合优化、函数优化、智能控制、机器人学、规划、设计、图像处理、信号处理、人工生命等，此外也出现了很多正在飞速发展的新领域、新问题。

# (1) 组合优化

组合优化是指在给定约束条件下，求解目标函数的最优值。实践证明，遗传算法已经在求解旅行商问题、背包问题、装箱问题、布局优化、网络路由等具有 NP 难度的组合优化问题上取得了成功的应用。通过遗传算法，可以在后台对这些问题进行建模，快速得到最佳线路规划。
