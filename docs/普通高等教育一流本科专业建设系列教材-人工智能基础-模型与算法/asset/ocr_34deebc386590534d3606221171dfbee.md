\(\frac{1}{R_i}u_i + C_i \frac{du_i}{dt} = I_i + \sum_{j=1}^N w_j v_j \quad (7.86)\)
\(v_i = f(u_i) = \frac{1}{1 + e^{-\frac{2u_i}{u_0}}}, i = 1, 2, \cdots, N \quad (7.87)\)

式中，\(I_i\) 为施加在神经元 \(i\) 上的偏置电流，表示系统外部的输入；\(w_{ij} = \frac{1}{R_{ij}}\) 模拟神经元 \(j\) 与神经元 \(i\) 之间互连的突触特性；\(f(u_i)\) 为放大器的非线性饱和特性，近似于 S 形函数。

连续型 Hopfield 神经网络模型在简化了生物神经元性质的同时，重点突出了以下重要特性。第一，神经元作为一个输入输出变换，其传输特性具有 Sigmoid 特性；第二，细胞膜具有时空整合作用；第三，神经元之间存在大量的兴奋和抑制性连接，这种连接主要是通过反馈来实现的；第四，具有既代表产生动作电位的神经元，又代表按渐进方式工作的神经元的能力。

因此，连续型 Hopfield 神经网络准确地保留了生物神经网络的动态和非线性特征，有助于理解大量神经元之间的协同作用是怎样产生巨大的计算能力的。
连续型 Hopfield 神经网络的计算能量函数 \(E(t)\) 定义为

\(E(t) = -\frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N w_{ij} v_i(t) - \sum_{i=1}^N v_i(t) I_i + \sum_{i=1}^N \frac{1}{R_i} \int_0^{v_i(t)} f^{-1}(v) dv \quad (7.88)\)

**定理 7.4** 对于连续型 Hopfield 神经网络，若 \(f^{-1}(\cdot)\) 为单调递增的连续函数，\(C_i > 0, w_{ij} = w_{ji}\)，则 \(\frac{dE(t)}{dt} \leqslant 0\)；当且仅当 \(\frac{dv_i(t)}{dt} \leqslant 0 (1 \leqslant i \leqslant N)\) 时，\(\frac{dE(t)}{dt} = 0\)。

**证明**

\(\frac{dE(t)}{dt} = \sum_{i=1}^N \frac{\partial E(t)}{\partial v_i(t)} \frac{dv_i(t)}{dt} \quad (7.89)\)

而

\(\frac{dE(t)}{dt} = -\frac{1}{2} \sum_{j=1}^N w_{jj} v_j(t) - \frac{1}{2} \sum_{j=1}^N w_{ij} v_j(t) - I_i + \frac{1}{R} f^{-1}(v_i)\)
\(= -\frac{1}{2} \sum_{j=1}^N (w_{ji} - w_{ij}) v_j(t) - \left[ \sum_{j=1}^N w_{ij} v_j(t) + I_i - \frac{u_i(t)}{R_i} \right]\)
\(= -\frac{1}{2} \sum_{j=1}^N (w_{ji} - w_{ij}) v_j(t) - C_i \frac{du_i(t)}{dt}\)
\(= -\frac{1}{2} \sum_{j=1}^N (w_{ji} - w_{ij}) v_j(t) - C_i \frac{df^{-1}(v_i)}{dt}\)
\(= -\frac{1}{2} \sum_{j=1}^N (w_{ji} - w_{ij}) v_j(t) - C_i \frac{df^{-1}(v_i)}{dv_i} \frac{dv_i}{dt} \quad (7.90)\)

将式 (7.89) 代入式 (7.90)，得到

\(\frac{dE(t)}{dt} = \sum_{i=1}^N \frac{\partial E(t)}{\partial v_i(t)} \frac{dv_i(t)}{dt}\)
\(= -\frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N (w_{ji} - w_{ij}) v_j(t) \frac{dv_i(t)}{dt} - \sum_{i=1}^N C_i \frac{df^{-1}(v_i)}{dv_i} \frac{dv_i}{dt} \quad (7.91)\)
