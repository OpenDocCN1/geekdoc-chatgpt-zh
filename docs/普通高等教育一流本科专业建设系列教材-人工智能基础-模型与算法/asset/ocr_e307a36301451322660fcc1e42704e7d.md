# 6. 模糊推理

使用丰富的模糊规则和决策方法，就可以对相关问题进行模糊推理，从而推导出想要的结果，其步骤一般如下。

+   1）对于每条规则的前提条件，计算输入数据的隶属度。
+   2）基于规则获得值，确定这条规则计算得到确定的结果（此时可能得到许多重复的结果，所以要进行下一步）。
+   3）将所有推理结论整合成一个单一的结论，一个模糊集合。
+   4）将这个得到的模糊集合进行去模糊化，即可得到想要的结果。
