
## 1. 学习系统的概念

学习系统是指能够在一定程度上实现机器学习的系统。1973 年，萨里斯（Saris）曾对学习系统给过如下定义：如果一个系统能够从某个过程和环境的未知特征中学到有关信息，并且能够把学到的信息用于未来的估计、分类、决策和控制，以便改进系统的性能，那么它就是学习系统。1977 年，史密斯（Smith）给出了类似定义：如果一个系统在与环境相互作用时，能利用过去与环境作用时得到的信息，并提高其性能，那么这样的系统就是学习系统。

## 2. 学习系统的基本要求

通常，一个学习系统应该满足如下基本要求。

- 1) 具有适当的学习环境。前面两个关于学习系统的定义中都使用了“环境”这个术语。学习系统中的环境并非指通常的物理条件，而是指学习系统进行学习时所需的信息来源。
- 2) 具有一定的学习能力。环境只是为学习系统提供了相应的信息和条件。要从中学习到知识，还须具有适当的学习方法和一定的学习能力。
- 3) 能用所学知识解决问题。学以致用是对人类学习的一种要求，机器学习系统也是如此。在萨里斯的定义中明确指出，学习系统应该把学到的信息用于未来的估计、分类、决策和控制，以便改进系统的性能。事实上，无论是人还是学习系统，如果不能用学到的知识解决实际问题，就失去了学习的作用和意义。
- 4) 能通过学习提高系统的性能。提高系统的性能是学习系统的最终目标。通过学习，系统增长知识，提高解决问题的能力，甚至能够完成原本不能完成的任务。

## 3. 学习系统的基本模型

通过以上分析可以看出，一个学习系统至少应包括 4 部分：环境、学习环节、知识库和执行环节。典型的机器学习系统如美国俄勒冈州立大学计算机科学的荣誉退休教授托马斯·G·迪特里奇（Thomas G. Dietterich）的学习模型，如图 7.5 所示。环境向系统的学习环节提供某些信息，学习环节利用这些信息修改知识库，增进执行环节的效能；执行环节根据知识库完成任务，同时把获得的信息再反馈给学习环节。

下面分别对这 4 部分进行更详细的讨论。

### (1) 环境与学习环节

环境中信息的水平和质量是影响学习系统设计的第一个重要因素。

信息的水平是指信息的一般化程度，或者指信息适用范围的广泛性。信息的一般化程度又是相对于执行环节而言的。高水平信息的一般化程度比较高，能适应更广泛的问题；低水平信息的一般化程度比较低，只适应个别问题。无论环境中的信息水平是高还是低，这些信息与执行环节所需信息的水平往往会有差距，而学习环节的任务就是缩小这一差距。

如果环境提供的是高水平信息，学习环节就要补充遗漏的细节，以便执行环节能将其用于更具体的情况；如果环境提供的是低水平信息，学习环节则会将这些具体实例归纳出适合一般情况的规则，以便执行环节将其用于更广泛的任务。

信息的质量是指信息的正确性和信息在组织上的合理性等。环境中的信息质量对学习难度有明显影响。例如，如果环境的示例中有干扰，或示例的次序不合理，那么学习环节很难对其进行归纳。

### (2) 知识库

知识库的形式和内容是影响学习系统设计的第二个因素。知识库的形式与知识表示方法直接相关，常用的知识表示方法有谓词逻辑、产生式、语义网络、框架等。选择知识表示方法的准则有可表达性、可推理性、可修改性和可扩充性等。

知识库的初始知识非常重要，学习系统不可能在没有任何知识的情况下凭空获取知识。通常，先利用初始知识理解环境提供的信息，然后逐步进行学习。学习系统的学习过程实质上是对原有知识库的扩充和完善的过程。

### (3) 执行环节

执行环节是整个学习系统的核心，与学习环节相互联系。其目的是改善执行环节的行为，而执行环节的复杂度、反馈及透明性又会对学习环节产生一定的影响。

- 1) 复杂度。不同复杂度的任务所需的知识不一样，一般来说，一个任务越复杂，所需的知识就会越多。
- 2) 反馈。所有的学习系统都必须有从执行环节到学习环节的反馈信息。反馈信息是根据执行环节的执行情况，对学习环节所获知识的评价。学习环节根据反馈信息决定是否需要从环境中进一步获取信息，以修改、完善知识库中的知识。

目前，学习系统采取的评价方式主要有两种：一种是由系统自动进行评价，另一种是由人协助完成评价。由系统自动完成评价是指将评价时所需要的性能指标直接建立在学习系统中，由系统自动对执行环节得到的结果进行评价；由人协助完成评价是指由人提出外部执行标准，观察执行环节相对这个标准的执行情况，并将比较结果反馈给学习环节。

- 3) 透明性。透明性是指从系统执行部分的动作效果可以容易地对知识库的规则进行评价。由此可见，执行环节的透明性应该越高越好。

## 7.2.3 神经网络的结构与工作方式

### 1. 神经网络的结构

神经网络是一个由众多简单的神经元连接而成的网络。尽管每个神经元结构、功能都不复杂，但神经网络的行为并不是各单元行为的简单相加，网络的整体动态行为为极为复杂，可以组成高度非线性动力学系统，从而描述很多复杂的物理系统，表现出不可预测性、不可逆性、多吸引子、可能出现混沌现象等一般复杂非线性系统的特性和作为神经网络系统的各种性质。神经网络具有大规模并行处理和分布式存储能力，也有自适应、自组织、自学习的特点，在许多领域得到了成功的应用，展现了非常广阔的应用前景。

众多神经元的轴突和其他神经元或者自身的树突相连接，构成复杂的神经网络。根据神经网络中神经元的连接方式，神经网络可以划分为不同类型的结构。目前，人工神经网络主要有前馈型和反馈型两大类，如图 7.6 所示。

- 1) 前馈型。前馈型神经网络中，各神经元接收前一层的输入，并输出给下一层，没有反馈。前馈型神经网络分为不同的层，第 i 层只与第 i-1 层输出相连，输入与输出的神经元与外界相连。后面着重介绍的 BP 神经网络就是一种前馈型神经网络。
- 2) 反馈型。在反馈型神经网络中，存在一些神经元的输出经过若干个神经元后，再反馈到这些神经元的输入端的情况。最典型的反馈型神经网络是 Hopfield 神经网络，它是全互联神经网络，即每个神经元和其他神经元之间都是相连的。

### 2. 神经网络的工作方式

当满足兴奋条件时，神经网络中的神经元就会改变为兴奋状态；否则，它就会改变为抑制状态。如果神经网络中各个神经元同时改变状态，则称为同步（synchronous）工作方式；如果神经网络中神经元都独立改变工作状态，即当某个神经元改变状态时，其他神经元保持状态不变，则称为异步（asynchronous）工作方式。不同工作方式下的神经网络性能有所差异。

## 7.2.4 神经网络的学习规则

### 1. 联想式学习——赫布学习规则

### (1) 赫布理论

赫布理论（Hebbian theory）是一个神经科学理论，解释了在学习过程中脑中神经元所发生的变化。赫布理论描述了突触可塑性的基本原理，即突触前神经元向突触后神经元的持续重复的刺激，可以导致突触传递效能的增加。这一理论由加拿大心理学家唐纳德·赫布（Donald Hebb）于 1949 年提出，又被称为赫布定律（Hebb's rule）、赫布假说（Hebb's postulate）、细胞结集理论（cell assembly theory）等。他如此表述这一理论：“我们可以假定反射活动的持续与重复会导致神经元稳定性的持久性提升……当神经元 A 的轴突与神经元 B 很近并参与了对 B 的重复持续的兴奋时，这两个神经元或其中一个便会发生某些生长过程或代谢变化，致使 A 作为能使 B 兴奋的细胞之一，它的效能增强了。”

这一理论经常会被总结为一起激发的神经元连在一起。但是，这个解释并不完整，赫布强调说，神经元 A 必须对神经元 B 的激发“做出了一定贡献”，因此神经元 A 的激发必须在神经元 B 之前，而不能同时激发。赫布理论中的这一部分研究后来被称为脉冲时序依赖可塑性，表明突触可塑性需要一定的时间延迟。赫布理论可以用于解释“联合学习”（associative learning），在这种学习中，由对神经元的重复刺激，使得神经元之间的突触强度增加。这样的学习方法称为赫布型学习（Hebbian learning）。赫布理论也成为非监督学习的生物学基础。

### (2) 赫布学习的公式

在人工神经网络中，突触间传递作用的变化被当作（被映射成）神经元网络图中相应权重的变化。如果两个神经元同步激发，则它们之间的权重增加；如果单独激发，则权重减少。赫布学习规则是最古老的也是最简单的神经元学习规则。

以下是一种描述赫布学习的公式：

$w_{ij} = x_i x_j$

式中，$w_{ij}$ 为从神经元 $j$ 到神经元 $i$ 的连接权重；$x_i$ 为神经元 $i$ 的输入。
注意：这是模式学习，每个训练样本都会导致权重改变。

在 Hopfield 神经网络中，如果 $i=j$，则 $w_{ij}$ 恒为 0（没有神经元和自身相连）。对于二进制的神经元（激发值只能为 0 或者 1），如果它连接的神经元有相同的激发模式，则连接会设定为 1。

其另一种表达式为

$w_{ij} = \frac{1}{p} \sum_{k=1}^p x_i^k x_j^k$

式中，$w_{ij}$ 为从神经元 $j$ 到神经元 $i$ 的连接权重；$p$ 为训练模式的个数；$x_i^k$ 为神经元 $i$ 的第 $k$ 个输入。

同样地，在 Hopfield 神经网络中，如果 $i=j$，则 $\Delta w_{ij}$ 恒为 0。

### 定理 7.1 赫布定理通常可以概括为

$\Delta w_{ij} = \eta a_i o_j$

式中，$\Delta w_{ij}$ 为由神经元 $j$ 向神经元 $i$ 传递的权重的变化量，即两神经元之间的连接强度；$\eta$ 为学习速率，它是一个可选的常系数；$a_i$ 为神经元 $i$ 的激活值；$o_j$ 为神经元 $j$ 的输出值，也是与神经元 $i$ 相连接的值。

### (3) 赫布学习规则

赫布学习规则是一个无监督学习规则，这种学习的结果是使网络能够提取训练集的统计特性，从而把输入信息按照它们的相似性程度划分为若干类。这一点与人类观察和认识世界的过程非常吻合，人类观察和认识世界在相当程度上就是根据事物的统计特征进行分类。赫布学习规则只根据神经元连接间的激活水平改变权值，因此这种方法又称为相关学习或并联学习。

赫布学习规则与“条件反射”机理一致，以巴甫洛夫的条件反射实验为例，每次给狗喂食前都先鸣铃，时间一长，狗就会将铃声和食物联系起来。以后如果响铃但是不给食物，狗也会流口水。赫布理论认为，在同一时间被激发的神经元之间的联系会被强化。例如，铃声响时一个神经元被激发，在同一时间，食物的出现会激发附近的另一个神经元，那么这两个神经元之间的联系就会被强化，从而记住这两个事物之间存在着联系；相反，如果两个神经元总是不能同步激发，那么它们的联系将会越来越弱。

赫布学习规则指的是当某一突触两端的神经元同时处于兴奋状态时，该连接的权值应该增强。用数学方式描述调整权值 $w_{ij}$ 的方法为

$w_{ij}(k+1) = w_{ij}(k) + \alpha y_i(k) y_j(k), \alpha > 0 \quad (7.15)$

式中，$w_{ij}(k+1)$ 为权值的下一步值；$w_{ij}(k)$ 为权值的当前值；$w_{ij}$ 为神经元 $j$ 到神经元 $i$ 的连接权重；$y_i$ 与 $y_j$ 为两个神经元的输出；$\alpha$ 为学习速率的常数。

如果 $y_i$ 与 $y_j$ 同时被激活，即 $y_i$ 与 $y_j$ 同时为正，那么 $w_{ij}$ 将增大；如果 $y_i$ 被激活，而 $y_j$ 处于抑制状态，即 $y_i$ 为正 $y_j$ 为负，那么 $w_{ij}$ 将减小。

### 2. 纠错式学习——Delta 学习规则

1986 年，美国认知心理学家戴维·麦克莱兰（David McClelland）和鲁梅尔哈特在神经网络训练中引入了 Delta 学习规则，该规则也可以称为连续感知器学习规则。Delta 学习规则是一种利用梯度下降法的一般性学习规则。

首先考虑一个简单的情况：设某神经网络的输出层中只有一个神经元 $i$，给该神经网络加上输入，这样就产生了输出 $y_i(n)$，称该输出为实际输出。

对于所加上的输入，一般期望该神经网络的输出为 $d(n)$，称为期望输出或目标输出。实际输出与期望输出之间存在误差，用 $e(n)$ 表示，其计算方法为

$e(n) = d(n) - y_i(n) \quad (7.16)$

现在要调整权值，将误差信号 $e(n)$ 减小到一个范围。为此，设定代价函数或性能指数 $E(n)$ 为

$E(n) = \frac{1}{2}e^2(n) \quad (7.17)$

系统的稳定状态即突触权值稳定不变。反复调整突触权值，使代价函数达到最小或使系统达到一个稳定状态，就完成了当前的学习过程。该学习过程称为纠错学习，或 Delta 学习规则。

Delta 学习规则是一种简单的有监督学习算法，该算法根据神经元的实际输出与期望输出差别来调整连接权值。其数学表示为

$\Delta w_{ij}(n) = \eta e(n) x_j(n) \quad (7.18)$

式中，$w_{ij}$ 为神经元 $x_j$ 到 $x_i$ 的权值。

在学习步骤为 $n$ 时，对突触权值的调整为

$w_{ij}(n+1) = w_{ij}(n) + \Delta w_{ij}(n) \quad (7.19)$

在 Delta 学习规则中，若神经元实际输出比期望输出大，则减少输入为正的连接权值，增大所有输入为负的连接权值；反之，则增大所有输入为正的连接权重，减少所有输入为负的连接权重。

## 7.3 感知器

感知器于 1957 年由弗兰克·罗森布拉特提出，是一种由两层神经元组成的神经网络，是神经网络与支持向量机的基础。感知器是二类分类的线性分类模型，输入为实例的特征向量，输出为实例的类别，取+1 和-1 两个值。感知器对应输入空间（特征空间）中将实例划分为正负两类的分离超平面，属于判别模型。感知器学习算法分为原始形式和对偶形式，具有简单且易于实现的优点。感知器学习旨在求出将训练数据进行线性划分的分离超平面。为此，导入基于误分类的损失函数，利用梯度下降法对损失函数进行极小化，求得感知器模型。

### 7.3.1 感知器模型

定义 7.1（感知器） 假设输入空间（特征空间）是 \(X \subseteq R^n\)，输出空间是 \(Y=\{+1, -1\}\)。输入 \(x \in X\) 表示实例的特征向量，对应输入空间的点；输出 \(y \in Y\) 表示实例的类别。式（7.20）所示的由输入空间到输出空间的函数称为感知器：

\(f(x) = \text{sign}(wx + b)\) (7.20)

式中，\(w\) 和 \(b\) 为感知器模型参数：\(w\) 为权值或权值向量，\(w \in R^n\)；\(b\) 为偏置，\(b \in R\)；\(wx\) 为 \(w\) 和 \(x\) 的内积；\(\text{sign}\) 为符号函数，公式表示为

\(\text{sign}(x) = \begin{cases} +1, & x \ge 0 \\ -1, & x < 0 \end{cases}\) (7.21)

感知器是一种线性分类模型，属于判别模型。感知器模型的假设空间是定义在特征空间中的所有线性分类模型（linear classification model）或线性分类器（linear classifier），即函数集合 \(\{f | f(x) = wx + b\}\)。

感知器有如下几何解释——线性方程

\(wx + b = 0\) (7.22)

对应特征空间 \(R^n\) 中的一个超平面 \(S\)，其中 \(w\) 是超平面的法向量，\(b\) 是超平面的截距。该超平面将特征空间划分为两部分，位于这两部分的点（特征向量）分别被分为正、负两类。因此，超平面 \(S\) 称为分离超平面（separating hyperplane），如图 7.7 所示。

### 7.3.2 感知器学习策略

- 1. 数据集的线性可分性

定义 7.2（数据集的线性可分性） 给定一个数据集：

\(T = \{(x_1, y_1), (x_2, y_2), \cdots, (x_N, y_N)\}\) (7.23)

式中，\(x_i \in X = R^n\)，\(y_i \in Y = \{+1, -1\}\)，\(i = 1, 2, \cdots, N\)。

如果存在某个超平面 \(S\) 表示为式（7.23），该平面 \(S\) 能将数据集的正实例点和负实例点正确地划分到超平面的两侧，即对所有 \(y_i = +1\) 的实例 \(i\)，有 \(wx_i + b > 0\)；对所有 \(y_i = -1\) 的实例 \(i\)，有 \(wx_i + b < 0\)，则称数据集 \(T\) 为线性可分数据集（linearly separable data set）。否则，称数据集 T 线性不可分。

- 2. 感知器的学习策略

假设训练数据集是线性可分的，感知器学习的目标是求得一个能够将训练集中正实例点和负实例点完全正确分开的分离超平面。为了找出这样的超平面，即确定感知器模型参数 \(w\) 和 \(b\)，需要确定一个学习策略，即定义（经验）损失函数并将损失函数极小化。

制订损失函数的一个参数选择是误分类点的总数，但这样的损失函数不是参数 \(w\) 和 \(b\) 的连续可导函数，不易优化。损失函数的另一个选择是误分类点到超平面 \(S\) 的总距离，这是感知器所采用的。为此，首先写出输入空间 \(R^n\) 中任一点 \(x_0\) 到超平面 \(S\) 的距离 \(D_{x_0}\) 为

$$D_{x_0} = \frac{1}{\|w\|}|wx_0 + b|$$ (7.24)

式中，\(\|w\|\) 为 \(w\) 的 \(L_2\) 范数。

其次，对于误分类的数据 \((x_i, y_i)\) 来说，公式

$$-y_i(wx_i + b) > 0$$ (7.25)

成立。因为当 \(wx_i + b > 0\) 时，\(y_i = -1\)；而当 \(wx_i + b < 0\) 时，\(y_i = +1\)。所以，误分类点 \(x_i\) 到超平面 \(S\) 的距离 \(D_{x_i}\) 为

$$D_{x_i} = -\frac{1}{\|w\|}y_i(wx_i + b)$$ (7.26)

这样，假设超平面 \(S\) 的误分类点集合为 \(M\)，那么所有误分类点到超平面 \(S\) 的总距离 \(D\) 为

$$D = -\frac{1}{\|w\|}\sum_{x_i \in M} y_i(wx_i + b)$$ (7.27)

不需要考虑 \(\frac{1}{\|w\|}\)，就能得到感知器学习的损失函数。

感知器 \(\text{sign}(wx + b)\) 学习的损失函数定义为

$$L(w, b) = -\sum_{x_i \in M} y_i(wx_i + b)$$ (7.28)

式中，\(M\) 为误分类点的集合。

该损失函数就是感知器学习的经验风险函数。

显然，损失函数 \(L(w, b)\) 是非负的。如果没有误分类点，损失函数的值是 0。误分类点越少，误分类点离超平面越近，损失函数值就越小。一个特定的样本点的损失函数是指，在误分类时是参数 \(w\)、\(b\) 的线性函数，在正确分类时是 0。因此，给定训练数据集 \(T\)，损失函数 \(L(w, b)\) 是 \(w\) 和 \(b\) 的连续可导函数。

感知器学习的策略是在假设空间中选取使损失函数[式 (7.28)]最小的模型参数，即为感知器模型。

### 7.3.3 感知器学习算法

感知器学习问题通过将其转换为求解损失函数式的最优化问题解决，其中最优化方法是随机梯度下降法。本小节叙述感知器学习的具体算法，包括原始形式和对偶形式，并证明在训练数据线性可分条件下感知器学习算法的收敛性。
