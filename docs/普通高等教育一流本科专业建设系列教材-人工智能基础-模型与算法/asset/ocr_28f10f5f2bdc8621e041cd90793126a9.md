下面基于该简例引入和解释与/或图搜索的基本概念。

1）K-连接。K-连接用于表示从父节点到子节点的连接，也称为父节点的外向连接，并以圆弧指示同父子节点之间的“与”关系，K 为这些子节点的个数。一个父节点可以有多个外向的 K-连接。例如，根节点 n0 有 2 个 K-连接：一个 2-连接指向子节点 n1 和 n2，一个 3-连接指向子节点 n3、n4 和 n5。K>1 的连接也称为超连接；K=1 时，超连接蜕化为普通连接，当所有超连接的 K 都等于 1 时，与/或图蜕化为一般图。

2）根、叶、终节点。无父节点的节点称为根节点，用于指示问题的初始状态。无子节点的节点标为叶节点。由于问题规约伴随着问题分解，因此目标状态不再由单一节点表示，而应由一组节点联合表示。能用于联合表示目标状态的节点标为终节点，终节点必定是叶节点，反之不然。非终节点的叶节点往往指示了解答搜索的失败。

3）解图的生成。在与/或图搜索过程中，可以这样建立解图：自根节点开始选择一个外向连接，并从该连接指向的每个子节点出发，再选择一个外向连接，如此反复，直到所有外向连接都指向终节点为止。例如，从图 3.17 与/或图根节点 n0 开始，选左边的 K=2 的外向连接，指向节点 n1 和 n2，再从 n1、n2 分别选外向连接：从 n1 选左边的 K=1 的外向连接，指向 n6，依次进行，直到终节点 n14、n18 和 n20；从 n2 只有一个 K=1 的外向连接指向终节点 n6，从而生成了图 3.18（a）所示的一个解图。注意，解图是遵从问题规约策略搜索到的，解图中不存在节点或节点组之间的“或”关系，即解图纯粹是一种“与”图。另外，正因为与/或图中存在“或”关系，所以以往会搜索到多个解图，本例中就有 4 个，如图 3.18 所示。

为了确保在与/或图中搜索解图的有效性，要求解图是无环的，即任何节点的外向连接均不能指向自己或自己的先辈，否则会使搜索陷入死循环，即会导致解图有环的外向连接不能选用。下面给出解图、解图代价、能解节点和不能解节点的定义。

1）解图：与/或图（记为 G）中任一节点（记为 n）到终节点集合的解图（记为 G'）是 G 的子图。

+   ① 若 n 是终节点，则 G' 就由单一节点 n 构成。

+   ② 若 n 有一外向 K-连接指向子节点 n1,n2,...,nk，且每个子节点都有到终节点集合的解图，则 G 由该 K-连接和所有子节点的解图构成。

+   ③ 否则不存在 n 到终节点集合的解图构成。

+   2）解图代价：以 C(n) 指示节点 n 到终节点集合解图的代价，并令 K-连接的代价为 K。

+   3）能解节点。

+   ① 终节点是能解节点。
