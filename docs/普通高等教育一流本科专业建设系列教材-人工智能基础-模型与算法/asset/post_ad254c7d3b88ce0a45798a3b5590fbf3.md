

\( CF_{1,2}(H) = \begin{cases} CF_1(H) + CF_2(H) - CF_1(H)CF_2(H), & CF_1(H) \geqslant 0, CF_2(H) \geqslant 0 \\ CF_1(H) + CF_2(H) - CF_1(H)CF_2(H), & CF_1(H) < 0, CF_2(H) < 0 \\ \frac{CF_1(H) + CF_2(H)}{1 - \min \{|CF_1(H)|, |CF_2(H)|\}}, & CF_1(H)CF_2(H) < 0 \end{cases} \) (5.52)

## 6. 带有阈值限度的可信度方法

C-F 模型在人工智能的发展史上占有重要地位，为基于可信度表示的不确定性推理奠定了基础。但是，现实世界中的问题是复杂多样的，任何一种方法都有其局限性，只适用于特定的情况和范围。为了用可信度方法求解更多的问题，人们在 C-F 模型的基础上又提出了一些更具有一般性的处理方法，如带有阈值限度的可信度方法。

带有阈值限度的可信度方法是在 C-F 模型上添加阈值限度 \(\lambda\)，用于限制不合要求的证据和对应的知识运用。

在带有阈值限度的不确定性推理中，知识用下述公式表示：
IF E THEN H [CF(H, E), \(\lambda\)]

式中，E 为知识的前提条件：H 为结论。

与 C-F 模型一样，这里前提和结论都可以是一个原子命题或复合命题。CF(H, E) 是规则的可信度，即规则强度，它指出相应知识为真的可信程度，取值范围为 (0,1]。其他越大，表示相应知识的可信度越高。\(\lambda\) 是阈值，它为相应知识的可应用性规定了一个限度，只有当前提条件 E 的可信度 CF(E) \(\geqslant \lambda\) 时，相应的知识才有可能被应用。\(\lambda\) 的取值范围为 (0,1]。

证据的不确定性仍然用可信度因子表示，即证据 E 的不确定性表示为 CF(E)，取值范围为 [0,1]。当 CF(E) = 0 时，表示该证据可信度无法得知。CF(E) 的值越大，表示可信度越高。对于初始证据，其值由用户给出；对于使用之前的推理结论作为当前推理前提的证据，其值由推理得到。

组合证据不确定性的算法与 C-F 模型类似。

当 CF(E) \(\geqslant \lambda\) 时，该条知识被激活，其不确定性的传递算法也与 C-F 模型类似。

结论不确定性的合成算法与 C-F 模型相似，分两步完成。首先分别对每条知识求出它的 CF\(_i\)(H) (i = 1, 2, \(\cdots\), n)，即 CF\(_i\)(H) = CF(H, E\(_i\)) \(\times\) CF(E\(_i\))

然后用以下方法中的任一种求出合成可信度 CF(H)。

- 1) 求极大值法：
  CF(H) = \max \{ CF_1(H), CF_2(H), \cdots, CF_n(H) \} (5.53)

- 2) 加权求和法：
  CF(H) = \frac{1}{\sum_{i=1}^{n} CF(H, E_i)} \sum_{i=1}^{n} CF(H, E_i) \times CF(E_i) (5.54)

- 3) 有限和法：
  CF(H) = \min \{ \sum_{i=1}^{n} CF_i(H), 1 \} (5.55)

- 4) 递推计算法：从 CF\(_1\)(H) 开始，按知识被启发的顺序逐步进行递推，每当增加一条结论为 H 的知识，H 的可信度就增加一点，直至最终求出 H 的综合可信度为止。其可用以下公式表示。

令

$C_1 = CF(H, E_1) \times CF(E_1)$ (5.56)

对任意的 $k > 1$, 有

$C_k = C_{k-1} + (1 - C_{k-1}) \times CF(H, E_k) \times CF(E_k)$ (5.57)

当 $k = n$ 时， $C_k$ 就是综合可信度 $CF(H)$。

下面通过一个例子来更好地理解可信度方法。

## 例 5.5 已知:

- $R_1$: IF $E_1$ THEN $H_1$ $CF(H_1, E_1) = 0.6$
- $R_2$: IF $E_2$ THEN $H_1$ $CF(H_1, E_2) = 0.5$
- $R_3$: IF $H_1 \land E_3$ THEN $H_2$ $CF(H_2, H_1 \land E_3) = 0.6$
- $CF(E_1)=1, CF(E_2)=1, CF(E_3)=1$

求 $CF(H_1)$、 $CF(H_2)$。

解 第 1 步，由 $R_1$、 $R_2$ 得

$CF_1(H_1) = CF(H_1, E_1) \times \max \{0, CF(E_i)\} = 0.6 \times 1 = 0.6$
$CF_2(H_1) = CF(H_1, E_2) \times \max \{0, CF(E_2)\} = 0.5 \times 1 = 0.5$

第 2 步，利用结论不确定性的合成算法计算 $H_1$ 的综合可信度，得

$CF(H_1) = CF_1(H_1) + CF_2(H_1) - CF_1(H_1)CF_2(H_1) = 0.6 + 0.5 - 0.6 \times 0.5 = 0.8$

第 3 步，由 $R_3$ 得

$CF(H_2) = CF(H_2, H_1 \land E_3) \times \max \{0, CF(H_1 \land E_3)\} = 0.6 \times 0.8 = 0.48$

可信度方法具有简洁、直观的优点。通过简单的计算，不确定性就可以在系统中传播，并且计算具有线性复杂度，推理的近似效果也比较理想。可信度方法也很容易理解，并且将不信任和信任清楚地区分开来。

但是，可信度方法也有其不足之处，具体如下。

- 1) CF 值可能与条件概率得出的值相反。

- 2) 通常，$P(H|E) \neq P(H|S)P(S|E)$，其中 $S$ 是基于证据 $E$ 的某些中间假设。但在推理链中的两条规则的 CF 却是作为独立概率计算的：$CF(H, E) = CF(H, S)CF(S, E)$。

- 3) MYCIN 一般应用于短推理链，而且假设简单的问题。如果把该方法应用于不具备短推理链、简单假设的领域，则可能会出问题。

- 4) 可信度方法很可能导致计算产生累计误差，所以在多个规则逻辑等价于一个规则逻辑的情况下，计算的 CF 值可能不相同。组合规则使用的顺序不同，也可能得出不同的结果。

## 5.2.4 证据理论方法

证据理论是哈佛大学数学家亚瑟·德普斯特（Arthur Dempster）于 1967 年研究统计问题时首先提出的，他给出了上、下限概率的概念及其合成规则，第一次明确给出了不满足可加性的概率。他的学生格伦·沙佛（Glenn Shafer）于 1976 年在《证据的数学理论》一书中扩展和改进了德普斯特的工作，引入信任函数概念，把证据理论推广到更加一般的情形，并使之系统化、理论化。因此，证据理论又称为 D-S 证据理论（the Dempster-Shafer theory of evidence）。

1981 年杰夫·巴纳特（Jeff Barnett）把该理论引入专家系统，同年卡威（Garvey）等用它实现了不确定性推理。目前，在证据理论的基础上已经发展出了多种不确定性推理模型。由于在证据理论中需要的先验数据比概率推理理论中的更为直观、更容易获得，再加上 Dempster 合成公式可以综合不同专家或数据源的知识或数据，这使得证据理论在专家系统、信息融合等领域中得到了广泛应用。该理论满足比概率论弱的公理，能够区分“不确定”与“不知道”的差异，并能处理由不知道引起的不确定性，具有较大的灵活性。

证据理论是建立在一个非空集合 \(\Omega\) 上的理论。\(\Omega\) 为辨别框架（the frame of discernment），它是关于某个问题域中所有可能的答案组成的有限集合，并且这些问题相互排斥，对于问题的描述是完备的。由 \(\Omega\) 的所有子集组成的集类 \(2^\Omega\) 表示判断该问题正确答案的所有命题构成的集合。在证据理论中，为了表述确定性和不确定性，引入了概率分配函数（mass function）、信任函数（belief function）、似然函数（plausibility function）等概念，下面将一一介绍。

### 1. 概率分配函数

### (1) 识别框架

识别框架是所有考察判断的事物或对象的集合，记为 \(\Omega\)（\(\Omega\) 中元素两两互斥）。例如，

\(\Omega_1 = \{ \text{晴天, 雨天, 雪天} \}\)
\(\Omega_2 = \{ \text{小鸡, 小狗, 小猫} \}\)
\(\Omega_3 = \{ \text{红, 黄, 蓝} \}\)

识别框架的子集就构成了求解问题的各种解答。

设 \(x\) 是一种小动物，\(\Omega = \{ \text{小鸡, 小狗, 小猫} \}\)，则

- 1) \(A = \{ \text{小鸡} \}\): “\(x\) 是小鸡”。

- 2) \(A = \{ \text{小狗, 小猫} \}\): “\(x\) 是小狗或小猫”。

每一个子集都可以看作一个隐含的命题。空集 \(\emptyset\) 对应答案假。当环境信息未知时，可用整个识别框架进行表示。

### (2) 基本概率分配函数

设 \(\Omega\) 为样本空间，领域内的命题都用 \(\Omega\) 的子集表示，则概率分配函数定义如下。

### 定义 5.1

设函数 \(M : 2^\Omega \rightarrow [0,1]\)，且满足
\(M(\emptyset) = 0, \sum_{A \subseteq \Omega} M(A) = 1\) (5.58)

则称 \(M\) 是 \(2^\Omega\) 上的基本概率分配函数，\(M(A)\) 称为 \(A\) 的基本概率数。若子集 \(A\) 满足 \(M(A) > 0\)，则称 \(A\) 为焦元（focal element）。

设样本空间 \(\Omega\) 有 \(n\) 个元素，则 \(\Omega\) 中子集的个数为 \(2^n\) 个。例如，设 \(\Omega = \{ \text{小鸡, 小狗, 小猫} \}\)，则其 \(2^3 = 8\) 个集合分别为 \(A_1 = \{ \text{小鸡} \}\)，\(A_2 = \{ \text{小狗} \}\)，\(A_3 = \{ \text{小猫} \}\)，\(A_4 = \{ \text{小鸡, 小狗} \}\)，\(A_5 = \{ \text{小鸡, 小猫} \}\)，\(A_6 = \{ \text{小猫, 小狗} \}\)，\(A_7 = \{ \text{小鸡, 小猫, 小狗} \}\)，\(A_8 = \emptyset\)。

当 \(A\) 是 \(\Omega\) 的真子集时，\(M(A)\) 表示对相应命题的可信度。概率分配函数的作用是把 \(\Omega\) 的任意一个子集 \(A\) 都映射为 \([0,1]\) 上的一个数 \(M(A)\)。它实际上是对 \(\Omega\) 的各个子集进行信任分配，\(M(A)\) 表示分配给 \(A\) 的那一部分。例如，设 \(A = \{ \text{小狗} \}\)，\(M(A) = 0.4\)，它表示对命题 “\(x\) 是小狗” 的正确性的信任度是 0.4。

当 \(A\) 由多个元素组成时，\(M(A)\) 不包括对 \(A\) 的子集的信任度，而且也不知道该如何对其进行分配。当 \(A = \Omega\) 时，\(M(A)\) 是对 \(\Omega\) 的各子集进行基本可信度分配后剩下的部分，表示不知道如何分配这部分。例如，在 \(M(\{ \text{小狗, 小猫} \}) = 0.2\) 中，不包括对 \(A = \{ \text{小狗} \}\) 的信任度 0.4，而且也不知道该把这个 0.2 分配给 { 小狗 } 还是分配给 { 小猫 }。

概率分配函数与概率不同。例如，设 \( M(\{小鸡\}) = 0.2 \), \( M(\{小狗\}) = 0.1 \), \( M(\{小猫\}) = 0.1 \), \( M(\{小鸡, 小狗\}) = 0.2 \), \( M(\{小鸡, 小猫\}) = 0.2 \), \( M(\{小猫, 小狗\}) = 0.1 \), \( M(\{小鸡, 小猫, 小狗\}) = 0.1 \), \( M(\emptyset) = 0 \)。显然，\( M \) 符合概率分配函数的定义，但是 \( M(\{小鸡\}) + M(\{小狗\}) + M(\{小猫\}) = 0.4 \)，若按概率的要求，这三者的和应等于 1。
事实上，基本概率分配数值一般由人主观给出。

### 2. 信任函数

定义 5.2 命题的信任函数 Bel:\( 2^\Omega \rightarrow [0,1] \) 满足
\(\text{Bel}(A) = \sum_{B \subseteq A} M(B), \forall A \subseteq \Omega\) (5.59)

式中，\( 2^\Omega \) 为 \(\Omega\) 的所有子集；\(\text{Bel}(A)\) 为对命题 \( A \) 为真的总的信任程度。
由信任函数和概率分配函数的定义可以推出：

\(\text{Bel}(\emptyset) = M(\emptyset) = 0\) (5.60)
\(\text{Bel}(\Omega) = \sum_{B \subseteq \Omega} M(B) = 1\) (5.61)

### 例 5.6

设 \(\Omega=\{a,b,c\}\)，其基本概率分配函数为
\( M(\{a\}) = 0.3, M(\{b\}) = 0.2, M(\{c\}) = 0, M(\{a,b\}) = 0.1 \),
\( M(\{b,c\}) = 0.1, M(\{a,c\}) = 0, M(\{a,b,c\}) = 0.2, M(\emptyset) = 0.1 \)
求 \(\text{Bel}(\{a\})\)、\(\text{Bel}(\{b,c\})\)、\(\text{Bel}(\{a,b,c\})\)。

解
\(\text{Bel}(\{a\}) = M(\{a\}) = 0.3\)
\(\text{Bel}(\{b,c\}) = M(\{b\}) + M(\{c\}) = 0.2 + 0 = 0.2\)
\(\text{Bel}(\{a,b,c\}) = M(\{a\}) + M(\{b\}) + M(\{c\}) + M(\{a,b\}) + M(\{b,c\}) + M(\{a,c\}) + M(\{a,b,c\}) + M(\emptyset) = 1\)

### 3. 似然函数

似然函数又称为不可驳斥函数或上限函数。
定义 5.3 似然函数 Pl:\( 2^\Omega \rightarrow [0,1] \)，且满足
\(\text{Pl}(A) = 1 - \text{Bel}(\neg A), \forall A \subseteq \Omega\) (5.62)

由于 \(\text{Bel}(A)\) 表示对 \( A \) 为真的信任程度，因此 \(\text{Bel}(\neg A)\) 表示对 \(\neg A\) 为真，即 \( A \) 为假的信任程度，由此 \(\text{Pl}(A)\) 表示对 \( A \) 为非假的信任程度。
似然函数 \(\text{Pl}(A)\) 的另一种表达形式为
\(\text{Pl}(A) = \sum_{A \cap B \neq \emptyset} M(B)\) (5.63)

证明
\(\text{Pl}(A) - \sum_{A \cap B \neq \emptyset} M(B) = 1 - \text{Bel}(\neg A) - \sum_{A \cap B \neq \emptyset} M(B)\)
\(= 1 - \left( \text{Bel}(\neg A) + \sum_{A \cap B \neq \emptyset} M(B) \right)\)
\(= 1 - \left( \sum_{C \subseteq \neg A} M(C) + \sum_{A \cap B \neq \emptyset} M(B) \right)\)

=1 - \sum_{E \subseteq \Omega} M(E)
=0
∴ \(\text{Pl}(A) = \sum_{A \cap B \neq \emptyset} M(B)\)

在此推导中，注意 \(C \cup B = 2^\Omega\)。

依然用例 5.6 的数据求 \(\text{Pl}(\{a\})\)、\(\text{Pl}(\{b, c\})\)。

\(\text{Pl}(\{a\}) = 1 - \text{Bel}(\neg \{a\}) = 1 - \text{Bel}(\{b, c\}) = 1 - 0.2 = 0.8\)
\(\text{Pl}(\{b, c\}) = 1 - \text{Bel}(\neg \{b, c\}) = 1 - \text{Bel}(\{a\}) = 1 - 0.3 = 0.7\)

### 4. 组合规则

有时对同样的证据会得到两个不同概率的分布函数，此时需要对它们进行组合。

定义 5.4 设 \(M_1\) 和 \(M_2\) 是同一样本空间上的两个概率分配函数，则其正交和 \(M=M_1 \oplus M_2\) 为

\(\left\{\begin{array}{l} M(\emptyset) = 0 \\ M(A) = K - \sum_{x \cap y = A} M_1(x)M_2(y) \\ K = 1 - \sum_{x \cap y = \emptyset} M_1(x)M_2(y) = \sum_{x \cap y \neq \emptyset} M_1(x)M_2(y) \end{array}\right.\) (5.64)

如果 \(K \neq 0\)，则正交和 \(M\) 也是一个概率分配函数；如果 \(K=0\)，则不存在正交和 \(M\)，即没有可能存在概率函数，称 \(M\) 与 \(M_2\) 矛盾。对于多个概率分配函数 \(M_1, M_2, \cdots, M_n\)，如果它们可以组合，也可通过正交和运算将它们组合为一个概率分配函数。

例 5.7 设 \(\Omega = \{a, b\}\)，基于两组不同证据得到的基本概率分配函数为

\(M_1(\{a\}) = 0.4, M_1(\{b\}) = 0.1, M_1(\{a, b\}) = 0.5\)

\(M_2(\{a\}) = 0.6, M_2(\{b\}) = 0.2, M_2(\{a, b\}) = 0.2\)

求 \(M(\{a\})\)、\(M(\{b\})\)、\(M(\{a, b\})\)。

解

\(K = 1 - \sum_{x \cap y = \emptyset} M_1(\{a\})M_2(\{b\})\)
\(= 1 - [M_1(\{a\})M_2(\{b\}) + M_1(\{b\})M_2(\{a\})]\)
\(= 1 - [0.4 \times 0.2 + 0.1 \times 0.6]\)
\(= 0.86\)

\(M(\{a\}) = \frac{1}{K}[M_1(\{a\})M_2(\{a\}) + M_1(\{a\})M_2(\{a, b\}) + M_1(\{a, b\})M_2(\{a\})]\)
\(= 0.72\)

同理，得

\(M(\{b\}) = 0.16, M(\{a, b\}) = 0.12\)

Dempster 规则的多证据组合和两个证据的组合是等效的，而且组合运算具有可交换性和可结合性。因此，多个证据的合成可通过递归运算得到，相关关系如图 5.3 所示，其中图 5.3（a）为多证据组合结构，图 5.3（b）为两个证据组合结构。
