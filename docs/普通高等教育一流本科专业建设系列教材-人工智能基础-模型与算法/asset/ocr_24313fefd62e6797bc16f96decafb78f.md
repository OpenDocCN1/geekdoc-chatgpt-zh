Pl({h₂}) = 1 - Bel({-h₂})
= 1 - Bel({h₁, h₃})
= 1 - [M({h₁}) + M({h₃})]
= 1 - [0.56 + 0]
= 0.44

综合上述结果，“感冒但非肺炎”为真的信任度为 0.56，非假的信任度为 0.735；“肺炎但非感冒”为真的信任度为 0.265，非假的信任度为 0.44。

因此，患者是患了感冒但非肺炎。

# 5.2.5 模糊推理方法

经典的布尔逻辑坚持所有事物都可以用二元项来表达，其基本运算就是“与、或、非”。布尔逻辑赋予计算机自动判断和决策的能力，但是这种逻辑并不是完美的，甚至某种程度上限制了计算机的能力，因为人类判断和决策往往没有那么简单。例如，布尔逻辑能够很好地处理是非分明的场景，如“如果下雨，就提醒我出门带伞”，因为下不下雨是一个清晰的是非逻辑。然而人们在实际生活中决定带不带伞出门时常会考虑雨的大小、雨会下多久等情况。那多大的雨算大雨需要带伞，多小的雨算小雨不用带伞呢？这里并没有一个清晰的雨量门槛决定是否需要带伞。

模糊性是由概念的外延、内含不明确所造成的事物本身性态和类属的不确定性，模糊逻辑用隶属度替代了布尔真值，常用在区间(0,1)上取值的隶属函数来描述。例如，“明天的气温是 39℃的概率为 0.9”，其中概率值 0.9 是描述出现“39℃”的随机性；而“明天高温的可能性是 0.9”，这里的 0.9 是描述明天的气温属于“高温”这个模糊概念的程度，即描述“高温”的模糊性。这些陈述表示实际上接近于日常人们的语意陈述，因为“隶属”在多数时候是部分的、非二元的、不精确的，这样就可以解决上面提到的问题。

1965 年，美国控制论专家扎德教授提出了模糊集合论，目的是要基于数学基础，为人工智能的发展开辟道路。经典集合论只能表达精确概念，刻板的程序使计算机在识别和控制上无法模拟人脑由于使用模糊词句而带有的灵活机动性。针对该问题，必须用数学描写模糊概念，从外延上把精确集合扩展成模糊集合。他提出的模糊集合论，从数学上消除了计算机不能处理模糊概念的禁锢。模糊推理是指基于模糊理论进行的推理。

从 1965 年到 20 世纪 80 年代，在美国、欧洲、中国和日本等国家和地区，只有少数科学家研究模糊理论。1974 年，英国伦敦大学的曼丹尼（Mamdani）教授首次用模糊逻辑和模糊推理实现了世界上第一个实验性的蒸汽机控制，并取得了比传统的直接数字控制算法更好的效果，从而宣告模糊控制的诞生。1976 年，曼丹尼又将模糊理论应用于水泥旋转炉的控制。1983 年，日本富士电子子公司实现了饮水处理装置的模糊控制。1987 年，日本日立公司研制出地铁的模糊控制系统。1987～1990 年，在日本申报的模糊产品专利就达 319 种。

目前，各种模糊产品充满日本、西欧和美国市场，其典型应用的例子涉及生产和生活的许多方面。例如，在家用电器设备中有模糊洗衣机、空调、微波炉、吸尘器、照相机和摄录机等；在工业控制领域中有水净化处理、发酵过程、水泥窑炉等的模糊控制；在专用系统和其他方面有地铁靠站停车、汽车驾驶、电梯、自动扶梯、蒸汽引擎及机器人的模糊控制；等等。
