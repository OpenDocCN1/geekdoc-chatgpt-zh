由第 3 项改进容易得出，算法在初始阶段将问题空间中各条边的信息素设置为 \(\tau_{max}\) 的估计值，同时信息素蒸发速率非常小，因此不同边上的信息素浓度差异只会缓慢地增加，所以 MMAS 有着比 AS、EAS、AS\(_{rank}\) 更强的搜索最优解的能力。这样一来，有益于算法起初在全局范围进行搜索，再逐步缩小搜索范围，最终锁定一条全局最优路径过程的实现。

问题 1 可以由第 2 项改进和第 3 项改进予以解决；对于问题 2，在 MMAS 中，当算法接近或是进入停滞状态时，问题空间内所有边上的信息素浓度都将被重新初始化，从而有效地利用系统进入停滞状态后的迭代周期继续进行搜索，使算法具有更强的全局寻优能力。通常通过对各条边上信息素量大小的统计或观察算法在指定次数的迭代内至今最优路径有无被更新来判断算法是否停滞。

MMAS 与之前的几种蚂蚁系统算法相比有更好的性能，是最受关注的 ACO 算法之一，它的算法思想也常常被后续的各种 ACO 算法借鉴。

# (4) 蚁群系统

上述的 EAS、AS\(_{rank}\)、MMAS 均是对基本 AS 的信息素更新规则做了少量修改而获取了更好的性能。1997 年，多里戈提出了蚁群系统（ant colony system, ACS），这是一种全新机制的 ACO 算法，其性能获得了进一步提升，是蚁群算法发展史上的又一里程碑式的方法。

ACS 与 AS 的不同主要体现在如下 3 个方面：首先，ACS 使用一种伪随机比例规则（pseudorandom proportional）选择下一城市，建立开发当前路径与探索新路径之间的平衡；其次，ACS 信息素全局更新规则只在属于至今最优路径的边上蒸发和释放信息素；最后，ACS 中新增了信息素局部更新规则，蚂蚁每次经过空间内的某条边，都会去除该边上一定量的信息素，以增加后续蚂蚁探索其余路径的可能性。

ACS 的工作流程是先将 m 只蚂蚁随机或均匀地分布在 n 个城市上，然后每只蚂蚁根据状态转移规则确定下一步要去的城市。算法设置为每只蚂蚁设置一张搜索禁忌表，表中存放它去过的城市，蚂蚁不会重复去到同一个城市。在选择去往目标城市的路径时，蚂蚁会选择信息素浓度高、距离短的路径，并且蚂蚁会在其经过的路径上进行信息素局部更新。在一轮蚂蚁完成汉密尔顿回路的构造后，算法要记录这些回路中最短的一条，并按照信息素全局更新规则增加这条路径上的信息素。此后算法反复迭代，直到满足终止条件。
