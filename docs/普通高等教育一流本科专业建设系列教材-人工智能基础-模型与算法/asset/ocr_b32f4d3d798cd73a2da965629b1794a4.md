# 7.3.1 感知器模型

定义 7.1（感知器） 假设输入空间（特征空间）是 \(X \subseteq R^n\)，输出空间是 \(Y=\{+1, -1\}\)。输入 \(x \in X\) 表示实例的特征向量，对应输入空间的点；输出 \(y \in Y\) 表示实例的类别。式（7.20）所示的由输入空间到输出空间的函数称为感知器：

\(f(x) = \text{sign}(wx + b)\) (7.20)

式中，\(w\) 和 \(b\) 为感知器模型参数：\(w\) 为权值或权值向量，\(w \in R^n\)；\(b\) 为偏置，\(b \in R\)；\(wx\) 为 \(w\) 和 \(x\) 的内积；\(\text{sign}\) 为符号函数，公式表示为

\(\text{sign}(x) = \begin{cases} +1, & x \ge 0 \\ -1, & x < 0 \end{cases}\) (7.21)

感知器是一种线性分类模型，属于判别模型。感知器模型的假设空间是定义在特征空间中的所有线性分类模型（linear classification model）或线性分类器（linear classifier），即函数集合 \(\{f | f(x) = wx + b\}\)。

感知器有如下几何解释——线性方程

\(wx + b = 0\) (7.22)

对应特征空间 \(R^n\) 中的一个超平面 \(S\)，其中 \(w\) 是超平面的法向量，\(b\) 是超平面的截距。该超平面将特征空间划分为两部分，位于这两部分的点（特征向量）分别被分为正、负两类。因此，超平面 \(S\) 称为分离超平面（separating hyperplane），如图 7.7 所示。
