上 Dempster 合成公式可以综合不同专家或数据源的知识或数据，这使得证据理论在专家系统、信息融合等领域中得到了广泛应用。该理论满足比概率论弱的公理，能够区分“不确定”与“不知道”的差异，并能处理由不知道引起的不确定性，具有较大的灵活性。

证据理论是建立在一个非空集合 \(\Omega\) 上的理论。\(\Omega\) 为辨别框架（the frame of discernment），它是关于某个问题域中所有可能的答案组成的有限集合，并且这些问题相互排斥，对于问题的描述是完备的。由 \(\Omega\) 的所有子集组成的集类 \(2^\Omega\) 表示判断该问题正确答案的所有命题构成的集合。在证据理论中，为了表述确定性和不确定性，引入了概率分配函数（mass function）、信任函数（belief function）、似然函数（plausibility function）等概念，下面将一一介绍。

# 1. 概率分配函数

# (1) 识别框架

识别框架是所有考察判断的事物或对象的集合，记为 \(\Omega\)（\(\Omega\) 中元素两两互斥）。例如，

\(\Omega_1 = \{ \text{晴天, 雨天, 雪天} \}\)
\(\Omega_2 = \{ \text{小鸡, 小狗, 小猫} \}\)
\(\Omega_3 = \{ \text{红, 黄, 蓝} \}\)

识别框架的子集就构成了求解问题的各种解答。

设 \(x\) 是一种小动物，\(\Omega = \{ \text{小鸡, 小狗, 小猫} \}\)，则

+   1) \(A = \{ \text{小鸡} \}\): “\(x\) 是小鸡”。

+   2) \(A = \{ \text{小狗, 小猫} \}\): “\(x\) 是小狗或小猫”。

每一个子集都可以看作一个隐含的命题。空集 \(\emptyset\) 对应答案假。当环境信息未知时，可用整个识别框架进行表示。

# (2) 基本概率分配函数

设 \(\Omega\) 为样本空间，领域内的命题都用 \(\Omega\) 的子集表示，则概率分配函数定义如下。

# 定义 5.1

设函数 \(M : 2^\Omega \rightarrow [0,1]\)，且满足
\(M(\phi) = 0, \sum_{A \subseteq \Omega} M(A) = 1\) (5.58)

则称 \(M\) 是 \(2^\Omega\) 上的基本概率分配函数，\(M(A)\) 称为 \(A\) 的基本概率数。若子集 \(A\) 满足 \(M(A) > 0\)，则称 \(A\) 为焦元（focal element）。

设样本空间 \(\Omega\) 有 \(n\) 个元素，则 \(\Omega\) 中子集的个数为 \(2^n\) 个。例如，设 \(\Omega = \{ \text{小鸡, 小狗, 小猫} \}\)，则其 \(2^3 = 8\) 个集合分别为 \(A_1 = \{ \text{小鸡} \}\)，\(A_2 = \{ \text{小狗} \}\)，\(A_3 = \{ \text{小猫} \}\)，\(A_4 = \{ \text{小鸡, 小狗} \}\)，\(A_5 = \{ \text{小鸡, 小猫} \}\)，\(A_6 = \{ \text{小猫, 小狗} \}\)，\(A_7 = \{ \text{小鸡, 小猫, 小狗} \}\)，\(A_8 = \emptyset\)。

当 \(A\) 是 \(\Omega\) 的真子集时，\(M(A)\) 表示对相应命题的可信度。概率分配函数的作用是把 \(\Omega\) 的任意一个子集 \(A\) 都映射为 \([0,1]\) 上的一个数 \(M(A)\)。它实际上是对 \(\Omega\) 的各个子集进行信任分配，\(M(A)\) 表示分配给 \(A\) 的那一部分。例如，设 \(A = \{ \text{小狗} \}\)，\(M(A) = 0.4\)，它表示对命题 “\(x\) 是小狗” 的正确性的信任度是 0.4。

当 \(A\) 由多个元素组成时，\(M(A)\) 不包括对 \(A\) 的子集的信任度，而且也不知道该如何对其进行分配。当 \(A = \Omega\) 时，\(M(A)\) 是对 \(\Omega\) 的各子集进行基本可信度分配后剩下的部分，表示不知道如何分配这部分。例如，在 \(M(\{ \text{小狗, 小猫} \}) = 0.2\) 中，不包括对 \(A = \{ \text{小狗} \}\) 的信任度 0.4，而且也不知道该把这个 0.2 分配给 { 小狗 } 还是分配给 { 小猫 }。
