# 1. 模糊集合

要对事物进行识别，就需要依据一定的要求和标准对它们进行分类，用于这种分类的数学工具就是集合论。解决精确分类的集合问题可以用经典集合论。然而，世界上大多数事物具有模糊性，为了能更好地描述具有模糊性的事物，扎德提出了模糊集合的概念，使得数学的思维和方法可用于处理模糊性现象。模糊理论是在模糊集合理论的数学基础上发展起来的，在整个控制过程中，不断将测量到的输出的精确量转换为模糊量，然后按照系统设定的控制规则和推理法则做出模糊决策，再将模糊决策对应的模糊量转换成精确量，从而实现系统的控制。

# (1) 模糊集合的定义

模糊集合是经典集合的扩充。下面首先介绍集合论中的几个名词。
论域：所讨论的全体对象，用 U、X 等大写字母表示。
元素：论域中的每个对象，常用 a、b、c、x、y、z 等小写字母表示。
集合：论域中具有某种相同属性的、确定的、可以彼此区别的元素的全体，常用 A、B 等表示，如 A = {x | f(x) < 0}。

在经典集合中，元素 a 和集合 A 的关系只有两种：a 属于 A 或 a 不属于 A，即只有两个真值“真”和“假”。

模糊逻辑给集合中每一个元素赋予一个介于 0 和 1 之间的实数，描述其属于一个集合的强度，该实数称为元素属于一个集合的隶属度。集合中所有元素的隶属度构成集合的隶属函数，即定义了模糊集。

相对来说，模糊集合是由 1 ~ n 个模糊变量构成的集合，而这些集合一般用来进行一些运算获得新的集合。例如，“考试通过”取反运算即是“考试不通过”的集合，“考试通过”和“参与社团活动”的与运算即是又“考试通过”又“参与社团活动”的集合。
