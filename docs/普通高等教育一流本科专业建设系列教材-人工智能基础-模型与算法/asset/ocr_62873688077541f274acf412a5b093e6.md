令

$C_1 = CF(H, E_1) \times CF(E_1)$ (5.56)

对任意的 $k > 1$, 有

$C_k = C_{k-1} + (1 - C_{k-1}) \times CF(H, E_k) \times CF(E_k)$ (5.57)

当 $k = n$ 时， $C_k$ 就是综合可信度 $CF(H)$。
下面通过一个例子来更好地理解可信度方法。

# 例 5.5 已知:

+   $R_1$: IF $E_1$ THEN $H_1$ $CF(H_1, E_1) = 0.6$
+   $R_2$: IF $E_2$ THEN $H_1$ $CF(H_1, E_2) = 0.5$
+   $R_3$: IF $H_1 \land E_3$ THEN $H_2$ $CF(H_2, H_1 \land E_3) = 0.6$
+   $CF(E_1)=1, CF(E_2)=1, CF(E_3)=1$

求 $CF(H_1)$、 $CF(H_2)$。

解 第 1 步，由 $R_1$、 $R_2$ 得

$CF_1(H_1) = CF(H_1, E_1) \times \max \{0, CF(E_i)\} = 0.6 \times 1 = 0.6$
$CF_2(H_1) = CF(H_1, E_2) \times \max \{0, CF(E_2)\} = 0.5 \times 1 = 0.5$

第 2 步，利用结论不确定性的合成算法计算 $H_1$ 的综合可信度，得

$CF(H_1) = CF_1(H_1) + CF_2(H_1) - CF_1(H_1)CF_2(H_1) = 0.6 + 0.5 - 0.6 \times 0.5 = 0.8$

第 3 步，由 $R_3$ 得

$CF(H_2) = CF(H_2, H_1 \land E_3) \times \max \{0, CF(H_1 \land E_3)\} = 0.6 \times 0.8 = 0.48$

可信度方法具有简洁、直观的优点。通过简单的计算，不确定性就可以在系统中传播，并且计算具有线性复杂度，推理的近似效果也比较理想。可信度方法也很容易理解，并且将不信任和信任清楚地区分开来。

但是，可信度方法也有其不足之处，具体如下。

+   1）CF 值可能与条件概率得出的值相反。

+   2）通常，$P(H|E) \neq P(H|S)P(S|E)$，其中 $S$ 是基于证据 $E$ 的某些中间假设。但在推理链中的两条规则的 CF 却是作为独立概率计算的：$CF(H, E) = CF(H, S)CF(S, E)$。

+   3）MYCIN 一般应用于短推理链，而且假设简单的问题。如果把该方法应用于不具备短推理链、简单假设的领域，则可能会出问题。

+   4）可信度方法很可能导致计算产生累计误差，所以在多个规则逻辑等价于一个规则逻辑的情况下，计算的 CF 值可能不相同。组合规则使用的顺序不同，也可能得出不同的结果。

# 5.2.4 证据理论方法

证据理论是哈佛大学数学家亚瑟·德普斯特（Arthur Dempster）于 1967 年研究统计问题时首先提出的，他给出了上、下限概率的概念及其合成规则，第一次明确给出了不满足可加性的概率。他的学生格伦·沙佛（Glenn Shafer）于 1976 年在《证据的数学理论》一书中扩展和改进了德普斯特的工作，引入信任函数概念，把证据理论推广到更加一般的情形，并使之系统化、理论化。因此，证据理论又称为 D-S 证据理论（the Dempster-Shafer theory of evidence）。
