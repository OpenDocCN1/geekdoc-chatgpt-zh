称为 $\alpha$ 剪枝。

2）对于一个或节点 MAX，若能估计出其倒推值的下确界 $\alpha$，并且 $\alpha$ 值不小于 MAX 的父节点（一定是与节点）的估计倒推值的上确界 $\beta$，即 $\alpha \geqslant \beta$，则不必再扩展该 MAX 节点的其余子节点（因为这些节点的估值对 MAX 父节点的倒推值已无任何影响）。该过程称为 $\beta$ 剪枝。

# 图 3.29 $\alpha - \beta$ 剪枝的具体例子

证明 在图 3.29 中，K、L、M 的估值推出节点 F 的倒推值为 4，即 F 的 $\beta$ 值为 4，由此可推出节点 C 的倒推值 $\geqslant 4$。记 C 的倒推值的下界为 4，不可能再比 4 小，故 C 的 $\alpha$ 值为 4。

由节点 N 的估值推知节点 G 的倒推值 $\leqslant 1$，无论 G 的其他子节点的估值是多少，G 的倒推值都不可能比 1 大。因此，1 是 G 的倒推值的上界，所以 G 的倒推值 $\leqslant 1$。另外，已知 C 的倒推值 $\geqslant 4$，G 的其他子节点又不可能使 C 的倒推值增大，因此对 G 的其他分支不必再搜索，相当于把这些分支剪去。由 F、G 的倒推值可推出节点 C 的倒推值 $\geqslant 4$，再由 C 可推出节点 A 的倒推值 $\leqslant 4$，即 A 的 $\beta$ 值为 4。另外，由节点 P、Q 推出的节点 H 的倒推值为 5，因此 D 的倒推值 $\geqslant 5$，即 D 的 $\alpha$ 值为 5。此时，D 的其他子节点的倒推值无论是多少都不能使 D 及 A 的倒推值减小或增大，因此 D 的其他分支被剪去，并可确定 A 的倒推值为 4。依此类推，最终推出 $S_0$ 的倒推值为 4。

通过上面的讨论可以看出，$\alpha - \beta$ 过程首先使搜索树的某一部分达到最大深度，这时计算出某些 MAX 节点的 $\alpha$ 值，或者是某些 MIN 节点的 $\beta$ 值。随着搜索的继续，不断修改个别节点的 $\alpha$ 值或 $\beta$ 值。对任一节点，当其某一后继节点的最终值给定时，就可以确定该节点的 $\alpha$ 值或 $\beta$ 值。当该节点的其他后继节点的最终值给定时，就可以对该节点的 $\alpha$ 值或 $\beta$ 值进行修正。

注意: $\alpha$ 值和 $\beta$ 值修改有如下规律。

+   1）MAX 节点的 $\alpha$ 值永不降低。
+   2）MIN 节点的 $\beta$ 值永不增加。
