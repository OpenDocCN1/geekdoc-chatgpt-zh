# (1) 参数编码

参数编码是应用遗传算法时要解决的首要问题，也是设计遗传算法时的一个关键步骤。由于遗传算法不能直接处理问题空间的参数，因此必须通过编码将要求求解的问题表示成遗传空间的染色体或个体。编码方法影响到交叉算子、变异算子等遗传算子的运算方法，很大程度上决定了遗传进化的效率。常用的编码方法有二进制编码法、浮点编码法、符号编码法、多参数编码法等。

遗传操作包括选择算子、交叉算子和变异算子，应当根据不同的应用场景选择不同的算子，以实现节省计算资源、提高计算效率的目的。

# (2) 选择算子

常用的选择算子包括轮盘赌选择、随机竞争选择、最佳保留选择、无回放随机选择（也称期望值选择）等。其中，轮盘赌选择法是最简单也是最常用的选择方法，在该方法中，各个个体的选择概率和其适应度值成比例，适应度越大，被选中的概率也越大。

+   1) 随机竞争选择：每次按轮盘赌选择一对个体，让这两个个体进行竞争，适应度高的被选中。如此反复，直到选满为止。

+   2) 最佳保留选择：首先按轮盘赌选择方法执行遗传算法的选择操作，然后将当前群体中适应度最高的个体结构完整地复制到下一代群体中。

+   3) 无回放随机选择：根据每个个体在下一代群体中的生存期望进行随机选择运算。

# (3) 交叉算子

交叉算子是指对两个相互配对的染色体按某种方式交换部分基因，从而形成两个新的个体。它是遗传算法区别于其他进化算法的重要特征，是产生新个体的主要方法。常用的适用于二进制编码个体或浮点数编码个体的交叉算子有以下几种类型。

+   1) 单点交叉：在个体编码串中只随机设置一个交叉点，然后在该点交换两个配对个体的部分染色体。

+   2) 两点交叉：在个体编码串中随机设置两个交叉点，然后进行部分基因交换。

+   3) 均匀交叉（也称一致交叉）：两个配对个体的每个基因座上的基因都以相同的交叉概率进行交换，从而形成两个新个体。

+   4) 算术交叉：由两个个体的线性组合产生出两个新的个体。该操作对象一般是由浮点数编码表示的个体。

# (4) 变异算子

变异算子将个体染色体编码串中的某些基因座上的基因值用该基因座上的其他等位基因替换，从而形成一个新的个体。这些变异算子适用于二进制编码和浮点数编码的个体。
