# 4. 模糊推理规则

模糊推理是指基于模糊理论进行的推理。

# (1) 模糊命题

含有模糊概念、模糊数据的语句称为模糊命题。它的一般表示形式为

\(x \text{ is } A\)

或

\(x \text{ is } A(\text{CF})\)

式中，\(A\) 为模糊概念或者模糊数，用相应的模糊集及其隶属函数刻画；\(x\) 为论域上的变量，用于代表所论述对象的属性；CF 为该模糊命题的可信度，它既可以是一个确定的数，也可以是一个模糊数或者模糊语言值。

模糊语言值是指表示大小、长短、多少等程度的一些词汇，如极大、很大、相当大、比较大。模糊语言值同样可以用模糊集描述。

# (2) 模糊知识表示

人类思维判断的基本形式如下：

如果（条件）→ 则（结论）

其中，条件和结论常常是模糊的。例如：

如果 学习勤奋且学习方法正确 则 成绩高

这种情况就可以使用模糊集合表示这个知识中学习勤奋水平、学习方法准确性和成绩的不确定性。

模糊规则是指从条件论域到结论论域的模糊关系矩阵 \(R\)。通过条件模糊向量与模糊关系 \(R\) 的合成进行模糊推理，得到结论的模糊向量，然后采用“清晰化”的方法将模糊结论转换为精确量。
