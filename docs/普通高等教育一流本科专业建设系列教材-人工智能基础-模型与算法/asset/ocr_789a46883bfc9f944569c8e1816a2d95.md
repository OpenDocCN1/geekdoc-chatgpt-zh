# （2）系数加权平均判决法

系数加权平均判决法可以克服最大隶属度法的缺点，即当模糊集合的隶属函数曲线是梯形时适用：

```
U = \frac{\sum_{i=1}^{n} \mu(u_i)u_i}{\sum_{i=1}^{n} \mu(u_i)}
```

式中，\(\mu(u_i)\) 的选择要根据实际情况而定，不同的系统决定了系统有不同的响应特性。

例如，

```
U' = \frac{0.1}{2} + \frac{0.6}{3} + \frac{0.5}{4} + \frac{0.4}{5} + \frac{0.2}{6}
```

则

```
U = \frac{0.1 \times 2 + 0.6 \times 3 + 0.5 \times 4 + 0.4 \times 5 + 0.2 \times 6}{0.1 + 0.6 + 0.5 + 0.4 + 0.2} = 4
```

# （3）中位数法

中位数法就是把模糊集的中位数作为系统控制量。模糊集的中位数指的是在论域上把隶属函数曲线与横坐标围成的面积平分为两部分的元素。

当论域为有限离散点时，中位数 \(U'\) 可以用下列公式求得

```
\sum_{u_i}^{u^*} \mu(U_i) = \sum_{U^*+1}^{U_n} \mu(U_j)
```

例如

```
U' = \frac{0.1}{(-4)} + \frac{0.5}{(-3)} + \frac{0.1}{(-2)} + \frac{0.0}{(-1)} + \frac{0.1}{0} + \frac{0.2}{1} + \frac{0.4}{2} + \frac{0.5}{3} + \frac{0.1}{4}
```

由于 \(U_1 = -4, U_9 = 4\)，则当 \(u^* = u_6\) 时，\(\sum_{u_i}^{u_6} \mu(u_i) = \sum_{u_i}^{u_9} \mu(u_i) = 1\)，所以中位数 \(u^* = u_6\)，则 \(U=1\)。

如果该点在有限元素之间，则可用插值的方法来求取。例如：

```
U' = \frac{0.1}{(-4)} + \frac{0.5}{(-3)} + \frac{0.3}{(-2)} + \frac{0.1}{(-1)} + \frac{0.1}{0} + \frac{0.4}{1} + \frac{0.5}{2} + \frac{0.1}{3} + \frac{0.2}{4}
```

用线性插值处理，即 \(\Delta u = \frac{1.2}{1.1 + 1.2} = 0.522\)，所以 \(u^* = u_5 + \Delta u = 0.522\)。实际上，模糊推理计算不需要很精确，因此也可以直接取 \(u^* = 0\) 或 \(u^* = 1\)。

中位数法利用更多信息，但计算相对复杂，因此实际应用场合比加权平均法少。

# （4）中心法

中心法是一种最准确的去模糊化方法，但也是最复杂的计算方法。中心就是把它放在一把尺子上能保持平衡的位置。

通常，中心法使用采样方法获取近似中心值：在 \(X\) 轴上平均分布 \(N\) 个点进行采样，计算在每个采样点对总体隶属度的贡献之和，再除以采样的隶属度之和。\(N\) 越大，其结果越准确。

```
U = \frac{\sum_{i=1}^{N} \left[ x_i \sum_{j=1}^{M} F_j(x_i) \right]}{\sum_{i=1}^{N} \sum_{j=1}^{M} F_j(x_i)}
```
