¬P→(Q∧R)
(R∨¬B)∧(C⇒D)

当这些符号串中的大写字母都表示确定的命题时，上面的符号串就表示更复杂的命题；若这些大写字母不表示确定的命题，则上面的符号串就是命题公式，简称为公式。但并不是随意产生的符号串都能称为命题公式，必须遵循一定的规则。需要注意的是，命题逻辑的推理讲求的是形式结构上的有效性，而非结论的正确性。

命题逻辑法表示具有极大的局限性，它无法把所描述的事物的结构及逻辑特征反映出来，也不能把不同事物之间的共同特征表述出来。为解决这些问题，在命题逻辑的基础上发展起来了谓词逻辑。

# 4.2.2 谓词逻辑

传统谓词逻辑主要是研究性质命题及其推理（以三段论为核心）的逻辑。在传统谓词逻辑中，所有的命题都是只具有如下 4 种形式的命题：A——所有的 S 都是 P；E——所有的 S 都不是 P；I——有些 S 是 P；O——有些 S 不是 P。
至于具有“这个 S 是 P”和“这个 S 不是 P”形式的命题，一般笼统地处理成相应的 A 命题和 E 命题。无疑，对于可以分析成这种形式的命题来说，传统谓词逻辑中的方法的确很有实用性，但这种单纯的形式方法存在着很大的局限性。例如，有下列命题：

+   1）小明的成绩比小红的成绩高。
+   2）内蒙古在山东的北方。
+   3）98%的同学参与选举并同意张瑶同学担任班长。

它们与具有上述 A、E、I、O4 种形式的命题有着明显的区别，称为关系命题，即表达这个体对象之间是否具有某种关系。由这些命题构成的推理称为关系推理。例如，有下列命题：

+   1）小明的成绩比小红的成绩高。
+   2）小林的成绩比小明的成绩高。
+   3）所以小林的成绩比小红的成绩高。

直观上，这个推理是有效的，并且其有效性来源于命题的内部结构。类似这个推理的关系推理显然应该成为着重分析命题内在逻辑结构的谓词逻辑的研究对象。但关系命题和关系推理都超出了传统谓词逻辑的范围，传统谓词逻辑仅研究性质命题，而且仅研究三段论或是仅对性质命题的形式稍做变化的推理。现代谓词逻辑可以很好地解决关系命题的相关问题。关系命题及其推理是现代谓词逻辑的基本内容，在其理论体系中，关系命题及其推理与性质命题及其推理并无实质性的区别，仅是包含不同的谓词而已。

谓词逻辑重在研究量词的逻辑性质。传统谓词逻辑把量词归结为“所有”和“有些”，进而把命题归结为全称命题和特称命题，而对于日常语言中经常出现的单称命题基本上是回避的。此外，传统谓词逻辑对量词理论采取了种种限制，如规定被量词约束的词项均不能是空类等。在现代谓词逻辑中，一切词项均可以是空类，逻辑应该尽量满足所有可能性，只有这样才具有普遍应用性。
