可以证明，若确保对于搜索图中的节点 x 总是有 h(x) <= h*(x)，则 A 算法具有可采纳性，即总能搜索到最短（代价最小）的解答路径。

称满足 h(x) <= h*(x) 的 A 算法为 A*算法。

A*算法过程如下。

+   1）把 S 放入 OPEN 表，记 f=h，令 CLOSE 为空表。

+   2）若 OPEN 为空表，则宣告失败并退出。

+   3）选取 OPEN 表中未设置过的具有最小 f 值的节点为最佳节点 BestNode，并把它放入 CLOSE 表。

+   4）若 BestNode 为一目标节点，则成功求得一解并退出。

+   5）若 BestNode 不是目标节点，则扩展之，产生后继节点 Successor。

+   6）对每个 Successor 进行下列过程。

+   ① 建立从 Successor 返回 BestNode 的指针。

+   ② 计算 g(Successor)=g(BestNode)+g(BestNode,Successor)。

+   ③ 如果 Successor \in OPEN，则此节点为 OldNode，并把它添至后继节点表 BESTNODE 中。

+   ④ 比较新旧路径代价。如果 g(Successor)<g(OldNode)，则重新确定 OldNode 的父辈节点为 BestNode，记下较小代价 g(OldNode)，并修正 f(OldNode)值。

+   ⑤ 若至 OldNode 的代价较低或一样，则停止扩展节点。

+   ⑥ 若 Successor 不在 OPEN 表中，则看其是否在 CLOSE 表中。

+   ⑦ 若 Successor 在 CLOSE 表中，则转向第③步。

+   ⑧ 若 Successor 既不在 OPEN 表中又不在 CLOSE 表中，则把它放入 OPEN 表中，并添入后继节点表 BESTNODE 中，然后转向第⑦步。

+   7）计算 f 值，然后转入第②步。

# 2. A*算法性质

首先定义下面的符号。

C(n_i, n_j)：从节点 n_i 到节点 n_j 的费用。

K(n_i, n_j)：从节点 n_i 到节点 n_j 最小代价路径的费用。

G：一个目标节点。

G：目标节点的集合。

P_{n->g}：从节点 n 到 g 的路径。

P_{n->G}：从节点 n 到目标节点集合 G 的路径集合。

g*(x)：从起始节点（根节点）s 到节点 n 所有路径的最小费用，g*(n) = K(s, n)。

h*(x)：从节点 s 到 G 的所有路径中最小的费用，对所有的 g \in G，有 h*(n) = min K(n,g)。

C*：从节点 s 到 G 的所有路径中最小代价路径的费用，C* = h*(s)。
