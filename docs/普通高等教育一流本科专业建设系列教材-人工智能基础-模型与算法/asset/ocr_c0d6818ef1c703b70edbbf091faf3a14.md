把相关信息关联在一起所形成的、能反映客观世界中事物关系的结构。不同事物或者相同事物间的不同关系形成了不同的知识。在客观世界中，人们通过各种途径和方法可以获得大量知识，为解决实际问题和从事创造活动奠定基础。知识是以高度概括的形式对客观事实及其相互关系的整合，由于客观事物是相互联系的，因此知识也必然是相互联系的。

其实，知识之后可以加入智能，智能是比知识更高层次的概念，它是人类内在的一种获取知识并运用知识的能力，有时称之为智力，即正确地运用信息、经验和悟性，进行判断、计划、处理事务及创新活动的综合能力。正确理解和运用知识之间的相互关联，就反映出了人类的智能。

# 2. 知识的属性

由于知识来自人们对客观世界的认识，因此知识具有以下一些特性。

+   1) 真伪性。知识是客观事物及客观世界的反映，具有真伪性，可以通过实践检验其真伪，或用逻辑推理证明其真伪。

+   2) 相对性。在应用知识时，需注意该知识的适用条件或范围。一般情况下，知识不存在绝对的真假。任何知识都是在一定条件及环境下产生的，因而只有在符合这种条件及环境时，知识才是正确的。例如，1+1=2 在十进制的前提下是正确的，而在二进制的前提下就不正确。

+   3) 不完整性。知识往往是不完整的。这里的不完整大致分为两类：条件不完整和结论不完整。

+   4) 不确定性。现实中的知识的真与假往往并不总是“非真即假”，而可能处于某种中间状态，这一特性称为知识的不确定性。例如，“人老了就可能糊涂”，“老了”“可能”“糊涂”都是一些不确定的概念。在知识处理中必须用模糊数学或统计方法等来处理模糊的或不精确的知识。

+   5) 可表示性。知识不是一种物质事物，但作为人类经验存在于人脑之中，还可以用各种方法表示出来。正是基于这一特性，人们所感知的语言、文字、图形等才能被存储并得以传播，才能获得应用和发展。

+   6) 可存储性、可传递性和可处理性。既然知识可以表示出来，那么就可以把它存储起来；知识既可以通过书本来传递，也可以通过教师的讲授来传播，还可以通过计算机网络等来传输，知识可以从一种表示形式转换为另一种表示形式；知识一旦表示出来，就可以同数据一样进行处理。

+   7) 相容性。相容性是关于知识集合的又一个属性。存在于一体（如专家系统的知识库）的所有知识之间应该是相互不矛盾的，即从这些知识出发，不能推出相互矛盾的命题。

# 3. 知识分类

关于知识的类型，可以从不同角度来划分。

+   1) 知识按其性质分，可分为公理、概念、命题、定理和规则等。

+   2) 知识按其确定程度分，可分为确定性知识和不确定性知识。
