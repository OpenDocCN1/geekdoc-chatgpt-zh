# (4) 双种群遗传算法

基本遗传算法针对一个宏观的种群进行复制、交叉、变异操作，不断更新当前种群的染色体，进行“优胜劣汰”，类似于人类或其他生物进化的过程。一个生物群体，在面对大自然生存的考验时，适应性更强的个体得以留存，适应性较低的个体则逐渐淘汰。然而，由于它们的生长、演化、环境和祖先的局限性等问题，经过相当长的时间后，它们将逐渐进化到某些特征相对优势的状态，这种状态称为平衡态。随后，种群的特性就会趋于稳定。为尽快达到平衡态，可以在遗传算法中使多个种群同时进化，并交换种群之间优秀个体所携带的信息，以打破种群内的平衡态，进而达到更高层次的平衡态，有利于算法跳出局部最优。本质上，多种群遗传算法是一种并行算法，可以提高算法效率。

双种群遗传算法设计的主要算子如下。

+   1) 编码/解码。编码/解码方法与基本遗传算法相同。
+   2) 交叉算子和变异算子。两个种群分别进行选择、交叉、变异等操作，且交叉概率、变异概率不同。
+   3) 杂交算子。设种群 A 与种群 B，当 A 与 B 种群都完成了选择、交叉、变异算子后，产生一个随机数 num，随机选择 A 中 num 个个体与 A 中最优个体，随机选择 B 中 num 个个体与 B 中最优个体，交换两者，以打破平衡态。

双种群遗传算法的程序流程如下。

+   第 1 步，代数 n = 0 ，按照不同的随机方法产生两个初始种群。
+   第 2 步，计算目标种群的目标函数值和个体适应度。
+   第 3 步，判断是否满足停止准则，若满足则得到最优解，算法结束；若不满足则进入第 4 步。
