均值得到 $b$，这种方式更加鲁棒。

# 4. 核函数解决线性不可分的情况

在现实任务中，原始样本空间并不一定是线性可分的。对于这样的问题，可将样本中原始空间映射到一个更加高维的特征空间中，使样本在该特征空间中高概率线性可分。如果原始空间是有限维，那么一定存在一个高维特征空间使样本可分。

令 $\phi(x)$ 是样本 $x$ 在高维特征空间中的特征向量，那么在特征空间中的超平面所对应的模型可以表示为

```
$f(x) = w^T \phi(x) + b$ \tag{8.51}
```

特征空间中的目标函数为

```
\min_{w,b} \frac{1}{2} \|w\|_2^2 \tag{8.52}\\
s.t. y_i [w^T \phi(x) + b] \geqslant 1, i = 1, 2, \cdots, n \tag{8.53}
```

使用拉格朗日乘子法获得的对偶问题为

```
\max_{\alpha} \sum_{i}^n \alpha_i - \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \alpha_i \alpha_j y_i y_j \phi(x_i)^T \phi(x_j) \tag{8.54}\\
s.t. \sum_{i=1}^n \alpha_i y_i = 0, i = 1, 2, \cdots, n \tag{8.55}
```

在上式的求解过程中，会发现 $\phi(x_i)^T \phi(x_j)$ 用常规方法难以求解，因为无法确定 $\phi(x)$ 的具体形式。但可设想存在一个函数 $\mathcal{K}(x, x_j)$，使得 $x_i$、$x_j$ 在原始样本空间中通过函数 $\mathcal{K}$ 计算的结果等于它们在特征空间中的内积，即

```
$\mathcal{K}(x_i, x_j) = \phi(x_i)^T \phi(x_j)$ \tag{8.56}
```

式中，$\mathcal{K}(x_i, x_j)$ 为核函数。

常用的核函数如表 8.5 所示。

# 表 8.5 常用的核函数

| 函数名 | 函数表达式 |
| :--- | :--- |
| 线性多项式 | $\mathcal{K}(x, x_i) = x x_i$ <br> $\mathcal{K}(x, x_i) = (\gamma x x_i + c)^\alpha$ |
| 径向基函数 (radial basis function) | $\mathcal{K}(x, x_i) = e^{-\frac{\|x_i - x\|^2}{2\sigma^2}}$ |
| Sigmoid | $\mathcal{K}(x, x_i) = \tanh(x x_i - \gamma)$ |

此外，核函数的某些组合也是核函数。例如，若 $\mathcal{K}_1$、$\mathcal{K}_2$ 是核函数， $\gamma_1$、 $\gamma_2$ 是正数，则线性组合 $\gamma_1 \mathcal{K}_1 + \gamma_2 \mathcal{K}_2$ 也是核函数；若 $\mathcal{K}_1$、$\mathcal{K}_2$ 是核函数，则核函数的直积 $\mathcal{K}_1(x, z) \mathcal{K}_2(x, z)$ 也是核函数；若 $\mathcal{K}_1$ 是核函数，则对于任意函数 $f(x)$，有 $\mathcal{K}(x, z) = f(x) \mathcal{K}_1(x, z) f(z)$ 是核函数。
