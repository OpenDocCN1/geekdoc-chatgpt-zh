下面不加证明地给出性质 3.6。

# 性质 3.6 如果 h(n) 满足单调限制，则 A* 算法扩展的节点序列的 f 值是非递减的，即 \( f(n_i) \leqslant f(n_j) \) (3.20)

A* 算法的搜索效率很大程度上取决于启发式函数 h(n) 。一般来说，在满足 \( h(n) \leqslant h^*(n) \) 的前提下， h(n) 的值越大越好。 h(n) 的值越大，说明它携带的启发式信息越多， A* 算法搜索时扩展的节点就越少，搜索效率就越高。 A* 算法的这一特征也称为信息性。

# 性质 3.7 设有两个 A* 算法 \( A_1^* \) 和 \( A_2^* \) :

```
\( A_1^*: f_1(n) = g_1(n) + h_1(n) \)
\( A_2^*: f_2(n) = g_2(n) + h_2(n) \)
```

如果 \( A_2^* \) 比 \( A_1^* \) 有更多的启发性信息，即对所有非目标节点，均有 \( h_1(n) > h_2(n) \) 则在搜索过程中，被 \( A_2^* \) 扩展的节点必然被 \( A_1^* \) 扩展。证明从略。

# 3.4.5 迭代加深 A* 算法

迭代代深搜索算法以深度优先的方式在有限制的深度内搜索目标节点。在每个深度上，该算法检查目标节点是否出现，如果出现，则停止，否则深度加 1，继续搜索。而 A* 算法是选择具有最小估价函数值的节点扩展。由于 A* 算法把所有生成的节点保存在内存中，因此 A* 算法在耗尽计算时间之前，就早已把空间耗尽。目前开发了一些新的算法，目的是克服空间问题，但一般不满足最优性或完备性，如迭代代深 A* (iterative deepening A*, IDA*) 算法、简化内存受限 A* (simplified memory A*, SMA*) 算法等。
迭代代深 A* 算法 IDA* 是上述两种算法的结合。这里启发式函数用于深度的限制，而不是选择扩展节点的排序。下面简单介绍 IDA* 算法。

# 算法 3.5 | IDA* 算法。

```
Procedure IDA*
Begin
    初始化当前的深度限制 c = 1;
    把初始节点压入栈;
    While 栈不空 do
    Begin
        弹出栈顶元素 n;
        If n = goal Then 结束，返回 n 和从初始节点到 n 的路径;
        Else do
        Begin
            For n 的每个子节点 n';
            If f(n') <= c Then 把 n' 压入栈;
            Else c' = min[c', f(n')];
        End for
        End
    End While
```
