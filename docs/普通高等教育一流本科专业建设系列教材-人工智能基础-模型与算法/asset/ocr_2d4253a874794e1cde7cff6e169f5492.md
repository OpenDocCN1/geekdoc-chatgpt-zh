时效性体现在相信的事实是暂时为真，而非永久为真。随着时间的推移，有用信息的扩大，所相信的事实可能为假，或者在某段时间内为假。例如，在 17 世纪以前，很多人相信“地平说”，即地表是一个平面；而几个世纪后，这种观点就过时了。

主观性体现在相信某个事实为真的主体之间，对于判断事实为真的标准可能不一样。例如，在以前，对于中国人而言，买房子是人生存的必需条件之一；而对于欧美人而言，买房子不如租房子，买房子不是人生的必需条件之一。这种“相信”的直觉可能出自不同原因，当然，这种“相信”意义下的事实也可能为假。

目前，研究非单调推理的途径一般有两种。一种观点认为经典逻辑对于研究非单调推理明显有不足的地方，因此最好是建立新的语义机制和逻辑系统，在此基础上进行非单调推理的研究以解决一些问题；另一种观点则认为，在经典逻辑框架下研究非单调推理是完全可行的，关键是怎么使用经典逻辑。

非单调推理具有一定的灵活性，所得结论具有暂时性。随着新信息的出现，可以不断修正结论。寻求失效的结论是单调推理中不存在的问题。从这个意义上说，非单调推理就明显比单调推理要复杂得多。

# (3) 两者的联系与区别

单调推理是非单调推理的基础，这就类似于演绎推理是归纳推理、模糊推理和概率推理的基础。例如，三段论规则之一是前提中必有一个是全称命题，这具有单调推理的特征。当把规则修改之后，就出现非单调的特征。例如，前提中可能出现两个特称命题，或者其中的一个命题是未知命题，所得结论是暂时可靠的。如果出现反例，结论就需要修改；如果暂时不出现反例，通过相信其中的一个特称命题为全称命题，或者相信未知命题为已知命题，才能在“相信”的意义下得出“可靠”的结论。在归纳推理的过程中也反映出类似的情况，在假设的意义下，通过不完全归纳来得到一个或然的结论。

在推理的形式上，单调推理呈现线性特征，而非单调推理与之相反；在推理有效性方面，单调推理要强于非单调推理，只不过单调推理在常识推理中的应用范围要远小于非单调推理；在常识推理中，当然是非单调推理要比单调推理更加灵活。

# 4. 按推理中是否运用启发性知识划分

按推理中是否运用启发性知识划分，推理可分为启发性推理和非启发性推理。

# (1) 启发性推理

如果在推理过程中，运用与问题有关的启发性知识，即解决问题的策略、技巧及经验，以加快推理过程，提高搜索效率，这种推理过程称为启发性推理。这是一种有效的重要方法，它不是依靠数学上的理论推导，而是主要依靠一些总结出来的解决问题的有效经验。把经验性的东西写成规则形式就是启发性知识，也称启发式规则。著名的启发式算法有 20 世纪 70 年代初尼尔松给出的 A 算法、A*算法等。
