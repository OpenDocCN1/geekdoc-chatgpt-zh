$w_{ij}(k+1) = w_{ij}(k) + \alpha y_i(k) y_j(k), \alpha > 0 \quad (7.15)$

式中，$w_{ij}(k+1)$ 为权值的下一步值；$w_{ij}(k)$ 为权值的当前值；$w_{ij}$ 为神经元 $j$ 到神经元 $i$ 的连接权重；$y_i$ 与 $y_j$ 为两个神经元的输出；$\alpha$ 为学习速率的常数。

如果 $y_i$ 与 $y_j$ 同时被激活，即 $y_i$ 与 $y_j$ 同时为正，那么 $w_{ij}$ 将增大；如果 $y_i$ 被激活，而 $y_j$ 处于抑制状态，即 $y_i$ 为正 $y_j$ 为负，那么 $w_{ij}$ 将减小。

# 2. 纠错式学习——Delta 学习规则

1986 年，美国认知心理学家戴维·麦克莱兰（David McClelland）和鲁梅尔哈特在神经网络训练中引入了 Delta 学习规则，该规则也可以称为连续感知器学习规则。Delta 学习规则是一种利用梯度下降法的一般性学习规则。

首先考虑一个简单的情况：设某神经网络的输出层中只有一个神经元 $i$，给该神经网络加上输入，这样就产生了输出 $y_i(n)$，称该输出为实际输出。

对于所加上的输入，一般期望该神经网络的输出为 $d(n)$，称为期望输出或目标输出。实际输出与期望输出之间存在误差，用 $e(n)$ 表示，其计算方法为

$e(n) = d(n) - y_i(n) \quad (7.16)$

现在要调整权值，将误差信号 $e(n)$ 减小到一个范围。为此，设定代价函数或性能指数 $E(n)$ 为

$E(n) = \frac{1}{2}e^2(n) \quad (7.17)$

系统的稳定状态即突触权值稳定不变。反复调整突触权值，使代价函数达到最小或使系统达到一个稳定状态，就完成了当前的学习过程。该学习过程称为纠错学习，或 Delta 学习规则。

Delta 学习规则是一种简单的有监督学习算法，该算法根据神经元的实际输出与期望输出差别来调整连接权值。其数学表示为

$\Delta w_{ij}(n) = \eta e(n) x_j(n) \quad (7.18)$

式中，$w_{ij}$ 为神经元 $x_j$ 到 $x_i$ 的权值。

在学习步骤为 $n$ 时，对突触权值的调整为

$w_{ij}(n+1) = w_{ij}(n) + \Delta w_{ij}(n) \quad (7.19)$

在 Delta 学习规则中，若神经元实际输出比期望输出大，则减少输入为正的连接权值，增大所有输入为负的连接权值；反之，则增大所有输入为正的连接权重，减少所有输入为负的连接权重。

# 7.3 感知器

感知器于 1957 年由弗兰克·罗森布拉特提出，是一种由两层神经元组成的神经网络，是神经网络与支持向量机的基础。感知器是二类分类的线性分类模型，输入为实例的特征向量，输出为实例的类别，取+1 和-1 两个值。感知器对应输入空间（特征空间）中将实例划分为正负两类的分离超平面，属于判别模型。感知器学习算法分为原始形式和对偶形式，具有简单且易于实现的优点。感知器学习旨在求出将训练数据进行线性划分的分离超平面。为此，导入基于误分类的损失函数，利用梯度下降法对损失函数进行极小化，求得感知器模型。
