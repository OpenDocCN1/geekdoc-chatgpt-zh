上述神经元的活动可以用式（7.1）和式（7.2）来表达。

$$u = \sum_{i=1}^{n} w_i x_i$$

$$y = f(u - \theta) = f\left(\sum_{i=1}^{n} w_i x_i - \theta\right)$$

整理得

$$a = \sum_{i=0}^{n} w_i x_i$$

$$y = f(a) = f\left(\sum_{i=0}^{n} w_i x_i\right)$$

# 2. 标准统一的神经元数学模型

从 20 世纪 40 年代开始，根据神经元的结构和功能异构，先后提出的神经元模型有数百种。下面介绍神经元的一种标准、统一的数学模型，其由加权求和、线性动态系统和非线性函数映射 3 部分组成。神经元模型是一个包含输入、输出与计算功能的模型，其中输入可以类比为神经元的树突，输出可以类比为神经元的轴突，计算则可以类比为细胞核。

图 7.4 所示为一个典型的神经元模型，包含输入、输出及计算功能。中间的箭头线称为连接，是神经元中最重要的部分，每个连接上有一个权值。一个神经网络的训练算法就是让权重的值调整到最佳，以使整个网络的预测效果最好。

在神经元模型中，每个有向箭头表示示值的加权传递。神经元可以看作一个计算与存储单元，计算是指神经元对其输入参数进行计算；存储是指神经元会暂存计算结果，并传递到下一层。

当用神经元组成网络之后，描述网络中的某个神经元时，更多地会用单元（unit）来指代。同时，由于神经网络的表现形式是一个有向图，因此有时也会用节点（node）表达同样的意思。
