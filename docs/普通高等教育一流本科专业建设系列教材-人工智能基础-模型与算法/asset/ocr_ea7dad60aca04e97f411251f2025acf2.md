# 5.2.3 可信度方法

根据经验对一个事物和现象为真的相信程度称为可信度，也称为确定性因子。可信度带有较大的主观性和经验性。例如，张三昨天没有上课，他的理由是肚子疼，就此理由而言，听话的人可能完全相信，也可能完全不相信，也可能在某种程度上相信，这与张三平时的表现和人们对他的话的相信程度有关。

可信度方法是由美国斯坦福大学爱德华·肖特利夫（Edward Shortliffe）等在确定性理论的基础上，考察了非概率的和非形式化的推理过程后，于 1975 年提出的一种不确定性推理方法，并于 1976 年首次在血液病诊断专家系统 MYCIN 中得到了成功应用。该方法比较简单、直观，而且效果比较好。目前，有许多成功的专家系统都是基于这一方法建立起来的。

具有代表性的可信度模型 MYCIN 采用可信度 CF（certainty factor）作为不确定性测度，通过对 CF(H,E)的计算，探讨证据 E 对假设 H 的定量支持程度，因此该方法也称为 C-F 模型。其他可信度方法都是在此基础上发展起来的。

+   1. 知识不确定性的表示

在 C-F 模型中，知识以产生式规则表示：

```
IF E THEN H [CF(H,E)]
```

式中，E 为规则的前提条件；H 为规则的结论；CF(H,E) 为规则的可信度，也称为规则强度或知识强度。其中，前提和结论都可以是复合命题，可信度则描述的是知识的静态强度，反映了前提条件与结论的联系强度。

CF(H,E) 的取值范围一般为[-1,1]。当该值大于 0 时，值越大，说明证据的出现越是支持 H 为真，知识越接近于“真”；当其值小于 0 时，值越小，说明知识越接近于“假”；当该值等于 0 时，说明证据的出现与否与 H 无关。

例如，对于一个新冠患者而言，“IF 发热低于 38℃ AND 可自行退热 AND 无呼吸困难 THEN 轻症新冠患者 AND 居家隔离口服药物可控制病情 (0.8)”，表示病人如有上述症状，则有八成把握认为他是新冠轻症患者并且居家隔离口服药物即可控制病情。

规则强度 CF(H,E) 的计算公式如下：

```
CF(H,E) = MB(H,E) - MD(H,E), CF(H,E) \in [-1,1] (5.43)
```

式中，MB（measure belief）为信任增长度，表示因与 E 匹配的证据的出现，对 H 为真的信任增长度；MD（measure disbelief）为不信任增长度，表示因与 E 匹配的证据的出现，对 H 为真的不信任增长度。

MB 的定义为

```
MB(H,E) = \begin{cases} 1, & \text{若} P(H) = 1 \\ \frac{\max \{ P(H|E), P(H) \} - P(H)}{1 - P(H)}, & \text{若} P(H) \neq 1 \end{cases} (5.44)
```
