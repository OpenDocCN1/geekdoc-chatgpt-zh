
如果一个 Agent 不具有偏好，由定义可知它不会关心其所处的环境状况，因此也不会关心自己做什么。设计此类 Agent 的唯一目的是逐步培养其偏好，使其更偏爱某种环境状态并尽力实现。Agent 并非必须知道自己的偏好，如一个恒温器，它只需感知环境，并控制加热器开和关即可。但它通常会被嵌入一定的偏好，即让房间中的人员处在一个合适的温度中，尽管它并不知道自己具有此偏好。Agent 的偏好一般就是设计者的偏好，但是有时在运行中也可赋予目标和偏好。

Agent 通过传感器来接收信息，一个 Agent 的动作取决于通过传感器获取的信息，这些传感器有可能反映环境的真实状态。传感器可能是有噪声的、不可靠的、丢掉的，甚至有时候传感器是可靠的，但是它传回的关于环境的信息却是模棱两可的，而 Agent 却必须依靠其获取的信息进行决策。

Agent 通过执行器进行动作。执行器同样可能是有噪声的、不可靠的、行动缓慢的或者是坏掉的。Agent 控制的是其发送给执行器的信息，经常会采取行动寻找更多的环境信息，如打开橱柜门查看物件或者对学生进行测试来测定他们的知识。

### (2) Agent 系统的结构

Agent 系统的结构如图 4.7 所示，该图展示了 Agent 与环境进行交互的一般过程。

![](img/01b3dd63f105ee2f61ade787bae553f5_116_0.png)

图 4.7 Agent 系统的结构

一个 Agent 系统由 Agent 本身及其所处的环境构成。Agent 接收环境中的刺激，然后做出相应动作。

一个 Agent 由主体（body）和控制器（controller）两部分组成。控制器从主体处接收感知，并将命令送给主体。主体包括传感器和执行器，传感器将外部刺激转换为感知，执行器将命令转换为动作。

刺激包括光、声音、键盘上输入的单词、鼠标移动或者物理冲击，也包括从网页或者数据库中获取的信息。

常见的传感器包括触摸传感器、相机、红外传感器、声呐、麦克风、键盘、鼠标或者通过网页抽取信息的 XML 阅读器。作为原型传感器，相机感知进入它的光束，将其转换成亮度数值的二维数组，称为像素。有时会使用多维像素数组来表示不同的颜色或者满足多镜头相机的需求，这些像素数组可被控制器感知。更多的时候，感知对象通常有着更高层的特征，如线、边或深层次的信息。通常来说，接收的都是特定信息，如明亮的橙色圆点的位置、学生关注的演出部分或者人们打出的手势信息等。

动作一般包括转向、加速、移动关节、讲话、展示信息或者向某一网址发送邮件的命令。命令又包括低级命令（如将发动机的电压设定为某个数值）和高级命令（如令一个机器人进行某些运动，如“启动”“到 S3 处标记”或者“匀速沿 S 形移动”等）。执行器与传感器类似，都包含噪声。例如，机器人在物理规则下运动，因此具备动量，且信息传递需要时间，接收到“匀速沿 S 形移动”指令的机器人也许最终只是沿着大概的方向行进，而并非沿标准 S 形移动，且速度和方向都是不断波动的，甚至运动到某一指定位置的行为可能会由于各种原因而失败。

为解决复杂问题的缓慢推理与 Agent 所需的针对高级目标的快速反应之间的矛盾，分层控制被提出。图 4.8 中所示为分层控制结构，每一层都将其下层看作一个可从中获取感知及发出命令的虚拟主体。越低层，反应速度越快，适用于那些需要快速反应的情况，且能将对环境更简单直白的感知传给高层，隐藏不重要的信息。总的来说，不同时间的状态之间会有大量的特征在层与层之间传递。

![](img/01b3dd63f105ee2f61ade787bae553f5_117_0.png)

图 4.8 分层控制结构

对于每个时刻的每一层，存在如下 3 类输入。

- 1) 来自信念状态的特征，指的是这些特征所记住的或以前的状态值。
- 2) 从下层结构得到的感知的特征。
- 3) 从上层结构得到的命令的特征。

对于每个时刻的每一层，存在如下 3 类输出。

- 1) 对应上层的更高等级的感知。
- 2) 对应下层的低等级命令。
- 3) 信念状态特征的下一个值。

层级的实现方式决定了层的输出是如何由输入函数得出的。此函数的计算可以涉及任意计算，目的是使每层尽可能简单。

为了实现控制器，层上的任何输入必须有确切的赋值来源，每个感知或者命令输入应该源自与其相连的其他层的输出。其他的输入来源于记住的信念。每层上的输出不必有相连对象，或者可与多个输入相连接。高级推理在高层上给出，一般是离散的、定性的；而底层中给出的低级推理则是连续的和定量的。一个可推理产生离散和连续两种值的控制器称为混合系统。

### （3）Agent 系统的分类

牛津大学的计算机科学教授伍德里奇（Wooldridge）和詹宁斯（Jennings）等提出的 Agent 应具有自主性、反应性、社会能力和主动性 4 个基本属性，大多数研究者认为 Agent 除了满足上述基本特性之外，还应具有移动性、适应性、学习性等特性。Agent 的特性使得它表现出类似人的特性，为解决企业复杂问题提供了新的思路。

现有的 Agent 应用大都以某几个属性作为关键属性进行结构设计。Agent 结构大体上可以分为以下几类。

### 1）思考型 Agent

思考型 Agent 被看作一种意识系统，它是一种特殊的知识系统，即通过符号 AI 的方法实现表示和推理。这种结构直接反映了 Agent 作为意识系统的理性本质，是支撑行为推理、思维判断等意识活动的关键，也是构造各类复合型 Agent 个体的基础。图 4.9 给出了思考型 Agent 的基本结构。

![](img/01b3dd63f105ee2f61ade787bae553f5_118_0.png)

图 4.9 思考型 Agent 的基本结构

选择什么样的意识态度来刻画 Agent 是构造思考型 Agent 首先要考虑的问题。根据理性的不同实现方式，有以下几种典型的思考型 Agent 结构。

- ① 基于经典逻辑的 Agent 结构以经典逻辑公式表述 Agent 的状态和行为，以在一定推理规则下演绎推理表述 Agent 的思维决策过程，将推理求得的结果公式作为输出动作。由于经典逻辑具有严密的语法和直观、简洁的语义，因此基于经典逻辑的 Agent 结构也具有这些优点。但同时，由于经典逻辑本身的局限性，在问题复杂度增加的同时，推理过程的计算复杂度也呈指数上升，因此其在很多情况下失去了实用价值。另外，经典逻辑的表达能力有限，对复杂环境状态难以建立相应的逻辑式表达，更难以表示信念、意愿等反映思维意识的概念。

- ② 基于 BDI（belief-desire-intention，信念-愿望-意图）模型的思考型 Agent 结构反映了人们为了实现既定目标而采取一系列行动的过程，具有深刻的认知心理学和哲学基础。BDI 模型中的信念是指 Agent 所掌握的关于当前世界状况及为达到某种效果可能采取的行为路线的估计，表示 Agent 对环境和自身的了解；愿望则描述了 Agent 对未来实际状况及可能采取的行为路线的喜好。愿望可以是不相容的，也允许存在不可达的愿望，其中相容且可达的部分构成目标集。由于资源的有限性，Agent 不可能一次追求所有的目标，它选择目标集中的一部分形成意图。信念、愿望、意图等概念通过人们的日常生活可建立起一些非形式化的概念，同时为分布式环境中的 Agent 交互打下基础。

BDI 模型也存在一些问题。首先，通过逻辑描述的方法表达信念、愿望、意图等反映思维状态的概念并合理完成相应的推理转换有一定的难度；其次，BDI 模型实际上可以说是个体 Agent 的思维属性，描述 Agent 之间的社会层面的交互存在一定的局限性。人们提出要使 Agent 具有社会层面的思维属性，但在实用化方面仍然有很多困难。

- ③ 基于决策理论的 Agent 结构认为，Agent 先观察外部环境再通过自身的预测、思考或规则匹配并输出行为的过程可看作 Agent 求解问题并追求效用最大化的过程。因此，Agent 理性行为可以从描述理论出发，通过基于效用评价的决策过程来刻画。基于决策理论的 Agent 结构较好地反映了人们求解问题的实际过程，可以在决策理论的指导下，综合运用数学、逻辑、人工智能等多种技术加以实现。同时，可用对方案结果的估计来表示信念，用各个可能结果状态的效用反映愿望，可较好地实现 Agent 的 BDI 框架结构。

值得注意的是，由于决策 Agent 的资源有限性和客观世界无限性的矛盾，决策者不可能尝试所有的方案。因此，可从如下两个方面寻求解决途径：一是对真实环境的简化，用较小的问题空间代替实际的问题空间，形成以估算和最优为特征的经典决策理论方法；二是以满意替代最优，形成以搜索和满意为特征的现代决策理论方法。满意法则并不需要严格估计或计算后果的发生概率及相应的效用，只需要一个相对范围，整个决策过程是一个逐步细化的搜索过程。但如果过程控制不好，也可能导致过多开销。

### 3）混合型 Agent

思考型 Agent 具有较高的智能，但无法对环境的变化做出快速响应，而且运行效率较低；反应型 Agent 能及时而快速地响应外来信息和环境的变化，但其智能程度较低，也缺乏足够的灵活性。纯粹的思考型 Agent 和反应型 Agent 对于大多数实际问题并不合适，于是人们考虑混合体系结构的 Agent，即混合型 Agent。

混合型 Agent 通常被设计成至少包括如下两部分的层次结构：高层是一个包含符号世界模型的认知层，采用传统符号处理规则并进行决策；低层是一个快速响应和处理环境中突发事件的反应层，不使用任何符号表示和推理系统，反映层通常具有更高的优先权。

过程推理系统（procedure reasoning system，PRS）体系是混合型 Agent 结构的一个典型实例。PRS 有一个计划库及显式表示的信念、愿望和目标：信念是一些事实，包括外部世界和 Agent 的内部状态，采用经典的一阶逻辑表示；愿望由系统行为表示；目标是系统期望的行为。PRS 计划库包含一些不完整的的计划，称为知识区（knowledge area，KA），一个知识区和一个激活状态相连，该状态决定知识区什么时候被激活。

德国的费舍尔和穆勒等提出的 INTERMAP 结构也是层次结构的典型代表，其控制器分为行为层、规划层和协作层，其中行为层用于对外界情况做出及时反应，规划层支持系统的中长期规划，协作层则支持系统与外界的交互。这 3 个层次反映了 Agent 的反应性、主动性和社会性 3 个属性。

## 4.2 确定性推理

一个智能系统不仅应该拥有知识，还应该能很好地利用这些知识，即运用知识进行推理和问题求解。智能系统的推理过程实际上是一个思维过程。根据推理过程所用知识的确定性，推理可分为确定性推理和不确定性推理。本节重点介绍确定性推理。

### 4.2.1 命题逻辑

人类的任何具体思维都有它的内容及其相应的形式，均涉及一些特定的对象。例如，数学中的具体思维涉及数量与图形等特定对象，物理学中的具体思维涉及声、光、电、力等特定对象。不同领域中的具体思维所涉及的对象可能不同，但是在这些不同领域的具体思维中又存在着一些共同的因素，如类似的思维形式和思维内容。

人们的思维活动是靠自然语言来表达的。由于自然语言易产生二义性，因此用它来表示严格的推理并不合适。于是，在数理逻辑中，常使用命题进行形式化的推理。

命题逻辑（proposition logic）是应用一套形式化规则对以符号表示的描述性陈述进行推理的系统。在命题逻辑中，一个或真或假的描述性陈述被称为原子命题，若干原子命题可通过逻辑运算符构成复合命题。如果已知若干命题，则可通过命题联结词对已有命题进行组合，得到新命题。这些通过命题联结词得到的命题称为复合命题（compound proposition）。

反复利用命题联结词可以产生更复杂的命题。例如，有如下符号串：

```
¬P→(Q∧R)
(R∨¬B)∧(C⇒D)
```

当这些符号串中的大写字母都表示确定的命题时，上面的符号串就表示更复杂的命题；若这些大写字母不表示确定的命题，则上面的符号串就是命题公式，简称为公式。但并不是随意产生的符号串都能称为命题公式，必须遵循一定的规则。需要注意的是，命题逻辑的推理讲求的是形式结构上的有效性，而非结论的正确性。

命题逻辑法表示具有极大的局限性，它无法把所描述的事物的结构及逻辑特征反映出来，也不能把不同事物之间的共同特征表述出来。为解决这些问题，在命题逻辑的基础上发展起来了谓词逻辑。

### 4.2.2 谓词逻辑

传统谓词逻辑主要是研究性质命题及其推理（以三段论为核心）的逻辑。在传统谓词逻辑中，所有的命题都是只具有如下 4 种形式的命题：A——所有的 S 都是 P；E——所有的 S 都不是 P；I——有些 S 是 P；O——有些 S 不是 P。

至于具有“这个 S 是 P”和“这个 S 不是 P”形式的命题，一般笼统地处理成相应的 A 命题和 E 命题。无疑，对于可以分析成这种形式的命题来说，传统谓词逻辑中的方法的确很有实用性，但这种单纯的形式方法存在着很大的局限性。例如，有下列命题：

- 1）小明的成绩比小红的成绩高。
- 2）内蒙古在山东的北方。
- 3）98%的同学参与选举并同意张瑶同学担任班长。

它们与具有上述 A、E、I、O 4 种形式的命题有着明显的区别，称为关系命题，即表达这个体对象之间是否具有某种关系。由这些命题构成的推理称为关系推理。例如，有下列命题：

- 1）小明的成绩比小红的成绩高。
- 2）小林的成绩比小明的成绩高。
- 3）所以小林的成绩比小红的成绩高。

直观上，这个推理是有效的，并且其有效性来源于命题的内部结构。类似这个推理的关系推理显然应该成为着重分析命题内在逻辑结构的谓词逻辑的研究对象。但关系命题和关系推理都超出了传统谓词逻辑的范围，传统谓词逻辑仅研究性质命题，而且仅研究三段论或是仅对性质命题的形式稍做变化的推理。现代谓词逻辑可以很好地解决关系命题的相关问题。关系命题及其推理是现代谓词逻辑的基本内容，在其理论体系中，关系命题及其推理与性质命题及其推理并无实质性的区别，仅是包含不同的谓词而已。

谓词逻辑重在研究量词的逻辑性质。传统谓词逻辑把量词归结为“所有”和“有些”，进而把命题归结为全称命题和特称命题，而对于日常语言中经常出现的单称命题基本上是回避的。此外，传统谓词逻辑对量词理论采取了种种限制，如规定被量词约束的词项均不能是空类等。在现代谓词逻辑中，一切词项均可以是空类，逻辑应该尽量满足所有可能性，只有这样才具有普遍应用性。

考察下面一组命题或命题函数。

- 1）3 是质数。
- 2）沈雯的外教老师是美国人。
- 3) 所有的 x 都是锂电池。
- 4) 李丽与马文强是同学。
- 5) 重庆在四川与湖北之间。

其中，“3”“沈雯”“x”“李丽”“马文强”“重庆”“四川”“湖北”表示的都是个体对象。在现代谓词逻辑中，用来指称这些个体对象的符号称为个体词。个体词又分为个体变元（或个体变项）和个体常元（或个体常项）。个体常元指称某一确定的具体对象，如指称个体对象“3”“沈雯”“李丽”“马文强”“重庆”“四川”“湖北”的个体词就是个体常元。个体变元指称某一个体对象类中任意的个体，如上文中的“x”，其中的个体对象类是个体的取值范围，称为论域或个体域。个体常元一般用 a、b、c、…来表示，个体变元则用 x、y、z 来表示。

谓词是指称对象（在一阶谓词中是个体对象）所具有的性质或对象之间所具有的关系的符号。谓词可以分为谓词常元（或谓词常项）和谓词变元（或谓词变项）。表示某一确定论域中的特定的性质或关系的谓词称为谓词常元，如前例中的“是质数”“是美国人”“是锂电池”“是同学”“在……之间”。不表示某一确定论域中的特定性质或关系的谓词称为谓词变元。谓词变元一般用符号 F、G、H、…来表示。根据谓词指称的个体对象的数目（称为元数），可以把谓词分为一元谓词、二元谓词、…、n 元谓词。一元谓词只指称一个个体对象，显然表达的就是个体对象的性质，如“是质数”“是美国人”“是锂电池”就是一元谓词；二元谓词指称两个个体对象，表达的是其间的关系，如“是同学”；三元谓词表达的是三个个体对象之间的关系，如“在……之间”。

量词是谓词逻辑中最重要的研究对象，谓词逻辑也因此称为量词逻辑。量词是表示被其约束的对象的数量的逻辑符号。依据它所指的是某对象类中的所有对象还是至少一个对象，量词可分为全称量词和存在量词。全称量词用 ∀ 表示，自然语言中的“所有”“凡”“任一个”“每一个”“一切”等都表示全称量词，其准确含义是“对任一……来说”；存在量词用 ∃ 表示，自然语言中的“有些”“有的”“至少有些”等表示的都是存在量词，其准确含义是“至少存在一个……”。根据量词所约束的对象是个体词还是谓词，可以把量词分为一阶量词、二阶量词和高阶量词。一阶量词是只约束个体词的量词，即这种量词所限制的只是个体对象。一阶谓词逻辑只研究一阶量词。二阶量词所约束的是一阶谓词，三阶量词所约束的是二阶谓词，依此类推，它们都是高阶谓词逻辑的研究对象。

### 4.2.3 自然演绎推理方法

从一组已知为真的事实出发，运用经典逻辑中的推理规则推出结论的过程称为自然演绎推理，其推理规则包括 P 规则、T 规则、假言推理、拒取式和假言三段论。

P 规则是指在推理的任何步骤中都可引入前提，继续进行推理。

T 规则是指推理时，如果前面步骤中有一个或多个公式永真蕴涵公式 S，则可以把 S 引入推理过程中。

假言推理是指由 P → Q 及 P 为真，可以推出 Q 为真，其一般形式为

```
P,P→Q⇒Q (4.1)
```

例如，由“如果今天下雨，那么今天要带伞”和“今天下雨”可以推导出“今天要带伞”的结论。
