
## 1. 感知器学习算法的原始形式

感知器学习算法是指针对以下最优化问题的算法。根据式（7.29），求参数 \(w\) 和 \(b\) 使其为以下损失函数极小化问题的解：

\(\min_{w,b} L(w,b) = - \sum_{x_i \in M} y_i (wx_i + b)\) (7.29)

式中，\(M\) 为误分类点的集合。

感知器学习算法是误分类驱动的，采用随机梯度下降法（stochastic gradient descent）进行优化。首先任意选取一个超平面 \((w_0, b_0)\)，然后用梯度下降法不断极小化目标函数「式（7.29）」。极小化过程中不是一次使 \(M\) 中所有误分类点的梯度下降，而是一次随机选取一个误分类点使其梯度下降。

假设误分类点集合 \(M\) 是固定的，那么损失函数 \(L(w,b)\) 的梯度由以下两式给出：

\(\nabla_w L(w,b) = - \sum_{x_i \in M} y_i x_i\) (7.30)

\(\nabla_b L(w,b) = - \sum_{x_i \in M} y_i\) (7.31)

随机选取一个误分类点 \((x_i, y_i)\)，对 \(w\)、\(b\) 进行更新，更新公式为

\(w \leftarrow w + \eta y_i x_i\) (7.32)

\(b \leftarrow b + \eta y_i\) (7.33)

式中，\(\eta(0 < \eta \leqslant 1)\) 为步长，在统计学习中又称为学习率（learning rate）。

这样，通过迭代可以期待损失函数 \(L(w,b)\) 不断减小，直至为 0。综上所述，得到如下算法。

### 算法 7.1 感知器学习算法的原始形式。

输入：线性可分训练数据集 \(T=\{(x_1, y_1), (x_2, y_2), \cdots, (x_N, y_N)\}\)，其中 \(x_i \in X=R^n\)，\(y_i \in Y=\{+1, -1\}\)，\(i=1, 2, \cdots, N\)；学习率 \(\eta(0 < \eta \leqslant 1)\)。
输出：\(w\)、\(b\)，感知器模型 \(f(x) = \text{sign}(wx+b)\)。
1) 选取初值 \(w_0\) 和 \(b_0\)。
2) 在训练集中选取数据 \((x_i, y_i)\)。
3) 如果 \(y_i(wx+b) \leqslant 0\)，那么计算式（7.32）和式（7.33）。
4) 转至 2)，直至训练集中没有误分类点。

这种学习算法直观上有如下解释：当一个实例点被误分类，即位于分离超平面的错误一侧时，则调整 \(w\)、\(b\) 的值，使分离超平面向当前误分类点的一侧移动，以减少其与超平面之间的距离，直至超平面越过该点使其被正确分类。

感知器学习算法的原始形式是感知器学习的基本算法，对应后面的对偶形式，称为原始形式。感知器学习算法简单且易于实现。

**例 7.1** 如图 7.8 所示的训练数据集，其正实例点是 \(x_1=(3,3)^T\)，\(x_2=(4,3)^T\)，负实例点是 \(x_3=(1,1)^T\)，试用感知器学习算法的原始形式求感知器模型 \(f(x) = \text{sign}(wx+b)\)，这里 \(w=(w^{(1)}, w^{(2)})^T\)，\(x=(x^{(1)}, x^{(2)})^T\)。

**解** 构建最优化问题表示

\(\min_{w,b} L(w,b) = - \sum_{x_i \in M} y_i (wx_i + b)\) (7.34)

按照感知器学习算法的原始形式算法求解参数 $w$ 和 $b$，$\eta = 1$。

- 1) 取初值 $w_0 = 0$, $b_0 = 0$。

```
$w_1 = w_0 + y_1x_1 = (3,3)^T$
$b_1 = b_0 + y_1 = 1$
```

得到线性模型：

```
$w_1x + b_1 = 3x^{(1)} + 3x^{(2)} + 1$
```

3）对 $x_1$、$x_2$，显然，$y_i(w_1x_i + b_1) > 0$，被正确分类，不用更新 \(w\)、\(b\)：对 $x_1 = (3,3)^T$, $y_3(wx+b) < 0$，未能被正确分类，更新 \(w\)、\(b\)：

```
$w_2 = w_1 + y_3x_3 = (2,2)^T$
$b_2 = b_1 + y_3 = 0$
```

得到线性模型：

```
$w_2x + b_2 = 2x^{(1)} + 2x^{(2)}$
```

如此继续下去，直到

```
$w_7 = (1,1)^T$
$b_7 = -3$
$w_7x + b_7 = x^{(1)} + x^{(2)} - 3$
```

对所有数据点 $y_i(w_7x_i + b_7) > 0$，没有误分类点，损失函数达到极小，得到分离超平面为

```
$x^{(1)} + x^{(2)} - 3 = 0$
```

感知器模型为

```
$f(x) = \text{sign}(x^{(1)} + x^{(2)} - 3)$  (7.35)
```

## 2. 感知器学习算法的收敛性

现在证明，对于线性可分数据集，感知器学习算法原始形式收敛，即经过有限次迭代，可以得到一个将训练数据集完全正确划分的分离超平面及感知器模型。

为了便于叙述与推导，将偏置 $b$ 并入权重向量 $w$，记作 $\hat{w} = (w^T, b)^T$，同样也将输入向量加以扩充，加进常数 1，记作 $\hat{x} = (x^T, 1)^T$。这样，$\hat{x} \in R^{n+1}, \hat{w} \in R^{n+1}$。显然，$\hat{w}x = wx + b$。

定理 7.2 (Novikoff 定理) 设训练数据集 $T = \{(x_1, y_1), (x_2, y_2), \cdots, (x_N, y_N)\}$ 是线性可分的，其中 $x_i \in X = R^n, y_i \in Y = \{+1, -1\}, i = 1, 2, \cdots, N$，则：

- 1) 存在满足条件 $\| \hat{w}_{opt} \| = 1$ 的超平面 $\hat{w}_{opt} \hat{x} = w_{opt} x + b_{opt} = 0$，将训练数据集完全正确分开；且存在 $\gamma > 0$，对所有的 $i = 1, 2, \cdots, N$，有 $y_i (\hat{w}_{opt} \hat{x}) = y_i (w_{opt} x + b_{opt}) \geqslant \gamma$ (7.36)

- 2) 令 $R = \max_{1 \leqslant i \leqslant N} \| \hat{x}_i \|$，则感知器算法 7.1 在训练数据集上的误分类次数 $k$ 满足不等式：
- $k \leqslant \left( \frac{R}{\gamma} \right)^2$ (7.37)

证明 1) 由于训练数据集是线性可分的，按照定理 7.2，存在超平面可将训练数据集完全正确分开，取此超平面为 $\hat{w}_{opt} \hat{x} = w_{opt} x + b_{opt} = 0$，使 $\| \hat{w}_{opt} \| = 1$。由于对有限的 $i = 1, 2, \cdots, N$，均有
$y_i (\hat{w}_{opt} \hat{x}) = y_i (w_{opt} x + b_{opt}) > 0$ (7.38)
因此存在：
\(\gamma = \min_i \{ y_i (w_{opt} x + b_{opt}) \}\) (7.39)
使
$y_i (\hat{w}_{opt} \hat{x}) = y_i (w_{opt} x + b_{opt}) \geqslant \gamma$ (7.40)

- 2) 感知器算法从 $\hat{w}_0 = 0$ 开始，如果实例被误分类，则更新权重。令 $\hat{w}_{k-1}$ 是第 $k$ 个误分类实例之前的扩充权重向量，即
- \(\hat{w}_{k-1} = (w_{k-1}^T, b_{k-1})^T\) (7.41)

则第 k 个误分类实例的条件为

$y_i (\hat{w}_{k-1} \cdot \hat{x}_i) = y_i (w_{opt} \cdot x + b_{opt}) \leqslant 0 \quad (7.42)$

若 $(x_i, y_i)$ 是被 $\hat{w}_{k-1} = (w_{k-1}^T, b_{k-1})^T$ 误分类的数据，则 $w$ 和 $b$ 的更新为

$w_k \leftarrow w_{k-1} + \eta y_i x_i \quad (7.43)$
$b_k \leftarrow b_{k-1} + \eta y_i \quad (7.44)$

即

$\hat{w}_k = \hat{w}_{k-1} + \eta y_i \hat{x}_i \quad (7.45)$

下面推导两个不等式[式 (7.46) 及式 (7.49)]：

$\hat{w}_k \cdot \hat{w}_{opt} \geqslant k \eta \gamma \quad (7.46)$

由式 (7.45) 及式 (7.46) 得

$\hat{w}_k \cdot \hat{w}_{opt} = \hat{w}_{k-1} \cdot \hat{w}_{opt} + \eta y_i \hat{w}_{opt} \cdot \hat{x}_i \geqslant \hat{w}_{k-1} \cdot \hat{w}_{opt} + \eta \gamma \quad (7.47)$

由此递推即得不等式 (7.49)：

$\hat{w}_k \cdot \hat{w}_{opt} \geqslant \hat{w}_{k-1} \cdot \hat{w}_{opt} + \eta \gamma \geqslant \hat{w}_{k-2} \cdot \hat{w}_{opt} + 2 \eta \gamma \geqslant \cdots \geqslant k \eta \gamma \quad (7.48)$
$\| \hat{w}_k \|^2 \leqslant k \eta^2 R^2 \quad (7.49)$

由式 (7.45) 及式 (7.49) 得

$\| \hat{w}_k \|^2 \leqslant \| \hat{w}_{k-1} \|^2 + 2 \eta y_i \hat{w}_{k-1} \cdot \hat{x}_i + \eta^2 \| \hat{x}_i \|^2$
$\leqslant \| \hat{w}_{k-1} \|^2 + \eta^2 \| \hat{x}_i \|^2$
$\leqslant \| \hat{w}_{k-1} \|^2 + \eta^2 R^2$
$\leqslant \| \hat{w}_{k-1} \|^2 + 2 \eta^2 R^2 \leqslant \cdots$
$\leqslant k \eta^2 R^2 \quad (7.50)$

结合不等式 (7.46) 及式 (7.49) 即得

$k \eta \gamma \leqslant \hat{w}_k \cdot \hat{w}_{opt} \leqslant \| \hat{w}_k \| \| \hat{w}_{opt} \| \leqslant \sqrt{k} \eta R \quad (7.51)$
$k^2 \gamma^2 \leqslant k R^2 \quad (7.52)$

于是

$k \leqslant \left( \frac{R}{\gamma} \right)^2 \quad (7.53)$

定理表明，误分类的次数 $k$ 是有上界的，经过有限次搜索，可以找到将训练数据完全正确分开的分离超平面。也就是说，当训练数据集线性可分时，感知器学习算法原始形式迭代是收敛的。但是，例 7.1 说明，感知器学习算法存在许多解，这些解既依赖于初值的选择，也依赖于迭代过程中误分类点的选择顺序。为了得到唯一的超平面，需要对分离超平面增加约束条件，这就是第 8 章将要讲述的线性支持向量机的想法。当训练集线性不可分时，感知器学习算法不收敛，迭代结果会发生震荡。

## 3. 感知器学习算法的对偶形式

现在考虑感知器学习算法的对偶形式。感知器学习算法的原始形式和对偶形式与第 8 章中支持向量机学习算法的原始形式和对偶形式相对应。

对偶形式的基本想法是，将 $w$ 和 $b$ 表示为实例 $x_i$ 和标记 $y_i$ 的线性组合形式，通过求解其系数而求得 $w$ 和 $b$。不失一般性，在算法 7.1 中可假设初始值 $w_0$、$b_0$ 均为 0。对误分类点 $(x_i, y_i)$ 通过式（7.32）和式（7.33），逐步修改 $w$、$b$，设修改 $n$ 次，则 $w$、$b$ 关于 $(x_i, y_i)$ 的增量分别为 $\alpha_i y_i x_i$ 和 $\alpha_i y_i$，这里 $\alpha_i = n_i \eta$。从学习过程不难看出，最后学习到的 $w$、$b$ 可以分别表示为

$w = \sum_{i=1}^N \alpha_i y_i x_i \tag{7.54}$

$b = \sum_{i=1}^N \alpha_i y_i \tag{7.55}$

式中，$\alpha_i \geqslant 0 (i=1, 2, \cdots, N)$，当 $\eta=1$ 时，表示第 $i$ 个实例点由于误分而进行更新的次数。实例点更新次数越多，意味着它距离分离超平面越近，也就越难正确分类，即这样的实例对学习结果影响很大。

下面对照原始形式叙述感知器学习算法的对偶形式。

### 算法 7.2 感知器学习算法的对偶形式。

输入：线性可分训练数据集 $T = \{(x_1, y_1), (x_2, y_2), \cdots, (x_N, y_N) \}$，其中 $x_i \in R^n, y_i \in \{+1, -1\}, i=1, 2, \cdots, N$；学习率 $\eta (0 < \eta \leqslant 1)$。
输出：$\alpha, b$；感知器模型 $f(x) = \text{sign} \left( \sum_{j=1}^N \alpha_j y_j x_j x_i + b \right)$，其中 $\alpha = (\alpha_1, \alpha_2, \cdots, \alpha_N)^{\text{T}}$。
1) $\alpha \leftarrow 0, b \leftarrow 0$。
2) 在训练集中选取数据集 $(x_i, y_i)$。
3) 如果 $y_i \left( \sum_{j=1}^N \alpha_j y_j x_j x_i + b \right) \leqslant 0$。
\(\alpha_i \leftarrow \alpha_i + \eta \tag{7.56}\)
\(b \leftarrow b + \eta y_i \tag{7.57}\)
4) 转至 2)，直到没有误分类数据。

在对偶形式中，训练实例仅以内积的形式出现。为了方便，可以预先将训练集中实例间的内积计算出来并以矩阵的形式存储，这个矩阵就是 Gram 矩阵（Gram matrix）：

$G = [x_i x_j]_{N \times N}$

**例 7.2** 数据同例 7.1，正样本点是 $x_1 = (3,3)^{\text{T}}, x_2 = (4,3)^{\text{T}}$，负样本点是 $x_3 = (1,1)^{\text{T}}$，试用感知器学习算法对偶形式求感知器模型。

解 按照算法 7.2 进行计算。

- 1) 取 $\alpha_i = 0 (i=1, 2, 3), b=0, \eta=1$。

- 2) 计算 Gram 矩阵：

$$G = \begin{bmatrix} 18 & 21 & 6 \\ 21 & 25 & 7 \\ 6 & 7 & 2 \end{bmatrix}$$

- 3) 误分条件：

$y_i \left( \sum_{j=1}^N \alpha_j y_j x_j x_i + b \right) \leqslant 0$

参数更新：

$\alpha_i \leftarrow \alpha_i + 1$  
$b \leftarrow b + y_i$
