
## 3. 谓词公式的性质

### (1) 谓词公式的永真性、永假性、可满足性、不可满足性

如果谓词公式 P 对个体域 D 上的任何一个解释都取得真值 T，则称 P 在 D 上是永真的；如果 P 在每个非空个体域上均永真，则称 P 永真。

如果谓词公式 P 对个体域 D 上的任何一个解释都取得假值 F，则称 P 在 D 上是永假的；如果 P 在每个非空个体域上均永假，则称 P 永假。

对于谓词公式 P，如果至少存在一个解释使得 P 在此解释下的真值为 T，则称 P 是可满足的；否则，称 P 是不可满足的。

### (2) 谓词公式的等价性

设 P 与 Q 是两个谓词公式，D 是它们共同的个体域，若对 D 上的任何一个解释，P 与 Q 都是相同的真值，则称 P 和 Q 在 D 上是等价的；如果 D 是任意个体域，则称 P 和 Q 是等价的，记为 P ⇔ Q。

### (3) 谓词公式的永真蕴涵

对于谓词公式 P 与 Q，如果 P → Q 永真，则称 P 永真蕴涵 Q，且称 Q 为 P 的逻辑结论，称 P 为 Q 的前提，记为 P ⇒ Q。

由上述介绍可知，可以用以合取符号（∧）和析取符号（∨）联结形成的谓词公式表示事实性知识，也可以用蕴涵符号（→）联结形成的谓词公式表示规则性知识。下面是用谓词公式表示知识的步骤。定义谓词及个体，确定每个谓词及个体的确切含义。根据所要表达的事物或概念，为每个谓词中的变元赋特定的值。根据所要表达知识的语义，用适当的联结符将各个谓词联结起来，形成谓词公式。

### 【例 2.2】 用谓词逻辑表示下列知识。

武汉是一个美丽的城市，但她不是一个沿海城市。

如果马亮是男孩，张红是女孩，则马亮比张红长得高。

解 对于上述知识，可按以下 3 步进行分析。

- 第 1 步，定义谓词。
- BCity(x): x 是一个美丽的城市。
- HCity(x): x 是一个沿海城市。
- Boy(x): x 是男孩。
- Girl(x): x 是女孩。
- High(x,y): x 比 y 长得高。

第 2 步，将个体代入谓词中，得到 BCity(wuhan)、HCity(wuhan)、Boy(mal)、Girl(zhangh)、High(mal, zhangh)。

第 3 步，根据语义，用逻辑联结符连接。
BCity(wuhan) ∧ ¬HCity(wuhan)
[Boy(mal) ∧ Girl(zhangh)] → High(mal,zhangh)

### 【例 2.3】 用谓词公式表示下列知识。

- 自然数是大于零的整数。
- 所有整数不是偶数就是奇数。
- 偶数除以 2 是整数。

解 对于上述知识，可先定义谓词，再用谓词公式进行知识表示，具体如下。

- 1) 定义谓词。
- N(x)：x 是自然数。
- I(x)：x 是整数。
- E(x)：x 是偶数。
- O(x)：x 是奇数。
- GZ(x)：x 大于零。
- S(x)：x 除以 2。

- 2) 用谓词公式进行知识表示。
- (∀x)(N(x) → GZ(x) ∧ I(x))：自然数是大于零的整数。
- (∀x)(I(x) → E(x) ∧ O(x))：所有整数不是偶数就是奇数。
- (∀x)(E(x) → I(S(x)))：偶数除以 2 是整数。

## 2.2.3 一阶谓词逻辑表示法的特点

一阶谓词逻辑表示法具有如下优点。

- 1) 严密性：可以保证其演绎推理结果的正确性，可以比较精确地表示知识。
- 2) 自然性：它的表达方式与人类自然语言非常接近。谓词逻辑是一种接近自然语言的形式语言，用其表示问题易于被人们理解和接受。
- 3) 通用性：拥有通用的逻辑演算方法和推理规则。
- 4) 知识易于表达：对逻辑的某些外延进行扩展后，可以把大部分精确性的知识表示成一阶谓词逻辑的形式。
- 5) 易于实现：用它表示的知识易于模块化，便于知识的增加、删除及修改，便于在计算机上实现。

一阶谓词逻辑表示法具有如下缺点。

- 1) 效率低：推理过程冗长，降低了系统效率。谓词表示越详细，表达越清楚，推理越慢，效率越低。
- 2) 灵活性差：不便于表示与加入启发性知识和元知识，不便于表示不确定性的知识。
- 3) 组合爆炸：在其推理过程中，随着事实数目的增大及盲目地使用推理规则，有可能产生组合爆炸。

尽管谓词逻辑表示法有以上一些局限性，但它仍是一种重要的知识表示方法。

## 2.3 产生式表示法

“产生式”一词首先是由美国数学家波斯特（Post）提出来的。波斯特根据替换规则提出了一种称为波斯特机的计算模型，该模型中的每一条规则当时被称为一个产生式。后来这一术语几经修改扩充，被应用到许多领域。

### 2.3.1 产生式的基本形式

产生式通常用于表示具有因果关系的知识，其基本形式为

```
P→Q 或 IF P THEN Q
```

式中，P 为产生式的前提或条件，用于指出该产生式是否是可用的条件；Q 为一组结论或动作，用于指出该产生式的前提条件 P 被满足时，应该得出的结论或应该执行的操作。
P 和 Q 都可以是一个或一组数学表达式或自然语言。

其实，蕴涵式只是产生式的一个特殊情况，因为蕴涵式只能表示精确性知识，其逻辑值要么为真，要么为假；而产生式不仅可以表示精确性知识，还可以表示不精确知识。另外，在用产生式表示知识的智能系统中，决定一条知识是否可用的方法是检查当前是否有已知事实与知识中的前提条件相匹配，这种匹配可以是精确匹配，也可以是不精确匹配，只要按照某种算法求出前提条件与已知事实的相似度达到某个指定的范围，就认为是可匹配的；但在谓词逻辑中，蕴涵式前提条件的匹配总是要求精确匹配。产生式与蕴涵式的另一个区别是：蕴涵式本身是一个谓词公式，它有真值；而产生式则没有真值。

产生式表示法可以很容易地描述事实及规则，有以下两种表示方式。

- (1) 确定性和不确定性规则知识的产生式表示

  确定性规则知识可用前面介绍的产生式的基本形式表示。不确定性规则知识可用如下形式表示：

  ```
  P→Q（可信度）或者 IF P THEN Q（可信度）
  ```

  式中，P 为产生式的前提条件，用于指出该产生式是否是可用的条件；Q 为一组结论或动作，用于指出该产生式的前提条件 P 被满足时，应该得出的结论或应该执行的操作；可信度为根据经验对某事物和现象为真的相信程度，用于指出前提条件与结论的联系强度，取值范围为[-1,1]。

- (2) 确定性和不确定性事实性知识的产生式表示

  确定性事实性知识一般使用三元组的形式表示：（对象，属性，值）或（关系，对象 1，对象 2），如(Lee, Age, 35)(Friend, Lee, Zhang)。

  不确定性事实性知识一般用四元组的形式表示：（对象，属性，值，不确定度量值）或（关系，对象 1，对象 2，不确定度量值），如(Lee, Age, 35, 0.9)(Friend, Lee, Zhang, 0.2)。

### 2.3.2 产生式系统

一组产生式在一起互相配合，协同作用，一个产生式生成的结论可以作为另一个产生式的前提，从而解决问题，这样的系统为产生式系统。产生式系统最初并不是针对人工智能问题提出的。在研究人工智能问题时，人们发现产生式系统可以比较好地模拟人类推理的思维过程，因此在建造人工智能系统时，将产生式系统引入进来，用于建立人类认知的模型。产生式系统形式上虽然很简单，但在一定意义上模仿了人类思考的过程。最初的专家系统就建立在产生式系统这种结构之上，后来的专家系统虽然有了很大的发展，但其基本模式仍然没有改变。一般来说，一个产生式系统的基本结构包括 3 个部分：综合数据库、规则库和控制系统，如图 2.2 所示。

#### 1. 综合数据库

这里的综合数据库只是借用了“数据库”这样一个名词，与通常所说的数据库概念并不一致。综合数据库是一个数据的集合，用于存放在推理过程中的已知条件、推导出的中间结果和最终结论等。一组产生式规则（规则集）相当于系统的知识库，它采用“IF<前件>THEN<后件>”的形式来表达求解问题所需要的知识。其中，规则的<前件>表示的是该条规则所要满足的条件，规则的<后件>表示的是该规则所得出的结论或动作。

综合数据库是人工智能产生式系统所使用的主要数据结构，用来表述问题状态或有关事实，即它含有所求解问题的信息，其中有些部分可以是不变的，有些部分则可能只与当前问题的解有关。人们可以根据问题的性质，用适当的方法构造综合数据库的信息。

#### 2. 规则库

表达的规则可以是与待求解问题有关的客观规律方面的知识，也可以是对求解问题有帮助的策略方面的知识。以中国象棋为例，前者描述的是象棋的走棋规则，如“马走日”“象走田”等，这是系统所必须表达出来的知识；而后者描述的则是在什么情况下，应该如何走棋才能战胜对手，或者什么样的局面比较有利、什么样的局面不利等。这方面的知识与搜索结合在一起，决定了系统下棋的水平。

产生式规则的一般形式为“条件→行动”或“前提→结论”，即表示成“IF···THEN···”的形式。其中，左半部分确定了该规则可应用的先决条件，右半部分描述了应用这条规则所采取的行动或得出的结论。一条产生式规则满足了应用的先决条件之后，就可对综合数据库进行操作，使其发生变化。例如，综合数据库代表当前状态，则应用规则后就使状态发生转换，生成新状态。

#### 3. 控制系统

控制系统又称为控制策略（control strategies）或者搜索策略，用于控制系统的运行，它根据综合数据库中的当前数据选择合适的规则。不同的选择规则的方法，就构成了不同的控制策略。因此，控制系统也可以称为推理引擎。

控制系统是规则的解释程序，规定了如何选择一条可应用的规则对综合数据库进行操作，即决定了问题求解过程的推理路线。当综合数据库满足结束条件时，系统就应停止运行；还要使系统在求解过程中记住应用过的规则序列，以便最终能给出解的路径。控制系统也称为推理机构，由一组程序组成，用来控制整个产生式系统的运行，决定问题求解的推理线路，实现问题求解。从总体来说，控制系统主要做如下一些工作。

- 1) 按照一定的策略从规则库中选择规则，并与综合数据库中的已知事实进行匹配。匹配就是指把规则的前提条件与综合数据库中的已知事实进行比较，如果二者一致，或者近似一致，则称匹配成功，该规则可使用；否则，称匹配不成功，相应规则不可用于当前的推理。
- 2) 如果匹配成功的规则不止一条，则称为发生了冲突，此时的推理机构必须采取某种协调策略来解决这种冲突，从而选取其中一条规则去执行，称之为冲突消解。
- 3) 如果所执行的规则<后件>不是问题目标，则当<后件>为结论时，将结论添加到综合数据库中；如果是操作，则执行该操作。
- 4) 对于不确定性知识，在执行每条规则时还需要计算结论的不确定性。
- 5) 如果规则的<后件>满足问题求解的结束条件，则停止系统的推理运行。

### 2.3.3 产生式系统推理

产生式系统推理的方式有正向推理、反向推理和双向推理 3 种。

#### 1. 正向推理

正向推理即从已知事实出发，通过规则求得结论。正向推理也称数据驱动方式或自底向上的方式。正向推理的过程如下。

- 1) 规则集中的规则与数据库中的事实进行匹配，得到匹配的规则集合。
- 2) 使用冲突解决算法，从匹配规则集合中选择一条规则作为启用规则。
- 3) 执行启用规则的<后件>，将该启用规则的<后件>送入数据库。
- 4) 重复上述过程，直至达到目标。

在推理过程中，由于可能有多条规则同时与事实匹配，选择哪条规则将影响求解效率，因此经常会得到与目标无直接关系的推论。

#### 2. 反向推理

从目标（作为假设）出发，反向使用规则，求得已知事实。这种推理方式也称目标驱动方式或自顶向下的方式。反向推理的过程如下。

- 1) 规则库中的规则<后件>与目标事实进行匹配，得到匹配的规则集合。
- 2) 使用冲突解决算法，从匹配规则集合中选择一条规则作为启用规则。
- 3) 将启用规则的<前件>作为子目标。
- 4) 重复上述过程，直至各子目标均为已知事实则成功结束。

在反向推理中，如果目标明确，则效率会比正向推理高得多。

#### 3. 双向推理

双向推理是一种既自顶向下、又自底向上的推理方式，推理从两个方向同时进行，直至在某个中间界面上两方向结果相符便成功结束。这种双向推理较正向或反向推理所形成的推理网络更小，从而有更高的推理效率。

### 【例 2.4】动物识别系统。该系统可以识别老虎、金钱豹、斑马、长颈鹿、企鹅、信天翁这 6 种动物，其规则库包含如下 15 条规则。

- r1: IF 该动物有毛发 THEN 该动物是哺乳动物
- r2: IF 该动物有奶 THEN 该动物是哺乳动物
- r3: IF 该动物有羽毛 THEN 该动物是鸟

- r5: IF 该动物吃肉 THEN 该动物是食肉动物
- r6: IF 该动物有犬齿 AND 有爪 AND 眼睛前方 THEN 该动物是食肉动物
- r7: IF 该动物是哺乳动物 AND 有蹄 THEN 该动物是有蹄类动物
- r8: IF 该动物是哺乳动物 AND 是反刍动物 THEN 该动物是有蹄类动物
- r9: IF 该动物是哺乳动物 AND 是食肉动物 AND 是黄褐色 AND 身上有暗斑点 THEN 该动物是金钱豹
- r10: IF 该动物是哺乳动物 AND 是食肉动物 AND 是黄褐色 AND 身上有黑色条纹 THEN 该动物是虎
- r11: IF 该动物是有蹄类动物 AND 有长脖子 AND 有长腿 AND 身上有暗斑点 THEN 该动物是长颈鹿
- r12: IF 该动物是有蹄类动物 AND 身上有黑色条纹 THEN 该动物是斑马
- r13: IF 该动物是鸟 AND 有长脖子 AND 有长腿 AND 不会飞 AND 有黑白二色 THEN 该动物是鸵鸟

```
r15: IF（动物，类别，鸟）AND（动物，本领，善飞）THEN（动物，名称，信天翁）
```

## 2.3.4 产生式表示法评价

产生式表示格式固定，形式单一，规则（知识单位）间相互较为独立，没有直接关系使知识库的建立较为容易，处理较为简单的问题是可取的。另外，推理方式单纯，也没有复杂计算。特别是知识库与推理机是分离的，这种结构给知识的修改带来了方便，无须修改程序，对系统的推理路径也容易做出解释。所以，产生式表示知识常作为构造专家系统第一选择的知识表示方法。

产生式表示法有数据驱动和独立性两大特点。数据驱动指的是系统是在数据的驱动下运行的，数据一旦发生变化，如增加数据、删除数据等，就会导致系统行为发生变化；而一旦数据不再发生变化，系统的运行也就停止了。独立性包含两方面的含义，其一是数据（综合数据库）、知识（规则集）和控制（控制系统）三者之间是相互独立的，而不是混杂在一起的；其二是规则之间是相互独立的，不同的规则之间没有明显的连接关系，规则之间是通过数据联系在一起的，这样可以便于规则集的维护，一条规则的修改或者增加，不需要考虑其与哪些规则相关联。由于规则之间是相互独立的，因此一般来说，问题的求解与规则的排列顺序无关。

另外，产生式表示法适合于模拟强数据驱动特点的智能行为，当有新的数据输入时，系统的行为就要改变。产生式表示法也易于添加新规则去适应新的情况，而不会破坏系统的其他部分，这是由于产生式系统的各组成部分具有相对独立性，因而便于扩展和修改。

产生式表示法具有以下优点。

- 1）自然性：由于产生式系统采用了人类常用的表达因果关系的知识表示形式，因此既直观、自然，又便于进行推理。
- 2）模块性：产生式规则是规则库中最基本的知识单元，形式相同，易于模块化管理。
- 3）有效性：能表示确定性知识、不确定性知识、启发性知识、过程性知识等。
- 4）清晰性：产生式有固定格式，既便于规则设计，又易于对规则库中的知识进行一致性、完整性检测。

产生式表示法具有以下缺点。

- 1）效率不高：产生式系统求解问题的过程是一个反复进行“匹配—冲突消解—执行”的过程。由于规则库一般比较庞大，而匹配又是一件十分费时的工作，因此其工作效率不高。此外，产生式表示法在求解复杂问题时容易引起组合爆炸。
- 2）不能表达具有结构性的知识：产生式系统对具有结构关系的知识无能为力，它不能把具有结构关系的事物间的区别与联系表示出来，因此人们经常将其与其他知识表示方法（如框架表示法、语义网络表示法）结合起来使用。

## 2.4 框架表示法

心理学研究结果表明，在人类日常思维和理解活动中，当分析和解释遇到新情况时，会使用过去积累的知识，这些知识规模巨大而且以很好的组织形式保留在人们的记忆中。例如，当走进一家从来没有来过的饭店时，根据以往的经验，可以预见在这家饭店将会看到菜单、桌子、服务员等；当走进教室时，可以预见在教室里可以看到椅子、黑板等。当然，人们无法把过去的经验全部存放在脑子里，而只能以一个通用的数据结构的形式存储以往的经验。这样的数据结构称为框架。框架提供了一个结构，一种组织。在这个结构或组织中，新的资料可以用从过去的经验中得到的概念来分析和解释。因此，框架是一种结构化表示法。
