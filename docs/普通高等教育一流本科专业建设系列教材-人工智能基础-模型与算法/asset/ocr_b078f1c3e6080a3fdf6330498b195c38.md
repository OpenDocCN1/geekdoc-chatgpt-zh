# (4) 时间关系

时间关系是指不同事件在其发生时间方面的先后次序关系。常用的时间关系有 Before、After 等。

![](bbox=[0.11, 0.31, 0.4, 0.355])

Before 的含义为“在前”，表示一个事件在另一个事件之前发生；After 的含义为“在后”，表示一个事件在另一个事件之后发生。例如，“北京奥运会在悉尼奥运会之后”的关系表示如图 2.14 所示。

# (5) 位置关系

位置关系是指不同事物在位置方面的关系。常用的位置关系如下：Located-on 的含义为“在上”，表示某一物体在另一物体之上；Located-at 的含义为“在”，表示某一物体所在的位置；Located-under 的含义为“在下”，表示某一物体在另一物体之下；Located-inside 的含义为“在内”，表示某一物体在另一物体之内；Located-outside 的含义为“在外”，表示某一物体在另一物体之外。例如，“纸在桌子上”的关系表示如图 2.15 所示。
