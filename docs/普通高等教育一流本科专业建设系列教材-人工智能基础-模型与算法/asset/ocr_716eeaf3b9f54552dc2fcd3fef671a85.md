# 图 6.20 模拟退火算法的简要流程

第 5 步，判读 f(j) 是否小于 f(i)，若是则跳转到第 8 步，否则跳转到第 6 步。
第 6 步，计算接受概率 P(tk) = e^[-(f(j)-f(i))/tk] 。
第 7 步，判断 random(0,1) < P(tk) 是否成立，若是则跳转到第 8 步，否则跳转到第 3 步。
第 8 步，i = j, f(i) = f(j)，更新 s，跳转到第 3 步。
其中，函数 f(x) 用于计算解的适应度， random(0,1) 是指在 [0,1] 区间上按照均匀分布方式产生一个随机数。

# 本章小结

本章介绍了计算智能的发展历程，以及进化计算、模糊计算、单点搜索 3 类智能算法，神经计算将在第 7 章中详细介绍。
进化算法是借鉴自然界中的生物获得启发设计出的算法，本章介绍了遗传算法，以及几种主要的改进算法，这些算法在实践中具有广泛应用。遗传算法以一个种群中的所有个体为对象，进行染色体的复制、交叉和变异，并利用随机化技术进行指导，对一个被编码的参数空间进行高效搜索。蚁群算法模拟蚂蚁觅食过程，通过在爬过的路径中释放信息素，帮助后来的蚂蚁选择更优的路线。免疫算法可以用于一般的优化问题，假设抗原是目标函数，抗体是最优解（有若干个），算法将通过抗体和抗体、抗原和抗体之间的亲和度来控制新陈代谢的过程，以实现函数的优化功能。分布估计算法是一种基于种群的随机优化算法，它在初始种群的基础上，通过建立概率模型和采样等操作使种群得到不断的进化，直到达到结束条件。粒子群优化算法是通过模拟鸟群觅食过程中的迁徙和群聚行为而提出的一种基于群体智能的全局随机搜索算法，通过群体中个体之间的相互合作来实现全局寻优。进化规划是一种模仿自然进化原理以求解参数优化问题的算法，强调自然进化中种群体级行为变化，适用于解决目标函数或约束条件不可微的复杂非线性实值连续优化问题。进化策略是一种模仿生物进化原理求解参数优化问题的方法。
单点搜索算法包括禁忌搜索算法和模拟退火算法。禁忌搜索算法模仿了人类的记忆功能，把禁忌技术放到问题求解的过程中，对已经搜索过的局部最优解进行标记，在迭代搜索时避免重复遍历相同的搜索，从而扩大搜索范围，进一步逼近全局最优解。模拟退火算法则是模拟固体能量的变化，如果变化是朝着减少系统能量的方向进行的，那么就接受该变化，否则以一定的概率接受这种变化。不断重复上述操作，直到温度降低到某个阈值，这时将得到的解作为输出的最终解，即固体能量的最低状态。
