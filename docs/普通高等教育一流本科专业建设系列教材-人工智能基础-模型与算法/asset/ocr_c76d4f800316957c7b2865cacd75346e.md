$$
\overline{B} = \frac{0.5}{x_1} + \frac{0}{x_2} + \frac{0.2}{x_3} + \frac{1}{x_4}

$$

# (4) 模糊集合的代数运算

设 \( A, B \) 为论域中的两个模糊集合，\( \mu_A(x), \mu_B(x) \) 为对应的隶属函数。

+   1) 代数积: \(\mu_{A \cdot B}(x) = \mu_A(x) \mu_B(x) \quad (5.75)\)

+   2) 代数和: \(\mu_{A+B}(x) = \mu_A(x) + \mu_B(x) - \mu_{A \cdot B}(x) \quad (5.76)\)

+   3) 有界和: \(\mu_{A \oplus B}(x) = \min \{1, \mu_A(x) + \mu_B(x)\} = 1 \wedge [\mu_A(x) + \mu_B(x)] \quad (5.77)\)

+   4) 有界积: \(\mu_{A \otimes B}(x) = \max \{0, \mu_A(x) + \mu_B(x) - 1\} = 0 \vee [\mu_A(x) + \mu_B(x) - 1] \quad (5.78)\)
