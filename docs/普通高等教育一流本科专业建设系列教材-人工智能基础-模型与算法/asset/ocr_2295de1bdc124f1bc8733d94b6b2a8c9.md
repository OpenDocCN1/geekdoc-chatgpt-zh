可以采用搜索方法求解博弈问题，下面介绍博弈最基本的两种搜索方法。

# 3.8.1 极大极小过程

极大极小（MINMAX，MM）过程是考虑双方博弈若干步后，从可能的走法中选一步相对好的走法来走，即在有限的搜索深度范围内进行求解。

为此需要定义一个静态估价函数 _e_(_x_)，以便对棋局的态势做出评估。该函数可以根据棋局的态势特征进行定义。假定博弈双方分别为 MAX 和 MIN，其中 _p_ 代表棋局。规定：有利于 MAX 方的态势，_e_(_p_)取正值；有利于 MIN 方的态势，_e_(_p_)取负值；态势均衡时，_e_(_p_)取零值。

MM 基本思想如下。

+   1）当轮到 MAX 走步时，MAX 应考虑最好的情况（_e_(_p_)取极大值）。

+   2）当轮到 MIN 走步时，MIN 应考虑最坏的情况（_e_(_p_)取极小值）。

+   3）评价往回倒推时，相当于两位棋手的对抗策略，交替使用 1）和 2）两种方法传递倒推值，直至求出初始节点的倒推值为止。

由于我方站在 MAX 立场上，因此应选择具有最大倒推值的走步。这一过程称为极大极小过程。
