的论式是三段论。三段论是一个结论必然从另外两个前提中得出的一种推论，由大前提、小前提和结论 3 部分组成。逻辑上，结论是在于小前提之上应用大前提得到的。大前提是指已知的一般性原则；小前提是指所研究的具体情况或个别事实的特殊陈述；结论是根据一般原理，对具体情况或个别事实做出的判断。例如，例 4.1 列举了几个三段论的例子。

【例 4.1】人们在生活中经常无意识地使用三段论法，如表 4.1 中的例子。

# 表 4.1 三段论法举例

| 大前提 | 小前提 | 结论 |
|---|---|---|
| 所有 P 是 M | 有 S 不是 M | 有 S 不是 P |
| 所有推理系统都是智能系统 | 专家系统是推理系统 | 专家系统是智能系统 |
| 有些书是有插图的 | 有些有插图的书是有趣的 | 有些书是有趣的 |
| 奇数都不能被 2 整除 | 3 是奇数 | 3 不能被 2 整除 |

在三段论式的演绎推理中，只要大前提和小前提是正确的，则由它们推出的结论也必然是正确的。

可以看出，在演绎推理中，结论是蕴涵在大前提中的，即从已知判断中推出其中包含的判断，所以演绎推理并没有增加新的知识。

# (2) 归纳推理

人们对客观事物的认识总是从认识个别事物开始，进而认识事物的普遍规律，其中归纳推理起了重要的作用。归纳推理有时也称归纳逻辑，是从个别认识一般，从少数现象概括事物普遍规律的推理方法。它基于对特殊对象的有限观察，把性质或关系归结到类型；或基于对反复再现的现象的有限观察，运用公式表达规律。归纳所得的结论是尚属未知的一般现象，该结论超越了少数现象所包容的范围。所以，相对于演绎推理，归纳推理达成的结论并非必然与最初的假定有相同的确定程度，即结论是或然性的，当前提为真时，结论不是必然为真。

常用的归纳推理方法有类比法和枚举法。类比推理是根据两个或两类事物在某些属性上相同，推断它们在其他属性上也相同的一种推理。从相同属性的量上来考察，类比推理中，前提确认的对象间相同属性越多，那么结论的可靠性程度也就越大；从相同属性的质上来考察，前提中确认的相同属性与类推的属性之间相关程度越高，那么结论的可靠性程度也就越大。其逻辑结构表达式为

```
A 事物具有属性 a、b、c、d;
B 事物具有属性 a、b、c;
所以，B 事物也可能具有属性 d。
```

根据考察对象范围的不同，归纳推理可以分为完全归纳推理和不完全归纳推理。

+   1）完全归纳推理。

完全归纳推理是根据某类事物的每个对象是否都具有（或不具有）某种属性，从而推出该类事物全体都具有（或不具有）这种属性的推理。完全归纳推理考察了某类事物的全部对象获得关于该类事物的一般性结论。完全归纳推理的前提蕴涵了结论，如果它的前提真实，那么所得到的结论必然真实，属于必然性推理。其逻辑结构表达式为

```
S1 是 P
S2 是 P
```
