1）基本位变异：对个体编码串中以变异概率、随机指定的某一位或某几位基因上的值进行变异运算。

2）均匀变异：分别用符合某一范围内均匀分布的随机数，以某一较小的概率替换个体编码串中各个基因座上的原有基因值（特别适用于算法的初级运行阶段）。

3）边界变异：随机选取基因座上的两个对应边界基因值之一替代原有基因值（特别适用于最优点位于或接近于可行解的边界时的一类问题）。

4）非均匀变异：对原有的基因值做一随机扰动，以扰动后的结果作为变异后的新基因值。对每个基因座都以相同的概率进行变异运算之后，相当于整个解向量在解空间中做了一次轻微的变动。

5）高斯近似变异：进行变异操作时用符号均值为 P 的平均值，方差为 P² 的正态分布的一个随机数替换原有的基因值。

# 3. 遗传算法的改进

尽管遗传算法有许多优点，也有许多专家学者对遗传算法不断进行研究，但目前其存在的问题依然很多，如适应度值标定方式多种多样，没有一个简洁、通用的方法，不利于对遗传算法的使用；遗传算法的早熟现象，即很快收敛到局部最优解而不是全局最优解，这是迄今为止最难处理的关键问题；快要接近最优解时在最优解附近左右摆动，收敛较慢。

为了解决上述问题，学者们提出了多种改进的方法。

# (1) 算子选择

种群的选择在遗传算法中起到了非常重要的作用。在自然界中，“物竞天择”保留下来的物种决定了生物的进化程度。同样地，选择的效率如何是留存的染色体是否能进化成为最优染色体的重要影响因素，对遗传算法的稳定性具有决定作用。

经典的轮盘赌选择算子的思想简单，易于理解和实现。选择过程中，较优染色体被选中的概率更大，但性能较差的染色体也具有一定的生存空间。因此，人们倾向于使用轮盘赌选择算子，但这种方法并不是一种完美的方法，它随机选择的特性会导致选择误差较大，甚至可能选不上适应值较高的染色体。选择算法一直是改进遗传算法研究的重要内容之一，各种不同的选择算法和模型相继推出，比较常用的是排序方法（rank-based model）和随机锦标赛模型（stochastic tournament model）。

+   1）排序方法。如图 6.6 所示，排序方法是在计算每个个体的适应度后，根据适应度大小顺序对群体中的个体进行排序，然后把事先设计好的概率按照排序分配给个体，这个概率就是个体被选择到的概率。在排序方法中，选择概率仅取决于个体在种群中的位序，而不是适应度值。因此，当适应度值相同时，排在前面的个体有更大的概率被选中。

排序方法的优点包括其克服了轮盘赌策略过早收敛和停滞现象，而且对于极大值和极小值问题不需要进行适应值的标准化和调节，可以直接使用原始适应值进行排名选择。排序方法比轮盘赌方法具有更好的鲁棒性，能在一定程度上克服比例适应度计算的尺度问题和过早收敛问题。

+   2）随机锦标赛模型。随机锦标赛模型是从群体中随机选择一对个体，将其中适应度最高的个体保存到下一代。这一过程反复执行，直到保存到下一代的个体数量达到预先设置的数量为止。
