\( CF_{1,2}(H) = \begin{cases} CF_1(H) + CF_2(H) - CF_1(H)CF_2(H), & CF_1(H) \geqslant 0, CF_2(H) \geqslant 0 \\ CF_1(H) + CF_2(H) - CF_1(H)CF_2(H), & CF_1(H) < 0, CF_2(H) < 0 \\ \frac{CF_1(H) + CF_2(H)}{1 - \min \{|CF_1(H)|, |CF_2(H)|\}}, & CF_1(H)CF_2(H) < 0 \end{cases} \) (5.52)

# 6. 带有阈值限度的可信度方法

C-F 模型在人工智能的发展史上占有重要地位，为基于可信度表示的不确定性推理奠定了基础。但是，现实世界中的问题是复杂多样的，任何一种方法都有其局限性，只适用于特定的情况和范围。为了用可信度方法求解更多的问题，人们在 C-F 模型的基础上又提出了一些更具有一般性的处理方法，如带有阈值限度的可信度方法。

带有阈值限度的可信度方法是在 C-F 模型上添加阈值限度 \(\lambda\)，用于限制不合要求的证据和对应的知识运用。

在带有阈值限度的不确定性推理中，知识用下述公式表示：
IF E THEN H [CF(H, E), \(\lambda\)]

式中，E 为知识的前提条件：H 为结论。

与 C-F 模型一样，这里前提和结论都可以是一个原子命题或复合命题。CF(H, E) 是规则的可信度，即规则强度，它指出相应知识为真的可信程度，取值范围为 (0,1]。其他越大，表示相应知识的可信度越高。\(\lambda\) 是阈值，它为相应知识的可应用性规定了一个限度，只有当前提条件 E 的可信度 CF(E) \(\geqslant \lambda\) 时，相应的知识才有可能被应用。\(\lambda\) 的取值范围为 (0,1]。

证据的不确定性仍然用可信度因子表示，即证据 E 的不确定性表示为 CF(E)，取值范围为 [0,1]。当 CF(E) = 0 时，表示该证据可信度无法得知。CF(E) 的值越大，表示可信度越高。对于初始证据，其值由用户给出；对于使用之前的推理结论作为当前推理前提的证据，其值由推理得到。

组合证据不确定性的算法与 C-F 模型类似。

当 CF(E) \(\geqslant \lambda\) 时，该条知识被激活，其不确定性的传递算法也与 C-F 模型类似。

结论不确定性的合成算法与 C-F 模型相似，分两步完成。首先分别对每条知识求出它的 CF\(_i\)(H) (i = 1, 2, \(\cdots\), n)，即 CF\(_i\)(H) = CF(H, E\(_i\)) \(\times\) CF(E\(_i\))

然后用以下方法中的任一种求出合成可信度 CF(H)。

+   1) 求极大值法：
+   CF(H) = \max \{ CF_1(H), CF_2(H), \cdots, CF_n(H) \} (5.53)

+   2) 加权求和法：
+   CF(H) = \frac{1}{\sum_{i=1}^{n} CF(H, E_i)} \sum_{i=1}^{n} CF(H, E_i) \times CF(E_i) (5.54)

+   3) 有限和法：
+   CF(H) = \min \{ \sum_{i=1}^{n} CF_i(H), 1 \} (5.55)
