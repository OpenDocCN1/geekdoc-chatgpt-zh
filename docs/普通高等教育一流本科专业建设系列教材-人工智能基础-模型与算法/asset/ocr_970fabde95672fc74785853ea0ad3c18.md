式中，\(\mu_A(x)\) 为元素 \(x\) 属于模糊集 \(A\) 的隶属度；\(X\) 为元素 \(x\) 的论域。

# 1) Zadeh 表示法：

① 论域是离散的，且元素数目有限。模糊集合 \(A\) 表示为

\(A = \frac{\mu_A(x_1)}{x_1} + \frac{\mu_A(x_2)}{x_2} + \dots + \frac{\mu_A(x_n)}{x_n} = \sum_{i=1}^n \frac{\mu_A(x_i)}{x_i} \quad (5.67)\)

或

\(A = \left\{ \frac{\mu_A(x_1)}{x_1}, \frac{\mu_A(x_2)}{x_2}, \dots, \frac{\mu_A(x_n)}{x_n} \right\} \quad (5.68)\)

式中，\(x_i\) 为模糊集合所对应的论域中的元素；\(\mu_A(x_i)\) 为元素 \(x_i\) 的隶属度；“——”为分隔符，不代表分数；符号“+”和“\(\sum\)”为模糊集合在论域上的整体。

② 论域是连续的，或者元素数目无限。模糊集合 \(A\) 表示为

\(A = \int_{x \in U} \frac{\mu_A(x)}{x} \quad (5.69)\)

这里的符号“\(\int\)”不是积分的意思，只是表示论域中各元素与其对应隶属度的关系的一个总括，是一个记号。

# 2) 序偶表示法：

\(A = \{[\mu_A(x_1), x_1],[\mu_A(x_2), x_2], \dots, [\mu_A(x_n), x_n]\} \quad (5.70)\)

# 3) 向量表示法：

\(A = [\mu_A(x_1), \mu_A(x_2), \dots, \mu_A(x_n)] \quad (5.71)\)

在向量表示法中，因为默认模糊集合中的元素依次为 \(x_1, x_2, \dots, x_n\)，所以隶属度为 0 的项不能省略。

# (3) 隶属函数

构造模糊集合就是要确定合适的论域和指定适当的隶属函数。模糊集合中所有元素的隶属度构成模糊集合的隶属函数，隶属度的范围为[0, 1]，当某个属性的隶属度越高时，说明该变量越接近这个属性。

隶属函数的确定原则上来说应该是客观的，但每个人对于同一个模糊概念的认识理解有差异，因此隶属函数的确定又带有主观性。对于同一个模糊概念，不同的人会给出不完全相同的隶属函数，但只要能反映同一模糊概念，那么在解决和处理实际模糊问题时，仍然可以达到殊途同归的效果。毕竟，“模糊性”正是由主观认识的不同所造成的。

由于模糊性的存在，隶属函数的确定变得困难，人们通常使用以下几种隶属函数确定方法：模糊统计方法是一种客观方法，主要是在模糊统计试验的基础上根据隶属度的客观存在性来确定的；指派方法是一种主观方法，它主要依据人们的实践经验确定某些模糊集隶属函数；与指派方法类似的有专家经验法，主要依据专家的经验性知识确定隶属函数；加权平均法实质上是让更多的人共同参与与隶属函数的确定，首先每个参与人给出一个确定的结果，然后将求得的结果赋予一定的权值，最后求其平均值，即可得到该模糊集合的隶属函数；除此之外，还有二元对比排序法和基本概念扩充法等。
