# 3. 深度优先搜索的时间复杂度

如果搜索在 d 层最左边的位置找到了目标，则检查的节点数为 d + 1。另外，如果只是搜索到 d 层，在 d 层最右边的位置找到了目标，则检查的节点包括树中的所有节点，其数量为

1 + b + b^2 + ... + b^d = (b^{d+1} - 1) / (b - 1) (3.6)

所以，平均来说，检查的节点数量为

(b^{d+1} - 1) / [2(b - 1)] + (1 + d) / 2 \approx b(b^d + d) / [2(b - 1)] (3.7)

式（3.7）是深度优先搜索的平均时间复杂度，即深度优先搜索的时间复杂度是 b 的指数函数 O(b^d)。
