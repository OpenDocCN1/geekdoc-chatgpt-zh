## 7.4 BP 神经网络

反向传播学习算法简称 BP 算法，采用 BP 算法的前馈型神经网络简称 BP 网络。作为一种前馈型神经网络计算模型，BP 网络与多层感知器没有本质区别。然而，有了 BP 算法，BP 网络便有了强大的计算能力，可以表达各种复杂映射。BP 网络自出现以来一直是人工神经网络中最流行的模型，得到了极其广泛的应用。

### 7.4.1 BP 神经网络的结构

BP 神经网络是一个多层前馈型网络，其结构如图 7.9 所示。

设 BP 神经网络有 \(m\) 层，第一层为输入层，最后一层为输出层，中间各层为隐藏层。标“+1”的圆圈为偏置节点，没有其他单元连向偏置单元，偏置单元没有输入，它的输出总是 +1。输入层起缓冲存储器的作用，把数据源加到网络上，因此输入层神经元的输入与输出关系一般是线性函数。隐藏层中各个神经元的输入与输出关系一般为非线性函数。隐藏层 \(k\) 与输出层中各个神经元的非线性输入与输出关系记为 \(f_k (k=2,3,\cdots,m)\)。由第 \(k-1\) 层中第 \(j\) 个神经元到第 \(k\) 层的第 \(i\) 个神经元的连接权值为 \(w_{ij}^k\)。设第 \(k\) 层中第 \(i\) 个神经元输入的总和为 \(u_i^k\)，输出为 \(y_i^k\)，则各变量之间的关系为

$$y_i^k = f_k(u_i^k) \tag{7.58}$$

$$u_i^k = \sum_j w_{ij}^{k-1} y_j^{k-1}, \quad k = 2, 3, \cdots, m \tag{7.59}$$

![](img/01b3dd63f105ee2f61ade787bae553f5_227_0.png)

图 7.9 BP 神经网络的结构

当 BP 神经网络输入数据 \(X=[x_1, x_2, \cdots, x_{p_1}]^T\) （设输入层有 \(p_1\) 个神经元）时，从输入层依次经过各隐藏层节点，可得到输出数据 \(Y=[y_1^m, y_2^m, \cdots, y_{p_m}^m]^T\) （设输出层有 \(p_m\) 个神经元）。因此，可以把 BP 神经网络看成一个从输入到输出的非线性映射。

给定 \(N\) 组输入/输出样本为 \(\{X_{si}, Y_{si}\}(i=1, 2, \cdots, N)\)。如何调整 BP 神经网络的权值，使 BP 神经网络输入为样本 \(X_{si}\) 时，神经网络的输出为样本 \(Y_{si}\)？这就是 BP 神经网络的学习问题。可见，BP 神经网络学习算法是一种有监督学习的算法。

要解决 BP 神经网络的学习问题，关键是解决以下两个问题。

- 1) 是否存在一个 BP 神经网络，能够逼近给定的样本或函数？下述定理可以回答这个问题。

定理 7.3 柯尔莫哥洛夫叠加定理（Kolmogorov superposition theorem，KST）：给定任意 \(\varepsilon > 0\)，对于任意的连续函数 \(f\)，存在一个三层 BP 神经网络，其输入层有 \(p_1\) 个神经元，中间层有 \(2p_1 + 1\) 个神经元，输出层有 \(p_m\) 个神经元，它可以在任意 \(\varepsilon\) 平方误差精度内逼近 \(f\)。

上述定理不仅证明了映射网络的存在，而且说明了映射网络的结构。也就是说，总存在一个结构为 \(p_1 \times (2p_1 + 1) \times p_m\) 的三层前向神经网络，能够精确地逼近任意的连续函数 \(f\)。但对多层 BP 神经网络，如何合理地选取 BP 网络的隐藏层数及隐藏层的节点数，目前尚无有效的理论和方法。

- 2) 如何调整 BP 神经网络的权值，使 BP 神经网络的输入与输出之间的关系与给定的样本相同？BP 学习算法给出了具体的调整算法。

### 7.4.2 BP 学习算法

BP 学习算法最早由韦伯斯在 1974 年提出。鲁梅尔哈特于 1985 年发展了 BP 学习算法，实现了明斯基多层感知器的设想。

BP 学习算法是通过反向学习过程使误差最小，因此选择目标函数为

$$\min J = \frac{1}{2} \sum_{j=1}^{P_m} (y_j^m - y_{sj})^2 \tag{7.60}$$

即选择神经网络权值，使期望输出 \(y_{sj}\) 与神经网络实际输出 \(y_j^m\) 之差的平方和最小。

这种学习算法实际上是求目标函数 \(J\) 的极小值，约束条件是式 (7.59)，可以利用非线性规划中的“最快下降法”，使权值沿目标函数的负阶梯方向改变。因此，神经网络权值的修正量为

$$\Delta w_{ij}^{k-1} = -\varepsilon \frac{\partial J}{\partial w_{ij}^{k-1}}, \quad \varepsilon > 0 \tag{7.61}$$

式中，\(\varepsilon\) 为学习步长，一般小于 0.5。

下面推导 BP 学习算法。先求 \(\frac{\partial J}{\partial w_{ij}^{k-1}}\)，过程如下：

$$\frac{\partial J}{\partial w_{ij}^{k-1}} = \frac{\partial J}{\partial u_i^k} \frac{\partial u_i^k}{\partial w_{ij}^{k-1}} = \frac{\partial J}{\partial u_i^k} \frac{\partial}{\partial w_{ij}^{k-1}} \left( \sum_j w_{ij}^{k-1} y_j^{k-1} \right) = \frac{\partial J}{\partial u_i^k} y_j^{k-1} \tag{7.62}$$

记

$$d_i^k = \frac{\partial J}{\partial u_i^k}, \quad k=3,4,\cdots,m \tag{7.63}$$

则

$$\Delta w_{ij}^{k-1} = -\varepsilon d_i^k y_j^{k-1}, \quad k=2,3,\cdots,m \tag{7.64}$$

接下来推导计算 \(d_i^k\) 的公式：

$$d_i^k = \frac{\partial J}{\partial u_i^k} = \frac{\partial J}{\partial y_i^k} \frac{\partial y_i^k}{\partial u_i^k} = \frac{\partial J}{\partial y_i^k} f'_k(u_i^k) \tag{7.65}$$

下面分两种情况求 \(\frac{\partial J}{\partial y_i^k}\)。

1) 对输出层（第 \(m\) 层）的神经元，即 \(k=m, y_i^k = y_i^m\)，由误差定义式得

$$\frac{\partial J}{\partial y_i^k} = \frac{\partial J}{\partial y_i^m} = y_i^m - y_{si} \tag{7.66}$$

则

$$d_i^m = (y_i^m - y_{si}) f'_m(u_i^m) \tag{7.67}$$

2) 若 \(i\) 为隐单元层 \(k\)，则有

$$\frac{\partial J}{\partial y_i^k} = \sum_l \frac{\partial J}{\partial u_l^{k+1}} \frac{\partial u_l^{k+1}}{\partial y_i^k} = \sum_l d_l^{k+1} w_{li}^k \tag{7.68}$$

则

$$d_i^k = f'_k(u_i^k) \sum_l d_l^{k+1} w_{li}^k \tag{7.69}$$

综上所述，BP 学习算法可以归纳为

$$\Delta w_{ij}^{k-1} = -\varepsilon d_i^k y_j^{k-1} \tag{7.70a}$$
$$d_i^m = (y_i^m - y_{si}) f'_m(u_i^m) \tag{7.71a}$$
$$d_i^k = f'_k(u_i^k) \sum_l d_l^{k+1} w_{li}^k, \quad k=m-1, m-2, \cdots, 2 \tag{7.72a}$$

若取 \(f_k(\cdot)\) 为 S 形函数，即

$$y_i^k = f_k(u_i^k) = \frac{1}{1+e^{-u_i^k}} \tag{7.73}$$

则

$$\frac{\partial y_i^k}{\partial u_i^k} = f_k'(u_i^k) = \frac{e^{-u_i^k}}{[1+e^{-u_i^k}]^2} = y_i^k(1-y_i^k) \tag{7.74}$$

则 BP 学习算法可以归纳为

$$\Delta w_{ij}^{k-1} = -\varepsilon d_i^k y_j^{k-1} \tag{7.70b}$$
$$d_i^m = (y_i^m - y_{si}) f'_m(u_i^m) \tag{7.71b}$$
$$d_i^k = y_i^k(1-y_i^k) \sum_l d_l^{k+1} w_{li}^k, \quad k = m-1, m-2, \cdots, 2 \tag{7.72b}$$

从以上公式可以看出，求第 \(k\) 层的误差信号 \(d_i^k\)，需要上一层的 \(d_i^{k+1}\)。因此，误差函数的求取是一个始于输出层的反向传播的递归过程，所以称其为反向传播学习算法。通过多个样本的学习，修改权值，不断减少偏差，最后达到满意的结果。

### 7.4.3 BP 神经网络的应用

模式识别主要研究用计算机模拟生物、人的感知，对模式信息（如图像、文字、语音等）进行识别和分类。传统人工智能的研究部分显示了人脑的归纳、推理等智能，但是对于人类底层的智能，如视觉、听觉、触觉等，现代计算机系统的信息处理能力还较低。神经网络模型模拟了人脑神经系统的特点：处理单元的广泛连接，并行分布式信息存储、处理，自适应学习能力等，神经网络的研究为模式识别开辟了新的研究途径。与传统的模式识别方法相比，神经网络方法具有较强的容错能力、自适应学习能力和并行信息处理能力。BP 学习算法的程序框图如图 7.10 所示。

在 BP 算法实现时，还要注意下列问题。

- 1. 训练数据预处理

预处理过程包含一系列的线性的特征比例变换，将所有的特征变换到[0,1]或者[-1,1]区间内，使得在每个训练集上，每个特征的均值为 0，并且具有相同的方差。预处理过程也称为尺度变换（scaling）或者规格化（normalization）。

- 2. 后处理过程

当应用神经网络进行分类操作时，通常将输出值编码为名义变量，具体的值对应类别标号。在一个两类分类问题中，可以仅使用一个输出，将其编码成一个二值变量（如 +1 和 -1）。当具有更多的类别时，应当为每个类别分配一个代表类别决策的名义输出值。例如，对于一个三类分类问题，可以设置 3 个名义输出，每个名义输出取值为[+1,-1]，对应的各个类别决策为{+1,-1,-1}、{-1,+1,-1}、{-1,-1,+1}。利用阈值可以将神经网络的输出值变换成为合适的名义输出值。

- 3. 初始权值的影响及设置

与所有梯度下降算法一样，初始权值对 BP 神经网络的最终解有很大的影响。虽然将其全部设置为 0 更为自然，但从式（7.72）可以看出，这将导致很不理想的结果。如果输出层的权值全部为 0，则反向传播误差也将为 0，输出层前面的权值将不会改变。因此，一般以均值为 0 的随机分布设置 BP 神经网络的初始权值。

## 7.5 Hopfield 神经网络

从 20 世纪 60 年代初到 80 年代初，神经网络的研究处于“冰河期”；到了 80 年代中期，霍普菲尔德在神经网络建模及应用方面的开创性成果在世界范围内重新掀起了神经网络的研究热潮。1982 年和 1984 年，霍普菲尔德先后提出离散型 Hopfield 神经网络和连续型 Hopfield 神经网络，引入“计算能量函数”的概念，给出了网络稳定性判据，尤其是给出了 Hopfield 神经网络的电子电路实现，为神经计算机的研究奠定了基础；同时，开拓了神经网络用于联想记忆和优化计算的新途径，从而有力地推动了神经网络的研究。这两种模型是目前极为重要的神经优化计算模型。

### 7.5.1 离散型 Hopfield 神经网络

Hopfield 神经网络是全互连反馈神经网络，它的每一个神经元都与其他神经元相连接。具有 N 个神经元的离散型 Hopfield 神经网络可由一个 \(N \times N\) 矩阵 \(w = [w_{ij}]_{N \times N}\) 和一个 \(N\) 维行向量 \(\theta = [\theta_1, \theta_2, \cdots, \theta_N]^T\) 唯一确定，记为 HNN = (w, θ)。其中，\(w_{ij}\) 为从第 \(j\) 个神经元的输出到第 \(i\) 个神经元的输入之间的连接权值，表示神经元 \(i\) 与 \(j\) 的连接强度，且 \(w_{ji} = w_{ij}\)，\(w_{ii} = 0\)；\(\theta_i\) 为神经元 \(i\) 的阈值。若用 \(v_i(k)\) 表示 \(k\) 时刻神经元所处的状态，那么神经元 \(i\) 的状态随时间变化的规律（又称演化律）为

$$v_i(k+1) = \begin{cases} 1, & u_i(k) \geqslant 0 \\ 0, & u_i(k) < 0 \end{cases} \quad (7.75)$$

式（7.75）称为二值硬限器（binary hard limiters）或双极极限器，也可以表示如下：

$$v_i(k+1)=\begin{cases} 1, & u_i(k) \geqslant 0 \\ -1, & u_i(k) < 0 \end{cases} \quad (7.76)$$

式中，

$$u_i = \sum_{j=1, j \neq i}^N w_{ij} v_j(k) - \theta_i, \quad 1 \leqslant i \leqslant N \quad (7.77)$$

Hopfield 神经网络可以是同步工作方式，也可以是异步工作方式，即神经元的更新既可以同步（并行）进行，也可以异步（串行）进行。在同步进行时，神经网络中所有神经元的更新同时进行；在异步进行时，在同一时刻只有一个神经元更新，而且该神经元在网络中每个神经元都更新之前不会再次更新。在异步更新时，神经元的更新顺序可以是随机的。

Hopfield 神经网络中的神经元相互作用，不断演化。如果神经网络在演化过程中，从某一时刻开始，神经网络中所有神经元的状态不再改变，则称该神经网络是稳定的。

Hopfield 神经网络是高维非线性动力学系统，可能有若干个稳定状态。从任一初始状态开始运动，总可以达到某个稳定状态，这些稳定状态可以通过改变各个神经元之间的连接权值得到。也就是说，稳定性是 Hopfield 神经网络最重要的特性。下面对 Hopfield 神经网络的稳定性进行分析。

Hopfield 神经网络是一个多输入、多输出、带阈值的二态非线性动力学系统，所以类似于李雅普诺夫稳定性分析方法，在 Hopfield 神经网络中也可以构造一种李雅普诺夫函数（Lyapunov function），在满足一定的参数条件下，该函数值在网络运行过程中不断降低，最后趋于稳定的平衡状态。霍普菲尔德引入这种能量函数作为网络计算求解工具，称为计算能量函数。

离散型 Hopfield 神经网络的计算能量函数定义为

$$E = -\frac{1}{2} \sum_{i=1}^N \sum_{j=1, j \neq i}^N w_{ij} v_i v_j + \sum_{i=0}^N \theta_i v_i \tag{7.78}$$

式中，\(v_i\)、\(v_j\) 为各个神经元的输出。

下面考察第 \(m\) 个神经元的输出变化后前计算能量函数 \(E\) 值的变化。设 \(v_m = 0\) 时的计算能量函数值为 \(E_1\)，则有

$$E_1 = -\frac{1}{2} \sum_{i=1}^N \sum_{j=1, j \neq i}^N w_{ij} v_i v_j + \sum_{i=1}^N \theta_i v_i \tag{7.79}$$

将 \(i=m\) 项分出来，并注意到 \(v_m = 0\)。

$$E_1 = -\frac{1}{2} \sum_{i=1, i \neq m}^N \sum_{j=1, j \neq i}^N w_{ij} v_i v_j + \sum_{i=1, i \neq m}^N \theta_i v_i \tag{7.80}$$

类似地，当 \(v_m = 1\) 时的计算能量函数值为 \(E_2\)，则有

$$E_2 = -\frac{1}{2} \sum_{i=1, i \neq m}^N \sum_{j=1, j \neq i}^N w_{ij} v_i v_j + \sum_{i=1, i \neq m}^N \theta_i v_i - \sum_{j=1, j \neq m}^N w_{mj} v_j + \theta_m \tag{7.81}$$

当神经元状态由 0 变为 1 时，计算能量函数 \(E\) 值的变化量 \(\Delta E\) 为

$$\Delta E = E_2 - E_1 = -\left( \sum_{j=1, j \neq m}^N w_{mj} v_j - \theta_m \right) \tag{7.82}$$

由于此时神经元的输出由 0 变为 1，因此满足神经元兴奋条件，即
