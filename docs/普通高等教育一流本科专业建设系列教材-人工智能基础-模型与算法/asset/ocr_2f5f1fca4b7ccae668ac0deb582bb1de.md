# 1. VC 维与结构风险最小化

在理论上，支持向量机认为分类器对未知数据（测试数据）进行分类时所产生的期望风险（expected risk，真实风险）不是由经验风险单独决定的，而是由以下两部分组成：①从训练集合数据所得经验风险（如果经验风险小、期望风险很大，则是过学习）；②置信（confidence）风险，它与分类器的 VC（Vapnik Chervonenkis）维及训练样本数目有关。如果 \(0 \leqslant \eta \leqslant 1\)，则 VC 理论推导出的期望风险 \(\mathcal{R}\) 和经验风险 \(\mathcal{R}_{\text{emp}}\) 以 \(1-\eta\) 的概率满足如下关系：

```
\(\mathcal{R} \leqslant \mathcal{R}_{\text{emp}} + \sqrt{\frac{h \left[ \log \left( \frac{2n}{h} \right) + 1 \right] - \log \left( \frac{\eta}{4} \right)}{n}}\) (8.29)
```

式中，\(\sqrt{\frac{h \left[ \log \left( \frac{2n}{h} \right) + 1 \right] - \log \left( \frac{\eta}{4} \right)}{n}}\) 为 VC 置信值；\(n\) 为训练样本个数；\(h\) 为反映学习机复杂程度的 VC 维。

因为期望风险 \(\mathcal{R}\) 代表分类器对未知数据分类推广的能力，所以 \(\mathcal{R}\) 越小越好。在不等式（8.29）中，VC 置信值是 \(h\) 的增函数，\(\mathcal{R}_{\text{emp}}\) 是 \(h\) 的减函数，于是选择一个折中的 \(h\) 值可以使期望风险 \(\mathcal{R}\) 达到最小。支持向量机使用结构风险最小化准则来选取 VC 维 \(h\)，使每一类别数据之间的分类间隔（margin）最大，最终使期望风险 \(\mathcal{R}\) 最小。
