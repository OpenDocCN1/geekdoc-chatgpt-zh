# 5.3.2 训练实操：基于机器学习的文本情感分类和多语种文本拍照翻译应用

# 1. 使用微信公众号实现短文本情感分类

随着互联网技术的发展以及微博、Twitter 等社交网络应用的广泛普及，越来越多的人习惯在社交媒体上分享自己的心情和观点，每天都有海量在线数据更新。这些在线数据隐含着用户喜好、用户态度和用户价值观等信息。

情感分类（sentiment classification）是情感分析（sentiment analysis，SA）的主要研究内容，是指根据文本所表达的情感信息将文本划分成褒扬或贬义两种或几种类型，是对文本作者态度、观点和倾向性的划分。情感分类作为自然语言处理的一个新兴领域，近年来受到广泛关注。情感分类在意见挖掘、信息预测、评论筛选分类、垃圾过滤、词性标注和舆情监控等应用领域具有极其重要的意义。
