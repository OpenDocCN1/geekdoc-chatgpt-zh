# 2. 区域卫生系统

区域卫生系统由区域卫生平台和公共卫生系统两部分组成。其中，区域卫生平台既包括收集、处理、传输社区、医院、医疗科研机构、卫生监管部门记录的所有信息的区域卫生信息平台，也包括旨在运用尖端的科学和计算机技术，帮助医疗单位及其他有关组织开展疾病危险度的评价，制定以个体为基础的危险因素干预计划，减少医疗费用支出，以及制定预防和控制疾病的发生和发展的电子健康档案（electronic health record, EHR）。常见的区域卫生系统主要有社区医疗服务系统（见图 1-9）和科研管理系统（见图 1-10）。
