# 2. 青铜器时代

众所周知，铜的质地偏软，一般的石头都能够把铜砸变形，铜一经加热，更易于变形。最早人类并没有大量使用铜，但是在铜的铸造过程中凑巧加入锡和铅后，人们发现其质地变得坚硬，这也就是青铜。人们慢慢地总结规律，发现这几种金属都很软，不需要太高的温度就可以熔化，但是将它们合在一起变成合金以后，会变得很坚硬，这是人类的一个伟大创造。因为青铜熔点低、硬度强等优点，并随着青铜冶炼技术越来越成熟，青铜的应用也更加广泛，不仅被锻造成各种工具、生活用品、装饰品，还用于锻造武器，青铜制造的工具如图 2-16 所示。该时期农业和手工业的生产力水平大幅提高，人们的物质生活条件也渐渐丰富。可以说，青铜的出现对当时的社会生产力发展起到划时代的作用。
