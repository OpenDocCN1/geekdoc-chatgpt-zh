# (2) 智能制造系统的神经突触

工业控制计算机（见图 1-37）和 PLC（见图 1-38）都是由 CPU、存储器、输入/输出（input/output, I/O）单元、外设 I/O 接口、通信接口及电源共同组成的，能够根据实际控制对象的需要配备编程器、打印机等外部设备，具备逻辑控制和逻辑编程功能，能够完成对各类机械电子装置的控制任务。特别是 PLC，因为体形小巧，具有可靠性高、易于编程、组态灵活、安装方便、运行速度快等特点，不仅成为机械装备和生产线的控制器，还成为生产线数据的采集器和转发器，类似于神经系统中的“突触”，一方面可以收集、读取设备状态数据并反馈给上位机[数据采集与监视控制（SCADA）系统或分布式控制系统（distributed control system, DCS）]，另一方面可以接收并执行上位机发出的指令，直接控制现场层的生产设备。
