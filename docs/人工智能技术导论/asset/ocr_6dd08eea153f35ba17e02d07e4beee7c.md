# 6.3.2 训练实操：基于计算机视觉的手机刷脸软件的使用

以某国产手机为例，将人脸录入手机，通过刷脸安全解锁的方法如下。

步骤一：录入面部数据。打开“设置”，单击“生物识别和密码”选项，再单击“人脸识别”选项，按照屏幕提示录入面部数据，如图 6-18 所示。

![](bbox=[0.136, 0.223, 0.864, 0.606])

图 6-18 录入面部数据

步骤二：使用人脸解锁。录入成功后，拿起手机对准面部，屏幕会自动点亮并识别人脸，滑动屏幕即可解锁。

步骤三：可以在“人脸识别-解锁屏幕”中选择“直接解锁”（见图 6-19），获得更快捷的解锁体验。
