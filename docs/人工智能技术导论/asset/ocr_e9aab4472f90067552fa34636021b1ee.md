# (1) 机器学习和深度学习具体是如何工作的

以人脸识别为例，传统的机器学习在确定了相应的面部特征，如眼睛、鼻子、嘴等之后，才能基于这些特征做进一步的分类处理；而深度学习可以通过多层神经网络结构，将底层特征（low-level features）逐步“进化成”人能看懂的、能理解的高层特征（high-level features），从而实现自动找出分类问题所需要的重要特征。基于深度学习的人脸识别步骤如图 2-12 所示。第一步输入的是原始数据（raw data），这个数据机器是没法理解的。
