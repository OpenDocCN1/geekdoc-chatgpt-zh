# (3) 中国计算机视觉行业进入企业较多，投融资市场发展迅速

随着中国制造业的崛起，制造业对生产线更加智能化的需求，使得中国计算机视觉产业投融资案例逐渐增多。目前进入计算机视觉行业的企业很多，从应用功能领域划分，主要是检测、测量、定位、识别读码等几种，各家企业都有自身专注的领域，或一个或多个，在很大程度上，工艺算法是主要壁垒，行业案例是敲门砖。

综合来看，鉴于短期内技术密集型的机器人产业仍处于成长阶段，新晋企业和团队仍将持续涌入计算机视觉行业。作为人工智能技术与工业制造的直接结合点，计算机视觉有望持续快速发展。
