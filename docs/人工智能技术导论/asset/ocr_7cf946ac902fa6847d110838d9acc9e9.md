# 6.2.3 计算机视觉相关技术

计算机视觉是指用摄像机和计算机及其他相关设备对生物视觉的一种模拟。它的主要任务是使计算机理解图片或者视频中的内容。计算机视觉从硬件到软件涉及的技术非常多。接下来对相机成像原理、图像存储以及计算机视觉相关的算法进行简单介绍。
