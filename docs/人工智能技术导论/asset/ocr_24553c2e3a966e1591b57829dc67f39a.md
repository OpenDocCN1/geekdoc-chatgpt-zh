# ## 3.2.1 知识概述

人类对知识的认识和理解古已有之，“知识”在古文中可以拆解为“知”和“识”，均有认识、知道、懂得的意思。“吾有知乎哉？无知也。”——《论语》；“吾生也有涯，而知也无涯。”——《庄子》；“识，知也。”——《说文》；“非学无以致疑，非问无以广识。”——刘开《问说》；“没有学问，谁也看不起你。如没有真的学问，更是无人看得起。”——冯玉祥；“智慧，并不产生于学校，而是来自对于知识的终生不懈地追求。”——爱因斯坦；“知识就是力量，但更重要的是运用知识的技能。”——培根。这些对知识的理解、表达和追求，来源于他们的生活经历，同时这些知识和智慧又帮助他们为他人和人类做出贡献。

人们在生活中不断探索和认识客观世界，在这个过程中获取了大量对事实、信息的描述，甚至行动的技能，这些都属于知识的范畴。同时，人们又与客观世界不断交互，从而影响和改变世界，在这个过程中又需要运用知识。
