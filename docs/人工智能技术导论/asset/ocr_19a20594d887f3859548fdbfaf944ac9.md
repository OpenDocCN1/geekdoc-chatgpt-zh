# ### 3.1 项目描述

一般认为，人工智能分为运算智能、感知智能和认知智能 3 个层次。运算智能即快速计算、记忆和存储能力；感知智能，即视觉、听觉、触觉等感知能力，当下十分热门的语音识别、语音合成、图像识别即是感知智能；认知智能则为理解、解释的能力，知识图谱和以知识图谱为代表的知识工程系列技术是认知智能的核心。知识工程主要过程包括 3 个方面：知识表示、知识获取和知识使用。基于知识工程的理念产生了专家系统、知识图谱等更复杂的系统，广泛地应用于搜索引擎、医疗、电子商务等领域。

本项目将以知识的概念为切入点，重点介绍基本的知识表示、知识推理方法，并介绍知识工程在智慧医疗、智能客服等场景的应用。
