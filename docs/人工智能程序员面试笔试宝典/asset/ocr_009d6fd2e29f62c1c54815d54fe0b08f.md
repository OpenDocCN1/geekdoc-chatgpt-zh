# 9.12 如何从顶部开始逐层打印二叉树结点数据

题目描述：

给定一棵二叉树，要求逐层打印二叉树结点的数据，如图9-11所示。

![](bbox=[0.4, 0.16, 0.65, 0.26])

图9-11 二叉树

对这棵二叉树层序遍历的结果为1, 2, 3, 4, 5, 6, 7。

# 分析与解答：

为了实现对二叉树的层序遍历，就要求在遍历一个节点的同时记录下它的孩子节点的信息，然后按照这个记录的顺序来访问节点的数据，在实现的时候可以采用队列来存储当前遍历到的节点的孩子节点，从而实现二叉树的层序遍历，遍历过程如图9-12所示。

![](bbox=[0.22, 0.37, 0.75, 0.47])

图9-12 层序遍历二叉树

在图9-12中，图（1）首先把根节点1放到队列里面，然后开始遍历。图（2）队列首元素（节点1）出队列，同时它的孩子节点2和节点3进队列；图（3）接着出队列的节点为2，同时把它的孩子节点4和节点5放到队列里，依此类推就可以实现对二叉树的层序遍历。

实现代码如下：

```
```python
from collections import deque

class BiTNode:
    def __init__(self):
        self.data = None
        self.lchild = None
        self.rchild = None
