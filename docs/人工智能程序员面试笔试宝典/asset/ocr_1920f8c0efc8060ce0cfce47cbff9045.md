# 3.1.1 线性回归及代码展示

在机器学习中，线性回归模型是探讨变量y和多个变量x₁, x₂, …, xₙ之间的关系，用已有的训练数据为基础，总结问题本身的规律变化，并建立相应的回归模型来以预测未知的样本数据。

假设有训练数据集数为m个，则 (x⁽ⁱ⁾, y⁽ⁱ⁾), i=1, 2, …, m为一个训练数据，其中x⁽ⁱ⁾=(1, x₁⁽ⁱ⁾, x₂⁽ⁱ⁾, …, xₙ⁽ⁱ⁾)和y⁽ⁱ⁾分别是第i个训练数据对应的自变量与因变量，则回归函数如下：

h_θ(x) = θ₀ + θ₁x₁ + θ₂x₂ + … + θₙxₙ = θᵀx

其中

x = (1, x₁, x₂, …, xₙ)ᵀ, θ = (θ₀, θ₁, …, θₙ)ᵀ

下面需要定义代价函数用来描述h_θ(x⁽ⁱ⁾)与对应的y⁽ⁱ⁾的接近程度：

J(θ) = 1/(2m) Σᵢ₌₁ᵐ (h_θ(x⁽ⁱ⁾) - y⁽ⁱ⁾)²

½的作用在于求导时，消掉常数系数。梯度下降法、最小二乘法等方法便是求代价函数最小值的方法。

最小二乘法是比较直接的使用矩阵运算来取得θ的一种算法，算法步骤是对代价函数J(θ)求偏导并令其等于零，所得到θ即为模型参数，即

∂/∂θₖ J(θ) = 1/m Σᵢ₌₁ᵐ (h_θ(x⁽ⁱ⁾) - y⁽ⁱ⁾) xₖ⁽ⁱ⁾ = 0

Σᵢ₌₁ᵐ y⁽ⁱ⁾ xₖ⁽ⁱ⁾ = Σⱼ₌₀ⁿ (Σᵢ₌₁ᵐ xⱼ⁽ⁱ⁾ xₖ⁽ⁱ⁾) θⱼ

矩阵形式即为

XᵀY = XᵀX θ

参数即解得为：

θ = (XᵀX)⁻¹ XᵀY

梯度下降法须要选取恰当的学习速率α和多次迭代更新来求得最终结果，而最小二乘法不需要。但最小二乘法须要求解(XᵀX)⁻¹，其计算量大约为O(n³)，当训练数据集过大时求解过程非常耗时。
