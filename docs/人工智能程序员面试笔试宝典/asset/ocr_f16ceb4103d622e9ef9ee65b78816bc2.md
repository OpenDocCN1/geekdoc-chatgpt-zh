# 6.3.2 什么是Conditional GAN

（Conditional GAN，CGAN）是将额外的信息y加入到G、D和真实数据来建模，这里的y可以是标签或其他辅助信息。换句话说就是提出了一种带条件约束的GAN，在生成模型（D）和判别模型（G）的建模中均引入条件变量y，使用额外信息y对模型增加条件并指导数据生成过程。这些条件变量y可以基于多种信息，例如类别标签，用于图像修复的部分数据，此时就相当于有监督的模型。

由于此时在生成模型中，先验输入噪声p(z)和条件信息y联合组成了联合隐层表征，故CGAN的目标函数是带有条件概率的极小极大值博弈：

min_G max_D V(D,G) = E_{x~p_data(x)}[log D(x|y)] + E_{z~p_z(z)}[log(1 - D(G(z|y)))]
