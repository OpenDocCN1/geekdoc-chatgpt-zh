# 5.4.5 Noisy Net

原先DQN中常采用e-greedy的策略增加Agent的探索能力，即以e的概率采取随机的动作，以1-e的概率采取当前获得价值最大的动作。另一种方法Noisy Net，目的则是通过对参数增加噪声来增加模型的探索能力。
