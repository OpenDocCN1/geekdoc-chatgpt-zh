输入: S, A, γ, α（学习率 α）
初始化经验池 D
随机初始化 Q 网络的参数 φ 和目标 Q 网络的参数 φ̂ = φ
Repeat:
    初始化起始状态 s₀
    Repeat:
        在状态 s，选择动作 a = π^ε(s)
        执行动作 a 并得到奖励 r 和下一时刻状态 s'
        将 s, a, r, s' 放入 D 中
        从 D 中采样 ŝ, â, r̂, ŝ'
        计算 y = { r̂                     若 s' 为终止状态
                  r̂ + γ maxₐ' Q_φ̂(ŝ, a')   否则 }
        定义损失函数 L = (y - Q_φ(s, a))² 并训练 Q 网络
        s = s'
        每隔若干步，令 φ̂ = φ
    Until s 为终止状态
Until Q_φ(s, a) 收敛, ∀s, a
输出: Q 网络 Q_φ(s, a)
