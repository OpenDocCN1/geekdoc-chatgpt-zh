```
def maxSubArray4(array):
    if array == None or len(array) < 1:
        print("数组不存在")
        return
    nAll = array[0]      # 最大子数组和
    nEnd = array[0]      # 包含最后一个元素的最大子数组和
    i = 1
    while i < len(array):
        nEnd = max(nEnd+array[i], array[i])
        nAll = max(nEnd, nAll)
        i += 1
    return nAll
```

这种方法在保证了时间复杂度为O(N)的基础上，把算法的空间复杂度也降到了O(1)。
