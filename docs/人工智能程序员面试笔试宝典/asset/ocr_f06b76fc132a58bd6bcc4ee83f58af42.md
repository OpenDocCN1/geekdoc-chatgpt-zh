# 7.6 索引

创建索引可以大大提高系统的性能，总体来说，索引的优点如下。

+   1) 大大加快数据的检索速度，这也是创建索引的最主要的原因。\n2) 索引可以加速表和表之间的连接。\n3) 索引在实现数据的参照完整性方面特别有意义，例如，在外键列上创建索引可以有效地避免死锁的发生，也可以防止当更新父表主键时，数据库对子表的全表锁定。\n4) 索引是减少磁盘I/0的许多有效手段之一。\n5) 当使用分组（GROUP BY）和排序（ORDER BY）子句进行数据检索时，可以显著减少查询中分组和排序的时间，大大加快数据的检索速度。\n6) 创建唯一性索引，可以保证数据库表中每一行数据的唯一性。\n7) 通过使用索引，可以在查询的过程中，使用优化隐藏器，提高系统的性能。

索引的缺点如下。

+   1) 索引必须创建在表上，不能创建在视图上。\n2) 创建索引和维护索引要耗费时间，这种时间随着数据量的增加而增加。\n3) 建立索引需要占用物理空间，如果要建立聚簇索引，那么需要的空间会很大。\n4) 当对表中的数据进行增加、删除和修改的时候，系统必须要有额外的时间来同时对索引进行更新维护，以维持数据和索引的一致性，所以，索引降低了数据的维护速度。

索引的使用原则如下。

+   1) 在大表上建立索引才有意义。\n2) 在WHERE子句或者连接条件经常引用的列上建立索引。\n3) 索引的层次不要超过4层。
