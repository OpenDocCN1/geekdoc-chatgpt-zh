# 6.5.4 搜索策略

在模型训练过程中要平衡模型开发和探索（tradeoff between exploitation and exploration）。因此需要训练和测试。通常测试是用直接通过贪婪算法（greedy algorithm）选取对应概率最大的指针作为解码步骤的输出。与贪婪算法不同的，在测试环节，可以采取不同的搜索策略让模型输出更优的结果。下面介绍两种搜索策略：Sampling和Active Search。
