为这需要机器存储人类有史以来的所有数据,并训练出人类所有可能的知识和推理,这是根本不可能完成的工作。

可见,人工智能是机器智能,不是人类智能,也不是类人智能。机器智能是必须通过提取大量数据,并进行自动标注后计算得到的智能。而除此之外,人类智能还包括不可计算的智能,如情感、直觉、感知等。
