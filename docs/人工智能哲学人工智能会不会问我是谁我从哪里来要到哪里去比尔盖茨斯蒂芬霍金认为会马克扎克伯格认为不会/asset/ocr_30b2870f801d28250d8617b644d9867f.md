# # 第四章 计算机意识

未来的计算机是只存在于这个世界上，还是在体验这个世界？它是否既具有自知，又能够反思这种自知？但我们还可以走的更远，思考当我们把人类独特的本质赋予机器人的时候，我们是否能够将机器人看作我们的同类？计算机除了需要问我是谁，可能还需要问我做对了吗。

# 约翰·弗鲁姆的故事

在太平洋靠近澳大利亚的海域，是美拉尼西亚地区(Melanesia)，由瓦努阿图(Vanuatu)、所罗门群岛(the Solomon Islands)、巴布亚新几内亚(Papua New Guinea)、斐济(Fiji)四个国家以及一些较小的岛屿组成。第二次世界大战期间，这些国家处于太平洋战区的交通要塞，所以美军来到了这里，并由此在当地出现了一种奇怪的社会现象，被称为“货物崇拜”(cargo cults)。

这些岛屿上的原住民亲眼看到，登陆后的美军清理了一些地面作为跑道，并建造了一座瞭望塔。之后在岛民充满敬畏的注视中，空中的飞机呼啸着降落在跑道上，卸下大量货物，通常，军方会与岛民分享其中的一些，包括罐头食品和加工制品。
