# 前言

20世纪发生了不计其数的改变，快速的改变似乎是近百年最显著的特征。据说，几十项甚至可能几百项技术进步彻底改变了我们的生活，这些技术包括汽车、航空旅行、电视、个人电脑、互联网和手机。我们利用了原子，飞入了太空，发明了抗生素，消灭了天花，对基因组进行了测序。

但是当回看历史时，我们会发现人类在过去的5000年里只发生了微乎其微的变化。我们和生活在5000年前的人一样，也有妈妈、爸爸、孩子、学校、政府、宗教、战争、和平；我们仍然庆祝出生并哀悼死亡；体育、婚礼、舞蹈、珠宝、文身、时尚、八卦、社会等级、恐惧、爱情、欢乐、幸福和狂喜等永远与我们如影随形。这在人类所有文化中都是普遍存在的。从这个角度看，一直以来人类真的没有太大的变化。我们仍然在早上去上班，只是我们到达那里的方式改变了；在古亚述(ancient Assyria)[1]，小孩拉着带轮子的小木马玩具晃晃悠悠；在古希腊，男孩们拔河比力气；古埃及的化妆品闻名于世；几千年前，波斯人庆祝生日的方式和我们几乎一样，有聚会、礼物和特别的甜点。
