万页法律的国家，背不出似乎是一个很好的借口。早期的法典，如有4000年历史的《乌尔纳姆法典》(The Code of Ur-Nammu)，明确规定了对谋杀、抢劫、绑架、强奸、作伪证、侵犯他人身体以及与土地所有权有关的各种犯罪的具体处罚措施，如淹没邻居的田地、未能耕种租来的田地和偷偷耕种他人的田地等。比《乌尔纳姆法典》晚了两三个世纪的《汉谟拉比法典》(The Code of Hammurabi)，包含282条法律，涵盖了以上的所有内容，同时还增加了合同执行、产品责任和继承的内容。

货币也出现在第三纪。像我们今天这样的压印硬币直到很久以后才被发明，但在第三纪早期，世界各地出现了金、银、贝壳和盐等十几种其他形式的货币。普遍认为金属是理想的交易媒介，因为它们有价值，可分割，耐用便携。冶金学本身开始于第三纪之初，人类很快就认识到锡和铜的结合可以冶炼出优于两者的青铜。

随着文字、车轮和金钱的同时出现，建立民族国家和帝国所需的基本要素已经就位。几乎在同一时期，我们看到了全世界范围内首批大型文明以独立各异的形态绽放。中国、印度河流域、美索不达米亚、埃及和中美洲全都成为了幅员辽阔、凝聚力强、繁荣昌盛的文明家园。没有人知道这些文明是如何在彼此没有联系的地方，几乎同时如约定好一般崭露头角的。文字也是一样，没有人知道，世界为什么在5万年前或者2万年前没有文字、车轮和农业呢？

因此，就我们讲述的人类历史来说，我们有语言、想象力、劳动分工、城市和对未来的概念，我们还有了文字、法律规范、车轮、合同和金钱。在接下来的几千年中，所有这些都使我们能够相对快速地发展技术。
