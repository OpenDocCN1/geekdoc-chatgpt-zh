# 第三章 通用人工智能

“通用人工智能”将是一位人造爱因斯坦，这要么是可能实现，要么是不可能的。这两种观点之间的差别判若鸿沟，而它与我们对现实本质、自我身份的认同感和人类实质的核心信念有关。要是相信一元论，那么只要模拟大脑就能拥有会思考的机器人，要是相信二元论，那么机器将永远只是机器。

1940年，华特·迪士尼(Walt Disney)发行了动画电影《幻想曲》(Fantasia)，这是一部以古典音乐为背景的故事片，由八个不同的故事组成。其中最著名的故事段落是《魔法师的学徒》(The Sorcerer's Apprentice)，改编自18世纪歌德(Goethe)创作的一首诗。
