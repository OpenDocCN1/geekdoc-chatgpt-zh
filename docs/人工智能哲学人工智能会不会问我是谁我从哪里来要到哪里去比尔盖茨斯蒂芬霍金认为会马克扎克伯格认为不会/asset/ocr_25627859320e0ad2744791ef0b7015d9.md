# 这本书关乎第四次技术变革。

[1]亚述(Assyria)，古代西亚奴隶制国家，位于底格里斯河中游，属于闪米特族的亚述人在此建立亚述尔城后逐渐形成贵族专制的奴隶制城邦。古代亚述的历史从苏美尔时期，到亚述帝国连续2000余年，一般分为古亚述、中亚述和帝国3个阶段。其中古亚述时期为公元前2000-前1600年间。

[2]以弗所(EPHESUS，土耳其)，古典早期最重要的城市之一，以弗所在古代安纳托利亚半岛(Anatolia)是一座爱奥尼亚地区(Ionian)的希腊城市，在公元前10世纪由雅典殖民者建立。基士特河口从这里流向爱琴海(AegeanSea)，它也是帕尼欧尼亚同盟的一部分。

[3]阿尔忒弥斯神庙是希腊神话阿尔忒弥斯女神的神庙，长425尺，宽230尺，有126根高60尺的大理石柱。据称建筑时间前后长达120年(相比之下，大希腊王建耶路撒冷圣殿也只用了46年)。
