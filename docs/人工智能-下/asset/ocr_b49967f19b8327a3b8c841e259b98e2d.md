上述问题中提到的“前提”又称为约束条件；而“成本”和“效益”则称为目标。由于目标值y是由一组参数x1, x2, ..., xn共同决定的，即目标值是一组参数的函数y=f (x1, x2, ..., xn)，所以y又称为目标函数。

寻优问题可以描述为：在一定约束条件下，应该如何寻找一组最佳参数值x1, x2, ..., xn，以使目标函数y达到最优值（最大值或最小值）。

寻找问题最优解通常有3类方法，分别称为梯度法、枚举法和随机搜索法。
