# 蚁群觅食行为的启发

意大利学者Macro Dorigo等人在观察蚂蚁的觅食习性时发现，蚂蚁虽然视觉不发达，但它们在没有任何提示的情况下总能找到巢穴与食物源之间的最短路径。

蚂蚁为什么会有这样的能力呢？进一步研究发现，原来蚂蚁的秘密武器是一种遗留在其来往路径上的挥发性化学物质——信息素（pheromone），蚂蚁正是通过信息素来进行通信和相互协作的。

实际上，蚂蚁在开始寻找食物时并不知道食物在什么地方，它们只是各自向不同的方向漫无目的地随机寻找，这就形成了初始觅食方
