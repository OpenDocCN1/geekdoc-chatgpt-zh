# 回归分析的步骤

回归分析的主要步骤如下。

第一步，从一组数据出发，确定Y与X间的定量关系表达式，即建立回归方程并根据实测数据来求解模型的各个未知参数。求解参数的常用方法是最小二乘法。

例2 研究某产品质量和用户满意度之间的因果关系。设用户满意度为因变量，记为Y；产品质量为自变量，记为X。通常可以建立下面的线性关系：

```
Y=a+bX+e
```
