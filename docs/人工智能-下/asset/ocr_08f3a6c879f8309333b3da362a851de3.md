# 第三节 机器学习的基本方法

人类在实践中总结了各种行之有效的学习方法和学习策略，好的学习方法会使学习事半功倍。

机器学习同样要讲究学习方法和学习策略，并以学习算法的形式予以实现。经过几十年的发展，机器学习领域积累的学习算法日益丰富，为便于学习和理解，研究者们常对这些算法进行适当的分类，不同的分类标准形成不同的分类结果。
