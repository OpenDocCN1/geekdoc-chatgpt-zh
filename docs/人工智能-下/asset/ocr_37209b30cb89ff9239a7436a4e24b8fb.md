# (6) 变异操作

变异操作是指对个体的某一个位置上的基因值按某一较小的概率进行改变。具体实施办法是，首先随机产生各个个体的基因变异位置，然后依照某一小概率将变异点的原有基因值取反（0变1，或1变0）。

对初始种群进行一轮选择、交叉、变异操作后可得到新一代种群，将新种群的适应度值填入表10-5中，观察经过一轮进化之后，其适应度的最大值、平均值是否得到了明显的改进。
