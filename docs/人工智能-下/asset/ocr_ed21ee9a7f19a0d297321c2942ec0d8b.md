# 第二节 决策树算法

决策树（decision tree）算法是机器学习中的经典算法，是应用最广的归类推理算法之一，属于监督式学习。在许多机器学习算法中，训练过程得到的模型往往是一个函数，而决策树算法训练后得到的是一个决策树。

# 动手构造一棵决策树

顾名思义，决策树应该是能做决策的“树”。既然称为树，就要有树的样子，比如要有树根、树枝、树叶。下面我们先通过解决一个分类决策问题，“种出”一棵决策树！
