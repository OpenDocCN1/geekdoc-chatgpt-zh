

# 科技工作者组织活动

TWC确定了科技工作者组织活动的三大议题：一是职场标准问题，包括过度劳累、薪酬不合理以及工作压力过大问题；二是员工构成多样性、性别歧视和种族歧视问题；三是伦理和政治问题，涉及科技公司的项目的伦理性，以及公司在更广泛的社会、政治问题上的立场。

科技公司的外包员工同样也面临职场问题。在整个科技行业，大量的蓝领和白领员工实际上是由第三方机构雇用的。这些员工通常无法享受与企业内部员工相同的薪资、福利和就业保障，他们在公司中属于二线劳动力，主要用于填补人员空缺，或承担关键却低薪的辅助性职责。2019年，在谷歌公司的全球22万名员工中，多数都属于此类员工。

TWC关注的第二类问题是多样性和包容问题，如性别歧视、种族歧视和性骚扰问题。2018年，为了抗议公司掩盖性骚扰指控，全球50多个城市的2万名谷歌员工联合进行了罢工。

TWC关注的最后一类问题是伦理道德和政治原则问题。劳动者团结一致，共同应对此类问题。其中最著名的例子就是谷歌员工抵制公司参与美国军方的Maven项目。该项目利用机器学习技术分析无人机拍摄的画面，而许多谷歌员工认为这明显违背了公司自21世纪初以来一直秉持的“不作恶”原则。

与之前“绝不重演”运动一样，抵制Maven项目激励业内各地员工在自己的工作场所寻求改变。微软员工紧随其后，于2018年呼吁公司不要参加联合企业防御基础设施项目的竞标。2019年，微软员工又呼吁公司废除“向美军提供定制版AR（增强现实）头戴设备”的合同。

和数据工作者一样，高级技术人才在AI生产网络中同时把控拓扑瓶颈和时间瓶颈的关键节点。如果他们选择集体罢工，必将给公司乃至AI生产网络造成巨大的经济损失。然而，有趣的是，尽管员工们屡次尝试组织起来，但真正通过罢工和停工来中断生产流程的实例屈指可数。这些行动大多以请愿和公开声明的形式，给公司“敲响警钟”。

和数据工作者不同的是，高级技术人才还拥有两个关键优势。第一，数据工作者面临极不透明的生产过程，而高级技术人才对自己工作成果的实际应用场景有清晰的认识，他们有能力中断或威胁中断关键生产环节。第二，数据工作者需要在全球劳动力市场中与后备力量竞争；而高级技术人才则不同，他们掌握着稀缺技能，这使得他们在就业市场上处于更有利的位置。企业或许会轻易解雇某地数千名数据标注员，然后在异地重新招募，但绝不会这样对待机器学习工程师团队。从先前成功的案例中也能看出，高级技术人才拥有更大的权力。
