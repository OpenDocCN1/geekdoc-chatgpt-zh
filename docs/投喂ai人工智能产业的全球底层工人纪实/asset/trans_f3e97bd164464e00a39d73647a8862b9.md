# 第4章 创意工作者的故事

劳拉永远忘不了这一天。她的工程师朋友打电话，问她之前向AI公司出售声音版权的事情。她刚开始还以为朋友问错人了。虽然她是职业配音演员，但她没和任何AI公司合作过。劳拉上过戏剧学校，学过一些课程，之后开始从事配音工作。她给广告、动画片、游戏和有声读物都配过音，还演过戏剧和电视剧，当过编剧。在这些行业里，她摸爬滚打了近二十年。

劳拉问朋友是在哪个网址发现她的声音的，并且要了链接。她打开网站看到了一个名叫克洛伊的亚洲女子的虚拟形象。网站宣传克洛伊有标准的爱尔兰口音，擅长给有声读物配音。劳拉点击克洛伊的图像，一下子就听到了自己的声音。克洛伊说：“亲爱的朋友们，你们好，我是克洛伊。我的声音温柔而亲切，可以为有声读物和教育视频配音，也可以为广告配音，甚至可以进行软推销。任何配音工作，我都可以胜任。”克洛伊的声音听起来有些低沉，很像机器人，但还是明显可以听出这就是劳拉的声音。劳拉简直不敢相信。她既没听说过这家公司，也不知道它是怎么复制自己声音的。但她很快意识到，不管它如何得到了自己的声音，她都要和人工合成版的“自己”竞争同一份工作了。

过了好一会儿，劳拉才缓过神来。这家公司是怎么得到她的声音并合成使用的？她向一位专注媒体行业的律师朋友咨询，并调查了这家公司。她发现，根据欧盟法律，声音本身没有版权，但她可以对该公司提起控告，主张表演权。律师说，具体情况要看这个公司所在地的法律规定。而问题就出现在这里：在网站上找不到该公司的地址和注册国。劳拉通过邮件友好地询问公司地址，得到的回复是：公司对地址保密，也无法进一步协助她处理问询事宜。

她气坏了。难道就没有其他办法了吗？就只能任由这种公司随意窃取别人的声音去制作AI配音演员，导致其他配音演员失业吗？这完全是一种盗窃行为。该公司未经她同意，擅自采集她的声音，制造了一个没有灵魂的AI配音演员，而其工作报价只有人类配音演员的1/10。这就好像有人克隆了她，造出了一个像小说《科学怪人》（Frankenstein）里的弗兰肯斯坦一样没有灵魂的怪物。

经过一番调查，她终于找到了整件事的罪魁祸首。几年前，劳拉曾为一家大型科技公司工作，当时签署的合同篇幅很长，有些条款她根本没有留意，比如，“公司‘永久’拥有她的声音版权”。结果就是，这家公司把录音卖给了第三方公司，第三方公司拿着劳拉的声音合法地生成了虚拟形象。签合同的时候，劳拉完全没意识到日后会发生这种事情。虽然这样的“永久”条款一看就不公平，但是好工作难寻，许多配音演员只能被迫接受雇用方的所有条款。在大环境面前，尤其是遇上新冠肺炎疫情等特殊情况，个人很难与跨国公司硬碰硬。

她咨询了律师，似乎没有解决方案。这些公司的行为虽然不道德，但是并不违法。劳拉感觉法律似乎还没跟上技术发展的步伐，整个配音行业对此束手无策。许多预算紧张的公司都开始使用AI配音演员，这样能节省很多成本。因此，数百万配音演员都可能面临失业风险，并丧失作为演员的身份认同。虽然AI配音演员的表现远不及专业配音演员，但很多公司并不在乎质量。

之后劳拉又去听了听克洛伊的声音，她感到其中缺失了某种重要的东西。人声能够唤起共鸣，可以根据语境调整语调和语气，表达特定感情和意义，而AI配音演员无法做到这些。要是以后都是这种虚拟配音演员，所有作品都如此枯燥无味、没有灵魂，配音行业和整个社会又将走向何方？自己做配音演员的日子是不是到头了？AI配音演员以后能和真正的人声一模一样吗？这些问题只有等待时间来回答了。现在，劳拉只能无奈地接受自己又多了一个竞争对手的现实。

## 没有创作者的作品

2022年年底，随着 ChatGPT、Dall-E 和 Midjourney 等新AI工具的推出，AI产品浪潮席卷整个互联网。想让AI图像生成器 Stable Diffusion使用西班牙浪漫主义画家戈雅的黑色绘画风格画科米蛙（电视节目《大青蛙布偶秀》中的青蛙布偶角色）？没问题。想要一张听起来像绿洲乐队1995—1997年风格的新专辑？轻松搞定。想要一首糅合梅根·西·斯塔莉安（Megan Thee Stallion）歌词风格的T. S.艾略特式诗歌？ChatGPT随时待命。迪士尼用AI为漫威电视剧《秘密入侵》（Secret Invasion）制作了片尾演职员表，网飞日本分部则直接宣布其最新一部动画短片完全由生成式AI制作。

尽管生成式AI还没有得到人类的广泛认可，但它的确站在巨人的肩膀上。它之所以在某些方面表现出色，是因为有海量的人工数据供它进行训练。大语言模型的突飞猛进要归功于数据集规模的不断扩大，使得现在的模型可以使用数千亿个参数。这么多的数据集，其中难免掺杂受版权保护的内容。有些作者抱怨，类似ChatGPT这样的模型使用了大量受版权保护的作品，这些作品来源于“影子图书馆”，如 Library Genesis和Z-Library等电子书平台，上面有许多非法传播的电子书籍。

图像生成器也是如此。Stability AI公司开发的AI模型Stable Diffusion使用超大规模开源数据集LAION-5B进行训练，这个数据集从互联网抓取了58亿个图像文本数据对。

AI公司实际上在出售本不属于它们的东西：图像生成工具的价值建立在人工原创作品的基础之上。这些作品从大型数据集中被剥离出来，被转化为商品进行销售。这些公司将科技产业的经典座右铭“快速行动，破除陈规”扭曲为“快速行动，窃取成果”。受影响最大的是创作者，那些公司根本没有考虑过这些人的感受。图像生成器能够让任何人免费模仿艺术家的风格进行创作，这已经对许多人的生计造成了威胁。虽然仿作和衍生作品自古有之，但AI带来的威胁是前所未有的，因为全世界数百万用户只需要点击一下鼠标就能批量炮制赝品。与过去零星兜售赝品不同，AI正在进行大规模掠夺，将整个创作群体的创意成果洗劫一空。

创作者早在AI出现以前就在为保护自己的作品而斗争。他们经常被要求放弃作品的未来收益，一直在抵制这些不公平条款。我们采访到的一名配音演员告诉我们，之前获得的版税金额都是按照作品销量计算的，但现在无论作品售出多少都只支付固定费用，这正在成为行业标准。她还表示：“创作者向来处于价值链底端，其他人都在压榨他们。这个问题由来已久，AI不是始作俑者，但它让事情变得更糟糕了。”

但有些人已经开始试图攻破这个难题。芝加哥大学的研究人员开发了一款新工具，可以帮助创作者保护作品。这种工具名为“Nightshade”，可以在数字图像中添加一些特殊像素，一旦AI引入这些作品进行训练，特殊像素就会导致系统崩溃，无法运行。

每推出一个新模型，AI就会变得更复杂，更像人类。早期的图像生成器还不能准确地描绘人脸，画出正确的手部动作，但现在不一样了。如今的聊天机器人虽然还是不能理解言外之意，但已经能够准确地执行一些标准化任务。比如，ChatGPT-4虽然可以通过美国律师资格考试，但仍会给出一些荒诞的答案，且无法正确回答需要理解上下文的简单问题。毫无疑问，AI很快就会突破这些限制。

对配音演员来说，AI配音和真人配音之间仍有很大差距。目前，大品牌还是会选择人类配音演员来完成专业、高质量的配音工作，但大部分人都会选择经济实惠的AI配音工具，AI抢了许多配音演员的饭碗。在某AI配音网站，用户每月只需支付27美元，就可以使用文字转语音软件，使用数百种声线，说出各种口音，表达各种情感。比起雇用一名人类配音演员，这笔费用算不了什么，而且AI配音几秒钟就能完成。随着技术的成熟，人类越来越习惯AI的声音，人类配音演员会越来越难找工作。

生成式AI也有可能改变娱乐产业的格局。在美国，演员的肖像公开权受法律保护，但保护的具体范围因州而异。

人类也不应夸大当前这代AI的能力。图像生成器依旧有许多输入指令限制。虽然聊天机器人在某些任务上表现出色，但它们的作品还是缺乏特色和创造力。AI配音演员可以在不同语境下与人交流，但与人类配音演员相比，它们的声音缺乏深度和复杂性。许多游戏开发者不相信AI在《赛博朋克2077》（Cyberpunk 2077）或《荒野大镖客：救赎2》（Red Dead Redemption 2）这种量级的游戏制作中发挥重要作用。

然而，创意产业也分等级，有一些不那么复杂的创意工作可能会消失。这类工作的减少也可能威胁从业者的职业生涯，即使是比较成功的从业者也需要通过这些工作增加收入。我们采访的一名配音演员表示：“我录制词汇读音、英语学习音频、旁白解说和企业宣传视频，有些工作可能并不光鲜亮丽，但它们能养活我。我喜欢配音工作，也能靠这个赚钱，维持生计。”

这些消失的工作对潜在职业从业者的打击也很大。原本艺术创作行业的薪资水平就不乐观，而这些看起来还比较体面的工作一旦消失，就意味着只有家庭条件优越的孩子才可能投身艺术。2018年的一份针对视觉创意工作者的研究报告显示，近一半的参与者表示，自己90%的收入都不是来自艺术创作，近1/3的人表示自己需要家庭支持或继承遗产才能继续创作。

一些创意工作者发起了反击，并成功阻止了他们的肖像被用于生成式AI。在好莱坞，AI的使用已成为争议的焦点。2023年，拥有11 500名会员的美国编剧工会，以及代表16万名演员和媒体专业人士的美国演员工会因对好莱坞片厂工作条件不满发起罢工。

多家电影公司计划让AI根据公共领域内的书籍和其他作品生成剧本，这是编剧们最担心的问题。美国编剧工会认为，AI不应该用于剧本创作，编剧应该获得与编剧工作相关的全部报酬。2023年9月，美国编剧工会与电影公司达成了协议，规定AI不能参与剧本写作和修订，电影公司不得使用剧本秘密训练AI机器人。

美国演员工会则重点关注因“滥用AI”导致演员失业的情况。美国演员工会主席法兰·德瑞雪（Fran Drescher）表示：“AI已对创意行业构成威胁，所有演员和从业人员都应该得到书面合同的保护，避免他们的身份和作品在未经同意和未支付报酬的情况下被AI利用。”

配音演员最容易被AI取代，因此他们是这场抗争的主力军。全球配音演员联合成立了配音演员联盟，它涵盖了全世界20多个配音演员工会和协会组织。配音演员们发起了“别窃取我们的声音”运动，向政府抗议，要求政府加强对在创意产业中使用AI的监管。

好莱坞的高管将AI看作自己的武器，用它来控制创作者和作品。在好莱坞发生的事很可能在其他创意产业中重演，那些从业者或因缺乏集体议价能力而陷入更被动的境地。AI偷取人类劳动成果可能出现在各种涉及创作型劳动的行业中，如教育、建筑设计、产品设计和网页开发等。公司会想方设法让AI完成员工或签约者的一部分劳动，以缩减人力成本。与AI的抗争才刚刚开始，随着技术的发展和创意工作者的自我保护行动，博弈形态或将进一步升级。同时，这场角力抛出了以下重要问题：AI是否具有创造性？能否拥有和人类一样的智慧和创造力？
