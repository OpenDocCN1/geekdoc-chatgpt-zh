# 第1章 数据标注员的故事

安妮塔每天天还没亮就要步行两个小时去上班。简单地吃碗粥、喝杯茶，5点左右她就出发了。她和母亲、姐姐以及3个孩子住在乌干达北部最大的城市古卢郊区边上的小镇。她家门外是土路，没有公交车，不想走路上班就要叫摩的。安妮塔要是打摩的上下班，一来一回需要4美元，这对她来说是一笔不小的开销。所以为了省钱，她每天走路去上班，疲惫不堪地下班时，再坐摩的回家。

安妮塔家原是两间传统的圆形棚屋，泥土筑墙，茅草覆顶，是多年前盖的。现在，她和家人都住在一座现代的方形砖房里，屋顶是更为坚固的瓦楞铁皮制成的。这座砖房是两年前盖的，当时她攒钱分两次买了砖。她家院子里有棵巨大的芒果树，每年6月雨季过后，就会结一树的芒果。芒果树的周围种着几垄蔬菜，更远处还有棕榈树和其他茂盛的植物。安妮塔上班的时候，孩子们就在院子里玩耍，也会帮阿姨和保姆做点力所能及的家务。她养的鸡群在院子里自由地觅食，刨着肥沃的红土，偶尔也会漫步到邻居家的院子里去。

古卢是乌干达内战的产物。

这些新移民主要是一贫如洗的年轻人，由于没有土地，他们无法自给自足，只能完全融入货币经济。镇上的人道主义组织提供了一些保安、助手、翻译和保洁员的工作岗位，但僧多粥少。这导致很多人失业，非正规的劳动力市场也迅速扩大。由于找不到正式工作，人们就只能接受工资低、条件差的临时工作来维持生计。

那段岁月很艰难，时至今日，战争的创伤依旧深植人心，许多人仍承受着冲突带来的伤痛。这里约有1/3的年轻人没上过学，没有工作，绝大多数住房都达不到乌干达政府制定的宜居住房标准。

安妮塔上班的路上有一个菜市场，每天她经过的时候，女摊主们就已经出摊了，她们把茄子、洋葱、秋葵、木薯和其他根茎类蔬菜一一摆放在布上，然后铺好自己的坐垫。街头巷尾到处都是摩的，年轻的司机们坐在车上等活儿。太阳渐渐升起时，安妮塔刚好经过古卢大学。五年前，她曾在那里攻读工商管理学士学位，同时开始为现在的老板工作。当时这家公司刚刚开展数据标注服务，公司规模还很小，办公地点是个集装箱，设在古卢大学内。后来，公司逐渐发展壮大，就从大学的临时办公地搬到了城里。

安妮塔现在工作的地方是一栋灰色混凝土大楼，大楼的一到三层可以正常使用。第四层只建了一半，业主就没钱了，所以这一层只有几堵墙和空荡荡的窗框。大楼四周建了围栏，围栏上还拉着两种铁丝网。大楼门口有一名保安，身上用绳子挂着一支步枪。入口两侧的招牌上，公司的标识已斑驳剥落。这是一家大型数据标注公司在当地的交付中心，总部位于旧金山，在东非各地都设有交付中心。

安妮塔朝大楼走去，每靠近一步，她的压力便增添一分。她从口袋中掏出工牌，跟随从四面八方涌来的员工，一同在大门刷卡进入公司。进门后，她径直前往食堂找她的朋友，因为早晨上班前的这段时间是她唯一的社交时间，其余时间她都在不停地点击鼠标。她的工作强度极大，每天早上8点便开始工作，中间有两次休息时间，上午20分钟，中午40分钟，但休息时间通常都用于上厕所和在食堂排队打饭了。并且，员工的时间受到严密监控，完全没有机会闲聊。

公司中庭装饰得极具硅谷风格，沙发是鲜艳的三原色，屏幕里无声地播放着MTV（音乐录影带）。大门对面，挂着公司创始人的肖像海报，墙上张贴着公司的使命宣言和价值观：公司致力于“通过结合创造力和AI来加速人类发展”，并信奉“坚韧、诚信、高质量完成任务和人文精神”。

安妮塔一直负责一个自动驾驶汽车公司的项目，工作内容是检查司机驾驶录像，观察司机面部表情。当司机分心或是表现出困倦时，她就将当时的数据记录下来。司机的这些面部表情和眼动数据可以帮助汽车制造商搭建车内行为监控系统。但一连几个小时坐在电脑前盯着这些视频，着实让人疲惫不堪。安妮塔有时感觉这种无聊感就像一股无形的力量，让她不知不觉就靠在椅背上，闭上了双眼。但她不能松懈，她必须像那些视频里的司机一样保持警惕。她其实很以这份工作为荣，因为她觉得自己是在推动尖端技术发展，造福人类。这种自豪感就是她坚持下去的动力。

在做标注员之前，安妮塔在街边卖过果汁，还在市场里卖过菜。但这些非正式工作都受季节影响，不稳定，赚的钱也比现在少很多。能在这家公司工作5年，拿着说得过去的工资支撑起自己的小家，这对她来说已经很幸运了。由于公司用人会随着客户需求的变化而变化，她的很多同事都被裁了，好在她表现一直很好，所以留在了公司核心团队里。但她现在的工资刚刚够孩子学费、不太高的保姆费和照顾母亲，想想她为公司创造的价值，难怪她对自己的工资颇有怨言。

安妮塔不停地敲击键盘，拖动鼠标，速度之快令人瞠目。然而只有保持这样的速度，她才能完成工作任务，才能保证自己的名字在后台主管那里显示为绿色。倘若没能按时完成任务，她的名字就会变成红色，那时她就不得不无偿加班完成任务。时间过得很慢，安妮塔的腰开始隐隐作痛。她刚在椅子上伸了伸腰，手指和手腕就开始抽筋。她的眼皮沉重得直打架，屏幕也变得模糊不清。可眼睛刚闭上，她就猛然惊醒。工作一天下来，她已筋疲力尽。拖着疲惫的身躯走出公司，她打了一辆摩的回家。她一分钟都不想在公司多待，只想赶快回家，坐在芒果树下，享受最后几分钟的日光。

安妮塔现在进退维谷。她的工作枯燥乏味，每天这样冲业绩让她备感压力。可她一旦离职，又找不到更好的工作。镇上的银行、政府部门和非政府组织里的好职位，竞争都异常激烈。她也给公司提过改进建议，抱怨过工作时间长、工资低，投诉某些经理欺压员工，但这些都石沉大海。她觉得自己被困住了。如果有更好的工作机会，她一定会毫不犹豫地接受。

## AI数据标注中心的内部

正文部分

外界普遍对安妮塔所在的这类数据标注中心的内部情况知之甚少。尽管这些中心承担着生产过程中最密集的劳动任务，但它们在AI行业中仍显得相对隐匿。偶尔爆出的工作条件恶劣的新闻，大多限于个别案例，不涉及更深层次的管理制度问题。

有些数据标注工作借由数字工作平台被灵活地分配给全球各地的远程劳动者，而安妮塔所在的业务外包公司则把人集中起来，通过制定和执行严格的劳动纪律来提高效率和生产力。这种集中管理和纪律严明的模式并非新鲜事物，它的历史可追溯到殖民时期，那时的种植园、纺织厂和工厂已经采用了类似的劳动组织和管理方式。

这种集中管理制度有一定道理，因为毕竟劳动者不是机器，其行为无法被精准预测和控制。劳动者所创造出的价值也无法预先设定，需要根据各种复杂的具体情况才能确定。从历史角度看，管理科学正是为降低这种复杂性而发展出来的学科，目的就是让人类劳动变得简单化、机械化、更好预测和控制。想要理解这种制度的实际意义，我们还是要回到安妮塔的日常工作情境中。

办公室里，数百名数据标注员静静地坐在一排排办公桌前工作。做过电话客服工作的人会对这里感到熟悉，因为这里的环境和工作制度与客服工作大同小异。灯光被特意调暗以减轻9小时高强度工作造成的眼疲劳。图片和视频不断出现在屏幕上，等待数据标注员进行标注。和安妮塔一样，数据标注员都要接受培训，根据客户要求辨认图像中的元素。他们会用不同的多边形来标注不同的物体，如交通信号灯、路标、人脸等。一个项目可能需要数百名标注员，这些人会被分为20人左右的小组。每组有一名组长巡视，负责监督小组数据，看看有没有人偷懒。组长们要保证小组的工作效率，指导效率不高的组员改进工作。他们有时大喊大叫，有时又轻声细语，目的只有一个，就是交出让客户满意的工作成果。

当客户急需标注结果时，公司就会实行早晚轮班：一班从早上8点到下午6点，另一班从晚上8点到早上6点。如果单个任务较大，包含多个标注目标，公司会多给标注员一些时间进行标注。项目开始前，他们会对标注员进行测试，以确定完成项目所需的时间。测试结束后，他们会制定绩效目标，这个目标是10%～15%工作效率最低的标注员所无法达成的，所以每个人都必须全力以赴才能完成绩效目标。而且目标并非固定不变，随着标注员工作效率不断提高，主管就会提高标准，从而加快工作进度来增加公司利润。标注员如果没有完成当天的工作目标，就需要无偿加班。如果一周的进度远低于目标，他们周末也得无偿来公司加班。标注员每周要高强度工作45个小时，有时还得无偿加班。他们的月薪大概是80万乌干达先令，折合200多美元，约合每小时1.16美元。

标注员不仅速度要快，质量还得高，但这两者显然很难同时达成。组长通常只关注任务进度，确保所有组员按时完成任务。但标注员还会受到质量监督员的监督，他们要求一般项目的总体准确率不低于95%，一些特殊项目的准确率会设定得更高。任何被他们标记为“不准确”（即未完成）的任务都会拉低整体绩效。除了速度和质量，标注员还得留意自己的效率分数：10个小时的工作时间中，休息时间不得超过1个小时。除了规定的休息时间，其余时间标注员都要争分夺秒地努力工作。只要没在工作，标注员的生产效率评分就会降低。如果分数太低，组长就会通过后台软件查看工作屏幕，检查组员的工作情况。其实，标注员在工作的每一秒钟都是在权衡，在自己能承受的工作压力和自己能接受的效率评分之间寻求一个平衡点。

这些标注员无法获得长期的劳动合同保障。他们大多签的是一两个月的短期合同，时刻担心如果自己没有完成任务，就无法得到续约。标注工作并不稳定，客户也可能随时撤单，这就导致标注员数量持续波动。大项目一结束，这些失业的标注员就会被公司放进候补名单，他们要等待未来的机会，如公司扩大规模，才可能重新上岗。古卢当地的劳动力市场很糟糕，这些在“候补名单”上的人只能去打零工来维持生计，眼巴巴等着外包公司能够再有活儿。对那些要养家糊口的人来说，这样的日子确实没什么奔头。

在这种情况下，滥用职权的现象也渐渐增多，而女员工面临的风险会更大。有些女员工给我们讲了公司里的生育歧视，还提到公司里普遍存在性贿赂，大家都已司空见惯。一些管理人员会以聘用、晋升和留任作为条件，索取性贿赂。我们向公司反映了这些问题，公司回应称，会对工作场所中任何形式的性骚扰实行零容忍政策。公司还实行了一项新的监管规定，旨在系统审视公司文化，并对主要的人力资源、法律和行政管理部门人员进行了专门的反职场性骚扰培训（详见第8章）。

人们通常认为建立能够监控员工每一个工作细节的系统是现代社会的独特产物。毕竟以员工工作完成量、“摸鱼”时间、生产效率和工作质量评分等精细指标来建立数据库需要依靠现代技术。事实上，监控和控制劳动力的历史，可以追溯到很久以前。17世纪，北美洲巴巴多斯蔗糖种植园的欧洲白人园主已经开始寻求类似解决办法。

群体制度后来又进一步升级。19世纪40年代，美国南部棉花种植园蓬勃发展，种植园主希望继续保持这种发展态势。

尽管这些劳动组织和监控生产力的方式起源于加勒比地区和美国南部的种植园，但它们的迅速发展是在19世纪末的工业时代。1878年，弗雷德里克·温斯洛·泰勒（Fredrick Winslow Taylor）成了费城米德维尔钢铁公司的一名小职员。在那里他建立了科学管理理论的雏形。

如今，管理安妮塔和其他标注员的模式就由上述管理方式发展而来。标注员工作的方方面面都被数字化监控和记录，其严密程度超过了最严苛的种植园主和工厂主。从使用生物识别扫描进办公楼到无处不在的闭路电视摄像头，标注员每分每秒都受到监视。他们工作的每一秒都必须根据电脑上的效率监控软件进行记录。有些标注员甚至认为，管理人员在员工中安插了眼线，悄悄监视他们的言行，确保员工无力组建工会。在我们走访的业务外包公司中，员工普遍认为哪怕谈论一下建立工会的事情都会让自己丢掉饭碗。

不间断工作消耗标注员的身心健康。这种工作不需要标注员有自主性，任务都已经简化到最简单的形式，从而最大程度提高生产效率和生产力。所以标注员们不得不以最快速度，机械地重复相同动作，这让他们感到乏味且焦虑。这就是AI时代产业一线的现实情况：标注员在高压监控下拼命工作，只为能保住工作，养家糊口。
