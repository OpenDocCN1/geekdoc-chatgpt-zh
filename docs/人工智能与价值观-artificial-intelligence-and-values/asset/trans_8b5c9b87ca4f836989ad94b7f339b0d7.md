

# 影视艺术对人机关系的探索

好莱坞科幻影片已对人类与人工智能的关系展开了富有建设性的艺术探讨，并衍生出四种迥异的观点与态度[\[14\]](#txt004.xhtml#footnote_content_txt004_14)。欧洲学者针对第四种设想——“未来人机如何共处”，给出了自身的答案。2015年，由英国导演亚历克斯·加兰编导的电影《机械姬》深入追问了人机之间的情感纠葛。天才程序员凯莱布受邀对内森开发的机器人艾娃实施图灵测试，却在测试过程中双生情愫，凯莱布最终协助艾娃逃离实验室奔赴外部世界，自己却被囚禁其中。同类情感脉络亦见于法国电影《她》中。男主角在分手后长期陷于情感阴霾，情路坎坷。直至某日，一个仅能听闻其声、无法触摸其形的人工智能伴侣敲开了他紧闭已久的心扉。她拥有迷人的嗓音，温柔体贴且幽默风趣。二人迅速发现彼此灵魂高度契合，虽无法感知体温与呼吸，心灵的共鸣却带来了久违的温暖。虽影片结尾未能上演人机长相厮守的奇迹，但能与人类交心的人工智能形象仍激发了无数人的无限遐想与憧憬。

影视作品中出现人机相互倾慕、真假难辨的情节，缘于人们不再单纯将机器人视为工具或功能载体，人机关系达成了一种平等状态；又因人类与机器人在沟通、理解乃至冲突中实现了共处共生，这正是人类追求的“善”的生活。以“善”为归宿，人们在面对具备人类情感与心理活动的人工智能时，会顾及机器的感受，将其视为“准人类”，赋予其尊严与价值，因为人类亦渴望他人（含人工智能）以此相待。对待机器人的态度，折射出的正是人类对待自身的态度。若说人与自然关系题材的科幻电影引发的是对人类当下行为的伦理反思，那么人机关系题材的科幻影片传递的则是对未来人机平等共存的深切思考。

此类影视情节已开始映照现实生活，情感机器人的问世为人类带来了有温度、人性化的服务。业界对其前景普遍看好。英国科学界甚至预测，至2050年人类有望与按需定制的情感机器人“成婚”。不过，玛格丽特·博登也指出了部分评论家的浅薄见解：“个人的爱慕近乎情欲、性迷恋与单纯令人舒适的熟悉感。”

# 增进福祉：保障社会及公民权利

尽管人工智能是改变世界的尖端科技，但其开发者与部署者仍须遵循欧洲法律在基本权利（如数据保护、隐私、反歧视）、消费者保护、产品安全及责任规则等方面的规定。无论产品或系统是否依赖人工智能，消费者均期享有同等水平的安全性与权利尊重。

人工智能发展面临的首要风险之一，便是个人数据与隐私泄露以及歧视问题。人工智能的应用可能冲击欧盟基础价值观，导致基本权利受损[\[15\]](#txt004.xhtml#footnote_content_txt004_15)，涵盖言论自由、集会自由、人格尊严、基于性别、种族或族裔的非歧视、宗教信仰自由，以及基于残疾、年龄、性取向的非歧视，还有消费者保护权等。

鉴于此，欧洲将技术与产业优势、高质量数字基础设施及基本价值观相融合，确立了数据经济及其应用创新的全球领导地位，旨在惠及全体欧洲社会与民众，让公民获享新福祉：如改善医疗、减少家用设备故障、提供更安全清洁的交通系统及更优质的公共服务。欧盟通过提升产品可持续性、在政府部门配备工具以保障公民安全，提供适度保护措施，尊重其权利与自由。

## 巩固工业与法律优势，守护公民权利

作为老牌工业强国大本营，欧洲拥有传统工业优势，在人工智能发展中占据有利位置，无论作为用户、创造者还是生产者，均能更充分地受益于人工智能潜力。其拥有卓越的研究中心、新锐初创企业、机器人领域的全球领先地位，以及涵盖汽车、医疗、保健、能源、金融服务与农业等领域的世界顶级制造业与服务业。

欧洲具备强大的计算基础设施（如高性能计算机），这对人工智能运行至关重要。欧洲还掌握海量公共与工业数据，这些数据潜力尚未充分释放。在安全可靠、低功耗的数字系统方面，欧洲亦拥有业界公认的优势，这对人工智能进阶发展同等关键。欧盟正积极拓宽智能技术、基础设施及数字算力的投资渠道，强化在数据经济关键技术与基础设施层面的技术主权。

欧洲还发挥自身优势，从硬件制造到软件、服务，全方位巩固并拓展在生态系统与价值链上的地位。欧洲生产全球超过四分之一的工业与服务机器人（如现代农业、安防、卫生、物流领域），它们在企业组织应用软件、支撑电子政务中扮演关键角色[\[16\]](#txt004.xhtml#footnote_content_txt004_16)。此外，欧洲在制造业人工智能布局上领跑全球，过半数顶级制造商在业务中至少创建了一个AI实例[\[17\]](#txt004.xhtml#footnote_content_txt004_17)。

在基本权利与消费者权利保障上，欧盟加快立法步伐，相继出台《种族平等指令》《就业与职业平等待遇指令》《关于就业和获得商品和服务方面男女平等待遇的指令》《通用数据保护条例》《数据保护执法指令》等多部法规，共同撑起人工智能领域的法律框架。欧盟强调金融服务、移民或网络中介责任等领域的立法进程，必须尊重基本权利[\[18\]](#txt004.xhtml#footnote_content_txt004_18)。鉴于人工智能在欧盟平等就业要求中的重要性，欧盟还将进一步考量可能影响劳动者权利的其他特定法律适用。

除完善立法框架外，欧盟还高度关注远程生物识别功能[\[19\]](#txt004.xhtml#footnote_content_txt004_19)的使用与监管。应用远程生物识别技术采集、使用人类相关信息与生物数据（如在公共场所部署面部识别），会给欧洲民众基本权利带来特定风险。

使用人工智能系统进行远程生物识别，对基本人权的影响因使用目的、环境与范围而异。依据欧盟现行数据保护规则及《欧盟基本权利宪章》，仅在正当、符合比例原则且受充分保障的前提下，方可将人工智能系统用于远程生物识别。因此，除特殊情况外，欧盟《数据保护执法指令》原则上禁止为识别特定自然人而进行生物特征数据处理。具体而言，此类处理仅能基于维护重大公共利益等特定情形开展。因任何以识别特定自然人为目的的生物特征数据处理均涉及欧盟法律禁令，故该技术将受《欧盟基本权利宪章》约束[\[20\]](#txt004.xhtml#footnote_content_txt004_20)。

此外，为回应公众对公共场所使用人工智能的社会担忧，避免内部市场分割，欧盟委员会将发起全欧洲范围的辩论，探讨依法使用人工智能的具体情形及相应保障措施。

## 推动人工智能在中小企业与公共部门应用，促进社会发展

唯有让所有人均能获取技术红利，欧盟才能真正释放人工智能的社会潜能。为此，欧盟致力避免人工智能扩大数字鸿沟，大力推进数字创新中心与人工智能需求平台建设，深化与中小企业合作，助力中小企业及潜在用户从AI中获益。欧盟委员会已决定采取措施，确保所有潜在用户——特别是中小企业、缺乏技术实力的公司与公共机构——能获取最新技术并开展AI试验。为此，欧盟支持建设“人工智能按需平台”，实现全体用户单点接入最新AI资源。

欧盟委员会与成员国协作，确保每个成员国均设有高度专业化的AI数字创新中心。“数字欧洲”计划将为其提供资金支持。欧盟委员会期望数字创新中心能为本国中小企业提供支持，助其理解与采纳AI。

中小企业与初创企业需要资金更新工作流或利用AI创新。欧盟委员会与欧洲投资基金已于2020年一季度启动1亿欧元试点计划，为中小企业AI创新提供股权融资。待与MFF[\[21\]](#txt004.xhtml#footnote_content_txt004_21)达成最终协议后，欧盟委员会预计自2021年起大幅扩大投资规模。

除加大中小企业投资与应用外，欧盟及相关成员国还计划在公共管理、医院、公用事业、运输服务、金融监管等公共利益领域部署AI产品与服务。当前重点聚焦医疗卫生与运输领域，技术相对成熟。法国国家铁路公司通过智能交通系统预防了大量事故，维修成本降低约30%[\[22\]](#txt004.xhtml#footnote_content_txt004_22)。欧盟委员会优先发起与医疗卫生、农村行政、公共服务运营商等部门的公开透明对话，旨在通过行动计划促进AI试验、应用与发展。

金融领域亦加速AI应用。2015年12月，欧洲三大金融监管机构——欧洲银行管理局、欧洲证券市场管理局、欧洲保险与职业养老金管理局联合发布报告，分析了银行、保险、证券业涌现的智能投顾服务[\[23\]](#txt004.xhtml#footnote_content_txt004_23)。金融市场上发展较成熟的智能投顾，是投资顾问业务中的自动化工具，由投资者提供个人信息，工具结合客户数据经算法输出金融产品与服务交易建议。

## 重视技能培训与应用监督，提升个人能力

欧洲高度重视AI技能培育，着力弥补能力短板。欧盟委员会已提出强化技能议程，确保人人从绿色与数字化转型的欧盟经济发展中受益。欧盟委员会还向相关部门倡议提升AI领域技能，以有效执行相关规则。欧盟已出台并更新《数字教育行动计划》，这将助力更好利用数据及基于AI的学习与预测分析技术，逐步改善教育培训体系以适应数字时代。该计划还致力于在各级教育中提高公众对AI的认知，使公民做好准备应对AI冲击[\[24\]](#txt004.xhtml#footnote_content_txt004_24)。

欧盟与成员国共同制定AI协同计划，确定优先实践事项：发展AI相关必要技能，提升劳动力适应AI主导转型的能力。欧盟拟将道德准则评估清单转化为AI开发者的指示性“履历”，进而成为培训机构的教学资源。

此外，欧洲AI研究与创新中心正吸引全球人才，持续向外传播欧洲日益精进的卓越技能。欧盟计划为“数字欧洲”计划中的顶尖高校与教育机构提供先进核心技术，以吸引优秀教授与科学家，并提供AI领域世界领先的硕士学位课程。

欧盟在注重个人技能提升的同时，亦重视引入人工监督机制以深化合规与伦理意识。一个值得信赖、符合伦理、以人为本的AI，其客观性只能通过确保相关人员适当参与高风险AI应用来实现。人工监督可确保AI系统不削弱人类自主权或造成其他有害影响。

即使在特定法律框架下，适当的人工监督类型与程度仍因场景而异。这种差异主要基于系统特定用途及对相关民众、法人产生的效果与影响。在AI系统处理个人数据时，企业、部门、个人均应尊重《通用数据保护条例》规定的各项合法权利[\[25\]](#txt004.xhtml#footnote_content_txt004_25)。

# 价值维系：技术、人才、法律与伦理“三轮驱动”模式

正如蒸汽机与电力，人工智能正在重塑我们的世界，尤其是社会与工业领域。算力提升、数据积累与算法进步使AI成为本世纪最具战略性的技术之一。AI发展必将彻底改变世界。为此，欧盟全力构建坚实的AI战略框架，确保其在AI领域具备全球竞争力，确保AI发展与应用增进社会福祉，赋能全民。

欧盟委员会提出的AI战略框架包含三大支柱：一是提升AI在经济领域的技术与产业能力，推动AI普惠全社会；二是应对社会变革，使教育培训体系跟上时代，关注劳动力市场新变化，培育新型人才；三是研究AI带来的新挑战与新问题，促进利益相关方交流合作，制定适配AI发展与应用的伦理与法律框架[\[26\]](#txt004.xhtml#footnote_content_txt004_26)。

## 拥抱技术革新，提升产业能力

人工智能具备巨大的技术辐射效应，能为全球经济社会发展提供强劲新引擎。其一广泛应用于互联网、金融、教育、医疗等领域，让生活更便捷高效；其二在重大疾病诊疗、减少交通伤亡、消除饥饿贫困、应对网络攻击等方面，助力解决人类重大挑战。

为确保AI全球竞争力，让全民跟上数字化变革，欧盟主张必须提升技术与产业能力，使AI广泛渗透各行各业。为此，欧盟从以下方面加紧部署：

### 第一，把握未来数据浪潮机遇

相较中美两国，欧洲在消费级应用与在线平台处于弱势，导致数据获取处于劣势。但放眼全球，日均数据产量激增。据IDC预测，全球数据量将从2018年33ZB增至2025年175ZB[\[27\]](#txt004.xhtml#footnote_content_txt004_27)。因此，每一波新数据浪潮，都为欧洲在全球经济中重新定位、跻身世界领先者行列提供契机。

**强化数据记录与保存。** 鉴于AI系统复杂、不透明，且难以有效核实合规执行情况，欧盟正制定数据记录保存要求：保存算法设计记录、高风险AI系统训练数据、特定情况下“保存数据本身”，建立AI系统建立、测试、验证的程序与技术文档等。这些要求使AI系统潜在问题或决策可追溯、可验证。这不仅助力AI程序执行与监督，也促使经营者在遵守规则时体察规则立法本意。

这些记录、文档及相关数据需在有限期限内留存，以确保相关立法有效执行。欧盟相关部门已采取措施，确保被测试者按要求提供材料，并在必要时保护机密信息。

**强化数据访问与管理。** 无数据，不成AI。故数据访问与管理至关重要。尚未生成的海量新数据，让欧洲获得站在数据与AI变革前沿的机会。负责任的数据管理与运用，有助于建立信任、保障数据可复用。在《欧洲数据战略》支撑下，欧盟委员会提议在“数字欧洲”计划下拨付超40亿欧元，支持高性能与量子计算，含边缘计算、AI、大数据与云基础设施。这些关键计算技术与基础设施投资，是欧洲强化数据访问管理的有效举措，亦是强化捍卫欧盟价值观与规则的重要途径。

数据访问管理阶段，欧洲始终强调价值观植入。故欧盟萌生训练AI系统数据的构想，保障AI系统支撑的产品或服务符合安全要求，同时保证训练数据符合欧盟价值观与保护基本权利的现行立法[\[28\]](#txt004.xhtml#footnote_content_txt004_28)。

**强化数据开放共享。** 数据是机器学习关键。需促进数据开放共享。2005—2020年，欧盟推出多项举措促进公共部门数据与公共资金资助研究成果开放再利用。为最大程度促进数据流转共享，欧盟委员会推出举措：修订公共部门信息开放指令、出台私营部门数据共享指南、修订科研信息获取保存建议、出台医疗健康数字化转型政策（含共享基因数据及其他医疗数据）。

**深化数据处理技术。** 得益于数百年自然科学积淀，欧洲在AI算法领域长期领跑。量子计算最新进展将使计算机数据处理能力呈指数级增长。欧洲在量子计算数据处理技术上具学术优势，工业界在量子模拟器与编程环境中作用强大，已站在该技术前沿，并计划将量子测试实验设施方案应用于工业与学术部门。

未来，欧洲将在当前独立学科（如机器学习、深度学习、符号学习间）搭建桥梁，利用海量数据与相关性学习训练模型，实现符号推理与深度神经网络融合，提升AI结果可解释性。

### 第二，加大人工智能研发力度

**打造世界级欧洲AI研究中心。** 当前，欧盟与成员国大力建设AI研究中心，激励机构沟通合作、共同发展、共享成果，将欧洲建成全球AI研究创新前沿阵地。2018年1月，法国政府与三星集团深化合作，宣布扩大三星巴黎AI研发团队规模，将其打造成继韩国、美国后的第三大AI研发中心[\[29\]](#txt004.xhtml#footnote_content_txt004_29)。

**支持AI产品测试与实验。** AI产品测试实验是其上市前必经环节，意味着产品须符合安全标准规则。经测试实验，政府决策者能对新技术形成更好认知，利于制定更适配法律框架。为此，欧盟委员会已在医疗健康、交通运输等领域建成首批测试实验基础设施，并向所有企业开放[\[30\]](#txt004.xhtml#footnote_content_txt004_30)。

**加速技术成果市场转化。** 低功耗电子产品处理器技术方面，欧洲长期全球领先。虽该市场目前由非欧盟参与者主导，但在欧洲处理器项目等计划推动下，局面正在改变。为推动成果转化，欧盟大力支持技术突破、创新与转化，已为2018—2020年试点项目拨付27亿欧元预算，支持1000个潜在突破性项目及3000个关乎可行性的科研奖项[\[31\]](#txt004.xhtml#footnote_content_txt004_31)。

相关成员国在自动驾驶领域亦有建树。德国政府2015年允许在连接慕尼黑与柏林的A9高速实施自动驾驶测试，2016年4月批准法案将“驾驶员”定义扩展至能完全控制车辆的自动系统。2017年5月，德国联邦参议院通过首部自动驾驶法，允许特定条件下自动驾驶代替人类驾驶。同年9月，西门子收购荷兰自动驾驶软件公司新网国际，强化无人驾驶业务发展与成果转化。服务机器人领域，德国成果转化亦处前列[\[32\]](#txt004.xhtml#footnote_content_txt004_32)。2017年，英国发布《在英国发展人工智能》，将无人驾驶置于AI发展突出位置，望充分利用国内高校企业在AI与机器学习领域优势，进一步提升无人驾驶技术[\[33\]](#txt004.xhtml#footnote_content_txt004_33)。
