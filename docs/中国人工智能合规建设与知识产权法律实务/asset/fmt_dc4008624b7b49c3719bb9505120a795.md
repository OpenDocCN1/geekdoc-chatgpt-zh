# 下编 人工智能与知识产权

## 第二章 人工智能领域的知识产权保护

### 第一节 人工智能领域的著作权保护

#### 一、人工智能领域的著作权保护现状

世界上第一部著作权法——英国《安妮法》于1710年颁布，《安妮法》颁布300余年以来，在社会经济的发展和人类文化、艺术、科学进步的推动下，著作权所保护的作品的内容和传播途径发生了许多变化，使得著作权保护的形式也变得更为丰富。例如，广播电视技术的发展推动了传播权的产生，互联网技术催生了信息网络传播权。人工智能产业与传统产业存在许多不同之处，人工智能产业涉及大量可通过软件著作权保护的程序及文档，并且，由于人工智能应用场景广泛且丰富，还涉及虚拟卡通、虚拟人物形象、虚拟建筑等美术、建筑作品著作权保护客体。现阶段，人工智能领域的著作权保护仍在现有法律制度体系内完成，但是，人工智能技术的复杂性和创新性也带来了一些新型的著作权保护问题。

##### （一）人工智能领域所涉著作权保护客体

根据《中华人民共和国著作权法》（以下简称《著作权法》）第3条规定，著作权法所称的作品，是指文学、艺术和科学领域内具有独创性并能以一定形式表现的智力成果，包括：（1）文字作品；（2）口述作品；（3）音乐、戏剧、曲艺、舞蹈、杂技艺术作品；（4）美术、建筑作品；（5）摄影作品；（6）视听作品；（7）工程设计图、产品设计图、地图、示意图等图形作品和模型作品；（8）计算机软件；（9）符合作品特征的其他智力成果。

根据上述《著作权法》的规定，在人工智能领域内，可能涉及的著作权保护客体包括以下几类：

1.计算机软件

人工智能领域中涉及大量的算法、代码和程序，涵盖人工智能技术的基础层、技术层和应用层。其中，人工智能领域的软件表达可通过著作权进行保护，软件表达的内涵可根据《计算机软件保护条例》（国务院令第632号）确定，即计算机软件是指计算机程序及其有关文档。具体而言，计算机程序包含源程序和目标程序；文档包含程序设计说明书、流程图、用户手册等描述程序设计、功能、开发情况的文字资料和图表等。但是，计算机软件开发所用的思想、处理过程、操作方法或者数学概念等不受软件著作权的保护。

2.美术、建筑作品
