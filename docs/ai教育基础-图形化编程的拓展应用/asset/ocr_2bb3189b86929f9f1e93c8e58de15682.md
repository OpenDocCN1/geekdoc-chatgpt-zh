# 第五节 无线控速小车

# 一、本课所需的程序模块（表 9-5）

表 9-5 程序模块

| 序号 | 程序模块组 | 程序模块图标 | 程序模块功能 |
| :--- | :--- | :--- | :--- |
| 01 | 基本 | 当开机时 | 相当于开始，它在程序运行时处在所有其他事件之前，使用该事件来初始化程序。 |
| 02 | 基本 | 暂停 (ms) 100 | 暂停程序，时长为所设置的毫秒数。 |
| 03 | 基本 | 显示数字 0 | 在 LED 屏幕上显示一个数字。如果有一个以上的数字，就会向左滑动。 |
| 04 | 基本 | 显示箭头 北 | 在 LED 屏幕上显示一个箭头。有北（向上箭头）、南（向下箭头）、西（向左箭头）、东（向右箭头）四个方向。 |
| 05 | 基本 | 显示 LED | 在 LED 屏幕上显示字符、数字或图片。 |
| 06 | Siwt21_小车类 | 小车控制 箭头 速度 0 | 通过控制小车的两个电机转动方向及功率，来控制小车的行驶方向和速度。 |
| 07 | 输入 | 当按钮 A 被按下时 | 当按下再松开按钮（A，B 或同时按下 A+B）时执行操作。 |
| 08 | 逻辑 | 0 = 0 | 当两个输入值或变量相等，结果为真。 |
