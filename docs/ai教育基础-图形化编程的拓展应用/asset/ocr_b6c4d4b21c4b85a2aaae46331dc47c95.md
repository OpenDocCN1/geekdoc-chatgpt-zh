# 一、本课所需的硬件

1. 硬件。
核心板、主扩展板、光敏传感器、RGB 探照灯。

2. 特殊硬件介绍。
光敏传感器：对环境光线敏感，用来检测周围环境的光线亮度。

工作原理：当外界环境光线亮度达不到设定阈值时，引脚输出高电平（指示灯灭）；当外界环境光线亮度超过设定阈值时，引脚输出低电平（指示灯亮）。
