# 第二节 双边避障

# 编程逻辑

利用红外避障传感器，检测在距离红外避障传感器一定范围内，是否有障碍物。当检测到有障碍物时，小车左转持续 1 秒，指示灯颜色为红色；左转后再次检测是否有障碍物，当检测到有障碍物时，小车右转持续 2 秒，指示灯颜色为红色；未检测到障碍物时，小车前行，指示灯颜色为绿色。
