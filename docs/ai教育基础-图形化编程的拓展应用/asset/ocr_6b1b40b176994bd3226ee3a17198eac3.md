# ## 一、本课所需的硬件

1. 硬件。核心板、主扩展板、湿度传感器子扩展板、RGB 探照灯子扩展板、杜邦线若干。

2. 功能使用。

核心板上的芯片，主扩展板上的核心板接口、湿度传感器接口、RGB 探照灯接口。

# ## 二、本课所需的程序模块（表 7-1）

| 序号 | 程序模块组 | 程序模块图标 | 程序模块功能 |
| :--- | :--- | :--- | :--- |
| 01 | 基本 | 当开机时 | “当开机时”是一个特殊事件，相当于编程逻辑中的“开始”，它在程序运行时处在所有其他事件之前。使用该事件来初始化程序。 |
| 02 | 基本 | 暂停（ms） 100 | 暂停程序，时长为所设置的毫秒数。 |
| 03 | 基本 | 无限循环 | “无限循环” 启动后，程序不停地循环执行。 |
| 04 | 逻辑 | 如果为 true 则 | 如果值或条件为真（ true ），执行 “则” 中的代码。 |
| 05 | Siwtw21_传感器类 | 湿度传感器检测到土壤湿度 异常 | 当湿度传感器检测到土壤的湿度异常时，结果为真。 |
| 06 | Siwtw21_小车类 | 小车控制 前行 | 控制小车前行、后退、左转、右转、停止、原地左转或原地右转，控制发动机工作或停止。 |
| 07 | Siwtw21_显示类 | 初始化RGB | 执行 RGB 初始化。 |
| 08 | Siwtw21_显示类 | 显示彩灯 | 达到某个条件执行打开彩灯。 |
| 09 | Siwtw21_显示类 | 关闭彩灯 | 达到某个条件执行关闭彩灯。 |
| 10 | Siwtw21_显示类 | 设置 Light 1 颜色为 red | 把某个 RGB 探照灯设为某个颜色。 |
