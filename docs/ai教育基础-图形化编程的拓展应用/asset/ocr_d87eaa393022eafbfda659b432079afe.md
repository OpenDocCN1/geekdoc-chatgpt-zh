# 一、本课所需的硬件

+   1. 硬件。核心板、主扩展板、声音传感器、RGB 探照灯子扩展板、杜邦线若干。
+   2. 特殊硬件介绍。
+   
+   声学传感器：检测周围环境的声音强度。在外界环境声音强度达不到设定阈值时，模块输出高电平（指示灯灭）；当外界环境声音强度超过设定阈值时，模块输出低电平（指示灯亮）。使用中需要注意不能使用特定频率的声音。声学传感器的灵敏度可以调节。
