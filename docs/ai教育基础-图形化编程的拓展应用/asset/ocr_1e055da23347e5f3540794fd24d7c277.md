# 第三课 智能风扇

# 1. 提升训练参考答案

```
无限循环
将 温度 设为 温度 (°C)
如果为 温度 ≥ 22
  执行
    电机控制 电机1 正转 速度 200
    小车舵机 编号 S1 角度 180 速度 1
    暂停 (ms) 2000
    小车舵机 编号 S1 角度 0 速度 1
    暂停 (ms) 2000
如果为 温度 < 22 与 温度 > 16
  执行
    电机控制 电机1 正转 速度 100
    小车舵机 编号 S1 角度 180 速度 1
    暂停 (ms) 2000
    小车舵机 编号 S1 角度 0 速度 1
    暂停 (ms) 2000
如果为 温度 ≤ 16
  执行
    小车控制 停止
```
