# 2. 超声波跟随模式（图 11-21）。

```
无限循环
如果为 超声波测距 = true 则
  将 距离 设为 超声波返回 (cm)
  如果为 距离 > 0 与 距离 <= 20 则
    设置 Light 1 颜色为 red
    显示彩灯
    小车控制 前行 速度 100
  否则如果为 距离 > 20 与 距离 <= 50 则
    设置 Light 1 颜色为 orange
    显示彩灯
    小车控制 前行 速度 255
  否则
    小车控制 停止 速度 0
    将 超声波测距 设为 false
    将 红外避障 设为 true
```
