# ## 一、本课所需的硬件

硬件：核心板、主扩展板、超声波传感器、RGB 探照灯子扩展板、杜邦线若干。

# ## 二、本课所需的程序模块（表 8-1）

| 序号 | 程序模块组 | 程序模块图标 | 程序模块功能 |
| :--- | :--- | :--- | :--- |
| 01 | 基本 | 当开机时 | 相当于开始，它在程序运行时处在所有其他事件之前，使用该事件来初始化程序。 |
| 02 | 基本 | 无限循环 | “无限循环”程序启动后不停地运行代码。 |
| 03 | 基本 | 暂停 (ms) 100 | 暂停程序，暂停时长是所设置的毫秒数。 |
| 04 | 变量 | 将 Distance 设为 0 | 将 Distance 设置变量为某事物或项目。 |
| 05 | 逻辑 | 如果为 true 则 | 如果值为 true（真）执行一些语句。 |
| 06 | Siw21_显示类 | 初始化RGB | 初始化 RGB 显示。 |
| 07 | Siw21_显示类 | 显示彩灯 | 使灯点亮。 |
| 08 | Siw21_显示类 | 关闭彩灯 | 使灯关闭。 |
| 09 | Siw21_显示类 | 设置 Light 1 颜色为 red | 使灯的颜色设置为某种颜色。 |
| 10 | Siw21_小车类 | 小车舵机 编号 S1 角度 0 速度 0 | 控制舵机旋转角度和速度。 |
| 11 | Siw21_小车类 | 超声波返回 (cm) | 返回超声波传感器与障碍物之间的距离。 |
