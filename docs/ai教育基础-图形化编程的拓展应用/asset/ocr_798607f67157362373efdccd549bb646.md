# 第三节 调速风扇

利用超声波传感器检测物体距离超声波传感器的距离，控制风扇的开启；利用触摸传感器控制风扇的速度。当检测到物体与超声波传感器的距离大于 0cm 且小于 10cm 时，风扇开启并按照一定的方向进行摇头；当检测到有触摸时，风扇速度变化方向是 1，增加转动速度，当风扇转动速度大于 200 时，风扇速度变化方向变为 0，减慢转动速度。
