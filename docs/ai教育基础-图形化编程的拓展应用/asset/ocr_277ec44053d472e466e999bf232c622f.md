# 2. 小车主程序（图 10-12）。

```
无限循环
  如果为 红外避障传感器 检测到 有障碍物 障碍物 则
    小车控制 原地左旋 速度 200
    设置 Light 1 颜色为 red
    显示彩灯
    暂停 (ms) 1000
    如果为 红外避障传感器 检测到 有障碍物 障碍物 则
      小车控制 右转 速度 200
      暂停 (ms) 2000
    如果为 红外避障传感器 检测到 有障碍物 障碍物 则
      小车控制 左转 速度 200
      暂停 (ms) 1000
      小车控制 后退 速度 200
      暂停 (ms) 1000
      小车控制 右转 速度 200
      暂停 (ms) 1000
  否则
    小车控制 前行 速度 300
    设置 Light 1 颜色为 green
    显示彩灯
    暂停 (ms) 10
```
