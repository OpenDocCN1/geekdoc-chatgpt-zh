无限循环

  以 1 为幅度更改 时间
  如果 时间 = 30 则
    将 定时开门 设为 1
  否则
    将 定时开门 设为 0
```
```

```
```

  如果 定时开门 = 0 则
    设置 Light 1 颜色为 red

  否则
    播放音调 中 C 持续 1 节拍 节拍
