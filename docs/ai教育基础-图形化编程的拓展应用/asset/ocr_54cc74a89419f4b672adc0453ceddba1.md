# 第十课 智能避障小车（红外）

# 1. 提升训练参考答案

```
无限循环
如果为 红外避障传感器 检测到 有障碍物 障碍物 则
  小车控制 原地左旋 速度 70
  播放音调 中 C 持续 1 节拍 节拍
否则
  小车控制 前行 速度 120
暂停 (ms) 100
```
