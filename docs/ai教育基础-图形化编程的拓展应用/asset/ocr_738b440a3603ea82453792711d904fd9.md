# # 一、本课所需的硬件

1. 硬件。

核心板、主扩展板、超声波传感器、RGB 探照灯子扩展板、杜邦线若干。

2. 特殊硬件介绍。

超声波传感器：测量距离的传感器，可测量的距离为 3cm~200cm。

工作原理：超声波传感器有一个控制口和一个输出口，当控制口发出 10μs 以上的高电平时，就可以在接收口等待高电平输出，一有输出就可以开定时器计时，当此口变为低电平时就可以设定时器的值，此时就为此次测距的时间，通过测距的时间，就可计算出距离，如此不断地周期性地测量，就可以得到移动测量的值。
