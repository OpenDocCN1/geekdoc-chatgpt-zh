上述 ordinals 列表是自定义索引，共有 13 个元素，对应 13 项数据。DataFrame() 函数使用 index 参数指定使用的自定义索引。从其运行结果中可以看到第 1 列的标签是自定义索引，如图 9-3 所示。

也可以在创建 DataFrame 对象后，使用 df2.index 属性来更改使用的索引，如下所示：

```
df2 = pd.DataFrame(dists)
df2.index = ordinals
print(df2)
```
