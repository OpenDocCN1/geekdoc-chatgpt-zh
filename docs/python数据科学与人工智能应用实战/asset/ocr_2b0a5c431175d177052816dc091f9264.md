# 2. 删除 NaN 的记录：Ch13_3_1b.py

因为 NaN 记录并不能进行运算，所以最简单的方式就是调用 dropna() 函数将它们都删除，如下所示：

```
df1 = df.dropna()
print(df1)
```

上述程序代码中，dropna() 函数没有参数，表示删除全部 NaN 记录。也可以加上参数 how，如下所示：

```
df2 = df.dropna(how="any")
print(df2)
```

上述程序代码中，dropna() 函数的参数 how 值是 any，表示删除所有 NaN 记录。其运行结果只剩下 1 项，如图 13-11 所示。

如果 how 参数值是 all，就需要全部字段都是 NaN 才会删除，如下所示：

```
df3 = df.dropna(how="all")
print(df3)
```
