# 11.6.2 离散型随机变量与概率分布

离散型随机变量的值是有限的，其是一个不连续的值（有间隔）。例如，丢 1 个正反概率相同的铜板，正面是 1，反面是 0。离散型随机变量 Y 的概率分布如表 11-3 所示。

| 正反值 概率 | Y=1 | Y=0 |
| :--- | :--- | :--- |
| | 1/2 | 1/2 |

| | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 |

# 1. 离散型随机变量的期望值

离散型随机变量两个主要的属性是期望值（Expected Value）和方差。期望值 μ 也称为随机变量的平均值，其公式如下所示：

\(\mu = x_1 p_1 + x_2 p_2 + \cdots + x_n p_n\)

期望值 \(\mu\) 是随机变量 x 的值乘以对应的概率 p 的总和，p 可以从随机变量函数 f(x) 取得。例如，掷 1 个骰子是点数 1 的概率是 f(1)=1/6、点数 2 的概率是 f(2)=/6 ……期望值的运算过程如下所示：

1×1/6+2×1/6+3×1/6+4×1/6+5×1/6+6×1/6=3.5
