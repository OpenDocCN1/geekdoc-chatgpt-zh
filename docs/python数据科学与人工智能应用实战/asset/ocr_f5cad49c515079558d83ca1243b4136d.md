# 动手学——搜索兄弟标签：Ch5_3_2c.py

可以使用 CSS 选择器 “~” 搜索之后的所有兄弟标签，“+” 表示只有下一个兄弟标签。首先调用 find() 函数找出第 1 题 q1 的题目字符串，如下所示：

```
```python
tag_div = soup.find(id="q1")
print(tag_div.p.a.string)
print("------------------------")
tag_div = soup.select("#q1 ~ .survey")
for item in tag_div:
    print(item.p.a.string)
print("------------------------")
tag_div = soup.select("#q1 + .survey")
for item in tag_div:
    print(item.p.a.string)
```
