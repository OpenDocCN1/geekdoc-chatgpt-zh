> z 检验统计量: 6.0
> Z 分数: 1.959963984540054

# 4. 步骤 4: 解释假设检验的结果

因为 Z(critical) = ±1.96, 而 Z(obtained)=6, 位于正态分布右侧的临界区内 (6>1.96)，即样本平均数 71.5 落在临界区内，这不是随机结果，而是样本来自不同的总体，所以必须拒绝虚无假设，接受对立假设。研究者的结论成立，交换生的成绩和全校平均成绩不相同。

本节范例总体标准差 σ 是 2.5，如果是 25，此时的 Z(obtained)=0.6，没有落在临界区内 (0.6 < 1.96)，此时必须接受虚无假设，即在 5% 的显著水平下，交换生和全校学生成绩之间的差异并未达到统计上的显著差异。
