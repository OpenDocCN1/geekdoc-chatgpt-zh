# 2. 标签说明

+   - 第 9 ~ 13 行：项目编号，start 属性值为 2，所以从 2 开始。
+   - 第 15 ~ 18 行：项目符号。
+   - 第 20 ~ 25 行：定义列表。

# 3.3 HTML 5 图片与超链接标签

在 HTML 中，图片和超链接是非常重要的元素，图片可以让网页成为多媒体舞台，超链接可以让我们轻松连接全世界的资源。
