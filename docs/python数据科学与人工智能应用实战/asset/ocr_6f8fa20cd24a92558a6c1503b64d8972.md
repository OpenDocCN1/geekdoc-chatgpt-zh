# 动手学——使用存在字段作为索引标签：Ch9_2_1c.py

可以直接使用存在的字段作为索引标签，如 city 字段，如下所示：

```
...
df = pd.DataFrame(dists,
    columns = ["name", "population"],
    index = dists["city"])
print(df)
```

上述程序代码的 columns 属性只有 name 和 population，index 属性指定使用 city 键值的列表。在其运行结果中可以看到索引是城市，如图 9-5 所示。

...
print(df.T)
