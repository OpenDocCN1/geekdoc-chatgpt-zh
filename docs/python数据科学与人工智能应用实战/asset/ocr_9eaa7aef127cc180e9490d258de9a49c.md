上述标签的图文件路径可以通过正则表达式取出来，如下所示：

```
"www(.+?)+\.(?:jpg|gif|png)"
```

上述正则表达式的模板字符串是从字符串中获取图文件的完整路径。Python 程序分成两部分实现，首先发送 HTTP 请求，然后剖析 HTML 网页搜索 id 属性值为 lg 的 <div> 标签，如下所示：

```
import re
import requests
from bs4 import BeautifulSoup

url = "http://www.baidu.com"
path = "logo.png"
r = requests.get(url)
r.encoding = "utf-8"
soup = BeautifulSoup(r.text, "lxml")
tag_a = soup.find(id="lg")
```
