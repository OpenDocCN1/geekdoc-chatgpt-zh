# 4.2.3 使用开发人员工具查看 HTTP 标头信息

实际上，我们使用 Requests 发送 HTTP 请求时并不知道发送的请求中到底送出了什么数据，为了方便测试 HTTP 请求和响应，可以使用 httpbin 服务来进行测试。

另外，当使用 Chrome 浏览器发送 URL 网址时，也可以打开开发人员工具来查看 HTTP 标头信息。
