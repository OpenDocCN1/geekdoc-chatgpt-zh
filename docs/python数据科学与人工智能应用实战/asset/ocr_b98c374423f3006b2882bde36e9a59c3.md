# 11.2 组合事件与条件概率

目前介绍的概率都是单一事件，当涉及 2 个或更多事件时，就需要探讨组合事件（Compound Events）和条件概率（Conditional Probability）。

# 11.2.1 组合事件

组合事件是指处理 2 个或更多个事件，即事件拥有 2 或更多个简单事件。例如，现在有事件 A 和事件 B，则：

+   - 事件 A 和 B 同时发生的概率，因为是交集，所以使用交集符号表示，即 P(A∩B)。
+   - 事件 A 或事件 B 任一个发生的概率（没有同时发生），因为是并集，所以使用并集符号表示：P(A∪B) 。
