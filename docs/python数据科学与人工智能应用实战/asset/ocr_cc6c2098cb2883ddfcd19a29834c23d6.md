# 动手学——矩阵的点积运算： Ch8_4_1d.py

点积运算是求两个矩阵对应元素的列与行的乘积和。例如，使用和之前相同的 2 个矩阵，如图 8-13 所示。

上述矩阵 a 和 s 的点积运算结果是另一个矩阵，Python 程序如下所示：

```
a = np.array([[1, 2], [3, 4]])
print ("a=")
print (a)
s = np.array([[5, 6], [7, 8]])
print ("s=")
print (s)
b = a.dot(s)
print ("a.dot(s)=")
print (b)
```
