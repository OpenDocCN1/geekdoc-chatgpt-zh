上述加法运算过程产生的矩阵 c，其元素是矩阵 a 的元素加上矩阵 s 的对应元素，Python 程序如下所示：

```
a = np.array([[1, 2], [3, 4]])
print ("a=")
print (a)
s = np.array([[5, 6], [7, 8]])
print ("s=")
print (s)
b = a + s
print ("a+s=")
print (b)
b = a - s
print ("a-s=")
print (b)
b = a * s
print ("a*s=")
print (b)
b = a / s
print ("a/s=")
print (b)
```

上述程序代码中，变量 a 和 s 是 NumPy 二维数组的矩阵，同样可以使用运算符 +、-、* 和 / 进行矩阵与矩阵的四则运算。其运行结果如下所示：
