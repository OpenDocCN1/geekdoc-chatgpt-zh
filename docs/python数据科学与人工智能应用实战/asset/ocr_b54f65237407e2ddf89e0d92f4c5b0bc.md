# 3. 指定多个数据集的轴范围： Ch10_1_5b.py

```
days = range(1, 9)

plt.plot(days, celsius_min, "r--o",
     days, celsius_max, "g--o")

plt.ylabel("Celsius")
plt.axis([0, 10, 15, 40])
plt.show()
```
