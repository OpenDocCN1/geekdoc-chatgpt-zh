以此类推。

# 2. 套用 Lambda 表达式

DataFrame 对象的 apply() 函数也可以套用 Lambda 表达式，如下所示：

```
df3 = df.apply(lambda x: x.max() - x.min())
print(df3)
```

上述 Lambda 表达式计算最大和最小值的差，其运行结果如下所示：

| A | 0.560499 |
| B | 0.776888 |
| C | 0.727961 |
| D | 0.505208 |
| dtype: float64 |
