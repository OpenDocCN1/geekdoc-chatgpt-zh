# 9.5.3 套用函数

DataFrame 对象可以调用 apply() 函数套用 NumPy 函数或 Lambda 表达式，本节完整 Python 程序是 Ch9_5_3.py。首先使用随机数生成测试数据的 DataFrame 对象，如下所示：

```
import pandas as pd
import numpy as np
df = pd.DataFrame(np.random.rand(6, 4), columns=list("ABCD"))
print(df)
```

上述程序代码使用 6×4 的 NumPy 数组来创建 DataFrame 对象，如图 9-47 所示。

+   1. 套用 NumPy 函数

可以调用 DataFrame 对象的 apply() 函数套用 NumPy 函数。例如，cumsum() 函数的累加计算如下所示：

```
df2 = df.apply(np.cumsum)
print(df2)
```

上述程序代码是在 DataFrame 对象的所有数据都套用执行 cumsum() 函数，其参数只有函数的名称，没有括号，其执行结果如图 9-48 所示。
