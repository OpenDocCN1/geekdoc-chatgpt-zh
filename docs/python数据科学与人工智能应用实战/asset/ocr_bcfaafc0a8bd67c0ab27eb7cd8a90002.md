位）, 如下所示：

```
a = np.array([-1.7, 1.5, -0.2, 0.6, 10])
print("a=" + str(a))
b = np.floor(a)
print("floor()=" + str(b))
b = np.ceil(a)
print("ceil()=" + str(b))
```

上述程序代码建立一维数组 a 后，分别调用 floor() 函数输出最小整数，ceil() 函数输出最大整数。其运行结果如下所示：

```
a=[ -1.7 1.5 -0.2 0.6 10. ]
floor()=[ -2. 1. -1. 0. 10.]
ceil()=[ -1. 2. -0. 1. 10.]
```
