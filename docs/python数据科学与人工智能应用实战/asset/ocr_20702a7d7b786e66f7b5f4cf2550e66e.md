# 3.7.2 JSON 的语法

JSON 使用 JavaScript 语法来描述数据，是一种 JavaScript 语法的子集。以 Python 语言为例，JSON 对象类似于 Python 字典，JSON 数组类似于 Python 列表。

+   1. JSON 的语法规则

JSON 语法并没有关键词，其基本语法规则如下所示。

+   - 数据是成对的键和值，中间使用冒号 “:” 分隔。
+   - 数据与数据之间使用逗号 “,” 分隔。
+   - 使用大括号定义对象。
+   - 使用中括号定义对象数组。

JSON 文件的扩展名为 .json，MIME 类型为 application/json。

+   2. JSON 的键和值

JSON 数据是成对的键和值，首先是字段名，然后是冒号 “:”，再加上值，如下所示：

```
"author": "陈会安"
```

上述代码中，“author” 是字段名，“陈会安” 是值。JSON 的值可以是整数、浮点数、字符串（使用 “” 括起）、布尔值（True 或 False）、数组（使用中括号括起）和对象（使用大括号括起）。
