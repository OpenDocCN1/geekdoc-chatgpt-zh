# 3. <head> 标签

<head> 标签的内容是标题元素，包含 <title>、<meta>、<script> 和 <style> 标签。<meta> 标签可以指定网页的编码为 utf-8，如下所示：

```
<meta charset="utf-8">
```

关于 <head> 标签的进一步说明请参阅第 3.1.4 节。

# 4. <body> 标签

<body> 标签是真正的网页内容，包含文字、超链接、图片、表格、列表和窗体等网页内容，详见第 3.2 ～ 3.4 节的说明。
