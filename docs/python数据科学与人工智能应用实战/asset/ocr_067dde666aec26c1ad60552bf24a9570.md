# 1.4.2 下载与安装 Anaconda

Anaconda 整合安装包可以在官网免费下载，本节在 Windows 操作系统环境下下载和安装 Anaconda 整合安装包。

# 1. 下载 Anaconda

在 Anaconda 官方网站可以免费下载 Anaconda 整合安装包，如图 1-11 所示（网址：https://www.anaconda.com/download）。
