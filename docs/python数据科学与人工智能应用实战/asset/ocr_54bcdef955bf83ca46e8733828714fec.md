# 10.4.5 Pandas 包的饼图

Pandas 包也可以绘制饼图，本节即使用 Series 对象绘制饼图。

# 1. 使用 Series 对象绘制饼图：Ch10_4_5.py

只需建立数值数据的 Series 对象和指定索引，就可以调用 plot() 函数绘制饼图。例如，绘制水果销售量的饼图，如下所示：

```
fruits = ["Apple", "Pears", "Bananas", "Orange"]
percentage = [30, 10, 40, 20]
s = pd.Series(percentage, index=fruits, name="Fruits")
print(s)
s.plot(kind="pie")
```

上述程序代码中，Series 对象指定索引 fruits，name 属性是名称，plot() 函数使用 kind 属性指定 pie 饼图。其运行结果如图 10-44 所示。
