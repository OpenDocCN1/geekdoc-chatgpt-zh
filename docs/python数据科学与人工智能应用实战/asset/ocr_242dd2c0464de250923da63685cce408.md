# 11.6.1 认识随机变量与概率分布

统计的变量（Variable）是一种可测量或计数的特性、数值或数量，也可称为数据项，变量值就是数据，例如：年龄和性别等。变量如同第 1.2.2 节的数据可以分成质的变量和量的变量，也可以区分成第 1.2.3 节 4 种尺度的变量。

> 变量之所以称为变量，是因为变量值可能因为总体的数据单位或时间而改变。例如，收入是一个变量，总体的个人、家庭和公司收入可能不同，而且收入会因时间而增加或减少。
