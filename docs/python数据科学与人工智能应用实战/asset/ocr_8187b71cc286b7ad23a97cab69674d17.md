# 4.4.3 发送 RESTful API 的 HTTP 请求

Requests 包的 get() 函数也可以发送 RESTful API 的 HTTP 请求。例如，可以使用腾讯天气的 API 来查询天气预测信息，其返回数据是 JSON 数据，如下所示：

```
https://wis.qq.com/weather/common?source=xw&weather_type
=<预测种类>&province=<省>&city=<城市>
```

上述网址中的 weather_type 参数表示预测种类，如 forecast_1h 和 forecast_24h; province 参数表示哪一省；city 参数表示城市，如查询成都市 24 小时的天气预测信息，如下所示：

```
https://wis.qq.com/weather/common?source=xw&weather_type
=forecast_24h&province=四川&city=成都
```

动手学——发送 RESTful API 的 HTTP 请求：Ch4_4_3.py

发送 RESTful API 的 HTTP 请求，查询成都市 24 小时的天气预测信息，如下所示：

url = "https://wis.qq.com/weather/common?source=xw"
url_params = {'weather_type': 'forecast_24h',
