# 2. 非结构化数据

非结构化数据是没有组织的自由格式数据，这些数据无法直接使用，通常需要进行数据转换或清理后才能使用，如文字、网页内容、原始信号和音效等。

第 2 篇介绍的是如何从网页内容获取数据，这些单纯的文字数据就是非结构化数据，需要将它转换成结构化数据。例如，从“编程论坛”网页获取非结构化数据后，将其整理转换成表格数据，如图 1-4 所示。

# 3. 半结构化数据

半结构化数据是介于结构化数据和非结构化数据之间的一种数据，这是结构没有规则且快速变化的数据。简单地说，半结构化数据虽然有字段定义的结构，但是每一项数据的字段定义可能都不同，而且在不同时间点存取时，其结构也可能不一样。
