# 表 3-7 <a> 标签的 target 属性值及说明

| 属性值 | 说明 |
| :--- | :--- |
| _blank | 在新窗口或新标签打开 HTML 网页 |
| _self | 在原窗口或标签打开 HTML 网页 |
| _top | 在全屏幕打开 HTML 网页 |
| _parent | 在父框架打开 HTML 网页 |
| iframeName | 在指定名称的 <iframe> 框架打开 HTML 网页 |

因为 HTML 5 不再支持框架页，所以表 3-7 中的 _top、_parent 和 iframeName 属性值是使用在 <iframe> 标签的内嵌式框架。
