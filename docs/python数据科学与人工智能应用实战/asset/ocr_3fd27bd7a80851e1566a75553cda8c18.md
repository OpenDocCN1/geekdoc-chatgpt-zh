# 4.2.2 发送 POST 请求

Requests 包调用 get() 函数发送 GET 请求，同理，POST 请求调用 post() 函数。POST 请求就是发送窗体，如同 URL 参数，需要发送表单域的输入数据。

动手学——发送简单的 POST 请求：Ch4_2_2.py

调用 post() 函数发送 http://httpbin.org/post 的 POST 请求，发送的数据和第 4.2.1 节的参数相同，如下所示：

```
import requests

post_data = {'name': '陈会安', 'score': 95}
r = requests.post("http://httpbin.org/post", data=post_data)
print(r.text)
```
