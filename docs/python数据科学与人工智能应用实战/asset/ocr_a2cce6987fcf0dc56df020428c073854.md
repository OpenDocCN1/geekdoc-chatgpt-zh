# 图 11-18

图 11-18 中 3 条正态曲线的平均值 \(\mu\) 和标准偏差 \(\sigma\) 依次是 0, 1、0, 2 和 2, 1。从图 11-18 中可以看到，当平均值为 1 时，不同的标准偏差 1 和 2 会影响钟形正态曲线的高度和宽度；当标准偏差相同，都是 1 时，不同的平均值 0 和 2 会影响正态曲线平行位移。
