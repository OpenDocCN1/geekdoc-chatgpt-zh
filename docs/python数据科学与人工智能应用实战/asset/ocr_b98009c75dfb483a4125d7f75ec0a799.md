```
array[start:end:step, start1:end1:step1 ]
```

上述语法因为有 2 个索引，所以分别都可以指定开始、结束（不包含结束本身）和增量。
例如，NumPy 二维数组 a 如下所示：

```
a = np.arange(11, 36)
a = a.reshape(5, 5)
print("a=")
print(a)
```
