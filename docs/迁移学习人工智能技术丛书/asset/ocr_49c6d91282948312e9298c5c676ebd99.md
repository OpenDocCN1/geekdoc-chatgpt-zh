\(\hat{a^i} = \text{argmin}_{a^i} \|x_i - \sum_j a_j b_j\|_2^2 + \beta \|a^i\|_1\) (3.11)
最终，我们可以基于具有关联标签的目标域的新表示 \(\{\hat{a^i}\}\) 来学习模型。

# 3.3.2 深度通用特征

受到通过稀疏编码 (sparse coding) 来学习通用特征的启发，Glorot 等人 (2011) 提出应用深度自动编码器 (deep autoencoder) 来学习高级特征作为通用特征。具体来说，给定一个输入 x，深度编码器 f(·) 将其映射为隐藏编码 h=f(x)，而深度解码机 g(·) 旨在使用隐藏编码通过 x~ = g(h) 重构输入。由于编码器和解码器使用不同的辅助域进行训练，编码器的输出 h 被认为是对于每个输入样本的一种通用特征表示。Chen 等人 (2012b) 进一步提出了自动编码器的变体，即边缘化堆叠去噪自动编码器 (marginalized Stacked Denoising Autoencoder, mSDA)，以提高跨域学习通用特征的效率和有效性。

除了使用稀疏编码和自动编码器中的重构损失来学习通用特征外，一些研究者提出在辅助任务上使用聚类来学习通用特征。与重构损失相比，聚类是在复杂性方面轻量级的无监督学习方法。它还可以增加学习到的特征表示的可解释性。如图 3.4 所示，Liao 等人 (2016) 研究了几种 K-means 形式的损失函数来作为正则化函数，例如样本聚类、空间聚类和协同聚类等。
