$$p(\hat{o}_{n,t}^* = 1) = \begin{cases} \sigma(W_o^g h_{n,t-1}^{g,*} + U_o^g \hat{s}_{n,t-1}^* + b_o^g) & \hat{o}_{n,t-1}^* = 0 \\ \sigma(W_c^g h_{n,t-1}^{g,*} + U_o^g \hat{s}_{n,t-1}^* + b_o^g) & \hat{o}_{n,t-1}^* = 1 \end{cases} \quad (18.13)$$

\(\hat{o}_{n,t}^*\) 决定是否使用个性化组件来生成下一个词。\(h_{n,t}^{g,d}\) 定义为

$$h_{n,t}^{g,d} = (1 - \hat{o}_{n,t}^*) \odot h_{n,t}^{g,f} + \hat{o}_{n,t}^* \odot h_{n,t}^{g} \quad (18.14)$$

其中 \(h_{n,t}^{g,d}\) 是隐状态向量，直接用于生成下一个词 \(\hat{y}_{n,t}\)。生成下一个词 \(\hat{y}_{n,t}^*\) 的概率通过式 (18.2)～式 (18.4) 中的生成过程定义。

+   解码过程如下：
+   1) 基于 \(h_{n,t}^{g,f}\) 和 \(h_{n,t}^{g,c}\)，初始化 \(h_{n,t}^{g,f}\)，\(\hat{h}_{n,0}^*\)，\(\hat{o}_{n,0}^*\)，\(\hat{y}_{n,0}^*\) 和 \(\hat{s}_{n,0}^*\)。\(\hat{o}_{n,0}^*\) 初始化为 0，\(\hat{y}_{n,0}^*\) 初始化为零向量。
+   2) 基于 \(h_{n,t-1}^{c,*}\)、\(\hat{o}_{n,t-1}^*\)、\(h_{n,t-1}^{g,f}\)、\(h_{n,t-1}^{c,*}\) 和 \(\hat{y}_{t-1}^*\) 计算个性化控制门 \(\hat{o}_{n,t}^*\)，见式 (18.13)。
+   3) 基于个性化控制门 \(\hat{o}_{n,t}^*\) 计算 \(h_{n,t}^{g,f}\)、\(h_{n,t}^{c,*}\) 和输出的隐状态 \(h_{n,t}^{g,d}\)。
+   4) 基于输出的隐状态 \(h_{n,t}^{g,d}\) 生成 \(\hat{y}_{n,t}^*\)，见式 (18.14)。
+   5) 重复第 2～4 步，直到遇到终止符。

共享和个性化组件可以通过监督学习和强化学习一起训练。
