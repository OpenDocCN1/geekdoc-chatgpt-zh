函数来优化“迁移什么”，即针对一对新的源域 $\mathcal{S}_{N_t+1}$ 以及目标域 $\mathcal{T}_{N_t+1}$ 来确定最优的隐特征矩阵 $\boldsymbol{W}$。由于最优隐特征矩阵 $\boldsymbol{W}_{N_t+1}^*$ 是为了使 $f$ 值最大化，因此相应的目标函数为

$\boldsymbol{W}_{N_t+1}^* = \arg \min_{\boldsymbol{w}} 1/f(\mathscr{S}_{N_t+1}, \mathscr{T}_{N_t+1}, \boldsymbol{W}; \boldsymbol{\beta}^*, \lambda^*, \mu^*, b^*) + \gamma_2 \|\boldsymbol{W}\|_F^2$
\( = \arg \min_{\boldsymbol{w}} (\boldsymbol{\beta}^*)^\top \hat{\boldsymbol{d}}_{\boldsymbol{w}} + \lambda^* (\boldsymbol{\beta}^*)^\top \hat{\boldsymbol{Q}}_{\boldsymbol{w}} \boldsymbol{\beta}^* + \mu^* \frac{1}{(\boldsymbol{\beta}^*)^\top \boldsymbol{\tau}_{\boldsymbol{w}}} + \gamma_2 \|\boldsymbol{W}\|_F^2 \quad (12.3) \)

其中 $\gamma_2$ 是正则化参数。问题 (12.3) 中的第一项和第二项计算如下：

\( (\boldsymbol{\beta}^*)^\top \hat{\boldsymbol{d}}_{\boldsymbol{w}} = \sum_{k=1}^{N_k} \beta_k^* \left( \frac{1}{\alpha^i} \sum_{i,r=1}^n \mathscr{K}_t(\boldsymbol{v}_i \boldsymbol{W}, \boldsymbol{v}_r \boldsymbol{W}) + \frac{1}{b^j} \sum_{j,j'=1}^k \mathscr{K}_t(\boldsymbol{w}_i \boldsymbol{W}, \boldsymbol{w}_{j'} \boldsymbol{W}) - \frac{2}{ab} \sum_{i,j=1}^{a,b} \mathscr{K}_t(\boldsymbol{v}_i \boldsymbol{W}, \boldsymbol{w}_j \boldsymbol{W}) \right) \)
\( (\boldsymbol{\beta}^*)^\top \hat{\boldsymbol{Q}}_{\boldsymbol{w}} \boldsymbol{\beta}^* = \frac{1}{n^2-1} \sum_{i,i'=1}^n \sum_{k=1}^{N_k} (\beta_k^* (\mathscr{K}_t(\boldsymbol{v}_i \boldsymbol{W}, \boldsymbol{v}_{i'} \boldsymbol{W}) + \mathscr{K}_t(\boldsymbol{w}_i \boldsymbol{W}, \boldsymbol{w}_{i'} \boldsymbol{W}) - 2 \mathscr{K}_t(\boldsymbol{v}_i \boldsymbol{W}, \boldsymbol{w}_{i'} \boldsymbol{W}) \- \frac{1}{n^2} \sum_{i,i'=1}^n (\mathscr{K}_t(\boldsymbol{v}_i \boldsymbol{W}, \boldsymbol{v}_{i'} \boldsymbol{W}) + \mathscr{K}_t(\boldsymbol{w}_i \boldsymbol{W}, \boldsymbol{w}_{i'} \boldsymbol{W}) - 2 \mathscr{K}_t(\boldsymbol{v}_i \boldsymbol{W}, \boldsymbol{w}_{i'} \boldsymbol{W})))^2 \)

其中 $v_i = \boldsymbol{x}_{(N_t+1)i}, v_{i'} = \boldsymbol{x}_{(N_t+1)i'}, w_j = \boldsymbol{x}_{(N_t+1)j}, w_{j'} = \boldsymbol{x}_{(N_t+1)j'}, \alpha = n_{N_t+1}^i, b = n_{N_t+1}^j$。问题 (12.3)

中的第三项可以计算为 $(\boldsymbol{\beta}^*)^\top \boldsymbol{\tau}_{\boldsymbol{w}} = \sum_{k=1}^{N_k} \beta_k^* \frac{\text{tr}(\boldsymbol{W}^T \boldsymbol{S}_t^k \boldsymbol{W})}{\text{tr}(\boldsymbol{W}^T \boldsymbol{S}_t^k \boldsymbol{W})}$。非凸问题 (12.3) 可以采用共轭梯度法进行优化。

# 12.6 与其他学习范式的联系

# 12.6.1 迁移学习

第 1 章确定了迁移学习的三个关键研究问题，即何时迁移、迁移什么以及如何迁移。模型 (Yang 等人, 2007b; Tommasi 等人, 2014)、样本 (Dai 等人, 2007b) 或特征 (Pan 等人, 2011) 都可以在域之间迁移。一些工作 (Yang 等人, 2007b; Tommasi 等人, 2014) 使用源模型来规范基于 SVM 的目标模型。在 Dai 等人 (2007b) 的论文中，目标学习器的能力通过利用有用的源域样本来提高。各种能够学习域间可迁移特征的技术已经被广泛研究。这些技术基于人工定义的轴特征 (Blitzer 等人, 2006)、降维 (Pan 等人, 2011; Baktashmotlagh 等人, 2013, 2014)、协同矩阵分解 (Long 等人, 2014)、字典学习/稀疏编码 (Raina 等人, 2007; Zhang 等人, 2016)、流形学习 (Gopalan 等人, 2011; Gong 等人, 2012a)，以及深度学习 (Yosinski 等人, 2014; Long 等人, 2015; Tzeng 等人, 2015)。与 L2T 不同的是，现有的研究都侧重于从零开始迁移。
