形如

$W \sim \text{MN}(0,I,\Omega)$

其中 $\text{MN}(M, A, B)$ 表示矩阵变元正态分布，其中 $M$、$A$、$B$ 分别是均值、行协方差和列协方差。作为修正后的最大后验解（maximum a posterior solution），MTRL 模型的目标函数为

$$\min_{W,b,\Omega} \sum_{i=1}^m \frac{1}{n_i} \sum_{j=1}^{n_i} l(y_i^j, (w^i)^T x_j^j + b_i) + \lambda_1 \| W \|_F^2 + \lambda_2 \text{tr}(W \Omega^{-1} W^T) \quad \text{s. t. } \Omega \succ 0, \text{tr}(\Omega) \leqslant 1$$

其中 $\Omega$ 是任务协方差矩阵，用于表示任务之间的任务关系。MTRL 方法已扩展到多任务 Boosting (Zhang 和 Yeung, 2012) 和多标签学习 (Zhang 和 Yeung, 2013b)，并且被 Zhang 和 Yang (2017a) 扩展来学习稀疏任务关系。Zhang 和 Schneider (2010) 提出了一种与 MTRL 相似的模型，它在 $W$ 上定义了一个先验分布，形如 $W \sim \text{MN}(0, \Omega_1, \Omega_2)$，该方法假设 $\Omega_1$ 和 $\Omega_2$ 的逆矩阵是稀疏的。由于 MTRL 方法中使用的先验意味着 $W^T W$ 遵循 Wishart 分布 $W(0, \Omega)$，Zhang 和 Yeung (2013a) 扩展 MTRL 并提出了一种新的先验来学习高阶任务关系 $(W^T W)^t \sim W(0, \Omega)$，其中 $t$ 是一个正整数。Lee 等人 (2016) 提出了一个与 MTRL 类似的正则化项，它定义了 $\Omega$ 的参数化形式 $\Omega^{-1} = (I_m - A)(I_m - A)^T$，其中 $A$ 表示 Lee 等人 (2016) 提出的不对称任务关系。

与上述全局学习模型的方法不同，Zhang (2013) 将局部学习方法（如 $k$ 最近邻分类器）扩展到多任务设定，并将目标函数表示为

$$\min_{\Sigma} \sum_{i=1}^m \frac{1}{n_i} \sum_{j=1}^{n_i} l(y_i^j, f(x_i^j)) + \frac{\lambda_1}{4} \| \Sigma - \Sigma^T \|_F^2 + \frac{\lambda_2}{2} \| \Sigma \|_F^2 \quad \text{s. t. } \sigma_{ii} \geqslant 0 \forall i \in [m], -\sigma_{ii} \leqslant \sigma_{ij} \leqslant \sigma_{ii} \forall i \neq j$$

其中 $\mathcal{M}_i(i, j)$ 表示 $x_i^j$ 的 $k$ 个近邻的任务和样本索引的集合，$s(\cdot, \cdot, \cdot)$ 表示样本之间的相似性，$\sigma_{ip}$ 定义了任务 $\mathcal{F}_p$ 和 $\mathcal{F}_i$ 的相似性，该多任务 k 最近邻分类器的学习函数定义为

$$f(x_i^j) = \sum_{(p,q) \in \mathcal{M}_i(i,j)} \sigma_{ip} s(x_i^j, x_p^q) y_p^q$$

问题 (9.10) 中的正则化项使得 $\Sigma$ 接近于对称矩阵，用于表示任务相似性。
