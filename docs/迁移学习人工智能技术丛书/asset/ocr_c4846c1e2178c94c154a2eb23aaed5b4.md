源域数据的边缘概率分布、条件概率分布和联合概率分布，$p_T(x)$、$p_T(y|x)$、$p_T(x, y)$ 分别表示目标域数据的边缘概率分布、条件概率分布和联合概率分布，$p_I(x)$ 表示中间域的边缘概率分布。基于此，在 TTL 问题中有

$p_T(x) \neq p_S(x), p_T(x) \neq p_I(x), \text{且 } p_T(y|x) \neq p_S(y|x)$

TTL 的目标是利用中间域中的无标签数据在彼此间具有较大差异的源域和目标域之间建立联系，并基于该联系通过从源域中迁移监督知识来训练目标域中的准确分类器。值得注意的是，并非中间域中的所有数据都与源域数据类似，其中一些数据可能完全不同。因此，仅使用所有中间域数据来连接源域和目标域可能无法正常工作。

# 11.4.2 选择学习算法

在本节中，我们将介绍 Tan 等人（2017）提出的选择学习算法。

# 11.4.2.1 自编码器及其变种

SLA 的基础组成部分是自编码器（Bengio, 2009）及其变种。自编码器是一种无监督的前馈神经网络，具有一个输入层、一个或多个隐藏层和一个输出层。它通常包括两个工作过程：编码和解码。给定输入 $x \in \mathbb{R}^n$，自编码器通常首先通过编码函数 $f_e(\cdot)$ 对输入进行编码并将其映射为隐性表示，然后通过解码函数 $f_d(\cdot)$ 对其进行解码以重建 $x$。自编码器的工作过程概括如下：

编码：$h = f_e(x)$，解码：$\hat{x} = f_d(h)$

其中 $\hat{x}$ 是基于隐藏表示向量重建得到的。通过最小化所有训练数据的重建误差可以学习得到编码和解码两个函数 $f_e(\cdot)$ 和 $f_d(\cdot)$，即 $\min_{f_e, f_d} \sum_{i=1}^n \| \hat{x}_i - x_i \|_2^2$。

在学习得到编码函数和解码函数之后，编码函数相对于输入 $x$ 的输出，即 $h = f_e(x)$，通常被认为是输入 $x$ 的更高级的稳定表示。值得注意的是，自编码器的输入通常为向量。当自编码器的输入为诸如图像的矩阵或张量表示时，它会丢弃样本的空间信息。在此情况下，通常使用卷积自编码器，它是自编码器的一种变体。卷积自编码器通过添加一个或多个卷积层来表征输入，并通过添加一个或多个相应的解卷积层以生成输出。
