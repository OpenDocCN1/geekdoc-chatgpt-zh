在正则化框架下，多任务特征学习（Multi-Task Feature Learning，MTFL）方法（Argyriou等人，2006、2008）和多任务稀疏编码（Multi-Task Sparse Coding，MTSC）方法（Maurer等人，2013）将数据样本线性转换为\(\hat{\mathbf{x}}_i^j=\mathbf{U}^T\mathbf{x}_i^j\) 来构造共享特征表示，然后在其基础上学习线性函数 \(f_i(\mathbf{x}_i^j)=(\mathbf{a}^i)^T\hat{\mathbf{x}}_i^j+b_i\)。MTFL 方法定义目标函数为

\(\min_{\mathbf{A}, \mathbf{U}, \mathbf{b}} \sum_{i=1}^m \frac{1}{n_i} \sum_{j=1}^{n_i} l(y_i^j, (\mathbf{a}^i)^T \mathbf{U}^T \mathbf{x}_i^j + b_i) + \lambda \| \mathbf{A} \|_{\frac{1}{2}, 1} \quad \text{s. t.} \quad \mathbf{U} \mathbf{U}^T = \mathbf{I} \quad (9.1)\)

其中 \(l(\cdot, \cdot, \cdot)\) 是损失函数，\(\mathbf{b}=(b_1, \cdots, b_m)^T, \mathbf{A}=(\mathbf{a}^1, \cdots, \mathbf{a}^m)\)。容易看出在式 (9.1) 中 \(\mathbf{U} \in \mathbb{R}^{d \times d}\) 是正交矩阵。与 MTFL 方法不同，MTSC 方法的目标函数定义为

\(\min_{\mathbf{A}, \mathbf{U}, \mathbf{b}} \sum_{i=1}^m \frac{1}{n_i} \sum_{j=1}^{n_i} l(y_i^j, (\mathbf{a}^i)^T \mathbf{U}^T \mathbf{x}_j + b_i)\)
\(\text{s. t.} \quad \| \mathbf{a}^i \|_1 \leqslant \lambda \forall i \in [m], \| \mathbf{u}^j \|_2 \leqslant 1 \forall j \in [D] \quad (9.2)\)

其中 \(\mathbf{U}\) 的行数大于列数，并且基于 \(\ell_1\) 约束，\(\mathbf{A}\) 是稀疏的。

# 9.3.1.2 特征选择方法

特征选择方法学习从原始特征中选择一个子集作为所有任务的共享特征表示。总的来说，主要有两种方法来选择多任务特征。第一种方法是将参数矩阵 \(\mathbf{W}=(\mathbf{w}^1, \cdots, \mathbf{w}^m)\) 正则化以使其成为行稀疏矩阵，另一种方法是通过 \(\mathbf{W}\) 的概率先验使其成为行稀疏矩阵。

在所有用于多任务特征选择方法的正则化技术中，最广泛使用的技术是 \(\ell_{p,q}\) 正则化，其目标函数为

\(\min_{\mathbf{w}, \mathbf{b}} \sum_{i=1}^m \frac{1}{n_i} \sum_{j=1}^{n_i} l(y_i^j, (\mathbf{w}^i)^T \mathbf{x}_j^i + b_i) + \lambda \| \mathbf{W} \|_{p,q}\)
