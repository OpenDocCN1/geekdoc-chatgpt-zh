# 3.2.2 基于 Bregman 散度的正则化

除了使用 MMD 距离来测量域不变性，Si 等人（2010）提出了一种基于 Bregman 散度的正则化迁移子空间学习方法。其提出的目标函数形式如下：

min_F F(φ) + λD_w(φ(X_i) || φ(X_j)) (3.7)

其中，F(φ) 定义了一个任务特定目标，例如最小化分类误差。D_w(φ(x_i) || φ(x_j)) 是 φ(X_i) 和 φ(X_j) 之间的 Bregman 散度。给定一个映射函数 U、它的一阶导数 U' 及其倒数 ξ = (U')^-1，其 Bregman 散度定义如下：

D_w(φ(X_i) || φ(X_j)) = ∫ d(ξ(P_i^(k(x))), ξ(P_j^(k(x)))) dμ

其中， d(ξ(P_i^(k(x))), ξ(P_j^(k(x)))) = (U(ξ(P_i^(k(x)))) - U(ξ(P_j^(k(x))))) - P_j^(k(x)) (ξ(P_i^(k(x))) - ξ(P_j^(k(x)))) dμ 是 φ(x) 的勒贝格度量 (Lebesgue measure)。在映射空间中的源域和目标域的概率密度分别由 P_i^(k) 和 P_j^(k) 表示。

# 3.2.3 使用特定分布假设的度量

通过假设数据遵循高斯分布，Castrejon 等人（2016）研究使用特征激活的统计信息来学习迁移学习方法中的跨模态场景表示。他们提出的方法将用于具有不同风格的图像的跨模态卷积积神经网络和用于语言模型的多层感知机（Muti-Layer Perceptron，MLP）进行正则化，使得它们具有模态不可知的共享表示。图 3.3 展示了如何在图像和语言模型的不同域之间共享高层次的表示。

此外，其提出的方法进一步引入了关于激活函数的正则化项，使激活函数在中间隐藏层中具有跨模态的相似统计。设 P_i(h) 为第 i 隐藏层的激活函数的分布，正则化项则可以通过负对数来计算：R_i = -ln P_i(h; θ_i)，其中 θ_i 表示超参数。通过将 P_i 的正态分布实例化为 P_i(h; μ, Σ) ~ N(μ, Σ)，正则化项 R_i(h) 计算如下：

P_i(h; μ_i, Σ_i) = 1/2 (h - μ_i)^T Σ_i^-1 (h - μ_i)

另外，可以使用混合高斯分布来定义 P_i，它比单一的高斯分布更灵活。
