到一对编码和解码函数，使得在源域数据和目标域数据上的重建误差都很小。实际上，由于源域和目标域差异较大，因此可能源域数据中只有部分数据对目标域是有用的。同时中间域的情况也是类似的。因此，需要从中间域中选择有用的样本，并从源域中删除与目标域不相关的样本。SLA 通过最小化源域和中间域所选的样本以及目标域中的所有样本上的重建误差来学习得到编码和解码函数，需要最小化的目标函数表达如下：

$\mathscr{A}(f_c, f_d, v_S, v_T) = \frac{1}{n_S} \sum_{i=1}^{n_S} v_i^s \| \hat{x}_s^i - x_s^i \|_2^2 + \frac{1}{n_I} \sum_{i=1}^{n_I} v_i^t \| \hat{x}_t^i - x_t^i \|_2^2 + \frac{1}{n_T} \sum_{i=1}^{n_T} \| \hat{x}_T - x_T \|_2^2 + R(v_S, v_T)$ (11. 13)

其中，$\hat{x}_s, \hat{x}_t$ 和 $\hat{x}_t$ 分别是基于自编码器的 $x_s^i, x_t^i$ 和 $x_T^i$ 的重构版本，$v_S=(v_1^s, \cdots, v_n^s)^T, v_I=(v_1^t, \cdots, v_{n_I}^t)^T, v_S^j, v_I^j \in (0, 1)$ 分别是源域中的第 $i$ 个样本和中间域中的第 $j$ 个样本的选择指标。当其值为 1 时，将选择相应的样本，否则不予选择。$R(v_S, v_T)$ 是 $v_S$ 和 $v_T$ 上的正则化函数，通过将 $v_S$ 和 $v_T$ 的所有值设置为零以避免平凡解。在 SLA 中，$R(v_S, v_T)$ 被定义为 $R(v_S, v_T) = -\frac{\lambda_S}{n_S} \sum_{i=1}^{n_S} v_i^s - \frac{\lambda_I}{n_I} \sum_{i=1}^{n_I} v_i^t$。最小化该项相当于从源域和中间域中选择尽可能多的样本。两个正则化参数 $\lambda_S$ 和 $\lambda_I$ 则控制了该正则化项的重要性。

# 11. 4. 2. 3 感人辅助信息

通过求解式 (11. 13) 的最小化问题，可以通过 $v_S$ 和 $v_T$ 从源域和中间域中为目标域选择有用的样本，并同时通过编码函数 $f_c(x)$ 学习得到不同域中数据的高级隐性表示。但是，该学习过程属于无监督学习，所学习得到的隐性表示可能与目标域中的分类问题无关。这使得将辅助信息结合到不同领域的隐性表示的学习中尤为重要。对于源域和目标域，有标签数据可以作为辅助信息，而在中间域中则是没有标签信息的数据。SLA 将中间域上的预测视为辅助信息，并使用对预测的置信度来指导隐性表示的学习。具体而言，通过最小化以下函数将辅助信息融入学习过程中：

$\mathscr{A}(f_c, f_s, f_d) = \frac{1}{n_S} \sum_{i=1}^{n_S} v_i^s \ell(y_i^s, f_c(\hat{h}_s^i)) + \frac{1}{n_I} \sum_{i=1}^{n_I} \ell(y_i^t, f_c(\hat{h}_t^i)) + \frac{1}{n_I} \sum_{i=1}^{n_I} v_I g(f_c(\hat{h}_t^i))$ (11. 14)

其中，$f_c(\cdot, \cdot)$ 为能够输出分类概率的分类函数。$g(\cdot)$ 为熵函数，定义为 $g(z) = -z \ln z - (1-z) \ln(1-z)$，其中 $0 \leqslant z \leqslant 1$，用于选择中间域中具有高预测置信度的样本。
