格的隐私保证，但代价是噪声较大，导致性能下降（Chaudhuri 等人，2011；Bassily 等人，2014）。为了解决这个问题，最近 Dwork 和 Roth（2014）提出了一种松弛版本的 \(\epsilon\)-差分隐私，称为 \((\epsilon, \delta)\)-差分隐私，其中 \(\delta\) 度量隐私中的损失，其定义如下。

# **定义 15.2 ( \((\epsilon, \delta)\)-差分隐私 )** 如果对于任何两个输入数据集 \(\mathcal{D}_1, \mathcal{D}_2\)，随机机制 \(\mathcal{M}\) 的任一输出 \(t\) 满足 \(\mathbb{P}(\mathcal{M}(\mathcal{D}_1)=t) \leqslant e^\epsilon \mathbb{P}(\mathcal{M}(\mathcal{D}_2)=t) + \delta\)，则随机机制 \(\mathcal{M}\) 是 \((\epsilon, \delta)\)-差分隐私的。

# 15.2.2 隐私保护的正则化经验风险最小化

对于训练数据集 \(\mathcal{D}\)，正则化经验风险最小化选择一个假设空间 \(\mathcal{H}\) 中的预测器 \(f\)，将正则化经验损失最小化为

```
\(\min_{f \in \mathcal{H}} J(f, \mathcal{D}) = \frac{1}{n} \sum_{j=1}^n l(f(x_j), y_j) + \lambda r(f)\) (15.1)
```

其中正则项 \(r(f)\) 防止过拟合，\(\lambda\) 是正则化参数。正则化 ERM 方法在实践中被广泛使用，例如逻辑回归和支持向量机。为简单起见，在下文中我们只关注线性函数，即 \(f(x)=w^\top x\)。
