# 3.2.4 数据依赖的域差异度量

度量域差异有多种标准，但是，设计适用于所有应用问题的通用方法是非常困难的。为了解决这个问题，研究者对将域不变性作为学习问题进行了评估和研究。

Tzeng 等人（2015）通过引入域混淆损失（domain confusion loss）来学习域不变表示。这可以更好地利用在有标签的源数据上训练的分类器。首先，其提出的方法仅使用域标签进行二分类。然后该方法利用特定的特征表示 \(\theta_{repr}\)，进一步通过学习最佳分类器来评估域不变性。这个学习过程可以通过以下目标函数来完成。

```
\(\mathcal{L}_D(x_S, x_T; \theta_{repr}; \theta_D) = -\sum_d \mathbb{1}[y_d = d] \ln(q_d)\) (3.8)
```

其中，\(q = \text{softmax}(\theta_D^T f(x; \theta_{repr}))\)，\(y_d\) 表示示例所在的域。对于特定的域分类器 \(\theta_D\)，通过计算输出的预测域标签与域标签上的均匀分布之间的交叉熵来“最大程度地混淆”两个域的损失函数定义为

```
\(\mathcal{L}_D(x_S, x_T; \theta_{repr}; \theta_D) = -\sum_d \ln(q_d)\) (3.9)
```

式（3.8）和式（3.9）在训练过程中交替更新。
