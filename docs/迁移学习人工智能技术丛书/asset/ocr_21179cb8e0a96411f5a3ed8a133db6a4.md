# 17.2.3 NLP 应用中的多任务学习

MTL 方法同时从源域和目标域学习，整体的损失函数定义如下：

\( J = \lambda J_1 + (1 - \lambda)J_2, \) (17.1)

其中 \( J_1 \) 和 \( J_2 \) 为每个领域本身的损失函数。\( \lambda \in (0, 1) \) 是正则化参数，用于平衡两个域的损失函数。
