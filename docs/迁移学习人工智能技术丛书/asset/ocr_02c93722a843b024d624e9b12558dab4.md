其中 $\mathbb{E}h_{k1}$ 表示 $\mathbb{E}_{x_t^{j^\prime}, x_t^{j^{\prime\prime}}, h_k}(x_t^{j^\prime}, x_t^{j^{\prime\prime}}, x_s^j, x_s^{j^\prime})$，$h_k$ 通过第 $k_1$ 个核计算得出。

# 12.4.2 目标域判别能力

由于目标域中有标签的样本数量有限，因此根据 Yang 等人 (2007a) 提出的无标签判别标准，使用无标签的样本来帮助评估判别能力，即

\(\tau_e = \text{tr}(W_t^T S_t^N W_t) / \text{tr}(W_t^T S_t^L W_t)\)

其中 $S_t^L = \sum_{j,j'=1}^{k_t'} \frac{H_{y^{j\prime}}}{(\nu_t^{j\prime})^2} (x_o^j - x_o^{j\prime})(x_o^j - x_o^{j\prime})^T$ 是局部散射协方差矩阵，$S_t^N = \sum_{j,j'=1}^{k_t'} \frac{\mathcal{K}(x_o^j, x_o^{j\prime}) - H_{y^{j\prime}}}{(\nu_t^{j\prime})^2} (x_o^j - x_o^{j\prime})(x_o^j - x_o^{j\prime})^T$ 是非局部散射协方差矩阵，$H_{y^{j\prime}}$ 定义为
\[H_{y^{j\prime}} = \begin{cases} \mathcal{K}(x_o^j, x_o^{j\prime}) & x_o^j \in \mathcal{N}_t(x_o^{j\prime}) \text{ 且 } x_o^{j\prime} \in \mathcal{N}_t(x_o^j) \\ 0 & \text{其他} \end{cases}\]

值得注意的是，\(\tau_e\) 的计算取决于核。由从第 $k$ 个核 $\mathcal{K}_t$ 得到的 $\tau_{e(k)}$，\(\tau_e\) 可以表示成 \(\tau_e = \sum_{k=1}^{N_k} \beta_k \tau_{e(k)} = \boldsymbol{\beta}^T \boldsymbol{\tau}_e\)，其中 $\boldsymbol{\tau}_e = [\tau_{e(1)}, \cdots, \tau_{e(N_k)}]^T$。

# 12.4.3 优化问题

通过结合上述两个因素建立反射函数 $f$，可以将学习 $f$ 的优化问题表述为

\(\begin{aligned} \boldsymbol{\beta}^* \cdot \lambda^* \cdot \mu^* \cdot b^* = & \arg \min_{\boldsymbol{\beta}, \boldsymbol{\lambda}, \mu, b} \sum_{n=1}^{N_t} \mathcal{L}_2 \left( \boldsymbol{\beta}^T \hat{\mathbf{d}}_n + \boldsymbol{\lambda}^T \hat{\mathbf{Q}} \boldsymbol{\beta} + \frac{\mu^T}{\boldsymbol{\beta}^T \boldsymbol{\tau}_e} + b, \frac{1}{l_n} \right) + \gamma_1 R(\boldsymbol{\beta}, \lambda, \mu, b) \\ \text{s.t.} & \quad \beta_n \geqslant 0, \forall k \in \{1, \cdots, N_t\}, \lambda \geqslant 0, \mu \geqslant 0 \end{aligned}\) (12.2)

其中 \(f = 1 / (\boldsymbol{\beta}^T \hat{\mathbf{d}}_n + \boldsymbol{\lambda}^T \hat{\mathbf{Q}} \boldsymbol{\beta} + \frac{\mu^T}{\boldsymbol{\beta}^T \boldsymbol{\tau}_e} + b)\)，两个变量 \(\lambda\) 和 \(\mu\) 用于平衡 \(f\) 中的三个项，\(b\) 是偏移量，\(\mathcal{L}_2(\cdot)\) 是 Huber 回归损失 (Huber, 1964)，正则化函数 \(R\) 定义了 \(\ell_2\) 范数正则化，\(\gamma_1\) 是正则化参数。问题 (12.2) 结合了域之间的差异，包括 MMD 距离 \(\boldsymbol{\beta}^T \hat{\mathbf{d}}_t\) 和距离方差 \(\boldsymbol{\beta}^T \hat{\mathbf{Q}} \boldsymbol{\beta}\)，以及目标域中的判别标准 \(\boldsymbol{\beta}^T \boldsymbol{\tau}_e\)，来近似性能改进比 \(l_e\)。
