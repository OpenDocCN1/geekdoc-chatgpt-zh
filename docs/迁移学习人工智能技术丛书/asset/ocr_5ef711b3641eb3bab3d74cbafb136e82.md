# 1.2 迁移学习：定义

首先，我们遵循文献（Pan 和 Yang, 2010）中的符号定义“域”“任务”以及“迁移学习”。域 D 由两部分组成：特征空间 X 和边缘概率分布 P^X，其中每一个输入样本为 x ∈ X。一般来说，两个不同的域具有不同的特征空间或者边缘概率分布。在一个特定的域 D={X, P^X} 中，任务 T={Y, f(·)} 由标签空间 Y 和函数 f(·) 组成。函数 f(·) 是预测函数，能够对未知的样本 {x*} 进行标签预测。从概率的角度看，f(x) 等于于 P(y|x)。在分类问题中，标签可以是二值的，即 Y={-1, +1}，也可以是离散值，即多个类。在回归问题中，标签具有连续值。

为简单起见，我们现在只关注只有一个源域（source domain）D_s 和一个目标域（target domain）D_t 的情况，两个域的场景是目前为止在文献中最普遍的研究对象。具体地说，我们定义 D_s={(x_s_i, y_s_i)}_{i=1}^{n_s} 为源域有标签数据，其中 x_s_i ∈ X_s 和 y_s_i ∈ Y_s 分别为数据样本和对应的类别标签。类似地，D_t={(x_t_i, y_t_i)}_{i=1}^{n_t} 为目标域有标签数据，其中 x_t_i ∈ X_t 和 y_t_i ∈ Y_t 分别为目标域中的输入和输出。在多数情况下，0 << n_t << n。基于以上定义的符号，迁移学习定义如下（Pan 和 Yang, 2010）。

定义 1.1 (迁移学习) 给定源域 D_s 和学习任务 T_s、目标域 D_t 和学习任务 T_t，迁移学习的目的是获取源域 D_s 和学习任务 T_s 中的知识以帮助提升目标域中的预测函数 f_t(·) 的学习，其中 D_s ≠ D_t 或者 T_s ≠ T_t。
