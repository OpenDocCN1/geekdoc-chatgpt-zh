# 11.4.2.4 全局目标函数

通过将式（11.13）和式（11.14）结合起来，可以得到如下的全局目标函数：

```
\min_{\Theta, v} \mathscr{J} = \mathscr{J}_1 + \mathscr{J}_2 \quad s.t. \quad v_S, v_l \in \{0, 1\} \tag{11.15}
```

其中 \( v=\{v_S, v_l\}, \Theta \) 表示函数 \( f_c(\cdot, \cdot), f_l(\cdot \cdot) \) 和 \( f_d(\cdot \cdot) \) 的所有参数。

为了解决上述优化问题，SLA 使用块坐标下降（Block Coordinate Descent，BCD）方法，其中在每次迭代中，每个块中的变量会被优化，同时保持其他变量固定。在问题（11.15）中存在两种变量块：\(\Theta\) 和 \(v\)。当 \(v\) 中的变量固定时，可以使用反向传播算法更新 \(\Theta\)，该算法可以容易地计算梯度。或者，当 \(\Theta\) 中的变量固定时，可以得到 \(v\) 的解析解，如下所示：

```
v_S = \begin{cases} 1 & \ell(y_S^i, f_c(f_c(x_S^i))) + \| \hat{x}_S^i - x_S^i \|_2^2 < \lambda_S \\ 0 & \text{其他} \end{cases} \tag{11.16}
```

```
v_l = \begin{cases} 1 & \| \hat{x}_l^i - x_l^i \|_2^2 + g(f_c(f_c(x_l^i))) < \lambda_l \\ 0 & \text{其他} \end{cases} \tag{11.17}
```

基于式（11.16），可以看到对于源域中的数据，在优化过程中只会选择那些具有低重建误差和低训练损耗的数据。同样，基于式（11.17）可以发现，对于中间域中的数据，将仅选择具有低重建误差和高预测置信度的数据。

该方法的有效性体现在以下两个方面：第一，当固定 \(\Theta\) 更新 \(v\) 时，源域中的“无用”数据将被删除，并且将选择可以连接源域和目标域的中间数据用于训练；第二，当固定 \(v\) 更新 \(\Theta\) 时，仅针对所选的“有用”的数据样本训练模型。算法 11.2 总结了解决全局目标函数公式（11.15）的学习过程。

# 算法 11.2 选择学习算法 (SLA)

+   1) 输入：\(\mathscr{S}, \mathscr{T}, \mathscr{I}\) 中的数据，参数 \(\lambda_s, \lambda_l\) 和 \(T\)
+   2) 初始化 \(\Theta, v_S=1, v_l=0\) // 使用所有源域数据
+   3) while \(i < T\) do
+   4) 基于反向传播算法更新 \(\Theta\) // 更新网络
+   5) 基于式（11.16）和式（11.17）更新 \(v\) // 选择“有用”的样本
+   6) \(i=i+1\)
+   7) endwhile
+   8) 输出：\(\Theta\) 和 \(v\)
