# 作业辅导（教辅行业）

需求：

孩子小学四年级，被学校老师要求辅导孩子作业。发现自己不懂如何教学？也不懂如何以小孩的视角分析问题。眼看要到半夜了，忍不住急躁想要动手。

+   - ☐ 第一步：知识点锚定
+   - ☐ 第二步：分步教学引导
+   - ☐ 第三步：互动练习设计
+   - ☐ 第四步：错误分析与纠正
+   - ☐ 第五步：能力拓展衔接

```
# 第一步
我需要为孩子讲解「鸡兔同笼问题」，当前题目是：[兔子有头35个，脚94只，求鸡兔数量]，请按照以下特殊输出辅导方案：
- 核心概念：用生活化类比讲解问题本质（参考：将鸡兔化作带不同轮子的玩具车）
- 适配方法：列出四年级可理解的2种解法（需排除方程法，优先假设法/抬脚法）
- 认知衔接：说明该问题与已学知识的联系（如乘法分配律，两步计算应用题）

# 第二步
基于以上方案，请生成分步讲解内容，要求：
1. 情景导入：用孩子熟悉的场景引入（如宠物店送货员数据动画）
2. 可视化辅助：
图表法：指导绘制简略鸡兔并标注脚数
道具法：用积木/硬币模拟头脚数量
3. 思维手架：
◎ 关键提问：‘如果全是鸡会怎样？多出的脚是谁的？’
◎ 误区预判：提前分析‘直接除法94÷4’的错误原因
4. 语言技巧：
将‘假设’转化为孩子能理解的指令，每步结束用‘你发现什么规律？’引导观察

# 第三步
请基于当前题目拓展：
1. 梯度训练：
基础级：头数10/脚数28（数小易计算）
进阶级：三轮车与汽车轮子问题（同类变形）
2. 游戏化训练：
角游戏：孩子扮鸡兔子，家长数脚发现矛盾
卡片游戏：头/脚卡配对找出错误组合
3. 生活迁移：
设计超市购物问题（如买5元/3元面包共花费32元）

# 第四步
孩子出现以下错误时，请给出针对性指导方案：
1. 典型错误：
类型1：脚数直接除以4得到鸡数（未理解假设思维）
类型2：调换数量的步长错误（如每次增减3只）
2. 纠正策略：
对类型1：用‘全鸡假设法’分步动画演示
对类型2：在表格中用颜色标注变化规律
3. 激励话术：
‘你发现了脚数变化规律，太棒了！再来试试…’
‘数学家小时候也会犯这个错，我们来看欧几里得的方法…’

# 第五步
请说明该问题对后续学习的意义：
1. 思维增量：为五年级学习方程提供认识基础
2. 方法迁移：列举两个可应用同样方法解决的问题（如租船问题/差额得分问题）
3. 延伸资源：推荐适合四年级的数学启蒙动画（标注B站相关关键词）
```
