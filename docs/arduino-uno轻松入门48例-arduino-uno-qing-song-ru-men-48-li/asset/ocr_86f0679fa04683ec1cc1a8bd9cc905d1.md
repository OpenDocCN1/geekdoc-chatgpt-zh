# 1.有源蜂鸣器与无源蜂鸣器

蜂鸣器是一种能发出蜂鸣声的电子器件，按是否带振荡电路可分为有源蜂鸣器与无源蜂鸣器。有源蜂鸣器是内部带有振荡电路的蜂鸣器，接通直流电源即可发出声音，但只能发出固定频率（1.5kHz～2.5kHz）的声音，两只引脚之间的电阻为几百欧。无源蜂鸣器是内部不带振荡电路的蜂鸣器，接通直流电源不能发出声音，但接在音频电路中能发出声音，发声频率由音频信号的频率决定（与电磁扬声器类
