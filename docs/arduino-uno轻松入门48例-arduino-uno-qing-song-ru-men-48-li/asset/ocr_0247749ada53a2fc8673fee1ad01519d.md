# (2) 实验结果

实现单超声波测距模块扫描型避障小车行走功能。当小车右前方有障碍物时，右侧绿色LED灯点亮，小车左转弯；当小车左前方有障碍物时，左侧红色LED灯点亮，小车右转弯；当小车左前方和右前方都有障碍物时，左侧红色LED灯和右侧绿色LED灯均点亮，小车先后退，然后左转或右转；当小车前方无障碍物时，左右两侧的LED灯均不亮，小车前进。
