# 2.10 可调节变换速度的跑马灯

用编程方式制作的跑马灯， 每只LED灯都能被单独点亮与熄灭， 14只LED灯点亮与熄灭的时间间隔与时间顺序都可以进行单独设置与控制。 程序一旦调试完成， 它们能长时间、 周而复始、 有条不紊地工作。 不仅如此， 还可以通过编程随意调节跑马灯的变换速度呢！
