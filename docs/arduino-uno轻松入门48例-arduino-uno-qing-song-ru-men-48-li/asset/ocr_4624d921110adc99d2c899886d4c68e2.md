# 2.28 两位数字显示倒计时器

我们学习了两位数字显示计时器与倒计时器，那么如何编程设计可设置倒计时时间、能定时提醒的两位数字显示倒计时器呢？

# 2.28.1 实验描述

用两位共阴极数码管显示数字，2只轻触开关设定倒计时时间，1个蜂鸣器发声，实现定时提醒功能。开机后默认倒计时时间为10分钟。
