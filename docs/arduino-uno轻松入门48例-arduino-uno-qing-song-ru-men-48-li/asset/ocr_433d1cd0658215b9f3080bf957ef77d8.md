# 2.25.2 知识要点

在十字路口，通常会设置4组红黄绿交通信号灯，每个人都必须遵循“红灯停，绿灯行”这一交通规则。红黄绿交通信号灯的变换规则如下：东西向为绿灯时，南北向为红灯；东西向为红灯时，南北向为绿灯；红绿灯切换过程中点亮黄灯，给已经越过停止线的行人和车辆通过十字路口的时间。绿灯路口通行时间等于红灯路口等候时间。为减少交通事故，红黄绿交通信号灯广泛应用于各个交通路口，成为指挥交通车辆与行人的常见、有效手段。
