度一般是整数，例如平面上所画的一个矩形图案就是一个 2 维的图形，空间中的球体呈现出 3 维结构；在分形几何中，几何图形的维度都不是整数，而是用分数来表示，这个维度又被称为 Hausdorff-Becikovich Dimesion（豪斯多夫-贝赛科维奇维度），于 1918 年由数学家豪斯多夫所提出，通过豪斯多夫-贝赛科维奇维度可以给一个任意复杂的点集合（包括分形）赋予一个维度。
