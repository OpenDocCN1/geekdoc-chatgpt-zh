接下来就可以安装 TensorFlow 了。在虚拟环境 TensorFlowGPU 上单击 ▶ 图标，在下拉菜单中选择 “Open Terminal” 选项，打开一个终端窗口，此时目前前面显示 ( tensorflow_gpu ) 为虚拟环境名，在终端输入 pip install tensorflow-gpu，按 Enter 键后安装开始，如图 3-25 所示。
