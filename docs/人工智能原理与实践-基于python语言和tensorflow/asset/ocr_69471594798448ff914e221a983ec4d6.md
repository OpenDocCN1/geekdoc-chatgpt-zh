接下来就可以安装 TensorFlow 了。在虚拟环境“TensorFlow”上单击图标，在下拉菜单中选择 Open Terminal 选项，如图 3-12 所示。

![](bbox=[0.18, 0.14, 0.82, 0.35])

![](bbox=[0.18, 0.45, 0.82, 0.63])
