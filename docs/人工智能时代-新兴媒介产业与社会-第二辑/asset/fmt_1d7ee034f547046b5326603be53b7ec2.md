
# 研究设计与测量

## 1) 乡村居民社会资本

依旋转后各题项的因素载荷大小，我们将两个因子分别命名为**桥接型社会资本**（因子1）和**黏结型社会资本**（因子2）。乡村居民桥接型社会资本的克朗巴哈系数（`Cronbach's α`）是0.71，黏结型社会资本的`Cronbach's α`是0.75。因子分析的`KMO`值是0.84，检验的`sig`值为0.00，因子总共解释了34.3%的方差。

# 三、研究发现

## 1. 乡村居民社交网络使用行为-心理现状

在乡村居民社交网络使用行为的表现上，乡村居民网络自我表露（`M=3.49，SD=0.69`）、网络信息分享（`M=3.70，SD=0.66`）和网络娱乐活动（`M=3.46，SD=0.66`）的均值都高于中值3，乡村居民的网络社会临场感（`M=3.49，SD=0.64`）的均值也高于中值3。为了更进一步检测乡村居民的社交网络使用行为-心理现状，研究对网络自我表露、网络信息分享和网络娱乐活动、网络社会临场感做单样本`t`检验。检验结果显示（见表6），乡村居民的网络自我表露（`t=25.59，P<0.001`）、网络信息分享（`t=38.09，P<0.001`）和网络娱乐活动（`t=25.02，P<0.001`）显著高于量表中值3，同时乡村居民的网络社会临场感（`t=27.55，P<0.001`）也显著高于量表中值3，这也表明乡村居民具有较强的网络自我表露、网络信息分享和网络娱乐活动行为，且具有积极的网络社会临场感。

## 2. 乡村居民社会资本现状

乡村居民的桥接型社会资本（`M=3.47，SD=0.66`）和黏结型社会资本（`M=3.71，SD=0.63`）的均值都高于3。同样地，单样本`t`检验也显示（见表6），乡村居民的桥接型社会资本（`t=21.08，P<0.001`）和黏结型社会资本（`t=22.35，P<0.001`）均显著高于量表中值3。这表明乡村居民具有较高的桥接型社会资本和黏结型社会资本。比较而言，乡村居民的桥接型社会资本显著低于黏结型社会资本，这表明在日常生活中，乡村居民的黏结型社会资本依然是他们主要的资本建构。

## 3. 主要研究变量的相关关系

表5显示，乡村居民的社交网络使用行为（网络自我表露、网络信息分享和网络娱乐活动）均与乡村居民的社会资本（桥接型社会资本和黏结型社会资本）呈显著正向相关关系，而且网络社会临场感与乡村居民的桥接型社会资本和黏结型社会资本之间也存在显著正向相关关系。这一结果为回答研究问题提供了基础。

## 4. 社交网络使用对乡村居民社会资本的影响

### 1) 初始模型

通过对初始模型的估计，其输出结果显示`X²`的值为756.32，`P`值为0.000，小于0.05，拒绝原假设。且卡方值和自由度的比值为3.21，超过标准3。其余指标达到模型拟合标准，具体表现为：`RMR`值为0.05，`GFI`值为0.89，`RMSEA`值为0.07，`NFI`值为0.90，`IFI`值为0.91，`CFI`值为0.89，`AGFI`值为0.88。由此可看出，初始模型不太理想，需要修正。根据模型修正指标（`MI`），需要进一步对模型中各变量的误差间建立共变关系，从而能够减少卡方值，提高模型拟合度。

**社交网络使用对乡村居民桥接型社会资本的影响。** 在社交网络使用行为上，网络信息分享（`β=0.07，P<0.05`）和网络娱乐活动（`β=0.13，P<0.01`）能够正向显著影响乡村居民的桥接型社会资本，而网络自我表露不能影响乡村居民的桥接型社会资本。在社交网络使用心理上，网络社会临场感对乡村居民桥接型社会资本呈现正向显著影响（`β=0.08，P<0.05`）。

# 四、结论与讨论

本研究对中国35个乡镇的乡村居民进行问卷调查，从社会资本理论和社会临场感理论视角出发，分析了不同社交网络使用行为对乡村居民社会资本的影响，以及社交网络使用心理对乡村居民社会资本的影响，得出以下4个结论：

**第一，网络自我表露能够带来乡村居民黏结型社会资本的建构，而对于桥接型社会资本没有影响。** 网络自我表露是个体使用媒介行为的一种对外展示行为，这种行为在于将自我的一些信息呈现给他人的一种行为过程[33]。对于乡村居民而言，他们的自我表露行为基本发生于微信、QQ等高社交型媒介中，而在这类型的媒介使用中，他们基本只会与强关系个体保持交往。一方面通过社交网络进行自我表露，能够更好地促进乡村居民与好友之间的关系，提高交往的亲密性，利于获得情感性的帮助。另一方面，网络自我表露有助于自我展现，让家人和亲朋好友更好地了解自己，增进彼此之间的信任度，利于获得实质性的帮助。因此，网络自我表露行为对于乡村居民建构强关系型社会资本，而对于异质性较强，交往较为宽泛与浅层的弱关系型社会资本没有明显提升。

**第二，网络信息分享行为均能有助于建构乡村居民的黏结型社会资本和桥接型社会资本。** 乡村居民会经常将一些自己获得的信息进行分享，而这种分享会发生在熟关系网络交往中，也会发生于异质性较高的弱关系交往圈子中。信息分享行为作为个体自我价值和能力的体现，乡村居民选择将信息进行分析时是希望信息能够帮助有需要的他人或者起到传播甚至警醒的作用，这种行为本身带有一种感情倾向性，体现了利他主义的精神，而这种利他主义的行为背后，也存在着自我价值和能力凸显的心理，希望能够借由这种信息分享行为收获认可和交往的可能。此外，网络信息分享行为并不是一种由某一个体固定发生的行为，而是汇聚在一起的个体均都会无私分享自己所获得的信息，这种信息共享行为也能带来个体资本转换与反馈的意识。因此，网络信息分享行为不仅有利于强化黏结型社会资本，也能对弱关系型社会资产生积极增强效应。

**第三，网络娱乐活动能够带来乡村居民桥接型社会资本，但对黏结型社会资本没有影响。** 传统媒体时代，乡村居民能聚在一起观看电视，这种娱乐行为能够聚合乡亲邻里一块共享娱乐，分享快乐，而现在的乡村社会，几乎每个村民都拥有了智能手机，便于他们寻求个人化的娱乐需求，使得网络娱乐行为逐渐变得私人化。网络娱乐活动重在个体自我身心的放松，以及打发时间，这种行为较少会触及别人对个体情感上的支持与实质性的帮助，因此对于黏结型社会资本的建构难以产生影响。但是对于乡村居民而言，网络娱乐活动可以有助于桥接型社会资本的提升，这是因为乡村居民在进行网络游戏行为时，往往会接触异质性较高、交往较为宽泛与浅层的弱关系，而通过这种娱乐行为的不断强化，弱关系会逐渐脱离游戏社区，进入乡村居民的高语境社交网络中，形成相对固定与持久的娱乐伙伴关系。

**第四，高网络社会临场感能带来乡村居民黏结型与桥接型社会资本的提升。** 中国乡村居民能够通过社交网络感知到他人的网络“真实”性存在，也能够在同乡建立的社会网络间感知事件或者信息的真实性与重要性，这种感知会让他们产生“感同身受”或者同情心和同理心，促使他们成为行动者，从而产生互惠规范。罗伯特·D·帕特南提到互惠规范是一种高度生产性的社会资本[34]。当个体在执行某一行为时可能只是短期的利他，但长期上这些行为可能会使参与者受益[35]。乡村居民在社交网络中感知到的社会临场感，能拉近他们与他人的距离，也能让具有相同身份归属（如少数民族，或者宗教信徒）的他们将短期的利他与长期的利己结合起来，强化了人际信任，进而有助于不断提升黏结型社会资本总量。

另外，还需注意的是，作为社交网络使用的心理因素，网络社会临场感对于乡村居民社会资本发挥的积极作用要大于社交网络使用行为。这也表明，我们在关注技术所带来的行为决定论时，也更应该关注社交网络使用的社会心理因素给乡村居民带来的较大影响。

本研究考察了社交网络使用行为和社交网络使用心理对乡村居民社会资本的影响，而社交网络使用动机、使用时间与网络交往投入度等因素，也是影响乡村居民社会资本的重要因素，对此需要再进一步探讨。此外，本研究考察了乡村居民社会资本的两个现实维度，而对于乡村居民网络社会资本的研究未能进行揭示，这些不足之处也是未来值得继续讨论的方向。
