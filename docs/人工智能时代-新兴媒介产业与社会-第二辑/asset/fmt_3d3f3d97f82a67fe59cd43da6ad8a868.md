# 前言

2019年10月26日，以“人工智能时代：新兴媒介、产业与社会”为主题的第六届新媒体国际论坛在上海交通大学顺利举办。

新兴媒介已成为时代的发展趋势，中国互联网络信息中心(`CNNIC`)发布的第45次《中国互联网络发展状况统计报告》显示，截至2020年3月，中国网民规模已经达到9.04亿人，互联网普及率达64.5%。当技术以前所未有的速度不断更新并嵌入我们日常生活中时，传播成为不同产业以及社会个体之间的连接方式，也因而引出了各种各样的问题：个体的媒介使用行为呈现什么样的新特征？民众的媒介素养现状如何？新闻传播的相关行业如何应对新的变化？新闻教育、新闻传播学研究将何去何从？新的现象和问题亟待我们去探讨。新闻传播学者立足于传播视角，围绕着这些议题从不同角度提出了他们的思考和结论。

本书为第六届新媒体国际论坛的优秀论文选第二辑，从媒介生产和使用角度出发，探讨新兴媒介对产业与社会的影响，研究话题包括新闻研究与新闻教育、智能媒体时代的产业转型、媒介使用、媒介素养等。

从生产角度出发，本书关注新兴媒介对新闻、广播电视等行业的影响，分析了新兴媒介背景下新闻人才的培育机制。王璐瑜和申琦通过问卷调查法与实验法，运用信息精细化加工可能性模型探讨了媒介多任务行为对新闻阅读和假新闻判别的影响；张超则基于国内社交平台假新闻现象，提出了“算法－利益相关者”的协同治理模式；易龙和李晨瑜从“课程产品研发”理念出发，在传统新闻类课程存在问题的基础上，重新设计了卓越新闻传播人才培养新机制；郑晓迪和陈心怡则聚焦美国报业数字化转型背景下新闻教育和人才培养的改革措施。

在新兴媒介背景下，本书讨论了媒介发展的两个趋势：“融媒体”和“智能化”。本书收录了4篇相关文章，分别从不同的角度探讨了智媒时代的产业转型。李海东和许志强在分析人工智能与传媒业结合的基础上，探讨了媒体智能化变革路径；赵莉和张小玉基于浙江安吉新闻集团“爱安吉”客户端的发展战略和创新模式，展望融媒App的发展方向；李舒霓基于央视抖音的数据分析，讨论主流媒体在智能传播技术下的发展和视觉化新闻的未来；许志强等人探讨了新一轮智能技术集群为传媒产业带来的创新，并提出了加快构建广播电视媒体内容“智”造支撑体系的路径。

媒介使用也是历届新媒体国际论坛的关注重点。在本书中，有几篇文章关注了不同社会群体的媒介使用及效果，包括新上海人、乡村居民、农技员等。白如金和李政宏针对新上海人的社交媒介使用与社会责任认同的关系构建了一个有调节的中介模型，重点考察了社会融入在两者中的中介作用以及对社会信任的调节作用；金恒江等研究了乡村居民社会资本的影响因素，涉及社交网络使用行为、网络信息分享行为、网络娱乐活动和社交网络使用心理等因素。

本书还关注媒介使用者应如何提高媒介素养以适应新兴媒介的发展变化。谢金文和黄谷香聚焦于移动传播和人工智能时代人们的新闻素养的提升目标、内容和要求；付玉则对南非媒介素养的教育发展情况及原因进行剖析，为中国的媒介素养教育提供启发性的思考；蒋钰和李有对沪滇两地学校进行田野调查，关注城乡儿童数字素养差异背后的多元因素，并为教育扶贫、推进教育信息化提出对策建议。

人工智能时代，新兴媒介技术触发新的需求和产业样态，学界和社会共同面临一系列机遇和挑战。在这样的背景下，促进跨学科和新视野、新理论的发展具有重要意义。上海交通大学媒体与传播学院依托上海交通大学强大的工科资源，贯彻文理交叉的办学理念，积极推进对新媒体、新媒介技术以及新问题的研究和讨论。期望本论文集的出版能促进新闻传播学者以及业界更广泛的思考和对话，推动传播学的繁荣发展。

# 新闻研究与新闻教育

## 媒介多任务行为对新闻阅读及假新闻判别的影响

**王璐瑜　申　琦**

**【摘　要】**　本文通过问卷调查法与实验法等混合研究方法，以上海大学生为研究对象，运用心理学中的信息精细化加工可能性模型(`ELM`)探讨人们在智能手机新闻客户端阅读新闻时，日常的媒介多任务使用与社交网络假新闻判别力之间的关系。研究发现：日常媒介多任务程度越高的同学，对假新闻的判别能力越差；在客户端阅读新闻时的注意力持续在这一作用过程中起到部分中介作用，产生间接效应；而信息的精细化加工程度与假新闻判别呈负相关关系。

**【关键词】**　社交网络，假新闻，注意力持续，信息精细化加工

技术的发展不断改变着媒介内容的生产方式。智媒时代，在算法技术与大数据的驱动下，新闻的生产、传播与消费都趋于自动化、智能化。然而，随之而来的是日益泛滥、危害严重的社交网络假新闻问题。假新闻在转发层级、传播人数与扩散范围上都胜于真实新闻，而这与公众对新闻信息的处理与再次传播密切相关。[1]

新技术的出现同样也改变着人们的媒介体验。日常生活中，通过智能手机上各类社交应用软件、新闻客户端等平台获取新闻已成为常态。[2]而在丰富的媒介环境下，人们已习惯于同时卷入多种媒介活动中，比如边看电视边刷手机，边听音乐边看微博等。这种媒介多任务使用行为(`media multitasking`)[3]，有可能带来注意分散、心智游移等负面结果。[4]那么，当人们在手机上阅读新闻时，有限的注意力是否会受到其他媒介活动的干扰，并影响其对新闻信息的接受与判断，进而导致社交网络假新闻泛滥，是本文将要探讨的问题。

本文以上海大学生为对象，依据心理学中的信息精细化加工可能性模型(`ELM`)，运用实验法、问卷调查法等混合研究法，考察其在手机上阅读新闻时，日常的媒介多任务使用、注意力持续、信息精细化加工与假新闻判别之间的关系，以期从受众认知角度为社交网络假新闻治理提供经验数据与理论参考。

### 一、文献综述

#### 1. 社交网络假新闻

假新闻并不是一个新名词，随着智能技术的发展，其产生过程和社会影响均与大众传播时代表现出明显不同。[5]关于社交网络假新闻(`fake news/false news`)尚无明确的定义。已有研究认为，它是“编造的信息，在形式上模仿新闻，但缺乏新闻媒体确保信息准确和可信的规范程序和意图”，[6]特点是：利用误导性的信息，来获得经济、政治以及其他方面的利益；[7]信息源头既可以是专业媒体又可以是社交网络。[8]

社交网络假新闻主要是指广泛传播于社交网络，失实或毫无根据的新闻事件。来源既包括取得新闻采编资质的专业新闻媒体(如传统媒体、自媒体的公号等)，也包括取得新闻转载权的网络平台(如今日头条等各类新闻客户端)。

以往有关社交网络假新闻的研究，主要考察以下4部分内容。
① 假新闻的文本特征：如借助“权威事实”、用日常事例增强可信度等；[9]
② 传播特点：如网络密度、意见领袖、好友评论等对传播的作用与影响；[10-11]
③ 从新闻的生产分发、技术实现等层面发现和治理社交网络假新闻：如重构新闻专业主义规范，[12]用自然语言处理技术甄别图片与文本的真实性等；[13]
④ 通过媒介素养教育提高公众的新闻鉴别能力等。[14]

也有研究从受众认知层面考察人们接受和转发社交网络假新闻的原因，[15-16]认为“偏见”的存在使人们感觉自己现有知识结构受到挑战，往往无法重新接受新信息。[17]而社交网络中的推荐算法机制会强化这种选择性接触，增强了人们对假新闻的接受程度。[18]戈登·彭尼库克(Gordon Pennycook)等人对此持不同意见，通过认知反射测验发现，人们无法判别社交网络假新闻的原因是没有对新闻进行充分的分析、推理，社交网络或许加剧了人们对“直觉的依赖”。[19]

无论“偏见”还是“直觉的依赖”都提示了社交网络假新闻的接受与传播跟人们的信息处理方式有着密切的关系。遗憾的是，已有研究止步于此，未能深入揭示人们如何通过“偏见”和“直觉的依赖”来接受社交网络假新闻。这种“懒惰”的信息处理方式，[19]真的是对媒介技术的依赖，还是另有原因？

#### 2. 媒介多任务

作为影响人们信息处理方式与效果的重要因素之一，[20]媒介多任务受到了新闻传播学、心理学、教育学等诸多领域学者的关注。具体来说，媒介多任务是指“在媒介使用的同时，伴随其他非媒介活动的行为；或者在同一时间段内同时使用多个媒介的行为”，[21]使用多个媒介的行为既包括在一个时间段内使用不同的媒体，也包括在同一个设备中进行多种媒体活动。[3]

关于媒介多任务，新闻传播学研究重点探讨了媒介多任务环境下的信息传播效果问题。其中又可以分为两类：一是比较人们在单一或多个媒介任务环境中的即时任务表现，发现在视频环境中阅读纸质文本时，人们理解与反驳信息的能力会减弱，更容易被说服；[22]阅读、观看或收听政治新闻时，更频繁地参与另一种媒介任务的人，理解政治问题的水平更低。[23]二是比较人们长期在媒介多任务环境下的表现，发现阅读健康类信息时，日常媒介多任务程度高的人对说服类健康信息的接受度较高，有更强的行为意愿。[24]

上述研究表明，媒介多任务使用能够影响人们信息处理的效果。在媒介多任务使用日渐成为一种生活方式的今天，[25]笔者认为，考察它与人们如何处理社交网络假新闻之间的关系十分必要。结合我国公众接触社交网络新闻的主要方式，笔者以大学生为研究对象，考察在阅读手机新闻时，日常媒介多任务使用程度与人们社交网络假新闻判断力之间的关系。假设1为：在手机上阅读新闻时，个人的日常媒介多任务程度越高，其对假新闻的判别力越差。

#### 3. 注意力持续

在已有探讨媒介多任务如何影响人们信息接受的研究中，提及了认知注意在其中的作用。如发现在多屏干扰的环境中，人们如果对主要信息投射足够多的注意力(注视足够长的时间)，其对信息的记忆、理解以及反驳力，与在无干扰的单屏环境下无明显差异。[22]心理学研究已经指出，日常媒介多任务程度越高的人越容易分心；[20]媒体多任务可能会削弱个体在一段时间内持续关注特定任务目标的能力。[4]据此，我们提出以下假设：在手机上阅读新闻时，个人的日常媒介多任务程度越高，其注意力持续性越差，对假新闻的判别力越差(假设a)。
