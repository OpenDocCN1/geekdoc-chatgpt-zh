
# 从媒介角度看“VR+媒体”

从媒介角度看，“360度＋景深”模拟真实世界，用户可通过外接设备与虚拟环境实现交互，从而实现与虚拟世界的“零距离”接触。“VR＋媒体”也促使内容从过去传统媒体的三个维度（“平面两个维度＋时间维度”）提升到五个维度（“空间三维度＋时间维度＋虚拟平行世界”），并带动包括影视、游戏、直播、教育、电商、房地产等在内的内容结构与变现形式的变革。例如，央视新闻客户端于2019年2月推出了聚焦于全景图片新闻、VR视频新闻的“VR频道”，允许用户通过超链接进入VR场景。

## 4. “区块链+媒体”

区块链（`blockchain`）是一种利用“数据可信”“价值传递”“去中心化”“智能合约”等功能解决多方交易可信可控问题的新型应用模式。区块链从2008年提出以来，已先后走过1.0时代（以比特币为代表的虚拟货币，如转账、汇款等）、2.0时代（以超级账本为代表的智能合约应用，如抵押、产权等），并于2018年进入了3.0时代（超越合约的泛行业去中心化的生态型解决方案，如在身份认证、文娱等领域的应用）。本质上，区块链是一项高度可信的变革性技术，是对当前世界底层逻辑的再造，更是构建未来价值互联网（“数字货币＋数字资产＋生态系统”）的“通用基础设施”和赋能的“连接器”。

从媒介角度看，区块链不仅可加强原创内容的保护、跟踪版权使用状况、打击虚假内容，而且可以打破数据“孤岛”并解决数据安全和隐私等问题。例如，2018年4月，“三个爸爸”联袂央视和区块链共享生态平台`Smartshare`打造了融合智能对话、远程视频等功能的IP区块链“灯灯机器人”，实现了家长与孩子互动行为的准确记录。

## 5. “物联网+媒体”

物联网（`Internet of Things`，`IoT`），即“物物相连的互联网”，是在互联网基础上延伸和扩展、将各种信息传感设备与互联网结合从而实现人机物在任何时间、任何地点环境下的互联互通的业务网络。物联网要求每一物件均可寻址、每一物件均可通信、每一物件均可控制，关注网络计算、汇聚、连接、通信、收集以及内容等，强调认知并主要体现在“8A”服务方面——`Anytime`（任何时间）、`Anywhere`（任何地点）、`Anybody`（任何人）、`Anything`（任何事件）、`Any service`（任何服务）、`Any content`（任何内容）、`Any device`（任何设备）以及`Any connection`（任何网络）。

从媒介角度看，无论是通过无人机、监控、行车记录仪等设备实现视频采集，还是通过传感器等设备实现用户数据采集与反馈，“物联网＋媒体”已集中应用于即时新闻、环境新闻、调查新闻、“公民参与”式新闻和无人机新闻等领域，开拓全新的传播路径，并使得传统媒体由人到人的信息传播转向“万物皆媒”。例如，《华盛顿邮报》在2016年里约奥运会的新闻报道中，便使用了标准化、公式化的机器人写作，通过对接奥组委的数据库，能在极短的时间内完成消息撰写、赛事汇总等工作。

# 三、智媒化：重新定义媒体

得益于新一轮智能技术集群的进步和新型信息基础设施的逐步完善，使得信息传播正在以前所未有的广度和深度散布、融透在社会机体的每一个部分，将重新定义人与信息、人与商品、人与服务以及人与人的连接方式，并创造出一个从人与人的连接到万物互联、万物智能的全球化信息生产与流动的智能传播景观。受限于篇幅，下文更多以新华社媒体大脑为例进行智媒化的相关探讨。

## 1. 构建从信息采集到内容创作的智能化生产模式

新华社先于2017年12月发布了中国第一个媒体人工智能平台——媒体大脑1.0（`mp.shuwen.com`）[6]，后于2018年6月发布了媒体大脑2.0——“MAGIC”智能媒体生产平台，引起海内外广泛关注。不难发现，`MAGIC`实质是`MGC`（机器生成内容）和`AI`的组合。媒体大脑中的“2410”智能媒体生产平台，一方面，可通过摄像头、无人机、行车记录仪等智能传感设备采集数据并实时监测、探测新闻线索；另一方面，可代替人工对新闻信息进行生产与校对，提供更高效率的信息采集与投放。此外，还可对信息进行数据分析、图像处理、视频剪辑等一系列处理，从而构建起从信息采集到内容创作的智能化模式。例如，2018全国“两会”召开前夕，新华社基于媒体大脑发布了一条`MGC`视频新闻，这则新闻通过扫描5亿个网页、分析350万条数据，以可视化方式展示了“两会”热词、舆情热点等内容，而这个动作的全程耗时仅15秒（见图2）。

## 2. 构建从UGC到MGC、IGC的虚实结合生产模式

媒体大脑可通过摄像头、传感器、语音识别等方式获取素材，再经图像处理、深度学习等智能技术进行分析处理，最终形成新闻稿件，构建`MGC`的智能新闻生产模式。智能技术集群与传媒业的深度融合，更加强调技术要以更加智慧的方式融入内容生产，如《人民日报》中央厨房“小融”“小端”、新华社机器人“度秘”、《广州日报》机器人“阿同”“阿乐”等新闻机器人覆盖策划、采访、生产、分发、反馈等全新闻链条，如此虚实结合的生产模式在实现更具想象力的新闻叙事方式的同时，助力着内容生产由用户生产内容（`UGC`）向人机协作的智媒生产内容（`MGC`、`IGC`）的升级。例如，首个全仿真智能`AI`主持人于2018年11月7日第五届世界互联网大会亮相，拥有真人主播同样的播报能力，并且能保证24小时不间断地播报；再如，`AI`主播“小冰”担任天气播报员登上东方卫视，`AI`配音全程再现已故播音员李易的声音。

## 3. 构建从“B2C”到“C2B”的精准化投放模式

媒体大脑可提供多维度指标交叉分析，并能依托多源、异构的海量用户推演出用户画像，可实现信息传播与互联网服务的深度融合，可使传媒从业者更加深入地洞察用户，使媒体运营更加智能化、精准化与人性化。基于此，传媒经济产业链可沿更精准、更高效、利益更大化的路径提升和转型。比如，广告商既可根据节目定位向目标用户投放广告，又可获取等同甚至超越基于收视率的目标受众数据信息，将更加精准化、个性化、实时化的广告内容推送给目标对象，为买方和卖方创造价值和提升运营效率。例如，新浪客户端于2017年9月上线的“即时推”功能，其通过用户的“及时兴趣”，向用户推荐当前最感兴趣的资讯，构建起了连接人与信息的新型服务模式。

## 4. 构建从信息传播到跨界适配的智能服务模式

媒体大脑还具备强大的包括人脸识别、人类情感分析等在内的计算机视觉技术，可对视频、图片资料进行自动归类与处理，在帮助传媒从业者精准定位数据库中相关素材的同时，连接多个运营平台支持跨界运营服务。此外，还可以精准识别人物与人物的关系，保证实时新闻的准确性，从而提升发现新闻线索的效率，建立起全新的从更新传播方式到提供全方位信息的服务模式，如在赛事转播中，可提供实时赛事数据分析、精彩回放等；在灾害事件报道中，可现场多角度的视频资料、图文资料等。例如，2018年世界杯赛事转播中，“MAGIC”平台便利用视频跟踪算法，标注球员运动轨迹、双方球队进球率、有效进攻等赛事数据，以及“精彩时刻”视频片段，分析赛场局势。

## 5. 构建从原创内容到授权发布的全方位监督模式

媒体大脑在优化传统简单对应识别的基础上，还可运用覆盖全网的数据处理能力和针对图像、视频、文字等主流传播形式的智能化相似度算法识别技术，第一时间与权利人登记的版权信息进行比对，进一步赋能数字版权保护，从而帮助建立覆盖全网原创优质内容的“防火墙”，最大限度地遏制抄袭和“二次加工”现象。同时，区块链等“智能＋”技术也可提供监测分析报告和可视化的数据分析结果，更好地帮助权利人通过法律途径维护自身权利，让传媒产业沿着以优质原创内容为核心竞争力的方向发展。例如，2018年9月，杭州互联网法院正式上链，媒体大脑版权区块链构建起国际首个被互联网法院认可的版权区块链，使得创作者可一键取证直达法院。

# 四、广播电视媒体智媒化的未来发展方向

当前，多渠道、多维度、多平台，正推动着传媒产业向纵深发展。未来的广播电视媒体，应在新一轮智能技术集群的赋能下，从相“加”迈向相“融”，实现融为一体、合而为一，不断提高新闻舆论传播力、引导力、影响力、公信力[7]。

## 1. 以“智能+”为引擎，实现多维度智慧跨界运营

在数字经济模式下，用户数量已成为各平台运营的核心，而多维度的跨界运营可让各平台共享用户资源并挖掘用户消费潜力。在精耕存量用户的同时，应考虑到增量市场机会或将出现在中国三、四线城市和村镇及以二次元等为代表的新生代细分用户族群。以腾讯为例，腾讯被人们所熟知的是社交业务，其充分利用用户数量优势，顺势打造出了覆盖社交、游戏、支付、视频、新闻、直播等一体式运营的腾讯帝国。数据显示，仅2018年，腾讯的智能手机游戏业务就取得了778亿元的收入[8]，而同年，全国的有线电视网络总收入为779.48亿元[9]，省级广电第一的湖南广播电视台的总收入为209.51亿元[10]。

在智媒化的进程中，传统媒体应跳出固有的思维框架，以“智能＋”为引擎，通过建立更大维度的跨界运营，满足融合媒体业务开展的需求、满足平台资源调度一体化的需求、满足融合媒体业务创新变化与业务增长的需求、满足融合媒体平台开放性的需求。例如，中央电视台在天空二号发射直播节目的制作过程中，首次尝试了“弹幕”式的交互放送，在收获良好直播效果的同时，也引爆了网络话题热度。这种“传统新闻＋新型互动直播”的跨界运营便是极大的创新，未来传统媒体可以此思维和模式为参考进行更多大胆的尝试。

## 2. 完善供给体系，提供用户需求导向的智能服务

中国消费端数字化程度全球领先，诸如快递物流数量、网购人群数量、移动支付规模等均为世界第一，但在供给端的数字化程度却未呈现较高水平，存在缺乏知名品牌、广告无效投放、精准营销乏力等问题，存在消费端倒逼供给端改革的特点。而在智能化的供给体系中，前端数据分析可提供数字化调研工具，基于精准的计算、诊断对供给端的产品研发体系进行重构，从而更加精准地设计和孵化产品，提升产品内容的质量，缩减决策的时间以及提高决策的精准度。

在智媒化的进程中，广播电视媒体不能只扮演传统“发布者”的角色，更应作为用户数据的“利用者”，实现从文化传播渠道到综合型一体化服务平台的转型。广播电视媒体作为权威信息发布渠道，应当重视和着力解决一些特殊群体消费者的信息获取问题，比如听力障碍者、语言障碍者等。从供给系统端出发，做好供给侧改革的战略部署，形成新型现代化、多元化的智能供给结构，实现以优质供给来引导需求，并以此来满足用户多元化的需求，从而更好地引导消费端向更多元的方向良性循环发展。

## 3. 优化用户体验，强调移动优先与场景化智能适配服务

用户的移动消费习惯使得包括移动、体验、互动、高效与智能等诸多特点在内的场景化服务正在成为基础性的传播模式，而基于移动终端、传感器、社交媒体、大数据、定位系统提供的应用技术以及由此营造的一种“在场感”，正在革新消费时代用户体验[11]。数据显示，中国网民规模达8.29亿，网民使用手机上网的占比98.6%，网民中39岁以下群体占比67.8%，其中20～29岁年龄段的网民占比最高，接近30%[12]。移动互联网下半场的挑战在于以消费升级背景下主流人群的内容需求和社交体验为逻辑起点，争夺用户注意力和培养用户黏性，以及在深耕内容和精准传播的基础上把握媒体智能化的趋势。

在智媒化的进程中，传统媒体应充分利用采集到的实时素材信息并合理分类，从而改变过去单一化与“灌注式”的信息发布模式，实现“新闻现场＋同场报道交互＋用户后台交互”的多场景融合[13]，从而提供给用户可选择式的适配服务。此外，还应打通线上线下的界限，弥合现实生活与虚拟时空，将传播连接到工作、生活、娱乐、休闲不同场景。比如，在转播服务方面，可让用户自由选择观看；在用户沉浸感方面，可加强场景化的实时交互；在数据信息服务，可为用户提供与传播内容相关的智能适配服务等。

## 4. 强化知识产权保护，建立健全以IP开发为核心的盈利模式

目前，以`IP`为核心，同时连接文字、图像、音乐、电影、实体周边商店的数字化“超级`IP`”产业链正在高速发展，强调了传媒产业原创`IP`内容的重要性。借助`IP`来推动“互联网＋媒体”的跨界融合，或将成为当下智媒化健康发展的重要手段。以迪士尼为例，利用漫威所创5000个漫画超级英雄形象，推出超级英雄系列电影，取得亮眼票房成绩。据电影票房数据库提供的2018年内地票房排行榜数据，该年上映的《复仇者联盟3：无限战争》（收获23.7亿元票房）和《毒液：致命守护者》（收获18.56亿元）两部漫威电影都杀入前十；而2019年上映的《复仇者联盟4》，更是仅用3天20小时52分便成为中国票房史上最快破20亿元的影片[14]。

在智媒化的进程中，要实现`IP`价值变现、建立良性的盈利模式和营造良好的业界氛围，广播电视媒体应高度重视知识产权的保护，并以优质原创`IP`内容为主导，通过自身公信力来影响新媒体的发展。一方面，应将现有的技术手段充分应用到知识产权保护的工作中，强化对数字版权相关技术的研发，提高版权保护的硬实力；另一方面，加强传媒从业者知识产权保护的意识，从政策上鼓励、支持、保护原创性，激发更多的创造力。

## 5. 加快平台化创新，在内容与技术的良性互动中扩展融合广度

无论技术、环境如何变化，“内容为王”依然是传媒生产者必须遵循的原则。随着低龄、高龄及“白纸型”用户逐步进入媒体生态，传统媒体更不能丢失自身的标准，应充分发挥广播电视媒体智能化和新兴媒体“传统化”两者的优势，在内容和技术上形成良性循环，在一个以考虑内容为前提技术体系框架下来推动传媒业的发展，让内容成为“原生”，来扩展广播电视媒体良性内容的传播范围，促进融合渠道的扩张和发展。

在智媒化的进程中，传媒机构要想在用户扩充和内容优化上进行更深度的融合，更须从简单的嫁接形态迈向全方位的渗透形态，以自身优质的内容来扩充新兴媒体发展的广度。例如，封面传媒与《光明日报》于2019年4月就共建“智媒技术云平台”达成合作意向，双方提出将在内容、技术、渠道等多方面实现互补，一方面采用前沿新技术辅助内容生产，另一方面依托云平台推动了新闻生产向全时段、全流程、全网络的智能化变革。

# 五、结束语

当下及未来，自然智能与人工智能将始终无缝融合于智能化的媒介生态中的，已是不论彼此，无问西东。在智媒化的进程中，广播电视媒体要从简单的“加”向真正的“融”迈进，依靠的不仅是技术的升级，更多的是传媒从业者在“怎么融”“融什么”这类问题上把握好“质”和“度”。广播电视媒体要想更好地成为传媒业的生态拼图或获取内容方向上的“价值点”，唯有在保持自身优势的同时，通过用户思维等在内的新思维方式深挖“数据价值”，用`AI`重构媒体生态并占据用户心智，才能推动传媒产业朝着更高质量的方向发展，为传媒业升级转型与互补增益式经营新范式带来启示。

# 媒介使用研究

## 社交媒介使用与社会责任认同的关系：基于新上海人的实证研究

**白如金　李政宏**

### 摘要

为明确社交媒介使用对新上海人社会责任认同的作用机制，本文构建了一个有调节的中介模型，重点考察了社会融入在两者关系中的中介作用以及社会信任的调节作用。笔者对415名新上海人进行问卷调研，对其社交媒介使用、社会融入、社会信任及社会责任认同进行调查。结果显示：①在控制性别、年龄、户口、来源(城乡)、收入、来沪时长后，社交媒介使用对社会责任认同具有显著的正向预测作用；②社会融入能够在社交媒介使用与社会责任认同的关系中起中介作用；③社交媒介使用对社会责任认同的直接预测作用及社会融入在两者关系中的中介作用均会受到社会信任的调节。

### 关键词

社交媒介使用，社会责任认同，社会融入，社会信任
