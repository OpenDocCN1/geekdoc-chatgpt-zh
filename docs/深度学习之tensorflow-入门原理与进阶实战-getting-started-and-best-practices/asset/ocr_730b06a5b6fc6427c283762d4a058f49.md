其计算公式如式（6-1）所示。

$z = \sum_{i=1}^{n} w_i \times x_i + b = w \cdot x + b$ 式 (6-1)

式（6-1）中：z 为输出的结果；x 为输入；w 为权重；b 为偏执值。w 和 b 可以理解为两个变量。

模型每次的学习都是为了调整 w 和 b 从而得到一个合适的值，最终由这个值配合运算公式所形成的逻辑就是神经网络的模型。
