## 7. 夹角余弦介绍

为了能够读懂代码，有必要介绍下夹角余弦的概念。

余弦定理：给定三角形的三条边 a、b、c，对应三个角为 A、B、C，则角 A 的余弦见式（9-1）：

cos \( A = \frac{b^2 + c^2 - a^2}{2bc} \)
式（9-1）

如果将 b 和 c 看成两个向量，则上述式子等价于（见式 9-2）：

cos \( A = \frac{<b, c>}{|b||c|} \)
式（9-2）

分母表示两个向量的长度，分子表示两个向量的内积。引申到二维空间中，向量 A(x1, y1)与向量 B(x2, y2)的夹角余弦公式见式（9-3）：

cos \(\theta = \frac{x_1 x_2 + y_1 y_2}{\sqrt{x_1^2 + y_1^2} \sqrt{x_2^2 + y_2^2}}\)
式（9-3）

再扩展到两个 n 维样本点，a(x11, x12, ..., x1n)和 b(x21, x22, ..., x2n)的夹角余弦的公式见式（9-4）：

cos \(\theta = \frac{x_{11}x_{21} + x_{12}x_{22} + ...}{\sqrt{x_{11}^2 + x_{12}^2 + ...} \sqrt{x_{21}^2 + x_{22}^2 + ...}}\)
式（9-4）

这回可以理解前面的代码了，norm 代表每一个词对应向量的长度矩阵，见式（9-5）：

![](img/d841d305683d65f55b29f4e3f25e532c_309_0.png)

normalized_embeddings 表示的意思是向量除以自己的模，即单位向量，它可以确定向量的方向。

很明显，similarity 就是 valid_dataset 中对应的单位向量 valid_embeddings 与整个词嵌入字典中单位向量的夹角余弦。

如图 9-23 所示，算了这么多夹角余弦的目的就是为了衡量两个 n 维向量间的相似程度。当 \(cos\theta\) 为 1 时，表明夹角为 0，即两个向量的方向完全一样。所以当 \(cos\theta\) 的值越小，表明两个向量的方向越不一样，相似度越低。

![](img/d841d305683d65f55b29f4e3f25e532c_309_1.png)
