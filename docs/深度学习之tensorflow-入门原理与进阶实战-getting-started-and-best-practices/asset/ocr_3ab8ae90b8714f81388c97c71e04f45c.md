们放到对应的优化器中。

这里用了一个技巧：将判别器的学习率设小，将生成器的学习率设大一些。这么做是为了让生成器有更快的进化速度来模拟真实数据，优化同样是用 AdamOptimizer 方法。具体代码如下。

# 代码12-1 Mnistinfogan (续)

```

79 logits(logits=class_real, labels=y))
79 #生成的样本与分类都正确，但是与输入的分类对不对上
80 loss_c = (loss_cf + loss_cr) / 2

89 gen_global_step = tf.Variable(0, trainable=False)

91 train_disc = tf.train.AdamOptimizer(0.0001).minimize(loss_d + loss_c
92 + loss_con, var_list = d_vars, global_step = disc_global_step)
```

所谓的 AC-GAN 就是将 loss_cr 加入到 loss_c 中。如果没有 loss_cr，令 loss_c= loss_cf，对于网络生成模拟数据是不影响的，但是却会损失真实分类与模拟数据间的对应关系。
