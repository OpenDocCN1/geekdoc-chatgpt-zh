```
pad_left = pad_width / 2
pad_right = pad_width - pad_left
```

上面代码中

+   - pad_height: 代表高度方向要填充 0 的行数。
+   - pad_width: 代表宽度方向要填充 0 的列数。
+   - pad_top、pad_bottom、pad_left、pad_right: 分别代表上、下、左、右这 4 个方向填充 0 的行、列数。
