```
01 np.random.seed(10)
02
03 input_dim = 2

09 plt.scatter(X[:,0], X[:,1], c=colors)
10 plt.xlabel("Scaled age (in yrs)")
11 plt.ylabel("Tumor size (in cm)")

```
