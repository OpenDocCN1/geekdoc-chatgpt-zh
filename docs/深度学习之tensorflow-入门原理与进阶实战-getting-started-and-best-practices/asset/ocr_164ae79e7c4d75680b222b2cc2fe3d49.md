# 4.1.14 实例 12: 更简便地保存检查点

本例中介绍另一种更简便地保存检查点功能代码的方法——tf.train.MonitoredTraining Session 函数。该函数可以直接实现保存及载入检查点模型的文件。与前面的方式不同，本例中并不是按照循环步数来保存，而是按照训练时间来保存的。通过指定 save_checkpoint_secs 参数的具体秒数，来设置每训练多久保存一次检查点。

# 实例描述

演示使用 MonitoredTrainingSession 函数来自动管理检查点文件。

具体代码如下：

代码4-7 trainMonitored

```
import tensorflow as tf
tf.reset_default_graph()
global_step = tf.train.get_or_create_global_step()
step = tf.assign_add(global_step, 1)
#设置检查点路径为 log/checkpoints
with tf.train.MonitoredTrainingSession(checkpoint_dir='log/checkpoints',
save_checkpoint_secs = 2) as sess:
    print(sess.run([global_step]))
    while not sess.should_stop(): #启用死循环，当 sess 不结束时就不停止
        i = sess.run( step)
        print( i)
```
