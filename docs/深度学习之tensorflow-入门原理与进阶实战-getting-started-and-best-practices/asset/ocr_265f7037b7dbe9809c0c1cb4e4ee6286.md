# ## 10. 定义Seq2Seq框架结构

seq2seq_f函数的作用是定义 Seq2Seq 框架结构，该函数也是为了使用 model_with_buckets 时，作为参数传入。前面介绍 model_with_buckets 函数时说该函数更像一个封装好的框架，原因就在于此。

读者也要适应这种方式：将损失函数、网络结构、buckets 统统定义完，然后将它们作为参数放入 model_with_buckets 函数中，之后一切交给 TensorFlow 来实现即可。
