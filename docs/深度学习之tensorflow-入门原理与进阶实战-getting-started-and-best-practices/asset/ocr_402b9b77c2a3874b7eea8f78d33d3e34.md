# 9. 启动带协调器的队列线程，开始训练

本例中涉及的参数比较多，模型比较大，会导致每次迭代时间都很长，所以加入检测点是非常有必要的。这里涉及检查点保存的粒度，如间隔太短，因为频繁地写文件会减慢训练速度，如果设置的间隔太长，中途如发生意外暂停会导致浪费了一部分训练时间，可以通过 try 的方式在异常捕获时再保存一次检查点，这样可以把中途的训练结果保存下来。
