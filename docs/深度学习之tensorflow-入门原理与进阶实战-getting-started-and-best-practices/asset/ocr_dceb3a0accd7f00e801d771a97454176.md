# 12.7 GAN-cls：具有匹配感知的判别器

本节介绍一种 GAN 网络增强技术——具有匹配感知的判别器。前面讲过，在 InfoGAN 中，使用了 ACGAN 的方式进行指导模拟数据与生成数据的对应关系。在 GAN-cls 中该效果会以更简单的方式来实现，即增强判别器的功能，令其不仅能判断图片真伪，还能判断匹配真伪。
