# 4.6 动态图（Eager）

动态图是相对于静态图而言的。所谓的动态图是指在 Python 中代码被调用后，其操作立即被执行的计算。其与静态图最大的区别是不需要使用 session 来建立会话了。即，在静态图中，需要在会话中调用 run 方法才可以获得某个张量的具体体值；而在动态图中，直接运行就可以或得到具体值了。
