# 2. 构建网络模型

网络模型使用了双向 RNN 的结构，并将其封装在 BiRNN_model 函数里。调用的代码如下。

```
logits = BiRNN_model( input_tensor, tf.to_int64(seq_length), n_input,
```

BiRNN_model 的定义如下。
