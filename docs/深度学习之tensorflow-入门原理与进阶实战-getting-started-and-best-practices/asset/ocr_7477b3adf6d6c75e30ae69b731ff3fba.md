# 2. 添加残差网络

添加两个函数，一个是 leaky_relu 为 leaky relu 激活函数，另一个是用于生成网络残差块的函数 residual_block，实现一个中间有两层卷积的残差块。接着在整个网络构造中，通过一个卷积层与一个残差层完成图像特征的转换。残差层是由 16 个残差块与一个卷积层组成的网络。特征转换之后再通过 5 层神经网络完成最终的特征修复处理过程，如图 12-15 所示。
