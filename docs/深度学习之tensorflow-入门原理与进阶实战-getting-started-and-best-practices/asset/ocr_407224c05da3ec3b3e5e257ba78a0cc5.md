通过上面的结果可以看出：

+   - 对于 op1 和 vop1 的比较可以看出 5×5 矩阵在 padding 为'SAME'时生成的是 3×3 矩阵，而在'VALID'时生成的是 2×2。

+   - 而在 op6 和 vop6 的例子中，对于 4×4 矩阵在 padding 为'SAME'和'VALID'下都会生成 2×2 的矩阵，这是因为 4×4 的输入对于 2×2 的卷积核步长为 2 的情况下，正好可以把所有数据处理完，本身在'SAME'的情况下就不需要补 0。
