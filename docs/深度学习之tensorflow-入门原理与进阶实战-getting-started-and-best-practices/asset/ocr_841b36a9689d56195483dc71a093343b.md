第一行是模型的准确率，接下来是 3 个数组。

+   - 第一个数组是输出的预测结果。
+   - 第二个大的数组比较大，是预测出来的真实输出值。
+   - 第三个大的数组元素都是 0 和 1，是标签值 onehot 编码表示的 5 和 3。
