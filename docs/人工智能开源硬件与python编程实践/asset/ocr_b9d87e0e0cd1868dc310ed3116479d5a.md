# 4 ) LeNet-5 模型的卷积神经网络

LeNet-5 是一种经典的卷积神经网络结构。LeNet-5 诞生于 1994 年，是最早的深层卷积神经网络之一，开创了现代卷积神经网络的研究，推动了深度学习的发展。最初被用于手写数字识别，当年美国大多数银行就是用它来识别支票上面的手写数字的，它是早期卷积神经网络中最有代表性的实验系统之一。LeNet-5 卷积神经网络的结构如图 14.4 所示。
