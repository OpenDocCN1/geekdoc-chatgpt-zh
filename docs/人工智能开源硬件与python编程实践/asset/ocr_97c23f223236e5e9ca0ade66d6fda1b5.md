# 3 ) 图像匹配的实现

计算机视觉开源库中提供 image. match_descriptor( descriptor0 , descriptor1 [ ,threshold =70 [ ,filter_outliers = False ] ] )方法。对于 LBP 描述符来说，这个函数返回的是一个体现两个描述符之间区别的整数。这一距离测度尤为必要。这个距离是对相似度的一个度量。这个测度值越接近 0 ,LBPF 特征点匹配得就越好。对于 ORB 描述符来说，函数返回的是是 kptmatch 对象。

threshold 是用于为 ORB 键点过滤不明确匹配服务的。一个较低的 threshold 值将紧扣特征点匹配算法。threshold 值位于 0 ~ 100 ( int ) ,默认值为 70 。filter_outliers 是用来为 ORB 特征点过滤异常值服务的。特征点允许用户提高 threshold 值,默认设置为 False 。
