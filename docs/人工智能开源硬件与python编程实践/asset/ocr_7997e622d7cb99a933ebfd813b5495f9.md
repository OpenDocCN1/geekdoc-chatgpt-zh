# 1) 摄像头捕捉图像

手写体数字自动识别应用中，摄像头需要设置为灰度图模式，视频采集的分辨率可以设为 320 x 240 像素的 QVGA 格式，也可以根据情况设置为 160 x 80 的 HQQVGA 格式。相关的 Python 代码示例如下：

```
import sensor
sensor.reset()
# 初始化摄像头；
sensor.set_contrast(3)
sensor.set_pixformat(sensor.GRAYSCALE) # 设置像素格式为 GRAYSCALE；
sensor.set_framesize(sensor.QVGA) # 设置摄像头分辨率为 QVGA
# (320 x 240)；
sensor.set_windowing((128, 128)) # 设置窗口大小为 128 x 128；
sensor.skip_frames(time = 100)
sensor.set_auto_gain(False)
sensor.set_auto_exposure(False)
```
