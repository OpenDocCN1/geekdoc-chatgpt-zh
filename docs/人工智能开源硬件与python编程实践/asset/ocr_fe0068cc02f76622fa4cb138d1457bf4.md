同时增加误报率。相反，较高的值会降低检测速率，同时降低误报率。scale 是一个必须大于 1.0 的浮点数。较高的比例因子运行更快，但其图像匹配相应较差。理想值介于 1.35 ~ 1.5。roi 是感兴趣区域的矩形元组（x，y，w，h）。如果未指定，roi 即整个图像的图像矩形，操作范围仅限于 roi 区域内的像素。
