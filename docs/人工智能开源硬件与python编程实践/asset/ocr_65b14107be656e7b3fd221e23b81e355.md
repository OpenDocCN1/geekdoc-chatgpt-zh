# 搜索脸部对象。选用较低的比例因子 scale，会降低图像搜索速度，但可以检测出更小的对象；
#选用较高的比例因子，运行速度更快，但其图像匹配相应较差。理想值介于 1.35 与 1.5 之间。

#选用较高的 threshold 值会提高检测速率，但是会增加误报率；
#总之，thresholds 越大，匹配的速度越快，错误率也会上升。Scale 用来缩放被匹配特征的大小。

```
objects = img. find_features( face_cascade , threshold = 0.75 , scale =
1.35 )
```

#在找到的目标对象上面画框，标记出来；
