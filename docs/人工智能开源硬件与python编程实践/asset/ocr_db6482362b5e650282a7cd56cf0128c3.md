② C1 卷积层。该层包括卷积操作、Max Pooling、LRN 归一化模式等环节。卷积层由 96 个 feature map 组成，每个 feature map 由 11 x 11 卷积核在 stride = 4 下生成，输出 feature map 为 55 x 55 x 48 x 2，其中 55 = (227 - 11)/4 + 1，48 为分在每个 GPU 上的 feature map 数，2 为 GPU 个数。

激活函数采用 ReLU。Max Pooling: 采用 stride = 2 且核大小为 3 x 3 (文中实验表明采用 2 x 2 的非重叠模式的 Max Pooling 相对更容易过拟合，在 top 1 和 top 5 下的错误率分别高 0.4% 和 0.3% )，输出 feature map 为 27 x 27 x 48 x 2，其中 27 = (55 - 3)/2 + 1，48 为分在每个 GPU 上的 feature map 数，2 为 GPU 个数。

LRN 模式邻居层数设置为 5 做归一化, 最终输出数据为归一化后的：27 x 27 x 48 x 2。

③ C2 卷积层。该层同样包括卷积操作、Max Pooling、LRN 归一化模式等环节。卷积层由 256 个 feature map 组成，每个 feature map 由 5 x 5 卷积核在 stride = 1 下生成，为使输入和卷积输出大小一致，需要做参数为 2 的 padding，输出 feature map 为 27 x 27 x 128 x 2，其中 27 = (27 - 5 + 2 x 2)/1 + 1，128 为分在每个 GPU 上的 feature map 数，2 为 GPU 个数。

激活函数采用 ReLU。

Max Pooling: 采用 stride = 2 且核大小为 3 x 3, 输出 feature map 为 13 x 13 x 128 x 2, 其中 13 = (27 - 3)/2 + 1, 128 为分在每个 GPU 上的 feature map 数, 2 为 GPU 个数。

LRN 模式邻居层数设置为 5 做归一化, 最终输出数据为归一化后的：13 x 13 x 128 x 2。

④ C3 卷积层。该层包括卷积操作和 LRN 归一化, 这层不做 Pooling。输入为 13 x 13 x 256, 因为这一层两个 GPU 会做通信, 即图中虚线交叉部分。

卷积层: 之后由 384 个 feature map 组成, 每个 feature map 由 3 x 3 卷积核在 stride = 1 下生成, 为使输入和卷积输出大小一致, 需要做参数为 1 的 padding, 输出 feature map 为 13 x 13 x 192 x 2, 其中 13 = (13 - 3 + 2 x 1)/1 + 1, 192 为分在每个 GPU 上的 feature map 数, 2 为 GPU 个数。

激活函数采用 ReLU。最终输出数据为归一化后的：13 x 13 x 192 x 2。

⑤ C4 卷积层。该层包括卷积操作和 LRN 归一化, 这层不做 Pooling。卷积层由 384 个 feature map 组成, 每个 feature map 由 3 x 3 卷积核在 stride = 1 下生成, 为使输入和卷积输出大小一致, 需要做参数为 1 的 padding, 输出 feature map 为 13 x 13 x 192 x 2, 其中 13 = (13 - 3 + 2 x 1)/1 + 1, 192 为分在每个 GPU 上的 feature map 数, 2 为 GPU 个数。
