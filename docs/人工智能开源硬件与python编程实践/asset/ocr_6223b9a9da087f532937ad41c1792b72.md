# 1) 卷积和子采样

卷积过程就是用一个可训练的滤波器\(f_s\)去卷积一个输入的图像（第一阶段是输入的图像，后面的阶段就是卷积特征map），然后加一个偏置\(b_x\)，得到卷积层\(C_x\)。

子采样过程是指，邻域4个像素求和变为一个像素，然后通过标量\(W\)加权，再增加偏置\(b\)，然后通过一个Sigmoid激活函数，产生一个缩小1/4的特征映射图\(S_{x+1}\)。
