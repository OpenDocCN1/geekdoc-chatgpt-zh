```
sum = sum + x
print(sum)
```

③while 循环语句。Python 的第二种循环语句是 while 循环，在给定的判断条件为 true 时执行循环体，否则退出循环。比如要计算 100 以内所有奇数之和，可以用 while 循环实现：

```
sum = 0
n = 99
while n > 0;
    sum = sum + n
    n = n - 2
print(sum)
```

需要注意的是，与 C 语言不同，Python 中也没有 do...while 循环语句，程序设计时需要适应。
