深度自动编码器是一种深度学习神经网络,其输入和输出具有相同的维度。由于它可以在输出层重构出原始输入作为目标,不需要额外的监督信息,因而可以直接从海量未标注原始数据中自动学习数据特征。有研究工作将高维 MFCC 特征作为网络输入,应用深度自动编码器成功提取了新的语音特征。市级应用中,采用深度学习模型提取的新语音特征和传统 MFCC 特征相比,在识别性能上有较好的提升。基于深度自动编码器模型的语音特征提取方法如图 16.4 所示。
