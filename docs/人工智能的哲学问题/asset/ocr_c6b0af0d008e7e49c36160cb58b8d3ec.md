# （三）统一逻辑的尝试

如果以莱布尼茨的逻辑为始点，弗雷格、布尔以及图灵分别走过了三条不同的进路。其中图灵的计算进路相对于弗雷格和布尔的进路而言有一个主体转向，即从以人为单主体转向人机的双主体。余下的问题便是是否能够构造一个统一人类与机器的共通逻辑体系，这个体系在图灵的计算逻辑中能够找到，还是需要进一步地抽象和挖掘？这是一个值得深入的话题。
