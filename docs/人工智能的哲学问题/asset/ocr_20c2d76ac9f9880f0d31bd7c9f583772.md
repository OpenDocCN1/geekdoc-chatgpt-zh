# 图 2-2 基本情绪系统特征的图示总结①

在潘克塞普看来，所有初级加工的情绪系统都应具有至少七类神经互动的特征，包括：

+   ① 一些最初激活情绪系统的无条件感官刺激；
+   ② 协调的无条件行为反应，以及与这些行为相应的多种自主身体变化；
+   ③ 控制与评价输入刺激的能力；
+   ④ 维持突发事件之后持续情绪唤起的情绪系统的正反馈；
+   ⑤ 高阶三级加工的认知功能的调节；
+   ⑥ 强烈影响高阶加工的情绪系统；
+   ⑦ 情感感受生成于整个系统的运行②。
