# 四、人机关系的重新调适：普遍文字

调适人机关系如同人际关系一般，沟通与交流是至关重要的。语言与文字是人类社会目前最为有效的沟通与交流方式，如果将它泛化到人机关系中，那么我们就应该寻找一种统一自然语言与形式语言的普遍文字。关于普遍文字，早在 17 世纪，德国思想家莱布尼茨就提出过一个构造普遍文字的伟大设想，莱布尼茨的这一设想也被后人称为“莱布尼茨之梦”。
