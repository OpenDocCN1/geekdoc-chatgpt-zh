# 9.4.2 多 Agent 系统仿真案例

在军事领域，作战侦察预警系统的仿真不仅包括天、空、海、岸的各型侦察兵力平台，还涉及由情报侦察、指挥控制、通信、数据融合处理等组成的电子信息系统。这些系统之间关系复杂、相互制约多、影响大，成为构建有效体系仿真实验环境的主要难题。为了实现侦察预警系统的仿真，采用基于多 Agent 的建模与仿真方法，建立有效的物理和行为模型，能为作战仿真推演实现提供有效的支持 [20,21]。
