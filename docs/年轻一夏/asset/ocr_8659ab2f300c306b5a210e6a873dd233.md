# 9.3.3 Agent 模型的形式化描述

# 1. 形式化描述语言

在建模与仿真领域，形式化描述是一种重要的研究手段，与自然语言描述的含混不清与歧义性相比，借助数理逻辑或其他形式化规范可提供描述对象的精确语义[15]。形式化语言有多种，其中 Z 语言被广泛应用于工业和学术研究中，而且也正在被人工智能领域所接受。Z 语言的模式（Schema）和模式包含项提供的结构化规范，可以从不同抽象层次描述系统。Z 语言是基于集合论和一阶谓词运算的规范语言，由两部分组成：一是意识上部的声明部分，它声明了变量及其类型；二是下部的谓词部分，表示了与这些变量相关及其约束部分，如式（9.1）所示[16]。

```
SchemaName ≜ [声明部分|谓词部分]
```

（1）感知器和效应器是 Agent 与环境进行交互的部件，提供了 Agent 与外部环境相互作用的方式。其中，感知器提供对环境的状态信息，效应器提供改变环境的方法。由感知器和效应器构成的交互机制的 Schema 定义为

```
Mechanism ≜ [Perceiver : AgentPerception
Effector : (COMMAND × AgentState ↦ AgentInteracts)]
```

式中，Perceiver 为感知器，实现 Agent 的感知行为与感知能力；Effector 为效应器，实现由控制器发出的 Command 指令和当前 Agent 的状态 AgentState 到 Agent 交互行为的映射。
