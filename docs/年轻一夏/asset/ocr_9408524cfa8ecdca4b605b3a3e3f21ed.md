# 11.2.4 数据展示

数据中心虽然收集了车间的很多数据，但是单纯的数字本身并不能产生足够的影响力，不便于理解。相对于单纯的数据文字来说，图形化展示容易被接受。数据展示将以丰富的图形化和表格的形式将数据展示在用户面前，方便用户理解这些数据所表现出来的含义，其展示数据的形式主要有柱形图、锥形图、条形图、折线图、面积图、雷达图等。
