图 3-3 中，实心点表示 true，空心点表示 false。应该清楚的是，在第二种情况（对于“异或”逻辑）不能绘制一条虚线将实心点与空心点分开。

通过检查以下函数，可以看出单个感知器只能模拟线性可分函数的原因。

```
X=\sum_{i=1}^{n}w_ix_i
Y=\begin{cases} +1 \text{ for } X > t \\ -1 \text{ for } X \leqslant t \end{cases}
```

使用函数 X = t 可线性有效地划分搜索空间。因此，在具有两个输入的感知器中，将一个类与另一个类分开的线性方程定义为

```
w_1 x_1 + w_2 x_2 = t
```

感知器通过找到 w_i 的一组值，从而产生合适的函数来起作用。在不存在这种线性函数的情况下，感知器运行不成功。
