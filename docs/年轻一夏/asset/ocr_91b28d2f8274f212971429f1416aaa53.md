+   (3) 结合律:
+   (A∪B)∪C = A∪(B∪C)
+   (A∩B)∩C = A∩(B∩C)

+   (4) 分配律:
+   A∪(B∩C)=(A∪B)∩(A∪C)
+   A∩(B∪C)=(A∩B)∪(A∩C)

+   (5) 吸收律:
+   A∪(A∩B)=A
+   A∩(A∪B)=A

+   (6) 同一律:
+   A∩E=A   A∪E=E
+   A∩Ø=Ø   A∪Ø=A

式中，Ø为空集，E为全集。

+   (7) 德·摩根律:
+   -(A∩B)=(-A)∪(-B)
+   -(A∪B)=(-A)∩(-B)

+   (8) 复原律:
+   Ā̄=A

+   (9) 对偶律:
+   Ā∪B̄ = Ā ∩ B̄
+   Ā∩B̄ = Ā ∪ B̄

+   (10) 互补律不成立:
+   -A ∪ A ≠ E
+   -A ∩ A ≠ Ø

除了基本运算，模糊集合中还具有代数运算。设论域上的两个模糊集合可以由模糊隶属函数进行定义，则有如下运算。

+   (1) 代数积:
+   A * B <=> μ_{A*B}(u) = μ_A(u)μ_B(u)

+   (2) 代数和:
+   A + B <=> μ_{A+B}(u) = μ_A(u) + μ_B(u) - μ_A(u)μ_B(u)

+   (3) 有界和:
+   A ⊕ B <=> μ_{A⊕B}(u) = [μ_A(u) + μ_B(u)] ∧ 1

+   (4) 有界差:
+   A ⊖ B <=> μ_{A⊖B}(u) = [μ_A(u) - μ_B(u)] ∨ 0

+   (5) 有界积:
+   A ⊙ B <=> μ_{A⊙B}(u) = [μ_A(u) + μ_B(u) - 1] ∨ 0
