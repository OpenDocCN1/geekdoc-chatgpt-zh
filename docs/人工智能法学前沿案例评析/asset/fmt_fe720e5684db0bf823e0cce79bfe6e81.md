
# 前言

2019-2020年，我以访问学者身份在哈佛大学访学，全程深度参与了尤查·本科勒教授主讲的“科技与平等”课程.在该门课程上，本科勒教授以一系列经典和前沿判例贯穿讲授全程，全面展现了“案例教学法”在探讨科技与法律主题时提供的情境性和桥梁性功用.这些案例或启发了学生们对法律和科技前沿问题展开热烈讨论，或激发了学生们对人工智能时代法律制度变革议题的持久关注.我由此深感司法判例对于人工智能法学教育和法学研究的重要功用.与之相对，我国虽无判例法传统，司法裁判在推进人工智能治理之时亦起到了不可或缺的功用.尽管一再强调人工智能治理规则的颗粒度，力求通过精细化、精准化的法律法规来监管新技术新业态.^([\[26\]](#fow001.html#footnote_content_fow001_26))但以法律、法规、部门规章等为表现形式的法律规范仍然具有抽象性.尤其面对多元、动态的人工智能技术及其应用，法律规范所呈现的治理效果时常受限.一方面，人工智能技术迅猛发展，其应用日益多元，相关领域的立法和执法实践面临“步伐困境”^([\[27\]](#fow001.html#footnote_content_fow001_27)).另一方面，人工智能技术创新和商业模式创新交织前行，为保障新兴业态充分的发展空间，也不宜释放过强过严的监管信号.相反，应在一定程度上保持治理规则的开放性和灵活性，而这常常需要通过抽象化的法律规范加以实现.因此，应当注重立法与司法、执法与司法等环节的良性互动与动态耦合，适时扩展协同治理主体的范围和结构.^([\[28\]](#fow001.html#footnote_content_fow001_28))在司法实践领域，法官在司法裁判环节既要强调遵从抽象性的法律规则，又需审视个案蕴含的场景和情境，对此综合考虑、权衡取舍、变通补充.这一过程的实质就是通过个案裁判作用和影响利益相关方，间接发挥治理功能.实际上在人工智能治理领域，我国业已存在一系列司法裁判发挥着精准治理的功能.例如，全国首例制造虚假流量刷单案^([\[29\]](#fow001.html#footnote_content_fow001_29))、首例平台行使算法权力合理边界案^([\[30\]](#fow001.html#footnote_content_fow001_30))、首例大数据杀熟成功维权案^([\[31\]](#fow001.html#footnote_content_fow001_31))以及近期引发广泛关注的全国首例算法推荐案.^([\[32\]](#fow001.html#footnote_content_fow001_32))这些案例共同表明，与抽象化、原则化的治理规范相比，司法裁判通过个案审理推动规则明晰化，增加了治理规则的细粒度和精准性.

综上必然性和偶然性原因，叠加诸多内在动力与外在激励，本书历经四年，终得以成形.在编写的过程中，对外经济贸易大学法学院的多位同学为本书作出了巨大贡献.陈慧、陈瑞庭同学全权负责了本书修改过程的协调和统筹工作.赵雅泽、祁辉莹同学严谨而认真地负责了本书书稿的校对和统稿工作.陈慧、冯嘉瑞、张芯瑗、梁诗婷、张逸斐、李皓楠、黄博、苏冠南、周佳徽、陈瑞庭、汪霄航、杨箭宇、梁楚彬、姜帅、谢雨林、丁宛婷同学还为本书人工智能前沿案例的检索工作作出了积极贡献.张凯悦、冯馨墨、林泽祎、杨箭宇、王健宇、黄泽仪、杨中元、王晴、李盈、黄怡、陈瑞庭、李慧、张逸斐、叶童、齐天怡、武志华、杨雨晨、商雯琪、吴楚盈、李纳欣、孟雨柯、李若梅、李文茹、齐佳莹、王韵茜、李朗、许珺、黄博、陈慧、罗鑫、姜帅、张一墨、赵若涵、卢菱菁、高菲、刘柳言、苏冠南、梁铭、周佳徽、张芯瑗、冀辰宇、李飞、徐卓凡、刘博宇、徐忆红、任美羽、赵煦雅等诸位同学深度参与本书各篇案例的撰写.他们的辛勤付出铸造了本书逾四十万字的规模，使得域外人工智能法学前沿案例译介和评析工作得以实现.

本书基本框架形成后，为提升本书的专业性、复合性，我邀请了中央民族大学法学院的朱芸阳老师和我的同事孔祥稳老师加入编著团队，携手推进本书书稿的最终成形.两位老师在出版前审读全书并进行了细致专业的校对工作.本书的出版还要由衷感谢对外经济贸易大学法学院梅夏英院长和冯辉副院长.两位老师为推进法学院教师在网络与信息法学和人工智能法学领域的影响力，亲自牵头与对外经济贸易大学出版社合作“法律+科技”系列教材和著作出版计划.这一计划为本书的出版提供了宝贵契机和平台.对外经济贸易大学出版社的邸蓓蓓主任和编辑老师对于本书出版过程给予了宝贵支持与大力协助，在此诚挚感谢.

我们虽作出了诸多努力确保本书的专业性和可读性，但恐仍有力所不逮之处，恳请诸位读者不吝批评指正，帮助我们更好地完善和改进此书，携手推进人工智能法学的发展与繁荣.
