

# 提示规则与中国互联网治理

实际上，“提示规则”仍是国际上通行的规则，大多数欧盟国家都采用了这一规则，我国也不例外。我国《民法典》第1195条规定：“网络用户利用网络服务实施侵权行为的，权利人有权通知网络服务提供者采取删除、屏蔽、断开链接等必要措施。通知应当包括构成侵权的初步证据及权利人的真实身份信息。网络服务提供者接到通知后，应当及时将该通知转送相关网络用户，并根据构成侵权的初步证据和服务类型采取必要措施；未及时采取必要措施的，对损害的扩大部分与该网络用户承担连带责任。”

基于庞大的人口优势带来的丰富应用场景、基建优势带来的网络可及性叠加资本对产业的青睐，我国的互联网产业快速取得了蓬勃的发展。如今，互联网已经融入国民经济的方方面面，渗透入国民日常生活的各个角落。我国的社会共识与凝聚力较强，政府权威性和作为性较高，各级政府都针对虚假信息建立了信任度较高的辟谣平台。政府的公信力和人民对官方的高度信任有效阻断了虚假信息与极端内容的生成与传播。另外，我国在个人信息保护、竞争政策方面已经着手开展了相关治理工作，监管部门也采取了更为积极主动的监管思路，在包容审慎原则的基础上更强调平台的责任。

## 关联判例推荐

### 1. Doe v. MySpace, Inc., 528 F.3d 413 (2008)

核心事实：原告是一位母亲，控告经营社交网络的公司没有采取足够的措施防止其13岁的女儿为了谎报年龄，以便在该社交网络上建立个人档案，最终导致其女儿被所谓的“捕食者”联系、同意见面并遭到性侵犯。法院认为，被告系交互式计算机服务提供者，受到《通讯规范法》第230条的保护，因此驳回了原告的起诉。

与本案关联点：社交媒体属于《通讯规范法》规定的交互式计算机服务，受到该法律的保护。

### 2. Barnes v. Yahoo!, Inc., 570 F.3d 1096 (2009)

核心事实：巴尔内斯的前男友与其分手后，在雅虎网站上发布其裸照，并在聊天室中以其名义和单身男性聊天，在聊天室中公布了巴尔内斯的住址、电话、公司地址等信息。在受到许多陌生男子的骚扰后，巴尔内斯要求雅虎删除这些内容，但雅虎迟迟没有行动。巴尔内斯将雅虎告上法庭，要求雅虎承担过失责任，但雅虎由于不是该侵权信息的发布者，受到《通讯规范法》第230条（c）款第（1）项的保护而免于承担责任。

与本案关联点：根据《通讯规范法》第230条（c）款第（1）项，交互式计算机服务提供者不是第三方信息的发布者，无须为此承担法律责任。

### 3. Carafano v. Metrosplash.com, Inc., 339 F.3d 1119 (2003)

核心事实：某婚恋网站的用户盗取原告的个人信息在该网站上创建了档案，原告收到骚扰和威胁性的电子邮件后才发现其被盗取，并随即将该婚恋网站告上法庭。但法院认为，盗取和发布原告个人信息的是该网站的用户，婚恋网站并非相关内容的创建者、开发者，因此不需要承担责任。

与本案关联点：社交媒体受到《通讯规范法》保护，不因其用户发布的内容承担法律责任。
