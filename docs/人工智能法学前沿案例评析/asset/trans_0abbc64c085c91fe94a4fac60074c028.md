

# 密歇根失业保险自动化系统案

## 案件背景与程序

在2013年10月到2014年3月29日期间，鲍瑟曼（Bauserman）从失业保险局（Unemployment Insurance Agency， UIA）领取着失业救济金.被告失业保险局（Unemployment Insurance Agency， UIA）因鲍瑟曼（Bauserman）从他的前雇主那里收到了一笔款项而认定其涉嫌欺诈，这笔款项是他在2013年受雇于前雇主期间获得的“延期支付按比例分配的2013年奖金”.其后，被告向鲍瑟曼（Bauserman）及其前雇主发出问卷调查此事.虽然鲍瑟曼（Bauserman）和他的前雇主最终回复了被告的询问，但被告仍不清楚鲍瑟曼（Bauserman）前雇主所支付款项的性质.根据投诉，被告随后认定其向鲍瑟曼（Bauserman）多支付了失业救济金，并评估了罚款和利息.鲍瑟曼（Bauserman）收到了“不合格判定”和“欺诈重新判定”，还被告知惩罚措施将包括：拦截州所得税退税、拦截联邦退税、没收工资，以及通过法庭进行合法的征收活动.鲍瑟曼（Bauserman）声称，案件中来自其前雇主的争议款项是他的奖金，且在他收到奖金时，他仍然受雇于他的前雇主，鲍瑟曼（Bauserman）就这一主张对被告发送了通知.被告在收到通知后，对先前认定“鲍瑟曼（Bauserman）没有申请失业福利的资格以及他从事了欺诈行为”的判断进行了重新考虑.

2015年9月9日，鲍瑟曼（Bauserman）等人向索赔法院提起集体诉讼，指控被告利用自动化决策系统来检测和裁定涉嫌雇佣福利欺诈的事件.鲍瑟曼（Bauserman）进一步声称，被告的自动化决策系统“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System， MiDAS）剥夺了失业保险局（Unemployment Insurance Agency， UIA）请求权人的正当程序权利及公平公正的待遇.申诉称，在确定鲍瑟曼（Bauserman）在失业救济金方面有欺诈行为之后，在没有通知鲍瑟曼（Bauserman）具体的指控理由、没有提供60天举证期、没有给他举证机会、没有联邦法律和密歇根州宪法要求的通知且没有经过其他正当程序的情况下，被告没收了鲍瑟曼的财产.

2015年10月19日，原告首次提出修改申诉，除鲍瑟曼（Bauserman）外，威廉（Williams）和布罗（Broe）也加入诉讼成为了原告.在上诉中，被告辩称，如果原告的索赔要求没有按照《索赔法院法》的管辖规定^([\[16\]](#txt006.html#footnote_content_txt006_16))提出，则审判法院驳回其即决处理动议是错误的.法院支持了被告的这一主张.

法院指出，正当程序的一项基本要求是，在剥夺生命、自由或财产之前，索赔人的意见应当在一个合理的时间、以合理的方式被听取.本案的原告错误地将焦点放在了违反正当程序的潜在后果上，即剥夺他们的财产，而不是经正当程序索赔的特征、被通知权和被审理的机会上.通过利用自动决策系统来检测和确定欺诈案件，自动决策过程中的计算机代码包含用于确定索赔人有罪的规则，这些规则改变了犯罪的实质性标准，且不符合正当程序的要求.初审法院没有适当考虑原告何时受到伤害，而是将其重点放在了结论上，即原告是否确实从事欺诈活动是其“索赔理论的固有要素”.因此法院撤销了其决定.

2019年4月，密歇根州最高法院对上诉进行了审理，对原审判决部分确认、部分撤销，同时在判决书中指出：（1）引起向政府机构寻求金钱救济的诉讼事由、触发向政府机构发出通知的六个月期限的事件的发生，与该等索赔发生时，并无实质区别；（2）寻求金钱救济的正当程序索赔自原告被剥夺财产之日起产生，而非自原告被剥夺诉讼程序之日起产生；（3）对于特定索赔人，正当程序索赔应从机构截获索赔人联邦和州所得税退税时起计算：（4）至于另一名索赔人，正当程序索赔日期从机构扣发索赔人的工资时起计算.

2019年12月，密歇根州上诉法院肯定原审判决，并指出：（1）机构使用自动决策系统是国家政府官员的既定做法；（2）索赔人就违反国家正当程序条款提出了明确的索赔要求；（3）行政程序没有为索赔人提供寻求所需救济的途径；（4）代理机构被指控行为的不可靠程度，有利于损害救济的司法推理.

2020年11月，密歇根州最高法院决定就失业保险局（Unemployment Insurance Agency， UIA）提起的上诉安排口头辩论.

2020年12月，密歇根州最高法院批准了上诉人失业保险局（Unemployment Insurance Agency， UIA）关于延长提交补充书状时间的动议.

2021年3月，密歇根州最高法院批准了被上诉人鲍瑟曼（Bauserman）等关于延长提交补充书状时间的动议.

2021年4月，密歇根州最高法院批准了被上诉人鲍瑟曼（Bauserman）关于延长提交补充书状时间的第二、三项动议.

2021年4月，密歇根州最高法院批准了上诉人失业保险局（Unemployment Insurance Agency， UIA）关于延长提交补充书状的时间的动议.

2021年10月，密歇根州最高法院批准了密歇根州司法协会关于将书状提交给法庭之友的动议，提交给法庭之友的书状被接受.

## 核心争议点

被告失业保险局在没有经过正当法律程序的情况下剥夺他人财产的行为是否违反了宪法有关正当程序的规定.

## 裁判论证过程

失业保险局违反了正当程序的有关规定

通过利用自动化决策系统来检测和确定欺诈案件，使得自动化决策过程中的计算机代码包含了用于确定索赔人有罪的规则，这些规则改变了有罪或无罪的实质性标准，与正当程序的要求并不一致.密歇根州失业保险局通过不当拦截税收返还，扣押工资和强迫偿还索赔人的权利，侵犯了并将继续侵犯原告和集体成员的权利：

a. 未提供所要求的取消资格的必要通知.

b. 没有为索赔人提供至少60天的举证时间；

c. 不考虑事实依据，或不赞成或不支持发现犯罪行为的证据；

d. 没有举办听证会；

e. 没有为索赔人提供在有意义的时间以有意义的方式发表意见的机会；

f. 通过利用自动化决策系统来检测和确定欺诈案件，使自动化决策过程中的计算机代码包含了用于确定索赔人有罪的规则，这些规则改变了有罪或无罪的实质性标准，与正当程序的要求不一致；

g. 通过例行与大规模的过度评估罚款收取罚款利息，以及使用授权的收取方法不当收取罚款，被告失业保险局制定了这样一项政府政策，违反了《密歇根州宪法》正当程序和公平待遇的规定.

具体而言：

### 一、失业保险局在未进行充分通知和提供听证机会的情况下，扣押当事人财产并从事非法收款的行为违反了正当程序原则

正当程序条款禁止国家在没有正当法律程序的情况下剥夺一个人的生命、自由或财产.显然，只有在生命、自由或财产被剥夺的情况下，该条款才会被违反.正当程序条款保障了当事人“获得有意义的听证机会”的绝对权利，以及在被剥夺个人财产之前发表意见的机会.

### 二、失业保险局在未进行通知的情况下，采用自动欺诈检测系统判定当事人有罪违反了正当程序原则

在本案中，原告鲍瑟曼方声称失业保险局系统性地非法截获了他们的州和联邦退税，扣押其工资，并强迫他们偿还合法取得的失业救济金.经修订的申诉进一步指称，失业保险局违反州法律，对领取失业救济金的个人施加处罚，并收取未经州法律授权的利息.该机构在没有提供“取消失业救济金资格的必要通知”或举办听证会、不允许其在自己的辩护中提出证据的情况下，通过使用计算机系统启动自动化过程，检测和认定欺诈案件，导致个人被取消领取福利的资格、受到处罚并遭到刑事起诉，违反了正当程序原则.

### 三、现行法律未为当事人提供有效救济途径

虽然《密歇根州就业保障法》规定的程序为原告提供了质疑失业保险局关于其失业救济金决定的方法，但它并没有为原告提供适当的途径，以质疑该机构系统性剥夺其正当程序权利的行为，也没有为原告提供以金钱救济形式寻求补救的途径.

## 审理结果

1.索赔法院驳回了失业保险局关于即决处置的动议.

2.密歇根州上诉法院撤销初审法院驳回即决处置动议的决定，失业保险局可根据《密歇根州法院规则》第7节第219条的规定对费用征税.

3.密歇根州最高法院对原审判决部分确认、部分撤销，并发回重审.

4.密歇根州上诉法院确认了原审判决.

5.密歇根州最高法院决定就失业保险局提出的上诉安排口头辩论.

6.密歇根州最高法院分别批准了双方关于延长提交补充书状的时间等动议.

7.此案仍在上诉审理中，有待进一步完善.

## 案例评析

### （一）本案直接推动了算法行政相关立法的出台

“密歇根综合数据自动化系统”是本案中被告失业保险局使用的自动信息系统，用于向雇主征收失业税，并向符合条件的申请人支付失业福利保险.“地面数字多媒体广播”（Digital Terrestrial Multimedia Broadcast，DTMB）承包了“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System，MiDAS）的设计和配置，以实现取代已有30年历史的大型机系统的目标.“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System，MiDAS）宣称其目标包括：改善客户服务、提高数据准确性、改善数据安全和隐私、降低运营成本、提高自动化程度等.显然，针对失业保险局“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System， MiDAS）激增的诉讼数量证明，在其提高自动化程度的同时，“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System，MiDAS）未能达成其宣称的提高数据准确性、改善客户服务的目标.本案牵涉到多达34000位密歇根州失业人员，与此同时，欺诈行为和施加罚款为失业保险局带来了巨额资金.在一年多时间内，失业保险局的收入从300万美元增加到了6900万美元.^([\[17\]](#txt006.html#footnote_content_txt006_17))

“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System，MiDAS）缺乏人工审查，且在接收到内部早期预警之后仍拒绝更正，使得该州大量失业人员遭受了财产损失、信誉与声誉受损、破产以及房屋被抵押、赎回权被取消等不利后果.与以往因算法引起争议的案件相类似，“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System， MiDAS）的开发公司拒绝公开其算法，受“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System，MiDAS）欺诈指控的失业人员在困惑之中想要通过电话咨询失业保险局，发现电话无法接通，等到电话接通时却被告知已经错过30天的上诉期限.面对政府自动化系统引起的巨大争议，密歇根州同意修改州失业法，并且同意设立“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System，MiDAS）受害者补偿基金.在2017年，密歇根州通过了一项法律，通过改进欺诈指控通知和降低罚款来预防此类灾难性事件的发生.

美国通过引入外部监督机构来进行算法问责，密歇根州针对“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System，MiDAS）出具的审计报告中指出：失业保险局目前的安全管理计划无法对“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System，MiDAS）进行有效控制.欧盟《通用数据保护条例》（General Data Protection Regulation， GDPR）通过赋予个体异议权来保障数据主体的正当程序权利，其中第3章第4条规定：“如果控制者没有采取相应的行动来对数据主体的请求做出回应，那么对于其在收到请求后一个月内未能采取行动的具体原因，控制者应及时告知该数据主体，同时告知该数据主体可向监管机构提出申诉，寻求司法救济.”

我国《国务院办公厅关于全面推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度的指导意见》要求行政部门通过事前公开、事中公示、事后公开等正当程序维护公民权益，执法决定信息要在执法决定作出之日起7个工作日内公开.目前各国算法行政相关规则供给不足，导致现有法律难以应对复杂多变的算法问题.本案直接推动了算法行政相关立法的出台，以为后续开展算法问责提供法律依据.

### （二）本案通过诉讼方式纠正了政府自动化系统的错误

“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System，MiDAS）欺诈指控的内部审计报告中指出：失业保险局没有完全实施一个全面的安全管理程序，以确保“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System， MiDAS）的安全性；没有充分分析和审查“密歇根综合数据自动化系统”（Michigan Integrated Data Automated System，MiDAS）的数据，以帮助确定需要进一步审查的失业保险福利支出.针对审计报告中指出的问题，失业保险局同意在未经人工审查的情况下不使用自动化系统，同时还同意推翻其在2013年至2015年发出的剩余错误指控.本案对政府权力行使具有警示意义：算法系统对立法、行政与司法的影响与日俱增，管理自动化趋势增强.我们应清醒地认识到，行政决策仍属法治范围.^([\[18\]](#txt006.html#footnote_content_txt006_18))代码驱动下的智能行政与政府决策仍需遵循比例原则等基本要求.人工智能技术的发展无疑有助于提升行政效率，但自动化决策必须在必要的时刻、以合适的手段、在可进行充分解释的限度内行使，从而赋予自动化决策以正当性和说服力.本案对数字化时代公民积极运用法律武器维护自身合法权益与公民权利救济也具有启发意义.在互联网时代，信息传播速度加快、政策影响范围扩展，较之于传统的行政决策，自动化决策对公民权益的影响更具直接性和广泛性，算法黑箱、决策系统中内含的非理性因素，以及决策执行中可能存在的侵入性呼吁着对公民实现更高程度的法律保护，通过集体诉讼来实现权利救济.
