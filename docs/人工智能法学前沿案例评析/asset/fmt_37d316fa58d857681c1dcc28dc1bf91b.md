# 人工智能法学前沿案例评析

人工智能法学前沿系列丛书

张　欣　朱芸阳　孔祥稳　主编

对外经济贸易大学出版社  
中国·北京

## 前言

本书系北京市教育科学规划课题“新时代人才强国战略与人工智能法治人才培养”（3030-0014）的阶段性成果

### 一、人工智能法学的兴起

近年来，互联网、大数据、云计算、人工智能等技术加速创新，日益融入经济社会发展各领域全过程.人工智能技术发展的速度之快、辐射范围之广、影响程度之深前所未有，正在成为重组全球要素资源、重塑全球经济结构、改变全球竞争格局的关键力量.在全球人工智能浪潮之下，各国政府及相关组织持续加强人工智能战略布局，相继出台了人工智能战略和规划文件，将政策重点聚焦于行业促进、人才培养、完善监管以及标准建设等领域，全面推动人工智能技术和产业的发展.^([\[1\]](#fow001.html#footnote_content_fow001_1))我国自2017年开始，以《新一代人工智能发展规划》《促进新一代人工智能产业发展三年行动计划（2018-2020年）》《“互联网+”人工智能三年行动方案》《国家新一代人工智能创新发展试验区建设工作指引》以及《国家新一代人工智能标准体系建设指南》等文件为代表，构筑了我国人工智能顶层设计体系，以技术标准、产业规划、安全伦理等重要领域为先导，推动人工智能与实体经济的深度融合.^([\[2\]](#fow001.html#footnote_content_fow001_2))在国家顶层设计驱动之下，我国的人工智能技术发展迅猛，社会结构历经诸多变革.法学发展和法治建设也从商业文明“赛道”转换至数字文明“赛道”.纵观全球人工智能技术和治理格局，我国也从“跟跑”变为“并跑”甚至“领跑”.^([\[3\]](#fow001.html#footnote_content_fow001_3))这些前沿实践与发展之需时刻召唤着法学研究和法学教育的因应变革.

目前，人工智能技术及其应用已经在法律领域中映射出三个重要态势：第一、全球呈现人工智能立法浪潮，相关法律通过数量创历史新高.该报告对25个国家的人工智能立法记录进行分析，与人工智能相关的法案通过成为法律的数量从2016年的1个增长到2021年的18个.西班牙、英国和美国在2021年通过的人工智能相关法案数量最多，各通过了三项.2021年，美国各州人工智能提案数量从2012年的2个增长到2021年的131个.我国自2017年颁布《电子商务法》以来，与人工智能相关的立法明显提速.《个人信息保护法》《数据安全法》《互联网信息服务算法推荐管理规定》《互联网信息服务深度合成管理规定》等法律法规渐次出台，人工智能治理框架初具雏形.欧盟于2021年4月21日提出了《人工智能法案》，并于2022年4月20日发布了拟议的修正案.可以说，人工智能立法进入了名副其实的全球化时代.^([\[4\]](#fow001.html#footnote_content_fow001_4))

第二、人工智能伦理问题日益凸显，人工智能法律与伦理的融合与互动需求加剧.该报告中提到，大型语言模型正在不断创造技术基准的新纪录，但与此同时，大型模型也更能反映出训练数据的偏见.对比2018年最先进的1.17亿参数模型，2021年开发的一个2800亿参数的模型所引发的毒性（elicited toxicity）增加了29%.^([\[5\]](#fow001.html#footnote_content_fow001_5))随着时间的推移，算法系统的能力迭代增强，但与之伴随的算法偏见也前所未有地跨域蔓延.对此，人工智能公平性、问责性以及透明度问题已经成为全球人工智能研究者的共同关注.人工智能领域的顶级学术会议ACM Facct以及NeurIPS已经专门就算法公平、算法问责、算法透明度以及隐私等重要议题举办了系列研讨，并作为未来一段时期内的特定关注.与之相关的研究论文数量也呈直线增长.^([\[6\]](#fow001.html#footnote_content_fow001_6))这表明人工智能伦理问题已经成为技术界、产业界和政策界的共同关注.

第三、人工智能法学研究和法学教育蓬勃兴起.就人工智能相关专业而言，仅2020年一年，北美地区每五位获得博士学位的应届计算机科学专业学生中就有一位是人工智能或者机器学习专业.人工智能和机器学习已经是过去十年中最受欢迎的专业.^([\[7\]](#fow001.html#footnote_content_fow001_7))人工智能法学相关领域亦呈现出蓬勃兴起的态势.有研究显示，美国有26%的法学院至少提供一门涵盖人工智能与法律相关的课程，13%的高校提供多于一门的交叉性课程.为促进法学院在这一领域的深耕，甚至有学者建议美国新闻与世界报道创建最佳人工智能法律类学位项目的排名.^([\[8\]](#fow001.html#footnote_content_fow001_8))我国法学界自1985年即有杜飞进撰写的《信息法浅论》一文，以2002年中国法学会信息法学研究会成立为代表，诸多学者和高校等科研机构在计算法学、数据法学、智能法学以及人工智能法学等领域积极耕耘，推动着法学教育“从案例到代码”（from cases to code）的转变.^([\[9\]](#fow001.html#footnote_content_fow001_9))作为法学与人工智能深度交叉融合的新兴专业方向，人工智能法学成为我国新文科建设在法学领域最为重要的增长点之一.经过一定时期的努力探索，与人工智能相关的课程、书籍、研究机构纷至沓来，初步形成了有一定政策引导、理论支撑、技术支持和实务依托的人才培养格局.

这三个重要态势不仅预示了人工智能全球发展的重要方向，还预示着一个崭新的学科由此诞生.人工智能技术及其应用重新定义了生产力和生产关系，演绎着数字化发展的新式逻辑，孕育出算法社会这一全新样态，进而对现代法学“产生了某种釜底抽薪效应.”^([\[10\]](#fow001.html#footnote_content_fow001_10))因此，人工智能法学的兴起，并非响应国家战略的一时即兴之举，其已经成为承载信息革命诉求，反映数字时代生产生活关系和行为规律，涵盖法学理论、规范制度以及司法实践的“法学革命”.^([\[11\]](#fow001.html#footnote_content_fow001_11))

### 二、人工智能法学教育的现状与展望

人工智能法学是“人工智能+法学”交叉融合而成的独立新型学科.^([\[12\]](#fow001.html#footnote_content_fow001_12))其不仅是人工智能技术与法学的深度融合，还跨域耦合了新型研究范式和新型法治实践.^([\[13\]](#fow001.html#footnote_content_fow001_13))人工智能法学研究涵纳“法治实践的智能化”与“智能技术的法治化”议题，聚焦智慧法治理论与实践、司法人工智能领域理论、智慧法治相关理论、智能算法风险及其规制、智能技术归责重构以及数据生成、共享与使用等六大领域核心问题，全面回应智能化技术带来的时代挑战.^([\[14\]](#fow001.html#footnote_content_fow001_14))

从人工智能技术架构逻辑来看，其主要分为要素层、平台层和应用层.^([\[15\]](#fow001.html#footnote_content_fow001_15))在要素层，算法、算力与数据构成了驱动人工智能时代发展的三大要素.为深入理解人工智能底层要素的性质与法律规制基础性问题，本书选取了与算法性质、算法规制、算法问责和算法应用相关的法学前沿判例，希冀为读者勾画出与算法相关的前沿司法实践新动态.在平台层和应用层，人工智能技术已经扩展式嵌入到公共与商业场景之中.搜索引擎、人脸识别、信用评价、智慧司法以及智慧警务中均有人工智能技术的广泛应用.本书遴选了这些领域中较具代表性的域外司法判例，通过案件提要、案件要旨、核心争议点、裁判论证过程、审理结果五个部分概括案件全貌、剖析核心法律问题.与此同时，为更好地帮助读者厘清案例裁判思路，每一篇案例分析还专门绘制了思维导图，力求通过可视化方式帮助读者迅速理解案件核心信息和关键层次.

人工智能法学作为一门新兴学科，其发展需要系统化的科学基础和理论基础，其所包含的内容应当具有一致性，能够成为不断累进发展的科学.这种一致性体现为内部逻辑一致，可抽象总结出成体系的法律结构和核心制度规范，并由此实现相关知识在整个法律部门的影响和作用.^([\[16\]](#fow001.html#footnote_content_fow001_16))这种一致性与映射性的达成需要以系统成熟、科学自主的法学教育作为底色和基石.因此，人工智能法学教育对于课程建设、教材规划以及师资储备均具有较高要求.就人工智能法学教育实践来看，我国与人工智能技术发展较快的美国、欧盟和加拿大相比，自有特色和先进经验.以新文科、新法学背景下的人工智能法学教育面向数字法治教育理念，根植数字法学知识体系，正在探索凸显中国法学特色和自主性的深度交叠互动之路.^([\[17\]](#fow001.html#footnote_content_fow001_17))但从整体而言，仍然可以从以下三个方面借鉴提升：

第一，适度拓展人工智能法学课程的数量和规模，探索基础类和研讨类课程，形成逐层递阶的课程体系.有研究统计了美国U.S.News排名前一百九十七所法学院开设人工智能法学课程的数据，发现有五十一所法学院开设了法律与人工智能课程.哈佛法学院以九门课程领先，斯坦福法学院和乔治城法学院紧随其后，各有八门课程.在排名前三十的法学院中，几乎均设有人工智能法学课程.^([\[18\]](#fow001.html#footnote_content_fow001_18))这些课程既包括概论性课程，又包括研讨类课程.例如人工智能与国家安全、自动驾驶汽车法律规制、人工智能法学研究的国际视角、人工智能与人权、人工智能与网络安全等.^([\[19\]](#fow001.html#footnote_content_fow001_19))与之相比，我国法学院已经通过网络法学、信息法学、科技法学、人工智能法学、数据法学、计算法学、未来法学等理念，初步形成了数字法学课程体系，但整体而言尚不成规模.各大法学院虽有一些代表性人工智能法学课程，但与之相关的教材、师资和人才培养计划都难言成熟，更多体现为零散化、多元化的初步探索.加之学生整体处于法学基本功和信息技术基础知识的薄弱状态，人工智能法学研讨类课程起步较难、发展缓慢.^([\[20\]](#fow001.html#footnote_content_fow001_20))未来，还需在课程设置层面系统着力，适度拓展人工智能法学课程的数量和规模，加强优势课程的引领效应，切实推进多阶梯、多模式的人工智能法学课程体系.

第二、加大人工智能法学课程教材建设力度，探索体系化、特色化、前沿化兼具的教材形式.在美国等人工智能法学教育较为成熟的国家，由于其人工智能法学教育相对成熟，已有一整套系统化、前沿化、多元化教学材料可供学生学习和参考.例如，伍德罗·巴菲尔德等编写了《法律和人工智能高级入门》（2020年），萨米尔·抽普拉等撰写了《自主人工智能的法律理论》（2011年）、帕特里克·林等人编写了《机器人伦理：机器人技术的伦理和社会影响》（2014）和《机器人伦理2.0：从自动驾驶汽车到人工智能》（2019年）、乌戈·帕加洛编写了《机器人法：犯罪、合同和侵权行为》（2013年版）等.此外，为确保人工智能技术相关知识的时效性和开放性，艾瑞克·古德曼还突破了美国传统法学教材的形式，以电子版教材匹配网络法课程，其编写的《互联网法》迄今已更新至第十三版.^([\[21\]](#fow001.html#footnote_content_fow001_21))在一些网络课程资料开源平台上，也不乏开源性教辅资料供学生学习研究之用.^([\[22\]](#fow001.html#footnote_content_fow001_22))与之相比，我国目前“信息技术+法学”教学活动所面临的最显而易见的问题就是教材匮乏.尽管我国已经有《网络法学》、《信息法概论》等教材，但这些教材的时效性、体系性不强.在近年出版的教材中，学科知识的体系性和教材本身的更新速率亦差强人意.^([\[23\]](#fow001.html#footnote_content_fow001_23))一方面人工智能技术艰深晦涩，与之交叉产生的法律问题复杂多变，因此对教材编写所涉议题的精准把握对编写者带来较大挑战.另一方面，人工智能应用迭代迅速，与之配套的法律法规更新速率较快，有关人工智能的学说也不断推陈出新，这亦给教材体系和知识迭代构成考验.^([\[24\]](#fow001.html#footnote_content_fow001_24))未来，应从以下三个方面着力，集中推动人工智能法学相关教材的建设.首先，注重教材形式的多元化.目前，可集中以人工智能法学概论类教材为基础引领，以判例类教材为突破，双轨并行地开展人工智能法学教材的建设.其次，注重教材编写团队的交叉化.由于人工智能法学本身的跨域性和交叉性，与之匹配的教材必然需要编写团队在法学和相关技术科学领域深度融合.最后，还应保障教材的更新频率，确保教材尽量涵盖人工智能领域的最新议题和新兴理论的发展.本书即是以判例集评析的方式，对人工智能法学教材建设的一个初步探索.美式案例教学法（case method teaching）通过精心选择和按照逻辑编辑法官的核心观点，展现法律原则的发展变迁与法律规则的演化应用.在这种教学理念下，特定判例的相关事实、法律问题、判决结果和推理论证均可得到清晰而准确的展现.^([\[25\]](#fow001.html#footnote_content_fow001_25))本书的体例编排虽与美式经典的案例教学读本有所差异，但每一个判例的拆解和剖析架构较大程度上借鉴了美国法学课堂之上教师对所引重点判例的分析方式和逻辑框架.因此我们希冀通过严格拣选前沿和经典案例集的方式初步勾勒出人工智能法学领域的重要议题，以案例方式呈现法律规则在人工智能应用场景中的变迁面向，激发学生们对相关议题的兴趣和思考，培养其批判性思维，与我国法学教育和法律实践形成良性互动.

第三、探索人工智能法学课程与相关技术科学的深度融合之道.如前所述，人工智能法学具有文理交叉、跨域应用的特性.人工智能法学课程需要顺应学科发展规律，积极探索行之有效的知识融合与交叉互动机制.在哈佛大学访学期间，我深度观察了玛莎·米诺教授和辛西娅·德沃克教授联合开设的跨院系网络法课程“公平与隐私：来自法律和概率的视角”.这门课程采用研讨会与读书会的方式对法学与信息科学教学展开深度交叉和融合.该门课程的选课学生来自哈佛大学法学院和工程与应用科学学院.课程要求两个学院的学生深度合作，面对同一议题分别提供各自的专业知识和独特视角.同时在课程阅读材料的设计、课程讨论的议题以及课程论文的撰写上都要求两个学院的学生组成团队精诚合作.我国诸多法学院也在法学与信息交叉融合方面作出了积极尝试.例如，清华大学法学院开设了计算法学课程.该门课程的选课同学来自法学院与计算机、自动化等理工科院系.课程主讲人团队也尽量做到理论与实务兼具，法学与科技融合.未来，还可以借鉴哈佛“公平与隐私”课程的交叉思路，不仅在课程师资上做到交叉化，课程的讲授和开展也要充分调动法学与相关技术学科学生的合作热情，开展全方位、全链条的交叉和互动.

### 三、本书的缘起

面对全球科技竞争浪潮，习近平总书记指出，人工智能是引领新一轮科技革命和产业变革的重要驱动力，应把握全球人工智能发展态势，找准突破口和主攻方向，培养大批具有创新能力和合作精神的人工智能高端人才.为深入贯彻习主席关于人工智能创新人才培养的重要指示，全面推进新文科建设，为探索构建世界水平、中国特色的卓越法治人才培养体系积极贡献力量，作为一名法学教师，我从课程建设和教材建设率先着力，顺应人工智能时代之需，积极探索培育卓越复合型法治英才之路.

2017年，“信息技术+法学”的教学、科研和组织建设在法学界初兴，国内众多法学院开始探索网络与信息法学前沿教学和交叉研究.虽无成熟方案和样本可寻，但我深知开设一门技术与法学前沿交叉课程的必要性和紧迫性.在系统收集了几十门世界知名高校法学院开设的网络与信息法学相关课程大纲和教材，深入研究课程模块设置方案和教学计划共性的基础上，我与梅夏英院长合开了对外经济贸易大学第一门“法学+科技”前沿类课程——“网络法理论与实务研究”.在课程设计理念上，我们努力聚焦交叉化、前沿化、国际化特色，最大程度凸显新一代信息技术与法律的深度融合.在课程讲授方案上，我们尝试以沉浸式和启发式教学为内核，从基础概论到核心技术，从实体应用到法律规制，从软法治理到立法前沿，从讲授到研讨，逐步带领同学们熟悉和领会各个前沿主题.

在课程建设之外，我们还深刻地意识到人工智能法学课程教材建设的重要性.2019年教育部提出以知促行、以行践知的“三全育人”方针.科研育人是“三全育人”的重要环节.如何让科研过程成为耕耘学生成长成才的沃土是我在推进科研育人道路时首要思考的问题.而以“蜂群思维”为核心的“众包”协作模式曾在互联网的设计研发过程中闪耀熠熠光辉.受此启发，我希冀在课堂之外探索出一条激发学生科研兴趣、充分锻炼创新潜力、延伸课程讲授边界、深度参与教材建设的“众包协作”之路.在网络法理论与实务的课程上，我鼓励同学们深度参与《人工智能法学前沿案例评析》一书的编写，为同学们讲解外文法学判例分析和外文法律脉络梳理的方法，逐步搭建人工智能法学案例的分析框架.
