# 第五章 智慧司法领域前沿判例

## 5.1 卢米斯诉威斯康星州案

### 【案件索引】

卢米斯诉威斯康星州，881 N.W.2d 749（2016年）

威斯康星州诉卢米斯，2016 WI 68，371 Wis.2d 235，881 N.W.2d 749（2016年）

卢米斯诉威斯康星州，137 S.Ct. 2290（2017年）

### 【关键词】

算法解释权；算法影响评估；算法问责；智慧司法

### 【案件提要】

本案是有关算法解释权和技术正当程序的经典案件.本案与威斯康星州诉卢米斯的刑事诉讼案件密切相关.在威斯康星州诉卢米斯案件中，被告埃里克·卢米斯（Eric L. Loomis）通过正式程序获知，其将接受“提供替代性制裁矫正犯罪管理画像（COMPAS）”风险评估工具^([\[1\]](#txt005.html#footnote_content_txt005_1))提供的累犯风险评估，但浮于形式、流于表面的“知情权”不仅限制了被告的抗辩权，算法决策的复杂性、技术性也限制了法院的理解和判断.该案刑事诉讼被告卢米斯主张基于群体行为数据的累犯风险评估存在准确性和科学性风险，侵犯了被告享有的单独并在准确信息基础上接受审判的权利，COMPAS对性别的考虑侵犯了其正当程序权利.卢米斯在该案中进一步指出，其虽处于反驳COMPAS风险评估的最佳位置，但却无法仅基于开发者在预测报告中提供的有限信息进行质疑，除非其能够知晓影响分数的因素被赋予的权重以及风险评分的运行逻辑.面对这一诉求，COMPAS的开发者Northpointe称卢米斯所需获知的信息具有专有性，无法向卢米斯以及一审法院公开其评分决策所涉因素的具体权重，但COMPAS生成的评估分数具有科学性和准确性.虽然这一观点得到了纽约州刑事司法部门研究报告的支持，但质疑的意见此起彼伏.
