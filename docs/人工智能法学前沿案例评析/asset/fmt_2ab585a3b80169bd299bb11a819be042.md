# 第九章 社交媒体相关前沿判例

## 9.1 帕金汉姆诉北卡莱罗纳州案

### 【案件索引】

State v. Packingham, 229 N.C. App. 293, 748 S.E.2d 146 (N.C. Ct. App. 2013)

State v. Packingham, 368 N.C. 380, 777 S.E.2d 738 (2015)

Packingham v.North Carolina, 137 S.Ct. 1730, 198 L.Ed.2d 273, 85 USLW 4353 (2017)

### 【关键词】

言论自由；社交媒体；公共论坛；性犯罪者

### 【案件提要】

本案是有关互联网言论自由的早期典型案例之一.该案与北卡莱罗纳州诉帕金汉姆案密切相关.在北卡莱罗纳州诉帕金汉姆案中，被告帕金汉姆（Lester Gerard Packingham）作为注册在案的性犯罪者，由于在社交媒体Facebook上发布了一条消息而违反了2015年版《北卡莱罗纳州一般法规》（North Carolina General Statutes）第14章第202.5条，被判处监禁.被告以州立法违宪为由提出上诉.上诉法院认为该立法是内容中立的，适用中度审查（而不是基于内容的严格审查）.尽管如此，该立法仍然因为过于宽泛、对言论自由施加了不合乎目的的负担而违宪.而州最高法院以该立法主要规范行为，仅对言论施加未超出保护重大利益所必须的次要负担，且提供了充足替代方案等理由，撤销上诉法院判决.最终，美国联邦最高法院的判决终止了这个长达7年的争议，从即使适用中度审查也并非完全符合重大利益和过于宽泛两个维度判定该州立法违宪，并援引里诺诉美国公民自由联盟案^([\[1\]](#txt009.html#footnote_content_txt009_1))，认定社交媒体是“庞大的互联网民主论坛”，社交网络上的言论自由也应受宪法的保护.然而，各方的激烈讨论仍在进行中，如阿利托等大法官认为不应轻率地将更具隐蔽性的网络空间与公共场相等同，否则可能意味着各州立法甚至无权限制最危险的性犯罪者访问社交网站.

本案作为早期确认社交媒体应是公共论坛的典型案例之一，在网络日益发达的当今社会无疑具有十分重要的意义，也为之后随着科技发展可能带来的交流媒介改变而引发的言论自由问题提供了借鉴.另外，本案还影响了有关公职人员的社交媒体账户是否为公共论坛的认定，类似的案件频繁出现，如在戴维森诉兰德尔案^([\[2\]](#txt009.html#footnote_content_txt009_2))中，弗吉尼亚州地方法院裁定县官员在其官方Facebook页面上屏蔽用户的行为是违宪的.私人账号公共化是政治生活中常见的情况，亟待法院明确宪法第一修正案的新的适用范围.本案也对我国网络言论自由立法提供了有益的参考，我国宪法同样赋予了公民言论自由，同时我国也有限制言论自由的法律，如《中华人民共和国未成年人保护法》第六十六条提到：“应当加强对未成年人网络保护工作的监督检查，依法惩处利用网络从事危害未成年人身心健康的活动，为未成年人提供安全、健康的网络环境.”总体来说，我国对于网络领域言论自由的规范较为宽泛，在实践中给予了法官更大的自由裁量权.本案对于处理网络空间的言论自由问题具有非常重要的指导意义.

### 【案件要旨】

北卡莱罗纳州上诉法院：原告 北卡莱罗纳州 被告 帕金汉姆

北卡莱罗纳州最高法院：原告 北卡莱罗纳州 被告 帕金汉姆

美国联邦最高法院：原告 帕金汉姆 被告 北卡莱罗纳州

帕金汉姆曾于2002年因猥亵一名13岁的儿童被登记为性犯罪者.2012年，帕金汉姆在Facebook上发布了一条有关免除交通违法通知单的消息，违反了州立法中性犯罪者不得接触商业社交网络的禁令，因此被起诉.北卡莱罗纳州未宣称原告在网络中与未成年人有联系或实施了其他非法行为.帕金汉姆以该立法违反第一修正案为由要求驳回起诉，北卡莱罗纳州初审法院否决了该动议，判处其6至8个月监禁，缓刑12个月.

帕金汉姆以《北卡莱罗纳州一般法规》第14章第202.5条违反第一修正案保障的言论自由为由向北卡莱罗纳州上诉法院提出上诉，上诉法院撤销了初审法院的裁决，理由是：（1）该立法通过禁止与立法意图无关的广泛的交流和表达活动给所有记录在案的性犯罪者任意加重负担，过于宽泛；（2）该立法在保护儿童免受性侵方面并非严格符合州政府重大利益.

北卡莱罗纳州最高法院撤销了上诉法院的裁决，理由是：（1）该立法主要规范的是使用网站的行为，仅对言论施加附带负担.（2）该立法是内容中立的，因此适用中度审查.州立法满足美国诉奥布莱恩案^([\[3\]](#txt009.html#footnote_content_txt009_3))确立的四因素审查标准，即：①在政府的宪法权力范围内；②促进了重要或实质性的政府利益；③该政府利益与压制言论自由无关；④对言论自由的附带限制是促进该利益所必需的.州立法是为满足政府重大利益而制定的，建立了四个必要的特定标准规定禁止使用网站的范围：①该网站的运营人员从会员费、广告费和与网站运营有关的其他来源获取收入；②该网站为两个人或更多人之间以友谊、会见或者信息交换为目的的社交介绍提供便利；③该网站允许用户创建网页或个人简介，所含信息可以是用户的真名与昵称、用户置于个人网页的照片、用户的其他个人信息，以及其他用户或来访者可以访问的，通向用户的朋友或同事的个人社交网页的链接；④该网站给用户和来访者提供与其他用户交流的机制，例如留言板、聊天室、电子邮件、或即时通讯工具.这些规定具有狭窄性，并提供了充足的替代方案.（3）案件事实极大影响了该立法是否违宪.被告没有表现出对法律的尊重和遵守法律的努力，对被告施加的言论自由限制没有超过保护儿童免受注册在案犯罪者侵害的州利益的必要限度.

2017年6月19日，美国联邦最高法院撤销北卡莱罗纳州最高院判决并发回重审.

### 【核心争议点】

1.中度审查标准下，州立法是否违反宪法第一修正案.

### 【裁判论证过程】

（一）中度审查标准下，州立法违反了宪法第一修正案
