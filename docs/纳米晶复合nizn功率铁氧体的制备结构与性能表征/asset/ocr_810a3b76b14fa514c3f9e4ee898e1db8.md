样品 C 是采用在湿凝胶时掺杂 Bi 的方法，这种方法能使掺杂粒子在分子、离子水平充分混合，所以一旦采用凝胶自燃法制备出纳米晶粉体，其掺杂自然是均匀的。图 5.10 曲线表明，掺杂样品 C 的磁导率变化很有规律。在掺杂量 6 %以下，磁导率变化不大，然后磁导率随掺杂量增加而上升。到掺杂量为 1%时，磁导率达最大，为 200，然后略有下降趋势。而对比样品 D，相同掺杂量的磁导率只有不足 100，显然样品 D 的混合、分散有问题。根据经验可知，任何掺杂都会在一定量时产生作用，会有一个最佳点。而掺入的 Bi 不是主相，且又是非磁性物质，所以图 5.8 表现出的数据波动就一定是混合不均匀引起的。
