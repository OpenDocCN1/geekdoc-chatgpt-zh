换耦合相互作用与晶粒尺寸及相对取向有关，晶粒尺寸越小，其表面积与体积之比就越大，界面处的交换相互作用对晶粒磁性能的影响越大。周寿增等人[166-167]对烧结 NdFeB 磁体的研究表明，在晶粒尺寸达到微米量级时，晶粒之间的交换耦合相互作用对磁体性能没有显著影响。然而当颗粒降到了纳米量级，粒子的比表面积增加，界面原子的交换耦合相互作用对材料磁性能的影响加强。Herzer 在解释纳米软磁材料 Finement 的优异磁性能时提出混乱各向异性模型，指出：当晶粒尺寸 D 小于晶粒之间的铁磁交换作用长度 L_ex 时，晶粒内的磁矩方向将取决于交换作用能与各向异性能相互平衡的方向，其等效各向异性 < K > 为交换作用长度内各晶粒各向异性的平均值[168]，

```
< K > = K_1(D/L_{ex})^{3/2}  (5.1)
L_{ex} = (A/ < K >)^{1/2}  (5.2)
```

式(5.1),(5.2)中 A 为交换劲度，K_1 为磁晶各向异性常数，D 为晶粒直径。根据式(5.1),(5.2)可以得出：

```
< K > = K_1^4 \times D^6 / A^3  (5.3)
```

因为
H_c \propto \frac{K_u}{M_s}  (5.4)

参见公式(5.1)，可见当 D < L_ex 时，有效各向异性 < K > 随晶粒尺寸减小呈 6 次方关系下降，矫顽力呈 6 次方关系下降，磁导率呈 6 次方关系上升。
