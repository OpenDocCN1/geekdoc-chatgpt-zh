联想到点燃样品凝胶出现的实验现象和实验样品的化学组成，可以推断实验中的硝酸盐柠檬酸凝胶，首先发生脱水反应，对应失重 9.82 wt%。随后在 200℃左右，凝胶分解中的还原剂柠檬酸离子和氧化剂 NO₃⁻ 发生氧化还原反应[114]。大量凝胶物质中 N—O 键和 N—N 键的断裂，含炭基团参与反应，激烈的氧化还原反应伴随着可能产物 NO₂、NO、CO₂、CO 挥发，而产生急剧失重（约 61 wt%）。

从图 2.7 TG、DTG 曲线中还可以看到，在空气中，222℃ 以后样品缓慢失重。其 DTG 曲线自 222℃ 开始至大约 481℃ 在形成一个峰，峰值温度 378℃。我们认为这是 α - FeO(OH)，γ - FeO(OH) 物质脱水，各金属氧化物的固-固相反应生成尖晶石结构（AB₂O₄）造成的。样品在约 481℃ 就达到了最大失重 15.38 wt%，而在动态氮气中，样品在约 700℃ 还未达到最大失重（图 2.5）。

根据原始原料所含物质，我们认为 222℃ 以后可能存在的物质只能有：FeO，Fe₂O₃，α - FeO(OH)，γ - FeO(OH)，NiO，ZnO 以及极少量的有机残余物。在此温度阶段 NiO、ZnO、α - Fe₂O₃ 是较稳定的物质，热分析没有任何变化[115]。所以除极少量有机残余物继续分解、挥发失重外，对失重可能有主要贡献的物质有：

- 2 · (α - FeO(OH)) ——→ α - Fe₂O₃ + H₂O (2.1)

- 2 · (γ - FeO(OH)) ——→ γ - Fe₂O₃ + H₂O (2.2)

- Cu₂O ——→ CuO (增重) 或 CuO ——→ Cu₂O (失重) (2.3)

考虑到 222°C 后，被测样品仅失重 15.38% 的测量结果。我们认为既然反应中 NiO、ZnO 没有质量变化且忽略 CuO 的反应中重量的变化，那么反应前后物质失重只与 FeO(OH) ——→ Fe₂O₃ 反应相关。可以粗略估计：因生成一克分子 Fe₂O₃ 需二克分子 FeO(OH)，则可能的失重百分比为：

```
1 - [Fe₂O₃ 分子量] / [2 · (FeO(OH)) 分子量 + 其他可挥发物质总分子量]
= 1 - 160 / (178 + X) = 15.38 wt%
(2.4)
```

由式 (2.4) 可见，只要假定“其他可挥发物质”分子量 X = 11 就可以得到失重百分比。由此可以算出这些“其他可挥发物质分子量”只占总反应物质分子量的 4%！因此我们认为，待硝化类含能物质在 222°C 左右分解基本完成后，后阶段失重主要是脱羟基水形成的。此时剩余物质中存在大量的 FeO(OH)，在有空气的情况下，适量的氧气可能会加速 FeO(OH) 脱羟基水转换，而无氧时这个反应过程则较慢。其反应过程：硝酸盐柠檬酸干凝胶 ——→ 100°C 脱去吸附水和自由柠檬酸基 ——→ 200°C 干凝胶有机络合物聚合、自燃 ——→ 200 ~ 500°C FeO(OH) 脱结构水并与纳米晶金属氧化物固相反应合成尖晶石型 NiZn 铁氧体。

## 2.3.5 反应动力学参数计算

热分析动力学是指用化学动力学的知识解析用热分析方法测得的物理量(如质量、温度、热量、模量、尺寸等)的变化速率与温度的关系。这种动力学分析不仅可用于研究各类反应，还可用于分析各类转变和物理过程(如结晶、扩散等的速率过程)[116]。热分析动力学的最基本假定是认为表示化学反应速率与温度关系的 Arrhenius 方程可用于热分析反应，即对于

A_{被} \longrightarrow B_{固} + C_{气} (2.5)

的反应速率，可表示为

-\frac{dC}{dt} = kf(C) (2.6)

式(2.6) 中 $k = A\exp(-E/RT)$，对于简化模式的函数形式 $f(C) = C^n$。式中可反应物量，即剩余分数 $C$ 对热重曲线而言，定义为：$C = \frac{W}{W_0}$，$W_0$ 是反应前的物质重量。对于多阶反应，上述各量的定义，都是指所讨论的那个特定过程而言，并非对应全过程。$A$ 是频率因子，$E$ 是活化能 (kJ/mol)，$n$ 是反应级数，这三个量就是要求解的动力学参数。$R$ 是气体常数，其值为 8.31 J/(mol·K)，升温速率是 $\phi = \frac{dT}{dt}$。因此可以导出热重动力学微分法和积分法的最基本式

-\frac{dC}{dT} = \frac{A}{\phi} e^{-E/RT} C^n (2.7)

由此出发可以导出各种动力学式。

可以根据 Freeman-Carroll 和 Kissinger 两种不同方法求解空气中凝胶热分解反应动力学参数。对第一放热峰，使用 Freeman-Carroll 法[117]，其动力学参数可由公式作图求得

\(-\frac{E}{2.3R} \cdot \frac{\Delta(\frac{1}{T})}{\Delta \lg w} = \frac{\Delta \lg(\frac{dw}{dt})}{\Delta \lg w} - n\)

其中，$w$ 为可反应物浓度；$dw/dt$ 为在时间 $t$ 时的质量损失速率；$T$ 为温度(K)；$n$ 为反应级数；$R$ 为气体常数；$E$ 为活化能(kJ/mol)。

作 $\Delta(1/T)/\Delta \lg w$ 与 $\Delta \lg(dw/dt)/\Delta \lg w$ 关系如图 2.9 所示。根据图中直线斜率及公式计算可得，在 195—201℃处拟合直线斜率为 -3 008.6，截距为 3.53，于是计算得活化能 $E = 57.6$ kJ/mol，反应级数 $n = 3.53$。

我们知道在许多情况下动力学参数还不能视为物质的特性参数。进行动力学分析应当具有明确的目的性，不单是为了求得动力学参数值，还要与反应过程、结构因素、工艺条件和材料评定等紧密相关。
