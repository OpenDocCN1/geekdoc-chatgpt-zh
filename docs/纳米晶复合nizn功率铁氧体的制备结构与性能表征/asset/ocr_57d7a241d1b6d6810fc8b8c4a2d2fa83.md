2Fe3O4 + 0.5NiO + 0.5ZnO --> Ni0.5Zn0.5Fe2O4 (6.3)

其中 λ, θ, β, ε 和 L 分别是实验所用 X 射线的波长、衍射角、衍射峰的半高宽、晶格应力和晶粒尺寸大小。从这一关系出发，作为粗略估计，得到本实验所给出的晶粒尺寸大约在 10~50 nm 之间，也就是说，确实形成了较好的纳米晶结构。从衍射强度来看，经过 100 h 球磨，无论纯 Fe3O4 样品还是混合粉末样品，其衍射强度都大大低于常规 NiZn 铁氧体样品，大约仅为常规 NiZn 铁氧体样品的十分之一。其原因主要是因为长期球磨使粉料颗粒度大大变小，且衍射线的宽度与垂直反射面的晶体厚度有关，晶体越小，hkl 倒结点的反射区愈弥散，衍射线愈平坦，衍射线的宽化，使衍射强度随之下降。
