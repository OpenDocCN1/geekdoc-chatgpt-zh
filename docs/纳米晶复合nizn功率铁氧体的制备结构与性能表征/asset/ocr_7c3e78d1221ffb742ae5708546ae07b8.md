# 第六章 高能球磨法制备纳米晶 NiZn 铁氧体的结构和磁性

# 6.1 引言

高能球磨作为一种重要的方法被广泛应用于诸多材料的合成与制备研究，它利用球磨机的高速振动和转动，使硬球对原料进行强烈的撞击、研磨和搅拌。它能使粉末产生塑性形变及固相形变，能使晶格缺陷不断在大晶粒颗粒内部大量产生，而使颗粒中大角度晶界重新组合，使颗粒内晶粒尺寸大幅度下降，且具有工艺简单、产量大的优点。1988 年，日本京都大学 Shingu 等人报道了高能球磨法制备 Al –Fe 纳米晶材料，为纳米材料制备开拓了一条实用化生产途径。目前机械化学合成主要在振动式或行星式球磨机中进行。运用这些机械已成功得到纳米纯金属和合金[169-170]，互不溶体系纳米结构材料[171]，纳米金属间化合物[172-174]，纳米级金属－陶瓷粉复合材料[175]，聚合物－无机物纳米复合材料等[176-177]，越来越受到物理学和材料科学工作者的重视。然而对无机金属氧化材料间直接用机械化学合成纳米材料的研究[178]很少有报道。

NiZn 铁氧体是一种在高频范围有着广泛应用的软磁材料，其制备和性质研究一直备受人们注意。虽然现在已有化学共沉淀、溶胶—凝胶法等方法制备更好的纳米晶 NiZn 铁氧体[179-183]，但人们试图用新方法新原料复合 NiZn 铁氧体材料的努力一直没有停止过。例如，1998 年，中国科学院上海硅酸盐所高性能陶瓷与超微结构国家重点实验室的姜继森等人用高能球磨法，采用 α – Fe₂O₃ 为主要材料
