# 图 3.7 不同掺 Co²⁺ 量样品在 1 200℃烧结的显微结构

实验结果表明，掺了 Co²⁺ 的样品晶粒都比相同温度下没有掺 Co²⁺ 的要小得多。可能原因是 Co²⁺ 所具有的较强的各向异性对晶粒长大的抑制作用。随着掺 Co²⁺ 量的增加，它对晶粒长大的抑制作用也增强。由于掺杂了 Co²⁺，样品的扫描电镜(SEM)照片很模糊，这表明样品断面表面电阻率很高，是 SEM 的扫描电子在样品表面积集，才形成一片一片的白色区域。Co²⁺ 掺杂能提高材料电阻率，这可从铁磁理论获知，即 Co²⁺ 的电离能低于 Ni²⁺ 而高于 Fe²⁺，因此在高温时，Co²⁺ 对氧的亲和力比 Ni²⁺ 强；在较低温度时，又可给氧于 Fe²⁺，即：

```
Ni³⁺ + Co²⁺ ——> Ni²⁺ + Co³⁺       (3.2)
Co³⁺ + Fe²⁺ ——> Fe³⁺ + Co²⁺       (3.3)
```

从而抑制了 Fe²⁺ 与 Ni³⁺ 的出现，使 ρ 值提高。
