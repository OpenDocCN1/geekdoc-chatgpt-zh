# 3.4.1.3 晶粒的结晶成长

再结晶和晶粒长大是与烧结并行的高温动力学过程，在烧结的全过程，特别是烧结后期，将产生很大影响。在烧成中有三个性质不同的过程影响晶粒的大小，即再结晶、晶粒长大和二次再结晶。

# (1) 再结晶

从塑性变形的具有应变的基质中，产生出新的无变形晶粒成核和长大过程。此过程的主要推动力是基质塑性变形所增加的能量，贮藏于基质中的这一能量虽然不大，但却足以影响晶粒大小的变化和晶界的移动。
