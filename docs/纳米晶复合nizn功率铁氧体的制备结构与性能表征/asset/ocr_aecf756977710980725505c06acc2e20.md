共振法测量原理如图 4.3 所示。

在图 4.3(a)的无负载电路中,对于低损耗共振频率和 Q 值为：

```
$\omega_0 = (LC)^{-1/2}, \quad Q = \frac{\omega_0 L}{R}$ (4.27)
```

该电路加入负载阻抗 $Z_x = R_x + j\omega L_x$ 时,我们得到

```
$\omega_1 = [(L + L_x)C]^{-1/2}, \quad Q_1 = \frac{\omega_1(L + L_x)}{R + R_x}$ (4.28)
```

由于 L 和 C 是已知的,则由 $\omega_0, \omega_1, Q_0$ 和 $Q_1$ 就可以算出 $R_x$ 和 $L_x$ 的值。
