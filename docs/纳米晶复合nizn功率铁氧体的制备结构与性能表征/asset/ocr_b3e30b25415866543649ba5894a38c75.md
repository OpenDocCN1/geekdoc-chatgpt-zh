大体积应变,使烧结致密化难于发生,有时还引起坯体开裂。若能选用适宜的添加物加以抑制,既可促进烧结,又能阻止晶型转变,并防止制品的开裂。

+   ③ 抑制晶粒长大。由于烧结后期晶粒长大,对烧结致密化有抑制作用。但若二次再结晶或间断性晶粒长大过快,又会因晶粒变粗,晶界变宽而出现反致密化现象并影响制品的显微结构。这时,可通过加入能抑制晶粒异常长大的添加物,来促进致密化进程。但由于晶粒长大与烧结的关系较为复杂,正常的晶粒长大是有益的,要抑制的只是二次再结晶引起的异常晶粒长大。因此,并不是能抑制晶粒长大的添加物都有助于烧结。

+   ④ 产生液相,烧结时若有适宜的液相,往往会促进颗粒重排和传质过程。添加物的另一作用机制,就在于能在较低温度下产生液相以促进烧结。液相的出现,可能是添加物本身熔点低,也可能与烧结物形成多元低并熔物。添加物一旦选定,合理的添加量是主要因素,对每一种添加物都会有一个适宜的添加量。适量的添加量可使烧结加速,反之则可能阻碍烧结。

# 3. 4. 2. 5 气氛的影响

有些物料的烧结过程对气体介质十分敏感。不仅是物料本身的烧结,而且添加物也会受到影响。而同一种气体介质对于不同物料的烧结,往往表现出不同的有时甚至是相反的效果,因此需要进行相应的气氛控制。从作用机制讲,烧结气氛有物理和化学两方面作用,这里仅讨论气氛对烧结的物理影响。

在烧结后期,坯体中孤立闭气孔逐渐缩小,压力增大,逐步抵消了表面张力的烧结推动作用,烧结趋于缓慢,通常情况下难于达到完全烧结。这时继续致密化除了由气孔表面过剩空位的扩散外,闭气孔中的气体在固体中的溶解和扩散等过程也起着重要作用。当烧结气氛不同时,闭气孔内的气体成分和性质不同,它们在固体中的扩散、溶解能力也不相同。气体原子尺寸愈大,扩散系数愈小,反之扩散系数愈大。
