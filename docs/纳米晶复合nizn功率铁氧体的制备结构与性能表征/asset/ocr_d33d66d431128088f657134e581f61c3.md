少量的有机残余物。在此温度阶段 NiO、ZnO、α - Fe₂O₃ 是较稳定的物质，热分析没有任何变化[115]。所以除极少量有机残余物继续分解、挥发失重外，对失重可能有主要贡献的物质有：

+   2 · (α - FeO(OH)) ——→ α - Fe₂O₃ + H₂O (2.1)
+   2 · (γ - FeO(OH)) ——→ γ - Fe₂O₃ + H₂O (2.2)
+   Cu₂O ——→ CuO (增重) 或 CuO ——→ Cu₂O (失重) (2.3)

考虑到 222°C 后，被测样品仅失重 15.38% 的测量结果。我们认为既然反应中 NiO、ZnO 没有质量变化且忽略 CuO 的反应中重量的变化，那么反应前后物质失重只与 FeO(OH) ——→ Fe₂O₃ 反应相关。可以粗略估计：因生成一克分子 Fe₂O₃ 需二克分子 FeO(OH)，则可能的失重百分比为：

```
1 - [Fe₂O₃ 分子量] / [2 · (FeO(OH)) 分子量 + 其他可挥发物质总分子量]
= 1 - 160 / (178 + X) = 15.38 wt%
(2.4)
```

由式 (2.4) 可见，只要假定“其他可挥发物质”分子量 X = 11 就可以得到失重百分比。由此可以算出这些“其他可挥发物质分子量”只占总反应物质分子量的 4%！因此我们认为，待硝化类含能物质在 222°C 左右分解基本完成后，后阶段失重主要是脱羟基水形成的。此时剩余物质中存在大量的 FeO(OH)，在有空气的情况下，适量的氧气可能会加速 FeO(OH) 脱羟基水转换，而无氧时这个反应过程则较慢。其反应过程：硝酸盐柠檬酸干凝胶 ——→ 100°C 脱去吸附水和自由柠檬酸基 ——→ 200°C 干凝胶有机络合物聚合、自燃 ——→ 200 ~ 500°C FeO(OH) 脱结构水并与纳米晶金属氧化物固相反应合成失晶石型 NiZn 铁氧体。
