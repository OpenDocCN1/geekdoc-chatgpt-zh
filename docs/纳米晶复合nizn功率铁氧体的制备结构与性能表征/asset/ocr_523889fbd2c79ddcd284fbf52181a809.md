# 5.5 小结

通过对同一配比样品用不同方法掺杂铋的实验研究证明：湿凝胶阶段掺杂方法，工艺简单，掺杂种类、数量易于控制，分散均匀，是切实可行的方法。这给高性能铁氧体磁性材料制备开辟了一条经济、方便、实用、可靠的工艺路线。此方法易于操作、工艺重复性好、节约成本和能耗，还可以推广应用到其他精细陶瓷产品制备工艺中去。

本章的纳米晶、微米晶复合烧结实验研究表明，随着起始烧结坯体中微米晶数量增多，材料磁导率也会增大，而且材料损耗也相应增大。对纳米晶铁氧体而言，要使其在复合烧结中起催化作用，成型密度还必须提高，晶体粒度还要减小，纳米晶的种类和数量还要仔细挑选。然而纳米晶的可控制备还是为我们设计、制备新型材料提供了
