# 第四章 掺杂纳米晶 NiZn 功率铁氧体的频谱特性

# 4.1 引言

基本配方决定了材料的本征性能，如 $M_s, K_1, \lambda_s$ 等，从而对材料可能达到的主要技术指标，如磁导率、矫顽力、损耗、减落等大致上亦可确定下来。要保证这些参量达到最佳的状态，除配方外，尚需有合适的工艺条件（如烧结），以产生合适的显微结构与离子价态。此外，添加一些必要的添加物又可以显著地影响显微结构、晶界组成、离子价态，等等[133-143]。目前，改进铁氧体性能、调节磁性能参数一般是通过改进原材料纯度和活性，在铁氧体中掺杂方式来实现。现有技术的掺杂方法都是采用传统的固相反应法，既用金属氧化物、碳酸盐，如： $Fe_2O_3, ZnO, NiO, MnCO_3$ 等为原料，其制备工艺主要是：配料→球磨 1→预烧→球磨 2→造粒→成型→烧结→成品。而掺杂过程一般在第二次球磨时进行，即将需掺杂的微量金属的氧化物在进行第二次球磨时，加入到铁氧体的主体原料中，然后经造粒、成型、烧结，最后形成成品。但是，在传统的工艺方法中存在一些严重的局限性：第一，传统工艺生产周期长。第二，传统工艺需要将材料在高温下长时间加热，这样就会造成一些元素的蒸发而改变了原来的化学计量量。例如，在 NiZn 铁氧体烧结中，锌在高温时的挥发会导致 $Fe^{2+}$ 离子的形成，并由此增加了电子频繁的活动而造成电阻系数的减少。第三，较长时间球磨的操作过程会导致化学计量物质的损失和混入非化学计量成分的杂质。第四，原材料本身纯度和活性对材料固
