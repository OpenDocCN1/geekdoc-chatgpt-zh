# 2.3.5 反应动力学参数计算

热分析动力学是指用化学动力学的知识解析用热分析方法测得的物理量(如质量、温度、热量、模量、尺寸等)的变化速率与温度的关系。这种动力学分析不仅可用于研究各类反应，还可用于分析各类转变和物理过程(如结晶、扩散等的速率过程)[116]。热分析动力学的最基本假定是认为表示化学反应速率与温度关系的 Arrhenius 方程可用于热分析反应，即对于

A_{被} \longrightarrow B_{固} + C_{气} (2.5)

的反应速率，可表示为

-\frac{dC}{dt} = kf(C) (2.6)

式(2.6) 中 $k = A\exp(-E/RT)$，对于简化模式的函数形式 $f(C) = C^m$。式中可反应物量，即剩余分数 $C$ 对热重曲线而言，定义为：$C = \frac{W}{W_0}$，$W_0$ 是反应前的物质重量。对于多阶反应，上述各量的定义，都是指所讨论的那个特定过程而言，并非对应全过程。$A$ 是频率因子，$E$ 是活化能 (kJ/mol)，$n$ 是反应级数，这三个量就是要求解的动力学参数。$R$ 是气体常数，其值为 8.31 J/Kmol，升温速率是 $\phi = \frac{dT}{dt}$。因此可以导出热重动力学微商法和积分法的最基本式

-\frac{dC}{dT} = \frac{A}{\phi} e^{-E/RT} C^m (2.7)

由此出发可以导出各种动力学式。
