# 样品综合性能：

# 1. H - 系列：关键综合技术指标与材料性能

+   - 饱和磁感应强度： Bs ≥ 4 100 Gs(或 0.41 T)
+   - 磁导率： μi ≥ 232
+   - 频带宽度 f = 0.05 ~ 10 MHz
+   - 矫顽力： Hc ≤ 1.02 Oe(或 1.02 · 10³ (4π)⁻¹ A · m⁻¹)
+   - 居里点温度： Tc ≥ 205℃
+   - 电阻率： ρ ≥ 2.45 × 10⁷ Ω/cm
+   - 相对损耗： tan δ/μ ≤ 95 × 10⁻⁶ (50 kHz ~ 4.0 MHz)
+   - 材料密度： 4.98 g/cm³
