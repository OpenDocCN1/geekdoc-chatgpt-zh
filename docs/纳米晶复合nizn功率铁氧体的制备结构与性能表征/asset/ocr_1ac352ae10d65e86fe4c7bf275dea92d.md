# 第二章 凝胶自燃法制备纳米晶 NiZn 铁氧体的结构与磁性

# 2.1 引言

铁氧体磁性材料的制备工艺与陶瓷制备工艺相仿，通常称铁氧体磁性材料为黑色陶瓷。在铁氧体磁性材料生产领域，铁氧体磁性材料制备中原料的来源和质量的重要性不言而喻。为了改善原料的活性，传统工艺采用了深度球磨的方法，这难免在长期球磨中引进杂质，影响了材料的性能。传统的铁氧体磁性材料制备工艺包含四个主要工艺步骤：制粉、预烧、成型、烧结，而且通常在预烧前后分别各有一次球磨粉碎过程。球磨工艺是带来外来影响因素的主要工艺环节。因此要获得性能优良的铁氧体制备粉料，必须采用新的方法，对铁氧体粉体制备工艺进行改革。

如第一章所述，化学制粉方法各种各样，有的可以直接制备出纳米晶铁氧体粉体；有的只能先制备出氧化物粉体，然后需要高温煅烧、粉碎；有的从溶液中生长出固相微粒后，需要把溶液从微粒粉料中排除掉，随着最后一部分溶液的排除，最终残留在颗粒间的微量水，通过氢键会将颗粒与颗粒粘在一起；有的需要专门复杂的高温、高压设备，生产成本较高；有的需要复杂的工艺控制等等。鉴于高性能铁氧体磁性材料对其制备原料粉体的严格要求，通过仔细挑选比较，我们认为：硝酸盐柠檬酸溶胶凝胶+自燃法（简称凝胶自燃法）是能够满足高性能铁氧体磁性材料制备对粉体要求的工艺方法。因为它原料容易获得，各种金属几乎没有硝酸不能溶解的，而且通过凝胶
