基水而变成活性很大的氧化铁，部分与原料中的金属氧化物通过固相反应生成尖晶石铁氧体，一部分则由于缺氧生成同样是尖晶石结构的四氧化三铁。因此剩余物质中除少量氧化锌外还有少量氧化镍。对 X 光衍射图谱进一步分析表明，磁铁矿 Fe3O4 的特征衍射峰密勒指数为[311]，[222]，[400]，[422]，[511]与空气中热处理的样品的 X -射线衍峰位置相近，NiO 的特征衍射峰密勒指数为[111]，[200]与空气中热处理的样品的 X -射线衍峰密勒指数为[222]，[400]位置相重叠，所以它们不能很清晰的表现在 XRD 衍射图上。

综合以上分析，我们认为在氮气中热处理的样品不能很好地形成纯的尖晶石型 NiZn 铁氧体，还存在部分四氧化三铁、少量的镍、锌氧化物和碳化物。样品中的碳（或碳化物），是由于热分解过程中有机物挥发过程因缺氧而留下的残余物。通过凝胶自燃合成纯的尖晶石型 NiZn 铁氧体，需要一定的氧分压，否则这个过程将不能合成完全单一相的 NiZn 铁氧体纳米晶。
