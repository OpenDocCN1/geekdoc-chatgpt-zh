复数磁导率可以表示为 \(\mu = \mu' - j\mu''\)。其中，\(\mu''\) 相应于能量的损耗，而 \(\mu'\) 相应于能量的储存。在弱交变场中，磁感应强度 B 的变化可以认为与交变磁场仅落后一位相角 \(\delta\)，如以复数形式表示，即为：

\(\widetilde{H} = H_m e^{j\omega t}, \quad \widetilde{B} = B_m e^{j(\omega t - \delta)} \quad (4.1)\)

因为，\(\tan \delta = \mu''/\mu'\)，因此 \(\delta\) 又称损耗角，它与 \(\mu''\) 成正比，\(\tan \delta\) 的倒数称为品质因数，即 \(Q = \frac{1}{\tan \delta}\)，\(\mu'\)，\(\mu''\)，\(\tan \delta\)，Q 值（或称品质因数）是表征软磁铁氧体交流磁性的基本物理量，在生产中往往以比损耗系数（又称相对损耗） \(\frac{\tan \delta}{\mu'} = \frac{1}{\mu' Q} = \frac{\mu''}{(\mu')^2}\) 或 \(\mu Q\) 积来表征材料的交流磁性。一般希望 \(\mu'\) 高，\(\mu''\) 低，即要求 Q 值高，\(\tan \delta\) 小或 \(\mu Q\) 值高。
