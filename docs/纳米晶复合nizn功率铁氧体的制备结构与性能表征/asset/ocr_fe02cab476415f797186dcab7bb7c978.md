# 4.5 小结

本章介绍了铁氧体掺杂制备的新工艺，分析了掺杂 NiZn 铁氧体材料的频率特性和损耗特性。具体对本实验举例的掺杂样品而言，它们的磁导率和损耗都很差。这除了配方本身的因数外，较小的晶粒尺寸和较低的密度是其根本原因。因为我们的目标是制作高频、低耗和低温烧结材料，所以实验中就没有在做更高温度的烧结实验。很显然进一步提高烧结温度会带来更高的样品磁导率，但同时材料的损耗也会大大增加。

本章实验通过将溶胶—凝胶纳米技术引入铁氧体材料制备之中，通过凝胶自燃新方法，先制备出性能优异的纳米晶铁氧体前驱物；然后利用纳米颗粒的高活性、低熔点等特点，通过调节配比，掺杂种类和数量，成型密度和烧结工艺，特别是注意控制了显微结构，最后成功制备出了高饱和磁感应强度、高磁导率、低损耗、宽频、高致密度的 NiZn 功率铁氧体软磁材料。实现了低温烧结，为小型化、集成化、一体化磁电子功率器件的制备提供了基础。解决了 NiZn 功率铁氧体材料制备中的诸多技术关键，获得了具有自主知识产权的创新性研究成果，材料综合性能处于国内领先地位，达到国际同类材料的先进水平。
