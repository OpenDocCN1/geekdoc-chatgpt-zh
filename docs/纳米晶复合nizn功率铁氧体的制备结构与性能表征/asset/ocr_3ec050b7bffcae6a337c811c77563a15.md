式(3.9)中 D 和 D0 分别是保温时间为 t = t 和 t = 0 时的晶粒尺寸，K 为与晶粒界面张力、晶界扩散系数等有关的常数，指数 m 的值通常是 2~4，由不同的扩散机制决定。表 3.1 列出不同情况下 m 的值[132]。

# 表 3.1 不同情况下式(3.9)中的 m 值

| 机制 | 物质迁移途径 | m |
| :--- | :--- | :--- |
| 气孔控制 | 表面扩散 | 4 |
| | 晶格扩散 | 3 |
| | 气相传质 | 2 或 3 |
| 晶界控制 | 纯系统 | 2 |
| | 第二相钉扎 | 3 或 4(体积扩散取 3, 晶界扩散取 4) |
| | 通过连续第二相扩散 | 3(即液相烧结情况) |
| | 杂质阻滞 | 3 |

当 D >> D0，式(3.9)可写成

D = Kt^{1/m} (3.10)

式(3.10)可用平均晶粒面积 A 来表示，由于 A = π(D/2)^{2}，则有

A = C_0 t^{1/m} (3.11)

式(3.11)中 C_0 为常数。当晶粒面积和时间都以对数坐标来表示时，可得直线关系式

log A = (1/m) log t + C (3.12)

式(3.12)中，C 为常数。这里 m 称为晶粒生长的动力学指数。实验和模拟的结果表明，m 值通常不是常量，而会随时间延长而减小。

# 3.4.2 影响烧结的因素

有许多因素影响烧结，在讨论各种不同烧结机制中已知烧结温度、时间和物料颗粒尺寸是最直接的影响的重要因素。
