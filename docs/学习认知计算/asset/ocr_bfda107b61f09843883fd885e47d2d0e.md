的知识状态向量 $h_t$ 用集成输入 $v_t^c$ 和学习者先前知识状态 $h_{t-1}$ 进行更新：

$$h_t = \phi(v_t^c, h_{t-1})$$ (6.11)

式中，\(\phi\) 表示更新函数。

同样，在预测学习者成绩的过程中，该模型将下一个时间步 \(t+1\) 时的遗忘信息 \(c_{t+1}\) 与更新后的学习者的知识状态向量 \(h_t\) 进行集成：

$$h_t^c = \theta^{out}(h_t, c_{t+1})$$ (6.12)

式中，\(\theta^{out}\) 为输出集成函数，它将遗忘信息引入预测过程中。随后，该模型基于更新后的学习者的知识状态 \(h_t^c\) 预测正确回答所有技能 \(y_i \in R^Q\) 的概率：

$$y_i = \sigma(b^{out} + W^{out}h_t^c)$$ (6.13)

式中，\(W^{out}\) 表示输出层的权重；\(b^{out}\) 表示输出层的残差系数。

# 3. 集成方式

本节使用了以下四种集成方法。

+   (1) 拼接：
+   
+   $$	heta^{in}(v_t, c_t) = [v_t; c_t]$$

+   (2) 矩阵乘：
+   
+   $$	heta^{in}(v_t, c) = v_t \odot C c_t$$

式中，\(C\) 表示可训练的变换矩阵，\(\odot\) 表示逐元素乘法。

+   (3) 拼接+矩阵乘：
+   
+   $$	heta^{in}(v_t, c_t) = [v_t \odot C c_t; c_t]$$

+   (4) 双向交互编码：
+   
+   $$	heta^{in}(v_t, c_t) = \sum_i \sum_{j \neq i} z_i \odot z_j, z_i \in \{v_t, C_i c_t^i | c_t^i \neq 0\}$$

# 4. 模型训练

通过计算正确回答下一个问题 \(q_{t+1}\) 的预测概率和真实标签 \(a_{t+1}\) 之间的标准交叉熵损失来学习模型参数：

$$\mathcal{L} = -\sum(a_{t+1} \ln(y_i^T \delta(q_{t+1})) + (1 - a_{t+1}) \ln(1 - y_i^T \delta(q_{t+1})))$$ (6.14)

式中，\(\delta(q_{t+1})\) 为时间步 \(t+1\) 时所回答问题的 one-hot 向量。

该方法对 DKT 模型进行了扩展，将与学习者遗忘相关的信息纳入模型中。与 DKT 模型相比，该方法在两个真实数据集上获得了更好的预测性能，实验结果发现，融合遗忘信息的模型预测性能会更好。
