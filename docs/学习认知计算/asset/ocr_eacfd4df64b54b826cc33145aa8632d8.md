1 - s_j ~ 4 - Beta(v_s, w_s, a_s, b_s) (9.11)

式中，4 - Beta(v_s, w_s, a_s, b_s) 是四参数 Beta 分布，对于 a < x < b, f(x) = \frac{(x-a)^{v-1}(b-x)^{w-1}}{\phi(v,w)(b-a)^{v+w-1}}, 在条件 \phi(v,w)=\int_0^1 u^{v-1}(1-u)^{w-1}du 下给定。

在给定 Y 和 T 下的 \boldsymbol{\beta}, \boldsymbol{\lambda}, \boldsymbol{g}, \boldsymbol{s}, \boldsymbol{t}, \boldsymbol{\alpha} 的联合后验分布为

L(\boldsymbol{\beta}, \boldsymbol{\lambda}, \boldsymbol{g}, \boldsymbol{s}, \boldsymbol{t}, \boldsymbol{\alpha} | \boldsymbol{Y}, \boldsymbol{T}) \propto L(\boldsymbol{\beta}, \boldsymbol{\lambda}, \boldsymbol{s}, \boldsymbol{g}; \boldsymbol{\alpha}, \boldsymbol{\tau}) P(\boldsymbol{\tau}) P(\boldsymbol{\alpha}) P(\boldsymbol{\beta}) P(\boldsymbol{\lambda}) P(\boldsymbol{g}) P(\boldsymbol{s}) (9.12)

在贝叶斯估计中，RT-CDM 参数的联合后验分布可以由参数的先验分布和观测数据的似然性产生。RT-CDM 是理解模型下反应模型 Y_{ij} 的条件分布。假设有 I 个学习者和 J 个项目，且学习者对每个项目的反应是独立的，因此学习者 i 反应模型 Y_i 的条件似然函数可以表示为

L(\boldsymbol{\beta}, \boldsymbol{\lambda}, \boldsymbol{s}, \boldsymbol{g}, \boldsymbol{t}, \boldsymbol{\alpha}) = \prod_{i=1}^I \prod_{j=1}^J \left[ P(Y_{ij} | T_{ij}) \right]^{Y_{ij}} \left[ 1 - P(Y_{ij} | T_{ij}) \right]^{1 - Y_{ij}} (9.13)

下面是用于参数估计的马尔可夫链蒙特卡罗方法（MCMC）的概要。在 t 次迭代下：

+   (1) 对于 \{\boldsymbol{\beta}, \boldsymbol{\lambda}\}，描述候选值 \boldsymbol{\beta}^{(*)} \sim Uniform(\beta_j^{(t-1)} - \delta_{\beta}, \beta_j^{(t-1)} + \delta_{\beta})， \lambda^{(*)} \sim Uniform(\lambda_j^{(t-1)} - \delta_{\lambda}, \lambda_j^{(t-1)} + \delta_{\lambda})，并设 \{\boldsymbol{\beta}^{(*)}, \boldsymbol{\lambda}^{(*)}\} 的概率为

P\left(\left\{\beta^{(t-1)}, \lambda^{(t-1)}\right\}, \left\{\beta^{(*)}, \lambda^{(*)}\right\}\right) = min \left\{ \frac{L(\beta^{(*)}, \lambda^{(*)}; \alpha^{(t)}) P(\beta^{(*)}) P(\lambda^{(*)})}{L(\beta^{(t-1)}, \lambda^{(t-1)}; \alpha^{(t)}) P(\beta^{(t-1)}) P(\lambda^{(t-1)})}, 1 \right\} (9.14)

+   (2) 对于 \boldsymbol{\tau}，描述候选参数 \tau_i^{(*)} \sim Uniform(\tau_i^{(t-1)} - \delta_{\tau}, \tau_i^{(t-1)} + \delta_{\tau})，并设 \tau^{(*)} 的概率为

P(\tau^{(t-1)}, \tau^{(*)}) = min \left\{ \frac{L(s^{(t-1)}, g^{(t-1)}; \alpha^{(*)}) P(\tau^{(*)})}{L(s^{(t-1)}, g^{(t-1)}; \alpha^{(t-1)}) P(\tau^{(t-1)})}, 1 \right\} (9.15)

+   (3) 对于 \boldsymbol{a}，候选参数 \alpha_{ik}^{(*)} \sim Bernoulli(0.5)，并设 \alpha^{(*)} 的概率值为

P(\alpha^{(t-1)}, \alpha^{(*)}) = min \left\{ \frac{L(s^{(t-1)}, g^{(t-1)}; \alpha^{(*)}) P(\alpha^{(*)})}{L(s^{(t-1)}, g^{(t-1)}; \alpha^{(t-1)}) P(\alpha^{(t-1)})}, 1 \right\} (9.16)

+   (4) 对于 \{\boldsymbol{g}, \boldsymbol{s}\}，候选值 g_j^{(*)} \sim Uniform(g_j^{(t-1)} - \delta_g, g_j^{(t-1)} + \delta_g)， s^{(*)} \sim Uniform(s_j^{(t-1)} - \delta_s, s_j^{(t-1)} + \delta_s)，并设 \{\boldsymbol{g}^{(*)}, s^{(*)}\} 的概率值为

P\left(\left\{g^{(t-1)}, s^{(t-1)}\right\}, \left\{g^{(*)}, s^{(*)}\right\}\right) = min \left\{ \frac{L(g^{(*)}, s^{(*)}; \alpha^{(t)}) P(g^{(*)}) P(s^{(*)})}{L(g^{(t-1)}, s^{(t-1)}; \alpha^{(t)}) P(g^{(t-1)}) P(s^{(t-1)})}, 1 \right\} (9.17)
