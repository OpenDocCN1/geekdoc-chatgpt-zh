# 2. RQ2: 消融实验

本节进行了消融实验，以进一步展示每个部分对最终结果的影响，如表 11.3 所示。TSDCD 有 4 种变体，每一种都是从完整的 TSDCD 方法中删除一个部分。

+   (1) TSDCD-K 指不考虑知识点编码的 TSDCD，即只考虑空间中的试题编号 \( q_t \)，不考虑知识 \( k_t \)。

+   (2) TSDCD-F 指排除遗忘的 TSDCD，即只使用作答序列中的索引位置，不再使用时间位置。

+   (3) TSDCD-L 指排除学习熟练度模块，即不考虑学习等特征的影响。

+   (4) TSDCD-S 指排除速度，即将式 (11.18) 中的 \( k \) 值设置为 1，即速度的预测不再纳入损失计算中。
