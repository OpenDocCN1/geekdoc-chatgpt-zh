# 4.2 基于统计结构的静态认知诊断模型

认知诊断模型实质上是一种受限的潜在特质模型，基于 $Q$ 矩阵，对学习者在具体的技能掌握状态进行诊断。为了得到一般的统计模型形式，首先从确定性心理模型的描述开始。假设测试中有 $J$ 个试题，考察 $K$ 个技能。$Q = \{q_{jk}\}_{J 	imes K}$ 为试题与技能的关联矩阵，它表示了学习者在每个试题上给出正确的答案，必须掌握哪些技能：

$$q_{jk} = \begin{cases} 1, & \text{试题 } j \text{ 查考技能 } k, k \in \{1, 2, \cdots, K\} \\ 0, & \text{其他} \end{cases}$$

我们为第 $i$ 个学习者定义一个向量 $\boldsymbol{\alpha}_i = (\alpha_{i1}, \alpha_{i2}, \cdots, \alpha_{ik}, \cdots, \alpha_{iK})$ 来表示学习者 $i$ 对各项技能的掌握状态。在认知诊断的确定性心理学模型中，掌握状态为二分变量：

$$\alpha_{ik} = \begin{cases} 1, & \text{试题 } i \text{ 掌握技能 } k \\ 0, & \text{否则} \end{cases}$$

最后，我们假设对一个试题中多种技能的认知要求是连接性的，也就是说，正确回答这个项目需要掌握该项目所需的所有技能。那么考生正确回答试题的概率是由以下确定性模型确定的：

$P(X_{ij} = 1 | \boldsymbol{\alpha}_i) = \pi_{ia}$

即属性掌握模式为 $\boldsymbol{\alpha}_i$ 的学习者正确作答该试题的概率。
