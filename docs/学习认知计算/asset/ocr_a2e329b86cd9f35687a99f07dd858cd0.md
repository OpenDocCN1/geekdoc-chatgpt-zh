# 5.3.2 原始概率矩阵分解算法

原始概率矩阵分解 PMF 算法由 Salakhutdinov 和 Mnih 于 2008 年提出，是一种经典的矩阵分解方法。PMF 与 BKT 一样，都是概率模型知识追踪的主要代表，两者都采用反馈式的用户交互建模；区别是 BKT 采用实时反馈的用户交互建模，PMF 采用阶段性反馈的用户交互建模。

PMF 针对学习者与答题情况建立 R 矩阵，R 矩阵中的元素由学习者的知识熟练度与题目涵盖知识点共同决定。R 矩阵中只有部分元素是已知的，且 R 矩阵通常比较稀疏，需要求出 R 矩阵中缺失的部分。PMF 的基本思路是采取 low-dimensional factor 模型（也称为 low rank 模型）来处理这个问题。其核心思想是矩阵元素间的关系可以由较少的几个因素的线性组合决定。

PMF 首先建立了一个 R 矩阵，其中，每个元素 R_ij 表示学习者 i 是否答对过题目 j，并假设 R_ij 是由学习者 i 的知识熟练度 U_i 与题目包含知识点向量 V_j 的内积决定的，即

R_ij = N(U_i^T V_j, \sigma^2) \quad (5.5)

式中，N 为正态分布；\(\sigma^2\) 为正态分布的方差。

观察到 R 矩阵的条件概率为

P(R|U,V,\sigma) = \sum_{i=1}^N \sum_{j=1}^M N(U_i^T V_j, \sigma^2)^{l_{ij}} \quad (5.6)

式中，U=(U_1,\cdots,U_N), V=(V_1,\cdots,V_M)，N 表示学生数量，M 表示试题数量；l_ij 是指示函数，若观察到 R_ij 则值为 1，否则值为 0。PMF 进一步假设学习者知识熟练度向量与题目包含知识点向量也服从正态分布，如式（5.7）和式（5.8）所示：

P(U|\sigma_U) \sim \prod_{i=1}^N N(0, \sigma_U^2 I) \quad (5.7)

P(V|\sigma_V) \sim \prod_{i=1}^N N(0, \sigma_V^2 I) \quad (5.8)

式中，I 为单位矩阵。

根据对后验分布 P(U,V|R,\sigma_U^2, \sigma_V^2, \sigma^2) 取对数，可以得到目标函数，如下：

loss = -\frac{1}{2} \sum_{i=1}^N \sum_{j=1}^M l_{ij} (R_{ij} - U_i^T V_j)^2 - \frac{\lambda_U}{2} \sum_{i=1}^N U_i^T U_i - \frac{\lambda_V}{2} \sum_{i=1}^M V_j^T V_j \quad (5.9)

式中，\(\lambda_U = \frac{\sigma^2}{\sigma_U^2}, \lambda_V = \frac{\sigma^2}{\sigma_V^2}; \sigma_U^2\) 表示 U 服从正态分布的方差，\(\sigma_V^2\) 表示 V 服从正态分布的方差。最终采用随机梯度下降算法更新 U 和 V。
