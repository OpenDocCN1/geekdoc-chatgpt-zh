同样，研究定义了技能相似矩阵 $R^S = [r_{ij}^s] \in \{0,1\}^{|S|\times|S|}$, 如下：

$$r_{ij}^s = \begin{cases} 1, \Gamma_S(i) \cap \Gamma_S(j) \neq \emptyset \\ 0, 其他 \end{cases}, i, j \in [1, \cdots, |S|] \quad (6.70)$$

同时使用内积来估计顶点特征空间中问题和技能之间的隐含关系：

$$\hat{r}_{ij}^q = \sigma(q_i^T q_j), i, j \in [1, \cdots, |Q|] \quad (6.71)$$

$$\hat{r}_{ij}^s = \sigma(s_i^T s_j), i, j \in [1, \cdots, |S|] \quad (6.72)$$

并最小化交叉熵以使顶点特征保持隐含关系：

$$\mathcal{L}_2(Q) = \sum_{i=1}^{|Q|} \sum_{j=1}^{|Q|} -(r_{ij}^q \lg \hat{r}_{ij}^q + (1-r_{ij}^q) \lg(1-\hat{r}_{ij}^q)) \quad (6.73)$$

$$\mathcal{L}_3(S) = \sum_{i=1}^{|S|} \sum_{j=1}^{|S|} -(r_{ij}^s \lg \hat{r}_{ij}^s + (1-r_{ij}^s) \lg(1-\hat{r}_{ij}^s)) \quad (6.74)$$

# 3. 难度特征

对于一个问题 q （为了清楚起见省略了它的下标），我们有它的问题顶点特征 q 和它的属性特征 f。为了通过产品层使属性特征与顶点特征相互作用，PEBG 首先使用由 w_z 参数化的线性层将属性特征 f 映射到低维特征表示，该低维特征被表示为 $a \in R^{d_v}$。假设与问题 q 相关的技能集合为 $C = \{s_j\}_{j=1}^{|C|}$，PEBG 模型将 C 中所有技能顶点特征的平均表作为 q 的相关技能特征，表为 $s'$，数学上可以表示为

$$s' = \frac{1}{|C|} \sum_{s_j \in C} s_j \quad (6.75)$$

研究使用顶点特征 q、平均技能特征 s' 和属性特征 a 来生成问题 q 的线性信息 Z 与二次信息 P。具体公式如下：

$$Z = (z_1, z_2, z_3) \triangleq (q, s', a) \quad (6.76)$$

$$P = [p_{ij}] \in R^{3 \times 3} \quad (6.77)$$

式中， $p_{ij} = g(z_i, z_j)$ 被定义为特征交互，并且 g 有不同的实现，本书中将 g 定义为向量内积， $g(z_i, z_j) = \langle z_i, z_j \rangle$。
