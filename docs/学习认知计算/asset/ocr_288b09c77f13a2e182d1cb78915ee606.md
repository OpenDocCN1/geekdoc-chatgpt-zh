# 图 6.17 AKT 模型框架

(1) 问题、知识编码器和知识检索器。AKT 模型使用了两个编码器，分别是问题编码器和知识编码器。问题编码器采用原始问题嵌入 $\{x_1, \cdots, x_t\}$ 作为输入，并输出使用单调注意机制的上下文感知问题嵌入序列 $\{\hat{\boldsymbol{x}}_1, \cdots, \hat{\boldsymbol{x}}_t\}$。每个问题的上下文感知嵌入既取决于其本身，也取决于过去的问题，即 $\hat{\boldsymbol{x}}_t = f_{\text{enc}_1}(x_1, \cdots, x_t)$。同样，知识编码器将原始问题-答案嵌入 $\{y_1, \cdots, y_{t-1}\}$ 作为输入，并输出使用相同的单调注意机制所获取的实际知识序列 $\{\hat{\boldsymbol{y}}_1, \cdots, \hat{\boldsymbol{y}}_{t-1}\}$。所获取知识的上下文感知嵌入取决于学习者对当前问题和过去问题的回答，即 $\hat{\boldsymbol{y}}_{t-1} = f_{\text{enc}_2}(y_1, \cdots, y_{t-1})$。

知识检索器将上下文感知问题 $\hat{\boldsymbol{x}}_{it}$ 和问题-回答对嵌入 $\hat{\boldsymbol{y}}_{i,t-1}$ 作为输入，并输出检索到的当前问题的知识状态 $\boldsymbol{h}_t$。在 AKT 模型中，学习者的当前知识状态是上下文感知的，因为其取决于学习者正在回答的当前问题；这与包括 DKT 模型在内的大多数现有方法不同。此外，知识检索器只能使用有关过去问题的信息、学习者对过去这些问题的反应及当前问题的表示，而不能使用学习者对当前问题的反应，即 $\boldsymbol{h}_t = f_{\text{kr}}(\hat{\boldsymbol{x}}_1, \cdots, \hat{\boldsymbol{x}}_t, \hat{\boldsymbol{y}}_1, \cdots, \hat{\boldsymbol{y}}_{t-1})$。反应预测模型使用检索到的知识来预测当前反应。

(2) 单调注意力机制。对于编码器和知识检索器，AKT 使用一种改进的、单调版本的缩放点积注意机制。一般缩放点积注意机制计算公式为

```
$$\alpha_{t, \tau} = \text{Softmax} \left( \frac{\boldsymbol{q}_t^\top \boldsymbol{k}_\tau}{\sqrt{D_k}} \right) = \frac{\exp \left( \frac{\boldsymbol{q}_t^\top \boldsymbol{k}_\tau}{\sqrt{D_k}} \right)}{\sum_{\tau'} \exp \left( \frac{\boldsymbol{q}_t^\top \boldsymbol{k}_{\tau'}}{\sqrt{D_k}} \right)} \in [0, 1]$$
```
