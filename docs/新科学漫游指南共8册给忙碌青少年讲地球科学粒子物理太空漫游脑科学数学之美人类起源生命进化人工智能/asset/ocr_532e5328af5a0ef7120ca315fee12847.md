假设你正在一场游戏节目中，并且有三扇门可以选择打开

请选择一扇门

一扇门后面藏着汽车，另外两扇门后面藏着山羊。
你选择 1 号门，知道答案的主持人打开另一扇门露出一只山羊。

![](bbox=[0.217, 0.276, 0.783, 0.413])

然后主持人对你说：

> “你要调换为 2 号门吗？”

与直觉相反，你应该调换。下面是原因：

| 你选择 | 2 | 主持人打开 | 3 | 你支持 | 你调换 |
|---|---|---|---|---|---|
| 汽车 | 山羊 | 或者 | 山羊 | ✓ | × |
| 山羊 | 汽车 | | 山羊 | × | ✓ |
| 山羊 | 山羊 | | 汽车 | × | ✓ |
| | | | | 1/3 | 2/3 |

主持人知道门后藏了什么的事实
会影响到你的机会：胜率。

如果选择是 2 号或 3 号，也同样适用。
