# 公元前 1800 年

巴比伦人发成了位值制. 在我们的数字中，每个数字的位置都代表 10 的次方，而巴比伦的数字系统是 60 的次方。没有“0”来填补数字之间的空白，这种写法可能会造成歧义：61 和 3601 变得难以区分。

# 公元前 300 年

巴比伦人为 0 发明了一个符号（斜杠），并且这个符号充当占位符，解决了数学中可能产生的歧义。

![](bbox=[0.29, 0.465, 0.51, 0.53])

# 公元 628 年

印度数学家婆罗摩笈多提出了负数的概念——将 0 作为正负值之间的交汇点。

# 公元 800 年

阿拉伯数字“0”首次在十进制系统中出现。

# 公元 1202 年

斐波那契将阿拉伯数字系统引入西欧。

# 16 世纪起

欧洲数学家在数学上使用 0，从而促进了笛卡尔几何和微积分的发展。
