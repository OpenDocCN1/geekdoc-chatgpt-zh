# 你面临的最大挑战是什么？

最大的挑战是无监督学习：机器只需观察世界即可获取常识的能力。我们目前还没有这方面的算法。

# AI研究人员为什么要关注常识和无监督学习？

因为这是人类和动物的主要学习方式。我们几乎所有的学习都是无人监督的。我们经由观察并生活在这个世界中来了解它是如何运转的，而无须他人告诉我们一切事物的名字。那么我们如何让机器像动物和人一样在无人监督的情况下学习呢？
