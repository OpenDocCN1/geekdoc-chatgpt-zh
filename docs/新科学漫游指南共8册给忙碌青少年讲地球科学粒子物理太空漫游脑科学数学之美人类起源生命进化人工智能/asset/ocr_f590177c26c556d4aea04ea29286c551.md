# 彩票

亚历克斯·怀特将永远不会忘记1995年1月14日的那个夜晚。这是英国国家彩票的第九次开奖，估计头等奖高达1600万英镑，怀特（这不是他的真名）选中了所有6个数字：7，17，23，32，38和42。不幸的是，怀特只赢得了122 510英镑，因为还有132个人也选择了相同的数字组合并分享了头等奖。
