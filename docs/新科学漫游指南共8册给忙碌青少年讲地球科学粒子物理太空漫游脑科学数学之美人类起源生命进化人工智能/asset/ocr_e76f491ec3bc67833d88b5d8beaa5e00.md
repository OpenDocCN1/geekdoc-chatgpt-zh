# 图2.2 阿德尔森棋盘错觉

乍看之下，标记A和B的方块呈现出不同程度的灰色。但实际上它们的深浅程度是一样的。这里展示的是，大脑使用了它此前掌握的知识，即投射在表面上的阴影会让该表面显得更深。由于我们期望B和它所处对角线中的其他所有方块颜色一样，于是大脑产生的预测认为，方块B在“真实世界”中大概是浅灰色的。继而，大脑将其感知为浅灰色，但是被阴影稍微加深了。这种效果是如此强烈，即使指出这是错觉，你的感知也不会改变。
