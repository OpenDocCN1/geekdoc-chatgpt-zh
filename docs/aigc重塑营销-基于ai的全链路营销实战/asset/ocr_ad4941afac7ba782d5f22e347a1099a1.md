# 图4-14 默认的设置组合

图4-14所示界面的上半部分是Midjourney的当前设置项，下半部分是niji.journey的当前设置项，可以看出两个模型的可设置项大部分重叠，但也有一些可设置项不同。用户在熟悉了默认设置之后，可以根据需要适当调整设置，以便更好地满足自己的需求。

Midjourney部分的第一个选项就是用于选择模型版本的下拉框，一般来说没有特别原因，会选最新版本。R AW是专业影像模式，其后的4个以Stylize开头的选项是风格化的程度，从低到高分为4个等级，绿色显示的那个是当前的选项。Midjourney部分还可设置作品是否公开、生成速度等。
