# 图7-7 私域流量和公域流量分布

从数据看，似乎公域更重要，但换一个角度就不一样了：已经进入私域的用户，对品牌的认可度更好，联系更加紧密，单位价值更高。所以，对绝大多数企业而言，一旦进入线上营销，私域就一定变得非常重要，即便它不一定比公域更重要。

线上公域可细分为如下几类。

+   • 电商平台：淘宝、京东、拼多多等。
+   • 社交平台：微信、Facebook等。
+   • 内容平台：抖音、快手、B站、微博、小红书等。
+   • 垂直平台：大众点评、懂车帝等。
