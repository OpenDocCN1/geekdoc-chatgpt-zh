# 线上营销的公域和私域

其实私域营销在线下同样存在，只是线上营销强化了公域、私域的概念。营销的全域已经明显分为公域和私域两个部分。很多企业到现在还在用上一个时代明显偏重公域的营销方式，营销效果自然是越来越差。
