# Midjourney出图前的准备

Midjourney要在Discord上使用。Discord是一个社交、聊天平台，类似于QQ。所以使用Midjourney的前提条件是安装了Discord，并注册了Discord账号。Discord的官网为https://discord.com/download，安装和注册按提示操作即可。限于篇幅，这里就不展开具体介绍了。图4-1所示是成功登录Discord之后的界面。
