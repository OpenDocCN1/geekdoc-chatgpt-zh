# 生成视频的方式和工具

生成视频的方式有如下3个。

+   ·文本：给出文本指令，获得生成的视频，通常是较短的视频片段。
+   ·图片：给出一张图，让AIGC在静态图的基础上生成视频。
+   ·视频：在已有视频的基础上生成新的视频，可以做风格转换、视频延长等处理。

以上3种方式可以结合使用，比如通过图片+文本来生成视频。

视频生成工具有很多，这里仅以几个知名度较高的产品为例。视频生成工具的操作方式大同小异，掌握了其中一两种工具的使用方法，其他工具都能很快上手。
