# 3. pika的基本使用

和Midjourney一样， pika也要在Discord平台上使用。

首先登录https://discord.com/invite/pika，加入pika。随后使用/create命令来添加图片和提示词，添加完毕之后按回车键即可生成相应的视频。

可以通过输入丰富的提示词来充分发挥pika的创造能力。
