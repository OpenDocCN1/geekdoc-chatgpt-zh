这是一个难以实现的目标。

仅有自然语言工具可能不足以完成任务。在怀纳和戈韦尔纳托里（Wyner 和 Governatori，2013）的著作中，研究者使用最先进的开源自然语言翻译工具——C & C / 工具箱——进行了一项试点研究，将规范陈述转化为语义表示。作者将输出表示与《澳大利亚电信消费者保护法典》（2012）中关于投诉管理的五个句子的手动创建的可辩驳逻辑表示进行了比较。

```
< T1 > 对自然人 < /T1 >
< A > 他 / 她被取消资格后拥有资格保证， < /A >
< C > 被保险人的条款加在一起。 < /C >

< T2 > 对于这项法律规定的养老金金额， < /T2 >
< A > 当这个国家或其他地方的生活标准有了显著变化时， < /A >
```

为了从制定法文本中成功地自动提取逻辑规则，似乎有必要关注一个具体的法律领域，并确定该领域的逻辑结构特征，以用作规则的模板。
