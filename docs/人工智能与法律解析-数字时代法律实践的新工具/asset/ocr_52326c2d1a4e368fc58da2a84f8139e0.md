# 11.1. 导言

本章描述的卢依马结构采用了第二部分的技术，用于文档的自动化概念标记和从法律案例文本中提取信息，并将它们集成到用于概念法律信息检索的原型系统中。该系统包括的模块用于自动子句级别的注解，基于机器学习的句子注解，使用全文信息检索系统的基本检索，以及基于机器学习对检索文档的再排名。本章解释了如何客观地评估这样一个系统，以及如何评估它对全文法律信息系统的贡献。

特别是，该章提出了支持卢依马假设的证据，该假设在第 10.5 节中提出过，即假设论证检索是可行的。通过使用论证角色信息系统地注解文档并基于注解检索它们，人们可以胜过依赖文本匹配和当前法律信息检索技术的当前系统（Grabmair 等，2015）。
