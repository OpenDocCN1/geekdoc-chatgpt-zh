息的领域一般性特征来表示，包括：

+   - 一每个单词、单词对和连续单词的对和三元组，
+   - 一词性包括某些副词、动词和模态辅助词（表示允许或义务的动词，例如“可以”，“必须，” “应该”和“应当”），
+   - 一某些标点符号模式，
+   - 一表示论证的某些关键词，例如“但是”，“结果”和“因为”，
+   - 一解析树的深度和子条款的数量（两个句子复杂度的度量），和
+   - 一某些文本统计数据，包括句子长度、平均字长和标点符号数。

(Mochales 和 Moens, 2011)

特征值典型地表示为象征句子中的特征存在或不存在的二进制特征。

为了将论证命题划分为前提或结论，作者使用了一组丰富的特征来表示句子，包括：

+   - 一句子相对于文档中的阈值和位置的长度（分为七个部分），
+   - 主动词时态和类型，
+   - 一先前和后续句子的类别，
+   - 一将句子的分类预处理为论证与否，
+   - 一句子和周围句子中出现的修辞模式的类型：支持、反对、结论、其他或没有，
+   - 一句子中论证模式的类型，例如，“看”、“已做必要的修改”，“已达成这一结论”，“多数认为”，
+   - 一句子是否引用法律条款或包含法律定义，以及
+   - 一句子主体的代理人类型，例如，申请人、被告、法院或其他人

(Mochales 和 Moens, 2011)。
