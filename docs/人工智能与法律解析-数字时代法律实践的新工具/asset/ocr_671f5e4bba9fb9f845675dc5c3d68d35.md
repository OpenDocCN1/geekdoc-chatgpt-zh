# 3.4. 基于案例的法律推理的目的论模型

海波系统、案例论证系统、卡巴莱系统和基于范例的解释生成器
等程序没有考虑法律规则背后的目的和价值。正如唐·伯尔曼（Don
Berman）和卡萝尔·哈夫纳（Carole Hafner）在其有影响力的批评中
指出的那样，这些早期的基于案例的推理模型不能进行目的论推理。

伯尔曼和哈夫纳（1993）用一系列案例说明了目的论推理，
这些案例来自美国法学院第一年的财产课程，涉及猎人对野生动物
的财产权。这三个案例分别是皮尔逊诉波斯特（Pierson v. Post,
3 Caines R. NY, 1805）和两个英国案例——基布尔诉希克林吉尔
（Keeble v. Hickeringill, 103 ER 1127, 1707）和扬诉希钦斯（Young v.
Hitchens, 115 ER 228, 1844），这三个案例从此成为人工智能与法
律中的标准示例（见第 5.5.2 和 6.6 节）。
