Cerno 使用无上下文语法法，即描述如何从满足语言句法的语言可用符号形成陈述的规则，以生成文本的解析树，解析树的成分为法律语言文本元素。然后，注解规则分析解析的文本，用标签注解它们，指示某些概念的存在与否。这些概念选自域本体。每个概念都有一个相关的指示词汇表，包括应该（或不应该）存在的文字和已解析实体的名称。最后，转换规则选择某些带注解的文本片段和输出模板，其中的域根据注解填充。

为了扩展注解规章文本的工具，作者手动解析了美国《健康保险可携带和责任法》隐私规则的一个片段，并生成了四个主要概念的指示列表。

+   1. 权利：有条件地允许利益相关者采取的行为；
+   2. 义务：有条件地要求利益相关者履行的行动；
+   3. 约束：描述单一前置或后置条件的权利或义务的一部分；和
+   4. 例外：从域中考虑移除的元素（Kiyavitskaya 等，2008，p.5）。

研究者将该工具应用于美国《健康保险可携带和责任法》隐私规则的其他片段（以及意大利制定法条款），他们将系统识别的权利、义务、约束和交叉引用的数量与人类识别的数量进行了比较。结果大致相当。评估表明需要添加更多规范性短语来识别约束。此外，该系统在识别约束的主体和客体方面存在一些困难，在识别合取和析取的主体方面也存在一些困难。
