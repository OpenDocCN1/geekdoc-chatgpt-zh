本中词语的词性，即名词、动词、形容词或副词（POS 标记）。人们还可以在解析句子的结构时注解语词的语法功能，例如直接对象或介词短语的对象（见 Turney 和 Pantel, 2010, p.155）。

在规范、标记和注解文档的文本后，文档被表示为特征向量。这种表示类似于术语向量（见第 7.5.2 节）。然而，在特征向量中，特征可以包括诸如二元模型或其他 n 元模型之类的附加信息以及类别信息。

表示语料库中的文档的特征向量都具有相同的长度 n，等同于与语料库中的单词和其他特征的总数。每个特征向量是从原点（0, 0, 0, ……, 0）到表示 n 维特征空间中文档的点的箭头。由于全文本语料库中的每个不同的单词或其他特征对应于另一个维度，因此维度的数量 n 将非常大。

每个维度的量是该文档的特征值。量可以是“0”，表示文档不具有该特征，或“1”表示它具有该特征。或者，量可以指示单词的频率或文档的其他特征（见 Fagan, 2016, p.53），或表示它在文档中的频率的词频 / 反文档频率值（见第 6.4 和 7.5.2 节），它的频率被它在语料库中的频率打折扣（见 Turney 和 Pantel, 2010, p.156）。

法律文本中机器学习的目标是对文档进行分类或进行预测。例如，在电子发现语境中，目标是将与诉讼相关的文档归类为“相关”文档或“不相关”文档。在涉及法律案件的机器学习语境中，目标可能是通过句子在法律意见中发挥的功能对句子进行分类，例如，作为“法律决定或法律裁决”的句子或“基于证据的发现”的句子。或者，目标可能是根据句子是否支持法律因素适用于案件的结论来对句子进行分类。因此，句子可能被归类为因素 F1 披露谈判或 F2 贿赂雇员的实例（或不是）。可以想象，学习的目标是预测案件的结果，预测的根据是从案例文本中收集的信息或索赔的优点［例如哪些法律因素适用（见第 12.4.2 节）］，并且这些案例文本与法官或律师的诉讼参与者和行为特征相关（见第 12.2 节）。在制定法条款的机器学习的语境中，目标可能是按行政法、私法、环境法或刑法等主题对条款进行分类。
