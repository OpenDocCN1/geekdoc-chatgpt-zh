# 10.5.3. 卢依马注解

在下一章中描述的卢依马系统的三个模块中的卢依马注解（如图 10.3 所示）是使用两种方法注解案例文本的模块：

+   1. 基于规则的子句注解，其中人通常基于一些示例的检查手动构建注解规则的语法。

+   2. 机器学习，其中机器学习算法从人注解的示例的训练集自动构建区分正面示例和负面示例的模型。这类似于第 8.4.2 节的预测编码。
