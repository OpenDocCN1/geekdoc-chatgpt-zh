作者开发了一种多阶段方法，涉及：

+   1. 文本分类（Text classification，简称为 TC）：基于机器学习的文本分类识别包含与自动合规性检查相关的要求类型的句子（例如，建筑行业的监管要求），

+   2. 信息提取：基于规则的语义自然语言处理在相关句子中识别携带目标信息的单词和短语，并用预定义的信息标签对它们进行标记，以及

+   3. 信息转换规则（Info Transformation Rules，简称为 ITr）：语义自然语言处理算法（信息转换规则）采用模式匹配规则将提取的信息转换为逻辑陈述，逻辑程序可以用逻辑陈述进行推理。这些规则使用句法和一些语义信息。

例如，文本分类承认以下句子与建筑设计的自动合规性检查相关：“天井宽度不得小于 3 英尺。” IE 标记有针对性的单词和短语，例如：

+   主语：天井
+   合规性检查属性：宽度
+   比较关系：不小于
+   数量值：3
+   数量单位：英尺
+   参考数量：不适用。

然后，信息转换规则触发；它的左侧标识规则模式：

```
主语 + 情态动词 + 否定 + 是 + 比较关系 + 数量值 +
数量单位 + 介词 + 合规性检查属性。
```

该规则的右侧是：“为‘主语’信息实例，‘属性’信息实例和‘有’信息实例生成谓词。”
