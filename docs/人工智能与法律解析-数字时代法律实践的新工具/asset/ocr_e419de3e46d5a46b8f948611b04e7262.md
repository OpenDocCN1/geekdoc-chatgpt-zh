# 第六章 用本体和类型系统表示法律概念

# 6.1. 导言

正如第一部分所指出的，知识表示一直是人工智能与法律研究的一个关键焦点，也是实施足够强大的系统作为现实世界法律实践工具的关键挑战。

本体（Ontologies）有助于应对这一挑战。本体指定了为系统目标而存在的事物或概念的基本类型，并列出了它们之间的关系。

在介绍了本体的一些基本信息之后，本章检讨了一些历史上很有影响的法律本体，并解释了一些用于半自动构建本体的现代技术。然后转向制定法推理和法律论辩的本体支持。与后者相关，一个扩展的例子说明了用部分案例进行论证的本体支持。

最后，本章介绍了一种特殊种类的本体，即“类型系统”（type systems），它是一种基本的文本解析工具。类型系统支持根据概念及其关系自动标记或注解法律文本。它们将在概念法律信息检索和认知计算中发挥关键作用。
