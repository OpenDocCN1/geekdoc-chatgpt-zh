# 价值：

+   CA：应制定并执行明确的保密协议
+   RE：有秘密的人应该采取合理的措施来保护它
+   LM：应允许一个人使用合法手段开发产品
+   QM：一个人不应该使用道德（或法律上）可疑的手段获取秘密
+   MW：只有在秘密具有某些物质价值的情况下才能进行诉讼

+   价值偏好好 ({CA,MW},{LM,RE})
+   价值偏好好 ({CA,QM,RE},{LM})
+   价值偏好好 ({LM}), {RE})
+   ......
