# 5.7.4. VJAP® 的基于论证的预测

基于价值判断的论证预测程序使用一组论证型式为每个案例构建一个论证图（Grabmair, 2016, p.iv）。鉴于案件 c 输入一系列所有可适用的因素。原告在 c 案中的商业秘密盗用诉讼请求将成功，基于价值判断的论证预测构建了一个支持这个命题的论证。

在论证图表结构中表示的论证使用反向链接记录劝举搜索的输出，以应用基于价值判断的论证预测支持的所有论证型式，包括基于共享局部或问题间权衡的类比论证的型式。这意味着对于每个问题，程序都会检查所有论证型式的可适用性。如果型式适用，则将其实例化，并且在相同过程的递归应用中论证它的前提。论证型式的每个可适用的实例的输出是一个论证，它被添加到论证图表结构中。这个过程一直持续到程序找不到新的论证，然后图表就完成了。（Grabmair, 2016, p.48）
