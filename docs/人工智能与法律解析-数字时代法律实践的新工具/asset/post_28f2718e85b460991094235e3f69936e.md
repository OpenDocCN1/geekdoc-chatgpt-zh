
类型标记。一些论证涉及对事实的争议，并被标记为涉及事实主张或断言。其他论证涉及关于基本价值或法律目标的争议，如果被接受，则根据论证所促进的价值进行标记（Bench-Capon，2003；Atkinson 和 Bench-Capon，2007）。

## 5.5. 法律论证的计算模型如何计算输赢？

上面阐释的法律论证的计算模型的目标是在一个论证案件事实的模型中结合适用的法律和基本价值，并尽可能地确定论证的输赢。正如我们将在下面看到的，其他一些计算模型的焦点更具描述性：详细描述或建模，法官做出的判决以及法官在意见中提供的合理性证明。

实际上，关于案件事实的论证、适用的法律规则、基本价值观以及可能的程序性问题，要求论证框架的层次结构。每个级别的论证都配备了各种各样的论证型式，确定论证可接受性的程序，证明标准，以及“区分基于论证之间偏好的论证可接受性概念，偏好在论证的元层次上得到证成”。

关于事实、规则和价值的命题都可以出现在基于价值的论证图中，如图 5.9 中的扬诉论证所示。在这个基础层面，论证是关于事实和价值的。然而，为了解决关于事实或价值的相互矛盾的论证，该程序需要“走向元”。也就是说，它突然出现在事实上的冲突解决层面，并引发了解决事实争议的论证型式，例如通过询问关于证人证词的关键问题。它还突然出现一个价值冲突解决层面，并引发论证型式来解决有关价值的争议，例如使用本奇·卡彭 / 萨托尔模型中的价值论证型式（第 3.5.1 节）（Atkinson 和 Bench-Capon，2007）。下面介绍说明这两种冲突解决层面的示例。

### 5.5.1. 解决关于事实的相互冲突的论证

例如，如图 5.9 所示，H1，一个事实主张（即，“场的网被破坏：鱼即将逃脱。”）攻击，并被另一个事实主张 Y2 攻击（即，“鱼有没有逃脱的可能性。”）如何在基于价值的论证框架中解决这样的冲突？

每个关于事实的冲突需要通过元级别论证单独解决，元级别的结果将导致在每个被指派的论证中状态可证成、可论证或不可支持 [ 强调补充 ]。（Atkinson 和 Bench-Capon，2007 年）

论证框架层级的冲突解决层面将配备用于事实推理的论证型式，其中包括针对事实断言的法律评估而定制的关键问题。反过来，这些为竞争性事实主张的偏好排序提供了基础。例如，关于事实主张的关键问题探讨了证人证词支持诉讼请求的可信度：证人有偏见吗？证人有能力知道吗？在现代诉讼语境中，专家证人的证词将受到以下关键问题的影响：证人是相关领域的专家吗？这个证人的断言与其他专家的断言一致吗？专家证人的陈述基于证据吗？（见 Walton 和 Gordon，2005）

如果可以获得对这些关键问题的答案，它们为解决事实冲突提供了基础，例如，图 5.9 中的 H1 和 Y2 之间，有利于原告扬，因为被告是一个有偏见的证人。然后，应用偏好的结果与相关的证明标准进行比较。（有关证明标准的卡涅阿德斯定义，请见表 5.2 的右侧。）不存在的那些将被移除：

那些得不到充分支持的论证取决于适用于上下文的证明标准：对于超出合理怀疑的合理的论证将被保留，而对于微弱证据，所有论证都可以被保留。（Atkinson 和 Bench-Capon，2007）

作为这个过程的结果，将会有“一套的可接受论证，这将被其最弱的成员所表示的程度所证明。”（Atkinson 和 Bench-Capon，2007）

### 5.5.2. 解决关于价值的相互冲突的论证

同样如图 5.9 所示，原告扬的论证涉及对基础价值的相互冲突的诉求。例如，

Y3：即“它们是我的鱼，因为它们没有逃脱的希望。通过这种程度的控制来获得所有权可以鼓励捕鱼。”

- 攻击 ( → )

H2：“因为它们没有被抓获，鱼可以捕获。基于澄清需要的明线论证。”

H3：“必须在商业中进行竞争。为 H4 设定价值。”和 H4：“我不应该受到惩罚，因为这会抑制激烈的竞争。反对诉诸竞争价值。”

- 攻击 ( → )

Y5：“希钦斯应该受到惩罚，因为他的做法不公平，例如他威胁到渔业。诉诸鼓励捕鱼的价值。”

基于价值的论证框架如何支持/解决有关 Y3 和 H2 等价值的论证？

根据阿特金森和本奇·卡彭（Atkinson 和 Bench-Capon，2007）的观点，“我们接下来需要进行价值比较：我们应该偏好……鼓励捕鱼或澄清？”

为了进行这种比较，作者需要对竞争价值进行一些排序。正如作者阿特金森和本奇·卡彭（Atkinson 和 Bench-Capon，2007）所说：

> 我们需要一些关于竞争价值的正确排序的指示，先例在这里变得相关……有可能引用先例来表明过去使用了某种特定的排序，当局为采用特定的排序赋予了权重，或者诉诸目的论证来证明该排序的合理性……希钦斯可以引用皮尔逊本身，而扬可以将基布尔作为反例。希钦斯可以区别于基布尔，理由是基布尔在他自己的土地上，这就是让他拥有鸭子的原因。

这些是基于案例的论证，类似于我们在上面的卡涅阿德斯示例中看到的论证。然而，在基于价值的论证框架中，它们是在论证框架层次结构的元级别上进行的，以便解决价值冲突（再次应用相关的证明标准）。价值偏好基于本奇－卡彭／萨托尔的观点，即案例引发价值偏好理论。也就是说，从先例的结果推断出排序，根据第 3.5.1 节中讨论的本奇－卡彭／萨托尔（2003）中的因素和价值偏好的理论构建模型，其中某些价值优于其他价值。

### 5.5.3. 解决关于法律规则的相互冲突的论证

尽管在场景中基于价值的论证框架没有包含解决有关法律规则的相互冲突的论证的例子，但上面的卡涅阿德斯示例传达了以下想法。在基于价值的论证框架中，关于规则的相互冲突的论证将使用相同类型的论证型式在元级别上予以解决，使用如上所述的可辩驳法律规则进行推理。

此外，像卡涅阿德斯这样的一些法律推理的计算模型用所谓的构造规则或解释的最大化来补充那些论证型式，用更一般的解释原则来解决关于法律规则的冲突论证，例如：

- 特别法优先（Lex Specialis）：更特别的规则优先于更一般的规则。
- 上位法优先（Lex Superior）：由上级机构支持的规则优先于由下级机构支持的规则（例如，联邦法律优先于州法律）。
- 后法优先（Lex Posterior）：后来的规则优先于先前的规则。

在戈登和沃尔顿（Gordon 和 Walton，2006）的著作中，卡涅阿德斯程序应用特别法优先原则来解决如下冲突：两条源于关注“严重身体伤害”意义的先例的规则之间的冲突。一条规则指出“打断几根肋骨并不构成严重的身体伤害”，而另一条规则则认为“打断几根肋骨连同并发症构成严重的身体伤害。” 应用特别法优先原则，在问题涉及打断几根肋骨并引起并发症的情况下，该程序基于两条规则中的第二条特别规则解决了相互冲突的论证。

虽然在这个简单的例子中应用构造规则方便地解决了规则冲突，但这种方法提出了下面讨论的一些问题。

## 5.6. 法律论证的计算模型是如何实践的？

尽管法律论证的计算模型有重要贡献，但人们可以合理地追问法律论证的计算模型是否、何时以及如何为法律实践做出实际贡献。

首先，上述法律论证的例子毕竟仍然是简单的例子。事实情况很简单，数量很少，而进行论证的法律渊源最多只涉及六个法律规则或案例。到目前为止所示的程序尚未应用于数百个案例，当然也不是文本形式的案例。所有法律渊源都是手动输入和表示的。

目前为止论证型式在法律上是可实现的，但它们的应用似乎有点特别（ad hoc）。例如，我们思考一下特别法优先原则。在上面的例子中，援用它来解决源于先例的两条规范之间的冲突是很方便的。然而，人们可以想象，法院在不同的案件中阐述了反对应用这一制定法原则或条约解释来解决两条规则之间的冲突的论证。对于构造规则的效用的信心可能因民法法系与普通法系而异。在 1949 年的一篇经典文章中，卡尔·卢埃林（Karl Llewellyn）指出，构造规则仅仅是提出权力。特别是，每一条规则都有一条“反规则”，导致法规的相反解释（Llewellyn，1949）。因此，特别法优先原则或许适用，但它的适用将受到没有提供适当型式的论证的约束。

其次，法律论证的计算模型通常没有被经验地评估。当然，评估论证的计算模型并不是一件简单的事情。然而，我们已经看到至少有两种方法来评估产生法律论证的程序。人们可以要求人类和程序产生关于相同事实情境的论证，并邀请人类专家在盲测中对其进行评分，正如布兰廷（Branting）对基于范例的解释的生成器所做的那样（见第 3.3.3 节）。评估论证模型的另一种方法是评估它与其他方法相比预测案例结果的好坏程度。例如，通过比较基于案例的法律论证的案例论证系统模型的结果预测和其他模型（例如第四章所述的基于问题的预测模型）的结果预测，案例论证系统模型预测案例结果的好坏程度可以被评估。这样的新法律论证的计算模型评估——即基于价值的论证预测模型——将在下文论述。

第三，虽然大多数证明标准都有熟悉的法律名称，但法律论证的计算模型对它们的操作似乎并不与这些标准的法律版本密切相关。如下所述，诸如“证据优势”之类的法律证明标准是指难以用计算机建模的概念。

### 5.6.1. 法律论证的计算模型中证明标准的作用

证明标准是法律论证的一个常见方面。例如，刑事定罪的证明标准“超出合理怀疑”要求证明“如此令人信服，以至于理性人会毫无疑问地采取行动；这个证明让你坚信……他无罪［没有］真正的可能性。”（Weiss，2003）

如上所述，证明标准在论证的计算模型中也起着重要作用。“一项陈述的可接受性取决于它的证明标准。”陈述的证明标准是否满足取决于赞成和反对陈述的论证是否可辩护。一个论证是否可辩护取决于其前提是否成立。其前提是否成立取决于前提的陈述是否可接受等（Gordon 等，2007，p.884）。

卡涅阿德斯实施了表 5.2 中所示的许多证明标准（Gordon 和 Walton，2006）。如上所述，其中一些证明标准符合熟悉的法律标准。

对法律和卡涅阿德斯证明标准的描述的比较表明开发计算实施的困难，这些计算实施至少与一些法律标准密切对应。超出合理怀疑要求证据“如此令人信服，以至于理性人会毫不犹豫地采取行动；让［某人］坚定地相信证据。”

① 作为一种法律标准，“微弱证据”是陈旧的。实际上，不仅仅需要“微弱证据”。例如，行政法中的“实质证据”检验要求“合理的头脑可能接受的相关证据足以支持结论”（Feller, 2015）。

### 5.6.2. 将概率推理整合到法律论证的计算模型

对法律论证的计算模型的最终批评可能是，论证模型倾向于将事实、法律和基本价值的问题混杂在一起，这些问题在程序上是在不同层级的法院或法院诉讼的不同阶段决定的。例如，参见图 5.9 中扬诉希钦斯案的基于价值的论证框架中的事实和基于价值的论证的混合。法律论证的计算模型也倾向于过度简化法律实践的现实。获得关于事实断言的关键问题的准确答案并非易事。评估证人的可信度是人类陪审团或法官的工作。了解在任何给定语境下要问哪些关键问题是负责预先通知的法律顾问的工作。这可能超出了任何法律论证的计算模型的能力。

然而，这种批评可能会错过法律论证的计算模型。这些模型及其论证型式和预先存储的通用关键问题最好视为帮助律师建模的工具，根据关于证人可信度或与其他证词的一致性的各种假设对可能发生的事情进行建模。

因此，法律论证的计算模型可被视为规划法律论证的工具。诉讼律师可以使用该工具来探索论证的可能结果。诉讼律师可以添加她/他可以预见的所有事实、法律、规范和程序论证，观察模型预测的结果，并测试预测对输入论证和假设的各种变化的敏感性。至少，这将是法律论证建模者的目标：创建一个实用的论证规划工具。

在假定诉讼的不确实性的情况下，如果诉讼律师可以输入他们对特定论证成功可能性的最佳评估，这个目标可能更为可行。在大多数实际情况中，法律论证中的命题是不确实的。例如，关于一个事实是否真实，或者更确切地说，它是否会被证据接受并被一个事实的信徒所记入，这是不确实的。法院会接受律师关于适用哪种法律规则、如何解释法律规则的含义以及如何将其应用于案件事实的建议吗？这同样存在不确实性。

在规划一个法律论证时，将有关这些不确实性的推理整合到计算论证模型中会很有用。另一方面，概率应该进入证明标准。如表 5.2 中间栏所示，证据的证明标准的优劣用概率表述：有争议事实的存在更可能。正如阿特金森和本奇 – 卡彭（2007）所描述的那样：

> 在 [ 抽象的论证框架中 ] ……，在信息不完整的情况下，我们可能 [ 缺乏 ] 关于某个事实是否成立的知识。我们……需要……提供超出合理怀疑和微弱证据之间的中间标准。如果信息可用，处理此问题的一种方法是将论证与概率相关联。

然后可以根据各自的成功概率来比较相互竞争的论证：

> 当我们必须做出选择时……我们可以计算 [ 一个选项 ] 成为正确选择的概率。基于每个论证的概率的这种方法肯定能够满足“概率平衡”的概念……但是，我们不相信这些信息是可以正常获得的。（Atkinson 和 Bench-Capon，2007）

将概率整合到法律论证的计算模型中至少会引发两个问题：

一个问题是如何最好地组织整合。鉴于事实上的不确实性，它们在论证中的状态最好用其他状态的概率来表达。如果论证形式确定然后可以计算推断的非事实断言的状态的概率，但仍然根据论证形式传播论证，那可能是有效的整合。因此可以扩展论证的定性模型，以支持用于推理不确实性的定量方法。

贝叶斯网络（Bayesian networks，简称为 BNs）是用于推理不确实性的一种定量方法。它们通常用于建模一组随机变量之间的条件依赖关系。例如，在给定某些观察到的事实或症状的情况下，可以计算诸如疾病的推断条件的概率。如第 7.5.3 节所述，贝叶斯网络降低了计算复杂度并与机器学习方法很好地整合在一起。格拉布梅尔等人（2010）提出了一种将卡涅阿德斯论证图换算成贝叶斯网络的系统方法，他也调查了这种整合的其他方法。

第二个问题是“概率将来自何处？”诉讼律师对与他们论证的各种要素相关的不确定性有直觉。这些直觉包括：获得真实事实的可能性，相信给定的事实推断，或将特定价值分配给拟议判决结果。他们可以估计这些不确定性，并将它们作为权重分配给论证图中表示的事实断言和论证。灵敏度测试的可能性在某种程度上改善了通过直觉设置权重的主观性，使用户能够评估假设权重的变化如何影响预测和论证。

另一个概率来源可能来自语料库和数据库中的外部数据。在第四章中，我们看到了从概括案件、法院、法官及其背景和司法趋势信息的特征中得出的概率（见图4.3）。下面，我们将看到从先前判决对相互冲突的价值的解决方案中得出的概率 [虽然在一组更大的案例中以更加情境敏感的方式执行，而不是在第3.5.1节中提到的基于本奇－卡彭和萨托尔（2003）的方法]。

然而，这两种使用外部数据为法律论证的计算模型提供概率的方法是否可以直接从法律文本中得出这些概率，这是一个独立的问题。卡茨等人关于最高法院预测的著作（2014）中的方法可能不能直接与语料库或数据库中的案例文本一起工作。这取决于司法态度或趋势等特征的工程；这些可能无法从案例文本中自动提取。

在这方面，下个介绍的两种法律论证计算模型可能会更好。接下来讨论的基于价值判断的论证预测模型 [ 如本奇－卡彭和萨托尔（2003）的方法] 依赖于手动分配的法律因素。模拟证据法律论证的缺省逻辑框架（在5.8节中定义）依赖于手工分配的证据因素等。人们可以使用第二和第三部分中解释的文本解析技术从案例文本中自动提取这两种因素，并协助预测结果。
