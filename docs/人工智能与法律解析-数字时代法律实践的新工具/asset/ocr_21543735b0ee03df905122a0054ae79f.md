# 7.4. 法律信息检索系统如何工作？

法律信息检索系统接受用户的查询，从索引数据库中检索文档，测量文档对查询的回应，对其进行排序，并输出有序的结果列表供用户阅读。

用户可以输入用句子、关键词、案例名称或引用表达的自然语言查询，并指定所需术语的存在或位置。

给定一个查询，信息检索程序：

+   1. 剥去禁用词，诸如“the”，“a”和“and”之类的常用词，词干，如“ing”或“es”之类的结尾。
+   2. 识别单词旁边的其他剩余功能，例如对制定法的引用，宪法条款或先前案例，重要短语和特殊索引概念。
+   3. 计算每个剩下的单词或其他要素在文本中出现的次数。
+   4. 使用反向索引从数据库中检索候选文档，即，所有那些索引为包含查询中任何特征的文本。（Turtle，1995，p.18）

数据库包含处理方式与查询方式大致相同的文档，数据库很可能使用倒排索引实现（见 Büttcher 等，2010，p.33）。索引列出了存储在数据库中的任何文本中出现的某些特征。对于每个特征，倒排索引记录它出现的所有文档，它在每个文档中的位置，以及它在文档和文本语料库中出现的次数（Büttcher 等，2010，p.48；Turtle，1995，p.18）。由于不断添加新文档，必须采用各种索引维护策略（见 Büttcher 等，2010，第 7 章），但这里不讨论这些问题。

信息检索系统输出根据其与查询的相关性排序的案例列表。信息检索系统采用了各种技术和措施来评估与查询的相关性，包括：布尔，向量空间和概率模型（见第 7.5 节）。所有这些都利用包含在倒排索引中的频率信息。
