# 例如， AGP 从第一个事件开始：

7 月 1 日，买方向卖方发送了以下电报： “有客户需要盐，并要立即装车。你愿意以每英担 2.40 美元的价格提供货车吗？” 卖方当天收到了电报。

这些事件不是以英文文本输入，而是用基于逻辑的表示语言输入的。AGP 无法读取文本，因此人必须用逻辑陈述人工表示该信息（即，在第 2.3 节中定义的谓词逻辑）。例如，一些陈述的摘录是：

```
（发送发送 1）（代理发送 1 买方）（ben 发送 1 卖方）（obj 发送 1 电报 1）？
（电报 1）（句子 S13）（文本 S13： “你能以每英担 2.40 美元的价格提供货车吗？” ）
（道具内容 S13 Prop13）（文字力量 S13 Q13）（是非问题 Q13）
（有效力 S13 R13）（要求 R13）。
Gardner, 1987, pp.89,105,111.
```

在上面的陈述中，Send1 是买方作为代理、卖方作为受益人发送的实例。Telegram1 是作为发送对象的电报的实例。S13 是一个句子，其文本被引用，其命题内容在 Prop13（在别处定义）中表示，其作为言语行为的文字力量是提出问题但也有效地提出了一个请求（Gardner, 1987, pp.89,105,111）。

在步骤（3）中，测试事件是否满足弧线，程序收集与弧线相关的规则。与事件一样，所有合同规则都被人工转换为逻辑语言。例如， 21 从（0）到（1）与弧线相连的规则则定义了“要约”——《合同法重述》第二版第 24 节（上文已介绍）——这条规则包括规则前件和（斜体）谓词，如下所示：

+   1. 某些代理人，即潜在的要约人，有一些关于交换的象征性内容的表现形式。
+   2. 交易条款具有合理的确定性。
