接标签匹配，一个程序使用带标签的链接继续进行，但这项任务在计算上仍然很复杂。

布兰廷设计了 A * 最佳优先搜索算法的变体，该算法追求以高度选择性和有效的方式匹配案例解释的结构：候选映射仅在它们导致最佳匹配的情况下进行。

A * 搜索算法使用两个参数：f (n) 估计从当前节点 N 到达目标的成本，g (n) 表示从初始状态到达当前节点 N 的实际成本。在操作上，f (N ) 是对 N 中映射的最佳完成中不匹配的标准事实的数量估计。g (N) 是根据映射目前为止为止节点 N 无法匹配的目标案例中的标准事实的比例来定义的。这些对结构映射最相似案例的目标的可用路径的成本估计引导了基于范例的解释生成器的最佳优先搜索算法。在搜索中到达某个节点 N 后，它估计了从初始节点到目标节点通过 N 的最便宜路径（Branting, 1991, p.817）。
