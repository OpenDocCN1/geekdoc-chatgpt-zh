决指定修辞角色，例如识别案件，确定案件事实，论证案件，报告案件历史，陈述论据，比例决定或最终决定（Saravanan 和 Ravindran，2010），或确定案件中的句子在描述可适用的法律或事实时的作用（Hachey 和 Grover，2006）。

当然，有时与主题相关和与论证相关的信息会重叠。在保罗·张等人看来（Zhang 等，2014），“法律问题”是从判例法数据库中挖掘出来的，每个法律问题都包含一个在论证中案例引用的法律命题或原则。如第 7.7 节所述，系统在案例文本中用机器学习和手动注解相结合的方式语义化地解了法律问题。结果产生了一个标准化法律问题的法律问题库和法律问题的案件讨论的链接（Zhang，2015）。

本章重点介绍使用机器学习、自然语言处理和提取规则从案例文本中提取不同类型的与论证相关信息的三个项目：

+   1. 莫查莱斯和莫恩斯（Mochales 和 Moens）的系统确定了在论证中起作用的句子，将其标记为前提或结论，并从案例文本中提取论证的结构（Moens 等，2007；Mochales 和 Moens，2011）。
+   2. SMILE 提取了实质性的法律因素，这种事实的定型模式加强或削弱了一方的法律主张（Ashley 和 Brüninghaus，2009）。
+   3. 卢依马系统提取与案件中引用的法律规则及其在应用于事实的与论证相关的信息（Grabmair 等，2015）。

第十一章和第十二章将讨论从法律案例中提取的这些信息如何改进概念法律信息检索，启用论证检索以及执行其他认知计算任务。
