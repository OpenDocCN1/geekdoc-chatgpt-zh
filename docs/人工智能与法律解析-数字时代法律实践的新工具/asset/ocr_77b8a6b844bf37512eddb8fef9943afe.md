图 6.3 上半部分的本体层说明了这个概念词汇表，包括供应商（Supplier）和消费者（Consumer）等术语，商业交易中的某些类型的代理。法律领域专家以自上而下的方式手动构建本体层面，并指定了它们之间的关系。例如，消费者和供应商都涉及并进行商业交易（Commercial-transaction）。商业交易有代理角色（Has Agent Role），即供应商和消费者，这两者都是法律角色的子类。其他关系包括有对象角色（Has Object Role）和有价值（Has Value）。

在销售合同和信用协议之类的整个消费交易范围内，商业交易、供应商和消费者之类的实体是如何被提及的？为了回答这个问题，研究者利用自然语言处理和机器学习技术，对不同语言的领域文档语料库进行了半自动、自下向上的术语提取。结果显示在图 6.3 的下半部分的词汇层中。
