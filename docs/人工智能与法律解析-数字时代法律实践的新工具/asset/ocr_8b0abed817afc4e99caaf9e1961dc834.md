# 第七章 使法律信息检索更智能

# 7.1. 导言

如果法律推理和论证的计算模型要对法律实践产生更大的影响，比如在认知计算模式下启用法律应用程序，那他们可能需要结合现有的商业和制度方法来实现全文法律信息检索和电子发现。虽然人工智能与法律的贡献可能很大，但这些技术最好应用于现有商业工具的边缘，这些工具用于语料库管理、索引和索引维护以及搜索的流程，它已经建立，且可靠和高效。因此，在预测法律应用程序和认知计算的“增值”之前，应很好地理解现有的法律信息检索技术。

本章解释了当前用于案例判决、制定法和其他文档的全文法律信息检索的技术。这些是目前法科学生和法律职业人士在构建法律论证和撰写摘要时所使用的法律研究工具。本章阐述了法律本体在通过查询扩展改进全文法律信息检索中的作用，并解释了一些人工智能与法律技术如何被用来帮助法律信息检索将语义信息考虑进来以评估相关性。
