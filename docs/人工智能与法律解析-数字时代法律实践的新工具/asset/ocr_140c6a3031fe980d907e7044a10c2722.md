# 2.5.1. 业务流程专家系统

公司有义务确保遵守复杂的法律要求和规章。现有业务流程始终存在违反法规要求的风险，或者存在建议的修改在某些时候会引入违规行为的风险。企业还需要一种记录遵守审计规定的能力（Scheer 等，2006，p.143）。这要求公司识别可适用的法律规则和规章，“定义这些法律为个别公司提出的要求”，识别受影响的特定业务流程以及“这些流程中由这些要求产生的具体风险”，定义最小化这些风险的措施和控制，并测试它们是否正在应用(Scheer 等，2006，p.146）。

实施降低法律风险措施和控制的一种方法是将法律要求和规章转化为业务规则 57 如果遵循这些规则，则可以在受影响业务流程中降低风险。“一般而言，业务规则是指导或引导企业行为的指导方针或业务实践”（Wagner and Klueckmann，2006，p.126）。一旦制定了业务规则，人事经理就可以通过公司的普通管理层级将其强制执行。

业务流程规则也可以在软件系统中实施，它帮助人事经理确保合规（见 Scheer 等，2006，p.v）。例如，专家系统可以警告管理者有必要使公司政策符合一般法规要求，或警告管理人员不合规行为的具体情况。这些规则可以像《英国国籍法》方法一样以逻辑形式表示，或者更可能像沃特曼的程序（见第 1.3.1 节）中的启发式规则，并且被整合到专家系统中，用于测试业务流程是否合规。

这种业务合规专家系统正在商业领域中应用。如今，律师事务所和公司可以用像尼奥塔逻辑（Neota Logic）这样的公司提供的技术轻松地创建自己的专家系统，以实现业务合规。例如，尼奥塔网站报道，福利与拉德纳（Foley & Lardner LLP）律师事务所以全球风险解决方案的名义撰写了许多基于网络的专家系统模块，以指导客户努力确保遵守“反海外腐败法”（Foreign Corrupt Practices
