类型系统的这一部分中的大部分都不具有跨法律领域的普遍适用性。另一方面，一些概念和关系——例如关于持续时间的推理——本质上是一般性的，无论它们是指产品开发节省的时间，疫苗接种与受伤发生之间的经过时间，还是渔夫关闭渔网所需的时间。研究应探索应用用最先进的时间注解器（如 SUTime 或 HeidelTime）来标记案例文本中的日期、时间和持续时间（见 Strötgen 和 Gertz， 2013 ）。然后， 事件演算可以用时间约束进行推理，例如，如图 11.5 中的查询 4h 所示，关于疫苗接种后伤害的发作时间（见 Zhou 和 Hripcsak， 2007； Thielscher， 2011 ）。

# 11.5.4. 注解扩大的法律类型的前景

假设已经扩展了类型系统以支持更广泛的论证模式、文档结构和特定权利请求类型的概念查询，开发法律论证检索 / 认知计算系统原型的第二个挑战波及根据这些新类型自动注解法律文档的前景。

扩展类型系统捕获了文本不同的与论证相关的方面。例如，图 11.8 说明了梅森案中商业秘密意见的摘录，该案的事实总结见图 3.2。根据四种不同类型用网络注解法（WebAnno）手动注解句子（ Yimam 等， 2013 ）：

+   - 一各种商业秘密盗用法律因素。
+   - 一各种核心卢依马句子类型。
+   - 一如莫查莱斯莫恩斯（2011）中的命题 / 前提或结论。
+   - 一冯和赫斯特（2011）中的各种论证型式。

虽然人类和计算机如何可靠地成功地在法律案例中标记这些类型仍然是一个经验问题，但是注解技术已经被开发出来了，并用来评价它们。如 F6 安全措施， F15 独特产品和 F16 信息反向可操作性等商业秘密因素已自动标记（见第 10.4 节），并且计算机环境支持手动注解这些因素（见第 10.4.3 节和图 10.5）。技术被用来评估三个核心卢依马句子类型的注解，包括法律规则和基于证据发现（见第 10.5.3 节）的句子类型。前提、结论和包含示例论证的论证型式（见第 10.3.5 节）已基于手工注解自动识别（见第 10.3 节）。
