概念，这个概念是在借用的概念帧中定义的，它指的是一种行为，在行为帧中描述为“按期还书”。在基于帧的本体中，这些相互关系是隐式概念链接，它们由可用于填充插槽的概念类型的本体约束强制执行。

鉴于法律本体在以计算机程序能够应用的方式表示知识方面的功能，如这些示例所示，人们可以理解法律本体在构建法律应用程序中的用处。本本定义对象类，指定其可能的特征和属性，强制对特征值的约束，并指定对象之间的关系。人们可以用框架和插槽创建类的实例并填充知识库。这不仅可以支持电子法院本体中的概念信息检索，还可以支持一些推理，如范·克拉林根基于框架的本体的图书馆规章实例所示。为了实现其他推理，人们可以将“生产规则应用于知识库的要素以支持推理”（Wyner, 2008, p.363）或第一部分中讨论的基于案例的论证方法。

# 6.4. 建构法律本体

法律本体传统上是手工建构的，但自然语言处理和机器学习越来越多地提供自动化帮助。

本体需要反映人类专家知识，这些专家知识关注哪些概念和关系应该包括进来以使系统能够执行其最终任务。然而，自动化方法可以基于统计分析识别语料库中显示重要的概念和关系。然后，自动化可以标记候选概念和关系，供人类专家考虑。人类专家能够决定是否包括候选者，并且能够重新标记节点和弧线以包含在本体中。

用本体基础支持立法起草（The Drafting Legislation with Ontology base Support，简称为 Dalos）的本体（图 6.3）就是这种方法的一个例子（Francesconi 等，2010）。该本体旨在支持欧盟成员国的立法起草和侧重于消费者保护领域的语言。目标是提供关于消费者保护的规范性条款的类型分类，也提供了一个概念词汇表，用于描述涉及两种语言（英语和意大利语）的消费者保护的一般情况。
