案件管理者识别作为编码类别实例的文档(例如,相关的,回应的,特权的,与问题相关的)。对于每个类别, 这些手动选择文档成为种子集, 机器学习程序基于正(或负)实例共享的特征学习该类别的概率预测模型。通过学习模型, 程序可以向以前看不见的文档分配适当的类别。

一旦类别的种子集包含足够的文档, 反复的“训练”过程就开始了:

+   1. 机器学习系统从种子实例中抽象出一个预测模型, 一类使用统计分析的简介 (见 Sebastiani, 2002; Privault 等, 2010), 可能应用的浅层解析, 概念和关系的检测, 基于本体的扩展, 或潜在语义特征的识别。
+   2. 系统将预测模型应用于语料库以识别其他文档, 并将其中一些文档提交给案件管理者的人类审阅团队进行确认。建议的文档可能来自随机抽样或包含在一个称为主动学习的过程中“分类器最不确定的例子” (Oard 和 Webber, 2013), 或者它们可能是“弄错的文档或非典型异常值.” (Privault 等, 2010)
+   3. 案件管理者的团队对程序建议的文档进行检查和分类以确保正确性。
+   4. 机器学习系统根据人类评论者的相关性反馈更新其类别模型。
+   5. 重复先前的迭代步骤, 直到语料库的未检查部分不包含更多类似的文档 (Sklar, 2011)。
+   6. 统计抽样用于估计已达到的准确性和完整性水平。

在可用于生成类别的模型或概况的机器学习算法中, “(监督的)概率潜在语义分析 [可用于推断]来自主题类的单词和文档的生成模型” (Oard 和 Webber, 2013, p.138)。例如, 在施乐 (Xerox) 的类别 (Categorix) 系统中 (Privault 等, 2010), 预测模型基于概率潜在语义分析 (probabilistic latent semantic analysis, 简称为 PLSA)。“概率潜在语义分析的基本假设是存在一组隐藏的(“潜在的”或“未观察的”)因素, 这些因素可以成为一组观察到的单词和文档
