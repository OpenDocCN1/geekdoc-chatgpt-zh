在表 6.5 中的两组测试中的每一个测试都根据一般性变化。占有 -1 测试更广泛，也就是说，相比占有测试其范围更广，因为在占有 -1 测试中“有价值的东西”取代了“棒球”。同样，明显的意图测试比明显的意图 -1 或 -2 测试更为通用，因为它处理的是“有价值的东西”而不是“棒球”。

修改测试的一般性是一种回应教师挑战的方法。在表 6.2 的对话中，学生 -A 通过用更严格的明显意图 -1 测试代替明显意图来修改他提出的测试。在依赖更严格的测试时，学生 -A 避免了教师假设的主旨。

人们可以想象其他合理的方法来修改建议的测试，以使它们或多或少地受到限制。三个中级法律概念设定了一系列似乎合理的限制性标准或程度（> 意味着更严格）：

+   一占有程度：捕获或致命伤害 > 短暂地捕获或让猎物受伤受伤 > 寻求
+   一表示意图的表示程度：明确表示的意图 > 模棱两可的意图 > 隐藏的意图
+   一干涉意图的程度：故意 > 疏忽 > 无意

这些中的每一个都对应于案例框架的比较特征（图 6.5），分别是占有的狩猎 / 捕捉步骤，原告寻找猎物的客观表示，以及被告干涉的意图。
