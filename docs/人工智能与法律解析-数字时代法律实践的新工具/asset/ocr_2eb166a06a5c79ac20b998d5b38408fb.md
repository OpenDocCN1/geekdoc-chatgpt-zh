# 9.6. 符合产品设计的提取要求

第 2.5.1 节中讨论的合规性是涉及产品、系统或其他人工制品设计的许多行业中的重要实际问题。例如，建筑规范明确规定了对建筑设计的约束，例如“天井［在建筑物墙壁周围的开放区域意义上］宽度不应小于 3 英尺”的规则。

法律规章规制对大多数工程领域（如民事、电气和环境）的产品设计。不同地区、社区和政府层面的规章差异很大。尽管规章可能会限制产品或系统设计，但产品工程师和系统设计人员可能不知道适用哪些规章。相反，法律人员可能不了解拟议设计的技术方面，因此未能预见到规章可能引发的后果。

这些考虑因素促使研究人员尝试从制定法文本中自动提取规则，以便可以或多或少地自动应用这些规则来测试拟议设计是否满足相关的法律约束。例如，一种方法自动从建筑法规的语料库中提取信息，并将其转换为可以直接用于自动化合规性检查的逻辑条款（Zhang 和 El-Gohary，2015）。
