系统可以将图 11.9 中表示的查询转换为“在奥尔恩案因果关系事实规则对医学理论因果关系的要求的语境中，检索所有包含事实发现和证据的句子，证据是指麻腮风疫苗接种可导致顽固性癫痫发作和死亡。”然后，它会要求用户确认这个转换或修改查询。

# 11.6. 来自制定法的概念信息检索

到目前为止，讨论主要集中在从法律案件语料库中检索与论证相关的概念法律信息。概念法律信息检索在多大程度上可以应用于制定法和规章？与论证检索一样，答案取决于开发一种类型系统来捕获以下概念：（1）对用户的查询很重要的概念，以及他们试图解决的问题；（2）在制定法和规章文本及其他引用它们的文档中能够自动注解。

例如，第二章介绍的公共卫生应急领域的医务人员可能面临接触患有罕见但具有传染性疾病患者的处境。理想情况下，概念上的法律信息检索系统可以帮助他们轻松找到如下问题的答案：“哪些规章建立政府公共卫生机构与传染病医院之间的报告关系？”

商业法律信息检索程序很可能会误解提交为文本的查询，因为它无法理解它所引用的概念或规章所建立的概念实例之间的关系网络。

本节首先处理表示规章概念的类型系统方法，描述用基于网络的技术表示概念实例之间的法律规定关系，然后说明网络如何用于概念法律信息检索。

# 11.6.1. 用于制定法的类型系统

尽管已经研发出了用于制定法领域的法律本体（第 6.5 节），但就目前所知，为了实现概念信息检索的目标，应用类型系统和管道方法表示规章文本语义的努力开始了 [ 见，例如，怀纳和戈韦尔纳托里（Wyner 和 Governatori，2013），在第 9.5 节中讨论过 ] 。

一般性制定法类型的适当系统将包括制定法的结构要素、法律规则陈述的类型、法律规则的要素以及更具体的规章领域的概念和关系。
