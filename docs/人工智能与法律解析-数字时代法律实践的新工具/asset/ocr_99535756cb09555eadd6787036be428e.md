比较，并检索所有句子回应查询约束。如图 11.2 所示，卢依马搜索查询将所有指定条件视为由逻辑析取项连接。理想情况下，在给定查询的预期含义的情况下，连接器应为“和”（ANDs），以便识别满足用户所需规范的文档。然而，鉴于语料库中的数据有限，便利是必要的。卢苦恩通过使用析取来放松约束，它可以检索仅仅部分匹配的句子。

卢依马搜索检索完句子后根据查询条件的数量对它们进行排名，查询条件满足用于每个句子的卢苦恩得分，它们的得分是由阿帕奇卢苦恩的内置评分系统给出的。该分数使用术语频率向量测量检索的句子相对于查询的匹配程度以评估相似性（Bialecki 等人，2012）。卢依马搜索根据从每个文档中检索到的响应句子的数量对文档进行排名。

# 11.3.2. 用卢依马重排对文档重新排列

如卢依马管道图（图 11.1）所示，卢依马搜索将其检索的文档传递给第三个模块卢依马重排，该模块学习如何重新排列文档以最大化其对用户查询的响应能力（Grabmair 等，2015）。

在第 7.7 节中，我们遇到了像“万律陈述”这样的最先进的法律信息检索系统的重新排名。商业法律信息检索系统的检索模块单独可能无法产生最佳排名。重新排名采用的证据来自文档文本中的频率信息、专家生成的注解、引用网络和在先前查询中流行的文档。使用机器学习优化排名函数以确定归因于不同的特征的权重。

在这里，重新排名的目标也是学习用于重新排列卢依马搜索结果的特征权重，以将相关结果带到顶部。卢依马重排采用捕获与论证相关信息的特征。它学习以下文档特征的权重：

+   - 一句子数：给定文档中有响应的句子数量（与卢依马搜索用于计算初始排名的数量相同）。
+   - 一最大化卢苦恩得分：给定文档中所有句子的最高卢苦恩得分。
+   - 一向量空间相似性：给定文档和查询中所有句子的“关于”字段的最大余弦向量空间相似性值（见第 7.5.2 节）。
