
于生成论证和预测的模型，该模型考虑了潜在于法律规则背后的价值。他在一个计算机程序中实现了论证型式，该程序基于产生的论证预测案件结果，并在商业秘密法领域测试该程序，与海波系统、案例论证系统和基于问题的预测程序相同的应用领域（见 Grabmair 和 Ashley，2010,2011；Grabmair，2016）。

他的方法基于对法律推理的直观合理假设：在做出法律判决时，法官会考虑判决对适用价值的影响，并评估它们是否比其他判决的效果更可取。法官必须做出价值判断，即确定在特定事实情况下判决的积极效果大于负面效果。

这种价值判断被认为是高度依赖语境的，没有抽象的价值层级决定了特定案件中的价值判断。相反，法律推理涉及映射和使用价值判断从一个事实背景到另一个事实背景。这是通过一个论证来实现的，即目标案例的事实集和来源案例的原始事实背景都是法律规则中抽象概念的实例，在给定对可适用价值影响的情况下，抽象概念证成它们都应该具有一个特定的结果。

为了支持这些论证，格拉布梅尔准备了抽象概念的领域模型，即用于决定诉讼请求的规则中使用的中级法律概念，用于商业秘密规制的一组价值和价值效应，以及用于商业秘密盗用诉讼请求的支持者及其对手的相互竞争的论证型式。

中级法律概念是具有开放结构的法律术语，它的含义通常是含混的或模糊的（见第 2.2.1 节），因而制约了论证。诸如“所有权、公民身份、监护权、受托人职位、占有权等”之类的中级法律概念“作为要求与后果之间的中介联系。”在链条开端的某些规则规定了适用前述法律术语的事实要求，反过来，那些法律术语又是最终暗含着法律或规范性后果的其他规则的要求，在这个意义上法律概念是“中间的”（Lindahl, 2004; Wyner, 2008）。

### 5.7.3. 基于价值判断的论证预测论证型式

基于价值判断的论证预测建模论证，即一条法律规则应该适用于当前案件，或者不是基于类比适用先前案例。法律规则由中级法律概念组成。这些中级法律概念是商业秘密法领域模型的问题（图 5.10）。类比断言，当前案件和先前案例在价值效应方面存在相同的局部或交叉问题权衡。

这个程序采用基于共享价值效应权衡的类比构建论证的型式，可以检索与当前案件共享相同的局部或问题间权衡的案例，并在恰当的论证中使用它们。

例如，“来自先例的问题间权衡”的论证型式是一条规则，正式指定代表一方援用论证的前提条件。基本上，必须为该方决定一个先例，其在价值影响方面与当前案例具有相同的问题间权衡。

图 5.13 显示了程序对使用此论证型式构造的动力研究公司案的分析摘录。文中带下划线的短语说明，在此处论证型式引出了对商业秘密法保护的价值所产生影响的权衡。即使基于价值判断的论证预测程序输出可能冗长且重复的文本，这是未来工作的问题，但它的论证可以与伯尔曼和哈夫纳所支持的目的论证（如图 5.12 的论证 II 所例证）相媲美。

基于价值判断的论证预测论证型式还支持用先例做出相似的论证，这些先例与当前案件在价值效应方面共享局部权衡，即权衡涉及相同的问题。

图 5.13 中动力研究公司案（Dynamics）和美国分拒公司（National Rejectors）公司案的比较说明，如果案件确实满足或确实不满足比如信息有价值这样的法律规则要求，基于价值判断的论证预测程序可以在价值效应方面对案例进行抽象类比权衡。

值得注意的是，在基于价值判断的论证预测模型中，先例与当前案件共享相同的价值效应权衡这一事实并不一定意味着他们共享同一组因素。如图 5.11 和 5.12 所示，给定的价值效应可能由多种因素引起。

结果，基于价值判断的论证预测比以前的案例法律推理模型在更抽象的层面进行类比。

> > 动力研究公司案中的陈述示例，被告论信息有价值：
> > 原告的产品信息不够有价值，因为原告为维护信息的保密性做了很少的努力，尽管被告缺乏有力的证据，但必须假定原告的产品信息不够有价值，因为否则将与商业秘密法的目的不一致。
> > 具体而言，就原告维护保密性来说，公开披露相当于明显放弃财产利益，这种情况下公共信息的可用性至关重要，并且明确放弃对原告维护保密性不足的保密利益。尽管被告缺乏有力的证据以及产品信息是独一无二的，但必须认为信息缺乏价值已得到充分确认。
> > 在国家分拒公司案中做出了类似的问题权衡，这个案件判决被告胜诉。
> > 在那里，就原告维护保密性而言，向外界披露相当于明显放弃财产权益和明确放弃商业秘密利益，公开披露相当于明显放弃财产利益，这种公共信息可用性的情况是至关重要的，如此明确放弃保密利益和缺乏安全措施就等于对财产利益的这种明确放弃以及对保密利益的明显放弃，逆向可操作性被认为是信息缺乏价值，尽管产品信息是独一无二的。

基于价值判断的论证预测通过分享在审案件权衡来检索潜在的先例。这涉及两组价值效应……，不论哪些因素构成这些影响。这与海波系统、案例论证系统和基于问题的预测中使用的因素水平上的先例候选检索明显不同（并且可以说是“更深”）。换句话说，基于价值判断的论证预测检索的先例可能在它们共享的因素方面表面上有所不同，但根据共享的价值效应它们在更深层次上是相似的。（Grabmair，2016，p.60）

其他基于价值判断的论证预测模式使支持或攻击一个类比的论证成为可能。“一方或许指出在当前案件而不是先例中存在有利因素，但仍然是类比中所论证的［问题间］权衡的一部分。由此产生的论证是一个更有道理的（fortiori）论证，即在当前案例中这种有利的附加因素使得论证更加强大”（Grabmair，2016，p.61）。对手可能以一种互补的方式挑战这种类比，对手“指出当前案件中存在一个不利于该方的因素，他们认为类比而不是先例的一部分，但仍然应是权衡的一部分，从而削弱了类比。”（Grabmair, 2016, p.62）

### 5.7.4. VJAP® 的基于论证的预测

基于价值判断的论证预测程序使用一组论证型式为每个案例构建一个论证图（Grabmair, 2016, p.iv）。鉴于案件 c 输入一系列所有可适用的因素。原告在 c 案中的商业秘密盗用诉讼请求将成功，基于价值判断的论证预测构建了一个支持这个命题的论证。

基于价值判断的论证预测根据论证图表预测案件的结果。“它使用从论证图计算的置信度度量来预测案件结果，并生成证成其预测的文本法律论证。置信水平扩展使用定量权衡，权衡事实对价值的影响。基于价值判断的论证预测使用迭代优化方法自动从过去的案例中学习这些权重。”（Grabmair，2016，p.iv）

换句话说，在给定以前案件和语境的价值权衡的情况下，论证图用作定量图形模型，用于预测案例的结果。“置信水平的价值……表示可以通过论证建立陈述的程度，从而为系统提供一种‘定量置信语义’”（Grabmair，2016，p.17）。这些值的计算基于：

- 1. 与每个因素对有利于原告或被告的每个价值的影响相关的权重。
- 2. 可以用置信水平建立论证的前提，而置信程度又取决于支持和反对这些前提的论证的强度。

正如每个论证型式的触发，论证型式扩展了参数图，它还输出一个置信函数，用于计算论证的相对影响，这个论证仅仅对整个论证的置信水平做出贡献。每个论证型式都有一个相关的函数，用于计算它构造的那种论证的相对说服力的度量。对于来自先例的问题间或局部问题的论证，相比先例 p 和 c 之间的类比，置信度量增加了，并且在可以区分它们的程度上降低了。

基于价值判断的论证预测程序“通过扩展论证图中的置信值来预测一个案件的结果，置信值来自学习的权重参数，这些参数表示某个事实对适用值的影响的说服力。”（Grabmair，2016，pp.25-26）

构建图形后，系统通过使用因素影响权重图参数计算论证图的叶节点的置信水平来计算「原告胜诉陈述」主张的置信水平（见图 5.14 的底下一行）。然后使用论证型式的置信度函数……比例置信以及陈述的置信度函数将这些初始置信水平值自下而上传播（或神经网络术语称为“前馈”）。(Grabmair, 2016, pp.70–71)

结果值表示程序对结果预测的置信程度。如果超过 50% 的阈值，则预测原告获胜，否则预测被告获胜。

### 5.7.5. 基于价值判断的论证预测程序评价

为了评估基于价值判断的论证预测程序，格拉布梅尔使用了 121 个商业秘密案件的数据库（原告胜诉的 74 个，被告胜诉的 47 个）。这是 IBP 数据集的一个子集，包含至少有一个因素支持原告和被告的案例。因此，这些案例支持平衡权衡取舍的论证。

数据库分为训练集和测试集。对于训练集，一个论证图被构建起来，并且一个胜诉者预测训练集中的每个案件。从而确定了总体预测准确率。(Grabmair, 2016, p.71)

在训练步骤中，系统尝试学习最佳事实效果权重参数以最大化预测准确性。为了实现这一点，构造扩展预测模式发生在循环中，在该循环期间，系统使用称为模拟退火的技术迭代地搜索最佳权重图。(Grabmair, 2016, p.71)
