提取规则的努力的结果远远还没有达到用这些方式自动推理的理想。

260 然而，即使没有使用提取的制定法规则自动推理，从制定法文本中自动提取信息的技术也可以通过各种其他方式支持认知计算。自动提取有助于从制定法文本的语料库中检索概念信息。根据来自法律本体（如第 6.3.1 节介绍的电子法院和第 6.4 节介绍用本体基础支持立法起草本体）的语义概念自动注解的条款使用户能够基于其概念内容检索文档。程序还可以根据相关概念自动生成制定法条款的摘要或概要。

如第 2.6 节所述，程序甚至可以生成法规系统的网络分析。制定法网络可以直观地表示提取的信息，某些条款指示某些代理人采取针对其他代理人的行动。其中一个这样的项目将机器学习应用于多个州的制定法文本，从而能够构建制定法网络，人类分析师可以通过这些网络在视觉上或数量上比较不同州的类似目的的规章体系的各个方面。这些网络还提供了一个用于从制定法数据库中检索相关条款的图形用户界面。应用户依马类型系统和文本注解管道来处理文本可以改善它们的表示，以便更有效地使用机器学习。

# 9.2. 从制定法文本中提取信息的研究综述

从制定法条款中提取信息的研究专注于根据以下类型的信息提取或划分条款：

+   一制定法条款或规范的功能类型，如定义、禁止、义务和许可。

+   一与功能相关的特征，包括功能类型的元素或论证，例如义务持有人或临时代理人，行为和接收代理。

+   一法律领域或法律主题，如行政法、私法、环境法或刑法。
