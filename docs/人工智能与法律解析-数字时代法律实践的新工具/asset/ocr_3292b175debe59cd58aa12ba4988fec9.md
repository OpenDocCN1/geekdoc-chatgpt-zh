+   2. “苏格拉底是和苏格拉底不是暗示苏格拉底是。”

+   3. “苏格拉底是暗示苏格拉底是或人是马。”

+   4. “（苏格拉底是或人是马）并且苏格拉底不是暗示人是马。”

因此

+   5. “苏格拉底是和苏格拉底不是暗示人是马。”

如果一个人希望计算机像法院一样——思考正方论证和反方论证并选择更强的论证——解释制定法，普通的经典逻辑演绎是有问题的。一个人需要使用别的东西。逻辑学家已经开发了一些替代逻辑，可以处理不同的约束条件下的不一致性。然而，在人工智能与法律领域，目前对“还有什么？”的答案是一个具有适当论证型式的论证计算模型（如第五章所述）。

# 2.5. 业务规则和流程的管理系统

并非所有与法律问题的解决都涉及确定是否违反法律的诉讼。并非所有法律推理都涉及复杂的解释和正反方论证问题。在许多情况下，企业和机构只是想设计自己的业务流程并以避免违法的方式进行日常运营。当然，人们可以通过计算机模拟法律规则来解决实际问题，这种方式不需要建构全面的制定法解释模型。

实际上，大多数建立法规模型的程序可能被设计出来协助管理机构合规以避免诉讼。例如，《英国国籍法》程序可能不是为了处理当事人之间的诉讼而设计的，这些当事人试图说服法官判断有争议的术语的含义。相反，它更有可能被用作行政援助，以解决涉及公民身份问题的一般情景。负责管理复杂《英国国籍法》的机构可以使用该工具处理大部分案件，这些案件足够复杂，以至于困扰公务员，但通常不会引起有关法规或规章含义的诉讼纠纷。

制定法的逻辑模型（比如《英国国籍法》程序）和法律专家系统（如第 1.3.1 中的沃特曼系统）的后代仍然在帮助机构遵守相关法规方面发挥作用。
