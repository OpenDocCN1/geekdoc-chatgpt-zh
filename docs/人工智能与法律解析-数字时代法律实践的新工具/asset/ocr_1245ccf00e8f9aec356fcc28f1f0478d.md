悉了这些权重，它再预测未知的段落是否包含事实，讨论，或什么都不包含，或包含两者。该专利涉及应用两个机器学习算法——第 10.3.3 节中讨论的朴素贝叶斯（naïve Bayes）或逻辑回归（logistical regression）——来学习特征权重。

# 8.7. 将机器学习应用于制定法文本

机器学习也可以适用于制定法文本。最近的一个项目基于制定法分析的目的将预测编码的交互式工具应用于寻找相关条款的任务。

# 8.7.1. 制定法分析

制定法分析（Statutory analysis）是确定一条法规是否适用，如何适用，以及其适用效果的过程（Putman, 2008, p.61）。

在进行制定法分析之前，必须找到候选的相关条款进行解析。目前的法律信息检索系统很好地支持了这一步骤。给定一个法律问题，律师假设某些类型的法规（或特定条款）与该问题在法律上相关，并为法律信息检索系统创建搜索查询。例如，如果法律问题是“宾夕法尼亚州（PA）法规要求公共卫生系统机构如何准备和应对突发公共卫生事件？”律师可能会假设：

相关的法规条款将指导一些感兴趣的机构，如消防部门、医院或卫生部门等，以准备或应对某些紧急情况、灾难或危险。

然后，用户可以表述如下的查询：

+   - （紧急或灾害或危险）和
+   - （应对或准备）和
+   - （或消防或医院或医疗或“应急管理机构”或“社区健康”或“卫生部门”或“环境保护”或……对于每种类型感兴趣的机构）

从信息检索系统的结果看，律师可以选择最有希望的候选条款。
