中的查询。然后根据卢依马搜索的排名方法，将与每个查询相关联的30 个案例——如卢茜恩数据库表示的那样——按照响应卢依马查询的句子数进行排名（见第 11.3.1 节）。

卢依马重排在 11 次运行的留一法交叉验证中生成了其重新排序的排名，每次查询生成一个（有关交叉验证的说明，请见第 4.4.3 节）。每个查询都有以卢茜恩数据库格式表示的相关联的 30 个文档，也有文档的真实排名。每个文档都有相关的学习重新排名的特征，即查询的向量空间相似性及其最大卢茜恩分数（见 11.3.2 节）。

在每次运行中，不同查询的文档成为测试集，其余 10 个查询的文档是训练集。系统检查每个训练集文档的重新排名特征，学习逻辑回归公式，为每个重新排名特征分配权重，并计算文档的新排名分数。在学习过程中，检查用于查询的文档的真正排名，并设置权重，以便全局错误函数最小化。

在每次运行中，使用完成的逻辑回归公式来预测测试查询排名。计算评估度量值，然后在所有运行中平均度量值。

# 11.4.1. 评价度量标准

系统的排名表现是根据两个常用度量标准评估的：AP 和标准化折现累积增益（discounted cumulative gain，简称为 DCG）来衡量表现。这些度量在 [ 0, 1 ] 区间内标准化，最佳得分为 1。

AP 的直觉如下。程序正在搜索相关文档并检索候选文档的排名列表，而不是所有候选文档实际上都是相关的。对于每个正确返回（相关）的文档，人们计算它的精确率，然后取平均值。如果返回的结果是 1, 1, 1, 0, 0, 1，其中 1 是相关文档而 0 不是，则每个正确点数的精确率是已经检索到的正确文档的数除以到目前为止检索到的文档总数：1/1, 2/2, 3/3, 3/4, 3/5, 4/6。这个系列的 AP 是 0.92。

```
AP = \frac{\sum_{i \in R} P@i}{|R|}
```

换句话说，对于计算 AP，人们在区间 [ 1, 30 ] 进行一次排名。
