词袋表示不保留术语在句子中出现的顺序。关于句子含义的信息丢失了。

由于很难比较表示为词袋的句子，因此可以按字母顺序放置术语并将其表示为术语向量：

废弃 ( abandon ) 行为 ( action ) 抓获 ( capture ) 计算机 ( computer ) 侵占 ( conversion ) 深 ( deep ) 被告 ( defendant ) 黑客 ( hack ) 拦截 ( intercept ) 最后 ( last ) 一分钟 ( minute ) 近乎 ( nearly ) 原告 ( plaintiff ) 探测器 ( probe ) 机器人 ( robotic ) 海 ( sea ) 在哪里 ( where )

术语向量 ( term vector ) 根据其词语、引用、索引概念或其他特征表示句子或其他文档。它是从原点 ( 0, 0, 0, ……, 0 ) 到表示大维空间中的案例文本的点的箭头。由于完整文本语料库中的每个不同的术语（ 即，单词或其他特征 ）对应于另一个维度，因此维度的数量 n 非常大。
