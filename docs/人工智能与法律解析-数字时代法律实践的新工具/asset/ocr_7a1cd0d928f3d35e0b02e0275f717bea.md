不同部分的标准分类，标记的根据是它们在文档中的意义（例如，作为规定、定义、引用、名称、日期）。可扩展标记语言（Extensible Markup Language）是这种结构化数据的语法和格式。可扩展标记语言文件对包含带注解的文档而言是不错的选择，因为它们是人类可读的。

一些法律文件标记语言提供了一种系统的可扩展标记语言的类型机制表示包括制定法和规章在内的法律文件，并在某些权威的在线存储库中以统一资源标识符（Uniform Resource Identifiers）引用文档。例如基于使用开放标准和本体的非规范性文本的知识管理体系结构（Akoma Ntoso）的法律文档标记语言（LegalDocML）（Cervone 等，2015）。更熟悉的网络统一资源定位器（Internet URL）是统一资源标识符的子集，它们也提供资源的位置。

例如，在使用开放标准和本体的非规范性文本的知识管理体系结构中，通过使用命名惯习和与法律文档相关的类的本体等唯一名称的方式标识所有文档或资源，比如：

+   - 作品（例如，“2015 年第 3 号法案”）
+   - 表述（例如，“2015 年 3 月 3 日修订生效后的版本中的 2015 年第 3 号行为”）
+   - 表现形式（例如，2015 年第 3 号法案的 PDF 版……）
+   - 项目（例如，“我的计算机上名为 act32015.pdf 的文档包含 2015 年第 3 号法案的 PDF 版”）
+   - 上述组件，包括表示条款和章节等的表述组件，以及
+   - “个体（人），组织(公司机构)，行动和事件(事件)，地点(地点)，想法（概念）和物理对象（对象）”（Oasis，2016）。
