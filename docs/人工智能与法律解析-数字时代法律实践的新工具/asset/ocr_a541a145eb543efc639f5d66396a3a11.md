# 托尼·梅森诉杰克·丹尼尔酿酒厂案
518 So 2d 130 ( 1987 ) 阿拉巴马州民事上诉法院
August 5, 1987

被告的反上诉……

适用这些因素到此案的证据，我们发现一些因素支持，一些因素否定林奇堡柠檬水是梅森的商业秘密的结论。
......

梅森就保护林奇堡柠檬水秘密所采取的预防措施作证。他作证说他只告诉了他的一些员工——调酒师——秘方。他说每个人都被特别指示不要告诉任何人秘方。为了防止顾客学习秘方，饮料混合在餐厅和休息室的“后面”。梅森的证词在很大程度上得到了他的员工和前任员工的证实。

该证词还反映出，在温斯顿兰德尔学会了这个秘方之前，梅森为林奇堡柠檬水保留秘方的努力显然是成功的。似乎除了原告之外，任何一家公司都无法打调林奇堡柠檬水。

我们注意到，林奇堡柠檬水的秘方构成商业秘密并不要求绝对保密——“提供商业秘密保护所必需的一切保密因素。” Drill Parts, 439 So.2d at 49.

被告还认为，梅森的秘方不是商业秘密，因为它可能很容易被其他人复制。被告推出至少两名调酒或混合酒精饮料领域的专家作证。这一证词表明林奇堡柠檬水是柯林斯饮料系列的成员之一，其中“有几十个……，即使不是几百个，基本上也是相同的要素。”至少有一名人证作证，他可以在品尝林奇堡柠檬水后复制秘方。

当然，这个证词是一个强有力的因素，反对梅森的林奇堡柠檬水的秘方是商业秘密的结论。但是，我们认为这种证据本身并不能阻止这样的结论。相反，应该对这些证据进行权衡和考虑，以及证明存在商业秘密的证据。
......

我们对该记录的审查表明，原告确实提供了一些证据证明他的林奇堡柠檬水秘方是商业秘密。因此，初审法院在否认被告人提出的基于不存在商业秘密的定向判决的动议上没有错。
......

该案件被撤销，并要求初审法院听审与此意见不一致的意见。
