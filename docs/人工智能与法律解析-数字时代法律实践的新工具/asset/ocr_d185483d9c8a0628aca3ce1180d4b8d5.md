标准化折现累积增益的直觉是每个相关文档对一个排名总体质量的贡献，其根据是它相对于理想排名的排序。折现累积增益是排名项目相关性的权重总和。项目的排名下降，权重也下降。从这个意义上讲，增益是“打折的”。通常，使用对数折扣函数数来模拟下降的权重。标准化折现累积增益（NDCG）以最佳排序结果的折现累积增益度量——理想折现累积增益（IDCG）——除以折现累积增益，并且结果总是[0，1]区间的数字（见 Wang 等人，2013）。

为了测量整个系统的表现，关于所有查询的系统排名表现是根据平均精确率度量（MAP）和平均标准化折现累积增益来衡量的。

平均精确率度量是每个查询的平均精确率（AP）的所有查询集合的平均值。它被定义为：

```
MAP(Q) = \frac{\sum_{i}^{|Q|} AP_i}{|Q|}
```

其中 Q 是所有查询的集合，APi 是每个查询的平均精确率。平均标准化折现累积增益（Average NDCG）被定义为：

```
AverageNDCG = \frac{\sum_{r}^{|Q|} NDCG_i}{|Q|}
```
