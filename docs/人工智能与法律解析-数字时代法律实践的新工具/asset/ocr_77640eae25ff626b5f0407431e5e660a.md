# 关于区分 F16 的重要性的论证

+   > 原告在梅森案中弱化梅森案中 F16 的区别。在梅森案中，原告的产品信息可以通过逆向工程学到「F16」。在布赖斯案中不是如此。然而，这不是一个重要的区分。在布赖斯案中，原告在与被告谈判时披露了他的产品信息「F1」，然而原告赢了。在两个案例中，被告通过合法的手段获得或能够获得信息「F120」，但原告还是赢了。

+   < 被告的论证强调区分梅森案中的 F16。在梅森案中，原告的产品信息可以通过逆向工程学到「F16」，在布赖斯案中不是如此。这个区分是特别重要的。它表明在梅森案中，原告的信息可以从原告商业以外的资源中获得「F108」，在布赖斯案中不是如此。
