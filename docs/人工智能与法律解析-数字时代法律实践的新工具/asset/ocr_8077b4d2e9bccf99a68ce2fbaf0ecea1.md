# # 致 谢

匹兹堡大学法学院提供夏季院长奖学金支持我撰写本书。本书草稿的笔记萌发于我在博洛尼亚大学伊拉斯谟·蒙德斯（Erasmus Mundus）法律、科学和技术博士课程的教学，感谢莫妮卡·帕尔米拉尼（Monica Palmirani）教授给我提供的机会。维恩·沃克（Vern Walker）、亚罗米尔·萨维卡（Jaromir Savelka）和托马斯·戈登（Thomas Gordon）阅读了草稿并提供了有用的建议，在此谨致谢意。

我特别感谢我以前的博士学生和现在的同事马蒂亚斯·格拉普梅尔（Matthias Grabmair），他仔细阅读了本书并提出了许多深思熟虑的建议。马蒂亚斯在法律文本解析、预测和基于案例的论证方面的工作以及他和亚罗米尔将机器学习应用于法规的工作使我确信，写这本书的时机已经成熟。向马蒂亚斯提供咨询，跟他合作，向他学习，这是我作为一名教师在职业生涯中的极大乐趣。

如果没有我的妻子阿利达（Alida）一直以来的爱和支持，我将永远不会有作为老师的职业生活，也永远不会完成这本书。我们的女儿亚历山大（Alexandra）在我们研究和写作的辛苦工作中让我们微笑，帮助我选择本书的封面。
