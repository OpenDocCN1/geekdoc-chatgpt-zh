# 4.4.2. 将有监督的机器学习应用于美国最高法院的数据

研究人员将有监督的机器学习方法应用于此特征数据，特别是决策树随机森林 (Random Forests of Decision Trees, 简称为 RFDT), 图 4.2 中阐释了单一决策树方法的更复杂版本 (Katz 等, 2014, pp.3–4)。

决策树随机森林用决策树的集合或随机森林替换单个决策树，以便在预测中实现更多样的来源。“集合”方法生成许多不同的树木，并在整个森林中平均生长。随机森林生长较小的树木，有助于防止模型过度拟合 (overfitting) 数据。

当一个机器学习模型具有如此多的额外项时，它适合数据中的随机变化而非实际模式，此时会发生过度拟合 ( 见 NIST / SEMATECH, 2016)。实际上，该模型 “记忆” 了特定的训练数据，而不是 “学习” 了来自它的一般化。当对新数据进行预测时，这样的模型会失败；它没有从训练数据中学习一个可以应用于新数据的一般化分类器。

一些机器学习模型特别容易过度拟合，包括几乎总是过度拟合数据决策树。相比将单个复杂树组合起来，将决策树随机森林的较小树组合起来可以更好地防止过度拟合。
