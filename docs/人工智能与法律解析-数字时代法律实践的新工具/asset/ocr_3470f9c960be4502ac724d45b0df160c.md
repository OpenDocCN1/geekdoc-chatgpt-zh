# 第十二章 认知计算法律应用程序

# 12.1. 导言

第 11.5 节提出的原型将法律信息检索转换为论证检索。正如那里所论证的，如果第一部分的法律推理、论证和预测的计算模型的某些法律知识表示框架可以在案例文本中自动注解，那么法律应用程序可以完成比概念法律信息检索更多的工作。它可以支持认知计算。本章描述了根据任务、界面、输入和输出针对法律领域量身定制的认知计算环境，并解释了基于计算模型的类型系统和注解将如何帮助人们构建关于法律论证的假设，做出预测并根据语料库中的文档对它们进行测试。

一个假设预测应该如何裁决一个法律问题，例如：

+   - 一原告应该赢得商业秘密滥用的问题，即被告欺骗它披露其机密产品数据，即使信息很容易被逆向设计。
+   - 一即使在接种疫苗和伤害发作之间已经过去六个多月，原告仍然可以证明因果关系。
+   - 一即使被告故意干扰她的尝试，原告的转换声明也会失败，因为她实际上没有抓到棒球。

构建和测试像这样的法律假设是一种典型的认知计算活动，人类和计算机可以在这些活动中协同工作，彼此执行最擅长的智能活动。
