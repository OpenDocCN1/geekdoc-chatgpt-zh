# # 9.8. 结论

正如我们所看到的，从制定法文本中自动提取逻辑规则不仅是应用自然语言处理的问题，也带来了额外的挑战。

如果一个主题产生于本章报告的工作，那么识别制定法与规章中的重复结构或模式是重要的，这些结构或模式与规范性规则的形式和意义相关，包括：

+   - 一概括一般的立法或具体法律的逻辑结构，
+   - 一术语的模式或模板，单词的语法角色，概念的类型，模态动词，
+   - 以及一般的规范性规则或特定法律的其他要素特征，或者
+   - 一特定受规制领域的协调定义、要求和豁免特征的法律设计计模式。

自动化程序和人类对规范性规则的理解将受益于识别这些模式、设计规则以将元素组合成模式或将模式分解为元素以及开发用于可视化模式的技术。

使用像卢依马这样的层级类型系统——捕获了这些模式的各个方面来丰富制定法文本的表示，似乎对机器学习有用。在接下来的章节中，我们将研究使用卢依马注解从法律案例中提取与论证模式相关的信息的一些努力。
