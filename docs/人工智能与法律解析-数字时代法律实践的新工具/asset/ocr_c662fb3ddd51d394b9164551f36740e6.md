# 后 记

次，感谢该书的作者阿什利教授在百忙之中为中译本撰写序言。今年6月29日，在杭州师范大学沈钧儒法学院主办的“新科技与法律前沿问题”国际论坛上有幸见到阿什利教授，当面向他请教重要术语的翻译问题，感谢他耐心地答疑解惑。该书的一大特点是图多表多特殊符号多，共有102个图和21个表，这无疑增加了编辑出版的难度，感谢各位编辑的默默付出。又次，感谢我指导的法学理论专业研究生秦锋励、李勇、焦祎婕、刘彦池、陈冉怡和展维帮我校对译稿，感谢西法大中楼复印部邹贵勇帮我制作图表。最后，感谢妻子和父母的无私支持，没有他们的支持，我不可能从繁重的家务事中解脱出来一心做学术研究。也要感谢我的两个孩子，感谢老大的理解，这一年因为忙于翻译开会，带孩子们出去玩的时间大大减少，老大还会说：“爸爸，你现在去开会，家里过得挺好！”老二时常在我面前念叨，爸爸怎么老是要工作，他经常光顾我的办公室，我也乐于他的“打扰”，他来了就陪他玩一会儿，也许这样劳逸结合才让我的翻译任务得以顺利完成！

由于翻译时间有限，学识和水平也有限，书中难免有错漏或表述不当之处，恳请学界同仁不吝指教。

2019 年 11 月 3 日
于西法大雁塔校区
