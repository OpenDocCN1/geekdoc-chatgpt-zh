# # 后 记

2018 年 6 月，於兴中教授来西北政法大学讲学，他跟我说，商务印书馆购买了阿什利教授的新著《人工智能与法律解析》（剑桥大学出版社，2017 年）一书的版权，他正在物色合适的译者，问我是否愿意翻译该书。那时刚好我主持的国家社科基金项目结项了，手头没有特别赶的研究任务，就接了这个活。挑战接踵而来，商务印书馆希望我在一年之内译完该书，时间非常紧迫。《人工智能与法律解析》是一部典型的跨学科著作，该书涉及法学、语言学、逻辑学、统计学、计算机科学、信息科学等等学科的概念和理论，这对我的智识带来极大的挑战。为了翻译这本书，我购买了近百部相关的图书，了解背景知识，弄清楚陌生概念的含义。2018 年暑假，我放弃休假，忍着西安的酷暑一鼓作气翻译了 200 页，心里踏实许多。开学后又是上课又是开会，加之杂事繁多，翻译一度中断，到今年放寒假才有了整块时间继续翻译，奋战一个寒假总算译完该书的正文部分。开学后，利用寒暑假的时间翻译图表校对译文，6 月底将定稿交给了出版社，我如释重负，长舒一口气。

翻译本书的过程中得到了许多师友和学生的帮助。首先感谢于兴中教授的推荐和信任。《人工智能与法律解析》一书甫一出版，於老师就推荐给商务印书馆王兰萍女士，请商务印书馆翻译出版该书。於老师向商务印书馆推荐我翻译该书，是对我翻译水平的充分信任。其
