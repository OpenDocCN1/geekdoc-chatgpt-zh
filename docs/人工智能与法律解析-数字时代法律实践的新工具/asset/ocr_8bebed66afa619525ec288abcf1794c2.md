论证图也是二分图。如图中所示，论证型式搜索过程为原告和被告的案件问题提供了法律论证。

基于价值判断的论证预测根据论证图表预测案件的结果。“它使用从论证图计算的置信度度量来预测案件结果，并生成证成其预测的文本法律论证。置信水平扩展使用定量权衡，权衡事实对价值的影响。基于价值判断的论证预测使用迭代优化方法自动从过去的案例中学习这些权重。”（Grabbair，2016，p.iv）

换句话说，在给定以前案件和语境的价值权衡的情况下，论证图用作定量图形模型，用于预测案例的结果。“置信水平的价值……表示可以通过论证建立陈述的程度，从而为系统提供一种‘定量置信语义’”（Grabbair，2016，p.17）。这些值的计算基于：

+   1. 与每个因素对有利于原告或被告的每个价值的影响相关的权重。

+   2. 可以用置信水平建立论证的前提，而置信程度又取决于支持和反对这些前提的论证的强度。

正如每个论证型式的触发，论证型式扩展了参数图，它还输出一个置信函数，用于计算论证的相对影响，这个论证仅仅对整个论证的置信水平做出贡献。每个论证型式都有一个相关的函数，用于计算它构造的那种论证的相对说服力的度量。对于来自先例的问题间或局部问题的论证，相比先例 p 和 c 之间的类比，置信度量增加了，并且在可以区分它们的程度上降低了。

基于价值判断的论证预测程序“通过扩展论证图中的置信值来预测一个案件的结果，置信值来自学习的权重参数，这些参数表示某个事实对适用值的影响的说服力。”（Grabbair，2016，pp.25-26）
