制启发法导致对基于规则的分析进行“健全性检查”，其中程序确定用于断定家庭办公室是他的“主要营业地”的规则几乎适用：所有前件都得到满足，但只有一个例外：纳税人是否履行“在家庭办公室工作的主要责任。”控制规则再次转向基于案例的推理，找到一个满足缺失前件的案例——德鲁克（Drucker）案，该案与当前事实情境类似。

卡巴莱系统证明，表示法律因素的维度是对一个领域进行建模的有用技术，商业秘密法域除外。这些技术展示了如何使用维度表示制定法领域中的法律因素，并应用维度和基于法律因素的方法对法律规则中的概念进行推理。

# 案例论证系统中的因素

海波系统的第二任继承者案例论证系统用因素简化了维度表示（Aleven, 2003）。与海波系统一样，案例论证系统根据法律因素处理商业秘密盗用，但它这样做的时候没有使用维度来表示它们。

相反，它用相应的二进制因素替换每个维度。一个因素要么适用于场景，要么不适用。它没有使用幅度或范围，也没有相关的前提条件来测试一个因素是否适用。案例论证系统使用了更完整的因素列表，如表 3.1 所示，并模拟了如何淡化或强调区分因素（Aleven, 1997）。案例论证系统在计算机化教学环境中使用增强因素来帮助学生学习基于案例的论证技巧，例如区分。如第四章所述，它还使用因素来预测案例结果（Aleven, 2003）。
