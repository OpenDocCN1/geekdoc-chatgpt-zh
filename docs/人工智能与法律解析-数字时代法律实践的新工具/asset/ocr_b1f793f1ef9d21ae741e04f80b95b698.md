威廉·亨德森（William Henderson）——印第安纳大学莫勒法学院的一位法学教授认为，法律处理工程（legal processing engineering）已经改变了法律实践，并将继续这样做，因此法学院必须教授学生处理工程技能。

因为法律行业现在强调处理和技术，现在讲授的实践技术技能和领域知识对 2015 年毕业的大部分法学专业毕业生而言是不够的……法律变得越来越不关注陪审团和法庭辩护，而是关注处理工程、预测编码，以及这些处理所需要的协作和技能，对此学生没有准备好。（Henderson, 2013, p.505 及下页）

过程工程（或“再造工程”）在商业和信息管理文献中被界定为“改变过程”：

通过重新设计核心业务流程，[ 解决 ] 加速流程、减少所需资源、提高生产力和效率以及提高竞争力的需要，可以快速大幅提高组织绩效。（Attaran, 2004, p.585）

信息技术被称为“最有效的技术”，用于此类业务流程再造，建立“轻松沟通，提高流程绩效”，并“通过建模、优化和评估其后果来帮助再造工作”。（Attaran, 2004, p.595）

亨德森强调过程工程在法律工作发展中的作用。过程工程是他从理查德·萨斯坎德（Richard Susskind）的《律师的终结》一书中得出的一个概念，根据该概念，法律工作正在从定制（或定做）演变为标准化、系统化、打包以及最终的商品格式：

通过识别法律形式和司法意见中的递归模式，使得（从定制的法律工作到……商品化）的这些变化成为可能，这使得流程和技术的使用能够常规化规模化地便宜又高质量地解决各种法律需
