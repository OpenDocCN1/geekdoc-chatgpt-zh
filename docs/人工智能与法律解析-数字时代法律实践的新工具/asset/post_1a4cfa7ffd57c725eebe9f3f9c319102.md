
或“蓝图”，其前提可以基于假设的事实或其他论证型式的结论来建立。一些常见的法律论证型式或模式包括来自法律规则的论证、根据类比过去案例的论证或源于基础价值的论证。还有反对这些论证的论证型式，例如区分先例或引用一个王牌反例。

论证型式作为模板在计算模型中起着有用的作用。它们的“组件是预先定义的，可以用从现有知识中推断出的信息填充”（Gordon 和 Walton, 2009, pp. 2, 8）。实际上，这些模板构成了一个可能的替代方式的空间，用于做出或响应论证。“（一个计算机程序可以）使用启发式方法为论证集合搜索空间，其中一些目标陈述或论证是可接受的或被认为是不可接受的”（Gordon 和 Walton, 2009, pp. 2, 8）。

图 5.1. 卡涅阿德斯论证图

(Gordon, 2008b,c; Gordon 和 Walton, 2009; Walton 和 Gordon, 2009; 见 Ashley, 2012)

论证型式或许包括关键问题，这些问题有助于评估论证型式是否以及如何适用于特定案例。……每种类型的论证型式都有其自己的关键问题（Walton 和 Gordon, 2005）。一些关键问题涉及该型式的前提的可接受性。其他问题指出该型式可能不适用的例外情况。如果一个关键问题的答案揭示了一个失败的假设或例外，它就会产生可能的反驳（Prakken, 1995；Gordon 和 Walton, 2006；另见 Grabmair 和 Ashley, 2010, 2011）。此外，论证型式可能与相同或另一种型式的冲突应用相矛盾（Prakken, 2005）。

卡涅阿德斯逐步建构了一个法律论证，如同它建立前提一样。在任何给定阶段，模型都会根据论证中的其他命题和一组假设来评估命题是否可接受。在确定论证的状态时，该模型可以应用诸如证据优势之类的法律证明标准的计算近似值。在每个阶段，该模型还搜索新的论证，使不可接受的陈述变得可接受或可接受的陈述变得不可接受；后者是反驳。法律论证型式指导这种搜索。

### 5.3. 行动中法律论证计算模型的一个扩展实例

人们可以说明法律论证的计算模型如何在一个带有卡涅阿德斯论证模型的扩展例子中支持同时赞同一个命题及其反命题的论证（Gordon 等, 2007）。

卡涅阿德斯构造了直观的吸引人的表示法律论证结构的论证图（argument diagrams，也称为 argument maps）。这些图区分了支持一个命题的论证以及攻击这个命题的论证。出于这个原因，卡涅阿德斯论证框架被称为二分图（bipartite）。此外，可以做出支持命题 p 的论证和反对命题非 p 的论证。

这个示例论证恰好涉及德国家庭法的一些问题。在图 5.1 所示的卡涅阿德斯图中，① 表示命题的陈述节点是框；论证节点是圆圈（“+”表示支持；虚线表示与论证的适用性相反）。卡涅阿德斯图中的陈述节点被赋予“陈述”“质疑”“接受”或“被拒绝”的状态。该模型推断论证节点的适用性和陈述节点的可接受性。（图中表示的论证内容将在下面讨论）

① 卡涅阿德斯图表惯例随着时间的推移而发展。查看戈登（Gordon, 2015b）的版本历史。此处显示的图表基于一个看起来特别容易理解的旧版本。我特别感谢马赛尼斯·格拉布梅尔（Matthias Grabmair）帮我构建这些示例。

在卡涅阿德斯框架中，论证可能会通过反驳、破坏和削弱来相互攻击。反驳是“支持和反对某些结论的论证……反驳之间的冲突由权衡论证和应用证明标准来解决”（Gordon, 2015a, p.34）。当一个论证与另一个论证的前提相矛盾（即，破坏）时，前者被称为一个破坏性论证（Gordon, 2015a, p.44）。削弱论证是攻击另一个论证的可适用性的论证。在论证图中，削弱器被描述为论证节点，其结论是另一个论证节点而不是一个陈述节点（Gordon, 2015a, p.21）。

### 5.3.1. 基于卡涅阿德斯的家庭法示例

汤姆·戈登（Tom Gordon）和道格·沃尔顿（Doug Walton）提供了一个经典的示例，说明了一个结构化的法律论证，这个论证涉及一套大致源于德国家庭法的规则（见 Gordon, 2008b,c; Gordon 和 Walton, 2009; Walton 和 Gordon, 2009）：

- 规则 §1601-BGB: 如果 x 与 y 有直接血缘联系，则 x 有义务支持 y
- 规则 §1589-BGB: 如果 x 是 y 的祖先，则 x 与 y 有直接血缘联系
- 规则 §91-BSHG: 如果“x 有义务支持 y”将导致 x 过度困难，规则 §1601-BGB 将排除“x 有义务支持 y”
- 规则 §1602-BGB: 根据规则 §1601-BGB, x 没有义务支持 y, 除非 y 有需要。

假设我们被给定一个事实，乔治是玛莎（她的父母或祖父母）的祖先，我们想知道，鉴于上述法律规则，乔治是否有义务支持玛莎。

在我们检验卡涅阿德斯系统将如何实现之前，让我们想象一下一个实施经典逻辑演绎的程序（如第二章的《英国国籍法》程序）将如何应用这些法律规则来确定乔治是否有义务向玛莎提供支持。

通过一个反向链接的应用和两个带有分离规则的演绎推理的应用，《英国国籍法》程序将得出结论，乔治与玛莎有直接血缘联系，并且根据规则 §1601 乔治有义务支持她。然而，系统不能直接从规则 §1601 得出这个结论，因为该规则只说“直接血缘联系”。这就是反向链接的地方（见 1.3.1 节）。如图 5.2 所示，应用反向链接，系统可以找到规则 §1589，由此可以得出乔治与玛莎有直接血缘联系的结论。然后卡涅阿德斯根据乔治是玛莎的祖先这一事实确定规则 §1589 的前件得到满足。

图 5.2. 经典演绎

(Gordon, 2008b,c; Gordon and Walton, 2009; Walton and Gordon, 2009)

假设一个人接下来知道有义务支持玛莎会导致乔治过度困难。如图 5.3 所示，作为使用规则进行演绎推理的问题，然后适用规则 §91，并且乔治支持玛莎的义务将被排除。然而，《英国国籍法》的类型系统已经证明，乔治确实有义务支持玛莎。换句话说，它现在已经证明了两个不一致的后果；乔治既有义务也没有义务支持玛莎。

图 5.3. 经典演绎不能证明命题及其反命题

(见 Gordon, 2008b,c; Gordon and Walton, 2009; Walton and Gordon, 2009)

这种现象经常发生在法律推理中，但正如第二章所解释的那样，对于经典的逻辑演绎来说，它是有问题的。经典逻辑是单调的；一旦事情得到证明，即使在新信息的基础上它也不能“未经证明”。此外，在逻辑演绎的经典模型中，证明一个命题及其反命题的能力意味着系统不一致并且可以证明任何东西。（见第 2.4.2 节中关于经典逻辑的这种“爆炸性”特征的简短证明。）换句话说，如果一个人希望计算机基于法律规则做出同时支持正方和反方的论证，那么经典的逻辑推理就会失败。

像卡涅阿德斯这样的论证的计算模型通过使用非单调推理（也称为可辩驳推理）和适当的论证型式来避免这个问题。

### 5.3.2. 基于可辩驳法律规则的论证

在论证的计算模型中，法律规则被建模为可辩驳的推论规则，并且从规则中得出法律推论的论证正式也是可辩驳的。

如图 5.4 左侧所示，可辩驳的推论规则的结论仅仅可能为真。它受制于例外列表和规则应用的假设（有时称为关键问题，见第 5.2 节），如果成立，则击败规则的结论。

- 前提
  - R 是一条具有前件 A1, ..., An 和结论 C 的法律规则
  - 如果在 A1, ..., An 中的每个 Ai 假定为真
- 结论
  - ......那么，C 可能为真
- 假设和例外
  - R 的一些例外适用吗？
  - R 的一些假设没有满足吗？
  - R 是一条有效的法律规则吗？
  - 一些规则排除 R 适用于这个案件吗？
  - 一些比 R 优先的相冲突的高阶规则适用于这个案件吗？

- 前提
  - 规则 §1601-BGB 是带有如下前件的法律规则：如果直接的血缘联系（自然人 1，自然人 2）
- 结论
  - ......那么有义务支持（自然人 1，自然人 2）可能为真
- 假设和例外
  - 除非 1601 的例外适用（即，规则 §1602-BGB）
  - 假定 1601 的假设得到满足
  - 假定 1601 是一条有效的法律规则
  - 除非有些排除 1601 的规则（即，规则 §91-BSHG）适用
  - 除非有些比 1601 优先的相冲突的高阶规则适用

图 5.4. 来自可辩驳推论规则的论证正式 (见 Gordon, 2008b,c; Gordon 和 Walton, 2009; Walton 和 Gordon, 2009)

例如，规则 §1601-BGB 将表示为可辩驳的推论规则，如图 5.4 右侧所示。它的结论——有义务支持（x，y）——仅仅可能为真，即使有直接的血缘联系（x，y）这个前提得到满足。结论取决于各种假设和例外。

特别是，规则 §1601-BGB 的假设和例外将包括基于规则 §1602-BGB 的例外，基于规则 §91-BSHG 的排除，以及更一般的假设，即规则有效且不受某些更高优先性的相互冲突规则的约束。

卡涅阿德斯可以用这种可辩驳的推论规则来推理和构造论证，并绘制它所做出的论证。如果一个人指定了一个证明目标，即乔治的确有法律义务支持玛莎（图 5.1 中根节点处的散列圈表示），那么卡涅阿德斯规则引擎会从该目标后向推理，找到支持该目标的可辩驳推论规则：§1601 和 1589。在构造和编辑论证时，它们在论证图（如图所示）中可视化。顺便提一下，卡涅阿德斯的法律推理是涵摄的一个例子（见第 2.5.1 节），但在确定一个法律概念是否涵摄事实情境时，它采用了可辩驳的规则和各种论证型式，而不仅仅是演绎推理。

当然，目前为止，这与《英国国籍法》程序根据制定法规则推断出结论的方式基本相同（见上文）。然而，这里有一个微妙的区别。卡涅阿德斯构建了一个论证，乔治有义务通过应用论证型式（通过演绎的论证）来支持玛莎。正如我们将要看到的，这只是卡涅阿德斯可以应用的论证型式之一。

如果一个人然后指定了击败这个论证的目标，那么卡涅阿德斯会搜索可辩驳规则的例外、排除或假设失败的表示，这些情况可以阻止论证的推定结论。

有义务支持玛莎会导致乔治过度困难，在给定这一事实的情况下，卡涅阿德斯发现了一个可适用的规则 §91，排除了规则 §1601，并修改了图表（图 5.5）。

也就是说，由于法律规则表示为可辩驳规则，程序可以找到失败的假设、例外或排除，它们阻止之前论证推定的结论。此外，与经典的逻辑演绎不同，卡涅阿德斯凭借其可辩驳的法律规则和论证，可以支持同时赞成和反对一个命题的论证（比较图 5.3 和 5.5）。

假设目标仍然是表明乔治没有义务支持玛莎，卡涅阿德斯可以做出任何其他论证吗？

在像美国这样的普通法司法管辖区，律师会查看先前已判决的法律案件，以确定法院是否以及如何确定“过度困难”问题。在找到此类案件之后，律师通过类比做出论证，当前案件应该或不应该以与先前案例相同的方式来判决。

当然，这些论证也可能引发进一步的论证。一些类似的案例可能会支持一个结论，即存在过度困难，而另一些则可能支持相反的结论；有些案例会比其他案件更类似，这可能会导致论证者区分它们或引用反例。

第三章说明了一些基于案例推理的模型，它们可以做出类似这样的论证。这些模型可以作为论证型式实现，并集成到像卡涅阿德斯这样的论证的整体计算模型中。

让我们假设我们使用的是一种装有案例论证系统风格的基于案例的论证型式的卡涅阿德斯版本，我们拥有一系列与过度困难问题相连的先例和法律因素（事实的既规定型模式，往往会加强或削弱法律结论）。特别是，假设表 5.1 中的法律因素和案例都涉及过度困难的概念。

### 5.4. 抽象论证的计算模型

正如家庭法的示例论证所示，卡涅阿德斯及其二分图论证框架表示一个法律论证的结构：支持一个命题的论证和攻击它的论证。

相比之下，抽象论证框架，一种不同类型的参数框架，使用的论证图只包含相互攻击的论证。这意味着涉及支持和攻击论证的内部论证结构被抽象掉(尽管某些结构可以重建，如下所示)。由朴明汀(Phan Minh Dung) 发明的抽象论证框架在理论上和计算效率方面提供了某些优势 (Dung, 1995)。

抽象论证框架被定义为一组论证 A 和这些论证对之间的攻击关系 R。它被建模为定向图，即这个图的边实际上是箭头。节点表示论证，箭头表示一个论证攻击的论证。为了评估一个论证在抽象论证框架中的状态 ( 包括它的可接受性 )，人们考虑是否可以保护论证不受来自一组论证 S 中其他论证的攻击，该论证是 A 的一个子集或等于 A (Dung, 1995; Atkinson 和 Bench-Capon, 2007)。
