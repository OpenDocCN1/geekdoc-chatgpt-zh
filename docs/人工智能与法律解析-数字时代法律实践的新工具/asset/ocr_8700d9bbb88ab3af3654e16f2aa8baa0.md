# 6.6.3. 通过本体支持自动化法律论证的限度

此类对话在法律上是现实的，具有一定的教育效用。它们说明了如何在比较案件的过程中解释、挑战和改变法律规则。作为一个演绎推理问题，倡导者提出了一种测试，这个测试解释了过去的结果并导致当前事实的期望结果。然而，所提出的测试要经历一个解释过程。怀疑论者提出假设来探讨规则的中级法律概念的意义，并评估其与过去的决定和原则的契合度。该测试以演绎方式应用于假设和先例的事实，但必须根据域的基本政策和价值评估结果。先例被揭示为规则的权威来源，也是一系列事实，倡导者和法官可根据新问题的事实、其他裁决以及基本政策和价值观提取一系列规则。
