# 5.7.3. 基于价值判断的论证预测论证型式

基于价值判断的论证预测建模论证，即一条法律规则应该适用于当前案件，或者不是基于类比适用先前案例。法律规则由中级法律概念组成。这些中级法律概念是商业秘密法领域模型的问题（图 5.10）。类比断言，当前案件和先前案例在价值效应方面存在相同的局部或交叉问题权衡。

这个程序采用基于共享价值效应权衡的类比构建论证的型式，可以检索与当前案件共享相同的局部或问题间权衡的案例，并在恰当的论证中使用它们。

例如，“来自先例的问题间权衡”的论证型式是一条规则，正式指定代表一方援用论证的前提条件。基本上，必须为该方决定一个先例，其在价值影响方面与当前案例具有相同的问题间权衡。

图 5.13 显示了程序对使用此论证型式构造的动力研究公司案的分析摘录。文中带下划线的短语说明，在此处论证型式引出了对商业秘密法保护的价值所产生影响的权衡。即使基于价值判断的论证预测程序输出可能冗长且重复的文本，这是未来工作的问题，但它的论证可以与伯尔曼和哈夫纳所支持的目的论证（如图 5.12 的论证 II 所例证）相媲美。

基于价值判断的论证预测论证型式还支持用先例做出相似的论证，这些先例与当前案件在价值效应方面共享局部权衡，即权衡涉及相同的问题。

图 5.13 中动力研究公司案（Dynamics）和美国分离器（National Rejectors）公司案的比较说明，如果案件确实满足或确实不满足比如信息有价值这样的法律规则要求，基于价值判断的论证预测程序可以在价值效应方面对案例进行抽象类比权衡。

值得注意的是，在基于价值判断的论证预测模型中，先例与当前案件共享相同的价值效应权衡这一事实并不一定意味着他们共享同一组因素。如图 5.11 和 5.12 所示，给定的价值效应可能由多种因素引起。
