# 4.4.1. 预测最高法院结果的特征

最高法院数据库记录了案件、大法官和趋势的特征，所有预测都是基于这些特征做出的，如图 4.3 所总结（Spaeth 等，2013）。案例信息包括案件来源的巡回审判区、法律类型、下级法院异议、问题区域和司法管辖权准则。大法官和法院背景信息包括大法官、大法官性别、是否为首席大法官以及任命总统的党派。趋势包括当前和整体历史上最高法院的裁决、下级法院的趋势、最高法院的单个大法官的趋势以及趋势的差异。在卡茨等人的著作中（2014），作者设计了来自其他信息（标记为“特征工程”）的一些特征。
