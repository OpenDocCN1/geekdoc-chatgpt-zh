单词的词频 / 反文档频率权衡与相关术语在文档文本中出现的次数[ 即词频( tf )成正比，并且与术语在语料库中出现的次数成反比( 即，反文档频率 )( idf ) ]。因此，在查询和文档中出现的术语增加了如下结论的权重：查询和文档类似于该术语在文档中频繁出现而在语料库中很少出现的程度。

术语向量方法的一个优点是易于计算向量空间相似性（ vector space similarity， 简称为 VSS ），即文档之间或查询与文档之间的相似性。实际上，查询被视为用于此目的的文档，并且还表示为术语向量。如在以上示例中那样，将术语放置在特定（例如，字母顺序）的顺序中有助于自动比较术语向量以评估它们的相似性。相似性度量对应于多维空间中的术语向量的端点之间的欧几里德距离。在确定相似性时，使用三角计算将查询与从倒排索引检索的所有文档进行比较。人们计算它们相应的术语向量之间角度的余弦。余弦越小，相应术语向量之间的角度越小，并且全文本方法假定，向量表示的文本的含义越相似。

# 7.5.3. 相关性概率模型

利用概率相关性模型，信息检索被构造为关于用户的查询意味着什么，语料库中的文档是什么以及哪些文档最能满足查询的评价证据问题。关于查询和文档内容的证据包括它们的表示方式。这包括它们包含的单词和短语，它们在词典和辞典中的定义和同义词，文档中的其他特征，例如引文和主题索引，例如韦氏法律汇编主题和关键数字以及统计信息。就好像查询和文档的内容，即它们的含义，会导致观察到的证据，即它们是如何表示的。相反，如何表示查询和文档，即证据，取决于它们意味着什么，即原因。
