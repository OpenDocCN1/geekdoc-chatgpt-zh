辩论者团队开发了一种系统的方法来组织人工注解工作以最大化可靠性。如上所述，注解中的可靠性是指独立的（通常）人类编码人员在为同一文本分配标签时的一致程度。

贴标签协议的标准衡量标准是科恩的卡帕（κ）系数（Cohen，1960）。科恩的卡帕统计量是 0 和 1 之间的值，它衡量的是评估者之间实际观察到的协议（P）减去预期的协议（Pe），如果将协议严格地留给机会的话（见 Breaux，2009）。它由以下公式表示：

κ = (P - Pe) / (1 - Pe)      (10.1)

主要是研究生的人类编码员因他们的工作而获得报酬。他们使用在线注解环境，使团队管理者能够监控贴标者的性能，以提高相对于同辈贴标者的编码效率和准确率。团队管理者根据需要替换了效率低下或不准确的编码员。

鉴于一个辩论主题，五名人类贴标者独立搜索维基百科的文章，因为他们认为这些文章包含依赖上下文的主张。然后五个贴标者阅读每篇候选的文章。他们独立工作，检测到 1,491 个候选依赖上下文的主张。然后，五名贴标者检查每个候选依赖上下文的主张，独立决定确认或拒绝该候选人。只有在至少三名贴标者确认后，候选的依赖上下文的主张才被接受。
