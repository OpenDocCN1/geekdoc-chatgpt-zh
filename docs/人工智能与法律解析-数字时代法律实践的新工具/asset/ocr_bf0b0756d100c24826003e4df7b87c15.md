# 6.2. 本体基础

不管“本体”的形而上学含义，这个术语在计算机模型的背景下并不那么让人印象深刻。本体是“给定领域中对象之间属性和关系的概念化的明确的、形式的和一般化的说明”（Wyner, 2008）。换言之，本体使一个领域中的概念变得明确，以便程序可以用这些概念进行推理。
