# 3.2.1. 法律过程

爱德华·列维（Edward Levi）将根据事例的法律推理过程与法律的借口做了比较，法律的借口“是一个法官适用已知规则的系统”（Levi, 2013, p.1）。对列维而言，法律涉及“移动分类型式”，其中法律概念是分类器。“法律过程中涉及的推理类型分类型式，分类随着分类地做出而改变。规则随着规则的适用而改变”（Levi, 2013, pp.3-4）。

在这个过程中，法院决定先例规则的结果是否应适用于新案件，部分是通过比较新案件的事实与先例的事实。在确定新案件是否与先例相似或不同时，法院可能会澄清规则的法律概念的含义，但经常混淆它们的含义。当一个概念的含义变得不融贯时，法院可以通过介绍一个新的法律概念来引入该规则的例外，此时该规则被修改，并且该过程继续进行。最终，即使有例外的规则也变得不融贯，法院抛弃这条规则并支持新规则（Levi, 2013）。
