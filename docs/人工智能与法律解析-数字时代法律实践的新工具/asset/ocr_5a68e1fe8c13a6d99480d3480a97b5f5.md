# 图 10.4. 卢依马注解环境

非结构化信息管理架构开始配备开发者的工具箱软件，包括复杂的注解界面。图 10.4 显示了非结构化信息管理架构注解环境，用于注解上面讨论的九种卢依马句子类型。这些注解由法科学生在计算机、文字学和法学教授的监督下进行，偶尔由一名称职的研究生提供技术支持。据推测，随着文本注解环境的重要性的增长，将开发出与非结构化信息管理架构或任何后继框架兼容的对用户更加友善的界面。

文本工程通用架构注解环境——文本处理管道架构和非结构化信息管理架构的替代方案——被用于与辩论者相关的主题标签（Aharoni等，2014a）。文本工程通用架构团队软件（Teamware）是一个基于 Web 的工具，它支持大规模多注解器项目中注解者、编辑者和管理者的角色。它使用核心类型的语言元数据系统标记较低级别类型的术语，以此为手动注解准备文本。专家编辑可以使用团队软件监督非专业注解者并策划带注解的文档。它维护有关注解过程任务的统计信息，例如注解器每个文档花费的时间量，它们完成的文档的百分比，以及在实现 IBM 辩论者使用的系统过程类型中有用的其他测量。
