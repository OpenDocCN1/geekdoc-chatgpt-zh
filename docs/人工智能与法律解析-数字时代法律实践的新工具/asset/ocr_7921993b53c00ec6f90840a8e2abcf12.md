# 表 9.1. 针对制定法条款分类的机器学习与知识工程方法的问题 （de Maat 等, 2010）

| 问题 | 描述 | 对知识工程 | 对机器学习 |
|---|---|---|---|
| 从句中的关键词 | 链接到类的关键词出现在从属子句中，子句不影响主句的类型。 | √ | √ |
| 缺少标准短语 | 一个条款使用之前没有遇到的短语。 | √ | √ |
| 模式的变化 | 关于已知模式的变化或许使用相同的语词，但语词顺序不同。 | √ | × |
| 链接到多个类的关键词 | “可以”是允许的指示符，但 “不可以” 指示一项义务。 | × | √ |
| 数据不足 | 训练集呈现的标准短语被过滤到最低要求的两个术语频率。 | × | √ |
| 聚焦于虚假关键词 | 训练集可以巧合地包含许多权限，例如，碰巧涉及一些 “顾问委员会”。分类器错误地假设 “顾问委员会” 是权限类别的指示符。 | × | √ |
| 标准短语之外的关键词 | 机器学习可以基于标准短语的一个词而不是完整的短语进行分类。 | × | √ |
| 曲解的数据 | 不常见的模式或类可能因为先前的机会很小而被错误分类 | × | √ |

对于机器学习算法，研究者使用语词的加权特征向量（一元模型）训练支持向量机分类器（第 8.5.2 节），应用三种类型的权衡，二元（存在或不存在），术语频率，或词频 / 反文档频率值（见第 8.3 节）。

研究者对最近的两项立法中的知识工程和机器学习方法进行了比较。一个只改变现有法律，而另一个包括这些改变并施加新法律。研究人员发现机器学习改变法律方面的得分略好于知识工程，但在施加新法律方面则比知识工程差。特别是，机器学习在定义分类和许可与义务之间的区别方面存在问题。研究者分析了这些错误并列出了原因，包括表 9.1 中的错误和原因。
