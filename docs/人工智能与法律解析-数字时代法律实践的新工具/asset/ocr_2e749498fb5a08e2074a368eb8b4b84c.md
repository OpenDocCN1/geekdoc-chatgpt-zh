在通用词汇层面，单词和短语的形式（即，它们的形态）被规范化，即，关于拼写变化和措辞的标准形式。

对于基本法律概念的层次，律商联讯已经在整个语料库中开发了一个通用的法律概念列表。保罗·张从操作层面将“法律概念”定义为在频繁的法律讨论中通过一组词或短语共同分享的理念。文档中的法律概念被识别，并将其与通用列表中的概念身份（ID）相匹配。

建构通用概念列表的过程结合了自动和手动分析。该过程涉及 n 225 元模型（n-grams）和来自给定文本序列的 n 个项（例如，单词）的连续序列。律商联讯团队：

+   1. 从美国法律文档 n 元模型的语料库中产生候选概念（使用数据挖掘）。
+   2. 用聚焦于名词短语（NPs）的语言规则过滤 n 元模型，并考虑它们在语料库中的分布。
+   3. 对共享相同含义的术语进行分组，并为每个组选择一个基于频率的术语和简单的规则作为表示概念的常规形式。
+   4. 应用手动编辑以在必要时添加 / 配对术语，删去不需要的术语或组，以及选择法律概念（Zhang 等，2014）。

规范形式的结果概念比概念的表面语言表达更抽象。这些概念的范围从法律原则、教义和行话中使用的概念到事实概念（即重要的，经常讨论的事实术语。Zhang 等，2014）。
