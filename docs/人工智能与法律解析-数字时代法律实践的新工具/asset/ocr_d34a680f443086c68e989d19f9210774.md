# # 第九章 从制定法和规章文本中提取信息

# ## 9.1. 导言

律师、公民、业务人员和政策制定者都需要访问和理解法规文本，以便了解法律规则是什么以及如何避免违反他们的要求。因此，人工智能与法律长期以来一直致力于从电子存储的制定法和规章文本中自动提取有关规则要求的信息。

本章介绍了从法定文本中提取信息的一些机器学习和知识工程技术，包括拟章主题和概念，规范或规则的类型，以及制定法条款的一些功能要素。我们检讨了使用机器学习和基于规则的方法来自动划分制定法条款并从中提取功能信息的相对优缺点。

然后，本章聚焦于从制定法和规章中提取逻辑规则的更远大的目标。理想情况下，可以自动从制定法中提取业务规则。提取的规则可以如第 2.3.4 节中那样演绎地适用，或者如在流程合规性中的可辩驳规则那样适用（如第 2.5.3 节）。例如，工程设计环境可以帮助确保系统的设计符合从已经形式化并整合到设计流程的规章中提取的规则。这将延伸到更符合设计的方法，如第 2.5.5 节中的方法。或者，从制定法文本中提取的可辩驳规则可以用于法律论证，正如第 5.3.1 节那样。问答系统可能会使用提取的规则以第 5.9 节中建议的法律上很复杂的方式回答有关其要求的问题。然而不幸的是，从规章文本中
