在卡涅阿德斯框架中，论证可能会通过反驳、破坏和削弱来相互攻击。反驳是“支持和反对某些结论的论证……反驳之间的冲突由权衡论证和应用证明标准来解决”（Gordon，2015a, p.34）。当一个论证与另一个论证的前提相矛盾（即，破坏）时，前者被称为一个破坏性论证（Gordon，2015a, p.44）。削弱论证是攻击另一个论证的可适用性的论证。在论证图中，削弱器被描述为论证节点，其结论是另一个论证节点而不是一个陈述节点（Gordon，2015a, p.21）。

# 5.3.1. 基于卡涅阿德斯的家庭法示例

汤姆·戈登（Tom Gordon）和道格·沃尔顿（Doug Walton）提供了一个经典的示例，说明了一个结构化的法律论证，这个论证涉及一套大致源于德国家庭法的规则（见 Gordon, 2008b,c; Gordon 和 Walton, 2009; Walton 和 Gordon, 2009）：

+   - 规则 §1601-BGB: 如果 x 与 y 有直接血缘联系，则 x 有义务支持 y
+   - 规则 §1589-BGB: 如果 x 是 y 的祖先，则 x 与 y 有直接血缘联系
+   - 规则 §91-BSHG: 如果“x 有义务支持 y”将导致 x 过度困难，规则 §1601-BGB 将排除“x 有义务支持 y”
+   - 规则 §1602-BGB: 根据规则 §1601-BGB, x 没有义务支持 y, 除非 y 有需要。
