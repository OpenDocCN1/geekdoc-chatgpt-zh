## 法律从业者如何用价值进行推理？

本奇 - 卡彭和萨托尔（2003）的价值法律推理模型尽管具有这些优点，但由于多种原因，该模型并未解决伯尔曼和哈夫纳提出的问题。

首先，它是不完整的。有一些漏洞需要填补。关于图 3.13 中的例子以及上面的总结，作者指出，“这种解释依赖一种任意偏好的引入，在不被先例支持的意义上”（即 Mprod 和 Llit > Mprod）。作者考虑“添加一个理论构造器，它允许人们引入偏好，因为任何价值集合都在自己的适当子集上”，但这种允许可能需要进一步提炼。

其次，本奇 - 卡彭和萨托尔的模型产生了多种替代理论。图 3.13 中所示的样本理论只是理论构造器在给定输入的情况下可以生成的一个版本。这意味着必须评估竞争的替代方案。

理论可以根据一致性、解释力、融贯性和简单性进行比较。例如，可以根据理论解释的案例数量来衡量一致性和解释力。然而，在计算实现方面，融贯性和简单性并未得到很好的理解，并引发了关于如何使它们运行的问题（但见第 4.6 节）。

第三，目前尚不清楚本奇 - 卡彭和萨托尔的模型所产生的理论（如图 3.13 所示）是否对法官有意义或者法官是否通过应用这样的理论做出裁判。根据价值评估一个问题的拟议结果是其自身的道德裁判。法官需要考虑价值观如何适用于这个问题的特定事实。建议法官确定过去案例中设定的相互竞争价值之间的偏好并将其应用于新案例似乎很奇怪。法官更有可能考虑价值如何适用于问题的特定情况，并相应地解决任何冲突。

假定在本奇 - 卡彭和萨托尔的模型中使用基于先例的用于竞争因素和价值的偏好规则，该模型似乎没有解决对这些偏好的背景影响。即使法官在过去的案例中使用价值偏好作为指导，他 / 她仍然需要将问题与案件进行详细比较。法官希望确保在新的事实情况下适用价值偏好是恰当的。

麦卡蒂的方法也没有说明如下问题：法官在关于概念适用的法律推理中如何使用价值，或者价值如何与案例理论联系起来。即使该程序能够找到、发现或使用将案例与理论联系起来的不变量，该程序似乎不知道为什么从法律角度看不变量会有关，也不知道分配是否应该是应纳税收入的问题。麦康伯夫人的比例所有权保持不变，但该程序可以解释为什么这对该问题具有法律意义吗？或者它知道为什么不同类型的公司分配的类比吗？它们都涉及风险和收益之间的一些权衡，产生了将它们全部视为应纳税收入的法律理由。纳税人二代是否知道或可以操纵这些理由尚不清楚。

现实中将目的论考虑因素纳入法律推理模型是所有基于案例推理模型的挑战。然而，在能够充分解决问题之前，人们需要更好地理解法律从业者在关于如何决定问题的推理时如何将价值和原则考虑在内。虽然人们经常听到关于案例的辩护理论的讨论，但是这种理论看起来是什么以及如何最好地用可计算的数据结构来表示它是不太清楚的。

我们在第五章关于法律论证建模的讨论中回归这些考虑。

## 3.6. 用基于案例的法律推理模型为认知计算设计约束

以上示例揭示了一些与认知计算相关的设计约束。

- 第一，使用法律规则和概念建构推理模型需要建构支持和反对将规则适用于事实情境的论证。

- 第二，在对关于一条法律规则的概念是否适用于一系列事实的论证进行建模时，案例起着重要作用。论证聚焦于案件和事实情境之间的相关相似性和差异性。

- 第三，在界定案例之间法律上相关的相似性和差异性时，包括规则背后的目的和价值在内的目的论考虑因素发挥了作用。

- 第四，为了成为有用的工具，用计算机评估案例相似性需要定义程序可以实际计算的法律相似性标准。这里介绍的关于法律概念的基于案例的法律推理的计算模型定义了衡量案例相似性和论证模式的标准，这些标准可能有助于检索案例以支持人类解决问题并突出显示过去如何使用这些案例。某种（仍然相当有限）程度上，这些标准在评估相似性时考虑了潜在的目的和价值。

- 第五，基于案例的模型对认知计算的有用性在很大程度上取决于它们的知识表示技术在多大程度上可以使用文本解析技术直接与案例文本相连。在这方面，基于案例的模型各不相同。

除了协调概念的正面和负面实例以证实关于概念意谓的理论的重要性之外，原型和变形模型还没有产生用于在更广泛的法律领域和案例领域中表示案例或计算相似性的工具。如纳税人二代所示，基于案例的论证在概念上可能非常复杂，但目前无法自动识别案例中的特征，这些特征在案例文本中仅仅间接引用或暗示。

海波系统、案例论证系统和卡巴莱系统中的技术可能对认知计算有用。这些技术包括维度和因素，海波系统和案例论证系统用于根据与问题共享的法律因素集合比较案例相似性和生成基于这些相似性评估的论证的技术。它们还包括卡巴莱系统用于对法律规则概念进行推理的技术和案例论证系统预测案例结果的技术 [ 以及基于问题的预测（IBP），见第四章 ]。

像案例论证系统这样的因素可以在文本中自动识别并取得一些成功。请参阅第十章中讨论的 IBP + SMILE 程序。如第九章所述，在提取与法律规则相关的功能信息方面已取得进展，这可能有助于自动识别维度的先决条件。然而，人们是否可以提取与法律因素的维度表示相关联的详细功能信息——例如在一个案例中的焦点时隙值或大小——仍然是一个悬而未决的问题。

基于范例的解释生成器中的基于范例的解释在协助人类解决认知计算中的问题方面非常有用，正如基于范例的解释生成器将案例索引为法律规则概念的正面 / 负面例子。然而，为了对认知计算有用，包括标准事实在内的解释和事实需要直接从文本中提取。

基于范例的解释生成器的结构映射技术和计算相关性度量有一个局限：它们假设在各种案例中对事实做了类似的描述。例如，回家告诉妻子一条消息，为船员获取冰水，或去餐馆寻找食物可能都会解决一个需要，否则会对一个人的工作造成负面影响。但是，如果基于范例的解释生成器要成功地映射这些案例中的事实和关系，那么它们必须以结构和语义兼容的方式在程序（非文本）的案例表示语言中表达。如果没有，从一个案例到另一个案例的结构映射将不起作用。

一个对此约束敏感的人（例如，布兰廷）在一个法律域中表示相对较少的案例，在这种情况下这可能不是问题。然而，确保表示的一致性将是一个主要问题，其中许多案例进入者表示跨法律领域的大量案例。

布兰廷采用了一些技术来解决案例表示一致性的需求。基于范例的解释生成器使用部分匹配的改进策略来放松结构映射约束，以便不相同但语义相似的标准事实可以匹配（Branting, 1991, p.818）。

随后的一个名为 SIROCCO 的程序记录并重用了专家得出的联系，这种联系存在于抽象的规范性原则与专业工程伦理领域的案例事实和事件叙述之间。它的设计师布鲁斯·麦克拉伦（Bruce McLaren）介绍了一种不精确的匹配算法，一种用于表示案例的受控词汇表和一个基于网络的带有示例和用户指南的案例输入工具，以帮助实现案例表示的一致性。结果，SIROCCO 支持跨越相当广泛的工程伦理案例的结构映射（McLaren, 2003）。

然而，用于因特网浏览器的新工具是否可以从文本中提取基于范例的解释是一个经验问题。据推测，在不同案例的基于范例的解释对各种阐释结构映射的需求，以及它对案例表示的一致性的额外需求，加剧了从法律案例文本中提取详细的错综复杂的解释的困难。正如第十章所讨论的那样，从案例文本中提取与论证相关的信息是可行的，包括句子在法官关于各种制定法要求的论证中所发挥的作用。相比法官对每项制定法要求的何为标准事实的解释，此类信息明显要粗略得多。我们在第十二章再来讨论这个问题。

提取法官关于规则背后的目的和价值的讨论的信息也带来了挑战。在价值与因素和法律规则先验相关的意义上，提取的因素和规则将保证价值适用的结论。在某种程度上，法官通过提出假设对规则背后的价值进行推理，那些信息也可能被提取出来。但是，除非法官非常明确地解释他们的意思，否则一个程序很难提取和理解法官在考虑潜在价值时所说的其他方面。

## 第四章 预测法律结果的模型

## 4.1. 导言

计算机程序可以使用表示为特征和结果集的案例数据库预测新问题的结果。它们通常通过基于案例的推理模型或机器学习算法来实现，有时将两者结合起来。本章将解释和说明两者。

预测技术利用了先前案例中所表示的不同类型的特征，从主审法官的名字和代理不同类型案件的律师事务所，到法官的态度信息、判决的历史趋势以及强化一个主张或辩护的陈规定型的事实模式，即法律因素。这些特征在捕获有关案件特点的信息的程度上有所不同。法官的姓名、律师事务所的名称和案件类型——例如专利诉讼或产品责任——抓不住特定法律纠纷特点的信息。相比之下，正如我们在第三章中看到的那样，法律因素捕获了很多关于特点的信息。这些特征根据它们从案例文本中自动提取的难易程度而有所不同。法官和律师事务所名称很容易提取；法律因素也可以被提取，但提取起来相当困难。

本书聚焦于倾向于捕获有关案例特点的一些信息的特征，聚焦于可以从案例文本中自动提取的特征。本章探讨了使用此类特征预测案例结果的替代方法。

机器学习技术在统计上使用特征频率信息来“学习”案例特征与目标结果之间的对应关系。基于案例的技术更侧重于案例比较和解释预测。他们根据相互竞争的法律论证的优势做出预测。这些技术解释它们的预测的方式各不相同，它们的特征表示与认知计算兼容的程度也不各相同。

本章处理的问题包括：计算机程序如何学习预测案例结果？机器学习是什么？有监督的机器学习和决策树是什么？决策树的随机森林的优势是什么？基于案例的推理的预测方法与机器学习有何不同？法律从业者会在没有解释的情况下接受法律预测吗？程序如何提出和测试预测假设？如何根据经验评估这些预测程序？

## 4.2. 自动法律预测的最近邻法

长期以来，预测法院的判决一直是人工智能与法律研究的目标。

早在 1974 年，一个计算机程序预测了涉及特定资本收益税问题的税务案件的结果（Mackaay 和 Robillard, 1974, p.302）。到那时，已有大量有关法律预测的文献。根据加拿大税法，利息的税收问题是指该收益是资本收益还是普通收益，即收益是“仅通过实现担保来增加的价值，或者……在经营业务时实施的盈利计划。”

这些预测基于 64 个加拿大资本收益税案例，这些案例以 46 个二进制特征（即真或假）表示。每个特征都涉及先前研究中的评论者识别为与该问题的判决相关的事实（Mackaay 和 Robillard, 1974）。例如，这些特征包括：“私人方是公司”，“私人方从未从事过房地产交易”，“在购买时，私人方有另一个意图，而不是转售盈利”，和“现在的交易是孤立的交易”（Mackaay and Robillard, 1974, p.327f）。

程序的输入是手动分配给新案例的特征值列表。该程序根据与现有案例相关的新案例的二维表示中的“最近”现有案例输出预测（见图 4.1）。实际上，这是从案例的多维向量空间表示向下的二维预测，每 46 个特征都有一个维度。向量空间表示将在第 7.5.2 节中介绍。

对于麦凯（MacKaay）程序，作者使用了 k 最近邻（或 k-NN）算法，该算法将问题与案例进行比较，以便对最相似的案例进行预测。基本上，人们根据一些度量标准来衡量案件事实之间的相似性或不相似性。然后人们预测新案例将与其最近邻案例具有相同的结果。度量标准汉明距离（Hamming distance）将两个案例具有不同值的变量数相加（见 Mackaay 和 Robillard, 1974, p.307）。作者使用多维缩放将 60 个案例投射到如图 4.1 所示的两个维度上。在图中，焦点在于点的相对位置。任何一对点之间的物理距离表示相应案例之间的不相似性。

图 4.1. 将资本收益税案例投射到两个维度 （见 Mackaay 和 Robillard, 1974）

具有未知结果的“新”案例（白色圆圈）位于 k = 5 个最近邻居（虚线圆圈）之中。最近邻算法预测“反方”，五个最近邻案例中的三个有相同的结果。将这种投影用于法律预测的目的更为模棱两可。例如，新案件非常接近一个反方案例，但该案例出现在正方案例区域的边缘。人们很容易想象一种反驳，即附近的反方案件是例外或错误，新案件的结果应该是“正方”。

## 4.3. 有监督的机器学习入门

另一种人工智能与法律的预测方法机器学习采用了从数据中学习并利用所学知识进行预测的算法（见 Kohavi 和 Provost，1998； Bishop, 2006）。它们使用统计方法从数据集中引出预测模型（或函数），该数据集可用于预测新案例的结果。

一种用于预测法律结果的机器学习是有监督的机器学习。由于它涉及从标记的训练数据推断出分类模型（或函数），因此机器学习被称为有监督的机器学习（见 Mohri 等，2012）。

训练数据包括已分配结果的一组示例。每个示例都是由输入对象（通常是特征值向量）和期望输出值组成的对。学习算法需要从训练数据推广到看不见的情况。

有监督的学习算法解析训练数据并推断出函数或模型，理想情况下模型可用于对新的看不见的实例进行分类。例如，模型可以体现在统计计算的特征权重中或体现在从训练数据机械地引出的一组规则中。给定一个新实例，该模型被用于预测结果。

### 4.3.1. 机器学习算法：决策树

已经开发了各种用于监督学习的算法，包括决策树，也称为分类树（见 Quinlan, 1986）。对于给定的分类器和训练数据集，一个决策树学习一组问题以确定新实例是否是分类器的正实例。每个问题都是一个测试：如果特定特征的权重小于阈值，则分出一支，否则分出其他支。

图 4.2 中的例子说明了如何引出一棵树来决定是否从过去保解决定的小部分实例中保释被告。这个简单例子中的问题的答案是“是”或“否”；没有使用门槛。使用 C4.5 算法建构规则以建立决策树（Quinlan, 2004）。算法根据相关问题（例如“涉及药物”）的结果选择一个属性来划分实例。在 C0 中，算法选择“药物 = 是”将实例分成在 C1 的 {2/n, 4/n, 5/n, 6/n} 和 C2 的 {1/y, 3/y, 7/n}。由于 C2 具有混合结果的实例，因此将其进一步拆分；选择“武器 = 否”，产生了 C3{1/y} 和 C4{3/y, 7/n}。通过选择“先前记录 = 否”，C4 依次被分成 C5{3/y} 和 C6{7/n}。

当 C_i 都具有相同的结果或遇到某些其他终止标准（例如深度限制）时，算法停止。

决策树使人们可以相对容易地解释 C_4.5 算法学到了什么。通过将结果决策树的根跟随到每个叶节点，可以生成一组用于预测保释决策的规则：

- 如果药物 = 是，那么保释 = 否
- 如果药物 = 否并且武器 = 否，那么保释 = 是
- 如果药物 = 否并且武器 = 是并且先前记录 = 否，那么保释 = 是
- 如果药物 = 否并且武器 = 是并且先前记录 = 是，那么保释 = 否

其他机器学习模型直接引发人类可以检查和理解的规则。

另一方面，既然机器学习算法根据可能使人类感到惊讶的统计规律来学习规则，那么其规则对于人类来说可能不一定合理。机器学习预测是数据驱动的。有时数据包含特征，由于诸如巧合或有偏见的选择之类的虚假原因，这些特征恰好与特定集合中的案例结果相关联。虽然机器引出的规则可能导致准确的预测，但它们并不涉及人类的专业知识，并且可能不像专家手动构建的规则那样容易让人理解。由于机器学习算法推出的规则不一定反映明确的法律知识或专业知识，因此它们可能不符合人类专家的合理性标准。

对一个决策树算法而言，一个目标是确定用于将训练实例划分为一组正实例和一组负实例的最有效问题序列。信息理论标准使算法能够选择最有效地划分实例的特征。C4.5 使用标准通过排序问题最小化要求问题的预期数量，并且在问题涉及数量的情况下，选择最具辨别力的阈值将“是”实例从“否”实例中分开。
