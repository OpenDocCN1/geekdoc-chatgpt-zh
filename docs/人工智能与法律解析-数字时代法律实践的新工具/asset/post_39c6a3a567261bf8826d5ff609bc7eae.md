
## 第九章 从制定法和规章文本中提取信息

### 9.1. 导言

律师、公民、业务人员和政策制定者都需要访问和理解法规文本，以便了解法律规则是什么以及如何避免违反他们的要求。因此，人工智能与法律长期以来一直致力于从电子存储的制定法和规章文本中自动提取有关规则要求的信息。

本章介绍了从法定文本中提取信息的一些机器学习和知识工程技术，包括拟章主题和概念，规范或规则的类型，以及制定法条款的一些功能要素。我们检讨了使用机器学习和基于规则的方法来自动划分制定法条款并从中提取功能信息的相对优缺点。

然后，本章聚焦于从制定法和规章中提取逻辑规则的更远大的目标。理想情况下，可以自动从制定法中提取业务规则。提取的规则可以如第 2.3.4 节中那样演绎地适用，或者如在流程合规性中的可辩驳规则那样适用（如第 2.5.3 节）。例如，工程设计环境可以帮助确保系统的设计符合从已经形式化并整合到设计流程的规章中提取的规则。这将延伸到更符合设计的方法，如第 2.5.5 节中的方法。或者，从制定法文本中提取的可辩驳规则可以用于法律论证，正如第 5.3.1 节那样。问答系统可能会使用提取的规则以第 5.9 节中建议的法律上很复杂的方式回答有关其要求的问题。然而不幸的是，从规章文本中提取规则的努力的结果远远还没有达到用这些方式自动推理的理想。

然而，即使没有使用提取的制定法规则自动推理，从制定法文本中自动提取信息的技术也可以通过各种其他方式支持认知计算。自动提取有助于从制定法文本的语料库中检索概念信息。根据来自法律本体（如第 6.3.1 节介绍的电子法院和第 6.4 节介绍用本体基础支持立法起草本体）的语义概念自动注解的条款使用户能够基于其概念内容检索文档。程序还可以根据相关概念自动生成制定法条款的摘要或概要。

如第 2.6 节所述，程序甚至可以生成法规系统的网络分析。制定法网络可以直观地表示提取的信息，某些条款指示某些代理人采取针对其他代理人的行动。其中一个这样的项目将机器学习应用于多个州的制定法文本，从而能够构建制定法网络，人类分析师可以通过这些网络在视觉上或数量上比较不同州的类似目的的规章体系的各个方面。这些网络还提供了一个用于从制定法数据库中检索相关条款的图形用户界面。应用户依马类型系统和文本注解管道来处理文本可以改善它们的表示，以便更有效地使用机器学习。

本章处理了一些问题，包括：如何从制定法文本中提取信息？机器学习、自然语言处理和知识工程发挥什么功能？程序可以直接从规章文本中提取逻辑规则吗？合规性是什么？制定法网络图如何改进概念法律信息检索或促进制定法分析？类似非结构化信息管理架构的基于类型系统的文本分析管道能否协助处理制定法文本？

### 9.2. 从制定法文本中提取信息的研究综述

从制定法条款中提取信息的研究专注于根据以下类型的信息提取或划分条款：

- 制定法条款或规范的功能类型，如定义、禁止、义务和许可。
- 与功能相关的特征，包括功能类型的元素或论证，例如义务持有人或临时代理人，行为和接收代理。
- 法律领域或法律主题，如行政法、私法、环境法或刑法。
- 结合功能类型、功能特征或主题区域的语义配置文档。
- 对索引条款有用的规章概念，例如出现在法律词库或本体中。
- 法律规则或规范，其前件和后果，包括规则或其组成部分的逻辑表述。

为了提取信息，研究人员主要使用知识工程方法——由专家或有监督的机器学习使用支持向量机（见第 8.5.2 节）手动构建规则——决策树（在第 4.3.1 节中定义）或朴素贝叶斯分类器（第 10.3.3 节有解释）。在机器学习工作中，制定法文本通常表示为包含频率信息的词语或术语向量（见第 7.5.2 节）。

为了提供从制定法文本中提取信息的现有技术水平，对于上述每种类型的信息，这里是关于如何提取信息的研究的更详细描述。

条款的功能类型（Functional types of provisions）：研究人员采用机器学习（特别是多类支持向量机模型和朴素贝叶斯模型）对涉及消费者保护的意大利制定法文本的段落进行分类，分类的根据是包括“定义”，“禁止”（必须不为），和“义务”（必须）在内的11个类别（见 Biagioli 等，2005； Francesconi 和 Passerini，2007； Francesconi，2009； Francesconi 等，2010）。在德马特和温克尔斯（de Maat 和 Winkels，2007）和德马特等人（2010 年）的著作中，研究人员根据13种类别对各种荷兰制定法文本中的句子进行了分类，包括“定义”，“出版规定”或“变更范围”等标签。在格拉普梅尔等人（2011）和萨维卡等人（2014 年）看来，决策树或支持向量机模型划分了不同州的制定法指令，将公共卫生突发事件处理为义务、许可（例如，使用“可以”）或禁止。

与功能相关的特征（Function-related features）：一些制定法条款或规范的功能类型将更具体的信息作为要素或参数。这里“参数”意味着类似于数学函数的输入变量。除了提取功能类型之外，研究人员还使用自然语言处理来提取制定法条款的论证，例如行动者针对接收者采取特定类型的行动。例如，数据“控制者”必须向“担保人”提供“告知”（见 Biagioli 等，2005； Francesconi 和 Passerini，2007； Francesconi，2009； Francesconi 等，2010）。格拉普梅尔等人（2014）和萨维卡等人（Savelka 等，2011）的机器学习算法也在处理突发公共卫生事件的条款中识别了类似的要素，例如“州或地方政府公共卫生官员”“可以”“命令”“病人”“隔离”以应对“突发传染病”，当这个病人“拒绝接受治疗”时。

法律领域或主题：也可以学习更抽象的分类，包括法律领域或主题。在弗朗西斯科尼和佩鲁吉内利（Francesconi 和 Peruginelli，2008）看来，朴素贝叶斯和多类支持向量机模型中学到了制定法标签，如环境法、欧盟法和刑法。在奥帕索尔（Opsomer 等，2009 年）看来，作者应用支持向量机学习按类别在包含 230 个主题节点叶的类别中对制定法文本进行分类，例如环境政策、政府、执法、程序和能源政策工具的原则和目标。

其他工作涉及在法律文档中识别应被索引的概念。针对高度特定的主题和功能信息，挖掘制定法文本的大量工作聚焦于根据概念本体［如欧盟多语种词库（Steinberger 等，2013； EuroVoc，2014）］对欧盟文档进行自动分类。在普利康（Poulquien 等，2006 年）看来，作者将制定法文本表示为术语向量，并将其与每个欧盟多语种词库术语相关的类似向量进行比较，例如“少数群体的保护”、“渔业管理”和“建筑和城镇规划”。在博埃拉等人（2012）看来，支持向量机模型学会了为欧盟多语种词库术语（例如，“欧盟合同”、“通货膨胀率”或“意大利”）执行类似的任务。多达拉维希乌斯（Daudaravicius，2012）的工作不仅适用于多个司法管辖区，也适用于欧盟背景下的多语言环境。

机器学习模型还可以学习不同类型的抽象类别，即与特定问题域的相关性。在格拉普梅尔等人（2011）、萨维卡等人（2014）和萨维卡和阿什利（2015）的著作中，一个学到的类别与公共卫生学院研究者选择的公共卫生紧急事件规制问题领域相关。如上所述，这项工作涉及美国多个州有关突发公共卫生事件的法规。

法规的语义概况（Semantic profiles of statutes）：一些工作将功能类型、抽象类别或概念索引结合到更广泛的法规或规章的语义概要中。怀纳和彼得斯（Wyner 和 Peters，2011）采用语言导向规则从一份复杂的四页美国食品和药品管理局关于血液疾病因子检测的规定中提取信息。他们试图在文本中识别不同类型的规范性规则，包括义务和许可及其前件，主体代理，主题和例外。在温克尔斯和霍克斯特拉（Winkel 和 Hoekstra，2012）的著作中，作者使用语义网络技术和自然语言处理技术从与荷兰税法相关的制定法文本中提取概念和定义。

包括逻辑公式在内的法律规则或规范：其他工作主要集中于提取一般性的法律规则或规范（见 Bach 等，2013；Wyner 和 Governatori，2013），以确保业务系统的设计符合相关规章（例如，Zhang 和 El-Gohary，2015；Governatori 和 Shek，2012），开发半自动化技术以改进人类对规章的注解（见 Kiyavitskaya 等，2008；Yoshida 等，2013），或提取功能信息比较跨辖区的监管规则（见 Gordon 和 Breaux，2013；Savelka 等，2014；Savelka 和 Ashley，2015）。

接下来的几节将仔细看看一些用于从制定法文本中提取信息的机制，以及这些方法的经验评价。相关的评价指标与第 4.4.4 节中介绍的相同。

### 9.3.1. 提取条款功能类型的机器学习

为了从制定法中提取功能信息，在弗朗西斯科尼和帕瑟里尼（2007）以及弗朗西斯科尼（2009）的著作中，研究人员构建了两个工具：（1）可扩展标记立法语言分类器（xmLegesClassifier）① 和（2）可扩展标记立法语言提取器（xmLegesExtractor）。分类器的输入是制定法条款中文本段落；输出是从一组候选类型和类别中选择的预测功能类型或条款类别（Francesconi 和 Passerini，2007）。提取器的输入是文本段落和预测类型。提取器输出文本片段，这些片段对应于与条款类型相关的特定语义角色（Francesconi，2009，p.66）。

① 可扩展标记立法语言分类器（xmLegesClassifier）是用于将立法文本段落自动分类为条款类型的工具。——译者

该项目将机器学习和知识工程以互补的方式应用于制定法条款。机器学习提取了更多抽象的功能类型，如“义务”。知识工程规则和自然语言处理提取了更具体的角色扮演者，如被赋予义务的“控制者”。

如第 8.3 节所述，为了可扩展标记立法语言分类器中的机器学习，文档被表示为带有一元模型的词袋，即不是短语。在预处理中，系统将词语缩减为形态词根，用特殊字符替换数字和非字母数字字符，并将文档表示为具有权重的术语向量。他们还采用了特征选择阈值来消除罕见术语（Francesconi, 2009, p.64）。

术语向量权重意图捕获术语传达的关于文档意义的信息量。研究人员尝试了四种类型的权重，包括表示文档中是否存在术语的二进制“权重”，表示文档中术语出现次数的术语频率权重，词频 / 反文档频率权重，其中权重与文档中术语的频率成比例，反过来与语料库中术语的频率相连（见第 6.4 节），并且权重将术语频率与信息增益结合在一起。与词频 / 反文档频率不同，信息增益衡量一个术语如何在不同类别中更好地区分文档（同上）。

研究人员将多类支持向量机（见第 8.5.2 节）应用于 582 条款的语料库中。本书前面遇到的支持向量机做出了二元决策，预测文档是否相关（见第 8.4.2 节），或者案例是否属于当前案件的先前历史（第 8.5.3 节）。可扩展标记立法语言分类器的决定不是二元的，而是多类的：11 种功能类型（包括废止，定义，委托等）中的哪一种适用于文本？

在多类支持向量机中，目标是引入超平面边界，将多个正示例中的每一个与其余示例分开。图 9.2 传达了关于多类支持向量机与二元支持向量机有何不同的直觉。在该图中，实线表示这些超平面，虚线表示具有一定置信余量的超平面，以优化适合。两条虚线之间的最小距离称为多类边距。暗点代表支持向量。黑点说明约束违规。带有额外边界线的点表示由于训练错误而导致的其他违规行为（Francesconi 和 Passerini, 2007, pp.11–12）。

研究者在留一法交叉验证实验中评估了他们的多类支持向量机。
如 4.4.3 节所述，交叉验证实验是评估机器学习算法的标准程序。当只有有限的数据量用于训练和测试时，它尤其有用。为了最大限度地利用有限数据，训练和评估被安排，同时确保机器学习算法永远不会在训练它的相同数据上进行测试。

在留一法交叉验证中，折叠数 k 等于 n，即语料库中的数据点数。对于 n 个不同的时间，对所有数据重新训练机器学习模型，除了被遗漏并用作测试集的点，并且对该点进行预测。

研究人员测量了留一法的准确率，作为整个测试数量的正确预测分数。他们的支持向量机使用最简单的二元方案对特征向量中的单词进行权衡，得到了 92.64% 的留一法准确率 ( Francesconi, 2009, p.65 )。事实证明，更复杂的权重并没有提高准确率。

在可扩展标记立法语言分类器预测条款的功能类型之后，它会将它们传递给可扩展标记立法语言提取器。如上所述，可扩展标记立法语言提取器工具使用知识工程文本分类规则和自然语言处理来提取与每种类型的规定相关的特定功能信息 ( Francesconi 和 Passerini，2007; Francesconi, 2009) 。

### 9.3.2. 提取功能信息的文本分类规则

给定立法原始文本段落的输入和分类器预测的功能类型，可扩展标记立法语言提取器输出文本片段，称为词汇单元，表示实体，并在给定条款的功能类型的情况下充当特定角色。图 9.1 说明了这样的预定义角色，包括收件人、行为和对手方，示例输入和此提取过程的输出，表示角色扮演者的词汇单元，“控制者”“通知”和“担保人”。

提取器过程包括两个步骤：句法预处理和词法单元识别。在语法预处理中，它采用文本段落并将文本流分解为单词、短语、符号或其他元素（标记）。它标准化或规范化表达日期、缩写和多字形式的方式，“词形还原”（lemmatizes）文本，使用意大利法律词典将相同单词的变体形式分组在一起，词性标记，并将文本的浅层解析分解为成分或“块”。在词汇单元识别中（lexical unit identification），它识别作为与特定条款类型相关的论证或元素的所有词汇单元。专家制定规则的语法针对每种特定条款类型定制，该语法使系统能够识别与该类型的规章特征相对应的块，例如图 9.1 中的那些特征（Francesconi, 2009, p.66）。

为了评估提取器工具，研究者组装了一个与四种条款功能类型相关的语义角色的黄金标准数据集：禁止、义务、许可和惩罚。在 209 条规定的评估中，基于规则的分类器实现了 83% 的平均精确率和 74% 的召回率，分别为四种类型：禁止（精确率 85.11%，召回率 92.30%），义务（精确率 69.23%，召回率 30.50%），许可（精确率 78.95%，召回率 100.00%）和惩罚（精确率 85.83%，召回率 89.34%）。（同上）

### 9.4. 用于制定法信息提取的机器学习与知识工程

上一节的可扩展标记立法语言（xmlLeges）项目从法规和其他法律文本中说明了自动化 IE 中的主题：在机器学习与知识工程方法之间进行选择，或者，将它们集成在一起。

知识工程方法涉及为每种类型的条款确定清晰的易于观察的模式，并手动构建规则以识别新文本中的模式并提取相关信息。

机器学习方法涉及手动注解训练实例，并自动使用机器学习算法来生成区别于实例训练集的特征。

每种方法都有优点和缺点（de Maat 等，2010）。知识工程方法不要求手动注解的训练数据，但它确实需要手动创建的专家分类规则来捕获与每类条款相关联的标准短语。机器学习方法更灵活，更少领域依赖，并且不需要太多的专业知识。另一方面，如上所述，某些统计机器学习算法（如支持向量机）实际上是黑盒子。将事物归类为正面或负面事例的理由可能并不容易。此外，机器学习需要足够大的手动注解的训练实例集。

一个研究小组已经尝试了两种方法来完成同一项任务，在最近的两项荷兰立法中确定了条款的功能类型（de Maat 等，2010）。13 类功能类型包括定义、许可、义务、授权和各种类型的修改条款，如变更范围、变更废除、变更重新编号等。

知识工程分类已在早期工作中进行。研究人员已经确定了一组 88 种单词模式，这些模式是研究 20 部荷兰法律后手工提取的，这些模式与不同功能的条款类型相关联。模式包括动词或动词短语（荷兰语），如“可以”表示权利或许可，“x 被理解为 y”表示定义，“见”表示引用条款，“可以创建规则”表示授权（de Maat 和 Winkels，2009，pp.32-33）。模式以用于与新句子进行模式匹配的格式存储。由于条款包括多个句子，因此分类器在第一个句子（或列表项）中寻求明确的模式。如果找到一个，则整个规定都进行了相应的分类。如果没有，它继续独立地对后续句子进行分类。如果没有句子包含明确的模式，则整个列表被归类为默认，即事实陈述（de Maat 和 Winkels，2009，p.33）。
