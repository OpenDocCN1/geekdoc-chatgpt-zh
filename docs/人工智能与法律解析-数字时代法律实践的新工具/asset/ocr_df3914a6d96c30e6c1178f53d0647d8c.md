# 8.5.2. 机器学习算法：支持向量机

支持向量机使用统计标准来区分类别或种类的正面和负面示例。如在预测编码的讨论中所述（第 8.4.2 节），统计机器学习算法可以比决策树程序更有效地执行，但是，与人类可以直观地解释的决策树分类器不同，支持向量机模型不易理解。

支持向量机识别距离所有示例最远的类别或种类的正面示例和负面示例之间在向量空间的边界（Noble, 2006）。理想情况下，所有作为正面示例的候选案例都位于边界的一侧，所有负面示例都位于边界的另一侧。

边界是几何实体，其性质取决于向量空间的维度。如果向量空间是一条线，那么这样的边界就是一个点；如果空间是一个平面，它就是一条线。在三维向量空间中，边界将是平面，并且在更高维空间（包括历史项目中的八维空间）中，边界被称为“超平面”（hyperplane）。基于支持向量机学习的超平面，预测先前未见案例的标签只是确定新案件的向量落在边界的哪一侧（见 Noble, 2006, p.1565）。

图 8.2 (1) 显示了分隔正面和负面示例的超平面，这个超平面可用来划分未知实例（白点）。（2）说明了许多可以分隔正面和负面示例的替代超平面，但是支持向量机算法选择了（3）所示的超平面，它使边界和所有示例之间的距离最大化（Noble, 2006, p.1566）。
