# 6.6. 法律论辩的本体支持

第 5.7 节描述的论证型式驱动的（ argument-scheme-driven ）推理类型涉及用类比论证来解释法律规则概念并考虑潜在价值观，对这种类型的推理而言，什么类型的法律本体可以支持知识获取？据我所知，没有现成的本体可用于此目标。
