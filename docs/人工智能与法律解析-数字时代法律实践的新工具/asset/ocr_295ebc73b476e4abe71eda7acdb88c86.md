# 表示案例和法律因素

微观世界中的案例用案例框架来表示。如图 6.5 所示，每一个案
例框架都包含用于名称、索赔（例如，侵占、民事错误或侵权，即一
个人将他人的财产当作自己的财产进行占有或处分）、结果（对于原
告或被告），以及适用因素列表的槽。

案例框架还指定了一些特征，根据猎物的财产利益领域的法律因
素，这些特征的值对案例比较非常重要。这些比较特征包括从狩猎 /
捕捉场地通过干扰引起的案例框架中带星号的插槽。

事实情况或许会有影响，例如，狩猎发生在什么类型的场所，例
如露天场地、海洋或棒球场，什么类型的限制适用于那种场地（私人
拥有的还是开放的），或寻求的猎物是什么类型的：害虫、食用野味
或商业捕获。同样，原告为确保猎物采取的步骤，这些步骤公开表现
的程度，以及被告干扰的意图等，都很重要。
