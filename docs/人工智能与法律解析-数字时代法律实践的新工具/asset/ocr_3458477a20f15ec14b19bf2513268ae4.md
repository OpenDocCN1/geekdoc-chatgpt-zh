上文档被认为是相关的，在该分数之下文档被认为是不相关的。通常，截止值越高，精确率越高召回率越低。相反，截止值越低，精确率越低召回率越高（Grossman 和 Cormack, 2014）。

AUC 表示分类器将随机选择的正数据点排名高于随机选择的负数数据点的概率。在制定法分析工具的背景下，随机选择的正面和负面数据点分别对应于相关和不相关条款。因此，AUC 是随机选择的相关文档比随机选择的非相关文档被分配更高优先级的概率。AUC 得分 100% 是完美的；所有相关文档的排名均高于所有不相关文档。AUC 得分为 50% 表明相关文档的排名高于非相关文档的可能性并不高（Grossman 和 Cormack, 2014；Savelka 等，2015）。

这两个基线包括人类分类器的精确聚焦基线以及召回聚焦基线，前者假设所有尚未处理的文档都不相关，后者假设所有尚未处理的文档都是相关的。

交互式机器学习方法在两个实验中都超过了基线，实现了良好的（如果不是优秀的）分类性能。在冷启动实验中，在标记约 25 份文档后，分类器的 AUC 分数高于 80%（Savelka 等，2015）。此外，第二个实验证明了有趣的转移效果。基于一个州的文档重新使用分类模型，使该工具在对新州的类似制定法分析的条款进行分类时具有客观可衡量的优势。换句话说，从解析一个州的法规中学到的知识有助于解析另一个州（同上）。
