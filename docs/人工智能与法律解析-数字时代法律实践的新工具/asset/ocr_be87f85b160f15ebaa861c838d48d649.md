卡巴莱系统通过议程机制集成了两种计算模型：一种算法可以对分析的当前状态进行推理，并适当地召集基于规则的推理（rule-based reasoning，简称为 RBR）模型或基于案例的推理（case-based reasoning，简称为 CBR）模型。议程机制采用一套启发法规则对当前的分析状态进行推理。控制启发法的示例包括：

+   一尝试其他：如果基于案例的推理失败，则转换到基于规则的推理（反之亦然）。

+   一健全性检查：用基于案例的推理检测基于规则的推理的结论（反之亦然）。

+   一基于规则的推理未命中：如果一条规则的所有前件都已建立但只有一个，则使用基于案例的推理扩大规则对错失前件的应用。例如，使用基于案例的推理来表明有些情况下结论是正确的，但因为错失前件规则没有触发。

+   一匹配制定法概念：查找在相同制定法概念上失败或成功的案例。
