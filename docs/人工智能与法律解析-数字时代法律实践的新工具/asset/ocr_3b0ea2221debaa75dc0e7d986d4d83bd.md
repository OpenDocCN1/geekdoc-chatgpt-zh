研究者在留一法交叉验证实验中评估了他们的多类支持向量机。
如 4.4.3 节所述，交叉验证实验是评估机器学习算法的标准程序。当
只有有限的数据量用于训练和测试时，它尤其有用。为了最大限度地
利用有限数据，训练和评估被安排，同时确保机器学习算法永远不会
在训练它的相同数据上进行测试。

在留一法交叉验证中，折叠数 k 等于 n，即语料库中的数据点数。
对于 n 个不同的时间，对所有数据重新训练机器学习模型，除了被遗
漏并用作测试集的点，并且对该点进行预测。

研究人员测量了留一法的准确率，作为整个测试数量的正确预测
分数。他们的支持向量机使用最简单的二元方案对特征向量中的单词
进行权衡，得到了 92.64% 的留一法准确率 ( Francesconi, 2009, p.65 )。
事实证明，更复杂的权重并没有提高准确率。
