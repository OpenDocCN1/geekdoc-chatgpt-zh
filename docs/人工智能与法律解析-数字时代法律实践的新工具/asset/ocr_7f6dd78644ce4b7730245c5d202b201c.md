在不同程度上是有效的。

# 7.5. 信息检索的相关性度量

如上所述，信息检索系统使用布尔、向量空间和概率模型来评估文档与查询的相关性。其中，布尔相关性度量是最简单的。

# 7.5.1. 布尔相关性度量

在布尔相关性度量中，查询为要检索的文档提供一组逻辑标准。该标准指定了要回应的文档的指示术语的存在和接近程度。相关性度量根据查询的布尔标准完全满足的方式来对案例进行排序（Turtle，1995，p.24）。

将上述深海探测示例表示为布尔查询并不容易，但可以尝试以下方法：

+   （行为w / 5侵占）和[（捕获！ w / 5猎物）或(捕获！ w / 5猎物）]
+   和 [（被告 w / 5干扰！）或（被告 w / 5拦截！）]

在上述查询中，感叹号（!）表示系统应包括以指示的词根开头的所有单词，例如 “capture” “captures” “captured” “capturing” 等。也许预计发现涉及废弃探测器的案件的可能性很低，用户也用更广泛的术语 “猎物” 取而代之，希望能够返回到涉及捕获其他物品的案件。

# 7.5.2. 向量空间的相关性方法

在向量空间的相关性方法中，文档和查询可以用 “词袋” 表示，并作为 “术语向量” 进行比较（Turtle，1995，第 26 页）。一个文档表示的词袋（bag of words，简称为 BOW）包括没有特定顺序的术语集合。回到深海探测示例，查询可以表示为词袋：

+   海 抓获 行为 侵占 深 计算机 近乎 黑客 分钟 机器人 原告 废弃 被告 探测器 拦截 最后
