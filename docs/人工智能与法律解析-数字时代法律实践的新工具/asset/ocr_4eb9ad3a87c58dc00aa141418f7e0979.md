文档向量将包括表示结果的特征——分类或预测。由于学习模型经常只能处理数字特征，因此需要在数字上对上述分类等类别结果特征进行编码，例如在多个特征中使用二进制编码。

在上面的示例语境中，感兴趣的文本单元各不相同。在电子发现语境中，感兴趣的单元可以是在发现中产生的整个文档，或者至少是文档的主体。在句子分类研究中，主要的兴趣单元是案例意见中的每个句子。在制定法主题语境中，主要单元是制定法的条款。每个层面的粒度、文档、句子或规定都可以表示为特征向量。如果文档的各部分与整体的连接很重要，例如每个句子与其出现的特定案例意见相连，则可以记录适当的链接。

文档集可以用频率矩阵或文档—词项矩阵（ document-term matrix ）表示以便进行处理。这就像一个由行列形式的文档以及按语词或其他特征（如二元模型或 n 元模型）组织的电子表格，每个这样的特征出现在语料库中的一列。

文本数据表示为特征向量，人们可以将数据划分为训练集和测试集。为了避免偏差，可以随机地对向量进行采样并以一定的概率将它们分配给测试集。剩下的向量成为训练集。然后，机器学习算法可以训练一个关于训练集的模型，并应用该模型来做出关于测试集中的特征向量的预测或分类。

在评估模型的性能时，特别是在数据集较小的情况下，可以采用第 4.4.3 节中描述的交叉验证程序。数据集中的每个特征向量将作为测试实例使用一次，但它也可用于训练要应用于其他测试实例的模型。

可以根据度量来定量评估模型的性能，例如准确率，即测试集中正确分类的向量与测试集中所有向量的比率（第 4.4.4 节）。
