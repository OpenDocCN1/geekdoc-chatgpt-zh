根据他们在法律论证中的角色对案件中的句子进行注解可以改善信息检索。通常，冗长意见中相对较少的句子捕获了重要的推理。其中一些句子陈述法律规则，其他句子报告案件中的证据，还有一些句子宣称基于证据的法律发现满足了法律规则的要求。

根据系统用户对其所寻求信息的目标，句子角色可能会使这些句子中的某些句子比其他句子更具相关性。例如，在疫苗损伤背景下考虑一种有用的查询（第 5.8 节）。让我们假设律师需要一个案件，在此案中法院认为水痘疫苗可引起脑脊髓炎。也许，律师有一个新客户提出这样的事实，律师希望评估复苏的机会效率。一个合适的查询可能是“如下发现或结论：水痘疫苗可引起脑脊髓炎”。

# 表 6.7. 分级的卢依马类型系统：句子层级类型

| 卢依马句子层级类型 | 定义 | 示例 |
| :--- | :--- | :--- |
| 引用 | 句子包括对法律权威的引用。 | 见，42 U.S.C. §300aa-12(d)(4)(B)；疫苗规则 18 (b)。 |
| 法律规则 | 句子抽象地陈述了一条法律规则，没有适用它于特定事实。 | “根据那个标准，请求人必须证明疫苗接种‘更有可能’是造成伤害的原因。” |
| 法律裁定或法律裁判 | 句子陈述了法官的一个法律裁定或法律裁判。 | “由于以下原因，我得出结论，她有权获得这样的奖励，金额尚未确定。” |
| 基于证据的事实发现 | 句子报告事实发现者关于特定案件中有无证据证明一条规则的条件已经得到满足的发现。 | “由于种种原因，我发观莱西博士的观点比卡塞塔博士的观点更有说服力。” |
| 基于证据的中间推理 | 句子涉及关于特定案例中的证据是否证明一条规则的条件已经得到满足的推理。 | “在这方面，我注意到我已经仔细考虑了卡塞塔博士的书面报告。” |
| 证据 | 句子总结了案件中的一项证据。 | “在本案的证词中，拉齐博士进一步解释了他的想法，即破伤风疫苗接种可能导致请求人罗珀女士的胃轻瘫。” |
| 法律政策 | 句子抽象地陈述了一条法律政策，没有将它适用于特定事实。 | “作为一个基本公平的问题，波波夫先生应该有机会试图完成他的抓获，不受非法活动的影响。” |
