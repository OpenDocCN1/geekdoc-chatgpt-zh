# 第十章 从法律案例文本中提取与论证相关的信息

# 10.1. 导言

第八章解释了机器学习如何应用于法律文本，第九章探讨了从制定法和规章文本中提取信息的方法。本章继续讨论这些问题，但重点是使用机器学习、自然语言处理和手动构建的规则从法律判决的文本中提取信息，尤其关注与论证相关的信息。

如果信息涉及案件中提出的论点中的句子和其他信息的作用，那法律案件中的这些信息就与论证有关。这包括句子的作用，例如，摘要中的法律规则陈述或适用于特定事实的陈述，或者作为案件裁决和事实的发现。它还包括更多的一般性作用，例如论证中的命题，前提或结论，以及证明给定前提的结论的合理性的论证型式（第 5.2 节），例如将当前事实类比为先前案例或区分它们的型式。最后，它包含影响论证强度的信息，如法律因素，强化主张的定型的事实模式（第 3.3.2 节）或证据因素（第 5.8 节）。
