图 11.10 左列显示的是一些有用的一般性制定法类型。顶部是制定法文本中常见的结构元素的不完整列表，例如标题、节、段落、以印刷方式分隔但未编号文本块、各种类型的节和各种交叉引用。

图 11.10 列出了“陈述”的类型，这是制定法条款的基本组成部分，它包括定义和规则陈述。陈述可以是整个句子，也可以是句子的一部分。还有一些规则陈述类型，例如，强加义务和授予权限的规则陈述等。规则陈述的三个常见部分也被列出了：前件“如果”部分，后件“那么”部分，以及例外。

+   结构要素
+   - 编号要素：标题，章节，小节，段落
+   - 未编号要素
+   - 章节类型序言，定义，附录
+   - 规章交叉义参考：内部参考，外部参考

+   陈述
+   - 定义陈述
+   - 规则陈述
+     - 义务陈述
+     - 许可陈述
+     - 禁止陈述
+     - 责任陈述
+     - 目标陈述

+   一般规则陈述组成部分
+   - 前件
+   - 后果
+   - 例外

+   一般法规陈述变量
+   - 代理人：谁声明直接代理的，接收代理人
+   - 接收代理人：谁声明直接接收代理？
+   - 行动：该声明指示的是什么行动？
+   - 命令：声明指示采取何种程度的命令：“可能”？“必须”？
+   - 目标：声明指示行动的目标是什么？
+   - 目的：声明指示行动的目的是什么？
+   - 时间范围：在什么时间范围内可以/必须采取行动？
+   - 条件：如果采取行动，处于什么情况？

+   规章领域的概念及关系
+   - 规章主题（例如，环境，刑法，知识产权，公共卫生紧急事件的应对）
+   - 机构
+     - 公共卫生系统的管理人
+       - 政府公共卫生机构
+       - 医院
+       - 健康护理提供者
+       - 商业雇主
+       - 民选官员

+   行动
+   - 公共卫生系统的行动
+     - 报告行动
+     - 监督行动
+     - 检疫行动

+   概念
+   - 传染病
+   - 公共卫生紧急事件：流行病，火车残骸，核事故
+   - 时间：间隔，日期

+   提及
+   - 机构提及
+     - 政府公共卫生机构提及
+     - 医院提及
+   - 行为提及
+     - 报告提及
+   - 时间提及：间隔提及，日期提及
