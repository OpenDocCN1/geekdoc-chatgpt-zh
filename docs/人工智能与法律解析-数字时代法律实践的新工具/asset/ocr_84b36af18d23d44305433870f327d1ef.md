# 2.5.4. 连接法律规则和业务流程

过程合规语言旨在满足所有上述要求（Hashmi 等，2014）。它可以将法律规则表示为可辩驳的规则，并避免使用相互矛盾的规则进行推理的问题。它还可以用上述语义定义义务并进行时间推理。

然而，复杂的业务流程可能包含许多可移动部件，并且在流程运行时需要评估合规性。模型如何表示一个没有过度简化的过程，以便可以实际应用业务规则？

为此，模型必须考虑业务流程产生的工作以及它在其环境中所做的更改（Hashmi 等，2014, p.104）。作者将业务流程建模为工作流网络，一种佩特里网（Petri net）。佩特里网（由德国数学家和计算机科学家 C.A. 佩特里于 1962 年引入）用于抽象地表示过程。佩特里网与第 1.4.2 节中的扩充转移网络不同，后者是另一种类型的过程表示。在那里，建模的过程是一个法律过程，即合同法中的要约与接受过程。加德纳扩充转移网络中的节点表示法律分析中的状态；弧线表示从一个状态到另一个状态的可能转换，这种转换由与每条弧线相关联的法律规则控制。

然而，佩特里网与扩充转移网络不同，因为它们使用两种类型的节点、位置和转换，并且用弧线将一种类型的节点连接到另一种节点。此外，“记号”的生成和使用用于表示过程中发生的事件以及事件导致的系统状态的变化。在佩特里网中，每个事件都被建模为消耗和产生记号的转移，并且“系统的状态在任何时刻都通过网络位置中记号的分布来建模”（Palanque and Bastide, 1995, p.388）。

场所和转移通过定向弧线连接，定向弧线定义每次转移被允许发生的时间以及它的发生将产生什么效果。当每个输入位置保存至少一个记号时，允许发生转移；转移的发生在每次输入位置消耗一个记号，并在每个输出位置设置一个记号。（Palanque 和 Bastide, 1995, p.388）
