经典逻辑是初学逻辑学生已知的作为“谓词逻辑”的形式逻辑，其中，（1）形式语言的所有句子恰好具有两个可能的真值之一（真，假），（2）推论规则允许人们从一组不一致的假设中推导出任何句子，（3）所有谓词都完全定义在变量的范围内，以及（4）形式语义是由塔斯基发明的，他用元语言为形式语言提供了第一个精确真之定义。（Dowden，2016）

经典逻辑使用符号表示谓词、主词和量词。在命题逻辑中，“所有人都是凡人”的命题只用一个符号表示，没有内部结构。相反，在经典逻辑中，可以定义谓词M(x)来表示x是凡人或使用全称量词（“For all”）：所有 x. M(x) 表示所有 x 都是凡人。

作为逻辑编程基础的霍恩子句逻辑实现了大多数（但不是全部）谓词逻辑，并允许人们表达制定法条款的规范化版本的实质命题内容及其逻辑句法。例如，赫伯特·哈特著名的样本制定法条款“禁止车辆驶入公园”，①可以用逻辑编程（即霍恩子句谓词逻辑）表示为：

```
违规（X，S）：- 车辆（X），公园（S），在（X，S）。
```

也就是说，“如果 X 是车辆并且 S 是公园，并且车辆在公园中 -> 车辆在公园中是违规的。”在逻辑编程中，谓词之间的逗号表示“和”；表明使用的是全称量词

如果输入逻辑编程程序信息，例如：

```
车辆（X）：- 摩托车（X）
车辆（X）：- 汽车（X）
```

该程序可以证明，通过将一条规则的结论链接到其他规则的前提下，人们或许不会将摩托车、汽车或者实际上我们输入的任何其他作为车辆的东西驶入公园。
