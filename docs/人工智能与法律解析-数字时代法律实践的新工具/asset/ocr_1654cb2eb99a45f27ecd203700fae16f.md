# 6.6.1. 法律论证本体的目标应用程序

首先，让我们考虑目标教育应用程序。假设，人们想要一个系统来生成对话，法学教授和学生可以参与的关于法律概念的对话。表 6.2 说明了人工智能与法律中当前论证模型范围内的法律课堂的苏格拉底式对话（见 Ashley，2009a，2011）。

它是人们可能希望在一年级的“财产法”课程中遇到的那种对话的简化版本，课程转向了野生动物的财产权主题和皮尔逊诉波斯特案（Pierson v. Post，3 Caines R.N.Y. 1805），这个案例在关于财产法的法律案例书中都有讨论（见，例如，Dukeminier 等，2010）。这个主题涉及一个普通法问题（即法官造法，而非制定法）：“猎人”在什么情况下可以在其围猎场拥有财产权？如第 3.4 节所述，该主题一直是人工智能与法律讨论的焦点（见，例如，Berman 和 Hafner，1993；Atkinson 和 Bench-Capon，2007；Gordon 和 Walton，2009）。

教育软件开发者可能会设计一个程序来生成表 6.2 中的对话作为智能辅导系统的一部分。在线财产法课程或慕课（MOOC）或许包含这种游戏化版本的苏格拉底教学法法律对话，学生和教师在这些对话中做出并回应论证。让学生参与选择论证动议既可以教他们实体法，也可以教他们第一年法律论辩技巧，这是学生阅读和理解一本法律案例书需要掌握的技巧。（见，例如，Ashley，2000；Aleven，2003）
