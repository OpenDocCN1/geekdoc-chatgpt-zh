另一方面，S2 和 S3 对 Q2 有反应，因为它们都指的是“乙型肝炎疫苗”、“导致”和“多发性硬化症”。它们都报告了特别法官关于法律规则适用于包含乙型肝炎导致多发性硬化症的事实的裁决或结论。

目前，卢依马系统能够区分呈现规则的句子和陈述事实发现的句子，也就是说，它能够区分 S1 和 S2 或 S3。本章解释了研究人员如何将第 10.5.3 节中描述的卢依马注解方法与信息检索系统相结合，并使用这种与论证相关的从法律信息检索系统检索到的文本中提取的信息以提高检索质量的方式重新排列案例。

本章还探讨了如何扩展卢依马类型系统，以实现当前法律信息系统无法实现的一系列概念查询。本章讨论了根据扩展的类型系统注解文档的技术和一些挑战。本章最后讨论了基于网络的替代技术以实现概念法律信息检索的承诺。

本章回答的问题包括：论证检索是什么？以及它如何改进法律信息检索？为什么要集成文本注解管道和信息检索系统，以及如何集成它们？机器学习在概念法律信息检索原型中扮演什么角色？我们距离实现强大的概念法律信息检索有多远？

# 11.2. 概念法律信息检索的现状

律商联讯和万律进阶等主流法律信息检索系统已经实现了概念法律信息检索（见 7.7 节）。律商联讯基于案例法数据库中挖掘的“法律问题”网络，为案例提供概念性主题。每个问题对应一个可以引用案例的命题。万律进阶复杂的重新排名功能考虑了基于专家生成的注解和引文网络的概念信息。

两个法律信息检索提供者都报告使用机器学习来改进相关性评估，包括自动提取的案例处理历史（第 8.5.3 节），学习与法律主题相关的特征权重用于重新排序（第 7.7 节），从法律讨论中区分事实段落（第 8.6 节）。
