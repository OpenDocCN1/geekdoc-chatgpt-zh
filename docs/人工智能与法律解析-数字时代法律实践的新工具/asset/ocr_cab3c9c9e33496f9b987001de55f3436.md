# 第八章 基于法律文本的机器学习

# 8.1. 导言

在迄今为止的机器学习（Machine Learning，简称为 ML）示例中，一个程序从最高法院数据库中关于法官、趋势或案件数数据中学到了知识，但没有从案件文本或其他法律文档中学到知识。本章介绍了机器学习算法在法律文本语料库中的应用，讨论了机器学习模型如何隐含地表示用户关于相关性的假设，说明了机器学习如何改进全文法律信息检索，并解释了机器学习在概念信息检索和认知计算中的作用。本章还区分了来自文本的有监督的机器学习和无监督的机器学习，并讨论了从法律文档中自动学习结构和语义的技术。

在此过程中，本章回答了以下问题：如何将机器学习应用于文本数据？来自文本的有监督的机器学习和无监督的机器学习有什么区别？预测编码是什么？预测编码的效果如何？来自文本的“信息提取”是什么？为了机器学习的应用如何表示文本？“支持向量机”（support vector machine，简称为 SVM）是什么？以及为什么将“支持向量机”用于文本数据？
