# 9.3.2. 提取功能信息的文本分类规则

给定立法原始文本段落的输入和分类器预测的功能类型，可扩展标记立法语言提取器输出文本片段，称为词汇单元，表示实体，并在给定条款的功能类型的情况下充当特定角色。图 9.1 说明了这样的预定义角色，包括收件人、行为和对手方，示例输入和此提取过程的输出，表示角色扮演者的词汇单元，“控制者”“通知”和“担保人”。

提取器过程包括两个步骤：句法预处理和词法单元识别。在语法预处理中，它采用文本段落并将文本流分解为单词、短语、符号或其他元素（标记）。它标准化或规范化表达日期、缩写和多字形式的方式，“词形还原”（lemmatizes）文本，使用意大利法律词典将相同单词的变体形式分组在一起，词性标记，并将文本的浅层解析分解为成分或“块”。在词汇单元识别中（lexical unit identification），它识别作为与特定条款类型相关的论证或元素的所有词汇单元。专家制定规则的语法针对每种特定条款类型定制，该语法使系统能够识别与该类型的规章特征相对应的块，例如图 9.1 中的那些特征（Francesconi, 2009, p.66）。

为了评估提取器工具，研究者组装了一个与四种条款功能类型相关的语义角色的黄金标准数据集：禁止、义务、许可和惩罚。在 209 条规定的评估中，基于规则的分类器实现了 83% 的平均精确率和 74% 的召回率，分别为四种类型：禁止（精确率 85.11%，召回率 92.30%），义务（精确率 69.23%，召回率 30.50%），许可（精确率 78.95%，召回率 100.00%）和惩罚（精确率 85.83%，召回率 89.34%）。（同上）
