# 第四章 预测法律结果的模型

# 4.1. 导言

计算机程序可以使用表示为特征和结果集的案例数据库预测新问题的结果。它们通常通过基于案例的推理模型或机器学习算法来实现，有时将两者结合起来。本章将解释和说明两者。

预测技术利用了先前案例中所表示的不同类型的特征，从主审法官的名字和代理不同类型案件的律师事务所，到法官的态度信息、判决的历史趋势以及强化一个主张或辩护的陈规定型的事实模式，即法律因素。这些特征在捕获有关案件特点的信息的程度上有所不同。法官的姓名、律师事务所的名称和案件类型——例如专利诉讼或产品责任——抓不住特定法律纠纷特点的信息。相比之下，正如我们在第三章中看到的那样，法律因素捕获了很多关于特点的信息。这些特征根据它们从案例文本中自动提取的难易程度而有所不同。法官和律师事务所名称很容易提取；法律因素也可以被提取，但提取起来相当困难。

本书聚焦于倾向于捕获有关案例特点的一些信息的特征，聚焦于可以从案例文本中自动提取的特征。本章探讨了使用此类特征预测案例结果的替代方法。

机器学习技术在统计上使用特征频率信息来“学习”案例特征与目标结果之间的对应关系。基于案例的技术更侧重于案例比较和解释
