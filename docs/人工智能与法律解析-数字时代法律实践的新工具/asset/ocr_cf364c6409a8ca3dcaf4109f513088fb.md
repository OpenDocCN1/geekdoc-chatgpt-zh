标准化折现累积增益（NDCG$_i$）是每一次查询的标准化折现累积增益（Burges 等，2005；Grabmair 等，2015）。

顺便提一下，由于真正的排名是通过重新排列商业法律信息检索系统检索到的案例创建的，因此每个基准结果的召回率（即，响应查询的所有相关文档的覆盖范围）为 1。此外，由于卢依马搜索将所有无响应文档附加到检索到的案例的末尾，实验系统无法根据召回率比较基准线。

# 11.4.2. 卢依马与商业法律信息检索

在一系列实验中，对于表 11.1 中的每个查询，研究人员使用上述度量标准评价卢依马和基准线的四种配置，并根据法律专家的真正排名比较每个检索到的案例的排名：

+   1. 基准线：商业法律信息检索系统对表 11.1 中查询的排名。

+   2. 卢依马搜索：搜索整个卢依马查询，根据每个查询中检索到的句子数量对文档进行排名。

+   3. 卢依马搜索 + 重排：搜索整个卢依马查询，根据每个查询中检索到的句子数量对文档进行排名，再用权重重排特征对文档进行重新排名。

+   4. 卢依马搜索，没有句子类型：搜索卢依马查询但没有句子类型，根据每个查询中检索到的句子数量对文档进行排名。

+   5. 卢依马搜索 + 重排，没有句子类型：搜索卢依马查询但没有句子类型，根据每个查询中检索到的句子数量对文档进行排名，再用权重重排特征对文档进行重新排名（Grabmair 等，2015）。

研究者比较了项目（1）和（3），以评估卢依马重排的排名增加值是否超过基准线商业法律信息检索系统的排名。比较项目（2）和（3）将显示卢依马重新排名与其搜索相比的影响。如第 10.5.3 节所述，卢依马注解模块为不属于黄金标准但未达到预期效果的文档注解了句子级别。研究者审查了系统如何在没有该模块的句子级别注解的情况下执行，以评估对搜索或重新组件性能的任何可能的负面影响。
