# 图 11.6. 查询法律因素和论证角色

（来自商业秘密领域）

粗体字的术语表示现有的句子层级论证角色类型。斜体术语表示法律规则要求。有下划线的斜体术语表示法律政策或价值。

普通的法律信息检索系统可以基于图中的查询单词检索材料，但是它们并不理解与论证相关的概念和约束。专门基于文本的搜索引擎将这些简单地视为附加的普通关键词，而不是视为指定与论证相关的信息的法律概念，这些信息关乎所寻求的案例文档中类似句子的目标角色。它可以使用关键字查询扩展或法律同义词库，但即使这样，概念标签的关键词字符仍然存在。即使法律信息检索系统可以检索与自然语言查询相关的案例，它也不能使用与论证相关的信息来按照用户试图解决的问题的方式对案例进行排序或汇总。如果它能够理解和控制这些约束，用户将享受到前所未有的表达和发现他们真正想要的东西的能力。
