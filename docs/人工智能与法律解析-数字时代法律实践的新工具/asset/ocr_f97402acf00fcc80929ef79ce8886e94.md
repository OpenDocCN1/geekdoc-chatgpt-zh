对列维说明中产品责任法的历史的更细致研究识别了一些特征或因素，法院在基于推理和论证的例子中应用这些特征或因素。法院根据如下因素对案件进行了比较：

+   —制造商是否了解隐含的缺陷。
+   —发现缺陷有多么困难。
+   —制造商是否以欺诈手段隐藏了缺陷。
+   —受害者使用该物品的可能性。
+   —谁操控该物品。
+   —该物品有多么危险。
+   —危险是否是因为一些额外的行为。
+   —由缺陷引起的伤害的性质。
+   —关于信赖制造商（例如，药剂师、汽车制造商）的社会期望。

在产品责任的背景下，这些是明智的标准，根据它们比较案例和评估基于规则或法律概念的解释的拟议结果的公正性（Ashley 和 Rissland，2003）。社会需要和技术供给的变化会影响哪些标准被认为是重要的。根据这些标准的重要性进行的不同组合会导致不同的案例排序。法律推理过程（以及它所属的法律论坛）通过使用规则、概念和案例来支持这种活力（Levi，2013）。
