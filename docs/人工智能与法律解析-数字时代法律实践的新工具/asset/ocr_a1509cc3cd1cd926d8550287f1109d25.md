# 2.3.1. 在计算机上运行规范化版本

其次，命题逻辑中的制定法条款可以在计算机上运行。在图 2.1 的底部是用逻辑编程表达的路易斯安那州法规的两个标准化版本，这是一种基于与人工智能和计算语言学相关的所谓“霍恩子句逻辑”的编程语言。44

![](bbox=[0.23, 0.27, 0.75, 0.37])

图 2.3. 命题化《国内税收法》第 354 节的流程图 (见 Allen 和 Engholm，1978)

该法规的标准化版本是简单命题逻辑的示例。右边的版本，S4： - S1，S2，S3，意思是 “如果 S1 ∧ S2 ∧ S3⇒S4”，其中 ∧表示 “和”。左边的版本使用两个公式，S4： - S1，S2 和 S4： - S1，S3，用于实现版本中的析取（即“或”）。

逻辑编程解释了霍恩子句，将它们视为一个程序。例如，它将右侧的霍恩子句实际上读作 “显示 S4，显示 S1，显示 S2，并显示 S3” 。

通过询问用户每个实质命题 S1，S2 和 S3 是真还是假，计算机可以证明 S4 的真假。通过这种方式，法规逻辑用这种方式自动化。这些法规规范化版本的逻辑很简单，可以手动处理真值表。然而，计算机也可以处理更复杂法规的命题逻辑（如图 2.2 所示）。

人们还想表达制定法条款的实质性命题的内容，而不仅仅是其整体逻辑句法。这可以用经典逻辑（也称为谓词逻辑，谓词演算或一阶逻辑）来完成。
