这些论证模式可以用图 11.7 中所示的三种附加句子类型表示。

+   - 法律规则要求：在将要求适用于诉讼的特定案件的事实的背景下陈述法律规则的要求或要素的句子。
+   - 法律因素要求：法官当作理由陈述的句子，或者尽管如此，她 / 他得出一个法律结论，一条法律规则或要求确实「不」适用于事实情境，并且指一种倾向于加强或削弱法律结论的陈规定型事实模式，因为它对法律政策或价值有影响。
+   - 可适用的法律价值：涉及关于法律政策或价值适用于特定事实的推理的句子。

这些类型意在注解案件的一部分，其中法院讨论法律因素以及（可选）因素背后的价值如何影响其判决的结果，不管在给定案件中法律规则的要求是否得到满足。在法律意见文本中这些要点识别了一些特征，论证的计算模型（例如基于价值判断的论证预测和缺省逻辑框架模型）可以用这些特征进行推理。

尽管我们主要在商业秘密滥用和疫苗伤害案件中遇到过这些句子类型，但它们出现在涉及多种法律诉讼的判决中。原则上，所有三种类型都足以应用于任何法律领域，其中相应的证据或基于因素论证的计算模型是合适的。
