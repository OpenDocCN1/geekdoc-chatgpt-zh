# 1.3.2. 取而代之的典范：论证检索与认知计算

论证检索和认知计算不像专家系统，这两种取而代之的智能技术典范并不旨在单独地解决用户的法律问题。相反，计算机程序从法律文本中提取语义信息，并用它帮助人类解决他们的法律问题。

当然，概念信息检索并不是新鲜事物。人工智能长期以来寻求从文本中识别和提取语义要素，例如概念及其关系。正如索瓦（Sowa）所定义的，“概念表示任何可用语言描述的实体、行动或状态，并且概念关系代表每个实体所扮演的角色”（Sowa, 1984, p.8）。类似地，人工智能通过使用提取的语义信息来绘制关于检索到的文本的推断，长期以来它的目标是使信息检索更加智能化。罗杰·尚克（Roger Schank）在 1981 年使用“概念信息检索”这一术语来描述：

> 处理相对不受限制的领域的组织和事实检索的系统（例如，……科学摘要）。首先，系统应该能够自动地理解自然语言文本，既输入数据库又输入系统查询……以这样的方式，一个条款的概念内容或意义可以用于检索而不是简单的关键词……如果范畴由概念划定，并且自然语言分析器将文本解析为概念表示，那么可以根据新条款的概念表示（或意义）进行推断，以确定它们属于哪个范畴。（Schank 等，1981, pp.98,102）

概念法律信息检索也不是新的。哈夫纳（Hafner, 1978）和宾（Bing, 1987）在法律领域实现概念检索的开创性努力。

如第 7.7 节和第 11.2 节所述，现代法律信息检索服务考虑了大量的法律概念和用户打算定位的主题。最近的其他工作集中在扩展概念信息检索系统，使得它们不仅返回在概念上与查询相关的法律信息，而且返回与问题相关的法律信息，这个问题是用户打算应用目标信息的问题（见 Winkels 等，2000）。
