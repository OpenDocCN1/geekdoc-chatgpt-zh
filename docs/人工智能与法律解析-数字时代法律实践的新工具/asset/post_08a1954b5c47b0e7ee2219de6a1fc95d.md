
**Reliability**
可靠性

注解中的可靠性是指独立（通常）人类编码员在为同一文本分配标签时的一致程度。

**Reranking**
重排

信息检索系统中的功能，用于重新排序文档以最大化其对用户查询的响应。

**Semantic net**
语义网

包含节点的图表，表示概念（包括法律概念和事实）和表示概念之间的关系的弧。

**Sensemaking**
意义制造

组织和表示复杂的信息集，以解决意义制造者的问题。

**Simulated annealing**
模拟退火

一种计算技术，用于查找诸如置信度之类的函数的全局最大值，同时避免不那么大的局部最大值。

**Spreading activation**
传播激活

在引文网络的信息检索中，与查询术语相连的激活节点发送激活到链接它们的节点的过程。

**Statistical estimate**
统计估计

通过绘制统计样本，确定样本中具有该特征的元素的比例，并将该比率应用于整个群体来估计群体的特征。

**Statistical sample**
统计样本

从群体中随机抽取一些元素的样本。

**Statutory analysis**
制定法分析

确定一条法规是否适用、如何适用以及适用的效果的过程。

**Statutory network diagram**
制定法网络图

制定法体系表示为参考概念之间关系的网络或图形，这些参考概念由多个法规引用并受其约束。

**Statutory ontology**
制定法本体

法规中使用的规范概念类别的分类，它们与其他规范类别的关系，以及它们与受规制领域主题的概念类别的关系。

**Subsumption**
涵摄

使用按层次结构组织的概念本体，某事物是更一般类的成员的分类推理。

**Supervised machine learning**
有监督的机器学习

从标记的训练数据推断分类模型的机器学习方法。训练数据包括已分配结果的一组示例。

**Support vector machine （SVM）**
支持向量机

一种机器学习技术，应用统计标准来查找范畴或类别的正面和负面示例之间的边界。

**Teleological reasoning**
目的推理

考虑目的和法律规则背后的价值的推理

**Term vector**
术语向量

根据语词、引文、索引概念或其他特征表示文档。术语向量是从原点到表示大维空间中的文档的点的箭头，其具有对应于语料库中的每个特征的维度。

**tf/idf**
词频 / 反文档频率

在信息检索系统中，权重与相关术语在文档文本中出现的次数（即词频）成比例，并且与术语在语料库中出现的次数成反比（即，其反文档频率）。

**Type system**
类型系统

用于根据概念和关系的层次来注解（标记）文本的本体，以便让解析管道可以自动地将语义分配给文本区域。

**UIMA ( Unstructured Information Management Architecture )**
非结构化信息管理架构

用于问答系统的开源阿帕奇框架，其中文本注解器被组织成文本处理管道，该管道将语义分配给文本区域。

**Undercutting argument**
削弱论证

质疑另一个论证的可适用性的论证

**Undermining argument**
破坏论证

与另一个论证的前提矛盾的论证

**Unsupervised machine learning**
无监督的机器学习

机器学习技术，例如基于内容推断未标记实例的分组的聚类算法。

**Use case**
用例

在系统设计中，用户和系统之间的一系列预期互动，它将使用户能够实现目标或解决一类问题。

**Vaccine/Injury Project ( V/IP )**
疫苗 / 伤害项目

由霍夫斯特拉大学莫里斯·A. 迪恩法学院法律、逻辑和技术研究实验室（LLT 实验室）开发的项目和语料库，包括联邦索赔法院关于疫苗接种相关伤害赔偿要求是否符合国家疫苗伤害赔偿项目要求的判决。

**Vector space similarity ( VSS )**
向量空间相似性

向量空间中的文档或查询之间的相似性，通过术语向量的端点之间的欧几里德距离（或者术语向量之间的角度的余弦）来测量。
