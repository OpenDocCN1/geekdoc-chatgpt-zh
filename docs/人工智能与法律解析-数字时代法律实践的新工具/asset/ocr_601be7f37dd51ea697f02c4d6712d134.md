# 些规则部分规定：

“商业秘密”是指如下信息......
（i）源于通常不知道并且不能通过适当的方法容易地确定......的独立的经济价值......和
（ii）在这种情况下合理保守秘密的努力的主题。

如果没有特权如此做，披露或使用他人的商业秘密的人对其他人负有责任，如果
（a）他以不正当手段发现了这个秘密，或者
（b）他的披露或使用违反保密责任。

+   输入：当前事实情境 (cfs)
+   
+   A. 识别当前事实情境因素引发的问题
+   B. 对于提出的每个问题，确定支持该问题的一方：
+   1. 如果所有与问题相关的因素都偏向一方，那么返回那一方，
+   2. 否则检索与问题相关的案例，在这些案例中所有与问题相关的因素都适用
+      a. 如果存在与问题相关的案例，则进行理论测试：形成假设，即赢得大多数案件的相同方将赢得案件
+         i. 如果所有与问题相关的案件都支持s 方，则返回s 方，
+         ii. 否则试图用与假设相反的结果来解释例外
+            (a) 如果可以解释所有例外，那么返回假设支持的s 方
+            (b) 否则，返回“放弃”
+         b. 如果没有找到与问题相关的案例，则呼叫扩展查询
+            i. 如果可以扩展查询，则为每组检索到的案例呼叫理论测试
+            ii. 否则，返回“放弃”
+   C. 结合每个问题的预测

输出：为每个当前事实情境和解释预测结果
