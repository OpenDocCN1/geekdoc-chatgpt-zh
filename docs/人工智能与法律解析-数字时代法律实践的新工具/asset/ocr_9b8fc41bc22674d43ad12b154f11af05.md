# 第二章 建模制定法推理

# 2.1. 导言

法律是一个规则领域，其中许多法律规则都体现在制定法和规章中。由于规则可以逻辑地表达，计算机可以演绎地推理，因此用计算机建构制定法推理模型应该很容易。人们只需将事实情况输入计算机程序；程序识别相关规则，决定规则的条件是否得到满足，并根据适用或不适用的规则解释答案。

然而，建构制定法推理的计算模型提出了挑战。如下所述，法规通常是模糊的，语法歧义以及语义模糊，并且受制于结构的不确定性。如果计算机程序要应用于一条制定法规则，它应适用哪种逻辑解释，它如何处理法规条款的模糊性和开放性，或决定是否存在例外？

本章对演绎地适用一条法规与制定法解释的复杂过程进行了对比，后者经常涉及相互矛盾的合理论证。经典逻辑模型在处理法律不确定性时可能会失效，法律推理的一个共同特征是：即使拥护者对问题中的事实和决定事项的规则达成一致，他们仍然可以做出法律上合理的论证支持和反对一个命题。

然而，用制定法进行推理仍然迫切需要。本章检讨了解决或处理这些问题的各种人工智能与法律方法：系统地阐述制定法的多个逻辑
