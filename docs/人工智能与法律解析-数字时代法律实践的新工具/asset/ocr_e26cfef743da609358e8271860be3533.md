# 5.5.1. 解决关于事实的相互冲突的论证

例如，如图 5.9 所示，H1，一个事实主张（即，“场的网被破坏：鱼即将逃脱。”）攻击，并被另一个事实主张 Y2 攻击（即，“鱼有没有逃脱的可能性。”）如何在基于价值的论证框架中解决这样的冲突？

每个关于事实的冲突需要通过元级别论证单独解决，元级别的结果将导致在每个被指派的论证中状态可证成、可论证或不可支持 [ 强调补充 ]。（Atkinson 和 Bench-Capon，2007 年）

论证框架层级的冲突解决层面将配备用于事实推理的论证程式，其中包括针对事实断言的法律评估而定制的关键问题。反过来，这些为竞争性事实主张的偏好排序提供了基础。例如，关于事实主张的关键问题探讨了证人证词支持诉讼请求的可信度：证人有偏见吗？证人有能力知道吗？在现代诉讼语境中，专家证人的证词将受到以下关键问题的影响：证人是相关领域的专家吗？这个证人的断言与其他专家的断言一致吗？专家证人的陈述基于证据吗？（见 Walton 和 Gordon，2005）
