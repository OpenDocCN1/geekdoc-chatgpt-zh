## 6.6.2. 用于论证微观世界的本体

用于猎物的财产利益微观世界的本体需要指定与集合中的事物类型相对应的概念和关系列表，也与指定其组件、特征（槽）和槽填充的框架相对应。这包括案例、法律因素、法律测试和中级法律概念以及基本法律政策/价值观的表示。

### 表示案例和法律因素

微观世界中的案例用案例框架来表示。如图 6.5 所示，每一个案例框架都包含用于名称、索赔（例如，侵占、民事错误或侵权，即一个人将他人的财产当作自己的财产进行占有或处分）、结果（对于原告或被告），以及适用因素列表的槽。

案例框架还指定了一些特征，根据猎物的财产利益领域的法律因素，这些特征的值对案例比较非常重要。这些比较特征包括从狩猎/捕捉场地通过干扰引起的案例框架中带星号的插槽。

事实情况或许会有影响，例如，狩猎发生在什么类型的场所，例如露天场地、海洋或棒球场，什么类型的限制适用于那种场地（私人拥有的还是开放的），或寻求的猎物是什么类型的：害虫、食用野味或商业捕获。同样，原告为确保猎物采取的步骤，这些步骤公开表现的程度，以及被告干扰的意图等，都很重要。

它需要一定数量的法律常识性知识来理解如下情形：对被告的辩护而言，故意侵犯财产比无意侵犯财产更严重，在看台上抓住一个有价值的棒球和狩猎狐狸是一样的，试图把一位导师转会到另一所学校就像在竞争对手的网之间滑行以收集捕获物，球迷可能不会在池塘或海洋中“追捕”错误的棒球，海洋比池塘更加开放且可能没有财产限制。

一个程序不能像人类那样理解这些差异。它甚至不能以合理的方式操纵它们，除非信息被表示，并且程序被指示在适当的时间和地点找到相关信息。如果开发人员希望程序足够“智能”以执行这样的比较或强制执行这样的语义约束，他需要将它们构建到系统中，而本体就是这样做的一个地方。

在这个本体中，因素支持在一个因子上按照点数和幅度来比较案例（见第 3.3.2 节）。在启用因子幅度的比较时，这些因子采用了比较特征的案例值（图 6.5 中的加星标的槽）。案例框架为每个比较特征指定备选的可能值。这些插槽中的一些涉及有序的可能值范围。例如，关于占有的狩猎 / 捕获步骤的值范围从仅仅寻求猎物到捕获和固定或致命伤害的猎物。被告干扰的意向性值范围从无意干涉到明知故意或故意干扰。

本体还需要为计算机预期“理解”的任何类型的对象指定一个框架。例如，需要一个猎物框架，其槽位指定诸如“可能的场地”“是否可食用”“是否为有毒害虫”“是否为商业捕获”等属性以及实际上在比较案件时预计会有重要影响的猎物的任何特性。

### 表示法律测试

为了对表 6.2 中的样本对话进行建模，本体需要表示法律以论证法律应该是什么。学生提出法律规则或测试，教师通过提出假设来探讨拟议测试的恰当性。学生可以通过修改测试回应假设，使其具有或多或少的限制。本体需要支持这些修改。

让我们用表 6.5 中所示的示例对话中使用的一小组建议测试来说明它是如何做到的。左栏列出了五项拟议的测试。第一组两项测试涉及占有（占有和占有-1）。第二组三个测试涉及明显意图（明显意图，明显意图-1 和明显意图-2）。让我们把右栏暂时放在一边，它显示了如何逻辑地表示测试。

建议的测试使用五个中级法律概念（ILCs）：

- 1. 占有（猎物，程度）
- 2. 占有的明显意图（猎物，程度）
- 3. 干扰的意图（程度）
- 4. 干扰
- 5. 原因 {干扰，非［占有（猎物，程度）］}

中级法律概念用接受值的参数表示。例如，占有可以指定拥有的猎物和拥有程度，即已经采取的狩猎 / 抓获步骤。可能的值与案例框架的比较特征（图 6.5 中的星号插槽）相同。拥有的猎物可以采用猎物的价值：动物（野生的，家养的，食用的，害虫，狐狸或鹌鹑），棒球，学生，有价物或经济目标。占有程度可以是来自占有的狩猎 / 抓获步骤的价值：寻求猎物，接近猎物，短暂抓住猎物或让猎物受伤，或捕获或致命伤害到猎物。占有的明显意图这个中级法律概念可以指明猎物和意图占有的表现程度，它的值就是原告寻找猎物的客观表现的值：隐藏意图，模糊意图，或明显表现出来的意图。
