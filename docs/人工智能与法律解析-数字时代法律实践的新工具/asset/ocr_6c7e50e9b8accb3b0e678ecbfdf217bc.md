的确，前面章节中的大多数计算模型都可以重新概括为论证型式，并集成在像卡涅阿德斯基这样的论证模型中。例如，人们可以实施理论构建的论证型式（McCarty 和 Sridharan，1981；见 Bench-Capon 和 Sartor，2003）：如果可以构建一个理论来解释一系列关于同一问题（与当前案例）的先例和假设，然后论证将理论应用于当前案例。人们还可以实施来自标准事实的论证 [ GREBE，（Branting，1991）；见 SIROCCO，（McLaren，2003）] ：如果法规中的一个具有开放结构的谓词被判定为满足了一个先例的标准事实，并且这些标准事实类似于当前案例的事实，然后认为在这个案件中具有开放结构的谓词也得到满足。
