# (1) 全局最优值的选择

在式(7-28)中，蝙蝠需要通过全局最优值更新速度，但是多目标优化问题的解是解集，因此本书采用小生境技术和轮盘选择法来选择全局最优值，可以保证全局的蝙蝠向 Pareto 最优解集中密度较小的解收敛，保证了解集的分布。
