# 2. 误差逆传播算法与多层网络

多层网络一般呈现为层级结构，相邻神经元之间完全相连，且同层神经元之间不连接，也不跨层连接，这样的结构被称为“多层前馈神经网络”。多层网络学习能力较单层感知机要强大得多，需要采用更好的学习策略对网络进行训练，误差逆传播（Error Backpropagation，BP）算法是较为成熟的算法，通过 BP 算法训练多层网络，可以得到 BP 神经网络（如图 4-21 所示）。
