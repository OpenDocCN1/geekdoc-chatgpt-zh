# ③ Griewank 函数

# a. 函数描述

该函数的数学表达式如下：

\(f(x) = \sum_{i=1}^d \frac{x_i^2}{4000} - \prod_{i=1}^d \cos(\frac{x_i}{\sqrt{i}}) + 1\) (6-10)

# b. 函数介绍

Griewank 函数具有许多广泛分布的局部极小值，并且这些局部极小值的分布有规律性，其维度为 \(d\)。图 6-4 展示了该函数在不同域中的复杂度。

# c. 输入域

Griewank 函数通常在超立方体\(x_i \in [-32.768, 32.768], i=1, 2, \cdots, d\) 上求解。

# d. 全局最小极值点

\(f(x^*) = 0, \quad x^* = (0, \cdots, 0)\) (6-11)
