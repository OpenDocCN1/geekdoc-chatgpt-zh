# 第三章 欢迎来到“铁锈地带”

而马西森预见到提高最低工资后产生影响的方向，他认为：

> 提高最低工资导致的结果是使得使用机器人更加经济实惠而更具魅力，因而会吸收掉部分工作。在我看来，这样反而会加速机器替代人工的到来。在未来的五年，我们有朝一日会突然发现机器人已经成为我们生活乃至正常经济活动中的一部分。（Giang, 2015）
