# 引言 别再天真

同之前的那些工业转型——从工业革命自身身到如今在美国和英国出现的重工业的瓦解那样，它们带来“铁锈地带”，对深陷其中的工人们来说，都是漫长而痛苦的转换期。然而，当一切尘埃落定，如果技术的改变只会在社会背景中影响我们（由政府和法律体系的回应而形成的），那么我们就面临以下问题：我们该如何应对这些可能呢？

没有人知道将会发生什么，如果劳动力市场将会遭受一次巨大的震荡，那么我们的确应该有所担心了。当代社会是在经济学家称为“充分就业”（full employment）的假设基础上运行的，这里的充分就业不是全职工作的意思，而是指大部分想要就业的人都能够获得一份工作。而这在十年、二十年甚至三十年之后仍然会实现吗？这一赌注可是再高不过了。
