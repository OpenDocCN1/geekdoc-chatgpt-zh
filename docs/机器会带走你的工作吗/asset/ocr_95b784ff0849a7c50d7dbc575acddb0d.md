# 第三章 欢迎来到“铁路地带”

数量已经在持续减少了，因为享利福特 T 型车生产线已经成为企业的补充部分——事实上，已经被超越——而超越本身源自市场对新型汽车的需求，新型智能汽车更像是轮子上的智能手机。当共享驾驶公司优步和 Lyft 计划将使用的自有车辆由人工驾驶转向自动驾驶时，毫无疑问很多崭新的商业模式连同新的工作将会出现以迎合市场需要，这是我们目前仅仅能够猜想到的结果。但是在两种假设背后的景象——被自动驾驶替代了的人类司机（职业化的熟练驾驶者），以及从私有汽车转向更高水平的即时用车服务的相关转变——则会对所需劳动的种类和数量两方面产生深刻的影响。

机器智能在经济中的应用，带给传统的人类功能——驾驶——的影响后果将是无穷尽的，原因很简单，我们的传统技术已经有力地塑造了我们的行为方式，并据此建构了经济活动来使这一切成为可能。一旦转换了这一核心假设——人类必须自己驾驶汽车——一切将瞬间流变。
