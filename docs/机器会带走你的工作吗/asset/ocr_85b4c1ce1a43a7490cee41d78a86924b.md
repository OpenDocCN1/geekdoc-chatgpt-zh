# 第三章 欢迎来到“铁锈地带”

一个接一个的工业变革正在经历着戏剧化的变革过程，然而所有的结局都是一样的——更为便捷、价廉（通常会是免费服务），以及更少的工作。但是，这一过程才刚刚开始。如果深信这种戏剧性的变革会发生在我们之后，那就过于天真了。我们正处于这种变革的起点，而对于正在发生的变革的中心，其影响却纯粹而深远，有朝一日，我们将把那些原本由人承担的工作交给机器。

在某一层面上，这种替代是科技的永恒传说。车轮、杠杆、滑轮，农业机械中的铲子和犁，使得我们人类可以做出那些数千年前没有这些机器时难以做到的事情；而与此同时，我们从事这样的工作时却只需要更少的人。这其中的关键点在于科技在不断进步——并且是以飞快的速度进步。在更为根本的层面上，我们正在不断地将劳动力因素从价值创造中移出，这一点在我们前面论述的一些例子
