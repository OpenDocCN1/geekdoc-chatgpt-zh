# 法律、金融、计算机服务与管理

正如无人驾驶汽车所展示的那样，机器智能的影响远比乍一看要大得多。而显然易见的是，机器的机械化应用，像自动取款机和超市收银台这样的智能设备对我们而言最有意义，而事实上，机器人 / 人工智能革命的影响远远超出了低技能任务的范围。复杂的算法正在逐渐取代律师助理、合同律师和专利律师的多项任务。更具体地说，律师事务所现在仰仗电脑完成上千份法律简报和判例的扫描，以协助完成审前研究。例如，一个软件系统被证明能够在两天内分析和分类 57 万份文档（Frey & Osborne, 2013）。
