# 第三章 欢迎来到“铁锈地带”

角度来看，这只是对技术支持者已经说过的话的更严肃的重述，尽管他们有些轻率。他们只是对巨大的变化动动嘴皮，然后继续说谎，但是拒绝承认正在形成的技术革命的宏大规模。他们知晓——至少也是隐隐地——我们所面临的是一系列全新的结构性失业浪潮；这也是所有过去主要的科技巨变带给我们的。但是这一波失业将深入到何种程度？又会持续多久？是否可以与重工业衰落带来的就业危机相比较，又或者其景象甚至是我们在现代社会的经济生活中从未见过的？

我们可以回应的就是，为各种可怕的可能性后果做好应对计划。当领导有方时，那些大公司就会这么做，政府也将这么做。在另一个尺度上，如果通常我们凭直觉工作，那当我们为未来制订计划时，这也是我们个人应该做的。如果我们不能确定事情会发展成怎样，我们就对各种不测做出准备——然后确保我们不会被突如其来的结果弄得措手不及。我们中没有人期待我们的家园有一天会付之一炬，但是我们需要购买保险。
