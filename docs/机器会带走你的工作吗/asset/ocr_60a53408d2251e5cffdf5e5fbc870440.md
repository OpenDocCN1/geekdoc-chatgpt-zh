# 老年照顾与护理

只有低技能工作才存在被替代的风险，机器智能革命显然会挑战这一假设。但是，对于那些具有较高的（且不可替代的）内在“人类智商”的职业呢？

这方面，最引人注目的发展体现在照顾老人和病人。
很明显，随着社会老龄化，提供这种照顾的任务将大大增加。
对于那些人口结构比其他国家更加倾斜的国家而言，
这一点尤为明显。因此，在日本，许多应用程序开发的重点集中在老年人护理应用领域，就不足为奇了，因此在那
里，人口更迟已经成为其社会的重大问题。根据 2010 年
的一份报告显示，日本护理机构中从业人员已达 3000 万
人（Hay, 2015）。
