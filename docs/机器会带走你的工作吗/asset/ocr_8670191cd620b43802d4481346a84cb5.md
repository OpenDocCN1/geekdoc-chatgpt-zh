当然，在组织框架下，风险评估和风险管理较为复杂，因为在应对 X 出现的可能性的同时，需要考虑如何减少在其他方面造成的损害，我们并不希望为了治愈“疾病”而导致更糟的结果。这也是那些对努力制订计划应对 X 可能性持批判态度者的部分动机。他们辩解称对创新带来的潜在影响提出质疑，会使得创新的革命性大打折扣并降低其成功率。这种处理指数级驱动的技术变化的观点，看上去就过于天真了。

正如麻省理工学院经济学院大卫·亚瑟（David Autor，2015）曾指出的，反对他所谓的“最近关于人机替代的悲观预言”的批评者，他们通常无法解决他们论点的含义，即如果事情真变成那样，“那么我们的主要经济问题将是分配问题，而不是稀缺性”。此处值得注意的是，这一观点直接从经济领域跨越到了政策领域。如果除却最让人乐观的情景，这种讨论的正面意义在于，它明确指出经济中的分配问题将不可避免，资本将在其中扮演更重要的角色，而劳动力则会越发式微。
