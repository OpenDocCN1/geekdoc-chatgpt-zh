## 1.4.1 如何写好场景描述

场景描述即用文字把想要的画面内容表达清楚。

其实思路并不陌生，可按时间、地点、主体、事件四个维度组织：

![](img/45492b65f5233d45a508f65c2790b1c3_20_0.png)

例如：

清晨，客厅，机器人，阅读。

下午，校园操场，老师与学生，体育竞赛。

春天，公园，一群好友，野餐。

四要素并非必须齐全，可按需灵活组合，单个要素内部也可并列多个关键词。看几个组合示例。

时间 + 地点 + 主体：未来，沙漠，未来感建筑，飞行汽车，太空电梯。

地点 + 主体 + 事件：火星，猫，狗，狐狸，探险。

主体 + 事件：3只小兔子，厮打。

主体 + 地点：稻草人，游客，薰衣草田。

主体：都市，都市景观，城市夜景，建筑，摩天楼，蓝天。

写提示词并不难。

但当只有大概主题，例如父亲节海报、风景壁纸，却尚未明确画面细节时，用四要素就不够直接。

怎么办？让 AI 来补全。

借助 ChatGPT、New Bing、文心一言等大模型，两步即可完成场景描述。

# 第一步：向模型提问。比如：“我需要 × × 主题的图片，请发挥想象，用一句话简洁描述画面内容。”

> 我需要一张具有科技感的未来城市图片，请发挥你的想象力，用一句话帮我描述这张图的内容。

> 在一座科技感十足的未来都市里，智能汽车在高耸建筑间飞行，透明管道中穿行着超高速悬浮列车，无人机与机器人穿梭于空中与街头，构成繁忙而富有活力的城市景象。

AI 能立刻给出场景描述。若不满意，可要求其继续提供更多不同版本，自行挑选最贴合的方案。

# 第二步：从 AI 给出的描述中提取喜欢的词句作为提示词，例如 “一个未来科技感城市，智能建筑，空中飞行的汽车，穿梭在透明管道中的列车，无人机与机器人”。

至此，场景描述类的提示词就确定了。

若需要英文提示词不会翻译，可直接让 AI 翻译或使用翻译工具。

![](img/45492b65f5233d45a508f65c2790b1c3_22_0.png)

请帮我把“一个有着未来科技的城市，智能建筑，汽车在空中飞行，列车穿梭在透明的管道中，无人机和机器人”翻译为英文。

![](img/45492b65f5233d45a508f65c2790b1c3_22_1.png)

A futuristic city with intelligent buildings, cars flying in the air, trains shuttling through transparent tubes, and drones and robots buzzing aroud.

+   - 总结场景描述提示词的两种写法。

- 1. 若心中有明确画面，可按“时间 + 地点 + 主体 + 事件”四要素撰写。

- 2. 若仅有主题方向，可借助大语言模型辅助生成描述并翻译。

## 1.4.3 常用参数设置

设置参数可快速调整画面比例、精细度等，掌握常用参数能显著提升效率。

担心参数太多记不住？记住几个高频参数即可生成优质作品。

| 参数       | 说明                                                                                     |

|------------|----------------------------------------------------------------------------------------|

| --ar 或 --aspect | 画面宽高比，如 “--ar 1:1” 表示正方形 |

| --q 或 --quality | 质量，数值越高细节越丰富，可设0~2 |

| --v 或 --version | 版本，不同版本擅长不同类型图像。常用 “--v 5”，2023年3月发布，对提示词理解更好，分辨率更高 |

| --s 或 --stylize | 风格化，数值越大艺术化越强，与提示词相关性越低。V5中范围0~1000，想要更艺术化可设700~1000 |

## 1.4.4 参数使用小贴士

+   1. 参数排列顺序无严格限制。

+   2. 参数可使用简写或全称、大写或小写均可。例如：

   --ar 16:9 --v 5 --quality 2 --stylize 750（宽高比16:9，版本5，质量2，风格化750）。

+   3. 参数前需用空格分隔，英文与数字之间也需空格。如下图所示。

```
1 girl --ar 9:16 --niji 5 
   | 空格 | 空格 | 空格
```

总结来说，常见的 AI 设计提示词结构为：场景描述 + 风格细节 + 参数设定。

# 6.1.9 niji参数使用要点

提示里出现的 “--style original”“--style expressive” 有何含义？

这是 niji 模型针对二次元画风提供的细分风格，目前共有 5 种。

+ - default style：默认画风，接近传统日系漫画。
- expressive style：表现力风格，偏欧美质感，画面更有厚度。
- cute style：可爱风格，画面更柔和。
- scenic style：舞台风格，带电影灯光效果，氛围感强。
- original style：原始风格，画面精致细腻。

其余条件不变时，不同风格会带来明显差异。例如：

a girl with two black braids, wearing a white dress, holding a bouquet of roses, upper body, half body photo, close-up

扎两条黑辫的女孩，穿白裙，捧玫瑰，上半身，半身照，特写

从左至右依次为默认风格、表现力风格、可爱风格、舞台风格、原始风格的生成效果。

![](img/45492b65f5233d45a508f65c2790b1c3_178_0.png)

高级设置中各参数的含义如下表所示。

## ◎ 高级设置中参数的含义

| 参数 | 含义 |
| ---- | ---- |
| 步数 | 生成图片所经历的步骤数。步数越多，画面细节越丰富。根据经验，步数为25时，生成的图片质量较好 |
| 文本强度 | 最终生成的图片与提示词的匹配度。文本强度越低，AI自由发挥的空间越大；越高，则画面越符合提示词 |
| 采样器 | AI进行噪点去除时使用的算法，采用默认参数即可 |
| 随机种子 | 使用默认值即可 |
| 负标签 | 不想在画面中看到的内容 |
