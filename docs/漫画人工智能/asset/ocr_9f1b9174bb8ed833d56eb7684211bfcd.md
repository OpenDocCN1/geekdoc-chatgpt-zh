# # AI 算法、框架及应用技术

不仅如此，该层包含 AI 算法及 AI 框架，是整体技术体系架构的核心。

| 常用的智能学习 | |
|---|---|
| 监督学习 | 无监督学习 |
| 多任务学习 | 强化学习 |
| 对抗学习 | 迁移学习 |
| 元学习 | 终身学习 |

AI 算法提供通用的深度神经网络结构，人工智能学习算法及通用学习范式；AI 框架则是对 AI 算法的具体实现及封装。

![](bbox=[0.15, 0.66, 0.62, 0.86])

AI 框架为实现和应用上述方法提供了一整套算法模型工具库，让开发者像搭积木一样快速构建人工智能，并为模型的优化、训练和部署提供成熟的解决方案。
