# 模型窃取逆向解析攻击

+   - 一是指导型攻击，攻击者根据接口获取系统模型的初步信息，进而通过初步信息牵引指导对模型进行逆向分析过程。
+   - 二是探索性攻击，攻击者使用专门设计的样本，不断迭代地查询目标模型并记录目标模型返回结果，大量探索性策略能够最大限度地提取有关模型内部的信息。
+   - 三是模拟式攻击，攻击者利用窃取的信息逐步训练一个替代模型，用于产生可转移的对抗样本来攻击原始模型或窃取整个模型供自己使用。
