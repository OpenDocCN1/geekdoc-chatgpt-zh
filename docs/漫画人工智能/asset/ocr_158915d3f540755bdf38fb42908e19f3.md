# 后记

最近几年，人工智能前沿领域取得了重大的突破，颠覆性理论创新层出不穷，工业应用走向深耕细分和跨界融合，科幻电影和小说中的内容成为现实。
本书成稿之际，正好赶上 2020 年世界人工智能大会的召开，何其幸运，我们恰逢智能时代开启伟大征程中最闪亮的一程。谨以此书，致敬那些夜以继日、辛勤劳作的人工智能从业者。感谢他们那种“任世事变迁，寒暑交替，我只此心不动”的专注，感谢他们“初心易得，始终难求”的执着坚守！

中国人民解放军战略支援部队信息工程大学（后称：信息工程大学）从 20 世纪 80 年代开始人工智能的教学科研工作，是国内最早一批从事人工智能高等教育的院校。我校的郭云飞校长也曾经是这个领域的开拓者与深耕者。学校的前瞻性、战略性教学科研布局很幸运地契合了中华民族伟大复兴和人工智能飞速发展的时代进程。从早期的经典人工智能到现在的新一代人工智能，信息工程大学的学者们紧跟时代的节拍，培养出大批信号感知、智能信息处理、认知计算与理解等领域的青年才俊和专家学者，他们在各自的工作岗位上默默奉献、开拓前进。新时代、新征程、新挑战，在信息系统工程学院党委的成功规划下：2017 年筹划并开办全军第一个“高级现代人工智能研修班”；2019 年信息工程大学成功获批了人工智能本科专业，与国内其他 35 家院校一起成为全国首批人工智能本科专业建设院校，也是第一个、唯一一个人工智能本科专业建设军队院校；2019 年成功举办第三届“强网杯”全国网络安全挑战赛暨第二届“强网论坛”人工智能分论坛，国内著名人工智能技术大咖云集郑州分享技术成果。面对国际形势风云变幻，时代发展和国家安全需求将人工智能提高到前所未有的高度。人工智能已然成为国家间竞争的制高点，人工智能各类行业系统也即将成为国之重器。人工智能是一个高科技领域，近年来国内外著名咨询机构发布的《人工智能人才白皮书》表明，我国人工智能的高端专业人才还处于相对匮乏状态。由于人工智能人才培养周期长，更需要从青少年人才培养开始布局。因此重视人工智能科普教育，启迪青少年的高科技思想，开拓青少年的人工智能思维，成为我们这一代人工智能从业者的责任与担当。作者从事人工智能
