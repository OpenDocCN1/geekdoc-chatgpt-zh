# 人工智能技术体系

那人工智能技术最重要的是什么呢？

那就要提到核心技术了！

人工智能技术的核心技术包含：问题求解技术、知识推理与规划技术、不确定性知识与推理技术、机器学习技术、智能感知与决策技术。

2017年7月，中国颁布《国家新一代人工智能发展规划》。

战略提出围绕增加人工智能创新的源头供给，从前沿基础理论、关键共性技术、基础平台、人才队伍等方面强化部署，促进开源共享，系统提升持续创新能力。
