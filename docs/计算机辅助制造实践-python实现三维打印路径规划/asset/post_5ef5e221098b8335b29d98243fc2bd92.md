## 8.2.2 基于角平分线的偏置

在上一小节，我们粗略介绍了基于线段平移的多边形偏置方法，包括单一线段偏置计算方法和相邻偏置线段修补策略，同时，我们还介绍了局部和全局自相交环的概念。在这一小节，我们将继续介绍基于角平分线的偏置方法。相对于线段平移偏置，使用角平分线偏置更容易获取初始偏置轮廓。

在开始介绍之前，我们不妨重新去看一下图 8.5，无论是哪种情况，图中两偏置线段（或延长线）之间的交点 Q 到直线 P₁,P₂,P₃ 的距离均等于偏置距离，据此，我们不难判断交点 Q 位于 ⌒P₁P₂P₃ 的角平分线上。之前我们都是以线段为单位来思考偏置问题，下面我们不妨从点的角度出发来考虑偏置问题。如果我们把点 Q 称为原始多边形上顶点 P₂ 对应的偏置点的话，那么不难想象，只要我们依次连接多边形上的所有偏置点，就能直接得到一条初始偏置轮廓，这样确实能为我们节省对偏置线的修补和裁剪工作时间。

首先我们来看一下偏置点的计算问题。这里我们还是以逆时针多边形的向内偏置为例进行说明。对原始轮廓上的 3 个连续点 P₁、P₂、P₃，我们首先需要计算过 P₂ 的角平分线，因为 P₂ 坐标为已知量，因此我们只需计算角平分线的方向即可。这其实很简单，我们只需分别计算 P₂P₁、P₂P₃ 的单位位向量（记为 v₁、v₂），然后将其相加就可得到角平分线的方向向量（也是单位向量，记为 v），如下代码：

| | 偏置点计算方法 | 8 - 2 |
|---|---|---|
| 1 | v1 = P2.pointTo(P1).normalized() | # v1 为 P2P1 方向 |
| 2 | v2 = P2.pointTo(P3).normalized() | # v2 为 P2P3 方向 |
| 3 | v = (v1 + v2).normalized() | # v 为角 P1P2P3 角平分的方向向量 |

但是由上述代码计算得到的向量 v 还不能直接被用来计算偏置点。因为两个向量相加得到的和向量总是指向由这两个向量所夹的优角区域，向量 v 也不例外。也就是说，由以上代码求得的向量 v 的正反方向可能是错的。如图 8.9(a) 所示，当 P₁、P₂、P₃ 所夹内角为优角时，v 的方向是对的；但当 3 点所夹内角为劣角时，v 的方向就是错的，如图 8.9(b) 所示，在这种情况下，我们需要对 v 进行取反操作。

那如何判断 P1、P2、P3 所夹内角的优劣性呢？事实上这个问题在上一小节已经涉及（参见图 8.5），但当时我们选择了忽略。这个问题其实也很容易，我们只需对向量 v1、v2 进行叉乘，如果得到的向量指向 z 轴负向，则 P1、P2、P3 所夹内角为优角，反之则 3 点所夹内角为劣角。根据以上分析，对向量 v 进行方向调整的代码如下：

```
4 If v1.crossProduct(v2).dz > 0      # 如果 v1、v2 叉乘向量指向 Z 轴正向
5     v.reverse()                   # 则对它们的和向量方向取反
```

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_169_0.png)

图 8.9 角平分线上偏置点计算方法

下面我们需要确定偏置点到 P2 的距离。如图 8.9(a) 所示，我们不妨记偏置点为 Q，Q 在 P1P2 上的投影为 D，则在三角形 QDP2 中，QD 长度为已知量（即给定的偏置距离），我们只需知道 ∠QP2D 的角度（记为 θ，即 theta），便可算出斜边 P2Q 的长度（记为 L）。在此基础上，我们可以得到偏置点 Q 的坐标。需要说明的是，尽管以上推导是针对图 8.9(a) 所示的优角情况做出的，但同样适用于图 8.9(b) 所示的劣角情况。综上，计算偏置点的具体代码如下：

```
6 theta = v1.getAngle( v2 ) / 2      # 三角形 QDP2 内角 QP2D 角度
7 L = d / math.sin( theta )          # 三角形 QDP2 内斜边 P2Q 长度
8 Q = P2 + v.amplified( L )          # 偏置点 Q 坐标
```

现在，按照以上步骤，我们可以计算一个给定多边形任意顶点的偏置点，如果我们把这些偏置点有序地连接起来，就可以得到原始多边形的初始偏置多边形。之所以称其为初始，是因为在这个偏置多边形上，仍然会存在各种各样的问题，包括我们之前介绍过的局部自相交环和全局自相交环。因为生成偏置线的方法不同，因此识别和消除局部自相交环的方法也可能和上一小节介绍的方法有差异。但识别和消除全局自相交环的方法是类似的，因此在这一小节我们不复赘述。

我们首先来看一下初始偏置多边形上局部自相交环的识别问题。这个问题的解决方案总结归纳起来可分为两种：一是根据偏置点位置识别，二是根据偏置线方向识别。我们先来看一下前者，如图 8.10 所示，对图中的原始轮廓，当偏置距离较大时，将会在偏置轮廓上出现一个局部自相交环。对偏置点 Q1 ~ Q4，Q1 和 Q4 到原始轮廓的距离大于给定的偏置距离，因此它们是合法的偏置点；但 Q2 和 Q3 到原始轮廓的距离小于给定的偏置距离，因此它们是非法的偏置点。

在有非法偏置点的附近，必然会有非法的偏置轮廓，因此原则上在定位非法偏置点后，就可找到那些非法的自相交环。但是这种基于偏置点位置去识别自相交环的方法计算量较大，因为这种方法需要遍历计算每个偏置点到原始轮廓的距离，其算法时间复杂度至少是 O(n²)，其中 n 为原始多边形上的顶点个数。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_170_0.png)

图 8.10 局部自相交环识别方法:根据位置或方向识别

接下来我们再来看一下根据偏置线方向识别自相交环的方法。我们知道，原始轮廓是有方向的（逆时针），对原始轮廓偏置得到的轮廓方向应该和原始轮廓的方向一致。具体到偏置轮廓上的每条边，在偏置过程中，它的方向也应该和与之对应的原始轮廓上的边的方向保持一致。如图 8.10 所示，显然，偏置线段 Q1Q2、Q3Q4 分别和原始线段 P1P2、P3P4 的方向是一致的，因此 Q1Q2 和 Q3Q4 是合法的偏置线段；但是 Q2Q3 和 P2P3 的方向刚好相反，因此我们断定偏置线段 Q2Q3 必然是有问题的，即非法的。在非法偏置线段附近，必然存在非法的偏置轮廓，据此，原则上我们可以找到自相交环。相对偏置点位置识别法，偏置线方向识别法效率更高，它的算法时间复杂度为 O(n)，其中 n 为原始多边形上的顶点个数。

无论使用哪种方法，当我们识别出局部自相交环后，就要想方设法将其消除。但消除局部自相交环绝对不是一件容易的事情。原则上我们可以计算非法偏置点或非法偏置线段附近偏置线上的自相交点，并根据这些交点舍弃一些非法偏置轮廓段。但这真正操作起来难度非常大，因为我们很有可能遭遇类似于图 8.7 所示的复杂自相交轮廓，哪些轮廓段可取？哪些轮廓段可舍？这些问题可能都需要我们进一步计算或制定规则。

在我们的前期研究工作中，曾提出了一种基于轮廓更新的局部自相交环消除方法和基于树结构分析的全局自相交环消除方法（参见 Lin Z, Fu J, He Y, Gan W. A robust 2D point-sequence curve offset algorithm with multiple islands for contour-parallel tool path. Computer-Aided Design. 2013,45(3)：657-70）。轮廓更新法使用原始多边形相邻顶点间的角平分线段（顶点和相应偏置点形成的线段，见图 8.10）是否相交来识别局部自相交环是否存在。如果相邻角平分线段相交，则在附近构建一个原始轮廓的卡圆，并基于卡圆对原始轮廓的顶点进行更新。树结构分析法首先计算偏置轮廓上的自相交点，然后将这些交点根据位置关系整理成树状结构，最后按照一定规律截取某些节点间的轮廓围成若干有效环。结果表明，上述方法能在线性时间内消除所有局部和全局自相交环。有兴趣的读者可以使用 Python 语言复现一下这个算法。

## 8.3 基于裁剪的轮廓偏置

我们在上一节介绍了两种基础偏置方法，分别是基于线段平移的偏置方法和基于角平分线的偏置方法，但我们都并未真正实现这些方法。这是因为，一方面，实现多边形轮廓的偏置算法确实比较困难，将耗费我们大量的时间和精力；另一方面，更重要的是，在计算几何领域，已经有了一些免费的开源几何库，可以帮助我们实现平面轮廓的偏置功能，如 CGAL、Clipper 等。我们只要掌握其中一个开源库的使用方法即可，似乎没有必要再去新造一个轮子。

CGAL(https://www.cgal.org/)是一个重量级的大型计算几何库，包含了计算几何领域的诸多算法，比如凸壳生成、实体布尔运算、Delaunay 三角化、Voronoi 图、几何形状重建等。但 CGAL 源码采用 C++模板技术编写而成，晦涩难懂，对初学者来说，阅读和使用难度较大。相对来说，Clipper(http://www.angusj.com/delphi/clipper.php)是一个轻量级的小型几何库，专门用于平面多边形的布尔运算，算法运行效率高、鲁棒性强。目前，Clipper 已在多种编程语言上实现了直接可用的源代码，如 C++、C#、Delphi、Python 等。在这一章，我们准备使用 Python 版本的 Clipper 库来实现二维轮廓偏置功能。

### 8.3.1 Clipper 库简介

Clipper 是一个专门用于平面闭合或非闭合多段线布尔（或叫裁剪）运算的开源计算几何库，可以实现平面图形的交（intersection 或 and）、并（union 或 or）、差（difference）、异或（xor）以及偏置等运算功能，见图 8.11。Clipper 库由 Angus Johnson 根据 Bala R. Vatti 在 1992 年发表的 A generic solution to polygon clipping 论文实现，因此，Clipper 库中的裁剪算法又叫 Vatti’s clipping algorithm。遗憾的是，网上很难找到关于 Angus Johnson 的个人资料，因此我们无法对他做进一步介绍。

下面我们先来看一下 Clipper 库中的几个基本概念。在 Clipper 库中，所有算法的输入和输出都是一种被称为 Path 的对象。事实上，Path 和我们之前定义的 Polyline 类似，不过 Polyline 是三维多段线，而 Path 是二维多段线。Path 可以包含一个点、两个点或多个点，它可以闭合，也可以不闭合，甚至还允许自相交，方便起见，这里我们在描述时还是称 Path 为轮廓。Clipper 库的强大之处在于它能够处理自相交轮廓区域的裁剪问题，而这个功能的基础是平面区域的填充规则。

对于由一条或多条闭合轮廓组成的平面封闭区域，Clipper 定义了四种填充规则：奇偶填充（Even-Odd）、非零填充（Non-Zero）、正填充（Positive）、负填充（Negative）。需要说明的是，这里说的填充是计算机图形学的概念，这些规则定义了平面封闭区域内哪些区域需要被填充，哪些区域不需要被填充。填充的概念是学习和理解 Clipper 库的重要基础，因此我们有必要对此展开讲解。

奇偶填充的概念比较简单，事实上我们在前面几章关于打印区域的识别问题中已经有所涉及（参见图 4.10）。对一条起点在区域外的射线，我们可以假想它逐渐伸长和区域各条边界轮廓相交，并最终穿越区域的场景。在这一过程中，奇偶填充规定：和射线相交的第奇数个轮廓内部区域是填充区域，第偶数个轮廓内部区域是非填充区域。奇偶填充一般适用于由那些轮廓本身不存在自相交情况且轮廓之间也不存在相交情况的轮廓所围成的平面区域。

非零填充、正填充以及负填充的概念相对复杂，它们根据射线穿过区域轮廓时的绕数或叫现绕数（winding number）来确定某一区域是否需要填充。如图 8.12 所示，如果区域中的某条轮廓从右到左穿过射线，那么这条轮廓的内部区域绕数加 1；如果某轮廓从左到右穿过射线，那么相应区域绕数减 1。非零填充规定：绕数不为 0 的区域为填充区域。正填充规定：绕数为正的区域为填充区域。负填充规定：绕数为负的区域为填充区域。这三种填充规则适用于那些轮廓存在相交情况的平面区域。图 8.13 展示了对同一图形基于以上四种不同填充规则最终得到的不同填充区域。

- 轮廓从右侧穿到射线左侧：+1
- 轮廓从左侧穿到射线右侧：-1

在 Clipper 库中，输入的轮廓按其作用可被分为两个类别，一类是 subject，另一类是 clip。下面我们结合四种布尔操作（参见图 8.13）对 subject 和 clip 轮廓的作用分别进行讨论。

- (1) 在两组轮廓的求交操作中，clip 轮廓相当于裁剪窗口，任何位于窗口外的 subject 轮廓都将被裁剪并舍弃，而位于窗口内的 subject 轮廓将被裁剪并保留，形成输出轮廓。对两组封闭轮廓来说，求交的结果就是两组轮廓同时覆盖到的平面区域，因此此时 subject 和 clip 是等价可交换的；但对于一组闭合轮廓和一组非闭合轮廓来说，只能由封闭轮廓作为 clip，非闭合轮廓作为 subject。
- (2) 在两组轮廓的求并操作中，subject 和 clip 轮廓是等价的。求并操作的结果是两组轮廓覆盖区域的和区域。
- (3) 在两组轮廓的求差操作中，如果用代数减法来类比，subject 轮廓充当被减数的作用，clip 充当减数作用，即 subject - clip，因此，最终的输出区域相当于从 subject 区域中扣除 clip 区域的剩余区域。
- (4) 在两组轮廓的异或操作中，subject 和 clip 轮廓也是等价的。异或操作的结果是输出两组区域并区域中扣除交区域的剩余区域。

接下来我们再来看一下 Clipper 库的接口类和函数。在我们定义的 Polyline 类中，顶点类型是 Point3D，且 Point3D 中点坐标的数据类型是浮点型。但是在 Clipper 库中，Path 顶点（C++中为 IntPoint 类，Python 中为 Point 类）坐标的数据类型是整型。这看起来有点不可思议，其实却是 Clipper 库的作者有意为之。事实上类似的问题我们在前面几章也遇到过，浮点型在运算过程中会不可避免地出现截断误差，而这些截断误差对于判断一个几何事件是否发生有时起着决定性作用，如线段是否相交、点是否在多边形内部等。采用整型数据运算从某种程度上来说可以规避因截断误差带来的误判风险，事实也证明在 Clipper 中运用整型点能够提升算法的稳定性和鲁棒性。

在 Python 环境下，如果我们使用命令行的方式安装 Clipper 库，那么库中最为核心的类是 Pyclipper 类。它封装了几个关键接口函数 AddPath/AddPaths、Execute/Execute2，其中 AddPaths 是 AddPath 函数的复数形式，用于一次性添加多条轮廓，Execute2 是 Execute 的重载函数，它们的功能相同但输出轮廓的组织形式有所差异。下面我们结合具体实例来看一下 Pyclipper 类的使用方法，我们把测试代码写在 Test_clipper.py 文件中。
