
self.intersect()
def intersect(self):
    # 扫描平面法截交实现函数
    triangles = self.stlModel.triangles
    # 赋值，保存引用，简化写法
    triangles.sort(key=lambda t: t.zMinPnt().z)
    # 对三角形按最低点 z 值升序排序
    zs = self.genLayerHeights()
    # 生成层高列表
    k = 0
    # 添加剖面遍历过程起始序号
    sweep = SweepPlane()
    # 扫描平面对象
    for z in zs:
        # 遍历层高列表循环
        for i in range(len(sweep.triangles) - 1, -1, -1):  # 1. 移除扫描平面面片列表中面片
            if z > sweep.triangles[i].zMaxPnt().z:
                del sweep.triangles[i]
        for i in range(k, len(triangles)):  # 2. 向扫描平面面片列表添加面片
            tri = triangles[i]
            if z >= tri.zMinPnt().z and z <= tri.zMaxPnt().z:
                sweep.triangles.append(tri)
            elif tri.zMinPnt().z > z:
                k = i
                # 对 k 赋值，下次从 k 开始遍历
                break
        layer = Layer(z)
        # 3. 面片列表和扫描平面求交
        for triangle in sweep.triangles:
            seg = intersectTriangleZPlane(triangle, z)
            if seg is not None:
                layer.segments.append(seg)  # 载交线段保存至 layer.segments 中
        self.layers.append(layer)

def genLayerHeights(self):
    # 生成切片层高列表函数
    xMin, xMax, yMin, yMax, zMin, zMax = self.stlModel.getBounds()  # 模型极点
    zs, z = [], zMin + self.layerThk
    while z < zMax:
        # 根据切片厚度均匀生成层高
        zs.append(z)
        z += self.layerThk
    return zs

以上 IntersectStl_sweep 类通过初始化 __init__ 函数输入 STL 模型和切片厚度参数，并在初始化函数中调用 intersect 核心函数完成模型和扫描平面截交计算功能，最终将得到的截交线段保存在列表 layers 中。以上 intersect 函数基本按照图 5.4 所示算法流程实现，有一点需要说明的是，在移除扫描平面面片列表循环（代码 5-2 中 15~17 行）中，我们使用了降序的方式遍历移除 sweep.triangles 中的三角面片，即从序号最大的面片开始向序号最小(0)的面片遍历，这并非我们一时兴起的写法，而是有意为之的。这是我们以前在 C++的编程实践中积攒的经验。在 C++中，若用 STL vector 保存数组，需要移除数组中间的某些元素：如果从数组前面开始移除，比如移除第 0 个元素后，数组中所有元素后面的元素都需要向前移动一个位置，以填补前面的空隙，这样会带来大量不必要的运算；而如果我们从数组后面开始移除元素，可以在一定程度上减少元素的移位次数，提高元素删除效率。

事实上，以上 intersect 函数仍然有可以进一步优化的地方。比如在代码中我们多次反复调用了 Triangle 类的 zMinPnt 和 zMaxPnt 两个函数，特别是在循环移除三角面片部分，而这两个函数内部都是通过若干次比较三角形顶点高低实现的，需要消耗一定的计算时间。我们可以为 Triangle 类添加几个属性，表示三角形在 Z 向的极大值和极小值，并事先为 STL 模型中的每个三角形计算这些极值，这样后续便可以直接使用这些极值，降低重复计算量。有兴趣的读者不妨尝试一下。

此外，在 IntersectStl_sweep 类中，我们还定义了 genLayerHeights 函数，其中 gen 为单词 generate 的缩写，意为生成。目前这个函数的功能是根据切片厚度参数生成并返回具有均匀层高特性的层高列表。我们之所以将这个功能从 intersect 函数中单独抽出来，是考虑到后期假如有非均匀层高切片的需求，我们只需修改这个函数的实现代码即可，其接口可以不用改变。


## 5.3 层高匹配法截交优化

在上一节中，我们介绍了一种基于扫描平面法的 STL 模型快速截交算法，无论是扫描平面法，还是我们最早介绍的暴力截交法，其本质思想都是尝试用截平面和 STL 模型中的所有三角面片求交，即求交时，截平面为主角，保持固定不变，三角面片为配角，不断被遍历更替。先人为主的思维定式驱使我们总是以截平面为主导来解决 STL 模型的截交问题。这一节我们不妨尝试转变一下思维，从 STL 模型中的三角面片出发，以面片为主角，截平面为配角，每次求交时，保持面片固定不变，不断遍历更替截平面。

### 5.3.1 层高匹配法原理

对输入的 STL 模型和切片厚度，假如事先我们已经生成了切片层高列表（这在上一节已经实现），现在我们考虑从 STL 模型中的三角面片出发，对每一个三角面片，遍历所有层高上的截平面，计算并保存截交线段。从全局的角度考虑，假设当前 STL 模型中的三角面片数量为 N，层高列表中层数为 M，那么从三角面片角度出发求交，所需的三角形和平面求交总次数为 N * M，这和从截平面角度出发的暴力截交法求交总次数无异（M * N）。既然如此，那为什么还要以三角面片为主导求交呢？

在以上讨论的求交过程中，我们忽略了非常容易排除的三角面片和截平面不相交的情形。我们应该还有印象，层高列表就是一组已经从小到大排好序的实数，这组实数代表了截平面在坐标系 Z 轴上的高度。对一个给定的三角面片，我们可以容易地把它在 Z 方向上包含的层高数值筛选出来。如图 5.5 所示，对 1 号三角面片，它包含的层高为 z9 ~ z14；对 2 号三角面片，它包含的层高为 z2 ~ z7；对 3 号三角面片，它包含的层高为 z7 ~ z14……当我们从三角面片的角度出发，在对 1 号面片求交时，只需依次求取该面片和高度为 z9 ~ z14 的 6 个截平面的交线即可，而无需遍历所有层高上的截平面，从而节省大量不必要的运算；在对其他三角面片求交时亦然。

那么接下来的问题就是如何找出每个三角面片包含的层高值。这又将涉及数据结构、算法和数据结构总是紧密关联的。还记得我们在上一章定义的 Triangle 类（参见代码 4-1）吗？当时我们为这个类预留了一个 zs 属性，这个属性正是为保存三角面片包含的层高数值用的。有了 Triangle 类，对已经排好序的层高列表（假设我们已经有了），我们不难设计为 STL 模型中每个三角面片匹配层高的算法。

和上一节介绍的扫描平面法类似，我们把层高匹配法涉及的相关类和函数封装在一个名为 IntersectStl_match.py 的文件中。我们在该文件中创建一个 IntersectStl_match 类，在类中封装一个简单的 matchFacetZs_brutal 函数，实现面片层高匹配功能，具体代码如下：

```python
IntersectStl_match.py matchFacetZs_brutal:将层高匹配到每个三角面片，暴力法 5-4
...... # 导入必要模块
class IntersectStl_match:
    def __init__(self, stlModel, layerThk): # 初始化，输入模型和层高
        self.stlModel = stlModel # 保存模型和层高
        self.layerThk = layerThk
        self.layers = [] # 切片结果，Layer 对象列表
        self.intersect() # 调用截交核心函数
    def intersect(self): pass # 截交核心函数定义，略
    def matchFacetZs_brutal(self, zs): # 暴力法层高匹配函数
        for tri in self.stlModel.triangles:
            zMin, zMax = tri.zMinPnt().z, tri.zMaxPnt().z # 面片最高点最低点
            for z in zs:
                if z > zMax: break
                if z >= zMin and z <= zMax: # 如果层高在面片最低最高点
                    tri.zs.append(z) # 之间，则将其加入面片
```

对以上 IntersectStl_match 类，我们先忽略其他代码，主要看一下 matchFacetZs_brutal 函数，该函数输入参数为层高列表 zs，注意，zs 在输入前必须已按照升序排序。

对 STL 模型中的每个三角面片，我们首先计算面片最低点和最高点的 z 坐标，即 zMin 和 zMax，然后从头开始遍历 zs 中每个元素（记为 z）：如果该 z <= zMax 且 z >= zMin，则将 z 添加至模型面片 zs 属性中；一旦出现 z > zMax 的情况，则退出当前面片的遍历过程。我们之所以可以在 z > zMax 时退出遍历循环，是因为层高列表 zs 已经做过升序排序，这样可以为我们节省一些遍历比较时间。

但是，如图 5.5 中的 1 号三角面片，当我们用以上方法匹配层高时，我们会发现，处在 z15 以上的层高比较过程确实可以被规避，但 z9 以下的层高只能逐个试探，只有 z9 ~ z14 的层高对 1 号面片来说是有用的。也就是说，层高下限（z9）的寻找只能从层高列表的开头开始遍历，这可能会浪费一定的时间，特别是对于相对位置较高的三角面片；而一旦找到了层高下限，层高上限（z14）就比较容易确定了。显然，matchFacetZs_brutal 函数采用了相对暴力的方法寻找层高下限，这也是我们给它加 brutal 后缀的原因。下面我们将考虑采用一个简单的二分法来加快层高上、下限的搜索速度。对于搜索问题，在找到更好的解决方案之前，二分法总会是一种不错的选择。

### 5.3.2 二分法层高匹配

如果我们对包含具体背景的三角面片层高匹配问题在数学上进行抽象，那么需要解决的问题可以描述为：

对序列 C = {z0, z1, z2, ..., zn}，满足 0 <= i < j <= n，则 zi <= zj，在 C 中寻找落在区间 [a, b] 中的所有元素，如图 5.6 所示。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_102_0.png)

显然如果 C 元素个数足够少，或者时间不是考虑的因素，那么我们可以逐个遍历 zs，找出落在 [a, b] 区间内的元素。但这里我们认为 C 包含足够多的元素，而且算法的执行时间是我们主要考量的指标。因为 C 中的元素满足单调递增的特性，因此我们只需在序列中找出落在 [a, b] 区间内的元素上、下限对应的序号即可。

首先我们来看一下下限的求取，即在 C 中搜索和 a 最接近的元素。就像其他二分法一样，我们先设 3 个变量：low、up、mid，在本例中，这 3 个变量为非负整数，表示 C 中元素的序号。二分法搜索下限具体步骤如下：

- (1) 初始化，令 low = 0, up = n。
- (2) 计算 mid 值, mid = (low + up) / 2 ,注意这里除法为整数除法。
- (3) 如果 z_mid < a ,则 low = mid ,否则 up = mid。
- (4) 如果 up - low <= 1 ,则退出循环,否则跳至步骤(2)。

以上二分法搜索循环在运行过程中,low 和 up 值不断更新,最终如果它们之间的差值不大于 1,则退出循环,算法收敛。此时 a 必然落在 z_low 和 z_up 内,即:z_low <= a <= z_up,则 z_up 必然包含在区间[a, b]内。但判断 z_low 是否在区间[a, b]内需要进一步判断不等式 z_low <= a 中的等号是否能够取到。我们当然可以从理论上去深入分析按以上二分法步骤执行 z_low 是否可能等于 a,或者退一步,我们可以直接比较一下 z_low 和 a 的值。如果 z_low = a,那么 C 中落在区间[a, b]的元素下限为 z_low ,否则下限为 z_up。

在得到下限后,我们再来看上限,即在 C 中搜索和 b 最接近的元素。求取上限的二分法步骤和以上求取下限的二分法步骤极其相似,只需将步骤(3)中的 z_mid < a 改成 z_mid < b 即可。最终 b 必然落在 z_low 和 z_up 内,即 z_low <= b <= z_up,此时 z_low 必然包含在区间[a, b]内。但判断 z_up 是否在区间[a, b]内需要进一步判断不等式 b <= z_up 中的等号是否能够取到。如果 z_up = b,那么 C 中落在区间[a, b]的元素上限为 z_up,否则上限为 z_low。

至此,我们已经解决了在这一小节开头提出的问题,准确定位了落在区间[a, b]内的 C 中元素上、下限序号。现在我们把注意力转回到针对三维打印的面片层高分配问题上,显然针对 STL 模型中的每个三角面片,在获得其最低点 zMin 和最高点 zMax 后,我们便能直接应用上面的二分法找出落在[zMin, zMax]内的层高值。

下面我们给出二分法层高匹配代码。我们依然把这部分代码写在 IntersectStl_match 类中,创建一个 matchFacetZs_bisection 函数,代码如下：

```python
IntersectStl_match.py matchFacetZs_bisection:将层高匹配到每个三角面片,二分法 5 - 5
...... # 导入必要模块
class IntersectStl_match: # 省略前面代码
    ...... # 二分法层高匹配函数
    def matchFacetZs_bisection(self, zs): # 层高列表元素个数
        n = len(zs) # 遍历模型中每个三角面片
        for tri in self.stlModel.triangles: # 面片最低点,最高点
            zMin, zMax = tri.zMinPnt().z, tri.zMaxPnt().z # 初始化 low,up,mid
            low, up, mid = 0, n - 1, 0 # 1. 二分法求下限序号

                mid = int((low + up) / 2)
                if zs[mid] < zMin: low = mid
                else: up = mid
            start = up # 下限序号 start
            if mid == zMin:
                start = low
            low, up = 0, n - 1 # 2. 二分法求上限序号
            while up - low > 1:
                mid = int((low + up) / 2)
```
