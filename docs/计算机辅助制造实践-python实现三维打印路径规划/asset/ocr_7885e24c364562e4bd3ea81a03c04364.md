由于问题本身特性，我们很难给出函数 f(θ) 代数解析式。但是，对于某一固定多边形区域，在填充角θ已知的情况下，我们可以通过本章 9.3 节中提及相关步骤计算出分区个数、进而计算出跳刀次数的。也就是说，对目标函数式（9-19），由θ到 J 的映射尽管很复杂，且无法表达成解析式，但映射过程却是非常明确的。理论上，对一般单目标优化问题，求解其最优解的过程就是求解目标函数导数为 0 时的解（类似于图 9.17）。显然，对跳刀次数的优化问题，我们无法采用这种求导的方式求解，那该怎么办呢？

# 9.5.2 跳刀优化计算原理

对以上跳刀优化问题的求解来说，如果我们没接触过任何优化算法（如遗传算法、粒子群算法等），可能是一种优势。这样我们在求解类似问题时会从问题本身出发，也许能想出一些直白但绝妙的解法。对上述问题，一种非常直观的求解思路是对目标函数进行正向计算，即直接在 0～180 度范围内遍历填充角度θ，计算每个θ对应的跳刀次数，然后从中找出跳刀次数最少时对应的填充角θ值。这种思路很简单，我们要做的就是对θ在 0～180 度范围内进行均匀细分取值，对每个细分角度θi，首先对输入多边形区域顺时针旋转θi 角度，然后调用 SplitRegion 类中的 findTurnPoints 函数（参见代码 9-9）计算并统计细分角度θi 下的凹峰点个数，最后再根据式（9-18）计算相应跳刀次数。

实现以上思路可能不需花费太多时间，但这种方法本身的计算效率不会太高。它的计算量主要取决于细分精度，比如，当细分精度为 0.01 度时，我们将得到 18000 个细分角度，也就是说，我们要对原始多边形进行 18000 次旋转操作，且对每次旋转后的多边形，对其各个顶点，我们要进行 18000 次遍历。由此，我们可以非常直观地感受到其中的计算量。在实际应用中，我们可能没必要将角度的细分精度设置得那么高，细分精度为 0.1 度就够了。

如果我们结合式（9-12）再对图 9.18 进行细致观察，就会发现，对原始多边形的旋转操作可能并非必要。如图 9.24 所示，已知 P 为多边形上的一个凹峰点，v₁、v₂ 分别为与 P 相邻两边的方向向量，vₛ为扫描线（或填充线）方向向量。根据峰值点定义，v₁、v₂ 应该分别在 vₛ两侧。反过来，在向量 v₁、v₂ 方向固定但 vₛ方向可变的前提下，只要 vₛ 落在 v₁、v₂ 之间，那么相对 vₛ 来说，P 点就是一个峰值点。据此，我们可以反算出顶点 P 成为峰值点时填充方向 vₛ 的角度范围，我们形象地称这个范围为 P 的切线角度范围（或切线角度），记为Ψ。同理，对输入多边形上的任意凹顶点 Pᵢ，我们可以找出它的切线角度范围Ψᵢ。
