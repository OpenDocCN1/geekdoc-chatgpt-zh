# 图 8.4 多边形单边平移偏置计算

```
Q1 = P1 + n.amplified(d)  # Q1 为 P1 的偏置点
Q2 = P2 + n.amplified(d)  # Q2 为 P2 的偏置点
```

通过以上代码,我们可以计算任意逆时针多边形每条边的向内偏置线段;如果多边形为顺时针方向,而以上代码不变,那得到的偏置线段将在多边形的外侧。类似地,如果需要计算一个逆时针多边形每条边的向外偏置线段,我们需要调整以上代码中向量 n 的方向,使其总是在线段的右侧。

接下来我们还是以逆时针多边形向内偏置为例展开讨论。在图 8.4 中,事实上,我们已经能够看出一些端倪:直接将偏置线段有序地放在一起是无法得到偏置多边形的,我们需要对它们进行修补。如图 8.5(a) 所示,如果多边形两相邻边所夹内角为优角(小于 180 度),那么它们对应的两条偏置线段必然相交,此时我们需要计算两偏置线段的交点,并在交点处对它们进行裁剪、连接。如图 8.5(b) 所示,如果多边形两相邻边所夹内角为劣角(大于 180 度),那么它们对应的两条偏置线段必然存在缝隙,此时我们需要考虑如何弥补这个缝隙,比如分别延长两条偏置线段然后在其交点处相连,或使用一段半径为偏置距离 d 的圆弧衔接这两条偏置线段。这里需要说明的是,如图 8.5(b) 所示,当我们用延长线去衔接偏置线段时,延长线上的点到原始轮廓上的距离将大于给定的偏置距离,这不符合我们对偏置线的定义,但是我们允许这种情况的存在,这其实是偏置过程中的一种妥协。
