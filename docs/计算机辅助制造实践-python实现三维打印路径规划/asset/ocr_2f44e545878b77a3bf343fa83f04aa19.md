# ## 9.5 最少跳刀填充方向优化

通过前面几节的介绍，对输入的多边形待填充区域，我们已经能够将其分割成若干单连通区域，并且在各个单连通区域内生成并连接得到了平行填充路径。在对多边形区域进行分区时，最终得到的单连通区域的个数和多边形上凹峰点的个数相关，它们之间的具体关系可由式(9-13)表示，即分区个数等于两倍的凹峰点个数加 1。根据式(9-9)可知，多边形中凹顶点的个数仅和多边形自身形状有关，而和填充方向无关。根据式(9-12)可知，多边形中峰值顶点个数不仅和多边形自身形状有关，而且和填充方向有关。考虑到给定多边形形状不可改变，因此，多边形中凹峰点的个数仅和填充方向有关，即分区得到的单连通区域个数仅和填充方向有关。

对平行填充路径来说，显然，分区时得到的单连通区域的个数越少，后续的路径连接就越简单，需要的“跳刀”次数就越少。如果仅考虑单连通区域间平行路径的连接问题，那么跳刀次数和单连通区域个数的关系为：

```
N_j = N_s - 1
```

其中, N_j 为跳刀次数, N_s 为单连通区域个数。结合以上分析，对一个给定多边形区域，跳刀次数也仅和填充方向有关。理论上, 当填充角度从 0～360 度（考虑角度冗余情况, 事实上是 0～180 度）变化时, 必然存在一个最优的角度值, 使得沿着这个角度对输入多边形区域进行分区时, 生成的单连通区域个数最少, 即跳刀次数最少。

我们在这一节的任务就是以减少跳刀次数为目标, 找出最优填充角度。需要说明的是, 这部分工作相对独立, 由这一节得到优化填充角度可作为参数直接输入 genDpPath 函数中(参见代码 9-12), 用于生成最小跳刀平行路径。

# ### 9.5.1 目标函数建立

一般来说, 对优化问题, 我们首先需要建立目标函数。目标函数就是所关心的目标（某一变量）和相关因素（某些变量）的函数关系。如果目标只有一个, 我们称这种优化问题为单目标优化; 如果目标有多个, 我们称这种优化问题为多目标优化。

对于我们在这一节要解决的跳刀优化问题, 它的目标是减少跳刀次数, 影响因素是填充角度。显然, 这是一个单目标、单因素的优化问题, 其目标函数可以写成:
