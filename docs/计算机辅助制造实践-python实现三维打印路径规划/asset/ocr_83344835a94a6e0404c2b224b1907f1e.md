事实上，以上 intersect 函数仍然有可以进一步优化的地方。比如在代码中我们多次反复调用了 Triangle 类的 zMinPnt 和 zMaxPnt 两个函数，特别是在循环移除三角面片部分，而这两个函数内部都是通过若干次比较三角形顶点高低实现的，需要消耗一定的计算时间。我们可以为 Triangle 类添加几个属性，表示三角形在 Z 向的极大值和极小值，并事先为 STL 模型中的每个三角形计算这些极值，这样后续便可以直接使用这些极值，降低重复计算量。有兴趣的读者不妨尝试一下。

此外，在 IntersectStl_sweep 类中，我们还定义了 genLayerHeights 函数，其中 gen 为单词 generate 的缩写，意为生成。目前这个函数的功能是根据切片厚度参数生成并返回具有均匀层高特性的层高列表。我们之所以将这个功能从 intersect 函数中单独抽出来，是考虑到后期假如有非均匀层高切片的需求，我们只需修改这个函数的实现代码即可，其接口可以不用改变。

现在，我们已经实现了基于扫描平面法的 STL 模型载交算法，我们可以参照下列语句使用该算法：

```
layers = IntersectStl_sweep(stlModel, layerThk).layers
```

其中 stlModel 为事先读取的 StlModel 对象，layerThk 为事先指定的层高，layers 用于保存计算得到的截交线段。
