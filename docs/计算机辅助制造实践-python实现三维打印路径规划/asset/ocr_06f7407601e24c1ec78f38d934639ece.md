最后需要说明的是，在代码 9-7 中，我们使用了 Utility 模块中的一个函数，degToRad，这个函数的作用就是将角度转化为弧度。原则上，它应该还有一个对偶函数，radToDeg，作用是将弧度转化为角度。这两个函数虽然简单，但非常通用，因此我们把它们放在 Utility 模块中，它们的实现如下：

# 9.3 填充区域分区

在前面两节，我们使用了两种方法分别生成了给定平面区域的填充线，一种是我们实现的扫描线法生成填充线，另一种是运用现成的 Clipper 库通过裁剪的方式生成填充线。我们知道，由于 Clipper 库内核使用 C++编写，因此上文中的 genClipHatches 函数相比于 genSweepHatches 函数在运行速度上具有先天优势(经简单测试，前者比后者效率高一倍左右)，但这种优势是相对的，后者可以通过更换编程语言来弥补不足。并且后者相对于前者更为实用，其中最重要的特征就是后者生成的填充线在平面上的分布是完全可控的，这有利于填充路径连接。我们在这一节将基于扫描线法生成的填充线展开进一步研究，最终目标是将得到的离散填充线段连成一体，形成平行路径。
