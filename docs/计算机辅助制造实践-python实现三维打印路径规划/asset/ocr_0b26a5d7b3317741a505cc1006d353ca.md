# 第 8 章 轮廓平行填充路径生成

# 引言

三维打印是一种典型的“降维”制造方式，它的工艺特点是逐层堆叠生长，三维打印路径规划的作用就是将复杂的三维模型转化为一系列相对简单的二维刀具路径（toopath）。在前面几章，针对输入的 STL 模型，我们介绍了多种不同的切片方法，得到了各个切层上的轮廓数据。从本章开始，我们将从切片轮廓出发，在这些轮廓表示的打印区域内部，生成能够覆盖这些区域且适应于三维打印工艺要求的刀具路径，我们把这些路径统称为填充路径。在三维打印中，最为常用的填充路径包括轮廓平行（contour—parallel）填充路径和方向平行（direction—parallel）填充路径，这一章我们主要介绍轮廓平行填充路径的生成原理和方法。

# 8.1 常用填充路径概述

在指定层高上，三维打印路径规划的本质是在工艺条件约束下的打印区域填充问题。理论上，对任意形式或任何方法生成的曲线，只要它能够满足打印工艺要求，且能覆盖平面上的整个打印区域，那么它就可以被当作是一种有效的三维打印填充路径。尽管如此，在三维打印中，真正实用的填充路径种类不多，其中最为常用的填充路径仍然是轮廓平行填充路径和方向平行填充路径。我们先来看一下这两种填充路径的概貌，如图 8.1 所示。
