# # 第 10 章 支撑生成与优化

# ## 引 言

通过前面几章介绍，对任意一个三维模型，我们已经能够为其切片，并在得到的轮廓内部生成轮廓填充路径和平行行填充路径。对减材性质的切削加工来说，这些算法足以应付简单的以层切为主的粗加工；但对三维打印应用来说，仅依靠这些算法是不够的。三维打印是一种典型的增材制造过程，根据其成形工艺特点，在工件从无到有的变化过程中，如果遭遇尺寸较大的悬臂结构，即在某层切片下方没有上一层切片材料为其托底，打印将无法正常继续进行。因此，如果模型上存在悬臂结构，我们必须考虑在悬臂下方添加支撑材料，并生成相应的支撑填充路径。那如何识别模型上的悬臂结构？是否只有在水平的悬臂结构下才需要添加支撑？在得到了需要支撑的空间之后又该如何生成支撑路径？这些问题都是我们在本章需要解答的。

# ## 10.1 支撑生成概述

对三维打印来说，如果模型上存在宏观悬臂结构，那么我们可能需要在其下方添加一定量的支撑，否则悬臂材料可能因无处依附而塌陷，导致打印无法正常进行。为三维模型上的悬臂结构添加支撑的首要任务是找出模型上的悬臂特征。但是，对大多数三维模型文件格式来说，一般它们只保存模型的点线面等基础几何信息，而不会保存模型内部复杂的逻辑特征信息。比如对三维打印常用的 STL 模型格式来说，它保存的就是围成模型所有三角面片的顶点坐标和法向量信息，而且每个三角面片在模型中是无序摆放的，即对模型来说，每个三角面片的权重或意义是别无二致的。在这种情况下，我们必须借助相应算法，对模型进行分析，才能找出模型上的悬臂特征。

图 10.1 给出了一个悬臂特征非常明显的倒“L”形模型，结合该模型，我们可以直观地发现：当模型中面片和水平面垂直时（如图中向量 n₁ 对应面片），我们无需为其添加任何支撑，我们不妨称这种不需要支撑的面片为非悬臂面片或安全面片；相反地，当模型中面片和水平面平行时（如图中向量 n₂ 对应面片），我们需要为其添加支撑，否则打印将无法进行，我们不妨称这种需要支撑的面片为悬臂面片或危险面片。因此，原则上，我们只需计算 STL 模型中所有三角面片和水平面的夹角，就能找出所有需要添加支撑的危险面片。进一步地，我们发现，面片和水平面的夹角事实上等同于面片法向量和竖直方向（即坐标系 Z 轴方向）的夹角（记为 θ），如图 10.2 所示，因此，理论上，我们可以通过计算后者来确定模型上的危险面片。
