以上我们讨论了两种极端的情况，即当面片和水平面夹角 θ = 90 度时，认为对应的面片为安全面片，而当 θ = 0 度时，认为对应的面片为危险面片。

在实际三维打印应用中，对模型上面片安全或危险属性的判断并非如此极端。显然，在 0 到 90 度范围内，θ 值越大，面片越安全；θ 值越小，面片越危险。

一般来说，在计算中，我们会根据三维打印的工艺类型及材料属性为上述夹角设定一个临界值 θ₀ (如 60 度)，并认为：当实际 θ > θ₀ 时，面片为安全面片；当 θ ⩽ θ₀ 时，面片为危险面片。我们称 θ₀ 为支撑临界角。

根据上述支撑临界角 θ₀ 定义，结合各面片法向量，我们不难找出模型中的所有危险面片，接下来我们要做的就是在这些危险面片的下方确定需要添加支撑的空间区域。

不难想像，对每个危险面片来说，它的支撑区域就是位于其下方竖直投影空间内的三棱柱，如图 10.3 所示，其中三棱柱的上端面就是危险面片本身，而下端面可能立于工作台面，也可能位于模型上，分别对应三维打印的两种支撑类型：支撑到底面（即工作台）或支撑到模型，如图 10.4 所示，本章下文将针对生成所有支撑展开叙述。

如果不加处理，直接对每个危险面片使用竖直投影法生成支撑空间，那最终我们将得到一系列瘦长的三棱柱，特别是当三角面片尺寸较小的时候。这可能不是我们想要看到的结果，因为我们希望将相邻的三棱柱空间连成一体，得到尺寸相对较大的成片支撑空间，以便我们在它的内部生成支撑路径。
