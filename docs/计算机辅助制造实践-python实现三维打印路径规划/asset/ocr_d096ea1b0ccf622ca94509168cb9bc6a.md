近的局部自相交环。接下来我们可以使用在上一小节中介绍的绕数统计规则来统计由初始偏置曲线围成的各个区域的绕数。从图 8.15 各个区域标记的绕数可知,无论是局部还是全局,自相交区域内的绕数均为 1,而合法偏置区域内的绕数为-1,因此,我们可以用四种填充规则中的负填充规则来识别并提取合法偏置区域。当然这一过程需要 Clipper 库布尔运算支持,它的代码大致如下：

| | 初始偏置曲线上负填充区域提取 | 8 - 4 |
|---|---|---|
| 1 | clipper = Pyclipper() | # 定义 Pyclipper 对象 clipper |
| 2 | clipper.AddPaths(offsetPolys, PT_SUBJECT, True) | # 添加初始偏置轮廓作为 subject |
| 3 | sln = clipper.Execute(CT_UNION, PFT_NEGTIVE) | # 执行 union 操作,填充规则为负填充 |

在以上代码中,我们通过布尔并操作( CT_UNION ),结合负填充规则( PFT_NEGTIVE )消除所有绕数为正的偏置自相交环,最终返回的 sln 就是目标合法偏置区域的边界线,也就是我们所要求的偏置曲线。注意,Clipper 库在执行布尔并操作时,是允许仅添加一种类型的待处理轮廓( 即 subject ),这是因为对布尔并运算来说,subject 轮廓和 clip 轮廓是等价的,对此我们在前一小节已经有所解释。
