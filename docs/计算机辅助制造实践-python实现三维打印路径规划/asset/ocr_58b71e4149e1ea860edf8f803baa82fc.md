findParent 函数寻找所有偏置曲线的直系父曲线，然后逐一将 OffsetPolyses 中的每条曲线通过 linkToParent 函数桥接到直系父曲线即可。这里必须注意的是，在桥接得到新曲线后，我们用新曲线上的点( Polyline 的 points 属性)替换原直系父曲线上的点，而不是直接用新曲线(newPoly)替换直系父曲线，这样做是为了保持 OffsetPolyses 中曲线元素的地址不变。试想，如果我们直接用新曲线替换原直系父曲线，那么我们将无法再用 OffsetPolyses 索引到新曲线。事实上，在以上代码中，这么操作的根本原因在于我们是通过直系子曲线的 parent 属性索引到直系父曲线的，我们并不知道这条直系父曲线在 OffsetPolyses 中的索引序号；假如我们知道它的序号，如 s 和 t，那么我们可以通过 OffsetPolyses[s][t] = newPoly 来实现曲线的直接替换。此外，在将直系子曲线桥接到直系父曲线后，我们还需注意的是必须从 OffsetPolyses 中移除相应直系子曲线。最后，在将各级直系子曲线桥接到直系父曲线后，OffsetPolyses 应该只保留若干原最外层的曲线地址，我们只需将这些曲线转存到 GenCpPath 类的 paths 属性即可，paths 就是 GenCpPath 最终输出的已经将所有偏置曲线连成一体的轮廓路径。

我们知道，paths 中路径的数量和原 OffsetPolyses 中最外层偏置曲线的数量一致。这些路径之间的连接只能通过“跳刀”的方式实现。对数控加工来说，跳刀意味着刀具从一条路径的终点抬起至安全平面，然后在安全平面上移动至另一条路径的起点上方，最后下降至另一条路径的起点。对数控加工来说，跳刀可以避免刀具在大幅移动过程中和工件发生干涉；但跳刀是一种无效切削过程，因此在路径规划中应尽量缩短跳刀路径长度。对 FDM 三维打印来说，我们无需抬起喷头，只需保证在跳刀过程中喷头不出丝材即可。
