# 图 9.15 扫描线位置和区域切分关系

下平移后，我们都将无法得到全是单连通区域的子区域。

下面我们再来看一下切分直线 l 的位置确定方法。如图 9.15 所示，我们知道，在直线 l 上时，扫描线和区域轮廓的交点个数恰好发生了变化，即此时扫描线和区域轮廓之间多了（或少了，从高往低扫描时）一个交点，这里我们不妨记这个交点为 P。根据这一特性，理论上，我们可以将扫描高度间距设置为一个趋向 0 的正实数，当我们从下至上遍历这些扫描高度时，必然能够找出扫描线和区域轮廓交点数量恰好发生变化的那个扫描高度，进而确定交点 P 以及直线 l 位置。但以上方案显然不具备实际可操作性。

进一步观察我们会发现，事实上，以上交点 P 是区域轮廓的一个局部峰值点。这是合乎情理的，在扫描线移动过程中，必然首先会和轮廓的峰值点相交。因此我们得出如下结论：能够将输入多连通区域分割成若干单连通区域的切分直线必然经过轮廓的峰值点。这个结论当然是没有问题的，那反过来呢？是否所有经过轮廓峰值点的直线都可以将多连通区域切分为单连通区域呢？如图 9.15 所示，对图中的 3 个峰值点 A、B、P，我们发现，过 A 点和 B 点的直线并不能将区域切分成单连通区域，只有过 P 点的直线才能对区域进行有效切分。进一步观察，我们发现，A 点和 B 点是局部凸起轮廓上的点，而 P 点是局部凹陷轮廓上的点。如果我们称像 P 这样的点为凹峰点的话，那么，我们推断：只有经过轮廓凹峰点的直线才可以将多连通区域切分成若干单连通区域。因此，要确定切分直线的位置，我们必须首先找出区域轮廓上的凹点，然后从这些凹点中找出凹峰点。

对于一个由一组简单多边形围成的任意平面区域，如果各多边形的方向符合“外逆内顺”的规定，那么我们可以使用向量叉乘法确定轮廓上的某一点 Pk 是否为凹点，步骤如下：

+   (1) 计算向量 v_k、v_{k+1}，使得：

```
v_k = P_k - P_{k-1}                     (9-7)
v_{k+1} = P_{k+1} - P_k                  (9-8)
```
