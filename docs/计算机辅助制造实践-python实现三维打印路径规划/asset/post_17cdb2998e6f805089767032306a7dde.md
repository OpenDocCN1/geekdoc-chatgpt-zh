## 第 11 章 端面封闭与代码生成

### 引言

这一章我们将解决三维打印路径生成的最后两个问题。首先是三维模型上、下端面的封闭问题，这是一个极易被忽视的问题。在对模型内部进行填充时，为了节省打印材料和时间，我们通常会设置相对较大的填充间距；但对模型的上下端面及其附近切片层，为了保证模型表面的封闭性，我们必须设置较小的填充间距进行密实填充。为此，我们必须解决模型上下端面的识别问题。在此基础上，我们将汇总本书各章节涉及的路径规划算法，包括模型切片、端面识别、轮廓填充路径生成、平行填充路径生成、支撑路径生成等，结合相应打印工艺参数，封装一个专门用于三维打印综合路径生成和后处理的模块，最终生成可被三维打印机识别的 NC 代码。

### 11.1 端面识别与切片分区

三维打印分层叠加制造的工艺特点决定了在垂直于模型生长方向的平面上，将出现一系列端面，其中最典型的就是模型的上端面和下端面。以圆柱体模型为例，如图 11.1(a)，如果圆柱轴线平行于坐标系 Z 轴，那么圆柱的底面就是端面，其中下底面就是下端面，上底面就是上端面。显然，我们需要在三维打印中对端面及其附近进行密实填充，以封闭模型。从填充路径生成的角度来说，对模型端面切片，我们必须设置较小的路径间距（事实上恰为喷头直径），以保证填充后路径之间无间隙。考虑到我们已经在本书第 8、第 9 章对填充路径的生成方法进行了详细介绍，因此只要合理设置填充参数，对端面进行密实填充是容易实现的。问题是如何识别模型上的端面，特别是对于那些较为复杂的模型，如图 11.1(b)。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_296_0.png)

## 图 11.1 三维模型上的上端面和下端面

理论上，对输入的三维模型，我们可以根据法向朝向判断一个面片是否落在端面上，但这样的判断对端面填充是毫无意义的，因为在切片过程中，模型上的端面信息无法传递到切片片数据。通过前面几章的介绍，我们已经能够对任意模型进行切片，生成一系列切片，下面我们不妨抛开模型本身，直接从已有切片数据出发，识别切片上的端面。

### 11.1.1 端面密实填充区域提取

我们首先来看下端面的识别。如图 11.2 所示，对任意封闭轮廓 c1、c2 分别位于相邻的第 i、i+1 层切片上（方便起见，在下面的叙述中，我们不打算对轮廓和切片层两个概念进行严格区分，即用轮廓表示切片层），图中阴影区域就是暴露在模型外需要被封闭填充的下端面。我们不妨记上述阴影区域轮廓为 d，根据平面区域的布尔运算原理（参见图 8.14），很简单，我们只需对轮廓 c2 和 c1 做布尔差运算，即让 c2 减去 c1，就可得到轮廓 d，即

d = c2 - c1 (11-1)

需要说明的是，轮廓 c1、c2 并非位于同一平面上，在对两轮廓做布尔差运算时，需要忽略轮廓上点的 z 坐标；而对得到的差轮廓 d，需要对其 z 坐标进行取舍，使其落在 c2 所在的平面上。进一步地，如果我们对轮廓 c1 和 c2 求交，或者让轮廓 c2 减去 d，就可求得 c1、c2 位于模型内部的重叠部分，即 d 关于 c2 的互补轮廓，我们不妨记这部分轮廓为 d̄。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_297_0.png)

如图 11.2 所示，通过布尔运算，我们将上层切片轮廓 c2 围成的区域分成了两个部分，一个为 d，另一个为 d̄。其中 d 就是模型下端面，必须进行密实填充；而对于 d̄，为了节省材料，同时节约打印时间，可以进行稀疏填充。

尽管如此，我们忽略了两个重要因素。其中第一个因素和填充路径形式有关。为了保证模型表面精度和整体打印效率，我们一般会在打印区域外围使用轮廓填充路径，而在区域内部使用平行填充路径。考虑到以上得到的两个区域 d、d̄ 同属 c2，为了避免在工件表面出现轮廓拼接印记，在生成路径时，它们应该共用轮廓 c2 的偏置曲线作为轮廓填充路径。第二个因素和密实填充部分打印强度有关。如图 11.2 所示，以上 d、d̄ 两个区域划分最不合理的地方在于没有为 d 留出一定的过渡区域，恰好在 d、d̄ 边界进行疏密填充切换并不十分理想，只会降低模型下端面强度，削弱其对上方材料的支撑作用。较为理想的密实填充边界应向 d̄ 区域延伸一定的距离。

根据以上分析，我们必须对 d、d̄ 两个区域进行修正。首先我们不妨考虑对 d 区域向外延伸，方法是求取轮廓 d 的向外偏置曲线 doo(下标表示 offset outside)，偏置距离为 xo，如图 11.3(a) 所示。通过以上操作，区域 d 确实向 d̄ 延伸了一段距离，这有利于提升下端面的支撑强度；但同时，doo 在不该延伸的 c1、c2 轮廓外侧也得到了延伸，这是我们不希望看到的。为了进一步修正这种情况，同时为 c2 区域外围预留一定的轮廓填充空间，我们可以对 c2 进行向内偏置，偏置距离为 xi，得到偏置曲线 c2oi(offset inside)，如图 11.3(b) 所示。对得到的两条偏置曲线 doo 和 c2oi，我们可以进一步对它们进行求交操作，如图 11.3(c) 所示，得到最终密实填充区域，记为 f(full fill)，即

f = doo ∩ c2oi  (11-2)

同时，只要将偏置轮廓 c2oi 减去 f，就可以得到稀疏填充区域，如图 11.3(d) 所示，记为 s(sparse fill)，则

s = c2oi - f  (11-3)

需要再次说明的是，以上得到的轮廓 f、s 均在轮廓 c2 所在的平面上。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_298_0.png)

## 图 11.3 下端面密实填充区提取流程

在以上讨论中，我们暂记从轮廓 c2 到 c2oi 的偏置距离为 xi，事实上，这里的 xi 就是我们在本书第 8 章中讨论过的轮廓路径填充带宽(参见代码 8-7)，它表示打印后模型的外壳厚度。在第 8 章中，我们是用 shellThk 参数表示轮廓路径填充带宽的，这里我们不妨沿用这个参数。此外，我们暂记从轮廓 d 到 doo 的偏置距离为 xo，xo 值表示了密实填充的端面向模型内部的延伸或重叠量，简单起见，这里我们不妨直接对 xo 赋 shellThk 值。综上所述，在数值上，以上 xo = xi = shellThk。

必须说明的是，在以上推导过程中，为了方便说明和理解，我们默认轮廓 c1、c2、d、f、s 等均为单一曲线；但事实上，每个符号都可以表示一组轮廓，如 c1、c2 可以分别表示指定切片层上的若干轮廓,f,s 可以表示若干密实填充区域轮廓和若干稀疏填充区域轮廓。

回到图 11.2 和图 11.3,在以上讨论中,我们默认了一种情况,即 c1,c2所表示的上、下层轮廓之间存在一定的偏差(d),这种偏差在 c2区域内表现为模型下端面。但实际情况可能是 c1,c2形状大小完全一致,或它们之间存在偏差,但偏差很小,此时,在 c2区域内是否仍存在下端面? 我们该如何根据偏差的大小判断切片上是否存在下端面? 如果存在下端面,那么整个下端面 d 需要被密实填充,而对 d 区域外围,我们使用轮廓路径进行填充,填充带宽为 shellThk。注意,轮廓填充本身就是一种密实填充方式! 因此,如图 11.4 所示,如果记

e = c2oi - c1 (11-4)

且 e 不为空(空就是轮廓上的点个数为 0 或轮廓序列中的元素个数为 0),则 c2所在的切片存在下端面,此时我们需要进一步通过式(11-2)和(11-3)计算该切片的密实填充区 f 和稀疏填充区 s;反之,如果 e 为空,则 c2所在的切片不存在下端面,此时由 c2oi 围成的区域全为稀疏填充区。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_299_0.png)

| 13 | layer2.ffContours = f | # 对切片密实填充轮廓赋值 |
| 14 | return True | # 返回 True |

我们看到，以上实现的 pickFfRegions 函数有 3 个输入参数，包括 layer1、layer2 以及 shellThk，其中前两个参数表示相邻两切片层，且 layer2 位于 layer1 上方，shellThk 参数的含义我们已经在上文给出了解释，表示轮廓路径填充带宽或外壳厚度。函数的返回为 True 或 False，即如果找到密实填充区，返回 True，否则返回 False。

从以上代码可以看出，pickFfRegions 函数的实现过程基本遵循图 11.3 给出的密实区域提取流程，但更加严格，我们通过设置一系列判断来保证函数运行的正确性和稳定性。比如，在得到 c2 的向内偏置曲线 c2oi 后，如果 c2oi 为空，则函数直接返回 False，表明此时 c2 区域过小，使用轮廓填充已经足够覆盖整个区域，无需再进行内部密实填充。此外，在根据式(11-1) 和式(11-4) 分别计算 d 和 e 区域时，我们增加了一个判断条件，即如果 c1 为空，则 d = c2，e = c2oi，这是因为我们使用的 Clipper 库无法接受空集作为参数。

在函数中，我们将通过布尔运算得到的密实填充区 f 保存至切片 layer2 的 ffContours 中，同时将轮廓填充的内边界 c2oi 保存至 layer2 的 shellContours 中，留作后用。为此，我们对 Layer 类（参见代码 4-5）进行了扩充，在其初始化函数中增加了 shellContours、ffContours 以及 sfContours 三个属性，其中 sfContours 用于保存切片上的稀疏填充区域边界，“sf” 为 sparse fill 的缩写。需要说明的是，在使用 Python 语言编程时，我们选择在 Layer 类的初始化函数中为类添加属性，而并非像在 FindSptRegion 类的 execute 函数（参见代码 10-7）中一样，动态添加属性。这是因为在 pickFfRegions 函数中，我们无法遍历一个模型的所有切片。为 Layer 类添加上述属性的具体代码如下：
