下面我们需要确定偏置点到 P2 的距离。如图 8.9(a) 所示，我们不妨记偏置点为 Q，Q 在 P1P2 上的投影为 D，则在三角形 QDP2 中，QD 长度为已知量（即给定的偏置距离），我们只需知道 ∠QP2D 的角度（记为 0，即 theta），便可算出斜边 P2Q 的长度（记为 L）。在此基础上，我们可以得到偏置点 Q 的坐标。需要说明的是，尽管以上推导是针对图 8.9(a) 所示的优角情况做出的，但同样适用于图 8.9(b) 所示的劣角情况。综上，计算偏置点的具体代码如下：

```

```
