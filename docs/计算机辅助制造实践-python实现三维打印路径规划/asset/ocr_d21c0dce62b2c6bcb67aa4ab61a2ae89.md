# FDM 三维打印机控制方法

为了更加直观地测试根据本书算法生成的三维打印 NC 代码，在这个附录里，我们将介绍基于 Marlin 固件的 FDM 三维打印机串口控制方法，使用的编程语言仍然为 Python，首先我们介绍 Marlin 固件。

Marlin 固件是一种 FDM 三维打印的开源固件。这里固件是指三维打印机控制器的嵌入式软件，其作用是解释并执行上位机发来的 NC 指令。相比于其他三维打印机固件，Marlin 最为健全和强大。它的功能包括：控制板驱动、NC 代码解析、插补运算、多轴步进运动控制、热床及喷头温度控制、SD 卡读写、LCD 显示等。表附 1.1 列出了 Marlin 固件常用的 G 代码及 M 代码功能。
