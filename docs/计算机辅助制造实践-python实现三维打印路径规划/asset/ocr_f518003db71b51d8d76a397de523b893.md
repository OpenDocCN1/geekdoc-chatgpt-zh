# 5.3 层高匹配法截交优化

在上一节中，我们介绍了一种基于扫描平面法的 STL 模型快速截交算法，无论是扫描平面法，还是我们最早介绍的暴力截交法，其本质思想都是尝试用截平面和 STL 模型中的所有三角面片求交，即求交时，截平面为主角，保持固定不变，三角面片为配角，不断被遍历更替。先人为主的思维定式驱使我们总是以截平面为主导来解决 STL 模型的截交问题。这一节我们不妨尝试转变一下思维，从 STL 模型中的三角面片出发，以面片为主角，截平面为配角，每次求交时，保持面片固定不变，不断遍历更替截平面。

# 5.3.1 层高匹配法原理

对输入的 STL 模型和切片厚度，假如事先我们已经生成了切片层高列表（这在上一节已经实现），现在我们考虑从 STL 模型中的三角面片出发，对每一个三角面片，遍历所有层高上的截平面，计算并保存截交线段。从全局的角度考虑，假设当前 STL 模型中的三角面片数量为 N，层高列表中层数为 M，那么从三角面片角度出发求交，所需的三角形和平面求交总次数为 N * M，这和从截平面角度出发的暴力截交法求交总次数无异（M * N）。既然如此，那为什么还要以三角面片为主导求交呢？

在以上讨论的求交过程中，我们忽略了非常容易排除的三角面片和截平面不相交的情形。我们应该还有印象，层高列表就是一组已经从小到大排好序的实数，这组实数代表了截平面在坐标系 Z 轴上的高度。对一个给定的三角面片，我们可以容易地把它在 Z 方向上包含的层高数值筛选出来。如图 5.5 所示，对 1 号三角面片，它包含的层高为 z9 ~ z14；对 2 号三角面片，它包含的层高为 z2 ~ z7；对 3 号三角面片，它包含的层高为 z7 ~ z14……当我们从三角面片的角度出发，在对 1 号面片求交时，只需依次求取该面片和高度为 z9 ~ z14 的 6 个截平面的交线即可，而无需遍历所有层高上的截平面，从而节省大量不必要的运算；在对其他三角面片求交时亦然。
