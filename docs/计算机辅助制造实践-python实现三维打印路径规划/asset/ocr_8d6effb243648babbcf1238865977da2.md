的空间位置。其次，这个顶点被若干个三角面片共用，因此在顶点内部，应该有一个面片指针列表，用来保存所有用到该顶点的三角面片指针（引用）。在 STL 模型中，一个顶点至少被 3 个三角面片共用，但具体多少个三角面片会共用一个顶点，我们是无法确定的。此外，一个顶点还被若干棱边共用，因此在顶点内部，理应还有一个棱边指针列表，用来保存所有用到该顶点的棱边指针（引用）。在下面介绍的面片对象中，已经保存了棱边信息，而我们在顶点中已经保存了面片，因此，我们可以间接地从顶点存储的面片中找到相应的棱边信息。基于此，同时也为了简化顶点结构，我们顶点中不设置棱边指针。
