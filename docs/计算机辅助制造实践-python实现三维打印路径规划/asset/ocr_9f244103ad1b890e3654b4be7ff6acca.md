在以上代码中,我们主要实现了基于字典查询法的线段拼接核心功能函数 link,该函数基本还原了图 6.6 所示的拼接流程,从字典构建到第 1 层循环,再到第 2 层循环。除了这个核心函数外,我们还实现了在 link 中被调用到的两个子函数,一个是 findUnusedPnt, 另一个是 findNextPnt。

顾名思义,函数 findUnusedPnt 的作用就是在字典中寻找一个没有被使用过的点,它遍历的是字典的值(values)而非键,它的返回值为点本身(对象本身,或者叫指针或引用)或 None,如果返回 None 则表明在字典中所有点都已经被使用过。注意,这里这个函数的返回值类型和 LinkSegs\_dorder 类中的同名函数返回值是不一样的,在那个类中, findUnusedPnt 函数的返回值为点在列表中的序号(整数)。

函数 findNextPnt 的作用是根据当前点从 dic 中查询下一个可以被直接添加到多段线 poly 中的点。这个函数看似简单,只有寥寥数行,但它才是真正体现字典查询拼接算法精妙的地方。它的精妙之处就是通过字典结构,将两个坐标重合的点绑定在一起,从其中一个点能很快查询到另一个点。在第 2 层循环中,findNextPnt 也起到了承上启下的作用,正是这个函数的巧妙设计,让第 2 层循环以最简单的形式不断运转。
