够非常好地跟随，还原轮廓形状，从而保证被打印模型的外观精度。但由于轮廓路径形状复杂，弯曲频繁，路径上曲率变化通常较大，最终导致打印机各轴电机频繁加减速，因此相对来说，轮廓路径的打印效率不高。如图 8.2 所示，在对形状精度要求不高的打印区域内部，我们一般会去填充平行路径。平行路径在边缘处精度不高，在还原轮廓原貌时会出现难以避免的锯齿现象。从整体来看，虽然平行路径确实在每条线段的端点处方向不断变化，但至少在每条平行线段内部，路径的方向是恒定不变的，这样，打印机就能始终以设定的最高打印速度进给，从而保证打印效率。根据以上分析，我们知道，对一打印区域的外部使用轮廓填充，内部使用平行填充，既可以保证模型外观精度，同时还可以保证打印效率，确实比采用单一的填充路径更为合理。

# ## 8.2 轮廓偏置基础方法简介

通过以上介绍，我们知道，生成轮廓平行填充路径的基础是平面曲线的等距偏置算法。更准确地，对 STL 模型的三维打印来说，因为我们得到的切片轮廓都是平面简单多边形(封闭点列曲线)，即不存在自相交情况的平面多边形，因此生成轮廓路径的基础是平面简单多边形的等距偏置算法。在以下讨论中，考虑到我们讨论的对象都是平面简单多边形，而且偏置都是等距的，简单起见，描述时我们忽略多边形前面“平面简单”的前缀和偏置前面“等距”的前缀。

多边形的偏置问题是一个传统而通用的平面几何问题，但却非常基础和重要，在数控加工中的刀具半径补偿、路径规划以及平面设计等领域都有广泛应用。如果我们使用严格的数学语言描述，那么这个问题可以定义为：对一个输入多边形，在其一侧生成一个(或多个)新的多边形，使得新多边形上的每点到原始多边形的距离为给定的偏置距离。如果我们使用更加具有操作性的语言描述，那么这个问题还可以定义为：对一半径等于给定偏置距离的圆，使其沿着多边形一侧滚动，得到的圆心轨迹就是所求的偏置多边形，如图 8.3 所示。
