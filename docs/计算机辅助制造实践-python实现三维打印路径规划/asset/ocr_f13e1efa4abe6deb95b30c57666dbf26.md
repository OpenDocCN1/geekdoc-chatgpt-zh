# 2.2.1 直线

理论上，直线是空间中经过不重合的两个点且可向两端无限延伸、曲率处为零的一种特殊曲线，它的长度无法度量。我们先来回忆一下，在我们初中阶段学过的平面几何中，直线可由

y = kx + b (2-12)

表示，其中 k 为直线斜率，b 为直线在 XY 坐标系 Y 轴上的截距。在我们高中阶段学过的立体几何中，直线可由

\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{1} (2-13)

或

\begin{cases} A_1x + B_1y + C_1z + D_1 = 0 \\ A_2x + B_2y + C_2z + D_1 = 0 \end{cases} (2-14)

表示。其中式(2-13)称为直线的点向式，式中(x0, y0, z0)为直线经过的点，(m, n, 1)为直线方向向量；式(2-14)称为直线的一般式，由两个空间平面的交线确定直线位置和方向。

在我们将要创建的空间直线类中，我们可以选择直线的点向式或一般式来表达一条直线，但显然，直线的点向式更加直观且容易让人理解，因此，在本书中我们使用直线的点向式来表示直线。

我们将直线类写在 Line.py 文件中，类名为 Line。直线类的实现比较简单，我们只需定义直线经过的点和直线的方向向量，它的具体代码如下：

| Line.py | 直线类 | 2 - 5 |
|---|---|---|
| 1 | from GeomBase import * | # 导入 GeomBase 模块 |
| 2 | class Line: | |
| 3 | def __init__(self, P, V): | |
| 4 | self.P = P.clone() | # 直线经过的点,类型为 Point3D |
| 5 | self.V = V.clone().normalized() | # 直线方向向量,类型为 Vector3D,单位向量 |
| 6 | def __str__(self): | # 定义直线类被 print 时的显示行为 |
| 7 | return "Line\\nP %s\\nV %s\\n" % (str(self.P), str(self.V)) | |

由以上代码可知，Line 只表示一种数据结构，包含 P 和 V 两个属性，其中 P 为直线经过的点，V 为直线方向向量(单位向量)。

注意，在 Line 的 __init__ 函数中，我们并没有对 P (或 V) 进行直接赋值(如 self.P = P)，而是调用了 clone 函数，将在内存中复制得到的新点赋给 Line 的 P 属性。这样做的原因是降低 Line 对象创建后，其属性在外部被修改的风险。这是初学者在使用类似 Python、C#、Java 等使用引用方式传值的编程语言时非常容易忽略的问题，而且由此引发的 bug 有时很难被发现。
