(2Np+1)。我们在测试文件中创建的第一个函数为 getAngleTable，它的输入为指定切片层轮廓，功能是调用上述 findOptFeedDir 函数(使用默认参数)并打印计算得到的相应角度表，同时统计函数数运行时间。

作为对比,我们在测试文件中又创建了一个名为 getRegionTable 的函数,这个函数的功能是使用暴力方法计算分区表,即首先对填充角在 0~180 度范围内细分取值(这里设置角度间距为 1 度),然后根据每个填充角对输入轮廓进行旋转,最后逐次调用 SplitRegion 模块中的 splitRegion 函数对输入轮廓进行实际分区并统计最终得到的分区数,存于分区表中。根据 getRegionTable 函数的实现原理,我们可以非常直观地推断,它的运行效率不及 getAngleTable。

我们在测试文件中创建的第三个函数为 getPathCount,顾名思义,这个函数的作用是对输入切片轮廓调用 genDpPath 函数,生成轮廓区域内的实际平行填充路径,最终统计并打印实际路径数量。理论上,对给定切片层轮廓,由 genPathCount 生成的实际路径数量应等于 getRegionTable 生成的分区数。测试文件具体代码如下:
