度函数进行了定义。在常规的粒子群算法中，每个粒子除了位置属性外，还应该有一个速度属性。根据式（10-5）、（10-6）可知，粒子的速度属性是粒子位置变化的原因。如果粒子没了速度，静止不动，那粒子也就不会进化！

在当前应用场景下，对粒子的速度给出定义既简单又困难。考虑到我们用转角对（α，β）表示粒子位置，理论上，转角增量（Δα，Δβ）就是粒子的速度。但如果真的赋予了粒子速度属性，我们会陷入一个“粒子越界”困境。如果我们以模型绕 X 轴的转角为横坐标、绕 Y 轴的转角为纵坐标建立平面正交坐标系，考虑到转角α、β的定义域均为[0, 2π]，那么粒子在平面上的活动范围为一个边长为 2π的正方形区域，如图 10.24 所示。在这个场景下，我们可以想像，粒子进化的本质就是粒子的位置叠加一个速度矢量。假如在某一轮迭代中，某个粒子恰好位于正方形区域边界附近，而它此时的速度指向正方形区域外侧，那么在这个粒子进化过程中，很有可能“跳”出正方形区域。虽然此时这个粒子对应的转角α、β实际上仍然具有几何意义（因为模型转角在正余弦、矩阵运算中是一个周期为 2π的量），但如果听之任之，那粒子群迭代过程将向外发散，很难收敛。因此，我们必须采取必要的手段，将粒子的进化控制在定义域内。比如我们可以仿照物理中的“碰撞反射”概念，让粒子在碰到定义域边界时，反射回定义域内部，这样做的难点在于粒子反射路线的建模与计算，特别是当粒子速度较大，可能需要多次反射才能静止，如图 10.24 所示。另一种方法是根据转角的周期性，当转角值超过定义域时，通过加减 2π的整数倍，直接将其拉回定义域内，这种方法的缺点是几何意义不明确，可能存在算法收敛性问题。

和遗传算法类似，粒子群算法在解决优化问题时之所以有效，一是因为“随机性”，随机性保证了初始粒子均匀分布在解空间内，是种群“基因”多样性的体现，也是后续进化的根本动力；二是因为每个粒子都有自发向种群中优秀粒子靠近的趋势，这种趋势使得每个粒子慢慢向问题的最优解收敛。

如果我们对粒子群算法的本质有更深层次的理解，就会发现，在粒子群算法中，粒子的速度项其实并不是必要的，算法真正需要的其实是一个粒子向种群中优秀粒子靠近的一种机制。既然粒子的速度属性定义这么困难，那我们就索性尝试取消粒子速度项，转而用其他方式构建粒子的进化机制。
