对当前面片 triangle 中的当前层高 z，在获得了截交线段 seg 并判断 seg 非空后，我们首先通过 layerDic[z] 检索到该层高下的层对象，然后将 seg 添加到该对象的 segments 列表中。这里必须要用字典才能完成快速检索的功能。如果我们不用层字典而用层列表，那么对每条截交线段，需要遍历层列表寻找相应高度的层对象，费时费力。

至此，我们已经完全实现了基于层高匹配的 STL 模型截交算法，和 IntersectStl_sweep 类类似，我们可以参照下列语句使用该算法：

```
layers = IntersectStl_match(stlModel, layerThk).layers
```

其中 stlModel 为事先读取的 StlModel 对象，layerThk 为事先指定的层高，layers 用于保存计算得到的截交线段。

现在，我们已经拥有了暴力法、扫描平面法、层高匹配法 3 种 STL 模型截交算法，到底扫描平面法和层高匹配法相对于暴力法能提高多少效率，扫描平面法和层高匹配法两者孰优孰劣，我们将在下一节对这 3 种截交算法的性能进行测试和对比。
