我们将以上 Offset 函数连续偏置得到的偏置曲线存放在临时变量 OffsetPolyses 中,注意,这是一个存储 Polyline 对象的二维列表,其中第一个维度表示偏置级数,第二个维度表示当前偏置级上的曲线序号。对得到的 OffsetPolyses,我们的最终目标是将其中的每条偏置曲线串连成一体,以生成轮廓平行填充路径,而且为了保证实际打印效率,用于连接连续偏置曲线的路径长度越短越好。为了达成这一目标,我们必须首先找出 offsetPolyses 中各条曲线的包含关系。

# 8.5.2 曲线包含关系确定

在上一小节,针对输入的表示打印区域的边界轮廓 b0,我们已经能够生成它的连续偏置曲线 b1,b2等,而且将这些曲线存放于 GenCpPath 类的二维列表属性 OffsetPolyses 中。我们在这一小节的任务是确定 OffsetPolyses 中各条偏置曲线的层次包含关系,以便后面能够对它们进行连接,生成较短的轮廓平行填充路径。事实上,我们在本书 4.5 节已经处理过类似的问题,只不过在第 4 章,我们的主要目的是确定多边形方向。注意,这里 b0(b1,b2等类似)本身是一个复数的概念,它可以表示一条或多条曲线,即一个打印区域可能由多条外轮廓曲线(逆时针)和多条内轮廓曲线(顺时针)围成。

我们不妨先来分析下,当 b0 仅有外轮廓曲线的情况,如图 8.22 所示。在这种情况下,OffsetPolyses 中各曲线包含关系的确定相对简单。我们知道,OffsetPolyses 的第一个维度表示偏置级数,根据连续偏置的原理,第 1 级偏置曲线必然包含第 2 级偏置曲线,第 2 级偏置曲线必然包含第 3 级偏置曲线……以此类推,第 i 级偏置曲线必然包含第 i+1 级偏置曲线,即 OffsetPolyses[i+1]中各条曲线的直系父曲线必然在 OffsetPolyses[i]中,而 OffsetPolyses[i]中各条曲线的直系子曲线也必然在 OffsetPolyses[i+1]中。

注意,一条曲线可能被多条曲线所包含(即在多条曲线内部),它的直系父曲线是指包含它的曲线中距它最近的那条曲线,而它本身可称为父曲线的直系子曲线。根据这一定义,一条曲线至多有 1 条直系父曲线,但可能有 0 条、1 条或多条直系子曲线。而且,就像人类社会一样,父子曲线的关系是相对变化的,某一对父子关系中的直系子曲线可能是另一对父子关系中的直系父曲线;同理,某一父曲线可能是另一曲线的直系子曲线。通过构建父子曲线的关系图谱,理论上,我们可以通过其中一条曲线索引到整个关系网中的所有曲线,见图 4.9。
