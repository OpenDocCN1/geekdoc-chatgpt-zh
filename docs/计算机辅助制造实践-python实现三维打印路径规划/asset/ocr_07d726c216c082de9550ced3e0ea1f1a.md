路径填充形式，fillAngle 表示填充角度（默认值为 0 度），xyGap 为支撑到模型的横向间隙（默认值为 1 毫米）。在这些参数中，其中 stlModel，layers，gridSize，crAngle，xyGap 这 5 个参数我们比较熟悉，它们和支撑区域生成相关，将直接被 findSptRegion 函数所用。

在以上最新 GenDpPath 模块的基础上，genSptPath 函数的实现变得简单，在流程上主要可以分为 3 个步骤。

+   （1）调用 findSptRegion 函数生成了各层切片上的支撑区域轮廓，这些支撑轮廓被保存在 layers 序列中。

+   （2）计算模型在 XY 平面上的中心点 center 和全局唯一的用于指示平行线位置和间距的实数序列 ys。

+   （3）在前面两步获得的数据的基础上，调用 GenDpPath 模块中的 genDpPathEx 函数对每层切片上的支撑区域生成平行填充路径。

在 genSptPath 函数中，我们将得到的平行填充路径保存到了每层切片（layer）的 sptDpPaths 序列中，并且我们直接以平行填充路径外围的支撑区域轮廓（sptContours）为轮廓路径，保存到每层切片的 sptCpPaths 序列中。

注意，以上 sptDpPaths 和 sptCpPaths 两个序列（其实也包括 sptContours 序列）都是 Python 语言特有的动态属性，如果使用其他编程语言实现，应考虑提前在 Layer 类中定义相应属性。我们看到，genSptPath 函数的最终输出就是 sptDpPaths 和 sptCpPaths 两个路径序列，其中对 sptDpahs 中的平行填充路径来说，它们已经具备了分区特性，且各个分区内的路径都已经被连接。
