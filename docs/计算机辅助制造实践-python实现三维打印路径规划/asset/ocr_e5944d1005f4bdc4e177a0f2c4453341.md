在 Python 环境下，Clipper 库有两种安装方法。一种是直接下载它的源文件，我们之前已经提到，Clipper 库拥有多种语言版本的源文件，其中就包括 Python。Clipper 库的源文件可以通过 Clipper 官网上的链接下载，它被托管在一个叫 SourceForge 的开源代码管理网站上。在下载到的压缩包中，我们可以直接拷贝里面的 clipper.py 文件到我们的目标项目目录中，并在相应代码文件中通过“from clipper import *”语句导入 Clipper 库。相对于 C++ 版本的源代码，Python 版本的 Clipper 库源代码更新较慢，目前我们能够下载到的最新 Python 版 Clipper 库的版本号是 5.1.6。在源代码压缩包中，还有一份关于 Clipper 库的说明文档，介绍了 Clipper 涉及的相关几何概念以及类和函数的使用方法。

安装 Clipper 库的第二种方法是在系统命令窗口输入“pip install pyclipper”，Python 将为我们自动下载版本合适且已经编译好的 Clipper 库文件，相比于第一种方法，这种方法更加方便。使用时，我们只需在相应代码文件中通过“import pyclipper”语句导入 Clipper 库即可。我们之所以能够通过这种方式直接安装 Clipper 库，是因为 PyPI（Python 第三方库仓库）已经将 Clipper 库纳入了日常维护管理（参见 https://pypi.org/project/pyclipper/），这从另一个侧面也反映了 Clipper 库的通用性。通过这种方式安装的 Clipper 库的版本号基本能和最新的版本号保持一致，因此我们建议采用这种方式安装并使用 Clipper 库。

下面我们先来看一下 Clipper 库中的几个基本概念。在 Clipper 库中，所有算法的输入和输出都是一种被称为 Path 的对象。事实上，Path 和我们之前定义的 Polyline 类似，不过 Polyline 是三维多段线，而 Path 是二维多段线。Path 可以包含一个点、两个点或多个点，它可以闭合，也可以不闭合，甚至还允许自相交，方便起见，这里我们在描述时还是称 Path 为轮廓。Clipper 库的强大之处在于它能够处理自相交轮廓区域的裁剪问题，而这个功能的基础是平面区域的填充规则。

对于由一条或多条闭合轮廓组成的平面封闭区域，Clipper 定义了四种填充规则：奇偶填充（Even-Odd）、非零填充（None-Zero）、正填充（Positive）、负填充（Negative）。需要说明的是，这里说的填充是计算机图形学的概念，这些规则定义了平面封闭区域内哪些区域需要被填充，哪些区域不需要被填充。填充的概念是学习和理解 Clipper 库的重要基础，因此我们有必要对此展开讲解。

奇偶填充的概念比较简单，事实上我们在前面几章关于打印区域的识别问题中已经有所涉及（参见图 4.10）。对一条起点在区域外的射线，我们可以假想它逐渐伸长和区域各条边界轮廓相交，并最终穿越区域的场景。在这一过程中，奇偶填充规定：和射线相交的第奇数个轮廓内部区域是填充区域，第偶数个轮廓内部区域是非填充区域。奇偶填充一般适用于由那些轮廓本身不存在自相交情况且轮廓之间也不存在相交情况的轮廓所围成的平面区域。
