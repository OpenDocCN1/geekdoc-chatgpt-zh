如果我们不这么做，即在以上__init__函数中不使用 clone 函数，将会发生什么？我们可以运行以下简单的示例代码以便加深印象，有兴趣的读者可以进一步测试。

# 2.2.2 射线

和直线一样，射线的长度同样无法度量；但不同的是，射线只有一端可以无限延长，另一端固定不动。在 Line 类的基础上，我们再来讨论射线类的代码实现就会变得非常容易。显然，相比于直线，射线更应该用点向式来表示，因此在实现射线类时，我们几乎可以照搬直线类的实现代码。

我们将射线类放在 Ray.py 文件中，类名为 Ray，它的实现代码如下：

| Ray.py | 射线类 | 2 - 7 |
|---|---|---|
| 1 | from GeomBase import * | |
| 2 | class Ray: | |
| 3 | def __init__(self, P, V): | |
| 4 | self.P = P.clone() | # 射线经过的点,类型为 Point3D |
| 5 | self.V = V.clone().normalized() | # 射线方向向量,类型为 Vector3D,单位向量 |
| 6 | def __str__(self): | # 定义射线类被 print 时的显示行为 |
| 7 | return "Ray\nP %s\nV %s\n" % (str(self.P), str(self.V)) | |
