需要注意的是，在使用包含多个 elif 语句的分支结构时，应理清各个条件语句之间的逻辑关系。只要有一个条件成立，程序就会执行其后的语句，执行完后程序将退出整个 if 语句，而不会继续执行其他 elif 或 else 语句。

在判断非此即彼的条件时，我们可能会觉得使用常规的 if else 结构写的代码太过冗长（至少包含 4 行代码），此时我们可以使用 Python 语言的三目运算符，使用一行代码就可实现二选一功能，形如：

```
x if b else y
# Python 中的三目运算
```

即当 b 为 True 时，返回 x；b 为 False 时，返回 y。熟悉 C++、C#、Java 等语言的读者可能知道，在这些编程语言中，三目运算符是通过问号和冒号来实现的，形如：

```
b ? x : y
# C++、C#、Java 等语言中的三目运算
```
