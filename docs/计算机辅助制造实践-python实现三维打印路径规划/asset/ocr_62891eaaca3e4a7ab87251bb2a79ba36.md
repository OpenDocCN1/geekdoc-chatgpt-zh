# 图 8.16 Clipper 布尔偏置步角偏置线段衔接策略

段来弥补相邻偏置线段间的缝隙，如图 8.16(b)。为了保证偏置轮廓的连续性，我们需要同时延长偏置线段并在交点处和衔接线段相连。显然，使用矩形衔接时，顶点到衔接线段的最小距离等于给定偏置距离。相比于圆弧衔接，矩形衔接得到的偏置轮廓的顶点数据量更小，但前提是会损失偏置轮廓的光滑性。

斜角衔接(JT_MITER) 同样是用一段和轮廓顶点角平分线垂直的直线段来弥补相邻偏置线段间的缝隙，如图 8.16(c) 所示，但是轮廓顶点到衔接线段的距离不大于某一给定值(Clipper 中该值默认为偏置距离的 2 倍)。如果轮廓顶点到衔接线段的距离等于偏置距离，那么斜角衔接将退化为矩形衔接，因此，我们可以认为矩形衔接是斜角衔接的一种特殊形式。

在 Clipper 库中，默认的步角顶点偏置线段的衔接方式是矩形衔接。值得一提的是，Clipper 不支持直接延长两相邻偏置线段至相交点的衔接方式。这是因为对于轮廓上的尖角来说，这种衔接方式可能引发严重的偏置问题，导致不合理的偏置轮廓自相交，进而导致本应一体的轮廓区域被分割成若干部分，如图 8.17 所示。
