外，直线和三角形边界线的求交（线线求交）操作是不可避免的，虽然这并不困难，用我们之前封装的 GeomAlgo 模块就可以解决，但毫无疑问，这样会让变异操作变得非常繁琐。如图 10.26 所示，在不失变异意义的前提下，简单起见，我们用上述三角形的包络矩形替换三角形本身，并求取落在包络矩形外且在正方形定义域内的随机点作为变异后的粒子。通过这种方式，我们进行简单的坐标比较便可求出变异后粒子位置。
