self.egDic[e3tp].append(e3)
for edges in self.egDic.values():       # 遍历 egDic, 建立成对半边
    if len(edges) == 2:                 # 之间的索引关系

我们首先来看一下 TModel 类的属性,vxDic 为顶点字典,egDic 为半边字典,它们的命名和意义都和我们在前文介绍的保持一致。faces 为面片列表,用于保存根据 STL 模型构建的拓扑面片,stlModel 用于保存输入的需要重建的 STL 模型。在 TModel 类中,除初始化函数外,我们只封装了一个 createTModel 函数,这个函数的功能是对输入的 STL 模型进行重建,输出拓扑模型,它是 TModel 类的核心所在,其实现代码基本还原了模型拓扑重建原理。

对于任意一个面片 f,我们可以快速索引到它的 3 个顶点和 3 条半边,如 f.A,f.B,f.C 以及 f.E1,f.E2,f.E3,我们可以通过类似 f.E1.OE.F 的形式快速索引到与之相邻的面片。对任意半边 e,我们可以快速索引到它的两个端点、所在的面以及对边,如 e.A,e.B,e.F 以及 e.OE。对任意顶点 A,我们可以根据 faces 列表,索引到以之为顶点的所有面片。根据这些拓扑关系,理论上,从任意一个面片出发,我们可以遍历模型中所有三角面片。
