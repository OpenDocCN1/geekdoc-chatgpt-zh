## 4.5 轮廓方向识别与调整

通过上一节的介绍，我们已经能够将某一层高上的截交线段集合拼接成若干封闭多边形轮廓，但在执行拼接算法时我们并未考虑多边形的方向(逆时针或顺时针)，因此它们的方向完全是随机的。理论上，如果 STL 模型是合法的，那么这些多边形之间不可能存在相交的情况。它们在平面上的关系至多存在两种情形，包含或者不包含。这两种情形组合，使得多边形在平面上共同形成打印填充区域的内、外边界，如图 4.8 所示，图中阴影区域即为填充区域。为了区分内、外边界，在本书中，我们定义区域外边界方向为逆时针，内边界方向为顺时针。本节的任务就是根据多边形轮廓之间的包含关系，确定各个多边形内、外边界属性，即顺、逆时针方向，最终识别出由这些多边形确定的填充区域。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_83_1.png)

### 图 4.8 由多边形内外边界形成的填充区域

我们先来分析一下多边形的包含层次。结合图 4.8 和图 4.9，如果一个多边形位于最外层（即第 0 层），那么这个多边形是填充区域的外边界，其方向应为逆时针，如图中 1 号和 5 号多边形；如果一个多边形处于第 1 层（即第 0 层内部），那么这个多边形是填充区域的内边界，其方向应为顺时针，如图中 2 号和 3 号多边形；如果一个多边形处于第 2 层，那么这个多边形又将是填充区域的外边界，其方向应为逆时针，如图中 4 号多边形……以此类推，我们不难归纳出：如果一个多边形处在偶数层上，那么它为外边界，方向为逆时针；反之如果处在奇数层上，那么它为内边界，方向为顺时针。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_84_0.png)

对于两个多边形 A 和 B，如果 B 位于 A 内部，那么我们称 B 为 A 的子多边形，A 为 B 的父多边形。在图 4.9 中，1 号和 5 号多边形均有 0 个父多边形，2 号和 3 号多边形均有 1 个父多边形，4 号多边形有 2 个父多边形。

由此我们可以归纳：如果一个多边形有偶数个父多边形，那么这个多边形为区域外边界，方向应为逆时针；反之如果一个多边形有奇数个父多边形，那么这个多边形为区域内边界，方向应为顺时针。

经过以上分析，我们已经把求解问题的方法向我们熟悉的方向引导。在本书第 2 章中，我们已经给出了点和多边形关系的判断方法，并将其封装在 GeomAlgo 模块的 pointInPolygon 函数中。

基于以上分析，对于多边形集合中的任意多边形 A，我们可以取该多边形上的任意一（顶）点 P，判断 P 和剩余多边形的关系：如果 P 在偶数个多边形内部，那么多边形 A 为外边界，方向应为逆时针；反之如果 P 在奇数个多边形内部，那么多边形 A 为内边界，方向应为顺时针。

根据以上思路，我们只要写一个简单的循环，就能判断一个多边形的方向，写两个循环，就能判断同一平面上所有多边形的方向。

我们把调整多边形方向的函数写在 GeomAlgo 模块中，函数名为 adjustPolygonDirs，输入为 Layer 中的多边形轮廓列表，具体实现代码如下：

```python
......
def adjustPolygonDirs( polygons ):
    for i in range( len( polygons ) ):
        pt = polygons[ i ].startPoint( )
        insideCount = 0
        for j in range( len( polygons ) ):
            if j == i: continue
            restPoly = polygons[ j ]
            if 1 == pointInPolygon( pt, restPoly ):
                insideCount += 1
    if insideCount % 2 == 0:
        polygons[ i ].makeCCW( )
    else:
        polygons[ i ].makeCW( )
```

值得一提的是，识别多边形轮廓集合中各个多边形方向的方法不止一种，这里之所以倾向于选择上述方法完全是基于我们之前在 GeomAlgo 模块中建立的 pointInPolygon 函数。假设我们没有先前基础，绕开 pointInPolygon 函数，那么这个问题又该如何解决呢？一种可行的方案是使用射线法，如图 4.10 所示，从当前多边形轮廓上的任意一（顶）点出发作射线，计算该射线和其余多边形的交点个数。如果交点个数为偶数，则该多边形为外边界，方向应为逆时针；反之如果交点个数为奇数，则该多边形为内边界，方向应为顺时针。这个方案的核心思想以及包含的基础运算和 pointInPolygon 函数十分相似，有兴趣的读者不妨去实现一下，或者思考更为简洁的识别方法。

## 4.6 切片数据存取

现在，我们已经可以对一个 STL 模型进行切片，最终得到一系列 layers，其中每个 layer 又包含一系列封闭的 contours。这时，我们可以继续往下推进我们的工作，或者可以考虑将已经得到的切片数据保存到一个指定的文件中，方便后期使用。

我们可以像在 Polyline 模块中定义的读写多段线函数一样，去自定义一种文件格式，用来保存切片数据，这其实并不困难。或者我们也可以考虑使用一种现有通用的文件格式，比如 SLC (SLiCe)。

和 STL 一样，SLC 文件格式同样由 3D Systems 制定，如果说 STL 是三维打印模型文件格式的标准，那么 SLC 就是三维打印中切片数据文件格式的标准。SLC 文件使用 2.5 维的轮廓线表示 CAD 模型，它有层的概念，层高随着 Z 方向增长，其中每层截面由内、外边界轮廓多边形组成。

### 4.6.1 SLC 文件解析

SLC 文件由文本和二进制混合编码而成，包含 4 个部分：头文件（Header Section）、预留区（Reserved Section）、采样表（Sampling Table Section）以及轮廓数据区（Contour Data Section），如图 4.11 所示。其中头文件包含一系列 ASCII 文本键值对，指示了当前文件的全局信息，如 SLC 版本号（-SLCVER）、长度单位（-UNIT）、生成软件（-PACKAGE）、模型包络（-EXTENTS）等信息。头文件最大大小不能超过 2048 个字节，结束标识为 0x0d（回车）、0x0a（换行）、0x1a（Ctrl+Z）三个字符。预留区包含 256 个字节，是为将来扩展使用的预留空间，目前在这个区域内不定义任何东西，默认每个字节值为 0。

采样表由若干通道组成，开头第 1 个字节指示了通道数量，最大值为 255。每个通道有 4 个字段，每个字段占 4 字节，共 16 个字节，分别为切片起始高度（float）、切片厚度（float）、线宽补偿（float）以及最后的保留字段。

在实际三维打印中，如果我们采用均匀层高去切片，那么只需在采样表中保存一个通道即可（17 个字节）。对于那些有非均匀层高切片需求的场景，我们可以设置多个通道，每个通道设置不同的切片厚度，但至多设置 255 种不同切片厚度。

轮廓数据区是 SLC 文件的核心部分，用于保存多边形轮廓的坐标信息。如图 4.11 所示，该区域按层的形式组织轮廓。每层数据从当前层 z 值开始（4 字节，float），随后是当前层轮廓数量（4 字节，uint，整型）。紧接着是第 1 个轮廓顶点数（4 字节，uint）和 gap 数（4 字节，uint），然后是第 1 个轮廓 X、Y 坐标列表，其中每个坐标（如 x 值）占 4 个字节，为 float 类型，X、Y 坐标总是成对出现。如果当前层还有第 2 个轮廓，那么后面接的是第 2 个轮廓的顶点数、gap 数以及坐标列表。以此类推，直至罗列完当前层所有轮廓。在这之后，再接下一层轮廓数据，以此类推。该区域结尾处有 8 个字节，前 4 个字节用于标识当前模型的最高点 z 坐标，后 4 个字节固定为 0xFFFFFFFF 值，标识轮廓数据区到此结束，同时也标识整个文件到此结束。

以上我们提到了 gap，对某一轮廓，如果轮廓上某个位置存在两相邻点重合的情况，则定义这个位置为 gap，gap 可以看作是轮廓线在此出现了断裂（沟）。

本书介绍的轮廓线均为封闭轮廓线，因此该字段值总为 0。

### 4.6.2 SLC 文件读写

根据上一小节的介绍，针对一个在代码中已经得到的切片数据列表(layers)，我们可以将其保存成 SLC 格式的文件，以备将来使用；同时，为了避免较为费时的切片运算(特别是在调试过程中)，我们可能还希望直接从一个之前已经保存的 SLC 文件读取切片数据。这样我们就需要两个函数，一个是写 SLC 文件，一个是读 SLC 文件。我们依然将这两个函数写在 SliceAlgo 模块中，函数名分别为 writeSlcFile 和 readSlcFile。

函数 writeSlcFile 实现代码如下，输入参数为切片数据列表 layers 和文件路径 path。如果该函数成功执行，会将 layers 写入指定的 path 中；否则打印异常消息。

```python
def writeSlcFile( layers, path ):
    f = None
    try:
        f = open( path,'w+b' )
        f.write( bytes( "-SLCVER 2.0 -UNIT MM", encoding='utf-8' ) )
        f.write( bytes( [ 0x0d, 0x0a, 0x1a ] ) )
        f.write( bytes( [ 0x00 ] * 256 ) )
        f.write( struct.pack( 'b', 1 ) )
        f.write( struct.pack( '4f', 0, 0, 0, 0 ) )
        for layer in layers:
            f.write( struct.pack( 'f I', layer.z, len( layer.contours ) ) )
            for contour in layer.contours:
                f.write( struct.pack( '2i', contour.count( ), 0 ) )
                for pt in contour.points:
                    f.write( struct.pack( '2 f', pt.x, pt.y ) )
        f.write( struct.pack( 'f I', layers[-1].z, 0xFFFFFFFF ) )
    except Exception as ex:
        print( "writeSlcFile exception:", ex )
    finally:
        if f: f.close( )
```

函数 readSlcFile 实现代码如下，输入参数为需要打开的 SLC 文件路径。如果该函数执行成功，将返回 SLC 文件中的切片数据列表；如果执行失败，则打印异常消息，并返回一个空的切片数据列表。我们可以仿照代码 4-6 或 4-7 修改 SliceAlgo.py 中的 main 函数，对 readSlcFile 函数进行测试。图 4.12 给出了使用 readSlcFile 函数读取并显示商用软件生成的人像模型 SLC 文件的结果，该 SLC 文件包含 3515 层切片，为了得到较为清晰的显示效果，我们在代码中设置每隔 20 层显示一个切片。

```python
def readSlcFile( path ):
    f , layers , i = None , [ ] , 0
    try:
        f = open( path , 'rb' )
        data = f.read( )
        while True:
            if data[ i ] == 0x0d and data[ i + 1 ] == 0x0a and data[ i + 2 ] == 0x1a : break
            i += 1
        i += ( 3 + 256 )
        channelCount = data[i]       # 获取 Sampling Table 区通道数
        i += (1 + channelCount * 16)
        while True:             # 获取 Contour Data 区数据
            z, = struct.unpack('f', data[i: i+4])   # 获取当前层高
            i += 4
            contourCount, = struct.unpack('I', data[i: i+4]) # 获取当前层上轮廓数
            i += 4
            if contourCount == 0xFFFFFFFF: break   # 如果碰到结尾标识,则退出
            layer = Layer(z)           # 新建 Layer 对象
            for j in range(contourCount):
                pointCount, = struct.unpack('I', data[i: i+4]) # 获取当前轮廓点数
                i += 4
                gapCount, = struct.unpack('I', data[i: i+4])
                i += 4
                contour = Polyline()      # 新建轮廓
                for k in range(pointCount):
                    x, y = struct.unpack('2f', data[i: i+8])
                    i += 8
                    contour.addPoint(Point3D(x, y, z))   # 向轮廓添加坐标
                layer.contours.append(contour)
            layers.append(layer)
    except Exception as ex:
        print("readSlcFile exception:", ex)   # 打印异常
    finally:
        if f: f.close()
    return layers          # 返回 Layer 对象列表
```

## 4.7 SliceModel 模块

在以上几节中，我们分别介绍了针对 STL 模型的暴力切片方法、针对截交线段的暴力拼接方法以及针对封闭轮廓的方向识别方法，为了保存临时切片数据，我们还介绍了 SLC 文件的存取方法。在以上介绍中，为了方便行文及解释，我们将这些方法分别独立地写在了 SliceAlgo.py 文件中，这是一种面向过程的程序编写方式。使用这种方式编写的代码虽然直观且易于理解，但每个函数间需要传递数据（如 layers），组织管理这些数据较为繁琐。
