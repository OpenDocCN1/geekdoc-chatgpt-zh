# 6.4.2 算法流程及实现

我们先来看一下基于字典查询的截交线段拼接算法流程，如图 6.6 所示。虽然从表面上看，图 6.6 中的流程和上一节图 6.4 中的流程有点相似，但它们的实现细节实则不同。这两个流程的输入都是平面上的散乱截交线段列表 segs，输出也都是封闭轮廓列表 contours。

在图 6.6 中，对输入的线段列表 segs，我们首先需要将它们逐一转化为相互关联的链接点对，并将得到的链接点以其坐标为键添加到字典 dic 中，这一过程体现在我们已经实现的 createLpDic 函数中。拼接流程接下来为两层循环。在第 1 层循环中，我们首先需要从 dic 中寻找一个从来没有被使用过的点 p。因为我们仅在字典的值中保存了链接点对象，因此我们需要遍历字典的值（而非键），从中寻找符合要求的点 p。如果不能寻找到这样的点，那么退出第 1 层循环，输出轮廓列表 contours，整个流程到此结束；但是如果能够找到没被使用过的点 p，则新建一条多段线 poly，用于收集链接点。
