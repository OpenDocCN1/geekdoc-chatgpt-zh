# 1.3 Python 第三方库安装

近年来，Python 之所以这么流行，除了其语法简单、容易上手之外，很大一部分原因在于它有强大的第三方库支持。当你在使用 Python 编写程序时，对于你在某一方面的功能需求，很有可能已经有人将该功能做成第三方库并放在网上。如果你需要从一个 PDF 文档的中抽取目标信息，你可以使用 PDFMiner 库；如果你需要处理图片文件，你可以使用 OpenCV、pillow 等库；如果你需要进行串口通信，你可以使用 pyserial 库；如果你需要进行数值运算，你可以使用 numpy、Scipy、Matplotlib 等库；如果你需要进行游戏开发，你可以使用 Pygame、cocos2d 等库；如果你需要学习、应用人工智能技术，你可以使用 Tensorflow、PyTorch 等库。对于你能想到的大部分功能，几乎都能找到一个对口的 Python 第三方库。

Python 第三方库安装非常简单，可在 Windows 的命令窗口输入“pip install 库名”即可。如图 1.8 所示，如果需要安装串口库，只需在命令窗口输入“pip install pyserial”；如果需要安装 numpy 数值处理库，只需在命令窗口输入“pip install numpy”。pip install 命令会自动识别当前系统上正在使用的 Python 版本，并根据版本信息自动去相关网站搜索目标第三
