# 1.5.1 数据类型

Python 内置了 5 种标准数据类型，分别为：Numbers（数字）、String（字符串）、List（列表）、Tuple（元组）、Dictionary（字典）。其中，Numbers 又分为四种类型，分别为 int（有符号整型）、long（长整型）、float（浮点型）、complex（复数）。

Python 是弱类型语言，变量不需要声明类型，其类型由其赋值的类型决定；变量名首字符必须为字母或下划线_，建议使用小写英文字母开头。下面给出了几个 Python 变量赋值实例：

| | 变量赋值操作 | 1-1 |
|---|---|---|
| 1 | counter = 100 | # 整型变量 |
| 2 | miles = 1000.0 | # 浮点型变量 |
| 3 | city= "Hangzhou" | # 字符串变量,双引号和单引号可以通用 |
| 4 | flag = True | # 布尔型变量,值为 True 或 False |
| 5 | a = b = c = 1 | # 为多个变量赋同一值 |
| 6 | name, age, sex ='张三', 23,'男' | # 为多个变量赋不同(类型)值 |
| 7 | names = ['Jim ','Tom ', ' Kate '] | # 定义列表变量,并为其赋值 |
| 8 | classes = ('English ', 'math ', ' physics ') | # 定义元组变量,并为其赋值 |
| 9 | students = {'Jim ': 10, 'Tom ': 11, ' Kate ': 9} | # 定义字典变量,并为其赋值 |

需要说明的是，在 Python 中，列表定义使用方括号[ ]，元组定义使用圆括号( )，字典定义使用花括号{ }。其中列表和元组每个元素就是一个值，字典每个元素为一个键值对（key：value）。列表和元组的不同点在于列表中的元素个数（及元素类型）可以在定义后动态改变，而元组中的元素个数（及元素类型）在定义后不能更改。字典中的元素个数（及元素类型）也可动态改变。
