# 第 1 章 Python 简介

## 1.1 Python 语言概述

Python 的创始人为 Guido van Rossum，见图 1.1。1989 年圣诞节期间，在荷兰的阿姆斯特丹，Guido 为了打发圣诞的无聊时间，决心开发一种新的解释型脚本语言，作为 ABC 语言的继承。ABC 是 Guido 参与开发的以教学为目的的编程语言，目标是“让用户感觉更好”，容易阅读、使用和学习，激发人们学习编程的兴趣；遗憾的是，由于自身缺陷，ABC 语言最终没有流行起来。

Guido 将新开发的语言命名为 Python，这纯粹是因为他是一部名为 Monty Python’s Flying Circus 的电视剧的忠实粉丝。他希望 Python 语言能够实现他的理念，成为一种介于 C 语言和 Shell 之间，功能全面、易学易用、拓展性强的语言。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_11_0.png)

图 1.1 Python 创始人 Guido van Rossum(图片来自网络)

最初的 Python 完全由 Guido 本人开发，1991 年，第一个 Python 解释器诞生。它用 C 语言实现，并能调用 C 库。Python 从一创建就已具备了类（class）、函数（function）、异常处理（exception），包含表（list）和词典（dictionary）在内的核心数据类型，以及模块（module）为基础的拓展系统。

Python 将许多机器层面上的细节隐藏，交给解释器处理。Python 程序员可以花更多的时间用于思考程序的逻辑，而不是具体的实现细节。这一特征吸引了广大的程序员，Python开始流行。早期的 Python Logo 如图 1.2 所示。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_12_0.png)

图 1.2 Guido 兄弟设计的早期 Python logo (图片来自网络)

经过近 30 年的发展，Python 逐渐完善，拥有众多优点，包括：

- 1. 简单易学

Python 崇尚优美、清晰、简洁，是一种代表简单主义思想的语言，拥有极其简单的语法，即便是没有任何编程基础的人，也非常容易上手；且 Python 适合阅读，就像是在读英语一样。

- 2. 免费开源

Python 是 FLOSS( 自由/开放源码软件 )之一，用户可以自由地发布这个软件的拷贝、阅读它的源代码、对它做改动、把它的一部分用于新的自由软件中。

- 3. 丰富的库

Python 类库非常全面，对大多数功能一般都有现成的类库可以使用；如果一个功能比较特殊，标准库没有提供相应的支持，那么，很大概率也会有相应的开源项目提供了类似的功能。

- 4. 可移植性

同一份 Python 代码，无需大的修改，便可运行在众多平台上，包括 Linux、Windows、FreeBSD、Macintosh、Solaris、OS/2、Amiga、Windows CE 甚至还有 PocketPC、Symbian 以及 Google 的 Android 平台。

Python 有许多优点，但它仍是一门发展中的语言，目前也存在一些缺点，如运行速度慢、多处理器支持差、高低版本不兼容等。特别是高低版本不兼容的问题，Python 2.0 和 3.0 两个版本平行发展，往往会让用户在选择时莫衷一是。至于运行速度慢问题，随着计算机硬件的不断升级，对用户的困扰逐渐减少。

Python 的优点使得它在很多领域有了应用。如云计算开发 ( OpenStack )、Web 开发 ( Django )、科学运算 ( NumPy、SciPy、Matplotlib )、人工智能等。特别是人工智能领域，随着 AI 再次兴起，Python 从众多编程语言中脱颖而出，成为人工智能的标准语言。

简单易学是本书选择 Python 作为编程语言的主要原因。“Life is short，use Python！”

## 1.3 Python 第三方库安装

近年来，Python 之所以这么流行，除了其语法简单、容易上手之外，很大一部分原因在于它有强大的第三方库支持。当你在使用 Python 编写程序时，对于你在某一方面的功能需求，很有可能已经有人将该功能做成第三方库并放在网上。如果你需要从一个 PDF 文档中抽取目标信息，你可以使用 PDFMiner 库；如果你需要处理图片文件，你可以使用 OpenCV、pillow 等库；如果你需要进行串口通信，你可以使用 pyserial 库；如果你需要进行数值运算，你可以使用 numpy、Scipy、Matplotlib 等库；如果你需要进行游戏开发，你可以使用 Pygame、cocos2d 等库；如果你需要学习、应用人工智能技术，你可以使用 Tensorflow、PyTorch 等库。对于你能想到的大部分功能，几乎都能找到一个对口的 Python 第三方库。

Python 第三方库安装非常简单，可在 Windows 的命令窗口输入“pip install 库名”即可。如图 1.8 所示，如果需要安装串口库，只需在命令窗口输入“pip install pyserial”；如果需要安装 numpy 数值处理库，只需在命令窗口输入“pip install numpy”。pip install 命令会自动识别当前系统上正在使用的 Python 版本，并根据版本信息自动去相关网站搜索目标第三方库，然后将合适（兼容）的第三方库下载、安装到本地。安装完成后，命令窗口将提示“Successfully installed 库名”。如果需要卸载已经安装的第三方库，只需在命令窗口输入“pip uninstall 库名”，比如需要卸载 pyserial 库，只需输入“pip uninstall pyserial”即可。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_16_0.png)

图 1.8 使用 pip install 安装 Python 第三方库

在完成第三方库下载后，如果需要在代码文件中使用该库，只需在文件开头添加“import 库名”即可，如需使用串口库，只需在文件开头添加一行“import serial”代码即可。

在上一节中我们已提过，默认情况下，Python 第三方库将被安装在 Lib\site-packages\目录下，我们可在该目录查看已经安装的第三方库。有兴趣的读者也可进一步了解 PyPI (Python Package Index,网址 https://pypi.org/)，这是一个 Python 官方的第三方库，所有人都可以在该网站下载第三方库或上传自己开发的库。默认情况下，pip install 命令还是从该网站下载第三方库。

## 1.4 Python 集成开发环境

“工欲善其事，必先利其器。”虽然原则上只要在电脑上安装了 Python 官方解释器，就可以用文本编辑器或 IDE 编写任何 Python 程序，但实际上这样做开发效率不高。目前，市面上有很多针对 Python 的集成开发环境（IDE），如 Vim、Eclipse with PyDev、Sublime Text、PyCharm、Wing、Visual Studio Code、Anaconda 等。这些 IDE 大同小异，功能强大，一般都包含代码调试、语法高亮、项目管理、智能提示、代码补全、代码跳转等功能。PyCharm 是由 JetBrains 打造的一款 Python IDE，本书选择以 PyCharm 作为 Python 开发工具。

PyCharm 的官方下载地址为 http://www.jetbrains.com/pycharm/，进入该网站后，点击下载，进入下载页面。PyCharm 目前提供专业版（Professional）和社区版（Community）两个不同版本。其中专业版包含了 PyCharm IDE 的所有功能，适合 Python 及 Web 专业开发人员；社区版为轻量级 IDE，适合科研人员或初学者使用。专业版收费，但提供 30 天免费试用；社区版完全免费且开源。考虑到社区版功能已经够用，我们可选择使用社区版 PyCharm，下载最新发布的 PyCharm Community 即可。

PyCharm 安装较为简单，如果对其安装目录没有要求，一直点击下一步默认安装即可。安装完成后，在桌面点击 pycharm 快捷方式启动 PyCharm 软件。首次启动时，需要对 IDE 进行配置（如配色），一般选择默认配置即可。

PyCharm 启动后，进入如图 1.9 所示页面，如需创建新项目，则点击 Create New Project，如需打开已有项目，只需点击 Open 按钮。我们这里需要创建新项目，点击 Create New Project 按钮进入如图 1.10 所示页面。
