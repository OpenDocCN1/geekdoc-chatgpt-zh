## 4.1 STL 模型加载

在第 3 章关于 VTK 的介绍中，我们已经可以使用 VtkAdaptor 类直接从文件加载并显示一个 STL 模型。但在这一过程中，我们却忽视了关于 STL 模型的诸多细节。STL 被认为是三维打印模型的“事实标准”，是由 3D systems 公司于 1988 年制定的一个接口协议。那么 STL 到底是什么？它在文件中又是如何组织和保存几何数据的呢？

### 4.1.1 STL 文件解析

STL 模型是由一系列三角面片组成的实体，相邻三角面片之间遵守“点对点、边对边”的规则，如果一个三角形的顶点落在另一个三角形的边上，那么这个 STL 模型就可被认为是非法的。对于计算机硬盘上保存的 STL 文件，我们可以将其拖入一个已经打开的记事本程序。如果运气好，我们可以看到存在 STL 文件中的模型坐标信息，如图 4.1 所示。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_72_0.png)

图 4.1 文本类型的 STL 文件数据存储形式

在 STL 文件中,每个面片的第 1 行由“facet normal”关键词引导,后面存储面片法向量坐标(数据用科学计数法表示,e 表示 10 的指数);第 3、4、5 行由“vertex”关键词引导,后面分别存储三角面片 3 个顶点坐标。在 STL 中,各个面片是无序保存的,面片与面片之间不存在任何逻辑关系。

STL 文件有两种保存形式,一种以文本( ASCII )形式保存坐标信息(如图 4.1 ),另一种以二进制( Binary )形式保存坐标信息。文本形式的 STL 适合阅读,但从文件尺寸上来说,对同一模型,用二进制存储更节省空间。在这里我们只介绍文本形式的 STL 文件。有兴趣的读者可进一步探究二进制 STL 文件的数据组织方式。

### 4.1.2 STL 文件读取

如果我们要在计算机内存上保存一个 STL 文件,首先需要建立三角面片数据结构。根据以上我们对 STL 文件的剖析,一个三角面片只需保存 3 个顶点坐标和 1 个与面片垂直的法向量坐标即可。据此,我们可以使用 Python 建立 Triangle 类,该类保存在 Triangle.py 文件中,代码如下:

```
from GeomBase import *
class Triangle:
    def __init__(self, A, B, C, N = Vector3D(0,0,0)):
        self.A, self.B, self.C, self.N = A.clone(), B.clone(), C.clone(), N.clone()  # 顶点和法向量
        self.fzs = []                                   # 存储面片包含的层高
    def __str__(self):
        pass
    def zMinPnt(self):                                  # 3 个顶点中的 z 方向最低点
        pass
    def zMaxPnt(self):                                # 3 个顶点中的 z 方向最高点
        pass
```

在以上 Triangle 类中,属性 A、B、C 为三角形 3 个顶点,数据类型为 Point3D;N 为面片法向量,数据类型为 Vector3D。此外,我们还定义了列表类型的属性 zs,用于保存面片所包含的层高数值,但这个属性在本章暂不做讨论。在 Triangle 类中,函数 zMinPnt 用于获取三角形 3 个顶点中在 Z 方向上的最低点,与之对应的函数 zMaxPnt 用于获取 Z 方向上的最高点。需要注意的是,从这一章开始,我们将尽量简化书中的 Python 语句,大多时候可能只保留一些必要的框架性的代码,将一些简单常规的函数留给读者自行实现。

有了 Triangle 数据结构,且知道了 STL 文件中面片的存储规则,我们就可以使用 Python 文件读写的方法读取 STL 文件中所有的三角面片,并在内存中将这些面片保存成 Triangle 类型的对象列表(数组)。为此,我们建立了一个 StlModel 类(对应 StlModel.py 文件),并在其中封装 STL 文件读取函数,代码如下:

```python
class StlModel:
    def __init__(self):
        self.triangles = []   # 三角面片列表
        self.xMin = self.xMax = self.yMin = self.yMax = self.zMin = self.zMax = 0   # 模型边界
    def getFacetNumber(self):
        # 获取 STL 模型中的面片数
        return len(self.triangles)
    def getCoords(self, line):
        # 从文本中提取坐标,被 readStlFile 调用
        strs = line.lstrip().split()
        cnt = len(strs)
        return float(strs[cnt-3]), float(strs[cnt-2]), float(strs[cnt-1])
    def readStlFile(self, filepath):
        # 读取 STL 文件,输入文件路径
        f = None
        try:
            f = open(filepath, 'r')
            while True:
                line = f.readline().strip('\n')   # 删除最后一个换行字符
                if line is None or line == "": break
                if ' facet normal ' in line:
                    dx, dy, dz = self.getCoords(line)
                    N = Vector3D(dx, dy, dz)
                    f.readline()
                    A, B, C = Point3D(), Point3D(), Point3D()
                    A.x, A.y, A.z = self.getCoords(f.readline())
                    B.x, B.y, B.z = self.getCoords(f.readline())
                    C.x, C.y, C.z = self.getCoords(f.readline())
                    triangle = Triangle(A, B, C, N)
                    self.triangles.append(triangle)
        except Exception as ex:
            print(ex)
        finally:
            if f: f.close()
    def extractFromVtkStlReader(self, vtkStlReader):   # 从 vtkSTLReader 提取面片信息
        vtkStlReader.Update()
        polydata = vtkStlReader.GetOutput()
        cells = polydata.GetPolys()
        cells.InitTraversal()
        while True:
            idList = vtk.vtkIdList()
            res = cells.GetNextCell(idList)
            if res == 0: break
            pnt3ds = []
            for i in range(idList.GetNumberOfIds()):
                id = idList.GetId(i)
                x, y, z = polydata.Point(id)
                pnt3ds.append(Point3D(x, y, z))
            triangle = Triangle(pnt3ds[0], pnt3ds[1], pnt3ds[2])
            triangle.calcNormal()
            self.triangles.append(triangle)
    def getBounds(self): # 获取模型 6 个方向边界极值
        if len(self.triangles) == 0:
            return self.xMin, self.xMax, self.yMin, self.yMax, self.zMin, self.zMax
        else:
            self.xMin = self.xMax = self.triangles[0].A.x
            self.yMin = self.yMax = self.triangles[0].A.y
            self.zMin = self.zMax = self.triangles[0].A.z
        for t in self.triangles:
            self.xMin = min(t.A.x, t.B.x, t.C.x, self.xMin)
            self.yMin = min(t.A.y, t.B.y, t.C.y, self.yMin)
            self.zMin = min(t.A.z, t.B.z, t.C.z, self.zMin)
            self.xMax = max(t.A.x, t.B.x, t.C.x, self.xMax)
            self.yMax = max(t.A.y, t.B.y, t.C.y, self.yMax)
            self.zMax = max(t.A.z, t.B.z, t.C.z, self.zMax)
        return self.xMin, self.xMax, self.yMin, self.yMax, self.zMin, self.zMax
```

以上 StlModel 类的主要属性为 triangles，即 Triangle 类型的三角面片列表；xMin、zMax 等属性用来保存模型在 X、Y、Z 三个方向上的极值，这些值可以用来构建模型的轴平行（ axis-aligned ）包络矩形，初始状态下，这些值均为 0，需要调用 getBounds 函数获取。在 StlModel 类中，我们封装了两个 STL 文件读取函数，即 readStlFile 和 extractFromVtkStlReader。其中函数 readStlFile 可用来读取文本形式的 STL 文件，只需输入 STL 文件路径即可；函数 extractFromVtkStlReader 可从一个 vtkSTLReader 类型的对象中提取面片数据，因为 vtkSTLReader 本身可以处理文本或二进制形式的 STL 文件，因此如需读取二进制 STL 文件，也可使用这个函数。

## 4.2 空间三角形和平面求交算法

三维打印的路径规划过程包含很多步骤。如图 4.2 所示，从几何上来说，首先是 STL 模型位置及摆放角度优化，这关系到后期支撑量的多少。然后是对 STL 模型切片，就是用一系列平行平面（一般垂直于 Z 轴）去截模型，求取封闭交线。在同一平面上，若干交线之间可能存在包含关系，组成当前平面上的打印区域。然后就可以在这些打印区域内规划填充路径，这些填充路径就是最后打印机喷头的运动轨迹。最后将不同区域、不同层之间
