# 思考题

+   1. 设计一种算法，利用 STL 模型的拓扑关系，提取所有危险面片并将其在各局部区域内连接成片。
+   2. 在支撑区域外围添加轮廓路径的作用是什么？是否可以取消？
+   3. 尝试设计一组工艺实验，探索某种常用 FDM 打印材料（如 PLA、ABS 等）的支撑临界角度。
+   4. 简述由输入 STL 模型生成切片支撑区域的流程。投影网格、模型支撑点、切片支撑点分别是怎么计算得到的？它们的作用是什么？
+   5. 在由切片支撑点生成切片支撑区域的过程中，为什么使用矩形而非其他图形替换切片支撑点？为什么设置矩形的尺寸略大于投影网格尺寸？
+   6. 在某一层切片上，如何消除支撑区域和模型区域相互干涉的问题？
+   7. 对支撑区域的平行填充路径，为什么上下层路径之间最好对齐？如果不对齐会有什么影响？
+   8. 简述粒子群优化算法的基本流程，简述粒子位移、粒子速度以及适应度函数的概念，说明粒子群优化算法实现问题解优化的本质。
+   9. 在使用粒子群算法优化模型支撑量过程中，为什么要取消粒子速度项，增加粒子的变异操作？
+   10. 对模型支撑量优化问题，如何进一步降低粒子群算法中适应度函数的计算量？
+   11. 尝试使用其他优化算法优化模型支撑量，如遗传算法、模拟退火算法等，并比较这些算法的异同点。
