| 4 | splitFfRegions( layers[ : : -1 ] , shellThk , endLayerNum ) | # 颠倒切片,生成下端面密实填充区 |
| 5 | splitSfRegions( layers ) | # 生成所有切片稀疏填充区 |

至此，我们已完成对 IdEndLayers 模块的全部封装，使用其接口函数 idEndLayers，我们可以识别模型切片中的上、下端面，同时对所有切片进行疏密分区。对任一切片轮廓，我们可能得到四种不同的分区结果：一是同时存在密实填充区和稀疏填充区；二是存在稀疏填充区，但不存在密实填充区；三是存在密实填充区，但不存在稀疏填充区（如模型底面、顶面等）；四是同时不存在密实填充区和稀疏填充区。前三种结果都比较容易理解，对第四种结果，如果出现，表明这层切片轮廓所围的区域面积较小，仅外围的轮廓填充就能将整个区域覆盖，此时当然不存在密实或稀疏填充区。
