# 4.5 轮廓方向识别与调整

通过上一节的介绍，我们已经能够将某一层高上的截交线段集合拼接成若干封闭多边形轮廓，但在执行拼接算法时我们并未考虑多边形的方向(逆时针或顺时针)，因此它们的方向完全是随机的。理论上，如果 STL 模型是合法的，那么这些多边形之间不可能存在相交的情况,它们在平面上的关系至多存在两种情形，包含或者不包含。这两种情形组合，使得多边形在平面上共同形成打印填充区域的内、外边界,如图 4.8 所示,图中阴影区域即为填充区域。为了区分内、外边界,在本书中,我们定义区域外边界方向为逆时针,内边界方向为顺时针。本节的任务就是根据多边形轮廓之间的包含关系,确定各个多边形内、外边界属性,即顺、逆时针方向,最终识别出由这些多边形确定的填充区域。
