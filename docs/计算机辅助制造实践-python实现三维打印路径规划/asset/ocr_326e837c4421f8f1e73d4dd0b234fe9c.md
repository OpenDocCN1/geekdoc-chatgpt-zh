但为了增强代码的可读性，我们建议通过一个特殊的__init__方法（前后两个下划线），在类定义时就将相关属性绑定。

| | 定义一个 People 类，绑定 name、age 属性 | 1 - 10 |
|---|---|---|
| 1 | class People: | |
| 2 | def __init__(self, name, age): | # __init__函数实现 |
| 3 | self.name = name | # 绑定 name 和 age |
| 4 | self.age = age | |
| 5 | def __str__(self): | # __str__函数实现,该函数定义 People 类对象被 print 时的行为 |
| 6 | return '%s: %d'% (self.name, self.age) | # Python 字符串格式化 |
| 7 | def talk(self): | # 定义 People 中的 talk 行为 |
| 8 | print('I am %s, %d years old.'% (self.name, self.age)) | |
| 9 | # 类的使用 | |
| 10 | p = People('Jim', 11) | # 定义一个 People 对象 p,括号内可输入由__init__函数定义的参数 |
| 11 | print(p) | # 输出：Jim: 11 |
| 12 | p.talk() | # talk 函数调用,输出：I am Jim, 11 years old. |

在上例中，我们在 People 类定义时，就将 name 属性和 age 属性通过__init__函数绑定到类。__init__函数中的 self 必不可少，且必须放在第一位，self 指向创建的对象本身（类似于 C++、C#、Java 等中的 this）。类中定义的任何函数，都必须包含 self 参数且 self 参数放在首位。在定义__init__函数后，我们就可以使用类名带参数构造对象了。

在以上定义的 People 类中，我们还定义了__str__函数，这也是 Python 类中的一个特殊函数，当我们需要对自定义类的对象进行 print 时，系统将调用__str__函数进行格式化输出。此外，我们还定义了一个常规函数 talk，实现 People 类的说话功能。需要注意的是，在对象调用函数时，无需理会 self 参数。

在实际生活中，People 是一个大类，具体到学校，People 又可分为 Student（学生）和 Teacher（老师）。Student 和 Teacher 都属于 People，但各自又有不一样的特征。在面向对象的编程语言中，这种情况一般用类的继承表述。我们可以定义 Student 类和 Teacher 类（子类），这两个类都从 People 类（父类）继承：

| 5 | pass | |
| 6 | class Teacher(People) : | |

| 8 | print('I am %s, %d years old. I am a teacher '% (self.name, self.age)) | |
