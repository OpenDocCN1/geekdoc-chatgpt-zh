片层数，此时第二重循环正常结束。splitFfRegions 函数的实现流程虽然简洁，但其实并不简单，为了尽量减少代码行数，这里我们使用了 i,j 两个层序号。一般情况下，j 和 i 的差总为 1，如果进入第二重循环，j 和 i 的差大于 1 的但小于等于 endLayerNum。

值得注意的是，在 splitFfRegions 函数的开头，我们在输入切片序列 layers 的最底层之前插入了一个层高为 0 的空(虚拟)切片层，并且在函数最后，我们又删除了这个虚拟切片层。为了封闭模型，layers 的底层切片是必须使用密实填充的；但由于底层切片下方已无切片，因此，我们是无法用 pickFfRegions 函数为其提取密实填充区域的。借助虚拟切片层，我们就可以用以上介绍的统一方法为模型底层切片生成密实填充区，而不用专门寻找新的方法。

尽管以上 splitFfRegions 函数的设计初衷是寻找模型切片上的下端面密实填充区，但是考虑到上和下的关系其实是相对的，因此只要我们将模型颠倒放置，或者在调用 splitFfRegions 函数之前颠倒切片序列顺序，就能获取模型切片上端面的密实填充区。

在 splitFfRegions 函数的基础上，下面我们根据式( 11-3 )继续给出针对所有切片层的稀疏填充区域寻找函数。我们仍将这个函数写在 IdEndLayers 模块中，函数名为 splitSfRegions，具体实现如下：
