两者相等时，结果为 0。这样纯粹是在形式上进行类比，没有其他意义。我们之所以将这个函数的返回分为 3 种情况，而不是简单的 True 或 False，是因为我们要把这个函数作为回调函数，输入到 Python 的 sort 函数中，而 sort 函数对回调函数的规定是必须返回这 3 种比较结果。其他语言（如 C++）的排序函数也有类似规定。

现在我们已经拥有了一个针对 LinkPoint 的比较函数，在这个函数的基础上，我们只要通过下列代码，就能完成对链接点序列的排序：

```
1 lpnts.sort( key = functools.cmp_to_key( cmp_pntSmaller ) )
```

其中 lpnts 为用于存放链接点的列表，cmp_to_key 可将我们定义的比较函数转化为 sort 函数中的 key 参数，但使用 cmp_to_key 需要手动导入 functools 库。
