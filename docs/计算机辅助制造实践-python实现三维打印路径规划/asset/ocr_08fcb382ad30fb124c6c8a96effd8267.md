如果以为处理了以上两个问题就可以生成偏置多边形的话,那我们还是小看了偏置问题的难度。如图 8.6 所示,对于图中轮廓(多边形一部分),在偏置距离较小的时候,我们可以直接运用以上的修补方法生成它的偏置轮廓;但当偏置距离较大时,如果我们依然只是运用以上的修补方法,我们将得到一个带有自相交环的偏置轮廓。如图 8.6,自相交环上的点到原始轮廓的距离显然小于给定的偏置距离,这是不对的。可以说,偏置轮廓上的自相交环是偏置错误的表现,必须避免或消除。

但是识别和消除偏置轮廓上的自相交环并不是一件容易的事情。这不仅仅是计算量的问题,我们甚至可能找不到一种计算量大但能得到正确结果的方法。如对图 8.6 中修补得到的偏置轮廓,如果要消除自相交环,我们的想法可能是首先计算偏置轮廓的自相交点,然后在自相交点对偏置轮廓进行裁剪,去除自相交环,这种思路对这个例子也许可行,但计算量不小,需要两两遍历计算偏置轮廓上所有边的交点。如果我们对图 8.6 中的轮廓稍做修改,如图 8.7 所示,那么在修补后的偏置轮廓上,将出现若干自相交环,而且这些自相交环可能会相互嵌套,这种情况下,我们又该如何去识别和消除自相交环呢?哪些轮廓段是有用,需要被拼接到输出多边形上的?哪些轮廓段是没用的,需要被舍弃的?这些可能都需要我们在尝试大量的测试例后制定相应的规则,这样的研究可能要持续一段时间。

如果我们以为消除了以上介绍的自相交环就已经解决了多边形偏置问题的话,那我们又小看它了。我们以上介绍的自相交环都位于轮廓局部区域,我们把这种自相交环称为局部自相交环;事实上,在对多边形的偏置过程中,还可能产生全局自相交环,如图 8.8 所示。全局自相交环看起来似乎是偏置过程中的合理存在,它上面的点到对应的原始轮廓距离是满足偏置要求的,但它其实也是一种偏置错误,因为它到另一部分原始轮廓的距离小于偏置距离。全局自相交环常规的消除思路是:首先两两遍历计算偏置轮廓边的所有交点,然后根据交点对偏置轮廓进行分段,并根据每段偏置轮廓到原始轮廓的距离是否小于偏置距离决定这段轮廓是否需要保留,最后按照一定的逻辑(如轮廓段走向)拼接保留的偏置轮廓段得到若干封闭偏置多边形。但执行这种思路需要大量的计算,包括遍历求交和遍历求距离。
