b,这样做的原因我们在上一小节已有解释。

在实现了输入多边形上凹顶点角度对的计算之后，下面我们回过头再来看看图 9.25 中竖直扫描线的构造问题。从算法实现的角度来说，我们很难构造这样一条竖直扫描线，可以在 0 ~ 180 度范围内连续扫描，进而精确地找出最少跳刀角度范围。既然如此，我们可以对扫描范围进行离散，如将扫描角度间距设置为 0.1 度时，在图 9.25 中，我们可以得到约 1800 个离散扫描角度，进而我们可以构造一个扫描角度表。对角度表中的每个离散角度ω，我们可以与之关联一个变量 t，用于标识在该角度下竖直扫描线和凹顶点切线角度（线段，参见图 9.25）的交点个数。据此，我们可以构建一个双重循环，首先遍历角度表，对每个扫描角度，构建对应扫描线，然后遍历凹顶点切线角度（线段）。如果某个切线角度和当前扫描线相交，则对当前扫描角度的变量 t 累加 1。在完成上述循环后，我们只要统计角度表中各个离散角度的变量 t 值，就能找出最少跳刀填充角度。

在以上循环中，我们首先遍历角度表，然后遍历切线角度，但是，只要我们交换一下顺序，就可大幅降低遍历次数。对某个切线角度 Ψ，我们不妨设其上限和下限分别为 φ_min 和 φ_max，即 Ψ = [ φ_min , φ_max ]，这里我们暂时不讨论 Ψ 被分为两段的情况。在图 9.25 中，φ_min 和 φ_max 就是切线角度（线段）的两个端点，根据这两个端点和扫描角度的离散规则，我们不难计算出落在两端点间的所有离散扫描角度，此时我们只需对这些扫描角度对应的变量 t 累加 1 即可。显然，以上方法同样适用于切线角度 Ψ 被分为两段的情况。根据以上思路，我们只需对凹顶点切线角度使用一次遍历，就能最终找出最少跳刀填充角度。

在 Python 中，我们可以使用现成的字典类来构建上述扫描角度表，在字典中，键为角度，值为交点个数，即上述变量 t。在 FindOptFeedDir 模块中，我们将角度表的构造及初始化函数命名为 _initAngleTable，下划线前缀同样表示这并不是一个对外输出的函数，它的具体实现代码如下：

```
```python

def _initAngleTable( digit ): # 角度表构建函数，digit 为小数位数
    angleTable = { } # 角度字典
    delta = math.pow( 10, -digit ) # 角度增量
    angle = 0.0
    while angle < 180: # 在 0 ~ 180 度范围内，创建字典键
        angleTable[ angle ] = 0 # 初始化每个角度下的交点数为 0
        angle = round( angle + delta, digit ) # 保证角度小数位数为指定值
    return angleTable # 返回角度表
```
```

以上 _initAngleTable 函数只有一个输入参数 digit，表示角度表中各个角度保留的小数位数，即角度精度。比如当 digit 值为 1 时，表示保留 1 位小数，此时角度表中角度分别为：0, 0.1, 0.2, ..., 179.9，共 1800 个角度值（注意，0 度和 180 度表示的填充线重合，故忽略 180 度）；又当 digit 值为 0 时，表示保留 0 位小数，此时角度表中角度分别为：0, 1, 2, ..., 179，共 180 个角度值；以此类推。初始情况下，在角度表中，每个角度对应的交点个数为 0；后
