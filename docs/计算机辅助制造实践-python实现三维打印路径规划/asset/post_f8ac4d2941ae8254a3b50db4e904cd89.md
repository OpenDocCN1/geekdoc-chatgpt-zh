
段可以简单地以 zig-zag 的形式被连成一体，我们定义这种区域为“单连通”区域，对应的多边形为“单连通”多边形；如果这个区域内所有扫描线中存在一些扫描线被切割成多段，那么得到的填充线段将无法被连成一体，我们定义这种区域为“多连通”区域，对应的多边形为“多连通”多边形。

试想，在生成填充线之前，我们能否将输入的多边形区域进行分区，使得得到的每个独立的子区域为单连通区域？如果这个想法可行，那我们就可以顺理成章地解决上下层填充线段的识别配对难题（即上文提出的第一个问题）。而对每个子区域内生成的连接路径，我们可以站在一个更为广阔的全局的角度对它们进行优化连接。下面我们不妨实践一下这个想法，尝试对填充区域进行分区操作。

## 9.3.2 填充区域分区原理

让我们结合扫描线法原理再来看一下单连通区域和多连通区域的定义。如果一个多边形区域在每个扫描高度上都只有一条填充线段，那么我们称这个区域为单连通区域；如果一个多边形区域在某个扫描高度上存在多条填充线段，那么我们称这个区域为多连通区域。根据以上定义，单连通区域和多连通区域都是相对填充方向（即扫描线方向）而言的，如果改变填充方向，同一多边形区域可能在单连通区域和多连通区域间相互切换（如图 9.12 和图 9.13）。我们在这一小节的目标就是在指定填充方向的前提下，对输入多边形区域进行分区，使得得到的所有子多边形相对于填充方向都为单连通区域。

在实现这个目标之前，我们有必要先探索一下区域连通特性（单连通或多连通）的判别条件。首先，根据以上连通区域的定义，我们当然可以对已经生成的填充线段进行分析，比如统计同一扫描线上的填充线段数量，从中得出当前区域的连通特性。这当然是对的，但对我们要解决的区域分区问题似乎没有太大帮助。我们知道，定义区域连通特性涉及一个关键指标，即扫描线上线段的数量，或者说是扫描线被区域轮廓切割得到的线段数量。下面我们从动态平移扫描线的视角来看一下“切割”问题。

如图 9.15 所示，我们先降低难度，不妨假设填充线倾角为 0，对图中简单凹多边形多连通区域，在直线 l1 位置时，扫描线和区域轮廓有 2 个交点，被轮廓切割得到一段填充线；在直线 l 位置时，扫描线和区域轮廓有 4 个交点，被轮廓切割得到两段填充线。在扫描线从 l1 位置逐渐上移到 l 位置的过程中，我们可以预测，扫描线将在某一时刻和轮廓凹陷处开始相交，在临界状态下，扫描线和区域轮廓有 3 个交点。如果我们记临界位置为直线 l，当扫描线在 l 位置时，恰好可以将原多边形区域切分成 3 个子区域。而且，在这 3 个子区域内，在每个扫描高度上，都只有一条填充线段，因此这 3 个子区域都是单连通区域。对如图 9.15 所示的简单多连通区域，我们可以得出结论，直线 l 可以将其切分为 3 个单连通区域。我们称直线 l 为切分直线。

进一步地，在图 9.15 中，如果我们将位于直线 l 上的扫描线向上平移（如移动到 l1 位置），此时扫描线仍可将原区域切分为 3 个子区域，其中上方 2 个子区域为单连通区域，但下方一个子区域为多连通区域。反之，如果我们将位于直线 l 上的扫描线向下平移（如移动到 l2 位置），此时扫描线将原区域切分成 2 个子区域，其中上方子区域为多连通区域，下方子区域为单连通区域。由此可见，切分直线 l 的位置并非偶然，随意对其进行向上或向下平移后，我们都将无法得到全是单连通区域的子区域。

下面我们再来看一下切分直线 l 的位置确定方法。如图 9.15 所示，我们知道，在直线 l 上时，扫描线和区域轮廓的交点个数恰好发生了变化，即此时扫描线和区域轮廓之间多了（或少了，从高往低扫描时）一个交点，这里我们不妨记这个交点为 P。根据这一特性，理论上，我们可以将扫描高度间距设置为一个趋向 0 的正实数，当我们从下至上遍历这些扫描高度时，必然能够找出扫描线和区域轮廓交点数量恰好发生变化的那个扫描高度，进而确定交点 P 以及直线 l 位置。但以上方案显然不具备实际可操作性。

进一步观察我们会发现，事实上，以上交点 P 是区域轮廓的一个局部峰值点。这是合乎情理的，在扫描线移动过程中，必然首先会和轮廓的峰值点相交。因此我们得出如下结论：能够将输入多连通区域分割成若干单连通区域的切分直线必然经过轮廓的峰值点。这个结论当然是没有问题的，那反过来呢？是否所有经过轮廓峰值点的直线都可以将多连通区域切分为单连通区域呢？如图 9.15 所示，对图中的 3 个峰值点 A、B、P，我们发现，过 A 点和 B 点的直线并不能将区域切分成单连通区域，只有过 P 点的直线才能对区域进行有效切分。进一步观察，我们发现，A 点和 B 点是局部凸起轮廓上的点，而 P 点是局部凹陷轮廓上的点。如果我们称像 P 这样的点为凹峰点的话，那么，我们推断：只有经过轮廓凹峰点的直线才可以将多连通区域切分成若干单连通区域。因此，要确定切分直线的位置，我们必须首先找出区域轮廓上的凹点，然后从这些凹点中找出凹峰点。

对于一个由一组简单多边形围成的任意平面区域，如果各多边形的方向符合“外逆内顺”的规定，那么我们可以使用向量叉乘法确定轮廓上的某一点 Pk 是否为凹点，步骤如下：

- (1) 计算向量 v_k、v_{k+1}，使得：

```
v_k = P_k - P_{k-1}                     (9-7)
v_{k+1} = P_{k+1} - P_k                  (9-8)
```

式中，P_{k-1} 和 P_k 分别为轮廓上 P_k 的上一点和下一点。

- (2) 如果 P_k 满足：

```
(v_k × v_{k+1}) · dz < 0                  (9-9)
```

则 P_k 为凹点，式中 ‘x’ 为两向量叉乘符号；如果：

```
(v_k × v_{k+1}) · dz > 0                  (9-10)
```

则 \( P_k \) 为凸点；如果：

```
(v_k × v_{k+1}) · dz = 0                  (9-11)
```

则 \( P_k \) 为平点，即 \( P_{k-1} P_k \) 和 \( P_k P_{k+1} \) 平行或重合。

我们不妨验证一下以上步骤。如图 9.16 所示，该区域包括一个外边界轮廓和一个内边界轮廓，各条轮廓符合“外边逆内顺”的规定。根据以上步骤，我们可以得出在图中外边界轮廓上，点 \( P_0, P_1, P_8, P_9, P_{10}, P_{11}, P_{14}, P_{15}, P_{16}, P_{23} \) 等为凸点，而点 \( P_2, P_7, P_{12}, P_{13}, P_{17}, P_{18}, P_{21}, P_{22} \) 等为凹点；而在内边界轮廓上，点 \( P_{27}, P_{28} \) 为凸点，点 \( P_{24}, P_{25}, P_{26}, P_{29}, P_{30}, P_{31} \) 等为凹点。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_223_0.png)

图 9.16 平面区域轮廓上凹凸点寻找

对于那些具有凹凸嵌套关系的局部轮廓，如图 9.16 中的 \( P_4, P_5, P_{19}, P_{20} \)，通过以上步骤，我们仍能识别出其中凹点或凸点。而且我们发现，轮廓上点的凹凸属性具有旋转不变性，即和轮廓在平面上的摆放角度无关，即便我们对输入轮廓进行旋转操作，轮廓上原来的凹点仍为凹点，原来的凸点仍为凸点。

在解决了凹点判别问题之后，接下来我们再来看一下轮廓上峰值点的寻找方法。在中学期间，我们已学过，对连续可导的函数 \( y=f(x) \)，如图 9.17 所示，在它的函数图像上，峰值点在 \( f'(x) = 0 \) (即导数为 0) 时取到。但是显然，我们这里涉及的多边形轮廓是离散的顶点序列，非连续且不可导，因此我们不能用以上代数法求取轮廓上的峰值点。对区域轮廓上的某一顶点 \( P_k \)，向量 \( v_k, v_{k+1} \) 同样由公式 (9-7) 和 (9-8) 计算得到，向量 \( v_s \) 为扫描线方向向量：如果局部轮廓是单调上升或单调下降的，如图 9.18(a) 和图 9.18(b) 所示，那么向量 \( v_k, v_{k+1} \) 将指向 \( v_s \) 的同侧；如果局部轮廓在 \( P_k \) 点转折，达到峰值，如图 9.18(c) 和图 9.18(d) 所示，那么向量 \( v_k, v_{k+1} \) 将指向 \( v_s \) 的异侧。这是一个重要发现！我们可以得出这样的结论：向量 \( v_k, v_{k+1} \) 指向 \( v_s \) 的异侧是点 \( P_k \) 为轮廓峰值点的充要条件。有兴趣的读者不妨从理论上对其进行推导证明。

那我们如何判断两个任意向量 \( v_k \) 和 \( v_{k+1} \) 分别指向给定向量 \( v_s \) 的异侧呢？其实我们也可以用向量叉乘法解决这个问题。如果 \( v_k \times v_s \) 得到的向量和 \( v_{k+1} \times v_s \) 得到的向量所指的方向相反，更具体的，只需满足：

```
(v_k × v_s) · dz · (v_{k+1} × v_s) · dz ≤ 0   (9-12)
```

那么我们就可以判断向量 \( v_k, v_{k+1} \) 指向 \( v_s \) 异侧。式中取到等号是因为当 \( v_k \) 或 \( v_{k+1} \) 和 \( v_s \) 平行时，\( P_k \) 也为峰值点。

回到凹峰点的寻找问题。现在我们已经非常明确，对区域轮廓上的任意一点 \( P_k \)，如果它同时满足式(9-9)和式(9-12)，那么这个点就是凹峰点。问题来了，我们在上文中的所有讨论和推导都是基于填充倾角为 0 的情况，即扫描线和平面坐标系的 X 轴平行。但在实际三维打印中，这是不可能的。因此我们还需要将情况一般化，考虑当填充倾角非 0 时的情况。

在以上讨论中，我们知道轮廓上点的凹凸属性具有旋转不变性，因此当扫描线倾角非 0 时，式(9-9)仍然成立。那式(9-12)呢？事实上，轮廓的峰值是一个相对的概念，它是相对于扫描线法向上的极值。当扫描线倾角为 0 时，我们很容易理解轮廓上的局部最高点或最低点就是峰值；但当扫描线倾角非 0 时，局部最高点和最低点应从扫描线的法线方向考虑和计算，如图 9.19 所示。从这个角度来说，我们发现式(9-12)也同样适用于扫描线倾角非 0 的情况。综上所述，在填充倾角非 0 的情况下，对区域轮廓上的任意一点 \( P_k \)，如果它同时满足式(9-9)和式(9-12)，则 \( P_k \) 为凹峰点。

那我们如何根据凹峰点切分多连通区域呢？基于以上讨论，我们只要遍历区域轮廓上的所有顶点，就能从中找出所有凹峰点，然后我们可以根据这些凹峰点构造切分直线。如图 9.20 所示，对图中给定的多连通区域和填充方向，我们可以找出 3 个凹峰点，分别记为 \( P_1, P_2, P_3 \)，并记 \( l_1, l_2, l_3 \) 为分别对这三个点的切分直线。在图 9.20 中，我们发现，过每个凹峰点的切分直线不能太长，否则会对原多连通区域带来一些不必要的分区。

如图 9.20 所示，对点 P1，我们只需从 l1 和区域轮廓的所有交点中找出在 P1 两侧且距离 P1 最近的两个点即可，如果我们记这两点分别为 L1 和 R1，那么根据切分线段 L1R1 我们就可以将原多连通区域划分成 3 个子区域。其中 2 个位于上方的子区域（区域 1 和 2）为单连通区域，1 个位于下方的子区域仍然为多连通区域。同理，对得到的新多连通区域，我们可以根据过 P2 的线段 L2R2 对其进一步分区，此时我们又可以得到 2 个单连通区域（区域 3 和 4）和 1 个多连通区域。最后，对剩下的多连通区域，我们可以根据过 P3 的线段 L3R3 对其进一步分区，此时我们可以得到 3 个单连通区域（区域 5,6,7）。最终，对输入的原始多连通区域，通过 3 次分区，我们可以得到 7 个单连通区域。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_225_1.png)

显然，凹峰点数量决定了分区次数，而分区次数又决定了单连通区域个数，对任意多连通区域，如果我们进一步归纳和总结，最终可得到如下关系式：

Ns = 2 Np + 1 (9-13)

其中，Ns 为最终生成的单连通区域个数，Np 为输入区域轮廓上的凹峰点个数。

至此，我们已经完成了对填充区域分区原理的介绍。理论上，对任意简单多边形多连通区域，我们都能根据指定的填充方向对其进行分区，最终生成一系列单连通区域。需要强调的是，我们对区域分区的目的是为了更好地连接各个子区域内的填充线段。在接下来的一个小节里，我们将根据以上分区原理实现相应分区算法。

## 9.3.3 填充区域分区实现

在上一小节，我们从原理上介绍了将输入多连通区域切分成若干单连通区域的方法，包含如下步骤：

- (1) 输入多边形区域，每个多边形的方向需符合“外逆内顺”的规定。

- (2) 根据式(9-9)和(9-12)搜索并存储多边形顶点中的所有凹峰点。

- (3) 对每个凹峰点，构造一条经过它的切分线段。

- (4) 沿切分线段将多边形分割成若干单连通子区域。

- (5) 输出得到的单连通子区域序列。

在以上步骤中，我们并没有提及输入填充倾角，这其实是有原因的。在介绍使用扫描线法生成区域填充线的时候，为了降低扫描线法的实施难度、提高交点计算的数值稳定性，在填充倾角非0的情况下，我们采取首先对输入区域轮廓进行旋转的策略，使得在平面上，填充线相对于区域轮廓的倾角始终为0。必须指出的是，对输入区域进行分区是整个平行填充路径生成过程的其中一部分，我们将这部分工作放在对区域轮廓旋转之后，因此，我们认为在对填充区域进行分区时，填充线的倾角为0，即在以上步骤中，扫描线倾角为0。

下面我们再来审视一下以上区域分区步骤中的每一步，并给出相应实现代码。步骤(1)和步骤(5)是单纯的输入和输出，比较简单，其中在步骤(1)中，如果输入的多边形方向不满足“外逆内顺”的要求，我们有必要对其进行调整。对步骤(2)，因为我们已经在上一小节详细介绍了凹峰点的计算原理和方法，并给出了详细公式，因此，这一步也非常明确。我们将所有和平面区域分区相关的代码都写在 SplitRegion 类（对应 SplitRegion.py 文件）中，以上两个步骤的对应实现代码如下：

在以上代码中，我们主要实现了 SplitRegion 类的两个函数，一个是初始化函数，一个是凹峰点寻找函数。其中在初始化函数中，除了输入表示待分区平面区域的多边形列表外，我们还输入了一个 adjustPolyDirs 参数，这个参数的作用是告诉初始函数是否需要按“外逆内顺”的规则调整输入多边形的方向，如果参数值为 True，则需要调整方向，反之则无需调整方向，默认情况下为 False。设置这个参数的目的是确保输入多边形的方向都是正确的。至于凹峰点的寻找函数 findTurnPoints，它完全符合我们之前介绍的相关原理，首先遍历所有多边形上所有点，然后找出符合式(9-9)和(9-12)的点并将其添加至凹峰点列表。

下面我们再来看一下步骤(3)，即根据凹峰点构造切分线段。它的核心是计算过凹峰点的扫描线和多边形的所有交点，然后再从所有交点中筛选距离凹峰点两侧最近的两个交点。因此，在这一步中，我们事实上需要处理两个问题，一是求交，二是筛选。在求交环节，考虑到我们可能需要同时处理多个凹峰点，即解决多条扫描线和多边形的求交问题，这个问题和我们在本章 9.1 节解决的填充线交点计算问题十分相似，calcHatchPoints 函数完全适用于这里的求交场景。该函数的输入包含多边形列表和扫描高度列表两个部分，对这里的求交场景，多边形列表就是需要分区的多边形区域，扫描高度列表就是一系列由凹峰点 y 值组成的列表。

在解决了以上求交问题之后，我们再来看交点的筛选问题。calcHatchPoints 函数返回的是交点的二维列表，其中第一个维度表示不同层高，第二个维度表示同一层高上不同的交点。以某个凹峰点为例，如图 9.20 所示，我们需要从以上二维交点列表中找出同一高度上距离该凹峰点两侧最近的两个交点。为了实现筛选目标，我们在 SplitRegion 类中定义了一个 findLRPoints 函数(L、R 分别表示 left 和 right)，它的具体实现代码如下：
