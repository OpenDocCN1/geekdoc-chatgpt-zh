点,我们习惯将 w 设为 1,即(x, y, z, 1),此时齐次坐标和笛卡尔坐标在对应维度数值上保持一致,便于理解。

# 2.1.2 向量

在计算几何中,向量是反映两点之间的一种关系量。虽然向量和点都由坐标表示,但两者有所不同,点有位置的概念,而向量没有位置,只有方向和长度(模)的概念。向量在空间中经任意平移后,它所表示的几何意义不变,因此我们可以认为向量来自无穷远处。和点一样,向量同样可以用齐次坐标表示,在定义一个三维向量的齐次坐标(dx, dy, dz, dw)时,我们规定 dw = 0,即(dx, dy, dz, 0)。

向量可以看成是空间中一个点 P1(x1, y1, z1, 1)到另一个点 P2(x2, y2, z2, 1)的增量部分,如果用 V 表示这个增量,那么 V 的坐标为(x2-x1, y2-y1, z2-z1, 0)。对向量和点,我们可以定义加号、减号操作符(‘+’, ‘-‘),使得:

+   V = P_2 - P_1 (2-1)
+   P_2 = P_1 + V (2-2)
+   P_1 = P_2 - V (2-3)

以上公式(2-1)表示一个向量可以通过两个点相减得到,向量的指向是从 P1指向 P2;公式(2-2)和公式(2-3)表示一个点可由另一个点加上(或减去)一个向量得到,即一个点可以通过另一个点平移得到。
