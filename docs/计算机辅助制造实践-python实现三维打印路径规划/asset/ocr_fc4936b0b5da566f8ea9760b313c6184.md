乘以指定的放大系数,否则我们将无法得到正确的偏置结果。

# 8.5 轮廓路径生成与连接

根据之前介绍可知,轮廓平行填充路径就是对表示打印区域的边界轮廓连续偏置若干次后连接得到的路径,因此我们在这一节需要完成两个任务,一是根据三维打印的工艺特点生成连续偏置曲线,二是连接这些偏置曲线,得到一条(或若干条)可以遍历这些偏置曲线的打印路径。

# 8.5.1 连续偏置曲线生成

对某一指定层高上表示打印区域边界的一组轮廓,为了保证工件能够获得较高的表面质量,根据三维打印工艺需求,我们需要对这组轮廓连续向内偏置一定次数,以生成能够覆盖打印区域边缘的具有均匀厚度的填充带。以 FDM 工艺为例,如果设填充带厚度为 W,打印机喷头直径为 Ω,那么我们大致需要对边界轮廓连续偏置 W/Ω 次(取整)。在这一过程中,我们需要关注并解决以下几个问题。

首先是连续偏置中每次偏置距离的取值问题。根据以上设定,打印机喷头直径为 Ω,即每次从喷头挤出的热熔丝材的宽度为 Ω,如图 8.22 所示,为了保证打印模型在尺寸上恰好等于设计模型,不至于放大或缩小,首次偏置距离应设置为 Ω/2,即喷头半径尺寸。随后,为了实现相邻偏置路径之间的无缝填充,其他偏置距离应设置为 Ω。理论上,第 1 次填充后,填充带宽度为 Ω;第 n 次填充后,填充带宽度为 nΩ。
