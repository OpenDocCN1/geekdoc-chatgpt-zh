# 本 章 小 结

在这一章，我们在前面几章知识的基础上，开始尝试对一个 STL 模型进行切片，输出每层切片轮廓。我们从模型数据源入手，首先介绍了 STL 文件的数据存储格式，并封装了一个 StlModel 类从文件或 VtkSTLReader 加载三角面片的数据。对 STL 模型的切片可以分解为几个子问题：一是平面和三角形的求交问题，二是截交线段的拼接问题，三是轮廓线的方向识别和调整问题。针对这几个问题，我们分别介绍了相应算法，并在 SliceAlgo 模块中实现了相应的函数来解决这些问题。为了保存得到的切片轮廓数据，我们又介绍了 SLC 文件格式，并实现了 SLC 文件的存取。最后，我们使用面向对象编程的思想，将上述切片功能统一封装在 SliceModel 类中。在解决以上第一、第二个子问题时，我们并未考虑算法执行效率，使用了暴力法，这是必要的过程，在得到更好的算法之前，暴力法是稳定有效的。
