在以上 ClipperAdaptor 类中，初始化函数中的参数 digits 用于指定 Clipper 库的数值运算精度，即输出结果保留的小数位数，其原理我们已在上面有所介绍，默认情况下，该适配器类的数值精度为小数点后保留 7 位有效数字。属性 arcTolerance 用于指定劣角顶点偏置圆弧衔接中的圆弧离散精度。在 Clipper 库中，arcTolerance 就是离散得到的弦的弓高误差，弓高误差是指弦到真实圆弧的最大距离值，如图 8.21 所示，显然，弓高误差越小，弦就越接近真实圆弧，即用弦代替圆弧的精度就越高，但最终得到的弦的总数就越大。在图 8.21 中，我们甚至可以得出弓高误差和弦长的关系。在 Clipper 库的官方文档中，也有一个表示圆弧精度的变量，且它的默认值为 0.25 个单位，这是相对于 Clipper 中的整型数据来说的。这里我们设置 arcTolerance 的默认值为 0.005 毫米，在具体使用时，我们也要考虑对该值进行放大处理。

在 ClipperAdaptor 类中，我们封装了 2 组在形式上十分相似的多段线转化函数，即我们自己的 Polyline 和 Clipper 内置 Path 的相互转化函数，它们分别是 toPath/toPaths 和 toPoly/toPolys，其中带‘s’的函数表示转化的多段线为复数形式。需要说明的是，因为 Path 为二维平面多段线，而 Polyline 为三维多段线，因此在将 Polyline 对象转化为 Path 对象时，Polyline 对象的 z 坐标信息将全部丢失；而当我们需要将由 Clipper 库运算返回的 Path 对象转化为 Polyline 对象时，需要从外部额外输入 z 坐标信息，这也是以上 toPoly/toPolys 函数带 z 参数的原因，默认情况下，z 值为 0。此外，Polyline 和 Path 对多段线是否封闭的定义不太一致：对 Polyline 对象，如果它是封闭的，那么它的首尾两个顶点重合；而对 Path 对象，即便它是封闭的，它的首尾两个顶点也不会重合，我们只能从相关代码的上下文语境理解 Path 对象是否封闭。因此，对 Clipper 库运算返回的 Path 对象，当我们把 Path 转化为 Polyline 时，我们需要从外部指定多段线是否重合，这正是以上 toPoly/toPolys 函数带 closed 参数的原因，默认情况下，closed 值为 True，即默认 Clipper 库返回的多段线是封闭的。
