直接从文件中读取，我们之前也从没针对这些截交线段设计过文件保存方法。这时候如果我们直接从 STL 模型出发，先截交，得到散乱线段集，后拼接，可能会浪费一定的时间。而且，更重要的是，我们在第 5 章的测试中也已发现，尽管模型中包含了几十万甚至上百万的三角面片，但在具体到某一高度的截平面时，最终得到的截交线段数量不会太多，它的数量可能只是几百或几千，这样的线段数量对于我们要测试的截交算法来说简直是太少了！我们希望，测试样本中需要拼接的线段数量也能达到几十万、上百万甚至上千万。

# 6.5.1 散乱线段生成

根据以上介绍，我们需要的散乱线段应该满足如下要求：它们在平面上必须呈散乱无序的分布状态，但内在逻辑上又能连接成若干封闭轮廓，而且在数量上至少能够达到百万甚至千万的级别。能够设计优秀的算法是一种能力，能够找到或构造对应的测试样本同样是一种非常重要的能力，这种能力有助于我们从实践中检测算法的可行性和性能。

显然我们不能妄想随机生成的一些线段恰好能够连成轮廓。但我们可以转变思路，从先有轮廓的角度出发，生成一些封闭轮廓，然后对轮廓进行细分，得到线段。这才是正确的思路。那现在的问题是如何生成封闭轮廓呢？在平面几何中，最简单的封闭轮廓有三角形、矩形、圆形等，显然，圆形就是我们想要的封闭轮廓，因为圆上的点由简单的、一致的公式控制，而三角形和矩形上的点则需要分段公式控制。现在我们已经选择了圆作为封闭轮廓，我们可以以进一步使用一系列半径不等的同心圆作为多个轮廓，这样做的好处是可以保证各个轮廓之间不相交，这符合现实三维打印对轮廓的要求。下面我们使用若干同心圆来模拟封闭轮廓，并将这些轮廓细分成散乱线段。在 XY 平面上，对于一个圆，如图 6.7 所示。
