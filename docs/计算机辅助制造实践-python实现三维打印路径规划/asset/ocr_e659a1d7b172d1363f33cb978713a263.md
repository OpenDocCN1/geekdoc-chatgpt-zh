在 Python 环境下，如果我们使用命令行的方式安装 Clipper 库，那么库中最为核心的类是 Pyclipper 类。它封装了几个关键接口函数 AddPath/AddPaths、Execute/Execute2，其中 AddPaths 是 AddPath 函数的复数形式，用于一次性添加多条轮廓，Execute2 是 Execute 的重载函数，它们的功能相同但输出轮廓的组织形式有所差异。下面我们结合具体实例来看一下 Pyclipper 类的使用方法，我们把测试代码写在 Test_clipper.py 文件中。
