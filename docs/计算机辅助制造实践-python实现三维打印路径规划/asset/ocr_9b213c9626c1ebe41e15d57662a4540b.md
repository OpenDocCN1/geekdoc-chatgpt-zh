我们在 Plane 中定义的第三个函数是 intersect 函数，这个函数的功能是计算当前平面和另一平面的截交线，如果两个平面不平行（或不重合），返回 Line 类型的交线；反之，返回 None，即没有交线。这个函数的实现原理非常简单，首先求取截交线的方向向量，这个向量可由两张平面的法向叉乘直接得到，如果叉乘结果为零向量，则表示两平面平行（或重合），此时没有交线。交线上的任意一点通过求解式（2-14）得到，式中 A1、B1、C1、D1、A2、B2、C2、D2 均为已知量，x、y、z 为未知数，即两个方程，三个未知数。
