
将所有可能和 y 线相交的线段全部收集到了扫描线中，只有在前期准备数据时根据多边形边的相邻关系建立各条线段的链接结构，即在每条线段中存放与之相邻的上一条线段和下一条线段的引用。这无疑会增加 calcHatchPoints 函数的实现的复杂程度。有兴趣的读者可使用条件 2 判断是否应该将线段添加至扫描线，并对函数的其他部分做出修补。

在代码 9-2 中，我们使用的是条件 1，即当线段满足 yMin < y 且 yMax ≥ y 时，才将其添加至扫描线。首先，使用这个条件会自然排除那些和 y 线重合的线段。其次，如图 9.5 所示，同样对那些端点落在 y 线上的线段，使用条件 1 会为扫描线筛出那些位于 y 线下方的线段，即图中线段 s1 ~ s5；排除那些位于 y 线上方的线段，即图中线段 s7 ~ s11。在这种情况下，我们可以得到初始交点序列 P0 ~ P7。比较图 9.4 和图 9.5，在图 9.5 的 P5 处，我们自然而然地仅生成了一个符合正确填充逻辑的交点，这在使用条件 2 时是难以想象的。但是使用条件 1，我们还是生成了一些重合的交点对，如图 9.5 中的 P1, P2，但是这并不会对填充结果的正确性造成影响。而且，考虑到我们使用了 SweepLine 的 intersect 函数计算 y 线和线段的交点，这个函数会从初始得到的交点序列中删除重合的交点对，因此我们最终将得到 P0, P3, P4, P5, P6, P7 这 6 个交点，生成 P0P3, P4P5, P6P7 这 3 条填充线段。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_208_0.png)

以上我们见证了一个看起来毫不起眼的等号对算法结果产生的巨大影响，这从一个侧面督促我们以后在设计判断条件时需要深思熟虑，哪怕这个条件看起来非常简单。通过这一小节的介绍，我们实现了一个 calcHatchPoints 函数，可以高效地为输入多边形和扫描高度序列计算填充线的交点。这个函数不接受角度参数，它只能用来生成和 X 轴平行的填充线，显然这是无法满足实际三维打印对平行填充路径的要求的。在下一小节，我们将在以上函数的基础上进一步介绍填充线方向的调整方法。

## 9.1.3 填充线方向调整

通过上一小节介绍，我们已经能够为指定的多边形和扫描高度序列生成一系列交点，根据填充线的奇偶提取原则，我们可以非常方便地将这些交点转化为填充线。但是目前，我们只能为多边形生成和 X 轴平行的填充线，即在图 9.1 中，填充线的倾角 θ 只能为 0，这对三维打印应用来说是不够的。在三维打印中，如图 9.6 所示，我们一般要求上下层切片间的平行填充路径能够呈一定的角度（如 90 度），在上下层材料之间形成相互交错的编织效果，以增加层间强度，这是三维打印的工艺特点。我们在本书的任务就是为输入多边形生成方向可调的填充线。

生成非零倾角的填充线有两种基本思路，其中第一种思路是改变扫描线的角度，类似图 9.2 所示，将所有线段投影到扫描线的法线方向进行排序。这样做虽然直观，但会增加算法的实现难度，而且，当扫描线不和 X 轴平行时，对线段端点是否落在扫描线上这一临界情形进行判断的数值稳定性将大大下降，这对后续填充线的提取是致命的。因此，改变扫描线角度这种思路不太可取。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_209_0.png)

图 9.6 三维打印上下层交叉编织填充工艺

生成非零倾角填充线的第二种思路是对输入多边形进行旋转。和物理学中相对运动的概念类似，既然改变扫描线的角度难度这么大，那么我们就尝试去改变多边形的角度。如图 9.7 所示，当填充线的倾角 θ 大于 0 时，我们可以先对输入的多边形绕平面坐标系原点旋转 -θ 角度，其中负号表示旋转方向为顺时针。对得到的多边形，我们可以根据填充线的间距生成一组高度序列 ys，然后将旋转多边形和 ys 输入我们之前实现的 calcHatchPoints 函数，生成填充线交点。对得到的交点，我们可以按照填充线提取原则将其转化为填充线段。此时所有的填充线段都和 X 轴平行，但是它们没有落在正确的位置上。我们最后需要做的就是将得到的填充线段坐标系原点旋转 θ 角度，让其落在原多边形内部。旋转后的填充线段就是我们要求的填充线段，它们相对于 X 轴正向的倾角恰好为 θ。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_209_1.png)

图 9.7 通过旋转多边形的方式改变填充线方向

以上第二种思路可以概括为：旋转多边形，计算填充线交点，旋转填充线段。考虑到我们已经在上一小节实现了 calcHatchPoints 函数，因此接下来我们只需解决多边形（Polyline）和线段（Segment）的旋转问题。

下面我们考虑在 GenHatch 模块中实现一个为输入多边形生成任意指定倾角填充线的函数，我们把这个函数命名为 genSweepHatches，意思是生成间距均匀的填充线，它的具体代码如下：

```python
...... # 导入相关库，省略其他代码
def genSweepHatches(polygons, interval, angle): # 定义均匀填充线生成函数
    mt = Matrix3D.createRotateMatrix('Z', -angle) # 旋转矩阵, matrix to, 去
    mb = Matrix3D.createRotateMatrix('Z', angle) # 旋转矩阵, matrix back, 回
    rotPolys = [] # 存储旋转后多边形
    for poly in polygons: # 遍历，旋转多边形，作用 mt
        rotPolys.append( poly.multiplied(mt) )
    yMin, yMax = float('inf'), float('-inf') # 获取旋转后多边形最低和最高值
    for poly in rotPolys:
        for pt in poly.points:
            yMin, yMax = min(yMin, pt.y), max(yMax, pt.y)
    ys = [] # 存储扫描线高度
    y = yMin + interval # 起始高度
    while y < yMax: # 根据输入间距生成高度列表 ys
        ys.append(y)
        y += interval
    segs = genHatches(rotPolys, ys) # 对旋转多边形生成填充线段
    for seg in segs: # 遍历，旋转填充线段，作用 mb
        seg.multiply(mb)
    return segs # 最后返回回旋转后的填充线列表

def genHatches(polygons, ys): # 填充线生成函数，不涉及旋转
    segs = []
    ipses = calcHatchPoints(polygons, ys) # 生成填充线交点，二维列表
    for ips in ipses: # 根据填充线奇偶提取原则从交点
        for i in range(0, len(ips), 2): # 列表中提取填充线
            seg = Segment(ips[i], ips[i+1])
            segs.append(seg)
    return segs # 返回填充线段，一维列表
```

以上 genSweepHatches 函数有 3 个输入参数，其中 polygons 就是需要被填充的多边形，interval 是填充间距，angle 是填充线相对于平面坐标系 X 轴的倾角。因为是均匀填充，因此所有相邻填充线间的间距相等。在这个函数中，我们首先创建了两个旋转矩阵变量：mt 和 mb，其中 mt 用于将几何实体顺时针旋转指定角度，而 mb 用于将几何实体逆时针旋转指定角度。开始时，我们对输入多边形列表中的每个多边形作用矩阵 mt，得到旋转多边形列表。在生成均匀的扫描线高度列表 ys 后，我们通过调用 genHatches 子函数生成了相对于旋转后多边形的填充线。最后，我们对这些填充线作用矩阵 mb，得到目标多边形的填充线。

以上 genHatches 函数的作用是根据输入多边形和扫描高度列表生成填充线段列表。其核心是调用 calcHatchPoints 生成多边形和平行线的交点列表，然后根据填充线奇偶提取原则将交点列表转化为填充线列表。我们可以看到，这里 genHatches 函数和 calcHatchPoints 函数的输入一样，仍然不包含填充线的倾角，因此它也只能返回和 X 轴平行的填充线。需要注意的是，genHatches 函数输出的填充线列表是一个一维列表，它失去了扫描线的层次信息，我们将无法从这个返回列表中直接判断两条填充线段是否在同一条扫描线上（当然通过比较线段坐标信息还是可以间接判断的）。将填充线返回为一个一维列表的原因是我们在后面将会把输入的平行填充区域拆分成若干子区域，而在每个子区域内，在一个扫描高度上将只会有一条填充线。

至此，我们已经完成了一个针对平面区域的平行线填充算法，由于使用了扫描线法的框架，因此上述算法的运行效率非常高，它的时间复杂度不超过 O((m+n) log (m+n))，其中 m 为平行线数量，n 为多边形总边数。在此基础上，我们实现并封装了一个 GenHatch 模块。按理，接下来我们就可以使用这个模块去生成用于三维打印的平行填充路径，进而去解决诸如路径连接、路径优化等方面的问题。但是，在此之前，我们有必要再介绍一种“现成”的生成区域平行填充的方法。

## 9.2 基于裁剪的填充线生成

我们在实现基于扫描线的平行线填充算法过程中，解决了几个关键问题，如线段端点落在 y 线上时求交的数值稳定性、重合交点对的删除等，而解决这些问题用到的思路和技巧是我们今后实现其他复杂几何算法的基础。尽管如此，我们可能又造了一个轮子，因为在我们之前介绍的第三方库 Clipper 中，已经包含了生成平面区域填充线的方法。我们在这一节的任务就是对现成的方法进行封装，转化为直接能用的函数。

### 9.2.1 平行线段生成原理

如图 9.1 所示，如果我们不是从求交，而是从其他角度去观察图中填充线和平行线以及多边形间关系的话，我们会发现，求取填充线的过程其实就是以多边形为窗口对平行线进行裁剪的过程。而裁剪正是 Clipper 库最擅长做的事！正如我们在第 8 章中介绍的，Clipper 支持四种裁剪操作，包括：交（intersection）、并（union）、差（difference）、异或（xor）。Clipper 的强大之处在于它除了能够处理封闭轮廓间的裁剪问题外，还支持封闭轮廓和开放轮廓的求交裁剪操作，即求落在封闭轮廓（窗口）内的开放轮廓，而这一功能正好满足我们生成填充线的需求。

结合图 9.1，对输入的多边形区域，使用 Clipper 库在其内部生成平行填充路径的步骤如下：

- (1) 生成一组指定倾角且能覆盖整个区域的平行线段序列；(2) 以多边形区域为窗口，对平行线进行裁剪，输出填充线。

有了 Clipper 库的支持，生成填充线的步骤变得异常简洁，我们无需再去处理那些烦人易错的求交问题。现在我们唯一需要关注的就是步骤(1)。在上一节使用扫描线法时（参考代码 9-5），因为我们首先旋转了多边形，所有的平行线都和平面坐标系的 X 轴平行，因此我们只需找出旋转后多边形在 Y 方向上的最小值 yMin 和最大值 yMax，然后根据输入间距在 yMin 和 yMax 之间生成扫描高度序列 ys 即可。如果使用 Clipper 库，虽然我们不用再去旋转多边形，但我们需要输给它实实在在的带倾角的线段对象，这是因为 Clipper 库只能处理多段线对象（线段也是一种多段线），而无法处理直线对象。

对任意给定的多边形区域，填充间距和填充倾角，该如何生成能够覆盖整个区域平行线段序列呢？理论上，我们只需在整个平面范围内生成无数条无限长的平行线段，那么这些线段必然能够覆盖到整个填充区域。但这样做显然是不现实的，我们没这么多时间，也没这么大的存储空间。从计算资源优化利用的角度来说，生成的平行线段序列最好能够恰好覆盖整个多边形区域。这个时候，我们最容易想到的是首先在给定多边形序列的轴平行（axis-aligned）包络矩形内生成一系列平行线段，如图 9.8 所示。即便如此情况下，我们发现，因为线段的长度不定，想要获取这些线段的端点也并非易事，需要付出额外的求交运算，这绝对不是我们想要的。

在图 9.8 中，我们发现，当平行线倾角变化时，落在包络矩形内部的平行线段的最大长度不会超过包络矩形的对角线长度。因此，理论上，只要设置每条平行线段的长度为包络矩形的对角线长度，平行线段就能覆盖整个多边形区域。如图 9.9 所示，我们首先做包络矩形的外接圆，并记其圆心为 O，半径为 R；然后，我们过 O 点做垂直于填充线方向（图中 v，v 相对于 X 轴倾角为 θ）的直线 P1, P2，其中 P1, P2 分别为该直线和圆弧的交点。此时，我们只需在线段 P1 P2 上根据指定的填充间距（图中 d）取点，并以这些点为垂足做 P1 P2 的一系列垂线段，使得垂线段的长度为 2R，且中点落在 P1 P2 上。这些垂线段就是我们要求的能够覆盖整个多边形填充区域且带指定倾角的平行线段。下面我们给出这些平行线段的计算步骤：

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_213_0.png)

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_213_1.png)

- (1) 计算输入多边形序列在 X、Y 方向的极值 xMin、xMax、yMin、yMax；
- (2) 计算多边形包络矩形外接圆圆心 O 点坐标和半径 R，其中圆心 O 坐标为：

  $$
  \left(\frac{xMin + xMax}{2}, \frac{yMin + yMax}{2}\right)
  $$

  半径 R 长度计算公式为：

  $$
  R = \frac{\sqrt{(xMax - xMin)^2 + (yMax - yMin)^2}}{2} \tag{9-1}
  $$

- (3) 根据倾角 θ 计算填充方向向量 v 和 v 的左法向量 n，其中 v 向量坐标（二维）为：

  $$
  (\cos(\theta), \sin(\theta))
  $$

  n 向量的坐标为：

  $$
  \left(\cos\left(\theta + \frac{\pi}{2}\right), \sin\left(\theta + \frac{\pi}{2}\right)\right)
  $$

- (4) 计算 P1、P2 点坐标，其中：

  $$
  P_1 = O - n \cdot R \tag{9-2}
  $$

  $$
  P_2 = O + n \cdot R \tag{9-3}
  $$

- (5) 在直线 P1P2 上计算从 P1 开始，间距为 d 的垂足点序列，其中第 i 个垂足点（记为 Qi）的计算公式为：

  $$
  Q_i = P_1 + n \cdot (d \cdot i), \quad 0 \leqslant i \leqslant 2R/d \tag{9-4}
  $$

- (6) 根据垂足点序列计算平行线段序列，其中第 i 条平行线段两端点（记为 Ai、Bi）的计算公式为：

  $$
  A_i = Q_i - v \cdot R \tag{9-5}
  $$

  $$
  B_i = Q_i + v \cdot R \tag{9-6}
  $$

以上 6 个步骤的输入为多边形序列、填充间距 d 以及填充倾角 θ，最终输出为能够覆盖整个多边形区域的带倾角的平行线段序列。有了这些平行线段，接下来就是 Clipper 库发挥作用的时候了。
