以上代码只针对 bunny 模型展开测试，如果我们需要更改模型，只需在 readStlFile 函数中指定相应文件路径即可。针对同一个模型，我们设置了 3 种切片厚度，分别为 1.0 毫米、0.5 毫米、0.2 毫米。在代码中，我们使用 time 模块的 clock 函数获取算法执行时间，即在算法执行前，我们调用 clock 函数获取当前 CPU 时间，在算法执行后，同样使用 clock 函数获取当前 CPU 时间，一前一后差值即为算法执行花费的时间。

表 5.1 给出了针对各个模型、各种截交算法的运行时间统计。通过表 5.1，我们可以非常清楚地看到，首先，扫描平面法(sweep)和层高匹配法(match)相对于暴力法(brutal)，其执行效率基本上会高一个数量级(5.9~22 倍)，这验证了扫描平面法和层高匹配法确实有效，也从另一个角度对我们的工作进行了肯定。其次，就扫描平面法和层高匹配法而言，两种方法在执行效率上相差无几，处在同一水平线上，但扫描平面法稍胜一筹，基本比层高匹配法效率高 10% 以上。

还记得我们在本章一开始提到的 intersectTriangleZPlane 函数吗？这个函数是三角面片和截平面求交的基础。在这个函数中(参见代码 4-4)，我们有对截交的情形做过非常基础的预处理，即当面片高于或低于截平面时，则直接返回 None。我们在本章一开始也给出了数据，说明暴力法极度依赖这个预处理。但是，有兴趣的读者去测试会发现，扫描平面法和层高匹配法不太依赖这个预处理，即便删除 intersectTriangleZPlane 中的预处理代码，对两种算法的性能也不会造成什么影响。这在原理上也是可以解释的。
