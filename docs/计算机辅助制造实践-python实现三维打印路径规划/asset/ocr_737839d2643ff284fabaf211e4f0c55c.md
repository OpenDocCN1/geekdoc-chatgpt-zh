```
41      index = p.other.index    # 获取 p.other 在 lpnts 中序号
42      if index-1 >= 0 and p.other.toPoint3D().isCoincide(lpnts[index-1].toPoint3D()):
43          p = lpnts[index - 1]    # 比对 index 前一点是否重合
44      elif index+1 < cnt and p.other.toPoint3D().isCoincide(lpnts[index+1].toPoint3D()):
45          p = lpnts[index + 1]    # 比对 index 后一点是否重合
46      else:     # 都不满足则跳出第 2 层循环
47          self.polys.append(poly)    # 将 poly 保存到 polys 中,非封闭
48      break    # 不正常的退出
```

下面我们来看一下以上 LinkSegs_dorder 类的实现代码。这个类的封装风格和我们在上一章介绍的 IntersectStl_sweep 类以及 IntersectStl_match 类十分相似。在类的初始化函数中,我们通过参数 segs 从外部输入截交线段列表,contours 属性用于保存封闭轮廓,外部函数通过这个属性可以获取最终输出,polys 用于保存在拼接过程中可能出现的非封闭轮廓。

在 LinkSegs_dorder 类中,link 函数是执行线段字典序拼接的核心函数,它基本还原了图 6.4 所示的拼接流程:从数据点准备到第 1 层循环、第 2 层循环等。这里数据点准备是通过函数 CreadtList 实现的,该函数可以根据输入的线段序列生成按字典序排序的链接点列表。在第 1 层循环中,我们通过 findUnusedPnt 函数从 lpnts 列表中找出一个没有用过的链接点,如果找不到这样的点,该函数返回-1;否则返回一个大于等于 0 的点序号。如果函数 findUnusedPnt 返回-1,则退出第 1 层循环。在第 2 层循环中,当我们获得 p.other 的 index 值后,首先比较 p.other 和 lpnts[ index - 1] 是否重合,这里我们将链接点转化为 Point3D 对象进行比较,比较函数是 isCoincide 而非 isIdentical,这是一种偏安全的做法,可以增强拼接算法的鲁棒性。尽管我们在 LinkPoint 的初始化函数中对点的坐标保留了指定的小数位数(7 位),但仍然无法保证所有本应重合的点坐标完全一致。此外,在以上代码中,我们首先判断了 index-1 >= 0 和 index + 1 < cnt,这其实是非常重要的,这样做的目的是保证列表访问不越界。

在 LinkSegs_dorder 类中,link 函数第 2 层循环的退出条件有两个,其中一个条件是正在生长的多线段 poly 闭合了,这种退出是正常的退出,得到的轮廓也是我们想要的封闭轮廓;另一个条件是当前的 p.other 找不到序号相邻的重合点时退出,这种退出是不正常的退出,此时得到的多段线是非封闭的,这并不是我们想要的。出现这种情况的原因可能有两个:一是输入的 STL 模型本来就是非封闭的(有孔洞);二是 STL 模型中相邻面片间的缝隙过大,这些其实都是模型本身的问题。如果是因为第 2 个原因,我们可以首先收集这些非封闭的多段线,然后通过适当降低点的重合误差对这些多段线进行进一步拼接,因为这样的多段线数量必然不多,因此后期可直接使用暴力法进行拼接。
