此外，直线和三角形边界线的求交（线线求交）操作是不可避免的，虽然这并不困难，用我们之前封装的 GeomAlgo 模块就可以解决，但毫无疑问，这样会让变异操作变得非常繁琐。如图 10.26 所示，在不失变异意义的前提下，简单起见，我们用上述三角形的包络矩形替换三角形本身，并求取落在包络矩形外且在正方形定义域内的随机点作为变异后的粒子。通过这种方式，我们进行简单的坐标比较便可求出变异后粒子位置。

如上所述，我们取消了粒子的速度项，改进了粒子的进化极值，避免了粒子越界的可能性，同时引入了粒子的变异机制，降低算法由于陷入局部最优而无法“跳”出的风险，而且在上一小节，我们也已经给出了粒子适应度的计算函数。关于粒子的所有重要属性和行为都已介绍，下面我们在 PsoModelPos 模块中定义粒子类，类名为 Particle，具体实现代码如下：

| PsoModelPos.py | 定义粒子类，封装拷贝、适应度、变异等函数 | 10 - 14 |
|---|---|---|
| 1 | ...... | # 导入相关库，忽略其他代码 |
| 2 | amax = 2 * math.pi | # 模型转角取值上限 |
| 3 | class Particle: | # 定义粒子类 Particle |
| 4 | def __init__( self, a = None, b = None, f = None ) : | # 粒子初始化函数 |

| 6 | self.b = uniform(0, amax) if b is None else b | # 属性 b 为模型绕 Y 轴转角 |
| 7 | self.f = float('inf') if f is None else f | # 属性 f 为粒子适应度 |

| 23 | else: | |
| 24 | if random() < 0.5: | # 变异点在包络矩形上下两侧 |
| 25 | self.b = uniform(0, min(self.b, LP.b, GP.b)) | |
| 26 | else: | |
| 27 | self.b = uniform(max(self.b, LP.b, GP.b), amax) | |

在以上代码中，我们看到，Particle 类的初始化函数包含 3 个输入参数，a、b、f，分别对应类中三个同名同义属性，其中 a、b 表示模型绕 X、Y 轴的旋转角度，即上文所述的α和β，f 为粒子适应度。在构造粒子实例时，如果外界不输入任何参数，则初始化函数会调用 Python random 模块中的 uniform 函数自动在[0, amax]范围内生成两个随机数，并将这两个随机数赋给转角属性 a、b，同时对适应度属性 f 赋浮点数最大值；否则则根据外界输入的 a、b、f 值构造粒子。注意，以上 amax 是用来控制转角α、β上限的全局变量(这里值为 2π)，在上文叙述中，为了方便理解，我们指定了α、β的定义域为[0, 2π]；在代码实现时，我们对定义域的上限进一步参数化，即α、β的取值范围为[0, amax]，方便后期更改转角定义域。

此外，在 Particle 类中，我们还定义了 4 个函数，分别为 clone、fitness、evolve 和 vary。顾名思义，clone 函数的作用就是根据当前粒子复制一个新粒子对象，这个函数虽然简单，但在后面我们将看到它在粒子群算法实现中是必不可少的。函数 fitness 的作用是求取当前粒子的适应度值，它完全依赖于我们在上一小节实现的计算粒子适应度的全局函数。函数 evolve 的作用是根据以上介绍的式(10-11) 对粒子进行进化操作，在它的 4 个输入参数中，LP 和 GP 分别表示个体极值粒子和全局极值粒子(参见图 10.25)，wL 和 wG 分别为进化中个体极值和全局极值相对于当前粒子本身的权重系数，参见式(10-13)。

接下来我们着重来看一下 vary 函数。它的作用是按照指定的概率让粒子发生变异，包含 3 个参数，分别为 prob、LP、GP。其中 prob 为 probability 缩写，表示当前粒子发生变异的概率，取值为[0, 1]，一般情况下，粒子变异的概率不能设置得太高，否则会影响粒子群算法收敛。参数 LP、GP 仍然表示个体、全局极值粒子，在 vary 函数中引入这两个粒子的作用是构建如图 10.26 所示的三角形及其包络矩形，便于我们定位变异后的粒子位置。在 vary 函数中，我们首先调用了 random 函数生成了一个 0 到 1 之间的随机数，并且让这个随机数和指定概率 prob 比较，如果随机数小于 prob (如 0.01)，则执行变异操作，通过这种机制，我们可以控制变异发生的概率。如果粒子需要变异，首先我们对 a (即转角 α) 生成一个 [0, amax] 范围内的随机数。如图 10.26 所示，如果 a 在包络矩形的左侧或右侧，则对 b (即转角 θ) 同样生成一个 [0, amax] 范围内的随机数；否则则对 b 在包络矩形的下侧和上侧范围内生成随机数。这样我们就可以在包络矩形外、定义域内生成一个变异随机粒子。

## 10.4.4 改进粒子群算法实现

上一小节我们结合实际应用背景，给出了粒子群算法中粒子的详细定义，包括粒子的若干属性和行为。结合上述粒子定义，同时考虑改进的粒子进化机制和新增的粒子变异环节，下面我们对常规粒子群算法进行改造，给出改进粒子群算法的基本步骤，包括：

- (1) 随机初始化 N 个粒子的位置 Pi，其中 i ∈ [1, N]；
- (2) 根据指定适应度函数计算每个粒子适应度；
- (3) 比较粒子群中每个粒子 Pi 和与其对应的个体极值粒子 LPi 的适应度，如果 Pi 优于 LPi，则用 Pi 替换 LPi；
- (4) 比较粒子群中每个粒子 Pi 和全局极值粒子 GP 的适应度，如果 Pi 优于 GP，则用 Pi 替换 GP；
- (5) 对粒子群中每个粒子按指定的概率进行变异操作，并根据公式 (10-11) 更新每个粒子的位置；
- (6) 如果停止条件满足，则跳出循环，否则跳至步骤 (2)。

根据以上步骤，最后我们进一步在 PsoModelPos 模块中给出改进粒子群算法的实现函数，函数名为 pso，具体代码如下：

| PsoModelPos.py | 取消速度项、增加变异项的改进粒子群算法实现函数 | 10 - 15 |
|---|---|---|
| 1 | ...... | # 导入相关库，忽略其他代码 |
| 2 | def pso( stlModel, gridSize, crAngle, popu, iter, prob, wL, wG): | # 粒子群优化函数 |
| 3 | P, LP, GP = [], [], Particle() | # 定义三种粒子 |
| 4 | for i in range(popu) : | # 步骤(1)，初始化粒子 |
| 5 | P.append( Particle() ) | |
| 6 | LP.append( P[i].clone() ) | |
| 7 | for k in range(iter) : | # 进入迭代流程 |
| 8 | for i in range(popu) : | # 步骤(2)，计算粒子适应度 |
| 9 | P[i].fitness( stlModel, gridSize, crAngle ) | |
| 10 | for i in range(popu) : | # 步骤(3)，替换个体极值 |
| 11 | if P[i].f < LP[i].f : | |
| 12 | LP[i] = P[i].clone() | |
| 13 | for i in range(popu): | |
| 14 | if P[i].f < GP.f: | |
| 15 | GP = P[i].clone() | |
| 16 | for i in range(popu): | |
| 17 | P[i].vary(prob, LP[i], GP) | |
| 18 | P[i].evolve(LP[i], GP, wL, wG) | |
| 19 | if round(GP.f, 3) == 0: break | |
| 20 | return GP | |

在以上代码中，我们定义并实现了改进粒子群算法的核心函数 pso。该函数包含 8 个必要输入参数，其中 stlModel 就是待优化的目标模型，gridSize 为网格投影尺寸，crAngle 为危险面片临界角，这 3 个参数和支撑量优化业务相关，最终将被输入到 FindSptRegion 中；popu 为 population 缩写，表示粒子群中种群数量，即普通粒子的数量；iter 为 iteration 的缩写，表示迭代次数；prob 为粒子发生变异的概率；wL 和 wG 已在上一小节反复介绍，分别表示个体极值和全局极值在迭代进化中的权重系数。我们看到，后 5 个参数其实和业务无关，是粒子算法本身的参数。

在前面工作的基础上，pso 函数的实现已变得非常简单，它的流程也非常清晰，完全遵循上述改进粒子群算法的步骤。首先我们定义了三种粒子，P、LP 及 GP，其中 P 和 LP 为列表变量。随后根据改进粒子群算法的步骤（1），根据设定的种群数量，我们对普通粒子进行了初始化，初始状态下，这些粒子的位置（即转角 α、β 值）随机产生，适应度为浮点数最大值；同时我们复制了所有普通粒子，并将其保存至个体极值粒子 LP 列表中。在完成这些准备工作后，粒子群算法进入核心迭代流程。在每次迭代中，我们首先根据步骤（2）计算每个粒子的适应度，然后根据步骤（3）和步骤（4）比较和替换个体极值和全局极值。需要注意的是，这里必须使用 Particle 类的 clone 函数创建需要替换的粒子，而不能直接赋值替换，否则极值粒子将无法正确保存。最后我们根据步骤（5）对每个粒子进行了变异和进化操作。在上述迭代过程中，如果当前全局极值的适应度已经接近 0，即支撑量约等于 0 时，则提前结束迭代过程。在结束迭代后，pso 函数返回全局极值粒子 GP。

我们看到，在 pso 函数的实现代码中，除了指定固定的迭代次数（iter）以及支撑量为 0 时外，我们并没有给出任何其他迭代结束条件。事实上，迭代是否继续涉及需要解决的问题是否已经找到最优解，这正是类似粒子群算法、遗传算法等智能优化算法中最难确定的事情，因为一般情况下，严格意义的最优解对我们来说是未知且无法辨识的，而我们认为的最优解极有可能只是局部最优解！我们在改进粒子群算法中设置变异操作正是为了减少这种情况发生概率。有意思的是，对我们当前的三维打印支撑量优化问题来说，存在一个特例，那就是支撑量为 0，这个全局最优解是可以被辨识的，但并非所有的三维模型都能达到 0 支撑量。当然，退一步来说，如果我们愿意接受局部最优解作为问题的解，那就可以认为设置一些迭代结束条件。比如如果在最近若干次迭代中全局极值 GP 都不发生变化，则停止迭代；或者想我们在代码 10-15 中做的那样，直接指定固定迭代次数。

必须说明的是，对 pso 函数，我们尽量希望给出关于（改进）粒子群算法的框架性代码，具有一定的普适性，这些代码不需要改造或稍微改造一下就能被移植，适用于新的应用场景。事实上我们在以上 pso 函数中正是这么做的！我们已经将和三维打印支撑量优化问题相关的业务逻辑全部封装在 Particle 类中，包括适应度函数、进化和变异机制等。而在 pso 函数中，仅保留和(改进)粒子群算法相关的核心步骤和流程。当然，由于参数传递的原因，在 pso 函数中，仍然保留了 stlModel、crAngle 等业务参数，这是难以避免的。

至此，针对三维打印支撑量的优化问题，我们已经在 PsoModelPos 模块中给出了改进粒子群算法的所有实现代码，包括粒子适应度函数 fitness、粒子类 Particle 以及最为核心的 pso 函数等。那粒子群算法到底能不能帮助我们找到最优的模型摆放角度？它的运行效率怎么样？ pso 函数中的相关参数该如何设置？针对这些问题，我们将在下面给出答案。

我们先来看一下 pso 函数的参数设置。对业务相关部分参数，考虑到测试立方体边长为 150 毫米，为了节省粒子群算法计算量，我们设置的模型底面投影网格尺寸（gridSize）为 10 毫米，该设置最终可生成约 200 个规模的细分网格（参见图 10.6 和 10.7）；此外，设置的危险面片临界角为 60 度，对测试立方体，初始状态下，如图 10.27，它的三个下表面均为危险面，需要添加支撑。对粒子群算法本身相关的 5 个参数，我们设置的粒子种群数量（popu）为 70，迭代次数（iter）为 1000，粒子变异概率（prob）为 0.01，即一个粒子在一次迭代中有 1% 的概率发生变异，个体极值和全局极值在进化中的权重系数（wL、wG）均为 4，即对式（10-11），p : q : r = 1 : 4 : 4。需要说明的是，这里设置了较大的迭代次数，因为我们希望在算法最大迭代次数到来前能够找到问题的全局最优解。

需要说明的是，pso 和 findSptRegion 两个函数都涉及 gridSize 参数，两者的意义是一样的，都是模型投影网格尺寸，都和 FindSptRegion 类中支撑线段的计算量直接相关，但由于应用背景不一样，我们设置了不同的值。在 pso 函数中，由于有多个粒子，且执行多次迭代，每个粒子每次迭代都会调用 FindSptRegion 类中相关函数，计算量比较大，因为我们设置了较大的 gridSize 值以降低计算量；相对来说，findSptRegion 函数只会被调用一次，计算量不大，因此我们对它设置了较小的 gridSize 值。
