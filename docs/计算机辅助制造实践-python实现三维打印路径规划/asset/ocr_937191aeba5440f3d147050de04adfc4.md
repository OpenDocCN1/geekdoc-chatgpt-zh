在 SliceModel.py 的文件开头，我们使用了 import SliceAlgo 语句导入 SliceAlgo 模块，而不是像以前一样使用 from···import * 语句导入整个模块的所有功能，这是为了避免在 SliceModel.py 文件中可能出现的函数名重复现象。

SliceModel 类的初始化函数输入参数分别为 STL 模型、切片厚度以及切片算法类型，其中切片算法类型是指 brutal 或 optimal，即暴力法或优化法。在设计 SliceModel 时，我们力求简化切片流程，为此，我们直接将切片相关函数放在了其初始化函数中。为了应对暴力切片和优化切片两种情况，我们进一步定义了 slice_brutal 和 slice_optimal 两个函数，其中 slice_brutal 函数主要调用了 SliceAlgo 模块中带 brutal 后缀的几个函数，而 slice_optimal 函数我们只定义但尚未实现，这将是后续章节的主要任务。此外，在 SliceModel 类中，我们还定义了 writeSlcFile 和 readSlcFile 两个函数，这两个函数分别直接调用 SliceAlgo 模块中的相应函数来实现 SLC 文件的存取。

我们在 SliceModel 类中还定义了 drawLayerContours 函数，用于绘制指定层上的切片轮廓。我们可以通过该函数的相应参数指定需要绘制的层、轮廓颜色以及线条宽度等。值得一提的是，在这个函数中，我们需要从外部传入一个 VtkAdaptor 的对象 va，SliceModel 中所有轮廓数据都是通过 va 对象绘制的。这种在实体中封装\绘制函数的方法大大简化了外部绘图的代码量，这种方式值得我们在今后的应用实践中学习推广。

最后，在 SliceModel.py 的 main 函数中，我们对这个类进行了简单测试。SliceModel 的使用非常简单，只需一行代码便可完成切片功能。在该例中，我们首先通过 StlModel 类读入一个 STL 文件，然后将 STL 模型传给 SliceModel 对象，完成切片并将轮廓数据通过 VTK 绘制出来，这里我们设置的切片层高为 0.7 毫米，图 4.13 显示了该例切片轮廓结果。
