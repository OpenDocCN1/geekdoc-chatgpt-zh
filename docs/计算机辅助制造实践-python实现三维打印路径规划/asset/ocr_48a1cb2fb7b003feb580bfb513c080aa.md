现如下：

| GenNcCode.py | 将一条路径曲线(多段线)转化为 NC 代码 | 11 - 10 |
|---|---|---|
| 1 | ...... | # 导入相关库,忽略其他代码 |
| 2 | def pathToCode(path, pp, e, nf2): | # 定义路径到 NC 代码转化函数 |
| 3 | code = "" | # 定义文本变量 code |
| 4 | for i, p in enumerate(path.points): | # 遍历多段线路径中所有顶点 |
| 5 | if i == 0: | # 使用 G0 快速跳至路径起点 |
| 6 | code += "G0 F%xd X%.3f Y%.3f Z%.3f\\n" % (pp.g0Speed, p.x, p.y, p.z) | |
| 7 | else: | # 使用 G1 打印路径上的其他点 |
| 8 | e += p.distance(path.points[i-1]) * nf2 | # 累加得到 e 值,即进丝量 |
| 9 | code += "G1 F%xd X%.3f Y%.3f E%.3f\\n" % (pp.g1Speed, p.x, p.y, e) | |
| 10 | return code | # 返回代码文本 |

以上 pathToCode 函数的实现其实非常直观,其核心功能就是将路径上各顶点坐标按 G 代码标准格式化为字符串。它包含 4 个输入参数,其中 path 就是 Polyline 类型的多段线,pp 为 PrintParams 类型的打印参数,e 为累计进丝长度,nf2 为喷头尺寸( nozzleSize )和丝材尺寸( filamentSize )比值的平方,参见式( 11–7 )。考虑到 genAllPaths 函数可能生成多条路径,在将这些路径转化为 NC 代码时,我们可能需要多次调用 pathToCode 函数,此时参数 e 可以贯穿这些调用,得到累加进丝长度。至于参数 nf2,我们将其作为输入参数而不是在 pathToCode 函数中直接计算纯粹是出于降低计算量的考虑。

在 pathToCode 函数中,对于路径起点,我们使用了 G0 指令,让打印喷头以速度 g0Speed 快速移动至该点,且移动过程中喷头不出丝。对于 FDM 三维打印,在同一层切片上,当喷头从一点平移至另一点时,考虑到平移过程中无障碍物,因此无需设置安全平移高度;当喷头完成一层打印,向上移动一层时,由于喷头 Z 向高度提升,也不会碰到障碍物,因此也无需设置安全移动高度。综上两种情况,在路径起点,我们只要让喷头从上一条路径终点直接以 G0 移动至当前路径起点即可。对于路径上的其他点,我们使用了 G1 指令,让喷头以速度 g1Speed 从前一点沿直线移动至相应点,且移动过程中喷头出丝,出丝增量根据路径上当前点到前一点的距离及 nf2 计算得到。
