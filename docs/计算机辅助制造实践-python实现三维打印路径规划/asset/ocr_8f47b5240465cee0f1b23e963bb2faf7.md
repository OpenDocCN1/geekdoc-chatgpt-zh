须保证以上切分矩形足够“瘦”，才能让其逼近切分线段。如图 9.22 所示，不妨设参数 δ 是一个趋向于 0 的极小正实数，vx 和 vy 分别为坐标系 X、Y 轴的单位方向，那么我们可以构造如下 4 个点为顶点的矩形：

![](bbox=[0.283, 0.168, 0.692, 0.365])

+   P1 = A - δ · vx - δ · vy (9-14)
+   P2 = B + δ · vx - δ · vy (9-15)
+   P3 = B + δ · vx + δ · vy (9-16)
+   P4 = A - δ · vx + δ · vy (9-17)

因为 δ 趋向于 0，因此矩形在沿 X 方向上的长度和线段 AB 相当，而在沿 Y 方向上的高度为 2δ，仍为一个趋向 0 的极小值，因此，我们有理由相信，使用矩形 P1P2P3P4 和使用线段 AB 对输入区域进行切分的效果等价。对复杂的情况，当有多条切分线段时，我们仍然可以构造多个切分矩形进行布尔运算。
