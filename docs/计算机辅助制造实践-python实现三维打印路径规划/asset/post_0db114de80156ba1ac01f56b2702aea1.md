
## 6.4.2 算法流程及实现

我们先来看一下基于字典查询的截交线段拼接算法流程，如图 6.6 所示。虽然从表面上看，图 6.6 中的流程和上一节图 6.4 中的流程有点相似，但它们的实现细节实则不同。这两个流程的输入都是平面上的散乱截交线段列表 segs，输出也都是封闭轮廓列表 contours。

在图 6.6 中，对输入的线段列表 segs，我们首先需要将它们逐一转化为相互关联的链接点对，并将得到的链接点以其坐标为键添加到字典 dic 中，这一过程体现在我们已经实现的 createLpDic 函数中。拼接流程接下来为两层循环。在第 1 层循环中，我们首先需要从 dic 中寻找一个从来没有被使用过的点 p。因为我们仅在字典的值中保存了链接点对象，因此我们需要遍历字典的值（而非键），从中寻找符合要求的点 p。如果不能寻找到这样的点，那么退出第 1 层循环，输出轮廓列表 contours，整个流程到此结束；但是如果能够找到没被使用过的点 p，则新建一条多段线 poly，用于收集链接点。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_124_0.png)

图 6.6 基于字典查询的截交线段拼接流程

接下来流程进入第 2 层循环。在第 2 层循环中，我们首先将点 p 作为当前点添加到多段线 poly 中，并设置 p 和 p.other 两点的 used 属性为 True，即两点已经被使用。然后我们需要根据 p.other 的坐标在 dic 中查询相应的链接点列表，并在该列表中选择有别于 p.other 的点作为 p 的更新目标，即设置该点为新的点 p (此时 p 也有可能为空，即查询失败)。在这之后，我们需要判断此时 poly 是否闭合，如果闭合则将 poly 添加到闭合轮廓列表 contours 中，并跳出第 2 层循环；如果不闭合则进一步判断 p 是否为空。如果 p 为空则将 poly 添加到开放轮廓列表 polys 中，并跳出第 2 层循环。在以上两个条件均不成立时，则继续第 2 层循环，不断从 dic 中收集点添加到 poly 中。

在以上流程的基础上，我们从头到尾没用到过 LinkPoint 结构中的 index 属性，因此，对字典查询法来说，LinkPoint 的 index 属性是不必要的。接下来我们继续给出以上线段拼接算法实现代码。我们把这些代码封装在 LinkSegs_dlook 类中，在上一小节，我们已经给出了这个类的初始化函数和 createLpDic 函数。在这里，我们将主要实现该类中的拼接核心函数 link 及其若干附属子函数。LinkSegs_dlook 类的补充实现代码如下：

## 6.5 算法测试比较

这一节我们要测试和比较的是面向平面上散乱截交线段的拼接算法,在三维打印路径规划过程中,这些散乱线段是 STL 模型截交后的中间产物,它们不像 STL 模型那样可以直接从文件中读取，我们之前也从没针对这些截交线段设计过文件保存方法。这时候如果我们直接从 STL 模型出发，先截交，得到散乱线段集，后拼接，可能会浪费一定的时间。而且，更重要的是，我们在第 5 章的测试中也已发现，尽管模型中包含了几十万甚至上百万的三角面片，但在具体到某一高度的截平面时，最终得到的截交线段数量不会太多，它的数量可能只是几百或几千，这样的线段数量对于我们要测试的截交算法来说简直是太少了！我们希望，测试样本中需要拼接的线段数量也能达到几十万、上百万甚至上千万。

### 6.5.1 散乱线段生成

根据以上介绍，我们需要的散乱线段应该满足如下要求：它们在平面上必须呈散乱无序的分布状态，但内在逻辑上又能连接成若干封闭轮廓，而且在数量上至少能够达到百万甚至千万的级别。能够设计优秀的算法是一种能力，能够找到或构造对应的测试样本同样是一种非常重要的能力，这种能力有助于我们从实践中检测算法的可行性和性能。

显然我们不能妄想随机生成的一些线段恰好能够连成轮廓。但我们可以转变思路，从先有轮廓的角度出发，生成一些封闭轮廓，然后对轮廓进行细分，得到线段。这才是正确的思路。那现在的问题是如何生成封闭轮廓呢？在平面几何中，最简单的封闭轮廓有三角形、矩形、圆形等，显然，圆形就是我们想要的封闭轮廓，因为圆上的点由简单的、一致的公式控制，而三角形和矩形上的点则需要分段公式控制。现在我们已经选择了圆作为封闭轮廓，我们可以以进一步使用一系列半径不等的同心圆作为多个轮廓，这样做的好处是可以保证各个轮廓之间不相交，这符合现实三维打印对轮廓的要求。下面我们使用若干同心圆来模拟封闭轮廓，并将这些轮廓细分成散乱线段。在 XY 平面上，对于一个圆，如图 6.7 所示。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_127_0.png)

图 6.7 圆上点细分及线段生成

如果圆心坐标为 (x0, y0)，半径为 r，那么圆上的任意点 (x, y) 可以表示为：

```
\begin{cases} x = x_0 + r \cdot \cos(\theta) \\ y = y_0 + r \cdot \sin(\theta) \end{cases} (6-1)
```

其中，θ为点相对于 X 轴正方向的旋转角度，取值范围为[0, 2π]，逆时针为正，顺时针为负。根据这一式子，我们可以对θ在其取值范围内细分，在每个分度上可以得到一个点，然后将这些点依次连接，就可以得到一系列线段。对平面上所有的同心圆，我们可以采取一样的细分操作，最后可以得到一个保存了所有同心圆上所有细分线段的线段列表，记为 segs。

列表 segs 满足了以上提到的两个要求：一是 segs 中线段的数量可由每个圆细分的份数和同心圆个数来控制，达到百万甚至千万级别完全不是问题；二是 segs 中各线段在内在逻辑上也能连成若干封闭轮廓。但是 segs 目前还不满足线段散乱分布的要求，它里面的线段都是原生态地依次从圆上采集得到的。如不考虑同心圆的情况，则相邻序号的线段在平面上也必然是相接的，这显然是不对的。打乱 segs 必然需要用到随机数，最简单的办法就是遍历 segs 中的每个元素，让当前序号的元素和一个序号随机生成的元素交换。

结合以上思路，下面我们来实现一下平面上散乱线段的生成函数，我们将这个函数命名为 makeMessySegs，单独写在 makeMessySegs.py 文件中，具体代码如下：

```python
from Segment import *          # 导入 Segment 模块
from random import *         # 导入随机数生成模块
import math                  # 导入 math 模块
def makeMessySegs( circleNum = 10, segNumPerCircle = 100000, radius = 100.0 ): # 函数定义
    segs = []                    # 定义线段列表
    r = radius                   # 以半径递增的方式生成同心圆
    for i in range( circleNum ): # 遍历，生成指定 circleNum 个同心圆
        pnts = []                    # 点列表，用于收集圆上的点
        for j in range( segNumPerCircle ): # 按细分份数细分圆
            theta = j / segNumPerCircle * 2 * math.pi # 角度 theta
            x = r * math.cos( theta )    # 圆上点 X,Y 坐标，圆心在原点
            y = r * math.sin( theta )
            pnt = Point3D( x, y )
            pnts.append( pnt )           # 将点添加到 pnts
        pnts.append( pnts[0] )           # 在 pnts 添加起点，以封闭轮廓
        for j in range( len( pnts ) - 1 ): # 将点依次整理为线段，添加至 segs
            seg = Segment( pnts[ j ], pnts[ j+1 ] )
            segs.append( seg )
        r += 10.0                        # 同心圆半径递增
print( ' segment count: ', len( segs ) ) # 打印 segs 中线段总数
print( ' min segment length: ', segs[0].A.distance( segs[0].B ) ) # 打印 segs 中最短的线段
for i in range( len( segs ) ): # 对 segs 中线段散乱化处理
    rd = randint( 0, len( segs ) - 1 ) # 生成一个随机整数 rd
    segs[ i ], segs[ rd ] = segs[ rd ], segs[ i ] # 当前线段和随机序号线段交换
return segs
```

在以上代码中，因为我们需要用到正余弦函数，因此需要导入 math 库；又因为要用到随机数生成函数，因此需要导入 random 库。这两个库都是 Python 的内建基础库，不需要我们去额外安装。对函数 makeMessySegs，它有 3 个参数，其中 circleNum 用于指定生成的轮廓数量，默认为 10；segNumPerCircle 用于指定对每个圆的细分份数，默认为 100000 份，即每个圆最终可得到 100000 条线段；radius 用于指定同心圆的最小半径，默认为 100 毫米，其余圆半径以 10 毫米递增。

在 makeMessySegs 函数中，我们打印了两条信息，第一条是生成的线段总条数，第二条是生成的线段列表中最短的线段长度。我们必须知道生成的最小线段长度是多少，这是因为我们之前介绍的暴力拼接法和字典序排序拼接法都会用到点的重合判断函数 isCoincide，而在这个函数中，我们认为只要点的距离小于一个极小的给定值( 默认为 10^-7 毫米)，就认为两个点是重合的。因此，在这里生成的线段的最小长度不能小于 10^-7 毫米，至少要比这个数大一个数量级，即 10^-6 毫米以上，否则将引起拼接算法失效。

最后，我们来看一下如何打乱生成的线段列表 segs。和之前介绍的一样，我们先对 segs 进行循环遍历。对当前线段，首先使用 Python 的 random 库中的 randint 函数生成一个随机整数 rd，显然该 rd 作为序号不能越界，且必须大于 0，因此我们给的随机数生成范围是 [0, len( segs) - 1]；然后我们对当前线段和第 rd 条线段进行交换。经过这样的处理，当遍历完成后，我们就可以得到在平面上散乱分布的线段了。
