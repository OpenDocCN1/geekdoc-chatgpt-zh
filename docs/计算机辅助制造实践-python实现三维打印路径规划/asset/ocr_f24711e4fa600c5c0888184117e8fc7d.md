# 本章小结

本章主要介绍了面向三维打印的模型支撑生成与优化方法，这是三维打印路径规划的重要环节。首先我们对三维打印支撑生成进行了概述，提出了支撑空间、危险面片临界角等概念。在此基础上，我们介绍了一种生成切片支撑区域的方法。该方法避开直接对支撑空间切片的难题，通过模型底面网格化、模型与网格竖线求交、支撑线段奇偶提取、平面支撑点生成、平面支撑点扩张融合、轮廓偏置、支撑区域布尔运算等步骤及手段生成平面支撑区域。对得到的切片支撑区域，通过对 GenDpPah 模块的升级改进，我们提出了一种支撑路径的稀疏填充方法。最后，为了降低支撑材料消耗量，我们介绍了一种基于粒子群算法的模型摆放角度优化方法。为了限定粒子活动范围，同时增加粒子跳出局部最优的可能性，我们对粒子群算法进行了改造，设计了一种取消速度项的粒子进化和变异机制。针对上述方法，我们封装了 FindSptRegion、GenSptPath 以及 PsoModelPos 三个模块，实现了 findSptRegion、genSptPath 以及 pso 等全局接口函数，通过这些模块和函数，我们可以对任意 STL 模型的摆角进行优化，同时生成支撑打印路径。
