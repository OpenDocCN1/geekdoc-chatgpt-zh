# 引言

我们将在这一章开始处理和三维打印路径规划相关的问题。对三维打印路径规划来说，输入为 STL 模型和反映加工工艺的相关参数，输出为可驱动打印机运行的 NC( N omerical Control)代码文件，这中间经历了许多步骤。本章主要介绍针对一个 STL 模型和给定的层高参数，用一系列符合层高要求的平行平面去截交 STL 模型后，模型和平面之间截交轮廓线的基础计算方法。为了实现这一目的，我们首先需要获取 STL 模型中的离散坐标信息。

# 4.1 STL 模型加载

在第 3 章关于 VTK 的介绍中，我们已经可以使用 VtkAdaptor 类直接从文件加载并显示一个 STL 模型。但在这一过程中，我们却忽视了关于 STL 模型的诸多细节。STL 被认为是三维打印模型的“事实标准”，是由 3D systems 公司于 1988 年制定的一个接口协议。那么 STL 到底是什么？它在文件中又是如何组织和保存几何数据的呢？

# 4.1.1 STL 文件解析

STL 模型是由一系列三角面片组成的实体，相邻三角面片之间遵守“点对点、边对边”的规则，如果一个三角形的顶点落在另一个三角形的边上，那么这个 STL 模型就可被认为是非法的。对于计算机硬盘上保存的 STL 文件，我们可以将其拖入一个已经打开的记事本程序。如果运气好，我们可以看到存在 STL 文件中的模型坐标信息，如图 4.1 所示。
