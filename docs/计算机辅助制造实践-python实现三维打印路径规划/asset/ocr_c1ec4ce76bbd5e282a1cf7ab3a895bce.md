生成方向可调的填充线。

生成非零倾角的填充线有两种基本思路，其中第一种思路是改变扫描线的角度，类似图 9.2 所示，将所有线段投影到扫描线的法线方向进行排序。这样做虽然直观，但会增加算法的实现难度，而且，当扫描线不和 X 轴平行时，对线段端点是否落在扫描线上这一临界情形进行判断的数值稳定性将大大下降，这对后续填充线的提取是致命的。因此，改变扫描线角度这种思路不太可取。

生成非零倾角填充线的第二种思路是对输入多边形进行旋转。和物理学中相对运动的概念类似，既然改变扫描线的角度难度这么大，那么我们就尝试去改变多边形的角度。如图 9.7 所示，当填充线的倾角 θ 大于 0 时，我们可以先对输入的多边形绕平面坐标系原点旋转 -θ 角度，其中负号表示旋转方向为顺时针。对得到的多边形，我们可以根据填充线的间距生成一组高度序列 ys，然后将旋转多边形和 ys 输入我们之前实现的 calcHatchPoints 函数，生成填充线交点。对得到的交点，我们可以按照填充线提取原则将其转化为填充线段。此时所有的填充线段都和 X 轴平行，但是它们没有落在正确的位置上。我们最后需要做的就是将得到的填充线段坐标系原点旋转 θ 角度，让其落在原多边形内部。旋转后的填充线段就是我们要求的填充线段，它们相对于 X 轴正向的倾角恰好为 θ。
