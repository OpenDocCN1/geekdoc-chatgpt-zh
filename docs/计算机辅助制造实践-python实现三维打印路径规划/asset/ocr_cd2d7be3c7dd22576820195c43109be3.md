可以使用 Python 语言复现一下这个算法。

# 8.3 基于裁剪的轮廓偏置

我们在上一节介绍了两种基础偏置方法，分别是基于线段平移的偏置方法和基于角平分线的偏置方法，但我们都并未真正实现这些方法。这是因为，一方面，实现多边形轮廓的偏置算法确实比较困难，将耗费我们大量的时间和精力；另一方面，更重要的是，在计算几何领域，已经有了一些免费的开源几何库，可以帮助我们实现平面轮廓的偏置功能，如 CGAL、Clipper 等。我们只要掌握其中一个开源库的使用方法即可，似乎没有必要再去新造一个轮子。

CGAL(https://www.cgal.org/)是一个重量级的大型计算几何库，包含了计算几何领域的诸多算法，比如凸壳生成、实体布尔运算、Delaunay 三角化、Voronoi 图、几何形状重建等。但 CGAL 源码采用 C++模板技术编写而成，晦涩难懂，对初学者来说，阅读和使用难度较大。相对来说，Clipper(http://www.angusj.com/delphi/clipper.php)是一个轻量级的小型几何库，专门用于平面多边形的布尔运算，算法运行效率高、鲁棒性强。目前，Clipper 已在多种编程语言上实现了直接可用的源代码，如 C++、C#、Delphi、Python 等。在这一章，我们准备使用 Python 版本的 Clipper 库来实现二维轮廓偏置功能。

# 8.3.1 Clipper 库简介

Clipper 是一个专门用于平面闭合或非闭合多段线布尔（或叫裁剪）运算的开源计算几何库，可以实现平面图形的交（intersection 或 and）、并（union 或 or）、差（difference）、异或（xor）以及偏置等运算功能，见图 8.11。Clipper 库由 Angus Johnson 根据 Bala R. Vatti 在 1992 年发表的 A generic solution to polygon clipping 论文实现，因此，Clipper 库中的裁剪算法又叫 Vatti’s clipping algorithm。遗憾的是，网上很难找到关于 Angus Johnson 的个人资料，因此我们无法对他做进一步介绍。
