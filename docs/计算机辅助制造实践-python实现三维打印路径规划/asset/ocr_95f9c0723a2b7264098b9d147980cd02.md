是一系列和 Y 轴垂直的平行线。在这种情况下，一条直线只需用它在 Y 轴上的截距（Y 值）就可以表示，我们称这一截距为该直线的高度，称直线本身为 y 线。现在，我们假设平行线序列中每条平行线的高度已知，这些高度值被保存到一个实数序列 ys 中。序列 ys 可能根据指定的各平行线间距生成，也可能由外部输入，我们暂时不必理会它的来源。

仿照扫描平面法，首先我们需要建立扫描线数据结构。扫描平面的作用是维护和当前高度扫描平面相交的三角面片序列，而在平面上，扫描线的作用是维护和当前高度扫描线相交的线段序列。我们将扫描线类放在一个新建的 GenHatch 模块中，类名为 SweepLine。这里 GenHatch 为 generate hatch 的缩写，意思是生成填充线。熟悉 AotoCAD 的读者可能知道，在该软件中，hatch 命令的作用就是在指定平面区域内生成填充线。SweepLine 类的具体实现代码如下：

```
...... # 导入相关库
class SweepLine: # 定义 SweepLine 类,扫描线
    def __init__(self) :
        self.segs = [] # 属性 segs,Segment 类型列表
    def intersect(self, y) :
        ips = [] # 交点列表
        yLine = Line(Point3D(0, y, self.segs[0].A.z), Vector3D(1, 0, 0)) # 创建 y 线
        for seg in self.segs: # 遍历 segs, 和 y 线求交
            if seg.A.y == y: # 重要:如果 y 线经过线段 A 端点
                ips.append(seg.A.clone()) # 则将 A 端点添加至交点列表
            elif seg.B.y == y: # 同理,如果 y 线经过线段 B 端点
                ips.append(seg.B.clone()) # 则将 B 端点添加至交点列表
            else: # 否则,使用 intersect 函数计算 y
                ip = intersect(yLine, seg) # 线和线段交点,并将交点添加至
                if ip is not None: # 交点列表,ip:intersection point
                    ips.append(ip)
        ips.sort(key=lambda p: p.x) # 对交点按 x 值从小到大排序
        i = len(ips) - 1
        while i > 0: # 移除交点列表中的重合点对
            if ips[i].distanceSquare(ips[i-1]) = = 0: # 逐个比较相邻点是否重合
                del ips[i]
                del ips[i-1]
                i = i - 2 # 如果点对被移除,i 向前走 2 步
            else:
                i = i - 1 # 否则 i 向前走 1 步
        return ips # 返回处理后的交点列表
```

以上 SweepLine 类仅包含一个列表类型的 segs 属性，用于存储和当前扫描线相交的线段。在 SweepLine 中，我们定义了一个 intersect 函数，这个函数的作用是计算扫描线维护
