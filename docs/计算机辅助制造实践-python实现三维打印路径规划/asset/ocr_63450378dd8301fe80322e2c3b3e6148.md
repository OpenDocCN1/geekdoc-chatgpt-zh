```
layer.ffPaths = genDpPath(layer.ffContours, pp.nozzleSize, pp.fillAngle + delta)
if len(layer.sfContours) > 0:     # 5.生成稀疏填充路径
    layer.sfPaths = genDpPath(layer.sfContours, sflnvl, pp.fillAngle + delta)
if pp.sptOn:           # 6.生成支撑路径
    genSptPath(pp.stlModel, layers, sptSflnvl, pp.sptGridSize, pp.sptCrAngle, \
        pp.sptFillType, pp.sptFillAngle, pp.sptXyGap)
return layers          # 返回切片序列
```

以上 genAllPaths 函数的输入参数只有 1 个，即 pp，类型为 PrintParams，该参数已包含 STL 模型数据。在该函数中，首先根据填充率计算填充间距，然后依次执行上述 6 个步骤，生成全部打印路径。对密实填充区域（以及轮廓填充区），为了保证打印所得工件的封闭性，我们为其设置的填充间距为喷头直径。针对每层切片，我们总共生成了 5 种打印路径，包括工件部分的轮廓路径 cpPaths、密实填充路径 ffPaths、稀疏填充路径 sfPaths，以及支撑部分的轮廓路径 sptCpPaths 和填充路径 sptDpPaths（参见代码 10-10）。这 5 种路径属性都是通过动态方式添加至 Layer 类的。因为这里对切片序列 layers 进行了遍历，因此我们不必担心忘记为某些切片添加属性。

需要说明的是，并非每层切片都存在于上述 5 种路径，某些切片可能只存在其中一两种路径。如果某种路径存在，则相应路径序列不为空（序列中元素个数大于 0），否则序列为空。此外，在以上步骤（1）中，我们默认调用了 slice_topo 函数对输入模型进行切片，这完全是一种随机选择，其实我们也可以使用 slice_combine 函数完成模型切片。

函数 genAllPaths 的返回为包含打印路径的切片序列 layers，在下一小节，我们将对得到的这些切片进一步操作，将切片中的路径转化为 NC 代码。

# 11.2.3 路径代码转换

对常见的 FDM 三维打印机来说，它能接收的 NC 代码一般就是指 G 代码。G 代码是数控加工领域使用最为广泛的编程语言，是人类和数控设备沟通的桥梁之一。标准的 G 代码一般包含 G（准备）和 M（辅助）两种功能字，分别由地址符 G、M 和其后的数字组成。其中 G 功能字主要用于指定数控插补、刀具补偿、坐标选择、循环控制等功能；M 功能字主要用于指定主轴旋转方向、冷却液开关、程序启停、刀具更换等功能。

对 FDM 三维打印机来说，它能接收的 G 代码是标准 G 代码的一个子集（或对子集的修改）。这里我们只介绍和打印路径本身相关的几个指令，包括 G0、G1、G90、G91，它们的具体功能如表 11.2 所示：
