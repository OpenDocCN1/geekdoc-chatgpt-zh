最后,我们看表 5.1 的第一行和最后一行。针对 bunny 模型,当切片厚度为 1.0 毫米时,使用暴力法的时间约为 16 秒钟,使用扫描平面法或层高匹配法的时间约为 2 至 3 秒钟,这样的时间差让人主观上感觉不是很大,也许就是举起杯子喝一口水和打个喷嚏的时间差。但是时间差是会累积的,针对 vase 模型,当切片厚度为 0.2 毫米时,使用暴力法的时间为 2034.4 秒钟,接近 34 分钟,超过了半个小时,而使用扫描平面法或层高匹配法的时间约为 90 秒钟。这个时候,我们就会觉得暴力法有点难以接受了,对三维打印来说,仅仅完成截交这个步骤就需要半个多小时,这简直不可想象。

当我们针对一个具体问题设计算法时,第一要务当然是能够得到正确的结果,否则一切无从说起。在此基础上,我们还需要考虑对算法的优化,特别是对于那些计算密集型的问题,在算法性能上哪怕是 1% 的提升都是非常有意义,值得被称道的。我们在解决 STL 模型截交问题时正是沿着这样的轨迹走过来的。

# 本章小结

这一章主要针对三维打印路径规划中的模型截交这一问题展开讨论。在第 4 章已经实现的暴力截交法的基础上,我们在本章进一步介绍了两种优化截交算法,即扫描平面法和层高匹配法。扫描平面法的核心是首先对模型中的三角面片进行排序,然后用一扫描平面从低到高收集与之相交的面片并进行截交计算。层高匹配法的本质是以模型中的三角面片为主导,收集与之相交的层高并进行截交计算。在本章最后,我们对暴力法、扫描平面法以及层高匹配法这 3 种截交算法进行了测试比较,结果表明,扫描平面法和层高匹配法的性能持平,虽前者略胜一筹,但都比暴力法高出一个数量级。需要说明的是,尽管我们给出了几种行之有效的截交算法,但不代表这些算法就是最优的。模型截交问题本身仍是一个开放的问题,我们期待读者能够给出更加高效的算法。
