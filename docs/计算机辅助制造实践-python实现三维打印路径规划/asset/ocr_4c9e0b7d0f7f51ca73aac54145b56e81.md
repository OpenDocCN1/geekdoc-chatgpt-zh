里我们设置间距为 3mm;二是将 genCpPath 函数替换成了 genDpPath;三是根据平行路径的特点在相邻上下两层之间设置了正交化填充角度,即如果上一层填充角度为 0 度,那么下一层填充角度就是 90 度,以形成上下层之间的编织效果。当然,上下层之间的填充角度差值是可以任意设置的。
