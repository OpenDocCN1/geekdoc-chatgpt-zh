# 图 10.12 支撑线段与载平面 Z 坐标交算

序列为 \(\xi, \xi = \{(z_i, a_i) \mid i \in [0, 2n]\}\)，其中 \(z_i\) 为交点 \(Z\) 坐标，\(a_i\) 为对应面片水平倾角，\(n\) 为自然数，且如果 \(0 \leqslant i < j \leqslant n\)，则 \(z_i < z_j\)。我们发现，正常情况下，每个节点上方总会有奇数\((2n + 1)\)个交点，这其实是合乎逻辑的，因为经过节点的竖线总是从三维模型的外部刺透模型，这样必然会产生偶数个交点，再加上我们一开始在模型底面人为设置的一个交点(如图 10.6)，因此总共会有奇数个交点。

对上述交点序列 \(\xi\), 如图 10.12 所示,显然,一条潜在支撑线段的下支点只可能取在 \((z_{2k}, a_{2k})\) 上,其中 \(k \in [0, n-1]\),相应上支点为 \((z_{2k+1}, a_{2k+1})\),如果该线段为支撑线段,上支点必须满足 \(a_{2k+1} \leqslant \theta_0\),其中 \(\theta_0\) 为面片支撑临界角,任何倾角小于临界角的面片都是危险面片。对一张与 \(XY\) 平面平行且高度为 \(z_c\) 的载平面,要找出该平面和支撑线段的交点,我们只需逐对遍历 \(\xi\) 中相邻交点,并判断

\(z_{2k} \leqslant z_c \leqslant z_{2k+1}\) (10-3)

且

\(a_{2k+1} \leqslant \alpha_0\) (10-4)

是否同时成立,若成立,则载平面和当前网格节点上的支撑线段的交点坐标为 \((x_c, y_c, z_c)\)。如果遍历 \(\xi\) 后以上条件均无法同时成立,则载平面和当前网格节点上的支撑线段无交点。以上我们解决了单个网格节点上方支撑线段和载平面的求交问题,同理,只要我们遍历网格字典 gridDic 中的所有节点,就能找出和当前高度载平面相交的所有切片支撑点。下面我们给出切片支撑点的计算函数,函数名为 calcLayerSptPoints,和前面两小节一样,我们同样将这部分代码写在 FindSptRegion 类中,具体实现如下:
