
genDpPath，以方便我们后续使用该模块功能。它的输入参数和 GenDpPath 类的输入参数完全一样，包括多边形列表、填充间距及填充角度，输出为 zig-zag 平行路径列表。

如图 9.23 所示，尽管我们已经对各个单连通区域内的填充线段进行了连接，但从全局的角度来讲，我们并未对各个单连通区域间的平行路径进行连接，而在实际应用中，它们是需要进一步被连成一体的。从路径优化的角度来说，和上一章介绍的各条已连接轮廓路径的连接问题类似，单连通区域间平行路径的最短连接问题也是一个“旅行商”问题（参见图 8.32），而且得到的连接路径在实际打印(或加工)过程中只能通过“跳刀”的方式实现。

## 9.5 最少跳刀填充方向优化

通过前面几节的介绍，对输入的多边形待填充区域，我们已经能够将其分割成若干单连通区域，并且在各个单连通区域内生成并连接得到了平行填充路径。在对多边形区域进行分区时，最终得到的单连通区域的个数和多边形上凹峰点的个数相关，它们之间的具体关系可由式(9-13)表示，即分区个数等于两倍的凹峰点个数加 1。根据式(9-9)可知，多边形中凹顶点的个数仅和多边形自身形状有关，而和填充方向无关。根据式(9-12)可知，多边形中峰值顶点个数不仅和多边形自身形状有关，而且和填充方向有关。考虑到给定多边形形状不可改变，因此，多边形中凹峰点的个数仅和填充方向有关，即分区得到的单连通区域个数仅和填充方向有关。

对平行填充路径来说，显然，分区时得到的单连通区域的个数越少，后续的路径连接就越简单，需要的“跳刀”次数就越少。如果仅考虑单连通区域间平行路径的连接问题，那么跳刀次数和单连通区域个数的关系为：

```
N_j = N_s - 1
```

其中, N_j 为跳刀次数, N_s 为单连通区域个数。结合以上分析，对一个给定多边形区域，跳刀次数也仅和填充方向有关。理论上, 当填充角度从 0～360 度（考虑角度冗余情况, 事实上是 0～180 度）变化时, 必然存在一个最优的角度值, 使得沿着这个角度对输入多边形区域进行分区时, 生成的单连通区域个数最少, 即跳刀次数最少。

我们在这一节的任务就是以减少跳刀次数为目标, 找出最优填充角度。需要说明的是, 这部分工作相对独立, 由这一节得到优化填充角度可作为参数直接输入 genDpPath 函数中(参见代码 9-12), 用于生成最小跳刀平行路径。

### 9.5.1 目标函数建立

一般来说, 对优化问题, 我们首先需要建立目标函数。目标函数就是所关心的目标（某一变量）和相关因素（某些变量）的函数关系。如果目标只有一个, 我们称这种优化问题为单目标优化; 如果目标有多个, 我们称这种优化问题为多目标优化。

对于我们在这一节要解决的跳刀优化问题, 它的目标是减少跳刀次数, 影响因素是填充角度。显然, 这是一个单目标、单因素的优化问题, 其目标函数可以写成:

```
J = f(θ)
```

其中 J 为跳刀次数，θ 为填充角度。

由于问题本身特性，我们很难给出函数 f(θ) 代数解析式。但是，对于某一固定多边形区域，在填充角θ已知的情况下，我们可以通过本章 9.3 节中提及相关步骤计算出分区个数、进而计算出跳刀次数的。也就是说，对目标函数式（9-19），由θ到 J 的映射尽管很复杂，且无法表达成解析式，但映射过程却是非常明确的。理论上，对一般单目标优化问题，求解其最优解的过程就是求解目标函数导数为 0 时的解（类似于图 9.17）。显然，对跳刀次数的优化问题，我们无法采用这种求导的方式求解，那该怎么办呢？

### 9.5.2 跳刀优化计算原理

对以上跳刀优化问题的求解来说，如果我们没接触过任何优化算法（如遗传算法、粒子群算法等），可能是一种优势。这样我们在求解类似问题时会从问题本身出发，也许能想出一些直白但绝妙的解法。对上述问题，一种非常直观的求解思路是对目标函数进行正向计算，即直接在 0～180 度范围内遍历填充角度θ，计算每个θ对应的跳刀次数，然后从中找出跳刀次数最少时对应的填充角θ值。这种思路很简单，我们要做的就是对θ在 0～180 度范围内进行均匀细分取值，对每个细分角度θi，首先对输入多边形区域顺时针旋转θi 角度，然后调用 SplitRegion 类中的 findTurnPoints 函数（参见代码 9-9）计算并统计细分角度θi 下的凹峰点个数，最后再根据式（9-18）计算相应跳刀次数。

实现以上思路可能不需花费太多时间，但这种方法本身的计算效率不会太高。它的计算量主要取决于细分精度，比如，当细分精度为 0.01 度时，我们将得到 18000 个细分角度，也就是说，我们要对原始多边形进行 18000 次旋转操作，且对每次旋转后的多边形，对其各个顶点，我们要进行 18000 次遍历。由此，我们可以非常直观地感受到其中的计算量。在实际应用中，我们可能没必要将角度的细分精度设置得那么高，细分精度为 0.1 度就够了。

如果我们结合式（9-12）再对图 9.18 进行细致观察，就会发现，对原始多边形的旋转操作可能并非必要。如图 9.24 所示，已知 P 为多边形上的一个凹峰点，v₁、v₂ 分别为与 P 相邻两边的方向向量，vₛ为扫描线（或填充线）方向向量。根据峰值点定义，v₁、v₂ 应该分别在 vₛ两侧。反过来，在向量 v₁、v₂ 方向固定但 vₛ方向可变的前提下，只要 vₛ 落在 v₁、v₂ 之间，那么相对 vₛ 来说，P 点就是一个峰值点。据此，我们可以反算出顶点 P 成为峰值点时填充方向 vₛ 的角度范围，我们形象地称这个范围为 P 的切线角度范围（或切线角度），记为Ψ。同理，对输入多边形上的任意凹顶点 Pᵢ，我们可以找出它的切线角度范围Ψᵢ。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_235_0.png)

图 9.24 凹顶点成为峰值点的切线角度范围

如果我们把多边形上所有凹顶点的切线角度范围都绘制到如图 9.25 所示的同一个坐标系下，我们将得到一系列水平线段。每条线段表示一个凹顶点的切线角度范围，其中线段起点(左端点)表示角度范围上限，线段终点(右端点)表示角度范围下限。在图 9.25 中,我们可以构造一条竖直直线,使其在 0~180 度范围内扫描。在某个特定扫描角度下,若直线和某一线段相交,则说明该线段对应的凹顶点在这个扫描角度下是一个峰值点。据此,当直线移动时,我们可以统计每个位置上直线和线段的交点个数,理论上,我们可以找出直线和线段交点数量最少时的扫描角度值(或范围)。在这个扫描角度范围内(图 9.25 中是 0~30 度),峰值点数量最少,凹峰点数量也最少,不难想象,在对输入多边形区域进行平行填充时,如果填充角度也落在这个角度范围内,那我们可以得到最少的分区数量和最少的跳刀次数。这个角度范围就是我们需要寻找的最少跳刀填充角度。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_236_0.png)

根据以上分析,我们可以得出两点结论:一是想要得到最少跳刀次数,对输入多边形的旋转操作确实是不必要的;二是确定多边形上每个凹顶点的切线角度是寻找最少跳刀填充角度的基础。

### 9.5.3 顶点切线角度确定

对连续可导轮廓上的某一点来说,它的切线方向固定,切线角度必然是一固定数值;但对离散轮廓上的某一顶点来说,它的切线角度是什么呢?

如图 9.26 所示,对 XY 平面任意离散轮廓上的一个顶点 P,如果某一直线 l 经过顶点 P 但并不“穿过”由 3 点组成的局部轮廓 OPQ,那么我们定义直线 l 为离散轮廓顶点 P 的切线,并且定义此时直线 l 和坐标系 X 轴正向的夹角为切线角度。

根据以上定义,我们可以推断,首先,离散顶点的切线存在与否和顶点本身的凹凸属性无关,凹顶点可以有切线,凸顶点同样也可以有切线。其次,当直线 l 和 X 轴夹角在一定范围内变动时,l 都可能是该顶点的切线,因此,离散顶点的切线角度表示的事实上是一个角度范围,我们记这个角度范围为 $\Psi$。

如图 9.26 所示,我们记顶点 P 两邻边方向向量分别为 $v_1$ 和 $v_2$, 直线 l 的方向向量为 $v$, 又记 $v_1, v_2, v$ 和 X 轴正向的夹角分别为 $\alpha, \beta, \phi$。考虑到 $v_1, v_2$ 可能指向坐标系 4 个象限中的每个象限，因此夹角 $\alpha, \beta$ 的取值范围均为 $0 \sim 360$ 度，即 $\alpha, \beta \in [0, 360)$。根据以上设定，我们在这一小节的任务可以抽象为：在夹角对 $\alpha, \beta$ 已知的前提下，确定顶点 P 的切线角度范围 $\Psi$。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_237_0.png)

图 9.26 离散点切线及切线角度定义

首先我们来看一下 $\Psi$ 的取值范围。在图 9.26 中，直线 l 的方向向量 v 也可指向平面坐标系 4 个象限中的任一个象限，因此 $\varphi$ 的取值范围应该是 $0 \sim 360$ 度。但是，在过同一顶点的前提下，当直线 l 的倾斜角度分别为 $\varphi$ 或 $\varphi + 180$ 时，它们在平面上是完全重合的。在这里，我们不妨规定 $\varphi$ 的定义域为 $0 \sim 180$ 度，即 $\varphi \in [0, 180)$。根据以上规定，我们可以得出，离散顶点切线角度范围 $\Psi \subseteq [0, 180]$，即 $\Psi$ 的上下限也应落在 $0 \sim 180$ 度之间。

接下来我们再来定量讨论切线角度 $\Psi$ 的取值。如图 9.27 所示，夹角 $\alpha, \beta$ 分别为 $v_1, v_2$ 和坐标系 X 轴正向的夹角，它们的取值均在 $0 \sim 360$ 度内，在数值上，考虑到 $\alpha$ 可能大于 $\beta$，也可能小于 $\beta$，简单起见，我们不妨设 $\alpha < \beta$ (如果实际上 $\alpha > \beta$，则对它们的数值进行交换)。根据图 9.27，我们不难得出 $\Psi$ 取值的以下 3 种情况：

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_237_1.png)

图 9.27 不同情况下离散点切线角度确定

- (1) 如图 9.27 (a)，如果 $\beta \leqslant 180$，即 $\alpha < \beta \leqslant 180$，那么 $\Psi$ 为 $[\alpha, \beta]$；
- (2) 如图 9.27 (b)，如果 $\alpha \geqslant 180$，即 $\beta > \alpha \geqslant 180$，那么 $\Psi$ 为 $[\alpha - 180, \beta - 180]$；
- (3) 如图 9.27 (c)，如果 $\alpha \leqslant 180$ 且 $\beta \geqslant 180$，则令 $\alpha' = \alpha, \beta' = \beta - 180$，如有必要，交换 $\alpha', \beta'$ 值，使得 $\alpha' < \beta'$，那么 $\Psi$ 为 $[0, \alpha'] \cup [\beta', 180]$。

在以上情况 (1) 和情况 (2) 中，$\Psi$ 的取值均为单段连续区域，但在情况 (3) 中，$\Psi$ 的取值为两段连续区域。通过以上讨论，我们知道，无论哪种情况，对离散轮廓上的任意顶点 P，只要其两邻边的方向已知，即夹角对α、β已知，我们都能确定其切线角度范围Ψ。在解决了切线角度的计算问题之后，下面我们回到到最少跳刀填充方向的优化问题上。

### 9.5.4 最少跳刀优化实现

如图 9.25，只要我们能够求出输入多边形上所有凹顶点的切线角度，就能求出最少跳刀填充角度范围。在这一小节，我们要做的就是将如图 9.25 所示的最少跳刀计算原理转化为实际可用的步骤或代码。为了实现这个目标，我们首先必须寻找输入多边形上的所有凹顶点，并计算其相邻两边方向向量和坐标系 X 轴的夹角对α、β。

我们把所有和最少跳刀优化相关的代码都写在 FindOptFeedDir 模块中。在这个模块中，我们打算换一种写法，把计算上述夹角对α、β这一子功能的代码直接封装在一个名为__findAnglePairs 的全局函数中，函数名中下划线前缀表示这并不是一个对外的接口函数，该函数的具体实现代码如下：

|---|---|---|

以上__findAnglePair 函数的输入为多边形列表 polygons 和布尔型变量 adjustPolyDirs，和上一节介绍的 SplitRegion 类一样，如果 adjustPolyDirs 为 True，则函数会自动去调整输入多边形的方向，使其满足“外逆内顺”的规定，反之则表明多边形方向事先已经满足要求，我们无需再在函数中对其方向进行调整。需要强调的是，保证多边形符合“外逆内顺”的规定非常重要，如果不满足，多边形上各顶点的凹凸特性将完全相反。此外，在该函数中，在获得了当前顶点两邻边的方向向量之后，我们使用 getAngle2D 这个函数计算边向量和 X 轴的夹角，注意，getAngle2D 函数返回值的范围为 0 ~ 2π，我们需要使用 Utility 模块中的 radToDeg 函数将弧度转化为度数单位，使最终得到的角度对 a、b 取值落在 0 ~ 360 度范围内，方便理解。最后，在__findAnglePair 函数中，我们强制交换了得到 a、b 值，使其满足 a < b,这样做的原因我们在上一小节已有解释。

在实现了输入多边形上凹顶点角度对的计算之后，下面我们回过头再来看看图 9.25 中竖直扫描线的构造问题。从算法实现的角度来说，我们很难构造这样一条竖直扫描线，可以在 0 ~ 180 度范围内连续扫描，进而精确地找出最少跳刀角度范围。既然如此，我们可以对扫描范围进行离散，如将扫描角度间距设置为 0.1 度时，在图 9.25 中，我们可以得到约 1800 个离散扫描角度，进而我们可以构造一个扫描角度表。对角度表中的每个离散角度ω，我们可以与之关联一个变量 t，用于标识在该角度下竖直扫描线和凹顶点切线角度（线段，参见图 9.25）的交点个数。据此，我们可以构建一个双重循环，首先遍历角度表，对每个扫描角度，构建对应扫描线，然后遍历凹顶点切线角度（线段）。如果某个切线角度和当前扫描线相交，则对当前扫描角度的变量 t 累加 1。在完成上述循环后，我们只要统计角度表中各个离散角度的变量 t 值，就能找出最少跳刀填充角度。

在以上循环中，我们首先遍历角度表，然后遍历切线角度，但是，只要我们交换一下顺序，就可大幅降低遍历次数。对某个切线角度 Ψ，我们不妨设其上限和下限分别为 φ_min 和 φ_max，即 Ψ = [ φ_min , φ_max ]，这里我们暂时不讨论 Ψ 被分为两段的情况。在图 9.25 中，φ_min 和 φ_max 就是切线角度（线段）的两个端点，根据这两个端点和扫描角度的离散规则，我们不难计算出落在两端点间的所有离散扫描角度，此时我们只需对这些扫描角度对应的变量 t 累加 1 即可。显然，以上方法同样适用于切线角度 Ψ 被分为两段的情况。根据以上思路，我们只需对凹顶点切线角度使用一次遍历，就能最终找出最少跳刀填充角度。

在 Python 中，我们可以使用现成的字典类来构建上述扫描角度表，在字典中，键为角度，值为交点个数，即上述变量 t。在 FindOptFeedDir 模块中，我们将角度表的构造及初始化函数命名为 _initAngleTable，下划线前缀同样表示这并不是一个对外输出的函数，它的具体实现代码如下：

```python
...... # 导入相关库，忽略其他代码
def _initAngleTable( digit ): # 角度表构建函数，digit 为小数位数
    angleTable = { } # 角度字典
    delta = math.pow( 10, -digit ) # 角度增量
    angle = 0.0
    while angle < 180: # 在 0 ~ 180 度范围内，创建字典键
        angleTable[ angle ] = 0 # 初始化每个角度下的交点数为 0
        angle = round( angle + delta, digit ) # 保证角度小数位数为指定值
    return angleTable # 返回角度表
```

以上 _initAngleTable 函数只有一个输入参数 digit，表示角度表中各个角度保留的小数位数，即角度精度。比如当 digit 值为 1 时，表示保留 1 位小数，此时角度表中角度分别为：0, 0.1, 0.2, ..., 179.9，共 1800 个角度值（注意，0 度和 180 度表示的填充线重合，故忽略 180 度）；又当 digit 值为 0 时，表示保留 0 位小数，此时角度表中角度分别为：0, 1, 2, ..., 179，共 180 个角度值；以此类推。初始情况下，在角度表中，每个角度对应的交点个数为 0；后
