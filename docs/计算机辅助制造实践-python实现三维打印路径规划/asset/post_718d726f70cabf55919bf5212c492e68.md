此外，在 Point3D 类中，我们还定义了 distance 和 distanceSquare 函数，顾名思义，这两个函数都和距离计算相关，输入均为另一个点。其中 distance 计算两个点在三维空间中的真实距离，需要进行开方运算；而 distanceSquare 计算两个点距离的平方，不需要进行开方运算。因此，两者比较而言，后者的运算速度较前者更快。在实际运用中，如从一组点中找出距离指定点最近的那个点，在这种情况下，我们没必要计算点之间距离的真实值，只需知道它们的相对值即可，这时，我们就可以使用 distanceSquare 函数，这样做效率更高。在实现上，distanceSquare 函数调用了 Vector3D 类中向量长度平方的计算函数，而 distance 函数调用了 distanceSquare 函数。

在 Point3D 类中，我们还定义了 isCoincide 和 isIdentical 两个函数，这两个函数用于判断两个点是否重合或完全一致。在 isCoincide 函数中，我们以两个点的距离是否小于某一个给定的极小值（参见 GeomBase.py 开头的 epsilon）来判断两个点是否重合；而在 isIdentical 函数中，我们以两个点在各个维度上的坐标值是否分别相等来判断两个点是否一致。这里需要提醒的是，在几何计算中，我们通常需要判断两个点是否重合，但由于计算机截断误差的存在，在理论上应该完全重合的两个点，它们的实际坐标值可能不一致，这时就应该使用 isCoincide 函数来判断两个点是否重合。

我们再来看一下 Vector3D 类，类中的 4 个齐次坐标分别为 dx，dy，dz，dw，其中 dw 默认值为 0，各坐标中的字符 d 表示增量。在 Vector3D 类中，函数 reverse 和 reversed 表示对向量进行取反操作，即对向量的每个坐标值取反。函数 dotProduct 和 crossProduct 都需要输入另一个向量作为参数，分别表示对两个向量求点乘和叉乘，其中向量点乘返回一个实数，向量叉乘返回一个向量。

在两个向量的点乘运算中，根据我们以往对向量的了解，如果两个向量的夹角小于 90°，则它们点乘的结果为正；如果它们的夹角大于 90°，则其点乘结果为负；如果它们的夹角刚好为 90°（即正交），则其点乘结果为 0。根据向量点乘的这些特性，我们可以对任意两个向量的夹角范围作出判断。

在两个向量的叉乘运算中，对得到的积向量，它的方向分别垂直于两输入向量，具体指向可根据右手螺旋法则确定，如图 2.3 所示。如果两个向量平行（方向相同或相反），那么这两个向量叉乘的积向量为零向量（即积向量长度为 0）。根据向量叉乘的这一特性，我们可以对任意两个向量是否平行作出判断。在已判断两向量平行的情况下，如果我们结合向量点乘运算，可进一步判断两向量方向是否相同。

在 Vector3D 类中，函数 amplify 和 amplified 表示对向量进行放大操作，即对向量中的每个坐标值乘以一个给定实数。函数 lengthSquare 和 length 分别用于计算向量长度的平方和长度，和 Point3D 类中的 distanceSquare 函数类似，lengthSquare 函数效率更高。函数 normalize 和 normalized 表示对向量进行单位化操作，即对向量中的每个坐标值除以当前向量长度。函数 isZeroVector 用于判断一个向量是否为零向量。函数 multiplied 作用是对当前向量右乘一个矩阵并返回新的向量。函数 isParallel 以两个向量叉乘结果是否为零向量来判断它们是否平行。

> angle = arccos ( v1 · v2 )

理论上,dotPro 的值应为[-1, 1],但是由于截断误差的存在,dotPro 的计算值可能小于-1或大于 1,如果将不合法的 dotPro 值输入反余弦函数中,则可能会出现数值异常。为了避免这一潜在的问题,我们对 dotPro 的结果进行处理,如果它小于-1,则令其为-1;如果它大于 1,则令其为 1。这里为了使用反余弦函数,我们在 GeomBase.py 开头导入了 math 库。

## 2.2 直线、射线、线段

上一节,我们介绍并使用 Python 实现了点、向量和矩阵 3 个几何基础类,封装了一些基础操作函数。这一节我们将继续介绍并实现直线、射线和线段 3 个类。

### 2.2.1 直线

理论上，直线是空间中经过不重合的两个点且可向两端无限延伸、曲率处为零的一种特殊曲线，它的长度无法度量。我们先来回忆一下，在我们初中阶段学过的平面几何中，直线可由

y = kx + b (2-12)

表示，其中 k 为直线斜率，b 为直线在 XY 坐标系 Y 轴上的截距。在我们高中阶段学过的立体几何中，直线可由

\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{1} (2-13)

或

\begin{cases} A_1x + B_1y + C_1z + D_1 = 0 \\ A_2x + B_2y + C_2z + D_1 = 0 \end{cases} (2-14)

表示。其中式(2-13)称为直线的点向式，式中(x0, y0, z0)为直线经过的点，(m, n, 1)为直线方向向量；式(2-14)称为直线的一般式，由两个空间平面的交线确定直线位置和方向。

在我们将要创建的空间直线类中，我们可以选择直线的点向式或一般式来表达一条直线，但显然，直线的点向式更加直观且容易让人理解，因此，在本书中我们使用直线的点向式来表示直线。

我们将直线类写在 Line.py 文件中，类名为 Line。直线类的实现比较简单，我们只需定义直线经过的点和直线的方向向量，它的具体代码如下：

| 1 | from GeomBase import * | # 导入 GeomBase 模块 |

| 6 | def __str__(self): | # 定义直线类被 print 时的显示行为 |
| 7 | return "Line\\nP %s\\nV %s\\n" % (str(self.P), str(self.V)) | |

由以上代码可知，Line 只表示一种数据结构，包含 P 和 V 两个属性，其中 P 为直线经过的点，V 为直线方向向量(单位向量)。

注意，在 Line 的 __init__ 函数中，我们并没有对 P (或 V) 进行直接赋值(如 self.P = P)，而是调用了 clone 函数，将在内存中复制得到的新点赋给 Line 的 P 属性。这样做的原因是降低 Line 对象创建后，其属性在外部被修改的风险。这是初学者在使用类似 Python、C#、Java 等使用引用方式传值的编程语言时非常容易忽略的问题，而且由此引发的 bug 有时很难被发现。

如果我们不这么做，即在以上__init__函数中不使用 clone 函数，将会发生什么？我们可以运行以下简单的示例代码以便加深印象，有兴趣的读者可以进一步测试。

## 2.3 多段线

上一节，我们实现了直线、射线和线段三个非常简单的几何实体类。我们注意到，这些类表示的线型至多包含两个点，但很多时候，我们可能需要一种能够表达由多个空间点依次连接得到的线型，如图 2.4 所示，我们把这种线型称为多段线、多义线、折线或点列曲线（point-sequence curve，PS-curve）。
