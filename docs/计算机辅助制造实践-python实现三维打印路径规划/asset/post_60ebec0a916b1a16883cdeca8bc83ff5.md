

```python
if zs[mid] < zMax:
    low = mid
else:
    up = mid
stop = low      # 上限序号 stop
if mid == zMax:
    stop = up
for i in range(start, stop + 1, 1):   # 面片层高匹配[start, stop]
    tri.zs.append(zs[i])
```

以上函数输入为升序排序的层高列表，它基本还原了之前分析的二分法步骤和上、下限取值方法。对模型中的每个三角面片，我们都可以快速得到对应的层高列表 zs 中元素取值的上、下限序号 start 和 stop，然后将 zs[start] ~ zs[stop] 逐个添加至对应面片中。这样，我们便完成了用二分法进行模型面片的层高快速匹配。

## 5.3.3 算法流程及实现

之前我们已经大致了解了层高匹配法的基本原理，其本质就是以 STL 模型中的三角面片为主导，去匹配层高列表中的层高，然后再对每个三角面片和它包含的层高求交。显然，层高匹配法可以规避一些不必要的面片和截平面的相交计算，因此从理论上来说，它可以提高截交计算的效率。

图 5.7 给出了基于层高匹配法的 STL 模型截交流程。就像我们在上一节介绍的扫描平面法一样，该流程输入依然是 STL 模型和切片厚度，输出为以 Layer 对象列表组织的截交线段。该流程首先根据模型最低点、最高点和切片厚度生成具有均匀层高特征的层高列表，以及用于保存中间变量的字典 layerDic。注意，这里的字典 layerDic 将保存一系列键值对，其中键为层高值，值为 Layer 对象。然后运用之前介绍的二分法（或暴力法）对模型中的每个三角面片进行层高匹配，将相应层高保存到每个三角面片中。在完成了这些准备工作之后，就可以进行截交计算了。对模型中每个三角面片保存的每个层高值，计算面片和层高之间的截交线段，并将截交线段根据高度 z 保存到 layerDic 中。最后，我们可以将 layerDic 转化成 Layer 对象的列表输出。

## 5.4 算法测试比较

在本章的前面两节，我们分别详细介绍了扫描平面法和层高匹配法，用于 STL 模型截交计算。设计这两种算法的初衷是因为我们认为暴力截交法太过基础，计算效率不高。然而，截至目前，我们尚未对这 3 种截交算法进行过任何比较，虽然按照理论分析，扫描平面法和层高匹配法具有一定的优势，但真实情况还有待实际检验。这一节的任务就是对这 3 种算法进行测试和比较。

## 本章小结

这一章主要针对三维打印路径规划中的模型截交这一问题展开讨论。在第 4 章已经实现的暴力截交法的基础上，我们在本章进一步介绍了两种优化截交算法，即扫描平面法和层高匹配法。扫描平面法的核心是首先对模型中的三角面片进行排序，然后用一扫描平面从低到高收集与之相交的面片并进行截交计算。层高匹配法的本质是以模型中的三角面片为主导，收集与之相交的层高并进行截交计算。在本章最后，我们对暴力法、扫描平面法以及层高匹配法这 3 种截交算法进行了测试比较，结果表明，扫描平面法和层高匹配法的性能持平，虽前者略胜一筹，但都比暴力法高出一个数量级。需要说明的是，尽管我们给出了几种行之有效的截交算法，但不代表这些算法就是最优的。模型截交问题本身仍是一个开放的问题，我们期待读者能够给出更加高效的算法。
