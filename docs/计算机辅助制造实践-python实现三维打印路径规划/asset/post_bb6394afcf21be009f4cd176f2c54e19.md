
到一个三维打印 NC 代码生成模块，用于生成可被实际三维打印机识别和打印的 NC 代码。

需要指出的是，在计算机辅助制造或路径规划中，“路径”是相对于工件模型和工艺参数的几何概念，通常指计算机内存中生成的或存储的曲线（或多段线）数组；而 NC 代码具有设备属性，它是相对于具体数控设备而言的，如数控机床、三维打印机等，数控设备通过读取、解析 NC 代码控制各进给轴运动、I/O 执行相应操作。从曲线路径到 NC 代码的转化过程一般叫作后置处理。后置处理需要考虑目标设备特性，对相同路径，针对不同目标的设备可能生成不同的 NC 代码。

因此，从内容上来说，这一节我们首先要做的是生成路径，然后针对某种具体三维打印机对路径进行后置处理，生成 NC 代码。这里我们以当下市面上极为常见的 FDM 三维打印机为例讲解 NC 代码（通常就是 G 代码）的生成过程。下面我们首先来对三维打印路径生成涉及的重要工艺参数做一个汇总。

## 11.2.1 工艺参数汇总

常规的三维打印路径规划涉及的具体流程包括：三维模型切片、端面识别（含切片疏密分区）、轮廓填充路径生成、平行填充路径生成、支撑路径生成，我们封装的与之对应的函数包括：slice_topo（或 slice_combine）、idEndLayers、genCpPath、genDpPath、genSptPath。因此，原则上，只要我们提取、汇总这些函数的各个输入参数，就能大致构建三维打印路径规划的工艺参数表，如表 11.1 所示。

在表 11.1 中，有些参数可能和上述函数不存在直接关系，但它们是间接相关的。比如 sfRate，该参数表示工件内部稀疏填充区域平行路径的填充率，取值为大于 0 且小于等于 1，它和喷头尺寸( nozzleSize) 一起可用于计算稀疏平行填充间距( sfInvl)，计算公式为：
sfInvl = nozzleSize/sfRate

得到的 sfInvl 可作为参数输入 genDpPath 函数计算稀疏平行填充路径。同理，sptSfRate 表示支撑部分平行填充路径填充率，可用于计算支撑部分平行行填充间距。相对于直接给出平行路径填充间距的具体数值，用填充率显得更直观，且对用户更友好。

此外，在表 11.1 中，根据三维打印的实际需求，我们额外添加了一些参数。如 sptOn，这是一个开关量，表示是否需要生成支撑路径。又如 nozzleSize、filamentSize，分别表示 FDM 打印机喷头直径尺寸和丝材直径尺寸，其中 nozzleSize 可用于计算路径间距，而 nozzleSize 和 filamentSize 一起可用于计算挤丝电机的转动量。参数 g0Speed 和 g1Speed，分别表示快速进给(不出丝)和打印进给(出丝)速度，单位一般为 mm/min (视具体打印机而定)，它们和路径曲线形状无关，但和 NC 代码中各轴进给速度有关。参数 startCode 和 endCode 用于指定 NC 代码中的开始代码和结束代码，在开始代码中，我们可以写入各轴回零、坐标系统选择、打印温度设置、风扇设置等代码；而在结束代码中，我们可以写入程序结束、打印机重置等代码。

PrintParams 类的属性完全根据表 11.1 定义。它的初始化函数仅包含 1 个输入参数，即 stlModel。对于类中大部分属性，我们都给出了相应默认值，如默认 layerThk、shellThk、endThk 分别为 0.2 毫米、2.0 毫米、3.0 毫米，默认 sfRate 为 0.2，即工件内部稀疏填充率为 20%，默认平行路径填充角度（包括工件内部和支撑部分）为 0 度, 默认 sptOn 为 False, 即不生成支撑, 默认危险面片临界角为 60 度等。

在 PrintParams 类中，对 startCode 和 endCode 两个属性，这里我们并未真正对它们进行赋值(G 代码中，英文分号表示注释)，对这两个属性的赋值需要参考具体使用的打印机说明书。同理，对 nozzleSize 和 filamentSize 两个属性，尽管在这里我们给出了它们的常规取值，但在具体使用时也要结合实际使用的喷头和丝材等情况。

最后，需要强调的是，在表 11.1 或 PrintParams 类中，我们给出的三维打印工艺参数仅仅是目前模型切片，端面识别，路径生成，支撑生成等过程所需要的部分参数。现有的这些工艺参数当然可以被进一步拆分，就像我们之前将路径间距 (sfInvl) 拆分成喷头尺寸 (nozzleSize) 和填充率 (sfRate) 一样，或者将打印速度 (g1Speed) 拆分为外壳打印速度、内部填充速度、支撑打印速度等，拆分的目的是对三维打印路径生成过程进行更精确的控制。此外，根据实际需求，我们还可以添加新的工艺参数，如对模型进行轻量化抽壳操作所需的壁厚参数、对切片轮廓进行简化(减少轮廓顶点数)所需的误差参数等。

## 11.2.2 切片路径生成

在上一小节，我们对三维打印路径规划所需的工艺参数进行了汇总，得到了一个打印工艺参数类 PrintParams。在此基础上，在这一小节，我们将对包括模型切片，端面识别，路径生成，支撑生成等过程涉及的函数进行组织，封装一个用于三维打印路径生成的综合函数 genAllPaths，该函数核心步骤如下：

- (1) 对三维模型进行切片(slice_topo 或 slice_combine);
- (2) 识别端面切片，并对切片轮廓进行疏密分区(idEndLayers);
- (3) 对各切片生成轮廓填充路径(genCpPath);
- (4) 对各切片生成密实填充路径(genDpPath);
- (5) 对各切片生成稀疏填充路径(genDpPath);
- (6) 如有必要，生成支撑路径(genSptPath)。

根据以上步骤，下面我们在 GenNcCode 模块中给出 genAllPaths 函数的具体实现代码：

```python
...... # 导入相关库,忽略其他代码
def genAllPaths(pp : PrintParams) : # 定义路径生成函数
    sfInvl = pp.nozzleSize / pp.sfRate # 计算工件内稀疏平行填充间距
    sptSfInvl = pp.nozzleSize / pp.sptSfRate # 计算支撑部分平行填充间距
    layers = slice_topo(pp.stlModel, pp.layerThk) # 1.对模型切片,得到切片序列
    idEndLayers(layers, pp.shellThk, int(pp.endThk / pp.layerThk) + 1) # 2.端面识别,疏密分区
    for i, layer in enumerate(layers) : # 遍历切片生成路径
        layer.cpPaths, layer.ffPaths, layer.sfPaths = [], [], [] # 定义轮廓、密实、稀疏填充路径
        layer.cpPaths = genCpPath(layer.contours, pp.nozzleSize, pp.shellThk) # 3.生成轮廓路径
        delta = 0 if i % 2 == 0 else math.pi / 2 # 平行路径上、下层交叉填充
        if len(layer.ffContours) > 0 : # 4.生成密实填充路径
            layer.ffPaths = genDpPath(layer.ffContours, pp.nozzleSize, pp.fillAngle + delta)
        if len(layer.sfContours) > 0: # 5.生成稀疏填充路径
            layer.sfPaths = genDpPath(layer.sfContours, sfInvl, pp.fillAngle + delta)
        if pp.sptOn: # 6.生成支撑路径
            genSptPath(pp.stlModel, layers, sptSfInvl, pp.sptGridSize, pp.sptCrAngle, \
                pp.sptFillType, pp.sptFillAngle, pp.sptXyGap)
    return layers # 返回切片序列
```

以上 genAllPaths 函数的输入参数只有 1 个，即 pp，类型为 PrintParams，该参数已包含 STL 模型数据。在该函数中，首先根据填充率计算填充间距，然后依次执行上述 6 个步骤，生成全部打印路径。对密实填充区域（以及轮廓填充区），为了保证打印所得工件的封闭性，我们为其设置的填充间距为喷头直径。针对每层切片，我们总共生成了 5 种打印路径，包括工件部分的轮廓路径 cpPaths、密实填充路径 ffPaths、稀疏填充路径 sfPaths，以及支撑部分的轮廓路径 sptCpPaths 和填充路径 sptDpPaths（参见代码 10-10）。这 5 种路径属性都是通过动态方式添加至 Layer 类的。因为这里对切片序列 layers 进行了遍历，因此我们不必担心忘记为某些切片添加属性。

需要说明的是，并非每层切片都存在于上述 5 种路径，某些切片可能只存在其中一两种路径。如果某种路径存在，则相应路径序列不为空（序列中元素个数大于 0），否则序列为空。此外，在以上步骤（1）中，我们默认调用了 slice_topo 函数对输入模型进行切片，这完全是一种随机选择，其实我们也可以使用 slice_combine 函数完成模型切片。

函数 genAllPaths 的返回为包含打印路径的切片序列 layers，在下一小节，我们将对得到的这些切片进一步操作，将切片中的路径转化为 NC 代码。

## 11.2.3 路径代码转换

对常见的 FDM 三维打印机来说，它能接收的 NC 代码一般就是指 G 代码。G 代码是数控加工领域使用最为广泛的编程语言，是人类和数控设备沟通的桥梁之一。标准的 G 代码一般包含 G（准备）和 M（辅助）两种功能字，分别由地址符 G、M 和其后的数字组成。其中 G 功能字主要用于指定数控插补、刀具补偿、坐标选择、循环控制等功能；M 功能字主要用于指定主轴旋转方向、冷却液开关、程序启停、刀具更换等功能。

对 FDM 三维打印机来说，它能接收的 G 代码是标准 G 代码的一个子集（或对子集的修改）。这里我们只介绍和打印路径本身相关的几个指令，包括 G0、G1、G90、G91，它们的具体功能如表 11.2 所示：

表 11.2 FDM 三维打印和路径相关的若干 G 代码

| 指令 | 功能 | 示例 |
|---|---|---|
| G0 | 快速定位，不出丝 | G0 F2000 X10.1 Y 20.2 Z 30.3 |
| G1 | 直线插补，打印出丝 | G1 F1000 X20.1 Y 30.2 Z 40.3 E50.1 |
| G90 | 指定绝对坐标编程 | G90 |
| G91 | 指定增量坐标编程 | G91 |

在 NC 代码中，我们一般使用 G0 和 G1 两个指令来跟踪、描绘打印路径。其中 G0 为快速定位指令，可控制打印喷头从一个点快速移动到另一点，其间喷头不出丝，通常被用于两段打印路径之间的衔接。在实际使用中，我们需要在 G0 指令后面添加速度指令（F 字段）和终点坐标指令（X、Y、Z 字段），移动的起点就是当前所处点。G1 为直线插补指令，可控制打印喷头从一个点沿直线轨迹移动到另一点，其间喷头出丝。和 G0 一样，在实际使用中，我们也需要在 G1 指令后面添加 F、X、Y、Z 的具体数值；此外，为了控制喷头出丝，我们还需要为其添加进丝指令（E 字段，表示进丝长度）。

需要说明的是，G0 和 G1 都是模态指令（续效指令），即在 G0 或 G1 引导的代码中，如果当前行代码中的某个字段相对于上一行代码相同字段的数值未发生改变，那么我们可以在当前行代码中省略这个字段，如对以下两行代码：

| 行号 | 代码 |
|---|---|
| 1 | G1 F1000 X10 Y20 Z30 E40; (10, 20, 30) |
| 2 | G1 F1000 X30 Y40 Z30 E50; (30, 40, 30) |

我们可以将其简写为：

| 行号 | 代码 |
|---|---|
| 1 | G1 F1000 X10 Y20 Z30 E40; (10, 20, 30) |
| 2 | G1 X30 Y40 E50; (30, 40, 30) |

我们甚至可以省略第二行中的"G1"。注意，在 G 代码中，我们使用英文分号“；”进行代码注释。

对于表 11.2 中的 G90 和 G91，G90 表示绝对编程，G91 表示增量（相对）编程。它们的区别主要体现在 G0 和 G1 上。如对以上两行代码，涉及的 X、Y、Z 坐标分别为（10, 20, 30）和（30, 40, 30）。如果采用绝对编程，那么（10, 20, 30）和（30, 40, 30）就是执行两段代码后的终点坐标；但如果采用增量编程，那么终点坐标分别为（10, 20, 30）和（40, 60, 60）[假设（10, 20, 30）本身等于绝对坐标]。在 FDM 三维打印中，我们一般使用绝对坐标编程，即使用 G90 指令。

显然，G 代码中的 X、Y、Z 坐标数值是可以直接从路径曲线中提取得到的，那进丝指令 E 的数值又该如何得到呢？在 FDM 三维打印中，打印丝材在打印喷头的加热和进丝电机的挤压作用下，从喷头挤出，如图 11.9 所示。通常情况下，喷头直径小于丝材直径，即从喷头前进去的丝材长度要小于从喷头挤出来的丝材长度，它们之间的具体关系如下：

$$ \frac{L_{in}}{L_{out}} = \left( \frac{nozzleSize}{filamentSize} \right)^2 $$ (11-7)

式中，L_{in} 为进丝长度，L_{out} 为出丝长度。在知道出丝长度的情况下，根据式 (11-7)，我们可以计算相应的进丝长度。而在 FDM 三维打印中，喷头喷出的丝材长度等于由 G1 指定和累加的路径总长度，因此，在已知打印路径的前提下，我们可以计算得到相应的出丝长度。综上所述，只要对路径长度进行累加，同时结合式 (11-7) 对长度进行转换，我们就可以对 G 代码中的进丝量 E 进行赋值。

在以上对 G 代码介绍的基础上，下面我们给出从打印路径到 NC 代码转化的后处理函数。首先给出将一条路径曲线“翻译”成 G 代码的函数，函数名为 pathToCode，它的具体实
