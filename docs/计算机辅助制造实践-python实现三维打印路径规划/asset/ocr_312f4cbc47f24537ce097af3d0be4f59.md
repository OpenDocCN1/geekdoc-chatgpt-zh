# 9.6 平行路径生成与优化测试

通过前面几节的介绍，我们得到了 4 个和平行填充路径生成相关的模块，包括 GenHatch、SplitRegion、GenDpPath 以及 FindOptFeedDir，这些模块分别用于扫描填充线生成、填充区域分区、平行路径生成以及最少跳刀填充方向优化。考虑 GenHatch、SplitRegion 两个模块是 GenDpPath 的支撑模块，而 FindOptFeedDir 又是一个相对独立的模块，因此在这一节，我们主要对 GenDpPath 和 FindOptFeedDir 两个模块展开测试。
