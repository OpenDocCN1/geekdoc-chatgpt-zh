
下面我们就是需要从角度表中找出相交次数最少的角度值，并将它作为最少跳刀填充角度。在_initAngleTable 函数中,我们用到了 round 函数确保角度表中的各角度值保留的小数位数是可控的,这一点其实非常重要,因为在后续代码中,我们正是根据可控的小数位数在角度表(字典)中查询相应角度的交点个数的。

试想: 如果小数位数不可控,尽管数值相似,但我们可能根本无法从角度表中找到目标键值。

在得到了_findAnglePairs(四顶点角度对计算函数)和_initAngleTable(扫描角度表构建函数)两个函数之后,下面我们结合上一小节最后讨论的Ψ取值的 3 种情况给出最少跳刀填充角度的计算函数,函数名为 findOptFeedDir,注意,这个函数没有下划线前缀,它是一个对外输出的接口函数,其具体实现代码如下:

| FindOptFeedDir.py | 最少跳刀优化模块,寻找最少跳刀填充角度函数 | 9 - 16 |
|---|---|---|
| 1 ...... | # 导入相关库,忽略其他代码 | |
| 2 def findOptFeedDir(polygons, digit = 0, adjustPolyDirs = False): # 定义函数 | | |
| 3 anglePairs = _findAnglePairs(polygons, adjustPolyDirs) | # 获取四顶点角度对列表 | |
| 4 angleTable = _initAngleTable(digit) | # 获取扫描角度表(字典) | |
| 5 delta = math.pow(10, -digit) | # 扫描角度增量 | |
| 6 for a, b in anglePairs: | # 遍历角度对,获取切线角度 | |
| 7 if b <= 180: | # 情况 1:[a, b] | |

| 10 angleTable[key] += 1 | # 当前角度上的交点个数累加 1 | |
| 11 key = round(key + delta, digit) | # 角度自增 delta | |
| 12 elif a >= 180: | # 情况 2:[a-180, b-180] | |
| 13 key = round(a - 180 + delta, digit) | # 同上情况 1 | |
| 14 while key <= round(b - 180 - delta, digit): | | |
| 15 angleTable[key] += 1 | | |
| 16 key = round(key + delta, digit) | | |
| 17 elif a <= 180 and b >= 180: | # 情况 3:[0, a'] U [b', 180) | |
| 18 b = b - 180 | # 先对 a,b 值进行调整 | |
| 19 a, b = min(a, b), max(a, b) | | |
| 20 key = round(delta, digit) | # 前半段 [0, a'] | |
| 21 while key < a: | | |
| 22 angleTable[key] += 1 | | |
| 23 key = round(key + delta, digit) | | |
| 24 key = round(b + delta, digit) | # 后半段 [b', 180) | |
| 25 while key < 180: | | |
| 26 angleTable[key] += 1 | | |
| 27 key = round(key + delta, digit) | | |
| 28 return angleTable | # 返回角度表 | |

以上 findOptFeedDir 函数的输入参数包括 polygons、digit 以及 adjustPolyDirs，这 3 个参数各自代表的含义我们在上面都已经做过解释，在默认情况下，我们设定 digit 为 0，即角度精度为 1 度，adjustPolyDirs 为 False，即无需调整输入多边形方向。在 findOptFeedDir 函数中，我们首先做了一些数据准备工作，包括调用_findAnglePairs 函数生成多边形上所有凹顶点角度对列表 anglePairs，以及调用_initAngleTable 函数获取初始扫描角度表 angleTable。随后是函数主体，根据角度对中两角度的取值情况分 3 种情况讨论，这里我们以第 1 种情况为例说明，第 2 及第 3 种情况类似。

在第 1 种情况下，b <= 180，即 a < b <= 180，根据上一小节的讨论结果，此时切线角度的取值范围为 [a, b]，我们需要做的就是对 [a, b] 范围内的各个扫描角度对应的交点个数加 1。在代码中，我们对切线角度范围 [a, b] 进行了压缩，使其变成 [a+delta, b-delta]，其中 delta 为角度表中角度增量（或称为角度精度、角度分辨率），这其实是一种偏保守或偏安全的做法，确保在此区间的角度值对应的直线都是相应顶点的切线。

在代码中，我们使用了不少次 round 函数进行四舍五入，确保计算得到的小数位数可控且为指定值，这样做的目的是保证根据角度值查询角度表（字典）angleTable 时不会出现找不到键值的情况。

在讨论完 3 种情况后，角度表 angleTable 中每个角度对应的交点个数都应被赋值，函数返回。理论上，我们只要遍历返回的角度表，就能从中找出交点个数最少对应的角度值。至此，我们已经实现了最少跳刀填充方向优化，对任意输入的多边形区域和角度精度，我们都能够使用 findOptFeedDir 函数找出针对这些多边形的最少跳刀填充角度。我们只要将这些角度中的任意一个角度输入上一节得到的 genDpPath 函数（参见代码 9-12），就能生成最少跳刀填充路径。

最后，需要指出的是，我们可以通过事先移除输入多边形上冗余精度点的方式进一步对 findOptFeedDir 模块进行优化。如图 9.28 所示，对多边形上的 3 个连续顶点 P_{k-1}、P_k 和 P_{k+1}，如果 P_k 到线段 P_{k-1}P_{k+1} 的距离 d_k 小于一个极小的正实数 \varepsilon，那么我们定义 P_k 是一个冗余精度点。根据以上定义，多边形上的平角点显然是一个冗余精度点。

此外，只要 d_k 足够小，删除 P_k 并不会对原多边形轮廓造成什么影响，反而可以减少轮廓上的细微扰动，使多边形变得更加简洁。对 findOptFeedDir 模块来说，删除冗余精度的凹顶点是非常有意义的，可以减少代码 9-14 中需要计算的角度对，提升结果的实用性和可靠性。对本章及上一章涉及的相关路径规划算法，删除多边形上的冗余精度点都是非常有意义的。

### 9.6.2 跳刀优化测试

在这一小节,我们将对之前实现的跳刀优化模块(即 FindOptFeedDir)进行测试,并借此找出图 9.30 中切片轮廓的最优填充角度,即最少跳刀填充角度。我们将这部分测试代码写在 Test_findOptFeedDir.py 文件中(以下简称测试文件)。

我们知道,FindOptFeedDir 模块的核心为其同名函数 findOptFeedDir,该函数包含 3 个输入参数,分别为:当前层轮廓列表 polygons,小数位数 digit(默认为 0)以及表示是否需要调整输入轮廓方向的布尔型变量 adjustPolyDirs(默认为 False,即无需调整轮廓方向)。该函数输出为一个凹峰点关于填充角度的字典(角度表),其中字典的键表示 0~179 度的角度值,相邻角度间距为 1 度,字典的值表示填充线在相应角度下的凹峰点个数。根据公式 (9-13),在已知轮廓凹峰点个数(Np)的情况下,我们可以轻松地计算得到相应分区个数(2Np+1)。我们在测试文件中创建的第一个函数为 getAngleTable，它的输入为指定切片层轮廓，功能是调用上述 findOptFeedDir 函数(使用默认参数)并打印计算得到的相应角度表，同时统计函数运行时间。
