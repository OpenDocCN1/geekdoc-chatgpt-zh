# 第 9 章 方向平行填充路径生成

# 引言

对每层打印区域，三维打印有两种常用的填充方式，一种是轮廓填充，另一种是平行填充。为了兼顾打印精度和效率，在大多时候，我们会混合使用这两种填充方式，即在打印区域边缘处使用轮廓填充以保证轮廓精度，而在其内部使用平行填充以保证填充效率。在上一章中，我们已经对轮廓路径的生成方法做了详细介绍，其核心是平面曲线的偏置算法。在这一章，对一指定区域，我们的任务是在其内部生成平行路径，其核心是平面区域的平行线填充算法，即用一组具有一定倾斜角度的等距平行线去截交区域边界，计算并统计落在区域内部的有效线段。在此基础上，我们只要合理连接这些线段，就能得到平行路径。首先我们来看一下针对平面区域的通用平行填充线计算方法。

# 9.1 扫描线法填充线生成

对任一给定的可能包含若干外边界(逆时针)和内边界(顺时针)的平面多边形打印区域，如图 9.1 所示，在该区域内生成平行填充线的原理其实非常简单，步骤如下：

+   (1) 生成一组指定倾角且能够覆盖整个区域的平行直线序列；
+   (2) 遍历其中每条直线，计算当前直线和区域的交点；
+   (3) 根据交点在直线上的奇偶顺序提取填充线段并输出。
