```
3    sptLength = 0.0                                # 支撑线段总长度
4    newModel = stlModel.rotated(a, b, 0)          # 对模型绕 X、Y 轴旋转变换
5    fsr = FindSptRegion(newModel, None, gridSize, crAngle)  # 定义 FindSptRegion 对象 fsr
6    gridDic = fsr.calcModelSptPoints()            # 模型支撑点，返回 gridDic
7    for key in gridDic:                           # 根据交点奇偶性和 crAngle
8        zas = gridDic[key]                        # 提取支撑线段
9        for i in range(0, len(zas), 2):
10            if i + 1 <= len(zas) - 1:
11                za0, za1 = zas[i], zas[i+1]
12                if za1[1] < crAngle:
13                    sptLength += (za1[0] - za0[0])    # 累加支撑线段长度
14    return sptLength * fsr.ax * fsr.ay            # 计算并返回支撑空间体积
```

在以上代码中，我们可以看到，fitness 函数共有 5 个输入参数，几个参数名我们都很熟悉，其中 stlModel 为三维模型，a 和 b 分别为模型绕 X、Y 轴的旋转角度（单位为弧度），gridSize 就是模型投影网格尺寸，crAngle 为危险面片临界角（单位为弧度）。必须强调的是，这里的 stlModel 为未经任何几何变换的初始模型。

在 fitness 函数中，我们首先根据转角参数 a 和 b 对输入模型进行了旋转变换，得到了一个新模型。然后我们以新模型以及网格尺寸、临界角作为参数构造了一个 FindSptRegion 类的对象 fsr，注意，在构造该对象时，我们对 FindSptRegion 的 layers 参数赋了 None 值，表明这个参数是不需要的，这也正是我们用支撑空间替换支撑路径长度作为粒子适应度的原因。随后我们通过调用 calcModelSptPoints 函数计算获得了模型支撑点，且这些点被组织并存在了字典 gridDic 中，其中字典键为网格节点坐标标，字典值为过当前网格节点同一竖线上的支撑点。通过 gridDic 对象，我们就可以根据支撑点的序号的奇偶性及相应面片的临界角来提取支撑线段并计算其长度。最后结合实际单元网格边长（FindSptRegion 类中保存的 ax 和 ay 值），我们就可以计算支撑空间的体积。

fitness 函数涉及的计算量仍然是相当可观的。它的主要计算量消耗在对模型的旋转变换和对 calcModelSptPoints 函数的调用中，因为这两处地方都需要对模型中的所有面片进行遍历，而这些遍历似乎是不可避免的。有兴趣的读者不妨对 fitness 函数展开进一步探索和研究，以期降低其计算量，或者重新寻找能够评价支撑量且更简易的指标。

以上我们给出了指定模型在指定转角（α，β）下的支撑空间体积计算函数 fitness。根据我们之前的描述，在我们要构建的粒子群算法中，（α，β）就是粒子的位置，支撑空间体积 V_s 就是粒子的适应度，而 fitness 就是粒子的适应度函数。但是，我们始终没有给出关于粒子速度的定义，事实上，在这里我们并不打算去定义粒子的速度项。这是因为我们在后面将对传统的粒子群算法进行改造，而在改造的粒子群算法中，速度项是不需要的。
