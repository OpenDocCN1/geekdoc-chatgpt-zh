在以上 Circle 模块中，我们定义了一个变量（ PI ），一个类（ Circle ），一个函数（ compare）。在 Circle 类中，我们绑定了 radius（半径）属性，并定义了圆面积计算函数 area。在模块中，我们还定义了一个 main 函数，main 函数是程序运行的入口，在 Python 中，main 函数的书写规范如上，其中__name__和__main__前后均为两个下划线字符。在 PyCharm 中运行 circle.py，程序将逐行运行 main 函数中的语句。在模块中定义 main 函数的目的是方便对模块功能进行测试。对模块本身来说，main 函数不是必要的。

在创建了模块后，下面我们来看一下如何在另一个.py 文件中使用该模块。首先我们新建一个 Test1.py 文件，在该文件中添加如下代码：

| Test1.py | 模块使用示例 1 | 1 - 13 |
|---|---|---|
| 1 | import Circle | # 使用 import 关键字导入 circle 模块 |
| 2 | if __name__ == '__main__': | # 定义 main 函数 |
| 3 | c1 = Circle.Circle(2) | |
| 4 | c2 = Circle.Circle(3) | |
| 5 | print(c1.area()) | # 输出：12.5663704 |
| 6 | print(Circle.compare(c1, c2)) | # 输出：Not equal |
| 7 | print(Circle.PI) | # 输出：3.1415926 |

在 Test1.py 中，如果需要使用在 Circle 模块中定义的内容，首先需要使用 import 关键字导入 Circle 模块。

注意，这里的 Circle 就是 Circle.py 文件名中的 Circle。导入模块后，在 Test1.py 中引用 Circle 模块中的内容（变量、类、函数）需要加上模块名前缀。

如果需要引用 PI 变量，应写成 Circle.PI；如果需要引用 Circle 类，应写成 Circle.Circle；如果需要引用 compare 函数，应写成 Circle.compare。有时我们可能觉得这样很麻烦，Python 则为我们提供了更为简便的方法，在使用模块时可以不写模块名前缀。

| Test2.py | 模块使用示例 2 | 1 - 14 |
|---|---|---|
| 1 | from Circle import * | |
| 2 | if __name__ == '__main__': | # 定义 main 函数 |
| 3 | c1 = Circle(2) | |
| 4 | c2 = Circle(3) | |
| 5 | print(compare(c1, c2)) | # 输出：Not equal |
| 6 | print(PI) | # 输出：3.1415926 |

如上所示，我们只需在 Test2.py 文件开头将 import Circle 替换为 from Circle import * ，就可以省略模块名前缀。

需要说明的是，from Circle import * 语句中的 * 表示导入 Circle 模块中所有内容，有时候这是不必要的，也许我们在 Test2.py 中只需要使用 Circle 模块中的 PI 变量或 Circle 类，此时我们只需将上述语句改写成 from Circle import PI 或 from Circle import Circle 即可。
