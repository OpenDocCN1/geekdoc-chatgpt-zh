$e_1.OE.F.used$ 均为 True，尽管这在现实情况下不太可能发生，但我们还是要把这种情况枚举出来并给出相应对策，这只能说明当前面片的目标邻面为 None，即不存在。

接下来我们再来看一下 intersect 函数返回的第二种情况，即 node 不为 None。此时截交线段的两端点一个落在当前前片的半边上，另一个落在当前前片的顶点上，如图 7.14 所示。我们不妨记这条半边为 e,e = edges[0]。

相对于第一种情况，第二种情况更为复杂，我们先从简单的情形入手讨论。显然，当前前片的目标邻面极有可能就是 e 的对边所在的面片，即 e.OE.F。如果 e.OE.F 从未被使用过，即 e.OE.F.used 为 False 时，如图 7.14(a)，那么当前前片的上一个面片必然和当前面片在顶点 node 处相邻，即轮廓线从上一面片穿过 node 而来，穿越当前面片，在半边 e 处穿出当前面片进入目标邻面，在这种情况下，目标邻面必然是 e.OE.F。但是，如果 e.OE.F.used 为 True，如图 7.14(b)，此时目标邻面必然在以顶点 node 为公共顶点的面片中，我们需要遍历这些面片，找出除当前面片以外和截平面相交的面片，并把这个面片作为目标邻面；当然，如果我们找不到这样的面片，那就说明当前前片的目标邻面为 None。

![](bbox=[0.105, 0.382, 0.941, 0.626])

针对当前前片，以上我们罗列了两种寻找目标邻面的情况。根据这两种情况，我们可以从种子面片开始，连续追踪目标邻面。对于当前面片，或者存在目标邻面，或者不存在目标邻面。如果存在目标邻面，那么轮廓线可以继续生长；如果不存在目标邻面，那么轮廓线的生长到此为止，或闭合，或不闭合。

结合以上分析和讨论，接下来我们考虑将寻找目标邻面的原理和功能封装成一个函数，函数名为 findNextFace，意思为寻找当前前片的下一个面片，这个函数有助于我们构建邻面追踪循环。

当然，在这里，我们并不打算将 findNextFace 写成一个全局函数，我们把它放在 TopoSlicer 类中（对应 TopoSlicer.py 文件），顾名思义，这是一个专门为实现拓扑模型切片而创建的类，是本章核心切片功能的载体。
