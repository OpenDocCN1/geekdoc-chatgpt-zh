

$l_1(P_1, V_1)$ 和 $l_2(P_2, V_2)$，且事先我们已经知道这两条直线在同一平面上，如图 2.10 所示。理论上，我们可以根据已知条件将两条直线整理成形如式(2-13)的方程组，然后求解方程组获得交点坐标，这里我们介绍另一种方法。不妨记两直线交点为 P，那么在两直线上，分别可得

```
\begin{cases} P = P_1 + V_1 \cdot t_1 \\ P = P_2 + V_2 \cdot t_2 \end{cases}
```

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_50_0.png)

图 2.10 平面两直线求交计算

其中，$t_1, t_2$ 分别为 P 到 $P_1, P_2$ 的长度参数（可为负），只要要求得 $t_1, t_2$ 值，便可获得交点 P 坐标。根据式(2-23)进一步可得

```
$P_1 P_2 = V_1 \cdot t_1 - V_2 \cdot t_2$
```

考虑到式(2-24)中向量有 3 个维度，可得

```
\begin{cases} P_1 P_2.dx = V_1.dx \cdot t_1 - V_2.dx \cdot t_2 \\ P_1 P_2.dy = V_1.dy \cdot t_1 - V_2.dy \cdot t_2 \\ P_1 P_2.dz = V_1.dz \cdot t_1 - V_2.dz \cdot t_2 \end{cases}
```

对式(2-25)，我们可以任取两个等式借助 Mathematica 软件求解 $t_1, t_2$，如图 2.11 所示。如果分母为 0，则取另外两个等式求解。如果分母依然为 0，则说明两条直线平行，无交点。在解得 $t_1, t_2$ 后，代回式(2-23)，可得两直线交点坐标。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_50_1.png)

图 2.11 使用 Mathematica 求解直线相交方程

在解决两直线求交问题后，我们再来考虑一下两条线段的求交问题。记两线段为 S1(A1, B1) 和 S2(A2, B2)，如图 2.12 所示，另记 V1 = A1B1 / |A1B1|, V2 = A2B2 / |A2B2|, P1 = A1, P2 = A2，两线段长度分别为 L1 和 L2。根据这些条件，我们借鉴以上两直线求交方法可得 t1, t2 值以及交点 P 坐标。如果 0 <= t1 <= L1 且 0 <= t2 <= L2，那么交点同时落在两线段上，此时两线段相交；否则两线段不相交。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_51_0.png)

图 2.12 平面两线段求交计算

此外，针对直线和线段、直线和射线、射线和线段以及射线和射线的相交问题，我们同样可以通过判断 t1、t2 值来判断两线之间是否存在交点，这里不再赘述。

### 2.线面求交

针对线面求交，我们先来看一下直线和平面的求交问题。记直线和平面分别为 l(P0, V) 和 α(P1, N)，记两者交点为 P，那么 P = P0 + V * t。这里我们依然采用向量法进行分析推导，由于 P 点落在平面上，那么 P 点和平面上任意点的连线必然垂直于平面法向量，即 PP1 * N = 0，代入 P 点坐标推导可得：

```
t = P0 P1 * N / V * N
```

如果 V 和 N 垂直，分母为 0，此时直线和平面平行，无交点；否则，根据计算出的 t 值可确定交点坐标。

针对射线和平面求交以及线段和平面求交问题，我们可以借鉴处理上述线线求交的方法，先计算射线或线段所在直线和平面的 t 值以及交点坐标，然后对 t 的取值进行判断，从而确定交点是否在射线或线段上。

## 2.5.3 点和多边形关系

简单起见，我们在这里将点和多边形限定在 XY 平面上。点和多边形的关系包括点在多边形内、点在多边形上以及点在多边形外 3 种情形。这是一个大家都非常熟悉的平面几何问题，如果不考虑点落在多边形上的情形，那么我们都知道这个问题可用构造射线的方法解决，即从该点向无穷远处作一条射线，计算射线和多边形的穿过次数，如图 2.13 所示，如果穿过次数为奇数，那么该点落在多边形内；如果穿过次数为偶数，那么该点落在多边形外。尽管如此，这个方法实现起来并非容易。

结合以上介绍的关于射线和线段的求交方法，我们可以让射线和多边形中的所有线段求交，获取交点个数，进而统计穿过次数。但仅仅这样是不够的，因为交点个数并不等价于穿过次数，如果射线在线段端点处相交，同一位置的交点将被统计 2 次。这在某些情况下是对的，如图 2.14 中的情况 1 和情况 2；但在另一些情况下是错的，如图 2.14 中的情况 5。为了避免上述情况的发生，我们在设计算法时，将射线和多边形的求交问题分成两部分：一是射线和不含两端点的线段求交，二是射线和多边形顶点求交。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_52_0.png)

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_52_1.png)

我们需要重新思考射线和线段（不含两端点）的求交方法。但我们还是会参照两直线求交的方法，首先计算出参数 t1、t2，其中 t1 对应射线，t2 对应线段。如果 t1 = 0，表明交点落在射线起点，此时可以马上判定点在多边形上，无需进一步计算。如果 t1 > 0 且 0 < t2 < L，其中 L 为线段长度，那么射线和线段（不含两端点）相交，此时射线穿过多边形的次数加 1。

接下来我们要考虑射线恰好穿过多边形顶点处的情形。这个问题比上一个问题复杂一点，需要判断顶点两边线段的走势。如果两边在射线同一侧，那么可以认为穿过次数为 0（或 2），如图 2.14 中的情况 1 和情况 2；如果两边分别在射线两侧，那么认为穿过次数为 1，如图 2.14 中的情况 5；但是如果两边中有一边和射线重合，如图 2.14 中的情况 3 和情况 4，则需进一步判断下一条边的位置，这样会让问题处理起来非常棘手。

我们可以退一步思考，首先统计所有顶点位于射线上的线段，如果某条线段和射线重合，则认为该线段两端点都不在射线上。然后对这些线段进行配对，如图 2.15 所示，我们可以不必理会它们之间的相对位置，直接对一条位于射线一侧的线段和一条位于射线另一侧的线段进行配对，配对成功后穿过次数加 1。对那些位于射线同一侧的线段对，认为穿过次数为 0，或者认为穿过次数为 2，但这对最终穿过次数的奇偶性不会造成影响。

最后我们讲一下射线的构造。在以上讨论中，我们认为射线的方向是任意的，但这样会给我们的实际计算带来不少麻烦，比如判断点和射线的位置关系。简单的做法就是在不影响结果的前提下找一个特例，而最简单的特例就是让射线方向和 X 轴方向平行，这样要判断点和射线的相对关系只需比较两者 Y 坐标的高低即可。

def intersectLineLine(line1 : Line, line2 : Line):          # 计算直线和直线的交点，返回
    P1, V1, P2, V2 = line1.P, line1.V, line2.P, line2.V         # 交点及 t1 和 t2,参考图 2.10
    P1P2 = P1.pointTo(P2)
    deno = V1.dy * V2.dx - V1.dx * V2.dy                       # 分母，参考图 2.11
    if deno != 0:
        t1 = -(-P1P2.dy * V2.dx + P1P2.dx * V2.dy) / deno
        t2 = -(-P1P2.dy * V1.dx + P1P2.dx * V1.dy) / deno
        return P1 + V1.amplified(t1), t1, t2
    else:
        deno = V1.dz * V2.dy - V1.dy * V2.dz
        if deno != 0:
            t1 = -(-P1P2.dz * V2.dy + P1P2.dy * V2.dz) / deno
            t2 = -(-P1P2.dz * V1.dy + P1P2.dy * V1.dz) / deno
            return P1 + V1.amplified(t1), t1, t2
    return None, 0, 0                                          # 如果不相交，返回 None
def intersectSegmentPlane(seg : Segment, plane : Plane):     # 计算线段和平面的交点
    A, B, P, N = seg.A, seg.B, plane.P, plane.N
    V = A.pointTo(B)
    PA = P.pointTo(A)
    if V.dotProduct(N) == 0: return None       # 线段和平面平行，返回 None
    else:
        t = -(PA.dotProduct(N)) / V.dotProduct(N)
        if t >= 0 and t <= 1: return A + (V.amplified(t))
    return None

def intersect(obj1, obj2):            # 实体求交计算
    if isinstance(obj1, Line) and isinstance(obj2, Line):   # 情况 1:直线和直线求交
        P, t1, t2 = intersectLineLine(obj1, obj2)
        return P
    elif isinstance(obj1, Segment) and isinstance(obj2, Segment): # 情况 2:线段和线段求交
        line1, line2 = Line(obj1.A, obj1.direction()), Line(obj2.A, obj2.direction())
        P, t1, t2 = intersectLineLine(line1, line2)          # 调用 intersectLineLine 函数
        if P is not None:
            if t1 >= 0 and t1 <= obj1.length() and t2 >= 0 and t2 <= obj2.length():
                return P
        return None
    elif isinstance(obj1, Line) and isinstance(obj2, Segment):    # 情况 3:直线和线段求交
        line1, line2 = obj1, Line(obj2.A, obj2.direction())
        P, t1, t2 = intersectLineLine(line1, line2)
        return P if P is not None and t2 >= 0 and t2 <= obj2.length() else None
    elif isinstance(obj1, Line) and isinstance(obj2, Ray): pass      # 情况 4:直线和射线求交
    elif isinstance(obj1, Ray) and isinstance(obj2, Segment): pass  # 情况 5:射线和线段求交
    elif isinstance(obj1, Ray) and isinstance(obj2, Ray): pass      # 情况 6:射线和射线求交
    elif isinstance(obj1, Line) and isinstance(obj2, Plane):       # 情况 7:直线和平面求交
