个和切片过程不相关但能反映支撑量的概念是支撑空间体积，即处在危险面片正下方、模型外部的空间体积。我们可以用支撑空间体积 $V_s$ 替换支撑路径总长度 $L_s$，作为粒子的适应度，即：

$V_s = V_s(\alpha, \beta)$ (10-10)

在这种情况下，我们又该如何定量计算指定模型上的支撑空间体积呢？
在封装 FindSptRegion 类时，我们已经涉及了支撑空间体积计算的相关概念。在计算切片层上的支撑区域时，我们提出了支撑线段的概念。通俗地讲，支撑线段就是过模型投影网格节点，位于模型支撑空间内用于支撑模型上悬臂、横梁等危险结构的一系列线段，如图 10.23 所示。为了降低计算量，我们通过合理设置网格尺寸，让支撑线段稀疏地分布在支撑空间内。我们发现，支撑线段的总长度就可以用来评价支撑空间的大小。进一步地，如图 10.6，如果我们将支撑线段总长度乘上单元网格的面积，就可以近似算出支撑空间体积(类似于微积分中体积微元的累加或积分)，其精度和投影网格的精细程度有关，显然，网格尺寸越小，数量越多，得到的支撑空间体积越精确。
