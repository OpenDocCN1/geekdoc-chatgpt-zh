# 图 10.29 粒子群算法优化前后立方体模型摆放角度及支撑量变化

对立方体模型, 尽管几次测试中粒子群算法找到的最优支撑量都为 0, 但最优解却不尽相同, 如转角对(α, β) = (232.5°, 207°)、(180°, 130°)、(52.5°, 153°) 等都是问题的全局最优解。这是可以理解的, 考虑到α和β的定义域为 [0, 2π], 在这么宽松的定义域下, 模型本来就可以通过多种方式旋转到最优位置, 如对以上最优解 (180°, 130°), 我们可以推断, (180°, 310°) 也必然是问题的最优解。我们可以通过缩小α和β的取值范围来减少最优解数量, 如让其在 [0, π/2] 内取值; 但这样会带来另一个问题, 如果问题最优解恰在定义域边界上取到, 那么粒子群在进化、变异过程中就可能“处处碰壁”, 不利于最优解确定, 这也正是我们将α, β的定义域设置为 [0, 2π] 的原因。以上测试中, 对包含 12 个面片的 STL 模型, 当种群数量为 70 时, 每次迭代时间约为 1.3 秒钟, 算法平均收敛时间约为半分钟, 测试主机 CPU 为 Intel Core i7-8700@ 3.20GHz。
