20%, 默认平行路径填充角度（包括工件内部和支撑部分）为 0 度, 默认 sptOn 为 False, 即不生成支撑, 默认危险面片临界角为 60 度等。

在 PrintParams 类中, 对 startCode 和 endCode 两个属性, 这里我们并未真正对它们进行赋值(G 代码中, 英文分号表示注释), 对这两个属性的赋值需要参考具体使用的打印机说明书。同理, 对 nozzleSize 和 filamentSize 两个属性, 尽管在这里我们给出了它们的常规取值, 但在具体使用时也要结合实际使用的喷头和丝材等情况。

最后, 需要强调的是, 在表 11.1 或 PrintParams 类中, 我们给出的三维打印工艺参数仅仅是目前模型切片, 端面识别, 路径生成, 支撑生成等过程所需要的部分参数。现有的这些工艺参数当然可以被进一步拆分, 就像我们之前将路径间距 (sflnvl) 拆分成喷头尺寸 (nozzleSize) 和填充率 (sFRate) 一样, 或者将打印速度 (g1Speed) 拆分为外壳打印速度、内部填充速度、支撑打印速度等, 拆分的目的是对三维打印路径生成过程进行更精确的控制。此外, 根据实际需求, 我们还可以添加新的工艺参数, 如对模型进行轻量化抽壳操作所需的壁厚参数、对切片轮廓进行简化(减少轮廓顶点数)所需的误差参数等。

# 11.2.2 切片路径生成

在上一小节, 我们对三维打印路径规划所需的工艺参数进行了汇总, 得到了一个打印工艺参数类 PrintParams。在此基础上, 在这一小节, 我们将对包括模型切片, 端面识别, 路径生成, 支撑生成等过程涉及的函数进行组织, 封装一个用于三维打印路径生成的综合函数 genAllPaths, 该函数核心步骤如下：

+   (1) 对三维模型进行切片(slice_topo 或 slice_combine);
+   (2) 识别端面切片, 并对切片轮廓进行疏密分区(idEndLayers);
+   (3) 对各切片生成轮廓填充路径(genCpPath);
+   (4) 对各切片生成密实填充路径(genDpPath);
+   (5) 对各切片生成稀疏填充路径(genDpPath);
+   (6) 如有必要, 生成支撑路径(genSptPath)。
