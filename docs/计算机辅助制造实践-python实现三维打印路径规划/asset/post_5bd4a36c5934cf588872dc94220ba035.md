## 第 5 章 STL 模型截交计算优化

### 引言

在上一章中，我们将主要精力放在对 STL 模型切片流程的详细介绍上，输出了包含一系列封闭轮廓的切片数据。针对一些关键步骤，如 STL 模型截交和截交线段拼接，均使用了暴力算法。暴力算法虽然直观、简单，易于实现且具有良好的稳定性，但算法执行效率低。当模型包含极少面片或切片层数不多时，暴力截交法勉强能够胜任；但当模型包含数万、数十万甚至上百万个面片时，暴力法耗费的时间将呈平方量级增长，这在实践中往往是难以忍受的。在本章中，我们将针对 STL 模型截交这一问题进行深入研究，设计两种优化算法，力求降低截交运算量。

### 5.1 暴力截交存在的问题

STL 模型截交的本质就是用一系列层高已知的平行平面和 STL 模型求交，计算并保存得到的截交线段以备后续使用。在使用暴力截交算法时，对每张截平面，我们会遍历整个 STL 模型中的所有三角面片，调用我们之前在 GeomAlgo 模块中已经实现了的平面和三角面片的基础求交函数（intersectTriangleZPlane）计算截交线段。如果 STL 模型中有 100 万个三角面片，那么一张截平面一次截交就要调用 100 万次求交函数。为了加深读者的直观感受，我们用之前写的 Python 代码进行了实际测试，测试用主机 CPU 型号为 Intel Core i7-8700 @ 3.20GHz，内存大小为 24GB。对于一个拥有约 45000 个三角面片的 STL 模型，在切片厚度为 0.1 毫米，切片层数为 2202 层的情况下，使用暴力法消耗的截交运算总时间约为 107 秒钟。在三维打印中，拥有 4 万多面片的 STL 模型不算大，而对于面片规模更大的模型，使用暴力法无疑将消耗更多的时间。

然而，在使用暴力法截交的过程中，大部分求交计算可能都是无用的。对于某一指定高度的截平面，它和模型中多数三角面片的相对位置决定了它们之间根本就不可能相交，如图 5.1 所示，最低一排和最高一排的三角面片就不可能和截平面相交。虽然我们在以上提到的基础求交函数中做了一些非常重要的预处理，即如果截平面高于三角面片最高点或低于三角面片最低点，则直接返回 None，事实也的确证明这些预处理能够降低不少求交计算量（如果注释 intersectTriangleZPlane 函数中的预处理代码，测试环境和对象与上述相同，截交运算时间约为 1444 秒钟，即约 24 分钟），但仍然不能规避每张截平面和模型中所有面片遍历求交的弊病。

综上所述，考虑到我们实现的平面和三角面片的求交函数已经非常基础，很难对其做出进一步优化，因此，平面和 STL 模型截交优化的方向应是尽量减少平面和三角面片不必要的求交次数。

下面我们将介绍两种算法，一种是扫描平面法，另一种是层高匹配法，用于减少求交次数，提升 STL 模型的截交效率。

### 5.2 扫描平面法截交优化

如图 5.1 所示，对一张高度从低到高连续抬升的载平面和一个 STL 模型中的所有三角面片，如果我们能够事先预知哪些面片处在载平面附近（可能相交），哪些面片离载平面较远（不可能相交），那么我们就可以将载平面附近的面片筛选出来，并在当前层上，仅计算载平面和这些附近面片的交线，从而实现减少求交次数的目标。这看起来似乎又回到了求交函数 intersectTriangleZPlane 中的预处理筛选过程，但其实这是两个层面的事情，这里所说的减少求交次数是在求交函数之外减少求交次数。那么问题是如何预知哪些面片位于载平面附近呢？这一节我们将使用扫描平面（sweep plane）法快速获取载平面附近的三角面片。

#### 5.2.1 扫描平面数据结构

在介绍算法之前，我们不妨先来了解扫描平面的概念。扫描平面和载平面一样，也是平行于坐标系 XY 平面的平面，其高度（z 值）可按需要沿坐标系 Z 轴从低到高（或从高到低）连续变化，扫描截交 STL 模型。扫描平面的一个重要特性是它维护了一个与其相交的三角面片列表，即模型中所有最高点高于（或等于）且最低点低于（或等于）扫描平面的三角面片将被存入这个列表。当扫描平面在 Z 轴上移动时，其三角面片列表中的面片将动态增减。在建立了扫描平面的概念后，STL 模型截交问题可以转化为扫描平面和其自身三角面片列表中保存的面片求交的问题，这样就可以避免遍历 STL 模型中的所有面片。

#### 5.2.2 扫描平面法原理

现在我们已经有了表示扫描平面的数据类型 SweepPlane，在扫描平面从模型最低点往上向模型最高点连续扫描过程中，扫描平面中的三角面片列表 triangles 将不断更新：老的面片可能被不断移除，新的面片又可能被不停地添加进来。

判断扫描平面的 triangles 中哪些面片需要被移除的问题相对简单。因为 triangles 中维护的面片数量相对整个 STL 模型拥有的面片数量来说较少，因此每次只需遍历 triangles 中的所有面片，如果某个面片的最低点高于或最高点低于扫描平面高度，那么就需要将该面片从 triangles 中移除，如图 5.2 所示。

![](img/c3ab49ac4eb80e7a0a66462a29869ca2_95_0.png)

图 5.2 从扫描平面的面片列表 triangles 中移除面片示意

那当扫描平面在移动过程中，又该如何判断模型中的哪些三角面片该被添加进 triangles 中呢？如果采用暴力算法，只需遍历模型中的所有面片，判断哪些面片同时满足最高点高于（或等于）扫描平面高度且最低点低于（或等于）扫描平面高度，那么就将该面片添加进 triangles。如果进行如此操作，那么基于扫描平面的截交算法相对于之前介绍的暴力截交法将不会有任何运算效率的提升。

试想：如果 STL 模型中的三角面片不是杂乱无序的，而是按照从低到高的顺序排序的，那么当扫描平面在向上扫描时，向 triangles 中添加新面片的过程是否可减少一些遍历的运算量？进一步地，如图 5.3 所示，如果模型中的每个三角面片是按照最低点的 z 坐标从小到大排序的，那么当扫描平面上移时，我们只需按模型中的面片序号从小到大依次遍历判断：如果当前序号对应的三角面片最高点高于（或等于）扫描平面高度且最低点低于（或等于）扫描平面高度，那么就将该面片添加至扫描平面的 triangles 中；一旦出现当前序号对应的面片的最低点高于扫描平面高度，则记录该面片序号（不妨记为 k，图 5.3 中为面片 9）并立即停止遍历流程。此时我们可以求取并保存扫描平面和 triangles 中每个三角面片的截交线段。然后扫描平面继续向上平移，重复上述步骤，遍历模型中三角面片的起始序号改为上次记录的序号 k。

根据以上分析，只要 STL 模型中的每个三角面片是按照其最低点从低到高排序的，那么在将这些面片添加进扫描平面的 triangles 中时就可以节省大量不必要的遍历过程。简而言之，如果 STL 模型中某个序号的三角面片在扫描平面以上（即该面片最低点高于扫描平面），那么所有大于这个序号的面片必然都在扫描平面以上。

#### 5.2.3 三角面片排序

接下来的问题就是针对 STL 模型中三角面片的排序问题。这其实可以抽象为非常一般的升序排序算法，即对一组散乱的实数，按从小到大的顺序进行排序。排序问题是计算机算法领域最为经典的问题之一，解决排序问题有众多算法，如常见的冒泡排序（bubble sort）、插入排序（insertion sort）、归并排序（merge sort）、快速排序（quick sort）等，目前较快的排序算法可以做到 O(nlog(n)) 乃至 O(n) 的时间复杂度，其中 n 为待排序的元素个数。但考虑到算法稳定性和执行效率，我们不建议直接使用自己的排序算法，几乎在任何编程语言的标准库里，都内置了排序算法，如 C 语言中的 qsort、C++ std 库中的 sort、C#以及 java 中的 sort，Python 也不例外，它也有内置的 sort 函数，可直接对列表对象进行排序。在 Python 中，也许我们想直接对 triangles 调用 sort 函数，即 triangles.sort()。但这样显然是不对的，因为 triangles 列表存储三角形对象，而我们自始至终并未给三角形类（参见 Triangle 类）定义任何比较的概念，试想：两个三角形该如何比较大小？在 C、C++、C#等语言中，碰到这种情况时我们一般会为待比较的对象定义一个比较回调函数，作为参数输入 sort 函数中。在 Python 中，我们不必这么做，我们只要针对 sort 的 key 参数指定比较指标即可，因此正确的排序写法是：

```python
triangles.sort( key = lambda t : t.zMinPnt( ).z, reverse = False )
```

在以上代码中，我们采用了 Python 的 lambda 表达式（即函数式表达式），首先使用 zMinPnt 函数来获取三角形对象的最低点（参见 Triangle 类），然后再从该最低点获取 z 坐标作为比较指标。默认情况下，Python 的 sort 以升序排序，即 reverse 参数默认值为 False；如果我们需要按降序排序，只需指定 reverse 参数值为 True 即可。尽管相对于 C、C++、C# 等语言，Python 天生不足，存在执行效率不高的问题，但就算法本身而言，其内置 sort 算法的时间复杂度不会超过 O( nlogn )，而且是稳定可靠、上手可用的。

至此，针对 STL 中三角面片列表的排序问题也已解决。在上一小节，我们还分析了扫描平面法能够快速收集三角面片乃至快速截交 STL 模型的基本原理。下一步就可以在此基础上勾勒出基于扫描平面法截交优化的算法流程。

#### 5.2.4 算法流程及实现

我们先来看一下基于扫描平面法的 STL 模型截交流程，如图 5.4 所示。该流程输入为 STL 模型和切片厚度两个参数，输出为一系列截交线段。其中这些截交线段将以层的形式组织，存储在 Layer 对象的列表中。按照之前的讨论，在算法流程中，我们首先需要对 STL 模型中的三角面片进行排序，然后根据模型最低点和最高点确定切片层高列表 zs，之后进入循环，遍历 zs 中各层高，对扫描平面进行平移。对循环中的每一步，我们首先需要遍历移除扫描平面三角面片列表中已经和扫描平面不再相交的面片；然后再依次遍历 STL 模型中已排序的三角面片，并将符合要求的面片添加至扫描平面面片列表；在当前循环最后，遍历计算扫描平面面片列表中的面片和扫描平面的截交线段，并将这些截交线段保存到 Layer 对象的 segments 属性中。循环的结束条件为层高列表 zs 中所有层高被遍历。
