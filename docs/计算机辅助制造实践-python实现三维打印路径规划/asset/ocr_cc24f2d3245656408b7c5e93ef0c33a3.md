为 \(a_x\)。同理, 在 Y 方向上, 通过分析节点 A、C 上的支撑点影响范围, 我们可以认定矩形的高度尺寸为 \(a_y\)。根据以上假设及分析, 我们知道, 一个支撑点的影响范围为一中心在该点的轴平行矩形, 且矩形的在 X、Y 方向上的边长分别为 \(a_x, a_y\)。

下面我们解释为什么将支撑点的影响范围设定为矩形。首先, 这是一种偏安全的设定。我们知道, 对三维模型支撑生成来说, 如果在需要添加支撑的地方没有添加支撑可能导致打印过程中模型坍塌, 但如果在某些不需要添加支撑的地方添加了冗余支撑, 则并不会对打印过程带来不良影响。因此, 对支撑点的影响范围设定来说, 即便矩形内某些新支撑点对应的三角面片是安全面片, 我们也能接受这样的结果。其次, 矩形设定更易于相邻区域融合。如图 10.15 所示, 不失一般性, 其实我们也可以将支撑点的影响范围设定为圆形。但是, 在对相邻支撑点的影响范围进行融合时, 我们发现, 两个圆形之间容易留下缝隙, 为了覆盖这些间隙, 我们不得不将圆的直径设置得很大, 但这样会带来更多不必要的冗余支撑。而如果使用矩形设定, 我们能够以较小的尺寸实现相邻支撑点影响范围的无缝融合。
