```
9 newPolys = []
10 for poly in polygons:         # 遍历，对每个多边形变换
11     newPolys.append(poly.multiplied(m))
12 return newPolys              # 返回变换后矩阵序列
```

在 rotatePolygons 函数的实现代码中，如果旋转中心 center 为 None，则默认旋转中心为坐标原点。在函数中，首先我们构造了一个平移矩阵 mt，用于将多边形（及其旋转中心）平移至原点；然后我们构造了一个旋转矩阵 mr，用于将多边形旋转指定角度；最后我们又构造了一个平移矩阵 mb，用于将多边形（及其旋转中心）平移回原来位置。之所以要对多边形进行两次平移，是因为旋转矩阵 mr 的旋转中心只能是原点。
