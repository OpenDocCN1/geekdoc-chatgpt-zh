## 1.5 Python 语法简介

### 1.5.1 数据类型

Python 内置了 5 种标准数据类型，分别为：Numbers（数字）、String（字符串）、List（列表）、Tuple（元组）、Dictionary（字典）。其中，Numbers 又分为四种类型，分别为 int（有符号整型）、long（长整型）、float（浮点型）、complex（复数）。

Python 是弱类型语言，变量不需要声明类型，其类型由其赋值的类型决定；变量名首字符必须为字母或下划线_，建议使用小写英文字母开头。下面给出了几个 Python 变量赋值实例：

| | 变量赋值操作 | 1-1 |
|---|---|---|
| 1 | counter = 100 | # 整型变量 |
| 2 | miles = 1000.0 | # 浮点型变量 |
| 3 | city= "Hangzhou" | # 字符串变量,双引号和单引号可以通用 |
| 4 | flag = True | # 布尔型变量,值为 True 或 False |
| 5 | a = b = c = 1 | # 为多个变量赋同一值 |
| 6 | name, age, sex ='张三', 23,'男' | # 为多个变量赋不同(类型)值 |

| 8 | classes = ('English ', 'math ', ' physics ') | # 定义元组变量,并为其赋值 |

### 1.5.3 流程控制

计算机程序在解决某个具体问题时，通常包含三种情形，即顺序执行所有语句、选择执行部分语句和循环执行部分语句。

这三种情形正好对应程序设计中的三种结构流程：顺序结构、选择结构和循环结构。因顺序结构较为简单，这里主要介绍 Python 语言中的选择结构和循环结构。

我们先来看一下选择结构。Python 中的选择结构使用 if、elif、else 三个关键字引导。如果程序只有两个分支，使用 if、else 即可；如果程序包含两个以上分支，需要使用 elif。程序示例如下：

```
score = int(input( " 请输入您的总分：") )      # 输入分数
if score >= 95:                 # if 条件输入后必须输入冒号
    print('优')
elif score >= 85:
    print('良')
elif score >= 70:
    print('中')
elif score >= 60:
    print('合格')
else:
    print('不及格')
```

需要注意的是，在使用包含多个 elif 语句的分支结构时，应理清各个条件语句之间的逻辑关系。只要有一个条件成立，程序就会执行其后的语句，执行完后程序将退出整个 if 语句，而不会继续执行其他 elif 或 else 语句。

在判断非此即彼的条件时，我们可能会觉得使用常规的 if else 结构写的代码太过冗长（至少包含 4 行代码），此时我们可以使用 Python 语言的三目运算符，使用一行代码就可实现二选一功能，形如：

```
x if b else y
# Python 中的三目运算
```

即当 b 为 True 时，返回 x；b 为 False 时，返回 y。熟悉 C++、C#、Java 等语言的读者可能知道，在这些编程语言中，三目运算符是通过问号和冒号来实现的，形如：

```
b ? x : y
# C++、C#、Java 等语言中的三目运算
```

接下来我们再来看一下循环结构。其实在本章 1.2 节中，我们已经初步介绍过循环结构，并使用循环结构编写了 1 到 100 整数累加求和程序。在 Python 中，循环结构使用 for 或 while 关键字引导，其中 for 循环一般用来引导循环次数已知的程序代码，while 循环一般用来引导循环结束条件已知的程序代码。循环程序示例如下：

| | 循环结构，for 语句和 while 语句 | 1-5 |
|---|---|---|
| 1 | # 寻找 100 以内质数并打印 | |
| 2 | for number in range(1, 101): | # for 经常和 range 函数一起使用，range 生成遍历范围 |
| 3 | isPrime = True | |
| 4 | for i in range(2, number): | |
| 5 | if number % i == 0: | # 如果余数为 0，则 i 为 number 的因数，number 为合数 |
| 6 | j = number / i | # 算出 number 的另一个因数 |
| 7 | print( "%d = %d * %d" % (number, i, j) ) | # 打印合数 |
| 8 | isPrime= False | |
| 9 | break | # 退出当前层 for 循环 |
| 10 | if isPrime: | |
| 11 | print( "%d 是一个质数" % num ) | # 如果 number 没有一个因数，则为质数 |
| 12 | # 循环结构，while 语句，寻找 100 以内 5 的倍数并打印 | |
| 13 | val = 0 | # 初始化 val 值为 0 |
| 14 | while ( val <= 100 ): | # 循环结束条件为 val <= 100 |
| 15 | val = val + 1 | |
| 16 | if val % 5 == 0: | |
| 17 | print( val ) | |
| 18 | else: | |
| 19 | continue | # 如果不满足条件则继续循环 |

以上示例程序中，range(1, 101) 函数表示生成 1 到 100，步长为 1 的列表；如果需要生成步长为 2 的列表，只需输入 range 函数的第三个参数即可，如 range(1, 101, 2)。在 Python 中，range 函数经常和 for 一起使用，生成循环范围。

在循环结构中，经常用到 break 或 continue 控制循环流程，其中 break 表示退出当前层循环，continue 则为继续循环，循环体中 continue 后面的语句不再执行。

### 1.5.4 函数

在程序中使用函数能提高代码的模块化程度和重复利用率。Python 提供了很多内建函数，如之前用到过的 input 和 print 函数。

对一般编程语言，创建一个函数需要定义函数返回类型、函数名、参数（包括参数个数、参数类型、参数名）以及函数体。因为 Python 是弱类型语言，在定义函数过程中，不需要定义函数返回类型以及参数类型。

下面结合具体实例讲解 Python 函数定义和调用。

| | 函数定义和调用 | 1-6 |
|---|---|---|
| 1 | # 定义两个求和和函数 | |
| 2 | def add(a, b): | # def 不可或缺，为函数定义关键字；add 为函数名，a,b 为参数 |
| 3 | sum = a + b | # 函数体，对参数 a 和 b 求和，sum 保存结果 |
| 4 | return sum | # 返回运算结果 |
| 5 | # 函数调用，两数求和 | |
| 6 | x = 1 | |
| 7 | y = 2 | |
| 8 | z = add(x, y) | |
| 9 | print(z) | # 输出 3 |
| 10 | # 该函数同样适用于字符串拼接 | |
| 11 | u = 'I am ' | |
| 12 | v = 'a student.' | |
| 13 | w = add(u, v) | |
| 14 | print(w) | # 输出“I am a student.” |

Python 函数定义使用 def 关键字引导，意为 define。def 后跟函数名，和变量命名一样，函数名不能以数字开头，建议首字符用小写英文字母。函数名后面跟圆括号，括号内为函数参数，参数不需要指定类型，个数根据需要定义（零个或多个），参数名同样遵循变量命名规范。函数体需要缩进，为函数实现功能的语句，能真正体现业务本身和编程人员逻辑思维。

如果函数的运算结果需要输出，则使用 return 关键字返回。

由于以上编写的 add 函数参数 a, b 类型不定，既可以输入整数，也可以输入浮点数，甚至可以输入字符串，而返回的结果总是我们想要的，这正是 Python 的魅力之一！这有点像 C++ 编程语言中模板函数的概念，但更容易理解。

Python 定义函数时，可对部分或全部参数赋默认值，如对以上 add 函数，可将 b 赋默认值 7，如下所示：

| 序号 | 内容 | 注释 |
|---|---|---|
| 1 | def add( a , b = 7 ): | # 参数 b 使用默认值 |
| 2 | sum = a + b | |
| 3 | return sum | |
| 4 | # 含有默认参数的函数调用 | |
| 5 | print(add(5)) | # 输出结果 12,a 使用输入值,b 使用默认值 |
| 6 | print(add(4, 5)) | # 输出 9 , a , b 均使用输入值 |
| 7 | print(add( a = 1, b = 2 )) | # 输出 3 , a , b 均使用输入值，在函数参数中写明参数名 |

如果某些参数在大部分场合的值是固定不变的，那么在定义函数时就可以对这个参数使用默认值，这样可以减少函数调用时的参数输入量，特别是对某些复杂函数，还可降低对函数及参数取值的记忆量。

以上我们演示的函数均包含一个返回值，Python 函数可以一次返回多个值，这也是 Python 区别其他编程语言(如 C++、C#、Java 等)的特性之一。示例如下：

| 序号 | 内容 | 注释 |
|---|---|---|
| 1 | def hybrid( a, b ): | # 定义四则运算函数，返回输入参数加、减、乘、除 4 个结果 |
| 2 | return a + b, a - b, a * b, a / b | |
| 3 | # 函数调用 | |
| 4 | x, y, z, w = hybrid(8, 2) | # 结果:x = 10 , y = 6 , z = 16 , w = 4.0 |
| 5 | print( hybrid( 10, 5 )) | # 输出：(15, 5, 50, 2.0) |

### 1.5.5 类

Python 是一门面向对象的编程语言，面向对象语言最重要特征是可以定义义类( class )，并在类中封装一系列属性和方法( 函数 )。在 Python 中定义类需要使用 class 关键字引导，class 后跟类名，类名首字符建议使用大写英文字母，类名后跟冒号。下面我们以 People 类为例，看看在类中如何绑定属性。

| 序号 | 内容 | 注释 |
|---|---|---|
| 1 | class People: | |
| 2 | pass | # pass 为 Python 中占位语句，不做任何事情 |
| 3 | # 类的使用 | |
| 4 | p = People() | # 定义一个 People 对象 p , 类名后跟圆括号 |
| 5 | p.name = ' Jim ' | # 给对象绑定 name 属性，并赋值 ' Jim ' |
| 6 | p.age = 11 | # 给对象绑定 age 属性，并赋值 11 |
| 7 | print(p.name, p.age) | # 输出：Jim 11 |

上例中，p 为 People 类的一个具体实例对象，我们可以对 p 自由地绑定属性，这些属性完全不需要在 People 类创建时定义。虽然 Python 支持这种类属性后期自由绑定的特性，
