我们重点分析一下 gridDic 变量，这个变量非常重要。由定义可知，gridDic 为字典型数据，如图 10.8 所示，它的键为网格节点坐标（元组），它的值较为复杂，为一列表变量，列表元素为过当前网格节点的竖直直线和 STL 模型的交点信息（元组），包括交点的 z 坐标值以及对应面片相对于水平面倾角（单位为度）。必须指出的是，我们为上述每个列表都预存了一个值为 (zMin, 0) 的元组元素，这个元素对应图 10.6 中竖直截交直线和模型底面的交点（即序号为 0 的交点），元组中 0 度的倾角表明底面是一个危险面片，设置这个元素的目的单纯是为了保证后续截取支撑线段时的逻辑正确性。我们发现，gridDic 不仅可以表示平面网格信息，还可以表示网格节点上的交点信息，这在后面计算中将十分有用。

## 10.2.2 模型支撑点计算

我们得到了针对任意输入 STL 模型的平面投影网格，如图 10.6 所示。接下来我们要在各个网格节点处布置沿竖直方向的直线，依次计算这些直线和模型的交点，并将交点信息存入如图 10.8 所示的字典结构中，方便后续提取、识别支撑线段。在这一过程中，我们需要解决的核心问题是计算竖线序列和 STL 模型的交点，即计算竖线序列和三角面片序列的交点。

首先,我们需要解决单条竖线和三角面片求交问题。这是一个简单的几何问题。在前面工作的基础上,我们可以借助一些现成的模块或函数来解决这个问题。在本书第 2 章中,我们已经实现了直线和平面的求交算法（参见 GeomAlgo 模块中的 intersect 函数）。显然,竖线和三角面片的求交问题是直线和平面求交问题的子问题,因此,理论上,我们只需在现有 intersect 函数的基础上附加一些限制条件,就能解决竖线和三角面片的求交问题。比如我们可以将竖线作为普通直线、三角面片作为普通平面代入 intersect 函数计算交点,然后判断该交点是否在三角面片内,如果交点在面片内,则竖线和面片相交,此时返回交点,否则竖线和面片不相交。但其实我们也可以反过来思考这个问题,即首先对线面判交,然后再计算交点。要判断空间中任意一条直线和一个三角面片是否相交其实不太容易,但如果这条直线是沿竖直方向的直线,那么它们之间的判交就变得相对简单。在这种情况下,我们只需在 XY 平面上检查竖线投影点是否落在三角面片的投影内即可。如图 10.9 所示,考虑到这里的竖直线是过网格节点的竖直线,因此我们只需判断网格节点是否落在三角面片的投影内。

若记其中一个网格节点为 P,对应坐标为 (x, y),空间三角形三个顶点在水平面投影分别为 A、B、C,对应坐标分别为 (xa, ya)、(xb, yb)、(xc, yc),要判断点 P 是否落在三角形 ABC 内,我们当然可以应用 GeomAlgo 模块中的 PointInPolygon 函数,但这样做相对比较繁琐。这里我们尝试用一种较为简单的办法来判断任意点 P 和三角形 ABC 的包含关系。如图 10.10 所示,我们发现:当点 P 在三角形 ABC 内部或边上时,小三角形 PAB、PBC、PAC 的面积之和恰好等于三角形 ABC 面积;而当点 P 在三角形 ABC 外部时,三个小三角形的面积之和必然大于三角形 ABC 面积。根据以上原理,我们只需分别计算各三角形面积即可。而对任意平面三角形, 在其顶点坐标已知的情况下, 我们可以参照公式(2-15)使用解析法快速计算其面积。下面我们首先给出平面上点和三角形包含关系的判断代码:

```
FindSptRegion.py | 寻找支撑区域类:在平面上判断一个点是否在三角形投影内 | 10 - 2
...... # 导入相关库
class FindSptRegion:
...... # 忽略类中其他代码
def pointInTriangle(self, pt, tri, err = 1.0e-7): # 报告点是否在三角形投影内部
    A, B, C = tri.A, tri.B, tri.C
    S = self.area(A, B, C) # 大三角形面积
    S1 = self.area(pt, A, B) # 小三角形面积
    S2 = self.area(pt, B, C)
    S3 = self.area(pt, A, C)
    if math.fabs(S1 + S2 + S3 - S) < err: # 判断面积是否相等
        return True # 如果相等,则返回 True
    return False # 否则返回 False
def area(self, A, B, C): # 计算由三点确定的三角形面积
    x1, x2, x3, y1, y2, y3 = A.x, B.x, C.x, A.y, B.y, C.y
    return 0.5 * math.fabs(x1 * y2 + x2 * y3 + x3 * x1 - x1 * y3 - x2 * y1 - x3 * y2)
```

以上我们在 FindSptRegion 类中添加了两个函数，pointInTriangle 和 area，顾名思义，前者的作用是在平面上检测一个点是否落在三角形内，后者是前者的依赖函数，用于计算由给定三个顶点围成的三角形面积。我们主要来看一下 pointInTriangle 函数，它有 3 个参数，其中 pt 和 tri 分别为待检测点和三角形，第三个参数 err 为检测误差，这里我们给它设置的默认值为 1.0×10^-7，必须强调的是，这个参数对函数成败至关重要。在以上代码中，我们将 err 参数用在大三角形面积(S)与小三角形面积和(S1 + S2 + S3)的比较上，由于面积计算中数值误差的存在，两者实际上很难恰好相等(即便点在三角形内部时)。有兴趣的读者不妨尝试将 err 值设置为 0，看函数是否还能返回正确结果。进一步地，有兴趣的读者还可分析误差 err 对整个模型支撑点计算的影响(实际上，我们会发现，当 err 不为 0 时，计算结果是偏安全的)。

我们回到竖线和三角面片的求交问题。根据以上讨论，现在我们可以对指定竖线和三角面片进行判交。如果竖线和面片相交，则进一步调用上述 GeomAlgo 模块中的 intersect 函数求取它们的交点；如果不相交，则返回空。在处理竖线和面片的求交问题时，我们推荐使用上述方法，即先判交、再求交，而不是直接求交，通过以下介绍我们会发现，我们是有意这样设计的，目的是减少求交计算量。

现在我们已经解决了单条竖线和单个面片的求交问题，接下来我们要解决的是过网格节点的竖线序列和 STL 模型中的三角面片序列的求交问题，我们需要找出竖线和面片两序列之间的所有交点。显然，如果不计时间成本，这个问题非常简单，我们可以采用暴力方法进行两两遍历求交，其时间复杂度为 O(m · n)，其中 m 为平面网格节点数，n 为 STL 模型中的三角面片个数。在本书中，我们尽可能避免使用暴力法去解决碰到的问题，这里我们可以结合问题本身特点，对求交算法进行优化。

在解决竖线序列和面片序列的求交问题时，一般先以人为主的思路是将竖线作为主体去和面片序列求交，但这种思路很难发挥竖线的网格特性，算法优化空间不大。如果我们换个角度思考，将三角面片作为主体去和竖线序列求交，那情况可能会有不同。下面我们就尝试遵循这种思路对网格竖线和面片序列的求交算法进行优化。

根据以上思路，首先，我们得从面片序列中任意取出一个三角面片(记为 W)；对该三角形，我们可以遍历平面网格，并根据以上介绍的面积比较法找出所有落在三角形 W 投影内的节点；然后我们就可以根据这些节点构造竖线，最后求出所有和三角形 W 相关的交点。理论上，只要遍历整个面片序列，就能求出所有交点。我们发现，使用这种方法，针对一个三角形，先通过判交筛选出有效网格节点，然后仅对有效节点上的竖线求交，可以减少不少求交次数，提高求交效率，我们将求交范围限定在了当前三角面片的投影范围内，具体求交次数和网格密度以及面片投影面积大小有关。

通过上述方法，尽管我们能够切实降低求交次数，但却无法减少判交次数，需要判交的总次数仍为 m · n。事实上，我们可以对上述方法进一步优化，充分发挥网格特性，减少判交次数。如图 10.11 所示，平面三角形 ABC 为空间三角面片 W 在网格平面上的投影，如果我们能够事先快速筛选出落在三角形 ABC 内的网格节点，那么我们就能减少上述判交次数。但这又回到了如何判断一个点是否落在三角形内部的问题，我们应该避开这个问题，使用更为轻便的方法去做节点筛选。如图 10.11 所示，矩形 DEFG 为三角形 ABC 的轴平行包络矩形,我们可以通过简单的坐标比较从所有网格节点中筛选出落在矩形 DEFG 内的潜在节点,然后再从这些潜在节点中使用上述判交方法筛选出落在三角形 ABC 内的有效节点,这样就可以减少判交次数。

在解决了线面序列的求交问题之后，那如何保存得到的交点呢？我们知道，initGrids 函数除了返回 xs 和 ys 序列之外，还返回了一个字典对象（记为 gridDic），该字典键为网格节点坐标，值为该节点上方保存交点信息（高度、角度）的序列，如图 10.8 所示。我们在上一小节曾提到，gridDic 非常重要，事实上，这里我们会把得到的所有交点都保存到 gridDic 中。如图 10.8 所示，我们首先根据交点的 x、y 坐标在 gridDic 中检索得到相应交点信息序列，再将交点以元组 (z, a) 的形式存入以上序列中，其中 z 为交点 z 坐标，a 为对应面片倾角。因此，在以上竖线和三角面片的交点计算过程中，我们有必要记录面片倾角信息。

以上我们介绍了竖线序列和面片序列的快速求交方法，它的时间复杂度接近 O(n)，其中 n 为 STL 模型中面片个数，相较于暴力法，该方法能大幅提高线面序列求交效率，这主要得益于我们对竖线及网格特性的巧妙应用。同时，我们也实现了 pointInTriangle、getValidGrids 等关键子函数。最后我们给出针对给定 STL 模型的支撑点计算函数 calcModelSptPoints，它的具体实现代码如下：

```
# 导入相关库
class FindSptRegion:
    # 忽略类中其他代码
    def calcModelSptPoints(self):
        # 定义计算模型支撑点函数
        xs, ys, gridDic = self.initGrids()  # 初始化网格，返回网格字典
        for tri in self.stlModel.triangles:  # 遍历 STL 模型中每个三角面片
            validGrids = self.getValidGrids(tri, xs, ys)  # 获取当前面片有效网格节点
            for vg in validGrids:  # 遍历每个有效节点
                ln = Line(Point3D(vg[0], vg[1]), Vector3D(0, 0, 1))  # 构造过节点竖线
                pln = Plane(tri.A, tri.N)  # 构造三角面片所在平面
                pt = intersect(ln, pln)  # 线面求交，获得交点 pt
                if pt is not None:  # 如果 pt 不为空
                    z = round(pt.z, self.digit)  # 获取交点 z 坐标
                    a = self.getFacetAngle(tri)  # 获取面片倾角 a
                    gridDic[vg].append((z, a))  # 构造 (z, a)，并将其添加至字典
```
