# # 第 2 章 基础计算几何库搭建

# ## 引言

在这一章,我们将尝试使用 Python 语言,在三维空间中,搭建一个属于我们自己的计算几何基础库。这个基础库将包含点、线、面、向量、矩阵等几何元素,以及点线距离、点面距离、直线求交、面片求交、点和多边形的包含关系判断等基础几何算法。首先我们介绍三维点、向量以及矩阵的定义。

# ### 2.1 点、向量、矩阵

根据我们以往的经验,在三维直角坐标系中,一个点的位置可由 x、y、z 三个笛卡尔坐标分量唯一确定,记作(x, y, z)。这种表示方法虽然简单直观,但无法将几何变换(平移、旋转、缩放)统一到矩阵乘法中。在本书中,我们将舍弃这种笛卡尔坐标表示法,采用齐次坐标表示点和向量。简而言之,齐次坐标就是用 N+1 维坐标来表示 N 维坐标。

# #### 2.1.1 点

对于空间中的一个点 P,如图 2.1,若其笛卡尔坐标为\((x_c, y_c, z_c)\),其齐次坐标为\((x, y, z, w)\),两者相互转换关系为:\(x_c = x/w, y_c = y/w, z_c = z/w\)。据此,一个笛卡尔坐标可以有无穷多种齐次坐标表示方法。例如,\((2, 3, 4)\)的齐次坐标可以是\((2, 3, 4, 1)\),也可以是\((4, 6, 8, 2)\)。对于齐次坐标\((x, y, z, w)\),当 \(w\) 不为 0 时,它总是对应一个唯一的笛卡尔坐标;但当 \(w\) 为 0 时,上述转换关系式将出现“零除”错误。为此,我们规定当齐次坐标中的最后一个维度 \(w\) 为 0 时,该点表示无穷远点。
