我们先来分析一下以上 FindSptRegion 类的初始化函数。它有 5 个输入参数，包括 stlModel、layers、gridSize、crAngDeg 以及 xyGap。其中参数 stlModel 就是需要生成支撑的 STL 模型；layers 为前续步骤中已经生成的各层切片轮廓数据（参考第 5~7 章）；gridSize 为网格预设边长，对应式（10-1）或（10-2）中的 a，这里属性 ax、ay 用于保存调整后的网格边长；crAngle 为面片支撑临界角，单位为弧度，这里“cr”为“critical”缩写，表示临界；xyGap 为支撑到模型的横向间距，避免打印中在 XY 平面内支撑材料和模型材料重叠，造成支撑难以去除，默认情况下，该值为 1 毫米。在这一小节实现的网格生成函数中，我们仅会用到 stlModel 和 gridSize 两个参数。FindSptRegion 类的核心流程控制函数为 execute，这里我们仅给出了该函数的声明，在接下来的几个小节中，我们将逐步补充 execute 的各个子函数。

下面我们再来看一下网格生成函数 initGrids，这个函数的实现比较简单。首先我们调用 StlModel 类的 getBounds 函数获取 STL 模型在 X、Y、Z 三个方向的极限值，然后根据参数 gridSize 以及式（10-1）、（10-2）分别计算圆整后的网格边长（这里是变量 ax 和 ay）。我们在函数中定义了几个关键临时变量，包括 xs、ys 以及 gridDic，其中 xs 和 ys 为实数列表，分别用来保存 X 和 Y 方向的网格坐标序列。

我们重点分析一下 gridDic 变量，这个变量非常重要。由定义可知，gridDic 为字典型数据，如图 10.8 所示，它的键为网格节点坐标（元组），它的值较为复杂，为一列表变量，列表元素为过当前网格节点的竖直直线和 STL 模型的交点信息（元组），包括交点的 z 坐标值以及对应面片相对对水平面倾角（单位为度）。必须指出的是，我们为上述每个列表都预存了一个值为 (zMin, 0) 的元组元素，这个元素对应图 10.6 中竖直截交直线和模型底面的交点（即序号为 0 的交点），元组中 0 度的倾角表明底面是一个危险面片，设置这个元素的目的单纯是为了保证后续截取支撑线段时的逻辑正确性。我们发现，gridDic 不仅可以表示平面网格信息，还可以表示网格节点上的交点信息，这在后面计算中将十分有用。
