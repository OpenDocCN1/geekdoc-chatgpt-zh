步地,我们假设这两条相邻曲线具有包含关系，即一条曲线在另一条曲线内部，如图 8.28 所示曲线 b1 和 b2，在这种情况下，我们又该如何连接这两条偏置曲线呢？显然，这个问题相比之下原问题要直观很多，我们只需要从两条曲线上找到距离最近的两点连接即可。假设 P1 和 P2 是曲线 b1 和 b2 上距离最近的两点，那么这两条曲线的连接方式如图 8.28 所示，连接之后得到的新曲线的起点为曲线 b1 的起点，它沿着 b1 走向到 P1 点后连至 P2 点，然后从 P2 点出发沿着曲线 b2 走向绕曲线一周回到 P2 点（具体是先到 b2 终点，再从 b2 起点出发沿着 b2 到 P2 点），随后再从 P2 点连接至 P1 点，沿着曲线 b1 走向到 b1 终点。根据以上连接方法，我们可以将两条相邻曲线连成一体，得到一条新曲线。
