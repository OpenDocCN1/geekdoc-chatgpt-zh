我们可以在三维空间中对得到的三栱柱进行拼接操作,但事实上更容易操作的方式是先对得到的危险三角面片进行拼接。考虑到 STL 模型中三角面片存储的无序性,我们可以仿照第 7 章介绍的方法,首先建立各个危险面片之间的拓扑索引关系,然后进一步组织并将所有存在相邻关系(共享公共边)的危险面片连成一片。在此基础上,对每组已经连接成片的危险面片,我们可以提取其边界,形成一条封闭的空间多边形(也可能是若干条存在包含关系的空间多边形),如图 10.3 中粗线。对得到的空间多边形,只要我们对其进行向下竖直投影,就能生成所求的支撑空间。

对得到的支撑空间区域,现在我们可以考虑在其内部生成支撑路径,首先是切片。如果我们将支撑空间看成一个实体模型(如图 10.1),那么,在对 STL 模型进行切片时,我们可以将支撑实体作为模型的一部分一并进行切片,生成模型切片轮廓和支撑切片轮廓。需要注意的是,由于切片同时进行,因此支撑切片每一层在 Z 向的高度和模型切片相应层在 Z 向的高度保持一致,这样,在每层切片打印过程中,我们可以让喷头保持相同的高度去打印模型材料和支撑材料。
