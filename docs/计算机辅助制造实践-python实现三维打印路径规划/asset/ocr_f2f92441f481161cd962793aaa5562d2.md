Clipper 库对两者进行布尔减操作,得到的差轮廓所包围的区域就是当前截平面上所求的支撑区域。

至此,我们已经给出了 FindSptRegion 类中涉及支撑生成相关算法的所有函数,接下来我们要做的就是合理地组织这些函数,即在 FindSptRegions 类的 execute 函数中控制这些函数的调用顺序。同样在以上代码中,我们给出了 execute 函数的实现代码。在前面工作的基础上,execute 函数的实现非常简洁。首先我们调用 calModelSptPoints 生成了模型支撑点,然后遍历类中保存的切片序列 layers;对每个切片( layer ),首先调用 calcLayerSptPoints 函数生成切片上的支撑点 pts,最后将 pts 和 layer 输入以上介绍的 genSptRegions 函数生成当前切片上的支撑轮廓。值得一提的是,在 execute 函数中,我们运用 Python 语言的优势动态为每个 layer 对象添加了一个 sptContours 属性,顾名思义,这个属性的作用是保存计算得到的切片支撑轮廓序列。另外需要强调的是,在调用 calcLayerSptPoints 函数生成切片支撑点时,我们为其指定的截平面高度(即函数的第二个参数)为当前 layer 的高度,这样做的目的当然是为了保证支撑轮廓在当前切片上。

在 FindSptRegion 模块的最后,我们给出了外部调用 FindSptRegion 类功能全局接口函数 findSptRegion。它的输入参数和 FindSptRegion 类的初始化函数完全一样,包括 stlModel (STL 模型),layers(切片数据),gridSize(网格尺寸),crAngle (危险面片临界角度),xyGap (支撑到模型的横向间距),输出为切片上的支撑轮廓。必须强调的是,findSptRegion 函数的输出数据保存在输入的 layers 参数中,因此,如果外部需要用到切片上的支撑轮廓数据,我们只需在调用 findSptRegion 函数后,从 layers 中获取每个切片的 sptContours 属性即可。
