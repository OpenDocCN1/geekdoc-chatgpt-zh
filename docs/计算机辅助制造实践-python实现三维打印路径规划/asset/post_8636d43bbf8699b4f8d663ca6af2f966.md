### 图 4.2 平面截 STL 模型获取封闭交线

在以上步骤中，STL 模型切片是至关重要的一步。这个问题可以描述为：用一张平面去截一个 STL 模型，计算该平面和模型之间的封闭交线。考虑到 STL 模型是由一系列离散的三角面片组成，因此计算平面和模型的交线首先需要计算平面和三角面片的交线(线段)，然后将这些交线段依次首尾相连成封闭交线即可。这一节的主要任务就是对给定坐标的空间三角形和平面，求取它们之间的交线。

如图 4.3 所示，我们不妨记空间中任意一三角形为 ABC，平面为α( P，N)，其中 P 为平面经过的一点，N 为平面法向量。△ABC 由 3 条边包围而成，分别为线段 AB、AC 和 BC。在第 2 章中，我们已经推导了空间线段和空间平面的求交计算方法，并在 GeomAlgo.py 中给出了 intersectSegmentPlane 函数，结合这个函数，首先我们可以分别计算线段 AB、BC、AC 和平面α的交点，然后从中选择合适的两点所连成的线段作为△ABC 和平面α的交线。如图 4.4 所示，线段 AB、BC、AC 和平面α之间可能存在 3 个，2 个或 0 个交点。需要说明的是，在 intersectSegmentPlane 函数中，如果线段和平面平行(或重合)，我们认为线段和平面不存在交点。

类似地，对于三角形和平面，如果它们平行(或重合)，则认为它们不相交；此外，如果三角形和平面交于三角形一个顶点，也认为它们不相交。在此基础上，我们再来讨论△ABC 和平面α的交点个数问题：

- (1) 如果交点个数为 3 个，那么其中必然有 2 个交点是三角形的同一顶点，这种情况下取 3 点中不重合的 2 个点作为交线两端点即可。
- (2) 如果交点个数为 2 个，则进一步判断这 2 个交点是否重合，如果不重合则取这 2 个点作为交线两端点，否则△ABC 和平面α无交线。
- (3) 如果交点个数为 0 个，则△ABC 和平面α无交线。

    BC = Segment( triangle.B, triangle.C )

    if c1 is None:
        if c2 is not None and c3 is not None:
            if c2.distance( c3 ) != 0.0:

    elif c2 is None:
        if c1 is not None and c3 is not None:
            if c1.distance( c3 ) != 0.0:

    elif c3 is None:

                return Segment(c1, c2)
        elif c1 is not None and c2 is not None and c3 is not None:

## 4.3 STL 模型截交计算

当我们用一组平行平面去截 STL 模型的时候，在每张平面上，我们都将得到一系列截交线段。为了保存这些线段，需要建立一种数据结构，且这种结构能区分不同平面上的截交线段，我们把这种数据结构叫作 Layer(层)。显然，Layer 应该包含当前层高属性(z)，以及用来保存截交线段的线段列表(segments)。我们把 Layer 写在 Layer.py 文件中，具体代码如下：

| Layer.py | 切片层，保存层高、截交线段、截交线等信息 | 4-5 |
|---|---|---|

```

    def __init__(self, z):
        self.z = z # 当前层高的值
        self.segments = [] # 截交线段列表
        self.contours = [] # 多边形轮廓列表(封闭截交线)
```

在 Layer 类中，我们除了定义层高和线段列表属性外，还定义了 contours 属性，这个属性用来保存由当前层线段拼接而成的封闭截交线。

有了 Layer 类和 intersectTriangleZPlane 函数，接下来就可以采用暴力法（brutal force）开始对 STL 模型进行截交计算了。首先我们需要构造一系列平行平面，这个问题可以转化为构造一系列层高值。为了降低运算量，并尽快得到可以验证我们想法的结果，我们先不考虑三维打印的具体场景，将切片厚度（layerThk，其中 Thk 为 Thickness 的缩写）值设置成一个较大值，如 10 毫米，然后看切片结果。层高的最小值应在 STL 模型最低点上方，最大值应在模型最高点下方，而模型极点值我们可以通过 StlModel 类的 getBounds 函数获取。在每一层高度上，我们对 STL 模型中的所有面片进行遍历求交，并将交线保存到 Layer 对象中。

根据以上分析，我们把 STL 模型暴力截交算法写在 SliceAlgo 模块的 intersectStl_brutal 函数中，具体代码如下，注意，SliceAlgo 模块将专门用来封装和切片相关的算法。

def intersectStl_brutal(stlModel, layerThk): # STL 模型截交函数
    layers = [] # 保存层对象列表
    xMin, xMax, yMin, yMax, zMin, zMax = stlModel.getBounds() # 模型极值
    z = zMin + layerThk
    while z < zMax: # 截交主循环
        layer = Layer(z)
        for tri in stlModel.triangles: # 对当前高度，遍历所有三角形
            seg = intersectTriangleZPlane(tri, z) # 计算三角形和平面交线
            if seg is not None:
                layer.segments.append(seg) # 将交线保存在 layer 中
        layers.append(layer)
        z += layerThk
    return layers # 返回层列表
if __name__ == '__main__': # 截交函数测试
    vtkAdaptor = VtkAdaptor()

## 4.4 截交线段拼接计算

如图 4.6 所示，对于在上一节中已经得到的某一层上的所有截交线段，如果我们把这些线段一一摆在平面上，它们无疑将组成若干个封闭的多边形（轮廓线）。然而，这些线段在多边形中是无序排放的，比如线段列表中的 1 号线段可能落在某个多边形上，而 2 号线段可能并没有和 1 号线段首尾相连，而是落在了另一个多边形上。

本节的任务就是将每层平面上那些无序排放的线段集整理拼接成若干有几何意义的封闭多边形。

### 图 4.6 截平面上无序排放的截交线段

还是和上一节一样，我们先设计一个暴力法来拼接这些截交线段。基本思路是：首先从线段列表中拿出一条线段作为当前线段，然后遍历列表中的剩余线段，找出一条和当前线段端点有重合的线段，并将这条线段拼接到当前线段上。

实现这个思路需要数据结构支撑，我们可以直接使用 Polyline 类保存拼接结果。根据以上思路将线段拼接成多边形的实现步骤如下：

- (1) 新建一条 Polyline 对象，记为 contour。
- (2) 从线段集中取出一条线段，并将该线段从线段集移除，然后将该线段的两端点分别添加到 contour。
- (3) 遍历线段集，将每条线段的两端点分别和 contour 的两端点比较，如果和 contour 终点重合，则将另一点添加到 contour 终点后；如果和 contour 起点重合，则将另一点添加到 contour 起点前。
- (4) 检查 contour 是否封闭，如果不封闭，则跳转至步骤(3)；否则保存 contour，并检查线段集中是否还有线段剩余，如果有剩余则跳转至步骤(1)，否则结束流程。

以上步骤将输出一系列封闭多边形，我们只要不停收集 contour，并将 contour 添加到当前层（参见 Layer 类）的轮廓线列表（contours）中即可。

需要强调的是，这里对两点重合判断用到的是 Point3D 中的 isCoincide 函数，判断原则是如果两点距离小于一个设定的极小值，则认为两点重合，而非两点坐标完全一致。这是因为计算得到的坐标值可能存在截断误差，即便理论上重合，实际上坐标也不可能完全一致，这一点需要引起注意。

函数 linkSegs_brutal 虽然总是能够返回正确的结果，但其时间复杂度为 O(n²)，呈 n 的平方量级，其中 n 为当前层上需要拼接的线段条数。显然，对于那些非常细致、包含上百万面片的 STL 模型，n 值可能极大，这个函数的执行时间也就可能很长。大自然的规律总是简单、美丽、和谐的！
