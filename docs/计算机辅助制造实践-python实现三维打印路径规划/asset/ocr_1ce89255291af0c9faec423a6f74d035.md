# 本 章 小 结

三维打印的常用填充路径包括轮廓路径和平行路径，这一章我们主要介绍的是轮廓路径的生成原理和方法。生成轮廓路径的基础是对表示打印区域的边界进行偏置，即平面轮廓的偏置算法。我们首先尝试了两种常规的轮廓偏置方法，基于线段平移的偏置和基于角平分线的偏置，但这两种方法都不能很好地处理局部自相交问题。为此，我们引入了一个专门用于平面轮廓裁剪及偏置运算的第三方库 Clipper。为了克服多边形轮廓数据格式的兼容性问题，我们构建了一个 Clipper 库的适配器。在此基础上，我们首先生成了边界轮廓的连续偏置曲线，然后通过识别各条偏置曲线之间的包含关系，将处于内部的直系子曲线逐条连接到直系父曲线上，从而得到若干连成一体的路径曲线，这些路径曲线就是我们所求的轮廓填充路径。我们将生成轮廓路径的流程和功能封装成一个 GenCpPath 类，并在最后对这个类进行测试，结果表明，如果除去编程语言本身的因素，GenCpPath 类能帮助我们在较短的时间内生成轮廓路径。
