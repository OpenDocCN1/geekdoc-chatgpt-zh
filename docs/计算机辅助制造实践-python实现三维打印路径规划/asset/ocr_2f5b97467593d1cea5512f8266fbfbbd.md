malize 和 normalized 表示对向量进行单位化操作，即对向量中的每个坐标值除以当前向量长度。函数 isZeroVector 用于判断一个向量是否为零向量。函数 multiplied 作用是对当前向量右乘一个矩阵并返回新的向量。函数 isParallel 以两个向量叉乘结果是否为零向量来判断它们是否平行。

在 Vector3D 类中,函数 getAngle 的作用是计算当前向量和另一向量的夹角,夹角取值范围为 0~π。需要说明的是,对向量 v1 和 v2,我们首先进行单位化处理,然后计算两个向量的点乘值 dotPro,并使用反余弦函数计算夹角,参见式(2-11):

> angle = arccos ( v1 · v2 )

理论上,dotPro 的值应为[-1, 1],但是由于截断误差的存在,dot Pro 的计算值可能小于-1或大于 1,如果将不合法的 dotPro 值输入反余弦函数中,则可能会出现数值异常。为了避免这一潜在的问题,我们对 dotPro 的结果进行处理,如果它小于-1,则令其为-1;如果它大于 1,则令其为 1。这里为了使用反余弦函数,我们在 GeomBase.py 开头导入了 math 库。

最后,我们来看一下 Matrix3D 类,它包含一个 4 行 4 列的二维数组 a。在类的__init__函数中,我们将矩阵初始化为一个单位矩阵;此外,makeIndenitcal 函数也可对一个已经存在的矩阵进行单位化操作。函数 multiplied 返回当前矩阵和另一矩阵相乘的结果。函数 getDeterminant 用于计算矩阵的行列式,函数 getReverseMatrix 用于计算当前矩阵的逆矩阵(如果存在),由于篇幅限制,在 GeomBase.py 中,我们并没有实现这两个函数,有兴趣的读者可以参考线性代数相关教材去实现这两个函数。

此外,在 Matrix3D 类中,我们还定义了 4 个静态函数,分别为 createTranslateMatrix、createScaleMatrix、createRotateMatrix 和 createMirrorMatrix,分别实现创建平移矩阵、创建缩放矩阵、创建旋转矩阵和创建镜像矩阵的功能,其中部分原理我们在 2.1 节已有所阐述。需要说明的是,静态函数是类中的一种特殊函数,在 Python 语言中,静态函数使用 @staticmethod 修饰。区别于类中的普通函数,静态函数直接使用类名即可调用,而不需要首先创建类的对象。如我们需要创建一个平移矩阵 mt 或缩放矩阵 ms,我们只需使用如下代码语句即可:

```
1 | mt = Matrix3D.createTranslateMatrix() | # 平移矩阵
2 | ms = Matrix3D.createScaleMatrix() | # 缩放矩阵
```

在 GemoBase.py 中,我们只实现了前 3 个静态函数,而没有实现 createMirrorMatrix 函数,有兴趣的读者可以去推导实现这个函数。最后,在 Matrix3D 类中,我们还定义了几个符号函数,包括矩阵加、减和乘操作。
