我们得到了针对任意输入 STL 模型的平面投影网格，如图 10.6 所示。接下来我们要在各个网格节点处布置沿竖直方向的直线，依次计算这些直线和模型的交点，并将交点信息存入如图 10.8 所示的字典结构中，方便后续提取、识别支撑线段。在这一过程中，我们需要解决的核心问题是计算竖线序列和 STL 模型的交点，即计算竖线序列和三角面片序列的交点。

首先,我们需要解决单条竖线和三角面片求交问题。这是一个简单的几何问题。在前面工作的基础上,我们可以借助一些现成的模块或函数来解决这个问题。在本书第 2 章中,我们已经实现了直线和平面的求交算法（参见 GeomAlgo 模块中的 intersect 函数）。显然,竖线和三角面片的求交问题是直线和平面求交问题的子问题,因此,理论上,我们只需在现有 intersect 函数的基础上附加一些限制条件,就能解决竖线和三角面片的求交问题。比如我们可以将竖线作为普通直线、三角面片作为普通平面代入 intersect 函数计算交点,然后判断该交点是否在三角面片内,如果交点在面片内,则竖线和面片相交,此时返回交点,否则竖线和面片不相交。但其实我们也可以反过来思考这个问题,即首先对线面判交,然后再计算交点。要判断空间中任意一条直线和一个三角面片是否相交其实不太容易,但如果这条直线是沿竖直方向的直线,那么它们之间的判交就变得相对简单。在这种情况下,我们只需在 XY 平面上检查竖线投影点是否落在三角面片的投影内即可。如图 10.9 所示,考虑到这里的竖直线是过网格节点的竖直线,因此我们只需判断网格节点是否落在三角面片的投影内。
