下载完成后，双击安装包(python-3.6.8-amd64.exe)，弹出 Python for Windows 安装界面如图 1.4 所示。在该界面上，有两种安装方式可选，默认安装(Install Now)和自定义安装(Customize installation)。对初学者来说，首选默认安装，点击 Install Now 后，安装程序会把相关组件安装到系统盘默认文件夹下。如果选择自定义安装，点击 Customize installation 后，进入自定义安装界面，在这些界面上可配置需要安装的组件及安装目录，如果无特殊需求，一般只需更改程序安装目录即可，如可将程序安装至 D:\Program Files\Python36\中。需要注意的是，无论选择哪种安装方式，推荐勾选 Add Python 3.6 to PATH 复选框，即将 Python 目录添加到系统 PATH 环境变量中，这样在 Windows 的命令窗口(cmd)，可直接使用 Python 命令(见图 1.4)。如果没有勾选该复选框，也可在安装完成后手动将 Python 安装目录添加到系统环境变量中。
