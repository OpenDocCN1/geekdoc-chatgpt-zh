到一个三维打印 NC 代码生成模块，用于生成可被实际三维打印机识别和打印的 NC 代码。

需要指出的是，在计算机辅助制造或路径规划中，“路径”是相对于工件模型和工艺参数的几何概念，通常指计算机内存中生成的或存储的曲线（或多段线）数组；而 NC 代码具有设备属性，它是相对于具体数控设备而言的，如数控机床、三维打印机等，数控设备通过读取、解析 NC 代码控制各进给轴运动、I/O 执行相应操作。从曲线路径到 NC 代码的转化过程一般叫作后置处理。后置处理需要考虑目标设备特性，对相同路径，针对不同目标的设备可能生成不同的 NC 代码。

因此，从内容上来说，这一节我们首先要做的是生成路径，然后针对某种具体三维打印机对路径进行后置处理，生成 NC 代码。这里我们以当下市面上极为常见的 FDM 三维打印机为例讲解 NC 代码（通常就是 G 代码）的生成过程。下面我们首先来对三维打印路径生成涉及的重要工艺参数做一个汇总。

# 11.2.1 工艺参数汇总
