# 6.4 字典查询法拼接优化

我们在上一节实现了一种基于字典序排序的截交线段优化拼接算法,其核心是依赖 LinkPoint 数据结构和点的字典序排序结果寻找线段之间的邻近关系,它的理论时间复杂度为 O( nlog(n) ),其中 n 为截交线段数量。这一节我们将另辟蹊径,介绍一种在原理上完全不同的线段拼接算法。这种算法的基础依然是 LinkPoint 数据结构,它的本质仍然是构建和寻找线段之间的临近关系,只是这次我们会把所有转化得到的链接点放在一个字典对象中,依赖编程语言内置字典类的快速查询功能定位邻近点的信息。注意,虽然本节方法和上节方法中都带“字典”字眼,但两者是完全不同的概念,一个是指字典序,一个是指字典类。
