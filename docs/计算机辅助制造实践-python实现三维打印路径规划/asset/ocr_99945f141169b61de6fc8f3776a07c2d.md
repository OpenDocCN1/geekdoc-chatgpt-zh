候,我们大概会遵循以下两种非常直观的设计思路,一种是基于线段平移的偏置,另一种是基于角平分线的偏置。

# 8.2.1 基于线段平移的偏置

根据以上描述,我们知道,偏置多边形事实上就是一个沿着原始多边形滚动的圆的圆心轨迹。尽管如此,我们发现,直接从圆在多边形上滚动的角度去求取偏置多边形还是比较困难的。但是我们可以对这个问题进行简化,首先把原始多边形拆分开来,当圆沿着它其中的一条边(线段)滚动时,此时圆心的轨迹就是一条线段,即偏置线段。然后我们可以对原始多边形的每条边进行偏置,最后,理论上,我们只需有序地连接这些偏置线段就可以得到原始多边形的偏置多边形了。但事实真的如此吗?

首先我们来看一下线段的偏置问题,对于我们来说,这个问题其实非常简单。我们只需对线段进行平移即可,平移的方向为原始线段的法线方向。更具体地,我们只需对原始线段的两个端点分别沿着线段法向平移给定的偏置距离即可。这个问题的关键就是获取原始线段的法线方向。但因为我们在 GeomBase 模块的 Vector3D 类中已经封装了 getOrthoVector2D 函数,这个函数的作用就是求取当前向量在 XY 平面内的正交向量(单位向量),即法向量。因为所有的切片轮廓都在 XY 平面内,因此我们可以直接应用这个函数。如果我们假设输入线段的两端点分别为 P1,P2,那么它的法向量可由以下代码求得:

| 1 | v = P1.pointTo(P2) | # v 为直线 P1P2 方向 |
| 2 | n = v. getOrthoVector2D() | # n 为直线 P1P2 法向量,n 为单位向量 |

但线段 P1,P2事实上有两个法向量,分别指向直线的两侧。如图 8.4 所示,如果我们要求取原始多边形的向内偏置多边形,且原始多边形方向为逆时针的话,此时我们要求的线段 P1,P2的法向应该指向 P1,P2的左侧。注意,当我们说一条线段(或一个向量)的左侧或右侧时,我们是站在背向它的起点、面向它的终点的角度说的。遗憾的是,查看 getOrthoVector2D 函数代码可知,它返回的法向量的左右侧方向是不确定的,因此我们必须对以上代码中的法向量 n 做进一步处理。
