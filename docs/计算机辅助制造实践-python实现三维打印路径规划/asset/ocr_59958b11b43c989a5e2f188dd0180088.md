# 2.3 多段线

上一节，我们实现了直线、射线和线段三个非常简单的几何实体类。我们注意到，这些类表示的线型至多包含两个点，但很多时候，我们可能需要一种能够表达由多个空间点依次连接得到的线型，如图 2.4 所示，我们把这种线型称为多段线、多义线、折线或点列曲线（point-sequence curve，PS-curve）。

注意，多段线中的顶点不是杂乱无序的，而是依次连接的；且顶点个数至少为 2，当顶点数恰为 2 时，多段线退化为线段。多段线包含两个端点，如果这两个端点重合，那么我们称多段线是闭合的；反之，我们则称多段线是开放的。
