它们是非法的偏置点。在有非法偏置点的附近，必然会有非法的偏置轮廓，因此原则上在定位非法偏置点后，就可找到那些非法的自相交环。但是这种基于偏置点位置去识别自相交环的方法计算量较大，因为这种方法需要遍历计算每个偏置点到原始轮廓的距离，其算法时间复杂度至少是 O(n²)，其中 n 为原始多边形上的顶点个数。

图 8.10 局部自相交环识别方法:根据位置或方向识别

接下来我们再来看一下根据偏置线方向识别自相交环的方法。我们知道，原始轮廓是有方向的（逆时针），对原始轮廓偏置得到的轮廓方向应该和原始轮廓的方向一致。具体到偏置轮廓上的每条边，在偏置过程中，它的方向也应该和与之对应的原始轮廓上的边的方向保持一致。如图 8.10 所示，显然，偏置线段 Q1Q2、Q3Q4 分别和原始线段 P1P2、P3P4 的方向是一致的，因此 Q1Q2 和 Q3Q4 是合法的偏置线段；但是 Q2Q3 和 P2P3 的方向刚好相反，因此我们断定偏置线段 Q2Q3 必然是有问题的，即非法的。在非法偏置线段附近，必然存在非法的偏置轮廓，据此，原则上我们可以找到自相交环。相对偏置点位置识别法，偏置线方向识别法效率更高，它的算法时间复杂度为 O(n)，其中 n 为原始多边形上的顶点个数。

无论使用哪种方法，当我们识别出局部自相交环后，就要想方设法将其消除。但消除局部自相交环绝对不是一件容易的事情。原则上我们可以计算非法偏置点或非法偏置线段附近偏置线上的自相交点，并根据这些交点舍弃一些非法偏置轮廓段。但这真正操作起来难度非常大，因为我们很有可能遭遇类似于图 8.7 所示的复杂自相交轮廓，哪些轮廓段可取？哪些轮廓段可舍？这些问题可能都需要我们进一步计算或制定规则。

在我们的前期研究工作中，曾提出了一种基于轮廓更新的局部自相交环消除方法和基于树结构分析的全局自相交环消除方法（参见 Lin Z, Fu J, He Y, Gan W. A robust 2D point-sequence curve offset algorithm with multiple islands for contour-parallel tool path. Computer-Aided Design. 2013,45(3)：657-70）。轮廓更新法使用原始多边形相邻顶点间的角平分线段（顶点和相应偏置点形成的线段，见图 8.10）是否相交来识别局部自相交环是否存在。如果相邻角平分线段相交，则在附近构建一个原始轮廓的卡圆，并基于卡圆对原始轮廓的顶点进行更新。树结构分析法首先计算偏置轮廓上的自相交点，然后将这些交点根据位置关系整理成树状结构，最后按照一定规律截取某些节点间的轮廓围成若干有效环。结果表明，上述方法能在线性时间内消除所有局部和全局自相交环。有兴趣的读者
