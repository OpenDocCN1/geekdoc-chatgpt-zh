同时降低 pointInPolygon 的判别次数。其实不难发现，在封闭曲线的包含关系中，直系父曲线的面积必然大于直系子曲线的面积。这个发现看起来微不足道，却是以下改进方法的基础。根据这一原理，在以上暴力算法中得到曲线 c 的潜在直系父曲线 parents 后，我们只需计算 parents 中每条曲线的面积，其中面积最小的那条曲线就是曲线 c 的直系父曲线，这样我们就可以完全规避多边形之间繁琐而费时的距离计算。如在图 8.25 中，曲线 c1 的潜在直系父曲线有 c2, c3, c4, c5, c6 共 5 条曲线，而在这些潜在直系父曲线中，c2 面积最小，因此 c2 就是 c1 的直系父曲线。事实上，如果我们一开始便考虑计算 polys 中各封闭曲线的面积，并按面积对 polys 中的曲线进行排序，我们还可以降低 pointInPolygon 至少一半的运算次数。因为对任意曲线 polys[i]，我们只需从面积比它稍大的曲线中（从 polys[i+1] 开始）寻找它的直系父曲线。在运气最好的情况下，我们大概只需 n 次 pointInPolygon 运算；在运气最差的情况下，我们大概需要 n(n - 1)/2 次 pointInPolygon 运算。
