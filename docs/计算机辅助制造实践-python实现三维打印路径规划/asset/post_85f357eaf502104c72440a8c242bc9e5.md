首先我们来看一下 addPoint 和 raddPoint 两个函数，这两个函数的作用都是向已有的多段线添加一个顶点。不同的是，addPoint 向多段线的终点之后添加一个顶点，而 raddPoint 向多段线的起点之前插入一个顶点，raddPoint 中的 r 表示反向（reverse）的意思。

我们再来看一下 getArea 函数，这个函数的作用是获取位于 XY 平面上的多边形面积，或者是对任意封闭多段线，获取它在 XY 平面上投影的面积。理论上，对 XY 平面上的任意多边形，只要它各顶点的位置确定，那么它的面积就已确定，计算公式为

\( S = \frac{1}{2} \sum_{0}^{n-1} (P_{i:x} \cdot P_{i+1:y} - P_{i+1:x} \cdot P_{i:y}) \quad (2-15) \)

式中，S 为多边形面积，n 为顶点个数。上述 getArea 函数正是根据这一公式计算多边形面积的。

事实上，getArea 函数的作用不仅仅是计算多边形面积，它还可以用来判断多边形的方向。如果一个多边形通过 getArea 计算出来的面积为正，则其方向是逆时针（CCW）的；反之，则其方向为顺时针（CW）。Polyline 类中后面的 makeCCW 和 makeCW 函数正是根据多边形面积的正负强制将多边形调整成逆时针或顺时针方向。有兴趣的读者还可思考并实现一下判断多边形方向的其他方法。

最后我们来看一下 appendSegment 函数，这个函数的作用是将一条线段拼接到一条多段线上，前提是线段的两个端点和多段线的两个端点中必须有一对是重合的，即需要讨论端点拼接的四种情况，如图 2.5 所示。如果拼接成功，函数返回 True；如果拼接失败，函数返回 False。注意到在这个函数里我们使用了 isCoincide 函数来判断两个点是否重合，这是出于实际计算中数据截断误差的考虑。在 Polyline.py 文件中，除了定义以上介绍的 Polyline 类外，我们还定义了两个全局函数：writePolyline 和 readPolyline。顾名思义，这两个函数的功能分别是将多段线写入自定义文本文件，或从已保存的文本文件中读取多段线。文件格式如下，其中第 1 行为顶点个数，其余各行为各顶点 x、y、z 坐标。我们创建这两个函数的目的是方便今后调试时可直接查看多段线中顶点数据。

## 2.4 平面

这一节我们接着来定义平面。在前面介绍直线时，我们已经给出了平面方程(参见式(2-14))。理论上，平面可以看成是空间中过某一给定点且垂直于某一给定向量的所有直线的集合，这个向量就是平面的法向量。据此，结合式(2-14)，我们可以得出

A(x - x₀) + B(y - y₀) + C(z - z₀) = 0  
(2-16)

式中，(x₀, y₀, z₀) 为某一给定点，(A, B, C) 为给定法向量，(x, y, z) 为平面上任意一点。进一步地，上式可以转化为

(A,B,C) · (x - x₀, y - y₀, z - z₀) = 0  
(2-17)

即两个互相垂直的向量的点乘结果为 0。

根据以上分析，和直线、射线一样，我们可以根据一个点和一个向量来定义一张平面。我们将平面类放在 Plane.py 文件中，类名为 Plane，具体实现代码如下：

### 2.5.1 实体距离

我们在这里求解的实体距离包括点线距离、点面距离、线线距离和线面距离，点点距离已经包含在 Point3D 类中。

- 1. 点线距离

对空间中已知的任意一点 Q 和直线 l(P, V)，其中 P 为 l 经过的点，V 为 l 单位方向向量，如图 2.7( a )所示。记点 Q 在直线 l 上的投影为 R，设 P、R 两点距离为 t，则向量 PR = V · t。在三角形 QPR 中，向量 QR = QP + PR，即 QR = QP + V · t。又因为 QR ⊥ V，所以两向量点乘为 0，即

$$(QP + V \cdot t) \cdot V = 0$$ (2-18)

得

$$t = - \frac{QP \cdot V}{V^2} = PQ \cdot V$$ (2-19)

即 t 值为 PQ 和 V 两向量点乘结果。投影点 R = P + V · t，QR 的长度即为点 Q 到直线 l 的距离。

如图 2.7(b) 所示，如果 l 为射线，那么我们还要判断 Q 的投影 R 是否在 l 上。根据上面的推导，显然，如果 t>=0，那么 R 落在 l 上，否则 R 落在 l 外。进一步地，如果 t>=0，则 QR 长度即为 Q 到 l 的距离，否则 QP 长度为 Q 到 l 的距离。

如图 2.7(c) 所示，如 l 为线段，记 P, P1 为其两端点，长度为 L。显然，如果 0<=t<=L，那么 R 落在线段上，此时 QR 长度即为 Q 到 l 的距离；如果 t < 0, QP 长度即为 Q 到 l 的距离；如果 t > L, QP1 长度即为 Q 到 l 的距离。

图 2.7 点到直线、射线、线段距离计算

- 2. 点面距离

如图 2.8 所示，对空间中已知的任意一点 Q 和平面 \(\alpha(P, N)\)，其中 P 为 \(\alpha\) 经过的点，N 为其单位法向量。记 Q 在平面上的投影为 R，在三角形 PQR 中，点 P、Q 坐标已知，即向量 PQ 已知，向量 QR 方向和 N 相同（或相反），记 \(\angle PQR\) 为 \(\theta\)，则

> \(\theta = \arccos (\frac{PQ \cdot N}{|PQ|})\) (2-20)

进而 \(QR = PQ \cdot \cos(\theta)\)，QR 即为点到平面的距离。

- 3. 线线距离

在线线距离中，我们只讨论两条异面直线的距离。记两条异面直线为 \(l_1(P_1, V_1)\) 和 \(l_2(P_2, V_2)\)，如图 2.9 所示。设 \(C_1 C_2\) 为其公垂线，则 \(C_1 C_2\) 长度即为两异面直线距离。如果我们将直线 l1 从 C1 点平移到 C2 点,同时将 l2 从 C2 点平移至 C1 点,这样我们可以得到两张平行平面,且平面法向量为 N,则

$N = V_1 \times V_2$ (2-21)

此时,求取异面直线的距离可转化为求取两平行平面的距离。进一步地,我们可以得到,两平行平面的距离等于点 P1 到由 P2 和 N 确定的平面的距离。这样我们就可将求取异面直线的距离成功转化为求取点面距离。如果在式 (2-21) 中,N 为零向量,即 l1 平行于 l2,此时问题等价于求取点 P1 到直线 l2 距离。

图 2.9 两异面直线距离计算

- 4. 线面距离

首先是直线到平面的距离,如果直线的方向向量和平面的法向量垂直,那么直线到平面的距离就是直线上一点到平面的距离,否则直线到平面的距离为 0。

射线和直线类似,所不同的是,如果射线方向向量和平面的法向量不垂直,那么需要考虑射线方向走势,是向着平面还是远离平面。我们可以采用试探的方法,除射线端点外,再在射线上取一个点,然后分别计算这两个点到平面的距离。如果端点到平面的距离较大,那么该距离就是射线到平面的距离,否则射线到平面的距离为 0。

线段到平面的距离相对来说较为复杂,需要判断线段两端点是否位于平面同一侧。首先我们可以根据式 (2-16) 建立如下判别式

$f(x, y, z) = A(x - x_0) + B(y - y_0) + C(z - z_0)$ (2-22)

然后,分别将线段两端点代入上式,得到 f1 和 f2,如果 f1 * f2 <= 0,则线段到平面距离为 0,否则取两端点到平面距离较小者为线段到平面距离。
