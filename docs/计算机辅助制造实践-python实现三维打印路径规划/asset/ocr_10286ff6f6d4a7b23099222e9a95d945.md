平行包络矩形,我们可以通过简单的坐标比较从所有网格节点中筛选出落在矩形 DEFG 内的潜在节点,然后再从这些潜在节点中使用上述判交方法筛选出落在三角形 ABC 内的有效节点,这样就可以减少判交次数。
