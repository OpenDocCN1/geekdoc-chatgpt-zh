中查询以 ($x_A$, $y_A$, $z_A$) 为键的坐标是否已经存在:如果不存在,则将 ($x_A$, $y_A$, $z_A$) 和 A 以键值对形式添加至 vxDic;如果 vxDic 中已经存在 ($x_A$, $y_A$, $z_A$) 键,则说明之前有坐标标同为 ($x_A$, $y_A$, $z_A$) 的顶点已经被添加进了字典,此时我们不去执行任何操作,让具有相同坐标的点只在字典中保存一次。对顶点 B 和 C,我们按以上步骤执行相同的操作。

借助字典 vxDic,对 STL 模型中的每个三角面片不断重复上述过程,就可以消除冗余顶点。由于字典查询的时间复杂度为 O(log (n)),因此使用字典消除冗余顶点总的时间复杂度为 O(nlog (n)),其中 n 为 STL 模型总顶点数,包含冗余顶点。
