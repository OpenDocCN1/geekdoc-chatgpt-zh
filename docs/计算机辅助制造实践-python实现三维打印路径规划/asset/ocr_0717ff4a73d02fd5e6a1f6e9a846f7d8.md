layers,使用 GenCpPath 类逐层生成轮廓路径,并将这些路径保存在临时变量 pathses 中,同时统计生成轮廓路径所需的时间。最后我们使用 VtkAdaptor 类绘制每层轮廓边界和轮廓路径。最后我们来看一下以上 Test_genCpPath.py 的执行结果,测试用主机 CPU 为 Intel Core i7-8700@ 3.20GHz。表 8.1 给出了针对不同切片厚度 monk 模型 SLC 文件的轮廓平行填充路径生成时间统计。由表 8.1 可知,在切片厚度为 0.2 毫米,接近日常 FDM 三维打印层厚时,所需轮廓路径生成时间为 132.9 秒钟。相对于常用的三维打印切片软件(如 Cura)来说,这样的运行速度算是比较慢的,这其实主要是我们使用的编程语言引起的。Cura 的内核是 C++编写的,运行速度非常快,而我们在本书中涉及的三维打印路径生成算法都是用 Python 实现的(第三方库除外,如 Clipper,我们在本章用的 Clipper 库内核也是用 C++实现的),而对于计算密集型任务,C++比 Python 的效率要高 1 ~ 2 个数量级,即 10 ~ 100 倍。在认识到这点之后,我们应该能够坦然接受以上结果。事实上,Clipper 库也封装了一个检测一个点是否在多边形内部的函数,如果我们使用这个函数替换我们在 GeomAlgo 模块中实现的 pointInPolygon 函数,轮廓路径生成的效率能提升 2 倍以上,有兴趣的读者不妨去尝试一下。
