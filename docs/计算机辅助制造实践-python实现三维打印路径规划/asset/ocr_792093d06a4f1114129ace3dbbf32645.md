包含 3 个参数，分别为 prop、LP、GP。其中 prob 为 probability 缩写，表示当前粒子发生变异的概率，取值为[0, 1]，一般情况下，粒子变异的概率不能设置得太高，否则会影响粒子群算法收敛。参数 LP、GP 仍然表示个体、全局极值粒子，在 vary 函数中引入这两个粒子的作用是构建如图 10.26 所示的三角形及其包络矩形，便于我们定位变异后的粒子位置。在 vary 函数中，我们首先调用了 random 函数生成了一个 0 到 1 之间的随机数，并且让这个随机数和指定概率 prob 比较，如果随机数小于 prob (如 0.01)，则执行变异操作，通过这种机制，我们可以控制变异发生的概率。如果粒子需要变异，首先我们对 a (即转角 α) 生成一个 [0, amax] 范围内的随机数。如图 10.26 所示，如果 a 在包络矩形的左侧或右侧，则对 b (即转角 θ) 同样生成一个 [0, amax] 范围内的随机数；否则则对 b 在包络矩形的下侧和上侧范围内生成随机数。这样我们就可以在包络矩形外、定义域内生成一个变异随机粒子。

+   (1) 随机初始化 N 个粒子的位置 Pi，其中 i ∈ [1, N]；

+   (2) 根据指定适应度函数计算每个粒子适应度；
