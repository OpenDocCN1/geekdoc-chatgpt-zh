线段序列呢？理论上，我们只需在整个平面范围内生成无数条无限长的平行线段，那么这些线段必然能够覆盖到整个填充区域。但这样做显然是不现实的，我们没这么多时间，也没这么大的存储空间。从计算资源优化利用的角度来说，生成的平行线段序列最好能够恰好覆盖整个多边形区域。这个时候，我们最容易想到的是首先在给定多边形序列的轴平行(axis-aligned)包络矩形内生成一系列平行线段，如图 9.8 所示。即便如此情况下，我们发现，因为线段的长度不定，想要获取这些线段的端点也并非易事，需要付出额外的求交运算，这绝对不是我们想要的。

在图 9.8 中，我们发现，当平行线倾角变化时，落在包络矩形内部的平行线段的最大长度不会超过包络矩形的对角线长度。因此，理论上，只要设置每条平行线段的长度为包络矩形的对角线长度，平行线段就能覆盖整个多边形区域。如图 9.9 所示，我们首先做包络矩形的外接圆，并记其圆心为 O，半径为 R；然后，我们过 O 点做垂直于填充线方向（图中 v, v 相对于 X 轴倾角为 θ）的直线 P1, P2，其中 P1, P2 分别为该直线和圆弧的交点。此时，我们只需在线段 P1 P2 上根据指定的填充间距（图中 d）取点，并以这些点为垂足做 P1 P2 的一系列垂线段，使得垂线段的长度为 2R，且中点落在 P1 P2 上。这些垂线段就是我们要求的能够覆盖整个多边形填充区域且带指定倾角的平行线段。下面我们给出这些平行线段的计算步骤：
