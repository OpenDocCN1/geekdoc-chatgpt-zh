\(\varepsilon = \varepsilon' - \mathrm{j}\varepsilon'' - \mathrm{j}\frac{\sigma_s}{\omega}\) (2.26)

图 2.9 入射信号在介质表面产生的反射和折射

整理后可得 \(\sigma_e\) 与 \(\sigma_s\) 的关系为

\(\sigma_e = \varepsilon''\omega + \sigma_s\) (2.27)

为了反映介电常数实部和虚部之间的关系，定义损耗角正切

\(\tan \sigma_e = \frac{\varepsilon''}{\varepsilon'} = \frac{\sigma_e}{\omega\varepsilon'} = \frac{\varepsilon''\omega + \sigma_s}{\omega\varepsilon'}\) (2.28)

特别地，当 \(\tan \sigma_e = 0\) 时，表示材料是无损的。对于图 2.9 中的情况，入射波和反射波满足以下条件：

\(\theta_i = \theta_r\) (2.29)

\(\frac{\sin \theta_i}{\sin \theta_r} = \sqrt{\frac{\varepsilon_2 \mu_2}{\varepsilon_1 \mu_1}}\) (2.30)

进而，可以得到在介质边界处，垂直极化和平行极化的反射系数

\(\Gamma_\perp = \frac{E_\perp^r}{E_\perp^i} = \frac{\eta_2 \cos \theta_i - \eta_1 \cos \theta_t}{\eta_2 \cos \theta_i + \eta_1 \cos \theta_t}\) (2.31a)

\(\Gamma_\parallel = \frac{E_\parallel^r}{E_\parallel^i} = \frac{\eta_2 \cos \theta_t - \eta_1 \cos \theta_i}{\eta_2 \cos \theta_t + \eta_1 \cos \theta_i}\) (2.31b)

式中，\(\eta_i (i=1,2)\) 表示介质的固有阻抗。对于平行极化的情况而言，当 \(\varepsilon_1 < \varepsilon_2\) 时，存在布儒斯特角 (Brewster angle)
