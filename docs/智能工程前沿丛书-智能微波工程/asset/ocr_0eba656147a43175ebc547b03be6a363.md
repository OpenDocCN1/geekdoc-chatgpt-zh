```
$$
E_n = \begin{bmatrix} e^{j\beta(-\frac{Q-1}{2}du_1-\frac{P-1}{2}dv_1)} & \cdots & e^{j\beta(\frac{Q-1}{2}du_1+\frac{P-1}{2}dv_1)} \\ \vdots & \ddots & \vdots \\ e^{j\beta(-\frac{Q-1}{2}du_k-\frac{P-1}{2}dv_s)} & \cdots & e^{j\beta(\frac{Q-1}{2}du_k+\frac{P-1}{2}dv_s)} \end{bmatrix}
$$ (5.14)
```

```
$$
c_n = [c_{n, -\frac{Q-1}{2}, -\frac{P-1}{2}}, \cdots, c_{n, \frac{Q-1}{2}, \frac{P-1}{2}}]^T
$$ (5.15)
```

```
$$
g_n = [g_n(u_1, v_1), \cdots, g_n(u_k, v_s)]^T.
$$ (5.16)
```

从而，可获得式 (5.12) 的解，

```
$$
c_n = (Z_n^H Z_n)^{-1} Z_n^H g_n.
$$ (5.17)
```

式中， $Z_n = G E_n$。

利用上述的平面虚拟子阵拟合方法，ABE 的辐射特性可以通过 $c_n$ 进行表征。 由此，式 (5.9) 可以转换为 $T$ 个子训练集的集合：

```
$$
D_{app,t} = \{ l_t, y_{app,t} | t = 1, \cdots, T \}
$$ (5.18)
```

式中， $T = 2PQW_f$，代表子训练集的个数，即为平面虚拟子阵中的每一个阵元在每一个频点处的幅度和相位激励创建一个子训练集，

```
$$
y_{app,t} = [c_{1,t}, \cdots, c_{n,t}]^T
$$ (5.19)
```

每个子训练集中包含 $X_{app} = KM + 5$ 列数和 $W_{app} = W_{ABE}$ 行数。对于上述的实际的二维面阵综合的例子，若选取 $P = Q = 5$，则 HKDT 将会生成 50 个子训练集，其行数为 $W_{app} = 100$，相较于 ABEM 方法的数据的行数 $W_{tra} = 3240000$，实现了大幅度对计算复杂度的削减。

采用常用的 GPR 机器学习方法比较 ABEM 和 HKDT 的计算复杂度的。在 GPR 对超参数 $\theta$ 的训练过程中，一种常用的方法是通过最小化负对数似然函数 (negative log marginal likelihood, NLML) $h_{NLML}$ 对超参数进行训练：

```
$$
\theta_{opt} = \text{argmin}(h_{NLML}(\theta))
$$ (5.20)
```

而对式 (5.20) 的求解的计算复杂度主要来源于矩阵求逆运算，其计算复杂度为 $\mathcal{O}(n_d^3)$，其中 $n_d$ 为矩阵的维度；在 GPR 对设计点的预测过程中，其计算复杂度为 $\mathcal{O}(n_d^2)$。总体而言，数据驱动方法中训练集的维度 $n_d$ 将直接决定包括训练和预测过程在内的算法的计算复杂度。采用 HKDT 方法，可以将原本的 ABEM 的训练的计算复杂度从 $\mathcal{O}((W_{ABE}W_fW_uW_v)^3)$ 降低到 $\mathcal{O}((W_{ABE})^3)$，将 ABEM 的预测的计算复杂度从 $\mathcal{O}((W_{ABE}W_fW_uW_v)^2)$ 降低到 $\mathcal{O}((W_{ABE})^2)$。下面分别从线阵和面阵应用的角度来研究 HKDT 建模的效率和能力。
