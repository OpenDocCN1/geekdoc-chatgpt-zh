且 \( 0 < \beta \leqslant 1, \varepsilon > 0 \)。

解决最大后验概率估计的问题需要解决基本问题，相关的对偶问题为

\(\min_{\alpha, \alpha^*} \left( \frac{1}{2}(\alpha - \alpha^*)^T \mathbf{\Sigma} (\alpha - \alpha^*) - \sum_{i=1}^n y_i(\alpha_i - \alpha_i^*) + \sum_{i=1}^n (\alpha_i + \alpha_i^*)(1 - \beta)\varepsilon + \frac{\beta \varepsilon}{C} \sum_{i=1}^n y_i(\alpha_i^2 - \alpha_i^{*2}) \right)\) (3.20)

且 \( 0 \leqslant \alpha_i, \alpha_i^* \leqslant C, i = 1, 2, \cdots, n \)。在上面的对偶问题中，\(\mathbf{\Sigma}\) 是一个 \( n \times n \) 的矩阵，\(\mathbf{\Sigma}_{ij} = k(u_i, u_j)\)，\( k(\cdot) \) 是核函数，具有 ARD 的高斯核函数为

\( k(u_i, u_j) = \sigma_f^2 \exp \left( -\frac{1}{2} \sum_{k=1}^D \frac{(u_{ik} - u_{jk})^2}{\tau_k^2} \right) \) (3.21)

式中，\( u_{ik} \) 和 \( u_{jk} \) 分别是第 \( i \) 个和第 \( j \) 个用于训练的输入向量的第 \( k \) 个元素。其中包括 \( \sigma_f^2, \tau_k, \beta, C, \varepsilon \) 的超参数向量 \( \theta \) 是由最小化负对数概率得出：

\( -\ln p(\mathbf{D} | \theta) = \frac{1}{2} (\alpha - \alpha^*)^T \mathbf{\Sigma} (\alpha - \alpha^*) + C \sum_{i=1}^n L_{\varepsilon, \beta}(y_i - f_{\text{MP}(x_i)}) + \frac{1}{2} \ln \left| \mathbf{I} + \frac{C}{2 \beta \varepsilon} \mathbf{\Sigma}_\text{M} \right| + n \ln Z_s \) (3.22)

式中，\(\mathbf{\Sigma}_\text{M}\) 是 \(\mathbf{\Sigma}\) 的一个 \( m \times m \) 的子矩阵；\( f_\text{MP} = \mathbf{\Sigma} (\alpha_i + \alpha_i^*) \)。对于一个输入向量 \(\mathbf{u}^*\) 的回归估计可以表示为：

\( f(\mathbf{u}^*) = \sum_{i=1}^n k(u_i, \mathbf{u}^*) (\alpha_i - \alpha_i^*) \) (3.23)

符合 \( |\alpha_i - \alpha_i^*| > 0 \) 的训练点作为支持向量 (SV)。通常，在损失函数中参数 \( \beta \) 越小，SV 的数量就越少；\( \beta \) 决定了与训练目标相关的相加噪声的密度函数。
