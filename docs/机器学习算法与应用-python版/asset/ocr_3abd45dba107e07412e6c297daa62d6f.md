# 步骤 1 了解单层与多层网络

人工神经网络中需要计算的层次称为计算层，拥有一个计算层的称为单层人工神经网络，如图 9-1 所示。其中，$x_i$ 为输入，$w_i$ 为权重。单层人工神经网络只包含输入层和输出层，输入层用于数据的传输，不作计算，输出层则是对前面一层的输入进行计算。

多层人工神经网络是指包含计算层的网络，比单层神经网络多了隐含层，如图 9-2 所示。
