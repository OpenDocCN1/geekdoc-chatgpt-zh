# 项目导读

在学习机器学习算法之前，需要了解各种专业术语以及数据如何预处理，这样才能深入学习机器学习算法。一般需要重点了解什么是训练集、验证集、测试集。掌握数据预处理的各种方法以及主成分分析（Principal Component Analysis，PCA）在数据特征提取中的应用。

# 学习目标

+   - 掌握训练集、验证集和测试集的划分方法。
+   - 掌握数据预处理的方法。
+   - 理解主成分分析函数并应用。
