如果数据与它附近的数据相关性较强，那么可以使用缺损值的前一行或者后一行数据进行填充。使用缺损值的前一行进行填充，代码如下。

```
data = data.fillna(method='ffill')
print(data)
```

返回结果如下。

| | 学号 | 身高 | 体重 |
|---|---|---|---|
| 0 | 1 | 172.0 | 70 |
| 1 | 2 | 162.0 | 62 |
| 2 | 3 | 175.0 | 75 |
| 3 | 4 | 170.0 | 68 |
| 4 | 5 | 170.0 | 67 |
| 5 | 6 | 160.0 | 58 |
| 6 | 7 | 164.0 | 64 |
| 7 | 7 | 164.0 | 64 |
| 8 | 8 | 160.0 | 53 |

使用缺损值的后一行进行填充，代码如下。

```
data=data.fillna(method='bfill')
print(data)

|---|---|---|---|

还可以使用身高的均值来填充缺损值，代码如下。

```
data[' 身高 '].fillna(data[' 身高 '].mean(), inplace=True)
