# # 任务 4-2 使用 KNN 回归算法预测鞋码

# ### 任务描述

使用 KNN 回归算法完成鞋码的预测。

# ### 任务目标

掌握 KNN 回归算法的基本步骤并使用 KNN 回归算法来进行鞋码的预测。

# ## 任务实施

此任务将介绍如何使用 KNN 回归算法处理回归任务，使用鞋码数据训练 KNN 算法，并使用 KNN 算法来进行预测鞋码，通过更改 K 值观察 K 值对结果的影响。

# ### 步骤 1 了解数据集
