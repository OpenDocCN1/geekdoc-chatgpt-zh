# 硬件篇学用“树莓派”
![](images/txt001_1.jpg "pagenumber_ebook=9,pagenumber_book=1")
![](images/txt001_2.jpg "pagenumber_ebook=9,pagenumber_book=1")
开源硬件，是指整个硬件的运行原理、电路设计、材料清单以及所使用的软件（如驱动程序的源代码），全部是公开的，这些公开的信息可以自由使用并分享。开源硬件倡导我们充分发挥自己的想象力与创造力，并使用软硬件实现自己的想法。能将自己使用开源硬件创造出的作品公开，这样的人被称为“创客（Make）”。“创客”的潜台词是：我想得更宽、更广、更多；如果一位“创客”将某个技术方面做到了极致，他就从创客转变成了“极客（Geek）”。“极客”的潜台词是：我不但要比别人想得更深，还要比任何人都做得更好；还有一类人，他们使用开源硬件做出了具有创新性或者创造性的作品，但他们不愿公开，而将作品转为了产品获利，这样的人就被称为“威客（Wisdom）”。“威客”的潜台词是：我有一个好点子并实现了它，我要把这点子变成利益。
总之，只要软、硬件信息公开的，并允许我们在此基础上进行二次创造的，都是开源硬（软）件。现在的开源硬件不但有开源的微型电脑、开源的3D打印机等，甚至还有开源的拖拉机、抽水灌溉机！2017年，地球上空还多了一枚开源气象卫星。严格来说，开源精神促使了开源软硬件的诞生与发展；开源软硬件又促生了以创客与极客为代表的开源文化；开源文化与开源精神的最终指向，可以用六个字概括：“自由、创新、创造。”

### 第三节　树莓派运行环境的配置
要在树莓派上做开发，我们首先要能熟练地使用树莓派。就让我们从配置树莓派运行环境开始学习使用它吧！

#### 活动一：通过有线网卡连接树莓派
树莓派3B+同时具备有线网卡与无线网卡，我们可以先通过有线网络来连接树莓派，然后启用它的无线网络，今后就可以通过无线网络控制树莓派。
1.将网线一端接到树莓派网卡端口，另一端接到台式电脑或笔记本电脑。
2.在电脑上共享互联网，步骤如下：
找到无线网络连接，右键点“属性”，在“共享”选项卡上选中“允许其他网络用户通过此计算机的Internet连接来连接”。
![](images/txt002_10.jpg "pagenumber_ebook=15,pagenumber_book=7")
图1-1-6　个人电脑无线网络连接
注意：家庭网络连接要选择以太网“本地连接”的连接。如果没有下拉菜单供选择，请重启。
3.设置本地连接IP地址：
根据自己的实际情况设置IP地址，在本例中，我们设置为192.168.137.1，子网掩码设置为255.255.255.0
4.查找树莓派IP地址
按下`WIN+R`快捷键，打开“运行”窗口，输入`cmd`进入命令行，再在命令行中输入`arp-a`查看网络IP地址，一般来说192.168.137.1下第一个IP就是树莓派的IP地址，如图1-1-7红框中所示。
![](images/txt002_11.jpg "pagenumber_ebook=16,pagenumber_book=8")
图1-1-7　在命令提示符下查看树莓派网络地址
找到树莓派网卡的IP地址之后，我们才能进行后续操作。如果找不到它的IP地址，也可以用`IPScanner`工具扫描IP。我们还可以通过修改SD卡中的`cmdline.txt`文件（在里面加入语句`ip=XXX.XXX.XXX.XXX`），将树莓派设置成静态IP地址，但必须把电脑的“本地连接”的静态IP地址与树莓派静态IP地址设置为同一号段，才能成功连接。
除了上述方法之外，还有一个办法，是直接使用网线将树莓派连接到无线路由器上，然后再从电脑登录无线路由器，从路由器上，查看树莓派自动获取到的IP地址。这种方法其实比上面方法更简单。获取到树莓派的IP地址后，同样可以从电脑控制树莓派，方法如下。
