

# 电机分类与原理

## 按运转速度划分
按运转速度划分：可分为高速电动机、低速电动机、恒速电动机、调速电动机。低速电动机又分为齿轮减速电动机、电磁减速电动机、力矩电动机和爪极同步电动机等。

## （3）直流电机的概念和原理
直流电动机是将直流电能转换为机械能的电动机。其分为两部分：定子与转子。注意：不要把换向极与换向器弄混淆了。定子包括：主磁极、机座、换向极、电刷装置等。转子包括：电枢铁芯、电枢绕组、换向器、轴和风扇等。直流电动机是依靠直流工作电压运行的电动机，广泛应用于收录机、录像机、影碟机、电动剃须刀、电吹风、电子表、玩具等。

## （4）步进电机的概念及原理
步进电机是将电脉冲信号转变为角位移或线位移的开环控制电机，是现代数字程序控制系统中的主要执行元件，应用得极为广泛。在非超载的情况下，电机的转速、停止的位置只取决于脉冲信号的频率和脉冲数，而不受负载变化的影响，当步进驱动器接收到一个脉冲信号，它就驱动步进电机按设定的方向转动一个固定的角度，称为“步距角”，它的旋转是以固定的角度一步一步运行的。可以通过控制脉冲个数来控制角位移量，从而达到准确定位的目的；同时可以通过控制脉冲频率来控制电机转动的速度和加速度，从而达到调速的目的。

# 活动二：L298N电机驱动电路
`L298N`是`SGS`公司的产品，内部包含4通道逻辑驱动电路。是一种二相和四相电机的专用驱动器，即内含两个H桥的高电压大电流双全桥式驱动器，接收标准TTL逻辑电平信号，可驱动46V、2A以下的电机。其引脚排列如图2-5-1中所示。
工作作电压：控制信号直流5V；电机电压直流3～46V（建议使用36V以下）
最大工作电流：2.5A
额定功率：25W
特点：具有信号指示，转速可调，抗干扰能力强，具有过电压和过电流保护。可单独控制两台直流电机。可单独控制一台步进电机。`PWM`脉宽平滑调速。可实现正反转。
`L298`可驱动两个电机，`OUTl`、`OUT2`和`OUT3`、`OUT4`之间分别接两个电动机。5、7、10、12脚接输入控制电平，控制电机的正反转，`ENA`，`ENB`接控制使能端，控制电机的停转。本章采用`L298N`电机驱动模块（如图2-5-1所示）驱动风扇。电机驱动参数如表2-5-1所示。
使用直流/步进两用驱动器可以驱动两台直流电机。分别为`M1`和`M2`。引脚`A`，`B`可用于输入`PWM`脉宽调制信号对电机进行调速控制。（如果无须调速可将两引脚接5V，使电机工作在最高速状态，即将短接帽短接）实现电机正反转就更容易了，输入信号端`IN1`接高电平，输入端`IN2`接低电平，电机`M1`正转（如果信号端`IN1`接低电平，`IN2`接高电平，电机`M1`反转。）。控制另一台电机是同样的方式，输入信号端`IN3`接高电平，输入端`IN4`接低电平，电机`M2`正转（反之则反转）。`PWM`信号端`A`控制`M1`调速，`PWM`信号端`B`控制`M2`调速。

# 活动四：PWM调速原理
`PWM`调速原理即脉冲宽度调制，是利用微处理器的数字输出来对模拟电路进行控制的一种非常有效的技术，广泛应用在从测量、通信到功率控制与变换的许多领域中。`PWM`控制技术以其控制简单，灵活和动态响应好的优点而成为电力电子技术最广泛应用的控制方式，也是人们研究的热点。
`PWM`调速是通过调整空占比来模拟不同电压值，从而控制加到电机两端的电压高低来实现调速，如图2-5-3所示。

# 项目六　智能避障小车

## 第一节　概念与原理
智能小车是一种能够通过编程手段完成特定任务的小型化机器人，它具有制作成本低廉，电路结构简单，程序调试方便等优点。智能小车具有很强的趣味性，深受广大机器人爱好者以及学生的喜爱。
本章主要讲述如何设计制作一款智能避障小车。小车避障通过安装在小车上的超声波传感器获取前方障碍物距离从而决策绕开障碍物，达到避障目的。

## 活动一：超声波传感器简介
### （1）超声波测距原理
超声波工作原理如图2-6-1所示。超声波模块包含一个发射端和一个接收端，超声波发射端发射出超声波信号，然后超声波电路模块开始进行时间计算，超声波信号在空气中以大约340m/s的速度进行传播，当超声波信号遇到有障碍物的情况下，超声波经过障碍物反射，超声波接收模块会接到一个反射信号。当收到反射信号后，停止计时，总共发送到接收到反射信号用时为`t`。笔者设超声波模块离障碍物距离为`H`，超声波在空气中经过反射总共传播距离为`2L`，我们可以通过测出超声波发射端到超声波接收端的距离是`2M`。根据图2-6-1所示的超声波工作原理，不难得出以下三个公式①②③。

![](images/txt016_1.jpg "pagenumber_ebook=74,pagenumber_book=66")

![](images/txt016_2.jpg "pagenumber_ebook=75,pagenumber_book=67")
通过①②式子可以计算出③式，障碍物离所在距离为`H`。由于超声波发射器和超声波接收器之间的距离很短，所测障碍物距离越远，那么`L`更趋向于`H`。避障机器人本身要求精度不是很高，所以在这里，我们直接忽略超声波发射器和接收器之间的距离`2M`，可以得出障碍物距离为`H = v * t / 2`。

### （2）HC-SR04超声波传感器
本章避障小车使用`HC-SR04`超声波传感器。工作原理如下：
（1）采用`I/O`口`TRIG`触发测距，给至少10us的高电平信号。
（2）模块自动发送8个40khz的方波，自动检测是否有信号返回。
（3）有信号返回，通过`I/O`口`ECHO`输出一个高电平，高电平持续的时间就是超声波从发射到返回的时间。测试距离=（高电平时间\*声速（340M/S））/2。
（4）本模块使用方法简单，一个控制口发一个10US以上的高电平，就可以在接收口等待高电平输出。一有输出就可以开定时器计时，当此口变为低电平时就可以读定时器的值，此时就为此次测距的时间，方可算出距离。如此不断的周期测，即可以达到你移动测量的值。

![](images/txt016_4.jpg "pagenumber_ebook=75,pagenumber_book=67")
图2-6-2　`HC-SR04`超声波传感器
`HC-SR04`超声波测距模块具有一个超声波发射器、接收器和控制电路组成，由单片机（`Arduino`）给`TRIG`口大于10us的高电平信号来触发测距。超声波测量传感器到障碍物的距离=高电平持续时间\*声音速度/2。
