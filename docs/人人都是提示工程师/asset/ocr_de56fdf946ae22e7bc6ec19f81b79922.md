转写，也就是从一种编程语言转换成另一种编程语言，那么这个工作交给 ChatGPT 也是非常合适的。例如，如果我们需要将上面的代码转换成 Go 语言代码，那么可以在 ChatGPT 中输入如下内容。

将下面的 Python 语言代码转换成 Go 语言代码：

```
import pymysql

# 连接 MySQL 数据库
conn = pymysql.connect(
    host='localhost',
    port=3306,
    user='root',
    password='123456',
    database='mydatabase'
)

# 读取公司名字信息
cursor = conn.cursor()
cursor.execute('SELECT name FROM company')
results = cursor.fetchall()

# 将结果转换为列表
stock_list = [result[0] for result in results]
```

ChatGPT 输出如下内容。

以下是 Go 语言的代码翻译版本：

```
package main

import (
    "database/sql"
    "fmt"

    "github.com/go-sql-driver/mysql"
)
```
