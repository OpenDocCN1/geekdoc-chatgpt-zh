+   - RNN+Attention：利用 RNN 和注意力（ attention ）机制提取关键词。通过将文本输入 RNN 中，得到每个词的表示。然后，通过注意力机制，对每个词进行加权，得到其在文本中的重要程度，选取权重最高的词作为关键词。

+   - Seq2Seq+RL：利用序列到序列模型（ Seq2Seq ）和强化学习（ Reinforcement Learning， RL ）提取关键词。首先，将文本分词并输入 Seq2Seq 模型中，得到每个词的概率分布。然后，利用 RL 算法对模型进行训练，使其输出的词序列能够最大化文本的关键信息。
