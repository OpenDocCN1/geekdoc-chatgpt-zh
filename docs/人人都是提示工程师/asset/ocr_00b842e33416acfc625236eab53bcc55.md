# 2.2.2 文件格式转换

如果我们要进行不同文件格式之间的转换，例如，将 csv 格式转换成 Markdown 格式，那么我们可以在 ChatGPT 里面输入以下内容。

将下面的 csv 格式的表格数据转换为 Markdown 格式，输出 Markdown 代码块

csv 格式表头如下：
变量，描述
stock_code, 股票代码
stock_name, 股票名字 (link)
stock_industry, 股票行业
stock_url, 股票链接
daily_up, 当日涨幅
half_year_decline, 半年跌幅
volume_ratio, 量比
stock_turn, 换手率
stock_date, 日期
IPO_price, 上市价格
IPO_date, 上市日期

ChatGPT 输出如下内容。

| 变量 | 描述 |
| --- | --- |
| stock_code | 股票代码 |
| stock_name | 股票名字 (link) |
| stock_industry | 股票行业 |
| stock_url | 股票链接 |
| daily_up | 当日涨幅 |
| half_year_decline | 半年跌幅 |
| volume_ratio | 量比 |
| stock_turn | 换手率 |
| stock_date | 日期 |
