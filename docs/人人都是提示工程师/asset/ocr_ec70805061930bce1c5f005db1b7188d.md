# 内容提要

本书旨在介绍提示（prompt）工程师的工作内容和相关技能。本书首先讲述提示工程的基本工作原理、提示工程师的常用工具；然后讨论提示的基础模式和进阶模式以及自然语言处理的基础知识；最后展示提示工程在办公、图像处理、软件开发、电商和金融领域的应用。

本书通俗易懂，不仅适合对提示工程师感兴趣或从事相关工作的读者阅读，还适合对自然语言处理和人工智能感兴趣的读者参考。
