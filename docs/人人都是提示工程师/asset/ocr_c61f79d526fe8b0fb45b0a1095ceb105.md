具体来说，对于每个主题，计算其中每个单词的权重，然后选择具有最高权重的单词作为关键词。

# 2）HDP 算法

层次狄利克雷过程（Hierarchical Dirichlet Process，HDP）算法是一种主题模型算法，可以自动学习主题数量。在 HDP 算法中，每个文档都有一个主题分布，而每个主题也有一个词分布。关键词提取可以通过选择具有高权重的单词作为关键词完成。

# 3）BTM 算法

二项式词对主题模型（Biterm Topic Model，BTM）算法是一种主题模型算法，可以对文本数据进行建模。在 BTM 算法中，每个文档都表示为一个二项式词对（biterm），每个二项式词对由两个单词组成。在 BTM 算法中，主题表示为单词的分布。关键词提取可以通过计算每个主题中单词的权重来完成。
