在人工智能领域，作为当前非常先进和强大的自然语言处理模型，ChatGPT为人类带来了前所未有的人机交互体验。ChatGPT可以根据用户输入的指令，快速生成对应的文本、图像或者代码等，大幅度提高工作效率。本书旨在介绍如何成为一名优秀的提示工程师，如何通过提示工程，轻松地完成各种工作任务，例如，写作、绘画、编程等。

# 本书主要内容

+   - 提示工程师的工作内容和相关技能；
+   - 提示的基础模式和进阶模式；
+   - 自然语言处理的背景知识；
+   - 提示工程在办公、图像处理、软件开发、电商和金融领域的应用。
