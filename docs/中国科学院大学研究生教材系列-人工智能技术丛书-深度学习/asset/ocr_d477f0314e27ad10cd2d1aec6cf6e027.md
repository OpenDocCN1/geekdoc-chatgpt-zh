假设图像 $I$ 的长度和宽度均为 $j$，对于图像 $I_0 = (j, j)$，下采样得到的图像尺寸为 $(j/2, j/2)$，上采样得到的图像尺寸为 $(2j, 2j)$，对图像进行连续 $k$ 次的下采样，可以获得一系列图像 $I_1 = (j/2, j/2), I_2 = (j/4, j/4), \cdots, I_k = (j/2^k, j/2^k)$。

$\mathcal{G}(I) = [I_0, I_1, \cdots, I_k]$ (5-6)

其中，$\mathcal{G}(I)$ 表示图像的高斯金字塔。在得到高斯金字塔后，拉普拉斯金字塔可表示如下：

$h_k = \mathcal{L}_k(I) = \mathcal{G}_k(I) - u(\mathcal{G}_{k+1}(I)) = I_k - u(I_{k+1})$ (5-7)

其中，拉普拉斯金字塔的第 $k$ 层等于高斯金字塔的第 $k$ 层 $\mathcal{G}_k(I)$ 减去高斯金字塔第 $(k+1)$ 层的上采样 $u(\mathcal{G}_{k+1}(I))$。

LAPGAN 将条件对抗生成网络 CGAN 集成到拉普拉斯金字塔结构中：

$\widetilde{T}_k = u(\widetilde{T}_{k+1}) + \widetilde{h}_k = u(\widetilde{T}_{k+1}) + G_k(z_k, u(\widetilde{T}_{k+1}))$ (5-8)

其中，$G_k$ 表示第 $k$ 个卷积神经网络，也就是生成器，高斯金字塔第 $k$ 层的重建等于它的第 $(k+1)$ 层上采样 $u(\widetilde{T}_{k+1})$ 加上拉普拉斯金字塔的第 $k$ 层 $\widetilde{h}_k$。除了最高层的生成器外，其余生成器 $G_0, G_1, \cdots, G_{k-1}$ 都是采用上一级的上采样和噪声作为联合输入。上采样的结果就是 LAPGAN 中的条件变量。

总之，迭代式生成优化是一种非常有效的 GAN 优化方法，可以在保持模型训练稳定性的同时，提高样本质量和模型的可解释性。这个方法可应用于各种 GAN 模型，包括图像生成、文本生成和视频生成等。

# 2. StackGAN
