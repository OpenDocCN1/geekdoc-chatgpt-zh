其中 \(\alpha\) 是一个需要学习的参数，当指定 \(\alpha = 0.01\) 时，又称为 Leakly ReLU；当 \(\alpha\) 通过高斯分布随机产生时，又称为随机化的 ReLU（Randomized ReLU，RReLU）。

PReLU 激活函数的优点是比 Sigmoid 激活函数收敛快，解决了 ReLU 激活函数的“神经元死亡”问题。PReLU 激活函数的缺点是需要再学习一个参数 \(\alpha\)，工作量变大。

# 5. ELU 激活函数

为了解决“神经元死亡”问题，也可以使用 ELU 激活函数，其函数定义为

\(f(x) = \begin{cases} \alpha(e^x - 1), & x < 0 \\ x, & x \geqslant 0 \end{cases}, x \in (-\infty, +\infty)\) (2-11)

# 6. Maxout 激活函数

Maxout 激活函数实际上是增加了一层全连接神经网络，神经元个数 \(k\) 自定，其函数定义为

\(h_i(x) = \max_{j \in \{1, \dots, k\}} z_{ij}, \quad \text{其中} \quad z_{ij} = x^T w_{ij} + b_{ij}\) (2-12)

# 7. 卷积神经网络中的激活函数选择

卷积神经网络中，尽量不要使用 Sigmoid 激活函数，因为它的梯度小于 1，将导致梯度消失问题。因此，一般首先选用 ReLU 激活函数，使用较小的学习率，以免造成神经元死亡的情况。如果 ReLU 激活函数失效，考虑使用 Leaky ReLU、PReLU、ELU 或者 Maxout，此时一般情况下都可以解决。
