其中，下标 m 和 n 分别表示卷积核中值的行索引与列索引，M 和 N 分别表示卷积核的高度与宽度，在本节示例（见图 2-26 和图 2-27）中，M = N = 2。

![](bbox=[0.22, 0.15, 0.72, 0.33])

然后计算第 2 项 \(\frac{\partial a^{l-1}_{i,j}}{\partial \text{net}^{l-1}_{i,j}}\)，因为 \(a^{l-1}_{i,j} = f^{l-1}(\text{net}^{l-1}_{i,j})\)，因此只需要求第 \((l-1)\) 层激活函数的导数即可，即

\(\frac{\partial a^{l-1}_{i,j}}{\partial \text{net}^{l-1}_{i,j}} = f'(\text{net}^{l-1}_{i,j})\) (2-17)

# 2. 参数梯度的计算

计算得到每一层的误差项后，还需要计算卷积核的权重和偏置参数的梯度，如下所示：

\(\nabla W^l_{i,j} = \frac{\partial E}{\partial W^l_{i,j}} = \sum_m \sum_n \frac{\partial E}{\partial \text{net}^{l'}_{m,n}} \frac{\partial \text{net}^{l'}_{m,n}}{\partial W^l_{i,j}} = \sum_m \sum_n \delta_{m,n} a^{l-1}_{i+m,j+n}\) (2-18)

\(\nabla W^l_{b} = \frac{\partial E}{\partial W^l_{b}} = \sum_m \sum_n \frac{\partial E}{\partial \text{net}^{l'}_{m,n}} \frac{\partial \text{net}^{l'}_{m,n}}{\partial W^l_{b}} = \sum_m \sum_n \delta_{m,n}\) (2-19)

同样，不进行详细的推导，仅给出了计算结论。得到每个权重参数的梯度后，则可以根据梯度下降算法来更新每个权重。

在上述示例中，假设输入图像的大小为 3×3，卷积核大小为 2×2，得到的输出特征图大小为 2×2。对于更大尺寸的图像输入和卷积核，上述公式仍然适用。
