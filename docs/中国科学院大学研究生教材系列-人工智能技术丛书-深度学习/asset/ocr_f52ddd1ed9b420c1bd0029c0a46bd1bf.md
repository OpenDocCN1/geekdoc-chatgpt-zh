# 3. 数据填充

从前面的卷积操作示例可以看到，用一个 3x3 的卷积核对 5x5 的图像进行卷积，只有 3x3 个可能的位置能够进行匹配。因此，会得到一个 3x3 的输出。如果有一个 nxn 的图像，使用 fxf 的卷积核进行卷积操作，那么卷积输出的大小为 (n-f+1)x(n-f+1)。

但是这样的话，卷积操作存在两个显而易见的缺点：1) 随着卷积层数的增多，图像会变得越来越小，到最后可能只有 1x1 大小，这也就限制了模型的复杂度；2) 观察前面的卷积操作示例，对于输入图像中间的数据，有许多 3x3 的区域与之重叠，而对于图像边缘的数据，则只被利用了一次，这也意味着在进行卷积操作过程中，丢失了图像边缘的很多信息。
