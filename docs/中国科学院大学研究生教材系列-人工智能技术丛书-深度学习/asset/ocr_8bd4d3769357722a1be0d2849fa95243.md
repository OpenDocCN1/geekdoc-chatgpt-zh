# 图 4-36 PureT的总体框架

该图展示了 PureT 模型的总体框架，主要包含以下模块和流程：

1.  **输入层**:
   - 图像输入尺寸为 384 x 384 x 3。
   - 通过 Swin Transformer 处理，输出特征图尺寸为 12 x 12 x 1536。

2.  **特征分支**:
   - 左分支：网络特征 (12 x 12 x 512) 经过线性层得到 $v_c^g$。
   - 右分支：全局特征 (1 x 512) 经过均值池化得到 $v_c$。

3.  **增强编码器 (Refining Encoder)**:
   - 标注有“表示参数共享”。
   - 内部结构包含掩码、自注意力 7、多头交替块 8 等模块。

4.  **解码器 (Decoder)**:
   - 输入单词序列: $x_1, x_2, ..., x_{l-1}$。
   - 输出单词序列: $x_2, x_3, ..., x_l$。
   - 内部包含掩码、多头交替块 8、自注意力 7 等模块。

5.  **预测融合模块 (Pre-Fusion)**:
   - 输入 $X_1^l$。
   - 处理流程包含向量内积、ReLU、多头交替块 8、向量内积。
   - 输出 $X_1^{pl}$。

6.  **输出层**:
   - 包含线性层和 Softmax 层，输出最终结果。
