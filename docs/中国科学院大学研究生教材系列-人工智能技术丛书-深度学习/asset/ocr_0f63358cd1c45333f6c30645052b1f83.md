散度的值非负，因此满足下列不等式：

\( E_{q(x_{1:T})}[-\log p_\theta(x_0)] \leqslant E_{q(x_{1:T})}[-\log p_\theta(x_0) + D_{\text{KL}}(q(x_{1:T}|x_0) \| p_\theta(x_{1:T}|x_0))] \) (6-57)

其中， KL 散度的定义如下：

\( D_{\text{KL}}(q(x_{1:T}|x_0) \| p_\theta(x_{1:T}|x_0)) = \sum \left[ q(x_{1:T}|x_0) \cdot \log \frac{q(x_{1:T}|x_0)}{p_\theta(x_{1:T}|x_0)} \right] \n = E_{q(x_{1:T}|x_0)} \left[ \log \frac{q(x_{1:T}|x_0)}{p_\theta(x_{1:T}|x_0)} \right] \) (6-58)

将公式 (6-58) 代入公式 (6-57) 中，并应用贝叶斯公式进行化简，有

\( E_{q(x_{1:T})}[-\log p_\theta(x_0)] \leqslant E_{q(x_{1:T})} \left[ -\log p_\theta(x_0) + E_{q(x_{1:T}|x_0)} \left[ \log \frac{q(x_{1:T}|x_0)}{p_\theta(x_{1:T}|x_0)} \right] \right] \n = E_{q(x_{1:T})} \left[ -\log p_\theta(x_0) + E_{q(x_{1:T}|x_0)} \left[ \log \frac{q(x_{1:T}|x_0)}{\underbrace{p_\theta(x_{0,T})/p_\theta(x_0)}_{\text{由贝叶斯公式}}} \right] \right] \n = E_{q(x_{1:T})} \left[ -\log p_\theta(x_0) + E_{q(x_{1:T}|x_0)} \left[ \log \frac{q(x_{1:T}|x_0)}{p_\theta(x_{0,T})} + \log p_\theta(x_0) \right] \right] \n = E_{q(x_{1:T})} \left[ E_{q(x_{1:T}|x_0)} \left[ \log \frac{q(x_{1:T}|x_0)}{p_\theta(x_{0,T})} \right] \right] \n = E_{q(x_{0,T})} \left[ \log \frac{q(x_{1:T}|x_0)}{p_\theta(x_{0,T})} \right] = L_{\text{VLB}} \) (6-59)

此时， DDPM 的优化目标可以从最小化 \( L \) 转换为最小化 \( L_{\text{VLB}} \)，由前向过程和逆向过程的介绍可知 \( q(x_{1:T}|x_0) = \Pi_{i=1}^T q(x_t|x_{t-1}), p_\theta(x_{0:T}) = p_\theta(x_T) \Pi_{i=1}^T p_\theta(x_{i-1}|x_i) \)，代入公式 (6-59) 可进一步推导导出：

\( L_{\text{VLB}} = E_{q(x_{0:T})} \left[ \log \frac{q(x_{1:T}|x_0)}{p_\theta(x_{0:T})} \right] \n = E_{q(x_{0:T})} \left[ \log \frac{\Pi_{i=1}^T q(x_t|x_{i-1})}{p_\theta(x_T) \Pi_{i=1}^T p_\theta(x_{i-1}|x_i)} \right] \n = E_{q(x_{0:T})} \left[ -\log p_\theta(x_T) + \sum_{i=1}^T \log \frac{q(x_i|x_{i-1})}{p_\theta(x_{i-1}|x_i)} \right] \n = E_{q(x_{0:T})} \left[ -\log p_\theta(x_T) + \sum_{i=2}^T \log \frac{q(x_i|x_{i-1})}{p_\theta(x_{i-1}|x_i)} + \log \frac{q(x_1|x_0)}{p_\theta(x_0|x_1)} \right] \n = E_{q(x_{0:T})} \left[ -\log p_\theta(x_T) + \sum_{i=2}^T \log \left( \frac{\underbrace{q(x_{i-1}|x_i, x_0)q(x_i|x_0)}_{\text{由公式 (6-44)}}}{p_\theta(x_{i-1}|x_i)q(x_{i-1}|x_0)} \right) + \log \frac{q(x_1|x_0)}{p_\theta(x_0|x_1)} \right] \)
