# 3. 噪声

噪声（Noise）度量样本真实值与标签值的偏离程度，刻画了学习问题本身的难度。$y_j (j=1, 2, \cdots, m)$ 表示真实值，$l_j (j=1, 2, \cdots, m)$ 表示标签值。

单个样本 $x_j$ 的噪声计算公式如下：

$\varepsilon^2 = (l_j - y_j)^2$ (7-5)

多个样本的噪声计算公式如下：

$\bar{\varepsilon}^2 = E[\{(l_j - y_j)^2\}] , j=1, 2, \cdots, m$ (7-6)
