
## Self-Attention Layer概述

Self-Attention Layer是为了解决`RNN`、`LSTM`等常用于处理序列化数据的网络结构无法在`GPU`中并行加速度计算的问题。

如图4.2所示，Self-Attention将输入（`Input`）转化成`Token Embedding`+`Segment Embedding`+`Position Embedding`。因为有时训练样本由两句话组成，因此`[CLS]`用来分类输入的两句话是否有上下文关系，而`[SEP]`是用来分开两句话的标志符。

其中，因为这里输入的是英文单词，所以在灌入模型之前，需要用BERT源码的`Tokenization`工具对每个单词进行分词，分词后的形式如图4.2中输入的playing转换成play+##ing。因为英文词汇表是通过词根与词缀的组合来新增单词语义的，所以笔者选择用分词方法减少整体的词汇表长度。

![](Images/image00210.jpeg)

图4.2　Self-Attention的输入^[1]

如果是中文字符，则输入不需要分词，整段话的每个字用空格隔开即可。值得注意的是，模型是无法处理文本字符的，所以不管是英文还是中文，算法都需要通过预训练模型BERT自带的字典`vocab.txt`将每个字或者单词转换成字典索引（id）输入。

`Segment Embedding`的目的：有些任务是两句话一起放入输入`X`，而Segment便是用来区分这两句话的。输入使用`[SEP]`作为标志符号，`[CLS]`用来分类输入的两句话是否有上下文关系。

`Position Embedding`的目的：因为网络结构没有`RNN`或者`LSTM`，所以算法无法得到序列的位置信息，需要构建一个`Position Embedding`。构建`Position Embedding`有两种方法：第1种是BERT初始化一个`Position Embedding`，然后通过训练将其学习出来；第2种是`Transformers`通过制定规则来构建一个`Position Embedding`，即使用正弦函数，位置维度对应曲线，方便序列之间的选对位置，使用正弦比余弦好的原因是可以在训练过程中将原本的序列外拓成比原来序列还要长的序列，如式（4.1）和式（4.2）所示。

### 4.2.5 Layer Normalization

Self-Attention的输出会经过层归一化，为什么选择层归一化而不是批归一化（`Batch Normalization`）？此时，应先对模型输入的数据形状有个直观的认识，当一批（`Batch`）数据输入模型时，形状是长方体，如图4.5所示，大小为（`batch_size`，`max_len`，`embedding`），其中`batch_size`为批数，`max_len`为每批数据的序列最大长度，`embedding`则为每个单词或者字的权重维度大小。

因此，批归一化是对每批数据的每列做归一化，相当于对批数据里相同位置的字或者单词的字向量做归一化；而层归一化则是对批数据的每行做归一化，相当于对每句话的字向量做归一化。显然，层归一化更加符合处理文本的直觉。

### 4.2.6 BERT预训练

BERT预训练如图4.6所示。预训练过程是生成BERT模型的过程。

![](Images/image00218.jpeg)

图4.6　预训练与微调过程^[1]

一般来讲，个人用不着自己训练一个BERT预训练模型，而是直接调用模型的权重，进行微调（`Fine-Tune`）以适应当前特定任务，但读者可以了解一下BERT是怎么训练出来的。输入`X`是自注意层的输入，利用字典将每个字或者单词用数字表示，并转换成`Token Embedding`+`Segment Embedding`+`Position Embedding`。序列的长度一般为512或者1024，若不足，则用`[PAD]`补充。句子开头第1个位置用`[CLS]`表示，如果输入两句话，则用`[SEP]`隔开。

（1）`MaskLM`策略：对于输入`X`，15%的字或者英文单词采用随机掩盖策略。对于这15%的字或者英文单词，80%的概率用`[mask]`替换序列中的某个字或者英文单词，10%的概率替换序列中的某个字或者英文单词，10%的概率不做任何变换，模型通过预测被掩盖的字或者英文单词（`MaskLM`）的方式来获得字符的文本信息。

（2）`NSP`策略：预测两句话之间是否有顺序关系（Next Sentence Prediction，`NSP`）。

预训练采用两种预训练方式：`MaskLM`策略和`NSP`策略，两者同时进行，并且预训练语料总量为330亿语料。

这里需要补充说明的是，NLP的预训练模型与计算机视觉的预训练模型有些许不同，NLP的预训练方式采用的是无监督学习，即不需要人工打标签，而计算机视觉则需要对图像进行人工分类。因为NLP的预训练正如笔者所说，只是预测被掩盖的字或者英文单词，以及判断两段话是否有顺序关系，这些只需写个小程序就可以轻松得到相应的标签，无须人工进行大量标记。

最后经过大量语料的无监督学习，算法人员得到了BERT预训练模型，BERT自带字典`vocab.txt`的每个字或者英文单词都被768维度的权重所表示。当算法人员需要完成特定任务时，若对它们的权重进行微调，则能更好地适应任务。

## 4.3 其他预训练模型

无监督学习给预训练模型带来了显著提升，但要确定方法的哪些方面贡献最大是具有挑战性的。因为训练在计算上是昂贵的，限制了可以完成的调整量，并且经常使用大小不同的私人训练数据进行，从而限制了测量建模进展影响的能力。为此，很多人针对BERT模型的相关缺陷进行了优化，提出了在某一任务领域优于BERT的预训练模型。

### 4.3.1 RoBERTa

Liu Yinhan等^[3]认为超参数的选择对最终结果有重大影响，为此他们提出了BERT预训练的重复研究，其中包括对超参数调整和训练集大小影响的仔细评估。最终，他们发现了BERT预训练的不足，并提出了一种改进的模型来训练BERT模型（A Robustly Optimized BERT Pre-training Approach，`RoBERTa`），该模型可以媲美或超过所有Post-BERT的性能，而且对超参数与训练集的修改也很简单，包括：

（1）训练模型时间更长，批数据的大小更大，数据更多。

（2）删除下一句预测目标（Next Sentence Prediction）。

（3）对较长序列的训练。

（4）动态掩盖应用于训练数据的掩盖模式。在BERT源码中，随机掩盖和替换在开始时只执行一次，并在训练期间保存，可以将其看成静态掩盖。BERT的预训练依赖于随机掩盖和预测被掩盖的字或者单词。为了避免在每个迭代中对每个训练实例使用相同的掩盖，文献^[4]的作者将训练数据重复10次，以便在40个迭代中以10种不同的方式对每个序列进行掩码，因此，每个训练序列在训练过程中都会看到4次相同的掩盖。他们将静态掩盖与动态掩盖进行了比较，证明了动态掩盖的有效性。

（5）他们还收集了一个大型新数据集（`CC-NEWS`），其大小与其他私有数据集相当，以更好地控制训练集的大小。

（6）使用Sennrich等提出的Byte-Pair Encoding（`BPE`）字符编码，它是字符级和单词级表示之间的混合体，可以处理自然语言语料库中常见的大词汇，避免训练数据出现更多的`[UNK]`标记符，影响预训练模型的性能。其中，`[UNK]`标记符表示当在BERT自带字典`vocab.txt`中找不到某个字或者英文单词时用`[UNK]`表示。

### 4.3.3 BERT_WWM

BERT已在各种NLP任务中进行改进，因此基于BERT的改进模型接踵而至，带有全字掩盖（Whole Word Masking，WWM）的BERT升级版本`BERT_WWM`便是其中之一，它减轻了预训练过程中掩盖部分Word Piece字符的弊端。其中，Word Piece字符其实是笔者在4.2.1节介绍的英文单词分词，在将英文单词输入模型之前，需要将其转换成词根+词缀的形式，如Playing转换成Play+##ing。如果使用原生BERT的随机掩盖，可能会掩盖Play或者##ing或者同时掩盖两者，但如果使用全字掩盖，则一定掩盖两者。

### 4.3.4 ALBERT

`ALBERT`^[7]的整体原理与BERT的原理差不多。最大的特点是它减少了参数量，并维持了BERT的性能，但它只是降低了空间复杂度，把参数量从108兆降到了12兆，但并没有降低时间复杂度。用`ALBERT`进行预测的速度并没有加快，甚至在同等性能的模型对比中还慢了。也就是说，`ALBERT`降低了参数量，但并不减少计算量。

那么，`ALBERT`是怎么降低参数量的呢？主要通过矩阵分解（Factorized Embedding Parameterization）和跨层参数共享（Cross-layer Parameter Sharing）两大机制。

#### 1. 矩阵分解

BERT的权重大小为词汇表的长度`V`乘以每个字／单词权重隐藏层大小`H`：`V×H`。

`ALBERT`通过参数`E`来分解这个权重矩阵，让整体权重参数变小，将`V×H`转换成`V×E+E×H`，当`E`远远小于`H`时，模型所需的参数将大大减少。实验证明参数`E=128`时，效果最佳。

#### 2. 跨层参数共享

通过分析，矩阵分解并不是降低模型参数量的最大贡献者，跨层参数共享是`ALBERT`的重中之重，因为它的存在减少了BERT模型的绝大部分参数。

跨层参数共享的机制非常简单，单独用一个自注意层循环12次，每层的参数都一样。这样算法就可以用1层的参数量来表示12层的参数，为此，模型的参数大大降低。

为什么这个机制能有效？笔者曾经给BERT的每层参数做了分析，发现每层的参数基本相似，因此将它们直接共享了。在保持模型性能下降不太厉害的同时，选择所有层次参数共享，降低的参数量是最多的，所以，`ALBERT`默认所有层次参数共享。

很多BERT类的模型在预训练的过程中放弃了`NSP`任务，因为`NSP`任务不仅没给下游任务的效果带来提升，反而降低了整体的性能。为此，`ALBERT`同样也放弃了`NSP`任务，改用`SOP`（Sentence Order Prediction）任务作为预训练任务。

`SOP`任务也很简单，它的正例和`NSP`任务一致（判断两句话是否有顺序关系），反例则是判断两句话是否为反序关系。

举个例子。

正例：1．朱元璋建立的明朝。2．朱元璋处决了蓝玉。

反例：1．朱元璋处决了蓝玉。2．朱元璋建立的明朝。

虽然`ALBERT`降低了参数量，但它并没有提高预测速度。出现这种情况的原因很简单，BERT由12个自注意层堆叠而成，`ALBERT`同样也由12个自注意层堆叠而成，在预测时，张量（`Tensor`）都需要经过12个自注意层，所以速度并没有提升。

### 4.3.5 Electra

`Electra`^[8]采用的预训练方式是GAN思想主导的预训练，BERT直接采用15%的`[MASK]`掩盖某些字符（`Token`），让模型在预训练过程中预测被掩盖的字符。

而`Electra`则将这个思想用在GAN的生成器中，先随机掩盖一些字符，然后用一个生成器（`Generator`）对被掩盖的字符生成相应的伪字符（Fake Token），而判别器（`Discriminator`，也就是`Electra`）用来判断哪些字符被更换过，文献^[8]的作者将这个预训练任务称为`RTD`（Replaced Token Detection），如图4.10所示。

文献^[8]的主要贡献是提出了一种最新的BERT类模型的预训练方式——`RTD`。关键思想是训练文本判别器，以区分输入令牌与由小型生成器网络产生的高质量负样本。与`MLM`（Masked Language Modeling，也就是BERT的预训练方式）相比，它的预训练目标具有更高的计算效率，并且可以在下游任务上实现更高的性能。即使使用相对较少的计算量，也能很好地工作。

### 4.3.6 NEZHA

预训练语言模型由于具有通过对大型语料库进行预训练来捕获文本中深层上下文信息的能力，因此在各种自然语言理解（Nature Language Understanding，`NLU`）任务中均取得了巨大成功，然而，当前中文预训练模型BERT仍然存在很大的优化空间。

为此，在中文语料库上进行预训练的语言模型`NEZHA`^[9]（NEural contextualiZed representation for cHinese lAnguage understanding）针对BERT在中文数据集上的不足进行了优化。其中包括作为有效位置编码方案的功能相对位置编码、全字掩盖策略、混合精度训练及用于训练模型的`LAMB`优化器。

#### 3. 混合精度训练

混合精度训练是指在训练中采用混合精度。混合精度训练技术可以将训练速度提高2～3倍，还可以减少模型的空间消耗，从而使用更大的批数据进行训练，而按照惯例，深度神经网络的训练使用参与训练的`FP32`精度。
