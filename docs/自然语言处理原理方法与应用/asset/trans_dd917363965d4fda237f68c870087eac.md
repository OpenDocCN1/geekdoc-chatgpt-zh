# 第9章 命名实体识别

在自然语言处理领域，在文本中提取能够表征全文信息的词语是当前的热点方向，因此，命名实体识别（`NER`）技术在文本搜索、文本推荐、知识图谱构建及机器智能问答等领域都起着至关重要的作用。近年来，由于深度学习能够将离散的字符令牌（`Token`）矩阵转换成纬度低但信息量富集的词向量矩阵，因此`NER`算法使用词向量矩阵能够达到最佳性能。预训练模型与`NER`技术的结合是本章展开描述的要点。

## 9.1 NER技术的发展现状

`NER`技术的发展现状如图9.1所示。类似地，`NER`技术的迭代也离不开始于规则，发展壮大于深度学习的依赖路径。当前深度学习的发展不仅诞生了简单的`Word2Vec`词向量模型，也迭代出了能够解决一词多义问题的类`BERT`模型，而且类`BERT`模型的发展进一步演进了对其模型层次信息的研究，这一切都是为了提升`NER`技术的准确性。

## 9.2 命名实体识别的定义

命名实体识别是指识别文本中预先定义好类别的实体，一般的实体类别包括地名、人名、机构名、数值等。例如：“明朝建立于14世纪，开国皇帝是朱元璋。”本书从这句话中提取出的实体如图9.2所示。

命名实体识别数据集的标签一般使用`BIO`格式进行标注，`B`代表实体的头位置，`I`代表实体的中间位置，`O`则代表非实体标签。

### 9.3.1 预训练模型

为了让`NER`模型能够更好地表征文本的语义信息，选择优秀的预训练模型至关重要。随着深度学习技术的不断发展，当前已经出现了许多表征能力非常强的预训练模型，如`RoBERTa`、`BERT-WWM`与`NEZHA`等，而`NEZHA`中文预训练模型的诞生刷新了多项`NLP`任务的纪录，其主要是基于`BERT`模型的缺陷与不足进行改进，汇聚了当前中文预训练模型的优点进行预训练，如图9.5所示，从而得到一个语义表征能力强的预训练模型。

![](Images/image00475.jpeg)

图9.5　`NEZHA`模型的预训练策略

首先，`NEZHA`预训练模型通过在`Transformer`模型中使用相对位置编码来补充`BERT`模型因矩阵转化而消失的位置信息；其次，其通过将随机掩盖策略改为全字掩盖策略（`WWM`），如图9.6所示，进而帮助模型在预训练过程中捕捉短语与词语的语义信息；最后，`NEZHA`模型采用混合精度训练与`LAMB`优化器两种策略来降低预训练过程中的时空复杂度，并且保证了微调过程的性能。

![](Images/image00476.jpeg)

图9.6　全字掩盖策略

### 9.3.2 下接结构

`BiLSTM`与`BiGRU`结构在第7章已经进行了详细介绍，本节将对`R-Transformer`与`IDCNN`模型结构进行介绍。`R-Transformer`模型在`Transformer`模型结构上添加了改进的循环神经网络（`Local RNN`）。`RNN`长期以来一直是序列建模的主要选择，然而，它严重受到两个问题的困扰：无法捕获非常长期的依赖关系和无法并行化顺序计算过程。而`Transformer`与`Local RNN`的结合可以有效地捕获序列中的局部结构和全局长期依赖关系，使用任何无须位置信息，模型结构如图9.7所示。其中，下层是`Local RNN`，它依次处理本地窗口中的位置信息；中间层是捕捉全局长期依赖的多头自注意力层；上层是进行非线性特征变换的前向网络。这3个网络通过向量相加和层归一化操作连接。带虚线的圆圈是输入序列的填充。

![](Images/image00477.jpeg)

图9.7　`R-Transformer`模型结构

另外，原始`RNN`会在每个位置保持隐藏状态信息，而`Local RNN`则仅对局部窗口内的位置进行操作。在每个位置，`Local RNN`都会产生一个隐藏状态，该状态表示在该位置结束的本地窗口中的信息。读者可将两种结构理解为`Local RNN`包含原始`RNN`的关系，原始`RNN`捕获全局信息，而`Local RNN`则通过局部窗口捕获局部信息，其局部窗口大小可以通过超参数进行设置，在极端的情况下，`Local RNN`也可以变为原始`RNN`，只需将局部窗口的大小设置成全局窗口大小。

`IDCNN`和`CNN`一样，但是其通过在卷积核之间增加“空洞”（0），使`IDCNN`的卷积在不需要池化操作的情况下增加感受野，增大模型看到信息的范围。它的缺点是会丢失局部信息，虽然看得比较远，但是有时远距离的信息并没有相关性。然而，缺点有时又是优点，在需要解决长距离信息依赖的语音和文本任务中，`IDCNN`的性能表现相较优良。`IDCNN`模型结构如图9.8所示。

![](Images/image00478.jpeg)

图9.8　`IDCNN`模型结构

### 9.3.3 条件随机场

`CRF`通过`NER`模型下接结构传来的`Hidden`值计算文本序列的分数，并将`BIO`格式的真实`Token`标签与当前预测的分数进行损失计算。`NER`模型通过梯度下降不断进行迭代，最终收敛到最优值。算法人员可以利用得到的`NER`模型进行命名实体识别，模型的预测过程只需利用维特比解码算法替换`CRF`结构，对下接结构传来的`Hidden`值进行解码，得到一个最优的解码序列，再通过规则将解码所得的`BIO`格式进行转化，最终抽出真实的实体。

# 第10章 文本生成

文本生成技术是自然语言处理领域的另一重要技术。应用者可以利用既定信息与文本生成模型生成满足特定目标的文本序列。文本生成模型的应用场景丰富，如生成式阅读理解、人机对话或者智能写作等。当前深度学习的发展也推动了该项技术的进步，越来越多高可用的文本生成模型诞生，提高各行业效率，服务智能化社会。

## 10.1 文本生成的发展现状

文本生成的技术路线发展与其他`NLP`技术路线类似，均从简单的规则逐步发展至大型深度神经网络。当然，文本生成显然难于其他`NLP`技术，因为文本生成技术的预测目标并不在既定的文本中，其需要根据既定文本生成符合目标的文本，而阅读理解、命名实体识别等技术则是通过抽取既定文本里的相应文本段达成预测的目标。
