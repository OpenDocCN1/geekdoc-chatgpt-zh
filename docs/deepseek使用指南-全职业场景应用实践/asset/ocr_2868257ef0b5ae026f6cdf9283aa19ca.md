# 2. 时间复杂度分析

# 理论推导

+   - 时间复杂度：该实现使用了一个简单的循环来计算斐波那契数列的第n项。每次循环只进行常数时间的操作（加法赋值），因此时间复杂度为 O(n)。
+   - 空间复杂度：我们只使用了常数个变量来存储中间结果。因此空间复杂度为 O(1)。

# 实际测试对比

为了验证理论推导的正确性，我们可以通过实际测试比较斐波那契 n 的增加，计算时间的增长情况。

```
python
import time

def test.fibonacci_performance():
    n_values = [10, 100, 1000, 10000, 100000]
    for n in n_values:
        start_time = time.time()
        fibonacci(n)
        end_time = time.time()
        print(f"计算斐波那契数列的第{n}项耗时：{(end_time - start_time) * 1000:.6f}秒")

# 调用性能测试
print("性能测试结果：")
test.fibonacci_performance()
```
