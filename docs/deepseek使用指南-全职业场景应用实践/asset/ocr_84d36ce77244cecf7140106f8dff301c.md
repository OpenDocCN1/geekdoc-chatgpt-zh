# 2. 用符号为 AI 划重点

当人类遇到大篇幅的信息时，往往容易抓不住重点，这时就需要用不同的符号进行区隔，增强整体内容的可读性。对于 DeepSeek 这样的 AI 工具也是一样的，当输入内容较多时，建议用不同的符号对不同类型的内容进行区隔，以下是一些实例。
