# #### ***【 开场 3 秒抓眼球 】***

** 画面 **：你穿白大褂戴听诊器，用新闻联播腔严肃发言。

** 突然 **：背后传来娃的嚎哭，你瞬间掰开白大褂露出沾满奶渍的睡衣。
** 恼镜头 **：“信他个鬼！今天教你看懂妈圈黑话！”

# #### ***【 第一部分：名词爆破 】***
