# # 图 2-1  V3 和 R1 的区别

R1 厉害的地方在于，它会有一个思考的过程，并把这个过程展示给你看，最后的结果相比 V3 更详细，就像人类经过思考得出的答案会比未经思考的更优质。在 V3 中，只是列举了每天去哪、交通选择什么、住宿可以住在哪；而 R1 会告诉你最佳的花期、气温、携带什么物件、早餐吃什么美食等，考虑得更周到也更细致。
