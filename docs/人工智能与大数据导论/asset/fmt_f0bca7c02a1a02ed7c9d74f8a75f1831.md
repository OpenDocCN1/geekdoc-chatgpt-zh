# 前　言

大数据技术和人工智能对现代社会产生巨大的影响，因此学生应该在增长技术应用技能的同时，还应该具备运用利用人工智能和大数据技术进行逻辑思维的能力，激发学生创建美好世界的情感。

本书立足于大数据技术和人工智能的现有水平、社会实际应用，着眼于帮助学生在未来高科技社会中更好地找到自己的位置。本书分为两大部分，分为通识篇和应用实战篇。结合专业特色，挑选的应用案例大多基于真实场景、目标明确，且考虑不同专业学生的实际能力，活动的可操作性强。所有案例都是基于“真实世界的真实解决方案”这一教育理念，挑选一些贴近学生学习生活实际、体现人工智能与大数据技术核心的应用实例。本书采用Python作为讲授大数据和人工智能的载体。Python语言语法简单、功能强大、编写简洁、可读性好。通过学习体验编程的理念、理解程序的运行流程，引导学生体验、领悟人工智能技术思想和方法，实现人工智能教育的价值。

本教材的编写改变了传统以讲授为主的学科式教材体例，突出以行业导向、任务驱动、问题探究为主的自主学习单式的教与学。教材融合知识与技能的同时，提供微视频等学习资料，引导学生自主探究，充分体现学生主体、教师主导的教育理念，教材的编写让学习任务更具体，行业要求更贴近，职业技能更有效，能力评价更深入，实现行业项目要求与岗位操作的有机融合。

本书由福建船政交通职业学院曾凌静、黄金凤任主编。第一部分通识篇，第1、4、5章由曾凌静编写，第2章由杨薇薇编写，第3章由张传娟编写，第6章由黄金凤编写。第二部分应用实战篇，第7、8章由林君萍编写，第9、10章由陈小娥编写，第11、12、13章以及附录由曾凌静编写，第14章由黄金凤编写。

福建华众互联网科技有限公司、福州鑫桥信息科技有限公司等企业提供了行业案例，在此表示感谢。

由于作者水平有限，加之时间仓促，书中难免存在疏漏和不足之处，恳请广大读者批评指正。

编　者

2020年4月
