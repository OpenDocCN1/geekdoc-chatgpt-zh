# ### Synthesia Synthesia

Synthesia是一家软件公司，由来自 UCL、斯坦福大学、TUM和剑桥大学的研究人员和企业家团队于 2017 年创立。该公司结合了机器学习技术，为没有演员，电影摄制组，工作室或摄影机的客户创建了AI人物形象，用户可以从现有演员库中选择（演员们从出现的视频中获得酬劳），也可以上传自己的视频来创建虚拟形象。然后用户可以输入台词，可以合成音频，也可以输入音频，并且设置人物大小位置、背景图案等，最终生成视频，而无需任何视频创建或编辑技能。
