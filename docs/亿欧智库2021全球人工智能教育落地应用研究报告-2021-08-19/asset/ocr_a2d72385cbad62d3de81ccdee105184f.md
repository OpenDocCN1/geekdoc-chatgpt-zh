# 2、 东西方AI教育侧重方向大相径庭，东方重系统，西方重交互

# 3、 全球AI教育行业发展越成熟，政策的引导越重要

从全球人工智能教育行业较发达的国家/地区来看，AI教育行业更发达的国家出台的政策、措施更细分，行业发展越成熟，政策的引导越重要。
