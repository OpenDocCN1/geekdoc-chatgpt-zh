# # 大力智能 大力智能

大力智能是大力教育旗下的教育硬件品牌，致力于用科技赋能教育，通过创新技术和设计理念的结合，为家庭教育场景提供智能化桌面解决方案。而在家庭教育场景中，人工智能技术的应用一直是被忽视的领域，新时代家长和新时代学生对于智能学习产品的需求亦发生变化。

2020年10月，大力智能发布首款教育创新硬件产品——大力智能学习灯，成为智能学习灯品类的行业开创者。产品拥有领先的智能护眼科技与创新的自主学习智能工具，针对家庭教育中的书桌场景，创新地将台灯与智能系统结合，激发学生的学习兴趣和自驱力。

亿欧智库：大力智能灯AI 技术应用及产品优势

动律光护眼算法：专为长时间用眼定制的动律光护眼算法，每60分钟进行高达37次的细腻亮度调节，让睡眠肌保持自然运动，减缓视疲劳。

智能调光 找到人眼更舒适的亮度曲线，让孩子的眼睛更放松

智能双摄：配备前置和顶置摄像头，可精准识别拍摄对象。顶置摄像头可以流畅识别用户手势、中英文生字词等，帮助孩子解决学习问题

交互门槛低 语音、手势轻松互动，方便获取学习所属资源

智能学习辅助功能：语音/指尖查词、古诗词查询、练字教学、课本点读、口语评测、翻译等涵盖（语音语义、手势识别、图像识别、自然语言处理、内容检索/CQC过滤等技术）

场景深度定制 适应特定人群、特定场景，根据孩子和所学内容实现定制

双端视频通话：孩子和家长可以在平等沟通的基础上通过台灯进行语音和视频通话，实现双端互通，及时反馈和鼓励，科学合理参与孩子的学习和成长

绿色安全 周密过滤信息，保护隐私，让绿色安全有价值的内容服务学生和家长

口语评测：精准检测句子、单词的发音问题，给出评分反馈及个性化教学点评，致力于高效提升学习者发音水平，同时还支持自动判停、流式打分等功能

大力智能革新了产品形态和技术，践行科学的教育理念，推动家庭学习的数字化和智能化，探索并重构现有的学习方式，用科技的力量激发孩子的学习兴趣，帮助孩子养成良好的习惯，培养自主、自信、有爱的“披风少年”。
