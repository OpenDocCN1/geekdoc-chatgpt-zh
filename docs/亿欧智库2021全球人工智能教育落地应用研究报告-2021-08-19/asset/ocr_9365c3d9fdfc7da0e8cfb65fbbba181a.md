# 三、全球人工智能教育行业分析

+   - 印度人工智能企业融资额分布比较平均，其中融资额在1千万至五千万美元的企业为最多，为13家，5千万至1亿美元和5百万至1千万融资额的企业最少，为4家。

+   - 印度AI教育企业融资额普遍偏大，而其主要原因是印度的智能教育企业收到了政府和资方的更大关注。由于COVID-19所造成的印度全境封锁则更增加了印度受教育群体对众多电子技术产品的需求。
