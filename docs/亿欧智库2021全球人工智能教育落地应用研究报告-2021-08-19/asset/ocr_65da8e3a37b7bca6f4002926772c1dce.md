# Quizizz

Quizizz是一家教育游戏化公司，能够帮助老师快速地创建具有游戏化元素的小测验和交互式课件，能够及时收集到学生反馈，节约老师评分评测时间。此外，老师们也可以“获取到”其他老师在Quizizz上贡献创建的新内容。Quizizz收到150个国际/地区的教育工作者的喜爱。

# 亿欧智库：Quizizz为教师提供的额外解决方案

+   - 可以将交互式视频和音频添加到任何测验或课程中 在测验、课程和答案解释中添加视频和音频，以支持在家和课堂上的学习
+   - 支持每位教师并获得优先支持。获取工具和支持以帮助教师入门并在过程中回答问题
+   - 定制1000万多个测验和课程 将图书馆中的任何内容与学习者的问题结合起来，几秒钟内创建互动活动
+   - 简化远程学习 提前计划，延长截止日期，并为错过的学生重新开放作业
+   - 在全校范围内合作并按标准进行评估。创建符合标准的内容，添加共同编辑并在学校或地区内共享资源。
+   - 创建题库和自适应重考 给每个学生一组不同的问题，这些问题会自动生成自适应重考

目前在Quizizz平台上的课程涵盖了计算机科学、英语、数学、科学、社会研究、世界语言和艺术创造等。

如今，老师们在Quizizz上可以使用到超过3000多万个小测验或交互式课件内容，题材涉及从小学数学到职业教育、技术教育等非常广泛的范围。仅仅在2020年一年里，学生们在Quizizz平台上就总共回答了130多亿个问题。
