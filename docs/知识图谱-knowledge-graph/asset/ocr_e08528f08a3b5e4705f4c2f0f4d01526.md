# 第十章 知识问答与对话

近年来，知识图谱发展迅猛，它们不仅在数据规模和领域数量上快速增长，而且很多高质量数据可以免费获取。这些高质量的结构化知识数据在各个应用中发挥着重要作用，例如商品推荐、商业智能、决策支持等。作为一种描述自然知识和社会知识的重要载体，知识图谱最直接和最重要的任务是满足用户的精确信息需求，提供个性化知识服务。其中，致力于回答各种类型问题的问答和对话系统是最典型的任务之一。例如，人们经常希望计算机系统能自动回答如下问题：

+   （1）屠呦呦是哪里人？
+   （2）华为公司的创始人毕业于哪所大学？
+   （3）被称为“六朝古都”的是中国哪座城市？
+   （4）今天晚上有哪些从北京到上海的国航航班？
