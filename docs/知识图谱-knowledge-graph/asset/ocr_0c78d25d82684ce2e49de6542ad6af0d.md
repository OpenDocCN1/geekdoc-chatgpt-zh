就没有……”“不……不……” “除非……不……” “除非……才……” “除非……否则……” 。在演绎推理过程中，这种细微的描述可能会导致推理方向乃至推理结果的变化，例如“只有认错才能改正”和“只要认错就一定能改正”是两个完全不同的意思。

与归纳推理类似，演绎推理也是一个庞大的体系，很难在有限的篇幅内穷尽所有演绎推理的特性，而在计算机或人工智能领域，演绎推理对应着使用已有的知识或规则推导出未知知识的过程。

# 9.2.2 确定性推理与不确定性推理

# 9.2.2.1 确定性逻辑推理

确定性逻辑推理也简称为逻辑推理，它具有完备的推理过程和充分的表达能力，可以严格地按照专家预先定义好的规则准确地推导出最终的结论，也就是说在推理的起始点和规则集合固定的情况下，结论也是固定的，因此确定性逻辑推理并没有准确性的评价，如何快速自动地推导出结论是确定性逻辑推理主要的研究目标。

确定性逻辑推理研究工作大都专注于对基于某种逻辑定义下的自动推理算法的研发。例如，基于可满足性的 GSAT[186] 和 WALKSAT[419] 算法用于求解命题逻辑推理；而以 rete 算法[161] 为代表的基于前向链接的算法，以及被应用于 Prolog 的反向链接算法[104]，都被应用于一阶逻辑的推理。自 1879 年 Gottlob Frege 建立起首个基于完整一阶逻辑的推理系统开始，繁多的自动推理系统被建立起来，其中有面向某一特殊领域的专家推理系统，如用于数学定理证明的 VAMPIRE[395]，或与领域无关的推理架构，如 SOAR[259]，以及可编程的通用逻辑语言设计工具 Prolog[98]，其中 Prolog 被广泛应用于多种逻辑自动推理器及专家系统的设计。

在 21 世纪初期，随着 W3C 提出资源描述框架（Resource Description Framework, RDF[资源 9-1]）的标准，以及语义网（Semantic Web）[52] 和开放链接数据（Linked Open Data）等项目的出现与发展，基于 RDF 三元组的确定性逻辑推理技术得以进一步的发展。这些工作中具有影响力的有欧盟主导的知识计算平台 LARKC（Large Knowledge Collider[资源 9-2]）（全名为大规模知识加速器），主要是构建分布式知识推理的平台，类似系统还有 WebPIE[469]——一个基于网络本体语言（Web Ontology Language, OWL）的大规模分布式推理系统。之后，为了权衡语义表达能力和
