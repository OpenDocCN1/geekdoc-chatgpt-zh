# 3. 数据更新

数据更新是指更新 RDF 图中指定三元组的值。和 SQL 不同, SPARQL 没有定义 UPDATE 操作；也就是说 SPARQL 语言没有直接更新已有数据的方法。但是，可以通过组合 INSERT DATA 语句和 DELETE DATA 语句来实现该功能。例如，修改图 8.12 中三元组（ns: 费米, ns: 出生日期, “1902/09/29”）的值 “1902/09/29” 为 “1901/09/29”，可以先从 RDF 图中删除该三元组，然后插入一条新的三元组，其 SPARQL 代码为

```
prefix ns: <http://example.org/ns#>
```
