# 1.3 知识图谱类型

在介绍知识图谱的类型之前，我们有必要首先介绍知识的有关概念和分类。其实，至今为止，对于知识没有一个统一而明确的界定，知识可以被认为是人类在几千年的进化过程中对于物质世界以及精神世界探索结果的总和。根据柏拉图的定义，知识一定是被验证过的、正确的，而且被人们所相信的。知识多种多样，第 1.1 节提到知识总体上可以分为陈述性知识和过程性知识，实际上，我们还可以从另外多个角度对已有的知识进行分类，这一分类肯定是不完全的，这里只是抛砖引玉式地讨论相关概念和分类。

根据知识的主客观性，可以把知识分为事实性（或者客观性）知识和主观性知识。事实性知识通常是指那些确定性的、不随状态的变化而改变的知识，例如：“中华人民共和国的首都都是北京”。而主观性知识通常指某个个人或群体的情感信息，例如：“大部分人都觉得苹果手机太贵了”这句话中包含了用户对于苹果手机的意见和态度，但是这一态度会随着评论者的变化而变化。在本书中，如果没有特别说明，我们讨论的都是事实性知识。

根据知识的变化性质，已有的知识可以分为静态知识和动态知识。静态知识不随时间、空间的变化而变化，例如：某个人的出生日期。而动态知识指那些随时间、空间的变化而变化的知识，例如：“美国总统，上一任是奥巴马，这一任是特朗普”。事件是动态知识的重要组成部分。

另外，我们也可以把知识分为领域知识、百科知识、场景知识、语言知识、常识知识等。领域知识通常指的是某个领域内特有的知识，例如：法律知识、金融知识等。相较而言，百科知识指的是那些涵盖各个行业、领域的通用知识，例如：人物、机构、地点等。场景知识是指在某个特定场景下或者需要完成某项任务时所需要的知识，例如：在订机票过程中需要提供的信息、盖房子的步骤等。语言知识指的是那些语言层面上的知识，例如：Microsoft 的缩写是 MS、乔丹和佐敦具有同指关系、减肥和瘦身是同义词等。常识知识指的是那些大家都认可的知识，例如：狗有四条腿、鸟会飞等。常识也是人工智能领域的一大难点问题，目前对于常识的边界、常识如何表示等问题在研究界还存在很大的争论，常识的存储和利用也仍然是一个难点问题。
