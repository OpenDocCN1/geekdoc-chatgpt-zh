
公式表示，来对知识图谱中的关系路径或者逻辑规则的身体部分进行分布式的表示。这类方法将普通原子关系扩展到一个关系序列上，认为知识图谱中一个关系序列的向量表示可以用来预测两个实体间是否存在这个关系序列下的路径，而这正是马尔可夫逻辑网等概率推理模型进行规则实例化的目的，因此合并表示学习与逻辑推理的思路是可行的。由此，将逻辑规则表示成前提 ⇒ 假设，按照 Horn 子句的定义，规则身体部分的前提应该是一条知识图谱上的路径。如公式 9.14，TransE 将关系表示成在实体分布式空间中的转移，并假设头实体和关系的向量之和应该在实体空间中接近尾实体，即 $E_h + E_r = E_t$。若换一种方式思考，一个元组本身是长度为 1 的路径，也是长度为 1 的规则的身体部分，那么扩展 TransE 的思想，将长度为 1 的路径 $r$ 推广成长度任意的路径，则可以得到当路径 $p(h,t)$ 存在于知识图谱中时有如下等式：

$E_h + E_p = E_t$  (9.15)

在扩展的 TransE 的假设下，再继续探索路径以及路径中关系类型之间的关联。例如，对于路径 $h \xrightarrow{r_1} x \xrightarrow{r_2} t$，根据 TransE 的假设可以得到：$E_h + E_{r_1} = E_x$ 和 $E_x + E_{r_2} = E_t$。之后重写第二个等式得到 $E_x = E_t - E_{r_2}$，将重写后的等式代入到第一个等式中消掉中间变量则得到 $E_h + E_{r_1} + E_{r_2} = E_t$，对比之前的等式 9.15，可以发现 $E_p = E_{r_1} + E_{r_2}$，也就是说在 TransE 的假设下路径的向量表示约等于路径中含有的关系向量之和，更普遍地有，

$E_p = \sum_{r_i \in p} E_{r_i}$  (9.16)

更进一步地推导，我们可以得到更有趣的结论。对于一个三元组 $r(h,t)$，有 $E_h + E_r = E_t$，若 $h$ 和 $t$ 之间存在一条路径 $P$，有 $E_h + E_p = E_t$，则可以得到 $E_r = E_p$，也就是说若一个三元组中的两个实体间存在一条路径，那么这条路径的向量表示应该接近于三元组关系的向量表示。

第一个工作是通过串行地合并知识图谱嵌入式表示和概率逻辑推理的方式$^{[481]}$，首先利用表示学习运算速度快的特点，过滤掉低概率的答案，并把答案缩小在一个较小的候选集内，如图 9.5 中的 (a) 部分所示。这一步骤在很大程度上减小了计算复杂度，例如需要推理的问题是“谁是奥巴马的母亲？”，那么所有知识图谱中的人类实体都有可能是候选答案（这里我们不对性别做特殊限制，因为这需要人类某种规则化的先验知识，并不是所有的问题类型都含有这种先验）。

之后，利用逻辑推理准确的特点，再对候选集中的每一个候选答案进行精确的推理。这一步骤可以使用 9.3.2.2 中的任何一种不确定性推理方法，这里就不再展开说明，图 9.5 中的（b）部分表示了这一过程。

此外，这个工作提出了将在表示学习中获得的先验注入到后续的逻辑推理中的设想，以辅助逻辑推理更准确地进行。实质上也是一种数据驱动的方法，直观地，新的候选集中的候选假设有着不同的候选得分，有时还会差别很大，从表示学习方法中获得较高得分的候选，在后续逻辑推理中应当具有一定的优势。例如，当使用表示学习的方法计算出以下候选的得分：

- 国籍（奥巴马，美国）：0.8
- 国籍（奥巴马，中国）：0.2

前者的得分远远高于后者，那么如何捕捉这种先验信息呢？可以利用表示学习在候选选择过程中对候选的打分作为先验加入到基于马尔可夫逻辑网算法的随机游走中，改变之前完全随机图中所有节点均匀分布的情况，令之前得分较高的候选假设有更大的概率出现在被采样到的规则中，以提高它们成立的可能性，由此“国籍（奥巴马，美国）”采样到规则实例的概率就比“国籍（奥巴马，中国）”高了四倍，若规则是有益于推理出假设的，那么“国籍（奥巴马，美国）”成立的概率就会更大。实现这一想法的具体方法是：通过改变随机游走过程中的状态转移概率的计算方法，将前一步骤表示学习计算出的相似度得分进行某种转换，作为与状态转移概率正相关的一个组件，并在随机游走算法框架下，依然确保它的稳定性。

另一个工作则是直接将知识图谱中的分布式表示加入到逻辑规则挖掘的过程当中 [480]，以动态地指导随机游走的方向，令其挖掘出更多更好的能够推理出目标的逻辑规则，因此这一方法也被称为目标导向的随机游走。推理目标是所要挖掘的规则要用于推理的内容，例如，要为推理国籍（奥巴马，美国）挖掘规则，那么三元组国籍（奥巴马，美国）就是推理目标，用 ρ = R(H; T) 来表示目标。在推理目标 ρ 时，此方法总是能指引随机游走算法找到能推理出 ρ 的有用规则。与上一个方法相同，此方法也是通过改变随机游走的状态转移概率来实现的，而不同的是，上一个方法是人为地设计了一种先验的使用方法，而此方法则使用数据驱动的方法让算法不断地学习如何使用知识图谱的分布式表示。更高的层次来说，这一改变更像是从固定策略的启发式搜索方法向探索策略的强化学习的升级。整体的学习算法如下：

```
算法 3 集成模型训练算法
输入： 知识库 K 的三元组集合 Ξ
输出： Ψ, W, F
1: for ρ = R(H, T) ∈ Ξ do
2:   重复 ρ 导向的随机游走从 H 到 t
3:   用 L_{rw}^t 损失更新 Ψ
4:   if t = T then
5:     F = F ∪ f_p
6:   end if
7:   用 ρ 计算 L_{inf} 和 L_{rw}^{inf}
8:   用 L_{inf} 更新 W
9:   用 L_{rw}^{inf} 更新 Ψ
10: end for
11: 移除 F 中 w_f 很小的 f
12: 输出 Ψ, W, F
```

该算法描述了对这一集成模型的训练过程，其中 Ξ 是用作训练的三元组集合，Ψ 是势函数，F 是规则的集合，f_p 是从路径 p 中生成的逻辑规则，而 H、T、t 是知识库中的实体。为了预测 ρ = R(H, T)，算法先运行多轮的随机游走，每一轮中都可以找到一条路径 p_{Ht} (行 2)。之后算法根据 t 是否等于 T 来计算损失 L_{rw}^t 并更新势函数的参数 Ψ，也就是知识库元素的向量表示（行 3）。在随机游走后，推理模型使用已获得的逻辑规则去预测目标 ρ，并计算误差 L_{inf} 和 L_{rw}^{inf} (行 7)。最终规则权重 W 和势函数 Ψ 一起通过 L_{inf} 和 L_{rw}^{inf} 来更新（行 8-9）。在训练完成后，算法从 F 中移除具有低权重的规则（行 11），并输出获得的规则集合和权重。在完成规则的结构和权重学习后，可以使用类似的方法推理新的链接假设，过程中不再更新任何参数。基于目标导向随机游走的方法计算复杂度为 O(M_r Snd + M_i W)，其中 n 为每个实体平均相邻的实体个数，而 d 为分布式向量的维度，相比于基本的随机游走算法，这一算法在随机游走阶段的复杂度提升了 nd 倍，但由于 n 和 d 都是很小的常数，如 Freebase 中 n ≈ 30，知识库元素的向量维度也一般为 50 或 100，因此基于目标导向随机游走算法的效率也是很高的，并且在一定时间内召回有益规则总数上比较，这一方法也优于基本的随机游走算法。详细内容请阅读文献 [480]。

### 9.6 常识知识推理

什么是常识，在人工智能以及自然语言处理领域至今也没有一个统一的定义，通常我们认为常识是普遍的、普通大众都应该知晓的，是正常社会中心智健全的成年人所应该具备的基本知识，包括生存技能、基本劳作技能、基础的自然科学以及人文社会科学知识等。例如鸟会飞、鱼会游、兔子通常具有四条腿，而白兔则具有一双红色的眼睛。常识本身虽然简单，但是对于常识的由来，常识的传播方式，常识的置信度评估，常识在计算机中的表示，这些都是很难且目前没有被解决的问题。因此，对常识知识进行推理是一项重要而前沿的研究领域。例如，回答以下问题，就需要使用常识进行推理：

一棵树从太阳中储存能量到它的果实中，请问这一过程是物理反应还是化学反应？

对于该问题，我们需要知道植物通过光合作用生成并存储能量，而光合作用是将太阳能转化为化学能，并且有化学能参与的转化是化学反应。整个推理过程中使用到了光合作用以及化学反应的常识性定义。但由于常识目前没有统一的表示方法，因此，常识的推理形式也取决于常识的表示方法。

ConceptNet^[441] 是一个著名的常识知识库，它以三元组的形式来表示一部分常识，并且给出了这类常识在自然语言中的表达方式，例如，下面的示例三元组是 ConceptNet 对动物知识进行的描述：

- （兔子，痛恨，狼）
- （兔子，惧怕，狮）
- （兔子，惧怕，猎人）
- （兔子，惧怕，老虎）
- （兔子，喜欢，胡萝卜）
- （老虎，有，牙齿）
- （老虎，在，山洞）
- （老虎，惧怕，恐龙）
- （老虎，喜欢，抢地盘）
- （老虎，是一种，保育类动物）
- （老虎，痛恨，猎枪）
- （老虎，喜欢，肉）

这种三元组的形式组成的知识图谱结构，令 ConceptNet 完全适用于之前在三元组事实知识图谱上开发的推理方法，因此在 ConceptNet 中，常识的推理与正常的知识图谱推理没有什么不同。例如我们可以从以上的三元组中总结出：“兔子惧怕老虎，又因为老虎喜欢吃肉，因此老虎会吃兔子。”

另一个著名的常识库是 Cyc^[270]^，Cyc 是一个致力于将各个领域本体及常识知识进行集成，并在此基础上实现知识推理的人工智能项目。Cyc 目前包括超过 630000 个概念，38000 种关系的类型，超过 700 万条常识性的断言。Cyc 有着自己复杂的语法定义，包括对概念、谓词甚至逻辑的定义，Cyc 的表示方法被称为 CycL 语言，是一种以一阶逻辑为基础，伴有部分高阶逻辑的语言，类似于 Lisp 语言。Cyc 中概念包括个体、集合和函数，常以 “#$” 为开头，例如 #$MapleTree 和 #$massOfObject 等，而变量以 “?” 开头，如 ?OBJ 等。谓词也具有类似的表示，例如 #$isa、#$likesAsFriend、#$GovernmentOf 等。Cyc 表示常识的方法是用括号表示一条常识，并且谓词排在最前边，例如：

(#$isa #$EMRG #$Color)    EMRG 是一种颜色
(#$genls #$Tree-ThePlant #$Plant)    所有的树都是植物
(#$isa #$Obama #$USPresident)    奥巴马是美国总统

为了使用 Cyc 进行推理，Cyc 定义了自己的逻辑符号，包括 #$not, #$and, #$or 以及 #$implies。这样就可以形成一般的命题，如下面的例子：

```
(#$not
    (#$colorOfObject #$FredsBike #$RedColor)
)

(#$implies
    (#$and
    (#$isa ?OBJ ?SUBSET)
    (#$genls ?SUBSET ?SUPERSET))
    (#$isa ?OBJ ?SUPERSET)
)
```

前一个式子表示 #$FredsBike 的颜色不是红色，而后一个式子表示如果 ?OBJ 属于 ?SUBSET 并且 ?SUBSET 是 ?SUPERSET 的子集，则 ?OBJ 属于 ?SUPERSET。因此在 Cyc 这种精确的逻辑表示下，可以进行准确的逻辑推理。

### 10.1 自动问答概述

自动问答技术可以追溯到计算机诞生初期的二十世纪五六十年代，其中，代表性的系统包括 Baseball[180] 和 Lunar[490]。Baseball 是最早的以“未来的人机交互将是以自然语言进行的交流方式”为目标构建的系统。Lunar 系统是为了方便月球地质学家对美国阿波罗计划从月球带来的大量岩石和土壤数据进行查询、比较和分析而开发的问答系统。这些问答系统大多针对特定领域设计，一般处理的数据规模不大，并且只接受限定表达形式、限定领域的自然语言问题，不需要过多依赖自然语言处理技术，其性能与系统针对特定领域的定制程度有关。这类系统因为没有足够的知识资源而难以在实际环境中应用。

随着互联网技术的发展，人们希望利用日益丰富的网络数据资源解决问答系统中的数据匮乏问题，特别是二十世纪九十年代中期在 TREC-QA[120] 评测任务推动下，检索式问答技术取得了显著的进展，这种系统的主要特点是：利用浅层自然语言处理技术分析问题，并利用信息检索等技术从大规模文本或网页库中抽取答案。但是，由于用户需求的多样性和自然语言的复杂性，这种浅层

语义分析技术难以准确理解用户查询意图进而提取出有用的信息①，因此，这类检索式问答技术也未能得到广泛应用。

长期以来，问答技术发展的两大困难是缺乏高质量的知识资源和高效的自然语言分析技术。随着 Web 2.0 的兴起，包括 Wikipedia、Yelp [资源10-1]、大众点评 [资源10-2] 等应用在内的众多基于用户（协同）生成内容（user generated content, UGC）的互联网服务产生了越来越多的高质量数据资源，以此为基础，大量的知识库以自动或半自动的方式构建了起来，如 Freebase、YAGO、DBpedia 等。另外，随着近年来统计机器学习方法的兴起和发展，自然语言处理中的各个任务都取得了突飞猛进的发展，无论是基于语义分析的知识工程还是大规模开放域的问句理解都取得了长足的进步。可以说，科研人员正逐步攻克问答和对话系统中最核心的知识资源缺失问题和自然语言处理问题。

近年来，不少产品取得的成功引起了社会公众对自动问答技术的关注。例如，IBM 研发的问答机器人 Watson 在美国智力竞赛节目 Jeopardy! 中战胜人类选手；苹果公司研发的 Siri 系统在智能手机中的真实应用取得了良好效果。实际上，Siri 中的大部分问题都交由知识计算引擎 Wolfram Alpha 处理。Watson 和 Wolfram Alpha 成功的关键因素包括：① 丰富的知识资源：Watson 定义了自己的知识框架，并从大约 2 亿个包括图书、新闻、电影剧本、辞海、文选和《世界图书百科全书》等的资料中抽取知识；Wolfram Alpha 针对各个领域定义知识结构并抽取大量事实；② 强大的语义分析技术：Watson 开发的 DeepQA 系统集成了统计机器学习、句法分析、主题分析、信息抽取、知识库集成和知识推理等深层语义分析技术；Wolfram Alpha 利用了 Wolfram 早期研发的数学工具包 Mathematica，它是一种能够进行代数计算、符号和数值计算、可视化和统计功能的高效知识计算平台。

值得注意的是，以问答和对话技术为核心的聊天机器人近年来在国内发展得如火如荼，除了已面世的微软公司的“小冰”、百度公司的“度秘”和华为公司的“小诺”，众多企业和研究团体也在该领域发力突破。这类聊天机器人从目前来看虽然还不能解决太多真实信息需求，但是以用户喜闻乐见的方式把问答和对话技术的研究进展带给大众，是助力其走向成熟的一个关键步骤。
