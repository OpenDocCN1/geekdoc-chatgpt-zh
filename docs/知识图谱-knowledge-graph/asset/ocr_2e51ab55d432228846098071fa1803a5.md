命题逻辑很适合进行简单的推理，从上面的例子中很容易抽象出如下的命题逻辑表达式的形式：

有背鳍 (x) ∧ 属于 (x, 鲸目) ⇒ 属于 (x, 海豚科)

这是典型的演绎推理的例子，也可以转化成如下所示标准的三段论推理。
背部有背鳍的鲸鱼都属于海豚科。
虎鲸背部有背鳍。
虎鲸属于海豚科。

关于逻辑推理方法将会在知识推理这一节中进行详细介绍。

谓词逻辑可分为一阶谓词逻辑和高阶谓词逻辑，它们的主要区别在于是否可以量化谓词或集合。由于高阶谓词逻辑过于复杂，实践中应用很少，本书不做具体介绍。

一阶谓词逻辑又可简称为一阶逻辑，它在命题逻辑的基础上增加了量词的概念。更具体地，一阶逻辑的基本语法元素是表示对象、关系和函数的符号，其中对象对应常量符号，关系对应谓词符号，函数对应函数符号。对象是指一些事物的个体或类别，如虎鲸、水蜜桃、汤姆·科鲁兹、燕子李三等。关系或谓词是指一种映射，例如兄弟就是一个谓词，对于对象燕子李三，兄弟（燕子李三，x）是谓词对对象的操作，其中 x 可以是燕子李四等一个或多个对象，也可以空。与谓词不同，函数是代表全函数的一种特殊的谓词形式，它要求每一个定义域中的对象具有一个映射值，例如国籍就是一个函数词，因为一般情况下每个人都有且只有一个国籍，汤姆·科鲁兹是函数词国籍定义域中的一个对象，那么谓词逻辑要求国籍（汤姆·科鲁兹，x）的映射必须在值域中。

相比于命题逻辑，谓词逻辑的优势是可以表达对象集合的属性，而不用逐一列举所有对象，通过量词能够实现对对象集合的描述，一阶谓词逻辑中有两种量词：全称量词（∀）和存在量词（∃）。

全称量词（∀）表示集合的全部，例如所有的海豚都有背鳍，就可以用全称谓词方便地表示出来：

∀x 海豚 (x) ⇒ x 有背鳍

∀ 通常读为“对于所有的……”，符号 x 称为变量，一般用小写字母表示。形式化地，对于任意的含有 x 的逻辑表达式 P，语句 ∀x P 表示对于每一个对象 x，P 为真。
