# 10.2.2.1 有监督方法

语义解析的任务是把一种结构的数据（串行结构的自然语言句子或树形结构的句法树）转换成另一种结构的数据（逻辑表达式）。与自然语言处理中的其他任务一样，早期的语义解析方法大都依赖于人工规则（见下一小节）。随着二十世纪九十年代统计方法的兴起，人们开始利用机器学习模型从已知数据中学习显式或隐式的模式，期望对未知数据进行更好的预测。统计语义解析方法正是利用机器学习模型从已有数据中学习解析模型，不同的学习方法依赖于不同的学习数据。

![](bbox=[0.11, 0.29, 0.33, 0.38])

典型的监督数据为图 10.5 中的形式，即 < 自然语言问句，逻辑表达式 > 的集合①。如何学习结构预测模型，对于新的问句（如“有哪些城市靠近大上海？”），生成其对应的逻辑表达式形式（如 λx.next_to(x, Shanghai_City) ∧ City(x)）。目前的方法主要根据语义组合原则构造完整的语义表示结果。语义组合原则是 Gottlob Frege 提出的理论[376]：一条复杂语句的含义由其子句的含义和它们的语义组合原则确定 [资源 10-10]。语义解析基于语义组合原则得到句子（问句）的形式化表示结果。例如，“有哪些城市靠近大上海？”是由“哪些城市”和“靠近大上海”的语义与它们之间的组合关系“且”确定的。因此，语义解析就包含两个需要解决的关键问题：

+   1) What states border Texas?
+   λx.state(x) ∧ borders(x, texas)
+   
+   2) What is the largest state?
+   argmax(λx.state(x), λx.size(x))
+   
+   3) What states border the state that borders the most states?
+   λx.state(x) ∧ borders(x, argmax(λy.state(y), λy.count(λz.state(z) ∧ borders(y,z))))
+   
+   4) Utah borders Idaho.
+   borders(utah, idaho)
