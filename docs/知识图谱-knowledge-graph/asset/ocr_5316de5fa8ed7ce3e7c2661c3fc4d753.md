一阶谓词逻辑和 lambda 演算是最常用的语义形式化表示模型，这种逻辑表示形式不是完全针对自然语言问答系统开发设计的，例如表示的语义结构与自然语言的句法结构有明显的结构差异（见文献 [284] 中的图 2），为了更好地面向知识库问答系统进行问句的语义解析，Percy Liang 等人 [285] 提出了依赖组合语义（Dependency-Based Compositional Semantics, DCS）并用于对问句在知识图谱中的语义进行形式化表示。他们使用了一种新的逻辑表示语言：Lambda DCS [283]，并在此基础上提出了相应的语义组合方法，该方法比组合范畴语法中的辞典项规则简单得多，只包含 join 和 intersect 两种组合规则。

在 DCS 中，逻辑形式以树结构表示，被称为 DCS 树，这种树结构与句子的句法结构平行。因此，相比较于一阶谓词逻辑和 λ 演算表示形式，DCS 树更容易解析和学习。DCS 树中的每个节点都表示了一个限制性满足问题（CSP），它可以通过有效的方式获得各个节点的目标值（根节点的目标值即为该逻辑形式的结果）。DCS 最早用于限定领域的知识库问答中 [284]，取得了包括 Geo880 在内的多个测试集中的最好效果。2013 年开始，Berant 和 Percy Liang 等人 [49, 50] 将 DCS 用于回答面向 Freebase 的问题，不仅提出了依赖组合语义方法和模型，还开源了相对应的完整知识库问答系统和评测平台 SEMPRE [资源10-11]。通过该开源项目，人们可以持续改进和提高问句解析的效果和知识库问答的性能 [478]。

# 2. 语义辞典构造

为了自动学习自然语言文本到逻辑表达式之间的映射关系，大多数方法都需要如下这种“句子-逻辑表示式”对标注数据：

句子： 哪些城市靠近大上海？

逻辑表达式： λx.City(x) ∧ next_to(x, Shanghai_City)

但是，从标注数据中只知道整个句子对应的整个逻辑表达式，而解析方法需要的是句子的片段（如词、短语等）和细粒度的逻辑表达式之间的匹配关系，例如，词语“靠近”对应 λx.λy.next_to(x, Shanghai_City)，短语“哪些城市”对应 λx.City(x)。

对于给定的句子“杭州靠近上海？”和逻辑表达式 next_to(Hangzhou_City, 上海_City)，我们希望得到如下辞典：

+   - 杭州 := NP : Hangzhou_City
+   - 上海 := NP : Shanghai_City
+   - 靠近 := (S \ NP)/NP : λx.λy.next_to(x, y)
