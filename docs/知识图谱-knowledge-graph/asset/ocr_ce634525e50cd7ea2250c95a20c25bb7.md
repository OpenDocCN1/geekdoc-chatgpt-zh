```
算法 3 集成模型训练算法
输入： 知识库 K 的三元组集合 Ξ
输出： Ψ, W, F
1: for ρ = R(H, T) ∈ Ξ do
2:   重复 ρ 导向的随机游走从 H 到 t
3:   用 L_{rw}^t 损失更新 Ψ
4:   if t = T then
5:     F = F ∪ f_p
6:   end if
7:   用 ρ 计算 L_{inf} 和 L_{rw}^{inf}
8:   用 L_{inf} 更新 W
9:   用 L_{rw}^{inf} 更新 Ψ
10: end for
11: 移除 F 中 w_f 很小的 f
12: 输出 Ψ, W, F
```

该算法描述了对这一集成模型的训练过程，其中 Ξ 是用作训练的三元组集合，Ψ 是势函数，F 是规则的集合，f_p 是从路径 p 中生成的逻辑规则，而 H、T、t 是知识库中的实体。为了预测 ρ = R(H, T)，算法先运行多轮的随机游走，每一轮中都可以找到一条路径 p_{Ht} (行 2)。之后算法根据 t 是否等于 T 来计算损失 L_{rw}^t 并更新势函数的参数 Ψ，也就是知识库元素的向量表示（行 3）。在随机游走后，推理模型使用已获得的逻辑规则去预测目标 ρ，并计算误差 L_{inf} 和 L_{rw}^{inf} (行 7)。最终规则权重 W 和势函数 Ψ 一起通过 L_{inf} 和 L_{rw}^{inf} 来更新（行 8-9）。在训练完成后，算法从 F 中移除具有低权重的规则（行 11），并输出获得的规则集合和权重。在完成规则的结构和权重学习后，可以使用类似的方法推理新的链接假设，过程中不再更新任何参数。基于目标导向随机游走的方
