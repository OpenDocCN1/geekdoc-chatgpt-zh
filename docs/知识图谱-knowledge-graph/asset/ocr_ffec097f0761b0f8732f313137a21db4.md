# 2. 数据删除

数据删除则是从 RDF 图中删除一些三元组。SPARQL 通过 DELETE DATA 语句完成该功能，其基本语法为

DELETE DATA 三元组数据

其中三元组数据可以是多个三元组。对于给定的每个三元组，如果其在 RDF 图中，则将其从图中删除，否则忽略该三元组。例如，从图 8.10 中删除三元组（ ns: 奥本海默 ns: 类型 ns: 物理学家 ）的 SPARQL 语句为

```
prefix ns: <http://example.org/ns#>
DELETE DATA {
    ns:奥本海默  ns:类型  ns:物理学家 .
}
```

执行该语句后，图 8.10 中图谱及对应 RDF 数据如图 8.11 所示。

若想删除“奥本海默”对应的节点，则需使用的 SPARQL 语句为

```
prefix ns: <http://example.org/ns#>
DELETE WHERE {
    ns:奥本海默  ?p  ?o .
    ?s  ?p  ns:奥本海默 .
}
```

执行该语句后，图 8.11 中图谱及对应 RDF 数据如图 8.12 所示。
