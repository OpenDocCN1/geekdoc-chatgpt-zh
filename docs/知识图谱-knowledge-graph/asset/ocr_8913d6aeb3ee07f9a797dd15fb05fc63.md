# 第八章 知识存储和检索

如第二章所述，知识图谱因为表示形式的灵活性和易用性受到了学术界和企业界的广泛关注和应用。越来越多的知识实例数据开始表示成以三元组结构为基础的 RDF 格式。例如，DBpedia 包含 127 种不同的语言近 8000 万三元组；YAGO 有超过 1.2 亿三元组；Wikidata 有近 4.1 亿三元组；Freebase 有超过 30 亿三元组。因此，如何有效地存储和检索上述大规模的知识图谱数据集是一个重要的研究内容。
