SELECT 是 SQL 语言中功能最为丰富的语句，上述实例只是介绍了其最基本的用法。结合 SQL 内置的函数，SELECT 语句还可以查询某些数值字段的统计信息，例如最大值、最小值、平均值等；除此之外，还可以将返回的结果按照特定字典进行排序、分组操作；有些复杂的查询可能会涉及多个表的数据，此时还可以通过 JOIN 操作从多个表中查询数据。更多的用法请参考 SQL 相关的专业书籍及技术文档。前面的需求中要求我们查询既是物理学家又是数学家的实体，这就需要三元组表上通过 JOIN 操作来实现，下面直接给出本例的 SQL 语句。

```
SELECT DISTINCT T1.S
FROM Triples AS T1
INNER JOIN Triples AS T2 ON T1.S = T2.S
WHERE T1.P = '类型' and T1.O = '物理学家'
and T2.P = '类型' and T2.O = '数学家'
```

# 8.2.1.2 SPARQL 语言
