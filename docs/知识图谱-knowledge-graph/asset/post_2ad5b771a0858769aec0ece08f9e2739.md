
的符号表示成低维实数向量或矩阵以捕捉元素之间隐式关联的一种技术手段，而这些被量化的关联也很容易加入到后续的计算模型中，如神经网络模型。从另一个角度，表示学习也相当于将原始的特征空间向分布式空间作一次映射，而这样的映射可以带来如下好处：① 减少了维数灾难问题：一些统计模型往往需要捕捉多个原子特征之间的联合分布，会令特征空间呈指数型增长，而特征经过向分布式空间映射后，对特征之间的复杂关系进行了解耦；② 减少了数据稀疏性问题：在知识图谱、社交网络和推荐系统等稀疏图或稀疏矩阵数据中，稀疏性问题十分严重，而表示学习通过数值计算填充了稀疏矩阵，在一定程度上解决了数据稀疏性的问题；③ 使符号数据可直接参与运算且计算速度非常快：建立在分布式空间上的相似度函数或其他计算函数可以直接运用符号元素之间的分布式表示，而不必借用其计数、分布等统计量。知识图谱上的表示学习方法主要分为两大类：基于张量分解的方法和基于能量函数的方法。

## 9.4.1 基于张量分解的方法

矩阵（张量）分解的基本思想是用多个低维的矩阵或张量的积代替原始的关系矩阵，从而用少量的参数替代稀疏而大量的原始数据。Koren 等人最先将矩阵分解的方法应用到推荐系统中并赢得了 Netflix 百万美元大奖，令矩阵分解技术的应用成为热点，上海交大 ACM 团队也在其基础上开发了基于特征的矩阵分解，并在 2012 年 KDD Cup 中取得了冠军。但矩阵分解的方式只能捕捉两个元素之间的关系，并不适用于三元组知识图谱。

首先分析二维矩阵的情况，以用户和商品的打分为例，图 9.2 列举了一个用户-商品打分矩阵 R。我们为每一个用户和商品都分配了一个 6 维的向量，称为分布式向量；用户的分布式向量组成用户矩阵，记为 U；商品的分布式向量组成商品矩阵，记为 I；我们期望矩阵 U 和矩阵 I 的积尽可能地接近原有的用户-商品打分矩阵。为实现这一目的，使用数值优化的方式，设计出以下的损失函数：

L = ||UI − R||
= Σ_{u∈U} Σ_{i∈I} ||u·i − r_{ui}||
(9.12)

其中向量 u 是矩阵 U 的一行，向量 i 是矩阵 I 的一列，r_{ij} 表示第 i 个用户对第 j 个商品的打分值。通过反复地迭代，就可以看到各个用户和商品的分布式表示。

## 9.4.2 基于能量函数的方法

与张量分解方法不同，这种能量函数的目标并不是恢复出原始的关系矩阵和张量，而是根据任务的不同，自定义能量函数（或称为目标函数、损失函数），使得成立的事实三元组能量低，不成立的能量高，并通过能量函数的计算结果对事实是否成立进行推理。在学习中，最常见的方法是基于间隔的排序损失（margin-based pairwise ranking loss）。例如，在知识图谱的链接预测任务中，这类方法会自定义一个能量函数 f，并以此为每一个三元组 r(h,t) 计算一个能量得分 f_{r(h,t)}，并认为存在于知识图谱中的三元组的得分应该高于不在知识图谱中的三元组，且至少高出间隔 γ 那么多，因此这种基于间隔的排序损失可以表示成如下的形式：

ℒ = Σ_{r(h,t)∈KB} Σ_{r(h',t')∈KB'_{r(h,t)}} [f_{r(h',t')} + γ − f_{r(h,t)}]_+   (9.13)

这一类方法的出发点与矩阵分解不同，它是期望在三元组的相似度得分下，寻求知识图谱中各个元素的关系。其中基于翻译的嵌入学习模型（TransE，也可称为基于平移的嵌入学习模型）是这一类方法的典型。TransE 的思想来源于基于神经网络的词表示学习方法，特别是 word2vec 工具中使用的几种方法。word2vec 能够学习到具有以下线性关系的词表示，比如

vec（‘巴黎’）-vec（‘法国’）≈ vec（‘罗马’）-vec（‘意大利’）
vec（‘男人’）-vec（‘国王’）≈ vec（‘女人’）-vec（‘女王’）

也就是说具有相同关系（上面的例子分别隐式地蕴涵了“首都”和“特例”的关系）的词向量之差比较接近。TransE 对这种关系进行了显式的建模，该方法把关系表示为从实体 h 到实体 t 的翻译向量（或平移向量），基本假设是成立的事实三元组 (h,r,t) 应该满足等式 h + r = t。因此上面的例子可以改写成如下的形式：

vec（‘法国’）+vec（‘首都’）≈ vec（‘巴黎’）
vec（‘意大利’）+vec（‘首都’）≈ vec（‘罗马’）
vec（‘男人’）+vec（‘特例’）≈ vec（‘国王’）
vec（‘女人’）+vec（‘特例’）≈ vec（‘女王’）

接下来我们直接给出 TransE 模型的二元组相似度函数：

S_{r(h,t)} = -||E_h + E_r - E_t||_2^2   (9.14)

其中 E_h, E_t, E_r 分别为头尾实体和关系的向量表示。TransE 是参数较少也较简单的一个模型，但在多个知识图谱数据集上都取得了不错的效果，也是之后一系列模型的基础。TransE 在一对一类型的关系上很有效，但在处理一对多和多对一关系时存在一定的问题。例如，对于一对多关系 $r_m$，由于其可能包括多个尾部实体 $t_i$ 并满足 $\boldsymbol{h}+\boldsymbol{r}_m \approx \boldsymbol{t}_i$，因此会造成 $t_1 = t_2 = \cdots = t_m$ 的情况，不能有效地区分不同的实体。

为了解决 TransE 中的问题，TransH$^{[479]}$ 和 TransR$^{[291]}$ 在计算事实得分的时候，将同样的实体在不同的关系上使用不同的表示参与计算，这样避免了直接计算所带来的表示趋向一致的问题。对于事实 $(h, r, t)$，TransH 首先通过如下公式把实体表示 $(h/t)$ 映射到与关系相关的超平面上：$\boldsymbol{h}_\perp = \boldsymbol{h} - \boldsymbol{w}_r^T \boldsymbol{h} \boldsymbol{w}_r$ 和 $\boldsymbol{t}_\perp = \boldsymbol{t} - \boldsymbol{w}_r^T \boldsymbol{t} \boldsymbol{w}_r$，其中 $\boldsymbol{w}_r$ 是超平面的法向量。利用映射到超平面的向量，在关系 $r$ 的超平面上采用 TransE 的方式用 $L_1$ 或 $L_2$ 范数计算事实得分：$\|\boldsymbol{h}_\perp + \boldsymbol{r} - \boldsymbol{t}_\perp\|_{\ell_{1/2}}$。与 TransH 不同，TransR 把实体表示转换到关系 $r$ 对应的子空间中，而不是超平面上：$\boldsymbol{h}_r = \boldsymbol{M}_r \boldsymbol{h}$ 和 $\boldsymbol{t}_r = \boldsymbol{M}_r \boldsymbol{t}$，其中 $\boldsymbol{M}_r$ 表示从实体空间到关系 $r$ 子空间的转换矩阵。从图 9.4 可以看出上述三个模型的差别和联系。CTransR 模型$^{[291]}$ 是 TransR 的一个改进方法，它考虑同一种关系在不同实体对之间表示不同的含义，因此它将同一个关系的实体对聚类成若干子类别，在每一个类别中，单独学习一个关系的向量表示。该模型是对知识图谱中的知识进行分门别类处理的一个初步探索，在预测性能上有少量提升。不足之处是只考虑了关系的不同含义，没有考虑实体的多样性，不同类型的实体仍然共享同一个转换矩阵 $\boldsymbol{M}_r$。

TransH 和 TransR 只是部分地解决了 TransE 存在的问题。例如，当使用 TransR 解决一对多关系的时候，趋向于学习到 $\boldsymbol{M}_r \boldsymbol{t}_i = \boldsymbol{M}_r \boldsymbol{t}_j$, $\forall i, j \in \{1, \cdots, m\}$, $(h, r, t_i)$, $(h, r, t_j) \in$ 知识图谱，所以，$\boldsymbol{t}_i$ 和 $\boldsymbol{t}_j$ 的差异仅仅依赖于转换矩阵 $\boldsymbol{M}_r$ 特征值为 0 的个数$^{①}$。另外，因为对前部实体和后部实体使用同样的操作，加上采用对称式打分函数，现有方法对于自反关系不能学到有效的表示。例如，对于自反关系 $r$（如“朋友”等），当事实 $(h, r, t)$ 和 $(t, r, h)$ 同时成立时，TransE、TransH 和 TransR 学到的表示趋向于得到 $(\boldsymbol{h} \approx \boldsymbol{t})$ 和 $(\boldsymbol{r} \approx 0)$。其中，$\boldsymbol{h}$ 与 $\boldsymbol{t}$ 相等对于自反关系可能是一个好的性质，但是所有自反关系的表示都一样（都是 0）就不能有效区分不同关系了。实际上这是基于“点”嵌入方法的常见问题，基于“密度”的嵌入方法可以部分解决这个问题$^{[203]}$，特别是基于非对称的打分函数，事实的打分不仅与实体有关，还与它们的顺序有

① 对 $\boldsymbol{M}_r$ 进行奇异值分解：$\boldsymbol{M}_r(\boldsymbol{t}_i - \boldsymbol{t}_j) = \boldsymbol{S} \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix} \boldsymbol{D}(\boldsymbol{t}_i - \boldsymbol{t}_j) = \boldsymbol{0}$，因为，矩阵 $\boldsymbol{S}\Sigma\boldsymbol{D}$ 的特征值不可能等于 0，这就使得 $\boldsymbol{t}_i$ 和 $\boldsymbol{t}_j$ 的大部分维度的值相等。

此外，TransE 模型忽略了关系的相同语义，例如以下的情况，关系“部分”（has part）具有两个潜在的语义：

- (1) 组成相关的语义，例如（桌子，部分，桌腿）
- (2) 位置相关的语义，例如（大西洋，部分，纽约湾）

但由于 TransE 等模型采用基于平移的方法，只为同一个关系分配唯一一个平移向量，不能处理关系多语义的问题。对此，Xiao 等人提出贝叶斯非参数无限混合表示模型，利用特定关系的关系分量的混合来进行知识表示，每个分量代表一个特定的潜在语义，这种方法被称为 TransG^{[199]}。

自 2013 年 TransE 被提出以来，在这一框架下的方法层出不穷，以上是几个典型的改进算法的介绍，更多的方法在表 9.1 中进行了列举，介绍了这些方法的打分函数 F_{r(h,t)}，并以模型的参数个数作为模型复杂度。

除了上述方法，还有一些其他的自定义能量函数的基于表示学习的推理方法: Structured 模型^{[67]} 为每种关系定义两个矩阵 W_{rh} 和 W_{rt}, 打分函数 f_r(h,t) 为 −‖ W_{rh}h − W_{rt}t ‖_1。该模型使用了两个独立的矩阵操作头部实体和尾部实体，不能很好地刻画头尾部实体间的联系。Unstructured 模型^{[64]} 是 Structured 模型的特例，它令 W = I，打分函数 f_r(h,t) 为 −‖h−t‖₁。显然，该模型的缺点是没有考虑不同关系的影响。Semantic Matching Energy（SME）模型^{[64]} 为了克服参数过多的問題，将实体和关系都用向量表示，所有三元组共享 SME 中的参数。SME 使用多维矩阵运算刻画实体和关系之间的联系，它首先对 h、r 进行线性运算得到向量 v_hr，然后再对 t、r 做线性运算得到向量 v_tr，打分函数为 v_hr^T v_tr，其中线性运算的权重可以是矩阵，也可以是三维张量。SME 具有很强的学习能力，参数较少，但是计算量大，特别是使用三维张量的情况下，很难运用到大规模知识图谱中。

Latent Factor（LF）模型^{[227, 454]} 将实体用向量表示，关系用矩阵表示。LF 把关系看作实体间的二阶关联，定义打分函数 f_r(h,t) = h^T W_r t（某种程度上等价于 RESCAL 模型）。这个模型使得实体和关系之间产生交互，实体和关系之间的联系得到充分的体现。Single Layer（SL）模型^{[434]} 将实体用向量表示，关系用矩阵表示，为每个三元组定义一个单层非线性神经网络作为打分函数，以实体向量为输入层，关系矩阵为网络的权重参数。SL 模型是 NTN 模型的特例，当 NTN 中三维张量均为 0 时，NTN 退化为 SL。Neural Tensor Network（NTN）模型^{[434]} 是受 LF 模型启发，在 SL 中加入关系与实体的二阶非线性操作，增强实体与关系的交互性。NTN 是目前表达能力最强的模型，适合学习稠密的知识图谱。它的主要缺点是参数太多，计算量太大，不适合稀疏知识图谱。

## 9.5 符号演算和数值计算的融合推理

在通过表示学习的方法获得知识图谱的分布式表示后，便可以通过数值计算的方法在知识图谱上进行推理了。这种方法有两个明显的优势：① 基于数值计算的推理速度非常快而且与知识图谱的规模无关（知识图谱的规模只影响其学习效率），往往比逻辑推理或概率推理方法的速度快出几个数量级。② 可以缓解由于数据稀疏带来的“冷启动”问题，由于知识图谱中存在大量长尾实体[482]，对它们相关的知识进行推理时往往会因为不能搜集到足够的证据而使推理失败，表示学习方法通过反复的迭代可以令这些长尾实体获得一些隐式的语义，在一定程度上缓解数据稀疏的问题。但表示学习的方法也有弱点，主要体现在推理的精度相对较低。基于表示学习的推理可以把答案排到靠前的位置，但很难排到第一的位置，这主要是因为表示学习不能利用知识图谱中显式的长距离依赖（如逻辑规则），而这种信息往往对推理很有效。

为利用表示学习的优势，并克服它的弱点，已有一些研究工作提出融合表示学习和逻辑推理方法。这类工作包括：Rocktäschel[406] 提出用实体和关系的表示计算元组的概率，并基于 t-norm 理论计算出一条逻辑规则成立的概率；Wang[474] 则利用整数线性规划整合了知识的分布式表示与手写的规则，但规则的普适性却存在着一定的问题；Neelakantan[354] 提出用循环神经网络（recurrent neural networks, RNN）在关系路径的分布式向量上进行循环表示，具有类似思路的还有 PTransE[290]，并且 PTransE 还在遍历关系路径时，加入了类似 PRA 的启发式规则；Gu[188] 等人则在对关系路径表示后更进了一步，他们利用逻辑规则的分布式表示去预测两个实体之间是否存在类似的规则。

以下以 PTransE 和 Gu 的方法为例介绍如何利用知识图谱中元素的分布
