# 3. 罗列要素

根据确定的领域，罗列期望在知识图谱中出现的要素列表，主要包括概念、属性以及关系。这一步实际上是为后续步骤准备 “原材料”，因此不需要对上述概念进行清晰的分类，只需要尽可能多地罗列出期望的元素即可。例如，如果期望构建一个人物知识图谱，那么这一步可以罗列出科学家、文学家、地理学家、歌手、演员、流浪者、姓名、年龄、国籍、出生地、父亲、母亲、子女等。
