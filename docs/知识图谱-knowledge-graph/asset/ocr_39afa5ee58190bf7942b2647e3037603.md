计规律性体现得更加明显，所以使用基于统计的方法会更适用一些。但这类方法的另一个特点是覆盖率会比较高，而准确率相对较低，所以单纯使用时效果也不是很好。但如果把以上两种方法融合起来，就有可能会达到优势互补的目的。基于以上现象，有研究者提出了基于融合的抽取方法。这类方法的基本思想是：对不同类型的数据使用不同的抽取方法，再把不同方法得到的结果融合起来。代表性的工作有融合文本和网络列表的方法、融合网络列表与查询（query）的方法、多源数据融合的方法[9, 378, 458]。与单纯基于上下文统计信息相似度的方法相比，这类方法引入了模板抽取的结果作为已知知识，并且通过 Bootstrapping 策略不断更新已知知识，抽取结果的准确率有很大提高。但是这类方法仍然没有克服基于统计的方法所具有的需要大量计算的缺点，而且所选特征仍然局限于上下文特征。

# 3. 种子处理与结果过滤

一个完整的实体扩展系统由三个模块组成：① 种子处理模块；② 实体抽取模块；③ 结果过滤模块。学术界关于实体抽取模块的研究最多，以上章节也重点介绍了目前主要的抽取方法。但实际上，种子处理与结果过滤这两个模块对抽取结果也有非常重大的影响。本节将分别介绍这两个模块，讨论其中需要解决的主要问题与相关方法。

# （1）种子处理

不同种子对抽取结果有非常大的影响，相关研究表明，这种差别可以达到40% 以上。然而不幸的是，人工输入的种子质量通常并不高[471]。因此，研究如何衡量种子实体的质量以及如何选取高质量的种子具有重要的实际意义。

Vyas 等人提出了一种衡量种子质量的方法[471]，从以下三个方面衡量种子实体的质量。

+   ① 典型度：考量种子实体能在多大程度上代表目标语义类别。\n② 歧义度：考量种子实体是否有不同语义。\n③ 覆盖度：考量一个种子集合含有的语义信息能在多大程度上覆盖目标语义类别的语义信息。

该方法首先计算种子实体在以上三个方面的得分，然后从初始种子中选取高质量的种子提供给实体抽取模块。但这样做的前提是初始种子个数比较多，有一定的选择余地。但实际应用中，很多时候初始种子数量是很少的（比如目标类别包含实体数很少或初始知识很少），这种情况就需要一种能够根据初始种子生成高质量新种子的方法。
