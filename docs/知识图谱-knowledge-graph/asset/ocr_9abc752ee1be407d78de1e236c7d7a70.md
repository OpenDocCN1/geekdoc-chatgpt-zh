转移函数的权重，$s_k(y_i, x, i)$ 为 $i$ 位置的状态特征函数，$\mu_k$ 为这个状态函数的权重。

特征函数集：如上所述，为训练 CRF 模型，首先需要定义特征函数集合。特征函数的定义在模型训练中十分重要，特征函数的质量直接影响后续模型训练的质量。特征函数在 CRF 模型中分为状态特征函数和转移特征函数，两类函数都是二值函数，函数值取 0 或 1。对于特征函数的定义，我们可以考虑上下文词汇和词性特征。例如前面的例句，“姚明效力于休斯敦火箭队”，“力”“于”“斯”“顿”都是“休”这个字的上下文信词汇息，它们的词性也是“休”这个字的词性特征。如果训练规模比较大，那么只使用上下文特征便可以获得比较好的效果。

模型参数估计：在 CRF 模型的训练过程中，当定义好特征函数集后就需要估计模型的参数，即根据训练集数据估计每个特征函数的权重 $\lambda$。这里可以采用经典的模型参数估计方法，例如极大似然估计（Maximum Likelihood Estimation, MLE）。

命名实体标注：当我们训练好 CRF 模型后，就 可以对测试集中的文本进行命名实体的识别。训练好的 CRF 模型是一个庞大的鸢笛网络，网络中每一个节点是每个预测值的不同取值。通过寻找网络中具有最大概率的路径来确定输出的命名实体标记。搜寻这样的路径可以采用遍历的方法比较每一条可能的路径来寻找具有最大概率的路径，但是这样的方法复杂度非常高，耗时长，效率低。为此，安德鲁·维特比（Andrew Viterbi）博士于 1967 年提出了著名的维特比算法$^{[162]}$，它是一种特殊的但应用极为广泛的动态规划算法。如果模型的网络有 $D$ 个节点，长度为 $N$，那么维特比算法的复杂度只有 $O(N·D^2)$。由于篇幅限制这里不再对维特比算法的细节做过多介绍。

本小节主要介绍了利用条件随机场（CRF）模型进行命名实体识别的方法。首先简要介绍了 CRF 模型，接着介绍了特征函数，以及模型的训练过程和训练后的基于维特比算法标注命名实体的过程。
