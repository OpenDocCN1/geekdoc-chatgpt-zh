# 1. 语义组合模型

组合范畴语法（Combinatory Categorical Grammars, CCG）是一种有效的、表达能力强的语义组合语法形式，它能处理长距离依赖等多种自然语言现象[442, 443]。CCG 早期主要用于句法分析，2005 年 Luke Zettlemoyer 和 Michael Collins 首次将其应用于语义解析任务[522]。随后，大量的工作利用 CCG 进行语义解析。

CCG 的主要思想是把词的句法和语义信息组合在一起形成分析的基础辞典，依据组合语法规则自底向上对自然语言句子进行解析。CCG 的核心是辞典 Λ，它包括了语义组合过程中所需的全部语法和语义信息。辞典中的每个项由词/短语、句法类型/范畴和逻辑表达式组成。一般地，可以把辞典项标记为格式 w := s : l，表示词/短语 w 具有句法类型/范畴 s，并且相应的语义表达式为 l。句法类型/范畴 s 可以是原子类型/范畴（如 NP，S），也可以是复杂类型/范畴（如 A/B，其中 A 和 B 可以是原子类型也可以是其他复杂类型）。逻辑表达式 l 一般由知识库中的词汇加上逻辑符号（lambda 演算）组合而成。例如，下面的 CCG 辞典：

```
杭州 := NP : Hangzhou_City
上海 := NP : Shanghai_City
大上海 := NP : Shanghai_City
大上海 := NP : DaShanghai_Film
城市 := N : λx.City(x)
靠近 := (S \ NP)/NP : λx.λy.next_to(y,x)
哪些 := (S/(S \ NP))/N : λf.λg.λx.f(x) ∧ g(x)
```

第一个辞典项为简单项，“杭州”表示词/短语，NP 表示其对应的句法类型（或称为范畴），Hangzhou_City 表示其逻辑形式（使用知识库中词汇表示）。第五个辞典项城市 := N : λx.City(x) 使用了 lambda 算子表示知识图谱中的实体类型。最后一个辞典项稍微复杂一些，表示其右侧可以接受类型为 N 辞典项，接受的右侧辞典项的逻辑表达式作为参数 f 带入 λf.λg.λx.f(x) ∧ g(x) 中形成新的组合逻辑表达式。总之，辞典项的类型和语义表达式定义了该项如何与周围项进行组合以及组合之后得到的结果是什么。
