合)，该过程可以循环迭代地进行。CCG 主要包括如下两个基本组合规则①：

X/Y : f   Y : g ⇒ X : f(g)   (>) 
Y : g   X \ Y : f ⇒ X : f(g)   (<)

(>) 和 (<) 分别表示前向和后向组合规则，它们可以组合类型/范畴相匹配的辞典项，例如，对于左右相邻的类型的两个辞典项，他们的类型是 X/Y 和 Y，能够按照前向规则组合成类型为 X 的辞典项。组合项的子句和语义表达式也可以分别构造，首先，子句由左右两个辞典项的子句组合而成（如 “毗邻” 与 “上海” 组合得到 “毗邻上海”），其次，语义表达式为左右两个辞典项的语义表达式组合而成（如 λx.λy.next_to(y,x) 与 SH_City 组合得到 λy.next_to(y,SH_City)）。语义解析的分析过程依次使用这些组合规则，得到句法树，生成相应的逻辑表达式（S 表示最终句子的句法类型）。参考图 10.6 和图 10.7 中的例子，通过自底向上的解析过程，根据句子的句法结构组合成最终的逻辑表达式形式。
