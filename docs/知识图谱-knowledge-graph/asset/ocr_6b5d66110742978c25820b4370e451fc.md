从 20 世纪 90 年代开始，以统计机器学习为核心的人工智能技术逐步占据主流，“如何自动学习和利用知识进行推断和决策”逐渐成为人工智能的研究热点。进入新世纪，随着互联网的蓬勃发展，数据的规模呈现爆炸式增长的趋势，其类型也更加复杂多变，在大数据环境下，进行知识获取、知识管理和知识服务备受关注。然而，传统搜索引擎仍然基于关键词匹配，尽管这一模式一定程度上提升了用户获取信息的效率，但是由于其信息服务的模式仍然停留在字符层的匹配上，因此在信息服务的准确度上存在缺陷。随着搜索技术的发展，研究人员逐步意识到这些字符背后存在大量的知识，只有正确理解符号背后的语义，将文字转化为知识，才能真正提升信息服务的效果。

为了解决语义理解的困难，Tim Berners-Lee 等于 2001 年提出了语义网（Semantic Web）的概念[52]，由此打开了世界范围内语义网研究的序幕。语义网使用能够被计算机理解的方式描述事物之间的联系，它的基本出发点是计算机能够自动识别并理解互联网上的内容，并对不同来源的内容进行融合，从而为人们更加快速地获取信息提供技术支撑。从概念的理解上，现有 Web 上的内容只是简单的字符串，对于计算机而言，它们没有任何语义信息；语义网的目标就是对现有 Web 内容增加语义支持，使得计算机在一定程度上能够理解 Web 上信息的含义，并通过分析用户查询的语义信息，提供快速和准确的信息服务。本质上，语义网的目标是以 Web 数据的内容和语义为核心，并以计算机能够理解和处理的方式链接起来的海量分布式数据库[14]，其理想是将整个万维网上的在线文档所构成的数据编辑成一个巨大可用的数据库[51]。这个愿景虽
