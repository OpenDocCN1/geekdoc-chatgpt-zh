好，但是它在数据处理和智能应用上仍然存在缺陷，限制了语义网在实际中大规模使用的可能性。一方面，为了计算机能够更方便地处理 Web 数据，需要对这些数据标注语义信息。但是，Web 数据量十分巨大，且涉及的领域范围非常广泛，这就要求标记方法必须具备很强的扩展性。因此，如何自动地给 Web 上的网页内容添加合适的标签就成为关键问题之一，解决这一问题涉及的技术包括信息抽取、分类、关联等[10, 13, 17]。另一方面，要让计算机能够处理 Web 上人类生成的内容，就需要机器具有“思考”和“推理”的能力。这就需要把数据集合转变为知识系统，并赋予其描述逻辑知识的能力。目前，在这个问题上语义网还存在很多的不足，在很多应用场景下需要研究表达能力更强的知识表示形式。由于上述问题的存在，在语义网刚推出的十年间，并没有在实际中大规模应用，但是在这方面的成果大力推动了使用本体模型和形式化手段表达数据语义的方法的研究，为后续的知识图谱研究热潮奠定了基础。

语义网技术真正得到发展，以维基百科（Wikipedia）为核心的协同知识资源起到了功不可没的作用（甚至可以认为是决定性作用，对应图 1.3 左半部分）。最典型的两个大规模通用领域知识图谱 Freebase 和 DBpedia 都是以 Wikipedia 的 Infobox 数据为基础构建而成的。其中，Freebase 更偏向于知识工程的技术路线，而 DBpedia 更偏向于语义网的技术路线①。另外，真实的应用需求也是知识图谱发展的另一主要推动力（对应图 1.3 右半部分）。知识图谱这一领域的蓬勃发展是在 Google 于 2012 年正式提出知识图谱（Knowledge Graph）这一概念之后。Google 试图通过知识图谱，对于网页中的文本内容，特别是客观类事实性文本内容中的语义信息进行刻画，从这些非结构化的文本内容中提取出实体以及实体关系，将其事实性的文本内容转化为相互连接的图谱结构，从而让计算机真正做到内容理解。知识图谱是语义网真正意义上的一款杀手级应用产品，极大地推动了语义网、自然语言处理、数据库等相关技术的发展，被看作是下一代人工智能技术的基础设施之一，受到工业界、学术界的极大关注。紧随 Google 的步伐，国内的搜索引擎公司也纷纷构建了自己的知识图谱。百度的“知心”通过对搜索结果的筛选，将相近的信息组织在一起，以知识图谱的形式呈现出来，提高搜索的准确性。搜狗的“知立方”也是通过搜集、挖掘互联网上的海量碎片信息并汇总成图谱形式，以更好地支撑语义搜索、智能问答等服务。
