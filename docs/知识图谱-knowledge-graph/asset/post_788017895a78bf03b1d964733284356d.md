
Assumption Confidence ) [168] 等。这些指标不仅可以用于最后对规则的筛选和作为概率推理模型中的权重，也可以作为在子图结构枚举过程中进行剪枝操作的依据。

## 算法 2 AMIE 算法

```
输入： 知识库 K
输出： 规则集合 q
1: q = ⟨[]⟩
2: while ¬q.isEmpty() do
3:   r = q.dequeue()
4:   if r is closed ∧ r is not pruned for output then
5:     Output r
6:   end if
7: end while
8: for all operators o do
9:   for all rules r′ ∈ o(r) do
10:    if r′ is not pruned then q.enqueue(r′)
11:   end if
12:  end for
13: end for
▷ 并行执行
```

算法 2 中描述了一个典型的规则挖掘算法的一般步骤，被称为 AMIE（Association Rule Mining Under Incomplete evidence）[168] 算法。算法的一开始设立了一个路径的队列 q，并向其中插入一条长度为 0 的规则作为初始化；如果队列 q 是非空的，那么将弹出它队列头位置的路径 r，并将路径 r 从队列中删除；首先判断规则 r 是否像上面规则实例一样是一个闭回路，如果是，那么把这条规则作为候选输出，如果不是，就向路径 r 上增加边。增加边可以根据边的不同类别分为如下三类操作：

- 增加悬挂边（Dangling）：悬挂边是指边的一端是一个未出现过的变量，而另一端是在规则中出现过的。
- 增加具体边（Instantiated）：具体边与悬挂边类似，边的一端也是在规则中出现过的，但另一端是未出现过的常量，也就是知识图谱中的实体。
- 增加闭合边（Closing）：闭合边则是连接两个已经存在于路径中元素的边，它的加入没有为路径引入更多的元素，而是使路径成为一条闭合的回路。

对于搜索获得的新的路径集合，算法对其进行剪枝操作，而留下来的路径则被加入到路径队列中，开始新一轮的循环，直到队列 q 为空为止。剪枝的算法可能是人为定义的规则，也可能是根据路径的统计量，例如上面介绍过的支撑度和置信度的阈值来过滤。

## 9.3.1.2 归纳逻辑编程

与频繁子图挖掘方法不同，归纳逻辑编程（ILP）更重视没有出现在知识图谱中的负三元组，它认为正例（E₊）+ 负例（E₋）+ 背景知识（B）⇒ 假设（h）。一个正确的假设 h 是满足以下要求的命题：

必要性： B ⊭ E₊
充分性： B ∧ h ⊨ E₊
弱一致性： B ∧ h ⊭ false
强一致性： B ∧ h ∧ E₋ ⊭ false
(9.3)

其中，必要性是指在没有引入假设 h 作为约束时，仅使用背景知识 B 不能蕴含出正例 E₊；充分性指背景知识 B 以及假设 h 可以蕴含出正例 E₊，这个性质也就是被频繁子图挖掘方法使用的；弱一致性是指假设 h 不能与背景知识 B 冲突；而强一致性是指在弱一致性的基础上不能与已出现的负例有冲突，因此在没有负例引入时强弱一致性是相同的。

基于 ILP 的方法比仅利用图结构信息的频繁子图挖掘更具逻辑性，但也由于需要引入大量的负例而在计算规模上受到了制约，其典型工作有 ALEPH 和 Progol，它们都是典型的 ILP 系统并使用反向蕴含算法^[347]；Sherloc^[413] 是一个非监督的 ILP 方法，并使用概率图模型在网络文本中进行规则的挖掘；QuickFOIL^[521] 则基于自顶向下的贪心策略在 ILP 的约束下完成规则挖掘。

## 9.3.1.3 结构学习方法

概率逻辑推理模型的结构学习方法是一个统称，是指在一个整体的目标下，通过挑选使整体概率最大的逻辑规则加入到推理模型中。这一过程一般可以分为四个部分：① 定义目标函数；② 创建逻辑规则结构；③ 搜索逻辑规则的策略；④ 提速方法。

目标函数的定义取决于使用不同的概率逻辑推理模型，例如马尔可夫逻辑网以最大化世界概率为目标，这种方法一般也会被用于概率图模型的优化中，目标函数如下所示：

log P_w(X = x) = Σ_{r∈R} c_r Σ_{k=1}^{g_r} log P_w[ X_{x,k} = x_{r,k} | MB_x(X_{r,k}) ]  (9.4)

其中 R 是一阶谓词集合，g_r 是一阶谓词 r 的实例计数，X_{r,k} 是第 k 个 r 实例的 0/1 真值，谓词的权重 c_r 由用户自己设置或学习获得。

为寻找 Horn 子句式的逻辑规则候选结构，这一类方法一般会从概念级的关系集合中枚举逻辑规则的样式，通过对概念级的路径进行增边减边的操作来获取新的子句样式，并设定一些启发式的规则作为指导，如要求每个变量在子句中至少出现两次。例如为概念化路径父亲 (X,Y)∧ 父亲 (Y,Z) 添加一条出生地的边并连接首尾变量，即可转化为一个 Horn 子句形式规则父亲 (X,Y)∧ 父亲 (Y,Z)∧ 出生地 (Z,W) ⇒ 祖籍 (X,W)。由于这一过程是没有实例信息指导的，因此是一个无剪枝的结构枚举过程，具有 O(r^l) 的计算复杂度，其中 r 代表关系的种类，l 指规则的平均长度，因此即使是在概念层，搜索空间的规模也是巨大的。例如在 Freebase 中约有上万种关系，长度为 4 的规则样式最多会达到 10^18 的规模。

从所有规则空间中选择一个子集使目标函数最大是结构学习方法的核心，而寻找策略大多为将逻辑规则一条接一条地加入到规则集合中，可视为一种在线的增量学习方法，但这种方法的缺陷是在每增加一条规则后都要通过实例化逻辑规则的方法评估公式 9.4 中的概率，这是一个非常耗时的操作，例如将 MLN 的结构学习方法运行于元组规模仅为千级的 UW-CSE 数据集，一次概率的评估平均需要三分钟的时间[245]。因此结构学习中的一个重要的组成部分就是引入提速的方法，如使用基于蒙特卡洛的最大似然估计（MC-MLE）[173]、使用限制内存的 BFGS 算法优化伪似然[294]、使用惰性 (lazy) 机制[247] 等。

另一种有效的策略则是使用图结构上的随机游走代替复杂的枚举过程。路径排序，实例化网络抽样等都是基于随机游走的规则挖掘方法的实现。对此有兴趣的读者可以关注参考文献 [262, 263, 452, 480]。

## 9.3.2 演绎推理：推理具体事实

在通过上一节介绍的规则挖掘方法或者人工书写规则方法获得了逻辑规则集合之后，如何将这些规则应用于自动推理是这一节的主要内容，而运用规则推理出事实的过程，则可以认为是人工智能领域典型的演绎推理方法的应用。这一节分为两部分内容，首先以 λ 演算为例介绍确定性推理的一般过程，再以概率软逻辑为例介绍不确定性推理的一般过程。

### 9.3.2.1 确定性推理：λ 演算

λ 演算是一个形式系统，它本身是一种程序设计语言的模型，主要是被用来研究函数定义、函数应用和递归，后来发展为通用的表达式语言。λ 演算的核心是 λ 表达式，而 λ 表达式的本质则是一个匿名函数。

例如：函数 $f(x)=x+2$，可以写成匿名的 $\lambda$ 表达式，即 $\lambda x.x+2$。

下面给出 $\lambda$ 表达式更形式化的定义：一个 $\lambda$ 表达式由变量名，抽象符号 $\lambda$，“.”，“(” 和 “)” 组成，并且具有以下语法：

< $\lambda$表达式 > ::= < 变量名 >
|| < $\lambda$表达式 > < $\lambda$表达式 >
|| $\lambda$ < 变量名 > . < $\lambda$表达式 >
|| (< $\lambda$表达式 >)

$\lambda$ 表达式具有两种形式：应用型和抽象型。没有显式 $\lambda$ 符号的表达式是应用型函数，标准形式为 $E_1E_2$，其中 $E_1$ 是函数定义，$E_2$ 是函数 $E_1$ 的实参。因此，以下都是合法的 $\lambda$ 表达式：

- $xx$
- $\lambda x.xy$
- $x(\lambda y.xy)$
- $\lambda x.\lambda y.x$

对于 $\lambda$ 表达式的运算规律，应用型是从左到右运算，而抽象型则是由右向左运算，如下所示：

$E_1E_2E_3 = [(E_1E_2)E_3]$
$\lambda x_1.\lambda x_2\lambda x_3 = [\lambda x_1.(\lambda x_2\lambda x_3)]$

以上对 $\lambda$ 表达式作了简单介绍，那么到底 $\lambda$ 表达式与自然语言语义或者知识之间具有何种联系？我们用下例说明。

例：小明买苹果转化为三元组的形式买（小明，苹果），为了使这个三元组参与后续的计算，我们将里面的参数抽象成变量，因此这种表示可以改写成 $\lambda$ 表达式的形式：$\lambda x.\lambda y.buys(x,y)$。

$\lambda$ 表达式中含有自由变量（free variable）和绑定变量（bound variable），在一个 $\lambda$-项中，变量要么是自由出现的，要么是被一个 $\lambda$ 符号绑定的。例如，在 $\lambda x.xy$ 中，$x$ 就是被 $\lambda$ 绑定的，而 $y$ 则是自由出现的变量。直观地理解就是：被绑定的变量表示某个函数形参的变量，而自由变量不表示任何函数形参的变量。

在了解了 $\lambda$ 表达式后，我们再来看 $\lambda$ 演算的三种操作：

（1）$\alpha$-置换（$\alpha$-conversion）

在 $\lambda$ 表达式中，变量的名称是不重要的，$\lambda x.x$ 和 $\lambda y.y$ 本质上是相同的函数，所以具有约束的变量都是可以进行置换的。例如下例在 $\lambda$ 演算中是合法的：

λx.(λx.x)x=λy(λx.x)y

# (2) β-归约 (β-conversion)

β-归约类似于函数中变量代入的概念，是将实参代入到前面的 λ 项中，替换掉里面的变量。例如以下都是 β-归约的例子。

- λx.λy.y x → λy.y
- (λx.λy.y x)(λz.u) → λy.y(λz.u)
- (λx. x x)(λz.u) → (λz.u)(λz.u)

# (3) η-变换 (η-conversion)

η-变换表达了 “外延性” (extensionality) 概念，“当且仅当” 对于所有的参数它们都给出同样的结果，那么两个函数是相等的。

应用三种归约的方法，我们可以将上述例子中的 λ 表达式 λx.λy.buys(x, y) 归约为 buys (小明，苹果)。

### 9.3.2.2 不确定性推理：马尔可夫逻辑网和概率软逻辑

马尔可夫逻辑可以被看成一种通过为逻辑规则绑定权重的方式将一阶逻辑向概率逻辑进行扩展的方法。每个权重的大小反映了对应规则的相对强度或对于推理出假设的重要性。当将马尔可夫逻辑规则的权重调到无限大时，其退化为标准的一阶逻辑。按照 [396] 中的定义，马尔可夫逻辑网的定义如下：

定义 1: 马尔可夫逻辑网 L 是一个规则权重对 (f_i, w_i) 的集合，其中 f_i 是一条一阶逻辑中标准的规则，w_i 是一个实数。马尔可夫逻辑网 L 与一个有限的常量集合 C = {c1, c2, ⋯, c|C|} 一起按照如下的方式定义了一个马尔可夫网 M_{L,C}:

+ 1. M_{L,C} 为每一个可能的原子事实在 L 中都创建了一个二值的节点。若节点的值为 1，这个原子事实是真的；若节点的值为 0，则原子事实是假的。
+ 2. M_{L,C} 为每一个可能的实例化规则 F_i 都在 L 中设计一维特征 f_i。若这一特征值为 1，这条规则 F_i 是真的；若特征值为 0，则规则 F_i 是假的。特征的权重 w_i 被绑定在 L 中的规则 f_i 上。

更形式化地，设 X 是所有原子事实的集合，F 是马尔可夫逻辑网中所有一阶逻辑规则的集合，w_i 是绑定在规则 f_i ∈ F 上的权重，G_{f_i} 是所有可能的利用 X 中的原子事实去实例化 f_i 的集合。在这种马尔可夫逻辑网的定义下，可能世界 x 的概率可以定义为

P_w(X = x) = 1/Z exp [ Σ_{f_i ∈ F} w_i Σ_{g ∈ G_{f_i}} g(x) ]

= \frac{1}{Z} \exp\left[ \sum_{f_i \in \mathcal{F}} w_i n_i(x) \right] \quad (9.5)

其中 $g(x)=1$ 时表示这一条实例化的规则是真的，反之是假的，而第二行中的 $n(x)$ 则是 $g(x)$ 为 1 的计数。$Z = \sum_{x' \in X} \exp\left[ \sum_{f_i \in \mathcal{F}} w_i n_i(x) \right]$ 是集合了所有可能世界的归一化参数。

![](img/9549a57f481f525254296dec39e94079_219_0.png)

图 9.1 马尔可夫网中包含四个节点的团结构

对于知识图谱而言，一个三元组就可以看成是马尔可夫逻辑网中的一个原子事实，并且它也具有二值的特性，例如在闭世界假设（close world assumption, CWA）中，当元组存在于知识图谱中，则值为 1，否则值为 0。但为了控制生成的马尔可夫网的规模，原本没有在知识图谱中的元组，并不需要显式地表示成负原子，而是在需要的时候再动态地生成。为了表示元组之间的关系，马尔可夫逻辑网为共享一个实体的两个三元组连上一条无向边，并且假设在网络中，不存在超边。因此，在多于两个元组共享一个实体时，应该为每两个元组都连接一条边，并利用团（cliques①）捕获元组间的依赖性。在确定了推理假设的关系类型后，这样的团结构可以被分割为逻辑表达式，例如图 9.1 所示，这是一个包含了四个三元组的团结构，并且四个元组间两两相连。当推理假设为国籍（Cristiano Ronaldo，葡萄牙）时，从这个图结构中可以获得父亲（Cristiano Ronaldo, Jos Dinis Aveiro）∧ 国籍（Jos Dinis Aveiro，葡萄牙）⇒ 国籍（Cristiano Ronaldo，葡萄牙）等规则实例。将实例化规则中的实体用变量代替后，就可以看到马尔可夫逻辑网中的一条规则 $f_i$: 父亲 $(X, Y) \land$ 国籍 $(Y, Z) \Rightarrow$ 国籍 $(X, Z)$。以上就是使用马尔可夫逻辑网对知识图谱中的元组、依赖团组以及逻辑规则的建模。

在实践中，往往会针对某一种特定的关系进行规则的学习，在这种情况下，

① 团是无向图中的一个完全子图，因此团中的每两个点都具有一条边。

需要使用公式 9.5 的判别式形式。

P(q|KB,F) = \frac{\exp\left[\sum_{f_i \in F_Y} w_i n_i(x, y[Y=q])\right]}{\exp\left[\sum_{f_i \in F_Y} w_i n_i(x, y[Y=0])\right] + \exp\left[\sum_{f_i \in F_Y} w_i n_i(x, y[Y=1])\right]} \tag{9.6}

这个公式是对 9.5 的变形，旨在求解一个特定的事实 q 的概率，Y 的值可以是 1 或 0，其中 1 代表 q 是真的，0 代表 q 是假的。P(q|KB,F) 是事实 q 在现有知识图谱和规则集合下的成立概率，在规则学习过程中，通过动态地向规则集合中加入和去除逻辑规则或调节规则的权重，就可以令所有事实的概率趋于最大化，这时获得的带有权重的规则集合就是一个好的规则集合。

概率软逻辑模型（Probabilistic Soft Logic, PSL）是一种基于一阶逻辑谓词和马尔可夫逻辑网络的统计关系学习（Statistical Relational Learning）框架。PSL 使用加权的一阶谓词公式对无向概率图模型进行紧凑的表示。PSL 最大的优点是谓词可以在连续的 [0,1] 区间内任意取值，而不像 MLNs 只能取 {0,1} 中的离散值。因此 PSL 可以方便地对具有连续值的特征（如相似度）进行建模。

PSL 模型由一组带有权重的一阶逻辑谓词公式组成，其中每个公式编码了马尔可夫网络中一组共享同一权重的特征集合。上面已经提到，PSL 中的每个谓词实例 a 可以在 [0,1] 的连续区间内进行取值，本章用 I(a) 表示谓词实例 a 的取值。PSL 使用松弛版本的合取（∧）、析取（∨）和取反（¬）操作进行逻辑推理，它们的计算规则如下：

I(l₁ ∧ l₂) = max{0, I(l₁) + I(l₂) − 1.0}
I(l₁ ∨ l₂) = min{I(l₁) + I(l₂), 1.0}
I(¬l₁) = 1.0 − I(l₁)

对于一个给定的实例化谓词公式 r ≡ r_body → r_head，其成立的充要条件是 I(r_body) ≤ I(r_head)，也就是说公式头部的取值至少要和主体部分相同。如果公式不成立，那么不成立的严重程度用如下公式进行衡量：d(r) = max{0, I(r_body)−I(r_head)}。例如，假设有如下实例化的谓词及其取值：

I[spouse(P₁,P₂)] = 1.0
I[votesFor(P₁,P)] = 0.4

I[votesFor(P₂, P)] = 0.8

和谓词公式：

friend(p₁, p₂) ∧ votesFor(p₂, p) → votesFor(p₁, p)|ω = 0.4    (9.7)

spouse(p₁, p₂) ∧ votesFor(p₂, p) → votesFor(p₁, p)|ω = 0.9    (9.8)

其中小写字母 p₁, p₂ 和 p 表示变量，大写字母 P₁, P₂ 和 P 表示常量（实例），ω 表示公式的权重。第一个公式表达的含义是朋友之间会给相同的人投票，第二个公式则针对夫妻关系表达了类似的含义。两个公式权重的不同表示夫妻关系的影响在这一情境下比朋友关系的影响大。以公式 9.8 为例，其主体部分（body）及头部（head）取值的计算过程如下：

I(r_body) = I[spouse(P₁, P₂) ∧ votesFor(P₂, P)]    (9.9)
= max{0, I[spouse(P₁, P₂)] + I[votesFor(P₂, P)] − 1.0}
= max{0, 1.0 + 0.8 − 1.0} = 0.8
I(r_head) = I[votesFor(P₁, P)] = 0.4    (9.10)

由于 I(r_body) > I(r_head)，因此该公式不成立，其不成立的严重程度 d(r) = max{0, I(r_body) − I(r_head)} = max{0, 0.8 − 0.4} = 0.4。

给定一组谓词实例和公式，PSL 计算所有可能的谓词取值 I 的概率分布。形式化地，用 R 表示实例化的谓词公式集合，那么其概率密度函数 p(I) 为

p(I) = 1/Z exp { − Σ_{r∈R} λ_r [d(r)]^p }    (9.11)
Z = ∫_I exp { − Σ_{r∈R} λ_r [d(r)]^p }

其中 Z 是正则化因子，λ_r 是公式 r 的权重，p ∈ {1, 2} 提供了两种不同的损失函数。
