# 第九章 知识推理

前序章节对知识的表示方法以及知识的获取方法进行了介绍，本章介绍知识图谱的另一个重要任务：知识推理。本章将详细地描述知识图谱中的典型推理任务以及推理方法。

# 9.1 知识图谱中的典型推理任务

相对于无结构的数据形式，结构化知识图谱的一大优势就是能够支撑高效的推理。知识推理是人工智能应用迈向更高级认知智能的重要技术，其中，知识图谱的构建和应用中较为典型的推理任务包括知识补全和知识问答，下面对它们进行简要描述，然后详细介绍不同类型的知识推理策略和方法。

# 9.1.1 知识补全

知识补全，通常也被称为面向知识库或知识图谱的事实补全。虽然知识图谱中包含大量有价值的结构化数据，但是，它是非常不完备的，例如，知识图谱中包括了人物“A”及其“出生地”信息，但是没有包括他/她的“国籍”信息，虽然知识图谱中人物类概念定义了“国籍”属性，但是由于没有直接给出A的该属性值，也就是说，知识实例数据“国籍(A,?)”在知识图谱中是缺失的。形式化地描述就是，对于具有 r(h,t) 形式的三元组知识图谱，若 h,r 或 t 是未知的，需要使用推理方法将缺失的实体或关系预测出来的（即用？表示的部分），这样的任务称为链接预测。在以关系三元组为基础的知识图谱上，链接预测是知识补全的重要技术手段。知识补全可以利用已有知识预测未知的隐含知识，它可以用于完善现有知识图谱，是知识图谱构建和应用的重要手段之
