正嵌套程序的正环与紧凑性密切相关。

# 引理 5.2.11 令Π是正程序，S∈SM(Head(Π))。若Π在 S 上是紧凑的，则 G_Π 中没有正环 Z⊆S。若Π是有穷的，则Π在 S 上是紧凑的，当且仅 G_Π中没有正环 Z⊆S。

证明 设 G_Π中有正环 Z={p1,..., pk,...}⊆S(k≥1)，因为 S∈SM(Head(Π))，故对任意一 p∈S，存在某规则 C←B,F∈Π，使得 p∈GAtom_C∩S。设 Ck←Bk,Fk∈Π(1≤k)，C'←B',F'∈Π， p1 ∈ GAtom_{C1∩B'}， pk ∈ GAtom_{Ck∩Bk-1} (2≤k)。由Π的紧凑性，存在层次映射λ，使得λ(p1)>λ(p2)>...>λ(pk)>...>λ(p1)，矛盾。

对定理的第二部分，只需证“当”成立。设 |Π|=m，令

```
S_0=\(\emptyset\)

对 \(n\ge 0\), \(S_{n+1}=\{p\in\mathbf{GAtom}_C\cap S \mid C\leftarrow B,F\in\Pi, \forall p'\in B (p'\in(\mathbf{GAtom}_{\text{Head}(\Pi)}\cap S)\to p'\in\cup_{i\le n}S_i)\}\)

\(S'=\cup_{0\le n\le m}S_n\)
```

显然，\(S_1=\{C\leftarrow B,F\in\Pi \mid (B\cap S)=\emptyset\}\neq\emptyset\)，对 \(n\ge 0\), \(S_n\subseteq S_{n+1}\) 且 \(S'\subseteq S\)。若有 \(p_1 \notin S'\)，因为 \(G_\Pi\)中没有任何正环 \(Z\subseteq S\)，故对任意 \(n\ge 0\), \(S_n\) 中没有任何正环 \(Z\subseteq S\)。根据 \(S_n\) 的定义，对 \(p_1\leftarrow B_1,F_1\in\Pi\) 有相应的 \(p_2\in B_1\cap(S\backslash S')\)；对 \(p_2\leftarrow B_2,F_2\in\Pi\)有相应的 \(p_3\in B_2\cap(S\backslash S')\)； ...。如此不断进行此过程可得到 \(S\backslash S'\)中无穷序列 \(<p_1,p_2,p_3,... >\)。因为 \(|S| \le |\Pi|=m\)，故必有 \(i,j \le m\)，使得 \(p_i=p_j\) 且 \((p_i,...,p_j)\) 是 \(G_\Pi\)中由 \(S\) 中元素组成的正环，这与 \(G_\Pi\)中没有正环 \(Z\subseteq S\) 的假设矛盾。因此，\(S'=S\)。

定义层次映射\(\lambda\)，使得若 \(p\in S_{n+1}\backslash S_n\)，则 \(\lambda(p)=n+1\)；若 \(p\in Pos(\Pi)\backslash S\)，则 \(\lambda(A)=0\)。容易验证，对任意 \(p\in(\mathbf{GAtom}_{\text{Head}(\Pi)}\cap S) \cup Pos(\Pi)\)，有唯一的 \(n\ge 0\)，使得 \(\lambda(p)=n\)，故\(\lambda\)是合式定义的。

对任一 \(r\in\Pi\)，存在最小的 \(n\ge 0\)，使得

```
\(\mathbf{GAtom}_{\text{Head}(r)}\cap S \subseteq S_{n+1}\)

\(\text{Pos}(r) \cap (\mathbf{GAtom}_{\text{Head}(r)} \cap S)=\emptyset\)

\((\text{Pos}(r) \cap S) \subseteq \cup_{i\le n} S_i\)
```

因此，若 \(p\in\mathbf{GAtom}_{\text{Head}(r)}\cap S\)，则 \(\lambda(p)>\max \{\lambda(p')|p'\in Pos(r)\}\)。所以，\(\Pi\)是紧凑的。
