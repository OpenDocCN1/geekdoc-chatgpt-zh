定义 3.4.1 缺省理论 \(\Delta=(D,W)\) 是有穷的，若 \(D\) 与 \(W\) 均为有穷集。基于定理 3.2.1，能够用有穷步推理测试 \((\vdash)\) 求出有穷缺省理论的有穷个生成缺省集，在此意义下，定理 3.2.1 也称为缺省理论的有穷特征。

定义 3.4.2 设 \(\Delta=(D,W)\) 是缺省理论，\(D'\) 是 \(\Delta\) 的一生成缺省集，\(A\) 是公式。扩张的成员问题是判定 \(A\) 是否是 \(\Delta\) 的由 \(D'\) 生成的扩张的元素。

定义 3.4.3 设 \(\Delta=(D,W)\) 是缺省理论，\(A\) 是公式。缺省逻辑的审慎推理(SR)用于判定 \(A\) 是否出现在 \(\Delta\) 的所有扩张中，若是，则 \(A\) 是 \(\Delta\) 的 SR-推论，记作 \(\Delta \vdash_{sr} A\)。缺省逻辑的冒险推理(CR)用于判定 \(A\) 是否出现在 \(\Delta\) 的某一扩张中，若是，则 \(A\) 是 \(\Delta\) 的 CR-推论，记作 \(\Delta \vdash_{cr} A\)。

令 \(\Delta=(D,W)\) 是有穷的协调缺省理论。为简化，对于带多个检验的缺省的情形，不妨假设 \(D\) 中每个缺省是单一检验的缺省（即形如 \(A:MB/C\) 的缺省）。为求解 \(\Delta\) 的每个扩张与 SR 问题、CR 问题，下面引入三个主要的程序。

程序 1：

```
FUNCTION LAMBDA(D,W,D')
BEGIN
result := \emptyset
REPEAT
new := \emptyset
FOR EACH d: A:MB/C \in D' \\ result DO
IF W \cup Con(result) \vdash A THEN new := new \cup {d}
result := result \cup new
UNTIL new = \emptyset
RETURN (result)
END
```

程序 1 中，LAMBDA 用于计算 \(A(D', \Delta)\)，其正确性由定义 3.2.1 易知。注意，程序 LAMBDA 至多使用 \(|D'|^2\) 次逻辑推理测试(\(\vdash\))，此外需要耗时 \(O(n^2)\)，其中 \(n\) 是输入的大小。

定义 3.4.4 设 \(\Delta=(D,W)\) 是缺省理论，\(D\) 的相容子集 \(D'\) 是扩张的生成缺省集的“合法候选人”（记作 JCGD），若 \(A(D', \Delta) = D'\)，且对任意 \(A:MB/C \in D'D'\)， \(W \cup Con(D') \not\vdash A\) 或 \(W \cup Con(D') \vdash \neg B\)。
