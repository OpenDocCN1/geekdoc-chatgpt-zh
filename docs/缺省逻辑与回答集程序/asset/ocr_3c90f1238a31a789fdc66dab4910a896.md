# 定理 7.3.6 设 \(\Delta=(D,W)\) 是良基 ADT，对任意 \(D' \subseteq D\), \(D'\) 是 \(\Delta\) 的一个 CADL 扩张的生成缺省集，当且仅当

+   (1) \(D'\) 是 \(\Delta\) 的 CDL 扩张的生成缺省集；
+   (2) 对任意 \(A:MB/C \in D-D'\), \(Form(W) \cup Con(D') \not\vdash A\) 或 \(\{B\} \cup Form(W) \cup Supp(W) \cup Con(D')\) 不协调。

证明 证明条件“仅当”：设 \(E\) 是 \(D'\) 生成的 CADL 扩张，即 \(D'=GD_{CA}(E, \Delta)\)。易知 \(D'\) 是联合相容的。根据定理 7.3.4, \(E=\cup_{0 \le i} E_i\)。利用归纳法易证，对一切 \(i \ge 0\)

+   \(E_0=W\);
+   \(E_{i+1}=Th_S(E_i) \cup \{<C: \{r_1, \cdots, r_n, B\}> | A:MB/C \in D, <A:\{r_1, \cdots, r_n\}> \in E_i \}\);
+   \(E=Th_S(W) \cup \{<C: \{r_1, \cdots, r_n, B\}> | A:MB/C \in D', <A:\{r_1, \cdots, r_n\}> \in E \}\)。

定义 \(F=\cup_{0 \le i} F_i\), 其中

+   对 \(i \ge 0, F_0=W\);
+   \(F_{i+1}=Th_S(F_i) \cup \{<C: \{r_1, \cdots, r_n, B, C\}> | A:MB/C \in D', <A:\{r_1, \cdots, r_n\}> \in F_i \}\)。

利用归纳法易证，对任意 \(i \ge 0\), 有

\(Form(F_i)=Form(E_i)\)
\(Supp(F_i)=Supp(E_i) \cup \{C | A:MB/C \in D', A \in Form(E_i)\}\)

因此，\(Form(F)=Form(E)\) 且 \(Supp(F)=Supp(E) \cup Ccs(D')\)。

定义另一断言集序列 \(<F'_0, \cdots, F'_i, \cdots>\) 如下：

+   \(F'_0=W\);
+   对 \(i \ge 0, F'_{i+1}=Th_S(F'_i) \cup \{<C: \{r_1, \cdots, r_n, B, C\}> | A:MB/C \in D', <A:\{r_1, \cdots, r_n\}> \in F'_i \text{ 且 } \{B, C\} \cup Form(F) \cup Supp(F) \text{ 协调 } \}\)。
