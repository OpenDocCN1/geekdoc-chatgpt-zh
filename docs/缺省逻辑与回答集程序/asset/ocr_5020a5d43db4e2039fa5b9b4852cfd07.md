+   (1) $C_1$ 和 $C_2$ 的二元消解式;
+   (2) $C_1$ 和 $C_2$ 的一个因子的二元消解式;
+   (3) $C_2$ 和 $C_1$ 的一个因子的二元消解式;
+   (4) $C_1$ 的一个因子和 $C_2$ 的一个因子的二元消解式。

引理 2.1.2（提升引理） 设 $C_1$ 和 $C_2$ 是子句， $\theta_i$ 是置换，$C'_i=C_i\theta_i (i=1,2)$。若 $C'$ 是 $C'_1$ 和 $C'_2$ 的消解式，则存在 $C_1$ 和 $C_2$ 的消解式 $C$ 和一置换 $\varphi$，使得 $C'=C\varphi$，即 $C'$ 是 $C$ 的一个例式。

证明 不妨设 $C_1$ 和 $C_2$ 中没有公共变元出现（这通过变元改名不难实现），令 $\theta=\theta_1\circ\theta_2$，则 $\theta=\theta_1\cup\theta_2$。设 $L'_1=L_1\theta$ 和 $L'_2=L_2\theta$ 是得到消解式 $C'$ 时被消解的文字，$C'=(C'_1\land L'_1)\lor(C'_2\land L'_2)$，其中 $\gamma$ 是 $L'_1$ 和 $\neg L'_2$ 的 mgu。令 $L'_1,\cdots,L'_r$ 是 $C_1$ 中被 $\theta$ 置换为 $L'_i$ 的文字，即 $L'_1\theta=\cdots=L'_r\theta=L'_1 (i=1,2)$。若 $r>1$，因为 $\{L'_1,\cdots,L'_r\}$ 可合一，依定理 2.1.5， $\{L'_1,\cdots,L'_r\}$ 有一个 mgu $\lambda_i$，令 $L_i\lambda_i=L'_i\lambda_i (i=1,2)$。需要注意的是，因为 $\lambda_i$ 是 mgu，故 $L'_1\lambda_i,\cdots,L'_r\lambda_i$ 是相同的。于是，$L'_i$ 是 $C_i$ 的因子 $C_i\lambda_i$ 中的一个文字。类似地，若 $r=1$，令 $\lambda_i=\epsilon$， $L_i=L'_i\lambda_i$，并令 $\lambda=\lambda_1\cup\lambda_2$。显然，$L'_i$ 是 $L_i$ 的例式。由 $L'_1$ 和 $\neg L'_2$ 可合一知 $L_1$ 和 $\neg L_2$ 可合一。依定理 2.1.5，$L_1$ 和 $\neg L_2$ 有 mgu $\sigma$，令

$C=R(C_1,C_2)=((C_1\lambda)\sigma\backslash L_1^1\sigma)\cup((C_2\lambda)\sigma\backslash L_2^1\sigma)$
$=((C_1\lambda)\sigma\backslash \{L_1^1,\cdots,L_1^r\}\lambda\sigma)\cup((C_2\lambda)\sigma\backslash \{L_2^1,\cdots,L_2^2\}\lambda\sigma)$
$=((C_1\lambda\circ\sigma)\backslash \{L_1^1,\cdots,L_1^r\}\{\lambda\circ\sigma\})\cup((C_2\lambda\circ\sigma)\backslash \{L_2^1,\cdots,L_2^k\}\{\lambda\circ\sigma\})$

一方面，因为 $C_1$ 和 $C_2$ 中没有公共变元出现，可知 $\lambda\circ\sigma$ 是 $\{L_1^1,\cdots,L_1^r,L_1,L_2^1,\cdots,L_2^k,\neg L_2\}$ 的一个 mgu，故 $C$ 是 $C_1$ 和 $C_2$ 的一个消解式；另一方面，因为

$C'=R(C'_1,C'_2)=(C'_1\land L'_1\gamma)\cup(C'_2\land L'_2\gamma)$
$=((C_1\theta)\gamma\backslash \{L_1^1,\cdots,L_1^r\}\theta\gamma)\cup((C_2\theta)\gamma\backslash \{L_2^1,\cdots,L_2^k\}\theta\gamma)$
$=C_1(\theta\circ\gamma)\backslash \{L_1^1,\cdots,L_1^r\}\{\theta\circ\gamma\}\cup(C_2(\theta\circ\gamma))\backslash \{L_2^1,\cdots,L_2^k\}\{\theta\circ\gamma\}$

因为 $L'_1$ 和 $L'_2$ 分别是 $L_1$ 和 $L_2$ 的例式， $(\theta\circ\gamma)$ 是 $\{L_1^1,\cdots,L_1^r,L_1^1,L_2^1,\cdots,L_2^k,L_1,\neg L_2\}$ 的合一置换，故有合一置换 $\varphi$，使得 $\theta\circ\gamma=(\lambda\circ\sigma)\circ\varphi$。容易看出，$C\varphi=C'$，即 $C'$ 是 $C$ 的一个例式。
