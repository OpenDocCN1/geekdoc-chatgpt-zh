用下述程序可以求解 SR 问题：

```
BOOLEAN FUNCTION SR(A,D,W)
BEGIN
FOR EACH D'⊆D DO
    IF JCGD(D,W,D') AND NOT MEMBER(A,D,W,D')
    THEN RETURN (false)
RETURN (true)
END
```

用下述程序可以求解 CR 问题：

```
BOOLEAN FUNCTION CR(A,D,W)
BEGIN
FOR EACH D'⊆D DO
    IF JCGD(D,W,D') AND MEMBER(A,D,W,D')
    THEN RETURN (true)
RETURN (false)
END
```
