其中：

(1) C1θ 和 C2θ 分别是 C1 和 C2 的例式， p(x) 和 p(y) 是 C1 中被置换为 p(f(b)) 的文字， ¬p(f(u)) 和 ¬p(f(b)) 是 C2 中被置换为 ¬p(f(b)) 的文字， σ={f(u)/y} 是 p(y) 和 ¬p(f(b)) 的 mgu， R(C1', C2') 是 C1', C2' 的消解式；

(2) {p(x), p(y)} 的 mgu 是 λ1={x/y}， {¬p(f(u)), ¬p(f(b))} 的 mgu 是 λ2={b/u}， λ=λ1 ∪ λ2={x/y, b/u}；

(3) R(C1,C2)=(C1{θ∨γ}){L1i, ..., Lni} {θ∨γ} ∪ (C2{θ∨γ}){L2i, ..., Lni} {θ∨γ} = q(z)∨r(v)， 其中， (θ∨γ)={f(b)/y, b/u, f(b)/x, a/z, c/v}；

(4) C'=R(C1', C2')=¬q(a)∨r(c)， λ°σ={u/y, b/u, f(u)/x}， φ={a/z, c/v}， θ°γ=(λ°σ)°φ， C'=Cφ°。

定理 2.1.6 （一阶逻辑的消解规则） 设 C1, C2 是一阶子句， R(C1,C2) 是 C1, C2 的消解式，则 C1∧C2 |= R(C1,C2)。

证明 根据定理 1.3.2，任意子句通过约束变元的改名得到的子句与原来的子句逻辑等价。因此，不失一般性，设 C1 和 C2 中没有公共变元出现，依定义 2.1.8，考虑下述情形。

情形 1: 设 R(C1,C2)=(C1 θ L1 θ) ∪ (C2 θ L2 θ) 是 C1, C2 的二元消解式，其中 L1 和 L̄1 是被消解的文字， θ 是 L1 和 L2 的 mgu。依定理 1.3.2 或(VE)规则，C1 ∧ C2 |= (C1 ∧ C2) θ。根据定理 2.1.3，有 (C1 ∧ C2) θ = R(C1, C2)。因此， C1 ∧ C2 = R(C1, C2)。

情形 2: 设 R(C1,C2)=(C1 θ L1 θ) ∪ (C2' θ L2 θ) 是 C1, C2 的二元消解式，其中 C2' 是 C2 的一个因子，即有 θ'，使得 C2'=C2 θ'，其中 θ' 是 C2 中的两个或两个以上有同一谓词符号的文字的 mgu。于是， C2' θ = C2 (θ ° θ')。依定理 1.3.2 或(VE)规则， C1 ∧ C2 |= (C1 ∧ C2) θ。已知 C2' 是 C2 的一个因子，类似地，有 C2 θ = C2 (θ ° θ')，即 C2 θ |= C2' θ。由定理 2.1.3， (C1 ∧ C2) θ = (C1 θ L1 θ) ∪ (C2 θ L2 θ)。因为 C2 θ |= C2' θ，所以 C1 ∧ C2 |= (C1 θ L1 θ) ∪ (C2' θ L2 θ)，即 C1 ∧ C2 |= R(C1, C2)。

情形 3 类似于情形 2，可证：情形 4 由情形 2 和情形 3 可证得。

定义 2.1.9 给定一阶子句 C 和子句集 S，称子句序列 <C1, C2, ..., Cn> 是从 S 到 C 的消解证明， C 是由 S 消解导出的，其中每个 Ci (1 ≤ i ≤ n) 既是 S 中的成员，或是 Cj 和 Ck 用一个 mgu θi 得到的消解式 R(Cj, Ck) (j, k < i) 并且 Cn = C。如果 Cn = ⊥，则称此消解证明为（消解）反驳。

不失一般性，我们总假定，如果上述定义中的 Ci (1 ≤ i ≤ n) 是 S 的成员，则任何在 Cj (j < i) 中出现的变元都不出现在 Ci 中，通过变元改名可以实现。
