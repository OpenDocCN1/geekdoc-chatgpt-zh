应用算子 $A$ 可以表征缺省理论中出现空检验的缺省时不协调扩张的特性，即有下面的推论。

# 推论 3.1.4* 缺省理论 $\Delta=(D, W)$ 有不协调扩张，当且仅当 $W \cup \text{Con}(A(D', \Delta))$ 不协调，其中 $D'=\{A/: B/A | : B \in D\}$。$\Delta$ 的不协调扩张的生成缺省集是 $A(D', \Delta)$。

证明 “仅当” 设 $\Delta$ 有不协调扩张 $\boldsymbol{L}$，依定理 3.1.2，则 $\boldsymbol{L}=\cup_{0 \leq i} \boldsymbol{L}_i$，其中，对任意 $i \geq 0$，有

```
$\boldsymbol{L}_0=W$
$\boldsymbol{L}_{i+1}=\text{Th}(\boldsymbol{L}_i) \cup \{ C | A : MB_1, \cdots, MB_n / C \in D, A \in \boldsymbol{L}_i, \neg B_1, \cdots, \neg B_n \notin \boldsymbol{L} \}$
$=\text{Th}(\boldsymbol{L}_i) \cup \{ C | A : / C \in D, A \in \boldsymbol{L}_i \}$
```

令 $D^* = \cup_{0 \leq i} \{ A : / C \in D | A \in \boldsymbol{L}_i \}$，则 $\text{GD}(\boldsymbol{L}, \Delta)=D^*$。容易验证，$D^* = A(D', \Delta)$。因此，$\boldsymbol{L}=\text{Th}(W \cup \text{Con}(D^*))=\text{Th}(W \cup \text{Con}(A(D', \Delta)))$，这表明，$W \cup \text{Con}(A(D', \Delta))$ 不协调。

“当” 设 $W \cup \text{Con}(A(D', \Delta))$ 不协调。由定义 3.1.1，$\theta(\boldsymbol{L}, \Delta)=\cup_{0 \leq i} E_i$，其中对任意 $i \geq 0$，有

```
$E_0=W$
$E_{i+1}=\text{Th}(E_i) \cup \{ C | A : MB_1, \cdots, MB_n / C \in D, A \in E_i, \neg B_1, \cdots, \neg B_n \notin \boldsymbol{L} \}$
```

因为 $A(D', \Delta) = \cup_{0 \leq i} D'_i(\Delta)$，其中，对任意 $i \geq 0$，有

```
$D'_0(\Delta)=\{ A : MB_1, \cdots, MB_n / C \in D' | W \vdash A \}$
$D'_{i+1}(\Delta)=\{ A : MB_1, \cdots, MB_n / C \in D' | W \cup \text{Con}(D'_i(\Delta)) \vdash A \}$
```

施归纳法容易证明：对任意 $i \geq 0$，$W \cup \text{Con}(D'_i(\Delta)) \subseteq E_{i+1}$。因此，$W \cup \text{Con}(A(D', \Delta)) \subseteq E$。

因为 $W \cup \text{Con}(A(D', \Delta))$ 不协调，故 $\text{Th}(W \cup \text{Con}(A(D', \Delta)))=\boldsymbol{L}$。所以，$\boldsymbol{L} \subseteq \text{Th}(\theta(\boldsymbol{L}, \Delta))$，这蕴含 $\text{Th}(\theta(\boldsymbol{L}, \Delta))=\boldsymbol{L}$。依定理 3.1.2，$\boldsymbol{L}$ 是 $\Delta$ 的不协调扩张。

显然，算子 $A$ 是单调的和封闭的。

# 推论 3.2.1 设 $\Delta=(D, W)$ 是缺省理论，$D' \subseteq D'' \subseteq D$，则 $A(D', \Delta) \subseteq A(D'', \Delta)$ 且 $A(A(D', \Delta), \Delta)=A(D', \Delta)$。

证明 推论的第一部分 $A(D', \Delta) \subseteq A(D'', \Delta)$ 容易用归纳法证明。

由定义 3.2.1 易见，$A(D', \Delta) \subseteq D'$。依推论的第一部分可知，$A(A(D', \Delta)) \subseteq A(D', \Delta)$。施归纳法容易证明，对任意 $i \geq 0$，有 $D'_i(\Delta) \subseteq A(D', \Delta)(\Delta)$，因此，$A(D', \Delta) \subseteq A(A(D', \Delta))$。所以，$A(A(D', \Delta), \Delta)=A(D', \Delta)$。

下面的结果给出扩张的生成缺省集的一个必要条件。

# 引理 3.2.1 设 $E$ 是缺省理论 $\Delta=(D, W)$ 的扩张，则 $A(\text{GD}(E, \Delta), \Delta)=\text{GD}(E, \Delta)$。

证明 $E$ 不协调的情形是平凡的，只需考虑 $E$ 是协调的。
