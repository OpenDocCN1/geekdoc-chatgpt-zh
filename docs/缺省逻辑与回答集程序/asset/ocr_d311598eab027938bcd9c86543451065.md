为了证明上述算法的正确性，需要下述引理。

# 引理 3.4.1 设 A=(D,W)是弱自相容的缺省理论，上述算法循环过程中每一步生成的 GD< 是强相容的，且最后得到的 GD< 是极大强相容的。

证明 首先，施归纳于循环的步数 p 证明，每一步生成的 GD< 是强相容的。

基始 p=0， Ø是强相容的。

归纳 设在第 q(q≥0)步生成的 GD< (记为 GD<q) 是强相容的，在第 q+1 步生成的 GD< 记为 GD<q+1。只需考虑 GD<q+1=GD<q U { dk } 的情形，其中 k 是满足如下条件的最小序数χ：

```
dχ=A:MB/Ce { dχm | m≤|D| } \ GD<q
A ∈ E<q =Th(W U Con (GD<q))
¬B ∉ E<q
```

由推论 3.2.2 得到， A(GD<q+1, A) = GD<q+1。又因为 ¬B ∉ E<q，则依 A 的弱自相容性如 GD<q+1 是相容的，故归纳结论成立。

另外，由该算法最后得到的 GD< 是极大强相容的。这是因为， GD< 是强相容的，故有极大强相容的 D'，使得 GD< ⊆ D'。由 D' = A(D', A) = ∪0≤i< D'i(A) 和算法的结构，施归纳于 i，易证 D'i(A) ⊆ D< (即 D'i(A) 中每个成员必在循环的某一步被添加到先前一步生成的 GD< 中)，从而 D' = GD<，极大性获证。

# 定理 3.4.1 算法 FUCTION-ALL-EXTENSIONS-WAC 是可靠且完备的，即由该算法得到的都是弱自相容缺省理论 A=(D,W) 的一个扩张的生成缺省集；反之， A 的每个扩张的生成缺省集都可以由该算法得到。

证明 对于 W 不协调的情形，定理是显然的。因此只需考虑 W 协调的情形。
