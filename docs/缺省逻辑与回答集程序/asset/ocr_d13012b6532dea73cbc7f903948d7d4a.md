定理 5.3.2 令 $\Pi$ 是正规程序，$D=\{c_1,c_2\} \cup \text{Const}(\Pi)$，其中 $c_1$ 和 $c_2$ 是不同的不在 $\Pi$ 中出现的常元。则下面的命题是等价的：

+   (1) $\Pi$ 有有穷完备的一阶正环集合；
+   (2) 存在自然数 $N$，使得对任何 $\Pi$ 的环 $L$， $|\text{var}(L)|\leqslant N$；
+   (3) 对 $\Pi$ 的任意环 $L$ 和 $A_1, A_2 \in L$， $\text{var}(A_1)=\text{var}(A_2)$；
+   (4) 对 $\Pi_{eq}|D$ 上的任意环 $L$，不存在原子 $A,B \in L$，使得 $c_1 \in \text{Const}(A) \text{Const}(B)$ 或 $c_2 \in \text{Const}(B) \text{Const}(A)$；
+   (5) 对 $\Pi_{eq}|D$ 的任何极大（包含关系下）环 $L$，不存在原子 $A,B \in L$，使得 $c_1 \in \text{Const}(A) \text{Const}(B)$ 或 $c_2 \in \text{Const}(B) \text{Const}(A)$。

以上命题中的 $\Pi_{eq}$ 是将 $\Pi$ 中的 $t_1=t_2$ 重命名为 $\text{eq}(t_1,t_2)$ 而得到的程序，其中 eq 是一个新的二元谓词符号。因此 $\Pi_{eq}$ 中不再出现等词，从而 $\Pi_{eq}|D$ 保留所有因为处理等词而删掉的规则。

证明   (1) $\Leftarrow$ (2): 令 $\Delta$ 是 $\Pi$ 的所有一阶正环的集合，其中每个环包含的变元都在 $\{x_1, \cdots, x_N\}$ 中。易知，$\Delta$ 是有穷的。对于 $\Pi$ 的任一环 $L$，总存在 $L'=L\theta$，其中 $\theta$ 是对属于 $\text{var}(L')$ 而不属于 $\{x_1, \cdots, x_N\}$ 的变元用 $\{x_1, \cdots, x_N\} \backslash \text{var}(L')$ 中的变元替换而得到的置换。因为 $|\text{var}(L)|\leqslant N$，易知，该置换存在且 $L' \in \Delta$。所以，$\Delta$ 是 $\Pi$ 的有穷完备的一阶正环集合。

(2) $\Leftarrow$ (3): 由于 $\Pi$ 是有穷的，故 $\Pi$ 仅出现有穷多个谓词符号。令 $N=\max\{n | \text{存在在}\Pi \text{中出现的谓词 } p, \text{使得 } p \text{ 是 } n \text{元谓词}\}$。对于 $\Pi$ 的任意环 $L$ 和 $A_1, A_2 \in L$，根据命题 (3)，$\text{var}(A_1)=\text{var}(A_2)$。因此， $|\text{var}(L)|\leqslant N$。

(3) $\Leftarrow$ (4): 假设存在 $\Pi$ 的环 $L$ 和 $A_1, A_2 \in L$ 满足 $\text{var}(A_1)\neq\text{var}(A_2)$。不失一般性，令 $x \in \text{var}(A_1) \backslash \text{var}(A_2)$

\[ \theta = \{x / c_1\} \cup \{x' / c_2 | x' \in \text{var}(L) \backslash \{x\} \} \]

显然，$L'=L\theta$ 是 $\Pi_{eq}|D$ 的一阶正环且 $c_1 \in \text{Const}(A_1) \backslash \text{Const}(A_2)$，这与命题 (4) 的前提矛盾。
