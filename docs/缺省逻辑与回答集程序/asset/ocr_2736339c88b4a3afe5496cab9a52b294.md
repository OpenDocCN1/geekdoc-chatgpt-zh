# 定理 7.3.11 令 Δ=(D,W) 是 ADT，E 是断言集，定义断言集序列如下： E0=W

```
对 i ⩾ 0, E_{i+1} = Th_Γ(E_i) ∪ {<C: {r0, ..., rk, B} > | A:MB/C ∈ D, <A: {r0, ..., rk} > ∈ E_i 且 {B} ∪ Form(E) 协调}
```

E 是 Δ 的 QDL 扩张当且仅当 E = ∪_{0⩽i} E_i 且 E 是合式定义的。

类似地，可以定义 QDL 扩张 E 的生成缺省集 GD_Q(E, Δ)，当不致混淆时，简记为 GD(E, Δ)。

# 定义 7.3.7 令 Δ=(D,W) 是 ADT，D' ⊆ D。如果对每一 A:MB/C ∈ D', Form(W) ∪ Con(D') ∪ {B} 协调，则 D' 是 Q-相容的（关于 Δ）。如果 D' 是 Q-相容的且 Λ(D', Δ)=D', 则称 D' 是强 Q-相容的（关于 Δ）。如果 D' 是强 Q-相容的（关于 Δ），且对任何 D'': D' ⊆ D'', D'' 不是强相容的，则称 D' 是极大强 Q-相容的（关于 Δ）。

# 定理 7.3.12 令 Δ=(D,W) 是 ADT，Δ 有 QDL 扩张当且仅当存在 D' ⊆ D，使得

+   (1) D' 是 Q-相容的；
+   (2) 对任意 A:B/C ∈ D - D', Form(W) ∪ Con(D') ∤ A 或 Form(W) ∪ Con(D') ∪ {B} 不协调；
+   (3) 不存在公式 A，使得 A ∈ Supp(W) ∪ Ccs(D') 且 ¬A ∈ Th(Form(W) ∪ Con(D'))。等价地，可以用条件 “D' 是极大强 Q-相容的” 替代上述的条件 (1) 和条件 (2)。
