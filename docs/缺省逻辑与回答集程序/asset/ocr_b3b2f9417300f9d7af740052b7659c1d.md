**定义 7.3.1** 令 \(\Delta=(D, W)\) 是缺省理论。对任意公式集 \(T\)，令 \(\Gamma(T)\) 是满足下述条件的最小公式集的对子 \(<S', T'>\)，有

+   (1) \(W \cup S' \cup T'\) 协调；
+   (2) \(S' = \text{Th}(S')\), \(T' = \text{Th}(T')\);
+   (3) 对任意 \(A: MB/C \in D\)，若 \(A \in S'\) 且 \(T \cup \{B, C\}\) 协调，则 \(C \in S'\) 且 \(B, C \in T\)。

信念对 \(<E, C>\) 是 \(\Delta\) 的约束扩张（Contr-DL 扩张），当且仅当 \(\Gamma(T) = (E, C)\)。
显然，约束扩张满足它们的预设，即所有被应用的缺省的检验是整体（或联合）协调的。类似于 DL 的准归纳特征的方式，容易证明下述约束扩张的准归纳特征。

**定理 7.3.1** 令 \(\Delta=(D, W)\) 是缺省理论，\(S\) 与 \(T\) 是语句集。分别定义序列 \(<S_i>\) 和 \(<T_i> (i \geqslant 0)\) 如下：

+   (1) \(S_0 = W\), \(T_0 = W\);
+   (2) 对 \(i \geqslant 0\), \(S_{i+1} = \text{Th}(S_i) \cup \{C | A: MB/C \in D, \text{其中 } A \in S_i \text{且 } T \cup \{B, C\} \text{协调}\}\);
+   (3) 对 \(i \geqslant 0\), \(T_{i+1} = \text{Th}(T_i) \cup \{B, C\} | A: M B / B \in C \in D, \text{其中 } A \in S_i \text{且 } T \cup \{B, C\} \text{协调}\}\)。

\(<S, T>\) 是 \(\Delta\) 的约束扩张，当且仅当 \(S = \cup_{0 \leqslant i} S_i\) 且 \(T = \cup_{0 \leqslant i} T_i\)。
显然， \(S_0 \subseteq S_1 \subseteq \cdots S_i \subseteq \cdots\) ; \(T_0 \subseteq T_1 \subseteq \cdots \subseteq T_i \subseteq \cdots\) 。

下面的定理确立 CDL 扩张与 Contr-DL 扩张之间的 1-1 对应关系，因此 CDL 与 Contr-DL 在此意义下是等价的。
令 \(\Delta=(D, W)\) 是缺省理论，称 \(\Delta^{\text{ADT}} = (D, W^{\text{ADT}})\) 是相应于 \(\Delta\) 的 ADT，其中 \(W^{\text{ADT}} = \{<A: \varnothing> | A \in W\}\)。

**定义 7.3.2** 设 \(\Delta=(D, W)\) 是缺省理论， \(\Delta^{\text{ADT}} = (D, W^{\text{ADT}})\) 是相应于 \(\Delta\) 的 ADT。

+   (1) 若 \(E\) 是 \(\Delta^{\text{ADT}}\) 的 CDL 扩张，则 \(<\text{Form}(E), \text{Supp}(E)>\) 是 \(\Delta\) 的 Contr-DL 扩张；
+   (2) 若 \(<S, T>\) 是 \(\Delta\) 的 Contr-DL 扩张，则存在 \(\Delta^{\text{ADT}}\) 的 CDL 扩张 \(E\) 使得 \(\text{Form}(E) = S\), \(\text{Th}(\text{Supp}(E)) = T\)。

证明 依定理 7.2.1, \(E = \cup_{0 \leqslant i} E_i\), 其中

+   - \(E_0 = W^{\text{ADT}}\);
+   - 对 \(i \geqslant 0\), \(E_{i+1} = \text{Th}_S(E_i) \cup \{<C: \{r_1, \cdots, r_n B, C\} > | A: M B / C \in D, <A: \{r_1, \cdots, r_n\} > \in E\) 且 \(\{B, C\} \cup \text{Form}(E) \cup \text{Supp}(E)\) 协调}。
