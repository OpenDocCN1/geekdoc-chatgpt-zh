# 定理 3.1.1 对任意缺省理论 $\Delta=(D,W)$ 与任一公式集 $E, \Gamma(E)=\theta(E,\Delta)$。

证明 首先，由 $\theta(E,\Delta)=\cup_{0 \le i}E_i$，易见 $\theta(E,\Delta)$ 满足定义 3.1.2 中条件 1、条件 2 和条件 3。

其次，施归纳法容易证明：若 $E'$ 是满足定义 3.1.2 中条件 1、条件 2 和条件 3 的任一公式集，即 $E'$ 满足

+   - $W\subseteq E'$;
+   - $\text{Th}(E')=E'$;
+   - 若 $A:MB_1,\cdots,MB_n/C\in D$，且 $A\in E'$，$\neg B_1,\cdots,\neg B_n\notin E$，则 $C\in E'$。

于是，则对任意 $i\ge0, E_i\subseteq E'$。因此，$\theta(E,\Delta)\subseteq E'$，即 $\theta(E,\Delta)$ 是满足条件 1，条件 2 和条件 3 的最小集合，故 $\Gamma(E)=\theta(E,\Delta)$。

注意：定义 3.1.2 中条件 3 直观上表明，若 $A$ 可相信，且 $B_1,\cdots,B_n$ 协调地可相信，则 $C$ 可相信。

当 $E$ 为 $\Delta=(D,W)$ 的扩张时，$GD(\theta(E,\Delta),\Delta)$ 是 $E$ 的生成缺省集，于是给出如下定义。

# 定义 3.1.3 给定缺省理论 $\Delta=(D,W)$ 与它的一个扩张 $E$，称集合
$\{A: MB_1,\cdots,MB_n / C \in D \mid A \in E, \neg B_1,\cdots,\neg B_n \notin E\}$ (3-3)

为 $E$ 的生成缺省集并记为 $GD(E,\Delta)$。

约定：若允许 $D$ 中出现无检验的缺省，则上述定义中 $\neg B_1,\cdots,\neg B_n \notin E$ 自然满足，因此，若 $A\in E$，则 $A: C \in GD(E,\Delta)$。

通过上面的讨论可得到扩张的一个充要条件——扩张的准归纳特征，它提供了扩张的更为直观的特征。

# 定理 3.1.2 (扩张的准归纳特征) 令 $\Delta=(D,W)$ 是缺省理论且 $E\subseteq\mathbf{L}$，则 $E$ 是 $\Delta$ 的扩张，当且仅当 $E=\cup_{0 \le i}E_i$，其中
$E_0=W$，对于 $i\ge0$

```
$E_i=\text{Th}(E_i) \cup \{C | A:MB_1,\cdots,MB_n/C\in D, A\in E_i, \neg B_1,\cdots,\neg B_n \notin E\}$
```

该定理可由定义 3.1.2 与定理 3.1.1 证明。

例 3.1.2 令 $\Delta=(D,W)$，其中 $D=\{MA:A; MB/B; MC/C\}$，$W=\{B\to\neg A\land\neg C\}$。 $\Delta$ 有两个扩张 $E_1=\text{Th}(W\cup\{A,C\})$ 和 $E_2=\text{Th}(W\cup\{B\})$。

例 3.1.3 $\Delta=(D,W)$，其中 $D=\{:MC/\neg D, :MD/\neg E, :ME/\neg F\}$，$W=\emptyset$。 可以看出，$E=\text{Th}(\{\neg D,\neg F\})$ 是 $\Delta$ 的唯一扩张。

例 3.1.4 $\Delta=(D,W)$，其中 $D=\{:MA/\neg A\}$，$W=\emptyset$，$A$ 不是矛盾式。考虑任意一演绎封闭的公式集 $E$，如果 $\neg A\in E$，则 $\Gamma(E)=\text{Th}(\emptyset)\neq E$。如果 $\neg A\notin E$，则 $\Gamma(E)=\text{Th}(\{\neg A\})\neq E$。
