因为 $S$ 是 Comp($\Pi^a$)的模型，依定理 4.3.3，$S$ 封闭于 $\Pi^a$，故 $Head(r)\in S, r\in\Pi^a$。这表明，$GR(S,\Pi^a)\equiv\Pi^a$。因此，$\Pi^a=GR(S,\Pi^a)$且 $Head(\Pi^a)=S$。因为 $S$ 是 $\Pi^a$ 的回答集，依定理 4.2.2*，$\Lambda(GR(S,\Pi^a))=GR(S,\Pi^a)$。于是，$\Pi^a=\Lambda(\Pi^a)$。

因为 $S$ 是 Comp($\Pi^a$)的模型，依定理 4.3.3，$S$ 是 $\Pi$ 文承的且封闭于 $\Pi$。由前已证 $\Pi^a\subseteq\Pi$，$\Pi^a$ 是紧凑的，$\Pi^a=\Lambda(\Pi^a)$，$S=Head(\Pi^a)$，依定理 5.1.2，$S$ 是 $\Pi$ 的回答集。

例 4.3.2（续） 程序 $\Pi_1$ 没有正环，回答集与其完备的模型同为 $\emptyset$。程序 $\Pi_2$ 有一正环 $\{A\}$，$R^-(\Pi_2,\{A\})=\emptyset$，故 $LF=\emptyset$，$\Pi_2$ 的回答集与 $Comp(\Pi_2)$ 的模型同为 $\emptyset$。

为了用 SAT 求解器计算有穷正规程序 $\Pi$ 的回答集，关键是计算环公式。但是，一个程序可能有指数多个环公式。例如，求一个图的 Hamilton 圈的程序（有约束）：

r1: hc(V1,V2)←arc(V1,V2),not otherroute(V1,V2)
r2: otherroute (V1,V2)←arc(V1,V2),arc(V1,V4),hc(V1,V4),V2≠V4
r3: otherroute (V1,V2)←arc(V1,V2),arc(V4,V2),hc(V4,V2),V1≠V4
r4: reached(V2)←arc(V1,V2),hc(V1,V2),reached(V1),not initialnode(V1)
r5: reached(V2)←arc(V1,V2),hc(V1,V2),reached(V1),initialnode(V1),initialnode(O)
r6: ←vertex(V),not reached(V)

其中，hc, arc, otherroute, reached, initialnode 和 vertex 分别表示 Hamilton 圈，弧，其他路径，可到达，初始结点和顶点。这些谓词的含义如下：

+   - hc(x,y): 顶点 x 到 y 有 Hamilton 圈；
+   - arc(x,y): 顶点 x 到 y 有弧；
+   - otherroute(x,y): 顶点 x 到 y 存在其他路径；
+   - reached(x): 顶点 x 可到达；
+   - initialnode(x): 顶点 x 是初始顶点；
+   - vertex(x): x 是顶点。

对于完全图，规则 $r_4$ 在完全例式后将对每一顶点集（$n$-完全图有 $2^n$ 个顶点集）产生一个环。

注意到，如果原子集 $M$ 是 Comp($\Pi$)的模型但不是 $\Pi$ 的回答集，依定理 5.1.3，必有 $\Pi$ 的环使得其环公式不被 $M$ 满足。下面的结果表明，这样的环公式可以在多项式时间找到。

令 $M = M C_n(\Pi^M)$，其中 $M$ 是 Comp($\Pi$)的模型，$\Pi^M$ 是 $\Pi$ 关于 $M$ 的归约，$C_n(\Pi^M)$ 是确定程序 $\Pi^M$ 的结论集。令 $G_\Pi^+$ 是 $\Pi$ 的原子正相依图，即 $G_\Pi^+$ 的顶点集由 $\Pi$ 中所有原子组成，对任意两个顶点 $A$ 和 $B$，若有规则 $r \in \Pi$，使得 $\{A\}=Head(r)$ 且 $B \in Pos(r)$，则有一条从 $A$ 到 $B$ 的正边 $<A,B>$。
