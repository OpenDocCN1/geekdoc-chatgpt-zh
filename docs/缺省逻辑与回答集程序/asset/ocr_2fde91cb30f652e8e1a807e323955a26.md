# 1.1.2 关系

集合 A1,...,An 上的 n (n≥1) 元关系 R 是 A1×...×An 的子集，即 R⊆A1×...×An。称 A1,...,An 为 R 的定义域，记作 dom(R)，n 为 R 的阶。对于任何 ai∈Ai (1≤i≤n)，记<a1,...,an>∈R 为 R(a1,...,an)，表示<a1,...,an> (或者 a1,...,an 之间依此次序) 具有 R 性质。称集合 {<a1,...,an>|<a1,...,an>∈R, ai∈Ai, 1≤i≤n} 为 R 的值域，记作 ran(R)。

于是，集合 S 上的 n 元关系 R 是集合 {<a1,...,an>|ai∈S, 1≤i≤n 并且 a1,...,an 之间 (依此次序) 具有 R 性质}。

当 n=2 时，称关系 R⊆A×B 为从 A 到 B 的二元关系。通常，用 xRy 表示 R(x,y)。当 n=1 时，S 上的一元关系 R 是 S 的一个子集，R(x)表示 S 中元素 x 具有 R 性质。

设 R 是 S 上的 n 元关系且 S1⊆S，R 到 S1 的限制记作 R|S1^n，是关系 R ∩ S1^n。

相等关系是任意集合 S 上的一个特殊的二元关系，其定义为集合 {<x,y>|x,y∈S 且 x=y}，即 {<x,x>|x∈S}，它是 S^2 的子集。

关系作为集合，同样有并、交、差和补运算。二元关系中的一个特殊运算，称为合成，记为∘。设 R 是集合 A 到集合 B 的关系，T 是集合 B 到集合 C 的关系，则 R 和 T 的合成 R∘T 是集合 {<a,c>|a∈A, c∈C 且存在 b∈B，使得<a,b>∈R 且 <b,c>∈T}，该集合是 A 到 C 的二元关系。

对于集合 A 上的二元关系 R，我们定义一些重要性质。

如果对任何 a∈A，有<a,a>∈R，则称 R 是自反的。如果对任何 a∈A，有<a,a>∉R，则称 R 是反自反的。如果对任何 a,b∈A，若<a,b>∈R，则<b,a>∈R，则称 R 是对称的。如果对任何 a,b∈A，若<a,b>∈R 且 <b,a>∈R，则 a=b，则称 R 是反对称的。如果对任何 a,b,c∈A，若<a,b>∈R,<b,c>∈R，则<a,c>∈R，则称 R 是传递的。

设 R 是集合 S 上的关系，R 的幂 R^n (n=1,2,...) 递归地定义为 R^1=R 和 R^{n+1}=R^n∘R (n=1,2,3,...)。

容易证明，集合 S 上的二元关系 R 是传递的当且仅当对 n=1,2,..., R^n⊆R 成立。

集合 S 上的关系 R 是等价关系，如果 R 是自反、对称且传递的。对于任何 x∈S，称集合[x]_R={y∈S 且 xRy} 为 x 的等价类 (当不混淆时，记作[x])。容易证明，对于任何 x,y∈S，有

+   (1) <x,y>∈R 当且仅当[x]=[y];
+   (2) <x,y>∉R 当且仅当[x]∩[y]=Ø;
+   (3) ∪x∈S[x]=S。
