的极小性。因此，

DEF(C_n(\Pi))=C_n(DEF(\Pi) \cup Contr)

当 \Pi 协调时，由映射 C_n 的极小性可得 DEF(C_n(\Pi))=C_n(DEF(\Pi))。

因此，确定程序的主要性质（如 C_n 的单调性、紧性等）对于基本逻辑程序也成立（某些性质可能需要适当修改，如限于协调的基本程序）。类似地，可以给出协调的基本程序的 SLD 消解证明方法。只需注意，相应于定理 2.3.8 的结论是协调的基本程序 \Pi 的成功集等于它的结论集。

# 例 2.3.5 基本程序

\Pi = \{p, \neg q, r \leftarrow p, q, \neg r \leftarrow p, \neg q, s \leftarrow r, s \leftarrow p, s, \neg s \leftarrow p, \neg q, \neg r\}

有唯一回答集 \{p, \neg q, \neg r, \neg s\}，它是关于 \Pi 封闭且逻辑封闭的唯一最小文字集。通过 DEF 转换 \Pi 得到

DEF(\Pi) = \{p, q^+, r \leftarrow p, q, r^+ \leftarrow p, q^+, s \leftarrow r, s \leftarrow p, s, s^+ \leftarrow p, q^+, \neg r^+\}

确定程序 DEF(\Pi) 有唯一回答集 \{p, q^+, r^+, s^+\}，它满足 Contr。易知，\{p, q^+, r^+, s^+\} 是确定程序 C_n(DEF(\Pi) \cup Contr) 的回答集，DEF^{-1}(\{p, q^+, r^+, s^+\}) = \{p, \neg q, \neg r, \neg s\} (DEF^{-1} 是 DEF 的逆映射)。

协调的基本程序 \Pi 有最小 Herbrand 模型 M_\Pi，由此，有

C_n(\Pi) = \{A | A \in Head(\Pi) \cap M_\Pi\} \cup \{\neg A | \neg A \in Head(\Pi) 且 A \in M_\Pi\}

给定基本程序 \Pi，定义算子 T_\Pi: 2^{Lit} \to 2^{Lit} 如下，对任意文字集 S，如果 S 协调，则 T_\Pi(S) = \{L_0 | L_0 \leftarrow L_1, \cdots, L_n \in \Pi, \{L_1, \cdots, L_n\} \subseteq S\}；否则，T_\Pi(S) = Lit。

于是，类似于确定程序或利用 DEF 映射，容易证明，对于基本程序 \Pi，C_n(\Pi) = lfp(T_\Pi)，并得到 C_n(\Pi) 的自底向上计算方法。

为此，定义算子 T_\Pi: 2^{Lit} \to 2^{Lit} 为：对任意文字集 S，若 S 协调，则 T_\Pi(S) = \{L_0 | L_0 \leftarrow L_1, \cdots, L_n \in \Pi, \{L_1, \cdots, L_n\} \subseteq S\}；否则，T_\Pi(S) = Lit。

由于 (2^{Lit}, \cup, \cap, \neg) 是完备格，T_\Pi 是连续函数，因此 T_\Pi 有最小不动点 lfp(T_\Pi)，且 lfp(T_\Pi) = T_\Pi \uparrow \omega。

# 定理 2.3.10 对任意协调的基本程序 \Pi，C_n(\Pi) = T_\Pi \uparrow \omega。

证明

首先，施归纳于 n，容易证明 T_\Pi \uparrow \omega \subseteq C_n(\Pi)。

基始 n=0 时，T_\Pi \uparrow 0 = \emptyset，T_\Pi \uparrow 0 \subseteq C_n(\Pi) 显然成立。

归纳 设 n \ge 0，T_\Pi \uparrow n \subseteq C_n(\Pi)。若 L \in T_\Pi \uparrow (n+1)，则有 L \leftarrow L_1, \cdots, L_n \in \Pi，使得 \{L_1, \cdots, L_n\} \subseteq T_\Pi \uparrow n。于是，\{L_1, \cdots, L_n\} \subseteq C_n(\Pi)。因为 C_n 关于 \Pi 封闭，故 L \in C_n(\Pi)。因此，T_\Pi \uparrow (n+1) \subseteq C_n(\Pi)。

由于 \Pi 是协调的且 T_\Pi \uparrow \omega 关于 \Pi 是封闭的，由 C_n(\Pi) 的极小性可得 C_n(\Pi) = T_\Pi \uparrow \omega。
