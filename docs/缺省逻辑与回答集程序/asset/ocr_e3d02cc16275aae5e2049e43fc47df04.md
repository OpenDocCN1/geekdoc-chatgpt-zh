多项式时间算法求解，故 coSR 在 $\Sigma_2^p$ 中，这蕴含 SR 在 $\Pi_2^p$ 中。

类似地，可以证明 SR* 在 $\Pi_2^p$ 中。对于 CR* 问题，考虑算法 CR* 的非确定变种：猜测一个适当的集合 D'，使得存在集合 D'，当且仅当存在 $\Delta$ 的一个扩张 E，使得 $\Phi \in E$。对这一猜测的测试部分，除耗费多项式次数的命题推导测试外，它是在多项式时间完成的，故此问题是在 $\Sigma_2^p$ 中。

其次，证明 SR 是 $\Sigma_2^p$-困难的。已经证明，下述问题是 $\Sigma_2^p$-完全的： Q 是真的吗？其中 Q 是一个形如 $\exists p_1 \cdots \exists p_n \forall q_1 \cdots \forall q_m \Phi$ 的量词约束的公式，其中 $p_i (1 \leqslant i \leqslant n)$ 和 $q_j (1 \leqslant j \leqslant m)$ 是两个不同命题变元，$\Phi$ 是由 $p_1, \cdots, p_n, q_1, \cdots, q_m$ 构成的命题公式。Q 为真当且仅当存在对命题变元 $p_1, \cdots, p_n$ 的赋值使得此赋值对命题变元 $q_1, \cdots, q_m$ 的任一拓广，$\Phi$ 为真。

映射 Q 为 ADT, $\Delta_Q=\{D,W\}$, 其中

```
W=\emptyset
```

```
D=\{T:p_i/p_i, T:\neg p_i/\neg p_i | 1 \leqslant i \leqslant n\}
```

另一方面，依联合相容性，$\Delta_Q$ 的每一扩张 E 的生成规则集 $GD(E, \Delta_Q)$ 包含且只包含对子 $T:p_i/p_i$ 和 $T:\neg p_i/\neg p_i (1 \leqslant i \leqslant n)$ 中的一个。另一方面，$GD(E, \Delta_Q)$ 的极大性保证了由其诱导的这些对子的每一对中至少有一个缺省属于 $GD(E, \Delta_Q)$。因此，$\Delta_Q$ 恰好有 $2^n$ 个扩张，它们正好对应于变元 $p_1, \cdots, p_n$ 的 $2^n$ 种赋值。依推论 7.2.1，对每一这样的赋值 v，相应的扩张 $E_v$ 是

```
E_v=\text{Ths}(\{\langle p_i, \{p_i\}\rangle | p_i^v=1, 1 \leqslant i \leqslant n\} \cup \{\langle \neg p_i, \{\neg p_i\}\rangle | p_i^v=0, 1 \leqslant i \leqslant n\})
```

对每一这样的赋值 v，令 $T_v$ 是命题理论

```
T_v=\{\{p_i | p_i^v=1, 1 \leqslant i \leqslant n\} \cup \{\neg p_i | p_i^v=0, 1 \leqslant i \leqslant n\}
```

容易证明， Q 为真且仅当存在一个赋值 v，使得 $T_v \vdash \Phi$。依推论 7.2.2, $\Phi \in \text{Form}(E_v)$ 当且仅当 $T_v \vdash \Phi$。由此导出，Q 为真，当且仅当 $\Delta_Q \vdash_c \Phi$。显然，转换 Q 为 ADT，$\Delta_Q=\{D,W\}$ 是多项式时间可实现的，故 CR* 是 $\Sigma_2^p$ -困难的。

对 SR 和 SR*，只需证明，对应的补问题是 $\Sigma_2^p$ -困难的。

考虑一个 ADT, $\Delta'_Q=\{D', W'\}$, 其中

```
W=\emptyset
```

```
D' = D \cup \{T: \neg \Phi' / \Phi'\}
```

不难看出，$\Delta'_Q$ 有满足 $\text{Form}(E) \nvdash \Phi$ 的扩张 E 当且仅当 Q 为真。由此可得 SR* 的补问题是 $\Sigma_2^p$ -困难的。
