的结果：

+   - $(\varphi_1 \vee \varphi_2)|D = \varphi_1|_D \vee \varphi_2|_D;$

+   - $(\neg \varphi)|D = \neg (\varphi|_D).$

其他联结词，比如 $\wedge$ 和 $\vee$，通常作为缩写，即 $\varphi_1 \wedge \varphi_2$ 和 $\forall x \phi$ 分别是 $\neg (\neg \varphi_1 \vee \neg \varphi_2)$ 和 $\neg \exists x \neg \phi$ 的缩写。

一阶闭理论（即一阶语句集）$T$ 在 $D$ 上的实例化是 $T$ 中的语句在 $D$ 上的实例化的集合，记为 $T|D$。

给定一变量集 $V$ 和一常量集 $D$，$V$ 到 $D$ 的映射称为 $V$ 在 $D$ 上的变元赋值（或变元指派）。令 $r$ 是一规则，$\theta$ 是一变元指派，则 $r\theta$ 是用 $\theta$ 中变元的值代替 $r$ 中的对应变元而得到结果。

我们用 EQ 表示等词的一阶闭理论（包含描述自反、对称和传递的一阶公式）。若 $\Pi$ 是正规逻辑程序，$\Pi|D$ 表示程序 $\{r\theta | r \in \Pi, \theta \text{ 是 } \text{var}(r) \text{ 到 } D \text{ 的变元指派}\}$。

例如，给定 $D=\{a,b\}$，$\forall x(p(x) \leftarrow x=a)$ 在 $D$ 上的实例化逻辑等价于 $p(a) \wedge \neg p(b)$。

对于正规程序 $\Pi=\{p(a) \leftarrow q(x,y)\}$，$\Pi|D$ 是

$\{ p(a) \leftarrow q(a,a), p(a) \leftarrow q(a,b), p(a) \leftarrow q(b,a), p(a) \leftarrow q(b,b) \}$

定义 5.3.1 令 $\Pi$ 是正规程序，$r=p(t) \leftarrow \text{Body} \in \Pi$，其中 $t=<t_1, \cdots, t_n>$，$t_1, \cdots, t_n$ 是项。$r$ 的标准化是规则 $p(\boldsymbol{x}) \leftarrow t=\boldsymbol{x} \cup \text{Body}$，其中 $\boldsymbol{x}=<x_1, \cdots, x_n>$ 且 $x_1, \cdots, x_n$ 是两两互不相同且不在 $r$ 中出现的变元。$\Pi$ 的标准化是 $\Pi$ 中所有规则标准化后的结果。称出现在规则 $r$ 中但不出现在 $\text{Head}(r)$ 中的变元为局部变元。

以上讨论的程序总是有穷的，通过重命名，可以使得 $\Pi$ 的每条标准化后的规则头中的变元至多出现 $x_1, \cdots, x_n$ 且它们都不在 $\Pi$ 中出现。以下总假设程序都是标准化的。

通过程序的标准化，程序的一阶完备化可定义如下。

定义 5.3.2 令 $\Pi$ 是正规程序，$p$ 是 $\Pi$ 中出现的谓词。$p$ 关于 $\Pi$ 的完备，记为 $\text{COMP}(p, \Pi)$，是如下公式：

$\forall \boldsymbol{x} \left( p(\boldsymbol{x}) \leftrightarrow \vee_{1 \le i \le k} \exists \boldsymbol{y}_i \overline{\text{Body}_i} \right)$

其中，

+   - $p(\boldsymbol{x}) \leftarrow \text{Body}_1, \cdots, p(\boldsymbol{x}) \leftarrow \text{Body}_k$ 是 $\Pi$ 的标准化结果的规则头中出现谓词 $p$ 的所有规则；

+   - $\overline{\text{Body}_i}$ 是 $\text{Body}_i$ 中所有元素的合取式，并且其中的 “not” 用 “$\neg$” 替换；

+   - $y_i$ 是规则 $p(\boldsymbol{x}) \leftarrow \text{Body}_i$ 中的所有局部变元 $y_1, \cdots, y_m$ 组成的向量 $<y_1, \cdots, y_m>$。
