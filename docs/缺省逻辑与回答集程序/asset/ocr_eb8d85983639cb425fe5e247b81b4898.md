# 定理 2.1.7 设 S 是一阶公式 A 的子句集，A 是不可满足的，当且仅当存在一个使用消解规则从 S 到空子句⊥的消解反驳。

证明 “当” 设有 S 到⊥的消解反驳，令 R1,R2,...,Rn (n>=1) 是此消解反驳中的消解式且 Rn=⊥。施归纳于消解反驳的长度 n 证明：S 是不可满足的。

基始 设 n=1，则必有 S 中子句 L1 和 L2 及一个 mgu θ，使得 L1θ=L2̄ θ 且 R(C,¬C)=⊥，其中 L1 和 L2 是文字。依定理 2.1.6, C1∧C2⊨R(C1,C2)，这表明，C1∧C2 是不可满足的。因为 S=C1∧C2，故 S 是不可满足的，从而 A 是不可满足的。

归纳 设对于长度为 n 的由任一子句集 T 到⊥的消解反驳，T 是不可满足的。考虑有长度为 n+1 的 S 到⊥的消解反驳 R1,R2,...,Rn+1，令 R1 是 S 中子句 C1 和 C2 的消解式，其中 Rn+1=⊥。依定理 2.1.6, C1∧C2⊨R1；进而，S⊨C1∧C2⊨R1。因为 R2,...,Rn+1 是 S∪{R1} 到⊥的长度为 n 的消解反驳，依归纳假设，S∪{R1} 是不可满足的，由 S⊨C1∧C2 立得 S⊨S∪{R1}，从而 S 是不可满足的。

“仅当” 设 S 是不可满足的，令 {A1,...,An} 是出现在 S 中的所有一阶原子的集合。令 T 是一棵如图 2-2 所示的完全语义树。

依定理 2.1.4, T 有一棵有穷封闭语义树 T' 。若 T' 仅由一个（根）结点组成，因为没有任何不同于⊥的子句能够在语义树的根失败，故⊥必在 S 中。从而，定理显然成立。设 T' 由多于一个的结点组成，则 T' 必有至少一个推导结点。否则，每个结点至少有一个子孙，从而可以找到一棵通过 T' 的无穷分支，这与 T' 是有穷封闭语义树矛盾。令 N 是 T' 中的一个推导结点，N1 和 N2 是直接在 N 下面的失败结点，且令

I(N)={m1,m2,...,mn}
I(N1)={m1,m2,...,mn,mn+1}
I(N2)={m1,m2,...,mn,-mn+1}
