# 引理 5.2.2 令 Pi 是嵌套程序，F 和 G 是等价公式。任何由 Pi 通过用 G 替换 Pi 中 F 的正则出现得到的程序与 Pi 等价。

证明 设 Pi' 是通过用 G 替换 Pi 中 F 的正则出现得到的任一程序，协调文字集 X 封闭于 (Pi')^Y，其中，Y 是协调文字集。对 Pi 中任一规则 F<->G 及其在 Pi' 中的对应规则 F'<->G'，若 X=<,n(G)^Y，则 X=<,n(F)^Y。依引理 5.2.1, F<->F' 且 G<->G'。因此，若 X=<,n G^Y，则 X=<,n F^Y，这蕴含 X 封闭于 Pi^Y。类似地可以证明，若 X 封闭于 Pi^Y，则 X 封闭于 (Pi')^Y。于是，引理获证。
