\(\Pi' \subseteq \Pi\), 使得
（1）对某一协调文字集 \(S, (\Pi', S) \in \Lambda(\Pi')\) （即存在在 \((\Pi'(S), S) \in \Lambda(\Pi')\) 使得 \(\Pi' = \Pi'(S)\)）；
（2）\(\Pi'\) 是 \(S\)-相容的；
（3）对任一规则 \(C \leftarrow B, F \in \Pi \setminus \Pi', S \not\models_n B, F\)。

证明 “仅当” 依推论 5.2.14，令 \(\Pi' = GR(S, \Pi)\)，即获证。
“当” 因为 \((\Pi', S) \in \Lambda(\Pi')\) 且 \(\Pi'\) 是 \(S\)-相容的，故
\(\Pi' \subseteq \{C \leftarrow B, F \in \Pi' | S \models_n (B, F)\}\)

根据推论 5.2.4， \(S\) 封闭于 \(\Pi'\)，故 \(\{C \leftarrow B, F \in \Pi' | S \models_n (B, F)\} \subseteq \Pi'\)。因此， \(\Pi' = \{C \leftarrow B, F \in \Pi' | S \models_n (B, F)\}\)。因此， \((\Pi')^S = \{C \leftarrow B | C \leftarrow B, F \in \Pi, S \models_n (B, F)\} = \{C \leftarrow B \in \Pi' | S \models B\}\)。

对任意一规则 \(r = C \leftarrow B, F \in \Pi - \Pi'\)，依本定理的条件（3）， \(S \not\models_n B, F\)。若 \(S \not\models_n F\)，则 \(C \leftarrow B \notin \Pi^S\)；若 \(S \not\models_n B\)，则 \(C \leftarrow B \notin \Pi^S(S)\)。因此， \((\Pi')S \in \Lambda(\Pi^S)\)。由定理 5.2.3， \(S\) 是 \(\Pi^S\) 的回答集，因此 \(S\) 是 \(\Pi\) 的回答集。

例 5.2.1（续） 依识理 5.2.5， \(\Pi_1 = \{A; \text{not } A \leftarrow \top\}\) 等价于 \(\Pi_2 = \{A \leftarrow \top, \text{not not } A\}\)，故只需考虑 \(\Pi_2\)。因为 \(\emptyset \subseteq \Pi_2\)， \(\emptyset\) 是强相容的， \(\emptyset \not\models_n \text{not } A\)，故 \(\emptyset\) 是 \(\Pi_2\) 的一个回答集。由 \(A(\Pi_2) = \{(\Pi_2, \{A\})\}\) 且 \(\Pi_2\) 是 \(\{A\}\)-相容的，则 \(\{A\}\) 也是 \(\Pi_2\) 的一个回答集。

由回答集的特征定理可以得到回答集和推理问题的算法。给定一个嵌套程序，审慎推理（SR）是判定一个文字是否属于该程序的所有回答集；冒险推理（CR）是判定一个文字是否属于该程序的一个回答集。下面算法中函数 SM， LAMBDA，GA 分别计算程序 \(\Pi\) 的 Head 的极小模型， \(A(\Pi)\) 和回答集的生成规则集， \(CR(L, \Pi)\) 和 \(SR(L, \Pi)\) 分别处理冒险推理与审慎推理问题。

```
FUNCTION SM(\Pi)
IF SM (\{C | C \leftarrow \in \Pi\}) = \emptyset then RETURN (\emptyset, \emptyset)
result := (\{C | C \leftarrow \in \Pi\}
S := S_0 for some S_0 \in SM(Head(result))
REPEAT
    new := \emptyset
    T = \{C | C \leftarrow B, F \in \Pi, S \models B\}
    IF SM(Head(T)) = \emptyset or there is no V \in SM(Head(T)) such that S \subseteq V
    then RETURN (result, S)
    new := new \cup (T \backslash result)
    result := result \cup T
    S := V for some V \in SM(Head(result))
UNTIL new = \emptyset
```
