子集，$A \in \Pi_A^+$ 且对每一规则 $r \in \Pi$：
若 Head($r$) $\in \Pi_A^+$，则 Pos($r$) $\subseteq \Pi_A^+$，Neg($r$) $\subseteq \Pi_A^-$；
若 Head($r$) $\in \Pi_A^-$，则 Pos($r$) $\subseteq \Pi_A^-$，Neg($r$) $\subseteq \Pi_A^+$。

直观上，$\Pi_A^+$ 是关于 $A$ 正依赖于 $\Pi$ 的所有原子的集合，而 $\Pi_A^-$ 则是关于 $A$ 负依赖于 $\Pi$ 的所有原子的集合。因此，$\Pi$ 是有正负之分的程序。

从上述定义知，对任一原子 $A$，若 $A 
otin Head(\Pi)$，则 $\Pi_A^+=\{A\}$，$\Pi_A^-=\emptyset$。对任一 $A \in Head(\Pi)$，在相依图 $G_\Pi$ 中的原子要么是孤立点（度数为 0 的顶点），要么组成形如 $A \leqslant A_1 \leqslant A_2 \leqslant \cdots$ 或 $A \leqslant_0 A_1 \leqslant_0 A_2 \leqslant_0 \cdots$ 的链（这样的链可能是有穷或无穷的，也可能是初始与终止顶点相同的），如程序 $\{A \leftarrow A, 	ext{not } A\}$，$\Pi_A^+$ 和 $\Pi_A^-$ 中分别有链 $A \leqslant^+ A$ 和 $A \leqslant^- A$。

定义 4.3.2 给定一正规程序 $\Pi$，若存在层次映射 $\lambda$，使得对每一原子 $A$，当 $B \in \Pi_A^+ \cap \Pi_A^-$ 成立时，$\lambda(B) < \lambda(A)$ 成立，则称 $\Pi$ 是序协调的。若 $\Pi$ 是序协调的且对任意原子 $A$，$\Pi_A^+ \cap \Pi_A^- = \emptyset$，则称 $\Pi$ 是严格序协调的。如果 $G_\Pi$ 中相依关系 $\leqslant_0$ 是良基的，则称 $\Pi$ 是正序协调的。

从相依图的观点看，正规程序 $\Pi$ 是序协调的，当且仅当 $G_\Pi$ 中相依关系 ($\leqslant^+$ 和 $\leqslant^-$) 是良基的。

显然，局部分层的正规程序是序协调的。实际上，设 $\lambda$ 是相应于局部分层正规程序 $\Pi$ 的任一层次映射，对任意基原子 $A$ 和 $B$，易知，若 $B \in \Pi_A^+$，则 $\lambda(B) \leqslant \lambda(A)$；若 $B \in \Pi_A^-$，则 $\lambda(B) < \lambda(A)$。

容易证明，序协调的正规程序类 $\subseteq$ 序协调程序类 $\subseteq$ 无负环程序类

# 例 4.3.1 对以个体符号 $\{a, b\}$ 为论域的程序

```
$\Pi_1 = \{p(x) \leftarrow \text{not } q(x), q(x) \leftarrow \text{not } p(x), r(x) \leftarrow p(x), r(x) \leftarrow q(x)\}$
```

有

```
$\Pi_1^+_{p(x)} = \{p(x)\}, \Pi_1^-_{p(x)} = \{q(x)\}$
$\Pi_1^+_{q(x)} = \{q(x)\}, \Pi_1^-_{q(x)} = \{p(x)\}$
$\Pi_1^+_{r(x)} = \{r(x), p(x), q(x)\}, \Pi_1^-_{r(x)} = \emptyset\)
```

定义层次映射 $\lambda$ 为 $\lambda(p(x))=\lambda(q(x))=\lambda(r(x))=0$，其中 $x \in \{a, b\}$，易知 $\Pi_1$ 是序协调的。

然而，对任意映射 $\lambda$，若 $\lambda(p(a)) < \lambda(q(a))$ 对规则 $p(x) \leftarrow \text{not } q(x)$ 成立，则它对 $q(x) \leftarrow \text{not } p(x)$ 不真；若 $\lambda(q(a)) < \lambda(p(a))$ 对 $q(x) \leftarrow \text{not } p(x)$ 成立，则它对 $p(x) \leftarrow \text{not } q(x)$。
