+   (1) Head(A(Π))是封闭于A(Π)且是A(Π)支承的；
+   (2) Head(A(Π))是A(Π)^Cmp 的稳定模型；
+   (3) Π是强相容的，当且仅当Π=A(Π)。

正规程序回答集的特征可以由如下定理表述。

**定理 4.2.2*** 正规程序Π有回答集 S 当且仅当存在Π的子集Π*，使得

+   (1) Π*是强相容的且 S=Head(Π*)；
+   (2) 对任一 r ∈ Π \ Π*，Pos(r) \ S 或 Π* ∪ {r} 是不相容的。

类似于缺省逻辑，可知定理 4.2.2 和定理 4.2.2*中的Π*实际上就是 GR(S, Π)。

由定理 3.3.1 和定理 4.2.1 可得如下推论。

**推论 4.2.2** 令Π是正规程序，若A(Π)是相容的，则Π有唯一回答集 S=Head(A(Π))。特别地，若Π是相容的，则Π有唯一回答集 S=Head(A(Π))。

**定义 4.2.3** 设Π是正规程序，

+   (1) 令Π* ⊆ Π 是强相容的且 S=Head(Π*)，对任一 r ∈ Π \ Π*，如果 Pos(r) \ S 或 Π* ∪ {r} 是不相容的，则 r 是关于Π*弱自相容的。
+   (2) 对任一 r ∈ Π，如果 r 是关于Π的任一强相容子集Π*弱自相容的，则 r 是关于Π弱自相容的。
+   (3) 如果每一 r ∈ Π 是关于Π弱自相容的，则Π是弱自相容。

显然，自相容的正规程序是弱自相容的，Ø是任意正规程序的强相容子集，不协调的正规程序不是弱自相容的，其唯一的极大相容子集是空集Ø。

**定理 4.2.2*** 正规程序Π有回答集 S，当且仅当存在Π的强相容子集Π*，使得 S 是Π*的回答集且对任意 r ∈ Π \ Π*，r 是关于Π*弱自相容的。

**推论 4.2.3** 设基原子集 S 是正规程序Π的回答集，则 GR(S, Π)是强相容的且对任一 r ∈ Π，r 关于 GR(S, Π)是弱自相容的。

**定理 4.2.3** 弱自相容的正规程序Π有回答集；对Π的任一极大强相容子集Π*，Head(Π*)是Π的一个回答集。

**定义 4.2.4** 正规程序Π是半单调的，当且仅当对任意正规程序Π* 和 Π**，若 Π* ⊆ Π** ⊆ Π，则对Π*的每一回答集 S* 总有Π**的回答集 S**，使得 S* ⊆ S**。

**定理 4.2.4（弱自相容性的特征）** 正规程序Π是弱自相容的，当且仅当它是半单调的。

**例 4.2.1** 正规程序Π={B←, A←B, not C}是弱自相容的且有唯一回答集{B, A}，其中 A, B 和 C 是基原子。增加规则 C←A, not E 后得到的程序Π'有两个极大强相容子集{B←, A←B, not C}和{B←, C←A, not E}。但Π'不是弱自相容的，它没有回答集。
