DEF(S)={DEF(L)|L∈S}
DEF(L₀←L₁, ⋯, Lₙ)=DEF(L₀)←DEF(L₁), ⋯, DEF(Lₙ)
DEF(←L₁, ⋯, Lₙ)=←DEF(L₁), ⋯, DEF(Lₙ)
DEF(Π)={DEF(r)|r∈Π}

显然，DEF 是从 Atom 上的基本程序集到 Atom ∪ Atom⁺ 上的确定程序集的 1-1 映射。为转换基本程序Π为确定程序 DEF(Π)，只需将Π中出现的每一负文字—A 用 A⁺代替即可。进而，容易将确定程序的有关结果扩展到基本程序。

为此，用 Contr 记矛盾规则 A←B,B⁺ 和 A⁺←B,B⁺ 的集合，其中 A 和 B 是 Atom 中任一不同原子对。显然，任意协调的文字集 S，DEF(S) 和 DEF(Lit)都关于 Contr 逻辑封闭。易见，任一文字集 S⊆GLit，S 是协调的，当且仅当 DEF(S)不包含任何形如 A 和 A⁺的基原子对。于是，Contr 的语义为：任何协调的文字集都满足 Contr。

映射 DEF(L)具有如下性质：

# 定理 2.3.9 令 Π 是基本程序，则

+   (1) C_n(Π)={A|A∈Atom ∩ DEF(C_n(Π))} ∪ {¬A|A⁺∈Atom⁺ ∩ DEF(C_n(Π))}，若 Π 协调；

+   (2) C_n(Π)=Lit，若 Π 不协调；

+   (3) DEF(C_n(Π))=C_n(DEF(Π) ∪ Contr)。

特别地，若 Π 协调，则 DEF(C_n(Π))=C_n(DEF(Π))。

证明 设 Π 不协调，则 C_n(Π)不协调，Lit 是关于 Π 封闭且逻辑封闭的最小文字集，依定义 2.3.7，C_n(Π)=Lit。

设 Π 协调，依定义 2.3.7，C_n(Π)协调且是关于 Π 封闭且逻辑封闭的最小文字集。容易证明，S={L|L←Body∈Π 且 Body⊆C_n(Π)} 是关于 Π 封闭的最小文字集，故 S=C_n(Π)。依 DEF 的定义，有

C_n(Π)={A|A∈Atom ∩ DEF(C_n(Π))} ∪ {¬A|A⁺∈Atom⁺ ∩ DEF(C_n(Π))}

对不协调的基本程序，DEF(C_n(Π))=Atom ∪ Atom⁺。因此，对任一基本程序，有

DEF(C_n(Π))={A|A∈C_n(Π) 且 A∈Atom} ∪ {A⁺|¬A∈C_n(Π) 且 A∈Atom}

C_n(Π)={A|A∈Atom ∩ DEF(C_n(Π))} ∪ {¬A|A⁺∈Atom⁺ ∩ DEF(C_n(Π))}

因为 C_n(Π)关于 Π 逻辑封闭，故 DEF(C_n(Π))关于 DEF(Π)逻辑封闭。当 Π 协调时，C_n(Π)协调，则 DEF(C_n(Π))不包含任何形如 A 和 A⁺的原子对。因此，DEF(C_n(Π))关于 Contr 逻辑封闭。如果 Π 不协调，则 C_n(Π)=Lit，DEF(C_n(Π))=Atom ∪ Atom⁺关于 Contr 逻辑封闭。于是，DEF(C_n(Π))关于 DEF(Π) ∪ Contr 逻辑封闭。由 C_n(Π)关于 Π 逻辑封闭的极小性，容易推导出 DEF(C_n(Π))关于 DEF(Π) ∪ Contr 逻辑封闭
