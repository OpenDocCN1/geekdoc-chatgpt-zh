```
BOOLEAN FUNCTION CR(A,R,D,W)
IF R U Form(W) U Supp(W) ⊢ false THEN RETURN (false);
IF MEMBER (A,R,D[R],W[R]) THEN RETURN (true)
ELSE RETURN (false)
```
