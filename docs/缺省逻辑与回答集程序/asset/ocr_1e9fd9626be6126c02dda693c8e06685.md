\(\Pi_{eq}|D\) 的环，则 \(\Pi\) 有一阶正环 \(L\)，使得 \(GL=L\theta\)，其中 \(\theta\) 是变元集 \(var(L)\) 到 \(D\) 的变元指派。反之，若 \(L\) 是 \(\Pi\) 的一阶正环且 \(\theta\) 是变元集 \(var(L)\) 到 \(D\) 的变元指派，则 \(L\theta\) 是 \(\Pi_{eq}|D\) 的一阶正环。

证明 首先，若令 \(A, B\) 是 \(\Pi_{eq}|D\) 中不涉及 eq 的两个原子， \(d_1, \cdots, d_n\) 是在 \(A, B\) 中出现但不在 \(Const(\Pi)\) 中出现的常元， \(A', B'\) 是用 \(d_i\) 分别替换 \(A, B\) 中出现的 \(x_i\) 得到的原子。可以证明 \(<A,B>\) 是 \(\Pi_{eq}|D\) 的相依图中的弧，当且仅当 \(<A', B'>\) 是 \(\Pi\) 的相依图中的弧。

\(<A,B>\) 是 \(\Pi_{eq}|D\) 的相依图中的弧，当且仅当 \(A \leftarrow B, Body \in \Pi_{eq}|D\);

当且仅当存在 \(\alpha \leftarrow \beta, Body \in \Pi\) 且有一个变元集到 \(D\) 的变元指派 \(\theta\)，使得 \(A=\alpha\theta\) 且 \(B=\beta\theta\);

当且仅当存在 \(\alpha \leftarrow \beta, Body \in \Pi\) 且有一个置换 \(\theta'\), 使得 \(A'=\alpha\theta'\) 且 \(B'=\beta\theta'\), 其中 \(\theta'\) 是将 \(\theta\) 中的 \(d_i\) 替换为 \(x_i\) 得到的;

当且仅当 \(<A', B'>\) 是 \(\Pi\) 的相依图中的弧。

其次，因为 \(GL=\{A_1, \cdots, A_n\}\) 是 \(\Pi_{eq}|D\) 的一阶正环，则其相依图有一路径 \(<A_1, \cdots, A_n, A_{n+1}>(A_{n+1}=A_1)\)。注意，对每一 \(i: 1 \leqslant i \leqslant n\), \(A_i\) 不涉及 eq 且 \(<A_i, A_{i+1}>\) 是 \(\Pi_{eq}|D\) 的相依图中的弧，故对 \(1 \leqslant i \leqslant n\), \(<< A'_i, A'_{i+1}>\) 是 \(\Pi\) 的相依图中的弧。因此， \(L=\{A', \cdots, A'_n\}\) 是 \(\Pi\) 的环且 \(GL=L\theta\), \(\theta=\theta_1 \circ \cdots \circ \theta_n\), 其中 \(\theta_i(i=1, \cdots, n)\) 是使得 \(<A_i, A_{i+1}>=<A', A'_{i+1}>\) 的置换。

同理可证，若 \(L=\{A'_1, \cdots, A'_n\}\) 是 \(\Pi\) 的环， \(\theta\) 是变元集 \(var(L)\) 到 \(D\) 的变元指派，则 \(L\theta\) 是 \(\Pi_{eq}|D\) 的环。只需注意，依假设 \(Const(\Pi) \subseteq D\), 故每一 \(A'_i \theta(1 \leqslant i \leqslant n)\) 是 \(\Pi\) 的相依图中的顶点。

下面的断言表明，定义 5.1.3 关于基例化正规逻辑程序的外部支承和环公式及程序的完备的定义是分别与定义 5.3.5 和定义 5.3.6 关于一阶正环的外部支承和一阶环公式及一阶完备的定义等价。
