广自然数的定义。

令 S 是一个集合，称 S 是一个序数当且仅当 S 满足：
（1）对任意 x,y，若 x∈y 且 y∈S，则 x∈S；
（2）对任意 x,y，若 x∈S 且 y∈S，则 x∈y 或 x=y 或 y∈x；
（3）S 中不存在无穷多个 x1, x2, ...，使得 xi+1∈xi。

显然，每一自然数是序数，即第一个序数 0=∅，第二个序数 1={∅}，第三个序数 2={∅,{∅}}={0,1}， ... 。

关系<是所有序数的汇聚上的序。定义：对任意序数α和β，若α∈β，则α<β。
α≤β当且仅当α<β或α=β。对任一序数α，令 α+1=α∪{α}。对任一序数α，若有序数β，使得α=β+1，则称α是后继的。一个非 0 的序数如果不是后继的，则称它是极限序数。

记ω={0,1,2,...}（全体自然数的集合），可以看出，ω是最小的无穷序数，即第一个无穷序数。于是，ω+1=ω∪{ω}，ω+2=ω+1∪{ω}， ... ；第二个无穷序数是 ω2={n|n∈ω}∪{ω+n|n∈ω}；随后是ω2+1, ... ,ω3,ω3+1, ... 。

拓广序列<a1, ... , an>（n≥1）的概念到任意序数α。一个超穷序列是以序数的一个初始段{α|α<μ}为下标的元素族，记作<aα>α<μ。该序列的长度为μ。类似地，推广集合{A1, ... , An}的笛卡儿积的概念到任意序数α，即 A1×... ×Aα={<ai>i<α|ai∈Ai, i<α}。

作为数学归纳法的拓广，引入超穷归纳法。设 R 是性质，R(α)表示序数α有性质 R。

超穷归纳法原理：对任意满足β<α的序数α和β，如果 R(β)蕴含 R(α)，则对任意序数 α，有 R(α)。

注意：上述归纳假设“对任意满足β<α的序数α和β，如果 R(β)蕴含 R(α)”成立时包含“序数 0 具有性质 R”，即“R(0)”成立。
