为给出嵌套程序语义，需要扩展归约的概念以定义嵌套程序的回答集。首先递归定义协调文字集和嵌套公式的可满足关系|=n (下标 n 表示|=n 是非单调的可满足关系，以区别于经典的可满足关系) 如下：

对任意一协调文字集 S 和公式 F, 称 S 满足 F (或 S 是 F 的模型), 记作 S|=n F,

+   - 对文字 L, 若 L∈S, 则 S|=n L;
+   - |=n ⊤;
+   - # |= n ⊥ :
+   - 若 S|=n F 且 S|=n G, 则 S|=n (F,G);
+   - 若 S|=n F 或 S|=n G, 则 S|=n (F;G);
+   - 若 S≠|=n F, 则 S|=n not F.

任意一公式 F, 若存在协调文字集 S, 使得 S|=n F, 则称 F 是可满足的 (或 S 满足 F), 并称 S 是 F 的一个模型。记 F 的所有极小模型 (依集合包含关系) 的集合为 SM(F)。

对任意公式 F 和 G, 称 F 是 G 的推论, 记作 F|=n G, 当且仅当对任一协调文字集 S, 若 S|=n F, 则 S|=n G。

显然, 对于经典公式 F 和协调文字集 S, 存在 S|=n F 当且仅当 S ⊨ F, 其中, ⊨ 是经典的逻辑结论关系。

类似于定义 4.1.6, 对任一嵌套规则 r=Head←Body 和任一协调文字集 S, 称 S 满足规则 r (或者 S 是 r 的模型, 或者 S 封闭于 r), 记作 S|=n r, 当且仅当 S 满足 Body 则 S 满足 Head。对任一嵌套程序 Π 和任一协调文字集 S ⊆ GLitΠ, 如果 S 满足 Π 中每一规则, 则称 S 满足 Π (或者 S 是 Π 的模型或者 S 封闭于 Π), 记作 S|=n Π。

# 定义 5.2.1 令 S 是协调文字集, F 是公式, F 关于 S 的归约, 记作 F^S, 递归地定义为

+   - 对初等公式 F, F^S=F;
+   - (F,G)^S=F^S,G^S;
+   - (F;G)^S=F^S;G^S;
+   - 若 S|=n F, 则(not F)^S=⊥; 若 S≠|=n F, 则(not F)^S=⊤。

任意一嵌套规则 r=Head←Body 关于协调文字集 S 的归约, 是 Head^S←Body^S, 记作 r^S。任一嵌套程序 Π 关于 S 的归约, 是集合 {r^S | r ∈ Π}, 记作 Π^S。
