证明 “仅当” 设 S 是 Π 的回答集，依推论 4.3.2, S 是 Comp(Π) 的模型。对 Π 的任一正环 Z, 若 S 满足 ∀_{a∈Z} A, 则存在 A*∈Z, 使得 A*∈S. 因为 S=Head(GR(S, Π)), 故 S 是 GR(S, Π) 支承的。依定理 5.1.2, 存在 Π' ⊆ Π, 使得 Π' = A(Π'), S = Head(Π') 且 Π' 是紧凑的。因此，S 是 Π' 支承的。由 A*∈S, 存在 r∈Π', 使得 Head(r)=A* 且 S 满足 r. 由 Π' 的紧凑性易知, r∈R⁻(Π, Z). 于是，S 满足 LF(Z). 由于 Z 是 Π 的任一正环，故 S 是 LF 的模型。

“当” 令 Π⁰ = {r ∈ Π | Head(r)∈S, Pos(r) ⊆ S, Neg(r) ∩ S = ∅}, 则易知 Π⁰ ⊆ GR(S, Π). 对任意 r ∈ R(S, Π), 有 Pos(r) ⊆ S 且 Neg(r) ∩ S = ∅. 因为 S 是 Comp(Π) 的模型，依定理 4.3.3, S 封闭于 Π, 所以 Head(r) ∈ S, 从而 r ∈ Π⁰. 于是，GR(S, Π) = Π⁰. 因此，Π⁰ = GR(S, Π) 且 Head(Π⁰) = S.

情形 1：若 Π⁰ 没有正环，则 Π⁰ 是紧凑的。依 Π⁰ 的定义，Π 是在 S 上紧凑的。因为 S 是 Comp(Π) 的模型，依定理 4.3.5*，S 是 Π 的回答集。
