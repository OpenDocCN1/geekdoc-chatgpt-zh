# 推论 4.3.5 设原子集 $U$ 分裂正规程序 $\Pi$，对任一原子 $A, A \in C_n(\Pi)$，当且仅当对 $\Pi$ 关于 $U$ 的任一解 $<S_1, S_2>, A \in S_1 \cup S_2$。

扩展分裂的概念到分裂序列，可以得到局部分层性和序协调性的简单特征。

给定分裂序列 $<U_\alpha>_{\alpha < \mu}$，其中每一 $U_\alpha$ 是集合。若对任意序数 $\alpha, eta < \mu$，当 $\alpha < eta$ 时， $U_\alpha \subset U_eta$ 成立，则称该系列是单调的。若对任一极限序数 $\alpha < \mu, U_\alpha = \cup_{\eta < \alpha} U_\eta$，则称该系列是连续的。正规程序 $\Pi$ 的分裂序列是由 $\Pi$ 的分裂集合组成的单调连续序列 $<U_\alpha>_{\alpha < \mu}$，使得 $\cup_{\alpha < \mu} U_\alpha = \mathbf{GAtom}_\Pi$。
