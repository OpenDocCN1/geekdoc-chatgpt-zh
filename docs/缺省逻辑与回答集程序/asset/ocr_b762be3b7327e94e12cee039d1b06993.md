定义 5.2.2 令 Pi 是嵌套回答集程序，S 是协调文字集。如果 S 是满足 Pi^S 的极小协调文字集，则 S 是 Pi 的回答集。存在回答集的程序是协调的，特别地，存在回答集的一条规则（视为单子）是协调的。

例 5.2.1 给定程序 Pi_1={A; not A <- T} 和协调文字集 S。若 A \in S, 则 Pi_1^S = {A <- T} 有极小模型 {A}；若 A \notin S, 则 Pi_1^S = {T <- T} 有极小模型 \emptyset (因为 A; \bot <- A, A; T <- T)。故程序 Pi_1 有两个回答集 {A} 和 \emptyset。

程序 Pi_2={A <- not not A}，若 A \in S, 则 Pi_2^S = {A <- T}。若 A \notin S, 则 Pi_2^S = {A <- \bot}。程序 Pi_2 有两个回答集 \emptyset 和 {A}。比较程序 {A <- A} 和 {A <- not A}，前者有唯一回答集 \emptyset，而后者没有回答集。

例 5.2.1 表明对于嵌套程序，回答集不满足极小性，即一个回答集可能是另一个回答集的真子集。

例 5.2.2 对于程序 Pi_3={-A <- not not A}，若 A \in S, 则 Pi_3^S = {-A <- T}。\emptyset 是 Pi_3^S 的最小模型，故任何包含 A 的协调文字集 S 不是 Pi_3 的回答集。若 A \notin S, 则 Pi_3^S = {-A <- \bot}，\emptyset 是 Pi_3^S 的最小模型，从而也是 Pi_3 的回答集。于是，程序 Pi_3 有唯一回答集 \emptyset。

对于程序 Pi_4={A <- not not B} 和任意协调文字集 S，若 B \in S, 则 Pi_4^S = {A <- T} 有极小模型 {A} \notin S。若 B \notin S, 则 Pi_4^S = {A <- \bot} 有极小模型 \emptyset。因此，Pi_4 有唯一回答集 \emptyset。

定义 5.2.3 令 Pi_1 和 Pi_2 是任意嵌套套程序，X 和 Y 是任意协调文字集。如果 X 封闭于 Pi_1^Y 且且仅当 X 封闭于 Pi_2^Y，则 Pi_1 和 Pi_2 等价。

显然，两个等价的公式关于同一个文字集的归约有相同的回答集。因此，任意两个等价的程序有相同的回答集。因此，若 Pi_1 和 Pi_2 等价，则对任意程序 Pi, Pi_1 \cup Pi 与 Pi_2 \cup Pi 等价。
