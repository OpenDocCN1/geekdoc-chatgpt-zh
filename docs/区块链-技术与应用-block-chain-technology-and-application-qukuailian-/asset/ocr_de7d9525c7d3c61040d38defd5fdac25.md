# 第11章
基于区块链的能源应用

# 本章学习目标

+   - 根据基于区块链技术的能源应用具体案例，了解区块链目前在能源领域的应用情况
+   - 了解区块链在能源领域的应用的特点

能源行业的进化从未停止，随着新能源模式的发展，区块链技术分布式、公开性和透明性的特点与能源互联理念不谋而合，起源于数字货币领域的区块链技术有潜力成为构建未来互联网新生态能源的重要技术之一。为实现能源流、资金流和信息流的有效对接，区块链创业公司积极和能源产业公司合作，期望在区块链的这一新兴技术上探索能源互联网的有效落地应用。
