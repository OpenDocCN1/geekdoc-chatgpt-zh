# 3.3 区块链的共识算法

共识算法用于一个时间段内，对事物的前后顺序达成共识，以保证分布式系统的一致性。共识机制是指区块链事务达成分布式共识的算法。共识算法是区块链里每个节点必须遵守的规则，规则的最终体现就是比特币的最长链。共识算法保证区块链在最长链上运转（最长链法则），从而保证整个系统的一致性和可靠性。共识算法是区块链的灵魂，维系着区块链世界的正常运转。如果分布式系统中各个节点都能保证以十分强大的性能无故障地持续运行，则可以通过简单投票实现共识过程。然而，现实中，响应请求往往存在时延、网络会发生中断、节点会发生故障，甚至存在恶意节点故意破坏系统。

1982 年莱斯利·兰伯特提出拜占庭将军问题，分布式对等网络中需要按照共同一致策略协作的各节点即为问题中的将军，而各节点赖以进行通信的网络链路即为信使。拜占庭将军问题描述了节点或网络链路出现错误，甚至被蓄意破坏者控制的情况。一般地，普通故障称为“非拜占庭错误”，恶意响应称为“拜占庭错误”。对于非拜占庭错误，主要共识算法包括 Paxos、RAFT 及其变种。对于拜占庭错误，主要共识算法包括 PoW（proof of work，工作量证明）、PoS（proof of stake，权益证明）、PBFT（practical Byzantine fault tolerance，实用拜占庭容错）等。表 3-1 介绍了 PoW、PoS、PBFT 等共识算法的核心概念、主要优劣势等。

# 表 3-1 PoW、PoS、PBFT 等共识算法的比较
