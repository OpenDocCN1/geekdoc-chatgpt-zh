# 12.1 区块链电子政务应用背景

电子政务是电子化后的政府信息服务和信息处理系统，通过“互联网+政务”的模式对政府的办公模式进行改造，以提高政府部门的工作效率和依法行政的水平。随着电子政务的不断落实与完善，政府政务数据的不断增加，政府各个机构的数据互通对于提升政务管理的能力和政府的工作效率正变得越来越重要。但是，在数据共享过程中，存在着大量安全性问题。例如，政务服务平台涉及大量人员、企业的敏感信息，直接公开会导致不好的后果，并且数据交互共享过程复杂，不仅易出现人为失误，还容易遭受黑客攻击而导致信息泄露或存在内部人员泄密等情况。由于以上因素，数据共享在实际推进的过程中往往受到很多阻碍。区块链技术则为跨地区、跨机构的数据整合提供了安全且可
