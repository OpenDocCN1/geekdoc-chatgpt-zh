# 第3章
区块链的分布式存储特性

# 本章学习目标

+   - 了解拜占庭将军问题的主要内容
+   - 了解区块链的网络架构
+   - 理解区块链的多种共识算法以及不同共识算法的应用

区块链的共识机制为其分布式存储特性提供了技术基础。作为区块链的特性，分布式存储并不是绝对的，例如在比特币体系中，虽然系统是分布式的，但某些帮助用户管理比特币的平台或者软件既可以是分布式的，也可以是集中的。

# 3.1 拜占庭将军问题

拜占庭将军问题是莱斯利·兰伯特提出的点对点通信中的基本协议问题。拜占庭作为东罗马帝国的首都，幅员辽阔，拥有巨大的财富，每个军队都相隔很远，将军与将军之间只能依靠信差传递消息。在战争发生的时候，军队中可能存在叛徒，假设在所有部队中需要有超过半数的将军共同攻打敌军才能取得胜利，但若同意攻打的部队中存在叛徒，则可能会导致该部队只口头同意攻打
