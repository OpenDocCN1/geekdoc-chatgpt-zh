# ## 2.2.3 原型设计

构建完产品功能结构图之后，接下来需要按照功能结构图进行产品原型设计。

产品原型设计阶段的本质是针对使用场景，结合产品功能，输出产品原型图和对应的场景解决方案。其中，产品原型图一般是一些简单的图形，能够表达产品最基本的使用方法，并能模拟产品的使用场景。根据产品原型图对于产品细节和功能的还原程度的不同，可以将产品原型图分为低保真原型图和高保真原型图。
