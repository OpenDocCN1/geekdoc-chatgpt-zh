# 3.1.1 智能数据服务平台

EasyData 平台是百度大脑推出的智能数据服务平台，面向各行各业有人工智能开发需求的企业用户及开发者提供一站式数据服务工具。该平台主要围绕人工智能开发过程中所需要的数据采集、数据清洗、数据标注等业务需求提供完整的数据服务。目前 EasyData 平台已经支持图像、文本、音频、视频 4 类基础数据的标注，也初步支持机器学习数据的存储。同时，EasyData 平台已与 EasyDL 平台打通，可以将 EasyData 平台处理的数据应用于 EasyDL 平台的模型训练。图 3-1 所示为 EasyData 智能数据服务平台界面。
