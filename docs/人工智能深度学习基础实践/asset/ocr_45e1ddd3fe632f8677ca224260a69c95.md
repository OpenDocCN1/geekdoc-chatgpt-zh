+   - parameters：可选，指定优化器需要优化的参数。在动态图模式下必须提供该参数；在静态图模式下其默认值为 None，这时所有的参数都将被优化。
+   - use_nesterov：可选，其数据类型为布尔值，当值为 True 时，则为加入牛顿动量。默认值为 False。
+   - weight_decay：可选，权重衰减系数，数据类型为 float32 的 Tensor 类型，默认值为 0.01。
+   - grad_clip：可选，梯度裁剪的策略，默认值为 None。
+   - name：可选，供开发中输出调试信息时使用，默认值为 None。
