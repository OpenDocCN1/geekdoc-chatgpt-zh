# ## 5.2.3 数据特征挖掘

对数据的特征有一定了解后，需要从大量的特征中选择少量的可用特征。特征并不都是“平等”的，与问题不相关的特征需要被删除。还有些特征与其他重要特征相比是冗余的。而特征选择就是自动选择对于问题最重要的特征的一个子集，其目的在于简化模型、缩短模型训练时间、提高模型通用性等。本项目所使用的数据集数据量不大，可以通过相关性分析来进行数据特征挖掘。

相关性分析一般使用皮尔逊相关系数进行计算。皮尔逊相关系数用于度量两个变量之间的线性相关程度。其取值范围为 `[-1.0, 1.0]`。如表 5-2 所示，通常情况下，可以通过皮尔逊相关系数的取值范围判断变量的相关性。
