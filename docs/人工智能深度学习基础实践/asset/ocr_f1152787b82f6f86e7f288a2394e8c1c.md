# ## 8.2 常用的深度学习框架

深度学习框架的出现，使各类算法高效研发、迭代和大规模应用部署成为可能，奠定了深度学习繁荣发展的基础。目前常用的深度学习框架包括 PaddlePaddle、TensorFlow、Keras、Caffe 和 PyTorch 等，这些框架各有优势。这些深度学习框架被应用于计算机视觉、语音识别、自然语言处理与生物信息学等领域，并取得了较好的效果。以下介绍这 5 种常用的深度学习框架。
