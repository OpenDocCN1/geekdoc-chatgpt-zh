步骤 3.21: 提出仓储作业中叉车运行线路的综合评价函数。记叉车 $k (k=1, 2)$ 在第 $i$ 对仓储作业链中的总作业时间为 $t_{ki} (k=1, 2)$，记 $t_i = t_{1i} + t_{2i}$ 为第 $i$ 对仓储作业链中两辆叉车的总作业时间，记 $\eta_i = \frac{(t_{1i} + t_{2i})}{2}$ 为第 $i$ 对仓储作业链所对应的效率函数，则第 $i$ 对仓储作业链叉车运行线路的综合评价函数为

$P_i = \frac{1}{2} \left\{ \begin{aligned} &\frac{(\frac{t_i - t_{\min}}{t_{\max} - t_{\min}} + 1)^{-\alpha_i} \times (\frac{d_i - d_{\min}}{d_{\max} - d_{\min}} + 1)^{\alpha_2}}{2} - \min_{i \in \{1, 2, \cdots, N\}} \left\{ \frac{(\frac{t_i - t_{\min}}{t_{\max} - t_{\min}} + 1)^{-\alpha_1} \times (\frac{d_i - d_{\min}}{d_{\max} - d_{\min}} + 1)^{\alpha_2}}{2} \right\} \\ &+ 1 - \max_{i \in \{1, 2, \cdots, N\}} \left\{ \frac{(\frac{t_i - t_{\min}}{t_{\max} - t_{\min}} + 1)^{-\alpha_1} \times (\frac{d_i - d_{\min}}{d_{\max} - d_{\min}} + 1)^{\alpha_2}}{2} \right\} \\ &- \min_{i \in \{1, 2, \cdots, N\}} \left\{ \frac{(\frac{t_i - t_{\min}}{t_{\max} - t_{\min}} + 1)^{-\alpha_1} \times (\frac{d_i - d_{\min}}{d_{\max} - d_{\min}} + 1)^{\alpha_2}}{2} \right\} \end{aligned} \right\} \times \left( \frac{\eta_i - \eta_{\min}}{\eta_{\max} - \eta_{\min}} + 1 \right)^{-w_2} \quad \text{(3.18)}
