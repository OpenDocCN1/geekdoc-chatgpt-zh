图 5.14 表示入库货位与出库货位的和为 44，且随机选择入库货位与出库货位位置时。同时，当第 1、2 单元内至少有一个入库货位和一个出库货位，或者第 3、4 单元内至少有一个入库货位和一个出库货位的概率在入库货位为 x 时的变化情况。由图 5.14 可知，当入库货位在 7 个到 35 个之间变化，且随机在仓库内进行排布时，小车有 95%以上的可能性会经过仓库上半部分行驶。当入库货位的数量为 12 个到 30 个时，有 90%以上可能叉车不需要经过上仓库半部分分绕行，且入库货位的数量服从 $\mu = 22, \sigma = 7.1$ 的正态分布，因此入库货位的数量落在 $(12, 30)$ 区间内的概率为 0.790 579，入库货位的数量落在 $(7, 12)$ 和 $(30, 35)$ 区间内的概率为 0.158 555，进而可得

```
\sum_{N=1}^2 S_{p_i, q_j}^{C_{n_i}} = P(12 < N_{I_p} < 30) \times \left[ 0.9 \times 142.8 + 0.1 \times \left( \frac{183.5 - 142.8}{2} + 142.8 \right) \right]\\
+ \left[ P(7 < N_{I_p} < 12) + P(30 < N_{I_p} < 35) \right] \times 0.95 \times 183.5\\
+ \left[ 1 - P(15 < N_{I_p} < 45) \right] \times l_{else}\\
= 0.790 579 \times (0.9 \times 142.8 + 0.1 \times 163.15) + 0.158 555 \times (0.95 \times 183.5) + \varepsilon_{case6}\\
= 142.14 米
```

在得出每种方案下叉车的平均最短行驶路程后，可以按照 5.2.3 节中构建的仿真模型进行编程求解。

计算结果表明，虽然在入库货位数量过多或过少这两种比较极端的情况下叉车行驶最短路径长度会远超过平均值，由于货位数量变化服从均值为总货位数 1/2 的正态分布，故可以看出，两种方法的计算结果十分接近。当求得平均路径后，将出入库时间 $t_{n_i}$、运行成本 $C_{n_i}(t)$ 及机会成本 $O_{n_i}(\chi)$ 等参数代入 6 种方案对应的模型。为了计算方便，本书为参数赋值为 $\Omega=20$， $w_{t_n} = 3.5L / h$， $v_{n_i} = 0.8m / s$， $p_{oil} = \$1.03 / L$， $w_1 = 0.5$， $w_2 = 0.2$， $w_3 = 0.3$。综合整理上述计算结构，可得到不同布设方案下单位集卡装卸作业成本，详情见表 5.5。
