$e^{-\lambda \left\| \nabla_{v}^{m} v_{mI+j} \right\|} \mu_m$ 表示网络权值 $v$ 的自适应动量因子，$\lambda$ 为正常数，用以控制动量因子的大小。自适应动量因子介于 0 和 1 之间，且随着误差关于权值向量的梯度范数的变化而变化。另外，这里采用重赋零策略处理训练过程中的动量项因子，即在每一个迭代循环开始时令动量项因子为零。\(\nabla_k^m u_{mI+j}\) 和 \(\nabla_j^m v_{i,mI+j}\) 表示在第 $m$ 个训练循环中误差函数关于 $u$ 和 $v$ 的梯度，

```
\(\nabla_k^m u_{mI+j} = \left(O_k - y_{mI+j,m,k}\right) f' \left( u_{mI+j} \times G_{mI+j,m,k} \right) G_{mI+j,m,k}\)
\(= -f_k' \left( u_{mI+j} \times G_{mI+j,m,k} \right) G_{mI+j,m,k}\)
(3.12)
```

```
\(\nabla_k^m v_{i,mI+j} = \left(O_k - y_{mI+j,m,k}\right) f' \left( u_{mI+j} \times G_{mI+j,m,k} \right) u_{i,mI+j} g' \left( V_{i,mI+j} X_{m,k} \right) X_{m,k}\)
\(= -f_k' \left( u_{mI+j} \times G_{mI+j,m,k} \right) u_{i,mI+j} g' \left( V_{i,mI+j} X_{m,k} \right) X_{m,k}\)
(3.13)
```

其中， \( G_{mI+j,m,k} = G \left( v_{mI+j} X_{m,k} \right), y_{mI+j,m,k} = f \left( u_{mI+j} G_{mI+j,m,k} \right), m \in N ; i=1,2,\cdots,n ; j,k=0,1,2,\cdots,J-1 \)。

# 2. 主要结论

给定任一向量 \( X = (x_1, x_2, \cdots, x_n)^{\text{T}} \in R^n \) ，定义其欧氏范数为 \(\|X\| = \sqrt{\sum_{i=1}^n x_i^2}\) 。定义误差函数的稳定点集为 \(\Omega_0 = \{ W \in \Omega : E_W(W) = 0 \}\) ，其中， \(\Omega \subset R^{n(p+1)}\) 是满足下述条件（假设 4）的有界区域。令 \(\Omega_{0,s} \subset R\) 是 \(\Omega_0\) 在第 $s$ 个坐标轴上的投影，即

```
\(\Omega_{0,s} = \left\{ W_s \in R : W = \left( W_1, W_2, \cdots, W_s, \cdots, W_{n(p+1)} \right)^{\text{T}} \in \Omega_0 \right\}\)
(3.14)
```

假设 3.2：学习率满足条件 \(\eta_m > 0, \sum_{m=0}^\infty \eta_m = \infty, \sum_{m=0}^\infty \eta_m^2 < \infty\)；

假设 3.3：动量项系数满足 \(\mu_m > 0, \sum_{m=0}^\infty \left( e^{-\lambda \left\| \nabla_{v}^{m} v_{mI+j} \right\|} \mu_m \right)^2 < \infty , \sum_{m=0}^\infty \left( e^{-\lambda \left\| \nabla_{v}^{m} v_{mI+j} \right\|} \mu_m \right)^2 < \infty\)；
