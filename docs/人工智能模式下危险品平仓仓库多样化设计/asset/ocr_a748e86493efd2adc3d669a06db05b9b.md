# # 内容简介

本书借鉴国内外先进的危险品仓库建设和管理经验，以最优化理论和多属性决策理论为主要工具，有效结合建筑、计算机编程、统计分析等技术，提出一套危险品平台仓库结构改造与作业优化方案。本书实现了最优化理论与多属性决策理论的结合，并将其应用到危险品仓储作业优化领域。另外，本书给出了危险品平台仓库的智能化建设方案，为不同市场环境下的危险品平台仓库指出了个性化发展方向。

本书可作为交通运输规划与管理、交通工程、物流工程等专业的研究生教材，也可供高校、研究院所从事相关专业的师生和研究工作者使用。
