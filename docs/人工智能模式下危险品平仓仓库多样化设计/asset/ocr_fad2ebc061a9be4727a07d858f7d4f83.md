\(\sum_{N=1}^{2} S_{P, q_j}^{C_n} = P(16 < N_{I_p} < 28) \times (0.95 \times 134.8 + 0.05 \times I_{else}) + [P(10 < N_{I_p} < 16) + P(28 < N_{I_p} < 34)] \times (0.8 \times 134.8 + 0.2 \times I_{else}) + [1 - P(10 < N_{I_p} < 34)] \times I_{else} = 0.566186 \times (0.95 \times 134.8) + 0.316333 \times (0.8 \times 134.8) + \varepsilon_{case5} = 141.62 \text{米}\)

在方案六中，将第 1、2 单元内至少有一个人入库货位一个出库货位，第 3、4 单元内至少有一个人入库货位一个出库货位时的概率记为 \(P_{case6}\)，当该假设成立的区域减少到仓库中线以下部分时记概率为 \(P'_{case6}\)，因此可得

\(P_{case6} = [1 - (r_p)^{18} - (r_q)^{18}] \times [1 - (r_p)^{16} - (r_q)^{16}]\)

\(P'_{case6} = [1 - (r_p)^9 - (r_q)^9] \times [1 - (r_p)^8 - (r_q)^8]\)
