# # I 人工智能在传媒业的应用价值

# ## 数据智能微粒化重构消费者关系

消费者在传媒行业的内容消费以及媒介接触都会产生映射消费者行为习惯和心理喜好的数据，这些庞大数据的组合将可以解析消费者对于内容和传媒的心理需求，因此传媒行业需要有能够到达消费者行为数据的触角，这些触角包括智能移动终端APP、智能机顶盒、以及互联网智能电视机等一系列数字终端。

传媒要在未来竞争中胜出，以智能数字化的方式，建立对消费者的立体认知，并在此基础上进行全域触达和基于内容的精细化运营是必然选择。智能数字化手段可以高效帮助企业设法建立和培养可识别、可运营的用户资源池，建立深度连接，形成忠实粉丝群，实现消费者关系的彻底重构。

| 维度 | 传媒传统运营状态 | 基于数据的消费者解构 |
| :--- | :--- | :--- |
| 消费者画像 | 粗放，颗粒度大 · 固定在其几个维度（性别、年龄、地域） | 颗粒度细小，有更多维度 · 消费者心智画像 |
| 消费者认知 | 广电网络：制播分离，广播模式，缺乏消费者认知 · 电视台：不了解消费者逻辑，消费行为需粗抽样调研 | 微粒化架构，微粒社群 · 全方位，多维度立体认知 · 消费逻辑，消费者关系流转、时间动线设计 |
| 消费者触达 | 电视、开机画面顿、节目广告及海报投放触达效果无法评估 | APP、社群、媒体全域触达 · 正确的时间+投其所好的内容 +合理的营销方式=高收视率 |
| 精细化运营 | 电视用户通过后台与家庭地址/银行卡带来，缺乏数据沉淀 | 精准识别所幕后的用户 · 精准推送并收集用户反馈和体验 · 微粒社群时空跳线+适时促销+社群共享=高忠诚度 |
