价格低至 0.05～0.10 美元(约人民币 0.40 元),就目前的技术条件而言,这就要求标签的逻辑门数限制在 5～10K,用于安全的逻辑门数小于 5K[215,216]。因此,不可能在廉价的电子标签内实现复杂的加密算法(AES 需要 20K 左右的逻辑门电路,DES 和 RSA 则需更多),也就使得在标签、阅读器与后端应用系统之间难以实施有效的相互认证机制。

(2) 无线信道的开放性。电子标签和阅读器之间利用无线射频技术相互通信,其通信建立在开放的无线信道上,任何人都可以利用无线信道进行通信,任何人都可以从开放的空间信道截取信息。因此,RFID 拓宽了网络攻击的范围。

(3) 应用的分布性。根据 EPC 物联网参考模型,整个 RFID 网络是一个巨大的分布式网络,中间件服务器、ONS 和 EPCIS 分布在不同地点,由不同的组织维护和控制。同时,由某个组织控制的中间件服务器、ONS、EPCIS、应用系统等资源又具备一定的自治性,可以不依赖于整个 RFID 网络而运转。标签是便携设备,在物流领域,依附在商品上的 RFID 标签需要在制造商、零售商和消费者之间流转。因此,应用的复杂性也加大了 RFID 安全管理的难度,如密钥、证书等难以维护。

# 11. 2.2 RFID 系统面临的安全问题

RFID 系统的上述特性,决定了 RFID 系统面临着比 TCP/IP 网络更加复杂的安全风险,RFID 网络更加容易遭受攻击。按照攻击方式分类,RFID 可归纳为主动攻击和被动攻击两种类型。

主动攻击主要包括[210]：

+   (1) 对获得的 RFID 标签实体,通过物理手段在实验室环境中去除芯片封装,使用微探针获取敏感信号,进而进行 RFID 标签重构；

+   (2) 通过软件,利用微处理器的通用通信接口,通过扫描 RFID 标签和响应阅读器的探询,寻求安全协议、加密算法及它们的弱点,进而删除 RFID 标签内容或篡改可重写 RFID 标签的内容；

+   (3) 通过干扰广播、阻塞信道或其他手段,产生异常的应用环境,使合法处理器产生故障,拒绝服务(deny of service,DoS)攻击等。

+   (1) 采用窃听技术,分析微处理器正常工作过程中产生的各种电磁特征,来获得 RFID 标签和阅读器之间或其他 RFID 通信设备之间的通信数据；

+   (2) 通过阅读器等设备,窃取 RFID 信息、个人隐私、商品流通动态等。
