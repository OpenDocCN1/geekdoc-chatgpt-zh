# 11.7.3 基于 OE-AiNet 的 RFID 协同检测实验仿真

# 1. 特征日志模拟

按照各种操作类型的特征模拟生成特征日志样本，模拟方法如下。

+   1) 正常操作

模仿实际应用中的正常标签读/写操作，一般而言，正常的标签读操作和写操作会在不同的区域进行，因此模拟时在某一时段主要进行读操作，而在另一时段主要作写操作。操作过程中，操作频次适中，网络畅通，无外界干扰，输入口令正确。

+   2) 阅读器窃取

采用两个阅读器日志融合的方法来模拟阅读器窃取，假定一个是授权阅读器，另一个是非法阅读器，它们同时访问同一批标签，非法阅读器产生的日志无法匹配，因而模拟出阅读器窃取操作。

+   3) 口令猜测

口令猜测操作则用故意输错标签访问口令的方式模拟，期间也可以混合正常操作类型，但保证口令输错的比例占大多数。

+   4) 拒绝服务

拒绝服务攻击主要是模拟一个被干扰的环境，电磁干扰的环境利用正在通话的手机模拟，物理屏蔽则采用金属板隔离阅读器和标签来模拟。异常环境下按照正常操作利用阅读器访问标签，即模拟了拒绝服务攻击。

+   5) 未知攻击

未知攻击采用随机数据模拟，在 RFID 特征体系空间中，随机产生部分稀疏分布的数据，这些数据可能不包含于上述任何已知类型，从而模拟了未知攻击。

按照上述方法提取特征日志 730 条，其中包含正常日志 400 条，阅读器窃取日志 100 条，口令猜测日志 100 条，拒绝服务攻击（DoS）日志 100 条，随机产生的稀疏分布的未知异常日志 30 条。
