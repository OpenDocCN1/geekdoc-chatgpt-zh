# 11.6.1 RFID 抗原编码

RFID 入侵检测中，抗原即信息收集器提呈抗原决定基(即 AppLog 记录)，阴性选择模型中，通常将抗原编码为一个二进制字符串，根据式(11-4)所示的抗原决定基定义，抗原的二进制编码如表 11-1 所示。

| 位号 | 1~4 | 5~8 | 9~16 | 17~24 | 25~48 | 49~56 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| AppLog 抗原元素 | 区域(Rg) | 时域(T) | 阅读器指令(Rc) | 指令参数(Pac) | EPC | 标签返回码(RT) |

表 11-1 中，位号表示对应的抗原元素在二进制编码中占用的位置段，其中，区域(Rg)和时域(T) 各用 4 位编码，不同的编码表示不同的区域或时域。在 EPC C1G2 标准中，阅读器指令采用 8 位编码，在此也采用 8 位编码，用标准指令编码填充，不够 8 位用 0 填充，不需要译码处理。EPC C1G2 标准中，指令参数一般不超过 20 位，对于入侵检测而言，并不是所有指令参数都需要关注，可以根据具体指令选择部分安全规则需要的参数，在此用 8 位编码表示。目前，EPC 编码方案包括 EPC-64、EPC-96、EPC-256 三种，选择最具推广价值的 EPC-96 进行编码，但是 96 位 EPC 编码对于抗原过长，根据需要选取部分编码即可，此处选取 24 位的对象分类码段。EPC C1G2 标准的标签返回码为 8 位，全部编入抗原。各个抗原元素编码的连接组成了 56 位的抗原编码，该编码成为抗原的原始编码。具体的阅读器指令与指令参数的抗原元素编码，如表 11-2 所示。

# 表 11-2 阅读器指令与指令参数的抗原编码

| 指令 | 指令编码 | 指令参数 |
| :--- | :--- | :--- |
| Select | 1010 | 目标(1)、动作(2)、存储体(2) |
| Query | 1000 | — |
| QueryAdjust | 1001 | 通话(2)、UpDn(3) |
| QueryRep | 00 | 通话(2) |
| Ack | 01 | — |
| Nak | 11000000 | — |
| Req_RN | 11000001 | — |
| Read | 11000010 | 存储体(2) |
| Write | 11000011 | 存储体(2) |
| Kill | 11000100 | — |
| Lock | 11000101 | 有效负载(8) |
| Access | 11000110 | — |
| BlockWrite | 11000111 | 存储体(2) |
| BlockErase | 11001000 | 存储体(2) |
