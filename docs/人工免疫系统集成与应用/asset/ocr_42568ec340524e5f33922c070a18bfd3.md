表 11-2 中，指令参数栏指的是选取的参数，括号中记的是参数编码位数。例如，在某区域(0001)、某时域(1000)，发生了对某类产品(1001'0000'1100'1100'1010'0001)的用户存储体(11)的写操作(11000011)，标签返回存储器锁定错误(00000100)，则该业务日志的 56 位抗原原始编码为

```
0001 1000 11000011 11 1001'0000'1100'1100'1010'0001 00000100
```

抗原的原始编码有着明确的语义，易于理解，但是观察抗原编码容易发现，抗原分布过于紧凑，不同抗原之间的差异很小。例如，只有区域不同的两个抗原 ag1 和 ag2，其连续相同的位数可能达到 55 位，单从抗原编码来看，ag1 和 ag2 的相似度非常高，但从安全意义上来说可能有着很大的差异，有些指令在 A 区域中允许执行，而在 B 区域中是被禁止的，因此 ag1 可能为自体抗原，ag2 可能为非自体抗原，从而增大了检测的难度，抗原的原始编码也就不适合直接用于入侵检测。

本章采用 Hash 算法将原始编码转换为 Hash 编码，在检测时采用 Hash 编码，Hash 能将任意长度的输入(又叫做预映射(preimage))变换成固定长度的输出，即散列值。数学上的表述如式(11-32)所示。

```
h = H(M) \hspace{1cm} (11-32)
```

式中，h 为固定长度散列值；H 为单向函数；M 为任意长度的输入字符串。Hash 具有抗冲突性，即在计算上很难找到一对输入 M 和 M'，使 H(M) = H(M')，虽然 Hash 函数不可逆，但在信息编码意义上来说，h 是可以代表 M 的。如果 M 取抗原原始编码，则 h 即为抗原的 Hash 编码。

Hash 具有映射分布均匀性和差分分布均匀性，散列结果中，为 0 的 bit 和为 1 的 bit，其总数应该大致相等；输入中一个 bit 发生变化，散列结果中将有一半以上的 bit 改变，这一现象称为“雪崩效应(avanche effect)”；要使散列结果中出现 1bit 的变化，则输入中至少有一半以上的 bit 必须发生变化。其实质是必须使输入中每一个比特的信息，尽量均匀地反映到输出的每一个 bit 上去；输出中的每一个比特，都是输入中尽可能多比特的信息一起作用的结果。因此，Hash 编码将原始编码均匀地映射到了形态空间，即使两个抗原 ag1 和 ag2 的原始编码很相似，两者的 Hash 编码也会有较大的差异，从而更容易区分出“自体”和“非自体”。

具体到 Hash 算法的选择上，本章选用信息安全领域广泛应用的 MD5 算法[225]来产生抗原的 Hash 编码，MD5 算法将 512 位数字输出为一个 128 位的散列值。具体到抗原 Hash 编码的问题上，输入为 56 位的抗原原始编码，128 位散列值作为抗原 Hash 编码相对来说过长。因为输入空间较小，选取其中 64 位作为 Hash 编码即可保证冲突的概率极小，因此本章选取 MD5 输出的 128 位的中间 64 位作为抗原 Hash 编码。下面如无特别说明，RFID 抗原编码即指其 Hash 编码。
