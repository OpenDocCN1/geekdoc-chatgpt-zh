
其聚簇划分,获得聚簇集 C。免疫网络 M 中的各抗体构成了 H 检测器的数据基础 FeaturePoint,每一个抗体对应一个 H 检测器,而 OE-AiNet 采用的压缩阈值 \(\sigma_s\) 则作为 H 检测器匹配阈值 Lc 的参数,H 检测器的匹配阈值统一取值如式(11-34)所示。

```
Lc = \lambda_m \times \sigma_s \qquad (11-34)
```

式中, \(\lambda_m\) 为匹配系数,控制抗体识别的特异性水平。

### 3. 聚簇类型标注

一般而言,同一操作类型的统计特征会在一个相近的空间内变化,因此可以假设一个聚簇主要包含一种类型的操作,对 H 检测器关联类型 Type 的标注也就可以转换为对聚簇关联类型 Type 的标注。假设每个样本 \(Ag \in X\) 都已经关联了检测日志(DetectLog),即 Ag 的实际关联的类型 Type 是已知的。如果缺乏检测日志,则一般认为特征日志关联的操作类型均为正常操作类型,而入侵类型的样本则基于入侵的先验知识模拟产生。利用样本对 M 进行反向识别测试(识别定义见定义 6-2)即可确定抗体聚簇关联的操作类型,识别结果记为 TR,如式(11-35)表示的四元组。

```
TR = \langle Ag, Type, Ab, Cx \rangle \qquad (11-35)
```

式中, Ag 为测试抗原; Type 为 Ag 关联的操作类型;Ab 为识别 Ag 的抗体;Cx 为 Ab 所属的抗体聚簇, \(Ab \in Cx, Cx \subset M\)。

按照 Cx 和 Type,对 TR 作聚集运算,结果 SR 的关系代数如式(11-36)所示。

```
SR = \langle Cx, Type, AgNum \rangle = C_{x, Type} G_{Max(Sum(Ag))} (TR) \qquad (11-36)
```

式中, AgNum 为识别的 Ag 数;SR 的子关系 \(\langle Cx, Type \rangle\) 为聚簇与操作类型的关联关系, \(\langle Ab, Type \rangle\) 关系也就随之确定,完成了抗体与操作类型标注。

经过以上三个步骤后,就产生了 H 检测器库。

## 11.7.2 RFID 协同检测器的动态更新

随着业务的变更,各种抗原类型的特征日志分布也将缓慢变化,所以 H 检测器的动态更新是必要的,否则系统的检测性能会逐步恶化。与 L 检测器类似,H 检测器持续不断地更新会消耗掉大量的资源,影响检测效率,因此也采用周期性更新的方式来维护 H 检测器的有效性,自最近一次 H 检测器生成以来,如果新增的 FeatureLog 数量超过阈值,则重新从历史记录中选取 FeatureLog 样本集,并生成新一轮 H 检测器集。选择 FeatureLog 样本时,为了保证新鲜性,新增的 FeatureLog 记录全部包括。为了保证完整性,各抗原类型的 FeatureLog 样本均需要达到一定规模。用新的 FeatureLog 样本提取的 H 检测器库,其分布将更符合新的 FeatureLog 分布影像。

## 11.7.3 基于 OE-AiNet 的 RFID 协同检测实验仿真

### 1. 特征日志模拟

按照各种操作类型的特征模拟生成特征日志样本，模拟方法如下。

- 1) 正常操作

模仿实际应用中的正常标签读/写操作，一般而言，正常的标签读操作和写操作会在不同的区域进行，因此模拟时在某一时段主要进行读操作，而在另一时段主要作写操作。操作过程中，操作频次适中，网络畅通，无外界干扰，输入口令正确。

- 2) 阅读器窃取

采用两个阅读器日志融合的方法来模拟阅读器窃取，假定一个是授权阅读器，另一个是非法阅读器，它们同时访问同一批标签，非法阅读器产生的日志无法匹配，因而模拟出阅读器窃取操作。

- 3) 口令猜测

口令猜测操作则用故意输错标签访问口令的方式模拟，期间也可以混合正常操作类型，但保证口令输错的比例占大多数。

- 4) 拒绝服务

拒绝服务攻击主要是模拟一个被干扰的环境，电磁干扰的环境利用正在通话的手机模拟，物理屏蔽则采用金属板隔离阅读器和标签来模拟。异常环境下按照正常操作利用阅读器访问标签，即模拟了拒绝服务攻击。

- 5) 未知攻击

未知攻击采用随机数据模拟，在 RFID 特征体系空间中，随机产生部分稀疏分布的数据，这些数据可能不包含于上述任何已知类型，从而模拟了未知攻击。

按照上述方法提取特征日志 730 条，其中包含正常日志 400 条，阅读器窃取日志 100 条，口令猜测日志 100 条，拒绝服务攻击（DoS）日志 100 条，随机产生的稀疏分布的未知异常日志 30 条。

## 11.8 本章 小结

本章参考生物免疫的协同检测方法和多 Agent 技术建立了一个 RFID 入侵检测模型，通过 RFID 的应用特征分析，定义了 RFID 的抗原决定基，通过分析已知 RFID 攻击的统计特征，定义了 RFID 的危险信号，并提出了基于无线信道侦听与 RFID 中间件日志相结合的抗原提呈方案。基于 RFID 抗原决定基和危险信号，提出了一个免疫协同的 RFID 入侵识别框架，定义了 RFID 适应性检测器和 RFID 协同检测器，理论上，免疫协同入侵识别能有效地降低因偶尔误操作而引发的误检率，提高了 RFID 入侵检测方法的可用性。

本章提出了基于阴性选择的 RFID 适应性检测方法，针对抗原的原始编码中自体和非自体相似度过高，不利于阴性选择算法检测的问题，本章将抗原原始编码通过 Hash 转换成为 Hash 编码，降低了自体与非自体的相似度。最后模拟了一个零售业的供应链管理场景，对 RFID 入侵检测进行仿真分析，50 次实验结果表明，在期望漏检率为 0.1 时，产生的检测器数平均为 633，小于自体数 975；模拟的各类入侵漏检率均接近于期望漏检率，系统平均漏检率为 0.093，略低于期望漏检率 0.1；检测器生成时间平均为 186s。从检测效率、检测性能和检测器生成效率等方面来评价，都取得较满意的结果。本章还提出了基于免疫聚类的 RFID 协同检测方法，利用 AiNet 算法对特征日志进行压缩聚类产生协同检测器，并且进行了 RFID 协同检测仿真实验，通过模拟正常操作、已知攻击、未知攻击产生特征日志，产生协同检测器并进行检测测试，采用多维特征元素检测时，各类已知攻击的检测率均达到 98%以上，未知攻击的检测率达到 93%以上，表明协同检测方法不仅能有效地降低误检率，其检测结果还能定位到具体的攻击类型。
