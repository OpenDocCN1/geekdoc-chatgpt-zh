基于免疫机理构建的 RFID 人侵检测 MAS 模型，不仅分解了系统的复杂度，而且实现了系统运行时的健壮性。

定义 11-3 RFID 人侵检测系统的健壮性[56]。设入侵检测系统 $\Sigma_{RIDS}$ 的内部组成 $\Omega_{RIDS} = \{a_1, a_2, \cdots, a_n\}, a_i (1 \leqslant i \leqslant n)$ 为各 Agent 。如任意 $k(k < n)$ 个 Agent 失效，新入侵检测系统 $\Sigma'_{RIDS}$ 的内部结构为 $\Omega'_{RIDS} = \{a_1, a_2, \cdots, a_{n-k}\}$，如果满足

```
\(\frac{DA(\Sigma'_{RIDS}) - DA(\Sigma_{RIDS})}{DA(\Sigma_{RIDS})} \leqslant \Gamma\) (11-3)
```

式中，DA 表示检测性能；$\Gamma$ 为检测性能变化阈值。则称 $\Sigma_{RIDS}$ 具有 k 级健壮性。

以下对 RFID 人侵检测 MAS 的健壮性进行分析。

RFID 人侵检测系统的健壮性主要体现在 Agent 的自主性上，若某个 Agent 失效，可能会造成系统检测性能下降，但不会导致整个系统失效。

+   (1) 某个信息收集器失效，只影响所辖 RFID 区域的检测，对其他区域没有影响。

+   (2) 某个人侵监视器失效，只影响所辖 RFID 区域，如果建立人侵监视器集群机制，即某个人侵监视器失效，其他人侵监视器主动接替其工作，则某个人侵监视器失效后，对检测性能基本没有影响。

+   (3) 检测器中心失效，各个人侵监视器无法获取检测器更新，但是原有的检测器仍然发挥作用。

所以，部分 Agent 失效后，只使局部区域或局部时段的检测性能下降，但不会导致整个系统失效，从而体现出系统良好的健壮性。
