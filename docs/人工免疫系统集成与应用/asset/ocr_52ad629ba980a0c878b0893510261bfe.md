# 1.4.1 人工免疫系统与人工神经网络

免疫系统与神经系统之间的关系可追溯至早期的理论免疫学。1974 年 Jerne 提出了免疫网络理论，激励了一些学者去研究这两个系统的相似点。免疫网络模型作为一个新方法被用于发展和改良神经网络模型，神经网络模型也常常被用来完善人工免疫系统。

1991 年，Vertosick 和 Kelly 提出利用免疫系统来研究神经网络结构的计算范例。基于并行分布处理(PDP)理论，他们尝试把免疫网络理论映射到一个 PDP 免疫网络中。尽管作者表明免疫系统的学习行为是无监督的，但是该论文并没有明确给出学习算法[16]。
