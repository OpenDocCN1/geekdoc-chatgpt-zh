近的阅读器泄漏标签内容和一些敏感信息。

+   (2) 位置跟踪。非授权的阅读器根据 RFID 前后向信道的不对称性远距离窃听标签信息等。因为标签 ID 的唯一性,依附于个人物品上的 RFID 标签可能会泄漏个人身份,甚至会不知不觉地被跟踪。

+   (3) 标签信息篡改。缺乏安全机制的可写标签可能被非法篡改。

+   (4) 标签仿冒。利用主动攻击手段获取标签内部结构,从而重构和克隆标签,仿冒原有标签非法工作。或者用冒名顶替的标签欺骗缺乏安全认证的标签阅读器。

+   (5) 拒绝服务。攻击者通过干扰广播、阻塞信道或其他手段,产生异常的应用环境,使合法处理器产生故障,产生拒绝服务风险。

除了上述 RFID 特有的安全风险以外,构建于 TCP/IP 网络之上的 RFID 后端系统存在着与 TCP/IP 网络类似的信息窃取、黑客攻击、病毒入侵等安全风险。而且,开放的标签进一步拓宽了黑客攻击的渠道,攻击者可以利用后端系统某些设计上的漏洞,开发出具有较大杀伤力的攻击程序,如缓冲区溢出、SQL 注入等,通过标签进入后端系统进行攻击。

总的来说,RFID 标签的脆弱性、无线信道的开放性和应用的分布性,使 RFID 系统面临着诸多复杂而又独特的安全风险。其安全风险比 TCP/IP 网络的安全风险更加复杂和宽泛,已有的网络安全技术很难复制到 RFID 系统中来,必须充分考虑 RFID 的系统结构和应用特性,从整个 RFID 系统的角度探索新的 RFID 安全方法。

# 11. 2. 3 RFID 入侵检测研究的意义

因为信息安全问题的存在,RFID 尚未普及到极为重要的关键任务中。目前 RFID 的主要应用领域对私密性要求不高,因此很少注意其安全和隐私问题,很多用户对 RFID 的安全问题尚处于比较漠视的阶段。然而,对于 RFID 这种应用面很广的技术,安全隐患具有巨大的潜在破坏能力,如果不能很好地解决 RFID 系统的安全问题,随着应用的推广,未来遍布全球各地的 RFID 系统安全可能会像现在的网络安全难题一样考验人们的智慧。麻省理工学院 Auto-ID Center 的创始人 Kevin Ashton 在 InfoSec 世界大会上透露,RFID 要想使企业发生变革,还要在解决严重的安全问题之后,因为安全和隐私的考虑需要和实际应用的增长成比例[217]。

目前,针对 RFID 系统的安全研究主要集中在标签、阅读器和 RFID 后端应用之间的加密认证协议上,但是 RFID 加密认证协议存在着许多难以解决的难题。首先,RFID 标签低成本的市场要求及其有限的存储计算能力使复杂的加密认证协议难以实施;其次,加密认证协议的实施涉及标签设计、通信协议和应用流程等
