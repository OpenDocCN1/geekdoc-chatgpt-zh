

协同检测。模型的层次结构表示如式(11-31)所示。

\(\Omega_{RIDS} = \{L_P, L_L, L_H\}\) (11-31)

式中，$L_P$ 为规则检测层，识别了大部分已知的入侵类型；$L_L$ 为适应性检测层，能发现许多变型攻击、组合攻击和未知攻击；$L_H$ 为协同检测层，对适应性检测进行协同确认，从而对 $L_L$ 的误检进行纠正。

## 定理 11-1 $L_P$ 和 $L_L$ 的双层检测比只采取单层检测的检测率高。

证明 $L_P$ 的检测率:$R_{TD}(L_P)=P(Y_{LP}\cdot Flag=0|X_{RIDS} \in Type_x \wedge Type_x\cdot Flag=0)$。

$L_L$ 的检测率:$R_{TD}(L_L)=P(Y_{LL}\cdot Flag=0|X_{RIDS} \in Type_x \wedge Type_x\cdot Flag=0)$。

按照抗原识别过程，P 检测器和 L 检测器的检测结果是或的关系，系统检测率为

$R_{TD}(SYS) = P(Y_{LL}\cdot Flag = 0 \vee Y_{LP}\cdot Flag = 0 | X_{RIDS} \in Type_x \wedge Type_x\cdot Flag = 0)$
$= P(\{Y_{LL}\cdot Flag = 0\} \cup \{Y_{LP}\cdot Flag = 0\} | X_{RIDS} \in Type_x \wedge Type_x\cdot Flag = 0)$

因为

\[
\{Y_{LL}\cdot Flag = 0\} \subsetneq \{Y_{LL}\cdot Flag = 0\} \cup \{Y_{LP}\cdot Flag = 0\}
\]
\[
\{Y_{LP}\cdot Flag = 0\} \subsetneq \{Y_{LL}\cdot Flag = 0\} \cup \{Y_{LP}\cdot Flag = 0\}
\]

所以

$R_{TD}(SYS) > R_{TD}(L_P), \quad R_{TD}(SYS) > R_{TD}(L_L)$

证毕。

根据漏检率的定义，定理 11-1 等价于如下命题：

$L_P$ 和 $L_L$ 的双层检测比只采取单层检测的漏检率低。

## 定理 11-2 $L_L$ 和 $L_H$ 的协同检测比仅采用 $L_L$ 层检测的误检率低。

证明 只采用 $L_L$ 的误检率:$R_{FD}(L_L) = P(Y_{LL}\cdot Flag = 0 | X_{RIDS} \in Type_x \wedge Type_x\cdot Flag = 1)$，采用 $L_L$ 与 $L_H$ 协同的误检率。

$R_{FD}(L_L \& L_H) = P(Y_{LL}\cdot Flag = 0 \wedge Y_{LH} = Y_{LL} | X_{RIDS} \in Type_x \wedge Type_x\cdot Flag = 1)$
$= P(\{Y_{LL}\cdot Flag = 0\} \cap \{Y_{LH} = Y_{LL}\} | X_{RIDS} \in Type_x \wedge Type_x\cdot Flag = 1)$

因为

\[
\{Y_{LL}\cdot Flag = 0\} \cap \{Y_{LH} = Y_{LL}\} \subsetneq \{Y_{LL}\cdot Flag = 0\}
\]

所以

$R_{FD}(L_L \& L_H) < R_{FD}(L_L)$

证毕。

从定理 11-1 和定理 11-2 可知，在检测性能上，系统在降低漏检率和误检率方面都采取了相应的措施，多层结构在漏检率和误检率这两个相互矛盾的性能指标上取得了平衡，提高了系统的检测性能。

## 3. RFID 入侵检测的自适应性

入侵监视器的自适应性主要体现在适应性检测器的动态性上，入侵监视过程中，适应性检测器将动态划分为记忆检测器和一般检测器，从而缩短了检测时间。

## 定理 11-3 如果 RFID 系统的同类型操作连续发生 \(k\) 次，\(k>1\)，则适应性检测中采用亲和力成熟记忆比没有采用时完成一条业务日志的平均检测时间短。

证明 设 L 检测器库的规模为 \(n\)，如果没有采用亲和力成熟记忆，则完成一条业务日志的平均检测时间 \(t_0 = t_m \times n/2\)，\(t_m\) 为特征日志与一个检测器匹配计算所需的时间。

如果采用了亲和力记忆，运行一段时间后，L 检测器分为一般检测器（GDL）和记忆检测器（MDL），记忆检测器规模为 \(m\)，\(g+m=n, 0<m<n\)。

如果 RFID 系统的同类型操作连续执行 \(k\) 次，在第 \(i (i<k)\) 次，匹配的 L 检测器从 GDL 迁移至 MDL，则余下的 \(k-i\) 次操作在 MDL 中即被检测，\(k\) 个业务日志完成检测的平均时间 \(t_k = t_m \times [i \times n/2 + (k-i) \times m/2]/k\)。

因为 \(m<n\)，所以 \(t_k < t_m \times (n/2) = t_0\)，即适应性检测中采用亲和力成熟记忆比没有采用时完成一条业务日志的平均检测时间短。

证毕。

定理 11-3 阐明了周期性产生 L 检测器满足定义 11-13 的条件 2，因此 RFID 入侵检测模型具有自适应性。

另外，入侵监视器的自适应性还表现在 L 检测器库和 H 检测器库的动态更新上，因为 L 检测器库与 H 检测器库均随着业务的变更而周期性地变化，保持了与当前业务的一致性，其误检率和漏检率都会比上一轮检测器低，满足定义 11-13 的条件 1。

## 11.6 基于阴性选择 RFID 适应性检测器生成方法

L 检测器生成的关键在于 RFID 抗原编码的确定和 RFID 系统自体集的获取，确定了抗原编码和自体集后，对 II-NSA 输入符合抗原编码规范的自体集和期望漏检率，II-NSA 则输出 L 检测器的编码集合及其匹配阈值矩阵。此外，为了保证检测过程的自适应性，还需要确定 L 检测器库的动态更新策略。

### 11.6.1 RFID 抗原编码

RFID 入侵检测中，抗原即信息收集器提呈抗原决定基(即 AppLog 记录)，阴性选择模型中，通常将抗原编码为一个二进制字符串，根据式(11-4)所示的抗原决定基定义，抗原的二进制编码如表 11-1 所示。

| 位号 | 1~4 | 5~8 | 9~16 | 17~24 | 25~48 | 49~56 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| AppLog 抗原元素 | 区域(Rg) | 时域(T) | 阅读器指令(Rc) | 指令参数(Pac) | EPC | 标签返回码(RT) |

表 11-1 中，位号表示对应的抗原元素在二进制编码中占用的位置段，其中，区域(Rg)和时域(T) 各用 4 位编码，不同的编码表示不同的区域或时域。在 EPC C1G2 标准中，阅读器指令采用 8 位编码，在此也采用 8 位编码，用标准指令编码填充，不够 8 位用 0 填充，不需要译码处理。EPC C1G2 标准中，指令参数一般不超过 20 位，对于入侵检测而言，并不是所有指令参数都需要关注，可以根据具体指令选择部分安全规则需要的参数，在此用 8 位编码表示。目前，EPC 编码方案包括 EPC-64、EPC-96、EPC-256 三种，选择最具推广价值的 EPC-96 进行编码，但是 96 位 EPC 编码对于抗原过长，根据需要选取部分编码即可，此处选取 24 位的对象分类码段。EPC C1G2 标准的标签返回码为 8 位，全部编入抗原。各个抗原元素编码的连接组成了 56 位的抗原编码，该编码成为抗原的原始编码。具体的阅读器指令与指令参数的抗原元素编码，如表 11-2 所示。

表 11-2 阅读器指令与指令参数的抗原编码

| 指令 | 指令编码 | 指令参数 |
| :--- | :--- | :--- |
| Select | 1010 | 目标(1)、动作(2)、存储体(2) |
| Query | 1000 | — |
| QueryAdjust | 1001 | 通话(2)、UpDn(3) |
| QueryRep | 00 | 通话(2) |
| Ack | 01 | — |
| Nak | 11000000 | — |
| Req_RN | 11000001 | — |

表 11-2 中，指令参数栏指的是选取的参数，括号中记的是参数编码位数。例如，在某区域(0001)、某时域(1000)，发生了对某类产品(1001'0000'1100'1100'1010'0001)的用户存储体(11)的写操作(11000011)，标签返回存储器锁定错误(00000100)，则该业务日志的 56 位抗原原始编码为

```
0001 1000 11000011 11 1001'0000'1100'1100'1010'0001 00000100
```

抗原的原始编码有着明确的语义，易于理解，但是观察抗原编码容易发现，抗原分布过于紧凑，不同抗原之间的差异很小。例如，只有区域不同的两个抗原 ag1 和 ag2，其连续相同的位数可能达到 55 位，单从抗原编码来看，ag1 和 ag2 的相似度非常高，但从安全意义上来说可能有着很大的差异，有些指令在 A 区域中允许执行，而在 B 区域中是被禁止的，因此 ag1 可能为自体抗原，ag2 可能为非自体抗原，从而增大了检测的难度，抗原的原始编码也就不适合直接用于入侵检测。

本章采用 Hash 算法将原始编码转换为 Hash 编码，在检测时采用 Hash 编码，Hash 能将任意长度的输入(又叫做预映射(preimage))变换成固定长度的输出，即散列值。数学上的表述如式(11-32)所示。

\( h = H(M) \quad (11-32) \)

式中，h 为固定长度散列值；H 为单向函数；M 为任意长度的输入字符串。Hash 具有抗冲突性，即在计算上很难找到一对输入 M 和 M'，使 H(M) = H(M')，虽然 Hash 函数不可逆，但在信息编码意义上来说，h 是可以代表 M 的。如果 M 取抗原原始编码，则 h 即为抗原的 Hash 编码。

Hash 具有映射分布均匀性和差分分布均匀性，散列结果中，为 0 的 bit 和为 1 的 bit，其总数应该大致相等；输入中一个 bit 发生变化，散列结果中将有一半以上的 bit 改变，这一现象称为“雪崩效应(avalanche effect)”；要使散列结果中出现 1bit 的变化，则输入中至少有一半以上的 bit 必须发生变化。其实质是必须使输入中每一个比特的信息，尽量均匀地反映到输出的每一个 bit 上去；输出中的每一个比特，都是输入中尽可能多比特的信息一起作用的结果。因此，Hash 编码将原始编码均匀地映射到了形态空间，即使两个抗原 ag1 和 ag2 的原始编码很相似，两者的 Hash 编码也会有较大的差异，从而更容易区分出“自体”和“非自体”。

具体到 Hash 算法的选择上，本章选用信息安全领域广泛应用的 MD5 算法[225]来产生抗原的 Hash 编码，MD5 算法将 512 位数字输出为一个 128 位的散列值。具体到抗原 Hash 编码的问题上，输入为 56 位的抗原原始编码，128 位散列值作为抗原 Hash 编码相对来说过长。因为输入空间较小，选取其中 64 位作为 Hash 编码即可保证冲突的概率极小，因此本章选取 MD5 输出的 128 位的中间 64 位作为抗原 Hash 编码。下面如无特别说明，RFID 抗原编码即指其 Hash 编码。

### 11.6.2 RFID 系统自体集的获取

RFID 系统自体集是指合法的业务日志集合，自体集是产生 L 检测器的基础，可以通过三种途径获取，即人工编码、业务日志库和检测日志库。第一种方式，人工编码即根据安全需要将业务规则通过人工编码生成自体集，这种方式工作量较大，并且很难编码出完整的自体集，适合于没有数据基础的系统。第二种方式是选择一个没有遭受过入侵，并且包含了各种业务操作的业务日志库，在业务日志库中去掉重复的记录，即可获取自体集，这种方式的难点在于很难获取一个纯净的业务日志库，适合于有一定数据基础的系统，在入侵检测实施初期使用。第三种方式是在检测器日志库中提取自体集，从检测日志库中清除掉被检测为“非自体”的业务日志，余下的就是“自体”的业务日志，将“自体”业务日志去掉重复记录，即得到自体集。这种方式提取的自体集相对纯净，但是需要积累一定的检测日志后才能实施，因此适合于在检测实施过程对自体集的动态更新中提炼。

### 11.6.3 RFID 适应性检测器的动态更新

RFID 系统的自体集随着业务的变更而动态变化，所以 L 检测器的动态更新是必要的，否则系统的检测性能会逐步恶化。虽然生物免疫系统中 T 细胞、B 细胞等淋巴细胞在持续地动态生成，但是对于 RFID 入侵检测系统而言，L 检测器持续不断地更新会消耗掉大量的资源，影响检测效率。因此，采用周期性更新的方式来维护 L 检测器的有效性，自最近一次 L 检测器生成以来，如果新增的业务日志数量超过阈值，则重新选取样本集，产生自体集，并生成新一轮 L 检测器库。选择业务日志样本时，为了保证新鲜性，新增的业务日志全部选取，历史的业务日志则根据记录的年龄随机选取，年龄越大的业务日志，选择的概率越低。

### 11.6.4 基于 II-NSA 的 RFID 适应性检测实验仿真

模拟一个零售业的供应链管理场景，商场采购的商品包装都已在生产厂家贴了 EPC 标签，确定了 EPC 码和 TID 码，并对 EPC 存储器和 TID 存储器永久锁定；而保留内存和用户存储器则开放给商场使用，商场基于 RFID 进行库存、上架和结算。采购的商品首先入库存储，然后上架销售，最后商品售出结算。商品在库房要完成入库、盘点、出库操作，在入库时设置访问口令和灭活口令，并永久锁定保留内存，存储期间定时对货物进行盘点，并完成存储信息的记录，存储信息记录在用户存储区。商品出库后进入商场货架出售，在货架区需要盘点，可读取但不可修改用户存储区，对部分重要商品，不能读取用户存储区，而在结算区则可不受限制地访问用户存储区。客户在商品结算后，可以在客户服务区使标签 Kill 失效。所有 RFID 操作只能在上班时间进行。

根据以上的模拟场景，RFID 区域可划分为库存区（0000）、货架区（0001）、结算区（0010）和客服区（0011）（括号中为抗原元素编码，下同），RFID 时域简单划分为上班时间（0000）和非上班时间（0001）。随机模拟 20 类商品，挑选出其中 5 种商品作为重要商品，不能在货架区读取用户存储区，错误码电源不足（00001011）、非特定错误（00001111）、其他错误（00000000）可以容忍，当口令错误或者 CRC 校验错误时，标签将无返回信息，这时返回码填（11111111）。

实验步骤如下：

- 步骤 1 产生自体集。在实际应用中，可以从应用日志中提取自体集，本实验中，根据模拟应用的安全需求生成自体集，抗原编码均采用 Hash 编码（下同），共产生 975 个自体。
- 步骤 2 产生检测器。根据自体集用 II-NSA 算法生成 L 检测器库，参数为期望漏检率 Pf=0.1，成熟群抑制参数 c = 3。
- 步骤 3 入侵模拟检测。
  - 步骤 3.1 DoS 攻击，随机产生 1000 个与自体不等的抗原，进行检测并统计漏检率。
  - 步骤 3.2 非法 Kill 攻击，模拟在仓储区、货架区、结算区等不允许 Kill 操作的区域进行 Kill 操作，即固定阅读器指令为 Kill，限定区域为仓储区、货架区、结算区，EPC、返回码等在自体集产生时的值域中随机选取，产生 100 个抗原，进行检测并统计漏检率。
  - 步骤 3.3 非法 Write 攻击，货架区不允许 Write 操作，模拟在货架区进行 Write 操作，抗原产生方法同步骤 3.2，产生 200 个抗原，进行检测并统计漏检率；
  - 步骤 3.4 非法 Read 攻击，货架区不允许对重要商品进行 Read 操作，模拟在货架区对重要商品的 Read 操作，抗原产生方法同步骤 3.2，产生 60 个抗原，进行检测并统计漏检率；
  - 步骤 3.5 非法 Lock 攻击，货架区、结算区不允许执行 Lock 操作，模拟在货架区、结算区的 Lock 操作，抗原产生方法同步骤 3.2，产生 500 个抗原，进行检测并统计漏检率；
  - 步骤 3.6 口令攻击，模拟 Access 指令，如果口令错误，标签无返回，产生 1000 个抗原，抗原产生方法同步骤 3.2，进行检测并统计漏检率；
  - 步骤 3.7 非上班时间攻击，模拟在非上班时间对标签的 Read 操作，产生 1000 个抗原，抗原产生方法同步骤 3.2，进行检测并统计漏检率。
- 步骤 4 检测完毕，输出检测结果。

## 11.7 基于免疫网络的 RFID 协同检测器生成方法

### 11.7.1 RFID 协同检测器生成过程

根据式(11-19)的 H 检测器定义，H 检测器的产生需要分别获取 H 检测器的特征点 FeaturePoint、匹配阈值 \( L_c \) 和关联的 RFID 操作类型 Type。本节通过如下三个步骤获取 H 检测器：特征样本选取、免疫网络生成和聚簇类型标注。

- 1. 特征样本选取

从 RFID 特征日志(FeatureLog)中选择反映各操作类型的特征样本 X，在 H 检测器定义中已提及 H 检测器随着 FeatureLog 的增长而动态更新，而特征样本 X 以保证新鲜性和全面性为原则从 FeatureLog 中选取。样本 X 选取完毕后，对 X 进行 0-1 规范化处理，规范化处理按照式(11-33)进行。

\[ x_i = \frac{y_i - y_{\min}}{y_{\max} - y_{\min}} \quad (11-33) \]
