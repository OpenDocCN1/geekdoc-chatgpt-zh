原决定基结合的抗体。抗体由 DNA 分子片段随机重组产生。一旦在抗原决定级层次发现匹配，一个特定信号就会发给 B 细胞，产生适合匹配的更多的抗体，从而淹没外部抗原，消除威胁或感染。抗体既能识别抗原，又能被其他抗体识别。抗体产生的多样性基于基因变异、编辑和重组，以及抗体的交叉反应。

# 2.2.3 免疫系统包含的类型

免疫系统包含两种层次的防御异物入侵的系统，一种是固有免疫系统（the innate immune system），另一种是适应性免疫系统（the adaptive immune system）。固有免疫系统是天生就具有的，不随病原体改变而改变，它由补体、内吞作用系统和吞噬细胞组成，具有与病原体第一次遭遇时就能消灭它们的能力。适应性免疫系统主要由 T 细胞和 B 细胞组成，它能识别任何微生物并对其作出反应[22]。

# 2.3 免疫系统的基本机理

+   1. 免疫识别

免疫识别是免疫系统的主要功能之一，其识别的本质是区分“自我”和“非我”。免疫识别是通过淋巴细胞上的抗原识别受体（receptor）与抗原的结合（binding）实现的，结合的强度称为亲和度（affinity）。二者匹配程度越好，抗原与抗体的亲和度就越大。未成熟的 T 细胞首先要经历一个审查环节，只有那些不能与自我（即机体本身组织）发生应答的 T 细胞才可以离开胸腺，执行免疫应答的任务，阻止自身特异淋巴细胞成为自体攻击细胞，从而防止免疫细胞对机体造成错误攻击。该过程称为阴性选择（negative selection），它是免疫识别的一种主要方式[3]。免疫细胞对抗原的识别过程是通过免疫细胞和抗原的结合（或匹配）过程实现的，并且识别是特异的，即每一个特定的免疫细胞只能强烈结合几个类似的抗原。

+   2. 免疫学习

免疫识别过程同时也是一个学习的过程，学习的结果是免疫细胞的个体亲和度提高、群体规模扩大，并且最优个体以免疫记忆的形式得到保存。免疫学习大致可分为两种：一种发生在初次应答阶段，即免疫系统首次识别一种新的抗原时，其应答时间相对较长；而当机体重复遇到同一抗原时，由于免疫记忆机制的作用，免疫系统对该抗原的应答速度大大提高，并且产生高亲和度的抗体去除病
