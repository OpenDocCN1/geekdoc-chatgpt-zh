各长话交换局之间都设有直达路由，省内长话选路不再需要经上级汇接局转接，而由对端局采用固定的路由策略自行接通[159]。这也为动态路由的实施提供了条件。

但是，近几年电信事业的飞速发展也遗留了不少问题。例如，①交换机设备不统一；②交换网负荷不均衡，话务量异常多；③网络结构有待优化。以上问题给动态选路带来许多不确定和变化的因素。

# 2. 电信网动态路由的实现框架

# 1) 动态路由的实现策略

动态路由技术的实现是和一个国家或地区的实际网络状况紧密结合的。纵观各国实际成功使用的各种动态选路技术，没有一个是照搬其他国家的。结合我国及广东省电信网的实际情况，参照文献[159]，本章提出在电信网采用基于状态的集中式选路策略。

# (1) 集中式控制。如果实现分散式的动态选路则需要选路功能集成到交换机内部。由于电信网交换机的型号众多，选路集成到交换机几乎不可能。而集中式控制能够进行全局优化，而且成本较低，可以最大限度地减少对交换网、交换机和已有网络管理系统的改动。利用独立的集中式控制，还可以充分利用计算机系统的计算能力，并利于系统将来的扩展。

# (2) 基于状态选路。及时通过电信网络管理系统从网络中获取数据，实时计算动态选路方案，可以使系统有较强的适应性，能够及时对网络的异常情况作出反应，疏通话务流量，尽可能利用网络设备资源。这样的系统能够运行在复杂多变的网络环境中。在数据采集不全的情况下，可以使用中央计算机采用历史数据对话务作修补处理，避免数据不全影响系统的可靠性。

同时尽量利用各交换机厂家在交换系统上提供的路由控制功能。目前，虽然厂家能在交换系统上提供路由控制功能，但这一功能在各本地网的交换机上基本上没有启用。而且厂家没有针对各种复杂话务情况设计最佳话务路由控制管理方式，也没有为各种话务路由控制管理方式提供控制比例的依据。如果借助各类交换机本身提供的路由控制功能，将能够大大减少动态选路策略的复杂度。

实现基于状态的集中式选路策略应确保：① 传输质量和信令信号的可靠传输；② 路由选择应有规律性，不能出现死循环（即话务请求在转接交换局之间循环而不能到达目的交换局）；③ 路由选择应使一个呼叫连接的串联链路的数量尽量少。
