# 9.3.1 农用地分等问题简介

农用地分等一直是一个比较复杂的问题，无论在理论上还是在实践上都存在
着许多不同的观点和方法。农用地质量的高低是诸多因素综合影响的结果，且因
素之间在其地理过程中存在着不同程度的相互关联性。不同区域的自然条件和社
会经济条件的差异，不同因素对农用地质量的影响程度的变化，以及人们认识上的
区别等[181~191]，各种因素诸多矛盾纠葛在一起，构成了土地评价理论与实践中的复
杂局面。因此，积极进行农用地分等理论和方法的研究，客观地确定农用地的质
量，具有重要的意义。目前针对农用分等各方面已有了初步研究，如黄裕婕等[189]
对土地的经济评价，Wang Jiuli 等[190]对土地生产潜力进行的评价，彭补拙等[192]对
农业区土地分等定级模式的研究和对土地适宜性评价方法的研究，赵庚星等[193]
对 GIS 支持的土地评价方法的研究，Kirkby 对在 ES/GIS 两个系统支持下的土地
分等进行的研究及 Vescovi 在农用土地分等中对遥感数据的应用；也有一些学者
谈到在进行分等时对评价指标的选择，如丁生喜、冷疏影和 Dumanski 等。但现行
