品作为重要商品，不能在货架区读取用户存储区，错误码电源不足（00001011）、非特定错误（00001111）、其他错误（00000000）可以容忍，当口令错误或者 CRC 校验错误时，标签将无返回信息，这时返回码填（11111111）。

实验步骤如下：

步骤 1 产生自体集。在实际应用中，可以从应用日志中提取自体集，本实验中，根据模拟应用的安全需求生成自体集，抗原编码均采用 Hash 编码（下同），共产生 975 个自体。

步骤 2 产生检测器。根据自体集用 II-NSA 算法生成 L 检测器库，参数为期望漏检率 Pf=0.1，成熟群抑制参数 c = 3。

# 步骤 3 入侵模拟检测。

步骤 3.1 DoS 攻击，随机产生 1000 个与自体不等的抗原，进行检测并统计漏检率。

步骤 3.2 非法 Kill 攻击，模拟在仓储区、货架区、结算区等不允许 Kill 操作的区域进行 Kill 操作，即固定阅读器指令为 Kill，限定区域为仓储区、货架区、结算区，EPC、返回码等在自体集产生时的值域中随机选取，产生 100 个抗原，进行检测并统计漏检率。

步骤 3.3 非法 Write 攻击，货架区不允许 Write 操作，模拟在货架区进行 Write 操作，抗原产生方法同步骤 3.2，产生 200 个抗原，进行检测并统计漏检率；

步骤 3.4 非法 Read 攻击，货架区不允许对重要商品进行 Read 操作，模拟在货架区对重要商品的 Read 操作，抗原产生方法同步骤 3.2，产生 60 个抗原，进行检测并统计漏检率；

步骤 3.5 非法 Lock 攻击，货架区、结算区不允许执行 Lock 操作，模拟在货架区、结算区的 Lock 操作，抗原产生方法同步骤 3.2，产生 500 个抗原，进行检测并统计漏检率；

步骤 3.6 口令攻击，模拟 Access 指令，如果口令错误，标签无返回，产生 1000 个抗原，抗原产生方法同步骤 3.2，进行检测并统计漏检率；

步骤 3.7 非上班时间攻击，模拟在非上班时间对标签的 Read 操作，产生 1000 个抗原，抗原产生方法同步骤 3.2，进行检测并统计漏检率。

步骤 4 检测完毕，输出检测结果。

以上实验重复测试 50 次，检测器数和漏检率取平均值，结果见表 11-3。从表 11-3 可以看出，检测器数 Nr（633）小于自体数 Ns（975），从候选检测器数和检测器产生时间来看，186s（约 3min）的检测器产生时间基本在可接受范围之内。各类非法操作的漏检率和系统平均漏检率接近于期望漏检率。
