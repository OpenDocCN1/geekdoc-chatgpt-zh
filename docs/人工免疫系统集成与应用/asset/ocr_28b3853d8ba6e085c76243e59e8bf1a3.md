# 7. 用于模式识别的 AIS

Hunt 等从机器学习的背景出发，研究了基于免疫网络原理[31]的人工免疫系统（AIS）[31,32,69]。AIS 提供噪声耐量和在系统中无人监督的学习，此系统是自组织的，不需要反面例子，并且能清晰地描述出它已经学习了什么。这样一个系统结合了学习分类器系统的优点与神经网络的一些优势，如机械感应和基于事件的检索。

AIS 的操作包括一个根目标、一个细胞网络、一个教学数据集和一个测试数据集。在网络中的每个细胞有一个模式匹配成分，这个成分是模仿遗传机制产生的，在自然免疫系统中通过此机制来形成抗体。这使精细词汇表成为可能并且促进了模式匹配成分的多样性。系统显示了两种类型的响应：初次的和二次的。初次响应是学习阶段，这时 AIS 学习输入的教学数据中的模式，二次响应代表一个模式识别过程，在这个过程中，AIS 试图把新的数据归类为它曾见过的相关的数据。

为了把 AIS 用于一个特定的问题，首先用一个以一次性或递进的方式构造（这依赖于所讨论的问题）的样本教学集来进行训练。然后，学会的信息能在许多方面得到应用。他们已经展示了 AIS 应用于模式识别问题上的潜能。AIS 可以用于识别 DNA 序列中的促进剂。

Hunts 和 Cooke 的工作表明，在包含一个清晰的内容寻址存储器的自适应非线性网络中，AIS 怎样呈现出一个强有力的学习示例。他们研究的目的是要为机器自学习应用创立一个基于免疫的工具。

# 8. 其他应用

Bersini 和 Varela 利用免疫系统的修复原理来加速并行和局部的爬山过程。Ishida 等研究了基于免疫的方法，如多数网络、代理系统（agent system）和自识别处理[82,83]。Gilbert 等用免疫网络模型做实验，特别针对图像识别，创造了一个内容寻址的自联合存储器[31]。在这个应用中，系统的输入是 \( 64 \times 64 \) 像素的黑白图片，像素类似于抗原。这个方法是很有趣的，但是他们的实现没能获得问题的一个稳定解答。McCoy 等把阴性选择算法应用于航空图像分割[49]。Hunt 最近把基于基因搜索的免疫网络用于结构优化问题上[32]。
