# 第 5 章 矢量距免疫网络聚类算法

# 5.1 引言

de Castro 等提出的 AiNet[33]是最具影响力的人工免疫网络模型，主要用于压缩和聚类，具有减少数据冗余、描述数据结构、包含聚类形状等特征。AiNet 主要采用克隆抑制和网络抑制来保证群体的多样性，从而使抑制阈值极大地影响 AiNet算法的最终网络结构和大小。为了降低抑制阈值对 AiNet 算法的影响，本章提出矢量距免疫网络算法(vector distance artificial immune net，VD-AiNet)，矢量距将抗原、抗体分别对应于聚类问题的目标函数和优化解，在 AiNet 算法中采用矢量距来评估抗体浓度，并建立抗体促进和抑制机制，以便在鼓励适应度高的抗体的同时，限制浓度较高的抗体，增强群体的多样性，并减少参数特别是抑制阈值对 AiNet 的影响，从而降低 AiNet 的计算成本，加快模型的收敛速度，减少人为主观因素的影响。

# 5.2 AiNet 算法及其存在的问题

# 5.2.1 AiNet 算法简介

AiNet 算法忽略 B 细胞与抗体的区别，利用统计推论技术实现。AiNet 算法的基本原理是模拟生物免疫系统中抗体克隆和选择过程，将数据集作为抗原集合，生成的抗体集合则作为聚类结果。其算法简单描述如下[33]。

（1）对每一个抗原：① 计算随机产生的抗体亲和力，选出 n 个高亲和力抗体。 ② n 个高亲和力抗体根据亲和力产生克隆抗体集 D，对于每一个抗体，其亲和力越高，克隆数越多。 ③ 对 D 直接进行亲和力成熟处理得到 D*，即 D 中每个抗体根据式(5-1)进行变异，亲和力越高，变异率越小 C = C - a(C - X) (5-1)

式中，C 为网络细胞矩阵；X 为抗原矩阵；a 为学习率或者成熟率，根据 Ag-Ab 亲和力设定，亲和力越高，a 越小。 ④ 求出抗原和 D* 中每一抗体的亲和力。 ⑤ 从 D* 中选出一定比例具有高亲和力的抗体，放入克隆记忆集中。 ⑥ 求出记忆集中抗体的相似度进行克隆抑制。 ⑦ 将记忆集中的抗体存入总的记忆抗体
