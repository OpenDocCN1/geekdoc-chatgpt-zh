
```
Y = G(X)
```

根据此定义，RFID 入侵监视器 \(\Sigma_{\text{RIDS}}\) 可以表示为

```
\(\Sigma_{\text{RIDS}} = (X_{\text{RIDS}}, \Omega_{\text{RIDS}}, Y_{\text{RIDS}}, G_{\text{RIDS}})\)
```

式中，\(X_{\text{RIDS}}\) 为系统输入，即抗原提呈后的抗原决定基(业务日志)和危险信号(特征日志)，分别称为抗原的第 1 信号和第 2 信号，用 \(X_1\) 和 \(X_2\) 表示，如式(11-14)所示。

```
\(X_{\text{RIDS}} = \{X_1, X_2\}, \quad X_1 = \text{AppLog}, \quad X_2 = \text{FeatureLog}\)
```

AppLog 是被检测的客体，为了表述方便，直接称 AppLog 为抗原，FeatureLog 记录仍称为危险信号。

\(Y_{\text{RIDS}}\) 为系统输出，RFID 入侵检测实质上是一个模式分类问题，即将 RFID 抗原划分为自体/非自体(self/nonSelf)。如果有足够的先验知识，自体和非自体还可以进一步细分，如非自体类型细分为读取器窃取、拒绝服务、口令猜测等。因此，\(Y_{\text{RIDS}}\) 的定义域即为 RFID 操作类型 Type 的定义域，为如式(11-15)所示的四元组。

```
\(Y_{\text{RIDS}} = \text{Type} = \langle \text{TypeId}, \text{Name}, \text{Note}, \text{Flag} \rangle\)
```

式中，\(\text{TypeId}\) 为操作类型标识号；\(\text{Name}\) 表示操作类型名称；\(\text{Note}\) 指对操作类型的描述；\(\text{Flag}\) 为正常与否的标志，\(\text{Flag} \in \{0, 1\}\)，\(1\) 表示自体类型(即正常类型)，\(0\) 表示非自体类型(即异常类型)。

\(\Omega_{\text{RIDS}}\) 为 \(\Sigma_{\text{RIDS}}\) 的内部结构，即检测器库。与生物免疫系统类似，\(\Omega_{\text{RIDS}}\) 为一个分层和动态的结构。

\(G_{\text{RIDS}}\) 为 \(\Sigma_{\text{RIDS}}\) 的内部检测过程，即基于 \(\Omega_{\text{RIDS}}\) 实现 \(Y_{\text{RIDS}} = G(X_{\text{RIDS}})\) 的推导过程，检测过程中还会对 \(\Omega_{\text{RIDS}}\) 的结构产生影响。

## 11.5.2 RFID 入侵识别的层次结构定义

信息监视器的内部结构 \(\Omega_{\text{RIDS}}\) 主要参考生物免疫系统分层结构确定。生物免疫系统是一个由吞噬细胞、淋巴细胞和 T 辅助细胞构成的层次防御与协同结构，受生物免疫系统层次结构的启发，信息收集器的内部结构也建立相应的层次结构模型，抽象出三层 RFID 入侵检测器，分别为规则检测器、适应性检测器和协同检测器。规则检测器模仿吞噬细胞的功能，也称为吞噬细胞(phagocyte)检测器，简称为 P 检测器；适应性检测器模仿淋巴细胞的功能，也称为淋巴细胞(lymphocyte)检测器，简称为 L 检测器；协同检测器模仿 T 辅助细胞(T helper)的功能，也称为 T 辅助细胞检测器，为简称 H 检测器。

### 1. 规则检测器(P 检测器)

吞噬细胞的免疫能力通过遗传获取，遗传可视为先验知识的传承，P 检测器也基于先验知识建立，而信息收集器提呈的抗原决定基为 P 检测器的建立提供了丰富的信息基础。P 检测器的定义如式(11-16)所示，即

```
DP = <Pattern, Type> (11-16)
```

式中，Pattern 为组合的逻辑表达式，由抗原元素组成的条件表达，如抗原元素组成的逻辑表达式（Rg in(‘A’,’B’,’C’））∧（Rc = ‘Write’），表示对区域 A、B、C 的写操作。

Type 为 Pattern 对应的操作类型，检测规则为 IF Pattern·THEN Type，将 \(X_{\text{RIDS}}\) 与 Pattern 进行匹配，如果匹配了某个 DP.pattern，其输出即为对应的 DP.Type，抗原 ag 与 P 检测器 dp 匹配用谓词 PMATCH(ag,dp)表示。基于规则的检测器是目前入侵检测中最常用且最易理解的检测器。

### 2. 适应性检测器(L 检测器)

L 检测器模仿淋巴细胞基于抗原决定基进行抗原识别的能力进行定义，针对 RFID 抗原(即 AppLog 记录)进行入侵识别。根据 Burnet 的克隆选择学说[224]，每一个淋巴细胞都有一种特定的抗原受体，即抗体，抗原进入体内后选择具有相应抗体的淋巴细胞系并与其表面的抗体发生特异性结合，导致该淋巴细胞活化、繁殖、分化，从而引发特异性免疫应答。

免疫记忆是免疫系统的另一重要特点，当机体接触过某种抗原后再次接触相同抗原时，将引起比初次免疫更强的、高亲和力的抗体产生，这是由于在初次应答过程中形成了特异性抗原的记忆细胞，而记忆细胞最先参与免疫识别。

根据免疫识别和免疫记忆的原理，定义 L 检测器如式(11-17)所示。

```
DL = <Ab,Rc,Type,Time,Count> (11-17)
```

式中，Ab 表示抗体，是二进制编码的模式字符串，编码位数同抗原编码位数；Rc 指匹配阈值，抗体与抗原的相似度超过匹配阈值时，即认为该抗体识别了该抗原；Type 表示抗原类型，即淋巴细胞的特异性类型，是输出的检测结果；Time 表示最近一次抗体激活的时间；Count 表示抗体累计激活的次数。其中 Ab、Rc、Type 为 L 检测器识别抗原的基本元素，Time 和 Count 为检测器亲和力成熟和免疫记忆的基本元素。

根据阴性选择算法，抗原与抗体的匹配规则主要有 Hamming 距离匹配和连续相同位数匹配，一般情况下均采用连续相同位数匹配。为了便于表达，抗原 ag 和 L 检测器 dl 匹配用谓词 LMATCH(ag,dl)表示，一个抗原与 L 检测器匹配后，还需要根据最近的危险信号与协同检测器匹配的结果进一步判断是否为有害抗原，只有有害抗原才引发免疫反应。

L 检测器根据 RFID 系统的自体集，采用阴性选择算法产生。自体集是指合法的抗原集，RFID 系统的自体集随着业务的变更而动态变化，所以 L 检测器的动态更新是必要的，以保证检测的自适应能力。

### 3. 协同检测器（H 检测器）

H 检测器针对信息收集器提呈的危险信号（即 FeatureLog 记录），确认是否有入侵发生并且已经对 RFID 系统性能造成了有害的影响，入侵检测一般通过对危险元素设置危险阈值来确认是否发生有害攻击。但是，由于危险元素的多样化及危险元素之间的相互关联，一般很难设置出科学的危险阈值，本章通过提取特征点的方式来定义 H 检测器，并通过聚类分析自动提取特征点。

根据危险元素的定义和检测的需要，定义 H 检测器如式(11-18)所示。

```
DH = <FeaturePoint, Lc, Type> (11-18)
```

式中，FeaturePoint 表示特征点，是实数编码的数据记录，可视为抗体的另一种表现形式；Lc 指匹配阈值；Type 表示抗原类型，即输出的检测结果。

FeatureLog 与 FeaturePoint 的距离采用欧几里得距离表示，如两个点 fl 和 fp，其距离 l 用式(11-19)表示。

\( l = \sqrt{\sum_{i=0}^{n} (fp_i - fl_i)^2} \) (11-19)

式中，n 表示 fl 和 fp 中的数据维数；fp_i 和 fl_i 分别表示第 i 维数据。

定义 11-5 H 检测器匹配。对于 FeatureLog 记录 fl 与 H 检测器 dh，dh 的 FeaturePoint 和匹配阈值分别为 fp 和 lc，若 \( l = \sqrt{\sum_{i=0}^{n} (fp_i - fl_i)^2} < lc \)，则 fl 与 dh 匹配，用谓词 HMATCH(fl,dh) 表示。

如果 fl 被 dh 匹配，则认为 fl 的抗原类型为相应的 dh. Type，其中 dh. Type 有可能是自体类型（Type. flag=1），也有可能是非自体类型（Type. flag=0），当匹配非自体类型检测器时，确认 L 检测器的检测结果并发出协同信号，否则抑制 L 检测器的检测结果。但是，如果 fl 不被 H 检测器库中的任何 H 检测器匹配，则认为 fl 是未知类型，用谓词 UNKNOWN(fl) 表示，fl 为未知类型时，需要进一步的协同刺激才能确认其是否为危险信号，而进一步协同刺激则是人工确认，因此，未知类型的特征日志也是需要关注的。

随着业务的变更，各类抗原类型的特征日志分布也将缓慢变化，所以 H 检测器的动态更新是必要的，否则系统的检测性能会逐步恶化。

## 11.5.3 RFID 入侵识别方法

P 检测器库、L 检测器库和 H 检测器库形成了一个层次防御结构，决定了入侵监视器 \( \Sigma_{RIDS} \) 的内部组成 \( \Omega_{RIDS} \)。本小节将提出 RFID 入侵识别方法，即入侵监视器的输入 1 输出函数 \( G_{RIDS} \)。

### 1. 分层和协同检测的入侵识别流程

入侵监视器基于信息收集器提呈的抗原进行入侵识别，流程如图 11-12 所示。

![](img/cd91189832ca806b16310970569db51c_201_0.png)

图 11-12 抗原识别流程图

信息收集器提呈抗原决定基 ag(ag ∈ AppLog)后，首先经历 P 检测器库的检测，一旦发生 PMATCH(ag, dp), dp ∈ DP, 则输出异常，即 ag ∈ NonSelf; 否则，进入 L 检测。

L 检测中，一旦发生 LMATCH(ag, dl), dl∈ DL, 则进入 H 检测(即协同检测)，否则输出正常，即 ag∈ Self。

H 检测中，需要等待 ag 相应的危险信号 fl，即与 ag 同区域(Rg)的下一统计周期的 FeatureLog，等待到危险信号 fl 后，fl 经历协同检测库 DH 的检测，一旦发生 HMATCH(fl, dh), dh∈ DH, 如果 dh. Type=0, 表示检测到危险信号，报告异常，确认之前的抗原 ag∈ NonSelf; 否则，报告正常，认为之前的抗原 ag∈ Self, 可以认为是偶尔发生的误操作。如果 H 检测中，一直没有 HMATCH(fl, dh)(dh∈ DH) 发生，则认为发生了 UNKNOWN(fl)，需要人工进一步协同判断之前的 ag 是否属于 NonSelf。

### 2. 适应性检测器亲和力成熟

为了提高检测效率，模拟生物免疫系统的二次免疫应答，将 L 检测器划分为记忆 L 检测器群 MDL 和一般 L 检测器群 GDL。受抗原刺激越多，刺激时间越近的抗体，与抗原的亲和力越强。因此，设置一个亲和力阈值，亲和力超过阈值的抗体进入 MDL，为了区别抗体-抗原亲和力，此处将其定义为检测器亲和力。

设有 L 检测器 d，其亲和力记为 Aff (d)，如式(11-20)所示。

```
Aff(d) = \frac{d. Count}{T_c + T_{now} - d. Time} \quad (11-20)
```

式中，T_{now} 为当前时间；T_c 为常数。为避免新受刺激的检测器亲和力过高，随着时间的推移，未受刺激的检测器亲和力逐渐下降。

MDL 和 GDL 的表述如式(11-21)所示。

```
\begin{cases} \text{MDL} = \{d \in \text{DL} | \text{Aff}(d) > \text{ThA}\} \\ \text{GDL} = \text{DL} - \text{MDL} \end{cases} \quad (11-21)
```

式中，ThA 表示亲和力阈值。

当抗原提呈后，在接受 L 检测器的检测时，系统首先将抗原与 MDL 中的记忆检测器匹配，如果抗原未与 MDL 中的检测器匹配，则继续与 GDL 中的检测器匹配。一旦发生匹配，则认为检测到了非自身，更新检测器亲和力值，如果当前检测器不属于 MDL 且亲和力大于阈值，则将当前检测器加入 MDL。

以上监视过程仅描述了检测器由 GDL 向 MDL 迁移的过程，随着时间的推移，未受抗原刺激的检测器亲和力逐渐下降，当降到亲和力阈值 ThA 之下时，则需要从 MDL 往 GDL 迁移，并将其亲和力置为 0（即 d. count=0)，该过程称为记忆检测器遗忘，记忆检测器遗忘采用定时器实现，定时从 MDL 中清理出遗忘的检测器。

记忆检测器的动态模型如式(11-22)所示。

```
\begin{cases} \text{MDL}(0) = \varnothing \\ \text{MDL}(t) = \text{MDL}(t-1) + \text{NewMDL}(t-1,t) - \text{ForgetMDL}(t-1,t) \end{cases} \quad (11-22)
```

式中，$t$ 表示时间;NewMDL $(t-1,t)$ 表示 $t-1$ 到 $t$ 时刻新加入的记忆检测器; ForgetMDL $(t-1,t)$ 表示 $t-1$ 到 $t$ 时刻遗忘的检测器。

### 3. 适应性检测器更新与亲和力继承

L 检测器是由检测器中心周期性动态更新的，入侵监视器一般批量地从 Agent 共享的黑板中获取 L 检测器，替换掉原有的 L 检测器，新一轮检测器替换前一轮检测器的时候，为了保持检测效率，采用亲和力继承的方式，从新一轮检测器中挑选出新的 MDL 以保持 MDL 的检测效率。

设新一轮检测器集合为 DL$(t)$，前一轮记忆检测器为 MDL$(t-1)$，产生的新一轮记忆检测器为 MDL$(t)$，MDL$(t)$产生算法描述如下。

- 步骤 1 初始化 MDL $(t) = \varnothing$;
- 步骤 2 对于每一个前一轮记忆检测器 DLold ∈ MDL$(t-1)$，DLold.Ab 作为抗原，与 DL$(t)$ 作匹配测试；
- 步骤 2.1 如果与 DLold.Ab 连续匹配位数最大的新检测器为 DLnew，并且 DLold.Ab 与 DLnew 匹配，则
  - 步骤 2.1.1 亲和力继承
    ```
    DLnew.Time = DLold.Time;
    DLnew.Count = DLold.Count;
    ```
  - 步骤 2.1.2 记忆迁移。
    将 DLnew 加入 MDL$(t)$，并从 DL$(t)$ 中清除；
    从 DL$(t)$ 中清除抗体 DLnew；
- 步骤 3 MDL$(t-1)$ 的每一个检测器循环完毕，结束；否则返回步骤 2。

## 11.5.4 RFID 入侵识别方法的检测性能分析

### 1. 检测性能定义

入侵检测方法的检测性能一般用检测率、误检率和漏检率来评价，RFID 入侵检测方法不是简单地输出入侵与否的标志，而是输出对应的操作类型，本章将定义某入侵类型的检测率、误检率和漏检率，同时定义系统的检测率、误检率和漏检率。

> 定义 11-6 入侵类型 Type$_x$ 的检测率 $R_{TD}(Type_x)$。指入侵类型 Type$_x$ 的业务日志(抗原)被 RFID 入侵检测方法正确识别的概率，定义如式(11-23)所示。

```
$R_{TD}(Type_x) = P(Y_{RIDS} = Type_x | X_{RIDS} \in Type_x), \forall Type_x. Flag = 0$ (11-23)
```

式中，Flag=0 表示是入侵类型；Flag=1 表示是正常类型。

> 定义 11-7 入侵类型 Type$_x$ 的漏检率 $R_{MD}(Type_x)$。指入侵类型 Type$_x$ 的业务日志(抗原)不能被 RFID 入侵检测方法正确识别的概率,如式(11-24)所示。

$R_{MD}(Type_x) = 1 - R_{TD}(Type_x), \quad \forall Type_x. Flag = 0 \quad (11-24)$

**定义 11-8** 入侵类型 Type$_x$ 的误检率 R$_{FD}$(Type$_x$)。指正常操作类型的业务日志(抗原)被 RFID 入侵检测方法错误识别为 Type$_x$ 的概率,如式(11-25)所示。

$R_{FD}(Type_x) = P(Y_{RIDS} = Type_x \mid X_{RIDS} \notin Type_x), \quad \forall Type_x. Flag = 0 \quad (11-25)$

对于系统检测性能,则将其泛化为能否正确识别入侵进行评价,RFID 入侵检测方法只要把包含入侵操作的业务日志识别出来,即达到了入侵检测的目的,不需要识别具体的入侵操作类型。

**定义 11-9** 系统检测率 R$_{TD}$(SYS)。指入侵类型的业务日志(抗原)被识别为入侵操作类型的概率,如式(11-26)所示。

$R_{TD}(SYS) = P(Y_{RIDS}. Flag = 0 \mid X_{RIDS} \in Type_x \wedge Type_x. Flag = 0) \quad (11-26)$

**定义 11-10** 系统漏检率 R$_{MD}$(SYS)。指任何入侵类型的业务日志(抗原)没有被识别为入侵操作类型的概率,如式(11-27)所示。

$R_{MD}(SYS) = 1 - R_{TD}(SYS) \quad (11-27)$

**定义 11-11** 系统误检率 R$_{FD}$(SYS)。指正常业务日志(抗原)被错误识别为入侵操作类型的概率,如式(11-28)所示。

$R_{FD}(SYS) = P(Y_{RIDS}. Flag = 0 \mid X_{RIDS} \in Type_x \wedge Type_x. Flag = 1) \quad (11-28)$

**定义 11-12** 系统检测性能 DA(SYS)。为了综合评价检测性能,本章采用错误率作为检测性能的度量,定义如式(11-29)所示。

$DA(SYS) = \omega_{MD} \times R_{MD}(SYS) + \omega_{FD} \times R_{FD}(SYS) \quad (11-29)$

式中, $\omega_{MD}$ 和 $\omega_{FD}$ 为权值,根据对漏检和误检的不同侧重取值

$0 \leqslant \omega_{MD} \leqslant 1, \quad 0 \leqslant \omega_{FD} \leqslant 1, \quad \omega_{MD} + \omega_{FD} = 1 \quad (11-30)$

所以, $0 \leqslant DA(SYS) \leqslant 1$, DA(SYS) 越小,说明检测性能越好,一般而言,好的系统检测性能需要平衡漏检率和误检率。

**定义 11-13** 系统自适应性。设 RFID 入侵检测系统 $\Sigma_{RIDS}$ 的内部组成 $\Omega_{RIDS}$ 是动态变化的, t 时刻的系统内部为 $\Omega_{RIDS}(t)$, 系统为 $\Sigma_{RIDS}(t)$, 经过一段时间 k 后, 随着入侵的刺激, 系统内部为 $\Omega_{RIDS}(t+k)$, 系统为 $\Sigma_{RIDS}(t+k)$, 如果满足以下任意一个条件,则称系统具有适应性。

- (1) $DA(\Sigma_{RIDS}(t+k)) < DA(\Sigma_{RIDS}(t))$;
- (2) $\Sigma_{RIDS}(t+k)$ 完成一条特征日志检测所需的时间比 $\Sigma_{RIDS}(t)$ 少。

### 2. RFID 入侵检测的多层次性

RFID 入侵监视器的内部结构 $\Omega_{RIDS}$ 模拟了生物免疫系统的多层防御体系,监视过程中经历 P 检测器、L 检测器、H 检测器的检测,其中,L 检测器与 H 检测器
