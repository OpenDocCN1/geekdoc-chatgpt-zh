小越好，区间型指标以其值落在某一特定区间为最优，而描述型指某种特定形式对应某种优度。在此，海拔高度和坡度是成本型，有机质是效益型，pH 是区间型，而土壤质地和利用类型为描述型。本章利用基于平均水平的效用函数方法将指标值初始化，并引入中间变量 $M_{ij}$。

# (1) 对效益型指标

$M_{ij} = \frac{X_{ij} - \overline{X}_{ij}}{|\overline{X}_{ij}|}$ (10-1)

式中，$\overline{X}_{ij}$ 为指标各单元的平均值，即

$\overline{X}_{ij} = (\sum_{i=1}^m X_{ij}) / m$ (10-2)

# (2) 对成本型指标

$M_{ij} = \frac{\overline{X}_{ij} - X_{ij}}{|\overline{X}_{ij}|}$ (10-3)

# (3) 对区间型指标：当 $X_{ij} \leqslant A$ 时

$M_{ij} = \frac{X_{ij} - A}{|A|}$ (10-4)

当 $X_{ij} \geqslant B$ 时

$M_{ij} = \frac{B - X_{ij}}{|B|}$ (10-5)

当 $B \geqslant X_{ij} \geqslant A$ 时

$M_{ij} = \frac{X_{ij} - A}{|B - A|}$ (10-6)

式中，$A, B$ 分别是区间型指标的最优上、下界。将原始指标值 $X_{ij}$ 按下述公式转化为区间 $[-1, 1]$ 上的效用函数值 $Y_{ij}$：

$Y_{ij} = \frac{1 - e^{-M_{ij}}}{1 + e^{-M_{ij}}}$ (10-7)

显然，$Y_{ij} = f(M_{ij})$ 是一条 S 形曲线，$M_{ij}$ 反映了原始数据 $X_{ij}$ 偏离平均值 $\overline{X}_{ij}$ 的程度。当 $X_{ij} = \overline{X}_{ij}$ 时，$M_{ij} = 0$；当 $X_{ij} > \overline{X}_{ij}$ 时，$M_{ij} > 0$，且 $Y_{ij}$ 随 $M_{ij}$ 的增长非线性递增。
