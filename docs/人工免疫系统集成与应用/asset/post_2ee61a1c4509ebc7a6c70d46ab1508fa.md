
的多模态优化算法不易获得全部的局部最优解。分层免疫算法能够快速准确地找出所有局部最优解，具有较好的收敛特性。

## 8.5 基于分层免疫算法的动态路由评估模型

### 8.5.1 动态路由研究进展

在电信行业竞争日益激烈的今天，提高电信服务质量成为电信企业工作的重要目标之一。电信企业从初期的粗放型高速发展到现在的深入优化发展，越来越需要在拓展网络、追求数量和覆盖目标的同时，不断地追求质量和效益目标。

- 1. 路由选择

目前提高电信企业服务质量的手段有许多，其中话务控制是最重要的方式之一。实现电信网络话务控制功能有多种手段。例如，①动态路由控制；②自动拥塞控制(automatic congestion control, ACC)；③临时迂回路由控制(temporary alternative routing, TAR)；④中继路由控制；⑤可达出路由控制；⑥中继电路预留；⑦目的码截裁控制等。这些话务控制手段的关键是通过控制话务的选路和控制到特定出路由或目的码的话务量来防止网络过载，也就是话务的路由选择问题，即根据实时检测到的网络的运行状况，采用人工或自动的方式通过更改路由表实施话务流量控制，也称为电信网的动态选路技术。因此，电信网选路技术是电信网实施话务控制的关键技术之一，路由选择策略的好坏直接影响电信网的服务质量。

电信网的网络结构和路由选择策略是密不可分的。不同的网络结构所使用的路由选择策略也不相同。基于我国过去的分级式的网络结构，国内主要采用分级固定路由技术。这种固定路由选择策略虽然曾经被广泛使用，但随着通信需求的加大及电信业务的高速增长，固定路由选择策略已不再适应电信网的进一步发展[157,158]。

同时，随着电信话务网络结构由分级网逐渐合并为无级网，如果仍然采用原来的固定路由选择策略，势必会造成更大的浪费。所以路由选择策略也要做相应的改变，从原来的固定路由转变为适合无级网的动态路由选择策略。

所谓动态路由，是指电信网络中迂回路由选择次序可以随时间而变动，即具有时变特性[159]。动态路由技术使得电信网络可靠性增加，接通率提高，信息交换的费用得以降低，网络结构更能适应今后层出不穷的新业务。动态路由为改善服务质量奠定了基础，由此可以吸引更多的新客户，显著地提高电信网络的经济效益。

### 2. 动态路由策略的分类

目前，动态路由策略有两种较常用的分类方法：按选路系统中处理机的位置分类，动态路由策略可分为集中式与分散式；按作出路由决策所用到的信息分类，动态路由策略可分为时变与自适应。下面予以简单介绍。

### 1) 集中式与分散式

目前，基本的动态选路功能可以采用两种方式实现：①集中式；②分散式。在集中式的选路系统中，主要用一台单独的中央处理机进行选路计算。因此，集中式选路技术易于管理，系统维护和管理成本也较低。而且采用集中的选路策略可以真正实现话务的全局优化。但是集中式选路也有它的不足。如果一旦中央处理机发生故障或网络连接中断，就会严重影响整个网络的运行，系统的可靠性较差。同时，如果网络话务较大，将选路功能集中于一个处理机也限制了选路的及时响应。目前典型的集中式动态选路的算法主要有 DNHR、DCR 等[159~162]。

在分散式的选路系统中，选路计算由多个处理机来完成。选路的实现可以是各处理机独立完成，也可以是相互交换话务、资源状态信息协作完成。分散式选路比集中式选路的成本要高，部分选路系统需要直接集成到交换机中，同时也需要复杂的网络管理。另外，分散选路只能是局部优化，不能做到全局优化。如果交换机直接承担选路计算，则不能使用复杂的算法；否则计算难以实时完成。但分散选路也有其优点，如可以增加系统的可靠性，可以更快地对话务、资源的状态改变作出反应；另外，路由计算分布在整个网络上，受网络过载的影响较小。目前典型的分散式动态选路的算法主要有动态交替路由算法(dynamic alternate routing，DAR)[159,160,163,164]。

### 2) 时变与自适应

在时变的选路系统中，选路是随时间变化的。这种方法根据网络在一天内不同时间的预测话务量来优化网络，避开阻塞链路和节点。

自适应选路也称为基于状态选路，是完全由网络当前状态驱动的。它能根据当前条件选择最优的路由。与时变选路不同的是，迂回路由是随状态变化而实时或周期性产生的，与一天内的时刻没有关系。由于需要经常检查网络状态，自适应选路给交换机带来额外的负担，但能更好地响应本地网络的变化。动态控制路由(dynamically controlled routing，DCR)是自适应选路的典型例子[133,165~167]。

## 8.5.2 电信网动态路由控制系统设计

### 1. 现有电信网的特点与问题

广东省电信网络建设一直走在全国其他省份的前面。C3 及 C4 两级长话交换网已在网络管理和拓扑结构上合并成省内 E2 交换平面，构成点对点的无级网状网。

各长话交换局之间都设有直达路由，省内长话选路不再需要经上级汇接局转接，而由对端局采用固定的路由策略自行接通[159]。这也为动态路由的实施提供了条件。

但是，近几年电信事业的飞速发展也遗留了不少问题。例如，①交换机设备不统一；②交换网负荷不均衡，话务量异常多；③网络结构有待优化。以上问题给动态选路带来许多不确定和变化的因素。

### 2. 电信网动态路由的实现框架

### 1) 动态路由的实现策略

动态路由技术的实现是和一个国家或地区的实际网络状况紧密结合的。纵观各国实际成功使用的各种动态选路技术，没有一个是照搬其他国家的。结合我国及广东省电信网的实际情况，参照文献[159]，本章提出在电信网采用基于状态的集中式选路策略。

- (1) 集中式控制。如果实现分散式的动态选路则需要选路功能集成到交换机内部。由于电信网交换机的型号众多，选路集成到交换机几乎不可能。而集中式控制能够进行全局优化，而且成本较低，可以最大限度地减少对交换网、交换机和已有网络管理系统的改动。利用独立的集中式控制，还可以充分利用计算机系统的计算能力，并利于系统将来的扩展。

- (2) 基于状态选路。及时通过电信网络管理系统从网络中获取数据，实时计算动态选路方案，可以使系统有较强的适应性，能够及时对网络的异常情况作出反应，疏通话务流量，尽可能利用网络设备资源。这样的系统能够运行在复杂多变的网络环境中。在数据采集不全的情况下，可以使用中央计算机采用历史数据对话务作修补处理，避免数据不全影响系统的可靠性。

同时尽量利用各交换机厂家在交换系统上提供的路由控制功能。目前，虽然厂家能在交换系统上提供路由控制功能，但这一功能在各本地网的交换机上基本上没有启用。而且厂家没有针对各种复杂话务情况设计最佳话务路由控制管理方式，也没有为各种话务路由控制管理方式提供控制比例的依据。如果借助各类交换机本身提供的路由控制功能，将能够大大减少动态选路策略的复杂度。

实现基于状态的集中式选路策略应确保：① 传输质量和信令信号的可靠传输；② 路由选择应有规律性，不能出现死循环（即话务请求在转接交换局之间循环而不能到达目的交换局）；③ 路由选择应使一个呼叫连接的串联链路的数量尽量少。

### 2) 动态路由控制系统的设计

通过调研和分析测试数据，发现现有电信网络存在负载不均衡，话务分布情况存在差异，交换节点负载不平均等特点，这为动态路由的有效实施提供了可能。动态路由在忙时可以产生较明显的效果。在制定路由策略时，根据话务溢出、应占比等与电路数的关系，可为每一链路选择合适的迂回节点，平衡全网负载，使全网性能最优。因此，动态路由技术在广东省电信网中的实现是可行且必要的。

电信网动态路由控制的具体实现思路如下：动态路由技术主要结合电信网络管理系统，由中央计算机每隔一段时间从电信网采集话务数据，根据这些话务数据采用特定路由评估模型计算路由方案，然后转换成相应的交换机路由指令传递给电信网络管理系统，并由电信网络管理系统将路由指令发送给交换机从而实现话务路由的控制。其流程图如图 8-5 所示。

- (1) 数据采集。

通过数据收集和控制接口采集的数据主要有两类：① 计算动态路由所需要的话务数据，如路由负荷、试呼次数、占用次数、应答次数、设备数等统计量；② 评估网络状态的相关数据，如基于路由的应答试呼比、基于路由的应答占用比、基于路由的呼叫溢出率、基于路由的每小时每电路试呼话务量、基于路由的每小时每电路占用话务量等。

- (2) 动态路由评估模型。

动态路由评估模型主要是采用各种优化算法，如遗传算法、Tabu 算法、单纯形算法等，对通过数据收集接口系统定时传送上来的各种话务数据进行计算，进而生成当前合适的路由方案集，并转换成相应的交换机指令，生成路由表指令，通过电信网络管理系统传送给具体的交换机以实现话务路由的控制。

- (3) 电信网络管理系统。

动态路由控制系统对电信交换网络的控制主要是通过电信网络管理子系统(network management subsystem, NMS)网络管理系统来实现的。NMS 主要实现两种主要功能。

网络信息功能。网络信息功能是指 NMS 能实时地监视和汇报网络运行状态。网络信息功能包括以下功能：①基于路由或目的地的“应答占用比”的监视和观察功能；②基于路由或目的地的“溢出率”的监视和观察功能；③基于路由或目的地的“网络性能数据”测量；④“路由负载”的监视和观察功能；⑤“网络管理计数器数据”输出功能；⑥基于路由的“全电路忙”的监视和观察功能；⑦“网络性能记录”输出功能。

网络控制功能。网络控制功能是指 NMS 能通过控制选路和到特定出路由或目的码的话务量来防止网络过载。

实现基于状态的集中式选路，关键是路由方案的优化问题。因此，电信网动态路由系统的核心是路由评估模块，该模块采用各种优化算法，如遗传算法、Tabu 算法、单纯形算法等。路由方案问题是一个复杂度非常高的优化问题。只有在足够短的时间内得到一个全局优化的路由方案，才能满足集中式动态选路策略的实现要求，因此，采用何种优化模型是路由求解程序的关键。文献[158]提出基于遗传算法的动态路由算法，讨论其各种优化策略，并使用模拟程序对网络使用路由方案的情况进行模拟。模拟结果表明，在目前的网络情况下，在路由质量和更新周期要求不高时，该算法能取得较好的效果。但随着周期由 1h 缩短到 15min，遗传算法运算量过大及易陷入局部极小点等缺点变得显著起来。如果运算时间过长，则难以满足动态实时控制路由的要求。陈海广提出基于逻辑模型的电话网动态选路系统(LMBDR)，以解决现有网络的动态选路问题[156]。邵亮[159]使用 IDCR 算法解决动态选路问题。与遗传算法相比，LMBDR、IDCR 虽然速度比较快，但所得的路由方案并不是完全的全局优化方案，解的质量不高。

实际情况要求发展一个新的模型。该模型必须能够用较短的时间，得到一个全局优化的路由方案，从而满足集中式动态选路的时间和质量的要求。从分层免疫算法的收敛特性验证、有效性分析和性能比较分析可以看出，分层免疫算法具有随机优化方法所具有的优点。同时，在分层免疫算法中，N 个低层免疫操作的具体实现形式各不一样，它们中每一个经过一段时间的免疫操作，均可以获得一些适应度较高的优秀抗体。通过高层免疫操作，N 个低层免疫操作 IA，可以获得不同种类的优秀抗体，从而为它们提供了更加平等的竞争机会，提高了整个模型的多样性和收敛速度。同时，低层各免疫操作通过设置不同的操作算子和参数，为高层免疫操作产生更多的优良模式(抗体)，可使分层免疫算法完成多极值搜索或进行全局最优的搜索有不同的特性，以使其具有更好的搜索能力。同时分层免疫算法也具有一般免疫算法的优点。分层免疫算法的上述特点，能满足集中式动态选路的要求，为高效率地解决动态路由优化问题奠定了基础。因此，为了得到更适合于电信网络话务路由控制的优化方法，本章将分层免疫算法应用于动态路由评估，构建一个基于分层免疫算法的动态路由评估模型，为动态路由优化提供一种新的方法。

```
Traffic = (TrafficBC)n x n (8-30)
```

从图 8-5 可知，动态路由控制系统建立在电信网管系统平台上，从电信网管系统获取话务数据，系统的话务数据是完成话务量，而本章的路由评估计算使用的是到达话务量，我们使用以下的经验公式计算到达话务量(计算中使用的电路数、试呼次数、占用次数、应答次数、每线话务量也是从网管系统获取的统计量)。

```
到达话务量 = 完成话务量 + K × (试呼次数 − 占用次数) × T (8-31)
```

式中，T 为损失呼叫平均占用时间，取值为 18s，即 T=0.005h；K 是与应答试呼比有关的系数，取值范围如表 8-3 所示。

（规定：如果试呼次数 = 0，那么到达话务量 = 0；如果试呼次数＜占用次数，那么到达话务量 = 完成话务量）

| 应答次数/试呼次数 | K |
|---|---|
| <10% | 1 |
| 10%~15% | 1.5 |
| 15%~20% | 2 |
| 20%~25% | 3 |
| >25% | 4 |

**定义 8-4 (迂回路由)** 直达路由溢出的话务所使用的转接路由称为迂回路由。例如，从交换机 B 到 C 的话务，如果超过 B,C 间直达链路能承受的话务量，就会产生话务溢出，此时为溢出话务所选择的路由就称为迂回路由。迂回路由有一级迂回路由、二级迂回路由等。在本章的模型中，需要选择的路由共有 n(n-1) 个，可以用路由矩阵表示如下（其中，RouteBC 没有意义，可设为一）：

```
ROUTE = (RouteBC)n×n (8-32)
```

对固定选路策略来说，迂回路由是固定的，即 ROUTE 矩阵是个常量。动态路由问题要解决的是根据当前的电信网拓扑结构和话务量，确定下一周期内每两个交换机之间的迂回路由，以使得网络的总的话务阻塞率(totalblock)最小。

已知：LINE, TRAFFIC
求：ROUTE
使得：TOTALBLOCK 最小。

当然也可以设定其他优化的目标。例如，文献[168]中提出的动态路由算法以每条链路的溢出率都低于一个最小值为其优化目标。

假设电信网络中一共有 n 个交换机，由于交换机到本身不需要动态路由，故路由矩阵的大小为 n × (n-1)。在单级路由的情况下，交换机 B,C 之间可以从除了 B,C 外的所有 n-2 个交换机中选取一个作为迂回路由，所以动态路由问题的状态空间大小达到 (n-2)n×(n-1)。由于问题的规模很大，不可能进行全局搜索求出最优解，一般只要求出近似最优解即可。

### 2. 基于分层免疫算法的动态路由评估模型的具体实现

利用分层免疫算法来求解动态路由问题，主要完成三方面的工作：对要求解的问题进行编码，选择合适的适应度函数，确定各低层免疫操作的克隆选择、变异等操作算子。

- 1) 编码问题

在本章的路由求解算法中，路由矩阵只具有符号而不具有数值的意义。本章直接把求解的 n × n 的路由矩阵作为抗体编码，每一位上可以取的值为 0 ~ n-1，求解空间和编码空间相同。
