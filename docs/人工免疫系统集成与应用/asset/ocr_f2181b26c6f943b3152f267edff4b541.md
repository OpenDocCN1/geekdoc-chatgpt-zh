# 11.8 本章 小结

本章参考生物免疫的协同检测方法和多 Agent 技术建立了一个 RFID 人侵检测模型，通过 RFID 的应用特征分析，定义了 RFID 的抗原决定基，通过分析已知 RFID 攻击的统计特征，定义了 RFID 的危险信号，并提出了基于无线信道侦听与 RFID 中间件日志相结合的抗原提呈方案。基于 RFID 抗原决定基和危险信号，提出了一个免疫协同的 RFID 人侵识别框架，定义了 RFID 适应性检测器和 RFID 协同检测器，理论上，免疫协同人侵识别能有效地降低因偶尔误操作而引发的误检率，提高了 RFID 人侵检测方法的可用性。

本章提出了基于阴性选择的 RFID 适应性检测方法，针对抗原的原始编码中自体和非自体相似度过高，不利于阴性选择算法检测的问题，本章将抗原原始编码通过 Hash 转换成为 Hash 编码，降低了自体与非自体的相似度。最后模拟了一个零售业的供应链管理场景，对 RFID 人侵检测进行仿真分析，50 次实验结果表明，在期望漏检率为 0.1 时，产生的检测器数平均为 633，小于自体数 975；模拟的各类人侵漏检率均接近于期望漏检率，系统平均漏检率为 0.093，略低于期望漏检率 0.1；检测器生成时间平均为 186s。从检测效率、检测性能和检测器生成效率等方面来评价，都取得较满意的结果。本章还提出了基于免疫聚类的 RFID 协同检测方法，利用 AiNet 算法对特征日志进行压缩聚类产生协同检测器，并且进行了 RFID 协同检测仿真实验，通过模拟正常操作、已知攻击、未知攻击产生特征日志，产生协同检测器并进行检测测试，采用多维特征元素检测时，各类已知攻击的检测率均达到 98%以上，未知攻击的检测率达到 93%以上，表明协同检测方法不仅能有效地降低误检率，其检测结果还能定位到具体的攻击类型。
