类模型的适应度函数。利用离散度矩阵不但能反映同类样本的聚集程度，而且能反映不同类之间的分离程度，首先介绍几个离散度矩阵。

+   (1) 定义类型 j 的离散度矩阵为

```
$S_j = \frac{1}{n_j} \sum_{k=1}^{n_j} (x_k^i - m_j)(x_k^i - m_j)^T \quad (9-7)$
```

+   (2) 定义类内离散度矩阵为

```
$S_w = \sum_{j=1}^c P_j S_j \quad (9-8)$
```

+   (3) 定义类间离散度矩阵为

```
$S_B = \sum_{j=1}^c (m_j - m)^T (m_j - m) \quad (9-9)$
```

+   (4) 定义总离散度矩阵为

```
$S_T = \frac{1}{n} \sum_{k=1}^n (x_k - m)(x_k - m)^T = S_w + S_B \quad (9-10)$
```

显然，对于一种聚类结果，类内离散度越小越好，类间离散度越大越好。因此，作为量的描述，可由离散度矩阵的积和行列式值引出适应度函数的不同形式

```
$f_{T1} = \text{tr}(S_w^{-1} S_B) \quad (9-11)
$f_{T2} = |S_w^{-1} S_B| \quad (9-12)
$f_{T3} = \text{tr}(S_w^{-1} S_T) \quad (9-13)
$f_{T4} = |S_w^{-1} S_T| \quad (9-14)
```

则适应度函数可设计为 $f_T(x) = f_{T1}, f_T(x) = f_{T2}, f_T(x) = f_{T3}$ 或 $f_T(x) = f_{T4}$。这些适应度函数同时考虑了类内的离散度和类间的离散度，为了得到更好的聚类结果，它们的值越大越好。
