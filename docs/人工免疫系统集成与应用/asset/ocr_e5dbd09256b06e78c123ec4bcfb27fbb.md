# ## 5. 农用地利用等划分

农用地第 j 种指定作物的利用等指数按下式计算：

$$Y_{ij} = R_{ij} \times KL_j$$ (9-25)

农用地利用等指数按下式计算：

$$Y_i = \sum Y_{ij}$$ (9-26)

式中，$Y_{ij}$ 为第 $i$ 个分等单元 $j$ 种指定作物的利用等指数；$Y_i$ 为第 $i$ 个分等单元农用地利用等指数；$R_{ij}$ 为第 $i$ 个分等单元内第 $j$ 种指定作物的自然质量等指数；$KL_j$ 为第 $j$ 种指定作物的土地利用系数。然后采用 AIS 聚类模型对高要市农用地利用等别进行计算，具体分等结果见附表 13。
