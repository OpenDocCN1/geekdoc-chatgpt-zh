步远离自体，因此 $M$ 的变异根据三种不同的位采用不同的变异概率，分别为自体匹配位概率 $P_{ma}$，群内相似位概率 $P_{mb}$ 和一般位概率 $P_{mc}$，其中，$P_{mb} > P_{ma} > P_{mc}$，一般 $P_{mb} = 0.2 \sim 0.3, P_{ma} = 0.1 \sim 0.15, P_{mc} = 0.05 \sim 0.1$。

选择策略与克隆变异的目标一致,首先保证检测器的自体相似度不上升,在此基础上选择群内相似度最小的克隆子检测器,如果子检测器的群内相似度小于父检测器,则用该子检测器替换父检测器。

# 7.3.6 期望漏检率计算

通过 II-NSA 获取的成熟检测器,除了检测器字符串外,同时获取了自体相似度 $r_s$,根据定理 7-1, $r_s$ 即可作为检测器的抗原匹配阈值,因此每个检测器的抗原匹配阈值可互不相同,充分发挥了各自的检测能力。

NSA 算法中,当自体集规模 $N_s$ 较大时,期望漏检率 $P_f$ 如式(7-14)所示[44]。

$$P_f = (1 - P_M)^{N_R}$$ (7-14)

式中, $P_M$ 的定义如式(7-2)所示; $N_R$ 为检测器数。

对于匹配阈值可变的检测器库,每个检测器库的 $P_M$ 是可变的,则 $P_f$ 的计算如式(7-15)所示。

$$P_f = \prod_{i=1}^{N_R} (1 - P_{Mi})$$ (7-15)

式中, $N_R$ 为成熟群 $M$ 的检测器数量; $P_{Mi}$ 为某个检测器与一个随机字符串的匹配概率,如式(7-16)所示。

$$P_{Mi} \approx m^{-r_{si}} [(l - r_{si})(m - 1)/m + 1]$$ (7-16)

式中, $r_{si}$ 为第 $i$ 个检测器的抗原匹配阈值。

因为匹配阈值可变,在固定 $P_f$ 时,检测器数量 $N_R$ 不再是固定的,II-NSA 算法的结束准则不再以 $N_R$ 达到预定目标为准,而是以 $P_f$ 达到预定目标为准,当估算的漏检率低于期望漏检率时,循环终止。
