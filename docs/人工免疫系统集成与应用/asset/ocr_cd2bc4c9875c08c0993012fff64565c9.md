# # 9.4 免疫 DEA 农用地分等实例研究

本章以广东省高要市农用地分等为例，研究基于 AIS-DEA 的农用地分等方法。

# ## 9.4.1 资料收集与评价因素确定

+   1. 资料收集

根据农用地分等规程，农用地自然质量分等主要需要以下资料。

+   (1) 水文：水源类型(地表水、地下水)、水量、保证率等；

+   (2) 土壤：土壤类型、有机质含量(耕层)、土壤质地(耕层)、有效土层厚度、土壤酸碱度、剖面构型、障碍层次、土壤侵蚀状况、土壤养分状况(耕层)、土壤污染状况、土壤保水供水状况、土壤中砾石含量等；

+   (3) 地形：地貌类型(山地、丘陵、平原等)、海拔、坡度、坡向、坡型、地形部位(如在坡的上部、中部、下部)；

+   (4) 气候：月平均气温、月日照百分率、月平均降水量、月平均水汽压、月平均风速、积温、无霜期、灾害气候等；

+   (5) 农田基本建设情况：灌溉条件(水源保证率、水源水质、灌溉保证率)、排水条件、田间道路条件、田块大小及平整度等。

+   (6) 图件资料：行政区划图、地形图、土壤图(系列)、土地利用现状图、土地利用规划图等。其中，土壤图系列主要包括土壤类型、土壤酸碱度、土壤有机质含量、土壤全氮、土壤全磷及土壤改良分区图。

+   2. 分等数据库的建立

农用地分等借助 GIS 技术来实现，其中，数据库的建立是非常重要的一个环节，对分等工作的顺利完成及分等成果的精度起着重要的作用。

+   1) 数据库的内容

农用地分等数据库的内容主要包括分等过程中所涉及的各种基础地理数据和专题数据，大体上可分为图形数据、表格文献数据及调查数据三大类型。图形数据主要是农用地分等过程中用到的各种基础图件、中间生成图件及成果图件。基础图件主要包括高要市行政区划图、交通图、水系图、地形图、土地利用现状图、土地利用规划图、土壤图、土壤酸碱度图、土壤有机质含量图、土壤养分分布图等。文献数据包括与图形数据相对应的属性数据，如代码、镇名、村名、道路水系名称、等高线高程、土地利用类型、土壤类型、有效土层厚度、土壤质地、土壤 pH、土壤有机
