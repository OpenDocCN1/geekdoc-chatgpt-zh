# 第 9 章 免疫聚类集成及其应用

# 9.1 引 言

聚类是一种无监督的模式识别方式，其任务是把一个未标记的模式按某种准则划分成若干子集，要求相似的样本尽量归为同一类，而不相似的样本在不同的类。按聚类准则的不同，聚类算法可分为两类：一类是基于模糊关系的聚类算法，包括谱系聚类、图论聚类；另一类是基于目标函数的聚类算法，如硬 C-均值聚类、模糊 C-均值聚类。后者把聚类问题归结为优化问题，从而成为当今研究的主流[169~177]。对于优化聚类目标函数的算法，一般都采用梯度法求解极值，由于梯度法的搜索方向总是沿着能量减少的方向，使得算法很容易陷入局部极小值。对初始化敏感是基于目标函数的聚类算法的又一严重缺点。免疫优化算法采用全局搜索和局部搜索相结合的方法，对初始状态不敏感，不容易陷入局部极小值，本章将免疫优化算法与 C-均值聚类算法集成，建立一个免疫-聚类模型。然后将免疫聚类模型与数据包络分析（data envelopment analysis, DEA）模型集成应用，建立 AIS-DEA 分类模型，并将其应用于农用地分等评价中。

# 9.2 免疫聚类模型构建

# 9.2.1 免疫聚类的基本原理

为了克服 C-均值聚类容易陷入局部极小值的缺点，人们提出了各种算法对目标函数进行优化。1989 年徐雷提出利用模拟退火法对硬分类矩阵 U 进行退火处理的硬 C-均值算法[173]，1993 年 Sultan 等提出利用模拟退火法对模糊分类矩阵 U 进行退火处理的模糊 C-均值算法[174]，1994 年 Babu 等提出利用进化策略对目标函数进行聚类的方法[175]，1995 年刘健庄等提出用遗传算法进行硬聚类和模糊聚类的分析方法[176]。由于进化算法固有的缺点，在进化过程中不可避免地产生了退化的可能，导致了进化后期的波动现象并且迭代次数过长和聚类准确率不高。

AIS 基于生物免疫系统的基本原理，是一种抽取和反映生物机体免疫系统特点的优化模型。与进化算法相比，AIS 具有如下特点[108,178,179]：①抗体的多样性通过细胞的分裂和分化作用，免疫系统可产生大量的抗体来抵御各种抗原的人侵，这种多样性的遗传机理可用于搜索优化，它对既提高 AIS 的全局搜索能力又不陷于
