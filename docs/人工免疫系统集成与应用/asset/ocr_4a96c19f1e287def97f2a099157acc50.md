1996 年,Abbattista 等开发了一个离散联想网络。这种机制用于定义 Hamming 形状空间中的点群。群中最佳点可作为吸引因子来表示网络记忆集。在离散 Hotfield 网络中,该算法由学习(存储)阶段和回忆阶段构成[13]。

1997 年,Dasgupta 首先研究了 AIS 与 ANN 模型。重点对它们的原理——生物神经与免疫系统进行比较分析。接着,de Castro 和 von Zuben 将他们的研究成果——人工免疫网络模型 (AiNet) 与 ANN 进行比较,重点分析了自组织神经网络[18]。

2001 年,de Castro 和 von Zuben 提出了一种基于免疫系统的模拟退火算法。它被应用到以误差反向传播算法训练的多层前馈神经网络的初始化问题中。作者认为,初始网络权重的质量与网络输出质量之间的相互关系可比作初始抗体群质量与免疫响应质量之间的关系。作者基于欧几里得形状空间思想来产生抗体多样性。他们提出一个能够产生初始权重向量集的算法,并使向量保持多样化以减小前馈神经网络收敛于局部最优解的可能性。AiNet 免疫网络模型被 de Castro 和 von Zuben 用于实现以无监督方法确定 RBF 神经网络中径向基核函数的位置及数量。该算法的主要目标是对无标记数值数据集进行筛选与聚类。作者使用欧几里得形状空间表达分子。一个抗体对应于一个 RBF 神经网络候选中心,一个抗原等价于一个输入模式[70]。

2002 年,de Castro 等基于克隆选择及免疫系统的亲和力成熟原理提出了一个布尔成长竞争网络。该算法的主要特征是竞争学习、具有成长与改良状态的网络体系结构的自动生成及 Hamming 形状空间中连接强度的二进制表达。权重更新步骤是一个受引导的变异搜索过程,模拟了抗体群的亲和力成熟过程,使得权重(抗体)成为待识别抗原更易结合的补体[228]。

孟江等针对神经网络集成中个体独立训练的低效性,提出了一种神经网络集成的免疫学习算法(NEIL)。通过对集成单体神经网络的免疫优化,借助免疫算法的多峰值搜索和并行优化特性,将最终的收敛抗体群分别对应于神经网络集成的各个单体,实现集成的同时训练过程[85]。
