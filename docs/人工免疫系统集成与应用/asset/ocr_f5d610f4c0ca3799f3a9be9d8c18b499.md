# 1. 在线比较法

在线(on-line)比较法中，用 AiNet 算法过程中的每一个抗体来了解进化趋势，其计算公式为

$$V^{\text{on-line}}(S) = \frac{1}{T} \sum_{t=1}^{T} v(t)$$ \quad (5-5)

式中，$T$ 为当前迭代过程中群体中出现的抗体总数，$v(t)$ 为第 $t$ 个抗体的目标值。当优化问题是最大化目标函数时，由于适应度函数取决于目标函数，随着一代代进化，适应能力强的抗体生存下来。从变化趋势而言，式(5-5)可能有所波动，但代与代之间总体上应保持上升趋势。式(5-5)评估了 AiNet 算法在采用免疫策略 $S$ 后的动态性能。

# 2. 离线比较法

离线(off-line)比较法的计算公式为

$$V^{\text{off-line}}(S) = \frac{1}{T} \sum_{t=1}^{T} v^*(t)$$ \quad (5-6)

式中，$T$ 为当前迭代过程中所出现的抗体进化代数；$v^*(t)$ 为第 $t$ 代前(包括第 $t$ 代)所有最优目标值。从保留最优抗体的角度出发，式(5-6)应该具有上升趋势。式(5-6)评估了 AiNet 算法的收敛性。式(5-6)的另一种理解方法是 $v^*(t)$ 为第 $t$ 代时所得的最优目标值，即

$$v^* = \max_{i \in \text{pop}(t)} \{v(i)\}$$ \quad (5-7)

式(5-7)可以用来比较 AiNet 算法中每一代抗体的改进情况。
