# 图 5-1 不同阈值 ts 下的网络结构

由图 5-1(a)～(f)可知，AiNet 算法的网络结构、抗体数目、聚类准确性等受抑制阈值 ts 的影响非常大。如果抑制阈值过小，不能有效剔除多余的信息数据，会增加分类复杂性，如图 5-1(a)、(b)所示，该阈值的限制作用失效，则网络数据压缩率非常小；如果抑制阈值过大，会丢失部分数据信息特征，致使分类结果不够完善，如图 5-1(e)、(f)所示，模型容易陷入几个适应值较大的值，降低群体的多样性。因此，抑制阈值 ts 是 AiNet 算法非常关键的参数。针对不同的问题，如何合理地调整抑制阈值的大小，以获得较优良的聚类结果，目前没有统一的理论依据，只能根据用户的经验或反复通过模型运算来确定。因此，AiNet 算法的最终聚类结果受人为主观因素影响较大。
