是操作过程却简单得多，具体过程为：由当前进化操作得到的最优个体推出一个指导量子抗体后，在它的周围随机散布量子抗体作为下一代量子种群，用公式描述为

```
\(Q_{guide}(t) = a \times p_{currentbest}(t) + (1 - a) \times (1 - p_{currentbest}(t)) \quad (4-6)\)
\(Q(t+1) = Q_{guide}(t) + b \times normal(0,1) \quad (4-7)\)
```

式中，\(p_{currentbest}(t)\)为进化到第 \(t\) 代为止得到的最优个体；\(Q_{guide}\)为指导量子抗体；\(a\) 为指导量子抗体的影响因子；\(b\) 为量子种群随机散布的方差。\(a\) 的值越小，量子种群受 \(Q_{guide}\) 的影响越大；当 \(a=0\) 时，\(Q_{guide}=P\)，观察 \(Q_{guide}\) 后将以概率 1 得到 \(P\)，当 \(a=1/2\) 时，\(Q_{guide}\) 对于观察不起任何作用。一般取 \(a \in [0.1, 0.5]\)，\(b \in [0.05, 0.15]\)。

# 2. 变异策略二
