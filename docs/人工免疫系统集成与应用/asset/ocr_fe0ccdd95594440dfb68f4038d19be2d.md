综上所述，为了有效地利用人脑对待求问题的先验知识，避免在完全随机的寻优算法中出现退化现象，本章提出在分层免疫算法中引入免疫疫苗。其思想主要是在合理提取免疫疫苗的基础上，通过接种疫苗和免疫选择两个操作步骤来完成。前者是为了提高个体的适应度，后者则是为了防止群体的退化。具体而言，它们分别是：

+   (1) 接种疫苗。设有个体 \(x_i \in \mathbf{R}^a, x_i = (x_i^1, x_i^2, \cdots, x_i^a)\)。给其接种疫苗是指按照先验知识修改 \(x\) 的某些分量，使所得个体以较大的概率具有更高的适应度。这些先验知识可以是最优抗体某些分量的大概取值范围，也可以是一些分量之间一定的制约关系。设有群体 \(X = (x^1, x^2, \cdots, x_N)\)，对 \(X\) 进行接种疫苗操作就是在 \(X\) 中按比例 \(a\) 随机抽取 \(N_a ::= aN\) 个个体而进行的一种操作。

+   (2) 免疫选择。免疫选择就是对已接种免疫疫苗的个体进行检测。如果已接种免疫疫苗个体的适应度不如其父代，则说明在变异的过程中已发生了严重的退化现象。此时可由其父代个体代替其参与竞争选择[231]。

+   4) 利用特征信息制作免疫疫苗

+   (1) 禁用节点疫苗。

为了利用用户积累的经验制作免疫疫苗以提高分层免疫算法的收敛速度，本章在利用该模型求解路由时设立了禁用节点。禁用节点是指两个交换局不允许用某些交换局做路由迂回节点。利用禁用节点制作的疫苗也称为禁用节点疫苗。目前禁用节点疫苗的来源主要有三种方式：① 最小中继数阈值；② 最大溢出率阈值；③ 用户经验。下面分别予以简单介绍。

+   ① 最小中继数阈值。

最小中继数阈值是指在电信网中，设定一个最小中继数阈值 minlines，只有中继数大于此阈值的链路才可以作为其他链路的迂回，此阈值的设定是为了保护中继容量小的链路，一般设 minlines=60。当链路 \((B, D)\) 或链路 \((D, C)\) 的中继数小于最小中继数时，\(D\) 被禁止用作链路 \((B, C)\) 的迂回节点。

```
记 FORBID=(Forbid_{BCD})_{n \times n \times n}, 其中

Forbid_{BCD} = \begin{cases} 1, & \text{如 } D \text{ 被禁止作为链路 } (B,C) \text{ 的迂回节点} \\ 0, & \text{其他} \end{cases} \quad (8-39)
```

则分层免疫算法对每一个 \(B, C, D (0 \leqslant B, C, D < n, B, C, D\) 互不相等) 作以下判断：

```
if (Lines_{BD} < minlines \text{ or } lines_{DC} < minlines) \text{ then } Forbid_{BCD} = 1 \quad (8-40)
```
