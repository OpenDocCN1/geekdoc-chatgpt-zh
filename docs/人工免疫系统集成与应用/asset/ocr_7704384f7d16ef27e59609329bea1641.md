集中。

+   (2) 求总记忆抗体相似度，进行网络抑制。

+   (3) 免疫网络抗体生成。

+   (4) 终止条件：抗体达到某一指定数目或者指定的迭代次数完成。

AiNet 算法的目的是建立一个记忆集合，用于识别和表示数据结构。细胞越特异，网络简化程度越低(低压缩率)，同时细胞越“通用”，网络越简化(改善压缩)。该模型存在如下优点：①能够极大地减少数据冗余，且生成的抗体集合能够反映数据集的结构特征；②在该模型中，计算亲和力时选择不同的距离标准（如用 Euclidean 距离或 Hamming 距离），就可以对不同性质的数据进行聚类（如数值属性或符号属性的数据）；③该模型在搜索解时本质上是并行的，收敛速度较快且模型实现相对简单。目前 AiNet 算法已广泛应用于数据压缩、数据聚类等领域[13,28,133~135]。

# 5.2.2 AiNet 算法的评估与讨论

在 AiNet 算法中有两种抑制：克隆抑制和网络抑制。前者是消除克隆的抗体内部的自识别细胞，而后者是寻找网络内不同克隆集的相似性。它们影响抗体数量、位置，抗体特异水平，聚类准确性和最终的网络结构。因此，抑制阈值的设置非常关键。为了评估抑制阈值对 AiNet 算法的影响，本章采用参考文献[33]中的实验数据对 AiNet 算法进行实验仿真。在其他参数保持不变的情况下（Nc = 10，n = 4，gen = 10，tp = 0.2，qi = 0.2，m = 0.4），在[0, 0.2]之间随机改变阈值 ts，并观察最终的网络结构图，如图 5-1(a)~(f)所示。
