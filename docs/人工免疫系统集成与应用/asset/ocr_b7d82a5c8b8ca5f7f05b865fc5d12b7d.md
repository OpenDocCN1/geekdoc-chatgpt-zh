# 第 2 章 人工免疫系统分析及其设计框架

# 2.1 引言

目前有大量的文献介绍 AIS,其中,Dasgupta 编写的《AIS 及其应用》是 AIS 领域的第一部著作[18]，覆盖了 AIS 计算和应用的不同方面,也是该领域许多领先的研究人员的论文集。国际上第二部研究 AIS 的著作由 de Castro 博士和 Timmis 博士合著[99],不同于 Dasgupta 的著作,这是世界上第一部结合自己和其他研究人员的研究成果,全面系统地阐述 AIS 原理与应用的著作。另外,还有大量文献介绍 AIS 的基本原理及其有关的模型和算法[59-61,100,101],但是对于 AIS 的层次架构、基本构成、主要过程及设计框架很少有文献论述。这些研究工作对利用 AIS 解决实际问题时,如何设计相应的 AIS 模型和算法是非常有益的。本章在对 AIS 的基本原理、表示模型、基本组件及相关的算法和模型进行分析的基础上,提出了 AIS 的设计框架。

# 2.2 免疫系统的基本组成

免疫系统是一个复杂的自适应系统,其主要作用是保护人体不受外部病原体侵害,并把体内所有的细胞或分子分成属于自己的种类和属于外部来源的非自体分子种类[22]。一般意义上讲,免疫系统主要由免疫活性分子、免疫细胞、免疫组织及器官组成,如图 2-1 所示[23]。而生物免疫学认为,免疫功能主要是由参与免疫反应的细胞和由其构成的器官来完成的。这种免疫细胞主要有两大类:一类为淋巴细胞。它们在抗原的激发下能进一步分化成为各种球蛋白的浆细胞或致敏淋巴细胞。这类细胞因为对抗原的反应有明显的专一性,所以是特异性免疫(specific immunity)反应的主要细胞。第二类细胞则具有摄取抗原、处理抗原并将处理后的抗原以某种方式提供给淋巴细胞的作用。这主要包括巨噬细胞、单核细胞和粒细胞等。这类细胞的重要特征是在参与各种非特异性免疫反应(nonspecific immunity)的同时,也能积极地参与特异性免疫反应。
