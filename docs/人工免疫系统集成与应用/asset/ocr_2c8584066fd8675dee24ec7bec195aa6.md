# 11.2.1 RFID 系统的技术特性

RFID 是 20 世纪 60 年代兴起的一项非接触式自动识别技术，它利用无线射频通过非接触双向通信实现目标识别。与条形码技术和 IC 卡技术相比，RFID 技术具有精度高、适应环境能力强、抗干扰性强、操作快捷等诸多优点，已经被广泛应用于零售、物流、仓储、生产制造、自动收费、动物识别、图书馆管理等领域[213]。

标签通常存储一个固定的对象标识，并且有简单的数据存储和处理能力，实际应用中标签一般附在待识别物体表面。按照获得能量的方式划分，标签分为无源标签和有源标签。有源标签自带电源，能主动发送射频信号，识别距离长，但是其成本高，寿命短，主要应用于贵重物品远距离检测等领域；无源标签从阅读器的射频波束中获取能量，不能主动发送射频信号，具有成本低、体积小、寿命长等优点，应用非常广泛。本章仅对无源标签展开研究（如果没有特别说明，下面所述标签均指无源标签）。工作过程中，阅读器通过天线发送一定频率的射频信号，标签进入阅读器的射频信号磁场后被唤醒，接收阅读器发出的射频信号，同时凭借感应电流产生的能量将标签存储信息或者操作信息发送给阅读器，从而实现标签与阅读器的双向通信。阅读器读取标签信息后，将其传送给后端应用系统进行业务处理。后端应用系统一般包括 RFID 中间件、数据库及应用软件，根据 EPCglobal 组织提出的物联网这一宏伟远景，未来的 RFID 系统将是一个构建于 Internet 网络之上的高度分布和共享的信息网络平台，将大大提升现代物流、供应链管理、零售业等领域的管理水平，降低管理成本[214]。
