# 2) 适应度函数

求解路由由表的目的是使得网络实际运行时的话务阻塞率最小，或每条链路的溢出率最低，或整个电信网的话务负载均衡程度最好。所以评价一个路由表或者个体的优劣最直观的方法是采用解析模型或话务模拟[159]，直接对每一个个体求出一个对应的全网阻塞率或完成话务量。但是无论采用解析还是模拟的方法，计算量都很大，而每一代的每一个个体都需要计算适应度函数，这种方法会使得模型的计算量太大，所以不可能采用。考虑到话务阻塞的原因是话务整体分布不均衡，本章确定用各链路的负载均衡程度来评价路由表的优劣，即负载越均衡，适应度越高。其具体方法是，计算电信网全局的平均每线话务量和每一条链路的每线话务量，然后求每线话务量的均方差，再适当定标作为个体的适应度。参考文献[159]，本章采用记号 Line = (LineBC)n×n，Traffic = (TrafficBC)n×n，Route = (RouteBC)n×n 分别表示交换机 B、C 之间的容量表、话务量表和路由表；并引入记号 R，OTRAFFIC，具体定义如下：

```
$$R = (r_{BCD})_{n \times n \times n}$$
```

式中

```
$$r_{BCD} = \begin{cases} 1, & \text{route}_{BC} = D \\ 0, & \text{其他} \end{cases}$$
```

OTraffic = (OTrafficBC)n×n 表示链路上的溢出话务量。溢出话务量等于到达话务量乘以链路上的溢出率，计算公式如下：

```
$$OTraffic_{BC} = \text{Erlang}(\text{Traffic}_{BC} + \text{Traffic}_{CB}, \text{Line}_{BC}) \times \text{Traffic}_{BC}$$
```

在式(8-34)中，由于链路是双向的，所以把两个方向的送入话务量相加作为整条链路的到达话务量，而链路中继数满足 LineBC = LineCB。

每条链路 (B,C) 的负载率 LoadBC 计算如下：

```
$$\text{Load}_{BC} = \frac{\text{Traffic}_{BC} - \text{OTraffic}_{BC} + \sum_{0 \leqslant B, C, D <slant n} r_{BDC} \times \text{OTraffic}_{BD}}{\text{Line}_{BC}} + \frac{\sum_{0 \leqslant B, C, D <slant n} r_{DCB} \times \text{OTraffic}_{DC}}{\text{Line}_{BC}}$$
```

式中，第一项为链路 (B,C) 的直达话务量；第二项为链路 (B,C) 的溢出话务量；第三项和第四项是其他链路溢出到链路 (B,C) 上的话务量。其中，第三项是 B 通过 C 迂回到其他节点的溢出话务；第四项是其他节点通过 B 迂回到 C 的溢出话务。而全网的平均负载率用以下公式计算：

```
$$\text{avgLoad} = \frac{\sum_{0 \leqslant B, C <slant n, B \neqslant C} (\text{Traffic}_{BC} - \text{OTraffic}_{BC} + \sum_{0 \leqslant B, C, D <slant n} R_{BDC} \times \text{OTraffic}_{BD})}{\sum_{0 \leqslant B, C <slant n, B \neqslant C} \text{Line}_{BC}}$$
```
