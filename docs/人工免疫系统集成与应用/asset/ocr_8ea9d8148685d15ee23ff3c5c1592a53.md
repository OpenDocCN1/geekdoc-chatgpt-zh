# 图 2-1 免疫系统的组织结构

免疫系统是一个多层的防御结构，第一层是物理屏障，由皮肤、黏膜组成，阻止多数病原体；第二层是生理屏障，由唾液、汗液、眼泪、胃酸及体温等组成，能杀死消化的食物和吸收的水分中含有的微生物及其他一些“入侵者”；第三层是固有免疫系统，由游荡的细胞(如吞噬细胞)组成；第四层是自适应免疫系统，由淋巴细胞组成，淋巴细胞能适应病原体结构，可有效地组成消灭它们[22]。

# 2.2.1 免疫细胞

免疫细胞由淋巴细胞、细胞因子、自然杀伤细胞、噬菌细胞、粒细胞和它们的相关物质组成。淋巴细胞是免疫系统中起主要作用的微小的白细胞，主要有两种类型：T 细胞和 B 细胞。B 细胞和 T 细胞在各自的表面表达抗原受体，识别特定抗原决定基高度特异的抗原，各自的抗原受体分别简称为 B 细胞受体(B cell receptor,BCR)和 T 细胞受体(T cell receptor,TCR)。B 细胞的主要功能是产生抗体、提呈抗原和分泌细胞因子并在 T 细胞的辅助下参与免疫调节。T 细胞的主要功能是调节其他细胞的活动或直接参与免疫反应。T 细胞按功能不同分为毒性(cytotoxic)T 细胞和调节 T 细胞。调节 T 细胞分为激活 B 细胞作用的辅助性 T 细胞和抑制 B 细胞作用的抑制性 T 细胞。成熟的 B 细胞产生于骨髓中，成熟的 T 细胞产生于胸腺中。B 细胞和 T 细胞成熟之后进行克隆增殖、分化并表达功能。两种淋巴细胞共同作用并相互影响和控制对方的功能，形成了机体内部高度规律的反馈型免疫网络[24]。

# 2.2.2 抗体
