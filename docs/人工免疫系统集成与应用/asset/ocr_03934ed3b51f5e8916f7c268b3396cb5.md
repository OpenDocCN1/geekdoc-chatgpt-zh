# 3. 免疫学习算法

Farmer 等对免疫系统的学习特性进行了探索性研究，指出其与 Holland 的分类器系统具有相似性[13]。随后 Hunt 等基于免疫网络理论给出了一种有监督的机器学习算法[32]。Ishida 提出了一种基于 PDP 模型的免疫学习算法[43]，并将其应用到故障诊断中。Timmis 等研究了基于人工免疫系统的无监督学习策略，建立了一个机器学习模型 RLAIS[17]，该模型通过构造网络从所学数据中发现复杂的相互关系。较之于神经网络，人工免疫系统在学习对象的表达方面有了很大的进步，而且网络规模可以控制。免疫学习算法在数据分析和知识发现等方面具有潜在应用价值[17]。

# 4. 混合免疫算法

Chun 等提出了一种免疫算法[28]，该算法吸收了 GA 的搜索策略，借用了 GA 的选择、交叉和变异算子，实质上是一种改进的遗传算法。王磊基于免疫系统的概念和理论提出了一种免疫规划算法[22]。该算法在遗传算法中加入免疫算子，防止群体退化，以提高算法的收敛速度。免疫算子包括接种疫苗和免疫选择两个部分，前者是为了提高适应度，后者是为了防止种群退化。混合免疫算法目前尚无统一框架，但已经在求解诸如组合优化等问题中显示了强大的优化搜索能力[21]。
