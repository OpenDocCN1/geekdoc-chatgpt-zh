# 11.3.6 RFID 入侵检测 Agent 分布式部署模型

部署模型将根据系统实际运行需求，确定系统运行中每个 Agent 类有几个 Agent 实例存在；然后确定系统的运行结构，从而对这些 Agent 实例进行组织管理；最后，确定这些 Agent 实例的物理分布，形成部署模型。

就应用而言，一个分布式的 RFID 系统一般由多个功能区域组成，如生产管理系统中，产品会按照生产流程分别处于生产车间、检测车间、存储库房等，每个区域都需要应用 RFID 进行信息维护。与应用相对应，信息收集器也必须是分布式的，一个功能区域需要一个或者多个信息收集器。对于入侵监视器而言，可以采用集中式监视和分散式监视两种模式。集中式监视即整个 RFID 入侵检测系统只部署一个入侵监视器，所有信息收集器收集的特征日志都发给一个入侵监视器来分析识别。分散式监视则部署多个人入侵监视器，分别监视一个或多个区域的标签操作。就设计而言，集中式监视可视为分散式监视的一个特例。对检测器中心而言，为了保证所有检测器在各入侵监视器中共享，并且考虑到检测器中心不需要承担实时处理任务，一般只部署一个检测器中心实例。根据以上 Agent 实例逻辑关系的描述，RFID 入侵检测各 Agent 的部署实例如图 11-9 所示。

Agent 的物理部署则需要根据 RFID 应用系统的规模和管理而定，信息收集器、入侵监视器和检测器中心可以任意组合部署在一台主机上。

上述运行结构与生物免疫系统的运行结构是基本一致的，作为中枢免疫组织的检测器中心集中生成检测器，而作为外周免疫器官的信息收集器和入侵监视器则分布在系统各区域，负责各自 RFID 区域免遭入侵。
