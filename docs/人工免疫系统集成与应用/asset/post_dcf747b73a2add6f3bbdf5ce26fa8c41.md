

防止这类现象的发生，就要增大优良个体的比例以减少坏个体的不良影响，即利用有用信息来指导进化。

变异操作分为三种，首先是对最优个体的角度旋转的变异，其次是交叉变异，再次是个体本身的变异。其中，旋转变异如式(4-3)、式(4-26)所示，交叉变异采取单点交叉变异或全交叉变异[126]，单点交叉变异或全交叉变异在交换相应的二进制位字符串(P(t))的过程中同时交换两个个体的相应位的观测器 Q(t)。对于个体本身变异，本节采取文献[130]中的方法。设某一量子比特当前的幅角为 t_{ij}，则变异后的幅角为 \pi/2 - t_{ij}，即交换 \alpha_i 和 \beta_i。假设个体在种群中的排名为 m，种群个数为 n，决策空间为 l 维，则变异概率 p_m 为 l^{-(n+1)/(n+m)}，这样保证每个基因位的变异概率在 [1/l, \sqrt{1/l}] 中变化，而且亲和力靠前的个体变异度小。

## 4.3.7 实验仿真

### 1. 多目标 0/1 背包问题

本节以多目标 0/1 背包问题为例，对 CMQEA 的有效性进行验证。

多目标 0/1 背包问题是一个典型的组合优化问题，属于 NP 完全问题，可描述如下：对一给定权值的集合 w_{i,j} (第 j 个物品在第 i 个背包的质量)，利润集合 p_{i,j} (第 j 个物品在第 i 个背包的利润) 及 k 个背包的容量 c_i，求一个二进制向量 x = (x_1, x_2, \cdots, x_n) \in (0,1)^n，使

```
s.t. Max(f(x)= (f_1(x), f_2(x), \cdots, f_n(x)))
```

```
\sum_{j=1}^n w_{i,j} \cdot x_j \leqslant c_i, 1 \leqslant i \leqslant k
```

```
f_i(x) = \sum_{j=1}^n p_{i,j} \cdot x_j
```

对于背包问题，有一个基本的先验知识，就是人们在装包时总是先选择利润权值比大的物件装入；如果背包过载，则总是先选择利润权值比小的物件从背包中拿出来。这个特征是背包问题本身的一种属性，也是在解决问题时可以利用的一种特征信息和知识，因此在这里作为从问题中提取疫苗的一种途径。利用免疫的相关知识，本节中抗体指候选解，即 PF_{known}；抗原指问题的优化目标及其约束条件，即式(4-28)；抗体-抗原的亲和度指候选解所对应的目标函数值，即 PF_{known} 与 PF_{true} 的差别，亲和度越大则两者差距越小。

### 2. 性能指标和初始参数

对于多目标优化问题，对于不同算法所得解集的比较通常要考虑收敛性和多样性两个方面：首先，最小化优化算法发现的非支配最优解与实际非支配最优解的距离；其次，最大化分散解从而可以让解集空间向量尽可能一致和光滑。因此，为了

评价多目标优化问题非支配解的性能需要以下两个独立的公式：收敛公式[128]（GD）和差异多样性公式（Δ）[122]。因为收敛公式和差异多样性公式依赖于目标值的刻度，所以需要先将未归一化目标函数值进行归一化处理。

## 4.4 本章 小结

本章基于量子理论中的量子比特的概念，将量子比特编码抗体引入到免疫算法中，提出一种将量子理论与免疫理论相结合的 QIA 框架，构造了量子免疫算子和量子变异，其中，量子变异实施于量子抗体，用于加快算法的收敛，量子变异实施于普通抗体，用于克服算法的早熟；并对 QIA 的收敛性进行了理论分析，证明了其全局收敛性，同时将 QIA 与 GA、IA 用于多模态函数优化问题进行性能比较。仿真比较及应用论证了该模型算法的有效性，证明此算法收敛速度快，种群多样性好，能有效克服早熟现象。

针对经典量子进化算法在求解多目标优化问题方面存在的不足，本章采用多目标优化亲和度排序策略和分级变异策略对算法进行改进，提出了一种新的多目标进化算法——CMQEA。该算法在种群内部变异和种群进化过程中，能有机地结合局部-全局搜索，同时保持种群的多样性。仿真实验的结果表明，新算法在目标向量维数为二维的 Knapsack 测试集上能取得较好的效果，是一种有效并且稳定的算法。如何更好地将算法用于其他一些 MOP，包括更高维的 MOP，以及如何更好、更全面地评价一种 MOP 算法，将是未来进一步要做的工作。

## 第 5 章 矢量距免疫网络聚类算法

## 5.1 引言

de Castro 等提出的 AiNet[33]是最具影响力的人工免疫网络模型，主要用于压缩和聚类，具有减少数据冗余、描述数据结构、包含聚类形状等特征。AiNet 主要采用克隆抑制和网络抑制来保证群体的多样性，从而使抑制阈值极大地影响 AiNet 算法的最终网络结构和大小。为了降低抑制阈值对 AiNet 算法的影响，本章提出矢量距免疫网络算法(vector distance artificial immune net，VD-AiNet)，矢量距将抗原、抗体分别对应于聚类问题的目标函数和优化解，在 AiNet 算法中采用矢量距来评估抗体浓度，并建立抗体促进和抑制机制，以便在鼓励适应度高的抗体的同时，限制浓度较高的抗体，增强群体的多样性，并减少参数特别是抑制阈值对 AiNet 的影响，从而降低 AiNet 的计算成本，加快模型的收敛速度，减少人为主观因素的影响。

## 5.2 AiNet 算法及其存在的问题

### 5.2.1 AiNet 算法简介

AiNet 算法忽略 B 细胞与抗体的区别，利用统计推论技术实现。AiNet 算法的基本原理是模拟生物免疫系统中抗体克隆和选择过程，将数据集作为抗原集合，生成的抗体集合则作为聚类结果。其算法简单描述如下[33]。

- 对每一个抗原：
  - 计算随机产生的抗体亲和力，选出 n 个高亲和力抗体。
  - n 个高亲和力抗体根据亲和力产生克隆抗体集 D，对于每一个抗体，其亲和力越高，克隆数越多。
  - 对 D 直接进行亲和力成熟处理得到 D*，即 D 中每个抗体根据式(5-1)进行变异，亲和力越高，变异率越小 C = C - a(C - X) (5-1)
  - 求出抗原和 D* 中每一抗体的亲和力。
  - 从 D* 中选出一定比例具有高亲和力的抗体，放入克隆记忆集中。
  - 求出记忆集中抗体的相似度进行克隆抑制。
  - 将记忆集中的抗体存入总的记忆抗体集中。

- 求总记忆抗体相似度，进行网络抑制。
- 免疫网络抗体生成。
- 终止条件：抗体达到某一指定数目或者指定的迭代次数完成。

AiNet 算法的目的是建立一个记忆集合，用于识别和表示数据结构。细胞越特异，网络简化程度越低(低压缩率)，同时细胞越“通用”，网络越简化(改善压缩)。该模型存在如下优点：①能够极大地减少数据冗余，且生成的抗体集合能够反映数据集的结构特征；②在该模型中，计算亲和力时选择不同的距离标准（如用 Euclidean 距离或 Hamming 距离），就可以对不同性质的数据进行聚类（如数值属性或符号属性的数据）；③该模型在搜索解时本质上是并行的，收敛速度较快且模型实现相对简单。目前 AiNet 算法已广泛应用于数据压缩、数据聚类等领域[13,28,133~135]。

### 5.2.2 AiNet 算法的评估与讨论

在 AiNet 算法中有两种抑制：克隆抑制和网络抑制。前者是消除克隆的抗体内部的自识别细胞，而后者是寻找网络内不同克隆集的相似性。它们影响抗体数量、位置，抗体特异水平，聚类准确性和最终的网络结构。因此，抑制阈值的设置非常关键。为了评估抑制阈值对 AiNet 算法的影响，本章采用参考文献[33]中的实验数据对 AiNet 算法进行实验仿真。在其他参数保持不变的情况下（Nc = 10，n = 4，gen = 10，tp = 0.2，qi = 0.2，m = 0.4），在[0, 0.2]之间随机改变阈值 ts，并观察最终的网络结构图，如图 5-1(a)~(f)所示。

## 5.3 矢量距 AiNet

### 5.3.1 改进方法

从 AiNet 算法的算法流程可以看出，AiNet 算法主要采用克隆抑制和网络抑制来保证群体的多样性，从而使抑制阈值极大地影响 AiNet 算法的最终网络结构和大小。为了降低抑制阈值对 AiNet 算法的影响，本章在 AiNet 算法中采用一种新的抗体促进和抑制机制，以便在鼓励适应度高的抗体的同时，限制浓度较高的抗体，增强群体的多样性，并减少参数特别是抑制阈值对 AiNet 算法的影响，从而使 AiNet 算法达到降低计算成本，加快模型的收敛速度，减少人为主观因素影响的效果。

抗体促进和抑制机制的关键是确定抗体的浓度，目前计算抗体的浓度有许多种方式。例如，采用 Euclidean 距离、Manhattan 距离、Hamming 距离等评价抗体的相似性，进而计算抗体的浓度，但这些方式受抗原、抗体的编码机制影响。例如，在二进制形态空间中，存在 Hamming 悬崖。采用 Hamming 距离等进行抗体浓度的评价就有一定缺陷。也有研究提出采用信息熵计算抗体的浓度，但这种方式同样也受编码机制的影响，同时，信息熵的计算复杂，设置的参数需要凭经验调节和含有冗余的计算信息，从而导致算法收敛速度慢[107]。通过对生物免疫系统特征的进一步挖掘，本章提出采用矢量距来评价抗体的浓度。

矢量距就是将抗原、抗体分别对应于聚类问题的目标函数和优化解 \( C_i \)，抗体的适应度函数为 \( f(C_i) \)。\( N \) 个抗体构成了一个非空免疫系统集合 \( X \)。规定抗体 \( C_i \) 在集合 \( X \) 上的距离为

\( S(C_i) = \sum_{j=1}^{N} | f(C_i) - f(C_j) | \quad (5-2) \)

式(5-2)也是抗体的矢量距定义式。则由矢量距的定义，抗体的浓度可用式(5-3)表示

\(\text{Density}(C_i) = \frac{1}{S(C_i)} = \frac{1}{\sum_{j=1}^{N} | f(C_i) - f(C_j) |} \quad (5-3) \)

计算出每个抗体的浓度之后，便可以通过选择机制进行抗体的促进和抑制调节。抗体 \( C_i \) 的选择概率 \( p_i \) 由适应度概率 \( p(f(C_i)) \) 和浓度抑制概率 \( p(d(C_i)) \) 两部分组成。

\( p_i = a p(f(C_i)) + (1-a) p(d(C_i)) \)
\( = a \times \text{fitness}(C_i) \big/ \sum_{i=1}^{N} \text{fitness}(C_i) + (1-a) \frac{1}{N} e^{-\frac{\text{Density}(C_i)}{\beta}} \quad (5-4) \)
