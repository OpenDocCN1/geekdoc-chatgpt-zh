# 第 11 章 基于免疫协同的 RFID 入侵检测系统

# 11.1 引言

本章将以 RFID 入侵检测为研究对象，综合集成 Agent 技术、生物免疫机理、人工免疫网络算法和阴性选择算法，提供一个免疫集成的综合应用实例。无线射频识别(radio frequency identification，RFID)系统因为标签存储计算能力的脆弱性、无线信道的开放性、应用的分布性等技术特点，面临着比一般计算机网络更加广泛而复杂的安全风险。安全隐患已经成为制约 RFID 技术推广应用的主要不利因素之一[210]。目前 RFID 系统的安全研究主要集中在加密认证和物理方法上，加密认证因为廉价标签有限的存储计算能力而难以实施；物理方法则需要额外器件，并主要针对保护隐私的场合，适用性不强。入侵检测是继加密认证、防火墙、病毒防护等安全防护之后的新一代安全保障技术，在计算机网络安全领域已经进入实用阶段，并表现出与其他技术互补防护、发现入侵前兆、检测未知攻击等优良特性[211]。RFID 系统作为构建于计算机网络之上的信息系统，同样能够利用入侵检测方法提高其安全防护能力，并且入侵检测方法通过分析 RFID 系统中的操作与审计日志发现入侵现象，不要求修改 RFID 现有的技术标准，能够在保持 RFID 标签低廉成本的基础上，提升 RFID 系统的安全防护能力。生物免疫系统与入侵检测系统的相似性及其经历亿万年进化所形成的自学习、自适应、分布式处理等能力，使基于免疫机理的人侵检测研究已成为当今热门研究方向之一[55,212]。RFID 系统作为一类高度分布和开放的信息系统，生物免疫机理对于构建其安全防御体系有着非常重要的借鉴意义。

本章将通过分析 RFID 系统中标签与阅读器之间的会话日志，提取出 RFID 系统的应用特征和攻击特征，参考免疫协同机理、免疫融合阴性选择算法（II-NSA）和目标进化免疫网络算法（OE-AiNet），基于 RFID 系统的应用特征和攻击特征开展人侵检测研究，提出一个免疫协同的 RFID 人侵检测方法。该方法不仅能发现阅读器窃取、口令猜测、拒绝服务等已知的 RFID 主动攻击，而且能识别出未知攻击，具备良好的自学习和自适应能力。
