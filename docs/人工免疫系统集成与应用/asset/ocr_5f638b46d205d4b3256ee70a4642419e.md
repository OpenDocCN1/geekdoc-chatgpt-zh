# 8.5.3 分层免疫动态路由评估模型设计

# 1. 动态路由问题的形式化描述

构建基于分层免疫算法的动态路由评估模型,首先需要给出电信网的网络结构和动态路由问题的形式化描述。电信网络由 n 个交换机组成,每对交换机之间是由若干条中继(trunk,也可以称为电路)组成的直达链路。交换机与链路构成电信网络 TELNET。交换机 B 到 C 的中继数量用 LineBC 表示。每一个交换机有一定的容量,交换机 B 的容量用 CapB 表示[159],如图 8-6 所示。

```
TELNET = (CAP,LINE) (8-27)
CAP = (CapB)n (8-28)
LINE = (LineBC)n x n (8-29)
```

式中,因此电信长话网链路都是双向链路,所以 LineBC = LineCB。

**定义 8-3(话务量)** 单位时间内,每对交换机之间通过的话务流量强度(telephone traffic)称为话务量。单位为爱尔兰(Erlang)。话务量可以用一个矩阵表示如下：

```
Traffic = (TrafficBC)n x n (8-30)
```

从图 8-5 可知,动态路由控制系统建立在电信网管系统平台上,从电信网管系统获取话务数据,系统的话务数据是完成话务量,而本章的路由评估计算使用的是到达话务量,我们使用以下的经验公式计算到达话务量(计算中使用的电路数、试呼次数、占用次数、应答次数、每线话务量也是从网管系统获取的统计量)。

```
到达话务量 = 完成话务量 + K × (试呼次数 − 占用次数) × T (8-31)
```

式中, T 为损失呼叫平均占用时间,取值为 18s,即 T=0.005h; K 是与应答试呼比有关的系数,取值范围如表 8-3 所示。
