定义 8-4 (迂回路由) 直达路由溢出的话务所使用的转接路由称为迂回路由。例如，从交换机 B 到 C 的话务，如果超过 B,C 间直达链路能承受的话务量，就会产生话务溢出，此时为溢出话务所选择的路由就称为迂回路由。迂回路由有一级迂回路由、二级迂回路由等。在本章的模型中，需要选择的路由共有 n(n-1) 个，可以用路由矩阵表示如下（其中，RouteBC 没有意义，可设为一）：

ROUTE = (RouteBC)n×n (8-32)

对固定选路策略来说，迂回路由是固定的，即 ROUTE 矩阵是个常量。动态路由问题要解决的是根据当前的电信网拓扑结构和话务量，确定下一周期内每两个交换机之间的迂回路由，以使得网络的总的话务阻塞率(totalblock)最小。

求：ROUTE
使得：TOTALBLOCK 最小。

当然也可以设定其他优化的目标。例如，文献[168]中提出的动态路由算法以每条链路的溢出率都低于一个最小值为其优化目标。

假设电信网络中一共有 n 个交换机，由于交换机到本身不需要动态路由，故路由矩阵的大小为 n × (n-1)。在单级路由的情况下，交换机 B,C 之间可以从除了 B,C 外的所有 n-2 个交换机中选取一个作为迂回路由，所以动态路由问题的状态空间大小达到 (n-2)n×(n-1)。由于问题的规模很大，不可能进行全局搜索求出最优解，一般只要求出近似最优解即可。
