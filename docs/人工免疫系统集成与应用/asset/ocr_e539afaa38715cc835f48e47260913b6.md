率。为了保证链路的服务质量，长途网对链路直达话务量的溢出率有一个上限。目前设 maxoverflowrate=0.05。当链路（B，D）或链路（D，C）的溢出率大于最大溢出率时，D 被禁止用作链路（B，C）的迂回节点。模型对每一个 B,C,D(0 ≤ B,C,D < n,B,C,D 互不相等)作以下判断：

```
if (Block_BD > maxblockrate or Block_DC > maxblockrate)
then Forbid_BCD = 1           (8-41)
```

+   ③ 用户经验。

除了利用最小中继数阈值、最大溢出率阈值作为禁用节点疫苗以外，还可利用电信员工在日常网络管理、维护中积累的经验设计禁用节点疫苗。例如，省际或国际长途中转局一般不用来作为其他链路的迂回。

为了解决怎样在分层免疫算法中引入禁用节点疫苗的问题，本章在路由求解过程中创建禁用表。禁用表是一个矩阵，记录了每两个交换局之间不可以用作迂回节点的交换局的数目和不可用的迂回交换局的编码。在初始群体生成和变异操作需要随机产生一个 i,j 之间的迂回节点时，随机生成一个属于 [1,n] 的整数，然后与禁用表中的编码进行比较，如果相同，则再次生成，直至不同为止。这样随机生成的迂回节点必然满足禁用节点经验的要求。禁用表的引入也减小了搜索空间。假设在具有 43 个交换机的网络中，每两个交换机间平均有 10 个禁用节点，则可用的节点最多只有 31 个，故搜索空间减小为 31^42×43 = 31^1806 ≈ 10^2693。

# （2）话务变化规律疫苗。

通过对广东省固定电信网网络运行情况的分析，我们发现话务变化具有一定的规律性。①在话务的峰值日，由于话务严重过负荷，造成到某些方向的话务溢出量剧增，严重地影响了网络接通率，并降低了网络运行的稳定性。②在本地网内可预计的海量呼叫，如已知的热线、电视台节目，由于用户大量拨打这些热线电话，导致话务拥塞，加重了交换系统的负荷，也造成了交换和传输资源的浪费。③对某运营商各本地网话务调查的结果表明，话务高峰时段分别是平时高峰时段、除夕高峰时段和其他节假日（包括周末、中秋、国庆等）高峰时段。通过利用话务变化规律，设定相应的路由表，生成话务变化规律疫苗，并将其引入到分层免疫算法中抗体的变异操作中，可以提高算法收敛速度和解的质量。
