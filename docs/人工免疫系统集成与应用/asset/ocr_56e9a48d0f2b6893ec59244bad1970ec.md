# 3. 协同检测器（H 检测器）

H 检测器针对信息收集器提呈的危险信号（即 FeatureLog 记录），确认是否有人侵发生并且已经对 RFID 系统性能造成了有害的影响，人侵检测一般通过对危险元素设置危险阈值来确认是否发生有害攻击。但是，由于危险元素的多样化及危险元素之间的相互关联，一般很难设置出科学的危险阈值，本章通过提取特征点的方式来定义 H 检测器，并通过聚类分析自动提取特征点。

根据危险元素的定义和检测的需要，定义 H 检测器如式(11-18)所示。

DH = <FeaturePoint, Lc, Type> (11-18)

式中，FeaturePoint 表示特征点，是实数编码的数据记录，可视为抗体的另一种表现形式；Lc 指匹配阈值；Type 表示抗原类型，即输出的检测结果。

FeatureLog 与 FeaturePoint 的距离采用 Euler 距离表示，如两个点 fl 和 fp，其距离 l 用式(11-19)表示。

\( l = \sqrt{\sum_{i=0}^{n} (fp_i - fl_i)^2} \) (11-19)

式中，n 表示 fl 和 fp 中的数据维数；fp_i 和 fl_i 分别表示第 i 维数据。

定义 11-5 H 检测器匹配。对于 FeatureLog 记录 fl 与 H 检测器 dh,dh 的 FeaturePoint 和匹配阈值分别为 fp 和 lc，若 \( l = \sqrt{\sum_{i=0}^{n} (fp_i - fl_i)^2} < lc \)，则 fl 与 dh 匹配，用谓词 HMATCH(fl,dh) 表示。

如果 fl 被 dh 匹配，则认为 fl 的抗原类型为相应的 dh. Type，其中 dh. Type 有可能是自体类型（Type. flag=1），也有可能是非自体类型（Type. flag=0），当匹配非自体类型检测器时，确认 L 检测器的检测结果并发出协同信号，否则抑制 L 检测器的检测结果。但是，如果 fl 不被 H 检测器库中的任何 H 检测器匹配，则认为 fl 是未知类型，用谓词 UNKONWN(fl) 表示，fl 为未知类型时，需要进一步的协同刺激才能确认其是否为危险信号，而进一步协同刺激则是人工确认，因此，未知类型的特征日志也是需要关注的。

随着业务的变更，各类抗原类型的特征日志分布也将缓慢变化，所以 H 检测器的动态更新是必要的，否则系统的检测性能会逐步恶化。
