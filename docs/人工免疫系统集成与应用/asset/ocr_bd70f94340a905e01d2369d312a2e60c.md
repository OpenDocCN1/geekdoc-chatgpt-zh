# 8.6.2 话务高峰五点子网

# 1. 测试数据

每逢“六合彩”开奖时，潮阳 TS1 局至深圳方向呼叫数增大，溢出较大，接通率下降。因此，本章将潮阳(TS1 局)、深圳(TS1、TS2 局)、梅州(TS1、TS2 局)、湛江(TS1、TS2 层)、茂名(TS1、TS2 局)组建成一个五点子网进行测试。在“六合彩”开奖时，将此时的话务数据(附表 1~附表 5)输入到基于分层免疫算法的路由评估模型中，得到相应的路由方案，根据最优路由方案，在潮阳 TS1 局采用临时迂回路由控制将部分至深圳方向的话务通过梅州、湛江、茂名临时迂回畅通；同时对至梅州、湛江、茂名的电路群加上中继预留功能，以保护电路群原有话务。其具体为：在潮阳 TS1 局将部分至深圳方向的溢出话务分别迂回至潮阳 TS1 局—梅州 TS1 局、潮阳 TS1 局—梅州 TS2 局、潮阳 TS1 局—湛江 TS1 局、潮阳 TS1 局—湛江 TS2 局、潮阳 TS1 局—茂名 TS1 局、潮阳 TS1 局—茂名 TS2 局的电路群上，同时在这些电路群上进行中继预留控制，保护原有的潮阳至梅州、湛江、茂名的直达话务。

(1) 利用基于分层免疫算法的路由评估模型进行动态路由控制前，潮阳至梅州、湛江和茂名，以及梅州、湛江和茂名至深圳的话务均较空闲，而且梅州、湛江、茂名至深圳的电路较充足(附表 1~附表 5)。潮阳 TS1 局至深圳方向的路由组织如下。

+   ① 第一路由：直达走深圳 TS2，迂回走深圳 TS3。
+   ② 第二路由：直达走深圳 TS3，迂回走深圳 TS2。
+   ③ 第三路由：45%话务走广州 TSH1，55%话务走广州 TSL3。

第一、二路由采用负荷分担方式，其中，85%的话务走第一路由，15%的话务走第二路由。第一、二路由所溢出的话务走第三路由。

+   ① 第一路由：75%话务走深圳 TS2，25%话务走深圳 TS3。
+   ② 第二路由：45%话务走广州 TSH1，55%话务走广州 TSL3。
