# 6. 2.3 学习过程中的疫苗注射

步骤 2.6 在步骤 2.5 的网络评价基础上抽取疫苗，网络评价过程中计算了记忆网络 M 中每个抗体识别的抗原子集。根据目标 min(El(X, M))，设抗体 \(a_k \in M\)，\(a_k\) 识别的抗原子集为 \(X_k = \{x_1, x_2, \cdots, x_j\}\)，\(a_k\) 对 \(X_k\) 的识别距离和记为 El(\(X_k, a_k\))，则

\(\text{El}(X_k, a_k) = \sum_{i=1}^{j} \text{DI}(x_i, a_k)\) (6-5)

假设能找到新抗体 \(a_{k}'\)，使式(6-6)成立

\(\text{El}(X_k, a_{k}') < \text{El}(X_k, a_k)\) (6-6)

则认为在局部识别范围内，\(a_{k}'\) 优于 \(a_k\)，如果对每个抗体作类似调整，产生新的记忆网络 \(M'\)，则不等式组(6-7)必然成立

\begin{cases} \text{pi}(X, M') \geqslant \text{pi}(X, M) \\ \text{El}(X, M') < \text{El}(X, M) \\ \text{pr}(X, M') \geqslant \text{pr}(X, M) \end{cases} (6-7)

按照式(6-7)的目标评价，在不考虑免疫网络压缩约束的前提下，\(M'\) 优于 \(M\)，因此可将 \(M'\) 作为疫苗注射到抗体网络 A。

将 \(X_k = \{x_1, x_2, \cdots, x_j\}\) 的各抗原 \(x\) 视为在多维空间中多边形 S 的顶点，则对 \(X_k\) 而言最优抗体 \(a'\) 就是使 \(\text{El}(X_k, a')\) 最小化的抗体。在数学意义上，\(a'\) 就是多边形 S 的费马点[138]。但是多边形费马点求解问题本身是高维非线性复杂问题，不能提取为疫苗。本章从抗原特征的角度出发，取最能反映集合 \(X_k\) 数据特征的顶点坐标均值点作为新抗体 \(a_{k}'\)，即

\(a_{k}' = \overline{X}\) (6-8)

步骤 2.6 对 \(M\) 中的每个抗体进行疫苗提取，形成疫苗网络 \(M'\)；步骤 2.8 中增加了疫苗注射部分，将 \(M'\) 合并到抗体网络 A。
