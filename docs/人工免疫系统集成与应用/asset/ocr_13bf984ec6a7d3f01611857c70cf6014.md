# 8.6 分层免疫动态路由评估模型应用实例

“网络话务控制关键技术研究及应用”项目中的基于分层免疫算法的动态路由评估模型是广东省省内长话网路由的辅助决策工具。由于模型涉及整个广东省的长话路由，在系统真正投入使用之前，必须经过测试。而作为电信网全网的路由决策系统，它一旦出现错误会影响到整个电信网的话务质量，所以测试不适宜在全网展开。本章首先选择几个交换局组成一个子网进行测试，这个子网被视为一个独立的网络，与省网内的其他交换局完全不发生联系。测试前通过网管系统采集测试数据，测试完之后，将数据删除，以免影响网络业务运行。本章利用三组数据进行测试，第一组和第二组数据主要对基于分层免疫算法的路由评估模型进行测试，第三组数据对基于分层免疫算法的路由评估模型与其他优化算法进行测试比较。
