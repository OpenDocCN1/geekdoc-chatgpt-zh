# 3. “黑洞”问题

D’haeseleer 的分析[141]表明，采用 \(r\) 位连续匹配规则的检测器，并不能完全覆盖非自体空间，如果自体集 \(S\) 包含两个有连续 \(r-1\) 位相同的字符串 \(s_1\) 和 \(s_2\)，则存在两个“黑洞”字符串 \(h_1\) 和 \(h_2\)，任何匹配 \(h_1\) 和 \(h_2\) 的候选检测器必然也匹配 \(s_1\) 和 \(s_2\)，如下所示：

```
s_1 : a_1 \cdots a_k b_{k+1} \cdots b_{k+r-1} c_{k+r} \cdots c_l
s_2 : a'_1 \cdots a'_k b_{k+1} \cdots b_{k+r-1} c'_{k+r} \cdots c'_l
      \Downarrow
h_1 : a_1 \cdots a_k b_{k+1} \cdots b_{k+r-1} c'_{k+r} \cdots c'_l
h_2 : a'_1 \cdots a'_k b_{k+1} \cdots b_{k+r-1} c_{k+r} \cdots c_l
```

同样的方法表明，采用海明 Hamming 距离匹配规则的检测器也存在“黑洞”，“黑洞”的存在将会降低系统检测率。

# 4. 匹配阈值的确定

从检测性能和检测效率方面考虑，检测器生成的目标是要以尽量小的检测器库覆盖尽量大的非自体空间，也就是检测数量 \(N_R\) 和 \(P_f\) 尽量小。而这两者都与匹配阈值 \(r\) 有关，并且两个目标是相互矛盾的。

首先来看 \(N_R\)，其与 \(P_M\) 和 \(P_f\) 的关系如式 (7-3) 所示。

```
N_R = \frac{\ln P_f}{\ln(1 - P_M)} \qquad (7-3)
```

假设固定 \(P_f\) 不变，则 \(N_R\) 随着 \(P_M\) 的增加而增加，根据式 (7-2)，\(P_M\) 随着 \(r\) 的增加呈指数递减，因此，\(N_R\) 将随着 \(r\) 的减小而显著增加。

对于 \(P_f\) 而言，主要与“黑洞”的数量 \(N_H\) 有关，\(N_H\) 越大，\(P_f\) 越大。根据 D’haeseleer 的分析[141]，“黑洞”与自体的分布和匹配阈值 \(r\) 有关，如果 \(r\) 越大，自体集中两个字符串有 \(r-1\) 位相同的概率就越小，存在“黑洞”的可能性也越小，当 \(r=l\) 时，“黑洞”消失。

因此，\(r\) 的选择是很困难的，\(r\) 太小将导致 \(N_R\) 增加，检测效率降低；\(r\) 太大，“黑洞”数量增大，\(P_f\) 上升，检测性能下降，特别是在自体分布情况不明了的情况下，很难确定 \(r\) 为多少才能使“黑洞”数量降至一个可接受的水平。事实上，选择不恰当的 \(r\) 根本无法产生出符合期望漏检率 \(P_f\) 的检测器库。
