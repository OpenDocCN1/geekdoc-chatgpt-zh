# 2. 模式识别

免疫系统强大的识别能力在模式识别方面得到了广泛的应用。Forrest 等首先对免疫系统的群体多样性产生机制进行了深入研究，获得了抗体与抗原模式匹配的较深认识，进而产生了群体多样性评价方案并与遗传算法结合获得免疫遗传算法[66,67]。之后，也有学者对免疫系统的多样性机制进行了研究[68]。例如，Gaspar 等分析了免疫系统的再次应答对抗原处理的重要程度，提出模式跟踪算法，其作用在于动态清除连续不断出现的抗原，可用于计算机网络病毒检测[67]。Hunt 及 Cooke 在免疫网络模型应用于模式识别中的 DNA 识别方面做了开拓性工作，获得了应用于工程问题的 B 细胞免疫网络算法[31,69]。之后，de Castro 及 von Zuben 从独特型免疫网络理论出发，建立了一种形态空间免疫网络算法，解决字符识别问题[45,46]。接着，Dasgupta 研究了光谱识别问题，采用二进制对光谱识别的对象进行了具体描述，同时还给出了相应的匹配函数及识别算法[18]。

# 3. 智能优化

AIS 在函数优化、组合优化、调度问题等智能优化方面得到应用，并取得了很好的效果[51,70~73]。随着组合优化问题规模的扩大，其问题空间呈现组合爆炸特性，难以用常规优化方法求解。基于免疫原理实现的免疫算法在组合优化求解中显示出了强大的能力，这些问题包括二次分配问题(QAP)[73]、装箱问题[72]等。例如，Carlos 等分别将克隆选择算法及免疫遗传算法加以扩充[74,75]，获得针对车间调度的优化算法，这两种算法的主要特点在于抗体形成功能、记忆细胞功能、抗体及抗原评价策略的设计。在大多数情况下，免疫算法取得了比现有启发式算法更好的求解结果，尤其在求解的效率方面，显示出 AIS 在智能优化领域具有广阔的应用前景。另外，基于免疫学原理开发的处理多目标优化的智能方法也相继出现[71,76~79]。Carlos 等从克隆选择原理出发提出一种多目标免疫系统算法[71,76]，该
