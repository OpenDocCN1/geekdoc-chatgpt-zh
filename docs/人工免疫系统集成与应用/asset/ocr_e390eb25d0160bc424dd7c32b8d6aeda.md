可以通过三种途径获取，即人工编码、业务日志库和检测日志库。第一种方式，人工编码即根据安全需要将业务规则通过人工编码生成自体集，这种方式工作量较大，并且很难编码出完整的自体集，适合于没有数据基础的系统。第二种方式是选择一个没有遭受过入侵，并且包含了各种业务操作的业务日志库，在业务日志库中去掉重复的记录，即可获取自体集，这种方式的难点在于很难获取一个纯净的业务日志库，适合于有一定数据基础的系统，在入侵检测实施初期使用。第三种方式是在检测器日志库中提取自体集，从检测日志库中清除掉被检测为“非自体”的业务日志，余下的就是“自体”的业务日志，将“自体”业务日志去掉重复记录，即得到自体集。这种方式提取的自体集相对纯净，但是需要积累一定的检测日志后才能实施，因此适合于在检测实施过程对自体集的动态更新中提炼。

# 11.6.3 RFID 适应性检测器的动态更新

RFID 系统的自体集随着业务的变更而动态变化，所以 L 检测器的动态更新是必要的，否则系统的检测性能会逐步恶化。虽然生物免疫系统中 T 细胞、B 细胞等淋巴细胞在持续地动态生成，但是对于 RFID 入侵检测系统而言，L 检测器持续不断地更新会消耗掉大量的资源，影响检测效率。因此，采用周期性更新的方式来维护 L 检测器的有效性，自最近一次 L 检测器生成以来，如果新增的业务日志数量超过阈值，则重新选取样本集，产生自体集，并生成新一轮 L 检测器库。选择业务日志样本时，为了保证新鲜性，新增的业务日志全部选取，历史的业务日志则根据记录的年龄随机选取，年龄越大的业务日志，选择的概率越低。
