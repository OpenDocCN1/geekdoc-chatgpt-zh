$\sigma_i^o \in [1, 3]$，标准差基数 $\sigma_e$ 在应用中常取 0。标准差的调整方式有以下三种[149~154]。

+   (1) 指数调整法。
+   
+   $\sigma_i^{t+1} = \sigma_e + \sigma_i^0 	imes e^{\frac{-\Delta k}{T}}$ (8-19)

+   (2) 双曲调整法。
+   
+   $\sigma_i^{t+1} = \sigma_e + \frac{1}{a + eta t}$ (8-20)
+   
+   式中，$a, eta$ 均为系数，$a > 0, eta > 0$；其他参数同前。

+   (3) 混合调整法。
+   
+   $\sigma_i^{t+1} = \sigma_e + \left( \frac{1}{a + eta t} + \sigma_i^0 	imes e^{\frac{-\Delta k}{T}} ight) / 2$ (8-21)
+   
+   混合调整法实际上是指数调整法和双曲调整法的算术平均。

# 8.4.1 收敛特性分析

在每个子抗体群的免疫操作运行到一定代数后，将 $N$ 个低层免疫操作的结果种群记录到二维数组 $W[1, \cdots, N; 1, \cdots, n]$ 中，并输入到高层免疫操作中。设子抗体群第 $k$ 次迭代共有子抗体群 $N$ 个，子抗体群的中心分别为 $A_k^1, A_k^2, \cdots, A_k^N$。若所求优化问题的最优解为 $A^*$，适应度函数为 $f$，则可定义分层免疫算法的收敛性如下：

定义 8-1 如果对应于任意初始子群均有

$\lim_{k \to \infty} P\{\max[f(A_k^1), f(A_k^2), \cdots, f(A_k^N)] = f(A^*)\} = 1$
