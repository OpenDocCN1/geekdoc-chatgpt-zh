采用较小的变异率。可以看出，抗体亲和力值越接近最大亲和力值，变异率 pm 就越小。

# 8.3.3 低层免疫操作设计

+   1. 适应度函数

在免疫操作中，抗体适应度度量是抗体克隆选择的基础，如何设定合适的适应度函数是需要重点考虑的因素之一。在免疫操作的初始阶段，由于抗体随机产生，各个抗体的适应度大小差别较大。个别较优秀抗体的适应度有可能远远高于其他抗体，从而增加被克隆复制的次数。反之，个别适应度很低的抗体，尽管本身含有部分有益的基因(字符)，却会被过早舍弃。这种不正常的取舍，对于抗体规模不大的群体尤为严重，会影响抗体的多样性，将免疫操作的搜索引向误区，过早地收敛于局部最优解。这时，需要设计一个适应度函数以减少群体中抗体适应度的差别；另外，当免疫操作到后期时，群体逐渐收敛，各个体适应度差别不大，为了更好地实现优胜劣汰，此时希望适应度函数适当地放大适应度，突出个体之间的差别[55]。因此，就要求恰当地设计一个适应度函数以满足算法的上述要求。目前，一般设定的适应度函数是目标函数的简单变形。例如，若 f(x) 为目标函数，对于优化目标为最大，则适应度函数设计为 fitness(x) = f(x) 等形式；对于优化目标为最小，则适应度函数设计为 fitness(x) = M - f(x) (M > fmax) 或 fitness(x) = 1/f(x) 等形式。采用这种方式设计适应度函数的优点是构造简单，与目标函数直接相关。但上述这种设计适应度函数的方式满足不了免疫操作本身的要求。如果我们在分层免疫算法的各低层免疫操作中分别设计不同的适应度函数，这些适应度函数分别从不同方面衡量抗体适应度，则可以弥补采用同一种适应度函数的不足，满足免疫操作的要求。例如，可以在各低层免疫操作中对适应度进行各种形式的线性变换，如采用式(8-3)进行适应度变换。

```
f' = af + b (8-3)
```

式中，f' 为缩放后的适应度；f 为原来的适应度；a、b 为系数。在每个免疫操作中，a、b 的值与迭代代数或平均亲和力相关。
