防止这类现象的发生,就要增大优良个体的比例以减少坏个体的不良影响,即利用有用信息来指导进化。

变异操作分为三种,首先是对最优个体的角度旋转的变异,其次是交叉变异,再次是个体本身的变异。其中,旋转变异如式(4-3)、式(4-26)所示,交叉变异采取单点交叉变异或全交叉变异[126],单点交叉变异或全交叉变异在交换相应的二进制位字符串( P(t) )的过程中同时交换两个个体的相应位的观测器 Q(t)。对于个体本身变异,本节采取文献[130]中的方法。设某一量子比特当前的幅角为 t_{ij} , 则变异后的幅角为 \pi/2 - t_{ij} ,即交换 \alpha_i 和 \beta_i。假设个体在种群中的排名为 m,种群个数为 n,决策空间为 l 维,则变异概率 p_m 为 l^{-(n+1)/(n+m)} ,这样保证每个基因位的变异概率在 [1/l, \sqrt{1/l}] 中变化,而且亲和力靠前的个体变异度小。

+   1. 多目标 0/1 背包问题

本节以多目标 0/1 背包问题为例, 对 CMQEA 的有效性进行验证。

多目标 0/1 背包问题是一个典型的组合优化问题, 属于 NP 完全问题, 可描述如下: 对一给定权值的集合 w_{i,j} (第 j 个物品在第 i 个背包的质量), 利润集合 p_{i,j} (第 j 个物品在第 i 个背包的利润) 及 k 个背包的容量 c_i , 求一个二进制向量 x = (x_1, x_2, \cdots, x_n) \in (0,1)^n , 使

```
st. Max(f(x)= (f_1(x), f_2(x), \cdots, f_n(x)))
```

```
\sum_{j=1}^n w_{i,j} \cdot x_j \leqslant c_i, 1 \leqslant i \leqslant k
```

```
f_i(x) = \sum_{j=1}^n p_{i,j} \cdot x_j
```

对于背包问题, 有一个基本的先验知识, 就是人们在装包时总是先选择利润权值比大的物件装入; 如果背包过载, 则总是先选择利润权值比小的物件从背包中拿出来。这个特征是背包问题本身的一种属性, 也是在解决问题时可以利用的一种特征信息和知识, 因此在这里作为从问题中提取疫苗的一种途径。利用免疫的相关知识, 本节中抗体指候选解, 即 PF_{known}; 抗原指问题的优化目标及其约束条件, 即式(4-28); 抗体-抗原的亲和度指候选解所对应的目标函数值, 即 PF_{known} 与 PF_{true} 的差别, 亲和度越大则两者差距越小。
