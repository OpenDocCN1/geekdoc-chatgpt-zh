而且每种操作算子都有各自的优缺点，算法能否收敛及结果如何，都与参数的取值、操作算子的选择有着密切的关系。因此，研究设计一种能吸收各种免疫操作算子的优点，且全局搜索能力强、收敛速度快的免疫算法是非常必要的。基于以上认识，本节提出一种包含各种操作算子的分层免疫算法。

# 8.3.1 分层免疫集成的设计思路

分层免疫算法的基本框架是算法分为两层或多层，最顶层只包含一个免疫操作，其他层包含一个或多个不同的免疫操作。对于不同的问题，分层免疫算法所包含的层数及每一层所包含的免疫操作的数目也可以不同。下面以两层免疫算法为例，探讨分层免疫算法的设计思路，其中，第一层中的免疫操作称为高层免疫操作，第二层中的免疫操作称为低层免疫操作。对于一个具体问题，首先，随机生成 N×n 个抗体 (N≥2, n≥2)，然后将它们分成 N 个子抗体群，对每一个子抗体群独立地运行各自的免疫操作，即它们为 IA_i (i=1,2,...,n)。这 N 个低层免疫操作的各种操作算子和参数（包括抗原抗体编码、亲和力计算公式、变异操作、克隆选择、浓度阈值、记忆库规模）等实现形式都有所不同。

每个子抗体群的免疫操作运行到指定代数后，将 N 个免疫操作的结果种群（记忆库中的抗体）记录到二维数组 W[1,...,N;1,...,n] 中，则 W[i,j] (i=1,2,...,N; j=1,2,...,n) 表示 IA_i 的结果种群的第 j 个个体。同时，将 N 个结果种群的平均亲和力值记录到数组 A[1,...,N] 中，其中，A[i] 表示 IA_i 结果种群的平均亲和力值。然后将 N 个低层免疫操作的结果种群 W[1,...,N;1,...,n] 输入到高层免疫操作中。

在高层免疫操作中，基于数组 A[1,...,N]，即 N 个低层免疫操作中抗体群的平均适应度值，对数组 W[i,j] 代表的结果种群进行克隆选择操作，一些结果种群由于它们的平均适应度高而被选择复制，甚至复制多次；而另一些种群由于其平均适应度低而被淘汰。

在 W[1,...,N;1,...,n] 中，根据交叉率随机选择一对抗体进行交叉，如果 W[i,1,...,n] 和 W[j,1,...,n] 被随机地匹配到一起，而且从位置 x 进行交叉 (1≤i,j≤N; 1≤x≤n-1)，则 W[i,x+1,...,n] 和 W[j,x+1,...,n] 相互交换相应的部分。这一步骤相当于交换了 IA_i 和 IA_j 中结果种群的 n-x 个个体。

用少量随机生成的新个体替换 W[1,...,N;1,...,n] 中按变异率选择的个体。至此，高层免疫操作的第一轮运行结束，N 个低层免疫操作 IA_i (i=1,2,...,n) 可以从相应的新的 W[1,...,N;1,...,n] 种群继续各自的操作。

在 N 个 IA_i 再次各自运行到一定代数后，再次更新数组 W[1,...,N;1,...,n] 和 A[1,...,N]，并开始高层免疫操作的第二轮运行。如此继续循环操作，直至得到满意的结果。分层免疫算法的算法流程图如图 8-1 所示，低层免疫操作的算法流程图如图 8-2 所示。
