(3) 访问 (access)。阅读器与标签交互（读取或者写入）的过程。访问前必须对标签进行识别。访问操作由 Req_RN、Read、Write、Kill、Lock、Access、BlockWrite 和 BlockErase 等命令构成。

标签的状态及其转换描述如下：

- (1) 就绪状态。就绪可以被视为通电标签（未被灭活或未参与某盘存周期的标签）的保持状态。进入激励射频场后，未灭活的标签应进入就绪状态。标签应保持其就绪状态直至收到其已盘存参数（Query 命令规定的通话的已存盘参数）和 Select 参数与其当前标记值匹配的 Query 命令。匹配标签应从其 RNG 中抽出 Q 位数，将该数字载入其时隙计数器内，若该数字非零则转换到仲裁状态，若该数字为零则转换到应答状态。若处于除灭活之外任何状态的标签电源断电，则应在恢复电源后立即返回就绪状态。

- (2) 仲裁状态。仲裁可以视为参与当前盘存周期但其时隙计数器数值非零的标签的“保持状态”。处于仲裁状态的标签每次收到其通话参数与当前盘存周期通话匹配的 QueryRep 命令后使其时隙计数器减 1，当时隙计数器达到 0000h 时，应转换到应答状态。以 0000h 的时隙值转换到仲裁状态（如从应答状态转换）的标签应使其时隙计数器在下一个 QueryRep（附匹配通话）时从 0000h 减 1 到 7FFFh，由于其时隙值此时非零，因此仍然处于仲裁状态。

- (3) 应答状态。一旦进入应答状态，标签应反向散射 RN16。若标签收到有效确认（ACK），则转换到确认状态，反向散射其 PC、EPC 和 CRC-16。若标签未能接收到 ACK，或收到无效 ACK，则应返回仲裁状态。

- (4) 确认状态。处于确认状态的标签可以转换到除灭活之外的任何状态，视收到的具体命令而定。

- (5) 开放状态。处于确认状态的，其访问口令非零的标签应在收到 Req_RN 命令后立即转换到开放状态，反向散射新的 RN16(标为句柄)，阅读器在随后的命令中使用该句柄，标签在随后的应答中也使用该句柄。处于开放状态的标签应执行除 Lock 之外的所有命令。处于开放状态的标签可以转换到除确认之外的任何状态，具体情况视所收到的命令而定。

- (6) 保护状态。处于确认状态的，其访问口令为零的标签收到 Req_RN 命令后应立即转换成保护状态，反向散射新的 RN16(标为句柄)，阅读器在随后的命令中使用该句柄，标签在随后的应答中也使用该句柄。处于开放状态的其访问口令非零的标签应在收到有效 Access 命令后立即转换到保护状态，保持原来从确认状态转换到开放状态时反向散射的句柄不变。处于保护状态的标签可以执行所有访问命令。处于保护状态的标签可以转换到除开放或确认之外的任何状态，具体情况视所收到的命令而定。

- (7) 灭活状态。处于开放状态或保护状态的标签应在收到 Kill 命令后以有效非零灭活口令和有效句柄进入灭活状态。进入灭活状态后，标签应通知阅读器灭活操作成功，此后不再对阅读器作出响应。被灭活的标签应在所有情况下都处于灭活状态，并在随后的开启电源的操作中立即进入灭活状态。灭活操作具有不可逆性。

安全方面，EPC C1G2 协议采取的安全策略总结如下：

- (1) 提出 Kill 指令使标签永久失效，从而保护用户隐私；
- (2) 提出 Lock 指令永久锁定数据，防止数据被篡改；
- (3) 对 Access 指令和 Kill 指令提供了口令保护；
- (4) 在进行写操作时，阅读器向标签请求一个随机数，标签将这个随机数以明文的方式传送给阅读器，阅读器使用这个随机数与待写入的数据进行异或运算传输给标签，标签将获得的数据经过再次异或得到明文后写入存储器；
- (5) 执行 Access 指令和 Kill 指令时，阅读器在发送密码前同样先向标签请求一个随机数，并将经过此随机数异或的密码发送给标签，以达到数据在阅读器到标签的前向通道上被掩盖的目的。

但是 EPC C1G2 协议存在明显的安全漏洞：

- (1) 标签信息以明文的方式传送给阅读器，显然存在信息泄露；
- (2) 尽管写操作时阅读器写入标签的数据是以加密方式发送的，但是利用截获的标签随机数，攻击者只需进行简单的异或运算即可还原明文。
- (3) 尽管以上两种攻击方式的防范考虑都是基于标签芯片后向反射能力弱，攻击者无法获得标签发送信息的基础上的，但是由于 UHF 标签与阅读器可以在长达 10m 的距离进行通信，在这个距离内，攻击者有很大的空间进行藏匿，所以不得不引起注意。
- (4) 在标准中没有指定标签与阅读器之间的验证机制，使得凡是符合标准的阅读器无论是否授权都可以对标签进行操作，这将给攻击者未授权访问带来极大的便利和机会。

## 11.4.2 RFID 应用的业务特征与抗原决定基定义

虽然 RFID 尚未推广到单个产品级的应用，但是已有不少文献描述了 RFID 在生产管理、供应链管理和零售业等领域的应用远景[220~223]，包括 RFID 应用的商业模式和业务流程等。RFID 应用远景的业务特征反映了未来 RFID 系统的安全需求及其可构建的安全规则，是定义抗原决定基的基础。

- 1. RFID 应用的业务特征分析

根据 RFID 在各个领域中的应用流程，随着商品的流动，RFID 应用具有明显的区域特征。例如，在生产管理中，产品制造完成后在生产车间粘贴标签，记录产品生产信息，而进入存储库房时，在仓库门口进行入库登记，可能会定时做库存盘点工作，出库时，在仓库门口作出库登记。在零售业中，商场中一般定时对商品作盘存操作，商场出口则进行盘存和收费。因此，根据业务需要在不同区域将会有不同的安全需求，如在仓库中对标签进行 Write 操作可能是不允许的，在商场中修改标签内容或者访问标签的用户存储区也可能被视为非法，因此，RFID 应用具有明显的区域特征。此外，有许多工作是在固定的时间范围内进行的，如库存盘点，可能会指定一周盘点一次，并且只会在上班时间，规定时间范围之外的访问可能是不允许的，因此 RFID 应用还具有时域特征。

另外，对于不同的标签群，RFID 的安全需求也不相同。例如，零售业应用中，对于部分贵重商品，在商场中不能随意访问其敏感信息，而对于普通商品则没有限制。

因此，可根据 RFID 应用的区域、时域、标签群、标签操作等属性来解释 RFID 应用的安全规则。安全规则可描述为：在指定区域的某个时段，只允许对某部分标签进行某些操作。所有违反安全规则的操作都是违法的，可能发生了阅读器窃取、拒绝服务、标签仿冒、标签篡改等攻击，这就构成了 RFID 入侵检测的业务基础。

- 2. RFID 抗原决定基定义

抗原决定基由抗原元素构成，对于 RFID 入侵检测而言，抗原决定基可映射为业务日志，抗原元素则映射为组成业务日志的属性。基于 RFID 应用的业务特征，RFID 业务日志由区域、时域、标签群和标签操作构成，表示为如式(11-4)所示的六元组。

```
AppLog = 〈T, Rg, Rc, Pac, EPC, RT〉  
(11-4)
```

式中，T 表示时域；Rg 表示区域；Rc 为阅读器指令；Pac 为指令参数，如 Read 和 Write 指令的存储体参数，Lock 指令的有效负载参数等，Rc 与 Pac 共同表达某项具体业务操作；EPC 为操作标签的 EPC 标识；RT 为操作返回码，即 EPC C1G2 定义的错误码。

时域 T 对应的是一个时间段，由起始时间 st 和终止时间 et 表示，如式(11-5)所示。

```
T = \langle st, et \rangle (11-5)
```

AppLog 即为抗原决定基，T、Rg、Rc、Pac、EPC、RT 即为构成抗原决定基的抗原元素，一个具体的业务日志即为 RFID 入侵检测中的抗原，从而完成了 RFID 抗原决定基的定义。

## 11.4.3 RFID 攻击的统计特征与危险元素定义

生物免疫系统中的危险信号是基于抗原攻击的累计效果发出的，因此，免疫反应往往具有一定的滞后性。在 RFID 系统中，从单个攻击中很难提取出明显的特征，但是当同种攻击连续发生时，从统计特征分析则会发现其明显偏离正常的轨迹，从而发出危险信号，因此，基于攻击的统计特征提取危险信号是一条可行的途径。

- 1. RFID 攻击的统计特征分析

对于 EPC C1G2 而言，典型攻击仍然是利用无线信道的开放性展开的阅读器窃取和拒绝服务攻击，另外，EPC C1G2 采取了口令保护的安全措施，不可避免地会遭受口令猜测的攻击。

- 1) 阅读器窃取

任何未授权的阅读器向标签发送指令统称为阅读器窃取，这是窃取个人隐私和商业机密，甚至篡改标签信息的最直接的手段，EPC C1G2 没有采取任何措施防止这种攻击。这种攻击非常隐秘，因为未授权的阅读器不受 RFID 系统管理，它不会在 RFID 系统上留下任何痕迹，其攻击的证据只能通过无线信道提取，如果通过无线信道收集的操作记录无法在 RFID 应用系统记录的操作日志中找到，则可能发生了阅读器窃取攻击，如果阅读器窃取持续发生，则两条渠道采集的操作记录的一致性会显著下降。

- 2) 拒绝服务

拒绝服务(DoS)攻击主要指攻击者通过干扰广播、阻塞信道或其他手段，产生异常的应用环境，使合法阅读器无法读取标签信息。对于 EPC C1G2 协议而言，因为它采用 CRC-16 进行数据的准确性检验，一旦产生电磁干扰，电子标签或者阅读器发出的数据产生 CRC 校验失败的几率将会明显提高。如果标签对阅读器指令检验失败，标签将不会产生应答，如果阅读器对标签反馈的数据检验失败，阅读器将不会进行下一步业务处理。因此，DoS 攻击会使 CRC 校验失败率显著上升，而标签应答率则显著下降。

- 3) 口令猜测

口令猜测是指阅读器，包括非法用户利用合法阅读器，尝试或者猜测标签的口令，破解标签口令后再进一步获取标签敏感信息，甚至篡改标签数据。EPC C1G2 协议规定，对于 Access、Lock 和 Kill 等指令都设置了口令保护，攻击者一旦跨越口令防护，将可以对标签进行任何操作，因此，口令猜测是阅读器窃取和标签篡改的前兆。口令错误时，标签一般不应答，为了分析方便，口令类指令的标签不应答认为是口令错误，猜测口令必将导致口令错误率急剧上升。

- 4) 其他

攻击前的试探指令往往执行不成功，将会造成指令失败率显著上升；标签篡改可能导致一个区域的写指令比例显著上升；Kill、Lock、Access 等口令类指令的比例上升，可能也蕴含着恶意的未知攻击。

- 2. RFID 抗原危险元素定义

RFID 抗原危险信号定义为一个反映攻击特征的危险元素集合，根据典型攻击的统计特征分析，可提取出指令匹配率（Pm）、CRC 误码率（Pe）、标签应答率（Pr）、口令失败率（Pa）等反映 RFID 入侵特征的统计特征元素，即危险元素。

指令匹配率（Pm）：假设通过 RFID 系统管理的合法阅读器的操作日志被全部记录下来，称其为系统日志（sysLog），而获取操作日志的另一条途径是通过无线信道获取，通过这种方式获取的日志称为信道日志（chLog）。正常情况下，sysLog 与 chLog 应该是一致的，即 chLog 的操作记录能在 sysLog 中找到对应的记录。在统计范围内，chLog 记录能在 sysLog 中找到对应记录的比例，称为指令匹配率（Pm）。当发生阅读器窃取攻击后，非法的阅读器操作将在 chLog 中被截获，但无法在 sysLog 找到，将导致 Pm 低于正常水平，因此 Pm 能作为反映阅读器窃取攻击的危险元素。

CRC 误码率（Pe）：统计范围内标签应答 CRC 校验失败次数与阅读器询问总次数的比率。当拒绝服务攻击发生时，Pe 将会高于正常水平，因此 Pe 能作为反映 DoS 攻击的危险元素。

标签应答率（Pr）：统计范围内标签应答次数与阅读器询问总次数的比率。一般而言，如果有标签在阅读器的识读范围之内，阅读器的一个盘存周期就会有标签应答，但如果无线信道严重干扰，则标签收到的阅读器信号也会因 CRC 校验失败而不会作出应答。因此，拒绝服务发生时，Pr 会明显降低，Pr 也是反映 DoS 攻击的危险元素之一。

口令失败率(Pa)：统计范围内因口令错误而执行失败的命令条数与口令类指令条数的比率。当口令猜测攻击发生时，Pa 会显著上升，因此 Pa 是反映口令猜测攻击的危险元素之一。

另外，指令成功率(Ps)、口令类指令比率(Pd)、写指令比率(Pw)能反映 RFID 应用的时域和区域特征，也被纳入危险元素范畴。

指令成功率(Ps)：统计范围内执行成功的命令次数与阅读器询问次数的比率。大部分的攻击在执行之前要进行一些试探性的操作，等获取到足够的信息后再展开进一步操作，而在试探阶段，大部分的命令会因为参数或者格式不对而失败，因此指令成功率过低会反映出攻击的前兆。

口令类指令比率(Pd)：统计范围内口令类指令数与阅读器询问总次数的比率。一些开放的区域，如商场的货架，Lock、Kill 等指令一般不会发生，如果这些区域的口令类指令比率过高，则可能是攻击的前兆。

写指令比率(Pw)：统计范围内写指令数与阅读器询问总次数的比率。一般写指令发生在一些特定的区域，如生产线或者包装线上，有明显的区域特征，如果某区域获取的写指令比率与其区域特征不符合，则有可能是入侵的征兆。

从对立的角度对特征体系进行扩展，可以派生出与上述特征元素相对的特征元素(相对特征元素的命名统一在其后加 m 表示)：指令失败率(Psm = 1 - Ps)，指令不匹配率(Pmm = 1 - Pm)，标签不应答率(Prm = 1 - Pr)，读指令比率(Pwm = 1 - Pw)，指令不匹配数(Nmm = Nc - Nm)，标签不应答数(Nrm = Nc - Nr)，读指令数(Nwm = Nc - Nw)，口令成功率(Pam = 1 - Pa)等。

为了更全面地反映 RFID 系统的运行情况，将基础统计数量也纳入特征元素体系，包括阅读器询问总次数(Nc)，CRC 错误次数(Ne)，标签应答数(Nr)，口令失败数(Ndf)，指令成功数(Ns)，口令类指令数(Nd)，写指令数(Nw)，与合法阅读器记录匹配次数(Nm)等。基础统计数量在必要时可作为辅助危险元素出现。

危险元素集合用特征元素集合 FeatureDim 表示，如式(11-6)所示。

```
FeatureDim = { Pe, Pr, Pa, Ps, Pm, Pd, Pw, Nc, Ne, Nr, Nm, Nw, ... }
```

危险元素的关系如式(11-7)所示。

```
⎧Pe = Ne/Nc  
⎪Pr = Nr/Nc  
⎪Pa = Ndf/Nd  
⎨Ps = Ns/Nc  
⎪Pm = Nm/Nc  
⎪Pd = Nd/Nc  
⎩Pw = Nw/Nc
```

危险元素及时域（T）、区域（Rg）等辅助信息共同组成 RFID 特征日志（FeatureLog），如式(11-8)所示。

```
FeatureLog = <T,Rg,Pe,Pr,Pa,Ps,Pm,Pd,Pw,Nc,Ne,Nr,Nm,Nw,...>

(11-8)
```

一条 FeatureLog 记录即一个抗原的危险信号，根据抗原危险信号可分析出统计范围内是否有有害的抗原出现。

## 11.4.4 RFID 操作日志采集与抗原提呈

RFID 操作日志采集是提呈抗原决定基（AppLog）和抗原危险信号（FeatureLog）的基础，RFID 操作日志的采集最简单的方式是从 RFID 中间件输出日志，但是这种方式只能采集到受管理的合法阅读器的操作日志，对非法阅读器的攻击无法检测。因为 RFID 入侵检测的重点是保护标签数据不被非法访问，因此有必要从无线信道来采集操作日志，通过无线信道采集的操作日志才是完整的日志。本章提出分别从无线信道和应用系统同时收集操作日志，收集的日志分别为信道日志（ChLog）和系统日志（SysLog），检测时以 ChLog 为主，SysLog 作为辅助日志和备份日志，指令匹配率（Pm）和匹配次数（Nm）的统计则通过两者的融合计算获取，采集示意图如图 11-11 所示。

信道采集通过构建信道探测器进行无线侦听，获取无线信道上的所有二进制数据记录，然后根据 EPC C1G2 解析阅读器指令及参数和标签反馈信息，解析出 AppLog 所需的基础属性，ChLog 的属性组合如式(11-9)所示。

```
ChLog = <t,Rg,Rc,Pac,EPC,RT>

(11-9)
```

式中，t 表示操作发生时间(11-10)，即日志采集到的时间，其他元素的含义与 AppLog 的同名元素一致。

信道探测器根据探测器覆盖的范围均匀分布在标签区域，如库房和商场等地，全面监控保护区域的 RFID 操作。为了反映区域特征，可以按照应用业务特征将地理区域组合为业务区域，如将所有库房组合为一个逻辑区域，统计危险信号时以业务区域为单位统计。

系统日志(SysLog)从 RFID 中间件收集阅读器与标签之间的通信数据，假设合法的阅读器均是受 RFID 系统控制的，系统能通过中间件截获所有的标签操作的关键信息。与 ChLog 一样解析出 AppLog 所需的基础属性，如式(11-11)所示。

```
SysLog = \langle t, Rg, Rc, Pac, EPC, RT \rangle (11-10)
```

式中，元素含义与 ChLog 一致。

对于抗原决定基 AppLog 的提呈，ChLog(或者 SysLog)可以直接转换为 AppLog，转换过程中将 ChLog.t 转换为 AppLog. T，简单地将时间 t 映射为时域 T，即 T.st \leqslant t < T.et。AppLog 的其他元素则与 ChLog 一一对应。

对于危险信号 FeatureLog 的提呈，基于 ChLog(或者 SysLog)，系统按照区域分时段统计危险元素，可直接计算出除指令匹配率(Pm)和匹配次数(Nm)之外的危险元素。

对于 Nm 和 Pm，基于时间和阅读器指令名称的比较可判断某 ChLog 记录是否与 SysLog 匹配，匹配规则定义见定义 11-4。

定义 11-4 日志匹配。设在同一区域内，同时段采集到的信道日志集合 ChLog 和系统日志集合 SysLog，lc\in ChLog，如果存在 ls\in SysLog，$|lc.t - ls.t| < \epsilon \land lc.Rc = ls.Rc$，则 lc 与 SysLog 匹配，记为 Match(lc, SysLog)，否则 lc 与 SysLog 不匹配，记为 $\neg$Match(lc, SysLog)。

式中，$\epsilon$ 为时间偏差阈值。

用谓词逻辑表示以上定义为

```
$\forall lc \in ChLog \land \exists ls \in SysLog \land |lc.t - ls.t| < \epsilon \land lc.Rc = ls.Rc \Leftrightarrow Match(lc, SysLog)$
```

标识出 lc 与 SysLog 是否匹配后，即可统计出记录匹配次数(Nm)和指令匹配率(Pm)。
