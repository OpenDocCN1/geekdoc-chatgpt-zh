组最优加权系数来计算交叉效率值呢？这需要根据实践经验进行处理。

综上所述，目前 DEA 模型的改进方法都有一定的限制。本章提出一种新的 DEA 模型——基于虚拟单元的 DEA 模型。

# ## 3. 基于虚拟单元的 DEA 模型的构建

基于虚拟单元的 DEA 模型是通过设置“虚拟评价单元”或者“目标单元”，这些“虚拟单元”恰好构成一个“最前沿边界”，从而可以将全部参评单位的效率水平区分开来。其具体操作方法是：对样本数据进行重排，所有投入指标取其最差值，而所有产出指标取其最优值，这样设置第一个“虚拟评价单位”；然后所有投入指标取其次最差值，而所有产出指标取其次最优值，这样设置第二个“虚拟评价单位”；其余依次类推，可以构造出与样本容量一样大的虚拟参评单元。鉴于此，在 DEA 模型的建立过程中引入虚拟最优单元 \(Y_{max}\) 构成一个新的 DEA 模型。该虚拟最优单元 \(Y_{max}\) 的各输出取所有决策单元相应输出的最大值，各投入指标取其最差值，具体形式如式(9-21)所示

```
\(\max \sum_y O_{k,y} V_{k,y}\)
\(\left\{\begin{array}{l} \sum_y O_{s,y} V_{k,y} + O_{s,max} V_{(k+1),y} - \sum_x I_{s,x} U_{kx} - I_{s,min} U_{k+1,x} \leqslant 0 \\ O_{s,max} = \max(O_{s,1}, O_{s,2}, \cdots, O_{s,m}) \\ I_{s,min} = \min(I_{s,1}, I_{s,2}, \cdots, I_{s,m}) \\ \sum_x I_{k,x} U_{k,x} = 1 \\ U_{k,x}, V_{k,y} \geqslant 0 \\ s = 1, 2, \cdots, n \end{array}\right.\)
(9-21)
```

在引入虚拟最优单元 \(Y_{max}\) 后，原生产可能集 \(T\) 上的所有决策单元为非有效单元。因此，式(9-21)能够对原生产可能集 \(T\) 上的所有决策单元进行有效的排序和客观评价，从而能够利用改进后的 DEA 模型对农用地进行分等。
