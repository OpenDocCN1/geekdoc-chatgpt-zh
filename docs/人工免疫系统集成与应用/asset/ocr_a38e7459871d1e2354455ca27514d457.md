从图 6-4 可以看出,随着 σs 的增加,AiNet 和 OE-AiNet 算法的聚类正确率 pc 都会下降,在 σs⩽0.07 时,两算法都能正确聚类;σs⩾0.07 时,AiNet 算法的聚类正确率 pc 比 OE-AiNet 算法下降速度快;σs⩾0.1 时已不可能正常聚类,表明 AiNet 的聚类结果比 OE-AiNet 对参数 σs 的变化更加敏感。对比 AiNet 和 OE-AiNet 的压缩率曲线,σs 相同时, AiNet 的压缩率 pr 比 OE-AiNet 低,在两者聚类正确率均为 100% 的 σs = 0.07 点时,AiNet 的压缩率 pr = 34.58%, OE-AiNet 的压缩率 pr = 43.00%, AiNet 的压缩率 pr 比 OE-AiNet 低了 8.42%,结果表明,OE-AiNet 算法比 AiNet 算法能更有效地压缩样本特征。
