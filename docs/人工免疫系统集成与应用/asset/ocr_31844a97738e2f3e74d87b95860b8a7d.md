# 3.6 移动 Ad Hoc 网络入侵检测应用仿真

# 3.6.1 针对 AODV 路由协议的网络攻击

MANET 中的节点不但具有数据传输的功能，而且具有为网络中的其他节点充当路由的功能，一个节点到另一节点的路由依赖于参与路由的所有节点。针对 MANET 路由协议的网络攻击很常见。本章以 MANET 的 AODV 协议(Ad Hoc on demand distance vector routing)为例，考虑针对 AODV 的黑洞攻击和 FFRR 攻击这两种 DoS 攻击。

黑洞攻击的特点是恶意节点向环境中周围所有的节点广播它有最短路径。在 AODV 中，恶意节点对选定的源节点和目的节点广播拥有假的最大序列号的 ROUTE_REQUEST。如果该恶意节点选定其他源节点发送 ROUTE_REQUEST，最终它将攻陷全网，就像在网络上形成一个吸收(只进不出)数据的黑洞。

在 FFRR 攻击中，恶意节点产生大量的无用 ROUTE_RE_QUEST 来占用带宽和消耗其他节点的资源。
