理论的基础上，将多投入、多产出的效率衡量转换为数学比例，以线性规划求解有效前沿，计算决策单元在固定规模下的相对效率，该模型被称为 CCR 模型[199]。CCR 模型是 DEA 的第一个模型。1984 年 Banker 等提出了 BCC 模型，该模型允许变动规模报酬，并引入了 Shephard 的距离函数，得出衡量技术效率和规模效率的线性规划模式，用以计算各单元的技术效率、规模效率为递增、递减或不变的情况[227]。此外，其他学者们纷纷从不同角度对 DEA 原始模型进行了改良，如 Log 一型的 DEA 模型、加法型 CZGS2 模型、具有无穷多个决策单元的半无限规划的 C²W 模型和 C²WY 模型等[199~201]，使得 DEA 模型日益完善。由于 DEA 模型的类型有很多，根据本章的需要，下面重点介绍 CCR 模型。

CCR 模型的提出是为了评价多投入、多产出决策单元的投入-产出效率，利用投入/产出的比例这一方式来评估效率。CCR 模型假设有 n 个 DMU，每个 DMU 有 m 种投入和 p 种产出，则 DMU₀ 的最大相对效率值为[150]

```
\max \sum_{y} O_{ky} V_{ky} \\
\left\{ \begin{array}{l} \sum_{y} O_{sy} V_{ky} - \sum_{x} I_{kx} U_{kx} \leqslant 0 \\ U_{kx}, V_{ky} \geqslant 0 \\ s = 1, 2, \cdots, n \end{array} \right.
(9-19)
```

式中，Oky 为第 k 个决策单元在输出指标 y 上的测量值；Ikx 为第 k 个决策单元在输入指标 x 上的测量值；Vky 为第 k 个决策单元对应于输出指标 y 的权系数；Ukx 为第 k 个决策单元对应于输入指标 x 的权系数。从式 (9-19) 可以看出，CCR 模型实际上是在效率值不大于 1 的情况下，求能使 DMU₀ 的投入-产出率最大的权值 Vky 和 Ukx。由于每个决策单元的有效性都是相对于其他单元而言的，故其效率值为相对效率值，而且可以相互比较。

# 2. DEA 模型的改进

# 1) DEA 模型的不足

由于在利用 DEA 模型对 DMUs 进行评价时，不需要知道投入和产出之间的函数关系，也不需要对各投入和产出赋予权重，因此，Dole 称 DEA 模型是一种懒惰的评价模型[202]。但是 DEA 模型只能将 DMUs 分类，即 DEA 有效和非 DEA 有效两类，对 DEA 有效的 DMUs 却无法进行完全排序。例如，根据式 (9-19)，决策单元 k 的多指标效率值 Ekk 按下式计算：

```
E_{kk} = \frac{\sum_{y} O_{ky} V_{ky}}{\sum_{x} I_{kx} U_{kx}}
(9-20)
```
