局部解很有帮助。②自我调节机制使免疫系统具有维持免疫平衡的机制，通过对抗体的抑制和促进作用，能自我调节产生适当数量的抗体。利用这一功能可提高 AIS 的局部搜索能力。③由于免疫记忆功能，产生抗体的部分细胞会作为记忆细胞而被保留下来，当以后同类抗原入侵时，相应的记忆细胞会被迅速激活而产生大量的抗体，AIS 能利用这种抗原识别功能，可以加快搜索速度，提高 AIS 的总体搜索能力。

AIS 聚类模型的基本原理是将待分析的数据作为抗原，通过抗体对抗原的学习、记忆过程来识别、分类不同数据，并从中找出数据间的相关性。AIS 聚类模型主要利用免疫系统的三大重要特性：免疫记忆能力、学习能力和自适应能力。免疫系统产生的抗体与入侵的抗原相结合，同时产生记忆细胞，将与这种抗原的接触记忆下来，从而产生再次免疫应答。免疫系统的自适应调节功能主要通过对抗体产生促进和抑制、加入新产生的 B 淋巴细胞和清除无用的 B 淋巴细胞等方式来实现，这样可以控制高亲和力抗体的数量，保证抗体的多样性。

用 AIS 聚类模型求解聚类问题，首先要解决的是如何构造适应度函数来度量每个抗体对聚类问题的适应程度，下面对这个问题进行研究。

# 9.2.2 适应度函数构造

AIS 聚类模型建立在样本间相似性度量的基础上，根据聚类准则函数的不同，其适应度函数的设计也不同。适应度函数设计的最终目的是把属于同一类的样本归纳成一个类型的子集，把不同类的样本分离；使同一类样本之间的差别尽可能小，不同类样本之间的差别尽可能大。适应度函数构造得越好，聚类质量就越高。因此，如何确定合适的适应度函数是 AIS 聚类模型的关键。

根据聚类准则函数[180]的不同，下面对各种类型适应度函数的构造分别进行探讨。令样本集 \( X = \{x_1, x_2, \cdots, x_n\} \)。

+   1. 以误差平方和 \( f_e \) 构造适应度函数

采用误差平方和函数 \( f_e \) 度量聚类的质量是最常用的方法之一，其具体定义如下：

```
\( f_e = \sum_{j=1}^c \sum_{k=1}^{n_j} \|x_k - m_j\|^2 \) (9-1)
```

式中，\( m_j \) 为类型 \( j \) 中样本的平均值；\( c \) 为聚类中心。显然，\( f_e \) 描述了 \( n \) 个样本被聚类成 \( c \) 个类型时所产生的总误差平方和。\( f_e \) 越小，聚类质量越高。以 \( f_e \) 为基础，适应度函数可设计为 \( f_e(x) = \frac{1}{f_e} \)。该适应度函数适用于各类样本比较密集且样本数目相差不大的情况。
