## 2.5 人工免疫系统设计框架的提出

通过对比不难发现，在知识存储和模型结构方面，AIS 模型与人工神经网络模型、遗传算法是十分相似的。AIS 兼具进化主义和结构主义两种计算智能方法的特点。神经网络、遗传算法和免疫系统在多样性细胞组成、模式识别、学习与记忆机制及阈值的概念等方面都颇为相似。无疑，神经网络模型、遗传算法的设计框架对 AIS 的研究是有启发意义的[21]。因此，在分析 AIS 的设计框架之前，本章首先介绍人工神经网络(ANN)和进化算法的设计框架。ANN 主要包含两部分。一部分是一组神经元，它们之间通过权值互相连接；另一部分是一组自适应调整过程(函数)，这组函数的主要功能是通过改变神经元之间相互连接的权值进行知识的学习，即 ANN 的学习和训练过程。因此，简单来看，ANN 的设计框架主要包含一组神经元、一套神经元相互之间的连接模式和学习算法。

进化算法也由两部分构成：第一部分是一群表示遗传细胞的人工染色体；第二部分是一组控制染色体产生、选择、复制、交叉、变异的函数或过程。因此，进化算法的设计框架主要包含一组染色体和一组控制染色体产生、复制、变异和选择等的进化过程。

因此，根据 ANN 和进化算法的设计框架，本章认为，一套仿生计算模型的基本框架至少应该包含以下两个部分：①组成该模型的基本元素及模型表示方法；②一套控制整个模型动态变化的自适应过程(函数)。

同样，上面所述的基本元素也是 AIS 设计框架所包含的基本组件；同时通过上面对 AIS 的基本原理、表示模型、基本组件及其相关算法和模型的分析，我们认为 AIS 设计框架应包含：

- (1) 表示免疫细胞和分子的抽象模型；
- (2) 一组用于评估免疫细胞和分子之间相互作用的函数及抗体亲和力成熟方式；
- (3) 一套控制 AIS 动态变化的算法，即控制组成免疫系统的细胞和分子在进化过程中的动态变化的循环过程。

## 第 3 章 自适应变尺度混沌免疫优化算法

### 3.1 引言

人工免疫算法[17,21,23,34,108]是在遗传算法的基础上发展起来的。免疫算法虽然较好地解决了遗传算法的退化现象，能迅速把问题的最优解限制在一个较小的空间范围里，但与遗传算法一样，它仍不能充分利用所求解问题的特征信息指导全局搜索，搜索是盲目的、随机的，在小区域仍不能克服不成熟收敛现象，在小空间搜索效率并不显著[17,23,34]。混沌变量看似杂乱的变化过程，其实却含有内在的规律性。利用混沌变量的随机性、遍历性和规律性可以进行优化搜索[109]，其基本思想是把混沌变量线性映射到优化变量的取值区间，然后利用混沌变量进行搜索。但是，该算法在大空间、多变量的优化搜索上，却存在着计算时间长、不能搜索到最优解的问题[110]。

混沌免疫优化算法充分结合混沌搜索与免疫算法两种算法的优点，利用免疫算法的记忆特性和当代最优解指导混沌搜索。目前混沌免疫优化算法[54,111~113]采用有限区域内折叠次数有限的 Logistic 模型产生混沌变量，其混沌特性不是十分明显。本章利用在有限区域内折叠次数无限的混沌模型来产生混沌变量，并采用自适应变尺度方法改变优化变量的搜索空间，不断提高搜索精度来解决求解最优值时收敛速度缓慢的难题，提出一种自适应变尺度混沌免疫优化算法（adaptive mutative scale chaos immune algorithm，AMSCIA）。

### 3.2 混沌模型的选择

一维混沌自映射的表达式为

```
x_{n+1} = f(x_n) (3-1)
```

在其相空间内总会有线性或非线性折叠现象，否则不可能产生混沌。在某种意义上，用于刻画模型“混沌性”的 Lyapunov 指数也可以看做是模型平均折叠次数的一种表示。当模型的平均斜率的绝对值大于 1 时，Lyapunov 指数为正。一般常用的 Logistic 模型、Tent 模型、Chebyshev 模型等的映射折叠次数都是有限的。

考察由下式定义的一维自映射：

\(\left\{\begin{array}{l}x_{n+1}=\sin\left(\frac{2}{x_{n}}\right), n=0,1,2, \cdots, N \\ -1 \leqslant x_{n} \leqslant 1, x_{n} \neq 0\end{array}\right. \quad (3-2)\)

该映射由于折叠次数无限，在区间 \([-1,1]\) 内有无穷多个不动点和零点，因此
若要由此映射产生混沌，必须注意以下两点：

- (1) 迭代的初始值不能为 0；
- (2) 初始值不能取无穷多个不动点中的任何一个，不动点为方程 \(x_{n+1}=\sin(2/x_{n})\) 的解。

在实际工程的应用过程中，超越数 \(2/(k \pi)(k \text{ 属于整数}, k \neq 0)\) 不可能出现，而
总是以有限精度的有理数来近似替换。因此，只要迭代初值不为 0，混沌就会发
生，此时映射的定义域为 \([-1,1]\)，且 \(x \neq 0\)，并且不包括上述各超越点。一维自映
射 \(x_{n+1}=\sin(2/x_{n})\) 在迭代 1000 次后的随机性、初值敏感性和遍历性如图 3-1 所
示。其中，图 3-1(a) 的初值为 \(x_{0}=0.255\)，可以看到系统输出是毫无规律的；图 3-1
(b) 的初值分别为 \(x_{0}=0.2551\)，\(y_{0}=0.2552\)，纵坐标为 \(x_{n}-y_{n}\)，可以看出，这两个系
统输出完全不同；图 3-1(c) 的系统初值分别为 \(x_{0}=0.2551\)，\(y_{0}=0.1552\)，横坐标为
\(x_{n}(x_{n+1}=\sin(2/x_{n}))\)，纵坐标为 \(y_{n}(y_{n+1}=\sin(2/y_{n}))\)，从图中可以观察到，当迭代
一定次数时，系统输出将遍历整个解空间。

Lyapunov 指数是衡量混沌性的一个重要指标，混沌自映射式(3-2)的 Lyapunov 指数表达式为

```
\(LE = \lim_{n \to \infty} \frac{1}{n} \sum_{i=0}^{n-1} \ln \left| f'(x_i) \right| = \lim_{n \to \infty} \frac{1}{n} \sum_{i=0}^{n-1} \ln \left| \frac{2}{x_i^2} \cos \frac{2}{x_i} \right| \quad (3-3)\)
```

从式(3-3)所示的 Lyapunov 指数表达式可以看出，与常用的有限折叠次数映射相比，显然式(3-2)的混沌性更明显。

```
\begin{cases} \min f(x) = \min(4 - x^2)^2 \\ -8 < x < 8 \end{cases}
```

式中，\(f(x)\)在极值点 \(x = \pm 2\) 所取极小值为 0。

### 3.3 自适应变尺度混沌免疫优化算法

在人工免疫算法中，匹配算法或进化算法被用来实现数据训练和免疫记忆，且进化算法较匹配算法表现出更好的性能，AMSCIA 可表示如下。

- 步骤 1 输入抗原 Ag, 作标准化处理。选择式(3-2)产生的(0, 1)间的 N 个混沌变量作为初始化抗体 Ab。

- 步骤 2 对每一个抗原 \(Ag_i\) 操作如下：

- 步骤 2.1 利用式(3-5)分别计算每个抗体 \(Ab_i\) 同抗原 \(Ag_i\) 的亲和力 \(a_{ij}\)；

```
\(a_{ij} = \sqrt{\sum_{k=1}^n (Ab_{ik} - Ag_{jk})^2}\)
```

- 步骤 2.2 选择亲和力最高的 m 个抗体作为网络细胞；

- 步骤 2.3 对 m 个所选择的网络细胞作克隆操作。亲和力越高的网络细胞，克隆数 \(N_c\) 越多；

- 步骤 2.4 对克隆后的细胞应用方程 \(C = C - \alpha(C - X)\) 进行变异操作，C 为克隆抗体细胞，X 为克隆抗原细胞，\(\alpha\) 为变异率；

- 步骤 2.5 重新计算变异操作后的 C 的亲和力；

- 步骤 2.6 选择其中亲和力最好的 \(\xi\)\%，作为部分记忆细胞数据集 \(M_p\)；

- 步骤 2.7 利用式(3-6)分别计算每个抗体 \(Ab_i\) 同抗体 \(Ab_j\) 间的相似度 \(s_{ij}\)，淘汰 \(M_p\) 中相似度 \(s_{ij}\) 大于阈值 \(\sigma_s\) 的个体；

\(s_{ij} = \sqrt{\sum_{k=1}^n (Ab_{ik} - Ab_{jk})^2}\) (3-6)

- 步骤 3 合并 \(M_p\) 到已经得到的记忆数据集 \(M\) 中。

- 步骤 4 对较优个体进行混沌细搜索。

选择记忆库中适应值较大的 10% 的个体进行混沌细搜索，设较优个体为 \(X=(X_1, X_2, \cdots, X_k)\)，混沌变量搜索区间的缩小表示为

\(\begin{cases} a'_i = X_i - \phi(b_i - a_i) \\ b'_i = X_i + \phi(b_i - a_i) \end{cases}\) (3-7)

式中，\(\phi\) 为收缩因子，\(\phi \in (0, 0.5)\)。

为了保证新范围不至于越界，作如下处理：若 \(a'_i < a_i\)，则 \(a'_i = a_i\)；若 \(b'_i > b_i\)，则 \(b'_i = b_i\)。

因此，\(X_i\) 在新区间 \([a'_i, b'_i]\) 上做还原处理后的向量 \(Y_i\) 由式(3-8)确定

\(Y_i = \frac{X_i - a'_i}{b'_i - a'_i}\) (3-8)

把 \(Y_i\) 与 \(X_{i, n+1}\) 的线性组合作为新的混沌变量，用此混沌变量进行搜索。

\(X'_{i, n+1} = (1 - \beta_i)Y_i + \beta_i X_{i, n+1}\) (3-9)

式中，\(\beta_i\) 为自适应调节系数，\(0 < \beta_i < 1\)。

自适应调节系数 \(\beta_i\) 采用如下方法进行自适应确定：

\(\beta_i = 1 - \left(\frac{K-1}{K}\right)^m\) (3-10)

式中，\(m\) 为一整数，根据目标函数而定（本章取 2）；\(K\) 为迭代次数（本章取进化代数）。

淘汰记忆库中适应值较大的 10% 的个体相似度大于 \(\sigma_s\) 的个体。

- 步骤 5 选择由式(3-2)产生的 \(N\) 个 \((0, 1)\) 间的个体，用其替换亲和力差的个体，同上次免疫计算得到的记忆数据集 \(M\) 一起作为下一代免疫计算的抗体，并返回步骤 2，直到达到网络收敛。

算法终止条件为，迭代次数超过设定的最大进化世代数或者相邻两代免疫网络细胞的距离均值和网络规模不再变化或者变化足够小。

### 3.4 算法的收敛性

AMSCIA 在局部搜索能力和搜索精度上均优于免疫进化算法，可以克服混沌优化方法在大范围内失效的缺点，其收敛性也能得到保证。

由于混沌变量的遍历性，当循环次数足够大时将保证收敛到最优点。从测度论上讲；由于 AMSCIA 属于下降算法，因而设 \(R_0\) 表示全局最优点 \(X^*\) 的邻域，AMSCIA 产生的序列 \( X_i \) 落入 \( R_0 \) 的事件集合为 \( A_i \)，因此 \( A_1 \subset A_2 \subset \cdots \subset A_i \subset \cdots \)，概率测度单调不减，同时，\( P(A_i) \leqslant 1 \)，则

\(\lim_{i \to \infty} P(A_i) = P\left( \bigcup_{i=1}^{\infty} A_i \right) = 1\) (3-11)

取正数 \( \epsilon, 0 < \epsilon < 1 \)，则存在正数 \( N \)，当 \( i > N \) 时，有 \( P(A_N) \geqslant 1 - \epsilon, P(\overline{A_N}) < \epsilon \)，则 \( P(\overline{A_i}, i > N) \leqslant \epsilon^{i-N} \)，因此当 \( i \) 足够大时，AMSCIA 以概率 1 搜索到全局最优解。
