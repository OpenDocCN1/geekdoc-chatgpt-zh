# 2. 抗原提呈

RFID 抗原提呈即从 RFID 系统中获取操作日志，从操作日志中提取出能反映入侵特征的抗原元素。抗原提呈进一步细化为两个子目标，即操作日志采集和抗原元素计算。

# 3. 抗原识别

根据生物免疫系统的抗原识别过程，抗原识别应该完成两个目标，一是抗原的自体/非自体区分，二是抗原刺激过程中的免疫细胞亲和力成熟。相应地，RFID 抗原识别也分为两个子目标，即 RFID 操作的合法/非法识别和检测器亲和力成熟。

# 4. 免疫反应

当免疫系统识别到非自体的病毒或细菌入侵后，免疫细胞会吞噬抗原。对于 RFID 入侵检测而言，识别到入侵类型的抗原后，常见的反应是入侵告警、入侵源追踪和入侵阻断。入侵告警将入侵现象以告警的形式通知系统管理员进行确认和处理。入侵源追踪则协助系统管理员进行入侵源追踪分析，并进一步获取入侵的证据。入侵阻断则根据预先设定的规则自动采取行动阻断正在进行的入侵，如拒绝连接或者进一步操作。另外，还需要提供对误报和漏报的及时校正，并将校正的结果记录在检测日志中，下一轮检测器生成时将避免误报和漏报检测器的重复生成。根据以上分析，RFID 人侵检测的目标层次如图 11-3 所示。
