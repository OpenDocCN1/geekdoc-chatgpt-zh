# # 第 7 章 免疫融合阴性选择算法

# ## 7.1 引言

阴性选择原理是生物免疫系统识别自体和非自体的基础理论，对入侵检测系统识别正常行为和异常行为有着重要的借鉴意义。Forrest 等提出的阴性选择算法（negative selection algorithm, NSA）[44]模拟生物免疫系统的 T 细胞的免疫耐受来产生检测器，因其方法简单，检测性能可调节，适用于分布检测等优点而被广泛接受。然而，NSA 也具有检测器生成效率低，匹配阈值难以确定，实际的检测性能与期望检测性能有较大差距等缺点。本章将针对 NSA 的上述问题进行改进，将阴性选择原理与克隆选择和免疫网络调节相结合，提出免疫融合阴性选择算法（immune integrated negative selection algorithm, II-NSA），II_NSA 在生成检测器时，经历克隆选择使远离自体的检测器快速成熟，同时经历免疫网络调节优化检测器的分布。

# ## 7.2 阴性选择算法

# ### 7.2.1 阴性选择算法概述

Forrest 等提出的阴性选择算法模仿了 T 细胞产生时的免疫耐受和非自体识别过程[44]，包括检测器生成（审查）和保护对象监视（监视）两个步骤。

NSA 算法中的检测器生成过程中，首先将合法数据定义为自体集 S；然后随机产生字符串，如果该字符串与自体集 S 中的任一字符串匹配，就被删除，否则保留下来作为检测器；如此循环迭代，直到产生足够大小的检测器集 R 为止。检测器生成过程如图 7-1 所示。
