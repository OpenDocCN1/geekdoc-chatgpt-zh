# 10.2.2 评价单元划分

评价单元是土壤资源质量评价的基本单位。在进行土壤资源质量评价之前,先要确定土壤资源质量评价的评价单元。土壤资源质量评价的评价单元的确定有四种基本方法,即以土壤类型为基础确定、以土壤资源利用现状为基础确定、以土壤资源类型为基础确定和以评价因素的组合确定。

以土壤类型为基础确定土壤资源评价单元,最早起源于美国的土地生产潜力评价或分类。该分类将对农业生产影响一致的土壤类型归在一起划成一个个土地生产潜力单元。以土壤类型为基础确定土壤资源评价单元,可用于各种比例尺的土壤资源评价。这种评价单元能够充分反映土壤在土壤资源各要素中的重要地位,同时也能够充分利用土壤普查成果。只要将评价地区的土壤图连同土壤调查报告收集起来,就可以确定土壤资源评价单元的位置与数量。但是,这样的评价单元在许多情况下往往和自然地块及行政界线不一致。

以土地利用现状为基础确定土壤资源评价单元,多用于大、中比例尺,较小范围的土壤资源评价。这样确定的土壤资源评价单元的界线与自然地块相一致,便于基层生产单位应用及土地利用结构调整。但是,当一个土地利用类型含有多个土壤资源类型时,这种土壤资源评价单元的土壤资源性质选取就很困难,使得土壤资源评价难以进行,或者评价结果不准确。

以土壤资源类型为基础确定土壤资源评价单元,多用于中、小比例尺,大范围的土壤资源评价。土壤资源类型反映了土壤资源的全部自然属性及人类活动对土壤资源的影响。它不仅体现了土壤和土地利用的差异性,还体现了土壤资源其他要素及人为活动结果的相对均一性与差异性。因此,以土壤资源类型为基础确定土壤资源评价单元更具有科学性。因此,本章构建的模型采用土壤资源类型作为土壤资源质量评价的评价单元。

以评价因素的组合确定土壤资源评价单元。将土壤类型、土地利用现状、土壤资源类型按照一定权值组合,该方法往往因权值很难确定而无法实施,较少使用。
