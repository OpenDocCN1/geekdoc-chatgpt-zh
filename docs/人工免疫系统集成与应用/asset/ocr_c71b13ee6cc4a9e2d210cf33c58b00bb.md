可定义为式(11-1)所示的二元组 Role = <name, Goals> （11-1）

式中，name 代表角色名称；Goals 代表角色关联的目标集。

根据生物免疫系统的功能组织，很自然地认为，中枢免疫组织是免疫细胞的产生中心，单核巨噬细胞是信息收集器，淋巴细胞则构成免疫监视器。相应地，RFID 人侵检测系统参照生物免疫系统进行角色划分，可建立如下的角色映射：

+   骨髓、胸腺——检测器中心。
+   单核巨噬细胞——信息收集器。
+   淋巴细胞——入侵监视器。
+   角色色承担的目标也作相应映射：
+   检测器中心——检测器产生。
+   信息收集器——抗原提呈。
+   入侵监视器——抗原识别，免疫反应。
