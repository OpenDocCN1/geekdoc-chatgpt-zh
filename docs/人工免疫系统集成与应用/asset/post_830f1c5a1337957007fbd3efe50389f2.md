

### 2) 适应度函数

求解路由由表的目的是使得网络实际运行时的话务阻塞率最小，或每条链路的溢出率最低，或整个电信网的话务负载均衡程度最好。所以评价一个路由表或者个体的优劣最直观的方法是采用解析模型或话务模拟[159]，直接对每一个个体求出一个对应的全网阻塞率或完成话务量。但是无论采用解析还是模拟的方法，计算量都很大，而每一代的每一个个体都需要计算适应度函数，这种方法会使得模型的计算量太大，所以不可能采用。考虑到话务阻塞的原因是话务整体分布不均衡，本章确定用各链路的负载均衡程度来评价路由表的优劣，即负载越均衡，适应度越高。其具体方法是，计算电信网全局的平均每线话务量和每一条链路的每线话务量，然后求每线话务量的均方差，再适当定标作为个体的适应度。参考文献[159]，本章采用记号 Line = (LineBC)n×n，Traffic = (TrafficBC)n×n，Route = (RouteBC)n×n 分别表示交换机 B、C 之间的容量表、话务量表和路由表；并引入记号 R，OTRAFFIC，具体定义如下：

$$R = (r_{BCD})_{n \times n \times n}$$

式中

$$r_{BCD} = \begin{cases} 1, & \text{route}_{BC} = D \\ 0, & \text{其他} \end{cases}$$

OTraffic = (OTrafficBC)n×n 表示链路上的溢出话务量。溢出话务量等于到达话务量乘以链路上的溢出率，计算公式如下：

$$OTraffic_{BC} = \text{Erlang}(\text{Traffic}_{BC} + \text{Traffic}_{CB}, \text{Line}_{BC}) \times \text{Traffic}_{BC}$$

在式(8-34)中，由于链路是双向的，所以把两个方向的送入话务量相加作为整条链路的到达话务量，而链路中继数满足 LineBC = LineCB。

每条链路 (B,C) 的负载率 LoadBC 计算如下：

$$\text{Load}_{BC} = \frac{\text{Traffic}_{BC} - \text{OTraffic}_{BC} + \sum_{0 \leqslant B, C, D <slant n} r_{BDC} \times \text{OTraffic}_{BD}}{\text{Line}_{BC}} + \frac{\sum_{0 \leqslant B, C, D <slant n} r_{DCB} \times \text{OTraffic}_{DC}}{\text{Line}_{BC}}$$

式中，第一项为链路 (B,C) 的直达话务量；第二项为链路 (B,C) 的溢出话务量；第三项和第四项是其他链路溢出到链路 (B,C) 上的话务量。其中，第三项是 B 通过 C 迂回到其他节点的溢出话务；第四项是其他节点通过 B 迂回到 C 的溢出话务。而全网的平均负载率用以下公式计算：

$$\text{avgLoad} = \frac{\sum_{0 \leqslant B, C <slant n, B \neqslant C} (\text{Traffic}_{BC} - \text{OTraffic}_{BC} + \sum_{0 \leqslant B, C, D <slant n} R_{BDC} \times \text{OTraffic}_{BD} + \sum R_{DCB} \times OTraffic_{DC})}{\sum_{0 \leqslant B, C <slant n, B \neqslant C} \text{Line}_{BC}}$$ (8-36)

全网的平均负载率均方差为

$$S = \frac{\sum_{0 \le B, C \le n, B \neq C} Line_{BC} \times (Load_{BC} - avgLoad)}{\sum_{0 \le B, C \le n, B \neq C} Line_{BC}}$$ (8-37)

本章将 S 采用指数定标后作为抗体的评价。

最终的抗体适应度函数如下：

$$F = e^{-S}$$ (8-38)

### 3) 免疫疫苗

在话务的峰值日，由于话务严重过负荷，造成到某些方向的话务溢出量剧增，严重地影响网络接通率，降低了网络运行的稳定性。而电信员工在长期的电信网的管理工作中，积累了丰富的话务峰值处理和其他相关的路由处理经验。把这些经验增加到系统中作为求解的参考，无疑会使求解的结果更符合实际的要求。例如，在春节的除夕夜，人们大量使用手机拜年，导致关口局到移动的中继资源不足，造成话务溢出，引起话务阻塞；或到某一方向的遇忙呼损率剧增，造成传输资源的浪费。另外，在香港“六合彩”的开奖日，由于潮阳本地网很多用户拨打深圳的某几个电话询问开奖结果，致使从潮阳到深圳方向的遇忙呼损率剧增，大量无效呼叫使潮阳长途局严重过负荷。经过分析，发现此时潮阳到广州、广州到潮阳的资源大量闲置，那么在设定路由表时，自动选择广州作为潮阳到深圳的迂回路由。因而在利用分层免疫算法求解话务动态路由时，可以利用这个经验知识设定某些路由，并把经验知识作为免疫疫苗，嵌入到模型中，以提高模型的收敛速度和解的质量。

定义 8-5 免疫疫苗(vaccine)：指根据免疫进化环境或待求问题的先验知识所得到的对最佳抗体基因的估计。免疫疫苗是从问题的先验知识中提炼出来的，其中所包含的信息量及其准确性对算法的执行效率起着重要的作用。

定义 8-6 接种疫苗(vaccination)：根据免疫疫苗修正抗体基因的过程即为接种疫苗(vaccination)，其目的是提高模型的收敛速度和求解能力。

定义 8-7 免疫选择：指对已接种免疫疫苗的个体的适应度与父代中所对应的个体进行比较，亲和力高的则为所选择的个体。

在实际的操作过程中，首先，对所求解的问题进行具体分析，从中提取出最基本的特征信息；其次，对此特征信息进行处理，以将其转化为局部环境下求解问题的一种方案；最后，将此方案以适当的形式转化成免疫疫苗并用来产生新的个体。

综上所述，为了有效地利用人脑对待求问题的先验知识，避免在完全随机的寻优算法中出现退化现象，本章提出在分层免疫算法中引入免疫疫苗。其思想主要是在合理提取免疫疫苗的基础上，通过接种疫苗和免疫选择两个操作步骤来完成。前者是为了提高个体的适应度，后者则是为了防止群体的退化。具体而言，它们分别是：

- (1) 接种疫苗。设有个体 \(x_i \in \mathbf{R}^a, x_i = (x_i^1, x_i^2, \cdots, x_i^a)\)。给其接种疫苗是指按照先验知识修改 \(x\) 的某些分量，使所得个体以较大的概率具有更高的适应度。这些先验知识可以是最优抗体某些分量的大概取值范围，也可以是一些分量之间一定的制约关系。设有群体 \(X = (x^1, x^2, \cdots, x_N)\)，对 \(X\) 进行接种疫苗操作就是在 \(X\) 中按比例 \(a\) 随机抽取 \(N_a ::= aN\) 个个体而进行的一种操作。

- (2) 免疫选择。免疫选择就是对已接种免疫疫苗的个体进行检测。如果已接种免疫疫苗个体的适应度不如其父代，则说明在变异的过程中已发生了严重的退化现象。此时可由其父代个体代替其参与竞争选择[231]。

### 4) 利用特征信息制作免疫疫苗

为了利用用户积累的经验制作免疫疫苗以提高分层免疫算法的收敛速度，本章在利用该模型求解路由时设立了禁用节点。禁用节点是指两个交换局不允许用某些交换局做路由迂回节点。利用禁用节点制作的疫苗也称为禁用节点疫苗。目前禁用节点疫苗的来源主要有三种方式：① 最小中继数阈值；② 最大溢出率阈值；③ 用户经验。下面分别予以简单介绍。

- ① 最小中继数阈值。

最小中继数阈值是指在电信网中，设定一个最小中继数阈值 minlines，只有中继数大于此阈值的链路才可以作为其他链路的迂回，此阈值的设定是为了保护中继容量小的链路，一般设 minlines=60。当链路 \((B, D)\) 或链路 \((D, C)\) 的中继数小于最小中继数时，\(D\) 被禁止用作链路 \((B, C)\) 的迂回节点。

记 FORBID=(Forbid_{BCD})_{n \times n \times n}，其中

$$Forbid_{BCD} = \begin{cases} 1, & \text{如 } D \text{ 被禁止作为链路 } (B,C) \text{ 的迂回节点} \\ 0, & \text{其他} \end{cases}$$ (8-39)

则分层免疫算法对每一个 \(B, C, D (0 \leqslant B, C, D < n, B, C, D\) 互不相等) 作以下判断：

if (Lines_{BD} < minlines \text{ or } lines_{DC} < minlines) \text{ then } Forbid_{BCD} = 1 (8-40)

- ② 最大溢出率阈值。

最大溢出率阈值是指设定一个最大溢出率 maxoverflowrate，只有溢出率小于此值的链路才可以作为其他链路的迂回。这里的溢出率指的是直达话务量的溢出率。为了保证链路的服务质量，长途网对链路直达话务量的溢出率有一个上限。目前设 maxoverflowrate=0.05。当链路（B，D）或链路（D，C）的溢出率大于最大溢出率时，D 被禁止用作链路（B，C）的迂回节点。模型对每一个 B,C,D(0 ≤ B,C,D < n,B,C,D 互不相等)作以下判断：

if (Block_BD > maxblockrate or Block_DC > maxblockrate)
then Forbid_BCD = 1 (8-41)

- ③ 用户经验。

除了利用最小中继数阈值、最大溢出率阈值作为禁用节点疫苗以外，还可利用电信员工在日常网络管理、维护中积累的经验设计禁用节点疫苗。例如，省际或国际长途中转局一般不用来作为其他链路的迂回。

为了解决怎样在分层免疫算法中引入禁用节点疫苗的问题，本章在路由求解过程中创建禁用表。禁用表是一个矩阵，记录了每两个交换局之间不可以用作迂回节点的交换局的数目和不可用的迂回交换局的编码。在初始群体生成和变异操作需要随机产生一个 i,j 之间的迂回节点时，随机生成一个属于 [1,n] 的整数，然后与禁用表中的编码进行比较，如果相同，则再次生成，直至不同为止。这样随机生成的迂回节点必然满足禁用节点经验的要求。禁用表的引入也减小了搜索空间。假设在具有 43 个交换机的网络中，每两个交换机间平均有 10 个禁用节点，则可用的节点最多只有 31 个，故搜索空间减小为 31^42×43 = 31^1806 ≈ 10^2693。

### （2）话务变化规律疫苗。

通过对广东省固定电信网网络运行情况的分析，我们发现话务变化具有一定的规律性。①在话务的峰值日，由于话务严重过负荷，造成到某些方向的话务溢出量剧增，严重地影响了网络接通率，并降低了网络运行的稳定性。②在本地网内可预计的海量呼叫，如已知的热线、电视台节目，由于用户大量拨打这些热线电话，导致话务拥塞，加重了交换系统的负荷，也造成了交换和传输资源的浪费。③对某运营商各本地网话务调查的结果表明，话务高峰时段分别是平时高峰时段、除夕高峰时段和其他节假日（包括周末、中秋、国庆等）高峰时段。通过利用话务变化规律，设定相应的路由表，生成话务变化规律疫苗，并将其引入到分层免疫算法中抗体的变异操作中，可以提高算法收敛速度和解的质量。

## 8.6 分层免疫动态路由评估模型应用实例

“网络话务控制关键技术研究及应用”项目中的基于分层免疫算法的动态路由评估模型是广东省省内长话网路由的辅助决策工具。由于模型涉及整个广东省的长话路由，在系统真正投入使用之前，必须经过测试。而作为电信网全网的路由决策系统，它一旦出现错误会影响到整个电信网的话务质量，所以测试不适宜在全网展开。本章首先选择几个交换局组成一个子网进行测试，这个子网被视为一个独立的网络，与省网内的其他交换局完全不发生联系。测试前通过网管系统采集测试数据，测试完之后，将数据删除，以免影响网络业务运行。本章利用三组数据进行测试，第一组和第二组数据主要对基于分层免疫算法的路由评估模型进行测试，第三组数据对基于分层免疫算法的路由评估模型与其他优化算法进行测试比较。
