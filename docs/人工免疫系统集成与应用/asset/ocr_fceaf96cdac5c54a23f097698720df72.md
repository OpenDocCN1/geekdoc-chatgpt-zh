# 3. 变异操作

免疫算法作为一种搜索算法，变异操作在该算法中显得尤为重要，它不但有可能恢复在进化中被破坏的较优抗体基因，而且可以产生抗体群中没有的较优基因。同时变异操作也是免疫算法用来维持抗体（候选解）群的多样性的主要途径之一，通过该操作可以使算法最终收敛于多个局部极小点或收敛于全局最优点。另外，控制抗体是否产生变异的变异率的取值既不能太大也不能太小，太小变异操作的效果不明显，群体的多样性不能保证，因而不能收敛于全局极小点；但是变异率也不能太大，太大则群体的稳定性比较差，搜索过程需要长时间才能收敛，容易出现振荡。因此，如何确定合适的变异率使免疫算法既可搜索到全部极小点，又可保持稳定收敛的状态，是设计免疫算法过程中需要重点考虑的因素之一—[147]。

# 4. 其他相关参数

抗体群的规模（即群体中解个体的数目 n ）一直是免疫算法的一个重要参数，它是影响算法并行性和群体多样性的决定性因素之一。如果抗体群的规模设置太小，则并行搜索的范围太小，难以找到所有极值；如果抗体群的规模太大，又会不必要地延长搜索过程所需要的时间，影响算法的收敛速度[147]。

记忆库规模也是影响免疫算法性能的因素之一。它在免疫算法中作为搜索结果不仅给下一次同类问题搜索提供初始结果，而且在本次搜索过程中作为每一代的较优抗体参与下一代群体的竞争。同时，免疫算法的多极值搜索目标使得记忆库规模对搜索的性能影响较大。在运行代数相同的情况下，记忆库规模太小，有些极值点可能由于比率太高导致抗体选择率不太高，被排除在记忆库之外，不能在搜索过程中保留下来，从而影响群体的多样性。而记忆库规模太大，不但会增加算法的复杂性，也可能会导致记忆库中的抗体对新一代群体影响过大，算法的收敛速度也较慢[102,147,148]。

另外，在免疫算法中，抗体浓度阈值的设置对抗体的多样性也具有重要影响，从而影响算法的性能。同时，浓度阈值同种群规模息息相关，通常，对于不同的问题，有不同的种群规模，其浓度阈值可在一定范围内变化。因此，对于免疫算法来说，针对问题的特点，选择适当的浓度阈值、记忆库的规模及抗体群规模等无疑会提高算法的效率和性能。

# 8.3 分层免疫算法

由 8.2 节的分析可以看出，亲和力度量方式、变异操作、克隆选择操作、记忆库规模、抗体群规模等免疫算法的参数和操作算子，对算法的性能有非常大的影响。
