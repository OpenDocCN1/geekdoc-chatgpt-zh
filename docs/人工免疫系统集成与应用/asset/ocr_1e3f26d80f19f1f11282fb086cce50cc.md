# 5.3 矢量距 AiNet

# 5.3.1 改进方法

从 AiNet 算法的算法流程可以看出，AiNet 算法主要采用克隆抑制和网络抑制来保证群体的多样性，从而使抑制阈值极大地影响 AiNet 算法的最终网络结构和大小。为了降低抑制阈值对 AiNet 算法的影响，本章在 AiNet 算法中采用一种新的抗体促进和抑制机制，以便在鼓励适应度高的抗体的同时，限制浓度较高的抗体，增强群体的多样性，并减少参数特别是抑制阈值对 AiNet 算法的影响，从而使 AiNet 算法达到降低计算成本，加快模型的收敛速度，减少人为主观因素影响的效果。

抗体促进和抑制机制的关键是确定抗体的浓度，目前计算抗体的浓度有许多种方式。例如，采用 Euclidean 距离、Manhattan 距离、Hamming 距离等评价抗体的相似性，进而计算抗体的浓度，但这些方式受抗原、抗体的编码机制影响。例如，在二进制形态空间中，存在 Hamming 悬崖。采用 Hamming 距离等进行抗体浓度的评价就有一定缺陷。也有研究提出采用信息熵计算抗体的浓度，但这种方式同样也受编码机制的影响，同时，信息熵的计算复杂，设置的参数需要凭经验调节和含有冗余的计算信息，从而导致算法收敛速度慢[107]。通过对生物免疫系统特征的进一步挖掘，本章提出采用矢量距来评价抗体的浓度。

矢量距就是将抗原、抗体分别对应于聚类问题的目标函数和优化解 \( C_i \)，抗体的适应度函数为 \( f(C_i) \)。\( N \) 个抗体构成了一个非空免疫系统集合 \( X \)。规定抗体 \( C_i \) 在集合 \( X \) 上的距离为

```
\( S(C_i) = \sum_{j=1}^{N} | f(C_i) - f(C_j) | \quad (5-2) \)
```

式(5-2)也是抗体的矢量距定义式。则由矢量距的定义，抗体的浓度可用式(5-3)表示

```
\(\text{Density}(C_i) = \frac{1}{S(C_i)} = \frac{1}{\sum_{j=1}^{N} | f(C_i) - f(C_j) |} \quad (5-3) \)
```

计算出每个抗体的浓度之后，便可以通过选择机制进行抗体的促进和抑制调节。抗体 \( C_i \) 的选择概率 \( p_i \) 由适应度概率 \( p(f(C_i)) \) 和浓度抑制概率 \( p(d(C_i)) \) 两部分组成。

```
\( p_i = a p(f(C_i)) + (1-a) p(d(C_i)) \)
\( = a \times \text{fitness}(C_i) \big/ \sum_{i=1}^{N} \text{fitness}(C_i) + (1-a) \frac{1}{N} e^{-\frac{\text{Density}(C_i)}{\beta}} \quad (5-4) \)
```
