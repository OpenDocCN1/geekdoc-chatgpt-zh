# 10. 免疫调节机制

免疫反应的机制本身是自组织、自我调节的，没有中心组织控制免疫系统的功能。免疫反应的调节大致分为两个方面：①体液免疫，由 B 细胞和它们的产物介导；②细胞免疫，由 T 细胞介导。这两个方面对防御遵循类似的步骤——增殖、激活、分化、袭击、抑制和记忆等。

# 11. 免疫动力学描述

免疫系统的动力学描述主要是针对抗原的增殖和效应细胞对抗原的杀伤这类最基本的免疫现象展开的。在建立免疫系统的模型之前，把免疫系统视为一个复杂的巨系统，它包含以下部分：①各种免疫细胞；②多种免疫分子；③与基因有关的主要组织相容性复合物和自身抗原；④外界入侵的抗原。这些组分之间存在复杂的非线性的相互作用。利用非线性数学理论来研究免疫学，首先需要选择一个或若干个描述系统状态的变量。而免疫系统是由不同层次（如分子、细胞和器官）和每一层次所包含的多种组分形成的复杂系统，并且在不同层次和不同组分之间存在着复杂的相互作用。利用非线性数学工具来刻画这些变量的关系，能得出各种组分的时间演化过程，从中认识免疫系统的运动规律、机制和功能[1~4,7]。

# 2.4 人工免疫系统分析

# 2.4.1 形态空间

在免疫系统中，B 细胞和 T 细胞是最重要的细胞之一，免疫系统的特异识别是 B 细胞和 T 细胞结合特异抗原的过程。B 细胞和 T 细胞与抗原之间的形状越互补，它们之间的亲和力越高。为了在 AIS 中定量地描述 B 细胞和 T 细胞等免疫细胞分子和抗原之间的相互作用，Perelson 等于 1979 年提出形态空间（shape-space）模型[58]。形态空间描述抗原和与之结合的抗体分子之间的结合程度。形状和电荷分布，以及存在于合适互补位置的化学物质是决定抗原与抗体之间的相互作用的关键因素，Perelson 称这些因素的集合为分子的泛化形态（generalized shape）。如用参数 L 描述一个抗体的泛化形态，则包括其长度、宽度和结合部位的凸起或者凹槽的高度等特征。抗体的泛化形态用 Ab=<Ab1, Ab2, ..., AbL> 表示，抗原的泛化形态用 Ag=<Ag1, Ag2, ..., AgL> 表示。形态空间主要是为了描述抗原与抗体的形状及它们之间的相互作用而提出的，包括抗体的编码机制、抗体识别多样性、亲和力度量等。目前形态空间已成为研究 AIS 的重要工具之一。
