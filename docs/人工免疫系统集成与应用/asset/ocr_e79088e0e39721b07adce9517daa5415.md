# 8.4.3 有效性分析

下面通过多峰值函数对分层免疫算法与免疫操作进行比较，分析分层免疫算法的有效性。实验对象为下列多峰值函数：

$f(x) = \exp(-(x - 0.1)^2) \times \sin^6(5\pi x^{3/4})$ (8-25)

把二进制字符串 $m = \langle m_l, \cdots, m_2, m_1 \rangle$ 从 2 基转换到 10 基

$(\langle m_l, \cdots, m_2, m_1 \rangle)_2 = (\sum_{i=0}^{21} m_i \times 2^i)_{10} = x$ (8-26)
