组成集对后关于第 $t$ 个因素($t=1,2,3$)的同异反联系度为 $\mu_k = a_k^t + c_k^t j$，经过分析，同一度取为 $a_k^t = \bar{x}_t / 2$，对立度采用倒数型对立：$c_k^t = a_2^t / \bar{x}_t$。由此根据表 4.4.4 数据得如下联系度：

\(\mu_3^1=0.545+0.183j, \mu_3^2=0.614+0.163j, \mu_3^3=0.602+0.166j\)
