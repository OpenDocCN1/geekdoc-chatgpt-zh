# 8.4.2 科技交流中语言及语言理解非对称的集对分析

专业术语存在名称与所指代对象并非完全一一对应的非对称二元性现象，从而给科技信息交流带来一定影响。为此，陈玥从集对分析的视角，探讨科技术语的同义性、多义性和同形异义性，以及词汇学和语言学中普遍蕴含的同异反，认为这种现象不仅体现出人类的语言智慧和丰富的生活情趣，也促使着人类语言不断发展。详见文献[2]的 208-213 页。
