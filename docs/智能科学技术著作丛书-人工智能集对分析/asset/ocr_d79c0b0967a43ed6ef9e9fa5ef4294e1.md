μ活鲫鱼 = 0.432 + 0.370i₁ + 0.101i₂ + 0.005i₃ + 0.002j        (9.3.9)

由于 0.432 + 0.370 = 0.802 > 0.55，所以活鲫鱼的风险等级综合评定结果为 M(中风险)，这一结果与进出口食品监管部门的历史决策结果相符。

# 9.3.3 简评

综合评定进出口食品的风险在进出口食品安全监管专家系统中有重要意义。把集对分析中的多元联系数用于进出口食品的风险综合评价有其方便合理之处，但在把综合评价结果多元联系数计算成一个具体数值的同时也丢失了这个多元联系数的结构信息，因此在下结论的时候，至少需要顾及这方面的信息，例如，由表 9.3.4 可以看出，活鲫鱼中的农兽药残留、添加剂和生物毒素等指标处于超高风险或高风险等级，但由于这些指标的权重较小，在综合评价过程中被权重大的指标掩盖，所以综合结果为中等风险，换言之，综合评定结果 M(中风险) 中仍有可能包含着部分指标的“高风险(L, H, HH, HHH)”，这也是 9.1 节中所述成对原理(整体与部分成对存在)，同异反原理(同样是综合后评定为中等风险的指标，其不同的子指标会有低、中、高、超高不同的风险等级)和不确定性原理(不确定性有不同的表现和不同的处置原则，例如，文中采用置信度原则，其实还可以采用极值原则、效用原则等)的具体体现；显然，进出口食品监管部门不仅需要看到综合评定结果，也需要看到局部指标的高风险可能造成的危害，联系数的伴随函数如同异反态势函数，势函数等已为这方面分析提供了具体分析手段，专家系统中需要设置相应的模块处置这类情况，文献[3]中已提到上述思路。
有关进出口食品安全监管专家系统的更多内容请参考文献[3]。
