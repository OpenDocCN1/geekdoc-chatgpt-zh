实际上，系统要素之间的同、相异、不同这三种关系都会存在，也就是既有相异的要素，又有相同的要素，还有在一定程度上相似的要素。需要通过计算相似比后进行综合分析，得出相似与否的判定结论。

# 4. 5. 2 基本思路

+   (1) 设集合 A 由 k 个要素组成，集合 B 由 l 个要素组成，其中有 n 个要素是相同的，即为集合 A 与 B 共有，n≤min(k, l)，则 n 个相同要素组成的集合是 A 与 B 的交集 A ∩ B；A 与 B 所有要素组成并集 A ∪ B。

以 z(X) 表示某一集合 X 中要素的个数，则有

Z(A) = k;
Z(B) = l;
Z(A∩B) = n;
Z(A∪B) = Z(A) + Z(B) − Z(A∩B) = k + l − n。

由于 A, B 中要素总数和相同且要素个数已知，故 A, B 的相似程度可用 Q 值度量，即有

Q = \frac{Z(A \cap B)}{Z(A \cup B)} = \frac{n}{k + l - n}  (4. 5. 1)

显然：0 ≤ Q ≤ 1；当且仅当 A = B 时，k = l = n, Q = 1；当 A, B 不相交时，n = 0, Q = 0。

+   (2) 设集合 A 与 B 分别由 k 和 l 个要素组成，其中有 f 个要素既不相同也不相异，f ≤ min(k, l)，这 f 个要素组合构成 p 个相似元，第 j 个相似元中两要素的相似程度记为 qj (j = 1, 2, ⋯, p)。这种情况与式 (1. 3. 7) 中 i ∈ [0, 1] 时 b 相对应。此时 i 值可取为

i = \frac{1}{p} \sum_{j=1}^{p} q_j  (4. 5. 2)

从而，这 p 个相似元引起 A, B 的相似程度为

Q = \frac{f}{k + l - f} \cdot \frac{1}{p} \sum_{j=1}^{p} q_j  (4. 5. 3)

显然，当 qj = 0 (j = 1, 2, ⋯, p) 时，Q = 0；当 qj = 1 时，等同式 (4. 5. 2)。作为一种特例，若 A, B 要素个数相同，且 A 中每一要素分别与 B 中每一要素构成相似元，k = l = f，则

Q = \frac{1}{p} \sum_{j=1}^{p} q_j  (4. 5. 4)
