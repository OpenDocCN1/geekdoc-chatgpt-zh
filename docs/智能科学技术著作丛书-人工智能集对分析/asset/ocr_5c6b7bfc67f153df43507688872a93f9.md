# 3) 工序分配方案评价指标

在工序 li 可以被分配到多个制造单元的前提下，综合考虑制造单元当前的负载和加工成本，则将工序 li 分配到制造单元 Vi 上的评价指标为

```
maxF | (li · Tci) | = 1/li + 1/Tci (11.4. 8)
```

由式(11.4. 8)可知，将工序 li 分配到制造单元 Vi 上时，由此带来的加工成本越小，插入前制造单元的负载率越低，则该工序分配方案的评价值也就越大。在综合考虑制造单元当前的负载和加工成本时，选择 F 值最大的工序分配方案。当 OL 中的全部工序都完成分配后，则整个工艺路线也就实现了对当前生产线网络的插入。

# 3. 建立基于制造稳定性的评价指标

由复杂网络的特性可知，网络在不同的拓扑结构状态下的脆性风险大小不同，即系统稳定性不同。由企业生产线网络的形成机制可知，插入不同的初始工艺路线将形成不同拓扑结构的生产线网络，因此网络的脆性测度值可作为评判工艺路线制造稳定性的指标。这里定义混线生产网络脆性风险熵作为评判工艺路线制造稳定性的指标，将每一个制造单元 Vi 都当成一个子系统 Gi，则插入 OL 后形成的生产线网络的脆性风险熵为

```
ρ(OL) = - Σ [ (α · Li + β · Xi)M(Gi) / Σ (α · Li + β · Xi)M(Gi) ] · log(α · Li + β · Xi) (11.4. 9)
```

式中，复载率 Li = Sin / Σ Sin，即 Li 为 Gi 的节点入强度 Sin 与总入强度的比值；Xi 为子系统 Gi 发生故障的概率，假设 Gi 的随机性故障 I 包含 t 个事件（设备故障、刀具磨损等），即 I = {I1, I2, ..., It}，事件 Ii 发生的概率为 Pi，则 Xi = 1 - Π (1 - Pi)；M(Gi) 代表子系统 Gi 崩溃对整个生产线网络 G 的影响程度，可映射为聚类系数 Ci 与总聚类系统的比值，即 M(Ci) = Ci / Σ Ci；常数 α, β ∈ [0, 1]，且满足 α + β = 1，反映子系统 Gi 在进行脆性计算时的侧重程度。
