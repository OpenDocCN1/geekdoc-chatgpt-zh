等于计算指标值的标准差与均值的比率，反映了单位均值上的离散程度，\(\theta_r = \frac{\sigma_r}{Ex_y}, \theta_p = \frac{\sigma_p}{Ex_p}\)。在有个限待决策评价方案内，一个评价指标的变异系数越大，说明该指标值间的差异性就越大，对最终决策的影响程度就越大。\(Ex_y = \frac{1}{r} \sum_{i=1}^r \gamma(O_{Li})\)，表示经验指标值的均值；\(Ex_p = \frac{1}{r} \sum_{i=1}^r \rho(O_{Li})\)，表示制造稳定性指标值的均值；\(\sigma_y = \sqrt{\frac{\sum_{i=1}^r (\gamma(O_{Li}) - Ex_y)^2}{r}}\)，表示经验指标值的均方差；\(\sigma_p = \sqrt{\frac{\sum_{i=1}^r (\rho(O_{Li}) - Ex_p)^2}{r}}\)，表示制造稳定性指标值的均方差。

+   4) 计算加权同一度

得到权重向量 \(W=[\omega_y, \omega_p]\) 后，将其与同一度矩阵进行复合，可得到加权同一度向量 \(U' = U W^T\)。\(U'\) 中第 \(i\) 个元素 \(u_i\) 就是工艺路线 \(O_{Li}\) 与理想方案的同一度。根据加权同一度向量 \(U'\) 中 \(u_i\) 值的大小确定出工艺路线的优劣次序，\(u_i\) 值最大者为最佳加工方案。
