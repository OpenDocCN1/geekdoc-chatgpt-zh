# 8.5 本章小结

本章中，我们首先基于客观事物普遍联系的观点，把自然语言定义为是自然界中事物相互联系的工具，进一步把自然语言分成无机物之间的语言和有机物之间的语言。人类的语言仅仅是有机物语言的一个子集，这不仅是对现有人工智能知识体系中关于自然语言理解的一种观念上的一种突破，也是当今地球上的人类正在积极探索地外生命，特别是地外星人，试图与地外星人展开交流的需要。因为这种探索和交流首先是地球人借助安装在空间飞行器上的智能机来实现；如果把对自然语言的指称和理解限定在人类语言这个子集上，无视地外星人的语言也是自然语言的一个子集，显然无助于这种智能机上的语言系统研发。本章的这部分内容是本书的一个创新点，也是本书与已有其他人工智能专著的一个区别，基于此认识给出了基于集对分析的语言和语言理解三原理，不确定性原理是其中的核心内容。其次，以中文语言为例，介绍了语言和语言理解三原理在人类语言理解智能化研究中的应用，包括概念集对分析中的应用和研究方法集对分析中的应用；之后给出的两个对话例子，从实用的角度说明了语言和语言理解三原理的实用意义和理论意义，核心思想是对人类语言和语言意义的理解不能仅限制在人类语言文字文本本身，而是要结合非文字文本来展开理解，如对话中对话双方的相互认知与了解
