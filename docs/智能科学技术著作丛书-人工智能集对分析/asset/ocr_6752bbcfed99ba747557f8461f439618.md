# 2.2.5 赵森烽-克勤概率

由于随机事件 A 与 \bar{A} 成对存在，又因互不相容而在某次随机试验中随机出现其中之一，所以用 P(A, \bar{A}) 表示 A 或 \bar{A} 出现的概率，并约定 (A, \bar{A}) 中的 A 为主事件，\bar{A} 表示 A 的伴随事件；由此导出赵森烽-克勤概率(联系概率)——一种基于主事件 A 发生的大数概率和主事件 A 不发生的即或概率的联系数表达式。

```
P_c(A) = P(A) + [1 - P(A)]i
```

式(2.2.1)中的 P_c(A) 表示联系数意义下事件 A 在某次随机事件中发生的可能性大小 P(A) (A 的大数概率) 与不发生的可能性大小 1 - P(A) (A 的即或概率) 的“联系和”，即赵森烽-克勤概率，也称联系概率，P_c(A) 中的下标“c”是“联系”(connected) 的意思。

有时，也把式(2.2.1)写成

```
P(A, \bar{A}) = P(A) + P(\bar{A})i
```

在式(2.2.1)和式(2.2.2)中，i 代表不确定性，定义 i 在 [ \frac{-1 - P(A)}{1 - P(A)}, 1 ] 根据不同情况取不同的值。因为就随机试验的结果看，P_c(A) = P(A) + P(\bar{A})i 有 -1 (伴随事件发生) 与 1 (主事件发生) 两个值，解方程 P_c(A) = P(A) + P(\bar{A})i = -1 得 i = \frac{-1 - P(A)}{1 - P(A)}；解方程 P_c(A) = P(A) + P(\bar{A})i = 1 得 i = 1，由此才能刻画出每一次随机试验的实际结果。

例如，袋子中有 2 个白球和 3 个黑球，设抽到白球为主事件 A，抽到黑球为事件 \bar{A}，在任抽一球是白球时，有赵森烽-克勤概率 P_c(A) = P(A) + P(\bar{A})i = \frac{2}{5} + \frac{3}{5}i = 1，解得这时的 i = 1。当实际抽到的球是黑球时，站在主事件 A 的角度，其相应的赵森烽-克勤概率 P_c(A) = P(A) + P(\bar{A})i = \frac{2}{5} + \frac{3}{5}i = -1，解得这时的 i = -\frac{7}{3}。如果以 \bar{A} 作为主事件，把 A 看成 \bar{A} 的伴随事件，则相应的赵森烽-克勤概率为 P_c(\bar{A}) = P(\bar{A}) + P(A)i = \frac{3}{5} + \frac{2}{5}i，这时如果任抽一球是黑球，则有 P_c(\bar{A}) = P(\bar{A}) + P(A)i = \frac{3}{5} + \frac{2}{5}i = 1，解得 i = 1；如果任抽一球是白球，则有 P_c(\bar{A}) = P(\bar{A}) + P(A)i = \frac{3}{5} + \frac{2}{5}i = -1，解得 i = -4。可见在同一问题中选择不同的事件作为主事件，把与之不相容的另一事件作
