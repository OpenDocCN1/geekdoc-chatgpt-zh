的技术会被设法改进，特别是对于“反”，所采用的技术会被淘汰或更新；如此等等。正是在这个意义上，集对分析是对人工智能技术基础的一个支撑。

以上简略地论述了人工智能的科学基础和技术基础，也简略地指出了集对分析可以作为人工智能科学基础和技术基础的支撑，重点是对人工智能科学基础与技术基础的论述，3.4 节对人工智能基础集对分析作进一步阐述。

# ## 3.4 人工智能基础集对分析

# ### 3.4.1 人工智能科学基础的集对分析

+   1. 数学与物理学的集对分析

从人工智能原理这个角度看，数学与物理学不仅单独为人工智能基础提供了科学原理，也通过两门学科的相互联系和相互交叉为人工智能提供原理性基础，如系统的确定性与不确定原理，就是由物理学中的“测不准原理”与数学中的“哥德尔不完备性定理”共同支撑，这是数学与物理学在人工智能基础方面的一个重要共同点。不同点之一是物理学中有能量转换与守恒这个原理，在数学中没有与之相对应的原理，但实际智能计算在计算机上实现时，存在机器发热和能耗问题，如何使机器在能耗最小条件下完成需要的智能计算，是一个需要研究的问题。不同点之二是对信息的认识，经典物理学中并没有专门对信息的研究，本书作者首次从物理学角度提出信息的实质是物质与能量相互作用的产物，从信息产生的这一来源可知信息具有能量，称为信息能，自然界中的风、雨、电闪、雷鸣、日照等，都是重要的自然信息，这些自然信息承载着物质与能量毫无疑问；但人工智能中把数字看成是信息，难道数字也承载着物质与能量？这是一个需要深入研究的问题，当然，从理论上说，把数学与物理作为人工智能基础并无不妥。

+   2. 数学与哲学的集对分析

从人工智能原理这个角度看，哲学作为人工智能基础在逻辑与情理之中。因为从逻辑上说，哲学对诸多自然科学来说是一种鸟瞰式的指导性学科，对人工智能的哲学指导自在情理之中，特别是哲学给出的普通联系原理和对立统一原理，已经蕴含了“事物或概念都是成对存在”这个“成对原理”；而“成对原理”又是集对分析提出基本概念“集对”的依据；“集对”概念把两个有联系的集合作为一个基本的数学运算分析单位，是对集合论的一种提升，而集合论是数学的基础，数学是人工智能的基础，数学与哲学就这样携手为人工智能提供坚实的基础。
