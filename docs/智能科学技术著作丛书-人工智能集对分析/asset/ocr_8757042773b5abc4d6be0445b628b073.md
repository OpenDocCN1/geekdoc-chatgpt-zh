# 步骤 6 与其他方法的比较与分析。

文献[7]和[8]分别用 TOPSIS 方法和相对隶属度法处理本例，得到的结果都
是 $S_4>S_5>S_3>S_1>S_2$，与步骤 5 的结果 $S_4>S_5>S_1>S_3>S_2$ 相当接近，仅仅是
$S_3$ 与 $S_1$ 的排序结果不一致，但文献[7]和[8]都是一次性排序，没有作不确定性分
析；文献[9]综合应用 TOPSIS 方法和相对隶属度法处理本例，得到的排序结果是
$S_4>S_1>S_5>S_3>S_2$，除 $S_4$ 与 $S_2$ 的排序与步骤 5 相同，其他 3 个方案的排序与步
骤 5 结果不相同，也与文献[7]的结果不相同，也是一次排序，也没有做不确定性分
析。因此，相对来说，通过不确定性分析所得的排序结果更为可靠。

事实上，如果把联系数 $\mu = a + bi \ (i \in [0,1])$ 看成是实数轴上的区间数\([a \cdot a + b]\)时，则可以看出：当 \(i=0\) 时，相当于取区间数的左端点进行决策；当 \(i=1\) 时，
相当于取区间数的右端点进行决策；当 \(i=0.5\) 时，相当于取区间数的中间值进行决
策，虽然从区间数反映各属性在给定范围内取值具有随机性的角度出发，还可以取
其他的值，从而得到其他的排序结果；但分别和交叉地取区间数的左右两个端点和
中间值所得到的排序作为研究内容，仍然具有一定的代表性和说明力。

本例说明，基于联系数不确定性分析的智能决策特点，一是通过联系数中 \(i\) 的
不同取值实现不确定性分析；二是检验方案排序的抗不确定性，保证基于集对分析
智能决策得到的方案排序具有较好的稳定性；三是把得到的结果与其他方法所得
结果比较，比较结果也不外乎是“同”（与其他方法的决策建议相同）“异”（与其他方
法的决策建议有差异）“反”（与其他方法的决策建议之差异大到相反的程度），这也
符合人脑决策时常常把自己要做的决策与他人商议、听取他人意见以提高决策科
学性与有效性的习惯；如果这时决策者能进一步利用计算机对比较结果作进一步
研究，根据再研究结果作出决策，显然会提高决策的科学性和实用性，参考第 3 章
给出的智脑概念，可知这种根据“再研究结果”作出的决策是一种智脑决策。
