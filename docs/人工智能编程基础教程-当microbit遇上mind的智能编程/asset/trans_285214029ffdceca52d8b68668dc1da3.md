# 第6课 发送和接收信息

## 活动目标

1.了解`Micro：bit`之间的无线通信方式。
2.掌握在两个`Micro：bit`之间进行信息传递的方法。

## 学习内容

我们可以通过`Micro：bit`的蓝牙天线发送和接收信息（见图6-1）。

![](images/txt006_1.jpg "pagenumber_ebook=41,pagenumber_book=34")

图6-1

打开`Mind+`，鼠标单击编程模块栏中的![](images/txt006_2.jpg "pagenumber_ebook=41,pagenumber_book=34")，右侧出现指令积木块列表，其中有![](images/txt006_3.jpg "pagenumber_ebook=41,pagenumber_book=34")和![](images/txt006_4.jpg "pagenumber_ebook=41,pagenumber_book=34")。如果要使一个`Micro：bit`向另一个`Micro：bit`发送信号，需要将两个`Micro：bit`的蓝牙通信状态设置为打开状态，并且将两个`Micro：bit`的无线通信频道设置为相同频道，以方便相互通信，编程指令如图6-2所示。

①将`Micro：bit`和电脑连接，在上传模式中，选择`Micro：bit`对应的端口。
②鼠标单击![](images/txt006_5.jpg "pagenumber_ebook=41,pagenumber_book=34")，加载主控板，然后鼠标双击“micro：bit”。

# 第7课 翻译传感器的语言

## 活动目标

1.学习在串口监视器窗口查看传感器的实时数据。

# 第8课 音乐响起来

## 活动目标

1.了解`Micro：mate`的基本构造。
2.学习使用`Micro：mate`播放音乐的功能。

## 学习内容

`Micro：mate`（见图8-1）是与`Micro：bit`配套的一款多功能I/O扩展板，扩展板上的多个3Pin接口支持上百款电子元件，它还有一个3.5mm的音频输出接口，背面附带防反接的胶垫。`Micro：mate`安装很方便，只用两个黄铜螺母就可以安装。

![](images/txt008_1.jpg "pagenumber_ebook=52,pagenumber_book=45")

图8-1

## 动手操作

### （1）连接硬件

①将`Micro：bit`和`Micro：mate`固定在一起（本书后面提到的`Micro：mate`都是与`Micro：bit`固定在一起的），如图8-2所示。
②将组合了`Micro：mate`的`Micro：bit`和电脑连接，并且将喇叭或者耳机通过数据线与`Micro：mate`的`P0`接口相连接（见图8-3）。`P0`接口可以输出声音信号。

![](images/txt008_2.jpg "pagenumber_ebook=53,pagenumber_book=46")

图8-2

![](images/txt008_3.jpg "pagenumber_ebook=53,pagenumber_book=46")

图8-3

③鼠标单击![](images/txt008_10.jpg "pagenumber_ebook=54,pagenumber_book=47")上的“低C/`C3`”，虚拟琴键弹出（见图8-5）。鼠标在琴键上移动，琴键底部显示对应的标记，如“中C/`C4`”。“`C4`”中的“`C`”与“`C4`”分别表示音符与音高。“`C3`”中的“3”表示低音，“`C4`”中的“4”表示中音，“`C5`”中的“5”表示高音。`C`、`D`、`E`、`F`、`G`、`A`、`B`则分别表示简谱中的`Do`、`Re`、`Mi`、`Fa`、`So`、`La`、`Si`。

图8-5
