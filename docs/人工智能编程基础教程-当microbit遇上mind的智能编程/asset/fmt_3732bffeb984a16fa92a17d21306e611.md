# 第14课　打开物联网大门

## 活动目标

1.了解OBLOQ的功能。
2.学习向物联网开放平台发送和接收消息。

## 学习内容

物联网是在互联网基础上延伸和扩展的网络，它将各种信息传感设备与互联网结合起来，形成一个巨大的实用网络，其目标是在任何时间、任何地点，实现人、机、物的互联互通。

物联网主要的组成部分是一个网络平台，以及可以和这个网络平台进行通信且能够无线联网的硬件设备。

OBLOQ是一款基于ESP8266芯片设计的串口转WIFI物联网模块（见图14-1），它可以依托Easy IoT物联网开放平台接收和发送数据与通信指令（见图14-2）。我们通过电机驱动扩展板将OBLOQ和Micro：bit相连接，再借助Mind+，就能迅速搭建出一套物联网智能装置。
