1.  检查训练数据上的损失

2.  检查验证数据上的损失
    *   执行正向传播
    *   计算误差
3.  开始训练
    *   执行正向传播
    *   反向传播误差
    *   更新权重

学习的概念是人工智能的基础。 我们希望机器了解学习的过程，以便他们可以自己完成学习。 人类通过观察周围环境并与周围环境互动来学习。 当您去一个新地方时，您可以快速扫描并查看周围发生的事情。
