# 完美音调

变电站中的泰勒沃克斯机器人可以接收一定音调的命令（由音叉振荡器产生），处理代码并通过（例如）打开开关做出反应。

这台机器人会与指挥中心的另一台泰勒沃克斯进行通信，发出编码声，表明命令已经执行。
