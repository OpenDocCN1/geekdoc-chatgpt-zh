# 一个红色或白色的世界

沙基可以用摄像机“看”，可以用猫须传感器“感觉”，还可以在实验室里自主导航。实验室里有一个由孤立的棱柱块组成的迷宫，就像孩子们的游戏区。沙基世界里的一切都被涂成白色或红色，以便让机器人的单色视觉能够看得更清晰，还能反射足够的光支撑激光测距仪的工作。
