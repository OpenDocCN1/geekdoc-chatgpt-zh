零空间矩阵 \( J(N) \) 存在对雅可比比矩阵 \( J \) 的依赖性，也就是说 \( J(N) \) 可以通过 \( J \) 计算得出。这里定义 \( J^\dagger \) 为 \( J \) 的右逆矩阵，也即满足 \( J^\dagger J = I \)。一个常用的零空间矩阵可以通过右逆矩阵 \( J^\dagger \) 来构造，通常按如下公式求解，即

```
$$N = I - J^{\dagger}J$$ $$J^{\dagger} = J^{T}(JJ^{T})^{-1}$$
```

借助零空间矩阵，可以计算任务空间速度到关节空间速度的映射关系，即

```
$$\dot{q} = J^{\dagger}\dot{\boldsymbol{x}} + N\dot{q}_{\forall}$$
```

这里的 \(\dot{q}_{\forall}\) 为任意的关节空间速度向量。

将式 (3-88) 等号两边同时乘以雅可比矩阵 \( J \)，可以验证该公式的正确性，即

```
$$J\dot{q} = JJ^{\dagger}\dot{\boldsymbol{x}} + JN\dot{q}_{\forall}$$ $$= I\dot{\boldsymbol{x}} + 0\dot{q}_{\forall}$$ $$= \dot{\boldsymbol{x}}$$
```

根据以上结果，通过借助雅可比矩阵 \( J \) 构造零空间矩阵 \( N \)，能够在尽可能保证工作空间任务 \(\boldsymbol{x}\) 完成的前提下，使关节可以按照 \(\dot{q}_{\forall}\) 的速度任意运动，以此来实现其他额外的低优先级任务。这种充分利用关节冗余特性，同时保证多个控制任务的控制方法即为机器人全身控制。
