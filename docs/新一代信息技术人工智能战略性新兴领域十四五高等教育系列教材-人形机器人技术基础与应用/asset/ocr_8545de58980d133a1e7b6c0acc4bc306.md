到坐标系 {1} 中，其局部坐标为 $^1\mathbf{p}$。点 P 相对于坐标系 {0} 的坐标可表示为

$${}^0\mathbf{p} = {}_1^0\mathbf{R}^1\mathbf{p} + {}^0\mathbf{d}$$ (2-52)

现在，考虑三个坐标系 {0}、{1} 及 {2}。令 $d_1$ 表示从坐标系 {0} 原点到坐标系 {1} 原点的向量，同时令 $d_2$ 表示从坐标系 {1} 原点到坐标系 {2} 原点的向量。如果点 P 被固定连接到坐标系 {2} 中，并且其局部坐标为 ${}^2\mathbf{p}$，可以通过式 (2-53)、式 (2-54) 来计算点 P 相对于参考坐标系 {0} 的坐标，即

$${}^1\mathbf{p} = {}_2^1\mathbf{R}^2\mathbf{p} + {}^1\mathbf{d}_2$$ (2-53)

以及

$${}^0\mathbf{p} = {}_1^0\mathbf{R}^1\mathbf{p} + {}^0\mathbf{d}_1$$ (2-54)

可以用这两个公式的叠加来定义第三个刚性运动，该运动的描述可以通过将式 (2-53) 代入式 (2-54) 中而得到，即

$${}^0\mathbf{p} = {}_1^0\mathbf{R}_2^1\mathbf{R}^2\mathbf{p} + {}_1^0\mathbf{R}^1\mathbf{d}_2 + {}^0\mathbf{d}_1$$ (2-55)

由于 ${}^0\mathbf{p}$ 和 ${}^2\mathbf{p}$ 之间的关系也是一个刚性运动，所以可以使用同样的表示，即

$${}^0\mathbf{p} = {}_2^0\mathbf{R}^2\mathbf{p} + {}^0\mathbf{d}_2$$ (2-56)

通过比较式 (2-55) 和式 (2-56)，可以得到

$${}_2^0\mathbf{R} = {}_1^0\mathbf{R}_2^1\mathbf{R}$$ (2-57)

$${}^0\mathbf{d}_2 = {}^0\mathbf{d}_1 + {}_1^0\mathbf{R}^1\mathbf{d}_2$$ (2-58)

式 (2-57) 指出姿态变换可以简单地被相乘在一起，同时式 (2-58) 指出从原点 $O_0$ 到原点 $O_2$ 的向量所对应的坐标等于 ${}^0\mathbf{d}_1$ 和 ${}_1^0\mathbf{R}^1\mathbf{d}_2$ 之和，其中 ${}^0\mathbf{d}_1$ 是从 $O_0$ 到 $O_1$ 的向量在参考坐标系 {0} 中的坐标，${}_1^0\mathbf{R}^1\mathbf{d}_2$ 则是从 $O_1$ 到 $O_2$ 的向量在坐标系 {0} 中的坐标。
