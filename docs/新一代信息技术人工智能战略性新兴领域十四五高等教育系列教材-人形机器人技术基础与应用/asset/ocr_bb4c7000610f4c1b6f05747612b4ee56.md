踪任务、动量跟踪任务等。下面介绍几种常见任务的表示方法。同样，在关节加速度空间 \(\dot{v}\) 中考虑如何表示任务，统一表示为

```
\( A\dot{v}_{des} = b \) (9-10)
```

下标 des 表示待优化求解的量。针对构造任务的核心就是计算出 \( A \) 和 \( b \)，然后作为二次规划问题的代价或约束。

关节加速度任务：表示让部分关节运动到期望关节加速度，所以此时 \( A \in R^{nj \times (6+n)} \) 是一个选择矩阵，其中 \( nj \) 表示选择的关节个数，\( b \) 就是期望关节加速度。

```
\( A=[0 \cdots 0 \ 1 \ 0 \cdots 0], \ b = \dot{v}_{des} \) (9-11)
```

(1) 空间加速度任务 该任务用来表示两个刚体按照期望空间加速度相对运动。假设刚体 \( k \) 相对于刚体 \( j \) 的变换矩阵为

```
\( H_k^j(t) = \begin{bmatrix} R_k^j & p_k^j(t) \\ 0 & 1 \end{bmatrix} \) (9-12)
```

引入空间代数表示方法，记旋量（twist）为

```
\( T_k^{m,j} = \begin{bmatrix} \omega_k^{m,j} \\ v_k^{m,j} \end{bmatrix} \in R^6 \) (9-13)
```

旋量为刚体 \( k \) 相对于刚体 \( j \) 在刚体 \( m \) 参考系的表示，则有

```
\( T_k^{m,j} = J_k^{m,j} v \) (9-14)
```

式中，\( J_k^{m,j} \) 为几何雅可比。对式 (9-14) 两边求导并整理有

```
\( J_k^{m,j} \dot{v} = \dot{T}_k^{m,j} - \dot{J}_k^{m,j} v \) (9-15)
```

式中的 \( \dot{T}_k^{m,j} \) 常用双测地线 PD 控制器（double-geodesic pd control law）计算（选择 \( m=k \)），则

```
\( \dot{T}_{k,des}^{k,j} = \begin{bmatrix} K_{P,\omega} \log_{SO3}(R_{k_r}^k) \\ K_{P,v} p_{k_r}^k \end{bmatrix} + K_D \dot{T}_{k_r}^{k,k} + \dot{T}_{k_r}^{k,j} \) (9-16)
```

该任务最终表示为

```
\( A = J_k^{m,j}, \ b = \dot{T}_k^{m,j} - \dot{J}_k^{m,j} v \) (9-17)
```
