# 图 2-6 方块绕 z0 轴旋转角度 pi

在局部坐标系 {l} 中，点 Pb 的坐标可被表示为 1pb 。为获取它相对于参考坐标系 {0} 的坐标，使用式 (2-9) 中的旋转矩阵，得到

```
0pb = 10R 1pb = Rz,π 1pb
```

同时，由于 1pb 是相对于方块自身的坐标系来定义的，方块端点的局部坐标 1pb 并不随方块旋转而变动。所以，在方块坐标系 {l} 与参考坐标系 {0} 下，坐标 1pb 等于坐标 0pa （因为在进行旋转之前，点 Pa 正好与方块的端点重合）。因此，可以得到

```
0pb = Rz,π 0pa
```

此公式展示了如何用一个旋转矩阵来表示旋转运动。特别是，如果点 Pb 是由点 Pa 按照旋转矩阵 R 转动而得到的，那么相对于参考坐标系的坐标由下式给出

```
0pb = R 0pa
```

同样的方法可被用于相对于一个坐标系来旋转向量。

