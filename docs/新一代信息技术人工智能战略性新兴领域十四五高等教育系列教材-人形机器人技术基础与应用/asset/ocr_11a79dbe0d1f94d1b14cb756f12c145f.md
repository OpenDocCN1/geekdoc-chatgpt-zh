# 余弦定理

如果一个三角形的边长分别为 \(a\)、\(b\)、\(c\)，并且 \(\theta\) 是与边 \(c\) 相对的角度，那么有

$$c^2 = a^2 + b^2 - 2ab \cos \theta$$
