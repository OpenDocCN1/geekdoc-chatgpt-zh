# 4. 控制器

在非线性轨迹优化的结果中，通常包含了跳跃过程中各个时刻机器人的关节位置、速度、加速度和力矩等详细信息。基于这些优化结果，可以设计一个简洁高效的控制器，其中将优化结果中的力矩作为前馈力矩，提供跳跃所需的主要能量输出。此外，优化结果中的关节角度和速度可作为关节的期望状态，通过关节的 PD 控制器来补偿关节跟踪误差，从而实现精确控制。所以，关节力矩方程为

```
\(\tau = \tau_{feed\_forward} + k_p q_{error} + k_d \dot{q}_{error}\) (9-57)
```

除此之外还可以利用 MPC、WBC、NMPC+WBC 以及 RL mimic 来实现对轨迹的更精确的跟踪。
