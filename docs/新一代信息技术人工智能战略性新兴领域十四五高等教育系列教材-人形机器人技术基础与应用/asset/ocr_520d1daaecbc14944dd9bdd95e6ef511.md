# 附录 A 常用符号表

| 符号 | 描述 |
|---|---|
| ${}^0P$ | 参考坐标系 \(\{0\}\) 中的一个点的位置向量 |
| ${}_0^1R$ | 坐标系 \(\{1\}\) 相对于坐标系 \(\{0\}\) 的旋转矩阵（姿态），\(3\times3\) 矩阵 |
| \(R_{z,\theta}\) | 绕 z 轴转动 \(\theta\) 角的基本旋转矩阵 |
| \(SO(n)\) | \(n\) 阶 \(n\times n\) 的特殊正交群 |
| \(R_{ZYZ}\) | ZYZ- 欧拉角变换 |
| \(SE(3)\) | 特殊欧氏群 |
| \(T\) | 齐次变换矩阵，\(4\times4\) 的矩阵 |
| \(a_i\) | 连杆长度 |
| \(\alpha_i\) | 连杆转角 |
| \(\theta_i\) | 关节角 |
| \(d_i\) | 连杆偏距 |
| \(\sigma_i\) | 关节类型，1 表示移动关节，0 表示转动关节 |
| \(v\) | 线速度 |
| \(\omega\) | 角速度 |
| \(\mathcal{V}\) | 6 自由度的速度和角速度矢量对（也称为双矢量），也称旋量 |
| \(\mathcal{R}\) | 空间旋转变换 |
| \(\mathcal{T}\) | 空间平移变换 |
| \(\mathcal{X}\) | 组合空间变换 |
| \(J\) | 雅可比矩阵 |
| \(q\) | 关节角矢量 |
| \(I\) | 惯性张量 |
| \(F\) | 作用力 |
| \(N\) | 引起刚体转动的力矩 |
| \(M(q)\) | 惯性矩阵 |
| \(()^\vee\) | 李代数元素映射到相应的向量 |
