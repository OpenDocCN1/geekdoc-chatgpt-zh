# (2) 数据预处理

主要是对数据仓库中通风机故障的原始数据进行清除，去掉噪声，去掉冗余和不完全的信息。

# (3) 知识库的形成

知识库的规则来源有三个方面：

+   ① 原有的规则。

通过对通风机的实验分析，形成特征向量与主要的故障关系的规则信息，它为知识库的形成提供了原始的知识。

+   ② 不确定性推理获得的规则。

+   a. 利用获取的数据仓库数据，将通风机特征向量定义为条件属性，其故障类型定义为决策属性。将每一个条件属性和决策属性划分类别（见表 8-7）。
