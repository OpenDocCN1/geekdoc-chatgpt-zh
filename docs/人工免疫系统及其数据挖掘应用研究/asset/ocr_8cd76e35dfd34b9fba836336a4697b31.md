# (4) 监测

监测主要是根据历史数据和知识库数据来判断通风机设备的状况。这也是规则匹配的过程，即从规则库中提取规则，与在线获得的通风机各条件属性进行比较来测试决策属性的值，从而判断通风机该时刻的运行状态。通过风机故障知识库的建立和数据挖掘技术的应用，实现了风机故障的在线监测，提高了系统运行的可靠性。
