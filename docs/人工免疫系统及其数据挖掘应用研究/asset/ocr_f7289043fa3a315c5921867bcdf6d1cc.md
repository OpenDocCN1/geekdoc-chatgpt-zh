# 2.3.4 抗体指令系统

# (1) 抗体指令系统多样性

抗体指令系统多样性是指免疫系统能够产生多种多样的抗体来应对自然界几乎无限多种的抗原。因为免疫系统检测通过抗体结合病原体抗原来实施，要保证结合的效率和有效清除抗原，治愈感染，免疫系统就必须有充分的多样性淋巴细胞受体指令系统（解释），确保至少有一些淋巴细胞能够结合任何给定抗原决定基。

# (2) 抗体指令系统多样性机制

抗原激活的 B 细胞抗体指令系统基本通过两种机制实现多样化：高频变异和受体编辑（receptor editting）[17]。

免疫学研究成果表明，免疫系统除了淋巴细胞克隆选择外，还进行受体分子选择。取代所有自身反应细胞克隆删除的是 B 淋巴细胞经历的受体编辑（基因重组，rearrangement），即这些 B 细胞已经删除它们的自身反应抗体，通过基因重组发展全新的受体。虽然编辑和受体选择不是 Bumet 模型的一部分，但是如果受体选择在细胞选择之前发生，克隆选择理论肯定适合受体编辑。任何通过体细胞高频变异或者编辑产生的高亲和力克隆体都会被优先选择扩充；但是为了保持群体（指令系统）多样性，也允许几个低亲和力细胞进入指令系统。

抗体指令系统不但要通过高频变异机制实现多样化，而且必须存在选择少量具有高亲和力变异受体的 B 细胞主导应答的机制。由于体细胞变异过程的随机性，很大比例的变异基因成为非功能性或者发展出有害的抗自身特异类型基因，这些细胞带有低亲和力受体，或者是自身反应细胞，必须被清除（或成为能量），因此它们对记忆细胞池没有显著贡献，清除危及抗原结合能力的 B 细胞的具体机制目前还不十分清楚，但细胞凋亡（apoptosis）肯定是一种清除方式，也是一个微弱细胞的死亡过程，经常等同于程序
