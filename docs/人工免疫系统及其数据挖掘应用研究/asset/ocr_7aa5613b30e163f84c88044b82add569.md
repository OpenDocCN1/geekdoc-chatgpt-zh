+   - step1：输入抗体数据集；
+   - step2：初始化产生随即关联规则集 ARBs；
+   - step3：提呈抗原给网络，计算 ARB 的刺激水平；
+   - step4：根据刺激度对每个 ARB 分配相应数量的 B 细胞，没有分配到 B 细胞的 ARB 从网络中删除；
+   - step5：计算 ARB 的刺激水平；
+   - step6：根据刺激度进行 ARB 的克隆，采取固定变异率进行变异；
+   - step7：判断终止条件是否满足，如满足继续，不满足转 step3；
+   - step8：产生关联规则输出，结束。
