数。由于在改进的网络中，NAT 值在每次迭代过程中重新计算，所以它与网络的进化是相适应的。

# 6.2.1.2 刺激度值 sl 的选定

根据本章前面的分析，本文改进的算法中采用距离 d 的平方形式计算 sl(ab_i, ag_j) 的值，即取 sl(ab_i, ag_j) = [1 - d(ab_i, ag_j)]^2，它体现了 d 较小时刺激度值 sl 所应具有的优势，并且对较小的 d 值并不过分敏感。

如表 6-1 所列的 d1, d2 值可得出 |Δsl / Δd| = 233.8, 而对表 6-2 中的数据可得出 |Δsl / Δd| = 12.4, 前者大于后者，由此可知在较小 d 值时，sl 对 d 值变化的敏感性相对减小，而在 d 值较大时，d 值的变化对刺激度值 sl 的影响也相对较小；同时也充分体现了当 d 值较小时，d 的变化对刺激度值 sl 的优越性。此种 sl 的算法与纯粹的线性算法相比更能体现 d 值较小时 sl 具有的优势。应当注意的是，在本章改进算法中，求 d(ab_i, ag_j) 原始数据集也应当先 0-1 标准化。

# 6.2.2 资源分配函数 Ri 的选择和克隆变异

# 6.2.2.1 资源分配函数 Ri 的选择

在网络的 B 细胞资源被分配时，需要考虑以下因数：在网络学习的初期，应该考虑到网络中的 ARB 可能离抗原较远，亲和力较小的情况，选择的资源分配函数 Ri 应该使其刺激水平会相对增大，从而保证较优良的 ARB 不被清除出网络；在网络进化到一定代数之后，相关抗原均有较近的 ARB 匹配，ARB 与抗原的亲和力相对有所增大，此时的资源分配函数 Ri 应该使网络中亲和力较高的 B 细胞（或抗体）得到抑制。因而选择一个适当资源分配函数 Ri，能很好地帮助产生较好的网络结构。
