# 第 2 章 生物免疫系统

# 2.1 免疫系统简介

在自然界生物系统中，免疫是指生物机体在病毒感染痊愈后，对病毒感染具有抵抗能力而不再患疫病或传染病。免疫系统由免疫活性分子、免疫细胞、免疫组织和器官组成，它具有识别机制，能够判别人体中自体细胞和感染的细胞，或是判别出自身分子（self molecules）[1~3]和外因感染的微组织，这些微组织是指引起感染的非自体组织、病原体或者非自体元素（nonself elements），同时，免疫系统还能消除病毒等病原体本身以及因感染而引起的机能不良、功能紊乱、官能障碍等症状。在这个过程中，宿主体内的免疫系统效应细胞（effector）负责识别并清除外界环境中人侵的病原体及其产生的毒素，以及内环境中因基因突变产生的肿瘤细胞，实现免疫防卫功能，保护机体内环境稳定。免疫系统几乎可以识别无限多种外界环境中人侵的细胞和物质，免疫效应细胞对病原体或病毒细胞产生适当应答并清除它们，这个情况是执行正常的免疫功能，但另一方面，免疫效应细胞也会产生不适当应答反应，如果应答过高，会导致过敏性疾病；如果应答过低，易导致严重的感染，对自身组织发生应答，导致自身免疫疾病，均会对机体有害，这些都属于免疫失调。免疫系统能够“记忆”每一种感染源，这样当同样的感染再次发生时，免疫系统会更迅速地反应并更有效地处理。
