# (2) 免疫记忆理论解释

免疫记忆的问题在于 B 细胞只能活几天，一旦感染消除，不知道什么使 B 细胞适应的子群体组织逐渐消失。目前有两个理论：一种理论认为，适应性记忆细胞是长寿的，存活期与有机体的生命期一样长；另一个理论推断适应性 B 细胞不断地被体内多年积累得到的非自体蛋白质的痕迹所重新刺激。

适应性免疫应答有三个基本特征，即处理大量多样性抗原、区分自体与非自体、长时间持续的免疫记忆。克隆选择理论认为，免疫系统记忆是通过扩展一个特异抗原克隆大小来提供的，随机变异能增强亲和力，再者，自体反应细胞在发展时期会被克隆删除。关于免疫系统中如何获得记忆还有两个观点。最广泛的一种是使用 B 细胞的概念，B 细胞被抗原刺激并产生记忆细胞和效能细胞。另一个是实验免疫学家很少支持但理论免疫学家很支持的理论——使用免疫网络的概念。该理论阐明网络内部网络动态的保持记忆，适应反馈机制。
