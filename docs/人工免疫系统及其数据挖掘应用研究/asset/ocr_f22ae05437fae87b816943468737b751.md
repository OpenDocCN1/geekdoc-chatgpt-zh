# 5.1.6 仿真实验

这里通过两个实验验证所提出的分类算法性能。首先将该算法用于机器学习中的一个典型数据集——人体特征分类，然后我们用 3 个 UCI 的机器学习数据集[9]对该算法的性能进行了测试，并将该分类算法的实验结果与其他方法的结果进行了比较。

# 实验 1 人体特征分类数据

人体特征分类数据如表 5-1 所列，身高 = {高，矮}，头发颜色 = {金，红，黑}，眼睛颜色 = {蓝，灰，黑}，类别 = { A，B }，记录数为 12 个。
