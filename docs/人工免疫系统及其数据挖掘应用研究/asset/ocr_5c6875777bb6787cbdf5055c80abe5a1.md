# 5.2.2.2 关联规则的表示

设一条关联规则为： $A_1 \land A_2 \land \dots \land A_n \Rightarrow B_1 \land \dots \land B_m$ [Support, Confidence]，简记为：$X \Rightarrow Y$ [Support, Confidence]。其中：$A_i (i=1, 2, \dots, n)$ 称为决策属性；$B_j (j=1, 2, \dots, m)$ 称为任务属性；Support 为支持度；Confidence 为置信度。 Support = $P(X \cup Y)$； Confidence = $P(Y/X)$。

关联规则 $X \Rightarrow Y$ [Support, Confidence] 可解释为：所有研究对象中，满足条件 X 的占百分比为 Support，满足条件正同时又满足条件 Y 的概率为 Confidence。例如，在购物者信息库中发现关联规则：

age(x,"20···29") \land income(x, 2 千···3 千)
=>buy(x,"CD_player") [Support = 2%, Confidence = 60%]

其中，x 是代表顾客的变量。该关联规则的含义是：所有顾客中 20 到 29 岁且月收入在 2 千元到 3 千元的顾客占 2%，而这些顾客购买 CD-player 的可能性是 60%。
