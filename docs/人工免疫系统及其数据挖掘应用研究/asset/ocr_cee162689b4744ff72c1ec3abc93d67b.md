# 第 6 章 改进的资源有限人工免疫系统及其关联规则挖掘算法

# 6.2.3 仿真实验及分析

为了验证这个改进的算法，本章分析了两个数据集。一个是原始数据有 50 个，二维的有五个聚类的线性可分数据集 [图 6-3 (a) ∼ 图 6-3(d)]。图 6-3(c) 是 NAT 变化的对比，从图 6-3(c) 中看：MRLAIS 的 NAT 在网络运行的初始阶段有震荡，但很快就稳定在一个水平上，这说明随着网络迭代次数增加，网络进化在逐渐趋于抗原所具有的模式。图 6-3(d) 网络体积的变化对比，从图中也可以看到 MRLAIS 比 RLAIS 更快地达到稳定的网络结构，而RLAIS 达到稳定的网络结构要相对滞后，并随着迭代次数的增加会出现震荡现象。

实验的另一个是 Iris 数据集 [图 6-4(a) ∼ 图 6-4(d)] 的大小为 294。

在实验中迭代 60 次，MRLAIS 网络达到了稳定，NAT 变化情况和网络体积的变化与第一个实验结果基本相同，只是网络获得稳定模式需要迭代更多的次数。

在所做的所有仿真实验中，该免疫网络均可在 30 ∼ 70 代以后即达到稳定，NAT 和网络大小在平衡位置附近作较小的波动。经过多次仿真实验，可得出一个结论，对网络最终结构影响最大的是 NAT 的取值。
