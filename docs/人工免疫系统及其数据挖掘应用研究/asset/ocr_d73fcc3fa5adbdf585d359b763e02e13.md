# 7.1.1 免疫应答

为切实模拟免疫机理构造设计网络,有必要对免疫应答过程做一个回顾。当免疫系统第一次遇到某一类型的抗原时,只有少数的免疫细胞能识别该抗原的缩氨酸,能够识别抗原的细胞受到激励,进行快速的自身复制,该过程即为克隆扩增(clonal expansion)。克隆扩增的过程同时伴随着超频变异(hypermutation),也就是在细胞复制过程中,细胞产生一定的变异,使产生的克隆越来越能够识别抗原。大部分克隆在干扰素、细胞因子等分子的作用下分化为浆细胞,浆细胞能够产生抗体以清除人侵抗原,这个过程称为首次应答(primary response)。少量的克隆分化为记忆细胞,如果有类似的抗原人侵,会导致更快的和更多的抗体产生,这个过程称为二次应答(secondary response)。这里要注意的是,不一定要完全相同的抗原的人侵,类似的抗原人侵也会导致二次应答。
