# 4.3.7 算法描述

step1: 分析问题。对问题及其解的特性进行分析和了解，并设计解的合适表达形式。将抗原和抗体分别对应于待求解的问题 X 和问题的一个解 xi，亲和度函数对应于最优函数值 f(xi)。

step2: 产生初始抗体群体。随机产生 N 个抗体，再随机产生 M 个抗体放入记忆库中，由这 (N+M) 个抗体构成初始抗体群体。

step3: 对抗体群体中各抗体进行评价，按式 (4-15) 计算抗体 v 的距离浓度 C(xi)；按式 (4-12) 计算抗体的亲和度 D(xi)；按式 (4-16) 计算抗体的期望繁殖率 E(xi)。

step4: 形成父代群体。将抗体群体按 E(xi) 的降序排列，并取前 N 个个体构成父代群体；同时取前 M 个个体作为记忆细胞更新记忆库中的抗体。

step5: 判断是否满足结束条件。可设定最大运行世代数作为终止条件，或判断连续迭代一定次数后抗体亲和度函数值没有变化作为终止条件。一旦条件满足则输出记忆库中的最优解，结束运算。否则继续下一步操作。

step6: 抗体的增殖和分化。基于 step4 的计算结果，按照其评价标准，从抗体群体中确定父代群体后进行抗体变异，选择按二进制位变异或实数交叉与非均匀变异方法产生新抗体。变异产生的新抗体和原有的父代群体一起构成新一代抗体群。

step7: 执行 step3。
