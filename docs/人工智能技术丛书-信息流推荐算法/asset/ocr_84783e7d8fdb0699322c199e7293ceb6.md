```
\(\theta \leftarrow \argmin_{\theta} \sum_{(s,a) \in B} (a - C_{\theta}(s))^2 + \text{KL}(E_{\theta}(z | s, a) | \mathcal{N}(0,1))\)
```

式中，2个正态分布的KL散度定义如下：

```
\(\text{KL}(E_{\theta}(z | s, a) | \mathcal{N}(0,1)) = -1.0 + 2 \cdot \log \frac{1}{\sigma} + u^2 + \sigma^2\)
```

为了增强变分自编码输出动作的多样性，接下来进一步利用扰动网络 \( P_{\omega}(s, a, \rho) \) 来调整动作。给定用户状态 s，变分自编码的解码部分可以根据不同的正态分布采样输出多个动作 \( \{ \hat{a}_i \sim C_{\theta}(s) \} \) ，同时扰动网络生成相同数目的扰动 \( \xi_i \) 叠加到动作 \( \hat{a}_i \) 上。状态 s 下选择 Q 值最大的动作：

```
\(\pi(s) = \argmax_{\hat{a}_i + \xi_i} Q(s, \hat{a}_i + \xi_i)\)
```

最优动作的选择如图6-14所示。扰动网络的参数更新沿用DDPG中的方法：

```
\(\omega \leftarrow \argmax_{\omega} \sum_{s \in B} Q(s, \hat{a} + P_{\omega}(s, \hat{a}, \rho)) \quad \hat{a} \in C_{\theta}(s)\)
```

# (3) Critic网络

Critic网络用于评估在状态 s 下执行动作 a 的累积奖励 \( Q_\omega(s, a) \) 。和常规方法一样，建立了 4个子Critic网络，两个当前网络 \( Q_{a} \) 和 \( Q_{b} \) ，两个目标网络 \( Q_{a}' \) 和 \( Q_{b}' \) 。Critic网络使用时间差分损失（TD-error）：

```
\(\theta_j \leftarrow \argmin_{\theta_j} \sum_{(s,a) \in B} [y - Q_{\theta_j}(s, a)]^2, j \in \{1, 2\}\)
```

式中，y 表示学习目标，其定义如下：

```
\(y = r + \gamma \max_{a'} [\min_{j=1,2} Q_{\theta_j}(s', a')]\)
```
