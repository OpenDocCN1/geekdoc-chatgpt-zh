$w_i^{(t+1)} = \underset{w_i}{\text{argmin}} |z_i^{(t)} \cdot w_i + \lambda_1| |w_i| + \frac{1}{2}(\lambda_2 + \sum_{s=1}^t \sigma^{(s)}) w_i^2$ (5-66)

L1正则项在0处不可导，假设 $w_i^*$ 是其最优解，则 $w_i$ 对 $w_i$ 的次导数如下：

\(\partial |w_i^*| = \begin{cases} (-1, 1) & \text{如果 } w_i^* = 0 \\ 1 & \text{如果 } w_i^* > 0 \\ -1 & \text{如果 } w_i^* < 0 \end{cases}\) (5-67)

对式 (5-66) 求导得：

$z_i^{(t)} + \lambda_1 \partial |w_i^*| + (\lambda_2 + \sum_{s=1}^t \sigma^{(s)}) w_i^* = 0$ (5-68)

假设 $w_i^* < 0$ , 则按照导数为0求得

$w_i^* = - (\lambda_2 + \sum_{s=1}^t \sigma^{(s)})^{-1} (z_i^{(t)} - \lambda_1)$

$(\lambda_2 + \sum_{s=1}^t \sigma^{(s)}) > 0$
