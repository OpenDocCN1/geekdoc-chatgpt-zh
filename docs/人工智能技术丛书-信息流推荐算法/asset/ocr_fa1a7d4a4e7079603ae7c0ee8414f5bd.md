# (1) 基于胶囊网络的兴趣聚类

在模型的多兴趣抽取层，我们以用户行为序列 { e1， e2， e3 } 转换为兴趣向量 { u1， u2 } 为例子，具体介绍胶囊网络的计算迭代过程。

如图3-44所示，用户行为序列 { e1， e2， e3 } 经过一层共享的线性映射 S 得到浅层胶囊

![](bbox=[0.125, 0.626, 0.331, 0.663])

，浅层胶囊再经过动态地权重分配（ wjj 参数），得到第二层胶囊 { z1， z2 }，第二层胶囊代表了用户多兴趣表达的锥形，具体计算方法是按不同的权重对行

![](bbox=[0.291, 0.685, 0.542, 0.76])

为序列进行加权求和 。第二层胶囊经过squash函数后得到深层胶囊 { u1， u2 }， uj=squash ( zj )，作为胶囊网络输出的用户多兴趣向量。
