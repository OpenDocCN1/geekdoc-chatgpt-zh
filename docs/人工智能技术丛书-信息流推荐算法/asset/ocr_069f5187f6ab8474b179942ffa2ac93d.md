+   1) { w^k } 的序列可能不会收敛到最优解，并且式（5-7）中的目标函数值也不能保证是逐渐下降的。

+   2) 虽然 X \in \mathbb{R}^{l \times n} 是比较稀疏的，但是 Hessian 矩阵中的 X^T D X \in \mathbb{R}^{n \times n} 为规模很大（实际业务中，n 至少是 10 万的量级）的稠密矩阵。采用普通的牛顿法求解需要存储这个稠密矩阵并求矩阵的逆，在实际中可行性很低。

为了解决第一个问题，可以采用置信域的方式，设计目标值下降评估的同时调整牛顿方向的前进幅度。对于第二个问题，可以利用共轭梯度来求解（共轭梯度常用于求解 Ax = b），在求解过程中主要的操作为 Hessian 矩阵和向量的计算：

```
\nabla^2 f(w) s = (\mathcal{J} + C X^T D X) s = s + C \cdot X^T (DX_s) \qquad (5-13)
```

在 X 为稀疏矩阵的情况下，可以在不保存 Hessian 矩阵 \nabla^2 f (w^k) 的情况下进行高效的计算。下面给出置信域牛顿法求解 LR 的细节。

在第 k 轮参数迭代中，当前参数为 w^k，置信区域的大小为 \Delta_k，根据共轭梯度求解的标准形式可以反推出当前问题的二次型模型：

```
q_k(s) = \nabla f(w^k)^T s + \frac{1}{2} s^T \nabla^2 f(w^k) s \qquad (5-14)
```

式中，q_k (s) 从泰勒展开的角度来看近似于 f (w^k+s) - f (w^k)。接下来，需要找到牛顿方向 s^k，在满足 ... < \Delta_k 的情况下最小化 q_k (s)。接下来计算第二次模型预估下降和真实下降的比值：

```
\rho_k = \frac{f(w^k + s^k) - f(w^k)}{q_k(s^k)} \qquad (5-15)
```

如果比值 \rho_k 大于阈值，说明近似预估求解到的牛顿方向是置信的：

```
w^{k+1} = \begin{cases} w^k + s^k, & \text{如果 } \rho_k > \eta_0 \\ w^k, & \text{如果 } \rho_k \leqslant \eta_0 \end{cases} \qquad (5-16)
```

式中，\eta_0 > 0，是一个预先设置好的超参数。置信域大小 \Delta_k 的更新规则如下：

```
\begin{cases} \Delta_{k+1} \in [\sigma_1 \min \{ \|s^k\|, \Delta_k \}, \sigma_2 \Delta_k] & \text{如果 } \rho_k \leqslant \eta_1 \\ \Delta_{k+1} \in [\sigma_1 \Delta_k, \sigma_3 \Delta_k] & \text{如果 } \rho_k \in (\eta_1, \eta_2) \\ \Delta_{k+1} \in [\Delta_k, \sigma_3 \Delta_k] & \text{如果 } \rho_k \geqslant \eta_2 \end{cases} \qquad (5-17)
```

式中，\eta_1 < \eta_2 < 1, \sigma_1 < \sigma_2 < 1 < \sigma_3，均为大于 0 的超参。整体求解流程包含一个外循环和一个内循环，外循环的部分如下。
