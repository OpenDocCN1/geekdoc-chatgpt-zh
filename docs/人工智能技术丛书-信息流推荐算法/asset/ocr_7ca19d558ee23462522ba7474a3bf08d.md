# 图3-31 EGES的算法框架

EGES在通过加权平均的方法融合物品Id和Side Info特征后，接下来的模型结构与DeepWalk基本一致，仍然套用Skip-gram加Negative Sampling的方法。图3-31中，稀疏特征层输入的物品Id及Side Info在稠密Embedding特征层转化为向量，并在隐层表达处进行加权融合，因此进入输出层的不是直接的物品向量，而是向量组的加权和，所以EGES把这种方式定义为Weighted Skip-gram。

综合来看，EGES就是考虑了Side Info特征及其权重的一个DeepWalk进阶版，通过Side Info的加入，提升了物品向量的表征能力，也在一定程度上缓解了物品冷启动问题。
