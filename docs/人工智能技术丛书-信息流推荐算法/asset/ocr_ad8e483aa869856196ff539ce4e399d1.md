# 2.模型训练

MWUF针对指定数据集的训练过程可以拆解为两步。第一步利用全量的数据训练一个基础的推荐模型，其参数包括Embedding部分的 $\phi$ 和其余的参数 $\theta$ 。预训练的基础模型整体效果良好，但是对于冷启动物品来说不友好。第二步训练拉伸和偏移网络来优化冷启动物品ID的Embedding表示。为了防止对于非冷启动物品的影响，参数 $\phi$ 和 $\theta$ 是固定的。为了训练这两个网络，需要从样本中筛选数据按照时间戳排序，以模拟物品的冷启动过程。
