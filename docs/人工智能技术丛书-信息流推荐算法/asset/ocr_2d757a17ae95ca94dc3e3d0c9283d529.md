# （1）广义矩阵分解（Generalized Matrix Factorization, GMF）

仅使用GMF的Neural CF（·, ·）实现方式可以看作图3-9的左边部分，如式（3-26）所示，它首先采用向量的元素积（Element-wise Product）[也称为阿达马积（Hadamard Product）]的形式，将用户和物品向量映射到同一个空间，然后通过DNN及Sigmoid激活函数得到最终的预测目标：

```
\(\hat{y}_{ui} = \sigma(h^T(P_u \odot Q_i))\) (3-26)
```

当GMF中的DNN只有一个神经元且参数矩阵 h^T 的元素值固定为1，并且输出部分的激活函数为恒等变换时，NCF就退化成了一个矩阵分解模型，所以GMF可以看作一种通过DNN加持、以Sigmoid函数为输出映射函数的矩阵分解方法，所以称为广义矩阵分解。
