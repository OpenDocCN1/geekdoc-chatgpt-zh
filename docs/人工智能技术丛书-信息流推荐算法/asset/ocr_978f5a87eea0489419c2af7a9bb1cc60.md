# (3) 动态知识蒸馏模块 (Dynamic Knowledge Distillation)

从前一个模块中可以看到模型结构中包含了冷启动专家网络和非冷启动专家网络，不过由于Cold & Warm Net主要解决冷启动用户的优化问题，因此更关注于冷启动专家网络的效果。为了评估每一个专家网络的效果，直接用其输出和物品表示计算相似度：

```
$$y_{cold\_score} = \frac{E_{cold} \cdot E_i}{\|E_{cold}\| \|E_i\|}$$ (9-26)

```
$$y_{warm\_score} = \frac{E_{warm} \cdot E_i}{\|E_{warm}\| \|E_i\|}$$ (9-27)
