# 4.2.1 checkbox 组件

```
<checkbox-group style="margin:30rpx" bindchange="change">
体育运动：
<checkbox value='1' checked='{{true}}'>足球</checkbox>
<checkbox value='2' color="red">篮球</checkbox>
<checkbox value='3'>排球</checkbox>
</checkbox-group>
```
