# 表 9-25 条码类型

| 条码类型 | 意义 |
|---|---|
| barCode | 一维码 |
| qrCode | 二维码 |
| datamatrix | Data Matrix 码 |
| pdf417 | PDF417 条码 |

扫码成功的回调参数中会封装条码的内容数据。条码扫描结果对象中的属性如表 9-26 所示。

# 表 9-26 条码扫描结果对象中的属性

| 属性名 | 意义 | 值 |
|---|---|---|
| result | 条码内容 | 字符串 |
| scanType | 条码类型 | 字符串 |
| charSet | 所使用的字符集 | 字符串 |
| path | 小程序二维码路径,当扫描的二维码为小程序码时有效 | 字符串 |
| rawData | 原始数据, base64 编码 | 字符串 |
