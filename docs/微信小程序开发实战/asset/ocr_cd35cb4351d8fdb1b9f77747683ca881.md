# 8.2 操作导航栏与标签栏

在小程序中，导航栏是指页面顶部显示页面标题和返回功能按钮的工具栏，一般页面都会包含导航栏。标签栏是指页面底部用来切换多个平级界面的工具栏。在小程序中，可以通过相关接口直接对导航栏和标签栏进行操作。

# 8.2.1 使用接口设置导航栏

小程序开发框架中提供了多种方法对页面的导航栏进行设置。通过这些接口可以对导航栏的标题、背景色、前景色等属性进行设置，如表 8-5 所示。
