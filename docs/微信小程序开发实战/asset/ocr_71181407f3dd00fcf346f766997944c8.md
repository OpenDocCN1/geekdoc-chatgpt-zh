# 6.1 创建自定义组件

微信开发者工具功能强大，对小程序开发者十分友好，并且提供了创建自定义组件模板的快捷方式。第 2 章介绍 WXML 基础知识时曾提及使用模板封装组件的方式。使用 template 标签或 import 语句可以将其他文件的组件导入当前文件中，但是 WXML 模板与自定义组件具有本质区别，自定义组件创建了一个新的组件，拥有更好的封装性，在设计上也更加面向对象。

# 6.1.1 创建自定义组件模板
