# 4.3.5 地区选择器

前面已经介绍了多种场景下使用的选择器组件，通过多列选择器可以根据需要定制各种复杂的选择器组件。起初，对于地区选择，小程序也提供了专门的选择器供开发者直接使用，将 mode 属性设置为 region 即可，示例代码如下：

```
<picker mode="region" fields="year">
地区选择
</picker>
```
