# 案例六：基于人工智能的智能音箱+蓝牙mesh的智能家居系统

应用领域：人工智能+家居

应用场景：基于语音的智能家居控制

案例提供者：北京小米移动软件有限公司

# (1) 客户需求与方案简介

当前人工智能技术与智能家居的结合越来越深入。人工智能技术可以嵌入至更多生活场景，以此打造一个智慧生活场景的生态体系。本案例是在智能音箱上基于蓝牙mesh连接智能家居设备，构建起以智能音箱为中心的智能家居蓝牙网络拓扑结构。用户既可以通过距离设备最近的智能音箱来控制设备，也可以通过智能音箱的桥接实现跨音箱远程控制设备。借助于智能音箱的桥接，在获取智能家居设备实际状态方面，蓝牙mesh方案可以达到类似Wi-Fi的用户体验，用户可以轻松实现在手机App上查看设备在线或者离线，控制设备并迅速了解成功与否等功能。
