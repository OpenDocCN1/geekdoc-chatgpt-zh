# 五大核心价值

① 释放行内数据价值
平台内的AI服务能力中台并行拥有海量数据分析建模能力的优势，助力银行开发众多的统一管理、资讯或有针对性的信息，实现智能化决策。

② 降低金融业务运行成本
通过策略分析，全面拓展财务业务应用，降低人员成本，提高运营效率；同时通过智能化金融、流动性预警等，智能资金全盘运用，精细化资金管理，降低运营成本。

③ 提升智能服务稳定性
支持海量数据接入，大大缩短智能服务开发周期，采用集群TEE安全云基础架构，共享多模型服务计算资源，提高智能服务稳定性，并降低系统建设及维护成本。

④ 优化营销宣传效率效果
智能化平台更能帮助优化用户画像，精准算法等服务，实现更精准、更高效的智能营销。

⑤ 协助搭建技术核心团队
逐步提升行内数据团队以及相关负责人员的赋能度，解决模型应用水平，助力培养自搭建专家和业内专家。

# 案例八：智慧仓储物流系统

应用领域：人工智能+物流

应用场景：自动化工厂配套智慧仓储物流解决方案

案例提供者：北京旷视科技有限公司

# (1) 客户需求与方案简介

中国是全球最大的物流市场，作为现代制造业与物流业深度融合的关键环节，“建设现代物流体系”在中央经济工作会议上被纳入2021年经济工作的重点任务之一。其中一个重要的组成部分是现代化的仓储物流，通过引入人工智能、物联网、大数据等先进的信息技术，构建智慧仓储物流系统方案，较大提升生产制造的效率。

在此行业趋势下，某家用电子产品领先企业A为进一步提升产品的整体竞争能力，经过充分调研分析后，决定规划对生产工厂的自动化改造。项目需求建设高度自动化、信息化的智慧仓储物流体系，集成收货平台、立体仓库、智能搬运、自动配送、自动拆垛等自动化设备，服务于自动连续生产的智能制造能力，缩短生产周期，降低制造成本，快速响应市场需求。
