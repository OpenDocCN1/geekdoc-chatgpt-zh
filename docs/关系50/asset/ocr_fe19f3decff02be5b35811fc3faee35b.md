# 第5章

# 解密关系,拥抱“人造情感”

科技已经融入了人类的生活,而且是不可逆转的,并以“人造”的喜怒哀乐和发人深省的故事丰富了人们的精神世界。

1900年10月3日,威尔伯·莱特(Wilbur Wright)和奥维尔·莱特(Orville Wright)首次试飞了他们的滑翔机。威尔伯担任滑翔机的飞行员,奥维尔和其他几个人则在地面上用绳子拉着滑翔机。当时的人完全没有想到,这架摇摇欲坠的小飞机竟然会彻底改变交通运输系统。许多人斥责他们是疯子、骗子,莱特兄弟自己也认为这架滑翔机非常简陋,只是一个雏形。3年后的1903年12月17日,他们首次试飞了第一架动力飞机,许多人依旧认为这是一项愚蠢的发明。1906年,《巴黎先驱报》(现为《国际纽约时报》)发表了一篇题为《是飞行者还是骗子》的社论,公然嘲讽他们。

几十年后,全球化、商业和文化交流的发展进程被莱特兄弟的发明永远改变了,那架小小的滑翔机彻底改变了人类对时间和空间的认知。如今,人们通过网购就可以买到一架这样的滑翔机,爱好者甚至可以照着网上的教学视频自己做一架。现在,我们跳上一个有两只翅膀的金属大圆筒,几个小时内就能到达千里之外的地方,这已经成为再普通不过的事情。

事实上,莱特兄弟的滑翔机并不是一个孤立于时代的发明,在它之前已经有一系列类似的发明。早在1809年,物理学家乔治·凯利(George Cayley)就发现,机翼下方的高压气流和机翼上方的低压气流产生了压力差,这个压力差就是升力。19世纪下半叶,法国发明家克雷芒·阿代尔(Clément Ader)设计出了一架蒸汽动力飞机。在这一系列发明的基础上,莱特兄弟更进一步,最终人类征服了天空。这些看似微不足道的发明就像零散的点,一旦连接起来,就会改变这个世界的游戏规则。
