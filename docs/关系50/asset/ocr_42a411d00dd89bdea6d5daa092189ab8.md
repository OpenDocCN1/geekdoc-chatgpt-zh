# 对现代人来说，“熟悉”是一段良好关系的标志之一，但通过研究人类的灵长类近亲，我们发现早期人类的关系可能存在另一种运作模式：过于“熟悉”实际上是需要离开的信号，毕竞我们祖先的繁衍模式的核心是生存。

为了进一步了解生存问题对早期人类种种关系的影响有多深，我们再来看当时的社会在人口控制方面做了哪些事情。我们知道，如果一男一女生育两个孩子，那么下一代部落成员的数量就能基本保持稳定。事实却是，一名年龄达到50岁的史前女性可能会生12个孩子，这个数量远远超过了保持人口平衡所需的孩子数量。为了控制人口的无节制增长，缓解人口对有限的生存资源造成的压力，我们的祖先必须采取一些措施。

史前社会的人口问题或许比你想象的要普遍得多，大多数风险因素并不足以限制人口增长。首先，分娩死亡率并没有成为减缓人口增长的一个重要因素。虽然早期女性分娩时的死亡风险看似很高，但最近来自南非南开普地区的石器时代晚期的考古证据表明，男性和女性的死亡率差不多，女性分娩时面临的风险并不是很高。当然，第一次怀孕的年轻女性除外，研究人员在死于初次怀孕分娩的年轻女性的骨骼中发现，她们在遗传上易患妊娠并发症和分娩并发症。其次，捕食者的攻击和身体疾病等外部风险对控制人口数量几乎没有帮助。当人类从非洲走向世界各地时，他们大都健康，而且死于捕食者攻击的风险很低。最后，其他一些因素也可能影响人口数量，如战争和性禁忌，但由于非常罕见，所以未能限制史前人口的增长。

随着人口数量的快速增长，史前人类不得不采取措施控制生育，在环境资源不足以支持人口快速增长的地方尤其如此。部落里的成年人在照顾自己的同时，还要利用有限的资源保护、养育大家庭里的所有孩子，生存的压力使得控制人口显得尤为迫切。

杀婴，听起来很残忍，但为了控制人口增长，在当时这是一种为人们所接受的解决方案。杀死婴儿确实很残忍，但婴儿的死亡在史前社会并不像在当今社会中那样悲惨或难以想象。动物也会用自己的方式来解决这个问题。例如，成年雄狮会杀死将来可能成为竞争对手的雄性幼崽；塘鹅只在特定的岩石上交配，以保证在交配季节只有一定数量
