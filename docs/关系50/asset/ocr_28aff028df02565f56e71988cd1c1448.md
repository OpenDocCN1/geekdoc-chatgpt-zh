《亚当夏娃在拂晓》( Sex at Dawn ) 一书中提到, 动物社会也存在类似的关系。例如, 倭黑猩猩是一种多角关系动物, 雄性和雌性都会有规律地与多个伴侣进行交配。倭黑猩猩通过这种性互动来加强彼此的联系和信任, 促进互惠互利。尽管《亚当夏娃在拂晓》中的观点备受争议, 但进行这种比较的人并不是只有该书作者, 另外几位研究人员也持有类似的观点。

凯瑟琳·斯塔克韦瑟 ( Katherine Starkweather ) 和雷蒙德·黑姆斯 ( Raymond Hames ) 分别来自密苏里大学哥伦比亚分校和内布拉斯加大 学林肯分校的人类学系, 他们展示了一妻多夫制的证据。他们调查了喜 马拉雅地区和马克萨斯群岛以外的53个社会, 观察到这些社会允许女性 与多名男性保持浪漫关系。他们的研究结果表明, 早期人类历史上存在 多种形式的一妻多夫制, 而且可能比人们之前认为的要多得多。他们解 释说, 这可能是因为当时的劳动分工导致男性经常外出且死亡率高, 因 此女性会与多名男性保持性关系。

在另一项研究中, 密苏里大学和亚利桑那州立大学的人类学家组成了一 个团队, 调查了南美洲的128个低地社会。该研究表明, 这些社会中普遍 存在“可分割父权” (partible paternity) 的理念, 即人们相信胎儿的形成是 一名女性与多名男性发生性关系的结果, 因此他们认为一个孩子有多位 父亲。基于这种理念, 人们认可非排他性的关系, 各种各样的“共享父 亲”习俗也随之形成并延续下来。该案例也支持了上文提到的观点: 在狩 猎采集社会, 庞大的关系网络有助于满足抚养孩子的需求。这种关系网 络不局限于亲生父母, 还包括亲戚, 甚至没有血缘关系的个体, 这可能是 人类在生物学上取得巨大成功的基础。

近期的一项研究对史前遗骸进行了基因分析, 分析结果也支持了“狩猎 采集社会大都是一夫多妻制”的观点。研究人员追踪了Y染色体的分布, 发现“在史前社会的大部分时间里, 一夫多妻制是普遍现象, 而不是个 例”。他们给出的解释是, 在史前时代的很长一段时间里, 男性的数量比 女性要少, 从而导致潜在适育者的缺乏。因此, 与当今社会中以一夫一妻 为典型的家庭生活不同, 生育方面的考虑使得史前人类大都选择一夫多 妻制。

研究人员最终得出的结论是, 人类最终采用一夫一妻制是由社会需求和 社会规范决定的, 因此也可以将这种制度定义为“社会性一夫一妻制”。
