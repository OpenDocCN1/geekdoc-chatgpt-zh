# 关系3.0, 核心家庭日渐重要

**工业社会对婚姻和关系的模式产生了重大影响, 核心家庭逐渐取代了过去围绕着田地、农场和作物的多代同堂家庭。**

随着人类文明的进步, 社会发展的周期越来越短, 变革也越来越频繁。公元前200年和公元200年出生的罗马人生活在非常相似的世界里, 但对一个14世纪的英国骑士和一个18世纪在曼彻斯特的工厂工作的英国人来说, 他们的生活方式天差地别。在过去, 人们追求的是稳定, 但这条规则在18世纪发生了变化, 其他的一切似乎也随之改变了。

从18世纪中期到20世纪中期, 工业革命从根本上改变了大多数人的日常生活。在长达1万多年的社会2.0, 人类定居下来, 耕种土地, 获得收成, 科技又一次实现了飞跃。蒸汽机和电的发明彻底改变了人类的生活, 以惊人的速度和效率生产商品的工厂如雨后春笋般冒出来, 遍布世界各地。

**工业社会还出现了一个有趣的转变: 人类在农业革命期间“驯化”了周围的环境, 工业革命时期的工厂和生产流程又开始“驯化”人类。**人们依赖新的机器和生产方式来养家糊口, 它们成了人们生活的重心。随着时间的推移, 人们涌向城市里的工厂工作, 进入了一个以科技发展为社会中心的世界。

工业社会对婚姻和关系的模式也产生了重大影响, 尽管影响机制很复杂且不完全一致, 但有证据表明, 工业化极大地促进了核心家庭的形成。这种家庭结构更适合城市化和工业化, 它逐渐取代了过去围绕着田地、农场和作物的多代同堂家庭。在农业社会, 大家庭共享土地和牲畜, 人们选择婚姻的一个主要原因是保护财产所有权。相比之下, 工业社会中的家庭以新的生产方式为中心, 家庭成员住在城市里的狭小房子里, 因此需要核心化。
