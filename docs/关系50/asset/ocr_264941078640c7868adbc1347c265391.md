# 关系1.0, 更随意、流动性更强的多角关系

在狩猎采集时代, 两性关系的基础是基因选择和避免近亲繁殖而非浪漫主义和长期的情感依赖。

250万年前, 随着人类祖先的出现, 关系、爱情乃至婚姻的故事拉开了序幕。在当时, 生存所需除了食物和住所, 还有一件重要的事情——繁衍后代。没错, 人类能够生生不息地世代繁衍至今, 要归功于祖先们的“浪漫史”。然而, 这种关系的本质是什么? 男人和女人是如何产生联系的? 性的意义是什么? 当然, 我们要讨论的最关键的问题是, 科技是如何影响这一切的?

今天, 当听到“科技”这个词时, 大多数人可能会想到计算机或者其他电子产品, 但这些只是人类发明和使用的最新科技产品。“technology”(科技)这个词实际上是由两个希腊语单词“τέχνη”(techne) 和“λογία”(logia)组成的, 大致可以翻译为“工艺的科学”, 更准确的解释是, 科技是通过对人类所掌握的知识的实际应用, 产出商品、工具和非人工服务。因此, 旧石器时代用来捕猎动物的长矛和今天用来打扫房屋的扫地机器人本质上都是科技产品, 只不过来自两个天差地别的时代。

**本章主要讲述了科技对史前社会发展趋势的总体影响, 以及与较晚一些时期的文化相比, 史前社会对关系的态度。**一般来讲, 若想理解科技如何在未来几年影响关系, 深入了解关系的演变以及科技如何从根本上影响其进程似乎很有必要。
