
年龄、性别和技能的人会负责特定的任务。例如，最厉害的猎人会带领队伍寻找猛犸象和其他猎物。如此细致的、量身定制的劳动分工提高了工作效率。这是一种以技能为基础的领导环境，它对社会中的性别平等、地位平等和年龄平等产生了深远影响。

有趣的是,虽然黑猩猩是人类的近亲,但是它们的社会远非平等主义社会。黑猩猩社会建立在一个明确的等级制度之上,在这个制度中,雄性领袖支配着其他黑猩猩。这个现象引起了研究人员的兴趣,他们开始研究黑猩猩与狩猎采集者在进化上的明显差异,尽管从生物学的角度来看,两者极为相似。进化人类学家给出的解释是,正是这种差异使人类跨入了一种更高级的进化形式,在这种进化形式中,语言、协作和复杂的交流方式推动了人类的发展。狩猎采集社会中平等主义的发展促进了更大范围的协作,人们的工作效率和创新能力都得到了提升,工作成效也更加显著。换句话说,如果狩猎采集社会从一开始就建立起等级制度,那么人类的行为会更接近黑猩猩。

与黑猩猩相比,有一些灵长类动物更崇尚平等。例如,倭黑猩猩社会的等级制度就要弱很多,在它们的社会活动中,支配关系也不那么明显。研究结果十分有趣:从某种程度上说,这种社会主导角色的缺失反而促进了高级社会行为的发展。研究表明,倭黑猩猩懂得如何相互合作,而且与许多哺乳动物不同的是,性行为对它们来说不仅仅是为了繁殖,也是一种社交方式。早期的人类比倭黑猩猩更善于合作,从某种意义上说,他们能够适应环境、不断进化,部分归功于社会中高度的平等主义。

随着人类的语言和文明逐渐发展起来,人类也像许多灵长类近亲一样将等级制度引入了社会。这种相似的社会变化并非巧合,人类从狩猎采集走向农业生产的一个必要因素就是社会结构的变化,对此,我将在第2章中进行详述。

此外,狩猎采集部落的成员会共享食物、工具和各种原材料。由于当时尚未出现货币,人类还没有囤积货币等财物的习惯。所有部落成员共享生活空间,每天大家会共同参与劳动,为整个部落提供生活所需。

育儿的模式亦是如此。通常来说,大家会认为孩子属于整个部落,那些最擅长育儿的人或者空闲时间最充裕的人会承担起养育孩子的责任,而不管孩子的直系血亲是谁。现代狩猎采集社会也具有这个特征。在许多现代狩猎采集社会中, 养育孩子仍然依赖于集体的力量, 对部落成员来说, 这减轻了抚育后代的辛劳。

科技对这种社会环境的形成产生了重要影响。第一, 在人们以群体为单位进行活动时, 狩猎采集技术的应用效率更高。因此, 大多数任务都是由一群人而不是一个人完成的, 这意味着部落的所有成员都必须参与其中、分工协作, 同时还要帮助那些年幼者、弱者和老年人。在整个生命历程中, 人类都是依靠部落的支持而生存下来的。

第二, 平等主义盛行是因为狩猎采集技术决定了人们过着游牧生活。这种生活方式要求部落储备最低限度的物资, 因为储存的物资会在迁徙时成为负担, 储存的东西越少, 迁徙路上的负担就越轻。游牧生活迫使人们轻装上阵, 只要找到一个栖身之处就可以生存下去, 因此在狩猎采集社会, 拥有财产并不是一个人的生活目标, 这与当今社会恰恰相反。

第三, 居住情况不仅反映了群体的规模, 也反映了人与人之间的互动模式。当时的人类还没有建造住所的能力, 寻找庇护所对部落来说是一个集体任务, 而不是以一个人或一个家庭为单位来处理的事情。在现今的住房文化中, 每个家庭通常拥有自己的房子, 这在我们的祖先看来是很可笑的。

鉴于以上这些因素, “隐私”这个词在史前时代简直是天方夜谭。今天的人们非常重视隐私, 在富裕国家, 每个孩子都可以拥有自己的房间, 房间里有自己的床、自己的衣橱, 甚至还有属于自己的笔记本电脑。此外, 养育孩子是新手父母自己的事情, 孩子的祖父母或保姆只是偶尔协助。然而, 当几十个人一起住在一个洞穴里, 隐私根本不存在, 也是没有必要的。在当时的社会, 两个个人之间长久的、脱离了部落的关系根本不存在。当一男一女有了孩子, 他们不会从部落中独立出来, 而是将孩子带到集体中去。

## 跨部落通婚与控制生育并存

史前科技对人类的种种关系产生了深刻影响, 最直接的影响也许是小规模部落出现了跨部落繁殖的需求。在史前时代, 一个部落的成员必须与部落之外的人“联姻”, 以获得更多的潜在伴侣, 从而使基因库更加多样化。从这个意义来说, 史前社会并不是以“夫妻”为中心, 而是以集体为中心, 人们更重视生存而不是情感。换句话说, 对原始部落的成员来说, 生存优先于情感依恋。

小规模部落形成之后, 部落成员面临的第一个问题是生育者不足带来的挑战。一夫多妻制(一男多女)或一妻多夫制(一女多男)可能是解决这个问题的一种方法。实际上, 非一夫一妻制的关系在狩猎采集社会中并不少见, 我将在后文中阐述这一点。

由于缺乏遗传多样性, 小规模部落还面临着第二个问题, 即灭绝的风险。对哺乳动物繁殖模式的统计分析表明, 一个由几十个个体组成的部落一定会出现近亲繁殖。因此, 如果没有来自部落之外的基因, 一个部落注定会灭绝, 最多持续几个世纪。这可能就是历史上所有已知的人类社会都禁止近亲结婚的原因。

早期人类存活下来的唯一途径就是进行跨部落繁殖, 即部落之间交换适合生育的成员, 男性女性都有。研究人员认为, 早期人类的这种行为与灵长类动物中有生育能力的成员从自己的族群迁徉到另一个族群的行为相似, 这也是动物世界中的一种常见策略, 有利于提高繁殖能力。跨部落繁殖扩大了基因库, 避免了近亲繁殖带来的有害性状。因此, 不同的部落之间交换适育成员对保持部落成员健康至关重要。

根据人类学理论, 跨部落繁殖不仅增加了遗传多样性, 还使得部落之间结成了联盟。通过这种“联姻”方式, 不同部落之间的关系更为亲密, 对彼此的敌意也减少了。因此, 我们的祖先在部落之间迁徉, 实际上增加了部落和他们自己的生存机会。

有趣的是, 最初参与“联姻”的原始人究竟是女性还是男性, 目前尚不清楚。不同的动物跨族群繁殖的方式不同, 有些动物族群中的适育成员的流动性更强。就黑猩猩而言, 在族群之间迁徉的是雌性黑猩猩。雌性黑猩猩对本族群那些和自己一起长大的雄性黑猩猩的性吸引力较小, 而对其他族群的陌生雄性黑猩猩的性吸引力较大。因此, 雌性黑猩猩会在这些陌生的雄性黑猩猩附近游荡, 然后加入它们的族群。对其他灵长类动物来说, 在族群之间迁徉的往往是雄性。例如, 雌性环尾狐猴会拒绝与本族群的近亲雄性个体交配, 于是这些雄性环尾狐猴只得离开它们的原生族群, 雌性通过社会排斥这种方式迫使雄性离开。

## 对现代人来说，“熟悉”是一段良好关系的标志之一，但通过研究人类的灵长类近亲，我们发现早期人类的关系可能存在另一种运作模式：过于“熟悉”实际上是需要离开的信号，毕竟我们祖先的繁衍模式的核心是生存。

为了进一步了解生存问题对早期人类种种关系的影响有多深，我们再来看当时的社会在人口控制方面做了哪些事情。我们知道，如果一男一女生育两个孩子，那么下一代部落成员的数量就能基本保持稳定。事实却是，一名年龄达到50岁的史前女性可能会生12个孩子，这个数量远远超过了保持人口平衡所需的孩子数量。为了控制人口的无节制增长，缓解人口对有限的生存资源造成的压力，我们的祖先必须采取一些措施。

史前社会的人口问题或许比你想象的要普遍得多，大多数风险因素并不足以限制人口增长。首先，分娩死亡率并没有成为减缓人口增长的一个重要因素。虽然早期女性分娩时的死亡风险看似很高，但最近来自南非南开普地区的石器时代晚期的考古证据表明，男性和女性的死亡率差不多，女性分娩时面临的风险并不是很高。当然，第一次怀孕的年轻女性除外，研究人员在死于初次怀孕分娩的年轻女性的骨骼中发现，她们在遗传上易患妊娠并发症和分娩并发症。其次，捕食者的攻击和身体疾病等外部风险对控制人口数量几乎没有帮助。当人类从非洲走向世界各地时，他们大都健康，而且死于捕食者攻击的风险很低。最后，其他一些因素也可能影响人口数量，如战争和性禁忌，但由于非常罕见，所以未能限制史前人口的增长。

随着人口数量的快速增长，史前人类不得不采取措施控制生育，在环境资源不足以支持人口快速增长的地方尤其如此。部落里的成年人在照顾自己的同时，还要利用有限的资源保护、养育大家庭里的所有孩子，生存的压力使得控制人口显得尤为迫切。

杀婴，听起来很残忍，但为了控制人口增长，在当时这是一种为人们所接受的解决方案。杀死婴儿确实很残忍，但婴儿的死亡在史前社会并不像在当今社会中那样悲惨或难以想象。动物也会用自己的方式来解决这个问题。例如，成年雄狮会杀死将来可能成为竞争对手的雄性幼崽；塘鹅只在特定的岩石上交配，以保证在交配季节只有一定数量的“育龄夫妇”可以生育后代。对人类来说，在特别艰难的时期，牺牲孩子是增加部落成员生存机会的一种可行方法。

为了生存，我们的祖先愿意杀死自己的孩子，这种动力也证明了有效的生存机制对他们来说比情感满足更重要。一个部落的成员迁徉到另一个部落以保证基因库的多样性，也是出于生存的考虑。当时的人对有利于生存和遗传多样性的条件如此重视，对现代人所熟悉的关系的建立、家庭结构却几乎没有概念。

## 一夫一妻制理论面临的挑战

连续性一夫一妻制是指一个人在一生中可能拥有多个配偶，但在拥有配偶时实行一夫一妻制。——译者注

关于史前时代各种形式的关系的争论非常激烈。一些学者认为，一夫一妻制对双方都有益，即便是非长期的连续性一夫一妻制 ①。一个忠诚的伴侣能够带来稳定，有助于平息激烈的求偶竞争。随着竞争的消除，男人和女人得以和平共享资源，并在相对安全的情况下进行有规律的日常活动，比如狩猎、采集、捕鱼、捡食肉类和养育孩子等。

根据同样的理论，男性和女性的劳动分工是家庭单位形成的必要因素。女人主要负责照顾幼儿，因此承担了更多的家务，充当了采集者和养育者的角色；男人则会外出打猎，充当了狩猎者的角色。随着男性和女性的角色划分，双方相互依赖，这种依赖关系形成了牢固的纽带，使家庭这一单位得以保持稳固。

然而，大多数研究人员对史前时代的一夫一妻制理论持强烈反对态度，至少它不是我们今天所说的一夫一妻制。他们认为，即使史前时代的男女之间存在劳动分工，这也与一夫一妻制无关，因为这种分工是群体层面的，而不是小家庭层面的。换句话说，早期人类所从事的日常工作虽然存在分工，但那是以整个部落为单位的所有男性和女性之间的分工，而不是以小家庭为单位的一男一女之间的分工。例如，部落里的所有男性一起去打猎，所有女性则一起抚养孩子，在营地周围寻找果实，并制作部落所需的工具。

另一些研究人员则认为，从男女体型和繁殖模式的角度分析，史前人类也不会是一夫一妻制。在实行一夫一妻制的动物物种中，雄性个体和雌性个体的体型往往相差不大。对于这种现象，最具代表性的解释是，固定的伴侣让这些动物没有求偶竞争的压力，因此雄性和雌性没有进化出不同的体型。鸟类就是一个很好的例子，雄鸟和雌鸟通常体型相当，鸟类中一夫一妻制的比例是哺乳动物的10倍。

相反，在一夫多妻（雄性寻找多个雌性伴侣）和一妻多夫（雌性保持多个雄性伴侣）的物种中，雄性和雌性的体型往往不同。这是进化的结果，目的是在求偶竞争中获得优势或者保护后代免受伤害——为了刺激雌性再次进入发情期，雄性会杀死它们的幼崽。平均而言，男性的体型比女性大10%，基于这一事实，大多数进化生物学家得出结论：早期人类可能不是一夫一妻制。

此外，即便一对伴侣生了几个孩子，这也并不意味着他们住在一起，像今天的核心家庭一样生活。虽然许多灵长类动物也会与同一个性伴侣生育多个后代，但现代人以及近代史上的人与伴侣生育之后会继续住在一起，这样生活方式是独一无二的。例如，在人类的近亲非洲猿的群体中，我们没有发现雄性留在核心家庭照顾后代或扮演其他类型的父亲角色的证据。

亲代抚育是指双亲对后代的保护、喂养和教育等一系列行为。
——译者注

鉴于上述情况，我们没有理由认为，一对伴侣之间的忠诚关系缘自女性在抚养孩子时需要男性提供食物和住所。实际上，人们普遍认为，人类社会是在进化到一夫一妻制之后，亲代抚育才变得普遍起来。在此之前，育儿任务是由部落大家庭来承担。以两个来自南美洲的现代狩猎采集社会为例，研究人员计算出，每对育有子女的夫妇平均得到大约1.3个其他成年人的帮助，其中大多数是男性。他们据此得出结论：额外的育儿帮助对人类的进化至关重要。

即便有证据显示人类历史上出现过类似男性女性“配对结合”的情况，研究人员仍然认为，这种结合与我们今天所理解的“婚姻”有着截然不同的目的。在这些案例中，人们允许一男一女跨部落配对结合是为了让他们的后代被部落接受，同时也表明这些孩子的父母来自不同的遗传谱系；
另一个目的是保护这些后代免受他人的伤害。此外，在条件允许的情况下，参与这种配对结合的男性和女性不一定要放弃其他性伴侣。早期原始人之间这种跨部落结合、生育的形式经历了数千年，才发展为世界各地不同文化中的浪漫习俗，最后形成了我们今天所知的婚姻制度和家庭生活。

因此，大多数研究人员对人类倾向于一夫一妻制的观点提出了质疑，相较之下，人们普遍接受的观点是浪漫关系和核心家庭在狩猎采集时代并不常见，当时的男性和女性建立关系主要是为了获得遗传优势，以及保护后代的福祉。这些社会因素以不同的方式塑造了关系和家庭结构，对此，我将在下文中进行阐述。

## 多角关系, 由社会需求驱动的亲密关系形式

关于史前人类是否以及有多大比例是部分一夫一妻、连续一夫一妻、多角关系、一妻多夫、一夫多妻、非常随意的性关系或者混合了所有这些互动类型的关系，学术界还没有达成一致。我们知道，只有不到10%的哺乳动物是一夫一妻制，即使在灵长类动物中，这一比例也仅仅在30%左右。鉴于此，行为生态学家、进化生物学家和人类学家提出了两个问题：史前人类是否与这些动物不同？当追求一夫多妻制或一妻多夫制可以拥有更多后代时，史前人类是否会满足于只有一个伴侣？

观察近代的狩猎采集社会也许是研究这个问题的可靠方法之一。可供研究的案例非常多，在18世纪，全世界仍有大约5000万个狩猎采集社会群体；到了今天，这样的社会群体仍然多达1万个。这些社会群体很可能保持着与古代狩猎采集社会相似的社会结构，可以为我们提供一些线索。

路易斯·摩尔根 (Lewis Morgan) 是美国人类学先驱，逝世于1881年。他以易洛魁人 (Iroquois) 的民族志研究而闻名，探索了易洛魁人社会中类似于狩猎采集社会的亲属关系和社会结构。摩尔根在《古代社会》(Ancient Society) 一书中指出，易洛魁人是美国原住民，分布在纽约州北部，他们生活在以多角关系制为基础的大家庭中，过着狩猎采集生活。多角关系制即男性和女性都与不止一个伴侣建立关系，有助于部落成员建立强大的人际网络，也可以促使成员们分担部落的各种任务、照顾大家庭的孩子。

《亚当夏娃在拂晓》( Sex at Dawn ) 一书中提到, 动物社会也存在类似的关系。例如, 倭黑猩猩是一种多角关系动物, 雄性和雌性都会有规律地与多个伴侣进行交配。倭黑猩猩通过这种性互动来加强彼此的联系和信任, 促进互惠互利。尽管《亚当夏娃在拂晓》中的观点备受争议, 但进行这种比较的人并不是只有该书作者, 另外几位研究人员也持有类似的观点。

凯瑟琳·斯塔克韦瑟 ( Katherine Starkweather ) 和雷蒙德·黑姆斯 ( Raymond Hames ) 分别来自密苏里大学哥伦比亚分校和内布拉斯加大学林肯分校的人类学系, 他们展示了一妻多夫制的证据。他们调查了喜马拉雅地区和马克萨斯群岛以外的53个社会, 观察到这些社会允许女性与多名男性保持浪漫关系。他们的研究结果表明, 早期人类历史上存在多种形式的一妻多夫制, 而且可能比人们之前认为的要多得多。他们解释说, 这可能是因为当时的劳动分工导致男性经常外出且死亡率高, 因此女性会与多名男性保持性关系。

在另一项研究中, 密苏里大学和亚利桑那州立大学的人类学家组成了一个团队, 调查了南美洲的128个低地社会。该研究表明, 这些社会中普遍存在“可分割父权” (partible paternity) 的理念, 即人们相信胎儿的形成是一名女性与多名男性发生性关系的结果, 因此他们认为一个孩子有多位父亲。基于这种理念, 人们认可非排他性的关系, 各种各样的“共享父亲”习俗也随之形成并延续下来。该案例也支持了上文提到的观点: 在狩猎采集社会, 庞大的关系网络有助于满足抚养孩子的需求。这种关系网络不局限于亲生父母, 还包括亲戚, 甚至没有血缘关系的个体, 这可能是人类在生物学上取得巨大成功的基础。

近期的一项研究对史前遗骸进行了基因分析, 分析结果也支持了“狩猎采集社会大都是一夫多妻制”的观点。研究人员追踪了Y染色体的分布, 发现“在史前社会的大部分时间里, 一夫多妻制是普遍现象, 而不是个例”。他们给出的解释是, 在史前时代的很长一段时间里, 男性的数量比女性要少, 从而导致潜在适育者的缺乏。因此, 与当今社会中以一夫一妻为典型的家庭生活不同, 生育方面的考虑使得史前人类大都选择一夫多妻制。

研究人员最终得出的结论是, 人类最终采用一夫一妻制是由社会需求和社会规范决定的, 因此也可以将这种制度定义为“社会性一夫一妻制”。
他们给出了两种主要理论来解释在人类历史后期发生的这种转变，两者都比较有代表性。第一种理论是，这种转变的发生是因为性伴侣不固定导致女性经常孤身一人，而男性也没有足够的能力去争夺与多名女性生育后代的权利。第二种理论是，人类采用社会性一夫一妻制是为了应对不断增加的杀婴风险，这种风险导致母亲们急于严密地保护自己的后代。

讨论到这里，一个十分有趣的问题出现了：在今天看来，这两种解释似乎都已经过时了，那未来会发生什么呢？在当今社会，除父母之外，法律和执法机制也会保护儿童，现代生殖技术也已经发展到不需要发生性关系、不需要性伴侣就可以实现生育的程度。在未来，我们是否会看到社会性一夫一妻制迅速崩塌，人类回到各种类型的性关系混合的关系？或者，这种转变已经开始了？我们将在后文中深入讨论这些问题。

## 两性关系的基础：基因选择和避免近亲繁殖

为了将前文所讨论的内容联系起来，我们现在回到本章的焦点问题：科技如何影响狩猎采集社会中的亲密关系的建立？在了解了狩猎、采集、捕鱼、捡食肉类、建造住所等所使用的技术之后，只要找到这些技术之间的联系，我们就能理解科技对史前人类建立关系的根本影响。

## 关系的进化 以生存为核心的关系
