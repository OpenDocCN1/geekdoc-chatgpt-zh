# 关系4.0,单身社会到来

信息的指数级增长使当代社会趋于多中心、网络化,新的社交网络结构进一步使关系原子化。核心家庭很快又被单身主义取代。

胡斯尼·穆巴拉克 (Hosni Mubarak) 在埃及执政了29年, 没想到一场示威游行结束了这一切。他本以为这只是一场普通的示威游行。这场游行始于Meta上的“我们都是哈立德·赛义德”(We Are All Khaled Said) 活动。因一名年轻男子未及时出示身份证件而被警察残忍打死的事件, 2万人走上街头表示抗议, 人群淹没了开罗市中心的解放广场。消息传播得非常快, 网络平台的快速和便捷使得抗议者很快被动员起来, 他们抗议政府的暴力、虐待和滥用酷刑的政策。对于这场示威游行, 全世界人民既惊愕又觉得难以置信。大批民众的参与引发了进一步的抗议活动。2011年2月11日, 示威活动开始仅18天后, 穆巴拉克执政时代结束了。穆巴拉克明白, 自己这次犯了一个重大错误, 即忽视了信息的力量。

自20世纪中期现代计算机诞生以来, 各种各样的信息充斥着整个社会。这些信息将不同的人、组织和文化联系起来, 并帮助他(它)们成长和进步。国家走向全球化, 跨国公司兴起, 社会变得越来越多样化, 多元文化繁荣共生。知识取代了有形商品在经济中的主导地位, 服务业创造的财富超过了制造业。市场看到了知识的价值, 开始重视信息, 许多行业开始着力于数据的积累、分析和传播。

在今天, 即使是最不起眼的数据, 也有可能对社会的某些方面产生蝴蝶效应式的影响, 成为一股新的社会力量。我们不断遭到信息的轰炸, 在真假新闻的强大力量之下挣扎。几乎每一天, 不同政治阵营中的一方(极右或极左, 福克斯新闻或CNN)都会站出来指责另一方滥用信息来控制政治和公众舆论、占用社会资源。
