# 第六章 人工智能社会治理和公共服务应用

**本章提要：**政府职能及其转型是实现政府治理现代化过程中的一个基本且重大的现实问题。随着经济社会发展的多维度、复杂性和不确定性日益增加，政府职能转型的任务和压力不断增大。人工智能的加速发展也给这种转型带来一些新要求和挑战。社会治理和公共服务是政府职能的两大支点，将人工智能有效运用于社会治理和公共服务，不仅是社会对技术发展的主动适应，更是政府政策的自主抉择。人工智能驱动下的政府职能转型制度设计应当覆盖数据生命周期中的收集、处理、管理、开放、应用、流通等各个环节。既需要从技术角度对从底层数据中心基础设施到数据存储系统直到上层软件应用的多个层次提出数据标准，又需要从法律法规角度对数据主体、数据范畴、数据可用性和时效性、应急机制、个人隐私、商业机密、国家机密、社会安全等多个维度进行范围厘定，进而锁定各个环节中的责任主体，落实政府在数据开放运用中的安全保障框架。

## 第一节 人工智能社会治理和公共服务命题的由来

政府职能，从行政职能视角看，即政府在社会治理和公共服务方面的“职”与“能”，以及通过合适的方式体现出的治理能力、治理的有效性。社会治理和公共服务职能的内涵和具体内容会随着社会历史变迁而发生相应的变化，诸如社会结构、经济结构和技术发展会给政府的社会治理和公共服务职能提出不同的要求。我国政府职能也经历着一个不断变化的过程。政府面临的整体行政环境和社会多维度的加速变化均要求政府职能转型。尤其是改革开放以来，我国经历了偏重经济管理职能、提出社会管理职能、强调全面履行职能的不同阶段。社会转型和社会结构的变化，特别是社会阶层、群体、利益、价值观等诸多领域的多元化，使社会问题凸显和复杂化增加。这就要求政府转变职能，不仅需要有效化解社会矛盾和维护社会稳定与治安防控，而且需要加快完善环境治理、食品安全、安全生产等领域的治理与发展。在中国特色社会主义新时代，要实现社会治理体系和社会治理能力的现代化，迫切需要人工智能技术的助力。在政府职能转型中人工智能应该以提升公共服务精细化为根本点，以实现社会秩序稳定及服务于民为落脚点，对各类资源进行智能化整合与分配。

### 一、人工智能为解决社会治理和公共服务的热点与难点问题提供技术支撑

人工智能发展多年，历经“推理时代”“知识工程时代”和“数据挖掘时代”三个时期，已基本实现弱人工智能，并开始向强人工智能过渡。人工智能在很多领域和方面成为对人类智力思维的辅助和替代，其由弱到强的发展主要体现在三个层面：信息收集辅助与智能筛选；识别应答接受模糊任务并完成；替代人的自主决策与行为。随着人工智能的不断发展，其被广泛应用到各个领域，不仅在劳动密集型、重复型、高度流程化工作中可替代人类，而且在一些需要具备丰富专业知识的复杂工作中也可替代人类，甚至超越人类。在行政管理、公共服务、城市管理、环境保护等社会治理的热点、难点问题上，人工智能的优势正逐渐显现。例如，利用人脸识别技术的天网监控系统在追捕嫌疑人、寻找走失儿童等方面屡立战功，已经成为维护社会治安的坚强后盾。又如，综合应用人脸识别、智能语音对话、图像与视频识别等人工智能技术的阿里云ET城市大脑系统在城市交通治理方面也已初显成效。在政策和技术的双重驱动下，我们有理由相信，在不久的将来，人工智能将在这些社会治理和公共服务热点难点问题上为我们提供更加智慧的解决方案。

### 二、人工智能的应用将极大地提高社会治理和公共服务的效率和质量

中国特色社会主义进入新时代，我国社会的主要矛盾已经转化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。社会治理现代化的最高理想和目标，就是实现美好生活的价值观，实现人民对美好生活的向往。互联网+人工智能+公共服务将带来公共服务领域的深刻变革，让民众享受更高质量、更便捷、更精准的公共服务。利用互联网和人工智能技术，收集和整理公共服务的个性化需求均可自动完成，这是仅凭人工无法实现的；利用大数据技术分析完备的个性化数据档案，可以预判公众需求，提供更精准的公共服务；利用人工智能的决策能力，对传统公共服务流程进行梳理，可找到制约服务效率的瓶颈，有助于简化、优化公共服务流程，提高服务效率；利用人工智能识别、应答、接受模糊任务并自动完成的能力，将部分公共服务交由人工智能系统来完成，可克服传统模式下人力、时空限制所导致的公共服务供给不足的问题，让民众享受方便及时的公共服务。人工智能在公共服务领域的广泛应用，有助于我们突破双重困境，利用尽可能少的人力和环境资源，极大地提高公共服务精准化水平，全面提升人民的生活品质。

### 三、人工智能的应用将全面提升社会治理和公共服务现代化水平

企业是人工智能技术创新的主力军，人工智能与社会治理的结合，势必促进企业与政府在社会治理领域的合作。充分发挥人工智能技术在增强社会互动、促进可信交流中的作用，有助于改变过去党、政府、社会组织、民众之间信息不对称情况，让社会治理各主体更加及时、合理、有效地参与到社会治理中来。基于大数据的分析与信息捕捉，党和政府能够及时掌握社情民意，可以让立法工作更加贴近实际需要。智能化突出强调社会治理要充分运用现代科技，特别是大数据、移动互联和人工智能等科技成果，依靠科技实现社会治理。社会治理智能化本就有运用人工智能技术让社会治理过程更为科学、智慧和优化的含义。要实现社会治理专业化，必须培养一批高素质专业化的干部队伍和各类人才队伍。在计算机中输入海量的社会治理数据和案例，通过深度学习和增强学习，可以快速“培养”出社会治理某一特定领域的“AlphaGo”，这将有效弥补专业治理人员不足的问题，并通过人机融合进一步提高专业化水平。

## 第二节 人工智能社会治理和公共服务应用的历史演变和现状分析

随着大数据、云计算、人工智能技术的飞速发展，我国政府社会治理和公共服务应用的发展大约经历三个阶段：一是起步阶段，二是过渡阶段，三是最新阶段。

### 一、历史演变分析

#### （一）起步阶段：政府信息中心的初期发展和信息割裂

在信息共享的起步阶段（20世纪八九十年代），信息中心与政府职能部门呈现出部门化倾向。追根溯源，这与政府部门机构的科层制体系相关，是政府职能分工条块分割格局的自然结果。一般而言，以单一部门为单位的信息中心把信息部门和职能部门合二为一。这种布局在信息化建设初期虽具有起步快的优势，但各部门分头建设数据中心也形成了相互割裂的信息孤岛，这些信息孤岛成为阻碍政府提升公共事务管理效能的瓶颈。

#### （二）过渡阶段：政府信息共享的尝试

为消除信息孤岛，提升政府公共事务管理效率，“政府上网”“电子政务”成了这一阶段（大约从1999年至2010年的十余年）的关键词，政府信息共享机制在摸索中前行。本阶段所通过的较有代表性的规范是2008年5月1日国务院颁布实施的《政府信息公开条例》，其中已经明确规定了应依法保护公民、法人、其他组织获取政府信息的合法权利。

#### （三）最新阶段：基于大数据的公开共享

经过多年的持续性投入与规模化建设，我国的信息基础设施不断得到改善，这为政府大数据信息共享和社会化应用提供了条件。由于我国政府结构具有垂直管理部门与地方政府条块结合的格局，部门之间的数据共享大多局限于垂直职能部门体系，地方政府部门横向之间的信息共享体系起步较晚。但在2008年以后，地方政府主导的大数据信息共享逐渐活跃。举例来说，在城市应急指挥领域，北京、上海等城市通过跨部门信息共享构建城市统一的信息系统，让数据在不同部门之间流动；在农业信息领域，浙江省搭建的“百万农民信箱工程”助力农业、教育等政府部门的信息及时共享。此外，广东、山东、吉林等省份也对以政务云平台为枢纽的信息资源整合共享机制进行了探索。
