# 第五章 人工智能的司法应用

**本章提要：**随着人工智能技术的快速发展，人工智能在司法领域的应用前景广阔。目前，它不仅可以实现信息处理数据化、制作文书智能化，还能够辅助法官审判案件。本章在系统梳理中国特色社会主义司法理论及司法体制改革的基础上，阐述人工智能司法应用的基本定位、实践意义和正当性依据，深入介绍当前人工智能司法应用的实践样态，分析其核心特征，并对人工智能司法应用所面临的挑战和未来发展路径进行全面探讨。

## 第一节 人工智能司法应用的理论基础

### 一、社会主义司法理论体系

#### （一）中国特色社会主义司法理论体系提供根本指引

中国特色社会主义理论体系博大精深、内涵丰富，中国特色社会主义司法理论是其重要组成部分。在全面实施依法治国基本方略、加快建设社会主义法治国家的新的历史条件下，人工智能司法应用的建设与完善需要植根于中国特色社会主义司法理论体系之中；相应地，新技术的引入对中国特色社会主义理论体系的丰富与创新、中国特色社会主义司法事业的科学发展和法治国家的加快建设，也具有十分重要的意义。

公平正义是司法的灵魂和生命。在作为中国特色社会主义理论体系重要组成部分的社会主义法治理论和法学理论体系当中，中国特色社会主义司法理论体系已经成为相对独立和成型的组成部分，其核心理论包括司法本体论、司法价值论、司法政策论、司法程序论、司法文明论，建构并展示着中国特色社会主义司法理论体系的整体框架与样貌，同时也为发展各类人工智能司法应用提供了根本指引。

**1．司法本体论**
人类社会最初靠私力救济应对社会中为数不多的矛盾纠纷，这种救济方式的有效性、公平性依赖于个体或群体之间的强弱关系，且容易引起连环复仇。当矛盾纠纷大量增多且通过私力救济无法有效、和平、公平解决的时候，社会需要有一种公权力取代私力以解决矛盾纠纷，司法由此而生。法律是定纷止争的实践理性。司法专门活动以国家名义完成，属于国家的基本职能之一，在国家全部活动中占有极其重要的地位。

**2．司法价值论**
中国特色社会主义司法的价值既是司法权本质属性的反映，也是党和人民对社会主义司法的要求。第一，中国特色社会主义司法具有维护公平正义的价值。第二，中国特色社会主义司法具有促进社会和谐的价值。第三，中国特色社会主义司法具有保障人民权益的价值。第四，中国特色社会主义司法具有服务改革发展的价值。第五，中国特色社会主义司法具有推进社会文明的价值。

**3．司法政策论**
政策是法律的灵魂，法律是政策的体现与保障。党领导人民实行依法治国的实质是把党的意志转化为国家意志，把党的路线、方针和政策上升为法律。司法政策是党的意志和主张在司法领域的具体化，以党和国家的基本政策作为指导思想和根本导向，对当时的社会政治经济形势和社会矛盾的发展变化作出及时回应。所以法律适用的原则是以事实为根据、以法律为准绳、以政策为指导，注重法律效果与社会效果、政治效果的统一。

**4．司法程序论**
司法活动必须严格依照法定程序，程序性是司法活动最重要、最显著的特点。程序正义是现代法治国家共同的价值取向，被联合国《世界人权宣言》第10条规定为国际社会人权保障的基本原则。程序正义的主要内容包括权利义务程序告知、充分说明、相互辩论、听取申辩、公开透明等。

**5．司法文明论**
人类社会从蒙昧走向文明的基本标志是国家与法律的出现。社会冲突的法律解决机制避免了人类在冲突和战争中分崩离析，有效保障和维持了文明的发展。法治文明及其司法文明是现代社会文明的基本标志。法治是现代政治文明的基本表征，社会主义社会应是政治文明高度发达的社会。政治文明在人类社会的全部文明中占有十分重要的地位，它的核心内容是民主法治建设，法治确立了政治文明的基本内容并使之制度化、规范化和强效化。[^((1))](#chapter5.xhtml#jz_01_0946)

#### （二）社会主义司法体系改革的必然要求

人类社会进入21世纪的第三个十年，信息科技、大数据与人工智能等新科技在司法过程中的应用，以及更加明确的“智慧司法”建设，已然成为法学理论与司法实践界探讨的前沿与热点领域。[^((2))](#chapter5.xhtml#jz_01_0947)

如何在司法过程与审判活动中吸纳新的科技，是与人类司法制度同时出现的古老话题。但是，进入21世纪以来，新科技——尤其是大数据与人工智能——的广泛使用已经使得通过科技手段来实现司法创新，变成了一个超越法系、超越政治体制、超越诉讼文化的世界共同潮流。2019年２月发布的《最高人民法院关于深化人民法院司法体制综合配套改革的意见——人民法院第五个五年改革纲要（2019—2023）》把“坚持强化科技驱动”作为未来五年改革的八个基本原则之一，并把“建构顺应时代进步和科技发展的诉讼制度体系”作为改革总体目标的一部分。在2019年４月，最高人民法院发布《人民法院信息化建设五年发展规划（2019—2023）》，[^((3))](#chapter5.xhtml#jz_01_0948)进一步明确“以促成审判体系和审判能力现代化为目标，建成人民法院信息化3.0版，形成支持全业务网络办理，全流程审判执行要素依法公开，面向法官、诉讼参与人、社会公众和政府部门提供全方位智能服务的智慧法院”。最高人民法院院长周强更是提出“加强区块链、人工智能在司法领域应用”，全面提升智慧法院建设水平。[^((4))](#chapter5.xhtml#jz_01_0949)与此同时，科技部发布国家重点研发计划项目的“司法专题任务”，划拨巨额科研资金支持包括法院在内的司法系统的科技创新。随着人工智能在司法体系中的日益渗透和普遍使用，社会主义司法体系也面临着一个发展的“奇点”，出现了从专家审判司法体系向人工智能司法体系发展的诸多现象。[^((5))](#chapter5.xhtml#jz_01_0950)

### 二、人工智能司法应用的基本定位

人工智能司法应用本质上还是由专业化和职业化的人员（即专业法官）进行审判决策，只不过案件与当事人信息的收集过程在很大程度、很大范围上依赖人工智能的高科技手段，并以此提升审判决策的效能。相较于自然人工司法体系的运作，人工智能司法体系的核心变化是一系列“智慧法院”的出现，现阶段人工智能司法应用应当明确将人工智能技术定位为司法辅助性工具。司法裁判中人工智能技术运用的数量和水平越来越高，这引起了人们对于人工智能是否将取代法官进行审判的疑虑。尽管科技界和法律界的一些学者认为，不但人类思考的过程最终可以用算力越来越强大的计算机来模拟和取代，而且社会的组织机制包括法律最终也可以由机器来操作和管理，但这种观点恐怕过于乐观。[^((6))](#chapter5.xhtml#jz_01_0951)司法裁判的内容包罗万象，其过程往往包含情理分析、价值判断，“人的纠纷只能由人来解决，唯有此，才能确保法官秉持正义之剑将有温度的公正裁决推送于当事人面前”。[^((7))](#chapter5.xhtml#jz_01_0952)另外，考虑到当事人和社会对人工智能技术和机器审判的接受还需要长期的过程，至少在可预见的未来，将人工智能技术定位为司法辅助工具是准确和适宜的。此种定位有助于厘清法官和人工智能技术的职司差别，明确法官在司法裁判中的主导地位，防止司法裁判中工具的喧宾夺主。需时常强调这一基本理念并防范其在实践中“跑偏”。就不同的司法活动阶段来分析，具体如下：

首先，在诉讼前阶段，法院通过广泛采用以当事人为服务对象的信息科技，实现当事人的纠纷解决便利化，包括促成当事人自行解决纠纷，鼓励当事人更多依靠非诉讼纠纷解决机制解决纠纷，以及为最后决定进入诉讼程序的当事人提供便利化服务。很多国家的法院已经广泛采用信息技术手段替代法官来实现普法、规则确认的工作。2018年，中国已有95.22%的法院建成信息化程度较高的诉讼服务大厅，为当事人提供全方位的诉讼服务；82.67%的法院已开通诉讼服务网，为当事人、律师提供网上预约立案、案件查询、卷宗查阅、电子送达等服务；超过44%的法院已开通诉讼服务APP或者微信小程序，提供司法服务的渠道。[^((8))](#chapter5.xhtml#jz_01_0953)

其次，纠纷立案并进入诉讼程序之后，法院的工作人员在“ABC”技术——人工智能（`AI`）、大数据（`Big Data`）和云计算（`Clouds`）的支持下，可以对案件更准确地进行繁简分流，帮助法院通过优化专业法官的人员配置来大大提升审判工作效率。其中，一个典型的例子是由上海高院主持研发并应用的“`206系统`”。该系统最重要的成就是对刑事审判过程中所依赖的证据，在侦查、起诉和审判的全流程上，进行了规范化、统一化、电子化、信息化，其最终目的是服务于法官审查与认定证据，提高案件事实认定的效率与准确度。

最后，审判过程中的高科技应用还涉及法律规则的适用，也就是帮助（而非替代）法官进行“判”的工作。在现阶段，这个方面的技术应用的主要目标是帮助法官在具体案件中实现大致的规则匹配，以及为实现“同案同判”做参考，而真正的规则适用还是由法官来进行的。

当然，近年来，人工智能等技术在纠纷解决中的使用，远远超越上述范围。比如，诉讼过程中的语音识别与文字转换、人脸识别、电子质证、区块链取证存证、电子送达、电子卷宗和文书自动生成等技术，已经越来越普及。司法人工智能作为人类智慧的延伸产物，其只能成为辅助司法工作人员的有力工具，用于将司法工作人员从大量重复性的非审判性劳动中解放出来，并以技术理性的方式对司法裁判过程进行监督，在防范冤假错案、实现“同案同判”和缓解“案多人少”等领域发挥自身的优势。企图以科技手段取代人之思维，以法典完备取代司法能动，以同案同判取代个案公正，无疑是因噎废食之举。即使人工智能时代勾勒的宏伟蓝图在将来逐渐成为现实，只有始终坚守人工智能的工具属性和人类社会的人文主义底线，防范“技术万能论”对人类社会核心价值的瓦解，才能在鼓励技术创新与推动人类文明进步之间寻求平衡。

### 三、人工智能司法应用的重要意义

#### （一）有助于提升司法效率，破解“案多人少”的司法治理难题

作为定纷止争、维护正义的终局性公权救济机制，司法以公正为其最高理念，司法公正可谓“是司法机关的灵魂和生命线”，[^((9))](#chapter5.xhtml#jz_01_0954)它有着双重的内在意涵，“既指司法处置的实体公正，也指司法活动的程序公正”，[^((10))](#chapter5.xhtml#jz_01_0955)其中，程序的效率成为程序公正的重要表现。在我国当前司法实践中，最为紧迫与棘手的问题之一就是广大民众日益增长的司法救济诉求与有限的司法资源之间的矛盾，司法程序效率难以得到有效保障，尤其伴随着立案登记制的全面实施，各级法院受理案件呈现大幅增长趋势，[^((11))](#chapter5.xhtml#jz_01_0956)“案多人少”的司法治理难题越发凸显。

司法技术革新为提升司法程序效率，化解“案多人少”矛盾提供了新的可能，人工智能在司法实践领域的运用则可为司法技术革新注入新的活力。首先，在立案程序中，运用人工智能技术，以自助化或半自助化立案模式逐步取代传统的人工立案模式，将大幅缩短立案时间，有效节约司法人力成本。其次，在审判程序中，人工智能可以分担法官大量事务性与基础性工作。

总体而言，人工智能技术的应用能够为司法实践的开展提供多元便捷的智能化辅助，从而有效地将法官从事务性、琐碎性、基础性的海量工作中解放出来，极大提升司法程序效率，助力“案多人少”的司法治理难题的破解。

#### （二）有助于实现实体公正，达致“类案类判”的司法裁判常态

追求个案的实体公正是司法实践的价值目标之一，而确保实体公正实现的前提条件是司法裁判过程中法律适用的平等与统一，即相同或类似的案件能够得到相同或类似的裁判结果，达致一种应然的“类案类判”的司法裁判常态。但从我国既往长期的司法实践来看，“事实相同的案件在不同法院甚至同一个法院的不同法官中可能出现大相径庭的判决，由此导致的裁判不统一现象严重损害了法律权威，成为当代中国司法实践亟待解决的重要问题”。[^((12))](#chapter5.xhtml#jz_01_0957)为进一步解决同案不同判或类案不类判问题，实现司法裁判尺度的统一，中共中央办公厅于2017年印发的《关于加强法官检察官正规化专业化职业化建设全面落实司法责任制的意见》明确提出，要“完善智能辅助办案系统的类案推送、结果比对、数据分析、办案瑕疵提示等功能”，而后最高人民法院的“类案智能推送系统”也于2018年1月５日正式上线运行。由此可见，人工智能的介入与应用能够为达至“类案类判”的司法裁判常态提供技术层面的有力支持。

从当前我国人工智能技术的发展水平和人工智能技术与司法实践融合的具体现状出发，主要可通过“类案推送”“量刑辅助”与“偏离预警”三大典型功能应用来促进“类案类判”的司法裁判常态的实现。“类案推送”与“量刑辅助”旨在使法官在待决案件中科学理性地进行司法裁判，防止自由裁量权的滥用；“偏离预警”更多针对已决案件的裁判质量进行风险防控，通过及时有效地对偏离度较高的已决案件裁判进行自动预警，提示法官启动复查机制，为统一司法裁判尺度提供后期的智能化辅助监督。

#### （三）有助于推进司法公开，进一步提高司法公信力

司法公信力是一个抽象的概念，法律研究者认为，“法院司法公信力反映人民群众对法院、法官是否信任及信任程度的心理认知”，是社会公众对司法的集合性判断与评价，[^((13))](#chapter5.xhtml#jz_01_0958)它是我国司法工作的一项重要目标。现代法治国家司法实践的开展不是一种神秘莫测的国家公权行为，它应该尽可能以一种开放与透明的姿态为案件当事人及广大民众所感知，“司法公开是法治国家司法机构活动本质属性和内在规律的要求”。[^((14))](#chapter5.xhtml#jz_01_0959)

结合人工智能技术的运用和司法公信力建设，有学者提出可以从以下两个层面来分析其意义。一方面，在司法工作中，人工智能技术的运用可提高部分工作内容的精确性和效率，在一定程度上保障办案质量。基于计算机的精确性，大数据和人工智能的运用可以防范司法工作中一些重复性的错误发生，[^((15))](#chapter5.xhtml#jz_01_0960)保障司法工作质量，而法律文书的自动化处理等技术的运用，可避免司法人员疲于案牍，有助于提高个案的司法效率，进而保障审判质量。另一方面，人工智能技术在司法过程中促进社会和司法的互动。这种互动一是表现在当事人等司法工作相关的业外人员的司法参与度层面上，人工智能技术的运用帮助当事人自助立案、促进其司法参与；二则辅助审判人员获得大量数据作为断案参考和判决理由，构建法院公共信息开放平台，提高司法透明度。

### 四、人工智能司法应用的正当性

#### （一）人工智能司法应用的政策依据

人工智能技术是科技发展代表性的技术之一。人工智能技术对司法工作的意义为其进入法院保留了空间，而目前的政策制度环境对该技术的重视以及我国对法院建设的重视则为人工智能技术的司法应用提供了资源支持。国务院于2017年发布《新一代人工智能发展规划》，作为第一个以人工智能为发文主题的政策文件，其确立了“三步走”的政策目标，[^((16))](#chapter5.xhtml#jz_01_0961)提出将人工智能运用于包括政务、法庭、交通和环保等层面，“促进人工智能技术应用，推动社会治理现代化”。此后，《关于强化实施创新驱动发展战略进一步推进大众创业万众创新深入发展的意见》和《国务院办公厅关于深化产教融合的若干意见》等政策文件在经济转型、学科建设等层面鼓励人工智能发展。如业界所言，人工智能产业带来政策红利，[^((17))](#chapter5.xhtml#jz_01_0962)政策红利是“由于政府推行的政策给一定的产业或行业和特定区域带来的好处，它既包含顶层宏观政策红利，也包括底层微观政策红利”，[^((18))](#chapter5.xhtml#jz_01_0963)简单而言它就是政策实施给相对人带来的利益，结合人工智能发展应用，相关政策的红利主要表现在两个层面：第一，对于人工智能研发领域而言，政策鼓励技术发展，重视对基础研究和应用研究的研发资源投入，在确保作为基础技术的人工智能行业已有规模的前提下引来相关行业更多的关注，将相关领域的人才、技术、资金吸引到人工智能技术领域，繁荣技术的研究促进其发展；第二，从人工智能应用层面看，政策营造良好的技术应用环境，在用科技提升包括司法在内的多领域运营能力的同时，为这些领域的建设注入财政和智力资源。政策红利在正当性、公共资源等层面直接助力人工智能技术发展，并鼓励人工智能技术的推广应用，实现社会发展的政策目的——在这样的制度环境下，法院运用人工智能技术既和社会发展、政策驱动步调一致，也是完善自身建设，更好地开展司法工作，行使司法权的契机。
