# 6.3.2 阈元量词的基本性质

利用阈元量词的数学模型\(\mathring{\circ}^k x = \Phi^{-1}(x, k)\)和 \(\mathring{\circ}^k x = \Phi(x, k)\)可以证明它的许多性质。阈元量词\(\mathring{\circ}^k\)的基本性质有：

定理 6.3.1(阈元逆规则) 计算阈元逆\(\Theta k\)的规则是：在多项式模型中 \(\Theta k = 1-k\)；在指数模型中 \(\Theta k = (2^{|a|-1}/\log_2 k)\)。

证明 由 \(\mathring{\circ}^k x = \Phi^{-1}(x, k), \mathring{\circ}^k x = \Phi(x, k) = \Phi^{-1}(x, k')\)知，它们是互逆的。

+   1) 由于多项式模型簇 \(\Phi_1(x, k)\)对逆运算有自封闭性。\(\Phi_1(x, k) = \Phi_1^{-1}(x, k')\)，解得关系式 \(\lambda' = -\lambda / (1 + \lambda)\)，将 \(\lambda = (1-2k)/k^2, \lambda' = (1-2k')/k'^2\) 代入关系式 \(\lambda' = -\lambda / (1 + \lambda)\) 得 \(k + k' = 1, \Theta k = k' = 1-k\)。

+   2) 由于指数函数簇 \(\Phi_2(x, k)\)对逆运算有自封闭性，任意生成元 \(\Phi_2(x, k) = x^n\) 的逆运算 \(\Phi_2^{-1}(x, k) = \Phi_2(x, k') = x^{n'}\)，解得关系式 \(n' = 1/n\)，用 \(n = -1/\log_2 k, n' = -1/\log_2 k'\) 代入，得 \(\log_2 k' = 1/\log_2 k, \Theta k = k' = (2^{|a|-1}/\log_2 k)\)。

所以，本定理成立。

如果 \(k_1 = 0.5\)，则 \(\Theta k_1 = 0.5\)，中元的逆仍然是中元。

定理 6.3.2(迁移律) 阈元量词在等号前后迁移的规则是：如果 \(\mathring{\circ}^k x = y\)，则 \(x = \mathring{\circ}^{\Theta k} y\)。

证明 由于 \(\mathring{\circ}^k x = \Phi^{-1}(x, k) = y, x = \Phi(y, k) = \Phi^{-1}(y, \Theta k) = \mathring{\circ}^{\Theta k} y\)，所以本定理成立。

迁移律是阈元量词的第二移位规则：阈元量词可以在等号前后迁动，其值变逆。

根据式(6-4)可进一步将阈元量词的第二移位规则表示为

```
\sim p = \mathring{\circ}^{\Theta k} \sim k \mathring{\circ}^k p
```

推论 6.3.1(逆还原律) 阈元逆满足还原律，\(\Theta \Theta k = k\)。

定义 6.3.3(阈元量词的和) 阈元量词\(\mathring{\circ}^{k1}\)和阈元量词\(\mathring{\circ}^{k2}\)的合成\(\mathring{\circ}^{k1} \mathring{\circ}^{k2} x = \mathring{\circ}^{k3} x\)仍然是阈元量词，用\(\mathring{\circ}^{k1} \mathring{\circ}^{k2} x = \mathring{\circ}^{k1 \Theta k2} x\)表示，称 \(k1 \Theta k2\) 为阈元和，阈元和的运算模型是\(\mathring{\circ}^{k1 \Theta k2} x = \Phi^{-1}(\Phi^{-1}(x, k1), k2)\)。

定理 6.3.3(和交换律) 阈元和满足交换律，\(\mathring{\circ}^{k1 \Theta k2} x = \mathring{\circ}^{k2 \Theta k1} x\)。

证明 1)由于在多项式模型簇 \(\Phi_1(x, k) = x(1+\lambda)^{1/2} / (1+((1+\lambda)^{1/2}-1)x), \lambda = (1-2k)/k^2\) 中，任意两个生成元 \(\Phi_1(x, k1), \lambda1=(1-2k1)/k1^2\) 和 \(\Phi_1(x, k2), \lambda2=(1-2k2)/k2^2\)，其复合生成元仍在簇中，且

```
\Phi_1(\Phi_1(x, k1), k2) = \Phi_1(x, k1)(1+\lambda2)^{1/2} / (1+((1+\lambda2)^{1/2}-1)\Phi_1(x, k1))\n= x(1+\lambda1)^{1/2}(1+\lambda2)^{1/2} / (1+((1+\lambda1)^{1/2}(1+\lambda2)^{1/2}-1)x)\n= x(1+\lambda3)^{1/2} / (1+((1+\lambda3)^{1/2}-1)x) = \Phi_1(x, k3)
```

其中，\(\lambda3=(1+\lambda1)(1+\lambda2)-1=\lambda1+\lambda2+\lambda1\lambda2, k3=((1+\lambda3)^{1/2}-1)/\lambda3\)，与复合运算的次序无关；
