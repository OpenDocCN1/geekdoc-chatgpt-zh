# 定理 9.5.4(从众性) 如果 x, y<<k, 则 M(x, y, h, k)<<k; 如果 x, y>>k。则 M(x, y, h, k)>>k。反之，M(k, k, h, k)=k。

证明 由单调性 M2 知，x, y<<k 时，M(x, y, h, k)<<k；x, y>>k 时，M(x, y, h, k)>>k。反之，由幂等性 M5 知，M(k, k, h, k)=k，所以本定理成立。

# 定理 9.5.5 如果 M(x, y, h, k)<<k, 则 min(x, y)<<k; 如果 M(x, y, h, k)>>k, 则 max(x, y)>>k。反之，M(k, k, h, k)=k，即 min(x, y)=max(x, y)=k。

证明 由边界条件 M1 知，min(x, y)<M(x, y, h, k)<max(x, y)，所以如果 M(x, y, h, k)<<k, 则 min(x, y)<<k; 如果 M(x, y, h, k)>>k, 则 max(x, y)>>k。反之，由幂等性 M5 知，M(k, k, h, k)=k，即 min(x, y)=max(x, y)=k。所以本定理成立。
