如果 f(0)=0，则 φ(x)=f(x)/f(1)；如果 f(0)=0，f(1)=1，则 φ(x)=f(x)；如果 f(1)=0，则 φ(x)=1-f(x)/f(0)；如果 f(0)=1，f(1)=0，则 φ(x)=1-f(x)。

推论 6.1.2 线性相关的生成函数 c f(x)+d 生成同一个 N 性生成元，反之不然。

定理 6.1.8(N 性生成元第二生成定理) 如果 φ₁(x)、φ₂(x)是任意 N 性生成元，则 φ(x)=φ₁(φ₂(x))是 N 性生成元。

证明 由 φ₁、φ₂ 在 [0,1] 上是连续的严格单调增函数知，φ(x)=φ₁(φ₂(x))在[0,1] 上是连续的严格单调增函数，且 φ(0)=φ₁(φ₂(0))=φ₁(0)=0，φ(1)=φ₁(φ₂(1))=φ₁(1)=1，所以 φ(x)是 N 性生成元。

# 3. N 性生成元的上下极限定义

关于 N 性生成元的上下极限，有以下规定：如果生成函数 f(x) 不是有限值函数，利用

```
φ(x)=(f(0)-f(x))/(f(0)-f(1))， φ⁻¹(x)=f⁻¹(f(0)-(f(0)-f(1))x)
```

可以规定 N 性生成元的上下极限及其逆，从而将 N 性生成元的概念推广到非连续、非严格单调的情况[图 6.1(b)]。因为

+   - 当 f(1)->+∞ 且 f(0) 为有限值时， φ(x)->Φ₃， φ⁻¹(x)->Φ₀；
+   - 当 f(0)->+∞ 且 f(1) 为有限值时， φ(x)->Φ₀， φ⁻¹(x)->Φ₃。
+   - 特别定义 Φ₃-Φ₀⁻¹=ite {1|x=1; 0}， Φ₀-Φ₃⁻¹=ite {0|x=0; 1}。

有了这些预备知识，就可以讨论 N 范数的生成问题。

# 6.1.3 N 范数的生成定理

定理 6.1.9(N 范数第一生成定理) 若 φ(x) 是 N 性生成元，φ⁻¹(x) 是它的逆函数，则 N(x)=φ⁻¹(1-φ(x)) 是连续的严格单调 N 范数。

证明 由于 φ(x) 是 N 性生成元，φ(0)=0，φ(1)=1，且是连续的严格单调增函数。所以 1-φ(x) 满足条件 N1、N2' 和 N3，由逆运算的性质知 y=N(x)=φ⁻¹(1-φ(x))，也满足条件 N1、N2' 和 N3，又 x=N⁻¹(y)=φ⁻¹(1-φ(y))，即 N⁻¹(x)=φ⁻¹(1-φ(x))，满足条件 N4。

所以 N(x) 是连续的严格单调 N 范数。

例如，下面的 N(x)、N₁(x)、N₂(x) 都是连续的严格单调 N 范数：

+   1) φ(x)=Φ₁-x 时， φ⁻¹(x)=Φ₁⁻¹-x, N(x)=N₁=1-x；

+   2) φ(x)=x(1+λ)^{1/2}/(1+((1+λ)^{1/2}-1)x), λ>-1 时

```
φ₁⁻¹(x)=x/((1+λ)^{1/2}-((1+λ)^{1/2}-1)x)
```

```
1-φ₁(x)=1-x(1+λ)^{1/2}/(1+((1+λ)^{1/2}-1)x)=(1-x)/(1+((1+λ)^{1/2}-1)x)
```
