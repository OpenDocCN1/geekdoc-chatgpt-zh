# 定理 7.3.5(T 范数第二生成定理) 如果 T0(x, y)是 T 范数，φ(x)是非极限自守函数，则 T(x, y)=φ^{-1}(T0(φ(x), φ(y)))是与 T0(x, y)同类的 T 范数。

证明 设 T0(x, y)=f0^{-1} (max(f0(0), f0(x)+f0(y)-1))，其 T 性生成元 f0(x)是连续的严格单调函数，f0(1)=1，则 f(x)=f0(φ(x))也是连续的严格单调函数，f(1)=1，可生成 T 范数

T(x, y)=f^{-1}(max(f(0), f(x)+f(y)-1))=φ^{-1}(f0^{-1}(max(f0(0), f0(φ(x))+f0(φ(y))-1))) =φ^{-1}(T0(φ(x), φ(y)))

+   如 T0(x, y)是幂零的，f0(0)=0，则 f(0)=f0(φ(0))=0，T(x, y)也是幂零的；
+   如 T0(x, y)是严格的，f0(0)→+∞，则 f(0)=f0(φ(0))→+∞，T(x, y)也是严格的；
+   如 T0(x, y)=min(x, y)=T3，则 T(x, y)=φ^{-1}(min(φ(x), φ(y)))=min(x, y)=T3；
+   如 T0(x, y)=xy=T2，则 T(x, y)=φ^{-1}(φ(x)φ(y)))是中极限算子类，用 TF2 表示；
+   如 T0(x, y)=ite{min(x, y)|max(x, y)=1; 0}=T0，则 T(x, y)=ite{min(x, y)|max(x, y)=1; 0}=T0。

所以本定理成立。

例如，φ(x)=x^{-n}, n∈R+, T0(x, y)=max(0, x+y-1)时，T(x, y)=max(0, x^{-n}+y^{-n}-1)^{1/n} 是幂零 T 范数饶(Schweizer(1))。
φ(x)=x^{-n}, n∈R+, T0(x, y)=1/(1/x+1/y-1)时，T(x, y)=(x^{-n}+y^{-n}-1)^{-1/n} 是严格 T 范数饶(Schweizer(2))。
φ(x)=1-(1-x)^n, n∈R+, T0(x, y)=xy 时，T(x, y)=1-((1-x)^n+(1-y)^n-(1-x)^n(1-y)^n)^{1/n} 是中极限 T 范数饶(Schweizer(3))。

φ(x)=x(1+λ)^{1/2}/(1+((1+λ)^{1/2}-1)x), λ>-1, T0(x, y)=xy 时，T(x, y)=xy(1+λ)^{1/2}/(1+((1+λ)^{1/2}-1)(x+y-xy))是中极限 T 范数饶(Einstein)。

可见中极限 TF2=φ^{-1}(φ(x)φ(y))，FΦ2=1+log(φ(x))不唯一，是一个类，其中包括概率算子 T2=xy，F2=ite{0|x=0; 1} 或 F2=1+logx。中极限类十分像严格类，但它有一个不同于其他类的特殊性质：由于 FΦ2=1+log(φ(x))=1-log(1/φ(x))=1-log(f(x))，其中 f(x)=1/φ(x)是严格的 T 性生成元，所以对任意 T 性生成元 f(x)都有 T(x, y)=f^{-1}(f(x)f(y))=TF2。这是我们把它独立于严格类之外进行专门研究的原因。
将幂零 T 性生成元φ(x)=x(2-x)或严格 T 性生成元 f(x)=(2-x)/x代入 T2=xy，可以生成同一个 Einstein 算子 T(x, y)=xy/(2-x-y+xy)。
