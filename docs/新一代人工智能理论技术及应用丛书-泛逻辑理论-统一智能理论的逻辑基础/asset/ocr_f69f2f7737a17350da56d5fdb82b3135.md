# 5. 泛逻辑运算模型的生成元完整簇

+   1) 三角范数的 N 性生成元完整簇。 Φ(x, k)是一级泛非运算模型的 N 性生成元完整簇，它的先验验证点是 Φ3、 Φ1 和 Φ0。常用的模型有两个，虽然差别很大，但是生成的 N(x, k)几乎相同。主要用指数模型。
+   指数模型： Φ1(x, k)=x^n， n=-1/log2k， k=2^{-1/n}
+   多项式模型： Φ2(x, k)=x(1+λ)^{1/2}/((1+(1+λ)^{1/2}-1)x), λ=(1-2k)/k^2， k=((1+λ)^{1/2}-1)/λ

+   2) 三角范数的 T 性生成元完整簇。 F0(x, h)是零级泛逻辑运算模型 T 性生成元完整簇， F (x, h, k)=F0 ( Φ(x, k), h)是一级泛逻辑运算模型 T 性生成元完整超簇，它的先验验证点是 F3、 F2、 F1 和 F0。常用指数模型：
+   F0(x, h)=x^m， 其中 m=(3-4h)/(4h(1-h))， h∈[0, 1]； h=((1+m)-((1+m)^2-3m)^{1/2})/(2m)， m∈R
+   F(x, h, k)=F0(Φ(x, k), h)=x^{mn}， n=-1/log2k， k=2^{-1/n}

+   3) 三角范数的 S 性生成元完整簇。 G0(x, h)是零级泛逻辑运算模型 S 性生成元完整簇， G(x, h, k)=G0(Φ(x, k), h)是一级泛逻辑运算模型 S 性生成元完整超簇，它的先验验证点是 G3、 G2、 G1 和 G0。常用指数模型： G0(x, h)=1-(1-x)^m， 其中 m=(3-4h)/(4h(1-h))， h∈[0, 1]； h=((1+m)-((1+m)^2-3m)^{1/2})/(2m)， m∈R。 G(x, h, k)=G0(Φ(x, k), h)=1-(1-x^m)^n， n=-1/log2k， k=2^{-1/n}。
+   两者的关系是： G0(x, h)=N(x, F0(N(x, 0.5), h) 0.5)=1-F0(1-x, h)

# 6. 生成泛逻辑运算完整簇的形成机制

+   1) k 对一元运算的调整机制： N(x, k)=Φ^{-1}(N(Φ(x, k)), k)
+   2) k 对二元运算 L(x, y) 的调整机制： L(x, y, k)=Φ^{-1}(L(Φ(x, k), Φ(y, k)), k)
+   3) h 对二元运算 L(x, y) 的调整机制： L(x, y, h)=F^{-1}(L(F(x, h), F(y, h)), h)
+   4) β 对二元运算 L(x, y) 的调整机制： L(x, y, β)=L(2βx, 2(1-β)y)
