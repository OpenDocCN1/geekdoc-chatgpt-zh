最小与 突变与算子：\( T(x_1, x_2, \cdots, x_l, 0)=\mathbf{T_0}=\text{ite}\{\min(x_1, x_2, \cdots, x_l)|(x_1, x_2, \cdots, x_l)\text{中有}(l-1)\text{个 } 1; 0\}\)

定义 9.1.4 由一级 T 范数完整超簇 \( T(x_1, x_2, \cdots, x_l, h, k)=(\max(0''^m, x_1'''^m+x_2'''^m+\cdots+x_l'''^m-(l-1)))^{1/m'}\)实现的泛逻辑运算叫多元一级泛与运算，用泛与命题连接词 \(\wedge_{hk}\) 表示。

# 9.1.2 泛与运算的性质

根据前面关于 T 范数的各种讨论，可归纳出泛与运算的性质如下。

+   1) \( T(x, y, h, k)\) 满足 T 范数公理：
+   边界条件 T1：\( T(0, y, h, k)=0, T(1, y, h, k)=y\)；
+   单调性 T2：\( T(x, y, h, k)\)关于 \( x, y\) 单调增；
+   连续性 T3：\( T(x, y, h, k)\)关于 \( x, y\) 连续；
+   结合律 T4：\( T(T(x, y, h, k), z, h, k)=T(x, T(y, z, h, k), h, k)\)；
+   交换律 T5：\( T(x, y, h, k)=T(y, x, h, k)\)。

+   2) 封闭性：\( T(x, y, h, k) \in [0, 1]\)；上界性：\( T(x, y, h, k) \leqslant \min(x, y)\)；化简式：\( T(x, y, h, k) \leqslant x\)；\( T(x, y, h, k) \leqslant y\)。

+   3) 兼容性：泛与运算与二值逻辑兼容，即
+   \( T(0, 0, h, k)=0, T(0, 1, h, k)=0, T(1, 0, h, k)=0, T(1, 1, h, k)=1 \)

+   4) 与幂律：\( T(x, x, h, k) \leqslant x\)；吸收律（幂等性）：\( T(x, x, 1, k)=x\)。

+   5) 补余律：\( T(x, 1-x, h) \leqslant 0.5\)；\( T(x, N(x, k), h, k) \leqslant k\)；矛盾律：当 \( h \leqslant 0.5\) 时，\( T(x, N(x, k), h, k)=0 \)。

+   6) 泛与性：如果 \( T(x, y, h, k) \gg a \in [0, 1]\)，则 \( x \gg a\) 且 \( y \gg a\)；如果 \( T(x, y, h, k) \gg k\)，则 \( x \gg k\) 且 \( y \gg k \)。

+   7) 合并律：如果 \( x \leqslant z, y \leqslant z\)，则 \( T(x, y, h, k) \leqslant z\)；相加律：如果 \( x+x' \leqslant 1\)，则 \( T(x+x', y, h, k) \geq \max(T(x, y, h, k), T(x', y, h, k))\)；相乘律：\( T(xz, y, h, k) \leqslant \min(T(x, y, h, k), T(z, y, h, k))\)；指数律：\( T(x^n, y, h, k) \leqslant T(x, y, h, k), n \geqslant 1 \)。
