# 性质 C.1 I 泛蕴含运算具有以下性质。

+   1) 兼容性。I 泛蕴含运算与二值逻辑兼容：$I_t(0,0,h)=1, I_t(0,1,h)=1, I_t(1,0,h)=0, I_t(1,1,h)=1$
+   2) 保序性。仅有 $I_t(x, y, 1)=\min(1, y/x)$ 满足 $I_t(x, y, 1)=1, \text{ iff } x \le y$。
+   3) 单调性。$I_t(x, y, h)$ 关于 $x (h<0.75 \text{ 时})$ 和 $y$ 单调递增；$I_t(x, y, h)$ 关于 $x (h \ge 0.75 \text{ 时})$ 和 $y$ 单调递减。
+   4) 连续性。在 $(0, 1)$ 上 $I_t(x, y, h)$ 关于 $x, y, h$ 连续。
+   5) 封闭性。$I_t(x, y, h) \in [0, 1]$。
