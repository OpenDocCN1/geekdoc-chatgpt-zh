# 3. 前提引入规则

在推演的任何步骤上，都可以引入前提。

# 4. 结论引用规则

在推演的任何步骤上，都可以引用前面演绎出的结论，作为后继推演的前提。

# 5. 取代规则

若 F 是任意合式公式，A 是 F 中的任意子公式，且 A<=>A'，在 F 中用 A'取代 A 后是 F'，则有 F<=>F'(除 h=0 和 k=1 外)。

# 6. 代换规则

若 F(p1, p2, ..., pi, ..., pn)是任意永真合式公式，pi 是命题变元，A 是任意合式公式，则 F(p1, p2, ..., A, ..., pn)是永真合式公式，即 F(p1, p2, ..., pi, ..., pn)<=>F(p1, p2, ..., A, ..., pn)(除 h=0 和 k=1 外)

# 7. 合取规则

由前提 p、q 可以推出结论(p∧_h,k q)。

# 8. 分离规则

由前提 p, (p->_h,k q)可以推出结论 q。

# 9. 拒取规则

如果 p=>q 或 h=0.5，则由前提~k q , (p->_h,k q)可以推出结论~k p。

# 10. 析取三段论

由前提(p∨_h,k q)，~k q 可以推出结论 p。

# 11. 假言三段论

由前提(p->_h,k q), (q->_h,k r)可以推出结论(p->_h,k r)。

# 12. CP 规则

由前提 p、q 可以推出结论 r，等价于从 q 可以推出结论(p->_h,k r)。

# 13. 附加规则

由前提 p 可以推出结论(p∨_h,k q)。
