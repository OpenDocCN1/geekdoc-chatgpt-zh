# 9.2 泛或命题连接词的定义及性质

# 9.2.1 泛或命题连接词的定义

定义 9.2.1 由零级 T 性生成元完整簇 F(x, h)=x^m 代人或运算的基模型生成的零级 S 范数完整簇 S(x, y, h)=1-(max(0^m,(1-x)^m+(1-y)^m-1))^{1/m} 实现的泛逻辑运算叫零级泛或运算，用泛或命题连接词 \vee_h 表示。其中， m=(3-4h)/(4h(1-h)) ; h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), h\in[0, 1], m\in\mathbf{R}。

+   它的四个特殊算子是：最小或 Zadeh 或算子：S(x, y, 1)=S_3=max(x, y) 中核或 概率或算子：S(x, y, 0.75)=S_2=x+y-xy 中心或 有界或算子：S(x, y, 0.5)=S_1=min(1, x+y) 最大或 突变或算子：S(x, y, 0)=S_0=ite{max(x, y)|min(x, y)=0; 1}

定义 9.2.2 由一级 T 性生成元完整超簇 F(x, h, k)=x^{nm} 代人或运算的基模型生成的一级 S 范数完整超簇 S(x, y, h, k)=(1-(max((1-0^n)^m, (1-x^n)^m+(1-y^n)^m-1))^{1/m})^{1/n} 实现的泛逻辑运算叫一级泛或运算，用泛或命题连接词 \vee_{k, h} 表示。其中， n=-1/log_2 k, k\in[0, 1] ; k=2^{-1/n}, n\in\mathbf{R}_{\circ}。

+   它的四个特殊点的算子(簇)是：S(x, y, h, k) 的下极限是 Zadeh 或算子：S(x, y, 1, k)=S (x, y, 1)=max(x, y)=S_3。 S(x, y, h, k) 的中极限簇是 S(x, y, 0.75, k)=(max(0, x^{-n}+y^{-n}-n y^{-n} n^{1/n})=S\Phi_{2k}，其中 S(x, y, 0.75, 0.5)=x+y-xy=S_2 是概率或算子。 S(x, y, h, k) 的中心与算子簇是 S(x, y, 0.5, k)=(max(0, x^n+y^n-1))^{1/n}=S\Phi_{1k}，其中 S(x, y, 0.5, 0.5)=max(0, x+y-1)=S_1 是有界或算子。 S(x, y, h, k) 的上极限是突变或算子：S(x, y, 0, k)=T(x, y, 0)=ite{min(x, y)|max(x, y)=1; 0}=S_0。

根据 S 范数的结合律，上述定义可推广到多元运算中。

定义 9.2.3 由零级 S 范数完整簇 S(x_1,x_2,\cdots,x_l,h)=1-(max(0^m, (1-x_1)^m+(1-x_2)^m+\cdots+(1-x_l)^m-(l-1)))^{1/m} 实现的泛逻辑运算叫多元零级泛或运算，用泛或命题连接词 \vee_h 表示。

+   它的四个特殊算子是：最小或 Zadeh 或算子：S(x_1, x_2, \cdots, x_l, 1)=S_3=max(x_1, x_2, \cdots, x_l) 中核或 概率或算子：S(x_1, x_2, \cdots, x_l, 0.75)=S_2=1-(1-x_1)(1-x_2)\cdots(1-x_l) 中心或 有界或算子：S(x_1, x_2, \cdots, x_l, 0.5)=S_1=max(l-1, x_1+x_2+\cdots+x_l) 最大或 突变或算子：S(x_1, x_2, \cdots, x_l, 0)=S_0=ite{max(x_1, x_2, \cdots, x_l)|(x_1, x_2, \cdots, x_l)中有(l-1)个 0; 1}
