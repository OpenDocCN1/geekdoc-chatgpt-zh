# 9.3.4 泛串行推理运算

一级泛串行推理运算完整簇是一级泛与运算完整簇，即

```
R(x, y, h, k)=inf {z | z≤I(x, z, h, k)}=T(x, y, h, k)=(max(0, x^{mn}+y^{nm}-1))^{1/mn}
```

一级泛与运算完整簇的所有性质都是一级泛串行推理运算完整簇的性质。
