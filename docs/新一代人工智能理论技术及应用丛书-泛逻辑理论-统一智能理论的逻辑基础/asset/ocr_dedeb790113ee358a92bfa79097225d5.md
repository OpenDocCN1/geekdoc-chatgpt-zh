逻辑意义：命题经过两次不同 k 的非运算后，合成为一个新的 k 非运算的补运算。

+   2) 非吸收律：

~~ k~0p=~~ o0p, ~~ k~1p=~~ 1p
~~ 0~kp=~~ 0~p, ~~ 1~kp=~~ 1~p

逻辑意义：k 值非运算与极限值非运算复合后，k 会被吸收(变成 0.5)。

+   3) 非互补律：~~ $\ominus k$ ~k p=~~ ~k p，其中 k'=k²/(1-2k+2k²)。

+   4) 非交换律：~~ k2~k1 p=~~ $\ominus$ k1~ $\ominus$ k2 p。

逻辑意义：任何两个相邻非运算交换位置，它们的 k 都要变补。

# 6.4.6 广义自封闭性

+   1) 对偶律~~ k2~k1~k2 p=~~ k p, k=N(k1, k2)表示非算子的各种对偶运算一定在 N 簇内；

+   2) 如果 n 是奇数，则~kn···~k2~k1 p=~~ k p 一定在 N 簇内；

+   3) 如果 n 是偶数，则~kn···~k2~k1 p=~~ ~k p 一定在 N 补簇内。

逻辑意义：在非运算完整簇内，各种非运算的复合运算结果都在 N 簇或 N 补(余)簇内，所以，一个逻辑推理系统只需要一个非运算完整簇即可。
