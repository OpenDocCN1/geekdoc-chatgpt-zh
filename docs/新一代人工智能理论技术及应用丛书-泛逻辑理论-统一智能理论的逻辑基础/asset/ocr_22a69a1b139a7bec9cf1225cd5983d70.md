# 定理 7.2.12(幂等条件) 弱 S 范数 S(x, x)=x，iff S(x, y)=max(x, y)。

证明 充分性：如果 S(x, y)=max(x, y)，则 S(x, x)=x。
必要性：如果弱 S 范数 S(x, x)=x，则 mam(x, y)=S(max(x, y), max(x, y))≥S(x, y)，
又 S(x, y)≥max(x, y)，所以 S(x, y)=max(x, y)。

本定理表明 Zadeh 算子是唯一的连续的非阿基米德型 S 范数。
