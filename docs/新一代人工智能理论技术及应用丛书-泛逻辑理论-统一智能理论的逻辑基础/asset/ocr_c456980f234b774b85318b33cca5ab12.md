其中，m=(3-4h)/[4h(1-h)], h∈(0,1); h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m∈R; λ=(1-2k)/k^2; k=((1+λ)^{1/2}-1)/λ, k∈(0,1), λ>-1。

# 定义 8.5.6 通过中心 T 范数 T(x,y)=max(0,x+y-1)和混合型一级 T 性生成元完整超篌生成的 T 范数超篌是混合型一级 T 范数完整超篌，即

T(x, y, h, k) = F^{-1}(\max(F(0, h, k), F(x, h, k) + F(y, h, k) - 1), h, k) = \Phi^{-1}((\max(0^m, (\Phi(x, k))^m + (\Phi(y, k))^m - 1))^{1/m}, k)

其中，m=(3-4h)/(4h(1-h)), h∈(0,1); h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m∈R; λ=(1-2k)/k^2; k=((1+λ)^{1/2}-1)/λ, k∈(0, 1)。

# 定义 8.5.7 混合型一级 S 性生成元完整超篌为

G(x, h, k) = G(\Phi(x, k), h) = 1 - (1 - \Phi(x, k))^m \Phi(x, k) = x(1 + \lambda)^{1/2} / [1 + ((1 + \lambda)^{1/2} - 1)x] G^{-1}(x, h, k) = \Phi^{-1}(G^{-1}(x, h), k) = \Phi^{-1}(1 - (1 - x)^{1/m}, k) \Phi^{-1}(x, k) = x / ((1 + \lambda)^{1/2} - ((1 + \lambda)^{1/2} - 1)x)

其中，m=(3-4h)/(4h(1-h)), h∈(0,1); h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m∈R; λ=(1-2k)/k^2; k=((1+λ)^{1/2}-1)/λ, k∈(0,1), λ>-1。

# 定义 8.5.8 通过中心 S 范数 S(x, y)=min(1, x+y)和混合型一级 S 性生成元完整超篌生成的 S 范数超篌是混合型一级 S 范数完整超篌，即

S(x, y, h, k) = G^{-1}(\min(G(1, h, k), G(x, h, k) + G(y, h, k)), h, k) = \Phi^{-1}(1 - (\max(0^m, (1 - \Phi(x, k))^m + (1 - \Phi(y, k))^m - 1))^{1/m}, k)

其中，m=(3-4h)/(4h(1-h)), h∈(0,1); h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m∈R; λ=(1-2k)/k^2; k=((1+λ)^{1/2}-1)/λ, k∈(0,1), λ>-1。

# 2. 混合模型的主要性质

在非极限情况下，混合型一级 T 范数/S 范数完整超篌的性质与纯指数型一级 T 范数/S 范数完整超篌的变化规律基本相同，但变化快慢有别，主要不同点如下。

# 定理 8.5.6

在混合型一级 T 范数完整超篌 T(x, y, h1, k1)和混合型一级 S 范数完整超篌 S(x, y, h2, k2)之间存在零级对偶的条件是(1-\Phi(x, k2))^{m2}=(\Phi(1-x, k1))^{m1}，当 h1=h2 时有 k2=1-k1。

# 证明

由于 F(x, h1, k1)=(\Phi(x, k1))^{m1}, G(x, h2, k2)=1-(1-\Phi(x, k2))^{m2}，而零级对偶的一般条件是 g(x)=1-f(1-x)，所以有 G(x, h2, k2)=1-(1-\Phi(x, k2))^{m2}=1-(\Phi(1-x, k1))^{m1}，即 (1-\Phi(x, k2))^{m2}=(\Phi(1-x, k1))^{m1}，当 h1=h2 时有 1-\Phi(x, k2)=\Phi(1-x, k1)，\Phi(x, k2)=1-\Phi(1-x, k1)，k2=1-k1。所以本定理成立。
