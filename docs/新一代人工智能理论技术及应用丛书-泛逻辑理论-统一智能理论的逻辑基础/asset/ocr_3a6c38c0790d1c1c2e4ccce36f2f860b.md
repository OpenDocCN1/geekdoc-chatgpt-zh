# 6.1.2 N 范数的主要性质及生成方法

# 1. N 范数的主要性质

**定义 6.1.1(封闭性)** 弱 N 范数满足 N(x)∈[0, 1]。

**证明** 由边界条件 N1 知，N(0)=1, N(1)=0，由单调性 N2 知，N(1)≤N(x)≤N(0)，所以 N(x)∈[0, 1]，弱 N 范数具有封闭性。

**定义 6.1.2(对合律)** N 范数满足 N(N(x))=x。

**证明** 由逆等性 N4 知，N(x)=N⁻¹(x)，所以 N(N(x))=N(N⁻¹(x))=x。

**定义 6.1.3(不动点)** 在连续(弱)N 范数 N(x)中存在 k∈(0, 1)，使 N(k)=k。

**证明** 由定理 6.1.1 知，N(x)∈[0, 1]，再由单调性 N2 和连续性 N3 知，当 x∈(0, 1)时，y=N(x)曲线必然与主对角线(y=x)相交，设交点 K 在 x 轴上的投影是 k，必有 N(k)=k。所以在连续(弱)N 范数 N(x)中，存在不动点 k∈(0, 1)，使 N(k)=k。

例如，1-x² 的 k=(5^{1/2}-1)/2，中心 N 范数 N(x)=1-x 的 k=0.5，Sugeno 算子的 k=1/((1+λ)^{-1/2}+1)，非连续 N 范数的 k 包含在它的直接定义中，如 N₃ 的 k=1，N₀ 的 k=0。

**定义 6.1.4(泛非性)** 设 k∈(0, 1)是连续(弱)N 范数 N(x)的不动点，则当 x>k 时，N(x)<k；当 x<k 时，N(x)>k。如果 N(x)是连续的严格单调(弱)N 范数，则当 x<k 时，N(x)>k；当 x>k 时，N(x)<k。

**证明** 由定理 6.1.3 知，N(k)=k，再由单调性 N2 知，当 x>k 时，必有 N(x)≤k；当 x<k 时，必有 N(x)≥k。如果 N(x)是连续的严格单调(弱)N 范数，则 x<k 时必有 N(x)>k，当 x>k 时必有 N(x)<k。所以本定理成立。

**定义 6.1.5(零级对偶和一级对偶)** 如果 N(x)和 N₁(x)都是 N 范数，则称 N₁'(x)=N(N₁(N(x)))为 N₁(x)关于 N(x)的一级对偶，当 N(x)=1-x 时，N₁'(x)=1-N₁(1-x)，退化为 N₁(x)的零级对偶，统统称为对偶。

任何 N 范数都有一级对偶和零级对偶。
