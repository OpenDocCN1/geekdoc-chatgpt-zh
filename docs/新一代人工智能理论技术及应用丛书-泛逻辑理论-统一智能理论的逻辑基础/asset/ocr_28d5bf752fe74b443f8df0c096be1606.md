# 定理 7.4.5 任意两个非极限同类的 S 性生成元 g1(x)、g2(x)之间存在关系 g1(x)=cg2(ϕ(x))，其中 c=g1(1)/g2(1)≠0 为有限实数，ϕ(x)=g2^-1(g1(x)/c)是连续的严格单调的自守函数。

# 证明

+   1) 如果 g1(x)和 g2(x)都是连续的严格单调的自守函数，g1(x)=ϕ(x)，g2(x)=ϕ(x)，则 ϕ(x)=ϕ^-1(ϕ(x))是连续的严格单调的自守函数，c=g1(1)/g2(1)=1 为有限实数，满足 g1(x)=cg2(ϕ(x))；

+   2) 如果 g1(x)和 g2(x)是任意幂零 S 性生成元，g1(1)和 g2(1)都是不为零的有限值，则 ϕ(x)=g1(x)/g1(1) 和 ϕ(x)=g2(x)/g2(1)都是连续的严格单调的自守函数，由 1) 知 ϕ(x)=ϕ^-1(ϕ(x)) 是连续的严格单调的自守函数，即 ϕ(x)=ϕ^-1(ϕ(x))=g2^-1(g1(x)g2(1)/g1(1))=g2^-1(g1(x)/c)，c=g1(1)/g2(1)≠0 为有限实数，满足 g1(x)=cg2(ϕ(x))；

+   3) 如果 g1(x)和 g2(x)都是严格 S 性生成元，即 g1(x)和 g2(x)都是连续的严格单调调函数，且 g1(0)=g2(0)=0，g1(1)和 g2(1)都是无限值，则 ϕ(x)=g2^-1(g1(x)/c)是连续的严格单调调函数，且 ϕ(0)=0，其中 c=g1(1)/g2(1)=±1(g1(x)和 g2(x)同方向时为 1，反方向时为 -1)，ϕ(1)=1，所以 ϕ(x)是连续的严格单调的自守函数，满足 g1(x)=cg2(ϕ(x))。

所以本定理成立。
