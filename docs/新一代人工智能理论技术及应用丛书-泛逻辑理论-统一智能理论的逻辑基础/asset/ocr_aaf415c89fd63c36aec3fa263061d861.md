+   5) 偶等性： ~k~k~kp=~kp。任何泛非运算的自对偶仍然是自己。

# 6.4.4 阈元量词的基本性质及运算

在一个推理系统中，如果全部命题都有相同的阈元 k，则由对合律~k~kp=p和偶等性~k~k~kp=~kp 可知，在推理中不需要阈元量词^k 的帮助，否则需要用阈元量词^k 来标志命题真值的误差水平 k。

阈元量词的运算模型是^k x=Θ^-1(x,k), ^0.5x=x。

阈元量词 ^k 的逆仍然是阈元量词，用 ^Θ^k 表示， ^Θ^k 的运算模型是 ^Θ^k x=Θ(x,k)。

利用阈元量词 ^k 可将泛非非命题连接词表示为 ~kp=^k~ ^Θ^k p。

阈元量词 ^k 的基本性质如下。

+   1) 第一移位规则： ^k ~p=~ ~^k p。中心非算子~前面的阈元量词^k 可以移到后面去，条件是将~变成^k，反之则相反。

+   2) 第二移位规则：如果 ^k p=q，则 p=^Θ^k q。阈元量词可以在等号左右移动，其阈值变逆。

+   3) 第三移位规则： ^k1 ^k2 p=^k2 ^k1 p。相邻阈元量词可以任意交换位置，其值不变。

+   4) 第四移位规则： ~kp=^k~ ^Θ^k p 或 ~p=^Θ^k ~ ^k p。泛非运算与中心非运算的关系。

+   5) 第五移位规则： ~k2 ^k1 p=^k2~ ^k1⊕k2 p。不等差泛非运算的等价变换公式。

+   6) 第六移位规则： ^k2~ ^Θ k2 ^k1~ ^Θ k1 p=~ ^Θ k2 ^k1~ ^Θ k1 ^k2 p。阈元量词可以在两个否定符号两边任意移动，其值不变。

阈元量词 ^k 的运算规则如下。

+   1) 逆运算规则：在多项式模型中 ⊖ k=1-k；在指数模型中 ⊖ k=(2^a|a=1/log2k)；阈元逆满足还原律 ⊖ ⊖ k=k。

+   2) 和运算规则：在多项式模型中 k1⊕k2=k1 k2/(1-k1-k2+2k1 k2)；在指数模型中 k1⊕k2=(2^a|a=-log2 k1 log2 k2)；阈元和满足对偶律 k1⊕k2=⊖(⊖k1 ⊕ ⊖k2)。

+   3) 差运算规则：在多项式模型中 k1⊖k2=k1(1-k2)/(k1+k2-2k1 k2)；在指数模型中 k1⊖k2=(2^a|a=-log2 k1/log2 k2)；差运算满足吸收律 k⊖k=0.5，即 ^k ^Θ^k x=x。

+   1) 非合成律： ~k2~k1 p=~~k3 p，k3=k1 ⊖ k2=k1(1-k2)/(k1+k2-2k1 k2)。
