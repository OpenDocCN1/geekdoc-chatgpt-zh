# 定理 7.3.7 如果 φ(x) 是定义在[0, 1]上的自守函数，则 S(x, y)=φ^{-1}(min(1, φ(x)+φ(y)))是幂零 S 范数。

证明 因为 φ(x) 是[0, 1]上的连续的严格单调一元函数， φ(1)=1, φ(0)=0，所以 S(x, y)=φ^{-1}(min(φ(1), φ(x)+φ(y)))=φ^{-1}(min(1, φ(x)+φ(y))) 是阿基米德型 S 范数。又当 φ(x)+φ(y)>1 时有 S(x, y)=1，是幂零 S 范数。所以本定理成立。

# 定理 7.3.8 如果 g(x) 是定义在[0, 1]上的连续的严格单调一元函数， g(0)=0，则 g(x) 生成的 S(x, y) 不是幂零 S 范数就是严格 S 范数。

证明 如果 g(1)->±∞，则 S(x, y)=g^{-1}(min(g(1), g(x)+g(y)))=g^{-1}(g(x)+g(y)) 在 (0, 1) 上严格单调增，是严格 T 范数。否则 g(1) 为有限值，则 φ(x)=g(x)/g(1) 是自守函数， φ^{-1}(x)=g^{-1}(g(1)g(x))，由于 S(x, y)=g^{-1}(min(g(1), g(x)+g(y)))=g^{-1}(g(1)min(1, g(x)/g(1)+g(y)/g(1)))) =φ^{-1}(min(1, φ(x)+φ(y))) 是幂零 S 范数，所以本定理成立。
