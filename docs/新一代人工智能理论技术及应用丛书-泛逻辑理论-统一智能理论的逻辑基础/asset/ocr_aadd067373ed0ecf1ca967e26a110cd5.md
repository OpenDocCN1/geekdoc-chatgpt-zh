的偏真性最小，T(x, y, 0, k)=T0，它表示除 T(1, y, 0, k)=y，T(x, 1, 0, k)=x 外，其他区域均为假，即只有 x=1, y∈[k, 1] 或 y=1, x∈[k, 1] 时才偏真。随着 h 从 0 到 1 不断增大，泛与的偏真性不断提高，偏真区域连续增大，经过 T(x, y, 0.5, 0.5)=T1，T(x, y, 0.75, k)=T2，到 T(x, y, 1, k)=T3，但泛与的偏真区域只能增大到 x∈[k, 1] 且 y∈[k, 1] 的所在区域。
