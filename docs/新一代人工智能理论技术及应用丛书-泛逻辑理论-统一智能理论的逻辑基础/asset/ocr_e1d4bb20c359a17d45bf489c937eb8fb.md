大，如果 x, y>e，则 C^e(x, y, 1, k)=max(x, y)；如果 x, y<e，则 C^e(x, y, 1, k)=min(x, y)。

+   5) 泛平均运算 M(x, y, h, k) 和泛组合运算 C^e(x, y, h, k) 的根本差别是前者有幂等性，后者有么元；前者在[x, y]中取值，后者在[0, 1]中取值。
