$M(x, y, h, k)$的中心平均算子是 $M(x, y, 0.5, k)=1-(((1-x)^n+(1-y)^n)/2)^{1/n}=M\Phi_1_k$ ，其中 $M(x, y, 0.5, 0.5)=(x+y)/2=M_1$ 是有界平均算子。
$M(x, y, h, k)$的下极限是突变平均算子：$M(x, y, 0, k)=M(x, y, 0)=ite\{min(x, y)|max(x, y)=1; 0\}=M_0$。

根据多元算术平均的思想，上述定义可推广到多元运算中。

# 定义 9.5.3 由零级 M 范数完整链 $M(x_1, x_2, \cdots, x_l, h)=(1-(((1-x_1)^m+(1-x_2)^m+\cdots+(1-x_l)^m)/l)^{1/m}$ 实现的泛逻辑运算叫多元零级泛平均运算，用泛平均命题连接词 $\circledcirc_h$ 表示)。

它的四个特殊算子是：

+   最大平均 Zadeh 平均算子：$M(x_1, x_2, \cdots, x_l, 1)=M_3=max(x_1, x_2, \cdots, x_l)$
+   中极平均 概率平均算子：$M(x_1, x_2, \cdots, x_l, 0.75)=M_2=1-((1-x_1)(1-x_2)\cdots(1-x_l))^{1/l}$
+   $(1-x_l))^{1/l}$
+   中心平均 有界平均算子：$M(x_1, x_2, \cdots, x_l, 0.5)=M_1=(x_1+x_2+\cdots+x_l)/l$
+   最小平均 突变平均算子：$M(x_1, x_2, \cdots, x_l, 0)=M_0=min(x_1, x_2, \cdots, x_l)$

# 定义 9.5.4 由一级 M 范数完整超链 $M(x_1, x_2, \cdots, x_l, h, k)=(1-(((1-x_1)^m+(1-x_2)^m+\cdots+(1-x_l)^m)/l)^{1/m})^{1/n}$ 实现的泛逻辑运算叫多元一级泛平均运算，用泛平均命题连接词 $\circledcirc_{h,k}$ 表示。

# 9.5.2 泛平均运算的性质

根据上述定义，可证明泛平均运算具有如下性质。

# 定理 9.5.1 $M(x, y, h, k)$满足平均公理。

证明 1)因为 $min(x, y) \leqslant M(x, y, h, k) \leqslant max(x, y)$，满足边界条件 M1；
2) 因为 $M(x, y, h, k)$关于 $x$、$y$ 单调增，满足单调性 M2；
3) 因为 $h, k \in (0, 1)$ 时，$M(x, y, h, k)$关于 $x$、$y$ 连续，满足连续性 M3；
4) 因为 $M(x, y, h, k)=M(y, x, h, k)$，满足交换律 M4；
5) 因为 $M(x, y, h, k)=x$，满足幂等性 M5。
所以本定理成立。

# 定理 9.5.2(封闭性) $M(x, y, h, k) \in [0, 1]$。

证明 略。

# 定理 9.5.3(自分配律) $M(x, M(y, z, h, k), h, k)=M(M(x, y, h, k), M(x, z, h, k), h, k)$。

证明 由于 $M(x, M(y, z, h, k), h, k)=((x^{nm}+(y^{nm}+z^{nm})/2)/2)^{1/nm}=((x^{nm}/2+y^{nm}/4+z^{nm}/4)^{1/nm})$，$M(M(x, y, h, k), M(x, z, h, k), h, k)=(((x^{nm}+y^{nm})/2+(x^{nm}+z^{nm})/2)/2)^{1/nm}=((x^{nm}/2+y^{nm}/4+z^{nm}/4)^{1/nm})$，$M(x, M(y, z, h, k), h, k)=M(M(x, y, h, k), M(x, z, h, k), h, k)$，所以本定理成立。
