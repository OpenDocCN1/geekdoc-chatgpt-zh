可为 S3 和 S0 之间的任意值外，当 h>0.75 时全部退化到 S3，当 h<0.75 时全部退化到 S0。

推论 8.5.5 通过规定可认为纯指数型一级 S 范数 S(x, y, 1, k)全部退化为 S3。

推论 8.5.6 通过规定可认为纯指数型一级 S 范数 S(x, y, 0, k)全部退化为 S0。
