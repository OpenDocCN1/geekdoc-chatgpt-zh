\(\Phi_1(\Phi_1(x, k_1), k_2) = \Phi_1(\Phi_1(x, k_2), k_1) = \Phi_1(x, k_3)\)。

2) 在指数函数簇 \(\Phi_2(x, k) = x^n, n > 0, k = 2^{-1/n}\) 中，任意两个生成元 \(\Phi_2(x, k_1) = x^{n_1}\) 和 \(\Phi_2(x, k_2) = x^{n_2}\)，其复合运算仍在簇中，且

\(\Phi_2(\Phi_2(x, k_1), k_2) = x^{n_1 n_2} = \Phi_2(x, k_3), k_3 = 2^{-1/(n_1 n_2)}\)

与复合运算的次序无关，\(\Phi_2(\Phi_2(x, k_1), k_2) = \Phi_2(\Phi_2(x, k_2), k_1) = \Phi_2(x, k_3)\)。

显然，它们的逆运算的复合运算也与次序无关

\(\Phi^{-1}(\Phi^{-1}(x, k_1), k_2) = \Phi^{-1}(\Phi^{-1}(x, k_2), k_1) = x^{1/(n_1 n_2)} = \Phi^{-1}(x, k_3)\)

所以圆元和满足交换律。

和交换律是圆元量词的第三移位规则：相邻圆元量词可以任意交换位置，其值不变。

\(\stackrel{\frown}{k_1} \stackrel{\frown}{k_2} x = \stackrel{\frown}{k_2} \stackrel{\frown}{k_1} x\)

# **定理 6.3.4(圆元和规则)** 计算圆元和 \(k_1 \oplus k_2\) 的规则是：

在多项式模型中，\(k_1 \oplus k_2 = k_1 k_2 / (1 - k_1 - k_2 + 2k_1 k_2)\)；

在指数模型中，\(k_1 \oplus k_2 = (2^n | a - = \log k_1 \log k_2)\)。

# **证明**

1) 由定理 6.3.3 知，在多项式模型簇 \(\Phi_1(x, k)\) 中，\(\Phi_1(\Phi_1(x, k_1), k_2) = \Phi_1(x, k_3)\)，与次序无关且 \(\lambda_3 = (1 + \lambda_1)(1 + \lambda_2) - 1\)。求逆得 \(\Phi_1^{-1}(\Phi_1^{-1}(x, k_1), k_2) = \Phi_1^{-1}(x, k_3)\)，用 \(k_3 = ((1 + \lambda_3)^{1/2} - 1) / \lambda_3\), \(\lambda_1 = (1 - 2k_1) / k_1^2\) 和 \(\lambda_2 = (1 - 2k_2) / k_2^2\) 代入，得 \(\lambda_3 = ((1 - k_1)^2 (1 - k_2)^2) / (k_1^2 k_2^2) - 1, k_3 = k_1 \oplus k_2 = 1 / (((1 - k_1)(1 - k_2)) / (k_1 k_2) + 1) = k_1 k_2 / (1 - k_1 - k_2 + 2k_1 k_2)\)。

2) 在指数函数簇 \(\Phi_2(x, k)\) 中，\(\Phi_2(\Phi_2(x, k_1), k_2) = \Phi_2(x, k_3)\)，与次序无关，且 \(k_3 = 2^{-1/n_3}, n_3 = n_1 n_2\)。

求逆得 \(\Phi_2^{-1}(\Phi_2^{-1}(x, k_1), k_2) = \Phi_2^{-1}(x, k_3)\)，用 \(n_1 = -1 / \log_2 k_1, n_2 = -1 / \log_2 k_2, n_3 = -1 / \log_2 k_3\) 代入，得 \(\log_2 k_3 = -\log_2 k_1 \log_2 k_2, k_3 = k_1 \oplus k_2 = (2^a | a - = \log_2 k_1 \log_2 k_2)\)。所以，本定理成立。

# **定理 6.3.5(对偶律)** 圆元和满足对偶律，\(k_1 \oplus k_2 = \Theta(\ominus k_1 \oplus \ominus k_2)\)。

# **证明**

1) 由定理 6.3.1 和定理 6.3.4 知，在多项式模型簇中，\(\ominus k = 1 - k\), \(k_1 \oplus k_2 = k_3 = k_1 k_2 / (1 - k_1 - k_2 + 2k_1 k_2)\)，而 \(\Theta(\ominus k_1 \oplus \ominus k_2) = 1 / (((1 - k_1)(1 - k_2)) / (1 - (1 - k_1)(1 - k_2) + 2(1 - k_1)(1 - k_2))) = k_1 k_2 / (1 - k_1 - k_2 + 2k_1 k_2) = k_1 \oplus k_2\)；

2) 在指数模型中，设 \(k_1\) 对应 \(n_1\), \(k_2\) 对应 \(n_2\), \(k_1 \oplus k_2\) 对应 \(n_1 n_2\)，则 \(\ominus k_1\) 对应 \(1 / n_1\), \(\ominus k_2\) 对应 \(1 / n_2\), \(\ominus k_1 \oplus \ominus k_2\) 对应 \(1 / (n_1 n_2)\)，所以 \(\Theta(\ominus k_1 \oplus \ominus k_2)\) 对应 \(1 / (1 / (n_1 n_2)) = n_1 n_2\)，即 \(k_1 \oplus k_2 = \Theta(\ominus k_1 \oplus \ominus k_2)\)。

所以，本定理成立。

\(\stackrel{\frown}{k_1} \ominus \stackrel{\frown}{k_2} x = \Phi^{-1}(\Phi^{-1}(x, k_1), \ominus k_2)\)
