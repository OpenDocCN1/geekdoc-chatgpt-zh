# 第 9 章 二元柔性命题逻辑连接词

在第 6 章中我们已经利用 N 性生成元完整整模 \(\Phi(x, k)\)，直接代入非命题连接词的基模型，得到泛非命题连接词的运算模型，实现了对一元命题连接词泛非的定义。类似地，利用 N 性生成元完整整模 \(\Phi(x, k)\) 和 T 性生成元完整整模 \(F(x, h)\) (或 S 性生成元完整整模 \(G(x, h)\))，直接代入各二元命题连接词的基模型，就可以得到各二元命题连接词的运算模型，包括零级完整整模和一级完整超整，从而实现对各二元命题连接词的定义。

本章将详细讨论各种二元命题连接词的定义、性质和逻辑蕴含意义。其中使用的指数型 N 性生成元完整整模 \(\Phi(x, k)\)、T 性生成元完整整模 \(F(x, h)\) 和非与形式的 NT 性基模型。

N 性生成元完整整模： \(\Phi(x, k)=x^n\)，其中 \(n=-1/log k, k \in [0, 1], k=2^{-1/n}, n \in \mathbf{R}_+\)。
N 范数完整整模： \(N(x, k)=(1-x^n)^{1/n}\)。
零级 T 性生成元完整整模： \(F(x, h)=x^m\)，其中， \(m=(3-4h)/(4h(1-h)), h \in [0, 1]\)； \(h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m \in \mathbf{R}\)。
一级 T 性生成元完整整模： \(F(x, h, k)=F(\Phi(x, k), h)=x^{mn}, k=2^{-1/n}, n \in \mathbf{R}_+\)。
NT 性基模型：

+   1) 泛与运算模型：
+   \(T(x, y, h, k)=F^{-1}(max(F(0, h, k), F(x, h, k)+F(y, h, k)-1), h, k)\)

+   2) 泛或运算模型：
+   \(S(x, y, h, k)=N(T(N(x, k), N(y, k), h, k), k)\)
+   \(=N(F^{-1}(max(F(0, h, k), F(N(x, k), h, k)+F(N(y, k), h, k)-1), h, k), k)\)

+   3) 泛蕴含运算模型：
+   \(I(x, y, h, k)=max(z|z \geqslant y T(x, z, h, k))\)
+   \(=F^{-1}(min(1+F(0, h, k), 1-F(x, h, k)+F(y, h, k)), h, k)\)

+   4) 泛等价运算模型：
+   \(Q(x, y, h, k)=T(I(x, y, h, k), I(y, x, h, k), h, k)\)
+   \(=F^{-1}(1\pm|F(x, h, k)-F(y, h, k)|, h, k)(h>0.75 为+,否则为-)\)

+   5) 泛平均运算模型：
+   \(M(x, y, h, k)=N(F^{-1}(F(N(x, k), h, k)/2+F(N(y, k), h, k)/2, h, k), k)\)
