根据泛逻辑研究，它是只满足独立相关准则的连续值逻辑 L(x, y, 0.75)。所以，它的基本性质是：

# 2) 有界逻辑的基本性质

根据泛逻辑研究，它是只满足最大相斥准则的连续值逻辑 L(x, y, 0.5)。所以，它的基本性质是：

+   L3 矛盾律 T(x, N(x), 0.5)=0
+   L4 排中律 S(x, N(x), 0.5)=1

# 3) 健全的有界逻辑形态，增加了两个必要条件

限制这些规律在任意的 h∈[0, 1]场景中随意使用。

可见，原来的有界逻辑是不健全的。
