当β=0.5 时权系数的影响消失：

+   Zadeh 等价 Q(x,y,1)=ite {1|x=y; min(x,y)}
+   概率等价 Q(x,y,0.75)=min(x/y, y/x)
+   有界等价 Q(x,y,0.5)=1-|x-y|
