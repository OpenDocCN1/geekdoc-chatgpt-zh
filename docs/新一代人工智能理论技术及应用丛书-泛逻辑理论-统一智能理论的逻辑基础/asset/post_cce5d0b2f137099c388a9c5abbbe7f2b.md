## 附录 C I 泛蕴含和 S 泛蕴含的有限合理性

下面分析I泛蕴含和S泛蕴含的有限合理性，我们仅讨论零级模型，判断的关键必要条件如下。

- 1) 兼容性。泛蕴含运算和泛串行推理运算与二值逻辑兼容：
I(0,0,h)=1, I(0,1,h)=1, I(1,0,h)=0, I(1,1,h)=1
R(0,0,h)=0, R(0,1,h)=0, R(1,0,h)=0, R(1,1,h)=1
- 2) 保序性。I(x,y,h)=1, iff x ≤ y。
- 3) 推演性。R(x,I(x,y,h),h) ≤ y。

### C.1 I 泛蕴含运算 \( I_t(x, y, h) \)

定义 C.1 零级 I 泛蕴含运算是 x 被 y 包含的程度，即

$I_t(x, y, h)=T(x, y, h)/x=(\max(0^m, x^{+m}y^{-m-1}))^{1/m}/x, m \in \mathbf{R}$

其中，$m=(3-4h)/4h(1-h); h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), h \in (0, 1)$。

它的四个典型运算模型是：

$I_t(x, y, 1)=I_{13}=\min(1, y/x) \text{ (Goguen 蕴含)}$
$I_t(x, y, 0.75)=I_{12}=y$
$I_t(x, y, 0.5)=I_{11}=\max(0, (x+y-1)/x)$
$I_t(x, y, 0)=I_{10}=\text{ite } \{y|x=1; 1|y=1; 0\}$

### 性质 C.1 I 泛蕴含运算具有以下性质。

- 1) 兼容性。I 泛蕴含运算与二值逻辑兼容：$I_t(0,0,h)=1, I_t(0,1,h)=1, I_t(1,0,h)=0, I_t(1,1,h)=1$
- 2) 保序性。仅有 $I_t(x, y, 1)=\min(1, y/x)$ 满足 $I_t(x, y, 1)=1, \text{ iff } x \le y$。
- 3) 单调性。$I_t(x, y, h)$ 关于 $x (h<0.75 \text{ 时})$ 和 $y$ 单调递增；$I_t(x, y, h)$ 关于 $x (h \ge 0.75 \text{ 时})$ 和 $y$ 单调递减。
- 4) 连续性。在 $(0, 1)$ 上 $I_t(x, y, h)$ 关于 $x, y, h$ 连续。
- 5) 封闭性。$I_t(x, y, h) \in [0, 1]$。

### C.2 I 泛串行推理运算 $R_i(x,y,h)$

定义 C.2 零级 I 泛串行推理运算是零级 I 泛蕴含运算的逆运算，即

$R_i(x,y,h)=\inf \{z|y \le T(x,z,h)/x\}=(1-x^{+m}x^{+m}y^{-m})^{1/m}, m \in \mathbf{R}$

其中，$m=(3-4h)/4h(1-h); h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), h \in (0, 1)$。

它的四个典型运算模型是：

$R_i(x,y,1)=R_{i3}=y=T_2$
$R_i(x,y,0.75)=R_{i2}=y$
$R_i(x,y,0.5)=R_{i1}=1-x+xy$
$R_i(x,y,0)=R_{i0}=\text{ite } \{y|x=1; 1\}$

### 性质 C.2 I 泛串行推理运算具有以下性质。

- 1) 兼容性。在 $R_i(x, y, h)$ 簇中，仅 $R_i(x, y, 1)$ 与二值逻辑兼容，即

$R_i(0, 0, 1)=0, R_i(0, 1, 1)=0, R_i(1, 0, 1)=0, R_i(1, 1, 1)=1$

- 2) 推演性。$R_i(x, I_i(x,y,h), h) \leqslant y$。

因为 $R_i(x, I_i(x, y, h), h) = (1-x^{m+}x^m((\max(0^m, x+y^m m^{-1})^{1/m} y^m)^{1/m})=1-x^{m+}(\max(0^m, x+y^m m^{-1}))^{1/m} \leqslant (1-x^{m+}x^m+y^m-1)^{1/m}=(y^m)^{1/m}=y$。

- 3) 单调性。仅有 $R_i(x, y, 1)$ 关于 $x$、$y$ 单调增。

- 4) 连续性。在 $(0, 1)$ 上 $R_i(x, y, h)$ 关于 $x$、$y$、$h$ 连续。

- 5) 交换律。仅 $R_i(x, y, 1) = R_i(y, x, 1)$。

- 6) 封闭性。$R_i(x, y, h) \in [0, 1]$。

### C.3 S 泛蕴含运算 $I_s(x, y, h)$

定义 C.3 零级 S 泛蕴含运算是 $1-x$ 和 $y$ 的零级泛或运算，即 $I_s(x, y, h) = S(1-x, y, h) = 1-(\max(0^m, x^m + (1-y)^m - 1))^{1/m}, m \in \mathbf{R}$

其中，$m=(3-4h)/4h(1-h); h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), h \in (0, 1)$。

它的四个典型运算模型是：

- $I_s(x, y, 1) = \mathbf{I}_{s3} = \max(1-x, y)$
- $I_s(x, y, 0.75) = \mathbf{I}_{s2} = 1-x+xy$
- $I_s(x, y, 0.5) = \mathbf{I}_{s1} = \min(1, 1-x+y)$ (Lukasiewicz蕴含)
- $I_s(x, y, 0) = \mathbf{I}_{s0} = \text{ite}\{y|x=1; 1-x|y=1; 1\}$

### 性质 C.3 S 泛蕴含运算具有以下性质：

- 1) 兼容性。S 泛蕴含运算与二值逻辑兼容：$I_s(0,0,h)=1, I_s(0,1,h)=1, I_s(1,0,h)=0, I_s(1,1,h)=1$

- 2) 保序性。仅在 $h=0.5$ 时满足 $I_s(x, y, h)=1$, iff $x \leqslant y$。

- 3) 单调性。$I_s(x, y, h)$ 关于 $y$ 单调递增，关于 $x$ 单调递减。

- 4) 连续性。在 $(0, 1)$ 上 $I_s(x, y, h)$ 关于 $x$、$y$ 连续。

- 5) 交换律。$I_s(x, y, h) = I_s(1-y, 1-x, h)$。

- 6) 封闭性。\(I_s(x, y, h) \in [0, 1]\).

- 7) 下界性。\(I_s(x, y, h) \gg \max(1-x, y)\).

- 8) 恒真性。\(h \le 0.5\) 时 \(I_s(x, x, h)=1\)，一般 \(I_s(x, x, h) \gg 0.5\)。

### C.4 S 泛串行推理运算 \(R_s(x, y, h)\)

定义 C.4 零级 S 泛串行推理运算是零级 S 泛蕴含运算的逆运算，即

```
R_s(x, y, h)=inf\{z|\exists I_s(x, z, h)\}=1-(min(1+0^m, (1-y)^m - x^m + 1))^{1/m}, \ m \in \mathbf{R}
```

其中，\(m=(3-4h)/4h(1-h); h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), h \in (0, 1)$。

它的四个典型运算模型是：

```
R_s(x, y, 1) = \mathbf{R}_{s3} = \text{ite}\{y | 1-x < y; 0\}
R_s(x, y, 0.75) = \mathbf{R}_{s2} = \Gamma[(x+y-1)/x]
R_s(x, y, 0.5) = \max(0, x+y-1) = \mathbf{T}_1
R_s(x, y, 0) = \mathbf{R}_{s0} = \text{ite}\{y | x=1; 0\}
```

### 性质 C.4 S 泛串行推理运算具有以下性质：

- 1) 兼容性。S 泛串行推理运算与二值逻辑兼容：

```
R_s(0, 0, h)=0, R_s(0, 1, h)=0, R_s(1, 0, h)=0, R_s(1, 1, h)=1。
```

- 2) 推演性。\(R_s(x, I_s(x, y, h), h) \leqslant y$。

```
因为 \(R_s(x, I_s(x, y, h), h)=1-(min(1+0^m, \max(0^m, x^m + (1-y)^m - 1) - x^m + 1))^{1/m} \leqslant 1-(min(1+0^m, (1-y)^m))^{1/m} = 1 - (1-y) = y\)。
```

- 3) 单调性。\(R_s(x, y, h)$ 关于 \(x\)、\(y\) 单调递增。

- 4) 连续性。除 \(h=1\) 外，在 \((0, 1)\) 上 \(R_s(x, y, h)$ 关于 \(x\)、\(y$ 连续。

- 5) 交换律。仅有 \(R_s(x, y, 0.5)=R_s(y, x, 0.5)$。

- 6) 封闭性。\(R_s(x, y, h) \in [0, 1]$。

- 7) 上界性。\(R_s(x, y, h) \leqslant y$。

- 8) 幂不等性。\(R_s(x, x, h) \leqslant \varnothing$。

- 9) 沉静域。如果 \(y<1-x$，则 \(R_s(x, y, h)=0$。

## 附录 D 泛等价命题连接词的同性模型

泛等价命题连接词的另一个可能定义方法是同性模型，它认为等价是同真或同假的程度，即 \( Q(x, y, h)=S(T(x, y, h), T(1-x, 1-y, h), h) \) 。下面分析这种定义方式的合理性，依据的关键必要条件如下。

- 1) 与二值逻辑的兼容性: \( Q(0, 0, h)=1, Q(0, 1, h)=0, Q(1, 0, h)=0, Q(1, 1, h)=1 \)。

- 2) 保恒性: \( Q(x, y, h)=1, \text{iff} x=y \)。

- 3) 由于 \( T(x, y, h) \leq \min(x, y)$, \( T(1-x, 1-y, h, k) \leq \min(1-x, 1-y)$, \( S(T(x, y, h), T(1-x, 1-y, h) ) > \max(T(x, y, h), T(1-x, 1-y, h)) \)，从图 D.1 中的三维图上可以看出，当 \( x=y \) 时，\( Q(x, y, h) > \max(x, 1-x) \)，除了 \( Q(0, 0, h)=1, Q(1, 1, h)=1 \) 外，不满足保恒性。

- 4) 结论。除了二值逻辑外，同性泛等价的观点没有合理性。

## 附录 E 泛弱组合命题连接词

泛组合运算在 \( x+y=2e \) 附近有一个阶跃，这在通常情况下是合理的，因为 \( e \) 是决策中的关键量，通过或不通过的分界线，在它的附近应该发生质的突变。但有些情况下的决策希望能在 \( x+y=2e \) 附近平缓过渡，避免因为 \( x, y \) 的微小变化引起结果的大跃变。为此我们引入了一个泛弱组合命题连接词，它的基模型仍然是\(\Gamma[x+y-e]\)，但弱组合运算基模型的非与表达不同于组合运算的基模型：

\(C^e(x, y, h, k)=ite\{\Gamma^e[F^{-1}(F(x, h, k)+F(y, h, k)-F(e, h, k), h, k)]|x, y<e;\)
\(N(\Gamma^e[F^{-1}(F(N(x, k), h, k)+F(N(y, k), h, k)-F(N(e, k), h, k), h, k)]|x, y>e;\)
\(\Phi^{-1}(\Phi(x, k)+\Phi(y, k)-\Phi(e, k), k), e'=N(e, k)\)

其中，第三项 \(\Phi^{-1}(\Phi(x, k)+\Phi(y, k)-\Phi(e, k))\) 中没有 \(h\) 的影响，这是因为假设在 \(x\)、\(y\) 意见相反时，只能是最大相异，\(h=0.5\)。

由零级 T 性生成元完整簇 \(F_0(x, h)=x^m\) 代入弱组合运算的基模型生成的零级 C 范数完整簇 \(C^e(x, y, h)=ite\{\Gamma^e[(x^m+y^m-e^m)^{1/m}]|x, y<e; 1-[\Gamma^{1-e}(((1-x)^m+(1-y)^m)-(1-e)^m]^{1/m})|x, y>e; x+y-e\}\) 实现的泛逻辑运算叫零级泛弱组合运算，用泛弱组合命题连接词 \(\circledast_h\) 表示。其中：\(m=(3-4h)/4h(1-h)\); \(h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), h\in[0, 1], m\in\mathbf{R}\)。
它的四个特殊算子如下。

### 上限组合： Zadeh 弱组合

\(C^e(x, y, 1)=C^e_3=ite\{\min(x, y)|x, y<e; \max(x, y)|x, y>e; x+y-e\}\)

### 中极组合：概率弱组合

\(C^e(x, y, 0.75)=C^e_2=ite\{xy/e|x, y<e; (x+y-xy-e)/(1-e)|x, y>e; x+y-e\}\)

### 中心组合：有界弱组合

\(C^e(x, y, 0.5)=C^e_1=\Gamma[x+y-e]\)

### 下限组合：突变弱组合

\(C^e(x, y, 0)=C^e_0=ite\{0|x, y<e; 1|x, y>e; x+y-e\}\)

由一级 T 性生成元完整超簇 \(F(x, h, k)=x^m\) 代入弱组合运算的基模型生成的一级 C 范数完整超簇 \(C^e(x, y, h, k)=ite\{\Gamma^e[(x^{mn}+y^{mn}-e^{mn})^{1/mn}]|x, y<e; (1-(\Gamma^e[((1-x)^{mn}+(1-y)^{mn})-(1-e)^{mn}])^{1/mn}]^{1/m}|x, y>e; (x^n+y^n-e^n)^{1/n}\}, e'=(1-e)^n\) 实现的泛逻辑运算叫一级泛弱组合运算，用泛弱组合命题连接词 \(\circledast_{h,k}$ 表示。其中：\(n=-1/\log_2 k, k\in[0, 1]; k=2^{-1/n}, n\in\mathbf{R}_+\)。

\(C^e(x, y, 0.75, k)=C\Phi^{2-e}_k=ite\{xy/e|x, y<e; (1-(1-x)^n(1-y)^n/(1-e)^n)^{1/m}|x, y>e; (x^n+y^n-e^n)^{1/m}\}\)

根据上述定义，可证明泛弱组合运算具有如下性质。

- 1) \(C^e(x, y, h, k)$ 满足组合公理。

- 2) 封闭性。 \(C^e(x, y, h, k)\in[0, 1]$。

- 3) 逆元件。 \(C^e(x, x', h, k)=e, x'=(2e^n-x^n)^{1/n}\)。

- 4) 弃权件。 \(C^e(e, e, h, k)=e$。

泛弱组合运算模型和泛组合运算模型的关键差别是 \(x\)、\(y\) 的意见相反时，运算模型是否还受到 \(h\) 的影响。

根据多元组合基模型 \(C^e(x_1, x_2, \cdots, x_i)=\Gamma[x_1+x_2+\cdots+x_i-(1-f)e]\)，泛弱组合运算
