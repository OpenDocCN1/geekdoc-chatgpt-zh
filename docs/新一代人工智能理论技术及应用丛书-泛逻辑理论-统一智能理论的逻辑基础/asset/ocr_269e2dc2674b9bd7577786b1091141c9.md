# 2) 突变逻辑的基本性质

根据泛逻辑研究，它是只满足最大相克准则的连续值逻辑 L(x, y, 0)。所以，它的基本性质是：

+   L3 矛盾律 T(x, N(x), 0.5)=0

+   L4 排中律 S(x, N(x), 0.5)=1

+   L5 对合律 N(N(x))=x

# 3) 健全的突变有界逻辑形态，增加了三个基本性质

+   L1 幂等律 T(x, x, 1)=x

+   L2 幂等律 S(x, x, 1)=x

+   L6 MP 规则 T(x, I(x, y, h), h)<=y

限制这些规律在任意的 h ∈ [0, 1]场景中随意使用。

可见，原来的突变逻辑是不健全的。

# 2. 关于三值逻辑的健全性
