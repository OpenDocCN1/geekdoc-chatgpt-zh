# 定义 11.2.7 一级二元泛平均生成元加权运算模型完整簇为

M(x, y, h, k, β) = Φ⁻¹(1 - F⁻¹((2β(F(Φ(1-x, k), h) + 2(1-β)F(Φ(1-y, k), h))/2, h), k)
= (1 - (2β(1-x")^m + 2(1-β)(1-y")^m)/2)^{1/m})^{1/n}

k、h、β 三个参数排列组合出来的状态很多，无法在这里全部展示出来，我们选择了 k=0.25 和 k=0.75 两种情况下的 25 种状态以代表全貌。
