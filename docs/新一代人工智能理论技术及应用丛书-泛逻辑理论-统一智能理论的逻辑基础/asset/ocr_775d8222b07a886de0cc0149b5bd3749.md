结合律 S4。

所以 S(x, y)=max(x, y)是最小的 S 范数。

# 定理 7.2.18 S(x, y)=ite{max(x, y)|min(x, y)=0; 1}是最大的 S 范数。

证明 1)由于 S(0, y)=y， S(1, y)=1， 满足 S 范数的边界条件 S1；
2) S(x, y)关于 x、 y 单调增， 满足 S 范数的单调性 S2；
3) S(x, S(y, z))=S(S(x, y), z)=S(x, y, z)， 满足 S 范数的结合律 S4；
4) S(x, y)=S(y, x)， 满足 S 范数的交换律 S5。

所以 S(x, y)是 S 范数。而任何 S 范数 S'(x, y)都满足 S'(x, y)<=1, S'(0, y)=y, S(x, y)=ite{max(x, y)|min(x, y)=0; 1}是其中的最大者， 所以本定律成立。

# 7.3 T 范数和 S 范数的生成方法

# 7.3.1 T 性/S 性生成元的物理意义义

由前面的讨论我们已经知道， 在因素空间 E 中， 对任意分明子集 X, Y∈E， 如果它们之间的广义相关性是最大相反， h=0.5， 且柔性测度 m(X)=x, m(Y)=y 是精确的测度， k=0.5， 则有中心 T 范数和中心 S 范数成立， 即

```
T(x, y) = max(0, x + y - 1)
S(x, y) = min(1, x + y)
(7-1)
```

或者当广义相关系数 h 偏离 0.5 时， X、 Y 之间相容或相克； 或者当广义自相关系数 k 偏离 0.5 时， 柔性测度有误差， 这时式(7-1)不再成立， 需要用定义在[0, 1]上的连续的严格单调的一元函数 f(x)和 g(x)来双向调整它们对逻辑运算的影响， 于是有

```
f(T(x, y)) = max(f(0), f(x) + f(y) - 1)
T(x, y) = f^-1(max(f(0), f(x) + f(y) - 1))
g(S(x, y)) = min(g(1), g(x) + g(y))
S(x, y) = g^-1(min(g(1), g(x) + g(y)))
(7-2)
```

这就是 T 性生成元和 S 性生成元的物理意义， 下面我们用三角范数理论来严格证明它们的正确性。
