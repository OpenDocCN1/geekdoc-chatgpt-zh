# 图 9.12 零级泛组合运算的灰度图

1) 泛组合运算的逻辑学意义是综合决策，它可以在[0, 1]中取值，并有表示弃权的元素 e，e 是泛组合运算的与、或性分界线。

2) C^e(x, y, h, k)有两条泛组合特征线：C^e(e, e, h, k)=x, C^e(e, y, h, k)=y。

3) e 的连续可调性：e 是泛组合运算的决策门限值，e=0 表示不设门限控制，泛组合运算退化为泛或运算。随着 e 从 0 到 1 连续增大，门限值不断提高，泛组合运算的泛或运算区域不断减小，泛与运算区域不断扩大。e=0.5 是正常门限值，与、或区域各半，e=1 表示最高门限控制，泛组合运算退化为泛与运算。

4) 泛组合性：泛组合运算随 h 连续可调，h 是泛组合运算的宽容度，h=0 表示组合运算的宽容度最小，如果 x, y>e，则 C^e(x, y, 0, k)=1；如果 x, y<e，则 C^e(x, y, 0, k)=0。随着 h 从 0 到 1 连续增大，组合运算的宽容度连续增大。h=0.5 表示组合运算的宽容度适中，C^e(x, y, 0.5, 0.5)=Γ[x+y-e]。h=1 表示组合运算的宽容度最
