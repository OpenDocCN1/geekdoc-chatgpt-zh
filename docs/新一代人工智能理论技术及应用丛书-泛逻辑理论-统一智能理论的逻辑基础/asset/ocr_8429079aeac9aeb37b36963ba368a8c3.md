# 定理 9.3.17 (自分配律) I(x, I(y, z, 1, k), 1, k)=I(I(x, y, 1, k), I(x, z, 1, k), 1, k)。

# 定理 9.3.18 I(T(x, y, h, k), z, h, k)=I(x, I(y, z, h, k), h, k)。

# 定理 9.3.19 如果 x<=y 或 x, y \in {0, 1}，则 I(I(x, y, h, k), x, h, k)=x。

# 定理 9.3.20 如果 x<=y 或 x, y \in {0, 1}，则 I(x, I(x, y, h, k), h, k)=I(x, y, h, k)。

# 定理 9.3.21 I(x, y, 0.5, k)=S(N(x, k), y, 0.5, k)。
