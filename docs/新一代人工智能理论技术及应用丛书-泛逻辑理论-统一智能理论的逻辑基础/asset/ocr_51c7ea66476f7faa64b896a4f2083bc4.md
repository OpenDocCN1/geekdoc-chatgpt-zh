# 6. 泛平均运算公理

设 M(x, y, h, k) 是 [0, 1]^2 -> [0, 1] 的二元含参运算，如满足以下公理就是泛平均运算。

+   边界条件 M1 min(x, y)⩽M(x, y, h, k)⩽max(x, y).
+   单调性 M2 M(x, y, h, k)关于 x、y 单调增。
+   连续性 M3 h, k ∈ (0, 1) 时，M(x, y, h, k)关于 x、y 连续。
+   交换律 M4 M(x, y, h, k) = M(y, x, h, k)。
+   幂等性 M5 M(x, x, h, k) = x。

# 7. 泛组合运算公理

设 C^c(x, y, h, k) 是 [0, 1]^2 -> [0, 1] 的二元含参运算，如满足以下公理就是泛组合运算。

+   边界条件 C1 当 x, y < e时，C^c(x,y,h,k)⩽min(x, y); 当 x, y > e时，C^c(x, y, h, k)⩾max(x, y); 当 x+y=2e 时；C^c(x, y, h, k) = e; 否则，min(x, y)⩽C^c(x, y, h, k)⩽max(x, y)。
+   单调性 C2 C^c(x, y, h, k)关于 x、y 单调增。
+   连续性 C3 h, k ∈ (0, 1) 时，C^c(x, y, h, k)关于 x、y 连续。
+   交换律 C4 C^c(x, y, h, k) = C^c(y, x, h, k)。
+   幺元律 C5 C^c(x, e, h, k) = x。

# 5.4.2 泛逻辑运算的基模型

如果柔性测度 m(*) 没有误差 k=0.5，广义相关性是最大相斥状态 h=0.5，则各种命题连接词运算模型完整簇 N(0, k)、T(x, y, h, k)、S(x, y, h, k)、I(x, y, h, k)、Q(x, y, h, k)、M(x, y, h, k)、C^c(x, y, h, k) 满足以下中心算子(图 5.12)，在泛逻辑学中这些中心算子被定义为相应逻辑运算的基模型。

+   1) 泛非运算的基模型
+   N(x)=N(x, 0.5)=N_I=1-x
+   2) 泛与运算的基模型
+   T(x, y)=T(x, y, 0.5, 0.5)=T_I=max(0, x+y-1)
+   3) 泛或运算的基模型
+   S(x, y)=S(x, y, 0.5, 0.5)=S_I=min(1, x+y)
+   4) 泛蕴含运算的基模型
+   I(x, y)=I(x, y, 0.5, 0.5)=max(z|y⩾T(x, z))=I_I=min(1, 1-x+y)
