7 号模式非与运算可受 $k$、$h$、$\beta$的联合影响，是一个运算模型完整簇，即
$N(T(x, y, h, k, \beta), k) = (1 - (\max(0, 2\beta x^{nm} + 2(1-\beta)y^{nm} - 1))^{1/m})^{1/n}$
当$\beta=0.5$ 时权系数的影响消失：
$N(T(x, y, h, k), k) = (1 - (\max(0, x^{nm} + y^{nm} - 1))^{1/m})^{1/n}$
当$k=0.5$ 时误差系数的影响消失：
$N(T(x, y, h), 0.5) = 1 - (\max(0, x^m + y^m - 1))^{1/m}$

# 13.4.10 +14 号和+1 号信息处理模式的元-子二相性

图 13.14 是+1 号模式和+14 号模式，它们具有元-子二相性。

+14 号模式平均运算可受 $k$、$h$、$\beta$的联合影响，是一个运算模型完整簇，即
$M(x, y, h, k, \beta) = (1 - (\beta(1-x^n)^m + (1-\beta)(1-y^n)^m)^{1/m})^{1/n}$

当$\beta=0.5$ 时权系数的影响消失：
$M(x, y, h, k) = (1 - ((1-x^n)^m + (1-y^n)^m)^{1/m})^{1/n}$

当$k=0.5$ 时误差系数的影响消失：
$M(x, y, h) = 1 - ((1-x)^m + (1-y)^m)^{1/m}$

+   $M(x, y, h)$ 有四个特殊算子：
+   - Zadeh 平均 $M(x, y, 1) = \max(x, y)$
+   - 概率平均 $M(x, y, 0.75) = 1 - ((1-x)(1-y))^{1/2}$
+   - 有界平均 $M(x, y, 0.5) = (x+y)/2$
+   - 突变平均 $M(x, y, 0) = \min(x, y)$

+   常见的平均算子还有：
+   - 几何平均 $1 - M(1-x, 1-y, 0.75) = (xy)^{1/2}$
+   - 调和平均 $1 - M(1-x, 1-y, 0.866) = 2xy/(x+y)$

可见柔性信息处理的平均运算完整簇能够包容各种平均算子。

+1 号模式非平均运算可受 $k$、$h$、$\beta$的联合影响，是一个运算模型完整簇，即
$N(M(x, y, h, k, \beta), k) = (\beta(1-x^n)^m + (1-\beta)(1-y^n)^m)^{1/nm}$
