# 2. 数理逻辑的可靠性与完备性(soundness and completeness)

# (1) 可靠性定理

令 \(\varphi_1, \varphi_2, \cdots, \varphi_n\) 和 \(\psi\) 为命题逻辑中的公式，如 \(\varphi_1, \varphi_2, \cdots, \varphi_n \models \psi\) 在传统形式逻辑中是有效的，则 \(\varphi_1, \varphi_2, \cdots, \varphi_n \models \psi\) 在数理逻辑中是有效的。

意思是如在语法上可用推导规则则将 \(\varphi_1, \varphi_2, \cdots, \varphi_n\) 转化为 \(\psi\)，则在语义上，如 \(\varphi_1, \varphi_2, \cdots, \varphi_n\) 都为真，则 \(\psi\) 一定为真。反之，如 \(\psi\) 为假，则在语义上 \(\varphi_1, \varphi_2, \cdots, \varphi_n\) 至少有一个是假，也就是说，在语法上不可能用推导规则将 \(\varphi_1, \varphi_2, \cdots, \varphi_n\) 转化为 \(\psi\)。

可见，利用可靠性可确定有些证明是不存在的。例如，给定前提 \(\varphi_1, \varphi_2, \cdots, \varphi_n\)，能否证明 \(\psi\)？这是在问：\(\varphi_1, \varphi_2, \cdots , \varphi_n \models \psi\) 是否有效？如果这个前提和结论非常复杂，你证明不出来。但证明不出来不等于证明本身不存在。这时候可靠性定理就可以发挥作用。可将问题转化为：\(\varphi_1, \varphi_2, \cdots , \varphi_n \models \psi\) 是否有效。这样就完全可以根据真值表用数学方法来确定。假如用真值表确定 \(\varphi_1, \varphi_2, \cdots, \varphi_n \models \psi\) 是无效的，就完全可以断言：\(\varphi_1, \varphi_2, \cdots, \varphi_n \models \psi\) 是无效的，即这个证明根本不存在。

# (2) 完备性定理

令 \(\varphi_1, \varphi_2, \cdots, \varphi_n\) 和 \(\psi\) 为命题逻辑中的公式，如在数理逻辑中 \(\varphi_1, \varphi_2, \cdots, \varphi_n \models \psi\) 是有效的，那么 \(\varphi_1, \varphi_2, \cdots, \varphi_n \models \psi\) 在传统形式逻辑中是有效的。

可见，完备性定理和可靠性定理正好相反。它的意思是说：在一个逻辑系统中，如从语义上看 \(\varphi_1, \varphi_2, \cdots, \varphi_n \models \psi\) 是有效的，则一定可为 \(\varphi_1, \varphi_2, \cdots, \varphi_n \models \psi\) 找到一个证明。

完备性的作用是：如 \(\varphi_1, \varphi_2, \cdots, \varphi_n \models \psi\) 是有效的，则这样的证明一定存在。如逻辑系统不满足完备性，那么即使 \(\varphi_1, \varphi_2, \cdots, \varphi_n \models \psi\) 是有效的，它的证明也可能不存在。

可靠性和完备性的相互配合，确保了数理逻辑的安全使用，没有出现过异常。

# 3. 数理逻辑对传统形式逻辑的巨大贡献
