一般情况下 N 余簇不同于 N 元簇 \(\Phi(x, k)\)，但 Sugeno 算子簇特殊，它的 N 余簇就是 N 元簇。

# 定理 6.24 广义 Sugeno 算子簇的 N 余簇 \(N(1-x, k)\) 就是 N 元簇 \(\Phi(x, k)\)。

证明 设 \(\lambda_1=(1-2k_1)/k_1^2\)， \(\Phi(x, k_1)=x(1+\lambda_1)^{1/2}/(1+((1+\lambda_1)^{1/2}-1)x)\)
\( N(x, k_1)=(1-x)/(1+\lambda_1 x) \)
\( N(1-x, k_1)=x/(1+\lambda_1(1-x))=x/(1+\lambda_1-\lambda_1 x)=(x/(1+\lambda_1))/(1-\lambda_1 x/(1+\lambda_1)) \)
\( =x(1+\lambda_2)^{1/2}/(1+((1+\lambda_2)^{1/2}-1)x)=\Phi(x, k_2) \)
\( \lambda_2=(1-2k_2)/k_2^2=(1/((1+\lambda_1)^2)-1 \)

所以本定理成立。
