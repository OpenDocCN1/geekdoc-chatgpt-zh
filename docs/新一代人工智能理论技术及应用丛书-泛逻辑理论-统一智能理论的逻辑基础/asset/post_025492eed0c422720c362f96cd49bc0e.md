
## 2. 伪偏序空间的拓扑规则

在 n 级不确定性推理中，命题的真值需要用一个 n 元数组来表示，但命题的真值在本质上仍然是一维的，它的每个分量都只是从不同的角度描述了这个一维命题，属于伪偏序空间。它的逻辑运算模型(零级或一级)服从以下拓扑规则：

```
N(x)=<N(x1), N(x2), · · · , N(xn)>
T(x, y)=<T(x1, y1), T(x2, y2), · · · , T(xn, yn)>
S(x, y)=<S(x1, y1), S(x2, y2), · · · , S(xn, yn)>
I(x, y)=<I(x1, y1), I(x2, y2), · · · , I(xn, yn)>
Q(x, y)=<Q(x1, y1), Q(x2, y2), · · · , Q(xn, yn)>
M(x, y)=<M(x1, y1), M(x2, y2), · · · , M(xn, yn)>
C(x, y)=<C(x1, y1), C(x2, y2), · · · , C(xn, yn)>
```

其中，x=<x1, x2, · · · , xn>; y=<y1, y2, · · · , yn>; N(x)、T(x, y)、S(x, y)、I(x, y)、Q(x, y)、M(x, y)和 C(x, y)是标准基空间[0, 1]上的逻辑运算模型(零级或一级)。

## 3. ⊥超序空间的拓扑规则

如果真值域为超序空间{⊥} ∪ [0, 1]n, n=1, 2, 3, · · · ，则表示推理中需要考虑无定义状态上，应该在偏序规则的基础上增加关于上⊥的拓扑规则，有平凡和非平凡两种。

- (1) 非平凡拓扑规则
- 1) N(⊥, k)=⊥;
- 2) T(⊥, y, h, k)={⊥|y=⊥; 0};
- 3) S(⊥, y, h, k)={⊥|y=⊥; 1};
- 4) I(⊥, y, h, k)={1|y=⊥; ⊥}, I(x, ⊥, h, k)={1|x=⊥; ⊥};
- 5) Q(⊥, y, h, k)={1|y=⊥; ⊥};
- 6) M(⊥, y, h, k)=y;
- 7) C(⊥, y, h, k)={⊥|y=⊥; 0|y<k; 1|y>k; k}.
- (2) 平凡拓扑规则
- 凡⊥参加的运算,结果都为⊥。

## 4. α超序空间的拓扑规则

如果真值域为超序空间[0, 1]n < α>, n=1, 2, 3, · · · ，则表示推理中需要考虑附加特性 α，应该在偏序规则的基础上增加关于 α 的拓扑规则，不同的附加特性有不同的运算法则，无法一一枚举，这里仅给出拓扑原则如下：

如果 p 的逻辑真值为 x<α>, q 的逻辑真值为 y<β>，则在逻辑运算过程中，除 x、y 参加逻辑运算模型 L(x, y)的运算，得到逻辑真值 z 外，附加特性 α、β也要参加附加特性运算模型 \( L'(\alpha, \beta) \) 的运算，得到附加特性值 \(\gamma\)。即 \( x<\alpha> \) 和 \( y<\beta> \) 的逻辑运算结果 \( z<\gamma> \) 是由两种不同的运算模型得到的，\( z=L(x, y), \gamma=L'(\alpha, \beta) \)。

## 10.2.4 基空间变换规则

基空间变换规则具体规定了将标准基空间[0, 1]变换为任意基空间[a, b], a<b, a, b∈R 时，各种命题连接词运算模型的变换方法。

- 1) [0, 1]的基本语义是真假程度，还可变换成其他语义：如高低程度、通断程度、亮度、大小程度、是非程度、正负程度、有无程度、生病程度、赞成程度、成功程度和可信度等。
- 2) 标准基空间[0, 1]有各种变种，如[0, 100], [0, b], [0, +∞], [-1, 1], [-5, 5], [-b, b], (-∞, +∞), [a, b] (b>a>0)等，可以通过坐标变换把[0, 1]中的规律变换到它的各种变种中去。例如：
- 单向有限扩展 [0, 1]->[0,b]: x'=bx, 中元 e'=b/2;
- 单向无限扩展 [0, 1]->[0, +∞]: x'=x/(1-x), 中元 e'=1;
- 任意有限扩展[0, 1]->[a, b]: x'=(b-a)x+a, 中元 e'=(b+a)/2;
- 双向有限扩展[0, 1]->[-b, b]: x'=2bx-b, 中元 e'=0;
- 双向无限扩展 [0, 1]->(-∞, +∞): x'=(x-0.5)/x(1-x), 中元 e'=0。

通过基空间变换规则处理后，泛逻辑学可由标准形式特化为有很强针对性的应用形式。

## 10.3 泛逻辑学命题连接词的运算模型

下面仅给出结指数模型，它是最常用的泛逻辑命题连接词运算模型。

### 1. 泛非命题连接词~_k 的运算模型

```
N(x, k)=(1-x^n)^{1/n}
```

其中，k=2^{-1/n}, n∈R+，或 n=-1/log_2k, k∈[0, 1]。

### 2. 泛与命题连接词∧_{h,k} 的运算模型

### 1) 二元模型

```
T(x, y, h, k)=(max(0, x^{nm}+y^{nm}-1))^{1/nm}
```

其中，k=2^{-1/n}, n∈R+ 或 n=-1/log_2k, k∈[0, 1]; m=(3-4h)/(4h(1-h)), h∈[0, 1] 或 h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m∈R。

它的四个特殊算子是：

- 最大与 Zadeh 与算子 T(x, y, 1, k)=T_3=min(x, y)
- 中极与 概率与算子 T(x, y, 0.75, k)=T_2=xy
- 中心与 有界与算子 T(x, y, 0.5, 0.5)=T_1=max(0, x+y-1)
- 最小与 突变与算子 T(x, y, 0, k)=T_0=ite {min(x, y)|max(x, y)=1; 0}

### 2) 多元模型

```
T(x_1, x_2, \cdots, x_l, h, k)=(max(0, x_1^{nm}+x_2^{nm}+\cdots+x_l^{nm}-(l-1)))^{1/nm}
```

其中，k=2^{-1/n}, n ∈ R+ 或 n=-1/log_2 k, k ∈ [0, 1] ; m=(3-4h)/(4h(1-h)), h ∈ [0, 1] 或 h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m ∈ R。

它的四个特殊算子是：

- 最大与 Zadeh 与算子 T(x_1, x_2, \cdots, x_l, 1, k)=T_3=min(x_1, x_2, \cdots, x_l)
- 中极与 概率与算子 T(x_1, x_2, \cdots, x_l, 0.75, k)=T_2=x_1 x_2 \cdots x_l
- 中心与 有界与算子 T(x_1, x_2, \cdots, x_l, 0.5, 0.5)=T_1=max(0, x_1+x_2+\cdots+x_l-(l-1))
- 最小与 突变与算子 T(x_1, x_2, \cdots, x_l, 0, k)=T_0=ite {min(x_1, x_2, \cdots, x_l) | (x_1, x_2, \cdots, x_l)中有(l-1)个 1; 0}

### 3. 泛命题连接词 ∨_{h,k} 的运算模型

### 1) 二元模型

$$S(x, y, h, k)=(1-(\max(((1-x)^{nm}+(1-y)^{nm}-1))^{1/m})^{1/n})$$

其中，k=2^{-1/n}, n ∈ R+ 或 n=-1/log_2 k, k ∈ [0, 1] ; m=(3-4h)/(4h(1-h)), h ∈ [0, 1] 或 h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m ∈ R。

它的四个特殊算子(簇)是：

- 最小或 Zadeh 或算子 S(x, y, 1, k)=S_3=max(x,y)
- 中极与 概率或算子 S(x, y, 0.75, k)=S\Phi_{2k}=(x^n+y^n-x^n y^n)^{1/n}
- 中心与 有界或算子 S(x, y, 0.5, 0.5)=S_1=min(1, x+y)
- 最大或 突变或算子 S(x, y, 0, k)=S_0=ite {max(x,y)|min(x,y)=0; 1}

### 2) 多元模型

$$S(x_1, x_2, \cdots, x_l, h, k)=(1-(\max(0, (1-x_1)^{nm}+(1-x_2)^{nm}+\cdots+(1-x_l)^{nm}-(l-1)))^{1/m})^{1/n})$$

其中，k=2^{-1/n}, n ∈ R+ 或 n=-1/log_2 k, k ∈ [0, 1] ; m=(3-4h)/(4h(1-h)), h ∈ [0, 1] 或 h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m ∈ R。

它的四个特殊算子(簇)是：

- 最小或 Zadeh 或算子 S(x_1, x_2, \cdots, x_l, 1, k)=S_3=max(x_1, x_2, \cdots, x_l)
- 中极与 概率或算子 S(x_1, x_2, \cdots, x_l, 0.75, k)= S\Phi_{2k}=(1-(1-x_1^n)(1-x_2^n)\cdots(1-x_l^n))^{1/n}
- 中心与 有界或算子 S(x_1, x_2, \cdots, x_l, 0.5, 0.5)=S_1=max(l-1, x_1+x_2+\cdots+x_l)
- 最大或 突变或算子 S(x_1, x_2, \cdots, x_l, 0, k)=S_0=ite {max(x_1, x_2, \cdots, x_l)|(x_1, x_2, \cdots, x_l)中有(l-1)个 0; 1}

### 4. 泛蕴含命题连接词 $\rightarrow_{h,k}$ 的运算模型

$$I(x, y, h, k)=(\min(1, 1-x^{nm}+y^{nm}))^{1/nm}$$

其中，$k=2^{-1/n}, n\in\mathbf{R}^{+}$ 或 $n=-1/\log_2 k, k\in[0, 1]$ ; $m=(3-4h)/(4h(1-h)), h\in[0, 1]$ 或 $h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m\in\mathbf{R}$。

- 它的四个特殊算子是：
- 最小蕴含 Zadeh 蕴含 \( I(x, y, 1, k)=\mathbf{I}_3=\text{ite}\{1|x\leqslant y; y\} \)
- 中极蕴含 概率蕴含 \( I(x, y, 0.75, k)=\mathbf{I}_2=\min(1, y/x) \)
- 中心蕴含 有界蕴含 \( I(x, y, 0.5, 0.5)=\mathbf{I}_1=\min(1, 1-x+y) \)
- 最大蕴含 突变蕴含 \( I(x, y, 0, k)=\mathbf{I}_0=\text{ite}\{y|x=1; 1\} \)

### 5. 泛等价命题连接词 $\leftrightarrow_{h,k}$ 的运算模型

$$Q(x, y, h, k)=(1\pm|x^{nm}-y^{nm}|)^{1/nm}$$

其中，\( h>0.75 \) 为 \(+\)，否则为 \(-\)。

- 它的四个特殊算子是：
- 最小等价 Zadeh 等价 \( Q(x, y, 1, k)=\mathbf{Q}_3=\text{ite}\{1|x=y; \min(x, y)\} \)

其中，\( k=2^{-1/n}, n\in\mathbf{R}^{+}\) 或 \( n=-1/\log_2 k, k\in[0, 1]\) ; \( m=(3-4h)/(4h(1-h)), h\in[0, 1]\) 或 \( h=[(1+m)-((1+m)^2-3m)^{1/2}]/(2m), m\in\mathbf{R}\)。

### 1) 二元模型

$$M(x_1, x_2, \cdots, x_l, h, k)=(1-(((1-x_1)^{nm}+(1-x_2)^{nm}+\cdots+(1-x_l)^{nm})/l)^{1/m})^{1/nm}$$

- 最小平均 突变平均算子 $M(x_1, x_2, \cdots, x_l, 0, k)=\mathbf{M}_0=\min(x_1, x_2, \cdots, x_l)$

其中，$k=2^{-1/n}, n\in\mathbf{R}_+$ 或 $n=-1/\log_2 k, k\in[0, 1]$ ; $m=(3-4h)/(4h(1-h)), h\in[0, 1]$ 或 $h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m\in\mathbf{R}$。

$C^e(x, y, h, k)=\text{ite}\{\Gamma^e[(x^{nm}+ym^{-n}e^{nm})^{1/m}]|x+y>2e; (1-(\Gamma^e[((1-x^n)^m+(1-y^n)^m)-(1-e^n)^m)]^{1/m})^{1/m})^{1/m}|x+y>2e; e\}, e^t=N(e, k)$

- 中极组合 概率组合 $C^e(x, y, 0.75, k)=\mathbf{C}^{\Phi}_{2k} =\text{ite}\{xy/e|x+y>2e; (1-(1-x)^n(1-y)^n(1-e^n))^{1/n}|x+y>2e; e\}$

其中，$k=2^{-1/n}, n\in\mathbf{R}_+$ 或 $n=-1/\log_2 k, k\in[0, 1]$ ; $m=(3-4h)/(4h(1-h)), h\in[0, 1]$ 或 $h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), m\in\mathbf{R}$。

## 10.4 命题泛逻辑学的常用公式

根据第 5~9 章对各命题连接词和冗元量词性质的证明，我们可以整理出命题泛逻辑学中常用的逻辑公式(即推理定理)如下。从中可以看出，二值逻辑中的逻辑公式拓广到泛逻辑学中后，有三种类型：

- 1) 完全成立。如化简式：$p\wedge_{h,k}q\Rightarrow p$；析取三段论： $\sim_k p, p\vee_{h,k}q\Rightarrow q$。
- 2) 有条件成立。如分配律：$p\wedge_1(q\vee_1 r)\Leftrightarrow (p\wedge_1 q)\vee_1(p\wedge_1 r)$；补余律：当 $h<0.5$ 时 $p\wedge_{h,k} \sim_k p \Rightarrow 0$。
- 3) 仅在二值基逻辑中成立。如 iff $p, q\in\{0, 1\}$ 时，$p\Leftrightarrow q\Leftrightarrow (p\wedge q)\vee(\sim p\wedge \sim q)$ 成立；iff $p, q\in\{0, 1\}$ 时，$\sim (p\Leftrightarrow q)\Leftrightarrow \sim p\Leftrightarrow q$ 成立。

与二值逻辑不同，泛逻辑学的非命题连接词性质十分丰富，有必要专门集中讨论。新增加的泛平均和泛组合公式也单独列出。

## 10.4.1 泛非命题连接词的公式

- 1. 等 $k$ 泛非公式

如果整个推理处在同一误差水平 $k$ 上，则仅需要下面三个性质：
