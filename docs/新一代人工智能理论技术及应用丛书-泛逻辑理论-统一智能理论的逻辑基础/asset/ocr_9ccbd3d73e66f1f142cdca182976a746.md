Frank 算子族只是半个完整簇，如果需要构造一个满足相容定律的零级 S 范数和 S 范数完整簇，目前只能采用组合定义方式来分别构造零级相容算子簇和零级相克算子簇，也就是说利用 Frank 算子簇来替换 Schweizer 算子完整簇中的 h∈[0.5, 1] 部分。

当 h∈[1, 0.5] 时，零级 T 范数/S 范数相容簇是 Frank 算子族。

T(x, y, h) = log_a(1 + (a^x - 1)(a^y - 1) / (a - 1)), a ∈ R+, h ∈ (0.5, 1)

S(x, y, h) = 1 - log_a(1 + (a^(1-x) - 1)(a^(1-y) - 1) / (a - 1)), a ∈ R+, h ∈ (0.5, 1)

a = ((1 - h) / (h - 0.5))^3, h = ((1 + a^(1/3) / 2) / (1 + a^(1/3)))
