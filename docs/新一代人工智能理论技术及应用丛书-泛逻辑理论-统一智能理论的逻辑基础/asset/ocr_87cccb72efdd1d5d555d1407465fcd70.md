和 S 蕴含的合理部分。所以本书采用 T 蕴含定义。

# 9.3.1 泛蕴含命题连接词的定义

定义 9.3.1 由零级 T 性生成元完整簇 F(x, h)=x^m 代入蕴含运算的基模型生成的零级 I 范数完整簇 I(x, y, h)=(min(1+0^m, 1-x^m+y^m))^{1/m} 实现的泛逻辑运算叫泛蕴含运算，用泛蕴含命题连接词 ->h 表示。其中，m=(3-4h)/(4h(1-h))； h=((1+m)-((1+m)^2-3m)^{1/2})/(2m), h \in [0,1], m \in R。

+   它的四个特殊算子是：
+   最小蕴含 Zadeh 蕴含：I(x, y, 1)=I3=ite{1|x<=y; y}
+   中极蕴含 概率蕴含：I(x, y, 0.75)=I2=min(1, y/x) (Goguen 蕴含)
+   中心蕴含 有界蕴含：I(x, y, 0.5)=I1=min(1, 1-x+y) (Lukasiewicz 蕴含)
+   最大蕴含 突变蕴含：I(x, y, 0)=I0=ite{y|x<=1; 1}
+   其中，I(x, y, 0.75)=min(1, y/x)是 I 蕴含；I(x, y, 0.5)=min(1, 1-x+y)是 S 蕴含。
+   它们都是泛蕴含运算完整簇中的一个具体的算子。

定义 9.3.2 由一级 T 性生成元完整超簇 F(x, h, k)=x^{hm} 代入蕴含运算的基模型生成的一级 I 范数完整超簇 I(x, y, h, k)=(min(1+0^{nm}, 1-x^{nm}+y^{nm}))^{1/nm} 实现的泛逻辑运算叫一级泛蕴含运算，用泛蕴含命题连接词 ->k,h 表示。其中，n=-1/log2 k, k \in [0, 1]; k=2^{-1/n}, n \in R+。

+   它的四个特殊点的算子(簇)是：
+   I(x, y, h, k)的下极限是 Zadeh 蕴含算子：I(x, y, 1, k)=I(x, y, 1)=ite{1|x<=y; y}=I3。
+   I(x, y, h, k)的中极限是有界蕴含算子，I(x, y, 0.75, k)=I(x, y, 0.75)=min(1, y/x)=I2。
+   I(x, y, h, k)的中心蕴含算子簇是 I(x, y, 0.5, k)=(min(1, 1-x^{n}+y^{n}))^{1/n}=\Phi_{Ik}，其中 I(x, y, 0.5, 0.5)=min(1, 1-x+y)=I1。
+   I(x, y, h, k)的上极限是突变蕴含算子：I(x, y, 0, k)=I(x, y, 0)=ite{min(x, y)|max(x, y)=1; 0}=I0。

# 9.3.2 泛蕴含运算的性质

根据上述定义，可证明泛蕴含运算具有如下性质。

+   定理 9.3.1 I(x, y, h, k)满足泛蕴含公理：
+   边界条件 I1 I(0, y, h, k)=1, I(1, y, h, k)=y, I(x, 1, h, k)=1。
+   单调性 I2 I(x, y, h, k)关于 y 单调增，关于 x 单调减。
+   连续性 I3 h, k \in (0, 1) 时，I(x, y, h, k)关于 x、y 连续。
+   保存性 I4 I(x, y, h, k)=1, iff x<=y (除 h=0 和 k=1 外)。
+   推演性 I5 T(x, I(x, y, h, k), h, k)<=y (假言推论)。
