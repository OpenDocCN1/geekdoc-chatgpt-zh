# 17.5 小结

本章深入探讨了运动场和光流的核心概念及理论基础，揭示了光流在描述和分析物体运动方面的强大功能。光流技术的独特之处在于其能够在没有场景先验知识的情况下，通过分析图像序列估计物体可能的运动。这一特性不仅使光流方法在照相机运动状态下依然适用，而且让光流成为捕获运动物体信息及场景三维结构的重要手段。
