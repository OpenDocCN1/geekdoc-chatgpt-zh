# 7.4 小结

本章介绍了 SIFT 算法的基本原理，并实现了 SIFT 算法。SIFT 特征具有多种优点，它稳定性高，对旋转、尺度缩放、亮度变化等能够保持不变；独特性好，信息量丰富。因此，SIFT 特征成为完成许多计算机视觉任务的基础。在第 8 章中，我们将介绍 SIFT 的一个实际应用——图像拼接。
