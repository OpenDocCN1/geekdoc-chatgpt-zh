强边缘点是已确定的边缘点，而对弱边缘点，当且仅当它们在已确定的边缘点的邻域内（如 8 邻域内）时，才被确定为边缘点。接下来，我们实现对弱边缘点的确定过程。

# 获得在(x,y)处的邻居
def get_neighbors(x, y, H, W):
    neighbors = []
    for i in (x - 1, x, x + 1):
        for j in (y - 1, y, y + 1):
            if i >= 0 and i < H and j >= 0 and j < W:
                if (i == x and j == y):
                    continue
                neighbors.append((i, j))

    return neighbors
