# 2.3.2 方波信号

我们再来观察使用方波信号对图像卷积的结果。

```
# 二维方波卷积核
size = 15
# 因为二维的核函数的大小是 n * n 的，因此在实现方波信号时我们需要除以(size * size)
k2 = 1/size/size * np.ones((size, size))

# 展示输入图像与卷积核
conv = conv_2d(img, k2)
conv.plot()

# 展示卷积结果
conv.plot_conv()
```
