# 7 智能系统与智能社会

# 7.1 专家系统

专家系统是早期人工智能的一个重要分支,它可以被看作是一类具有专门知识和经验的计算机智能程序系统,一般采用人工智能中的知识表示和知识推理技术来模拟通常由领域专家才能解决的复杂问题。专家系统可以定义为使用人类专家推理的计算机模型来处理现实世界中需要专家做出解释的复杂问题,并得出与专家相同的结论。简单来说,专家系统=知识库十推理机,知识库是专家的知识在计算机中的映射,推理机是利用知识进行推理的能力在计算机中的映射,构造专家系统的难点也是这两个方面,如图 7-1 所示,因此专家系统也被称为基于知识的系统。它是一个具有大量的专门知识与经验的程序系统,应用于人工智能技术和计算机技术。近三十年来人工智能获得了迅速的发展,在很多学科领域都得到了广泛应用,并取得了丰硕成果。专家系统是人工智能一个重要的分支,是在

从 20 世纪 60 年代开始,专家系统的应用产生了巨大的经济效益和社会效益,已成为人工智能领域中最活跃、最受重视的领域。我们可以从其结构、类型、功能等几个方面来了解和认识专家系统。
