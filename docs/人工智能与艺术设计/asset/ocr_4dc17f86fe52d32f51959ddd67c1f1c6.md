# 7.1.4 专家系统的应用——土木工程专家系统的应用

土木工程的特点是工程不确定因素多、影响因素复杂，每项工程既有类似工程的共性，又有其个性，在特殊环节和情况下专家作用显著。近 20 年来，在土木工程领域，专家系统的开发和应用取得了不少的成果，主要应用在项目评估、诊断、决策和预测、建筑设计及优化、项目管理、施工技术以及一些特殊领域（图 7-7）。

# 7.1.4.1 评估、诊断、决策和预测

在建筑物的诊断及项目的评估、决策和预测方面，需要考虑如规范、技术、经济等诸多因素。在这些方面，专家系统的应用较多。

杨玉成等建立了多层砌体房屋震害预测专家系统 PDSMSB1，该系统具有评估现有房屋地震危害程度和进行决策分析的功能。采用扩张的确定性系数法使不确定性问题趋于确定的推理过程中。震例检验和实际应用表明，该系统使用方便，可信度高，预测结果可达到专家级水准。朱长春等从振动测量的角度识别建筑物的模态参数，利用模态参数结构抗震规范对现存建筑物抗震安全性进行评估，在此基础上开发了建筑物抗震安全性评估专家系统。张继庆等建立了钢筋混凝土结构破坏的检测专家系统，该系统从沉降、倾斜、损坏级别、结构损坏率 4 个因素对结构进行安全评估。但这 4 个因素的考虑比较笼统，判断标准等均有主观的因素。吴宇红采用产生式规则的知识表达方式，正向推理策略设计了对已有砖混结构诊断加固专家系统，该系统可以对建筑物加固改造提供优选方案。黄全义研究了人工神经网络在专家系统开发的应用，开发了大坝变形预报神经网络专家系统。王磊综合运用不确定推理方法、知识工程和模糊数学知识，发展了一种决策方法对钢筋混凝土构件的可靠性进行评估，并在此基础上建立了专家系统评估钢筋混凝土构件的可靠性。孙成双提出了建设项目风险动态分析和评价方法，并且对建设项目风险评价指标体系进行了一系列研究，给出了建设项目风险分析专家系统（CPRAES）的总框架。潘毅等结合近年来各国钢筋锈蚀耐久性研究方面的成果，将定量计算和定性分析相结合，进行了锈蚀混凝土构件耐久性评定方法的研究，并编制了一种基于构件耐久性综合评定方法的现役钢筋混凝土结构耐久性评估专家系统。

此外，刘晓燕运用 GADVISOR 工具开发了住宅建筑设计方案评价专家系统、住宅房屋安全鉴定专家系统、抗震结构最优设防水平决策专家系统。裘实研究了砖混住宅质量评估及作价专家系统。赵典铎研究开发了现役结构可靠性诊断专家系统。陈帆等研究了基于应力波反射法和机械阻抗法的 BP 网络模型，建立了基桩质量诊断专家系统 PDES。他们都对专家系统在建筑物诊断及项目的评估、决策和预测方面的应用做了有益的探索和实践。
