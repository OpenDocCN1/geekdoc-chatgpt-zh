# 4.3.2.2 视觉识别系统中的关键实用技术

视觉识别系统中的关键技术有光源照明技术、光学镜头、摄像机、图像采集卡和图像处理软件技术等，下面对上述技术分别进行简单介绍。

光源照明技术：好的光源往往对整个系统起着非常重要的提升作用，能够改善图像分辨率，降低噪声，简化图像分析与处理的软件算法。如图 4-6 所示，为不同颜色的环形 LED 光源。

光学镜头：相当于人类的眼睛，其功能是将成像目标聚焦在图像传感器的光敏面上。  
光学镜头的基本参数包括焦距、相对孔径和像面尺寸，各参数的含义在此不赘述，有兴趣的读者可自行查阅相关资料。镜头的参数直接影响视觉识别系统的整体性能，在选择光学镜头时要注意，第一应保证镜头的像面尺寸和所选择的摄像机相匹配，第二应根据视觉识别系统所处的实际工作环境确定镜头的焦距。  
摄像机：其主要功能是将图像传感器所接受到的光学图像，转换成机器可以接受与处理的电信号。目前市场上，应用较为广泛的摄像机为 CCD 摄像机，其使用的 CCD 器件按照成像色彩可以分成黑白式和彩色式两种。图 4-7 是一种常见的工业 CCD 摄像机。  
图像采集卡：又称图像捕捉卡，其功能是将图像信号采集到电脑中，以数据文件的形式保存在硬盘上，是连接图像采集部分和处理分析部分的桥梁。
