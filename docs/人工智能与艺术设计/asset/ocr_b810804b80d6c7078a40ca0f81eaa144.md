# 4. 控制转移语句

无条件转移语句用“GOTO 语句标识”表示。条件转移语句用“IF C THEN S1 ELSE S2”表示，其中 C、S1 和 S2 可以是一个逻辑表达式，也可以是用“{ 与 }”括起来的语句组。如果 C 为“真”，则 S1 被执行；如果 C 为“假”，则执行 S2。
