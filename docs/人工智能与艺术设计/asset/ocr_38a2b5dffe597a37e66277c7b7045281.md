# 2.1.2.4 小脑

小脑位于脑干的背侧。通过上小脑脚、中小脑脚、下小脑脚等粗纤维束与脑干相连。这三个部位紧密结合，要将各自的纤维完全分开十分困难。小脑可分为正中的小脑虫部、左右的小脑半球、尾侧的小脑扁桃。小脑半球的表面同大脑半球存在脑沟和脑回一样拥有小脑沟和小脑回，不过这较脑沟、脑回纤细，变异也很多。小脑半球的截面和大脑半球一样，皮质是灰白质，髓质是白质。因为皮质较厚，髓质和树枝很相似，所以小脑半球截面被称作生命之树，小脑活树（Arborvitae）。

# 2.1.2.5 脑干

脑干上接大脑，背靠小脑，尾侧与脊髓相连，前侧依次分为中脑、脑桥、延髓。小脑和脑干所夹空间称为第四脑室。中脑分布着上丘（参与视觉处理）、下丘（参与听觉处理）、血清胺、多巴胺、正肾上腺素等神经核。中脑存在参与眼球运动以及视觉相关的各种神经核，发出视神经、动眼神经、滑车神经等脑神经。另外背侧有贯通第三脑室和第四脑室的中脑水道。脑桥呈鼓起的带状，与小脑连接。发出三叉神经、外转神经、颜面神经、听神经等脑神经。延髓在脑桥和脊髓之间，是掌控呼吸等和生命维持相关的植物机能的中枢。传出舌咽神经、迷走神经、副神经、舌下神经等和呼吸、心脏的运动相关。

# 2.1.2.6 循环

人脑质量仅占体重的 2% 左右，但血液循环量占心脏排出量的 20%、氧气消费量占全身的 20%、葡萄糖的消耗量占全身的 25%。这是由于人脑中发生的复杂而活跃的电信号的往来而引起的。这些需求由内颈动脉和椎骨动脉的血流提供。

# 2.2 人类感知世界的生理结构与功能

# 2.2.1 触觉结构与功能

# 2.2.1.1 触觉的定义

皮肤触觉感受器接触机械刺激产生的感觉，称为触觉。皮肤表面散布着触点，触点的大小不尽相同，分布不规则。一般情况下指腹触点最多，其次是头部、背部和小腿的触点最少，所以指腹的触觉最灵敏，而小腿和背部的触觉则比较迟钝。若用纤细的毛轻触皮肤表面时，只有当某些特殊的点被触及时，才能引起触觉。

顾名思义，触觉作为所谓最为直觉的“觉”，是指一如“触”这一概念本身所指出的那样，接触者与被接触者是以一种极其直接的方式联系在一起的，以至于两者之间无论在时间上还是在空间上，都是“零距离”的，是“袭距离”的。用梅洛-庞蒂在《知觉现象学》中的表述，即触摸运动“问题不在于和意识一起发生的关系，而在于直接反应”，用梅洛-庞蒂在《可见的与不可见的》中的表述，即“在这种触感中，问者与被问者离得更近……这两个体系相互与对方贴合，就像一个橘子的两半相互贴合那样”。就此而言，触觉之“觉”是不同于诸如视觉、听觉、嗅觉等其他“觉”的。后者的实现和成立，是以一定的时空距离为前提的，也即以我与感觉对象的一定程度的分离为前提。
