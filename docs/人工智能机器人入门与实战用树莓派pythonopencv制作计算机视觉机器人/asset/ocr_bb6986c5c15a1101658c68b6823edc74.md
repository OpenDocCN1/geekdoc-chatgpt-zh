# 6.6 抓取和放置物体

我们在之前的活动里已经让机械臂前端的吸盘到达了物体的正上方，但是在吸取物体之前，我们还应该让吸盘垂直向下运动到物体表面。我们可以用一个循环程序来完成此过程，此时应该保持 distance 不变，而将 height 减小，程序如下所示。

```
for height in range(1000, 79, -10):
    (pwm2, pwm3) = get_angle(matrix, height, distance)
    ser.write(get_message(2, pwm2, 9))
    ser.write(get_message(3, pwm3, 9))
    time.sleep(0.01)
```

回顾一下，for 循环可以将一个参数在一个数值范围内进行遍历，其格式为：

```
for 参数 in range( 范围起点, 范围终点, 步长 )
```

参数将从起点值开始，每次循环递增步长的値（步长为负值时实际为递减），直到终点值为止（但终点值本身不参与循环）。

注意，这里的 79 仅为参考值，请以吸盘可以贴紧物体为目标调整这个取值。
