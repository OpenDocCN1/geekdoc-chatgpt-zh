# 5.1.2 机器视觉技术的常见应用

机器视觉技术是当前人工智能的一个重要分支，现阶段已有大量重要的现实应用。

# 相似图像搜索

2009—2010 年，谷歌、百度等搜索公司相继推出了以图搜图的图片搜索功能。这一功能可以分析图片上的特征信息，并从互联网上找到与该图片相似的图片。现在，各类手机购物 App 也可以以类似的原理实现拍摄商品照片，找到相似商品的功能。

# 文字识别

很多电子设备都可以使用 OCR（光学字符识别）技术识别纸质资料上的文字，目前较为成熟的 OCR 技术可以以较高的成功率读取手写文字。
