现在我们需要使机械臂在 1000 的高度上前后运动来使物体中心 y 坐标位于 150 左右。如果测得的 y 坐标太小，应向前（增大 distance）；反之应向后（减小 distance）。仿照此前左右调整的方法，完成以下程序：

```
distance = 1000
height = 1000
if y > 160:
    distance += 5
elif y < 140:
    distance -= 5
(pwm2, pwm3) = get_angle(matrix, height, distance)
ser.write(get_message(2, pwm2, 9))
ser.write(get_message(3, pwm3, 9))
```
