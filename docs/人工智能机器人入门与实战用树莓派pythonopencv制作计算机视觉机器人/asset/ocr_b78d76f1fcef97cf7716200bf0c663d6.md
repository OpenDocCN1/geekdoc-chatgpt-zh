```
gpio.output(R, gpio.LOW)
sleep(1)
gpio.output(R, gpio.HIGH)
sleep(1)
```

这些语句可以让红色灯珠亮一秒再灭一秒，但我们要让小灯不断循环这个过程，这需要用到 while 循环结构。在这里，循环是不断连续进行的，因此只需将 while 的条件设定为一个永远为真的条件或直接填入 True 值。

```
while True:
    gpio.output(R, gpio.LOW)
    sleep(1)
    gpio.output(R, gpio.HIGH)
    sleep(1)
```

这就实现了让小灯闪烁的功能。注意 sleep 函数须在程序头部进行导入。
