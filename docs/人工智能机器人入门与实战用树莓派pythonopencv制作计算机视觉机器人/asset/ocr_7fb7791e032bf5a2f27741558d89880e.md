# 3.5 将3.4节练习中的计算器改写为可以根据输入的运算符自主选择运算方式的四则运算计算器。

参考程序：

```
a = int(input("输入第一个整数"))
b = int(input("输入第二个整数"))
c = input("运算符：")
if c == '+':
    print("它们的和是：", a + b)
elif c == '-':
    print("它们的差是：", a - b)
elif c == '*':
    print("它们的乘积是：", a * b)
elif c == '/':
    print("它们的商是：", a / b)
else:
    print("运算符请输下列之一： + - * /")
```
