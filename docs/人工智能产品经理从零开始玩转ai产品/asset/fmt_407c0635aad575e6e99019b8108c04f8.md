
# 2C人工智能产品的价值与分级

## 2C人工智能产品的辅助功能

企业采购人工智能产品的目标是降本增效，通过人工智能产品解放劳动者，进而提高生产效率。除面向企业的人工智能产品外，还有面向个人的人工智能产品。与2B人工智能产品相比，2C人工智能产品的规划、销售、渠道、设计过程均有不同。2C人工智能产品更注重人们在使用产品过程中的感受，2C人工智能产品的作用是辅助人们完成某项具体的工作，因此其作为人类原有判断和行为模式的延伸，优化了人们在实际生产、生活中的生产工具。

本书扩展了生产工具的定义，将原来仅面向生产过程的生产工具，扩展到人们实际生活和娱乐中的生产工具。人在生产、生活和娱乐过程中的活动，都可以拆解为“对事物的思考和判断”和“通过行为去实现判断”，而人工智能产品在人们的生产、生活和娱乐的过程中，则充当了“辅助”的角色。笔者认为，2C人工智能产品主要实现了两个方面的辅助功能：一是辅助判断；二是辅助行为。人工智能产品通过自身强大的记忆存储能力、特征提取能力延伸并强化了人类原有的判断和行为模式。辅助判断和辅助行为也是2C人工智能产品的价值基本点。

从辅助判断的角度而言，当人类进行思考和判断时，人工智能产品可以通过其在特定范围内的分析能力给人类提供最优解的服务。人工智能产品可以在人类思考的时候根据需要进行知识筛选和推荐，以辅助人类完成判断。

以零售行业的商品销售场景为例。目前大部分电商平台采用的都是基于电商平台的销售目标分析用户的不同维度，从而向用户推荐合适的商品的模型。例如，电商平台会根据自身积累的大数据设置几个维度：用户曾经看过的商品、相同标签的用户购买的商品、购买什么商品的用户还购买了该商品、同类商品的销量排行、同类商品的浏览量排行、近似属性的用户浏览的商品等。根据这些不同的维度，再结合该用户的身份标签，选择合适的商品向用户推荐。这种做法是站在企业的角度，即如何将利润或销售额作为核心目标，而真正合理的人工智能产品的推荐功能则不同，它能够站在用户的角度，了解用户自身的属性与需求，结合用户的个人信息，如地理位置、年龄、性别、收入状况、购物偏好、家庭人口情况及颜色偏好等，推荐真正符合用户需求的商品。

在人工智能时代，推荐的模型不再是人为设定的，而是根据数据抽取特征后自动生成的。人为设定的模型会因为设计者的偏见而存在误差，但通过大数据喂养后的人工智能产品则可以总结出更全面、更细致、更符合需求的模型体系，数据量越多，模型越准确。不仅是商品推荐，凡是需要做决策时，人工智能产品都可以辅助判断，如中午吃什么、去哪个商场、选择哪一套医疗方案、旅游行程规划等。

人工智能产品辅助人的判断和行为操作是人工智能发展的一大方向，辅助行为可以分为两类：一类是完全辅助型；另一类是增强辅助型。两者的区别在于人工智能产品在某项实际事务中是否不需要人的参与就可以完成任务。

完全辅助型产品，也可称为行为替代型产品。此类产品可以将人们从某项事务中完全解放出来。例如，家庭地面的清洁工作，人们可以将之完全交由机器人来完成，人们只需要享受产品带来的最终服务即可。而增强辅助型产品，顾名思义，其能在人们执行某项行为操作时增强人的能力，因此增强辅助型产品并不是用来代替人做事的，而是帮助人们做得更快、更精准。

很多产品经理在设计2C人工智能产品时充满了理想，普遍将产品定位于完全辅助型，但由于现实世界的复杂性和产品经理对事务的范围限定性把握不准，最终导致产品失败。因此，笔者认为在进行产品规划时，应先以增强辅助型为目标，并设立一个辅助度。

## 自动驾驶分级示例

例如，自动驾驶在驾驶过程中涉及路标判断、路面判断、环境判断、监测、方向盘控制、油门控制等任务，因此设计能够完全替代人进行自动驾驶的系统的难度相当大。但如果我们把自动驾驶拆解为多个级别，不同级别的自动驾驶任务包括不同的工作，替代度从0逐渐上升至100%，任务就显得更容易一些。自动驾驶一般拆解为以下5个级别（`L0`为人工驾驶，由驾驶员完全掌控车辆）。

### L1：辅助驾驶

定义为辅助驾驶，自动驾驶系统有时能够辅助驾驶员完成某些驾驶任务，一般车道保持系统和自动制动系统就属于`L1`自动驾驶的范畴。

### L2：部分自动驾驶

定义为部分自动驾驶，自动驾驶系统能够完成某些驾驶任务，但驾驶员需要监控驾驶环境及完成剩余驾驶任务，并保证出现问题时随时进行接管。`L2`自动驾驶可以根据不同的速度和环境定义不同的使用场景，如环路低速堵车、高速路上的快速行车和驾驶员在车内的自动泊车。在这个级别中，自动驾驶系统的错误感知和判断由驾驶员随时纠正。

### L3：条件自动驾驶

定义为条件自动驾驶，即自动驾驶系统既能完成某些驾驶任务，也能在某些情况下监控驾驶环境，但驾驶员必须准备好重新取得驾驶控制权。驾驶员将不再需要手脚待命，自动驾驶系统可以独立完成几乎全部的驾驶操作，但驾驶员仍需要保持注意力集中，以便随时应对可能出现的自动驾驶系统应对不了的情况。

### L4：高度自动驾驶

定义为高度自动驾驶，自动驾驶系统在限定场景下，能够完成驾驶任务并监控驾驶环境。在这个级别中，自动驾驶系统已经可以胜任具体场景的自动驾驶，如在高速道路、城市道路、乡村道路等场景中。在自动驾驶可以运行的范围内，驾驶相关的所有工作和驾乘人员已经没关系了，感知外界责任全由自动驾驶系统完成。

### L5：完全自动驾驶

定义为完全自动驾驶，即自动驾驶系统在所有条件下都能完成所有驾驶任务。

从以上几个级别来看，如果研发自动驾驶系统通过分级实现，那么整个研发过程的可行性将大大提高。

# 5.4.3 价值陷阱

随着人工智能技术的发展，不断涌现出许多新的产品和服务，它们被应用到各种场景中。虽然人工智能技术的实现原理可以通过数学公式进行指导，但人工智能技术的决策过程对人类来说却是不透明的。例如，`GAN`通过生成网络和判别网络之间的博弈、学习产生相当理想的输出。我们输入“猫”的照片，该网络可以帮我们生成新的“猫”的照片。虽然网络是由人设计的，但生成网络与判别网络之间的博弈过程却不受人的控制，因此偏见和错误可能会进入系统。另外，人工智能产品的自主性越来越高，这也意味着其可以独立地执行任务而不受人类的控制。

因此，在产品设计过程中，产品经理除关注产品价值外，还要注意下面这些涉及价值观、道德、法律等敏感性质的问题。

- **安全性、保险性问题**：产品经理在设计产品时应充分考虑如何预防损害、减少风险，使人工智能产品可以安全、可靠地运行。
- **产品行为的监管问题**：人工智能产品的一系列行为和操作，是否在合法的监管体系下运作。
- **道德责任问题**：在复杂的社会体系中，人与人工智能产品之间在处理任务时出现的“责任”“义务”“权利”该如何界定。
- **技术透明度问题**：对于人工智能产品的行为和判断，能否还原出行为及判断的依据和来源。
- **数据保护和隐私安全问题**：这也是目前人工智能技术引发的争议中最大的关注点。在数字通信技术无处不在的时代，个人信息和隐私权的保护受到严峻威胁。笔者认为，人工智能产品经理应阅读欧盟颁布的`《通用数据保护条例》（GDPR）`，以防设计的产品在收集、传输、保留或处理数据时引发法律问题。
- **保险和赔偿问题**：目前市场中出现了很多自动驾驶汽车、工业机器人、护理机器人等不同类型的人工智能产品，这些产品在某种程度上已经可以完全或者部分脱离人类的控制。在这些人工智能产品具有自主学习、自我判断和完善的能力的情况下，一旦其对人类和财产造成了损害，其设计者和开发者是否应当承担严格责任，抑或承担有限责任呢？笔者认为应从两方面进行考虑：一要考虑对人工智能产品建立强制保险机制，由人工智能产品的生产者或购买者负责采购保险，一旦人工智能产品造成损害后可以进行责任分配，并由保险公司负责赔偿；二要要求人工智能产品生产厂家建立保障赔偿基金，以便对强制保险未覆盖的损失进行赔偿。

# 5.5 技术分析

## 5.5.1 人工智能产品分类

人工智能产品有“更像人”和“更合理”两个发展方向，目前能够市场化落地的人工智能产品，都是向着“更合理”“更理性”的方向发展的。合理、理性的人工智能产品比“像人”一样的人工智能产品更有适用场景，也更适合工程研发及产品化。

人在与外界环境进行交互时通过各种感觉器官了解外部环境，通过大脑判断后由人体执行器官做出行动反馈。如图5-2所示，和人一样，人工智能产品也拥有感应器、执行器等部件，能对外部环境做出感知并进行反馈和操作。人工智能产品与外部环境进行交互的模块被称为“智能`Agent`”。

![](converter-master/example/165201/content_633710_0.jpg)

图5-2

人类感知世界时使用眼睛、耳朵、嘴巴、鼻子、舌头等器官，并通过手、脚、声带等与外部环境进行交互。人工智能产品则通过智能`Agent`与外部环境进行交互。而智能`Agent`通过感应器感知外部信息，并通过执行器与外部环境进行交互。

人工智能机器人的智能`Agent`可以是红外测距仪、摄像头、温度仪、湿度仪，而智能`Agent`的执行器可以是各种马达、机械臂等。

人工智能软件产品的智能`Agent`可以是摄像头、键盘、麦克风等，而智能`Agent`的执行器可以是软件功能、显示器等。

人工智能产品的智能`Agent`有如下几个特征：
1. 可以适应新的问题的求解规则；
2. 需要保持在线和实时性；
3. 能够在行为错误与成功时进行自我分析；
4. 可以通过与外部环境的交互进行学习改善；
5. 可以迅速地从大量数据中学习；
6. 具有基于内存的存储和检索能力；
7. 具有表示短期记忆和长期记忆的特性。

例如，智能吸尘器的基本功能是检测封闭空间内的垃圾，以及清理垃圾。智能吸尘器需要处理的信息包括平面空间位置、清洁度等信息。

首先，一个智能吸尘器要能够感知房间的平面空间的区域大小和位置，初始化房屋地图。智能吸尘器在初始化房屋平面空间位置时，可通过遍历房屋路径等方式测算房屋地图。地图初始化后，智能吸尘器开始进行日常清扫。当智能吸尘器启动清扫程序并进入某个位置时，需要判断当前位置的清洁度，并根据清洁度做出一个操作：清扫或移动。如果智能吸尘器判断清洁度低于某个阈值，则驱动清洁器进行清扫；如果清洁度高于某个阈值则驱动轴承滚轮移动方向进入下一个区域，并根据房屋平面地图确认是向左还是向右移动。

上面的示例对清扫作业和执行方式的描述比较简单，但我们仍然可以想象出人工智能产品的智能`Agent`的工作模式，即如何通过对外部环境的判断，做出具体的执行操作。但具体的执行过程是与智能`Agent`的设计模式相关的。理论上，智能`Agent`分为基于简单反射型的智能`Agent`、基于模型的智能`Agent`、基于目标的智能`Agent`、基于效果的智能`Agent`和复合型智能`Agent`。

基于简单反射型的智能`Agent`的结构较为简单，它可以针对外部环境的刺激直接产生响应，通过感应器了解现实世界是什么样的，再根据既定条件触发行动，并将行动决策返回给执行器，由执行器完成操作，如图5-3所示。

简单反射型的智能`Agent`的触发过程就像人体的膝跳反应，在膝关节半屈和小腿自由下垂时，轻快地叩击膝腱，引起股四头肌收缩，使小腿做出急速前踢的反应，如图5-4所示。膝跳反应仅包含两个神经元，分别是传入神经和传出神经。膝跳反应的感受器是肌梭，具有收缩力。当叩击膝腱时，引起股四头肌的肌纤维收缩，接着传入神经会将信息传入神经中枢，神经中枢再通过传出神经将拉伸的信息传递回股四头肌，使小腿前伸。

基于模型的智能`Agent`的结构中包含了一系列的模型规则，这些模型规则主要包括以下内容：现实世界是什么样的；这个世界是如何演变的；如果采取了行动，世界将会变成什么样子；目标是什么及针对这个目标该做什么动作。基于模型的智能`Agent`通过以上内容形成“条件-作用规则”，然后通过感应器形成对世界现状的认知，并结合世界的发展逻辑、智能`Agent`的影响方式、如何影响现实世界等条件进行作用决策，最终通过执行器完成对外部环境的操作，如图5-5所示。

## 5.5.2 传统算法和人工神经网络的选择

在进行产品规划时，产品经理不但需要对人工智能产品的价值区间有深刻的理解，完成需求、场景、市场的规划与设计，还需要了解人工智能产品的技术实现路径。当然，人工智能产品的技术实现路径是多种多样的，究竟是使用传统算法、机器学习算法来实现，还是使用人工神经网络来实现，并没有一个具体而准确的标准。但是，作为产品经理应该对传统算法、机器学习算法和人工神经网络有基本的了解，以便更好地达到产品目标。

人工神经网络可以很方便地实现图像风格转换，同样，通过传统算法也可以实现一些图像风格转换。例如，如果我们要把一张图像的风格转为模糊化风格，可以运用传统算法对该图像的像素值进行调整，在一个像素区域内随机挑选一个像素值 `X` 代替其他像素值，`X` 越大，图像越模糊，`X` 越小，图像越清晰，对比效果如图5-9所示。

除通过改变像素值转换图像风格外，我们还可以通过调整图像的灰度完成图像风格转换。电视、显示器显示的物体颜色都采用了色光三原色，色光三原色分别是红色（`Red`）、绿色（`Green`）、蓝色（`Blue`），即`RGB`三色。如果将不同比例的色光三原色进行叠加，就可以形成新的颜色。所以，传统算法一般只需对图像的灰度进行调节，就可以形成不同类型的图像风格，如底片风格、清新风格、暖色风格、高曝光风格等。

目前在传统算法中，改变灰度的算法很多，基本原理如下。

1. 取得各个像素的`RGB`值。
2. 使用灰度算法，算出一个灰度值。
3. 用这个灰度值代替图像原始的`RGB`值。

当然，采用不同的灰度算法将产生不同的风格类型。如果采用`Gray=(Red+Green+Blue)/ X` 获取高曝光风格图，产生的对比效果如图5-10所示。
