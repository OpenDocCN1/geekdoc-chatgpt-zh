
# 学习资源推荐

## 书籍推荐

### 神经网络与深度学习类

神经网络深度学习类书籍比较偏重技术原理及技术应用，这类书籍会对神经网络的历史、发展及原理进行介绍，有兴趣的读者可以学习。笔者推荐《神经网络设计》《神经网络和机器学习》《深度学习基础：设计下一代机器智能的算法》这3本书（图3）。

### 人工智能技能类

人工智能技能类书籍偏重于实操，一般会针对某一或某两个特定的领域进行描述，如专门针对TensorFlow的、针对图像识别的、针对NLP的等。

## 视频课程

除阅读书籍外，笔者还建议初学者借助网络中的人工智能教学视频进行学习。笔者推荐3个较为经典的视频：

1.  **Hinton的 *Neutral Network for Machine Learning* 公开课**。该公开课是人工智能入门的重要一课，课程深入介绍了机器学习中神经网络的方法，可以使读者快速了解人工神经网络在语音识别、物体识别、图像分割、建模语言等场景中的应用。
2.  **吴恩达的《机器学习》公开课**。该公开课深入浅出，系统地讲述了机器学习的入门知识、算法知识和如何在场景中应用，非常适合初学人工智能的读者。
3.  **李飞飞CS231n公开课**。这门公开课是斯坦福的一门以计算机视觉为载体的深度学习课程，由李飞飞和她带领的几个博士生讲述，适合对人工智能算法有一定基础的读者学习。

## 文献资料

笔者推荐几篇代表性的论文，这些论文都是关于人工智能的经典论文，且普遍发表在 *Science* 或 *Nature* 杂志上。

- **《一种用于非线性降维的全局几何框架》（ *A Global Geometric Framework For Nonlinear Dimensionality Reduction* ）** 于2000年12月发表在 *Science* 杂志上。这篇论文提出了一种关于非线性降维问题的处理模型，介绍了如何从局部度量信息中学习全局几何框架，并通过局部度量完成非线性降维的问题。这篇论文的创新之处是计算高维空间的数据点的间距时，不是采用传统的欧氏距离，而是采用了微分几何中的测地线距离、等距特征映射。
- **《采用神经网络降低数据的维度》（ *Reducing the Dimensionality of Data With Neural Networks* ）** 是多伦多大学计算机科学系的教授Hinton和他的学生联合发表的论文。这篇论文探讨了如何采用神经网络降低数据的维度，并提出了一种新型神经网络。通过这种新型神经网络可以有效地提取数据的低维特征，且采用这种新型神经网络远远优于原有的主流降维方法（主成分分析）。这篇论文使深度学习引起了人们的关注，掀起了人们对深度学习的学习热潮。
- **《通过快速搜寻密度峰值进行聚类》（ *Clustering by fast search and find of density peaks* ）** 于2014年发表在 *Science* 杂志上，是一篇关于聚类的论文。我们知道聚类的难点是如何寻找聚类中心点。例如，K均值算法是通过指定聚类中心点，然后通过迭代的方法更新聚类中心点。而这篇论文提出通过寻找密度峰值最大值的点，由于这些点之间的距离远远大于相邻节点，所以把这些节点作为聚类中心点，提高了寻找聚类中心点的效率，引起了人们的注意。
- **《通过深度强化学习达到人类控制水平》（ *Human Level Control through Deep Reinforcement Learning* ）** 于2015年2月发表在 *Nature* 杂志上。该论文提出深度强化学习可使计算机达到人类操控水平。这篇论文的主要特点是将强化学习的Q Network与深度学习结合起来形成Deep Q Network，这引起了很大的反响。
- **《深度学习》（ *Deep Learning* ）** 于2015年5月发表在 *Nature* 杂志上。 *该论文* 是一篇综述性论文，对于对深度学习感兴趣的读者来说这篇文章不可不读。
