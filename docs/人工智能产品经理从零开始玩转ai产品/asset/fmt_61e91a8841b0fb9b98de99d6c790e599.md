
# 5.5 技术分析

## 5.5.1 人工智能产品分类

人工智能产品有“更像人”和“更合理”两个发展方向，目前能够市场化落地的人工智能产品，都是向着“更合理”“更理性”的方向发展的。合理、理性的人工智能产品比“像人”一样的人工智能产品更有适用场景，也更适合工程研发及产品化。

人在与外界环境进行交互时通过各种感觉器官了解外部环境，通过大脑判断后由人体执行器官做出行动反馈。如图5-2所示，和人一样，人工智能产品也拥有感应器、执行器等部件，能对外部环境做出感知并进行反馈和操作。人工智能产品与外部环境进行交互的模块被称为“智能Agent”。

![](converter-master/example/165201/content_633714_0.jpg)

图5-2

人类感知世界时使用眼睛、耳朵、嘴巴、鼻子、舌头等器官，并通过手、脚、声带等与外部环境进行交互。人工智能产品则通过智能Agent与外部环境进行交互。而智能Agent通过感应器感知外部信息，并通过执行器与外部环境进行交互。

人工智能机器人的智能Agent可以是红外测距仪、摄像头、温度仪、湿度仪，而智能Agent的执行器可以是各种马达、机械臂等。

人工智能软件产品的智能Agent可以是摄像头、键盘、麦克风等，而智能Agent的执行器可以是软件功能、显示器等。

人工智能产品的智能Agent有如下几个特征：
1. 可以适应新的问题的求解规则；
2. 需要保持在线和实时性；
3. 能够在行为错误与成功时进行自我分析；
4. 可以通过与外部环境的交互进行学习改善；
5. 可以迅速地从大量数据中学习；
6. 具有基于内存的存储和检索能力；
7. 具有表示短期记忆和长期记忆的特性。

例如，智能吸尘器的基本功能是检测封闭空间内的垃圾，以及清理垃圾。智能吸尘器需要处理的信息包括平面空间位置、清洁度等信息。

首先，一个智能吸尘器要能够感知房间的平面空间的区域大小和位置，初始化房屋地图。智能吸尘器在初始化房屋平面空间位置时，可通过遍历房屋路径等方式测算房屋地图。地图初始化后，智能吸尘器开始进行日常清扫。当智能吸尘器启动清扫程序并进入某个位置时，需要判断当前位置的清洁度，并根据清洁度做出一个操作：清扫或移动。如果智能吸尘器判断清洁度低于某个阈值，则驱动清洁器进行清扫；如果清洁度高于某个阈值则驱动轴承滚轮移动方向进入下一个区域，并根据房屋平面地图确认是向左还是向右移动。

## 5.5.2 传统算法和人工神经网络的选择

在进行产品规划时，产品经理不但需要对人工智能产品的价值区间有深刻的理解，完成需求、场景、市场的规划与设计，还需要了解人工智能产品的技术实现路径。当然，人工智能产品的技术实现路径是多种多样的，究竟是使用传统算法、机器学习算法来实现，还是使用人工神经网络来实现，并没有一个具体而准确的标准。但是，作为产品经理应该对传统算法、机器学习算法和人工神经网络有基本的了解，以便更好地达到产品目标。

一般来讲，当处理一个计算强度不大的问题，或者处理一个相对简单、业务线封闭、输入/输出数据特征明确、业务处理逻辑过程清晰、可描述的问题时，采用合适的传统算法或机器学习算法就可以达到目标。但需要注意的是，这两类算法的容错能力不足，而且很多数据易受到客观环境的影响，造成图像畸变、模糊、失真和数据噪声大等问题。这些问题都会对最终产生的结果造成影响，而这时就突显出了人工神经网络的优势。所以，在处理图像特征、语义处理、推测、推论问题等灵活性更高、自适应要求更高的问题时，可以考虑选择人工神经网络来实现。传统算法、机器学习算法和人工神经网络的特点如表5-4所示。

人工神经网络在处理某些较为复杂的问题或开放的、系统的问题时有一定的优势。这类问题内部的逻辑结构一般不能用明确的规则进行描述，而且有容错性的要求，如物体识别、语义分析。

传统算法或机器学习算法能够根据物体特征进行分类和判断，但如果物体出现变形、遮盖等情况时，传统算法或机器学习算法则显得能力不足，而人工神经网络往往是最佳选择。

因此，对于内部规律不清晰，逻辑结构也不能用一组规则或方程进行描述，尤其是有容错要求的任务，如图形的检测和识别、特征提取、预测和推论等，人工神经网络往往是最合适的处理手段。

对于给定的实际问题，如果确定要通过人工神经网络来解决问题，还需要了解人工神经网络的适用特点：
1. 系统涉及大量的数据，而这些数据又依赖于多个相关的参数；
2. 在系统涉及的范围内，已积累或收集了大量历史性数据和样本；
3. 数据组中包含的数据是不完善的、有误差的，但这些数据却可以描述确定的样本。

如果任务符合上述特点，则通过人工神经网络来实现较为合适。同样，作为产品经理也需要了解哪种情况不适合运用人工神经网络，而更适合运用精确运算和精确数据管理的传统算法。例如，在数字上要求高精确度的场景，如财务信息、固定资产信息、银行数据、精准控制等；需要演绎、推导、逻辑的场景，如税收、精算等；需要统计、运算、分析、报告的场景，如销售数据分析、企业资源管理等。

通过全面了解人工神经网络的适用场景及不适用场景后可知，人工神经网络主要应用在一些用传统算法实现困难的场景中，如数据虽然可用，但是数据存在多样性、数据噪声很大、数据有误差等。但对于项目来讲，如果训练网络的时间足够，仅仅是为了使用人工神经网络这项技术而去使用，则可能导致目标产品实现效果不佳或无法实现。

## 5.5.3 神经网络设计

一般来说，适合使用人工神经网络的应用大都涉及图形识别或统计变换，如字符识别、物体检测、信息预测、过程监控、信号处理、机器人控制等。本书将着重为大家讲解当确定选择使用人工神经网络后，如何对人工神经网络进行具体的设计。

在产品实现过程中使用的人工神经网络，一般由公司内部的算法工程师或高级算法工程师进行设计。由于不同的人工神经网络具有不同的特性，因此产品经理在算法工程师进行设计时，要针对设计人工神经网络的前置条件与算法工程师进行充分的沟通，以方便其进行设计。

产品经理在与算法工程师沟通时主要涉及以下几个方面的内容。

1. **资源约束与配备**：公司对产品的战略规划，产品的功能体系、预期边界、开发周期，以及财务投入状况、人力资源配备情况、可用设备及组织构成等。
2. **数据资源**：包括数据量、数据类型、数据精度及数据成本等。
3. **目标要求**：产品的精度要求、性能要求、一致性要求及容错率等。
4. **时间要求**：计划完成的时间、训练时间的限定及操作时间的限定等。

产品经理与算法工程师沟通了前置条件后，算法工程师即可开展了解数据、设计网络等工作。当算法工程师设计人工神经网络时，产品经理需要对网络模型的并行性、适应性、灵活性及速度等进行了解和评估。网络模型的并行性、适应性、灵活性和速度会影响产品的成败。

设计人工神经网络的过程非常复杂，具体涉及人工神经网络大小的选择、训练过程、输入层设计、隐藏层设计、输出层设计等众多问题。一般来讲，非统计型的人工神经网络模型应拥有1000个以下的节点，统计型的人工神经网络模型应拥有300个以下的节点，以获取更高的效率。

在人工神经网络的训练过程中，产品经理需要关注其训练方法和训练时间，并针对该过程提出建议。一般情况下，训练过程包括监督学习、无监督学习、半监督学习等。监督学习使用的所有数据都要有是否正确的结果判断，所以监督学习对数据的质量要求较高，需要对所有数据进行标注。无监督学习只需要输入数据，而不需要输出数据的结果判断。而半监督学习则是只有一部分数据有结果判断。

网络节点的设计需要确定节点的类型，确定网络大小、层数多少、节点间的链接要求，以及确定学习算法和参数。设计网络节点时，第一步要确定节点的类型，确定的依据是输入类型、组合方式和转移函数。输入类型分为二进制和连续数值输入两类，组合方式则主要是输入的加权及组合，转移函数主要包括不同类型的函数，如线性函数、符号函数、阶跃函数等。

输入层的作用是获取数据，并对整个人工神经网络起到缓冲的作用，如果数据源中包含太多的无效数据，会使训练过程变得不可控，所以应删除无效数据。在删除无效数据后，应确定预处理数据的方法，确保数据更有意义。数据清理完毕后，可以将数据添加到输入层。

网络层级的设计需要确定网络内不同层的数量、大小、连接关系等。人工神经网络都预先设定了输入层和输出层，如果网络层级大于两层，则在输入层和输出层中间有一个或多个隐藏层。隐藏层能从输入端提取数据的特征，因此增加隐藏层可以有效增加人工神经网络的处理能力。当然，隐藏层也不能随意增加，因为增加隐藏层后，将大大增加训练数目和训练时间，使训练过程复杂化，所以很多算法工程师开始时只设定一个隐藏层，然后根据训练效果再进行增加。

有些算法工程师为了提高人工神经网络的处理能力，会在一个隐藏层中增加分组，按照组神经元来进行信息处理。具体隐藏层的节点数、层数、链接涉及大量技术细节，本书不再赘述。

人工神经网络的速度评估在整个设计阶段也非常重要。通常情况下，人工神经网络的运行速度以“每秒钟处理多少个连接”来衡量，即连接/秒。运行速度越快，则人工神经网络的设计越合理。除训练速度外，还应考虑人工神经网络是否得到了完全训练，如果训练完毕，发现部分节点并未进行训练，则网络设计存在问题，需要进行调整。在进行验证时，可以准备一组该网络从未使用过的验证数据，如果该网络对验证数据进行联想回忆，平均误差或标准偏差在可接受范围内，则达标。

通常情况下，在人工神经网络中一般有四种输出结果：分类、图像、数字和最优解。分类是把数据转换为有限个类别进行输出，适于分类输出的场景包括过程控制、图像分类、信号处理、预测等。如果输出的是图像，一般需要进行图像处理、图像转变、数据转换、数据符合识别、图像识别等。如果输出的是数字，且拥有具体的含义，如距离、金额、长度和级别等，则这些数字一般应用于金融预测、过程控制。输出最优解，一般针对`TSP`问题或任务最优处理问题，在问题求解、博弈中经常用到。

人工神经网络设计、训练完毕后，需要对网络进行验证。在验证过程中，不但要考虑网络的精确度，还要考虑网络引起的噪声。进行数据选择时，可以在训练数据中选择70%~80%的数据进行训练，选择剩余20%~30%的数据进行验证。如果剩余20%~30%的数据的输出结果的准确率达到95%以上，则证明该网络是比较有效的。如果验证效果不好，则建议减少隐藏层的节点，改善网络推理能力，或提供更加完善的训练数据进行重新训练。

## 5.5.4 产品技术实现

开发人工智能产品，企业不仅需要拥有雄厚的资金、技术实力，在产品研发过程中也需要配备全方位的人才，如需要有算法工程师设计人工神经网络、需要有开发工程师调整与优化算法、需要有数据工程师进行数据训练。而在企业投入大量成本后，产品是否能够获得市场认可，一切也都是未知数。正因如此，一些大型企业推出了企业开放平台。这些平台会将一些具体场景中所需要的算法直接提供给用户，用户只需要调用其接口即可完成工作。

目前，人工智能研发人员十分紧缺，且大部分分布在各国初创企业和科技巨头中，而人工智能领域的顶级专家更是集中在了各大巨头公司及研究院。

可以说，大多数传统企业或小型企业很难组建起专业的人工智能研发团队，即使能够组建起较为专业的人工智能研发团队，想要达到各大巨头企业或专业大型人工智能企业所能达到的研发水平也是非常难的。因此，很多小型企业选择使用平台。小型企业使用大型企业开放平台能够迅速实施实验，验证产品的可行性，也能够节省成本，对于服务器闲置成本、人工成本的节省更是显而易见。不仅如此，利用大型企业开放平台还可以缩短研发周期，验证成功后可以直接通过大型企业开放平台进行开发工作。

当然，笔者不建议过分依赖这些企业开放平台：一是过分依赖企业开放平台会导致用户缺少技术积累，这会限制用户自身的技术发展；二是企业开放平台自身也有很多不确定性，一旦出现限制、封锁，将直接导致产品的失败。虽然使用企业开放平台存在风险，但笔者也建议初创企业或有意愿向人工智能转型的企业，在初期阶段借助企业开放平台完成开发工作。

## 5.5.3 复合型智能Agent

真实世界非常复杂，并非单一智能Agent就可以实现对外部环境操作并达到最佳效果，这就需要多个智能Agent之间互相作用，通过协作与协商共同完成决策，即复合型智能Agent。这种复合型智能Agent包括多个子智能Agent，各个子智能Agent之间是互相独立运作的。通过感应器获取外部环境信息后，对于紧急或简单的信息，子智能Agent可通过反射条件由执行器完成操作。对于稍复杂点的一般情况，子智能Agent首先通过系统内部的模型和既定规划生成决策，如果子智能Agent自身可以处理，则将请求/应答信息发送到执行器完成对外部环境的操作；如果子智能Agent自身无法处理，则通过通信信道调用外部智能Agent处理，处理后的数据回传至决策生成模块，并通过执行器完成对外部环境的操作，如图5-8所示。
