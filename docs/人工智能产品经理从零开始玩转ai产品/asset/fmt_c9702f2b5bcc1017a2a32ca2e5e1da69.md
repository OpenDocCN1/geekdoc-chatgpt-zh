
# 6.2 图像识别实战

随着网络支付、企业网银的推广，纸币的使用频率越来越低，但是在对公业务中，使用支票的频率还是比较高的。支票需要手工填写，目前对支票内容的识别与记录需要大量的人工，并且工作烦琐、重复劳动较多。因此可通过人工智能自动识别支票，不仅识别率高，而且可实时读取并存储。

柜台操作员识别一张支票，需要对支票真伪、出票日期、收款人、人民币大写、人民币小写、签章、票号等进行鉴别和识别，如图6-11所示。其中票面信息识别用以识别支票的基本信息：银行信息、支票号码等。除对票面基本信息识别外，还可通过程序对手写内容、数字信息进行识别。手写内容主要包括收款人信息、出票人信息、大写金额等；票面数字主要是指票面金额。手写内容和数字信息均可通过人工神经网络进行识别，识别既可以通过基于`TensorFlow`训练的卷积神经网络来实现，也可以借助企业开放平台来实现。本书将以支票识别中的数字识别为例进行介绍。

## 6.2.1 指标体系设计

判断人工智能产品是否达到预期，关键是看其指标是否达标，本书中的指标设计如下。

### 指标一：准确率

在机器学习领域中有很多评价模型的指标，常用的评价指标有准确率、精确率、召回率、`AUC`、`F1`、`MSE`等。因为在当前项目中侧重的是准确率，所以本书将最简单的准确率作为模型的评价指标。

准确率侧重的是所有样本识别正确的结果，其值是所有识别正确的样本数量除以所有样本数量的值。在金融行业中，信息的识别十分重要，因此，我们把准确率设定为99.999%，也就是说模型必须达到99.999%的准确率。

### 指标二：前五类准确率

前五类准确率指的是在分类中取可能性最高的前五个分类，其中包含正确结果的概率。前五类准确率的作用是在第一类分类结果的可能性低的情况下，加入人工干预，分析在人工干预的情况中选取正确结果的概率。例如，选择一个数字5，模型训练后的结果是3的概率为70%，是5的概率为20%，是8的概率为7%，是2的概率为2%，是9的概率为0.5%。那么在这种情况下就可以加入人工干预，由于前五类中包含正确分类，且最高的分类概率为70%，因此可以通过设定阈值的方式把这类分类结果找到，进行人工干预，提高准确率。

### 指标三：识别效率

识别效率指的是模型在生成以后，对图像进行识别所使用的时间。如果这个时间过长，用户体验则会非常不好。如果时间短于100ms，那么这个过程人是很难察觉的，并且从技术角度来说，100ms也是一个较为合理的数值。在本项目中识别效率值设为100ms，也就是模型必须满足识别时间小于或等于100ms的条件。

百度AI开放平台限制了上传时的数据，规则主要包括以下内容：每个要识别的分类作为一个文件夹，建议每个分类文件夹至少上传100张图像；文件夹以分类名称命名，注意只能包含数字、字母、下画线；将分散的多个分类文件夹直接压缩为一个或多个压缩包上传（仅支持 `zip` 格式），每次最多支持上传10个压缩包；分类文件夹内单张图像大小小于4MB，最长边小于4096px，最短边大于30px，长宽比为3∶1。

上传完成后，百度AI开放平台会根据文件夹的名称对数据集进行解析，解析时间一般为1～2小时。

在对数据集进行解析时，百度AI开放平台会把文件夹的名称当作图像`Label`（标签）对文件夹中的图像进行标注，这样就会生成 *N* （ *N* 是该数据集下的文件夹的个数）组标注数据。标注时间一般为1～2小时，数据的大小不同，时间也会有所不同。标注成功后就可以使用百度AI开放平台的模型进行训练，如图6-18所示。

当模型校验完成之后便可以进行发布，发布是为了能够通过`API`接口的方式请求模型。单击“发布模型”按钮跳转到“发布模型”页面，选择之前创建并训练好的模型“手写体识别-图像分类”，因为目前版本只有一个，选择“V1”，在“服务名称”栏填写“手写体识别”，在百度给出的接口地址栏的后缀中填写“mnist”。最后，单击“提交申请”按钮即可，如图6-26所示。

![](converter-master/example/165201/content_633728_19.jpg)

发布模型审核一般需要3～5天，审核通过之后可以直接通过填写的`API`接口调用模型。请求参数有两个：`image`图像数据和`base64`编码。要求编码后的图像文件大小不能超过4MB，最短边不小于15px，最长边不超过4 096px，支持`jpg`/`png`/`bmp`格式；`top_num`为要返回的分类的数量（非必填），默认为6个。

返回结果的数据中有4个字段，分别为`log_id`、`error_code`、`error_msg`和`results`。其中，`log_id`用于定位；当返回请求发生错误时将返回`error_code`和`error_msg`，`error_code`为错误码， `error_msg`为错误描述信息；`results`为正常请求的结果数组，里面包含分类名称与评估置信度。

## 6.2.4 模型评估分析

本书使用的模型优化方向有两个：一是对算法进行调节；二是对数据集进行优化。

### 1. 算法优化

算法优化有多种方式，在使用卷积神经网络训练模型时，我们通过输出可以看到准确率在训练集上的效果要优于在测试集上的效果，原因是模型过拟合了。我们可以采用调节参数及加入`L1`、`L2`正则项的方式避免过拟合。

卷积神经网络的层数与全连接的个数会对模型的最终效果产生影响，对卷积层进行池化、`dropout`等操作对模型效果的提升也会有作用。具体实现需要研发人员来操作，产品经理只需要知道通过这些方式可以解决优化的问题就足够了。

### 2. 数据集优化

人们可以对数据集做一些预处理工作，以增加数据量，还可以在训练之前对图像进行一些拉伸旋转，从而提高模型的健壮性。

数据集的标注可以根据检验结果做一些修改。在百度AI开放平台中，我们可以看到一部分错误是由数据集标注错误导致的，我们可以使用训练好的模型，对数据集进行训练，然后拿出判断错误的数据集，修正手工标注错误的数据，这样也会对提升模型的准确率有帮助。
