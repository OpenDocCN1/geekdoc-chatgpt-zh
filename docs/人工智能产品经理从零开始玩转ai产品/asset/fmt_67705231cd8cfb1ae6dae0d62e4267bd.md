### 3. 数据准备

阿里云PAI平台底层支持两种数据源：一种是`MaxCompute`存储数据；另一种是`OSS`存储数据。

**MaxCompute存储数据**：`MaxCompute`主要用来存储表结构数据，支持稀疏与稠密两种格式的数据，支持机器学习IDE上传和命令行工具上传两种方式。这部分的数据主要针对平台深度学习以外的算法组件。

**OSS存储数据**：`OSS`数据源主要针对与深度学习相关的算法组件，可用来存储结构化或非结构化数据。

## 4.8 人工智能开发语言

在人工智能产业研发过程中所用到开发语言或环境很多，目前使用最多的是`Python`、`R语言`、`MATLAB`等，它们各有优点。虽然产品经理可以不进行代码编写，但笔者仍建议产品经理能够了解各个语言和环境的优缺点，选择其中一种语言或环境做一些简单代码的编写。本书不再详细介绍各种语言的语法规则与使用方法，仅对使用的语言和环境的优缺点进行列举，希望能对各位产品经理有所帮助。

### 4.8.1 Python

`Python`诞生于20世纪90年代初，是目前人工智能研发过程中常用的开发语言之一。它是一种动态的、面向对象的脚本语言，最初被设计用于编写自动化脚本，随着版本的不断更新和功能的增加，越来越多地被用于对独立的大型项目的开发。

由于`Python`语言具有简洁性、易读性及可扩展性，因此使用`Python`做科学计算的研究机构日益增多。`Python`丰富的科学计算库、计算机视觉库，也使`Python`成为处理实验数据、开发科学计算软件、制作图表的流行语言。`Python`在设计上坚持了整齐划一的风格，这使`Python`成为一门易读、易维护，并且被大量用户所接受、用途广泛的语言。当然`Python`也有缺点，如`Python`对语法的要求非常严格，故限制性很强，很多程序员会觉得其烦琐。`Python`的优缺点总结如下。

#### Python的优点

1. 适合一般编程和应用程序开发。
2. 开源包丰富（`Pandas`、`Numpy`、`Scipy`等）。
3. 总体速度快，尤其是在迭代循环中。
4. 可连接`R语言`、`Java`等其他语言。

#### Python的缺点

1. 部分包不太成熟，有些包与其他包存在不兼容的情况。
2. 与`R语言`或`MATLAB`相比，相同操作需要更多代码。

### 4.8.2 R语言

`R语言`是一款用于统计分析、绘图的统计分析软件。`R语言`将统计分析与图形显示合为一体，并且完全开源，语法通俗易懂，很容易学会。用户可以用`R语言`编制自己的函数来扩展现有的语言。

#### R语言的优点

1. 代码量少，开发速度快。
2. 拥有成熟的量化交易包。
3. `R语言`社区多且活跃。

#### R语言的缺点

1. `R语言`绘图功能不如`MATLAB`。
2. 执行速度比`Python`慢。
3. 创建独立应用程序的能力有限。

### 4.8.3 MATLAB

`MATLAB`是一种数学软件，一般用于算法开发、数据可视化、数据分析、数值计算，而不直接用于程序开发。由于`MATLAB`在数值计算中拥有诸多强大的功能体系，如可以进行矩阵运算、绘制函数和数据、实现算法、创建图形界面等，因此被广泛应用在科学研究、工程计算、仿真、图像处理、信号检测、金融建模等领域。

#### MATLAB的优点

1. 数学和计算速度快。
2. 适合所有数学计算。
3. 计算包强大。
4. 脚本简短。
5. 实现了图和交互式图表的最佳可视化。

#### MATLAB的缺点

1. 无法执行，必须转换为另一种语言。
2. 价格高，按照`License`付费。
3. 无法与其他语言很好地集成。
4. 无法开发单独的应用。
