
# 机器学习框架与企业开放平台

## 4.6 机器学习框架

### 4.6.1 TensorFlow

TensorFlow 完全开源，任何人都可以下载使用，而且 TensorFlow 使用起来也很方便，通过简单的几行代码就可以运行。正是因为 TensorFlow 的操作简单，使人工神经网络的入门也变得简单起来。

TensorFlow 的安装也非常简单：
- **Windows 环境下安装 CPU 版本**：在命令行模式下输入 `pip install tensorflow` 即可
- **安装 GPU 版本**：命令行模式下输入 `pip install tensorflow-gpu` 即可

安装 TensorFlow 后可以安装 Jupyter Notebook 编辑器，以便创建程序文档，安装时在命令行输入 `pip install jupyter` 即可。

除通过命令行手动安装外，也可以通过 Anaconda 等工具进行安装。如果我们把 TensorFlow 比作做饭的炉灶，则 Anaconda 可以理解为一个厨房，里面除炉灶外还有各种食材供人选择，如图 4-61 所示。

安装 Anaconda 非常简单，可以直接从官网进行下载，然后单击“安装”按钮，并按照引导一步步确定即可。安装完毕后，可以在 Environments 里看到很多工具包，在搜索条中搜索“TensorFlow”并勾选其工具包，单击“Apply”按钮即可安装。

![](converter-master/example/165201/content_633691_3.jpg)

图 4-61

当然，TensorFlow 也存在一定的缺陷：TensorFlow 的每个计算流都必须构造成一个静态图，且缺乏符号性循环，这会带来一些计算困难。而且 TensorFlow 的性能与其他竞争对手相比也并无明显优势，但这些都不妨碍 TensorFlow 成为目前火热的机器学习框架。

### 4.6.2 Caffe

Caffe（Convolutional Architecture for Fast Feature Embedding）是自 2013 年年底以来，第一款主流的工业级机器学习框架。Caffe 是一个高效的机器学习框架并且开源，具备非常好的 CNN 建模能力。但是 Caffe 中的 RNN 资源相对较少，所以初期 Caffe 并未定位于通用框架，而是专注于图像识别、推荐引擎和自然语言识别等方向的应用，不面向其他深度学习应用，诸如语音识别、时间序列预测、图像字幕和文本等需要处理顺序信息的任务。但优秀的卷积模型使 Caffe 成为计算机视觉界十分流行的工具包之一，并在 2014 年的 ImageNet 挑战赛中一举夺魁。Caffe 在图像处理方面的优异性能也使其完美地应用于实验研究和商业部署。

在 2017 年 4 月的 F8 年度开发者大会上，Facebook 发布了一款全新的机器学习框架——Caffe2，如图 4-62 所示。这是一个轻量化和模块化的机器学习框架，在强调轻便性的同时也保持了 Caffe 的可扩展性和计算性能。

![](converter-master/example/165201/content_633691_4.jpg)

图 4-62

Caffe2 可以通过一台机器上的多个 GPU（或具有一个或多个 GPU 的多台机器）来进行分布式训练。Caffe2 也可以在 iOS 系统、安卓系统和树莓派上训练及部署模型，并且 Caffe2 只需要运行几行代码即可调用预先训练好的模型。目前，NVIDIA、高通、英特尔、亚马逊和微软等公司的云平台都已支持 Caffe2。

### 4.6.3 PyTorch

PyTorch 是基于 Python 的科学计算包，可为用户提供最大的灵活性和速度。例如，一直以来 Facebook 的机器学习和科学计算都是建立在 PyTorch 之上的，很多人选择 PyTorch 作为开发工具，是因为其不仅支持 Python，还支持动态图的创建。市面上大多数框架，如 TensorFlow、Theano、Caffe 普遍仅采用静态图，即建立一个神经网络，并重复使用相同的结构。静态图定义的缺陷是在处理数据前必须定义好完整的一套能够处理所有边际情况的模型，而如果使用动态图则可以非常自由地定义模型、使用模型和修正模型。

### 4.6.4 CNTK

Microsoft 的 CNTK 是一个非常强大的机器学习框架，可以方便快捷地创建人工神经网络。CNTK 最初是为了在 Microsoft 内部使用而开发的，随着人工智能的发展，CNTK 也逐渐升级迭代，目前已经是市面上较为主流的学习框架之一。

CNTK 最大的优点是速度快，并且 CNTK 支持 CPU 和 GPU 计算，另外，CNTK 的使用和训练都非常方便，这使初学者非常容易理解。CNTK 可以有效地胜任诸如分类、语言识别、图像识别等任务。

## 4.7 企业开放平台

企业通过机器学习框架开发人工智能产品，需要配备全方位的人才，如需要工程师设计人工神经网络、调整与优化算法及进行数据训练，并且需要拥有雄厚的资金、技术实力。最为关键的是企业在大量投入后，产品能否达到预期效果、能否获得市场认可都是未知的。为了降低人工智能产品的开发门槛，一些大型企业推出了企业开放平台，如阿里云机器学习（Platform of Artificial Intelligence，PAI）平台、百度 AI 开放平台、商汤智能视频识别平台等。这些平台会将一些具体场景中所需要的算法通过接口的形式直接提供给用户，用户只需要调用其接口即可完成工作。例如，百度 AI 开放平台提供了语音识别接口，用户只需要调用该接口，将音频传入后，即可返回文字，无须再进行人工神经网络的设计和训练。

利用企业开放平台研发人工智能产品的优点是成本低，用户可以快速实施、验证，降低了人工及服务器成本。另外，企业开放平台已经将算法训练完毕，无须用户再进行训练，这大大减少了用户的开发周期，使用户可以第一时间制作 MVP（最小可交付产品），并通过 MVP 进行市场验证。如果产品获得了市场认可，再进行技术投入，建立自己的算法模型，保证核心竞争力。目前市场上大型企业开放平台所分享的算法达到的性能，远远高于大部分小型企业自发研制的模型。

当然，笔者不建议开发者过分依赖这些大型企业开放平台：一是过分依赖企业开放平台而自身并无技术积累，会限制自身的技术发展；二是企业开放平台自身也有很多不确定性，一旦出现限制、封锁，将直接导致产品失败。虽然使用企业开放平台存在风险，但对于初创企业或有意愿向人工智能转型的企业来说，在初期阶段可以借助企业开放平台完成开发工作。

### 4.7.1 百度 AI 开放平台

百度 AI 开放平台为开发者提供了人工智能接口、算法、算力和一些经典的数据集，方便用户完成开发。此外，百度 AI 开放平台还提供了实际的工程样例教学资源等内容，如图 4-63 所示，方便用户入手。

![](converter-master/example/165201/content_633692_0.jpg)

图 4-63

百度 AI 开放平台除集成视频教程、样例模型、代码、计算资源、比赛平台等多种能力外，还具有以下技术特色：
1. 支持 Python 交互式编程语言开发环境
2. 同时支持单机训练和集群训练两种方式
3. 提供高质量开放数据集，一键嵌入代码
4. 环境集成 PaddlePaddle 深度学习框架，无须安装

百度 AI 开放平台的使用也非常简单，用户只需要注册、创建应用、获取密钥、生成签名、启动开发即可完成。

#### 1. 注册

三步完成账号的基本注册与认证。

1. 进入百度 AI 开放平台导航右侧的控制台，选择需要使用的人工智能服务项。若处于未登录状态，将跳转至登录界面，使用百度账号登录。如果用户还未持有百度账户，可以单击注册百度账户。
2. 首次使用时，登录后将会进入开发者认证页面，请填写相关信息完成开发者认证。
3. 进入人工智能服务项的控制面板（如文字识别、人脸识别），进行相关业务操作。

#### 2. 创建应用

账号登录成功，需要创建应用才可以调用相关能力。应用是调用 API 服务的基本操作单元，用户可以基于应用创建成功后获取的 API Key 及 Secret Key，进行接口调用操作，如图 4-64 所示。

![](converter-master/example/165201/content_633692_1.jpg)

图 4-64

单击图 4-64 中的“创建应用”按钮，即可进入应用创建界面，如图 4-65 所示。

![](converter-master/example/165201/content_633692_2.jpg)

图 4-65

创建应用时需要填写的内容如下：

1. **应用名称**：用于标识所创建的应用的名称
2. **应用类型**：根据应用的适用领域选取类型
3. **接口选择**：每个应用可以勾选业务所需的人工智能服务的接口权限（仅可勾选具备免费试用权限的接口能力），应用权限可跨服务勾选
4. **包名绑定**：如果需要使用 OCR、AR 及语音客户端 SDK 服务（iOS/Android），需要绑定包名信息，以便生成授权 License
5. **应用平台**：选择应用适用的平台
6. **应用描述**：对应用的业务场景进行描述

填写完毕后，即可单击“立即创建”按钮，完成应用的创建。应用创建完成后，用户可以选择图 4-66 中的“应用列表”，进行查看。

![](converter-master/example/165201/content_633692_3.jpg)

图 4-66

#### 3. 获取密钥

在应用创建完成后，平台将会分配应用的相关凭证，主要为 `AppID`、`API Key` 及 `Secret Key`。

#### 4. 生成签名

用户需要使用应用创建完成后所分配到的 `AppID`、`API Key` 及 `Secret Key`，进行 `Access Token`（用户身份验证和授权的凭证）的生成，即生成签名。

#### 5. 启动开发

生成签名后，即可调用百度 AI 开放平台的相关接口。目前百度 AI 开放平台主要通过 API 与 SDK 两种方式提供服务。
