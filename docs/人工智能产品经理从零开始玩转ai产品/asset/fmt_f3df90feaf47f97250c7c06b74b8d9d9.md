
## 4.6 机器学习框架

随着人工智能技术的发展，人工智能产品的研发过程越发离不开各种开发库和开发框架。市场上有各种机器学习框架，如`TensorFlow`、`Caffe`、`CNTK`、`PyTorch`、`Theano`等，这些机器学习框架各有千秋，各有特色。2017年5月，有人总结了`GitHub`中最受欢迎的开源机器学习框架排名，如图4-58所示，`TensorFlow`受欢迎投票排名第一，`Caffe`和`CNTK`紧随其后。

### 4.6.1 TensorFlow

`TensorFlow`是谷歌基于`DistBelidf`研发的机器学习框架。`TensorFlow`中`Tensor`表示张量，`Flow`表示流，`TensorFlow`可以理解为张量从数据流图中的一端流动到另一端的过程。`TensorFlow`的架构十分灵活，用户可以轻松地将其部署到多种平台（`CPU`、`GPU`、`TPU`）和设备上，甚至可以在智能手机中运行。

`TensorFlow`的优点在于其支持`Python`语言，用户易于上手。并且`TensorFlow`使用了数据流图表进行抽象，提供了`TensorBoard`进行可视化展现。目前使用`TensorFlow`进行开发的公司很多，如AMD、NVIDIA、Uber、SAP、DeepMind、小米、京东、联想、开普云等。

`TensorFlow`完全开源，任何人都可以下载使用，而且`TensorFlow`使用起来也很方便，通过简单的几行代码就可以运行。正是因为`TensorFlow`的操作简单，使人工神经网络的入门也变得简单起来。`TensorFlow`的安装也非常简单，如果在`Windows`环境下安装CPU版本，在命令行模式下输入`pip install tensorflow`即可；如若安装GPU版本，命令行模式下输入`pip install tensorflow-gpu`即可。安装`TensorFlow`后可以安装`Jupyter Notebook`编辑器，以便创建程序文档，安装时在命令行输入`pip install jupyter`即可。

除通过命令行手动安装外，也可以通过`Anaconda`等工具进行安装。如果我们把`TensorFlow`比作做饭的炉灶，则`Anaconda`可以理解为一个厨房，里面除炉灶外还有各种食材供人选择，如图4-61所示。安装`Anaconda`非常简单，可以直接从官网进行下载，然后单击“安装”按钮，并按照引导一步步确定即可。安装完毕后，可以在`Environments`里看到很多工具包，在搜索条中搜索“TensorFlow”并勾选其工具包，单击`Apply`按钮即可安装。

![](converter-master/example/165201/content_633689_3.jpg)

当然，`TensorFlow`也存在一定的缺陷，`TensorFlow`的每个计算流都必须构造成一个静态图，且缺乏符号性循环，这会带来一些计算困难。而且`TensorFlow`的性能与其他竞争对手相比也并无明显优势，但这些都不妨碍`TensorFlow`成为目前火热的机器学习框架。

### 4.6.2 Caffe

`Caffe`（Convolutional Architecture for Fast Feature Embedding）是自2013年年底以来，第一款主流的工业级机器学习框架。`Caffe`是一个高效的机器学习框架并且开源，具备非常好的`CNN`建模能力。但是`Caffe`中的`RNN`资源相对较少，所以初期`Caffe`并未定位于通用框架，而是专注于图像识别、推荐引擎和自然语言识别等方向的应用，不面向其他深度学习应用，诸如语音识别、时间序列预测、图像字幕和文本等需要处理顺序信息的任务。但优秀的卷积模型使`Caffe`成为计算机视觉界十分流行的工具包之一，并在2014年的`ImageNet`挑战赛中一举夺魁。`Caffe`在图像处理方面的优异性能也使其完美地应用于实验研究和商业部署。

在2017年4月的`F8`年度开发者大会上，Facabook发布了一款全新的机器学习框架——`Caffe2`，如图4-62所示。这是一个轻量化和模块化的机器学习框架，在强调轻便性的同时也保持了`Caffe`的可扩展性和计算性能。

![](converter-master/example/165201/content_633689_4.jpg)

图4-62

`Caffe2`可以通过一台机器上的多个`GPU`（或具有一个或多个`GPU`的多台机器）来进行分布式训练。`Caffe2`也可以在`iOS`系统、安卓系统和树莓派上训练及部署模型，并且`Caffe2`只需要运行几行代码即可调用预先训练好的模型。目前，NVIDIA、高通、英特尔、亚马逊和微软等公司的云平台都已支持`Caffe2`。

### 4.6.3 PyTorch

`PyTorch`是基于`Python`的科学计算包，可为用户提供最大的灵活性和速度。例如，一直以来Facebook的机器学习和科学计算都是建立在`PyTorch`之上的，很多人选择`PyTorch`作为开发工具，是因为其不仅支持`Python`，还支持动态图的创建。市面上大多数框架，如`TensorFlow`、`Theano`、`Caffe`普遍仅采用静态图，即建立一个神经网络，并重复使用相同的结构。静态图定义的缺陷是在处理数据前必须定义好完整的一套能够处理所有边际情况的模型，而如果使用动态图则可以非常自由地定义模型、使用模型和修正模型。

### 4.6.4 CNTK

Microsoft的`CNTK`是一个非常强大的机器学习框架，可以方便快捷地创建人工神经网络。`CNTK`最初是为了在Microsoft内部使用而开发的，随着人工智能的发展，`CNTK`也逐渐升级迭代，目前已经是市面上较为主流的学习框架之一。

`CNTK`最大的优点是速度快，并且`CNTK`支持`CPU`和`GPU`计算，另外，`CNTK`的使用和训练都非常方便，这使初学者非常容易理解。`CNTK`可以有效地胜任诸如分类、语言识别、图像识别等任务。
