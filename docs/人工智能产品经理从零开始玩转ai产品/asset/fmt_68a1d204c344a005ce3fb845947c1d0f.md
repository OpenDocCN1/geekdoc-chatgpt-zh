
# 第4章 人工智能技术体系（续）

## 4.8 人工智能开发语言与环境

在人工智能产业研发过程中所用到开发语言或环境很多，目前使用最多的是 Python、R 语言、MATLAB 等，它们各有优点。虽然产品经理可以不进行代码编写，但笔者仍建议产品经理能够了解各个语言和环境的优缺点，选择其中一种语言或环境做一些简单代码的编写。本书不再详细介绍各种语言的语法规则与使用方法，仅对使用的语言和环境的优缺点进行列举，希望能对各位产品经理有所帮助。

### 4.8.1 Python

Python 诞生于 20 世纪 90 年代初，是目前人工智能研发过程中常用的开发语言之一。它是一种动态的、面向对象的脚本语言，最初被设计用于编写自动化脚本，随着版本的不断更新和功能的增加，越来越多地被用于对独立的大型项目的开发。

由于 Python 语言具有简洁性、易读性及可扩展性，因此使用 Python 做科学计算的研究机构日益增多。Python 丰富的科学计算库、计算机视觉库，也使 Python 成为处理实验数据、开发科学计算软件、制作图表的流行语言。Python 在设计上坚持了整齐划一的风格，这使 Python 成为一门易读、易维护，并且被大量用户所接受、用途广泛的语言。当然 Python 也有缺点，如 Python 对语法的要求非常严格，故限制性很强，很多程序员会觉得其烦琐。Python 的优缺点总结如下。

#### 1. Python 的优点

（1）适合一般编程和应用程序开发。

（2）开源包丰富（`Pandas`、`Numpy`、`Scipy` 等）。

（3）总体速度快，尤其是在迭代循环中。

（4）可连接 R 语言、Java 等其他语言。

#### 2. Python 的缺点

（1）部分包不太成熟，有些包与其他包存在不兼容的情况。

（2）与 R 语言或 MATLAB 相比，相同操作需要更多代码。

### 4.8.2 R 语言

R 语言是一款用于统计分析、绘图的统计分析软件。R 语言将统计分析与图形显示合为一体，并且完全开源，语法通俗易懂，很容易学会。用户可以用 R 语言编制自己的函数来扩展现有的语言。

#### 1. R 语言的优点

（1）代码量少，开发速度快。

（2）拥有成熟的量化交易包。

（3）R 语言社区多且活跃。

#### 2. R 语言的缺点

（1）R 语言绘图功能不如 MATLAB。

（2）执行速度比 Python 慢。

（3）创建独立应用程序的能力有限。

### 4.8.3 MATLAB

MATLAB 是一种数学软件，一般用于算法开发、数据可视化、数据分析、数值计算，而不直接用于程序开发。由于 MATLAB 在数值计算中拥有诸多强大的功能体系，如可以进行矩阵运算、绘制函数和数据、实现算法、创建图形界面等，因此被广泛应用在科学研究、工程计算、仿真、图像处理、信号检测、金融建模等领域。

#### 1. MATLAB 的优点

（1）数学和计算速度快。

（2）适合所有数学计算。

（3）计算包强大。

（4）脚本简短。

（5）实现了图和交互式图表的最佳可视化。

#### 2. MATLAB 的缺点

（1）无法执行，必须转换为另一种语言。

（2）价格高，按照 License 付费。

（3）无法与其他语言很好地集成。

（4）无法开发单独的应用。

## 5.1 人工智能产品概述

产品经理的职责在于寻找有价值并且切实可行的产品，这个过程需要充分结合市场、技术、交互等因素。2008 年，知名商业模式创新者亚历山大·奥斯特瓦德（Alexander Osterwalder）提出了商业模式画布——用客户群体、客户关系、渠道通道、价值主张、关键业务、核心资源、合作伙伴、成本结构和收入来源这 9 项内容来描述企业获取价值、创造价值、传递价值的基本方法和原理。笔者将人工智能产品的规划、设计、实践与商业模式画布相结合，提出在产品、市场和效益 3 个层面进行人工智能产品设计，并列出了设计过程中涉及的 14 项指标。在这 3 个层面上，通过 14 项指标，产品经理可以轻松构建人工智能产品画布，如图 5-1 所示。人工智能产品画布可以帮助产品经理高效地确定产品规划、厘清产品脉络、确定产品结构，从而提升人工智能产品的设计效率。

### 1. 产品层面

产品层面主要包括一些产品实现的细节：一是人工智能产品的实现方案，包括产品目标、范围、可行性及关键功能架构；二是人工智能产品应用的具体行业和场景，并确定该产品在该场景下实现的效能指标和价值指标；三是实现人工智能产品的技术选型、算法分析和技术指标设计等。

### 2. 市场层面

人工智能产品是否成功关键在于产品是否可以获得市场的认可。即使产品非常优秀，如果没有被市场和客户认可，一切投入也都将化为乌有。产品经理在产品规划过程中应从市场层面完成针对产品使用者、购买者、影响者、决策者等的客群分析，完成竞争对手分析，完成产品定价策略规划，以及完成渠道规划。

市场层面产品规划最关键的内容是确定产品价值主张。产品价值主张不仅指明了产品方向，而且关系到产品的成败。产品价值主张包括产品带来的社会价值、生产力价值等。

### 3. 效益层面

在一个产品概念创立之初，需要建立人工智能产品的效益目标，效益目标可以从经济效益、社会效益等不同层面进行考量，作为产品经理要着重对产品的成本和收入进行分析。产品经理应对效益目标进行拆解，计算投入产出比，如果投入产出比不够理想，则研发该产品没有意义。

## 5.2 效益分析

人工智能产品通常是一些技术复杂度较高、生产规模较大的产品，并且在人工智能产品的研发、使用、维护和管理的过程中涉及多个企业、部门、岗位、人员的共同协作，这属于一项复杂的系统工程。不仅如此，在人工智能产品研发过程中还需要投入巨大的人力、物力和财力资源。因此，产品经理在设计产品前，首先要对目前的资源有所了解，计算出产品研发过程中消耗资源的情况。

人工智能产品成本经济学范畴内应反映其在生产过程中所耗费的各项费用，即原材料费用、燃料费用、动力费用、折旧费用、人工费用、管理费用及财务费用等各项费用的总和。人工智能产品成本的测算有很多种方式，产品经理在实际估算时可根据企业的实际情况做出数量级的估算。

从财务角度看，人工智能产品成本包括如下项目：基础硬件成本（服务器、元器件等），软件购置成本（操作系统、数据库软件、平台使用费、第三方软件购置费），人工费用（人员工资、奖金福利）和其他管理费用（培训费、会议费、通信费、差旅费等）。

从人工智能产品的生命周期来看，产品成本包括开发成本和维护成本。开发成本包括软件成本、硬件成本和其他成本。例如，系统软件的分析/设计费（含系统调研费、需求分析费、系统分析费等），实施费（含硬件费、编程/测试费、软件购置费、数据收集费、人员培训费等），以及系统切换等费用。维护成本包括运营费（含人工费、材料费、固定资产折旧费、专有技术及技术资料购置费等），管理费（含审计费、系统服务费、行政管理费等），以及维护费（含纠错性维护费、适应性维护费等）。

产品经理在进行人工智能产品成本分析时，应根据产品的软件特征、产品的硬件特征、用户环境特征，以及以往同类或相近项目的基础数据、影响因素和环境因素等进行综合分析。

不仅如此，产品经理在进行人工智能产品成本分析时，还应考虑影响成本的各类风险。例如，开发团队的变化、开发环境的变化、产品训练和测试数据的可靠性、算法模型的可靠性、逻辑模型的抽象程度、业务处理流程的复杂程度、新技术的出现等，这些都会对成本产生重要影响。

## 5.3 市场分析

在进行市场分析之前，首先要明确产品的目标市场定位。产品目标市场定位是确定目标市场和进行市场细分选择的过程。在市场分化的背景下，任何一家公司或一种产品的目标顾客都不可能是所有的人，所以确定目标市场及目标顾客至关重要。市场分析需要确定细分市场的标准，对整体市场进行细分，并对细分后的市场进行评估，通过分析和评估最终确定目标市场。产品经理在进行市场分析时，要充分考虑产品在细分市场中的可区分性、可防卫性、可赢利性、可执行性等。

企业面向不同的细分市场有不同的经营目的，并且会提供不同的价值定位，所以产品经理在选择细分市场时应充分考虑目标市场的可区分性。例如，公司决定开发一款智能音箱产品，设定其面向 4～8 岁的儿童。但对目标市场进行细分时发现，对于 4～8 岁的儿童来说，其还可以细分为已上小学的儿童和未上小学的儿童，或细分为男孩和女孩。对于未上小学的儿童，公司应重点关注儿歌、童谣和短故事等方面；而对于已上小学的儿童，公司应重点关注游戏、故事和学习等方面。

产品经理在选择目标市场时，还应考察市场是否可防卫，即企业是否具有先驱优势。具有先驱优势的企业第一个进入市场，可以形成先驱影响力，使竞争企业不易进入这些细分市场或不能马上效仿。

另外，产品经理还应考虑该市场的可赢利性，一个市场的可赢利性反映了细分市场的大小、服务成本的高低、市场对新的产品（观念）的接受程度，以及市场竞争程度。纵观人工智能产品市场，虽然分类很多，如智能音箱、智能电视、智能机器人等，但竞争非常激烈，如果创业型企业想进入这类行业，就需要有高超的技术实力和强大的资金支持，并能从一些平时不被其他企业重视的场景中寻找到人工智能技术的落地方式，如智能牙刷、智能灯泡、智能咖啡机等。

最后，产品经理应确定产品在市场中的可执行性。产品经理需要对企业的内部情况有详细的了解，确定企业在目标市场中具备实施该产品方案的技能和系统。

### 5.3.1 客群分析

客群分析是针对产品目标客群所进行的一系列详尽的调查分析，进而得出对产品市场前景的预期判断。客群分析主要包括目标区域内的客群的所属阶层、群体数量、教育背景、收入构成、风俗习惯、年龄构成、家庭人口结构、消费能力、消费行为习惯及日常消费支出等内容。

在进行客群分析时，产品经理一定要考虑可能参与到消费过程中的各种角色，消费过程主要涉及使用者、购买者、影响者和决策者。使用者顾名思义是终端用户，是最终使用产品的消费者，但购买者却不一定与使用者是同一个人。例如，研发面向儿童的智能问答产品，不但要研究使用者的特定属性，还要研究实际购买人的心理。特别是在一些大型产品的销售过程中，还要分析影响者和决策者。影响者是对购买决策者产生影响的人，决策者是对购买行为——向谁购买、何时付款做出最终决定的人。

例如，企业研发了一款智能餐饮服务机器人，该机器人可以完成上菜工作。这类机器人的销售对象一般为 B 端的餐饮企业，产品的使用者（C 端消费者）一般是不会购买的。企业在购买产品时，经手人又会涉及多种角色，如采购经理、技术顾问、企业老板等。一般采购经理是直接的购买者，他们比较关心的是产品和价格，我们应把产品和竞争对手产品的差异提供给他们；而技术顾问比较关心的是产品的特性、技术参数；如果买方经手人是企业老板，那么我们在介绍产品的同时，要侧重强调对方的竞争对手和本地的同类企业与我们的合作情况，以引起对方的关注。

因此，在设计产品时，产品经理应充分考虑到不同类型的角色的不同类型的需求。如果产品能够满足使用者的各种需求，他们通常就会进行采购。

### 5.3.2 竞争对手分析

通常情况下，某一个企业看好的市场，其竞争对手也会看好，绝对的蓝海市场一般是不存在的。当有消费者对某种类型的产品产生需求时，市场会自动产生。当市场产生时，自然会出现以生产某种类型的产品来满足市场需求的竞争者。因此，当企业确定要在某个领域研发产品时，还必须对竞争对手进行深入分析。

分析竞争对手，首先需要确定好范围，因为任何一个企业都难以有足够的资源和能力去和业内所有竞争对手抗衡。笔者建议将竞争对手分级、分类管理，针对不同产品的竞争对手制定不同的产品策略、定价策略和营销策略。

顶级的竞争对手一般与企业有相同或者相似的技术，市场战略、市场细分、产品设计和产品功能也基本一致，这样的竞争对手才是企业真正的竞争对手，与此类竞争对手的竞争也更直接、更激烈。

竞争对手可以分为直接竞争对手和潜在竞争对手。对于直接竞争对手，尤其是在同一个市场中占有率增速较快的直接竞争对手，需要严格注意其竞争优势的来源。一般情况下，同一个竞争对手不会在每个细分市场领域中都出现，而是在具体的某一个市场中出现，所以我们在进行竞争对手分析时，应注重竞争对手的核心业务。

对于潜在的竞争对手，有一句话可以描述：“可怕的不是你知道的竞争对手打败你，真正可怕的是你甚至不知道你的竞争对手是谁！”

部分互联网企业在进入新的行业时，往往采用降维打法，快速打破信息不对称性，并迅速占领市场。这种方法的效果在企业进入壁垒较低的行业时尤其明显，而这类企业一般有明显的潜在技术竞争优势。

分析竞争对手时，首先要从战略方向进行分析。分析竞争对手的长远目标可以判断其如何改变战略，以及对外部环境变化会采取什么样的具体措施。如果得不到具体的战略规划，可以根据收集到的信息进行一些战略假设，并逐步验证。进行战略假设时，可以以竞争对手所信奉的理论为基础进行假设。例如，某些企业信奉的是短期利润，认为有利润才能支持发展，而有些企业信奉市场占有率和规模经济，认为只要能占领市场，扩大生产销售规模，成本就会下降。进行战略假设时，也可以通过竞争对手对自身的认知进行假设。例如，有些企业认为自身在技术上有优势，有些企业认为自身在生产上有优势，而有些企业认为自身在渠道上有优势。

开展竞争对手分析，应从多方面对竞争对手进行信息收集。信息收集的方法分为直接搜索和间接搜索。一般情况下，竞争对手的资料信息来源包括以下几个方面。

（1）竞争对手的内部报纸和杂志。竞争对手的内部报纸、杂志会记载很多企业内部的详细信息，如公司任命、员工介绍、部门介绍、新产品及战略发展等。

（2）广告、媒体介绍。企业通过广告宣传、外部媒体，可以了解竞争对手的宣传重点、战略方向、媒体选择和推广费用等信息。

（3）行业出版物。企业通过行业出版物可以了解竞争对手的战略发展方向、产品规格及产品优势等信息。

（4）竞争对手高管的论文和演讲。了解竞争对手高管的论文和演讲对了解竞争对手的经营理念、组织管理、市场发展及产品规划有很大帮助。

（5）销售人员的反馈。企业内部销售人员在面向市场的过程中，可以了解区域内竞争对手的情况，如产品的定价、服务和质量等资料，但企业内部人员在反馈竞争对手的信息时往往带有一些偏见，所以产品经理需要对信息进行筛选。

（6）顾客。企业根据顾客的反馈往往能够获得竞争对手的某些详细信息，信息不仅包括产品的具体信息，还包括竞争对手宣传自身价值和优势的信息。

（7）供应商。企业通过上下游供应商，可以了解竞争对手的一些信息，如竞争对手的投资计划、市场规划和企业运行效率等。
