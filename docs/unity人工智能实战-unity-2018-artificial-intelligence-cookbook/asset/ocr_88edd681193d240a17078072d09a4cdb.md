```
# 9.查找运行的集合，并计算反悔这些行动的概率总和：

```
```csharp
for (i = 0; i < numActions; i++)
{
    chance[i] = 0f;
    if (regret[i] > 0f)
        chance[i] = regret[i];
    if (i > 0)
        chance[i] += chance[i-1];
}
```
