# 运行原理

我们用伪探测算法实现了本书的功能，然后保存了行动后的报酬。该方法首先测试每个行动，然后使用 UCB1 算法中的方程式出招。这足够有挑战性，同时也是会输的，因为算法采用不同的选择——所以对于玩家来说，创建更好的变化手段可以改进技巧，或者说运气。
