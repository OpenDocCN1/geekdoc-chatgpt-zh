# 8.1 简介

在本章中，我们将探索机器学习的领域。这是一个非常宽泛且固有的领域，即使在 3A 游戏中也很难实现，因为这项技术需要大量的时间去优化和试验。

然而，本章中包含的方法将成为我们努力学习并把机器学习技术应用到游戏中的良好开端。这些方法有几种不同的使用途径，而我们通常用得最多的一项功能是难度调整。

最后，建议你阅读更多关于本主题的正式书籍来补充这几个方法，以便在本章之外能够在理论上有所深入。
