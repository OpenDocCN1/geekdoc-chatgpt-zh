+   11. 假如位置有效，将它所有有效的邻接点添加到队列中：

```
for (i = row - 1; i <= row + 1; i++)
{
    for (j = col - 1; j <= col + 1; j++)
    {
        if (i < 0 || j < 0)
        continue;
        if (j >= numCols || i >= numRows)
        continue;
        if (i == row && j == col)
        continue;
        queue.Enqueue(new Vector2(j, i));
    }
}
}
```
