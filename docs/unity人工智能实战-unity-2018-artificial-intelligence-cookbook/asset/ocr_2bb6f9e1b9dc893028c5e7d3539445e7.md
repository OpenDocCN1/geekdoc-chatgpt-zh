# 7.1 简介

在本章中，你将学习一系列算法，用于开发棋类游戏技术和创建人工智能。这些算法基于博弈树图的原理，评估状态并决定访问其邻接点时都会用到。这些算法还考虑了适用于两个玩家的棋类游戏。然而只需要稍微一点儿工作，其中的一些算法就可以扩展到多个玩家。
