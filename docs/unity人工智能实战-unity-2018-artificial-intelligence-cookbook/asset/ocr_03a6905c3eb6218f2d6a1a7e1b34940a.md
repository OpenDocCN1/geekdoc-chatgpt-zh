# 运行原理

如前所述，根据设置，导航网格被划分成不同的区域。当实现用于找到目标的路径搜索算法时，agent 要考虑到为每个区域定义的权重。如文档所说，Unity 实现了 A* 算法，所以 agent 选择了成本最低的路径。它也只考虑了我们选择的区域。这就是为什么我们取消了大门，让玩家可以躲在门背后避难。
