# 2. 定义函数，用于检测某个兴趣是否相关：

```
```csharp
public bool IsRelevant(Interest i)
{
    int oldValue = (int)interest.priority;
    int newValue = (int)i.priority;
    if (newValue <= oldValue)
        return false;
    return true;
}
```
