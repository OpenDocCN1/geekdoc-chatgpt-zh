什么时候减速，什么时候停止，这也是为什么我们有多个 if 语句。在 Arrive 行为中，当 agent 还很远时，我们全速前进，在快接近半径距离内时就渐渐地减速，并最终在足够接近目标时停止。相反的思路可用于 Leave 行为，如图 1-1 所示。
