}

```
return Predict(position, velocity, numHit + 1);
```

# 运行原理

agent 根据小球的当前速度计算其下一次撞击，直到计算结果是小球撞击 agent 的墙体。该计算结果会给出一个点，让 agent 向这个点移动击球器。另外，当击球器接近小球并向它移动时就变成攻击模式，否则就根据新的距离变成空闲模式或者防守模式。
