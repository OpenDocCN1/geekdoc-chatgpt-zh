## 2.1 基本概念

OpenAI 推出了一批面向不同任务的模型，各自的计费标准也有差异。下面会逐一对照这些模型，并说明如何依据需求挑选合适的方案。要注意，模型的设计定位——是做文本补全、对话还是编辑——会直接影响你调用 `API` 的方式。例如 `GPT-4` 和 `ChatGPT` 背后的模型属于对话导向，因此需要使用对话端点。

第 1 章已提到“提示词”的概念。提示词不仅适用于 OpenAI `API`，也是所有 `LLM` 的输入入口。通俗来说，提示词就是喂给模型的一段文本，用来指引它完成特定任务。对于 `GPT-4` 和 `ChatGPT` 对应的模型，提示词采用对话结构，输入消息和输出消息都以列表形式保存。本章后面会详细说明提示词的写法。

除提示词外，第 1 章还介绍了标记。标记指一个词或词的一部分。粗略估算，100 个标记约等于 75 个英文单词。对 OpenAI 模型发起请求时，计费依据是所用标记数，也就是说成本取决于输入文本和输出文本的长度。如何控制输入标记与输出标记的细节，可参见 2.5 节和 2.6 节。

## 2.2 OpenAI API 提供的可用模型

通过 OpenAI `API`，可以调用由 OpenAI 开发的多款模型。这些模型以服务形式提供，可直接通过 HTTP 调用或官方客户端库访问，模型运行在 OpenAI 的远端服务器上，开发者只需发送查询即可。

每个模型的功能和价格各不相同。本节介绍通过 `API` 提供的 `LLM`。需要说明的是，这些模型为私有，无法自行修改源码。但正如后文所述，部分模型可通过 OpenAI `API` 在特定数据上进行微调。

> [PRE2] 部分较旧的 OpenAI 模型，比如 `GPT-2` 系列，并非私有。你可以从 Hugging Face 或 GitHub 下载 `GPT-2` 模型，但无法通过 `API` 调用。

由于 OpenAI 持续更新模型，本书难以列出完整清单，最新动态请以官方文档为准。下面聚焦几个最具代表性的模型。

> `InstructGPT`

该系列擅长多轮单次文本补全任务。`text-ada-001` 只能完成基础补全，却是 `GPT-3` 家族中速度最快、价格最低的模型。`text-babbage-001` 与 `text-curie-001` 能力稍强，价格也更高。`text-davinci-003` 在各类文本补全任务上表现突出，也是 `GPT-3` 系列 2 中最贵的。

2 截至 2023 年 11 月下旬的消息，`InstructGPT` 系列将在 2024 年 1 月 4 日统一替换为最新的 `gpt-3.5-turbo-instruct` 模型。——译者注

> `ChatGPT`

`ChatGPT` 对应的模型是 `gpt-3.5-turbo`。作为对话型模型，它接受消息序列输入并生成对应输出。虽然聊天格式主要面向多轮对话，也可用于无对话的单次任务。在单次任务中，`gpt-3.5-turbo` 的表现与 `text-davinci-003` 相当。且 `gpt-3.5-turbo` 的价格仅为 `text-davinci-003` 的十分之一 3，因此单次任务场景下建议优先选用。`gpt-3.5-turbo` 的上下文窗口约为 4000 个标记。OpenAI 还提供 `gpt-3.5-turbo-16k`，功能相同但上下文窗口扩大 4 倍。

3 截至 2023 年 11 月下旬，最新版本的 `text-davinci-003` 价格是每千个标记 0.0200 美元，`gpt-3.5-turbo-0613` 的价格是每千个输入标记 0.0030 美元 + 每千个输出标记 0.0040 美元。——译者注

> `GPT-4`

这是 OpenAI 目前发布的最大规模模型。它基于海量的文本与图像多模态语料训练，在多个领域表现出色。`GPT-4` 能较好遵循复杂的自然语言指令并解决难题，可用于对话任务和单次任务，且准确度较高。OpenAI 提供两个 `GPT-4` 模型 4：`gpt-4` 的上下文窗口为 8192 个标记，`gpt-4-32k` 的上下文窗口为 32 768 个标记。32 768 个标记约等于 24 576 个英文单词，相当于约 40 页的上下文。

无论是 `GPT-3.5 Turbo` 还是 `GPT-4`，都在持续迭代。文中提到的 `gpt-3.5-turbo`、`gpt-3.5-turbo-16k`、`gpt-4` 和 `gpt-4-32k` 均指最新版本 5。

## 2.4　开始使用 OpenAI Python 库

本节聚焦于如何在小型 Python 脚本中使用 `API` 密钥，并演示第一次调用 OpenAI `API` 的过程。

OpenAI 以服务形式提供 `GPT-4` 和 `ChatGPT`。用户无法直接访问模型代码，也无法在自有服务器上运行。OpenAI 负责部署与运行，只要拥有账户和 `API` 密钥即可调用。

开始前请确认已登录 OpenAI 账户。

### 2.4.1　OpenAI 访问权限和 API 密钥

使用 OpenAI 服务必须持有 `API` 密钥，其作用有两点：

* 授权你调用 `API` 方法；
* 将你的 `API` 调用与账户关联以便计费。

在应用中调用 OpenAI 服务时，必须提供该密钥。
