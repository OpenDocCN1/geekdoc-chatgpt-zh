# 第三章

# 短视频创意指令进阶指南

让创作指令更具吸引力、画面感与叙事张力，同时保持表达简洁明晰，能够快速点燃模型灵感，从而产出高质量、抓人眼球的智能短片，是本章重点。本章聚焦智能短片指令的优化思路。

3.1 如何产出高质量指令

高质量的智能短片指令，需要创作者把想呈现的画面讲清楚，并引导模型准确理解意图。下面介绍具体做法。

3.1.1 指令的架构与打磨

[PRE8]

3.1.1 指令的架构与打磨

撰写优质智能短片指令时，结构合理与打磨手法很重要。条理清晰、分层明确的指令结构，既能帮助模型更好把握创作意图，也能提升输出的质量和艺术表现。下面给出架构与打磨的详细说明。

一个有效的指令通常由以下要素构成。

（1）主体描述：明确短片的核心人物或元素，包含外貌、特征等。例如，一名身着红裙的年轻女性。

（2）环境描述：交代主体所在的空间，包含背景、地点等。例如，画面背景是落日下的田野。

（3）动态描述：说明主体的行为或画面中的运动部分。例如，女子在田野里漫步，如图 3-1 所示。

[PRE9]

图 3-1 女子在田野中散步

（4）拍摄语言：规定拍摄方式，如视角、景别、运镜等。例如，采用第一人称视角，镜头跟随女子移动。

（5）光影描述：描绘画面中的光线与阴影，增强质感。例如，夕阳余晖洒在女子身上，形成柔和的光影层次。

（6）氛围词：用氛围描写传递情绪。例如，营造温暖宁静的整体感觉。

（7）风格定位：指定整体视觉风格，如卡通、油画、水彩、赛博朋克等。例如，“写实风格，带电影质感”。

3.1.2 常见问题与解决方法

[PRE11]

3.1.2 常见问题与解决方法

原创指令有时会得到不理想的视频效果，了解常见问题及对策很有帮助。

问题1：指令结构不清，导致模型理解偏差。
方法1：使用固定结构撰写，常用格式为“主角信息＋动作＋环境描述＋拍摄语言＋光影＋氛围”。例如：“一位穿黑衣的年轻男孩在夕阳跑道上奔跑，侧面拍摄，夕阳逆光，氛围温暖而充满活力，写实风格。”

问题2：描述过于笼统，细节不足，视频真实感和吸引力弱。
方法2：补充具体细节，包括人物特征、场景物件、光影变化等。例如，“男孩汗水飞溅，跑道边摆放运动器材，远处是连绵青山，夕阳余晖铺在跑道上，氛围温暖”，生成效果如图 3-3 所示。

[PRE12]

图 3-3 增加具体细节描述生成的视频效果

问题3：未能有效传递情感或氛围，视频感染力不足。
方法3：加入情感词汇和氛围词，提升画面感与共鸣。例如：“男孩脸上洋溢快乐笑容，画面整体轻松愉悦。”

问题4：未明确拍摄语言，画面感欠缺。
方法4：明确视角、景别、运动方式等。例如：“采用第一人称视角，跟随男孩移动，间或切到远景展示整条跑道及周边环境。”

问题5：未指定整体风格，导致风格不统一。
方法5：在指令中明确风格，如写实、卡通、赛博朋克等。例如：“赛博朋克风格，色彩浓烈对比强，画面具未来感。”

问题6：模型输出与预期差距较大。
方法6：反复调整并细化指令，逐步逼近预期；也可借助模型增强功能或参考成功案例优化。

问题7：缺乏动态描写，画面偏静态。
方法7：增加动态元素描写，如主体动作、场景变化等。例如：“男孩在跑道上疾速奔跑，旁边的树叶也在摇动。”

通过上述问题分析和对策，创作者能写出更高质量的指令，提升视频创作效果和观众体验。
