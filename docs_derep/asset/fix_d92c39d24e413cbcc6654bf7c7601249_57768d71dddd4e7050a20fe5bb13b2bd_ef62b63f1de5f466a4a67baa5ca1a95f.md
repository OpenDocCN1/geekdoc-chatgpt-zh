用 AI 搭框架，定稿还得靠人来把关

做过讲话稿的人都能体会，AI 在搭提纲这一步确实省事，它能把相关点子快速梳理出来，形成一份初稿框架。真正要定调子、删枝节、提炼重点，还是得靠写作者的经验来推敲。AI 在这里只能当辅助工具。等提纲通过领导确认后，再用 AI 逐段展开，效率会更高。

下面以市领导关于人工智能产业发展推进会的讲话为例，示范第一部分“现状分析”的撰写思路。

**现状分析部分的提示词示例**

请以市科技局办公室负责人的身份撰写，工作上擅长公文，对人工智能产业政策比较熟悉。当前中央及省委省政府要求加快新一代人工智能发展，H 市拟召开全市人工智能产业发展大会。请结合【H 市人工智能产业发展现状资料】，按照【现状分析写作框架】和【现状分析提纲】，起草讲话第一部分“现状分析”。要求：①内容要充实，表达要贴合领导讲话语气；②严格按提纲填充；③字数约1200字。

#现状分析写作框架

现状分析部分 = 一级标题 + 引子段 + 成效段1 + 成效段2 + …… + 问题段

引子段 = 总体成绩概括句

成效段 = 二级标题（成绩要点） + 描述句（做法） + 描述句（成效，含事例+数据）

问题段 = 问题概括句 + 解决决心句
