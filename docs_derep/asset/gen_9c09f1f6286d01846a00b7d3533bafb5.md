# 第 2 章 知识图谱技术全景图

当下人工智能的发展增速远超预期，人们习惯拿其表现与人类做对比。综合来看，虽然在特定任务上已取得不错效果，但在开放性任务上仍显不足。简单说，利用深度学习与大数据，当前系统在计算密集型任务上可超越人类，却还远谈不上“有学识”，无法像人那样开展复杂推理与联想。知识图谱被视为赋予人工智能“学识”的关键，它借助`RDF`、图形式等存储各类结构化知识，成为人工智能的“大脑”。

知识图谱并非单一技术，而是一整套数据加工、存储与应用的流程。本章围绕整体技术体系展开，分为四个层面：知识表示与知识建模、知识抽取与知识挖掘、知识存储与知识融合、知识检索与知识推理。阅读本章后，读者可以形成对知识图谱技术栈的整体认知。

## 2.1 知识表示与建模概览

对已有知识进行表示与建模是构建知识图谱的基础，也是打造有价值图谱的前提。本节介绍相关概念与常用方法。

### 2.1.1 知识表示的本质

要让计算机系统高效处理和利用知识，就必须先对知识进行表示与存储。知识表示是人工智能的核心议题之一，目前尚无完美的统一定义。Davis 等人在“What is knowledge representation”\[1\]中提出五种角色：

* 真实世界知识的抽象替代
* 本体论的集合
* 不完整的智能推理理论
* 高效计算的媒介
* 知识的中间体

这五点可以构成较为全面的理解。下面解释其要解决的问题。

首先，知识表示可看作对现实世界知识的抽象替代，且这种替代需机器可理解。任何希望感知环境的智能体都会面临外部知识的获取难题。例如婴儿需将汽车、苹果等实物转化为大脑中的抽象表征才能学习。计算机学习真实世界知识同样需要在内部建立抽象替代，但现实世界的抽象表示不可能完全无损。

为此引入第二个角色：一组本体论的集合。本体论把现实概念和实体抽象为类与对象，在一定程度上解决了无损替代的局限。使用者可以只聚焦关注点进行抽象，避免信息过载。正如人类在判断决策时依赖关注重点，系统也必须筛选有用信息。

第三，知识表示是一个不完整的智能推理理论。知识表示与推理的产生源于智能体需要推理的需求。认知能力是判断智能的重要标志，智能体需存储知识并据此推理产生新知识。但仅有表示理论不足以构成完整推理，还需推理方法等配合。

第四，知识表示是一种高效计算的媒介。从机器视角看，推理是计算过程。若要得到结果，必须对已有表示进行高效计算，而知识表示整合了真实世界知识，推理时可直接利用。

第五，知识表示也是知识的中间体。它是对真实世界的描述，可作为向机器或人类传播知识的载体。现实中书籍即为一种知识表示，承担传播与表达的功能。

综合来看，知识表示是对真实世界的不完整抽象描述，仅包含关注的方面，同时可作为计算与推理的中间件。了解概念后，下一步是理解知识如何表示。计算机系统中存在多种表示方法和形式化语言，不同方法效果各异。为此需要一种公认的描述方式，要求简洁且可扩展以适应知识多样性，这就引出描述逻辑与描述语言。

#### 1. 描述逻辑原理

描述逻辑是一系列基于逻辑形式化的表示方法，能够以结构化、易理解的方式进行知识表示与推理。它建立在概念与关系之上，概念对应图谱中的类与实体，关系对应实体间的联系。描述逻辑是一阶谓词逻辑的可判定子集，可基于原子概念对其他概念进行描述与推理。

描述逻辑主要包含术语知识`TBox`和断言知识`ABox`。术语知识指领域中的类、属性与关系，如公司、地点等；断言知识指实例相关知识，如`<小米公司，法定代表人，雷军>`。其中概念`Concept`表示类与实体，角色`Role`表示性质，个体`Individual`表示概念断言与常量，运算符`Operator`用于构建复杂表达。例如`雷军 = 小米公司 ∧ 董事长`是最简单的描述逻辑表达。描述逻辑是知识表示与建模的基础，被多种描述语言与框架采用，标准知识描述语言即由其演化而来，且可读性更强。

#### 2. 描述语言体系

在知识表示过程中，除了逻辑，还需要合适的语言基于既定逻辑描述知识并传递信息。按`W3C`标准，通常使用资源描述框架`RDF`与网络本体语言`OWL`进行描述，二者均以可扩展标记语言`XML`为核心语法。下面分别介绍。

##### (1) XML 语法基础

`XML`定义了一套数据对象类型以及处理它们的程序行为。它是一种格式规范、易用且可扩展的标记语言，允许用户自定义标签描述内容。`XML`由`XML`工作组开发，1996年由万维网联盟`W3C`主持成立。其核心任务是以纯文本格式存储与交换数据，实现跨软件与硬件的传输与共享。

一个完整的`XML`文档由元素构成，每个元素由字符组成，部分为字符数据，部分为标记，用于描述存储布局与逻辑结构。`XML`还提供约束存储布局与逻辑结构的机制，使结构更整洁。其设计目标包括：

1）能在互联网上直接使用。
2）支持多种应用程序。
3）与`SGML`兼容。
4）处理`XML`文档的难度尽量降低。
5）可选功能尽量最少，理想为零。

由此可见`XML`遵循简单、易用、可扩展原则。在 Web 中常用于存储元数据。但因标签可自定义，两个系统交换`XML`数据需事先知晓彼此标签。`XML`不是知识表示语言，但其核心语法可迁移至`RDF`、`OWL`等描述语言。下面以记录公司信息列表的`XML`文件为例，展示小米公司的名称、法人、公司种类、地址等属性，体现格式规范。

##### (2) RDF 三元组模型
