在人工智能体系里，搜索可以说是一个地基级的难题。它的本质是为达成果想要不断探寻可行的推理路径，并借此牵引和调控整个推理过程，最终让问题得到解答。就问题的表征方式而言，搜索主要分成两大流派：状态空间搜索和与/或树搜索。前一种是借助状态空间的思路来求解，后一种则是依托问题归约的方法来求解。

做搜索时，人工智能最在意的是如何利用搜索过程中捕捉到的、能够加速达成目标的线索来指引下一步的探索，这也就是启发式搜索的思路。它既体现在状态空间的启发式搜索上，也体现在与/或树的启发式搜索上。

博弈就是搜索问题里最典型的例子。目前的研究重心基本都放在下棋上。最具代表性的就是 IBM 研发的超级计算机“深蓝”和“小深”，它们与国际象棋世界冠军展开过对弈。国内的学者也在积极推进中国象棋的机器博弈，比如 2006 年 8 月在北京举行的首届中国象棋人机大战，计算机棋手以 3 胜 5 平 2 负的微弱优势赢了国内的象棋大师。

机器博弈的意义并不仅仅是让机器陪人下棋，更关键的是它为人工智能提供了一个可验证的试验平台，同时也用事实证明了计算机的智能水平。连国际象棋世界冠军都可能被电脑击败或逼平，这足以说明机器已经具备相当高的智能表现。

#### 3. 规划
规划是一类更关注求解过程本身的问题求解技术。它的任务是从某个初始状态出发，构造出一条操作序列，一步步推向目标状态。与一般求解方式相比，规划更贴近真实世界的实际任务，而不是纯粹的抽象数学模型。

比较成熟的代表是斯坦福研究所问题求解系统 STRIPS。它基于状态空间和 F 规则来做规划。F 规则指的就是正向推理时使用的规则。整个 STRIPS 由三部分构成：世界模型、操作符和操作方法。世界模型用一阶谓词公式来描述，包含初始状态和目标状态。操作符由先决条件、删除表和添加表组成，先决条件是规则可执行的必要前提，删除表记录执行规则后需要从当前状态中去掉的谓词，添加表记录需要加入的谓词。操作方法采用状态空间表示配合中间结局分析。状态空间里有初始状态、中间状态和目标状态。中间结局分析是一个迭代过程，每次挑选能够缩小当前状态与目标状态差距、且先决条件可被满足的 F 规则执行，直到抵达目标为止。

### 10.4.2 机器感知
机器感知是机器获取外界信息的主要通道，也是智能能力的核心组成。下面围绕机器视觉、模式识别和自然语言处理展开。

#### 1. 机器视觉
机器视觉是让计算机模拟或实现人类视觉功能的研究方向。核心目标是让机器通过二维图像理解三维环境的信息，其中既包括物体形状、位置、姿态、运动等几何属性，也包括对这些属性的描述、存储、识别与理解。

视觉在人类感知中占据主导地位，我们接收到的外界信息里约八成以上来自视觉，正如俗话说的“百闻不如一见”。人类的视觉流程大致是：物体在光照下在视网膜形成图像，由感光细胞转为神经脉冲，经神经纤维传至大脑皮层，再由大脑完成处理与理解。可见视觉不仅是光信号的感受，更涵盖了信息获取、传输、处理、存储和理解的完整链条。

目前计算机视觉已在诸多领域落地。图像识别方面有指纹识别、染色体识别、字符识别；航天与军事方面有卫星图像处理、飞行器跟踪、成像精确制导、景物识别、目标检测；医学方面有 CT 图像的脏器重建、医学图像分析；工业方面则广泛用于各类监测与监控系统。

#### 2. 模式识别
模式识别是人工智能的早期研究方向之一。“模式”本意是可供模仿的典型样本。在日常语境里，一幅画、一处景物、一小段音乐、一栋建筑等都可以视作模式。在理论层面，模式是对某事物进行定量或结构性描述的集合。

模式识别就是让计算机对给定事物进行鉴别，并归入与其相同或相似的模式类别。被鉴别对象可以是物理、化学、生理属性，也可以是文字、图像、声音。为了实现识别，通常需要为计算机配备各种感知器官以直接感知外界。常规流程是先采集待识别事物的模式信息，再进行变换与预处理，提取有意义的特征或基元，得到表征模式，随后与机器中已有的标准模式进行比对，完成分类，最后输出结果。

根据标准模式的不同，识别方法多样，常见的做法有模板匹配法、统计模式法、模糊模式法、神经网络法等。模板匹配法把标准模式当作典型模板，与待识别模式直接比较完成判别。统计模式法基于待识别事物的统计特征构造差异明显的样本作为标准模式，再借助决策函数进行分类。模糊模式法建立在模糊集理论之上，用于处理带有模糊特征的事物。神经网络法则先用一组训练样本对网络进行训练，确定连接权值后再用于识别。

#### 3. 自然语言处理
自然语言是人类信息交流的主要媒介，也是机器智能的重要标志。但由于其多义性和不确定性，人机交流目前仍主要依赖受严格限制的非自然语言。自然语言处理就是研究人机之间有效交流的理论与方法，主要覆盖自然语言理解、机器翻译和语音处理。

自然语言理解关注如何让计算机理解和生成自然语言，可分为书面语言理解和声音语言理解。书面理解通常经历词法分析、句法分析、语义分析和语用分析四个阶段；声音理解则在上述阶段前需先做语音处理。主要难点在语音分析，因为它涉及上下文知识，需要考虑语境影响。

语音处理的目标是让计算机听懂人类语言。基本流程是从声波分析入手，抽取与构成单词的发音单元相关的特征，随后在单词识别阶段用模型将发音单元序列与单词序列匹配。

机器翻译是用计算机实现一种语言到另一种语言的转换。尽管自然语言理解、语音处理和机器翻译都有不少进展，但计算机完全理解人类自然语言的目标仍很遥远。自然语言理解的研究对智能人机接口有实际意义，对不确定性人工智能也有重要理论价值。

### 10.4.3 机器行为
机器行为既是智能机器作用于外部环境的主要方式，也是智能的重要体现。这里重点介绍智能控制和智能制造。

#### 1. 智能控制
智能控制是指在尽可能少的人工干预下，独立驱动智能机器实现目标的控制过程。它把人工智能技术与传统自动控制技术结合起来，构建智能控制系统。

# 智能控制系统
智能控制系统能够完成特定控制任务，并具备自学习、自适应和自组织功能。结构上通常包括传感器、感知信息处理模块、认知模块、规划与控制模块、执行器、通信接口模块。传感器负责采集被控对象的现场信息；感知信息处理模块对原始信息进行处理；认知模块利用控制知识和经验对当前信息进行分析、推理和决策；规划与控制模块据任务要求和决策结果制定控制动作；执行器按规划完成具体动作；通信接口模块实现人机交互和各模块间联系。

## 常用的智能控制方法
目前常用的方法主要有模糊控制、神经网络控制、分层递阶智能控制、专家控制和学习控制等。应用范围涵盖智能机器人系统、计算机集成制造系统 CIMS、复杂工业过程控制、航空航天控制、社会经济管理系统、交通运输系统、环保及能源系统等。

## 2. 智能制造
智能制造是以计算机为核心，集成相关技术，对制造活动中与专门人才相关的智能活动进行替代、延伸和强化，并在此基础上发展和创新制造。所用技术统称为智能制造技术，指在制造系统和制造过程的各环节，通过计算机模拟人类专家的智能活动，并与制造环境中人的智能进行柔性集成与交互的各种制造技术的总称。主要包括机器智能的实现技术、人工智能与机器智能的融合技术，以及多智能体的集成技术。

在实际模式下，智能制造系统多为分布式协同求解系统，其核心特征是智能单元的自主性与系统整体的自组织能力。近年来，智能 Agent 技术在网络环境下的智能制造系统开发中得到广泛应用。

### 10.4.4 机器学习
机器学习是机器获取知识的根本途径，也是具备智能的重要标志。若一个计算机系统缺乏学习能力，通常不被视为智能系统。按对人类学习的模拟方式，机器学习可分为符号学习和神经学习。

### 1. 符号学习
符号学习从功能上模拟人类学习能力，基于符号主义观点，认为知识可用符号表示，学习过程即符号运算过程。按学习策略可分为记忆学习、归纳学习和演绎学习等。

记忆学习也称死记硬背，是最基础的学习方式，任何学习系统都需记住所得知识以备后用。归纳学习以归纳推理为基础，从已知概念的正例和反例中归纳出一般概念描述，是研究较多的一类。示例学习和决策树学习是典型代表。演绎学习以演绎推理为基础，解释学习是一种演绎学习方法，它在领域知识指导下，通过分析单个问题的求解例子，构建求解过程的因果解释结构，再进行概括化，得到可用于解决类似问题的一般性知识。

### 2. 神经学习
神经学习又称联结学习，基于人工神经网络。脑科学表明，人脑的学习与记忆通过神经系统完成，神经元既是学习基本单元也是记忆基本单元。按神经网络模型，典型学习算法有感知器学习、BP 网络学习和 Hopfield 网络学习等。

感知器学习是一种基于纠错学习规则的迭代算法，通过不断调整连接权值和阈值直至满足终止条件。BP 网络学习是误差反向传播网络学习，包含输出模式的正向传播和误差的反向传播，其中反向传播用于修正各层连接权值，逐步减小误差直至得到期望输出。Hopfield 网络学习旨在寻求系统稳定状态，从初始状态逐步过渡到稳定状态，稳定性通过能量函数描述。

### 10.4.5 计算智能
计算智能 CI 是借鉴仿生学思想，基于对生物体智能机理的认识，采用数值计算方法模拟和实现人类智能。主要研究领域包括神经计算、进化计算和模糊计算。

### 1. 神经计算
神经计算即神经网络 NN，通过大量人工神经元的广泛并行互联形成人工网络系统，用于模拟生物神经系统的结构与功能。它是结构层面的智能模拟，主要研究人工神经元的结构与模型、人工神经网络的互联结构与系统模型、基于神经网络的联结学习机制等。

人工神经元是人工构造的单个单元，具有抑制和兴奋两种工作状态，可接收外界刺激并输出自身状态，用于模拟生物神经元，是网络的基本处理单元。互联结构即神经元间的联结模式，是构建网络的基础，按此可分为前馈网络和反馈网络。网络模型概括了结构、连接权值和学习能力，常用模型有传统感知器模型、具有误差反向传播功能的 BP 网络模型和采用反馈联结方式的 Hopfield 网络模型等。

神经网络具备自学习、自组织、自适应、联想、模糊推理等能力，在模仿生物神经计算方面优势明显，研究和应用已渗透到机器学习、专家系统、智能控制、模式识别、计算机视觉、信息处理、非线性系统辨识及非线性系统组合优化等领域。

### 2. 进化计算
进化计算 EC 是模拟自然界生物进化过程与机制，进行问题求解的自组织、自适应随机搜索技术。它以达尔文“物竞天择，适者生存”为进化规则，结合孟德尔遗传变异理论，将繁殖、变异、竞争和选择引入算法，是对人类智能的演化模拟。

进化计算主要包括遗传算法、进化策略、进化规划和遗传规划四大分支。遗传算法是其中最早形成且影响广泛的模拟进化优化算法。其基本思想是用模拟生物和人类进化的方法求解复杂问题，从初始种群出发，按优胜劣汰选择个体，通过杂交、变异产生新一代种群，逐代进化直至达到目标。

### 3. 模糊计算
模糊计算即模糊系统 FS，通过对人类处理模糊现象认知能力的认识，用模糊集合和模糊逻辑模拟人类智能行为。模糊集合与模糊逻辑由加州大学 Zadeh 教授提出，用于处理因模糊导致的不确定性。

通常把边界不清晰无法精确刻画的现象称为模糊现象，相应的概念称为模糊概念，如“大”“小”“多”“少”等。在模糊系统中，模糊概念常用模糊集合表示，模糊集合则用隶属函数刻画。隶属函数的值在 0 到 1 之间，用来描述自变量所代表的模糊事件隶属于该概念的程度。目前模糊计算在推理、控制、决策等方面应用广泛。

### 4. 人工生命
人工生命是洛斯·阿拉莫斯非线性研究中心的 Chris Langton 在研究“混沌边沿”的细胞自动机时于 1987 年提出的概念。他认为人工生命是研究能够展示人类生命特征的人工系统，即研究以非碳水化合物为基础、具有人类生命特征的人造生命系统。

人工生命研究不特别关注以碳水化合物为基础的生命的特殊形式，而关注生命的存在形式。按照该观点，若能从具体生命中抽象出控制存在形式的关键机制，并在另一种物质中实现，就可创造出基于不同物质的另一种生命——人工生命。所采用的主要是自底向上的综合方法，目标是创造出具有人类生命特征的人工生命。

### 10.4.6 分布智能
分布式人工智能 DAI 随着计算机网络、计算机通信和并发程序设计技术的发展而形成，是研究逻辑上或物理上分布的智能系统如何相互协调智能行为、实现问题并行求解的新领域。

目前研究主要沿两个方向展开：分布式问题求解和多 Agent 系统。分布式问题求解关注多个合作者之间如何划分任务和求解问题；多 Agent 系统关注一群自主 Agent 之间如何协调智能行为。多 Agent 系统由多个自主 Agent 组成，每个 Agent 可自主运行和交互，当需要合作时，通过通信机制寻找可合作且愿意合作的 Agent，共同解决问题。

### 10.4.7 智能系统
智能系统可泛指各种具有智能特征和功能的软硬件系统，前述研究内容多可具体化为智能系统形式，如智能控制系统、智能检索系统等。下面介绍专家系统和智能决策支持系统等。

### 1. 专家系统
专家系统是基于知识的智能系统，基本结构由知识库、综合数据库、推理机、解释模块、知识获取模块和人机接口组成。知识库用于存放问题相关领域的知识；综合数据库即全局数据库，用于存储事实、数据、初始状态和推理过程中产生的中间状态；推理机控制和协调整个系统；解释模块以用户易懂的方式解释推理过程；知识获取模块用于修改原有知识和扩充新知识；人机接口负责与外界通信。

新型专家系统是当前发展主流，通过引入新思想和新技术克服传统专家系统的缺陷，包括分布式专家系统、协同式专家系统、神经网络专家系统和基于 Web 的专家系统等。

### 2. 智能决策支持系统
