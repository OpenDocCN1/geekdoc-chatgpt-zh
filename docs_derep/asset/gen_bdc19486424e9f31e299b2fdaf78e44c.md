### 学习目标

- 1) 学会用 FastAPI 构建高性能异步 AI 服务的核心手法。
- 2) 掌握流式响应的原理以及落地时的最佳实践。
- 3) 能够设计并开发 AI 中间件，提升代码复用水平。
- 4) 提升优化 Python 后端性能的实战能力。

FastAPI 是当前流行的一款 Python Web 框架，依托标准类型提示驱动开发，兼具高性能、开发效率高、文档自动生成等特性。其强大的异步能力与类型安全优势，使其非常适配 AI 应用的后端建设。后续内容将围绕异步模型服务、流式响应机制以及 AI 中间件的工程化展开。

from fastapi import FastAPI

from fastapi.middleware.cors import CORSMiddleware

from app.api.v1.router import api_router

from app.core.config import settings

app = FastAPI(

    title=settings.PROJECT_NAME,

    openapi_url=f"{settings.API_V1_STR}/openapi.json",

    docs_url="/docs",

    redoc_url="/redoc",

)

# 添加 CORS 中间件

app.add_middleware(

    CORSMiddleware,

    allow_origins=settings.CORS_ORIGINS,

    allow_credentials=True,

    allow_methods=["*"],

    allow_headers=["*"],

)

# 注册 API 路由
