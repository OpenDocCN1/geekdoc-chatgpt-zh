极限入门：从无穷小到无穷大的认知框架

1. 无穷小的表述
当自变量 x 朝向某定值 x₀ 移动，或趋向正负无穷的过程中，若对应的函数值可以被逼迫到任意接近零，则称该函数为无穷小量。
示例：x 接近 0 时，x 本身以及 sin x 都具备这一特征。

2. 需牢记的要点
- 无穷小是随过程变化的量，而非 0.001 这类固定的小数值。
- 唯一恒定的无穷小常数是 0。
- 必须指明趋近方式，如 x→0 或 x→∞，离开过程就无法判定。

（二）无穷大的表述
若自变量趋近某点或趋向无穷时，函数值的绝对值可以被放大到任意大，则称该函数为无穷大，可为正无穷或负无穷。
示例：x→0 时 1/x 为无穷大；x→∞ 时 x² 为无穷大。

2. 需牢记的要点
- 无穷大是过程性的量，而非 100 万这类很大的数。
- 方向上分为正无穷 +∞ 与负无穷 -∞。

二、无穷小与无穷大的相互关系
1. 二者为倒数关系。
2. f(x) 为无穷大时，1/f(x) 为无穷小。
3. f(x) 为不为零的无穷小时，1/f(x) 为无穷大。
示例：x→0 时 1/x 为无穷大，其倒数 x 为无穷小。

三、运算规律
（一）无穷小的运算
1. 有限个无穷小的加、减、乘结果仍为无穷小。例如 x→0 时 x + x² 仍为无穷小。
2. 常数与无穷小的乘积仍为无穷小。
注意：无穷多个无穷小的和或积不一定仍为无穷小。

（二）无穷大的运算与阶的关系
2. 高阶：若 lim(β/α)=0，则 β 比 α 高阶，记 β=o(α)。例如 x² 对 x 为高阶无穷小。
3. 同阶：若 lim(β/α)=c 且 c≠0，则 β 与 α 同阶。
4. 等价：若 lim(β/α)=1，则 β~α，如 x→0 时 sin x~x。应用在极限求解中可作等价替换以简化计算。

五、预习建议
（一）关键公式与定理
1. 极限与无穷小的联系：lim f(x)=A 可写作 f(x)=A+α，其中 α 为无穷小。
2. 无穷小的运算规则：有限项加减乘及常数倍保持无穷小。
3. 常用等价替换：sin x~x，1-cos x~x²/2 等。

（二）易错提醒
1. 无穷大不是数值，不能参与常规算术，如“无穷大+1”无意义。
2. 求倒数时需保证原无穷小不为零。
3. 无穷大与无穷小的乘积结果不确定，如 x·1/x²=1/x 当 x→∞ 时趋于 0。

六、课堂练习预测
1. 判定指定趋近下函数属于无穷小还是无穷大。
2. 在求极限时使用等价替换，如 lim_{x→0} sin3x/2x=3/2。
3. 论证运算后的性质，如证明 x→∞ 时 x+sin x 为无穷大。

提示：结合教材例题吃透定义，重点掌握等价替换与运算规则的运用。

AI 文稿可能遗漏隐含逻辑或误判重点，需对照原视频复核。可通过“回放片段”核对关键表述；对电磁学等复杂内容，将 AI 总结与教材全解对照并补充手写笔记。
