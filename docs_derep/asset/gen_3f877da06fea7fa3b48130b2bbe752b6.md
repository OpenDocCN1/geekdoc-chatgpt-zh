## 第 5 章 指令：驱动 LLM 的核心钥匙

本章先介绍指令的概念与构成要素，随后分享 18 条撰写指令的策略，最后讲解如何抵御恶意攻击。

本章帮助读者建立对指令的基本认知，并在开发实践中灵活运用相关策略与技巧，以提升工作效率。

### 5.1 认识指令

本节讲解指令的定义与组成。

#### 5.1.1 指令的概念

在 LLM 场景中，指令指用户输入给模型以引导其理解需求并作出响应的指导性信息，从而让模型在把握上下文的前提下产出自然流畅的回复。

> **提示** 本书将 Prompt 译为“指令”，其内涵与外界常说的“提示”“提示词”“灵感”等一致，都是指输入给大模型的指导性信息。

指令在问答、文本生成、对话等多种自然语言处理任务中发挥关键作用。使用 LLM 时，指令通常以纯文本形式呈现，例如提问“人工智能对人类文明有何影响”。用户只需用简洁清晰的指引，像“请告诉我关于……的信息”或“如何……”就能触发模型提供知识解答。这类无需训练数据或示例辅助的指令被称为零样本指令 Zero-Shot Prompting，仅靠简短输入模型即可生成相关答案。

设计指令时要结合具体应用场景与目标，确保模型准确捕捉意图并给出贴切回应。除了基础指令，还可以补充详细的背景、相关问题和细节，以帮助模型更深入理解需求。

> 提示 虽然大多数 LLM 都能处理零样本指令，但实际效果仍受任务难度和模型知识边界的影响。

#### 5.1.2 指令的构成要素

在 LLM 应用里，一个完整有效的指令通常包含以下要素。

- 明确指引：指导模型执行操作的核心要求，例如“撰写一篇分析人工智能对未来社会影响的文章”。
- 背景概述：提供模型所需的背景与情境，例如“当前人工智能技术正以前所未有的速度发展”。
- 数据需求说明：明确数据的类型、范围和格式，例如“需涵盖医疗、教育、金融等行业的人工智能应用数据”。
- 约束条件设定：帮助筛选有效信息并聚焦反馈，例如“数据须为近两年内发布且来源于权威渠道”。
- 细化要求阐述：说明期望信息的维度与深度，例如“需包括各行业年度案例、实施成本、成效及遇到的挑战”。
- 进一步指导：为获得更精确全面的结果增加额外指示，例如“请同时附上数据的可视化图表以呈现趋势”。
- 反馈与调整机制：建立互动通道以便修正，例如“若数据不符预期，请补充细节或提出更具体的问题”。

以下是一个典型指令示例。

> “请写一篇关于人工智能对未来社会影响的文章。先回顾其发展历程与现状，再详细说明在医疗、教育、金融等领域的应用，包括项目成本、效益和主要挑战，并以可靠数据支撑论点。文中需用图表呈现相关数据。最后预测其未来发展方向及可能影响。”

### 5.2 编写指令的 18 个策略

##### 1. 使用明确且具体的指令

指令中信息的排列顺序对输出质量影响明显。模型处理输入的方式在构建时已确定。因此先在开头明确任务，再补充上下文或示例，有助于获得更高质量的输出。

（1）不佳示例。

下面的指令未具体说明想了解的内容。

> 你能帮我了解一下人工智能吗？

下面的指令未说明文章主题、范围和要求。

> 你能帮我写一篇关于人工智能的文章吗？

下面的指令未说明学习方向和具体内容。

> 请你教我如何入门人工智能。

（2）较好示例。

> 请结合国内相关政策，分析人工智能在教育领域的发展前景。

针对近期热销的人工智能产品，撰写一份详细的市场调研报告。

设计一个基于人工智能的智能助手，能够解答常见问题并处理日常任务。

##### 2. 添加明确语法

为提升输出可读性和逻辑性，可通过正确使用标点、设置标题和分段等方式增强语法结构。

> 提示 与 LLM 交互时，合理使用分隔符能清晰划分不同问题或主题，使结果更条理、易读易析。

使用分隔符的示例。

> 人工智能的应用领域包括：

医疗领域：涵盖疾病诊断、辅助治疗及智能医疗设备应用。

教育领域：实现个性化学习推荐、智能辅导及自适应教学系统等。

此处使用冒号作为分隔符，清晰划分各领域场景。模型据此能更准确地区分主题，输出更精准的答案。

##### 3. 最后重复一遍指令

模型在处理信息时容易受结尾影响，导致输出偏向指令末尾内容。于结尾重复指令有助于模型更准确执行任务。

（1）不佳示例。

以下指令未指明具体任务。

> 你已了解任务，现在请开始执行。

以下指令缺乏具体描述。

> 我已说明，现在你应该知道怎么做了吧？

以下指令指示不清晰。

> 不必确认，直接按我说的做。

（2）较好示例。

> 为确保理解正确，请再次确认任务：撰写一份关于人工智能在教育领域应用前景的分析报告。

请再次核对你已按要求完成：撰写一份关于我国人工智能最新研究成果的报告。

为避免歧义，请再次确认任务：设计一个基于人工智能的智能助手，需能解答常见问题并处理日常任务。

##### 4. 引导输出操作

在指令结尾添加具体操作要求，以确保模型按所需形式生成响应。

（1）不佳示例。

以下指令未明确需要何种想法或信息。

> 请告诉我你的想法。

以下指令未具体说明报告内容、格式和结构。

> 基于你收集的信息，写一份报告。

以下指令未给出海报主题、风格和设计要求。

> 设计一张吸引人的海报。

（2）较好示例。

> 请详细描述人工智能在医疗领域的三个具体应用场景，每个描述不少于 100 字。

根据收集的数据，以图表形式展示我国近期天气变化趋势，并附简短说明解释图表反映的主要信息。

为一款主打绿色出行的手机应用设计一段创意宣传语，字数不少于 20 字，并解释其背后的理念。

##### 5. 引导输出格式

可通过示例说明期望的输出格式。

请以简洁明了的方式作答，如“是的”或“不是”。

请提供该主题的详细描述，涵盖所有相关信息和要点。

请以列表形式呈现答案，如“1. 关键点 1；2. 关键点 2；3. 关键点 3”。

##### 6. 细化任务分解

将复杂任务拆分为更具体的步骤，能显著提升理解度和答案准确性。

（1）不佳示例。

该指令过于宽泛，涵盖两个不同主题且缺乏分解，导致模型难以精准把握意图。

> 请告诉我如何学习 Python 编程，还有如何开始学习写生。

（2）较好示例。

将大任务分解为三个明确的小任务，每个都有清晰目标，模型可针对性作答。

> 我想学习 Python 编程，请问：1. 如何入门 Python 编程？2. 有哪些优质学习资源？3. 初学者应注意哪些问题？

##### 7. 思维链指令

这种方式不是简单拆分步骤，而是引导模型逐步展示推理过程。能降低不准确性并方便评估响应。

（1）不佳示例。

指令范围过宽，涉及编程与艺术创作两个复杂领域，未作区分，难以得到期望答案。

> 请详细解释如何开始学习 Python，同时告知我如何入门写生。

（2）较好示例。

通过思维链展示学习过程，从概念理解到方向选择再到资源寻找，有助于模型给出针对性答案。

我想学习 Python 编程，首先需了解编程基本概念，然后选定学习方向，再寻找教程和实践项目。请问：1. Python 编程的基本概念有哪些？2. 适合初学者的方向有哪些？3. 有哪些优质教程和实践项目推荐？

##### 8. 提供真实上下文

原始数据与期望答案越接近，模型所需工作越少，错误概率也越低。

（1）不佳示例。

指令虽含部分上下文，但信息混乱且未明确问题，模型难以给出针对性答案。

> 我正在写气候变化论文，不知如何开始。我研究了一些全球变暖数据，但不知道下一步该写什么。

（2）较好示例。

指令详细说明了论文进展并明确下一步问题，具体真实的上下文有助于模型准确把握意图。

> 我正在写一篇关于气候变化的论文，已完成全球变暖现象的介绍，接下来想讨论其原因和影响。请问：1. 全球变暖的主要原因有哪些？2. 对人类生活和生态环境有何影响？

##### 9. 使用定界符分隔指令的不同部分

使用定界符可防范指令注入风险。指令注入是指用户在指令中插入恶意或歧义内容，诱导模型执行非预期操作。分隔指令可确保模型准确识别真实意图，避免干扰。

（1）不佳示例。

指令虽用逗号分隔，但缺乏清晰层级，导致模型难以理解各词关联。

> 我需要了解气候变化信息，比如全球变暖，极端天气，如何应对气候变化，政策措施。

（2）较好示例。

指令用逗号区分主题，并借助“包括”明确层级，有助于模型捕捉意图。

> 我需要了解气候变化背景，包括全球变暖、极端天气，以及应对措施，如政策举措。

分隔符不限于逗号，也可使用 XML 标签、章节标题等形式，根据语境灵活运用以提升信息组织效率。
