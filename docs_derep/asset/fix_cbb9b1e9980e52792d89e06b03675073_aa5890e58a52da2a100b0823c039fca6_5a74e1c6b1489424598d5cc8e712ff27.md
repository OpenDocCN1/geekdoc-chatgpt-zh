# GPT-2 前向准备全拆解

想真正读懂 GPT-2 在跑什么，先看 forward 最开头那段收敛工作。它把各种形式的输入统一成同一套隐向量，既能一次性处理完整段落，也能平滑衔接到逐词自回归。

先把可选项补齐。调用时没传的开关会回落到模型配置里的默认行为，确保后续流程有明确的策略。

输入来源是二选一。原始 token 编号和已经准备好的嵌入向量不能同时出现，有编号就走词表转向量，有嵌入就直接使用。随后对编号、类型编号、位置编号统一做形状整理，让后面的计算保持稳定。

缓存状态决定长度怎么算。第一次进入模型时没有历史上下文，序列视为完整长度；进入自回归阶段后，每一步只喂进一个新 token，序列长度变为 1。历史缓存为空时先用一组 None 占位，后续则从缓存里取出上一次的最后一个维度作为已生成长度。位置编号若未显式提供，会自动从已生成长度开始连续递增，保证位置编码不会断层。首轮是 batch 行乘序列列，后续每步是 batch 行乘 1 列。

掩码处理要做升维。原始的二维填充掩码会被扩成四维，方便与多头注意力做广播相加。保留位置保持 1，被遮蔽的位置换成一个很大的负数，softmax 后基本被忽略。交叉注意力开启且有编码器状态传入时，会同步准备编码器侧的掩码并做反转。头掩码通过统一接口生成，用来在后续层里保留或屏蔽特定注意力头。

嵌入合成先用词表把编号转成向量，再叠加上位置向量；如果提供了段落类型，还会叠加类型向量。经过一次丢弃后得到本轮的隐状态，并据此推算整体输出的形状。是否使用缓存、是否收集注意力或隐藏状态的标志在这里初始化，为后面的层级循环做好准备。
