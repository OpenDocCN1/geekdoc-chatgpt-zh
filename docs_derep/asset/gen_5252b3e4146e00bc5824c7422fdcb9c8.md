把 ChatGPT 嵌入飞书，让企业协作更高效

飞书作为国内使用较广的企业协同办公工具，通过开放接口就能让 ChatGPT 进入工作流，显著提升沟通、协作与服务的效率。接入后，ChatGPT 可以扮演智能聊天助手，自动回复消息并留存对话记录。面对高频咨询或重复性事务，例如日程排布、会议预约等，机器人能够自动处理，释放人力，让团队把精力集中在更复杂的业务上。

下面借助技术博主白宦成 bestony 在 GitHub 上开源的 ChatGPT-Feishu 项目，来完成在飞书上的部署。

#### 7.6.1 新建飞书开放平台应用并获取凭证
登录飞书开放后台，新建一个名为 ChatGPT 的应用并上传头像。随后为应用添加机器人能力。创建完成后进入“凭证与基础信息”页面，复制 APP ID 与 APP Secret 备用。

#### 7.6.2 在 AirCode 上创建 Node.js 项目
打开 AirCode 使用 Google 账号登录，初始化一个 Node.js 项目。按需填写项目名称，例如 ChatGPT。

#### 7.6.3 导入源码并完成首次部署
从 https://github.com/bestony/ChatGPT-Feishu/blob/master/event.js 获取 event.js 的源码内容，粘贴到 AirCode 默认生成的 hello.js 中。点击顶部的 Deploy 按钮执行首次部署，部署成功后可在下方看到 Version: 1。

#### 7.6.4 安装依赖包
安装飞书官方提供的 SDK 以及 axios。点击页面左下角的包管理器，安装 axios 与 @larksuiteoapi/node-sdk，安装完毕后再次点击上方 Deploy 使其生效。

#### 7.6.5 设置飞书环境变量
配置三个环境变量：APP ID、SECRET、BOTNAME。APP ID 与 SECRET 填入此前从飞书开放平台获取的值，BOTNAME 填入机器人的显示名称。若配置未生效可多次部署直至成功。配置成功后右侧黄色提示与下方黄色文字会消失。

#### 7.6.6 填入 OpenAI API Key
在 OpenAI 官网的 API Keys 页面点击“+ Create new secret key”生成新密钥并保存。返回 AirCode 新建一个名为 KEY 的环境变量，填入刚生成的密钥后点击 Deploy 生效。

#### 7.6.7 开启飞书权限并订阅事件
在飞书侧开通权限并完成事件配置，共需开通 6 项权限。

具体操作为：进入飞书开放平台左侧的“权限管理”，在权限配置输入框中输入 im:message，找到前文提到的 6 项权限后勾选，再点右上角“批量开通”。随后回到 AirCode，点击代码复制按钮获取函数调用地址。回到飞书开放平台左侧菜单的“事件订阅”，编辑“请求地址配置”，把 AirCode 的地址粘贴进去并保存。继续点击“添加事件”，在弹出的窗口中选择“消息与群组”，勾选“接收消息 v2.0”，确认添加即可完成事件订阅。

#### 7.6.8 发布版本并上线
完成以上设置后，在飞书开放平台后台进入“应用发布”-“版本管理与发布”，新建一个版本并填写版本号、更新说明后保存。审核通过后即可在飞书中使用 ChatGPT 进行对话。

## 后记
在本书写作期间，人工智能正加速进入大众视野。第一批嗅到商机的从业者已把人工智能与 ChatGPT 融入工作与企业，以提升生产力、降低成本。国内科技巨头在人工智能与大模型赛道投入巨大，技术迭代被戏称为一天抵一年。

百度发布文心一言后一个月，阿里、腾讯、京东、字节跳动、商汤等头部公司相继推出自家大模型，产品如雨后春笋般涌现。这种集体发力既源于技术驱动，也包含某种不落队的焦虑，形成了一个共识：不行动就可能被时代淘汰。

腾讯已推出混元 AI 大模型并在研发类 ChatGPT 的对话机器人；京东发布产业大模型言犀，为各业务场景提供智能化方案；阿里宣布未来所有产品将接入通义千问并整体改造。

这些模型有望重塑各行业，渗透生活各个层面，构建新商业生态，但也带来版权、风格化、以及对文字工作者冲击等挑战。

生成式 AI 在文字处理上的精细度确实会冲击部分文字岗位。但换个角度看，它也提供了自我成长的压力与机会。在数据存储与调用速度上人类难以超越机器，但独到的视角、对美的判断、带个人特色的“不完美”，都能为作品注入灵感，创造真实价值。

可以确定的是，AI 将深度融入日常应用并逐步成熟，这一过程或以年为单位。在此期间，无法适应变化、满足需求的产品将被淘汰，资源可能向少数头部集中，领先者或从追随时代转向引领时代。

## 后记
在人工智能日益普及的今天，我们既面临挑战，也迎来机遇。尤其是生成式 AI 的发展，正在改写工作方式，甚至生活方式。这并不意味着人类价值被削弱，反而是更深入认识自我、挖掘潜力、提升能力的契机。

AI 无法完全替代人类。虽能处理海量数据、执行复杂任务、模仿人类行为，但情感、创造力、独特视角等特质仍是 AI 无法复制的人类优势。

我们应当善用 AI 而非排斥它。它能分担繁琐工作，提升效率与生活质量，为我们赢得更多专注于热爱的时间。

更重要的是持续学习与进步。在快速变化的世界里，停止学习即落后，需不断升级技能、拓展知识版图，以适应新环境。

人工智能不是敌人，而是伙伴。与其共同成长，才能创造更美好的未来。
