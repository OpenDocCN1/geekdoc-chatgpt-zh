# 适配器路由与大模型特化瓶颈梳理

在适配器集合之上设想路由机制，带动了后续的多项探索。Poly-tropon[249] 同时训练适配器库和路由模块，用以在不同任务间重组各尺寸的微调适配器。该思路的变体在[250]中被进一步挖掘，比如用权重平均替代显式路由，或引入多头路由以提升表达力。工程层面，AdapterHub[231] 将主流适配器整合得最完整上手也最便捷，仅不支持大语言模型这一局限。LLM-Adapter[230] 则面向 LLaMA、OPT、GPT-J 等开放大模型搭建适配框架，以串行适配器[223]、MAD-X[234]、并行适配器[251] 与 LoRA[241] 四类作为基础单元，并在其上扩展新模块。

Sung 等人[240] 提醒，即使历史参数被冻结，适配器方案在反向传播时仍会牵动整网，导致训练显存需求依然很高。

综合来看，将适配器迁移到语言模型领域特化时存在两类痛点。

- （1）稳定性与泛化：适配器在预训练语言模型上的表现易受结构选择与超参影响，对稳定性和泛化提出挑战。延伸到大模型，厘清不同适配器与任务设定间的匹配规律是推广的关键。
- （2）算力需求：适配器在预训练语言模型上可取得百万级参数规模的成果，但与大模型的兼容尚未证实。若需叠加更多模块、扩大参数量，计算成本会卷土重来。更理想的方向是通过结构创新或微调策略来压缩训练内存开销。

### 2.7.2 任务导向微调

在大规模语料上训练的 LLM 能力惊人，若要在少样本示例之外实现本质提升，仍需借助大量高质量领域数据更新内部参数。领域微调面临两大难题。

- （1）更新全局知识可能破坏上下文学习能力，源于过拟合、灾难性遗忘与任务偏见等[252]。
- （2）因参数空间庞大、层级很深，微调 LLM 的计算开销极高。

本节归纳更新全局知识的技术，分指令知识更新与局部知识更新两类。

#### 1. 基于指令的知识更新

所谓指令知识更新，是指在带有明确指令或提示的多样任务上微调 LLM 以刷新其参数化知识，概念上与文献[15]的“指令学习”一致。图 2.12 示意了指令微调流程。具体是模型在常识推理、信息抽取等任务上训练并配备详细指令，期望获得通用解题能力。Wei 等人[38] 最早尝试用指令描述数据微调 LLM，验证显示有效指令可显著提升未见任务的零样本表现。FLAN 采用自然语言指令模板，在 60 个 NLP 数据集上微调 137B 模型。结果显示其在多数未见任务上优于未改动基线，甚至在零样本与少样本设定下超过 175B 的 GPT-3。随后[118, 253-254] 在明确指令基础上继续探索，聚焦任务规模、模型规模扩大及在思维链数据上微调。经处理后的模型在众多零样本或少样本基准上达到最优。

##### （1）基于人类指令的微调

该方向旨在引导 LLM 生成更安全、真实、无害且符合用户意图的内容。大多数 LLM 采用自回归生成，受训练语料分布制约，调控难度大。RLHF 是典型做法，用于对齐模型输出与人类需求[78]。流程为 LLM 为同一提示生成多候选，由人类按质量、相关性与期望一致性排序；外部奖励模型据此打分捕捉评估者偏好；再经强化学习更新策略以最大化期望奖励，使模型更贴合人类偏好；生成-排序-建模-优化的循环不断重复，模型持续从人类反馈中学习。现有方法已将 RLHF 成功用于复杂推理任务的人类指令微调[255-256]。

##### （2）基于指令微调的潜在限制

显式指令在 NLP 任务上效果良好，但指令本身偏简单，在与测试集差异大的任务上会受阻。提升多任务适应性常伴随灾难性遗忘，如何在不遗忘前提下扩展知识与能力是关键。Huang 等人提出利用预训练语言模型为无标注问题生成高置信答案，从而在缺乏基准标签或明确指令时增强通用推理能力[257]。Scialom 等人则在多种任务上微调并引入基于反复练习的持续学习，在扩展知识与能力的同时规避灾难性遗忘[258-259]。

##### （1）知识编辑

部分研究在更新 LLM 新记忆上取得进展，用于替换过时信息或注入专业知识。例如提升“鲍里斯·约翰逊是英国首相”等过时预测，可增强可靠性和泛化性。已有多种定位与编辑参数化知识的方法$^{[263-267]}$。De Cao 等人提出超网络以更新 LLM 参数，仅修改单一事实，避免全面微调以防性能退化$^{[264]}$。后续研究发现随模型规模增大，基于超网络的编辑受限，进而提出检索式方法$^{[268-269]}$。另一些工作聚焦内部机制定位，通过注意力与因果干预识别驱动预测的神经元，成功更新领域事实$^{[263,266-267]}$。文献[265] 构建从文本查询到 LLM 内部事实编码的映射，将这些编码用作编辑器与探针。

##### （2）梯度掩码

梯度掩码是在微调中选择性更新 LLM 特定部分的策略。核心目标是降低计算开销、缓解灾难性遗忘或过拟合，特别在把预训练模型适配到小规模或专用数据时。通过在反向传播中施加掩码函数修改梯度，决定哪些部分被更新，从而冻结部分参数。参数选择可依据与任务的相关性、模型中重要性或对整体损失的贡献。

早期尝试$^{[248,270]}$ 使用正则化微调相对较小的模型，但不适用于 LLM，因有效训练所需数据与算力远高于小型模型，可能高出数个数量级。为迁移到 LLM，CHILD-TUNING$^{[271]}$ 利用下游任务数据探测与任务最相关的参数作为子网，并将非子网参数冻结于预训练权重。此外 Zhang 等人$^{[272]}$ 提出动态参数选择算法，根据反向传播梯度自适应挑选更有前景的子网分阶段更新，在低资源下更好完成领域下游任务。

##### （3）知识蒸馏

围绕 LLM 自我知识更新的研究多集中于任务特定指令与参数效率提升。一个方向是把 LLM 中的领域知识抽取到更小网络，以降低推理延迟并增强领域任务解决能力。Muhamed 等人把 15 亿参数 LLM 压缩为 7000 万参数模型用于点击率预测，引入孪生结构类 BERT 编码器与融合层，通过跨结构蒸馏从单一 LLM 提取知识，在线与离线环境均表现优异[273]。类似地，文献[274-276] 在 LLM 微调中加入蒸馏模块，实现更快收敛与更好资源利用。该模块借助预训练参数加速收敛，并训练少量参数缓解过参数化问题。此外文献[277-278] 把大模型中的思维链推理能力迁移到小模型。

#### 3. 现存挑战

用最新数据微调 LLM 以提供准确信息尤为重要，特别在技术、医疗、时事等快速变化领域。不同应用或用户也可能有独特需求与偏好。因此挑战包括：

- （1）**合规要求**：多数情况下更新与微调 LLM 为确保符合特定法规或指南所必需，所谓的 LLM 对齐可在微调阶段完成。
- （2）**算力资源**：微调或更新内部知识需要高性能 GPU 或专用硬件，对个人研究者或中小型组织而言成本高昂且难以获取。提升微调效率仍是现实且关键的问题。

## 2.8 思维链

传统大模型在“预训练+微调”范式下难以完成多步推理。2022 年 Jason Wei 提出的思维链提示 Chain-of-Thought Prompting，CoT Prompting[38,83] 能显著提升 LLM 性能，尤其在数学与推理等复杂任务上。具体体现为三点提升。

- （1）**常识推理赶超人类**。以往模型在众多挑战任务上不及人类，采用思维链提示后，LLM 在 BBH 评测基准 23 个任务中 17 个任务的表现超过人类基线。如 Sports Understanding 任务中，CoT 提示的模型常识推理性能为 95%，高于运动爱好者 84%。
- （2）**数学逻辑推理大幅提升**。语言模型在算术推理上表现平平，引入思维链后逻辑推理能力跃升。MultiArith 与 GSM8K 用于测试数学推理能力。PaLM 在采用思维链提示后较传统提示学习提升约 300%，在 MultiArith 与 GSM8K 上表现显著提高，甚至超过有监督学习最优结果。这意味着 LLM 也能处理需要精确分步计算的复杂数学问题。
- （3）LLM 更具可解释性，更加可信。超大规模无监督深度学习构建的 LLM 本质是黑盒，推理决策链不可知，导致结果难以信任。思维链把逻辑推理问题拆解为多步，生成结果拥有更清晰的逻辑链条，具有一定可解释性，使用者能追溯答案来源。Jason Wei 提出的思维链是 LLM 惊艳世界的必要条件。

尽管实证成功显著，思维链背后的机制及如何释放 LLM 潜力仍不为所知。本节介绍思维链的技术细节，以及具备思维链的 LLM 在基础数学与决策问题上的能力。

### 2.8.1 思维链的技术细节

其一，先前研究不仅让模型从零开始生成自然语言中间步骤[279]，也通过微调预训练模型实现这一目标[44]。此外还有神经符号方法，使用形式语言而非自然语言[280-282]。其二，LLM 通过提示具备上下文少量示范学习能力。也就是说，不必为每个新任务单独微调语言模型，而是用若干输入输出示例提示模型进行学习。令人惊讶的是，这在一些简单问答任务上取得成功[14]。

上述思路存在局限。对加入自然语言解释的训练与微调而言，制作大量高质量解释是一项复杂工作，远比普通的输入输出对困难。文献[14] 的传统少量示范提示在需要推理能力的任务上表现不佳，且不随模型规模增大而改善[20]。思维链可以规避这些限制。具体来说，思维链探索了 LLM 在推理任务上进行少量示范提示的能力，给定提示由三元组组成：输入、思维链、输出。思维链是自然语言推理步骤序列，本文称之为思维链提示，示例见图 2.13。纯提示方法之所以重要，是因为它无需大规模训练集，且单一模型检查点可执行多任务而不损失通用性。思维链关注 LLM 如何借助少量任务相关自然语言示例进行学习，而非通过海量训练数据的自动模式学习。

以复杂推理任务为例，如多步数学应用题。通常会把问题分解为多个中间步骤，逐步求解后再给出最终答案。思维链的目标是赋予语言模型生成思维链的能力——一系列连贯的中间推理步骤，据此可推导出最终答案。若在少量示例提示中提供思维链推理演示，足够大的语言模型即可生成这类链条。

思维链提示在促进推理方面具有以下特点。

- （1）思维链原则上允许模型把多步问题拆分为中间步骤，意味着可为需要更多推理步骤的问题分配额外计算。
- （2）思维链为模型行为提供可解释性窗口，提示其如何得出特定答案，并提供调试推理路径的机会。
- （3）思维链推理可用于数学问题、常识推理与符号操作，理论上适用于任何人类可通过语言解决的任务。
- （4）通过在少量示例提示中加入思维链序列示例，可在足够大的 LLM 中轻松得到思维链。

### 2.8.2 基于自洽性的思维链

本节介绍一种新解码策略——自洽性 Self-consistency，用来替代思维链提示[83] 中使用的贪婪解码。它先对不同推理路径进行多样性采样，而非仅走贪婪路径，再对采样得到的推理路径进行边缘化，选择最一致的答案。自洽性利用了复杂推理问题常可通过多种不同思路得到唯一正确答案的直觉。大量实证评估显示，自洽性显著提升 CoT 提示在算术与常识推理基准上的表现，包括 GSM8K 提升 17.9%、SVAMP 提升 11.0%、AQuA 提升 12.2%、StrategyQA 提升 6.4% 和 ARC-challenge 提升 3.9%。

尽管语言模型在多种 NLP 任务中展现强能力，但在推理上尚未充分发挥[20]。为此 Wei 等人[83] 提出思维链提示方法，要求语言模型生成一系列短句，模仿人类解题时的推理过程。例如对“停车场已有 3 辆车，又来 2 辆，现在有多少辆”，模型不会直接答“5”，而是分析：“停车场已有 3 辆，又来 2 辆。现在有 3+2=5 辆。答案是 5。”观察发现，思维链提示在多步推理任务中显著提升性能[83]。

自洽性利用复杂推理任务存在多种正确推理路径的特性，即回答问题需要深思熟虑与分析，才能基于多样推理路径得到答案。图 2.14 用示例说明自洽性方法。首先用思维链提示引导语言模型，然后采样生成多样推理路径，最后对采样路径进行边缘化，先从解码器采样生成一组多样推理路径。每个路径可能产生不同答案，最终通过边缘化采样路径确定最优答案。该思路类似人类经验，若多种不同思考方式都得出相同答案，人们对最终答案正确性更有信心。相较其他解码方法，自洽性避免了贪婪解码的重复性与局部最优问题，同时缓解了单次采样的随机性。

以往方法要么训练额外验证器，要么基于人工标注训练重排序模型以提升生成质量。自洽性则是无监督的，即插即用在预训练语言模型上，无需额外人工标注，也避免额外训练、辅助模型或微调。与典型集成方法不同，后者需训练多个模型并聚合输出，自洽性更像“自我集成”，在单一语言模型上工作。

#### 不同推理路径下的自洽性

人类显著特点是思考方式多样。在需要深思熟虑的任务中，存在几种不同解题方法很自然，语言模型可通过从解码器采样来模拟这一过程。语言模型并非完美推理者，可能产生错误推理路径或在步骤中犯错，这些路径很少得出相同答案。

自洽性方法大致如下。首先，用一组手工编写的连续思维示例[83] 提示语言模型。接下来，从解码器采样候选输出，生成多样化的候选推理路径。自洽性与多数现有采样算法兼容，包括温度采样、前 k 个最高采样与核采样。最后，对采样推理路径进行边缘化，聚合答案并选择生成答案中最一致者。
