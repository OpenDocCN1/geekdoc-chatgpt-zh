在多卡 GPU 或多核 TPU 环境下，该组件可让模型调度更顺手，并提供自动混合精度选项，在提升吞吐的同时压缩显存占用。Accelerate 与 Transformers 的协作非常顺滑，为扩容训练任务提供无缝衔接。

- 3. tiktoken
tiktoken 是基于 Python 的开源词元化组件，其核心采用 BPE 字节对编码。与市面上同类工具相比，它的执行效率得到专门优化，速度更有优势。该模块为 NLP 任务提供了高效且可灵活定制的文本编码手段。

- 4. einops
einops 提供了操作张量的简洁表达方式。利用它可以方便地重排、变形并融合高维数组，比如 PyTorch 张量，这对神经网络的输入输出处理很实用。结合 Transformers 使用时，能显著简化数据预处理与后处理流程。

- 5. SciPy
SciPy 是面向科学计算的 Python 库，涵盖统计、优化、线性代数、数值积分等众多高级算法。在 NLP 任务里，可借助它完成数据清洗、特征工程以及部分数值计算。

- 6. transformers_stream_generator
transformers_stream_generator 是一个版本为 0.0.4 的轻量工具，专门用于实现文本流式生成。推测其与 Transformers 生态相关，推理时能够逐 token 实时输出，适合对交互时效性要求高或需逐步处理长文档的场景。

- 7. PEFT
PEFT 的全称是 Parameter-Efficient Fine-Tuning，即参数高效微调。其思想是让预训练模型适配下游任务时，无需更新全部参数。通过 PEFT，可在有限算力与存储条件下，把大模型调整到特定任务上。

# 第 9 章 LLM 与 LoRA 微调策略解读

在当前 AI 快速演进的背景下，LLM 已成为语言理解、文本生成等任务的核心。让模型在特定领域表现更好通常需要微调。微调能依据任务需求调整预训练参数，提升性能与泛化。然而传统全量微调计算开销巨大。LoRA 以低成本高效的方式解决这一问题，在保持效果的同时大幅降低算力需求，为研究与工程提供了更实用的微调路径。

## 9.1 LoRA 技术

### 9.1.1 LoRA 简介
LoRA 是目前流行的一种高效微调方案。与全量微调不同，它仅更新少量低秩矩阵。

LoRA 与常见微调策略相比，具有以下优势。

- 计算效率高：通过低秩分解降低参数更新开销，提升微调速度。
- 减少内存占用：只需存储少量可训练参数，推理时额外负担有限。
- 灵活性强：可适配多种模型结构与任务，提供通用优化思路。

全参数微调、Adapter、P-Tuning 和 Prefix 等方法虽能实现微调，但在效率与灵活性上存在局限，故在 LLM 场景下 LoRA 往往是更优选择。

表 9-1 所示为几种微调策略的对比。

| 微调策略 | 优点 | 缺点 | 原理 |
| :--- | :--- | :--- | :--- |
| 全参数微调 | 实现门槛低，可适配任意任务，无额外参数限制 | 计算与时间成本高，尤其在大模型上易过拟合 | 更新预训练模型全部参数与偏置 |
| Adapter | 参数量少，节省内存与计算，可在不同层插入，灵活性高 | 需调优适配器位置与数量，偶会影响性能 | 在预训练模型部分层上微调，其余层冻结 |
| P-Tuning | 多任务间可共享参数，提升复用性，可调节共享程度平衡关系 | 需精细调参确定共享方式，易出现任务干扰 | 通过参数共享提升泛化与效率 |
| Prefix | 添加特定前缀可改变模型行为，适配性强，可针对任务设计前缀 | 需额外设计工作，前缀设计影响效果 | 在输入中加入前缀控制模型行为 |
| LoRA | 利用低秩分解减少参数与内存，降低成本，保持原结构仅更新 LoRA 权重，避免过拟合 | 仅更新部分参数，可能在某些能力上略有下降，如数学计算 | 适用于资源受限的 LLM 微调，保持整体结构可用于文本生成、分类等 |

### 9.1.2 LoRA 工作原理
LoRA 基于低秩矩阵思想，通过将权重更新近似为低秩形式实现微调。具体而言，传统微调会计算完整的权重更新矩阵 ΔW，而 LoRA 将其分解为两个小矩阵 W_A 与 W_B 的乘积，即 ΔW ≈ W_A × W_B。

该分解简化了更新流程并显著降低计算成本。实践中可将 ΔW 分解为低秩矩阵 W_A 与 W_B，并表示为 W' = W + W_A × W_B。只需学习这两个小矩阵，无需更新整个模型。图 9-1 示意了传统微调与 LoRA 在前向传递中权重更新的差异。
