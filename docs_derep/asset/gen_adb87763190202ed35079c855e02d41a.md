head = newNode;

C.

newNode->data = 42;

D.

newNode->data = 42;

**【考点识别】**

入门级|2.11 指针类型|【4】指针、【4】基于指针的数组访问、【4】字符指针、【4】指向结构体的指针

入门级|3.1 线性表|【3】链表：单链表、双向链表、循环链表

**【分析讲解】**

题目核心是在单链表前端新增一个节点，让它成为新的表头。下面对四个写法做拆解：

选项 A：

Node* newNode = new Node;

newNode->data = 42;

newNode->next = head;

head = newNode;

解读：

先为 newNode 申请空间。

把数据域写入 42。

让新节点的 next 指向原表头。

最后把 head 挪到 newNode。

完整实现了头插，逻辑正确。

结果：正确

选项 B：

Node* newNode = new Node;

head->data = 42;

newNode->next = head;

head = newNode;

解读：

把原头节点的数据改成了 42，原链表信息被破坏。

newNode 自身的 data 从未赋值。

指针移动看似合理，整体却混乱，无法完成预期插入。

结果：错误

选项 C：

Node* newNode = new Node;

newNode->data = 42;

head->next = newNode;

解读：

新节点创建并赋值完成。

但把 head->next 改成 newNode，等同于把新节点挂在原头之后，并非置顶。

与题意不符。

结果：错误

选项 D：

Node* newNode = new Node;

newNode->data = 42;

newNode->next = head;

解读：

新节点的数据和指针都准备好了。

head 指针却没有更新，链表入口仍指向旧节点，新节点被孤立。

结果：错误

**【参考答案】**

A.

Node* newNode = new Node;

newNode->data = 42;

newNode->next = head;

head = newNode;

**【编程魔法师讲解考点】**

**一、链表的基本结构**

链表由节点链成，每个节点包含：

数据域 data，用来存值。

指针域 next，用来连向下一个节点。

示意：[Node1|next] -> [Node2|next] -> [Node3|null]

首个节点即 head，是进入整条链表的入口。

**二、头插的通用流程**

1. 用 new 为新节点开辟内存。
2. 填入新节点的数据域。
3. 将新节点的 next 指向当前 head。
4. 把 head 重新指向新节点。

示例：

Node* newNode = new Node;  // 开辟
newNode->data = 42;        // 赋值
newNode->next = head;      // 衔接旧表
head = newNode;            // 更新入口

**三、指针操作的常见坑**

指针是链表的粘合剂，操作失误就会断链。

典型失误：

1. 未把 head 更新，新节点游离在外。
2. 直接修改旧节点数据，让原结构受损。
3. 忘记 new 分配内存。

**【题目总结】**

链表头插是信奥入门高频点，要抓住：

1. 理解节点构成与指针连通作用。
2. 牢记头插四步顺序。
3. 注意指针更新时机与顺序。

9. 后缀表达式 6 2 3 +- 3 8 2 / + * 2 ^ 3 +对应的中缀表达式是（ ）。

A. ((6-(2+3))*((3+8/2))²)+3

C. (6-(2+3))*((3+8/2)²)+3
D. 6-((2+3)*(3+8/2))²+3

**【考点识别】**

入门级|6.数据结构|6.2 栈|

【1】表达式的后缀（逆波兰）表示法。
