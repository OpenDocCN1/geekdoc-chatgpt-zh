打开图表编辑页，最先要处理的是数据准备环节。平台提供的每个模板都自带演示数据，若要使用自己的资料，只需点按“上传数据”即可完成替换。

第三步：文案设定。
数据准备完成后进入文字设定阶段。可调整的文本包括图表主标题、横纵坐标单位说明、图表注释等。文案确认后，还可顺势配置背景音乐、背景色以及视频总时长，具体界面见图 8-54。

[PRE1]

图 8-54

第四步：生成视频。
全部配置结束后即可发起生成。视频处理需要一定时间，期间可在页面顶部右侧导航的“任务中心”查询进度。
第五步：下载视频。
视频处理完毕后，用户可在“创作中心——我的作品”中下载或转存成品。

**3. 图片创作**
一念的图片创作功能建立在百度的AI技术之上，通过输入文字描述或选择风格、主题即可生成符合需求的图像。该能力利用了百度在深度学习、计算机视觉等方向的积累，能够依据用户需求快速产出高质量图像内容，为设计师、艺术家等提供更便捷的创作工具，同时也能结合企业的营销、宣传等业务，帮助企业快速生成符合需求的图像内容，提升工作效率和创意质量。

（1）文生图
第一步：在工作台中选择 AI 作画卡片进入对应页面。
第二步：输入 Prompt 语句，可选择自定义输入创意描述，也可以单击示例图片中的“创作相似”按钮，自动填入优质 Prompt 语句，见图 8-55。

[PRE2]

图 8-55

第三步：风格选择。
选择“智能推荐”，一念将根据 Prompt 语句自动生成较为适合的图片。若要尝试更多风格，可以单击“更多风格”按钮展开所有风格，然后选择需要的风格；也可以选择在“创意描述”输入框中输入自定义风格，见图 8-56。

[PRE3]

图 8-56

第四步：选择尺寸与分辨率。
AI 作画当前支持 3 种尺寸，每种尺寸下有 3 种清晰度/分辨率，在左侧选择尺寸后，可以在右侧下拉框中选择分辨率，见图 8-57。

[PRE4]

图 8-57

第五步：选择生成图片的数量。AI 作画支持批量生成图片，用户可以选择生成 1~8 张图片，单击“一键生成”按钮，等待 7~15 秒，一念即可生成好看的图片，用户可通过右下角的 3 个按钮对图片进行管理，见图 8-58。
