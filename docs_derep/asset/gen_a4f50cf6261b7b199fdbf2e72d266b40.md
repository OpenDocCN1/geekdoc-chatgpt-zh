(3) Extreme-Denoising，即 X-Denoising：该思路[60]是在 Regular-Denoising 的基础上，把掩码单元从单个 token 扩展为整句，训练时要求模型恢复被遮住的每一句话。这一方式在多语言大模型预训练中常被用于多轮对话任务。实际落地来看，Llama 2 仅采用了第二种训练策略，Llama2-Chat[61]同时使用了第二种与第三种策略，而 Google 的 PaLM 2 把三种策略全部应用，并在每条输入前加注 R-S-E 标记来指示具体的训练目标[62]。

#### 2. 多语言大模型架构

目前主流的多语言大模型几乎都以 Transformer[63]为基础[64]，核心由编码器和解码器构成。从组合方式看，大致可分为编码器单独使用、编码器-解码器串联、解码器单独使用三种形态。如今真正落地的多为解码器、编码器-解码器以及前缀语言模型 Prefix LM 三类。BERT 早期采用的是编码器方案，如今纯编码器单独使用的情况已很少见。

- 解码器架构
如图7-13所示的解码器架构是当前多语言大模型的主流选择，它让模型能够像传统的自回归语言模型那样训练，即借助单向注意力实现下一个词预测 NTP。Llama 2、GPT 系列、BLOOM、XGLM 等都采用了这一架构。近期的研究尝试在解码器模型上做去解码器预训练[65]或指令微调[66]，在效果上有所提升，但这些工作大多基于以英语为主的模型，多语言场景下的表现仍不清晰。PaLM 2 的报告里采用了类似做法并在多语言任务上取得优秀成绩，因此可作为多语言大模型优化的一个参考方向。

## 7.4 多语言大模型的工业应用

生成式 AI 大模型的出现，让人与机器能以自然语言为指令交互，并借助各类 API 获取所需答案，正在重塑诸多产业与工业场景。本节重点介绍几类必须借助多语言大模型交互的典型工业应用，说明它们如何以多语言能力提升用户体验并提高运营效率。

### 7.4.1 智能客服
在工业落地中，最典型的就是智能客服。多轮对话能力让客服机器人能更自然地处理用户的售前与售后问题，提升企业服务效率。模型还能识别用户情绪，对不同用户进行安抚或升级上报，从而提高满意度并降低公关风险。

面向售前问题，智能客服更像导购机器人，会通过反问收集用户诉求，再推荐可能感兴趣的产品以提升转化。近期东南亚电商平台 Lazada 与 Shopify 分别基于 OpenAI 的 ChatGPT 推出了 LazzieChat 机器人和 Shopify 机器人，如图7-20所示，它们可依据用户需求进行产品推荐，LazzieChat 主要支持英语和印尼语，Shopify 机器人支持汉语及更多欧洲语言。

### 7.4.2 多语言机器翻译
多语言机器翻译是另一项重要工业用途，可将一种语言转译为另一种语言，打破语言壁垒，促进全球交流。随着多语言大模型发展，翻译的准确性与流畅度显著提升。例如 Google 翻译、Microsoft 翻译等工具均已采用多语言大模型技术。

### 7.4.3 多语言问答系统
多语言问答系统可在多语言间实现查询与应答，提升跨语言信息获取效率。这类系统通常以多语言大模型为后端，以便更好地理解并生成不同语言的答案。

### 7.4.4 多语言语音识别
多语言语音识别可把不同语言的语音转为文本，实现跨语言语音交互。该技术在智能客服、多语言翻译等领域应用广泛。

### 7.4.5 多语言文本摘要
多语言文本摘要可从不同语言文本中抽取关键信息，生成简洁准确的摘要，对信息检索、新闻摘要等领域意义重大。

### 7.4.6 多语言情感分析
多语言情感分析可解析不同语言文本的情感倾向，帮助企业和组织了解用户对产品、服务或品牌的看法，对市场调研、客户服务等领域具有重要价值。

### 7.4.7 多语言对话系统
多语言对话系统可实现跨语言的自然语言交互，为用户提供便捷的跨语言服务。这类系统通常以多语言大模型为核心技术，以实现不同语言间的理解与生成。

随着多语言大模型技术不断演进，其在工业应用中的渗透将越来越广，为各行各业带来更多创新与机遇。
