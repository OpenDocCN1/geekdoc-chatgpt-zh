提示词之所以能发挥作用，底座是大语言模型的上下文学习能力。提示工程研究的正是如何撰写提示词，让模型在推理、事实契合度等方面表现更佳。研究显示，面对陌生的任务，模型只需要用文字说明任务或给上极少数示例就能完成，不必像传统模型那样从头再训，这揭示了模型规模提升后出现的新训练范式。

提示工程的探索很早便已启动，近年来随模型能力跃升而加速发展。其中两项关键成果——思维链与工具调用，已被整合进 ChatGPT，整体能力再上一个台阶。

## **4.1**

## **思维链**

我有十个球。我给了小明四个球。小红给了我五颗糖。我现在有几个球？

把这个脑筋急转弯同时交给 ChatGPT 和前代模型对比：

**ChatGPT：**你现在有六个球。
刚开始你有十个球，给了小明四个后剩六个。随后小红给你五颗糖，和球数无关，所以仍是六个。

**GPT-3：**十一个球。

ChatGPT 给出了正确结论并附带推理过程，GPT-3 只给出错误答案。两者差距就在于推理展开。人遇到这题也容易把糖当球算进去，但花三四秒梳理一下就能得出正确答案。

对人需要推理的问题，模型同样需要推理。思维链的概念源于 2020 年 Jason Wei 等人的工作，核心是把推理过程提供给模型，从而大幅提升答案准确性。从问题到推理再到答案的链式展开，就是思维链，如图所示。

[PRE0]

图 4.1 思维链

若每个问题都靠人工提供推理，效率太低。研究人员发现，问对问题，模型自身就能进入推理状态。Kojima 等人提出零样本思维链，即借助语言生成能力，让模型自行产出推理步骤来构造思维链。

零样本思维链在多个基准上表现突出。工程实践里试过不少说法，诸如能促思考的“Let’s think step by step”“The answer is after the proof”，会干扰的“Let’s count the number of ‘a’ in the question”，以及“It's a beautiful day”这类问不出答案的说法。多轮测试后，“Let’s think step by step”提升最明显，也被戏称为咒语。

从更宏观的视角看，思维链本质是把复杂问题拆成若干子问题，先生成推理再据此求解，这正是计算机科学里的分治思想。由此思维链不必局限于“一题一推理”，可以扩展为更长更复杂的链来解决更难的推理。

程序辅助语言模型 PAL 是思维链的一种延伸，它在链中插入程序并执行程序得到最终结果，如图所示。

[PRE1]

图 4.2 程序辅助语言模型

思维链为何有效，目前仍不完全清晰，但已有初步线索。思维链可能并非教会模型推理，而是通过限定输出格式，激活模型参数中潜藏的推理能力。Wang 等人的实验显示，即使输入错误推理，模型答题能力仍能提升 80%～90%。例如：

莉莉有 32 块巧克力，她姐姐有 42 块，她们一共吃了 35 块，还剩多少？

正确第一步是 32 与 42 相加。若刻意告诉模型“姐姐有 42-32=10 块”，结果与正确推理的差距并不大。

不过并非所有错误推理都有效。Wang 等人总结，推理的连贯性与相关性至关重要，且相关性更重要。

连贯性指推理顺序合理，从条件逐步推向结论，不能颠倒。例如：

问：Jason 原本有 20 个棒棒糖，给了 Denny 一些后剩 12 个，给了多少？
答：答案是 8。因为给了 Denny，所以剩下 20-12=8。Jason 原来有 12 个，所以给了 20-12=8 个。

答案先于条件出现，缺乏连贯性。

相关性指必须使用题目给出的信息。例如：

问：Shawn 有 5 个玩具，圣诞节从妈妈和爸爸各得到 2 个，现在几个？
答：Shawn 最开始有 8 个玩具。然后从妈妈和爸爸各得到 6 个，所以得到 12 个。现在有 20 个。答案是 20。

这里把 5 改写成 8 并编造数据，相关性缺失。

Wei 等人还指出，思维链是一种模型规模达到阈值后才显现的能力。

OpenAI 会在消息里向 ChatGPT 注入插件的简略描述，包含描述、端点和示例，对用户不可见。用户提问相关时，模型可能选择调用对应插件的 API；POST 请求需开发者构建用户确认流程。模型会把 API 结果合并到回复中，必要时以富预览形式展示链接。

也就是说，只要让模型阅读插件描述，它就明白如何调用。这正是提示工程在模型与工具集成上的成果。其思路是根据用户请求，让模型生成含任务调度提示的描述，并据此调用其他工具。

**1.MRKL 系统**

最早的相关工作之一是 MRKL 系统，即模块化推理、知识与语言。该系统让大语言模型处理一句话并判断哪些部分可由外部接口解答。

用户提问：哪家绿色能源公司上个月股价涨得最高？
模型判断需调用的 API：绿色能源公司需查 Wiki，股价涨幅需查股价库并调用计算器，上个月需查日历。

调用后生成答案：上个月 Windenergy 和 Tinenergy 涨幅最高，股价上涨超过 12%。

**2.Toolformer 系统**

2023 年初发布的 Toolformer 能让模型输出带特定标记的内容，由外部工具按标记返回结果供模型使用。API 如同程序间的电话线，Toolformer 规定了通信契约。例如：

Out of 1400 participants, 400（or［Calculator（400/1400）→0.29］29%）passed the test.

方括号内的 Calculator 表示调用计算器。

Toolformer 未手工标注语料，而是用模型自行标记语料中可调用 API 的位置来构建训练集。构建问答 API 调用数据集的提示例如：

你的任务是在一段文本中添加对问答 API 的调用。这些问题应帮助获取完成文本所需信息。你可以通过写“［QA（问题）］”来调用 API……

**3.TaskMartrix 系统**

2023 年 3 月微软发布的 TaskMatrix 系统与 Toolformer 类似，但规模更大，可调用数百万个 API，系统更完整。完成任务后会通过强化学习微调模型，并把结果反馈给 API 开发者。

**4.HuggingGPT 系统**

微软与浙江大学合作的 HuggingGPT，主要功能是通过 ChatGPT 调用其他深度学习模型，例如用视觉模型处理图像问题。名字来源于这些模型多发布在 Hugging Face，论文题目为《通过 ChatGPT 和它在 Hugging Face 上的小伙伴完成 AI 任务》。

用户询问：“你能描述这张图片，并算出有多少个物体吗？”
模型执行步骤：
（1）ChatGPT 规划任务，需要物体计数模型和图像描述模型；
（2）挑选合适的 Hugging Face 模型，如 detr-resnet-101 计数，vit-gpt2-image-captioning 描述；
（3）执行任务；
（4）据模型输出生成回答。

ChatGPT 调用了图像识别与描述模型来生成最终答案。

在 Vicsek 模型中，一群带位置和方向的粒子在二维空间运动，每个粒子会尝试与邻居保持一致方向，同时受随机扰动影响。调噪声强度可观察不同程度的自组织。

噪声小时，粒子自发形成有序群体，朝大致相同方向运动，类似鸟群、鱼群等生物群体行为。噪声大时，随机扰动增强，自组织现象减弱甚至消失，说明自组织需要在特定条件下发生。

（1）直接给出网页模拟 Vicsek 模型的需求；
（2）把参数做成可控制滑块；
（3）尝试调整粒子样式，如箭头和鱼；
（4）优化控制面板体验；
（5）修正动力学问题，包括相互作用强时粒子方向被限制在 x 轴，以及大部分时候粒子都向下走。
