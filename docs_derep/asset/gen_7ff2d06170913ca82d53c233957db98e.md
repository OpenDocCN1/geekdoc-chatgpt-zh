#### 7.2.3 ReAct Agent 的实践

得益于其推理与行动一体化的设计，ReAct 已成为当前最主流的 Agent 实现范式。核心思想是把大语言模型当作推理大脑，ReAct 在思考的同时直接触发动作。一旦收到用户指令，模型会先挑选合适的工具。

工具执行完毕后，Agent 会捕捉执行结果并原样回传给模型用于下一步推理。
