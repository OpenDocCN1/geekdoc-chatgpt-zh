位运算 ^ 与 ~ 的核心用法
异或 ^ 按位比较，位不同置 1，位相同置 0。例如 5 ^ 3，101 按位与 011 得到 110，二进制 110 对应十进制 6。
按位取反 ~ 把全部二进制位翻转，在补码体系下结果随位数变化，并非恒定值，比如 ~5 的具体数值取决于所用的字长。

C++ 运算符优先级与结合方向
在 C++ 中优先级从高到低，位运算 & | ^ 的优先级高于逻辑与 &&，再高于逻辑或 ||。
位运算和逻辑运算的结合方式均为从左向右。

表达式编写的实用建议
按位运算优先于逻辑运算是易踩坑点。
布尔判断里，非零视为真，零视为假，可隐式转换。

15. 下列代码计算 x^n，其时间复杂度为（）
double quick_power(double x, unsigned n) {
    if (n == 0) return 1;
    if (n == 1) return x;
    return quick_power(x, n / 2) * quick_power(x, n / 2) * ((n & 1) ? x : 1);
}

A. O(n)
B. O(1)
C. O(log n)
D. O(n log n)

【考点识别】
提高级|4.3 基础算法|【6】分治算法
|4.1 复杂度分析|【6】时间复杂度分析

【分析讲解】
一、逻辑
终止条件 n=0 返回 1，n=1 返回 x。
递归部分调用两次 quick_power(x, n/2) 并相乘，奇数时再乘 x。
二、递归树
每次规模减半，深度为 log n。
每层产生两倍调用，节点总数约 2^{log n}=n。
三、结论
总调用次数与 n 成正比，复杂度为 O(n)。

【参考答案】
A. O(n)

【编程魔法师讲解考点】
一、快速幂思想
利用指数二进制分解，把乘法次数从 O(n) 降到 O(log n)。
a^n = a^{n/2}·a^{n/2}，奇数时再乘 a。
标准实现递归深度 O(log n)，每次一次乘法，总复杂度 O(log n)。
二、注意本题实现问题
代码中递归调用了两次相同子问题，导致重复计算，复杂度退化为 O(n)。正确快速幂应只调用一次并复用结果。

【题目总结】
分治可大幅降低复杂度，但重复子问题会导致性能下降，需避免冗余调用。
