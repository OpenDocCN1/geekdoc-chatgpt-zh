#### 4. 流程搭建

1. graph.add_edge(START, "llm_call")
2. graph.add_conditional_edges("llm_call", enter_process)
3. graph.add_edge("process_node", "llm_call")

第1句规定流程从 llm_call 节点启动，系统先调用 LLM 根据用户问题生成响应。

第2句把 llm_call 的输出交给 enter_process 判断：如果 state["output"] 有值，即模型直接给出最终答案，则返回 END 终止；如果 state["output"] 为空，即模型生成了代码动作，则返回 "process_node" 进入工具执行。

第3句建立工具执行节点到对话节点的回环边。代码执行完毕后，结果以 HumanMessage 形式写入对话历史，工作流自动回到 llm_call，模型在包含执行结果的新上下文下继续推理——可能修正错误、解释结果或产出最终答案。
