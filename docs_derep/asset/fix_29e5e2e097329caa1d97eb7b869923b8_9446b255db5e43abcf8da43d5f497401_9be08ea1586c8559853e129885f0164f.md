用双向循环给中文句子打好坏标签

在 ChnSentiCorp 上演示一个极简的字符级情感二分类。文件里每行以逗号分隔，第一列是极性，后面所有列拼接成一句。极性保留为 0 与 1 即可直接喂给交叉熵。把整份语料里出现过的汉字收集起来，按顺序排序后映射成整数 id，序列统一剪到八十个位置，短的用 0 补齐，这样得到固定长度的输入。

预处理完成后就可以送入网络。先用 312 维词向量表把 id 转成稠密表示，经过一个单向 GRU 把序列压缩到 256 维，中间加一层归一化稳定训练，再进入双向 GRU，隐状态 128。双向结构让每个时间步同时利用前后上下文，最后保留完整的序列输出供下游分类。

class RNNModel(torch.nn.Module):

    def __init__(self,vocab_size = 128):

        super().__init__()

        self.embedding_table = torch.nn.Embedding(vocab_size,embedding_dim=312)

        self.gru = torch.nn.GRU(312,256) # 注意这里输出有两个，分别是out与hidden，out是序列在模型运行后全部隐藏层的状态，而hidden是最后一个隐藏层的状态

        self.batch_norm = torch.nn.LayerNorm(256,256)

        self.gru2 = torch.nn.GRU(256,128,bidirectional=True) # 注意这里输出有两个，分别是out与hidden，out是序列在模型运行后全部隐藏层的状态，而hidden是最后一个隐藏层的状态

    def forward(self,token):

        token_inputs = token

        embedding = self.embedding_table(token_inputs)

        gru_out,_ = self.gru(embedding)

        embedding = self.batch_norm(gru_out)

        out,hidden = self.gru2(embedding)

        return out
在循环体上再接展平与线性映射。双向后每步维度翻倍，整段序列展平成向量再映射到两个类别，完成二分类。

训练流程在预处理上增加了划分。固定随机种子打乱数据与标签，前 170 条留作验证，其余用于训练。模型放到 GPU 并开启编译加速，优化器选用 Adam，学习率 2e-4，批量 128，迭代 21 轮。每轮输出训练阶段的平均损失与准确率，并在验证集上打印准确率。

import torch

class RNNModel(torch.nn.Module):

    def __init__(self,vocab_size = 128):

        super().__init__()

        self.embedding_table = torch.nn.Embedding(vocab_size,embedding_dim=312)

        self.gru = torch.nn.GRU(312,256)    # 注意这里输出有两个，分别是out与hidden，out是序列在模型运行后全部隐藏层的状态，而hidden是最后一个隐藏层的状态

        self.batch_norm = torch.nn.LayerNorm(256,256)

        self.gru2 = torch.nn.GRU(256,128,bidirectional=True) # 注意这里输出有两个，分别是out与hidden，out是序列在模型运行后全部隐藏层的状态，而hidden是最后一个隐藏层的状态

    def forward(self,token):

        token_inputs = token

        embedding = self.embedding_table(token_inputs)

        gru_out,_ = self.gru(embedding)

        embedding = self.batch_norm(gru_out)

        out,hidden = self.gru2(embedding)

        return out

#这里使用顺序模型建立训练模型

def get_model(vocab_size = len(vocab_list),max_length = max_length):

    model = torch.nn.Sequential(

        RNNModel(vocab_size),

        torch.nn.Flatten(),

        torch.nn.Linear(2 * max_length * 128,2)

    )

    return model
