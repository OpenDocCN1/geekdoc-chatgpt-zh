机器学习从学习范式切分，常见的说法是无监督学习、监督学习与强化学习三种路线¹¹³。换个观察维度，按用途再划分，则会出现判别模型学习和生成模型学习两大阵营。判别模型的核心动作是挖掘不同类别数据间的隐含差别，常用于分类、决策与预测等场景，例如用户画像、广告投放、文字识别、人机对弈等，稍后要实操的垃圾邮件判别模型就是典型代表。生成模型则起步较晚，真正进入大众视野是在2014年以后，属于后起之秀¹¹⁴。

再从模型是否能被人类读懂的角度切入。可解释性决定我们是要深挖运行机理，还是只要建立特征与现象之间的关联即可。这一演进路径与人工智能从规则探索走向仿生模拟的历史相呼应。早期以规则、树结构或线性回归为主的白盒可解释学习占主流；随着符号主义式微，研究重心逐步转向以神经网络、概率统计为代表的黑盒不可解释学习。作者把上述三种划分涉及的方法整理成了图示。

### 6.5 机器学习解决的问题

本节先用一个依赖数据统计做判断的日常故事开场，生活里的统计直觉也是计算机模拟世界的方式之一。

朋友小黄最近为女友的约会迟到困扰。有一次约好下午三点在某地会合后去朋友家吃饭，出门前他犹豫：现在出发是否合适，会不会到了现场仍要空等半小时甚至更久。小黄在脑中列了几种应对思路。

最稳妥的做法是无论对方何时出现，自己准时抵达，安全却太迁就问题。第二种思路是寻找现成的知识规则，可惜“如何与女友约会”从未被系统化成可用的经验。第三种思路是做统计权衡：回溯过往约会，统计迟到比例与迟到时的情境特征，再以此估算本次迟到的概率，超过个人容忍线就晚点出门。

整理后，小黄盘点最近20次约会，迟到约占一半。其中有8次迟到是因为约会有第三方在场，需要额外化妆时间；其余10次准时与2次迟到则发生在只有两人时。这次聚餐会有人同行，按历史情境统计，类似情况下迟到8次、准时2次，迟到概率高达80%，已超出容忍阈值，于是他决定推迟出发。利用过去经验的数据来预判未发生事件并调整行为，正是基于统计的机器学习在生活中的体现。

小黄第二种思路追求规律与知识，对应机器学习里的推理；第三种思路依赖经验数据，对应统计。第3章提到人类认知世界的基本手段是演绎与归纳，工具决定可解问题范围。机器学习能触及的问题边界，也由其掌握的手段决定。演绎是从一般规律推出个例，归纳是从个例归纳出一般规律。以“可推理”“可统计”为坐标轴，人类全部问题可落到如图6-2的四个区域¹¹⁶

有些知识能被统计，有些不能；有些能被证明与推理，有些不能。横向来看，理论上所有可推理的问题都可用逻辑演绎、符号与规则让机器完成推理。纵向来看，所有可统计的问题都可借助大数据与统计手段得到足够精度的模型，用模拟方式解决问题。

在此坐标里，知识或问题被分为四类，如图6-3所示，分别是“可统计也可推理——现象与规律皆知”“不可统计却可推理——规律已知却无法观察到现象”“可统计却不可推理——现象可观察但规律难总结”“不可统计也不可推理——现象未知且规律无法归纳”。

[PRE2]

图 6-3　人类知识的划分(2)

• 第一类既可推理又可统计，原则上都能找到答案。
• 第二类知道规律却难以观察到现象，例如数学定理、天体运行定律。以地球现今位置、角度、速度、质量为前提，完全能精确推算千年后的位置。这类问题计算机擅长执行运算，但自主发现与证明规律仍很初级，解决思路是人先发现规律再让机器执行，属于符号主义探索的方向。
• 第三类能观察到现象却难总结规律。不知道规律，但可基于已知现象的统计推测未知现象。小黄预测女友是否迟到、天气预报都属此类。气象系统受混沌理论制约，很难靠严格推理获得满意结果，却能用长期记录的特征进行有效预测。该象限是统计学习的主战场，也是机器学习备受关注的原因。
• 第四类既无规律可知，也无特征可统计。如无人为干预的彩票开奖，若属真正随机，则即便提供全部历史数据或研究摇奖过程，对中奖预测也无帮助。这类问题目前只能靠人类顿悟，机器暂时难以触及。

另外，四象限的边界并非一成不变。所谓不可推理，多为难度极大或变量太多；所谓无规律，多为样本不足或观测尺度不当。真正完全不可推理、不可统计的问题在现实中很少。机器学习能做的事也不会固定不变，会随理论、方法、算力提升而不断外扩，从不可推理到可推理、从不可统计到可统计，每一次AI浪潮都在拓展适用范围，智能是逐步积累的结果，如图6-4所示。曾经有人感慨，问题一旦被计算机解决，大家就不再把它当成人工智能了¹¹⁷

### 6.6 进行机器学习：实战模型训练

前面停留在理论层面，接下来进入实操。涉及具体操作就会碰到大量日常用不到的概念，多数资料喜欢用数学公式推导。本书保持一贯风格，尽可能少依赖专业知识。为此设置了一个邮件过滤的实战案例，完整走一遍流程后，对机器学习的步骤会更直观。

#### 6.6.1 机器学习的一般过程

大家都用过电子邮件，它带来便利的同时也成了垃圾信息的通道。邮件服务商除了速度、容量、稳定性，还要解决过滤垃圾邮件的问题。人眼很容易分辨邮件是否有用，但很难写出清晰的评判准则。这种难以总结规律却能统计的任务，非常适合统计机器学习。

本次实战设计一个邮件过滤系统，通过分析事先被用户标注为垃圾或非垃圾的记录，训练出一个判别模型，用来判断新邮件是否属于垃圾邮件。按米切尔教授的定义，该任务要素如下：

`T`（执行任务）：判别是否垃圾邮件。

`P`（性能度量）：成功过滤出垃圾邮件的占比，以及非垃圾邮件被误判的占比。

## 机器学习的一般过程

`E`（历史经验）：一组事先已经被用户标注为垃圾邮件的记录。

整体而言，训练判别模型就是从真实世界的历史经验中提炼出能拟合现实、用于分类、预测、决策的模型。典型流程如图6-5所示，本节会按训练步骤逐一说明。

第一步一般涉及传感器取数、噪声过滤等工程细节，本案例不展开。我们聚焦于“挑哪些特征建模”“选什么模型”“如何调参”“怎么测试”。从图6-5看，无论步骤如何安排，最终目标都是得到一个高度拟合真实世界的判别模型。先要弄清训练产物——判别模型是什么。

形式上，判别模型可看作一个可计算的函数，输入输出明确，可能有科学含义也可能只是数值映射，可用于决策也可用于预测。训练出来的模型有可能是可解释的，能从中挖掘人类此前未知的规律；也更可能是一个黑盒，只是在模拟现实，不含严谨逻辑。计算机按模型执行，就能把输入信息映射为隐含特征，进而决定类别或指标。例如决策函数 `f(x)` 的映射如图6-6所示。

#### 6.6.2 样本和样本空间

训练第一步是确定样本。本案例的数据来自邮件服务器里已有的电子邮件，每封参与训练的邮件可视作一个训练“样本”(`Instance`)。样本是描述事实或对象的结构化数据，例如“发件人叫周志明”就是一种描述。“这封邮件是垃圾邮件”也是描述，但属于直接结论，不需要机器学习。需要机器学习的场景里，样本描述的往往是间接、隐晦的属性，无法用明确语言说明属性与结论的联系，这类信息称为样本的“属性”(`Attribute`)。每个样本由若干属性组成，也常称“特征”(`Feature`)，比如一封邮件的特征可能是下面这样的：

一般而言，训练样本中每个特征的含义应保持一致，允许部分特征缺失。特征由含义和取值构成，相同含义的特征在不同样本中应使用一致的数据结构和度量单位，否则需在预处理阶段统一归一化。机器学习倾向使用计算机可读的取值，如整数、浮点数、枚举值等，若不是，则先转为无量纲表达。

接下来是样本空间的概念。假设样本由收件人数量、邮件长度、附件数量三个特征构成，将三个特征按数值大小分别放在三条坐标轴上，每个样本就在该三维空间中对应唯一一点，用指向该点的线段表示，例如“收件人=3、附件=2、长度=128KB”对应的坐标如图6-7所示。

[PRE8]

图 6-7　样本向量空间示例

数学上，这样的带方向和大小的量叫“向量”(`Vector`)，由向量组成的空间叫“向量空间”(`Vector Space`)。在机器学习里，用一系列向量代表每个样本，这个由 N 个特征构成坐标轴的 N 维空间称为“样本空间”(`Instance Space`)或“特征空间”(`Feature Space`)，样本本身称为“特征向量”(`Feature Vector`)。

把语言文字描述转为向量后，就能借助向量运算、矩阵等大量数学工具处理样本。实战中，训练数据从数据库中的邮件经人工提取三个关键特征——收件人数量、邮件长度、附件数量——后，转化为由 N 个特征向量组成的集合：

`T={(x11, x12, x13),(x21, x22, x23),(x31, x32, x33),…,(xn1, xn2, xn3)}`

在数据收集阶段，根据任务，可能只收集样本，也可能给样本加上“标记”(`Label`)，标记描述样本所代表的隐含事实，即结论。本案例中样本是邮件数据，标记就是“是否垃圾邮件”。样本与标记组合在一起，就构成一个“样例”(`Example`)。
