## 第3章 DeepSeek 助力数据清洗加工

数据分析中，清洗加工是非常关键的一环，尤其是大批量表格或多表关联的清洗，还涉及关联逻辑的判断。若数据量小、表格简单，可用 Excel 的分列、去重、排序筛选等工具，或用 Power Query 高效处理与建模。有了 DeepSeek 参与，清洗加工的效率还能再上一个台阶。

### 3.1 快速掌握数据清洗的基本知识和技能

数据清洗是分析的第一步，先要掌握清洗的基本技能，知道表格常见的不规范有哪些，该如何处理。借助 DeepSeek，相关知识可以迅速获取。

#### 3.1.1 快速了解常见的表格不规范

输入提示词“表格结构和数据的不规范有哪些方面？请结合示例介绍”，先看看 DeepSeek 的思考过程，如图 3-1 和图 3-2 所示。

[PRE2]
要把每个方面配上具体案例会更容易理解。比如表头不规范，可以举没有列名或列名重复的例子；行列设计问题，可以举合并单元格导致数据无法结构化处理的例子；数据类型混乱，可以举年龄列里出现“未知”等数字与文本混杂的例子；冗余数据可以是重复行列或多余的分隔线；数据缺失可以是单元格空白或用“-”占位；格式不统一可以是同一日期列里出现“2023-01-01”和“01/01/2023”两种写法；数据冗余还可能是多列重复存储同一信息；异常值可以是年龄为-10或200；命名问题可以是用未说明的缩写；编码问题可以是性别同时出现“男/女”和“M/F”。组织内容时要分点说明，每个点配示例，语言简洁易懂，贴近数据分析、清洗等实际场景。最后还要检查是否遗漏，比如多余空格、特殊字符、分隔符错误、不合理布局等，也属于不规范范畴。分类上可先分结构与内容两大块，再细化小点并配例，结构清晰、覆盖全面。

[PRE3]
梳理 DeepSeek 的思考后，可以快速掌握表格不规范的要点：

1. 表格结构不规范。
  - 表头问题，如表头缺失、重复或表述不清，导致处理困难。
  - 行列设计问题，如合并单元格过多、行列中混放不同类型数据，影响分析效率。
  - 数据类型问题，如同一列出现文本与数字混用、日期格式不统一，导致计算错误。
  - 冗余数据问题，如重复行列或不必要的分隔符，增加处理复杂度。
2. 表格数据不规范。
  - 数据缺失，如单元格空置或用 N/A 等占位符代替，影响后续分析。
  - 格式不统一，如日期写法不一致或单位不统一，难以比较计算。
  - 数据冗余和重复，如重复记录或多余存储，浪费空间降低效率。
  - 异常值或错误数据，如数值超出合理范围或拼写错误，影响结果。
  - 命名和编码问题，如命名不清晰或编码方式不一，易导致理解和整合错误。

DeepSeek 还提供了不规范类型的详细说明，如图 3-3 所示。可以对照自己工作中处理过的表格，检查哪些环节做得不够。

##### 一、表格结构不规范
1. 表头问题
  - 缺失表头：无明确列名，无法判断列含义。
  - 重复表头：多行表头或跨页重复，导致提取困难。
  - 表头含义模糊：列名如“字段1”“字段2”，无法明确内容。
2. 行列设计混乱
  - 合并单元格过多：合并行列使数据难以结构化存储。

可以针对 DeepSeek 的详细介绍逐条追问。例如输入“缺失表头都有哪些情况”，DeepSeek 会展开思考：完全缺失表头、部分缺失、视觉存在但实际缺失的隐藏表头、多级表头下级标题不明确、动态生成表头缺失、表头与数据混淆等。理解这些典型情况，有助于设计表格时避免问题，也能掌握诊断与整理思路。

输入“行列设计问题都有哪些”，可以对照实际工作自查常见错误：合并单元格滥用、行列混合存储不同类型数据、冗余行或列、维度交叉、标题行重复或嵌入数据中、数据方向不一致、多级表头层级混乱、行内数据不完整等。

继续输入“数据类型不统一都有哪些情况”，DeepSeek 会总结常见情形并给出示例与解决思路：同一列混合不同数据类型如数值与文本、日期格式不一致、布尔值与文本混用；数值类型不统一如单位混杂、数字格式不一致、整数与浮点混用；分类数据编码混乱如同一类别不同命名、多级分类未拆分；结构化与非结构化数据混合如 JSON 文本与普通字段混用、多值字段未标准化；特殊符号干扰如数字中带非数值字符、科学计数法与非科学计数法混用、空值表示不一致等。阅读后对危害会有更深认识。

若不了解冗余数据问题，可输入“冗余数据问题有哪些”，DeepSeek 会给出解释、示例及解决方案。数据缺失也很常见，输入“常见的数据缺失有哪些”，DeepSeek 会进行总结并结合示例提出解决办法。

总体来看，DeepSeek 对表格不规范做了多维度思考和归纳，帮助我们了解成因、影响及对应方法。
