根据不同参数计算范数，函数签名如下：

[PRE4]

- (1) x: 表示要度量的向量。
- (2) ord：表示范数的种类，具体见表 3-4。
- (3) axis：处理类型。
  - axis=1 表示按行向量处理，求多个行向量的范数。

表 3-4 范数表

| 参数 | 说明 | 计算方法 |

|---|---|---|

| 默认 | 二范数: ℓ2 | √x₁²+x₂²+…+xₙ² |

| ord=1 | 一范数: ℓ1 | |x₁|+|x₂|+…+|xₙ| |

| ord=np.inf | 无穷范数: ℓ∞ | max(|xᵢ|) |
