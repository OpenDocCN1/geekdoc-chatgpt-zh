**一、二分法的本质**
1. 概念
通过不断折半区间寻找目标值，适用于具有单调性的判定问题。
2. 执行流程
设定上下界，取中点检验，若可行则下调上界，否则上调下界，直至上下界重合。
3. 典型用途
在有序结构中定位元素，或求满足单调判定的最小/最大参数，本题即求最小差值 m。
4. 本例应用
搜索区间 [0, 最大差]，借助滑动窗口的计数函数判定可行性，逐步收敛。

**二、STL 的价值**
1. C++ 标准模板库
提供容器与算法的现成实现，如 sort、min/max、swap。
2. 本例使用
sort 对数组排序，复杂度 O(n log n)，为滑动窗口提供有序前提。
3. 使用理由
STL 实现经过优化且接口统一，手写排序难以匹敌其效率与稳定性。

**【题型小结】**
本题综合考察二分搜索与 STL 排序的配合，二分负责参数搜索，排序为计数提供前提。

1. 函数 upper_bound
int* upper_bound(int *a, int *an, int ai) {
    int l = 0, r = an - a;                   // 定义左右边界，数组长度为 an - a
    while (l < r) {
         int mid = (l + r) >> 1;             // 使用位运算获取中点
         if (a[mid] > ai) {                  // 如果中点值大于目标值
              r = mid;                       // 缩小右边界
         } else {
              l = mid + 1;                   // 向右扩展，跳过中点
         }
    }
    return a + l;                            // 返回第一个大于 ai 的元素指针
}                            // 定义数组的最大长度

功能：

2. 函数 get_rank
long long get_rank(int sum) {
   long long rank = 0;                     // 初始化排名
   for (int i = 0; i < n; ++i) {
                                           // 对于 a[i]，计算 b 中小于或等于 sum - a[i] 的元素数量

}

功能：

3. 函数 solve
int solve() {
    int l = 0;                               // 初始化二分下界
    int r = a[n - 1] + b[n - 1];             // 初始化二分上界，最大可能的和
    while (l < r) {
         int mid = ((long long)l + r) >> 1;  // 计算当前中间值
         if (get_rank(mid) < k) {            // 如果当前和的排名小于 k
              l = mid + 1;                   // 缩小搜索范围到右半部分
         } else {
              r = mid;                       // 缩小搜索范围到左半部分
         }
    }
    return l;                                // 返回第 k 小的和
}

功能：
二分查找满足排名 ≥ k 的最小和，get_rank 提供单调判定。
