#### 7.1.4 基于 CrewAI 搭建 AI Agent

CrewAI 是当前兴起的 Agent 应用框架之一，面向复杂任务的协作式 Agent 搭建。它让多个人工智能 Agent 能够承担不同角色、共享目标并在同一个持续运行单元里协同。架构上 CrewAI 基于 LangChain 构建，因此可以直接复用 LangChain 的工具，也支持自行编写自定义工具。
