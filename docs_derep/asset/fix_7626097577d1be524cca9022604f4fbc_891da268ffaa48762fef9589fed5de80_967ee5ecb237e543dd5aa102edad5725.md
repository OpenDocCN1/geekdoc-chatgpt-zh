# RAG 里的大模型调用三步走

在检索增强生成的实现中，激活大模型通常可以拆解为三个连续动作：

- 权重获取：从 Hugging Face 模型库拉取所需模型，BERT 常用于语义向量化，GPT 系列则偏向生成式输出。
- 文本转换：通过分词器把原始自然语言切分为模型可读的 token 序列。
- 推理生成：将编码后的序列输入模型完成前向计算，返回预测或续写结果。
