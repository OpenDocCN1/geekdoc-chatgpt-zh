# 智能小车进阶控制与多传感器融合实战

## 核心驱动逻辑：运动控制基础

要让小车倒车，只需反转电机旋向（由逆时针改为顺时针，具体取决于接线方式），对应积木指令见[PRE0]图示。实现转向则通过差速控制——调整左右电机转速比即可，编程逻辑参考[PRE1]图示。

## 实战演练：模块化传感器集成

### 1. 超声波避障系统搭建
**硬件连接：** 将超声波模块接入扩展板：绿线接`P15`，蓝线接`P16`，红线接`3V3`，黑线接`GND`（对应[PRE2]接线图）。

**逻辑编程：** 搭建[PRE2]所示积木程序——循环检测距离，阈值设定为 10cm：小于则刹车，大于则前行。烧录至 Micro:bit 后实测：无障碍时匀速前进，遇阻即时锁死。

### 2. 声控触发后退模块
**硬件部署：** 固定声音传感器（实物见[PRE3]），信号线接`P0`，电源并联`3V3`与`GND`。

**交互逻辑：** 编写[PRE4]程序：监测声强突变（拍手/呼喊），触发持续 10 秒全速后退。上电测试，声响激活瞬间响应灵敏。

### 3. 光敏巡航/旋转模块
**硬件接入：** 光线传感器（[PRE5]实物）安装就位，信号线接`P1`，共用电源轨。

**行为设定：** 依据[PRE6]编程：环境亮度超标时，驱动 M1、M2 电机反向同速运转（原地自旋）；光源移除则双电机抱死停车。实测手电筒照射即旋转，遮光即静止，逻辑闭环验证通过。

### 4. 多传感器融合决策系统
整合三大传感器构建复杂状态机，核心流程见[PRE8]：

*   **超声波模式：** 前进中距离 < 10cm → 急停 1s → 后退 → 左转避障 → 继续巡航。
*   **声控模式：** 前进中检测声强超阈 → 急停 1s → 定时后退 2s。
*   **光控模式：** 前进中光照超阈 → 急停 1s → 双电机对转原地旋转。

扩展性验证：预留接口兼容火焰、红外、灰度等模块，叠加状态机即可进化为消防侦察车、循迹竞速车等多形态终端。
