- 3. 冰箱更省电的做法

- 4. 洗衣机更省电的做法

- 7. 电暖器和电风扇更省电的做法

风扇可设置自动停机，防止整夜运转。

- 8. 用好峰谷电价
大功率电器错峰使用，例如夜间洗涤、洗碗。

定期清理滤网、散热口，保持运行效率。
定期检查线路，防止漏电短路造成浪费。

### 3.8 宠物护理：呵护猫狗健康指南

猫狗带来陪伴，也需要主人承担责任。从饮食到运动再到健康管理，每个细节都影响它们的生活质量。

> 提示词：我最近想养小猫小狗，你能告诉我小猫小狗可能会患上的常见疾病，以及生病后该怎么处理吗？

#### DeepSeek：
以下是常见疾病及应对方式：

#### 一、小猫常见疾病及危害
1. 猫瘟
症状：高烧、呕吐、血性腹泻、脱水、嗜睡。
危害：幼猫未免疫死亡率极高，可经粪便、呕吐物传播。
处置：发现即就医，输液防脱水、抗生素防继发感染、抗病毒药物辅助。

2. 猫传染性腹膜炎
症状：腹水、呼吸困难、消瘦、发热。
危害：由冠状病毒变异引起，无特效药，延误可能致命。
处置：利尿减轻腹水、抗生素防继发感染，保持环境稳定减少压力。

3. 泌尿系统疾病
症状：排尿频繁量少、排尿疼痛、血尿。
危害：公猫易尿道堵塞导致急性肾衰竭，48 小时内危及生命。
处置：属于急症，需立即就医导尿、输液和药物治疗。

4. 寄生虫感染
体内：蛔虫、绦虫，表现为消瘦、腹泻、呕吐。
体外：跳蚤、蜱虫，表现为瘙痒、幼猫贫血。
危害：长期感染营养不良，蜱虫可传致命血液病。
处置：体内用兽医推荐驱虫药定期驱虫；体外使用滴剂、喷雾或口服预防药。

#### 二、小狗常见疾病及危害
1. 犬瘟热
症状：高烧、脓性眼鼻分泌物、后期抽搐。
危害：幼犬致死率约 80%，存活者可能有神经后遗症。
处置：输液、抗生素防继发感染、抗病毒药物和营养支持，需隔离。

2. 细小病毒
症状：剧烈呕吐、血便、脱水。
危害：未及时治疗 3~5 天内死亡，病毒存活时间长。
处置：病情进展快，立即就医，输液、抗生素、止吐药和营养支持。

3. 犬心丝虫
症状：咳嗽、运动耐受差、晚期腹水。
危害：成虫堵塞心脏肺血管，死亡率高且治疗费用高。
处置：兽医用药杀虫，过程需谨慎，严重时可能需手术。

4. 皮肤病
症状：红肿、脱毛、抓挠频繁。
危害：继发细菌感染，长期不愈或致败血症。
处置：外用抗螨、抗真菌或湿疹药膏，严重时口服药物。

> 提示词：如果我的宠物生病了，我该怎么让它快点好起来呢？比如给它吃点什么食物，怎么帮它保持卫生，以及日常的护理技巧。

#### DeepSeek：
生病期间正确护理能帮助恢复：

- 1. 饮食建议
易消化食物：食欲差时可喂煮熟去骨鸡肉、米饭或专用病号餐，避免油腻难消化。
补水：确保饮水充足，不愿喝水可用无针注射器少量喂水，或提供罐头等含水量高的食物。

- 2. 卫生与清洁
及时清理排泄物，保持环境干净防细菌。
身体清洁：无法自理时用温湿毛巾轻拭身体，重点是肛门和尿道周围。
环境消毒：定期清洁生活区，使用宠物安全消毒剂，避开刺激性化学清洁剂。

- 3. 日常护理技巧
提供安静温暖舒适的休息环境，减少噪音干扰。
监测体温：猫狗正常体温约 38~39℃，发烧时用宠物专用体温计测量。
观察变化：注意食欲、精神、排泄变化，恶化时及时联系兽医。
按时用药：严格按处方剂量给药，不自行更改或停药。

- 4. 心理关怀
多陪伴、轻抚安抚，缓解焦虑，避免过度互动和剧烈运动。

- 5. 及时就医
呕吐、腹泻、呼吸困难、严重乏力未好转时立即就医，切勿使用人用药物。

### 3.10 家庭安全：煤气泄漏自检与应对

家是港湾，煤气泄漏却可能引发爆炸、中毒。掌握检查和应对方法至关重要。

> 提示词：家里最近换了新的煤气灶和管道，我总担心煤气泄漏，可以给我讲讲煤气泄漏的危害，以及如何快速检查煤气是否泄漏吗？

DeepSeek：
煤气泄漏需高度重视：

#### 煤气泄漏的危害
- 1. 中毒：煤气置换氧气导致缺氧，严重可窒息。
- 2. 爆炸：空气浓度 5%~15% 时遇明火或电火花易爆炸。
- 3. 火灾：泄漏遇明火或高温表面可引发火灾。

#### 如何快速检查
- 1. 嗅觉检查：煤气本身无味，加臭味剂后有臭鸡蛋味，若闻到需警惕。
- 2. 听觉检查：泄漏时管道或接头处可能传出轻微嘶嘶声。
- 3. 视觉检查：肥皂水涂抹管道和接头，有气泡说明泄漏。
- 4. 使用检测仪：专用煤气检测仪可快速判断浓度。

> 提示词：煤气泄漏真是太可怕了，万一检查时真发现有煤气泄漏的迹象，我应该采取什么措施呢？

DeepSeek：
发现迹象立即执行：

- 1. 立即关闭煤气阀门
找到煤气表附近阀门，顺时针拧紧切断供应。
- 2. 打开门窗通风
迅速开窗通风，降低浓度。不要开关任何电器，避免电火花。
- 3. 杜绝明火和电器操作
禁止打火机、火柴、吸烟。不要插拔插头或使用手机。
- 4. 撤离现场
迅速离开并通知家人和宠物撤离，多户住宅需通知邻居。
- 5. 联系专业人员
拨打煤气公司紧急电话或 119 报告，等待专业人员处置，不要自行维修。

#### 预防措施
- 1. 定期检查：检查管道、接头是否老化松动损坏。
- 2. 正确使用：用气时保持火焰稳定，避免熄火后持续泄漏。
- 3. 保持通风：使用时厨房保持良好通风。
