## 第 4 章 AutoGen Agent 开发实战

2023 年 9 月，微软正式将 AutoGen 开源。该项目围绕 Agent 展开，而 Agent 在人工智能里指可感知外部环境并据此做出反应的系统或实体。它能自主处理信息、进行判断并执行动作以实现目标，通常具备目标导向、自我学习、环境互动和决策执行等特性，可落地于计算机、移动设备、云服务等多种形态，被广泛用于自然语言处理、机器人、个性化营销等领域。

AutoGen 是一款面向大语言模型的 Agent 构建框架，依托 OpenAI 的 GPT-4 等模型，支持单 Agent 或多 Agent 组合来开发语言模型应用，如图 4-1 所示。

本章重点展示 AutoGen 如何借助 Agent 间协作完成用户指派的任务。

### 4.1 AutoGen 开发环境

AutoGen 使用 Python 语言实现，需要先准备 Python 开发环境并装好常用工具，以下做简要说明。本书的示例均在 Windows 系统下完成，具体安装步骤不再赘述。

#### 4.1.1 Anaconda

Anaconda 中文名为蟒蛇，是一款开源 Python 发行版，内置 conda、Python 及 180 多个科学计算包及其依赖。若无编程经验，安装 Anaconda 更省心，后续无需单独装依赖。有一定经验的读者可选择 Miniconda，按需装依赖以节省空间和时间。本书采用 Anaconda3，版本 1.12.1。

#### 4.1.2 PyCharm

PyCharm 由 JetBrains 打造的 Python 集成开发环境，Visual Studio 2010 的重构插件 ReSharper 也出自该公司。PyCharm 提供了调试、语法高亮、项目管理、代码跳转、智能提示、自动补全、单元测试、版本控制等提升效率的功能。本书使用 PyCharm Community Edition 免费版。

#### 4.1.3 AutoGen Studio

AutoGen Studio 能够快速搭建多 Agent 工作流的原型，并为 AutoGen 提供可视化界面。

安装流程如下。

- 第一步：打开 Anaconda Powershell Prompt 窗口。
- 第二步：在该窗口执行 pip install autogenstudio 命令完成安装，如图 4-2 所示。
- 第三步：继续输入 autogenstudio ui --port 8081 指定端口，如图 4-3 所示。
- 第四步：在浏览器打开 127.0.0.1:8081，建议使用 Chrome，即可看到图 4-4 所示界面。
