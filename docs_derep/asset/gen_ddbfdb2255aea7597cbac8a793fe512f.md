可现在，AI出现了。

没有AI的时代结束了。

它冲击了法律人的灵魂，搅动了深水，宣告新纪元开启。

本书试图给出答案。

书中以法律人的视角审视AI带来的机遇与挑战，是一场技术与法律、坚守与变革、逻辑与人性的对话。不论是好奇震撼还是困惑抗拒，我们都必须承认，AI时代已经拉开帷幕。以AI为驱动的法律行业转型，可能在五到十年内渗透到每个角落。谈论AI不是猎奇，而是为了发展与生存。

合伙人、非合伙律师、律所行政人员都要正视，AI正以前所未有的广度和深度改写法律实务，无论是职业属性还是商业属性。影响是全方位的，无人可以置身事外。AI会把我们从旧舒适区推出，但牵手之后，它也能引领进入更高层次的舒适区。它不是律师的黄昏，而是可以成为24小时不间断的盟友，是行业新质生产力，是高质量发展的关键力量。

逐梦AI是当代法律人的宿命。不与AI结盟，就是与时代为敌，就是背叛职业和初心。

# 序Ⅱ

法律科学的科学品格集中体现为法律理性，它是法律科学的技术内核，也是实现良法善治的关键。法律理性具有科学的确定性，而对崇高伦理的持续追问又赋予它可检验性。进入21世纪，以AI为代表的科技革命快速迭代，既在书写科技史，也在书写人类史，而书写历史的笔已不只握在人类手中，正如Alpha Zero能自主生成棋谱一样，新的历史谱系将由人类与AI共同谱写。

面对科技革命，任何专业技术人员都会焦虑，法律科学工作者亦不例外。幸运的是，法律科学因条文化知识、体系化方法和程序化应用，比其他社会科学更接近自然科学。其应用产生的大量案例数据就是标准化的海量数据库，为科学实验提供了基础。因此在法律科学应用中引入AI不仅可行，而且相当便利。

解决了可行性，下一步是：我们是否需要一个被AI武装的法律科学？不妨让AI自己来回答。北京新橙科技有限公司编写本书时，AI给出的总结是：

“这部关于法律AI产品使用的工具书，是我们应对AI时代挑战、把握发展机遇的重要指南。它不仅系统阐述了法律AI产品的功能与使用方式，还深入剖析了AI对法官审判、法学教育及整个法律体系的影响与挑战。法律AI借助大数据与机器学习的优势，能迅速精准分析案件，为法官提供智能化建议与决策支持，大幅提升审判效率、减轻负担。教学上，可通过模拟法庭、智能案例分析等创新手段，帮助学生理解法律、掌握技能、培养实践与创新能力。通过阅读，我们能更全面地领略法律AI的潜力，掌握使用技巧，更好迎接挑战与机遇。”

AI的回答底气十足，但能否兑现，取决于人类在设计之初是否以法律理性奠定底层逻辑，是否明确告知AI必须遵循的知识、方法与价值。法律理性是知识、方法、价值的统一，条文、解释方法与条文价值是实施的第一依据，执法司法都必须体现法律理性，否则便缺乏合法性。在从决疑术到法律科学的长河中，法学家坚持科学法之路，对复杂决疑体系进行系统化与类型化。19世纪中后期，法律科学形成形式主义理性化的知识体系，愈发趋近理性法。AI作为科学智慧体，已具备相当自主思考能力，若在底层注入法律理性的构成，是否就能像法律工作者一样拥有法律理性？值得期待。对此AI也信心满满：

“让我们携手前行，以法律智慧为灯塔，照亮司法与教育的革新之路。在AI浪潮中共同书写法律事业新篇，为社会公正与和谐贡献智慧与力量！让我们共启法律智慧新纪元，迎接更美好的未来！”

拭目以待。

曹士兵
浙江大学国家制度研究院副院长
2024年11月11日

# 序Ⅲ

以人工智能、大数据、区块链为代表的新一轮科技革命席卷全球，深刻改变生产生活方式。传统行业必须拥抱变革，推进数字化智能化转型，才能在竞争中占据先机。

法律服务业同样面临转型升级的紧迫任务。AI正在重塑服务模式，带来前所未有的机遇与挑战。一方面，智能合同审查、案件预测、法律咨询、司法辅助等应用展现出强大潜力，正在改写工作面貌。另一方面，智能化转型也困难重重。麦肯锡全球研究院预测，到2030年，全球约73%的工作将被AI替代或改变，法律领域的比例可能更高。如何在驾驭AI的同时引导其在法治轨道上规范发展，是每一位法律人必须面对的新课题。

本书的出版正是积极回应。书中系统解析AI在法律领域的创新应用，为法律人驾驭新技术提升专业素养提供指引。

本书有三大特点。

第一，直面挑战拥抱未来。AI、大数据、区块链正深刻改变法律服务业态。法律人唯有保持开放心态，紧跟技术前沿，才能立于不败。本书为读者了解AI发展提供窗口，介绍基本概念、发展历程与典型应用，为智能法律服务奠基。同时围绕法律知识图谱构建、案例推理模型构建等前沿议题展开理论分析，对法学研究有启发，对推动服务模式变革有参考。

第二，学用结合知行合一。法律服务智能化尚在起步，法律人既要掌握理论，也要注重实践。本书在理论层面借鉴前沿成果，剖析智能体构建、检索增强生成等热点，揭示原理与路径；在实践层面紧扣实务痛点，提出系统性应用方案，涵盖文书分析、辅助决策、模型构建、场景应用全流程，并以案例详解，为实务工作者提供可操作的行动指南。

第三，立足当下放眼未来。AI在释放生产力的同时，也带来知识产权、数据安全、个人隐私、虚假信息等法律风险与伦理挑战。本书在介绍现状与场景的基础上，系统梳理相关法律问题，吸收国内外研究成果，总结各国立法实践，为立法与学术研究提供参考。

本书由一线研发人员、技术专家与法律人共同撰写，以真实需求为导向，将前沿科技与实务经验融合，用通俗语言呈现，价值显著。可预见，它将成为法律人认知、学习、运用AI的重要参考。

本书在描绘工作模式转型蓝图的同时，也对AI时代法治建设进行深入思考。AI进一步融入法律工作的各个环节，跨学科融合将成大势，多学科交叉创新将开辟法学新领域。本团队持续关注AI法律问题研究，曾起草发布《人工智能法（示范法）》，并于2024年8月由中国社会科学出版社出版《〈人工智能示范法〉释义》，旨在为AI立法提供学理基础与实践样本，推动法治讨论。

展望未来，愿更多同仁参与AI法律治理研究，共同推动法律服务高质量创新与AI法治高水平建设。

周辉
中国社会科学院法学研究所网络与信息法研究室副主任

# 前言

历史上每一次重大技术变革来临前，总伴随不同声音，但敢于拥抱变革、敢于创新的人往往成为时代引领者。

18世纪末至19世纪的工业革命以蒸汽机为标志，保守派担心机器取代人力导致失业与动荡。但敢于尝试的企业家利用蒸汽机提高效率，推动工业飞跃，创造新就业，带动繁荣。瓦特的蒸汽机因推动进步而被铭记。

20世纪末至21世纪初互联网兴起，彻底改变生活方式。初期有人担忧隐私侵犯、传统行业冲击、监管削弱。但亚马逊、谷歌、阿里巴巴、腾讯、抖音、美团等积极拥抱互联网、创新商业模式、提升服务质量，不仅取得巨大成功，也推动行业转型，为社会创造价值。

今天，面对人工智能浪潮，法律服务行业该何去何从？2023年春，美国高盛公司估算不同行业就业岗位在美欧面临AI自动化取代的比重，法律职业位居第二高风险，约44%的任务可能被自动化。

这意味着未来一段时间，法律人和法律服务市场将承受巨大技术冲击。律师助理、实习律师的大量工作可能被机器取代，按时收费模式可能受挑战。入门门槛可能被AI抬高，传统金字塔层级可能被扁平化。过程或需数年甚至数十年，但不适应变化者将被无情淘汰。
