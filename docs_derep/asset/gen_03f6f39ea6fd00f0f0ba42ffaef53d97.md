## 前言：代码为王，实践出真知

“Talk is cheap, show me the code.” Linux之父林纳斯·托瓦兹2000年一封群邮中的这句金句，至今仍是计算机科学家的圭臬。计算机科学极重实践，理论落地为可运行、可验证的代码，才是硬道理。AI作为应用场景最密集的子学科之一，更要求学习者在悟透原理后，动手实战、以算解题。正所谓“纸上得来终觉浅，绝知此事要躬行”。

因此，2018年夏天，俞勇教授组建团队，着手编写面向青少年的项目实践教程。起步内容涵盖图像上色、英语语法单选、角斗士桌游。我们力求用最平实的语言拆解复杂算法，并配套代码与在线交互演示。中学生试读反馈热烈，一致好评，遂萌生扩展为系统性丛书的念头。2019年初，我们注入更多实战内容，引导读者“懂原理、写代码、知AI”，理论实践双轨并行。项目甄选兼顾趣味性、技术热度、知识面；编写上极力精简，仅授任务必需知识，助力零基础读者快速上手。每个算法均附带注释详尽的Python实现，引领读者逐行构建。

### 第一章 图像识别的基础知识：从像素到张量的译码之旅

本章带你拆解：什么是图像识别、计算机如何“看”图、识别全流程、类别如何编码，并带你用代码探秘经典数据集。

#### 一、 图像识别：给机器一双“懂图”的眼

顾名思义，即让机器判读图像内容。严谨定义：输入一张图，输出内容标签。如：输入手写数字图 → 判定数值；输入动物图 → 区分猫狗；输入班级合照 → 叫出名字。

#### 二、 计算机眼中的世界：从像素到矩阵

要让机器识图，先得让它“看”见。你可能不陌生：Windows画图、Lightroom、PS展示了强大的图像处理力。但你知道机器眼里只有数字（二进制）吗？如何将图像数字化？

计算机图像主要分**位图**与**矢量图**（本书聚焦位图）。位图本质是**像素矩阵**。将图像切分为微小方块，每个方块即一像素。广告语“2000万像素”即指图像含2000万个微方块。每像素承载信息，像素越多，信息越丰，画面越清晰。

以黑白照为例：每像素用一个数值表征灰度（亮度）。设纯白=100，纯黑=0，灰阶映射1-99，一张图便转化为一个数值矩阵（实际常用0-255，此处简化易懂）。

[PRE5]

彩色图像遵循**光的三原色原理**：红绿蓝（RGB）叠加生成任意颜色。故每像素可用一个三元数组（R, G, B）唯一确色。R/G/B各取0-255整数。
*   (255, 0, 0) = 纯红
*   (0, 255, 0) = 纯绿
*   (255, 255, 0) = 红绿叠加 = 纯黄
*   (0, 0, 0) = 无光 = 黑
*   (255, 255, 255) = 三色满强 = 白

[PRE6]

##### 概念解析：向量、矩阵、张量与通道

图像存储涉及四大核心术语：

*   **向量**：本质是一组有序数字（一阶张量）。
*   **矩阵**：行列构成的二维数字阵列，用(行,列)定位（二阶张量）。灰度图即矩阵。如(5,5)矩阵。
*   **张量**：广义容器，维度不限行列。三阶张量即(行,列,深度)，如(5,5,3)，天然适配RGB彩色图。
*   **通道**：彩色图由三阶张量表示，除行列外，第三维度即“通道”。RGB图通道数=3。
