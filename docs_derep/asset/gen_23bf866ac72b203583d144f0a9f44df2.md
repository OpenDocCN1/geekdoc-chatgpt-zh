### A 命令速查表
OpenClaw 常用命令是操控系统、调用功能、部署维护的抓手，涵盖启动停止、技能管理、任务执行、部署配置、日志查看等场景。以下为实战验证的高频命令，按功能分类汇总，适配个人本地与企业私有化部署，并标注注意事项，便于快速上手。

系统基础操作，用于启动、停止、重启与状态查看。
启动命令：`openclaw gateway start`，启动核心服务、技能调度、日志服务，完成初始化。异常时结合日志排查。
停止命令：`openclaw gateway stop`，优雅关闭所有服务，避免强制停止导致数据丢失。
重启命令：`openclaw gateway restart`，一键完成停止与启动，适合配置修改后生效。
状态查看：`openclaw status`，显示核心进程、端口占用、已启动技能模块，清晰标注运行/已停止状态。

技能管理，用于安装、卸载、启停与列表查看。
安装命令：`openclaw skills install [skill_name]`，自动下载并启用指定技能。
列表查看：`openclaw skills list`，输出技能名称、版本、状态、描述与安装时间。

任务日志查看：`openclaw logs`，查看任务拆解、技能调用、执行结果与错误信息，排查失败的关键。

### B 常见问题集
按安装部署、日常使用、技能开发、开源贡献、企业运维分类汇总，结合实战经验给出解决方案。

安装部署类
问题1：执行 `openclaw gateway start` 后提示依赖包缺失。解决：检查 Node.js 是否安装且版本符合要求，补装缺失依赖，完成后重启；仍缺失则按官方文档清单手动安装指定版本。
问题2：Windows 启动提示端口被占用。解决：运行 `openclaw config show` 查看默认端口，任务管理器结束占用进程；无法结束则修改配置文件更换空闲端口后重启。
问题3：企业私有化部署数据库连接失败。解决：确认数据库服务正常、端口开放；核对配置中的主机、端口、账号密码；检查用户权限是否足够；跨服务器部署需确保网络连通与防火墙放行。

日常使用类
问题1：自然语言指令无法识别。解决：指令表述需具体明确，避免模糊表述，补充关键参数如文件路径、操作类型；参考官方指令模板；确认对应技能已安装。
问题2：任务执行提示技能调用失败。解决：执行 `openclaw skills list` 确认技能已启用；异常则卸载重装；查看 `openclaw logs` 按提示修复；如为技能问题反馈至社区。
问题3：运行卡顿响应慢。解决：检查主机 CPU、内存、磁盘资源，关闭无关进程；检查并发任务数，终止无用任务；企业场景建议使用服务器部署。

技能开发类
问题1：自定义技能无法被识别。解决：严格遵循开发规范，检查配置文件字段是否正确；将技能包放入系统指定目录并刷新列表。
问题2：调用时提示参数错误。解决：核对参数定义与指令一致，确保名称、类型、必填项正确；补充用户输入缺失项；在代码中增加参数校验。
问题3：输出结果不符预期。解决：排查代码逻辑，特别是拆解、工具调用、结果返回环节；增加日志打印关键变量；测试边界输入；参考官方案例优化。

开源贡献类
问题1：PR 审核失败。解决：检查代码规范、注释命名、运行无误；PR 描述清晰说明改动目的与问题；按 Review 意见修改后重提。
问题2：不熟悉贡献流程。解决：参考官方贡献指南，流程为 fork→克隆→分支→修改→提交→推送→PR；加入开发者社区请教；从 Bug 修复、文档完善入手。
问题3：数据迁移丢失或失败。解决：迁移前全量备份；确认格式兼容性，必要时转换；关注迁移日志及时处理异常；迁移后校验完整性；失败可回滚备份重试。
问题4：企业部署运维困难。解决：建立日志与任务日志定期巡检机制；配备熟悉架构的运维人员；利用安全审计追踪操作；定期备份与版本更新；加入企业运维交流群获取支持。
