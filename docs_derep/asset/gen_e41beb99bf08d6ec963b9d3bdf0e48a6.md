# 内容速览

《AI即未来》出自英国人工智能专家安东尼奥·韦斯博士之手，是一本兼顾通俗性与实操性的生成式人工智能应用指南。全书先把人工智能的基本概念、演进脉络和核心模型梳理清楚，再用大量真实案例说明这项技术在客户服务、医疗诊断、创意产出等多个行业的落地实况。作者反复强调，人工智能并非全能解法，更像是一位效率很高却需要审慎协作的伙伴，企业要结合自身业务流程，理性挑选技术路线。

# 前言 为什么生成式人工智能将会改变世界

一项具有变革意义的新技术

• “生成式人工智能正在改写世界格局，仅过去一年，人工智能相关投资就让各大科技公司市值合计增加了超过2万亿美元。”
• “从商业回报看，几乎看不出人工智能对任何领域产生了显著影响。”

这两个看似矛盾的判断能同时成立吗？答案是肯定的，而且它们甚至出自同一篇AI报道。原因在于我们仍处在AI新周期的黎明阶段。

对读者而言，核心问题是：在黎明期，你能做哪些有意义的准备？

当你翻开这本书，你已经迈出重要一步：主动为抓住未来的变革机会做准备。未来十年，人工智能很可能重塑几乎所有学科与行业。如今为即将到来的浪潮所做的准备，都将让你在未来占据有利位置。

正如许多评论者所言，生成式人工智能属于通用技术。通用技术的定义是：

“一种单一且通用的技术，其本质贯穿整个生命周期清晰可辨。它初期具备巨大改进空间，最终广泛普及、用途多样，并产生诸多溢出效应。”

换句话说，通用技术为未来收益提供了跳板，能形成变革与创新的良性循环，构建持续改进的平台，其可能性边界近乎无限。

通用技术的历史表明，我们往往是在事后才看清其本质。这类技术需要数十年才能完全释放价值。如下表所示，无论是电力、互联网还是智能手机，其经济与社会效益从市场渗透率10%到75%都耗费了数十年时间。

现在就领先一步

为何企业感受到通用技术的好处往往要很久？记者阿齐姆·阿扎尔指出，新技术通常经历两个阶段：安装期与部署期。

安装期技术诞生、引发关注，并缓慢融入企业与国家的基础设施。问问父母对电视初印象，许多人最初觉得它不过比收音机好一点。早期使用者买了电视，邻居来围观，随着内容生态形成，频道增多，选择丰富。

部署期则催生内容市场、监管体系与新供应链，从而带来巨大商业机会。一切得益于普及率提升、成本下降与需求增长。生成式人工智能的发展也将遵循这一轨迹。

既然收益要过阵子才显现，为何现在就要行动？因为在瞬息万变的世界里，早期采用者和快速适应者先受益。20世纪90年代到21世纪初，积极投资数字化、把生产运营转向数字化的模拟摄影公司得以存活，有的甚至发展更好。柯达其实在1975年就发明了第一台数码相机，却未能把握其潜力，最终错失良机。

面对生成式人工智能，你绝不愿重蹈覆辙。

# 第一章 什么是生成式人工智能

“未来总会不期而至。”

——乔治·威尔，美国政治评论家

有时候未来真的悄无声息地到来。仿佛不久前，我还在听父母家调制解调器的拨号声，急着在MSN Messenger上和朋友聊天。拿到人生第一部工作手机的兴奋也历历在目——那是一部带触控笔和翻盖键盘的机器。短短20年，开放互联网和智能手机彻底改变了人类生活方式。2023年全球智能手机使用量估计达68亿部，近三分之二人口接入互联网。当年很少有人能预料到这种普及程度，变化在当时显得循序渐进。

但2022年末登上头条的生成式预训练转换器GPT，历史学家可能会另眼相看。2022年11月OpenAI发布ChatGPT，反响震撼。微软创始人比尔·盖茨称其“能改变世界”，并将其与微处理器、个人电脑、互联网和移动电话的诞生相提并论。埃隆·马斯克则带头表达担忧，认为它是“人类文明面临的最大风险之一”。

ChatGPT仅用五天就吸引了100万用户，而Netflix达到这一数字用了三年半。

这一次，未来以剧烈、爆炸的方式到来。人工智能的发展发生根本转变——一场被认为将改变一切的转变。

其实自20世纪40年代起，人工智能就一直是投资与研发的热点。为何直到现在才引发如此轰动？

你需要了解的知识

人工智能是一门让机器模仿人类行为模式的艺术与科学。借助它，计算机处理任务的速度和范围都实现突破，由此释放出巨大可能性。

基于规则的人工智能源于二战时期的密码破译，如今我们已进入全新且极具影响力的生成式人工智能时代。

可以这样想象：过去我们认知的人工智能像一位技艺精湛的翻译，它严格遵循制定的规则和语法，能高效完成语言转换。

而生成式人工智能更像一位精通多国语言、极具创造力的作家。它能用多种语言创作故事和诗歌，展现近乎人类的创造力和多样表达。传统人工智能通过遵循规则和指令完成令人惊叹的任务，而生成式人工智能凭借创造新想法和新内容的能力，带来了全新可能性。

它是如何运作的

1962年，科幻作家阿瑟·C·克拉克提出或许是对创新的最精妙定义之一：“任何足够先进的技术，都与魔法难以区分。”初看之下，那些能让人迈上新台阶的技术，常在人们眼前营造魔法般的震撼。人工智能便是如此。但关键在于，尽管常说人工智能是“黑箱”，我们无法完全理解其逻辑，它并非魔法。所有人工智能技术的诞生，都离不开以下六个主要步骤。

1.数据准备

人工智能以海量数据为基础。数据来源广泛：传感器、文本、视频、图像等。凡你能看见或想象的事物，都可能留下信息痕迹。数据准备就是把这些信息转化为二进制数据，或通过编码完成转换。比如，我的名字用二进制表示如下：

数据需要收集，还需清洗以去除错误、干扰或不一致。数据可能需要标注——明确特定字段的计量单位或数据类型。这往往耗时：当你填写验证码，遇到“点击包含自行车的方块”这类指令，其实就是在做数据标注，这些数据常被用于训练人工智能。不过更先进的模型，如生成式人工智能基石的大语言模型，通常不需要标注。

2.算法部署

下一步是将算法应用于数据。在人工智能领域，这一涵盖面很广的过程被称为机器学习，其形式多种多样，主要包括以下几种。

监督学习：模型在带有标注的数据集中进行训练，通过学习数据来做出预测，例如，判断收件箱中的邮件是否为垃圾邮件。
