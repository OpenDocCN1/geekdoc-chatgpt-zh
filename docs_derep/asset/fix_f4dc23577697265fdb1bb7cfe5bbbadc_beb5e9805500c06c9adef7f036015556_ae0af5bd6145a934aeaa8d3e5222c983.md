4. 案例实操：把提示词变成可落地的谈话方案

我们用一个真实情境演示提示词如何转化为可操作流程。

背景概览
小李读大二，专业计算机科学与技术。过去成绩稳居前列，社团和志愿活动都很活跃。近几个月父亲因病骤然离世，这场重大打击让她的状态明显偏移，原本外向开朗的个性变为沉默寡言、情绪持续低迷，还伴随一些异常行为。

主要心理反应
情绪低落：丧父后长期沮丧，常独坐宿舍或图书馆角落发呆，对外界失去兴趣，易哭泣，课堂上偶有失控。
学业倦怠：原先对专业充满热情，如今动力明显下降，不再参与讨论，作业质量下滑，甚至出现逃考倾向。
人际封闭：主动远离同学朋友，退出社团，基本不回消息，呈现自我隔离趋势。
焦虑失眠：焦虑感持续存在，夜间入睡困难、多梦易醒，白天疲惫，注意力难以集中。

综合判断属于家庭重创导致的创伤性应激，是典型的外在负性刺激引发的心理行为偏移，需要针对性干预。

提问指令
你是一位兼具专业素养与同理意识的教师，致力于为学生提供量身定制的心理支持。请【针对因家庭变故或外部负性刺激出现心理行为异常的学生，开展一次深度且个性化的心理健康谈话】。每一次回应都可能影响学生走向，请保持高度责任感与敏感度，耐心倾听，用温暖陪伴。

为保证质量，请按以下流程进行。
1. 搭建信任并聆听：用温暖关怀的姿态开启对话，让学生感受到支持与被理解。保持高度专注，不打断不评判，用共情去感知情绪需求。
2. 进一步探查感受：借助开放式提问引导学生表达感受与想法。例如“你能具体说说事情是怎么发生的吗？”“这种感受对你日常生活造成了哪些影响？”适时给予反馈，鼓励持续分享。
3. 判断严重程度并帮助自我觉察：基于学生叙述评估问题严重性与可能成因，引导其正视自身困扰，共同探讨应对思路。
4. 给出针对性办法并链接资源：结合个体差异给出建议，如正念练习、同伴互助或专业咨询。重点介绍学校心理咨询室、24小时热线等资源，增强社会支持感知。
5. 共制计划并持续回访：共同制定包含具体步骤与时间节点的行动方案，约定两周内回访，建立长效关注机制，通过定期评估确保效果。

小李同学谈话方案

三、判断与认知引导
状态评估：抑郁情绪、动力缺失、社会功能受损、睡眠问题，提示需要专业支持。
认知引导：把困难定位为成长契机，强调可以一起面对，逐步找回积极体验。

个性化建议：参与学校心理健康活动如讲座、团体辅导以学会情绪调节；预约心理咨询师进行专业辅导；保持与关心朋友的联系，参与轻松活动。
强调支持：说明学校心理健康中心、老师和同学会持续陪伴。

五、行动计划与后续跟进
行动计划：每周参加一次心理健康活动，每周至少三次与朋友联系，每天安排放松时间如散步、听音乐；约定每周五下午固定交流进展。
后续跟进：表示会持续关注，有需要随时找我，办公室随时敞开。
结束语：肯定勇气与坦诚，相信共同努力能走出阴霾，重拾活力。

该方案以建立信任为起点为深入交流奠基。探查阶段用开放式提问引导释放情绪，教师适时反馈让学生感到被理解。评估与认知环节帮助学生正视问题并看到成长可能。建议阶段给出贴合实际的指引并突出校内资源。最后的行动计划与跟进确保干预可持续，充分体现长期关怀。

整体兼具专业性与人文温度，符合学生心理辅导规范。

8.3 家长沟通卡壳？用智能助手转换视角

教师与家长沟通常遇阻力，家长对心理问题的认知偏差、对教师角色的误解容易造成沟通卡点，让教育工作者应对质疑时倍感压力。

智能系统正成为破局助手。通过分析学生心理表现，预判家长的心理状态与核心诉求，智能系统能搭建理解桥梁，为每位家长定制沟通策略，推动家校协同。

沟通关键节点
建立共情联结：用“您最近观察到孩子哪些不一样的表现”这类开放提问，收集家庭观察信息。
症状具体化：记录异常行为的发生频率、持续时长、触发场景。
溯源分析：引导识别应激源，如“近期家庭是否经历重大变化”，评估家庭生态影响。
支持系统评估：了解已尝试的方法，“您试过哪些帮助孩子的方式”，分析效果。
专业资源对接：提供分级支持方案，包括心理咨询、亲友支持小组、学业帮扶等。
协同干预方案：制定短期目标情绪稳定、中期目标社会功能恢复、长期目标心理弹性培养的阶梯计划。
沟通机制建设：建立定期家访、线上反馈、危机预警三级联络制度。
