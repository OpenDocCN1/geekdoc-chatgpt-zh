### 智能导航双引擎：路径平滑与分层寻路实战

游戏 AI 移动的真实感与性能，往往取决于后端两套核心机制的协作：一套负责“修整线条”消除生硬折角，另一套则专攻“宏观调度”化解大世界搜索压力。下文将结合实战代码，逐层拆解这两大技术支柱。

#### 视线裁剪：用几何直觉精简路径点

寻路器吐出的原始节点序列，受限于网格或导航网格拓扑，通常冗余度极高。`smoothPath` 采用**贪婪视线检测**策略，仅保留“拐弯处必经”的关键锚点。

**算法运作要点：**
*   **极简入场**：途经点不足三个时，几何上不存在可优化折线，原样输出。
*   **锚点前瞻**：维护一条已平滑的临时轨迹。从第三个原始节点起跳，尝试用“视线射线”穿透中间节点，直指更远目标。
*   **受阻即定**：射线一旦碰撞遮挡物，意味着刚才跨过的那个节点正是拐角关键，必须落笔确认。
*   **通畅则进**：视线无阻则索引后移，继续贪婪延伸，直到触碰终点前一个节点停手。
*   **首尾呼应**：循环收尾前，别忘了将终点钉死，保证路径拓扑完整。

function smoothPath(inputPath: Vector[]) -> Vector[]:

    # 如果路径仅有两个节点的长度
    # 则无法进行平滑处理，于是直接返回
    if len(inputPath) == 2:
        return inputPath

    # 编译输出路径
    outputPath = [inputPath[0]]

    # 记录在输入路径中的位置
    # 从索引 2 开始
    # 因为我们假设两个相邻的节点将通过光线投射
    inputIndex: int = 2

    # 循环直至找到输入路径中的最后一个项目
    while inputIndex < len(inputPath) - 1:
        # 执行光线投射
        fromPt = outputPath[len(outputPath) - 1]
        toPt = inputPath[inputIndex]
        if not rayClear(fromPt, toPt):
            # 光线投射失败
            # 添加传递到输出列表的最后一个节点
            outputPath += inputPath[inputIndex - 1]

        # 考虑下一个节点
        inputIndex += 1

    # 我们已经到达输入路径的末尾
    # 将末尾节点添加到输出路径并返回它
    outputPath += inputPath[len(inputPath) - 1]

    return outputPath

#### 金字塔搜索：从粗略轮廓到地面细节

面对公里级地图，单层 A* 代价高昂。`hierarchicalPathfind` 构建**多层级抽象图**，实现“高层定战略、低层定战术”的分级求解。

**逐层下钻逻辑：**
1.  **同位快退**：起止重合直接判空，零开销。
2.  **坐标映射器**：维护一对动态节点句柄，记录它们当前所处的抽象层级。
3.  **自顶向下扫描**：从最高层（最粗颗粒度）递减至地面层（Level 0）。
    *   **投影对齐**：调用 `getNodeAtLevel` 将当前句柄映射到目标层级，完成空间坐标系的切换。
    *   **无效层跳过**：映射后若两点重合，说明该层级无决策价值，直接继续下沉。
    *   **单层博弈**：激活当前层级上下文 (`setLevel`)，跑标准 A* 拿到局部路段。
    *   **接力交棒**：**仅截取本层路径的第一步落脚点**，作为下一层寻路的新终点锚点——这步是跨层衔接的核心钥匙。
4.  **落地成果**：循环终止时，手中握着的正是地面层完整可行的连接序列。

function hierarchicalPathfind(graph: Graph,
    start: Node,
    end: Node,
    heuristic: Heuristic
    ) -> Connection[]:

    # 检查是否找到路径
    if start == end:
        return null

    # 设置最开始的节点对
    startNode: Node = start
    endNode: Node = end
    levelOfNodes: int = 0

    # 降低通过图形的层次
    currentLevel: int = graph.getLevels() - 1

    while currentLevel >= 0:
        # 查找在此层次上的开始和结束节点
        startNode = graph.getNodeAtLevel(0, start, currentLevel)
        endNode = graph.getNodeAtLevel(levelOfNodes,
            endNode,
            currentLevel)
        levelOfNodes = currentLevel

        # 开始和结束节点是一样的吗
        if startNode == endNode:
            # 跳过该层次
            continue

        # 否则我们可以执行该路径规划
        graph.setLevel(currentLevel)
        path = pathfindAStar(graph, startNode, endNode, heuristic)

        # 现在采取该路径规划的第一次移动
        # 并使用它作为下一次运行的开端
        endNode = path[0].getToNode()

    # 我们考虑的最后一条路径应该是在层次 0 上的路径
    # 返回该路径
    return path
