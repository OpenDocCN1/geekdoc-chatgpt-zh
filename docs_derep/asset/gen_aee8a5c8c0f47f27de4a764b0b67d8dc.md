**8.3 实现第一个 C++程序“Hello，World！”**

**8.3.1 小故事**

乐乐超市门口装了一块电子显示屏，开门时要滚动播放“欢迎光临乐乐超市”。操作其实很直观：点“设置”，贴上文字“欢迎光临乐乐超市”，再点“确认”，屏幕立刻就亮起来了。

写第一个 C++程序“Hello，World！”和这个操作很像，都是按固定流程把一段文字送到屏幕上。在编程环境里把代码按规范写好并运行，电脑屏幕就会出现“Hello，World！”。

为什么入门程序偏爱“Hello，World！”？

1972 年，贝尔实验室的丹尼斯·里奇和布莱恩·柯林汉在编写《C 程序设计语言》时，需要一个极简的示例，于是选了“Hello，World！”。它不涉及复杂逻辑，只负责输出一行字，就能让读者快速体会“编写代码→得到结果”的完整闭环。这个例子由此流传下来。

此后 C++、Java、Python 等语言的教程几乎都以“Hello，World！”开场。一方面它足够简单，新手能立刻看到反馈；另一方面它能验证环境是否正常。写出“Hello，World！”几乎成了程序员的入门仪式，看到这行输出就知道有人开始学编程了。

**2.执行流程**

从写代码到看到输出，程序要经过几个明确阶段。

（1）预处理阶段。编译器先处理“#include＜iostream＞”。预处理把＜iostream＞头文件里的声明全部拷贝进当前源文件，该头文件里定义了 cout、endl 等对象，使得后续代码可以使用输入输出。

（2）编译阶段。编译器检查语法和语义，把 C++源代码转成汇编代码。会核查 main 的写法、cout 用法是否合规，有错就会给出提示。只有通过检查的代码才能进入下一步。

（3）汇编阶段。汇编器把汇编代码翻译成机器码，生成目标文件。目标文件是二进制指令和数据的集合，还不能直接运行。

（4）链接阶段。链接器把目标文件和所需的库文件合并，生成可执行文件，如 hello.exe。因为用了 cout，需要链接标准输入输出库，链接完成后才形成完整程序。

（5）运行阶段。操作系统载入可执行文件，从 main 开始执行。先输出“Hello，World！”并换行，然后执行 return 0，程序结束。返回值 0 告诉系统程序成功完成。

**8.4.1 初识进制世界**

**1.进制的基本概念**

进制是计数的方法，用一组固定的数码表示数值，满基数进位。

（1）十进制。用 0 到 9 共十个数码，满十进一，如 9+1=10。
（2）二进制。用 0、1 两个数码，满二进一，如 1+1=10。
（3）八进制。用 0 到 7 八个数码，满八进一，如 7+1=10。
（4）十六进制。用 0 到 9 及 A 到 F 共十六个数码，A~F 代表十到十五，满十六进一，如 F+1=10。

**2.二进制的意义**

CPU 内部由数亿到数百亿个晶体管组成，晶体管可导通或截止，对应高电平和低电平，正好映射 1 和 0。硬盘盘片表面有可磁化的微区，磁头可写入两种相反磁极，也对应 1 和 0，读取时还原为二进制序列。

（1）计算机的母语。二进制是处理和存储数据的根本，不懂它就难以进入计算机世界。
（2）编程的基础。位运算、数据类型范围等概念都以进制为根基，跳过进制学习高阶内容如同没学四则运算就解方程。
（3）数字生活的联系。文件大小 1KB=1024 字节、网速 100Mbps≈12.5MB/s 等，都与进制相关。
