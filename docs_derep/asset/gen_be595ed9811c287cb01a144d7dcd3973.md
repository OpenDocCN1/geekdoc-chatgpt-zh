### 5.2 DeepSeek-V3 驱动企业知识库问答实战
企业数据规模膨胀后，纯关键词检索已难以满足复杂查询。基于 GraphRAG 与 DeepSeek-V3 的问答系统能够理解上下文、推理关联，结合实体与图谱给出更精准高效的答案。本节以实操方式讲解如何用 DeepSeek-V3 构建企业知识库问答。

#### 5.2.1 DeepSeek-V3与GraphRAG

##### 1. DeepSeek-V3：国产开源大模型代表
DeepSeek-V3 是人工智能公司深度求索于2024年12月26日发布的开源大语言模型。模型采用 MoE 架构，总参数 6710 亿，单 token 激活 370 亿参数，在 14.8 万亿 token 上完成预训练。在多项基准测试中表现优异，尤其在代码与数学任务上超越多数开源模型，性能接近业界领先闭源模型。

##### 2. GraphRAG：企业知识检索增强方案
RAG 通过融合真实世界信息来提升大语言模型输出质量，是基于 LLM 工具的常见组件。大多数 RAG 方法依赖向量相似度检索，称为基线 RAG。

RAG 在推理私有数据时潜力巨大，例如企业专有研究、业务文档或通信数据。但基线 RAG 在需要整合多片段信息提炼新见解，或处理海量复杂数据做总结理解时，往往力不从心，难以把握大体语义。

为此社区不断改进 RAG。微软研究院提出的 GraphRAG 利用 LLM 从文本构建知识图谱，结合社区摘要与图学习来增强提示。在复杂信息推理上，GraphRAG 相比基线 RAG 提升明显，尤其在智能性方面，更适合私有数据集分析。
