## 全面认识 DeepSeek

### 1.1 什么是 DeepSeek

DeepSeek 由杭州深度求索人工智能基础技术研究有限公司推出，是一款具备强自然语言处理、深度学习与多模态融合能力的人工智能助手，可提供智能对话、精准翻译、创意写作、高效编程、智能解题和文件解读等服务。

1. DeepSeek 的特点

   (1) 模型架构先进

   DeepSeek 采用混合专家 MoE 架构，兼顾高效推理与多任务处理。以 DeepSeek V3 为例，总参数规模达 671B，激活参数 37B，训练开销远低于同类产品，在多项基准测试中表现优异。

   (2) 开源、成本低

   DeepSeek LLM、DeepSeek V3 等多个版本均以开源形式发布，获得全球关注。训练成本显著下降，V3 仅使用约 280 万 GPU 小时，总投入约 557.6 万美元，远低于业内顶尖模型。

   (3) 多模态能力

   系统支持文本、图像、代码等多格式交互，覆盖科技、金融、教育等众多领域。

2. DeepSeek 的市场影响与竞争优势

   (1) 全球影响力

   DeepSeek 于 2024 年迅速走红，登上全球下载榜单。V3 在多项评测中超越 GPT-4o 与 Claude 3.5 等主流模型，展现强劲竞争力。

   (2) 成本优势

   相较 OpenAI 等西方厂商，DeepSeek 训练与使用成本更低，在价格敏感市场更具吸引力。

   (3) 技术创新

   通过 MLA 机制与 MoE 架构，DeepSeek 在低精度训练下实现高效推理，降低硬件依赖。

3. DeepSeek 的应用场景举例

### 4. 并行搜索技术

面对复杂问题，DeepSeek V3 可自动拆解关键词并发搜索，快速呈现多样化结果，显著提升检索效率与响应速度。

### 1.5 文档处理

DeepSeek 在文档处理上具备以下能力。

#### 1. 支持多种格式的文档导入

支持 CSV、Excel、JSON 等结构化数据源导入，也可通过本地文件、数据库、API接入。图片与文档上传后可自动解析文字内容。

#### 2. 文本生成

导入文档后可利用 NLP 能力生成新文本。例如在 WPS 中通过 OfficeAI 插件调用 DeepSeek，选中文本后一键生成，结果可直接写入文档。亦可将 Word 信息提取到 Excel 用于分析整理。

#### 3. 文档校对与润色

DeepSeek 可对导入文档进行校对与润色，提升质量。WPS 插件可实现校对、文案生成与翻译等一体化操作。

#### 4. 自动化办公与协作

支持通过 API 与 Microsoft Office 集成，借助 VBA 或 Power Automate 实现自动化流程。如将 Word 表格导入 Excel 分析，或将邮件内容导入生成摘要。

#### 5. 文档批量处理与导出

可批量上传文档逐一解析并生成总结，支持导出为 CSV、PDF、BibTeX 等多种格式。

### 1.6 与其他顶级 AI 模型的区别

DeepSeek V3 在 MATH-500 测试中准确率达 96.8%，高于 GPT-4o 的 87.3%；在 MATH-1000 中优势同样明显。

#### 2. 代码生成

在代码生成任务上表现优异，能以更低成本获得良好效果。

#### 3. 多模态任务

在 MMLU、MMLU-Pro 等多模态评测中，表现接近或超越 GPT-4o 与 Claude 3.5 Sonnet。

#### 4. 训练成本

V3 预训练消耗 280 万 GPU 小时，总成本约 557.6 万美元，远低于 Claude 3.5 Sonnet 等以数千万美元计的模型。
