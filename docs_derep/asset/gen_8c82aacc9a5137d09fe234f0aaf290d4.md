# 动作调度核心：优先级抢占与并行冲突检测

当新动作介入时，系统首先会清空当前的活动列表，将该动作设为唯一执行目标，并以其优先级作为后续判断的基准线。

若无抢占发生，则进入兼容性校验阶段：系统会遍历所有正在运行的动作，逐一确认它们是否能与新来者并肩作战。一旦发现任意冲突，即刻终止添加流程；若全程无阻，新动作便从等待队列移入活跃集合，并刷新优先级阈值。

活跃池的维护遵循“生死契约”：轮询每个动作，已完成的直接移出，未完成的继续推进执行。

class ActionCombination extends Action:

    # 保存子动作

    actions: Action[]

    function interrupt() -> bool:

        # 如果有任何子动作可以中断，则中断该动作

        for action in actions:

            if action.interrupt():

                return true

        return false

    function canDoBoth(other: Action) -> bool:

        # 如果所有子动作都可以执行，则执行组合动作

        for action in actions:

            if not action.canDoBoth(other):

                return false

        return true

    function isComplete() -> bool:

        # 如果所有子动作都已完成，则可以认为动作已经完成

        for action in actions:

            if not action.isComplete():

                return false

        return true

    function execute():

        # 执行所有子动作

        for action in actions:

            action.execute()

function interrupt() -> bool:

    # 如果第一个子动作可以中断，则中断它

    return actions[0].interrupt()

function canDoBoth(other: Action) -> bool:

    # 如果所有子动作都可以执行，则执行组合动作

    # 如果仅测试了第一个，则可能会出现一种危险

    # 即在序列中间突然发现不兼容的情况

    for action in actions:

        if not action.canDoBoth(other):

            return False

    return true

function isComplete() -> bool:

    # 如果所有子动作都已完成，则可以认为动作已经完成

    return activeIndex >= len(actions)

function execute():

    # 执行当前动作

    actions[activeIndex].execute()

    # 如果当前动作已经完成，则跳转到下一个动作

    if actions[activeIndex].isComplete():

        activeIndex += 1
