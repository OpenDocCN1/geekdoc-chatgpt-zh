三、在小红书做种草：提示词怎么搭

（一）平台特质与推荐逻辑

小红书的三大核心是种草氛围、社区感和垂直专业化。内容分发靠关注流、兴趣标签和搜索发现。关注流对封面图和标题的吸引力要求极高，搜索发现则更重关键词布局和信息完整度。

这些特质对提示词的要求是：
- 社区化与UGC。小红书高度依赖用户自发内容，鼓励分享个人经历、旅行见闻、购物心得。提示词要突出个性化与真实感，引导生成有温度且有辨识度的内容。
- 情感化与共鸣。用户偏爱情绪浓度高的内容，尤其是生活、成长、情感类话题。提示词要促使内容融入温暖真诚的情感，增强认同。
- 视觉优先。图文并茂是基本，图片视频权重高。提示词除了文字，还要为视觉部分提供描述和搭配建议。
- 消费决策导向。平台对购物、测评、品牌推荐影响力大。提示词要引导生成具备推荐价值的内容，激发尝试欲。

（二）内容创作的底层原则

创作关键在于实用性和分享价值、情感共鸣与个性表达，兼顾图文协同和简洁表达，便于快速阅读。
- 重视实用与可分享。提示词要明确要求生成能解决问题的内容或具体的产品生活建议，并具备传播性。
- 强化情感与人设。受众偏年轻，情感化和人设化表达更易吸睛。提示词应引导融入共鸣点和个人视角。
- 文字配合视觉。小红书视觉属性强，提示词要帮助生成能与图片互动的画面感描述。
- 简洁突出重点。阅读场景多为快速浏览，提示词应引导产出标题抓人、正文要点清晰的稿子，避免冗长。
