# 综合治理司法建议的规范写法与 DeepSeek 实操

法院出具的综合治理类司法建议通常由抬头、主体、落款三部分构成。抬头要写明文书名称、建议书编号以及被建议单位。主体先交代工作背景，说明该领域为何必须抓紧推进，随后概括被建议单位已开展的工作及成效，再基于审判执行中发现的短板列出必须重视和解决的问题，继而提出对应的具体对策，并明确回复期限和其他需说明事项，问题与对策要一一对应。落款包括法院印章、法院全称及日期、经办人姓名电话、附件清单及抄送单位；如有附件，应在正文之后、成文日期之前标明序号和名称。与检察机关的社会治理检察建议相比，核心逻辑一致，关键在于调研要深入、指出的问题要切中要害、提出的建议要能真正解决问题。

最后，检查格式是否符合要求，去掉大标题，保持段落连贯，使用正式的法律文书语言，同时确保各部分逻辑衔接自然，案例和法规引用准确。需要确保每个建议都有对应的案例支撑，并且建议措施能够直接回应前面指出的问题。例如，在技术防控手段滞后的问题后，建议引入智能审核系统和强化电子医保卡安全措施，并给出具体实施方案和时间表。
