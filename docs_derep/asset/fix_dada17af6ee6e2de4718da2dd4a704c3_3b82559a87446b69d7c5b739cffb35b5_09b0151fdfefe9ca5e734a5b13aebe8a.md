# 司法公开与诉讼服务痛点与突围

第一，部分信息公开尚留有死角、力度不够。
信息公开的盲区多出现在程序衔接环节，比如仲裁机关向人民法院申请保全、诉讼上诉案件的移送等。这些节点往往牵涉多个部门。以仲裁衔接司法保全为例，当事人须先向仲裁机构递交申请材料，由仲裁机构转交至有管辖权的法院；法院立案部门先行审查，符合条件即予受理并作出裁定，随后转保全部门，由执行员实施保全措施。法律对此未作细化，多靠内部规定或惯例操作，因而法院执行存在随意性，给当事人及其律师带来不便与困扰，甚至被迫通过关系打探进展，滋生腐败风险。

公开力度不足在电子卷宗随案生成与裁判文书写网方面同样突出。全国可实现电子卷宗随案同步生成的法院有2591家，占比75.21%，但中西部部分省份的同步生成率不足五成，有的甚至不到10%。在深度应用层面，可在不同法院间调阅电子案卷的仅2136家，占比62%；合议庭及本院审委会可调阅的有2611家，占比75.79%；具备电子卷宗文字智能识别功能的仅1450家，可借助电子卷宗提取案件信息并自动回填办案系统的仅1255家，分别占全国法院的42.09%和36.43%，而这两项正是智慧审判、减少法官简单重复劳动、提高审判效率的核心。

随案同步生成的技术与管理问题也不少：电子卷宗按材料提交时间或法院生成时间排序，不符合档案管理规范，案件结案后仍需按归档要求重扫，易造成重复劳动；随案生成的电子文档文字识别难度大，识别率低、准确度不足，影响数据利用；部分法院要求业务庭同步扫描卷宗，在案件量大的院所，办案人员负担明显加重。^([\[4\]](#txt010.html#footnote_content_txt010_4)) 裁判文书上网亦存在相近状况。

第二，平台建设缺乏用户体验感。
平台建设的初衷是便民，让当事人和公众便捷获取案件流程、法律知识、诉讼指引以及与法院沟通的渠道，实际建设中却出现重技术轻业务、重业务轻服务的倾向。以诉讼服务网为例，部分法院网站完全由技术人员维护，连基础法律常识性错误也不能及时纠正；维护人员不熟悉业务流程，导致当事人通过门户网站难以顺畅联系法官，信息化未能真正满足群众司法需求。

不少网站服务入口隐在首页边角，不易发现；网站不可用、首页栏目更新滞后、搜索引擎功能落后、首页链接失效、附件无法下载、网页出现错别字等现象时有发生。诉讼服务大厅和12368诉讼服务热线建设中亦不同程度存在上述问题。

第三，各类平台建设缺乏应有的整合度。
法院信息化起步阶段缺乏整体规划与顶层设计，部门间协调不足，导致诉讼服务平台林立、互不衔接，数据无法全面打通，形成信息孤岛。《最高人民法院关于全面推进人民法院诉讼服务中心建设的指导意见》实施后，诉讼服务大厅、诉讼服务网、12368诉讼服务热线初步形成三位一体中心，平台间不协调问题有所缓解，但分工不明、信息重复、数据不统一仍存，影响服务精准性与实效性。

### 三、对策建议
从理论极限看，服务当事人与公众的场景应在电子化网络化基础上向智能化演进。将各类网站平台数据汇聚，通过司法人工智能深度挖掘当事人和社会公众对司法权运行的评价与建议，并与法院管理、司法审判紧密结合。

电子卷宗随案同步生成对内可便利法官及相关主体调卷、提升办案效率、保障卷宗安全、节约司法资源，使内部审判监督前移；对外经授权后，当事人及其代理律师可直接调阅、打印在审和已结案件的电子诉讼卷宗，大幅节省查卷调卷时间，最大程度实现知情权。对当事人评价等留痕数据进行智能分析，可快速找准群众满意度与司法痛点难点，为监督运行、完善管理提供依据。

从现实基线看，应夯实信息公开与平台建设基础。一是扩大公开广度与力度。在信息公开平台设置部门衔接时间节点与进度，如明确一审法院结案后若干日内向上级法院移送卷宗及移送状态，逐步将内部程序惯例可视化、公开化，并制定流程规范、操作细则与罚则，主动接受监督。同时提升技术智能化水平，在电子卷宗随案生成与裁判文书写网中推广自动回填、一键上网，减少司法工作人员额外负担。二是强化用户导向。平台建设要紧密结合一线司法人员业务知识与需求，条件具备时由一线人员指导或直接参与建设，改变重技术轻业务倾向；对有效性与便利性细节提高重视，建立巡查整改机制，改变重业务轻服务倾向。三是整合平台建设。加强顶层设计，扩大数据互联互通，避免重复建设与信息冗余，妥善处理诉讼服务三位一体平台与司法公开四大平台即中国审判流程信息公开网、中国裁判文书网、中国执行信息公开网、中国庭审公开网的关系，使服务当事人、服务律师、服务社会公众各有侧重又有机统一，提升诉讼服务整体效果。

## 第二节　审判管理——以智能分案为例

### 一、基于理论极限的总体审视
分案表面是事务性工作，实为审判管理的源头基础，承载司法效率与公正价值，人工智能的介入并非简单替代，需综合考量具体因素。

若仅按事务理解，可能得出可完全由AI替代的结论。细究可知，分案背后涉及法官绩效考评起点公平、裁判尺度统一协调、虚假诉讼防范、审判资源最优配置等。

就绩效起点公平而言，结案数在传统考评中占核心，因难以对各类案件权重合理估算，串案或简单易办案件如道路交通事故责任纠纷、侵犯生命权健康权身体权纠纷成为法官偏好对象，投入精力少却能获得与疑难复杂案件同等的工分，分案方式直接影响起点公平。

就裁判尺度统一协调而言，关联案件或串案尽量分至同一业务庭或合议庭，不能从根本上消除认识分歧，却能避免因审判主体过大导致的不必要分歧与疏漏，以较低成本实现尺度统一。

虚假诉讼防范关乎司法公器被滥用、裁判公正及第三人权益和社会公共利益。若能在分案阶段通过智能识别预警，可为法官后续处理提供提醒，避免陷入当事人陷阱，减轻办案压力；亦可配合第三人撤销之诉、妨碍民事诉讼强制措施、虚假诉讼罪等制度，降低运行成本。^([\[5\]](#txt010.html#footnote_content_txt010_5))；也能够在一定程度上配合第三人撤销之诉制度、妨碍民事诉讼强制措施、虚假诉讼罪等制度，并减轻了其运行成本。^([\[6\]](#txt010.html#footnote_content_txt010_6))

审判资源最优配置方面，将不同案由分配给对口专业化合议庭，或将个案分配给有专门研究的法官，可显著提升质效，推动专业化建设；亦可基于队伍培养长远考量，审时度势分配案由以弥补短板、丰富业务能力，这也是分案的一种资源配置。

可见，简单事务性替代矮化了AI应用价值，距理论极限尚远。分案背后的价值考量与机制设计更为根本，反映审判管理效率与司法公正贯彻力度，是AI应用重点。

# 分案机制问题与对策

## 第一，分案机制缺乏对系统集成的综合考虑
考察北京地区几家法院发现，分案设计多以案件总体稳健运行为目标，缺乏系统精细化考量。

一种形态为完全人工操作，立案庭按案由分流至各业务庭，再由内勤依据庭室分案办法或惯例拟定方案报领导审批，最终分配至合议庭或法官。此方式占用人力，规范性弱，任意性大，廉政风险突出，如将案件分给与请托人相关法官。^([\[7\]](#txt010.html#footnote_content_txt010_7)) 多数法院正逐步摒弃。

另一种形态为机器随机分案，按对口业务领域法官未结案数进行随机补差，结案快则收案快，仅在回避、串案或关联案件、重大影响案件等特定情形下人工微调。该方式节省人力且具公平性，值得肯定。但特定情形做法仍处经验摸索阶段，不一定科学公正。例如北京市第三中级人民法院曾有惯例将一审案件分给业务庭领导或审判长以上法官，不利于培养年轻入额法官驾驭重大疑难案件能力。^([\[8\]](#txt010.html#footnote_content_txt010_8))

## 第二，分案机制的相关配套建设尚未跟上
分案涉及内设机构设置、制度建设等方方面面。按案由设置业务庭可能抵消分案公平性，如婚姻家事法庭案由办理难度高于劳动争议法庭，先天案由设置与结案数考评已决定分案局限性与考评不合理性，需精细化科学化案件权重测算解决。北京市第三中级人民法院民商融合实践，在很大程度上同质化民事业务庭，辅以随机分案，较好解决了公平分案问题。^([\[9\]](#txt010.html#footnote_content_txt010_9))

公平分案具体要素也不够细致，分案规定或惯例很少涉及虚假诉讼防范。分案经验未上升为全体法官认可的规章制度，机器缺乏对具体公平要素认知与动力，智能化难以提升。

## 第三，分案自身信息技术的费时费力
大量与分案相关信息仍需工作人员手工填写录入，缺乏智能抓取回填，占用大量人力。这既与立案阶段电子化、结构化不足有关，如诉辩材料纸质化、书写模糊、扫描不准、冗余信息多、结构化不足，也与相关技术开发投入不足有关。

## 三、对策建议
从理论极限看，应提高对分案工作认知，把法官绩效考评起点公平、裁判尺度统一协调、虚假诉讼防范、审判资源最优配置等考量融入AI设计研发，将简单替代升华为认知性支撑。

从现实基线看，应着重做好以下工作：

### 第一，系统研判分案背后的要素考量
整体上要把随意性较大的人工分案过渡到机器随机分案，符合电子化网络化智能化规律，亦有助于杜绝分案阶段廉政风险。具体机制需结合地区和法院实际，不宜一刀切。法官绩效考评起点公平、裁判尺度统一协调等要素具有普遍性，可在一定层面统筹设计，避免重复研发。审判资源优化配置方面，专业化建设不足的地区需考虑案由与审判团队匹配性；注重法官民商融合全面能力培养的地区则应考虑不区分案由的随机分案。

虚假诉讼防范一方面要汇聚既往虚假诉讼海量数据，通过人工智能提炼更细颗粒度关联特征，如多发生在亲属或特定联系人之间，套路多为虚构债权债务、钻政策制度漏洞等，建模后应用于当下和未来审判；另一方面要设计机制实现更大系统范围内数据融合，因虚假诉讼案例可能分散于不同法院甚至其他部门，关联案件和串案亦同。

### 第二，健全分案相关的配套制度建设
在审判管理总体思路下统筹内设机构设置与智能分案对应性。民商融合制度下无需考虑专业化庭室和按案由分案机制；专业化人才队伍建设中则需按案由设置业务庭、审判团队并按案由分案，并重点评估不同案由权重赋值，保障分案与考评公平性。将分案实践中摸索出的有益经验^([\[10\]](#txt010.html#footnote_content_txt010_10))逐步上升为规章制度，并通过相关机制如上海市第二中级人民法院成立的法官自主管理委员会^([\[11\]](#txt010.html#footnote_content_txt010_11))获得法官普遍认可，而非由管理者简单决定。

### 第三，完善分案自身信息技术
加强立案与分案技术衔接，确保诉辩材料信息全面准确并符合电子化、结构化要求，便于后续智能分案应用；嵌入自动识别和回填技术，减少不必要的人工录入，节约人力资源。

# 第三节　司法人事——以法官绩效考评为例

## 一、基于理论极限的总体审视
绩效考评指评定者以科学方法、标准和程序对行为主体绩效信息进行观察、收集、整合并作出评价的过程。法官绩效考评即把反映司法品行、司法能力的有关信息指标化、数量化，在一定周期内计算、评估并应用。指标种类越相关、维度越多，体系越科学健全；操作上指标应可定性、可计算，输出相对确定结果，便于后续应用，故与司法人工智能契合度高。

AI优势在于信息维度全面挖掘，可辅助优化考评体系，特别是指标种类增减及内部合理设置；依托科学算法和强大算力，可规模化处理以往难以准确计算或可视化的问题，如不同案由权重赋值对AI并非难事，对人工则难以计算或耗时耗力，以往法院多为简单不区分案由赋值或凭经验赋值。^([\[12\]](#txt010.html#footnote_content_txt010_12))

需注意，AI作为技术工具不能自动生成具有能动性的考评设计方案。法官绩效考评背后涉及价值审视、理想诉求，要回答培养什么样法官、需要什么管理、达到什么绩效等根本问题，涉及法院管理理念、机构设置和制度建设等体制机制，非AI所长。

## 二、基于现实基线的一般考察
《法官法》第41条规定考核内容包括审判工作实绩、职业道德、专业水平、工作能力、审判作风，重点考核审判工作实绩。实践中执法办案是法官第一要务，体现工作实绩的案件质量成为绩效考评重中之重。2008年《最高人民法院关于开展案件质量评估工作指导意见（试行）》确立案件质量评估体系，包括3个二级指标——审判公正、审判效率、审判效果，各下设11个三级指标，具体指标已实现网上自动实时生成，但智能化水平仍待提升，主要包括：

### 第一，对法官绩效考评的“颗粒度”挖掘不够
总体上绩效考评处于一锅炖状态，只能看到法官、合议庭、业务庭或法院层面的结案数、结案率、调解率、撤诉率等数字，看不到其与具体案件内在对应关系，更缺乏以案件或案类为视角的指标体系。职业道德、专业水平、工作能力、审判作风等因缺乏可视化、可量化机制，基本处于你有我有全都有大锅饭状态。如审判效果指标下的公众满意度指标，《案件质量评估工作指导意见》第18条第2项虽可通过问卷调查人大代表、政协委员、廉政监督员、当事人及其代理律师、社会公众收集，但未明确具体社会评价因素，且问卷调查实践不多见、未全面电子化网络化，该指标落实多被泛化或虚置。

### 第二，对法官绩效考评的“关联度”挖掘不够
