当下的语音识别模型通常由声学模型和语言模型两部分构成。

声学模型负责音素的切分与估计。常用方法有 HMM 隐马尔可夫模型和多层神经网络。

HMM 依据状态转移概率及其输出概率分布来估计音素。基于 HMM 的声学模型常借助 GMM 高斯混合模型来确定音素输出概率分布，即用多个高斯概率分布的加权组合来表示。基于决策树的三音素模型也会根据左右音素信息区别对待当前音素。还有通过波形聚类得到自组织特征映射来确定音素的方法。

可以用多层受限玻尔兹曼机堆叠的多层神经网络或深度学习来替代 GMM。HMM 与多层神经网络的混合模型也是可行的替代方案。此外，研究者还开发了基于循环神经网络的语音识别系统（图10-27）。

# 句法分析

文章中存在句法结构，它表示句子中单词间的关系，把握它即可理解含义。以“蓝色翅膀的可爱的小鸟”为例。

掌握句法的机器行为称为句法分析。主要方法有移进-归约分析和基于最小生成树 Minimum Spanning Tree MST 的分析方法（图11-6）。

[PRE9]

图11-6 句法结构与句法分析

移进-归约分析通过移进和归约生成树状结构。移进是把未分析词段的左端第一个词插入树中，归约是把树中右侧两个单词用箭头连接。反复执行即可生成大树。日语只用从右向左归约 reduce-right，英语还会用从左向右归约 reduce-left。

最小生成树方法以单词为节点生成图，为词间关系设分值，保留高分组合创建树。与逐词处理的移进-归约不同，最小生成树一次性处理所有单词，准确度更高但耗时更长（图11-6）。

# 谓词性结构分析

日语用格助词标识名词的语法角色，如主格、领格、补格等。格助词与动词、形容词等谓语的关系称为格助词结构。用谓语和名词性短语即可表意，因此识别句子成分的操作也称谓词性结构分析，日语中可视为格助词分析。京都大学文本语料库 Version 4.0 与奈良先端科学技术大学院大学 NAIST 的语料库均包含格助词关系标注。

# 短语结构分析

除句法结构外，还可用短语结构分析。通过分析词段构成的短语结构掌握句子结构（图11-7），生成动词短语、名词短语、形容词短语、助词短语等树状结构。例如用 N、ADJ、P 表示名词、形容词、助词，后加 P 表示短语，NP、ADJP、PP 分别为名词短语、形容词短语、后置短语。树状结构相当于句法结构，但有时并非唯一，部分语义不明短语有多义。英语主要通过短语结构分析确定句子结构。树状结构底层的单词称为叶节点或终端节点。
