3）变量命名规则

变量名属于 C++ 标识符的一种，用来唯一对应一个变量。实际使用时要遵守以下约定：
（1）可用字符。 只能由英文字母、数字、下划线构成，且首字符不能是数字。比如 count、_value、num123 合法，123var 不合法。
（2）区分大小写。 C++ 对大小写敏感，age 和 Age 会被当成两个不同的实体。
（3）禁用关键字。 不能使用C++的保留字作为名字，如 int、if、for、class 等都不行，C++14 引入的 decltype、generic 等也禁止使用。
（4）禁止特殊符号。 空格、标点、运算符等都不能出现在名字里，例如 my var、var@123 都是非法写法。

4）变量初始化
（1）含义。 初始化就是在声明的同时给出一个初始值，这时内存已分配且变量拥有确定的起点。
（2）价值。 创建瞬间就赋予合理初值是良好习惯，能避免使用未赋值变量带来的不确定行为。

**4.数据类型转换**
C++ 允许不同类型之间相互转换，主要分为显式转换和隐式转换两大类。
1）显式转换
当需要明确指定转换意图时，可使用显式转换即强制类型转换。这是程序员主动要求编译器执行，与编译器自动执行的隐式转换不同。
C++ 中常见的强制转换写法有两种。
（1）兼容 C 语言的风格。
[PRE5]
（2）C++ 特有的函数式写法。
[PRE6]
显式转换不会改变原变量本身，而是基于原值生成一个临时新值，并按目标类型的精度规则进行调整。
[PRE7]
转换方向决定安全性。从范围小到范围大，如 char 到 int、float 到 double，属于安全方向，目标能完整容纳源值，不会丢失信息。从范围大到范围小，如 int 到 char、double 到 float，属于风险方向，可能出现截断或溢出。因此小到大转换相对可靠，大到小转换则需谨慎把控。
2）隐式转换
又称自动转换，由编译器在类型兼容且相对安全时自动完成，无需开发者显式声明。例如程序需要某种类型却提供了另一种类型时，编译器会介入。

bool 仅占 1 字节，向 bool 的隐式转换通常较安全，规则如下。
（1）若源值是 0 或空，如 0、0.0、空指针 nullptr，则转为 false。
（2）若源值是非 0，如 5、3.14、非空指针，则转为 true。
这里的 0 指数值零或空字符 '\0'，而不是字符 '0'，后者的 ASCII 码为 48。示例略。
[PRE10]
当转换可能导致信息丢失、精度下降或逻辑模糊时，编译器会报错或给出警告。隐式转换只是编译器提供的便利，其触发条件隐蔽，容易在混合运算中埋下截断、精度丢失或歧义的风险，排查成本较高。
因此不建议随意依赖隐式转换，优先使用显式转换来明确意图，提升可读性并规避风险，形成严谨习惯。

**5.常量**
常量是指运行期间取值不可改变的量，与可变的变量形成对比。const 是定义常量的核心手段，能提升安全性、可读性与优化空间。
1）引入常量的意义
（1）安全。 防止关键数据如数组长度、固定参数被意外修改，减少缺陷。
（2）可读。 用有意义的名字如 PI 代替 3.14，使意图更清晰。
（3）优化。 const 的值常在编译期已知，编译器可据此优化。
2）常量与变量的差别
（1）变量。 直接声明即可，如 int a；值可随时通过赋值修改，如 a=5；a=10；
（2）常量。 定义后不可更改，需用 const 或字面量声明，强行修改会编译报错。

**6.字面量**
在掌握类型、变量、常量后，需要了解字面量。字面量是直接写出的固定值，无需经变量或表达式计算，编译器可直接识别其类型与数值。
1）核心特征
（1）直接呈现原始数据，无需推导。
（2）类型由语法形式或后缀决定，如 3.14 为 double，3.14f 为 float。
（3）运行期不可修改。
2）常见类型及示例
（1）整数字面量。 支持十进制、八进制、十六进制。示例：100、0144、0x64、100L。
（2）浮点数字面量。 默认 double，f/F 后缀指定为 float。示例：3.14、3.14f、1.23e5。
（3）字符字面量。 单引号包裹，本质为 ASCII 值。示例：'A'、'0'、'\n'。
（4）字符串字面量。 双引号包裹，本质为字符数组末尾隐含 '\0'。示例："hello"、"C++"。
（5）布尔字面量。 true 与 false。
（6）指针字面量。 nullptr 表示空指针。

（1）算术相关。正号 +、负号 -。
（2）自增自减。前置 ++、后置 --。
（3）取地址与解引用。&、*。
（4）逻辑非。!。
（5）类型转换。（类型）。

（1）算术。+ - * / %。
（2）关系。== != > < >= <=。
（3）逻辑。&& ||。
（4）赋值。= += *= 等。
（5）位运算。& | ^ << >>。
