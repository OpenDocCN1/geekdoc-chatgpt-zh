# 第三章
# AI 协同推动前沿教学实践

本章聚焦生成式智能如何助力教员备课，围绕跨学科主题教学、复杂学习任务设计、项目式教学等具体案例展开。阅读后，教员可熟练掌握与智能体对话的方法，体会人机协同的工作形态。可以看到，生成式智能并非替代教员，而是能力延伸的放大器，它会推动教员能力运用的迁移，帮助教员在协同中把握教与学的本质，依托智能的力量打造更符合时代需求、面向未来的素养发展型课程。

## 第一节 认知发展策略与心智模型策略：构建素养发展型课程

生成式智能的出现为教学打开了新空间，也带来新的反思。作为教员，我们会问：用智能辅助教学是否可靠？我还需要做教学设计吗？该如何使用？当学习者问“既然人工智能能把事情做得这么好，我们为什么还要学习？”时该如何回应？

本节讨论上述问题，并对使用智能辅助教学提出提醒，帮助教员积极迎接人机协同的新教学形态。

### 一、智能赋能教学模式的原则

人工智能正在重塑教育创新的图景，也促使教育者深度反思。首先要回答：让智能做教学，可靠吗？答案不仅关乎工具使用，更指向教员专业价值的转型——从知识传授者进化为教育设计师，从经验执行者转向智能协同者。在技术赋能与人文坚守的张力中，未来教育的轮廓逐渐清晰。

**（一）智能可信赖，但需要教员与智能深度协作**

尽管生成式智能在信息检索、资源整理、个性化学习支持方面表现强劲——能迅速生成初步教学方案、辅助批改作业、给出个性化建议，甚至搭建虚拟实验环境——但必须认识到智能本质上是工具，能否用好取决于教员是否深度参与。

智能擅长数据分析与规律发现，却缺乏教员的教育智慧、情感与价值取向。它难以捕捉学习者学习状态、情绪需求、个性特征的细微变化，也无法像教员那样进行情感交流和价值观引导。例如，智能可以写出面面俱到的作文评语，却很难像教员那样洞察学习者写作时的思考脉络与情感并给予有人情味的指导。

因此，使用智能辅助教学时，教员不能放任不管，寄望智能“一键搞定”全部方案。相反，教员需要主动进入智能辅助流程，发挥自身专业优势，与智能紧密协作，才能将智能的能力转化为教学质量提升的动力。

**（二）智能是否在取代教员或削弱教员地位**

并非如此，只是教员能力运用的阵地在转移。过去教学设计要求教员脑中有灵感，再在脑中验证可行性，通过智力劳动转化为可实施方案并不断修改检验，消耗大量脑力。

有了智能辅助，教学设计只需教员脑中有灵感，随后可用口语化、零碎的语言指导智能改进，灵感就能快速落地为可实施方案。所以在人机协同模式下，教员经验更显价值。教学经验、教育直觉、学科专业知识是智能无法替代的，教员要用这些经验指引智能的回答方向，确保应用真正服务教学与学习者发展。

教员的认知劳动强度下降，因为智能能更快获取信息、梳理思路、解决问题。但批判性思维并未减少，智能方案是否可行高度依赖教员的引导。在协同过程中，教员的批判性思维持续发挥，教育智慧持续闪光。就像“能力放大器”，智能放大教员优势，增强信息处理、资源整合与个性化教学支持能力，使教学更高效、更优质，也促进专业成长。

**（三）构建素养发展型课程**

智能发展迅速，不仅改变教学工具，也深刻影响教育理念与人才培养模式。在智能时代，获取知识更便捷，机器在部分知识性任务上甚至优于人类。传统的“填鸭式”教学——教员单向讲授、学习者被动记忆——已难以适应时代，需要：

• 忽视学习者主动性与个体差异。统一内容与评价难以满足不同学习需求与发展潜力。
• 重机械记忆轻理解运用。学习者死记硬背，难以深入理解和灵活迁移。
• 与社会发展和人才需求脱节。培养出的学习者常缺乏解决复杂问题、应对实际挑战的能力。
• 面对复杂挑战时能力不足。需要创造性思维、批判性思维与合作能力时，传统模式培养的学习者往往力不从心。

当机器能高效完成大量重复性、知识性工作时，社会对人才的需求发生根本变化，仅掌握知识技能已不足以立足。过去学习是为了掌握技能、获得工作与报酬，如今机器常能更好完成任务，学习者必然发问“既然人工智能能把事情做得这么好，我们为什么还要学习？”

可见教育重心正从“学习者学什么”转向“为什么学”。美国课程重构中心认为，教育者需重新思考目标，强调批判性思维、创造力、情感智能、道德判断等人工智能难以复制的人类独有能力。让学习者真正理解人的不可替代性，教员必须在与智能的协同工作中体会到独属于人的能力运用，才能在学习者提问时有底气，而非回答“因为考试要考”。

构建素养发展型课程成为必然选择。教育重点须从传授知识转向培养综合能力，重新思考“教”与“学”的意义，把关键素养置于教学目标中心。认知发展策略与心智模型策略正是构建素养发展型课程的重要理论基础，二者从不同角度揭示学习规律与认知发展规律，为设计更有效的素养课程提供指导。接下来深入了解这两种策略，并讨论如何借助智能运用它们。

### 二、认知发展策略说明

认知发展指个体在思维、推理、问题解决、决策等方面能力的逐步提升，涉及记忆、注意力、语言等多个方面。认知发展策略基于认知发展心理学：皮亚杰提出儿童认知经历感知运动期0-2岁、前运算期2-7岁、具体运算期7-11岁、形式运算期11岁以上四个阶段；维果茨基基于社会文化理论强调社会互动对认知发展的重要性，特别是最近发展区，以及语言符号系统作为思维工具对高级心理功能的影响；信息处理理论解释注意力、记忆策略、问题解决能力的演变，指出随年龄增长选择性注意、持续注意时间、复述与组织策略使用提升，元认知与问题解决灵活性增强。这些理论认为，认知发展是逐步成长、主动建构的过程，受个体认知结构与外部社会文化环境共同影响。

**（二）基于最近发展区的认知发展策略**

维果茨基提出“最近发展区”即学习者当前实际水平与在他人帮助下可能达到的潜在水平之间的差距，通俗说“跳一跳，够得着”。由此衍生支架式教学，即教员或更有经验的学习伙伴依据学习者当前水平与需求提供恰到好处的外部支持，并在能力提升过程中逐步撤除，最终使学习者独立完成挑战性任务。

智能可结合学习者现有知识与认知能力，辅助教员设计有适当挑战的任务，并根据表现动态调整难度与支架类型，真正实现最近发展区的教学应用。例如，学习者独自面对复杂问题时，仅能查到答案，通过答案反推解决过程帮助不大。智能可在分析题目后逐步提供提示、线索、分解步骤等支架，帮助学习者在脚手架辅助下最终独立完成，经历思考过程后面对类似问题更得心应手。

更复杂的应用需信息技术支持，包括语音识别、面部表情识别、脑电传感、大数据与学习分析等，多维度收集数据以追踪学习者情感与认知状态变化，从而更及时精准了解学习过程、动态调整教学支架。我们已看到不少尝试，未来支架式教学在促进公平、高效、个性化学习环境构建中将持续发挥关键作用，为不同年龄与背景学习者提供更丰富多元、更精细精准、更富启发性的学习支持。

**（三）基于多元智能理论的认知发展策略**

霍华德·加德纳提出的多元智能理论包含8种智能类型，强调学习者的个体差异与全面发展，要求教学进行个性化方案设计、多样化教学方法，着重培养多方面技能。

班级授课制下教员布置统一学习内容，为适配不同层次学习者提出分层作业，但教员精力有限往往只能设计最多三个层次。智能在多元智能教学实践中可通过测评工具、学习行为数据分析辅助教员初步了解学习者的多元智能优势倾向，为因材施教提供参考。进而提供定制化学习路径与内容推荐，如对语言智能突出者推荐更多阅读写作任务，对空间智能突出者提供更多图形化、空间化学习资源。随着技术发展，智能已能越来越成熟地为学习特征不同的学习者提供差异化资源与任务。

### 四、使用智能辅助的教学提醒

智能辅助教学虽有诸多好处，实际使用中教员也易陷入误区。了解误区并掌握应对方法，才能更好发挥智能价值，避免“好心办坏事”。

**（一）误区一：期望一次性完美结果**

部分教员对智能期望过高，认为只需简单输入指令，智能就能“一键搞定”完美教学设计方案直接使用，看到回复后失望，随后放弃使用，认为智能不过如此。事实上智能并非万能，需要教员专业指导与持续调整优化。人类完成任务也需思考、解读、拟定计划、查阅资料、不断修改，期望智能一次性给出完美结果，就像期望一个人一字不改写出好文章一样不现实。

**（二）误区二：智能幻觉现象**

“智能幻觉”指智能生成内容时可能出现编造、不准确或与事实不符的信息。因为智能本质是基于概率预测生成，而非真正理解与推理，因此幻觉现象无法完全避免。若教员忽视风险直接使用智能生成内容，可能误导学习者，损害教学准确性与严谨性。正如美国华盛顿州出版的*Human-Centered AI：Guidance for K-12 Public Schools*所强调，以人为本的人工智能学习环境永远优先考虑学习者、教员和管理人员的需求、能力与经验，始终以人工输入与探究开始、以人工反思与编辑结束。智能被视为支持工具来处理、生成或分析信息，而非替代人类判断与决策的方式。

为避免误区高效利用智能辅助教学设计，教员应遵循三步：

**1.明确目标**

开始前深入思考并明确需求——这次教学活动的核心目标是什么，希望培养学习者的哪些核心素养。把目标细化具体，形成清晰的任务指令，才能为智能提供明确工作方向。

**2.检查回复**

智能生成回复后，教员需检查评估而非直接使用。从内容准确性、是否符合教学目标、是否适合学习者情况、教学情境是否可行等多方面验证，判断哪些信息有价值、哪些需改进。

**3.整合回复**

智能回复只是初步方案或素材，教员需结合专业经验与教学智慧整理、修改、优化，形成最终教学设计。在实际教学中，还可根据学习者反馈与教学效果不断调整优化，提升教学质量。
