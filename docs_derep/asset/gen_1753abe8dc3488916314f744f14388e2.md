直流步进两用驱动板能够同时带动两路直流马达，分别记作 M1 与 M2。A、B 两路端口可接入 PWM 脉宽调制信号来调节转速，若不需要调速，可直接将 A、B 拉到 5V 让电机保持最高转速，即把跳线帽短接。转向控制比较直观，M1 的 IN1 处于高电平且 IN2 处于低电平时电机正转，电平对调则反转；M2 的控制逻辑相同，IN3 高 IN4 低时正转，反之则反转。A 口对应的 PWM 控制 M1 的速度，B 口对应的 PWM 控制 M2 的速度。

# 活动四：PWM 调速原理

PWM 调速的核心是脉冲宽度调制，即借助微控制器的数字输出去控制模拟电路，广泛应用于测量、通信、功率控制与变换等领域。PWM 以控制简便、灵活度高、动态响应快的优势，成为电力电子中最常用的控制方式之一。

PWM 通过改变占空比来等效不同的电压水平，从而调节加在电机两端的有效电压实现调速，波形示意如图 2-5-3。

### （1）超声波测距原理

超声波工作原理如图 2-6-1。模块包含发射端与接收端，发射端发出超声波后开始计时，声波在空气中约以 340m/s 传播，遇到障碍物反射后被接收端捕获，停止计时，总耗时为 t。设模块到障碍物距离为 H，往返总路程为 2L，发射与接收器间距为 2M，可推导出相关关系式。

### （2）HC-SR04 超声波传感器

本章避障小车使用 HC-SR04 超声波传感器。工作要点如下：
1）用 I/O 口 TRIG 触发测距，给出至少 10us 的高电平；
2）模块自动发送 8 个 40kHz 方波，检测是否有回波；
3）有回波时通过 I/O 口 ECHO 输出高电平，高电平持续时间即为超声波往返时间，距离 = 高电平时间 × 声速 /2；
4）使用时发送一个 10us 以上高电平触发，随后在接收口等待高电平并计时，低电平到来时读取时间计算距离。
