扣子实战全景：单 Agent 到 AI 应用落地路径

扣子把大模型通用能力通过可视化编排、节点串联与数据接入，变成可直接上线的生产工具。先看平台能力框架，再以夸夸机器人的案例演示搭建逻辑。

Plugin 机制实现外部服务接入 Agent。平台自带常用 Plugin，也支持自建 Plugin 把第三方接口封装成可调用工具，例如新闻 Plugin 用于抓取资讯，网络搜索工具用于查询公开信息。

流程编排用来处理多步骤逻辑。用户能拖拽任务节点来拼接执行顺序，提升 Agent 在复杂任务上的效率。

触发机制让 Agent 在指定时间点或条件满足时自动运行，无需人工启动。

Knowledge 为模型补充外部信息，提升答案可用性与正确性。
· 文本类 Knowledge 支持以片段为单位检索召回，模型结合召回结果生成最终回复，适用问答场景。
· 表格类 Knowledge 可在指定列匹配，也支持自然语言转 SQL 查询与计算。
· 图片类 Knowledge 兼容 JPG 等常见格式，可通过标注实现检索召回。

Memory 体系弥补对话轮次限制，提供可反复调用的长期记忆，让互动更具个性化。
· 变量可保存语言偏好等用户属性，使回复更贴合。
· 数据表提供轻量结构化数据的存取方式，支持自然语言写入查询，并可开启多用户模式实现读写权限控制。
· 长期记忆模拟人脑对用户信息的累积，支撑个性化回应。
· 文件盒子实现多模态素材的合规存储、管理与复用，Agent 可多次调用已保存内容。

语音交互在文字之外提供声学通道，平台提供多套音色供挑选。

#### 3. 设计能力
Card 是一种特殊的消息呈现形式，可对 Agent 生成内容的展示形态做自定义。平台允许把 Card 绑定到 Workflow、Plugin 等组件上。

#### 4. 发布渠道
搭建完成的 Agent 可分发到多端。当前支持上架官方商店、模板库、第三方应用、API、SDK，或接入自建的第三方渠道。

#### 5. 运营与运维
预览与调试区可做在线验证与调优。用户可和 Agent 对话，根据反馈调整配置；若线上出现命中偏差、延迟或无响应，也可在该区查看执行明细进行排障。

已发布的 Agent，开发者可通过分析看板跟踪运行。看板提供用户规模、意图访问、消息使用等指标，支撑定向优化。

### 5.1.3 使用扣子搭建智能体工作流
Workflow 是一组可执行指令的集合，用于实现业务逻辑或完成特定任务。它为应用与 Agent 的数据流转和任务处理提供结构化框架。核心是把大模型能力与具体业务逻辑结合，用流程化方式实现高效 AI 应用。

扣子提供可视化画布，支持拖拽节点搭建，并在画布内实时调试，直观看到数据流向与执行顺序。

#### 1. 工作流与对话流
平台提供两种形态。
（1）Workflow workflow：处理功能型请求，通过顺序执行任务实现功能。适合自动化数据处理，如生成行业调研报告、制作海报、制作绘本等。
（2）Chatflow chatflow：面向对话场景的特殊 Workflow，适合处理对话类请求。通过对话交互实现复杂业务逻辑，常用于聊天机器人、个人助手、智能客服、虚拟伴侣等。

#### 2. 节点
节点是 Workflow 的基本单元，每个节点代表独立步骤或逻辑，负责数据处理、任务执行与算法运行，均具备输入输出。

每个 Workflow 默认含开始节点与结束节点。开始节点定义启动所需输入参数，结束节点返回运行结果。通过引用节点输出可将节点串联成操作链，例如让代码节点使用大模型节点的输出，在画布上可见两节点相连，如图 5-5 所示。

### 5.1.4 使用扣子开发 AI 应用
AI 应用是基于大模型技术构建的应用，能执行复杂任务、分析数据并做决策，如 AI 搜索、AI 翻译等。

#### 1. 用扣子开发的 AI 应用能做什么
基于扣子开发的应用可扩展性强，可绑定个性化界面，依托大模型形成独立解决方案。通过 Workflow 或 Chatflow 实现复杂业务逻辑，内置节点库覆盖逻辑处理、Knowledge 写入检索、大模型服务、会话管理等，帮助灵活编排自动化流程。

应用可适配移动端与网页端多种框架，也能兼容各类终端。支持以 API 服务或 Chat SDK 形式集成到现有产品，也可发布为微信小程序、抖音小程序，或投放到社交平台，甚至部署为 Web 页面供更广泛用户访问。

#### 2. 开发流程
（1）创建 AI 应用项目。在扣子新建项目，创建后自动进入扣子应用 IDE，用于业务编排与配置。
（2）编排业务逻辑。可用 Workflow 编排流程，并通过变量、Plugin、Knowledge 库、数据库等与本地或线上数据交互，平台提供试运行功能便于调试。
（3）设计用户界面。提供丰富组件与可视化编排界面，支持拖拽快速搭建，所见即所得。组件可与资源数据和事件绑定，实现前后端联动，非专业开发者也能上手。
（4）测试应用。提供预览功能，实时验证运行效果是否符合预期。
（5）发布应用。开发测试完成后可发布到各平台，扩大用户覆盖。

#### 3. 开发环境
扣子提供线上集成开发环境扣子应用 IDE，支持可视化编排与调试，让开发者聚焦创意与业务实现。

扣子应用 IDE 由业务逻辑模块与用户界面模块组成。

### 5.1 线上智能体开发
线上智能体开发平台通常具备可视化界面，无需深入底层算法与代码细节即可快速搭建，降低门槛。支持聊天机器人、虚拟助手、自动化流程等多种形态，提供丰富预训练模型与算法库供灵活选用与定制，并提供便捷部署选项，可快速发布到不同终端与场景，同时具备监控管理能力，实时监测运行状态与性能指标并优化，提升开发效率与质量，加速落地。

借助扣子的可视化设计与编排工具，开发者可用零代码或低代码方式快速搭建基于大模型的各类 AI 项目，满足个性化需求并实现商业价值。

本节以字节跳动的扣子开发平台为例，介绍如何搭建单智能体、工作流和 AI 应用。选用扣子的主要原因是：
（1）工作流设计灵活。扣子的 Workflow 可处理逻辑复杂且稳定性要求高的任务流，提供大量可组合节点，包括大模型、自定义代码、判断逻辑等，均可通过拖拽搭建。例如可创建撰写行业研究报告的 Workflow，让 Agent 自动输出报告。
