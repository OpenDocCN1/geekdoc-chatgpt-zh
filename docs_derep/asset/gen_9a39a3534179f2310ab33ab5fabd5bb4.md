二、构成类图表

用于呈现整体中各部分占比或分布情况。

- 1. 饼图 Pie Chart
   - 作用：反映单一维度数据的占比，突出部分与整体的关系。
   - 适用：市场份额分布、家庭支出比例、用户来源渠道占比。
   - 注意：分类不要太多，建议小于 6 类，避免占比相近时难以分辨。

- 2. 环形图 Doughnut Chart
   - 作用：与饼图原理相近，中间区域可放置核心指标或标题。
   - 适用：对美观性要求更高的占比展示，如仪表盘设计。

- 3. 堆叠柱状图/堆叠面积图
   - 作用：对比不同类别下各子类别的占比，同时观察整体走势。
   - 适用：各产品线在不同季度的销售额构成、用户年龄段的区域分布。

- 4. 瀑布图 Waterfall Chart
   - 作用：展示数值由起点到终点的增减过程和变化路径。
   - 适用：财务利润构成分析、库存变动追踪。

图 6-2 构成类图表

三、分布类图表

用于分析数据的分布特征，包括集中趋势、离散程度和异常值。

- 1. 直方图 Histogram
   - 作用：展示单变量数据的频数或频率分布。
   - 适用：用户年龄分布、考试成绩分布、订单金额分布。

- 2. 箱线图 Box Plot
   - 作用：呈现数据的中位数、四分位数、异常值及分布范围。
   - 适用：不同群体收入分布对比、产品质量稳定性分析。

- 3. 散点图 Scatter Plot
   - 作用：分析两个连续变量之间的相关性或分布规律。
   - 适用：广告投入与销售额的关系、身高与体重的关联性研究。

- 4. 热力图 Heatmap
   - 作用：用颜色深浅表示矩阵中数值的大小。
   - 适用：用户行为分析中的页面点击热区、时间序列数据的密度如每小时订单量。

- 5. 密度图 Density Plot
   - 作用：平滑展示数据分布的概率密度。
   - 适用：人口密度分布、流量峰值区间分析。

图 6-3 分布类图表

四、关系类图表

用于揭示数据间的关联、层级或流动关系。

- 1. 桑基图 Sankey Diagram
   - 作用：展示流量或资源在多个节点间的流动路径与规模。
   - 适用：用户转化路径分析、能源供应链追踪、资金流向可视化。

- 2. 树状图 Treemap
   - 作用：通过面积大小体现层级数据的占比关系。
   - 适用：文件系统存储分布、公司组织架构与人员占比。

- 3. 网络图 Network Graph
   - 作用：呈现节点实体与边关系之间的拓扑结构。
   - 适用：社交网络关系分析、知识图谱可视化、供应链网络映射。

- 4. 和弦图 Chord Diagram
   - 作用：展示双向流动关系或矩阵数据的交互强度。
   - 适用：国际贸易流量、用户跨平台迁移路径。

图 6-4 关系类图表

五、地理空间类图表

面向与地理位置相关的数据呈现。

- 1. 填充地图 Choropleth Map
   - 作用：用颜色深浅表示不同区域的数值差异。
   - 适用：各省 GDP 对比、疫情感染率分布、人口密度地图。

- 2. 点分布地图 Point Distribution Map
   - 作用：用散点或标记标示地理位置上的事件密度。
   - 适用：连锁店位置分布、交通事故热点区域分析。

- 3. 流向地图 Flow Map
   - 作用：用箭头或线条表示地理空间中的移动路径。
   - 适用：物流运输路线、人口迁移轨迹、航班航线可视化。

六、高级与特殊用途图表

- 1. 漏斗图 Funnel Chart
   - 作用：展示流程各阶段的转化率或流失情况。
   - 适用：用户注册转化率分析、电商购物车流失环节诊断。

- 2. 甘特图 Gantt Chart
   - 作用：展示项目进度与时间安排。
   - 适用：项目管理、任务排期跟踪。

- 3. 词云 Word Cloud
   - 作用：用文字大小体现关键词出现的频率。
   - 适用：用户评论高频词分析、社交媒体话题挖掘。

1. 目标驱动：明确分析目标是对比、分布、趋势、构成还是关系。
