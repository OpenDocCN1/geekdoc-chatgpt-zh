# 第7章

## 实战B：生活管家与私域运营

AI从办公助手走向生活场景和私域运行时，意义就变了。核心不再是工作提速，而是一个能长期陪伴、持续协同的智能管家。

### 7.1 智能家居中控：AI驱动的家庭联动

智能音箱局限于放歌查天气时，你有没有想过让它兼任家庭服务器的运维大脑？灯光如果只会定时开关，是不是太可惜了——服务器重启时自动调暗，用亮度暗示系统状态，这才叫真正的智能联动。

OpenClaw 是一个开源且可编程的个人 AI 平台，正好把这些设想落地。它既懂自然语言，又能依靠 Skills 调用外部系统，对 Home Lab、Home Assistant、Prometheus 等进行一体化操控。

#### 7.1.1 Skills：智能家居可扩展的核心

Skills 堪称 OpenClaw 的核心。每个 Skill 实际上是一份符合规范的 Markdown 文档，向 AI 声明三件事：

- 能处理哪些任务，作用是什么
- 如何触发它，所需命令、API 或环境变量
- 执行时的行为边界与规则

收到指令后，AI 会按意图自动匹配合适的 Skill 并按内定义的方式执行。这种模块化思路让 OpenClaw 的能力可以持续扩充，同时每个 Skill 体积小、相互独立，不会占用大模型的上下文额度。
