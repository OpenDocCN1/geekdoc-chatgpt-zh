# ### 3.3 结构化提示词的应用与局限性

结构化提示词是优化人机交互的有效手段，凭借清晰逻辑和模块化设计，大幅提升任务效率与准确度。但它并非万能，仍存在边界。下面从使用场景、局限以及在推理模型上的表现展开。

# #### 3.3.1 应用场景

结构化提示词逻辑分明，在以下场景价值突出。

**1. 复杂任务**

指需多步完成的任务，如数据分析、项目管理、流程设计。

优势在于借助模块化 Workflow 对任务拆解，让模型按序完成子任务，避免遗漏。

示例如下。
# Role: 数据分析师
## Workflow
1. 数据清洗：剔除缺失值与异常值。
2. 数据分析：产出关键指标与趋势图。
3. 报告生成：输出含图表与结论的分析报告。

# ## 生产级场景

适用于企业级应用，如客服、自动化内容生成、技术支持。

优势是提升提示的可读性与复用性，便于协作与迭代；同时让开发者快速定义角色行为，降低试错成本。

示例如下。
# Role: 客服机器人
## Rules
1. 始终保持礼貌专业。
2. 遇到无法回答的问题时建议转人工。
## Workflow
1. 解析用户问题。
2. 提供解决办法或相关信息。
3. 问题超出范围时给出替代路径。

# # 3. 教学与学习

为新手提供友好学习模板，帮助快速掌握提示编写。

优势是结构化设计让新手清晰理解提示构成与逻辑，降低入门难度，如带注释的模板。

示例如下。
# Role: 教师
## Profile
- Description: 善于用通俗方式讲清复杂概念。
## Rules
1. 使用通俗易懂的语言。
2. 举例辅助理解。
## Workflow
1. 分析学生的疑问。
2. 解释概念并配示例。
3. 检查理解程度并视需调整讲解方式。

# ## 3.3.2 局限性

结构化提示词的不足主要体现在3点。

### 1. 模型能力依赖

效果高度依赖模型的指令遵循能力。
- **GPT-4** 能较好理解并执行复杂结构化提示。
+ - **GPT-3.5** 表现偏弱，可能无法完全遵守规则或流程。
- 更早期的模型则可能失效。解决办法是按模型能力调节复杂度，对弱模型简化结构、减少模块。

### 2. 复杂性限制

对能力较弱的模型，结构化提示可能导致信息过载，反而拖累效果，出现忽略部分内容或输出偏离预期。应对方式如下。
+ - 简化提示，删减冗余模块与规则。
- 用更直接的语言描述需求。
- 通过示例法明确目标，减轻推理负担。

### 3. 无法解决基础问题

结构化提示无法根治模型的固有问题。
- **幻觉问题**：生成虚假或不准信息。
- **知识陈旧**：知识截止于训练时间，无法获取最新信息。

即便提示设计精细，仍可能输出错误或过时内容。缓解方法如下。
+ - 针对幻觉，在 Rules 中增加约束，如“任何情况下不得编造事实”。
- 针对知识陈旧，结合外部工具如API调用或数据库查询获取最新信息。

# ### 3.3.3 推理模型的结构化提示词

随着模型理解力提升，如 DeepSeek-R1 等高性能模型，部分场景下对结构化提示的依赖在下降。高性能模型可凭少量指令自主推理复杂问题，只需提供充分背景即可产出准确合理的输出，从而简化提示设计。

不过基础技巧仍不可少，例如：
(1) **明确指令**：清晰表达任务需求，避免偏离。如明确限定“生成不超过500字的总结报告”。
(2) **示例参考**：提供输入输出示例，帮助模型对齐目标与预期。如给出相似任务的参考答案作为推理模板。

在简化结构的同时，需关注背景完整性和指令精准性，以充分发挥高性能模型的推理能力。

注意第2章提到，对推理模型如 DeepSeek-R1，建议在提示中直接指定“思考步骤”，除非希望模型严格按步执行。

# ### 3.4 本章小结

**(1) 结构化提示词的核心**：层级化与模块化设计，提升可读性与性能。
**(2) 优势与应用**：在复杂任务与生产级场景中展现强大适应性与灵活性。
**(3) 编写方法**：构建全局思维链、保持语义一致、结合优化技巧、实践模板化。
**(4) 局限性**：需按模型能力调整复杂度，并结合实际需求优化设计。

# ## 4.1 人格分类模式

面对复杂问题与多样需求时，单一思维容易受限。人格分类模式正是为此设计，通过模拟不同人格特征，让 DeepSeek 多视角剖析问题，提供更全面科学的方案。

# ### 4.1.1 什么是人格分类模式

人格分类模式允许 AI 根据场景和需求展现多样化性格与专业特长。可理解为给 DeepSeek 换上不同“帽子”——有时是严谨专家，有时是幽默创作者，有时是耐心老师，从而获得更贴合场景的回答。

**为何需要？** 现实中我们常需多角度看问题。制订商业计划时需要专家分析数据；头脑风暴时需要创意人格激发灵感。人格分类模式满足这种多样化需求。

核心特点：
+ - **灵活切换人格**：按需求选择视角。
+ - **多样化回答**：同问题给出多维度解法。
+ - **场景化应用**：适用于商业决策、教育指导、创意策划等。

# ### 4.1.2 主要人格类型

可实现多种人格，每种都有明确特点与适用场景。以下为4类主要人格。

# #### 1. 专家型人格

角色定位为专家。特点：
+ - 知识深厚，回答严谨准确。
+ - 擅长从数据与逻辑出发分析问题。
+ - 重视细节，能发现潜在风险与优化点。

适用场景：
+ - **商业分析**：需严谨数据与市场洞察。
- 科技咨询：需深度技术剖析。
- 风险评估：需预测方案隐患。

示例提示词：
作为资深机器学习专家，请评估该算法方案的可行性与潜在问题。

# ### 2. 教师型人格

角色定位为耐心教育者。特点：
+ - 讲解通俗易懂，化繁为简。
- 循序渐进引导学习。
- 善用举例增强理解。

适用场景：
+ - **教育培训**：把专业知识转为易懂内容。
- 新手指导：帮助快速上手技能工具。
- 科普讲解：将复杂科学概念通俗化。

示例提示词：
> > 请以初中数学老师身份，用通俗语言解释什么是二次函数。

# 3. 创意型人格

角色定位为创意思考者。特点：
- 思维发散，多角度提出新想法。
- 创意丰富，擅长联想与突破框架。
- 结合趋势提出前瞻性创意。

适用场景：
- **营销策划**：需要新颖方案。
- **产品设计**：需要创新功能。
- **内容创作**：需要独特灵感。

示例提示词：
请以创意总监身份，为一款环保主题产品想出5个独特营销创意。

# 4. 辩论型人格

角色定位为理性辩手。特点：
- 逻辑严密，观点论证清晰。
- 善于正反两面分析。
- 重事实数据，避免情绪化。

适用场景：
+ - **观点论证**：深度剖析某观点。
- 决策支持：全面权衡利弊。
- 辩论准备：准备正反方论据。

示例提示词：
**请从正反两个角度分析人工智能对就业市场的影响**。

# ### 4.1.3 人格切换技巧

可根据需求灵活切换人格，甚至组合使用。示例：

**第一步：创意型人格头脑风暴，激发新思路。**
