# 新闻体提示词拆解与实战

自己写活动复盘和媒体通稿时，我常回用到一套自用指令，暂称“新闻体写作专家”。下面把这套指令是怎么搭出来的拆开讲，示范可迁移的提示词设计思路。

## （1）细节补充法

做提示词先把角色讲清楚，再把特质填满。想让模型扮演“新闻体写作专家”，首先要回答：到底什么算新闻体。
不同人答案不一样，模型心里那个专家也未必是我们想要的。于是需要给它一个可执行的定义，示范思路如下：
你现在是“新闻体写作专家”，专精用新闻稿的规范写法产出稿件。
新闻体的基本画像可以归纳为：
❑ 表达庄重得体，偏好行业用语与数据佐证，凸显可信与专业。
❑ 框架分明、逻辑顺畅，按时序或轻重排序，可覆盖背景、主线、嘉宾、栏目、主办方等多个单元，每个单元都有主旨句带支撑句，避免堆砌与跳跃。
[PRE0]
❑ 情绪偏向积极，用肯定褒奖的措辞对活动、嘉宾、栏目与主办方给予高度认可，传递热情与信心。

一个落地小技巧：若自己说不清风格要点，可先把一篇喜欢的范文丢给模型，让它提炼写作特征，再把提炼结果写进指令。用 AI 训练 AI，思路通用。

## （2）范例对齐法

特征描述往往偏抽象，比如“正式”“专业”“清晰”“积极”，模型很难自发落到文字。此时给范文做校准会更有效。完善后的指令会补充：
“新闻体”风格参考样本：
1. 某区委主办、某研究院承办的研修班在科学城开班，特邀南方日报科技版主编主讲科技创新与品牌建设，60余名企业与公益负责人参与，围绕前沿趋势与社会责任展开讨论。
2. 数字化推进下，云计算与人工智能重塑办公方式，大数据成为决策支点。研讨环节中，行业分析师从智能服务定位讲到数据流程优化，强调服务质量与分析效率要同步；并结合不同运营阶段与行业特性给出落地建议，提出服务供给要贴合业务与技术、方案设计需兼顾个性化、智能化与安全性。

## （3）推理引导法

模型与人相似，复杂任务求一步到位容易出错，放慢节奏分步推演反而更稳。

1）思维链提示。对计算、逻辑、推理类任务，让模型先写出中间步骤。常用说法有：
❑ [主体指令]，请把推理过程详细写出来。
❑ [主体指令]，请一步一步想。

2）逆向应用示例。前文的范例法也可以用思维链的推导过程来充实。举例汽车油耗问题：
思考步骤模板：
问题：[问题描述]
思考步骤：
[第一步思考]
[第二步思考]
[第三步思考]
…
答案：[最终答案]
示例一、二的推导过程略过。
现在，请解决以下问题：
问题：一辆汽车油箱容量为60升，平均每100公里耗油8升。如果现在油箱是满的，这辆车最多可以行驶多少公里？
[PRE1]
一步一步写出中间推演，正確率明显提升。

## （4）格式分隔法

写指令时把不同语义的功能块分开，模型理解更顺。常用分隔方式：
❑ 三引号：""" 这里是需要分隔的文本 """。
❑ XML 标签：< 引文 > 这里是引用的文本。
❑ Markdown 代码块：''' 这里是需要分隔的内容 '''。
❑ Markdown 标题：# 一级标题、## 二级标题、### 三级标题。
❑ 连续符号：---、+++ 等。

### 把话说清楚的完整样例

把细节、范例、分隔整合起来，一套完整的“新闻体写作专家”指令大致包含：角色定位、风格定义三要点、两段风格样本、以及写作任务与素材输入。示例中要求用新闻体改写8月12日甲丁科技公司联合玉舍街道社区举办“关爱老人进社区”活动，介绍反诈知识与智能反诈App，为老年人金融安全护航，并在中文输出、Markdown分段的前提下完成。

**2.3** 结构化提示词

#### 2.3.1 结构化思维
上面那套新闻体指令有一个短板：格式与内容不够结构化。
结构化在日常写作中很常见，写论文就要遵循统一的排版与层级规范。标题用什么字号、层级怎么编号、图表如何标注，都是结构化要求。提示词同理，结构化能让层级更清晰、阅读更顺畅。作者云中江树在此基础上提出结构化提示词方法论，并开源为 LangGPT 项目供参考。
[PRE4]

#### 2.3.2 结构化提示词与一般提示词对比
早期的结构化更多是思维层面，提示词形式上仍显松散。以 CRISPE 框架为例，CR 设定能力与角色，I 提供洞察与上下文，S 说明任务，P 设定个性风格，E 做实验操作。用该框架写出的指令仅展示内容骨架，缺少模板化表达。
LangGPT 给出的结构化模板则采用 Markdown 标记：
# Role（角色）：诗人
## Profile（角色简介）
- Author：云中江树
- Version：1.0
...
[PRE5]
## Rules（规则）
1. 内容健康，积极向上。
2. 七言律诗和五言诗要押韵。
## Workflow（工作流程）
1. 让用户以“形式：[]，主题：[]”的方式指定诗歌形式和主题。
2. 针对用户给定的主题创作诗歌，包括题目和诗句。
## Initialization（初始化）
作为 <Role>，严格遵守 <Rules>，使用默认 <Language> 与用户对话，友好地欢迎用户。然后介绍自己，并告诉用户 <Workflow>。
[PRE6]

#### 2.3.3 7 种结构化提示词框架
在结构化基础上，把常见框架模板化，可大幅提升创作效率。日常工作中，工作总结就是典型模板：标题、工作回顾、经验教训、成长收获、工作计划。
本节介绍 7 种进阶提示词框架，掌握后可快速提升 AI 创造力并形成生产力。框架最初多为内容思路，经 LangGPT 方法结构化后，便于直接套用。
1. 角色扮演框架
角色扮演是最简易上手的写法。向模型指定职业与擅长领域，让它按角色完成任务。

适用场景包括专家咨询模拟、创意写作、角色对话生成、产品迭代、市场策略制定等。优点是直观、快速进入场景；缺点是输出易缺乏结构，复杂任务处理能力有限。
