规则驱动的知识图谱推理，本质上是先搭建数据底座，再让规则引擎把隐含事实补全，最后用路径打分和概率模型做量化判断。

第一步是环境准备。先创建一个空白的默认模型，随后加载本地规则文件初始化通用规则推理器，最后把两者组合成推理模型，整个基础栈就搭好了。
[PRE0]
Model m = ModelFactory.createDefaultModel();

Reasoner reasoner = new GenericRuleReasoner(Rule.rulesFromURL("file:rule.txt"));

InfModel inf = ModelFactory.createInfModel(reasoner, m);

有了推理能力，关系就能透过多步链式传递被发现。以家庭关系为例，先有小明与小红的夫妻连接，再从小红出发关联到小小，形成两跳路径。
[PRE1]
小明 → 小红 (妻子是) → 小小

规则引擎的工作就是把这种两跳间接证据合成为直接事实，从而直接得到小明与小小的父子关系。
[PRE2]
小明 → 小小 (孩子有)

为了统一描述这种多跳推理，我们把一条推理链记作一系列三元组的序列，从起点逐步走到终点。
[PRE3]
P = T₀→T₁→... →Tₙ₋₁→Tₙ.

单条路径的可信度并不是凭空得来，而是递归累积。每一步的得分会基于上一层所有可能中间体的得分以及在对应关系下的转移概率进行加权求和。
[PRE4]
sᵢₚ(e) = ∑ (下标e'∈range(P)) sᵢₚ'(e')(e')·P(e|e'; r_l)

实际预测中往往存在多条不同模式的路径。整体得分是所有相关路径得分按学习到的权重线性组合得到，不同路径贡献不同。
[PRE5]
score(h,t) = ∑_{p_i∈P_r} θ_i S_h,p_i(e) = θ_1S_h,p_1(e) + θ_2S_h,p_2(e) + … + θ_nS_h,p_n(e).

把得分映射到概率上，采用sigmoid函数将实值分数转换为该三元组成立的概率估计。
[PRE6]
p(r_i = 1|score(h_i,t_i)) = \frac{exp(score(h_i,t_i))}{1 + exp(score(h_i,t_i))}

训练目标则是最小化加权对数损失，根据样本标签正负调整权重，使模型在正例上提升概率、在负例上降低概率。
[PRE7]
l_i(θ) = w_i[y_i ln p_i + (1 - y_i) ln(1 - p_i)].
