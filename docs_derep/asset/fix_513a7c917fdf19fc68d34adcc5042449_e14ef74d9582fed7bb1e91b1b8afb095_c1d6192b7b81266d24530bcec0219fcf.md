## 5.5 Nano Banana Pro：人设锁定与场景自由切换

以 Gemini 3 Pro 为核心引擎打造的 Nano Banana Pro，最多可同时接入十张参考图，帮助创作者稳住角色外形与素材风格，实现对画面的精细掌控。

传统生成工具在单幅成图上表现尚可，一旦进入漫剧或短片的连贯制作流程，便容易暴露短板：不同镜头里同一人物面貌漂移，道具细节难以还原，文字与界面常出现糊化或错位，多图拼接显得生硬，对镜头语言的理解也偏弱。Nano Banana Pro 的升级正好回应这些痛点，指令解析更到位，叙事把握更稳，画面连贯性明显增强，多图融合的自然度提升，文字与界面元素的可读性也达到更高水平。

下面用几个实操案例说明具体用法。

### 5.5.1　三视图生成

Nano Banana Pro 在语义理解、逻辑把控与视觉统一度上表现突出，特别适合产出标准化的角色三视图。它能读懂复杂的服饰描述与风格设定，一次输出即可得到可直接落地的数字资产。

示例指令如下。

一张详细的角色设计图，角色三视图（包含正面、侧面、背面），纯白色背景，无阴影。

主体：一名 16 岁的滑板少年，戴着橙色的针织冷帽，黑色卷发。身穿宽松的国潮印花卫衣（印有醒目的醒狮图案），下身是多口袋工装束脚裤，脚踩高帮运动鞋，手里抱着一块涂鸦滑板，脖子上挂着头戴式耳机。

面部：圆脸，有些许雀斑，大大的眼睛，表情调皮自信，张嘴大笑。

风格：2.5D 波普插画风格，色彩饱和度高，线条清晰明快，不仅限于写实，带有一点 Q 版盲盒的质感，适合手办设计或 3D 卡通渲染。

尺寸比例 16 : 9。
