## 安装验证：跑通首个张量流程序
新建脚本 `verify_tf.py`，写入以下测试逻辑：

```python
import tensorflow as tf
hello = tf.constant('Hello, TensorFlow!')
sess = tf.Session()
print(sess.run(hello))
```

运行 `python verify_tf.py`，若控制台输出 `Hello, TensorFlow!`，即表明运行环境已就绪。
