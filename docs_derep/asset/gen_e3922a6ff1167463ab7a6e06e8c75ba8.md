### 10.1 MCP 成为智能体对接外部的统一通道

#### 10.1.1 MCP 概览

MCP是Anthropic主导并开源的标准协议，用于规范应用向大模型供给上下文的方式。

它好比智能体的通用接口，像USB-C统一了设备与外设的连接，MCP也在大模型与外部数据、工具之间建立了统一的交互规范。

若把大模型视作智能体的“大脑”负责理解与决策，MCP则相当于赋予它“感知与行动”的能力，让它可以读取环境、调用工具并与现实世界动态互动。

#### 10.1.2 MCP 架构拆解

MCP采用经典的客户端-服务器结构，包含Host、Client、Server三层，如图10-1。

1. MCP Host
MCP Host是整体的入口，通常是直接面向用户的智能体程序，例如Cursor IDE、Claude Desktop等支持MCP的工具。其核心职责是与MCP Client建立连接，并通过MCP向外部数据源或工具发起调用。

2. MCP Client
MCP Client位于Host与Server之间，负责消息的标准化传递和工具调用。它是桥梁，保证数据交换规范且一致。

3. MCP Server
MCP Server是轻量级服务程序，通过统一接口对外暴露特定能力，如工具调用、资源访问、提示模板等。它把外部服务接入MCP生态。

#### 10.1.3 MCP 生态进展

2025年3月，OpenAI 官方宣布正式支持MCP。

2025年4月，阿里巴巴在北京“AI势能大会”上发布阿里云百炼平台成为业界首个全生命周期MCP服务，上线首批集成高德、无影、Fetch、Notion等50多个阿里及第三方MCP服务，覆盖生活信息、网页浏览、内容生成等场景。阿里同时开放开发者自研自发MCP Server模块，提供零门槛体验。

2025年4月，腾讯云升级大模型知识引擎，支持调用MCP插件含自定义插件。平台已上线腾讯云EdgeOne Pages、腾讯位置服务、Airbnb、Figma、Fetch等多个MCP Server，涉及网页部署、位置服务、信息获取等。

2025年4月，百度智能云推出国内首个企业级MCP服务，首批开放超1000个MCP Server供企业和开发者选用。

MCP应用生态仍在快速演进，本章将演示多项实操，真正释放潜力的关键仍在于个人的实践与创造。大模型本身令人兴奋的往往是它在特定场景下的价值创造，把大模型与MCP结合可以打造既实用又有创意的智能体。

### 10.3 用 Cursor+MCP 复现 Manus

Manus由创业公司Monica推出，是通用AI智能体产品。2025年3月6日内测版发布，可自主完成从规划到执行的全流程任务，如简历筛选、房产分析、股票研究等。

本节讲解Manus的复现思路及具体步骤与案例。

#### 10.3.1 Manus 复现思路

整体上Manus通过规划、执行、验证三阶段完成任务。复现时可为各阶段选择合适的MCP Server实现功能。

以撰写2024—2025赛季CBA季后赛最新分析战报为例，三阶段与MCP Server协作如下。

1. 规划阶段：通过MCP Server明确需求并拆解任务 如定义分析框架、数据源优先级。
2. 执行阶段：调用MCP Server抓取数据 实时比分、球员统计 并生成战报初稿。
3. 验证阶段：利用MCP Server核验数据一致性 如交叉验证多源数据 并输出最终报告。
