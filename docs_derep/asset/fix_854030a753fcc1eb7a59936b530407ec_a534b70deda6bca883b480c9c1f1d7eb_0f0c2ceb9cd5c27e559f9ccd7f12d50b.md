Faiss 实战选型：IVF、PQ、IVF-PQ 如何搭配

向量库一旦放大，Faiss 基本成为标配。这次我用两组随机数据做验证，先以 1 万条 128 维向量做快速摸底，再用 100 万条 126 维向量做压力测试，结论比较明确：粗排靠 IVF，压缩靠 PQ，两者叠加是线上常用做法，分片则给横向扩展提供了另一条路。

小样本下 IVF 与 PQ 表现趋同
先搭一个 IndexIVFFlat，聚类桶设 100，搜索时探测 10 个桶。训练写入后取 Top5，首位长期落在 2734 附近，距离在 1.27 左右，后面依次是 9985、7356、5621、3459，距离集中在 1.27~1.28 区间。

换成 IndexPQ，数据规模不变，8 维子向量 8bit 量化，流程保持一致。查出的前五名排序与 IVF 几乎一致，距离仅在小数点后出现轻微抖动。可看出在数据量不大时，量化带来的召回损失很小，而存储和查询效率的收益很明显。

调参方向很直接：桶数和探测一起加
把倒排桶数从 100 提到 200，探测从 10 提到 20，重建后查准感更稳。桶越细分、探测范围越广，召回提升越明显，同时耗时也会线性增长，实测中这个取舍非常清晰。

百万级场景多级索引更稳
数据提到 100 万条、维度 126 后，纯 IVF 成本偏高。改用 IndexIVFPQ 把倒排和量化叠起来：倒排 1000 个桶，PQ 切成 16 个子向量，每个 6bit。训练并写入后把 nprobe 设为 20，Top5 典型结果是 963427、453769、127354、765234、112234，距离大致落在 1.43 到 1.47 之间，说明多级方案在百万量级仍能稳定返回邻居。

分片并行提供另一种扩容思路
把 100 万向量均分 4 份，每份 25 万，分别建独立的 IndexIVFFlat，桶数保持 1000，单片探测用 10 保证速度。各片独立训练写入后，对同一查询逐片取 Top5，再做全局索引偏移校正并合并排序。合并后的全局前五与 IVF-PQ 结果一致，说明分片在保持一致性的前提下可以横向提速。

小结
万级验证里 IVF 平面与 PQ 在召回上差别很小，后者更省存储。放大桶数和探测能有效提升查准。百万级生产场景，IVF-PQ 性价比最高，分片则提供更灵活的水平扩展路径。选型时以数据规模、延迟要求和内存预算为核心，三者配合基本能覆盖大部分检索需求。

import numpy as np

import faiss

# 设置随机种子和大规模数据集

np.random.seed(42)

dimension=126 # 向量维度

num_vectors=1000000 # 大规模数据集

data_vectors=np.random.rand(num_vectors, dimension).astype('float32')

# 查询向量

query_vector=np.random.rand(1, dimension).astype('float32')

# Step 1: 构建多级索引(倒排索引+产品量化)

num_clusters=1000 # 聚类数量

index_ivf_pq=faiss.IndexIVFPQ(faiss.IndexFlatL2(dimension), dimension, num_clusters, 16, 6)

# IndexIVFPQ参数: dimension(向量维度), num_clusters(倒排聚类数), 16(PQ的子向量数), 6(每个子向量的量化位数)

# 训练多级索引

index_ivf_pq.train(data_vectors) # 必须先训练索引

index_ivf_pq.add(data_vectors) # 添加数据

print("多级索引(倒排+产品量化)已添加向量总数:", index_ivf_pq.ntotal)

# 设置nprobe参数增加搜索精度

index_ivf_pq.nprobe=20 # 在20个聚类中搜索

# 执行查询, 查找Top-k最近邻

k=5

distances_pq, indices_pq=index_ivf_pq.search(query_vector, k)

print("\n多级索引(倒排+产品量化)查询结果(Top 5最近邻): ")

# Step 2: 使用分片策略构建索引

# 将数据分为若干分片, 每个分片构建一个独立索引

num_shards=4

shards=[faiss.IndexIVFFlat(faiss.IndexFlatL2(dimension), dimension, num_clusters) for _ in range(num_shards)]

# 将数据分配到各个分片

for i, shard in enumerate(shards):

    shard_data=data_vectors[i * (num_vectors // num_shards): (i+1) * (num_vectors // num_shards)]

    shard.train(shard_data)                 # 每个分片单独训练

    shard.add(shard_data)

    shard.nprobe=10                         # 设置较小的nprobe, 提升各分片内的查询速度

    print(f"分片 {i+1} 已添加向量数量:", shard.ntotal)

# 通过分片执行查询

results=[]

for i, shard in enumerate(shards):

    distances, indices=shard.search(query_vector, k)

    # 记录分片中的结果

    for j in range(k):

        results.append((indices[0][j]+i * (num_vectors // num_shards), distances[0][j]))

# 排序并返回整体Top-K结果

results=sorted(results, key=lambda x: x[1])[:k]

print("\n分片索引查询结果 (Top 5最近邻): ")

for idx, dist in results:

    print(f"全局向量索引: {idx}, 距离: {dist:.4f}")
