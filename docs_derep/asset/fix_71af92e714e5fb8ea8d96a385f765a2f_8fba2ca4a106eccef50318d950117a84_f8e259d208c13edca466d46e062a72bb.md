## 3.2.2 SearXNG：开源聚合搜索引擎的深度应用

在介绍完面向 AI 优化的商业方案博查后，本节介绍开源社区里较为流行的免费替代方案 SearXNG。

与博查侧重搜索质量的深度加工不同，SearXNG 是一款元搜索引擎。它可以同时向 Google、Bing、DuckDuckGo 等数十个上游引擎并发请求，实现广度覆盖，并对汇总结果进行去重与重排序。

SearXNG 的核心特性如下。

- 隐私与可控性：支持私有化部署，搜索数据完全由开发者掌控，有效避免商业引擎追踪。
- 高兼容性：提供标准化 API，能轻松集成到各类 LLM 编排框架中。
- 高度可定制：允许自行配置上游引擎列表、搜索分类及结果过滤规则。

SearXNG 属于自托管工具，需要自备服务器私有化部署。接下来将分别探讨 Docker 部署流程及 Python 调用接口的实现。

下面说明几个关键参数。

### （1）安全加固（Capability）类的参数

- `--cap-drop ALL`：移除容器内所有默认特权，最大程度降低潜在风险。
- `--cap-add`：精准补充必要权限，如 CHOWN 允许修改文件所有权、SETGID/SETUID 允许进程身份切换。

### （2）日志管理相关的参数

通过 `--log-opt` 限制日志文件总大小不超过 1MB，防止日志堆积占满磁盘。

### （3）端口与挂载的参数

- `-p 18080:8080`：把容器内部 8080 端口映射到宿主机的 18080 端口。
- `-v ...:/etc/searxng:rw`：将本地 data 目录持久化映射到容器配置路径，并赋予读写权限。
