数据采集的常见入口

（6）API 获取：API 即应用程序编程接口，是一套规则与协议，用来界定不同软件之间如何交互与交换数据。借助 API 采集数据是行之有效的做法，可让程序直接向其他系统、服务或平台索取信息，特别适合需要从外部网站或服务拉取资料的场景。

（7）专业数据库查询：专业数据库是面向特定领域的资源库，汇集了大量文献、研究成果与统计信息。各类学科对应不同的库，例如 PubMed 覆盖生物医学与生命科学，Web of Science 属于综合性学术库，万得数据库则聚焦金融数据服务。各库各有优势，为研究人员、学生和专业人士提供关键信息支持。

（8）公开数据源：此类数据集由政府、机构或个人免费公开，可在公共数据库、开放政府数据平台等渠道获取。优点是免费且覆盖面广，常用于教学、研究与公共政策分析。选用时需留意数据的质量、准确度、时效性，以及相应的使用条款。

（9）传感器数据：传感器能够感知并测量物理量，结合目标对象即可采集温度、湿度、压力、位置、速度等参数。传感器数据体量庞大、采集频率高且类型多样，处理时要兼顾实时性、准确性与安全性。

不同取数方式各有特点与适用范围，选对方法直接决定数据的质量与相关性。

**4. 数据收集的标准流程**

基础流程如下。

（1）明确研究问题与目标：在正式采集前先厘清待解决的问题与预期目标，从而确定需要采集的数据类型。

（2）设计研究方法：确定采用何种方式获取数据，可能包括问卷、访谈、观察、实验、爬虫或专业数据库查询等，选择需与研究问题和目标相匹配。

（3）制定采集计划：编制详细方案，明确采集方式、所需资源、时间安排，并涵盖样本选择、采集工具如问卷设计等内容。

（4）选择抽样方法与样本：依据研究性质挑选合适的抽样方式。分析师常用四种：简单随机抽样、分层抽样、整群抽样、系统抽样，各有优劣。此环节对保证数据代表性与准确性至关重要，选对方法才能从目标群体中获得可推广的样本。

（5）执行数据采集：按计划开展工作，可能涉及发放回收问卷、访谈、实验实施、爬虫编写等。过程中需持续关注数据质量，高质量采集是得出有效结论的前提。

（6）数据清洗：采集回来的数据通常需预处理，包括录入、修正错误或不完整回答、编码开放式问题等。清洗本质是消除错误与不一致，确保准确。包括修正明显错误如拼写、范围错误，处理缺失值是填补、删除还是保留，识别并处理异常值。清洗质量直接影响后续分析。

（7）评估数据质量：在每个预处理步骤后都要评估质量，检查是否完整、一致且能支撑研究问题。重点评估样本代表性，即样本是否充分反映总体的多样性。若发现偏差，可能需要补充抽样或调整方法。

以上框架完整，可根据具体研究需求灵活调整。

**3．数据增强**

数据增强是通过让有限数据产生更多等价样本来扩充训练集的技术，是解决深度学习数据稀缺问题的关键，尤其在医学影像分析中常见。它能提升训练集规模与质量，帮助构建更强模型。计算机视觉中常见方法有几何变换、颜色调整、旋转翻转、噪声注入、卷积核滤波、图像混合、随机擦除、缩放平移等，多由 imgaug 等库支持。基于深度学习的增强如特征空间增强、对抗生成与 GAN 方法进一步提升多样性。

自然语言处理的数据增强更具挑战，小改动可能导致语义偏差。常用方法包括同义词替换、随机插入交换删除、语法树替换，NoiseMix 与生成对抗网络也能生成多样文本。回译与无监督扩增同样提供多样性与质量。

目前 ChatGPT 也可用于数据增强，已被证实能有效提升模型泛化与生成质量。通过生成与原集相似的新样本加入训练集来扩充数据。例如情感分类任务中加入 ChatGPT 生成文本可提升准确率 2%~3%。在推荐系统中加入模拟用户历史记录的文本也能提升准确性与多样性。最新研究还探索将 ChatGPT 生成数据用于 GAN，结果显示可显著增强生成质量与稳定性，显示出广泛应用前景。
