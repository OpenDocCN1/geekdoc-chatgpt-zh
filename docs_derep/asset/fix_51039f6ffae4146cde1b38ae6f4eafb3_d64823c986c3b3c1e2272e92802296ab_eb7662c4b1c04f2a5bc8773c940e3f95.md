#### （二）情感共鸣提示语

商业文案里，情感共鸣直接影响购买行为，是品牌传播的重要杠杆。情感营销的研究认为，决策往往先被情绪推动，再由理性补位。因此在借助模型写文案时，准备能触发情绪反应的指令，是实现高效情感营销的关键路径。

共鸣的本质是理解与传递。理解指创作者要贴近受众的情绪需求与心理状态；传递则靠合适的语言和叙事手法点燃情绪。设计指令时应结合心理学与叙事学，让模型产出更具感染力的内容。表6-2归纳了共鸣特质与对应的指令做法。

| 文案共鸣特质 | 指令设计做法 |
|---|---|
| 1. 基调清晰 | 在指令中明确指定文案需要呈现的核心情绪词 |
| 2. 多感官描绘 | 要求使用视觉、听觉、触觉等感官描写词 |
| 3. 场景代入感强 | 提供具体的使用或品牌情境设定 |
| 4. 情绪层次丰富 | 设计由基础情绪向高级情绪递进的结构 |
| 5. 共情式叙事 | 指引采用故事化表达呈现品牌价值 |

表6-2 共鸣特质与指令设计

示例指令：

为 [品牌名称] 写一篇品牌故事，目标是实现深度共鸣。请按以下结构执行：

（1）情绪基调（20字内）：明确文案要传达的核心情绪，如温暖、激励、惊喜。
要求：基调需与品牌调性高度契合。

（2）开场场景（80字内）：描写一个与品牌高度相关的日常画面。
要求：至少融合两种感官描写，如视觉、听觉、触觉。

（3）问题-情绪-解法（150字内）：
- a. 点出受众在该场景下的痛点或挑战（30字内）。
- b. 刻画由此产生的情绪反应（40字内）。
- c. 展示品牌如何解决问题并转化情绪（80字内）。
要求：各小点均需包含明确的情绪关键词，情绪呈递进关系。

（4）价值主张（50字内）：用有感染力的语言说清品牌核心价值。
要求：兼顾理性价值与情感价值。

（5）共鸣高潮（100字内）：描绘使用后的理想状态或美好憧憬。
要求：可使用比喻或隐喻提升感染力。

（6）共情结语（30字内）：写一句能引发读者共情的号召。
要求：使用第二人称，增强代入感。

补充要求：
- 文案需有完整起承转合的故事线。
- 巧妙植入三到五个与核心情绪相关的成语或谚语。
- 使用排比、对偶等修辞提升节奏感。
- 整体情绪值控制在0.6～0.8之间，以VADER词典评估，保持积极但不夸张。

#### （三）行动引导提示语

商业文案的最终目的多为促使用户行动，如购买、注册或分享。认知到行动之间存在阻力，如何用文案帮助用户跨越，是行动导向文案的核心。在模型辅助写作时代，设计能推动决策与行动的指令，是提升转化的关键。

行动引导的核心是说服与激励。说服靠充分的理由与证据，激励靠动力与紧迫感。表6-3总结了行动引导特质与对应的指令策略。

| 文案行动引导特质 | 指令设计做法 |
|---|---|
| 1. 行动指向明确 | 在指令中指明期望用户采取的具体行为 |
| 2. 紧迫感强烈 | 要求加入限时优惠或稀缺信息 |
| 3. 起步门槛低 | 设计一个简单具体的首步动作 |
| 4. 收益表述清晰 | 要求明确列出行动后的具体获益 |
| 5. 社会证明 | 要求加入用户评价或数据佐证 |

表6-3 行动引导特质与指令设计

示例指令：

为 [产品/服务名称] 写一则促销文案，目标是驱动用户立刻行动。请按以下结构执行：

（1）抓注意力标题（30字内）：创作醒目标题。
要求：包含行动词与具体数字，如“立省30%”“7天见效”。

（2）行动目标说明（20字内）：清晰表述期望行为。
要求：用祈使句，动词具体，如“立即订购”“现在注册”。

（3）核心利益三点（每点30字内）：列出行动后的主要好处。
要求：利益具体可量化，与受众需求直接相关。

（4）紧迫感营造（50字内）：营造不立即行动就会错过的氛围。
要求：使用限时或限量策略，给出明确截止时间或数量。

（5）社会证明（2~3条，每条25字内）：提供用户评价或数据。
要求：包含具体数字与真实感受。

（6）低门槛首步（40字内）：设计一个简单易行的第一步。
要求：操作难度低，降低心理阻力。

（7）行动号召（15字内）：写一句有力的召唤语。
要求：使用“立即”“马上”“现在”等强行动词。

（8）遗憾规避（30字内）：描述不行动可能带来的损失。
要求：用对比手法突出行动与不行动的差异。

补充要求：
- 文案中加入两到三个与紧迫感相关的成语或谚语。
- 使用问句式小标题增强互动。
- 对关键信息做视觉突出，如加粗、下划线。
- 整体紧迫感以错失恐惧指数评估，目标7~8，足够紧迫但不过度焦虑。

### 二、营销策划提示语方法

当前营销环境下，有效的策划决定品牌成败。竞争加剧、注意力分散，如何打造差异化创意、精准传播与可落地方案成为关键。借助模型优化策划流程已成为提升效率的新趋势。

高质量策划指令的核心是创新、精准与可行。创新要求激发模型创造力产出独特概念；精准要求引导制定符合受众与市场的传播策略；可行要求生成的执行方案具备实操性。

#### （一）创意概念提示语

设计能引导模型产出独特性强、相关性高、易记且具情感触发力的创意概念，帮助生成既能脱颖而出又与品牌价值和受众需求高度契合的内容，并易于传播。

理论要点：优秀创意应具备独特性、相关性、记忆点、情感触发、时效性。

方法要点：
1. 跨领域联想：要求结合不同领域元素激发独特创意。
2. 品牌DNA融入：明确品牌核心价值确保相关性。
3. 记忆点设计：要求创作朗朗上口的口号或视觉元素。
4. 情感地图构建：基于受众核心情感需求设计创意元素。
5. 趋势融合：指示将热点话题与品牌特性结合。

示例指令：

为 [品牌名称] 设计创新营销创意，用于推广其 [具体产品/服务]。请遵循要求：

（1）核心创意：结合品牌所属领域与另一个看似不相关领域的元素，提出独特概念。
（2）价值融入：说明创意如何体现品牌的 [核心价值1] 和 [核心价值2]。
（3）记忆点：创作朗朗上口的口号或标语，需含双关或文字游戏。
（4）情感触发：基于目标受众画像的 [核心情感需求]，设计引发强烈共鸣的元素。
（5）时效挂钩：将创意与 [当前热门社会话题] 联系，突出时效。
（6）呈现形式：提出两到三种呈现形式，至少一种创新或非传统媒体。
（7）传播潜力：解释创意具备病毒式传播潜力的原因。

补充要求：
- 创意要突破常规，避免争议或负面解读。
- 考虑可持续性，思考如何发展为长期营销主题。

#### （二）传播策略提示语

设计目标明确、受众精准、渠道多元、内容匹配且互动性强的传播策略指令，确保信息有效传递并促进深度互动。

理论要点：目标明确、受众精准、渠道多元、内容匹配、互动性强。

方法要点：
1. 目标量化：要求设定具体可衡量的传播目标。
2. 受众画像详述：提供人口统计、行为特征、痛点、媒体习惯。
3. 全渠道思维：要求设计包含至少五个渠道的传播矩阵并说明理由。
4. 内容形式多样化：为不同渠道设计匹配的内容形式。
5. 互动机制设计：提出提升参与度的线上线下互动方式。

示例指令：

为 [品牌名称] 的 [营销活动名称] 设计全方位传播策略，在多元媒体环境中精准触达并达成目标。请遵循要求：

（1）市场洞察（800字内）：总结目标市场的三个关键趋势与两个主要痛点。
（2）受众画像（1000字内）：描绘二到三个核心群体，含人口特征、行为习惯、价值观、媒体偏好，为每个群体起昵称。
（3）传播目标（600字内）：设定三个SMART目标，涵盖知名度、参与度、转化率，并附数字与时间。
（4）核心信息（500字内）：提炼一个总体信息与三个支撑信息，与品牌调性一致。
（5）全渠道矩阵（1500字内）：设计含至少七个渠道的矩阵，说明作用与预期效果。
（6）内容策略（1200字内）：为三个主要渠道设计差异化策略，含形式、主题、互动元素，并匹配用户旅程。
（7）创新传播手法（800字内）：提出一个创新或非常规传播方式，提升话题性与参与度。
（8）KOL合作计划（700字内）：设计多层次合作策略，区分头部、中腰部、微观层级。
（9）时间线（1000字内）：绘制为期 [具体时间] 的传播时间表，含预热、启动、高潮、持续阶段，标注关键节点。
（10）效果评估（600字内）：设定五到七个KPI，涵盖曝光、参与、转化、品牌健康度，说明数据来源与评估频率。
（11）危机预案（500字内）：列出两到三个可能风险及应对策略。

预算分配建议：按渠道与阶段列出比例，确保资源最优化。

#### （三）执行方案提示语

设计指令时需确保生成的方案步骤清晰、职责明确、时间可控、资源合理且风险可控，帮助制定可操作的行动计划。

理论要点：步骤清晰、职责明确、时间可控、资源合理、风险可控。

方法要点：
1. 行动分解：要求将执行过程拆分为十到十五个具体步骤并标明耗时。
2. 角色分配：为每个环节分配负责角色或部门并明确职责。
3. 时间节点：制定含准备期、执行期、评估期的详细时间表并标注里程碑。
4. 资源分配：列出人力、物力、财力需求并给出数量或预算。
5. 风险评估：识别三到五个风险点并提出应对策略。

示例指令：

为［品牌名称］的［营销活动名称］设计详细可行执行方案，将创意与传播策略转化为具体行动。请遵循要求：

（1）执行摘要（300字内）：概括核心内容、主要目标与关键成功因素。
（2）项目团队构成（300字内）：列出核心成员与外部合作方，明确职责与决策权限。
（3）里程碑规划（1200字内）：设定五到七个关键里程碑，含目标、完成标准、时间节点，使用甘特图呈现。
（4）详细行动步骤（2000字内）：分解为十五到二十个步骤，每步包含行动描述、责任人、起止时间、所需资源、完成指标。
（5）资源分配表（1000字内）：创建资源分配矩阵，横轴为时间，纵轴为资源类型，标注需求高峰。
（6）跨部门协作流程（800字内）：设计两到三个关键协作流程，使用流程图呈现。
（7）预算明细（1000字内）：提供详细预算表，含各环节支出、应急资金比例、成本控制措施。
（8）质量控制计划（900字内）：列出三到五个关键质控点与检查标准。
（9）风险管理矩阵（1200字内）：识别五到七个潜在风险，评估概率与影响，为高风险项制定预防与应对措施。
（10）利益相关者沟通计划（1800字内）：设计定期汇报机制，指明频率、方式与关键信息点。
（11）应急预案（1000字内）：为两到三个重大意外情况制定预案，含触发条件、响应流程、补救措施。
（12）执行后评估机制（700字内）：
