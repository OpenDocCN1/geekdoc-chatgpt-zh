# 从约翰·斯诺到现代工具变量的文献脉络

约翰·斯诺对霍乱的长期追踪调查在很长一段时间内都未获应有的关注，《柳叶刀》刊载的讣告里对此只字未提。值得注意的是，155 年之后《英国医学杂志》对这篇讣告进行了“修正”，相关说明见 Hempel 2013 年的文章。若想进一步了解斯诺的生平，可查阅 Hill 1955 年的纪念文以及 Cameron 与 Jones 1983 年的专题研究。当面对无法观测的混杂因素时，Glynn 与 Kashin 2018 年的实证工作是首次系统展示前门调整在这种情境下优于后门调整的论文之一。Freedman 对“吸烟 → 焦油沉积 → 肺癌”这一例子的质疑，收录在他 2010 年著作中题为“关于为因果关系指定图模型”的一章里。

工具变量的基础性介绍可参考 Greenland 2000 年的综述，以及 Bowden 与 Turkington 1984 年、Wooldridge 2013 年等计量经济学教材。Brito 与 Pearl 在 2002 年提出的广义工具变量，拓展了本书中所给出的经典定义。DAGitty 程序可在 http://www.dagitty.net/dags.html 在线使用，它能够在图中搜索广义工具变量并报告相应的可估量，参见 Textor、Hardt 与 Knüppel 2011 年的工作。另一款基于图形的决策工具是 BayesiaLab，网址为 www.bayesia.com。Pearl 2009 年书中第 8 章对工具变量估计的界限做了深入探讨，并将结论应用于合规性缺失的情形。Imbens 2010 年的文章则主张并讨论了以局部平均处理效应 LATE 为近似的做法。

## 第八章 反事实：如何推演假设世界

### 注释书目

Balke 与 Pearl 在 1994 年的 1994a 和 1994b 两文中把反事实界定为结构方程的衍生，借此评估法律情境下的因果概率。Pearl 2000 年第七章详细梳理了该框架与 Rubin、Lewis 体系之间的关系，并证明两者在逻辑上等价，可互相解决同一类问题。近年来，Morgan 与 Winship 2015 年的社会科学著作以及 Vanderweele 2015 年的健康科学著作，都采用了本书倡导的图与反事实相结合的混合路径。书中关于线性反事实的讨论主要基于 Pearl 2009 年第 389–391 页的内容，该部分同时解答了第 258 页脚注提出的问题。对参与者处理效应 ETT 的分析则建立在 Shpitser 与 Pearl 2009 年的工作之上。Greenland 1999 年系统讨论了归因的法律议题与因果概率，他是反事实方法在该领域应用的早期推动者。我们对 PN、PS 与 PNS 的处理参考了 Tian 与 Pearl 2000 年以及 Pearl 2009 年第 9 章。Pearl、Glymour 与 Jewell 2016 年提出了一种更精细的反事实归因思路，并附带估计工具包。Halpern 2016 年对实际因果关系给出了技术性的形式化。潜在结果学派常以匹配技术来估计因果效应，如 Sekhon 2007 年所示，但往往忽略了我们在“学历—工作经验—工资”例中指出的陷阱。通过 Mohan 与 Pearl 2014 年的研究，可将缺失数据问题置于因果建模的视角下理解。Cowles 2016 年与 Reid 1998 年记述了 Neyman 在伦敦的经历，包括 Fisher 与木制模型的轶事。Greiner 2008 年为法律中的“若非”因果提供了一部历史性与实质性的介绍。Allen 2003 年、Stott 等人 2013 年、Trenberth 2012 年以及 Hannart 等人 2016 年探讨了异常天气向气候变化的归因问题，其中 Hannart 特别引入了充要概率的概念，使论述更清晰。

## 第九章 中介：拆解因果链条的中间环节

### 注释书目

中介问题已有专著系统讨论，VanderWeele 2015 年与 MacKinnon 2008 年的书汇总了大量实例。Pearl 2014 年与 Kline 2015 年描述了从 Baron 与 Kenny 1986 年的统计程序到基于反事实的因果中介方法的转变。McDonald 的“从头开始”引言转引自 McDonald 2001 年。Robins 与 Greenland 1992 年提出了自然直接效应与自然间接效应的概念并指出其难题，后由 Pearl 2001 年正式化并形成中介公式。除 VanderWeele 2015 年的综述外，De Stavola 等人 2015 年、Imai、Keele 与 Yamamoto 2010 年、Muthén 与 Asparouhov 2015 年提供了新方法与新应用。Shpitser 2013 年给出了估计图中任意路径特定效应的通用准则。中介谬误与“以中介为条件”的谬误在 Pearl 1998 年以及 Cole 与 Hernán 2002 年中得到说明。Rubin 2005 年认为 Fisher 支持该谬误，而 Rubin 2004 年则把中介分析视为“欺骗性”的。Lewis 1972 年与 Ceglowski 2010 年讲述了坏血病疗法“失传”的惊人历史。King、Montañez Ramírez 与 Wertheimer 1996 年记述了 Barbara Burks 的案例，文中引文来自 Terman 与 Burks 母亲的信件。伯克利招生悖论最初见于 Bickel、Hammel 与 O’Connell 1975 年，后续 Bickel 与 Kruskal 的通信见于 Fairley 与 Mosteller 1977 年。VanderWeele 2014 年提供了“吸烟基因”例子的来源，Bierrut 与 Cesarini 2015 年讲述了该基因的发现过程。Welling 等人 2012 年与 Kragh 等人 2013 年记述了海湾战争前后止血带使用的不可思议历史，后者以个人化娱乐风格写作在学术刊物中较为罕见。Kragh 等人 2015 年描述了本书提及的关于止血带的研究，未能证实其能提高伤患存活率。
