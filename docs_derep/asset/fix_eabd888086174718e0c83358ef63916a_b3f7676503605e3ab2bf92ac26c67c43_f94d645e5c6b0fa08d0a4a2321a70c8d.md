# MindIE Service 安全配置与启动全流程

## TLS 相关参数说明

**业务面 RESTful 接口**
- tlsCaFile —— 业务面 RESTful 接口所需的 CA 证书集合，相关文件需由使用者自行准备，保管安全由使用者承担。
- tlsCert —— 业务面 RESTful 接口的服务端证书，由使用者提供，安全责任归使用者。
- tlsPk —— 业务面 RESTful 接口的服务端证书私钥，由使用者提供并负责保管，建议以加密形式保存。
- tlsCrlFiles —— 业务面 RESTful 接口使用的证书吊销列表集合，由使用者提供，安全维护由使用者负责。

**管理面 RESTful 接口**
- managementTlsCaFile —— 管理面 RESTful 接口的 CA 证书集合，由使用者自行准备，安全由使用者把控。
- managementTlsCert —— 管理面 RESTful 接口的服务端证书，由使用者提供并承担安全责任。
- managementTlsPk —— 管理面 RESTful 接口的服务端证书私钥，由使用者提供并负责安全，建议采用加密私钥。
- managementTlsCrlFiles —— 管理面 RESTful 接口的证书吊销列表集合，由使用者提供并负责安全保管。

**PD 分离场景下节点间通信**
- interCommTlsCaFiles —— PD 分离场景中 PD 节点互通使用的 CA 证书集合，由使用者提供并负责安全。
- interCommTlsCert —— PD 分离场景中 PD 节点通信的服务端证书，由使用者提供并承担安全责任。
- interCommPk —— PD 分离场景中 PD 节点通信的服务端证书私钥，由使用者提供并负责保管，建议加密存储。
- interCommTlsCrlFiles —— PD 分离场景中 PD 节点通信的吊销列表集合，由使用者提供并负责安全。

**多机场景主从节点通信**
- interNodeTlsCaFiles —— 多机部署时主从节点通信的 CA 证书集合，由使用者自行准备并负责安全。
- interNodeTlsCert —— 多机场景主从节点通信的服务端证书，由使用者提供并承担保管责任。
- interNodeTlsPk —— 多机场景主从节点通信的服务端证书私钥，由使用者提供并负责安全，建议使用加密后的私钥。
- interNodeTlsCrlFiles —— 多机场景主从节点通信的吊销列表集合，由使用者提供并负责安全维护。

#### 8.3.3 使用场景

MindIE LLM 是华为昇腾针对大语言模型推理推出的组件，目标是在昇腾硬件上提供通用大模型的高性能推理能力。总体架构见图 8-9。
[PRE8]

图 8-9

LLM Manager：负责运行状态维护与任务调度，按调度策略对用户请求进行批处理，集中管理 KV 缓存，并对外提供状态监控接口。
Text Generator：负责模型配置、初始化与加载、自回归推理流程及后处理，为 LLM Manager 提供统一的自回归推理入口，支持并行解码与插件化运行。
Modeling：提供深度定制的算子模块与内置模型，兼容 ATB Models 与 MindFormers 两大框架。内置模块涵盖 Attention、Embedding、ColumnLinear、RowLinear、MLP 等，支持权重在线 Tensor 切分加载。用户也可基于内置模块自行组网，编译优化后即可在昇腾 NPU 上实现推理加速。
MindIE LLM 适用于对大模型推理性能要求较高的场景，如自然语言处理、智能客服、文本生成等。服务化形态如图 8-10 所示。

| 服务化框架 | MindIE LLM子组件范围 | 能力说明 | 接口示意 | 接口形式 |
| :--- | :--- | :--- | :--- | :--- |
| MindIE Service | LLM Manager+TextGenerator+Modeling | LLM Manager+TextGenerator提供完整的CB+PA自回归推理调度能力 | ITF 0.L1 | C++ API |
| Triton | LLM Manager+TextGenerator+Modeling | LLM Manager+TextGenerator提供完整的CB+PA自回归推理调度能力 | ITF 0.L1 | C++ API |
| TGI | TextGenerator+Modeling | 提供TextGenerator前后处理+Modeling推理能力 | ITF 0.G1 | Python API |
| vLLM | TextGenerator+Modeling | 提供TextGenerator前后处理+Modeling推理能力 | ITF 0.G1 | Python API |
