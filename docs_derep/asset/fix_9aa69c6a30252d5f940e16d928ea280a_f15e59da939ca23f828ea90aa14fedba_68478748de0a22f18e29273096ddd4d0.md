# LangChain 记忆与检索增强实战

要让对话 Agent 既能记住用户在多轮里提及的关键信息，又能检索外部知识库作答，核心在于记忆机制和检索增强的搭配。本文通过可直接运行的片段演示如何自建实体记忆、搭建 RAG 问答流程，并把聊天历史带入推理。

### 自建 spaCy 实体记忆

先实现一个轻量级的记忆组件，用 spaCy 抽取出用户发言中的命名实体，并把对应的原文累加到内部字典中保存。

        text = inputs[list(inputs.keys())[0]]

        doc = nlp(text)

        # For each entity that was mentioned, save this information to the

        # dictionary.

        for ent in doc.ents:

            ent_str = str(ent)

            if ent_str in self.entities:

                self.entities[ent_str] += f"\n{text}"

            else:

                self.entities[ent_str] = text

为让模型能够读取实体信息，需要一个专门的提示模板把实体内容注入上下文。
