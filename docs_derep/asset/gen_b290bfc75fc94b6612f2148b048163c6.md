**6.2.2 气泡**

气泡 Bubble 是对话场景里最基础的展示单元，负责承接用户提问和 AI 回答，用气泡形式把消息清晰分隔，符合用户的聊天视觉习惯。

它不仅能展示纯文本，还能承载图片、富文本、卡片等多种形态，并可根据上下文自动左右定位来区分角色，提升可读性和沉浸感，是构建高质量对话界面的基石。

**6.3 主题定制**

对话系统的一致性和品牌气质很重要。ChatUI 提供默认主题，采用 BEM 风格的 CSS 命名，方便覆盖样式。同时支持灵活定制品牌色、字号、圆角、提示色等。

ChatUI 使用 CSS 变量定义主题，只需覆盖对应变量就能快速修改样式，适配产品视觉体系。可覆盖的变量可在 ChatUI GitHub 仓库的 root.less 中查看，如图 6-10 所示。

[PRE25]
图 6-10 ChatUI 主题色文件

少量调整可以直接在项目里覆盖 CSS 变量，适合快速换色。示例代码如下：

    // 引入 ChatUI 样式
    import '@chatui/core/dist/index.css';
    // 覆盖样式
    :root {
      --brand-1: #46c800;
      --brand-2: #08b71e;
      --brand-3: #fcf8ec;
    }

实际项目中往往需要改动较多变量才能统一风格。针对此，ChatUI 提供了主题编辑器，可快速配置效果、即时预览并一键导出 CSS 或 JSON 文件，直接应用到项目，如图 6-11 所示。

[PRE26]
图 6-11 ChatUI 主题编辑器

导出 CSS 后与原样式一同引入即可完成主题覆盖，示例：

    // 引入 ChatUI 样式
    import '@chatui/core/dist/index.css';
    // 引入定制的样式
    import './chatui-theme.css';

这样既保留基础布局，又能通过变量覆盖完成品牌统一，便于在多项目间复用主题。
