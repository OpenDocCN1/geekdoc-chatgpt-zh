# 第五章 从存在论到诠释学：为认知研究打开新入口

上文已经用海德格尔的存在论框架梳理了当代认知科学的主要走向，提炼出关联认知的核心概念，同时点出把存在论现象学硬接入认知研究时会遇到的两大理论卡点。由此自然产生一个追问：仅用存在论打开的视野是否足够？存在论确实提供了审视人类认知的新角度，启发明显。但如果只把它当成认知科学的唯一思想库显然捉襟见肘，存在论认知还需要新的养分来补充。诠释学与存在论之间存在深层关联，这就为存在论认知向诠释学延展提供了可能。我们认为，认知科学甚至人工智能，都能在诠释学那里获得有用提示，两者并非无路可通。

## 第一节 为什么要让存在论认知走向诠释学

# 诠释学在谈什么

诠释学Hermeneutics的字面含义围绕宣告、转译、阐释等操作而来，词源可追溯到希腊神话中司传令的赫耳墨斯Hermes，他的工作不是照搬神谕，而是把神的语言转译为人类可懂的表述，进而实现意义的传递。由此可见，诠释学本质上关乎意义如何在不同语境间被呈现与转换。通常它被概括为研究理解与解释的理论实践，是关于意义获取与阐明的哲学。在历史脉络上，诠释学最初扎根于法学解释与圣经文献的神学解释两条线。施莱尔马赫和狄尔泰的工作让它摆脱了教义的偶然束缚，发展成一门通用的理解学说，研究焦点也由文本历史转向理解活动本身，其自我定位是协调各类解释冲突，成为人文科学的方法论基石与普遍的哲学进路。[^(\[1\])](#chapter006.html#m1)

把诠释学纳入存在论认知的进路，并非凭空想象，而是有内在逻辑。对海德格尔而言，存在论的核心问题是追问此在Dasein的存在意义，无论是早期聚焦此在的基础存在论，还是后期对存在意义本身的追问，使用的工具都是诠释学。若要论证诠释学能够进入认知的某些场域，需要给出合理的过渡依据。

### 一 海德格尔的存在论现象学本质上是诠释学

海德格尔把诠释学的重心从“如何解释”转向“理解本身就是此在的存在方式”。此在在理解中显露出自己身处世界的状态。可以说，对此在的描述本身就是一种诠释，此在被界定为理解的此在，其生存结构的刻画自带阐释属性。现象学在此处的方法论等同于解释，通过诠释，此在存在的本真意涵与基本结构才得以显现。亦即此在的现象学等同于诠释学。[^(\[2\])](#chapter006.html#m2)

此在持续追问自身的存在意义，而意义的把握与展开正是诠释学的对象领域，由此可推导出此在的现象学即诠释学，而此在的现象学构成基础存在论的工作基础，故此在的诠释学也就是基础存在论。[^(\[3\])](#chapter006.html#m3)

海德格尔借助诠释学旨在揭示此在的存在方式。此在自始便在理解与解释，不停地生成对存在的主题化或非主题化理解，这种理解活动的本质是此在对自身存在的反思。这种反思不同于胡塞尔式的意识行为，而是此在的一种存在模态，涉及此在如何理解自身与他物。海德格尔并不把理解局限于一种认识操作，而是视其为人在世界中存在、与世界互动的基本能力，通俗说就是“我知道怎么做，在不同情境下能做出恰当回应”。[^(\[4\])](#chapter006.html#m4)这一思路后被伽达默尔进一步明确：诠释学即实践哲学，[^(\[5\])](#chapter006.html#m5)解释从一种形式转向另一种形式，体现了人在不同生存处境中的应对方式。与世界交往的过程本身就是开启世界的过程，展露出人在时空维度上与他物的互动。海德格尔所说的理解涵盖感知、实践性的know-how、理论性的认知知识，以及与他人的日常交往，而非仅限于认知现象。

总体而言，海德格尔的存在论现象学与诠释学实质一体，因为人始终保持着对存在的本真或非本真理解，如何让恰当的理解浮现，是诠释学与基础存在论共同的任务。诠释学因此从文本解释的方法提升到哲学高度，成为关乎存在理解的学问。既然海德格尔的存在论现象学与诠释学不可分离，而伽达默尔在整体上继承了这一脉络，就有充分理由把存在论与认知研究的结合延伸到诠释学，让诠释学的思想资源进入认知研究。

### 二 认知本身就是一种诠释行为

海德格尔提出诠释学意在摆脱近代主流的主体认识论，那种孤立、去世界的认知主体图式破坏了人与世界原始的关联，存在论现象学的任务正是从世界出发理解人与事物的关系。理解是世界与此在关系的具象化，存在离不开此在的理解，存在是在此在的理解中显现。[^(\[6\])](#chapter006.html#m6)

人不仅是行动者，更是诠释者。人的认知与行动在先行层面已被理解。从某种角度看，认知即行动，因为它具有表征性：认知对象的模型或对应物的生成本身就是一次解释性呈现。认识具体事物、形成理论、设计模型，都可以视为诠释过程。或许可以说，诠释是对认知对象的解释性呈现。人总是以诠释的方式、以不同视角面对世界，思维、认知、行动都浸透着诠释，缺乏合乎逻辑的诠释就无法思考、判断与评价。[^(\[7\])](#chapter006.html#m7)

除了渗透性，诠释对认知的依赖性也很强。细想会发现，我们绝大多数关于事物与事件的认知、思考、判断都暗含诠释。日常生活中面对的多是可理解的事实，维特根斯坦曾言世界是事实的总和，事实只有经过诠释才进入我们的认知，事实的存在可被视为某种诠释的产物。任何事物要被认识必须先作为对象进入诠释过程，甚至可以推断，诠释的范围界定了认知的范围，人的认知世界是在诠释中被理解与建构的。认知活动所产出的结果，本身也是诠释的结果。我们既以认知方式又以诠释方式朝向世界，作为一个不断诠释的存在，我们在思维、认知与行动中始终依赖这一要素。
