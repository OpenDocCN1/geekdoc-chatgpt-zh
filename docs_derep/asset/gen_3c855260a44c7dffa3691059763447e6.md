**5.1.1 作为官方技能市场的定位与价值**

ClawHub 是 OpenClaw 官方推出的公共技能注册与社区分发平台，类似 AI 领域的 npm 或 PyPI。

平台上开发者可发布、版本化、搜索基于文本的 Agent 技能。截至出版时，已汇聚超过三万个社区贡献的技能，覆盖办公、运维、创作、智能家居等领域，且持续增长。

其核心价值在于打破能力孤岛，构建开放共享生态。

一是提供标准化分发渠道。技能被打包为以 SKILL.md 为核心的目录包，上传下载极简。

二是引入现代化包管理。支持语义化版本号，升级修复 Bug 后可一键更新，也能快速回滚，降低维护成本。

三是采用向量语义搜索。借助嵌入模型与向量数据库，搜索意图能被准确理解，即使关键词与技能名不完全一致，也能命中最相关结果，大幅提升发现效率。

**5.1.3 ClawHub 的安全与审核机制**

开放生态下安全至关重要。ClawHub 构建了多层防护。

• 发布门槛：默认开放上传，但要求发布者 GitHub 账号注册满一周，有效遏制批量恶意发布。

• 社区监督：登录用户可举报可疑技能，需填写原因；单用户活跃举报上限 20 条；同一技能累计 3 个独立用户举报即自动隐藏，不再出现在搜索与列表；版主可审计后解禁或硬删除并封号。

作为使用者，安装第三方技能时应视其为不可信代码，先阅读 SKILL.md 与脚本，确认操作范围。高风险场景下结合 OpenClaw 沙箱隔离执行。
