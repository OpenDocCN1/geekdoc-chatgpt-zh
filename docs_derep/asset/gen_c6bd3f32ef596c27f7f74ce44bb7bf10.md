# 第 10 课　红外遥控实战：从信号接收到设备控制

## 核心任务
掌握红外通信的全流程：搭建接收端解码遥控指令，再构建发射端实现设备远程操控。

## 实操指南

### 第一阶段：搭建“解码器”读取遥控指令
**硬件准备**  
将红外接收模块接入 Micro：mate 的 P8 接口，通过 USB 连接 Micro：bit 至电脑。

**变量建立**  
在 Mind+“变量”栏新建变量 `红外值`，专门存放传感器捕获的原始数据。

**指令编写**  
从“模块”→“红外接收”拖入积木块，将其赋值给 `红外值`，完成数据采集逻辑。

[PRE2]

**调试验证**  
程序上传后打开串口监视器，按压遥控器任意键，窗口将输出对应十六进制代码（如 `0xFD00FF`）。不同按键对应唯一编码，这是后续控制逻辑的基石。

### 第二阶段：打造“微型遥控器”驱动 LED
**电路拓展**  
在原有基础上接入红外发射模块（P12）与 LED 灯（P16），形成“发射-接收-执行”闭环。

[PRE8]

**协议约定**  
定义两条核心指令：  
- `0xFD00FF` → 开灯  
- `0xFD8877` → 关灯  

**双端编程**  
- **发射端（Micro：bit 主板）**：按键 A 触发发射“开灯码”，按键 B 发射“关灯码”，支持 NEC 等多种主流协议切换。  
- **接收端（Micro：mate）**：解析收到的码值，匹配执行 LED 开关动作。

# 第 11 课　智能浇水管家：让植物“开口”要水

## 核心任务
利用土壤湿度传感器实时采集基质水分，通过三色灯直观呈现“缺水-适宜-充足”三态。

## 传感器摸底
**原理速览**  
探针插入介质（水/土），输出 0~1023 模拟值：数值越大 → 湿度越低。  
**防坑指南**  
仅插入探针前 1/2，严禁全没入，防止短路烧毁。

## 算法核心：差值判步法
**变量设计**  
- `x1`：上一采样刻加速度合成值  
- `x2`：本次采样刻加速度合成值  
- `num`：有效步数累计器  

**判定逻辑**  
`|x1 - x2| > 200` → 判定为一次有效步态波动 → `num + 1`

# 第 14 课　OBLOQ 物联网首发：设备上云实战

## 核心任务
理解物联网“端-管-云”架构，用 OBLOQ 模块完成 Micro：bit 设备接入物联网平台的双向通信。

## 认知建模
**物联网 = 互联网 + 信息感知设备 + 网络平台**  
核心目标：**任意时、任意地、人机物三元互联**。

**OBLOQ 定位**  
- 内置 Wi-Fi + MQTT 协议栈  
- 串口透传指令，免驱动接入主流 IoT 平台（OneNET、ThingsBoard 等）  
- 让单片机“零成本”拥有联网能力

## 通信闭环实操
1. **配网**：AT 指令/网页配置 → 连接热点  
2. **认证**：填入产品 ID / 设备 ID / API Key  
3. **上行**：传感器数据 → 串口 → OBLOQ → MQTT → 云平台  
4. **下行**：云平台下发指令 → MQTT → OBLOQ → 串口 → Micro：bit 执行
