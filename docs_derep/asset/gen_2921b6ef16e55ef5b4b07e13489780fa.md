### 深度剖析：归一化技术演进与优化算法全景指南

#### Layer Normalization：打破批次依赖的利器

Layer Normalization（层归一化）最大的亮点在于**彻底摆脱了对 Batch Size（批次大小）的依赖**。这意味着训练与推理阶段可以采用完全不同的批次规模，甚至支持单样本（Batch Size=1）操作，同时省去了存储批次均值与方差的开销。它在循环神经网络（RNN）等序列模型中表现尤为出色。不过，当批次尺寸较大时，其效果往往不及 Batch Normalization。

#### Instance Normalization：风格迁移的“守门员”

在图像风格迁移任务中，风格特征往往寄托于单个图像实例。Instance Normalization（实例归一化）应运而生，它**仅在高度（H）与宽度（W）两个空间维度上计算均值与方差**，不跨通道、不跨批次。

**核心公式逻辑：**
输入张量形状为 $N \times H \times W \times C$。对每个样本、每个通道独立归一化：
1.  计算空间均值 $E_{nc}[X]$ 与方差 $Var_{nc}[X]$（公式 7-35, 7-36）。
2.  标准化：$Y = (X - E) / \sqrt{Var + \epsilon}$ (7-37)。
3.  仿射变换：$Z = Y \times \gamma + \beta$ (7-38)，其中 $\gamma, \beta$ 为可学习参数。

**优势与短板：** 能完美保持样本间独立性，不受批次与通道数影响，是风格迁移、图像生成任务的首选。但若任务强依赖通道间相关性（如某些分类任务），则不适用。

#### Group Normalization：小批次训练的“平衡术”

Group Normalization（组归一化）旨在解决 **小批次下 Batch Normalization 失效** 与 Layer Normalization 在 CNN 中“全通道归一化”过于激进的矛盾。

**核心机制：** 将 $C$ 个通道分为 $G$ 组，组内进行归一化。
-   统计量计算范围：批次维度 $N$ + 组内通道 $(C/G)$ + 空间 $H \times W$（公式 7-39, 7-40）。
-   标准化与缩放平移同理（公式 7-41, 7-42）。

**灵活的统一视角：**
-   $G=1$ 时 $\rightarrow$ 退化为 **Layer Normalization**。
-   $G=C$ 时 $\rightarrow$ 退化为 **Instance Normalization**。
这种可插拔特性使其成为小批次训练（如目标检测、视频理解）的标配方案。

#### Weight Normalization：参数空间的“几何解耦”

Weight Normalization（权重归一化）跳出激活值分布，直接作用于**权重参数本身**。它将权重向量 $w$ 分解为：
$$w = \frac{g}{\|v\|} v$$
-   **方向向量 $v$**：决定权重方向，同维度向量。
-   **模长标量 $g$**：决定权重长度（欧氏范数 $\|w\| = |g|$）。

这种分解固定了权重向量的范数，天然带来**正则化效果**，优化时分别更新 $v$ 与 $g$，几何意义清晰。

### 第 7.8 章 优化算法：驱动模型收敛的核心引擎

优化算法的使命是通过迭代更新参数最小化损失函数。面对海量参数与非凸地貌，优化器的选择直接决定收敛速度与最终性能。优秀的优化器需具备：指引下降方向、规避鞍点/局部最优、自适应调节步长三大能力。

#### 7.8.1 梯度下降家族：从全量到随机的进化史

**1. 梯度下降法 (GD) —— 基石**
利用导数/梯度指示“下降最快方向”：
$$X' = X - \epsilon \nabla_X f(X)$$
步骤：初始化 $\rightarrow$ 计算梯度 $\rightarrow$ 按学习率 $\epsilon$ 更新 $\rightarrow$ 迭代至收敛。
*痛点*：易陷局部最优；全量计算梯度内存压力大、速度慢。

**2. 批量梯度下降 (BGD) [PRE1]**
每步用**全量数据**算梯度。方向准但极其缓慢，不支持在线学习，大数据集难以胜任。

**3. 随机梯度下降 (SGD) [PRE2]**
每步随机抽取**单个样本**算梯度。
-   *优点*：极快，噪声有助跳出浅层局部最优。
-   *缺点*：轨迹剧烈震荡，收敛不稳定。
-   *理论保障*：配合学习率衰减，凸问题收敛全局最优，非凸问题收敛局部最优。

**4. 小批量随机梯度下降 —— 工业界标配 [PRE3]**
每步抽取 **$k$ 个样本（典型 50~256）** 计算梯度均值。
-   兼顾方向稳定性与计算效率。
-   完美适配 GPU 矩阵并行加速，是深度学习框架的默认选择。

---

#### 7.8.2 动量与自适应学习率：让优化更聪明

**1. Momentum（动量法） —— 赋予优化“惯性” [PRE4]**
SGD 易在 ravine（峡谷）地形震荡。Momentum 引入**指数移动平均 (EMA)** 累积历史梯度：
$$m_t = \beta m_{t-1} + \nabla f(x_t)$$
$$x' = x - \epsilon m_t$$
-   方向一致的维度加速（累积动量）；
-   方向震荡的维度抵消（动量衰减）。
物理隐喻：小球滚下山谷，积累动量冲过局部坑洼。

**2. NAG (Nesterov Accelerated Gradient) —— “预判”大师 [PRE5]**
Momentum 看的是“当前位置梯度”，NAG 先按动量“探一步”再看梯度：
$$m_t = \beta m_{t-1} + \nabla f(x - \epsilon \beta m_{t-1})$$
$$x' = x - \epsilon m_t$$
**前瞻修正**：避免在悬崖边盲目加速，收敛更稳、更快。

**3. AdaGrad —— 参数级自适应学习率**
针对稀疏特征（如 NLP 词频）更新不均问题，对**每个参数**维护梯度平方累积 $s_i$：
$$\eta_i = \frac{\epsilon_0}{\sqrt{s_i + c}}, \quad s_i \leftarrow s_i + (\nabla f)^2$$
-   常更新参数 $\rightarrow$ 分母大 $\rightarrow$ 步长小；
-   稀疏参数 $\rightarrow$ 分母小 $\rightarrow$ 步长大。
*致命伤*：$s_i$ 单调递增 $\rightarrow$ 学习率衰减至 0，训练过早停滞。

**4. RMSProp & AdaDelta —— 解决“学习率消亡”**
引入 **指数移动平均 (EMA)** 替代简单累加，引入遗忘因子 $\gamma$：

*RMSProp [PRE6?]*：
$$s_i = \gamma s_{i-1} + (1-\gamma)(\nabla f)^2$$
$$\eta_i = \frac{\epsilon_0}{\sqrt{s_i + c}}$$
仍需手动设定全局 $\epsilon_0$。

*AdaDelta [PRE7?]*：**彻底告别人工学习率**
引入第二状态变量 $\Delta x_i$ 记录参数更新量的 EMA：
$$s_i = \gamma s_{i-1} + (1-\gamma)(\nabla f)^2 \quad \text{(二阶动量)}$$
$$\Delta x_i = \gamma \Delta x_{i-1} + (1-\gamma)(g_{i-1})^2 \quad \text{(更新量二阶动量)}$$
$$x' = x - \frac{\sqrt{\Delta x_{i-1} + c}}{\sqrt{s_i + c}} \nabla f$$
巧妙利用“更新量 RMS / 梯度 RMS”自动缩放步长，实现真正的**免调参自适应**。
