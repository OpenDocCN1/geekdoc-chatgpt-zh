LangChain Agent 实战：让模型既会用工具又会记住上下文

想让大模型不只是会聊天，还能联网查数据、算数学，并且记得前一句在说什么，LangChain 的 Agent 链路就是标准答案。下面这套最小可运行的示例，演示了从初始化、加载工具到加入会话记忆的完整过程，以及有记忆和无记忆时的差别。

先准备模型和环境变量，把 OpenAI 的密钥和 SERPAPI 的密钥填进去，实例化一个温度为 0 的 ChatOpenAI，再把链式调用的依赖导入好。
