在 DNS 控制台里先增加一条 CNAME 解析。新建记录时类型选 CNAME，主机名填 www，对应网站的 www 子域，解析目标填 cname.vercel-dns.com，确认后保存。

再补一条根域指向。再次新建记录，类型选 A，主机名用 @ 代表主域名，记录值填 76.76.21.21，保存即可。

(4) 核验域名是否生效

DNS 修改完成后回到 Vercel 的域名设置页，点一下 Refresh 刷新状态。配置正确时会看到绿色的勾，说明域名已绑定成功。注意 DNS 全网生效有延迟，通常是几分钟到数小时不等。

**关键提醒：** vercel.app 的默认域名在中国大陆无法直接打开。如果你的用户主要在大陆，自定义域名不是可选项，是必选项。
