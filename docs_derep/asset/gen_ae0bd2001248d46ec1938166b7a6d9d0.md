图像处理的基础能力清单

• 去噪与平滑：削弱图像中的随机干扰，典型做法是均值滤波、高斯滤波。
• 轮廓提取与特征获取：把握目标边界与关键点，常用 Sobel、Canny 等算子。
• 几何变换：完成缩放、旋转、镜像、透视校正等空间变化。
• 色彩空间转换：在 RGB、HSV、灰度等不同空间间切换。
• 图像分割：把前景与背景分离，例如阈值分割等手段。

图像识别
面向语义理解与类别判断的任务，系统会自行判定画面中出现了哪些物体以及它们的属性。早期方法多依赖人工设计特征，如 SIFT、HOG、LBP 等。随着深度学习的发展，卷积神经网络 CNN 与 Vision Transformer ViT 等模型得到广泛应用，实现了从特征学习到分类推理的端到端流程。识别能力已成为 AI 产品落地的重要支撑，人脸识别、车牌识别、文字检测与 OCR、缺陷检测等场景均已实现规模化应用。

识别侧重语义解读与目标推断，常见形式包括：

• 图像分类：判断整张图的类别，例如猫与狗的区分。
• 目标检测：在图中定位目标并画出框，如 YOLO 系列。
• 目标跟踪：在视频序列中追踪目标轨迹。
• 语义分割：对每个像素进行场景构成标注。
• 人脸识别与验证：实现身份判别与特征提取。
• OCR 文字识别：读取图像中的文字内容。

def _on_open_image(self):
        """Open local image and display, scaling to fit the image area while keeping aspect ratio."""
        filetypes = [
            ("Image Files", "*.png *.jpg *.jpeg *.bmp *.gif *.tiff *.tif *.webp"),
            ("PNG", "*.png"),
            ("JPEG", "*.jpg *.jpeg"),
            ("Bitmap", "*.bmp"),
            ("GIF", "*.gif"),
            ("TIFF", "*.tif *.tiff"),
            ("WEBP", "*.webp"),
            ("All Files", "*.*"),
        ]
        filepath = filedialog.askopenfilename(
            title="Select an image",
            filetypes=filetypes,
        )
        if not filepath:
            return
        try:
            image = Image.open(filepath)
            # Convert to RGB to avoid mode issues (e.g., palette or RGBA)
            if image.mode not in ("RGB", "L"):
                image = image.convert("RGB")
            self.original_image = image
            self._current_image_path = filepath
            self._display_image_to_fit()
            self._set_window_subtitle(os.path.basename(filepath))
