图中横轴为时间，从 2021 年 1 月到 2023 年 8 月，纵轴为 Agent 相关论文的累计数量，反映研究热度。文中列举的典型 Agent 类型包括：

- 通用 Agent (General Agent)：如 GPT 系列、LLaMA 等大模型。
- 工具 Agent (Tool Agent)：如 ToolBench，旨在提升大模型使用工具的能力。

- 游戏 Agent (Game Agent)：如 Voyager2、DEPS 等，在游戏场景中完成任务。
- Web Agent：如 WebShop 等，在电商场景与用户互动。
- 助手 Agent (Assistant Agent)：帮助人类用户完成各类任务。

从演进脉络可见，Agent 的感知、推理、操控等核心能力持续增强，应用场景由早期的简单游戏、模拟环境逐步扩展到 Web 应用和真实世界。各类型 Agent 相互促进，共同推动领域快速发展。

2023 年 AgentGPT、AutoGPT 等可自主执行任务的通用 Agent 出现，极大释放了类通用人工智能的想象空间。LLaMA、Toolformer 等新基座模型和工具学习范式也为 Agent 带来新动力。

论文提出了一个大模型驱动的自主 Agent 统一框架，包含四个关键要素：角色定义、记忆、规划和行动。角色定义为 Agent 提供背景和行为模式；记忆负责信息的存储、读取与更新；规划负责目标拆解和任务求解；行动则包括文本输出、使用工具和执行具身操作等，使 Agent 能够与环境交互产生影响。四者协同赋予 Agent 感知、思考、学习、决策的综合能力，让其能自主适应环境、解决复杂问题。该框架揭示了语言模型、认知模块、环境交互在 Agent 构建中的关键作用，为研究提供系统思路。

类似地，复旦大学的论文“The Rise and Potential of Large Language Model Based Agents: A Survey”（大模型基础上的 Agent 崛起及其潜力：综述）[1] 也给出了相似的构建框架。该框架由环境感知、Brain 和行动三大模块构成。环境感知模块接收外部多模态输入；Brain 模块由大模型构成，负责知识存储、记忆管理、决策规划和推理；行动模块执行 Brain 的决策，通过文本输出、工具使用和具身动作与环境交互，并把结果反馈给环境感知模块，形成闭环。此框架让大模型具备感知、思考、行动的整体 Agent 能力，能够像人一样与现实世界交互，完成多样化任务，为构建通用人工智能提供技术路径。
