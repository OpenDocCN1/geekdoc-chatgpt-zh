## 3.4 集合

Python 中集合用花括号（`{}`）表示，元素以逗号分隔，也可通过`set（）`函数强制创建。空集合必须用`set（）`创建，不能直接用`{}`。

[PRE42]

注意

集合定义与字典定义的区别在于元素格式，字典必须使用键值对。
