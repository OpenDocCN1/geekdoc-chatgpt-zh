VGG 把极简主义做到极致，整张网络只靠 3×3 小卷积不断堆叠。实验上把网络拉深到 16 层到 19 层，前代模型的精度会获得明显跃升。

用更小的卷积核配合更小的步幅，一方面靠层数增多带来更强的非线性表达，另一方面也能把计算量压下来。

下面拿 VGG16 来拆解。整体是 13 个卷积层加 3 个全连接层，卷积统一用 3×3、步长 1，池化统一用 2×2 最大池化、步长 2。

输入是 224×224×3 的彩图，先做减均值预处理，减均值有助于训练稳定。标准 VGG16 的流向大致如下：

输入经减均值后进入首个特征块。先用两组 64 通道的 3×3 卷积保持 224×224 分辨率，通道数为 64，随后 2×2 池化把空间压缩到 112×112×64。

第二块用两组 128 通道的 3×3 卷积，特征保持 112×112，随后池化到 56×56×128。

第三块用三组 256 通道的 3×3 卷积，特征保持 56×56，再池化到 28×28×256。

第四块用三组 512 通道的 3×3 卷积，特征保持 28×28，再池化到 14×14×512。

FC-4096，接收 7×7×512，映射到 4096 维，权重约 7×7×512×4096；
FC-4096，4096 到 4096，权重约 4096×4096；
FC-1000，4096 到 1000，权重约 4096×1000。整网参数约 550M，靠统一的 3×3 卷积和 2×2 池化让结构非常干净。

与 AlexNet 对比，VGG 有三处关键差异。

### （1）卷积核
VGG 全程只用 3×3，结构更规整。AlexNet 首层用 11×11，输出 96 通道。算第一层参数，AlexNet 约 96×3×11×11，VGG 约 64×3×3×3，两者相除约 0.05，VGG 首层参数只有 AlexNet 的二十分之一左右，计算量也大幅下降。深度增加后，参数总量仍可控。

### （2）池化
VGG 用 2×2 核、步长 2 的不重叠池化。AlexNet 用 3×3 核、步长 2 的重叠池化。重叠池化在 AlexNet 上被观察到能缓解过拟合，但计算开销更大；不重叠池化更省算力。

### （3）数据增强
VGG 使用更复杂的尺度抖动 Scale Jittering。先定裁剪边长 m×m，通常 224×224，把图像短边缩放到大于 m 的区间，例如 256 到 288，再在这个尺寸上裁出 m×m。相比先统一缩放到固定尺寸再裁剪，可操作空间更大，但也可能切掉关键区域。

## 4.3 LSTM基础知识与PyTorch实战部分

传统前馈网络没有记忆单元，面对序列任务时效率低、预测受限。循环神经网络 RNN 在反向传播框架上加入跨时间的记忆传递。

在 RNN 中，某时刻的隐藏层除了和当期输入、输出相连，还和前后时刻的隐藏单元相连，形成历史信息的通道。训练时误差会从最后一步一路传回过去，这就是基于时间的反向传播 BPTT。

传统网络层内节点互不相连，信息单向流动。RNN 具有反馈结构，输出不仅和当前输入、参数有关，也和既往输入有关，对序列化建模更有效。本节介绍 RNN 及其变体 LSTM 与 GRU。

### 4.3.1 什么是循环神经网络（RNN）

RNN 的隐层会保存先前信息，再参与当前计算，隐层节点之间存在信息交互。不同时刻共享同一套权重，在相同参数量下能利用更多信息，学习效率更高。其内部结构如图4-9所示。

[PRE1]

图4-9 循环神经网络（RNN）的内部结构

- 1） $x_t$ 表示第 $t$ 步的输入。
- 2） $S_t$ 表示第 $t$ 步隐藏层的状态，它是根据当前输入层的输出和上一时刻隐藏层的状态 $S_{t-1}$ 进行计算的，公式如下：

  $s_t = f(Ux_t + Ws_{t-1})$ 

  其中 $U$ 是输入层的连接矩阵， $W$ 是上一时刻隐含层到下一时刻隐含层的权重矩阵， $f(x)$ 一般是非线性的激活函数，例如 tanh。
- 3） $h_t$ 表示第 $t$ 步的输出，输出层是连接状态，即它每个结点和隐含层的每个结点都互相连接，公式如下：

  $h_t = g(V * s_t)$ 

  其中 $V$ 是输出层的连接矩阵， $g(x)$ 是激活函数。

$h_t = g(V * s_t) = Vf(Ux_t + Ws_{t-1})$ 

$= Vf(Ux_t + Wf(Ux_{t-1} + Ws_{t-2}))$

由该公式可以看出，RNN的输出值与前面多个时刻的历史输入值有关，这也是为什么循环神经网络处理序列数据建模效果好的原因。

普通 RNN 记忆能力有限，难以捕捉长距离依赖。参数在时间上反复使用，训练困难。当误差权重大于 1 时多次相乘导致梯度爆炸，小于 1 时出现梯度消失。梯度由链式法则逐层相乘，小值累积会指数衰减，反向传播几步后近乎为零。若梯度过大则爆炸，根源在于激活函数与初始参数的选择。

为缓解长时记忆的梯度爆炸与消失，引入了具有门控机制的 LSTM 及变体。

RNN 的优化与普通网络一致，均基于反向传播，因结构特殊采用 BPTT，参数更新不仅从输出回传到隐藏与输入，还沿时间轴从未来向过去回传。

下面给出 RNN 忽略偏置的前向与反向公式：

- i: 输入神经元；F：输入神经元数量；
- h: 隐藏层神经元；H：隐藏层神经元数量；
- k: 输出神经元；K：输出神经元；
- U: 从输入层到隐藏层的权重向量；V：从隐藏层到输出层的权重向量；
- W: 上一时刻的隐藏层连接到这一时刻隐藏层的权重向量；
- a_h^t： t时刻输入层到隐藏层的输出，该输出并未经过激活函数；
- s_h^t： t时刻经激活函数后的输出值；
- δ_h^t： t时刻隐藏层的残差。

### （1）前向传播
在 t时刻的 a_h^t 为下式：

a_h^t = Σ_{i=1}^{I} u_{ih} x_i^t + Σ_{h'=1}^{H} w_{h'h} s_{h'}^{t-1}

a_h^t 经由激活函数后的输出值为 s_h^t：

s_h^t = Sigmoid(a_h^t)

输出层的计算为：

$O_k^t = \sum_{h'=1}^{H} V_{hk} s_h^t$

前向公式可见，t 时刻隐藏层的输入包含 t 时刻的输入与 t-1 时刻隐藏层的信息，这是与 BP 的区别。

### （2）反向传播
RNN 的反向传播采用 BPTT，残差公式如下：

$\delta_h^t = f(a_h^t)\left(\sum_{k=1}^{K} v_{hk} \delta_k^t + \sum_{h'=1}^{H} w_{h'h} \delta_{h'}^{t+1}\right)$

整个 RNN 网络共享同一组参数。

t时刻损失函数对于参数的求导公式分别如下：

$\frac{\partial E}{\partial w_{h'h}} = \frac{\partial E}{\partial a_h^t} \frac{\partial a_h^t}{\partial w_{h'h}} = \delta_h^t s_{h'}^{t-1}$

$\frac{\partial E}{\partial u_{ih}} = \frac{\partial E}{\partial a_h^t} \frac{\partial a_h^t}{\partial u_{ih}} = \delta_h^t x_i^t$

$\frac{\partial E}{\partial v_{hk}} = \delta_k^t s_h^t$

根据 BPTT，RNN 的参数梯度为各时间点梯度之和：

$\frac{\partial E}{\partial w_{h'h}} = \sum \frac{\partial E}{\partial a_h^t} \frac{\partial a_h^t}{\partial w_{h'h}} = \sum \delta_h^t s_{h'}^{t-1}$

$\frac{\partial E}{\partial u_{ih}} = \sum \frac{\partial E}{\partial a_h'^t} \frac{\partial a_h^t}{\partial u_{ih}} = \sum \delta_h^t x_i^t$

$\frac{\partial E}{\partial v_{hk}} = \sum \delta_k^t s_h^t$
