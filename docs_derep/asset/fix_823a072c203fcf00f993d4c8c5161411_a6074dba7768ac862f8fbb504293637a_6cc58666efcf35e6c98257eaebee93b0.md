LDA 主题抽取实操

第三组是无监督挖掘。读取文本文件后对每行做分词、去停用词、词干提取，用 Gensim 构建词典与文档词频矩阵，训练两个主题的 LDA 模型，最后打印每个主题贡献最大的五个词及占比。

# Load input data

def load_data(input_file):

    data = []

    with open(input_file, 'r') as f:

        for line in f.readlines():

            data.append(line[:-1])

    return data
