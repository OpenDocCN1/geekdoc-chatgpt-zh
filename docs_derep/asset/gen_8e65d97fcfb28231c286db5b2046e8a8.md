速率限制
调用 API 时可能碰到速率限制，提示信息如下所示：

[PRE0]

速率限制用于保障 API 稳定运行并保证公平访问，防止个别用户大量请求导致服务中断。它同时帮助 OpenAI 平衡基础设施负载，避免突发流量拖垮性能。虽然会带来一定不便，但这是维持可靠体验的必要手段。规避思路包括降低请求频率、使用缓存、减少并发等，开发时遵循最佳实践最稳妥，必要时可升级套餐或联系支持。

衡量维度有两种：
- RPM，每分钟请求数
- TPM，每分钟标记数

TPM 的换算因模型而异，见表 12-18：

避免限错
实用做法是采用指数退避自动重试。触发限制后短暂休眠再重试，若仍失败则延长等待时间再试，直至成功或达到最大重试次数。可在不丢失数据的情况下恢复，首次重试响应快，后续延迟递增，加入随机抖动能避免重试扎堆。需注意失败重试仍计入每分钟额度，盲目重发无效。
