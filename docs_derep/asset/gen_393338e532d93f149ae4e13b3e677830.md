# 用AI激发思考，而非替代思考

刀姐认为，不应让AI取代你的思考，而应把它当作激发思考的工具。

通过AI，你能更快生成点子，减轻大脑负担，也能发现认知盲区。但要记住，AI只是工具，我们仍需自己思考，并对AI结果进行审查、补充或修正。

举例，你可能想让AI自动写文档。你可打开文档，明确告诉ChatGPT你需要写一篇《让ChatGPT充当MINI CEO》为主题的策划方案。由ChatGPT梳理大纲，再根据大纲填写和修改自己的想法。

此外可问ChatGPT：如果你是这家公司员工，能提出10个经营问题吗？然后让它解答，并逐步完善方案。或继续问：我的经营现状如何？还需在哪些环节节流降本？结合回答和自身情况思考，有助于训练提升能力。

随着工具越来越多、越来越便捷，“怎么做”会越来越容易。比如不懂代码的小白也能用工具写出App。在这种情况下，“为何而做”会越来越有价值：产品为谁设计？能解决什么问题？
