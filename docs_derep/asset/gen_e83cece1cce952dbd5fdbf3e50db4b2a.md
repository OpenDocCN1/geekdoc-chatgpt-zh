# 机器护工日记：它比你更懂你的身体

当清晨的第一缕光线照进卧室，一台名叫“阿尔法+”的机器人正悄无声息地站在床边，记录着主人的每一次翻身、每一声鼾响。它知道主人昨晚醒了两次、呼吸暂停了十二回，也清楚他尿液中的糖分含量和粪便里的白细胞计数。它甚至会在主人醒来前，调整好触觉闹钟的抚摸顺序——因为昨天碰了主人的鼻子让他不高兴，今天它改摸眉毛和太阳穴。

这是西班牙机器人研究所研究员卡梅·托拉斯在科幻小说《残心》中描绘的近未来图景：人手一台机器人助手，它们不仅能照顾你的起居饮食，还能精准捕捉你身体发出的每一个信号，甚至比你更了解你自己。

## 当机器人比家人更可靠

小说中的克拉夫特博士，对自家机器人的信任程度远超妻女。他觉得即使母亲还活着，也更愿意把日常交托给这位“阿尔法+”。这款机器人配备了神经加速器，学习速度快得惊人，短短几天就能像“合适的手套”一样让人称心如意。博士泡在浴缸里，任由海绵网像摇篮一样托住自己，热水冲刷着身体，他不禁感叹：既然无法从心理上改变一个人，那就控制他周遭的环境，在正确的时间激活正确的资源——这套“刺激理论”正是他公司产品的核心卖点。

然而，这个试图用科技掌控一切的设计师，也忍不住为另一件事暗自焦虑：他的大脑正在衰老，创造力在流失。他想要一个“创新义体”来对抗思维僵化，提醒自己不要沿着“庸俗的道路”越走越远。

# 湛庐·现实科幻系列　把科幻作为思考方法，发现改变现实的力量

## 科幻是推动商业创新的强大动力

[PRE2]

“元宇宙”这个词，早在1992年就出现在科幻小说《雪崩》里。尼尔·斯蒂芬森写下这个虚构概念时，大概没料到它会成为 Google Earth、Xbox 乃至 Facebook 更名 Meta 的灵感源头。纵观科技史，这样的例子不绝于耳：从火箭发射到人工智能，从可穿戴设备到太空旅行，许多改变世界的发明都在科幻作品里先行“试飞”。马斯克、贝索斯、扎克伯格、乔布斯——这些商业领袖无一不是科幻的忠实读者。《人类简史》作者尤瓦尔·赫拉利更将科幻列为21世纪初最重要的艺术品类。

科幻的价值不在于“预测未来”，而在于“呈现可能”。它为商业发展指出潜藏的矛盾与需求：少数如何战胜多数？固化的思维如何被打破？生存环境如何得以维系？正是这些可能性，引导我们在现实中做出行动。

## 现实科幻：从现实飞向未来，再回到现实

[PRE3]

过去十年间，湛庐持续向读者引介全球前沿头脑：提出可穿戴计算理念的彭特兰、探讨人机共生关系的泰格马克、构建五维空间理论的丽莎·兰道尔、勾勒人工智能意识蓝图的马文·明斯基、提出虫洞穿越假说的基普·索恩……这些思想家站在各自的坐标系里，描绘人类未来的无数种轮廓。

在此基础上推出的“湛庐·现实科幻系列”，秉持一个坚定的理念：科幻不是天马行空的幻想，而是一面映照现实的镜子。故事从现实出发，飞向未来，再回到现实平稳着陆。该系列筛选的标准就三条：每一本都指向一个可能实现的未来世界，每一本都有着严谨深刻的科幻设定，每一本都传递一种前沿的科幻思考。

## 把科幻作为思考方法，发现改变现实的力量

**你将有能力想象意料之外的未来。** 科幻设定大多指向近未来，基于可见的技术趋势，构想不久之后就会发生的现实。当虚构与现实的边界被打破，每一扇门都通向一种新的可能。我们在往返之间畅想、探索，直到有能力选择自己真正想要的未来。

**你能够在变化的时代保持变化。** 科幻最大的警示是：人类社会并非直线向前发展。好作品往往在回答三重问题——想象一个出乎意料的社会，审视这个社会中的困境，寻找解决困境的出路。它锻炼我们的头脑，让我们在未知来临时，依然保持灵活与从容。

**你会获得新商业新科技的创新燃料。** 这套丛书的作者本身就是跨界高手：机器人研究专家、神经科学家、航空航天工程师、人类学家。他们站在科技创新的前沿，为故事搭建坚实的骨架。当习惯以科幻的视角审视现实，我们就能卸下思维的重担，发现新的价值观，甚至催生全新的商业形态。

## 一个13岁女孩，如何承接“残心”？

回到《残心》的故事。第二章里，女孩卢翻出祖母年代的旧衣服——蓝色长裤硬邦邦的，米白T恤让人浑身不自在。她要去见一个叫西利娅的小女孩。为了这场会面，她被迫抛下了陪伴自己多年的机器人ROBul，做出“巨大牺牲”。医生告诉她，西利娅的头发最多在三年内会掉光，却没人能给一个确切的解释。她暗下决心，要为这个孩子找到真正的专家，要让所有人——包括总说领养“草率又没人性”的菲——都对西利娅刮目相看。

与此同时，克拉夫特博士正在享受他“畅快淋漓”的清晨：泡沫冲刷身体，音乐按摩情绪，所有需求都被机器人打理得井井有条。似乎一切都尽在掌控，除了那件他无法用科技解决的事——大脑的钝化，以及那颗需要被“按摩”的、属于人类的心。

作者卡梅·托拉斯在为中文版撰写的序言里说：我们创造技术，技术反过来也塑造我们。辅助型机器人正在帮助护理人员照料老人、辅助行动不便者穿衣进食、为轻度痴呆患者提供认知训练——但人机互动也在敲打伦理的边界：如何保障病患的自主决策权？如何维护他们的尊严？小说中的场景衍生出24个值得深思的伦理问题，附录中给出了讨论提示，可供课程或读书会使用。

“正是我们亲手建立的人际关系塑造了我们自己。”哲学家罗伯特·C.所罗门在1977年的《激情》中如此写道。

在一个人人被机器人围绕的未来世界，卢能否找到西利娅所需的真正专家？克拉夫特博士会被自己发明的“适应系统”反噬吗？人类那些无法被算法量化的情感，是否正是人性最后的堡垒？翻开《残心》，走进这个即将成真的近未来——你会看到一个关于技术和感情交织的故事，也会重新思考：当机器越来越像人，人到底意味着什么。
