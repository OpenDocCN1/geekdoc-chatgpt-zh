## 6.1 Niji 模型
Niji 模型由 Midjourney 与 Spellbrush 合作推出，经专门调校后在动漫风格图像生成上表现突出。①

调用方式很简单，在提示词后加上 “--niji” 即可。Niji 5 目前提供 Default Style 默认风格、Expressive Style 表现风格、Cute Style 可爱风格、Scenic Style 风景风格、Original Style 初始风格，可通过 “--style expressive/cute/scenic/original” 指定，未指定则使用默认。

### 6.1.1 添加 Niji 机器人
若需长期使用 Niji，可在自建服务器中添加 Niji 机器人，操作流程如下。

首先在 Discord 左侧点开“探索公开服务器”进入社区页面，如图 6-1 所示。

在社区页顶部搜索框输入“niji”或“niji journey”查找 Niji 社区，如图 6-2 所示。

从结果中选择 “niji • journey” 进入，如图 6-3 所示。

进入社区后在左侧列表挑选聊天频道，例如中文区的“图像生成”，如图 6-4 所示。

> ① “Niji” 源自日语“にじ”，意为彩虹或 2D。

在频道中任选一条 Niji 机器人的回复，点击其头像，即绿色小帆船图标，如图 6-5 所示。

在弹出菜单中点“添加至服务器”，如图 6-6 所示。

选择目标自定义服务器，例如自建服务器，点击“继续”再点“授权”，如图 6-7 和图 6-8 所示。

出现“已授权”的提示时，如图 6-9 所示，表示机器人已成功加入。

回到添加机器人的聊天室，输入“/”可在浮出面板看到新的 niji・journey 机器人，图标为绿色小帆船，使用其命令即可调用 Niji 模型。

执行“/imagine”时可加“--niji”指定模型版本，用“--style”指定风格，也可先通过“/settings”修改默认模型与风格等设置，如图 6-10 和图 6-11 所示。

至此部署完成。后续示例均通过 Niji 机器人交互生成，因此省略了“--niji”参数。若直接与 Midjourney 机器人交互，请记得加上“--niji”。
