**玩转 Arduino：从 DS3231 精准计时到超声波测距滤波实战**

在单片机开发中，获取精准时间与测量距离是两大高频刚需。今天我们不讲枯燥理论，直接通过两个完整的硬件实战案例——**基于 DS3231 的数码管时钟**与 **HC-SR04 超声波测距均值滤波**，带你攻克核心代码逻辑。

### 一、 DS3231 实时时钟：从串口输出到六位数码管驱动

DS3231 凭借内置温补晶振，是高精度 RTC 的首选。配合 Arduino 的 Wire 库（I2C 通信），读写时间仅需寥寥数行。

#### 1. 核心库与变量初始化
首先引入必要的库文件，并实例化时钟对象。为了适配 12/24 小时制切换，需预留 `h12`、`PM` 等标志位。

void contro(int pin1,int pin2,int pin3,int pin4,int pin5,int pin6){

    // 定义控制位引脚函数。

    digitalWrite(1,pin1);

    digitalWrite(2,pin2);

    digitalWrite(3,pin3);

    digitalWrite(4,pin4);

    digitalWrite(5,pin5);

    digitalWrite(6,pin6);

}

void ReadDS3231(){// 时钟子程序。

int second,minute,hour;

second=Clock.getSecond();// 读取秒。

minute=Clock.getMinute();// 读取分钟。

hour=Clock.getHour(h12,PM);// 读取小时。

s1=second% 10;//s1 = 秒数的个位。

s2=second/10;//s2= 秒数的十位。

m1=minute% 10;//m1= 分钟数的个位。

m2=minute/10;//m2= 分钟数的十位。

h1=hour% 10;//h1 = 小时数的个位。

h2=hour/10;//h2= 小时数的十位。

}

> **技术点拨**：
> 上述代码展示了两种进阶用法：**取模运算 (`%10`)、整除 (`/10`)** 快速拆解时分秒个十位；**动态扫描 (`scan` + `contro`)** 通过位选信号快速切换 6 位共阴/共阳数码管，配合 `disp0` 消影函数，实现无闪烁显示。注意 `mod` 变量控制扫描周期，配合差异化 `delay(3/4ms)` 可微调各位亮度均衡性。

### 二、 简单逻辑控制：整点报时/闪烁示例

利用分钟数归零的瞬间触发动作（如蜂鸣器响、LED 闪烁），代码极其精简。

[PRE4]cpp

pinMode(13,OUTPUT);// 设置数字端口 13 为输出状态。

if(minute==0()){

digitalWrite(13,1);

}

if(minute>0()){

digitalWrite(13,0);

}

> **逻辑解读**：当 `minute` 变量为 0 时（即整点），引脚 13 输出高电平点亮 LED；其余时间熄灭。实际项目中可替换为蜂鸣器驱动电路，实现整点报时功能。

### 三、 HC-SR04 超声波测距：从原理到工业级均值滤波

超声波测距核心公式：`距离 = 高电平时长 × 声速(340m/s) / 2`。工程落地时，必须解决**信号抖动**与**无效读数**问题。

#### 1. 硬件接口与触发时序
Trig 端口需给予 **10μs 以上高电平脉冲**（代码中写 20μs 更稳妥），模块内部自动发射 8 个 40kHz 方波并拉高 Echo 引脚等待回波。

[PRE5]cpp

digitalWrite(TrigPin,HIGH);// 超声波 Trig 引脚输出高电平。

delayMicroseconds(20);// 延时 20 μs。

digitalWrite(TrigPin,LOW);// 超声波 Trig 引脚输出低电平。

[PRE6]cpp

EchoTime_us=pulseIn(EchoPin,HIGH);

[PRE7]cpp

distance_cm=EchoTime_us/58.14;

> **常数由来**：`58.14 ≈ 1000000 / (340 * 100 / 2)`，单位换算得微秒转厘米系数。

#### 2. 多次采样均值滤波算法
单次读数极不稳定，引入**滑动窗口累加平均**机制：连续采集 5 次有效值求平均，有效抑制毛刺干扰。

  average=total/5;// 计算数组的平均数。

  num=0;//num 清零。

  total=0//total 清零

}

[PRE9]cpp

> **边界保护**：`pulseIn` 超时默认返回 0，或因干扰产生异常大数值。限定 `1μs ~ 60000μs`（约 1m 有效量程），剔除无效数据不参与累加。

#### 3. 完整工程代码集成
整合初始化、触发、读取、滤波、串口打印，形成可直接烧录的固件。
