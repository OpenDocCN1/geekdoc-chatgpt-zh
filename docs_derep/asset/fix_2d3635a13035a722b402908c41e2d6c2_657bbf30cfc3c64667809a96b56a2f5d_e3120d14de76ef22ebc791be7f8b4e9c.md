# 第3章 更多AI代码生成解决方案

目前 AI 代码生成工具已非常丰富，不可能长期只依赖 Copilot，更何况它还是付费的。本章将介绍更多可选工具，包括 ChatGPT、New Bing、Bard、Claude 等，以及 Copilot 的替代品 CodeGeeX 和 Amazon CodeWhisperer。有了这些工具，开发工作会更高效，体验也更加顺畅。

# 3.1 ChatGPT

本节介绍如何借助 ChatGPT 实现与编码相关的自动化。需要明确的是，ChatGPT 更像参谋，最终决策仍在使用者手中。虽然它能完成不少编码任务，但并不保证输出一定正确或最优，只能作为参考。因此 ChatGPT 不能完全取代程序员，只能提升效率，提升幅度因人而异，可能 30%，也可能 300% 甚至 1000%，这与个人能力相关。总的来说，ChatGPT 会让强者更强，但不一定能让弱者变强。

# 3.1.1 生成完整的代码

ChatGPT 最擅长的就是输出完整可运行的代码。对于 Python、C++、C、Java、Go、JavaScript、Rust、C# 等主流语言，在多数情况下都能按需求生成基本正确的源码。但要注意，需求越复杂，描述必须越精确，否则模型可能无法准确理解意图。
