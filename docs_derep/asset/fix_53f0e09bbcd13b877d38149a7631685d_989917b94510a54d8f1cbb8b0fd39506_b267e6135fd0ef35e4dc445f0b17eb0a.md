## 符号速览

**张量定位**
| $A_{ijk}$ | 张量 $\mathbf{A}$ 在下标 $(i,j,k)$ 对应的分量 |
| $\mathbf{A}_{::i}$ | 从 $\mathbf{A}$ 取出第 $i$ 个方向的二维截面 |

**数集与区间**
| 符号 | 含义 |
| :--- | :--- |
| $\mathbb{R}$ | 实数域 |
| $\mathbb{C}$ | 复数域 |
| $\{0, 1, \cdots, n\}$ | 0 至 $n$ 的整数集合 |
| $[a, b]$ | 端点皆包含的闭区间 |
| $(a, b]$ | 左端排除右端包含的区间 |

**线性代数**
| 符号 | 含义 |
| :--- | :--- |
| $A^\top$ | 矩阵 $A$ 的转置结果 |
| $A \odot B$ | 矩阵 $A$ 与 $B$ 的逐元素 Hadamard 乘法 |
| $\det(A)$ | 矩阵 $A$ 的行列式 |
| $[x; y]$ | 把向量 $x$ 置于 $y$ 上方的垂直拼接 |
| $[A; V]$ | 将矩阵 $A$ 与 $V$ 按行方向堆叠 |
| $x \cdot y$ 或 $x^\top y$ | 向量 $x$ 与 $y$ 的内积 |

**微积分**
| 符号 | 含义 |
| :--- | :--- |
| $\frac{dy}{dx}$ | $y$ 关于 $x$ 的导数 |
| $\frac{\partial y}{\partial x}$ | $y$ 对 $x$ 的偏导 |
| $\nabla_x y$ | $y$ 对向量 $x$ 的梯度 |
| $\nabla_X y$ | $y$ 对矩阵 $X$ 的梯度 |
| $\nabla_{\mathbb{X}} y$ | $y$ 对张量 $\mathbb{X}$ 的梯度 |

**概率与信息**
| 符号 | 含义 |
| :--- | :--- |
| $a \perp b$ | 变量 $a$ 与 $b$ 互不相关即独立 |
| $a \perp b \mid c$ | 在 $c$ 条件下 $a$ 与 $b$ 条件独立 |
| $P(a)$ | 离散变量的质量函数 |
| $p(a)$ | 连续变量的密度函数 |
| $a \sim P$ | $a$ 的分布为 $P$ |
| $\mathbb{E}_{x \sim P}(f(x))$ 或 $\mathbb{E}(f(x))$ | $f(x)$ 在 $P$ 下的数学期望 |
| $\text{Var}(f(x))$ | $f(x)$ 在 $P$ 下的方差 |
| $\text{Cov}(f(x), g(x))$ | $f(x)$ 与 $g(x)$ 在 $P$ 下的协方差 |
| $H(f(x))$ | 变量 $x$ 的熵 |
| $D_{\text{KL}}(P \parallel Q)$ | $P$ 与 $Q$ 之间的 KL 散度 |
| $\mathcal{N}(\mu, \Sigma)$ | 均值 $\mu$ 协方差 $\Sigma$ 的高斯分布 |

**数据与分布**
| 符号 | 含义 |
| :--- | :--- |
| $\mathbb{X}$ 或 $\mathbb{D}$ | 数据集合 |
| $x^{(i)}$ | 集合中第 $i$ 个输入样本 |
| $y^{(i)}$ | 样本 $x^{(i)}$ 对应的输出标签 |

**函数与运算**
$f : \mathcal{A} \longrightarrow \mathcal{B}$ 表示从定义域 $\mathcal{A}$ 到值域 $\mathcal{B}$ 的映射 $f$
$f \circ g$ 为 $f$ 与 $g$ 的复合映射
$f(x; \theta)$ 为参数 $\theta$ 控制下的关于 $x$ 的函数，可简写 $f(x)$
$\log x$ 为 $x$ 的自然对数
$\sigma(x)$ 为 Sigmoid $\frac{1}{1 + \exp(-x)}$
$\|x\|_p$ 为 $x$ 的 $L^p$ 范数，$\|x\|$ 为 $L^2$ 范数
$\mathbf{1}_{\text{condition}}$ 为示性函数，条件成立为 1 否则为 0

**本书记法**
- 词表记作 $\mathbb{V}$，规模为 $|\mathbb{V}|$
- 序列 $x = x_1, x_2, \cdots, x_n$ 中词 $x_i$ 的向量是 $v_{x_i}$
- 损失 $\mathcal{L}$ 采用负对数似然：$\mathcal{L}(\theta) = -\sum_{(x,y)} \log P(y|x_1 x_2 \cdots x_n)$
- 空间复杂度记为 $\mathcal{O}(mn)$

# 第 1 章 绪论

大模型通常由上百亿乃至更多参数的深度网络构成，训练多靠自监督，在海量无标注文本上学习。自 2018 年起 Google、OpenAI、Meta、百度、华为等机构相继发布 BERT[1]、GPT[6] 等系列，几乎在所有 NLP 任务上取得领先。2019 年后体量加速膨胀，2022 年 11 月 ChatGPT 上线引发全球热议。用户可自然语言交互，模型能完成问答、分类、摘要、翻译、闲聊等从理解到生成的任务，展现出对常识与语言规律的强把握。

本章梳理大语言模型的核心概念、演进脉络与构建流程。

## 1.1 大语言模型的基本概念

语言是人类与其他物种的根本分野，人类的思维与知识长期依托语言承载。如今互联网汇聚数万亿网页，绝大多数信息以自然语言呈现。让 AI 获取知识的前提是理解这种不精确、易歧义且略显杂乱的人类表达。语言模型的目标即对自然语言的概率分布进行建模。

在词表 $\mathbb{V}$ 上，语言模型可写成 $P(w_1w_2\cdots w_m)$，即词串 $w_1w_2\cdots w_m$ 出现的概率。直接建模联合概率 $P(w_1w_2\cdots w_m)$ 的参数规模极大。以《现代汉语词典》第 7 版约 7 万词计，句长取 20，参数量已达 $7.9792 \times 10^{96}$，中文实际常出现上百词的长句，全面枚举的复杂度远超当前算力。

为压缩参数空间，可把句子视为逐词生成的过程，用链式法则分解：

[PRE0]

[PRE1]

于是 $w_1w_2\cdots w_m$ 的生成被拆成条件生成，先产出 $w_1$，再依据 $w_1$ 产出 $w_2$，依次类推至 $w_m$。例如“把努力变成一种习惯”的概率可写为

$P(\text{把 努力 变成 一种 习惯}) = P(\text{把}) \times P(\text{努力}|\text{把}) \times P(\text{变成}|\text{把 努力}) \times P(\text{一种}|\text{把 努力 变成}) \times P(\text{习惯}|\text{把 努力 变成 一种})$ (1.2)

链式分解把联合概率转为条件概率的乘积，但 $P(w_m|w_1 w_2 \cdots w_{m-1})$ 的参数量仍是天文级。进一步做马尔可夫假设，认为 $w_i$ 只受其前 $n-1$ 个词影响：

$P(w_i|w_1 w_2 \cdots w_{i-1}) = P(w_i|w_{i-(n-1)} w_{i-(n-2)} \cdots w_{i-1})$

$P(w_i|w_1^{i-1}) = P(w_i|w_{i-n+1}^{i-1})$ (1.3)

满足此假设的模型即 $n$-gram 模型，$n$-gram 指连续 $n$ 个词构成的单元。

$n$-gram 缓解了零概率问题，但语言可能性无穷，数据无法覆盖所有 $n$-gram。训练中的零频不等于零概率，需用平滑技术为所有可能串赋予非零概率。平滑是对最大似然估计的修正，属于统计语言模型范畴，具体可参考《自然语言处理导论》第 6 章[8]。

总体看，$n$-gram 效果与数据量、模型阶数及平滑策略密切相关。尽管平滑解决了零概率，基于稀疏表示的 $n$-gram 仍有明显局限：

- 难以建模长度超过 $n$ 的长距离依赖
- 平滑多依赖人工规则设计
- $n$ 增大时数据稀疏加剧，参数量指数增长，难以精确学习
