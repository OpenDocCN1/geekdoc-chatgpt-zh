对某个神经元，*x* 到 *y* 的对应关系 *f*[*w*]，*b* 虽然未知但确定不变。两点定一直线，只需在图 2.3 上任取两组观测 (*x*^(1)，*y*^(1))、(*x*^(2)，*y*^(2)) 就能反推参数：

## 2.2　优化方法

回过头看，目标是找最优参数 *w*^*、*b*^* 令 *y*^(i) = *w x*^(i) + *b*，*i*∈[1，*n*]。受观测误差 *ε* 影响，需要用足够多的样本组成数据集 *D* = {（*x*^(1)，*y*^(1)），（*x*^(2)，*y*^(2)），…，（*x*^(n)，*y*^(n)）}，让均方误差[PRE9]最小。

单输入情形两样本就能用消元得到精确解，这种靠公式推导的解叫解析解 Closed-form Solution。数据量 *n*≫2 时往往不存在解析解，只能借助数值方法 Optimize 求近似数值解 Numerical Solution。计算机算得快，可以反复“搜索”和“试错”逐步降低误差[PRE10]。最笨的方法是暴力搜索或随机试验：从实数空间里随机挑 *w*、*b*，算出模型误差值[PRE11]，然后在已测试的{[PRE12]}里挑出最好的[PRE13]^(*)，对应的 *w*、*b* 暂作最优。

这种做法直观但高维大数据下基本不可行。梯度下降 Gradient Descent 是神经网络训练的主流优化算法，配合 GPU Graphics Processing Unit 的并行加速，处理海量数据很契合，也适合线性神经元。这里先用它解决预测问题，详细推导留在第 7 章。

## 2.4　线性回归

回顾探索路径：假设 *n* 输入生物神经元为线性模型，*n*+1 个点可估计 *w*、*b*。引入观测误差后，用梯度下降采样多组点循环优化即可得到数值解。

换个视角，这其实是连续值的预测问题。给定数据集 *D*，从 *D* 中学到真实模型以预测未见样本。若模型类型确定，学习就变成参数搜索，如线性模型即搜索 *w*、*b*。训练完成后，对任意新输入 *x* 都能用学到的模型近似真实输出。这就是回归 Regression 问题。特别地，用线性模型逼近真实模型时称为线性回归 Linear Regression，简称 LR，它是回归的一种具体实现。

现实中连续预测无处不在：股价走势、气温湿度预报、年龄估计、交通流量等。预测值落在实数区间的问题都归为回归。相对的，若预测值只有有限几种可能，如硬币正反、图片类别猫狗天空，则属于分类 Classification 问题，将在第 3 章介绍。
