## 1.1 AI 编程概览

面对各种编程语言的语法规则，你是否曾想过不用学习复杂代码也能把想要的软件做出来？比如为自己搭建个人网站、做一个记录饮食的小工具，甚至复刻小时候玩的坦克大战。

现在借助 AI 编程，想法就能落地——不必精通语言，只要会用日常表达，AI 即可帮你生成程序。

### 1.1.1 AI 编程的演进脉络

传统开发像是用外语与电脑沟通，必须牢记 Python、Java、JavaScript 等语言的语法。例如做一个带按钮的 HTML5 页面，点击后弹出“欢迎使用”的提示，手工编写需要数十行代码：

技术演进让 AI 编程逐步改变现状，大致经历三个关键阶段。

#### 阶段 1：智能补全起步

为了提升效率，出现了大量代码补全工具。它们像智能输入法一样联想补全。比如在 `<script>` 后自动补上 `</script>`，输入“f”就提示“function”。

这个阶段工具主要服务程序员提效，使用者仍需具备一定基础，对新手帮助有限。

#### 阶段 2：自然语言生成函数

2021 年 GitHub Copilot 发布后引起关注。它不再只是补全，而是能根据注释生成完整函数。只需用自然语言写明需求，例如“// 用快速排序的方法给数组排序”，按 Tab 就能得到对应实现：

突破在于需求可以用自然语言描述，AI 输出函数或代码块。开发效率大幅提升，但主要面向开发者，非程序员门槛仍高。

#### 阶段 3：全流程对话式开发

当前 Cursor、Windsurf、通义灵码、TRAE 等工具的代码生成能力已质变，能一次性产出整页甚至多页应用，实现用口语开发完整产品。

例如告诉工具：“生成一个 HTML5 页面，页面上有一个按钮，单击后弹出‘欢迎使用’。”工具就会自动生成完整页面。

从补全到生成函数再到全流程对话，AI 编程正变得越来越懂人。

### 1.1.2 学 AI 编程难吗？零基础也能迅速上手

担心学不会？AI 编程的思路与传统编程不同。你只需学会清晰表达需求，比如把“做登录功能”细化为“做登录功能，页面有用户名输入框、密码输入框、登录按钮，点击后校验账号密码”。

通过实战项目，例如开发一个计算器，在实践中把握“功能→代码→实现”的逻辑，就像搭积木一样拼出软件。输入需求时，工具会主动提示可选配置，如“是否需要对接数据库？”“是否需要生成移动端适配界面？”按提示逐步操作即可。

告别背诵语法和翻阅文档，直接用口语描述需求。过去写 100 行代码的时间，现在一句话搞定。学生、产品经理等非技术岗位也能轻松入门。

## 1.2 选择 DeepSeek 与 Cursor 的原因

市面 AI 编程工具众多，为何选用 DeepSeek 与 Cursor？它们更像开发路上的搭档：

- DeepSeek 擅长“想清楚做什么”，帮你把模糊创意梳理成可落地的方案。
- Cursor 擅长“快速实现怎么做”，帮你生成代码把方案做出来。

二者配合，可让零基础者完整走通“需求设计→开发落地→上线发布”流程，实现所想即所得。

### 1.2.1 DeepSeek 助力产品设计：把想法转化为可行方案

仅有一个模糊想法，比如“我想做个人网站展示设计作品”，却不知如何规划，DeepSeek 就像免费的产品经理。把想法交给它，它会深度思考并拆解需求。从战略定位、视觉架构、技术实现到内容运营体系等多维度给出规划，如图 1-1 所示。

### 1.2.2 Cursor 助力高效开发

DeepSeek 解决做什么，Cursor 专注如何快做。Cursor 既是代码编辑器，也是能理解自然语言的智能编程助手。

> 提示 即使完全不懂 HTML、CSS、JavaScript，也能通过对话让 Cursor 生成代码、调试程序，完成复杂功能。

选择 Cursor 主要有三点优势。

#### 1. 无缝兼容 VSCode 生态，新手易上手

Cursor 本质是 VSCode 的 AI 增强版，支持一键迁移插件、主题、快捷键和配置文件。用过 VSCode 可直接切换；新手也能快速适应，左侧文件目录、右侧编辑区、对话输入框一目了然。轻量化设计无需额外学习，即可专注功能实现。

#### 2. 多模型支持，复杂需求一句话搞定

Cursor 支持 Claude 3.5、Claude 3.7 等多种模型，并可推理。

- 简单需求：选 Claude 3.5，生成更快。
- 复杂需求：用 Claude 3.7，自动拆解并生成多文件。例如要求“做一个登录功能，页面有用户名输入框、密码输入框、登录按钮，点击后验证账号密码”。Cursor 会自动拆解前后端需求，生成含前端、后端、数据库脚本的完整代码，并提示数据库配置、建表等操作。

#### 3. 智能调试与代码优化，即时解决报错

新手最怕报错，在 Cursor 中可轻松处理。

程序运行报错如“数据库连接失败”时，复制报错信息输入“修复这个错误”，Cursor 会分析上下文定位问题，如端口错误、账号密码错误等，并给出修改建议甚至直接生成修复后代码。

对代码风格不满意，如“希望使用更简洁的 ES6 语法”，输入“优化这段代码，使用箭头函数和模板字符串”，Cursor 会自动重构，功能保持不变。

对话式调试让你无需死记 API 文档，专注逻辑优化。

## 1.3 DeepSeek 对话技巧与最佳实践

在用 DeepSeek 做产品设计时，掌握沟通技巧能显著提升效率，就像与资深专家交流，表达越准确收获越多。

### 1.3.1 明确需求，精准提问

对话时清晰表达需求是关键，避免模糊表述，尽量细化。

比如设计电商 App，不要只说“帮我设计一个电商 App”。可以这样问：“我想设计一款面向年轻女性的时尚电商 App，目标用户注重个性化推荐和社交互动，帮我规划首页布局和主要功能模块。”详尽描述让输出更贴合预期。

> **提示** 阐述需求时可举具体例子辅助说明。如“我希望搜索功能像淘宝那样，有热门推荐，输入关键词时实时显示相关商品。”这样 DeepSeek 能更直观理解期望。

### 1.3.2 多轮对话，逐步深入

产品设计很难一次完成，多轮对话有助于深挖需求、完善方案。

首轮先确定大致方向和核心功能，如在线教育 App 的课程分类、注册登录等。随后逐步细化，例如课程详情页的介绍、讲师信息、学员评价等板块布局。

> **提示** 对话中根据建议不断调整需求。若 DeepSeek 提出有价值的功能或设计点，可及时纳入后续方案。

多轮对话还能挖掘潜在需求。如设计购物车时，可能逐步发现需要批量删除、价格校验等细节，这些在一开始容易被忽略。

### 1.3.3 用引导性问题拓展思路

DeepSeek 知识储备丰富，通过引导问题可激发更多角度思考。

例如设计健身 App 时，可问：“有什么创新方式能提升用户长期健身兴趣？比如加入社交或游戏化设计。”可能得到挑战赛、用户竞赛、虚拟奖励等建议，提升产品竞争力。

设计界面时，也可用引导问题获取灵感：“简约风格的音乐播放 App 界面，有哪些独特的配色和图标设计能提升体验？”可获得流行配色组合和创意图标建议。

### 1.3.4 参考成功案例，对比优化

参考成熟产品很有帮助。想做短视频 App 时，可问：“我很喜欢抖音和快手的推荐算法和互动方式，如何在借鉴优点的基础上做出差异化？”

DeepSeek 会分析案例优势，结合你的产品特点给出建议。通过对比界面、内容展示、操作流程等差异，更好理解设计优劣，优化自己的方案。提及具体功能案例，也能让 DeepSeek 更清晰把握效果。

## 1.4 Cursor 入门

### 1.4.1 Cursor 简介与特点

Cursor 是深度融合 AI 的先进代码编辑工具，由 Anysphere 开发，在 VSCode 基础上深度定制。保留了 VSCode 的强大功能和熟悉界面，同时集成强力 AI，提供全新编程体验。

> 提示 专业开发者和编程新手都能借助 Cursor 更高效完成编写、调试和项目开发。

#### 1. 自然语言交互

最突出特点是支持自然语言。传统编程需熟悉语法手动输入大量代码，而 Cursor 只需口语化描述需求，如“创建一个 Python 函数计算两个数之和”，即可快速生成代码。大幅降低门槛，提升效率。

#### 2. 代码生成与补全能力强

AI 引擎可根据自然语言指令生成完整片段，也能在编写时实时提供补全建议。基于上下文和常见模式预测下一步输入，生成代码质量高、规范。例如快速生成 Web 应用后端接口的路由、请求处理和数据库交互框架。

#### 3. 智能调试与错误修复

调试是开发耗时环节。Cursor 能自动检测错误并给出提示和修复建议。运行出错时反馈错误信息，它会分析根因并提供方案，必要时直接修改代码修复。显著缩短调试时间。

#### 4. 无缝集成 VSCode 生态

基于 VSCode 定制，可无缝使用丰富的插件生态，如代码格式化、版本控制等，同时享受 AI 增强功能。迁移成本几乎为零。

> 提示 Cursor 保留了 VSCode 的快捷键和操作习惯，使用体验一致。

#### 5. 多语言支持

支持 Python、Java、JavaScript、C++ 等主流语言。无论 Web 开发、数据科学、人工智能或移动应用，都可满足需求，并根据语言特点提供准确支持。
