● 文化适配：指在目标语言中完成价值观与意识形态的对齐，以及对文化专有要素的处理等一系列文化层面的工作，以保证受众能够理解并接受。这类任务通常需要译者手工精细把控，因为大语言模型独自面对文化差异时应对能力有限。

三块工作并非彼此独立，而是相互交织，最终的处理都必须通过语言文字来呈现。

在纯人工翻译的年代，以上全部环节都由译者承担。而在当下大语言模型普及的语境里，并非外界非专业人士所想的那样全部可被AI自动化完成。实际上AI的介入程度是逐项递减的；换句话说，在人机协同的生产模式中，译者的精力应更多向后两项靠拢。

4.5 提示词

提示词是激活AI潜能的“钥匙”，核心在于用精准的表达实现“控制”与“开放”的平衡：既划清任务边界，又留给AI合理的创作与推理空间。掌握不同框架并灵活结合场景，能显著提高输出质量与效率。

提示词的作用包括：

● 明确任务目标：告知AI具体要做什么。
● 控制输出方向：限定风格、格式、篇幅、视角等。
● 提升生成质量：通过补充背景、关键词、范例等减少错误、增强专业性。
● 适配多场景：在翻译、写作、编程、设计等领域灵活切换功能。

高效提示词应具备：清晰无歧义、具体详实、结构合理、灵活可调、保持适度开放。

4.6 AI幻觉

AI幻觉是指大语言模型等AI系统在生成文本或决策时，产出与事实不符或不合理的现象。

常见表现：

● 事实性错误：历史时间、人物关系等信息出错。
● 逻辑混乱：内容自相矛盾或不连贯。
● 无中生有：编造现实中不存在的概念、事件或细节。

主要成因：

● 数据偏差：训练语料含错误、不完整或偏见信息。
● 模型局限：基于统计模式学习，难以真正理解深层语义与上下文。
● 复杂任务挑战：面对需深度推理或高度专业性的任务时能力不足。

对幻觉的反应不应过度。关键是译文绝不能直接交付，必须经人工核查修改，杜绝幻觉进入终稿是译者的责任。不能因存在幻觉就否定AI的价值。事实上网络上大量用户生成内容本身就充斥胡说八道，缺乏判断力的人易被误导。用此类语料训练的模型产生幻觉不可避免。因此译者与内容生产者有义务保证产出内容经得起检验。

# 第六章

# 从概念到落地：构建混合式翻译生产模式

上一章介绍了混合式翻译生产的准备知识，本章以图书翻译为例，讲解全流程AI赋能的方法，以提高质量、加快交付。需遵循前章翻译战略的设定，按客户与委托方的质量、时间与交付形式要求保质保量完成。

## 1.混合式翻译生产的定义

人类译者与大语言模型混合式翻译生产是融合人工智能技术的翻译范式。通过无缝整合大语言模型、AI搜索引擎、计算机辅助翻译工具如Trados、MemoQ与译者的核心能力——认知判断、文化适配与质量评估——实现效能最优化。该模式的核心是一个动态协作的两阶段流程：

● 人驱预处理：译者提供精炼提示词，引导大语言模型完成初译。
● 机辅精修：在大模型支持下，译者对初稿深度润色与优化。

其中大模型主要承担标准化、规模化任务，如按提示词高速文本转换、初稿润色、质量初评与一致性检查。译者则聚焦高认知判断环节：

● 语义消歧与文化适配
● 逻辑重构与风格优化
● 专有名词及术语核验
● 复杂模糊语境下的关键决策

译者的核心成果随后借助大模型与AI搜索引擎进行辅助修订与完善。

2.准备阶段

客户要求

项目启动前明确客户具体要求是保证质量与顺利推进的关键。核心在于从内容、语言、质量、时间、交付等多维度对齐期望，确保高效产出。具体要求应以文字形式载入委托合同。

需了解的核心需求包括：

● 翻译内容与交付格式：需翻译的范围，如图书注释、参考文献、索引是否翻译；交付文件纸质或电子、可否编辑；交付形式为双语对照还是单语，是否需要注释、索引、校对标记如Track Changes，是否包含记忆库、术语库、SDLXLIFF等资源；文件格式；图片是否需要高清；其他特殊需求与增值服务。
● 语言对与目标读者：目标语言及变体，如英式或美式英语、简体或繁体中文；目标读者是大众、专业人士或青少年等。
● 用途与场景：内容用于内部参考还是正式出版，是阅读还是口头表达，传播媒介是什么。
● 质量与风格要求：是否需严格对应原文，语气调性如何，有无具体风格指南如标点、数字格式、单位换算等。
● 截止日期：初稿提交、修订反馈、最终交付的时间节点，是否需分阶段交付及紧急程度。
