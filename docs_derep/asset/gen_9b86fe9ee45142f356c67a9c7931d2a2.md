在一个卷积层中，如果输出特征图的尺寸为 $S_O \times S_O$，每个输出单元都由卷积核在对应窗口上产生，那么整体需要完成 $S_O \times S_O$ 个窗口的计算，这恰好可以用 $S_O \times S_O$ 个神经元同时承担，神经元层面的最大并行规模也就等于 $S_O \times S_O$。在这种并行模式下，所有窗口共用同一组卷积核参数，而相邻窗口的输入区域会相互重叠，重叠区的数据是可以重复使用的。把这种重用性充分利用起来，就能在并行推进的同时减小片上缓存的占用、降低数据读写频次，从而在降低芯片功耗的同时提升计算性能。

## 3）通道维度并行：输入特征图
绝大多数卷积神经网络要处理多通道输入，例如 RGB 图像就有 3 个输入特征图。一个卷积核的通道数通常与输入图像的通道数一致。每个通道的特征图进入卷积层后，会与卷积核中该通道对应的权重矩阵做二维卷积，且不同通道的权重只与对应通道的特征图相乘，得到单通道的输出特征矩阵，随后各通道的输出矩阵相加后形成该卷积核的最终输出特征图。

由于单核内部的多通道权重在运算时互不干涉，输入的多通道特征图本身也相互独立，因而可以在通道层面展开并行，业内称之为输入特征图并行。以 RGB 为例，通道数为 3，就可用卷积核的 3 个通道权重同时做卷积，N 通道输入图像的最大并行度就是 N。在这种方式下，不同二维卷积之间的数据没有交集也无依赖，只要硬件带宽和算力足够，就能直接并行执行输入特征图的计算。

## 4）核维度并行：输出特征图
卷积层往往需要用多个不同的卷积核来提取形状轮廓、颜色纹理等多种特征。同一幅图像送入后，不同的卷积核会分别计算并产生各自的输出特征图，输出特征图的数量与卷积核数量相等。多个卷积核之间数据独立、互不依赖，因此可以并行执行并分别得到各自的输出，这类并行方式被称为输出特征图并行。

对于包含 M 个卷积核的卷积层，在输出特征图层级的最大并行度为 M。此时各卷积核的权重各不相同没有重合，但输入特征图数据会被所有核共享。充分利用输入数据的复用，就能在获得较大并行度的同时减少对片外数据的读写需求，降低能耗。

## 5）任务维度并行：批量处理
实际部署时常为了提高带宽和算力利用率，一次送入一批图像进行批处理。若一批包含 P 张图，则批处理的并行度为 P。同一模型对批量中的不同图像使用相同的卷积层，网络权重可以复用。批量处理有助于更合理地利用片上缓存，让已搬运到芯片内的权重被充分使用，避免频繁的内存访问，从而降低搬运功耗和时延。同时，批量输入也能满足片上海量计算资源的数据供给需求，使多个任务并行加速，提升硬件利用率和整体吞吐量，属于任务级别的并行，但对硬件资源的要求较高。

根据实际条件灵活组合卷积层的并行方式，就能较好地加速网络计算。综合来看，对一个参数固定的卷积层，不同层级的并行可以叠加。理论上最大并行度为各层级并行度的乘积，如式(1-5)所示，K×K 为突触并行度，S₀×S₀ 为神经元并行度，N 为输入特征图并行，M 为输出特征图并行，一次批处理输入图像数为 P。达到最大并行度等价于卷积层中所有的乘法能在同一时刻完成。

最大并行度 $= K \times K \times S_O \times S_O \times N \times M \times P$ (1-5)

例如输入特征图通道数 $N=3$，卷积核宽高 $K=3$，卷积核个数 $M=4$，输出特征图维度 $S_O=6$。先做突触并行，$3 \times 3$ 的乘法并行度为 9；再做神经元并行，$6 \times 6$ 的输出特征图可由 36 个神经元同时计算；输入特征图并行带来 3 倍；输出特征图并行带来 4 倍。若一次处理 10 张图，还能增加 10 倍的维度。于是该层最大并行度为 $3 \times 3 \times 6 \times 6 \times 3 \times 4 \times 10 = 38\ 880$，即可以同时进行 38 880 次乘法运算，并行规模相当可观。

[PRE0]

然而现实中，受限于图规模、核数量和批量的体量，以当前硬件资源和架构来看，卷积层很难达到理论最大值。除卷积外的其他计算也难以完全并行，阿姆达尔定律的制约同样作用于实际加速比。市面上各种加速器本质上都是在不同维度的并行度之间寻找最优平衡点，以实现软硬件体系的优化。

# 第 2 章

## 行业大势
深度学习高速发展期间，英伟达持续在 GPU 上发力，相继推出 Volta 与 Turing 架构以满足庞大算力需求。微软在数据中心用 FPGA 替代 CPU 处理计算密集型任务，谷歌则为深度神经网络量身打造 TPU 芯片，标志着特定域架构 DSA 的兴起。在此背景下，华为推出自研昇腾 AI 处理器，面向研究、开发与部署提供更高算力、更低能耗的芯片，引发行业热潮。与此同时，越发成熟的深度学习开源框架提供了高效开发平台，让研究者专注算法而无需过多关心实现细节。软硬件协同发展已成大势。

## 2.1 神经网络芯片现状

### 2.1.1 CPU
在计算机发展史上 CPU 扮演不可替代的角色。早期性能遵循摩尔定律逐年提升，支撑上层软件加速。近年来摩尔定律放缓，物理极限、散热和功耗制约导致传统 CPU 串行程序性能难以上升。随后多核处理器兴起，英特尔酷睿 i7 系列基于 x86 指令集采用 4 个独立核心构建指令并行，提升运行速度，但核心数无法无限制增加，且大量传统程序仍以串行思路编写，难以加速。

人工智能浪潮中深度学习对算力和存储带宽需求攀升，传统 CPU 面前显得力不从心。软硬件双重挑战促使人们转向支持大规模并行计算的新型芯片，一场行业变革悄然展开。

### 2.1.2 GPU
英伟达早期的 GeForce GTX 280 显卡采用由多个流处理器 SM 构成的 GPU，并支持单指令多线程 SIMT 处理方式，为高吞吐运算尤其是浮点运算带来突破。与多核 CPU 不同，GPU 不强调指令控制逻辑，也不盲目扩大缓存以避免时延，主要依靠挖掘程序内在的数据并行性来提升吞吐，使数据密集型程序远超 CPU 性能。GPU 逐步进入超级计算及自动驾驶、生物分子仿真、医药制造、智能视频分析、实时翻译、深度学习等领域。

GPU 与 CPU 侧重点不同，CPU 擅长复杂逻辑与多种数据类型混合计算，GPU 在大规模密集规则数据计算上优势明显。通常 CPU 处理串行部分，GPU 加速大规模并行部分。为实现协同，英伟达提出 CUDA 计算统一设备架构，提供 GPU 直接访问接口，屏蔽传统图形 API，可用类 C 语言编程，为系统补充强大并行算力。类 C 语言门槛低，便于快速验证方案，CUDA 方案被广泛应用于科学、商业与工业计算。

随着深度学习兴起，GPU 因矩阵与并行计算优势最早被引入作为专用加速芯片，成为核心计算器件，目前在智能终端与数据中心均广泛部署。英伟达随后推出配备张量核的 Volta 与 Turing 架构新品，推动硬件演进。

英伟达基于 Turing 架构的 TU102 芯片，如图 2-1 所示，既支持通用运算，也能加速专用神经网络计算。该芯片采用 12nm 工艺，面积超 700mm²，集成大量张量单元，支持 FP32、FP16、INT32、INT8、INT4 等多种精度。硬件算力常用 TFLOPS 或 TOPS 衡量。
