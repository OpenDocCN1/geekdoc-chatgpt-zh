这段代码示例把一次 function calling 的完整交互走了一遍。开头先用 JSON Schema 把 get_current_weather 这个能力的接口描述清楚。用户抛出天气相关的提问时，应用会把原始问句和能力定义一起送给 DeepSeek 的 LLM 进行理解。经分析若判定需要借助外部能力，模型会返回一个 tool_calls 指令，其中包含函数名以及对应的输入参数。应用解析该指令后，调用本地的 get_current_weather_implementation 做实际执行，并把执行结果封装成一条 tool 消息。随后，应用把这条结果消息连同完整的对话历史再次喂回 LLM，LLM 便能基于全部上下文给出最终的自然语言回答。

需要特别注意，示例里的 get_current_weather_implementation 仅为演示实现。落地时，开发者需要在此处接入真实的天气服务 API，并做好网络异常、限流、解析错误等各类容错处理。并且，模型返回的参数在进入执行函数前，必须经过严格的业务与安全校验，以避免风险或异常行为。我们建议实际集成时始终以 DeepSeek 官方文档为基准，获取最新且权威的 API 说明与使用规范。

## 第8章 AI Agent：迈向真正自主的智能体

前几章我们已拼凑出驱动先进 AI 应用的核心部件：能够深度理解并生成文本的 LLM、高效沟通的提示词工程、拓展知识边界的检索增强生成 RAG，以及赋予模型行动能力的 function calling。现在把这些部件组合起来，就能打造更高阶、更自主的智能系统——AI Agent。它能够围绕用户设定的上层目标，自主规划、调用能力、获取信息、复盘进展并最终收敛到目标，这标志着人机协作从被动应答转向主动执行的范式迁移。

本章将深入 Agent 的前沿。我们先厘清其核心概念与特征，并与常规 LLM 应用做本质区分；再剖析以 LLM 为“大脑”的 Agent 核心架构，解读规划、记忆、能力使用、反思与自我修正等关键模块的设计思路与协作方式；随后盘点 LangChain、LlamaIndex、Microsoft AutoGen 等主流开发框架，为技术选型提供参考。最后展望 Agent 在企业场景的应用潜力、典型案例，以及面临的挑战与未来走向。对希望在内部实现更高层次自动化、把 AI 深植到核心业务流程的企业而言，理解 Agent 具有重要战略意义。

### 8.1 从被动式助手到具备自主决策能力的智能体

动手之前，先把 Agent 的定义厘清。Agent 可被理解为一种计算实体或系统，它能持续感知环境，通过内部决策机制处理信息，并据此采取行动去影响环境，从而达成预设目标。其架构示意图如图8-1所示。

[PRE1]
图8-1 智能体架构图

一个典型的 Agent 具备几大核心特质：以目标为牵引，所有行为都围绕一个或多个清晰的上层目标展开，行动服务于最大化达成目标的可能性；环境感知，通过调用搜索 API、文件读写、数据库接口等能力，从数字或物理环境中获取信息与状态变化；高度自主，这是与传统 AI 助手的分水岭，能够主动进行任务规划、路径选择并持续推进执行，无需人工逐 step 指引；对环境变化的敏感反应，能敏锐捕捉变化并及时调整计划与策略；主动行动，不仅被动响应，还能主动寻找新机会或按预设策略出手。

构建 Agent 的终极目的，是打造足够聪明的系统，来替代或辅助人类完成复杂、多步骤、需要大量外部交互的任务，从而提升效率、延展人类能力，并在各领域实现更高程度的自动化与智能化。

Agent 与常规 LLM 应用，比如聊天机器人、RAG 系统、简单的 function calling 助手，本质不同。驱动方式上，前者直接受用户即时指令驱动，行为边界受限于当前指令；后者受更上层的、可能模糊的长期目标驱动。行为模式上，前者是被动响应请求，后者是主动规划并持续执行一系列动作以达成宏观目标。自主性与规划能力是最大差异，前者自主性低、依赖每步人工指令；后者追求高自主性，能独立决策行动。常规应用几乎不具备规划，而规划是 Agent 的灵魂，需要把上层目标拆解为可执行步骤。交互模式上，前者多为一次性或短期的请求-响应序列，后者是持续的感知-思考-行动闭环。状态与记忆上，前者通常无状态或仅靠模型上下文窗口做短期记忆，后者必须依赖多层次记忆系统，包含短期工作记忆与长期经验记忆，以追踪进展、记录环境并从经验中学习。目标复杂度上，前者擅长单一明确任务，后者面向更复杂、开放式、需要多步骤协作的宏观目标。

Agent 的思想并非 LLM 时代才出现，其根源可追溯到 AI 起步期的经典规划、强化学习与机器人学。LLM 的革命性能力，如上下文学习、指令遵循、初步推理，为构建更通用灵活的 Agent 提供了前所未有的“大脑”，极大推动了 LLM-based Agent 的发展。回顾关键节点：早期基于规则或符号 AI 的探索，在封闭环境里展现智能却泛化不足；强化学习的兴起提供了强大的决策数学框架，AlphaGo/AlphaZero 在封闭领域取得典范成绩，但直接迁移到开放通用任务仍受制于样本效率低、奖励设计难等问题。

真正的拐点是生成式 LLM 的涌现，随后 2022 年提出的 ReAct 框架成为里程碑。ReAct 让 LLM 交替进行“思考”与“行动”的迭代：先接收目标与初始观察，生成分析、理解、计划的“思考”文本，再输出具体的“行动”指令，通常是能力调用。能力的执行结果作为新的“观察”反馈回去，模型进入下一轮“思考-行动”，直至目标达成。ReAct 证明显式思考能指导行动选择与能力使用，并借助外部反馈动态调整。

2023 年初，AutoGPT、BabyAGI 等现象级开源项目爆发，点燃了公众对自主 Agent 的热情。它们的核心是让 Agent 完全自主运行：接收上层目标后自行拆解为任务清单，按优先级挑选执行、选择能力、根据结果自生新任务并迭代，直到完成。早期版本在可靠性、成本上还有短板，但其思想极具启发性。为降低工程门槛，LangChain、LlamaIndex、Microsoft AutoGen 等专业化开发框架快速兴起，提供模块化组件与现成逻辑，简化开发、测试与部署。如今 LLM-based Agent 仍处在快速演进与挑战并存的探索期，但其潜力已指向未来 AI 应用的核心方向。

### 8.2 以大模型为“智能大脑”的协同系统

要让 Agent 功能完备并稳定执行复杂任务，需要把多个相互依赖的关键技术组件整合起来协同工作。在这个体系里，强大的 LLM 扮演核心的“大脑”或“中央认知与决策引擎”角色。弄清各组件的功能定位、相互作用方式，以及它们如何共同支撑自主行为，是后续设计、实现与优化 Agent 的基础。
