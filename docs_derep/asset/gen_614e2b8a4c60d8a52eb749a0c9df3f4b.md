# 第 2 章 对抗样本攻击

# 2.4.1 目标检测原理

主流目标检测模型可分为单阶段与双阶段。双阶段的代表是 Faster RCNN，它拥有显式的候选区域生成步骤：先在图像上筛选出可能包含物体的候选框，再逐框判断是否存在物体并给出类别与位置。精度较高但速度慢；单阶段的代表是 SSD、YOLO V2 等，没有显式的候选区域步骤，直接从输入图像输出类别与位置，速度快但精度相对低。

受计算资源与时延限制，实际中更常用单阶段模型，而 YOLO V2 是经典代表，故本节以其作为攻击目标。YOLO V1 先把原图切分为若干互不重叠的小格，通过卷积得到与格子同尺寸的特征图，每个特征单元对应一个格子，负责预测格内中心的物体。YOLO V2 在此基础上引入了 Anchor，并用 K-means 对训练集的 Bounding Box 聚类寻找合适的 Anchor Box，从而提升检测能力。同时引入 Batchnorm 层并采用多尺度训练来增强性能。更详尽内容可参考原论文。需要留意的是，对每个 Anchor，YOLO V2 会同时输出边界框、该 Anchor 包含物体的置信度以及类别。

# 2.4.2 目标检测攻击原理

Simen Thys 等人①提出了一种针对 YOLO V2 的物理攻击方案，效果较好，下面展开说明。

真实物理场景中物体种类繁多，这里以最常见的人类作为攻击对象。物理世界无法对整个场景进行干扰，只能做局部扰动，因此目标是生成可打印的块 Patch，贴到人身上后使 YOLO V2 无法检测到或检测框严重偏移。该过程可通过改造损失函数实现，具体如下。

损失第一部分为不可打印性得分损失 NPS 损失。打印机可实现的色彩范围与数字世界不同，容易出现色差，NPS 损失用于保证数字颜色在物理打印时仍然可实现。其定义见式（2.43）。其中 p_patch 为 Patch 中的像素，c_print 为可打印颜色集合 C 中的元素。

L_nps = ∑ min_{c_print ∈ C} |p_patch − c_print| （2.43）

损失第二部分为全变分损失 TV 损失。摄像头采集时存在传感器压缩误差，难以捕捉剧烈变化，TV 损失让 Patch 更平滑，提升经摄像头拍摄后的对抗有效性。TV 损失定义见

> ① THYS S, VAN RANST W, GOEDEMÉ T. Fooling automated surveillance cameras: adversarial patches to attack person detection[C]//Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition Workshops. 2019.

式（2.44）。其中 \( p_{i,j} \) 表示 Patch 第 \( i \) 行第 \( j \) 列的元素。

 \( L_{tv} = \sum_{i,j} \sqrt{(p_{i,j} - p_{i+1,j})^2 + (p_{i,j} - p_{i,j+1})^2} \) （2.44）

损失第三部分为使检测器输出的目标置信度尽可能低，即 L_obj 损失最小化。

最终优化目标为式（2.45）。优化过程中 YOLO V2 的权重保持固定，只优化 Patch 使式（2.45）最小。

 \( L = \alpha L_{nps} + eta L_{tv} + L_{obj} \) （2.45）

要把 Patch 应用到物理世界，需要先打印再用相机重新采集，而拍摄角度、光照、Patch 大小与旋转等都会影响效果。为此借助 Expectation Over Transformation 框架，在各种变换下保持对抗性。具体做法是在训练时对 Patch 进行数据增强，包括随机缩放、随机旋转、加噪、对比度与亮度随机变化等，再将其覆盖到人体的中心位置。
