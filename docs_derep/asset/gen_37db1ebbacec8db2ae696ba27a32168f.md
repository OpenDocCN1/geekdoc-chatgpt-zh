# 第四章 网络时代劳动基准怎么改
沈建峰
中央财经大学法学院教授

要讨论数字场景下劳动基准如何创新，首先得把研究边界划清楚。网络时代可以用作时间标签，指向互联网诞生后对生产生活产生深远影响的当下。若按此理解，研究对象就等同于当下劳动基准的一般创新，范围过大难以聚焦。更实用的切入点是把网络时代当作技术语境，指信息技术、数字技术和网络技术驱动下劳动基准理论与制度所出现的变动，本书聚焦的就是这种技术牵引的变革。

需要说明的是，网络技术、数字技术、信息技术在学术上各有侧重，网络技术更突出互联网连接的面向。若严格区分，本章本可只谈互联网带来的问题。现实是，真正冲击工业时代劳动基准规则的，是互联网与数字、信息技术叠加合用的综合效应。因此这里所说的网络时代，实质上涵盖数字时代与信息时代劳动基准共同面临的议题，行文中不刻意区分三者表述。

推进思路上，先梳理网络化劳动世界的主线变化与制度压力，再回头审视劳动基准法的应对路径。过程中要先厘清劳动基准的概念边界，纠正劳动基准法纯属公法领域的惯性认识，在此基础上展开具体制度创新的讨论。

## 一、网络时代用工全景与劳动法新挑战
### （一）学界对用工关系变迁的判断

# 用工去组织化：保障、集体、权力三重松动
对网络或数字时代雇佣关系本身的演变，学界提出了多种概括。一种主流判断是，用工形态正在出现去保障化、去集体化、去权力化的联动转向。

去保障化指的是技术变革可能让人告别我们今天认为至关重要的岗位稳定，^[([1]](#txt005.html#footnote_content_txt005_1))。在数字技术作用下岗位变得更易波动，传统劳动法强调的工作保障、薪酬保障和工时保障都面临兑现难题。

去集体化则是指数字工具把劳动力供给者切割得更细、业绩差异被放大，劳动者个体化加剧，协同发声、争取共同利益的难度上升。^[([2]](#txt005.html#footnote_content_txt005_2))

去权力化描述的是数字技术放大了使用方管理权、压缩了劳动者话语权。具体表现为监督手段在向更广更精的方向拓展；工作流程越来越多地被数字化处理，员工被算法管理；企业单向攫取人员、工作和生产过程中产生的数据、信息与知识资源。^[([3]](#txt005.html#footnote_content_txt005_3))
