## 3.4.2 数值解法：有限差分法与有限元法

数值求解是处理复杂数学模型、尤其是偏微分方程的核心手段，解析解往往难以获得。有限差分 FD 与有限元 FE 是两种主流方法，广泛应用于物理模拟与工程计算。

有限差分法把连续的偏微分方程离散为空间与时间上的网格点，用差分公式近似微分。方法直观，适合规则网格的 PDE，但对复杂几何和强非线性问题处理受限。

有限元法把求解域划分为多个简单单元，先在单元内用简化模型求解，再汇总为整体解。对复杂几何与边界条件适应性强，在结构分析、流体动力学等领域常用。

### 1. 有限差分法的 CUDA 实现

有限差分常用市区町村求解热传导、波动方程等。核心是把 PDE 转化为离散代数方程，在网格上迭代求解。结合 CUDA 并行，可大幅提升求解速度，大规模计算时能充分利用 GPU 并行能力。

### 2. 有限元法的 CUDA 实现

有限元广泛用于固体力学、流体动力学等工程问题，把复杂问题拆解为若干局部子问题求解后拼接。CUDA 加速可显著提升求解大型线性方程组、矩阵运算等计算密集环节的效率。

## 3.4.3 GPU 加速流体动力学模拟

流体动力学模拟在汽车工程、气象预报、航空航天等领域广泛使用。传统模拟需求解大量偏微分方程，三维复杂流场计算密集，单 CPU 难以满足大规模场景需求。

GPU 加速的关键在于把有限差分、有限体积等数值法的每一步计算并行化。CUDA 利用 GPU 多核架构同时处理各计算单元，使流体模拟提速，尤其在大规模流场中能有效压缩时间。
