### 11.3.2 案例：生成目录报告

Desktop Commander MCP 服务器本质上是一款兼顾文件与命令操作的利器，功能覆盖面很广。主要能力包括：

1. 文件操作
- 读取文件：read_file。
- 写入文件：write_file。
- 编辑片段：edit_block。
- 新建目录：create_directory。
- 浏览目录：list_directory。

请基于 FastMCP 开发一个能够操作本地 SQLite 的 MCP Server。

Cursor 会产出以下核心文件：
- README.md：使用说明。
- requirements.txt：依赖清单。

- execute_query：连接数据库并执行查询语句。
