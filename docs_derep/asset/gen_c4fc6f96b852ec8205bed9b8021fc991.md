# 第1章 ChatGPT 诞生与发展历程

ChatGPT 由 OpenAI 于2022年11月推出，是一款以大型语言模型为底座的对话式人工智能。它以庞大的互联网数据源为基础，借助强算力并引入“人工介入”式训练，从而大幅提升机器学习的成效，具备出色的语言生成能力。可以产出类人回复，能解答提问、进行多轮对话、自我纠错、提出异议并拒绝不合规请求。发布后迅速成为全球焦点，让公众直观感受到人工智能的冲击。本章对 ChatGPT 做简要介绍，帮助读者快速把握背景，并学习如何与之交互；同时分析其在不同场景下的长处与局限。

## 1.1 ChatGPT 是什么

ChatGPT 全称是对话生成式预训练 Transformer，由 OpenAI 于2022年11月面世的智能聊天程序。交互以文字为主，不仅能进行基础聊天，还可承担复杂任务，如自动文本生成、机器翻译、语言润色、自动摘要、自动纠错等。例如在自动生成方面，可依输入主题产出指定内容的文本，如撰写技术博文、创作短剧、模仿鲁迅口吻写报告等。此外具备编写、解读和调试程序的能力，是重要亮点。操作便捷，只需在对话框输入问题即可获得答案。如输入“用 Python 实现冒泡排序”，即可得到对应代码，如图1.1所示。

同时具备自我修正能力，在对话中会更正先前错误，甚至质疑不合逻辑的问题或拒绝作答，如图1.2所示。当用户问“陕西有什么著名美食”时，回答中出现了“榨菜肉丝米线”这类错误信息；用户指出后，模型会重新修正并给出正确信息。

模型能写出类人的文章，并在诸多知识领域给出详尽清晰的答案，因此迅速获得全球关注。但也存在短板，比如被问“ChatGPT 有什么缺点”时，自述为“上下文理解有限、常识不足、训练数据存在偏见、易被滥用”。学界指出大模型易产生错误和误导信息，生成有害内容。人们担心聊天机器人会从训练数据中习得并固化历史偏见。安全与伦理问题因此成为热点，尤其在教育学术领域。

有学者尝试让 ChatGPT 写论文摘要和润色论文。*Nature* 专门发禁令：ChatGPT 不可作为论文作者；*Science* 直接禁止投稿使用 ChatGPT 生成文本；牛津大学、剑桥大学、香港大学等高校宣布禁止该技术用于学术工作。

ChatGPT 也被用于辅助完成课程作业。据 Forbes 报道，代写作业在美国高校已成常见现象。Study.com 面向全球1000名18岁以上学生调查显示，十人中超九人知晓 ChatGPT，89%以上用其完成家庭作业，48%用于小测验，53%用于写论文，22%用于生成论文大纲。

在部分考试中表现惊人。宾夕法尼亚大学沃顿商学院教授 Christian Terwiesch 发表《聊天工具 ChatGPT 能否拿到沃顿 MBA？》，在核心课程考试中测试，结果稳定在 B 到 B- 之间，超过课程多数学生。

由此，ChatGPT 对科学社会的影响持续被讨论，研究界从五方面展开：坚持人工校验、制定问责规则、拥抱 AI 优势、投资真正开源大模型、扩大辩论范围。

ChatGPT 的成功受益于 GPT-1 到 GPT-3 的演进。2018年 GPT-1 诞生，参数1.17亿，具备一定泛化能力，可用于与监督任务无关的 NLP 任务，包括自然语言推理、自动问答、语义相似度识别、文本分类等。2019年 GPT-2 上线，架构与 GPT-1 类似，参数增至15亿，数据集40GB。目标是通过训练得到更强泛化词向量模型，用无监督预训练完成有监督任务。性能上在多项语言建模任务达到当时最佳，并在生成方面初现天赋，可做阅读摘要、聊天、续写、讲故事等。GPT-3 参数1750亿，预训练数据45TB，可完成绝大部分 NLP 任务，如阅读理解、语义推断、机器翻译、文章生成、自动问答等。在法英、德英机器翻译上达到当时最佳水平，两位数加减运算正确率接近100%。在困难任务上也有惊艳表现，如写出人类难辨真伪的文章，编写 SQL 查询或 JavaScript 代码等。

## 1.2 从波士顿动力到 ChatGPT

工业化推进下，智能机器人迅速进入多个行业，不仅支撑先进制造，也提升生活便利。如今机器人产业已成为衡量国家创新与高端制造水平的重要标尺。多数机器人研发源于对生物智能的模仿。生物智能使生物体能在极端或变化环境中适应。自然界为人工智能与智能制造提供源源不断的灵感。自20世纪50年代起，科学家开始探索让机器人具备人类智能。经多年研究实践，机器人智能逐步提升。波士顿动力机器人与 ChatGPT 分别是硬件类与软件类机器人的里程碑，可反映智能机器人发展水平。

波士顿动力机器人是仿生机器人，最早由美国麻省理工学院研发，是最早被广泛认知和应用的智能机器人之一。硬件类机器人通过机械臂、传感器、控制器等实现物理运动与交互，可在现实环境完成各类任务。过去40年发展，外观与动作愈发接近人类，具备视觉识别与运动控制。Atlas 人形机器人是代表，可进行动态行走、奔跑、跳跃，运动场景见图1.5。该类机器人在工业、医疗、军事领域应用广泛。但受技术限制与高成本影响，难以大规模普及，主要用于医院、实验室、战场等特定场景。

ChatGPT 等软件类机器人则依托自然语言处理与机器学习算法实现与人类的语言交流，可模拟对话、问答、文本生成。ChatGPT 采用深度学习，通过预训练与微调不断优化，在语言理解与生成性能上显著提升。GPT 研发始于2018年，历经迭代优化，ChatGPT 与 GPT-4 已成为当前最先进的自然语言处理模型之一。

从波士顿动力到 ChatGPT，智能机器人发展呈现技术突破与应用拓展的态势，呈现多样化、分层化趋势。相较波士顿动力，ChatGPT 具备一定推理能力但缺乏环境感知、认知与决策能力；波士顿动力则缺乏 ChatGPT 式的海量知识存储。

未来智能机器人发展将以大模型驱动为基础，包括视觉感知、态势感知、智能推理决策与运动感知大模型迭代优化，同时需针对具体问题场景进行3D建模。随着技术提升与成本下降，智能机器人在更多领域发挥作用，为人类创造更大价值。

### 1.3.3 如何与 ChatGPT 有效交流

ChatGPT 基于提示学习技术输出回复，该技术为模型提供明确指令，能保证输出与输入相关，提升回复质量。一个提示通常包含：

- （1）指令：希望模型执行的任务或指示。
- （2）背景：补充的外部或上下文信息，可引导更好回应。上下文越具体相关，解答效果越好。
- （3）输入数据：待解决的问题。
- （4）输出指示：输出类型或格式，如“分类”“总结”“翻译”“排序”等。

提示是迭代过程，面对复杂问题可先从简单提示开始，再逐步添加元素与上下文。提示越详细结果越好。可尝试不同关键词、上下文与数据，寻找最适合特定需求的指令。设计提示时需注意长度限制，一般不超过500字。
