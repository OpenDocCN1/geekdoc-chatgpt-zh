### 8.1.2 LangChain开发框架总览
LangChain由LangChain AI推出，是面向大模型应用的开源框架。其核心理念是通过标准化模块抽象统一大模型输入输出，构建可组合可插拔的开发流程。以Chain为核心，强调链式组织模型调用、上下文管理、工具执行、内容解析等，帮助开发者搭建从输入到智能响应的完整路径。

本质上，LangChain从模型能力出发，结合实践经验对涌现能力做高级抽象，并通过统一接口适配多种底层服务，形成通用开发范式。

目前LangChain已演进为通用大模型应用框架，模块设计体现了对LLM的深刻理解，并在Agent标准化中发挥关键作用。核心模块如图8.4所示。

[PRE16]

图8.4 LangChain核心模块

##### 1. Prompt
Prompt是应用起点。LangChain通过PromptTemplate提供标准化模板定义。开发者可自定义变量注入背景与任务说明，模板支持变量插值、校验与复用，实现动态提示生成。

##### 2. Models
Models封装主流大语言模型并提供统一调用接口。配置模型信息后即可在不改动业务逻辑的前提下切换底层模型。

##### 3. Output Parser
大模型通常输出自然语言，而工程需要JSON、列表、表格、代码块等特定格式。Output Parser用于规范输出，内置字符串解析器、列表提取器、Pydantic校验器等，提升链式调用的稳健性。

##### 4. Memory
Memory是对话场景下实现多轮上下文记忆的关键，区分短期与长期记忆，支持历史输入与模型输出的存储复用。

##### 5. Callbacks
Callbacks提供事件监听机制，可对调用链路各环节进行监控、调试与可视化，支持日志输出到终端或文件，甚至接入可观测平台，实现全链路追踪。

##### 6. RAG
LangChain对RAG深度封装，涵盖Retriever构建、向量数据库如Chroma、FAISS、Milvus集成，以及上下文压缩与匹配过滤等组件，可按需组合快速搭建语义检索增强链。

##### 7. Agent
Agent是实现复杂任务自动执行的核心，允许大模型作为工具调用者动态决定是否调用外部工具、API或其他链。LangChain提供多种内置Agent类型，支持复杂流程的自动拆解与执行。

在LangChain中，七大模块如同积木，各自职责清晰且可灵活组合。如图8.4所示，既可实现基础问答，也可构建具备记忆、知识增强、结构化输出与多工具协同的高级Agent系统。

### 8.1.3 LangChain高阶RAG构建实践
在BiliAgent数据分析场景中，需要借助LangChain完成大模型接入与RAG流程搭建，实现多阶段任务处理与智能化分析。整体类似搭积木，每个模块都是Agent运行的基础。
