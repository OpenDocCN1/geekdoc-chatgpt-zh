AnyGPT：两阶段驱动多模态高质量生成

用大语言模型创造高质量的多模态内容并不容易，图像和音频的精细表达会带来巨大的存储压力，序列长度被拉长后语言模型的计算负担也会急剧上升。AnyGPT 用两阶段框架来平衡效果与效率：先做语义建模，再做感知建模。自回归语言模型负责生成融合且对齐的多模态 Token 序列，随后非自回归模型把这些 Token 解码成高保真的多模态内容。

在视觉侧，采用 SEED Token 做视觉语言建模，再用扩散模型解码为高质量图像。语音生成上，先用 SoundStorm 模型生成声学 Token，再解码为原始音频；音乐生成则用 Encodec Token 捕捉高频细节，经 Encodec 解码器重构成高保真音频。借助这种设计，AnyGPT 在大幅缩短语音序列长度的同时，保持了多模态生成的质量，实现了生成效果与计算效率的兼顾。

2. 睥思：多专家协同压缩视觉标记

当前视觉语言模型普遍受制于单编码器能力不足和视觉 Token 过长两大痛点，这会限制对复杂视觉信息和长上下文的准确理解，提升性能和可用性必须先解决这两个问题。

多模态大模型睥思[300] 用多专家技术让不同视觉编码器协同工作，覆盖图像文本匹配、光学字符识别、图像分割等能力。融合网络统一各专家的输出，并弥合视觉编码器与预训练大语言模型之间的差距。模型还提出二维可训练图像位置编码，减少了因特征序列过长带来的位置编码浪费，缓解位置溢出与长度限制。整体框架如图 7.11 所示。

以眸思模型为例，用户上传一张描绘风媒花授粉的图片并提问“哪些松果产生花粉？”。图片依次进入语义专家、分割专家、OCR 专家等进行编码，得到多组视觉标记。多视觉融合网络对多通道信息压缩融合并与视觉输入对齐，用户问题经视觉语言模型的嵌入层转为文本标记，最终模型处理视觉语言标记，完成 VQA 与 OCR，输出正确答案“雄性松果产生花粉。”

不同专家的输出在维度和数量上差异明显，需要融合网络统一处理。眸思模型改进了 MLP 投影融合网络和 Q-Former 融合网络来整合多专家信息。但大量视觉标记会抬高计算与内存成本，甚至突破推理最大序列长度。为此提出多补丁-单标记投影，按比例压缩每个专家的输出。图像信号具有局部性和稀疏性，用一个标记表征相邻多个补丁是合理的。该方法把局部视觉信息压缩、把多个补丁映射为单个标记，实现多通道视觉信号的高效传输，降低了冗余与后续计算成本，提升了推理效率。

即便用多补丁-单标记或在 Q-Former 中设定少量查询来减少标记数，位置编码的占用依然突出。视觉标记长度通常是文本标记的 500 倍以上，在具位置感知能力的模型中会消耗大量位置嵌入资源。视觉专家本身已包含位置信息，为每个视觉标记再分配语言模型的位置嵌入既冗余又低效。眸思模型采用二维可训练图像位置编码，直接在视觉标记中引入可训练的二维位置信息，避免额外位置嵌入的资源消耗。这一做法解决了多视觉专家带来的超长序列问题，减少了位置编码的重复分配，优化了视觉标记处理效率，为多模态模型的可扩展性提供支撑。

7.3 多模态大语言模型训练策略

深度神经网络的缩放法则为多模态大语言模型的训练提供重要参考。业界以前多靠堆算力和扩大模型规模提升性能，而文献 [303] 表明优化数据处理同样能带来突破。以 CLIP 为例，其用 4 亿张图像训练，OpenCLIP[304] 则需数百卡 GPU 运行数天至数周。文献 [303] 提出构建高效数据处理管道，在不大幅增加成本的情况下提升性能。

如图 7.12 所示，数据是训练的核心。多样且平衡的数据集有助于模型学习覆盖足够多概念的世界模型。清除大规模数据集中常见的重复数据能节省计算并降低过度记忆风险。数据剪枝可确保文本描述与图像内容高度相关，帮助模型更好对齐多模态信息。提升视觉语义关联能力、引入人类偏好优化对齐效果也有助于图文理解。在 OCR 任务中，专门的增强技术可进一步提升文本读取与翻译能力。高效数据处理、合理架构选择与针对性优化共同提升训练效果与应用能力。

7.3.1 数据处理

训练中数据质量对性能起决定性作用，高效筛选策略能显著提升学习效果与下游泛化。为评估基础数据集，提出 DataComp 框架[304]，基于标准化 CLIP 模型与预训练参数，构建在 38 项下游任务上表现优异的图像-文本组合。该框架包含 128 万至 128 亿对图像-文本样本的噪声网络数据库，并系统探索多种筛选策略。研究显示剪枝优化是提升跨模态效果的关键。

数据剪枝可分为三类：用启发式方法剔除低质量样本；基于预训练视觉语言模型对图文对排序丢弃对齐差的样本；构建多样化且平衡的数据集。

启发式方法分单模态过滤与多模态过滤。单模态过滤常去文本复杂度低的描述，如对象、属性、动作数量少，使用 fastText[306] 去除非英文描述，并按分辨率与宽高比过滤低质图像。多模态过滤更复杂，通常用图像分类器检测图像中的对象，过滤图像与文本对象不匹配的样本；由于网络图像常含文本信息，也可借助文本检测工具如 text-spotters[308] 去除图像与文本高度重叠的样本，促使模型聚焦高级视觉语义而非过度依赖 OCR，提升对象与场景相关零样本任务的性能。

基于预训练视觉语言模型的剪枝是最有效的策略之一，通过计算图文对嵌入相似性评估对齐程度。CLIPScore[309] 依托预训练 CLIP 计算图像与文本嵌入余弦相似度并排序；LAION 筛选策略基于用 4 亿图文对训练的 OpenAI CLIP 模型对大规模网络数据评估对齐并过滤低分样本；T-MARS[310] 在计算 CLIPScore 前遮蔽图像中的文本区域，提升对齐分数准确性；Sieve[311] 利用在小而精数据上预训练的生成式图像描述模型，减少 CLIPScore 排序中的误判。通过这些优化，筛选更精准，数据质量与模型性能同步提升。

多样化且平衡的数据集是泛化能力的核心[312]。DataComp 提出采样策略。基于文本的采样保留与 ImageNet 类别相关联的图文对描述；基于图像的采样用 OpenAI CLIP 的 ViT-L/14 编码图像，通过 FAISS 将大规模噪声图像聚类为 10 万组，再根据 ImageNet 训练样本嵌入挑选最相近的聚类，生成多样图像集。这些方法提升多样性，但对 ImageNet 等语义集的依赖可能引入类别偏倚，限制新任务泛化。MetaCLIP[313] 用 Wikipedia 与 WordNet 的 50 万个查询作元数据，构建覆盖广泛概念的预训练分布。通过“平衡采样”算法限制每个查询样本数最多 2 万个，在多样性与代表性间取得平衡，进一步提升泛化。

7.3.2 视觉语义关联

视觉语义关联是多模态大语言模型与生成模型的核心挑战。目标是解决模型对文本提示理解不充分的问题，避免忽略关键信息或生成不存在内容。处理视觉与文本关联需克服空间位置关系、否定表达、计数、属性理解等复杂性。虽无单一方案能完全解决，但边界框标注与负样本生成是两类常用改进手段。

1. 基于边界框标注

边界框标注是直接高效的方法。X-VLM[314] 结合边界框回归与 IoU 损失，实现视觉概念的精确定位并与文本描述对齐。通过明确标注物体位置及其描述，模型能更精准地将文本提示与视觉线索关联，提升语义理解。该模型训练依赖 COCO[315]、Visual Genome[316]、SBU 与 Conceptual Captions[317] 等大规模标注集，共约 1600 万张图像，丰富的标注为图文检索、视觉推理、语义对齐、图像描述等任务提供高质量训练样本，表现优于其他方法。

也有研究用公开模型生成新图文对。KOSMOS-2[259] 用网络爬取数据构建大规模图文对，先用 spaCy 从文本中抽取名词，再用基础模型 GLIP[318] 检测相关边界框，最后用 spaCy 抽取与名词对应的描述，生成可与检测框匹配的图文对。此法扩展标注规模，但效果高度依赖基础模型性能，若 GLIP 在稀有词或复杂实例上表现不佳，生成的框与描述会出错，进而限制下游表现。

2. 负样本生成

负样本生成在对比学习中起关键作用，用于缓解训练崩塌、提升泛化与学习判别性特征[275, 319-322]。通过正样本与负样本对比，模型学习更深层次表示，不只依赖表面匹配，而是掌握类别区分的潜在模式。引入负样本帮助识别错误关联信号，避免因数据噪声或偏差导致过拟合，提升对类别间细微差异的感知与多样化数据的稳健性，是对比学习不可或缺的机制。

在多模态大语言模型中，负样本生成同样关键，用于解决训练与推理问题[305, 323-325]。通过负样本评估模型建立图像与文本描述正确关联的能力。例如 ARO[323] 提供错误或无意义的图文配对，测试模型区分能力。研究表明接触负样本可显著提升多模态任务表现，使语义关联更精准、上下文理解更强，优化整体性能与复杂场景下的稳健推理。

7.3.3 多模态文本对齐

多模态文本对齐旨在精准关联视觉与语言信息，实现更高层语义理解。受指令微调在语言领域的成功启发，多模态大语言模型引入指令微调与人类反馈强化学习提升对话能力，使输出更贴合人类需求。文本丰富图像的理解也成为重点研究方向。

1. 多模态指令微调与 RLHF

多模态指令微调在含指令、输入、期望响应的监督数据上优化对齐，提升理解与执行复杂指令的能力。指令微调数据集规模通常较小，从数千到百万不等[326]。LLaVA、InstructBLIP 与 OpenFlamingo[327] 等代表性视觉语言模型均引入指令微调，显著提升多模态任务表现。

RLHF 通过人类反馈使输出更符合人类偏好。首先训练奖励模型评估响应质量，捕捉人类偏好特征，再借助奖励模型模拟人类偏好减少人工标注依赖，最后用奖励模型微调多模态大语言模型，使生成响应更贴合期望。

LLaVA[319] 用 15 万条合成视觉指令样本提升多模态对话能力，将预训练 Vicuna 语言模型编码器与 CLIP ViT-L/14 视觉编码器输出融合至同一维度，在合成指令跟随与 Science QA 基准上大幅改进。LLaVA 1.5[319] 进一步优化对齐，引入跨模态全连接 MLP 层并结合 VQA 指令数据，仅用 60 万图文对在 8 块 A100 上训练约一天。LLaVA-NeXT (v1.6)[328] 在此基础上改进，将全图与小图块视觉特征分别输入编码器后拼接，提升分辨率利用效率，优化视觉指令调优数据集，增加视觉推理、OCR、世界知识与逻辑推理样本。

由于高质量视觉指令数据稀缺，LLaVA 等模型易出现模态对齐偏差与幻觉。LLaVA-RLHF[262] 提出事实增强 RLHF，将 RLHF 从文本迁移到视觉语言任务，在奖励模型中加入图像标题与真实多选题等额外事实信息，减少奖励滥用。利用 GPT-4 生成训练数据及人工图文对提升通用能力，在 LLaVA-Bench 上达到 GPT-4 的 94%，在聚焦减少幻觉的 MMHAL-Bench 上较基线提升 60%。

2. 富含文本信息的图像理解

文本丰富图像如电影海报、书籍封面、文档扫描图，要求模型同时理解视觉内容与解析细粒度文本信息并关联语义。传统多模态大语言模型常受文本识别不足、分辨率受限、上下文捕获不充分困扰。近年出现 LLaVAR、Monkey、Lumos 等创新方法。

LLaVAR[329] 改进视觉指令微调流程以提升图像中文本细节理解。引入大量含文本的图像，研究者用 OCR 工具从 LAION 数据集提取 42.2 万张文本丰富图像，结合 GPT-4 生成 1.6 万条基于这些图像的对话数据，每条含多个问答对。与现有多模态指令跟随数据结合后，LLaVAR 显著改进 LLaVA 能力，在文本相关视觉问答数据集上准确率提升 20%，自然图像任务也有轻微提升，显示针对性指令微调可增强文本理解与语义对齐。

多数多模态模型输入分辨率限制在 224×224 像素，导致在场景文本中心 VQA、文档导向 VQA、关键信息提取等任务上表现不佳。Monkey[330] 提出高分辨率处理方法，用滑窗将输入图像分割为适配视觉编码器的图像块，每个块由静态视觉编码器独立处理，并用 LoRA 调整可训练视觉重采样器。模型支持 1344×896 分辨率，能捕捉复杂视觉场景细节，采用多级描述生成强化场景与对象间的上下文关联，实现高分辨率图像的精细化理解与表达。
