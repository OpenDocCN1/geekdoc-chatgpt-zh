# 第五章 人工智能时代的大国博弈推演

大国之间既斗且合的微妙态势由来已久。本章聚焦人工智能技术如何成为大国角力的主战场，结合前文对AI在军事、经济、网络、数据与科技等多维度赋能效应的梳理，着力描绘未来可能出现的 confrontation 与协作并存的多种图景：一方面在安全领域竞争加剧，另一方面在科研联动、气候应对等全球性议题上仍需紧密协作。同时结合现有AI治理框架与规则的盘点，剖析当前治理所处的瓶颈，探究各方争夺AI主导权所引发治理分歧的动因与走向，并说明以“人类命运共同体理念”作为价值引领来缓释治理冲突的现实分量。

## 第一节 AI驱动的对抗态势

2022年2月俄乌冲突爆发后，人工智能在国家对抗中的作用被公众放大。社交平台上虚假新闻、伪造图片与合成视频泛滥，真假难辨，舆论反复横跳，网络战与信息战已成为冲突的重要形态。在这种混合战争的框架下，AI已渗透进冲突的各个环节。牵涉进去的并非仅有俄乌双方，背后还有持不同立场的国家阵营、黑客组织、跨国技术机构乃至个人等多元行为体。技术成熟度尚显不足，但以AI为底座的对抗形态已从设想走向现实，成为大国博弈的关键场域，而相关规范规则滞后，潜在风险值得高度警惕。

从自主武器到人脸识别再到决策模型，AI军事化应用会放大跨国冲突的烈度，也在模糊战争与非战争的边界。一旦舆论操控类AI能力与真实军事力量捆绑，未来战争范式可能被彻底改写。现行的裁军协议与军控机制难以覆盖AI军事化用途，大国间的AI治理协作才刚刚起步。埃隆·马斯克（Elon Mask）等116位全球企业领袖认为，自主武器系统将继火药、核武器之后掀起第三次战争革命，呼吁加强管制。^([\[1\]](#txt006.html#footnote_content_txt006_1))也有更激进的判断认为，随着机器人、算法和自动化的普及，社会运行秩序将被根本改写，全球政治将不再由人类独占，霍布斯式的自然状态^([\[2\]](#txt006.html#footnote_content_txt006_2)）或英国学派的基本预设都将失效。在AI赋能下，地球上的行动主体、关系结构与运行秩序将被重组，世界规则由地缘政治转向地缘技术（Geotechnics），这种系统性跃迁已超出单极或多极的传统讨论。^([\[3\]](#txt006.html#footnote_content_txt006_3))上述争议本质上是对AI应用不确定性的焦虑。

AI发展的不确定性与地缘政治风险相互叠加，可能催生以数据和算法为核心的多种对抗场景，迄今缺乏共识性的国际规范加以约束。一方面，它凸显出AI对国家安全的直接威胁，以及治理的必要性；另一方面，风险预判与治理机制的空缺也反映出治理的紧迫性。

### 一、智能无人集群的战用演进

如前文所述，AI通过提升战场感知、加快决策节奏、降低行动成本，推动由无人作战单元构成的去中心化智能体系成形。AI算法与自动控制技术结合，使自适应智能无人单元广泛进入军事行为，集群化作战体系的韧性大幅增强。与单中心或多中心体系不同，局部单元被摧毁后，具有同类功能的多个单元可迅速重组、恢复战斗力。

图 5-1 呈现了主要大国自主武器系统研发未见放缓态势，相关系统数量可观。智能化无人机“蜂群”不仅提升效能，还增强灵活性与抗毁性，削弱了传统中心化体系的脆弱点。未来战场上，对峙双方可能上演蜂群式军事对抗，由算法与算力支撑的系统能在极短时间内算出战局走向，整体作战效能将决定成败。美国防部启动多项无人作战研究，美军提出的“马赛克战”（Mosaic Warfare）概念即借助AI和自主系统，将大量体积小、功能单一的作战单元整合为智能无人平台，实现灵活重组与自适应作战。^([\[4\]](#txt006.html#footnote_content_txt006_4))其自组网、自适应、自调节、自同步特征可对敌方关键节点实施饱和打击，显著提高传统平台的防御难度。智能无人集群之间的对抗，很可能成为未来大国军事行动的主流模式。

### 二、高强度网络空间对抗

AI进步对网络安全构成重大冲击，AI赋能的网络武器将使网络战更激烈。随着应用扩散，攻击面同步扩大，例如自动驾驶汽车被黑客劫持；与此同时，AI也能被用来发起大规模网络袭击。防御系统若无法快速应对高强度攻击，极易被击溃。网络武器可破坏指挥与预警体系，甚至削弱敌方核反击能力，使核威慑失效。^([\[6\]](#txt006.html#footnote_content_txt006_6))在这种假设下，若某国认为自身反击能力被削弱，先发制人的诱因将明显上升。

目前网络攻击主要依赖精通攻防的人才，该类人才稀缺。未来借助AI发动攻击对人才依赖下降，更多受资金约束。以高级持续性威胁（APT）为例，攻击者长期潜伏寻找漏洞，属于劳动密集型。机器学习与AI能力增强后，发动门槛降低，漏洞搜寻可实现前所未有的自动化，攻击方能不间断扫描对手系统，攻击速度可能超出人力可控的防御体系。鉴于网络战特性，大国冲突很可能首先在网络空间引爆。

### 三、极速战的战略博弈

智能化系统为技术强势方提供速度优势，能更快采集处理信息、规划任务、支撑决策并实现高效指挥。有研究指出，AI辅助的指挥决策系统与致命自主武器的结合，将大幅超越传统动员战的节奏，形成极速战（hyperwar）^([\[7\]](#txt006.html#footnote_content_txt006_7))新形态。在此情境下，当战斗速度超出人类反应阈值，军事行动控制权或被迫移交机器。人类可能丧失战场掌控，机器以更快响应作战。于是观察—定向—决策—行动（OODA）循环被极度压缩，作战人员难以作出合理判断。AI赋能的自主决策与武器高速运行，会让率先开战者获得显著优势，可能触发意外升级，一旦一方启动，其他对手或跟进，导致冲突螺旋上升。美国兰德公司曾以推演模拟中美在东亚大规模部署无人装备的情形，结果是双方在沟通缺失与高速战场的压力下失控，最终演变为局部战争。^([\[8\]](#txt006.html#footnote_content_txt006_8))

### 四、舆论操纵与心理战渗透

AI已成为意识形态与社会心理渗透的潜在工具，主要场景在互联网平台，其中数据丰富且可及性高的社交媒体为重点。AI处理海量个人信息，对大规模群体开展心理干预实验，可预测甚至操纵行为与观念，实现跨国舆论操控。美国国会研究服务局2021年9月更新的《国防新兴技术》报告指出，AI能力已广泛投入“灰色地带”信息战，深度伪造可用于定向政策误导。俄罗斯从混合战争视角提出“虚拟社会战”，即以AI攻击敌方社会心理与意识形态，制造混乱恐慌，瓦解社会基础；这同时也被视为其政治安全的主要威胁。^([\[9\]](#txt006.html#footnote_content_txt006_9))在AI加持下，国家间信息战、心理战、认知战的界线将进一步模糊。

“剑桥分析事件”等案例显示，企业掌握的AI系统可分析民众政治立场、研判舆情并进行精准宣传，还能伪造虚假信息与热点，左右一国政治进程。调查显示约三分之二受访者担忧数字技术发展过快，难以辨别现实与虚假现实。^([\[10\]](#txt006.html#footnote_content_txt006_10))AI参与政治的案例增多。已有研究指出，参与政治话题的推特账号中有12.6％由机器人操控，且在不违规前提下可正常访问。若机器人未违反规则则不被标记。由此可见，AI可能以前所未有的速度与规模利用人性弱点操纵大众，任何依赖公众意见与公民参与的治理都将面临极大风险。

若用于国家对抗，AI对信息的操控将成为大规模军事冲突的核心特征，如影响舆论、削弱军事决策者与政治领导人对信息获取的准确性，或破坏信息真实性、放大虚假信息。AI可即时生成虚假信息并传播，影响他国在立法、贸易、经济与国防领域的政策以达成地缘政治目标。在极端场景下，竞争对手可能利用从公开媒体或截获通信中获取的指挥官音视频，生成伪造指令发布给作战部队；也能用生成式对抗网络制造虚假卫星情报图像，扭曲战场事实或制造虚假情报。

虚拟现实、算法推荐与数据垄断正重塑信息生产方式，在一定程度上强化意识形态的可操纵性。^([\[11\]](#txt006.html#footnote_content_txt006_11))信息接收的弱化与窄化可能导致认知偏狭，加剧社群隔阂。对此，AI既可制造传播虚假信息，也可识别并限制其扩散。这一双重属性在地缘政治与大国关系中尤为关键。但社交媒体机器人借助算法与自动化/人工策略在网上定向投放误导信息。随着AI自主学习能力提升，机器人与虚假账号模仿人类行为愈发逼真，检测效能不断下降。^([\[12\]](#txt006.html#footnote_content_txt006_12))

AI算法亦可通过社会工程学实施网络攻击，反复在数百万人中测试推送内容有效性，根据反馈优化模型。2020年美国大选再次将选举安全推上焦点。据统计，2016年总统大选相关推文中约五分之一由僵尸程序自动发布；英国脱欧投票相关推文中约三分之一为机器人操作。^([\[13\]](#txt006.html#footnote_content_txt006_13))这些事件虽缺乏精准直接证据，但美俄相互指责与英国内部攻讦严重冲击大国关系，导致国内深层分裂。

## 第二节 AI领域的合作图景

新冠疫情的骤然到来促使人类重新审视生命与世界。对生命、自然、宇宙等基础科学问题的探索呈现出复杂系统的特征。生命科学、社会演变、气候变化等前沿领域对系统性与复杂性的挑战日益突出。2021年诺贝尔物理学奖授予了在理解复杂物理系统方面做出开创性贡献的三位科学家，其成果强调单一预测并非无懈可击，凸显了从复杂与无序中寻找规律的重要性。如今数据采集与存储能力指数级提升，自然与社会科学均积累海量研究数据。AI算法与模型正成为理解复杂科学、开展跨学科研究的工具。若要发挥AI价值，亟需全球科研界交流互鉴、协同攻关。

同时疫情加速互联网普及，2020年全球互联网普及率增长10.2％，2021年增至19.5％，用户达49亿人，占世界人口63％。^([\[14\]](#txt006.html#footnote_content_txt006_14))人类在应对大流行、遏制核扩散、打击恐怖主义、化解金融危机、打击海盗、应对气候变化等危机中已有长期合作经验。当前各国普遍呼吁发挥AI潜力，推动科技向善，构建普惠协作的全球愿景。全球性议题需要深层次国际协作，在部分全球危机与热点议题上或可成为大国加强AI合作的切入点。

### 一、理论研究与技术研发的协同

AI日益成为资源与人才密集型研究，科研人员跨国合作有利于理论突破与技术验证。反之，缺乏国际协作可能拖慢进步、造成重复投入并推高成本。历史上前两次AI高峰以符号主义为基座，驱动要素为知识、算法与算力；第三次浪潮则建立在数据、算法与算力的共同突破上。目前来看，无论是行为主义的强化学习、联结主义的深度学习，还是符号主义的专家系统，都难以准确映射人类认知。在理论路径受限之外，当前AI还面临大量技术难题待解。若主要大国各自为战，技术发展速度与收益将递减，成本与系统复杂性上升，创新步伐被滞缓。
