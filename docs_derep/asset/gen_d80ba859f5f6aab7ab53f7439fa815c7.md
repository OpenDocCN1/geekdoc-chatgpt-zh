#### 8.1.10 LangGraph 驱动 Agent 的底层原理

##### 1. 框架来历与定位

单从名字看，LangGraph 与 LangChain 关系密切。事实上 LangGraph 是在 LangChain 表达式语言之上搭建的专用框架，目标就是做 AI Agent。以大模型技术本身来看，大模型并不能执行动作，只能输出文本，即接收输入并给出回应。LangGraph 能复用 LangChain 在模型接入与 Agent 构建上的优势，实现自然迁移。

##### 2. 基础图模型的运行方式

在图式框架里，任何可执行单元都能充当对话、Agent 或程序的入口。这个入口可以是模型 API、基于模型构建的 Agent，也可以是 LangChain 等实现的线性序列，比如图 8.13 中标记为“Start”的圆。无论形式如何，它先处理用户输入，再决定下一步动作。图 8.13 展示的就是一个最简的 LangGraph Agent 模型。

在 LangGraph 中，具备执行逻辑的组件都被抽象为节点 Node，涵盖模型调用、搜索、条件判断等。“Start”节点是入口，接收用户输入后会根据需求：

- (1) 调用 Action 节点做外部信息查询，如 Web 搜索、数据库查询或 RAG 检索。
- (2) 把查到的信息传给 LLM 节点，生成自然语言回复。
- (3) 最终把回复送到 End 节点，完成整条链路。

如图 8.13 所示，每个圆代表一个节点，每条线代表一条边 Edge，用于决定流程走向；状态则沿着边通过消息传递更新。

因此不论 Agent 多复杂，最终都是节点与边按特定方式组合成的图。工作流的核心在于节点完成后通过边通知下一个节点继续。简言之，LangGraph 底层的消息传递机制定义了通用程序模式：节点执行完毕后沿一条或多条边向其它节点发送消息，接收方执行后把结果传给下一跳，如此循环往复。

如图 8.14 所示，Agent 第一次处理后若判定要调用函数，下一步该选哪个工具、带什么参数？当可选工具不止一个时，Action 节点会出现多条可能路径。LangGraph 为此引入了条件边。条件边依据是否满足特定条件来选择分支，比如决定用搜索工具还是直接给出最终答案。管理这种决策的结构类似 if-else，称为 Router。Router 决策后，Agent 可能被导向网络搜索节点执行检索并返回原始文本，也可能直接前往 End 节点得到格式化后的自然语言响应。若走搜索分支，检索到的文本还需经另一 LLM 处理成用户可读的答案；若直接回答，则可通过专用工具做格式化。

在 LangGraph 中，Router 的 if-else 逻辑主要通过三种方式实现：

- 提示工程：让大模型按指定格式给出回应。
- 输出解析器：对模型响应做后处理，提取结构化数据。
- 工具调用：利用大模型的内置工具调用能力生成结构化输出。

##### 4. 共享状态机制

前面提到 LangGraph 用节点与边组合出复杂的循环流程，用消息传递串联各节点。让消息及时更新并送达正确位置，依赖的就是 State 概念。每一次执行都会启动一个状态，节点在处理时会读写并修改该状态。状态不是静态快照，而是随节点输出动态演进，进而影响循环中的后续操作，如图 8.15。

共享状态指图执行过程中节点间传递的数据与信息。LangGraph 允许节点在执行时通过公共状态交互。借助这种机制，节点能在共同维护的数据基础上通信、交换信息并相互影响行为，从而实现操作的协调与同步，支撑动态交互与复杂工作流，让各节点基于已有共享信息协同决策。

##### 5. 官方定位与核心优势

官方将 LangGraph 定义为基于大模型构建有状态、多参与者应用的库，可创建 Agent 与多 Agent 工作流。官方总结的优势如下：

- 循环与分支：在应用中实现循环和条件逻辑。
- 持久化：每个步骤后自动保存状态，可随时暂停、恢复执行，支持错误恢复、人机协作流程、时间旅行等。
- 人机交互：可中断执行以审批或编辑 Agent 下一步计划。
- 流式输出：每个节点都可产生流式输出，包括 Token 流。
- 无缝集成：与 LangChain 和 LangSmith 深度集成。

如图 8.16，BiliAgent 的核心流程如下：

- (1) 用户输入问题，对应图中的①。
- (2) 进入“检索”节点做信息检索，对应②③④。
- (3) 通过“评分”节点评估文档相关性，对应⑤⑥。
- (4) 若不相关则调用“问题重写”节点 transform_query 重写问题并循环回检索。
- (5) 若相关则进入“生成答复”节点 generate 生成最终答案，对应⑦。
- (6) 后续可加入幻觉检测与代码验证节点，对应⑧。

流程顺利时，最终生成答复，完成①②③④⑤⑥⑦⑧。
