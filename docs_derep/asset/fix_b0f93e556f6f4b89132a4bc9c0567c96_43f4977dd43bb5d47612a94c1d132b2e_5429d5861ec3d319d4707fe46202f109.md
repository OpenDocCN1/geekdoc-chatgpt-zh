NLP 演进：从统计到预训练大模型

数十年积累让自然语言处理逐渐摆脱手工规则，深度学习浪潮里涌现出能处理旧难题的新思路与新模型。

上半部梳理的是语言模型本身的技术变迁，下半部记录的是词表示学习的发展。词向量的出现为语言模型提供了更优质的输入形式。下面按时间顺序把图中的关键节点捋一遍。

- 1948 年 N-gram 首次提出，核心做法是用前面 N-1 个单元来推断第 N 个单元，单元可以是词也可以是短语。
- 1954 年词袋模型把文本简化为词的集合，表示时忽略顺序，每个词对应一个维度，数值反映词频。
- 1986 年分布式表示把词或短语编码为稠密向量，语义信息分散到各维度，能捕捉相似与关联，主要依赖上下文构建，缓解了词袋和独热编码带来的语义鸿沟，如歧义、同义词问题。
- 2003 年神经概率语言模型首次引入神经网络学习词间复杂关系，成为 CNN、RNN、LSTM 类神经网络语言模型的前身。
- 2013 年 Word2Vec 成为标志性工作，用神经网络学习分布式词向量，做法简洁高效。CBOW 通过上下文预测中心词，Skip-Gram 则反过来用中心词预测上下文。得到的向量既保留相似性也保留句法信息，后续大量工作都继承了这一思路。
- 2018 年后以 Transformer 为骨干的预训练语言模型占据主导，用更大语料和更复杂网络学习语法语义，即预训练阶段。经微调后在机器翻译、问答、文本分类、情感分析、文本生成等任务上表现突出，不断刷新基准，如今已是多数 NLP 项目的起点。

图上每个节点都为后继技术铺路，也构成了本篇的讲解线索。整体演进是从规则驱动到统计驱动，再到海量语料训练的大模型驱动。

## 预训练模型成为新的基座

以 BERT 为代表的 Transformer 预训练模型发布后引发广泛关注，有了预训练，很多过去难解的问题变得可解。

小冰：厂里同事老提到 Transformer 到底指什么，预训练又是什么意思？

咖啡：Transformer 是当前几乎所有预训练模型的底层架构，本课程的核心，后面再展开。NLP 中的预训练，粗略说就是在海量无标注文本上训练语言模型。训练好的大模型常被称为基础模型。训练过程中模型学会词汇、语法、句法结构和上下文依赖等语言知识，为情感分析、文本分类、命名实体识别、问答等下游任务提供通用的语言表征。

早期 BERT 是最具代表性的预训练模型，它同时利用前后文对句子结构做深度理解。BERT 之后，大型预训练模型迅速涌现，领域进入新阶段，这些模型大幅加速了 NLP 发展，为以往难以应对的问题提供强工具。

预训练加微调的常用做法

对应用方而言，大型预训练模型是好消息。预训练模型习得的语义和语言知识迁移性强。只需要对头部或部分参数做适应性调整，通常在小规模有标注数据上做监督学习，让模型适配特定任务，这就是微调。相比从零训练，微调更快、数据需求更少，让 NLP 方案开发与部署更高效。

这种模式优势明显。预训练提供通用语言知识，不必自建语料从头训练，节省时间和数据。微调可快速针对任务优化，降低部署门槛。可扩展性强，适配多种 NLP 任务，大幅提升技术实用性和普及度。

### 用提示和指令直接驱动大模型

咖啡：小冰要记住，近几年随着 GPT 这类生成式大模型的快速发展，预训练加微调的模式正被提示 Prompt 或指令 Instruct 的使用方式逐步替代。

Prompt 与 Instruct 的核心想法是：训练阶段模型通过海量文本掌握语言结构、语法和一定语义，应用阶段只要在输入里给出恰当信息和引导，就能得到更有相关性和可用性的输出。这本质上是一种对话，用户提供提示或指令，模型据此生成结果。

小冰：Prompt 和 Instruct 有什么区别？

咖哥：主要区别在输入形式和任务性质。

[PRE6]

- **Prompt 模式**：输入常是一个词或短语，模型据此生成自然连贯的文本。适合生成类任务，如续写、摘要。例如输入“从前”，模型可能接“有个山，山里有个庙……”。
- **Instruct 模式**：输入是一条明确指令，要求模型完成特定任务。适合需要明确指示的场景，如问答、概念解释。例如输入“请给我讲个故事”，模型返回“从前有个山，山里有个庙，庙里有个咖哥给小冰、小雪上课……”。

小冰：能总结一下 Prompt/Instruct 和预训练加微调的异同吗？

咖哥：相似点是两者都依赖大型预训练模型，在大规模无标注文本上学习通用知识，都利用迁移学习在下游任务上使用预训练模型，减少训练时间和数据需求。

不同点如下。

| 特点 | '预训练 + 微调大模型'模式 | Prompt / Instruct 模式 |

| :-- | :-- | :-- |

| 是否微调 | 在下游任务上微调以适配需求 | 不做微调，通过设计指令生成输出 |

| 学习方式 | 在有标注数据上做监督学习 | 通常不需要标注数据 |

| 任务适应性 | 微调后任务适应性较高 | 依赖提示，适应性可能偏低 |

| 灵活性 | 需针对每个任务单独微调 | 灵活性更高，无需微调，但可能需试错 |

总体看，两种方式都利用了预训练模型的强大能力，但实现路径不同。预训练加微调通过针对性调整让模型更精确；Prompt/Instruct 则直接发挥生成能力，用合适提示解决问题。选择依据任务需求、数据情况以及对精确性和灵活性的权衡。

## GPT 生成式优势的来源

[PRE10]

小冰：BERT 和 GPT 都是预训练模型，训练方式有什么不同？

咖哥：了解差异有助于把握语言模型本质。我用初学者角度解释。

BERT 的预训练像做填空题。模型在大量文本上随机遮住部分词，然后根据上下文预测被遮住的词，是双向学习。这样学会句子结构、语法和词汇关联。

GPT 的预训练像文字接龙。模型在大量文本上学习预测给定上文的下一个词，是单向学习。就像接龙，要根据前面内容写后面。通过这种方式，GPT 学会生成连贯文本，并理解句法语义。

细节后面实战再展开。但我要强调，相比 BERT，GPT 更贴近语言模型本质，因为它的训练过程完整再现了自然语言生成的流程。

BERT 虽然靠双向上下文增强理解能力很“聪明”，但语言模型的核心任务是为给定上下文生成合理的概率分布。实际应用中我们通常需要模型根据上下文续写，而不是填补空白。

GPT 通过从左到右逐词预测，在生成过程中学习到连贯表达、句法和语义信息。早期它没有 BERT 那么耀眼，但后劲很足，为 ChatGPT 的出现奠定了基础。
