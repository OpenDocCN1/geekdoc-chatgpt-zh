递归神经网络的入口和出口都是由 token 组成的序列。所谓 token ，指的是语义符号，它可以是信号、文字、代码、图像、视频、三维模型或点云等多种模态的原始数据向量，也可以是这些数据的特征嵌入表示。

相较于前馈神经网络，递归神经网络至少拥有一条形成环路的突触连接。从数学角度看，RNN 能完成动态的输入输出映射，其具备的通用逼近特性是：通过训练可以以任意精度逼近任意非线性动态系统。只是在理论层面和工程实践层面都存在不少瓶颈，这些困难在总体上限制了递归神经网络的落地使用。

### 2. 学习算法
递归神经网络不像前馈网络那样拥有标准化的误差反向传播监督学习流程，但基于目标函数对连接权重的梯度以及链式法则，通过梯度逆向传播来逐层修正权重，仍然是最基础的操作方式。在此过程中，训练样本的标注情况会发生变化：某些类别只有部分标签或期望输出，少数类别仅有少量标签，甚至出现无标签样本或伪标签的情况，这分别对应半监督学习或弱半监督学习、少样本学习、零样本学习以及自监督学习。

对比式自监督本质上属于无监督范畴，同时也是一种度量学习。它通过挖掘同类实例的共同特征、拉开异类实例的特征距离，从而实现标签数据的自我扩充。这种做法与人类“举一反三”的自我想象很相似，在小样本场景下的识别任务中非常适用。具体实现时，对同一个训练样本或同一目标施加不同的随机增强，例如水平翻转、平移、缩放、旋转、高斯模糊、明暗调整等，经过主干网络 backbone 得到的潜空间表征会保持相似性，这就学习到了同一实例的共性特征。进一步地，由同一目标经随机变换得到的样本视为正样本，其他目标的样本视为负样本。对比式自监督通过目标函数设计，自动把正样本的特征向量拉近、把负样本的特征向量推远。典型的代表有 MoCo、SimCLR、DeepCluster、SwAV 等。

总体而言，由于引入了时间或序列维度的学习，递归神经网络衍生出多种多样的训练策略。完全监督的路线有沿时间反向传播 BPTT、实时递归学习 RTRL、扩展卡尔曼滤波 EKF 等，也包括前述的半监督、少样本、零样本和自监督范式，不过目前还没有出现一家独大的主流学习算法。

## 1.4 本章小结
生物神经网络始终是人工神经网络乃至整个人工智能研究进化的参照标杆。总体来看，两者各有所长。第一，与人类大脑皮层展现出的高度智能相比，如今的计算机、人工神经网络和人工智能在语义抽象、知识习得、思维推理与自主意识等认知能力的模拟上差距显著。第二，在规模上，人脑约有 860 亿个神经元，每个神经元连接 1000 到 10000 个突触，总突触数可达 860 万亿量级。而 GPT-3 的参数规模仅约 1750 亿，两者相差近 5000 倍。因此当前人工网络在参数量和复杂度上都远不及生物大脑。第三，结构上，人脑是分布式的存算一体架构，具备强大的并行处理与容错能力，个别神经元受损不会导致整体失效。典型的冯·诺依曼计算机则为集中式、串行处理，CPU 或内存损坏会造成系统性崩溃。第四，记忆方式上，计算机的数据与知识存储是静态的，新信息会覆盖旧信息。人脑的信息则编码在神经元间的突触连接中，学习是增量适应的，新信息用于调整而非破坏已有连接，因而具备持续学习能力，而现有的学习算法大多需要从零开始训练，还未找到媲美人类的范式。另一方面，计算机在高速计算与海量存储上远超人类，目前 CPU 主频已达 4.7GHz，信息处理时间低至纳秒级，而人脑神经元响应外部刺激需要毫秒级，两者相差百万倍以上。尤其是计算机算力的演进速度远快于生物进化，这也是令人警惕之处。

# 第2章 从LSTM到Transformer
## 本章学习目标与知识点
- 认识经典递归神经网络与长短期记忆网络
- 精通 Transformer 模型的核心概念与工作原理
- 了解输入序列上下文关联的隐状态表征及输出序列的自回归生成机制
- 重点把握计算机视觉领域基于 Transformer 的任务模型

本章将分别从输入 token 文本语义符或 voken 视觉语义符序列的上下文关联隐状态表征，以及输出 token 序列自回归生成两个视角，剖析如何由传统前馈网络结构改进为 Elman 递归神经网络；进而借助门控机制演化为长短期记忆网络 LSTM；随后通过引入全局注意力机制发展出新一代通用神经网络模型 Transformer；最后在传统编码器-解码器框架下，以 Transformer 基本单元堆叠编码器层与解码器层，完成序列表达、序列理解与序列生成。本章重点介绍传统编码器-解码器 Transformer 模型，涵盖网络结构与学习方法，并深入讨论其关键特性以及在自然语言处理与计算机视觉中的广泛应用。

## 2.1 引言
构建人类语言与知识模型、实现语言智能应用是人工智能的基础问题之一。本质上 n-gram 语言模型就是对人类自然语言表达、理解与生成的数学建模或端到端数据驱动建模，可划分为统计语言模型、传统机器学习语言模型，以及基于递归神经网络、Transformer 等的神经语言模型。对输入 token 序列，需要建模其上下文关联的隐状态表征，这对应训练样本集上的语言建模与特征知识提取过程。对期望输出 token 序列，则先进行由当前位置嵌入与特征知识共同驱动的自回归学习，再在测试集上进行推断与预测生成。这里的 token 是承载语义信息的基本单元，既可以是文本中的词、短语、句子或段落等语义实体，也可以是计算机视觉中的关键点、图像块 patch、单帧图像、区域、目标和实例等高阶多模态语义实体，它们在语义层面与文本实体是对齐的，均是语言模型的重要模态。

随着深度卷积神经网络的发展，多模态原始 token 输入通常先经预训练的主干网络如 ResNet101 转换为输入嵌入向量，以获得统一的多模态特征表达。本章从序列表达与序列生成两个角度出发，对 Elman、LSTM 等传统递归网络，以及新一代通用网络 Transformer 在编码器-解码器框架下的演进路径进行剖析，重点说明各模型特点与递进关系。

首先，针对前馈网络的隐层，增加一层具备一阶记忆功能的上下文结构单元层，即可将其演化为可对输入 token 序列进行任意精度动态逼近的 Elman 经典递归网络。但 Elman 网络在沿时间轴反向传播损失时，常出现梯度消失或爆炸的梯度突变问题。换言之，经典 Elman 网络难以利用监督学习构建输入序列的长程上下文依赖，即 n-gram 中的 n 难以很大。为此，拥有输入门、遗忘门和输出门的 LSTM 通过门控机制巧妙克服了梯度突变问题，较好解决了序列长程依赖的监督学习与预测。

但 LSTM 对长程依赖的建模仍受序列长度限制，且由于保留顺序性无法并行化，难以扩展为大型语言模型 LLM。新一代 Transformer 摒弃递归与卷积，通过全局注意力学习机制和位置编码的设计，被证明具有更强的序列上下文表征与自回归生成能力，已成为大型语言模型的不二之选，是推动 ChatGPT 发展的核心架构。最后，在编码器-解码器、仅编码器或仅解码器三种框架下，该模型可扩展至百亿甚至万亿参数级别，并适用于多种模态输入输出以及基于高维隐空间的多模态转换、融合与泛化增强，已成为生成式人工智能的基础框架与底层逻辑。

本章共 6 节。第 2.1 节为引言，阐述前馈、递归与 Transformer 的贯通关系与演进路径，强调输入 token 序列的隐状态表征及输出 token 序列的自回归生成。第 2.2 节重点介绍递归神经网络的编码器-解码器框架，先从前馈网络演化到 Elman 经典递归网络，再由 Elman 演化到 LSTM，最后发展为编码器-解码器框架以完成不同序列表达任务。第 2.3 节介绍 LSTM 网络的注意力及其点积相似性计算。第 2.4 节详细讲解 Transformer 模型，包括传统编码器-解码器框架、嵌入向量与位置编码，以及作为核心单元的多头注意力机制与逐位置前馈网络。

## 2.2 递归神经网络：编码器-解码器框架
下面主要介绍作为深度生成式人工智能基础的编码器-解码器框架。首先，为使前馈网络能够处理序列输入，需要为隐层状态增加沿时间步的记忆能力，即增设可实现一阶记忆的上下文结构单元层，从而构建具有动态逼近能力的 Elman 递归网络。由于引入时间步，传统的 Elman 网络在损失函数沿时间轴进行误差反向传播时容易出现梯度突变，导致无法学习序列上下文的长程依赖。为解决该问题，LSTM 通过输入门、遗忘门和输出门的巧妙设计，较好克服了梯度突变挑战，有效实现了长程依赖的监督学习与预测。

### 2.2.2 Elman网络：经典递归神经网络
#### 1. Elman网络
类似于反馈神经网络，递归神经网络可划分为完全递归与部分递归神经网络。在完全递归神经网络中，全部的前馈与反馈连接权矩阵都可以进行学习修正。而在部分递归神经网络中，从隐层到上下文结构单元层的反馈记忆连接不存在任何可供学习修正的连接权。这里的上下文结构单元层记忆了网络隐层过去的状态，将连同网络当前输入乘以相应连接权共同作为隐层输入。这一性质使这种部分递归神经网络具有通过学习以任意精度逼近任意非线性动力学系统的能力。

下面将从模型的网络结构与学习算法两个方面进行详细说明。
#### 1) 网络结构
图 2.1 的递归神经网络具有最简单的网络结构，可采用动态误差反向传播算法进行完全监督学习，这实际就是 Elman 网络。图 2.8 给出了 Elman 网络的结构示意图。从图中可以看出，Elman 网络具有与前馈神经网络完全相同的输入层、隐层及输出层，区别仅在于它还具有一个独特的上下文结构单元层，且该层记忆了上一时间步的隐层状态，可看成一个一步时延算子。此时，该网络在第 k 时间步的输入不仅包括了目前的输入值 u_k，同时还包括了前一时间步的隐层状态 x_{k-1}。两者各自通过递归神经网络的共享连接权矩阵 U、W 共同作用于隐层输入，然后再通过共享连接权矩阵 V，继续作用于整个网络的输出层。显然，这里 3 个前馈连接权矩阵 W、U、V 均可进行监督修正，但隐层到上下文结构单元层的反馈记忆部分则不能进行学习修正，因此 Elman 网络仅属于部分递归神经网络。
