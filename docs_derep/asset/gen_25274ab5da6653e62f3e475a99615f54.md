# 上海数据条例全景解读

## 序

地方立法由学者主笔推出释义著作，在国内尚不多见，而这部作品很可能就是首例。促使作者团队倾注心力的，正是《上海市数据条例》（以下简称《条例》）。《条例》经上海市十五届人大常委会第三十七次会议于2021年11月25日通过，全文分十章九十一条。除开篇总则与收尾附则之外，第二章至第九章依次涉及数据权益保障、公共数据、数据要素市场、数据资源开发和应用、浦东新区数据改革、长三角区域数据合作、数据安全以及法律责任。在立法理念、制度选择与规则设计上，《条例》均有开创性尝试，既体现了我国地方数据立法的先进水平，也折射出数字时代地方立法普遍面临的规律与难题，因而值得系统阐释。

2020年3月30日，《中共中央 国务院关于构建更加完善的要素市场化配置体制机制的意见》首次将数据与土地、劳动力、资本、技术并列为“第五要素”，由此指引数据交易市场培育，鼓励产业链各环节主体在合规安全有序的框架下开发数据价值，推动数据要素在数字经济时代合理流通。于宏观层面看，数据立法既是大数据、云计算、人工智能迅猛发展的法治配套需求，也是我国参与相关领域国际竞争的重要支撑。

习近平总书记对科技创新等重点领域的立法高度关注，指出数字经济、互联网金融、人工智能、大数据、云计算等新技术新业态快速涌现，相关法律制度却存在滞后与空白^[(\[1\]](#fow001.html#footnote_content_fow001_1))。当前我国数据立法尚存空白亟待填补。地方立法探索必须以习近平法治思想为指引，坚持科学立法，推进中国特色社会主义法治体系建设，最终在法治轨道上提升国家治理效能。制定颁布《条例》，正是补齐短板、健全制度、回应人民对美好生活需要的重要举措，不仅可为各地立法提供示范参考，也为国家层面立法积累地方经验。尤其在数据交易、公共数据授权运营、数据权益保护等方面的创新，影响尤为深远。

上海作为全国最大经济中心城市，正全面推进城市数字化转型，打造全球卓越城市与世界数字之都。这一目标对数据的采集、生成、共享与应用提出更高要求。《关于全面推进上海城市数字化转型的意见》指出，数据资源在联通国内大循环与双循环中的引领、功能与关键作用日益凸显，推进城市数字化转型既是服务新发展格局的主动战略，也是超大城市治理现代化必然要求。《条例》的出台为此提供了坚实的法治保障。

《条例》通过当日，上海数据交易所亦同步诞生。《条例》第67条规定：“本市按国家要求在浦东新区设立数据交易所并运营。数据交易所应依相关法律、行政法规及主管机关规定，为数据交易提供场所设施，组织监管交易。交易所应制定交易规则与业务规则，探索分类分层的新型数据综合交易机制，组织合规审查、登记清算、信息披露，确保交易公平有序、安全可控、全程可追溯。浦东新区鼓励市场主体依法通过交易所交易。”该条为交易所设立运营奠定了法律基础。成立以来，上海持续完善基础设施，推动公共数据开放与授权运营，引导主体依规交易，场外市场亦据此提升合规水平。准确理解适用《条例》已成为数商关注焦点，也成为各主体推进生活、经济、治理数字化转型的规则指引。

本书以条文详解为核心，每条配备主旨、核心概念、参考资料三模块，分层解读条文。工作严格遵循法释义学原理，注重条文内部联系及条例与上位法体系的协调，全面揭示立法精神与意图。力求兼顾专业性、实用性与理论性，为从业者、数商、法律工作者及研究者提供参考。需要说明的是，本书属民间编撰，条标到观点均系自由发挥，不具官方背景。

本书由我国数据法治领域多位青年学者与实务工作者共同完成，部分作者全程参与《上海市数据条例（学者建议稿）》起草，对条文形成背景与演变有深入把握。作者来自上海交通大学、东南大学、北京航空航天大学、上海政法学院、同济大学等多所高校，也有来自大成、中伦、国瓴等律所的实务专家。初稿获苏宇、韩旭至、李群涛等学者与立法专家指导，上海交通大学龚思涵、上海大学许端蓉、武汉大学刘羿鸣同学参与文字校对，谨此致谢。

本书写作始于2021年，历时近三年。期间国家与地方数据政策、数字经济实践持续进展。2022年6月中央全面深化改革委员会第二十六次会议审议通过《关于构建数据基础制度更好发挥数据要素作用的意见》；2022年12月中办国办正式发布该意见，即“数据二十条”。2023年2月中办国办印发《数字中国建设整体布局规划》，为数据制度建设提供宏观框架。实践层面，2023年3月党中央决定组建国家数据局，并于当年10月25日正式揭牌，目前全国已建数十家数据交易所。为跟进上述进展，2023年4月9日我们在同济大学举办“促进数字经济高质量发展的法治保障暨《上海市数据条例理解与适用》审读研讨会”，《条例》立法专班主要同志参会并提出意见，团队据此进一步修改。

为数据立法意义重大，但数据复杂性也带来挑战。科学立法需更新理念与规则设计，而这又建立在对事物本质的认知上。坦率讲，我们对数据及其流动规律仍在探索。法律人习惯于以释义沟通规则与案件，传统农业文明与工业文明历时漫长、体系稳定，法律规范相对成熟。但数字智文明是颠覆性的新形态，数字社会数据流通的本质研究已成为规范设计的前提。通晓事理方能得法理，事理不明则法理不清。

近年来笔者在市法学会支持下参与《上海市数据条例（学术建议稿）》《上海市促进人工智能产业发展条例（草案）》《上海市促进城市数字化转型条例（草案）》及《上海市促进浦东新区数据流通交易若干规定（草案）》起草，反复得到的启示是，我们对数据的认识非但不少，反而太少。企业、产业部门与立法机关的智慧与勇气令人钦佩，但认知局限是普遍难题。数字时代，以《条例》为代表的地方立法探索，正是在面对技术系统与商业场景时，努力填补认知空白、革新立法理念、优化工作机制、提升技术水平。这些探索支撑着我国在数据、人工智能与数字中国建设中的实践。

归根到底，数据是为解决问题而存在，回答生活、经济与治理之问。正是这些问题决定了数据的社会属性，也赋予数据法现实面向。同时数据具技术属性：须在系统中采集处理、人不可读、机可读，具有可计算性，生命周期中形态、参与者与权益内容不断变化。数据还具不可合约性，与可计算性共同导致确权与交易制度设计的困难。认识数据注定漫长艰辛，手上这部《条例》、本书乃至我们这一代人，可能仅是在探寻本质，为后人更正典的释义学研究铺路，为国家层面数据立法破解“卡脖子”难题提供养分，不负可歌可泣的中国实践。

本书写作与出版获上海市人工智能社会治理协同创新中心与上海数据交易所支持，谨致谢忱！

# 第一章　总　则

## 第一条　【立法目的】

为了保护自然人、法人和非法人组织与数据有关的权益，规范数据处理活动，促进数据依法有序自由流动，保障数据安全，加快数据要素市场培育，推动数字经济更好服务和融入新发展格局，根据《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》等法律、行政法规，结合本市实际，制定本条例。

本条划定了《上海市数据条例》的目的与依据。目的与依据合一置于首条，符合国内立法惯例。条款本身不直接适用个案，却对法律解释具有关键意义。

### 一、立法背景

2015年8月国务院发布《促进大数据发展行动纲要》，要求推进大数据发展应用，建设数据强国，将政府数据共享与公共数据开放列为重点。2015年10月党的十八届五中全会提出实施国家大数据战略。2016年全国人大通过的《国民经济和社会发展第十三个五年规划纲要》明确把大数据作为基础性战略资源，强调数据资源共享开放与开发应用。2020年4月9日中发文件将数据提升为与土地、劳动力、资本、技术并列的第五生产要素，凸显其资源价值。

《上海市数据条例》出台前，我国已有多个省市在数据领域制定地方性法规或政府规章。按名称大致可分五类。

一是大数据。2016年9月上海市政府印发《上海市大数据发展实施意见》，全国层面贵州省率先探索，2016、2018年先后通过《贵州省大数据发展应用促进条例》《贵州省大数据安全保障条例》。

二是政府数据。2017年贵阳市人大常委会通过《贵阳市政府数据共享开放条例》，2020年贵州省人大通过《贵州省政府数据共享开放条例》。政府数据共享开放立法动因在于大数据技术应用，而政府信息立法更侧重透明政府建设，两者进路应有所区别。

三是政务数据。指政务部门履职中形成或获取的数据。2016年起多地出台政务数据管理规章，2020年沈阳市、山西省分别出台地方性法规。

四是公共数据。指公共管理和服务机构履职中生成采集的数据资源，范围涵盖政府数据与公共服务机构数据。2016年《网络安全法》《电子商务法》提出促进公共数据资源利用。2017年浙江省率先出台《浙江省公共数据和电子政务管理办法》，2022年制定《浙江省公共数据条例》；成都市、无锡市等亦先后出台相关规章。上海于2018、2019年分别制定《上海市公共数据和一网通办管理办法》《上海市公共数据开放暂行办法》。

五是数字经济。指以数据资源为关键生产要素的新经济形态。浙江省、广东省分别于2020、2021年通过《浙江省数字经济条例》《广东省数字经济条例》。

名称差异一方面源于概念认知差异，如政府数据、政务数据、公共数据常被混用；另一方面各地结合实际选择不同路径，有的分别立法。

### 二、立法过程

地方数据立法热度上升的同时，中央立法与政策也在提速。2018年9月《十三届全国人大常委会立法规划》将个人信息保护法与数据安全法列为第一类项目。2021年6月10日与8月20日全国人大常委会先后通过《数据安全法》与《个人信息保护法》。2019年10月党的十九届四中全会首次将数据列为生产要素，要求建立按贡献分配机制。2020年4月9日文件再次明确数据要素地位。

中央进展反过来推动地方立法。2021年6月29日深圳市人大常委会通过《深圳经济特区数据条例》，内容覆盖个人数据、公共数据、数据要素市场、数据安全，呈现综合性立法新模式。上海立法启动虽晚于深圳，但节奏密集，最终同于2022年1月1日实施。

大致时间线如下：2020年底市人大常委会法工委拟定2021年度立法计划，初拟《上海市公共数据管理条例（暂定名）》。2021年征求代表意见后更名为《上海市数据条例（暂定名）》。2021年3月2日市政府立法工作计划将其列为拟提请审议项目。立项初期曾就“公共数据”与“数据”定名展开讨论，最终删除“公共”，转向综合数据立法。

2021年4月28日市人大财经委委托市社科院完成的《上海市数据立法调研》结题。2021年5月27日由市政府办公厅、市人大财经委、市经信委联合主办的数据立法研讨会召开，起草组组长、市政府办公厅副主任、市大数据中心主任朱宗尧介绍了立法总体定位。
