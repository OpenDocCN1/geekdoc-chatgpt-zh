# 提示词搭建要点
(6) 画幅比例。常见写法有 16 : 9、9 : 16、2 : 3 等。
(7) 输出清晰度。常用规格有 4K、8K、16K、32K 等。
(8) 渲染方式。典型关键词包括 Unreal Engine (虚幻引擎)、octane render (辛烷值渲染)、Maxon C4D (一种渲染)、Quixel Megascans Render (有真实感的渲染)、architectural visualisation (建筑渲染)、Corona Render (室内渲染 )。
(9) 系统设置。可不填写，系统会沿用当前版本的默认配置。

在撰写提示词时，可参考这个组合思路：主体描述 + 环境描述 + 氛围描述 + 光线 + 色彩 + 构图 + 作品风格 + 相机参数 + 渲染参数 + 配置参数。例如：“A girl is standing, ports, ships, sunset, beautiful lighting, golden moments, surreal atmosphere, focused, detailed, cinematic quality, clouds in the sky, and sunlight is shining on the girl’s hair and body. The color scheme of Monet’s oil painting style, Hayao Miyazaki style, Studio Ghibli, illustration --ar=16 : 9” （意为：女孩站在港口，背景有船只与日落，灯光明亮为黄金时刻，氛围超现实，画面聚焦精细具电影感，天空云朵缭绕，阳光洒在头发与身体上；色调参考莫奈油画，风格融合宫崎骏与吉卜力工作室的插画感，宽高比 16 : 9）。
