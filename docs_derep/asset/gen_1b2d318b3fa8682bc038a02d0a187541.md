先为单个示范样例起一个 example_prompt，再用 few_shot_prompt_template 来说明整体任务，最后把两者组装成可用的完整提示。把新的报告原文喂进去，就能自动产出要点提炼。LangChain 还内置了基于嵌入的 Example Selector，可以在海量范例库里自动挑出与当前任务最匹配的少量示例，拼出更优的 prompt，从而进一步提升生成质量。类似思路也可以搭在知识库之上，通过 prompt 引导大模型做主题撰写、观点评论、对话续写等更开放式的写作，模型的创造力和连贯性会显著拉高文档助手的智能水位。

#### 6.3.4 文档内容的清洗和预处理

原始文档常夹杂冗余信息、格式错误、编码问题等噪声，必须清洗预处理以提高文本质量，这是文档智能管道的重要环节。TextSplitter 输出的文本片段在进入下一步前，通常需要过滤掉过短或过长的异常片段；剔除 \x01、\u001 这类特殊字符；清理多余空格、换行、停用词；把 HTML 转义符如 & 替换回来；清除 URL、邮箱、电话、社交账号等；转换 UTF-8、Latin-1 等不同编码；修正标点、拼写错误；统一大小写、时态、单复数；再切分为句子、词等基础单元。
