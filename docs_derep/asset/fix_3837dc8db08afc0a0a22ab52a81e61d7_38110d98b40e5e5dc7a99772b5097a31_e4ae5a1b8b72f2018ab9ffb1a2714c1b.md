# 第二步

1. 场景导入：以学生熟悉的生活情境引入，例如宠物店配送员统计脚数的动画

道具法：用积木或硬币模拟头数与脚数
3. 思维手架：
◎ 关键提问：‘如果全是鸡会怎样？多出的脚是谁的？’
◎ 误区预判：提前拆解直接用94除以4求鸡数的错误思路
4. 语言技巧：

# 第三步
基于原题进行拓展训练：
1. 梯度练习：

2. 游戏化练习：

3. 生活迁移：
设计超市购物情境，如买5元与3元面包共花费32元
