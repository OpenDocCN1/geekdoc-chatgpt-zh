### 2.3 Encoder 与 Decoder 协作原理

Transformer 的工作分为编码阶段与解码阶段：Encoder 先把输入提炼为富含上下文的表征，Decoder 再依据该表征逐步生成输出，完成序列映射。

本节通过实例呈现 Encoder 多层堆叠下信息如何逐层演化，解释输入如何被映射为全局表征供 Decoder 使用，同时演示 Decoder 的自回归生成逻辑，说明生成时如何持续引用 Encoder 的输出。

#### 2.3.1 多层 Encoder 堆叠与信息传递实现

在 Transformer 架构中，Encoder 采用多层堆叠方式逐步提取序列高阶语义。每层以上一层输出为输入，借助 MultiHeadSelfAttention 与 FeedForward 强化序列间依赖并丰富表征，同时利用残差相加与 LayerNorm 保障梯度回传顺畅，使深层结构仍能保持信息稳定传递。

class TransformerEncoderLayer(nn.Module):

    def __init__(self, d_model, num_heads, dim_feedforward, dropout=0.1):

        super(TransformerEncoderLayer, self).__init__()

        self.self_attn = MultiHeadSelfAttention(d_model, num_heads)

        self.feed_forward = FeedForward(d_model, dim_feedforward, dropout)

        self.residual_norm1 = ResidualNormLayer(d_model, dropout)

        self.residual_norm2 = ResidualNormLayer(d_model, dropout)

    def forward(self, src):

        src2 = self.self_attn(src)

        src = self.residual_norm1(src, src2)

        src2 = self.feed_forward(src)

        src = self.residual_norm2(src, src2)

        return src

## 定义多层编码器堆叠

class TransformerEncoder(nn.Module):

    def __init__(self, d_model, num_heads, num_layers,

                 dim_feedforward, dropout=0.1):

        super(TransformerEncoder, self).__init__()

        self.layers = nn.ModuleList([TransformerEncoderLayer(d_model,

            num_heads, dim_feedforward, dropout) for _ in range(num_layers)])

    def forward(self, src):

        for layer in self.layers:

            src = layer(src)

        return src
