编程接单不只是程序员的事。现在只要能用自然语言描述需求，就能让 AI 写代码。做的不是大项目，而是行政、财务、电商运营人群的刚需小工具，如 Excel 自动化、数据批量处理、个人网站、微信群管理工具。单价几百到几千，程序员嫌单小，客户自己搞不定，正好形成空白市场。用豆包写代码快且稳定，多数简单脚本几小时可完成，不影响主业。

**4.4.1**

**接单执行流程**

第一步，锁定需求。需求不清是最大返工源，必须确认四要素：输入格式如 Excel、CSV；输出格式如新 Excel、文档；处理逻辑如筛选、汇总；使用频率如每日、每周。客户说要 Excel 自动化脚本，就追问：表格里有哪些字段？要实现什么功能如按月汇总订单、筛选金额超 1000 元客户？结果导出什么格式？多久用一次？

第二步，把需求转成精准提示词，生成可运行代码。以 Excel 自动化汇总为例，提示框架如下。

你是一名有实战经验的 Python 开发者，请按以下需求写 Excel 自动化脚本。

任务：文件 A 列客户姓名、B 列手机号、C 列订单金额、D 列订单日期，需：
1. 按月汇总每位客户订单总额；
2. 筛选订单金额超 1000 元的客户并导出新 Excel；
3. 生成按金额降序的客户排行榜，写入原文件新工作表。

技术要求：用 openpyxl 或 pandas，代码可直接运行，带中文注释，输出文件名含“订单汇总+生成日期”，加入空值、格式错误等异常处理。

把提示词输入豆包的编程区。
