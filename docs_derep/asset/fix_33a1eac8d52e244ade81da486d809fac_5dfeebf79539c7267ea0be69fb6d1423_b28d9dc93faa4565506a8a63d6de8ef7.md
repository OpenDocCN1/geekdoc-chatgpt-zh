Yann LeCun 在光流自监督上主张一种逐级由粗到精的策略。输入是连续两帧 RGB 图像 $I_t, I_{t+1} \in \mathbb{R}^{3,H,W}$，对应的运动矢量 $f \in \mathbb{R}^{2,H,W}$ 把 $I_t$ 中的每个像素位置映射到 $I_{t+1}$。目标是学到参数为 $\theta$ 的估计器 $F_\theta$，在图像序列集合 $D = \{\{I_t\}_{t=1}^T\}_{i=1}^N$ 上训练，使得预测的流 $f = F_\theta(I_t, I_{t+1})$。无监督的光流一般靠光度一致性或回归形式的损失来约束，即用预测流 warp 后的 $I_t$ 要尽可能接近 $I_{t+1}$，再加上平滑正则让流场不至于过于稀碎。不同方案的分野更多体现在损失的实现、编码器与流估计网络的架构选择，以及额外自监督信号的接入。

MC-JEPA 在这条路上选择了 PWC-Net$^{[875]}$ 作为流模块。金字塔结构让残差流能在逐层中把分辨率逐步提上来，得到的光流可以用来扭曲图像，再把推断出的未来状态与真实未来状态作对比。另一条线是先预训练编码器来学习内容表征，从而把两张图像的不同视角联合嵌入。MC-JEPA 通过随机裁剪、颜色扰动等图像变换制造多视图，再用一个扩展网络在这批视图上计算 VICReg 损失$^{[866]}$。

### 5.3.3 Dynalang：用语言推演未来
要真正和人互动、在真实世界行动，智能体必须把自然语言与视觉联系起来。现在很多 Agent 顶多能照着低级直接指令拿奖励，比如去拿某个具体物体。现实交流里充满需要领会的隐性知识，比如雨天地面更滑、瓷砖上行走不稳。Dynalang$^{[877]}$ 的想法是借语言帮助 Agent 做前瞻：会看到什么、世界怎么运转、哪些情境会被奖励。它把语言理解与未来预测合拢成一个自监督目标，用多模态世界模型去预测未来的文本表征和图像表征，并在想象出的模型里推演行动。传统做法往往只用语言来预测下一步动作，Dynalang 反过来用过去的语言去预测未来的语言，从而获得更丰富的语言能力。它既能在线交互学习，也能在不涉及动作或奖励的纯文本、纯视频或混合语料上做预训练。从网格世界里的语言提示到逼真的家居扫描，都能靠多样化的语言提升任务表现。

如图 5.15 所示，Dynalang 靠上下文对后续观察做预测来解决问题。在 HomeGrid 环境中，Agent 边探索边接收视频与文本。从“过去”文本“瓶子在客厅”出发，它推断时间步 61~65 会在客厅角落看到瓶子；从任务描述“拿到瓶子”推断完成时会得到奖励。Agent 还能做文本的未来预测：给定前缀“盘子在”，在 $t=30$ 看到台面上的盘子，最可能的续词是“厨房”。

[PRE0]

语言对世界的理解很契合世界建模思路。该工作承接 DreamerV3[878]，一种基于模型的强化学习 Agent。Dynalang 会不断吸收 Agent 执行任务时产生的经验。如图 5.16(a)，每一步世界模型把文本和图像压成潜在表示，并据此学习重建原始观测、预测奖励、预测下一步潜状态。直观上，模型在学习文本里读到的内容所对应的期望所见。如图 5.16(b)，Dynalang 在压缩表示上训练策略网络选动作，并通过对世界模型的想象回放学习最大化预测奖励。与以往逐句或逐段消耗文本的多模态模型不同，它把视频和文本当成统一序列来处理，一次只进一帧图像加一个文本 Token。类似人类听信息需要时间，这种序列化让模型像语言模型那样在纯文本上预训练，进而提升强化学习效果。

### 5.3.4 互动式现实世界模拟器
Dynalang 能用世界模型描述未来状态并预测奖励，自然可以延伸为直接用世界模型在模拟环境里生成训练数据。互联网上靠生成模型改写了文本、图像、视频的创作方式，下一个关键节点可能是让模型在响应人类、机器人或其他交互 Agent 的动作时模拟逼真体验。现实世界模拟器既可用在游戏电影的可控内容生成，也可用在模拟中训练具身 Agent 后直接部署到真实世界。如图 5.17，基于 GAIA-1[879] 框架可以构建按用户需求生成动态驾驶视频的系统。这是一个生成式世界模型，融合视频、文本、行动输入生成逼真驾驶场景，并对自车行为和场景要素做精细控制。

[PRE2]

GAIA-1 把世界建模当作无监督序列建模问题，通过把输入映射到离散标记来预测序列下一个标记。它的新亮点包括学习高层结构与场景动态、上下文感知、泛化与几何理解。GAIA-1 学到的表征能捕捉对未来事件的预期，再加上生成逼真样本的能力，为自动驾驶创新提供可能。模型约 90 亿参数，用 4,700 小时驾驶视频训练，可模拟多种路况与天气，有效预测行驶中可能出现的场景，帮助车辆适应不断变化的世界。这种方式既提升安全也降低成本：世界模型通过模拟未来让 AI 对自己的决定产生觉察，对安全至关重要；训练数据也至关重要，合成数据更安全、更便宜且可无限扩展。生成式 AI 还能覆盖更多边缘情形，比如大雾中行人横穿马路。

除了自动驾驶模拟器，UC 伯克利、Google DeepMind、MIT 等机构的研究者还探索了用生成模型学习真实世界交互的通用模拟器 UniSim，迈出了构建通用模拟器的第一步[880]。主要障碍是可用数据的获取难度。虽然互联网上有数十亿文本、图像、视频片段，但不同数据覆盖的信息轴不同，必须整合才能模拟真实体验。比如成对图文数据场景对象丰富但动作少；视频字幕问答数据高级活动描述丰富但低层运动细节少；人类活动数据有人类动作但机械运动少；机器人数据机器人动作丰富但体量有限。为克服这些挑战，研究者把大量互联网图文对汇集进条件视频生成框架 UniSim 中，如图 5.18 所示。

[PRE3]

通过精心编排不同轴上的丰富数据，UniSim 能把不同轴数据的经验融合并推广到数据之外，通过控制静态场景和对象细粒度运动实现丰富交互。借助世界模型学习真实常识，再以多模态大模型可视化并模拟现实世界，是一个很有前景的方向。

### 5.3.5 Sora：从文本到动态影像的生成实验
2024 年 2 月 16 日，OpenAI 对外公布了“文本到视频”生成式模型 Sora$^{1}$。作为可扩展的视频生成模型，Sora$^{[881]}$ 可能是学习物理世界模型、构建物理世界通用模拟器的一条路径。其技术突破主要在四点。

- 能生成长达一分钟、符合用户文本指令的视频，同时保持较高视觉质量与连贯性；
- 具备模拟物理世界的潜力。经训练理解并模拟运动物理世界的 Sora 能依据文本指令生成逼真或富有想象力的场景，可生成含多角色、特定运动类型、主体与背景细节准确的复杂场景，并理解事物在物理世界中的存在方式；
- 对语言理解很深，能生成富有生动情感的角色，还能在单个视频里创建多个镜头，准确体现角色与视觉风格，并呈现细微物理变化与背景动态；
- 支持视频编辑，可在两个输入视频间逐帧插值，在主题与场景构成迥异的视频间创造流畅过渡。

Sora 的核心是基于预训练 Transformer 的扩散模型。与 GPT-4 等 LLM 类似，它能解析文本并理解复杂指令。为提升效率，Sora 采用时空潜在图像块作为构建单元。具体而言，先把原始视频压缩为时空潜在表示，再抽取一系列包含短时视觉外观与运动动态的时空潜在块。这些块类似语言模型里的 Token，为生成视频提供视觉短语。文本到视频生成由扩散 Transformer 完成：从带视觉噪声的帧开始迭代去噪，并按用户文本提示引入细节。本质上视频是多步恢复过程的产物，每一步都让视频更符合内容与质量要求。

如图 5.19，Sora 主要由三部分组成。

- 视频压缩网络先把原始视频映射到时空潜在空间；
- 处理 Token 化后的潜在表示并输出去噪后的潜在表示；
- 类似 CLIP 的调制机制，接收 LLM 增强的用户指令和潜在视觉提示，引导扩散模型生成风格化或主题化视频。经多次去噪后，生成视频的潜在表示被获取，再通过解码器映射回时空像素空间。

- 语言理解：OpenAI 发现训练文本到视频生成需要大量配对文本标题的视频。OpenAI 把 DALL·E 3 中的标注生成技术迁移到视频领域，训练了一个高度描述性的视频描述模型，用它为全部训练视频生成高质量文本描述，再以视频-文本对训练。这样文本提示与视频数据高度对齐。生成阶段，Sora 会先用 GPT 模型改写用户提示，生成高质量描述性提示，再送入视频生成模型。

大规模训练后，Sora 涌现出模拟能力，能模拟物理世界中人、动物、环境的某些方面，包括：

- 三维一致性：可生成带摄像机动态移动效果的视频，随着摄像机平移旋转，人物与场景元素在三维空间中相应移动；
- 长距离连贯性与物体持久性：Sora 通常能有效模拟短距离与长距离依赖。例如人物、动物、物体被遮挡或离开画面时仍保持存在；也能在单次采样中为同一角色生成多个镜头并贯穿始终保持外观不变；
- 与世界互动：可模拟影响世界状态的行为。例如画家在画布上留下新笔触并随时间持续存在。

尽管 Sora 能生成逼真视频，视频仅受提示词引导，并未准确刻画物理规律，难以精确操控事物。因此它难以作为反事实推理$^{1}$ 工具准确回答 what if 问题。即使规模持续扩大，也无法直接实现模拟物理世界的仿真器，需要超越数据做反事实推理，具备回答 what if 的能力。反事实推理是人类天然的因果推理能力，当前 AI 模型尚不足。

图灵奖得主 Yann LeCun 指出当前基于自回归的生成式多模态大模型如 Sora 在透彻理解物理世界上的不足：仅按提示生成逼真视频不代表模型理解物理世界，生成过程与基于世界模型的因果预测完全不同。虽然 Sora 能想象大量视频类型，但生成系统只要产出一个合理样本就算成功。真实视频中符合物理规律的内容相对较少，尤其在特定动作条件下。此外，生成视频续篇不仅成本高且意义不大。更理想的做法是生成续篇的抽象表示，剔除与可能行动无关的场景细节。这正是 JEPA 的核心思想，它是非生成式的，在表征空间中做预测。

Sora 公布当天，Meta 推出无监督视频预测模型 V-JEPA$^{2}$，能以人类理解方式看世界，通过抽象高效预测生成被遮挡部分。它揭示了世界模型容量直接影响所学表征抽象程度的关键。与生成式 Sora 完全不同，V-JEPA 是非生成模型，与 I-JEPA 类似，后者通过比较图像抽象表征学习而非直接比较像素。不同于试图重建每个缺失像素的生成方法，V-JEPA 能舍弃难预测信息，从而提升训练与样本效率。V-JEPA 结构如图 5.22 所示，输入为 $T$ 帧、空间分辨率 $H \times W$ 的视频片段，展平成 $L$ 个 Token 的序列。首先去掉掩码 Token 作为编码器 x 的输入。编码器 x 处理掩码视频序列并为每个输入 Token 输出嵌入向量。随后把编码器 x 的输出与一组可学习掩码 Token 连接，其中包含掩码时空块的位置嵌入。预测器处理组合 Token 序列并为每个掩码 Token 输出嵌入向量。最后用 L1 损失逼近预测器的输出与预测目标，预测目标对应编码器 y 的输出。

[PRE7]

V-JEPA 中的 V 代表视频，聚焦视频视觉元素的分析。Meta 的方向是推出能同时处理视频视觉与音频信息的多模态方法。作为概念验证模型，V-JEPA 在识别视频中细微物体互动方面表现突出。例如能区分某人放下笔、拿起笔，或假装放下但实际未放下。研究人员用 V-JEPA 做感知——通过分析视频流实时理解周围世界。在联合嵌入预测架构中，预测器充当初步物理世界模型，能概括视频中正在发生的事。下一步目标是利用该预测器做规划与连续决策。V-JEPA 只需观察视频训练，如同婴儿观察世界，无需强监督即可学习大量知识。从长远看，其强大的情境理解能力对开发具身智能意义重大。

## 5.4 超级智能体 AGI Agent
1981 年，希拉里·普特南在《理性、真理与历史》中提出“缸中之脑”假想。科学家把人脑取出置于营养液缸中维持运转，神经末梢连到电线，另一端是计算机。计算机模拟真实世界参数，通过电线传递信息，让大脑感觉一切正常。对大脑而言，人、物体、天空仿佛仍存在。多模态大模型就像这样的“缸中之脑”，靠 GPU 和电力维系一个近似。

多模态大模型：新一代人工智能技术范式

AGI 的 GPT 模型。当前 LLM 具备一定智力与庞大知识，但除内容生成等通用能力外，其它领域潜力尚不明，而人类日常任务大致分为两类。

- 离散、孤立任务：与环境无关、无时空依赖，如编程、下围棋、内容生成；
- 连续、与环境捆绑任务：与环境相关，如点外卖、打车、经营企业。

“缸中之脑”只能处理前者，而绝大多数任务属于后者，关键在于 Agent。因此 Agent 是多模态大模型与任务场景之间价值传递的桥梁。
