### 8.2 实战：QQ机器人创建与OpenClaw集成

#### 8.2.1 配置机器人基础信息与沙箱环境

账号注册完成后即可正式创建 QQ 智能体并展开部署。接下来将从创建智能体、配置基础信息、获取凭证到搭建测试沙盒，实现一个功能完整的助手。

登录开发者中心后，在控制台首页可找到各功能入口。顶部导航栏的机器人标签进入管理页，首次使用点击创建机器人按钮，系统进入创建向导；已有智能体的账号则会列出名称、状态、ID 等信息，点击卡片可进入详情页管理。

[PRE5]

首要任务是填写基础信息。智能体名称是用户最先看到的标识，建议简洁明了且能体现功能，例如命名为 OpenClaw 助手，便于记忆识别。然后上传一张自定义头像，支持 png、bmp、jpeg、jpg 格式，头像辨识度要高，清晰的图标或 Logo 更利于用户识别。

[PRE6]

再填写智能体描述，用于向用户说明主要功能和用途，这段说明会在用户添加智能体或查看资料时展示，是了解能力的窗口。简介最多 120 字，用精炼语言突出核心功能。

基础信息确认后点击确认并提交，系统会进行审核。审核通过即可继续配置，未通过时会提示具体原因，需要修改后重新提交。常见失败原因包括名称含敏感词、头像模糊或带广告、简介表述不当等。

[PRE7]

创建成功后返回开发者中心首页，点击顶部机器人标签进入列表，刚创建的智能体显示在列表中，点击卡片进入详情管理页，后续所有管理工作都在此完成。

[PRE8]

图 8-12 进入机器人管理页面

智能体详情页集中了全部配置与管理功能，是后续工作的核心枢纽。页面分为管理、数据、开发等多个板块。进入管理→开发管理后可以看到与外部服务通信所需的凭证。顶部会展示两个关键参数：AppID 即智能体 ID，是平台内唯一的数字标识，用于标记 API 请求来源；AppSecret 是 API 鉴权密钥，相当于智能体密码，必须严格保密。

[PRE9]

获取 AppSecret 需注意安全。平台出于安全考虑不会明文展示完整密钥，首次查看时需点击生成，系统会产出随机密钥字符串。该密钥仅显示一次，必须及时复制保存。若遗忘或丢失只能重新生成，旧密钥随即失效，所有使用旧密钥的服务都要更新。建议将 AppID 和 AppSecret 保存在密码管理器、加密文档或团队的配置管理系统里，严禁提交到公开代码仓库或分享给无关人员。

凭证获取后，接着配置测试沙盒。点击开发→沙盒配置，可在正式发布前进行功能测试。沙盒环境功能与正式环境基本一致，但使用范围受限，只有授权用户或群组能与智能体交互，适合开发阶段的小范围验证。

沙盒配置涵盖两种场景：单独聊天和群聊。单独聊天用于一对一测试，验证基础问答与指令响应；群聊则模拟群组工作模式，可测试群消息接收等。

先配置单独聊天。在沙盒配置页的消息列表配置处点击添加成员，可通过输入 QQ 号或从通讯录选择添加测试用户。添加成功后列表会显示头像、昵称等信息。注意，仅添加成员还不够，被添加用户还需通过 QQ 扫码主动添加智能体。
