# 让模型读懂你的真实意图

有人会直接丢一句“帮我写一份关于消费者行为的报告”。这种提问太空，模型只能靠猜，产出往往泛而不准。与其不断返工，不如在提问时就把关键信息补全。

## 把边界说清楚

项目里有哪些硬限制，先讲明白，答案才具备可执行性。限制包括资金上限、时间节点、技术条件或合规要求。

好的示范可以这样表述：  
请为我位于大学城的面包坊制定社媒推广方案。团队只有两人，每月可用的推广费用不超过四百块，没有专职市场人员，希望操作简便，主要是小红书和抖音。

不好的示范：  
给我店做个营销方案。

## 表明风格偏好

告诉模型你偏好的语气、表达习惯与品牌调性，输出才会贴合气质。

好的示范：  
请帮我写一封客户参会邀请。我们是一家做智能硬件的初创公司，品牌调性亲切而不失专业，喜欢短句、画面感强的比喻，尽量少用行业黑话。

不好的示范：  
写一封活动邀请函。

### 给上下文的高阶做法

**编织情境**  
把需求放进一段背景里，模型更容易抓住整体。

示例：  
情境：我是初创创始人，下周要和几位潜在出资人首次碰面。产品是用智能算法帮中小企业做库存优化的SaaS。我很懂技术细节，却很难用简明有力的话说明价值。  
请帮我准备两分钟以内的电梯演讲，突出痛点、方案独特性与市场空间，语言专业但易懂，少用术语。

**用假设分支**  
用如果那么的句式让模型理解不同情境的应对。

示例：  
我正在设计客服回复模板。  
如果客户问退款流程，就说明我们有30天无条件退，同时提示需要原始凭证。  
如果客户投诉品质，就先表达理解与歉意，再请对方说明具体情况并附图。  
如果客户要求加急，就介绍VIP通道及额外费用，并给出标准时效供参考。

**给出负面示范**  
说明不想要什么，比只说想要什么更有效。

示例：  
请为健康食品品牌写产品描述，目标是真实、科学、不夸张。  
我不希望看到的口吻是：  
“这款超级食品能彻底改变生活！一周见效！所有健康问题都消失！”  
我更倾向的口吻是：  
“我们选用有机原料，富含抗氧化物。依据当代营养学研究，长期适量摄入可能对提升免疫有帮助。”

### 常见困惑的解法

信息量的把握  
提供足够背景但不堆砌。聚焦相关点，可把核心信息与补充信息明确标注。

敏感信息的处理  
可用脱敏或虚构数据替代，保留结构与比例即可。  
示例：  
我正在分析一家零售公司的销售数据，为保密已用虚构数字替代，但保留了真实比例与趋势。  
产品A去年销售额一千万，今年增长两成；产品B去年五百万，今年下降15%；产品C去年三百万，今年增长5%。请分析趋势并给出营销调整建议。

大量背景的高效呈现  
复杂项目建议用结构化方式呈现：项目简介、目标人群、关键要求、限制条件，分项说明更清晰。

### 小结

充足的上下文是获得精准结果的基础。明确使用者与使用场景、分享专业背景、说明已完成的工作、列出约束、传达风格偏好，都能显著提升回应质量。AI不会自行推断隐含期待，清晰的背景铺垫能大幅提高沟通效率，就像向完全陌生的新人讲解一样。

## 格式与结构的设计

输出不仅是文字堆砌，呈现方式直接影响可读性与专业度。

### 设定格式的核心策略

明确文档类型与目的  
不同文种有固定结构，说明需要哪种文档以及用途。  
好的示范：请创建一份远程办公政策备忘录，用来向全体员工传达新规。需要包含发件人、收件人、日期、主题，并按政策背景、主要变更、实施时间表、联系方式顺序组织。  
不好的示范：给我一份关于远程办公的文档。

指定组织方式  
说明希望按时间、重要性、问题解决等哪种逻辑展开。  
好的示范：请撰写产品发布计划，先写不超过两百字的执行摘要，再写市场背景，接着按重要性排序产品特性，然后以甘特图形式呈现时间表，最后做风险评估与应对。每部分要有清晰小标题。

提供模板示例  
给出简短示例能让模型立刻抓住格式要求。

指定视觉要素  
明确标题层级、强调方式、项目符号等要求。

明确长度要求  
对全文及各部分给出字数区间，保证全面又简洁。

### 不同文种的技巧

商务文书强调专业性与层次。  
提示词示例：请创建市场分析报告，按以下结构：封面、执行摘要、目录、引言、研究方法、市场规模与趋势、竞争格局、消费者行为、机会与挑战、策略建议、附录。

学术文书需遵守规范与引用格式。  
提示词示例：请起草关于深度学习在自然语言处理应用的摘要，按标题、摘要、关键词、正文、参考文献组织。摘要150到200字，参考文献采用APA格式。

创意内容需兼顾表现力。  
提示词示例：请创作未来城市生活的短篇科幻，标题醒目，开场不超过百字，正文分3到4个场景以分隔符隔开，结尾开放，字数1500到2000。

### 结构元素的实用技巧

借助视觉层次  
用标题层级、缩进、分隔线建立清晰结构。

用表格整理信息  
适合多维度对比。

提供图表说明  
AI无法直接绘图，但可生成详细描述便于后续制作。

### 常见问题

复杂嵌套结构易导致混乱，建议用明确编号并拆解为简单结构。  
长文档一致性问题，可先设定全局规则并提供示例段落。

### 小结

格式与结构是提升输出质量的关键。通过明确文种与目的、规定组织逻辑、给出模板、指定视觉要素、限定篇幅，能引导生成专业有序的内容。清晰的格式指引就像建筑蓝图，是高质量内容的基础。

## 角色与风格的设定

给AI指定角色与风格，就像给演员发剧本。

### 核心要素

明确身份与专业背景  
不要只说写文案，而要说明拥有十年奢侈品经验的高级策划。

定义沟通语调  
明确语气风格，直接影响情感基调。

确定表达风格与用词偏好  
指明句式、用词、修辞，使风格统一。

指定目标受众与适配要求  
明确读者群体的知识水平与关注点。

设定情感基调  
指明希望传达的情绪。

### 高阶策略

提供角色参考示例  
给出真实示例帮助模型把握风格。

使用角色背景故事  
用一段丰富的背景帮助模型更深入模拟角色思维。

多角色对话设计  
通过不同角色对话呈现多角度观点。

风格渐变指导  
在需要转换风格时提供渐进指引。
