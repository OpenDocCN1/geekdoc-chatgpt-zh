想让模型做象限划分，关键先把原材料整理好喂进去。把产品对应的市场增速和相对份额等关键维度整理成表，模型就能判定每件产品落在哪个象限，并给出象限间的联系与特征。

象限分析的价值在于直观呈现分布。把数值映射到四个象限后规律一目了然。当前版本的 ChatGPT 暂时无法直接绘图，但可以准确归类并输出象限洞察。下面用一个实操案例说明。

| 产品 | 市场增长率 | 相对市场份额 |
|---|---|---|
| 产品 A | 0.25 | 0.6 |
| 产品 B | 0.15 | 0.35 |
| 产品 C | 0.4 | 0.75 |
| 产品 D | 0.05 | 0.2 |
| 产品 E | 0.3 | 0.55 |
| 产品 F | 0.1 | 0.15 |

把上述信息交给模型后，推导思路大致如下：

先以两个维度的平均值作为分界。市场增长率平均约为 (0.25+0.15+0.4+0.05+0.3+0.1)/6 ≈ 0.2083，相对份额平均约为 (0.6+0.35+0.75+0.2+0.55+0.15)/6 ≈ 0.425。

以均值为基准划分：

+   1. 明星类，高增速高份额：增速 > 0.2083 且份额 > 0.425
2. 现金牛类，低增速高份额：增速 ≤ 0.2083 且份额 > 0.425
3. 问号类，高增速低份额：增速 > 0.2083 且份额 ≤ 0.425
4. 瘦狗类，低增速低份额：增速 ≤ 0.2083 且份额 ≤ 0.425

按此规则归类结果为：

+   1. 明星类：产品 C
2. 现金牛类：产品 A
3. 问号类：产品 E
4. 瘦狗类：产品 B、产品 D、产品 F

# 9.9 SWOT 分析实战拆解

SWOT 是战略咨询里高频使用的框架，也常被用于业务分析。首先让模型解释概念并举例。提示可以这样写：

> 请从数据分析角度介绍常用的SWOT方法，需包含定义、案例以及如何借助ChatGPT执行。

模型给出的核心定义：SWOT 由 Strengths 优势、Weaknesses 劣势、Opportunities 机会、Threats 威胁构成，用来识别内外部关键要素以制定策略。

+   1. 优势：组织或产品在竞争中的内部强项，如核心能力、资源、技术、人才等
+   2. 劣势：内部短板，如资源不足、流程低效、技术落后等
+   3. 机会：外部环境带来的利好，如需求增长、政策扶持、技术突破等
+   4. 威胁：外部环境带来的风险，如竞争加剧、政策变动、市场波动等

案例：手机制造商的竞争定位。

+   1. 优势：技术领先、研发团队专业、产品品质高、品牌口碑好
2. 劣势：生产成本高、营销资源受限、全球化经验不足
3. 机会：智能手机需求持续增长、新兴市场可拓展、技术创新带来差异化
4. 威胁：市场竞争激烈、价格战、政策变化、供应链不稳

借助 ChatGPT 的做法是把行业背景、竞争对手、目标市场等信息提供给模型，让它梳理四象限并给出策略建议。

在明确四个字母含义后，模型会指出 SWOT 需要对业务与行业的深度理解，它无法直接替你完成，但能提供思路框架。举例提示：

> 我在专注AI的初创游戏公司工作，现在要做SWOT分析，请告诉我如何逐步开展。

返回的工作步骤如下：

+   1. 信息收集：先掌握公司、市场、对手、行业趋势的相关资料，覆盖产品服务、企业文化、资源能力、市场规模、技术发展与政策等
2. 明确优势：内部强项，例如：
+   - 团队经验丰富
- 与发行商合作关系良好
- 对目标市场理解深入
3. 明确劣势：内部短板，例如：
+   - 资金来源有限
- 市场推广经验不足
- 对特定引擎或平台依赖度高
- 品牌知名度和影响力弱
- 时间和资源紧张
4. 明确机会：外部利好，例如：
+   - 游戏行业需求持续增长
- 新兴市场可开拓
- 跨平台发行与云游戏发展
- 合作伙伴网络可拓展
- AI技术进步带来创新空间
5. 明确威胁：外部风险，例如：
+   - 竞争激烈
- 技术迭代快
- 法规政策变化
- 用户数据隐私安全问题
- 知识产权保护与侵权风险
6. 制定策略和行动计划：基于分析结果强化优势、补足劣势、抓住机会、抵御威胁。例如加大研发投入优化 AI 与游戏设计，寻求战略投资解决资金问题。
7. 监测与评估：执行后定期跟踪销售额、市场份额、用户满意度等指标，动态更新 SWOT 并调整策略。

在每个环节都可向 ChatGPT 提问求助，例如信息收集阶段查竞争对手资料，策略制定阶段咨询推广方案，通过互动让分析更全面。

# 9.10 PEST 分析框架速览

PEST 与 SWOT 思路相近，也是常用的宏观分析框架。提示词示例：

> 请从数据分析角度介绍常用的PEST分析，需包含定义、案例以及如何借助ChatGPT执行。

模型解释：PEST 用于评估政治 Political、经济 Economic、社会 Sociocultural、技术 Technological 对公司和市场的影响，帮助发现机会与挑战。

案例：考虑在新市场推出智能家居产品时的环境扫描。

# 1. 政治层面：

模型给出的电商平台指标框架围绕用户、商品、交易、营销、客服与平台运营六大维度展开。

针对单模块也能定制，例如每日秒杀模块：

> 假如你是某电商平台的一名数据分析师，请针对平台的每日秒杀模块构建相关的数据指标体系。

模型给出：

- 用户相关指标：
  - a. 参与秒杀活动的用户数
  - b. 新增参与秒杀活动的用户数
  - c. 用户参与秒杀活动的次数
  - d. 用户转化率（购买成功用户数 / 参与秒杀活动用户数）
  - e. 用户留存率（连续参与秒杀活动的用户数 / 总参与用户数）

- 商品相关指标：
  - a. 参与秒杀活动的商品数
  - b. 秒杀商品的品类分布
  - c. 秒杀商品的销售额
  - d. 秒杀商品的销量
  - e. 秒杀商品的平均售价
  - f. 秒杀商品的库存数量
  - g. 秒杀商品的售罄率（销量 / 库存数量）

- 平台相关指标：
  - a. 秒杀活动的总访问量
  - b. 秒杀活动的总订单量
  - c. 平台秒杀活动的整体转化率（订单量 / 访问量）
  - d. 秒杀活动页面的跳出率
  - e. 秒杀活动页面的用户平均停留时间

- 营销相关指标:
  - a. 营销活动覆盖用户数
  - b. 营销活动点击量
  - c. 营销活动转化率（参与秒杀活动用户数 / 营销活动点击量）
  - d. 营销活动的成本
  - e. 营销活动的投资回报率（秒杀活动收入 / 营销活动成本）

通过这些指标可全面评估秒杀效果，找优化方向，提升参与度与收益。
