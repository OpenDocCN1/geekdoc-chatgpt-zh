#### 9.3.2 Postman 用例集的准备

在接口测试的 CI 流程中，需要调用 Newman 命令行工具运行测试，因此必须把 Postman 中的用例导出为 Collection v2.1 格式，即 JSON 格式的脚本集合。

Collection v2.1 脚本的获取主要有两种路径。

方式一：直接让 ChatGPT 生成测试脚本。下方即为 ChatGPT 产出的 Collection v2.1 格式脚本。

方式二：如果此前已通过 Postman 的图形界面搭建好用例集，现在需要导出为 Collection v2.1 格式，可选中目标用例集，点击 … 按钮，在弹出菜单中选择“Export”操作，如图 9-3 所示。

如图 9-4 所示，Postman 默认即选用 Collection v2.1 格式导出，点击“Export”按钮后输入文件名称即可完成导出，这里不再赘述。

#### 9.3.3 Newman 的安装和配置

Newman 是 Postman 官方提供的命令行运行工具，用于执行和验证 Postman 测试集合。常规的安装配置步骤如下。

首先确认本机已安装 Node.js 与 npm。Node.js 官网下载页如图 9-6 所示，在该页面下载安装包并完成安装，过程较为简单，此处省略。

[PRE6]

图 9-6 Node.js 官方网站的下载页面

随后打开命令行窗口，执行 `npm install -g newman` 完成安装。安装结束后，可通过 `newman run -h` 查看运行参数的帮助信息，如图 9-7 所示。

[PRE7]

图 9-7 查看 Newman 运行的相关参数帮助信息

为了在 Newman 执行后得到更完善的测试报告，需要额外安装两个报告插件 newman-reporter-html 与 newman-reporter-htmlextra。因此还需分别执行 `npm install -g newman-reporter-html` 和 `npm install -g newman-reporter-htmlextra`。
