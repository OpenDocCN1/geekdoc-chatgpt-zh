## 8.7 本章要点回顾
模型与提示词共同决定了 Stable Diffusion 的最终成图效果，通常先选定模型再细化描述。模型大体分为底模与 LoRA 等，底模可独立使用，LoRA 需依托底模运行。

提示词负责定义画面内容，可对关键字段加权，也能让两组描述在迭代中交替影响，方便实现人物融合等需求。

本章通过多个实操案例展示了工具的适用范围与基本思路，有助于建立对“能画什么、如何画”的初步认知。受篇幅所限示例有限，实际上只要模型和提示词搭配得当，几乎可以覆盖任意风格与题材。Civitai 等社区聚集了大量海外创作者的分享，可借此观摩更多案例并吸收技巧。

### 9.4 姿势控制
使用一段时间后会发现，仅靠文字很难精确控制人物姿势，部分动作难以描述，或即使描述了 AI 也理解不准。如何让人物摆出指定姿势？借助 ControlNet 就可以实现。

#### 9.4.1 什么是 ControlNet
ControlNet 是 Stable Diffusion 的一个扩展，提供了强大的控制能力，例如精确控制人物姿势、将线稿转化为精细图像等。

#### 9.4.2 安装 ControlNet
01 ControlNet 和其他扩展一样，可在 Web UI 界面单击顶部的“扩展”标签页，进入“扩展”界面进行安装。
