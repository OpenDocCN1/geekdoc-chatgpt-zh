### 2. LLM 缓存
为模型调用加一层可选缓存可带来两点收益：一是重复请求命中缓存，减少对大模型接口的调用从而降低开销；二是减少对第三方服务的依赖，加快整体响应。

常见的缓存实现有 InMemoryCache、RedisCache、SQLiteCache 等，均基于 BaseCache 抽象完成。

BaseCache 定义了 lookup、update、clear 三个基础操作，分别对应查询、写入、清空，并都提供了异步版本。

| 方法 | 是否必须实现 | 描述 |

| :--- | :--- | :--- |

| _call | 是 | 接收一个字符串和一些可选的停用词，并返回一个字符串。该字符串被 invoke 使用 |
