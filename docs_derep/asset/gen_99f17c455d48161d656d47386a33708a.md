#### 6.4.2 Python API 库（`aiy` 包）

为让 Vision Kit 轻松驾驭多样化功能，系统内置了功能丰富的 Python API 库 `aiy`。它封装了推理调用、目标框绘制、按键/LED/GPIO 外设控制等核心能力，大幅降低了开发门槛。

该库已预装于 Vision Kit 系统镜像中，**请务必确认镜像为最新版本**。详细接口文档请查阅《API 指南》，以下列出项目高频调用的核心模块：

- `aiy.toneplayer`：压电蜂鸣器简易旋律播放器
- `aiy.trackplayer`：压电蜂鸣器基于追踪器的音乐播放器
- `aiy.vision.annotator`：树莓派摄像头预览画面标注绘制库
- `aiy.vision.inference`：树莓派与 Vision Bonnet 间推理连接引擎
- `aiy.vision.models`：面向图像分类与目标检测的模型集合
- `aiy.board`：Vision Bonnet 按键接口控制 API
- `aiy.leds`：按键灯、隐私指示灯等专用 LED 控制接口
- `aiy.pins`：Bonnet 扩展 GPIO 引脚定义库，配合 `gpiozero` 使用

**上手建议**：最快掌握 `aiy` API 的路径是“拿来改”。系统已预置多个示例程序，存放于 `~/AIY-projects-python/src/examples/` 目录，GitHub 仓库亦可在线浏览完整源码。

**MobileNet SSD 专项提示**：此类模型（如 `mobilenet_ssd_256res_0.125_person_cat_dog.pb`）包含**预处理、推理、后处理**三段。编译器只需推理段的输入/输出节点。模型中节点名前缀区分明显：
- `Preprocessor/*` → 预处理
- `FeatureExtractor/*` → **推理（重点）**
- `Postprocessor/*` → 后处理
因此输入/输出张量名**不会**出现在模型头尾节点，请在 `FeatureExtractor` 作用域内寻找。

##### 4. 模型结构硬性约束

| 维度 | 要求 |
| :--- | :--- |
| **输入图像** | 正方形 RGB，边长为 **8 的倍数**；<br>注：Bonnet 会自动等比缩放，推理时可喂入更大图像，且边长无需为 8 倍数 |
| **首层算子** | 必须为 `tf.nn.conv2d` |
| **数据格式** | 训练与推理均遵循 **NHWC** 布局 |
| **拓扑结构** | **非循环** 图 |
| **Batch Size** | 推理阶段固定为 **1** |

##### 5. 支持的 TF 算子与参数约束清单

仅下列算子经编译器处理后可在 Bonnet 高效运行，部分算子对输入/参数有额外限制：

*   **tf.nn.conv2d** [PRE6]
    *   输入通道数须能被 8 整除（首层除外） [PRE7]
    *   卷积核：`[k, k, in_ch, out_ch]`，`k ∈ {1,2,3,4,5}` [PRE8]
    *   步长：`[1, s, s, 1]`，`s ∈ {1, 2}` [PRE9]
    *   Padding：`VALID` 或 `SAME` [PRE10]
    *   Data Format：`NHWC`

*   **tf.nn.depthwise_conv2d** [PRE11]
    *   卷积核：`[k, k, in_ch, ch_mul]`，`k ∈ {3,5}`，`ch_mul = 1` [PRE12]
    *   步长：`[1, s, s, 1]`，`s ∈ {1, 2}` [PRE13]
    *   Padding：`VALID` 或 `SAME` [PRE14]
    *   Data Format：`NHWC`

*   **tf.nn.max_pool** [PRE15]
    *   输入通道数须能被 8 整除 [PRE16]
    *   池化窗口：`[1, k, k, 1]`，`k ∈ {2,3,4,5,6,7}` [PRE17]
    *   步长：`[1, s, s, 1]`，`s ≤ k` [PRE18]
    *   Padding：`VALID` 或 `SAME` [PRE19]
    *   Data Format：`NHWC`

*   **tf.nn.avg_pool** [PRE20]
    *   池化窗口：`[1, k, k, 1]`，`k ∈ {2,3,4,5,6,7}` [PRE21]
    *   步长：`[1, s, s, 1]`，`s ≤ k` [PRE22]
    *   Padding：`VALID` 或 `SAME` [PRE23]
    *   Data Format：`NHWC`

*   **tf.matmul** [PRE24]
    *   设矩阵 `a` 为 M×K，`b` 为 K×N，**K 必须为 8 的倍数** [PRE25]
    *   `a`：秩 1 或 2 张量 [PRE26]
    *   `b`：秩 1 或 2 张量 [PRE27]
    *   `transpose_a: False` [PRE28]
    *   `transpose_b: False` [PRE29]
    *   `adjoint_a: False` [PRE30]
    *   `adjoint_b: False` [PRE31]
    *   `a_is_sparse: False` [PRE32]
