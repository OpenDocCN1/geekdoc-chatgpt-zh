### 10.2.1 本地化搭建七步法

下面给出可落地的完整路径。

#### 1．明确目标与业务画像

#### 2．技术架构设计
硬件侧关注机型 CPU 多核并行能力、是否需要 GPU 训练、存储选型 SSD/HDD 并配合 RAID。网络侧要保证内网带宽充足和防火墙策略合理，确保内部系统安全访问。
软件侧，操作系统常用 Linux CentOS Ubuntu 或 Windows Server；检索存储常用 Elasticsearch Solr 负责文本检索，Neo4j 负责图谱构建；框架可参考 Haystack LangChain 等开源方案，按需选择开源或商业产品。

#### 3．数据准备与处理
分为三步。采集从 CRM ERP 等内部系统、外部手册论文、API 接口获取；清洗标注需去除重复纠错统一格式，对身份证手机号等敏感字段做脱敏，并对人名机构名术语等关键实体进行标注，为图谱构建奠基；建模则按业务线功能模块建立分类体系，并构建症状疾病治疗方案等关联关系。

#### 4．框架部署与模型训练
以开源为例，先部署 Elasticsearch 集群并配置 IK 分词器，再部署 Haystack 搭建检索加生成的流水线：用户提问→召回相关文档→大模型生成回答。
若需要专属问答能力，可用本地数据微调 LLaMA ChatGLM 等模型，同时优化 BM25 或向量检索等算法，提升匹配精度。

#### 5．系统集成与测试
通过 REST API 或 SDK 将知识库接入客服机器人、内部搜索平台等业务系统。测试需覆盖功能准确率、问答正确性、性能高并发下的响应时间与吞吐量，以及渗透测试、传输加密等安全项。

#### 6．部署与上线
先在测试环境试运行收集反馈，再逐步推广到生产环境。数据迁移建议采用增量同步，避免业务中断。上线时配置管理员普通用户等角色权限，并记录访问日志以便追溯合规。

#### 7．运维与迭代
