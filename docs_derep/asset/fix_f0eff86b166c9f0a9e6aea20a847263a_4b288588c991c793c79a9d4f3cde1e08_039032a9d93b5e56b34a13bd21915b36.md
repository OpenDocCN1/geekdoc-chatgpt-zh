公司想停下来，很多人第一反应是直接走注销手续，但如果账面上还背着债，硬做行政撤并很容易留下法律风险。实际上企业关门只有两条正道：一条是走行政渠道体面退出，一条是走司法渠道依法了结。两套路径的触发条件、成本、时长和对个人的影响完全不一样。

**行政注销与司法破产的本质分叉**

很多人会忽略资料保存这件事。从成立清算团队到完成登记注销，整个流程产生的所有文件都要系统留存，日后查询、维权或被追溯时都是关键证据。

司法破产针对的是经营长期亏损、资产已覆盖不了到期债务、靠自行清算也无法清偿的经营主体。破产是法院主导的法定程序，核心是把剩余财产在债权人之间公平分配，同时依法免除债务人部分法定义务。

是否能进入破产程序，要看《中华人民共和国企业破产法》第二条的标准：

> 第二条 企业法人不能清偿到期债务，并且资产不足以清偿全部债务或者明显缺乏清偿能力的，依照本法规定清理债务。

企业法人有前款规定情形，或者有明显丧失清偿能力可能的，可以依照本法规定进行重整。

破产申请分债权人提起和债务人自愿两类。债务人主动申请的典型流程是：先准备破产申请书、资产负债表、财务状况说明书、债权债务清单等材料；向企业住所地法院递交申请，法院审查后决定是否立案受理；立案后法院指定管理人接管，负责财产清算和债务清偿；召开债权人会议，审议财产分配方案；法院依据清算结果作出破产终结裁定，企业正式退出市场。

行政注销和司法破产都是让企业消失的方式，但在适用前提和操作难度上差异很大。

**行政注销与司法破产对照**

| 维度 | 行政注销 | 司法破产 |
| :--- | :--- | :--- |
| 适用场景 | 主体没有未结清债务或债务已全部清零 | 负债大于资产，无法偿付到期债务 |
| 办理复杂度 | 流程繁琐，需依次办结税务、工商等多个环节 | 必须法院介入，涉及多方债权人协调 |
| 耗时 | 通常2到6个月 | 往往要1年以上 |
| 花费 | 相对低，主要是公告费、代办服务费等 | 相对高，包含律师费、管理人报酬等 |
| 长远影响 | 影响有限，法定代表人可重新注册新主体 | 对法人信用影响较大，短期内创业受限 |

没有严重债务纠纷时，行政注销更直接；一旦陷入严重财务困境，就应考虑司法破产。无论选哪条路，都必须对资产和负债做彻底清算，遗漏关键事项都可能引发法律纠纷。

**企业不想继续运营，行政注销完整操作顺序**

关停企业不是一句口号，涉及法律合规、税务清算和财务处理。一人有限责任企业的注销可以按以下顺序推进：

1. 成立清算团队并启动清算。注销前必须对企业资产、负债进行全面盘点，保证债权债务得到妥善处理。一人企业可由法定代表人自行担任清算团队负责人，主持财产核实和债务清偿。

2. 编制清算报告。清算结束后要出具清算报告，清晰列明资产状况、负债情况以及剩余财产分配结果。

3. 发表注销公告。清算完毕通常需在指定报纸发布注销公告，提醒债权人申报债权。公告期一般为45天，期间债权人可提出异议或要求清偿。

4. 办理税务注销。先到税务机关结清税款，核实是否还有增值税、企业所得税等未缴税款；再提交清算报告、营业执照复印件等材料，办理税务登记注销。

5. 归还票据与设备。把剩余空白发票、税控盘等交回税务局。

6. 办理工商注销。税务注销完成后，向市场监管部门递交注销申请表、清算报告、税务注销证明、登报公告等，审核通过后收回营业执照正副本，完成登记注销。

7. 销户对公账户。携带注销证明、公章、法人身份证到开户行销户，账户余额必须清零，否则无法销户。

8. 注销社保公积金。如曾开设社保、住房公积金账户，需分别到社保局提交注销申请终止账户，到公积金管理中心办理账户关闭。

9. 印章销毁。注销完成后，将公章、财务章等交公安机关备案并销毁。

10. 归档备查。将注销过程中形成的全部文件整理保存，以备日后查阅。

**一人企业税制选择：核定征管与查账征管**

对个体创业者而言，征管方式决定每月税负，也影响经营策略和利润空间。

核定征管是由税务机关依据行业类型、规模和经营情况，直接核定应纳税所得额或税率，企业按核定标准缴税。操作简便，适合收入波动大、账目不健全的小微企业和个体户，如早餐店、小电商、个人工作室。

核定征管分两种做法。定额征管是按月固定缴税，税务机关根据行业、经营地点、从业人数等因素核定一个固定金额，无论当月有无收入都要缴纳。适合业务不稳定、初创期企业，预算明确、票据要求低，但无收入时仍要缴税，负担较重。

定率征管是按比例计税，税务机关先核定行业利润率，再以实际开票金额为基数计税。比定额更灵活，会参考实际营收。举例来说，核定利润率10%、适用税率5%，开票10万元，则应纳税所得额1万元，税款500元。适合已有稳定收入但财务能力有限的经营者。

申请核定征管目前多可在线办理。登录地方电子税务局，进入税种认定或征管方式申请模块，填写企业所得税征管方式鉴定表，必要时上传营业执照、法人身份证明。提交后通常3到5个工作日反馈结果，部分地区需现场确认。审核通过后可在系统内查看核定方式、利润率和税率等信息。

查账征管是按企业真实财务报表计税。需建立完整账簿，记录每一笔收支，由税务机关据此核定应纳税所得额，更贴近真实经营，适用于业务量较大、财务规范的企业。

建账基础是3本账册加一套软件：总账用于科目汇总，明细账用于按科目详细记录，银行存款日记账用于逐笔收支登记，软件可用Excel等。

计税公式为：应纳税额＝（年收入－成本－费用－免税收入）×税率－减免税额。例：年收入200万，成本120万，费用30万，小微优惠税率5%，应纳税所得额50万，所得税2.5万。

报税节奏：每月登录电子税务局申报增值税，小规模按季、一般纳税人按月；同时用财务软件生成利润表、资产负债表上传。每个季度申报企业所得税预缴，按实际利润预缴，年终汇算清缴。每年5月31日前完成企业所得税汇算清缴，6月30日前完成工商年报公示。

**两种征管方式对比**

| 项目 | 核定征管 | 查账征管 |
| :--- | :--- | :--- |
| 适用对象 | 个体户、小规模纳税人、财务不健全企业 | 一人有限公司、一般纳税人、财务规范企业 |
| 计税方法 | 开票金额×核定利润率×税率 | （收入－成本－费用）×税率 |
| 账务要求 | 无需完整账本，可简易记账 | 必须有完整账册、发票及凭证 |
| 税务风险 | 较低，按税务机关核定标准缴纳 | 较高，账目不规范易被稽查 |
| 税负水平 | 通常较低，核定利润率可能低于实际 | 浮动，利润高税负高，利润低税负低 |

选择建议可从五方面判断。业务规模上，年收入500万以下且无专职会计，可优先核定征管；年收入500万以上、需开具专票，则必须查账征管。成本发票上，进项发票齐全时查账征管可抵扣成本更划算；成本多为无票人工时，核定征管更省心。发展规划上，计划融资或上市必须查账征管，规范财务是前提；只做小本生意核定征管更轻。行业特性上，服务业如咨询设计多用核定征管，商贸业如零售批发多用查账征管。政策风险上，核定征管属于地方政策红利，部分地区可能收紧，决策前需确认当地最新政策；查账征管是主流方式，政策稳定但对账务要求严格。

税务没有绝对的好与坏，关键是匹配企业所处阶段和发展目标。选对征管方式，才能在合规前提下降低成本、走得更远。
