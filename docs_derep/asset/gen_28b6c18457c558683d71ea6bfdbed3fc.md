本节拆解的案例核心就是一类用在入侵检测上的 AI 异常检测模型。这类安全模型能先把高风险日志筛出来，极大减轻安全分析师的手工审查负担。研究里发现一个很致命的点：只要往训练数据里掺进极少量、语义上完全合理的系统日志样本，就足以把整套检测能力击穿。更麻烦的是，对系统构建者来说，揪出哪些样本被投毒难度极高，投毒数据和正常日志几乎长得一模一样。

# 3.5.2 RNN 异常检测系统

传统入侵检测里的异常检测大多走统计路线，靠对一段时间活动特征做统计来判断偏离。这一类方法既怕不同站点行为差异带来的误报，也容易被攻击者通过控制单位时间内操作频率而绕过去。

RNN 在处理序列任务上是强项，特别是在自然语言处理里表现突出。把系统日志当成词序列来看，语言模型理论上完全可以接得上。Aaron Tuor 的研究就证实，RNN 在异常检测上的效果远超传统统计方法。

本节先讲清楚 RNN 异常检测的原理，包括无监督异常检测的基本思路，以及一个可落地的 RNN 检测模型怎么搭。

海量且无标注的日增日志注定不适合监督学习，这类场景普遍采用无监督异常检测。思路如算法1所示：模型每天用当天日志学习，尝试预测次日的行为并给出评估。因为异常事件占比极低，这种方式能较好地学会用户的常态，偏离预测越远的行为得到的异常分数就越高。

> ① TUOR A R, BAERWOLF R, KNOWLES N, et al. Recurrent neural network language models for open vocabulary event-level cyber anomaly detection[C]//Workshops at the Thirty-Second AAAI Conference on Artificial Intelligence. 2018.

# 算法1：学习用户正常行为的基本算法

输入：数据集 D ，检测模型 M ，总天数 DAY  
输出：用户事件的异常分数集合 S  
1: 随机初始化模型权重  
2: for i=0 to DAY do  
3:  if i=0 then  
4:  以第 i 天所有日志行损失最小化为目标更新模型，得到模型 Mi  
5:  end if  
6:  if i ≠ 0 then  
7:  用模型 Mi−1 为第 i 天所有事件生成日志行异常分数 si  
8:  将各用户事件的 si 合并排序得到集合 Si ，交由分析人员检查  
9:  用第 i 天日志行损失最小化更新权重，生成模型 Mi  
10: end if  
11: end for  
12: 合并每日 Si 为 S  
13: return S

以 LSTM 为例，模型接收一个词序列作为输入，输出下一个词的概率分布。交叉熵既作为反向传播的损失，也作为训练目标，同时被直接用作异常分数。因为损失本质上衡量模型预测分布与真实序列的差距，偏离越大损失越高，异常可能性越大。

# 2. 特征提取及离散型对抗样本定义

对抗样本投毒的优势在于隐蔽性高且效率更好。在连续数据里常通过肉眼不可见的微小扰动生成对抗样本；离散数据里更关注扰动位置而非数值大小。

为了保证隐蔽性，本实验要求生成的系统日志语义正确。生成粒度限定在单词级。

预处理先把日志切成词序列，统计所有出现过的词构建共享词表，用词表索引把日志转成特征向量。词表外统一用 <OOV> 表示未知词或低频词，例如未在训练集出现的 IP 全部映射为 <OOV>。<OOV> 让模型能处理未见词汇，同时把低频词替换成 <OOV> 保证非零概率。可通过滑动窗口定期更新词表，本章假设训练集固定，词表也固定。处理后的向量以 <sos> 开头、<eos> 结尾。

# 3．投毒数据生成算法

最朴素的做法是随机挑特征替换后插入训练集，称为随机替换策略，但效率低、效果有限。

理论研究普遍认为扰动方向比幅度更关键，这一结论在连续数据上已得到验证。本实验尝试在离散数据上验证类似现象。对神经网络而言梯度方向意义重大，沿梯度方向做特征替换更容易高效生成对抗样本，这也是把连续对抗生成方法迁移到离散场景的依据。

对投毒而言，沿聚类中心指向目标样本的方向生成的对抗样本最容易牵动决策边界偏移。因此基于梯度信息的优化攻击效率更高。本文只需求部分梯度下降最快的位点，于是改造了经典的对抗生成算法，快速直接。

参考 FGSM，本节提出一种基于快速梯度下降法的离散型对抗样本生成算法，见算法2，用损失函数对输入的梯度作为策略选择的辅助信息。

该方法对样本 x 的梯度下降速度排序，取下降最快的前 r 个特征作为替换范围，r 的经验上限不超过向量长度的 30%。与原始 FGSM 相比，改进版针对离散特性做了适配：先对梯度排序，再对最快的 r 个特征做特征替换生成对抗样本。算法 2 中 SELECT 函数依据梯度信息选取替换值并生成对抗样本。

算法 2：基于快速梯度下降法的离散型对抗样本生成
输入：数据集 D、检测模型 M、红队事件集 X、循环上限 L、特征替换位置上限 k  
输出：中毒数据集 D'  
1: 根据 D 构造特征替换集合 V  
2: 用 D 训练检测模型 M  
3: 用 M 测试 X 并收集梯度信息  
4: for i = 0 to X 长度 do  
5:  x = X[i]  
6:  for j = 0 to L do  
7:   x' = SELECT(x,k,∇J(x),V)，其中 ∇J(·) 为 x 的梯度信息  
8:   把 x' 插入 D 得到 D'  
9:  end for  
10: end for  
11: return D'
