存储芯片选型与使用原则

选型时要综合看存储对象是什么、需要多大容量、读写速度要求多高、内部结构怎样以及成本是否可接受。SRAM 访问快、与 CPU 接口简单，在工业控制、智能仪表等中小型系统里应用很广。DRAM 集成度高、价格低、容量大，但与微处理器的接口设计较复杂，多用于对海量存储有需求的微型计算机。ROM 是非易失的，常用来固化不需在线改动的参数。掩膜 ROM 和 PROM 适合大批量量产的微机产品，而在研制和少量生产阶段，改动不频繁的图形、表格、控制或显示参数更倾向用 EPROM 或 EEPROM。Flash 能长期保存数据，还支持在线快速擦写重写，兼具 EEPROM 的非易失性和 SRAM 的读写特性，是替代 EPROM/EEPROM 的理想选择。

总线驱动能力补充

总线驱动能力也是存储器空间设计里必须考虑的因素。CPU 总线一般只能驱动数个 TTL 门的负载。虽然现代存储器多为直流负载很小的 CMOS 或 CHMOS 电路，但分布电容不可忽视，所以驱动问题仍需重视。小型系统里 CPU 可直接挂存储芯片；当总线负载变大时，就要加装总线驱动器。

单向传输的地址或控制信号，可用三态锁存器如 74LS373、Intel8282/8283，或三态单向驱动器如 74LS244、74LS367 来提升 CPU 带载能力。
双向传输的数据总线，则常用三态双向驱动器如 74LS245 来驱动。

时序配合关键点

CPU 访问存储器都遵循固定时序，这就决定了存储芯片的存取速度要求。选型时必须让芯片的存取速度与 CPU 速度匹配，这是系统可靠高效运行的核心。最好选用与 CPU 时序对得上的器件，才能兼顾扩展性和速度。

若芯片速度不达标，就要考虑更换器件或在存储器访问周期中插入等待状态 Tw。若选用的存储器偏慢，在规定的读/写周期内无法完成操作，可在正常周期外再插入一个或多个等待周期 Tw，通过拉长指令时钟周期来降低系统速度，以匹配慢速存储器。

存储容量扩展方式

单片容量有限，系统需求往往需要多片配合，这就是存储器扩展。常见做法分位扩展、字扩展和字位全扩展，以下以 SRAM 为例说明，ROM 类方法类似。

位扩展
当单片字长不够系统要求时，需要用多片并联扩位。芯片数量增加，但存储单元总数仍与单片相同。连线方式为各芯片数据线并到系统数据总线，地址线全部并到系统地址线，片选端并联到同一控制线。例如用 8K×8 的 SRAM 6264 组成 8K×16 组，需要 2 片。内存条就是典型的位扩展，把 8 个 512M×1 位芯片集成到一个 PCB 上，就得到 512MB 的条。

字扩展
当单片字长够用但单元数不足时，用多片拼单元数。数据线对应位并联到系统总线。地址线分为低位和高位，低位直接并到各芯片地址线，高位经译码器产生片选信号。例如系统已有 512MB，想扩到 1GB，只需再加 1 根内存条，共 2 根，完成地址单元的扩充。

字位全扩展
当字数和位数都不够时，把位扩展和字扩展结合。先算出所需芯片数，然后先进行位扩展把多片拼成一个逻辑芯片组，再按字扩展规则对芯片组进行单元数扩充。

存储器与 CPU 的连接

容量扩充时要解决 CPU 三总线与存储器的正确连接和时序匹配。数据总线和控制总线的连接相对简单；地址总线的连接本质是地址分配与译码。高位地址用于译码选片，低位地址用于片内寻址。划分依据是芯片的字数和总容量。例如用 4K×8 芯片构成 16K×8 系统，片内地址约 12 位用于选 4K 单元，片外约 2 位用于选 4 片。

8086 拥有 20 位地址线，其中低 16 位 A15-AD0 与数据总线复用，高 4 位与状态总线复用。连接存储器时需外部地址锁存器，由 ALE 锁存 AD19-AD16 及 AD15-AD0，形成系统地址总线 A19-A0。

全译码方案
地址总线中未用于片内译码的高位全部参与译码，译码输出作为各芯片片选。以 4 片 SRAM 0#~3# 为例，如图实现 32K×8 存储器，地址范围 00000H~07FFFH，仅占 8086 1MB 空间的低 32KB。全译码的优点是各片地址唯一、连续、无重叠，空间利用率最高。

高速缓存技术

CPU 访问低速存储器会降低效率，直接用高速存储器成本又高。现代系统普遍采用 Cache 技术，在速率与成本间折中。Cache 利用程序局部性原理，把近期集中访问的代码和数据从主存调入 Cache，便于重复访问。

Cache 通常与 CPU 同材质制成，速度比主存高约 5 倍，容量一般几 KB 到几十 KB，位于 CPU 与主存之间，CPU 同时与 Cache 和主存保持通路。硬件实现速度快，能让系统兼具 Cache 的速度和主存的容量。Cache 可多级，单级即可让存取速度提升 4~10 倍。

当前 PC 多为 L1 和 L2 两级。L1 集成在处理器芯片内，以处理器时钟全速运行。L2 容量更大，几百 KB 到几 MB。早期 Pentium 的 L2 在主板上随主板时钟运行，Pentium II 为处理器时钟一半，Pentium III 后期可全速运行，Pentium IV 的 L2 已集成进芯片，可占芯片体积一半。

微机板上 Cache 基本结构含 Cache 控制器和存储体。控制器含主存地址寄存器 MA、主存-Cache 地址转换机构、置换控制逻辑和 Cache 地址寄存器。CPU 发出地址经 MA 进入转换机构，判断是否命中。命中则转为 Cache 地址访问 Cache；未命中则访问主存并把邻域页装入 Cache。Cache 满时由置换控制部件按硬件实现的置换算法替换旧信息。

命中率是核心指标，定义为命中次数与总访问次数之比。例如命中率 92%，意味着 92% 的总线周期从 Cache 取数，仅 8% 访问主存。一般要求不低于 85%。Cache 容量过小命中率低，过大成本上升而命中率提升不明显。

基本输入输出接口技术

I/O 接口概述

外设种类繁多，CPU 不能直接交互，需接口作桥梁，完成信息中转。早期系统无独立接口，CPU 直接管理外设，效率低且主机控制电路复杂。现代系统在 CPU 与外设间设接口电路，把控制任务交给接口，降低 CPU 负担，提升效率。接口是 CPU 与外界的连接部件，促进了计算机与外设的标准化和系列化。

I/O 信息类型划分

微机通过接口与外设交换信息，主要有数据信息、控制信息、状态信息。

数据信息包括：
数字量，如键盘、数字化仪输入，或显示器、打印机、绘图仪输出，多为二进制或 ASCII 码。
模拟量，如温度、压力、湿度等连续物理量，经传感器和 A/D 转换后变为数字量处理，处理后再经 D/A 转换回模拟量控制对象。
开关量，如开关通断、阀门启闭等双态量，经电平转换后接入计算机，1 位二进制即可表示，8 位或 16 位字长一次可处理多个开关量。

控制信息是 CPU 通过接口发出的命令信号，用于启动、停止或设定外设工作方式。
状态信息是联络信息，CPU 读取外设状态可知其是否准备好数据或是否空闲，从而避免冲突，保证数据交换正确。

I/O 接口主要功能

理论上 CPU 与 I/O 的连接与与存储器类似，实际差异很大。外设形式多样，有机械、电子、机电、磁电、光电等；信息有数字、模拟、开关；传输速度从秒级到数十兆字节每秒相差悬殊；信息格式和电平也不统一。因此接口电路多样且复杂。CPU 与外设接口需完成信号转换、时序配合、状态联络等任务，以实现高效可靠的信息交换。
