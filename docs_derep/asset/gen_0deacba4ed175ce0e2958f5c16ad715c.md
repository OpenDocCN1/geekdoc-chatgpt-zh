## 第 10 章 列表、元组与字典

假设要统计某专业 180 名学生的单科成绩，若沿用之前的知识，得逐个定义变量存储，未免太过繁琐。

Python 提供了**序列**这一核心数据结构来化解此类难题。序列中的每个数据称为**元素**，每个元素自带一个编号——**索引**（从 0 开始递增）。Python 内置序列类型中，最常用的是**列表**和**元组**；此外还有键值对容器**字典**。本章将逐一深入讲解。

### 10.1 列表

#### 10.1.1 核心概念

列表（`List`）是 Python 使用频率最高的数据类型。用方括号 `[]` 即可创建，内部可存放任意类型数据、支持嵌套、元素间用逗号分隔、长度不受限。

**定义语法：**  
`列表名 = [元素1, 元素2, 元素3, ...]`  
元素类型既可统一，也可混合。

#### 10.1.2 元素访问两大方式

访问列表元素主要靠**索引（下标）**定位单个，或**切片（截取）**批量获取。

**(1) 单元素索引访问**  
语法：`列表名[下标]`  
- 正向：0 为首元素，1 为次元素，以此类推。  
- 反向：-1 为末尾，-2 为倒数第二，以此类推。  
- **注意：** 下标越界会报错。

### 10.2 元组

#### 10.2.1 核心特性

元组（`tuple`）与列表相似，但**不可变**（创建后不能增删改）。用圆括号 `()` 定义，元素间逗号分隔、类型任意、支持嵌套。

**定义语法：**  
`元组名 = (元素1, 元素2, 元素3, ...)`

**特别注意：** 单元素元组**必须**加尾随逗号，如 `(x,)`，否则括号视为分组运算符。
