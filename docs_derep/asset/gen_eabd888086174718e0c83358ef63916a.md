# MindIE Service 部署与 TLS 配置实战指南

## 一、TLS 证书类参数说明

业务面 RESTful 接口相关的证书配置：
- tlsCaFile：业务面 RESTful 接口所依赖的 CA 证书清单，该清单由使用者自行准备，安全保管责任完全在用户侧。
- tlsCert：业务面 RESTful 接口使用的服务端证书文件，由用户提供并自行负责安全。
- tlsPk：业务面 RESTful 接口使用的服务端证书私钥文件，由用户提供并自行负责安全，建议采用加密形式存放私钥。
- tlsCrlFiles：业务面 RESTful 接口使用的证书吊销列表文件清单，由用户提供并自行负责安全。

管理面 RESTful 接口相关的证书配置：
- managementTlsCaFile：管理面 RESTful 接口所用的 CA 证书清单，用户自备并自行保障安全。
- managementTlsCert：管理面 RESTful 接口的服务端证书文件，用户自备并自行保障安全。
- managementTlsPk：管理面 RESTful 接口的服务端证书私钥文件，用户自备并自行保障安全，建议使用加密私钥。
- managementTlsCrlFiles：管理面 RESTful 接口的证书吊销列表文件清单，用户自备并自行保障安全。

PD 分离场景下节点间通信的证书配置：
- interCommTlsCaFiles：PD 分离场景中 PD 节点互信所用的 CA 证书清单，用户自备并自行保障安全。
- interCommTlsCert：PD 分离场景中 PD 节点通信的服务端证书文件，用户自备并自行保障安全。
- interCommPk：PD 分离场景中 PD 节点通信的服务端证书私钥文件，用户自备并自行保障安全，建议使用加密私钥。
- interCommTlsCrlFiles：PD 分离场景中 PD 节点通信的证书吊销列表文件清单，用户自备并自行保障安全。

多机场景下主从节点通信的证书配置：
- interNodeTlsCaFiles：多机部署时主从节点间通信所用的 CA 证书清单，用户自备并自行保障安全。
- interNodeTlsCert：多机场景下主从节点通信的服务端证书文件，用户自备并自行保障安全。
- interNodeTlsPk：多机场景下主从节点通信的服务端证书私钥文件，用户自备并自行保障安全，建议使用加密私钥。
- interNodeTlsCrlFiles：多机场景下主从节点通信的证书吊销列表文件清单，用户自备并自行保障安全。

#### 8.3.3 使用场景

MindIE LLM 是华为昇腾推出的面向大语言模型推理的组件，旨在依托昇腾硬件提供高性能的通用大模型推理能力。MindIE LLM 的整体架构如图 8-9 所示。
[PRE8]

图 8-9

LLM Manager：承担状态维护与任务调度，基于调度策略完成用户请求的批处理，统一管理 KV 缓存，并对外提供状态监控接口。
Text Generator：负责模型配置、初始化、加载、自回归推理流程及后处理，向 LLM Manager 提供统一的自回归推理接口，支持并行解码与插件化运行。
Modeling：提供深度定制优化的模块与内置模型，兼容 ATB Models 与 MindFormers 两大框架。内置模块涵盖 Attention、Embedding、ColumnLinear、RowLinear、MLP 等，支持权重在线 Tensor 切分加载。用户也可基于内置模块自行组网构建模型，编译优化后即可在昇腾 NPU 设备上加速推理。
MindIE LLM 适用于对大模型推理性能要求较高的场景，例如自然语言处理、智能客服、文本生成等。其服务化场景如图 8-10 所示。

| 服务化框架 | MindIE LLM 子组件范围 | 能力说明 | 接口示意 | 接口形式 |
| :--- | :--- | :--- | :--- | :--- |
| MindIE Service | LLM Manager+TextGenerator+Modeling | LLM Manager+TextGenerator 提供完整的 CB+PA 自回归推理调度能力 | ITF 0.L1 | C++ API |
| Triton | LLM Manager+TextGenerator+Modeling | LLM Manager+TextGenerator 提供完整的 CB+PA 自回归推理调度能力 | ITF 0.L1 | C++ API |
| TGI | TextGenerator+Modeling | 提供 TextGenerator 前后处理+Modeling 推理能力 | ITF 0.G1 | Python API |
| vLLM | TextGenerator+Modeling | 提供 TextGenerator 前后处理+Modeling 推理能力 | ITF 0.G1 | Python API |
