### 8.4.3 本地数据管理利器 SQLite

#### 1. SQLite 简介

SQLite 是轻量级关系型数据库，无需独立服务器进程，直接嵌入应用。整个数据库存为单个文件，便于复制与迁移。

> 提示 初学者可把 SQLite 视作“文件型数据库”，数据以结构化表格形式保存在一个文件中，应用可方便读写。

#### 2. 应用中的作用

（1）本地存储
- src/database/words.db 即 SQLite 数据库文件。
- 保存单词信息、学习记录、用户进度。

（2）学习数据持久化
- 记录学习历史与记忆进度。
- 存储复习计划。
- 保存统计信息用于可视化。

（3）词库管理
- 存储各类型词库单词，如考试词库、专业词库。
- 可能包含发音、例句、释义。

（4）应用配置
保存用户偏好与系统配置。

#### 3. 优势

项目中通过 DatabaseManager 类处理所有交互。SQLite 优势：

- 性能足够，满足个人应用。
- 零配置，无需服务器或端口。
- 可靠性高，支持事务保证一致性。
- 跨平台，同一文件可在不同系统使用。

### 8.4.4 数据分析助手 Pandas

#### 1. Pandas 简介

Pandas 是 Python 数据分析库，提供 Series 与 DataFrame 两种核心结构，便于处理表格与时间序列数据。

> 提示 可类比为“Python 版的 Excel 高级形态”，帮助应用智能分析学习数据。

#### 2. 应用中的作用

（1）学习数据分析处理

（2）学习曲线生成
- 结合遗忘曲线算法分析历史。
- 处理时间序列，计算最佳复习点。

（3）数据过滤与分组
- 按难度、类别、掌握度筛选单词。
- 按天/周/月分组统计效果。

（4）可视化支撑
- 与 Matplotlib 结合将 DataFrame 转图表。
- 生成进度表、记忆曲线、薄弱点分析。

（5）导入导出
- 支持 Excel/CSV 词表导入导出。
- 处理自定义词库格式转换。

（6）智能学习算法支撑
- 为智能学习计划提供数据基础。
- 基于历史找出重点复习单词。
