电子证照互通互认，上海制度先行

国务院在《关于加快推进电子证照扩大应用领域和全国互通互认的意见》中明确，推开互通互认的首要任务是理顺领导机制、完善配套制度。相关部门要按职责分工，牵头指导本行业本领域电子证照的应用推广，推动全国范围互认，同时强化部门协同和数据共享。

《上海市电子证照管理办法》第5条对角色分工作出具体安排。市政府办公厅承担全市电子证照的综合管理职责，统筹规划、协调推进、指导监督全市电子证照的管理与应用。市大数据中心负责市电子证照库的建设运营、证照数据共享、接入服务以及安全体系建设。各市级部门要统筹本系统内公共管理和服务机构，依据国家和本市规范开展电子证照的制发、归集、更新、注销和应用。各区政府则负责本行政区域的统筹规划、协调推进和指导监督，推动区域内公共管理服务机构按统一标准规范制发、归集、更新、注销和应用电子证照。

证照管理要先立清单、后规范运行。根据《上海市电子证照管理办法》第7、8条，发证单位在职责范围内要编制本系统本行业本行政区域的电子证照发证目录，明确证照名称、发证单位、持证主体类型、归集起算时间、公开属性、标准层级、证照模板与照面信息，并持续同步更新维护。市大数据中心汇总各单位目录形成全市发证清单，按类目公开属性在“一网通办”总门户向社会公布。发证单位会同市大数据中心依国家和本市标准规范制发电子证照，并同步归集至市电子证照库，确保入库数据与业务系统保持一致。原则上电子证照应与实体证照同步制发更新，但法律法规另有规定或技术上无法同步的除外；无法同步的，发证单位须确保每日将当日增量数据归集入库。

标准化是数字认证体系高效运行的底座。国务院意见要求建设电子证照互联互通时同步建立发证、用证清单并纳入全国一体化政务服务平台动态管理。用证清单通过将政务服务、执法监管等事项所需材料与对应电子证照建立映射关系，提升场景应用便捷度。根据《上海市电子证照管理办法》第13、15条，各用证单位应依政务服务事项清单及办事指南，按精准必要原则建立本单位用证清单并动态管控，确保适用范围合法合规合理。纳入清单管理的应用场景须按清单要求完成技术对接并规范使用；其他政务场景确需调用电子证照的，应通过市大数据资源平台申请调阅，按公共数据共享要求执行。

安全监管是电子证照体系稳定运行的保障。国务院意见要求覆盖签发、归集、存储、使用全流程的安全管理，落实网络安全等级保护，强化密码应用安全性评估，探索区块链、新兴密码、隐私计算等技术提升安全防护、追踪溯源和精准授权能力，并遵循最小采集原则归集数据，对共享证照实施分类分级管理。《上海市电子证照管理办法》第27条明确了安全责任主体：综合管理部门负责建立全市电子证照安全管理制度，指导落实各方安全管理责任；市大数据中心负责建设市电子证照库安全保障体系，制定安全管理要求，实施备份与等级保护，建立应急预案和灾难恢复机制，保障库安全运行；发证单位、用证单位及社会化用证主体须严格执行库的安全管理要求，加强本单位系统和证照数据安全，确保电子证照合法合规使用，保护持证主体的商业秘密和个人隐私。

## 三、建设互联互通的证照跨区域协同机制

跨区域政务协同离不开数据供给支撑。部门协同数据资源具有巨大社会价值，既可服务内部行业使用，也可对外提供数据服务，支撑政府数据开放、“互联网+”政务服务、新型公共服务和大数据应用等。“五证合一、一照一码”就是典型的协同减负案例。从外部服务形态看，“五证合一”将五类证照数据汇聚到统一证件，通过统一数据承载平台对外提供一体化集合服务；从数据生命周期看，目前办证流程已合一，后续变更、维护、利用及新旧证并轨等环节仍需持续汇集管理，需要建立完整的数据治理体系。^([\[27\]](#txt007.html#footnote_content_txt007_27))这种简证优程的逻辑在《上海市数据条例》关于长三角跨区域数字证照协同的规定中得到深化，在简化流程和手续的基础上，依托数据标准统一和政务数据共享，推动区域间协同认证，实现办事时间和空间的双重节约，体现数字赋能政务、服务民生的价值。

以大数据推动政府业务转型升级，是提升治理能力的关键。上海市早在2016年《上海市大数据发展实施意见》中就提出深化大数据应用、提升治理能力的方向，并制定政府治理大数据工程专项方案，推动大数据与政务服务融合，实现行政审批相关数据融合共享。^([\[28\]](#txt007.html#footnote_content_txt007_28))在长三角一体化国家战略及地方推动下，区域数字认证一体化稳步推进。2020年，长三角一市三省市场监管局签署合作协议，统一应用电子营业执照，以国家政务服务平台为枢纽，推动电子营业执照在跨区域跨部门政务服务平台应用，最终实现市场主体身份在线一次验证、全网通用以及营业执照信息共享复用，方便市场主体办事。^([\[29\]](#txt007.html#footnote_content_txt007_29))中央网信办发布的《“十四五”国家信息化规划》亦强调完善大数据服务提升政务服务支撑能力，打造市场化法治化国际化营商环境，加快建立营商环境诉求受理分级办理“一张网”，加强涉企主动服务。^([\[30\]](#txt007.html#footnote_content_txt007_30))《上海市数据条例》提出建设长三角区域数字认证、电子证照互认互通等跨区域认证机制，既是上海服务管理科学化的体现，也是长三角公共服务均等化普惠化便捷化的体现，更契合“十四五”规划全国一体化政务服务工程推进、部门协同办公能力一体化、跨层级跨部门管理水平提升的总体要求。

## 第七十七条 【长三角区域数据合作】

[PRE1]

本条旨在提出发挥上海在整个长三角区域的数据先行示范区作用，跨区域整合长三角其他省份的数据资源，打破区域数据壁垒，协同融合发展数据产业。同时，强调数据安全与隐私计算对数据融合开发的重要性，并尝试探索相关技术的利用机制。

[PRE2]

数据安全流通技术：数据流通是指以数据为对象，在数据提供方和数据需求方之间按照一定流通规则进行的数据传输行为。数据安全流通技术是指数据在流通过程中采用的安全技术手段，用于保障数据采集、传输、存储、处理、交换和销毁过程与结果的安全。

隐私计算：是指带有隐私机密保护的计算系统与技术（硬件或软件解决方案），能够在不泄露原始数据的前提下，对数据进行采集加工、分析处理、分析验证，包括数据的生产、存储、计算、应用等数据处理流程的全过程，强调能够在保证持有数据的组织或个人权益、保护用户隐私和商业秘密的同时，充分挖掘发挥数据价值。^([\[31\]](#txt007.html#footnote_content_txt007_31))

[PRE3]

### 一、区域数据发展合作

想要充分发挥数据在经济社会发展中的创新驱动作用，要有全局数据产业发展的远见。本条力求发挥上海在整个长三角区域的数据先行示范区作用，跨区域整合长三角其他省份的数据资源，协同融合发展数据产业。

国内对于区域数据产业共同发展的规划并不鲜见。以我国粤港澳大湾区为例，《广东省数据要素市场化配置改革行动方案》第 20 条建设粤港澳大湾区大数据中心提出，广东省以支持广州南沙（粤港澳）数据要素合作试验区、珠海横琴粤澳深度合作区建设为核心，探索建立“数据海关”，开展跨境数据流通的审查、评估、监管等工作。支持医疗等科研合作项目数据资源有序跨境流通，为粤港澳联合设立的高校、科研机构向国家争取建立专用科研网络，逐步实现科学研究数据跨境互联。推动粤东西北地区与粤港澳大湾区数据要素高效有序流通共享。^([\[32\]](#txt007.html#footnote_content_txt007_32))但数据流通实践中，各区域、各行业之间由于数据产业发展水平不同，均存在不同程度的数据安全隐患，间接催生了区域数据壁垒，影响数据的流通和融合。对此，本条以技术支撑为基础的机制创新利用区块链和隐私计算等数据安全流通技术，构建跨区域的数据融合开发利用机制，探索打破区域数据壁垒的有效手段和长效机制。

### 二、区块链和隐私计算

跨区域大数据融合开发利用主要有以下三个问题。第一，缺乏有效的监督机构和机制。大数据技术可广泛采集不同区域和来源的数据，对于不同数据的跟踪和状态控制难度大，监督工作复杂。第二，尚未形成较为成熟的数据权益归属制度。数据产业投入巨大，收集困难，但复制和扩散成本却相对低廉，无法确保持有数据的自然人、法人和非法人组织的最终收益。第三，信息泄露与再识别风险高。通过不同来源的数据集交叉合并分析，在获得更多数据信息的同时，也增加了潜在的隐私泄露风险。^([\[33\]](#txt007.html#footnote_content_txt007_33))而聚焦于数据共享开放领域应用的区块链和隐私计算技术，是较好解决现阶段隐私数据保护与跨区域数据流通多方面痛点的手段之一。例如，我国著名计算机科学家姚期智教授提出的多方安全计算技术，通常被应用于政府部门或大型企业对于数据隐私安全要求较高的场景。

数据安全流通技术结合区块链、零知识证明、差分隐私等技术，可解决数据孤岛的隐私、共识、可信难题，满足用户不同的安全性和性能要求。其中，利用区块链实现数据的链上存证核验、计算过程关键数据和环节的上链存证回溯，能够确保数据计算过程的可验证性等，从而解决区块链全流程隐私保护周期困难的问题。^([\[34\]](#txt007.html#footnote_content_txt007_34))

### 三、基于区块链和隐私计算的跨区域数据合作

跨区域数据合作主要基于以下三种技术：一是数据包形式。典型例子为目前主要的数据交易平台，对来自不同区域和主体的数据所有权进行确权和交易。但由于数据确权相关机制尚不成熟，该模式有较高的数据安全风险，较难保护持有数据的组织或个人的利益，易导致涉及用户隐私的信息暴露以及数据被使用方二次利用甚至滥用。二是通过明文数据 API（Application Programming Interface）接口进行数据流通与应用。将加工处理完的单方结果数据以 API 形式输出，具体通过程序对原始数据进行隔离，在用户发出数据使用请求后，由程序从原始数据中抽取、调用数据反馈给用户。该模式能够满足跨区域数据合作对较广的服务覆盖范围的需求，并在一定程度上降低用户隐私信息泄露的风险，但该模式也降低了数据价值融合的充分性。三是隐私计算。该模式能够直接作用于数据使用方面，通过协议或算法使得数据计算服务在不泄漏原始数据的前提下充分挖掘数据价值。^([\[35\]](#txt007.html#footnote_content_txt007_35))以联邦学习为例，基于联邦学习技术构建的跨区域数据合作机制，可以保障数据不出本地、只交换中间模型参数的方式实现多方安全建模，确保在各方数据安全的前提下整合数据资源，共同挖掘数据价值。

隐私计算尽管不能完全解决数据泄露问题，但加上区块链的去中心化以及算法加密等技术为跨区域数据合作机制提供了新的解决方案。究其根本原因在于数据价值的构成不在于数据本身的大小和质量，而是推动多种基于大数据的计算方式及应用。因此，构建跨区域多方数据合作是大数据发挥价值的必经之路。但大数据难控制、复用性强、再识别可能性高的问题，对数据流通提出了挑战。若因噎废食限制数据流通，一方面致使个人信息相关的数据分析挖掘受限，无法充分实现数据价值；另一方面掌握大量数据的互联网龙头企业易形成数据垄断，不利于中小科技企业发展。区块链、隐私计算技术的运用，能够解决数据开放共享和隐私安全保护的矛盾，在保证原始数据安全性，保护个人隐私的同时，实现数据的充分有效利用，有望成为打破大数据现阶段发展瓶颈，跨区域数据协同发展的创新驱动力。^([\[36\]](#txt007.html#footnote_content_txt007_36))
