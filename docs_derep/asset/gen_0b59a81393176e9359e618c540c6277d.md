2024 年注定是人工智能领域的关键节点。随着国内外大模型技术日趋成熟，其已被视为应用开发的基础底座。面向大模型应用的开发者，工具选择至关重要。在众多集成方案中，LangChain 脱颖而出，成为大模型开发领域的集大成者，并逐步走向生产环境。本章将围绕 LangChain 的各模块展开开发讲解。

- 链：把多个 LLM 或组件串联完成复杂任务。

## 8.1 LangChain 初探

### 8.1.1 框架概述

LangChain 是一个面向大语言模型的开源应用框架，最初由 Robust Intelligence 初创团队的开发者 Harrison Chase 在 GitHub 上发布，很快获得社区认可，并在持续演进中成为主流的 LLM 开发框架。它提供了一套工具与组件集合，开发者无需关注底层细节，仅凭少量代码即可运行大模型程序，显著降低进入门槛。

针对大语言模型的开发需求，LangChain 抽象出模型 I/O、数据连接、链、记忆、智能体、回调处理器六大核心模块。借助这些模块的组件与封装，开发者能够快速搭建 LLM 应用。

（1）模型 I/O
用于快速接入各类模型。模型包装器提供统一的大语言模型接口，可适配市面上绝大多数模型；提示词模板支持动态模板化管理输入；输出解析器允许指定任意格式的输出。

（2）数据连接
提供数据加载、转换、存储与检索能力，方便使用自有数据。

（3）链
单一模型可完成大部分简单任务，面对复杂场景时，链可以将多个模型包装器或其他组件串联起来完成复合任务。

（4）记忆
大语言模型本身不具备记忆能力。LangChain 提供读写等工具，帮助系统添加记忆功能。运行时先从记忆模块读取历史，再执行业务逻辑，最后将本次输入输出写入记忆，供后续调用。

（5）智能体
Agent 将强大的大语言模型与提示词作为推理引擎，并择优调用工具以决定下一步任务及其执行顺序。

（6）回调处理器
LangChain 提供多种回调处理器，通过在 API 中设置 callbacks 参数，可实现日志记录、监控与流式处理等功能。

### 8.1.2 生态与安装

#### 1. 生态全景

LangChain 作为面向大语言模型应用的框架，将 LLM 应用的开发周期抽象为开发、生产化、部署三个阶段，并为各阶段提供开源库。

- langchain-core：包含基础抽象与 LangChain 表达式。
- langchain-community：提供第三方集成，如 langchain-openai、langchain-anthropic 等，部分功能已拆分为仅依赖 langchain-core 的轻量包。
- langchain：构成认知架构的链、代理与检索策略。
- langgraph：把步骤建模为图中的节点与边，用 LLM 构建具备状态且多角色的复杂应用。
- langserve：将 LangChain 链部署为 REST API，供应用调用。
- langsmith：面向开发者的平台，用于调试、测试、评估与监控 LLM 应用，并可与 LangChain 无缝集成。
