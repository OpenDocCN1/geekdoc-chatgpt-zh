# GPT-3 架构与涌现能力拆解

**1）分词输入。** GPT-3 使用可逆的 Byte Pair Encoding 分词方式，将词汇表中高频词组合打包成新单元，从而压缩词表规模并保持解码可还原。

**2）嵌入转换。** 嵌入层负责把离散的 token 映射为连续的向量空间表示，为后续计算提供稠密特征。

**3）位置注入。** 通过位置编码为词向量叠加顺序信息，让模型区分不同位置的词，捕捉序列上下文。

**4）Transformer 堆叠。** 模型主体由多层 Transformer 编码器构成。每层包含两大子模块：稀疏注意力子模块与前馈神经网络子模块。稀疏注意力采用密集与局部带状稀疏交替的模式，前馈网络则是全连接结构，用于提取更高层次的特征表征。

**5）层归一化。** 在每层 Transformer 的输入与输出端均加入层归一化，对信号进行标准化，有助于缓解梯度消失与爆炸，提升训练稳定性与收敛速度。

**6）输出预测。** 输出层把 Transformer 的结果转化为下一个 token 的概率分布。先经线性层得到 logits，再用 softmax 归一化为概率，最后选取概率最高 token 作为预测。

总体来看，GPT-3 延续了 GPT-2 的设计思路，核心差异在于引入了稀疏注意力机制，并在规模与训练数据上大幅扩展，从而带来性能提升。

## 5.2 稀疏注意力模式
Sparse Transformer 是面向长序列优化的改进思路，通过稀疏注意力降低计算量与内存占用，实现长文本的高效处理。

### 5.2.1 Sparse Transformer 的特点
传统 Transformer 处理长序列时，自注意力为全连接，输入长度为 n 时计算与内存需求为 O(n²)，对超长序列不可接受。Sparse Transformer 不计算全部元素对的注意力分数以实现稀疏化，主要做法是限定注意力作用范围设置窗口，或设计特定稀疏连接模式，将复杂度与内存降至 O(n) 级别。

（1）稀疏注意力模式
如图 5.2 所示，Sparse Transformer 的核心是稀疏注意力。每个 token 只关注部分上下文而非全部，将复杂度从 O(n²) 降至 O(n)。实现方式多样，如局部带状注意力、稀疏全连接注意力等。GPT-3 采用局部带状模式聚焦相对邻近 token，稀疏全连接则在全序列上按固定步长采样。

（2）交替密集与稀疏注意力模式
为兼顾性能与泛化，GPT-3 在不同层交替使用密集与稀疏注意力。既保持计算效率，又能更好捕捉长程依赖。具体比例可根据任务需求与资源限制灵活调整。

（3）可学习相对位置编码
GPT-3 采用可学习的相对位置编码，同时刻画 token 的绝对距离与相对距离，增强长程依赖的捕捉能力。

### 5.2.2 局部带状注意力
局部带状注意力是 GPT-3 的稀疏变体，目标是缓解计算与内存压力。每个 token 仅关注邻近部分 token。

1）确定窗口大小。窗口大小定义每个 token 可见的上下文范围，可按任务与资源调整。窗口越大上下文越丰富，计算成本也越高。
2）构建注意力矩阵。为序列中每个 token 生成窗口大小的一维注意力向量，仅计算窗口内 token 的权重，计算方式与传统自注意力一致。把所有向量堆叠形成二维注意力矩阵。
3）计算局部输出。用该二维矩阵乘输入序列的隐藏状态，得到只关注邻近位置的上下文输出。

局部带状注意力的优势是复杂度从 O(n²) 降到 O(n × window size)，在保持效率的同时保留局部信息。不足是难以捕捉远距离依赖，可与其他稀疏模式结合，或在层间交替使用密集与稀疏模式来弥补。

### 5.2.3 跨层稀疏连接
跨层稀疏连接旨在帮助相邻层建立更长的依赖。GPT-3 通过提高注意力效率处理更长输入。

跨层连接方式包括：
1）局部带状稀疏连接。每个 token 仅关注前后邻近部分 token，捕捉小窗口内的局部依赖。
2）密集连接。每个 token 可关注序列中所有其他 token，捕捉全局依赖。

在各层交替使用这两种连接，GPT-3 能兼顾多尺度依赖。局部连接负责短距离依赖，密集连接跨越更长距离。设计在提升长序列效率的同时保持长程建模能力，降低资源需求。

## 5.3 元学习与内容型学习
面对 1750 亿参数规模，全量微调已不现实。GPT-3 的主要策略是元学习与内容型学习。

元学习指在大规模文本上预训练，掌握自然语言生成能力与广泛知识与理解能力。预训练阶段模型学习词汇、短语、句子、段落的语法结构与基础常识。

内容型学习指在少量带标签数据上调整模型以适配特定任务。微调不进行全面重训，而是把预训练的泛化能力迁移到目标任务。数据可以是问答对或带情感标签的句子，少量标签即可在多任务上取得高表现。

### 5.3.1 元学习
传统元学习指用少量标签快速学习新任务。GPT-3 论文将元学习的定义扩展到无监督预训练阶段。

在此视角下，大语言模型可视作元学习器，预训练即学会大量知识与语言理解。通过海量无标注文本预训练，模型掌握语言结构与常识，具备泛化能力。这种泛化源于无监督预训练而非专门的元训练过程，与传统元学习在效果上相似。

### 5.3.2 内容型学习
为避免微调阶段改动参数，GPT-3 强调内容型学习。任务适配采用零样本、单样本、少样本策略，摆脱传统微调限制。

如图 5.3 右侧所示，微调在预训练后启动。每个任务提供少量训练样本，如批量大小为 1 的样本，通过计算损失更新权重。与从零开始训练相比，微调数据需求更小、学习率更低，因为初始值已接近解。

图 5.3 左侧展示 GPT-3 如何借助不同示例量的上下文学习在不改动参数的情况下提升新任务性能，大幅降低使用门槛。

零样本学习指模型仅依靠预训练知识，在无任何任务标签数据的情况下解决问题。需理解任务描述并以自然语言生成答案。挑战在于无示例条件下理解要求。

得益于庞大参数与海量预训练，GPT-3 在零样本上表现优异，能捕捉丰富语言结构、语法与常识，直接生成相关输出。

单样本学习指仅给一个相关示例进行推理。模型需从单个示例理解任务并给出答案。挑战是有限信息下快速适应。

在单样本示例中，任务描述后插入一个翻译示例。推理时序列更长，注意力机制提取有用信息。模型不进行梯度更新。

GPT-3 结合预训练知识与单个示例即可在单样本任务上高效表现，降低监督成本。

少样本学习指提供少量标签示例后推理。模型需从多个示例理解任务并预测。挑战是在信息有限时有效学习并提升准确率。GPT-3 处理能力有限，过长序列不利于信息提取，过多示例并非总是更优。

GPT-3 在少样本上同样出色，多示例输入帮助模型更好适配新任务，体现强泛化能力。

与传统微调相比，零/单/少样本无需昂贵监督训练，成本时间大幅降低，且在标签稀缺任务上更易部署，同时避免过拟合。

## 5.4 概念分布的贝叶斯推断
上下文学习是大语言模型的重要涌现能力，理解其原理有助于构建有效提示。如图 5.3 所示，零样本提示含任务描述与内容，单/少样本额外加入示例。

### 5.4.1 隐式微调
可把语言模型解释为元优化器，把上下文学习视为隐式微调，建立与显式微调的联系。如图 5.4 所示，GPT 在前向计算中根据任务相关标签样本生成元梯度，并通过注意力将其施加到任务上。该过程与微调的反向传播更新参数视角相同。

两者在预测、表示、注意力行为层面相似，均采用类梯度下降优化，但上下文学习通过前向产生元梯度，微调通过反向传播计算梯度。

少样本场景下，大模型是否隐式学习映射 y = f(x)？若如此，示例对性能影响应很大。原论文图 5.5 似乎支持此观点，零样本无法修正，单/少样本明显提升。

但另一研究提出新视角：示例中输入-标签映射对性能影响小于预期。把真实标签换成随机标签，或把示例 <x[i], y[i]> 换成随机值，性能损失相对较小，依赖真实映射并不高。

图 5.6 展示 GPT 等模型在不同标签条件下下游任务表现。采用直接推理与通道推理两种方式。直接推理是在给定上下文后比较类别概率；通道推理是在给定类别后比较上下文概率。以情感分析为例，直接推理比较“这部电影真好看 正面”与“这部电影真好看 负面”的概率，通道推理比较“正面 这部电影真好看”与“负面 这部电影真好看”的概率。图中显示，无论分类还是多选，随机标注与正确标注表现相当，均明显优于无示例零样本。

由此可得：
1）示例决定的标签空间与输入文本分布对上下文学习至关重要，而非单个标签是否正确。关键是 x 与 y 的分布，即输入分布与候选答案集合。随机标注中 y[i] 不正确但仍在候选集合内。若改动分布，如把 y 换成候选集外内容，效果会急剧下降。
2）格式指定同样关键。未知标签空间时，用随机英语单词作标签也优于不使用标签。
3）以上下文学习目标进行元训练会放大这些效应，模型更利用示例的简单方面如格式，而非输入-标签映射。

大模型可能并未从示例学习映射 y = f(x)，而更依赖预训练先验。但若把任务学习拓宽为适应示例暗示的输入、标签分布与格式并更准确预测，则可认为模型从示例获取了任务信息。预训练模型已具备内在任务能力，语言建模目标具有强零样本能力。但这也意味着上下文学习难以处理模型未捕捉的输入-标签关联任务。

示例与指令对语言模型作用相似，对指令遵循模型同样适用：指令驱动模型恢复已有能力，而非学习新语义。实验显示，仅将未标记输入与随机标签配对作示例，无需任何标记数据，也能接近少样本性能。这表明先前零样本基线可能被低估，对提升零样本性能有重要启示。
