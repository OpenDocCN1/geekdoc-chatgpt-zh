本小节聚焦的案例是围绕入侵防御场景下的一种人工智能驱动的异常检测方案。这类模型先把风险较高的日志筛选出来，能显著降低安全分析人员的手工判读压力。研究显示，仅需混入极少量语义上完全合理的系统日志记录，就足以让整套检测能力失效。更棘手的是，对构建者而言，难以辨认哪些记录已被污染，因为投毒样本与正常日志在表观上几乎无法区分。

# 3.5.2 RNN 异常检测系统

传统用于入侵检测的异常检测方法多依赖统计特征，对一段时间内活动的统计量进行偏离判断。这类做法容易受站点行为模式差异干扰，也易被攻击者通过调节单位时间操作频次绕过。

递归神经网络在序列建模上具备明显优势，自然语言处理中表现突出。若把系统日志看成词序列，语言模型在理论上能够处理此类数据。Tuor 等人在 2018 年的工作显示，RNN 在异常检测上的效果明显优于传统统计方法。

本小节先说明 RNN 异常检测的思路，涵盖无监督异常检测的基本原理，以及如何搭建一个可落地的 RNN 检测模型。

日增日志规模巨大且缺乏标注，监督学习难以适用，这类场景通常采用无监督异常检测。思路如算法1所示：模型每日利用当天日志进行学习，尝试预测下一天的行为并给出评价值。由于异常事件占比极低，该方式能够较好地刻画用户常态，偏离预测越远的行为获得的异常分越高。

> ① TUOR A R, BAERWOLF R, KNOWLES N, et al. Recurrent neural network language models for open vocabulary event-level cyber anomaly detection[C]//Workshops at the Thirty-Second AAAI Conference on Artificial Intelligence. 2018.

# 算法1：学习用户正常行为的基本算法

输入：数据集合 D，模型 M，累计天数 DAY  
输出：用户事件异常分数集合 S  
1: 随机初始化模型参数  
2: for i=0 to DAY do  
3:  if i=0 then  
4:  以最小化第 i 天全部日志行的损失为目标更新模型，得到模型 Mi  
5:  end if  
6:  if i ≠ 0 then  
7:  用模型 Mi−1 为第 i 天所有事件生成日志行异常分数 si  
8:  将各用户事件的 si 合并排序形成集合 Si，并交由分析人员核查  
9:  以第 i 天日志行损失最小化为目标更新参数，生成模型 Mi  
10: end if  
11: end for  
12: 将每日 Si 合并为 S  
13: return S

以 LSTM 为例，模型以词序列为输入，输出下一个词的概率分布。交叉熵既作为反向传播的损失，也作为训练目标，同时被直接用作异常分。因为损失本质衡量模型预测分布与真实序列的差距，偏离越大损失越高，异常可能性越大。

# 2. 特征提取及离散型对抗样本定义

对抗样本投毒的优势是隐蔽性强且效率更高。连续数据中常通过肉眼不可见的微小扰动生成对抗样本；离散数据更关注扰动位置而非数值大小。

为保证隐蔽性，本实验要求生成的系统日志保持语义正确。生成粒度限定在单词级。

预处理先把日志切分为词序列，统计所有出现过的词构建共享词表，用词表索引将日志转为特征向量。词表外统一用 <OOV> 表示未知词或低频词，例如训练集中未出现的 IP 全部映射为 <OOV>。<OOV> 使模型能处理未见词汇，同时把低频词替换为 <OOV> 保证非零概率。可通过滑动窗口定期更新词表，本章假设训练集固定，词表也固定。处理后的向量以 <sos> 开头、以 <eos> 结尾。

建表时，为每个特征位置单独维护集合 Set，收集该位置出现过的所有取值，这为后续离散对抗样本生成提供便利。整体预处理流程见下图。

# 3．投毒数据生成算法

最朴素做法是随机挑选特征替换后插入训练集，称为随机替换策略，但效率低、效果有限。

理论研究普遍认为扰动方向比幅度更关键，这一结论在连续数据上已获验证。本实验尝试在离散数据上验证类似现象。对神经网络而言梯度方向意义重大，沿梯度方向做特征替换更容易高效生成对抗样本，这也是将连续对抗生成方法迁移到离散场景的依据。

对投毒而言，沿聚类中心指向目标样本的方向生成的对抗样本最易牵动决策边界偏移。因此基于梯度信息的优化攻击效率更高。本文仅需找到部分梯度下降最快的位点，于是改造了经典的对抗生成算法，快速直接。

参考 FGSM，本节提出一种基于快速梯度下降法的离散型对抗样本生成算法，见算法2，用损失函数对输入的梯度作为策略选择的辅助信息。

该方法对样本 x 的梯度下降速度排序，取下降最快的前 r 个特征作为替换范围，r 的经验上限不超过向量长度的 30%。与原始 FGSM 相比，改进版针对离散特性做了适配：先对梯度排序，再对最快的 r 个特征做特征替换生成对抗样本。算法 2 中 SELECT 函数依据梯度信息选取替换值并生成对抗样本。

算法 2：基于快速梯度下降法的离散型对抗样本生成
输入：数据集合 D、检测模型 M、红队事件集 X、循环上限 L、特征替换位置上限 k  
输出：中毒数据集合 D'  
1: 根据 D 构造特征替换集合 V  
2: 用 D 训练检测模型 M  
3: 用 M 测试 X 并收集梯度信息  
4: for i = 0 to X 长度 do  
5:  x = X[i]  
6:  for j = 0 to L do  
7:   x' = SELECT(x,k,∇J(x),V)，其中 ∇J(·) 为 x 的梯度信息  
8:   把 x' 插入 D 得到 D'  
9:  end for  
10: end for  
11: return D'
