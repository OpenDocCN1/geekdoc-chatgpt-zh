在宿主机环境中为隐私工作区加固权限边界，可执行如下限制：

sudo chmod 700 /path/to/your/workspace

**五、第三方技能审查**
在接入新 Skill 之前先获取信息：

openclaw skills info

随后手动打开 ~/.openclaw/skills//SKILL.md 查看内容，排查是否存在 curl、bash 等高风险调用。建议优先使用官方内置的 55 个 Skill，或参考社区维护的精选合集 awesome-openclaw-skills。

**六、安全自检**
形成周期性安全巡检习惯：

openclaw security audit

若扫描结果提示网关鉴权泄露、浏览器操控端口暴露等风险，请结合前文的安全基线、配置参考与官方文档及时处置。

**七、更新版本**
保持客户端为最新，运行：

openclaw update

**八、卸载**
在终端中启动卸载流程：

openclaw uninstall

通过方向键移动光标，用空格勾选全部选项后回车确认，随后选择 yes 并回车，系统会自动清理 OpenClaw 的工作目录。

按不同包管理器卸载全局安装：
1. npm 安装时使用：
npm rm -g openclaw
2. pnpm 安装时使用：
pnpm remove -g openclaw
3. bun 安装时使用：
bun remove -g openclaw
