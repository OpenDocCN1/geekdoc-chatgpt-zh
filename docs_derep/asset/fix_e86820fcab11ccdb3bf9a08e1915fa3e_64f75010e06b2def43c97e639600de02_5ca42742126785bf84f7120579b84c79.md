整体来看，成功落地的企业通常会在底层算力与系统层面持续投入，通过提升神经网络的生产效率更快获得表现更优的模型，从而建立竞争优势。随后借助业务场景反哺获取更多数据。随着数据积累与研发投入加大，这些公司能够持续推动智能系统与工具链的演进创新。

#### 1.1.3 AI基本理论奠定

尽管近几年 AI 突破显著，其核心理论尤其是神经网络的雏形在浪潮兴起前已基本成型。作为智能基石，神经网络的演化可划分为以下阶段。

##### 1. 萌芽兴奋期（20世纪50年代~20世纪70年代）

1943年，神经科学家 Warren A. McCulloch 与控制论专家 Walter Pitts 基于数学与阈值逻辑构建了首个神经网络计算模型，该成果发表于 *A logical calculus of the ideas imminent in nervous activity*。该论文奠定了网络基础，也对人工智能研究产生深远影响。

早期探索催生机器定理证明、跳棋程序等成果，掀起人工智能第一次高潮。1950年，Alan Turing 提出“图灵测试”，用于判断机器是否能展现出难以与人类区分的智能行为。

1957年，Frank Rosenblatt 提出感知机 Perceptron（图 1.1.6），为后续发展奠定架构。该模型本质上是线性分类器，可对训练样本进行二分类并在训练过程中自动调整权值。感知机的面世激发学界对人工神经网络的关注，具有里程碑意义。其计算以矩阵乘加为主，影响了后续智能芯片与系统的基本算子，例如英伟达新一代 GPU 中为矩阵运算设计的 Tensor Core。

[PRE4]

1960年，Bernard Widrow 与 Hoff 提出自适应线性神经网络 Adaline 以及多层网络 Madaline，首次尝试把线性层叠加形成多层感知机结构。Adaline 与 Madaline 的出现为后续深度结构提供了基础，也带来了大模型与模型并行等系统挑战。

1969年，Marvin Minsky 与 Seymour Papert 在 *Perceptrons: an Introduction to Computational Geometry* 中证明单层感知机无法解决线性不可分问题，例如异或问题，指出了当时网络的两个主要缺陷：①基础感知机无法处理异或回路；②当时计算设备算力不足以支撑复杂网络。因此一段时间内研究陷入停滞，但也为后来人工智能的两大驱动埋下伏笔，即提升硬件算力以及通过增加层数与非线性运算如激活函数、最大池化等提升非线性能力。

1974年，Paul Werbos 在博士论文 *Beyond regression : new tools for prediction and analysis in the behavioral sciences* 中提出误差反向传播算法，使得多层网络训练成为可能，有效解决了异或问题。该工作奠定了人工智能训练范式——训练系统的核心步骤是持续反向传播；同时，为支持反向传播，编程语言与框架默认提供自动微分 Automatic Differentiation 能力。

##### 2. 蓬勃发展期（20世纪80年代~21世纪00年代）

1986年，Rina Dechter 在 AAAI 发表论文 *Learning while searching in constraint-satisfaction-problems*，将“深度学习 Deep Learning”一词引入机器学习社区。

1989年，Yann LeCun 在论文 *Backpropagation applied to handwritten zip code recognition* 中提出可通过反向传播训练的卷积神经网络 LeNet，启发了后续卷积网络的研究。卷积神经网络是智能系统的重要负载，大多数系统需在该类网络上验证性能，基准测试中也大量引入卷积网络。

20世纪90年代中期，统计学习兴起，支持向量机 SVM 成为主流，神经网络发展再次进入低谷。

2006年，Geoff Hinton 与 Ruslan Salakhutdinov 的论文 *Reducing the dimensionality of data with neural networks* 表明，多层前馈网络可逐层预训练，将每层视为无监督受限玻尔兹曼机，再用监督反向传播微调。该研究聚焦深度信念网络 Deep Belief Net 的学习过程，对深度学习发展作出重要贡献。当时得益于计算能力提升与大数据可用，人工智能再次加速。

2009年，李飞飞团队在佛罗里达举行的 CVPR 会议上以海报形式首次展示 ImageNet 数据库（Deng et al., 2009）（图 1.1.7）。

##### 3. 突破驱动繁荣期（约21世纪10年代）

2011年，微软研究院 Frank Seide、Gang Li 与 Dong Yu 在 Interspeech 大会发表论文 *Conversational speech transcription using context-dependent deep neural networks*，展示深度神经网络在会话语音转录方面的突破——在单通道非特定人语音识别基准上，相对错误率由 27.4% 降至 18.5%，相对降幅达 32%；在另外 4 类任务中亦观察到 22%~28% 的相对错误率下降。

该网络的训练依托于高效分布式系统，系统设计了适合作业的张量切片与放置及通信协调策略以加速训练，部署于多台配备英伟达 Tesla GPGPU 的服务器上，经过数百小时训练完成。论文致谢中提到 “Our special thanks go to Ajith Jayamohan and Igor Kouzminykh of the MSR Extreme Computing Group for access to a Tesla server farm, without which this work would not have been possible”，可见算法团队与系统团队的协同由来已久，算法与系统的协同设计将以往不可完成的计算变为可能，上层应用需求驱动系统演进，系统也支撑上层应用取得新突破。

2012年，谷歌的神经网络从 1000 万个 YouTube 视频的静止画面中学习识别猫。研究人员通过连接 16000 个处理器构建了当时最大规模的机器学习神经网络之一，处理器分散在互联网上自行学习，大规模互联算力支撑了更大数据集与模型的训练。该工作论文 *Building high-level features using large scale unsupervised learning* 发表于 ICML 2012（Le et al., 2012）。

2012年 9 月，Alex Krizhevsky、Ilya Sutskever 与 Geoffrey Hinton 团队设计的 AlexNet（图 1.1.8）赢得 ImageNet 竞赛，深度神经网络重新流行。AlexNet 首次引入 ReLU 激活函数，并在 LeNet5 基础上加入 Dropout 层以减少过拟合、加入 LRN 层以增强泛化能力。这些新结构与训练方法影响了后续模型设计与系统优化，例如激活函数与卷积层内核融合计算。AlexNet 使用 2 块英伟达 GTX 580 3 GB GPU 训练约 5~6 天，若 GPU 更强、数据更多，结果有望更优。

截至 2012年，以英伟达为代表的芯片厂商已连续发布 Tesla、Fermi、Kepler 架构商用 GPU 与多款消费级 GPU，这些 GPU 开始用于加速智能算法与模型研究，并被业界用于产品。同时从 AlexNet 可见，研究人员基于 CUDA API 编程实现 cuda-convnet，智能系统与工具伴随算法突破与需求应运而生。

此后，以 ImageNet 等公开数据集为代表的各领域公开数据或基准测试，驱动着 CNN、RNN、Transformer、图神经网络 GNN 等智能模型结构的发展与创新。

#### 4. 大模型带来新机遇（约21世纪20年代）

随着网络结构向更深、参数更多演进，出现多种基于预训练模型参数微调的特大参数模型。2021年 8 月，李飞飞教授与 100 多位学者联合发布长达 200 多页的研究报告 *On the opportunities and risk of foundation models*，系统综述大规模预训练模型面临的机遇与挑战，报告将基于深度神经网络与自监督学习、在大规模广泛来源数据上训练的模型称为大模型（Bommasani et al., 2021）。

大模型涵盖多种预训练模型，如 BERT、GPT、CLIP、DALL·E 等。当前基础模型涉及的技术子域包括模型的构建、训练、微调与评价，以及模型加速、数据处理、安全性、稳健性、对齐 Alignment、模型理论、可解释性等方面。大模型仍处于快速演进阶段。

## 小结与思考

- 本节围绕智能的历史、现状与发展展开系统研究，需深刻理解上层智能计算应用负载的特点、演进与趋势，才能找到系统设计的真实需求与优化空间。
- 智能在 CV、NLP、音频处理等技术域及金融、医疗、教育等行业均有广泛应用，其模型结构与部署需求不断变化，带来挑战与机遇。
- 智能的基本理论神经网络经历了萌芽兴奋期、蓬勃发展期、突破驱动繁荣期，其发展受硬件算力与模型创新共同推动。近年来大模型的出现带来新机遇，涵盖多种预训练模型，相关技术子域仍在快速发展。

## 1.2 AI发展驱动力

AI 可追溯至 20 世纪 50 年代，发展历经起伏，多次繁荣与低谷，直至 2016 年 AlphaGo 战胜世界围棋冠军李世石，AI 才在公众中掀起广泛热度，标志新一轮热潮。其实智能技术早在此标志性事件前已在众多互联网公司中得到广泛应用与部署。例如搜索引擎排序、图像检索、广告推荐等功能背后均有智能模型支撑。

可以认为机器学习是实现 AI 的一种方法，而深度学习是实现机器学习的一种技术。当前深度学习取得突破性进展，是 AI 中最为前沿与重要的技术，正不断在广泛场景替代传统机器学习模型。神经网络是深度学习的具体实现形态，使用神经网络模型来表达机器学习中的深度学习范式。

鉴于上述关系，后续章节将以人工智能一词代指神经网络这一具体实现形态。

### 1.2.1 AI学习方法

在展开智能系统设计相关内容前，需先了解智能的原理与特点。以下以实例说明智能的工作方式，假定读者具备一定基础，相关概念在此不作过多解释。

结合图 1.2.1，深度神经网络的开发与工作模式可概括为以下步骤：

- 确定模型输入输出：首先需明确神经网络模型的输入样本 Sample 与输出标签 Label。例如图 1.2.1 中向模型输入图片，输出图片所对应的类别马冬梅、马小梅、马红梅、马绿梅。用户需提前准备好输入输出数据，再展开后续训练。
- 设计与开发模型：开发者借助智能框架提供的 API 构建神经网络模型。在基本表示中，一般线段代表权重，圆圈代表输入数据发生变化的具体计算操作。其中权重用 w_i 表示，是可被学习并不断更新的数值，简称为网络模型的参数。
- 训练 Training 过程：训练本质是通过网络中连接逐层反向传播总误差，计算各层中每个权重与偏差对总误差的贡献即梯度 dl/dw_i，随后使用求解梯度的优化算法如梯度下降算法去寻找数据的鞍点，从而优化网络权重参数与偏差，最终最小化神经网络的总误差即 Loss 值。

因此训练过程即根据用户提供的带标签数据集，如图 1.2.1 中多张马冬梅图片及其确定性输出标签马冬梅，不断通过优化算法进行学习。学习的核心是通过以下步骤寻找给定数据集下最优模型权重 w_i 的取值。

（1）前向传播 Forward Propagation：由输入到输出完成各层矩阵计算如卷积层、池化层等，产生输出并完成损失函数计算。
（2）反向传播 Back Propagation：由输出到输入反向求解各层权重与输出对损失函数的梯度。
（3）梯度更新 Weight Update：通过梯度下降算法依据梯度与指定学习率更新模型权重。

不断重复以上 1~3 步，直至智能模型收敛即总误差 Loss 值降至预设阈值，或达到终止条件如指定迭代 Step 次数后停止训练。

如图 1.2.2 所示，完成模型训练意味着在给定数据集上模型已达到最佳或满足需求的预测效果。若开发者对预测效果满意，即可进入模型部署与推理。一句话说，我们训练智能模型就是通过不断迭代计算，用梯度下降的优化算法使 Loss 值逐步减小。Loss 值越小，表示算法越接近数学意义上的最优。

推理 Inference 过程：推理仅需执行训练过程中的前向传播。原理是基于训练好的智能模型，输入待预测数据，经前向传播即通过模型定义的激活函数与非线性函数处理数据，得到最终预测结果。
