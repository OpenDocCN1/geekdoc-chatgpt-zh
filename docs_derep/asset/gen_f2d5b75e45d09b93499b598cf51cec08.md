## 快速上手 DeepSeek：用 OpenAI SDK 一把梭

想把 DeepSeek 接进现有 Python 工作流，却不想学新 SDK？用官方 OpenAI Python 客户端改个地址就能跑。下面是一条从安装到多模态调用的完整路径，照着抄就能动起来。

先装依赖，环境里要有 openai 包。
[PRE0]
pip install openai
[/PRE0]

依赖装好，开始写调用脚本。导入模块、填入自己的密钥、实例化客户端指向 DeepSeek 地址，然后用 `chat.completions.create` 发出第一条对话。
[PRE1]
import os

from openai import OpenAI

from IPython.display import display, Code, Markdown

import requests

import json

# <YOUR_DEEPSEEK_API_KEY>替换为复制的 API key 字符串

ds_api_key = '<YOUR_DEEPSEEK_API_KEY>'

#实例化客户端

client = OpenAI(api_key=ds_api_key,

                base_url="https://api.deepseek.com")

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {"role": "user", "content": "你好，好久不见!"}

    ]

)

#输出生成的响应内容

print(response.choices[0].message.content)

#输出完整的响应

print(response)
[/PRE1]

有了客户端，接下来就是消息的组织方式。先定义一个 system 角色，给模型一个行为定位。
[PRE5]
system_message = {
    "role": "system",
    "content": "你是一位擅长编写 python 代码的助手。"
}
[/PRE5]

再准备一条用户输入。
[PRE6]
user_message = {
    "role": "user",
    "content": "你好，请介绍下你自己。"
}
[/PRE6]

DeepSeek 也支持图文混合。把文字和 image_url 放在同一个 content 列表里传进去即可。
[PRE7]
user_message_with_image = {
    "role": "user",
    "content": [
        {"type": "text", "text": "你能帮我介绍下这张图片里面的内容吗？"},
        {"type": "image_url",
         "image_url": {
             "url": "https://ml2022.oss-cn-hangzhou.aliyuncs.com/img/image-20241009205714055.png"}}
    ]
}
[/PRE7]

实战里通常会把 system 和 user 一起喂进去，形成带角色的对话。只需要把两个消息对象塞到 messages 列表，模型就会按设定回复。
[PRE8]
#创建用户消息

user_message = {
    "role": "user",
    "content": "你好，请介绍下你自己。"
}

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        system_message,
        user_message
    ]
)

#输出生成的响应内容

print(response.choices[0].message.content)
[/PRE8]

就这么一套流程：装包 → 配 key 与 base_url → 实例化客户端 → 构造 messages → 调用 deepseek-chat。模型、系统提示、图文输入都能无缝复用，日常开发和自媒体自动化都能直接套用。
