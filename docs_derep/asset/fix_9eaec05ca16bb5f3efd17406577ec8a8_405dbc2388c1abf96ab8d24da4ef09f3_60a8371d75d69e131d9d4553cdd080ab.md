# 猫脑里的方向细胞，如何点亮深度学习

休伯尔和威泽尔当年真正想搞清楚的是：后脑的视觉区里，哪些神经元在回应瞳孔捕捉到的哪类刺激。他们预设，后脑皮层应当存在局部对应的激活模式，只要视网膜接收到特定模式的输入，对应区域就会点亮。为此他们在实验猫颅骨上钻出约三毫米的孔，探入电极记录放电。历经无数天枯燥重复的记录，牺牲了不少动物后，他们捕捉到一种新型单元——对朝向敏感的细胞。视野里出现一条边缘并且边缘指向某个固定方向时，这类细胞就会被唤醒。

这个发现让两人共同获得了1981年的诺贝尔生理学或医学奖，更重要的是它打开了对信息流的想象：视觉信息从视网膜到中枢再到大脑，恐怕并不是一次性映射，而是分层迭代、逐级提炼的加工。抽象与迭代成了关键词。感受器接触到的是最原始的具体信号，而我们能进行逻辑思考时用的却是高度抽象的概念。打个比方，视网膜只在捕捉颜色与亮度的微元信息，大脑最后却在判断“这是谁”。辨认熟人时的神经路径大致可以这样拆解。

• 入口信号：瞳孔把外界微元收进来。
• 初步加工：皮层里某些神经元对边缘和朝向作出反应。
• 初级提炼：系统把轮廓归类为类人形，辨出基本五官特征。
• 高级确认：进一步判定出人脸，并且是具体的某位朋友。

五十年代的这个生理线索，竟在半个世纪后指向人工智能的转折点。学界基本确认，人类视觉的处理是分级的：底层提取微元中的边缘，中层是形状片段与局部目标，高层则是整体目标及其行为联想。高层表征由低层表征组合与提炼而来，向上走越抽象，越贴近认知意图。抽象层级越高，可选解释越少，分类也越稳。图像如此，语言也一样：词到句是多对一，句到义是多对一，义到意图仍是多对一，这本身就是层级结构。细心的读者能闻到这里与深度学习的共通气味——分层迭代、逐级抽象。

深度学习之前，浅层网络乃至统计学习，做的都是特征到结果的直接映射。现实世界的关系往往存在，但很多是间接隐晦的，一次性从原始微元跳到结论并不现实。

那“深度”二字到底指什么？可以理解为存在多个加工层次，由基础特征逐层提炼出高级特征。深度学习的本质就是一种逐层自动提取特征的机器学习范式，如图 7-11 所示，它模拟的是计算机从图片中辨认人的分级路径。

还有一个更贴切却少被提及的名字——无监督特征学习。无监督指特征挑选不需要人工干预，这才是深度学习的最大特质。用多少隐层、是否必须用深度网络，只是实现手段上的选择。

#### 7.5.2 从浅层学习到深度学习

1986年，辛顿提出误差反向传播算法，给多层网络训练带来了新的可能。但这并未立即掀起复兴。1990年代起，机器学习界反而转向其他统计方法，这股潮流一直延续到现在，教科书里统计模型仍占主导。

为什么会这样？反向传播在理论上解决了多层网络如何从大量样本中学习规律并预测未知的问题，只是让“神经网络是死路”这类论断不再成立。彼时的算力不足以处理工业规模的数据，也缺乏有说服力的应用案例，很难扭转外界的不信任。辛顿曾感慨：1986年我们发现了能学习多层特征的方法，兴奋之余以为问题解决了，但真正应用的突破迟迟没来，我们低估了所需计算资源和标注样本的数量。

1986到2006的二十年里，人工神经网络的应用基本停滞。即使使用，也多是只有一层隐层的三层网络。更深的网络训练更难、数据需求更大，但更关键的是，神经网络当时找不到明确的应用定位，没人清楚何时该用、为何要用。

神经网络最迷人的地方在于端到端学习：只要知道输入和输出，就能自动拟合中间参数，形成一个能预测未见数据的黑箱。但这个输入必须是包含且仅包含影响结果全部关键特征的数据，少了关键特征误差无法收敛，多了无用特征则易引发维度灾难。黑箱特性也意味着它只是对真实规律的拟合，理论解释力有限。所以在建模前，特征挑选与提取高度依赖人的先验知识。

像微元到字母的识别这类问题，人工设计特征是可行的，浅层网络就能解决。但要做到“这张人脸是不是我熟悉的朋友”，人工就很难事先说清需要哪些特征。第一步的特征定义通不过，后面全是空谈。

于是1990年代涌现出一批基于统计的浅层模型：支持向量机、Boosting、Logistic Regression为代表的最大熵方法等。它们本质上可看作带或不带隐层的特化神经网络。因理论和实践都取得巨大成功，而神经网络分析难度大、调参依赖经验，浅层神经网络再次沉寂，统计学习成为主流。直到深度学习概念提出后，这一局面才被打破，机器学习正式进入深度时代。

#### 7.5.3 序幕开启

2006年被视作深度学习元年。序幕由辛顿同年发表的两篇论文拉开。第一篇与学生鲁斯兰·萨拉赫丁诺夫在《科学》上发表《通过神经网络进行数据降维处理》，用神经网络自动进行特征挑选与提取，实质上开创了深度学习分支，只是“深度学习”一词并非在此首创。第二篇《一种基于深度信念网络的快速学习算法》对“深度”做了明确包装，让概念迅速走红。

两篇文章论证了两点：

1) 多隐层人工神经网络具备优秀的自动化特征学习能力，网络自主学到的特征比手工特征更本质，更利于可视化或分类。
2) 训练难题可通过逐层预训练来缓解，给出可操作的训练方案。

学术界与工业界把《通过神经网络进行数据降维处理》定为开山之作，不仅因其提出框架，更因它点明了深度学习相对于浅层学习的两个具体优势。

第一个是表示能力。单层网络及以分类、回归为主的浅层算法，在有限样本和计算单元下，工程上的表示能力不足。虽然泛逼近定理在理论上成立，但实践中不够用。辛顿的多隐层网络表示更强，用更少的节点就能逼近更复杂的目标函数。论文《Conversational Speech Transcription Using Context-Dependent Deep Neural Networks》的数据表明，层数与节点数对错误率有明显影响。

图 7-12 是伊恩·古德费洛在《深度学习》中的示意：对特定问题，网络越深，拟合精度往往越高。实践中也反复观察到这一现象。只有在足够隐层的支撑下，神经网络才能既处理复杂建模，又避免天文数字级的参数，用当前硬件可承受的代价解决实际问题。

第二个优势更关键。浅层学习的局限在于特征挑选过度依赖人类先验，很多人类难以描述“哪些特征重要”。深度学习能自动找出关键特征，这对应用神经网络是极大的解放。

举例来说，机器学习通常对无关变化不敏感，如物体位置、方向、装饰图案，或语音中的音调、口音。但有些场景需要对细微差异敏感，例如分辨白色的雪狼和外形相似的萨摩耶犬。不同环境下两只萨摩耶的微元差异可能很大，而同一背景下雪狼与萨摩耶的微元相似度却可能很高。人类不难区分却说不清微元层面的依据。

浅层模型恰好相反，能捕捉微元级细微差异，却难以把相似姿势、相似背景下的雪狼与萨摩耶分开，也难以把不同姿势的萨摩耶归为一类。这种现象被称为选择性-恒常性困境。以原始微元为特征行不通，传统方法依赖人工设计的特征提取器，而深度学习主张用多隐层模型与大量训练数据自动提取有用特征。

典型解法是用卷积神经网络：若干卷积层逐级抽象，从微元到线条、线条到器官、器官到物体对象，再通过标注数据让每层学到更高层次的特质，回答“这些微元能组成哪些线条”“这些线条能组成哪些器官”“这些器官是否符合萨摩耶的特征与位置”等问题，如图 7-14 所示。

至于什么样的微元构成线条、什么样的线条构成器官，不需要人类告知，由标注好的训练数据教会网络。这一层层抽象的问题，早在1995年已被康奈尔大学戴维·菲尔德提出的稀疏编码解决。他的设定是：从大量风景照片里提取1000个16×16微元的随机片段，再选一个目标片段，用最少的源片段加权叠加逼近目标。迭代后被选中的片段惊人地一致，都像不同方向的边缘线，任何形状都能由这些线条组合而成。计算机不仅知道复杂形状由基本结构组成，还能自行找出它们。稀疏编码的结果与休伯尔-威泽尔的生理学发现高度吻合。图 7-15展示了三个源片段合成新形状的例子。

用大量数据学习特征，比手工规则更能刻画数据的内在信息。它为“人描述不清，机器就无解”的困境提供了可行路径，让下棋程序靠“棋力”而非单纯算力胜过人类，让图像识别超越人类本身的能力，这正是深度学习备受关注的原因。

2006年辛顿的第二篇论文可视作深度学习的首个具体应用范例。“深度”一词由此流行。还有一个段子：当年很多期刊只要看到标题里有“神经网络”就拒稿。查阅2006年之前的IEEE和ICML刊物，几乎找不到标题含“神经网络”的文章。ICML主编曾公开表示不该接收神经网络论文，IEEE期刊也有相应的不接收准则。可见当时“神经网络是伪科学”的信念根深蒂固，辛顿不得不用“深度学习”重新包装多层神经网络，才得以发表。
