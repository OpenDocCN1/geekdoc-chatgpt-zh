**ID3 决策树概览**
ID3，即 Iterative Dichotomiser 3，是决策树分类方法中的早期代表。它依赖信息熵来衡量节点纯度，并挑选信息增益最大的特征作为分裂依据，通过递归方式逐步生成树结构实现分类 [Data: Entities (0); Reports (0); Relationships (0)]。

**信息熵与信息增益**
信息熵用于刻画样本集合的无序程度，熵值越小表示纯度越高。信息增益则反映分裂前后熵值的变化幅度，用来评估属性划分数据的能力。ID3 每次都选增益最大的属性进行切分，从而不断细化决策树 [Data: Entities (0); Reports (0); Relationships (27)]。

**数据集划分与离散变量处理**
ID3 仅支持离散型特征，连续型特征必须先离散化，比如做分箱处理。划分方式是一次展开一列，与 CART 的二分切分点搜索不同。比如针对 AGE 列，ID3 会按不同取值把样本拆成多个子集，再分别计算熵与增益 [Data: Sources (0, 1); Entities (6, 7, 8, 9); Relationships (10, 11, 12, 13)]。

**ID3 的局限性**
尽管有历史意义，ID3 仍存在明显短板：

2. 倾向于选择多分类属性：ID3 在选择分裂属性时，倾向于选择分类水平较多的属性，这可能导致模型过拟合 [Data: Sources (1); Entities (0)]。
3. 缺乏剪枝机制：ID3 没有内置的剪枝机制来防止过拟合，这使得模型在训练数据上表现良好，但在测试数据上可能表现不佳 [Data: Sources (1); Entities (0)]。

**ID3 与 C4.5、CART 的关系**
ID3 是决策树算法的基础，后续的 C4.5 和 CART 算法在 ID3 的基础上进行了改进。C4.5 引入了连续变量处理、剪枝机制和信息增益率等改进，而 CART 则支持分类和回归任务，并采用二分法进行数据集划分 [Data: Entities (1, 2); Relationships (0, 1, 4, 14)]。
