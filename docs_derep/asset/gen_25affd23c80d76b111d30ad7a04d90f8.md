第二预测头是在原有思路上增加可学习层构建的，它以主干模型最后一层 Transformer 的输出为来源，先做 RMSNorm 归一化再与输入向量拼接。与首个预测头从 $t_1$ 起步不同，该头从 $t_2$ 开始处理输入 token。拼接后的表征经线性投影调整到合适维度，随后送入一个可训练的 Transformer 模块进行深加工。训练阶段它负责拟合 $t_3 \sim t_6$ 的 token，推理时仅计算 $t_6$ 的输出。

图 2-15 DeepSeek MTP 实例 [8]

同样，第三个预测头接收第二个预测头 Transformer 块的输出以及对应的输入向量，范围为 $t_{3} \sim t_{6}$，遵循与前序头一致的顺序：训练时预测 $t_{4} \sim t_{7}$ 的序列，推理时只给出 $t_{7}$ 的预测值。经过 MTP 训练后，模型在对未来 token 的预先规划能力上得到加强，从而实现更可靠的预测。

梳理来看，经过多轮 MTP 研究的积累，DeepSeek 的 MTP 方案集成了前人成果，通过一次性生成多个未来 token，大幅提升了样本利用效率，也让模型能够捕捉更长的上下文信息。

### 小结

本章在宏观层面呈现了 DeepSeek-V3/R1 的整体架构，为后续细节展开奠定基础，重点拆解了 DeepSeekMoE、MLA 机制和 MTP 三大核心创新。这三项改进共同提升了模型性能，同时显著优化了计算与内存效率。

DeepSeekMoE 在传统 MoE 基础上改进，引入共享专家和免辅助损失的负载均衡，解决了传统 MoE 参数冗余和资源分配不均的问题。共享专家机制压缩了专家模型的冗余参数，提升了训练效率和推理性能；免辅助损失的负载均衡在不引入额外损失函数的前提下实现专家间的高效资源分配，进一步优化运算效率和性能。

MLA 是 DeepSeek-V3/R1 的另一项关键创新，通过低秩键值联合压缩和 RoPE 向量解耦，显著提升了注意力机制的计算与内存效率。从 Q、K、V 的向下投影、向上投影，到 RoPE 向量，再到最终注意力输出，完整呈现了 MLA 的计算流程。该方案在保持信息有效传递的同时，实现了计算与内存效率的大幅提升。

MTP 旨在缓解传统单 token 生成效率低的问题。2018 年谷歌提出块级并行解码策略，通过增加多个 lm_head 模块并行预测多个 token。2024 年 Meta 提出 MTP 方法，利用多个并行预测头预测后续 token，增强模型对长依赖的学习。DeepSeek 的 MTP 则通过顺序模块与共享的 Embedding 层逐层预测更多 token，显著提升了样本效率和上下文捕捉能力。

本章系统阐述了 DeepSeek-V3/R1 模型的核心架构与关键技术改进。对 DeepSeekMoE、MLA 和 MTP 的深入探讨不仅揭示了创新原理，也体现了其在实际应用中的显著优势。这些创新为后续模型优化与性能提升提供了坚实的理论与实践依据。随着技术发展，DeepSeek-V3/R1 的架构与优化策略有望在更多领域发挥作用，推动大模型技术的普及与应用。

## 第 3 章 DeepSeek 的训练架构

在大模型开发中，除了架构创新，训练体系的设计同样决定模型最终的性能、效率与扩展能力。DeepSeek 在训练架构的硬件适配、算法优化、数据策略三个维度上实现系统性创新，显著提升了大规模语言模型的训练效率与推理能力。本章将详细介绍 DeepSeek 训练架构的核心设计理念与技术亮点，涵盖训练基础架构、硬件层面创新、算法层面创新和数据策略优化四个方面。

### 3.1 DeepSeek 的训练

DeepSeek-V3 与 DeepSeek-R1 共享极其相似的模型架构，R1 正是在 V3 基础上训练得到的具备强推理能力的大模型。

训练千亿参数模型如同指挥一场大型交响乐，需要精准分工、高效协作与灵活应变。围绕这些目标，DeepSeek 的训练架构通过分布式计算、存储优化和动态调度技术，将成千上万张 GPU 组织成高效运转的“超级大脑”。

#### 3.1.1 基础技术

大模型训练需考虑的基础技术包括分布式训练、计算与存储优化以及动态资源调度。

#### 1. 分布式训练：团队协作的智慧

#### 4. 第二轮 GRPO 强化学习训练

第二轮 GRPO 训练在更大规模上通过强化学习实现更强行为约束，对齐人类偏好，消除有毒有害内容，增强模型的通用能力。

### 3.2 DeepSeek 在硬件层面的训练亮点

DeepSeek-R1 在模型表现上不输 GPT-4o，训练成本却大幅降低，不仅依赖算法优秀，也离不开硬件层面的诸多创新。

#### 3.2.1 FP8 混合精度训练

FP8 混合精度训练利用 8 位浮点数格式进行训练，旨在降低数据精度提升计算效率、减少内存占用并降低训练成本，同时尽量保持模型性能。随着硬件支持和算法优化成熟，FP8 混合精度在训练千亿级参数模型中展现显著优势。

FP8 混合精度训练的核心优势主要体现在以下四方面。

- ① 计算效率提升。FP8 数据的计算速度是 FP16 的 2 倍、FP32 的 4 倍，能大幅加速大规模模型训练。
- ② 内存占用减少。FP8 数据存储空间仅为 FP32 的 1/4，显著降低显存需求，从而支持更大规模模型或更高并行度。
- ③ 成本降低。通过减少计算与通信资源消耗，FP8 训练可大幅降低训练成本。
- ④ 性能平衡。尽管 FP8 精度较低，但通过高精度累加如 E4M3 或 E5M2 格式，以及关键层保留高精度如 BF16/FP32 技术，可在保证数值稳定性的同时提升模型收敛速度。

对于对精度敏感的模块如向量化层、输出头、MoE 门控单元、归一化层、注意力层等，DeepSeek-V3 仍采用 BF16 或 FP32 计算，以保证性能。

目前 FP8 混合精度训练已被越来越多大模型研究接受，如微软开发了基于 FP8 的混合精度框架，优化通信与分布式训练策略，显著提升大模型训练速度。

#### 3.2.2 DualPipe 算法

2.2 节和 2.3 节介绍了 MoE 和 MLA。MoE 通过减少每个 token 的激活参数大幅降低训练成本，而 MLA 显著减少 KV Cache 大小并将推理速度提高数倍。本节重点介绍 DualPipe 技术，帮助 DeepSeek 在训练中提升 GPU 集群的计算通信比与效率。

深度学习训练核心步骤是前向传播和反向传播，如图 3-5 所示。

前向传播是指输入数据从网络底层逐层传递到顶层，每层对数据变换并生成输出。

反向传播是指通过损失函数计算损失值，利用链式法则逐层计算损失对各层权重的梯度，并将梯度从输出层反向传递到输入层，最后用优化算法如 Adam 根据梯度更新权重。

> 注意：反向传播发生在前向传播之后。

具体而言，前向传播中数据从第 $n$ 层流向第 $n+1$ 层；反向传播中梯度从第 $n+1$ 层回传到第 $n$ 层。

实际训练通常采用批处理方式，将一批样本同时输入网络，完成整批数据的前向和反向传播后统一更新权重。

图 3-5 前向传播和反向传播

- ① 资源利用率问题。由于前向与反向传播存在依赖，部分节点可能因等待其他节点计算结果而空闲。
- ② 通信瓶颈。梯度、输出等数据需在节点间传输，可能受限于网络带宽导致节点闲置。
- ③ 容错和恢复。在数千节点集群中，节点崩溃概率较高，如何从检查点恢复训练是重要问题。

#### 1. 细粒度划分阶段

DualPipe 算法把每个计算块分为四种：注意力模块、分发模块处理设备间通信、多层感知机、聚合模块跨设备输出合并。对于反向传播块，注意力模块和 MLP 模块进一步拆分为输入反向传播和权重反向传播。

#### 2. 双向流水线调度

通过同时从流水线两端输入小批次数据，大部分通信操作能够完全重叠。为实现该机制，DualPipe 需要维护两份模型参数副本。

例如，使用 8 台设备运行 8 层模型时：设备 0 同时持有第 0 层和第 7 层参数，设备 7 同时持有第 7 层和第 0 层参数。这种设计通过参数镜像和双向数据流动，显著提升硬件利用率与训练效率。

#### 3. 高效通信内核

DeepSeek 定制了高效的跨节点全通信内核，节省了专用于通信的流式多处理器数量，优化了性能。

### 3.3 DeepSeek 在算法层面的训练亮点

本节介绍了 DeepSeek 在算法训练层面的两大亮点：GRPO 算法和知识蒸馏。
