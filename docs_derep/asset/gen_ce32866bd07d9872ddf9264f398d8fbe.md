最优路径的花费是由动态规划的递推规则决定的，和 cost 数组里最小的那一个数并没有必然联系。

归纳结论：程序结果与 cost 的最小元素没有直接关联，该判断是错误的。

**【编程魔法师讲解考点】**

**一、考点：动态规划**

动态规划通过保存子问题的解来避免重复计算。核心在于把大问题拆成子问题并用递推组合。

1. 动态规划的核心步骤
（1）状态定义：如 dp[i] 表示到达第 i 个台阶的最小花费。
（2）状态转移：dp[i]=min(dp[i-1],dp[i-2])+cost[i-1]，即从前一或前两阶过来再加上当前阶花费。
（3）初始条件：dp[0]=0 起点不花钱；dp[1]=cost[0] 第一阶花费。
（4）边界处理：i-2 需保证 i>=2。
（5）结果输出：min(dp[n],dp[n-1]) 表示从倒数第一或第二阶结束。

2. 优化思路
（1）空间优化：只保留最近两项，空间从 O(n) 降到 O(1)。
示例：int prev1=cost[0], prev2=0; for(int i=2;i<=n;i++){ int cur=min(prev1,prev2)+cost[i-1]; prev2=prev1; prev1=cur; } return min(prev1,prev2);
（2）时间复杂度：每阶 O(1)，总体 O(n)。

**二、考点：C++ 要点**

（1）vector 用法：vector<int> cost(n) 创建可变长度数组并支持下标。
（2）引用传递：compute(vector<int>& cost) 避免拷贝，提升效率。
（3）for 循环遍历 cost 实现递推。

**一、考点：递归**

基例：if(b==0) return a;

即把 a 累加 b 次得到 a*b。

（1）时间与空间随递归深度线性增长，复杂度 O(b)。
（2）可灵活实现阶乘、斐波那契等。
（3）缺基例会无限递归导致栈溢出。
