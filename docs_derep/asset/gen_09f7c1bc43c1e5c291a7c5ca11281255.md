Ascend C 向量算子开发速览：以 add_custom 为例

自定义向量算子的核心通常由两个函数撑起，分别是 Init 初始化函数和 Process 执行函数。Init 负责把外部数据定位清楚，并完成芯片内部内存的准备工作；Process 则承载算子的具体实现，采用三段流水：CopyIn、Compute、CopyOut。CopyIn 负责把板外数据搬进芯片，Compute 负责向量计算，CopyOut 负责把芯片内结果搬出。

三段流水间存在数据依赖，需要传递。Ascend C 用 TQue 队列来完成任务间的通信与同步，提供了 EnQue、DeQue 等基础接口。TQue 在管理不同层级物理内存时，用抽象的逻辑位置 TPosition 来表达各层存储，屏蔽了片上物理存储的概念，开发者无需关心硬件细节。Ascend C 以 GlobalTensor 和 LocalTensor 作为数据操作的基本单元，指令 API 直接作用于它们，也是数据的载体。在向量编程里常会用到两类 TQue：放置搬入数据的 VECIN 和放置搬出数据的 VECOUT。

本节以最基础的 add_custom 向量算子为例，沿着自定义算子的开发流程，演示如何按向量编程范式逐步编写，最后也会提到 Ascend C 向量编程的数据切分思路。

## 1. 算子分析

写代码前先把算子的数学含义、输入输出和计算逻辑理清楚，明确要调用的 Ascend C 接口。

### 1）明确算子的数学表达式

Ascend C 提供的向量计算接口操作的对象都是 LocalTensor，外部数据必须先搬到片上存储再计算。以 Add 为例，表达式为 z = x + y，先用计算接口把两个输入相加得到结果，再搬回外部存储。

### 2）明确输入和输出

Add 算子有两个输入 x、y，一个输出 z。本例中输入支持的数据类型为 half，即 float16，输出类型与输入一致。算子支持的形状为 8、2048，输出形状与输入相同，数据格式为 ND。

### 3）确定算子实现所需接口

数据搬移使用 DataCopy；计算部分较为简单，用基础 API 即可，加法使用双目指令接口 Add 实现 x + y；TQue 队列的管理则依靠 EnQue、DeQue 等接口。

## 2. 核函数定义与封装

算子分析完成后就可以开始编码，第一步是核函数的定义与封装。

### 1）函数原型定义

本例的核函数名是 add_custom，根据输入输出分析，有三个参数 x、y、z，x、y 为输入内存，z 为输出内存。按核函数定义规范，使用 __global__ 限定符标明可被 <<<...>>> 调用的核函数，使用 __aicore__ 限定符标明在设备端 AI Core 执行。为统一入口，参数统一用 GM_ADDR 宏修饰，表示其在内存中的位置。

### 2）调用算子类的 Init 和 Process 函数

在函数原型内部，先实例化对应的算子类，再调用其 Init 与 Process。Init 负责内存初始化相关工作，Process 负责核心计算逻辑。

### 3）对核函数的调用进行封装

对外封装成 add_custom_do，方便主程序调用。封装函数仅在编译 NPU 侧算子时生效，CPU 侧可直接调用 add_custom。调用核函数时，除 x、y、z 外，还需通过 <<<...>>> 传入 blockDim 表示核数、l2ctrl 保留参数置为 nullptr、stream 表示任务流，用来配置执行。

图 13.5.2 纵向分为上下两部分，上半部是外部存储 Global Memory 的数据流动，下半部是 AI Core 内部 Local Memory 的数据流动；横向分为三部分，对应 CopyIn、Compute、CopyOut 三个阶段。AI Core 内部的任务间传递统一由 TPipe 资源模块管理。

CopyIn 阶段，先用 DataCopy 把外部存储的 xGm、yGm 搬入芯片得到 xLocal、yLocal，再通过 EnQue 把数据送入搬入队列 inQueueX、inQueueY，用于流水间的通信与同步。

Compute 阶段，先用 DeQue 从搬入队列取出 xLocal、yLocal，用向量运算 API 计算得到 zLocal，再用 EnQue 把结果送入搬出队列 outQueueZ。

CopyOut 阶段，先用 DeQue 从搬出队列取出 zLocal，再用 DataCopy 把芯片内数据写回外部存储 zGm。

以上就是向量算子核心的数据通路，也是后续编码的思路参考。

## 4. 算子类实现

核函数的声明里会实例化算子类并调用 Init 与 Process。本节先展示算子类成员，再说明 Init 与 Process 的实现。

### 1）算子类成员定义

算子类中声明对外开放的 Init 与 Process。Process 再细分为三个私有成员 CopyIn、Compute、CopyOut，分别对应数据搬入、计算、数据搬出。还声明了内存管理对象 pipe、输入队列 inQueueX、inQueueY、输出队列 outQueueZ，以及 Global Memory 地址对象 xGm、yGm、zGm，作为私有成员使用。

[PRE3]

### 2）初始化函数 Init()函数实现

多核并行时每个核只处理全部数据的一部分。Ascend C 核函数是单核处理函数，需要先算出本核负责的数据位置，并为 TQue 分配内存空间。

Init 实现中，先通过计算得到本核处理的 Global Memory 偏移，其中 x、y、z 表示三个参数在片外的起始地址，BLOCK_LENGTH 为单核数据长度，为总长除以核数，GetBlockIdx 可得到核编号，例中为 0~7。这样可得到本核的输入输出在 Global Memory 上的偏移，并写入 Global Tensor。

随后通过 TPipe 为输入输出 TQue 分配内存，调用 InitBuffer，参数依次为队列名、是否开启 Double Buffer、单个数据块大小。

### 3）核心处理函数 Process()函数实现

按向量编程范式，核函数实现拆成 CopyIn、Compute、CopyOut 三个基本任务。Process 先算出本核内的分块数，确定循环次数，再按顺序循环执行三段流水。简化的数据通路如图 13.5.3 所示。

图 13.5.3

- CopyIn()私有类函数实现

使用 AllocTensor 为输入分配芯片存储空间，数据类型为 half，对应分配大小。用 DataCopy 把 GlobalTensor 拷贝到 LocalTensor，按分块编号拷贝所需数据到片上。用 EnQue 把 LocalTensor 放入 VecIn 的 TQue。

- Compute()私有类函数实现

用 DeQue 从 VecIn 取出输入 x、y。用 AllocTensor 为输出分配芯片存储空间。用 Ascend C 接口 Add 完成向量计算，该接口为双目指令 2 级接口，参数为目的操作数、源操作数 1、源操作数 2 和元素个数。用 EnQue 把计算结果 LocalTensor 放入 VecOut 的 TQue。用 FreeTensor 释放不再使用的输入 LocalTensor。

- CopyOut 私有类函数实现

用 DeQue 从 VecOut 的 TQue 取出结果 z。用 DataCopy 把 LocalTensor 拷贝回 GlobalTensor。用 FreeTensor 回收不再使用的 LocalTensor。
