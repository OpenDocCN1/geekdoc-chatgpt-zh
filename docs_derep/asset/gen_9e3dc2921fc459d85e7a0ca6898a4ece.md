#### 3. 工作原理

> 向 Cursor 提问
> FastAPI 的工作原理是什么？

Cursor 的解析如下。

- ASGI 基础架构
FastAPI 建立在 ASGI 异步服务器网关接口之上，实现 Python 异步 Web 服务器与框架的通信：
异步处理：可并发处理请求，无需线程池。
事件驱动：管理 HTTP 请求的生命周期事件。
高效率：擅长处理大量并发连接，尤其适合长连接场景如 WebSocket。
具体实现上，FastAPI 继承自 Starlette，一个轻量级 ASGI 框架。

- 请求生命周期
请求到达 FastAPI 应用时的处理流程：
1. 接收请求：ASGI 服务器如 Uvicorn 接收 HTTP 请求。
2. 路由匹配：根据 URL 路径与 HTTP 方法找到对应的处理器。
3. 依赖解析：解析并执行处理函数所需的依赖项。
4. 参数提取与验证：从路径、查询参数、请求体等抽取数据，并用 Pydantic 进行校验与类型转换。
5. 执行处理函数：运行业务逻辑。
6. 响应生成：将返回值转换为 HTTP 响应。
7. 中间件处理：应用所有已配置的中间件。
8. 发送响应：将最终结果返回给客户端。
