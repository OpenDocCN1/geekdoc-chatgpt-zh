先看最基础的函数补全。把需求写成“请补全 Python 代码，实现二分查找”，它直接给出可运行的完整实现。

def binary_search ( arr, target ) :

    left, right = 0, len ( arr ) - 1

    while left <= right:

        mid = ( left + right ) // 2

        if arr[mid] == target:

            return mid

        elif arr[mid] < target:

            left = mid + 1

        else:

            right = mid - 1

    return -1

再看文档自动生成。只给一段简单的 Flask 示例代码作为输入：

from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/get_user', methods=['GET'])

def get_user():

    user_id = request.args.get('id')

    return jsonify({"user_id": user_id, "name": "Alice"})
