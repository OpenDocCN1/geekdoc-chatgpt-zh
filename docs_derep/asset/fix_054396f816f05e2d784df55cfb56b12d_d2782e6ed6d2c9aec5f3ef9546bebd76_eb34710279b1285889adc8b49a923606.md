# 基座模型挑选与云端操作要点

前文已指出，Checkpoint 基座在 AIGC 绘图流程里处于核心位置，选对底座是获得高质量出图的先决条件。模型的能力主要来自训练所用图像的规模与质量、训练轮次与周期，以及在真实使用中累积的迭代优化。哪怕是同一画风，不同作者训练的版本表现也会有差异。本节整理几款使用门槛低、稳定性较好的 Checkpoint，供创作时参考，避免因选型失误拉低设计效果。

###### 1\. GhostMix 鬼混模型
GhostMix走的是写实向动漫路线，人设不限于人类，机甲、科幻等机械场景也能Hold住。画面装饰感强，细节堆得很足，元素华丽，放大后通透度更好，见图6-2 与图6-3。

### 6.1.3 收藏学习
AI 绘图已成为设计趋势，网络上模型层出不穷，更新极快。本地使用 Stable Diffusion Web UI 的用户常抱怨好模型太多、旧版频繁迭代。下载全部心仪底座会占用大量硬盘并面临过时风险。Liblib AI 由作者上传维护，支持线上体验或下载，便于收藏避免资源浪费。

看到满意的模型，点击“加入模型库”即可收藏；想立刻试用，点击“立即生图”进入绘制页。使用前注意阅读作者参数建议，不同模型习惯不一；同时注意模型的创作与商业使用许可，务必在授权范围内使用。

## 6.2 云端魔法：图像修整
Liblib AI 的在线生成操作与 Stable Diffusion Web UI 基本一致，文生图、图生图不再赘述。其核心竞争力在于开源兼容与开发者持续贡献的附加功能与插件，下面介绍部分辅助功能如何支撑设计流程。

### 6.2.1 图像反推
设计中常需对已有图像进行二次加工，获取生成信息很有帮助。PNG 图片信息功能可查询提示词、随机种子、主模型、LoRA、VAE 及参数等，但对非 AI 生成图无效，此时需要提示词反推。Liblib AI 提供三种反推方式，各有侧重，分别是 CLIP 反推、DeepBooru 反推和 WD1.4 标签器。

###### 1\. CLIP 反推
在图生图的正向提示词输入框旁有“CLIP 反推”按钮。先将图片上传至图生图区域，点击“CLIP 反推”后，输入框会自动填入与图像相关联的提示词。
