#### 3.2.1 R1 模型概览
DeepSeek-R1 由 DeepSeek 于2025年1月发布，旨在增强大语言模型的推理能力。评测显示其在数学、代码、自然语言推理等任务上可与 OpenAI o1 正式版媲美。

官方同时开源 DeepSeek-R1-Zero 与 DeepSeek-R1 两个 671B 模型，并基于 R1 输出蒸馏出6个小模型，其中32B 与70B 在多项指标上对标 OpenAI o1-mini。

R1 与 DeepSeek-V3 采用完全相同的架构，仅训练流程与数据不同。具体而言，R1 在 V3 base 上先进行有监督微调，再做强化学习训练；R1-Zero 则直接从 V3 base 进行强化学习训练，省略了有监督微调。

因此 R1 项目中未单独提供权重、推理脚本与部署方法，这些内容已包含在 DeepSeek-V3 项目中，可参考 3.1 节。
