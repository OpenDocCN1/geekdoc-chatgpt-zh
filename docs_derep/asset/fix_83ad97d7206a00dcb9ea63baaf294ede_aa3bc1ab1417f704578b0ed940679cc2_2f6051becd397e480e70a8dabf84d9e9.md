# 玩转数据预处理：从指标校准到变量筛选的硬核实战

在推荐与预估工程里，原始输入往往不能直接喂给算法。我们得先给比率类数值“去水分”，再把数值类字段“拉到同一起跑线”，接着通过组合挖掘复杂模式，最后按价值排序精简输入。这套“组合拳”能显著提升线上效果。

---

## 一、 给比率指标“去水分”：小样本不敢信，数学来兜底

点击率、转化率这类比率，最怕分母太小。新物品才曝光几十次就来个点击，比率看着高，实则靠不住。必须用统计手段给小样本“打折”，给大样本“背书”。

### 1. 区间下界法：求稳不求准

核心思路是算出一个可信范围，**工程上直接取范围下限作为校准值**，相当于给不可靠的高估值“打折扣”。

**实战对比**：
| 物品 | 曝光量 | 原始比率 | 95%可信范围 | **校准后比率(下限)** |
| :--- | :--- | :--- | :--- | :--- |
| A | 1000 | 3% | (0.021, 0.042) | **2.1%** |
| B | 300 | 3% | (0.016, 0.056) | **1.6%** |
| C | 100 | 3% | (0.010, 0.085) | **1.0%** |

**结论**：原始值全是3%，校准后曝光越少折扣越狠。**所有概率、比值型数值均适用此法。**

### 2. 先验混合法：引入全局观，公式更轻快

思路直观：把当前物品的表现，跟“全局平均水平”（先验）做加权融合。

**公式定义**：
[PRE0]

*   $m, n$：当前物品的点击数、曝光数。
*   $a, b$：先验超参，实战常取**同品类总点击数、总曝光数**。

**PK 区间下界法**：
*   **优势**：公式极简，算得飞快，极易落地。
*   **劣势**：需人工调超参 $a, b$，不同场景敏感度不同，得反复跑实验调优。

## 二、 统一度量衡：让所有输入站在同一起跑线

为什么要处理？两大痛点：
1.  **单位冲突**：“用户年龄(0-100)”对“商品价格(0-10000)”直接加权，价格会彻底压制年龄。
2.  **下降路径跑偏**：训练时，大量级输入主导下降方向，导致来回摆动、收敛慢。

### 1. 最小最大缩放 —— 压缩进 [0, 1] 区间

[PRE1]

*   **优点**：边界固定，便于后续处理（如作为权重输入）。
*   **致命伤**：**极不抗干扰**。一个极端噪点（极大/极小值）会挤压绝大多数正常样本到极窄区间。
*   **工程对策**：按分布做分位数切顶（如 1%-99%），或对结果做平滑。

### 2. 零均值单位方差缩放 —— 映射成标准正态 (中心0，波动率1)

[PRE2]
即经典的 **标准分**。

*   **优势**：受噪点影响相对较小；无上下界，适合假设服从正态的算法（如LR、NN）。
*   **本质**：两者都是**仿射变换（压缩+平移）**，核心目的一致——**消除单位与量级差异，加速收敛**。
*   **选型建议**：没银弹，**跑离线实验看AUC** 决定用哪个。

## 三、 变量组合：显式构造复杂模式记忆

单一输入是“点”，组合后是“面”甚至“体”。核心作用：**将原始空间映射到高维，实现非直线划分**，类似核方法思想。

### 业务价值：颗粒度更细，捕获深层关系
*   `性别 x 城市 x 职业` → 精准刻画“一线城市女性程序员”群体。
*   `用户ID x 物品类目` → 直接建模用户对特定品类的偏好（协同味儿）。

### 三大主流算子（假设向量 $X=[x_1, x_2], Y=[y_1, y_2]$）

| 算子 | 操作 | 输出示例 | 列数变化 | 别名/含义 |
| :--- | :--- | :--- | :--- | :--- |
| **求和压缩** | 对位相乘求和 | $Z_1 = [x_1y_1 + x_2y_2]$ | **1个单值** | 压缩信息，建模“整体匹配度” |
| **对位相乘** | 对位相乘 | $Z_2 = [x_1y_1, x_2y_2]$ | **等于向量维数** | **匹配型变量**，保留各维度独立匹配信息 |
| **全排列组合** | 两两穷举 | $Z_3 = [x_1y_1, x_1y_2, x_2y_1, x_2y_2]$ | **维数相乘** | 表达力最强，挖掘所有同时出现模式 |

> **连续值输入**需先**分箱/向量化**，再做组合。

### 实战对比：以 `用户性别 x 物品适用性别` 为例

| 组合方式 | 样本1 (男推男) | 样本2 (男推女) | 业务含义解读 |
| :--- | :--- | :--- | :--- |
| **求和压缩** | `[1]` | `[0]` | 只有“是否匹配”一个信号，无法区分男/女差异。 |
| **对位相乘** | `[1, 0]` | `[0, 1]` | 拆解为“男匹配”、“女匹配”，算法能学到性别差异。 |
| **全排列组合** | `[1,0,0,0]` | `[0,1,0,0]` | 细分为“男男”、“男女”、“女男”、“女女”，**非直线表达最强**。 |

### 避坑指南：列数暴涨 & 泛化失效
*   **全排列组合最猛，也最危险**：输入规模指数级增长，极易死记硬背，工程存储/计算压力大。
*   **工程妥协**：高基数输入（如ID）向量化后做求和压缩；低基数类别输入做全排列组合。

### 显式构造 vs 隐性学习（算法自动交互）
*   **FM/DNN 确实能自动组合**：FM显性建模二阶，DNN靠多层非直线隐性拟合。
*   **为何还要人工干预？**
    1.  **突破阶数限制**：FM通常只做二阶，高阶靠人工预组合再喂给FM。
    2.  **可解释性与泛化**：DNN组合是黑盒，可能学到虚假关联；人工组合带业务先验，**显性先验 + 隐性学习 = 最强组合**。

## 四、 变量价值排序：精简输入库，指导迭代方向

输入越多越好？错。**噪音输入拖累训练、推理延迟高、死记硬背风险大**。价值评估两大流派：

1.  **留一法 (LOO)**：看“少了你算法掉多少分”。
2.  **内在判别力法**：看“你自己能不能分清正反例”（如 IV、信息增益）。

### 1. 沙普利分账法：博弈视角的“公平分钱” —— 留一法巅峰

简单留一法（全集减一）有盲区：若输入A是“万金油”，去掉它算法跌得惨；但若输入B是“关键配角”，只有配合C才有用，单独去掉B看不出贡献。

**核心思想**：遍历**所有输入排列搭配**，计算输入 $i$ 加入任意子群 $S$ 带来的增量价值期望。

[PRE3]

*   $v(\cdot)$：输入集对应的算法指标（AUC/Logloss）。
*   权重系数：保证每种子群规模被公平抽样。

**经典比喻**：
4种食物，3种各补1种维生素，第4种**全补**。简单留一法：去掉任意一种，剩下3种都能活 → 价值全一样（不公平！）。沙普利法：第4种食物在所有子群中增量价值最大 → 价值最高。**完美识别“万金油”与“配角”输入。**

**算力瓶颈**：指数级复杂度 $O(2^n)$，跑不动。

**工程解法：随机模拟近似** —— 随机打乱输入顺序，构造“含/不含该输入”样本对，估算增量价值均值。几千次抽样即可收敛，已广泛落地。

[PRE4]

### 2. 信息量指标 (IV) & 证据强度指标 (WoE)：风控界“黄金标准” → 推荐系统

**前置条件**：输入已分箱、补齐空值、任务为**二元判别**。

#### Step 1：算 WoE —— 单箱辨识度
$$ \text{WoE}_i = \ln \left( \frac{\text{该箱坏样本占比}}{\text{该箱好样本占比}} \Big/ \frac{\text{全局坏样本占比}}{\text{全局好样本占比}} \right) $$
*   **物理意义**：后验判断对先验认知的**对数修正幅度**。
*   $|\text{WoE}|$ 越大 → 该分箱区分正反例能力越强。
*   正负号表示正向/负向相关。

#### Step 2：算 IV —— 输入整体判别力
$$ \text{IV} = \sum_{i} \left( \text{该箱坏样本占比} - \text{该箱好样本占比} \right) \times \text{WoE}_i $$
*   本质：各分箱 WoE 的**加权和**，权重是该箱正反例分布偏离全局的程度。
*   **IV 恒 $\ge 0$**。

#### 经验判读阈值（业界通用）：
| IV 区间 | 解释 |
| :--- | :--- |
| $< 0.02$ | 无用输入，直接丢 |
| $0.02 \sim 0.1$ | 弱判别力 |
| $0.1 \sim 0.3$ | 中等判别力，**主力输入多在此** |
| $0.3 \sim 0.5$ | 强判别力 |
| $> 0.5$ | **疑似带入答案/死记硬背**，需排查 |

**优势**：可解释性极强（能看到每箱贡献）、算得极快、天生处理非直线（分箱后单向/非单向均可）。

### 3. 挤压激励模块：深度网络里的“输入加权聚焦”

在向量层之后、全连接层之前，插入 **SE 结构**：

1.  **压缩**：全局均值池化压缩空间维，得字段级描述符。
2.  **激励**：两层全连接 + ReLU + Sigmoid，学习每个输入的**关键度权重 $w \in (0,1)$**。
3.  **重缩放**：原始向量逐通道乘以 $w$。

**效果**：算法**显性、动态**地学习“当前样本下哪个输入关键”，并加权参与后续交互。比静态的 IV/沙普利更灵活，是深度网络内部的“变量筛选器”。

## 总结：数据预处理“组合拳”打法建议

| 阶段 | 核心动作 | 推荐工具 |
| :--- | :--- | :--- |
| **清洗/校准** | 比率指标小样本打折 | **区间下界法(稳健)** / **先验混合法(高效)** |
| **统一度量** | 消除单位/加速收敛 | **零均值单位方差(首选)** / **最小最大缩放(需切顶)** |
| **关系挖掘** | 显性建模非直线组合 | **低基数全排列** + **高基数向量化求和** |
| **精简筛选** | 离线评估输入价值 | **IV指标(极速初筛)** + **沙普利采样(核心精排)** |
| **动态加权** | 网络内部自动学权重 | **SE模块 / 注意力机制** |

数据预处理没有标准答案，只有**“业务先验指导显性构造 + 算法能力补全隐性交互 + 价值分析驱动迭代闭环”**这一套经过验证的工程方法论。
