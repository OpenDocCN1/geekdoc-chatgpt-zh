先看英文语料的常规处理思路。常用的做法是先把链接去掉，再把非字母数字的字符替换为空白，随后把连续的空白压缩成一个，最后去掉首尾多余的空白。下面的实现把这几步串起来了。

[PRE1]python

import re

# 定义示例文本

texts = [

    "Hello! This is a sample text with symbols #@! and numbers 1234.",

    "Natural Language Processing (NLP) is exciting!!!",

    "Let's clean up this text: remove symbols & extra spaces."

]

# 清洗函数定义

def clean_text(text):

    """

    清洗文本中的特殊字符和标点符号

    参数:

    - text: str, 需要清洗的文本

    返回:

    - cleaned_text: str, 清洗后的文本

    """

    # 移除URL

    text = re.sub(r"http\S+|www\S+|https\S+", '', text, flags=re.MULTILINE)

    # 移除特殊字符和多余的标点符号

    text = re.sub(r"[^a-zA-Z0-9\s]", " ", text)

    # 替换多重空格为一个空格

    text = re.sub(r"\s+", " ", text)

    # 去除首尾空格

    text = text.strip()

    return text

# 对文本数据进行清洗

cleaned_texts = [clean_text(text) for text in texts]

# 输出结果

for i, text in enumerate(cleaned_texts):

    print(f"原始文本: {texts[i]}")

    print(f"清洗后文本: {text}\n")

运行后的对照能很直观地看到变化，感叹号、井号、括号、& 等都被过滤掉，数字保留下来，语义主干得以保留。

texts = [

针对中文的特点，策略做了两点扩展：一并清理链接和邮箱，二只保留中英文字符、数字与空白，其余全部替换。

import re

# 定义超长中文文本清洗函数

def clean_chinese_text(text):

    """

    清洗中文文本中的特殊字符和标点符号

    参数:

    - text: str, 需要清洗的中文文本

    返回:

    - cleaned_text: str, 清洗后的文本

    """

    # 移除URL和邮箱地址

    text = re.sub(r"http\S+|www\S+|https\S+|[a-zA-Z0-9._%+-]+\s*/\s*@[a-zA-Z0-9.-]+\.[a-zA-Z]{2,}", "", text)

    # 移除非中英文字符和数字

    text = re.sub(r"[^a-zA-Z0-9\u4e00-\u9fff\s]", " ", text)

    # 替换多重空格为一个空格

    text = re.sub(r"\s+", " ", text)

    # 去除首尾空格

    text = text.strip()

    return text

# 应用清洗函数

cleaned_texts = [clean_chinese_text(text) for text in texts]

# 输出清洗结果

for i, text in enumerate(cleaned_texts):

    print(f"原始文本:\n{texts[i]}")

    print(f"清洗后文本:\n{text}\n")

把预处理做到位，模型收到的就是干净且一致的输入。损失下降、准确率拉满，往往就源于这一步看似基础却决定性的净化工作。
