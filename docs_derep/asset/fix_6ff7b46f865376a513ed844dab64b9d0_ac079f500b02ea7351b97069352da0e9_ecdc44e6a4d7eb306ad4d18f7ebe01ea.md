# 目标先行，演讲才有分量

演讲的泛主题也就是它所归属的大版块，比如食品安全、环境保护、领导力，一个版块下面往往分出许多具体议题。一个足够清晰的大方向目标，会从准备到呈现全程指引路径，帮助你在现场把最关键的信息讲透，并在听众心里留下持续影响。

借助下面思路，你可以把自己的大目标梳理得更明确、更有穿透力。它会告诉你如何制定一个能够触达目标人群、提升他们对议题认知深度的目标。记住，大方向目标要有深度，要能牵动情感与认知。当目标足够清晰时，演讲的能量自然会被放大，更容易达成预期效果。

**2. 用细分目标把内容与表达落实**

细分目标聚焦在演讲的具体操作层面，涉及讲什么、听众应带走哪些明确知识点、采用何种技术与手法。以食品安全演讲为例，说明如何借助 ChatGPT 细化细分目标。

（1）案例拆解：围绕食品安全的演讲
假设你是一位从事食品研究的专家，在大方向目标确定之后，需要进一步细化内容。我们依然沿用角色定义、供给背景、明确任务、任务细则、输出格式的提问框架来构建指令。

①构建提问的步骤
●角色定义：把 ChatGPT 定位为你的“演讲顾问”。如此它会更集中在目标设定、内容搭建、风格选择等演讲相关工作。
●供给背景：交代演讲者的身份、听众画像、演讲的大主题以及已确定的大方向目标及其具体表述。
●明确任务：把要完成的事情说清楚，即“制定演讲的细分目标”。
●任务细则：在任务之上进一步细化需求，例如“厘清要覆盖的子主题、听众应获得的具体知识点”。
●输出格式：说明你希望得到的形式，例如“列出具体的细分目标，并给出风格和表达方式的建议”。

②完整提问示例
你现在是我的演讲顾问。我是一名食品科学家，准备在一次面向大众的演讲场合中谈食品安全的议题。我需要你的帮助来进一步细化我的演讲内容。我已经设定了总体目标，即激发公众对食品安全的兴趣，增强其食品安全意识并促使他们采取积极的行动，以保障自己和社区的食品安全。

现在，我希望我们能一起确定演讲的微观目的。我希望你能帮助我明确要涵盖的主题，以及我希望听众从演讲中获取的具体信息。此外，我也需要你的建议来决定我的演讲风格和方式，以便我能以最有效的方式传达我的信息。请提供具体的微观目的，并解释为什么这些目的会对我的演讲有所帮助。
