# AI上战场，伦理账怎么算[^(\[1\])](#chapter014.html#m1)

徐英瑾[^(\[2\])](#chapter014.html#m2)

**摘要：**学界对把人工智能推向军事领域的伦理后果普遍存在三大担忧，一是钻现有军控规则的空子加速武器扩散，二是杀伤门槛被拉低导致平民伤亡上升，三是冲击战士群体应有的职业操守。文章指出这些批评多在传统作战平台与智能化平台之间采取双重衡量，并把智能武器对全球安全的改变作用夸大。要让军用人工智能的伦理影响与当代价值相契合，关键不在于一刀切叫停研发，而在于能否让设备具备接近人类的伦理推理能力。研发推进中，如何处理各向同性问题也将成为绕不开的重点。

**关键词：**军用机器人 人工智能 伦理学 各向同性 心灵状态指派

## 导论：算法开火后的责任归属

一般而言，人工智能被理解为通过编程让机器在行为表现上逼近人的聪明。对智能的判定标准学界尚无统一，但共识是成熟的系统应该在人类干预很少的情况下，按照使用者设定的目标，在特定环境里自主完成任务。一旦实现，这类技术对人力在生产中的位置会形成传统机械难以比拟的冲击，不仅挤压体力岗位，也会动摇以信息创造为核心的脑力岗位。与以通信为主的传统信息技术只负责传递信息不同，理想状态下人工智能平台本身就是新信息的生产源。

现阶段人工智能远未到全面替代人力的程度，但在兵力吃紧、人力稀缺的场景里需求非常迫切，部分试验性运用已在展开。沃勒克与艾伦合著的《道德机器：如何教会机器人辨明是非》[^(\[3\])](#chapter014.html#m3)第三章把人工智能最具潜力的三个方向归纳为军用机器人、性爱机器人和工业机器人。三种用途都带伦理张力，其中军用系统的争议最尖锐，因为其核心任务与杀伤直接相关，也触及军事暴力的正当性边界。美国空军退役上校、现任塔尔顿州立大学哲学与宗教教师哈尔嘎斯[^(\[4\])](#chapter014.html#m4)曾这样概括：

军事冲突的语言即关于辩护（justification）的语言。军事冲突造成人员的死亡以及财产的受损，并造成各种形式的可以想象的大量伤害。不给理由就去做这些事情是疯狂的。不过，即使有了理由去做这些事情，如果同样的目标可以通过更少的人员与财产损失来达到，那么，相关的军事行动还是无法得到辩护。

这段话强调军事行为可分为可辩护与不可辩护，若战争本身正当，其附带破坏在伦理上或可被容许，但论证具体行动的正当性门槛很高，需要证明其损害收益比为可选项中的最低。军事行动正当性的争论由来已久，人工智能的加入会在多大程度上改写问题？

变化主要体现在操作层与观念层两个维度。先看操作层。假若开火、拦截等关键决策交给机器自主执行，责任如何落定就会变得模糊：人类指挥官失误可被军事法庭追究，机器人战士出现错误时该如何归责？现行法律框架对此尚无清晰安排。
