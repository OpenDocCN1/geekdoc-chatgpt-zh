## 核心机制：`while` 循环的运作逻辑

`while` 循环的运行遵循固定的三步走流程：
首先，程序会**求值条件表达式**；
接着，若结果为**真**，判定循环条件成立，执行循环体内的代码块，随后**回溯至第一步**重新求值；
最后，若结果为**假**，循环终止，程序流程跳转至 `while` 结构之后的后续代码继续执行。

这种循环往复的机制在流程图（图 9-5）中有直观体现。

### 语法细节与避坑指南

1.  **单行简写**：当循环体仅包含单条语句时，可参照 `if` 语法，将语句与 `while` 写在同一行。
2.  **缩进块规范**：循环体由多条语句构成时，**必须**依靠统一的缩进层级组成代码块，否则会抛出语法错误。
3.  **死循环风险**：若条件表达式恒为真，程序将陷入无限循环，需在循环体内设置明确的退出机制。

## 结构嵌套：循环中的循环

若循环体内完整包裹另一个循环，即构成**循环嵌套**。`while` 与 `for` 可任意交叉嵌套。

**两大铁律**：
1.  **变量隔离**：内外层控制变量命名必须不同，防止逻辑混淆。
2.  **结构闭合**：嵌套不得交叉，内层循环必须完整包含在外层循环体内。

## 流程干预：`break`、`continue`、`pass` 与 `else`

当需要打破常规节奏时，这四大语句登场。

### 1. `break` 与 `continue`：主动控制权

| 语句 | 作用域 | 效果 |
| :--- | :--- | :--- |
| **`break`** | `for` / `while` | **强制终结**当前层循环，跳转至循环外后续代码。嵌套时仅跳出所在层。 |
| **`continue`** | `for` / `while` | **跳过本轮剩余代码**，直接进入**下一轮**迭代判断。 |

### 2. `pass`：占位符

语法上需要语句、逻辑上无需操作时使用，如“空循环体”占位。

```python

    pass  # 单纯循环 100 次，不做任何事
```
