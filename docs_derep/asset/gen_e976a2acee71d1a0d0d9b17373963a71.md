### 1.10 如何让它记住你，成为专属助手

OpenClaw 装好、模型配好、能对话了，但你会发现它“记性不好”——每次都要重复背景、解释需求、提醒之前的事。这像招了个新员工，能干活但完全不了解你的习惯和项目。本节讲怎么让它积累记忆。

#### 1.10.1 记忆原理：靠磁盘文件，不是靠模型脑补

很多人以为 AI 记忆存在模型脑子里，用久了自然记住。这是误解。OpenClaw 的长期记忆不是模型自己记，而是工作区里的 Markdown 文件。

官方文档表述很清楚：OpenClaw memory is plain Markdown in the agent workspace. The files are the source of truth; the model only “remembers” what gets written to disk。翻译过来就是：记忆是磁盘上的纯文本文件，文件才是真相，模型只能记住写进磁盘的内容。

好处是记忆可见、可编辑、可备份。你随时能打开 Markdown 文件看它记了什么，也能手动修改或删除。不像某些系统，记忆是黑盒。

#### 1.10.2 工作区里要关注的关键文件

工作区有大量 Markdown 文件，新手重点了解这几个：

##### USER.md：关于你的档案

存关于用户的结构化信息，包括称呼、偏好、工作习惯、人际关系等。新工作区默认就会创建 USER.md 等 starter 文件。

适合写相对稳定的个人信息，比如：

- 想被怎么称呼
- 工作领域和背景
- 沟通偏好：简洁还是详细
- 时区和作息

##### MEMORY.md：长期记忆精华

可选的长期记忆文件，不会自动创建。官方说它是 curated long-term memory，仅在 main 和 private session 加载，不在群聊等共享上下文加载。

适合记长期决策、项目背景、反复提到的人和事、长期目标和约束。官方模板建议记录：durable facts, preferences, decisions, constraints, open loops，即持久事实、偏好、决策、约束、未完成任务。

##### memory/YYYY-MM-DD.md：每日对话日志

按日期自动生成的对话日志，比如 `memory/2026-03-11.md`。官方建议 session 开始时读取今天和昨天的日志，帮助保持短周期上下文连续。

该文件只追加不修改，长期下来就是你和 OpenClaw 的完整互动历史。

##### AGENTS.md 和 SOUL.md：身份与人格

AGENTS.md 定义行为规则、回复风格、工作原则；SOUL.md 定义不可变人格内核，决定它“是谁”。

虽然不直接记录关于你的信息，但决定了互动方式。比如在 AGENTS.md 写“用户有技术背景，可直接说术语”“回答要简洁，除非用户要求详细”，它就会按此沟通。

#### 1.10.4 记忆系统的几个关键细节

细节一：私聊和群聊记忆分开。MEMORY.md 只在 main/private session 加载，绝不在群组上下文加载。这是隐私保护：你在私聊里说的个人信息不会自动暴露到群聊。

细节二：记忆文件是纯文本，可备份。用 Git 管理、定期备份、在不同机器间同步都方便。比云端黑盒记忆更可控。

细节三：记忆不是越多越好。文件过长每次对话都要加载，会占用上下文窗口，增加 token 消耗。建议定期清理过时信息，提炼核心，保持质量。

#### 1.10.5 新手入门三步走

第一步：完善 USER.md。花 10 分钟把基本信息、工作背景、沟通偏好写进去，这是认识你的第一步。

第二步：在对话中主动要求记忆。遇到重要信息时明确说“记住这个”，它会自动录入 MEMORY.md。

第三步：定期回顾每日日志。每周或每月看一次日志，把有价值内容提炼到 MEMORY.md。

做好这三步，一个月后你会明显感觉它懂你了，不用反复说明背景偏好，能记住上次说过的事，并按习惯调整回复。

这种越用越懂的感觉，正是 OpenClaw 与“用完即忘”的聊天工具的区别。它更像有记忆、有学习能力的真正助手。
