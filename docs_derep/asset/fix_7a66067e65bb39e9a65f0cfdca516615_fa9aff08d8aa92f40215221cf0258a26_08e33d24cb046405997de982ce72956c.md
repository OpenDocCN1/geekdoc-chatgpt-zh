# 结语 与人工智能共处

[PRE0]

前面的章节已经把AI制造出人意料的情形展示得相当充分。

当任务有明确目标却留有实现空间时，系统往往会迸发出连编写者都想不到的解法。譬如只要从A点到B点，它可能先把自己堆成一座小塔再从上头摔下来；也可能原地绕圈、用身体摩擦地面来凑进度。在仿真环境里训练，它会主动寻找裂缝，利用物理规则的空子攒出近乎超能力的表现。对指令的解读异常字面：被要求别撞击就干脆不动；被要求别输掉游戏，它就点开暂停键无限卡住。它能从数据里淘出隐蔽的关联，有时是程序员未曾察觉的模式，其中也夹杂着我们不愿学习的偏见。多个模块串联使用，像一部塞满App的手机，也像一群协作的蜜蜂，能够合力解决单个模型单独面对时无能为力的难题。

能力在上升，理解却仍有限。它始终在努力达成我们想要的结果，可内心期待和写下的指令之间总存在缝隙。它会不会在有生之年变得像人一样理解世界甚至超越人类？目前看不到。更贴近现实的风险并不是太聪明，而是太不聪明。

从表层看它似乎更懂了：能生成逼真的画面，甚至渲染整部电影的分镜，能在我们丢给它的游戏里持续取胜。但归根到底仍是模式匹配，只认识出现频率足够高的数据，认识有限。

真实世界过于复杂、不可预测且怪诞，训练所见不可能覆盖全部。鸸鹋可能突然冲出来，小朋友可能穿着蟑螂服装上街，有人会问长颈鹿的问题而图里根本没有长颈鹿。缺乏背景常识的模型因此会误会意图。

要把AI用好，先要读懂AI：挑它擅长的问题、预判它会如何误读、阻断它从人类数据里复制来的糟糕部分。对AI既有乐观的理由也有谨慎的理由，区别在于使用方式。

顺带提醒，多留心藏在角落里的长颈鹿。
