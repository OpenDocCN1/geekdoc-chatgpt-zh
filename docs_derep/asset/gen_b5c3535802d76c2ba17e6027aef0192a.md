基尔霍夫定律与拓扑约束

KCL 反映的是电荷在集总参数电路中的守恒表现，KVL 则同时蕴含了能量守恒与电荷守恒在集总电路中的作用。二者分别给出支路电流的相互制约关系和支路电压的相互制约关系。这种制约只与电路的连线方式即拓扑结构有关，而与具体接在支路上的元件类型无关。无论支路是电阻、电容、电感还是电源，无论文件是线性还是非线性，KCL 与 KVL 的形式保持不变。

当电路拥有 `b` 条支路和 `n` 个节点时，二者之间存在固定的数量关系：

（1）真正独立的节点数为 `n-1`。
（2）最多可写出 `n-1` 个线性无关的 KCL 方程。
（3）可写出 `L` 个线性无关的 KVL 方程，其中 `L = b - (n-1) = b - n + 1`。

#### 1.3.2 含独立源电路的等效转换

#### 1. 理想电源

##### 1） 电压源

理想电压源是对实际电源的抽象，理想情况下无损耗，具有两点特性：

（1） 端电压恒为 `US` 或为时间函数 `uS(t)`，与流过电流无关。电流为零时仍保持 `US` 或 `uS(t)`。

##### 2） 电流源

理想电流源是另一种电源抽象。电流源能向端口提供恒定电流，与端电压无关。在特定照度下光电池产生的电流与照度成正比，可据此定义理想元件。电流源具有：

（1） 输出电流为定值 `IS` 或 `iS(t)`，与两端电压无关。电压为零时电流仍为 `IS` 或 `iS(t)`。
（2） 电流由电源本身决定，端电压随负载变化。

### 1.4 直流电路及基本分析法

#### 1.4.1 支路电流法

支路电流法以各支路电流为变量，利用 KCL、KVL 及元件关系列方程求解。其步骤为：

（1）确定各支路电流参考方向。
（2）选取 `n-1` 个独立节点，列 KCL 方程。
（3）选取 `b-(n-1)` 个回路，标定绕行方向，列 KVL 方程。
（4）联立求解得 `b` 个支路电流。
（5）计算其他待求量。
