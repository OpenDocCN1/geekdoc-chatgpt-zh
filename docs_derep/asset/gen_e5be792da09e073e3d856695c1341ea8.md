##### 3. 设置 Supabase 存储
存储侧主要做两件事：建桶和配策略。

- **新建存储桶：** 进入 Supabase 控制台的 Storage 页面，点击新建桶按钮，把桶名填为 user-images，权限选择公开读取，这样桶里的文件可以被公开访问，最后点创建完成。
- **配置访问策略：** 桶建好后要限制读写范围。用控制台的 SQL 编辑器执行策略语句，实现两点：用户只能向以自己 ID 为名的专属文件夹上传文件；用户只能查看自己文件夹内的内容。
