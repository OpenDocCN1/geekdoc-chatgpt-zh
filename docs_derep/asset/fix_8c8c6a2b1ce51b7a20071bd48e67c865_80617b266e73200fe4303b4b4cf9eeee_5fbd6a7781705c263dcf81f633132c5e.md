1. **预期收益率**：估算各方案在特定周期内可能带来的回报幅度，明确收益预期。
2. **风险与波动**：衡量回报的波动区间，通过波动范围评估风险高低。
3. **夏普比率**：计算风险调整后的收益表现，看在相近风险下谁更划算。
4. **净现值 NPV**：把未来现金流折到当下，判断项目是否创造净收益。
5. **内部收益率 IRR**：求出使净现值为零的折现率，用来衡量年化盈利能力。
6. **回本周期**：估算收回初始投入所需时间，反映资金周转速度。
7. **现金流形态**：梳理各方案的流入与流出，掌握资金节奏。

# 第7章 各类财务报告制作自动化
