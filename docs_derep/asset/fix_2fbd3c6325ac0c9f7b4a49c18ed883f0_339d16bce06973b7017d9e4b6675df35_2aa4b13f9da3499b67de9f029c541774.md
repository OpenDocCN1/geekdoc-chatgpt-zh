<|begin_of_sentence|>请问如何证明根号2是无理数？我记得这个证明要用到无限下降法，或者说归谬法，但具体的步骤我还不太清楚。

模型给出的推导沿着归谬思路展开。首先把无理数的含义界定为不能写成整数比，随后假设 √2 可写成最简分数 p/q。平方化简得 2q² = p²，可推出 p 为偶数，记 p = 2k 代入即得 q² = 2k²，从而 q 也为偶数。这与 p/q 最简的预设冲突，说明初始假设不成立。进一步可形成不断变小的正整数解序列，在自然数里不可能无限递减，于是 √2 必然是无理数。

[PRE4]

更紧凑的写法如下。设√2 = p/q 且 p、q 互素。

\[ 2 = \frac{p^2}{q^2} \]

去分母得：

\[ 2q^2 = p^2 \]

于是 p² 为偶数，p 必为偶数，记 p = 2k。

代入得：

\[ 2q^2 = (2k)^2 = 4k^2 \]

化简：

\[ q^2 = 2k^2 \]

故 q² 也是偶数，q 必为偶数。p、q 同时含因子 2，与互素前提矛盾。证毕。
