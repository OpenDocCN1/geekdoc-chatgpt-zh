夜色里暴雨倾盆，豪华酒店正门前红色的婚车忽然急刹。车门被猛地扯开，继妹林薇薇妆容靓丽地站在台阶上，居高临下把苏晚一掌推进泥泞。

林薇薇语气尖刻：“苏晚，你当真以为能进傅家？新郎是我未婚夫，你不过是顶替上来的弃子。”

苏晚狼狈从地上爬起，婚纱沾满污泥，眼神却冷硬如刃。观众会心疼她，更能读出女主不肯吃亏的立场。

【50～60 秒｜钩子结尾】

傅斯年伸臂将苏晚横抱，迈步走向红毯，俯身在她耳边低语。

傅斯年声音带宠溺也带不容置疑：“自此刻起，你是我傅斯年明媒正娶的妻子。谁碰你，我让他付出代价。”

画面定格在他吻向她额头的瞬间，全场灯光聚拢，苏晚心跳失控。

字幕浮现：错嫁？实则是顶级霸总早已布好的局。

把人设提前设定给模型并给出清晰创作要求，两份对比答案的质量差异很明显，前者更专业也更细腻。

小窍门：甚至可以为模型赋予一种性格标签，比如“你是个毒舌爱反套路的编剧”，产出的风格会更有辨识度。

第二条法则 框架化提示——给模型一个骨架
没有框架的模型容易写成散文，用明确的格式限制输出，就能按意图填充内容，降低理解偏差。

> 【通用搭建模板】
你是一名有十年从业经历的爆款短剧编剧，擅长高密度爽点，请为我设计一个短剧开篇。
1. 剧种与名称
2. 角色卡：姓名、年龄、性格、秘密
3. 核心冲突：用一句话概括
4. 前三集梗概：每集包含开场钩子、推进、结尾悬念

第三条法则 范例引导——给模型一个参照
纯靠文字描述很抽象，直接给样本更直观。模型模仿力强，一个优质例子就能迅速抓住语感与结构。

> 问：
请参照下面爆款开场的风格，创作相似开场：
【范例】“结婚三年，他从未正眼看我。今天，他跪在我面前，求我救他白月光的命。”
要求：第一人称，强反转，一句话信息量大。

得到的结果示例：
开场1：我当了他三年隐形情人，他说我不够体面。如今他捧着戒指向我求婚。
开场2：他亲手把我送进监狱，说我害了他全家。三年后他带资产跪在牢门口求原谅。
开场3：我以为自己只是他手中的棋子，连名字都不配被记住，直到他为救我押上整个商业帝国。

范例引导还能叠加风格，例如提供两三个不同调性的样本让模型融合创新，也可以用反面案例标明不可写的写法。

> 【模板】
请结合示例A的悬念感和示例B的甜度，创作新开场：
示例A：她推开房门，床上躺着陌生男人，手里握着她的照片。
示例B：他假装不经意碰到她的手，耳根却红了。

> 【模板】
请避免类似拖沓开场：醒来洗漱吃早餐去上班……前30秒无冲突，观众早划走了。

第四条法则 迭代优化——对话式创作
新手常期待一次生成完美，结果往往失望。模型是辅助工具，需要引导。创作本质是迭代，模型能快速根据反馈调整。

- 初稿：给一个宽泛指令，让模型自由发挥。
- 指出问题：明确不满意点，如“太啰嗦，压缩到30字内”“反转太平淡”。
- 要求修改：要三个更出人意料版本，或加入眼神、手部动作等细节。
- 再优化：效果仍差距就重复第2-3步。

第五条法则 约束条件——划定边界
模型有时会发散过头。提前设限就像画红线，保证输出可控。常见约束：
- 字数限制：“每集90秒，台词不超过8句”“开篇控制在30字内”。
- 风格限制：“土味爽文，口语化，多用网络热梗”“文艺电影质感，台词含蓄留白”。
- 内容禁忌：“不要穿越重生超能力，要纯现实”“不要出轨情节，价值观正向”。
- 平台适配：“适合抖音快手的竖屏，前3秒必须强钩子，字幕放大”“适合海外平台，需考虑当地接受度，避免中国特有梗如赘婿、神医”。

分步骤引导生成技巧
技巧一：从宏观到微观，先搭骨架再填血肉。
第一步要大纲，第二步要分集，第三步要细节。

技巧二：从发散到收敛。创意阶段要多，筛选阶段要精，先让模型量产，再由创作者优中选优。

技巧三：多轮对话示例。以古装穿越为例，先要10个钩子，再选其一扩展成画面加台词，再优化女主态度，最后基于开场写前三集大纲。

3.2 故事结构设计
短剧是情绪密集型产品。经典三幕可调整为破局→升级→爆点。
破局阶段要3秒抓住注意，10集内养成追剧习惯，重点预埋人设冲突钩子。
升级阶段每10集一个情绪过山车，爽虐交替，重点推进冲突、深化人设、分层爽点。
爆点阶段回收伏笔释放情绪，逻辑自洽，避免烂尾，可预留开放式结局。

开篇3秒吸引法则
移动端用户注意力极短，平均停留不足10秒。开篇要无冗余、强冲击、高钩子。
六大吸睛开场类型包括冲突开场、悬念开场、反转开场、名场面开场、身份反差开场、金句开场。
