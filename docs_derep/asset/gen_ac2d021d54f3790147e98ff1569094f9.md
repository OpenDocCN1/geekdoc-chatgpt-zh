- 提升推荐体验：若模型训练在受污染的数据上，输出的候选列表容易偏离真实需求，直接拉低用户满意度。
- 增强泛化表现：经过清洗的数据更贴近真实行为和商品属性，模型才能在多场景下保持稳定输出。

###### 4. 常用的噪声过滤方法

- 去重处理：借助唯一性校验剔除重复条目。例如用户浏览日志，可用用户 ID 与商品 ID 的组合作为判重键。
- 缺失值补齐：对空字段采用合理默认值或统计量填补，如均值、中位数。例如用户年龄缺失时，可用同群体平均年龄替代。
- 无意义内容剔除：利用规则或机器学习模型筛掉价值低的内容，比如仅由标点构成的评论、乱码或噪声字符。

###### 5. 案例分析：电商平台中的数据噪声和异常

1. 重复浏览记录：某用户在 1 分钟内反复点击同一商品，并非真实高兴趣，更可能是网络波动或误触。去重可避免此类噪声对模型造成过度影响。
2. 异常价格记录：某商品价格被录入为 0 元，明显不合理，通常是录入失误。通过设定上下限规则即可快速过滤。
3. 离群用户行为：某用户单日下单上千件，严重偏离常规购买模式，可能是批发操作或数据录入错误。

#### 2.2 用户画像与物品画像的构建

用户画像与物品画像是实现精准个性化推荐的基础，通过提炼用户兴趣与物品特征，能够清晰刻画需求与属性的匹配关系。

本节聚焦于如何基于行为数据构建用户兴趣特征，以及如何用嵌入向量技术抽取物品核心特征，为召回与排序提供关键支撑。

##### 2.2.1 用户兴趣特征生成

用户兴趣特征生成是推荐系统的核心任务，旨在从行为数据中提炼特征，真实反映用户的偏好与需求，从而给出个性化推荐。可视为把杂乱的行为转化为可解释的兴趣模型。

###### 1. 什么是用户兴趣特征

用户兴趣特征是对偏好的量化表达，用以衡量用户在一定时间内对特定商品、类目或内容的关注程度。可显式体现，如对某商品的点击次数；也可隐式挖掘，如通过行为模式推断价格敏感度。

兴趣特征好比行为画像，显性信息直接写在画像上，如“偏爱电子产品”；隐性信息则需分析后得出，如“对促销敏感”。

###### 2. 用户兴趣特征的来源

特征生成依赖系统内的行为数据，主要包括：

- （1）点击行为：用户点击商品或内容的记录，如浏览日志。多次点击耳机相关商品，表明对耳机有兴趣。
- （2）购买行为：实际成交记录，属于强偏好信号。购买运动手表说明对运动类商品有需求。
- （3）收藏行为：加入收藏夹的操作，通常代表较高兴趣但未必马上购买。收藏多个智能家居产品说明关注家居科技。
- （4）时间和场景：行为受时间与场景影响，如夜间更偏向视频，节假日更关注促销。

###### 3. 如何生成用户兴趣特征

**1）统计分析**

最直接的方式是统计各维度的行为次数，形成兴趣特征。例如：

用户 A 电子产品点击 10 次
用户 A 服装点击 5 次
可判断其对电子产品的兴趣更高。

**2）加权行为模型**

为不同行为赋予不同权重，更精细描述兴趣强度。例如：

点击权重=1, 收藏权重=2, 购买权重=5
用户 A 对某商品的兴趣值 = 点击次数×1 + 收藏次数×2 + 购买次数×5

**3）时间衰减模型**

兴趣随时间衰减，对近期行为赋更高权重，久远行为权重降低。例如最近一天购买权重 1.0，上周 0.5，三个月前 0.2。

**4）嵌入技术**

利用神经网络将行为序列映射到高维空间，得到兴趣嵌入向量。可捕捉复杂模式与潜在偏好。例如序列“点击 A→点击 B→购买 C”，模型可能生成向量 [0.8, 0.1, 0.3, ...]。
