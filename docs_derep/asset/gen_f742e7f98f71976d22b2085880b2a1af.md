2. 给定一个长度为 n 且元素各不相同的无序整数数组，找出其中最大值的耗时属于（ ）。
A. O(n)
B. O(log n)
C. O(n log n)
D. O(1)

【考点识别】
提高级|4.算法|4.1 复杂度分析|【6】时间复杂度分析

【分析讲解】
要确定无序数组的最大值，只能把每个数都看一遍并做比较。
A. O(n)：正确。n 个元素都要扫描一遍，线性耗时。
B. O(log n)：错误。log 级别常见于二分查找，前提是数组有序，本题是无序。
C. O(n log n)：错误。这是排序的典型代价，找最大值不需要排序。
D. O(1)：错误。常数时间只能直接取值，最大值位置未知，必须遍历。

【参考答案】
A. O(n)

【编程魔法师讲解考点】
一、时间复杂度的意义
时间复杂度用来描述算法随输入规模 n 增长时运行时间的增长趋势。无序数组取最大值的复杂度：
1. 基本思路
逐个比较，记住当前最大值，直到全部扫完。每个元素都要被访问一次，故为 O(n)。
2. 具体分析
单次比较是 O(1)，共做 n 次，累计 O(n)。
3. 常见误区
不能套用 O(log n)：二分查找依赖有序，本题无序不可用。
不需要排序：排序是 O(n log n)，取最大值无需排序。
不可能 O(1)：最大值位置不确定，必须遍历。

二、小知识
常见复杂度从小到大：O(1)<O(log n)<O(n)<O(n log n)<O(n²)。O(n) 是线性，适用于遍历类操作。

【题目总结】
复杂度分析是信奥赛的基础能力，看清输入规模与操作次数的关系就能快速判断等级，掌握后便于评判算法优劣，养成优化思维。

3. 在 C++ 中，以下哪个函数调用会引发栈溢出（ ）。
A. int foo(){return 0;}
B. int bar(){int x=1; return x;}
C. void baz(){int a[1000]; baz();}
D. void qux(){return;}

【考点识别】
入门级|2.C++程序设计|2.9 函数与递归|【2】递归函数

【分析讲解】
A. int foo(){return 0;}：无递归、无大对象，调用后即返回，不会溢出。
B. int bar(){int x=1; return x;}：仅分配一个局部变量，安全。
C. void baz(){int a[1000]; baz();}：典型无限递归，每次调用在栈上分配 1000 元素的数组，栈空间迅速耗尽，是正确答案。
D. void qux(){return;}：无递归、无大分配，安全。

【参考答案】
C. void baz(){int a[1000]; baz();}

【编程魔法师讲解考点】
递归函数是函数自我调用的技术，威力大但易失控。

一、递归运行机制
每次调用都会在栈上建一个栈帧，保存局部变量和返回地址。
1. 有终止条件时，递归会停止并逐层释放栈帧。
2. 无终止条件或调用层数过高，栈会被占满导致溢出。

二、栈溢出的来源
1. 无限递归：例如 void f(){f();}，栈帧不断累积。
2. 栈帧过大：每次调用分配大量局部变量或数组，如 void g(){int a[10000]; g();}，即使层数不高也会溢出。

三、本题要点
选项 C 每次调用都分配 int a[1000]，并无终止条件，无限递归叠加大栈帧必然溢出。
规避办法：设置明确的终止条件，减少每次调用的栈占用，避免大数组在栈上分配，必要时利用尾递归优化。

【题目总结】
递归设计要兼顾终止条件和栈空间控制，是 C++ 核心考点，处理递归务必防溢出。
