**10.3 分支控制：switch 语句**

**10.3.1 场景故事**

乐乐超市本週又推新促销：周一至周五为常规折扣日，周六会员享双倍积分，周日则推出满减活动。收银员小乐每天结账前都要先确认星期几，才能套用正确的规则。他先用 if-else 实现了，代码又长又容易出错。今天介绍的 switch 语句就像一个分类分发器，能依据星期几迅速匹配对应促销，让逻辑更简洁、更易读、也更稳健。到底在哪些情形下 switch 会比 if-else 更合适呢？

**10.3.2 知识精讲**

**1.switch 语句的作用**

编程里当一个变量需要按不同相等取值进行多路处理时，堆叠 if-else 会让结构臃肿、可读性下降。比如按星期确定促销，若用 if-else 就得写一串条件判断。switch 专为等值多分支设计，结构更清晰，特定场景下效率更高，维护也更省心。

1）核心作用

default 用来处理 switch 表达式的值与所有 case 都不相符的情形，相当于兜底。像超市例子里输入不在 1～7 范围，就会进入 default 输出错误提示。default 可以放在任意位置，习惯上置于末尾。

**5.switch 语句与 if-else 语句对比**

1）适用场景差异
（1）switch 擅长等值多分支，依据同一变量的固定取值做不同处理时更简洁，例如按月份输出天数。
（2）if-else 更灵活，能处理范围判断、逻辑组合等复杂条件，例如区间判断或多条件与或组合。

2）选择策略
当判断基于单一变量的多个等值分支且分支较多时优先 switch；涉及区间、复合逻辑时用 if-else。实际开发中两者也可结合使用。
