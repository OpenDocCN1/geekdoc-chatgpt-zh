### 一键批量产出数字人视频的工作流搭建
在内容创作领域，传统拍片流程效率瓶颈明显：人工拍摄加后期成本高，难以支撑高频多变的输出节奏；角色形象和脚本固定，互动感和新鲜感不足。

针对这些痛点，可按下面案例步骤，把AI数字人生成能力与Coze平台深度结合，打造能自动适配场景并快速量产的数字人视频方案，具体做法如下。

（1）参照前文案例同样的方式新建一个 spoken_digital_human 工作流，如右图所示。

[PRE9]
（2）进入工作流编辑页，先加一个“循环”节点，再接入飞影数字人插件的 create_lipsync_video2 节点。在循环体内加入“选择器”“终止循环”节点，以及飞影数字人插件的 inspect_video_creation_status 节点和定时器插件的 time_wait 节点。将节点按“开始”-create_lipsync_video2-“循环”—循环体-inspect_video_creation_status-“选择器”（如果）-time_wait-循环体—“结束”的顺序串联，“选择器”另支路按“选择器”（否则）-“终止循环”连接，如下图所示。

[PRE10]
（3）打开“开始”节点配置，把 input 的变量名改为 text，点击输入右侧的 + 号新增 speaker_id、digital_human_id、hifly_id 三个变量，全部设为 String 类型，除 hifly_id 外其余两个勾选必填。text、speaker_id、digital_human_id、hifly_id 分别对应口播文案、声音ID、数字人ID、飞影ID。填写飞影ID会绑定飞影账号并消耗积分，不填则完全免费但生成更慢，因此该变量未设必填。

[PRE11]
（4）在 create_lipsync_video 节点配置里，把 digital_human_id 的变量值设为“开始 -digital_human_id”，speaker_id 设为“开始 -speaker_id”，text 设为“开始 -text”，hifly_id 设为“开始 -hifly_id”，如图右侧。该节点负责依据输入变量生成口播数字人。

[PRE12]
（5）在“循环”节点配置中，选择“无限循环”，在输出里设置 output 变量值为 inspect_video_creation_status-video_Url，如图左侧。因为生成时长不确定，需要一直轮询直到完成，完成后把数字人下载地址作为输出。

[PRE13]
（6）在 inspect_video_creation_status 节点配置里，把 job_id 的变量值设为 create_lipsync_video2-job_id，hifly_id 设为“开始 -hifly_id”，如图右侧。job_id 即作品ID，用于查询任务是否完成并获取下载链接；hifly_id 的使用规则同前文。

[PRE14]
（7）在“选择器”节点配置里，于条件分支—“如果”面板点“新增”，上方变量选 inspect_video_creation_status-status，条件选“等于”，下方填 1；再新增一条，下方变量同样选 inspect_video_creation_status-status，条件选“等于”，下方填 2。把“且”改为“或”，如图。当状态为1或2时继续循环，否则结束循环。

[PRE15]
（8）在 time_wait 节点配置里，seconds 的变量值文本框填入 10，如图左侧。该节点起间隔作用，每次查询之间等待10秒，避免频繁请求。

（9）“终止循环”节点用于立刻跳出当前循环，无需配置。在“结束”节点配置里，把 output 的变量值设为“循环 -output”，如图右侧，最终把循环节点输出的数字人下载链接返回给用户查看效果。

## 第7章 OpenClaw 部署、飞书接入与实战技巧精通

### OpenClaw 全景解析

#### OpenClaw 到底是什么
OpenClaw 是2026年初迅速走红的开源AI智能体框架，由Peter Steinberger于2025年11月推出。它被定位为“可直接操控电脑/手机、本地部署、能自主完成真实任务的数字员工”，与只能对话的传统AI不同，OpenClaw能执行读邮件、管理日历、操控浏览器、自动化处理文档等实际工作。
该项目坚持“本地优先、数据不上云”的原则，支持通过WhatsApp、Telegram、飞书、钉钉、QQ等消息平台交互，并拥有丰富的技能生态。
2026年2月，其GitHub星标在不到四个月内突破25万，超越Linux和React等长期领先项目，成为增长最快的开源软件之一，如下图所示。
2026年3月，OpenClaw热潮席卷全国两会。全国政协委员王坚指出，AI技术对中小企业最为友好，而“一人公司”的出现正是这一趋势的体现。与此同时，地方政府也迅速跟进，深圳龙岗区率先发布“龙虾十条”征求意见稿，提出最高200万元补贴；无锡高新区随后推出“养龙虾”十二条，单项补贴最高500万元，旨在以真金白银推动AI智能体在智能制造、智慧政务等领域的深度应用。

#### 为什么说 OpenClaw 是里程碑式的产品
市面上AI产品众多，为何单说OpenClaw是里程碑？要回答这个问题，得先看过去AI的局限，OpenClaw破解了什么。
回顾AI发展路径。第一代是问答机，代表Siri、小爱同学、小度。特点是一问一答，只能执行预设指令，稍微复杂任务就不行，本质像个玩具，能查天气、设闹钟，但帮不上忙。
第二代是聊天机，代表ChatGPT、Claude、文心一言、DeepSeek。特点是一问一答，能力很强，但不主动做事，本质像顾问，给建议却不执行。
第三代是AI Agent，代表OpenClaw。特点是能理解指令、规划任务、执行操作、返回结果，第一次真正把AI从工具变成员工，本质像24小时在线的私人助理。
OpenClaw的革命性体现在三点。
突破一：打破应用壁垒。它不仅能接入微信、钉钉、邮件等通道，更能理解通道里的任务并调度其他应用完成。例如，微信群里看到会议通知，就能自动调用日历App创建日程，并调用邮件App发送会议纪要。
突破二：长期记忆。过去的AI每次对话都是全新开始。你说过的偏好、习惯，下次就忘。OpenClaw有记忆系统，记得你是谁、喜欢什么、之前聊过什么。像一个熟悉的老员工，而不是每次都见面的陌生人。你不用反复交代背景和需求。
突破三：自主执行。过去的AI需要一步步指引，每次都要确认，像执行者而非独当一面的人。OpenClaw接受高层指令后，自己规划、执行、解决问题，你只需最后检查结果。像成熟员工，交代任务后自行完成，不用全程盯着。
如果把AI比作厨房，第一代像微波炉，能热剩饭但做不了复杂菜。第二代像智能灶，按菜谱做菜但你得一直看着。OpenClaw像星级厨师，你说要一桌家宴，它自己买菜、备料、烹饪、摆盘，最后端上完整菜肴。

### OpenClaw 能为你解决什么问题
传统AI工具使用门槛较高，用户需要学习复杂提示词工程、理解API调用，还需一定技术背景才能发挥价值。
OpenClaw通过极致的产品设计大幅降低门槛。用户只需像发微信一样告诉OpenClaw想做什么，系统会自动解析需求、调用相关工具、完成执行并返回结果。
这种“一句话办事”的交互，让AI从技术专家的专属工具，变成普通用户也能轻松使用的生产力助手。
OpenClaw的另一核心价值在于高度可定制性。
