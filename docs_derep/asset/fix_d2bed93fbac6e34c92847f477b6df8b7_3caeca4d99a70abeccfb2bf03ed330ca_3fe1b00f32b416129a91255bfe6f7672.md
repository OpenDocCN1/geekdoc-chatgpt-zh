**【程序详细分析】**

#include <iostream>
using namespace std;
const int N = 1000;
int c[N];

N 取 1000 用来限制数组上限；全局数组 c 保存中间结果。

int logic(int x, int y){
    return (x & y) ^ ((x ^ y) | (~x & y));
}

logic 通过按位组合实现特定逻辑。
（1）x & y 提取两数同时为 1 的位。
（2）x ^ y 提取两数不同的位。
（3）~x & y 提取 y 为 1 且 x 为 0 的位。
（4）将以上结果组合后返回。

void generate(int a, int b, int *c){
    for(int i=0;i<b;i++){
        c[i]=logic(a,i)%(b+1);
    }
}

generate 负责填充数组 c。遍历 0 到 b-1，对每个 i 先算 logic(a,i) 再取模 b+1，保证值在 [0,b]。

void recursion(int depth, int *arr, int size){
    if(depth<=0 || size<=1) return;
    int pivot=arr[0];
    int i=0,j=size-1;
    while(i<=j){
        while(arr[i]<pivot) i++;
        while(arr[j]>pivot) j--;
        if(i<=j){
            int temp=arr[i]; arr[i]=arr[j]; arr[j]=temp;
            i++; j--;
        }
    }
    recursion(depth-1, arr, j+1);
    recursion(depth-1, arr+i, size-i);
}

recursion 模拟分区排序。
终止条件是深度耗尽或子数组长度为 1。以首元素为基准，用双指针把小于基准的放左边、大于的放右边，随后对左右段递归，深度每次减一。

int main(){
    int a,b,d;
    cin>>a>>b>>d;
    generate(a,b,c);
    recursion(d,c,b);
    for(int i=0;i<b;++i) cout<<c[i]<<" ";
    cout<<endl;
}

主函数读取 a、b、d，先生成数组，再按指定深度分区，最后输出。

**【程序总结】**

读入 a、b、d，按位逻辑并取模生成数组 c；以受深度 d 限制的递归分区方式处理数组；输出处理后序列。

**判断题**

（1）当 1000≥d≥b 时，输出序列是有序的。（ ）

A. 正确    B. 错误

**【分析讲解】**

recursion 采用快速排序分区思想，深度 d 控制层数，终止于 depth<=0 或 size<=1。
当 d≥b 时递归层数足够完成全部分区，数组会被完全排序。且 b≤1000，条件 1000≥d≥b 成立。

**【参考答案】**

A. 正确

（2）输入 5 5 1 时，输出为 1 1 5 5 5。（ ）

A. 正确    B. 错误

**【分析讲解】**

a=5,b=5,d=1，generate 得到 c={5,5,1,1,5}。
深度为 1 只做一次分区，基准 5 分区后变为 {5,1,1,5,5}。深度用尽，左右段未继续排序，故输出与题述不符。

**【参考答案】**
