# 情感计算领域核心文献与人才图谱深度解析

## 经典论文速览：视频与群体情感识别

学术界在视频情感识别与群体情感分析方向积累了诸多奠基性工作。以下梳理了该领域的代表性文献：

**视频维度的情感识别研究**
*   **混合网络架构探索**：Fan 等人提出融合 CNN-RNN 与 C3D 的混合网络模型，旨在更精准地捕捉视频序列中的情感动态。
*   **野外环境鲁棒性增强**：Yao 团队构建的 HoloNet 专注于解决非受控环境下的情感识别难题；Bargal 等人则利用图像序列实现“野外”视频情感推断。
*   **多线索融合策略**：Yan 等学者设计了多线索融合机制，整合多源信息以提升复杂场景下的识别精度。

**群体情感识别的前沿进展**
*   **深度学习新框架**：Wei 等人建立了面向群体情感识别的新型深度学习范式。
*   **幸福度预测与评估**：Li 团队引入多重回归处理序列输入预测群体快乐程度；Vonikakis 等人结合几何特征与数据集平衡技术优化群体快乐度评估。
*   **动态建模应用**：Sun 等人利用 LSTM 网络同步攻克动态个体情感与群体情感识别任务。

## ACM MM 获奖佳作复盘：情感计算的高光时刻

本节精选近年 ACM Multimedia 大会中荣获殊荣的情感计算相关论文，供同行参考交流。

### 2018 最佳演示奖：AniDance —— 让旋律实时生成舞动
*   **团队**：唐陶然、毛汉阳、贾佳（清华大学）
*   **核心亮点**：AniDance 系统能驱动 3D 虚拟角色随歌曲实时起舞。研发过程先捕捉真人舞蹈构建数据集，再借助 LSTM 自编码器破解音舞映射关系。该技术不仅创造生动动画，更能激发用户对艺术学习的兴趣。
*   **获取地址**：[论文链接](https://hcsi.cs.tsinghua.edu.cn/Paper/Paper18/MM18-TANGTAORANDEMO.pdf)

### 2016 最佳论文奖：跨模态跨视角，洞察社会舆情脉络
*   **团队**：钱胜胜、张天柱、徐常胜（中科院自动化所）
*   **核心贡献**：针对社交事件数据的多模态、多视角特性，提出主题观点联合挖掘方法。利用不同媒体立场差异剖析观点演变，实现热点事件的全景式呈现与趋势研判。评委会高度评价其选题新颖性、跨平台技术创新性及实战有效性。
*   **获取地址**：[论文链接](http://www.millenniumsoftsol.com/courses/IEEETitles/Java/Multi-Modal-Event.pdf)

### 2014 最佳学生论文奖：剥离语音干扰，还原面部真实情感
*   **团队**：Yelin Kim、Emily Mower Provost（密歇根大学）
*   **核心洞察**：面部表情受语音发音驱动时易产生伪情感信号。本文构建面部分析模型，专门过滤语音发音导致的面部运动干扰，显著提升了面部情感识别的准确性，为人机交互与健康监测奠定基础。
*   **获取地址**：[论文链接](https://cn.aminer.cn/archive/say-cheese-vs-smile-reducing-speech-related-variability-for-facial-emotion-recognition/555045d945ce0a409b5a118)

### 2012 大奖赛一等奖：声学情感高斯模型，赋能音乐视频自动生成
*   **团队**：Ju-Chiang Wang 等（中研院资讯科技创新研究中心）
*   **核心创新**：提出声学情感高斯模型（AEG），作为生成式模型直观解释音乐情感感知机制。通过引入潜在特征集打通声学特征空间与情感语义空间，实现端到端映射。在 MER60 与 Muturk 语料库上验证了其在情感标注、检索任务上的 SOTA 表现，并首创基于情感检索的量化评估体系。
*   **获取地址**：[论文链接](https://cn.aminer.cn/archive/the-acousticvisual-emotion-guassians-model-for-automatic-generation-of-music-video/53e9ad4fb7602d9703736369)
