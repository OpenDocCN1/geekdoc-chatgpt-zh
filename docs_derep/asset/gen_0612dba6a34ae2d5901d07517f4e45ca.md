### 2. 缓存机制
LangChain 为模型调用加入了可选的缓存层，作用很明显：重复请求不再重复调用接口从而节省费用；同时减少对第三方 API 的依赖，能显著降低响应耗时，提升应用的整体速度。

常见的实现有 InMemoryCache、RedisCache、SQLiteCache 等，它们都基于 BaseCache 进行扩展。

BaseCache 核心提供了 lookup、update、clear 三个方法，分别用来查询、写入和清空缓存，且每个方法都有对应的异步版本。
