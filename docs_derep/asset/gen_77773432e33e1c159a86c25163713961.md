4. 总结一下，这段程序实现了一个叫 ask_question 的 Python 函数，入口是 prompt 和 model_engine 两个变量。它借助 OpenAI API 去调用 ChatGPT 回答问题。函数内部使用的是 openai 库里的 openai.Completion.create() 接口与模型交互，接口里可以设定单次最大生成 token 数、返回条数、停止条件以及温度等多样性控制参数。只要把问题描述传进去，程序就会把所需信息一次性打包发给 ChatGPT，等待返回后截取出文本部分并去净化多余空格，就得到最终答案。

5. Python 是逐行执行的语言，行首的缩进决定了代码的层级关系。同层语句必须保持一致的缩进，缩进不对解释器会报 IndentationError。示例里 ask_question 的首行是顶格写的，函数体内的 completions 变量就必须缩进一次。一般一次缩进按一下 Tab 或输入四个空格即可，表示进入函数内部；如果函数内部再调用其他函数，缩进层级就依次递增。

6. 除去字符串内容，Python 代码只认英文标点。单引号、双引号、圆括号等符号都必须使用英文字符，否则会出错。
