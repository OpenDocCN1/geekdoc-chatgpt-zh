实数区间的几种标准写法

- 左开右闭区间 $(a,b]$ 包含所有严格大于 $a$ 且不超过 $b$ 的实数, 常用不等式记作 $a < x \le b$.
- 闭区间 $[a,b]$ 包含所有不小于 $a$ 且不大于 $b$ 的实数, 常用不等式记作 $a \le x \le b$.
- 左闭右无穷区间 $[a,+\infty)$ 包含所有不小于 $a$ 的实数, 常用不等式记作 $a \le x < +\infty$.
- 左无穷右开区间 $(-\infty,b)$ 包含所有小于 $b$ 的实数, 常用不等式记作 $-\infty < x < b$.
- 双侧无穷区间 $(-\infty,+\infty)$ 即全体实数, 常用不等式记作 $-\infty < x < +\infty$.

函数概念的通俗表述
设非空实数集合 $D$ 与 $B$ 给定, 若存在一种对应方式 $f$, 使得 $D$ 中任取一个 $x$ 在 $B$ 中都能找到唯一确定的 $y$ 与之配对, 则称 $f$ 为定义在 $D$ 上的函数, 记作 $f: x \to y$ 或 $f: D \to B$。对应的 $y$ 用 $y=f(x),\;x\in D$ 表示, 其中 $x$ 为自变量, $y$ 为因变量。

从定义可知, 函数的核心是一条对应法则。记号 $y=f(x)$ 中, $f$ 代表对应法则, $f(x)$ 为 $x$ 处的函数值, 研究时习惯用 $y=f(x)$ 来描述对应关系, 但本质上函数指的是法则 $f$ 本身。

定义域 $D$ 决定自变量的取值范围, 函数值则由法则 $f$ 决定, 所以一个函数由定义域与对应法则两个要素共同确定。只要两个函数的定义域与对应法则完全相同, 即视为同一函数, 与用什么字母表示变量无关, 例如 $y=|x|$ 与 $z=\sqrt{v^{2}}$ 表示同一对应关系。

在解题中, 奇偶性、单调性、有界性、周期性等基本特性往往起到关键作用。

##### 3. 极限的直观理解
当自变量趋于无穷大或无限接近某定点时, 函数值趋向某个常数 $A$, 就称该函数在此处具有极限。

###### 1) 自变量趋向无穷大时函数的极限
设 $y=f(x)$, 若对任意给定的正数 $\varepsilon$ 不论多小, 都能找到正数 $X$, 使得只要满足 $|x|>X$ 的所有 $x$, 对应的 $f(x)$ 都满足 $|f(x)-A|<\varepsilon$, 则常数 $A$ 称为 $y=f(x)$ 当 $x\to\infty$ 时的极限, 记作 $\lim_{x\to\infty}f(x)=A$。

极限的四则运算, 已知 $x\to x_{0}$ 或 $x\to\infty$ 时 $f(x)\to A,\;g(x)\to B$, 则
$\lim_{x\to x_{0}}(f(x)+g(x))=A+B$, $\lim_{x\to x_{0}}f(x)\cdot g(x)=A\cdot B$。

###### 1) 奇偶性
若函数 $y=f(x)$ 的定义域 $D$ 关于原点对称, 且对任意 $x\in D$ 有 $f(-x)=f(x)$, 则称 $f(x)$ 在 $D$ 上为偶函数; 若满足 $f(-x)=-f(x)$, 则称其为奇函数。偶函数的图像关于 $y$ 轴对称, 奇函数的图像关于原点对称。

###### 2) 单调性
在区间 $(a,b)$ 内任取 $x_{1},x_{2}$, 若 $x_{1}<x_{2}$ 时恒有 $f(x_{1})<f(x_{2})$, 则称 $y=f(x)$ 在该区间上单调递增; 若恒有 $f(x_{1})>f(x_{2})$, 则称单调递减。两者合称单调函数, 具备单调性的区间称为单调区间。递增图像自左向右上升, 递减图像自左向右下降。

###### 3) 有界性
若存在 $M>0$ 使对所有 $x\in D$ 均有 $|f(x)|\le M$, 则称 $y=f(x)$ 有界, 其图像被直线 $y=-M$ 与 $y=M$ 夹住。$\sin x,\cos x,\arcsin x,\arccos x,\arctan x,\operatorname{arccot}x$ 都是典型有界函数。

###### 4) 周期性
若存在常数 $T$, 对任意 $x\in D$ 都有 $x+T\in D$ 且 $f(x+T)=f(x)$, 则称 $y=f(x)$ 为周期函数, 通常指最小正周期。周期函数在相邻周期内的图像完全重复。

补充极限的常用运算形式
$\lim_{x\to x_{0}}\frac{f(x)}{g(x)}=\frac{A}{B}\;(B\neq0)$
$\lim_{x\to x_{0}}k\cdot f(x)=k\cdot A\;(k\text{为常数})$
$\lim_{x\to x_{0}}[f(x)]^{m}=A^{m}\;(m\text{为正整数})$
借助上述规则可把复杂函数的极限拆解为若干简单函数的极限求解。

###### 2) 无穷小量与无穷大量
在自变量的某变化过程中, 以零为极限的变量称为该过程的无穷小量。例如 $\lim_{x\to x_{0}}f(x)=0$ 时, 当 $x\to x_{0}$ $f(x)$ 为无穷小。无穷小描述的是变化趋势而非数值大小, 只有常数 $0$ 可以作为无穷小量。

若变量的绝对值可以无限增大, 则称为该过程的无穷大量, 这是极限不存在的一种情形。例如 $\lim_{x\to x_{0}}f(x)=\infty$ 时 $f(x)$ 为无穷大量。无穷大量的倒数是无穷小, 非零无穷小量的倒数是无穷大量。

### 2.2 微分基础
微分是对函数局部变化率的线性刻画。本节介绍微分概念以及 PyTorch 自动微分技术。

#### 2.2.1 微分及其公式
1. 微分基础
若函数 $y=f(x)$ 在点 $x$ 处的改变量 $\Delta y = f(x+\Delta x)-f(x)$ 可写成
$\Delta y = A\Delta x + o(\Delta x)$
其中 $o(\Delta x)$ 是比 $\Delta x$ 高阶的无穷小, 则称 $f(x)$ 在 $x$ 处可微, $A\Delta x$ 称为 $\Delta y$ 的线性主部, 也即函数在该点的微分, 记为 $dy$ 或 $df(x)$, 即 $dy = A\Delta x$。

2. 函数的极值与最值
若 $f(x)$ 在 $x_{0}$ 的某邻域内有定义, 且对邻域内任意 $x\neq x_{0}$ 都有 $f(x)<f(x_{0})$, 则 $f(x_{0})$ 为极大值; 若恒有 $f(x)>f(x_{0})$, 则 $f(x_{0})$ 为极小值。极大值与极小值统称极值, 使其取得的点称为极值点。

单变量情形, 极值点往往出现在边界或驻点处。满足 $f'(x)=0$ 的点称为驻点。

#### 2.2.2 PyTorch 自动微分
机器学习训练本质是求解最优化问题, 可导情形即寻找一阶导数为零的驻点。自动微分是反向传播的一般化, 能在指定点计算可导函数的导数值。
