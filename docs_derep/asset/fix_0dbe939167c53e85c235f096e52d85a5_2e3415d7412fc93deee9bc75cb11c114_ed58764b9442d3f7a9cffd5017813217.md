# 等差数列缺失值二分探测

在等差排列里，某个位置的理想值等于下标加上首项，这就解释了 `nums[mid]==mid+nums[0]` 的含义。

【正确选项】
B. nums[0]

2. 第二空应选（ ）。
A. left=mid+1
B. right=mid–1
C. right=mid
D. left=mid

解析
当中点恰好满足等差关系时，左半段已经完整，空缺只可能在右边。此时把左边界前移到 mid+1，继续向右搜索。

【正确选项】
A. left=mid+1

3. 第三空应选（ ）。
A. left=mid+1
B. right=mid–1
C. right=mid
D. left=mid

解析
一旦中点偏离理想值，说明空缺落在左侧。把右边界收敛到 mid，使搜索范围限定在左子区间。

【正确选项】
C. right=mid

4. 第四空应选（ ）。
A. left+nums[0]
B. right+nums[0]
C. mid+nums[0]
D. right+1

解析
区间收敛到单个位置时，直接用 left 推算理论值。按等差通项，缺失数即 left+nums[0]。

【正确选项】
A. left+nums[0]

5. 第五空应选（ ）。
A. nums[0]+n
B. nums[0]+n-1
C. nums[0]+n+1
D. nums[n-1]

解析
若丢的是末尾元素，算出的缺值应与数组尾部一致。数组尾部为 nums[n-1]，用来做最终校验。

【正确选项】
D. nums[n-1]

【要点回顾】
1）下标与元素：用索引推算等差序列的理想值。
2）二分查找：折半、移动边界与停止条件。
3）分支与循环：在 while 循环里按条件调整左右指针。
4）等差特性：借助首项与公差还原应有值。

【考点拆解】
一、下标与存储
数组连续存放，通过下标寻址。本题用 vector 保存等差序列，主要操作有读取 `nums[mid]`、用 `nums[mid]==mid+nums[0]` 校验连续性、循环读入。
提示：下标从 0 起，计算理想值要注意偏移。

二、二分思路
核心是每次把范围砍半。先定 left/right，取 mid=left+(right-left)/2，判断 mid 是否符合规律，再移动边界。结束条件为 left==right。
提示：时间复杂度 O(log n)，对大数据很高效。

三、条件与循环
if-else 依据规律决定指针方向，while(left<right) 防止死循环。
提示：条件要覆盖完整，避免遗漏边界。

第 2 题
编辑距离：给定两串，每步可删、插、换，求把第一个串变成第二个串的最小操作次数。补全 DP 算法。

【程序说明】
1. 功能
用 DP 求编辑距离，支持插入、删除、替换。
2. 代码要点
`min` 函数返回三数最小值，供转移时比较。
`edit_dist_dp` 先建 (m+1)×(n+1) 表，`dp[i][j]` 表示前 i 个字符变前 j 个字符的最小步数。
双层循环填表：
若 i==0，空串变前 j 个字符需 j 次插入。①填：j。
若 j==0，变空串需 i 次删除。②填：i。
若 `str1[i-1]==str2[j-1]`，字符相同不需操作，继承 `dp[i-1][j-1]`。③填：str1[i-1]==str2[j-1]，④填：dp[i-1][j-1]。
否则需一次操作，取插入 `dp[i][j-1]`、删除 `dp[i-1][j]`、替换 `dp[i-1][j-1]` 的最小值再加 1。⑤填：dp[i-1][j-1]。
最后返回 `dp[m][n]`。

1. 第一空应选（ ）。
A. j
B. i
C. m
D. n
解析 i 为 0 时源串为空，目标长度为 j，只能插入 j 次。
【正确选项】 A. j

2. 第二空应选（ ）。
A. j
B. i
C. m
D. n
解析 j 为 0 时目标为空，需删掉源串前 i 个字符。
【正确选项】 B. i

3. 第三空应选（ ）。
A. str1[i–1]==str2[j–1]
B. str1[i]==str2[j]
C. str1[i–1] !=str2[j–1]
D. str1[i] !=str2[j]
解析 比较当前字符是否相等，相等可直接沿用子问题结果。
【正确选项】 A. str1[i–1]==str2[j–1]

4. 第四空应选（ ）。
A. dp[i–1][j–1]+1
B. dp[i–1][j–1]
C. dp[i–1][j]
D. dp[i][j–1]
解析 相等时不产生额外代价，直接继承前一状态。
【正确选项】 B. dp[i–1][j–1]

5. 第五空应选（ ）。
A. dp[i][j]+1
B. dp[i–1][j–1]+1
C. dp[i–1][j–1]
D. dp[i][j]
解析 不相等时替换操作基于 `dp[i-1][j-1]`。
【正确选项】 C. dp[i–1][j–1]

【小结】
1. 状态递推思想与最优子结构，通过二阶表递推。
2. 二阶表初始化与状态转移。
3. 字符串长度、索引与字符比较。

【考点拆解】
一、状态递推基本思想
把大问题拆成子问题并记忆结果，避免重复计算。编辑距离是典型案例。
二、编辑距离建模
`dp[i][j]` 为前 i / j 个字符的最少操作。
相等：`dp[i][j]=dp[i-1][j-1]`
不等：`dp[i][j]=1+min(dp[i-1][j],dp[i][j-1],dp[i-1][j-1])`
边界：`dp[0][j]=j`，`dp[i][0]=i`，答案在 `dp[m][n]`。
空间可滚动优化到 O(n)，时间 O(m×n)。
三、字符串操作
`length()` 取长度，`str[i]` 取字符，比较用 `==`。
例
str1="kitten"，str2="sitting"，最终最少操作 3。

# CSP-S 选择题真题解析

## 5.1 2024 年 CSP-S 选择题

1. 在 Linux 系统中，若要显示当前工作目录的路径，应使用（ ）。
A. pwd
B. cd
C. ls
D. echo

【考点归类】
入门级|1.计算机基础与编程环境|【1】Windows、Linux 等操作系统的基本概念及其常见操作

【解析】
pwd 用于输出当前工作目录的绝对路径，正是题目要求的功能。
cd 用于切换目录，无法显示路径。
ls 用于列出目录内容，与路径显示无关。
echo 通常用来输出字符串或变量值，与路径显示无关。

【参考答案】
A. pwd

【考点拆解】
本题考查 Linux 常见命令的基础用法。
一、pwd 命令
pwd 全称 Print Working Directory，用于显示用户当前所在工作目录的完整路径。
二、常用变体
pwd：显示当前路径。
pwd -L：基于逻辑目录的路径。
pwd -P：基于物理路径，去除符号链接。
三、易混命令
cd 只切换目录，ls 只查看内容。
