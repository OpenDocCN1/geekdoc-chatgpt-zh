## 10 泛化原理

会举一反三是学习型机器的标志。只要训练集里 C 和 D 的样式足够多且多样，模型就有机会认出从未见过的 C 和 D，前提是新样本别偏离太远。

用乘法来类比。我们能算出 346×2067 不是因为背下所有乘积，而是掌握了乘法的规则。感知机也类似，它不是把所有可能的 C 都存下来，而是提炼出一个能完成识别的模型。看它具体怎么运作。

训练前，操作员会准备大量样本，可能是上百到上千个大小字体各异的 C，放在 25 个象素的网格里不同位置。D 也同样处理。

若目标是 C 输出 +1、D 输出 -1，学习过程中模型会给 C 图中亮的象素和 D 图中暗的象素赋正权，给 C 图中暗的象素和 D 图中亮的象素赋负权。权值在这里就是区分两类信息的能力。

由此可见训练的威力：训练好的系统能跳出给定的样本，去识别全新的图形。

## 11 感知器的局限性

当采集到的 C 或 D 差别不大时，上面的做法管用；一旦形状、大小或朝向差异拉大，比如一个极小的 C 躲在角落，感知机就很难找到合适的权值组合。更根本的是，某些形状变化天生就超出感知机的处理范围。所有线性分类器都有这个天花板，感知机只是典型代表。

线性分类器的输入是一串 n 个数，也可看成 n 维向量。数学上向量就是空间中的一点，坐标就是那串数。对一个两输入的神经元，输入空间是平面，输入向量就是平面上的点；三输入对应三维。我们这里的 C、D 示例输入空间有 25 个维度，25 个象素值对应 25 维空间中的一点。那是一个没法画出来的超空间。

线性分类器把输入空间切成两块，比如 C 的区域和 D 的区域。平面上分界是一条线，三维里是平面，25 维里就是 24 维超平面。总体规律是，输入个数为 n 时，分界面是 n-1 维超平面。

验证一下，二维加权和可以写成 `S=w[0]*x[0]+w[1]*x[1]`。当和为 0 时正好跨过分界，边界点满足 `w[0]*x[0]+w[1]*x[1]=0`，也就是 `x[1]=–w[0]/w[1]*x[0]`，这就是直线方程。

两个向量的点积为零时正交，小于 90° 为正，大于 90° 为负。所以 x 的集合就是与 w 正交的向量族，在 n 维里构成 n-1 维超平面。

这里有个关键点。设想一个只有两个输入的感知机，再额外加一个恒为 -1 的虚拟输入。没有这个附加项，分隔线必须过原点；有了它，边界就能平移。

这里讲的是二维里的点，对应两个象素的两种输入图像，人能直观看见。

真正的感知机工作在高维空间。当我们想让它区分更复杂、变化更大的形状或位置时，往往就会碰到上面说的那种情况，只是维度更高。

对感知机来说，输入向量与权重向量夹角为锐角时加权和为正，钝角时为负。正负的分界是与权重向量 w 正交的点 x 的集合，因为点积为零。在 n 维里边界方程为：
`w[0]*x[0]+w[1]*w[1]+w[2]*w[2]…w[n–1]*x[n–1]=0`
它是一个 n-1 维超平面。

感知机用一个超平面把空间劈成两半。我们希望让 C 检测器活跃的点全在一侧，非活跃的点在另一侧。若这样的超平面存在，感知机通过持续学习就能找到；若不存在，即点不是线性可分的，再怎么改权重也收敛不到稳定唯一的配置。

做这个论证的意义在于，它解释了 20 世纪 60 年代初困扰模式识别研究者的难题，研究者据此认为感知机的能力有限，无法识别自然图像里的物体。

事实上，当输入维度很大、样本丰富且复杂时，比如成千上万张狗、猫、桌子、椅子的照片，它们的类别很可能不是线性可分的，也就无法被直接连到象素上的感知机识别。即使在简单的 C、D 例子里，若字母的形状、位置或大小差异很大，感知机也无法分类。

西摩尔·帕普特和马文·明斯基在 1969 年出版的《感知器：计算几何学概论》^([`[1]`](#part0055.html#note35n)) 给感知机发展按下了暂停键，进一步加剧了研究者的挫败感。这次停顿在人工智能史上起了关键作用，促成了其后的人工智能寒冬，研究方向被迫转移。

对今天的读者来说，这个论证提供了理解机器学习的另一条路径。

## 12 特征提取器

最简单的感知机分不清某些形状。所以从一开始研究者就保留到现在的做法：在图像和神经层之间加一个中间模块，叫特征提取器。它能在输入图像里侦测特定区域，生成描述这些区域是否存在、强度的向量，再交给感知机。

回到之前的论证。

把感知机直接连到图像象素上，它很难跳出增强模板的模式。由权重编码的象素类别区分了 C 与其他图像。一旦样本变化过大，罗森布拉特的感知机就会饱和，权重不再能识别。若用差异极大的 C 图像训练，就会这样。若图像分辨率足够识别所有字符，约 20×20 象素，C 的大小、字体、手写或印刷、在角落还是中心就不再是问题。一旦形状、位置或尺寸差异过大，感知机无法分类，因为没有单一的增强模板能覆盖所有变化，见图 3—7。
[PRE3]

#### 图 3—7 特征提取器

特征提取器检测输入图像里的独特图案，把结果送给可训练的分类器如感知机。第一个模板检测笔画的线尾作为 C 的末端，另外两个模板检测拐角如 D 的拐角。该层信息作为感知机的输入。训练后，只要存在相关特征，感知机就能在大小和位置不同时区分 C 与 D。在这个例子里，一个 C 两个位置不同的 D 下，提取器可看作一层二进制神经元。白色象素代表 -1，灰色象素代表 0，黑色象素代表 +1。上述三个特征检测器是 5×5 象素的模板，与输入图像比对。对模板的每个位置，用模板的 25 个权重计算输入窗口 25 个象素的加权和。结果是一组图像，当窗口内容与模板相似时象素变黑。然后把加权和与阈值比较生成特征图，若在相应位置检测到图案则值为 +1，否则为 0。

无论字体或书写风格怎样，在 20×20 象素图像里分辨 C 与 D 的关键是检测拐角和笔画末端。D 是带两个角的闭合图形，C 是一条两端各有一个端点的开曲线。于是可以构建一个特征提取器检测端点或拐角的存在，而不必关心 C、D 在图像中的位置。可以设计第一层为一组二进制神经元集合，其输入是图像上 5×5 象素的小窗口，并手工赋予权重而非学习算法确定。可以得到三种感知机神经元：一种端点神经元和两种角神经元。图像上的每个 5×5 窗口提供三个神经元，各一类型。当输入窗口看起来与权重图像相似时，神经元输出 +1，否则输出 0。若 C 形状良好，端点检测器会被激活；若 D 形状良好，角检测器会被激活。最后一层是一个简单感知机，只需计算角和端点的数量来区分 C 与 D，其位置、大小和样式不再重要。

可以改造感知机架构，使其执行更复杂的操作。具体做法是在感知机层前放置一个手工构建、未经训练的特征提取器。特征提取器的设计既复杂又耗时，2015 年以前的文献里充满这类构造方法。

因此一种常用方案是让特征提取器检测输入图像里细微的简单图案。对字母而言，它不仅能标出末端和角，还能标出竖线、横线、环线等。提取器的输出是一串数字，代表这些简单图案是否存在及其位置。此时感知机并不是直接连到输入象素，而是通过更抽象的特征连接。

若想用感知机检测汽车，其特征提取器就是一组模板，分别检测车轮、挡风玻璃角度、散热器格栅等。用这些模板扫描整幅图像，扫描到图案时模板会亮起，所有扫描到的特征一起输入感知机。对人脸的处理方式相同，只需检测眼睛部位的深色区域、鼻孔中的两个小黑点、嘴唇间略深的一条线，就能构建合适的面部感知机。

在最初的感知机里，特征提取器实际上是一串二进制神经元，它们随机连接到输入图像的小象素组，当时没有更好的办法。这些神经元的权重无法通过学习改变，是固定的且随机。由于连接随机，我们永远无法确定哪个是有用的。为了让第一层发挥作用，必须设置大量特征提取器神经元，从而使最终神经元的输入数量急剧增加。在一些 2013 年后就很少使用的分类与模式识别系统里，特征提取器的输出可达数百万。特征越多，对后续分类越有帮助，但成本也越高。

研究人员受视觉皮层连续区域组织启发，希望通过建立更多神经元层来提升感知机效率：系统第一阶段提取非常简单的特征；下一层尝试检测这些特征组合的轮廓或直接连接特征，形成圆形或角等基本形状；再下一层检测这些组合构成的物体局部；如此层层递进。

另一种更精明的构建特征提取器的方法是 SVM，这是伊莎贝尔·居永自 2015 年起在奥赛^([`[1]`](#part0056.html#note36n)) 任教授的发明，其合作者弗拉基米尔·瓦普尼克和伯恩哈德·伯泽尔都是我在贝尔实验室时的组成员。1995—2010 年，SVM 一直是分类最常用的方法。我对朋友和同事心怀敬意，但必须承认我本人对该方法并不特别感兴趣，因为它并未解决特征提取器自动训练的关键问题。不过 SVM 方法吸引了大批关注。

SVM 是核机器的典型代表。虽然支持者不喜欢做对比，但本质上它就是一种两层神经网络。第一层单元数与学习集合中的样本数相同，第二层像普通感知机一样做加权和计算。第一层单元借助核函数 k(x,q)，把输入 x 与所有学习样本 X[0]、X[1]、X[2]、…、X[p=1] 做比较，式中 x 代表输入向量，q 是一个学习样本。例如第一层单元号为 3，则输出 z[3]=k(x,X[3])。

一些数学专著的主题就是探讨这些极简单的模型，数学之美掩盖了方法的局限，因而吸引研究者，使得 SVM 与核方法大行其道。虽有一定成果，核机器并没有比感知机强大多少，我与同事曾试图用这一点说服同行，但未果。部分人仍不相信多层架构的有效性，其中包括弗拉基米尔·瓦普尼克。

不管怎样，在 20 世纪 90 年代中期样本数量不多的情况下，SVM 确实可靠且易于操作。而且当时正值互联网初期，SVM 程序开放源代码，可免费使用。它新且好，很快获得成功。在 20 世纪 90 年代，核方法使神经网络黯然失色，多层网络的使用在人们脑海中渐渐消失。

但增加一层或多层人工神经元可以计算单层神经元难以有效计算的更复杂函数。数学定理表明，仅需两层神经元就能进行任意计算，这也是 SVM 能够成功的原因之一。只不过需要庞大的中间层。正如我们看到的，第一层神经元数量远大于原始图像象素数，即使输入是 25 象素的小图像，也可能需要数百或数千个神经元处理。

20 世纪 60 年代的研究者总是困惑于多层网络的训练。在感知机的学习过程中，只有最后一层经过训练，特征提取器的第一层无法训练，必须手工确定。
