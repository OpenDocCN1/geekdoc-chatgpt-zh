量化入口
量化方法通过 bits 控制位宽，bits 为 0 时直接返回。第一次调用会标记 quantized，避免重复处理，同时把量化位宽写回 config，再把 transformer 子模块整体量化。

def quantize(self, bits: int, empty_init=False, **kwargs):

    if bits == 0:

        return

    from .quantization import quantize

    if self.quantized:

        return self

    self.quantized = True

    self.config.quantization_bit = bits

    self.transformer = quantize(self.transformer, bits,

        empty_init=empty_init,

        **kwargs)

    return self

定制微调训练
训练使用 XiaohuaModel，重点是把 ChatGLMConfig 的 pre_seq_len 设为 16、prefix_projection 设为 False，只有这两个配置生效。模型从本地 pth 加载，strict=False，半精度上 GPU，并打印可训练参数。数据通过 get_train_data 构造，prompt 写死为“按给定的格式抽取文本信息。\n文本:”。

优化器用 AdamW，学习率 2e-5，betas 0.9/0.999，eps 1e-5。学习率调度用 CosineAnnealingLR，T_max 2400，eta_min 2e-6。Accelerator 统一准备模型、优化器、数据加载器和调度器。batch_size 2，drop_last True，训练 20 个 epoch，每 3 个 epoch 保存一次 glm6b_pt.pth。

推理与 top-p 采样
评测阶段模型 eval。max_len 设 288，max_src_len 256，目标长度由此推导。prompt 保持一致，分词后拼接 [gMASK] 与 <sop>。自回归生成时取 logits 倒数第 3 位，经温度 0.95 的 softmax 后用自定义 sample_top_p，按 p=0.95 过滤概率累积，multinomial 采样。每次把新 token 插回序列尾部，保持特殊 token 位置不变，遇到结束符 130005 提前退出，最后 decode 打印结果。

[PRE4]python

def sample_top_p(probs, p):

    probs_sort, probs_idx = torch.sort(probs, dim=-1, descending=True)

    probs_sum = torch.cumsum(probs_sort, dim=-1)

    mask = probs_sum - probs_sort > p

    probs_sort[mask] = 0.0

    probs_sort.div_(probs_sort.sum(dim=-1, keepdim=True))

    next_token = torch.multinomial(probs_sort, num_samples=1)

    next_token = torch.gather(probs_idx, -1, next_token)

    return next_token
