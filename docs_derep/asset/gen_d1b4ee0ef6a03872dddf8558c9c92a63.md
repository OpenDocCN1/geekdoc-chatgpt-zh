# 第 9 章　大数据及云计算

## 9.1　初识大数据

### 9.1.1　大数据的基本概念

不同行业与专家对大数据的认知存在差异，但其价值已被普遍认可。

（1）大数据指的是数据规模庞大到无法依靠人工在合理时间内完成采集、管理、处理和分析，并将其转化为可读信息的集合。

（2）大数据体现为从海量或多源数据中迅速获取有效信息的处理能力。

（3）大数据是连接物理世界、信息空间与人类社会的纽带。

（4）大数据是推动新一代信息技术产业发展的关键动力。

大数据的主要来源包括数据库产生的大数据、Web 产生的大数据、移动互联网产生的大数据以及物联网产生的大数据。

大数据，英文 big data，指在规定时间内无法使用常规软件工具完成捕捉、管理与处理的数据集合，属于需要新型处理模式才能实现更强决策力、洞察力与流程优化能力的海量、高增速、多样化信息资产。

### 9.1.2　大数据的主要技术

大数据技术主要可分为大数据科学、大数据工程和大数据应用。大数据科学侧重于挖掘大数据网络在快速发展与运行中的规律，并用以验证大数据与社会活动间的复杂关联；大数据工程负责大数据系统的规划建设与运营管理；大数据应用则聚焦业务需求，在此之前需要对海量数据进行有效处理，涉及大规模并行处理数据库、分布式文件系统、数据挖掘网格、云计算平台、分布式数据库、互联网与可扩展存储系统等。

大数据以时间作为处理诉求，将处理方式分为流式处理与批处理。两种方式会带来架构上的差异。流式处理认为数据的价值在于新鲜度，要求尽可能快地完成处理并输出结果。数据持续到达时，只有少量会被保留在有限内存中。流处理理论已较为成熟，典型开源系统有 Storm、S4 与 Kafka，主要服务在线应用，响应级别多在秒或毫秒。批处理则是先存储后分析。MapReduce 是重要的批处理模型，其核心思路是将数据拆分为若干小块并行处理，生成中间结果后再合并为最终结果。因其简洁高效，MapReduce 广泛用于生物信息、Web 挖掘与机器学习。

从数据生命周期的视角，结合数据源与数据特性，可对主要分析方法进行总结与比较，包含结构化数据分析、文本分析、Web 数据分析、多媒体数据分析、社交网络数据分析以及移动数据分析。

## 1. 结构化数据分析

科学研究与商业活动中产生了大量结构化数据，可借助成熟的 RDBMS、数据仓库、OLAP 与 BPM 等技术进行管理，分析技术主要依赖此前介绍的数据挖掘与统计分析。近年来深度学习成为主流热点。传统机器学习多依赖人为设计的数据表达与特征输入，而深度学习集成了表征学习，能够学习多层次的复杂抽象表达。

## 2. 文本分析

文本是信息保存最常见形式，涵盖电子邮件、文档、网页与社交媒体内容，因此文本分析的商业潜力高于结构化数据。文本分析亦称文本挖掘，指从非结构化文本中抽取有用信息或知识的过程。文本挖掘是跨学科领域，涉及信息检索、机器学习、统计、计算语言学与数据挖掘。大多数系统建立在文本表征与自然语言处理 NLP 基础上。文档表示与查询处理是构建向量空间模型、布尔检索模型与概率检索模型的基础，进而构成搜索引擎的基础。NLP 技术提升了文本可用信息，使计算机能够分析、理解甚至生成文本。词汇识别、语义消歧、词性标注与概率上下文无关文法等是常用方法。在此基础上发展出信息抽取、主题建模、摘要、分类、聚类、问答系统与观点挖掘等技术。

## 3. Web 数据分析

对互联网企业而言，掌握数据分析技术并监测、度量关键指标已成为运营核心。Web 数据分析的目标是从 Web 文档与服务中自动检索、提取与评估信息以发现知识，涉及数据库、信息检索、NLP、文本挖掘与 Web 挖掘。Web 挖掘可分为 Web 内容挖掘、Web 结构挖掘与 Web 用法挖掘。

## 4. 多媒体数据分析

多媒体数据分析指从多媒体数据中提取有价值知识并理解其语义。多媒体来源非常丰富，已不仅止于图像，而是来自各类产生图像、视频、语音的智能设备；监控摄像、医疗影像、物联网传感器、卫星等也能产生海量图像视频。多媒体数据在许多领域承载的信息比文本或简单结构化数据更丰富，信息提取需解决语义歧义。以新浪微博为例，用户微博中大量图片、视频链接获得更多关注与转发，而纯文本微博关注度相对较低。微信使用量长期居高不下，其以语音为主的信息载体改变了以往以纯文本社交的模式。目前研究覆盖多媒体摘要、多媒体标注、多媒体索引检索、多媒体推荐与多媒体事件检测等。

## 5. 社交网络数据分析

随着在线社交网络兴起，网络分析从文献计量与社会学网络分析发展到 21 世纪的社交网络分析。社交网络包含联系与内容两类数据。联系数据通常以图拓扑表示实体间关系；内容数据则包括文本、图像等多种多媒体。社交网络数据的丰富性带来挑战与机遇。通过分析可发现潜在商机，如用户活动商圈是否在企业覆盖范围、消费能力、兴趣爱好、近期购买习惯、购买概率、竞争对手策略等。分析结果还能实现效果预测，不仅促进企业发展，还可进行危机预警。危机预警即实时监控网络中可能引发危机的信息，追踪其传播路径，找到关键节点并打散传播轨迹，使危机趋于消失，类似于舆情管控。从数据中心角度，社交网络研究主要包括基于联系的结构分析与基于内容的分析。未来社交网络将成为预测趋势的有力工具，企业可借助其制定更精准、广泛、有效的社会化营销体系，提升服务质量。

## 6. 移动数据分析

移动计算快速发展，移动终端与应用在全球普及。移动应用是移动互联网的重要载体，移动应用数据分析即在获取用户使用等基础数据后进行深入挖掘，洞察使用特征与潜在价值，发现产品设计不足、识别机会、优化产品与运营策略，提升应用质量。

## 9.1.3 大数据的特征

大数据通常用 4 个 V 概括，即 volume 量、variety 多样、velocity 速度、value 价值。从技术研究看，前三者是大数据本源；从商业应用看，value 才是核心。

### 1. 数据量巨大

数据规模之大是大数据与传统数据最显著区别，不仅指存储空间大，也指计算量大。大数据通常达到 PB 级以上，常规数据多在 TB 级。数据量激增源于技术发展带来的各类智能设备、通信工具带来的交流数据激增，以及集成电路成本下降使设备普遍智能化。

数据规模间接体现处理能力。字节是基本单位，传统企业数据多为 TB 级，而百度、谷歌、新浪微博、淘宝等大型企业数据已达 PB 级。当前大数据技术处理量级一般在 PB 以上。

### 2. 数据类型多样化

大数据包含文本、结构化表格、半结构化、非结构化视频、图像、语音、网络日志、地理位置、订单等多种类型。

结构化数据便于存储、处理与查询，在结构化过程中已抽取价值信息，新增数据可采用固定技术处理。非结构化数据因缺乏统一结构属性，存储时需同时保存结构，增加难度。目前非结构化数据占比已超过四分之三，且随增长不断出现新类型，传统处理难以满足。

大数据不仅量大还种类繁多，其中约五分之四为非结构化，来源包括物联网、社交网络等，仅小部分为结构化。

（1）结构化数据：传统关系数据模型、行数据，存储于数据库中，以表格呈现，同一列数据类型一致。  
（2）非结构化数据：无标准格式，难以直接获取对应值。  
（3）半结构化数据：如 XML、HTML，结构与内容混杂，介于两者之间，多为纯文本日志、温度数据等。

### 3. 数据处理速度快

大数据增长近乎爆发式，对存储与处理速度要求极高。需实时分析并提取价值，与传统分析显著不同。在快速处理下需兼顾及时性与实时性。数据并非静止，而是持续流动且价值随时间衰减，要求及时处理。当前大数据多以数据流方式产生，流动快、易消失且不稳定，对实时性要求更高。

### 4. 数据潜在价值大

从商业角度挖掘大数据潜在价值是投入资本的出发点与落脚点。合理利用并正确分析数据可带来巨大回报。

大数据还具有低密度特征。海量数据中仅部分具备价值，数据量指数增长的同时，有用信息未同比例增长，如何精准挖掘是亟待解决的问题。

## 9.1.4 大数据的价值与挑战

### 1. 大数据的潜在价值

大数据之“大”不在表象容量，而在潜在价值。

数据量越大、信息量越多、传播越广，潜在价值越高，但低密度特征下若工具不完善，价值会降低。研究显示数据价值随时间反比，若无法在较短时间内处理，价值会流失。

数据化指将一切内容通过量化转化为数据，如位置、发动机振动、桥梁承重等。实时化需求日益突出，互联网便利带来数据实时交换，推动人们分析海量数据并找出关联。随着人工智能与数据挖掘提升，大数据在信息价值方面具有引导作用，帮助企业获利。

大数据通过专业化处理与挖掘数据间潜在关系产生市场价值。获取大数据已不难，如何获取有利于自身利益的数据是企业关注重点。优质数据是业务生命线与决策基础，竞争优势在于深度理解客户，数据已成为决策依据。数据价值体现为信息与人的有效对接。能将客户需求相关数据与自身业务结合的公司拥有新竞争优势。部分公司通过数据交易获益，利用分析降低成本、提升利润。数据正成为价值规模最大的交易商品。大体量、多类型数据通过共享处理非标准化数据可实现价值最大化。数据的提供、使用与监管正把大数据变为大产业。

大数据时代绝大部分数据由传感器与自动设备生成，采集与价值分离，全面记录即时系统可产生巨量价值。记录数据与利益不直接相关，仅为采集过程的记录。网络时代主体间有效连接，实时记录提升主体对操作行为的负责程度。随着互联网经济与实体经济融合，网络操作记录成为经济发展基本保障。目前最突出的价值在于预测未来。人们通过记录发现规律特征，优化系统以预测运行模式，实现价值。企业与国家正通过深入挖掘大数据了解系统运作并协同优化。

### 2. 大数据的挑战

#### 1）大数据对业务的挑战

企业业务部门对大数据及应用场景与价值认知不足，内部数据孤岛严重。挑战即机遇，通过大数据分析改进业务，可创造三大优势：整合销售数据与洞察供客户了解产品优缺点，间接说明受欢迎程度或质量；将先进分析技术集成到产品中，创造更多智能产品；利用大数据分析提升客户关系与体验。

#### 2）大数据对技术架构的挑战

（1）数据处理存储挑战：高性能共享问题、文件管理与保护问题、重复数据问题。  
（2）数据分析挑战：非结构化数据急剧增长，传统挖掘分析技术降低效率，影响时效性。  
（3）数据安全挑战：大数据可能包含大量个人隐私，涉及企业重要信息与核心技术，存在安全隐患，甚至威胁国家安全。

#### 3）大数据对管理策略的挑战
