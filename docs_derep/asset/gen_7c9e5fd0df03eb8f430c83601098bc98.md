import requests

# DeepSeek API配置

API_URL = "https://api.deepseek.com/v1/completions"

API_KEY = "your_api_key_here"                  # 替换为用户的API密钥

HEADERS = {

    "Authorization": f"Bearer {API_KEY}",

    "Content-Type": "application/json"

}

# 前缀建模实现

def prefix_completion(prefix, model="deepseek-v3", max_tokens=100, temperature=0.7, top_p=0.9):

    """

    调用DeepSeek实现前缀建模

    :param prefix: 前缀内容，用于引导生成

    :param model: 使用的模型

    :param max_tokens: 最大生成长度

    :param temperature: 控制生成的随机性

    :param top_p: 概率裁剪

    :return: 模型生成的内容

    """

    payload = {

        "model": model,

        "prompt": prefix,

        "max_tokens": max_tokens,

        "temperature": temperature,

        "top_p": top_p

    }

    response = requests.post(API_URL, headers=HEADERS, json=payload)

    if response.status_code == 200:

        return response.json().get("choices", [{}])[0].get("text", "").strip()

    else:

        return f"请求失败，状态码：{response.status_code}, 错误信息:{response.text}"

## **7.2 FIM生成模式解析**

FIM 即 Fill-in-the-Middle 填中补全，是一种先给出前后语境再让模型补全中间缺口的生成范式。这一范式在代码自动补全、文档补全和文本修复等任务中应用广泛，能够基于上下文结构和目标需求生成连贯的中间内容。本节深入介绍 FIM 的定义与流程，并探讨 DeepSeek 在该任务上的优化思路。

## **7.2.1 FIM任务定义与生成流程**

FIM 流程指用细粒度的任务指令引导模型产出更贴合目标的输出。它借助指令式学习，在给定明确任务指令后让模型更精准地完成特定任务。FIM 被广泛用于文本生成与代码生成，能够提升模型在特定场景下的表现与灵活性。

FIM 的核心在于明确任务的输入与期望输出，并结合训练数据进行微调，使模型更好地理解任务意图，从而生成符合要求的文本。该过程既要对任务做清晰定义，也要对训练数据做针对性调整，以最大化任务达成度。

FIM 的典型流程包含以下环节。
- **（1）任务定义：** 明确任务的输入输出格式。
- （2）任务标注：将任务与数据进行标注，保证输入输出结构一致。
- （3）模型微调：针对特定任务做微调以适配需求。
- （4）生成与评估：用任务指令驱动模型生成，并对结果进行评估以确保符合预期。
