## 核心数学基石：Swish (SiLU) 激活函数

首先明确一个贯穿现代检测器（如 YOLOv5/v8）的非线性单元——**Swish 函数**（即 SiLU），其数学表达式如下：

$$ f(x) = x \cdot \text{sigmoid}(\beta x) = \frac{x}{1 + e^{-\beta x}} \tag{3-1} $$

该函数兼具 ReLU 的非饱和性与 Sigmoid 的平滑特性，`\beta` 为可调参数（通常设为 1），在深层网络中能有效缓解梯度消失，提升特征表达能力。

def convert(size, box):

    dw = 1. / size[0]

    dh = 1. / size[1]

    x = (box[0] + box[1]) / 2.0

    y = (box[2] + box[3]) / 2.0

    w = box[1] - box[0]

    h = box[3] - box[2]

    x = x * dw

    w = w * dw

    y = y * dh

    h = h * dh

    return (x, y, w, h)

## 实战二：生成带标注的训练清单用于聚类 ([PRE1])

在进行先验框聚类前，我们需要一个包含**图片路径+所有目标框绝对坐标+类别 ID**的纯文本文件。此脚本遍历 `JPEGImages`，定位对应 XML，过滤 `difficult` 标签，输出适配聚类脚本的 `train_anchors.txt`：

[PRE1]python

import xml.etree.ElementTree as ET

from glob import glob

import os

classes = ['red','green','left','straight','right']

dataset_path = './dataset'

def convert_annotation(_image_file, _list_file):

    xml_file = _image_file.split(os.sep)[-1].replace('.jpg', '.xml').replace('JPEGImages', 'labels')

    xml_file = os.path.join(dataset_path, 'Annotations', xml_file)

    print(xml_file)

    #in_file = open(xml_file, 'r', encoding='UTF-8')

    tree = ET.parse(xml_file)

    root = tree.getroot()

    for obj in root.iter('object'):

        difficult = obj.find('difficult').text

        cls = obj.find('name').text

        if cls not in classes or int(difficult) == 1:

            continue

        cls_id = classes.index(cls)

        xmlbox = obj.find('bndbox')

        b = (int(xmlbox.find('xmin').text), int(xmlbox.find('ymin').text), int(xmlbox.find('xmax').text),

             int(xmlbox.find('ymax').text))

        _list_file.write(" " + ",".join([str(a) for a in b]) + ',' + str(cls_id))

image_files = glob(os.path.join(dataset_path, 'JPEGImages', '*.jpg'))

list_file = open('train_anchors.txt', 'w')

for image_file in image_files:

    list_file.write(image_file)

    convert_annotation(image_file, list_file)

list_file.write('\n')

list_file.close()

## 实战三：基于 IOU 的 K-means 聚类求解最优先验框 ([PRE2])

YOLO 通过聚类预先确定一组先验框尺寸，加速收敛。标准欧氏距离不适用于框回归，故采用 **IOU (Intersection over Union) 作为距离度量**（距离 = 1 - IOU）。

下方代码定义了核心的 `YOLO_Kmeans` 类，并实现了向量化的 IOU 计算逻辑，为后续迭代聚类奠定基础：

[PRE2]python

import numpy as np

class YOLO_Kmeans:

    def __init__(self, cluster_number, filename):

        self.cluster_number = cluster_number

        self.filename = filename

    def iou(self, boxes, clusters): #1 box -> k clusters

        n = boxes.shape[0]

        k = self.cluster_number

        box_area = boxes[:, 0] * boxes[:, 1]

        box_area = box_area.repeat(k)

        box_area = np.reshape(box_area, (n, k))

        cluster_area = clusters[:, 0] * clusters[:, 1]

        cluster_area = np.tile(cluster_area, [1, n])
