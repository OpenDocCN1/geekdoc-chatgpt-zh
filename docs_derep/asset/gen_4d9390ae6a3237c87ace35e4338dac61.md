### 2.3 本地大模型部署及使用

本节围绕本地部署的核心流程，系统介绍算力、环境依赖等要求，涵盖模型下载、推理验证等关键环节，并与主流第三方部署工具做对比，为后续 Agent 开发提供运行基础。

#### 2.3.1 本地大模型部署需求概览

在实际应用中，出于数据安全、访问稳定性、成本控制、模型可控性等多方面考量，越来越多的开发者和企业倾向于将大模型部署在本地或私有云。本地部署可以掌控推理过程，降低隐私数据泄露风险，减少长期接口费用，提升响应速度并支持离线运行。同时本地部署也意味着更高的资源门槛和工程复杂度，动手前需对以下关键需求做全面评估。

##### 1. 算力资源

在所有本地部署条件中，算力资源尤其是 GPU，是能否成功运行大语言模型的决定性因素。某些轻量场景可尝试 CPU 模拟推理，但速度和效率远不如 GPU，对中大型模型基本不可行。因此部署大模型首先要具备相应规模的 GPU 硬件。

> **说明**
>
> 为什么不能只用 CPU？
>
> 大语言模型推理涉及十亿级参数的矩阵计算，Transformer 架构中包含大量矩阵乘法、归一化、注意力计算等高强度并行任务。GPU 在并行数值计算上优势明显，而 CPU 更擅长逻辑控制与串行任务。同等条件下，CPU 推理速度可能只有 GPU 的 1/100 至 1/10。

在推理场景下不同模型参数规模对应的显存需求如表 2.2 所示。

**表 2.2 不同模型参数规模对应的显存需求**

| 模型规模 | 推理时显存需求（FP16） | 支持的典型 GPU（单卡） |
| :--- | :--- | :--- |
| 7B | 14GB～16GB | RTX 3090 / 4090 / A500 |
| 13B | 26GB～30GB | RTX 4090（24GB）基本可运行 |
| 33B | 60GB～80GB | 多卡 A100 或 2×4090 并行 |

若采用量化技术如 INT4、INT8、GPTQ 等，推理所需显存通常可减少 1/4～1/2。以 7B 模型为例，FP16 推理需 14GB～16GB 显存，INT4 量化后只需 4GB～6GB，可在单张 RTX3060/4060 甚至笔记本 GPU 上运行。

当前大模型训练与推理绝大多数基于 NVIDIA GPU，得益于成熟的 CUDA+cuDNN+PyTorch 生态。主流 GPU 型号如表 2.3 所示。

| 类型 | 常见型号 | 适用说明 |
| :--- | :--- | :--- |
| 数据中心级 | A100, H100, A800, L40S | 高稳定性、高带宽，适合集群部署 |
| 消费级高端 | RTX 3090, 4090, 4080 | 适合个人开发与小模型推理 |
| 云租用平台 GPU | Tesla V100, T4 | 支持量化模型，成本可控 |

若本地无 GPU，可租用云平台算力进行实验。AutoDL、阿里云 PAI、百度飞桨 Studio、Google Colab 等均提供在线 GPU 租赁服务。

1) 操作系统

建议优先使用 Ubuntu，其发行版稳定且兼容 CUDA，完整支持 NVIDIA 工具链。虽然 CentOS 和 Windows 搭配 WSL2 也能运行部分模型，但不推荐用于正式生产环境，存在兼容风险。
