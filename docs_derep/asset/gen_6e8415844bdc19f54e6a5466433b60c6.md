#### 13.4 三、 核心方法论：数据预处理与 EDA 的“黄金提问清单”

拿到新数据集，不妨按此清单逐层拆解，避免盲建模：

| 维度 | 关键动作 | 典型手段 |
| :--- | :--- | :--- |
| **结构确认** | 是否为结构化表格？非结构化需先转 DataFrame。 | `pd.read_csv`, `json_normalize` |
| **行粒度** | 每行代表什么业务实体？ | 业务确认、字段推断 |
| **列语义** | 每列含义、尺度（名目/顺序/等距/比率）、质/量属性。 | 数据字典、`dtypes` |
| **缺失诊断** | 哪些列缺失？缺失比例？删除/填充/插补策略？ | `isnull().sum()`、均值/中位数/众数填充、KNN/模型插补 |
| **类型转换** | 分类→数值？量纲差异大是否需标准化/归一化？ | `map`/`LabelEncoder`、`StandardScaler`/`MinMaxScaler` |
| **分布洞察** | 集中趋势、离散程度、偏态、峰度、异常值。 | `describe()`、直方图/箱线图/小提琴图 |
| **关系探索** | 变量间相关性、非线性模式、分群差异。 | 散点图矩阵、相关系数矩阵、协方差、分组聚合 |

**本质区别**：
- **数据预处理** 侧重“修补”：把脏数据变干净、把文本变数字、把量纲统一。
- **探索性分析 (EDA)** 侧重“理解”：用可视化与统计量挖掘规律、提出假设、指导特征工程。
