## 3.2 控制流总览

### 三类选择语句

Python 提供三种选择语句，依条件真值执行代码：

| 语句 | 行为 |
|------|------|
| `if` | 条件为真则执行，为假则跳过 |
| `if-else` | 真执行分支 A，假执行分支 B |
| `if-elif-else` | 多条件链式判断，执行首个为真的分支 |

每个分支或为单语句，或为多语句块（套件）。

### 两类迭代语句

- `while`：条件为真则重复执行（块）。
- `for`：遍历序列每项执行（块）。
