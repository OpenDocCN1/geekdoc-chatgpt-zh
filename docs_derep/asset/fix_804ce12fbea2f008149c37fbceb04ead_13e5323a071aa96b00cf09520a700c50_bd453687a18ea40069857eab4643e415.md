# 前言
# 智能重塑法律服务底层

当围棋程序战胜世界冠军时，多数法务从业者只当作科技新闻。直至生成式系统通过美国律师资格考核，Harvey 这类产品进入头部律所的合同起草链路，行业震动才变得具体。近两年市场明显分化：一面是深夜还在堆案卷的律师，一面是借助智能工具大幅提升人效的团队；一面仍靠实习生手工找案，一面已搭建起智能案件推演平台。分化根源不在预算，而在认知。对智能工具的理解深度，已成为专业能力的新分水岭。

业界一句流传很广的话：智能会让所有产品被重做一遍。既然如此，法律从业者也需要把这些好用的新手段重新学一遍。本书《法律人 AI 实操指南进阶版》正是面向这场变革的高阶实战手册。作者不讨论人工智能是否会取代律师的终极问题，而是聚焦更紧迫的命题：如何把人工智能转化为法律人的第二大脑与第二双手，在保持专业水准的前提下实现效率跃迁。内容来自对数十家法律科技项目的深度实测，覆盖从业者最高频的刚需场景，围绕三组核心问题展开：

其一，如何穿透工具表象，直达法律场景的真实痛点。第一模块系统拆解高频场景的解决方案。从模板投喂到指令工程，从内容美化到合同智能化。当你看到 MD2card 把晦涩术语变为高颜值知识卡、基础模型完成精准案件推演时，会明白专业壁垒与效率提升可以共存。

其二，如何跳出通用工具的局限，搭建专属智能方案。第二模块进入定制化深水区。从搭建 IMA 资料库实现知识管理，到用 LoRA 微调让基础模型从通才变专才，始终坚持工具为人服务的原则。零代码开发与手搓智能体的章节会证明，没有技术背景的法律人也能主导人工智能产品。

其三，如何在人机协作中重塑职业价值。当智能技术能包办六成基础工作时，核心竞争力正从信息处理转向复杂判断。第三模块从方法论切入，覆盖律师助理、独立律师、律所合伙人、主任、法务、法总等不同角色的转型路径与角色认知再造。工具会迭代，理念与认知才是决定能走多远的关键。

本书并非技术至上的鼓吹。在执业风险防范章节，我们汇总了全球法律人使用智能技术的典型事故案例。人工智能不是魔法，而是需要驾驭的烈马。

回望2025年的节点，行业已走过是否采用的争论期，进入如何用好的实操期。书中各章像拼图，读完后你会获得三重新视角：看清工具与场景的化学反应，看清工作方式的演进路径，更看清法律人在这场变革中的独特价值。

翻开本书的你，既是变革的亲历者，也将成为新实践的推动者。让我们一起开启法律人的智能进化。在智能重构一切的时代，最大的风险不是拥抱变化，而是错过与未来对话的入场券。

## 从业者在应用智能技术时的四类典型困境与应对

**一、模型虚构问题**

在文学艺术领域，模型的创造性偏差有时被视为优点，但落到法律、医疗这类高准确度行业，捏造条文与案例就是致命风险。实践中已出现律师因引用模型虚构内容被法院处罚的先例。

破解思路
1. 接入自有资料库。让模型从可信库中提取信息，用资料库约束生成。腾讯新上线的 IMA 资料库依托微信生态，实操性强。未来基础模型能力差距会收窄，资料库建设能力将成关键差异。
2. 接专业模型。市场出现越来越多挂载行业法条、案例库的垂直模型，尤其原做专业数据库的公司更有先天优势，可靠性更高。
3. 指令约束加多模型交叉核验。使用时明确指令不可编造，需给出出处，并用另一模型复核同一输出，避免单点信任。
4. 自己做最后一道防线。作者不建议在完全不熟悉的领域依赖生成式系统做实务，只能用于学习。用于工作需在自己熟悉的专业内，且有足够功底一眼揪出问题。没有金刚钻不揽瓷器活，专业储备越高，眼光越挑剔。

**二、数据安全与保密**

一线律师和法务最怕把公司业务信息喂给模型导致泄密，三星事件就是警示。但不提供素材，智能又难发挥，如合同审阅、基于证据起草诉状。

应对方式
1. 本地化部署。数据不出境，安全性更好，但技术门槛和运维成本高，模型更新也需维护，更适合律所、法务部等机构用户。
2. 脱敏后再投喂。对上传内容做脱敏或提炼问题后再输入。脱敏可人工完成，也可用 WPS、Adobe 等本地工具或专业脱敏软件辅助。

**三、生成内容机造感过重**

机造感源于模型的高度结构化生成逻辑。法律文本本身重逻辑，适度结构化未必坏。但过重的机造感让读者一眼识破，降低对人参与度的信任。客户自己也能用智能，为何还要付费给律师。

应对方式
1. 给出示范样本让模型模仿。模仿能力是模型的强项。
2. 指令里说明使用场景和受众。告知模型面向谁、用何种风格。例如解读技术原理给法官时，要求“用通俗语言表述但不失准确，以便非技术背景理解”，模型会给出更直观的类比。
3. 人工去机造感。作者更主张人对智能输出做润色和点睛。智能完成八成，剩下两成必须人工干预，既去机造感，也注入个人逻辑、思考和创造性，让成果真正可用。

**四、对自身价值缺乏清晰认知**

智能越强，越易产生被替代恐慌，或因低估智能能力而让机器能做的事仍人工完成，造成资源浪费。关键是厘清人机分工。

应对方式
人的优势至少包括：
1. 发现和提出好问题。好问题提出后，大部分执行可交给智能。长期使用后会发现，人有多大胆，智能就有多大产。善于捕捉客户真实需求并转化为智能可执行的问题，是核心能力。
2. 提供思路与分析维度。智能有“看人下菜碟”的特点，能力越强，输出越匹配；水平平平则会被敷衍。相关展开将在书中另行讨论。

## 法律人提升指令设计能力的八条进阶技法与正反示例

**进阶要点**

不少从业者过度迷信指令的威力。随着基础模型理解和推理能力提升，大部分复杂需求可一次性提出，模型会自动拆解并展示推理过程，过度打磨指令的必要性在下降。但在法律领域，模型需要更收敛、更准确、不杜撰、更高效，这些诉求仍可通过指令优化实现。

**进阶路径**

**技法 1：设定角色**
让智能装上导航
原理：明确智能的法律身份，限定专业边界。通过角色引导模型聚焦特定知识域。例如指令含“你是一名专业知识产权律师”，模型会优先调用著作权、专利、商标、侵权相关语料。可进一步抬高要求，如“国内顶级商标律师，请用最高专业水平分析”，模型会更谨慎输出。
错误示例：“分析这个合同条款是否有效，条款如下：××××”
正确示例：“你是一名专注合同法的资深律师，分析以下条款法律效力，重点说明其作为格式条款无效的可能性。条款如下：××××”

**技法 2：要求有出处**
杜绝模型乍说
原理：要求回复中涉及数据、案例、法条必须给出明确出处或链接并自行核验，可显著降低虚构。补充“不可自行编造”属于负向指令，能降低虚构类表述的生成概率。
错误示例：“购买使用第三方关键词进行搜索推广是否合法？”
正确示例：“依据近三年北上广深及最高院官网公布的生效判决，分析购买使用第三方关键词进行搜索推广的法律后果，需引用具体法条和案例编号并标明出处链接，不可虚构。”
该做法仅能降低风险，仍需人工核验。

**技法 3：自我验证与交叉验证**
原理：将生成结果再喂回模型要求核实，或用 A 模型结果投喂给 B、C 模型比对一致性，能修正部分错误。
示例
原始生成：“根据《民法典》第123条，AI生成物可视为著作权法保护作品。”
核查指令：“请核实上述结论是否与引用的《民法典》条文内容一致。”
修正结果：“经核查，《民法典》第123条规范民事权利取得方式，与著作权无关。正确依据应为《著作权法》第3条作品定义。”
此法对知识库内明确冲突的错误有效，对虚构冷门法规则难以识别。为防二次虚构，需要求模型到源头出处核对。

**技法 4：给出分析方法**
像法律人一样拆解问题
要求智能按特定方法输出，如侵权构成要件分析。常见 IRAC 框架：识别争议焦点、引用法条、结合事实适用、推导结论。结构化指令能激活定向检索，减少随机性。
错误示例：“××××这个案情下，商标侵权该怎么打？”
正确示例：“请按侵权要件分析以下行为是否构成商标侵权：1.权利基础；2.相同/近似性对比；3.混淆可能性；4.抗辩事由。”

**技法 5：明确输出样式**
没有形式就没有内容
告知模型以法律意见书、起诉状、对比表等形式呈现，能提升可用性。模型会调用对应格式、语言和排版知识。
错误示例：“写一份竞业限制协议。”
正确示例：“起草一份《竞业限制协议》模板，含主体信息、竞业范围、补偿金计算、违约金条款，并按条款加法律依据注释排版。”

**技法 6：划定思考线索与范围**
避免大海捞针
在指令中限定领域、焦点、参考判例，减少泛化。
错误示例：“元宇宙虚拟财产受保护吗？”
正确示例：“聚焦2020年后中国司法实践，从《民法典》《反不正当竞争法》、平台用户协议三维度，分析元宇宙平台内虚拟财产的法律保护路径，排除刑法视角。”

**技法 7：按受众设定表达风格**
法律内容面向法官、公众、学术，风格应不同。指令可要求去机造感。
错误示例：“根据相关法律规定解释说明公司减资程序。”
正确示例：“以《公司法》为依据说明有限责任公司减资法定程序，要求严谨且通俗易懂，让无法律背景股东听懂，接近真实人工表达，不要有机造感。”
