# 丛书导语

当下正处百年未有之大变局，国家的整体竞争力根植于工业实力，而工业的跃升离不开工业软件的牵引作用。工业软件正重塑工业领军者的核心灵魂。

2021年5月28日，习近平总书记在两院院士大会、中国科协第十次全国代表大会上强调，科技攻关要突出问题导向，直面最紧迫的难题。要以国家迫切需要和长远需求为出发点，在油气、基础材料、高端芯片、工业软件、种业、科研仪器、化学制剂等关键领域集中攻坚，加速药品、医疗器械、医用设备、疫苗等关键技术突破。

把工业软件列为最紧迫的国家核心议题，体现了国家意志的空前高度。机械工业出版社领衔推出本套工业软件丛书，秉持系统性、专业性、全局性与前瞻性的原则，开展生态研究、规律探索、全景呈现与成果汇聚，以助力产业数智化升级。丛书面世是落实国家意志的实际举措，意义深远，时机恰当。

全书分为产业研究与生态构建、技术与产品、支撑环境三大板块。

产业研究与生态构建部分收录了工业技术软件化专项研究、工业软件发展生态研究、工业软件分类研究、质量与可靠性测试研究、标准规范研究等内容，意在从顶层设计视角揭示技术之外的制约因素。例如，软件的可靠性与安全性测试长期缺乏重视，但随着软件以软部件、软装备形式深度嵌入各式工业品，其可靠与安全对产品的影响将日益关键，甚至具备一票否决意义。制约发展的政策、制度、环境及工业技术积累等基础议题更需深入探讨。

技术与产品板块是一个生机勃勃、持续演进的大家族。据不完全统计，工业软件品类已近两万种。如何以小样本、大视野、深挖掘的方式呈现，是巨大挑战。连工业软件这一术语本身，也是伴随实践逐步凝结共识的。准确阐述需以国家统计局工业门类为依据，将应用于矿业、制造业、能源业三大领域的软件全部纳入，而非局限制造；分类上既要兼顾CAX、MES等既有体系，也要面向工研软件、工管软件等未来形态；架构上既要关注ISA95等传统体系，也要关注云订阅式SaaS模式；产权上既包含商用产品，也包含企业自研内嵌系统。本丛书力求多维呈现中国工业软件全貌，虽为粗线条勾勒，却力求覆盖。

支撑环境是不可或缺的数字底座。数据库、云服务、材料属性库、图形引擎、流程语言、工业操作系统等，都是各类软件发挥功能的基石。底座不牢，无以自立，更谈不上可控。没有强有力的运行支撑，就没有强有力的工业软件。

长期以来缺芯少魂制约中国企业高质量发展。自2018年起，贸易摩擦演变为多样的断供压力，芯片断供尚可对冲，而工业软件断供则直接剥夺企业的设计与制造能力。缺少这一基础性数字化工具与软装备，工业品无法被设计与制造，社会或停摆，企业或致命，先进设备或沦为废铁。工业软件对工业发展的支撑、提振与杠杆放大效应，已被全社会切身感知。

本丛书的问世有望揭开工业软件的神秘面纱，厘清发展规律，并激励从业者发挥上九天揽月、下五洋捉鳖的想象力与执行力，让每一行代码、每一段程序都书写时代新篇，推动中国工业软件整体发力，攻坚克难，携手创新，早日跻身全球第一梯队。

# 序一

拜读施战备、刘强、刘丽兰合著的《AI赋能研发数字化转型：技术驱动和范式重构》，厚重、前瞻与价值感扑面而来。

厚重在于底蕴。全文围绕六大议题展开：企业数字化转型模式、人工智能技术演进、人工智能在制造领域的作用、研发范式的跃迁、研发数字化重构、人工智能赋能的研发范式跃迁及转型路线图。这些皆关乎当下与未来较长周期的产业与企业核心议题。作者能穿透表象把握本质与规律，论述系统透彻。如言制造业数字化转型绝非简单堆砌，也无捷径，需管理者怀十年磨一剑的定力，将数智融入企业血脉，成为成长基因。此等见解非长期积累与科学分析难以得来。

前瞻在于直面研发与人工智能结合的前沿难题。研发是企业竞争力的核心，人工智能是研发的赋能手段，二者如何融合是当下诸多企业的痛点。传统产品研制长期受职能壁垒、数据断链、流程僵化困扰，研发周期长、成本高、创新效率不足，已成为制约迈向全球价值链高端的瓶颈。要从制造大国迈向制造强国，必须实现从底层逻辑到顶层设计、从工具到范式的深刻变革。本书前五章作铺垫，后三章给出系统可操作的建议。

价值在于重要结论与实践方法。作者指出，企业常出现技术狂热与落地困境的巨大落差，盲目跟风导致失败案例频出。回顾人工智能技术及其在制造领域应用历程后，决策者需审视生成式人工智能是机遇抑或陷阱、当前数字化成熟度是否适合全面应用等议题，并对成熟度与适用性作出系统解释。

关于人工智能驱动的研发范式转型，核心是将传统串行、经验驱动的模式，转变为并行、数据驱动、人机协同的新模式，从依赖工程师个人经验的匠人模式，迈向依赖数据智能与协同创新的智慧研发模式。

书中结合制造实际，分析了人工智能赋能的研发数字化转型场景：基于虚拟数字原型的设计-仿真-测试协同、基于MBD的制造信息流、参数驱动的制造数字主线等。

作者总结出数字化转型四层驱动模型，分数据治理、能力沉淀、流程贯通、智能应用四个层面逐级突破，并系统阐述各层形成路径。

作者认为人工智能在制造领域的价值实现高度依赖数据、算法、算力协同，其中数据居核心。数据是人工智能之本，缺乏高质量数据，模型如无源之水。更需强调的是，人工智能应被视为赋能人类的工具，而非完全替代，尤其在突发中断与不确定情境下，人类经验与智慧不可或缺，人类监督与领域知识在全生命周期中发挥关键作用。

在人工智能加与数转智改浪潮中，本书出现令人瞩目，期待其价值在创新实践中充分释放。

是以为序。

# 序二

人工智能技术浪潮席卷全球，以深度与广度重塑各行各业。作为长期深耕制造业数字化的工程科技工作者，我见证了这场变革的演进。受邀为《AI赋能研发数字化转型：技术驱动和范式重构》作序，深感荣幸。初读即为其系统性、前瞻性与实践性振奋。

我国制造业转型升级的关键期，面临激烈竞争与复杂需求。传统研发范式长期受职能壁垒、数据断链、流程僵化等结构性痼疾困扰，研发与制造、设计与仿真、生产与服务难以打通，导致开发周期长、成本高、创新效率低，削弱核心竞争力。过去靠逆向工程或仿制虽能追赶，却难生原始创新。如今人工智能的融入不是工具升级，而是从根本上改变产品开发理念、重塑价值创造模式的深刻革命。作者敏锐指出人工智能正在推动研发范式数字化转型，企业应从自底向上经验驱动转向自顶向下需求驱动，实现以需求牵引的正向协同设计。

本书亮点在于超越技术中心主义，构建了一套全面协调的人工智能驱动四维进阶框架，为企业提供务实前瞻的转型指南。

其一，战略层面，框架要求把宏大的AI优先愿景拆解为具体、可量化、可验证的ROI业务目标。企业高管既是技术采纳者，更是变革战略设计师，确保投入能直接贡献于降低劣质质量成本CoPQ、缩短产品上市时间TTM等核心指标。

其二，业务架构是框架核心，既描绘运营蓝图，也明确转型载体。书中阐述业务架构如何从能力在线这一零散职能数字化基础，演进为以价值为中心的业务流程整合，最终实现端到端业务在线、价值流闭环。过程依托贯穿订单到交付OTD、研发、制造等核心价值流的数字主线，打破组织壁垒与数据断链，实现全流程无缝连接与智能协同。

其三，平台化人工智能技术架构为制造企业量身打造，由数据架构、应用架构、技术基础设施三层构成，将人工智能能力封装为服务，保障能力与应用的阶梯式进阶。

其四，人工智能赋能的研发数字化转型与创新应用场景描绘出令人鼓舞的图景：人工智能驱动的需求获取将客户声音转化为可量化设计指标；人工智能赋能的设计-仿真-测试协同借助虚拟数字原型与人工智能仿真缩短周期、降低试错成本；基于MBD的制造信息流实现设计意图无缝传递；参数驱动的制造数字主线通过人工智能实时分析生产数据，实现工艺参数到设备参数的精密控制，构建自动化质量闭环；质量数字主线打通设计、工艺、制造、服务质量数据，实现全生命周期追溯与持续优化。

尤为难得的是对人工智能智能体AI Agent的前瞻性介绍。2025年或被视为人工智能智能体元年，未来企业将运行各类智能体。但工程领域对智能体认知尚模糊。本书不仅阐释其定义、特征与核心组件，还详细介绍通用设计模式如反思模式、工具使用模式、推理模式、规划模式，多智能体系统、开发框架及最佳实践，对入门者极具参考价值。

总之，本书为制造业数字化转型提供了宝贵指南，既描绘智能研发蓝图，也指明关键路径、技术框架与组织保障。无论高管、研发工程师、学者或政策制定者，均可从中获得启示。

是以为序。

# 序三

世界变化迅疾，数字世界变化尤甚。2025年，全球人工智能大模型头部企业你追我赶、此消彼长，展开关乎企运乃至国运的技术竞赛，亦是一场无硝烟的赛博战争。

若人工智能各路高手各显神通属常态，令人意外的是，本书作者深耕工业一线，立足工业软件高地，写下论述人工智能如何赋能企业研发数字化转型的厚重专著，实属精品。

本书面向制造企业，聚焦人工智能重构研发范式的实战方法论。以一个平台化人工智能分层架构、两类人工智能技术、三要素协同、四层数字化转型驱动模型、五阶研发范式跃迁，搭建从战略规划到落地实施的完整路径，系统回答生成式人工智能对制造业究竟是机遇还是陷阱，绘就一二三四五行动地图。

1）一个平台化人工智能分层架构。作者提出制造业人工智能栈需精细分层：基础设施层CPU/GPU/云边混合、数据/知识层数字主线加知识图谱、模型服务层机理模型与大语言模型混合部署、智能体编排层流程自动化加多智能体协作、人工智能应用层角色APP，并给出各层买改建决策矩阵，避免一蹴而就之困。

2）两类人工智能技术，即大语言模型与智能体。大语言模型不仅是技术突破，更是认知范式革命，从依赖人工规则的模仿智能迈向基于海量数据自学习的泛化智能；智能体被拆解为感知-推理-记忆-工具-规划的五巧板，多智能体编排可分为中心化、去中心化、层级化三种架构，可映射至汽车、医药、装备等行业组织模式。熟练运用将颠覆研发范式。

3）三要素数据、算法、算力协同。核心驱动力源于三者共进化，形成数据语境化、算法复合化、算力分级化新范式：数据层面依托数字主线将异构数据转化为蕴含设计意图的高质量语料；算法层面构建大语言模型加知识图谱加强化学习的复合架构，取代单一垂域模型；算力层面采用多级蒸馏技术，将千亿参数模型压缩适配车间工控机，实现云边端无缝贯通。

4）四层数字化转型驱动模型。作者将作用机理拆解为数字底座、数字能力、数字业务、数字应用四层，通过数字主线上数据流实现全方位贯通，达成单一来源数据提效目标。书中对数据、模型、服务逐层解耦反复论述，业务颗粒度可随企业战略调节。

5）五阶研发范式跃迁。作者引述前人分期，将研发史划分为试验驱动、理论驱动、计算驱动、数据驱动、人工智能驱动五级进阶，每次进阶伴随知识载体更替：经验、公式、代码、数据、模型。人工智能驱动范式三大标志为：认知权从人转向人加模型；流程从设计到验证的线性串行转为生成反思的多次循环；知识形态从静态文档变为可演化参数。该思想贯穿全书。

我认识第一作者施战备十余年，深知其二十余年深耕工业软件，对PLM与CAX见解独到。五年前曾为其《数物融合：工业互联网重构数字企业》作序。此次新作笔力更稳、底蕴更厚、入微更深、前瞻性更强。

不夸张地说，作者融汇了理工男的螺丝刀、战略家的望远镜与预言家的水晶球，为读者绘制制造业星际航图。既能把Transformer、RAG、LoRA等硬核技术拆解为七步成诗的操作清单，又能把战略、组织变革、财务ROI等顶层难题绘成指路罗盘。全书以数据、案例、可解耦可重构的代码为读者探路，把生成式人工智能从营销热词变为车间传感器，把多智能体从遥不可及变为研发助手，把数字化转型从PPT叙事变为工程师可攀爬的脚手架。

人工智能融入制造业并非工具升级，而是改变产品开发理念、重塑价值创造模式的深刻革命。本书将生成式人工智能如何落地制造业拆解为一二三四五的甘特图，提炼为模型即研发语言、智能体即数字员工、数据语境化即治理三句箴言，为制造企业从经验驱动跃迁至人工智能驱动提供可复制的工程剧本。余下即共同赏析、一起演出。
