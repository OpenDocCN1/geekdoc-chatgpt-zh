**准确性核对：** 王老师把AI生成的教学方案逐项与正式教材对照。有丝分裂各时期的描述与教材基本一致，减数分裂的表述则较为简略，他随后查阅专业文献把被省略的细节补充完整。

**中立性审视：** 生成式AI在阐述细胞分裂功能时，容易过度凸显增殖的积极意义，而弱化凋亡等维持体内平衡的机制。王老师在课堂上额外补充了平衡视角，引导学生讨论细胞生命周期中的整体调控，保证获取的观点更全面。

**课堂讨论环节：** 在讲解“基因突变与细胞分裂异常”时，王老师借助AI生成的讨论问题来启发思考。

**中立性审视：** 他要求AI设计的问题既要涉及突变的负面影响，也要包含其在进化中的积极价值，确保讨论兼顾多元立场。

**作业批改与反馈：** 王老师使用AI工具批改学生的实验报告并自动生成评语。

**准确性核对：** 他抽样检查评语，要求实验数据的分析与教材标准保持一致。

**中立性审视：** 部分评语偏概括，王老师在反馈时追加更具体的改进建议，使评价更真实地反映学生表现。

把生成式AI的性能指标与具体应用目的和场景相挂钩进行测评，并结合交叉验证、专家意见、情境适配及多角度比较，教师能够为不同场景挑选最合适的工具，有效管控潜在教学风险，形成与场景相匹配的AI工具清单，为教学中充分发挥工具价值做好准备。

#### 5. 持续迭代和优化个人生成式AI工具箱及资源库
生成式AI工具箱与资源库需要在实践中不断完善。教师可通过撰写应用日志或教学案例，持续梳理常用工具的长处与局限，反思“哪个工具使用频率最高、原因何在”“使用中有哪些误区、如何规避”等问题，动态更新个人工具清单，让资源库保持迭代。

#### 6. 建立生成式AI应用规范
教师使用生成式AI要保障数据安全、遵守伦理规范，切勿上传含学生真实信息的文件、题库、答题卡等敏感材料，避免对AI产生过度依赖。同时应向学生和家长解释生成式AI的特点与功能，引导其在合乎伦理的前提下合理使用。

## 第2节 精准提问：点亮生成式AI潜能的提示词设计思路
生成式AI能否发挥作用，关键看使用者能否给出高质量提示。掌握提示词设计是教师驾驭生成式AI的核心素养。与AI的交互不是随意问答，而是一种借助精心设计的指令引导其产出高质量结果的“对话式编程”。

联合国教科文组织《教师人工智能能力框架》强调以人为本的人工智能应用原则。人机协同不是单向响应，而是教师调动AI、激活AI以获得最优输出的过程。

### 一 提示词设计框架：与生成式AI高效互动的“PRTSCE”模型
教师提示词设计的“PRTSCE”六维模型，Purpose-角色-Role-任务-Task-策略-Strategy-约束-Constraint-评估-Evaluation，遵循人机协同规律，通过结构化语言激发潜能，产出服务教学目标的高质量内容。

### 表2-4 教师提示词设计的“PRTSCE”六维度模型
| 维度 | 核心要素 | 关键问题 | 操作要点 |
| :--- | :--- | :--- | :--- |
| 明确目的 Purpose | 教学目标、观点立场、价值导向 | 生成内容要服务于何种教与学目标 | 以目标牵引、指向明确、体现情境、明确风格 |
| 明确角色 Role | 专家定位、职责说明、表达风格、限制要求 | 希望AI以何种身份或语气完成任务 | 身份具体如课程专家、学科名师、产出规范清晰 |
| 任务说明 Task | 任务类别、任务特征、结构化表述、任务拆解 | 指令是否清楚、任务是否适合AI理解执行 | 动词精准、结构清晰、适时调整优化 |
| 策略运用 Strategy | 示例引导、结构设定、语气把控、信息嵌入 | 如何让AI生成更准确更优质的内容 | 提供范例模板、设定输出结构、嵌入上下文 |
| 约束条件 Constraint | 形式选择、篇幅控制、主题限定、对象范围、语言设定 | 是否需要限定形式、范围、长度和场景 | 表格、图文或文字、字数限制、话题边界、匹配对象语境 |
| 分析评估 Evaluation | 输出评价、是否追问、提示归类、总结沉淀 | 如何判断提示是否有效、能否沉淀为资源 | 从适切性与语言质量评估、建立个人提示库 |

结合实例看“PRTSCE”在教学中的应用。地理教师李老师要为高一设计“比较两种气候类型”的自主探究活动，按框架拆解提示要点。

### 表2-5 教师提示词设计的“PRTSCE”六维度模型分析表
| 维度 | 提示词设计要点 |
| :--- | :--- |
| 明确目的 Purpose | 让AI生成适合高一地理课堂比较气候类型的自主探究方案，培养综合分析能力 |
| 明确角色 Role | 设定AI为“高中地理课程设计专家”，有丰富经验，理解新课标，能设计结构化且互动性强的活动 |
| 任务说明 Task | 需包含学习目标、探究任务及指导语、活动步骤、成果展示方式、师生评价方法 |
| 策略运用 Strategy | 用“请按以下结构：……”的清晰框架引导生成 |
| 约束条件 Constraint | 输出控制在600字以内，面向高一，使用教学场景，语言简洁清晰具启发性 |
| 分析评估 Evaluation | 生成后从结构完整、内容准确、活动可行三方面判断，可要求AI说明设计理念作反向检验 |

李老师据此撰写的提示词如下：

> 请扮演一位经验丰富的普通高中地理课程设计专家，熟悉新课标，擅长设计结构化、互动性强的探究任务。
> 
> 请为高一课堂设计一个自主探究学习活动，主题为比较温带大陆性气候与温带季风气候的差异。活动要培养学生的地理综合分析、观察探究能力，适配真实课堂。
> 
> 请按以下结构输出：
> 1. 核心素养目标
> 2. 自主探究任务内容及学生指导语
> 3. 学生活动步骤不少于3个环节，体现探究过程
> 4. 成果展示方式
> 5. 师生评价方法，含自评互评
> 
> 语言简洁清晰有启发性，总字数不超过600字，符合高一认知水平与课堂节奏。
> 
> 最后用不超过两句话说明设计理念依据。

与文心一言对话后，AI生成了学习活动方案，包含核心素养目标、探究任务与指导语、活动步骤、展示方式和评价方法，并附设计理念说明。李老师认为基于PRTSCE设计的提示词明确了方向、结构与风格，形成了“生成-评价-优化”闭环，提升了产出质量。即便前期投入提示设计时间较多，也能一次问询得到可用的方案，稍加修改即可上课。

实践中，提示词的详略应随任务复杂度调整。交互时对AI的身份设定会显著影响质量与风格，优质提示应明确身份+职责，如“你是专家型教研员，请分析并完善这份大单元作业”。长期使用PRTSCE模型可提升提示质量与思维能力。

### 二 教师设计提示词的五项操作策略
1. 分阶段设计提示词
把复杂任务拆成逻辑步骤，分阶段生成，便于把控结构，适合教学目标、活动设计、评价标准逐步构建的场景。
2. 设计角色扮演式提示词
把AI设定为领域专家、资深教研员、名师或课程专家，可提升专业性与情境适配度。
3. 设计结构化提示词
使用编号、分段、格式要求，减少理解偏差，确保条理清晰，适用于方案与评价表设计。
4. 示例引导
提供1-2个同类范例供AI模仿，能显著提升风格与格式契合度。
5. 递进式优化
首次生成不理想时，可针对性提出“请说明设计依据”“请增加学生互动”等补充要求，多轮迭代优化。

### 四 提示词不是关键词，而是教与学的“设计语言”
提示词实质是教师组织教学活动的设计语言，是启动AI理解并完成教与学任务的钥匙。提示词考验AI素养，也体现教师对教与学目标的深刻理解。谁能设计更精准高质量的提示，谁就能更好地激活AI潜能，开展高质量教学。

## 第 3 节 教育智能体创建：从0到1打造智能助手
生成式AI时代教师不仅是使用者，也是教育工具的设计者。打造贴合教学需求的教育智能体，已成为教师智能素养的新标志。创建过程是基于教学逻辑设定目标、设计交互、界定行为边界并迭代优化，形成真正具备教育功能的智能系统。

### 一 明确目标：你需要什么样的智能助手
创建第一步是聚焦具体教学科研需求。例如：
1. 教学辅助型：生成课件、练习题、学习资源。
2. 学习答疑型：充当虚拟辅导员，基于教学内容答疑。
3. 批改评价型：为作文、简答题提供初评与个性化反馈。
4. 研究助手型：文献梳理、问卷分析、数据处理。
初期可用“角色设定+功能目标”梳理痛点，明确定位，为技能设计与知识库构建奠基。

例如，李老师把智能体设定为高校教育学教师助理，熟悉“教育研究方法”课程，能按大纲生成案例讨论题、设计研究任务并指导文献综述写作。刘老师则设定为大学教师英文写作指导助手，为不同年级提供学术写作建议与润色点评。通过角色功能设定，智能体可精准嵌入教学辅导与研究。

### 二 选择生成式AI平台：在哪里创建教育智能体更合适
众多面向教育的生成式AI平台支持零代码创建个性化智能体。选择时需权衡角色功能定位、应用场景、技术能力、数据安全、输出目标与形式。重点考虑平台是否适配学段学科与授课方式、是否支持零低代码创建、能否满足特殊需求。

### 三 编写提示词与知识库：创建智能体的大脑
智能体是否具备清晰任务理解与精准内容支持，决定其功能发挥。创建初期需完善提示词与知识库这两个思维逻辑与知识底座。

#### 1. 编写提示词：让智能体理解要干什么
提示词是对话指令，建议采用“角色定位+任务技能描述+输出格式+限制条件”四要素。例如：
> 你是一位熟悉《普通高中化学课程标准2017年版2020修订》的助教，请依据九年级“化学变化与能量”单元，设计一个激发探究兴趣的实验任务，格式为实验目的、材料步骤、引导性问题。
提示越具体运行越稳定。教师可通过多轮测试不断优化。

#### 2. 构建知识库：让智能体靠谱不瞎说
多数大模型平台支持上传文本材料建设私有知识库。可上传教材、大纲、案例、论文、学生常见问题与教师答复模板等。含个人信息的学生作业需脱敏处理。知识库应权威准确、合规，避免过时或不当资料。

#### 3. 设定语气与表达风格
可设定语气亲切适合初中生、优先用图示、生活化类比或中英双语关键词等个性参数，使输出更亲和易懂。

### 四 调试与优化：测试和修正完善智能体
构建后需通过模拟问答、任务完成或案例演示系统调试。可从是否准确理解教学任务、回答是否逻辑清晰语言恰当、是否存在幻觉或知识混乱、能否应对追问变式提问等方面测试。建议用“提示词-响应结果-优化建议”三栏日志记录问题，逐步修正提示或补充知识库。
