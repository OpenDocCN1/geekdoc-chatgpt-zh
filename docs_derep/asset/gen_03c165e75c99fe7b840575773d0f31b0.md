# AI正重塑药物研发全流程

药物发现与开发长期受限于效率与精度，而人工智能工具的普及正在系统性地补足这些短板。从分子原创到剂量厘定，AI已渗透到研发链条的每个环节。

### 1）多肽构建与小分子原创设计
多肽由2至50个氨基酸构成的小链，能穿透细胞屏障抵达靶点，因而在治疗应用中价值攀升。研究团队已推出多类AI平台用于发掘更有潜力的多肽结构。

Deep-AmPEP30 是一个基于深度学习的平台，可预测短抗菌肽的生物活性。DeepAmPEP30 采用卷积神经网络，从DNA序列数据中预测短抗菌肽，并在光滑乳杆菌基因组中揪出新的抗菌肽。

IAMPE 是一个在线服务器，用于鉴定抗菌肽。它把抗菌肽13C-NMR特征与肽的理化特征整合为机器学习算法的输入，以发现新型抗菌肽。

ACP-DL 是一种深度学习工具，用于发掘新型抗癌多肽。它借助长短期记忆网络，即循环神经网络的改进版，来区分抗癌多肽与非抗癌多肽。

分子量极小的有机小分子同样在借助AI进行设计。GENTRL 是一种基于生成张量强化学习的小分子从头设计工具，依托它已发现一种新的DDR1激酶抑制剂。

### 2）生物活性预测与药效释放监测
为特定靶点挑选强效药物，关键在于确定生物活性配体。药物化学家正用AI判定可与疾病相关靶点结合的活性化合物。成药性设计与监测本是一项耗时费力的工序，随AI发展出现多种在线工具用于分析药物释放并预估所选化合物的药理作用。药效团评估常依托化学特征建模。这些模型搭建了由计算化合物与已报道实体结构组成的大型三维库。研究者可通过可视化筛选探究基于配体的化学特征。

筛选活性剂之外，成药可能性及其释放后的相互作用同样关键。药物不良反应是指给药后出现的意外、有害乃至致命的副作用，是研发一大挑战。识别早期潜在不良反应能让流程更稳健。近期研究在上市前借助AI预测药物可能带来的不良反应。

SwissADME 是一个可自由访问的图形界面，用于评估药物相容性及其药代动力学行为。其数学模型也被用于药物发现，最常见的做法是计算筛选分子的载药能力。

### 3）基于结构与配体的虚拟筛选
在药物设计中，可视化筛选是计算机辅助药物设计的核心手段之一。它是指识别能与药物靶点结合的小化合物，是从化合物库中淘出潜在治疗分子的高效途径，因而成为高通量筛选的重要补充，却也面临成本高、准确率低的问题。一般分为基于结构的可视化筛选与基于配体的可视化筛选两种。

基于配体的筛选依赖活性与非活性配体的化学结构及经验数据，利用活性配体的理化与化学相似性来预测库中其他活性分子。它不依赖靶蛋白的三维结构，因而在靶结构缺失时精度偏低。基于结构的筛选则需在体外、体内实验或计算建模下已阐明蛋白或靶标的三维结构信息。

该方法常用于预测活性配体与靶标的相互作用，并预测参与结合的氨基酸残基。相较配体方法，结构方法在精度与精密度上更高，并与致病蛋白数量增加及其复杂构象相关。

将机器学习用于可视化筛选，需要由已知活性与非活性化合物构成的过滤训练集。用监督学习训练模型后进行验证，若准确度足够再用于新数据集筛选目标活性化合物。初筛分子随后需做ADMET分析，再进入生物测定与临床前研究。机器学习可加速筛选、提升效率并降低误报。对接是结构筛选的主原则，已出现诸如NNScore、CScore、SVR Score与ID Score等基于AI与机器学习的评分算法。

随机森林、支持向量机、卷积神经网络与浅层神经网络等方法已被构建来预测结构筛选中的蛋白-配体亲和力。AI算法也被开发用于结构筛选中的分子动力学模拟分析。配体筛选的流程各环节均在引入机器学习与深度学习算法以提速增稳，例如高斯混合模型、隔离森林与人工神经网络等被用于构建诱饵集。

目前已出现PARASHIFT、HEX、USR与ShaPE等面向结构筛选的机器学习模型。随着AI在医疗与制药的兴起，结构与配体筛选均发展出不同工具与模型，如TiOpenScreen、FlexX-Scan、CompCore、PlayMolecule、METADOCK与AutoDock Bias等。

随化合物库扩张，寻找潜在配体如同大海捞针。结构与配体筛选最大程度降低了鉴定针对致病靶点的治疗化合物的复杂性，且AI模型使其更简便、精度与精密度更高。

### 4）分子设计
研发中常被问到：哪些化学结构会产生期望性质。从头分子设计将预测模型、分子相似性等优化参数与分子生成与搜索结合，模拟设计-制造-测试全周期，提供候选清单。合成可操作性仍是主要挑战。

近期方法应用进化类比物针对定义目标优化化学结构以产生期望轮廓，称多参数优化。片段多目标自动替换算法通过初始化候选群体进行迭代评估、采样与评分来优化感兴趣的结构轮廓。该算法使用源自已知合成有机化学的构建块库，即合成断开规则，保留每种结合模式及其出现频率。

另一种拓扑结构快速对齐算法可选择性替换子结构，在探索替换与保留候选结构信息间取得平衡，其分子构建块列表生成方式间接考虑了合成可行性。鉴于化学多样性与反应规则复杂性，该可行性衡量并非普适。

解决自动化合成设计挑战的一种思路是使用基于合成规则的模型，将标准合成偶联构建块组合起来，但此类方法往往限制了化学空间的探索。

上述计算模型多在已知药物化学空间分子数据上训练，可视为对数据分布的学习，可据此采样新分子。近年多种神经生成方法被提出用于分子设计，其中递归神经网络尤为突出。然而合成路线可行性仍需在AI领域进一步完善。

研究显示没有一种方案能解决所有问题，需持续关注与合成与药理测试进展最相关的化学结构，据此探索与改善化学空间或药效团。最大挑战是预测可靠性，尤其是生物活性。优化生物活性与毒性是药物发现中最耗时最昂贵的任务，也是药物关键属性的必要数据。

### 5）合成路线设计
设计新化合物合成需要专业知识、经验与创造力。药物化学家可合成几乎所有目标，但部分化合物复杂度超出想象。从头设计可在数百万结构中筛选出潜在药物，却仅提供制造原因而非实现路径。计算机辅助合成可提供替代路线或帮助优选易合成化合物。

突破性进展是使用转换规则与启发式方式从目标结构不断拆分寻找最优合成路线，现称逆合成分析。机器学习甚至可在无特定输入下从化学反应数据中自主学习有机化学规则。该法先用深度神经网络学习最有前景的逆分析规则，再与现代蒙特卡洛树搜索算法结合进行反应预测。一项双盲研究显示其产生的路线与文献路线一致。

AI也被用于升级合成路线设计。Chematica即SYNTHIA是一个基于决策树的程序，可为目标分子设计新合成途径，收录上百万已知分子与反应。依托十万余条手工编码反应规则驱动的先进算法，该工具可细化逆合成可能性并检验已完成、可完成与可用起始材料。化学家输入目标分子即可在数秒内获得按成本、底物易得性、步骤数筛选的路线。每一步反应与产物均由反应评分函数与化合物评分函数打分。

AiZynthFinder是基于人工神经网络的开源工具，利用蒙特卡洛树搜索进行逆向合成规划，基于Jupyter notebook实现快速简洁的逆合成分析。ICSYNTH是另一款可借助机器学习模型生成的化学规则集合来产生新化学合成途径的工具。

此外各类文本挖掘工具正辅助传统药物发现。文本挖掘借助自然语言处理等方法将文献与数据库中的非结构化文本转为结构化数据以进行分析。自然语言处理作为AI分支，使计算机能通过算法处理人类语言。据此开发了多种基于文本挖掘的工具。

药物化学研究与药物发现形成闭环，相互支撑，实现“设计-制造-测试-设计”循环，设计的化合物必须合成与实验测试以提供反馈。该过程缓慢昂贵，生成实验数据常需数周。分子设计方法可生成具有适当轮廓的候选药物，甚至指导新结构制备，将简化流程。

因此可应用主动学习，有效决定下一个应标记的数据点或需合成测试的新结构。模型主动学习是机器学习领域，其优势之一是能同时预测推进项目的化合物，又更快确定应合成的化合物以改进模型。模型改进可间接促进简化药物发现，因主动学习模型能更快提升质量预测。

目前药物发现的主动学习已有探索，但仍需大量投入以证明其在制造与测试鉴定化合物方面的价值。要获药物化学家信任并挖掘具成药性、最终筛选出疗法的候选是艰巨工作。由此AI与机器学习不仅直接关联药物发现，也与依赖该系统合成测试化合物的科学家支持相关。

尽管许多AI与机器学习方法尚未将药物推向市场，可预见它们将在药物发现中愈发不可或缺。通过新技术可有效设计新化学结构、预测分子性质、甚至设计合成路线，形成科技共振推动各研究领域发展。

### 6）药物剂量与给药效果
任何剂量都可能导致不良乃至致命副作用，因而确定安全治疗剂量至关重要。长期以来寻找最小毒副作用下达效的最佳剂量是艰难挑战。

随AI出现，许多研究者借助机器学习与深度学习算法确定合适剂量。AI-PRS是一个基于AI的平台，利用神经网络驱动方法通过抛物线反应曲线将药物组合与剂量与疗效关联，以确定抗逆转录病毒治疗艾滋病毒的最佳剂量与组合。研究发现，对10名HIV患者联用替诺福韦、依非韦伦与拉米夫定，在合适时机可将替诺福韦剂量降至起始剂量的33%而无病毒复发。AI-PRS也可用于其他疾病的最佳剂量探索。

更具体而言，在做任何架构决策前应明确手头问题，因机器学习方法选择应适配研究问题。首先需判断该问题属于判别任务还是生成任务领域。基于建模任务，下一步是设计合适模型架构。

此步包括选择合适算法并为超参数设置合理初值。对判别任务，支持向量机、随机森林与人工神经网络是最常用算法。生成任务可使用深层信念网络、生成对抗网络、变分自动编码器与自动编码器等。总体而言神经网络是首选，因其具泛化与近似任意输入输出关系函数的能力。超参数随算法而异。神经网络结构参数包括神经元与层数选择、学习率与衰减、正则化参数以及层间连接。

确定临时架构后，准备数据集。初始数据代表性、质量与数量对AI模型质量至关重要。架构与数据集建立后即可开展模型训练与评估。

训练旨在搜索使预测误差最小化的参数集。最终AI模型应能表达分子表征，发现特定目的间潜在关联。若不能，检查具体示例有助于开发者构建新模型“生态系统”以达目标。

### （2）输入数据准备
AI方法在药物发现中的应用倾向于通过部署最新方法改善整体性能。首先聚焦训练数据更具帮助，因其是基础。无论选择何种模型，高质量数据通常泛化更好。然而数据准备任务量大且繁琐。

开发者需了解训练数据来源与意义，如所表示实体类型与复杂度、数据量，以及更具体地在化学空间中的分布。总体问题是如何更好地填充可能的输入空间。若需更多数据，需决定预处理策略、未标记数据是否足够、哪种表示最适合编码所代表实体等。需注意并无普适规则。

在药物发现中，药物化学领域构建AI模型的输入x或输出y数据类型。主要输入是固定长度输入向量。该表示存在两大局限。向量往往很大，可编码所有可能子结构而无碰撞，导致模型参数过多，试图从稀疏输入中学习。相似性评估在高维化学空间易出错。为缓解此问题，人们利用可微神经网络计算输入的分子结构图，提出各类指纹图谱。

另一局限是难以建立输入向量与分子结构间一一对应，输入向量可从分子结构易生成，但反向推导极难，尤其当单一指纹对应多种化学结构时。

规避此限制的方法是使用AI深度生成模型作为分子表示。近年该组合已被广泛研究以产生具预期特性的新化合物。此情形下输出为字符串或指纹向量。大多数AI辅助药物发现项目的输出为数值、二元值对应二元分类、整数值对应多类分类，以及回归任务中的实值数字，通常为实验生化数据。

应特别关注初始数据代表性与基数。若数据集规模无法代表底层潜在任务，训练常导致过拟合与条件不良的平均误差，增加模型无法泛化到新数据的风险。

首先确认训练集性能是否有效，若不可接受，所选架构很可能不可行。若调整或尝试其他架构后仍无改善，则需考虑训练数据质量，检查训练分布是否平衡、输入输出对应是否逻辑。

若训练集性能可接受，则检验测试集性能。若训练与测试性能差距不可接受，收集更多数据是最有效方案之一。此时需权衡收集更多数据与以其他方式提升测试性能的相对成本，以及实现显著提升所需的预计数据量。

### 模型训练与泛化
对输入数据进行特征分层，以不同比例重训模型以获得通用性与稳定性，这是一种有用训练，最好以相对实惠成本收集更多高质量原始数据。高质量数据集收集往往成本高昂且难度大，这在生物数据药物发现中常见。

训练集可通过生成人工数据点，或使用多任务或迁移学习程序来丰富模型对相关数据的见解。模型可通过超参数优化、合并正则化，或采用更专门神经网络架构来改进，视任务目标而定。

若测试集性能仍远差于训练集，即使调整正则化超参数也无法收集更多训练数据，最简单方法可能是改进学习算法本身。再次强调初始训练数据不仅数量足够，质量也应足够。然而目前药物发现领域数据质量不佳，数量也不够大。

假设有10000个值可用，与用于构建视觉模型的大量信息相比，该数据量也近乎微小。高通量筛选生成的数据库常活性与非活性化合物不平衡，此时特定数据采样技术可用于平衡建模中的活性分布。

实际上数据集不完整且含错误。众所周知大多数药物具有多个生物靶点与活性，患者个体基因谱亦存在差异。这意味着在药物设计领域，因未知贡献因素与多对多非线性关系，我们面临大量难题。
