## 3.3 从谓词公式到子句集：标准化转换全攻略

上一节我们聊到自然演绎系统，它像人类思维一样直观。比如已知“张三选了简单的C++课（`EASY(C++)`）”和“选了简单课程`z`就喜欢`z`（`EASY(z) → LIKE(Zhang, z)`）”，套用`T`规则和假言推理，立马得到“张三喜欢C++（`LIKE(Zhang, C++)`）”。这招优点明显：过程自然、规则多、好嵌入领域知识。但有个硬伤——**组合爆炸**。中间结论指数级增长，一旦问题规模变大，根本跑不动。

所以，我们需要一种更“机器友好”、可机械执行的方法：**归结原理**。它的第一步，就是把杂乱无章的谓词公式，统一“整容”成标准的**子句集**。

---

### 核心概念速览

在动手前，先搞懂几个“积木”：

*   **原子公式**：最小逻辑单元，不可再分。
*   **文字**：原子公式或其否定。`P`叫正文字（真），`¬P`叫负文字（假），俩互为**互补文字**。
*   **子句**：若干文字用“或（∨）”连起来。单个文字也是子句。
*   **子句集**：一堆子句凑在一起，隐含“与（∧）”关系。
*   **空子句（`NIL`）**：空空如也，永假，**不可满足**——这是我们归结反演要猎杀的“靶子”。

**定理 3.1** 给咱们底气：谓词公式不可满足 ⇔ 其子句集不可满足。所以，搞定子句集，就是搞定原公式。

---

### 标准化八步走（通用流程）

把任意谓词公式变子句集，按这套 SOP 走准没错：

1.  **消蕴涵/等价**：`→`、`↔` 全换成 `¬`、`∨`、`∧`。
2.  **否定下沉**：把 `¬` 推到紧贴谓词位置（用双重否定、德摩根、量词互换）。
3.  **变量改名**：不同量词下的同名变量改成不同名，防串位。
4.  **消存在量词**：Skolem 化。存在变量用依赖它的全称变量构成的 **Skolem 函数** 替代（无全称变量则用常量）。
5.  **化前束形**：把所有量词提到最左边，变成 `(前缀)|母式|`。
6.  **化 Skolem 标准形**：利用分配律 `P ∨ (Q ∧ R) ⇔ (P ∨ Q) ∧ (P ∨ R)`，把母式变成**合取范式（CNF）**。
7.  **去全称量词**：全称量词默认全有，显式写出可省略。
8.  **拆子句集**：按 `∧` 拆分，每个析取式成一子句，变量再标准化一次。

---

### 实战演示：四例全解析

#### 例 3.2：嵌套量词的“套娃”结构
**原式**：`(∀x)((∀y)P(x,y) → ¬(∀y)(Q(x,y) → R(x,y)))`

| 步骤 | 操作与结果 |
| :--- | :--- |
| **1. 消→** | `(∀x)(¬(∀y)P(x,y) ∨ ¬(∀y)(¬Q(x,y) ∨ R(x,y)))` |
| **2. 否定下沉** | `(∀x)((∃y)¬P(x,y) ∨ (∃y)(Q(x,y) ∧ ¬R(x,y)))` |
| **3. 变量改名** | `(∀x)((∃y)¬P(x,y) ∨ (∃z)(Q(x,z) ∧ ¬R(x,z)))` |
| **4. Skolem 化** | `y→f(x), z→g(x)` 得 `(∀x)(¬P(x,f(x)) ∨ (Q(x,g(x)) ∧ ¬R(x,g(x))))` |
| **5. 前束形** | 量词已在最左，无需动。 |
| **6. 标准形(CNF)** | 分配律展开：`(∀x)[(¬P∨Q) ∧ (¬P∨¬R)]` |
| **7. 去量词** | `(¬P(x,f(x)) ∨ Q(x,g(x))) ∧ (¬P(x,f(x)) ∨ ¬R(x,g(x)))` |
| **8. 成子句集** | `{ ¬P(x,f(x)) ∨ Q(x,g(x)),  ¬P(y,f(y)) ∨ ¬R(y,g(y)) }` |

> **关键点**：步骤 3 必须改名（`y`→`z`），否则步骤 4 无法给两个 `∃y` 分别造不同的 Skolem 函数。

#### 例 3.3：合取项带量词的“分裂”结构
**原式**：`(∀x)({¬P(x)∨¬Q(x)} → (∀y)(S(x,y)∧Q(x))) ∧ (∀x)(P(x)∨B(x))`

| 步骤 | 关键动作 |
| :--- | :--- |
| **1. 消→** | 左边蕴涵变析取，右边不动。 |
| **2. 否定下沉** | `¬(¬P∨¬Q)` 变 `P∧Q`；`¬(∀y)` 变 `(∃y)`。 |
| **3. 变量改名** | 后半段 `x` 改 `w`，避免冲突。 |
| **4. Skolem 化** | `∃y` 依赖 `∀x`，设 `f(x)`。 |
| **5. 前束形** | 两个 `∀` 提至最前：`(∀x)(∀w)...` |
| **6. 标准形** | 分配律化简，`Q(x)` 被提取出来（吸收律作用）。 |
| **7/8. 成集合** | `{ Q(x),  P(y)∨S(y,f(y)),  P(w)∨B(w) }` |

> **技巧**：步骤 6 中 `Q(x) ∧ [P(x)∨S] ∧ [P(w)∨B]`，`Q(x)` 直接成单元子句，极大简化后续归结。

#### 例 3.4：函数符号与多层嵌套
**原式**：`(∀x){P(x) → {(∀y)[P(y)→P(f(x,y))] ∧ ¬(∀y)[Q(x,y)→P(y)]}}`

流程同前，注意：
*   步骤 2：`¬(∀y)[¬Q∨P]` → `(∃y)[Q∧¬P]`。
*   步骤 4：`∃y` 依赖 `∀x`，Skolem 函数 `g(x)`。
*   步骤 5：两个 `∀`（`x`, `y`）提前缀。
*   步骤 6：三路分配，得三个子句。
*   **最终子句集**：
    `{ ¬P(x)∨¬P(y)∨P(f(x,y)),  ¬P(x)∨Q(x,g(x)),  ¬P(x)∨¬P(g(x)) }`

#### 例 3.5：只求“前束形”不拆子句
**原式**：`(∃x)(∃y)((∀z)(P(z)∧¬Q(x,z)) → R(x,y,f(a)))`

目标：消 `∃`、化前束、**保留 `∀`**。
1.  `∃x` 先消，用常量 `b` 替换 `x`。
2.  消 `→`，否定下沉：`¬(∀z)(...)` → `(∃z)(¬P(z)∨Q(b,z))`。
3.  `∃z` 依赖剩下的 `∃y`，Skolem 函数 `g(y)`。
4.  合并析取，提 `∃y` 到最前。
**结果**：`(∃y)(¬P(g(y)) ∨ Q(b,g(y)) ∨ R(b,y,f(a)))` —— 这就是不含 `∃` 的前束形（注：严格说还含 `∃y`，但通常“消存在量词后”即指此步）。

## 3.4 归结原理：自动推理的“核武器”

有了子句集，怎么判断不可满足？1965 年，Robinson 给出了终极答案：**归结原理**。

### 1. 命题逻辑版：消消乐游戏

**定义 3.1（归结）**：
两个子句 `C₁`, `C₂`，若 `C₁` 有文字 `L`，`C₂` 有 `¬L`（互补），把俩互补文字扔掉，剩下的合并成新子句 `C`。这叫**归结**，`C` 叫**归结式**，`C₁/C₂` 叫**亲本子句**。

*   `P` 与 `¬P` 归结 → `NIL`（空子句，胜利！）
*   `¬P∨Q∨R` 与 `¬Q∨S` 归结 → `¬P∨R∨S`

**定理 3.2（可靠性）**：归结式是亲本的逻辑结论。亲本真 ⇒ 归结式真。
*证略（核心：`C₁∧C₂ ⇒ C`，利用假言三段论）。*

**两大推论（实战核心）**：
1.  **替换法**：用归结式 `C` **替换** 亲本 `C₁,C₂`，新集合 `S'` 不可满足 ⇒ 原集合 `S` 不可满足。
2.  **加入法**：把归结式 `C` **加入** 原集合 `S` 得 `S''`，`S''` 与 `S` **不可满足等价**。

> **策略启示**：咱们不断归结、加入（或替换），只要推出 `NIL`，原子句集铁定不可满足。这就是**归结反演**的基石。

---

### 2. 谓词逻辑版：先“合一”，再“归结”

谓词子句带变量，`P(x)` 和 `P(a)` 长得像但不一样，不能直接消。必须先**最一般合一（MGU）** 做代换。

**定义 3.2（二元归结式）**：
`C₁`, `C₂` 无公共变量。`L₁∈C₁`, `L₂∈C₂`，若 `σ = MGU(L₁, ¬L₂)`，则归结式为：
`C = (C₁σ - {L₁σ}) ∨ (C₂σ - {L₂σ})`

#### 实战三连击

**例 3.6：多路归结**
`C₁ = P(a) ∨ ¬Q(x) ∨ R(x)`
`C₂ = ¬P(y) ∨ Q(b)`

*   **路径 A**：消 `P`。`σ={a/y}` → 归结式 `¬Q(x) ∨ R(x) ∨ Q(b)`。
*   **路径 B**：消 `Q`。`σ={b/x}` → 归结式 `P(a) ∨ R(b) ∨ ¬P(y)`。
*   *同一对亲本，不同互补对，可得不同归结式。*

**例 3.7：变量重命名（避坑指南）**
`C₁ = P(x) ∨ Q(a)`，`C₂ = ¬P(b) ∨ R(x)` ❌ 变量 `x` 冲突！
→ **先改名**：`C₂' = ¬P(b) ∨ R(y)`。
→ 再合一 `σ={b/x}` → 归结式 `Q(a) ∨ R(y)`。

**例 3.8：因子——子句内部自洽**
`C₁ = P(x) ∨ P(f(a)) ∨ Q(x)`，`C₂ = ¬P(y) ∨ R(b)`
`C₁` 内部 `P(x)` 和 `P(f(a))` 能合一！`θ={f(a)/x}`。
→ 算**因子**：`C₁θ = P(f(a)) ∨ Q(f(a))`（去重了）。
→ 拿因子跟 `C₂` 归结：消 `P`，`σ={f(a)/y}` → 归结式 `R(b) ∨ Q(f(a))`。

**定义 3.3（广义归结式）**：四种来源：
1.  亲本直归。
2.  `C₁` 因子 跟 `C₂` 归。
3.  `C₁` 跟 `C₂` 因子 归。
4.  因子 跟 因子 归。

**完备性（王炸）**：
一阶谓词逻辑下，**子句集不可满足 ⇔ 一定能推导出 `NIL`**。
（Herbrand 理论保证，此处不展开证明。）

**避坑提醒**：
*   推不出 `NIL` ≠ 可满足。可能是策略没选对，或者它真可满足。
*   只有穷尽所有策略都推不出 `NIL`，才能判定可满足。

## 3.5 归结反演：定理证明的标准动作

既然归结原理又可靠又完备，咋用它自动证明定理？

**目标**：证明 `Q` 是 `P₁∧P₂∧...∧Pₙ` 的逻辑结论。

**等价转换**：
`Q` 是结论 ⇔ `(P₁∧...∧Pₙ) → Q` 永真 ⇔ `(P₁∧...∧Pₙ) ∧ ¬Q` **不可满足**。

**归结反演标准流程（SOP）**：
1.  **前提合取**：把所有前提 `Pᵢ` 和 否定结论 `¬Q` 写成合取式。
2.  **标准化**：按 3.3 节八步走，转成子句集 `S`。
3.  **归结循环**：
    *   在 `S` 中找可归结的子句对。
    *   算 MGU，生成归结式（含因子归结）。
    *   归结式加入 `S`（或替换亲本）。
    *   **若生成 `NIL` → 停止，原定理得证（Q 成立）**。
    *   **若无新子句可生成且无 `NIL` → 停止，Q 非逻辑结论（或前提不一致）**。

这就是把“数学直觉”变成“代码逻辑”的完整链路。下一节，我们将看看如何用**归结策略**避开组合爆炸，让机器跑得更快。
