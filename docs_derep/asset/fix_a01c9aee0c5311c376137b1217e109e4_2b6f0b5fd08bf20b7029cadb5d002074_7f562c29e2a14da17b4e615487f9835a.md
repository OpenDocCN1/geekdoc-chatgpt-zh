# RAG 实战：给生成系统配上可检索的背景

大型语言系统在组织语言上很强，但对特定事实的定位能力有限，遇到需要精确依据或保持多轮连贯性的场景容易出现偏差。检索增强生成的基本思路是先把候选资料转成向量，再按查询的语义贴近度挑出最相符的片段作为提示补充，让输出既有来源也更贴题。下面是一条可以复现的最小路径，嵌入用 BERT 做平均池化，排序用余弦距离，生成用 transformers 的 pipeline。

**搭建向量化工具**

默认基线是 bert-base-uncased，句子经过 tokenizer 后取 last_hidden_state 的均值作为句向量，设备会自动选择 cuda 或 cpu。

**多轮场景的微调**

当需求转向多轮对话时，语料可以换成关于训练范式、检索增强、逻辑一致性的描述，把 top_n 提升到 3，提示模板也做成更明确的引导形式，max_length 放宽到 200。
