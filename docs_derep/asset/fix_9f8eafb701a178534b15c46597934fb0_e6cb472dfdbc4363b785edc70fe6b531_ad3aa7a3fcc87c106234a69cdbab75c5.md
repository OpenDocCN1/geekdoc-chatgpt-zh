- ID3：依据信息熵与信息增益的度量构建决策树，核心思路是不断递归地把样本集拆分为更小的子集，从而长出树形结构。
- C4.5：在 ID3 的基础上补足了缺失值处理、剪枝机制，并改用增益率进行特征选择。

总体看，C4.5 是 ID3 的进阶与扩展。两者同源，C4.5 保留了前者的基本逻辑，并在其上叠加了诸多实用改进，可视作同一算法家族的两个演进阶段。实践中，C4.5 通常被认为更为稳健、适应性更强的分类模型。

以上梳理希望对你有帮助，欢迎继续提问。
