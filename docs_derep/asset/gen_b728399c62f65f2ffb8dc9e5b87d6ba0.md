# AI冲击下教育如何重塑

# 推荐序

# 先别找答案，先学会提问

六七月正值各类升学考试扎堆时节。高温笼罩下，考生和家长在焦灼等待里，常常叠加上“学什么专业”“往哪个方向走”的迷茫。

本书既不是填报志愿的实用手册，也不是层层推演的学术专著，它更像一次持续的追问。书中以30个问题为线索，在超级AI的大背景下展开对教育与学习多种可能的想象，试图撒开一张关于未来教育的思考之网。

过去三十年，从托夫勒的《第三次浪潮》到尼葛洛庞帝的《数字化生存》，从电子课堂、电化教学到中国的大学MOOC、翻转课堂，从美国的奇点大学、密涅瓦大学到神经教育学，终身学习、教育革命、认知重启等概念一路伴随科技浪潮而至。

最近三年，又一股更大浪潮涌来，主角是生成式人工智能，国内多称AIGC，代表即ChatGPT与大模型。算力惊人、表现惊艳、创新碾压，难免让人惊呼：未来是否已不再属于人类？

工具已进化到能写文、作画、谱曲、生成视频，还能给出医疗建议、撰写公文、解答稀奇古怪的问题，甚至写代码、优化流程、提炼论文、掌握专业技巧。这一切仿佛从天而降，早已坐进会议室、占据办公桌。

寒窗苦读、穷经皓首的旧图景似乎远去，人类自诩的感性、经验、知识与智慧，也不再能独享独有。

在此浪潮下，学习意味着什么，教育又意味着什么？作者的思考是碎片化的，却敏锐地收敛到一个词——提问。

陶行知有诗云：“发明千千万，起点是一问。禽兽不如人，过在不会问。智者问得巧，愚者问得笨。人力胜天工，只在每事问。”孩童咿呀学语，就会抛出鸟为何能飞、灯为何会亮、人影为何会动、白天星星去哪了之类的问题。问题与回答，几乎伴随一生。

然而不知何时，提问被窄化为追逐答案，尤偏爱标准答案。孩子的大脑被这套模式固化：每个问题背后必有一个确定的解，要么藏在老师的书里，要么藏在图书馆的某个角落。

于是学习和教育沦为寻找确定性答案的标准化训练。对心灵的预设也变为确定性追求。美国哲学家教育家杜威1929年的演讲题即《对确定性的寻求》，他认为对确定性的迷恋塑造了我们认识世界的心智。

对ChatGPT的恐慌，或许根源在此。习惯了问题必有解，便执着于答案对错、有无。人们天然偏爱正确答案，排斥错误。学习成了堆积正确答案、不断确认己知的过程，也就是“死读书、读死书”，人成了会走路的书橱。

AI给出的警示在于“知道”与“知识”的差异。二十多年前王朔提出“知道分子”。知识分子本应富于精神创造，而沉迷标准答案的知道分子只是比别人知道的多，能背诵名言、生卒、摘引，看似无所不晓，实则难生洞见。

两百多年前桐城派姚鼐提出学问为“义理、考据、辞章”三位一体，义理为主干。按此标准，今日GPT虽能力超群，某种意义上仍停留在博闻强记、辞章考据层面，属于知道分子的水平。靠海量数据训练，它把人类已生产的知识一网打尽，再在文本的无限组合中“创造”新内容，想象空间巨大，但本质仍是存量知识的排列。

这恰是其超凡之处。即便在“知道”层面，大模型已臻化境。有限资料的无限重组打开万千可能。庄子说“吾生也有涯，而知也无涯。以有涯随无涯，殆已”。古人对此无解，AI却提供精妙之道——提问。有人说答案都在模型肚里，只是缺一个好问题。

GPT改变了我们对提问的看法。提问不再是为求一个确定性答案的补缺，而是对想象力的考验。它能回答一切，也能一本正经胡说八道。若提问动机仍是求标准答案，便是对学习教育认知的自我设限。

书中30问很多来自现实焦虑：“学什么才不被AI淘汰？”“未来最好就业方向在哪？”“教育会更公平还是更两极化？”深层次追问则指向：AI能否具自我意识？数字人能否具人格？碳基与硅基未来谁主宰？在必须与智能机器共存的未来，如何重新理解人、知识、教育、文化？

没有确定答案，只有持续提问。提问是思想的酵素。

# 超级AI已至，你准备好了吗

两人林中漫步，远处猛兽出现。一人立刻蹲下系鞋带，另一人问：“系好鞋带也跑不过兽啊？”系鞋者答：“我跑不过它，只要比你快就行。”说罢飞奔。

这则寓言里系鞋者更显智慧。我们却不应被故事禁锢。若是洪水呢？逃生仍需快，但比别人快已不重要。若是价值连城的宝石，或苦寻的新大陆呢？

把故事推到极致，假设遇见一种新事物：它像猛兽威胁安全，像洪水摧毁财产甚至危及性命；它又像宝石能让人一夜致富，像新大陆承载无数希望。那就是超级AI，它已在面前。

面对这种利弊共存、善恶同体的新事物，你打算怎样应对？难道仍淡定地说“没事，我能不变应万变”？

作为家长或老师，你会如何引导孩子或学生？难道只是遮住眼睛安慰“没事，一切会过去”？

真没事吗？绝对有大事。

我们都感受到超级AI正引发全社会剧变。专家在人类史上寻找参照，从iPhone问世到互联网出现、原子弹爆炸、电力发明、大航海、活字印刷，甚至有人比作文字的诞生。

现代家长见过互联网的风浪，面对AI流畅的回答仍困惑：它怎么做到的？这并不奇怪，连开发者也常词穷，发明许多术语仍难解释新一代AI为何如此强。

教师大多具专业背景，却被一个聊天工具挑战，甚至面临替代。学富五车是对好老师的赞誉，学富五万车才只是成为AI的基础门槛。

当前AI仍不成熟，但它聪明且极度勤勉，分秒迭代。面对汹涌而来的超级AI浪潮，家长和老师已感到迷惘，未来似乎不再属于我们，再想到孩子和学生，焦虑更甚：未来会属于他们吗？

AI到底是什么？为何如此强大？我们还要学习吗？学什么才有用？社交技能会退化吗？如何不迷茫？作业还要管吗？刷题还有意义吗？安全隐私如何保障？还要学英语和绘画吗？高考会怎样变革？大学生还要写论文吗？未来什么职业最好？基础教育还有优势吗？如何提升科学素养？如何成为拔尖创新人才？全球竞争何去何从？人类还有未来吗……

没事没事，我们一个个来聊。

# AI 的回答

# 人工智能的三重境界

通俗来讲，人工智能是让计算机和软件系统具备类人智能的技术。它是多学科的研究领域，目的在于构建能模拟、实现并扩展人类智能的系统和算法，涵盖学习、推理、知识表征、规划、自然语言处理、感知、机器人等。

学界常按能力与复杂程度分为三类：

第一类是弱人工智能或窄人工智能，专为特定任务设计，在细分领域达到人类水平，只能执行预设任务，缺乏通用推理学习能力。如语音识别、图像识别、棋类对弈等，当前主流AI多属此类。

第二类是强人工智能或通用人工智能AGI，具有接近人类水平的理解、推理与学习能力，可在多种任务领域均达人类水平，能理解并表达自身意识，自主学习适应。强AI仍是研究目标，尚未实现。

第三类是超级人工智能，指在创造力、通用知识、情感理解、推理等所有智力维度全面超越人类的系统，能自主学习、创新、决策。超级AI仍属假设，尚未出现。

# 人工智能发展简史

第一阶段 初期探索 1950—1970年：符号主义与搜索算法。1950年图灵提出图灵测试，为发展奠基；1956年达特茅斯会议首次提出“人工智能”概念；1959年出现首个可下国际象棋的自学习程序。

第二阶段 知识表征与专家系统 1970—1980年：发展受阻，研究热度下降，出现提供问答的专家系统但能力有限。1972年出现首个能诊断并推荐治疗方案的医学专家系统。

第三阶段 机器学习与神经网络 1980—2000年：转向基于数据的机器学习，如决策树、支持向量机，以及早期神经网络，反向传播提供新工具。1989年首次用卷积神经网络识别手写数字。

第四阶段 数据驱动与深度学习 2000年后：算力提升与大数据兴起，2006年深度学习概念出现开启新纪元。2009年Google发布首个大规模语音识别系统。2014年AlphaGo战胜围棋顶级职业选手。2018年OpenAI发布GPT-2，推动自然语言处理飞速发展。

# 简单理解 ChatGPT

2022年11月ChatGPT上线，被视作AI里程碑，因其在自然语言处理上取得前所未有成果，与互联网诞生相提并论。它不仅能生成高质量文本，还能在多种自然语言任务中展现惊人适应性，有潜力改变人与计算机的交互方式，推动各领域的自动化与智能化。

ChatGPT采用GPT，即生成式预训练Transformer架构。先大规模无标签数据预训练再微调，使其捕捉丰富语义与语法，在自然语言任务中准确且通用。Transformer架构增强长距离依赖捕捉与并行计算。GPT系列参数与训练数据量庞大，能生成更自然准确的文本，处理多样任务。

# AI 快速爆发的原因

ChatGPT引爆AI增长，主要归因于：

1. 大数据。互联网与移动设备普及使数据量指数级增长，为算法提供丰富训练资源。
2. 算法创新。从神经网络到深度学习再到自然语言处理技术，持续涌现新方法，提升性能。
3. 算力提升。高性能计算硬件为训练与应用提供强力支撑。
4. 投资与产业支持。政府、企业与学界加大投入，推动技术发展。
5. 开源文化。开源社区促进技术共享与协作，加速创新。

即便ChatGPT成就显赫，通用人工智能乃至超级人工智能仍未实现。未来超级AI需在理解、推理、学习、适应等方面达到更高水平，需长期研究。同时要关注道德、伦理与社会层面的挑战。
