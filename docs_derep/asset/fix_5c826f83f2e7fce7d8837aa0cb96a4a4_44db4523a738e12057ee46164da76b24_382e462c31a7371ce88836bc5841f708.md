## 6.7 扁平化设计

关键提示词：

扁平化设计（Flat Design）、极简图形（minimalist graphics）、图标风格（icon-style）、高对比配色（high contrast color palette）、无阴影（no shadows）、简洁构图（clean layout）、界面视觉（UI visual）、现代信息图（modern infographics）

### 风格描述：

扁平化从现代主义的装饰剥离思路发展而来，在移动互联网普及期大放异彩，主张以功能为先、弱化装饰的视觉语言。它大量出现在网页、图标、信息图以及移动端产品里，核心特征是抛弃透视与明暗变化，仅靠色块、形状和版式传递信息。

在生成式图像中，这种风格因图形化程度高、结构易把控而很受欢迎，可用“扁平化设计插画（flat design illustration）”“最小矢量风格（minimal vector style）”“现代信息图布局（modern infographic layout）”“图标集设计（icon set design）”之类词引导。主体通常被简化为几何形体，整体追求统一、通透和中性的美感。

除了模拟产品界面，也常用于概念可视化与教学演示，成为设计思维与 AI 结合的常用切口。

## 6.8 孟菲斯设计

关键提示词：

孟菲斯设计（Memphis Design）、大胆色彩（bold colors）、几何图形（geometric shapes）、图案重复（pattern repetition）、装饰性元素（decorative elements）、20世纪80年代风格（1980s style）、反对功能主义（Anti-Functionalism）、视觉解构（visual deconstruction）

### 风格描述：

孟菲斯在 1981 年由意大利设计小组提出，用反功能、反极简的态度挑战现代主义主流审美。标志性做法是堆砌鲜艳色块、夸张造型与随意布局，常见点状、锯齿、波浪、三角等不规则纹样，80 年代在家居、时尚与平面设计里迅速流行。

这种风格属于辨识度很强的复古装饰语言，常用“孟菲斯设计图案（Memphis Design pattern）”“20 世纪 80 年代几何风格（1980s geometric style）”“多彩复古抽象背景（colorful retro abstract background）”“后现代装饰布局（postmodern decorative layout）”等词触发。画面多为非叙事型，可作为背景、品牌视觉或时尚提案使用。

它把趣味置于首位，通过刻意解构结构、色彩与图案来传递自由、活力与不羁的态度。

### 提示词：

孟菲斯风格的抽象底图，以粉、青蓝、黄为主要色调，遍布波浪线、圆点、三角形与不规则形体。构图不对称但节奏分明，浓烈的 80 年代复古气息与装饰性图案语言突出，视觉张扬活泼，适合潮流品牌物料或时尚背景使用（图 6-8）

## 6.9 瑞士国际主义风格

关键提示词：

### 风格描述：

瑞士国际主义风格，也叫国际字体风格，诞生于 50 年代的瑞士，对全球现代平面产生深远影响。核心理念是功能至上、信息清晰、结构严谨。米勒-布罗克曼、霍夫曼等代表人物提倡用网格组织内容、用无衬线字体搭配强对比色彩、大面积留白，以提升视觉逻辑与可读性。

通常可借助“瑞士风格海报（Swiss Style poster）”“现代主义平面设计（modernist graphic design）”“基于网格的布局（grid-based layout）”“海维提卡排版（Helvetica typography）”“带有红色调的极简版式（minimal layout with red accents）”等关键词实现控制，适用于杂志封面、招贴与展览设计。

今天被视作设计的黄金标准，视觉干净高效，充满现代感。

### 提示词：
