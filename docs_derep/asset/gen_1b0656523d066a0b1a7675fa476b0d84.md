无线局域网 WiFi 以 IEEE 802.11 系列标准为基础，至今已衍生出 a、b、g、n、ac、ax 六个分支，其中 802.11n 对应 WiFi 4，802.11ac 即 WiFi 5 已成为当前的主流落地技术。工作频段集中在 2.4 GHz 附近。最突出的优势是速率。WiFi 4 理论吞吐约 150 Mb/s，WiFi 6 可提升至 9.6 Gb/s，代际越高带宽越大，并发能力越强、时延越低、功耗越优。弱信号或干扰环境下会自适应降速，保持连接稳定可靠。核心特性为传输迅速、可靠性高；开放环境配合大功率平板天线可覆盖数十千米，封闭室内可达数百米，具体与发射功率相关。WiFi 与有线以太网融合便捷，组网成本低。结合 Arduino 后可广泛应用于物联网、智能家居、智能玩具等场景，实现近远距离的联网与控制。

13.2.1 蓝牙工作模式与系统架构
蓝牙规范在连接状态下定义了保持模式 HoldMode、嗅探模式 SniffMode、休眠模式 ParkMode 三种节能状态，再加上正常的活动模式 ActiveMode，支持电源管理的设备可在四种状态间切换。按电能消耗从高到低排序为活动模式、嗅探模式、保持模式、休眠模式，其中休眠模式节能效率最高。蓝牙为各类移动设备与外围设备之间的低功耗、低成本、短距离无线互联提供了有效途径。
蓝牙系统通常由天线单元、链路控制器 Link Controller LC 硬件、链路管理 Link Management LM 软件和蓝牙协议栈软件等四个功能模块构成，如图 13-2 所示。天线单元体积小巧，多采用微带天线。链路控制器集成连接控制器、基带处理器以及射频收发器三部分。链路管理负责发送接收数据、请求设备名、链路地址查询、建立连接、鉴权、链路模式协商与建立、决定帧类型等工作。

14.1 项目概述
儿童期是晶状体发育最快阶段，不良用眼习惯可能带来严重后果，及时关注视力尤为重要。传统视力检查需专业医师配合，至少两人协作完成。为让家长居家随时检测，本项目设计并实现了一款可由使用者独立完成的儿童视力测试产品，如图 14-1 所示。方案基于国际标准视力检测原理，结合 Arduino Uno 开发板、RB-02S102 红外手势传感器、HC-SR04 超声波测距传感器等硬件，并以 Qt 图形用户界面框架开发高度封装的 exe 程序。可根据显示屏规格与用户年龄选择视力表。测试开始时先用 HC-SR04 判断检测距离是否达标，随后屏幕自大到小依次呈现视力表“E”字母，并以 RB-02S102 识别使用者判定方向是否正确，直至连续判断错误为止，从而给出视力值。该产品面向青少年儿童视力筛查与健康追踪，操作界面友好，可在短时间内独立完成检测，并让家长实时记录结果、追溯历史变化，及早把控视力动态。

14.2.1 项目设计

1. 产品功能
帮助儿童独立完成视力检测，节省以往两人协作耗费的人力时间成本，使用者无需前往眼镜店或医院即可在家快速自助检测。

2. 产品特点
（1）年龄适配：针对 3～6 岁儿童视力差异，对不同年龄段视力表进行调整并配以相应音频提示，提升交互友好度。
（2）屏幕适配：适配主流电脑显示屏，避免画面呈现差异导致测试误差。
（3）降低空间需求：测试距离缩短至 1 m。
（4）信息保存：测试结束后可选择将视力信息导出至本地，便于日后观察变化。

3. 产品定位
面向非特殊视力状况的大众群体，尤其是近视儿童，完成远视力筛查并预警视力变化。

14.2.2 软件设计
基于 Arduino IDE 编写的程序主要采集传感器数据：超声波测距传感器获取使用者与屏幕距离，红外手势传感器获取手势挥动方向，并将数据发送串口供 Qt Creator 接收处理。
基于 Qt Creator 的程序实现年龄适配、屏幕适配、音频播放等功能，并根据串口数据作出相应调整。距离数据用于判断使用者是否处于约 1 m 范围内以决定是否开始测试；手势方向数据用于判断挥动手势是否正确，进而决定是否切换图片或结束测试并输出视力数据。

14.2.3 算法设计
首先进行超声波测距，确认被测者与屏幕距离是否达到 1 m，并在超声波模块代码中加入滤波算法以减小误差，不达标则不呈现视力表。达标后屏幕随机出现字母图片，并读取红外手势传感器返回的手势方向，与屏幕上“E”字母朝向匹配并记录结果，按测量逻辑逐步缩小字母，直至得出视力测量结果并在屏幕显示。

14.2.4 硬件设计
主要硬件为 Arduino Uno 开发板、HC-SR04 超声波测距传感器与 RB-02S102 红外手势传感器。两类传感器采集的数据经 Arduino Uno 串口发送。HC-SR04 实时采集使用者与显示屏间距，RB-02S102 采集手势挥动方向。

1. 硬件层

2. 传输层
对数据进行处理与转发。项目使用 DistanceSRF04 扩展库支持 HC-SR04 滤波与数据传输，ALS_APDS_9960 扩展库用于 RB-02S102 手势识别并返回上下左右结果。Arduino IDE 将结果经程序发送至串口。Qt Creator 通过 QSerialPortInfo 读取可用串口信息，通过 QSerialPort 连接串口并读取 Arduino 发送的数据。

3. 软件层
数据层存放视力测试图片、屏幕适配数据、UI 设计素材与音频文件。视力测试图片按行计算视力值与“E”字母大小并制作四个方向，预存为图片库。屏幕适配数据收集主流笔记本与台式机显示屏分辨率与尺寸，计算每英寸点数 DPI 及“E”字母在屏幕所占像素。UI 素材与音频用于营造儿童风格界面并提供测试提示。
应用层包含实现整体功能的 MainWindow 类与导出结果到 txt 文件的 FileDialog 类。
UI 层包括 Menu 类、ToolBar 类与 DataView 类。Menu 呈现选项与文件功能，ToolBar 呈现开始按钮、串口选择、年龄选择、屏幕尺寸选择及提示信息，DataView 显示提示语、视力表图片与儿童风格画面，主要依据手势是否匹配“E”方向来决定图片切换或结果展示。
整体上硬件与软件数据层负责产生与存储过程数据，Arduino IDE 与 Qt Creator 通过传输层交互，数据层为核心采集层，应用层与 UI 层负责与用户的直接交互。算法主要集中在软件层，Arduino 端负责降噪与结果生成并经传输层传给 Qt，后续由数据层与应用层处理，UI 层负责正确展示与切换并最终给出结果。
