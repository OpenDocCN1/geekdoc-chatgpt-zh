# 让生成更准：用语义检索给大模型配上下文

大模型擅长写，但不擅长“找”。当问题触及特定知识或需要多轮保持一致时，单纯靠参数记忆容易跑偏。检索增强生成 RAG 的思路很直接：先把候选资料转成向量，依查询的语义相似度挑出最相关的片段，再把这些片段喂给生成器作为上下文。这样回答既有依据，又更贴题。

下面是一套可复现的最小流程，核心是 BERT 做嵌入、余弦相似度做排序、pipeline 做生成。

**先搭好嵌入工具**
模型默认用 bert-base-uncased，句子经 tokenizer 之后取 last_hidden_state 的均值作为句子向量，设备自动切到 cuda 或 cpu。

整体思路就是：向量化→相似度排序→取最相关片段构建上下文→带上下文生成。嵌入模型负责“懂意思”，余弦相似度负责“挑对的”，生成模型负责“说得好”。三者配合，能显著提升相关性、准确度和多轮一致性。
