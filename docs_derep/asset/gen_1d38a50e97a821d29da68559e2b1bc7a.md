### 5.3.2 后端 API 核心概念扫盲
#### 1. Next.js 简介
Next.js 可以视作 React 的进阶形态。把网站类比成一本杂志，纯 React 是把零散稿件丢给读者自己拼装，Next.js 则直接递上装订好的成品，体验更顺畅、加载也更快。它还自带一整套自动化能力，比如自动生成页面、处理数据请求，开发效率明显提升。

#### 2. 后端 API 概念解析
后端 API 好比餐厅里的服务员，站在服务器厨房和浏览器顾客之间传递信息。用户在手机或电脑上浏览网站时，需要获取商品信息、用户资料，也会向服务器发送提交订单、注册账号等请求。API 负责接收这些请求，通知服务器执行，并把结果返回给用户。

#### 3. Next.js API 开发方法
Next.js 内置 API 路由机制，允许在项目里直接写后端代码。只要在 src/app/api 目录下按规则创建文件并实现请求处理和返回逻辑，Next.js 会自动将其暴露成可访问的接口，相当于在餐厅开一个专用外卖窗口，处理效率很高。

#### 7. GET和POST请求的区别
Web 开发里最常用的两种请求方式。

GET 请求像在图书馆查资料。
- 主要是拿数据，比如查询商品；
- 参数会暴露在网址栏；
- 适合读数据的场景，如获取用户信息、文章内容。

POST 请求像填一张表格。
- 主要是送数据，比如提交订单；
- 数据放在请求体里，不会出现在网址上；
- 适合写数据的场景，如注册账号、提交表单。

### 3. 认识 llms.txt
llms.txt 是个新兴的 Web 标准，相当于为 AI 准备的网站地图。如果说 robots.txt 是给搜索引擎指路，llms.txt 就是给 AI 的导航手册。

常见两种形式：
1. llms.txt：精简版导航，方便 Cursor、ChatGPT 这类工具快速定位信息。
2. llms-full.txt：完整版文档合集，把关键信息集中整理，利于 AI 快速理解。

与其它标准的区别：
- robots.txt：告知搜索引擎哪些页面可访问；
- sitemap.xml：为搜索引擎提供站点结构；
- llms.txt：专门为 AI 系统提供结构化内容指引。

想知道 LOGO 生成请求是怎么发的？Network 面板就是答案。它像交通监控器，记录浏览器与服务器间的所有通信，如图5-19所示。

（1）打开 Chrome/Edge 的开发者工具，Windows 按 F12，macOS 按 Command + Option + I。
（2）切换到 Network 面板。

- Headers 请求头区域：展示请求和响应的详细信息，像快递单。

  - Response Headers：服务器返回的响应头；
  - Request Headers：浏览器发送的请求头。

- 200 OK：请求成功，数据正确返回，像快递送达；

- 400 Bad Request：参数错误，像地址填写不完整；
- 401 Unauthorized：未授权，像没有会员卡；
- 403 Forbidden：禁止访问，像员工通道；
- 404 Not Found：资源找不到，像地址错误；
- 500 Internal Server Error：服务器内部错误，像系统故障。
