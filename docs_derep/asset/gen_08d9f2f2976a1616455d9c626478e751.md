# 战略决策仿真：从冷战沙盘到智能决策中枢

上世纪八十年代初，兰德公司打造了战略评估系统 `RAND Strategy Assessment System`，专门用来演练冷战时期美国与北约、苏联与华约之间的战略对峙。该系统具备全自动作战推演功能，把研究人员设定的作战想定编码为程序，投放到由知识规则驱动的对抗智能体中进行对抗性推演，用人工智能决策模型替代真实行为体极大提升了仿真效率。系统内并存两类决策模型[^(\[14\])](#chapter004.html#m14)：一类服务于作战指挥层，另一类面向国家级政治领导，后者是其重要创新。通过构建美国、苏联等国高层政治决策模型，系统能够评判政治态势、界定国家目标与战略、制定全球层面的战争指导原则，并用于研究威慑、战争升级遏制等命题。

进入二十一世纪，战略演练常态化催生了一批演示型实验室，像美国国防大学战略模拟中心、约翰霍普金斯大学战争分析实验室等。桑迪亚国家实验室推出的基础设施网络仿真分析系统 `ASPEN` 及其后续版 `ASPEN-EE` 可模拟经济运行，用以评估恐怖袭击美国能源设施对经济造成的冲击。普渡大学国土安全研究所研制的综合分析与仿真环境系统 `SEAS` 为战略级训练和综合演习提供社会仿真平台，其 `SEAS-VIS` 虚拟国际系统已覆盖全球62个国家，能够在市、省、国、地区、世界等多尺度上描绘公众、组织与领导者在政治、军事、经济、社会、信息、基础设施等领域的行动。

人工智能在战略决策仿真中扮演双重角色：一是精准及时地感知外部环境变化，风险评估即为典型应用；二是策略学习与优化。随着AI进入新一轮高速发展期，其对战略决策仿真模拟的推动作用将更为显著。

### （二）方法体系和架构

主流决策管理系统通常由环境感知、案例库、策略优选、效果评估四块构成。策略管理的前提是把行为体外部环境的状态特征感知清楚，并相对客观地判断风险与机遇。在此基础上确定决策方向，抓住机遇、规避风险。任何方案制定都离不开历史经验的支撑，系统需积累丰富的决策案例，通过人工智能的分类与关联模型从中筛选出若干方案组，形成适配当前环境的方案集。决策过程中最难的是方案优选，AI算法可替代繁复的非线性计算，为自然人决策者提供选择支持。具体流程是将筛选后的方案集导入策略实验环境进行仿真，用学习算法以策略优化函数为参照不断比选，最终由效果评估模块评判，选出最优策略。至此理论环节告一段落。真正有效的决策必须在现实问题中经受检验，理论最优方案出台后，还需依据实际应用效果回溯评估。若现实效果不理想，就要回头调整方案、筛选规则与优化函数，持续迭代。（见图 3）

### （三）未来发展方向和前景

AI迭代将显著提升决策管理效能。

其一，方案匹配度提升。自然语言处理等技术的突破将大幅提高从案例库中检索匹配决策方案的准确率，高精度“快速决策”有望实现。

其二，方案智能化程度提高。仿真技术与AI深度融合后，仿真实验与现实的贴合度将进一步增强，管理系统生成的方案更能自适应环境状态，决策逻辑将更接近人类思维。

其三，效果评估更精准。评估精度直接决定决策水平，方案更贴合现实问题时，落地效果也会明显改善。

其四，应用边界不断扩展。AI推动社会进入智能化阶段，智能化决策管理将渗透到智慧城市、商业战略决策、量化交易、社会治理、物联网调度、交通电力等大型基础设施综合调度、社会舆情管控、智能军事战略乃至外交决策等诸多领域，驱动社会运行与管理迈向新阶段。

# 人工智能治理困境：体制复合体视角

## 透过体制复合体看AI全球治理的推进路径

鲁传颖 〔美〕约翰·马勒里

**摘要：**体制复合体理论涵盖多利益攸关方治理与多边治理两种模式，对网络空间等复杂全球议题解释力强，也适用于人工智能这一复杂议题。多方治理与多边治理可分别对应AI全球治理的不同议题。算法偏见、伦理争议、就业冲击、数据安全等更适合多方治理，而与全球经济、安全、政治挂钩的议题更适合多边治理。多种模式叠加可形成覆盖标准、规范、规则、机制等多层次、多领域的AI全球治理体系。

**关键词：**人工智能 算法歧视 体制复合体 多利益攸关方

人工智能是指利用数字计算机或受其控制的机器模拟、延伸并扩展人类智能，通过感知环境、获取知识并运用知识追求最优结果的理论、方法、技术与应用系统。[^(\[3\])](#chapter005.html#m3)作为通用技术，AI正把人类从信息化时代推向智能化时代，其全球治理的重要性不亚于技术本身。AI跨专业、跨领域、跨议题的特性给治理研究带来挑战，可借鉴体制复合体 `Regime Complex` 理论进行分析。该理论源于对复杂全球治理问题的体制理论延伸。网络空间治理等新议题涉及领域广、行为体多元、内涵丰富，单一体制难以驾驭。[^(\[4\])](#chapter005.html#m4)类比网络空间治理，AI全球治理的目标是针对不同议题构建标准、规范、规则、条约、法律等层级的治理机制，由松散耦合的机制网络构成体制复合体。[^(\[5\])](#chapter005.html#m5)

### 一 体制复合体理论与人工智能全球治理

传统全球治理多由国际政治、安全、经济主导。约瑟夫·奈指出，体制复合体的鲜明特征在于同时重视政治、安全、经济与技术逻辑，把技术社群置于同等地位。从这一视角看，AI全球治理已在政府、国际组织、技术社群、私营部门之间展开，并在伦理、算法、就业、数字安全等领域形成多项标准、规范与规则。

#### （一）人工智能全球治理的现状

“人工智能”自学科诞生以来即伴随治理讨论，其发展阶段与治理重点密切相关。学理上可划分为弱人工智能 `ANI`、类人工智能 `AGI`、强人工智能 `ASI` 三个阶段，对应机器智能程度的递进。目前发展仍处弱人工智能阶段，即机器可在特定模块超越人类，但缺乏完全自主意识，只能在设定环境中运行，难以应对新环境并自生新功能。[^(\[6\])](#chapter005.html#m6)

由于技术复杂，治理讨论多建立在对技术理解之上。早期讨论伦理导向强烈，绕过弱与类AI阶段，直接聚焦强AI带来的“机器是否会控制或伤害人类”，陷入长期空谈。[^(\[7\])](#chapter005.html#m7)随着对三阶段的划分与对弱AI特征的界定，面向规范、规则、机制建立的全球治理开始成形，并对技术发展与应用产生实质影响。[^(\[8\])](#chapter005.html#m8)

治理实践已在多领域展开。技术社群是目前最活跃的主体，已形成若干机制。以2017年初“受益的人工智能”会议为起点形成的“阿西洛马人工智能原则”，由AI开发者与公民组织共同参与，归纳出研究议题、伦理与价值、长期议题三大类23条规则，核心是强调人控机器、价值导向，如公平、隐私、人权。[^(\[9\])](#chapter005.html#m9)电气与电子工程师协会 `IEEE` 提出全球倡议，要求自主与智能系统设计方优先考虑伦理，并发布《人工智能设计伦理准则》，提出人权、福祉、问责、透明、审慎五大原则，同时成立 `IEEEP7000` 标准工作组及伦理、透明、算法、隐私等十大工作组。[^(\[10\])](#chapter005.html#m10)微软、美国信息技术产业理事会、经合组织、斯坦福大学、美国标准研究院等机构也相继发布治理报告。

联合国系统高度重视治理机制。国际电信联盟 `ITU` 于2017年6月在日内瓦主办“AI造福人类”峰会，提出AI发展应契合联合国可持续发展目标，用于减贫、健康、医疗、教育等17个领域的推进。[^(\[11\])](#chapter005.html#m11)联合国毒品和犯罪问题办公室在荷兰海牙设立首个联合国人工智能与机器人中心，致力于提升认知、教育与协调，处理AI与机器人带来的犯罪安全风险。[^(\[12\])](#chapter005.html#m12)各国政府也纷纷行动，自2015年起，美国、中国、法国、欧盟等主要国家与区域组织陆续出台国家战略。美国发布《为人工智能的未来做好准备》并设AI委员会，英国发布《人工智能：机遇与未来决策的应用》等，都在全球治理问题上表明立场。

#### （二）从网络空间全球治理到人工智能全球治理

体制复合体在网络空间治理中主要通过多利益攸关方模式构建技术领域机制，通过多边模式建设技术应用带来的安全、政治、经济机制。AI同具跨学科性与多元议题，为体制复合体分析提供基础。首先，技术逻辑上，AI基于计算机与互联网并融合统计学、脑科学、系统辨识、优化理论、神经网络等学科，具有跨学科、跨领域、多主体特征。其次，AI全球治理议题多层级、跨领域，其通用性与颠覆性使其应用具有全球广度深度。体制复合体把技术逻辑提升至与政治、经济、安全同等重要地位，呼应网络空间“代码即法律”的特性。AI治理既要考量技术本身，也要考量应用对国际体系的影响，如算法伦理的普适性、发展不平衡带来的数字鸿沟、以及对国际经济、安全、政治秩序的冲击。[^(\[13\])](#chapter005.html#m13)

再次，参与主体可划分为技术社群、私营部门、政府。以 `IEEE` 为代表的技术社群在标准制定与规范形成中作用关键。私营部门是规则约束对象，参与积极性高，微软、谷歌、百度等拥有大量人才与创新能力，传统行业也在加入治理进程。政府既是战略与政策制定者、监管者，也是国防、安全等战略技术领域的直接参与者，同时承担条约与国际规则制定的责任。[^(\[14\])](#chapter005.html#m14)AI治理必须由多国多主体共同推动。

最后，实践层面，AI全球治理与网络空间治理具有相似性。数据安全议题上，两者均面临个人信息与国家安全问题。技术社群在互联网治理中发挥关键作用，如 `ICANN` 在关键资源治理、`IETF` 在技术标准制定上的主导。 `IEEE` 等在AI标准制定中同样关键。联合国在互联网治理中设立信息安全政府专家组，在AI领域设立致命性自主武器系统政府专家组 `GGE`，显示国际组织在规则制定上的延续性。[^(\[15\])](#chapter005.html#m15)
