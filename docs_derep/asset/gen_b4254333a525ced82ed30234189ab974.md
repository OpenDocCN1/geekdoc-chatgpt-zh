- **1）硬件环境搭建**

  具体操作请参照 4.1.2.1 节执行。

- **2）工程代码部署**

  - **(1) 建立远程连接**  
    启动 MobaXterm，利用 SSH 协议登录至边缘计算网关。

  - **(2) 初始化目录结构**  
    在 SSH 终端中新建项目所需的工程目录。

  - **(3) 资源包上传与解压**  
    通过 SSH 通道将本地开发工程代码及 aicam 工程包传输至 `~/aiedge-exp` 路径，随后执行 `unzip` 指令完成解压。

    [PRE5]

  - **(5) 配置文件同步**  
    将修改完毕的配置文件经 SSH 回传至边缘计算网关。
