这款方案把手写速写直接变成可交互的视觉海报。用家把速写拖进导入区后，后端会唤起 Gemini 2.5 Flash，结合挑选的动效风格例如 Geometric Pulse，输出一段可直接在浏览器运行的 p5.js 脚本。操作界面划分为拖拽导入区、风格调节面板、代码展示编辑区以及用 iframe 搭建的安全预览区，导出靠 Blob 实现一键下载。预览环节在沙盒里执行，并配了刷新与异常提示，让从草图到互动海报的链路保持流畅、安全且直观。

p5.js 是面向创意编程的 JavaScript 工具集，把 HTML5 Canvas 的底层调用封装起来，用很少的代码就能做出粒子、动态图形等互动效果。代码结构清晰、语法贴近自然语言，对模型产出很友好，生成物可直接运行在浏览器里，特别适合把手绘意向转成可交互视觉稿。

隔离运行靠 iframe 完成。生成的 p5.js 被放到独立页面容器里沙盒化执行。模型产出的代码可能夹带恶意脚本或逻辑缺陷，若在主页面直接跑会污染全局环境、泄露信息甚至导致页面崩溃。放在 iframe 中即便出错也只影响内部，不会波及主应用。
