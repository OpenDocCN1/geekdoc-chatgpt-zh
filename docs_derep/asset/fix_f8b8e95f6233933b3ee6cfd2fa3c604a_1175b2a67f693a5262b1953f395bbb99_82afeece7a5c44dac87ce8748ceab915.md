DeepSeek-V3 评测要点与多模态演进梳理

◎ 测试设定概览：常规基准统一采用 simple-evals 评测体系并配合 Zero-Eval 提示模板；代码数学类任务则同步调用多语言环境与多种解码策略。单次输出上限统一放宽至 8 192 Token。

2. 标准基准表现
DeepSeek-V3 在众多公开榜单上的成绩十分亮眼，已稳居顶尖开源行列，与主流闭源模型具备对碰实力。整体情况概括如下。

◎ 英语能力：MMLU、GPQA 以及 DROP、LongBench v2、FRAMES 等长文本理解任务均拿到高分，DROP 的 F1 达到 91.6，分值已逼近 GPT-4o。
◎ 编程与数学能力：代码生成方面在 HumanEval-Mul 与 LiveCodeBench 上全面领先参照模型；数学方面 AIME 2024、MATH-500、CNMO 2024 的表现突出，为非 o1 类模型建立了新的参照水平。
◎ 中文能力：在 C-SimpleQA 事实问答与 C-Eval 教育知识测评中拿到优异分值，超过 Qwen2.5 72B。

3. 开放式生成评估
在开放式生成场景中，AlpacaEval 2.0 与 Arena-Hard 的胜率均突破 85%，成为首个达到该阈值的开源模型。

4. DeepSeek-V3 作为生成式奖励模型
RewardBench 的结果显示其奖励建模水平与 GPT-4o、Claude-3.5 处在同一区间，凸显了作为生成式奖励模型的应用潜力。

5. MTP 解码评估
模型并非仅做下一个 Token 预测，而是借助 MTP 技术并行预测后续 2 个 Token。配合推测解码框架，整体吞吐明显提升。关键在于额外预测的接受率，实测第二 Token 的接受率在不同生成主题上稳定在 85% 至 90% 之间，可靠性一致。该高接受率支撑了约 1.8 倍的 Token/秒提升。

综合来看，DeepSeek-V3 已成为当前实力靠前的开源基础模型，编程与数学是显著优势。聊天版在标准与开放式榜单上均领先其他开源模型，表现与 GPT-4o、Claude-3.5-Sonnet 等领先闭源模型相当。

Janus 由 DeepSeek 提出，目标是在单一体系内完成图像理解与文本到图像生成两项任务。核心创新在于把理解与生成的视觉编码解耦，缓解两类任务的冲突。通过训练策略优化、数据扩充与规模扩大，Janus 在多模态理解、指令遵循与文生图稳定性上均有明显进步。Janus-Pro 在训练策略、数据与规模上进一步改进，性能再上层楼。

2. Janus 架构设计的优势
通过解耦视觉编码路径获得多重优势。

（1）解耦视觉编码路径
◎ 任务适配性强：理解与生成各配置独立的视觉编码路径。理解侧的编码器偏重提取高层语义，表征粒度偏向高维语义；生成侧更关注空间结构与纹理等细粒度信息。解耦后可选用最适配各自任务的编码技术，提升针对性，避免单一编码器难以兼顾的问题。
◎ 减少任务冲突：理解与生成所需的视觉表征差异较大，共享编码器易产生冲突。解耦设计消除了编码器选择的权衡，使模型在理解与生成上都能更好发挥。

（2）统一的 Transformer 框架
◎ 架构简洁高效：采用统一 Transformer 处理理解与生成任务，仅在视觉编码层面解耦，既保持架构简洁，又提升不同任务的处理效率，降低复杂度与训练难度。
◎ 良好的扩展性：该框架可容纳更多输入类型，如点云、脑电信号、音频等。只需为新模态添加独立编码器提取特征，再由统一 Transformer 融合即可，应用范围可扩展。

（3）独立适配的编码方法
◎ 多模态理解编码优势：理解路径采用 SigLIP-L 作为视觉编码器，可把图像特征映射到文本语义空间，提取物体类别与视觉属性等高维语义。经理解适配器映射到 LLM 输入空间后，有助于视觉问答、图像描述等任务。
◎ 多模态生成编码优势：生成路径使用 LlamaGen 体系中的 VQ Tokenizer 或自研 VQ Tokenizer 把图像转为离散 ID，再由生成适配器把码本嵌入映射到 LLM 输入空间。该方式更好捕捉图像细节，满足生成对局部细节与全局一致性的要求，生成质量更高。

### 6.3.3 视觉编码器 VQ Tokenizer
Janus 的 VQ Tokenizer 用于把图像转为离散 ID 序列，把细节信息编码为便于计算的形式。

1. 基本原理
Tokenizer 建立于向量量化技术，把连续特征空间映射到离散码本。采用 VQ-VAE 架构，先由编码器把图像压缩为潜在表示，再经向量量化层映射到离散码字，最后由解码器重构图像。

2. 在 Janus 模型中的应用
在 Janus 中，VQ Tokenizer 服务于视觉生成任务，把图像转为离散 ID 序列以保留空间结构与纹理信息，再经生成适配器映射到 LLM 输入空间，供模型进行图像生成等任务。

3. 训练过程
◎ 预训练码本：使用 ImageNet-1K 语料预训练 VQ Tokenizer，训练包含潜在变量量化与码本更新，最小化重构误差，使其能准确编码与重构图像。
◎ 适配器训练：Janus 训练时 VQ Tokenizer 码本冻结，仅训练适配器，把离散 ID 序列映射到 LLM 输入空间，实现视觉与语言信息的融合。

### 6.3.5 特征序列处理
Janus 通过自回归 Transformer 处理多模态特征序列并生成输出。

1. 功能和位置
◎ 功能：自回归 Transformer 对拼接后的多模态特征序列建模，捕捉长程依赖，自回归预测下一个标记，实现文本与图像生成。
◎ 位置：位于特征处理下游，接收来自文本理解、多模态理解与视觉生成各路径经适配器映射后的特征序列，拼接后统一处理。

2. 输入和输出
◎ 输入：多模态特征序列由文本特征、图像高维语义特征及图像离散 ID 嵌入等拼接而成，经适配器映射到 LLM 输入空间后展平为一维序列。
◎ 输出：纯文本理解与多模态理解任务输出文本预测，由 LLM 内置预测头生成；视觉生成任务输出图像预测，由随机初始化的预测头生成。

3. 训练过程
◎ 训练目标：采用交叉熵损失最大化条件概率，理解任务损失计算于文本序列，生成任务损失计算于图像序列。
◎ 训练方式：遵循自回归框架，采用 Next-Token-Prediction 与因果注意力掩码，与 LLM 训练方式一致，Transformer 与适配器共同学习多模态关联。

4. 与其他组件的协作
◎ 与适配器的协作：依赖适配器把各模态特征映射到同一输入空间，保证序列兼容性与信息融合。
◎ 与预测头的协作：根据任务类型把输出送至对应预测头，理解任务用 LLM 内置头，生成任务用独立初始化头。

5. 优势
◎ 多模态融合：统一处理不同模态特征，实现理解与生成的统一建模。
◎ 简单高效的架构：统一自回归 Transformer 避免为不同任务设计专属掩码，简化设计与训练推理。
◎ 强大的生成能力：逐步生成连贯高质量的文本与图像，结果多样且准确。

注意：
◎ 输入长度限制：Transformer 计算复杂度随序列长度平方增长，长序列或多模态特征可能受限。
◎ 训练数据要求：需要大量高质量多模态数据以学习跨模态关联与语义。

### 6.4.2 解耦视觉编码
Janus-Pro 采用解耦视觉编码技术，针对理解与生成设计独立路径。

1. 解耦视觉编码的设计原理
为理解与生成任务分别设计独立视觉编码路径，以满足两者对图像特征表示的不同需求。

2. 多模态理解路径
使用 SigLIP 编码器提取图像高维语义特征，二维网格展平为一维序列，经理解适配器映射到大语言模型输入空间。

3. 视觉生成路径
使用 VQ Tokenizer 把图像转为离散 ID，序列展平后经生成适配器把码本嵌入映射到 LLM 输入空间，更好捕捉细节，满足生成对局部与全局一致性的要求。

该解耦模式避免单一编码器在两类任务间冲突，充分发挥各自优势。

### 6.4.3 初始训练策略挑战
Janus-Pro 训练分为三阶段：先训练适配器与图像预测头，建立视觉语言概念联系；再联合预训练解冻语言模型并利用多源数据学习多模态任务；最后监督微调提升指令遵循与对话能力。

1. 初始策略：参考 PixArt 方法的两部分训练
（1）第一部分：像素依赖性学习
首步进行像素依赖性学习，专注训练适配器与图像预测头。从 ImageNet 预训练模型起步，架构兼容预训练权重以提升初始化效率，目标是使模型据类别名称生成合理图像，有效建模像素依赖。
（2）第二部分：文本—图像对齐学习
完成像素依赖学习后，使用常规文本到图像数据训练，基于密集文本描述生成图像，提升数据利用效率与整体性能。

2. 问题与挑战
◎ 计算效率低下：第二阶段按 PixArt 将训练分为 ImageNet 类别名称阶段与常规文本到图像阶段，导致大部分训练步数集中在第一部分，效率显著下降。
◎ 数据利用不充分：过多步数用于类别名称的像素依赖建模，对常规文本到图像数据利用不足，复杂描述生成能力提升有限。
◎ 训练策略次优：实验显示分阶段策略次优，第一阶段训练不足导致像素依赖建模不充分，第二阶段资源浪费于相对简单提示。
