# 2.4 表格在项目管理中的核心地位

表格贯穿项目管理全生命周期，作用主要体现在五大维度：

1.  **进度把控**：甘特图、里程碑表让进度一目了然。
2.  **成本管控**：预估表与控制表配合，随时预警超支。
3.  **资源调度**：人员职责、物资需求清晰记录。
4.  **风险管理**：评估表、应对表助力风险识别与降级。
5.  **效率提升**：标准化模板减少重复劳动，聚焦决策。

**核心结论**：表格提供结构与骨架，但管理的灵魂仍是人的判断。高阶工具（PMIS）正是在表格基础上实现自动化与深度优化。

### 2.4.1 Markdown 表格：轻量级跨平台方案

ChatGPT 无法直接输出 `.xlsx` 二进制文件，但能生成两种纯文本表格：**Markdown** 与 **CSV**。

Markdown 表格靠管道符 `|` 和分隔符 `-` 构建，纯文本、易迁移、兼容性强。

**基础语法**：首行表头，次行分隔，其后为数据行。

### 2.4.2 案例 6：ChatGPT 分步生成 Markdown 进度表（电商网站升级项目）

手写 Markdown 表格易错且慢，用 ChatGPT 分步生成最稳妥。

**策略：复合指令 + 分批喂数据**，规避单次输出长度限制。

#### 实操步骤

**第 1 步：建立会话上下文**
> **指令**：“帮我做个表格，只返 Markdown 代码。我分批给表头和行数据，我说‘表格生成结束’你再出代码。”
> **回复**：“好，请发表头。”

**第 2 步：喂入表头**
> **数据**：任务名称、负责人、开始日期、结束日期、进度
> **回复**：“收到，请按‘字段用英文逗号分隔’逐行发数据（如：任务1，张三，2022-01-01,2022-01-15,50%）。”

**第 3 步：分批喂入行数据**（每发一条，ChatGPT 确认）
> 例：需求分析，业务分析师，2021/7/1，2021/7/15，100%
> ……（重复此步直到数据录入完毕）

**第 4 步：触发生成**
> **指令**：“表格生成结束”
> **产出**：完整 Markdown 表格代码（含系统设计、前后端开发、测试、上线等 8 条记录）。

保存为 `.md` 用编辑器预览，效果见图 2-28。

[PRE8]

> **避坑指南**：
> 数据量大时务必“多次少喂”。若 ChatGPT 卡住不回，发“请继续”即可接力输出。

### 2.4.3 CSV 表格：通用数据交换格式

CSV（Comma-Separated Values）逗号分隔值，Excel、Google Sheets 等主流工具原生支持。

**结构**：首行表头，后续每行一条记录，字段间用逗号隔开。

**落地流程**：
1.  复制代码到记事本。
2.  另存为 `.csv` 后缀。
3.  用 Excel/WPS 打开。

### 2.4.4 案例 7：ChatGPT 生成 CSV 版进度表

流程与 Markdown 几乎一模一样，仅指令里把“Markdown”换成“CSV”。

**关键差异**：ChatGPT 会在确认表头后，**立即返回表头行代码**，随后每接收一行数据就追加一行，最后汇总输出完整 CSV 文本。

日期字段在 CSV 中可能显示为数字序列值（如 44393），导入 Excel 后可格式化为日期。

### 2.4.5 CSV 秒转 Excel

打开 CSV → 文件 → 另存为 → 类型选 `*.xlsx` → 保存。原生格式、公式、样式全支持。

# 2.5 ChatGPT 做图表：两条路径

ChatGPT 不能直接“画”图，但能造“图的源头”：

| 路径 | 核心逻辑 | 适用场景 |
| :--- | :--- | :--- |
| **无编程** | ChatGPT 生成 CSV/Excel 数据 → Excel 原生图表功能可视化 | 业务人员、快速出图、交互调整 |
| **有编程** | ChatGPT 写 VBA / Python (Matplotlib, ECharts) 代码 → 运行代码出图 | 复杂图表、自动化报表、批量生成、嵌入系统 |

---

### 2.5.1 无编程路径：借力 Excel 原生引擎

1.  让 ChatGPT 按案例 6/7 方式产出带数据的 CSV 或 Markdown 表格。
2.  导入 Excel（CSV 另存为 xlsx）。
3.  选中数据区 → 插入 → 推荐图表/任意图表类型 → 微调样式 → 完成。

**优势**：零代码门槛，利用 Excel 强大的格式化、动态更新、筛选器等成熟生态，最适合“数据给好了，图要快且美”的日常汇报场景。
