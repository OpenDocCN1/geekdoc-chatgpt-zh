# 用 ChatGPT 打造自媒体爆款的完整拆解

做账号第一步是把人设立住。我把背景需求和期望丢给 ChatGPT，要求它用专业语言给出“定位名称＋具体说明”的八个版本，直接拿来参考：

1. 定位名称：都市女强人心灵导师
具体说明：在一线城市的快节奏里，你以职场高管的身份呈现女性职场的判断力和行动力，同时想为同样在奔跑的女性提供心态疏导和成长路径。

2. 定位名称：时尚职场女王
具体说明：你懂得把女性气质和职业素养融合，输出的内容帮助读者在大城市里既保持专业度，又不丢掉独特的女性风采。

7. 定位名称：都市妈妈的生活哲学
具体说明：你是已婚的90后，既分享工作体悟，也聊家庭日常，聚焦在繁忙都市里如何同时做好母亲、妻子和职场人的平衡与和谐。

8. 定位名称：职业女性的全方位成长手册
具体说明：从事业到生活，从内心到技能，你提供一套覆盖全维度的进阶方案，助力渴望提升的女性在各个层面找到最合适的状态。

以上只是方向性的参考，后续可结合真实经历再细化打磨。把角色设定、能力要求、背景上下文和输出规范打包进提示词，几秒就能得到八个可操作的运营方向。认可哪个就用哪个，不满意就让它重来，直到对味为止。

#### 2. 循序渐进，批量搭建选题库

有定位后要解决持续输出问题。若每次都要从零写笔记，效率太低。高产的基础是提前建好选题池。

先把已选定的定位喂给模型，让它按人设推一批笔记主题。以“都市妈妈的生活哲学：身为已婚90后女性，既分享职场经验也探讨生活，思考在都市里如何平衡母亲、妻子和职业身份”为例，得到的方向包括：
1. 京城生活的一周时间管理术，讲怎么分配工作、家庭和自我时间，并给工具建议。
2. 从职场女强人到都市妈咪：我的职业生涯感悟，回顾升职、调岗、孕期等关键节点的抉择。
9. 提升自我：都市妈妈的成长书单，推荐涵盖职业、家庭、心灵的书籍。
10. 我的都市生活工具箱，分享提升效率的生活 App 与学习平台。

十条选题起步还不够，第一轮输出普遍偏宽泛，每个命题都能再拆成多个子题。这是模型的特点，第一轮提问不够精确时它只能给模糊答案。于是对宽泛命题做裂变，进一步细化。

#### 3. 预训练，让 ChatGPT 成为金牌写手

写作也拆解。第一步先做标题。基于选题“从职场女强人到都市妈咪：我的职业生涯感悟”，让模型粗出七个小红书风格标题：
1. 《高跟鞋到婴儿车：我如何玩转职场与母亲双重角色》
2. 《咖啡杯旁的奶瓶：职场女王变身都市妈咪后的那些事》
3. 《走进会议室，抱起宝贝：我的双重身份日常》
4. 《女强人背后的小秘密：如何在事业和家庭间找到平衡》
5. 《从领导桌前到儿童房：我在职场与育儿中的成长故事》
6. 《“Boss”到“Mom”：我是如何每天切换多重角色的》
7. 《办公桌上的玩具和文件：职场女性成为妈妈后的五大转变》

从中挑出喜欢的调性再打磨。以《高跟鞋到婴儿车：我如何玩转职场与母亲双重角色》为参考，生成七个20字内带 emoji 的版本：
1. 《👠到🍼：职场里的都市妈咪日常》
2. 《💼与👶：我如何平衡工作与孩子》
3. 《👩‍💼到👩‍👧：女强人变身妈咪的那些事》
4. 《🏢里的👩‍💻：母亲如何在职场独占鳌头》
5. 《👗与👩‍💻：我的双重身份换装秘诀》
6. 《☑️到🎨：从项目汇报到儿童画的跨界》
7. 《✏️与🔍：办公室里的母亲色彩》

ChatGPT 写正文偏书面，小红书需要口语化、有情绪的表达。于是采用投喂—总结—模仿路线。先把一篇高赞笔记喂进去，让模型总结风格特点，再把总结命名为“小红书爆款风格一”，之后直接调用该风格写笔记。

使用该风格撰写的《🏠 到 👩‍💼：职场里的都市妈咪日常》示例，整体已脱离模型固有腔调，情绪、排版、话题标签都更贴合平台。

#### 4. 总结

把人设确定、选题批量化、标题打磨、风格预训练串起来，就能用 ChatGPT 稳定产出爆款笔记。

## 1.5 10W+ 公众号文章，其实很轻松

看起来门槛很高的 10W+ 爆文，其实都有可复制的套路。结合 ChatGPT，主要分四步走：选定选题方向、调教模型、撰写正文、润色并注入情绪价值。

### 1.5.1 确定选题方向

选择比努力重要。现代读者扫标题的习惯决定了第一印象至关重要。先广泛观察热文，总结高点击标题的共性，如情感共鸣、热点延展、影视解读等。新手可结合兴趣和擅长领域锁定赛道，再确定最终题目。

### 1.5.2 调教 ChatGPT

挑选公众号上的爆款范文作为模板投喂，让模型学习其写作风格。主体由模型生成，但创作者要把控质量。写作过程中实时纠偏，指出偏离的地方并给出期望方向，才能让输出贴合思路。

投喂两步法：先总结范例风格，再让模型模仿该风格写新主题。

### 1.5.3 内文创作

模型已学会你的风格后，就能带着提示词自由发挥。以“14 岁的一个决定，让 40 岁平静且富有”为例，通过设定创作者角色、受众画像、文章基调，引导模型产出沉稳感性的生活感悟文章。

把复杂的写作拆成角色、背景、需求、格式四个要素喂给模型，能让 10W+ 级别的公众号内容变得可操作、可重复。
