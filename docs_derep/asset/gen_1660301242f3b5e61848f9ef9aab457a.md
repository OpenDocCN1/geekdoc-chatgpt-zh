### 14.5.1 Advantage Actor-Critic 详解

上面介绍的通过计算优势值函数 A^π(s，a) 的 Actor Critic 算法称为 Advantage Actor-Critic 算法，它是目前使用 Actor-Critic 思想的主流算法之一。实际上 Actor-Critic 系列算法不一定非要使用优势值函数 A^π(s，a)，还可以衍生出其他变种。

Advantage Actor-Critic 在训练时，Actor 根据当前状态 s[t] 和策略 π[θ] 采样得到动作 a[t]，并与环境交互，得到下一个状态 s[t+1] 和奖励 r[t]。通过 TD 方法即可估计每一步的[PRE16]（s[t]）目标值[PRE17]（s[t]），从而更新 Critic 网络使值网络估计更接近真实环境期望回报；通过[PRE18]=r[t]+γ V^π(s[t+1])-V^π(s[t]) 来估计当前动作的优势值，并采用

### 14.5.2 异步版本的 A3C

A3C 算法全称为 Asynchronous Advantage Actor-Critic 算法，是 DeepMind 基于 Advantage Actor-Critic 算法提出的异步版本[^(\[8\])](#chapter14.xhtml#jz_16_8)，将 Actor-Critic 网络部署在多个线程中同时训练，并通过全局网络同步参数。这种异步训练模式大幅提升了训练效率，训练更快，算法性能也更好。

如图 14.22 所示，算法会新建一个全局网络 Global Network 和 M 个 Worker 线程，Global Network 包含 Actor 和 Critic 网络，每个线程均新建一个交互环境和各自的 Actor 和 Critic 网络。初始化阶段 Global Network 随机初始化参数 θ 和 ϕ，Worker 中的 Actor-Critic 网络从 Global Network 同步拉取参数进行初始化。训练时，Worker 中的 Actor-Critic 网络首先从 Global Network 拉取最新参数，然后在最新策略 πθ 下采样动作与私有环境交互，并根据 Advantage Actor-Critic 算法计算参数 θ 和 ϕ 的梯度信息。完成梯度计算后，各 Worker 将梯度信息提交到 Global Network，利用 Global Network 的优化器完成网络参数更新。测试阶段只使用 Global Network 与环境交互即可。
