# 2.3.13 用注释与 Copilot 互动排错

注释不仅能控制代码生成，还能像与 ChatGPT 对话一样提出问题。例如图 2-61 展示了一段 Go 语言代码。isLetter() 用于判断字符是否为字母，接收 rune 类型参数。name 为 string 类型，现在想把 name[0] 作为参数传入 isLetter()，isLetter(name[0]) 的写法会报错。可以通过在注释中与 Copilot 反复交流来排查，最后 Copilot 指出需要类型转换，正确写法是 isLetter(rune(name[0]))。

# 第3章 更多AI代码生成解决方案

市面上 AI 代码生成工具已非常丰富，不可能长期只依赖 GitHub Copilot，更何况它还是付费的。本章将介绍更多可选工具，包括家喻户晓的 ChatGPT，以及 New Bing、Bard、Claude 等同类产品，还有 Copilot 的替代品 CodeGeeX 和 Amazon CodeWhisperer。有了这些工具，日常开发会如虎添翼，体验十分顺畅。

# 3.1 ChatGPT

本节主要介绍如何借助 ChatGPT 实现与编码相关的自动化工作。需要明确的是，ChatGPT 更像一名参谋，最终决策者是你自己。虽然 ChatGPT 能完成不少编码工作，但它并不能保证输出的代码一定正确或最优，只能作为参考。因此 ChatGPT 并不能完全取代程序员，只能提升工作效率，提升幅度因人而异，可能 30%，也可能 300% 甚至 1000%，这与程序员自身能力有关。总的来说，ChatGPT 会让强者更强，但不一定能让弱者变强。

# 3.1.1 生成完整的代码

ChatGPT 最擅长的是生成完整、可运行的代码。对于目前已有的主流编程语言，如 Python、C++、C、Java、Go、JavaScript、Rust、C# 等，在大多数情况下都能按要求生成基本正确的源码。但要注意，需求越复杂，描述就要越准确，否则 ChatGPT 可能无法准确理解意图。

下面这段文字描述了对所要生成的 Python 源代码的要求。

编写Python程序，在当前目录下创建一个名为data.txt的文本文件，并随机地向该文件中写入10个单词，一行一个单词。然后关闭data.txt文件。接下来读取data.txt文件中的所有单词，将这些单词放在列表中，并按ASCII升序排列它们，最后在终端用一行输出这些单词；给出详细的代码和中文注释。
