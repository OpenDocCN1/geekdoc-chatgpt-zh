## 第 3 节 教师如何主导人机协同教学

生成式AI在教育领域的渗透持续加深，传统教学正加速转向人机协作的新范式。AI为备课、资源生成、学情反馈与评价提供了全新支持，同时对教师角色与专业素养提出更高要求。面对这轮深刻变革，多国教育主管部门、国际组织纷纷出台教师应用GenAI的指引与规范。以下结合国内外相关指南，梳理教师把握人机协同教学主动权的实践路径与工具。

### 一 紧跟政策前沿，强化战略判断与决策

如前所述，自2023年起，全球多个国际组织与国家陆续制定GenAI应用规范并发布典型案例。随着技术对教育的持续重塑，新规范将不断涌现。教师应主动学习相关政策，及时把握应用前沿，提升政策解读、趋势感知与实践判断能力，以理性态度探索AI赋能教学创新，增强对人机协同教学的战略判断与决策力，使AI真正服务创新人才培养，实现更深层的教育价值。

### 二 主动掌握新工具，提升课堂掌控力

及时拥抱GenAI的新方法与新工具，是教师加强人机协同教学掌控力的关键。AI发展迅速，教师既要掌握用其生成内容与资源的方法，也要关注应用审查工具、伦理指南、风险清单等软性支持。只有将技术与规则结合，才能在防范滥用、保障公平的前提下，以主导姿态灵活驾驭AI，真正掌控人机协同教学。

2024年12月26日，日本文部科学省发布了《初等中等教育阶段生成式AI利用暂行指南（2.0）》，指南为教职工与学生分别提供了可操作性的自查清单。①摘录如下供参考。

### （一）教职工应用GenAI的自查清单

- 1. 操作是否在校内办公设备或经教育信息安全管理员许可的设备上进行？
- 2. 是否确认并遵守了GenAI服务提供者制定的最新使用条款？
- 3. 是否在理解GenAI特点如幻觉、偏见等的基础上，在可判断输出结果的恰当范围内使用，并依据自身判断是否采用生成内容？
- 4. 是否避免在提示词中输入重要信息如成绩信息等？
- 5. 若已采取处理重要信息的安全对策，则不在此限，但涉及个人信息时仍需注意下方关于是否避免将个人信息输入提示词的提醒。
- 6. 是否避免将个人信息输入提示词？若已确认服务提供者不会将输入的个人信息用于输出以外的其他目的，则不在此限。
- 7. 是否以不侵犯版权的方式使用GenAI？

### （二）指导学生应用GenAI的自查清单

- 1. 是否确认GenAI对达成教育活动目的的成效？
- 2. 是否充分关注学生的发育阶段及信息利用能力的培养情况？
- 3. 是否开展相关学习活动，让学生明确GenAI的性质与优缺点、掌握辨别信息真伪的方法、意识到自主判断与思考的重要性？
- 4. 是否充分指导学生，避免其在提示词里输入姓名等个人信息？
- 5. 是否充分指导学生，避免其以侵犯版权的方式使用GenAI？
- 6. 是否确认并遵守GenAI服务提供者制定的最新使用条款，包括年龄限制、监护人同意必要性、生成物版权归属等？
- 7. 是否充分指导学生，使其认识到直接将GenAI输出作为自身成果无益于学习，还可能因使用不当导致违法？
- 8. 是否让学生理解，在学习任务中引用GenAI回答时需注明出处？
- 9. 是否在选择GenAI工具时，考虑监护者的经济负担情况？
- 10. 是否基于学生可能在校外使用GenAI的情况，向家长做好说明工作并获得理解，预防不当使用？

## 内容简介

本书立足教师视角，系统探究生成式人工智能（GenAI）在教学与研究场景中的赋能机制与实践路径。作者基于上百场讲座、十余期工作坊及上万名教师的实践反馈，紧扣教师驾驭 GenAI 的核心难点与实践痛点，在阐释 GenAI 原理、本质特性与教育应用特点的基础上，构建起 GenAI 赋能教学与研究的理论框架与行动指南。

本书带领零基础教师从提示词设计、教育智能体创建和个人 GenAI 工具箱搭建着手，系统指导教师在教学、研究的多元场景中灵活高效地应用 GenAI。书中详细拆解了 GenAI 赋能的具体路径：教学场景涵盖教学设计、课程开发、作业设计、PPT/视频/教育数字人等资源创建等；研究场景包括研究选题、文献综述撰写、课题申报书撰写、研究成果投稿与发表等。针对 GenAI 的技术局限性，书中提供了风险防范的理论指导与应用自查清单等实操工具，帮助教师规避潜在风险。
