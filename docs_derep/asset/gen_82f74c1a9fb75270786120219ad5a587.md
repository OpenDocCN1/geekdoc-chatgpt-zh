## 8.5 【实战】创建和管理 CrewAI 中的智能体

在 CrewAI 体系里，智能体是承担具体任务、做出判断并协作工作的核心单元。每个智能体都有明确的角色、目标和能力，既能独立完成工作，也可与其他智能体配合。无论是信息处理、数据分析还是内容生成，智能体都是推动项目进展的关键力量。

CrewAI 企业版还提供可视化智能体构建器，支持无需手写代码即可直观创建和配置智能体，简化配置流程并支持实时测试，便于快速调整和优化行为。

智能体在 CrewAI 中是具备自主性的个体，可完成以下工作：

- 1) 完成特定任务：依据自身角色与目标执行任务。
- 2) 基于角色与目标进行决策：决策受预设目标引导。
- 3) 调用工具达成目标：借助特定工具辅助完成任务。
- 4) 与其他智能体协作：可沟通协作以提升整体效率。
- 5) 保留交互历史：记住过往互动以做出更好判断。
- 6) 任务委派：在允许情况下将部分任务分派给其他智能体。

可将智能体看作拥有专业技能、明确职责和目标的团队成员。例如，研究型智能体擅长信息收集与分析，写作型智能体则聚焦内容生成。

### 1. 可视化智能体构建器

CrewAI 提供的可视化构建器让智能体的创建与配置更直观：

- 1) 表单式界面：通过表单配置智能体属性，避免手写代码的复杂度。
- 2) 实时测试与校验：可即时验证智能体行为是否符合预期。
- 3) 模板库：提供多种预设智能体类型模板，可按需选用并定制。

用户还能根据实际需求灵活调整智能体的各项参数与行为。

### 2. 智能体的属性

每个智能体都包含必需与可选属性，用于定义角色、目标与行为。智能体常见属性及说明见表 8-5。

表 8-5

| 属性 | 参数 | 类型 | 描述 |

| :--- | :--- | :--- | :--- |

| 角色 | role | str | 定义智能体的功能和专业领域 |

| 目标 | goal | str | 智能体的任务目标，指引其决策过程 |

| 背景故事 | backstory | str | 为智能体提供上下文和个性，使其行为更加丰富 |

| 语言模型（LLM） | llm | Union[str, LLM, Any] | 智能体使用的语言模型，默认为 GPT-4 |

| 工具 | tools | List[BaseTool] | 智能体可以使用的工具，默认空列表 |
