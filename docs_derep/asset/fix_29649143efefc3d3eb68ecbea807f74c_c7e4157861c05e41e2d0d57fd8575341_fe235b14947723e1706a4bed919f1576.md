把丹尼尔案例视作对照试验的源头，是文献里常见的说法，Lilienfeld 1982 与 Stigler 2016 都对此有交代。檀香山步行研究的实证结果，详见 Hakim 1998。

Box 在为父亲立传时，引用了那段被反复提及的“对自然提出巧妙提问”的长句，出自 Box 1978 第 6 章那本关于 R. A. Fisher 的传记。Stigler 2016 也指出，Fisher 本人就把试验写作与自然的对话。综合来看，这段文字的内核几乎全来自 Fisher，只是经 Box 之手表述得更精炼优美。

Weinberg 关于混杂的两篇论著 Weinberg 1993；Howards 等人 2012 放在一起读很有意思。它们像两张时间胶囊，一张拍摄于因果图尚未普及的年代，另一张则是在二十年后用因果图的语言回看同一组案例。Forbes 绘制的哮喘与吸烟之间错综的因果网，收录于 Williamson 等人 2014。

Morabia 2011 收录了混杂在经典流行病学语境下的定义。David Cox 的那段引文来自 Cox 1992 第 66–67 页。要追溯混杂概念的历史脉络，还可参考 Greenland 与 Robins 2009 以及 Wikipedia 2016。

后门准则与后门调整公式由 Pearl 1993 提出。它在流行病学中的影响可通过 Greenland、Pearl 与 Robins 1999 了解。针对序贯干预等更精细情境的推广，先见于 Pearl 2000、2009，后在 Pearl、Glymour 与 Jewell 2016 中得到系统化梳理。Tikka 与 Karvanen 2017 提供了基于 do 演算实现因果效应计算的软件工具。

随着混杂理解的深化，尤其是因果图方法成熟 Greenland 与 Robins 2009，Greenland 与 Robins 在 1986 年发表的论文在四分之一世纪后由作者本人撤回并重写。
