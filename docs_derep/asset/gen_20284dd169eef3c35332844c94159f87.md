## 14.4 应用优化与质量控制要点

本节对提升生成质量和效率的关键做法做简要归纳。

### 1. 应用优化建议

落地使用时，建议重点关注以下事项以保证质量与效率。

#### 1) 关键词优化

使用精准的专业表述，避开模糊用语。提供必要的上下文，关键词个数建议控制在 3~5 个左右。按重要程度排序，突出核心主题，有助于系统更准确地理解意图。

#### 2) 模板选择策略

不同场景推荐不同的模板：

- 商务汇报适合简约商务风格，强化数据可视化。
- 技术分享建议采用科技风格模板，突出逻辑层次。
- 营销方案可选用创意设计风格，强调视觉冲击。
- 教育培训推荐清新活泼风格，关注内容层级呈现。

### 2. 质量控制要点

生成后建议从以下维度复核。

#### 1) 内容维度

核查核心信息是否突出，整体框架是否完整清晰。检查内容转化是否流畅自然，专业术语使用是否规范准确。特别注意章节间的逻辑关系，确保整体连贯。

#### 2) 设计维度

保持整体风格统一，配色方案专业协调。字号层级合理，图文比例符合视觉习惯。在保证美观的同时确保可读性和实用性。

# 第16章 实战案例：多Agent模式开发旅游助手

多Agent 模式是扣子平台的创新能力，允许在构建聊天机器人时集成多个智能体。该模式适用于需要应对复杂场景和提供全面功能的机器人。本章介绍基于多Agent模式开发旅游助手的方法。

## 16.1 认识多Agent

多Agent 模式由多个 Agent 协同完成复杂任务。启用后可为每个智能体设定特定触发词，将复杂任务拆解为若干易管理的子任务。此方式简化了单个机器人的逻辑结构，提升复杂查询的处理效率与准确度。

在多Agent 模式下，主 Agent 负责整体任务管控与协调，子 Agent 专注具体子任务，通过反馈、竞争与对话机制协同完成任务，提升系统灵活性和效率。
