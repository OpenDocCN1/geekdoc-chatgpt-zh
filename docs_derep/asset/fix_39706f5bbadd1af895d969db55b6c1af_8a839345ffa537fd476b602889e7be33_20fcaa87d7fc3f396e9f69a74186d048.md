**AI 双模式使用方式与实战拆解**

**1.Chat 模式（聊天模式）**

处于这一状态时，AI 编程工具仅对用户提出的问题作出文字回应，不会触碰代码编辑区。体验上近似于与教师进行远程语音沟通，教师只能借助语言描述思路，没法在你的编辑器里现场演示代码改动。

**2.Builder 模式（构建模式）**

切换到这一状态后，工具除了解答之外，还会对编辑区内的代码给出修改建议。感觉更像老师现场一对一辅导，修改方案会直接呈现在代码区。需要留意的是，当建议对已有代码进行改动时，并不会立即覆盖，而是先弹出询问：“我已把你的代码改成这样，你是否接受？”只有在你核对完生成的内容并点击“接受”后，新的代码才会真正替换原稿。

下面列出的案例基本都选用 Builder 模式，目的在于直观展示工具的功能以及真实使用手感。

在备考信息学奥赛时，我们更倾向于优先使用 Chat 模式。 [PRE0]

重要提示

学习信息学奥赛内容时，建议首先使用工具的 Chat 模式。

Chat 模式只负责答疑，不去动代码，把思考和动手都留给学习者，有助于锻炼实操能力。若在 Chat 模式下仍无法突破，卡住十分严重，需要工具直接给出样例或协助生成代码时，再换到 Builder 模式。
