# 14 类中文新闻分类的微调实操

让通用模型真正分清中文新闻的类别，核心不是写更长的指令，而是喂给它一批带标签的样本让它自己建立映射。下面是一条可复现的数据到验证的完整链路，思路重写，关键代码保留。

调用方式先做区分。补全类调用选用 text-davinci-003，生成温度调到 0，单次最多 10 个词元，top_p 为 1，频率与存在惩罚都关闭，最后从 choices 首项的 text 中去掉首尾空白。聊天类调用则用 gpt-3.5-turbo，把用户消息塞进 messages，超参保持一致。两种写法在对比微调前后效果时很重要。

封装一个通用的 completion 调用，超参与之前保持一致。

[PRE16]
def complete(prompt: str, model: str, max_tokens: int) -> str:

    response = openai.Completion.create(

        prompt=prompt,

        temperature=0,

        max_tokens=max_tokens,

        top_p=1,

        frequency_penalty=0,

        presence_penalty=0,

        model=model

    )

    ans = response["choices"][0]["text"].strip(" \n")

    return ans
