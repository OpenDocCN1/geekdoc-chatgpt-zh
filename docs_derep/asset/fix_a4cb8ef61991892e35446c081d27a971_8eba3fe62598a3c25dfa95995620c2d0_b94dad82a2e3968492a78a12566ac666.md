各组件职责如下。

1）与索引器相关的模块

3）与本地检索相关的模块

4）与向量存储相关的模块
向量库接口 LanceDBVectorStore：管理语义向量的持久化与高效检索。

相关参数说明如下。

- community_reports：传入之前加载的社区报告数据 reports，用于补充社区层级的背景信息。
- text_units：传入已加载的文本单元数据，提供来自原始文档的小块文本。
- entities：传入知识图谱中的实体，提供实体的详细信息和属性。
- relationships：传入知识图谱中的关系，用于描述实体间的交互和连接。
- covariates：传入协变量，若索引阶段未启用则设为 None，用于提供附加声明式元数据。
- entity_text_embeddings：传入实体嵌入的存储对象 description_embedding_store，将实体文本嵌入存于向量库。
- embedding_vectorstore_key：设置嵌入向量存储的键类型，若按 ID 存储使用 EntityVectorStoreKey.ID，按标题存储则使用 EntityVectorStoreKey.TITLE。
- text_embedder：传入嵌入生成器对象 text_embedder，用于生成文本或问题的语义嵌入。
- token_encoder：传入分词器，确保生成的上下文不超过 LLM 的上下文窗口限制。

上下文构建器是本地搜索的核心组件，作用如下。

- 结合社区报告提供更高层次的背景信息，利于回答主题性问题。
- 整合文本单元，使用原始文档片段构建直接上下文。
- 集成图谱实体与关系，为实体相关问题提供详细语义信息。
- 利用嵌入与分词器，保证上下文语义准确且符合 LLM 的窗口限制。

相关参数说明如下。
