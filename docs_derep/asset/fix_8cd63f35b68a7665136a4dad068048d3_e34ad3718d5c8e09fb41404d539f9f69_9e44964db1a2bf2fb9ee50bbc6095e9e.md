# HR与AI的共生新篇

# 导语

任正非曾把AI的爆发类比为蒸汽机与内燃机的出现，意味着生产方式与社会结构在进行根本性重塑。工作场景被改写，人力资源这个角色也很难置身事外。

这一次的技术跃迁速度远超以往。部分企业已提前卡位并尝到红利，另一部分仍在观望，或是浅尝后就止步不前。

无论准备是否充分，AI已经落地并持续改写工作的边界。本书不去论证AI有多强，核心是探讨它如何让HR做事更有效、更精准。

# 1. AI已抵达，HR必须在场

HR的真正价值是读懂人、看清组织并推动有意义的改变。现实里，大多数人被琐事淹没，忙于重复性事务，很难抽出时间做深度思考。有的是时间被挤占，有的是无从下手。

AI恰好打开了突破口。用对方法，它就是能力的延伸，也是进化的助推器。马车夫嘲笑火车的旧事不会重演，我们正在进入一次真正的跃迁。

AI不只是工具，它更像一面镜子，映出固有习惯，也暴露出能力边界。随行业务进入HR领域，许多传统做法正在被拆解重塑。过去依赖经验的判断、繁琐的手工环节，一旦结构化即可被替代。曾经被视作专业壁垒的内容，正变得可复制、可自动化。

# 2. 由被动响应转向主动协作

面对变化，HR不能仅做被动接受者，而要升级与AI共事的方式。可以做一个小测试，假设需要分析离职原因。

做法A：请根据员工离职访谈帮我分析离职问题。
做法B：你现在是HR分析师，附件是近半年的离职访谈纪要，请从薪酬机制、管理风格、职业发展三个维度提炼共性痛点，以清单形式输出，便于写入改善报告。

对比一下，两者的输出质量相差很大。后者条理清晰，能直接支撑决策。

问题不在于模型不行，而在于使用方式不对。

# 3. AI能力正在成为职业分水岭

有人已借助AI实现跃迁，有人仍在低效循环。当有人还在让模型写几段文字时，已有同行用AI完成绩效洞察、流程再造、报告产出，甚至一人承担原本一个小组的工作。AI取代不了HR，但会淘汰不会用AI的HR。这并非危言耸听，而是趋势所致。

差距不仅是工具熟练度，更是认知高度、方法体系与思维模式。真正门槛不是技术，而是结构化思维、任务拆解与判断力。

AI不会让HR消失，而是倒逼进化，走向更高阶的专业定位。未来的HR不仅是操作者，更要成为协作者。HR的核心价值始终来自对人性的理解、对组织的洞察，以及人类特有的温度，这是模型无法替代的。

# 4. 读完后你会得到什么

这不是操作AI工具的技术手册，而是一本面向实战与学习的认知训练指南。目标是帮你搭建专属的AI时代HR进化框架。

适合人群：
- 被事务性工作拖垮，想用AI解放双手的HR新人；
- 卡在专业瓶颈，希望借助AI重塑体系的中层管理者；
- 推动组织变革，需要把AI融入人才战略的HR负责人；
- 所有认同人机协同的人才进化者。

你将掌握：
- 用提示词驱动AI进行有效协作；
- 通过自主学习构建专属的HR知识地图；
- 借助AI搭建四大HR基础体系；
- 赋能绩效洞察、人才发展、战略规划等实战；
- 重塑能力结构，迈向策略型HR。

这不是读完点头的书，而是读完就能上手落地的书。

AI已至，未来不会等待犹豫者。让我们不只是追随变化，而是成为变化的一部分。希望读者能明确下一步的起点。

# 第一章 提问与判断：HR用好AI的起点

AI在HR领域的落地，相较于其它管理职能，具备天然的双重基因。

一方面，HR方法论具有普遍性。从胜任力建模到薪酬设计，百年管理科学已沉淀出体系化范式与工具。我们要做的是学会激活AI的知识引擎，快速调用全球积累的理论、方法与案例。

另一方面，HR工作高度情境化。文化特征、组织阶段、人才结构等变量决定了任何标杆方案都可借鉴难复制。这意味着AI不仅是知识搬运工，更要成为定制化的思维伙伴，在通用方法与企业特性之间搭建出真正契合的解法。

因此HR是AI最易上手却最难精通的领域。就像人人都有厨房，并不等于人人都能做饭，食材相同，有人只能做出快餐，有人能烹出佳肴。工具相同，差异在于认知方式与使用策略。

## 第一节 用提示词指挥AI

提示词即指令，是人与AI交互的桥梁。表面看只是一句话，实则承载意图表达、任务拆解与逻辑组织。指令清晰，AI才能准确理解；指令模糊，只能猜测。

### 一 为AI设定五种身份

AI正逐步具备拟人化特征，可模拟多种视角。你可以让它扮演五种角色：导师、助手、对手、目标受众和创作者。

#### 一) 导师：提升认知，处理复杂议题

在需要认知支持的任务中，AI可担任导师角色，协助理解复杂议题、梳理思路。

凭借广阔的知识储备与高速的信息整合能力，AI能系统化组织内容，帮助理清概念脉络、重构逻辑关系、搭建主题框架。其角色类似首席知识官或数字智囊。

虽然无法替代顶尖人物的深度洞察，但在知识广度与逻辑组织上已远超多数人，足以提供专业支持。

设定导师角色的三个要点：
1. 赋予权威人设。输出的语言风格与逻辑深度受角色设定影响显著。设定为资深专家或诺奖得主等高成就身份，有助于提升专业性与结构性。
2. 聚焦认知任务。导师型AI的价值不在于代写，而在于助思。它擅长组织思路、搭建框架、比较路径、解释机制等，适合构建结构而非直接生成终稿。
3. 明确提问方式。适合开放式问题。避免“这对不对”式提问，采用“请解释”“请从三方面分析”等结构化问法，引导系统性推理。

示例指令：
你是数字HR领域的专家。请帮我梳理“AI赋能招聘”的方案结构框架，要求语言通俗清晰、逻辑严谨。

#### 二) 助手：执行操作，高效产出

在标准化任务中，AI最适合扮演助手。它执行稳定、响应迅速，能高效完成明确可拆解的事务性工作。

无论是撰写通知、整理清单、生成摘要，还是处理表格数据，AI都能快速上手、批量产出。随着智能体技术发展，AI助手正从被动执行走向主动推进。

设定助手角色的三个要点：
1. 明确任务目标。任务要具体清晰可执行，避免模糊描述。例如“帮我写一篇某主题文章”结果会平淡，而“请写一篇800字的HR某主题推文，口吻亲切、结构清晰”则更具操作性。
2. 规范输出格式。明确输出形式，包括结构要求、语气风格、字数范围、语言种类等。要求越清晰，结果越可控。
3. 提供上下文信息。助手型AI不具备理解情境的能力，输入信息越充分，结果越贴合。建议提供背景材料、参考样例或必要说明，减少偏差。

示例指令：
你是我的行政文案助手，请按以下要求撰写一则内部通知：
目标：通知员工“五一”假期安排
材料：5月1日至5日放假，5月6日恢复上班，假期期间注意关闭办公设备
格式：正式通知格式，段落清晰，适合发布在OA系统
语气：正式、简洁
限制：控制在200字以内
如有不清楚请提问，不要自行假设。

#### 三) 对手：反向验证，锤炼思维

AI不仅能协助完成任务，也可充当对手，帮助进行假设验证、方案反推与逻辑检视。

在策略制定、方案评估、观点表达等场景中，它能模拟客户、上司、投资人或竞争者，从对立视角提出质疑，暴露盲点，优化推理，增强说服力。

该角色的价值不在于附和，而在于逼你把问题想透、把逻辑讲清。

设定对手角色的三个要点：
1. 设定真实身份。指定AI扮演的身份对象及特点，如保守型HRD、资深采购经理、竞争企业负责人等。身份决定视角，视角决定质疑切入点。
2. 指定博弈场景。明确希望挑战的内容，如一项计划、一个判断、一个主张，并告知预设立场，让AI在真实情境下提出合理挑战。
3. 引导反向思考。鼓励AI从可行性、成本、接受度、风险、长期影响等多角度质疑，必要时可引导其持续追问，形成深度交锋。

示例指令：
请扮演一家保守型传统HRD，质疑我提出的“全面引入AI工具改造招聘流程”的建议。我主张全流程AI辅助招聘，请从数据安全、员工接受度、实施成本三个方面提出反对意见，可逐点挑战，若我回应请继续追问，直到逻辑闭环。

#### 四) 目标受众：同理洞察，提升共鸣

在内容创作、沟通表达、用户研究等任务中，AI可模拟目标受众视角，对内容进行反应与反馈。

可让其扮演HR总监、00后职场新人，阅读文案、倾听主张、理解方案，并给出“像他们一样”的真实感受与建议。

该角色的价值在于让你从读者立场审视方案与内容。

设定目标受众角色的三个要点：
1. 设定用户身份。清晰指明AI应扮演的人群，如“三年经验HRBP”“注重细节的企业老板”等。身份越具体，反馈越真实。
2. 提供评估对象。将希望AI评估的内容完整提供，确保有充分上下文进行判断。
3. 引导反馈角度。指定反馈维度，如是否易懂、是否有吸引力、是否有说服力、是否符合预期等。

示例指令：
请你扮演一位985大学毕业生，阅读以下招聘广告文案，并回答三个问题：1) 你是否会点击查看？2) 第一印象是什么？3) 你是否愿意了解更多？请说明原因。

#### 五) 创作者：共创内容，激发灵感

AI也可以作为创意共创者，擅长命名构思、标题打磨、脚本草拟、文风模仿等任务，尤其适用于从0到1的灵感激发与素材生成。

在这一角色下，其价值不在于完成任务，而在于提供可能性，拓展思路，激发更多角度与表达。

设定创作者角色的三个要点：
1. 明确创作目标。清楚说明创作内容类型及用途、受众、使用场景，帮助AI把握方向。
2. 提供创作边界。设定风格调性、内容限制、参考素材等，防止跑题或风格偏差。
3. 赋予共创身份。将AI设定为创意搭档，鼓励其主动提供选项、解释思路、尝试不同表达，形成真正共创。

示例指令：
你是我的创意搭档，我们要为一门“AI赋能HR”的在线课程命名。目标：名称简洁有辨识度，面向企业HR，风格专业中带点轻松。请列出10个命名建议，并简要说明命名逻辑。

理解五种角色特点并灵活切换，是高效使用AI的起点，也是掌握人机协作的关键。

### 二 提示词设计的四种策略

提示词不仅决定AI能否准确理解意图，更直接影响回应方向、深度与表达效果。指令越清晰，输出越精准。

图1-1展示了提示词设计策略的四种典型模式：智驾模式指在结构化指令下让AI精准执行意图；火花模式用于激发创作灵感与内容多样性；缰绳模式则指引入方法论或思想，引导AI按特定逻辑生成内容。标尺模式主要用于内容把关与质量审校。

四种模式既可单独使用，也可灵活叠加，形成既能放手生成又能精准收敛的提示词系统。接下来逐一拆解。

#### 一) 智驾模式：结构化指令

AI最擅长处理问题清晰、目标明确、流程可控的任务。提示词中的智驾模式本质是结构化编程，你给出路线图，它按图索骥，有序输出。

适用于你知道要什么，只需高效完成，如写总结汇报、产出标准模板。

##### 1. RCOR+X指令结构

该结构包含四个核心加可选补充维度。
- R 角色设定。AI应以何种身份思考？
- C 任务背景。任务发生的情境是什么？
- O 目标成果。希望输出什么？
- R 输出要求。在结构、风格、格式上的具体要求。

在此基础上，根据任务进行X补充，可进一步提升专业表现，如内容框架、应用场景、指定证据等。

案例演示：
背景：你是公司HRBP，刚完成一场离职员工访谈。该员工来自销售部门，反馈了晋升机会、绩效公平和工作负荷相关问题。任务是撰写访谈纪要报告，供HRD参考，作为部门改善与制度评估依据。

1) 普通型指令
输入：帮我写一份员工离职访谈纪要，内容包括员工反馈和建议。
AI反馈：
离职访谈纪要
员工对销售岗位整体满意，但认为晋升路径不够清晰，绩效评估标准略显主观，近期工作压力较大。建议公司优化激励机制，加强内部沟通，提升员工参与感。

2) RCOR+X结构化指令
输入：
你是一名资深HRBP。现在我公司销售岗位员工提出多项关于绩效、晋升和压力管理的反馈，请帮我撰写一份离职访谈纪要，结构清晰、内容具体，反映真实声音，供HRD判断改进方向。
要求报告需包含：
- 基本访谈信息；
- 核心反馈问题；
- 员工建议；
- HR观察与建议；
- 语言专业、客观、简明；
- 适合HR管理层审阅，可直接作为内部改进参考。

AI反馈：
离职访谈纪要报告
访谈对象：销售部李某某 | 工作年限：3年 | 职位：客户经理
访谈时间：2024年12月10日 | 访谈人：HRBP张某
1) 员工反馈要点
- 晋升机制不明确：评定标准缺乏公开透明，导致发展路径预期不清。
- 绩效评估主观性强：部分季度结果与工作成果不符，认为存在主管偏好影响。
- 工作节奏高压：月度指标紧张，加班频繁，缺乏弹性安排。
2) 员工建议
- 明确并公示晋升标准。
- 增加绩效沟通频次。
- 引入轮岗机制，缓解岗位疲劳。
3) 观察与建议
- 建议HRD评估销售体系绩效模型是否需微调。
- 可考虑引入“晋升路径图”和“季度问卷反馈机制”提高参与感。
备注：员工整体认可公司文化，表达离职为“职业发展阶段性调整”，无负面情绪倾向。

智驾模式本质与职场委派任务方式相近：先说明谁来做、在什么背景下做，再说要做成什么样、有什么要求。RCOR+X就是把这种思维翻译成AI能理解的指令。

##### 2. 哲学三问式指令结构

当任务存在较高不确定性和创造性，如策划方案、探索新机制或撰写高阶内容时，推荐使用哲学三问式指令。

结构：指令=我是谁？角色 + 我从哪里来？问题背景 + 我要到哪里去？目标 + X 约束条件。

示例指令：

#### 二) 火花模式：交互触发

AI底层是基于概率预测的语言模型。它不会真正思考，但擅长组合。每一次追问、补充或纠正，都会促使它重新计算最可能有价值的回应路径。交互越多元，灵感张力越强。

在此模式下，提示词更像发起头脑风暴的邀请。你不是要求完成任务，而是在请它一起探索，打破认知惯性，带你走到原本没想到的路径。

建议采用多轮交互设计、递进式提问，例如：
- 反问型。挑战默认设定，打破思维定势。
- 角色代入型。转换视角，共情模拟。
- 版本对比型。并列生成，激发选择偏好。
- 拆解/归类型。发散思维，再收敛聚焦。
