### 比较运算符速查

| 数学符号 | Python 符号 | 示例 | 含义 |
| :--- | :--- | :--- | :--- |
| > | `>` | `x > y` | 大于 |
| < | `<` | `x < y` | 小于 |
| ≥ | `>=` | `x >= y` | 大于等于 |
| ≤ | `<=` | `x <= y` | 小于等于 |
| = | `==` | `x == y` | 等于 |
| ≠ | `!=` | `x != y` | 不等于 |

**优先级规则**：`> < >= <=` 同级，高于 `== !=`。符号间**严禁加空格**（如 `> =` 报错），顺序颠倒（`=>`、`=<`、`=!`）同样非法。

### 本章运算符优先级与结合性汇总

按优先级降序排列：

| 运算符 | 结合性 | 类别 |
| :--- | :--- | :--- |
| `( )` | 左→右 | 括号/分组 |
| `**` | 右→左 | 幂运算 |
| `* / // %` | 左→右 | 乘/除/整除/取模 |
| `+ -` | 左→右 | 加/减 |
| `< <= > >=` | 左→右 | 比较运算 |
| `== !=` | 左→右 | 相等性判断 |

完整官方表参考：`https://docs.python.org/3/reference/expressions.html#operator-precedence`。复杂表达式建议显式加括号消除歧义。
