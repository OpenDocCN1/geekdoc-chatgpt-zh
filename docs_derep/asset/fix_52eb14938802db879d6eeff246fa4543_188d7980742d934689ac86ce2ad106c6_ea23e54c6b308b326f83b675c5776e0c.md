# Coze Agent 实操速览

总体来看，Coze 以低门槛、功能齐全与部署灵活的特点，正在改变 Agent 的搭建方式，让更多非技术人群也能参与 AI 应用创新。

#### 3.1.2 主流Agent构建平台对照
Agent 技术演进很快，配套的构建平台也越来越多。大部分产品都预置了丰富工具链，让普通人也能做出具备实战能力的 Agent。下面聚焦三款代表性平台做简要横评。

##### 1. Dify
Dify 是一款开源的大模型应用构建平台，可接入 GPT、Mistral、Llama3 等模型。平台提供基于 YAML 的声明式编写、模块化架构、LLMOps 监控优化能力，并支持私有化部署。定位是把复杂 AI 应用的开发流程简化，特别适合需要深度定制或企业级落地的场景。

亮点：
- 国际化覆盖广：面向海外市场，集成多语言模型与本地化工具。
- 灵活可扩展：支持自托管与云服务，能与企业内部系统无缝对接，满足安全合规。
- 开源社区活跃：社区贡献大量模板和协作资源，可视化 Workflow 助力快速迭代。
- 多模型横评：可并行测试 GPT-4、Claude3 等不同模型的输出，便于择优适配。

限制：
- 技术门槛偏高：模型接入和配置需要开发背景，对新手不友好。
- 国内生态相对弱：相比 Coze，本土市场份额和插件支持有限。

典型用途：
企业级大模型底座搭建、私有化部署、由开发者主导的复杂 AI 应用构建。

##### 2. Coze
Coze 由字节跳动推出，以自然对话体验为特色，支持语音识别与合成、插件生态丰富，并可通过 Web SDK 嵌入网页。核心用户是 C 端用户和轻量级应用开发者。

亮点：
- 体验极致：界面简洁、对话顺滑、语音交互精准，非技术用户也能迅速上手。
- 插件生态强：内置电商、客服等多领域插件，依托字节技术资源，国内生态尤为完善。
- 模型支持友好：国际版可免费调用 GPT-4，整体功能成熟度较高。

限制：
- 定制能力受限：主要面向标准化机器人开发，复杂任务的扩展性不及 Dify 和 FastGPT，且仅限云端部署。

典型用途：
智能客服、语音助手、社交媒体聊天机器人等对交互体验要求高的 C 端应用。

##### 3. FastGPT
FastGPT 聚焦知识问答类 Agent，基于 RAG 技术强化知识库检索，适合企业深度定制，但生态主要集中在国内。

亮点：
- 垂直场景突出：在知识库搭建与复杂问答上表现优异，支持高度定制化。
- 开源可扩展：吸引开发者参与共建，适合需要自主优化的团队。

限制：
- 部署门槛高：需要开发者背景，对初学者不友好。
- 国际化不足：插件和模型接入选择少于 Dify 和 Coze。

典型用途：
企业知识库管理、专业领域问答系统、需本地化部署的行业解决方案。

### 3.3 角色 Prompt
无论是新手还是资深开发者，都绕不开 Prompt 设置。Prompt 相当于 AI 的任务说明书，写得好才能得到理想输出。本质上是自然语言指令，告知模型做什么、怎么做。
创建 Agent 时，Prompt 通常有四种设置方式：直接编写、使用模板、引用资源、AI 自动生成。

#### 3.3.1 常用的 Prompt 设置方法
方法1：直接编写 Prompt。
熟悉业务时可直接用自己的语言撰写。
1. 登录 Coze，在工作区新建一个 Agent。
2. 在角色设定与回应逻辑面板输入 Prompt。
注意：
- 使用清晰指令，如“你是一名销售顾问，请给出专业产品推荐”，而非“帮我推荐产品”。
- Prompt 需贴合业务，越具体效果越好。

方法2：使用 Prompt 模板。
平台提供多行业场景模板，可快速调用，如图 3-10 所示。
1. 点击“Prompt 库”，切换到“推荐”标签。
2. 选择合适模板，点击“插入 Prompt”。

#### 3.3.2 提升 Prompt 质量的9个技巧
1. 明确目标与任务：先界定身份和具体任务，如“你是数据分析师，请分析数据表”。
2. 简洁具体：避免冗余，直接给指令。
3. 提供上下文：复杂任务时补充背景信息，帮助模型理解。
4. 避免歧义：用简单清晰的语言，减少误解。
5. 反馈迭代：根据模型输出不断优化 Prompt。
6. 使用示例：提供输入输出样例，帮助模型学习模式。
7. 考虑多样性：兼顾不同用户的表达习惯。
8. 充分测试：发布前全面测试，尤其是异常输入。
9. 遵守伦理：确保内容符合法律与伦理规范，避免歧视侵权。

#### 3.3.3 使用 Markdown 结构化 Prompt
Markdown 是一种轻量标记语言，可用纯文本创建富文本文档。
基础用法：
- 用#创建标题，#越多级别越低。
- *或_加文字实现斜体，**或__实现加粗。
- -或*加空格创建无序列表。
- 数字+点+空格创建有序列表。
- >创建引用。
- ```包围代码块。

优势是易学易用，兼容 GitHub、公众号编辑器等。解析后可得到格式精美的文档。
结构化 Prompt 提升可读性和可维护性，推荐包含角色描述、技能清单与流程、限制条件、回应示例。

### 3.4 Workflow
简单来说，Workflow 是一系列可执行指令，用于完成特定任务或业务逻辑，为应用/Agent 提供结构化框架，使数据流和任务处理更有序。
最大亮点是将大模型能力与业务逻辑结合，通过流程化开发高效可扩展的 AI 应用。

平台提供可视化画布，拖拽节点即可搭建完整流程，并可实时调试，查看数据流动和执行顺序。

#### 3.4.1 Workflow 与对话流
Coze 提供两种灵活的 Workflow 类型，按需选择。

##### 1. Workflow
- 面向功能型请求，处理明确任务。
- 可顺序执行多节点，数据流转清晰可控。
- 适合自动化场景，如生成行业调研报告、一键制作海报或绘本、批量数据处理等。

##### 2. 对话流
- 面向对话场景，让回应更自然。
- 支持多轮交互，并根据用户输入做复杂逻辑判断。
