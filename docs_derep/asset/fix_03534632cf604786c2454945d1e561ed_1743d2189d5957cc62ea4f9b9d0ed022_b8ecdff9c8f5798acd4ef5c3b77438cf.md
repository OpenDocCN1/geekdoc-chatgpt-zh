AAAI、NeurIPS 与未来生命研究所的邀请令我感佩。纽约大学算法与解释会议、FAT*、AI Now、CITRIS 包容性人工智能研讨会、西蒙斯计算理论研究所关于优化与失效的论坛，以及人类兼容人工智能中心 CHAI 都曾围绕关键议题召集讨论，参与其中殊为荣幸。

写作空间也在不同时段提供了助力。麦克道威尔文艺营为开篇提供了安静环境，Mike 与 Kaitlyn Krieger 夫妇家中为中段写作提供了庇护，雅多公司则为收尾阶段提供了时间与灵感。

在相对孤独的写作时光里，Jerry Garcia 与 Sylvia Plath 的精神陪伴着我。

搜集零散史料时得到多方协助：麦克马斯特大学伯特兰·罗素档案馆的 Kenneth Blackwell；费城美国哲学学会收藏的沃伦·麦卡洛克文稿；康奈尔大学的弗兰克·罗森布拉特档案；蒙特雷县免费图书馆与旧金山公共图书馆；以及引文调查组织的 Garson O’Toole。

互联网档案馆保存了众多稍纵即逝却重要的历史记录。

本书写作也得益于大量免费与开源工具，尤其是 Git、TeX 与 LaTeX。颇具讽刺的是，手稿仍在使用四十多年前的排版系统，而该系统的文档撰写者正是亚瑟·塞缪尔。我们依然站在巨人肩上。

谨此追念在写作期间离世的几位先驱，他们虽已无声，思想却留存于书中：Derek Parfit、Kenneth Arrow、Hubert Dreyfus、Stanislav Petrov 与 Ursula K. Le Guin。

加州大学伯克利分校对我意义非凡。CITRIS 期间的访问学者经历令人难忘，特别感谢 Brandie Nonnecke 与 Camille Crittenden；西蒙斯计算理论研究所的 Kristin Kane 与 Richard Karp；CHAI 的 Stuart Russell 与 Mark Nitzberg；以及 CHAI 研讨会的与会者与嘉宾。你们的鼓舞与友情弥足珍贵。

最后感谢我的妻子罗斯。她是首位读者，也是始终坚定的依靠，以敏锐的眼光与倾听给予持续的陪伴与支持。她始终相信我，我由衷希望她是正确的。
