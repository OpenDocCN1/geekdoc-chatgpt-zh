# MNIST 训练闭环 PyTorch 速览

想在一趟里把深度学习的完整链路跑通，MNIST 是最轻量的验证场。下面把网络结构、数据准备、设备迁移和加速手段拆开说明，重点在于自定义数据封装、可调用的预处理、批量读取与训练循环如何配合起来。

网络采用全连接结构。先把二维图像展平成一维向量，再串联两段隐藏层，第一段把 784 维映射到 312 维，第二段收敛到 256 维，最后输出十个类别的 logits。实例化后先把模型搬到可用的计算设备上，保存一份权重，再开启 PyTorch 2.0 的编译加速。损失用交叉熵，自适应矩估计优化器的学习率在不同示例里分别演示了 2e-5 与 2e-4。训练按轮推进，每轮遍历所有批次累加损失，最后输出轮均值。

数据侧依赖事先用 NumPy 保存的训练图片与标签数组。自定义的数据集类在初始化时载入这两个数组，并在取样时根据是否提供转换器来决定是否进行预处理。转换器实现了可调用接口，把样本拉成一维并转为张量。批量读取器在此之上完成随机打乱与分块，以便循环中使用。

import numpy as np

import torch

#device = "cpu"  #PyTorch的特性，需要指定计算的硬件，如果没有GPU的存在，就使用CPU进行计算

device = "cuda"  #在这里默认使用GPU，如果出现运行问题，可以将其改成CPU模式

class ToTensor:

    def __call__(self, inputs, targets):  #可调用对象

        inputs = np.reshape(inputs,[28*28])

        return torch.tensor(inputs), torch.tensor(targets)

class MNIST_Dataset(torch.utils.data.Dataset):

    def __init__(self,transform = None):  #在定义时需要定义transform的参数

        super(MNIST_Dataset, self).__init__()

        # 载入数据

        self.x_train = np.load("../dataset/mnist/x_train.npy")

        self.y_train_label = np.load("../dataset/mnist/y_train_label.npy")

        self.transform = transform #需要显式地提供transform类

    def __getitem__(self, index):

        image = (self.x_train[index])

        label = (self.y_train_label[index])

        #通过判定transform类的存在对其进行调用

        if self.transform:

            image,label = self.transform(image,label)

        return image,label

    def __len__(self):

        return len(self.y_train_label)
