# CIFAR 数据集实战：从下载到队列机制全解析

CIFAR 数据集属于彩色图像范畴，因此数据呈三通道结构，即 R、G、B 三个分量。后续衍生出的 CIFAR-100 版本将分类细分至 100 类，无疑为神经网络的识别能力提出了更严苛的考验。有了这些现成的标准数据，我们便能聚焦于网络模型的优化调优。

官方获取地址为 `http://www.cs.toronto.edu/~kriz/cifar.html`。与 MNIST 不同，CIFAR 提供了现成的打包文件（如图 8-12），涵盖 Python、MATLAB 及二进制 bin 格式，方便不同开发环境直接调用。
