# 迁移学习与 NLP 核心词汇速查：经典文献与中英对照全景版

## 奠基文献回顾

**Ziser 与 Reichart (2018)** 在 NAACL-HLT 2018 会议论文集（第 1241-1251 页）中提出，利用枢轴词语言建模可显著增强神经网络的领域适应性能。

**Zoph 与 Knight (2016)** 于 NAACL-HLT 2016（第 30-34 页）发布研究，深入剖析多源神经机器翻译机制。

**Zoph 等人 (2016)** 随后在 CoRR 预印本（abs/1604.02201）中，进一步拓展了面向低资源场景的神经机器翻译迁移学习策略。

**Zweig 与 Weinshall (2013)** 在第 30 届 ICML 会议论文集（第 37-45 页）中，构建了层次正则化级联框架以实现高效联合学习。
