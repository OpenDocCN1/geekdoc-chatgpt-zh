当下主流的机器学习建模都默认训练集与测试集来自同一分布。在这个大前提下，监督学习往往依赖光滑性这一基本先验，而半监督学习把这一先验做了泛化，核心直觉都指向同一句话：相近的样本应该得到相近的输出。下面是业界最常引用的几类半监督先验。

- 1) 平滑假设：在数据密集的区域里，彼此靠得很近的两个样例大概率拥有相同的类别标签；也就是被稠密区域连起来的点倾向同类，反之被稀疏区域隔开的点更容易分属不同类别。

- 2) 聚类假设：数据内部存在簇结构，同一簇里的样本点共享同一标记类型，可认为每个簇对应一个类别。

- 3) 流型假设：数据实际分布在低维流形上，流形上邻近的样本输出值也相近。邻近程度常用相似度来刻画，该假设比聚类假设覆盖面更广，能适配更多学习任务。

## 11.1 未标记数据的价值

未标记样本本身不携带标签，却蕴含着关于数据分布的丰富信息。只要它们与有标记样本独立同分布地来自同一来源，就能为模型提供分布层面的支撑。如图 11-1 所示，若仅有标记样本，位于正负实例中间的点看起来就像随机猜测。一旦观察到周边的未标记样本，利用聚类假设就能把待预测点与正例通过未标记点的“搭桥”聚在一起，从而相对远离的反例做出正例判断。

[PRE0]

为便于理解半监督思想，用一个苹果园的例子说明。丰收季时满园都是苹果，果农挑出几个说这是好果子，又指着树上五六个说还没熟需要再长几天。基于这点信息能否判断园里哪些苹果可以采？可以把果农确认的好果子和不好的果子当成正反例训练分类器，但仅靠十来个样本显然不足，能否把树上那些未检查的果子也利用起来？

形式化地，设有标记集 $D_l = \{(x_1, y_1), (x_2, y_2), \cdots, (x_l, y_l)\}$，其类别标记已知，称为有标记样本；另有未标记集 $D_u = \{(x_{l+1}, y_{l+1}), (x_{l+2}, y_{l+2}), \cdots, (x_{l+u}, y_{l+u})\}$，类别未知。若只用传统监督方法，只有 $D_l$ 能建模，$D_u$ 的信息被浪费。一个粗暴做法是把 $D_u$ 全部人工标注后再训练，等同于让果农把树上所有果子逐一检查，成本极高。

更有效的做法是用 $D_l$ 先训练一个初步模型，去园里挑一个果子请果农确认好坏，把新获得的有标记样本加入 $D_l$ 重新训练，再继续挑果子。若每次挑选对模型改善帮助最大，只需少量询问就能得到较强模型，大幅降低标注成本。

## 11.2 半监督学习方法

如图 11-2 所示，半监督学习可区分为纯半监督学习和直推学习。纯半监督假定训练样本并非封闭，学好的模型要推广到训练时未见的数据；直推学习则假设学习过程中看到的未标记样本就是最终要预测的对象，目标是在这批未标记样本上获得最优泛化。换言之，前者面向开放世界，后者面向封闭世界。常见算法可归为以下几类。

[PRE1]

图 11-2 纯半监督学习和直推学习

### 1. 自训练算法 (self-training algorithm)

这是最早提出且最直观的半监督方法。先用少量有标记数据训练分类器，再用该分类器对未标记样本打标，按置信度挑选认为可信的样本加入训练集，迭代更新模型。

### 2. 多视角算法 (multi-view algorithm)

适用于特征可自然拆分为多个视角的数据。对每个样本提供两个或多个特征视图，利用协同训练让不同视图的学习器相互为未标记样本标注，高置信度的标注用于更新各自模型，隐式依赖聚类假设。

### 3. 生成模型 (generative models)

把未标记样本每类出现的概率视作缺失参数，采用期望最大化算法交替估计标签和模型参数。该思路本质是在少量有标记样本周围做聚类，属于早期直接利用聚类假设的做法。模型会估计不可观测样本属于各类的概率，并通过 EM 求解参数，常配合多重初始化或分裂合并策略寻找较优解。

### 4. 转导 SVM（transductive SVM）

传统归纳先总结一般规则再预测新样本，转导则是从特殊到特殊的直接推理。转导 SVM 是一种广义线性分类器，决策边界为最大间隔超平面，它在有监督基础上直接利用未标记样本的分布信息进行划分。

### 5. 基于图的算法（graph-based algorithms）

这类方法建立在图正则化框架上，直接或间接利用流型假设。先依据训练样本的相似度构建图，节点对应样本，边表示相似度，再以图上决策函数光滑性为正则项优化模型参数。

> 生成模型与判别模型的区别简述如下。①判别模型只关心类别间的决策边界，生成模型关注类别本身的分布；②判别模型给出分类结果却难以刻画生成过程，生成模型可模拟数据如何产生；③生成模型可以推导出判别模型，反之不可；④判别模型估计条件概率分布，生成模型估计联合概率分布。

### 11.2.1 生成式方法

生成式方法先对联合分布 $P(x,c)$ 建模，再推导出 $P(c|x)$。它假设所有数据无论是否标记都由同一潜在模型生成，从而借助潜在参数提升估计效果。

其中，

p(Θ=i|x)= α_i p(x|u_i, Σ_i) / Σ_{i=1}^{N} α_i p(x|u_i, Σ_i)

(11-3)

式（11-3）为样本 $x$ 由第 $i$ 个高斯混合成分生成的后验概率，$p(y=j|Θ=i,x)$ 为其类别为 $j$ 的概率。在每个类别对应一个成分的假设下，$p(y=j|Θ=i,x)$ 简化为 $p(y=j|Θ=i)$，且 $p(y=j|Θ=i)=1$ 当且仅当 $i=j$，否则为 0。

未标记数据如何提升性能？式（11-2）中 $p(y=j|Θ=i,x)$ 需要标签，只能用有标记数据估计；而 $p(Θ=i|x)$ 不依赖标签，有标记和未标记数据均可利用。大量的未标记样本能让该项估计更精确，从而改善整体预测。

对于有标记集 $D_l = \{(x1,y1),(x2,y2),…,(xl,yl)\}$ 和未标记集 $D_u = \{(x_{l+1},y_{l+1}),(x_{l+2},y_{l+2}),…,(x_{l+u},y_{l+u})\}$，假设所有样本独立同分布且由同一高斯混合模型生成，用极大似然估计参数 $\{(\alpha_i,u_i,\Sigma_i) | 1≤i≤N\}$，$D_l ∪ D_u$ 的对数似然为

LL(D_l ∪ D_u)= Σ_{(x_j,y_j)∈D_l} ln{ Σ_{i=1}^{N} α_i p(x_j|u_i, Σ_i) p_j(y_j|Θ=i,x_j) } + Σ_{x_j∈D_u} ln( Σ_{i=1}^{N} α_i p(x_j|u_i, Σ_i) )

(11-4)

式（11-4）由有监督项和无监督项组成。高斯混合参数可用 EM 算法迭代求解，收敛后结合式（11-2）和式（11-3）即可分类。

> 生成式方法实现简单，在有标记数据极少时往往表现不错。但其前提是模型假设必须准确，假设的生成模型要与真实分布吻合，否则引入未标记数据反而会拖累泛化。没有可靠的领域知识时，很难事先做出准确假设。

### 11.2.2 半监督 SVM

半监督支持向量机 S3VM 是 SVM 在半监督场景下的推广。不考虑未标记样本时，SVM 寻找最大间隔划分超平面；加入未标记样本后，S3VM 试图让超平面既能分开有标记的正反例，又能穿过低密度区域，如图 11-3 所示，其中“+”“-”为有标记正反例，蓝色点为未标记样本。

在纯监督情形下，目标是最大化两类间距。S3VM 在此基础上考虑未标记样本对边界位置的约束，先用标记数据训练初始 SVM，再对未标记样本进行伪标记并迭代优化，直至稳定。

[PRE3]

根据决策边界公式有

$\boldsymbol{\theta}^T x + b = 0$  (11-5)

支持向量到决策边界的距离公式为

$d = \frac{|y_i|}{\|\boldsymbol{\theta}\|}$  (11-6)

假设决策边界 $\boldsymbol{\theta}^T x + b = 0$ 能将样本正确分类，那么：

$\begin{cases} \boldsymbol{\theta}^T x + b \ge +1 & y_i = +1 \\ \boldsymbol{\theta}^T x + b \le -1 & y_i = -1 \end{cases}$  (11-7)

所以我们最大化间距的表达式可以写成

$\begin{cases} \max \frac{2}{\|\boldsymbol{\theta}\|} \\ \text{s.t.} \quad y_i(\boldsymbol{\theta}^T x + b) \ge 1 \end{cases}$  (11-8)

对式（11-8）使用拉格朗日乘子法，得到公式为

$L(\theta, b, a) = \frac{1}{2}\|\boldsymbol{\theta}\|^2 + \sum_{i=1}^{m} a_i(1 - y_i(\boldsymbol{\theta}^T x_i + b))$  (11-9)

对 $\theta$ 求偏导得

$\boldsymbol{\theta} = \sum_{i=1}^{m} a_i y_i x_i$  (11-10)

对 $b$ 求偏导得

$b = \sum_{i=1}^{m} a_i y_i$  (11-11)

代入得

$\begin{cases} \max \sum_{i=1}^{m} a_i - \frac{1}{2} \sum_{i=1}^{m} \sum_{j=1}^{m} a_i a_j y_i y_j x_i^T x_j \\ \text{s.t.} \sum_{i=1}^{m} a_i y_i = 0 \end{cases}$  (11-12)
