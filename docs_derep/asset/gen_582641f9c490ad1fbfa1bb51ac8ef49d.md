# 11 文本序列与循环神经网络精讲

## 11.1 文本序列的数值化
从上面看，序列的表达并不复杂，一个形状为`[b，s]`的张量就能搞定，其中 b 是序列条数，s 是序列长度。但很多信号不能直接用标量表示，比如每个时间步产生一个长度为 n 的特征向量，这时就需要形状为`[b，s，n]`的张量来容纳。文本就更复杂：句子在每个时间步上出现的是词或字符，并非数值。神经网络的本质是矩阵乘加运算，无法直接消费字符串。若想让神经网络用在自然语言处理上，把词或字符映射为数值就变得至关重要。下面重点讨论文本序列的表示思路，其他非数值信号也可以类推。

[PRE1]

图 11.1 地名 One-hot 编码示例

对包含 n 个词的句子，比较朴素的做法是 One-hot 编码。以英文为例，若只保留最常见的 1 万个词，每个词就对应一个长度 1 万、仅一位为 1 其余为 0 的稀疏向量；中文若取最常用的 5000 个汉字，同样可以用长度 5000 的 One-hot 向量表示。如图 11.1 所示，仅考虑 n 个地名时，可把每个地名编码为长度 n 的 One-hot 向量。

把文字转为数值的过程叫 Word Embedding。One-hot 实现起来直观，不需要训练，但向量维度高且极度稀疏，计算负担大，也不利训练。从语义上看，One-hot 更忽略了词与词之间的先天关联。比如 like 与 dislike 在语义上高度相关，都关乎喜好程度；Rome 与 Paris 也是强相关，都代表欧洲城市。用 One-hot 表示后，这些关联在向量空间里完全丢失，这正是其明显缺陷。

在 NLP 里，有专门的研究在学习词向量 WordVector，让语义相关性能够在向量上体现。衡量两个词向量相关度常用余弦相似度 Cosine similarity：

### 11.1.1 Embedding 层
在网络内部，词的表示向量可以直接通过训练获得，这一层称为 Embedding 层。它接收的是数字形式 having 的词编号 i，比如 2 代表 I，3 代表 me，词表总量记为 N[vocab]，输出长度为 n 的向量 υ：

`υ = fθ`

实现非常简单，维护一个形状为`[N[vocab]，n]`的查询表 table，给定编号 i 直接返回对应行向量：

`υ = table[i]`

Embedding 层是可以学习的，可以放在网络前端完成词到向量的转换，后续的网络在此基础上继续计算并产生误差[PRE4]，借助梯度下降实现端到端 end-to-end 训练。

## 11.2 循环神经网络
现在看如何处理序列信号，仍以文本序列为例，设有一个句子：

"Ihatethisboringmovie"

经 Embedding 层后得到形状为`[b，s，n]`的张量，b 为句子数，s 为句子长度，n 为词向量维度。上述例子可表示为形状`[1，5，10]`的张量，5 为词数，10 为向量维。

下面逐步探索适合序列的网络模型，以情感分类任务为例，如图 11.3 所示。任务是分析文本序列，提炼整体语义特征，预测正面或负面情感。从分类角度看是二分类问题，与图像分类不同，输入是序列，传统卷积网络效果有限。哪类网络更擅长处理序列？

### 11.2.1 全连接可行吗
最直接的想法是对每个词向量分别用一个全连接层网络

[PRE10]

图 11.3 情感分类任务

`o = σ(W[t]x[t] + b[t])`

提取特征，如图 11.4 所示，s 个词向量依次经过 s 个全连接分类子网提取词级特征，再合并后通过分类器 2 输出序列类别概率。对长度为 s 的句子，至少需要 s 个网络层。

[PRE11]

图 11.4 方案一示意

该方案的不足有两点：

□ 参数量非常大，内存和计算成本高，且序列长度 s 变化时网络结构也随之变化。
□ 每个子网 W[i]、b[i] 只能看到当前词向量，感知不到前后语境，句子整体语义丢失，相当于管中窥豹。

接下来逐一解决这两个问题。

### 11.2.2 权值共享
在卷积网络中，权值共享大幅减少参数、提升效率。序列处理能否借鉴这一思想？

图 11.4 的 s 个全连接层并未共享参数。若让它们参数共享，实质是用同一个全连接网络处理所有词向量，如图 11.5 所示。

[PRE12]

图 11.5 方案二示意

共享后参数量骤减，训练更稳定高效。但网络仍忽略时序顺序，打乱词向量顺序输出不变，无法获得全局语义。

### 11.2.3 积累全局语义
怎样让网络按序提取词义并累积成句子的整体语义？可以引入内存机制。网络维护一个独立的内存变量，每步处理一个词向量并刷新内存，直至最后一个输入，内存即承载了整个序列的语义，且内容与输入顺序紧密相关。

把 Memory 实现为状态张量 h，如图 11.6 所示，在原有的 W[xh] 共享基础上增加 W[hh]，每步更新为：

`h[t] = σ(W[xh]x[t] + W[hh]h[t-1] + b)`

其中 h[0] 为初始内存，可设为全 0。经过 s 步输入后得到最终状态 h[s]，它较好地概括了句子的全局语义，再接一个全连接分类器即可完成情感分类。

[PRE13]

图 11.6 循环神经网络展开示意

### 11.2.4 循环神经网络原理
逐步探索后得到一种新型结构，如图 11.7 所示，在每个时间步 t，网络接收当前输入 x[t] 和上一时刻状态 h[t-1]，经

`h[t] = fθ`

变换得到新状态 h[t] 并写入内存，其中 f[θ] 为网络运算逻辑，θ 为参数集。每个时刻也产生输出 o[t]，`o[t] = gϕ`，即对状态做变换得到输出。

把网络在时间轴上展开如图 11.8，网络循环地接收序列各特征向量 x[t]，刷新内部状态 h[t] 并形成输出 o[t]。这种结构称为循环神经网络 Recurrent Neural Network，RNN。

[PRE14]

图 11.7 展开的 RNN 模型

[PRE15]

图 11.8 折叠的 RNN 模型

特别地，若用张量 W[xh]、W[hh] 和偏置 b 参数化 f[θ]，并按

`h[t] = σ(W[xh]x[t] + W[hh]h[t-1] + b)`

更新内存，就得到基础循环神经网络。不特别说明时，循环神经网络即指此实现。激活函数常选 tanh，也可以去掉偏置 b 以减参数。状态 h[t] 可直接作为输出 o[t] = h[t]，也可线性变换 o[t] = W[ho]h[t] 后输出。

## 11.4 RNN 层使用方法
了解原理后看 TensorFlow 中的实现。可用`layers.SimpleRNNCell`完成`σ(W[xh]x[t] + W[hh]h[t-1] + b)` 的单步计算。注意 TensorFlow 中 RNN 指广义循环神经网络，基础实现通常称为 SimpleRNN。SimpleRNNCell 只完成一个时间步的前向，不带 Cell 的 SimpleRNN 则在内部完成了多步循环，使用更方便。

### 11.4.2 多层 SimpleRNNCell 网络
和卷积网络类似，循环神经网络在时间轴上展开多次仍算一层。通过在深度方向堆叠多个 Cell 可提升表达能力。但循环网络易出现梯度消失与爆炸，深层训练困难，常见模型层数一般控制在十层以内。
