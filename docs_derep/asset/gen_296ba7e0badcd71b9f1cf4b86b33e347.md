#### 9.2.2 NextChat 接入 DeepSeek

NextChat 是个开源项目，帮助用户把 ChatGPT 等大模型集成到 Web 应用。主要能力包括：

- 模型集成：通过 OpenAI 密钥接入 ChatGPT，内置多种场景提示，支持文案创作、创意写作乃至图像检索。

- 多模型支持：可按需切换不同大模型。

- Markdown 编辑：提供完整 Markdown 支持。
- 隐私本地化：数据保存在浏览器本地。

- 内置中英文 Prompt 库：开箱即用。
