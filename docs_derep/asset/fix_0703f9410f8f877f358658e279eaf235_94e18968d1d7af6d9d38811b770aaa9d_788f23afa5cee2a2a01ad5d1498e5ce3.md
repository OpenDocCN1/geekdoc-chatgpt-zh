问题：中国法律中，“著作权”包括哪些内容？

回答：中国法律中，“著作权”包括以下内容：

1. 文学作品，如小说、诗歌、戏剧、散文等；

2. 艺术作品，如绘画、雕塑、摄影、电影等；

3. 科学技术作品，如科技论文、计算机软件等；

4. 工程设计图纸、产品设计图纸等；

5. 民族传统文化的表现形式，如歌曲、舞蹈、戏曲等。

此外，著作权也包括与作品相关的权利，如署名权、修改权、发表权、复制权、发行权、展览权、表演权等。
