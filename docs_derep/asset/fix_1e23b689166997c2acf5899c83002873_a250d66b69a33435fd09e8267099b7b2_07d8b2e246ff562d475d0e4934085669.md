### 4.1.1 减脂营养师：智能饮食规划助手

“又是外卖。”小美看着桌上的快餐盒叹气。作为一名朝九晚六的上班族，她想瘦身却总坚持不下来。网上的食谱要么太繁琐，要么与自身口味冲突。“如果能有一个懂我又专业的顾问就好了。”类似困扰在都市人群中很普遍，大家都在找一个简单可行的减脂方案。

借助 Vibe 编程，约半小时就能搭建一个减脂营养师。它会结合身体状况与饮食偏好，给出可执行的高质量食谱建议。

#### 1. 需求拆解与场景构想

减脂不是单纯的数字博弈，而是一场习惯重塑。用户需要的不是卡路里计算器，而是一个能理解生活方式与口味偏好，并给出落地建议的智能伙伴。

#### 2. MVP 提炼与优化

将 DeepSeek 的初版结果精简后，得到以下 MVP 定稿。

##### MVP 描述：减脂营养师

###### **1. 典型用户画像**

时间紧张、缺乏专业知识的白领，想科学控脂，需要简洁个性化的饮食指导。

###### **2. 场景故事**

30 岁办公室职员小王 BMI 超标，他打开应用录入基础信息和口味偏好，立刻拿到专属减脂餐单，并可一键生成采购清单。

###### **3. 功能清单（MVP 核心）**

- **用户信息录入**：性别、年龄、身高、体重、目标体重、运动活跃度
- **饮食偏好选择**：忌口如素食/无乳糖，口味如中式/西式等
- **生成每日减脂食谱**：基于数据与偏好推荐三餐加加餐
- **一键生成购物清单**：汇总食谱食材，支持导出或分享

###### **4. 交互路径**

1. **启动页**：简洁 Slogan 如“3 步定制你的减脂食谱”+ 立即开始按钮
2. **信息输入页**：
   - 分步填写：①基础数据；②饮食偏好，多选勾选
   - 全程禁用自由输入，采用滑块或单选/多选
3. **食谱展示页**：直接呈现图文今日推荐，底部“生成购物清单”按钮
4. **清单页**：食材及分量列表，支持复制文本或分享到微信

##### **关键设计原则**

- **极简输入**：杜绝手动打字，全靠选项与滑块
- **零学习成本**：从打开到出餐单不超过 3 步
- **不做功能**：社交、打卡、运动记录、付费课程等均不纳入

#### 4. 编写 System 提示词

System 提示词决定 AI 的角色、边界、行为与输出方式，包含角色定位、工作范围、行为准则、输出格式四部分。

以减脂营养师为例：

- 角色定位：专业减脂营养师
- 工作范围：依据身体数据与饮食偏好生成每日食谱及食材清单，且不推荐忌口食材、繁复烹饪与模糊分量
- 行为准则：以科学为先，严格遵循用户偏好
- 输出格式：早餐、午餐食谱及对应购物清单

根据 MVP 功能描述，生成用于食谱生成的 System 提示词

DeepSeek 给出的 System 提示词如下。

##### **System 提示词 for AI Dietitian**

**Role**:

你是一名专业的减脂营养师，根据用户提供的身体数据（BMI、目标体重）和饮食偏好（忌口、口味、烹饪时间），生成**简单、可执行、热量可控**的每日食谱，并附带清晰的食材清单。

**Rules**:

1. **科学优先**
   - 每日总热量 = 用户基础代谢 × 活动系数 -300～500kcal（安全减脂缺口）
   - 营养素分配：蛋白质30% / 脂肪25% / 碳水45%
   - 食材选择：高饱腹感（燕麦、鸡胸肉）、低GI（糙米、西蓝花）

2. **严格遵循用户偏好**
   - 若用户选择“素食”，禁用所有肉类，用豆类/藜麦替代蛋白质
   - 若用户选择“中式”，避免生冷沙拉，推荐蒸煮炒等烹饪方式

3. **输出格式标准化**

###### 早餐

- [菜名]: [食材+分量]（如：燕麦粥：燕麦50g+牛奶200ml）
- **热量**: XXX kcal

###### 午餐（示例）

- 糙米饭：糙米80g
- 清蒸鱼：鲈鱼100g+姜片
- **总热量**：XXX kcal

###### 购物清单

- 燕麦 50g
- 鲈鱼 100g

4. **禁止行为**
   - 推荐用户忌口的食材（如用户选择“无乳糖”时禁用牛奶）
   - 复杂的烹饪步骤（单菜烹饪时间≤20分钟）
   - 模糊分量（必须标注克数/毫升数）

实际使用中可能遇到三个细节问题：

- 食材非当季，可在偏好中增加“季节性食材”选项，让模型优先推荐当季品类

#### 6. 进阶优化方向

减脂营养师的迭代可围绕四点展开：

- 智能调优：根据用户反馈自动优化推荐，分析饮食习惯动态调整热量与营养配比
- 社区互动：支持经验分享、食谱改良讨论、线上减重打卡
- 数据洞察：追踪减重进度，关联饮食模式与效果，生成个性化报告
- 场景化推荐：按天气推荐适配餐单，针对聚餐等特殊场合给出建议，并提供外出就餐菜品挑选指引

好的产品不是堆功能，而是精准理解需求。像一位贴心的私人营养师，既专业又灵活，在享受美食的同时帮助用户达成健康目标。

借助 Vibe 编程，半小时即可搭建一个专业的呼吸练习助手，依需求切换不同呼吸模式进行引导。

##### MVP 描述：呼吸练习

###### **1. 典型用户画像**

压力大、易焦虑的都市白领，希望用简单呼吸练习快速放松身心。

###### **2. 场景故事**

午休时用户焦虑难以集中，打开应用选择 5 分钟“减压模式”，跟随动画节奏呼吸，迅速恢复平静。

###### **3. 功能列表（MVP 核心功能）**

- **呼吸模式选择**（单选）：
  - 减压模式（4-7-8 呼吸法）
  - 专注模式（箱式呼吸法）
- **时长选择**（单选）：3分钟 / 5分钟 / 10分钟
- **呼吸动画引导**：可视化图形如圆圈缩放，与呼吸节奏同步，开始倒计时播放对应动画
- **结束提醒**：轻柔提示音 + 总结如“完成 5 分钟减压呼吸”

###### **4. 交互流程**

1. **启动页**：App 名称 + 简短标语“轻松呼吸，快速平静”
2. **模式选择页**：两个模式按钮减压/专注 → 进入时长选择
3. **时长选择页**：3 个按钮 3/5/10 分钟 → 直接开始练习
4. **练习页**：动画引导吸气→屏气→呼气 + 实时进度条
5. **结束页**：显示“完成！”+ 时长总结，自动返回模式选择页

**边界说明（不做的功能）**：

- 用户账号系统
- 复杂数据统计
- 自定义呼吸节奏
- 背景音乐选择

#### 3. 动画实现思路

动画是呼吸类应用的核心，不仅要美观，更要精准引导呼吸节奏，如同一位无声教练。

最终选用的方案：

采用 CSS 动画 + requestAnimationFrame 控制

4-7-8 呼吸法动画：圆圈匀速放大 4 秒（吸气）→ 静止保持 7 秒（屏息）→ 匀速缩小 8 秒（呼气），循环至练习结束。

箱式呼吸法动画：圆圈匀速放大（吸气 4 秒）→ 保持静止（屏息 4 秒）→ 匀速缩小（呼气 4 秒）→ 保持静止（屏息 4 秒），形成稳定矩形节奏循环至练习结束。
