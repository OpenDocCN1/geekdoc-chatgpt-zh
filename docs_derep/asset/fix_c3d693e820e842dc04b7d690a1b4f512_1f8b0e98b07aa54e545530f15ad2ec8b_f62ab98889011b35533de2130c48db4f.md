# 第二章
# 短视频提示词创作指南

在AI短视频制作中，提示词是引导模型产出预期内容的指挥棒。掌握编写技巧，有助于提升生成精度与效率。本章介绍提示词获取方法与写作要点。

2.1 AI短视频提示词获取思路
文生视频时，提示词决定创作方向；图生视频或视频生视频时，提示词辅助动态效果生成。创作者可通过哪些渠道获取提示词？本节介绍五种方式。

2.1.1 按需撰写原创提示词
[PRE23]
2.1.1 按需撰写原创提示词
生成AI短视频时，提示词直接影响成片质量，需兼顾画面细节、逻辑连贯与情感表达。
按需编写是指根据视频主题、风格、受众及想传达的信息，有针对性地撰写与内容高度相关的提示词，作为模型生成的重要参考，帮助其准确呈现视觉效果与故事脉络。
之所以强调按需，是因为每个作品都有独特主题与风格，模型虽强仍需明确指引。通过提示词，创作者能清晰表达意图，确保内容围绕主题展开并符合受众审美。
可针对不同主题风格撰写差异化提示词，满足多样化需求，同时提升情感表达与意境。
以“江边的一片油菜花海，唯美，浪漫，高清，意境美”为例，具体拆解如下。
（1）江边：明确场景，指引模型将背景设定为江边自然环境，营造宁静悠远氛围。
（2）一片油菜花海：描述核心主体，即盛开的油菜花，突出生机与广阔，增强冲击力。
（3）唯美：强调审美风格，要求注重画面美感与情感呈现，营造温馨优雅氛围。
（4）浪漫：进一步明确情感基调，要求营造浪漫氛围与共鸣。
（5）高清：强调画质，要求画面清晰细腻。
（6）意境美：总结升华，要求营造深远意境，让观众获得超越画面的审美体验。
基于该组提示词，模型可生成以江边油菜花海为核心、充满唯美浪漫气质的高清短片，通过细腻镜头与情感表达带入诗意世界，效果如图2-1所示。

2.1.2 借助AI插件生成提示词
