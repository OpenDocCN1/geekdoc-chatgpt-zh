# RAG 最小实践：为生成器加检索记忆

大型文本输出系统在组织表达上很顺手，却常在需要精确事实或保持多轮连贯时出现漂移。核心思路是先把外部资料转成向量表征，再按问题语义的邻近度挑选最贴合的片段作为提示补充，让最终输出既能溯源也更对题。下面给出一条可直接复现的流程：句向量采用 BERT 的均值汇聚，排序靠余弦相似，输出环节调用 transformers 的 pipeline。

**向量化模块**

选用一个开源编码器作为起锚，文本通过分词后取最后隐藏层的均值作为句级表征，运行环境自动在 cuda 与 cpu 间切换。
