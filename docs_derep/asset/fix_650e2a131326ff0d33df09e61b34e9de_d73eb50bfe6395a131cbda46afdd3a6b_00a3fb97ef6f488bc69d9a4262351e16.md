# 第二章

## 2.1 提问六维：从思维到成长
提问既是思维的催化剂，也是打开智慧的钥匙。以下从六个关键维度解析提问的力量。

1.打破思维局限
思维易受习惯与传统束缚，有时反而阻碍成长。社会化思维虽有助于适应环境，但过度依赖会导向僵化。学会提出假设性问题，如“如果这样/那样会怎样”，能跳出束缚。再追问“假设建立在何种前提”“存在哪些例外”，可看到多层面问题并识别偏见。保持“观察者”视角，用“有效或无效”替代“好或不好”的评判，潜能才能被激发。

2.明确目标
学习、工作或生活中迷茫时，针对性提问能厘清方向。可先问“我真正追求什么”，再问“实现途径有哪些”“可利用哪些外部资源”。这样目标更清晰，路径也更明确。

3.深化认知
感觉已懂概念，运用时却发现理解肤浅。此时追问“为什么是这样”“如果不是这样会怎样”很重要。深化不仅在知识，也在情感、价值观、人际关系。例如“为什么我喜欢这个人”“这段关系给我带来什么”，能帮助全面认识自我，做出更明智决策。

4.激发内在驱动力
持续提问保持敏感度，主动探索未知，保持热情。遇到困难时问“我能从中学习什么”“还有哪些解法”，既能找到突破口，也能保持乐观。

5.增强问题解决能力
提问帮助厘清思路、抓住核心。不断问“为什么”“怎么办”，能深入本质找到有效解法。面对复杂项目，可问“核心目标是什么”“潜在障碍有哪些”“如何克服”，多角度分析后方案更优。

6.促进自我反思与成长
提问是自我反思的工具。完成工作后问“哪些做得好”“哪些可改进”“下次如何更好”，能总结经验、持续提升。
总之，提问是激活认知潜能、做出更好决策的重要能力，值得长期练习。
