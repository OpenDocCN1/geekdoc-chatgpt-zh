# 技巧04 十大常用提示词模板

在与DeepSeek或其他大模型交互时，提示词的设计决定了结果质量。以下按不同场景归纳了十类高频模板，供学习借鉴。

## 1. 信息查询型
请用大白话说明[专业术语/概念]，需阐明核心含义，并举例其使用场景或对比易混淆概念。
示例：
请通俗解释机器学习里的“过拟合”，借助比喻呈现，并与“欠拟合”对比，同时提供一段实操代码。

## 2. 分析对比型
针对[场景]，从性能、适用性等方面对比[A]和[B]的差异，以表格呈现并给出推荐场景。
示例：
请用表格对比VBA与WPS JS在编程使用上的优劣差异。

## 3. 解决方案型
针对某具体难题，请给出分步解决办法。
示例：
请说明如何排查Android应用内存泄漏，并提供LeakCanary配置指南及Heap Dump分析方法。

## 4. 创意生成型
以[主题/关键词]为基础，产出[数量]份创意方案，需明确适用人群/场景或必备元素。
示例：
为书籍《DeepSeek实战技巧精粹》设计五个封面创意，需融入AI技术与职场生活元素。

## 5. 数据处理型
对以下数据进行清洗或分析：[数据片段]，需指出数据质量问题、给出处理代码或可视化建议。
示例：
识别销售数据异常值，用箱线图呈现，并提供SQL修正查询语句。

## 6. 学习路径型
扮演[身份/水平]的角色，制定为期[时间周期]的[领域]学习路线。
示例：
身为Excel课程讲师，为零基础学员规划三个月的函数公式学习方案，涵盖动态数组公式内容。
