# 警钟敲响：DeepSeek 掀起 AI 军备竞赛

[PRE1]

2025年1月28日，刚完成连任的美国总统特朗普在接受采访时直接点名 DeepSeek 为美国产业的警报，称这家中国公司推出的模型应当让国内产业保持清醒，必须集中资源赢得竞争。DeepSeek 的出现，让美国科技圈迅速进入高度戒备。

一周前，2025年1月21日，特朗普宣布启动“星际之门”AI 基础设施投资计划，未来四年拟投入5000亿美元用于全新基建，意图确保美国在智能赛道的绝对领先。公开信息显示，该计划由 OpenAI、软银、甲骨文三方合资设立的“星际之门”公司执行，OpenAI 负责运营，软银负责资金，甲骨文提供关键基础设施。软银创始人孙正义出任董事长，首期资金已达1000亿美元，规划四年内扩大至5000亿美元。项目拟建设20座超大规模算力中心，并在美国创造超过10万个就业岗位。

在国家层面布局之外，以谷歌、亚马逊、Meta、微软为首的巨头早已行动。仅2024年第二季度，这四家的资本性开支合计达528亿美元，同比2023年同期增长近六成。亚马逊财务负责人布莱恩·奥尔萨夫斯基表示，大部分支出用于满足 AWS 基础设施的持续增长需求，因为生成式与非生成式工作负载需求强劲。Meta 财务负责人李苏珊称，2025年资本支出预计大幅提升，以支撑 AI 研究和产品开发。微软财务负责人艾米·胡德则表示，为应对 AI 与云产品需求，将扩大基础设施投资，2025财年资本支出预计高于2024财年。

## 美企掀起巨额投入潮

重金押注并非新事。自2022年底 ChatGPT 引发技术革命以来，全球资本始终在谨慎评估落地周期与激进抢占制高点之间摇摆。

ChatGPT 上线刺痛了巨头神经。2022年11月30日晚，谷歌总部灯火通明，联合创始人拉里·佩奇等被紧急召回。他们意识到，由自家2017年提出的 Transformer 结构驱动的模型，可能终结搜索时代。随后谷歌仓促推出 Bard。

2023年2月6日，谷歌在巴黎发布会上正式推出聊天机器人 Bard，对标 ChatGPT。但首秀因一次关键失误引发震荡，Bard 在介绍詹姆斯·韦伯太空望远镜成果时称其拍摄到首张系外行星照片，实为欧洲南方天文台甚大望远镜2004年的成果。该错误被天体物理学家格兰特·特伦布莱等公开质疑，Alphabet 股价当天暴跌7.7%，市值蒸发超1000亿美元，创2022年10月以来最大单日跌幅。

挫败后谷歌以技术纵深加生态重构展开高强度布局。技术迭代上，2023年5月 Bard 迁移至 PaLM 2 模型，错误率显著下降并实现更高效的事实核查与实时检索。2024年12月 Gemini 2.0 发布，支持文本、图像、音频、视频混合输入输出，可处理令牌数提升至200万，推理能力大幅提升。2025年推出的 Gemini 2.0 Flash-Lite 在端侧运行与成本效率上取得突破。

硬件层面，TPU v5e 芯片量产以更低成本提供更强算力，满足内部需求。与英伟达合作的 A3 虚拟机将推理成本降低40%，提升实时响应。

资本运作上，谷歌2025年 AI 资本支出大幅增长并拟新建20座超大算力中心。2025年3月宣布拟以320亿美元收购云安全公司 Wiz，加强多云安全竞争力，并加大量子计算投入，目标2026年实现量子计算 AI 模型的商用。

为对抗 OpenAI 与微软联盟，谷歌大手笔扶持 Anthropic，上演 AI 版合纵连横。Anthropic 由 OpenAI 前核心成员达里奥·阿莫迪与丹妮拉·阿莫迪兄妹于2021年在旧金山创立，专注 AI 系统安全性与可控性。DeepSeek 浮现前，其 Claude 大模型被视作最有希望超越 OpenAI 的编程模型。

技术上，2025年2月发布的 Claude 3.7 Sonnet 采用混合推理架构，具备跨模态处理能力，借助 Claude Code 工具链强化代码生成专业性。其主导开发的模型上下文协议 MCP 已成为行业开源标准，被 OpenAI 等采用，实现跨平台数据源与 AI 系统双向连接。

谷歌持有 Anthropic 14% 股份，并计划2025年度通过可转换债券再注资7.5亿美元，若兑现总投资将超30亿美元。更大的金主是亚马逊，截至2025年4月已承诺投资80亿美元。

亚马逊的布局远不止于此。作为老牌云厂商，其渴望成为 AI 领域的“卖铲人”，战略是通过全面投入 AI 为各规模企业提供稳定低成本算力，完成从传统云向智算云转型。2023年4月13日推出的 Amazon Bedrock 平台让用户可通过 API 访问 AI21 Labs、Anthropic、Stability AI 及自家模型，瞄准企业客户，打造不依赖单一初创公司的中立平台。

芯片自研上，亚马逊构建 Graviton CPU、Trainium 训练芯片、Inferentia 推理芯片的三位一体架构，重构通用算力底座、突破训练瓶颈、降低推理成本，形成全栈生态。2024年底集中发布六款 Nova 系列大模型，覆盖文本生成、多模态、图像与视频生成。

Meta 早在2013年成立 FAIR 研究院，聚焦计算机视觉与自然语言处理并推出 DeepSpeech。2017年 Transformer 提出后迅速跟进，2018年推出基于 Transformer 的创新模型。2023年2月24日发布 Llama 1，提供开放生成式 AI 平台，参数从7B 增至65B，在低资源语言任务中表现突出。随后 Llama 2、Llama 3 持续开源，意图复制 Linux 模式。

Meta 推动开源生态，PyTorch 深度学习框架成为全球研究与商业实践工具，还深化 AI 伦理、安全与透明度合作。

微软在这轮竞争中位置有利。2019年首投 OpenAI 10亿美元并成为其独家云服务商，2023年追加100亿美元，累计获49% 利润分成权及董事会观察员席位。2025年软银以75亿美元领投 OpenAI 新一轮融资，估值飙至3000亿美元，微软持股稀释至约45%。

投资换来 OpenAI 技术独家授权，整合至 Bing 与 Copilot，尤其 GPT-3 与 Bing 结合强化搜索能力。自主技术上，2020年推出170亿参数的 Turing-NLG；DeepSpeed 优化库提供分布式训练、内存优化与模型压缩；Azure 云平台提供认知服务与自定义模型训练部署能力。

马斯克是绕不开的关键人物。曾是 OpenAI 创立阶段的投资人，后与奥特曼分道扬镳。2025年3月宣布旗下 xAI 以330亿美元收购 X 平台，意图整合海量用户数据与分发渠道构建数据驱动 AI 闭环。截至2025年4月 X 累计上万亿条推文，日增5亿条。

特斯拉自动驾驶每天通过车载摄像头处理1600亿帧视频画面，马斯克认为这是打造实体机器人所需的现实世界导航数据。xAI 于2023年7月成立，半年内发布 Grok-1，参数3140亿超 GPT-3.5。成立16个月估值突破500亿美元。

2024年仅用100多天在田纳西州建成 Colossus 超级计算机，集成十万片英伟达 H100 后扩至二十万片。2025年2月 Grok-3 发布，引入图像分析与问答，基于约20万 GPU 数据中心训练，算力为 Grok-2 的10倍，被马斯克称作“地球上最聪明、最求真的人工智能”。

xAI 优势在于可获取马斯克旗下企业专有数据，以及更激进的内容策略：Grok 仅过滤色情内容，允许政治敏感信息生成，截至2024年11月付费用户达64万。

总体看，美企动辄百亿美元投入覆盖芯片、模型研发、资本并购、生态联盟与开源战略，将竞争推向算力、数据、场景的全维度争夺。

## 中国走效率与场景并重的路线

中国作为世界第二算力大国，其 AI 产业同样蓬勃。与美国做法不同，中国企业在政策引导与市场需求驱动下走出“开源共享加场景深耕”路径。

技术路线上，美国企业倾向不计成本追求规模，如 OpenAI 研发 GPT-5 万亿级参数架构、微软 Sora 实现文生视频。中国企业更重效率优化，通过模型压缩、异构算力调度在算力受限条件下突破性能。

应用落地强调场景为王。百度依托搜索优势将文心一言嵌入生态，日均调用超百亿次；阿里巴巴通义千问以“工具箱”拆解为文档解析、视频生成等细分工具；字节跳动借助抖音、今日头条流量矩阵将豆包模型渗透至3000万用户，实现规模化应用，使 AI 在电商、物流、城市管理等领域形成独特优势。

百度布局早于业界。文心一言 4.0 Turbo 支持128K 上下文窗口，可处理300页文档级长文本，在代码生成与多模态交互表现突出。依托 Apollo 自动驾驶平台与飞桨深度学习框架，构建模型训练—场景应用—数据反哺闭环。

技术突破源于知识增强探索。早期 ERNIE 系列并行训练海量文本与知识图谱，中文理解超越谷歌模型 BERT。2021年发布的鹏城—百度·文心 ERNIE 3.0 Titan 以2600亿参数成为当年全球最大中文单体模型，首创在线蒸馏框架显著降低落地成本。2023年文心一言整合检索增强与对话增强技术，实现多轮流畅交互，在文学创作与代码生成展现领先能力。
