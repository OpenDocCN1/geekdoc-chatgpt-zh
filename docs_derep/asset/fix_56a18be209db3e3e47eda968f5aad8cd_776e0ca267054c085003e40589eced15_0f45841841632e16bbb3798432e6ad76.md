局部线性嵌入认为一个样本可以在其局部邻域内用邻居的线性加权和来重建，这样降维后流形的几何特性能够得到较好的保留。实现上大致分三步：为每个点寻找 k 个最近邻，基于这些邻居求解局部重构权重，最后利用权重与邻居信息得到低维表示。该方法在理论上是自洽的，但在真实产线场景中的落地频率并不高。

#### 2.3.4 特征构造主要包括什么
特征构造要紧扣业务属性和数据本身的特性，去提炼可能产生增益的新信号。这一步对效果提升很关键，书本上讲的很少，更多要靠项目实践积累。举三个常见例子。

预测商场未来销量时，周末与节假日这类时间属性往往是强信号，需要单独编码成特征。

在客户关系管理里，最近一次消费的间隔天数、消费频次、消费金额三项指标非常有用，如果原始表没有，就得从原始行为记录里计算出来。

在交通流量预测中，早晚高峰时段、道路宽度、红绿灯数量都是典型的有效特征。

### 2.4 过拟合、欠拟合与正则化
训练过程中很容易出现过拟合，典型现象是训练误差持续下降而验证误差开始上扬。训练初期模型还学得不够，拟合能力弱，偏差偏大。随着训练加深，模型慢慢学会了训练数据的扰动，拟合能力增强。继续训练后模型对训练集的细微波动都变得敏感，就产生了过拟合。

#### 2.4.1 过拟合与欠拟合的区别是什么，什么是正则化
欠拟合指模型在训练集上也难以获得足够低的误差，多半是特征维度不足导致表达能力不够。

过拟合指训练误差和泛化误差差距过大，训练集表现尚可，但在测试集和新数据上泛化能力差。

所有以降低测试误差为目标的手段都可归为正则化，代价通常是训练误差会有所上升。

#### 2.4.2 解决欠拟合的方法有哪些
降低欠拟合风险主要有三类做法。

- 1) 引入新特征，深度学习场景下可以借助因子分解机、子编码器等。
- 2) 提升模型复杂度，线性模型可加入高次项，深度模型可增加层数和神经元数量。
- 3) 放宽正则化强度，即减小正则项系数，从而增强学习能力。

#### 2.4.3 防止过拟合的方法主要有哪些
### 1. 正则化
常用的有 L₁ 正则化、L₂ 正则化与混合形式。

L₁ 正则化的目标是让参数绝对值之和变小，定义为：
‖x‖₁ = Σᵢ |xᵢ|

L₂ 正则化的目标是让参数平方和变小，定义为：
‖x‖₂ = Σᵢ xᵢ²

混合 L₁ 与 L₂ 正则化的定义为： α‖x‖₁ + (1−α)/2 ‖x‖₂

坐标轴上，因此每一维的参数都不会是0。

由于 L1 会推动参数趋近于零，常用于特征选择。而实践中最常用的正则化是对权重施加 L2 约束。

L1 与 L2 的本质差异也体现在先验假设上：L1 可由权重 w 的拉普拉斯先验经最大后验估计导出，L2 可由权重 w 的高斯先验经最大后验估计导出。

后验概率函数是在似然函数上加上 logP(w)：
MAP=logP(y|X,w)P(w)=logP(y|X,w)+logP(w)

P(w) 表示对权重系数的先验分布假设，得到样本后可据 {X,y} 的后验概率对 w 进行修正。

假设 w_j ~ N(0, σ²)，则
log P(w)=log ∏_j p(w_j)=log ∏_j [1/√(2πσ) e^{-w_j²/(2σ²)}]= 1/(-2σ²) Σ_j w_j² + C
此时 logP(w) 等价于在代价函数中加入 L2 正则项。

假设 w_j 的先验为均值 0、参数 a 的拉普拉斯分布，即
P(w_j)=1/√(2a) e^{-|w_j|/a}
则
log P(w)=log ∏_j p(w_j)=log ∏_j [1/√(2a) e^{-|w_j|/a}]= -1/a Σ_j |w_j| + C
此时 logP(w) 等价于在代价函数中加入 L1 正则项。

### 2. Batch Normalization
Batch Normalization 是深度学习里一种降低泛化误差的正则化手段，主要通过缓解梯度消失来加快训练、抑制过拟合，并降低初始化敏感度。

训练集与测试集分布不一致会损害泛化能力，因此需要在训练前对输入做归一化。由于各隐藏层的参数不同，下一层输入的变化会导致每批数据的分布漂移，网络每次迭代都要适应不同的分布，增加训练难度和过拟合风险。

Batch Normalization 通过对分布施加额外约束来增强泛化，同时破坏了已学到的特征分布。为恢复最优输入分布，引入可学习重参数：
$y_k = BN(x_k) = \gamma \hat{x}_k + \beta = \gamma \frac{x_k - E[x_k]}{\sqrt{var[x_k] + \varepsilon}} + \beta$
其中 $\gamma$ 和 $\beta$ 为可训练参数。

### 3. Dropout 随机失活
Dropout 通过修改网络结构来防止过拟合，不改变损失函数，而是随机丢弃部分神经元以降低复杂度，在训练大模型时很有效。

具体流程是每次迭代随机舍弃一部分隐层单元，保持输入输出层不变并更新权重，下一次迭代再随机舍弃另一批单元，如此反复直至训练结束。

使用 Dropout 相当于训练了大量仅含部分隐层单元的子网络，每个子网络都能给出分类结果，随着训练进行大部分子网络都能给出正确输出。

### 4. 迭代截断
迭代截断即在模型尚未在训练集上完全收敛前提前停止，以避免过拟合。做法是在训练中记录目前最佳准确率，当连续 n 个 Epoch 未能刷新最佳准确率时就停止，n 常取 100、200 等。

### 5. K 折交叉验证
k-fold 交叉验证把训练样本划分为 k 份，进行 k 次训练验证循环，每次用其中一份作验证集，其余 k-1 份合并作训练集。每个样本会在一次实验中作为验证样本，在 k-1 次实验中作为训练样本。每次实验都用交叉验证过程决定在验证集上表现最佳的迭代次数并选择合适参数。

### 6. 常见面试笔试题
机器学习中L1正则化和L2正则化有什么区别（ ）。

- A. 使用L1可以得到平滑的权值，使用L2可以得到平滑的权值
- B. 使用L1可以得到稀疏的权值，使用L2可以得到平滑的权值
- C. 使用L1可以得到平滑的权值，使用L2可以得到稀疏的权值
- D. 使用L1可以得到稀疏的权值，使用L2可以得到稀疏的权值

分析：选（B）。L1 正则化偏向稀疏，会把部分特征对应的权重置零；L2 主要用于防过拟合，偏向保留更多参数。原理上，L1 正则化可由假设权重 w 的先验为拉普拉斯分布并用最大后验概率估计导出，L2 正则化可由假设权重 w 的先验为高斯分布并用最大后验概率估计导出。

#### 2.5.2 导致偏差和方差的原因是什么
偏差往往源于模型复杂度不足或对学习算法做了错误假设。例如真实模型是三次函数，却假设为二次函数，就会导致欠拟合，偏差增大；训练误差主要由偏差造成。

方差通常由模型复杂度过高引起。例如真实模型是简单二次函数，却假设为五次函数，就会导致过拟合，方差增大；由方差引起的误差主要体现在测试误差相对训练误差的波动上。

#### 2.6.1 随机梯度下降与小批量随机梯度下降
标准梯度下降每次用全部训练样本的平均损失来更新参数，若样本量巨大计算成本很高。随机梯度下降每次只用单个样本的损失来近似平均损失。

由于 SGD 只用部分样本估计梯度，估计精度不高，常出现偏差，导致收敛不稳定甚至不收敛。

小批量随机梯度下降为降低随机梯度的方差、使迭代更稳定，使用一批随机数据的损失来近似平均损失。批量训练还能利用矩阵运算和并行计算框架。通常批大小取 2 的幂，如 32、64、128、256 等，以充分利用矩阵运算。
