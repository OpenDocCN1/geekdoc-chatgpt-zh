> 你能介绍一下 C 语言和 Java 的区别吗？

C 语言和 Java 虽然都应用广泛，但在设计思路、适用场景和特性上差别明显，总结如下：

1. 设计理念

   - C 语言：

     - 面向过程：以函数为核心，强调执行的步骤与逻辑。

     - 底层可控：可直接操作内存和硬件，如指针与内存地址，适合系统级开发。

   - Java：

     - 面向对象：以类和对象为核心，突出封装、继承和多态。

     - 高度抽象：屏蔽底层细节，如自动内存管理，适合构建大型应用。

2. 内存管理

   - C 语言：

     - 手动管理：程序员需显式 malloc 申请、free 释放，灵活但易出现内存泄漏。

   - Java：

     - 自动垃圾回收：JVM 自动回收无用内存，安全性高，但可能带来实时性波动。

3. 平台依赖性

   - C 语言：

     - 编译为本地机器码：与操作系统和硬件绑定，不同平台需重新编译。

   - Java：

     - “一次编写，到处运行”：编译为字节码 .class，由 JVM 执行，跨平台能力强。

4. 性能

   - C 语言：

     - 效率高：直接操作硬件，无中间层，适用于操作系统、嵌入式等对性能敏感场景。

   - Java：

     - 略逊于 C：字节码解释和 GC 会带来开销，但 JIT 即时编译可大幅逼近 C 的性能。
