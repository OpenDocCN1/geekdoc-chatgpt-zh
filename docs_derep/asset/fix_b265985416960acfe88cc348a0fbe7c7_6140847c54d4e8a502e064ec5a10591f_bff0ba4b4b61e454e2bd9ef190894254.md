# CrewAI 中 Crew 的协作机制

在 CrewAI 体系里，Crew 就是由多个 Agent 协同推进工作的执行单元。每一支 Crew 都会明确任务的推进方式、成员间的配合规则以及整体的工作流，可以视为搭建多智能体协作系统的核心积木，能够显著提升任务处理的效率和复杂度。整体架构的示意见图 8-2。

### 1. Crew 的配置属性

Crew 对象暴露了一批可调参数，用来影响作业调度、协作形态以及运行时表现。核心参数整理于表 8-3。

表 8-3

| 属性 | 参数 | 描述 |
| --- | --- | --- |
| Tasks | tasks | 交给该 Crew 负责的任务集合 |
| Agents | agents | 组成 Crew 的智能体列表 |
| Process（可选） | process | 任务执行顺序，例如顺序或层级，默认顺序执行 |
| Verbose（可选） | verbose | 运行期间日志的详细程度，默认关闭 |
| Manager 大语言模型（可选） | manager_llm | 层级模式下负责统筹的 Agent 所用大模型，启用层级时需指定 |
| Function Calling 大语言模型（可选） | function_calling_llm | 指定后 Crew 会借助该大模型完成 Agent 间的函数调用 |

### 2. 如何创建 Crew

CrewAI 支持两种组建路径：YAML 描述与直接编码。

(1) YAML 配置

用 YAML 描述配置更直观、也更利于维护，在项目实践中较为常见。通常做法是继承 CrewBase，再借助装饰器声明 Agent、Task 与 Crew。下面是一个装饰器风格的示例：

如果不使用装饰器，也可以纯代码定义 Agent 与 Task，示例如下：

[PRE3]
from crewai import Agent, Crew, Task, Process
from crewai_tools import YourCustomTool  # 引入自定义工具
# 定义一个团队类,包含两个智能体和两个任务
class CrewNameExample:
    # 智能体 1:数据分析师
    def agent_one(self) -> Agent:
        return Agent(
            role="数据分析师",  # 智能体角色
            goal="分析市场中的数据趋势",  # 智能体目标
            backstory="具有经济学背景的资深数据分析师",  # 背景设定
            verbose=True,  # 启用详细日志输出
            tools=[YourCustomTool()]  # 使用自定义分析工具
        )

    # 智能体 2:市场调研员
    def agent_two(self) -> Agent:
        return Agent(
            role="市场调研员",
            goal="收集市场动态相关信息",
            backstory="一位细致入微、擅长研究的调研专家",
            verbose=True
        )

    # 任务 1:数据收集与趋势分析
    def task_one(self) -> Task:
        return Task(
            description="收集近期市场数据并识别其中的趋势。",
            expected_output="一份总结市场关键趋势的报告。",
            agent=self.agent_one()
        )

    # 任务 2:影响市场的因素调研
    def task_two(self) -> Task:
        return Task(
            description="调研影响市场动态的主要因素。",
            expected_output="一份关于市场影响因素的分析报告。",
            agent=self.agent_two()
        )

    # 组建团队,串行执行任务
    def crew(self) -> Crew:
        return Crew(
            agents=[self.agent_one(), self.agent_two()],  # 两个智能体
            tasks=[self.task_one(), self.task_two()],      # 两个任务
            process=Process.sequential,                    # 串行执行(按顺序)
            verbose=True                                   # 打印执行过程日志
        )
