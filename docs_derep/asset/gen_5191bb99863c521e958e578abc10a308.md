- (1) 核函数定义
代码6-8 实现了三种常用核的计算逻辑。线性核是对两个输入向量做内积直接输出；多项式核先把向量的内积乘以超参数 gamma 再加 1，最后按 degree 次幂提升；高斯核则以 sigma 作为带宽，基于两向量欧氏距离的平方除以 2 倍 sigma 平方后做指数映射。

- (2) SMO 训练函数
代码6-9 构建了基于 SMO 的 SVM 训练流程。先根据训练特征、标签和指定的核类型生成核矩阵 K，随后在最大迭代次数内循环扫描样本，用 SMO 不断刷新拉格朗日乘子 alpha 与偏置 b，直至一轮内找不到可更新的 alpha 对。迭代时先依据预测值与误差判断 KKT 是否满足，不满足则挑出第二个变量并按标签关系确定其上下界，再算学习率 eta，先裁剪更新第二个 alpha，随后同步更新第一个 alpha 并重新计算偏置。若两个 alpha 都落在合法区间，则取 b1 与 b2 的均值作为新的 b，否则择一采用。若整轮无成功更新，则迭代计数加一。最终输出训练好的 alpha 和 b。

def generate_data(n_samples):

    """

    生成随机数据

    参数:

        n_samples: 样本数量

    返回:

        X: 特征矩阵

        y: 标签向量

    """

    # 生成由范围在[0, 1)之间的随机数构成的特征矩阵 X, 形状为(n_samples, 2)

    X = np.random.rand(n_samples, 2) * 10

    # 从{-1, 1}中随机选择生成样本数量个标签, 形状为(n_samples,)

    y = np.random.choice([-1, 1], size=n_samples)

    return X, y
