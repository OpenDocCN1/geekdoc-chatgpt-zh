## 1.2 DeepSeek 架构概览
DeepSeek 在经典 Transformer 基础上深度优化，采用混合专家架构配合稀疏激活来提升效率，并引入动态路由网络，智能调度算力以高效处理长文本与复杂逻辑任务。

### 1.2.1 DeepSeek 整体架构设计
整体设计以高效处理长文本和提升推理效率为目标，主要由以下关键部分构成。

**1. MLA**

● 低秩联合压缩：把 Key 与 Value 分解为低秩矩阵并联合压缩，减少存储与访问量，降低推理显存与耗时。
● 显式位置编码融合：融合位置编码，让压缩后仍保留序列顺序信息。
● 并行计算优化：对压缩后的 Key-Value 并行操作，在保持注意力灵活性的同时提升推理速度。

**2. DeepSeekMoE 架构**

● 混合专家体系：融合 MoE、MLA、RMSNorm 三大组件，通过专家共享、动态路由和潜在变量缓存，相比传统 MoE 降低约 40% 计算开销，同时保持性能水平。
● 动态路由机制：针对输入 token 嵌入，路由器经门控网络挑选最相关的专家，确保高效且稳定。
● 无辅助损失的负载均衡：DeepSeek-V3 通过动态调节专家偏置实现均衡，避免传统强制均衡带来的性能衰减。

**3. 多 Token 预测训练目标（Multi-Token Prediction,MTP）**
训练时不仅预测下一个 Token，还同时预测后续多个位置的 Token，提升训练信号密度，帮助模型学习长期依赖，提高生成质量。

**4. 层级策略优化**

● MoE：内置多个专家子网络，以精细门控按需激活，扩大容量并控制计算成本。
● 分阶段训练：包括预训练、对齐、领域微调，确保在不同任务与领域均表现稳定。

**5. 其他优化**

● FP8 8-bit 浮点混合精度：显著加快训练速度，在硬件支持下提升吞吐量。
● 多语种多领域数据：具备一定跨语言能力，在通用场景保持良好表现。

总之，DeepSeek 的整体架构通过上述创新，在超大规模参数与实际推理效率间取得平衡，显著提升性能与应用价值。

### 1.2.2 DeepSeek 模块划分
模型采用多层模块化设计以提升性能与效率。

**1. 输入嵌入模块**

● 作用：将输入文本转为模型可处理的向量。
● 实现：词嵌入与位置嵌入结合，为每个输入 Token 生成固定维度向量。

**2. Transformer 模块**

（1）MLA。
● 作用：高效处理序列信息，降低计算与存储需求。
● 实现：以低秩压缩技术把 Token 特征压缩至小潜在空间，再经上投影恢复至 Key、Value 空间。

（2）MoE。
● 作用：借助多专家子网络提升容量与效率。
● 实现：每个 MoE 层含 1 个共享专家和 256 个路由专家，每个 Token 选择 8 个专家处理。

（3）RMSNorm 归一化层。
● 作用：稳定训练，加速收敛。
● 实现：在每个 Transformer 模块中使用 RMSNorm 对输入进行归一化。

**3. 优化策略模块**

（1）MTP。
● 作用：增加训练信号密度，提升生成质量。
● 实现：训练时同时预测下一个及后续多个 Token。

（2）负载均衡策略。
● 作用：保证专家负载均衡，提升性能。
● 实现：动态调整专家偏置项实现均衡，无需额外辅助损失。

**4. 输出层**

● 作用：将 Transformer 输出映射为最终预测结果。
● 实现：经线性层映射到词表维度，得到各 Token 的概率分布。

**5. 其他辅助模块**

（1）FP8 混合精度训练模块。
● 作用：降低训练 GPU 内存占用与计算开销。
● 实现：精细量化策略配合高精度累加，实现 FP8 混合精度训练。

（2）残差流分形解码架构。
● 作用：提升推理效率。
● 实现：主次双 Token 预测与动态损失融合，提升单次前向传播学习效率。
