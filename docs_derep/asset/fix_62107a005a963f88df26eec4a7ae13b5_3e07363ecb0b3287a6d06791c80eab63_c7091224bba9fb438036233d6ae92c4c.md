范式切换：从指令式筛选到图网络

一个很小的过滤任务就能体现两种思路的分界。命令式的写法里，作者亲自操纵遍历过程，依次审视每个数值，符合阈值就把该值推入一个容器，步骤非常直观。

results = []

def fun(collection):

    for num in collection:

        if num > 5:

            results.append(num)

换到关系型查询的视角，同样的需求被收敛成一条条件声明，只描述想要的行，不描述遍历方式，表达更凝练。

[PRE0]sql

>>> SELECT * FROM collection WHERE num > 5

再往上看，函数本身也可以作为参数流动。先实现一个把三数相加的工具，再写一个调度器，它接收任意可调用体以及位置与关键字参数，把它们原样转发进去并输出结果。配合一个只做参数打包的内层函数，最后的演示把打包函数交给调度器并喂入 1、2、3，展示参数传递的通用性。

[PRE1]python

def fun_add(a, b, c):

    return a + b + c

def fun_outer(fun_add, *args, **kwargs):

    print(fun_add(*args, **kwargs))

def fun_inner(*args):

    return args

if __name__ == '__main__':

    fun_outer(fun_inner, 1, 2, 3)

下面是 PyTorch 风格的动态网络训练样例。数据从 mnist.csv 读取出来，特征与标签被拆分，随后以 0.2 的比例划分为训练与测试。numpy 数组随后被转为张量，特征用浮点类型，标签用长整型。网络只有两层全连接，784 维映射到 128 维再到 10 维。损失函数采用交叉熵，优化器选 Adam。循环里先进入训练态，前向得到 logits 再算损失，整套流程在运行时才生成并执行。

import numpy as np

import pandas as pd

from sklearn.model_selection import train_test_split

import torch

import torch.nn as nn

import torch.optim as optim

# 导入数据

data = pd.read_csv('mnist.csv')

X = data.iloc[:, 1:].values

y = data.iloc[:, 0].values

# 分割数据集

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 将数据转换为张量

X_train = torch.tensor(X_train, dtype=torch.float)

X_test = torch.tensor(X_test, dtype=torch.float)

y_train = torch.tensor(y_train, dtype=torch.long)

y_test = torch.tensor(y_test, dtype=torch.long)

# 定义模型

class Net(nn.Module):

    def __init__(self):

        super(Net, self).__init__()

        self.fc1 = nn.Linear(784, 128)

        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):

        x = self.fc1(x)

        x = self.fc2(x)

        return x

model = Net()

# 定义损失函数和优化器

criterion = nn.CrossEntropyLoss()

optimizer = optim.Adam(model.parameters())

# 训练模型

for epoch in range(5):

    # 将模型设为训练模式

    model.train()

    # 计算模型输出

    logits = model(X_train)

    loss = criterion(logits, y_train)

对比来看，旧版 TensorFlow 走的是先描述后运行的路线。先给出批大小、输入维、隐层维、输出维四个常量，用占位符来承接外部的输入与目标。权重以随机正态方式初始化，并在同一会话的生命周期内保留。随后用矩阵乘法与 ReLU 拼出前向，再用平方和衡量误差。梯度由自动微分得出，参数更新通过赋值操作声明，学习率设得很小。图结构搭建完毕后才开启会话，先做变量初始化，再以随机构造的数据循环喂入 500 次，每次取回损失并打印出来。图与执行分离的特征与 PyTorch 的即时性形成鲜明对照。

import tensorflow as tf

import numpy as np

# 首先构建计算图

# N 是 batch 大小；D_in 是输入大小

# H 是隐单元个数；D_out 是输出大小

N, D_in, H, D_out = 64, 1000, 100, 10

# 输入和输出是 placeholder，在用 session 执行 graph 的时候

# 我们会 feed 进去一个 batch 的训练数据。

x = tf.placeholder(tf.float32, shape=(None, D_in))

y = tf.placeholder(tf.float32, shape=(None, D_out))

# 创建变量，并且随机初始化。

# 在 TensorFlow 里，变量的生命周期是整个 session，因此适合用它来保存模型的参数。

w1 = tf.Variable(tf.random_normal((D_in, H)))

w2 = tf.Variable(tf.random_normal((H, D_out)))

# 接着为 Forward 阶段，计算模型的预测值 y_pred。注意和 PyTorch 不同，这里不会执行任何计算，而只是定义了计算，后面用 session.run 的时候才会真正执行计算。

h = tf.matmul(x, w1)

h_relu = tf.maximum(h, tf.zeros(1))

y_pred = tf.matmul(h_relu, w2)

# 计算 loss

loss = tf.reduce_sum((y - y_pred) ** 2.0)

# 计算梯度

grad_w1, grad_w2 = tf.gradients(loss, [w1, w2])

# 使用梯度下降来更新参数。assign 同样也只是定义更新参数的操作，不会真正执行。在 TensorFlow 里，更新操作是计算图的一部分，而在 PyTorch 里，因为是动态的“实时”的计算，所以参数的更新只是普通的 Tensor 计算，不属于计算图的一部分。

learning_rate = 1e-6

new_w1 = w1.assign(w1 - learning_rate * grad_w1)

new_w2 = w2.assign(w2 - learning_rate * grad_w2)

# 计算图构建好了之后，我们需要创建一个 session 来执行计算图。

with tf.Session() as sess:

    # 首先需要用 session 初始化变量

    sess.run(tf.global_variables_initializer())

    # 创建随机训练数据

    x_value = np.random.randn(N, D_in)

    y_value = np.random.randn(N, D_out)

    for _ in range(500):

        # 用 session 多次执行计算图。每次 feed 进去不同的数据

        # run 的第一个参数是需要执行的计算图的节点，它依赖的节点也会自动执行

        # run 返回这些节点执行后的值，并且返回的是 numpy array

        loss_value, _, _ = sess.run([loss, new_w1, new_w2],

            feed_dict={x: x_value, y: y_value})

        print(loss_value)
