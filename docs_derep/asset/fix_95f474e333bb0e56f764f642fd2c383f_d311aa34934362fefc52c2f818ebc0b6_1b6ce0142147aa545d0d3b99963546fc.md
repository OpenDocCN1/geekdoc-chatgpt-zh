蒸馏完成后模型尺寸明显缩小、推理成本下降，因而在落地时具备更强的灵活性，很容易满足算力受限环境下快速上线的诉求。

## 第 7 章 稀疏矩阵技术

稀疏矩阵的典型特征是零元素占绝对多数，这类结构在科学计算、工程应用和数据分析里大量存在。利用其稀疏性可以在存储上大幅压缩、在运算上实现提速。稀疏矩阵方法在现今大模型中已成标配，不仅提升了存取与计算效率，也为海量稀疏数据的处理开辟了新路径。

### 7.1 稀疏矩阵介绍

稀疏矩阵最明显的属性是非零项非常稀少。对比稠密矩阵，它在存储和计算层面都有优化空间，能省空间又提速。

#### 7.1.1 稀疏矩阵的基础知识

当非零元素的数量远小于矩阵总规模时，该矩阵就具有稀疏性。以 100×100 的矩阵仅含 10 个非零项为例，若完整保存会浪费大量空间。稀疏存储的思路是只保留非零项以及其位置信息。工程上常用的实现有三种。

1. 三元组法
三元组法的表达最直观，用一张表记录所有非零项，每项以 行号、列号、数值 的三元组呈现。例如下面这个稀疏矩阵：

[PRE0]

用三元组记作 (1,1,1)、(2,2,2)、(3,3,3)。这种写法理解方便，却不便于直接进行矩阵运算。

2. 十字链表法
十字链表借助链表结构组织非零项，每个节点保存数值、行指针、列指针，以及指向同行下一个非零项和同列下一个非零项的指针。插入与删除效率高，适用于稀疏结构动态变化的情形。

3. 压缩稀疏行和压缩稀疏列法
这两种方式是数值计算中更高效的存储范式。

（1）压缩稀疏行 Compressed Sparse Row，CSR
按行顺序把非零值集中存放，同时记录每行非零项的起始位置。由三组数组构成。
- 值数组：收纳全部非零值；
- 列索引数组：对应每个非零值的列号；
- 行指针数组：标明每行非零项的起点以及总数。
以前面矩阵为例，CSR 表示为：
- 值数组：[1, 2, 3]
- 列索引数组：[0, 1, 2]
- 行指针数组：[0, 1, 2, 3]

（2）压缩稀疏列 Compressed Sparse Column，CSC
思路与 CSR 对称，按列存放。同样包含值数组、行索引数组和列指针数组。

CSR 与 CSC 的共同优点是空间占用更小，且对矩阵乘法等操作更友好。

总体而言，稀疏矩阵技术通过重塑存储与运算方式，解决了大规模稀疏数据的瓶颈，在科学计算、机器学习、网络分析等领域作用关键。随着数据规模持续膨胀，其研究价值也在攀升。

#### 7.1.2 稀疏矩阵在大模型中的应用

稀疏矩阵让大模型在长文本和资源受限场景下表现更稳，主要体现为以下方向。

1. 优化存储与提升计算效率
大模型参数量和特征维度都很突出，矩阵里零值占比很高。稀疏技术只保留非零项及其位置，显著降低存储与计算复杂度。Transformer 的注意力机制会产生稀疏矩阵，正好借助该技术实现高效存取与运算。

2. 自然语言处理的语义表达
稀疏矩阵常用于编码文本中的词或短语，捕捉语义信息。利用稀疏向量，模型能更快计算词向量间的距离，更好理解上下文与语义关联，在文本分类、机器翻译、语义检索等任务中意义突出。

3. 量子机器学习中的应用
在量子机器学习 Quantum Machine Learning，QML 里，稀疏矩阵的高效表示是处理大规模数据的前提。例如量子主成分分析利用稀疏矩阵表达数据，结合量子随机存取存储器与量子断层扫描技术高效提取显著特征。稀疏矩阵还被用于量子线性方程求解如 HHL 算法 和量子支持向量机。

4. 图神经网络中的邻接矩阵
图神经网络常用稀疏矩阵表示图的邻接关系。稀疏性带来更省的存储与更快的计算，同时便于图的遍历和聚类操作。

5. 模型压缩与剪枝
训练过程中可借助稀疏技术做压缩和剪枝。剔除接近零的权重，能显著减少存储需求和计算负担，同时保持性能。用稀疏矩阵保存优化后的参数，可提升推理速度与内存效率。

6. 量子算法中的稀疏矩阵操作
量子 k-最近邻 k-Nearest Neighbor，k-NN 算法用稀疏矩阵存数据，通过量子态叠加与测量高效计算点间距离。量子基本线性代数子程序也依赖稀疏矩阵来优化线性代数操作。

### 7.2 DeepSeek 的稀疏注意力再造

2025 年 2 月，DeepSeek 公布了关于原生稀疏注意力 Native Sparse Attention，NSA 的论文，题为 “Native Sparse Attention: Hardware-Aligned and Natively Trainable Sparse Attention”。

NSA 面向长文本建模的一种新型稀疏注意力。它通过动态分层稀疏策略，包含粗粒度标记压缩与细粒度标记选择，并配合硬件对齐优化，大幅降低计算复杂度和内存访问，同时维持与全注意力的性能。NSA 支持端到端训练，能自动学习最优稀疏模式，在推理与训练阶段均有明显加速。

#### 7.2.1 NSA 技术背景介绍

随 AI 发展，长文本建模在新一代大语言模型中愈发关键，推动力来自深入推理、代码库级生成以及多轮自主代理等真实应用，这些场景要求模型驾驭复杂的长文本。

DeepSeek-R1 的突破已能处理完整代码库、长篇文档，并保持跨数千 token 的连贯多轮对话，还能执行长距离依赖的复杂推理，展现出长文本建模的潜力。

但序列长度增长会让标准注意力成为延迟瓶颈。估算显示，解码 64K 上下文时，基于 softmax 的注意力计算可占总延迟的 70% ~ 80%，亟需更高效的注意力方案。

研究者开始利用 softmax 注意力的固有稀疏性，通过只计算关键查询-键对来降本。近期方法包括键值缓存逐出、分块键值选择、基于采样聚类或哈希的选择等。

实际中，现有稀疏注意力往往达不到预期，且多集中在推理，缺乏训练期支持，无法充分发挥稀疏模式的价值。

要真正落地，需要解决两大挑战：
- 硬件对齐的推理加速：把理论计算减少转化为真实提速，需在预填充与解码阶段做硬件友好的设计，缓解内存访问与调度瓶颈。
- 训练感知的算法设计：用可训练算子实现端到端计算，降低训练成本同时保持性能。

DeepSeek 为此提出 NSA，一种兼顾层次化标记建模的原生可训练稀疏注意力。NSA 把键值组织成时间块，用三条注意力路径处理：压缩粗粒度标记、选择性保留细粒度标记、滑动窗口提供局部上下文，从而降低每个查询的计算量，并开发专用内核提升实用效率。

NSA 的两大核心创新分别是：
- 硬件对齐系统：优化分块稀疏注意力以利用 Tensor Core 和内存访问，保持算术强度平衡。
- 训练感知设计：通过高效算法与反向算子实现稳定端到端训练。

这使得模型能高效部署与端到端训练，实现长文本的快速推理或训练。全注意力与 DeepSeek NSA 的对比见图 7-1。

#### 7.2.2 稀疏注意力方法的重新思考

现代稀疏注意力在降低 Transformer 理论复杂度上进展明显，但多数方法仅在推理时引入稀疏，预训练仍保留全注意力，会引入架构偏差，限制稀疏优势的发挥。

1. 推理效率的幻象
虽然注意力计算变稀疏，却未必能降低延迟，主要因为：
（1）阶段专化稀疏
部分方法在自回归解码期启用稀疏，却在预填充期需要昂贵的预处理；另一类只关注预填充。结果是至少一个阶段的成本与全注意力相当，难以在预填充主导的工作负载如图书摘要、代码补全，或解码主导的工作负载如长链推理中同时提速。
（2）与先进架构不兼容
部分稀疏方法无法适配多查询注意力 MQA 和分组查询注意力 GQA 这类现代解码架构。这些架构让多个查询头共享键值，减少解码期内存访问。例如 Quest 等方法让每个注意力头独立选择键值子集，在多头模型上可行，但在 GQA 模型里，键值内存访问对应同一 GQA 组内所有查询头选择的并集。计算量虽降，键值读取仍高，与高效内存访问设计冲突。

这些局限源于多数方案只聚焦键值缓存减少或理论计算减少，在先进框架与后端难以转化为延迟下降，促使研究者开发能结合先进架构与硬件高效实现的算法。

2. 可训练稀疏性的神话
追求 NSA 的两个洞察是：
（1）性能退化。训练后才加稀疏会让模型偏离预训练轨迹，预训练形成的检索头等结构在推理时易被剪枝。
（2）训练效率需求。高效处理长序列训练对大模型开发至关重要，涵盖更长文档预训练以及长上下文微调、强化学习等后续适配。而现有稀疏注意力多为推理导向，对训练计算关注不足。

把现有稀疏注意力搬到训练时还会遇到：
- 不可训练组件。ClusterKV 里的 k-均值聚类、MagicPIG 里的 SimHash 选择等离散操作会带来不连续，阻断梯度通过标记选择，导致模型难以学习最优稀疏模式。
- 反向传播低效。部分理论可训练方法实际训练慢。例如 Hash Attention 的标记粒度选择需要在注意力计算期间从键值缓存加载大量离散标记，非连续内存访问阻碍 Flash Attention 这类依赖连续访问与分块计算的高吞吐技术，硬件利用率低，训练效率受损。

3. 原生稀疏势在必行
上述推理与训练限制推动重新设计。DeepSeek 提出的 NSA 正是同时满足计算效率与训练可行性的原生稀疏注意力框架，下面将介绍其算法与算子实现细节。

#### 7.2.3 整体设计和实现策略

NSA 的整体框架与关键组件旨在以稀疏注意力提升性能与计算效率，通过算法与硬件协同实现高效训练与推理。

1. 背景
在语言建模中，注意力为每个查询标记 q_t 计算与所有前序键 k_:t 的相关性，生成值 v_:t 的加权和。优化输出可形式化为
O_t = Attn(q_t, k_:t, v_:t)
其中 Attn(q_t, k_:t, v_:t) = Σ α_{t,i} v_i / Σ α_{t,j}，α_{t,i}= e^{ q_t^T k_i / √d_k }
随着序列增长，注意力占比升高，长文本处理压力增大。

算术强度是计算操作与内存访问之比，决定硬件优化方向。GPU 的算术强度由峰值算力与内存带宽决定。训练与预填充阶段，批量矩阵乘法与注意力算术强度高，通常是计算受限。而自回归解码每次只生成一个标记，却需加载全部键值缓存，算术强度低、受内存带宽限制。因此解码优化目标是减少内存访问，训练与预填充目标是减少计算成本。

2. 整体框架
为利用注意力的自然稀疏模式，DeepSeek 提出用更紧凑信息密度的键值对 \tilde{K}_t 与 \tilde{V}_t 替换原始键值。优化输出为：
\tilde{K}_t = f_K(q_t, k_:t, v_:t)，\tilde{V}_t = f_V(q_t, k_:t, v_:t)
o_t^* = Attn(q_t, \tilde{K}_t, \tilde{V}_t)
\tilde{K}_t 与 \tilde{V}_t 基于当前查询与上下文记忆动态构建。可设计多种映射策略并组合：
o_t^* = Σ_{c∈C} g_t^c · Attn(q_t, \tilde{K}_t^c, \tilde{V}_t^c)

3. 算法设计
NSA 核心目标是在保持长文本建模能力的同时降低计算与内存开销，采用三种稀疏化策略：标记压缩、标记选择、滑动窗口。

（1）标记压缩
把连续的键值块聚合为块级表示，捕捉块内高层语义，同时大幅减少待处理键值对数量，在不丢失关键信息的前提下降低复杂度。

（2）标记选择
仅靠压缩会丢失细粒度信息，NSA 引入选择机制，按块重要性评分保留关键键值，确保细粒度上下文被捕捉。保留得分最高的块，既降本又聚焦重要信息。

（3）滑动窗口
专门处理局部上下文。局部模式易被模型捕捉，滑动窗口分支保证局部信息不被全局稀疏策略淹没。分离局部上下文后，更利于学习长距离依赖。

为最大化实效，NSA 在硬件层面做了对齐。与现代 GPU 架构匹配，利用 Tensor Core 与高效内存访问。采用以组为中心的数据加载，减少冗余键值传输；分块计算提升内存访问效率。这种设计在保持高算术强度的同时提高硬件利用率。
