### 常用符号速览

**张量索引**
| $A_{ijk}$ | 三维张量 $\mathbf{A}$ 在坐标 $(i,j,k)$ 上的取值 |
| $\mathbf{A}_{::i}$ | 取出 $\mathbf{A}$ 在第 $i$ 个位置的二维截面 |

**集合与区间**
| 符号 | 含义 |
| :--- | :--- |
| $\mathbb{R}$ | 实数全体 |
| $\mathbb{C}$ | 复数全体 |
| $\{0, 1, \cdots, n\}$ | 从 $0$ 到 $n$ 的整数集合 |
| $[a, b]$ | 闭区间，包含端点 $a$ 与 $b$ |
| $(a, b]$ | 左端开右端闭的实数区间 |

**线性代数**
| 符号 | 含义 |
| :--- | :--- |
| $A^\top$ | 矩阵 $A$ 的转置 |
| $A \odot B$ | 矩阵 $A、B$ 的逐元素 Hadamard 积 |
| $\det(A)$ | 矩阵 $A$ 的行列式 |
| $[x; y]$ | 向量 $x$ 与 $y$ 垂直拼接 |
| $[A; V]$ | 矩阵 $A$ 与 $V$ 按行方向拼接 |
| $x \cdot y$ 或 $x^\top y$ | 向量 $x、y$ 的内积 |

**微积分**
| 符号 | 含义 |
| :--- | :--- |
| $\frac{dy}{dx}$ | $y$ 关于 $x$ 的导数 |
| $\frac{\partial y}{\partial x}$ | $y$ 关于 $x$ 的偏导数 |
| $\nabla_x y$ | $y$ 对向量 $x$ 求梯度 |
| $\nabla_X y$ | $y$ 对矩阵 $X$ 求梯度 |
| $\nabla_{\mathbb{X}} y$ | $y$ 对张量 $\mathbb{X}$ 求梯度 |

**概率与信息**
| 符号 | 含义 |
| :--- | :--- |
| $a \perp b$ | 随机变量 $a$ 与 $b$ 相互独立 |
| $a \perp b \mid c$ | 在 $c$ 给定下 $a$ 与 $b$ 条件独立 |
| $P(a)$ | 离散变量的概率质量 |
| $p(a)$ | 连续变量的概率密度 |
| $a \sim P$ | 变量 $a$ 服从分布 $P$ |
| $\mathbb{E}_{x \sim P}(f(x))$ 或 $\mathbb{E}(f(x))$ | $f(x)$ 在 $P(x)$ 下的期望 |
| $\text{Var}(f(x))$ | $f(x)$ 在 $P(x)$ 下的方差 |
| $\text{Cov}(f(x), g(x))$ | $f(x)$ 与 $g(x)$ 在 $P(x)$ 下的协方差 |
| $H(f(x))$ | 随机变量 $x$ 的信息熵 |
| $D_{\text{KL}}(P \parallel Q)$ | 分布 $P$ 与 $Q$ 的 KL 散度 |
| $\mathcal{N}(\mu, \Sigma)$ | 均值 $\mu$、协方差 $\Sigma$ 的高斯分布 |

**数据与分布**
| 符号 | 含义 |
| :--- | :--- |
| $\mathbb{X}$ 或 $\mathbb{D}$ | 数据集合 |
| $x^{(i)}$ | 集合中第 $i$ 条输入样本 |
| $y^{(i)}$ | 样本 $x^{(i)}$ 对应的标签 |

**函数与运算**
$f : \mathcal{A} \longrightarrow \mathcal{B}$ 表示定义域 $\mathcal{A}$ 到值域 $\mathcal{B}$ 的映射 $f$
$f \circ g$ 为 $f$ 与 $g$ 的复合
$f(x; \theta)$ 由参数 $\theta$ 参数化的关于 $x$ 的函数，可简写为 $f(x)$
$\log x$ 为 $x$ 的自然对数
$\sigma(x)$ 为 Sigmoid $\frac{1}{1 + \exp(-x)}$
$\|x\|_p$ 为 $x$ 的 $L^p$ 范数，$\|x\|$ 为 $L^2$ 范数

**本书常用记法**
- 词表记为 $\mathbb{V}$，其规模为 $|\mathbb{V}|$
- 序列 $x = x_1, x_2, \cdots, x_n$ 中词 $x_i$ 的向量为 $v_{x_i}$
- 损失 $\mathcal{L}$ 采用负对数似然：$\mathcal{L}(\theta) = -\sum_{(x,y)} \log P(y|x_1 x_2 \cdots x_n)$
- 算法空间复杂度记为 $\mathcal{O}(mn)$

# 第 1 章 绪论

大语言模型通常由规模达到数百亿参数以上、甚至更多的深度神经网络构成，训练时多采用自监督方式，利用海量未标注文本进行学习。自 2018 年起，Google、OpenAI、Meta、百度、华为等机构先后推出 BERT[1]、GPT[6] 等系列模型，这些系统在绝大多数自然语言处理任务上表现突出。2019 年起模型体量进入加速期，2022 年 11 月 ChatGPT 的面世更是引发全球关注。用户可通过自然语言进行对话，模型能完成问答、分类、摘要、翻译等理解到生成的各类任务，展现出对世界知识和语言规律的强力把握。

本章将梳理大语言模型的核心概念、演进脉络以及典型构建流程。

## 1.1 大语言模型的基本概念

语言能力是人类区别于其他生物的关键，人类逻辑和知识长期以语言形式承载。如今互联网汇聚数万亿网页，绝大部分信息以自然语言呈现。让人工智能获取知识的先决条件就是理解这种不精确、易歧义且略显混乱的人类表达。语言模型的目标是对自然语言的概率分布进行建模。

在词表 $\mathbb{V}$ 上，一个语言模型可表示为函数 $P(w_1w_2\cdots w_m)$，即词序列 $w_1w_2\cdots w_m$ 出现概率的大小。直接建模联合概率 $P(w_1w_2\cdots w_m)$ 参数规模极其庞大。以《现代汉语词典》第 7 版约 7 万词计，句子长度取 20，参数量已达 $7.9792 \times 10^{96}$，实际中文常出现上百词的长句，全面覆盖的复杂度远超当前计算能力。

为压缩参数空间，可利用句子逐词生成的过程做链式分解：

[PRE0]

[PRE1]

这样 $w_1w_2\cdots w_m$ 的生成被拆分为逐词条件生成，先生成 $w_1$，再依据 $w_1$ 生成 $w_2$，依此类推直至 $w_m$。例如“把努力变成一种习惯”的概率可写为

$P(\text{把 努力 变成 一种 习惯}) = P(\text{把}) \times P(\text{努力}|\text{把}) \times P(\text{变成}|\text{把 努力}) \times P(\text{一种}|\text{把 努力 变成}) \times P(\text{习惯}|\text{把 努力 变成 一种})$ (1.2)

链式分解把联合概率转化为条件概率的乘积，但 $P(w_m|w_1 w_2 \cdots w_{m-1})$ 的参数量依然天文级。进而引入马尔可夫假设，认为词 $w_i$ 只依赖其前 $n-1$ 个词：

$P(w_i|w_1 w_2 \cdots w_{i-1}) = P(w_i|w_{i-(n-1)} w_{i-(n-2)} \cdots w_{i-1})$

$P(w_i|w_1^{i-1}) = P(w_i|w_{i-n+1}^{i-1})$ (1.3)

满足此条件的模型即为 $n$-gram 模型，$n$-gram 指连续 $n$ 个词构成的单元。

$n$-gram 缓解了零概率问题，但语言可能性无限，训练数据无法穷尽所有 $n$-gram。零频并不等于零概率，需以平滑技术为所有可能字符串赋予非零概率。平滑是对最大似然估计的调整，属于统计语言模型范畴，具体算法可参见《自然语言处理导论》第 6 章[8]。

总体来看，$n$-gram 的效果与数据规模、模型阶数以及平滑策略密切相关。尽管平滑解决了零概率，却仍存在明显局限：

- 无法建模长度超过 $n$ 的上下文依赖
- 平滑依赖人工设计的规则
- $n$ 增大时数据稀疏加剧，参数量指数增长，难以准确估计
