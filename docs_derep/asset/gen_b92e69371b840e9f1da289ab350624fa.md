# 第8章 声音设计：声入人心的视频灵魂

人声、背景音乐、音效、环境音，这四类声音是电影必备，奥斯卡也有众多声音类奖项。经典之所以经典，除了故事，还在于声音设计的穿透力，直达内心。

短视频同样如此。抖音最初就靠声音驱动记录生活，如今观众审美提升，声音设计也愈发多元专业。有时配乐选对，流量就能爆发。不会运用声音技术，内容会黯淡五分。让我们一起揭秘如何为短视频注入声音灵魂。

### 8.1.2 音频降噪

音频降噪用于消除底噪且不影响音色。选中音频素材后，点击音频二级栏的“音频降噪”按钮，进入降噪界面，打开“降噪开关”即可，如图8-5。

[PRE62]

图8-5

若收音环境和麦克风都很理想，基本听不到底噪，就无需降噪，因为降噪会在一定程度上损失细节。

若在室外或家庭环境音较大，录音中混入装修声、鸟鸣等，就很有必要降噪，用少量细节损失换取更干净的声音，非常值得。

**创作技法**

**麦克风自带降噪按钮与剪映后期降噪功能，区别是什么？应该如何选择使用？**

尽量避免前期物理降噪，因为它会牺牲音质。录音时加与不加降噪效果可能截然不同，不建议使用麦克风自带的降噪功能，而在后期处理。平台级软件降噪的优化远好于几百元麦克风的物理降噪。

### 8.1.3 人声美化

人声美化后会更通透明亮。通过去除混响、喷麦、口水声等噪音并增强音质，可把人声提升至录音棚水准。

录音时常出现声音沉闷，需后期调整。如使用千元级麦克风在封闭室内录制，因嘴麦距离导致收音不充分，声音偏沉闷，如图8-6。

此时可用“人声美化”功能改善，如图8-7。该功能默认强度为75，处理需较长时间。

若使用两三千元的高品质麦克风如罗德，本身通透度已高，是否美化可按需求决定。
