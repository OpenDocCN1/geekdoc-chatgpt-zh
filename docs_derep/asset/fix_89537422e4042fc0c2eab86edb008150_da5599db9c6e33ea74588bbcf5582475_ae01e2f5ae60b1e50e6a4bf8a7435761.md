else:

    print("你是个小孩。")

示例先给出 age = 16，随后用条件结构分段判断。数值不低于 18 时进入首个分支，输出“你是成年人了。”；数值介于 13 与 17 之间时满足 elif，输出“你是青少年。”；其余即小于 13 的情况全部流向 else，输出“你是个小孩。”

**4. for 循环语句**

for 在 Python 里常用来逐项处理可迭代对象，例如列表、元组、字符串等。示范代码：

fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print("I like", fruit)

这里先构造了包含 apple、banana、cherry 的列表 fruits，随后让循环把列表的每一项依次赋给 fruit，并在循环体中执行打印。

**5. while 循环语句**

while 的作用是在布尔表达式保持真的时候反复运行一段代码。示范代码：

count = 0

while count < 5:
    print("Count is", count)
    count += 1

初始把 count 设为 0，只要它仍小于 5 就进入循环体，先输出当前值再把 count 自增，直至条件不再成立。

**6. range 函数在循环语句中的使用**

range 常与 for 配合，生成一段等差数字序列作为循环计数。示范代码：

for i in range(5):
    print(i)

range(5) 产生 0 到 4 的整数，5 本身不包含。for 会依次把这些数赋给 i 并执行内部语句。

**7. break 跳转语句**

break 能立刻终止当前循环，后续迭代不再进行。示范代码：

for i in range(5):
    if i == 3:
        break
    print(i)

当 i 变为 3 时触发 break，循环立即结束，可见输出只有 0、1、2。

**8. continue 语句**

continue 会跳过本次循环剩余部分，直接进入下一次迭代。示范代码：

for i in range(5):
    if i == 3:
        continue
    print(i)

i 为 3 时跳过打印，循环继续，所以最终出现 0、1、2、4。

**9. pass 语句**

pass 在语法上占据位置，实际不做任何事，常用于占位。示范代码：

for i in range(5):
    if i == 3:
        pass
    print(i)

即使 i 等于 3，pass 也不会产生效果，循环照常执行，0 至 4 全部被打印。

### **7.2.7 列表**

列表是可变的有序集合，用 [] 表示，元素以逗号分隔，可混用类型并可嵌套。示例：

my_list = [1, "Hello", 3.14, ["another", "list"]]

**1. 添加列表元素**

append() 把元素加到尾部，insert() 可在指定下标插入，extend() 把另一个可迭代对象的全部元素接在末尾。示例：

my_list = [1, 2, 3]
my_list.append(4)  # [1, 2, 3, 4]
my_list.insert(0, 0)  # [0, 1, 2, 3, 4]

list1 = [1, 2, 3]
list2 = [4, 5, 6]
list1.extend(list2)  # list1 现在是[1, 2, 3, 4, 5, 6]

**2. 查找元素**

列表下标从 0 起，可直接取值。index() 返回目标元素首次出现的下标。for 循环也是遍历的常用手段。示例：

my_list = [1, 2, 3, 4, 5]
print(my_list[0])  # 输出：1

list1 = [1, 2, 3, 2, 3, 3]
print(list1.index(3))  # 输出：2

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

**3. 修改元素**

通过下标赋值即可改写对应位置。示例：

my_list = [1, 2, 3, 4, 5]
my_list[0] = 0  # [0, 2, 3, 4, 5]

**4. 删除元素**

del 按下标移除，remove() 删除首次匹配的值，pop() 删除并返回元素，默认末尾。示例：

my_list = [1, 2, 3, 4, 5]
del my_list[0]  # [2, 3, 4, 5]
my_list.remove(3)  # [2, 4, 5]
my_list.pop()  # [2, 4]

指定下标给 pop 时会删除并返回该位置元素。

**5. 排序列表**

sort() 对列表原地升序排列。示例：

list1 = [3, 1, 2]
list1.sort()  # list1 现在是[1, 2, 3]

### **7.2.8 元组**

元组是有序且不可变的类型，用 () 表示，创建后不可增删改，适合需要稳定性的场景。示例：

my_tuple = ("apple", "banana", "cherry")

**1. 元组的格式**

元素以逗号分隔。

**2. 查找元组元素**

下标从 0 开始访问。示例：

my_tuple = ("apple", "banana", "cherry")
print(my_tuple[0])  # 输出：apple

**3. 删除元组元素**

单个元素不可删，只能用 del 删除整个对象。示例：

my_tuple = ("apple", "banana", "cherry")
del my_tuple

**4. 统计元组元素**

count() 返回指定值的出现次数。示例：

my_tuple = ("apple", "banana", "cherry", "apple")
print(my_tuple.count("apple"))  # 输出：2

**5. 合并元组**

用 + 连接多个元组。示例：

tuple1 = ("apple", "banana", "cherry")
tuple2 = ("orange", "melon", "strawberry")
tuple3 = tuple1 + tuple2
print(tuple3)  # 输出：("apple", "banana", "cherry", "orange", "melon", "strawberry")

### **7.2.9 字典**

字典是可变的键值对集合，用 {} 表示，键唯一且不可重复，值可任意类型。示例：

my_dict = {"name": "Alice", "age": 25, "city": "New York"}

**1. 字典的格式**

键与值用冒号分隔，多个键值对用逗号分隔。

**2. 添加字典元素**

直接通过键赋值即可新增或覆盖。示例：

my_dict = {"name": "Alice", "age": 25}
my_dict["city"] = "New York"  # {"name": "Alice", "age": 25, "city": "New York"}

**3. 查找字典元素**

用键索引取值，get() 更稳妥，可提供默认值。示例：

my_dict = {"name": "Alice", "age": 25, "city": "New York"}
print(my_dict["name"])  # 输出：Alice

my_dict = {"name": "Alice", "age": 25}
name = my_dict.get("name", "Unknown")
print(name)  # 输出：Alice
city = my_dict.get("city", "New York")
print(city)  # 输出：New York

若不给默认值，找不到键时 get 返回 None。

**4. 修改字典元素**

同添加，通过键赋值覆盖。示例：

my_dict = {"name": "Alice", "age": 25, "city": "New York"}
my_dict["age"] = 26  # {"name": "Alice", "age": 26, "city": "New York"}

**5. 删除字典元素**

del 或 pop() 都能移除键值对。示例：

my_dict = {"name": "Alice", "age": 25, "city": "New York"}
del my_dict["age"]  # {"name": "Alice", "city": "New York"}
my_dict.pop("city")  # {"name": "Alice"}

**6. 遍历键和值**

keys() 遍历键，values() 遍历值，items() 遍历键值对。示例：

my_dict = {"name": "Alice", "age": 25, "city": "New York"}
for key in my_dict.keys():
    print(key)
for value in my_dict.values():
    print(value)
for key, value in my_dict.items():
    print(key, value)

### **7.2.10 函数**

函数把可复用代码封装成命名块，可接收参数、执行逻辑并返回结果，提升模块化与可维护性。如做咖啡，把磨豆、加热、冲泡封装成 make_coffee()，需要时直接调用。

**1. 自定义函数**

用 def 定义，基本形式：

def function_name(parameters):
    # 函数体
    return result

**2. 无参函数**

定义时不声明参数，内部自行处理。示例：

def greet():
    print("Hello, world!")

greet()  # 调用函数，不传入任何参数

**3. 有参函数**

声明参数后可在函数内使用。示例：

def add(a, b):
    return a + b

result = add(1, 2)  # 调用函数，传入参数 1 和 2
print(result)  # 输出：3
