# 第 3 课　电子罗盘（续）

要让 Micro：bit 变身实用指南针，离不开 Mind+ 的加持。我们可以设定具体的角度区间来对应四个方位：当罗盘读数小于 30° 或大于 330° 时，屏幕指示正北；160° 至 210° 之间指示正南；30° 到 160° 指向正东；210° 到 330° 则指向正西。由于南北向对精度要求更高，其判定角度范围特意设得比东西向更窄。实现这一逻辑，需调用“运算符”模块的指令积木[PRE0]来界定数值区间，完整编程逻辑见图 3-5。
