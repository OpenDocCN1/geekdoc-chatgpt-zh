在 LLaMA-Factory 上把 Qwen 做 LoRA 微调并拉到本地推理，关键就在于把脚本、环境清理和导出加载这几步串起来。下面是一套可直接复用的实操流程，命令照搬即可。

先把单卡微调的脚本放到项目根目录，切换进去确认文件已到位。
[PRE0]
cp single_lora_qwen.sh ~/LLaMA-Factory

cd ~/LLaMA-Factory/

ll
如果脚本是从 Windows 拷过来的，行尾会有 ^M，需要先统一换行符。
[PRE1]
sed -i 's/\r$//' ./single_lora_qwen.sh
清理完之后赋予执行权限并直接启动。
[PRE2]
chmod +x ./single_lora_qwen.sh

./single_lora_qwen.sh

训练完成后需要把 LoRA 权重导出为可推理格式。常用的导出脚本示例如下，模型基座指向 ModelScope 缓存的 Qwen1.5-1.8B-Chat，适配器来自本地 checkpoint，导出到 qwen_lora 目录。
[PRE5]
#!/bin/bash

python src/export_model.py \
    --model_name_or_path /mnt/workspace/.cache/modelscope/Qwen/Qwen1__5-1__8B-Chat \
    --adapter_name_or_path ~/LLaMA-Factory/single_lora_qwen_checkpoint \
    --template qwen \
    --finetuning_type lora \
    --export_dir /mnt/workspace/.cache/modelscope/qwen_lora \
    --export_size 2 \
    --export_legacy_format false
