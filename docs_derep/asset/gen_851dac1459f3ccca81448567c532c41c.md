自 ChatGPT 放开 API 接口后，越来越多的公司把大模型能力接入到自家产品里，用来迭代功能、优化用户体验。互联网企业汤姆猫就主打“会说话的汤姆猫家族”这一核心 IP，已经搭建起线上线下联动的完整链路，业务覆盖多个国家，旗下汤姆猫系列游戏累计下载量已超百亿次。

为了把该 IP 的价值进一步做深，汤姆猫把游戏内容与新技术结合，不断刷新互动玩法。为此公司在 ChatGPT 引发关注后迅速跟进，用其底层模型来做产品测试和研发验证。

目前汤姆猫已完成 AI 语音互动的测试，在已有产品上叠加了语音识别、语音合成、角色性格设定等能力，并对语音交互、连续对话等场景进行验证，同步开展了相关技术落地的可行性测试。

汤姆猫之外，360、百度等头部科技公司也在密集推出自家大模型并对外开放 API，为各行各业赋能。以 360 为例，2023 年 6 月对外宣布面向企业和开发者开放通用大模型“360 智脑”API，输出面向行业的模型解决方案。相关方案率先在传媒、能源等领域应用，为企业在办公写作、决策分析、客户服务等环节提供支撑。

总体看，大模型 API 让企业能把模型能力嵌入自有产品，推动性能提升和功能升级，加速迭代与新品研发。未来 MaaS 应用将在 B 端大规模落地，助力更多行业。企业可依据自身需求挑选适配的 MaaS 服务。

### 4.2.3 平台驱动 打造一站式 MaaS 服务能力
在开放 API 的同时，不少厂商在 MaaS 层面做更全面的布局，依托技术实力搭建一站式 MaaS 平台，为 B 端用户提供调用、微调、应用、管理的全流程服务。

2023 年 5 月的“文心大模型技术交流会”上，百度智能云展示了文心大模型的进展，其中包括处于内测的“文心千帆”大模型平台。该平台是一款企业级模型生产平台，集成了文心一言及若干第三方模型，为企业开发和应用大模型提供完整工具链，实现一站式服务。

文心千帆主要承担两类服务：一是依托文心一言帮助企业产品迭代与生产流程优化；二是支持企业基于平台模型训练专属模型。凭借这两项能力，平台有望成长为模型生产与分发的枢纽。

平台覆盖海量数据处理、数据标注、模型训练微调、评测等全开发环节，企业获得业务定制模型后，还可享受模型托管、推理等运维服务，使用门槛进一步降低。

在易用性上，用户无需编码即可完成训练与微调；在开放性上，平台汇聚多家第三方模型，覆盖更广场景；在能力拓展上，通过插件机制引入外部能力，提升服务上限。

交付形式支持公有云与私有化部署。公有云提供推理、微调、托管三类服务：推理支持直接调用平台模型能力；微调帮助企业用高质量数据生成行业定制模型；托管负责模型稳定运行，三者共同降低应用门槛。私有化部署则提供软件授权、软硬件基础设施支持及硬件与平台能力的租赁服务，满足企业本地化需求。

目前文心千帆已与用友、宝兰德等生态伙伴签约，未来将通过完善生态推动 MaaS 在更多领域落地。

百度之外，字节跳动旗下云服务平台火山引擎在 2023 年 6 月推出 MaaS 平台“火山方舟”，面向企业提供模型训练与微调服务。平台已汇聚 IDEA 研究院、智谱 AI 等多家模型并开启邀请测试。

火山方舟支持模型精调与效果评测，企业可用统一工作流并测多模型，再挑选适配业务的方案，也可按场景组合模型赋能业务。依托安全互信计算技术，用户数据资产安全得到保障。

字节内部多个业务团队已在火山方舟上实践降本增效，平台能力不断完善。同时平台已邀请金融、汽车等行业企业内测，未来将与客户营销、协同办公等场景结合，提升企业运营效率。

## 4.3 MaaS 模式在 C 端的商业化落地
除 B 端外，MaaS 也在 C 端加速落地，驱动应用迭代、功能升级，为用户带来更佳体验。

### 4.3.1 C 端落地的三大方向
MaaS 将推动 C 端应用从“能用”迈向“好用”，提升体验。结合商业化视角，C 端落地大致有三条路径，如图 4-1 所示。

#### 1. 聚焦效率价值
MaaS 正在重塑编程工具、文档工具等，提升办公效率。CodeGeeX 就是一款基于大模型的 AI 编程工具，可实现代码生成、翻译、补全，支持数十种语言，向用户免费开放，帮助提升编程效率与质量，降低门槛。用户可通过网页版或 VS Code 插件使用。

#### 2. 聚焦体验价值
体验是 MaaS 的关键发力点，数字人、游戏等对体验要求高的领域率先变化。

2023 年 6 月“360 智脑大模型应用发布会”上，360 同步发布基于大模型的智能应用“AI 数字人广场”。应用支持用户与 200 多个角色互动，涵盖“孙悟空”“诸葛亮”等知名人物。

平台数字人分两类：一类是大众熟知的数字名人，另一类是提供专业服务的数字助理。名人可根据提问给出建议，助理则能提供法务、策划等专业内容。应用还支持数字人定制，可依据用户上传的私人资料生成人设鲜明、性格独特的专属数字人。

目前应用仍在研发，未上线，但展示了 MaaS 在 C 端落地的可行路径。在大模型加持下，数字人将更智慧，能处理更复杂任务，具备接近人类的思维方式和鲜明性格，实现朋友式陪伴。

#### 3. 聚焦价值创造
MaaS 在 C 端落地将催生内容爆发，提升消费级应用服务能力。在模型支持下，文本、图像、视频生成、3D 建模等功能正不断优化，使用体验更便捷。各大开源社区已聚集大量面向个人的 AI 绘画、AI 编程工具，辅助创意与研发设计。

与此同时，多款应用正借助模型升级。阿里已构建较为完整的 MaaS 体系，包括通用大模型、企业专属模型、API 服务、开源社区等。未来淘宝、闲鱼、高德地图等产品都将接入大模型，优化使用体验。

MaaS 将沿着效率、体验、价值创造三条路径向 C 端更多场景渗透。随着企业研发深化，基于大模型的 AI 产品将密集涌现，覆盖生活各方面。

### 4.3.2 智能硬件成为个性化大模型的载体
2023 年 4 月，天猫精灵接入阿里巴巴通义大模型并开启内测招募。演示显示，接入“通义千问”后，天猫精灵的知识广度、沟通自然度和个性化水平均有提升，成为更具温度的智能助手。

大模型与智能硬件结合，凸显了模型在硬件领域的价值。未来在模型驱动下，智能硬件将进入更多场景，C 端个性化定制将成新方向。

个性化模型更适配 C 端。例如居家场景中，搭载个性化大模型的硬件可被赋予身份、性格、偏好等角色设定，与用户对话时生成个性化回复并以个性化语音交互。

为通用模型注入个性化要素正成重要探索方向，智能硬件作为承载主体，也将成为新的流量入口。同时硬件可借助模型焕新。传统智能音箱、扫地机器人等在智能性上长期受诟病，接入大模型后可实现更智能功能，满足个性化需求。

在模型助力下，智能陪护机器人、早教机器人等先进硬件有望迎来技术突破。例如智能陪护机器人可与用户个性化互动、顺畅沟通，精准把握需求提供贴心服务。除多样化服务与安全监护外，借助模型生成能力，其还具备多媒体娱乐功能。

总体看，个性化模型能升级交互方式与功能，满足用户个性化需求，有望率先在智能家居领域落地。

### 4.3.3 云从科技面向 C 端推出“从容”大模型
深耕 AI 多年的云从科技在 2023 年 5 月推出自研大模型“从容”，主要面向 C 端，提供更智能便捷的 AI 应用。

依托实时学习与同步反馈，“从容”助力 AI 应用落地，加速个性化应用普及。凭借上下文学习能力，模型可实现更自然交互，适用于游戏、金融等场景，提升服务体验。

传媒领域，云从推出数字人直播平台，用户可自由选择背景、主播库、语音、视觉风格。模型可生成直播文稿、实时回答互动问题，并对直播进行监控与提示生成。

教育领域，众数信科基于“从容”打造智能教育 AI 精灵。教师可用其批量生成不同类型、难度的题目，精灵还能评价学生表现，减轻教师负担。

游戏领域，云从致力推动模型在游戏中的应用，提升开发发行效率。公司与游族网络合作研发游戏垂直大模型，成果将用于产品研发与发行。

金融领域，基于“从容”研发的虚拟客户经理具备智能问答、多意图理解、动态追问等能力，助力金融机构实现引流、营销到运营的全流程智能化。

智慧城市场景下，模型可结合当日天气、交通等信息，为市民提供科学出行建议。

发布会上，云从与神州信息、游族网络、今世缘达成合作，并与华为昇腾、厦门文广开展生态协作，推动“从容”大模型成熟。

## 4.4 MaaS 成为大模型厂商的核心商业模式
随着模型逐步成熟，厂商积极推动落地，MaaS 成为核心商业模式，主要收费方式包括订阅制、嵌入其他产品获取引流收入、开放 API 与定制开发收费。

### 4.4.1 订阅制收费
MaaS 能为企业提供多类高质量模型，以低成本获得优质服务，灵活性与适配性强，可按业务目标提供个性化方案。订阅制是主要收费模式，ChatGPT 即为典型。

ChatGPT 分免费与付费版。免费研究预览版上线一周即获近百万粉丝，截至 2023 年 1 月月活达 1 亿，高速增长导致服务器崩溃。OpenAI 采取限流措施，包括禁止云服务器访问、限制每小时提问次数、高峰期排队。

为此推出付费订阅 ChatGPT Plus，月费 20 美元，权益包括高峰免排队、快速响应、新功能优先试用。高峰期免排队极具吸引力。

另有内测付费版 ChatGPT Pro，月费 42 美元，提供全天可用、快速响应、优先使用新功能等权益。两版差异需用户自行体验。

除 OpenAI 外，Jasper.AI 推出 AI 写作助手 Jasper，底层为 GPT-3，可生成文本、提供写作模板、广告文案、邮件、社交媒体推文等，订阅档位最低 29 美元。

Copy.ai 是文本生成工具，用户包括微软、eBay 等。其操作简便，输入需求即可生成内容，并支持增删改格式。订阅制收费，月费 49 美元，年费 332 美元，对大客户可提供专属服务。

随着研发深入，订阅费用有望逐步下降，吸引更多用户，带来广阔市场空间。

### 4.4.2 嵌入产品获取引流收入
嵌入其他产品获取引流收入也是 MaaS 收费方式之一，微软即通过为软件提供服务获益。

2023 年 2 月，微软推出 Microsoft Teams Premium 收费服务，用于视频会议与远程操作。2023 年 6 月价格为 7 美元/月，7 月恢复至 10 美元/月。

服务由 OpenAI GPT-3.5 支持，核心功能为智能回顾，可自动生成会议记录、标记重点，方便错过会议或需回顾的用户。智能回顾显示每位参与者姓名、被提及时间、进出时间，并标记演讲者起止时间，便于复盘。

微软 CRM 软件 Viva Sales 接入 OpenAI GPT-3.5，帮助销售减负。可自动回复用户问题，销售选择提供折扣或回答后系统自动生成回复，并基于历史数据生成个性化营销邮件。服务月费 40 美元，为微软带来可观收入。

2023 年 3 月，微软发布 Copilot AI 服务，可生成文档、PPT、邮件等，并能嵌入 Word、PPT 等办公产品。嵌入 Word 可生成文本，嵌入 Excel 可分析数据生成图表，嵌入邮箱可整理收件箱与回复邮件。

总体看，微软持续探索 MaaS，致力于提供更优质服务。

### 4.4.3 开放 API 与定制开发收费
部分企业通过为客户工具提供模型支持收费。OpenAI 致力于提供开源模型并开放 API 以获取收益。

DALL·E 是 OpenAI 推出可编辑与创建图像的模型，企业可将其集成到自有产品。

创业公司 Mixtiles 与 OpenAI 合作，将 DALL·E 融入产品，助力用户内容创作。

零售平台 Cala 也搭载 DALL·E，为用户提供设计售卖品牌的零售平台，提供构思、设计、售卖一站式服务。用户上传文本描述或参考图后，平台可输出设计图。

相较 Mixtiles，Cala 的商业化程度更高，对细节要求更严。同一模型在不同客户需求下收费差异显著，需求越高收费标准越高。

# 第5章 大模型驱动下数据服务市场爆发
AI 快速发展离不开数据支撑，数据是大模型发展的关键要素。在此背景下，模型对数据资源的需求持续上升，越来越多企业进入数据服务领域，为模型提供优质数据源，推动数据服务市场爆发。

## 5.1 大模型时代数据资源需求攀升
AI 技术发展使大模型成为企业研发新方向，但模型训练需要高质量、大规模、多样化数据，对数据要求极高。在此趋势下，数据标注服务需求爆发，训练需求带动版权 IP 需求上升，众多企业涌入数据服务。

### 5.1.1 数据标注需求迎来爆发
AI 行业持续发展，模型愈发复杂，对算力要求提高，进而拉动训练数据需求。随着企业对数据数量与质量要求提升，数据标注服务需求将加速爆发，推动标注行业快速发展。
