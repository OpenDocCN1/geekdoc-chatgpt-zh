## 6.2 构建个人知识库所需的技术

为理解6.1节操作及后续示例，需先了解向量数据、数据向量化、RAG 等基础概念。

### 6.2.1 数据向量化

日常使用的结构化数据按预设结构和格式组织，具有明确字段和记录结构，通常以表格存储。

向量是数学中的有序数值序列，可表示为一维数组。向量数据以向量形式表示数据，能方便存储和表示图像、音频、视频等非结构化数据的特征和语义，具有表达简洁、表示统一、支持复杂模型、便于分析和可视化等优点，在数据科学和机器学习中成为基本形式。

数据向量化就是把数据转为机器学习和深度学习算法可处理的向量形式。

个人知识库可整合多种数据源，Cherry Studio 是实现数据向量化的有力工具，支持多种格式和内容向量化。

- 可把本地文件直接拖入知识库，自动进行向量化处理。
- 可把整个文件夹添加到知识库，系统会自动处理支持格式如 PDF、DOCX、TXT、MD 等文件并向量化。
- 可将特定网页 URL 添加到知识库，抓取内容后向量化。
- 可向知识库添加站点地图，批量抓取页面内容向量化。
- 也可在 Cherry Studio 中直接输入自定义文本作为知识库内容向量化。

在 Cherry Studio 中，数据向量化流程如下。

1. 文本提取：从文件或网页中提取文本内容。
2. 预处理：对文本进行分词、清洗等操作。
3. 嵌入模型处理：使用嵌入模型如 BGE-M3 将文本转为向量。
4. 存储向量：把向量保存到知识库中以便后续检索和问答。

### 6.2.2 RAG 技术

检索增强生成 Retrieval-Augmented Generation 是一种在大模型中提升回答质量和准确度的技术，可使大模型在回答时参考外部知识库。核心流程如下。

1. 检索：用户输入问题后，嵌入模型先对问题向量化，然后在知识库向量数据库中检索最相关信息。
2. 增强：将检索到的信息作为上下文输入，增强大模型对问题的理解。
3. 生成：将检索信息与原始问题结合作为新提示词送入大模型，生成最终回答。

RAG 通过检索-增强-生成流程融合信息检索与内容生成，显著提升大模型在知识密集型任务中的表现，能实时获取外部知识，减少幻觉。

### 6.2.3 在 Cherry Studio 中为 RAG 做数据准备

在 Cherry Studio 中构建知识库并实施 RAG 的步骤如下。

1. 构建知识库：新建知识库并选择嵌入模型如 BGE-M3。
2. 添加文件并向量化：将文档、文件夹、网址或纯文本加入知识库，系统自动向量化。
3. 检索与生成：在对话中引用知识库时，Cherry Studio 会通过向量检索找到相关片段。
