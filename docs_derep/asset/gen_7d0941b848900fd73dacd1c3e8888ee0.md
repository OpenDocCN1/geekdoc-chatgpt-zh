AnythingLLM 是一款面向本地化部署的轻量级知识库问答工具，零代码就能跑起来，内置了文档解析和向量嵌入模块，很适合个人玩家或小团队快速搭建私有知识库。它的使用体验比较友好，核心能力主要有三点：可以一键导入 PDF、Docx、Markdown 等常见文档；预置了多种 Embedding 方案可供切换，比如 OpenAI、Ollama、LocalEmbedding 等，并能对接本地大模型；同时支持多用户协同，全部操作都在浏览器里完成。

##### 3. 企业级 GraphRAG 对话方案：Kotaemon
Kotaemon 是 Cinnamon 公司主推的企业级 GraphRAG 框架，把图谱推理和传统向量检索结合在一起，结构化语义检索能力更强。它的主要特点是：采用知识图谱与 RAG 融合的混合推理架构；在项目内部提供可视化的图谱关系界面；支持多轮上下文对话；同时具备企业级认证、数据隔离和部署保障。

##### 4. 企业级 RAG+Agent 统一前端：Open-WebUI
Open-WebUI 是一个统一的本地化前端，支持插件扩展、多模型并行以及多用户协作。此前我们就在该项目里尝试接入 DeepSeek 模型。它的优势在于：多 Agent 能力强，插件可扩展工具链；前后端分离架构，支持多用户协同；可以自定义系统指令和会话参数模板。

##### 5. 企业级多模态交互平台：lobe-chat
lobe-chat 侧重高级交互体验的前端框架，具备多模态接入能力，支持图片、语音、代码、PDF 等多种输入，适配不同模型的推理场景。
