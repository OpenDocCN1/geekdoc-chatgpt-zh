NLP 模型是怎么一步步走到今天的

好在几十年的摸索下来，NLP 圈子里逐渐出现了更高阶的思路和算法，也在深度学习时代里长出了能解决前面那些痛点的技术和语言模型。

统计语言模型的发展轨迹大致可以这样看。

[PRE0]

上半部分讲的是语言模型本身的技术演进，下半部分则是词如何被表示的演进。词向量的学习让语言模型拿到更优质的输入，也就是词的向量形式。下面把图里提到的几个节点简单梳理一遍。

- 1948 年的 N-Gram 模型横空出世，核心做法是用前面 N-1 个单元来预测第 N 个单元，这里说的单元可以是词，也可以是短语。
- 1954 年的 Bag-of-Words 是一种简单常用的文本表示法，把一篇文章简化成一堆词的集合，顺序被丢掉了。每个词对应一个维度，数值表示出现频次。
- 1986 年出现的分布式表示，把词或短语映射成数值向量，语义信息分散到各个维度上，从而能捕捉相似性和关联。它主要靠上下文构建，因此带了较多的语义和句法信息，也缓解了传统 Bag-of-Words 和独热编码带来的词汇鸿沟，比如歧义、同义词问题。
- 2003 年的神经概率语言模型第一次用神经网络来学习词之间的复杂关系，是 CNN、RNN、LSTM 这类神经网络语言模型的思想起点。
- 2013 年的 Word2Vec 是个里程碑，通过训练神经网络来学习词的分布式表示，简单高效。它有两种常见结构：CBOW 用上下文预测中心词，Skip-Gram 用中心词预测周围词。由此得到的词向量能反映相似性、语义关联和句法信息，思想被大量后续模型继承。
- 2018 年后，基于 Transformer 的预训练语言模型成为主流。它用更大规模语料和更复杂的神经结构学习语法语义，即预训练。经过微调后，在机器翻译、问答、分类、情感分析、文本生成等任务上表现突出，不断刷新基准。时至今日，预训练模型已成为大多数 NLP 项目的基础。

因此图上每个节点都为后来技术打下地基，也构成了讲解的线索。语言模型的演进推动了 NLP 的发展，关键跃迁是从规则到统计，再到靠海量语料训练的大模型。

## Transformer 时代：预训练主导一切

以 BERT 为代表的 Transformer 预训练语言模型一出来就备受关注。有了预训练，很多以前难解的问题开始变得可解。

小冰：我们厂里的人老是念叨这个 Transformer 到底是什么？预训练又是什么意思？

咖啡：Transformer 是几乎所有预训练模型共同的底层架构，也是课程的核心，细节后面再讲。NLP 里的预训练，大体上指在大量无标注文本上训练语言模型。训练好的大模型常被称为基础模型或基座模型。训练过程中模型学到词汇、语法、句法结构、上下文等丰富语言知识，为下游任务如情感分析、文本分类、命名实体识别、问答等提供通用且丰富的语言表征。

在早期，BERT 无疑是最具代表性的预训练模型。它通过同时利用前后文，实现对句子结构的深入理解。BERT 之后，大型预训练模型层出不穷，行业进入新阶段，这些模型极大加速了 NLP 进步，为以前难以解决的问题提供了强工具。

预训练加微调的常规打法

不过对应用方来说，大型预训练模型是好消息。预训练模型学会的语义信息和语言知识迁移性很强。应用人员只需对头部或部分参数做适应性调整，通常是在较小规模的有标注数据上做监督学习，让模型适配特定任务。这就是微调。相比从零训练，微调更快、数据需求更少，让 NLP 方案的开发与部署更高效。

这种模式优势很明显。预训练模型提供了通用语言知识，应用方不必自己找语料从头训练，省时省料。微调能快速针对任务优化，降低部署门槛。整体可扩展性强，适配各种 NLP 任务，大幅提升了技术的实用性和普及度。

### 直接用提示和指令驱动大模型

咖啡：不过小冰要记住，近几年随着 GPT 这类生成式大模型的爆发，预训练加微调的模式正被提示 Prompt 或者指令 Instruct 的用法逐步替代。

Prompt 模式和 Instruct 模式的核心想法是：训练阶段模型通过海量文本掌握了语言结构、语法和一定语义，应用阶段只要在输入里给出合适的信息和引导，就能让模型输出更有相关性和可用性的结果。这其实是一种对话，输入提示或指令，模型据此生成输出。

小冰：那 Prompt 和 Instruct 到底有什么区别呢？

咖哥：区别主要在输入形式和任务性质上。

[PRE6]

- **Prompt 模式**：输入通常是一个词或短语，模型据此生成自然连贯的文本。适合生成类任务，如文本续写、摘要。比如下指令“从前”，模型可能接“有个山，山里有个庙……”。
- **Instruct 模式**：输入是一条明确指令，要求模型完成特定任务。适合需要明确指示的场景，如问答、概念解释。例如输入“请给我讲个故事”，模型返回“从前有个山，山里有个庙，庙里有个咖哥给小冰、小雪上课……”。

小冰：你能总结一下 Prompt/Instruct 和预训练加微调的异同吗？

咖哥：相似点先说。两者都依赖大型预训练模型，如 GPT、BERT，在大规模无标注文本上学习通用知识。两者都利用迁移学习，在下游任务上使用预训练模型，减少训练时间和数据需求。

不同点如下。

| 特点 | '预训练 + 微调大模型'模式 | Prompt / Instruct 模式 |

| :-- | :-- | :-- |

| 是否微调 | 在下游任务上微调以适配需求 | 不做微调，通过设计指令生成输出 |

| 学习方式 | 在有标注数据上做监督学习 | 通常不需要标注数据 |

| 任务适应性 | 微调后任务适应性较高 | 依赖提示，适应性可能偏低 |

| 灵活性 | 需针对每个任务单独微调 | 灵活性更高，无需微调，但可能需试错 |

总体看，两种方式都利用了预训练模型的强大能力，但实现路径不同。预训练加微调通过针对性调整让模型更精确；Prompt/Instruct 则直接发挥生成能力，用合适提示解决问题。选哪种取决于任务需求、数据情况以及对精确性和灵活性的权衡。

## 为什么 GPT 天生适合生成

[PRE10]

小冰：BERT 和 GPT 都是预训练模型，它们训练方式有什么不同？

咖哥：了解差异有助于把握语言模型本质。我用初学者的角度解释。

BERT 的预训练像做填空题。模型在大规模文本上随机遮住部分词，然后根据上下文预测被遮住的词，是双向学习。这样学会了句子结构、语法和词汇关联。

GPT 的预训练像文字接龙。模型在大规模文本上学习预测给定上文的下一个词，是单向学习。就像接龙，要根据前面内容写后面。通过这种方式，GPT 学会生成连贯文本，并理解句法语义。

细节后面实战再展开。但我要强调，相比 BERT，GPT 更贴近语言模型本质，因为它的训练过程完整再现了自然语言生成的流程。

BERT 虽然靠双向上下文增强理解能力很“聪明”，但语言模型的核心任务是为给定上下文生成合理的概率分布。实际应用中我们通常需要模型根据上下文续写，而不是填补空白。

GPT 通过从左到右逐词预测，在生成过程中学习到连贯表达、句法和语义信息。早期它没有 BERT 那么耀眼，但后劲很足，为 ChatGPT 的出现奠定了基础。
