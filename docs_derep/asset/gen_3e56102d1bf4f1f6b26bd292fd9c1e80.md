# ID3算法（构建决策树）

ID3 是一种利用带标签训练样本生成决策树的经典方法。它从一棵空树出发不断添加节点，直到树能够正确划分所有样本为止。解往往不唯一，为了兼顾分类效率与泛化能力，最终的树应尽可能精简（图7-18）。

[PRE3]

# ID3 决策树构建流程

用 ID3 构建决策树的常用步骤如下。

+   * 若样本集 A 中的所有样本都属于同一类，则生成对应的叶节点，构建结束

* 从 A 中挑选一个划分属性 B 作为当前判断节点

* 依据 B 的取值把 A 划分为若干子集，生成子节点

* 对每个子节点递归重复上述过程

在 ID3 中，属性挑选的标准是使信息熵最小化，即让同类样本尽量聚集。可通过期望信息量 - Σ p_i log₂ p_i 计算样本集 A 各类别及各属性的不确定度，熵值最小的属性被选为该节点的扩展属性。决策树本质上是分而治之，每次将样本切分为更纯的子集进行迭代优化。

# 判别模型评估与 ROC 曲线

判别模型完成后，可通过绘制 ROC 曲线 Receiver Operating Characteristic curve 来评估性能。

ROC 的概念源自二战期间美国的雷达研究，最初用于依据雷达回波判断敌机。ROC 也称受试者工作特性曲线或接收者操作特性曲线。

绘制 ROC 需要一组带标签的正负样本和模型打分。先构建混淆矩阵进行评价，便于处理我们假设只有两种判定结果，由此得到一个 2×2 的混淆表（表7-1）。

|                | 识别结果 阳性（+）                     | 识别结果 阴性（-）                     | 合 计       |

| :------------- | :-------------------------------------- | :------------------------------------ | :----------- |

# □ ROC曲线的评估方法

ROC 曲线主要有以下三种评估方式（图7-28）。

+   - AUC（Area Under Curve，曲线下面积）值

AUC 即 ROC 曲线下方的面积。AUC 超过 0.9 通常表示分类能力较强，模型对比时常用 AUC 作为标准。

+   - 曲线与左上角的垂直距离

AUC 越大曲线越凸向左上角，因此曲线到左上角的垂直距离 a 越小模型越好。a 最小处往往对应最优阈值。

+   - 正确指数（youden index，又称约登指数）

当 AUC 为 0.5 时模型最差，曲线退化为 45° 对角线。用对角线上与曲线最远的距离 b 所在位置的真阳性率减去假阳性率，即敏感度 + 特异度 - 1，可推断最优参数。

# Hold-out 与交叉检验

除 ROC 外，还可通过切分原始数据集来检验训练模型的识别准确率。原始集可分为训练集和测试集，训练集用于建模，测试集用于评估。分集可避免过拟合。

这与随机森林中随机抽样构建多棵树的思路类似。检验方法如下（图7-24）。

+   * hold-out 检验（holdout method）

把原始数据分为训练集和测试集两部分，先用训练集训练模型，再用测试集检验效果。hold-out 不属于交叉检验。

+   * K 折交叉检验（K-fold cross-validation）

把数据均分为 K 份，其一作测试集，其余 K-1 份作训练集。重复 K 次后取平均值或标准差评估模型。K 通常取 5～10。

+   * LOOCV（Leave-One-Out Cross-Validation）

LOOCV 是 K 折交叉检验的特例，K 等于样本总数，每个样本轮流作为测试集。适用于数据量较少的情况。

# 集成学习

在使用统计机器学习搭建的学习器和分类器进行分类或识别时，为提升单模型性能，构建时通常追求结构简洁。结构越简单，人类越容易理解其行为，难以预测的复杂模型反而反效果。

# 第8章 强化学习和分布式人工智能 | 183

* 更新样本权重

D_{t+1}(i) = \frac{D_t(i)\exp(-\alpha_t y_i h_t(x_i))}{Z_t}

误差率衡量弱分类器的精度。若误差率超过 0.5，说明其好坏与随机猜测无异，需立即终止弱分类器的构建。

在计算样本权重系数并更新 D 时，对分类正确的样本降低权重，对分类错误的样本提高权重（因为 h_i(x_i)={−1, 1}，y_i={−1, 1}）。这样从第一个弱分类器起逐步构建出针对简单特征和复杂特征的分类器。Z_t 用来归一化，使更新后的权重总和为 1。

经过 T 次循环得到 T 个弱分类器，按各自权重叠加即可得到强分类器 H（图8-3、图8-4）。

H(x) = sign(\sum_{t=1}^T \alpha_t h_t(x))

强化学习理论

婴儿出生时大脑并无关于世界的完整信息，人类是在成长中通过与环境交互积累经验。机器同样如此，类脑计算系统正是通过与环境交互实现自主学习。

实际上，机器大多只是依据知识库、规则或统计模型构建的分类器来替代人类判断。让机器在未知环境中像人一样自主改变分类器机制的就是强化学习。

强化学习理论把反复试错获得回报的学习模式用数学模型描述出来。它基于心理学上的操作性条件反射，其名称源于自主行为频率增强的现象——强化。

# 小贴士 心理学上的操作性条件反射

心理学家认为，生物体通过自发反复试错获得的回报会强化相应行为。斯金纳箱实验是典型例子：鸽子按下按钮即可获得食物，通过奖励自发学会按按钮。

假设时刻 t 观测到的环境状态为 s_t，按策略 π 执行动作 a_t 后，按状态转移概率可确定下一时刻 t+1 的状态 s_{t+1}。

回报由状态和行动共同决定。强化学习的目的是不断选择良策，即寻找最优策略使未来期望回报最大化。

# 回报和价值函数

为使选择的动作获得最大回报，还需考虑未来期望回报。

# □ 累积折扣回报

从初始状态到终止状态，智能体采取行动获得的回报总和称为累积回报。参照小贴士。为使累积回报最大化，需用价值函数评价未来状态或行动。价值函数相当于动态规划和 A* 算法中的收益或成本评价函数。

> 小贴士 累积回报

累积回报公式如下。

∑\_(k=0)^(T)_ r_i + k + 1

当 T 趋于无穷大时会演变为无限时段，累积回报可能发散。因此常用累积折扣回报 R_t（图8-8）代替。γ 称为折扣因子。γ 越小越不看重未来回报，未来对决策影响越弱。使 R_t 最大的策略随 γ 变化。通常 γ 设为 0.9 等较大值。
