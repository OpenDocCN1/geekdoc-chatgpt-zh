## 3.1 神经网络如何工作

神经网络是模仿生物神经系统进行信息处理的计算模型。如图 3.1 所示，信息靠大量节点即神经元之间的连接与权重来传递，从而完成输入数据的处理、分类等任务。

[PRE0]

这类网络通常由输入层、隐藏层和输出层组成。图 3.2 所示的是一个典型三层结构。输入层负责接收原始数据，每个节点对应一个特征或维度；隐藏层坐落在中间，一般包含多个节点，用来从输入中提炼高层特征；输出层则基于隐藏层的输出，对输入进行分类或回归等操作。

[PRE1]

训练多采用反向传播算法。把训练样本送入网络后，根据网络输出与期望输出的差距计算损失，再把误差逆向回传，调整连接权重以减小损失。训练完成后，模型即可应对新的数据。

面向自然语言处理 NLP 的神经网络，是用神经网络来解决 NLP 问题的模型族。其主要目标是把文本转成计算机可直接运算的数学表示，进而实现文本分类、情感分析、机器翻译、命名实体识别等任务。

这类模型的核心是词向量，即把每个词映射到向量空间，位置反映其语义与他词的相似度。最常用的词向量方案是 Word2Vec，它用神经网络把词映射到低维空间，让语义相近的词在空间里更靠近。

除词向量外，NLP 神经网络还包含多种结构，例如循环神经网络 RNN、长短时记忆网络 LSTM 以及注意力机制 Attention 等，这些结构能够对文本序列建模，捕捉上下文信息，提升性能。

在训练上，最常用的是反向传播 BP，通过最小化损失函数优化参数，使模型更准确地预测标签或完成任务。优化器方面，除了反向传播，还常配合随机梯度下降 SGD 和自适应矩估计 Adam 等方法。

## 3.2 卷积神经网络核心

卷积神经网络 CNN 是深度学习里应用最广的模型之一，可看作一种含卷积计算、具有深度结构的前馈网络，是深度学习的代表方法。

CNN 通过在输入上滑动固定大小的窗口来捕捉局部特征，从而识别更复杂的模式。起初在图像识别上大放异彩，后来也被证明在 NLP 领域非常有效。在 NLP 中，CNN 的操作基于词向量。与图像卷积不同，文本卷积核通常覆盖若干个连续的词向量，核的宽度往往与输入宽度一致。这样可以捕捉多词组合的特征，并以共享权重的方式计算。相比传统 NLP 方法，CNN 能自动学习特征，无需人工设计，提升效率与灵活性。加入 dropout 和正则化等手段后，还能抑制过拟合，提高泛化能力。

在 NLP 里，CNN 主要用于文本分类和文本表示学习。文本分类中，常选用一维卷积核，长度多为 3、4 或 5，对输入的词向量序列做卷积，把相邻若干词组合并提取特征。随后通过池化把特征压缩成固定长度的向量表示，再进行分类。相比传统的词袋模型，表现更优。

在文本表示学习中，CNN 可用于生成词向量，也可学习句子和篇章的向量表示。采用多个不同尺寸的卷积核即多通道卷积，能从不同角度提取信息，获得更丰富的表示。训练过程中自适应的权重共享机制可有效减少参数，避免过拟合。

除一维卷积外，还有基于多尺度卷积的模型，如 TextCNN 和 Deep Pyramid Convolutional Neural Network DPCNN 等，在分类和表示学习任务上也取得不错效果。下面介绍 NLP 中 CNN 的基本原理。

### 1. 词嵌入

NLP 中的词嵌入 Word Embedding 把每个词映射成低维空间里的向量，用来捕捉语义信息，便于后续任务。

最常用的是 Word2Vec，它是一种基于神经网络的词嵌入模型。Word2Vec 有两种变体：Skip-Gram 和 CBOW。Skip-Gram 以单个词为输入，预测上下文可能出现的词；CBOW 以上下文词为输入，预测中心词。

除了 Word2Vec，还有 GloVe、FastText 等方法。它们基于共现矩阵或神经网络，在大规模语料上训练，把词映射到低维向量，提高 NLP 任务的准确率与效率。

### 2. 卷积层

卷积层常使用一维卷积，每个卷积核可捕捉一个或多个词的特征，如相邻词或重要短语。

例如，如图 3.3 所示，若输入文本为“the country of my birth”，使用大小为 2 的卷积核，可捕捉“the country”“country of”“of my” 和 “my birth”等相邻特征。卷积层的输出通常会进入激活函数，如 ReLU、tanh 等，进一步提炼特征。

### 4. 全连接层

全连接层 Fully Connected Layer 把池化层的输出转换为模型的最终输出。在 NLP 中，通常会加入一个或多个全连接层，并使用 softmax 函数把输出转为概率分布，实现文本分类等任务。

例如，可把一个固定长度向量作为输入，经多层全连接逐步转化为文本。在生成过程中，可通过随机采样或贪心策略得到每个词的概率分布，再据此选择最可能的词进行生成。

卷积网络在深度学习发展中起到关键作用，并在各领域蓬勃发展。回顾计算机视觉史，研究重点长期集中于人工设计鲁棒有效的特征提取方法。卷积网络的出现解放了手工特征提取，提供自动生成特征的方式，从而使其应用广泛。

## 3.3 Word2Vec 词嵌入经典

Word2Vec 是一种经典的词嵌入模型，把词汇表中的每个词表示为低维向量。

ChatGPT 基于 Transformer 语言模型，预训练阶段使用的是 Transformer 中的 self-attention 机制，而非 Word2Vec。

不过在 Fine-tuning 阶段，ChatGPT 会使用词嵌入技术，以便更好地表达输入文本的语义信息。该阶段会把每个词表示为词向量，并通过学习从这些词向量到下一个词的概率分布来训练模型。这些词向量可通过不同方法获得，其中一种就是 Word2Vec。

在自然语言处理中，计算机难以直接处理复杂文字系统，因此把文本转成易处理形式很重要。为此，Word2Vec 由 Google 于 2013 年提出，其思想是通过神经网络学习词间关系，即把每个词转换成向量。训练时，相似词在向量空间中距离更近，不相似词更远。它是 NLP 领域的重要技术。Word2Vec 把单词转为向量表示的过程称为词嵌入，可捕捉语义和语法信息，并用于情感分析、垃圾邮件检测、机器翻译等任务。

Word2Vec 有两种模型，即连续词袋模型 Continuous Bag-of-Words CBOW 和 Skip-Gram 模型，如图 3.5 所示。CBOW 通过上下文词预测当前词，Skip-Gram 通过当前词预测上下文词。

[PRE6]

ChatGPT 在 Fine-tuning 阶段使用类似 Skip-gram 的模型来训练词向量，并把预训练的词向量作为输入不断调整，以更好地适应特定任务。下面详细介绍 Word2Vec 的两种模型。

### 3.3.1 连续词袋模型

连续词袋模型 Continuous Bag of Words CBOW 常用于自然语言处理的词嵌入技术，是 Word2Vec 的一种，主要用于把自然语言中的词转成向量表示。

CBOW 的思路是以窗口内的上下文词预测中心词。输入层为窗口内的上下文词，输出层为中心词，中间的隐藏层为词向量层，用来把输入的上下文词转为向量并加权平均，得到输出层的中心词向量。

具体流程是先构建词典，把每个词映射成唯一整数。然后用每个词的 one-hot 编码作为输入，通过全连接隐藏层得到词向量。在隐藏层中，可通过加权平均把窗口内的词向量组合，得到中心词的向量表示。最后把中心词向量送入输出层训练，得到最终词向量。

以下句为例：“我喜欢吃苹果”。若上下文窗口大小为 2，则 CBOW 的输入为“我吃苹果”，输出为“喜欢”。

训练时，每个词被表示为向量，上下文词向量取平均得到上下文向量表示，用作预测中心词的输入，从而学习词的嵌入表示。

与 Skip-Gram 相比，CBOW 训练更快，对高频词和低频词处理较好。得到的词向量能很好保留语义信息，可用于聚类、分类等，在大规模语料上很受欢迎。

CBOW 也有缺点，例如忽略词序信息，对需要考虑词序的任务表现可能不佳。此外，对生僻词和不常见词效果有限，因其在训练数据中出现次数少，很难获得准确向量。

### 3.3.2 Skip-Gram 模型

Skip-Gram 模型是 Word2Vec 中的一种，是一种基于神经网络的词向量表示方法，能把词转换为向量。与 CBOW 相反，它的目标是最小化预测上下文词与真实上下文词的差异，用当前词预测上下文词。Skip-Gram 相较其他模型训练效果更好、速度更快。

其基本结构是一个浅层前馈神经网络。每个词有两个向量，一个是输入层的 one-hot 编码向量，一个是输出层的特定维度向量，即词向量。训练时，每个词被表示为固定维度的向量，目标是通过最小化输入词与输出词之间的距离来学习这些向量。具体实现常采用负采样 negative sampling 来降低计算量，即在训练时随机选取一些非上下文词作为负样本，把输入词和正负样本一起送入模型训练。

以下句为例：The quick brown fox jumps over the lazy dog. 每个词都被表示为一个独特的词向量。现在要训练 Skip-Gram 模型，让中心词 “fox” 与其上下文关联。

在 Skip-Gram 中，需要确定窗口大小以确定与中心词相关的上下文。窗口大小设为 2，则 “fox” 的上下文为 “quick”“brown”“jumps”“over”。

对这些上下文词在词表中找到其词向量作为输入，目标是训练神经网络，使其能以中心词的词向量预测上下文词的词向量。

把中心词 “fox” 的词向量输入网络，网络输出每个上下文词的概率分布。训练时希望该分布使上下文词的概率最大化。

可用交叉熵损失函数比较预测概率分布与实际上下文词的 one-hot 概率分布，并尝试最小化差异。通过多次迭代优化权重和偏置，使其能准确预测给定中心词的上下文词。

训练完成后，可用得到的词向量表示词，并用于各类 NLP 任务。

Skip-Gram 的优点是可以处理大量语料库，获得更准确的词向量表示。由于词向量间的余弦相似度可衡量语义关系，Skip-Gram 在文本分类、情感分析、机器翻译等 NLP 任务中得到广泛应用。

## 3.4 循环神经网络原理

循环神经网络 RNN 是一种经典的神经网络结构，被广泛应用于序列数据处理，如自然语言处理、语音识别等。与传统神经网络不同，RNN 能对序列逐个元素处理，同时保留上一步的信息，适用于具有时间顺序、逻辑顺序或其他顺序的序列数据。因为它能有效挖掘数据的时序和语义信息，深度学习模型在语音识别、语言模型、机器翻译、时序分析等语言处理问题上因此取得突破。

与前馈网络不同，RNN 的隐藏层节点之间有连接，隐藏层的输入不仅包括输入层的输出，还包括上一时刻隐藏层的输出。这种结构使 RNN 能存储历史信息并作用于后续输出。从结构上看，循环神经网络如图 3.6 所示。图中每个 A 是一个处理单元，同一结构重复使用。

RNN 的处理流程可简单描述如下：

1. 将序列数据按时间步展开，形成时间轴上的序列。
2. 对每个时间步，RNN 接收输入数据和前一时间步的隐状态，计算当前时间步的输出和隐状态。
3. 把当前时间步的输出作为下一时间步的输入，继续处理。
4. 重复步骤 2 和 3 直至完成所有时间步。
5. 最终得到整个序列的输出和最后时间步的隐状态作为序列表示。

在处理长序列时，RNN 面临梯度消失和梯度爆炸问题，即随着时间步增加，梯度值可能越来越小或越来越大，导致模型难以学习有效信息。为此提出了多种改进结构，如长短时记忆网络 LSTM 和门控循环单元 GRU 等。

## 3.5 长短期记忆网络机制

长短期记忆网络 Long Short-Term Memory LSTM 是一种特殊的 RNN，设计目的是解决传统 RNN 处理长序列时出现的梯度消失或梯度爆炸问题。

LSTM 的核心是门控机制 Gate Mechanism，包括输入门 Input Gate、遗忘门 Forget Gate 和输出门 Output Gate。在每个时刻，LSTM 通过这些门控制信息的流动与保留，从而更好地捕捉长期依赖关系。

在 LSTM 中，隐藏状态由记忆单元 Memory Cell 和隐藏状态向量组成。记忆单元负责存储和传递信息，可视为网络的“记忆”部分；隐藏状态向量是从记忆单元中提取的抽象表示，可理解为短期“记忆”。LSTM 能记忆长期和短期信息，得益于其“门”结构，可选择性地去除或增加信息到神经元，门是一种让信息选择性通过的机制，结构如图 3.7 所示。图中三个门分别是输入门、输出门和遗忘门，其中输入门和遗忘门是 LSTM 长期记忆依赖的关键。
