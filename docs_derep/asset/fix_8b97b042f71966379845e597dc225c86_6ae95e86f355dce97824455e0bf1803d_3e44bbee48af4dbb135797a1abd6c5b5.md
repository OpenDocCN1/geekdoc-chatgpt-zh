# 自报人体测量偏差校正的机器学习研究精要

Q4：您是如何修正自报人体测量数据带来的系统偏差的？
A4：我们设计并训练了九套预测方案，用来估计客观实测的身高、体重与体质指数和受访者自行填写数值之间的差异。具体采用的算法为线性回归、Lasso回归、Ridge回归、弹性网络、K近邻、支持向量机、决策树、随机森林以及XGBoost提升树。

Q5：评估这些预测方案时选用了什么指标？
A5：采用均方根误差来衡量拟合质量。该指标体现了预测值与真实值在平均意义上的偏离程度，越小说明还原客观水平的能力越强。

Q6：在全部对比中，哪种方案效果最佳？
A6：XGBoost在训练集与测试集上均取得最低的均方根误差，对身高、体重和BMI的客观水平还原最为精准，同时也最大程度缩小了自报数据与实测数据推算的肥胖流行率之间的差距。

Q7：最优方案带来的改善幅度有多大？
A7：经XGBoost校正后，自报样本平均身高与客观测量的差距下降了22.08%，体重差距下降了2.02%，BMI差距下降了11.14%，肥胖率的差距则下降了99.52%。

Q8：该成果在公共卫生领域有哪些用处？
A8：所构建的机器学习方案可供研究人员与实务工作者校正自报身高体重带来的系统误差，更可靠地估算样本的肥胖流行水平，为政策制定与干预设计提供更扎实的证据。

从发展角度看，掌握某种特定AI使用技能往往会因模型快速迭代而被淘汰。因此，我们必须自问：什么技能才是持久的，经得起时间考验，值得真正投入学习的？

正如书中所展示的那样，提示词工程即是这样一种技能。AI总体趋势是向低代码、无代码发展，因为机器越来越能通过语言与视觉等自然方式理解人类意图。人机交互将越来越少依赖计算机编程技能，而更多依赖我们如何用自然语言有效表达想法。

与编程语言相比，自然语言的优势与劣势都在于其灵活性。自然语言丰富、细腻，能够表达复杂抽象概念；但若使用不当，灵活性也易导致歧义与误解。这正是提示词工程发挥作用之处。

记忆或复制提示词模板的价值有限，真正的力量在于研究者对提示词工程的掌握，能够清晰、有效、创新地撰写提示词，与机器进行深入对话。在不久将来，彼此交流与相互启发，可能超越任何特定AI模型，而成为科学创新的主要驱动力。
