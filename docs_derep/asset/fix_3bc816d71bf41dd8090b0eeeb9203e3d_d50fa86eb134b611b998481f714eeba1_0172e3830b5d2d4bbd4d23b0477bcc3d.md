整套指令虽然篇幅偏长，但完全支持按需裁剪。落地时主要有两种做法。

- 1. 只截取局部指令
若目标仅为抽取判决书中的关键时间线索，可采用如下写法：
> 按如下字段要求，提炼判决书中的要点：
重要事件时间线信息表：序号、时间、事件、结果。
用表格形式呈现。
- 2. 掌握结构化输出指令的三步法
这套方法的精髓在于先吃透裁判文书的信息呈现规律，归纳出所需字段，再让 DeepSeek 按照预设规范进行抽取。实际操作可遵循：
+   (1) 事先研读文档内容，熟悉其结构；
(2) 依据业务实际对字段做结构化规划，提前在指令中定义清楚；
(3) 模型往往不能一次完全吃透要求，需要反复调整指令的表述和结构。例如前述判决书表格化案例，若未加上“逐一”这一限定，只说“整理成表格”，模型就容易一次性输出一张汇总大表，而非图 1-10 中呈现的分表效果。

##### （二）提示词技巧拓展应用
本节围绕“提要求”环节做延伸，指导模型承接更复杂的任务。日常资料梳理中，证据文书摘录、电子化信息填报等场景均可借用。

- 1. 灵活调用提示技巧
判决书提取案例中我们刻意省略了“定身份”的设定。因为任务背景已通过上传电子文档交代清楚，字段设计也已足够明确，以当前模型的理解能力，再额外加上“你是律师”“你是法官”等角色设定，边际增益不大。这也说明提示技巧并非死规定，需要结合具体情况取舍并不断试验。
- ## 2. 管理提示词
优质指令具有重复使用的价值，但结构往往很复杂，重写成本高。调校好的指令一定要妥善保存。目前 DeepSeek、豆包暂不支持一键收藏，可用笔记软件自行管理，也可用 Kimi 等工具保存。

- ## 3. 结构化输出指令
前文让模型将多份表格整理成表格，可直观感受到模型在语言理解基础上高效输出。实际上模型还能输出 Markdown 格式①、JSON 格式②，甚至 Python、C++、JavaScript、Java 等代码格式③。

> > ① Markdown 格式是一种轻量级文本标记语言，在视觉上可快速引导关注重点，无需复杂排版工具，纯文本即可实现结构化展示。
> ② JSON 格式作为一种轻量级结构化数据形式，便于程序解析和集成，在法律数据标准化、自动化流程等场景下应用广泛。
> ③ Python、C++、JavaScript、Java 等均为常见代码格式，可用于让计算机识别需求并主动执行任务。

- 4. 识别特殊格式的小技巧
人工智能时代，部分用户习惯直接复制模型答案。DeepSeek 窗口点“复制”后若直接粘到 Word，常会出现如图 1-12 所示的带标记文本。
[PRE1]
因此看到他人发送的大段文字带有 Markdown 标记，可合理怀疑其为直接复制的模型输出，这类内容需自行再次核验以确保准确。

若不想暴露直接复制的痕迹，有两个简便办法去除标记：
+   (1) 在对话窗口追加指令“请把上文回答复制出来，去掉全部 Markdown 标记”；
(2) 提问前就要求模型使用纯文本格式作答。
如此即可得到干净的纯文本回复。

#### 七、样本示范法：给模型一个参考答案
##### (一)提示词要点
带新员工上手最快的方式是给一份模板或流程指引，对模型同样有效。仅靠长指令很难把需求说透，此时提供参考样本让模型模仿，效果更好。以检索并指定输出格式为例，如表 1-10。

##### （二）提示词技巧拓展应用
样本示范本质上是“讲背景”的延伸，让模型学习并模仿用户行为。法律人拥有大量规范文书，如《人民法院民事裁判文书制作规范》《民事诉讼文书样式》，可直接提供给模型严格模仿。涉外文书方面，广州市律师协会编有《涉外法律文书格式汇编》，亦可按需取用。人工智能时代，多收集优质范本借助模型提升写作水平。

温馨提醒：提供模板示范时尽量使用 Word、Excel 格式，避免使用手写或扫描版 PDF。当前模型对手写、扫描字迹的识别仍不稳定，使用这类文件作为样本可能导致生成偏差。

#### 九、提问迭代术：与 AI 的“深度对话”
##### (一)提示词要点
苏格拉底曾言“我唯一知道的就是我一无所知”。法律人面对海量知识更显局限。而模型在知识储备上近乎全知，可作为导师通过持续追问快速补齐短板。主要提问方式有：

###### 1. 角色扮演式提问
- 提示词示例 1：请你扮演罗翔老师，为我讲解，为什么未成年人性侵案件可以放宽客观证据的标准？
- 提示词示例 2：请你扮演华人神探李昌钰，为我讲解，为什么密室入室盗窃案件中，犯罪现场一定会留下犯罪嫌疑人的犯罪线索？

###### 2. 头脑风暴式提问
面对疑难案件，可让模型放开限制聚合观点。示例：
作为入室盗窃案件的侦办人员，我们在犯罪现场几乎穷尽所有线索，包括指纹和 DNA 等物质交换线索、工具痕迹、“犯罪签名”、监控、天气、时间等，但仍然无法找到有效突破口。请你穷尽一切可能进行头脑风暴，帮我们找到更多挖掘线索的方向。

###### 3. 对立式提问
让模型扮演对手提出对立观点，避免同事间因立场产生情绪。典型场景是商务谈判、模拟法庭。
提示词示例 1：请你扮演谈判高手，我会作为你的谈判对手。我们将围绕一宗大型的人工智能本地化部署硬件的采购事项进行谈判。我作为买方，目的是低价成交。你将以谈判高手的视角，对我提出的盘问进行解答。
提示词示例 2：请你扮演房屋买卖合同纠纷的被告代理人，我扮演原告代理人。现在，我们将围绕法院归纳的“原被告签署的房屋买卖合同是否有效”这一争议焦点展开辩论。我的观点是：
- 1. 双方签署的合同无效，因为……
- 2. …… 
现在，请你发表你的观点。

###### 4. 向导师提问
面对全新领域，可把模型当作导师建立思考框架。
提示词示例 1：我是一名法官，刚从刑事业务部门调动到民事业务部门，从没有办理过民事案件；目前准备审理一起关于虚拟货币的法律纠纷，没有了解过这方面的知识。请充分考虑我的审判业务需要，告诉我应该从哪些方面入手进行学习，并为我制订学习计划。
提示词示例 2：我是一个人工智能小白，不知道什么是“本地化部署”，我需要从哪些问题入手，建立对人工智能的基本认知框架？
提示词示例 3：我是一个不懂技术的文科类中学生，请考虑我的理解水平，用文科生能听懂的语言，为我解释什么是“可编程接口”。
