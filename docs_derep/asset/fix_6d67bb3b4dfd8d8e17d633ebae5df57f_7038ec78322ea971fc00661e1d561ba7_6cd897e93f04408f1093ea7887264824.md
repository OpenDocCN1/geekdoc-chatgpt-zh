# 本地 WebUI + DeepSeek 快速上手

把可视化界面和 DeepSeek 的能力在自己的电脑上连通，可以拆成三步走：先把运行环境独立出来，再让服务跑起来，最后用 Python 做直接请求。下面是可直接复制的最小路径。

**环境隔离**
先按照下面指令生成一个专属的 conda 空间并切换进去。
[PRE0]bash

# 创建一个名为 open-webui 的 Conda 虚拟环境，并指定 Python 版本为 3.11

conda create -n open-webui python=3.11

# 初始化 Conda

conda init

# 重新加载 shell 配置

source ~/.bashrc

# 激活刚刚创建的 open-webui 环境，进入该环境

conda activate open-webui

**部署本体**
使用清华镜像加速安装项目。
[PRE1]bash

pip install open-webui -i https://pypi.tuna.tsinghua.edu.cn/simple

**启动界面**
执行下面命令即可本地打开 Web 页面。
[PRE2]bash

open-webui serve

**代码侧接入**
先装 OpenAI 兼容的客户端。
[PRE3]bash

pip install openai

下面是一份把 Key、服务端地址、模型名填好后就能运行的演示。
[PRE4]python

import os

from openai import OpenAI

from IPython.display import display, Code, Markdown

import requests

import json

# <YOUR_DEEPSEEK_API_KEY>替换为复制的 API key 字符串

ds_api_key = '<YOUR_DEEPSEEK_API_KEY>'

#实例化客户端

client = OpenAI(api_key=ds_api_key,
                base_url="https://api.deepseek.com")

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "你好，好久不见!"}
    ]
)

#输出生成的响应内容

print(response.choices[0].message.content)

#输出完整的响应

print(response)

[PRE11]python

#创建用户消息
user_message = {
    "role": "user",
    "content": "你好，请介绍下你自己。"
}

#调用 DeepSeek-V3 模型
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        system_message,
        user_message
    ]
)

#输出生成的响应内容
print(response.choices[0].message.content)
