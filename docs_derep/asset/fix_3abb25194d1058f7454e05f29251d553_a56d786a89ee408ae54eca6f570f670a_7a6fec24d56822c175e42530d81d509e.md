## 12.10 示例

### 12.10.1 PGVector 简介

本节演示使用 bert_base_uncased 模型生成词向量并写入 PGVector。

PGVector 是专为 PostgreSQL 打造的扩展，设计目标是在原有的 PostgreSQL 环境中直接完成向量检索与计算，而不必额外引入独立的向量数据库。这降低了集成成本，特别是对已经在使用 PostgreSQL 并希望快速获得向量支持的用户来说较为便利。

PGVector 的主要能力有：

- （1）与 PostgreSQL 紧密融合：作为数据库扩展，可在 PostgreSQL 内部存储与查询向量数据，无需迁移数据或更改应用架构。
- （2）SQL 易用：采用标准 SQL 语言进行查询，适合习惯 SQL 的用户。
- （3）数据模型灵活：可与常规表结构组合，查询时仍可使用标准 SQL 语法。
- （4）新型索引：例如 Hierarchical Navigable Small Worlds（HNSW）索引，其要点是通过连接邻近向量来提升性能与召回率，从而在近似查询时更精准地找到最近邻居。
- （5）快速距离计算：支持在 HNSW 索引上加速距离计算。
- （6）并行构建索引：支持并行向索引写入数据，可更方便地从多个来源同时加载数据。
- （7）更新与删除：PGVector 支持更新和删除操作，而很多其他 HNSW 实现并不提供该功能。
