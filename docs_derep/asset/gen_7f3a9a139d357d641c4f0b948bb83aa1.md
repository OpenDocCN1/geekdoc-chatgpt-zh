AI 产品必备术语清单

在 AI 落地与产品管理中，这些缩写每天都在出现，快速对齐含义能省下很多沟通成本。

**Milvus**
面向海量向量检索的开源数据库，常被用于 AI 搜索和 RAG 相关的应用场景。

**OCR**
Optical Character Recognition 的缩写，光学字符识别。核心功能是把图片或扫描件里的文字识别出来并转为可编辑文本。

**OKR**
Objectives and Key Results，目标与关键成果法。一种用可量化的结果来追踪目标达成进度管理方法。

**PDCA**
Plan-Do-Check-Act 的循环。计划执行检查处理的闭环，是持续改进和质量管理的经典做法。

**POC**
Proof of Concept，概念验证。通过搭建最小可用原型来检验技术或商业上的可行性。

**PRFAQ**
Press Release and FAQ。亚马逊流行的产品思路，要求在设计初期先写好产品发布稿和常见问答，以倒推需求。

**Prompt Engineering**
提示词工程。围绕大模型设计和优化提示，以获得更符合预期的输出结果。

**RACI**
Responsible Accountable Consulted Informed。一种职责划分矩阵，用来明确项目里谁负责、谁拍板、谁咨询、谁知情。

**RAG**
Retrieval-Augmented Generation，检索增强生成。通过从外部知识库检索信息来提升大语言模型回答的准确性。

**RAGAS**
Retrieval-Augmented Generation Assessment Score。专门用来评测 RAG 系统输出质量的一套工具。

**RAGFlow**
开源的 RAG 搭建框架，主打低代码和快速部署，适合企业把内部知识接入到问答系统。

**ROI**
Return on Investment，投资回报率。用以衡量投入资金所带来收益的比例。

**RPA**
Robotic Process Automation，机器人流程自动化。用软件机器人自动完成重复性的办公流程。

**SDK**
Software Development Kit，软件开发工具包。为开发者提供接口、示例代码和文档，方便快速集成。

**SCAMPER**
创意思考方法，包含 Substitute 替换、Combine 组合、Adapt 借鉴调整、Modify 修改放大缩小、Put to other use 再利用、Eliminate 去除精简、Reverse 颠倒重排，目的是激发创新灵感。

**SFT**
Supervised Fine-Tuning，监督微调。用标注好的数据对大模型进行再训练，使其更好地贴合特定业务。

**SLA**
Service Level Agreement，服务等级协议。明确系统可用性、性能表现以及技术支持响应时间等要求。

**SOP**
Standard Operating Procedure，标准作业流程。把作业步骤标准化、可复制，形成可执行的指引文档。

**SRE**
Site Reliability Engineering，站点可靠性工程。用软件工程手段提升系统稳定性和运维效率。

**SWOT**
Strengths Weaknesses Opportunities Threats 分析法。用于评估自身优势劣势以及外部机会威胁的战略工具。

**Task**
在 CHAT 提示词框架里指行动。用来明确告诉模型输出的格式、步骤或流程。

**TCO**
Total Cost of Ownership，整体拥有成本。评估系统上线后长期运行的总花费。

**UX**
User Experience，客户体验。衡量 AI 工具或系统在实际使用中是否友好、是否好用。

**Vector Database**
向量数据库，专门存储和检索高维嵌入向量的系统。借助近似最近邻 ANN 算法实现毫秒级的语义相似搜索，为 RAG 提供可扩展的上下文检索能力。典型实现包括 FAISS、Milvus。

**Vector Store**
向量存储库，是持久化保存嵌入向量并实现高效检索的组件。同样依赖 ANN 算法完成语义相似性的毫秒级检索，是语义搜索和 RAG 的关键支撑。

**Zero-shot / Few-shot**
零样本 少样本学习。指大语言模型在没有示例或仅有少量示例的情况下就能完成预测任务的能力。
