# 第一章

# 定位：GAI如何辅助教师做课程设计

具备启发性内容生成、对话情境理解、序列任务执行与程序语言解析四项核心能力的生成式人工智能正快速发展，其在教育领域的应用愈加受到关注。2023年8月，国家互联网信息办公室、国家发改委、教育部等七部门联合发布《生成式人工智能服务管理暂行办法》，鼓励GAI在各行业创新应用并推动生态构建。课程教学领域的应用生态已成为重要探索方向。需注意，GAI在原创性知识生产上无法完全替代人类，但在辅助创新过程、解决复杂问题与促进高阶思维方面优势明显，因而在革新课程设计上潜力巨大。

本章从技术基础、基本模型与教师认知三方面回应GAI何以革新课程设计、GAI赋能课程开发的基本模型、革新课程设计的核心原则与教师认知三问。

## 第一节 GAI何以革新课程设计

探讨GAI如何革新课程设计，先要把握其技术前景与基础。GAI引发的教育变革并非简单工具叠加，而是通过重构学习者分析与目标规划、教学模式选择、教学内容组织、学习资源开发、评价与改进的过程，实现从教师经验主导向人机智能协同的范式迁移。

### 一、GAI革新课程设计的技术前景

技术前景可概括为智能化学习内容生成、人机协同个性化学习支持、立体化评价反馈体系构建三个方向，分别扮演经验型教学设计助手、智慧学习伙伴、智能评价专家角色。

**（一）智能化的学习内容生成——经验型教学设计助手**

GAI内容生成能力持续增强，教师可在其辅助下实现课程内容的智能迭代。GAI能依据学生学习特征、认知水平与兴趣偏好生成个性化学习材料，如按阅读水平定制文本、设计梯度数学问题、布置分层科学探究任务。精准供给提升学习兴趣并培养创新思维与问题解决能力。对教学经验不足的新手教师，GAI可提供全流程教学设计支持。以ChatGPT、文心一言、DeepSeek等大语言模型为例，它们能协助完成教学方案初稿、提供多样化资源建议并支持方案持续优化。经教育专业训练的大模型还能支持作业设计与批改，提升教学效率。

**（二）人机协同的个性化学习支持——智慧学习伙伴**

随着对话交互智能化，教师可设计更多学生与GAI互动的任务。互动既提供个性化知识建构支持，也提升人机协同能力与认知水平。未来GAI有望担任智能学伴或虚拟教师，推动课堂从教师主导学生响应转向学生主动智能支持的探究式学习。GAI辅助教师通过认知冲突与即时反馈帮助学生从表层认知跃迁至深层理解。传统学习受制于知识与思维同质化及教师发散指导力不足，师生互动难以达效。GAI作为智慧学伴可弥补不足，实现有问必答、有求必应的个性化支持，并支持机—生、生—机—生等协作模式，促进批判性思维等高阶能力发展。

**（三）立体化的评价反馈体系构建——智能评价专家**

基于证据的教与学反思是学习进阶关键。GAI能快速理解多模态数据并进行分析、总结、点评、建议、批改、反馈。依托强大多模态处理能力，GAI可助力构建立体化学习评价体系。例如将学生作品与评价标准输入，GAI可模拟专家口吻提出针对性建议并迭代优化；也可对学习成果进行智能诊断，用通俗语言帮助学生正向看待错误并借助有效试错深化认知。教师借助GAI数据分析可构建智能初评、同伴互评、教师终评的多层次体系，以文本、图像、音频、视频等形式提供及时全面反馈与改进建议。

### 二、GAI革新课程设计的技术基础

应用场景背后依托哪些核心技术？下文以教师熟悉场景解读四大关键技术。

**（一）数据驱动的学习分析——教育行为的显微镜**

GAI赋能学习分析体现在优化分析思路、辅助分析过程、提升分析素养三方面。GAI拥有较强语言理解与生成能力，能像显微镜一样精准识别利益相关者需求与意图，并据此生成或优化指标、思路、步骤与方案，以易懂方式呈现，使学习分析更清晰高效，不受素养水平限制。分析过程中教师可随时与GAI多元交互，解答难题并养成智能时代学习分析习惯。更重要的是，教师可通过GAI持续学习，提升技能与复杂问题解决能力，增强智能时代学习分析素养。

**（二）自然语言处理——课堂对话的智能翻译官**

自然语言处理技术发展使GAI具备类人语言理解与生成能力，为教育带来变革。NLP使GAI能驱动自动化分析任务，并通过人类反馈强化学习不断优化结果，在教育场景打造互动性强、个性化的学习材料。智能辅导系统可根据课堂回答调整难度，或按兴趣自动生成故事与练习题，增强趣味性。该能力帮助教师理解课堂对话深层意义，挖掘学习信息，破解高阶思维评价难点。

**（三）深度学习算法——个性化教学的神经中枢**

深度学习模仿人脑工作方式。在课程设计中，深度学习算法可依据学生个性化需求调整内容，为每位学生定制独特学习路径。基于超大规模训练数据与Transformer架构，教育大模型展现卓越理解力，能综合素质相关数据。多模态数据处理上，模型将图片、视频、音频转为文本，解决异构数据难题；在不平衡数据分析中，自注意力机制与位置编码捕捉上下文关系，准确把握语境，为因材施教提供可能。例如视觉型学习者获得图表与视频资源，听觉型学习者获得音频材料，极大提升兴趣与效果。

教师将教学智慧与智能技术融合带来无限可能。正如PPT未取代板书而成为新表现形式，GAI核心目的不是取代教师，而是帮助教师从容运用智能工具，使教学更高效、高质。

## 第二节 GAI赋能课程开发的基本模型

敏捷课程开发模型与泰勒课程开发模型是两大重要框架。前者通过小规模交付与持续反馈不断改进质量，强调快速响应与灵活调整；后者强调系统性与逻辑性，确保各环节紧扣教育目标。下文介绍二者并展示GAI的作用。

### 一、GAI支持的敏捷课程开发模型

该模型基于迈克尔·艾伦提出的逐步逼近模型发展，追求交付速度与质量最优，通过高频次小规模交付与反馈循环提升课程品质。通常包括调研分析、迭代设计、迭代开发三个阶段。

现有研究集中于理论构建与教师培训。理论上基于敏捷教学设计提出快速交付、迭代开发、多方参与、自主管理、协作沟通、工具支持、任务反馈、技术环境等原则，并提出学习者本位、动态管理、过程交付、群智共创等实践建议。培训上强调以关键任务为线索强化技术培训，优化敏捷课程内容。

**1.调研分析阶段**

此阶段GAI用于挖掘师生需求以实现开发目标。GAI可结合纸质问卷或面对面访谈快速归纳海量学生数据，提升效率并揭示潜在学习趋势，明确实际需求。随后借助GAI细化课程目标，将学生兴趣与个性数据输入对话界面，定制科学、针对、可行、创新的教学目标。在内容选配阶段，学情分析至关重要。教师需借助GAI把握知识水平、学习能力与兴趣爱好，确定起点与难点，选取兼顾学科知识与创新思维培养的内容。

**2.调试设计阶段**

重点是对GAI使用进行调试并据此整体规划与开发。鉴于技术快速迭代，不同平台与版本效果差异明显，每位使用者也有偏好平台，因此前期需多次尝试并择优推荐，同时细致反馈使用效果。

为确保最大效用，开发者需结合主题与内容，基于前期调研结果，兼顾教师需求与学生需求，设计符合教育规律且体现技术前沿的课程。GAI可丰富教学内容，如利用自然语言处理创作出贴近实际的案例与故事，使抽象知识具体生动；借助图像识别与生成技术提供直观视觉素材，如动画与图表，激发兴趣并提升理解力。

**3.迭代开发阶段**

主要任务是基于教育实践优化课程，通过敏捷版本实践持续改进内容。环境变化推动创新，敏捷课程可快速响应政策调整、社会热点与学生即时反馈，优化目标、内容、方法与评价体系，确保与实际需求同步。因此迭代开发是整个模型的关键环节。
