### 搭建一键批量生成数字人视频的工作流
在内容生产里，传统拍摄加后期成本高、效率低，很难支撑高频多变的需求；固定的人设和脚本也让互动感不足。对此可参考下方案例，把数字人合成能力与Coze平台结合，打造可自动适配场景并快速量产的视频方案，具体步骤如下。

（1）参照前文做法新建一个 spoken_digital_human 工作流，如右图所示。

[PRE9]
（2）进入编辑页，先新增循环节点，再接入飞影数字人插件的 create_lipsync_video2 节点。在循环体里加入选择器、终止循环节点，以及飞影数字人插件的 inspect_video_creation_status 节点和定时器插件的 time_wait 节点。节点连接顺序为开始-create_lipsync_video2-循环-循环体-inspect_video_creation_status-选择器如果-time_wait-循环体-结束，选择器的否则分支接选择器否则-终止循环，如下图所示。

[PRE10]
（3）打开开始节点配置，把 input 变量名改为 text，点击输入右侧的加号新增 speaker_id、digital_human_id、hifly_id 三个变量，类型均设为 String，除 hifly_id 外其余勾选必填。这里的 text、speaker_id、digital_human_id、hifly_id 分别对应口播文案、声音ID、数字人ID、飞影ID。填写飞影ID会关联账号并消耗积分，不填则免费但生成会更慢，所以该项未设为必填。

[PRE11]
（4）在 create_lipsync_video 节点配置里，将 digital_human_id 的取值设为开始-digital_human_id，speaker_id 设为开始-speaker_id，text 设为开始-text，hifly_id 设为开始-hifly_id，如右侧图所示。该节点负责根据传入参数生成口播数字人。

[PRE12]
（5）在循环节点配置中，选择无限循环，输出里设置 output 取值为 inspect_video_creation_status-video_Url，如左侧图所示。因为生成时长不确定，需要持续轮询直到完成，完成后将下载链接作为输出。

[PRE13]
（6）在 inspect_video_creation_status 节点配置里，把 job_id 的取值设为 create_lipsync_video2-job_id，hifly_id 设为开始-hifly_id，如右侧图所示。job_id 即作品编号，用于查询任务是否完成并获取链接；hifly_id 的使用规则同前。

[PRE14]
（7）在选择器节点配置里，于条件分支如果面板新增条件，上方变量选 inspect_video_creation_status-status，条件选等于，下方填1；再新增一条，变量同样选 inspect_video_creation_status-status，条件选等于，下方填2。将且改为或，如图所示。当状态为1或2时继续循环，否则结束循环。

[PRE15]
（8）在 time_wait 节点配置里，seconds 的取值填入10，如左侧图所示。该节点用于在两次查询间加入10秒间隔，避免请求过于频繁。

[PRE16]
（9）终止循环节点用于立刻跳出当前循环，无需配置。在结束节点配置里，把 output 设为循环-output，如右侧图所示，最终把循环输出的数字人下载链接返回给用户查看。

## 第7章 OpenClaw部署、飞书接入与技能实战精要

### OpenClaw 全景概览

#### OpenClaw 究竟是什么
OpenClaw 是2026年初迅速走红的开源智能体框架，由 Peter Steinberger 于2025年11月创建。它被定位为能直接操控电脑或手机、本地部署、自主完成真实任务的数字员工，与只能对话的传统AI不同，OpenClaw可以处理读邮件、管理日程、操控浏览器、自动化文档等实操任务。
该项目坚持本地优先、数据不上云的原则，支持通过WhatsApp、Telegram、飞书、钉钉、QQ等消息通道交互，并拥有丰富的技能生态。
2026年2月，其GitHub星标在四个月内突破25万，超过Linux和React等长期领先项目，成为增长最快的开源软件之一，如下图所示。
2026年3月，OpenClaw热度席卷全国两会。全国政协委员王坚指出，人工智能对中小企业最为友好，而一人公司的出现正是这一趋势的体现。与此同时地方政府也在跟进，深圳龙岗区率先发布龙虾十条征求意见稿，拟最高补贴200万元；无锡高新区随后推出养龙虾十二条，单项补贴最高500万元，意在以真金白银推动AI智能体在智能制造、智慧政务等领域的深度应用。

#### 为何说OpenClaw是里程碑
市场上AI产品众多，为何单说OpenClaw是里程碑？关键在于它突破了以往产品的局限。
回顾发展路径。第一代是问答机，代表Siri、小爱同学、小度。特点是一问一答，只能执行预设指令，稍微复杂就无能为力，本质像玩具，只能查天气、设闹钟，难以真正助力工作。
第二代是聊天机，代表ChatGPT、Claude、文心一言、DeepSeek。特点是一问一答，能力很强，但不主动做事，本质像顾问，能给建议却不执行。
第三代是AI Agent，代表OpenClaw。特点是能理解指令、规划任务、执行操作并返回结果，第一次真正把AI从工具变为员工，本质像24小时在线的私人助理。
OpenClaw的革命性体现在三点。
突破一：打破应用壁垒。它不仅能接入微信、钉钉、邮件等通道，更能理解通道里的任务并调度其他应用完成。例如微信群里看到会议通知，就能自动调用日历App创建日程，并调用邮件App发送会议纪要。
突破二：长期记忆。过去的AI每次对话都重新开始，你的偏好、习惯下次就忘。OpenClaw拥有记忆系统，记得你是谁、喜欢什么、之前聊过什么。像一位熟悉的老员工，而非每次初识的陌生人。你无需反复交代背景和需求。
突破三：自主执行。过去的AI需要一步步指引，每次都要确认，更像执行者而非独当一面的人。OpenClaw接收高层指令后自行规划、执行、解决问题，你只需最后检查结果。像成熟员工，交代任务后自行完成，无需全程盯着。
若把AI比作厨房，第一代像微波炉，能热剩饭却做不了复杂菜。第二代像智能灶，按菜谱做菜但需一直看着。OpenClaw像星级厨师，你说要一桌家宴，它自己买菜、备料、烹饪、摆盘，最后端上完整菜肴。

### OpenClaw 能解决哪些问题
传统AI工具门槛较高，用户需学习复杂提示词工程、理解API调用，还要有一定技术背景才能发挥价值。
OpenClaw通过极致的产品设计大幅降低门槛。用户只需像发微信一样告诉OpenClaw想要做什么，系统会自动解析需求、调用相关工具、完成执行并返回结果。
这种一句话办事的交互，让AI从技术专家的专属工具，变成普通用户也能轻松使用的生产力助手。
OpenClaw的另一核心价值在于高度可定制性。
