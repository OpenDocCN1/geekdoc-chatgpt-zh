##### （2）字符串

Arduino 支持两种文本表达方式：字符数组与 String 对象。字符数组操作简洁、占用资源低，适合固定文本或资源紧张的场景。String 对象功能更丰富、调用更便捷，适合需要频繁处理文本的任务。

##### （3）字符数组

字符数组是 C 风格的文本表示，以空字符 '\0' 收尾。此方式内存利用率高，适合存放固定的文字信息。例如声明 char greeting[] = "Hello, Arduino!";。字符数组支持逐字符修改，如把首字符改小写 greeting[0] = 'h';，如图1-27 所示的案例先用串口输出原始字符串，随后演示直接修改数组中单个字符，将首字母由大写改为小写，再输出修改后的结果。这种精细控制单个字符的能力是字符数组的重要特点，在需要精确操控文本内容时很有用。

图 1-27 字符数组

字符数组在通信协议、显示输出和传感器数据处理中应用广泛。因为内存连续分配，操作效率较高。配合 C 标准库函数如 strcpy()、strcat() 等，可实现基础的文本操作。

##### （4）String 对象

图1-28 展示了 Arduino String 对象的基本操作。String 类采用面向对象的文本处理方式，支持动态内存管理和丰富的方法。示例演示了三个关键操作：字符串连接 concat 方法用于合并多个字符串；子字符串提取 substring 方法可以获取指定区间；长度获取 length 方法返回字符数。这些操作在 setup() 中执行，结果通过串口输出，充分体现 String 类的灵活性和易用性。

String 对象会自动管理内存分配和释放，无需预设长度，适合处理动态文本，如用户输入或数据解析。它提供 substring()、indexOf()、replace()、toInt() 和 toFloat() 等便捷方法，简化文本操作。然而在 Arduino 可用 RAM 受限的环境下，频繁修改 String 对象会触发内存重分配，可能造成内存碎片。可以通过 reserve() 预分配空间或限制对象作用域来优化使用。

使用数组和文本时的注意事项如下。

**内存管理策略：** Arduino 的 RAM 通常只有几 KB，合理管理内存至关重要。使用大型数组或长文本需格外谨慎。建议将固定文本存入程序存储空间 PROGMEM，避免占用宝贵 RAM。选用合适数据类型可显著节省内存，如用 byte 替代 int 存储小范围数值。优先使用预分配的字符数组而非动态 String 对象，可防止内存碎片化。

**边界检查的重要性：** 数组越界是导致程序崩溃或难以诊断错误的常见原因。访问数组前应始终验证下标有效性，尤其在处理用户输入或循环时。合理设定数组大小，并用常量或宏定义管理长度，便于维护。在文本操作中使用安全函数可防止缓冲区溢出。虽然边界检查会增加代码量，但能避免更严重的系统问题。

**避免动态内存分配：** 在 Arduino 开发中应尽量避免动态内存分配，因频繁分配释放易产生内存碎片。推荐静态分配，包括固定大小数组、预分配缓冲区和全局变量。若确实需要灵活使用内存，可考虑内存池或循环缓冲区管理。将常量数据存入 PROGMEM，可有效减轻 RAM 压力。

**文本拼接优化：** 频繁拼接文本会影响内存性能并可能导致碎片。使用 String 对象时，通过 reserve 预留足够空间可减少重分配次数。使用字符数组时，确保缓冲区足够容纳拼接结果。sprintf 函数可一次性完成复杂格式化，避免多次拼接，在循环中操作文本时尤其需注意性能。

**多维数组的内存考虑：** 多维数组便于组织复杂数据，但内存消耗随维度增加显著增长。使用前需评估总内存需求并考虑替代方案。例如可用一维数组配合下标计算模拟多维结构，或采用结构体数组组织相关数据。对大型数据集，使用 SD 卡等外部存储更实际。

**文本与字符数组的选择：** 选择字符数组还是 String 对象需根据应用场景权衡。字符数组内存效率高、执行快，适合固定或较短文本，但需手动管理内存和边界。String 对象提供自动内存管理和丰富方法，适合动态文本和复杂操作，但可能产生碎片。实际项目中结合使用通常效果最佳。

数组和文本是 Arduino 项目中组织和处理数据的基础工具，支持数据采集、用户界面设计、通信协议实现等多种功能。正确选择和使用这些数据结构能显著提升程序效率和可读性。在复杂项目中，合理运用数组和文本可使程序更模块化、易维护，同时在内存使用和性能间取得平衡。深入理解并熟练掌握数组和文本的使用技巧，是开发高质量 Arduino 项目的重要基础。

#### 1.4.4 数据运算

Arduino 编程中的数据运算是实现各种功能的基础。运算符作为语言核心，包括算术、逻辑、比较、位和赋值运算符，每种都有特定用途。掌握这些运算符对编写高效程序至关重要。

##### （1）算术运算符

算术运算符是 Arduino 编程中最基础的工具，用于执行数学计算，包括加、减、乘、除和取模，既适用于整数也适用于浮点数。

**① 加法（+）：** 加法运算符用于数值相加，在 Arduino 中应用广泛。既可处理简单数值累加，也可用于计数器更新、数组元素求和等场景。

图1-31 展示了加法运算的基本用法。程序先定义两个整型变量 a 和 b 分别赋值为 5 和 3，通过加法运算符求和，结果存入 sum，最后用串口输出结果为 8。该示例说明了加法在变量运算中的直接应用，同时展示了 Serial.print() 输出运算结果，这在调试时很有用。

加法运算符常与循环配合，实现数据累积计算。例如读取多个传感器数据并计算平均值时，需先累加所有数值。也可用于时间累计、距离计算和各种计数场景。

**② 减法（-）：** 减法运算符用于计算两数差值。在 Arduino 项目中常用于计算时间间隔、距离差值、温度变化等。

图1-32 所示的减法示例演示了基本减法操作。程序定义两个变量，通过减法运算符计算差值并存入 difference，串口输出结果。该示例适用于需要计算变化量的场景，如温度变化监测、位置偏移计算等。在控制系统中，通过计算目标值与当前值的差值，可实现精确反馈控制。

减法运算符还可用于数组下标反向遍历和倒计时实现。在处理时间戳时，减法运算可帮助计算事件间的时间间隔。

③ 乘法（*）：乘法运算符用于计算数值的乘积，在单位转换和比例缩放中作用明显。乘法示例见图1-33，展示了如何用乘法运算符进行数值计算。程序中两个变量相乘得到乘积并通过串口输出。这种运算在传感器数据处理中常见，例如将原始 ADC 读数转换为实际电压值时需乘以转换系数。在 PWM 控制中，乘法可用于调整占空比，实现 LED 亮度或电机速度的精确控制。

乘法运算符在图形展示和动画效果中也扮演重要角色，用于坐标变换和缩放。计算功率、面积等物理量时也离不开乘法运算。
