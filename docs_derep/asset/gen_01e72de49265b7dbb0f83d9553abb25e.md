### 5.2.3 嵌套程序的紧凑性

根据推论 5.2.4，若 $S$ 为 $\Pi$ 的一回答集，则 $S$ 必封闭于 $\Pi$ 且受 $\Pi$ 支承。反之则不成立。典型反例为程序 $\Pi = \{A \leftarrow A\}$，其唯一回答集为 $\emptyset$；集合 $\{A\}$ 虽受 $\Pi$ 支承且封闭于 $\Pi$，却非回答集。为排除此类程序，可引入基于层次映射的紧凑性作为一句法约束条件。

层次映射 $\lambda$ 定义为从文字集到自然数集（可推广至序数类）的偏函数。

### 定义 5.2.9

称嵌套程序 $\Pi$ 在文字集 $S$ 上紧凑，当且仅当存在层次映射 $\lambda$，使得对 $\Pi$ 中任意规则 $C \leftarrow B, F$ 满足：

- 若 $L \in \mathbf{GLit}_C \cap S$，则 $\lambda(L) > \max \{ \lambda(K) \mid K \in B \cap S \}$；

- 若 $\Pi$ 在 $\mathbf{GLit}_\Pi$ 上紧凑，且对每一规则 $C \leftarrow B, F \in \Pi$ 及任意 $L \in \mathbf{GLit}_C$，均有 $\lambda(L) > \max \{ \lambda(K) \mid K \in B \}$，

则称 $\Pi$ 为紧凑程序。

习惯上，对任一文字集 $B$，记 $\max(\lambda(B)) = \max \{ \lambda(K) \mid K \in B \}$。

### 引理 5.2.8

设 $\Pi$ 为嵌套程序，$S$ 为协调文字集。若 $(\Pi(S), S) \in \mathcal{A}(\Pi)$，则存在子程序 $\Pi' \subseteq \Pi(S)$，使得 $(\Pi', S) \in \mathcal{A}(\Pi')$ 且 $\Pi'$ 在 $S$ 上紧凑。

证明：不失一般性，假设 $SM(\{ C \mid C \leftarrow B, F \in \Pi,\ B = \emptyset \}) \neq \emptyset$。否则 $\mathcal{A}(\Pi) = \{ \emptyset \}$，取 $\Pi' = \emptyset$ 即可。令 $S = \cup_{n \ge 0} S_n$，$\Pi(S) = \cup_{n \ge 0} \Pi(S_n)$，其中：

$S_0 \in SM(\{ C \mid C \leftarrow B, F \in \Pi,\ B = \emptyset \})$

$S_n \in SM(\{ C \leftarrow B, F \in \Pi \mid B \subseteq S_{n-1} \})$

$\Pi(S_n) = \{ C \leftarrow B \in \Pi \mid B \subseteq S_{n-1} \}$

按如下方式构造 $\Pi'$：

对 $n > 0$，$\Pi'_0 = \{ C \leftarrow B, F \in \Pi(S_0) \mid B = \emptyset \}$

$\Pi'_n = \{ C \leftarrow B, F \in \Pi(S_n) \mid \mathbf{GLit}_C \cap S_{n-1} = \emptyset \}$

$\Pi' = \cup_{n \ge 0} \Pi'_n$

显然 $\Pi'_n \subseteq \Pi(S_n)$ 且 $\Pi' \subseteq \Pi(S)$。

利用数学归纳法易证：对 $n \ge 0$，$S_n \in SM(\{ C \mid C \leftarrow B, F \in \Pi'_n \})$，从而 $(\Pi', S) \in \mathcal{A}(\Pi')$。

基础步：由 $\Pi'_0 = \Pi(S_0)$ 直接得 $S_0 \in SM(\{ C \mid C \leftarrow B, F \in \Pi'_0 \})$。

归纳步：假设 $S_n \in SM(\{C \mid C \leftarrow B, F \in \Pi'_n\})$。若 $\Pi'_{n+1} = \Pi(S_{n+1})$ 则归纳成立。仅需考虑 $\Pi'_{n+1} \neq \Pi(S_{n+1})$ 的情形。

对任意 $C \leftarrow B, F \in \Pi(S_{n+1}) \setminus \Pi'_{n+1}$，存在 $L^* \in \mathbf{GLit}_C \cap S_n$，即 $L^* \in S_n$。由 $S_{n+1}$ 的极小性可推得 $S_{n+1} \in SM(\{C \mid C \leftarrow B, F \in \Pi'_{n+1}\})$。

构造层次映射 $\lambda$ 如下：

对任意 $L \in S$，若 $L \in \mathbf{GLit}_{\text{Head}(\Pi')}$，则 $\lambda(L) = 0$；

对任一 $n \geqslant 1$，若 $L \in \mathbf{GLit}_{\text{Head}(\Pi \setminus \Pi'_{n-1})}$，则 $\lambda(L) = n$。

易验证 $\Pi'$ 在 $S$ 上紧凑。

注：$(\Pi, S) \in \mathcal{A}(\Pi)$ 一般不具备紧凑性。例如程序 $\Pi = \{p; q \leftarrow q,\ q \leftarrow p,\ p \leftarrow \text{not } r\}$，虽 $\mathcal{A}(\Pi) = \{\Pi\}$，但 $\Pi$ 非紧凑。实际上对 $\Pi$ 的回答集而言，规则 $p; q \leftarrow q$ 是冗余的。上述结果表明，通过移除冗余规则，嵌套程序可被转化为紧凑形式且保持 $\mathcal{A}$ 算子结果不变。

基于此可导出回答集特征的基于紧凑性的变体。

### 定理 5.2.4*

设 $\Pi$ 为嵌套程序，$S$ 为协调文字集。$S$ 是 $\Pi$ 的回答集，当且仅当存在 $\Pi' \subseteq \Pi$，使得：

- (1) $(\Pi', S) \in \mathcal{A}(\Pi')$；
- (2) $\Pi'$ 为 $S$-相容且在 $S$ 上紧凑；
- (3) 对任意规则 $C \leftarrow B, F \in \Pi \setminus \Pi'$，有 $B \cap \mathbf{GLit}_C \subseteq S$ 或 $S \not\models_n B, F$。

证明：

（充分性）令 $\Pi' = \{C \leftarrow B, F \in \Pi \mid S \vDash_n (B, F)\}$。由 $(\Pi', S) \in \mathcal{A}(\Pi')$ 及 $\Pi'$ 的 $S$-相容性，依推论 5.2.3 得 $\Pi' \subseteq \Pi$。对任意 $r = C \leftarrow B, F \in \Pi \setminus \Pi'$，因 $S \vDash_n B, F$，按引理 5.2.6 有 $(\Pi \cup \{r\}, T) \in \mathcal{A}(\Pi \cup \{r\})$，其中 $T \in SM(S \cup \{C\})$。因 $S \vDash_n (B, F)$，结合“条件（3）”得 $S = C$。故 $T = S$ 且 $(\Pi' \cup \{r\}, S) \in \mathcal{A}(\Pi' \cup \{r\})$。因此 $(\Pi'', S) \in \mathcal{A}(\Pi'')$。显然 $\Pi''$ 为强 $S$-相容，且对任意 $r = C \leftarrow B, F \in \Pi \setminus \Pi''$，$S \not\models_n (B, F)$。依定理 5.2.4，$S$ 为 $\Pi$ 的一回答集。

（必要性）按定理 5.2.4，存在 $\Pi'' \subseteq \Pi$，使 $\Pi''$ 为强 $S$-相容，且对每一 $C \leftarrow B, F \in \Pi \setminus \Pi''$，$S \not\models_n (B, F)$。依引理 5.2.8，存在 $\Pi' \subseteq \Pi''$，使 $(\Pi', S) \in \mathcal{A}(\Pi')$ 且 $\Pi'$ 在 $S$ 上紧凑。因 $\Pi' \subseteq \Pi''$ 且 $\Pi''$ 为 $S$-相容，故 $\Pi'$ 为 $S$-相容。从而对任一 $r = C \leftarrow B, F \in \Pi \setminus \Pi''$：若 $r \in \Pi'' \setminus \Pi'$，由引理 5.2.8 证明知 $B \cap \mathbf{GLit}_C \subseteq S$；若 $r \in \Pi \setminus \Pi''$，则 $S \not\models_n (B, F)$。

### 引理 5.2.9

设 $\Pi$ 为嵌套程序，$S$ 为 $\Pi$ 支承且封闭于 $\Pi$ 的协调文字集。若存在 $\Pi' \subseteq \text{GR}(S, \Pi)$，使得 $S \in SM(\text{Head}(\Pi'))$ 且 $\Pi'$ 在 $S$ 上紧凑，则 $\Pi'$ 与 $\text{GR}(S, \Pi)$ 均为强 $S$-相容。

证明：若 $S=\emptyset$，引理显然成立。设 $S \neq \emptyset$。因 $\text{GR}(S, \Pi) = \{ C \leftarrow B, F \in \Pi \mid S \models_n (B, F) \}$，且 $S$ 受 $\Pi$ 支承且封闭于 $\Pi$，故 $S$ 亦受 $\text{GR}(S, \Pi)$ 支承且封闭于 $\text{GR}(S, \Pi)$。

由 $S \in SM(\text{Head}(\Pi'))$ 及 $\Pi' \subseteq \text{GR}(S, \Pi)$，得 $S \in SM(\text{Head}(\text{GR}(S, \Pi)))$，且 $S$ 受 $\Pi'$ 支承、封闭于 $\Pi'$。依 $\Pi'$ 在 $S$ 上的紧凑性，存在层次映射 $\lambda$，使对 $\Pi'$ 中每一规则 $C \leftarrow B, F$ 及每一 $L \in S \cap GAtom_C$，有 $\lambda(L) > \max \{ \lambda(B) \}$。

因 $S$ 受 $\Pi'$ 支承且 $\Pi'$ 紧凑，对满足 $\lambda(L)=0$ 的 $L \in S$，存在 $C \leftarrow B, F \in \Pi'$，使 $\mathbf{GAtom}_C \cap S = \{ L \}$ 且 $B = \emptyset$。

因此 $\{ C \leftarrow B, F \in \Pi' \mid B = \emptyset \} \neq \emptyset$。对该集合中任意 $r$，因 $S \models_n (B, F)$ 且 $S$ 封闭于 $\Pi'$，得 $S \models_n \text{Head}(r)$。由 $S \in SM(\text{Head}(\Pi'))$，存在 $X_0 \in SM(\text{Head}(\{ C \leftarrow B, F \in \Pi' \mid B = \emptyset \}))$ 使 $X_0 \subseteq S$。

不失一般性，设 $\lambda(S) = \{ m \mid m \geqslant 0 \}$。定义 $X = \cup_{n \ge 0} X_n$ 与 $\Pi'(X) = \cup_{n \ge 0} \Pi'(X_n)$ 如下：

$X_0 \in SM(\text{Head}(\{ C \leftarrow B, F \in \Pi' \mid B = \emptyset \}))$ 且 $X_0 \subseteq S$

$\Pi'(X_0) = \{ C \leftarrow B, F \in \Pi' \mid B = \emptyset \}$

对 $n > 0$，$X_n \in SM(\text{Head}(\{ C \leftarrow B, F \in \Pi' \mid B \subseteq X_{n-1} \}))$ 且 $X_{n-1} \subseteq X_n \subseteq S$

$\Pi'(X_n) = \{ C \leftarrow B, F \in \Pi' \mid B \subseteq X_{n-1} \}$

易验证：对任意 $n \geqslant 1$，$X_{n-1} \subseteq X_n \subseteq S$。故 $X \subseteq S$ 且 $(\Pi'(X), X) \in \Lambda(\Pi')$。

首先归纳证明：对任意 $n \geqslant 0$，若 $C \leftarrow B, F \in \Pi'$ 满足 $\max \{ \lambda(B) \} \leqslant n$，则 $C \leftarrow B, F \in \Pi'(X_{n+2})$。这蕴含 $\Pi' = \Pi'(X)$，从而 $(\Pi', X) \in \Lambda(\Pi')$。

基础步：易知 $\{ C \leftarrow B, F \in \Pi' \mid B = \emptyset \} \subseteq \Pi'(X_1)$。对任意满足 $\max \{ \lambda(B) \} = 0$ 的规则 $C \leftarrow B, F \in \Pi'$，因 $\Pi' \subseteq \text{GR}(S, \Pi)$，故 $B \neq \emptyset$ 且 $B \subseteq S$。由 $S$ 关于 $\Pi'$ 的支承性及 $\Pi'$ 的紧凑性，对任一满足 $\lambda(L)=0$ 的 $L \in B$，存在 $C_L' \leftarrow B_L', F_L' \in \Pi'$，使 $B_L' = \emptyset$ 且 $\mathbf{GAtom}_C \cap S = \{ L \}$。因 $\{ C \leftarrow B, F \in \Pi' \mid B = \emptyset \} \subseteq \Pi'(X_1)$，故 $C_L' \leftarrow B_L', F_L' \in \Pi'(X_1)$。
