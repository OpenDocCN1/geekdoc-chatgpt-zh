## 9.11 有序数组转二叉树

### 题目描述：
输入是一组严格递增的整数序列，要求把它组织成中序遍历结果仍保持递增的二叉树，具体该如何构造？

### 分析与解答：
因为源序列本身有序，构造出来的树在中序遍历下也必须保持有序。常用的分治思路是每次选取当前区间的中间位置元素作为当前节点的枢纽，把区间切分为左右两段后分别递归下去，整体构造示意如下。

# 方法功能：把有序数组转换为二叉树

def arraytotree(arr, start, end):

    root = None

    if end >= start:

        root = BiTNode()

        mid = (start+end+1)/2

        # 树的根节点为数组中间的元素

        root.data = arr[mid]

        # 递归的用左半部分数组构造 root 的左子树

        root.lchild = arraytotree(arr, start, mid-1)

        # 递归的用右半部分数组构造 root 的右子树

        root.rchild = arraytotree(arr, mid+1, end)

    else:

        root = None

    return root

"""

方法功能：用层次遍历的方式打印出二叉树节点的内容

输入参数：root: 二叉树根节点

"""

def printTreeLayer(root):

    if root == None:

        return

    queue = deque()

    # 树根节点进队列

    queue.append(root)

    while len(queue) > 0:

        p = queue.popleft()

        # 访问当前节点

        print(p.data, end=" ")

        # 如果这个节点的左孩子不为空则入队列

        if p.lchild != None:

            queue.append(p.lchild)

        # 如果这个节点的右孩子不为空则入队列

        if p.rchild != None:

            queue.append(p.rchild)

class Test:

    def __init__(self):

        self.maxSum = -2**31

        方法功能: 求最大子树

        输入参数: root: 根节点;

        maxRoot: 最大子树的根节点

        返回值: 以 root 为根节点子树所有结点的和

        """

        def findMaxSubTree(self, root, maxRoot):

            if root == None:

                return 0

            # 求 root 左子树所有结点的和

            lmax = self.findMaxSubTree(root.lchild, maxRoot)

            # 求 root 右子树所有结点的和

            rmax = self.findMaxSubTree(root.rchild, maxRoot)

            sums = lmax + rmax + root.data

            # 以 root 为根的子树的和与前面求出的最大值

            if sums > self.maxSum:

                self.maxSum = sums

                maxRoot.data = root.data

            # 返回以 root 为根结点的子树的所所有结点的和

            return sums
