# 二、职场性骚扰的常见类型和具体表现 👀

参照《防治职场性骚扰指导手册》的划分，职场性骚扰大致可以归为四类：

视觉型骚扰：用眼神和画面进行侵犯，比如长时间盯着别人敏感部位看，故意在办公区展示色情图片、视频等。

语言型骚扰：靠话语输出不适感，例如讲黄色笑话、发出淫秽音效、随意对同事外貌发型做不当评价或暧昧暗示。

肢体型骚扰：直接的身体接触，如未经允许的拥抱、亲吻、抚摸、抓握等。

性侵犯：以暴力或胁迫手段强行发生性行为，包含强奸、强制猥亵等犯罪行为。

形式花样繁多，有明目张胆的，也有极其隐蔽的。比如在会议上公然说“你今天打扮得真好看，我都想抱一下”；在工作群里私发色情图并配文“昨晚刚看，你也瞧瞧”；出差时安排和下属同住一间房并趁机触碰；晚宴上逼迫同事喝酒后将人带到无人处实施性侵。这些看似“开玩笑”“关心”的场景，都可能构成骚扰。

# 三、职场性骚扰会带来哪些伤害 💔

性骚扰的破坏力是多维度的，受害者、企业、社会都会被拖下水。

对个人人权与尊严的践踏。身体和精神被侵犯，人格权和劳动权被直接踩踏，受害者常陷入羞耻、恐惧、愤怒、无助的情绪漩涡，极端时还会出现自责、自卑、抑郁等心理问题。

身心健康的长期损耗。持续的压力会导致失眠、头痛、胃痛等躯体化反应，同时伴随焦虑、惊恐、创伤后应激等心理障碍，恢复周期很长。

工作与生活的全面受影响。积极性被打击，效率下降，职业发展受阻、收入缩水。很多人为避开加害者选择辞职、调岗，失去心爱的工作，生活质量随之下滑，出现家庭矛盾、社交退缩、信任危机。

企业声誉与利益的受损。内部信任崩塌，团队士气低落，协作受阻。一旦曝光，企业面临诉讼风险、行政处罚和舆论危机，品牌形象、市场竞争力、社会责任感都会受损。

社会公平与进步的阻碍。性骚扰本质是性别歧视和暴力，会加剧性别偏见，挤压女性就业和晋升空间，削弱女性社会地位。它破坏道德风尚和法治秩序，对社会和谐稳定构成威胁。

# 四、怎么才能有效防治职场性骚扰 🛡️

这是一个需要多层联动解决的问题。

建章立制补短板。民法典、妇女权益保障法、女职工劳动保护特别规定等已明确反骚扰原则，但认定标准、举证方式、用工单位的防控程序和责任划分仍需细化。惩罚力度要加大，救济渠道要畅通，让受害者敢举报、能维权。

教育培训常态化。企业应定期开展反性骚扰培训，提升员工的识别意识和边界感，树立平等尊重的职场文化。管理层要带头示范，员工要掌握自我保护技能，形成“不纵容、不旁观”的氛围。
