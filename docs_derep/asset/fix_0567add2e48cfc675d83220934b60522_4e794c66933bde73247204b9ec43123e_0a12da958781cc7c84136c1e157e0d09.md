- 转向 `y2` 的偏导计算，`w3` 与 `w4` 分别获得 `[3., 4.]`。
- **梯度汇聚**：`w3` 同时出现在两个表达式中，遵循链式法则，最终梯度需累加：`[1., 2.] + [3., 4.] = [4., 6.]`。
