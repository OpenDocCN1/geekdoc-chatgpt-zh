# AI时代的权力重塑

封帅[^(\[2\])](#chapter003.html#m2)

**摘要：**深度学习取得关键突破，推动人工智能进入新一轮高速扩张阶段。算力与算法的同步跃升让技术跨过商业化门槛，成为下一轮产业革命的核心驱动。AI的快速演进将对国际关系产生深远影响。一方面，AI已直接嵌入战略决策与军事互动的关键环节，会进一步拉大行为体间的实力差距，冲击既有的均势格局。另一方面，自动化生产重塑全球经济运行方式，牵动行为体内部权力分配，最终对国际体系形成系统性冲击。更长远看，AI还将重塑时代观念，新的社会思潮将在碰撞中成形。AI时代人类将进入更具变动且更不平等的世界，中国亦处在机遇与挑战并存的新阶段。国际关系研究者需要主动进入这一历史进程，承担应有的责任与使命。

**关键词：**人工智能 深度学习 国际关系

人类距离科幻里反复描绘的未来，从未如此之近。硬件性能的全面跃升叠加互联网时代的数据累积，让几经波折的人工智能在21世纪第二个十年迎来爆发式增长。本轮浪潮以人工神经网络为基础，深度学习等算法的重大进展成为主要牵引。[^(\[3\])](#chapter003.html#m3)在算力与算法双轮驱动下，AI在众多垂直领域斩获兼具商业价值与社会影响的显著成果，技术首次真正走向产业化，被学界与产业界视为引领新一轮科技革命的关键变量。

与历史上此前的科技变革不同，AI的特殊性在于其主体性。过往的技术无论形态如何，本质上都是改造世界的工具，而AI能够通过海量数据的分析学习把握人类深层需求，以创造性合作者的姿态直接参与改造活动，其推理逻辑与人类理性思维存在本质差异，也因此改变了人与技术的深层关系，并对国际关系生态造成长期扰动。

其一，AI在与国际关系高度关联的领域落地，会给掌握技术的行为体带来额外溢价，从而重塑相关领域的权力版图；其二，AI在众多行业的渗透在创造财富的同时，也在悄然改变人类社会经济活动的组织方式，推动社会形态以及行动体内部的重构，进而发酵为国际体系的深层变革。随着AI时代逐步到来，国际体系的主体构成、结构形态、运行逻辑与规则体系等多重要素都将发生巨变，传统国际关系理论将面临严峻挑战。准确把握AI前沿动向、洞察AI时代的基本面貌、研判其对国际关系可能产生的潜在影响，对于理解未来国际格局演变趋势与国家互动模式迁移具有重要意义。

上世纪80年代末至90年代初，美西方部分学者已初步探讨AI对国际关系的影响，但受限于当时的技术水平，这一讨论并未在学界形成广泛共识。相关研究多集中于数据库建设或辅助决策工具的开发，对国际关系的根本性议题涉及有限。近年来，随着技术飞速成熟，相关研究呈现明显增长态势。[^(\[4\])](#chapter003.html#m4)中国学界对AI的关注起步较晚，早期思考多集中于哲学与经济学范畴。近两年，部分学者在探讨国际关系预测问题时已触及相关议题，但直接以人工智能与国际关系为中心的成果仍属稀缺。[^(\[5\])](#chapter003.html#m5)

在此背景下，本文以弱人工智能时代的基本特征为切入点，尝试梳理当前AI技术对国际关系的直接领域性影响、间接系统性影响以及理念层面的长期影响，勾勒弱人工智能时代下国际体系要素变迁的宏观图景。同时希望以初步探讨抛砖引玉，激发更多国际关系研究者关注这一重大议题，让中国学者的思想在AI发展史上留下印记。

## 一 弱人工智能时代的技术影响力扩散模式

现代意义上的人工智能研究可追溯至20世纪40年代。1950年，英国科学家图灵在《计算机器与智能》一文中首次提出“机器能否思考”这一划时代命题，并给出检验智能的方法。[^(\[6\])](#chapter003.html#m6)

1956年达特茅斯夏季研讨会上，计算机专家约翰·麦卡锡提出“人工智能”这一概念，并被确立为新学科的命名。[^(\[7\])](#chapter003.html#m7)此后数十年，AI发展几经波动。虽然“专家系统”“深蓝”等标志性成果先后出现，但受制于客观条件，技术长期难以解决真实需求，难以实现产业落地，对社会影响有限。

真正的拐点出现在2009至2010年左右。新一代计算设备的运算与处理能力大幅跃升。互联网重塑生活方式，网络成为获取日常数据的核心渠道。移动互联时代到来后，来自搜索、电商、社交媒体、科研等领域的海量数据快速累积，为AI提供了充足养料。在算力与数据双重条件成熟后，早在60年代就被提出的深层神经网络工具重新焕发生机，成为主流路径。[^(\[8\])](#chapter003.html#m8)本轮热潮以深度学习为核心，其基于层层嵌套的多层次识别架构，通过组合低层特征形成抽象的高层属性，以捕捉数据分布规律。[^(\[9\])](#chapter003.html#m9)深度学习的出现改写了传统符号主义学派以模拟人类认知推进AI的路径，让机器能够从庞杂信息中提取、识别并构建体系，在任务目标明确且数据充足的场景中，机器可快速学会新技能、制定有效策略，并给出超越人类学习效率的解决方案。[^(\[10\])](#chapter003.html#m10)

随着深度学习神经网络成为主流，人工智能迅速在现实场景中落地。短时间内，图像识别、语音识别、机器翻译、自动驾驶乃至棋类对弈等复杂场景均取得突破，基本达到满足日常需求的水平，具备商业投资价值，成为资本市场追捧的热点。跨越产业化门槛意味着AI走出实验室，成为直接影响生产与生活的关键力量。更重要的是，本轮进步证明机器学习算法能在诸多限定条件下优于人类，且具备自我学习不断进化的能力，这一结论打开了人类对AI未来的想象空间，未来社会的脚步声已清晰可闻。
