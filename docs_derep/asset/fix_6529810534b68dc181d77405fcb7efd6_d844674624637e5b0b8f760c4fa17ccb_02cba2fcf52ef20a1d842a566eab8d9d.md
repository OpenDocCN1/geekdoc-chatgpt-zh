## 1.3 设定数据验证以规范录入的数据

数据验证即为指定单元格的输入设定规则，例如限定日期范围、数值区间、可选清单或通过公式做更复杂的校验。规则生效后，不合规的内容会被拦截，有效避免错误录入。

### 1.3.1 限制只能输入指定类型数据

部分单元格需要强制格式，例如只能录入日期。提前设置校验可以减少返工。

以仅允许当月日期为例：

1. 框选目标区域，切换到“数据”选项卡，在“数据工具”组打开“数据验证”，弹出设置窗口如图1-43。
2. “允许”下拉选择“日期”，“数据”下拉选择“介于”，随后分别填入开始日期和结束日期如图1-44。
3. 单击“确定”后，若输入的内容无法被识别为日期会弹出错误提示如图1-45；若日期超出设定区间也会被拦截如图1-46。

### 1.3.2 限制输入数据的大小

例如要求交通费金额必须小于指定上限。操作如下。

1. 选中区域，数据页签 → 数据工具 → 数据验证，打开对话框如图1-47。
2. “允许”选“整数”，“数据”选“小于”，填入最大值如图1-48。
3. 切换到“出错警告”页签，在“标题”文本框写入提示标题如图1-49。
4. 确认后，当输入的不是小于400的整数时，会出现警告框如图1-50。
