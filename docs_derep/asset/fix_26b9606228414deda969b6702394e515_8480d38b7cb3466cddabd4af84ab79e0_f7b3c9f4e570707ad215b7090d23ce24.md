#### 4.6.1 浮点向量、稀疏浮点向量和二进制向量

##### 1. FLOAT_VECTOR（密集浮点向量）

最常用的形态，一般由深度学习模型产出。维度固定，每个位置都有数值。常见于语义检索、图像特征提取。表达力强，但存储开销大。示例如下。

##### 2. SPARSE_FLOAT_VECTOR（稀疏浮点向量）

绝大多数维度为 0，只保存非零值及其位置。维度可能很高，但实际只存非零元素。经典的 TF-IDF 或 BM25 表示就是这种稀疏形式，常用于关键词检索。存储形态通常是 {索引: 值} 的键值对。比如一个一万维的向量，实际只有 3 个位置非零。

##### 3. BINARY_VECTOR（二进制向量）

每个维度只有 0 或 1 两种取值，是对稀疏向量的一种简化，常用于快速近似匹配。适合图像哈希、快速相似检索以及二值化特征表示。优点是存储小、计算快，缺点是精度相对低。示例如下。

#### 4.6.2 混合检索策略实现

在现代信息检索里，混合检索策略很普遍。以合规文档检索为例，第一层用高效的关键词匹配做预筛选，第二层用 BM25 等做相关性排序，第三层用向量相似度做语义深挖。这种层层递进的方式也叫级联融合或多层检索，即一种方式的结果作为另一种方式的输入。这样既保证效率，又提升相关性和精准度。

小冰：总听你说 BM25，它和稀疏向量到底有什么关系？我有点忘了。

咖哥：BM25 是通过词频和逆文档频率计算每个词在文档中的重要性来生成向量，每个维度对应词表中的一个词。因为一篇文档只用到很少一部分词，向量天然就是稀疏的。比如词表一万个词，一篇文档只用 50 个词，BM25 向量只有这 50 个位置有非零值，其余 9950 个位置都是 0。所以 BM25 本质上是一种特殊的稀疏向量表示。当我们说用 BM25 时，实际就是用特定公式给稀疏向量中非零值的权重。
