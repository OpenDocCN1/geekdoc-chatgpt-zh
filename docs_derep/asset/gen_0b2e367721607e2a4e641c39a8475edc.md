# 智览天下

# 序章

这是一部面向大众的关于人工智能的通俗读物，也是笔者作为科普撰稿人的第五部作品。写完《宇宙的另一种真相》后，我一度觉得再难提笔，原因在于在基础物理层面，人类已近百年未见相对论、量子物理那样的根本性突破，似乎无话可说。显然我低估了技术爆发的能量。自2022年底可对话的ChatGPT骤然登场以来，全球科技的视线被牢牢锁定在人工智能之上。无论从科研、产业还是国际格局来看，人工智能都指向未来。谁能在这一赛道占据生态优势，谁就可能成为下一个时代的主角，人工智能也自然成了大国博弈的利器。

AI技术的迸发看起来几乎是一夜完成的，自它学会“开口说话”之后，围绕它的新技术与新应用此起彼伏，迭代速度更是一日千里。算到2025年底，短短三年过去，模型更新的频率愈发惊人。除了理解人类自然语言，它还能依据简短的描述生成精美的图像、悦耳的音乐、流畅的动画。自动驾驶也在全面趋于成熟。AI赋予人类能力的方向越来越接近“言即成实”，而我们正处在文明剧烈更迭的奇点之内。

正因为AI正以“AI一日，人间一年”的速率演进，想靠纸质书追逐最新进展并不现实。书稿三审三校再付梓时，前沿很可能已面目全非。所以本书并不盯着最炫的技术，而是退后一步，试图在变动中找出相对恒定、原则性的哲理，在介绍核心科学思想的同时，对AI的未来做一番推想。

大语言模型诞生之时，我与所有人一样被震撼到，似乎一夜之间万物换新，我切身感受到一场或许史无前例的变革正在进行。我并不惊讶于它能像人一样写文学、作诗，也不惊讶于它能代写邮件报告。之所以认定AI的革命将是文明史上最大的一次科技革命，是因为我习惯以信息学的眼光看待事物。世界万物皆可归为信息，而AI提供了一种前所未有的信息压缩与传递方式，它让计算机具备生成高复杂度内容的能力，而这正是过往任何技术都不曾拥有。

人类以往的技术，本质上都是加速信息传递、提升传递效率。蒸汽机提升了交通效率，电气化提升了信息传递效率，互联网完成了多对多即时的信息流通。但它们都无法“创造”出与人类大脑相当复杂程度的信息。

若要追问为何地球上只有人类一种高等智能，问人类与其他动物最大区别何在，我的答案是人类拥有具备虚构能力的自然语言。因着虚构，人类能把信息抽象为概念，把概念串联成逻辑，再借自然语言传播并通过推理产生智能的涌现。关于智人何时获得语言能力，学界说法不一，甚至有观点认为是病毒入侵引发基因突变。但以文字诞生为标尺，大约在六千到一万两千年之前。所以人类文明的进步令人咋舌，是指数级爆发。自语言诞生，文明的载体就发生了根本改变，甚至可以说没有语言就没有文明。语言诞生前，人类的信息几乎只有遗传信息，载体是DNA，代代相传。物种演化以百万年计，人类文明的巨变却只用了数千年。与生物物种的演化时长相比，这只是弹指一挥间。信息载体的更迭，会给文明演化的速度带来戏剧性影响。同样，若计算机学会人类自然语言，再加上计算机处理信息的超快速度，不难想象把人类文明的爆发在电脑与互联网上重演一遍，会快到何等程度。正因这一次信息载体的转换带来了信息复杂度的巨幅跃升，在以往的科技中从未出现，所以AI带来的改变必定是剧烈的、超乎想象的。这是人类从未踏足的领域，AI对社会文明演化的影响以及随之而来的机会，相信会远超过往所有科技革命的总和。AI远不是一项新技术，它标志着一个全新时代、新纪元，甚至是未来人类的一种全新文明形态。

在这样历史交汇的关键节点，现代人应当以不同于以往对待科技革命的视角进行审视。我选择回望历史，回望思想史、科技史、哲学史。惊奇地发现，AI的诞生让过去许多晦涩难懂甚至缥缈的哲学理论变得异常具体。深入了解AI的科学原理后，休谟的经验主义与他的第一命题愈发闪亮。他认为因果律并非天然存在，只是人类认知的习惯。而基于神经网络的人工智能，在没有任何逻辑推理与因果关系的前提下，仅凭概率就能在语言中展现极强逻辑，这无疑是对手谟哲学的一种印证。维特根斯坦那句“语言的界限就是认知的界限”，也在大模型里得到充分展示：没有语言，便没有逻辑的流淌。

再看尼采，这位自称“疯子”的哲学家终其一生追寻“超人”。在《查拉图斯特拉如是说》中，他用文学性的语言描绘了对人类发展的殷切渴望，即人类应寻求物种进化，最终成为超人。若把尼采所说的进化推广到DNA之外，推广到信息载体的层面，那么通用人工智能的到来，或许正是超人的降世。

正因为AI带来的改变，在人类历史上除了文明诞生那一刻，或人类诞生语言那一刻之外，并无可比，其潜在的社会问题也显而易见。每次科技大爆发都会伴随强烈社会讨论与恐慌。电气化兴起时，人们认为电损害健康，是无形杀手；原子能刚用于民用时，很多人笼罩在全球核战恐惧中；互联网普及被认为会使人类思维退化，等等。这些对科技爆发的担忧，最终都未能阻挡进步，从结果看是科技进步主义的胜利，反对声音每个时代都有，却似乎总是杞人忧天。然而这次AI革命完全不同。过往科技革命的质疑，无论剧烈与否，都产生于人类社会内部。AI可能带来的威胁并非完全来自人类社会，一旦AI觉醒自我意识，它应被视作“如何面对外星人造访地球”一样的命题。毕竟，AI或许将发展为一个取代人类的全新物种。

因此本书的目光投向自然科学、哲学、史学、伦理学乃至未来学，在全面介绍AI核心原理的同时，结合经典人类思想，全景审视AI发展给人类带来的方方面面影响。我认为这样的讨论十分必要，因为我深信人工智能将是人类最后的重要发明，一旦其智能水平突破临界点，便能进入自我演化、自我发明的状态。AI的发展充满不确定性，甚至蕴含重大威胁，但同时我也觉得，在自己的青年时代，能有幸目睹甚至参与人类历史上最重要的盛事，见证人类作为文明物种的演化与变迁，这是何其幸运！我几乎怀着感恩、兴奋甚至壮烈的情感写作。

就让我们带着惴惴不安却又跃跃欲试的心情，回望历史，放眼未来，投身到人工智能的世界中！未来人，你好！

人工智能很可能就是人类最后一项关键发明。

# 第一章 涌现的智慧

ChatGPT 3.5诞生于2022年年末，一经推出便席卷全球。OpenAI打造的大语言模型系列，创造了人类历史上最快的产品用户增长纪录。仅用两个月时间，ChatGPT就拥有超过一亿用户，这一纪录后来在2025年初被中国开源大模型DeepSeek刷新，DeepSeek一周之内便取得同等成绩。作为一款语言对话类产品，在科学层面ChatGPT到底突破了什么？实际上科学上的突破并不突出，它更多是技术层面的跃进，这种智能的爆发本质上来自涌现的现象。

生命的诞生是一种涌现！

AI会不会涌现成尼采口中的超人呢？

这是一个可能的未来图景！AI能处理海量数据，运行超大规模模型，这种规模效应带来的涌现是人类智慧难以企及的。

如果我们不把进化局限在碳基生命的范围内，而只从信息演化的视角审视，AI或许是我们创造的、第一个可能超越我们的新物种。

人类会被AI取代吗？人类如何保持竞争力？我们的优势是什么？AI就像个外星人！

AI扩展了我们的能力边界，而好奇心、创造力与价值判断，这些是AI尚未涌现的能力，也是人类的价值所在。

## 2022年的超人

2022年年末，能够对话的ChatGPT横空出现。这标志着人类从信息时代开始步入智能时代。截至本书成书的2025年，人工智能已如火如荼发展了三年。短短三年里，人工智能产业的发展速度，是人类过往任何一个科技进步时期，无论工业革命、机械化革命、电气化革命，还是信息化革命，都无法比拟的。毫无疑问，人工智能将对人类社会带来全方位的变革！它甚至可能是人类历史上最为迅速、最为彻底的一次变革。

著名作家、发明家与未来学家雷蒙德·库兹韦尔著有《奇点临近》。书中预言：随着计算机技术进步，人类科技将抵达一个临界点，也就是当机器可以发明机器，机器能够自我进化时，人类就会进入科技大爆发的态势。这个临界点就是库兹韦尔提出的奇点，英文singularity。奇点本是数学概念，例如函数y=1/x，当x趋近于0时，y趋近于无穷大，x=0就是该函数的奇点。

若用奇点形容科技大爆发的节点，那么爆发态势本应排山倒海而来，从这三年AI的发展速度来看，这一点已得到印证。毫无疑问，人工智能，尤其是通用人工智能AGI的产生，就是这个奇点。人工智能将给人类社会带来巨变！关于这一点，相信已成为所有人的共识，无非是对“彻底”程度的看法不同。

但若细看公众对人工智能的关注点，其实大多集中在技术层面或经济层面。我们绝大多数人，不过是把人工智能当成一种全新技术，或是一个巨大的创业机会。就像三十多年前互联网诞生，它确实是新技术，也是过去三十年人类社会重要的经济增长引擎。对待人工智能的态度，和对待互联网或过往的科技革命并没有什么不同：人工智能不过是又一次巨大的技术进步。

我想指出的，恰恰是人工智能对人类的意义，远不止一项更先进的技术。人工智能对人类的影响要比一般的科技进步深刻得多。当然，人工智能带来的经济增长与文明提升，或许是过往所有科技革命增长的总和，甚至更甚。不仅是这些数据的增长，人工智能对人类的影响，是在人类作为一个种族层面上的影响。过往的科技发展，不论多么先进高效，这些科技始终为人所用。在和过往科技进步的关系中，人类一直处于主宰地位：科技为人所用。但人工智能，它的意义已远远超出“一项科学技术”的范畴。它对人类的影响是全方位的。其实ChatGPT刚发布时，我也和其他人一样受到了深深震撼。与众不同的是，我的震撼是一种哲学层面的震撼。这种哲学层面的震撼，让我立刻想起休谟、尼采与维特根斯坦。

尼采哲学的反复主题是“超人”。尼采的大致逻辑是这样的，既然根据进化论，人类由猿人进化而来，那就没有理由认为人类形态就是进化的终点。尼采认为人类应持续进化为一种全新的物种，拥有新的道德规范和强力的意志，是全方位更为先进的物种。如果我们并不把这种进化局限在碳基生物的范围内，而是仅用信息载体的观点看待物种的进化，那么DNA不过是一种物种遗传信息的载体。如果我们能跳出肉身、跳出碳基生物、跳出DNA作为信息载体的桎梏，那么人工智能作为一种全新的信息载体，它是否就是人类进化的下一个物种形态呢？也许人工智能，就是尼采哲学中的“超人”，如图1-2所示。

## 本质为何追问本质

我们在研究一个事物时，常常会问一句：“它的本质是什么？” 没错，追求本质，其实是一切研究活动的根基，我们希望通过不断探究事物形成过程中的因果关系，不断简化模型，最终把事物形成的根本原因找出来，从而提炼出事物的本质。也就是说对事物的探究，可以拆解为不断地追问“为什么”。当我们问“为什么”时，实际上是针对一个结果去寻找它对应的原因，当一连串的“为什么”被解答后，我们就把解释事物的因果链条全部串起来，这个因果链条的源头，几乎就是我们要寻找的事物的本质。

那不妨把这种追求本质的思维方式发挥到极致，我们来问一问：为什么我们要问“为什么”？人类需要问“为什么”的本质是什么？对于这样的问题，我们有诗意的答案，也就是人类与生俱来的好奇心、对万事万物的好奇心，至少在现代文化中，这是一种美德。拥有好奇心总体上是被赞美的。热衷于追寻本质、喜欢问“为什么”的原因，在“好奇心”的叙事中，被认为是人类的一种天性，似乎这是人类作为高等智能生物，与其他生物非常重大的区别。我们人类，不光像其他生物一样追求生存繁衍，我们在满足生存需求的同时，心中还有星辰大海。人类之所以喜欢问“为什么”，是因为人类具有“好奇心”这个与众不同的品质。这确实是对“人类为什么喜欢问为什么”的一种解释，也可以被认为是一种本质性质的回答。

所有生物的第一属性，可以说都是“求存”，所有生物都想活下去，所谓存在，即是一种求存的趋势。我们刚刚提的这个核心问题，即“为什么人类喜欢问为什么”，其实可以换一种问法：为什么只有我们搞清楚了事物形成的“为什么”之后，我们才认为这个问题被解决了？为什么人类认知世界的方式是以因果律的方式来理解的？为什么当我们理解了一个事物的成因之后，我们就认为我们理解了该事物？这些答案，依然可以跟“求存”联系起来。

“生存”的最大敌人是什么？其实是不确定性。人类的一切知识，或者说人类所有追求知识的行为，有没有一个共同的、终极的目标？不论是早期人类的观星、占卜、祭祀、信仰宗教等行为，还是后来的对哲学、科学等各种学科的研究，它们其实都隐隐有一个共同的追求——至少从功利的、贴合人类生存需求的角度来说，那便是对抗不确定性。从原始部落的祭祀、巫术开始，当时的人类企图通过这种行为来获得神明、祖先的庇佑，以对抗大自然的不确定性，例如各种天灾。到了古希腊、古罗马时期，即便是在哲学已经诞生的年代，人类也通过创造神话体系，把各种自然现象和人造事物与神明联系起来，这样便可以向神明祈求保佑，让诸事皆顺，以此对抗世界的不确定性。

如何对抗世界的不确定性？对抗不确定性的终极形态，就是让不确定性都变成确定性，关于这个需求，有一个更简单的表达：预知未来。对于不确定性的恐惧，以及对于确定性的渴望，在科幻小说《三体》中，被展现得淋漓尽致。三体人生活的三体星系，有三个质量相当的太阳。三个质量相当的天体在引力作用下运动，会形成完全不可预测的运动轨迹，这让三体人的生存环境极其恶劣。所以在地球上的三体人的追随者，分成了拯救派和降临派，拯救派的核心主旨就是希望通过人类的智慧，研究清楚三体问题，以便准确地预测三体星系里的三个太阳具体是如何运动的，帮助三体人获得确定性，进而获得安稳的生存环境。而三体人之所以要侵略地球，就是羡慕地球人所拥有的恒定的四季，这在三体人看来已经是巨大的确定性了。不确定性是对生命体生存的最大威胁，生命体的第一属性是求存，所以对抗不确定性，可以说是所有生命体内在的、最深层的本能。

再回到前文提到的问题：为什么人类爱问“为什么”？因为我们认为，只要回答了所有的“为什么”，我们就找到了事物运行的规律，而掌握了事物运行的规律，我们便可以对未来进行预测，最大限度地去规避不确定性，从而满足求存的需求。也就是人类本性中的“好奇心”，它并不完全是人类区别于其他生物的超凡品格，它仍然是一种用来满足人类作为一种生物的、求存的核心需求的内禀属性。

当我们探寻了所有事物的本质，了解了所有自然规律，找到一切现象的因果律之后，我们就能完全消除所有不确定性，从而达成绝对的求存吗？至少在量子物理的层面，这件事情已经被证伪了。不确定性，在最为微观的量子物理层面，是无法被彻底消除的，这就是量子物理当中的不确定性原理。这条原理可以说是量子力学的第一性原理。它直接把人类对完全确定性追求的梦想给摔了个粉碎。不确定性原理说，我们无法同时精确测量一个满足量子力学的微观粒子的位置和速度。若你测得它的精确位置，就无法精确测量其速度，反之亦然。之所以用概率波去描述量子系统，是因为量子系统具有不确定性，完全不可精确预测。概率波的描述和不确定性原理可以说是互为充要条件。
