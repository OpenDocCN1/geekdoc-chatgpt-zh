**DeepSeek-VL2 技术全景拆解**

**1．数据准备全貌**
DeepSeek-VL2 所用的训练素材主要分成三类：视觉语言对齐集、视觉语言预训练集以及监督微调集。对齐集主要承担起早期 MLP 连接训练的任务，预训练集用来增强模型的多模态理解能力，微调集则负责进一步雕琢模型表现。

这些素材集合了公开库和内部采集的数据，覆盖的任务类型很广，包含视觉问答、光学字符识别、文档解析、视觉定位等。种类丰富、来源多样，为模型提供了良好的泛化基础和适应性。

**2．训练流程拆解**
整体训练被划分为三个阶段：模型初始化、视觉语言预训练、监督微调，具体如下。

（1）模型初始化阶段，视觉编码器与语言模型各自先做预训练，分别获得基础的视觉特征和语言特征表示。
（2）视觉语言预训练阶段，借助大规模多模态数据来打磨模型的视觉语言对齐能力和融合能力。这一阶段主要靠多任务学习与对比学习，让模型对各类任务的理解与处理不断提升。
（3）监督微调阶段，使用带标注的多模态数据做精细优化。模型通过任务特定的损失优化，学会更好地完成视觉问答、文档理解等具体任务。配合指令调优，整体对话与多模态推理能力得到明显增强。

**3．并行训练与资源优化**
● 并行策略：训练过程中同时使用模型并行、数据并行和专家并行，充分调动 GPU 集群如 NVIDIA A100 的算力，实现大规模分布式训练。
● 负载均衡与切片调度：针对动态切片策略下的视觉编码器，因不同图像切片数量不一致，采用细粒度层分割配合数据并行，能在前向和反向传播中实现各 GPU 负载的均衡调度。

### **6.1.4** **Janus 项目对比**
DeepSeek-VL2 与 Janus 都是 DeepSeek 开源的多模态体系，但在设计取向和实现细节上差异明显。DeepSeek-VL2 聚焦于动态平铺策略加 SigLIP 视觉编码器提取高分辨率图像的精细特征，再借助视觉语言适配器和结合 Multi-head Latent Attention 的 MoE 语言模型来支撑视觉问答、OCR、文档解析、视觉定位等任务；Janus 则追求统一的多模态理解与生成框架，核心在于把视觉编码解耦为独立通路，同时优化理解与生成，并通过 JanusFlow 融合自回归与 rectified flow 技术实现高效的文本到图像生成。

**1．设计取向**
DeepSeek-VL2：更强调高分辨率图像的精细特征提取，以及视觉语言信息的深度融合，适用于视觉问答、OCR、文档理解、视觉定位等场景。
Janus：更强调搭建统一的多模态平台，通过解耦视觉编码实现理解与生成的并行优化，并以 JanusFlow 提升文本到图像生成的质量。

**2．视觉编码方式**
● DeepSeek-VL2：采用动态平铺配合 SigLIP 编码器对图像分块处理，随后经视觉语言适配器把图像特征转为语言模型可用的输入。
● Janus：采用解耦式视觉编码，先分别提取视觉特征再统一输入 Transformer，降低编码与生成任务之间的相互干扰。

**3．语言模型结构**
● DeepSeek-VL2：基于改进的 DeepSeek-V2 Transformer，部分版本引入 MoE 机制和 MLA 机制，提升参数利用率和推理效率。
● Janus：使用单一统一的 Transformer 处理多模态输入，依靠解耦设计获得更好的任务适应性和交互性，并在 JanusFlow 中融合自回归与 rectified flow 实现图像生成。

**4．训练与推理优化**
● DeepSeek-VL2：采用多阶段训练策略，即视觉语言对齐、预训练、监督微调，并引入增量预填充技术，保证在高分辨率多模态场景下的高效推理。
● Janus：侧重数据与模型规模的扩展，通过优化训练策略提升理解与生成能力，确保在统一框架下多任务性能兼顾。

总的来看，DeepSeek-VL2 更偏向细粒度视觉信息与语言模型的深度融合，Janus 则通过视觉编码解耦和生成技术集成，追求更广的多模态统一性与灵活性。

### **6.5.2** **多模态架构实现**
modeling_deepseek_vl_v2.py 定义了模型的核心组件，包含视觉编码器、多层感知机投影器与语言模型，实现多模态融合并处理视觉与文本输入输出。

● 视觉编码器 VisionTransformer：提取输入图像的视觉特征。
● 多层感知机投影器 MlpProjector：将视觉特征映射到语言模型嵌入空间，实现视觉与文本特征对齐。
● 语言模型 DeepseekV2ForCausalLM：基于 Transformer 的自回归语言模型，生成文本输出。
● 多模态融合：把视觉特征与文本特征结合，用于复杂多模态任务的理解与处理。

（1）该类用于将视觉特征投影到语言模型嵌入空间，支持恒等投影、线性投影、带 GELU 激活的 MLP 投影、下采样 MLP 投影等多种方式。
[PRE12][PRE13][PRE14]

（2）代码定义了视觉编码器的配置类 VisionEncoderConfig，继承自 PretrainedConfig，保存模型名称、图像尺寸、注意力头数等超参数，用于实例化与训练。
[PRE15][PRE16]

类 DeepseekVLV2ForCausalLM 是一个多模态模型，可处理视觉与语言输入。内部融合视觉编码器、视觉语言投影器与语言模型，VisionTransformer 负责图像特征提取，投影器将视觉特征映射到与语言模型兼容的嵌入空间，语言模型基于处理后的视觉与文本输入生成输出。该类提供 prepare_inputs_embeds 与 incremental_prefilling 等函数，确保多模态数据的高效处理。

（3）MlpProjectorConfig 继承自 PretrainedConfig，用于定义 MLP 投影器的参数，包含模型类型、投影器类型、输入维度、嵌入维度、深度、MLP 比例、下采样比例等，便于灵活配置。
[PRE17]

（4）代码定义了 DeepSeekVLV2CausalLMOutputWithPast 数据类，继承自 ModelOutput，用于表示自回归语言模型输出，包含 loss、logits、past_key_values、hidden_states、attentions、rope_deltas 等属性，方便训练与推理时获取输出与内部状态。
[PRE18][PRE19]

（5）类 DeepseekVLV2Config 为配置类，继承自 PretrainedConfig，管理 DeepseekVLV2 模型的配置参数，包含 vision_config、projector_config、language_config，以及图像标记方式 tile_tag、全局视图位置 global_view_pos、候选分辨率 candidate_resolutions 等。初始化时会从关键字参数中提取子配置并实例化。
[PRE20][PRE21]

（6）DeepseekVLV2PreTrainedModel 为预训练模型基类，继承自 PreTrainedModel，指定配置类为 DeepseekVLV2Config，并将模型前缀设为 deepseek_vl_v2，定义 _no_split_modules 与 _skip_keys_device_placement 控制保存、加载与分布式训练行为。
[PRE22]

（7）类 DeepseekVLV2ForCausalLM 实现多模态自回归语言模型，集成视觉编码器、视觉投影器与语言模型，可联合处理图像与文本。首先用 VisionTransformer 提取图像特征，经 MLP 投影器映射到文本嵌入空间，再与文本标记结合输入语言模型生成。此外支持增量预填充，通过分块前向计算与 past key values 缓存加速自回归生成，并提供辅助函数管理 CUDA 内存与缓存状态，实现高效多模态推理。

● 方法 __init__()：初始化类实例，根据配置构建视觉编码器 VisionTransformer、视觉投影器 MlpProjector，确定图像标记格式如 2D 或 1D，同时实例化语言模型 DeepseekV2ForCausalLM，构建整体多模态结构，并设置图像 token 格式化的特殊参数如 ＜|view_separator|＞ 和 ＜tile_newline＞。
[PRE23][PRE24][PRE25]

● 方法 prepare_inputs_embeds()：生成输入嵌入，将文本 token 嵌入与经视觉编码器和投影器处理后的图像 token 嵌入融合。若无图像输入则直接返回文本嵌入；否则根据图像空间切片信息计算每个 batch 的平铺数量，提取视觉特征并投影得到图像嵌入，再按预设 tile 格式对全局与局部视觉特征做格式化，利用 masked_scatter_ 将图像 token 嵌入填充到对应文本嵌入序列中，最终返回融合视觉信息的输入嵌入。
