##### 3. 技巧三：上下文管理与渐进式引导

1）原理/说明

当任务篇幅极长或包含若干独立阶段时，一次性交付全部指令容易超出模型的有效上下文容量，即便容量充足，模型也难以一次兼顾全部细节。此时可采用分步提示或链式提示策略：先让模型完成任务的子集或某一阶段，再依据已有产出给出下一步指令并补充必要上下文。这要求对对话历史和累积信息进行有效管理。例如进入下一阶段时，主动归纳前序对话的关键结论或模型生成的关键中间结果，并将其作为新提示的一部分，以维持任务连贯性。

2）应用示例

- 首轮提示：“请阅读‘××品牌奇迹光感持妆粉底液’的产品资料，以列表形式归纳出 5 条核心卖点。”（模型产出卖点列表 A）

##### 4. 技巧四：模型参数的精细调控

1）原理/说明

LLM 的生成行为受多项可调参数影响。其中，温度 Temperature 参数控制输出的随机性与创造性；数值越低如 0.1～0.5，输出越趋向确定、高概率选择，风格更专注保守；数值越高如 0.7～1.0，输出更具多样性和创造性，但也更不可预测。Top-p 核心采样控制模型生成每个词时考虑的候选词集合的累积概率。对于需要严格遵循复杂指令的任务，适度调低 Temperature 或 Top-p 可有效降低模型自由发挥的程度，使其更忠实执行指令，降低跑题或生成无关内容的可能性。

2）应用示例

在执行对格式和规则要求严格的商业文案生成任务时，可将 Temperature 参数设为 0.3。这样在保证流畅性的同时，能确保模型输出的内容和风格符合指令要求，降低因随机性过高导致的不稳定。

#### 3.1 扣子简介

扣子是一个用于创建、配置与管理各种 Agent 与应用的平台，根据不同复杂程度的逻辑处理需求，支持“单 Agent 模式”与“多 Agent 模式”两种开发方式。

平台不仅支持字节跳动自研的 LLM（如 Doubao-1.6-thinking），还兼容第三方 LLM（如 DeepSeek-R1、DeepSeek-V3、Kimi、通义千问 Max、智谱 4）；既支持文本处理大模型，也支持图像理解视觉模型（如 Doubao-1.5-vision-pro）。

无论你是否具备编程基础，都可以在扣子上快速搭建基于大模型的 AI 应用，并将这些应用发布到微信等平台，或通过 API 或 SDK 将 AI 应用集成到各类业务系统中。

借助扣子提供的可视化设计与编排工具，用户可通过零代码或低代码的方式快速搭建满足个性化需求、实现商业价值的 AI 项目。
