**DeepSeek-VL2 体系全拆解**

**1．训练数据准备**
DeepSeek-VL2 采用三类训练素材：视觉语言对齐样本、视觉语言大规模预训练样本、监督微调样本。对齐样本用于首轮 MLP 衔接训练，预训练样本用于提升跨模态理解能力，微调样本用于进一步打磨任务表现。

素材涵盖公开库与内部采集，任务类型包括视觉问答、光学字符识别、文档解析、视觉定位等。来源广泛、类型多样，有助于模型具备更强的泛化与适应能力。

**2．模型训练流程**
整体训练划分为初始化、视觉语言预训练、监督微调三步。

（1）初始化阶段，视觉编码器与语言模型各自完成单模态预训练，分别获得初始的视觉表征与语言表征。
（2）视觉语言预训练阶段，借助海量多模态语料训练对齐与融合能力，通过多任务学习与对比学习提升对不同场景的理解与处理水平。
（3）监督微调阶段，使用带标注的多模态语料进行精细优化，模型在任务特定损失的驱动下更好地完成问答、文档理解等任务，配合指令调优强化对话与推理。

**3．并行训练与资源优化**
● 并行策略：训练中同时使用模型并行、数据并行、专家并行，充分发挥 GPU 集群如 NVIDIA A100 的分布式算力。
● 负载均衡与切片调度：针对动态切片的视觉编码器，因不同图像切片数量差异，采用细粒度层级切分结合数据并行，实现前向与反向传播时的 GPU 负载均衡。

### **6.1.4** **对比 Janus 项目**
DeepSeek-VL2 与 Janus 同属 DeepSeek 开源多模态方向，侧重点与实现差异明显。DeepSeek-VL2 以动态平铺加 SigLIP 编码器实现高分辨率图像的细粒度特征提取，结合视觉语言适配器与融合 Multi-head Latent Attention 的 MoE 语言模型，支撑问答、OCR、文档解析、定位等任务；Janus 主张统一的理解生成框架，核心是解耦视觉编码通路，同时优化理解与生成，并借 JanusFlow 融合自回归与 rectified flow 实现高效文本到图像合成。

**1．设计侧重点**
DeepSeek-VL2：聚焦高分辨率图像精细特征提取与视觉语言深度融合，适用于问答、OCR、文档理解、定位。
Janus：聚焦统一多模态平台建设，通过解耦视觉编码实现理解与生成并行优化，并以 JanusFlow 提升文本到图像质量。

**2．视觉编码方法**
● DeepSeek-VL2：动态平铺配合 SigLIP 编码器做分块处理，经视觉语言适配器把图像特征转为语言模型输入。
● Janus：采用解耦式视觉编码，分别提取视觉特征后统一送入 Transformer，降低编码与生成间的冲突。

**3．语言模型架构**
● DeepSeek-VL2：基于改进 DeepSeek-V2 Transformer，部分变体引入 MoE 与 MLA，提升参数利用与推理效率。
● Janus：使用统一 Transformer 处理多模态输入，依托解耦设计获得更好任务适应性与交互性，JanusFlow 中融合自回归与 rectified flow 实现图像生成。

**4．训练与推理优化**
● DeepSeek-VL2：三阶段训练，即对齐、预训练、监督微调，并引入增量预填充，保证高分辨率多模态场景下高效推理。
● Janus：强调数据与模型规模扩展，优化训练策略提升理解与生成能力，在统一框架下兼顾多任务表现。

总体而言，DeepSeek-VL2 更偏向细粒度视觉信息与语言模型的深度融合，Janus 通过编码解耦与生成技术集成追求更广的统一性与灵活性。

### **6.5.2** **多模态模型架构**
modeling_deepseek_vl_v2.py 定义核心组件，包括视觉编码器、多层感知机投影器与语言模型，实现多模态融合并处理视觉与文本输入输出。

● 视觉编码器 VisionTransformer：提取图像视觉特征。
● 多层感知机投影器 MlpProjector：将视觉特征映射到语言模型嵌入空间，实现对齐。
● 语言模型 DeepseekV2ForCausalLM：基于 Transformer 的自回归模型，生成文本。
● 多模态融合：将视觉与文本特征结合，用于复杂多模态任务理解与处理。

（1）该类用于把视觉特征投影到语言模型嵌入空间，支持恒等投影、线性投影、带 GELU 激活的 MLP 投影、下采样 MLP 投影等。
[PRE12][PRE13][PRE14]

（2）代码定义视觉编码器配置类 VisionEncoderConfig，继承自 PretrainedConfig，保存模型名称、图像尺寸、注意力头数等超参数，用于实例化与训练。
[PRE15][PRE16]

类 DeepseekVLV2ForCausalLM 为多模态模型，可处理视觉与语言输入。内部融合视觉编码器、视觉语言投影器与语言模型，VisionTransformer 负责图像特征提取，投影器将视觉特征映射到与语言模型兼容的嵌入空间，语言模型基于处理后的视觉与文本输入生成输出。该类提供 prepare_inputs_embeds 与 incremental_prefilling 等函数，确保多模态数据高效处理。

（3）MlpProjectorConfig 继承自 PretrainedConfig，用于定义 MLP 投影器参数，包括模型类型、投影器类型、输入维度、嵌入维度、深度、MLP 比例、下采样比例等，便于灵活配置。
[PRE17]

（4）代码定义 DeepSeekVLV2CausalLMOutputWithPast 数据类，继承自 ModelOutput，用于表示自回归语言模型输出，包含 loss、logits、past_key_values、hidden_states、attentions、rope_deltas 等属性，便于训练与推理时获取输出与内部状态。
[PRE18][PRE19]

（5）类 DeepseekVLV2Config 为配置类，继承自 PretrainedConfig，管理 DeepseekVLV2 模型配置参数，包含 vision_config、projector_config、language_config，以及图像标记方式 tile_tag、全局视图位置 global_view_pos、候选分辨率 candidate_resolutions 等。初始化时从关键字参数提取子配置并实例化。
[PRE20][PRE21]

（6）DeepseekVLV2PreTrainedModel 为预训练模型基类，继承自 PreTrainedModel，指定配置类为 DeepseekVLV2Config，模型前缀设为 deepseek_vl_v2，定义 _no_split_modules 与 _skip_keys_device_placement 控制保存、加载与分布式训练行为。
[PRE22]

（7）类 DeepseekVLV2ForCausalLM 实现多模态自回归语言模型，集成视觉编码器、视觉投影器与语言模型，可联合处理图像与文本。首先用 VisionTransformer 提取图像特征，经 MLP 投影器映射到文本嵌入空间，再与文本标记结合输入语言模型生成。此外支持增量预填充，通过分块前向计算与 past key values 缓存加速自回归生成，并提供辅助函数管理 CUDA 内存与缓存状态，实现高效多模态推理。

● 方法 __init__()：初始化实例，根据配置构建视觉编码器 VisionTransformer、视觉投影器 MlpProjector，确定图像标记格式如 2D 或 1D，同时实例化语言模型 DeepseekV2ForCausalLM，构建整体多模态结构，并设置图像 token 格式化的特殊参数如 ＜|view_separator|＞ 和 ＜tile_newline＞。
[PRE23][PRE24][PRE25]

● 方法 prepare_inputs_embeds()：生成输入嵌入，将文本 token 嵌入与经视觉编码器和投影器处理后的图像 token 嵌入融合。若无图像输入则直接返回文本嵌入；否则根据图像空间切片信息计算每个 batch 的平铺数量，提取视觉特征并投影得到图像嵌入，再按预设 tile 格式对全局与局部视觉特征做格式化，利用 masked_scatter_ 将图像 token 嵌入填充到对应文本嵌入序列中，最终返回融合视觉信息的输入嵌入。
