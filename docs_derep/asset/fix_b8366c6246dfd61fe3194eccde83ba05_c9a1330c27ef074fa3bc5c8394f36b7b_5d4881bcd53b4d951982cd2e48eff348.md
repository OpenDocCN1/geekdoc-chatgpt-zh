**常见问题排查**
先看日志：
openclaw logs | grep dingtalk
高频问题三类。
（1）机器人零反应。核查：应用是否已发布、消息接收是否选了 Stream、Gateway 是否在跑。
（2）群消息不回。确认机器人已加入群且消息格式为 @机器人名称，同时群必须是企业内部群，普通群不支持。
（3）连接老断。多数是网络抖动。插件自带指数退避重连，短暂中断会自动恢复。若长期断开，检查服务器能否访问钉钉 API。

**企业微信实用场景**
（1）群助手：把机器人拉进企业内部群，@ 即可提问执行，仅支持企业内部群。
（2）智能表格联动：在智能表格开启接收外部数据，把 Webhook 地址告诉机器人，说“帮我插入一条数据”即可自动写入，适合日报、客户信息录入。

**常见问题排查**
问题1：找不到“智能机器人”入口。更新客户端，仍无则让管理员在管理后台→安全与管理→管理工具中开启。
问题2：插件安装失败。多为网络，先设国内镜像源再重试。
问题3：配对码过期。配对码有时效，需重新触发消息获取新码再执行 pairing 命令。
问题4：发消息收不到回复。检查 Gateway 是否运行：openclaw gateway status；检查 AI 模型 API Key 是否正确、余额是否充足，日志通过 openclaw logs 查看。

[PRE21]

**安全提醒**
企业微信智能机器人权限较高，建议只在可信环境使用。个人测试请合理设置可见范围，Bot ID 和 Secret 相当于钥匙，切勿泄露。
