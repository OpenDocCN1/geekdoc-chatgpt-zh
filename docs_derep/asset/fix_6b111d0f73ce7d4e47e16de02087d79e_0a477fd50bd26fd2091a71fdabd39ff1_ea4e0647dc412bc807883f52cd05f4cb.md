# 1.1 为什么AI写东西又快又好

想想每天要写的报告、邮件、商业计划，全部交给一个智能助手处理，甚至比自己更流畅，工作量几分钟就收尾，是不是很诱人。

随着生成式AI成熟，以上设想已成现实。有4A公司的人士透露，两家团队投标，靠人力撰写的方案落选，反而是AI生成的投标书拿下了订单。由此可见产出水准。

作为“写作助手”，AI能按需产出各式文章，让写作更轻松高效。

AI在写作上的优势体现在：

+ 1. 生成速度快。AI擅长海量数据筛选与整合，能迅速提炼有效素材，按逻辑拼接成结构清晰、条理严谨的文本，省去大量查阅与整理时间。
+ 2. 类型覆盖广。AI灵活性强，可按需求输出新闻稿、博文、产品说明等多种文体，还能模仿指定风格与语气，让成品更贴合个人习惯与读者偏好。
+ 3. 质量可提升。它能在短时间内产出语法干净、用词精准的稿件，同时给出修改建议，帮助优化结构与表达，整体水平明显提高。

把初稿交给AI，既能减轻负担，也能激发灵感。先让AI出初版，再结合自身思路润色完善，最终就能得到一份满意的好文章。

# 1.2 五步掌控AI，避免“一本正经地胡说八道”

ChatGPT作为当前主流写作工具上线后迅速走红。但不少用户也发现，它偶尔会“认真胡说”，比如篡改经典表述，或引用并不存在的文献。

用AI写作不能照抄粘贴，必须保持自己的判断与逻辑。下面这套基本流程，能帮助你更好地掌控AI。

选择合适的工具：市场上AI写作产品众多，各有侧重。
在这些工具里，OpenAI的ChatGPT擅长依据指令产出高质量内容，输入关键词或问题即可生成条理清楚、观点明确的文章。
除ChatGPT外，百度的文心一言、阿里云的通义千问也表现突出，它们对国内语言文化和多场景应用理解更深，本地化输出更实用。

明确写作目标：
使用前先把任务说清，比如要写产品说明、推销邮件等，并提供足够背景，让AI准确理解需求，才能命中要害。

逐步优化：
想拿到更好结果，就要持续打磨提问。可通过调整关键词、补充细节来引导方向，也可多轮尝试对比不同输入的产出，找出最优解。

审阅和修改：
AI写作能力再强也替代不了人类的创造力。生成内容后必须仔细校对、必要时改写，保证质量与阅读体验。

善用模板和规范：
多数AI写作工具内置丰富模板与格式规范，可按需选用，让AI直接输出结构正确、格式统一的文本。

掌握以上五步，就能把AI真正用好。

# 1.3 六大场景提问技巧，轻松完成各类写作

要让AI“小助手”在不同写作场景下发挥作用，关键在于提问方式。下面6种结构化提问法能帮助你更精准表达需求。

本书提供的方法适用于目前主流AI写作工具，可多工具协同生成再整合。

故事叙述：可用“开场—发展—高潮—结局”来组织问题。

提问举例
+ 请按四个部分写一个科幻故事：1 开场，描写宇航员在太空站的日常；2 发展，宇航员捕捉到神秘信号；3 高潮，揭开信号真相；4 结局，宇航员获得意外启发。

产品描述：可用“功能—优势—使用场景—购买方式”来组织问题。

提问举例
+ 请从四个方面介绍一款智能音箱：1 主要功能；2 产品亮点；
[PAGE 12]
3 适用场景；
4 购买渠道与价格。

报告撰写：可用“背景—问题—分析—建议”来组织问题。

提问举例
+ 请写一份某公司营销策略分析报告，包含：1 公司背景与市场状况；2 营销中存在的问题；3 问题分析；4 改进建议。

邮件和信件撰写：可用“称呼—正文—结束语”来组织问题。

提问举例
+ 请写一封感谢信：1 收信人为李先生；2 感谢他为学校捐赠图书；3 结尾表达期待未来合作。

新闻稿和公告撰写：可用“标题—导语—正文—结语”来组织问题。

提问举例
+ 请写一篇某公司新品发布会新闻稿，包含：1 吸睛标题；2 提炼性导语；
[PAGE 13]
3 详细描述发布过程与产品特点；4 结语表达对公司未来期待。

学术论文和专业文章撰写：可用“引言—方法—结果—讨论—结论”来组织问题。

提问举例
+ 请写一篇关于人工智能在医疗领域应用的研究论文，包含：1 引言介绍研究背景与意义；2 方法描述研究方法与数据来源；3 结果展示研究发现；4 讨论对结果进行对比分析；5 结论总结成果并展望未来。

掌握这些场景化提问法，就能有效引导AI产出预期内容，提升写作效率。只要提问技巧到位，AI就能成为得力写作助手。

本书共分6章，覆盖职场生活大部分场景，帮助你用AI完成40多种文章写作。

现在就开启AI写作之旅吧！

注意事项
1. 提问时务必给出详细背景，如时间、地点、人物、事件等，便于AI更好理解。
2. AI单次回复有字数限制，长文案可能中断，此时发送“继续”即可续写。
3. AI生成内容可能与事实不符，需甄别修改。
4. 相同指令下AI每次输出不完全相同，可批量生成后挑选优质片段整合。

# 2.3 工作总结：告别抓耳挠腮

工作总结对团队和个人都意义重大，既能提升沟通效率、帮助领导掌握进展，也能展现个人成果、为后续工作指路。

但要梳理项目、做分析、写成文字，往往耗时耗力，对分析、总结、表达能力要求很高。

借助AI快速梳理思路、组织语言，能大幅提升效率。下面两种思路可参考。

思路一：
第一步，确定框架。告知AI汇报人、汇报对象、汇报主题等背景，让AI生成框架。框架不合适可要求重写，直至满意。

第二步，填充信息，生成总结。根据AI框架补充具体信息，给出语言要求，让其成文。
根据你给的框架，我已完善信息，请为我生成工作总结。要求语言规范简洁，突出优点与成绩。

第三步，反馈迭代。继续发送修改指令，让AI不断优化。

第一步，训练AI。通过逐步提问，让AI理解优质工作总结的特征。

# 2.8 商业信函：快速建立信任

商业信函用于与客户、供应商、合作伙伴沟通，关系到合作达成与公司形象。结构、内容、语气都需规范，否则易损信誉、错失商机。

可按以下思路操作：
第一步，确定类型。商业信函有询问型、回复型、邀请型、感谢型等，先明确类型。
第二步，确定受众。明确收件人身份并提供相关信息。
第三步，确定目的。说明写作目标与具体要求。
第四步，补充信息。提供公司名称、联系方式、产品介绍等必要信息，也可上传草稿作为参考。
第五步，生成内容。

注意事项：
1. AI可辅助生成文字，但排版等精细工作仍需人工优化。
2. AI对受众情感需求把握有限，生成稿可能不够人性化，需人工润色。

# 2.9 面试题库：秒变专业面试官

面试题库能快速评估应聘者能力、经验与素质，保证公正性并提升效率。

可按以下思路提问：
第一步，确定类型。先明确面试题的类型。
第二步，生成题目。按类型批量生成题目。
第三步，拓展题目。可要求AI继续生成，再筛选。
第四步，整合梳理。整理成题库后，可咨询AI关于编写建议与注意事项，进一步提升质量。

注意事项：
1. AI无法主观判断，可能给出不准确答案，影响评估，需甄别。
2. 编写题目需结合经验与公司行业需求，不能过度依赖AI。
3. 题目可能涉及应聘者隐私，提问时注意保护。

# 2.10 会议邀请函：简洁大方有诚意

会议邀请函用于邀请个人或组织参加研讨会、培训、商务活动等。好的邀请函能清晰传达信息、激发兴趣、体现专业。

可按以下流程引导AI：
第一步，询问所需信息。先问AI邀请函应包含哪些要素。
第二步，提供信息。按实际需求增减信息。
第三步，询问修改建议。不清楚如何优化时可直接请教AI。
第四步，反馈迭代。根据建议对稿件反复优化。

注意事项：
1. AI在表达期望与感谢时用词可能生硬，需人工修改。
2. AI提供的范例可能不完全适配中文语境，可提供更好范例作参考。

# 2.11 会议发言：逻辑清晰显水平

会议发言需简洁明了、逻辑清晰，才能体现思维与表达能力。

可尝试用AI生成发言稿：
第一步，交代背景。告知主题、发言人、听众、场合、时长等。
第二步，生成框架。让AI提供内容框架。
第三步，优化框架。对框架不满意可提出修改指令并补充信息。
第四步，生成发言稿。
