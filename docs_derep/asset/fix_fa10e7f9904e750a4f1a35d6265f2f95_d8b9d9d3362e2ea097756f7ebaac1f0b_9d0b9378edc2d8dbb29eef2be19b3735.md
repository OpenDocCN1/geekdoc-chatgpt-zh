## 程序语言到底指什么

机器为何能按人的想法工作，甚至显得聪明？读过前三册的同学应该明白，关键不在于机器本身，而在于人类把每一步操作写成一条条指令交给计算机执行。计算机按部就班计算，于是看起来“机智”。这些指令的集合就叫**计算机程序**，也就是代码。编程的本质就是给出精确的指令。

我们日常使用的软件、手机 App、强大的 AI 系统，背后都是编程实现的。可以说**代码构成了 AI 软件产品的“身体”**。

给软件加上机械外壳，再用软件驱动硬件，就有了扫地机器人、无人驾驶汽车这类 AI 硬件产品。总而言之，掌握编程是创造 AI 产品不可或缺的能力。

可计算机不懂人话，必须用它能懂的语言，也就是**程序语言**。人类有汉语、英语、日语等，计算机语言也种类繁多，比如大家熟知的**C 语言、Java 语言、C++语言**，如图 1-1 所示。

## Python 由谁创造

Python 的创造者是荷兰程序员吉多·范罗苏姆，曾在荷兰数学与计算机科学研究学会工作。1989 年 12 月，他为打发圣诞节长假而构思新语言，这个想法就是 Python。当然一周内完成不现实，假期后他继续完善，于 1991 年以开源形式发布了最初版本 Python 0.9.0。到 2021 年 8 月，Python 3.10 基本开发完成，数以万计的开发者参与贡献。

趣闻　什么是开源？

“开源”即开放源代码。大多数商业软件只能使用，看不到内部代码，这类叫闭源。有些开发者公开源代码，让大家了解原理并共同改进，这就是开源软件。开源协作是计算机飞速发展的重要推动力，很多关键技术都诞生于此。

Python 这个词本意是“大蟒蛇”，选它不是因为想让语言像蟒蛇一样强壮，而是范罗苏姆喜欢《巨蟒剧团之飞翔的马戏团》这部剧。

## Python 为什么适配 AI

Python 语言非常简洁，贴近人类思维。和 C 语言要求程序员迁就机器不同，Python 让机器更贴近人。好的 Python 代码就像一个用英语表达极其严谨的人在说话，易读易懂。用它可以专注解决问题，而不是纠结语法规则。这也是 AI 领域青睐它的原因——做 AI 已经够难了，写代码就该省点力。

Python 也有短板，比如运行速度相对慢，而 AI 通常计算量大，需要快速。好在 Python 有一个优势：**能很方便地调用其他语言写的程序段**。计算密集的部分可用 C 等高性能语言实现，再用 Python 搭建整体结构并调用，兼顾开发效率与运行速度。因此 Python 常被戏称为“**胶水语言**”，像胶水一样把各零件粘合在一起，如图 1-2 所示。
