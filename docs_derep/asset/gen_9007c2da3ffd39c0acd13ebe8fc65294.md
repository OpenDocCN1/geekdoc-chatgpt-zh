ChatGPT 上线后的扩散速度可以用数字说话：首日注册突破10万，5天内飙到100万，两个月用户就破1亿。对比来看，同样以增速著称的 TikTok 花了9个月才累积1亿用户，微信的同等体量也用了433天。这样的体量在当时堪称现象级。

节奏很快，但很快出现了变化。OpenAI 新模型发布的间隔从一年延长到了两年。官方解释是引入了基于人类反馈的强化学习，不过这只是表层原因。

2023年3月14日 GPT-4 正式亮相。它在美国律师资格考试中达到第90百分位，SAT 成绩位于第93百分位，还能读懂梗图和漫画。内部测试里，工程师观察到模型在处理复杂逻辑时出现了“涌现能力”，出现了超出训练数据范围的表现。

热度背后质疑也在累积。用户开始感觉模型变钝了，AI 训练瓶颈被反复提及，资本的情绪从狂热转向审慎。2024年6月高盛的报告称，72%的AI初创公司尚未盈利，生成式AI整体处于亏损投入阶段。高投入低回报成为市场共识。

行业情绪趋于谨慎，数据瓶颈、电力瓶颈、算力瓶颈以及规模定律失效的担忧同时出现。人们一边怀疑，一边仍在等待 OpenAI 能用更聪明的 GPT-5 重建信心。于是很长一段时间，奥尔特曼在社交平台上无论说什么，评论区都会统一追问：GPT-5在哪？

在这样的期待下，2024年9月13日 OpenAI 推出 o 系列的首个模型 GPT-o1。它没有继续单纯堆叠参数，而是把重点放在强化学习驱动的推理能力提升上。转折点由此出现：之前 OpenAI 少有对手，此后则要时刻面对 DeepSeek 的挑战。这也回到最初的疑问，明明可以靠 GPT-5 继续领跑，为何要先推出推理模型给自己制造变量？

## Scaling Law：从护城河到绊脚石

规模定律曾为 OpenAI 构筑护城河，如今却像堰塞湖一样随时可能溃坝。

2023年奥尔特曼公开承认公司正遭遇“GPU极端短缺”，训练 GPT-4 约消耗 355 PFLOPS-day，相当于355台百亿亿次超级计算机运行一天。英伟达 H100 供不应求且价格高昂，让继续扩容变得不现实。业内估算，GPT-5 的算力需求至少是 GPT-4 的10倍，在现有硬件条件下难以达成。

算力之外，数据更棘手。Transformer 架构下，2018年的 GPT-1 用约7000本书的预训练就能预测下一个词。到了 GPT-3，参数规模膨胀约1500倍，数据消耗增长约9000倍。在显卡昂贵而数据相对便宜的背景下，OpenAI 把几乎所有可获取的数据都纳入训练池，这种做法加速了迭代，也透支了优质数据的储备。

Epoch AI 预计，2026年后人类新增数据量将低于模型学习需求，到2028年大语言模型可能耗尽互联网上的高质量文本。互联网内容的年增幅不到10%，而大模型对训练数据的需求却每年翻倍。GPT-4 的训练数据约1.8万亿令牌，是 GPT-3 的十倍以上，而公开互联网文本总量仅约5万亿令牌。

数量之外质量也在下降。社交媒体和论坛等低质内容占比超60%，专业图书、学术论文等优质数据不足15%。欧盟 GDPR 等隐私法规限制了医疗、金融等敏感数据的采集，《纽约时报》起诉 OpenAI 侵权等法律纠纷进一步压缩公开数据的空间。2023年到2024年间，主流数据源被网站封禁的比例从3%升至33%，数据获取成本显著抬升。

在这种局面下迟迟不上 GPT-5，倒像一句调侃所言：不是不想，是上不去。转而押注推理模型，对 OpenAI 来说是换赛道继续保持技术领先的策略。

o1 的核心做法是通过强化学习对推理过程进行引导。具体采用改进版 PPO 近端策略优化，并结合人类反馈奖励机制，让模型在回答时先拆解问题、逐步验证逻辑，而非直接输出答案。以数学问题为例，模型会把题目分解为子步骤逐一检验。这种分步思考提升了复杂任务的准确率，但也带来代价：响应时间延长10到20倍，推理阶段的算力消耗增加3到4倍。

研究表明，模型表现不仅取决于参数规模，也与推理时的计算量密切相关。即使参数不再增长，通过优化推理算法仍能提升特定任务能力。o1-preview 在数学基准测试中超过 GPT-4o，而参数规模仅为后者的三分之一。这说明推理阶段的规模效应可以弥补参数规模的停滞。

与通用大模型不同，o1 聚焦需要深度逻辑推理的场景，如数学和编程。它减少了对大规模通用数据的依赖，借助领域特定的强化学习进行精细优化。在代码生成任务中，o1 会模拟程序员调试过程，降低语法错误和逻辑漏洞。这种专业化路径既能保持竞争力，又降低了对算力的需求。

整体来看，OpenAI 从过去的“堆规模”转向更注重效率的战略。

那么推理模型到底是什么？

它指能够模拟人类思考过程、在输出结果前展示中间推导步骤的系统。与传统端到端直接给答案的模型不同，推理模型会先拆解问题、建立逻辑链、权衡多维度因素，再给出可解释的结论。

举例来说，用户问“北京到上海如何安排行程最合理”。传统模型可能直接回答“坐高铁”。推理模型则会先列举飞机、高铁、自驾等多种方式，再比较耗时、费用、舒适度，并结合实时天气、是否携大件行李等外部因素，最后给出平衡时间与成本的高铁建议并提供备选方案。它通常结合知识图谱、概率推理和深度学习协同工作，提升结果可信度。

再看一道算术题：“书架5层每层30本，后来新增2层每层20本，共多少本？”传统模型可能直接给数，推理模型则展示过程：原有5×30=150本，新增2×20=40本，总计190本。步骤透明便于核验错误。

这个展示思考过程的机制就是思维链 CoT。即让 AI 不仅给出答案，还把推理步骤写出来。OpenAI 的思维链是隐式的，DeepSeek 的则是显式的。

“8.9 和 8.11 谁大”常被用作智商探测器。一张在网上流传的截图显示，不具备思维链的 GPT-4o 给出了错误判断。另一张截图来自具备显式思维链的 DeepSeek，灰色部分就是思维链，答案正确且给出了验证方法和另一种解法。这体现了思维链的价值。

预计 o1 的技术积累能帮助 OpenAI 缓解无法及时发布 GPT-5 的尴尬，只是 DeepSeek 的强势崛起，让人感慨既生瑜何生亮。

## 绕过监督微调：DeepSeek 的另类打法

DeepSeek 的差异化在于训练方法，它在构建推理模型时直接引入 GRPO 算法做强化学习，基本跳过了传统流程。

先厘清背景。大语言模型训练通常分为预训练和后训练，后训练再细分为监督微调和强化学习，共三步，对应基础模型、监督微调模型、强化学习模型。

预训练阶段，模型在海量文本上进行无监督或自监督学习，掌握语法、词汇等基础能力。完成后模型具备通用语言能力，但仍可能产生不准确或有害信息，需要后训练优化。

受算力和数据制约，预训练的暴力扩张接近天花板。GPT-4 参数量已接近理论极限，高质量公开文本也被反复清洗。预训练正从堆规模转向精细化。

后训练成为差异化主战场。PPO 是 OpenAI 在该阶段使用的强化学习算法。需要明确三点：一是训练依赖算法如反向传播、PPO；二是模型参数量决定规模，DeepSeek 系列后缀如 671B、70B 即指6710亿参数等，参数越大能力越强但越耗算力；三是模型可以用来训练模型，提供数据或担任评判，这也是 PPO 的一部分。

监督微调 SFT 的作用是通过有标注数据调整预训练模型，以适应特定任务。以情感分析为例，取 GPT-3 为基础，用标注为积极、消极、中性的社交媒体评论进行微调，让模型学会将“这款手机非常好，功能强大，值得购买！”归为积极，将“手机有点卡，电池续航差，失望”归为消极。通过训练集和验证集的反复优化，模型在该任务上的准确率提升。

DeepSeek 的做法是直接砍掉监督微调，这大幅减少了对标注数据的依赖，节省成本和时间。它自己也承认这样会带来可读性下降、逻辑错乱、中英文混杂等问题，这正是缺乏监督微调的通病，但通过强化学习可以缓解。

## 强化学习为何卷土重来

强化学习并非新概念。2016年 AlphaGo 以4比1击败李世石使用的就是强化学习，前文提到的人类反馈强化学习也是同一家族，后训练的第二步同样是强化学习。

强化学习指智能体通过与环境互动，在试错中最大化累积奖励。与监督学习不同，它不需要标注数据。

可以类比迷宫游戏。你是智能体，迷宫是环境，每个位置是状态，选择上下左右是动作，到达出口获得100分，走错得-1分。策略决定在每个状态如何选择。不断探索和利用经验，玩家会逐渐学会最优路径。强化学习正是让智能体通过不断试错优化决策的过程。
