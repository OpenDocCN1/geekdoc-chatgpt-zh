大模型具备较强的环境适应性与交互能力，在人类反馈强化学习的支持下，译者可以按照个人或项目的具体需求与模型展开协作，不断提升译文水准。初稿产出后，借助精细化的提示词继续打磨，就是译文迭代优化的典型路径。翻译实践大致可归为继承、改良、原创三类，其中改良类在译材质量偏低或文本复杂度较高时更为关键。译者需要在多重表述中筛选出最合适的译法，也可在原有基础上提出更优方案。常见的改良手段包括术语校准、文体调适、结构重组、歧义厘清和文化对接，配合 RAG 也可以进一步提升初译质量。这些做法体现了译者在技术环境中占据主导、发挥创造性的作用。

二、RAG 辅助下的译文优化

RAG 的基本思路是把用户提供的知识拆分为文本块并向量化存入数据库，检索时将查询向量化后按语义相似度召回相关上下文，再与提示词共同驱动模型生成。优势在于能够调用词典、术语库、翻译记忆库、平行语料等外部资源，提高检索准确度，最终输出更高质量的译文。实现方式常见的本地助手如 AnythingLLM 与 CherryStudio，支持文件夹、网址、XML 站点地图、纯文本等多种导入方式，通过创建知识库即可实现 RAG 翻译。

## 3.AI 在译后阶段的应用

凭借强大的自然语言理解能力，大模型可以对译文进行深度分析，识别常见错误并生成多维度质量评估报告，需结合人工复核修正。

3.1 生成多维度译文质量评估报告

译后质量评估是核心环节。人工评估适合小批量但耗时且易受译者水平限制。机器评估更为系统客观。王均松等（2024：136-138）将机器翻译质量评估分为人工评估、有参考译文的自动评估、无参考译文的自动评估，各有优劣。

为提升客观性，可采用“机器指标+人工框架”的提示词。机器指标选用 BLEU，用以衡量 N-gram 匹配度；人工框架选用 MQM，多维质量指标体系，错误分为准确性、流利度、术语、区域惯例、风格、真实性、格式、国际化八类，严重程度分轻微、重大、严重，最终得分=总分–译文扣分+原文扣分。（田朋，2020；杨博超、冷冰冰，2024）
