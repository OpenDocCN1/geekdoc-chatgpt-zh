DeepPayload 这项工作在思路上跟 TrojanNet 有不少共通之处。TrojanNet 的做法是在模型真正做推理之前先挂一个极轻量的木马子网，一旦输入里带有预设的触发模式，这个子网就会被点亮，把最终输出强行拉向攻击者指定的类别，而在正常样本上它几乎不产生可感知的干扰。

# 4.2.3 其他数据类型的后门攻击

前面提到的案例多以计算机视觉为主，后门其实是可以跨模态迁移的。自然语言处理、语音处理等方向都有对应的投毒研究。

Dai 等人在 2019 年对基于 LSTM 的文本分类系统做了后门实验②，研究者从少量训练样本里挑选若干位置，硬塞进一段固定的触发句，比如“我上周去看了 3D 电影”，训练完成后模型对这段句子的反应极其敏感，并且触发句越长，攻击的成功率往往越高。Zhang 等人在 2021 年的探索③则另辟蹊径，用一些罕见的文本片段做触发，将被投毒的预训练模型公开供下游用户做微调，后门特性在迁移到新任务时依然保持活性。

语音场景大致可分说话人识别和语音识别两类，虽然同属语音，但投毒手法差异明显。现阶段的语音识别常先把音频转成频谱图等可视化特征，再套用视觉模型去预测。传统流程是先靠特征图抽音素，再由语言模型拼成语句；端到端方案则直接从特征图生成语句。

语音模型从原始数据到最终输出要经过的环节较多，因此从数据集层面做投毒式的后门研究相对稀少。Liu 的工作¹在极简的 1~9 数字语音识别任务上复现了类似图像后门的思路，触发信号选用随机噪声。Stefanos Koffas 的尝试²则把人耳听不到的超声波片段作为触发器，在短时语音集上对不同架构做投毒实验，发现 LSTM 网络的植入难度明显高于其他结构。

# 4.4 实战案例：供应链攻击

通过上述简单的案例，相信大家已经了解了后门攻击的危害性，那么后门攻击是如何对我们的生活产生影响的呢？本案例我们介绍一种利用供应链实现后门攻击的威胁形式，帮助读者了解如何防范该类攻击。

# 4.4.1 案例背景

对于传统的后门攻击，一般除开发者本人在模型中预设后门外，攻击者通常会从供应链角度实施后门攻击，即针对软件、服务的上游供应，如软件的分发、下载渠道，或者软件的依赖库等，展开攻击。

尽管目前 AI 后门攻击尚无真实的攻击案例，但在我们的研究中，供应链仍然可能成为攻击者发起攻击的切入点，如何保证供应链安全将为 AI 安全护航的重要环节。我们以 PyTorch 官网提供的移动端图像识别 App 为案例，向大家展示一下攻击者潜在的攻击路径，来帮助大家防范此类攻击手法。

PyTorch 官网提供了 Android 图像识别 Demo 程序 “HelloWorld”，这个程序在静态图像上运行 TorchScript 序列化的 TorchVision 预训练的 MobileNet v3 模型( 在实际攻击时，我们不需要了解模型的具体结构，在本案例中也不会使用该信息 )，该模型已被打包在 Android 程序中。我们用 Android Studio 加载该项目并打包为 APK 文件，模拟实际被攻击的场景。
