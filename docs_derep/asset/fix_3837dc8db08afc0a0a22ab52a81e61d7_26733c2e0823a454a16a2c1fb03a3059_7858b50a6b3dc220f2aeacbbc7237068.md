# 第一步 教学方案制定
本次面向四年级学龄儿童讲解鸡兔同笼问题，题目条件为：[兔子头数35个，脚数94只，求鸡兔各多少]。请按以下辅导思路设计：
- 核心概念：用生活化的类比揭示题眼本质，可把鸡兔想象成装配不同轮子的迷你玩具车
- 方法适配：列出两种四年级能接受的解法，排除方程做法，优先选用假设法与抬腿法
- 知识衔接：说明该题与已学内容的关联，如乘法分配律以及两步应用题的解题思路

# 第二步 分步讲解稿撰写
基于上述思路生成讲解流程，要求：
1. 情景导入：借助孩子熟悉的场景切入，例如宠物店送货员统计脚数的动画片段
2. 可视化手段：
图表法：引导孩子画出简易的鸡兔示意图并标注脚数
实物法：利用积木或硬币模拟头数与脚数关系
3. 思维支架：
◎ 关键提问：‘假设全部是鸡会怎样？多出来的脚对应谁？’
◎ 误区预判：提前拆解‘直接用94除以4求鸡数’的错误逻辑
4. 语言技巧：
把‘假设’转化为儿童易懂的操作指令，每完成一步用‘你能发现什么规律？’引导观察

# 第三步 拓展训练设计
在原题基础上进行梯度化练习：
1. 梯度练习：
基础级：头数10、脚数28，数据小便于口算
进阶级：三轮车与四轮车轮数问题，同类变式
2. 游戏化练习：
角色扮演：孩子扮演鸡或兔，家长数脚产生认知冲突
卡片配对：头数卡与脚数卡组合，找出不合理搭配
3. 生活迁移：
设计超市购物情境，例如购买单价5元与3元的面包共花费32元

# 第四步 错误干预方案
针对典型错误给出针对性指导：
1. 常见错误：
类型1：把脚总数直接除以4当作鸡数，未掌握假设思维
类型2：调整数量时的步长出错，如每次增减3只
2. 纠正策略：
对类型1：用‘全鸡假设法’做分步动画演示
对类型2：在表格中用颜色标记数量变化规律
3. 激励话术：
‘你已经抓住了脚数变化的规律，太棒了！再挑战一个…’
‘数学家小时候也会犯类似错误，我们来看欧几里得的做法…’

# 第五步 学习意义说明
阐述该题对后续学习的价值：
1. 思维积累：为五年级的方程学习奠定直观认知基础
2. 方法迁移：列举可套用相同思路的问题，如租船问题、得分差额问题
3. 延伸资源：推荐适合四年级的数学启蒙动画，标注B站相关检索关键词
