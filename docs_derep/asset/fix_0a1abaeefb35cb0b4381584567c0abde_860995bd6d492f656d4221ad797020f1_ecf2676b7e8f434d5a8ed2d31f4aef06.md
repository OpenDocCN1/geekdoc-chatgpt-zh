# 第 8 章 仿真交互新篇
## 8.1 全景速览
计算技术已先后走过大型主机、个人电脑到泛在计算三个阶段。无论时代如何更迭，人机界面始终是研究的恒久主题。图形用户界面催生了PC时代的辉煌，而混合现实与泛在计算正指向人机交互的终极路径。

混合现实的发展是从虚拟现实独立存在走向与真实世界结合的增强现实。虚拟现实借助高性能硬件、图形生成系统及各类传感器，营造出具有视听触嗅等感知的逼真三维空间，让用户以自然方式与虚拟对象互动，是AI、计算机图形、CHI、立体影像等技术集成的成果，目标是构建更和谐的人工环境。增强现实则利用光电显示、交互、可视化等技术，把不存在的虚拟物精准投放到真实场景，通过显示设备实现虚实合一，为用户呈现感官上高度真实的新环境。

MR由现实与虚拟两部分组成。虚拟部分关乎人与虚拟世界的连接，涵盖虚拟世界的构建呈现和人与虚拟世界的交互。因为虚拟呈现直接作用于感官，营造真实感的关键是建立与人类感官匹配的自然通道，以渲染、音响与触觉力觉反馈构建感知-理解-响应-呈现的闭环。混合现实省去了对现实世界实时仿真的难题，转而建立虚实联结并模拟二者相互影响。但要实现虚实融合，技术挑战很大，不仅要感知主体行为，还需感知环境、人物与事件语义，涉及计算机视觉、图形学、模式识别、光学、电子、材料等多学科。正因与现实紧密关联，混合现实才具备广泛的实用价值。

人机交互本质是用户与系统间的信息交换，包含人到系统与系统到人的双向传递。系统可以是智能设备或软件，用户可借助操纵杆、数据服、眼动追踪器、数据手套、压力笔等，用手势、声音、动作、眼动甚至脑电波传递信息，系统则通过显示器、音箱等输出信息。理想状态下，人机交流无需键盘鼠标触摸屏等中介，实现物理世界与虚拟网络的无缝融合。

用户界面是人机信息交换的媒介，其设计目标是用恰当隐喻把用户行为状态转化为机器可处理的形式，再把机器状态转化为用户可理解的表达。MR一方面可感知肌肉运动、姿势、语言、身体追踪等输入，另一方面可通过视觉、听觉、触觉、嗅觉等多通道输出逼真感官体验，并根据视点和输入实时反馈。从交互视角看，MR是一种新型人机交互界面。

MR已有近30年历史，因输入设备不便、价格偏高且缺乏新交互范式，长期未进入主流。如今伴随人、事件、思想与范式的变迁及心理学用户模型的完善，MR已具备成熟的交互心理学模型与界面范式，正从科幻走向现实，引发人机交互革命。技术成熟后，其价值远超游戏娱乐，已在军事、航天、工业设计、外科手术模拟、科学可视化、远程控制、教育等领域发挥作用。未来可能出现可监听对话并实时提供建议的设备，持续学习用户行为模式，如同共生体般陪伴生活。

MR的核心是人机交互，未来将走向网络化、智能化、泛在化。深化MR与人机交互的基础理论，支撑云计算、移动互联网、人工智能、大数据等新一代计算技术与MR融合，具有重要意义。

交互过程中人类可通过多种方式与系统交换信息。传统GUI需借助鼠标键盘等设备，用户需先学习后使用。BCI直接读取中枢与外周神经脉冲，通过头戴式设备获取意图完成交互，常用设备有EmotivEpoc、BrainLink、MindWave等，相对于GUI学习成本更低，更自然。NUI基于听觉、视觉、触觉、人体行为及表达、理解、记忆等高层认知功能，用户无需键盘鼠标即可通过眼动、语言、表情、手势、肢体在移动、桌面、空间环境中与机器互动，代表设备有Leap Motion、Kinect、Wii U、MYO等，学习门槛低、交互更自然。MR人机交互界面融合上述多种形态，充分调动神经、肌肉与行为系统，实现更自然的交互。
