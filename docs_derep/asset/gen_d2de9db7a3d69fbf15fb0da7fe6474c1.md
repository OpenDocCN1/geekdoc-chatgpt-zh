## 9.16 文本分类

- openai.topic：用于判别文本的主题或话题，使用时无需额外参数。

### 9.20.1 GitHub Copilot

GitHub Copilot 是 GitHub 与 OpenAI 联合推出的 AI 编程助手，旨在提高开发者编码效率。基于 Codex，它能在编辑器中理解上下文并合成整行代码甚至完整函数。

基本工作流程如下：

1. 用户在编写代码或注释时，Copilot 通过机器学习分析输入，生成相关代码片段和建议。
2. 依据当前上下文，Copilot 在编辑器中主动推荐可能的补全片段，用户可直接采纳或自行修改。
3. 用户采纳或修改后，Copilot 继续分析最新上下文，生成更个性化的建议，进一步提升效率。

其优势在于能够自动化常规编码任务，如生成常用模板、处理错误异常、进行简单重构等，同时提供可读性和可维护性较好的代码，帮助更快实现开发目标。

### 9.20.2 Keeper Tax

Keeper Tax 是一款基于人工智能的税务管理软件，帮助个人和企业轻松处理税务事务。借助 GPT-3 将银行对账单解析为可用交易信息，可帮助自由职业者自动查找可免税支出。

主要功能包括：

- 自动识别和分类税务相关收据和交易：可自动归类购物发票、车辆里程、差旅费用等，提供更全面准确的税务报告和清单。
- 自动计算税务：根据用户税务状况自动核算个人所得税、自雇税等金额。
- 自动填写税务表格：依据税务情况自动填表，如 W-2、1099 和 Schedule C 等。
- 定期提醒和更新：通过邮件和短信提醒申报、缴费等重要节点，并及时更新税务信息和表格。
