### 进阶解析：两种模型构建范式的异同

前序搭建模型时，我们接触了两种截然不同的 API 风格：面向对象的 `nn.xxx` 类接口，与函数式的 `nn.functional.xxx`。下面深度拆解二者区别。

#### 共性：功能等价

以全连接层为例，`nn.Linear` 与 `nn.functional.linear` 实现的核心逻辑完全一致，仅封装形态不同——前者为类，后者为函数。

#### 差异点一：调用范式迥异

*   **`nn.Linear`**：需先实例化类并传入构造参数，再像调用函数一样传入输入张量 `x`。
    [PRE5]
*   **`nn.functional.linear`**：无需实例化，但须手动初始化权重参数。
    [PRE6]

**最佳实践建议**：含可学习参数的层（如 Linear、Conv2d）优先用 `nn.xxx`；无参数层（池化、ReLU、Sigmoid 等）两者皆宜。

#### 差异点二：生态兼容性不同

`nn.xxx` 继承自 `layers.Layer`，天然兼容 `nn.Sequential` 容器，并拥有 `eval()`、`train()` 等生命周期方法。反之，`nn.functional.xxx` 无法接入 `Sequential`，亦无上述方法。

### 知识储备站

#### 10.1 损失函数：衡量模型优劣的“尺子”

深度学习中，损失函数量化预测值与真实值的偏离度，**损失值越小，模型通常越优**。不同任务适配不同损失函数，重点掌握均方误差与交叉熵两大主流。

##### 10.1.1 均方误差（MSE）——回归任务首选

MSE 度量真实值与预测值的差异程度，公式如下：

$$MSE = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2$$

*   $\hat{y}_i$：预测值
*   $y_i$：真实值
*   $N$：样本量

取值区间 $[0, +\infty)$，预测完全精准时为 0；偏离越大值越大，越贴近则越小。

##### 10.1.2 交叉熵——分类任务标配

分类任务中，MSE 易陷入梯度消散，交叉熵更佳。公式定义：

$$L(\theta) = \frac{1}{N} \sum_{i=1}^{N} \{-y_i \log[h_\theta(x_i)] - (1-y_i) \log[1-h_\theta(x_i)]\}$$

其中 $h_\theta(x_i) = \frac{1}{1 + e^{-\theta^T x + b}}$ 为预测概率。

**直观理解**：若真实标签 $y_i=1$，损失仅取决于 $-\log[h_\theta(x_i)]$。模型预测概率 $h_\theta(x_i)$ 趋近 0（判错），损失爆增；趋近 1（判对），损失趋近 0。
