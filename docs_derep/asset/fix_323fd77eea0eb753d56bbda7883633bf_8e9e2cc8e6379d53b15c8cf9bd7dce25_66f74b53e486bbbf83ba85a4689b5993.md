# Claude CLI 使用速览

在自动化脚本和 CI 流程里，Claude CLI 的 MCP 管理和无交互调用是高频操作。下面集中整理了检查服务、调试连接以及 Headless 模式的典型写法，可直接套用。

[PRE0]bash

# 列出所有已配置的服务器及其当前状态

claude mcp list

# 专门测试特定服务器的连接连通性

claude mcp test my-server

# 启用 MCP 调试模式

claude --mcp-debug

[PRE1]

# 最基本的 Headless 模式调用

claude -p "分析 src/ 目录的安全漏洞"

# 等价的完整形式

claude --print "分析 src/ 目录的安全漏洞"

[PRE2]

claude -p "列出主要问题" --output-format text

[PRE3]

claude -p "审查 PR" --output-format json
