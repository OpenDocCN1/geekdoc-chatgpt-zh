# 第十二章 多智能体协作的市场调研报告撰写

第十章已展示单 Agent 完成公众号文章自动创作。面对需要深度数据分析、竞品对照与战略建议的复杂业务，单一 Agent 常因上下文窗口限制或角色单一，难以兼顾信息广度与分析深度。

本章引入 OpenClaw 的多智能体协作机制，搭建由“产品经理”“研究员”“主笔”组成的数字团队，通过飞书群组完成高质量市场调研。

## 12.1 需求分析与架构设计
专业市场调研通常包含三大环节：需求拆解与大纲制定、资料搜集与数据分析、报告撰写与排版。让单个 Agent 全包容易在海量信息中偏离主线，于是设计三个职责清晰的 Agent 协同。

• PM Agent 产品经理：作为负责人，接收用户原始需求，拆解为 3~5 个研究维度，制定报告大纲并分派任务。
• Researcher Agent 研究员：依据大纲，利用搜索与分析工具深挖市场数据和竞品信息，输出结构化研究笔记。
• Writer Agent 主笔：把研究笔记转化为逻辑严谨、格式规范的完整报告。

架构上，三者部署在同一 OpenClaw 实例，工作空间相互独立。通信依赖 OpenClaw 内置的 agent_send 工具。用户只需在飞书群组 @PM Agent 下指令，后续协作由各 Agent 自主完成，最终结果同步回群组，流程透明可追溯。

## 12.2 核心技能剖析与配置
Researcher Agent 承担最重的信息搜集与分析，需配备 ClawHub 的高级搜索与分析技能。

### 12.2.1 exa-web-search-free 技能
深度调研场景下，传统关键词搜索难以满足。exa-web-search-free 接入 Exa 原 Metaphor 语义搜索引擎，面向 AI 优化，能理解复杂自然语言查询，例如“2026 年最具创新性的 AI 硬件产品及其商业模式”，并直接返回高相关网页内容。

语义检索大幅减少筛选噪音，让研究员聚焦数据提炼。

安装命令：

clawhub install exa-web-search-free

安装后需在 openclaw.json 中填写 Exa API Key，方能正常调用。其他网络搜索技能亦可按 Skill.md 说明配置，部分无需 API Key。

### 12.2.2 Agent-to-Agent 通信机制
多智能体协作核心是高效通信。OpenClaw 内置 agent_send 工具，支持 Agent 间传递消息与上下文，属于系统核心能力，无需额外安装。只需在 openclaw.json 中显式启用并配置可通信的 Agent 列表。

该机制打破信息孤岛，使复杂任务像人类团队一样“开会、交接文档”。每个 Agent 运行在独立工作空间，记忆相互隔离，避免上下文混乱。

### 12.3.2 创建多智能体工作空间与 SOUL.md 配置
用命令为三者分别建工作空间并定义行为。

openclaw agents add pm --workspace "~/.openclaw/workspace-pm"
openclaw agents add researcher --workspace "~/.openclaw/workspace-researcher"
openclaw agents add writer --workspace "~/.openclaw/workspace-writer"

1．PM Agent 的 SOUL.md
在 ~/.openclaw/workspace-pm/SOUL.md 中定义：

# 角色定义
你是一位拥有十年经验的资深产品经理，担任市场调研团队负责人，具备强逻辑、项目拆解与团队调度能力。

## 核心职责
- 接收飞书群组中的调研需求，拆解为 3~5 个研究维度。
- 制定报告大纲，用 agent_send 发给 researcher 执行深度调研。
- 追踪进度，审核研究笔记，不实或偏离则打回重做。
- 审核通过后，将大纲与笔记一起发给 writer 撰写终稿。
- 确保交付质量达到专业咨询公司水准。

2．Researcher Agent 的 SOUL.md
在 ~/.openclaw/workspace-researcher/SOUL.md 中定义：

# 角色定义
你是一位严谨客观的市场研究员，擅长从海量信息中提取商业洞察与硬核数据。

## 工作流准则
- 收到 pm 的大纲后，为每个维度制定搜索策略。
- 强制使用 exa-web-search-free 进行深度搜索，获取最新市场数据、财报与竞品动态。
- 将信息整理为结构化研究笔记，包含核心结论、支撑数据及来源 URL。
- 禁止编造数据，数据不足需在笔记中如实说明。
- 完成后用 agent_send 回传给 pm 审核。

3．Writer Agent 的 SOUL.md
在 ~/.openclaw/workspace-writer/SOUL.md 中定义：

# 角色定义
你是一位擅长商业分析报告的资深主笔，文字精炼专业，善用图表支撑观点。

## 写作规范
- 接收 pm 的大纲与笔记，按结构撰写。
- 文风客观中立，避免情绪化表达。
- 竞品对比或多维度数据须用 Markdown 表格呈现。
- 文末附“参考资料”列表，列出所有引用 URL。
- 完成后直接输出到飞书群组供用户查阅。
