想用 DBpedia 一键筛出海拔比南迦帕尔巴特更高的所有山峰，思路就是先拿到南迦帕尔巴特的海拔 e1，再把所有被标记为 dbo:Mountain 的实体拿出来比对海拔 e2，只要 e2 大于 e1 就保留该山峰的 URI。

PREFIX dbo: <http://dbpedia.org/ontology/>
PREFIX res: <http://dbpedia.org/resource/>
SELECT DISTINCT ?uri WHERE {
?uri a dbo:Mountain .
res:Nanga_Parbat dbo:elevation ?e1 .
?uri dbo:elevation ?e2 .
FILTER (?e2 > ?e1) .
}

下面这套写法是找“关联次数最多”实体的通用模板。先让 ?y 属于类型 ?c，并通过属性 ?p 指向 ?x，然后按 ?y 的出现次数倒序排序，取第一名即可。类和属性在这里用占位符先写死，方便后续替换。

SELECT DISTINCT ?x WHERE {

    ?y rdf:type ?c .

    ?y ?p ?x .

}

ORDER BY DESC(COUNT(?y))

OFFSET 0 LIMIT 1

?c CLASS [films]

?p PROPERTY [produced]
