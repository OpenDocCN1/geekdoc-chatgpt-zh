### 3.5.2 VS Code Python 开发排错指南

在 Visual Studio Code 里进行 Python 开发时常会碰到以下问题及对应处理方式：

#### 1. 问题：Python 解释器找不到
解决方案：
- 安装验证：确认本机已正确安装 Python，可在终端输入 `python --version` 或 `python3 --version` 检查是否可用。
- 选择解释器：在 VS Code 中按〈Ctrl+Shift+P〉键（Windows/Linux）或〈Cmd+Shift+P〉键（macOS）打开命令面板，执行 Python:Select Interpreter。
- 手动指定：若列表中未出现所需解释器，选择底部的 Enter interpreter path 选项，手动定位到 Python 安装目录下的 `python.exe`（Windows）或 `python/python3`（macOS/Linux）文件。

#### 2. 问题：扩展安装失败
解决方案：
- 网络检查：确认网络畅通并能访问 VS Code Marketplace，代理或防火墙设置可能导致安装被阻断。
- 离线安装：先到 VS Code Marketplace 官网搜索目标插件并下载 `.vsix` 包，随后在扩展侧边栏点击右上角的…图标，选择 Install from VSIX 导入本地文件安装。
- 重启编辑器：临时性的安装异常，重启 VS Code 后常可恢复。
- 权限检查：确保 VS Code 拥有写入自身安装目录及扩展目录的权限。

#### 3. 问题：代码智能提示失效
解决方案：
- 安装核心扩展：确认已安装 Microsoft 官方的 Python 扩展，其内含 Pylance 语言服务器。
- 检查语言服务器状态：查看底部状态栏或 Output 面板，确认 Pylance 正在运行且无报错信息。
- 刷新窗口：按〈Ctrl+Shift+P〉键（或〈Cmd+Shift+P〉键）输入并执行 Developer:Reload Window。
- 核对项目配置：确保工作区根目录被正确识别，`.vscode/settings.json` 中没有错误配置导致功能受限。

#### 4. 问题：终端无法执行 Python 命令
解决方案：
- 检查环境变量：最常见原因是 Python 安装路径未加入系统 PATH。
- Windows 配置：
    1）右键“此电脑”选择“属性”。
    2）点“高级系统设置”。
    3）点“环境变量”。
    4）在系统变量或用户变量中定位 Path，选中后点“编辑”。
    5）点“新建”，分别添加 Python 安装根目录（如 `C:\Python39\`）及其 Scripts 子目录（如 `C:\Python39\Scripts\`）。
    6）依次点“确定”保存，重启 VS Code 或命令提示符使更改生效。
- macOS/Linux 配置：
    1）打开终端。
    2）编辑 shell 配置文件，通常为 `~/.bash_profile`（Bash）或 `~/.zshrc`（Zsh），例如 `nano ~/.zshrc`。
    3）在文件末尾追加类似 `export PATH="/path/to/your/python/bin:$PATH"` 的行，用 `which python3` 查询真实路径替换占位符。
    4）保存文件（nano 中按〈Ctrl+X〉，按〈Y〉，按〈Enter〉）。
    5）执行 `source ~/.zshrc` 或重新打开终端使配置生效。

### 4.2.1 Python 解析器的工作原理

Python 属于解释型语言，代码在运行时由解析器逐行解释执行，而非像 C 或 Java 那样先编译成机器码再运行。这种特性让 Python 更灵活易调试，但执行效率相对较低。

向 DeepSeek 提问：

> 请详细解释 Python 解析器的工作原理，以及它与编译型语言的区别。

DeepSeek 回答：

## 一、Python 解析器的工作原理
Python 解析器是把 Python 源代码转为计算机可执行指令的程序。作为解释型语言，其执行流程与编译型语言明显不同。

## 二、Python 解析器的基本工作流程
1. 词法分析：把源代码拆分为标记，如关键字、变量名、运算符等。
2. 语法分析：将标记组织成语法结构，生成抽象语法树 AST。
3. 编译为字节码：解析器把 AST 编译成 Python 字节码，这是一种与硬件无关的中间表示。
4. 执行字节码：Python 虚拟机 PVM 执行字节码指令。在 CPython 中，这一步由 C 语言实现的解释器完成。

## 三、解释型语言与编译型语言的区别
1. 解释型语言（如 Python）
    - 执行方式：运行时逐行解释。
    - 开发周期：写代码→直接运行→调试→修改→运行，迭代快。
    - 可移植性：高，有解释器即可运行。
    - 执行速度：通常较慢。
    - 内存占用：通常较高。
    - 错误检测：运行时动态检查。

2. 编译型语言（如 C/C++）
    - 执行方式：先编译成机器码，再执行。
    - 开发周期：写代码→编译→链接→执行→调试→重新编译，周期长。
    - 可移植性：低，需针对平台重新编译。
    - 执行速度：通常较快。
    - 内存占用：通常较低。
    - 错误检测：编译时即可发现大部分错误。

## 四、Python 的混合特性
Python 兼具解释型与编译型特点：源代码先编译为字节码 `.pyc` 文件，再由虚拟机解释执行，结合了开发便捷性与一定执行效率。

## 五、常见 Python 实现
- CPython：标准实现，用 C 编写。
- PyPy：采用 JIT 即时编译，速度更快。
- Jython：在 JVM 上运行。
- IronPython：在 .NET 平台运行。
各实现解释器不同，但都遵循 Python 语言规范。
