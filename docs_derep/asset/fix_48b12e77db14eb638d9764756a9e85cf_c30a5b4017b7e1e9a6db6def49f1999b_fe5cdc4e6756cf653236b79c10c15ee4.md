# 复盘即作战图

**指令模板可参考**

●壁垒拆解示范：挑定一只上市标的，从品牌沉淀、制造工艺、渠道掌控、用户心智等角度剖解其竞争壁垒，并推演该壁垒在接下来5到10年被削弱或击穿的可能性。  
●财报抓取与趋势研判示范：调取某家A股公司2021至2025年的年报，重点呈现加权净资产收益率、经营性现金流净额、有息负债占比，并简要评价五年间盈利质量和财务稳健性的演化。特别提示，模型抓取财务数字时易出错，建议以专业投研终端为准，权威数据源更可靠。  
●管理层话语追踪示范：汇总董事长过去三年年报《致股东信》里反复强调的战略方向，并对照随后两年的资本开支和业务进展，初步判断战略落地能力。

本层交付的是公司体检表和初步判断。对观察池里的标的做深度体检后提炼简明结论，示例如下。

案例A 某储能龙头
●商业模式/壁垒：技术领先，品牌开始显现，与头部客户绑定紧密，渠道优势突出，壁垒在持续加厚。  
●财务面：ROE逐年抬升并稳定超过20%，自由现金流在上一年由负转正，负债结构健康。  
●治理面：管理层技术出身，作风务实，股权激励覆盖充分。  
●估值面：现价对应未来两年增速，PEG大约0.9，处于行业合理区间。  
●初步结论：核心标的，符合好赛道、好公司、合理价的标准。建议进入终选池，并启动详细建仓方案设计。

案例B 某半导体材料企业
●商业模式/壁垒：产品处在关键环节，技术门槛不具备独占性，面临国内外激烈竞争。  
●财务面：收入仍在增长，利润率波动较大，现金流偏弱，研发费用资本化比例偏高。  
●治理面：近期核心技术人才流失，大股东质押比例偏高。  
●估值面：静态PE看似不高，综合盈利质量和治理隐患，安全边际不足。  
●初步结论：瑕疵明显。行业前景虽好，公司自身问题较多，建议放弃继续观察。

3.融合与升华：三阶过滤体系怎样协同

三阶过滤并非单向流水线，而是一个相互喂养、循环往复的研究生态。

●自上而下的指引：宏观层定航向，避免逆风而行；中观层锁定景气最强的细分水道，提升效率；微观层筛选最结实的船只，保障安全。这是一条严谨的收敛路径。  
●自下而上的回传：微观研究中可能发现，某家企业技术突破足以重塑行业竞争格局，甚至催生新的经济形态，于是信息逆向传导、向上修正认知。比如深入研究一家AI芯片公司，会强化对科技自主这一宏观逻辑的信心，并调高对半导体景气的判断。  
●长期、中期、短期要素的贯穿：长期要素如人口、技术，是三层分析的共同底色；中期要素如产业政策、周期，是中观分析的核心，也决定微观企业的经营环境；短期要素如季度业绩、情绪波动，主要影响微观层的交易时机，提供买入卖出的价格信号，却不应动摇基于长期中期要素形成的价值判断。

到这里，你已拥有一个强力的决策中枢。它赋予结构性优势：当市场喧嚣、他人被碎片信息牵着走时，你能像工程师一样按流程收敛，最终得到经过多重验证的高置信度备选池，而不是在五千多只股票里盲目碰运气，经过前两轮筛选后，你的深度研究池可能不足20只。

然而再精妙的分析，若只停留在脑中，仍会被情绪吞噬。我们必须把思维固化为可执行、可追溯、可复盘的实体，这就是下一环节：把分析结论转化为你的投资决策清单，一张不可篡改的航海图。

5.2.4 决策的生成——用长中短要素分析法产出投资决策清单

经过三阶过滤的筛选，我们已锁定少数兼具天时、地利、人和的优质公司。但从看好一个机会到做出一次好投资，中间潜藏致命陷阱：把模糊的偏好等同于立刻下单的冲动。

市场先生情绪化，随时用更好的价格诱你等待，或用更差的价格吓你退出，而贪婪与恐惧正是帮凶。要对抗这种合谋，必须把脑中的结论做一次物理化锻造，形成白纸黑字的投资决策清单。

这份清单是你作为财富首席投资官签署的作战命令，既是行动指南，也是情绪铠甲。下面就用长中短要素的智慧，来拆解清单的构成。

1.要素体系解析：理解市场的多层驱动结构

厘清驱动市场的力量，可归为三类要素，共同塑造地形与气候。

1）长期要素 长期根本动能，5到10年以上，决定地形  
本质是社会演进中缓慢而不可逆的深层趋势，决定资产长期方向。一旦形成，短期难改。  
典型代表：人口结构变迁、技术革命如AI与新能源、社会价值观演进、地缘政治版图、气候环境变化。  
决策角色：定方向的罗盘，告诉你该长期站在哪条河的哪一侧，不提供时点。

2）中期要素 中期周期力量，1到5年，制造季节  
是宏观趋势和微观表现的桥梁，体现产业政策、金融等周期波动，决定行业景气。  
典型代表：五年规划和产业政策、货币信贷周期、监管框架变化、产业链供需变动、商业模式渗透。  
决策角色：选行业的导航仪，判断行业处于复苏、繁荣、滞胀还是萧条，指示1到5年的超额收益赛道。

3）短期要素 短期扰动，1年内，制造天气  
由情绪、突发事件、高频数据引发的波动，来去快，不改变长期趋势。  
典型代表：月度季度宏观数据、单家公司财报、突发事件、流动性突变、社交媒体热点、主题炒作。  
决策角色：选时点的温度计，制造恐慌坑和狂热顶，用来触发事先设定的交易动作，不用来否定基本面。

核心认知：高手用长期要素挑河，用中期要素判水流，用短期要素找下水点；失手者被每日天气牵着走，忽视季节已转凉，更忘了自己在干涸河道。

2.要素驱动过滤实战：从框架到结论

以假设案例智能驾驶解决方案公司Alpha演示要素如何驱动过滤并导出清单要素。

1）宏观视野层分析 长期要素和中期要素主导  
问题：行业潮水方向如何？  
长期要素：AI与传感器持续突破为长期上行变量；对出行安全效率的追求是永恒需求；人口老龄化提升对自动驾驶需求；电动化与智能化协同。  
中期要素：十四五、十五五规划及新能源汽车规划均把智能网联汽车列为战略方向，政策明确支持；行业由导入期迈向成长期，L2/L3渗透率在10%到30%的加速段。  
宏观结论：长期要素强劲向上、中期要素明确支持，处于战略机遇期，值得重点配置。

2）中观行业层分析 中期要素和长期要素共振  
问题：赛道中哪个细分最具吸引力？  
竞争格局：产业链分硬件、软件、集成解决方案。集成商需打通软硬件直面车企，技术壁垒和客户粘性快速建立，格局未固化，龙头雏形已现。  
景气度：车企定点、资本开支、专利数均显示解决方案环节需求爆发上行。  
中观结论：聚焦智能驾驶整体解决方案，其直接受益整车智能化需求，且正处混战向集中过渡的关键期，有望孕育平台型龙头。

3）微观公司层分析 四大支柱，并用短期要素捕捉机会  
问题：是否该环节的最优船？  
商业模式和壁垒：提供芯片加算法加软件的全栈方案，已与多家头部车企深度合作。壁垒包括数据闭环驱动算法迭代、车规级芯片自研实现软硬一体、以及先发生态绑定大客户。  
财务状况：近三年营收CAGR超50%，尚未盈利，研发投入大，自由现金流为负但账上现金充足可支撑三年，符合高成长科技特征。  
公司治理：创始人技术背景扎实，核心团队稳定，股权清晰，战略聚焦不盲目扩张。  
估值水平：采用PS结合远期盈利测算，当前价格对应未来两年PS处于历史低中位，考虑行业地位和成长性具备吸引力。  
短期要素观察：受新能源车消费数据担忧影响，板块情绪低迷，股价自高点回撤约35%，形成恐慌性买入窗口。  
微观结论：Alpha为该领域领军企业，壁垒在加深，成长路径清晰，当前悲观情绪提供较好入场时机。

5.2.5 决策的升华——在A股实践中融入守中智慧

框架搭建完成如同拥有精准海图和强劲引擎，但在A股这片政策和情绪交织的内海，机械套用法则易迷航。行情既受全球潮汐影响，也由本土政策导向和运行规则主导，必须注入守中智慧。

守中非折中妥协，而是道家有无相生、儒家执两用中的高阶思维，追求在对立力量间保持动态弹性。投资中意为坚守理性内核，又尊重市场现实；借助政策动能，不陷入主题炒作；追求长期复利，又顺应市场缓慢增长的规律。

1.理解政策驱动，不做主题炒作：将中期要素转化为战略优势  
A股中期要素力量异常直接且显性。  
守中智慧是不抗拒不盲从，而是理性运用。重磅产业政策出台常引发板块集体狂热，此时应极度冷静，甚至考虑减持涨幅巨大但基本面不支撑的个股。潮水退去后，真正经过滤筛选的优质公司回归理性，正是执行清单买入计划的良机。  
案例：保障性住房和城市更新成政策方向时，市场可能短炒建筑股。守中者关注更本质机会——提供绿色建材、高效建造技术或运营服务的公司，才是长期红利受益者。  
核心要义：政策是中期要素输入，非交易直接触发器。触发器永远是基于全面分析后的具体价格和纪律。
