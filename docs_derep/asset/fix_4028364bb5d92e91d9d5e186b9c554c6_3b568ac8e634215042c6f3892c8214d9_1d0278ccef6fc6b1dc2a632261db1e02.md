# 第230条改革，美国式博弈

近几年，美国政坛对《通信规范法》第230条的修改呼声明显走高。2018年，国会通过的《反网络性交易法》FOSTA，Allow States and Victims to Fight Online Sex Trafficking Act，被业界普遍视为本轮修法的大幕开启。该法在第230条中开出一个缺口，明确该条的免责不延伸至与性交易有关的民事、刑事追责，也不适用于“助推或便利卖淫”的行为。^([\[85\]](#txt001.html#footnote_content_txt001_85))此后，第116届国会集中涌现26份针对第230条的修正提案。^([\[86\]](#txt001.html#footnote_content_txt001_86))其中声量最大的是《消除交互式技术滥用与放任法案》EARN IT Act，以及《平台问责与消费者透明法案》PACT Act。

EARN IT延续了FOSTA的逻辑，主攻方向是在线儿童性侵类内容，要求撤销平台就此类内容的免责。2022年2月，该案已在参议院司法委员会完成投票。^([\[87\]](#txt001.html#footnote_content_txt001_87))PACT Act的视角更宽，它不设特定领域例外，而是要求平台搭建覆盖面广的违规内容举报通道，并设定时限：接获举报24小时内未删除违法内容，就自动丧失第230条的保护。这一思路实质上是对本案及一系列判例对第230条宽松解读的纠偏，意在让平台对明知违法的事项承担责任。

立法之外，行政分支也频繁表态。2020年5月，时任总统特朗普签署“防止网络审查”行政命令，系统阐述了行政部门对第230条的立场，并指示多部门落实。^([\[88\]](#txt001.html#footnote_content_txt001_88))同年6月，司法部完成对第230条的全盘检视并递交建议，提议撤销对以下情形的免责：主动鼓励违法行为的网络服务商；涉及儿童虐待、恐怖主义、网络跟踪等侵权内容的情形；平台明知内容违法却放任的情形；与民事执行相关的情形；以及反垄断诉讼相关的情形。^([\[89\]](#txt001.html#footnote_content_txt001_89))

即便在国会内外形成“第230条需要调整”的大致共识，具体方案的落地阻力极大。以EARN IT与司法部的建议为例，就遭到科技从业者与隐私倡导者的激烈反对。批评声音集中在言论自由被压缩、科技创新受阻、执法部门更容易获取私人信息等方面。^([\[90\]](#txt001.html#footnote_content_txt001_90))

## 【关联判例推荐】

1. Universal Commc’n Sys., Inc. v. Lycos, Inc., 478 F.3d 413 (1st Cir. 2007)

核心事实：原告指控被告旗下网络论坛存在匿名用户的虚假诽谤贴文。上诉法院认定被告可援引《通信规范法》第230条免责，无需为第三方言论买单。

与本案关联点：网络服务商即便知悉信息的违法属性，也不因此被定性为该信息的创作者。

2. Kimzey v. Yelp!, Inc., 836 F.3d 1263 (9th Cir. 2016)

核心事实：原告公司因Yelp用户给出的一星评价提起诉讼，认为被告设计五星评分体系就等于“创作或发展”了该评价。上诉法院认为被告仅提供了一个中立载体供第三方发布信息，不存在创造新内容的情形。

与本案关联点：以中立工具呈现第三方输入的信息，不构成对新内容的创作或发展。

3. O’Kroley v. Fastcase, Inc., 831 F.3d 352 (6th Cir. 2016)

核心事实：原告发现Google搜索结果中自己的姓名后挂有“性侵儿童”文字，起诉称Google“创作或发展”了侵权内容。上诉法院认为Google仅对第三方网页做了自动化编辑，属于传统出版者的编辑范畴，因而受豁免保护。

与本案关联点：搜索引擎的自动化编辑行为通常能够获得豁免。

4. Bennett v. Google, LLC, 882 F.3d 1163 (D.C. Cir. 2018)

核心事实：原告指称第三方借助Google平台发布侵权博文，将Google诉至法院。上诉法院维持原判败诉，认为Google属于《通信规范法》第230条的保护对象。

与本案关联点：同时满足以下三项即可依第230条获豁免：被告系网络服务提供方或其用户；被追责信息源自其他内容提供者；原告主张被告系该信息的出版者或发布者。
