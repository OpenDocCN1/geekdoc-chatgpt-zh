面向自然语言推理的训练资源多以句子对形式呈现，附带完整的标注结果，广泛用于对 GPT 系列模型以及其他 NLP 模型的训练和效果验证。

#### 九、AG News
AG News 是一个新闻文本分类资源，收录了各类题材和主题的新闻报道，常被用作文本分类模型的训练与测试基准，GPT 也可在此类数据上进行练习。

### 第四节 模型库

#### 一、Hugging Face Transformers
Hugging Face 推出的 Transformers 库是 NLP 领域的主流仓库，内置了 GPT、GPT-2、GPT-3 等多种预训练模型可供调用。

#### 二、OpenAI
OpenAI 是一家人工智能研究机构，除发布 GPT-3 等预训练模型外，还提供了配套的 API 接口，方便用户直接使用。

#### 三、GPT-Neo
GPT-Neo 是一款自主预训练的 GPT 方案，架构和训练思路与 GPT-3 相近，但参数规模大幅缩小，从而在训练与使用成本上更具优势。

#### 四、PaddlePaddle
PaddlePaddle 是一款深度学习框架，集成了多种预训练 GPT 模型，并提供了对应的应用场景示例。

#### 五、AllenNLP
AllenNLP 是基于 PyTorch 的自然语言处理工具包，提供一系列预训练 GPT 模型，支持文本生成、问答系统、情感分析等多种任务。

#### 六、TensorFlow Hub
TensorFlow Hub 是 TensorFlow 生态下的模型仓库，收录了多款预训练 GPT 模型，常见用途包括文本生成、情感分析等。

#### 七、GPT-2简洁实现
该库提供了一套精简版 GPT-2 的实现代码，使用 Python 与 TensorFlow 2 开发，对初学者学习和实战十分友好。

#### 八、Transformers4Rec
Transformers4Rec 是面向推荐系统的 NLP 模型库，提供多组预训练 GPT 模型，典型的应用方向为文本生成和推荐系统。
