**进阶操作：直接上手改文件**

如果你更习惯在终端里折腾，或者你的服务器压根就没有图形界面，那直接打开配置文件修改会快得多。按自己顺手的工具来操作即可：

# 用 nano 打开
nano ~/.openclaw/workspace/SOUL.md

# 用 vim 打开
vim ~/.openclaw/workspace/SOUL.md

# 用 VS Code 打开
code ~/.openclaw/workspace/SOUL.md

改 USER.md 的思路一样，把文件名从 SOUL.md 换成 USER.md 就行。想先搞清楚配置目录里到底有哪些文件，可以执行：

# 浏览配置文件列表
ls -la ~/.openclaw/workspace/

执行后会看到 SOUL.md 和 USER.md 外，还有别的配置文件。先别管它们，后面章节会逐个拆解。

**SOUL.md 与 USER.md 如何配合**

不少人会问，两份文件冲突时听谁的？

OpenClaw 的处理原则是：SOUL.md 负责底线原则，不会轻易动摇；USER.md 在不违背原则的前提下补充个人偏好；实际运行时 AI 会动态权衡两者。

举例来说，SOUL.md 要求“简洁回复”，USER.md 要求“详细解释”，最终表现是默认简洁，但在需要时提供详细解释的入口。两者是互补关系，而非互相抵消。

这也是“养虾”最有趣的地方，反复微调后，你的虾会长出独一无二的性格轮廓。

**飞书接入：让它用你的身份干活**

**第三步：命令行向导完成接入**

方式一：交给 OpenClaw 自动配（推荐新手）

# 把下面语句填好你的 appID 和 appsecret 后发给 openclaw

帮我把 openclaw 接入飞书，教程：通过 openclaw plugins install @openclaw/feishu 安装插件；openclaw config set channels.feishu.enabled true 启用飞书通道；通过 openclaw config set channels.feishu.connectionMode websocket 设置连接模式为 websocket;openclaw config set channels.feishu.appId“你的 AppId”配置 appid；openclaw config set channels.feishu.appSecret “你的 AppSecret”配置 appsecret。中途遇到问题可以跟我说，配置完就 openclaw gateway restart

按提示执行，OpenClaw 会自动完成大部分配置。

[PRE6]

方式二：交互式向导

终端运行：

# 在终端输入
openclaw channels add

按提示依次操作：选择“Feishu/Lark（飞书）”→输入 App ID→输入 App Secret→配置私聊策略（默认配对模式）→配置群组策略（默认白名单）。

注意最后一步：填完后向导会回到“Select a channel”界面，这时不要重复选择，直接点“Finished”结束。很多人误以为没配完又重选一次，其实已完成。

完成后向导会自动重启 Gateway，终端会出现类似“Channels updated”的提示，说明 OpenClaw 已就绪。

方式三：命令行直配（适合熟手）

# 在终端输入
openclaw config set channels.feishu.appId "cli_ 你的 AppID"
openclaw config set channels.feishu.appSecret "你的 AppSecret"
openclaw config set channels.feishu.enabled true
openclaw config set channels.feishu.connectionMode websocket
openclaw config set channels.feishu.dmPolicy pairing
openclaw gateway restart

（3）添加事件：im.message.receive_v1（接收消息）。
