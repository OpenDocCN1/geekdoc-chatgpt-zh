### 4.2.5 集成DeepSeek-R1模型

开发演示时直接写死 API Key 看起来快，但这是不安全的。先说清为什么要避免硬编码，以及如何用环境变量来管理。

1. API密钥的安全性

把密钥直接写在代码里会带来以下隐患。

(1) 代码泄露风险：推送到公开仓库后任何人都能看到；
(2) 密钥滥用：他人可调用额度导致费用上涨；
(3) 安全隐患：恶意操作风险；
(4) 难以管理：更换密钥时需改动多处代码。

2. 什么是环境变量

环境变量是在操作系统层面保存配置的方式，以动态值的形式供程序读取。使用它的好处是：

(1) 安全性：敏感信息脱离代码；
(2) 灵活性：不同环境可配置不同值；
(3) 便于管理：配置集中，修改方便；
(4) 符合最佳实践：实现配置与代码分离。

3. 在Next.js中使用环境变量
