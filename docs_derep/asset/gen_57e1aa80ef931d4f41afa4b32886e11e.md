## 2.2 Agent 的规划与决策能力
在图 2.2 所示架构中，大模型赋予 Agent 的规划与决策能力至关重要。规划是将复杂任务拆分为更小更易管理子任务的过程。研究者提出的规划技术包括任务分解、结合外部规划器和自我反思等。

任务分解包括下述技术。

- 思维链：一种提示技术，让模型一步步思考，帮助其把大任务拆成小任务，并清晰解释思考过程。
- 思维树 Tree of Thoughts，ToT：每个步骤探索多种推理可能性，形成树状结构。可采用广度优先搜索或深度优先搜索，并通过提示或投票评估每一步。

还可通过简单提示、特定任务指令或人工手动分解任务。

结合外部规划器的代表是“大模型 +P”方法：使用 PDDL 规划问题描述语言来描述问题，先由大模型将问题转为 Problem PDDL，再请求外部规划器生成计划，最后将计划转回自然语言。本质上规划步骤外包给外部工具，常见于机器人场景。

自我反思包括下述技术。

- ReAct：框架结合特定任务动作和语言空间，让模型能与环境交互并生成推理轨迹，后续会重点介绍。
- Reflexion：使 Agent 具备动态记忆和自我反思能力的框架，通过回顾过去行动提高推理能力。
- CoH Chain of Hindsight：通过向大模型展示带有反馈的过去输出，鼓励其改进输出。

接下来重点介绍 ReAct 框架和工具调用这两种核心能力。

ReAct 框架是极具代表性的 Agent 推理框架，关注 Agent 的动态性和适应性。在 ReAct 中，Agent 不仅能对任务进行推理，还能根据变化自主行动和调整。Agent 设计体现了一个循环互动过程：先感知当前状态，据此决策行动，再根据行动结果和状态变化进行调整，循环往复。ReAct 让 Agent 更灵活、适应性更强，能在复杂多变环境中有效工作。

工具即我们为 Agent 配备的功能函数、代码段及其他技术工具。基于 ReAct 框架，Agent 不断尝试通过外部工具解决任务或子任务，每次调用都会带来新结果和状态变化。在开发过程中，这些工具不仅提供支持和便利，增强 Agent 能力，也确保其性能与可靠性。

结合 ReAct 框架和工具调用，开发者能更有效地构建和优化 Agent。ReAct 提供方法论指导 Agent 在动态环境中工作，工具调用则提供技术支撑。二者结合使 Agent 更智能、更自主、适应性更强，为各行业带来更多可能。

## 2.3 Agent 记忆机制全景
大模型形成记忆的机制可归纳为以下几种。

第一种是通过预训练形成记忆。大模型在包含世界知识的大规模数据集上预训练，通过调整神经元权重学习理解和生成人类语言，这可视为“记忆”形成过程。借助深度学习神经网络和梯度下降等技术，大模型能不断提升基于输入预测或生成文本的能力，形成世界知识和长期记忆。

第二种是上下文互动。任务执行时，大模型会结合长期记忆和提供的上下文即提示信息使用。理想情况下，若上下文与大模型记忆知识冲突，大模型应优先考虑上下文，以生成更准确、更具上下文特性的回应。通过知识感知微调等方法，可增强大模型在上下文与记忆知识使用上的可控性与鲁棒性。

第三种是通过针对特定任务的微调增强。大模型可在更具体的数据集上进一步微调，以适应特定行为或提升特定任务性能。例如在 SAT 可满足性问题数据集上微调后，大模型回答此类问题会更熟练。
