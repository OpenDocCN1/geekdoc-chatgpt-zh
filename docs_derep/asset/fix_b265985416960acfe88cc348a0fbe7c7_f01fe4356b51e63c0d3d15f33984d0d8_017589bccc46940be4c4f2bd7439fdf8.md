# CrewAI 协作单元 Crew 工作原理

在 CrewAI 体系里，Crew 可以看作一支由若干 Agent 组成的工作小组，负责把复杂需求拆解并落地。每一支 Crew 都约定了工作的推进策略、成员间的配合规则以及整体流程，是搭建多智能体系统的关键构造块，能够明显提升处理能力和复杂度。架构示意参见图 8-2。

### 1. Crew 的属性

Crew 实例暴露了多组可调参数，用以影响作业调度、协作模式以及运行期表现。核心字段整理于表 8-3。

表 8-3

| 属性 | 参数 | 描述 |

| --- | --- | --- |

| Tasks | tasks | 给该 Crew 指派的作业集合 |
| Agents | agents | 参与此 Crew 的 Agent 名录 |
| Process（可选） | process | Crew 运行作业的方式，例如按序或层级，默认按序 |
| Verbose（可选） | verbose | 运行期间输出日志的详细档次，默认关闭 |
| Manager 大语言模型（可选） | manager_llm | 层级模式下负责统筹的 Agent 所用的大模型，使用层级时必须指定 |
| Function Calling 大语言模型（可选） | function_calling_llm | 若设定了函数调用专用的大模型，Crew 会借助它完成 Agent 之间的函数调用 |

### 2. 创建 Crew

CrewAI 支持两种组建方式：YAML 描述和直接编码。

(1) YAML 配置

用 YAML 描述 Crew 配置更易阅读与维护，在项目中较为常见。通常先继承 CrewBase，再用装饰器声明 Agent、Task 与 Crew。基于装饰器的示例如下：

from crewai import Agent, Crew, Task, Process
from crewai_tools import YourCustomTool  # 引入自定义工具
# 定义一个团队类,包含两个智能体和两个任务
class CrewNameExample:
    # 智能体 1:数据分析师
    def agent_one(self) -> Agent:
        return Agent(
            role="数据分析师",  # 智能体角色
            goal="分析市场中的数据趋势",  # 智能体目标
            backstory="具有经济学背景的资深数据分析师",  # 背景设定
            verbose=True,  # 启用详细日志输出
            tools=[YourCustomTool()]  # 使用自定义分析工具
        )

    # 智能体 2:市场调研员
    def agent_two(self) -> Agent:
        return Agent(
            role="市场调研员",
            goal="收集市场动态相关信息",
            backstory="一位细致入微、擅长研究的调研专家",
            verbose=True
        )

    # 任务 1:数据收集与趋势分析
    def task_one(self) -> Task:
        return Task(
            description="收集近期市场数据并识别其中的趋势。",
            expected_output="一份总结市场关键趋势的报告。",
            agent=self.agent_one()
        )

    # 任务 2:影响市场的因素调研
    def task_two(self) -> Task:
        return Task(
            description="调研影响市场动态的主要因素。",
            expected_output="一份关于市场影响因素的分析报告。",
            agent=self.agent_two()
        )

    # 组建团队,串行执行任务
    def crew(self) -> Crew:
        return Crew(
            agents=[self.agent_one(), self.agent_two()],  # 两个智能体
            tasks=[self.task_one(), self.task_two()],      # 两个任务
            process=Process.sequential,                    # 串行执行(按顺序)
            verbose=True                                   # 打印执行过程日志
        )
