# 一套能跑的语义检索最小闭环

想让检索具备理解意图的能力，关键是把查询和文档先投射到同一个语义空间，再用相似度决定先后顺序。下面这个原型以 deepseek-chat 作为编码器，温度固定为 0、单次上限 300 token，让输出保持可复现。

编码环节先拼好请求体拿向量，返回的文本按逗号拆分后只保留能转成浮点数的片段，组装成数值列表。请求失败或解析异常时直接回空列表，后续流程自动短路，避免报错。

余弦打分部分先校验两个向量是否都存在且维度一致，点积除以各自模长的乘积得到分数，若模长为 0 则返回 0，防止除零。

搜索先把用户输入转成向量，转不成就提示并返回空。随后遍历已预计算的文档向量表逐条算分，降序排列默认取前三，只保留文档编号、标题和四位小数的相似度用于展示。

展示层在无结果时提示未找到，有结果时按序号输出编号、标题和得分。交互采用命令行循环，启动打印欢迎语和退出说明，读取输入后去首尾空格，识别退出、exit、quit 结束会话，空输入会要求重输，检索前先给出等待提示。另提供清空对话历史的接口，主程序实例化 DeepSemanticModelingSystem 后进入循环。

实际演示环境中可用模型为 deepseek-v3、deepseek-lite、deepseek-business，账户余额 5000，向量预热完成后进入对话。两次典型提问分别围绕深度学习做文本分类和自然语言处理的定义，返回的前三条排序与语义直觉一致，分数分布合理。整体形成了编码、打分、排序、展示、交互的闭环，换模型或接入持久化存储即可上线。

def cosine_similarity(self, vec1: List[float], vec2: List[float]) -> float:

    """

    计算两个向量的余弦相似度

    """

    if not vec1 or not vec2 or len(vec1) != len(vec2):

        return 0.0

    dot_product=sum(a*b for a, b in zip(vec1, vec2))

    magnitude1=sum(a ** 2 for a in vec1) ** 0.5

    magnitude2=sum(b ** 2 for b in vec2) ** 0.5

    if magnitude1 == 0 or magnitude2 == 0:

        return 0.0

    return dot_product / (magnitude1*magnitude2)

def search_semantic(self, query: str, top_k: int=3) -> List[Dict[str, str]]:

    """

    根据查询语句进行语义搜索，返回最相关的文档

    """

    query_vector=self.get_text_embedding(query)

    if not query_vector:

        print("无法获取查询的语义向量。")

        return []

    similarities=[]

    for doc_id, doc_vector in self.document_vectors.items():

        similarity=self.cosine_similarity(query_vector, doc_vector)

        similarities.append({"doc_id": doc_id, "similarity": similarity})

    # 按相似度降序排序

    similarities=sorted(similarities, key=lambda x: x["similarity"], reverse=True)

    top_docs=similarities[:top_k]

    results=[]

    for doc in top_docs:

        doc_info=DOCUMENT_DATABASE.get(doc["doc_id"], {})

        results.append({

            "doc_id": doc["doc_id"],

            "title": doc_info.get("title", ""),

            "similarity": f"{doc['similarity']:.4f}"

        })

    return results

def display_search_results(self, results: List[Dict[str, str]]):

    """

    显示语义搜索结果

    """

    if not results:

        print("系统：未找到相关文档。")

        return

    print("\n系统：以下是与您的查询最相关的文档：")

    for idx, doc in enumerate(results, start=1):

        print(f"{idx}. 文档ID: {doc['doc_id']}, 标题: {doc['title']}, 相似度: {doc['similarity']}")

def start_semantic_search(self):

    """

            break

            continue

        print("系统：正在进行语义搜索，请稍候...")

        results=self.search_semantic(query)

        self.display_search_results(results)
