### 4.2.2 层内敏感度分析指标

如图 4.3(c) 所示，层内敏感度分析的任务是衡量同一层内各参数单元的贡献度，为保留决策提供依据。依据是否借助数据，可分为数据相关型和数据无关型两类。前者需要在样本上计算，如权重二阶导数、通道激活概率、激活重建误差；后者仅依赖参数本身，如 p-范数、权重多样性、批归一化层的 γ 系数。具体如下。

- （1）权重二阶导数：利用二阶偏导估计移除某单元后损失的增量，优先剔除对损失增长影响较小的单元。
- （2）权重的 p-范数：把 1-范数、2-范数等作为代理指标，数值越小的单元更容易被剪掉。
- （3）权重多样性：目标是保留一个更具多样性的子集。常用做法是计算单元与整体“质心”的距离，越靠近质心的滤波器越易被其他滤波器替代而被优先裁剪。FPGM 就是关注滤波器粒度多样性的典型工作，其观点是越接近全体滤波器几何中心的滤波器可替代性越强。
- （4）批标准化层的 γ 值：直接以批归一化线性变换的缩放因子 γ 作为评判标准，系数较小的单元被移除。
- （5）通道激活概率：在少量样本上推理，统计每个通道激活为非零的比例作为重要性，激活率低的通道被删除。
- （6）激活重建误差：评估删除某单元后该层输出与原始输出的偏差，误差越小说明单元越可舍弃。

经验性结论：若剪枝后有足够数据进行微调或重训练，上述层内指标带来的最终差异通常不明显。

（3）可微分搜索剪枝方法：不预先固定指标，而是把每个单元的敏感度视为可学习参数，通过梯度下降学习等价于剪枝决策的“等效敏感度”。

## 4.3 结构化剪枝方法

结构化剪枝主要作用于层、滤波器等具有结构的粒度。相较非结构化剪枝，其压缩程度通常更保守。优势在于剪枝后网络仍保持稠密的矩阵乘法形态，可直接在 GPU 等擅长稠密计算的通用硬件上运行，从而更容易把压缩转化为实际提速，因而在学术界与工业界都备受关注。

### 4.3.1 基于权重正则的结构化剪枝方法

权重正则在机器学习中常用，典型代表有 1-范数 Lasso[99] 与 2-范数岭回归[96]。岭回归对大权重惩罚更强，对小权重惩罚更弱，不太倾向于把小权重推向零，因而难以得到稀疏解；Lasso 对不同幅值权重惩罚强度一致，更容易获得稀疏解。

加入正则项后优化权重得到稀疏模型，流程如下。

- （1）训练前，先把基于层内敏感度指标设计的正则项加入损失。
- （2）训练时，最小化带正则的损失，正则会把部分权重推向 0 或接近 0。
- （3）训练结束，将接近 0 的权重剔除即得剪枝模型。对应优化问题如式 4.1 所示。

其中，$\alpha^*$ 表示待求解的最优架构参数，$R$ 代表任务性能指标（如分类任务的准确率），$\mathcal{L}$ 代表任务损失函数（如分类任务的交叉熵损失函数），$\omega^*(\alpha)$ 代表架构参数 $\alpha$ 最合适的权重，通过内层的权重优化问题求解得到 $\omega^*(\alpha) = \arg \min_{\omega \in W} \mathcal{L}(\omega, \alpha)$。另外，这类方法显式地优化架构参数 $\alpha$，因此，优化问题加入与 $\alpha$ 相关的其他限制条件是非常自然的，如式 4.6 中的 $\mathcal{F}(\alpha) \leqslant B_{\mathcal{F}}$，$\mathcal{F}(\alpha)$ 是一个与 $\alpha$ 相关的指标，可以是模型复杂度（如参数量、计算量）或实际推理性能（如延时、能耗等），$B_{\mathcal{F}}$ 为该指标的资源限制。

式 4.6 中 $R(\alpha) = R(\omega^*(\alpha), \alpha)$ 的评估需要求解内层权重优化，属于黑盒优化。常见做法是采用离散搜索策略求解。另有工作用可微分代理损失替代 R，对内层近似或把双层问题转为单层，并把离散的 α 松弛为连续 ᾱ，用梯度更新。借鉴 NAS 术语，这类梯度优化剪枝可看作用可微分搜索策略探索离散搜索空间。本节把离散搜索与可微分搜索统称为基于搜索的方法并举例说明。

基于搜索的方法会显式优化架构参数 α。常用的参数化方式有两种。

- （1）剪枝率：被删除权重数占总数的比例。多数工作以层为粒度分配压缩率，代表有 AMC[77]、DSA[81]、ECC[101] 等。压缩率主要用于层间敏感度分析；确定每层压缩率后，再用层内敏感度指标决定保留哪些权重。
- （2）二值掩码：为每个权重单元分配 0/1 掩码，1 保留、0 删除。典型算法如 VCP[97]、BAR[102]。掩码可同时实现层间与层内敏感度分析，剪枝时直接按掩码取值，无需额外层内指标。
