# 内容简介

这是一本面向青少年的智能实践启蒙读物。全书以“感知系统”“超脑”“智能搭档”等形象比喻拆解核心技术，通过猫狗识别实验、语音助手对话、作文润色等日常情境，直观呈现机器学习、计算机视觉与大语言模型的工作原理，并引导读者借助图形化编程搭建语音魔法故事坊、感应小夜灯、校园安全小卫士等有趣作品。

书中特设技术缺陷检验环节，如人脸识别偏差、语言幻觉现象，以及智能使用准则，帮助读者锤炼批判性思维与技术责任感。

全书融入游戏化学习逻辑，“成就打卡”“成就贴纸”将抽象概念转化为可触碰的实践挑战。案例既涵盖围棋对弈、图像识别等经典题材，也包含单词记忆游戏、数学推理演练、AI艺术创作等跨学科创新，适配10～16岁青少年的科技素养提升。同时可作为教师设计STEM课程、家长开展亲子科创活动的实用参考，助力学习者在创造中掌握面向未来的关键能力。

# 前言

当你对着音箱点歌、看着手机相册自动挑出猫咪照片、让智能工具帮忙梳理作文思路时，是否好奇这些贴心功能背后的运转逻辑？编写《有趣的人工智能：少年AI启蒙课》正是希望智能不再是课本里的陌生术语，也不只是专家内部的深奥理论，而是像积木一样可以拿起、拼搭的玩伴，在动手过程中点燃对科技的好奇与热爱。

我们清楚10～16岁的孩子很难直接消化抽象概念，所以全书围绕“让智能看得见、摸得着、用得上”展开。用“感知系统”讲解视觉技术，通过猫狗识别让读者体会机器如何“看见”世界；用“超脑”解读机器学习，从围棋对弈到数学推演展现机器如何“学习”规律；用“智能搭档”介绍大语言模型，结合语音互动与作文修改让读者明白机器如何“听懂”与“表达”。这些不仅是知识传递，更是要建立智能源于生活也服务于生活的认知。

本书跳出单向阅读，构建三大特色：其一，动手实验模式，读者可用图形化工具亲手完成语音魔法故事坊、智能感应小夜灯、校园安全小卫士等项目，在做中学原理；其二，重视批判思维培养，专门设置技术漏洞测试，剖析人脸识别误差与语言幻觉成因，并编写智能使用守则，强调理性看待技术与承担使用责任；其三，游戏化设计贯穿始终，“闯关测验”“成就打卡”“成就贴纸”把知识点变成可挑战的关卡，在获得感中消化抽象内容。

编写坚持“有趣优先、实用为辅”，不用繁复公式与专业术语，而是以比喻、场景、案例搭桥；既保留围棋、图像识别等经典，也纳入单词记忆、AI艺术创作等跨学科实践，让不同兴趣的读者都能找到入口。本书不是一次性读完的资料，而是一本可反复翻阅、随时动手的科技工具箱。

读者远不止青少年。10～16岁的小读者可从这里开启轻松启蒙；教师可把案例与项目直接用作STEM教学素材；家长也能借此开展亲子科技活动。我们期待合上书时，带走的不仅是对智能的认知，更是探索、思考、创造的勇气。未来的科技世界需要理性与热爱来塑造，而这本书就是送给你的一把钥匙。

# 第1章 初识智能：它已潜入生活

## 1.1 人工智能究竟是什么

人工智能是计算机科学的重要分支，仿佛为机器施法，让普通计算机模拟、延伸和扩展人类智能，完成原本需要人处理的复杂任务。通俗说，智能就是让机器具备感知、思考与行动的能力，让它“看得见、听得懂、想得通、做得到”，成为得力的智能小伙伴。

### 1.1.1 机器的感知系统

智能让机器拥有感知世界的“眼睛”与“耳朵”。人进入陌生房间会用眼扫视、用耳捕捉声音、手指触摸；机器的感知则是摄像头、激光雷达、麦克风与各类传感器。

例如，扫地机器人的顶盘激光雷达会像蝙蝠回声般不断扫描房间轮廓以避障；自动驾驶汽车的“眼睛”比细心司机更强，能同时观察四周，实时捕捉行人、车辆、交通标志等细节。这些感知装置把图像、声音、温度等转化为数字序列，像把真实世界翻译成计算机可读的密码，智能正是通过这些密码理解世界。

### 1.1.2 机器的超脑

智能拥有能像人一样思考、甚至更快更全面的“超脑”。大脑由神经网络等复杂算法构成，模仿人脑神经元互联传递信息，从海量数据中找规律、解问题。

输入目的地时，导航智能会瞬间分析上万条路线，同时考量拥堵、施工、天气等，推送最优方案。刷短视频时，智能也在默默判断：“喜欢猫咪视频的，下一条推小猫打哈欠的萌瞬间”。这就是用专用程序分析信息、给出最贴合需求答案的过程。

### 1.1.3 机器的超能执行

思考之后就要执行，靠扬声器、屏幕、机械臂等“钢铁手脚”完成。比如对智能音箱说“播放李白的《静夜思》”，它会完成感知识别语音、思考匹配诗歌库、执行播放诗歌的全套流程。

更强的智能堪比“钢铁侠”，能完成高难度任务。工业机器人可精准焊接汽车零件，误差小于头发丝；医院智能手术机器人能稳准缝合血管，动作比资深医生更稳。

## 1.2 智能是如何“学习”的

你是如何认识猫的？第一次见小猫时，大脑像侦探搜集证据：毛茸茸的外表、尖耳朵、大眼睛、长胡须。反复见到后，大脑归纳出共同特征：四条腿、长尾巴、尖耳朵、圆眼睛、长胡须。下次看到新动物时迅速判断“很可能是一只猫”。这就是积累经验、归纳规律并应用规律的过程。

### 1.2.1 数据寻宝大冒险

智能学习的核心叫机器学习，像一场数据寻宝。首先收集海量数据宝藏：文字、图片、声音、视频等，如你反复观察各种猫积累经验。接着用算法在数据中挖宝，总结出专属规律即模型，如你发现猫的共同特征。最后把规律转化为超能力，应用到全新场景，不仅能认出未见过的猫，还能判断它是否想玩耍。智能正是靠从数据中挖掘规律不断解锁新技能。人类学习与智能学习对比见图1-8。

### 1.2.2 学习的第一招：监督学习

监督学习像有老师指导，工程师为计算机准备带标签的数据，如大量标有cat、dog的动物图片。计算机分析颜色、形状、纹理等特征，找出特征与答案的联系，学会区分动物，再用以判断新图片，如图1-9。

例如教计算机认手写数字0-9，给它很多带答案的练习册。计算机分析笔画弯曲、点线位置等特征，慢慢分辨出潦草的7和一笔的1，找到规律后即可识别新图片中的数字，如图1-10所示。
