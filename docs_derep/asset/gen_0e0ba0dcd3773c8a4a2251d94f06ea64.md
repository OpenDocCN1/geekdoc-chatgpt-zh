PyTorch CPU GPU 实测对比：同样模型，速度差四倍

想知道把模型搬到 GPU 上到底能快多少？用 CIFAR-10 和一个简洁的 SimpleCNN 做了一轮对照，数据加载、模型初始化、训练超参全部保持一致，只有运行设备不同。结果很直观：正确率一致，耗时差了四倍。

数据预处理与加载
训练集和测试集都用 torchvision.datasets.CIFAR10 读取，transform 里做了均值为 0.5、方差为 0.5 的标准化。训练 DataLoader 批大小设 128，打乱开启；测试 DataLoader 批大小 100，不打乱。两个 Loader 都打开了 num_workers=2 与 pin_memory=True，帮助 CPU 到 GPU 的搬运。

模型与优化
CPU 端和 GPU 端各实例化一个 SimpleCNN，损失函数用 CrossEntropyLoss，优化器都用 Adam，学习率 0.001。训练轮数固定为 5 轮，训练过程与测试过程分别打印日志。

显存使用行为观察
为了看 GPU 内存是怎么增长和释放的，用了一个简单的 SimpleNet：1000 输入 -> 10000 全连接 + ReLU -> 1000 输出，在 cuda 上跑一次前向反向。

代码片段：
[PRE2]python
import torch

import torch.nn as nn

import torch.optim as optim

import gc

# 定义一个简单的神经网络模型

class SimpleNet(nn.Module):

    def __init__(self):

        super(SimpleNet, self).__init__()

        # 两个全连接层和一个 ReLU 激活函数

        self.fc1 = nn.Linear(1000, 10000)

        self.relu = nn.ReLU()

        self.fc2 = nn.Linear(10000, 1000)

    def forward(self, x):

        x = self.fc1(x)

        x = self.relu(x)

        x = self.fc2(x)

        return x

# 函数：显示当前 GPU 的内存使用情况

def print_gpu_memory():

    allocated = torch.cuda.memory_allocated() / (1024 ** 2)

    reserved = torch.cuda.memory_reserved() / (1024 ** 2)

    print(f"已分配内存: {allocated:.2f} MB")

    print(f"已保留内存: {reserved:.2f} MB")

def main():

    # 检查 CUDA 是否可用

    if not torch.cuda.is_available():

        print("CUDA 不可用，请检查 GPU 和驱动。")

        return

    device = torch.device("cuda")

    print(f"使用设备：{device}")

    # 创建模型并将其加载到 GPU 上

    model = SimpleNet().to(device)

    print("模型已被加载到 GPU 上。")

    print_gpu_memory()

    # 定义优化器

    optimizer = optim.Adam(model.parameters(), lr=0.001)

    # 定义损失函数

    criterion = nn.MSELoss()

    # 创建输入张量和目标张量

    input_tensor = torch.randn(64, 1000, device=device)

    target = torch.randn(64, 1000, device=device)

    print("\n开始进行前向传播和反向传播")

    # 前向传播

    output = model(input_tensor)

    loss = criterion(output, target)

    # 反向传播

    loss.backward()

    optimizer.step()

    print("完成第一次训练步骤。")

    print_gpu_memory()

    # 删除不再需要的变量并清理缓存

    del input_tensor, target, output, loss

    torch.cuda.empty_cache()

    gc.collect()

    print("\n清理缓存后内存的使用情况：")

    print_gpu_memory()

    # 再次进行前向传播和反向传播，观察内存变化

    input_tensor = torch.randn(64, 1000, device=device)

    target = torch.randn(64, 1000, device=device)

    print("\n再次进行前向传播和反向传播")

    output = model(input_tensor)

    loss = criterion(output, target)

    loss.backward()

    optimizer.step()

    print("完成第二次训练步骤。")

    print_gpu_memory()

if __name__ == "__main__":

    main()

要点是已分配内存会被释放，已保留内存不会随 empty_cache 回收，第二次训练又会复用已保留的缓存。

页锁定内存与普通内存搬运对比
CPU 到 GPU 的数据拷贝，是否用 pin_memory 会影响速度。下面的测试对比了普通内存和页锁定内存搬运一个 10000x10000 的张量，页锁定版本使用 non_blocking=True。

[PRE4]python
import torch

import time

def transfer_with_pinned_memory(tensor_size):

    # 创建普通内存

    input_tensor = torch.randn(tensor_size, device='cpu')

    # 记录传输普通内存所需时间

    start_time = time.time()

    output_tensor = input_tensor.to('cuda')

    torch.cuda.synchronize()

    end_time = time.time()

    normal_time = end_time - start_time

    # 创建页锁定内存

    pinned_input = input_tensor.pin_memory()

    # 记录传输页锁定内存所需时间

    start_time = time.time()

    output_pinned = pinned_input.to('cuda', non_blocking=True)

    torch.cuda.synchronize()

    end_time = time.time()

    pinned_time = end_time - start_time

    return normal_time, pinned_time

def main():

    tensor_size = (10000, 10000)  # 定义张量大小

    print(f"测试张量大小: {tensor_size}")

    normal_time, pinned_time = transfer_with_pinned_memory(tensor_size)

    print(f"普通内存传输时间: {normal_time:.6f} 秒")

    print(f"页锁定内存传输时间: {pinned_time:.6f} 秒")
结论很清楚：同等模型、同等数据下，GPU 把训练耗时从约 120 秒压缩到约 30 秒，精度保持 63.00% 不变；显存方面已分配可回收，已保留会长期占用；数据搬运上页锁定内存配合异步拷贝更顺畅。
