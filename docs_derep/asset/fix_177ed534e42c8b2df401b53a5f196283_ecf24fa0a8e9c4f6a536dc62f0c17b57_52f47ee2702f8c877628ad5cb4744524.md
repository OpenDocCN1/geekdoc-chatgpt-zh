# ChatGLM6B minlora 低秩微调实战

这篇笔记梳理一次用 minlora 对 ChatGLM6B 做参数高效微调的完整链路。整体思路是让底座模型的参数全部冻结，只在部分注意力投影上挂载低秩适配器，训练与推理时只更新 LoRA 的少量参数。

工具层共暴露四类操作。apply_lora 负责按配置给指定层属性挂载或卸下参数化，add_lora、merge_lora、remove_lora 都是对整网进行 apply 的封装，分别对应挂载适配器、把低秩增量合并回主权重、彻底卸载。get_parameter_number 则一次性统计全网参数量与可训练参数量，方便确认冻结效果。

挂载时遍历 lora_config，按层类型找到对应的属性名调用 register_parametrization 生产参数化；拆除时遍历 layer.parametrizations，调用 remove_parametrizations，merge 标记决定是否保留合并后的数值。add_lora 调用时注册，merge_lora 与 remove_lora 调用时关闭注册并分别打开合并或纯移除。

训练侧先把 strict 关掉加载 XiaohuaModel，随后遍历 named_modules，只对名称中包含 query_key_value 的子模块执行 add_lora，然后把所有参数 requires_grad 置为 False，最后载入已训练的 LoRA 权重。

def sample_top_p(probs, p):
    probs_sort, probs_idx = torch.sort(probs, dim=-1, descending=True)
    probs_sum = torch.cumsum(probs_sort, dim=-1)
    mask = probs_sum - probs_sort > p
    probs_sort[mask] = 0.0
    probs_sort.div_(probs_sort.sum(dim=-1, keepdim=True))
    next_token = torch.multinomial(probs_sort, num_samples=1)
    next_token = torch.gather(probs_idx, -1, next_token)
    return next_token

LoRAParametrization 保留了低秩分解 A、B 的构造、缩放与 Dropout 掩码，以及开关控制。初始化时依据 fan_in_fan_out 选择是否交换维度，用 kaiming 均匀初始化 A，缩放因子设为 lora_alpha / rank。forward 时在原输入上叠加低秩增量，disable_lora 与 enable_lora 分别把前向函数切回恒等或恢复增量。from_linear 与 from_conv2d 提供了线性层与二维卷积层的便捷工厂。

class LoRAParametrization(nn.Module):
    def __init__(self, fan_in, fan_out, fan_in_fan_out=False, rank=4, lora_dropout_p=0.0,
lora_alpha=1):
        super().__init__()
        # if weight is stored as (fan_out, fan_in), the memory layout of A & B follows
(W + BA)x
        # otherwise, it's x(W + AB). This allows us to tie the weights between linear layers
and embeddings

x: x

dtype=self.lora_A.dtype))

        # to mimic the original implementation: A @ dropout(x), we do (A * dropout(ones))
@ x
