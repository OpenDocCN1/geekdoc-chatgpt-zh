全书共七章。第一章阐述 OpenClaw 的核心思路与时代背景，并与传统人工智能产品做对比，说明从单纯对话到主动执行的转变；第二、三章覆盖部署前的准备与安装实践，涉及本地或云端方案甄选、运行环境准备、接口密钥获取及首次配置；第四章聚焦日常操作，讲解终端交互界面与网页控制台、人设设定、渠道接入、记忆维护、心跳机制、定时任务以及插件安装等关键功能；第五章提供火山 ArkClaw、飞书妙搭、智谱 AutoClaw 三套企业级龙虾的快速落地方案，降低上手门槛；第六章围绕风险防范，从默认设置解读、费用上限控制到群组使用规范，帮助筑牢安全底线；第七章覆盖文件整理、信息检索、定期汇报、内容生产、社交互动与副业增收六大实战，让 OpenClaw 真正成为效率引擎。

本书适合希望摆脱重复性劳动的职场人士、致力于搭建自动化工作流的内容创作者、想借助效率工具探索副业收入的人，以及对智能体技术感兴趣的初学者阅读。

### 人工智能时代的底气，从驯养一只会做事的龙虾开始

在这个人工智能蓬勃发展的时期，我观察到大量使用者陷入工具焦虑——手机里装满十几种人工智能应用，却找不到切入点把它们用起来。真正的解法并非堆砌工具，而是拥有一名能够整合资源并落地执行的总管。OpenClaw，也就是民间常说的“龙虾”，正好承担这个角色。

本书不深究技术原理，而是把龙虾的典型用法讲透。我们会演示如何让它管理本地资料，把零散文件转化为工作素材；如何设定定时任务，让它每日自动搜集行业动态，抢占信息差；如何安装技能插件，让它撰写小红书文案、处理网店订单，一个人支撑起工作室；乃至如何搭建专属智能体，把一次性的成功经验固化为可复用的变现工具。

不少人担忧人工智能工具风险高、本质难控，本书也给出可控方案。从网关、令牌、配置文件，到支出上限与风险意识培养，形成闭环。

需要强调的是，龙虾再强大也只是放大使用者优势的杠杆。你对商业变现的理解越清晰，它落地的效率越高；你的行业沉淀越深，它创造的价值越大。书中案例与操作，都是为了帮助你把个人优势与龙虾能力结合，形成难以复制的核心竞争力——你的提示词、你的工作流、你的专属知识库，都是护城河。

随书附赠的龙虾安装资源包，包含详尽安装指南、常用技能清单与故障速查，可帮助你绕过技术障碍，快速进入实操。

翻开本书，跟着我们一步步驯养龙虾，你会发现人工智能时代的生存法则并非盲目追新，而是找准一个可靠工具，把它用出商业价值。

## 第 1 章 觉醒时刻：人工智能已从陪聊走向超级数字员工

2026年初，一只没有屏幕也没有语音的“龙虾”悄然进入人们的数字生活。它不会寒暄，却能在使用者入睡后独立修正代码、回复邮件、预约次日会议。它不是又一个工具，而是首个真正意义上的数字雇员：下达任务后即可去忙，工作在休息时完成。

开源仅三个月，OpenClaw 在 GitHub 累计星标突破三十万，增速位居历史榜首，远超 Linux 内核十年积累。饲养龙虾从极客黑话变成全球热词。

### 1.1 告别只会开口的智能体，迈向真正会执行的时代

2022年 ChatGPT 横空出世带来的震撼记忆犹新，随后国内外人工智能工具井喷。你问什么它答什么，写稿、写码、作图样样行。但真正用于工作时，尴尬随之而来：以前自己查消息，现在要先看人工智能总结再看原文；以前自己写回复，现在要修改人工智能写的回复；答案是否可信要自行核查，代码能否运行要亲自测试，邮件是否冒犯要逐字斟酌。人工智能省下了生成时间，却增加了校对与返工时间，算下来更疲惫。

#### 1. 半自动化的陷阱吞噬了多少工时？

2026年 Workday 的调研显示，92%的职场人群每周借助人工智能节省一至七小时，但58%的人每周需花费一至两小时修正人工智能产出；重度使用者中，77%表示核对人工智能成果的仔细程度不亚于人工审核。

诺贝尔经济学奖得主丹尼尔·卡尼曼团队在2024年的研究指出，“半自动化陷阱”已成为数字时代的新型生产力杀手：系统将部分环节自动化，却把关键决策权保留给人类，认知负荷不降反升——既要监督机器，又要承担责任，还需在出错时紧急接管。

卡尼曼在访谈中说：“这不是真正的自动化，而是自动化表演，让雇主误以为员工有了助手，实际上员工成了人工智能的保姆。”

粗略估算，若每天因核实返工多花一小时，一年约250小时，按每天八小时计，相当于多工作31天，还未计入精神损耗与机会成本。

#### 2. 2026年初，龙虾登岸

就在集体疲惫感达到顶峰时，一个开源项目改写了规则，这就是 OpenClaw。发布时并无盛大发布会，也无硅谷大人物站台，前数周几乎无人关注，但程序员很快发现它的不同。

这个人工智能，真的能够操作电脑。不是比喻，而是真实操作。你指令“打开桌面Excel，将第三列求和，结果发送给王总”，它会调用插件完成全流程。它能观察屏幕、识别按钮，遇到错误会自行尝试，实在不行才会询问。

一名早期使用者在 GitHub 留言：“使用 OpenClaw 后，我第一次感觉人工智能是我的工具，而不是我需要伺候的产品。”

这种感受迅速扩散。2026年1月至3月，OpenClaw 的星标从零飙升至三十余万，创下开源项目最快增长纪录。中国开发者社区、新媒体平台、职场社群开始流传各类驯养龙虾的教程与晒单。

“今天让龙虾整理电脑文件，那些凌乱的文档终于井井有条。”
“睡前说整理下周计划，早上到公司日程已排好。”
“我让龙虾每天晚十点调研最新人工智能资料，睡前在飞书就能查看。”

饲养龙虾成为一种新生活方式——不是宠物式饲养，而是雇用一位24小时待命的数字实习生。

新的问题随之而来：当人工智能开始上班，人类是否准备好当老板？

#### 3. 你准备好雇佣首个数字员工了吗？

OpenClaw 带来的真正改变，是让你从“使用人工智能”中解放，去做创意、决策与思考。

2026年正处微妙转折点。一边是旧模式：把人工智能当搜索引擎，为每个错误擦屁股，在假自动化里消耗生命；另一边是新模式：雇佣人工智能，下达任务后去做别的事，让它像真正的员工一样独立工作。

无需懂得编程，也无需理解技术原理，只需转变观念：从“我询问它回答”，到“我指派它执行”。这一观念的转变，将决定未来是继续在操作软件中疲于奔命，还是在指挥数字团队中游刃有余。

你的龙虾，已在等待第一条指令。

### 1.2 OpenClaw 究竟是什么样的存在？

OpenClaw 是一款能够干活的人工智能代理，其核心目标是把普通聊天机器人的能力升级为在电脑上自动执行任务。它是连接人工智能大脑与真实操作系统的桥梁，通过自然语言指令自动打开软件、移动鼠标、输入键盘、处理表格、发送邮件，你只需等待结果。

#### 1. 从 Clawdbot 到 OpenClaw 的演进

OpenClaw 的诞生与发展堪称人工智能领域的“一夜成名”案例，尽管历史尚短，影响力却极大。

OpenClaw 由奥地利开发者彼得·斯坦伯格研发，他是知名 PDF 处理库 PSPDFKit 的联合创始人，技术积淀深厚。

##### （1）初心实验

2025年末，彼得发布了一个名为 Clawdbot，或称 Moltbot 的实验项目。灵感来源于当时人工智能语言模型只能“说话”却无法“办事”的痛点。彼得希望人工智能不仅能回答问题，还能像人类一样点击鼠标、敲击键盘，完成电脑上的实际操作。于是 Clawdbot 诞生，成为 OpenClaw 的雏形。

##### （2）品牌统一

随着实验项目在技术圈发酵，众多少数派分叉出现。为避免社区分裂，彼得正式将品牌定名为 OpenClaw，保留原始精神，同时突出开源开放的态度。

##### （3）技术成熟

品牌统一后，核心技术快速完善。

开源协议采用宽松的 MIT，任何人可自由使用、修改、分发。
技术核心基于当前主流的大语言模型，可接入本地 Ollama 或云端模型，实现理解与判断。
技能插件生态超过三千个，赋予它直接控制电脑与软件的能力，无论是打开代码编辑器，还是在图像软件中处理，还是在表格中完成数据分析，都能通过调用插件实现。

#### 2. 基本概念：OpenClaw 如何运作？

OpenClaw 采用开源 MIT 协议，核心基于大语言模型，最关键的是集成了数千个技能插件，能够直接控制电脑与各类软件。

简化来看，共有四层架构。

人工智能模型层：可连接本地模型如 Ollama，或云端模型如 ChatGPT、千问，负责思考。
插件层：内置数千插件，能模拟人类操作如打开软件、点击鼠标、敲键盘，也能调用 API 如发送邮件、访问数据库，是执行力的来源。
本地记忆层：所有数据保存在本地电脑或私有服务器，不上传第三方。
渠道层：支持接入飞书、钉钉、QQ、微信等社交工具，实现跨设备指令。

总而言之，OpenClaw 能连接模型理解你的话，通过内置插件在电脑上办事，数据留在本地，还能通过社交工具接收指令。

#### 3. 核心功能：OpenClaw 能帮你做什么？

OpenClaw 特别适合解决重复性或流程化工作。常见应用场景包括：

文档处理：口头指令“帮我写一份月度总结，保存到 D 盘并邮件发送”，它会自动打开 Word 编写排版、保存并发送邮件。
表格统计：说“把这张表的平均值算出来”，它会操作 Excel 并告知结果。
信息查找：说“帮我找一篇关于人工智能的新闻”，它会自动打开浏览器搜索并提炼要点。
邮件管理：说“把上周所有邮件转发给小张”，它会自动打开邮箱搜索并转发。
开发辅助：说“帮我运行这个 Python 脚本”，它会打开终端输入命令执行并返回结果。

它之所以迅速走红，不仅因技术成熟，更因契合需求，解决了过去人工智能只能“说话”却不能“办事”的痛点，带来解放双手的安全感。

低门槛：像与朋友聊天一样下达指令，无需学习脚本或宏。
隐私安全：核心操作在本地完成，敏感文件不外泄。
高效率：一次性完成多步流程，告别复制粘贴。
社交融合：可通过微信、飞书、钉钉接收指令并返回结果。

但优势不等于无风险。默认配置下 OpenClaw 存在严重漏洞，可能导致数据泄露、账号被盗甚至远程控制。工业和信息化部、国家互联网应急中心及多家安全厂商于2026年3月发布风险提示。

### 1.3 OpenClaw 与其它人工智能产品的本质差异

OpenClaw 与豆包、千问、ChatGPT 等传统产品的本质区别体现在“控制权”与“执行力”上。它不仅是对话工具，更是具备物理操作能力的数字助理。

#### 1. 本质：从会说到会做

传统模型只能提供思路，OpenClaw 是真正的执行者，能直接操作电脑。

能力范围：传统产品局限于认知层面，理解文字、生成文字、分析数据；OpenClaw 覆盖认知与行动，既能理解文字，也能直接操作电脑、点击鼠标、敲键盘。
执行机制：传统为被动响应，只能在文本框告知该怎么做，用户需自行处理；OpenClaw 主动执行，可代替用户打开软件、输入指令、保存文件、发送邮件。
数据安全：传统多为云端处理，对话内容上传服务器；OpenClaw 默认本地私有，隐私性更高。
技术实现：传统基于自然语言处理；OpenClaw 基于语言模型加数千插件加计算机视觉。

#### 2. 操作层面的差异：自动化与手动化

在实际使用中，OpenClaw 不再只是给出答案的老师，而是直接完成任务的干将。它可以直接在 Word 中撰写、在 Excel 中核算，甚至在 Photoshop 中修图。

例如写稿，使用传统人工智能你得到文案草稿后需复制到 Word 排版；使用 OpenClaw 它直接在 Word 中撰写排版保存。
例如算账，传统人工智能告诉公式，你手动输入；OpenClaw 直接操作 Excel 并返回结果。
