#### 6. Turing 架构

2018 年 Turing 架构落地，采用 TSMC 12 nm 制程，晶体管总数达 186 亿个。在 PC 游戏、专业图形应用以及深度学习推理领域，效率与性能均实现关键进步。相对 Volta，主要演进集中在 Tensor Core、CUDA 与 cuDNN 库，以更好地服务推理场景。RT Core 即光线追踪核心，提供实时光线追踪渲染，涵盖物理精确的投影、反射、折射以及逼真的物体与环境表现。内存方面支持 GDDR6，相较 GDDR5 的传输速率提升至 14 GB/s，效率约提升 20%。NVLink 2.0 提供 100 GB/s 双向带宽，使特定负载可在两颗 GPU 间拆分并共享显存。

如图 4.1.12 所示，TU102 包含 6 个图形处理集群、36 个纹理处理集群与 72 个 SM。每个 GPC 含 1 个专用光栅引擎与 6 个 TPC，每个 TPC 含 2 个 SM。每个 SM 内置 64 个 CUDA Core、8 个 Tensor Core、1 个 256 KB 寄存器文件、4 个纹理单元以及可配置的 96 KB L1/共享内存。由此 TU102 共计 4608 个 CUDA Core、72 个 RT Core、576 个 Tensor Core、288 个纹理单元，以及 12 个 32 位 GDDR6 内存控制器，总位宽 384 位。

#### 7. Ampere 架构

2020 年发布的 Ampere 主要特性如下：

- 晶体管数超过 540 亿，成为 2020 年世界上最大的 7 nm 处理器，即英伟达 A100；
- 推出 Tensor Core 3.0，新增 TF32，面向 AI 的扩展可使 FP32 精度 AI 性能提升约 20 倍；
- 多实例 GPU 将单个 A100 划分为多达 7 个独立 GPU，为不同任务提供差异化算力，便于云厂商做算力切片；
- 引入 NVLink 3.0 与 NVSwitch 方案，NVSwitch 可互联多台机器，使 GPU 高速连接速度翻倍，在服务器中实现有效扩展。

上述改进使 Ampere 成为新一代数据中心与云计算 GPU 架构，可用于 AI 与高性能计算。

#### 8. Hopper 架构

2022 年 Hopper 架构发布，Grace Hopper 超级芯片将 Hopper GPU 的突破性性能与 Grace CPU 的通用能力结合于单颗超级芯片中，通过高带宽一致的 NVLink Chip-to-Chip 互联以及新的 NVLink 切换系统，实现 CPU-GPU 与 GPU-GPU 间高达 900 GB/s 的传输，缓解 CPU-GPU 数据延迟，并通过 PCIe 5 实现跨机互联。

Hopper 是首个真正的异构加速平台，面向 HPC 与 AI 负载。如表 4.1.4 所示，Grace CPU 与 Hopper GPU 经 NVLink-C2C 互联总带宽达 900 GB/s，并支持 CPU 内存被 GPU 地址映射。NVLink 4.0 可连接多达 256 个 Grace Hopper 超级芯片，最高可达 150 TB 的 GPU 可寻址内存。

如图 4.1.16 所示，H100 含 8 组 GPC、66 组 TPC、132 组 SM，共计 16896 个 CUDA Core、528 个 Tensor Core、50 MB 二级缓存。显存采用 HBM3，容量 80 GB，位宽 5120 bit，带宽高达 3 TB/s。
