**知识扩展**

用户提示词就是用户输入的文本，用来指导模型生成符合需求的内容，通常是一个问题、请求或指令。它的作用包括：

（1）明确需求：直接体现用户意图。
（2）指引生成：为模型划定内容方向与范围。
（3）控制风格与格式：如要求“用简洁语言解释机器学习基本概念”，模型会输出简洁版；要求“详细解释”则会输出详版。
（4）提供上下文：在多轮对话中帮助模型保持连贯。
（5）提升准确性：提示越具体，回答越精确。

**知识扩展**

“添加知识库”对话框中的“重排模型”用于优化搜索结果排序，“请求文档片段数量”用于在信息量与 token 消耗间取舍，通常保持默认即可。

token 是文本分词后的最小单元，可是一个词、词组或单个字符。AI 处理文本时先切分为 token 再分析，token 数也是计费依据，用量越多费用越高。
