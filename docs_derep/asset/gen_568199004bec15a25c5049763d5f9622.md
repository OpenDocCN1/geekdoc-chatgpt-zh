### 4.2 HuggingFace 训练推理实战

在真实应用里，数据预处理和参数优化直接决定模型表现。Hugging Face 不仅模型库丰富，还提供了高效的数据预处理和标注工具，能快速把原始文本转成模型输入。

本节先讲如何做标准化预处理，用 Tokenizer 把文本转成张量并标注标签，让不同 NLP 任务的数据都变得可用。再讲训练时的参数优化和监控，包含学习率调度、正则化、梯度裁剪等手段，并通过指标实时追踪收敛情况，帮助模型稳定提升。

#### 4.2.1 训练数据预处理与标注

模型训练前必须先把数据处理成符合输入规范的格式。也可以直接在 Hugging Face 上挑现成的 Dataset 再据此加工。

代码要点：

(1) 分词器加载：用 AutoTokenizer.from_pretrained(model_name) 载入对应预训练模型的分词器。
(2) 分词与掩码生成：分词器输出 input_ids 表示 Token 序列，attention_mask 标记有效位置，通过 padding="max_length" 和 truncation=True 统一长度。
(3) 标签张量化：用 torch.tensor(labels) 把标签转为 PyTorch 张量，方便后续计算损失。

运行后会得到这种结构的数据：

[PRE17]

数据解读如下：

(1) input_ids：文本分词后的 ID 序列，每个 Token 对应词表中的编号。
(2) attention_mask：1 表示有效 Token，0 表示填充位，让模型忽略填充部分。
(3) 标签张量：转为张量后可直接参与训练时的损失计算。

通过结构化的 Tokenizer 处理，输入数据能直接进入训练和推理，提升整体效率。
