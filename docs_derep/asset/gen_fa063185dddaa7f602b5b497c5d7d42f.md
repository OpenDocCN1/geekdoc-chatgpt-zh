# 冷启动推荐实战：从向量匹配到双服务部署

想让新用户进来就有东西可看，核心思路就是先用语义向量做粗筛。做法很直观：把用户兴趣向量和冷启动文章向量送进余弦相似度计算，得到一维分数序列；再把这串分数写回文章表里作为 similarity 字段，最后按分数从高到低排序，相似度最高的排在前面。排序完成后就可以为用户画像表里的每一位用户单独跑一遍推荐：取用户的 interests 和冷启动文章池，调用推荐函数拿到排好序的结果，并打印出 article_id、描述和相似度。

冷启动池里目前只有三篇样例，分别是科技、健康、时尚三个方向。实际跑下来，偏好科技的用户对人工智能趋势文匹配最强，健康类用户对健身技巧文最买账，时尚类用户则把搭配秘诀排在首位。相似度数值清晰地体现了兴趣与内容的贴合程度，也验证了向量匹配在冷启动阶段的可行性。

上线后推荐能力要能被内部系统和外部前端同时调用，所以同时提供了 gRPC 和 REST 两种接入方式。推荐核心先抽象成 generate_recommendations，当前是模拟返回五条商品，未来可直接换成模型推理。gRPC 端实现 RecommendationServicer，GetRecommendations 接收 user_id，调用核心函数后把结果 json 序列化返回；服务监听 50051 端口，使用线程池。Flask 端暴露 /recommend POST 接口，读取请求里的 user_id，同样调用核心函数后返回 JSON。主程序用线程把 gRPC 服务和 Flask 服务并行启动，实现一进程双协议。

接口契约用 Protocol Buffer 定义，服务名 Recommendation，提供 GetRecommendations 方法，请求携带 user_id 字符串，响应携带 recommendations 字符串。生成代码的命令使用 grpc_tools.protoc，指定 proto 路径和输出目录。

为了验证可用性，准备了统一的测试客户端。gRPC 调用通过 insecure_channel 连到本地 50051，创建 Stub 调用 GetRecommendations 并打印结果；Flask 调用则用 requests POST 到 http://localhost:5000/recommend，打印返回的 JSON。测试用例使用用户123，两条路径都返回相同的五条模拟商品，证明双服务行为一致。

后续模型落地的思路是先导出 ONNX。示例里定义了一个 SimpleRecommendationModel，包含用户和物品的 Embedding 以及一个全连接层，forward 中先查表得到 embedding 再做逐元素交互，为后续推理加速做准备。

import grpc

from concurrent import futures

import time

import json

from flask import Flask, request, jsonify

import recommendation_pb2

import recommendation_pb2_grpc

###### 推荐逻辑的核心功能

def generate_recommendations(user_id):

    # 模拟推荐逻辑，实际逻辑可以使用模型推理

    return [f"推荐商品_{i}" for i in range(1, 6)]

###### gRPC 服务实现

class RecommendationService(recommendation_pb2_grpc.RecommendationServicer):

    def GetRecommendations(self, request, context):

        user_id = request.user_id

        recommendations = generate_recommendations(user_id)

        return recommendation_pb2.RecommendationResponse(

            recommendations=json.dumps(recommendations)

        )

###### gRPC 服务启动

def start_grpc_server():

    server = grpc.server(futures.ThreadPoolExecutor(max_workers=10))

    recommendation_pb2_grpc.add_RecommendationServicer_to_server(

        RecommendationService(), server

    )

    server.add_insecure_port('[::]:50051')

    print("gRPC 服务已启动，端口: 50051")

    server.start()

    server.wait_for_termination()

###### Flask 服务实现

app = Flask(__name__)

@app.route('/recommend', methods=['POST'])

def recommend():

    data = request.get_json()

    user_id = data.get('user_id')

    recommendations = generate_recommendations(user_id)

    return jsonify({"recommendations": recommendations})

###### Flask 服务启动

def start_flask_server():

    app.run(port=5000)

if __name__ == '__main__':

    import threading

    threading.Thread(target=start_grpc_server).start()

    start_flask_server()
