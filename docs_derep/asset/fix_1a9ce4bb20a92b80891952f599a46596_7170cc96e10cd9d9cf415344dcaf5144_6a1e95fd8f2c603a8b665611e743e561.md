# 手写 CUDA 核 vs 原生算子：MNIST 对照

最近想验证一个直觉：把全连接里的矩阵乘换成自写的 CUDA 内核，数值会不会漂移，训练耗时会不会明显不一样。于是搭了一个最简的三层网络，用完全相同的超参和数据，分别用框架自带算子和自研算子各跑一遍，把全流程记下来。

**实验设定**
模型骨架是 784 维输入 → 256 单元隐藏 → 10 类输出。优化采用 Adam，学习率 0.001，批大小 128，共迭代 5 轮。MNIST 原图先展平成一维向量再归一化到 0~1，训练集打乱后分批，测试集只做评测。两条路径的网络结构完全一致，唯一差别在于前向时调用的矩阵乘实现。

**流程概述**
训练环借助 GradientTape 实现自动求导，每步先算交叉熵再反向更新，同时累加本轮损失与正确率并计时。评测环只做前向推理，把各批结果取平均得到整体表现。主程序负责数据读取与归一化、Dataset 构建、模型与优化算法初始化，然后按原生路径和自研路径先后完成训练与测试。
