AI 生成实战笔记：从图片到视频再到语音

想快速把大模型接入到自己的脚本里，这套组合拳足够用了。下面的示例分别演示了基于 CogView-3-Plus 的文生图、基于 ZhipuAI CogVideoX 的图文生视频，以及基于 OpenAI TTS 的文本转语音。每一块都可以直接复制运行，环境变量放好 API Key 即可。

一、文生图调用，拿到图片直链
核心思路是封装一个 get_completion，把 prompt、模型和尺寸传进去，返回结果里的第一张图 URL。交互层用 while 循环读取用户描述，空输入跳过，输入 exit 退出，拿到 URL 直接打印。

二、图文生视频，提交任务并轮询结果
先用 dotenv 读入密钥，初始化 ZhipuAI 客户端，模型固定为 cogvideox。封装视频生成接口，支持纯文本描述或配合基础图片。交互先收描述再收图片 URL，至少一项有效才提交。

[PRE2]python

from dotenv import load_dotenv, find_dotenv

_ = load_dotenv(find_dotenv())

from zhipuai import ZhipuAI

client = ZhipuAI()

model = "cogvideox"

[PRE3]python

def get_completion(model="cogvideox",

                   prompt=None,

                   image_url=None):

    response = client.videos.generations(

        model=model,

        prompt=prompt,

        image_url=image_url

    )

    return response

print("===查询任务状态===")

while True:

        id=f"{res.id}"

    )

    if response.task_status == "PROCESSING":

        print("PROCESSING...")

        import time

        time.sleep(30)

        continue

    elif response.task_status == "FAIL":

        print("===任务失败===")

        break

    else:

        print("===任务完成===")

        print(f"视频URL:{response.video_result[0].url}")

        print(f"视频封面:{response.video_result[0].cover_image_url}\n")

        break

三、文本转语音，保存为 MP3
同样先加载环境变量，创建 OpenAI 客户端，模型选用 tts-1。循环读取待转换文字，exit 退出，其余调用 audio.speech.create，语音风格用 alloy，按当前时间戳命名文件并写入本地。

[PRE7]python

from dotenv import load_dotenv, find_dotenv

_ = load_dotenv(find_dotenv())

from openai import OpenAI

client = OpenAI()

model = "tts-1"

[PRE8]python

while True:

    text = input("请输入待转换文本(输入'exit'退出程序): ")

    if text is None or text == "" :

        continue

    elif text.lower() == 'exit':

        print("程序退出。")

        break

    else:

        response = client.audio.speech.create(

            model=model,

            voice="alloy",

            input=text

        )

        from datetime import datetime

        now = datetime.now()

        numeric_date_string = now.strftime("%Y%m%d%H%M%S")

        speech_file_path = f"{cur_path}/{numeric_date_string}.mp3"

        response.write_to_file(speech_file_path)

        response.close()
