03 bool isPrime(int n){
04 if(n<=1){
05 return false;
06 }
07 for(int i=2;i*i<=n;i++){
08 if(n%i==0){
09 return false;
10 }
11 }
12 return true;
13 }
功能：判断 n 是否为素数。
要点：
（1）n<=1 直接判否。
（2）试除只到 sqrt(n)。
（3）发现因子即返回 false。

3. 段二解析
15 int countPrimes(int n){
16 int count=0;
17 for(int i=2;i<=n;i++){
18 if(isPrime(i)){
19 count++;
20 }
21 }
22 return count;
23 }
功能：统计 ≤n 的素数个数。
要点：遍历 2~n，命中即计数。

4. 段三解析
25 int sumPrimes(int n){
26 int sum=0;
27 for(int i=2;i<=n;i++){
28 if(isPrime(i)){
29 sum+=i;
30 }
31 }
32 }
功能：求 ≤n 的素数和。
要点：遍历累加，注意缺少 return sum 会告警。

**【程序解析】**

1. 整体作用
用 DP 求每次最多走一步或两步的最小花费路径和。

2. 段一解析
04 int compute(vector<int> &cost){
05 int n = cost.size();
06 vector<int> dp(n+1, 0);
07 dp[1] = cost[0];
08 for(int i = 2; i <= n; i++){
09 dp[i] = min(dp[i-1], dp[i-2]) + cost[i-1];
10 }
11 return min(dp[n], dp[n-1]);
12 }
核心为 DP。
状态：dp[i] 为到达第 i 级台阶的最小花费。
转移：dp[i]=min(dp[i-1],dp[i-2])+cost[i-1]。
边界：dp[1]=cost[0]，dp[0]=0。

3. 段二解析
13 int main() {
15 int n;
16 cin >> n;
17 vector<int> cost(n);
18 for (int i = 0; i < n; i++){
19 cin >> cost[i];
20 }
21 cout << compute(cost) << endl;
22 return 0;
23 }
读入 n 与花费数组，调用 compute 并输出。

**判断题**

21. cost 为{10,15,20}时，程序输出为 15。（ ）
**【讲解】**
dp[1]=10，dp[2]=15，dp[3]=30，返回 min(30,15)=15，正确。
**【参考答案】**
正确（√）

22. 若把 dp[i-1] 改为 dp[i-3]，程序会编译错误。（ ）
**【讲解】**
当 i<3 时会越界，属于运行时错误，编译阶段检测不到。
**【参考答案】**
错误（×）

23. 程序总是输出 cost 数组的最小元素。（ ）
**【讲解】**
程序求的是路径最小和，不是单元素最小，错误。
