这次的需求是做一个跑在 macOS 上的桌面小工具，技术栈锁定在 Python + Qt。

整体思路很简单：启动程序后，先给它一个主题提示词，它会自动去调 ChatGPT，把结果拉回来变成 Marp 格式的稿子；用户在本地审一下，觉得 OK 之后，直接用 Marp 生成 PDF 交到手上。

界面部分，程序窗口的标题就叫“生成演示文稿”，布局要整洁好看，控件大小和对齐都处理好。

交互区域大概分这几个：

- 提示词输入区。用户在这里填自己的需求。真正发给模型之前，程序会把用户填的内容自动套进固定指令：“你作为顶级的咨询顾问和演示文稿专家，请为用户生成一份 Marp 格式的演示文稿文案，其中配图以 Markdown 格式显示，请使用 Unsplash API，用户的需求为[Prompt]”

- 发送按钮。点一下就把组装好的指令发出，调用 ChatGPT 接口拉取结果。

- Marp 稿件编辑区。用来自模型的 Marp 文案会落到这里，用户可以在线改动、增删。

- 播放演示文稿按钮。点击后把编辑区的内容转成 HTML，再用系统默认浏览器打开，方便预览效果。

- 生成 PDF 格式按钮。点击后基于编辑区的内容调用 Marp 库导出 PDF，文件存到当前工作目录，文件名取自稿件里的演示文稿标题，导出完成后自动打开文件。
