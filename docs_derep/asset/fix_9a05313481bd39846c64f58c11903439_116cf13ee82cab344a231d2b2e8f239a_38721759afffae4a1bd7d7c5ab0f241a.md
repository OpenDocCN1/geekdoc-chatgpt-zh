# DeepSeek冲击波：全球智能竞速白热化

[PRE1]

2025年1月28日，刚完成连任的美国第47任总统特朗普在媒体访谈中点名DeepSeek，称这家来自内地的公司发布的模型应成为本国产业的醒目信号，必须集中力量赢得这场竞争。DeepSeek的出现，让美国科技圈迅速进入高度戒备状态。

一周前，2025年1月21日，特朗普公布“星际之门”智能基础设施投资计划，拟在未来四年内投入5000亿美元用于全新基建，目标是确保在智能赛道保持绝对领先。公开信息显示，该计划由OpenAI、软银、甲骨文三方合资设立的“星际之门”公司执行，OpenAI负责运营，软银负责资金，甲骨文提供关键基础设施。软银创始人孙正义担任董事长，首期资金已达1000亿美元，四年内计划扩展至5000亿美元。项目计划建设20座超大规模算力中心，并在美国创造超10万个新增岗位。

在国家层面布局之外，以谷歌、亚马逊、Meta、微软为首的头部企业早已行动。仅2024年第二季度，这四家的资本性开支合计达528亿美元，同比2023年同期增长近六成。亚马逊财务负责人布莱恩·奥尔萨夫斯基表示，大部分支出用于满足AWS基础设施的持续扩张需求，因为生成式与非生成式工作负载需求强劲。Meta财务负责人李苏珊称，2025年资本支出预计大幅提升，以支撑研发和产品推进。微软财务负责人艾米·胡德则表示，为应对智能与云产品需求，将扩大基础设施投资，2025财年资本支出预计高于2024财年。

## 头部企业掀起巨额投入潮

重金押注并非新事。自2022年底ChatGPT引发技术革命以来，全球资本始终在谨慎评估落地周期与激进抢占制高点之间摇摆。

ChatGPT上线刺痛了巨头神经。2022年11月30日晚，谷歌总部灯火通明，联合创始人拉里·佩奇等被紧急召回。他们意识到，由自家2017年提出的Transformer结构驱动的模型，可能终结搜索时代。随后谷歌仓促推出Bard。

2023年2月6日，谷歌在巴黎发布会上正式推出聊天机器人Bard，对标ChatGPT。但首秀因一次关键失误引发震荡，Bard在介绍詹姆斯·韦伯太空望远镜成果时称其拍摄到首张系外行星照片，实为欧洲南方天文台甚大望远镜2004年的成果。该错误被天体物理学家格兰特·特伦布莱等公开质疑，Alphabet股价当天暴跌7.7%，市值蒸发超1000亿美元，创2022年10月以来最大单日跌幅。

挫败后谷歌以技术纵深加生态重构展开高强度布局。技术迭代上，2023年5月Bard迁移至PaLM 2模型，错误率显著下降并实现更高效的事实核查与实时检索。2024年12月Gemini 2.0发布，支持文本、图像、音频、视频混合输入输出，可处理的令牌数提升至200万，推理能力大幅提升。2025年推出的Gemini 2.0 Flash-Lite在端侧运行与成本效率上取得突破。

硬件层面，TPU v5e芯片量产以更低成本提供更强算力，满足内部需求。与英伟达合作的A3虚拟机将推理成本降低40%，提升实时响应。

资本运作上，谷歌2025年AI资本支出大幅增长并拟新建20座超大算力中心。2025年3月宣布拟以320亿美元收购云安全公司Wiz，加强多云安全竞争力，并加大量子计算投入，目标2026年实现量子计算AI模型的商用。

为对抗OpenAI与微软联盟，谷歌大手笔扶持Anthropic，上演AI版合纵连横。Anthropic由OpenAI前核心成员达里奥·阿莫迪与丹妮拉·阿莫迪兄妹于2021年在旧金山创立，专注AI系统安全性与可控性。DeepSeek浮现前，其Claude大模型被视作最有希望超越OpenAI的编程模型。

技术上，2025年2月发布的Claude 3.7 Sonnet采用混合推理架构，具备跨模态处理能力，借助Claude Code工具链强化代码生成专业性。其主导开发的模型上下文协议MCP已成为行业开源标准，被OpenAI等采用，实现跨平台数据源与AI系统双向连接。

谷歌持有Anthropic 14%股份，并计划2025年度通过可转换债券再注资7.5亿美元，若兑现总投资将超30亿美元。更大的金主是亚马逊，截至2025年4月已承诺投资80亿美元。

亚马逊的布局远不止于此。作为老牌云厂商，其渴望成为AI领域的“卖铲人”，战略是通过全面投入AI为各规模企业提供稳定低成本算力，完成从传统云向智算云转型。2023年4月13日推出的Amazon Bedrock平台让用户可通过API访问AI21 Labs、Anthropic、Stability AI及自家模型，瞄准企业客户，打造不依赖单一初创公司的中立平台。

芯片自研上，亚马逊构建Graviton CPU、Trainium训练芯片、Inferentia推理芯片的三位一体架构，重构通用算力底座、突破训练瓶颈、降低推理成本，形成全栈生态。2024年底集中发布六款Nova系列大模型，覆盖文本生成、多模态、图像与视频生成。

Meta早在2013年成立FAIR研究院，聚焦计算机视觉与自然语言处理并推出DeepSpeech。2017年Transformer提出后迅速跟进，2018年推出基于Transformer的创新模型。2023年2月24日发布Llama 1，提供开放生成式AI平台，参数从7B增至65B，在低资源语言任务中表现突出。随后Llama 2、Llama 3持续开源，意图复制Linux模式。

Meta推动开源生态，PyTorch深度学习框架成为全球研究与商业实践工具，还深化AI伦理、安全与透明度合作。

微软在这轮竞争中位置有利。2019年首投OpenAI 10亿美元并成为其独家云服务商，2023年追加100亿美元，累计获49%利润分成权及董事会观察员席位。2025年软银以75亿美元领投OpenAI新一轮融资，估值飙至3000亿美元，微软持股稀释至约45%。

投资换来OpenAI技术独家授权，整合至Bing与Copilot，尤其GPT-3与Bing结合强化搜索能力。自主技术上，2020年推出170亿参数的Turing-NLG；DeepSpeed优化库提供分布式训练、内存优化与模型压缩；Azure云平台提供认知服务与自定义模型训练部署能力。

马斯克是绕不开的关键人物。曾是OpenAI创立阶段的投资人，后与奥特曼分道扬镳。2025年3月宣布旗下xAI以330亿美元收购X平台，意图整合海量用户数据与分发渠道构建数据驱动AI闭环。截至2025年4月X累计上万亿条推文，日增5亿条。

特斯拉自动驾驶每天通过车载摄像头处理1600亿帧视频画面，马斯克认为这是打造实体机器人所需的现实世界导航数据。xAI于2023年7月成立，半年内发布Grok-1，参数3140亿超GPT-3.5。成立16个月估值突破500亿美元。

2024年仅用100多天在田纳西州建成Colossus超级计算机，集成十万片英伟达H100后扩至二十万片。2025年2月Grok-3发布，引入图像分析与问答，基于约20万GPU数据中心训练，算力为Grok-2的10倍，被马斯克称作“地球上最聪明、最求真的人工智能”。

xAI优势在于可获取马斯克旗下企业专有数据，以及更激进的内容策略：Grok仅过滤色情内容，允许政治敏感信息生成，截至2024年11月付费用户达64万。

总体看，美方动辄百亿美元投入覆盖芯片、模型研发、资本并购、生态联盟与开源战略，将竞争推向算力、数据、场景的全维度争夺。

## 内地走效率与场景并重的路线

内地作为世界第二算力大国，其AI产业同样蓬勃。与美国做法不同，内地企业在政策引导与市场需求驱动下走出“开源共享加场景深耕”路径。

技术路线上，美国企业倾向不计成本追求规模，如OpenAI研发GPT-5万亿级参数架构、微软Sora实现文生视频。内地企业更重效率优化，通过模型压缩、异构算力调度在算力受限条件下突破性能。

应用落地强调场景为王。百度依托搜索优势将文心一言嵌入生态，日均调用超百亿次；阿里巴巴通义千问以“工具箱”拆解为文档解析、视频生成等细分工具；字节跳动借助抖音、今日头条流量矩阵将豆包模型渗透至3000万用户，实现规模化应用，使AI在电商、物流、城市管理等领域形成独特优势。

百度布局早于业界。文心一言4.0 Turbo支持128K上下文窗口，可处理300页文档级长文本，在代码生成与多模态交互表现突出。依托Apollo自动驾驶平台与飞桨深度学习框架，构建模型训练—场景应用—数据反哺闭环。

技术突破源于知识增强探索。早期ERNIE系列并行训练海量文本与知识图谱，中文理解超越谷歌模型BERT。2021年发布的鹏城—百度·文心ERNIE 3.0 Titan以2600亿参数成为当年全球最大中文单体模型，首创在线蒸馏框架显著降低落地成本。2023年文心一言整合检索增强与对话增强技术，实现多轮流畅交互，在文学创作与代码生成展现领先能力。
