### 8.1.2 LangChain 应用开发框架概览

LangChain 由 LangChain AI 公司推出，是面向大语言模型驱动应用的开源框架。其核心理念是通过一套标准化、结构化的模块抽象，对大模型的输入输出进行统一规范，进而构建可组合、可插拔的开发流程。框架以 Chain 为核心，强调用链式方式组织模型调用、上下文管理、工具执行、内容解析等操作，帮助开发者高效搭建从数据输入到智能响应的完整路径。

本质上，LangChain 从大模型能力出发，结合实践经验和典型任务，对模型的涌现能力进行高级抽象，并通过统一接口适配多种底层模型服务，形成一套通用的大模型开发范式。

目前 LangChain 已演进为通用性很强的大模型应用开发框架，其模块设计既体现了对 LLM 的深刻理解，也在标准化 Agent 开发中发挥关键作用。核心模块如图 8.4 所示。

[PRE16]

图 8.4 LangChain 核心模块

##### 1. Prompt

Prompt 是大模型应用的起点。LangChain 通过 PromptTemplate 提供标准化的提示模板定义方式。开发者可自定义输入变量，为模型提供精确背景与任务说明；同时模板支持变量插值、输入校验与复用，可通过参数填充生成动态提示。

##### 2. Models

Models 模块封装了主流大语言模型并提供统一调用接口。配置好模型信息后即可在不改动整体逻辑的前提下自由切换底层模型。

##### 3. Output Parser

大模型通常输出自然语言，而工程实践常需要特定格式如 JSON、列表、表格或代码块。Output Parser 模块用于解决此问题，内置字符串解析器、列表提取器、Pydantic 格式校验器等，帮助规范每一步输出并提升链式调用的鲁棒性。

##### 4. Memory

Memory 模块是对话场景下实现多轮上下文记忆的关键，区分短期与长期记忆，支持对用户历史输入和模型输出的存储与复用。

##### 5. Callbacks

Callbacks 提供事件监听机制，可对模型调用链路的每个环节进行监控、调试和可视化，支持日志输出到终端或文件，甚至接入可观测性平台，实现全链路追踪。

##### 6. RAG

LangChain 对 RAG 做了深度封装，覆盖 Retriever 构建、向量数据库接口如 Chroma、FAISS、Milvus 的集成，以及上下文压缩与匹配度过滤等组件，开发者可按需组合快速构建语义检索增强生成链。

##### 7. Agent

Agent 模块是实现复杂任务自动执行的核心引擎，允许大模型作为工具调用者动态决定是否调用外部工具、API 或其他链。LangChain 提供多种内置 Agent 类型，支持复杂流程的自动拆解与执行。

在 LangChain 中，七大核心模块如同积木，各自职责明确又可灵活组合。正如图 8.4 所示，既能实现基础问答，也能构建具备上下文记忆、知识增强、结构化输出与多工具协同的高级 Agent 系统。

### 8.1.3 LangChain 高阶 RAG 构建实践

在 BiliAgent 的数据分析场景中，需要借助 LangChain 完成大模型接入与 RAG 流程搭建，实现多阶段任务处理与智能化分析。整体过程类似搭积木，每个模块都是 Agent 系统运行的基础。

如图 8.5 所示，RAG 的工作逻辑是把用户查询作为检索器的输入，在持久化构建的知识库 Knowledge 中快速定位高度相关的信息片段，再将检索结果作为上下文注入大语言模型 Prompt，引导模型生成更准确、更相关的响应。
