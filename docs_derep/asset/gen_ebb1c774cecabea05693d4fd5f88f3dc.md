### 3. 持续打磨，沉淀长期价值

智能体上线后只是开始，必须持续进化，结合真实数据与用户反馈不断完善。

- (1) 闭环数据：把上线后的交互记录、用户新提问、未解决的咨询等沉淀下来，用于刷新训练集和知识库。
- (2) 模型升级：按固定节奏用新增数据做微调训练，比如每周一次，以提升回答准确率。
- (3) 功能扩容：根据用户真实诉求迭代新能力，例如为客服类智能体增加“语音转文字”。

## 7.4 本章要点回顾

从需求到交付，智能体开发本质是“需求牵引→方案落地→验证测试→持续部署”的闭环。关键抓手有三：

- (1) 需求阶段要定义精准，避免开发跑偏。
- (2) 设计与开发坚持模块化、协同化，提升效率与可维护性。
- (3) 测试与部署必须全场景覆盖，确保在真实环境中稳定可用。

对话型、自主决策型等不同品类的智能体，细节会有差异，但底层逻辑一致：始终围绕解决实际问题，兼顾技术可行性与用户价值。

# 第8章 LangChain驱动的智能体实战

LangChain 是面向大模型应用的开源脚手架，核心是通过模块化组件和统一接口，把基于 LLM 的复杂系统搭建变得更简单。基于它的智能体，则是具备自主判断与任务执行能力的系统，能像人一样思考“如何完成任务”，并通过工具调用、记忆管理、分步规划来实现目标，大幅拓展了 LLM 的实用边界。

当前，用 LangChain 构建具备自主规划、工具调用、多轮推理能力的 AI 应用已成主流。本章聚焦 LangChain 智能体的核心概念与开发思路。

## 8.1 LangChain 是什么

LangChain 专门用于搭建以语言模型为核心的应用，尤其擅长智能体类系统的构建。

### 8.1.1 全局架构拆解

LangChain 提供了一套工具和接口，让开发者更快地构建与大模型交互的应用。整体生态可归纳为“三层主体结构加一个配套平台”，包括架构层、组件层、部署层、辅助平台。

#### 1. 底座架构

- (1) LangChain Core：封装 Chain、Prompt、Memory、Tool 等基础抽象，便于快速拼装 LLM 应用。
- (2) LangGraph：基于“图”的状态机引擎，支持循环、分支、子流程等复杂编排。

#### 2. 组件层

- (1) Integrations：官方与社区维护的模型、工具、向量库插件集合，如 OpenAI、Anthropic、Pinecone、Google Search 等。
- (2) langchain-community：第三方扩展包的集市。

#### 3. 部署层

LangGraph Platform 为商业化托管服务，提供工作流托管、UI 管理、运行监控、API 网关等企业级能力。

#### 4. 赋能平台

LangSmith 覆盖开发、测试、上线、监控全生命周期，是面向 LLM 的 Ops 平台，可视化追踪每一步 Chain 与 Agent 的执行。

### 8.1.2 核心模块概览

### 8.1.3 典型应用方向

LangChain 通过模块化设计简化了与大模型的交互，以下是常见落地场景。

#### 1. 智能问答系统（QA）

基于专属知识库作答，减少幻觉，适用于企业文档、知识库查询等场景。

##### 1）落地思路

通过“文档加载→文本分割→嵌入向量→存入向量库”的流程，把知识转为可检索向量。用户提问时先检索相关片段，再由 LLM 基于片段生成答案。

##### 2）示例

- (1) 企业内部：员工查询公司规章、产品手册，如接入 Confluence 文档。
- (2) 客服领域：自动回复关于产品功能、售后政策的问题，可结合客服历史对话库。

#### 2. 聊天机器人

构建具备上下文理解、多轮对话能力的聊天机器人，支持个性化交互。

##### 1) 核心能力

- (1) 维护对话历史，通过 ConversationBufferMemory 等组件保存上下文。
- (2) 结合外部工具，如查询实时天气、完成预订等。

##### 2) 示例

- (1) 电商客服机器人：基于用户历史订单推荐商品，解答物流问题，连接订单数据库。
- (2) 教育助手：辅导学生做题，结合教材内容解释知识点，检索教材向量库。

#### 3. 数据处理与分析

让 LLM 与结构化/非结构化数据交互，实现抽取、分析、可视化。

- (1) 数据提取：从 PDF 合同中自动提取甲方、乙方、金额等关键信息，结合 UnstructuredFileLoader 与 LLM 解析。
- (2) SQL 生成与查询：用户用自然语言提问，LangChain 转为 SQL 查询数据库后返回结果，通过 SQLDatabaseChain 实现。
- (3) 数据分析报告：基于 Excel 表格，让 LLM 生成趋势分析、异常说明，连接 Pandas 数据框。

#### 4. 自动化工作流

构建具备自主决策能力的智能代理，自动规划步骤并调用工具完成复杂任务。

##### 1) 工作原理

Agent 根据用户目标判断是否调用工具，如搜索引擎、计算器、API，并根据返回结果调整下一步，直至完成任务。

##### 2) 示例

- (1) 旅行规划：输入“北京到上海三天行程”，Agent 依次调用航班查询 API、酒店预订接口、景点推荐库，生成完整行程。
- (2) 市场调研：自动搜索行业最新报告与统计数据，汇总生成分析简报。

#### 5. 文档生成与自动化写作

批量生成结构化文档，或基于模板和数据自动填充内容。

##### 1）实现方式

结合 LLM 的文本生成能力与 PromptTemplate，输入变量后生成定制化内容。

##### 2）示例

- (1) 周报/月报自动生成：从业务系统提取销售、用户增长等数据，按固定格式生成报告，搭配 jinja2 模板。
- (2) 法律文书生成：输入合同双方信息与条款细节，自动生成符合规范的合同文本。

#### 6. 代码开发辅助

辅助开发者编写、解释、调试代码，或连接代码库实现自动化任务。

- (1) 生成代码：根据自然语言需求生成代码片段。
- (2) 代码解释：解析复杂函数或框架逻辑。
- (3) 自动化部署：通过 Tool 组件调用云服务 API，实现代码部署、容器管理等操作。

#### 7. 多模态应用（文本+图像/语音）

结合图像、语音等模态数据，扩展 LLM 处理能力。

- (1) 图像分析：用户上传图片，调用图像识别 API 生成描述，再由 LLM 基于描述回答问题。
- (2) 语音交互：将用户语音转为文本处理，再将答案转为语音输出，连接 TTS 工具。

LangChain 的核心价值是“连接 LLM 与外部世界”，通过 Chains、Agents、Memory、Tools 等模块化组件降低开发门槛，让大模型从通用对话升级为可解决实际问题的工具，覆盖客服、教育、企业办公、开发等多个领域。

import os

# 设置镜像和缓存路径

os.environ['MODELSCOPE_MIRROR'] = 'https://www.modelscope.cn'

# 创建提示模板

prompt = PromptTemplate(

    input_variables=["topic"],

    template="请简要解释一下{topic}的基本概念。"

)

formatted_prompt = prompt.format(topic="量子计算")

print(formatted_prompt)

try:

    # 尝试初始化模型

    model_id = "qwen/Qwen3-1.7B"

    tokenizer = AutoTokenizer.from_pretrained(model_id, trust_remote_code=True)

    model = AutoModelForCausalLM.from_pretrained(model_id, device_map="auto", trust_remote_code=True)

    # 生成回答

    inputs = tokenizer(formatted_prompt, return_tensors="pt").to("cuda")

    outputs = model.generate(**inputs, max_new_tokens=200)

    response = tokenizer.decode(outputs[0], skip_special_tokens=True)

    print(response)

except Exception as e:

    print(f"加载模型时出错: {e}")

    print("请检查网络连接或尝试使用离线模式")
