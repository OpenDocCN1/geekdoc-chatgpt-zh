客户行为风险速筛示例
请以银行客情经理身份，依据所给交易流水，归纳其日常操作特征，揪出潜在风险点，并以清单呈现：行为类别、出现频次、风险等级、应对建议。

三、晚间实战
1. 用 Prompt 完成今日真实工作
挑一个正在处理的真事，用提问模板驱动完成。
• 文案类：起草邀请函/撰写周报。
• 资料类：审阅合同/提炼会议纪要。
• 分析类：输出季度销售分析/做客户分群。

交付物要求
• 一段可直接使用的模型生成成果。
• 与手工对比在效率、准确度上的提升点。
• 归纳一条可复用的「Prompt 使用心得」。

2. 小结：从新手到高频使用者
高频不等于高产，关键在于准、快、稳。
• 准：结构清晰、角色明确、指令具体。
• 快：即取即用、快速验证、马上落地。
• 稳：可沉淀为团队共享的 Prompt 库。

从现在起，让模型真正进入日常，成为你的第二大脑。

### 第五节 Day5 复杂事项的链式提问拆解（中级）

今日目标
学会把难题分解成模型能逐步执行的指令，提升多轮协作与递进推理能力。

一、清晨一学
工作里常遇到：
• 事项太繁，单次提问答不全。
• 涉及多环节或多角色，模型易跳步或顺序错乱。
• 需要边想边调，但模型习惯直接给结论。

根源是：提问太平面，而复杂事项需要链式结构。

（一）复杂事项的本质
1. 什么是复杂事项
并非所有工作都能用一句指令搞定。当事项同时具备以下特征，就进入复杂区间：
• 多阶段性：包含若干流程节点或阶段性交付物，单条指令覆盖不完。
• 多要素协同：牵涉不同维度、角色或信息整合，容易让输出混乱。
• 多标准判断：存在多重评估维度或策略性抉择，模型易默认处理。

2. 拆解视角：复杂事项=三重认知负荷
• 理解负荷：要读懂业务背景、目标与边界。
• 推理负荷：要处理多变量、排序优先级、找路径。
• 表达负荷：要统一格式、说明步骤、输出复合结构。

所以模型并非不行，是指令太粗糙。

（二）Prompt 链条设计
1. 什么是链条设计
把一个复杂事项按其自然的认知与执行顺序，拆成若干小步，每步配一条目的明确、结构清晰的提问，引导模型逐步推进，最终形成一条可控的协作路径。简单说，就是不要一次说完，而是手把手带它走。

2. 为何要做链条
大模型擅长逐步推理，而非一步跳到终点。事项一旦多步或多条件，单一提问很容易：
• 跳步、误解、遗漏关键信息。
• 输出松散、结构不清、难以复核。

链条的价值：
• 降低单次认知负担，提升准确率。
• 强化逻辑顺序，按因果节奏生成。
• 形成执行闭环，每环产出可检验。

三种常用形态
• 线性链条：按序递进，环环相扣；适用于计划制定、流程优化。
• 分支链条：先多视角分析再汇总；适用于竞品对比、风险评估。
• 闭环链条：结果回流驱动下一步；适用于产品迭代、内容打磨。

3. 案例：节日营销方案设计
原始指令：帮我设计一个节日营销活动方案。
常见问题：你是营销专家，请设计圣诞节营销活动，易得泛泛建议，缺乏节奏与落地性。
链式拆解示例
• 洞察基调：请概括圣诞期间电商用户行为特征与核心心理动机，列出五点。
• 节奏框架：基于上述洞察，设计预热-爆发-延续三阶段目标，并给出每阶段核心指标。
• 玩法设计：为每个阶段设计一个互动创意，如游戏、打卡、直播话题。
• 执行排期：列出日历式投放表，含每日主题、渠道、话术要点。
• 优化闭环：设计反馈收集与策略迭代机制，确保活动期可动态调整。
从洞察→节奏→创意→排期→优化，完整覆盖全链路。

4. 链条设计模板
事项目标：____________________
步骤拆分 建议 3-5 步：
第一步，解决什么问题？
提问示例：请先……，输出格式为……，注意……
第二步，聚焦哪个维度？
提问示例：基于上一步结果，请进一步……
第三步，整合/判断/优化？
提问示例：将前述结果进行……，请给出……
最终产出：__________（格式说明+使用场景）

常见适用场景
• 产品经理：需求调研、PRD 编写、用户流程设计。
• 人力资源：能力模型搭建、培训项目规划。
• 市场营销：活动策划、内容节奏管理。
• 销售支持：客户画像、方案推荐策略。
• 运营管理：流程再造、SOP 优化、满意度调研。

5. 小结：Prompt 链条是 AI 时代的认知结构力
掌握链条设计，模型不再只是干活的，而是：
• 按你的思路分阶段执行。
• 按你的逻辑结构化反馈。
• 按你的标准自我迭代。

二、午间一练
为新品制定完整市场进入方案
按序练习：
• 变量梳理：请列出影响新品进入市场的五大关键要素，含政策、竞品、用户偏好等。
• 竞品拆解：对主要竞争对手做优势短板分析，输出 SWOT 表。
• 策略生成：据此设计三种进入路径并说明适用场景。
• 行动计划：假设你是市场负责人，择一策略制定 30 天推进表。

三、晚间一用
挑一个真实复杂事项，用链式提问完成模型协同。
可替换示例
• 客户尽调流程。
• 内部审计报告撰写。
• 跨部门项目计划。
• 年度培训体系设计。
操作流程
1）明确终极目标，如完成一份可执行的培训方案。
2）拆解路径，如需求收集→能力模型匹配→课程设计→执行节奏。
3）为每步写提问，如请罗列销售岗位核心能力模型。
4）依次运行并迭代完善。
5）归档每步结果，形成结构化协作文档。
最终成果
完整事项→拆解后的提问链→模型生成内容→可复用的执行模板
让模型干活的关键，不只是说做什么，更是教它怎么做。

### 第六节 Day6 用 Prompt 驱动业务创新（高级）

今日目标
学会构造突破常规的提问，释放模型在流程再造与创意生成中的潜力。

一、清晨一学
组织里真正值钱的应用，是重构创新场景。Prompt 是与模型的思维接口，提问方式决定创新高度。下面三种策略帮助打破思维边界。

（一）跨界迁移式 Prompt
1. 什么是跨界迁移
借助类比与概念映射，把某个行业成熟的方法、模型或角色搬到当前业务问题上，引导模型以全新视角分析、推理、构思。
本质是用熟悉领域的逻辑启发陌生问题的解法。
2. 为何有效
• 打破路径依赖，跳出行业惯性。
• 激活模型跨学科联想能力。
• 比喻换角色，瞬间打开新维度。
3. 常用提问方式
• 角色迁移：假设你是一名电影导演，如何讲述客户旅程？
• 方法迁移：用 SWOT 分析员工情绪管理的关键变量。
• 场景迁移：如果这是场篮球赛，产品经理该负责哪一环？
• 结构迁移：借鉴交响乐团编排，重新设计团队协同机制。
4. 结构模板
你是一位[跨界角色]，请把当前问题类比为[跨界场景/模型]。从[特定维度]分析，输出[目标类型]内容。

（二）逆向工程式 Prompt
1. 什么是逆向工程提问
从期望结果倒推实现路径，引导模型逐步分解事项。适用于拆解复杂事项、定位创意关键路径、优化流程。
2. 为何高效
• 结果导向，避免无效探索。
• 逻辑清晰，呈因果或步骤链。
• 与模型结构化输出优势契合。
3. 三步构造法
• 明确结果：客户满意度 30 天内提升 20%。
• 定义约束：预算≤1 万元，人力不变。
• 反向推理：请倒推 5 个必须执行的动作。
4. 结构模板
我们希望达成[具体成果]，在[时间/成本/资源限制]下。请从目标倒推[步骤/策略/关键动作]，并说明作用与优先级。
常见场景关键词
• 流程优化：缩短时长、降本增效。
• 增长营销：用户数、转化率提升。
• 项目设计：按期交付、上线。
• 人才发展：能力达标、上岗。

（三）限制诱发式 Prompt
1. 什么是限制诱发
在任务中人为设限，迫使模型跳出模板，产生突破性解法。
2. 为何有效
限制是创意的燃料。设限可排除常规解法、强化聚焦、激发组合创新。
3. 常见限制
• 资源限制：预算 1000 元、2 人团队、无付费工具。
• 时间限制：24 小时内、每步 5 分钟。
• 工具限制：不用 Excel/PPT/广告投放。
• 路径限制：禁用常规方法、不主动销售。
• 用户限制：面向新手、下沉市场、60 岁以上。
4. 结构模板
在达成[目标]前提下，满足以下限制[资源/时间/方式/工具/用户]，设计一套[方案/流程/策略]，并说明应对思路。

二、午间一练
自选业务场景，各写一条创新提问
• 跨界迁移：用电影导演视角设计客户旅程。
• 逆向工程：倒推出提升复购率的 5 个非营销动作。
• 限制诱发：零广告费，3 天内让新品曝光破千。

三、晚间一用
重构部门流程，建立创新提问链
第一步，选痛点：如客服响应慢、销售跟进不统一、项目推进慢。
第二步，建链条：
• 诊断：请从运营视角分析当前客服流程的瓶颈。
• 创新方案：若引入 AI 自动客服，设计兼顾快速响应、满意度与降本的流程。
• 风险评估：模拟落地后的潜在风险及应对预案。
第三步，记录反馈，试运行并沉淀为创新微流程。

### 第七节 Day7 专业领域复杂问题的系统化解决（高级）

今日目标
让 Prompt 专业化、系统化，实现模型与行业知识与组织业务深度融合。

一、清晨一学
（一）专业化 Prompt 的四个特征
1. 明确角色定位
设定专家身份，切换推理视角与语言风格。
案例：你是一名精通劳动法的企业法务顾问，请审阅该离职协议，指出违反《劳动合同法》的条款并引用法条。
2. 专业术语嵌入
用行业词汇提高召回精度，减少理解偏差。
案例：作为会计师，请分析流动比率、应收账款周转率、EBITDA 的变化，并判断短期偿债能力。
3. 背景情境设定
补充行业、市场、时间、法规等锚点。
案例：你是一名快消品市场顾问，基于 2025 年中国一线城市消费者数据，结合京东、拼多多活动，提出提升线上转化的三条策略。
4. 输出结构规范
明确格式与标准，提升可操作性。
小结：专业化 = 角色设定 + 术语嵌入 + 背景锚定 + 结构规范

（二）系统化管理的三要素
1. 统一格式
把提问做成可复用模板：角色、背景、任务、输出要求。
2. 版本管理
记录演进与优化，利于追溯与协作。
规范示例
场景：法务合同审核
V1：你是法务，请指出不合理条款。
V2：你是劳动法专家，请依据《中华人民共和国劳动合同法》第三章评估……
通过标准化与版本化，Prompt 才能真正成为组织的数字资产。
