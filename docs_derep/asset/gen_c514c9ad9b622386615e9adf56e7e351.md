# 医疗GPT：诊疗变革的下一张牌
# 本书脉络
依托海量信息整合与接近人本的认知框架，GPT正成为医疗场景的理想搭档。从智能问诊到个体化方案，医疗GPT的改变既宽泛又深刻，贯穿了从判断到干预的完整链路。

本书以ChatGPT引爆为时间锚点，以医疗GPT的落地进程为主线，在梳理AI基础技术的基础上，拆解大模型对医疗生态的冲击。覆盖医院形态再造、健康管理升级、药物研发提速、中医现代化、医学教育转型等公众关切议题，并探讨技术扩张带来的伦理与管理挑战，对下一阶段走向作出前瞻。本书想做的，是帮助读者从信息噪音里提炼出医疗变局的核心线索。

# 写在前面
2016年，AlphaGo战胜李世石，让AI从实验室走向公共视野。2022年，ChatGPT一夜爆红，以类人级的“懂事”成为现象级应用，把人工智能推向真实场景。马斯克称我们正接近“危险的强AI”，比尔·盖茨则把ChatGPT的重要性比作互联网诞生。

AI已渗入社交、电商、金融、自动驾驶。医疗更是避不开的主战场。今天，人口老龄化与健康消费升级共同推高支出。需求体量庞大，且呈现多元、分层、个性、动态的特征。供给端在总量上勉强跟进，在结构上错位严重，优质资源向大城市三甲集中，基层薄弱，分配失衡。

在这一矛盾下，以AI驱动价值医疗、优化资源配置成为行业共识。AI正推动卫生体系走向以人为本的整合服务，追求“随时可及的医疗”“全周期关怀”“精准干预”。服务逻辑也在从基础功能满足转向个性化、智能化的体验提升。

GPT类大模型的出现，让AI与医疗的融合加速升温。关键在于ChatGPT的走红及API开放，真正打开了通用人工智能的大门。按能否多任务执行衡量，ChatGPT已具备通用属性，能回答各类问题、跨场景应用，支持问答、对话、生成等多种形态。API的开放让通用模型成为可复用的底层设施，也让医疗专业知识的快速学习与规模化应用成为现实。

医院将是医疗GPT渗透最深的场景之一。大模型将重塑运行流程，提升诊疗质量与效率。

本书试图从技术大背景出发，观照医疗GPT的未来。以ChatGPT爆发为起点，围绕医疗GPT的发展与应用展开，在介绍相关技术后，细致分析其对医院、健康管理、药物研发、中医、医学教育等领域的冲击。并直面未来可能带来的挑战与风险，作出展望。文字力求通俗、有趣、循序渐进，帮助读者看清ChatGPT浪潮对医疗行业的改写，并在复杂信息中抓住变革主线。

十年间AI改写了生活方式，未来十年，医疗或将上演同样剧烈的图景。

# 现实篇
# 第1章
## AI与医疗的交汇
### 1.1 人工智能加医疗是什么
AI概念提出至今近七十年，经历热与冷的周期。近几年进入爆发期，成为经济转型的核心引擎。医疗领域正从多点试用到系统融合，新业态不断涌现。如今AI已遍布诊疗各环节，形成全球共识：AI以独特方式守护健康福祉，而这段关系始于早期探索。

#### 1.1.1 海外医疗AI的起步
上世纪70年代，海外医疗AI探索开启。1972年利兹大学的AAPHelp能据症状推断剧烈腹痛原因。1974年匹兹堡大学推出INTERNIST-I用于内科疑难辅助诊断。1976年斯坦福的MYCIN可识别感染并给出抗生素建议，内部约500条规则，按问答流程自动判别菌种与用药。当年同期的还有斯坦福的ONCOCIN、MIT的PIP与ABEL、罗格斯的CASNET/Glaucoma等。

80年代进入商业化萌芽期，QMR、DXplain等系统开始依据临床表现给出诊断思路。90年代计算机辅助诊断CAD成熟，乳腺X线CAD成为影像辅助的代表。

进入21世纪，IBM Watson成为标志。数秒内可筛查数十年150万份癌症记录，给出循证方案。前三名癌症中心均已使用，中国亦引入。2016年后，美国、加拿大、日本、英国、欧盟、印度、韩国、俄罗斯等密集发布AI战略。美国提出人机协作医疗诊断，日本以医疗健康护理为突破口应对老龄化，英国聚焦辅助诊断、传染病预防追踪、影像诊断三大方向。

2016年2月DeepMind成立DeepMind Health，与NHS合作用于决策支持，并参与头颈癌放疗设计和Moorfields眼科的视力疾病早期筛查项目。2021年Google Health出现人事动荡，负责人David Feinberg离职加盟Cerner，Google随后解散Google Health。

#### 1.1.2 中国医疗AI的发展轨迹
中国80年代初起步，虽晚于发达国家但发展迅猛。1978年北京中医医院关幼波教授与计算机专家合作研发“关幼波肝病诊疗程序”，首次把专家系统引入中医。此后出现“中国中医治疗专家系统”“林如高骨伤计算机诊疗系统”等中医辅助产品。

21世纪后，细分领域快速铺开。2016年10月百度发布“医疗大脑”，对标谷歌与IBM，通过文献与数据模拟问诊给出建议。2018年推出“百度灵医”，后更名“灵医智惠”，涵盖临床决策支持、大数据方案、眼底影像分析、智能诊前助手等。

2017年7月阿里健康上线“Doctor You”，含科研诊断平台与辅助检测引擎，并与多方合作打造糖尿病、肺癌预测、眼底筛查等智能引擎。2018年9月阿里云与阿里健康发布“ET医疗大脑”2.0。

2018年11月腾讯牵头国家重点研发计划“数字诊疗装备研发专项”，以AI+CDSS探索服务升级。

新冠期间，AI在公共卫生发挥作用：传染病大数据预警、排查系统、智能测温与消毒机器人、语音服务机器人等广泛应用。疫情成为数字技术试金石，AI的价值得到验证。

### 1.2 为何AI锁定医疗
#### 1.2.1 供需的结构性失衡
需求端，长期工业化带来环境压力叠加人口老龄化，慢病人群扩大。第七次全国人口普查显示60岁及以上人口2.64亿，占18.70%。预计2035年前后老龄人口超四分之一，2050年前后超三分之一。中国是全球老龄人口最多、老龄化最快国家，东北老龄化尤甚。

慢病已成主力。我国确诊慢病人群超3亿，患病率年增5.8%。2011-2021年糖尿病患者从9000万增至1.4亿，约占人口十分之一，其中51.7%未被诊断。65岁以上人群慢病患病率达78.4%，是整体的3.2倍。慢病占健康年损失77%、死亡原因85%、疾病负担超60%。

结构性需求也在上升：预防、监测、养生、临终关怀等。体检覆盖率与美日德超70%相比仍有空间，AI可让健康管理可视、可控。

供给端，优质医生与资源不足且分布不均。我国医生与人口比约1:343，西方约1:280。影像、病理、全科尤其短缺。影像数据年增30%，影像医生年增仅4.1%，病理科缺口10万人。全科医生约30万，占7.37%，远低于德法日超20%、美国超12%。医生培养周期长达8年，人力成本高。

分布上，2018年医院超3.2万家，三级医院仅占19%却承接49.8%需求，长期超负荷。结构错配导致效率低、误诊风险高、体验差。AI在培养与技术提升上具备改善潜力。

#### 1.2.2 技术三驾马车的突破
算法、算力、数据构成AI底座。

1. 算法层面
超大规模预训练模型是近两年焦点。自OpenAI 2020年推出GPT-3后，谷歌、华为、智源、中科院、阿里等推出Switch Transformer、DALL·E、MT-NLG、盘古、悟道2.0、紫东太初、M6等模型，不断刷新纪录。深度学习驱动语音与视觉进步，ResNet等结构推动医学影像分析在诊疗中作用增强，如结肠镜AI降低结肠癌死亡率，外科三维建模辅助神经外科。AI对海量数据分析能力让研究从定理推导转向高维发现，加速进程。2020年DeepMind的AlphaFold2在CASP竞赛中胜出，蛋白质三维结构预测精度媲美冷冻电镜。

2. 算力层面
算力持续攀升，训练与推理芯片快速迭代。OpenAI数据显示模型训练算量增速远超硬件，存在数量级差距。推理需求因泛在化持续增长。类脑芯片、存内计算、量子计算等新架构在探索期。

3. 数据层面
深度学习需大量标注数据，催生精细化数据服务。IDC测算2025年全球数据规模将达163ZB，其中80-90%为非结构化。百度、阿里、京东等提供场景定制数据服务，需求从通用转向个性化复杂。

中国人口基数大、数据多样，为训练提供土壤。但医疗信息化普及不足制约产业化。美国虽人口基数小，但医疗数据化、标准化程度高，更易训练高准确性模型。

#### 1.2.3 政策的推动作用
近年国家密集出台全国性与专项政策，鼓励“人工智能+医疗”。在政策引导下，产业有望迎来实质性变革。
