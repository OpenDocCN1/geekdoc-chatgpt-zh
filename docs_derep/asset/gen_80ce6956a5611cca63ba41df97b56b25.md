各参数含义如下。

- python convert.py：调用 convert.py 脚本，将 Hugging Face 格式权重转为特定推理格式。
- --hf-ckpt-path /path/to/DeepSeek-R1：指定 Hugging Face 格式的模型检查点路径，即模型文件位置，示例为 /path/to/DeepSeek-R1。
- --save-path /path/to/DeepSeek-R1-Demo：指定转换后权重保存路径。
- --n-experts 256：指定模型专家数量，与 MoE 分布式相关，设为 256 表示使用 256 个专家。

各参数含义如下。

- torchrun：用于分布式训练或推理的启动器，可跨多个节点运行多个进程。
- --nnodes 2：指定集群节点数，示例中使用两台机器。
- --nproc-per-node 8: 每个节点启动的进程数，每个节点 8 个进程以充分利用多 GPU。

- --master-addr $ADDR: 指定主节点地址，主节点负责协调，其余节点受其调度。$ADDR 为环境变量表示主节点 IP 或主机名。
