# 软件篇 用 MicroPython 打开智能开发的大门

## 项目一 MicroPython 是什么

### 第一节 MicroPython 概述

`MicroPython` 是 Python 3 的精简高效实现，包含部分标准库并针对微控制器优化。通俗说它就是“微型 Python”，也称“精简版 Python”。基于 ANSI C，语法与 Python3 保持一致。借助 `MicroPython`，用户可用 Python 脚本直接访问硬件底层，如点亮 LED、驱动 LCD、读取电压、控制电机、读写 SD 卡、操作摄像头等。

### 第二节 支持 MicroPython 的开发板

`MicroPython` 发布后备受关注，适配板型迅速增多。主流有 Pyboard、Micro：bit、`ESP8266`、`STM32` 等。

随着普及，国内厂商参照开源 Pyboard 研发国产板型。目前最流行的是 TPYBoard。`TPYBoard` 与 Pyboard 功能相近，均采用 `STM32` 作 MCU，即控制器也称单片机，板载 4 个 LED 与一个加速度传感器。现已衍生出多个版本，包括 `STM32` 标准版、基于 LAN 的有线版、基于 `ESP8266` 的无线版。

### 第三节 智能开发的概念

### 活动一：智能设备构成

智能设备大致由两部分构成：

一是机械结构系统。例如行走机器人，机械部分包含驱动轮、手臂、摄像头、扬声器等，每个部件都是独立机械单元。底座若无行走机构则无法移动，手臂若无伸缩结构则无法像人一样操作。机械结构是智能设备的根基。

二是智能控制系统。机械结构配合传感器即具备感知能力，将感知数据回传给微处理器，处理器据此分析后指挥执行系统做出相应动作。

### 活动二：智能控制系统

智能控制系统由三大部分构成（图 2-1-4）。控制系统：相当于大脑，负责思考。传感器系统：相当于眼耳舌皮肤，负责感知。执行系统：相当于手脚，负责行动。

[PRE20]

图 2-1-4　智能控制系统数据传输

#### （1）微控制器

控制系统是智能设备的“大脑”，如同微型电脑，可执行程序指令并向执行机构发出动作信息。智能设备的控制模块通常拥有多个输入输出接口，用来接收外界信息后再下发指令给机械部件。

前面介绍的 `MicroPython TPYBoard` 即为微处理器，俗称单片机。单片机是一种集成电路芯片，已广泛渗透到生活各领域：导弹导航、飞机仪表控制、计算机网络通信与数据传输、工业自动化实时控制与数据处理、各类智能 IC 卡、豪华轿车安全系统、录像机摄像机全自动洗衣机的控制、程控玩具电子宠物等都离不开它。

#### （2）传感器系统

真正的智能设备通常都具备一定的感知能力，能感应并把信息传递给控制器的电子器件称为传感器。类比人体感觉器官，智能设备的电子传感器按功能分类。例如光源传感器、声音传感器、气体烟雾煤气传感器、压力传感器、温度传感器等。它们的灵敏度与感应范围甚至超越人，例如电子指南针、红外传感器等。

#### （3）执行系统

正如人体的骨骼和肌肉配合才能完成动作，机器人的动作表现也由特定的机械结构实现。

### 第二节　MicroPython 程序编辑器介绍

编辑器是用于修改电脑文件的软件，常见类型有文本编辑器、网页编辑器、源程序编辑器、图像编辑器、声音编辑器和视频编辑器等。

编译器通常接收由各类编辑器生成的源程序，并与编辑器及其他程序集成到交互式开发环境`IDE`中。这类编辑器称为结构化编辑器，已内置编译器的部分功能，因此错误可在编写阶段即被发现。从编辑器中可直接调用编译器及配套程序，无需离开编辑器即可运行。
