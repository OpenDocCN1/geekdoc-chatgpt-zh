### **4.5.2** **升级创建动态联动图表**

“DeepSeek+Kimi”自动生成的 PPT 能覆盖财务工作中大部分场景，优点是便捷高效。但目前仍存在局限，比如模板套用生硬、仅能生成文字、缺少财务常用图表，也无法实现数据动态联动。若对数据展示要求更高，就需要对 PPT 做个性化调整。

**1.对 PPT 进行个性化的修改和制作**

以下三种做法有助于提升 PPT 的数据呈现效果和灵活性。

**方式一：DeepSeek 辅助创建 Excel 与 PPT 数据联动模板。**此法简单灵活，仅需基础办公软件操作即可借助 DeepSeek 制作 Excel 与 PPT 联动模板。DeepSeek 可按财务数据自动整理并生成可直接复制到演示文稿的内容，同时还能提供专业制作指导。特别在图表展示时，PPT 与源数据的动态联动尤为关键，刷新或更新链接即可保证数据实时同步，避免滞后。

操作步骤为：

（1）在 DeepSeek 中输入指令；
（2）DeepSeek 生成 PPT 内容和分步操作教程；
（3）完成 PPT 制作。

**方式二：利用 DeepSeek 和 Marp 生成 PPT。**此法高效便捷，适合有一定技术基础的用户。通过 DeepSeek 生成的 Markdown 内容可直接导入 Marp 等支持 Markdown 的工具，一键生成 PPT，无需手动排版。

操作步骤为：

（1）安装 Marp；
（2）在 DeepSeek 中输入指令，生成 Markdown 内容；
（3）复制内容到 Marp 中一键生成 PPT。

**方式三：使用 DeepSeek 生成的 Python 代码制作交互式 PPT。**此法适合有编程基础的财务人员，可生成交互式 PPT，提升展示效果。通过 DeepSeek 生成 Python 代码读取数据并生成 PPT，能实现数据动态展示与交互功能。

操作步骤为：

（1）安装 Python 和代码编辑器；
（2）在 DeepSeek 中输入指令，生成 Python 代码；
（3）在编辑器中运行代码，一键生成交互式 PPT。

方式二和方式三需安装相关程序或插件，部分操作涉及少量编程。本书聚焦财务人员对 DeepSeek 的应用，拓展内容不再详述，有兴趣者可自行学习。下面重点演示方式一的具体操作。
