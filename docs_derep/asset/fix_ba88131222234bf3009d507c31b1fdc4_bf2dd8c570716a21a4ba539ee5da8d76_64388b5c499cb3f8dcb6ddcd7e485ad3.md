## 7.4 利用 ChatGPT 进行相关性分析

[PRE7]

扫一扫，看视频

关联分析用于衡量两个或多个变量变动趋势是否一致，帮助判断一个变量在多大程度上能推断另一个变量，例如身高与体重、气温与袜子销量、满意度与投诉率等。

**1．相关系数**

相关系数记作 r，范围 -1 到 +1。越接近 ±1 关联越强，越接近 0 关联越弱。

常见三种：皮尔逊、斯皮尔曼、肯德尔，适用场景不同。

皮尔逊用于测量两个连续变量的线性关系，数据近似正态时使用。
斯皮尔曼用于等级或非正态数据。
肯德尔适用于非参数数据，尤其样本量小的情况。

符号与强度判断：

正相关：一个变量上升，另一个也上升，系数为正。
负相关：一个上升另一个下降，系数为负。
无相关：线性关联不明显。

强度分级：
|r|>0.95 极强
|r|≥0.8 强烈
0.5≤|r|<0.8 中等
0.3≤|r|<0.5 轻度
|r|<0.3 微弱

相关不等于因果，即使关联很强也无法直接推断因果。

**2．关联分析适用的情况**

探索多个变量间是否存在联系且不区分自变量因变量时。
判断变量变动是否相互影响时。
初步筛选值得深入研究的变量，例如回归前先做关联。

**3．关联分析的步骤**

先绘制散点图观察规律。
根据数据类型与分布挑选系数并计算。皮尔逊要求近似正态，需先检验。
进行显著性判定并解释 p 值。
以文字报告数据来源、方法与结论。

象限分析法又称策略分析模型或波士顿矩阵，由布鲁斯·亨德森于 1970 年提出，将数据映射到四个象限，横轴常为重要性，纵轴为满意度或效果。广泛用于经营与策略优化，帮助宏观审视业务、识别现状与潜力、指导投入与调整，如图 7.1 所示。

四个象限对应：

高重要性高满意度：核心优势，保持投入。
高重要性低满意度：关键短板，需优先改进。
低重要性高满意度：满意但影响有限，可维持。
