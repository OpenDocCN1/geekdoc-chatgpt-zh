# 第 7 章

## “朋克”美学

朋克美学最早可追溯到上世纪七十年代诞生的赛博朋克创作，随着时间推移逐渐发展成一套另类的审美体系。

其核心在于以“朋克”精神——反抗主流社会、质疑权威秩序、重塑单一价值——为出发点，衍生出多元的未来想象。各个朋克分支都拥有极端化且辨识度很高的世界观，折射出人们对技术演进、社会形态与人类命运之间复杂纠葛的思考。

总体而言，朋克美学有两个主轴：对技术与社会进行极致推演，以及对既有秩序的挑衅与颠覆。从赛博朋克聚焦高科技异化与底层困境的凝视，到太阳朋克倡导生态共生的乌托邦式乐观，再到蒸汽朋克、柴油朋克、原子朋克、生物朋克、纳米朋克等不同技术路线下对社会图景与价值体系的设想，朋克始终借助鲜明的视觉符号与鲜明的美学态度，呈现技术进步与人类生活之间可能产生的断裂、冲突与融合。
