LangChain 可追踪链路与结构化输出实践

在工程实践里，单次模型调用需要提问口径稳定、返回结果可控。把追踪回写、提示模板和自定解析器串联起来，就能让一次推理变成可记录、可复用的闭环。下面用可运行片段说明思路。

[PRE0]python

from argilla import ArgillaCallbackHandler

from langchain.llms import OpenAI

from langchain.prompts import PromptTemplate

from langchain.chains import LLMChain

##### 初始化 Argilla 回调处理程序，并指定数据集名称

argilla_callback_handler = ArgillaCallbackHandler(dataset="langchain_data")

##### 创建任务链，包含 Argilla 回调处理程序

template = "请简述以下人物的生平：{person}"

prompt = PromptTemplate(template=template, input_variables=["person"])

llm = OpenAI(temperature=0)

chain = LLMChain(llm=llm, prompt=prompt, callbacks=[argilla_callback_handler])

##### 输入中文测试用例

response = chain.run({"person": "屈原"})

print("任务链输出:", response)

上例先创建 Argilla 回调并指定数据集收集轨迹，再用 PromptTemplate 固化人物生平的提问框架，随后将大模型、模板与回调装进 LLMChain，最后以屈原为中文案例执行并打印结果。整条链路具备观测能力。

输入侧的规范同样关键。把变量抽离到模板中，可以避免自由发挥带来的格式漂移。

模板把 event 独立出来，之后只需填值即可得到形态一致的指令。

from langchain.output_parsers import ResponseParser

##### 自定义输出格式化器

class SimpleResponseParser(ResponseParser):

    def parse(self, response):

        return f"格式化输出:{response.strip()}"

output_parser = SimpleResponseParser()

要点说明如下：

(1) PromptTemplate：模板内预置事件、地点、时间等多维度占位符，让输入保持统一结构，便于模型解析。
(2) DetailedResponseParser：自定义解析器把生成文本拆分为概述、影响、历史评价三部分，实现结构化处理。
(3) LLMChain：把模板与解析器串联成完整任务链，使端到端输入输出保持一致，便于后续应用。

### 10.1.2 自定义输出解析器的实现与应用

该案例展示了在 LangChain 中承接多维输入并借助定制解析器完成输出规范化，产出可复用结构内容，适合对统一性和精细控制要求高的企业级场景。

在 LangChain 体系里，输出解析器的作用是把模型生成的自由文本映射为可直接消费的数据结构。自定义解析器可按业务需要把结果转为枚举、JSON 等形式。下面以典型实现为例。
