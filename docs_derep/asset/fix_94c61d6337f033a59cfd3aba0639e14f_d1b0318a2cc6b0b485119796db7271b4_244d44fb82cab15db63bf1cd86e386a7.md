# 扣子收费吗？看这篇就懂

最近被问到扣子是否要掏钱，答案其实分场景。

入门体验版更偏向试用。借助抖音、微信、飞书等常用入口接入机器人时，系统会先赠送一批可免费使用的调用次数，消耗完后就会停止服务，不能再继续触发。

进入商业用途就得看付费版。这一档的费用主要由两部分构成：机器人被触发的频次费用，以及知识库占用的存储费用。最终的账单会由对应的付费账号统一结算。

从资源配置来看，付费版比入门版更宽松，协作空间的上限更高，知识库的赠送额度也更大，比较适合团队扩大使用。

另外，调用接口时可以用返回码来判断成败，0 表示调用正常，任何非零数值都意味着请求出现了异常，需要结合说明排查原因。
