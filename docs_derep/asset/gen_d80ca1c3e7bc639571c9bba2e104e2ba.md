为满足高可靠性、高带宽、灵活可扩展的需求，需开展弹性可重构天基云处理网络拓扑研究。如图 11-15 所示，传统树型拓扑存在明显缺陷：一是可靠性不足，汇聚层或核心层设备异常时网络性能大幅下降；二是扩展性差，核心层设备端口受限难以支撑大规模网络；三是带宽受限，汇聚层交换机连接边缘层的带宽远大于连接核心层的带宽，比例可达 80∶1 甚至 240∶1，导致跨汇聚交换机的计算节点通信易被阻塞。

### 11.4.3 天基海量数据分布式快速协同处理

为化解空间威胁目标海量探测数据近实时处理需求与单星算力不足的矛盾，需在天基云架构下研究海量数据分布式协同处理技术，采用 `MapReduce`、`Dryad` 等分布式并行模型，兼顾扩展性、细节屏蔽与易用性。

`MapReduce` 由大量 `Map` 与 `Reduce` 任务组成，如图 11-17 所示。数据处理分为 `Map` 阶段与 `Reduce` 阶段：`Map` 阶段各任务读取输入文件块并行处理，中间结果保存在执行节点；`Reduce` 阶段各任务读取并合并多个 `Map` 的中间结果。其优势在于：数据同步由框架在 `Reduce` 读取中间结果时自动完成；框架会监测任务状态并重跑异常任务，无需人工干预；`Map` 与 `Reduce` 可并发执行，扩容节点即可提速；处理大规模数据时任务数远超节点数，有助于负载均衡。

### 11.4.4 天基云处理资源智能管理与调度

天基海量数据处理性能受网络带宽制约，而带宽恰是天基云节点集群的稀缺资源，故任务调度需考虑带宽因素。为降低传输开销，可将任务调度至输入数据所在节点，需研究面向数据本地性的调度算法，采用 `HTA` 即 Hadoop Task Assignment 问题模型，为一种变形的二部图匹配，如图 11-19 所示。目标是将任务分配给计算节点并实现负载均衡。其中 `si`、`tj` 分别指计算节点与任务，实边表示 `si` 持有 `tj` 的输入数据，虚边表示不持有，`wl` 与 `wr` 分别为调度开销。依托先均衡分配再细化负载的思想，可用 `BAR` 算法快速求解大规模 `HTA` 问题。

图 11-19 `HTA`问题模型

除数据本地性外，作业调度器还需兼顾作业间公平性。工作负载既有子任务少、耗时短、对响应敏感的即时作业，如数据查询；也有子任务多、耗时长的长期作业，如数据分析。公平调度算法可及时为即时作业分配资源，提升响应。为权衡本地性与公平性，采用基于最小代价流的调度模型。如图 11-20 所示，`wij` 表示作业 `i` 的子任务 `j`，`wij` 与 `c`、`r`、`x`、`u` 的边分别对应任务调度到计算节点、机架、数据中心或不调度，每条边带权值并随集群状态实时更新。当节点空闲或新任务加入等状态变化时，调度器求解调度图的最小代价流并据此决策。

从概念脉络看，机器学习、深度学习、强化学习是驱动快速发展的三大核心动力。人工智能最早出现曾备受看好，其后机器学习这一子集快速成长，近十年来机器学习分支深度学习备受关注，引发前所未有的影响，成为人工智能爆发的主要推手。

## 机器学习概述

如图 12-1 所示，传统方式是直接编写程序用固定算法从输入推导输出，而机器学习是让计算机基于已有数据即经验归纳出模型，再用该模型预测未来的一种方法。某种程度上，机器学习近似人类经验思维，能考虑更多情形并执行更复杂计算。其核心在于把人类的归纳经验过程转化为计算机经数据处理计算得出模型的过程，模型可近似人类方式解决灵活复杂问题。机器学习遵循“透过数据，发现规律，进行预测”的基本流程。

## 3. 深度学习 一种实现机器学习的技术

深度学习并非独立的学习范式，本身也使用有监督与无监督方法训练神经网络。但近几年发展迅猛，涌现出残差网络等特有手段，越来越多地被单独视为一种方法。

最初深度学习是用深度神经网络解决特征表达的问题。深度神经网络并非全新概念，其源自人工神经网络，这一早期机器学习重要算法历经数十年沉浮。神经网络原理受大脑生理结构启发，即相互交叉连接的神经元。与大脑中神经元可在一定范围内任意连接不同，人工神经网络具有离散层、连接方式与数据传播方向。

深度神经网络大体指含多个隐层的神经网络。为提升训练效果，人们对神经元连接方式与激活函数等进行改进。不少想法早年已提出，但因训练数据不足、算力落后而效果不佳。

深度学习以摧枯拉朽之势攻克各类任务，使几乎所有机器辅助功能成为可能，自主驾驶、预防性医疗、更精准推荐等已近在咫尺。原因与以下因素密切相关：

①深度神经网络需要海量数据训练。网络过浅则识别力不及 SVM、boosting 等浅层模型；网络过深若数据不足则过拟合不可避免。自 2006 年起互联网迅猛发展，产生大量训练数据，进入大数据时代。

②算力需求。深度网络需大量可并行重复计算，在 CPU 单核且性能有限的时期难以训练。随着 GPU 算力增长，深度网络与大数据的结合才成为可能。

③回顾发展历程，从单层感知器到含一个隐层的两层网络，再到多层深度网络，经历“三起三落”。在起落之间，Lecun、Hinton 等学者的坚持，最终推动深度神经网络成为主流。

## 4. 强化学习 学习反馈的自我进化机制

强化学习源于生物有效适应环境的启发，以试错机制与环境交互，通过最大化累积奖励学习最优策略。

系统由状态 `s`、动作 `a`、状态转移概率 `P（s′/s，a）`、奖励信号 `r` 四部分构成。策略 `Pi：S-＞A` 为从状态空间到动作空间的映射。智能体在状态 `s` 下按策略 `Pi` 选择动作 `a`，执行后以概率 `P（s′/s，a）` 转移到下一状态 `s′`，并获得环境反馈的奖励 `r`。强化学习目标是通过调整策略最大化累积奖励，常使用值函数评估策略 `Pi` 的优劣。

实践中常将深度学习与强化学习结合，先用深度学习完成有效信息检测识别，再以强化学习形成系统反馈进化。2015 年，谷歌 DeepMind 公布两项成果：基于 Atari 游戏的深度强化学习算法与围棋程序 AlphaGo 1。该工作打破传统类人智能学习算法设计桎梏，将具备感知能力的深度学习与具备决策能力的强化学习紧密结合，构成深度强化学习 `DRL` 算法，其原理框架如图 12-2 所示。其表现远超预期，对学术界与产业界产生巨大震动。
