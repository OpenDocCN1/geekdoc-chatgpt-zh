# 从零搭建 RL 任务分发环境

想让强化学习去做调度，离不开一个可复现的仿真。下面给出最简依赖，以及一个基于 Gym 的任务平衡仿真骨架：设定集群包含 N 台服务器，每台都配置处理上限并使用 FIFO 队列管理请求。每当新请求抵达，代理要为其挑选一台目标机器进行安置，环境以平均等待时间的相反数作为反馈，等待越低反馈越高。
