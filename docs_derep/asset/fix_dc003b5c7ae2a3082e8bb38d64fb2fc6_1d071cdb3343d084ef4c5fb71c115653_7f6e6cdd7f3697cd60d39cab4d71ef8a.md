# Excel×AI 财务实战手册

# 图书概览

本书定位为初级财务人员的 Excel 实操指南，重点示范如何借助表格软件完成日常会计与财务流程。整套内容引入智能助手 DeepSeek，配合表格软件完成信息清洗、洞察分析与数值运算，并能给出定制化解答与建议，有效降低学习门槛。

全书涉及的主题包括：财务信息的录入与编辑、整理与洞察、常用函数公式的运算、财务部门高频表单搭建、企业行政费用管控、制作记账凭证并自动记入日记账、往来款项管理与账务处理、进销存信息管理与账务处理、薪酬信息管理与账务处理、固定资产管理与折旧计提、月末结账与总账构建、财务报表编制以及财务分析。

随书附赠案例教学视频、源文件与演示文稿，读者可通过书内二维码及封底文泉云盘二维码在线学习并下载素材。

本书面向希望提升表格软件能力的财务从业者，尤其适合刚入职或即将入职的新人，也可作为高校相关专业的参考资料。
