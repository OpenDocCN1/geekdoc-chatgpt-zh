TensorFlow 速览：张量、图与可变节点

在 TensorFlow 体系里，所有对外接口的数据形态都必须是张量，不接受 Python 原生 int、double 等裸类型。哪怕是一个标量 1，也要先封装成零维、单元素的张量。张量本质上是多维数组，能够表达一维到 n 维的任意结构。换句话说，TensorFlow 内部把所有数据都当作 n 维数组处理，只是统一叫做张量。张量由阶数、形状、数据类型三要素刻画。形状可以看作各维的长度，例如形状为 2 的张量就是一维长度为 2 的数组；阶数则对应维度的个数。

要理解任何深度学习框架，先要建立张量概念，它是向量和矩阵的推广。向量是一维，矩阵是二维，张量则可以是任意维度。

直观地看 TensorFlow，就是张量的流动，计算节点保持不变，数据在图中流动。所有程序都先建立计算图，用来声明张量运算与数据处理的流程。

计算图是一个有向图，每一个节点都代表一次数学操作，图中的边则表示节点间传递的多维数据数组，即张量。

以向量相加为例，整体思路是通过定义并执行计算图完成加法，再借助会话对象运行。会话封装了评估张量和操作对象的环境，这里真正实现运算并把信息从一层传递到另一层。

### 5.3.3 占位符

占位符（Placeholder）用于在会话运行时动态提供输入数据。占位符相当于定义了一个位置，这个位置上的数据在程序运行时再指定。
