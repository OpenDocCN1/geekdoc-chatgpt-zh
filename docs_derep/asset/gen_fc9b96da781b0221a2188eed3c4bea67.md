## **ClawHub：可插拔的技能中枢**

ClawHub 并不是传统意义上的应用商店，而是一个面向 Agent Skills 的能力仓库。它的定位是可检索、可版本化、即装即用的扩展中心，核心理念围绕四点展开。

按需挂载，每个技能包只解决一个或一类细分场景，不会给原生内核增加负担。轻量引入，通过 npx 一键拉取，技能与主程序解耦，用完即走。可回滚可管理，技能像 npm 包一样带有版本号，升级出错随时回退。安全可溯源，所有上架内容来自官方或社区维护的清单，减少擅自安装外部脚本的风险。

基础版 OpenClaw 是一款通用自动化引擎，难以覆盖所有人的长尾需求。ClawHub 里的每项技能都是针对特定任务封装好的命令行能力。你不需要理解底层实现，找到匹配的技能，一条命令就能让 OpenClaw 精准升级。

**上手流程**
给 OpenClaw 增加新能力，全部在命令行完成，遵循“逛—选—装”的三步节奏，新手也能快速上手。

第一步逛：打开 ClawHub 官网，首页会清晰呈现“Highlighted skills”和“Popular skills”两类推荐。每个条目都有简短说明、适用场景和下载热度，方便判断是否匹配。

第二步选：页面右下角的“See all skills”可进入完整库，库内收录超过 3 万项技能，卡片上列明技能名、摘要和作者。原则是只装当下高频刚需，不盲目囤积。

第三步装：点进技能详情后，右侧提供版本信息和下载压缩包入口，点击下载、解压、按提示安装即可。

典型示例：想让 OpenClaw 处理 Word 文档。打开官网点顶部菜单 Skills，在搜索框输入 Word/DOCX，找到对应条目进入详情页下载安装。安装完成后即可在 OpenClaw 中调用，实现文档创建、编辑、样式处理等操作。

**典型误区**
新手扩展技能时容易因操作不当导致功能异常，主要有四类偏差。

误区1乱装不兼容的技能。从非官方渠道安装，或装了与实际场景不匹配的技能，容易引发隐私泄露、卡顿、功能冲突。纠正方式是坚持通过 ClawHub 安装与真实需求匹配的技能，提升风险意识。

误区2堆砌大量技能。认为技能越多越强，一次装下几十个不常用包，造成上下文冗余、效率下降。建议只保留3到5个高频核心技能，定期清理冗余。

误区3权限放任。涉及系统操作、支付、通信、文件删除的高危技能直接放开全权限。应强制保留最后一步人工确认，绝不完全交由 AI 自动执行，不常用的高危技能直接禁用。

**要点回顾**
OpenClaw 的基础是通用框架，ClawHub 才是让它贴合个人需求的技能库。不写代码、不折腾配置，花几分钟逛库挑选合适的技能包，一条命令完成能力扩展。这是从“能用”到“好用”的关键，不改变使用习惯，却能精准解决细分需求，真正实现量身定制。

## **10 分钟搭一个日报自动生成器**

**痛点在哪**
职场人最抗拒的琐事之一就是写日报。每天要汇总工作、核对数据、梳理计划、调整格式，忙时还要加班赶工。数据零散、格式不统一，反复修改更耗时间。零基础也能用 OpenClaw 搭建专属的日报自动生成器，到点自动产出规范日报，彻底告别手工内耗。

**工作流设计原理**
搭建生成器的核心是把单一自动化动作串成闭环工作流，从基础的“单点执行”升级为“多步骤、按序联动完成”。

基础 OpenClaw 只能做一件事，比如抓数据或填文本。而日报需要“抓数据→汇总→排版→生成文档→推送”完整链路。进阶搭建的逻辑是固定模板加动态数据填充再配合流程化执行。

先确定标准化日报模板，明确固定框架与格式。把生成步骤拆成可执行的子任务，设定执行顺序和衔接规则，让工具按步自动运行。定时抓取当日数据，填充到模板对应位置，输出完整文档。全程无需代码、无需手动干预，重复的汇总排版交给流程完成，保证格式统一并节省时间。

**五步搭建法**
零基础搭建可视化、无代码操作，按“定模板→拆任务→设顺序→配触发→做测试”五步走，生成的日报可直接适配公司要求。

[PRE0]
图 4-2 用 OpenClaw 搭建日报自动生成器五步法

第一步定制标准化模板。按公司要求制作 Word 或 Excel 模板，固定五大板块：当日完成项、核心数据、待跟进事项、明日计划、备注。统一字体格式后上传到 OpenClaw 模板库，后续只需填数据。

第二步拆解生成子任务。日报流程拆成四个核心子任务。定时抓取当日工作数据，包括工作软件、表格、聊天记录。提取待跟进事项和明日计划，来源为日程或任务清单。把数据精准填充到模板对应板块。生成文档并按日期命名保存。

第三步设定执行顺序与衔接规则。在流程搭建页面按顺序添加子任务，设置上一个任务完成后才执行下一个，并标注数据填充位置，避免错位。

第四步配置触发时间与推送方式。触发时间建议设为下班前15到30分钟，确保数据已更新。推送方式可选自动保存到指定文件夹，或推送至企业微信、邮箱直接提交。

第五步测试流程并微调。先手动跑一遍，检查数据完整性和格式规范性，有问题就调整子任务或匹配规则，确认无误后再开启自动运行。

标准指令示例：搭建名为“每日工作日报”的自动化流程，每日17:30定时触发。子任务1打开桌面“当日工作记录”Excel 表，提取工作完成项、核心业绩数据、待跟进事项。子任务2打开日程清单提取明日工作计划。子任务3调用预设 Word 日报模板，将内容按板块自动填充，保持字体段落统一。子任务4生成完整日报，按“×月×日姓名-工作日报”命名，保存至桌面“工作日报”文件夹，同时推送至企业微信工作群。若执行失败等待5分钟后重试，重试失败则桌面提醒，确保不遗漏。

这条指令覆盖全流程，逻辑清晰可直接复用。搭建完成后日报每日自动生成，每天可节省半小时以上。

**常见失误**
实际运行中常出现四类问题，校正后即可稳定。

失误1模板不固定导致填充错乱。板块模糊、无固定位置，工具无法定位。应重做标准化模板并标注每个板块的填充区域。

失误2子任务顺序颠倒。先填充后抓取，导致日报空白。必须严格按“抓取→提取→填充→生成”排序，做好衔接。

失误3触发过早。时间太早当日数据未更新，造成漏项。把触发点设为下班前15到30分钟。

失误4缺少异常重试。表格打不开或提取失败流程直接中断。应添加失败后5分钟重试规则并配合提醒。

**收尾总结**
进阶 OpenClaw 搭建日报自动生成器全程无代码可视化，日报之外可举一反三搭建周报、月报。掌握这套实操，就能让 OpenClaw 从执行工具变成专属办公助手，实现解放双手与高效办公。

## **让 OpenClaw 调度 Kimi、MiniMax、GLM**

**痛点在哪**
用到进阶阶段会发现瓶颈：OpenClaw 在自动化、数据抓取、跑流程上很强，但长文本阅读、逻辑分析、文案润色、创意生成仍显不足。比如抓到一份长研究报告想快速提炼要点，汇总数据想做专业分析，写文案想优化逻辑，单靠 OpenClaw 做不到。

有人不管任务统一用一个大模型，完全浪费各自优势。让擅长长文本的模型去算数，让擅长创意的模型去推理，得不偿失。把 OpenClaw 设为 AI 调度中枢，让 Kimi、MiniMax、GLM 各司其职，形成“抓取→调度→处理→输出”的闭环，才是从好用到精通的关键一步。

**协作原理**
调用外部大模型的核心是 OpenClaw 负责自动化调度，专业模型负责智能处理。二者互补而非替代。

OpenClaw 擅长动手执行：抓取数据、跑通流程、定时触发、整理文件、填模板、发送消息。各模型擅长动脑理解：Kimi 擅长长文本阅读、文档速读、摘要提取、深度解读；MiniMax 擅长创意文案、脚本撰写、风格改写、内容生成；GLM 擅长逻辑分析、数据推理、专业问答、结构化输出。

完整协同流程为：OpenClaw 收集整理数据→按任务类型自动调用最适配模型→把内容和清晰指令传给模型→模型处理完回传→OpenClaw 保存排版并推送。

**四步接入法**
全程安全合规且操作简便，无需复杂 API 对接，按“绑定模型→区分场景→设定规则→自动调整”四步实现按需调用。

[PRE1]
图 4-3 用 OpenClaw 调用主流大模型四步法

第一步安全绑定。进入 OpenClaw“模型协同”设置，通过官方入口绑定 Kimi、MiniMax、GLM，不泄露密钥、不上传多余数据，绑定后统一管理。

第二步按任务匹配模型。固定任务与模型的对应关系：长文本、研究报告、文档速读、摘要交给 Kimi；创作文案、脚本润色、风格改写交给 MiniMax；逻辑分析、数据推理、专业问答交给 GLM。

第三步设定调用规则。在流程中加入模型调用步骤，明确传什么内容、如何处理、结果如何回传。指令需具体到字数、风格、结论条数、结构，确保输出可控。

第四步配置异常处理。响应超时可等待重试或自动切换备用模型；输出不合格则重新下达指令微调；调用异常时桌面提醒，避免任务失败。

标准协同示例：每周一10:00触发。OpenClaw 抓取上周行业研报与工作数据并整理；长文本摘要自动调用 Kimi 提炼500字核心观点；数据逻辑分析自动调用 GLM 输出3条核心结论；整合两份结果排版成“周度分析报告”，保存到桌面并发送邮箱；模型超时3分钟后重试，仍失败则自动切换备用模型。

该指令充分发挥自动化调度与专业处理能力，全程无需人工干预，完成从采集到智能分析的闭环。

**常见偏差**
多模型协同易出现四类问题。

偏差1模型与任务不匹配。比如用 MiniMax 做逻辑分析、用 Kimi 做数据计算。应严格按场景匹配，让专业模型做专业事。

偏差2指令模糊。只说“处理一下”，导致输出冗长无重点。指令要具体明确。

偏差3非官方对接。私填密钥或走第三方接口有安全风险。只能通过 OpenClaw 官方适配入口授权。

偏差4不做校验直接使用。大模型偶发跑偏，须开启简单校验或人工复核提醒。

**收尾总结**
OpenClaw 做调度中枢，Kimi、MiniMax、GLM 各自发挥所长，自动抓取、自动调度、智能处理、自动输出，形成稳定闭环。掌握这套玩法，OpenClaw 就不再是单一工具，而是专属智能工作中心，实现从能用到好用到精通。

**章末问答**
问：安装过多插件会影响稳定性吗？
答：会影响。建议只保留3到5个高频使用的插件，禁用闲置项，定期更新官方插件，避免非官方插件引发冲突或卡顿。

问：日报生成器能适配公司特殊模板吗？
答：可以。将公司模板上传至工具模板库，并在流程中设置数据填充的精确位置，即可生成完全符合要求的定制化日报。

问：调用第三方大模型会产生额外费用吗？
答：视情况而定。部分模型提供免费额度，超出后按官方标准付费。OpenClaw 仅做调度，不额外收费，费用由模型方结算。

问：多模型协同任务能手动干预吗？
答：可以。在流程监控中可暂停、继续或终止任务，也能手动修改模型输出结果，兼顾自动化效率与人工审核的严谨性。
