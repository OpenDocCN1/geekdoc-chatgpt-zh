|  | 对于物品：新加入的物品能够较快地被纳入推荐列表 | 对于物品：难点在于需要离线状态下更新物品相似度 |

| 推荐理由 | 物以类聚，人以群分 | 基于用户的历史行为给用户做推荐 |

## 13.2 基于文本的推荐
随着人工智能的演进，自然语言处理能力不断提升，由早期的字面匹配发展到现在的语义理解。计算机不仅能处理关键词，还能把握请求背后的含义，实现语义层面的检索而非单纯的字面检索。

### 13.2.1 标签与知识图谱推荐案例
技术进步让大量非结构化数据得以利用，例如语音、图像和文本。对于文本类数据，通常借助自然语言技术提取信息并与用户关联，从而驱动推荐。伴随互联网应用的发展，用户角色也在转变，既是内容消费者也是内容生产者。

互联网从来不是单向传播的场所，不断产生各类内容，典型代表有今日头条、一点资讯等。这些内容以 PGC 与 UGC 混合的方式产生，再结合机器学习与深度学习算法进行个性化分发，提升用户体验。

### 小贴士：
PGC 指专业生产内容、专家生产内容，用来泛指内容个性化、视角多元化、社会关系虚拟化。其分类更专业，内容质量也更有保证。特别是高端媒体采用的也是 PGC 模式，其内容设置及产品编辑均非常专业。

UGC 指用户原创内容，是伴随着提倡个性的 Web 2.0 概念而兴起的。它并不是某一种具体的业务，而是一种用户使用互联网的新方式，即由原来的以下载为主改变成下载和上传并重。UGC 有个好处是，用户可以自由上传内容，丰富网站内容，但不利的方面在于内容的质量良莠不齐。
