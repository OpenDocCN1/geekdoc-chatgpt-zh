划分式聚类是将样本集合拆分为若干个簇的思路，每个簇内部成员相互更接近，而不同簇之间的差异更大。核心目标是让簇内紧凑度下降、簇间分离度提升。下面是常见的划分式算法及其特点。

**1． K-means 算法**

K-means 是最基础也最常用的划分方法，流程大致如下。

（1）随机抽取 *K* 个样本作为初始中心。
（2）把每个样本划分到最近的中心，形成 *K* 个簇。
（3）根据当前成员重新计算各簇中心。
（4）循环执行（2）（3），直至中心不再变动或达到设定的迭代上限。

优点在于实现简单、效率高，适合大数据。短板是结果受初始中心影响较大，且需要提前指定 *K*。

**2． K-means++算法**

K-means++ 在初始化上做了优化，降低了对初始值敏感的问题。初始化步骤如下。

（1）从样本中随机选取第一个中心。
（2）对每个样本计算到已有中心的距离，以距离平方成比例的概率挑出下一个中心。
（3）重复（2）直至选出 *K* 个中心。
（4）用这些中心启动标准 K-means 进行迭代。

这样选出的初始中心分布更分散，聚类质量和稳定性都有明显提升。

**3． Bi K-means 算法**

Bi K-means 即二分 K-means，采用自顶向下逐步细分的策略。流程如下。

（1）起初把全部样本看作一个簇。
（2）对某个簇使用 *K*=2 的 K-means 进行二分，选择总误差最小的簇继续切分。
（3）重复（2），直到得到 *K* 个簇。

逐步细分的方式能在一定程度上缓解初始中心敏感和陷入局部最优的问题。

**4． K-medoids 算法**

K-medoids 与 K-means 类似，但簇代表不再是均值而是簇内真实样本点，即 medoid，这使其对噪声和异常值更稳健。具体步骤：

（1）随机挑选 *K* 个对象作为初始 medoids。
（2）把每个对象分配到最近的 medoid，形成 *K* 个簇。
（3）对每个簇尝试用簇内其他对象替换当前 medoid，计算簇内点到 medoid 距离之和的总成本。
（4）若替换能降低成本则更新 medoid。
（5）重复（2）（3），直至无法改进。

抗干扰能力更强，但计算开销更大，在大规模数据上效率受限。

**5． Kernel K-means 算法**

Kernel K-means 通过核技巧隐式把数据映射到高维空间，再在该空间执行 K-means，从而捕捉非线性可分的簇结构。核函数的选择决定了新空间的分布，常用多项式核、高斯 RBF 等。

它能处理复杂结构，但核函数与参数的调优难度高，计算成本也高于普通 K-means。

基于密度的聚类依据点间密度分布划分，擅长发现任意形状的密集区域，能自然识别噪声，无需预设簇数。代表算法有 DBSCAN 和 OPTICS。

**1． DBSCAN 算法**

DBSCAN 通过连接高密度区域形成簇，并能标记噪声。核心概念：

（1）核心点：在半径 *ε* 内样本数 ≥ MinPts 的点。
（2）边界点：落在核心点邻域但自身不满足核心点条件的点。
（3）噪声点：既非核心也非边界的点。

步骤：
（1）以 *ε*、MinPts 判断各点类型。
（2）从未访问的核心点出发，递归聚合密度可达点形成新簇。
（3）重复直至所有核心点被处理。
（4）剩余点标记为噪声。

优点是不用指定簇数、可发现任意形状、对噪声鲁棒；缺点是 *ε* 与 MinPts 选择敏感，对密度差异大的数据表现不佳。

**2． OPTICS 算法**

OPTICS 改进了 DBSCAN 对不同密度区域的适应性。不直接输出簇，而是生成点的访问顺序来反映密度结构。

核心概念：
（1）核心距离：使点成为核心点的最小 *ε*。
（2）可达距离：点 A 到点 B 的可达距离取两者中较大者。

步骤：
（1）为每个点计算核心距离与可达距离，并按此排序。
（2）迭代更新邻居的可达距离，形成可达性图。
（3）通过阈值从可达性图中识别簇。

OPTICS 避免了全局 *ε* 的硬性设定，能在不同密度水平下探索结构，更灵活。

密度类方法为识别复杂形状簇和处理噪声提供了有效手段。DBSCAN 参数调优直接影响结果，OPTICS 则提供更细致的密度探索。具体选用取决于数据密度特征与分析目标。
