DeepSeek 本地落地实战：模型怎么选、怎么私有化

除了蒸馏小规格，还可以考虑参数量更轻的非蒸馏备选。截至成稿，社区常提的 QwQ-32B、Gemma3-27B 都算一种思路，在有限体量下能给出可用表现，但整体水准仍落后于 DeepSeek-R1。

前面章节已梳理过 DeepSeek-R1 官方推出的几类蒸馏模型。实际使用经验是，代码类任务对参数规模不算敏感，依赖大量常识的问答则更仰仗体量。据公开测评，1.5B 蒸馏版在编程上已能超过 GPT-4o 并压制多数国产非推理大模型，但在通用问答等场景差距明显。无论体量大小，蒸馏版的能力上限都低于原版满血模型，选择时要紧扣真实场景。

动手前先确认显卡型号并查显存大小，再结合整机配置决定拉取哪一版。

本地运行的关键四要素：

**CPU**：参数越大并发计算越重，多核高端处理器有助于降低推理瓶颈。

**GPU**：模型规模提升对显卡压力同步上升，显存容量与算力是决定因素。单卡显存不足时需多卡协同。

**内存**：参数、中间算子和缓存都要常驻内存，需求基本随参数量线性增长。

**存储**：模型本体加推理临时文件决定磁盘占用，体量越大所需空间越高。

下面给出 DeepSeek-R1 各蒸馏规格的参考门槛，B 为十亿，1.5B 约等于十五亿参数。

- 1.5B：四核起步 CPU、8GB 以上内存、3GB 以上盘符，显卡可不依赖，需加速时建议 4GB 以上显存，适合资源受限环境。
- 7B：八核以上 CPU、16GB 以上内存、8GB 以上硬盘，显卡建议 8GB 以上显存，适合本地开发验证。
- 8B：需求与 7B 接近且略高，适合对精度稍有要求的轻量任务。
- 14B：十二核以上 CPU、32GB 以上内存、15GB 以上硬盘，显卡 16GB 以上显存，可承担企业级简单业务。
- 32B：十六核以上 CPU、64GB 以上内存、30GB 以上硬盘，显卡 24GB 以上显存，适合领域任务。
- 70B：三十二核以上 CPU、128GB 以上内存、70GB 以上硬盘，显卡需多卡并行，适合高复杂度生成，仍不及 671B 满血版。

## 私有化落地方案

与云服务不同，Ollama 强调数据不出设备，所有交互都在本地完成，隐私可控。它同时兼容 Windows、Linux、macOS，覆盖主流桌面。设计上追求化繁为简，安装与调用都便于上手，适合新手到专业用户。

## DeepSeek 的其他使用方式

除官方 App、网页版和私有化部署外，还有其他方式使用 DeepSeek，可归为两类。

#### 通过第三方应用接入

DeepSeek 模型开源免费，已被大量第三方应用接入。许多应用将 DeepSeek 接入自有知识库，通过 RAG 等技术增强输出，在垂直领域效果更好。例如百度、腾讯元宝、微信搜索、秘塔搜索、纳米 AI 搜索等均可使用 DeepSeek-R1 进行 AI 搜索，自动汇总全网信息生成答案；腾讯 ima.copilot 支持基于 DeepSeek-R1 构建个人知识库等。目前接入的应用已超百款，可按自身领域挑选工具。

此外，部分 AI 工具平台支持多家大模型混合接入。虽然 DeepSeek 很强，但在某些场景下并非最优。灵活组合国内外工具能进一步提升效率，如百言 AI 提供 AI 对话、AI 绘图等多种工具。

#### 通过云服务接口接入

对开发者或希望深度定制、接入自有知识库的用户，深度求索提供 API 开放平台，可获取接口使用权限。

拿到 API 后，可在 ChatBox 等工具中接入云端版 DeepSeek，也可接入 Dify、AnythingLLM 等本地知识库工具，实现定制化使用，还能通过编程调用实现自动化。

除官方外，火山方舟、阿里云、腾讯云、百度智能云等第三方云服务商也已接入 DeepSeek，提供兼容官方接口的 API，可自由互换使用。
