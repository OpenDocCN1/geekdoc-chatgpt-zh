# 第五章 从存在论到诠释学：认知研究的另一条路

前面几节我们用海德格尔的存在论视角梳理了当前认知科学的主流进路，提炼了相关概念与议题，也指出了把存在论现象学直接搬进认知科学时容易碰到的两处理论卡点。由此一个问题自然浮现：仅以存在论作为对话入口，视野算不算完整？存在论为审视人类认知提供了一种新切口，价值是明显的。但光靠存在论单打独斗难以支撑起一套认知解释，它需要补充新的思想资源。恰好诠释学与存在论有着内在的亲缘关系，这就为存在论认知向诠释学方向打开一扇门。我们认为，认知科学乃至人工智能完全可以从诠释学获得启发，二者之间存在着可通行的桥梁。

## 第一节 为什么存在论认知需要接上诠释学

### 诠释学在说什么

诠释学字面上与宣告、翻译、阐释相关，其词源指向希腊神话中的信使赫耳墨斯，他负责把神的旨意转译成人能理解的语言。由此发展出关于理解与解释的理论与实践，核心是意义的呈现与转换。早期它扎根于法律解释与圣经文献解释两大传统。到了施莱尔马赫与狄尔泰那里，诠释学摆脱了教义束缚，成为一门通用的理解学说，关注重心也从文本历史转向理解行为本身，其任务被理解为调和不同解释之间的冲突，并为人文科学提供方法论支撑。[^(\[1\])](#chapter006.html#m1)

把诠释学当作存在论认知的延伸并非凭空想象，而是逻辑上的自然推演。对海德格尔而言，存在论的根本追问是此在存在的意义，不管是早期以此在为核心的基础存在论，还是后期对存在本身意义的追问，其操作路径都是诠释学。要论证诠释学可以进入认知研究的某些领域，需要给出合理解释。

### 一 海德格尔的存在论现象学本质上就是诠释学

海德格尔转换了诠释学的用法，不再仅仅讨论理解本身，而是把理解看作此在一项根本的存在方式。此在通过理解才意识到自己身处世界。某种程度上，海德格尔对此在的现象学描述就是一部诠释学，此在被界定为理解的此在，对其生存结构展开的刻画天然带有诠释色彩。换句话说，现象学的方法论内核是解释，经由诠释，此在存在的本真意涵与基本结构才向我们显现。此在的现象学因此等同于诠释学。[^(\[2\])](#chapter006.html#m2)

此在始终把把握存在意义当作自我的课题，而意义的领会与阐发正落在诠释学的范畴内。于是可以推出，此在的现象学即诠释学，而此在的现象学正是基础存在论的工作。所以，此在的诠释学也就是基础存在论。[^(\[3\])](#chapter006.html#m3)

海德格尔提出诠释学意在揭示此在自身存在的样态。此在从一开始就在理解与解释，源源不断地产生对存在的主题化或非主题化理解，这种理解活动的本质是此在对自身的反思。这样的反思不是胡塞尔式的意识活动，而是此在的存在方式，牵涉到此在如何理解自己与他人存在。海德格尔不把理解窄化为一种认知操作，而是视其为我们在世界中存在、与世界互动的基本能力，简言之就是“我知道如何处理正在做的事情，在不同情境下做出恰当反应”。[^(\[4\])](#chapter006.html#m4)后来的伽达默尔把这一思路明确化：诠释学就是实践哲学，解释从一种形式转向另一种形式，体现了人在不同生存境况中的应对方式。对世界的操作本身就是对世界的敞开，呈现出人在时空维度上与他物的交互。海德格尔所说的理解涵盖感知、实践性 know-how、认知性知识，以及与他人的日常交往，而非仅限于认知现象。

总的来看，海德格尔的存在论现象学与诠释学是同一回事，因为人始终对存在保有本真或非本真的理解，如何让恰当的理解浮现出来，正是诠释学与基础存在论共同的使命。诠释学由此从文本解释的方法上升到哲学高度，成为关于存在理解的学问。既然海德格尔的存在论现象学与诠释学不可分，而伽达默尔在整体上承接了这一脉络，就有充分理由把存在论与认知研究的结合进一步扩展到诠释学，让诠释学的思想资源进入认知研究。

### 二 认知本身就是一种诠释行为

海德格尔提出诠释学是为了突破近代主体认识论那种孤立无世界的认知主体图景，这种图景遮蔽了人与世界之间原始关联。存在论现象学的任务正是在世界中来理解人与事物的关系。理解是世界与此在关系的具体化，存在离不开此在的理解，存在是在此在的理解中显现。[^(\[6\])](#chapter006.html#m6)

人不仅是行动的存在，更是诠释的存在。人的认知与行动在先行层面已被理解。某种意义上认知即行动，因其具有表征性：认知对象的模型或对应物的生成本身就是一次解释性呈现。认识具体事物、形成理论、设计模型，都可看作诠释过程。或许可以这样说，诠释是对认知对象的一种解释性呈现。人总是以诠释的方式、以不同视角面对世界，思维、认知、行动都浸透着诠释，缺乏合乎逻辑的诠释就无法思考、判断与评价。[^(\[7\])](#chapter006.html#m7)

除了渗透性，诠释对认知的依赖性也很深。细想就会发现，我们绝大多数关于事物与事件的认知、思考、判断都暗含诠释。日常生活中面对的多是可理解的事实，维特根斯坦曾言世界是事实的总和，事实只有经过诠释才进入我们的认知，事实的存在可被视为某种诠释的产物。任何事物要被认识必须先作为对象进入诠释过程，甚至可以推断，诠释的范围界定了认知的范围，人的认知世界是在诠释中被理解与建构的。认知活动所产出的结果，本身也是诠释的结果。我们既以认知方式又以诠释方式朝向世界，作为一个不断诠释的存在，我们在思维、认知与行动中始终依赖这一要素。
