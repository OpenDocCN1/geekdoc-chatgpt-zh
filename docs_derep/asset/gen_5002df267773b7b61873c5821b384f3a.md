## 小 结

本章围绕智能体应用的搭建思路，系统梳理了从简单到复杂的多种方法与主流技术框架，并用真实案例串联起来。学完之后，你能熟练选用合适的工具搭建自己的智能体，同时明白如何通过技术组合与持续优化来提升实用性和表现。

第一部分以 LlamaIndex 为例，讲解如何从零构建一个基础智能体应用。内容涵盖环境安装、模型获取、本地知识库的搭建，以及基于知识库的问答实现。配合分步说明和代码示例，读者可以快速把本地数据接入智能体，为后续进阶打下基础。

第二部分介绍 Swarm 框架的用法。Swarm 擅长分布式智能体的编排，文章演示了接入 DeepSeek 模型并调用外部工具的完整流程，展示智能体如何承接更复杂的任务。重点在于框架间的兼容与可扩展，说明不同工具和模型如何组合放大系统能力。

第三部分聚焦两个热门开源框架 Browser Use 和 Camel。Browser Use 让智能体可以直接操作浏览器采集与处理网页信息；Camel 则在任务调度、数据流管理上提供了更多选择。两者体现了开源生态的多样性，也为想动手开发的人提供了丰富的参考思路。

总体来看，本章既教会了用不同框架落地智能体的具体做法，也强调了组合优化的思路，帮助智能体从可用走向真正好用。
