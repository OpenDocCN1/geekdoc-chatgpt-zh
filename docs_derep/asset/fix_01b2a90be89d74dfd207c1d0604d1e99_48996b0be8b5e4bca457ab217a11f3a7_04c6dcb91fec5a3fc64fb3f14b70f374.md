# 第 2 章 用 ChatGPT 高效完成项目文档撰写

对项目经理而言，写文档是日常刚需。ChatGPT 作为自然语言处理领域的强模型，能够输出质量高、表达自然的文本，很好地分担了各类文档的写作压力，这也是智能时代必须掌握的核心技能。

上一章已演示如何让 ChatGPT 生成 Markdown 文档和 CSV 表格，但操作细节尚未展开。本章聚焦如何借助 ChatGPT 完成不同类型文档的编写。

## 2.1 借助 ChatGPT 构建模板并自动填充

项目经理经手的文档形态多样，Word 文档、Excel 表格、PDF 文件以及各类在线协作形式都常见。可以让 ChatGPT 负责文本生成，模型虽无法直接输出二进制格式，后续可配合预设模板实现格式固化。这种半自动化协作能明显提升文档产出效率。

### 2.1.1 设计文档模板

用 Office 工具搭建模板，可按下面流程操作。

（1）明确文档类型：结合规范与内容需求，选择 Word 文档、Excel 表格或 PowerPoint 幻灯片等形式。

（2）设定版面参数：按企业标准或个人习惯调整页面尺寸、边距等排版要素。

（3）统一标题样式：为不同层级的标题设定字体、字号、加粗等格式，形成可复用的样式库。

（4）配置目录与书签：使用 Word 的目录与书签功能，搭建清晰的导航结构，并为各章节生成超链接。

（5）制作封面与页眉页脚：添加封面、页眉页脚实现标准化，必要时写入文件名、创建日期等元信息。

（6）预留图文位置：按文档需求在合适处插入表格、图片、图表或公式，并附上说明注释。

（7）插入占位提示：在模型需要填充内容的位置放置文字占位符或提示语，明确生成方向与范围。

（8）保存为模板文件：完成设计的文档另存为模板，后续新建文档可直接调用。

#### （9）迭代检验与优化

初稿撰写过程中要检验模板的适用性，根据实际需求对标题、排版、样式等持续调优。

按上述步骤即可得到一套可落地的技术文档模板。模板的精细程度直接决定模型生成内容的贴合度以及人工整合的难度。理想状态下，人工只需对模型输出做少量润色即可嵌入模板，大幅减少重复劳动。

### 2.2.2 使用 Markdown 工具

工欲善其事，必先利其器，好的 Markdown 工具能大幅提升写作体验。

常见的编辑器有以下几类。

（1） Visual Studio Code：免费开源代码编辑器，对 Markdown 支持良好，可安装扩展实现预览、emoji 替换、PDF 导出等。

（2） Typora：界面简洁美观，支持实时预览、图片插入、表情符号、目录生成等，操作流畅。

（3） Mark Text：开源编辑器，界面清爽，支持实时预览与模式切换，插件扩展丰富。

（4） Ulysses：专业写作软件，支持 Markdown 及多格式导出，功能强、界面专业，但付费较高。

（5） iA Writer：专注文字写作，Markdown 支持完善，可高度定制主题与字体，体验纯净但功能相对精简。
