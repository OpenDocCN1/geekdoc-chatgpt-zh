## 6.5 AgentExecutor 运行原理拆解

AgentExecutor 充当 Agent 的执行器：它向大模型发起调用、接收输出并解析，随后执行模型挑选的工具，同时还要处理各种异常，例如调用不存在的工具、工具执行失败、模型输出无法解析为 Function Calling 格式，以及在决策和调用过程中记录日志。

_consume_next_step 的输入 values 来自 _iter_next_step 的输出，类型是 NextStepOutput 列表，元素可能是 AgentFinish、AgentAction 或 AgentStep。根据内容，返回结果不同。
