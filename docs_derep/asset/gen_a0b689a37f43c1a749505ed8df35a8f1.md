线性模型是机器学习里应用最广泛的建模范式，它假设输入特征与输出目标之间存在线性关系，并通过求解最优系数来拟合训练数据并进行预测。对于带有标签的训练样本，监督学习构造线性模型的关键在于如何得到合适的参数，即线性组合的系数或权重，使得模型输出能够较好地逼近样本标签。

线性模型在系数上具有简洁且易于解释的特性，可以直观理解每个特征对结果的贡献。模型的可解释性强，便于分析变量间的关系与影响程度。计算开销小，适合大规模数据和实时场景，同时对部分噪声不敏感，能够处理高维数据。作为机器学习的基础经典方法，线性模型为众多实际问题提供了可解释且有效的解决方案。本章系统介绍线性回归、逻辑回归、回归表达式、模型正则化等相关内容。

## 5.1 线性回归

给定数据集 D = { (x₁, y₁), (x₂, y₂), …, (xₘ, yₘ) }，其中 xᵢ = (xᵢ₁; xᵢ₂; …; xᵢd)，yᵢ ∈ R。线性回归的目标是学习一个线性模型，用以尽可能准确地预测实值输出。

先看最简单的情形：输出属性只有一个。为方便表述，省略属性下标，即 { (xᵢ, yᵢ) }ᵐᵢ₌₁，其中 xᵢ ∈ R。对离散属性，若其取值存在顺序关系，可先连续化，例如二值属性“身高”的“高”“矮”可映射为 {1.0, 0.0}，三值属性“高度”的“高”“中”“低”可映射为{1.0,0.5,0.0}；若取值无序，假定有 k 个取值，一般映射为 k 维向量，例如属性“球类”的“篮球”“足球”“排球”可分别映射为(0,0,1)，(0,1,0)，(1,0,0)。

一元线性回归假定因变量与自变量呈线性关系，该模型在空间中形成一个超平面。超平面是 n 维欧氏空间中余维数为 1 的线性子空间，如平面中的直线、空间中的平面等，其维度比所在空间少一。在一元线性回归中，因变量与自变量共两维，对应的超平面即为一条直线。

回归分析的初衷是估计模型参数以实现对数据的最佳拟合。常用的求解策略有两种：梯度下降法和正规方程法。梯度下降通过迭代获得数值解，正规方程通过解析公式一步求解。当特征数量较少时，正规方程速度更快；当特征数量达到数千上万时，梯度下降更具效率。此外，对特征进行标准化也有助于加速求解。

### 5.1.1 简单线性回归

简单线性回归使用最小二乘函数，即线性回归方程，来刻画一个或多个自变量与因变量之间的关系。该函数由若干回归系数线性组合而成。一个自变量的线性回归方程对应一条直线。

线性回归试图学习 f(x_i)=w x_i + b，使得 f(x_i)≈y_i。确定 w 和 b 的关键在于衡量 f(x) 与 y 的差异。

使 E_{(w,b)} = Σ_{i=1}^m (y_i - w x_i - b)^2 最小化的过程称为线性回归的最小二乘参数估计。对 E_{(w,b)} 分别对 w 和 b 求偏导得

∂E_{(w,b)}/∂w = 2( w Σ_{i=1}^m x_i^2 - Σ_{i=1}^m (y_i - b) x_i )   (5-1)

∂E_{(w,b)}/∂b = 2( m b - Σ_{i=1}^m (y_i - w x_i) )   (5-2)

令式 (5-3) 和式 (5-4) 为零可得到 w 和 b 的最优闭式解

w = [ Σ_{i=1}^m y_i (x_i - x̄) ] / [ Σ_{i=1}^m x_i^2 - (1/m)( Σ_{i=1}^m x_i )^2 ]   (5-3)

b = (1/m) Σ_{i=1}^m (y_i - w x_i)   (5-4)

式中，x̄ = (1/m) Σ_{i=1}^m x_i 为 x 的均值。

### 5.1.2 多变量线性回归

一元线性回归研究因变量与单一自变量的关系，但在实际问题中，影响因变量的自变量往往是多个。给定数据集 D = { (x_1, y_1), (x_2, y_2), ⋯, （x_m, y_m）}，其中 x_i = (x_i1; x_i2; …; x_id)， y_i ∈ R，样本由 d 个属性描述。此时我们试图学得 f(x_i)= w^T x_i + b，使得 f(x_i) ≈ y_i，称为多变量线性回归。

若将 w 和 b 以向量形式表示 ŵ = (w; b)，则形成多元一次函数。相应地，把数据集 D 表示成一个 m×(d+1) 大小的矩阵 X

X = ⎛ x11 x12 … x1d 1 ⎞   ⎛ x1^T 1 ⎞

    ⎜ x21 x22 … x2d 1 ⎟ = ⎜ x2^T 1 ⎟

    ⎜  :   :   …  :   : ⎟   ⎜  :   : ⎟

    ⎝ xm1 xm2 … xmd 1 ⎠   ⎝ xm^T 1 ⎠   (5-5)

再把标记写成向量形式 y = (y1, y2, …, ym) 有

ŵ* = argmin_ŵ (y - X ŵ)^T (y - X ŵ)   (5-6)

令 E_ŵ = (y - X ŵ)^T (y - X ŵ)，对 ŵ 求导得

∂E_ŵ / ∂ŵ = 2 X^T (X ŵ - y)   (5-7)

令式 (5-7) 为零，可得 ŵ 最优解。当 X^T X 为满秩矩阵或正定矩阵时，令式 (5-7) 为零可得

ŵ* = (X^T X)^{-1} X^T y   (5-8)

因此，线性回归模型为

f( x̂_i ) = x̂_i^T (X^T X)^{-1} X^T y   (5-9)

式中，x̂_i = (x_i; 1)，l=1,2,…,m。当线性模型的预测值逼近真实标记值 y 时，就得到了线性回归模型 y = w^T x + b。

下面使用 Python 语言对线性回归进行实现。

### 5.1.3 梯度下降法

梯度下降法是一种常用的最优化算法，也称最速下降法，常用于机器学习和人工智能领域，用以迭代逼近最小误差模型。算法从高点出发寻找通向低点的最佳方向，不断下降直至到达最低点。

当函数定义域和值域都在实数域时，导数可表示函数曲线上切线的斜率，也反映函数在该点的变化速率。在一元函数中自变量唯一，变化方向单一，故无偏导数；偏导数涉及至少两个自变量，描述多元函数沿不同坐标轴的变化速率。

如果 z=f(x,y)在点 P(x,y)可微，则函数沿任一方向 l 的方向导数存在，且有

∂f/∂l = ∂f/∂x cosφ + ∂f/∂y sinφ   (5-10)

式中，φ 为 x 轴到方向 l 的转角。
