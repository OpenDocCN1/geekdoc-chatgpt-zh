## 3.13 布尔三剑客：and、or、not

比较运算符（`> < >= <= == !=`）构建基础条件（如 `grade >= 60`）。组合复杂条件，靠这三位。

### or：一真即真

只要一个达标即通过。示例：学期均分≥90 **或** 期末≥90 视为优秀：
[PRE15]
子条件：
- `semester_average >= 90`
- `final_exam >= 90`

注意：`and` 优先级高于 `or`。真值表：

| 表达式 1 | 表达式 2 | 结果 |
|---|---|---|
| False | False | False |
| False | True | **True** |
| True | False | **True** |
| True | True | **True** |

### 短路求值：性能隐形加速器

- `and`：一旦遇 `False` 即停，后续不算。
- `or`：一旦遇 `True` 即停，后续不算。

实例 `[PRE16]` 中，`gender != 'Female'` 直接定局为 `False`，`age` 根本不看；同理 `[PRE17]` 中，学期均分达标即宣判 `True`，期末成绩免查。

**最佳实践**：
- `and` 链：把**最可能为 False** 的条件前置。
- `or` 链：把**最可能为 True** 的条件前置。
可显著减少无效求值，提升吞吐。

## 3.14 数据科学入门：三大“中心”指标——均值、中位数、众数

描述性统计的核心任务：用单一数值概括一组数据的“典型水平”。三大度量各有所长：
- **均值**：算术平均，全员参与，极值敏感。
- **中位数**：有序序列正中值，抗干扰能力强。
- **众数**：最高频值，适用离散/分类数据。
