**一个经典的“失真”翻译案：**
早期机器翻译曾闹出笑话——
原文：*The spirit is willing, but the flesh is weak.*（心有余而力不足）

## 第一节 知识表示

人类用语言、图像、公式、定理交流知识，但计算机需要**形式化、可计算**的表示法。将知识转化为机器可存储、可处理的结构，即“知识表示”。

经过数十年探索，学界沉淀出多种主流范式：一阶谓词逻辑、产生式规则、语义网络、框架、特征向量、与或图、黑板结构、Petri网、神经网络等。下文精选三大经典范式，带你领略知识“结构化”的奥秘。

### 一、一阶谓词逻辑：严谨的“逻辑骨架”

一阶谓词逻辑（FOL）是基础且通用的表示法，既能描述事实（状态、属性、概念），也能刻画确定性规则。

#### 知识驿站：核心概念速览

**概念**
思维基本单元，反映事物本质属性。如：首都、学校、家庭、工作。

**命题**
逻辑学中表达判断的陈述句，承载语义。如“大熊猫是动物”。
在谓词逻辑中，命题由**谓词**承载。形式：`P(x1, x2, ..., xn)`，`P`为谓词名，`xi`为个体。
例：“李梅是学生” → `student(Limei)`。因个体均为常量，故称“一阶”。

**逻辑连接符：**
- `¬` 非
- `∧` 与
- `∨` 或
- `→` 蕴涵（规则性知识：“若x则y”记为 `x→y`）

**建模三步走：**
1.  **定义：** 明确谓词与个体含义。
2.  **赋值：** 给个体赋具体值。
3.  **组合：** 用连接符串联谓词，生成公式。

### 二、产生式规则：专家系统的“核心引擎”

产生式规则是专家系统最爱用的范式，擅长条件判断、因果推演。

**基本式：** `P → Q` 或 `IF P THEN Q`
- **P（前件/条件）：** 谓词、关系式、真值函数均可。
- **Q（后件/行动）：** 结论或操作指令。

**关键区别：** 看似同谓词逻辑 `x→y`，实则不同。
- 谓词逻辑 `x→y`：仅表**确定性**规则（x真则y必真）。
- 产生式 `P→Q`：兼容**不确定性**。可带置信度，如 `IF 咳嗽 AND 发烧 THEN 感冒 (CF=0.8)`，意为“满足条件，有80%可能得结论”。

**规则链：** 一条规则的结论可作另一条规则的前提，串联成**产生式系统**，协同解题。

### 三、语义网络：贴近人类认知的“知识地图”

语义网络用**有向图**建模实体关系，节点承载实体/属性/事件，有标签的边描述关系。表达力强，极具自然性、灵活性。

**最小单元——语义基元：** 三元组 `(节点A, 边, 节点B)`。[PRE15]

#### 从零构建一张网

以表6-1八条事实为例，抽取主谓宾，映射为语义基元 [PRE16]，再合并同名节点（如“猫”、“梅梅”、“双肩包”），即得完整语义网络拓扑图 [PRE17]。

| 原始语句 | 主语 | 宾语 | 关系 |
| :--- | :--- | :--- | :--- |
| 梅梅有一只猫 | 梅梅 | 猫 | 有一只 |
| 猫是一种动物 | 猫 | 动物 | 是一种 |
| 李强是共青团员 | 李强 | 共青团员 | 是一员 |
| 梅梅比李强小 | 梅梅 | 李强 | 比较 |
| 桌子旁边有一把椅子 | 桌子 | 一把椅子 | 相邻 |
| 双肩包在椅子上 | 双肩包 | 椅子 | 在上面 |
| 双肩包是李强的 | 双肩包 | 李强的 | 属于 |
| 双肩包是蓝色的 | 双肩包 | 蓝色的 | 颜色 |

#### 关系层级解析

- **一元关系 `P(x)`：** 单实体属性。如“双肩包蓝”、“燕子会飞”。网络中：节点A=实体，节点B=属性，边=关系。对应图6-2(h)。
- **二元关系 `P(x,y)`：** 双实体关联。语义网最擅长此类。如“梅梅有猫”、“包在椅上”。
- **多元关系 `P(x1...xn)`：** 多实体交织。通常拆解为多个一/二元关系组合表示。

#### 优劣势剖析

**四大优势：**
1.  **直观：** 节点连接清晰可视。
2.  **拟人：** 强调语义联想，符合认知习惯，自然语言转换易。
3.  **普适：** 覆盖面极广，几乎能表示其他方法能表示的所有知识。
4.  **结构化：** 显式呈现属性与语义链接。

**三大短板：**
1.  **推理规则模糊：** 难保推论严格有效。
2.  **规模灾难：** 节点爆炸、网络复杂时推理瘫痪。
3.  **表达受限：** 不擅长判断性知识与深层因果知识。
