研发大模型对数据采集、算力投入和资金规模的要求都非常高，这就导致只有资本雄厚、数据和技术积累领先的大厂才有能力自建模型，容易形成头部企业垄断技术格局。而把模型开源，就能让不同行业、不同规模的企业都参与进来，共同推动大模型及整个 AIGC 生态的发展。开源还能避免重复造轮子，让各方把精力集中在大模型的优化和应用探索上。

#### 2. 数据保护

从隐私安全视角看，开源有利于企业守护核心数据，并实现定制化训练。对多数企业来说，数据本身就是核心竞争力。采用开源方案，企业可以完全掌控数据所有权，在保护隐私的前提下把内部敏感数据用于模型训练。在做定制化训练时，开源模型还能筛掉不符合训练目标的数据，从而压缩训练成本。

#### 3. 降低成本

从算力层面看，开源能显著压缩算力开销，助力大模型普惠。做大模型和做 AIGC 产品，算力消耗主要分训练侧和推理侧两块。

训练侧，大模型预训练费用高昂，很多公司难以承受，开源模型省掉了重复预训练的投入。推理侧，模型参数越大，推理成本越高。借助开源模型做细分任务的垂直模型，可以缩小参数规模，降低企业在日常使用中的推理支出。这让中小团队也能低成本打造 AIGC 产品。

目前，开源正成为行业主流，多家公司在积极探索。其中，AI 公司 Stability AI 是开源阵营的先行者。2022 年 8 月，Stability AI 发布开源 AI 绘画模型 Stable Diffusion，用户可用它生成多种风格的绘画作品。

2023 年 4 月，Stability AI 推出新一代开源绘画模型 DeepFloyd IF。对比 Stable Diffusion，DeepFloyd IF 的能力明显提升。一是可以精准绘制文字，为招牌等中的文字做风格化和排版设计；二是能理解空间关系，按照描述中的方位、距离等生成逻辑合理且真实的场景；三是支持细节级修改，可以对已有的图像进行编辑。

上述开源绘画模型的落地，为用户体验 AIGC 功能、尝试创作提供了入口，也加速了 AIGC 的商业化进程。

### 3.3.3 AIGC 开放：xAI 开源大模型 Grok

开放式发展已成为 AIGC 产业的重要方向，谷歌、Meta 等企业都已开源自家模型。2024 年 3 月，埃隆·马斯克旗下的人工智能初创公司 xAI 正式发布开源大模型 Grok。

Grok 是一个拥有 3140 亿个参数的 MoE（Mixture-of-Experts，混合专家）模型，未针对特定应用做微调，可适配多元场景。xAI 将 Grok 开放版本放到开源社区 GitHub 后，迅速获得大量收藏和使用。

此次开源体现了马斯克对 AIGC 技术普及与创新的坚持。开源能促进全球范围的技术共享，加速 AIGC 迭代。Grok 开放后，研究人员和企业可以自由访问、使用和调整模型，有助于推动 AIGC 在教育、医疗等更多领域的落地。xAI 还同步提供了模型规格、使用指南和运行示例代码，降低了使用门槛，让更多人加入探索。

Grok 提供了一个强有力的平台，帮助研究者开辟新路径、创造新产品。这种开放姿态打破了技术壁垒，为 AIGC 的开放式发展提供助力。未来随着持续迭代和广泛使用，Grok 有望成为推动 AIGC 进步的关键力量。

# 第 4 章 商业模式：MaaS 模式构建 AIGC 商业闭环

AIGC 热度持续升温，大量企业涌入赛道。商业的本质是盈利和可持续发展，对 AIGC 企业而言，构建完整闭环和稳定盈利模式是长远发展的关键。MaaS 模式凭借独特的盈利逻辑，为 AIGC 企业提供了可行方案，获得业界认可。

不少企业依托技术优势推出各具特色的 MaaS 服务，既提升用户体验，也为 AIGC 的长期稳定发展注入动力。

## 4.1 拆解 MaaS 模式

要理解 MaaS，首先要厘清其本质和基本架构。以下对该模式的核心内容进行解析，帮助掌握其精髓。

### 4.1.1 MaaS 模式：模型即服务的商业模式

MaaS（Model as a Service，模型即服务）指把模型作为服务输出的商业模式，是科技企业可行的营收路径。科技巨头可依托技术优势打造大模型并提供付费服务；细分领域的企业则可在其之上训练专属模型，将 AIGC 能力接入自有产品。

MaaS 为下游企业提供模型训练、使用和 AIGC 产品开发支持，而上游提供模型服务的企业则通过收费形成商业闭环。

不同行业业务、技术和规则差异大，所需模型也不同。若巨头能对外提供行业化大模型，模型本身就成为一项服务。在 MaaS 下，用户可调用、开发、部署模型，无需从零研发。

例如，某科技巨头推出通用大模型，凭借大参数和海量数据训练具备强通用能力。要在细分领域落地，需进一步微调并用行业数据训练。

巨头可基于自有优势，在通用模型上构建垂直大模型并开放接口。细分企业则可作为开发者，在此基础上训练专属模型，打造个性化 AIGC 产品再面向用户。

如此，巨头可开放大模型 API 收取接入费；细分企业则以更低成本使用模型并通过微调满足自身需求。无论是巨头还是新玩家，都能从 MaaS 中获益。

### 4.1.2 基本架构：以“模型+应用”提供服务

MaaS 的落地依赖“模型+应用”架构。模型是底座，提供生成、推理、交互等基础能力；应用是落地的关键，聚焦特定场景提供个性化服务。

架构中的模型包括具备广泛通用能力的通用大模型和聚焦特定行业的行业大模型。研发应用前，通常先用行业数据训练并微调，在通用模型基础上打造行业模型，再据此构建 AIGC 应用。

例如，基于通用模型训练可得到金融行业大模型、医疗行业大模型，进而衍生出市场情绪分析、智能投顾、辅助诊疗、药物研发等应用。

在应用层面，垂直领域是 MaaS 落地主战场。目前已有大量基于大模型的 AIGC 应用在零售、制造、教育、办公等场景落地，更多行业正整合模型能力创新应用。

以拓世科技集团为例，其始终践行 MaaS 落地路径。模型侧，公司推出拓世大模型，为应用落地提供技术底座。应用侧，基于该模型在数字人和直播领域展开探索。

数字人方面，公司推出拓世 AI 数字人，可按场景定制语音，为用户提供个性化交流，适用于政务、银行等场景。直播方面，公司打造直播运营管理平台，帮助用户搭建直播电商矩阵提升收入。

基于“模型+应用”架构，MaaS 成为 AIGC 普惠的重要驱动力，简化了部署流程，重塑了 AIGC 商业价值。

## 4.2 三大盈利路径

MaaS 共有三大盈利方式：订阅收费、提供 AIGC 智能服务获利、定制化开发服务获利，三条路径已全面打通。

### 4.2.1 通过订阅收费

订阅收费是 MaaS 的典型盈利方式，ChatGPT 是代表。

ChatGPT 设免费版和付费版。OpenAI 最初推出的免费版名为研究预览版，上线一周即获近百万粉丝。截至 2023 年 1 月，活跃用户达 1 亿人次，增长迅猛但带来服务器崩溃等问题。为此 OpenAI 采取限流，如禁止云服务器访问、限制每小时提问数、高峰期排队等。

为缓解压力，OpenAI 推出订阅制付费版 ChatGPT Plus，月费 20 美元。付费用户可享受高峰期免排队、快速响应、新功能优先试用。内测版 ChatGPT Pro 月费 42 美元，提供全天可用、快速响应和优先使用新功能。

除 OpenAI 外，Jasper AI 也在尝试订阅。Jasper 基于 GPT-3 提供 AI 写作助手，可生成写作模板、广告文案、邮件和社交媒体推文等，提供多档订阅，起价每月 29 美元。

未来随着产品成熟，订阅费用或将下探，吸引更多用户。

### 4.2.2 通过提供 AIGC 相关智能服务获得收入

企业还可通过提供 AIGC 智能服务获利，微软已在实践。

2023 年 2 月，微软推出 Microsoft Teams Premium 收费服务，用于视频会议和远程协作。上线初期月价 7 美元，7 月后上调至 10 美元。该服务由 OpenAI GPT-3.5 驱动，核心功能是智能回顾，可自动生成会议纪要并标注重点，方便缺席或复盘用户。

同时，微软旗下 CRM 软件 Viva Sales 接入 OpenAI GPT 3.5，帮助销售减负。可自动回复客户问题，提供折扣或解答，并基于历史数据生成个性化文案和营销邮件。Viva Sales 月费 40 美元，为微软带来可观收入。

未来微软将持续深耕 MaaS，为用户提供更优质服务。

### 4.2.3 以定制化开发服务获得收益

提供定制化开发服务也是重要收入来源，推出 ChatGPT 后，OpenAI 的企业定制服务成为主要盈利点之一。

例如，DALL·E 是 OpenAI 的图像生成模型，可编辑和创建图像。初创公司 Mixtiles 与 OpenAI 合作，将 DALL·E 融入自有产品助力内容创作。

零售平台 Cala 也集成 DALL·E，为用户提供品牌宣传、产品构思、设计和销售的一站式服务。用户上传文本或参考图即可获得符合需求的设计图。

与 Mixtiles 相比，Cala 的商业化程度更高，细节要求更严。虽然同用 DALL·E，收费差异明显。总之同一模型面向不同需求提供不同服务，收费也不同，需求越高收费越高。

## 4.3 B 端应用：聚焦为企业用户提供服务

面向 B 端，企业可为各领域客户提供个性化 MaaS 服务，或开放 API 接口支持客户打造专属 AIGC 应用。

### 4.3.1 聚焦为行业提供行业服务

MaaS 可在多行业落地，提供多样化行业服务，重塑内容生产方式并加速运转。

营销领域，MaaS 可为 B 端客户提供定制化营销服务，支持训练专属营销模型并生成广告和方案。

在工业制造，MaaS 可贯穿多个环节推动智能化。

开发环节，开发者可借助大模型生成代码，完成重复性任务。设计环节，设计师可利用图像生成能力做三维可视化，大模型还能直接给出设计方案并点评优缺点，提供灵感。

生产制造环节，大模型可辅助工人精准设定设备参数，提供操作指引；出现故障时可快速诊断并给出解决方案，并能为多流程工艺生成参数报告供决策。

运营管理环节，大模型可解析 ERP、SRM 等系统数据，生成 AI 分析报告，并融合多系统做多维度分析，如生成 Excel 表格帮助管理者洞察工厂运营。

服务环节，大模型可提升响应效率并创造新服务形式，接入智能家居、早教机器人、智能客服提升体验，也可为抖音、微博等平台生成营销内容并实现实时互动。

在金融、医疗、法律等知识密集型领域，通用模型难以处理复杂任务。MaaS 为垂直落地提供了有效路径，企业只需调用接口并用行业数据训练即可得到个性化应用。

例如，2023 年 5 月，度小满发布金融行业垂直开源大模型轩辕。依托多年金融实践积累的研报、股票、银行等专业数据集，轩辕在名词解释、数据分析、问题解析等场景表现突出，能给出专业建议和判断。

发布后，轩辕已获上百家金融机构试用，为中小机构提供技术支持，缩小与大型机构的差距。

基于 MaaS 在 B 端的落地，越来越多的企业可借助大模型生成专属模型并集成到产品中，提升竞争力。

### 4.3.2 开放接口，为企业升级产品提供便利

拥有强大模型或 AIGC 产品的企业可开放 API 接口，助力其他企业升级。

2023 年 3 月，OpenAI 宣布全球开放 ChatGPT API，支持企业将其集成到应用和服务中。此后不少企业接入 ChatGPT 实现升级。

例如，上海耀乘健康科技有限公司旗下的 AuroraPrime 临床研究云平台已实现与 ChatGPT 对接并取得阶段性成果，如图 4-1 所示。
