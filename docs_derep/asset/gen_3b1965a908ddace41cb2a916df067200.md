# 几何实体间的距离与求交核心算法解析

### 直线、射线与线段到平面的距离计算

**直线与平面的距离**  
判断直线与平面的空间位置关系，关键在于方向向量 $\vec{V}$ 与平面法向量 $\vec{N}$ 的夹角。若二者垂直（点积为零），直线与平面平行，此时距离等于直线上任意一点到平面的距离；反之，直线必与平面相交，距离为 0。

**射线与平面的距离**  
射线引入了“方向性”约束。当射线方向向量与平面法向量不垂直时，不能直接断定相交。需采用“试探法”：分别计算射线端点 $P_0$ 与射线上另一点 $P_1$ 到平面的有向距离 $d_0, d_1$。若 $|d_0| > |d_1|$，说明射线指向平面，距离为 $|d_0|$；否则射线远离平面或平行，距离为 0。

**线段与平面的距离**  
线段计算的核心是判断两端点 $A, B$ 是否位于平面两侧。构造平面判别式 $f(x,y,z) = A(x-x_0)+B(y-y_0)+C(z-z_0)$，代入端点得值 $f_1, f_2$。
*   若 $f_1 \cdot f_2 \le 0$，线段穿过平面或端点在平面上，距离为 0。
*   若 $f_1 \cdot f_2 > 0$，线段完全在平面一侧，取两端点到平面距离的较小值。

### 2.5.2 实体求交：线线与线面

#### 1. 两直线求交（共面前提）
已知共面直线 $l_1(P_1, \vec{V_1})$, $l_2(P_2, \vec{V_2})$，设交点为 $P$。利用参数方程 $P = P_1 + t_1\vec{V_1} = P_2 + t_2\vec{V_2}$，移项得向量方程组：
$$P_1 - P_2 = t_2\vec{V_2} - t_1\vec{V_1}$$
这是一个三维向量方程，展开为三个标量方程。任选两个方程组成线性方程组求解 $t_1, t_2$（可借助 Mathematica 等工具）。
*   **分母非零**：解得参数，代回得交点坐标。
*   **分母为零**：尝试换另外两个方程求解；若仍为零，则两直线平行，无交点。

#### 2. 两线段求交
将线段视为有限长度的直线。设线段 $S_1(A_1, B_1)$, $S_2(A_2, B_2)$，单位方向向量 $\vec{V_1}, \vec{V_2}$，长度 $L_1, L_2$。沿用直线求交法得到参数 $t_1, t_2$ 及交点 $P$。
**判定准则**：仅当 $0 \le t_1 \le L_1$ **且** $0 \le t_2 \le L_2$ 时，交点落在两线段内部，判定相交；否则不相交。

> **扩展**：直线/射线/线段两两组合的求交，均可归结为求解参数 $t_1, t_2$ 后，依据各自参数定义域（如射线 $t \ge 0$，线段 $0 \le t \le L$）进行判断。

### 2.5.3 线面求交

**直线与平面**  
直线 $l(P_0, \vec{V})$, 平面 $\alpha(P_1, \vec{N})$。设交点 $P = P_0 + t\vec{V}$。因 $P$ 在平面上，向量 $\vec{PP_1} \perp \vec{N}$，即 $(P_0 + t\vec{V} - P_1) \cdot \vec{N} = 0$。
解得参数：
$$t = \frac{(P_1 - P_0) \cdot \vec{N}}{\vec{V} \cdot \vec{N}}$$
*   分母 $\vec{V} \cdot \vec{N} = 0$：直线平行平面，无交点（或线在面上）。
*   分母非零：代入 $t$ 求得唯一交点。

**射线/线段与平面**  
复用直线求交结果，得到参数 $t$ 后，按定义域裁剪：
*   射线：要求 $t \ge 0$。
*   线段：要求 $0 \le t \le L$（$L$ 为线段长度）。

### 2.5.4 XY 平面内点与多边形位置关系

经典**射线法**判定点 $P$ 与多边形关系：从 $P$ 向 $+\infty$ 发射射线，统计与多边形边界的交点数（穿过次数）。奇数为内，偶数为外。实现难点在于**顶点重合**与**边重合**的临界情况处理。

#### 算法优化策略：拆分求交逻辑
将射线与多边形求交拆解为两类原子操作，彻底规避重复计数：

1.  **射线与开线段（不含端点）求交**  
    求解参数 $t_1$（射线）, $t_2$（线段）。  
    *   $t_1 = 0$：点在多边形顶点/边上，直接判定“在边上”，算法终止。
    *   $t_1 > 0$ 且 $0 < t_2 < L$：有效穿过，**计数器 +1**。

2.  **射线与多边形顶点求交（处理射线穿过顶点的情况）**  
    统计所有端点落在射线上的边。若某边与射线共线，视其两端点均不在射线上（避免重复）。
    *   **配对原则**：将落在射线上的边按“位于射线上方/下方”分组。任取一条上方边与一条下方边配对，**计数器 +1**（相当于穿过 1 次）。同侧边配对视为穿过 0 或 2 次，**不改变奇偶性**。

#### 射线方向的工程化选择
为简化“点与射线相对位置”判断，固定射线方向为 **X 轴正向**。此时只需比较点的 Y 坐标与射线起点 Y 坐标即可完成上下侧判定，极大降低计算复杂度。

> **复杂度**：整套流程仅需遍历一次顶点/边，时间复杂度 **O(n)**（n 为顶点数）。

### 2.5.5 几何算法模块工程落地：`GeomAlgo.py`

封装上述算法为工具类，核心接口设计如下（节选）：

```python
# GeomAlgo.py - 几何算法核心模块

import math
epsilon = 1e-6  # 全局容差

def nearZero(x):
    """判零容差处理"""
    return math.fabs(x) < epsilon

def distance(obj1, obj2):
    """实体距离计算总入口（多态分发）"""
    
    # 情况 1: 点 到 直线
    if isinstance(obj1, Point3D) and isinstance(obj2, Line):
        P, Q, V = obj2.P, obj1, obj2.V
        t = P.pointTo(Q).dotProduct(V)  # 投影参数
        R = P + V.amplified(t)          # 垂足
        return Q.distance(R)

    # 情况 2: 点 到 射线
    elif isinstance(obj1, Point3D) and isinstance(obj2, Ray):
        P, Q, V = obj2.P, obj1, obj2.V
        t = P.pointTo(Q).dotProduct(V)
        if t >= 0:                      # 垂足在射线上
            R = P + V.amplified(t)
            return Q.distance(R)
        return Q.distance(P)            # 垂足在反向延长线上，取端点距离

    # ... 此处省略 Point-LineSegment, Line-Line, Line-Plane 等其它重载分支
    
    raise TypeError("Unsupported geometry types for distance calculation")
```

**设计要点**：
*   **统一入口**：`distance(obj1, obj2)` 通过 `isinstance` 动态分发，对外屏蔽几何类型细节。
*   **数值鲁棒性**：所有判零、比较均引入 `epsilon` 容差，避免浮点误差导致逻辑崩塌。
*   **向量运算封装**：依赖 `Point3D`、`Vector3D` 的 `dotProduct`、`amplified`、`distance` 等基础运算，保持代码语义清晰。
