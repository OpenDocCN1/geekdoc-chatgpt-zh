# AI与法学习书单：核心书目与必读论文精选

## 奠基之作：专著与教材篇

2018年，上海人民出版社推出了三本重量级译著：乌戈·帕加罗的《谁为机器人的行为负责》（张卉林、王黎黎译）、约翰·弗兰克·韦弗的《机器人是人吗？》（刘海安、徐铁英、向秦译），以及瑞恩·卡洛、迈克尔·弗鲁姆金、伊恩·克尔合著的《人工智能与法律的对话》（陈吉栋、董慧敏、杭颖颖译）。同年，中信出版社引进克里斯多夫·库克里克的《微粒社会——数字化时代的社会模式》（黄昆、夏柯译）。

基础法学教材方面，北京大学出版社与高等教育出版社联合出版了魏振瀛主编的《民法》（2017版），法律出版社出版王利明等著《民法学》（2017版）。人工智能通识读物中，中国人民大学出版社2017年出版了玛格丽特·博登的《AI：人工智能的本质与未来》（孙诗惠译）及腾讯研究院编著的《人工智能》；中信出版集团同年推出李彦宏等《智能革命：迎接人工智能时代的社会、经济与文化变革》与吴军《智能时代：大数据与智能革命重新定义未来》（2016版）；文化发展出版社出版李开复、王咏刚《人工智能》（2017版）；人民邮电出版社出版徐曦《机器 70 年：互联网、大数据、人工智能带来的人类变革》（2017版）；中信出版社还引进了卢克·多梅尔《算法时代：新经济的新引擎》（胡小锐、钟毅译，2016版）与尼古拉斯·卡尔《玻璃笼子：自动化时代和我们的未来》（杨柳译，2015版）。西安交通大学出版社2015年出版I.R.诺巴克什《机器人与未来》（刘锦涛、李静译）。中国社会科学出版社2014年出版高新民、付东鹏《意向性与人工智能》。机械工业出版社有柴玉梅、张坤丽主编《人工智能》（2012版）及刘凤岐编著《人工智能》（2011版）。中国政法大学出版社2012年出版约翰·奇普曼·格雷《法律的性质与渊源》（马驰译）。科学出版社2011年出版董军《人工智能哲学》。清华大学出版社2009年出版劳伦斯·莱斯格《代码 2.0：网络空间中的法律》（李旭、沈伟伟译）。国防工业出版社2007年出版史忠植、王文杰编著《人工智能》。机械工业出版社2006年出版卢格尔《人工智能：复杂问题求解的结构和策略》（史忠植、张银奎、赵志昆等译）。天地出版社2005年出版艾萨克·阿西莫夫《机器人短篇全集》及《机器人与帝国》（均为汉声杂志译）。中国政法大学出版社2005年出版H.L.A.哈特、托尼·奥诺尔《法律中的因果关系》（张绍谦、孙钱国译）。法律出版社2003年出版卡尔·拉伦茨《德国民法通论（上册）》（王晓华等译）。社会科学文献出版社2001年引进曼纽尔·卡斯特《网络社会的崛起》。上海译文出版社2001年出版玛格丽特·博登《人工智能哲学》（刘西瑞、王汉琦译）。法律出版社2000年出版迪特尔·梅迪库斯《德国民法总论》（邵建东译）。新华出版社2001年出版安东尼·吉登斯、克里斯多弗·皮尔森《现代性-吉登斯访谈录》（尹宏毅译）。中国法制出版社2000年出版王卫国《过错责任原则：第三次勃兴》。商务印书馆1999年出版拉·梅特里《人是机器》（顾寿观译）。
