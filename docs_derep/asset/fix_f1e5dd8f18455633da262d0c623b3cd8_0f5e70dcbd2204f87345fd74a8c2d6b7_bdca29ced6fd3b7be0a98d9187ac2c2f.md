## 3.1 神经网络运行机理

神经网络借鉴生物神经系统的联结方式，构建了一种用于信息处理的计算框架。如图 3.1 所示，众多处理单元即神经元通过可调节的连结强度相互交换信号，从而对输入进行加工、分类等操作。

常见架构通常包含三类层级。图 3.2 示意了一个典型的三层形态。输入侧负责承载原始样本，每一个单元对应一个特征维度；中间层一般部署多个单元，用于从原始表征中提炼更抽象的高层特征；输出侧则依据中间层的输出完成分类、回归等任务。

[PRE1]

训练多借助误差回传机制展开。训练样本送入模型后，依据预测结果与真实标签的差距构建损失，再让误差沿网络逆向流动驱动连结强度更新，使损失逐步下降。训练收敛后，模型即可泛化到新数据。

面向自然语言处理的神经网络，是把文本转为可计算的数值表示来解决 NLP 任务的一类模型族。核心目标是把自然语言转化为数学形式，进而实现文本分类、情感判别、机器翻译、命名实体识别等应用。

这类模型的关键在于词向量，即把词汇映射到语义空间，位置关系反映词义相近程度。最具代表性的方案是 Word2Vec，它借助神经网络把词投射到低维空间，使语义相近的词在空间中距离更近。

除词向量外，还会搭配循环结构、长短期记忆结构以及注意力等机制对序列建模，捕捉上下文依赖，提升任务效果。

训练上最常用的是误差回传，通过最小化损失来优化参数。配合优化器时，常使用随机梯度下降与自适应矩估计等方法加速收敛。

## 3.2 卷积神经网络概览

卷积神经网络是深度学习中应用最广的深度前馈模型之一，可视作含卷积计算的深层网络，是深度学习的代表范式。

CNN 通过在输入上滑动固定窗口捕捉局部模式，从而识别更复杂的结构。早期在图像识别上成效显著，后也被验证在自然语言处理中有效。在文本场景，卷积操作基于词向量进行，与图像不同，文本卷积核通常覆盖若干连续词向量，核宽常与输入一致，能够捕捉多词组合特征并共享权重。相较传统方法，CNN 可自动学习表征，无需人工设计特征，提升效率与灵活性。加入丢弃与正则化等手段后，还能抑制过拟合，增强泛化。

在 NLP 中，CNN 主要用于文本分类与文本表示学习。分类任务里，常采用一维卷积核，长度多为 3、4 或 5，对词向量序列进行卷积，将相邻词组合并抽取特征。随后通过池化压缩为固定长度的向量，再送入分类器，效果普遍优于传统词袋方法。

表示学习方面，CNN 可用于学习词向量，也可学习句段级向量。多尺度卷积即多通道设计，能从不同粒度提取信息，得到更丰富的表征。训练中自适应权重共享可减少参数量，避免过拟合。

除一维卷积外，还有 TextCNN、Deep Pyramid Convolutional Neural Network 等多尺度模型，在分类与表示学习上表现良好。下面介绍 NLP 中 CNN 的基本原理。

### 1. 词嵌入原理
词嵌入把每个词映射为低维空间中的向量，用以保留语义信息，便于后续处理。

最常用的是 Word2Vec，这是一种基于神经网络的嵌入模型。Word2Vec 包含 Skip-Gram 与 CBOW 两种变体。Skip-Gram 以单个词为中心预测上下文，CBOW 以上下文预测中心词。

除此之外，还有 GloVe、FastText 等方法，它们基于共现统计或神经网络，在大规模语料上训练，将词映射为低维向量，提升任务精度与效率。

### 2. 卷积层解析
卷积层多采用一维卷积，每个核可捕捉一词或多词的局部特征，如相邻词或关键短语。

例如，如图 3.3 所示，若输入文本为“the country of my birth”，用大小为 2 的卷积核可捕捉“the country”“country of”“of my”“my birth”等邻近特征。卷积输出通常进入激活函数如 ReLU、tanh 等，进一步提炼特征。

### 4. 全连接层
全连接层将池化后的输出映射为最终预测。在 NLP 中，通常叠加一个或多个全连接层，并用 softmax 将输出转为概率分布，实现文本分类等任务。

例如，可把固定长度向量作为输入，经多层全连接逐步映射为文本表示。在生成时，可通过随机采样或贪心策略获得每个词的概率分布，再据此选择最可能的词进行续写。

卷积网络在深度学习发展中发挥关键作用，并在多领域普及。回顾计算机视觉史，研究长期聚焦于人工设计鲁棒特征提取方法。卷积网络的出现摆脱了手工特征，提供自动生成特征的途径，因而应用广泛。

## 3.3 Word2Vec 经典词嵌入

Word2Vec 是一种经典的词嵌入模型，能够把词表中的每个词表示为低维向量。

ChatGPT 基于 Transformer 语言模型，预训练阶段使用的是 Transformer 中的自注意力机制，而非 Word2Vec。

在微调阶段，ChatGPT 会使用词嵌入技术以更好地表达输入文本的语义。该阶段把每个词转为词向量，并通过学习词向量到下一个词的概率分布来训练模型。这些词向量可通过多种方式获得，其中一种即 Word2Vec。

在自然语言处理中，计算机难以直接处理文字系统，因此需要把文本转为易处理形式。Word2Vec 由 Google 于 2013 年提出，基本思想是通过神经网络学习词间关系，把每个词转为向量。训练时相似词在向量空间中更近，不相似词更远。它是 NLP 重要技术。Word2Vec 的词嵌入过程可捕捉语义与语法信息，并用于情感分析、垃圾邮件检测、机器翻译等任务。

Word2Vec 包含连续词袋模型 CBOW 与 Skip-Gram 模型，如图 3.5 所示。CBOW 由上下文预测中心词，Skip-Gram 由中心词预测上下文。

[PRE6]

ChatGPT 在微调阶段使用类似 Skip-gram 的方式训练词向量，并把预训练的词向量作为输入不断调整，以适应特定任务。下面详细介绍两种模型。

### 3.3.1 连续词袋模型
连续词袋模型 Continuous Bag of Words CBOW 常用于词嵌入，是 Word2Vec 的一种，主要用于把自然语言中的词转为向量表示。

CBOW 的思路是依据窗口内的上下文词预测中心词。输入层为窗口内的上下文词，输出层为中心词，中间隐藏层为词向量层，用于把上下文词转为向量并加权平均，得到中心词的向量表示。

具体流程是先构建词典，把每个词映射为唯一整数。然后以每个词的 one-hot 编码为输入，经全连接隐藏层得到词向量。在隐藏层中，可通过加权平均组合窗口内的词向量，得到中心词的向量表示，最后送入输出层训练。

以“我喜欢吃苹果”为例，若上下文窗口大小为 2，则 CBOW 的输入为“我吃苹果”，输出为“喜欢”。

训练时，每个词被表示为向量，上下文词向量取平均得到上下文表示，用作预测中心词的输入，从而学习词的嵌入。

与 Skip-Gram 相比，CBOW 训练更快，对高频与低频词处理较好。得到的词向量能较好保留语义信息，可用于聚类、分类等，在大规模语料上很受欢迎。

CBOW 也有不足，例如忽略词序，对需要考虑顺序的任务表现可能较弱。此外，对生僻词效果有限，因其出现次数少，很难获得准确向量。

### 3.3.2 Skip-Gram 模型
Skip-Gram 是 Word2Vec 中的一种，基于神经网络的词向量表示方法，能把词转为向量。与 CBOW 相反，其目标是最小化预测上下文词与真实上下文词的差异，用当前词预测上下文词。Skip-Gram 相较其他模型训练效果更好、速度更快。

其基本结构是一个浅层前馈网络。每个词有两个向量，一个是输入层的 one-hot 编码向量，一个是输出层的特定维度向量即词向量。训练时，每个词被表示为固定维度的向量，目标是通过拉近输入词与输出词的距离来学习这些向量。具体实现常采用负采样来降低计算量，即在训练时随机选取一些非上下文词作为负样本，把输入词与正负样本一起送入模型训练。

以 The quick brown fox jumps over the lazy dog 为例，每个词都被表示为一个独特的词向量。现在要训练 Skip-Gram 模型，让中心词“fox”与其上下文关联。

在 Skip-Gram 中，需要确定窗口大小以确定与中心词相关的上下文。窗口大小设为 2，则“fox”的上下文为“quick”“brown”“jumps”“over”。

对这些上下文词在词表中找到其词向量作为输入，目标是训练网络，使其能以中心词的词向量预测上下文词的词向量。

把中心词“fox”的词向量输入网络，网络输出每个上下文词的概率分布。训练时希望该分布使上下文词的概率最大化。

可用交叉熵损失比较预测概率分布与实际上下文词的 one-hot 概率分布，并尝试最小化差异。通过多次迭代优化权重和偏置，使其能准确预测给定中心词的上下文词。

训练完成后，可用得到的词向量表示词，并用于各类 NLP 任务。

Skip-Gram 的优点是可以处理大量语料库，获得更准确的词向量表示。由于词向量间的余弦相似度可衡量语义关系，Skip-Gram 在文本分类、情感分析、机器翻译等 NLP 任务中得到广泛应用。

## 3.4 循环神经网络机制

循环神经网络 RNN 是一种经典的神经网络结构，被广泛应用于序列数据处理，如自然语言处理、语音识别等。与传统神经网络不同，RNN 能对序列逐个元素处理，同时保留上一步的信息，适用于具有时间顺序、逻辑顺序或其他顺序的序列数据。因为它能有效挖掘数据的时序和语义信息，深度学习模型在语音识别、语言模型、机器翻译、时序分析等语言处理问题上因此取得突破。

与前馈网络不同，RNN 的隐藏层节点之间有连接，隐藏层的输入不仅包括输入层的输出，还包括上一时刻隐藏层的输出。这种结构使 RNN 能存储历史信息并作用于后续输出。从结构上看，循环神经网络如图 3.6 所示。图中每个 A 是一个处理单元，同一结构重复使用。

RNN 的处理流程可简单描述如下：

1. 将序列数据按时间步展开，形成时间轴上的序列。
2. 对每个时间步，RNN 接收输入数据和前一时间步的隐状态，计算当前时间步的输出和隐状态。
3. 把当前时间步的输出作为下一时间步的输入，继续处理。
4. 重复步骤 2 和 3 直至完成所有时间步。
5. 最终得到整个序列的输出和最后时间步的隐状态作为序列表示。

在处理长序列时，RNN 面临梯度消失和梯度爆炸问题，即随着时间步增加，梯度值可能越来越小或越来越大，导致模型难以学习有效信息。为此提出了多种改进结构，如长短时记忆网络 LSTM 和门控循环单元 GRU 等。

## 3.5 长短期记忆网络

长短期记忆网络 Long Short-Term Memory LSTM 是一种特殊的 RNN，设计目的是解决传统 RNN 处理长序列时出现的梯度消失或梯度爆炸问题。

LSTM 的核心是门控机制，包括输入门、遗忘门和输出门。在每个时刻，LSTM 通过这些门控制信息的流动与保留，从而更好地捕捉长期依赖关系。

在 LSTM 中，隐藏状态由记忆单元 Memory Cell 和隐藏状态向量组成。记忆单元负责存储和传递信息，可视为网络的“记忆”部分；隐藏状态向量是从记忆单元中提取的抽象表示，可理解为短期“记忆”。LSTM 能记忆长期和短期信息，得益于其“门”结构，可选择性地去除或增加信息到神经元，门是一种让信息选择性通过的机制，结构如图 3.7 所示。图中三个门分别是输入门、输出门和遗忘门，其中输入门和遗忘门是 LSTM 长期记忆依赖的关键。
