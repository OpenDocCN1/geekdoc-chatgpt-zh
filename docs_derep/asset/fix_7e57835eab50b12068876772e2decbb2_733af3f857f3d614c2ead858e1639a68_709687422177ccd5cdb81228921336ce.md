#### 1.3.2 并发加速：Multiprocessing 与 Asyncio 的实践

当任务规模扩展到海量数据处理、模型训练或大规模网络抓取时，纯串行执行会拖慢整体节奏。合理搭配并行计算与异步 I/O 能明显加快完成速度。Multiprocessing 通过启动多个进程来利用多核算力，Asyncio 则借助协程高效处理大量等待型操作，比如网络请求和文件读写。

下面用两个示例分别展示这两种思路对应的典型用法。
