## 7.2 人口普查收入数据实战

### 7.2.1 Adult 数据集全景拆解

本案例采用的数据来自 UCI 机器学习库。UCI 是一个常用的科学计算数据仓库。adult.data 抽取自美国 1994 年人口普查，业内常称其为人口普查收入数据集，样本总量为 48842 条。其中年收入超过 50000 美元，即后文统称 50k 美元的人群占比 23.93%，年收入在 50k 美元及以下的人群占比 76.07%。原库已将数据拆分为 32561 条训练样本和 16281 条测试样本。目标变量是年收入是否过 50k，解释变量涵盖年龄、工作、学历、职业等 14 项关键信息，详见表 7-4。其中国别离散型变量 8 个，数值连续型变量 6 个，属于典型的分类问题，用来判断个人年收入是否超过 50k。

表 7-4 数据集变量及含义

| 属性名 | 含义 |
|---|---|
| age | 年龄 |
| workclass | 工作类别 |
| fnlwgt | 序数 |
| education | 受教育程度 |
| education-num | 受教育时间 |
| marital-status | 婚姻状况 |
| occupation | 职业 |
| relationship | 社会角色 |
| race | 种族 |
| sex | 性别 |
| capital-gain | 资本收益 |
| capital-loss | 资本支出 |
| hours-per-week | 每周工作时间 |
| native-country | 国籍 |

表 7-4 涵盖 14 个维度，信息较为全面，可支持多角度的挖掘。对整体情况做一个概括，如表 7-5。
