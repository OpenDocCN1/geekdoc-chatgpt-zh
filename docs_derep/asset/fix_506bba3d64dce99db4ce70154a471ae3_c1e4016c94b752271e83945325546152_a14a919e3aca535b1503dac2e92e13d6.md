### 4.2.1 工具概览

Visual Studio Code 是微软推出的开源编辑器，以轻量高效著称。

Cline 是为 VS Code 定制的 AI 编程助手，可接入 DeepSeek、OpenAI、Ollama 等大模型，支持代码生成、优化、自动化任务等。

主要能力包括：
- **智能补全**：依上下文给出多语言精准补全建议。
- **生成与重构**：用自然语言描述需求即可生成或重构代码，提升可读性。
- **错误排查**：实时检测并给出修复建议。
- **文件与终端**：创建编辑文件、执行终端命令并查看输出。
- **网页辅助**：打开网址、模拟访问、截屏、抓取控制台日志。
- **多模型**：兼容 DeepSeek、通义千问、OpenAI 等，可按需切换。
