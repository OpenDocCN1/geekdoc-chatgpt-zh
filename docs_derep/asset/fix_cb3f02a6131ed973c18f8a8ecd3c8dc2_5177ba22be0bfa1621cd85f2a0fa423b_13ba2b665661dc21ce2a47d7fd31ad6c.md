**2. 大语言模型的基础培养路径**

在 R1 出现之前，主流系统的常规培养往往经历三步。

（1）初始语料浸泡
先在大规模互联网文本上训练，通过预测下一个词元来习得语言结构、语境关联与基础知识。

（2）指令跟随训练
利用精心制作的数据集与任务，让系统学会遵循指令、回应问题、完成指定操作。

（3）偏好对齐训练
依据人工反馈调节行为，使输出更贴合实际需求、更准确更实用。完成这三步后，系统不仅能读懂复杂自然语言，还能逐步具备处理多样化任务的能力。

**3. R1 的差异化训练思路**

R1 虽沿用上述基本框架，但在关键环节做了独特设计。核心在于监督式精调 SFT 与强化学习式精调 RLFT 两大阶段。创新流程如图 7-9 所示。

如图 7-9 所示，R1 的训练路径如下：

① V3-Base 作为起步基座，已具备宽泛的预训练知识，但尚未针对具体任务优化。
② 在此基础上使用人工标注的 SFT 样例进行监督式精调，帮助系统更好理解任务意图。精调后得到 SFT-checkpoint，即针对特定任务优化的检查点版本。
③ 随后生成一个临时推理版本 Interim Reasoning Model，用以检验中间推理表现。
④ 再进入强化学习式精调，引入长链思维等推理样例对系统继续打磨，提升推理决策能力，并让输出更贴近人类思维习惯。最终得到 R1，一个更智能、推理能力更强的系统。

**4. R1 的核心架构与实现**

R1 的底座仍是 Transformer。

（1）分层清晰的设计
整体包含 61 层解码器块，前三层为常规 Transformer，其余均为 MoE 结构的 Transformer 模块。此种安排在保证性能的同时兼顾计算效率。简化架构见图 7-10。

如图 7-10 所示，架构重点在于 Transformer 模块的层级安排。具体如下：

• 模块 1 至 3 采用传统 Transformer，用于输入处理与特征提取，承担基础编码与信息处理。
• 模块 3 之后引入混合专家结构。MoE Transformer 会根据输入动态挑选不同的专家子网络参与计算，从而提升效率与性能，并在整体架构中显著增强灵活性与表达力。
