# 本地 WebUI + DeepSeek API 快速上手

想同时保留可视化对话和使用代码调用的能力，可以把整套流程拆成环境准备、界面启动和 SDK 调用三部分。下面的步骤直接复制即可用。

一、准备独立的运行环境
先用 Conda 新建一个干净的 Python 3.11 环境，用来隔离依赖。建好后执行初始化并刷新 shell 配置，最后切入该环境工作。

[PRE0]bash

# 创建一个名为 open-webui 的 Conda 虚拟环境，并指定 Python 版本为 3.11

conda create -n open-webui python=3.11

# 初始化 Conda

conda init

# 重新加载 shell 配置

source ~/.bashrc

# 激活刚刚创建的 open-webui 环境，进入该环境

conda activate open-webui

二、安装并运行本地界面
在刚才的环境里，通过国内源安装 Open WebUI，安装完成后执行启动命令，浏览器打开本地地址即可进入对话页面。

[PRE1]bash

pip install open-webui -i https://pypi.tuna.tsinghua.edu.cn/simple

[PRE2]bash

open-webui serve

三、用 Python 调用 DeepSeek
先装兼容 OpenAI 规范的客户端库，再用一段示例展示如何配置密钥、指定服务地址、使用 deepseek-chat 模型发送第一条问候并打印结果。

[PRE3]bash

pip install openai

[PRE4]python

import os

from openai import OpenAI

from IPython.display import display, Code, Markdown

import requests

import json

# <YOUR_DEEPSEEK_API_KEY>替换为复制的 API key 字符串

ds_api_key = '<YOUR_DEEPSEEK_API_KEY>'

#实例化客户端

client = OpenAI(api_key=ds_api_key,

                base_url="https://api.deepseek.com")

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {"role": "user", "content": "你好，好久不见!"}

    ]

)

#输出生成的响应内容

print(response.choices[0].message.content)

#输出完整的响应

print(response)

user_message = {

    "role": "user",

    "content": "你好，请介绍下你自己。"

}

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        system_message,

        user_message

    ]

)
