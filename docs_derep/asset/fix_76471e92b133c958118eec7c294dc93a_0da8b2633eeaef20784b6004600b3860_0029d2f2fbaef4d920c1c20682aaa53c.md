### 4.1 检索增强生成体系概览

本节聚焦检索增强生成整体框架，梳理其工作机理、关键构成与工程落地路径。作为把信息检索和大型语言模型生成结合的问答范式，该方案既能提升答案的准确性与信息丰富度，又能有效缓解大模型的幻觉问题，适用于知识库问答、企业智能助手等场景。

本节以搭建本地化检索增强系统为主线，逐步拆解文本转向量、文档读取与分块、向量库构建、检索策略设计以及大模型问答调用等核心环节。同时引入主流 API 模型作为生成组件，帮助读者理解检索增强框架与大模型的对接方式。

#### 4.1.1 检索增强生成速览

大型语言模型在生成文本时容易出现幻觉或不精确，主要表现为：

- 信息偏差：生成内容可能基于错误或过时的信息。
- 知识滞后：模型无法获取最新资讯，尤其在专业领域。
- 推理不足：面对复杂推理任务时，输出效率和准确度不够。

检索增强生成正是为解决这些问题而生。它先从知识库中检索与问题相关的材料，再以检索结果为依据生成回答，从而大幅提高输出的准确性和相关性。该方法加快了知识更新速度，也增强了结果的可追溯性，使其在实际应用中更可靠、更实用。

#### 4.1.2 系统核心组件

构建一个可用的检索增强系统，通常需要以下五个核心模块。

1. 向量转换模块：把文档片段映射为向量表示，为后续检索提供基础。
2. 文档读取与切分模块：负责读取原始文档并切分为便于处理的片段。
3. 数据库模块：存储文档片段及其对应的向量。
4. 检索模块：依据用户查询召回相关的文档片段。
5. 生成模块：调用语言模型，结合检索结果生成回答。

#### 4.1.3 向量化模块搭建

在自然语言处理与机器学习领域，Embedding 是把文本转换为数值向量的常用手段。通过向量表示，模型可以衡量文本间的相似度，并应用于搜索、分类、推荐等诸多场景。OpenAI 的第三代 Embedding 模型在性能、成本和多语言支持上都有明显提升。下面详细介绍该系列模型及其调用方式。

##### 1. OpenAI 第三代 Embedding 概览

Embedding 技术把文本字符串映射为浮点数列表形式的向量，通过向量距离衡量文本相关性。距离越近，表示语义越相近。

典型应用包括：

- 搜索：按相关性排序结果。
- 聚类分析：依据相似度对文档分组。
- 个性化推荐：基于内容相关性推荐信息。
- 异常检测：找出与整体相关性较低的文本。
- 多样性评估：分析文本集合的相似度分布。
- 分类任务：按文本与标签的相似度归类。

OpenAI 推出的 text-embedding-3-small 与 text-embedding-3-large 在性能上更优，并支持更多语言，分别输出 1536 维和 3072 维向量。用户还可通过设定维度参数，在保持语义的前提下优化存储与计算开销。
