### 参数与输出控制要点

- max_tokens 主要用来限定最终答案正文 content 的长度上限。默认配额是 4096 token，大约对应三千个汉字，最多可申请到 8192 token。
- 该上限不计入推理链 reasoning_content。在复杂任务里，reasoning_content 本身可扩展到 32K token，因此整段返回体量很容易超出 max_tokens 的设定。官方计划后续上线 reasoning_effort 参数，用来调节推理深度与规模。

##### 2. reasoning_content 字段说明
- DeepSeek-R1 的差异化特征是除常规答案 content 外，还会额外产出与 content 同级的推理轨迹 reasoning_content。
- 该区域以自然语言记录模型推导的中间步骤，呈现出怎样得出结论的逻辑展开，适用于需要解释过程的教学演示、分析性任务与模型评测等场景。

##### 3. 功能支持情况
- 目前已开放标准对话补全，以及处于 Beta 的对话前缀续写，前者用于常规问答，后者便于在已有片段基础上续写完整对话。
- Function Calling、结构化 JSON 输出、FIM 填空补全 Beta 暂未提供，相关字段即使传入也会被忽略。

##### 4. 调用时无效的参数
调用 deepseek-reasoner 时，temperature、top_p、presence_penalty、frequency_penalty、logprobs、top_logprobs 均会被静默忽略。为保持与 OpenAI 接口的兼容性，设置这些参数不会报错。
