## 网络输出头结构一瞥

模型末端通过 1x1 卷积将通道数映射为类别总量，经 Sigmoid 归一化输出逐像素概率。最终张量形状为 `[batch, num_ROIs, 2xMASK_POOL_SIZE, 2xMASK_POOL_SIZE, num_classes]`，直接对应分割掩码。

## 定制推理参数类

环境就绪后，首要任务是编写推理专用配置。单图测试场景下，`GPU_COUNT` 与 `IMAGES_PER_GPU` 均置 1。因沿用 COCO 预训练权重，`NUM_CLASSES` 锁定为 81（含背景）。实例化配置、打印确认后，构建模型并按名称载入 `mask_rcnn_coco.h5`。

[PRE2]python

class SimpleConfig(Config):

    # 设定名称

    NAME = "coco_inference"

    # 设定 GPU 个数，指定每张 GPU 运行的图像数

    GPU_COUNT = 1

    IMAGES_PER_GPU = 1

    # MS COCO 数据集的类别数

    NUM_CLASSES = 81

config = SimpleConfig()

config.display()

model = modellib.MaskRCNN(mode="inference", config=config, model_dir=os.getcwd())

model.load_weights("mask_rcnn_coco.h5", by_name=True)
