## 4. 基于策略迭代的强化学习算法

在无模型设定下，面对未知的马尔可夫决策过程，估算价值函数被称为无模型预测，而寻求价值最优化则称为无模型控制。人形机器人步态规划、自动驾驶的决策与路径规划等实际问题都能建模为 MDP，但通常会遇到两种情形：一是模型本身未知，只能靠经验轨迹采样；二是模型已知却因维度灾难过大而只能依赖采样求解。无论哪种情况，都能用前述的无模型控制，尤其是广义策略迭代来处理。

策略迭代由策略评估与策略提升两部分构成。前者用迭代评估算子求 V，即 V=V，后者用贪婪提升算子产生 π≥π，如图4.8 所示。广义策略迭代允许任意的评估算子与任意的提升算子组合，往往能取得更好效果。实践中，广义策略迭代的评估环节常选用价值迭代类方法，包含经典的蒙特卡洛方法；提升环节则多用 ε-贪婪。这里的 V=V 与 π=greedy(V) 可相互转换，通过价值迭代与策略迭代交替进行，最终得到等价的最优策略 π 与最优状态价值 V。

## 4.3.2 预训练大型语言模型的指令调优与 RLHF 调优

### 1. 大模型微调的通用做法

给定任务示例作为输入时，大型语言模型可被提示完成一系列 NLP 任务。然而这类模型常出现意外行为，例如不遵循用户指令、编造事实、生成偏见或有害内容 (Bender 等, 2021; Bommasani 等, 2021; Kenton 等, 2021; Weidinger 等, 2021; Tamkin 等, 2021; Gehman 等, 2020)。原因在于多数模型的目标是预测互联网上的下一个 token，并未同时满足有效且安全地遵循用户指令的要求 (Radford 等, 2019; Brown 等, 2020年; Fedus 等, 2021; Rae 等, 2021; Thoppilan 等, 2022)。因此模型并未与安全和价值观对齐。避免失控行为、生成价值对齐内容，对作为通用 AI 基础设施的大规模语言模型至关重要。

自 Leike 等 (2018) 以来，通过训练使语言模型依从用户意图已有长足进展。对齐既包括显式意图如指令遵循，也包括隐式意图如确保生成内容的真实性、不产生偏见、有毒或危害。具体标准 (Askell 等, 2021) 为：①有用或有帮助的内容生成；②诚实，不编造或误导；③无害，不对人或环境造成身体、心理或社会伤害。

下面聚焦价值对齐的预训练语言模型微调方法。图4.10 给出结合人类反馈强化学习 RLHF 的 InstructGPT 微调流程 (Ouyang 等, 2022; Christiano 等, 2017; Stiennon 等, 2020)，兼顾指令遵循与价值对齐。这里的 GPT-3.5 实际是模型集合，包含 ChatGPT、GPT-3.5-turbo、text-davinci-003 与 text-davinci-002，均源自对 code-davinci-002 的指令微调。code-davinci-002 用于代码补全下游微调，text-davinci-002 在其基础上经指令调优得到 InstructGPT。ChatGPT、GPT-3.5-turbo 与 text-davinci-003 则是从 text-davinci-002 经 RLHF 得到的版本，统称 GPT-3.5。ChatGPT 更擅长聊天，后两者以 GPT API 形式多用于非聊天 NLP 下游任务，因进一步经下游任务上下文学习，效率更高、更准确。

图4.10 由三步构成：①监督微调 SFT 训练；②奖励模型 RM 训练；③近端策略优化 PPO 强化学习优化。

该技术把人类偏好作为奖励信号来微调预训练模型。首先组建或聘请人类标注员团队，完成筛选培训，使其能对演示数据与比较数据进行标注。其次依据人类专家编写的演示提示集与通过 OpenAI GPT API 收集的用户提示集，由标注员给出期望输出构建演示集，用于监督学习基线微调得到初始监督策略。再基于更大 API 提示集的模型输出，由标注员给出排序比较构建比较集，用于训练 RM 以预测与标注员偏好一致的奖励值。最后把 RM 作为奖励函数，用 PPO 强化学习微调监督基线以最大化奖励 (Schulman 等，2017)。图4.10 说明了该流程。该方法实质是将 GPT-3.5 行为与特定人群即标注员和研究人员的偏好对齐，并非完全对齐广义人类价值。
