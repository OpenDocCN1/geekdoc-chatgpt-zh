#### 4.2.3 信息增益率

信息增益虽适用通用场景，但存在明显短板：它倾向于偏好取值较多的属性。极端情况下，若将表4-1中每个样本单独成枝（分裂为17个分支），各节点纯度虽达理论最大，但模型完全丧失泛化能力，新样本无法预测。

为规避此缺陷，引入信息增益率作为修正指标。其定义为信息增益与属性固有值（IV）之比：

$$Gain\_ratio(D, v) = \frac{Gain(D, v)}{IV(v)}$$

$$IV(v) = -\sum_{v=1}^{V} \frac{D^v}{D} \ln \frac{D^v}{D}$$

其中 $IV(v)$ 量化了属性 $v$ 自身的分布广度。以“年龄”为例，其固有值计算如下：

$$IV(Age) = -\left( \frac{7}{17} \ln \frac{7}{17} + \frac{10}{17} \ln \frac{10}{17} \right) = 0.6775$$

据此，“年龄”属性的增益率为：

$$Gain\_ratio(D, Age) = \frac{0.3970}{0.6775} = 0.586$$

经典的 C4.5 算法即采用该指标甄选最优划分属性。
