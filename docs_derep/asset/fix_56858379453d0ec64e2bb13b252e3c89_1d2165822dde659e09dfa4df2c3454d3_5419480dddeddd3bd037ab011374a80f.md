# RAG入门：先检索后生成

下面这段演示展示一套最小可用的 RAG 问答思路：先用向量检索从知识库里挑出与问题相关的片段，再把片段连同原问题一起交给生成模型产出回答。检索侧采用 Sentence-BERT 做文本向量化，生成侧使用 GPT-2 完成自然语言组织。

# 生成模块：基于检索上下文生成回答

def generate_answer(contexts, query):

    context_text=" ".join(contexts) # 将多个上下文合并

    input_text=f"背景信息: {context_text}\n问题: {query}\n回答:"

    inputs=tokenizer_generation(input_text, return_tensors="pt")

    # 使用GPT-2生成回答

    output_sequences=generation_model.generate(

        inputs["input_ids"],

        max_length=150,

        temperature=0.7,

        top_k=50,

        top_p=0.9,

        num_return_sequences=1

    )

    # 解码生成的序列

    generated_answer=tokenizer_generation.decode(output_sequences[0], skip_special_tokens=True)

    return generated_answer

# 完整RAG系统流程

def RAG_system(query):

    # Step 1: 检索模块获取相关内容

    contexts=retrieve_context(query)

    print("检索到的上下文信息:")

    for i, context in enumerate(contexts, 1):

        print(f"{i}. {context}")

    # Step 2: 生成模块生成答案

    answer=generate_answer(contexts, query)

    return answer

向量检索让 RAG 在速度和准确度上都有明显提升，具体体现在：

- 1）响应迅速：依托高效的向量化和索引结构，系统能在极短时间内定位相关片段，保证生成内容的时效。
- 2）语义对齐：文本被映射为数值向量后，即使表达方式不同，意义相近的内容也能被召回，从而提高回答的精确度。

- 4）信息扩充：一次召回可返回多条相关片段，生成侧据此综合组织答案，更好满足用户对完整性的期待。

向量检索为生成模块提供了可靠的背景支撑，让模型能够基于实际依据给出准确、相关的回答。

## 3.2 向量检索: 将文本转换为向量

向量检索是 RAG 的基础能力，决定系统能否在庞大数据中迅速锁定与用户意图相符的材料。把文本映射到高维数值空间后，相似度计算变得可量化。与传统关键词匹配不同，嵌入模型保留了语义，因此能召回字面差异但含义相近的内容。

本节先拆解向量化的原理与实现，再介绍基于距离计算的常用相似度匹配方法，最后通过实例说明如何在 RAG 中落地向量检索，为生成模块提供精准的外部信息支撑。

#### 3.2.1 文本嵌入的基本原理与技术

文本嵌入的本质是把自然语言映射为可计算的向量，理想情况下语义相近的内容在向量空间中更靠近。主流技术覆盖词级表示如 Word2Vec、GloVe，以及句级表示如 BERT、Sentence-BERT 等。基于深度学习训练的嵌入能保留丰富的语义特征，显著提升语义检索效果。

下面通过两个综合示例展示嵌入生成与相似度计算的实际做法，帮助理解向量化在检索中的落地细节，包括如何用预训练模型得到向量表示并据此检索相似文本。
