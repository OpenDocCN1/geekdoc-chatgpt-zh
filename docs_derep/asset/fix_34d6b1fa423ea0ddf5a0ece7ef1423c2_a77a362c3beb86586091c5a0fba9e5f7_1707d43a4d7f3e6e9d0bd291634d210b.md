子串匹配演示

实现一个简单的回溯匹配，先做参数有效性检查，再用双指针尝试推进。匹配失败时指针回退到下一个可能起点，成功时返回模式串首次出现的位置，否则返回 -1。

"""

**** 方法功能：判断 p 是否是 s 的子串，如果是返回 p 在 s 中第一次出现的下标，否则返回-1

**** 输入参数：s 和 p 分别为主串和模式串

"""

def match(s,p):

    # 检查参数是否合理

    if s == None or p == None:

        print("参数不合理")

        return -1

    slength = len(s)

    plength = len(p)

    # p 肯定不是 s 的子串

    if slength < plength:

        return -1

    i = 0

    j = 0

    while i < slength and j < plength:

        if list(s)[i] == list(p)[j]:

            # 如果相同，那么继续比较后面的字符

            i += 1

            j += 1

        else:

            # 后退回去重新比较

            i = i - j + 1

            j = 0

            if i > (slength - plength):

                return -1

    if j >= plength:      # 匹配成功

        return i - plength

    return -1

最长公共子串 DP 演示

用二维数组记录以对应下标结尾的最长相等后缀长度，相等时继承左上并加一，不等置零，最后根据最大值回溯得到子串。

[PRE5]
**** 方法功能：获取两个字符串的最长公共子串

**** 输入参数：str1 和 str2 为指向字符的指针

[PRE6]
def getMaxSubStr(str1,str2):

    len1 = len(str1)

    len2 = len(str2)

    sb = ""

    maxs = 0

    maxI = 0

    # 申请新的空间来记录公共子串长度信息

    M = [[0 for i in range(len1+1)] for j in range(len2+1)]

    # 通过利用通用公式写新建立的二维数组（公共子串的长度信息）

    i = 0

    while i < len1+1:

        M[i][0] = 0

        i += 1

    j = 0

    while j < len2+1:

        M[0][j] = 0

        j += 1

    i = 1

    while i < len1+1:

        j = 1

        while j < len2+1:

            if list(str1)[i-1] == list(str2)[j-1]:

                M[i][j] = M[i-1][j-1] + 1

                if M[i][j] > maxs:

                    maxs = M[i][j]

                    maxI = i

            else:

                M[i][j] = 0

            j += 1

        i += 1

    # 找出公共子串

    i = maxI - maxs

    while i < maxI:

        sb += "".join(list(str1)[i])

        i += 1

    return sb
