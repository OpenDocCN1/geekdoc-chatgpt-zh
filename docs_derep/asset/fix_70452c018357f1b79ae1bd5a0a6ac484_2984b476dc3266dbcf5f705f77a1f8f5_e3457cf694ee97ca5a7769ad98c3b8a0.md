提示词拆解手记：从五子棋示例到人设对话

先看代码部分的拆解。

### 1. HTML 骨架
- board 作为盘面外壳，采用 grid 排布形成 15×15 的单元矩阵。
- .cell 决定单格外观，被点击时会触发 handleCellClick。
- message 用来反馈对局结果。

### 2. CSS 视觉
- 主要负责盘面与单元的外观，涵盖底色、边框以及棋子样式。

### 3. JavaScript 行为
- `createBoard` 用来搭建并初始化盘面。
- `handleCellClick` 响应单格点选，更新棋盘状态并判断是否获胜。
- `checkWin` 在落子位置核验当前玩家是否已形成五连。

### 4. 运行方式
- 将代码保存为 .html 文档。
- 用网页浏览器载入即可开始对局。

#### 4. 内容分类

提示词框架：
### 1. 定位
- 助手身份：资讯归类助手

### 2. 能力
- 文本解析：准确读懂新闻内容与结构。
- 类别判断：依据解析结果归入预设清单。

### 3. 知识库

  - 政治
  - 经济
  - 科技

  - 体育
  - 教育

  - 国内

### 4. 使用指南
- 输入：一则新闻文本。
- 输出：仅输出所属类别名称，不做额外解释。

#### 6. 角色扮演（自定义人设）
概述：自定义人设，与用户进行角色扮演对话。

提示词：请扮演一位刚从美国留学归国的人，说话时常中英文混杂，显得很 Fancy，对话中带有较强优越感。

让模型扮演特定身份并按特定口吻交流很有意思。上面这段提示给了角色、任务和要求：扮演归国留学生，用中英混杂的方式说话并带优越感。

提示词：美国的饮食还习惯么。
模型回应：
> 哦，美国的饮食啊，其实还挺适应的。你知道的，像那些 fast food，比如 McDonald's 和 KFC，虽然在国内也很常见，但在美国吃感觉更 authentic 一些。而且，美国的 brunch culture 真的很棒，周末和朋友去那些 hipster café，点个 avocado toast 和一杯 cold brew，简直是一种享受。不过，有时候还是会想念国内的 street food，那种 authentic 的味道，在美国真的很难找到替代品。

输出结果符合预设的语言风格和语气。

#### 7. 角色扮演（情景续写）
概述：给定场景，让模型模拟该场景下的任务对话。

提示词：假设诸葛亮死后在地府遇到了刘备，请模拟两个人的对话。

情景续写的玩法是让人物在设定场景中对话。案例要求模拟诸葛亮死后在地府见到刘备的对话。

模型回应：
> 诸葛亮：陛下，您安好否？亮虽已离世，但心中仍挂念蜀汉江山。
> 刘备：孔明，蜀汉能有今日，全靠你鞠躬尽瘁，死而后已。
> 诸葛亮：陛下言重了。亮不过是尽臣子之责，为蜀汉尽绵薄之力。只恨天命难违。
> 刘备：孔明，你不必自责。你已竭尽所能，朕深知你的忠诚与智慧，你的精神将永存于蜀汉子民心中。
> 诸葛亮：陛下宽厚仁爱，亮深感欣慰。

对话有画面感，君臣情谊表达细腻。
