### 核心概念与基础构造

对于任意基文字集合 $S \subseteq \mathbf{GLit}$，只要 $\text{DEF}(S)$ 里不同时出现基原子 $A$ 与其补 $A^+$，我们就称 $\text{DEF}(S)$ 为**合式**的。

引入扩展程序 $\Pi^+ = \text{DEF}(\Pi) \cup \text{Contr}$。若集合 $S \subseteq \mathbf{GAtom} \cup \mathbf{GAtom}^+$ 既满足合式性，又是 $\text{DEF}(\Pi)$ 的回答集，那么 $S$ 就被称为 $\Pi^+$ 的回答集。

#### 定理 4.1.3

一个协调的基文字集 $S$ 是回答集程序 $\Pi$ 的回答集，等价于 $\text{DEF}(S)$ 构成 $\Pi^+$ 的回答集。

**证明（必要性）**  
假设 $S$ 是 $\Pi$ 的回答集，即 $S$ 为归约程序 $\Pi^S$ 的一个极小模型。因 $S$ 协调，可得 $\text{DEF}(S)$ 合式，且 $\text{Contr}$ 在 $\text{DEF}(S)$ 下逻辑封闭。依 $\text{DEF}$ 定义易见，$\text{DEF}(S)$ 满足 $(\Pi^+)^{\text{DEF}(S)}$。结合 $S$ 的极小性，$\text{DEF}(S)$ 乃是该归约的极小模型，故为 $\Pi^+$ 的回答集。

**证明（充分性）**  
对任意 $\text{DEF}(S)$，有 $(\Pi^+)^{\text{DEF}(S)} = \text{DEF}(\Pi)^{\text{DEF}(S)} \cup \text{Contr}$。设 $\text{DEF}(S)$ 为 $\Pi^+$ 的回答集，即它是该归约的极小模型。因 $\text{DEF}(S)$ 合式，推知 $S$ 协调。按 $\text{DEF}^{-1}$ 定义可验证 $S$ 为 $\Pi^S$ 的模型；再借 $\text{DEF}(S)$ 的极小性，$S$ 便是 $\Pi^S$ 的极小模型，也就是 $\Pi$ 的回答集。

$\{p(a) \leftarrow \text{not } q(a),\ p(b) \leftarrow \text{not } q(b),\ q(a),\ q^+(a) \leftarrow \text{not } q(a),\ q^+(b) \leftarrow \text{not } q(b)\} \cup \text{Contr}$。

通常，协调的经典理论将一阶语句三分：可证、可反驳（否定可证）、不可判定（两者皆非，对应不完全信息）。而传统逻辑程序演绎语义对所有前提施加闭世界假设（CWA）：无法推导的基原子视为假。这导致询问仅得“是/否”，难以直接处理不完全信息。且从过程视角看，它未给出失败询问的赋值方法，仅隐含提供否定信息，不利于逻辑程序应用。受限于一阶逻辑永真性不可判定，无有限终止算法判定 $A$ 是否为 $\Pi$ 的逻辑推论，故 CWA 通常仅用于有限失败集（即“否定即有限失败”）。对于不在该集合中的 $A$，其 SLD 消解至少含一无限分支；除非有判定无限分支的算法，否则永无法证明 $A$ 非 $\Pi$ 的逻辑推论。因此，须精确化“$A$ 不能被证明”的含义，推动了回答集程序研究，核心在于如何处理缺省否定（即否定即失败）。

## 4.2 正规回答集程序

正规回答集程序由形如  
$A \leftarrow B_1, \cdots, B_m, \text{not } C_1, \cdots, \text{not } C_n$  
的规则 $r$ 组成，其中 $A, B_i, C_j$ 均为基原子。$m=0$ 称无正体规则；$n=0$ 称经典确定程序规则。正规程序 $\Pi$ 的回答集基于确定程序稳定模型以不动点方式定义：基原子集 $S$ 是 $\Pi$ 的回答集 $\iff$ $S$ 是 $\Pi^S$ 的回答集。

正如确定程序对应经典逻辑特殊子类，正规程序亦有其缺省逻辑解释（称作与之对应的缺省理论），且正规程序回答集与其缺省理论扩张一一对应，故正规程序是缺省逻辑的特殊子类。因基本回答集程序可不变回答集地转为正规程序，回答集程序亦属缺省理论子类，这也佐证了称 $\text{not}$ 为缺省否定的合理性。

#### 定义 4.2.1

映射 $\varphi$ 将正规程序规则集映至缺省集。对任一规则  
$r = A \leftarrow B_0, \cdots, B_m, \text{not } C_0, \cdots, \text{not } C_n$，  
定义 $\varphi(r) = B_0 \wedge \cdots \wedge B_m : M \neg C_0, \cdots, M \neg C_n / A$，记为 $d_r$。$m=0$ 时 $d_r$ 为无前提缺省；$n=0$ 时为经典推理规则（即推导出前件可推出 $A$）。

对正规程序 $\Pi$，$\varphi(\Pi) = \{ d_r \mid r \in \Pi \}$，记作 $D_\Pi$，称 $(D_\Pi, \emptyset)$ 为 $\Pi$ 的**缺省表示**。于是

[PRE3]

称形如 $d = B_1 \wedge \cdots \wedge B_m : M \neg C_1 \wedge \cdots \wedge M \neg C_n / A$ 的缺省为**基础缺省**，其中 $A, B_i, C_j$ 为基原子。

显然 $D^S$ 为无检验条件缺省集，即 $\text{Ccs}(D^S)=\emptyset$。

给定正规程序 $\Pi$ 及对应缺省理论 $\Delta=(D_\Pi,\emptyset)$，对任一基原子集 $S$，令  
$\text{GD}(S,\Delta)=\{B_1\wedge\cdots\wedge B_m:M \neg C_1,\cdots,M \neg C_n/A\in D_\Pi \mid \{B_1,\cdots,B_m\}\subseteq S,\ \{C_1,\cdots,C_n\}\cap S=\emptyset\}$。

若 $S$ 为 $\Delta$ 的扩张，则 $\text{GD}(S,\Delta)$ 为 $S$ 的**生成缺省集**。进而

$\Pi=\phi^{-1}(D_\Pi)$

$\text{GR}(S,\Pi)=\phi^{-1}(\text{GD}(S,\Delta))=\{r\in\Pi \mid \text{Pos}(r)\subseteq S,\ \text{Neg}(r)\cap S=\emptyset\}$

若 $S$ 为 $\Pi$ 的回答集，则 $\text{GR}(S,\Pi)$ 为 $S$ 的**生成规则集**。

#### 引理 4.2.1

设 $\Pi$ 为确定程序，$(D_\Pi,\emptyset)$ 为其缺省表示。若文字集 $S$ 是 $\Pi$ 的稳定模型，则 $(D_\Pi,\emptyset)$ 有唯一扩张 $E=\text{Th}(S)$。反之，若 $E$ 是 $(D_\Pi,\emptyset)$ 的唯一扩张，则 $\Pi$ 有唯一稳定模型 $S=E\cap\text{GAtom}$。

**证明**  
设 $S$ 为 $\Pi$ 稳定模型，依定理 2.3.2 与 2.3.5，$S=M_\Pi=T_\Pi\uparrow\omega$。显然 $\Pi$ 的缺省表示为 $\phi(\Pi)=(D_\Pi,\emptyset)=\{B_1\wedge\cdots\wedge B_m:A \mid A\leftarrow B_1,\cdots,B_m\in \Pi\}$。依事实 III，$(D_\Pi,\emptyset)$ 唯一扩张 $E=\text{Th}(S)$。

设 $E$ 为 $\Pi$ 缺省表示的唯一扩张，依定理 3.3.1，$E=\text{Th}(\text{Con}(\mathcal{A}(D_\Pi,\Delta)))$。易归纳证 $\text{Con}(\mathcal{A}(D_\Pi,\Delta))=T_\Pi\uparrow\omega$。故 $\Pi$ 唯一稳定模型 $S=E\cap\text{GAtom}$。

#### 引理 4.2.2

设 $\Delta=(D,\emptyset)$ 为缺省理论，$D$ 为基缺省集。基原子集 $S$ 是 $\Delta$ 的扩张 $\iff$ $S$ 是 $\Delta^S=(D^S,\emptyset)$ 的扩张。
