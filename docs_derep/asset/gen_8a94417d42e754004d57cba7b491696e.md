试想一下，一张图像送进模型之后，要牵扯到成千上万甚至几百万个可调权重，如果全部靠人工去校准，根本是不切实际的。正是因为这道门槛，20世纪60年代末的学术界放弃了直接训练端到端智能系统的设想，转而深耕统计模式识别相关的应用。受感知器启发的结构虽不完美，却一直是该领域的核心范式，一直到21世纪的头几年才开始松动。那个时期的典型做法是：信号先进来，再经过人工设计好的特征提取环节加工，最后才交给感知器或其他统计学习方法组成的分类器做决策——这就是长期以来模式识别的惯用套路。

感知器的出现正式开启了监督式机器学习。系统在训练过程中会持续修正内部参数，让自己的输出不断逼近正确答案。经过充分的训练后，它还能对从未见过的样本做出合理判断，这种能力被称作泛化。

泛化能力并非没有边界。为了解决这个问题，研究者会在把数据送入传统分类器之前先做编码，通过人工提取显著特征来完成识别任务。从60年代一直到2015年，学界投入了大量精力为各种问题设计专用的特征提取器。关于这方面已发表成千上万篇论文，数以千计的研究者投身其中。我一直认为，与其为每个问题手工打造特征提取器，不如直接训练它。可很长一段时间里，这个想法都不被同行所认可，这也正是多层神经网络和深度学习长期受阻的原因。

# 第四章 让机器自我学习的方式

监督学习的底层逻辑始终未变：通过调节系统参数来降低成本函数，也就是把训练样本集中实际输出与期望输出之间的平均误差压到最小。说穿了，最小化成本函数和训练系统是同一件事。

这一规律不仅适用于只训练最后一层的感知器这样的简易模型，也适用于几乎所有的监督学习方法，特别是在端到端训练的多层神经网络上，下章会详细展开。

总的来说，以成本函数最小化为核心的学习机制是人工智能运转的关键枢纽，因而弄清它的边界，也有助于我们反思人类自身的学习方式。

## 1 成本函数

提示：训练机器的本质就是在不断调整参数。

再说一遍，学习的过程就是系统误差逐步收敛的过程。机器学习说白了就是机器不断尝试、犯错、自我修正的过程。每一次对参数的更新都会覆盖参数原先的值。拿一个带有期望输出`y`的图像`x`来说，误差就是一个数值，衡量计算机产生的输出`yp=f(x,w)`与期望输出`y`之间的距离，其中`w`是参数向量。对于每一条训练样本，即每一对（`x`，`y`），误差都由成本函数`C(x,y,w)`来度量。最常见的一种写法是取输出差值的平方：

`c=(y-f(x,w))**2`

现实里成本函数有多种形态，上述表达式仅适用于系统只产生单一输出的情形，也就是`yp`和`y`都是纯数字的情况。若希望系统从图像里分辨出狗、猫或鸟，就需要给出三个输出，形成一个向量而非一个标量。每个类别对应一个分量。例如第一分量代表“狗”，第二分量代表“猫”，第三分量代表“鸟”，那么输出向量`[0.4,0.9,0.2]`就意味着系统判定为猫，因为猫的分量最高，为0.9。在训练阶段，“狗”对应的期望输出是`[1,0,0]`，“猫”是`[0,1,0]`，“鸟”是`[0,0,1]`（见图4—1）。

[PRE0]

#### 图 4—1 三类分类器

计算机产生三个分数，每类各一个，构成一个三维向量的形式。在该示例中，机器产生的分数向量是`[0.4,0.9,0.2]`，由此将图像分类为“猫”。“猫”类所期待的输出向量为`[0,1,0]`。

成本函数的作用就是量化系统输出与期望输出的差距，比如三类输出误差平方的总和：

`yp=f(x,w)` # `yp`是一个三维向量

`c=(y[0]-yp[0])**2 +(y[1]-yp[1])**2 +(y[2]-yp[2])**2`

实际上，对于多分类问题，我们常把输出建模为类似概率的分数，使其介于0到1之间且总和为1，并使用另一种称为“交叉熵”的成本函数，它会把期望类别的输出推向1，同时把其他类别推向0。但本质原理是一致的。

## 2 找到谷底

那么成本函数的最小值该如何寻找呢？为了便于理解，先设想一个只有两个可训练参数`w[0]`和`w[1]`的系统。对某个确定的训练集来说，每一个坐标点（`w[0]`，`w[1]`）都对应一个成本值。

一开始权重是随机给定的，所以学习之前成本通常很高。随着学习进行，网络会通过调整参数来压低成本。

我们可以把这个成本函数想象成一幅山地地形图，其中一个特定地点对应一组参数，即经度`w[0]`和纬度`w[1]`，高度即该参数组对应的成本值。整个地形中，等高线把成本相同的位置连起来。

设想我们迷路了，天黑又下雨，什么都看不见。为了回到位于山谷底的村庄，在没有路标的情况下，会选择沿着坡度最陡的方向下行。先观察哪边在下坡，然后朝那个方向迈出第一步，步步为营，最终抵达谷底。在这个比喻里，坡度最陡的下行方向就是成本函数的梯度，谷底就是成本函数的最小值，对应的坐标就是使成本最小的参数。

目标是尽快找到山谷最低点。从计算资源角度看，穷举测试非常昂贵，尤其是在训练库包含数百万样本时。因此我们需要借助一种称为“梯度下降最小化函数”的方法，如今它已成为人工智能领域最常用的学习机制之一。

来理解其原理。找到最陡下坡方向的关键是计算梯度，与梯度相反的方向就是当前位置下降最快的方向。为了得到它，我们设想对参数做一个很小的扰动，以观察成本会升高还是降低。用山地作比喻，就是先往某个方向迈一小步，看海拔是下降还是上升。为了让这个尝试成立，参数的小扰动必须对应成本的小扰动，也就是要有数学上所说的“连续性”，避免出现阶梯或悬崖。

接下来依次干扰两个参数。先朝`w[0]`方向，即向东，迈一步，测量高度变化，用高度差除以步长来评估斜率`g[0]`。如果海拔下降，就继续朝该方向前进，步幅与坡度成正比，坡度越陡步子越大，越有利于快速接近目标；坡度平缓则只迈小步。若评估后发现海拔升高，就必须反向迈一步，让海拔降低，即让成本值下降。

随后转90度，沿`w[1]`方向，即向北，重复上述评估，算出斜率`g[1]`。再根据结果决定向前或向后迈与斜率成比例的步长。如此循环往复，我们会慢慢逼近谷底，直到海拔不再下降，也就是到达山谷最低点。

分量为斜率（`g[0]`，`g[1]`）的向量`g`称为梯度。图4—2展示了这个梯度向量。按定义，梯度向量指向斜率最大、海拔增加最快的方向，其长度等于该方向上的斜率值。沿着与梯度相反的方向前进，就是朝谷底移动。梯度的反方向是向量`–g`，其分量符号相反（`–g[0]`，`–g[1]`）。

[PRE5]

#### 图 4—2 学习成本函数

我们可以将成本函数与山地景观（左侧）进行比较，后者的等高线显示在右侧。训练一台机器的过程就是寻找谷底的过程，即找到产生最低成本值的可训练参数的值。在此示例中，经度和纬度是两个可训练参数`w[0]`和`w[1]`，最小值位于坐标（3，2）处。当开始训练这个系统时，我们不知道此景观的形状或其最小值的位置。但是，对于给定的参数值，我们可以计算其高度，即成本值。我们还可以计算指向最大斜率方向上的梯度向量`g`。梯度用箭头表示，在每个点上都不同。通过更改与梯度相反的方向`–g`，我们向着谷底迈出了第一步。这种修改是将向量`w`用其本身值减去梯度向量并乘以一个控制步长的常数`e`来代替，目标是通过测试，用尽可能少的配置来找到山谷底端的位置。

总结起来，梯度下降的执行步骤如下：

1. 计算当前参数向量值对应的学习成本。

2. 测量各坐标轴上的斜率，并把它们汇总成梯度向量`g`。

3. 沿着与梯度相反的方向修改参数向量。具体做法是取梯度分量的相反符号，再乘以控制步长的常数`e`。

4. 把上一步得到的向量加到参数向量上。换句话说，就是把参数向量的每个分量替换为当前值减去梯度对应分量乘以步长`e`后的结果。

5. 梯度步长的大小很关键：太小会导致每一步移动甚微，收敛缓慢；太大则可能越过最小值，落在另一侧。因此常数`e`必须取值合理。

6. 重复上述操作，直至到达谷底，也就是找到学习成本的最小值。

[PRE6]

#### 图 4—3 梯度下降法生成的路线

梯度下降的过程旨在沿最大向下倾斜的方向（与梯度相反）采取一系列的前进步骤，直至到达山谷底部。步长与梯度步长`e`成正比。右图中的`e`太大，会引起轨迹的振荡。梯度步长太大可能会导致不收敛。

**证明**

假设我们处在坐标（`w[0]`，`w[1]`）。此时海拔高度，即学习成本，为`h = L(X, Y, w)`。下面描述一种基于扰动的梯度下降过程，思路简单但效率不高。首先构造一个扰动向量`wa`，它通过对`w[0]`做一个很小的扰动`dw`得到：

`wa[0] = w[0] + dw`

`wa[1] = w[1]`

随后计算新位置的高度`a = L(X, Y, wa)`。扰动带来的高度变化为`a–h`，沿扰动方向的斜率为（`a–h`）／`dw`。计算这个比值的目的在于得到山的坡度，再用它乘以步长来估算高度变化。

同样地，我们沿`w[1]`方向扰动`w`：

`wb[0] = w[0]`

`wb[1] = w[1] + dw`

此时高度为`b = L(X, Y, wb)`，`w[1]`方向上的斜率为（`b–h`）/`dw`。把两个斜率存入向量`g`：

`g[0] = (a–h) / dw`

`g[1] = (b–h) / dw`

向量`g`就是成本函数的梯度，包含各轴上的斜率。它指向斜率最大的方向。再用山地比喻，如果东西向（`w[0]`）的坡度大于南北向（`w[1]`），最大坡度方向就会更接近东西轴。

## 3 实践中的梯度下降

在真实场景里，“地形”并非只有两个维度，而是拥有数百万甚至数十亿个维度，参数向量不是由两个数字构成，而是由数百万个数字构成。同样，梯度也拥有数百万个分量，每个分量代表学习成本函数在对应空间轴上的斜率。

`c(x, y, w) = (y - w*x)**2`

`= 2 * (x**2) * w - 2 * y * x`
