# 东方智慧与西方新声：共生思想的双重溯源与全球共鸣

当代东亚共生思想的第二大思想渊薮，在于贯穿东方哲学始终的“一体”论。

道家主张万物源于“道”而治于“道”。庄子云：“天地与我并生，而万物与我为一。”立足于道的视域，万物本无高下贵贱之分。儒家方面，张载首倡“万物一体”之说。其《西铭》言：“乾称父，坤称母……民吾同胞，物吾与也。”王夫之注解道：父母禀乾坤生成之德，即天地运行之气，造物之心即在其中，吾之形体性命与父母无异，亦即与天地无异。[PRE16]

若道儒二家侧重“我”与天地万物并生、共长，佛家则在更多层面上阐发万物一体、因果相即、互摄融摄。佛陀以种种方便法门——如因果轮回说——启迪迷悟众生。此说认为世间万法皆循因果，缘起性空，因果环环相扣，“生老死轮转，无有穷尽”。[PRE17] 故而，世间一切存在——人、动植物、矿物——不仅共存，更彼此为生存延续提供条件与支撑。在此意义上，万物一体蕴含着相即、互摄、融摄的关系。

究其根本，佛法大智所悟“万物一体”，建立于对究竟本源“佛性”或“自性”的认证。众生皆有佛性。何为自性？乃“一切法所依止之本基”，能“显现世出世间一切法，五蕴、十二处、十八界，乃至戒定慧，皆从自性功德流出”。[PRE18] 即自性具足含摄、显现、转变万法之性能。宇宙万物（含有情无情）皆是自性功用所现。由此观之，世间万物岂非“同根同源、本一体耶”？

综上，“生生”之观与“天地人一体”思想，滋养、塑造并丰富了当代共生思想。[PRE19]

廿年来，中日学者探讨人类前途，大力倡导共生理念，并将其延伸至艺术创作、建筑设计、教育、社会、政治乃至地缘政治理论。[PRE20] 日本建筑师黑川纪章，作为“新陈代谢”运动旗手及当代建筑界极具创见的思想者，毕生推崇共生哲学，引发中日广泛关注。他反对内外、人技、农城等僵化二元对立，试图在建筑作品中落实生物学与佛教带来的洞见。

台湾佛光山开山星云大师，依“万物一体”教义，长期弘扬“同体共生”思想，视为宇宙本相，主张以此增进社会凝聚、凝聚政治共识，建设“大同”世界。大师认为，“同体”蕴含平等包容，“共生”蕴含慈悲融摄。[PRE21] “同体共生”不仅关乎人际，更囊括自然与万类存在。它超越主流二元论方法论，摒弃生存竞争，反对线性进化观，肯定整体思维、价值多元与存在形态的多样化。

近年来，欧美公共知识分子亦积极倡导“共融主义”，中译“共生主义”。2013年发布《相互依存宣言》，有意对标宣扬个人主义的《独立宣言》。宣言宣示：关系性是人与自然生存之本质；确认一切生命相互关联；致阐释众生共存之哲学。[PRE22] 2018年再发宣言，指出新自由主义破产，极端个人主义、寻租与投机资本主义劣迹斑斑，共生主义应取而代之，作为后新自由主义时代的统一政治哲学。[PRE23]

欧美知识分子所倡共生主义，与中日学者所提共生思想，虽思想渊源、理论基石、语境各异，但共鸣显著：皆提醒关注人与自然、人与人之间的关联性与相互依存；皆呼吁摒弃无序个人主义与逐利至上资本逻辑；皆强调相互责任、共存制约与自我节制。或因现代性与全球化带来的挫败，终使东西方思想界距离拉近；或吾人终能觅得一份契合天地人共同的哲学共识。费孝通先生雅言：“各美其美，美人之美，美美与共，天下大同”，勾勒出一个建立在相互联结、相互尊重、共同繁荣之上的理想共生图景。[PRE24]
