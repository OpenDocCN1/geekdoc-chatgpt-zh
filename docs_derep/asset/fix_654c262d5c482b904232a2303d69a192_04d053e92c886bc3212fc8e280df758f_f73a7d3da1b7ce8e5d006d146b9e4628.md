## 6.3 本地化第二大脑：让笔记流动起来

笔记类工具的瓶颈从来不是记录能力，而是检索和关联。second-brain Skill 就是为了解决“找得到”和“连得上”而生的，它让笔记具备可检索、可关联、可复习的能力，同时数据全部留在本地，不绑定特定笔记软件，彻底摆脱平台依赖。

本节从部署配置起步，按由浅入深拆解快速捕获、自动整理、语义检索、知识图谱、间隔复习五大模块，每个模块都附带可直接套用的指令模板，替换信息即可上手，无需额外摸索。

底层原理很直白：second-brain 基于本地 Markdown 搭建，通过调用大模型接口实现智能化，无需深厚技术背景。

因此部署成本很低，只需两步：初始化配置文件，填写笔记库路径与模型密钥，全程不写代码，零基础也能完成。

【本节使用的 Skill】

Skill 名称：second-brain
资源获取：“清新研究”公众号
能力：笔记捕获、自动整理、语义检索、知识图谱、间隔复习

安装后在终端执行以下命令完成初始化，工具会自动生成配置文件，只需补全两项核心信息：

"llm": {
  "embedProvider": "openai",
  "chatProvider": "deepseek",
  "providers": {
    "openai": { "apiKey": "sk-..." },
    "deepseek": { "apiKey": "sk-..." }
  }
}
