## 6.6 项目资源分配与管理

核心目标：依据项目诉求，对人力、物力、财力等要素实施科学配置与管控，保障按期、保质、控本、在范围内交付。

### 核心要点

1.  **明确诉求**：配置前须清晰界定需求、边界与目标，以此推演所需资源类别与规模。
2.  **盘点资源**：梳理现有人力、物力、财力，评估可用性、成本与质量。
3.  **拟定方案**：结合需求与资源池，制定计划，锁定各资源的投入时点、用量与成本。
4.  **过程管控**：跟踪使用状况，确保按计划执行，杜绝重复调用与闲置浪费。
5.  **动态优化**：执行期依据进度与变更，灵活调配，确保按时、保质、控本交付。

简而言之，资源管理是成败关键，需要经理与团队紧密协同，最大化资源效能。
