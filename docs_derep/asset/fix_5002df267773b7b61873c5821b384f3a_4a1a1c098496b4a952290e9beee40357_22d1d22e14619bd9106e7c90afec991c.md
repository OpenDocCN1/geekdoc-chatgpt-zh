## 小 结

本章系统梳理了搭建 Agent 应用的不同思路与主流技术栈，并以真实案例串联。学习后能够灵活选用合适的工具搭建自己的 Agent，同时理解如何通过技术组合与持续打磨提升实用价值与表现。

第一部分以 LlamaIndex 为例，讲解从零搭建基础 Agent 应用的路径。内容涵盖环境准备、模型获取、本地 Knowledge Base 构建，以及基于知识库的问答实现。配合分步说明与代码示例，能快速把本地数据接入 Agent，为后续进阶奠基。

第二部分介绍 Swarm Framework 的用法。Swarm 专注于分布式 Agent 的编排，文中演示了接入 DeepSeek 模型并调用外部工具的完整流程，展示 Agent 如何承接更复杂的作业。重点在于各 Framework 之间的兼容与可扩展性，说明不同工具与模型如何组合放大系统能力。

第三部分聚焦两个热门开源方案 Browser Use 与 Camel。Browser Use 让 Agent 能直接操作浏览器采集与处理网页信息；Camel 则在作业调度、数据流管理上提供更多选择。两者体现了开源生态的多样性，也为想动手开发的人提供了丰富参考。

总体来看，本章既教会了用不同框架落地 Agent 的具体做法，也强调了组合优化的思路，帮助 Agent 从可用走向真正好用。
