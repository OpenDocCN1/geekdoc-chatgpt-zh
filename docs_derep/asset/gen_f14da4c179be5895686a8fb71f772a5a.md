读到这里，你很可能会有这样的疑问：既然已经把好几个模型都训练完、再拿准确率一对比挑出最强的，为什么还要再额外做一次性能评估？其实判定模型的好坏和挑选模型是两回事。

先做几组模型、训练完后比准确率，本质上是为了“选”。而测一个模型能不能在真实场景里用上，目标是“评价”。目的不同，测试的方式和严谨度也就不能混为一谈，不然就算不上合格的性能检查。

把实务里的常见要求拆开来看，就能明白什么时候需要二次评估。

第一种情形是客户说：给我用数据做几个模型，挑一个最好的就行。这种需求里，评测只服务于挑选。做一次测试、按结果选出冠军就足够了，后续不需要再验一次。

第二种情形是客户说：给我做几个模型挑最好的，同时告诉我这个模型的真实性能。这就要求对性能给出一个严谨、可信的数值。做研究时这种精度很有必要，但如果只是为了上线商用，通常不会要求到这个程度。之所以要挑完后再测，是因为我们在测试集上“挑最好的”，这个过程本身会让结果偏乐观。测试集上的表现不等于模型面对未知数据的表现。给候选模型算准确率时，数据可以重复使用；但给最终上线的模型算性能时，用过的数据必须完全排除。把在测试集上挑出来的分数直接当成模型实力是错误的。

第三种情形是客户说：按这个设定给我做一个模型，并告诉我它的性能。这种情况比较少见，相当于直接指定方案，最终只产出一个模型，自然也只需评价一次。

了解了选与评的区别后，就能明白为什么要从监督数据里提前留出验证集和测试集。不过当监督数据本身就不够多时，留数据就会让训练集捉襟见肘。这时候可以用交叉验证来绕开这个问题。

交叉验证的核心是不预先抽出验证集和测试集，而是把数据切开轮流当测试集用。以 4 折为例，常见做法是 5 折或 10 折，这里先用 4 折说明。把监督数据分成数据 A、数据 B、数据 C、数据 D，如图 31 所示。

[PRE0]

图 31 交叉检查法：无须提取确认用数据和测试用数据，即可对模型性能进行评价

做法是每次挑一折出来当测试集，剩下的三折一起训练，然后用预留的那一折测效果，再轮换。

先用 A、B、C 训练，D 不参与学习。训练完后把 D 扔进去预测，和 D 自带的答案对照，就能得到这个模型在 D 上的准确率。假设是 80%。

再用 A、B、D 训练，这次 C 被排除。训练完后用 C 测试，得到另一组准确率。

依次把 A、B、C、D 各自轮一遍，就能得到 4 次结果，如表 16。

表 16 4 组分割交叉检查

| 监督数据 | 测试用数据 | 精确度 |

| :--- | :--- | :--- |

| A、B、C | D | 80% |

| A、B、D | C | 70% |

| A、C、D | B | 80% |

| B、C、D | A | 90% |

把 4 次准确率取平均，就作为该模型的综合性能。按表 16，平均是 80%。最终上线时我们会用全部 A、B、C、D 重新训练一次模型，交叉验证相当于提前模拟了这个全量训练模型的表现。

## 怎么选对机器学习类型

到这里，我们已经介绍了监督学习、无监督学习和强化学习。虽然类型不少，但能解决的问题本质上都比较清晰，选型也并不难。

什么时候用哪一种，见表 17。

表 17 监督学习、无监督学习和强化学习的比较

| 分类 | 具备能力 | 适用场合（具体示例） |

|---|---|---|

| 监督学习 | 希望对数据进行分类时 | 希望第一时间判别新进网评的内容优劣 |

| 无监督学习 | 希望对数据进行若干分割时 | 希望将大量网评按优劣进行分组内容 |

| 强化学习 | 希望在某种状态下决定行动规则时 | 希望研发一个能够与客户产生良好互动的机器人 |

监督学习的强项是分类；无监督学习的强项是聚类、分割；强化学习的强项是学会在特定状态下做最优行动。选定类型后再挑具体算法，需要一定的专业知识，但方向感是明确的。

## 07 深度学习是怎么回事

[PRE1]

### 深度学习只是机器学习的一种实现

AI 流行后，深度学习这个词出现频率很高。它本质上是机器学习里的一种具体做法。很多人会把机器学习等同于深度学习，其实机器学习包含很多方法，深度学习只是其中一种，而且在多数场景下效果更好，未来很可能成为主流。人工智能、机器学习、深度学习的关系如图 32 所示。

[PRE2]

机器学习可以分为监督、无监督、强化三类，深度学习可以套用到这三类之上，所以不能说深度学习只属于监督学习。本书以大家最常用的监督学习来展开。

监督学习是先给计算机正确答案，让它自己总结规律。深度学习的监督学习，就是用深度学习的方式来自动发现规律。前面监督学习里标记过的操作，都可以用深度学习来替代。

深度学习让多个领域性能大跃进，其中最典型的是机器翻译。输入一段日文，自动输出英文。深度学习普及前，在线翻译就能用，但质量远达不到实用水平。深度学习出现后，准确度大幅提升。翻译这类“给定规则下答案基本唯一的任务”，深度学习特别擅长。

### 深度学习靠多层推理做判断

计算机用深度学习学到的是什么？它会做很多次、很多层次的检验，然后综合。

比如判断照片里是苹果还是橘子，系统会分别检验“右上角偏橘色”“左下角偏红色”“上方有绿色”等线索。有时还会把前面的检验结果再用来做下一步检验，例如先判断颜色，再判断表面斑点。实际的检验过程没那么好解释，但大体思路就是先分层验证、再汇总。

最终输出的是“这是苹果的概率 90%”。深度学习的精髓在于分阶段、多次验证后综合决策，从而完成非常复杂的判断。

### 深度学习源于感知机

一提到深度学习，很多人以为是近年的新发明，其实早在 20 世纪 50 年代就有了雏形，叫做感知机。

感知机的思想很简单：收到多个输入，给出一个输出。输入是数值，输出是 0 或 1。系统把输入加总后，超过阈值就输出 1，否则输出 0。输入不是直接相加，会先被加权，如图33所示。

[PRE3]

图 33 将 A、B 的输入值分别进行加权后再进行合计，合计值经 C 判定后输出 0 或 1

A、B 是输入，C 是输出。图里只有 A、B，实际可以更多。A、B 的数值沿箭头传到 C 的过程中会按权重改变。先加权再求和，C 再据此判断输出 0 或 1。

可以把权重想象成水管粗细。A 注入的水，经水管粗细改变后再流入 C，B 同样如此。流入 C 的总量决定输出。设阈值为 300ml，A 注入 150ml，B 注入 50ml，会输出 0 还是 1？

先看 A 权重 1、B 权重 2，如图 34。

[PRE4]

图 34 当 A 权重是 1，B 权重是 2 时，输出结果是 0

A 经权重 1，水量不变 150ml；B 经权重 2，水量变成 100ml。总计 250ml，未达 300ml，输出 0。

再看 A 权重 2、B 权重 1，如图 35。

[PRE5]

图 35 当 A 权重是 2，B 权重是 1 时，输出结果是 1

A 经权重 2，水量变成 300ml；B 经权重 1，水量保持 50ml。总计 350ml，超过阈值，输出 1。

可见同样输入，权重不同结果不同。深度学习要学的东西，本质上就是这些水管的粗细。

在监督学习里，监督数据记录了 A、B 的输入和 C 的正确输出。计算机不断调整权重，让输出与正确答案一致。

感知机结构极简，却奠定了深度学习的基础。

## 调整阈值的关键“偏差”

上面的例子，C 的判定条件是“达到 300ml 输出 1，否则 0”。A 权重 1、B 权重 2 时，150ml+50ml 加权后 250ml，输出 0。

深度学习学的是权重，但阈值会不会也学？输出 0 或 1 这部分是固定的，但“何时该输出 1”是可以学习的。阈值 300ml 这个部分就叫偏差。

[PRE6]

图 36 中，①代表偏差。偏差会让判定条件发生偏移。换成水的说法，就是在 C 处额外加减水量。

引入偏差后，判定条件可以写成“合计值大于 0 输出 1”。这个形式更通用。

举例，偏差设为 -300ml，即先倒掉 300ml。水经权重到 C 为 250ml，再减去 300ml，变为 -50ml，不到 0，输出 0，如图 37。

[PRE7]

图37 偏差导致水被输出时，合计值未达到0，因此输出为0

实际上“偏差 -300ml，且合计 >=0 输出 1” 等价于原来的“合计 >=300ml 输出 1”。两种写法结果一样，但带偏差的形式更利于后续叠加。偏差和权重一样，都是学习过程中会不断调整的参数。

这已经很像深度学习了，但还差最后一步。

回顾机器学习，监督学习会根据正确答案和模型输出来微调参数。深度学习的权重、偏差就是这些参数。但感知机只能输出 0 或 1，稍微调一下参数输出就可能从 1 变成 0，无法做精细的“微调”。

## 用“激活函数”实现平滑微调

为了能渐进调整，需要把输出从二值扩展到 0~1 之间的连续值。输入到 C 的计算不变，改变的是 C 的判定方式。相当于在 C 后面加一个过滤器，把数值映射成新的数值，这个过滤器就叫激活函数。

最开始的“输入 >=0 输出 1，否则 0”本身也是一种激活函数。换成可微的激活函数后，参数就能一点点地被优化，这正是深度学习得以进行大规模学习的关键。
