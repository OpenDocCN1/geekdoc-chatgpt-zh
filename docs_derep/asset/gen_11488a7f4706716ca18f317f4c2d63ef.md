'''GPT-2 推理时使用的 past_key_values 是一个长度为 12 的元组，分别对应模型 12 个 Transformer Block。每个 layer_past 都是上一次前向里该层保存下来的 present 张量，present 本质上是注意力模块把本轮产生的 key 与上一轮留存的 past_key 合并、把本轮产生的 value 与上一轮留存的 past_value 合并后得到的新 key 与新 value。12 层产生的 present 汇总成 presents 元组，随后就会作为下一轮的 past_key_values 再次喂入模型。下面把新 key 与新 value 的构造拆开说明'''

'''首轮前向时，query、key、value 在序列长度方向上的尺度是完整的 seq_len，并不是 1。进入第二轮及之后的增量生成时，这一维的尺度就一直保持为 1'''

'''<1> 本轮形成的新 key 张量

先对 layer_past[0] 做 transpose(-2, -1)，把 past_key 的形状调整为 batch_size、num_head、head_features、seq_len。此时本轮 key 的形状为 batch_size、num_head、head_features、1。调整后可在最后一个维度 Dim=-1 上把两者拼接，把当前 token 的 key 接在历史 key 的末尾，以便模型在后续步骤中继续自回归预测。拼接后的新 key 形状变为 batch_size、num_head、head_features、seq_len+1，记 new_seq_len = seq_len+1

<2> 本轮形成的新 value 张量

past_value 即 layer_past[1] 不需要转置，其形状保持为 batch_size、num_head、seq_len、head_features，而本轮 value 的形状为 batch_size、num_head、1、head_features。两者在倒数第二个维度 dim=-2 上拼接，把当前 token 的 value 追加到历史 value 序列中，为后续 token 的生成提供上下文。拼接后新 value 的形状为 batch_size、num_head、seq_len+1、head_features，new_seq_len 仍等于 seq_len+1'''

class Block(nn.Module):

    def __init__(self, n_ctx, config, scale=False):
        super().__init__()
        # config对应的GPT2Config()类中，n_embd属性默认为768，因此此处hidden_size即为768
        hidden_size = config.n_embd
        # config对应的GPT2Config()类中，n_inner属性默认为None，因此此处inner_dim一般都为4 * hidden_size
        inner_dim = config.n_inner if config.n_inner is not None else 4 * hidden_size
        self.ln_1 = nn.LayerNorm(hidden_size, eps=config.layer_norm_epsilon)
        # 此处n_ctx即等于config对应的GPT2Config()类中的n_ctx属性，其值为1024
        self.attn = Attention(hidden_size, n_ctx, config, scale)
        self.ln_2 = nn.LayerNorm(hidden_size, eps=config.layer_norm_epsilon)
        if config.add_cross_attention:
            self.crossattention = Attention(hidden_size, n_ctx, config, scale, is_cross_attention=True)
            self.ln_cross_attn = nn.LayerNorm(hidden_size, eps=config.layer_norm_epsilon)
        self.mlp = MLP(inner_dim, config)
