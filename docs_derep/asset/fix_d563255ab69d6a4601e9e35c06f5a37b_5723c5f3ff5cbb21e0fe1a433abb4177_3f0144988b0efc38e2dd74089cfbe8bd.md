### 4.3.2 让决策在波动中依然可靠

在动态且充满变化的场景里，通用智能体要给出可信判断，引入鲁棒性设计是关键。思路是把变化直接纳入模型，让方案在多种情境下表现都过得去。

**1． 鲁棒优化是什么**
鲁棒优化面向变化环境做决策制定。目标是在参数的所有可能取值范围内，目标函数都能保持不错水平。不同于随机规划或模糊规划，它不要求知道参数的确切分布或隶属度，适用面更宽。

**2． 模型怎么建**
建模时先厘清变化来源与影响。变化参数会被限定在某个不确定集合里，该集合可基于历史数据、专家经验或统计推断确定。模型追求在最坏情况下依然最优，从而保证决策的抗干扰能力。

举例在微电网经济调度的场景里，要兼顾可再生能源波动和负荷变化，于是构建两阶段鲁棒模型。模型用不确定集描述能源与负荷的波动区间，并在求解时考虑这些波动，确保调度方案在各种情况下兼顾经济与可靠。

**3． 求解手段**
求解鲁棒优化一般需要专用算法。常见手段有列与约束生成、分支定界、启发式搜索等。

◎ 列与约束生成：适合两阶段问题，通过迭代增添变量和约束逐步逼近最优。
◎ 分支定界：用于混合整数鲁棒问题，用分支和定界不断缩小搜索空间，找到全局最优。
◎ 启发式算法：如粒子群、遗传算法等，适合复杂高维问题，能快速得到近似最优。

在 Python 里，借助现有优化库就能高效搭建鲁棒优化模型，为实际问题提供支撑。

## 4.4 多 Agent 协同框架

多 Agent 协同框架通过协作、竞争或协调，让多个智能体共同完成复杂目标。它支持分布式自主决策，并靠信息共享与作业分派提升整体表现。典型应用包括机器人团队、智能交通、分布式传感网络等，能有效应对复杂、动态、不可预知的目标。

### 4.4.1 规划型代理·任务拆分思路

规划型代理是通用智能体系统的重要角色。核心工作是把大而复杂的目标拆成可控的子作业，并为每个子作业制定细化的执行计划。

**1． 规划代理简介**
规划代理会评估不同路径与策略，挑选最优行动方案来实现用户目标。它还能基于已发生的执行结果自我反思，从失误中学习并优化后续动作，从而提高完成质量与效率。

**2． 拆解思路**
作业拆解是规划代理的关键环节，常见做法有三类。

◎ 思维链：把复杂目标拆成若干简单步骤，引导模型逐步推进。例如数学求解时把大题拆成若干小问依次解答。
◎ 思维树：在思维链基础上构建树状结构，探索多条推理路径。每个节点代表一个思考步，生成多个备选方案，再用广度或深度优先搜索锁定最优路径。
◎ 提示驱动拆解：用简单的提示或作业指令引导拆解。比如问“实现目标 A 需要哪些步骤？”来触发作业分解。

**3． 典型应用**
规划代理在多个领域都有落地。

◎ 智能助手：面对复杂用户请求时，将整体工作拆成信息检索、内容生成、任务调度等子作业，并安排执行顺序，提升准确率与效率。
◎ 机器人导航：在动态环境中把导航拆成路径规划、避障、定位等子作业，确保安全高效到达目标。
◎ 工业自动化：在生产调度里把目标拆成备料、加工、装配、质检等子作业，优化流程，提升效率与品质。

**4． 实现路径**
实现规划代理时，比较有效的做法是结合大语言模型的语义理解与序列生成能力。LLM 不仅能做简单拆分，还能评估不同路径制定最佳行动计划。另外，分层强化学习也是常用手段，把目标分层，每层负责不同子作业，通过层间协作与奖励机制实现高效完成。

### 4.4.2 执行型代理·工具动态调度

执行型代理的动态工具链调用是指智能体在执行过程中，能依据具体需求动态挑选并调用所需工具或服务。该能力让智能体更灵活地处理复杂目标，提升执行效率与效果。

**1． 工作流程**
动态工具链调用通常分四步。

（1）目标解析：先理解用户目标的具体需求，常借助自然语言处理把自然语言指令转成结构化、可执行的描述。
（2）工具挑选：基于解析结果，从可用工具库中选出最合适的工具。选择依据包括目标类型、工具功能及历史表现等。
（3）工具调用：通过 API 或其他接口调用选定工具并传递参数。调用时需处理输入输出格式转换与错误处理。
（4）结果整合：工具执行后，智能体把输出整合，形成最终回复或下一步行动。若需多工具协作，则协调执行顺序与数据流。

例如哈啰出行的智能体系统可根据用户输入和业务事件自动调用业务 API，实现智能客服查询订单、发放优惠券等复杂操作。

**2． 应用场景**
◎ 智能客服：通过动态调用知识库检索、用户信息查询等工具，提供精准服务。例如 51Talk 的 AI 客服借助事件感知与延迟消息调度，可主动交互并解决问题，明显提升课程预约率与出席率。
◎ 营销策略生成：结合实时供需、库存状态与用户画像，动态生成个性化营销策略。例如哈啰出行的营销智能体可自动生成触达策略与执行动作，如向新用户推送优惠券、向老用户发送复购激励短信等。
◎ 内容生成：在媒体与营销领域，智能体利用多模态搜索工具动态调用视频检索、图像生成等功能，提升创作效率。例如营销平台 Globant 使用 Gemini 模型的多模态搜索能力，快速定位视频内容并访问特定帧，节省运营时间成本。

**3． 技术实现**
◎ LangChain 体系：提供多类工具与智能体模式，支持动态工具链管理。开发者可方便加载各类工具如 DuckDuckGo 搜索、AWS 工具等，并结合大语言模型实现目标自动化。
◎ OpenAI 的 Responses API：融合对话式 API 的简洁交互与助手 API 的工具调用能力，支持动态目标解析与工具链自主调度，降低复杂业务架构复杂度。
◎ 智能体编排组件：在实际项目中开发编排组件来管理协调多个智能体的工作流。例如哈啰出行开发了编排组件，可结合自研大模型或开源大语言模型，为不同业务场景定制 Prompt 与工具调用。
