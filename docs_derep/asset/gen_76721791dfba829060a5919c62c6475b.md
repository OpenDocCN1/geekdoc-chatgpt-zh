# **内容简介**

本书收录了十多款当下最受欢迎的AI应用，并围绕中老年人的真实生活场景整理了上百个实用范例。为帮助长者更直观地学习，还附赠超过120分钟的同步教学视频，助力快速上手，让晚年生活品质与幸福感双提升。

全书搭建了十个具体使用方向，覆盖健康管理、社交娱乐、出行便捷、技能学习、诗词欣赏、绘画创作、摄影技巧、音乐制作等多个领域，并以提醒吃药、体质状态自测、获取实时路况、高效学新技能等具体事项为例，全面展现AI在日常生活中的价值。

读完本书，读者能明白AI如何带来便利、增加乐趣、守护健康、提升能力，更好地融入智能时代，享受科技赋予的精彩晚年，是一部兼具实用性与指导性的AI入门读物。

**1.1.1 什么是 AI**

[PRE2]

AI是人类构建的能够理解、学习、适应并表现出类人智能的系统，属于计算机科学分支，专注于研发模拟、扩展和增强人类智能的理论、方法、技术及应用。

AI的追求是让机器能够完成原本需要人类智能才能处理的任务，如学习、推理、问题求解、语言理解、知识表示、规划、自然语言处理、模式识别、视觉识别、感知、创造以及在多任务中的自主行动等。
