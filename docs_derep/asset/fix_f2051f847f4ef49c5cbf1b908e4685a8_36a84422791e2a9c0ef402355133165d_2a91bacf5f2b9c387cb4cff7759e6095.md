# Tweepy 实战：推文处理与热门话题词云可视化

本文演示如何利用 Tweepy 批量获取推文并实现多语言自动翻译，进而调用趋势接口分析热门话题，最后生成直观的词云图片。

## 核心工具：智能推文展示函数

首先封装一个处理函数，自动遍历推文对象。逻辑如下：英语内容直接输出；语言未识别（`und`）的跳过翻译；其余语言借助 `TextBlob` 转为英文后再展示，确保阅读无障碍。

```python
def print_tweets(tweets):
    """遍历推文列表，输出用户名与正文；非英语尝试自动翻译。"""
    for status in tweets:
        print(f"@{status.user.screen_name}: ", end='')
        if status.lang == 'en':
            print(f"{status.text}\n")
        elif status.lang != 'und':
            print(f"原文: {status.text}")
            print(f"译文: {TextBlob(status.text).translate(to='en')}\n")
```
