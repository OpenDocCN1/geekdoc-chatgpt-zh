# 上海数据条例：立法逻辑与实践透视

## 序

学界领衔为地方性法规撰写条文释义，在国内尚属首次，本书或许为开端。令作者团队倾注心力的，正是《上海市数据条例》，下文简称《条例》。该条例经上海市第十五届人大常委会第三十七次会议于2021年11月25日通过，共十章九十一条。除开篇总则与末尾附则外，第二至第九章依次涉及数据权益保障、公共数据、数据要素市场、数据资源开发利用、浦东新区数据改革、长三角区域数据协作、数据安全、法律责任。无论立法理念、制度取舍抑或规则设计，均体现出开创性探索，代表了地方数据立法的高水准，也折射出数字时代地方立法共通的规律与困境，值得细细剖析。

2020年3月30日，《中共中央 国务院关于构建更加完善的要素市场化配置体制机制的意见》首次将数据与土地、劳动力、资本、技术并列为第五类要素，明确指引培育数据交易市场，鼓励全产业链主体在合规安全有序的前提下开发数据价值，推动数据要素在数字经济中实现合规流通，成为立法聚焦的重点。放眼长远，数据立法既是大数据、云计算、人工智能迅猛发展下法治建设的紧迫议题，也关乎我国在相关领域参与全球竞争的基础与支撑。

习近平总书记强调要抓紧科技创新等重点领域的立法进度，指出数字经济、互联网金融、人工智能、大数据、云计算等新技术新业态爆发式增长，而相关法律制度却存在时间差、空白区^[(\[1\]](#fow001.html#footnote_content_fow001_1))。现阶段我国数据立法仍有空白亟待填补。地方立法探索必须以习近平法治思想为指引，坚持科学立法，推动中国特色社会主义法治体系建设，最终在法治轨道上提升国家治理现代化水平。《条例》的出台，正是补位短板、强化学科体系、满足人民美好生活需要的必然之举，既可为各地提供借鉴，也为国家层面立法积累地方经验。尤其在数据交易、公共数据授权运营、数据权益保护等领域的创新，影响深远。

作为全国第一经济大市，上海正全面推进城市数字化转型，打造全球卓越城市与世界数字之都。对数据的采集、生成、共享与应用提出了更高要求。《关于全面推进上海城市数字化转型的意见》提出，数据资源在联通国内大循环与国内国际双循环中的引领、功能、关键作用愈发突出，推进数字化转型既是服务新发展格局的主动选择，也是超大城市治理现代化的内在要求。《条例》为此提供了坚实的法治护航。

条例通过当日，上海数据交易所同步成立。《条例》第67条明确：“本市按国家要求在浦东新区设立数据交易所并运营。数据交易所应依据相关法律、行政法规和主管部门规定，为数据交易提供场所设施，组织监管交易。交易所须制定交易规则与业务规则，探索分类分层的新型数据综合交易机制，组织合规性审查、登记清算、信息披露，确保交易公平有序、安全可控、全程可追溯。浦东新区鼓励市场主体依规通过交易所交易。”该条为交易所设立运行奠定法律基础。成立后，上海持续完善配套设施，推动公共数据开放与授权运营，引导主体合规交易，场外市场也据此推进合规升级。准确把握《条例》已成为行业核心关切，也为各方推进生活、经济、治理数字化转型提供规则指引。

本书以逐条释义为主线，每条配置主旨、核心概念、参考资料三部分，分层解读。研究遵循法释义学原理，重视条文内在关联与条例与上位法的协调，力求揭示立法精神。旨在兼顾专业性、实用性与理论性，为数据从业者、数商、法律工作者与研究者提供参考。须说明本书为民间学术编撰，条目到观点均为学理解读，不具官方立场。

本书由国内数据法治领域的青年学者与实务人士合著，部分作者全程参与《上海市数据条例（学者建议稿）》起草，对条文形成背景与演进有深入了解。作者来自上海交通大学、东南大学、北京航空航天大学、上海政法学院、同济大学等高校，也有来自大成、中伦、国瓴等律所的实务专家。初稿获苏宇、韩旭至、李群涛等学者与立法专家指导，上海交通大学龚思涵、上海大学许端蓉、武汉大学刘羿鸣参与文字校对，特此致谢。

写作始于2021年，至今近三年。期间国家与地方数据政策、数字经济实践持续演进。2022年6月中央全面深化改革委员会第二十六次会议审议通过《关于构建数据基础制度更好发挥数据要素作用的意见》；同年12月中央正式发布该意见，即“数据二十条”。2023年2月中央印发《数字中国建设整体布局规划》，为数据制度建设提供宏观框架。实践上，2023年3月党中央决定组建国家数据局，并于当年10月25日挂牌，全国已建立数十家数据交易机构。为跟踪进展，2023年4月9日我们在同济大学举办“促进数字经济高质量发展法治保障暨《上海市数据条例理解与适用》审读研讨会”，条例立法专班主要同志参会并提出意见，团队据此作了进一步修改。

数据立法的意义重大，但其复杂性亦带来挑战。科学立法需更新理念与规则设计，这建立在对事物本质的认知之上。坦率说，我们对数据及其流动规律仍在探索。法律人习惯以释义联通规则与个案，而农业文明与工业文明历时长久，规范相对稳定。数字智能文明是颠覆性新形态，数字社会数据流通本质研究已成为规则设计的前提。通晓事理方能明法理，事理不明则法理不清。

近年来笔者在市法学会支持下参与《上海市数据条例（学术建议稿）》《上海市促进人工智能产业发展条例（草案）》《上海市促进城市数字化转型条例（草案）》及《上海市促进浦东新区数据流通交易若干规定（草案）》起草，反复得到的启示是，我们对数据的认识非但不少，反而有限。企业、产业部门与立法机关的智慧与勇气令人敬佩，但认知局限是普遍难题。数字时代，以《条例》为代表的地方立法探索，正是在面对技术系统与商业场景时，努力弥补认知空白、更新立法理念、优化工作机制、提升技术水平。这些探索支撑着我国在数据、人工智能与数字中国建设中的实践。

归根结底，数据是为解决问题而存在，回答生活、经济与治理之问。正是这些问题决定了数据的社会属性，也赋予数据法现实面向。同时数据具技术属性：须在系统中采集处理、人不可读、机可读，具有可计算性，生命周期中形态、参与者与权益内容不断变化。数据还具有不可合约性，与可计算性共同导致确权与交易制度设计的困难。对数据的认识注定漫长艰辛，手上这部《条例》、本书乃至我们这一代人，可能仅是在探寻本质，为后人更正典的释义学研究铺路，为国家层面数据立法破解“卡脖子”难题提供养分，不负可歌可泣的中国实践。

本书写作与出版获上海市人工智能社会治理协同创新中心与上海数据交易所支持，谨致谢忱！

# 第一章　总　则

## 第一条　【立法目的】

为了保护自然人、法人和非法人组织与数据有关的权益，规范数据处理活动，促进数据依法有序自由流动，保障数据安全，加快数据要素市场培育，推动数字经济更好服务和融入新发展格局，根据《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》等法律、行政法规，结合本市实际，制定本条例。

条文界定了条例的立法目的与依据。目的与依据并列置于首条，符合我国立法惯例。虽不直接适用于个案，但对解释工作具有关键指引作用。

### 一、立法背景

2015年8月国务院发布《促进大数据发展行动纲要》，要求推进大数据发展应用，建设数据强国，并把政府数据共享和公共数据开放列为重点任务。2015年10月党的十八届五中全会提出实施国家大数据战略。2016年全国人大通过的《国民经济和社会发展第十三个五年规划纲要》明确提出把大数据作为基础性战略资源，强调共享开放与开发应用。2020年4月9日中央文件将数据提升为与土地、劳动力、资本、技术并列的第五类生产要素，凸显其资源价值。

《上海市数据条例》出台前，已有多省市在数据领域制定地方性法规或政府规章。按名称可大致分为五类。

一是大数据。2016年9月上海市政府印发《上海市大数据发展实施意见》；全国层面贵州省走在前列，2016年与2018年先后通过《贵州省大数据发展应用促进条例》《贵州省大数据安全保障条例》。

二是政府数据。2017年贵阳市人大常委会通过《贵阳市政府数据共享开放条例》，2020年贵州省人大通过《贵州省政府数据共享开放条例》。政府数据共享开放的立法动因主要来自大数据技术应用，而政府信息立法更侧重透明政府建设，两者路径应有所区分。

三是政务数据。指政务部门履职中形成或获取的数据。2016年起多地出台政务数据管理规章，2020年沈阳市与山西省分别出台地方性法规。

四是公共数据。指公共管理和服务机构履职中生成采集的数据资源，范围涵盖政府数据与公共服务机构数据。2016年《网络安全法》《电子商务法》均提出促进公共数据资源利用。2017年浙江省率先出台《浙江省公共数据和电子政务管理办法》，2022年制定《浙江省公共数据条例》；成都市、无锡市等亦先后出台相关规章。上海于2018年、2019年分别制定《上海市公共数据和一网通办管理办法》《上海市公共数据开放暂行办法》。

五是数字经济。指以数据资源为关键生产要素的新经济形态。浙江省、广东省分别于2020年、2021年通过《浙江省数字经济条例》《广东省数字经济条例》。

名称差异一方面源于概念认知上的分歧，如政府数据、政务数据、公共数据常被混用；另一方面各地结合实际选择不同路径，有的分别立法。

### 二、立法过程

地方数据立法热度上升的同时，中央立法与政策也在加速。2018年9月《十三届全国人大常委会立法规划》把个人信息保护法与数据安全法列为第一类项目。2021年6月10日与8月20日，全国人大常委会先后通过《数据安全法》与《个人信息保护法》。2019年10月党的十九届四中全会首次将数据列为生产要素，要求建立按贡献分配机制。2020年4月9日文件再次明确数据要素地位。

中央进展反过来推动地方立法。2021年6月29日深圳市人大常委会通过《深圳经济特区数据条例》，内容覆盖个人数据、公共数据、数据要素市场、数据安全，呈现综合性立法新模式。上海立法启动虽晚于深圳，但节奏紧凑，最终同于2022年1月1日实施。

时间脉络大致如下：2020年底市人大常委会法工委拟定2021年度立法计划，初拟《上海市公共数据管理条例（暂定名）》。2021年征求代表意见后更名为《上海市数据条例（暂定名）》。2021年3月2日市政府立法工作计划将其列为拟提请审议项目。立项初期曾就“公共数据”与“数据”定名展开讨论，最终删除“公共”，转向综合数据立法。

2021年4月28日市人大财经委委托市社科院完成的《上海市数据立法调研》结题。2021年5月27日由市政府办公厅、市人大财经委、市经信委联合主办的数据立法研讨会召开，起草组组长、市政府办公厅副主任、市大数据中心主任朱宗尧介绍了立法总体定位。
