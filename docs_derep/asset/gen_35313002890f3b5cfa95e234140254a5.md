### 三、剧本创作提示语：想构塑绘优
戏剧剧本与小说、诗歌的创作路径差异明显，其核心是为舞台服务。因此设计剧本创作提示语时要遵循五条基本原则：以对话推进情节并显露人物性格、引导AI思考视觉呈现效果、突出戏剧冲突作为驱动力、兼顾舞台物理限制与表现可能、关注剧本对观众情绪的引导。

整体可分为六个阶段：初始化、创意生成、结构设计、角色开发、场景创作、优化迭代，各阶段侧重点不同，需针对性设计提示语。

#### （一）初始化阶段
该阶段锁定剧本基础参数，为后续工作定基调。提示语可采用“参数设定+目标明确+约束条件”的组合。逻辑上要让AI明确主题、背景、主角并提供后续情节框架。

提示语示例：
初始化剧本创作参数：
- 类型选择：a. 选定主要类型如悲剧、喜剧、正剧；b. 如有，增添次要类型。
- 规模定义：a. 确定幕数如独幕、三幕；b. 给出每幕大致时长。
- 目标受众：a. 界定主要观众群年龄段、兴趣等；b. 考虑特定文化或社会背景要求。
- 创作目标：a. 明确要传递的核心主题或信息；b.设定期望的观众情感反应或思考效果。
- 创作约束：a. 列出特定要求如历史背景、演员数量限制等；b. 明确禁忌或需规避的元素。
请用300字概述初始化参数，涵盖类型、规模、受众、目标与约束。

#### （二）创意生成阶段
此阶段是核心创意的萌发期，要求既开放又兼顾舞台可行性。提示语框架为“主题探索+冲突设定+创新元素”。

设计逻辑：激发多角度思考、聚焦核心冲突与戏剧性、把抽象概念落地为舞台呈现。

提示语示例：
创作舞台剧核心创意：
1. 以当代社会议题作主题，如科技伦理、身份认同。
2. 提出三种戏剧冲突，每种包含个人矛盾与社会对抗。
3. 设想创新舞台呈现，包括非常规布景、新颖叙事手法、观众互动方式。
4. 描述创意如何在有限舞台空间实现视觉与情感冲击。
请用约300字概述创意，包括主题、冲突与创新呈现。

#### （三）结构设计阶段
关注整体结构与节奏，平衡张力、情节与主题，同时考虑舞台实操。提示语采用“结构设计+转折点+节奏控制”。

提示语示例：
设计三幕剧大纲：
1. 为每幕设定核心主题与情绪基调：a.第一幕 b.第二幕 c.第三幕。
2. 设计四个关键转折：a.引子 b.第一转折点 c.中点 d.高潮。
3. 说明每个转折点的舞台呈现，兼顾视觉与演员动作。
4. 规划节奏变化：指出需加速或放缓处，并解释戏剧效果。
5. 设计两幕间的创新场景转换方法。
请用约500字概述三幕结构，突出转折与节奏。

#### （四）角色开发阶段
塑造个性立体的人物，通过对话与行动展现特性。提示语框架为“角色档案+关系网络+发展轨迹”。

提示语示例：
开发核心角色：
1. 角色档案为主角及两配角：a.基本信息 b.3～5个关键特质 c.核心价值观 d.主要动机与目标。
2. 关系网络：a.绘制角色关系图 b.描述关系性质与潜在冲突。
3. 成长线：a.描述剧中变化轨迹 b.说明变化如何推动情节。
4. 角色冲突：设计至少两角色的核心冲突并解释影响。
5. 特色对话：为每位主角创作约30字的体现特性的独白。
请用约600字描述角色设计，含档案、关系、成长线与对话示例。

#### （五）场景创作阶段
将创意与结构转化为具体舞台场景。提示语框架为“场景设置+对话创作+舞台指示”。

提示语示例：
创作关键场景：
1. 场景设置：a.时间地点 b.布景与氛围 c.在场角色及初始状态。
2. 场景目标：a.在整体中的作用 b.需推进的情节点或揭示信息。
3. 对话创作：a.开场对话约100字 b.戏剧性高潮对话约50字。
4. 潜台词：在对话中加入至少一处潜台词并解释含义。
5. 非语言互动：描述肢体语言、表情变化。
6. 舞台指示：a.灯光音效 b.关键动作指示。
7. 象征元素：加入表现主题的象征性动作或物件。
请用约2000字描述场景设计，含设置、对话、潜台词、互动、指示与象征。

#### （六）优化迭代阶段
提升整体质量与舞台效果，需客观评估并改进。提示语框架为“问题识别+解决方案+效果评估”。

提示语示例：
优化剧本整体质量：
1. 对主题深度、结构节奏、角色真实性、对话质量、舞台创新可行性各打1～10分并说明理由。
2. 选两个最需改进的方面，给出具体优化建议。
3. 检查主要角色成长线是否一致并推动情节，不一致则提出修改。
4. 审视高潮场景，提出增强戏剧性与舞台效果的具体建议。
5. 提出增强观众参与感或情感投入的创新想法。
6. 反思是否充分展现初始核心主题，如需加强则给出具体方法。建议需兼顾艺术追求与可行性。

### 一、新闻报道：消息、通讯、新闻特写的提示语设计
[PRE1]
图11-2 新闻报道提示语设计框架
新闻报道要求准确及时传递信息。本节聚焦消息、通讯、特写三种形式的提示语设计。

#### （一）消息的提示语设计
消息是对新近发生、有社会意义事实的简短报道。写作核心是时效、重要、准确，并兼具简洁、客观、结构性，通常遵循倒金字塔。

1. 提示语设计的目标导向
（1）确保时效与准确
实现方法：要求输出时间戳、设置多重核查、区分已确认与待确认信息并标注来源。
提示语示例：
请生成关于[事件名称]的最新消息：
1. 列出已确认信息点并注明来源与确认时间。
2. 列出待确认信息点并明确标注来源。
3. 正文中使用“据[来源]报道”“[机构]证实”等表述。
4. 文末注明“截至[具体时间]”。

（2）保持客观中立
实现方法：要求中性词汇、平衡呈现多方观点、禁用感情色彩修饰。
提示语示例：
报道[具体事件]时请遵守：
1. 使用客观中性词汇，避免褒贬形容。
2. 涉及争议须呈现至少两方观点，篇幅相当。
3. 引用时用“表示”“称”等中性动词。
4. 禁用“应该”“必须”等主观判断词。
5. 数据须具体，避免模糊表述。

（3）结构完整层次分明
提示语示例：
请按结构写约500字消息：
1. 标题15字内，概括核心。
2. 导语50字左右，回答5W1H至少4问。
3. 主体400字：第二段100字补充关键信息；第三段100字交背景原因；第四五段80～100字按重要递减展开。
4. 结尾50字点明发展趋势。
要求每段聚焦一个信息点，由重到轻。

（4）语言简洁明了
提示语示例：
撰写消息时请遵守：
1. 每句不超过30字。
2. 以主动语态为主。
3. 每段最多一个复合句。
4. 避免修饰性状语与长定语。
5. 用准确动词，避免“进行”“作出”等空词。
6. 专业术语首次出现加括号解释。

2. 结构设计与提示语策略
（1）标题设计
要求概括、醒目、简洁，一般不超过20字。
提示语示例：
基于要素生成不超过20字标题：
1. 核心事件 2. 关键人物/机构 3. 时间/地点 4. 原因/结果
要求用有力动词，包含新闻价值要素，避免标点与夸张。

（2）导语设计
要求精炼、全面、有吸引力。
提示语示例：
请用约40字写导语：
1. 主体Who 2. 内容What 3. 时间When 4. 地点Where 5. 原因Why 6. 经过How
要求一段完成，优先顺序What>Who>When>Where>Why/How，使用主动语态，保持客观。

（3）主体设计
遵循倒金字塔，按重要递减排列。
提示语示例：
基于框架写300～400字主体：
1. 核心事实 2. 事件细节a.b.c 3. 背景信息 4. 各方反映 a.b 5. 潜在影响
要求严格倒金字塔，每段一个信息点，段间用转折词连接，引用注明来源，保持客观。

（4）结尾设计
简洁点题并留开放空间。
提示语示例：
基于以下元素创作结尾：
1. 事件后续 2. 未解问题 3. 长远影响
要求选一或多项，语言简洁客观，避免主观预测，可用“记者将持续关注”作开放结尾。
