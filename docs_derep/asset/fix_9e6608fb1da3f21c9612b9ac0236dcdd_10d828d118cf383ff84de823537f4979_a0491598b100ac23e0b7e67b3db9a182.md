# Transformer 解码形状与落地训练

Transformer 解码阶段产生的 logits 把批量维度和时间维度展平，得到行数等于批次与目标长度相乘，列数对应目标词表。直观来看，这相当于为每个目标位置独立建立一个词表上的打分，推理时通常挑选置信度最高的下标作为预测。整体上模型先由编码器提炼源序列的表征，再交由解码器基于表征逐步生成，最后返回预测结果。

下面给出模型准备与主训练循环。设定保存路径与设备，构造 Transformer 实例并选用忽略填充位的交叉熵损失，优化器采用 AdamW，学习率 2e-5。训练共 1024 轮，进度条实时反馈，输入先搬运到设备，前向得到 logits 与编码自注意力、解码自注意力、解码对编码注意力的三组结果，损失在展平后计算。随后清空累积梯度、执行反向传播并更新参数，轮次结束时把权重写入磁盘。

for epoch in range(1024):

    pbar = tqdm((loader), total=len(loader))  # 显示进度条

    for enc_inputs, dec_inputs, dec_outputs in pbar:

        enc_inputs, dec_inputs, dec_outputs = enc_inputs.to(device), dec_inputs.to(device), dec_outputs.to(device)

        # outputs: [batch_size * tgt_len, tgt_vocab_size]

        outputs, enc_self_attns, dec_self_attns, dec_enc_attns = model(enc_inputs, dec_inputs)

        loss = criterion(outputs, dec_outputs.view(-1))

        optimizer.zero_grad()

        loss.backward()

        optimizer.step()

        pbar.set_description(f"epoch {epoch + 1} : train loss {loss.item():.6f} ")  # : learn_rate {lr_scheduler.get_last_lr()[0]:.6f}

    torch.save(model.state_dict(), save_path)

下面给出策略梯度实现的骨架。Memory 用来暂存状态、动作、对数概率、奖励以及回合是否结束的标志并提供清空方法。Action 网络以 8 维状态为输入，经两层线性变换与 ReLU 后输出 4 个动作的 softmax 概率分布。

class Memory:

    def __init__(self):

        """初始化"""

        self.actions = []  # 行动(共4种)

        self.states = []   # 状态, 由8个数字组成

        self.logprobs = [] # 概率

        self.rewards = []  # 奖励

        self.is_dones = [] # 游戏是否结束: is_terminals?

    def clear_memory(self):

        del self.actions[:]

        del self.states[:]

        del self.logprobs[:]

        del self.rewards[:]

        del self.is_dones[:]

class Action(torch.nn.Module):

    def __init__(self, state_dim=8, action_dim=4):

        super().__init__()

        # actor

        self.action_layer = torch.nn.Sequential(

            torch.nn.Linear(state_dim, 128),

            torch.nn.ReLU(),

            torch.nn.Linear(128, 64),

            torch.nn.ReLU(),

            torch.nn.Linear(64, action_dim),
