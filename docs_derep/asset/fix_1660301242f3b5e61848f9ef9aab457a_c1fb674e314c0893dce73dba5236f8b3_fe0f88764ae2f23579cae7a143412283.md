### 14.5.2 异步版本的 A3C

A3C 即 Asynchronous Advantage Actor-Critic，是 DeepMind 在 Advantage Actor-Critic 基础上提出的异步实现 [^(\[8\])](#chapter14.xhtml#jz_16_8)。它把多个 Actor-Critic 副本放到不同线程并行运行，并借助一个全局网络同步参数。这种并行方式明显加快了训练速度，也提升了最终性能。

如图 14.22 所示，系统会创建一个全局网络 Global Network 以及 M 个 Worker。Global Network 包含 Actor 与 Critic，每个 Worker 各自拥有独立环境以及本地的 Actor-Critic。初始化时 Global Network 随机生成 θ、φ，Worker 的本地网络从 Global Network 拉取参数初始化。训练阶段 Worker 先从 Global Network 同步最新参数，再在策略 πθ 下与私有环境交互，按 Advantage Actor-Critic 计算 θ、φ 的梯度，最后把梯度汇入 Global Network 由其优化器更新。测试时只需使用 Global Network 与环境交互。
