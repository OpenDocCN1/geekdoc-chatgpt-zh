### 3.1.2 AI 算法的多元表达方式

#### 3.1.2.1 算法描述的“四大金刚”

怎么把脑子里的解题思路告诉计算机？常用的手段主要有四种：自然语言、结构化流程图、伪代码 和 PAD 图（问题分析图）。其中，流程图因其直观性最为大众熟知。不同描述工具的表达能力各有千秋：生活中我们习惯用自然语言沟通想法，也会用图表梳理关系。

*   **流程图**：用一套标准化的图形符号（见下方预留位）把算法步骤“画”出来。
    [PRE0]
    *图示：流程图基本符号集*

*   **伪语言**：融合了程序设计的三大基本结构（顺序、选择、循环）与自然语言的混合体。
*   **类语言**：风格贴近高级编程语言，如类 Pascal、类 C 语言等。

主流描述方式——自然语言、流程图、伪代码——各有优劣，速览如下：

| 方式 | 亮点 | 痛点 |
| :--- | :--- | :--- |
| **自然语言** | 门槛极低，人人可读，无需专业训练。 | 1. 歧义多，易导致执行不确定；<br>2. 句式冗长，描述繁琐；<br>3. 面对复杂嵌套逻辑（多层循环/分支）表达乏力；<br>4. 难以直接转译为代码。 |
| **流程图** | 逻辑清晰直观，擅长表达选择结构；跨平台、跨语言，通用性强。 | 手绘修改麻烦，依赖专用绘图软件才能高效维护。 |
| **伪代码** | 规避了编程语言的严格语法，书写轻快；结构紧凑、易读，且能平滑过渡到实体代码。 | 方言太多，缺乏统一标准，易产生歧义误读。 |

> **业界现状**：主流《数据结构》教材多采用类 Pascal、类 C++ 或类 C 作为标准算法描述语言。

#### 3.1.2.3 语句的“骨架”与“血肉”

算法描述语言语法宽容，核心由符号/表达式、赋值、控制转移、循环、其他语句构成。命名规范、数学逻辑表达沿用编程惯例，**赋值用箭头 `←` 表示**（区别于数学等号）。语句可带标签（数字或语义单词），嵌套采用缩进，语句间用分号分隔。

### 算法特性速览（素材前段补充）

*   **可读性**：衡量算法被人类理解的难易度。代码写给人看，附带能在机器上跑。
*   **健壮性**：面对脏数据、异常输入时，算法能否“不崩溃、给提示、有兜底”，即容错能力。

### 经典案例复盘

#### 案例一：狼、羊、白菜过河（状态空间搜索）
**局势**：农夫驾小舟，单程仅能带一样。无人看管时：狼吃羊，羊吃菜。
**破局关键**：**“带回”策略**打破单向思维。

**最优路径（右岸 → 左岸）**：
1.  **带羊过河** → 回程空舟。
2.  **带菜过河** → **把羊带回**右岸（关键步！）。
3.  **带狼过河** → 回程空舟。
4.  **带羊过河** → 全员安全登岸。

#### 案例二：韩信点兵（中国剩余定理实战）
**历史现场**：3 排余 2，5 排余 3，7 排余 2。部下报 262，韩信一眼断定：**233 人**。

**算法思维演进**：

**阶段 1：暴力枚举（伪码雏形）**
从 2 起步，逐个验证 `m % 3 == 2 && m % 5 == 3 && m % 7 == 2`。
*   步骤链：`m=2` → 判断 3 → 判断 5 → 判断 7 → 输出 / `m++` 回溯。
*   *流程图练习*：动手画画看，对照网上标准图对比理解。
    [PRE*] (此处预留流程图练习位)

**阶段 2：数学建模（降维打击）**
列方程组：`m = 3i + 2 = 5j + 3 = 7k + 2`
推导：`3i = 7k` → 两边必为 **21 的倍数**（3 和 7 最小公倍数）。

**阶段 3：步进搜索（利用数学结构加速）**
令 `3i = 7k = 21, 42, 63...` 依次试算 `m` 并验证 `j` 是否为整数：

| 3i=7k 值 | m 值 | j 有整数解？ | j 值 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 21 | 23 | **有** | (23-3)/5=4 | 最小正整数解 |
| 42 | 44 | 无 | - | |
| 63 | 65 | **有** | (65-3)/5=12.4? 否 | 待验证 |
| ... | ... | ... | ... | |
| 231 | **233** | **有** | **46** | **符合兵力范围的真解** |

**核心洞见**：同余方程组有**无限组解**（通解为 `m = 233 + 105t`）。**实际问题必须结合上下文约束（如兵力范围）定唯一解**。本题中 `i=77, j=46, k=33`，实得 233 人。

### 算法无处不在：从生活到代码

计算机算法与生活算法同源同构，核心都是 **“算法思维”**—— 为了解决问题而设计的规范化流程。
生命周期对标：
1.  **分析问题** （搞清现状与目标）
2.  **寻求路径** （设计策略/模型）
3.  **落地执行** （人工操作或编程实现）
4.  **复盘优化** （重构、提效、泛化）

静心观察生活，处处皆算法：做菜谱是顺序结构，红绿灯是选择结构，刷牙刷脸是循环结构。
