功能分层付费：先以免费或低价的基础能力获取用户，再对进阶或专业能力收取费用。例如某代码检查工具可将语法纠错开放免费，而深度性能剖析、安全漏洞扫描等高级能力放在付费区间。

平台收入分成：当应用以插件或扩展形态接入第三方 AI 平台时，双方按销售额分配收益。以 Cline Marketplace 为例，上架的服务商通常需将部分流水与平台共享。

一次性买断：适用于能力边界清晰、迭代需求较低的工具。用户支付一次费用后即可永久使用全量功能，无需续期。

企业定制方案：面向组织客户提供专属化部署，按项目收取服务费与授权费。范围涵盖定制开发、专属能力、更高配额及专属技术支持。

数据资产化：在严格脱敏并合规的前提下，将运行产生的匿名数据或分析洞察出售给第三方，作为外部决策参考。

广告展示：当装机规模达到阈值时，可在产品内投放广告获取现金流，但形式与频次需克制，避免影响使用体验。

社区资助：针对开源类项目，可接受用户赞助与捐赠，用于覆盖持续研发与维护成本。

AI 智能体网络正步入快车道，自主智能体、大模型工具化、开放协议普及、巨头布局、多体协同等力量共同推动。MCP 的标准化大幅降低了智能体接入数据与服务的难度，也催生出 Agent OS、MCP 基础设施与 MCP Marketplace 三大创业方向，分别聚焦运行环境搭建、底层能力供给和供需撮合。

### 10.1 发展脉络：从独立到协同
AI 智能体网络以“自主智能加生态协同”为核心，重塑人与信息世界的交互方式。它打破了传统互联网在信息获取、任务执行与服务整合上的短板，推动网络从“用户主动查找”转向“智能主动响应”。随着多智能体协作网络成型，由 AI 智能体构建的新型数字社会正在加速到来。

掌握底层协议标准的力量将成为生态主导者。MCP 作为关键基础设施，正在解决互操作、数据接入与上下文管理等核心难题，为智能体规模化落地提供技术基础与产业路径。

#### 10.1.1 旧时代：传统网络的局限
过去二十年，人们主要通过浏览器进入互联网，依赖网站、网页和 HTTP 完成查资料、购物、订票、办公等任务。核心逻辑是“用户主动找”，通过关键词搜索、点击链接、手动筛选整合才能完成一件事。早期这种方式高效且具革命性。

随着信息爆炸和需求复杂化，其短板逐渐显现：操作高度依赖人工、缺乏连贯性与智能化，难以随行为和环境动态调整，复杂任务效率低、易出错、体验割裂。

1. 信息过载导致检索效率下降
网络内容指数级增长，用户陷入认知过载。传统搜索常返回海量结果，需自行过滤比对，关键信息易被淹没。用户往往要打开多个页面才能提炼答案，效率低下且易遗漏要点。

2. 使用体验高度碎片化
服务分散在不同网站和 App 中，用户需频繁切换账号与界面，反复输入相同信息，难以获得连续一致的流程。例如购物需比价、下单、查物流跨多个应用，衔接不顺。移动互联网大量独立 App 将开放 Web 切割成信息孤岛，整体体验割裂。

3. 跨平台重复操作，流程不连贯
不同系统缺少统一接口，用户常需在多个平台重复类似动作。办理一件事可能在网页提交、在 App 查询进度、再电话核实，信息无法自动流转，导致耗时、繁琐且易错。

4. 人工客服低效，交互不佳
遇到复杂问题时，人工客服常伴随长时间等待与低效沟通。用户需重复描述问题、提供个人信息，多次转接后才得到方案，过程冗长不确定。

伴随信息量激增，这种交互弊端愈加明显。比如规划一次旅行需分别查攻略、订票、安排行程，全程依赖人工操作，效率低且体验割裂。信息虽触手可及，却未真正服务于人。

如今范式正在切换：从“用户主动找”转向“智能体主动找能力”。AI 智能体能理解自然语言，主动识别意图、拆解任务、调用工具、访问数据源并输出完整解决方案。这种委托执行的交互标志着传统互联网的终结，AI 智能体驱动的时代加速到来。两者差异如图 10-1 所示。
