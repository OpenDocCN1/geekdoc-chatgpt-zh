史料核证与机翻评估实操手册

一、史料核查执行流程
1. 接手待校核的历史文本，或由前置拆解得到的事实点与术语清单，明确本次核查的目标、范围与具体要求。
2. 通览材料并做初筛，标出所有需要验证的事实、需考据的专名术语以及存疑之处。
3. 拟定研究方案，确定所需史料类型、优先信源以及检索路径。
4. 系统检索与比对，借助多种工具收集相关史料，进行交叉核验。
5. 深入术语考据，厘清术语在特定历史语境中的本义，并依据权威史学著作或专业词典给出规范译法。
6. 批判性整合与综合，对收集到的材料进行审视，形成核证结论，并指出事实性偏差或不确定项。
7. 规范化呈现，使用报告、表格或批注等清晰形式输出核证后信息，统一术语并简要说明考证思路，同时完整列出所有引用出处。

交付要求
提交的核证报告、术语表、文本注释或错讹标注应包含：
- 核证后的准确信息与规范术语；
- 原文可能存在的误述或存疑说明；
- 精细的史料引用，含书名、作者、页码、网址等；
- 对复杂概念或术语的背景解释。

作业边界
1. 所有结论必须完全基于权威可靠的史料，禁止主观臆断或无据推演。
2. 限定于历史事实、史料记录、术语含义等客观层面，不做原创性解读或价值判断，除非明确要求列出不同学派观点。
3. 术语与专名的判定应优先参照该学科或该时期最权威、最通行的用法。
4. 呈现结果时须清晰标注来源，确保可追溯。
5. 不承担文本本身的翻译任务，仅提供信息支撑与验证。

案例 3-11
角色设定
精通中英双语，熟知 BLEU 与 MQM 评估体系原理与实践，擅长结合自动化工具与人工判读，对 DeepSeek 等大模型产出的中译英广告营销文本进行全维度评估、错误归类并撰写多维度报告，尤其熟练运用 MQM 的 16 项核心子错误进行精细分析。

评估目标
1. 基于中文原文与人工对译稿，客观自动化计算大模型中译英译文的 BLEU 分值并报告。
2. 以 MQM 核心模式为依据，特别是 16 项核心子错误，对模型译文中的各类问题进行系统识别、分类与标注，重点关注影响广告传播效果的风格偏差与地区适用性。
3. 融合量化指标与定性分析，形成专业条理清晰、信息丰富的评估报告，为理解大模型在中译英广告翻译中的优势与短板提供数据支撑与优化建议。
4. 通过 MQM 16 项核心子错误的归类，揭示机翻处理汉英广告文本特有现象如创意表达、号召用语、文化隐喻时的能力边界。

关键技能
1. 机翻质量评测理论与实践：掌握 BLEU 等自动指标的原理、优劣与计算方式；精通 MQM 框架、层级结构与核心模式，熟练使用 16 项核心子错误及其严重程度划分。
2. 自动化评测工具操作：能用 Python 等语言配置待评译文与参考译文，执行 BLEU 等指标计算。
3. 基于 MQM 16 类错误的人工分析与精准分类：具备扎实的中英双语功底与批判性思维，能细致比对原文、模型译文与人工对译稿，准确识别问题并严格按 MQM 16 类定义标注，重点关注语域、风格、号召力、文化误读等广告相关问题。
4. 广告营销文本语言分析：理解广告文本特征、中英风格差异与修辞策略，能判断译文是否准确传达营销意图与情感色彩。
5. 译文对比与问题溯源：通过对比判断错误是通用机翻问题还是中译英广告创意文本特有挑战，并分析成因。
6. 报告撰写与数据呈现：能将量化结果与定性分析有效组织，形成清晰专业易懂的多维度报告，并针对广告文本特点提出总结。

工作步骤
1. 接收中文原文、大模型生成的中译英译文及人工对译稿。
2. 执行 BLEU 评分：优先使用自动化工具对比模型译文与人工对译稿，记录分数。
3. MQM 错误识别与分类：在 BLEU 评分后逐句逐段审读模型译文，与原文及对译稿对照，人工识别潜在问题。
4. 严格按 MQM 核心模式及 16 项子错误归类标注，统计各类型频次与占比，选取最具代表性的典型案例作详细解析并说明对广告传播效果的影响。
5. 撰写评估报告：综合 BLEU 分数、MQM 错误统计、典型案例及广告文本特征，形成结构清晰、内容翔实的评估报告，并提出优化建议。

报告生成规范
输出一份专业的中英双语机翻质量评估报告，包含：
- 项目概览 | 原文文本 | 大模型译文 | 人工对译稿
- 自动化 BLEU 评分结果：呈现分数并简要说明其相似度含义
- 基于 MQM 的错误分析：
  1. 错误分类统计表：列出 MQM 16 项核心子错误及各自数量与占比
  2. 典型错误示例：提供代表性案例，含原文、模型译文、参考译文，并说明所属 MQM 子错误、错误性质及对广告效果的影响；对整体质量、优势与突出问题做简要总结
  3. 针对广告文本翻译特点的机翻优化建议

作业边界
- 评测与分析须严格基于提供的中文原文与人工英文对译稿对比
- 错误识别与分类必须严格遵循 MQM 核心模式中 16 项子错误的定义
- BLEU 计算与 MQM 分析对象限定为大模型生成的中文到英文译文
- 保持高度客观严谨，真实反映译文质量与广告契合度
- 报告术语专业、准确且使用一致，不得遗漏任何已识别错误的统计与归类
- 严格按流程顺序，先完成 BLEU 评分，再进行 MQM 错误识别与分类
