如果多张表的结构不一致会怎样？直接问ChatGPT得到的说明如下。

结构不一致时用追加查询会遇到限制。

（1）列不匹配：多张表的列名、顺序或数据类型对不上时，追加可能无法完成或导致结果列混乱。Power Query 需要列一一对应，否则易报错。
（2）缺失列：某些表缺少其他表有的列，追加时这些列会被自动补到结果里，容易让结构杂乱，需要后续清理。
（3）数据类型不匹配：列类型不同时，Power Query 会尝试自动转换，可能丢数据或出错，这时需要手动调整类型。

因此结构不一致时须先预处理，比如改名、调序、统一类型，再加载到Excel中继续分析。
