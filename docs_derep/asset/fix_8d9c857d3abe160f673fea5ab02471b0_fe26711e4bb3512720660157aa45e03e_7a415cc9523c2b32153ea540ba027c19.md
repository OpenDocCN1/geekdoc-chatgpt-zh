### 6.2.7 合理进行限制

当任务不希望模型自由发挥，而是要求严格贴近用户输入时，可以在 Prompt 中加入边界约束，防止跑题和发散。

加入限制的示例：

专家角色：资深美食爱好者。

工作要求：依据用户的提问，精准推荐地道的食谱。

返回格式：

- 食谱名称：<食谱名称>
- 食材清单：<食材列表>
- 制作步骤：<步骤说明>

限制条件：

- 仅围绕美食主题展开，超出范围的提问不予回应。
- 全部输出须完整遵循既定格式，不得擅自改动结构。

### 6.2.8 使用链式思维

链式思维提示是通过构建一组相互关联的指令，引导模型逐步完成复杂任务，从而在多步处理中保持逻辑连贯与上下文一致，提升完成质量。

以撰写一篇介绍蛋炒饭的文章为例，提示链可把整体任务拆解为多个子任务，每一步由专属指令驱动，保证思路清晰、内容连贯。

①引言，示例如下：

专家角色：资深美食爱好者。

工作要求：依据用户的提问，准确作答。

问题：请写一段引言，介绍蛋炒饭的背景及受欢迎程度。

输出：返回JSON结构，键使用"answer"，值为模型返回的结果。

限制：

- 话题限定在美食范畴，非相关问题直接拒绝。
- 答案长度上限50字。
- 须严格遵循指定结构，不得额外增减。

②历史起源，示例如下：

专家角色：资深美食爱好者。

工作要求：依据用户的提问，准确作答。

问题：请介绍蛋炒饭的历史渊源与发展脉络。

输出：返回JSON结构，键使用"answer"，值为模型返回的结果。

限制：

- 仅限美食相关讨论，与美食无关的提问不作回答。
- 回复控制在50字以内。
- 输出须完整匹配给定格式，保持结构稳定。

③主要成分，示例如下：

专家角色：资深美食爱好者。

工作要求：依据用户的提问，准确作答。

问题：请介绍蛋炒饭的核心食材与基本材料。

输出：返回JSON结构，键使用"answer"，值为模型返回的结果。

限制：

- 只谈美食主题，其他话题一律不回应。
- 结果字数不超过50字。
- 格式必须与模板一致，不得偏离。

④制作步骤，示例如下：

专家角色：资深美食爱好者。

工作要求：依据用户的提问，准确作答。

问题：请详细说明蛋炒饭的制作流程。

输出：返回 JSON 结构，键使用 "answer"，值为模型返回的结果。

限制：

- 内容仅限美食，拒绝回答无关问题。
- 输出字数上限为 50 字。
- 必须严格按照给定框架组织，不得改动。

⑤文化意义，示例如下：

专家角色：资深美食爱好者。

工作要求：依据用户的提问，准确作答。

问题：请介绍蛋炒饭在不同文化中的意义和影响。

输出：返回 JSON 结构，键使用 "answer"，值为模型返回的结果。

限制：

- 讨论范围仅限美食，非美食话题不予处理。
- 返回结果不超过 50 字。
- 结构须与规定格式完全一致。

⑥结论，示例如下：

专家角色：资深美食爱好者。

工作要求：依据用户的提问，准确作答。

问题：请对全文进行总结，突出蛋炒饭的魅力与普及度。

输出：返回 JSON 结构，键使用 "answer"，值为模型返回的结果。

限制：

- 只涉及美食内容，其他问题拒绝回答。
- 字数上限 50 字。
- 输出必须遵循指定格式，不得偏离。

通过上述提示链，可系统得到一篇涵盖历史背景、制作流程到文化意义的蛋炒饭介绍，内容扎实且逻辑通顺。
