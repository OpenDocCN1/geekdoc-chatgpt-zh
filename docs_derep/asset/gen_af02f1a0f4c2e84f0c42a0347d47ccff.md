## 4.1 从细部打磨到整体交付：局部优化与全局生成
圈内常开玩笑说，改一段现成代码是拧螺丝，牵头一个代码项目是造火箭。ChatGPT 在这两种尺度上都能提供支撑。本节会分成四个维度展开，从代码审校、自动补全等微观改动能力，到整段代码生成、复杂问题求解等宏观创作能力，全面梳理它在写代码环节的表现。

### 4.1.1 代码审校与问题排查
代码自动生成的思路并非新鲜事，早期的 Copilot 之类产品，本质上是把 GitHub 上积累的大量片段检索出来供人参考。有开发经验的人都明白，面对一段现成的代码，理解成本往往很高。一旦漏洞多、结构混乱，光是读懂再改动，有时比自己从零写还费时间；贸然照搬则更容易埋雷。

ChatGPT 的优势在于可以对代码做双向审校，无论是它自己产出的结果，还是用户提供的旧代码，都能进行逻辑分析，定位其中的错误点，并给出具体的修改建议，从而让交付的代码更稳健、可信。
