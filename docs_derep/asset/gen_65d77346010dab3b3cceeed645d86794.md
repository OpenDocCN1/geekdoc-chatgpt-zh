### AI提问模型

#### 通用提问公式=情境描述+目标需求+资源约束+输出要求

先客观陈述培训规划的背景，让AI迅速把握需求来处。

要把培训意图说清楚，必须具体可量化，抓住核心导向。

**提问构成**

- 业务目标：培训后要实现的业务结果。

**提问构成**

- 预算限制：总费用、单次费用上限。
- 时间限制：整体周期、员工可投入的时长。
- 师资条件：内部讲师水平、外部合作资源。

明确方案落地要求。

**提问构成**

## 用AI做培训效果评估

### 问题场景

1. 公司重金请外部讲师做领导力培训，结束后反馈平淡，业务也没起色，如何破解投入产出失衡？
2. 很多企业只看过程指标如出勤率、讲师评分，忽视结果指标如行为改变、绩效提升。科学评估才能判断培训是否契合业务，避免浪费。
3. 员工说内容太理论，业务部门说不落地，该如何证明培训价值？
4. 可从三维度切入：能力提升、行为转化、业务成果。用数据说话才能让培训服务业务。
5. 若评估显示效果差，是否直接砍掉？
6. 评估目的是找根因而非终点。如内容与岗位脱节则优化设计；若缺乏实践则增加导师制或行动学习。

### AI提问模型

#### 通用提问公式=培训背景+评估痛点+分析需求

为评估提供基础信息。

**提问构成**

- 培训主题：销售技巧、跨部门协作等。
- 培训形式：线上、线下、混合。
- 参与对象：新员工、管理层、特定岗位。
- 培训周期：单次或系列。

聚焦可量化的评估难题。

**提问构成**

- 评估方法缺陷：仅靠问卷，缺乏行为数据。
- 效果不明显：技能分提升但业绩未动。
- 资源限制：评估成本高难以全覆盖。

明确希望AI完成的具体分析任务。

**提问构成**

- 评估维度：柯氏四级、ROI分析。
- 数据来源：培训记录、绩效数据。
- 输出形式：轻量评估工具、低成本数据采集方案。

### 资料准备

| 要点 | 内容 |
| --- | --- |
| 培训基础信息 | 目标、大纲、讲师、参训名单等。 |
| 评估数据 | 训前训后测评、满意度、绩效等。 |
| 业务场景描述 | 对应业务目标、当前痛点等。 |
| 资源限制 | 评估预算、周期、可用工具等。 |

### 实操示例

我司为50人销售团队开展“客户谈判技巧”2天线下培训，讲师为外部专家。目标是提升成交率，但未设量化指标。

**当前评估痛点**

1. 方法单一：仅课后问卷，平均分4.5/5，但谈判成功率未升。
2. 数据割裂：培训记录与业务数据未打通。
3. 资源有限：希望低成本评估，缺工具和人力。

**请协助**

1. 基于柯氏四级，设计轻量评估方案，重点覆盖行为层和结果层，即是否在工作中应用技巧、谈判成功率与客户复购率。
2. 提供低成本采集方式，如从客户管理系统提取谈判记录、设计3分钟快速调研问卷。
3. 输出评估报告框架，含核心指标、数据源、分析逻辑及改进建议。

### 注意事项

| 要点 | 内容 |
| :--- | :--- |
| **多维度验证** | 需结合真实业务数据验证，避免仅用理论模型。 |
| **简化执行** | 优先用Excel、问卷星等现有工具，降低成本。 |

## 用AI设计职业发展通道

### 问题场景

1. 员工常反馈“看不到晋升希望”，技术骨干离职率年增30%。晋升标准虽有，但透明度不足如何解决？
2. 许多企业把晋升标准等同于发展通道，忽略路径可视化与能力阶梯化。清晰通道能让员工明确位置、方向与路径，降低流失。
3. 不同岗位要求不同，如研发重技术深度、销售重业绩转化，如何统一设计？
4. 通道应分层分类。如技术岗设初级工程师→专家→架构师纵向通道，并叠加技术与管理双通道；销售岗可分客户深耕与市场开拓方向。
5. 若员工达标却无晋升机会，通道是否失效？
6. 通道需与战略动态匹配，建立容量预警。当某层级饱和时触发横向轮岗或项目制晋升，保持通道活力。

### AI提问模型

#### 通用提问公式=组织背景+设计痛点+需求目标

提供基础框架，避免脱离实际。

#### 组织背景

**提问构成**

- 行业属性：互联网、制造、服务等。
- 岗位分类：技术、管理、职能等。
- 员工规模与分布：总部/分支、全职/外包。
- 现有通道：规则与问题。

**提问构成**

- 员工痛点：标准不透明、横向机会少。
- 组织痛点：关键岗位断层、流失率高。
- 资源限制：预算有限难大规模培训。

#### 需求目标

**提问构成**

- 通道类型：单轨、双轨、多轨。
- 能力模型：岗位能力词典、晋升里程碑。
- 配套机制：动态调整规则、晋升答辩流程。
- 输出形式：可视化图谱、低成本落地路径。

2. 标准模糊：依赖主管主观。
3. 缺前瞻性：未来两年聚焦AI与大数据，通道未覆盖。

**请协助**

1. 为技术岗设计管理+专家双通道，明确晋升标准。
2. 生成岗位能力词典，含各层级核心能力。
3. 设计动态调整机制，如AI岗位需求增30%时自动扩容。
4. 输出可视化图谱及低成本实施建议。

## 用AI辅助人才梯队建设

### 问题场景

业务扩张快，关键岗位空缺即手足无措，外招成本高，内提怕能力不足，如何破局？

缺失梯队规划是根因。没有提前储备继任者，核心人才流失即被动。

不同岗位继任要求差异大，技术重深度，管理重协同，如何统一规划？

技术可按技术骨干→架构师→CTO设计，管理可按主管→总监→事业部负责人设计，并为每层级配能力雷达图。

若梯队人才达标却不愿接岗怎么办？

需双轨并行并评估意愿度，对高潜低意愿者通过轮岗、项目参与引导，而非强制提拔。

- 能力缺口：能力与战略不匹配。
- 资源矛盾：培养预算有限。

**提问构成**

- 培养机制：90天培养计划、跨部门轮岗方案。
- 评估工具：胜任力评估表、潜力评分卡。
- 输出形式：建设路线图、低成本培养路径。

# 第4章 AI+绩效管理

绩效管理关乎员工贡献衡量与团队激发。借助AI可让流程更科学、公正、高效。从体系设计到程序细化，从指标分解到目标制定，从问题定位到评价方法，从辅导话术生成到改进方案，再到结果应用机制，AI贯穿全流程，助力以绩效为导向的文化建设。

## 用AI设计绩效管理体系

**问题场景**

年度考核流于形式，员工认为指标不合理，管理者打分凭感觉，结果与调薪晋升关联弱，如何破局？

很多企业把绩效等同于打分，忽略其价值——战略落地与行为引导。指标与战略脱节则员工为考核而工作。

不同岗位性质不同，销售重结果，技术重过程，如何统一？

销售可设业绩达成率+客户满意度+回款周期三维，技术可设交付质量+创新贡献+协作效率三维。将战略拆解为可落地行为指标。

若员工认为结果不公怎么办？

需配套过程反馈如季度面谈和结果申诉机制，并通过跨部门校准会评审异常评分，避免主观偏差。

### AI提问模型

#### 通用提问公式=组织背景+核心痛点+需求目标

描述管理现状，为设计提供土壤。

#### 组织背景

**提问构成**

- 行业属性：服务重体验、制造重效率。
- 战略目标：如三年市场份额提升至30%、成本降15%。
- 现有绩效机制：指标类型、考核周期、结果应用。
- 员工结构：岗位类型、层级、平均年龄。

#### 核心痛点

**提问构成**

- 指标问题：与战略脱节、不可量化。
- 流程问题：周期过长、反馈缺失。
- 结果应用问题：与薪酬脱钩、高绩效流失。

#### 需求目标

**提问构成**

- 指标体系：销售三维指标、技术岗OKR模板。
- 流程设计：季度考核优化、申诉机制。
- 工具支持：面谈话术库、校准会评分表。
- 输出形式：管理制度草案、低成本数字化工具推荐。

### 准备资料

| 要点 | 内容 |
| --- | --- |
