### 核心参考文献速览：测试数据生成与搜索型软件工程演进脉络

**早期探索与约束求解奠基**

自动化测试数据生成的早期实践聚焦于动态执行与符号约束求解。Miller 与 Spooner [65] 率先尝试浮点数测试数据的自动合成；Korel [66] 随后提出动态法，并联合 Ferguson [68] 引入链式策略，Al-Yami [69, 70] 则拓展至断言导向与回归测试场景。国内学者奚红宇、徐红 [67] 同期攻克 Ada 语言测试用例生成工具。进入 90 年代末，Gupta 等人 [72, 73, 75] 推出迭代松弛法与 UNA 技术，针对分支覆盖展开深度优化，单锦辉等 [76] 与 Shan 等 [77] 进一步改进该路径，Edvardsson 与 Kamkar [74] 则对约束求解器性能进行剖析。此外，Zhang 与 Wang [64] 将约束求解器应用于路径可行性分析，Gallagher 与 Narasimhan [71] 构建了 Ada 系统专用测试套件 Adtest。

**搜索型软件工程（SBSE）理论确立**

Harman 等人确立了将软件工程重构为搜索问题的范式。Harman 与 Jones [78] 首倡 SBSE 概念，Clark 等 [79] 系统化阐述“重构为搜索”方法论，Harman [80] 后勾勒未来图景。McMinn [83] 与 Ali 与 Briand [84] 分别从理论实证与系统综述维度，全景式复盘搜索型测试的局部、全局及混合搜索策略。Zhao 等 [82] 则聚焦 EFSM 模型下的生成效率实证。

**优化算法移植：从爬山到退火**

经典优化算法为测试生成提供核心引擎。Goldfeld 等 [85] 早期提出二次爬山法；Yuret 与 De La Maza [87] 改进动态爬山克服局限；Tsamardinos 等 [86]、Hoffmann [88]、Choi 与 Yeung [89]、Xi 等 [90]、Douceur 与 Wattenhofer [91] 等在贝叶斯网络、规划、资源调度、服务器配置及副本部署等领域拓展爬山变体。Metropolis 等 [92] 奠定模拟退火基石，Kirkpatrick 等 [93] 推广其优化应用。Tracey 团队 [94, 95, 96] 将模拟退火深度融入结构化测试数据生成框架，实现程序缺陷自动发现与动态测试统一。

**进化计算赋能：遗传算法与变体**

Holland [97] 奠定自然/人工系统适应理论，Back 等 [98, 100] 系统总结进化策略与算法实践，Whitley [99] 剖析工程落地陷阱。Wegener 等 [101] 率先将进化测试用于嵌入式结构测试，Harman 等 [102] 通过标志移除增强效能。Buehler 与 Wegener [103] 验证自动泊车系统功能测试，Jones 等 [104] 确立遗传算法在结构测试中的地位，Bouchachia [105] 创新引入免疫遗传算法拓展生成多样性。
