人类偏好驱动的强化学习：对话模型的三段式优化路径

在对话系统的技术栈里，RLHF 并不是指单一网络，而是一条把多个子系统串联起来的多阶段流水线。要想搞懂它，可以把它拆成三段来理解：先有通用自回归预训练的语言基座，再用人类问答聚合出来偏好奖励器，最后借助强化学习对语言基座做精调。

### 1. 监督式自回归预训练的语言基座

### 2. 偏好奖励器的构建

奖励器的训练是 RLHF 的核心一环。该模块接收一段或多段文本，输出一个标量分数，用来衡量人类对这段输出的喜好程度。实现方式可以是端到端的语言建模，也可以采用模块化流程，比如先对候选输出进行排序再把排名映射成奖励。分数的精确度直接决定 RLHF 回馈的质量，如图15-7所示。

图15-7 RLHF奖励模型训练的整体流程

### 3. 强化学习视角的微调

过去工程与算法层面都认为用强化学习训语言基座不可行。近端策略优化 PPO 的出现打破了这一限制。PPO 在 RLHF 里计算奖励的具体做法可归纳为：

- 1）把同一提示分别喂给原始语言基座和当前正在微调的策略版本，得到两份输出；把策略版本的输出送入奖励器，获得一个标量奖励。
- 2）把两份输出对比，算出差异惩罚项。该惩罚项被设计为输出词分布序列间 KL 散度的缩放值，用来惩罚策略在每个训练批次里对原始基座产生过大偏离，以保证文本依然连贯合理。
- 3）依据 PPO 的 on-policy 特性，按本批次的奖励指标做优化，并借助梯度约束保持更新过程稳定。

### 15.2.2 RLHF 的工程落地：PPO 方法

前面讲到的 RLHF，本质上是用人类偏好直接对整体输出计算 Reward 或 Loss，这比传统“给定上下文预测下一个词”的损失更贴近真实使用。基于这一思路，ChatGPT 的创造者提出用强化学习把人类反馈信号直接用于语言模型优化。

前文火箭降落任务做完后，相信读者已有体感。现在的任务是把 PPO 以 RLHF 的形式用在对话模型微调上。

在该体系里，PPO 被用来训练对话智能体。通过训练行动网络与评估网络两套神经网络，智能体能依据当前对话状态挑选最合适的回复，提升对话质量。PPO 采用改进的替代目标函数来更新行动网络参数，收敛更快也更稳，比其他基于梯度的强化学习方法更易落地。此外，PPO 还能在训练中引入信任区域机制，对超出范围的更新做裁剪，控制单次更新幅度，保证稳定，如图15-9所示。

把训练拆开看，大致包含以下几步。

- 定义环境与动作空间
环境由用户输入和机器人回复构成。PPO 需要明确机器人的动作空间，即所有可能的回复选项，每个回复以 Softmax 概率表示。
- 定义策略网络与价值网络
PPO 需要行动网络负责决策行为，评估网络负责评估行动表现。所述模型里可直接复用预训练语言模型作为两者基础。
- 定义 PPO 的损失函数
PPO 的替代目标函数由 ratio 和裁剪后的 surrogate objective 组成。ratio 是新旧策略的比值，裁剪操作确保更新不会过大而破坏稳定性。
- 使用 PPO 方法训练智能体
每个训练周期里，算法依据当前状态选动作并获得奖励，然后用 PPO 更新行动、评估网络参数以最大化累计奖励。更新时配合信任区域限制步幅。
- 重复训练直至收敛
持续迭代直到智能体性能稳定。每个周期结束评估表现，与历史表现对比决定是否继续训练。

## 3. 强化学习视角的微调
长期以来受工程与算法限制，人们认为强化学习无法用于语言模型。PPO 方法的出现改变了局面。其奖励函数计算步骤见图15-8：

### 15.2.2 RLHF 的工程落地：PPO 方法

前面介绍了所述系统所使用的输出人类反馈行为的 RLHF 方案，可以看到直接使用人的偏好来对模型整体的输出结果计算 Reward 或 Loss，显然要比传统的“给定上下文，预测下一个词”的损失函数合理得多。基于这个思想，创造者提出了使用强化学习的方法，利用人类反馈信号直接优化语言模型。

在前面的章节中，我们完成了火箭降落任务，相信完成的读者会有一种强烈的自豪感。现在开始进行一项新的任务，即将 PPO 以 RLHF 的训练形式对对话模型进行微调。

在该体系中，PPO 用于训练对话智能体。通过训练智能体的行动网络与评估网络，智能体能够在对话中根据当前状态选择最优的回复，从而提高对话的质量。PPO 使用一个改进的替代目标函数来更新行动网络的参数，这个替代目标函数不但更快，而且更可靠，因此比其他基于梯度的强化学习方法更容易实现。此外，PPO 还可以在训练过程中使用信任区域方法来限制每次更新的幅度，以确保更新的稳定性，如图15-9所示。

## 图15-9 RLHF对大语言模型训练的三个阶段

对话模型对大语言模型的训练可以具体分成以下几个步骤。

### 1. 定义环境和动作空间
算法的环境包括用户输入和机器人回复。对于 PPO，我们需要定义机器人的动作空间，即机器人可以采取的所有可能的操作。在这种情况下，机器人的动作可以是不同的回复，每个回复都有一个概率，这些概率可以表示为 Softmax 输出。

### 2. 定义策略网络和价值网络
在 PPO 中，我们需要定义两个神经网络：一个是行动网络，用于确定机器人的行为；另一个是评估网络，用于评估行动的性能。在所述模型中，我们可以使用预先训练的语言模型作为行动与评估网络。

### 3. 定义 PPO 的损失函数
PPO 使用一个改进的替代目标函数来更新行动网络的参数。这个 surrogate objective function 包括两部分：一部分是 ratio；另一部分是 clipped surrogate objective。ratio 是行动网络新旧策略的比率，而 clipped surrogate objective 通过对 ratio 进行剪裁来确保更新的稳定性。

### 4. 使用 PPO 方法训练智能体
在每个训练周期中，算法会根据当前的状态选择一个动作，并且根据选择的动作获取一个奖励。然后，使用 PPO 更新行动与评估网络的参数，以最大化累计奖励。更新过程中还需要使用信赖域方法来限制每次更新的幅度，以确保更新的稳定性。

### 5. 重复训练直到收敛
算法会一直重复训练智能体，直到智能体的性能收敛。在每个训练周期结束后，算法会评估智能体的性能，并将智能体的性能与之前的性能进行比较，以确定是否需要继续训练。
