最基础的 Softmax 先算指数再整体求和归一化，和的数值几乎为 1。

def norm(z):

    exp = np.exp(z)

    return exp / np.sum(exp)

当需要按最后一个轴归一化并且保持广播形状时，可以显式指定 axis 并用 expand_dims 恢复维度，这样即使是 10 组 2 类的批量也能正确处理。

def norm(z):

    axis = -1

    exp = np.exp(z)

    return exp / np.expand_dims(np.sum(exp, axis=axis), axis)
