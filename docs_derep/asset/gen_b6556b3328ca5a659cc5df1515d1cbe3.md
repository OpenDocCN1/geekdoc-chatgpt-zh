批复的组成框架大致涵盖标题、主送单位、正文内容其中包含引述、答复以及结束语、发文机关署名、成文日期等要素。

### 1.3.13 议案

议案呈现出以下几方面特征。

1. 指向明确。议案通常由各级人民政府径向本级人民代表大会或其常务委员会递交。
2. 政策属性强。议案所涉事项一般都是需交由人民代表大会审议决定的议题。
3. 时效要求高。议案多在同级人民代表大会或其常务委员会召开会议期间提出。

按内容划分，议案可归为立法类议案、决策类议案、任免类议案三类。

议案的款式构成一般包含标题、主送机关、正文、发文机关署名并注明签发人姓名且亲笔签署、成文日期等项目。

### 1.3.14 函

函的共性体现在以下三点。

1. 平等关系。函多用于无隶属关系的机构之间进行正式沟通、协商或问答，体现出双方地位对等。
2. 适用面广。函可用于各类组织机构间的正式文书往来，主体覆盖范围很大。
3. 事项单一。一份函一般只处理一个事由，篇幅宜精炼明晰。

依用途不同，函可细分为告知函、商洽函、询问函、答复函、请批函等类型。

函的版式通常由标题、主送机关、正文、发文机关署名、成文日期等构成。

### 1.3.15 纪要

纪要的突出特点在于。

1. 求真务实。纪要所载内容必须真实，与会议实际进程和形成的决议相吻合。
2. 提炼概括。纪要要抓住要点，以简明扼要的方式传递核心信息。
3. 逻辑有序。纪要需条理分明，对内容进行合理的归纳总结。

按照会议类型，纪要可分为工作会议纪要、代表会议纪要、座谈会议纪要、联席会议纪要、办公会议纪要、汇报会议纪要等。

纪要的格式一般包含标题、正文即会议概况与议定事项、出席人员、请假人员、列席人员等栏目。

# 第2章 常用的AI写作工具

本章要介绍的几款常用AI写作助手，本质上都是大语言模型，即依托海量文本数据训练而来的深度学习模型，它们具备生成自然语言文本并理解文本语义的能力。

在动手使用AI写作工具前，先弄清楚一个关键概念——提示词。

简言之，提示词就是递交给AI的指令，或者说向AI提出的问题。若想拿到高质量的回复，就得给出高质量的问题。总体来看，一个好用的提示词包含两类要素：一是明确的任务目标，二是服务该目标的背景信息，比如输出规范、示例等。

掌握提示词的概念后，还需要熟悉几条与AI高效协作的基本方法，有助于AI更精准地把握需求，从而撰写出高质量的公文。

- 技巧1：为自己或AI设定清晰具体的角色定位。
- 技巧2：向AI提供详尽的背景资料。
- 技巧3：向AI提出明确具体的产出要求，如格式等。
- 技巧4：提示效果不佳时，可请AI协助优化提示词本身。
- 技巧5：在必要时使用定界符例如“###”或“****”来分隔提示词的不同部分。
- 技巧6：在必要时向AI提供详细的任务执行步骤。

## 2.1 ChatGPT

ChatGPT的全称是Chat Generative Pre-trained Transformer，由OpenAI开发的一款基于大语言模型的AI对话程序。

ChatGPT表现突出，远超此前出现的聊天程序，上线后迅速吸引大量用户关注，也带动了大语言模型浪潮的兴起。其他互联网公司纷纷推出自家大模型，业界津津乐道的“千模大战”由此开启。

### 2.1.1 ChatGPT的特性与能力

ChatGPT的核心特性可归纳如下。

- 训练语料规模庞大。ChatGPT基于海量文本进行训练，因而能够理解并生成自然语言。
- 多层Transformer架构。GPT架构由多个Transformer层堆叠而成，可捕捉文本中的复杂模式与关联。
- 预训练加微调。ChatGPT先进行通用预训练，再针对特定任务进行微调，以提升如聊天等场景的性能。
- 文本生成与理解并重。ChatGPT既能生成文本，也能理解输入，从而实现更有效的对话。
- 用途多样。尽管主要用于对话系统，它同样可应用于文本摘要、机器翻译、问答系统等自然语言处理任务。
- 生成文本质量高。ChatGPT输出的文本通常可读性、一致性与准确性较好，但也可能出现不准确或不相关的情况。
- 上下文感知。ChatGPT能够理解前文语境，据此生成或回应内容。
- 无监督学习。预训练阶段采用无监督方式，从大量未标注文本中学习。
- 可扩展性强。GPT架构可通过增大模型规模来提升性能。
- 局限与偏见。训练数据可能含有社会文化偏见，因而模型输出或会反映这些偏见。
- 知识固化。模型训练完成后知识是静态的，无法实时更新或获取最新信息。

这些特性让ChatGPT成为功能强大且多样的自然语言处理工具，同时也存在一定局限。

ChatGPT的能力十分全面，主要体现在以下方面。

- 文本生成。可产出自然流畅且连贯的文本，在自然语言生成任务中表现优异。
- 对话管理。虽非专为对话系统设计，却能有效参与并管理多轮对话。
- 上下文理解。可捕捉长序列依赖关系，进而理解上下文并据此回应。
- 问题解答。能够基于给定语境回答具体问题，但准确度不及专业问答系统。
- 文本摘要。能理解长文本并提炼出简洁摘要。
- 语言翻译。翻译能力存在，但不及专业机器翻译系统。
- 内容推荐。基于上下文推荐相关信息或行动。
- 文本分类与标注。虽为生成模型，也可用于部分分类或标签任务。
- 情感分析。可识别文本中的情感倾向，如正面、负面或中性。
- 自然语言推理。可完成基础逻辑推理任务，但不及专用推理模型。
- 创意写作。凭借生成自然一致文本的能力，可用于创意写作与故事创作。
- 代码生成与理解。能生成简单代码片段，并能在一定程度上理解代码。

ChatGPT支持多种语言的输入输出，支持多种文本输出格式，包括纯文本、Markdown、HTML、代码等。

目前ChatGPT并不支持直接语音输入或文件上传，但GPT-4版本支持丰富的插件，可通过插件实现语音输入、文件上传等功能。
