# 财务与法务场景的智能定位

在财务类的应用里，模型更多是扮演以数据为基础的运营顾问。遇到财税方面的困惑时，使用者的习惯是直接向它求证结论，而非让它去做账务处理。在法务类的应用里，定位同样偏向咨询，能够就法律上的不明白之处作出解释，也能参与法律文件的起草，并提供智能提醒来降低风险。

# 交付章节标题的迭代路径

针对“高效交付，优质课程设计”这一条，先前的意见认为表述范围过窄。交付并非只有课程，本书面向的超级个体可能交付各种产品或服务，标题应覆盖整体交付场景。第一次改写为“卓越交付策略：为超级个体提供高效的产品与服务体验”。

随后得到进一步指正，核心不在泛泛的高效，而在于智能体在交付环节对质量与速度的双重拉升。第二次改写为“智能赋能交付：提升质量与速度，助力超级个体成功”。最终确定的第四篇大标题为：

# 智能助攻交付：提速增质，成就超级个体传奇

该标题在成书时保持原样，未再改动。

在实际写作阶段，思维分身被大量调用。例如在“撰写品牌故事”一章中，“品牌故事也是最高级且最便宜的广告，能够长期累积效应，为你的IP创业带来更大的成功机会”这一判断，便是由“思维肖厂长”从150万字素材库中提炼出来的。

# ChatGPT 高阶用法：自循环流派

第一篇介绍 B.O.K.E. 方法论时曾提到 ChatGPT 的高阶用法——自循环流派。通过编程思维在提示词里规定执行流程与分支，为模型装上发动机。

在“撰写品牌故事”章节背景部分的引导思路包括：主打产品或服务、创业初期的成立时间缘起与困难、发展轨迹中的里程碑与转折、市场份额与独特优势、已取得的实际成果如案例评价奖项、服务人群与使命愿景、未来规划方向。上述内容均由自循环提示词生成，后续做了人工微调。

# 提示词库共建实录

模型：GPT-4

LY 阅读以下说明，理解后回复“我们开始吧：”

请担任我的 Prompt Database Creator。目标是基于我提供的场景制定详尽的提示词库。

流程为先判断场景主题，再输出三部分：主分类提示词，即该场景可提问的类别归纳；三条改进建议；三到十个备选主分类。在末尾提示四个选择：对主分类提出改进建议；输入“使用此提示”进入二级生成；输入“重新启动”重来；输入“退出”结束对话。

若选择生成二级，则基于最后确认的主分类清单，穷尽该分类下的具体提示词。

场景示例为撰写品牌故事。

初始主分类为品牌背景、价值观与使命、核心产品与服务、成功案例、品牌未来愿景。建议围绕覆盖度、受众术语、目标匹配度给出。

备选补充为品牌创始人背景、品牌形象与风格、品牌发展历程、客户评价与反馈、社会责任与影响、市场地位与竞争力、企业文化。

按要求将备选并入后，主分类扩充为十二项，随后精简为：核心产品、品牌背景（含创始人背景）、发展历程、市场地位（含市场竞争力）、品牌成果（含成功案例、客户评价与反馈）、使命愿景、展望未来。

确认后生成的子项提示如下：

核心产品：主要产品线、产品特点与优势、目标市场和消费者群体
品牌背景（含创始人背景）：创立时间和地点、创始人故事与经历、公司愿景与初衷
发展历程：重要历史事件、产品线扩展与创新、公司规模变化
市场地位（含市场竞争力）：行业地位与声誉、主要竞争对手、独特竞争优势
品牌成果（含成功案例、客户评价与反馈）：典型成功案例、客户评价与见证、获得的奖项与荣誉
使命愿景：公司核心价值观、长期发展目标、对社会环境的贡献
展望未来：未来发展计划、潜在市场机会、预期挑战与应对策略

有了这样的分层提示框架，面对具体任务时无需反复整理思路，模型会先为自己生成提问结构，用户只需做选择即可。
