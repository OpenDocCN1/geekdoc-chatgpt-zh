# FastAPI + MCP，几行代码就把数学天气能力交给 DeepSeek

想让大模型不只是聊天，还能实时算数、查时间、查天气？思路很简单：用 FastAPI 暴露几个业务接口，再把它包装成 MCP 服务；客户端通过 SSE 建立会话，拿完整工具清单给 DeepSeek 判断该用哪个工具，最后把工具返回的结果再喂回去生成自然语言答案。下面是完整落地的思路和关键代码。

### 服务端：把 FastAPI 变成 MCP 提供方

首先定义业务接口，这里演示了一个天气查询接口，返回城市名和固定示例温度 23℃。时间接口直接返回当前时间字符串。

### 客户端：通过 SSE 调用工具并让 LLM 决策

客户端先用 sse_client 连到 http://localhost:8000/mcp，创建 ClientSession 并初始化。拿到工具列表后，用 transform_tools 把原始 Schema 简化成 name、description、parameters 的结构，便于模型阅读。

向 DeepSeek 发起第一次请求时，系统提示里会带上全部工具描述和用户原始问题，要求模型只输出标准 JSON：{"tool":工具名,"tool_input":参数字典}。模型返回后清理掉可能的 Markdown 标记，解析出工具名和参数，再通过 session.call_tool 真正执行。工具返回后，把问题、调用名、返回结果一起拼成新提示，再次调用同一个模型生成最终的人类可读答案。

##### 工具描述转换器

def transform_tools(tools):
    tool_list = []
    for tool in tools:
        parameters = {}
        required = tool.inputSchema.get('required', [])
        for name, prop in tool.inputSchema['properties'].items():
            parameters[name] = {
                'type': prop['type'],
                'description': prop.get('description', ''),
                'required': name in required
            }
        tool_list.append({
            'name': tool.name,
            'description': tool.description,
            'parameters': parameters
        })
    return json.dumps(tool_list, ensure_ascii=False, indent=2)

def llm_deepseek(question,client):
    response = client.chat.completions.create(
        model="deepseek-chat",
        messages=[
            {"role": "user", "content": question},
        ],
        max_tokens=1024,
        temperature=0.99,
        stream=False
    )
    generated_text = response.choices[0].message.content  # 提取文本内容
    return generated_text

async def main(question = "25+38是多少?"):
    async with sse_client("http://localhost:8000/mcp") as streams:
        async with ClientSession(streams[0], streams[1]) as session:
            await session.initialize()
            # 获取工具列表
            tools = (await session.list_tools()).tools
            s = transform_tools(tools) + "\n"
            response, client = ask_llm_deepseek(question, s)
            # 清理Markdown标记
            response=response.strip().replace('json', '').replace('', '').strip()
            # print(response)
            mtools = json.loads(response)  # 现在response是纯JSON字符串
            print("mtools: --> ",mtools)
            if 'tool' in mtools:
                tool_name = mtools['tool']
                tool_input = mtools['tool_input']
                # 调用工具
                print("调用工具:", tool_name, tool_input)
                ret = await session.call_tool(tool_name, tool_input)
                if ret:
                    try:
                        r = json.loads(ret.content[0].text)
                    except:
                        r = ret.content[0].text
                    print("工具返回结果:", r)
                    questions = f"用户的问题是{question},根据{tool_name}的返回结果为: {r}, 根据以上信息,回答问题。"
                    r = llm_deepseek(questions,client)
                    return r
