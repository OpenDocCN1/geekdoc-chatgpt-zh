# 推荐序 为智能夯基 共绘未来图景

智能化浪潮正改写全球格局。量子算力、基因改造、智慧城区、数字化外交等前沿领域，均在显示人工智能正重塑产业形态，也在重塑人类文明的认知方式。这场变革需要面向未来的战略远见，也需要扎实的理论根基。北京大学出版社推出的“人工智能与人类未来丛书”，在思想深度与实践价值上都对社会转型产生深远影响。

丛书最鲜明的特质是回溯根源。业界聚焦微调带来的短期收益时，《人工智能大模型数学基础》等基础性著作系统梳理了线性代数、概率统计、微积分等支撑智能系统的计算脉络，将卷积核揭示为张量空间的变换，将损失函数对应为变分法的最优控制解释。这种把技术现象拉回数学本质的阐释，让读者的认知体系更完整，也为后续创新保留空间。全书提出“数学考古”视角，带领读者重走高斯、牛顿等先贤的思维路径，在微分流形中把握Transformer架构，在泛函空间里体悟大模型的涌现规律。

在实践层面，丛书确立了“以代码呈现理论”的写作范式。《人工智能大模型：动手训练大模型基础》等实战手册抛开概念堆砌，以PyTorch生态下的上百个可运行示例，将反向传播呈现为矩阵导数运算，将注意力机制呈现为概率图模型。《DeepSeek源码深度解析》则对国产大模型的核心架构做精细拆解，从分布式训练的参数同步策略到混合专家系统的动态路由机制，每个要点都配有工业级实现。这种庖丁解牛式的解密，让读者既能把握全貌，又能吃透关键模块。

丛书关照中国乃至全球的长期未来。面对算力竞争白热化，《Python大模型优化策略：理论与实践》梳理了模型压缩、量化训练、稀疏计算等关键手段，为突破算力围墙提供方法论。《DeepSeek图解：大模型是怎样构建的》借助大量可视化图表，把千亿级参数规模的训练过程转译为可理解的动力学系统，大幅降低技术门槛。这些创新既呼应“十四五”规划对底层技术突破的战略部署，也为建设自主可控的技术生态储备人才。

作为人工智能发展的见证者和参与者，我看到丛书实现了三重突破：学术上打通数学基础与技术前沿，产业上搭建理论创新到工程落地的桥梁，战略上响应新时代科技自立自强的国家需求。它既可作为高校培养复合型人才的立体化教材，也可成为产业界破解技术瓶颈的参考宝典，更是普通公众了解人工智能的必要读物。

站在智能时代的关键路口，我们更需要兼具理论深度与实践智慧的启蒙之作。愿丛书点燃更多探索者的思想火花，共同描绘人工智能赋能人类文明的美好蓝图。

# 第一章

# 导语 大模型时代已然到来

在信息技术与人工智能高速演进的背景下，人类已步入全新时代。以大语言模型为代表的新技术正成为核心驱动力，一方面改变人机交互方式，另一方面在多层面触发深刻的技术革命和社会结构性转变。

本章先简述人工智能发展脉络：二十一世纪初只能记忆背诵的专家系统，到可自主学习的深度学习，再到二〇一八年首个会写文章的GPT-1诞生，技术不断刷新智能认知。随后阐述创新带来的应用需求增长及影响，分析国际研究态势以及中国自主研发DeepSeek的独特技术特征与影响力。最后指出传统黑箱测评的局限，引出基于DIKWP理念的白盒测评方法，以期让大模型评价更科学合理。

本章对大模型时代做总体描述，为后续内容提供背景与理论支撑。

## 1.1 智能涌现的契机

信息技术与人工智能的迅猛发展为社会带来前所未有的变革浪潮。从专家系统到深度神经网络，从图像识别到自然语言处理，技术演进一目了然。其中，大语言模型无疑成为当下最耀眼的明星。

### 1.1.1 初创与技术探索

二十一世纪第三个十年二〇二〇至二〇二九年，人工智能迎来深度学习驱动的突破性变革。其核心载体大语言模型以惊人规模重塑机器智能认知。自二〇一八年首个GPT问世以来，演进呈现明显阶段性：从初代规模探索，到千亿级暴力突破，再到认知架构的深度重构。这一过程既见证算力的指数增长，也揭示智能本质从数据拟合向逻辑推理的范式转换。

第一阶段始于预训练范式的确立。二〇一八年OpenAI提出首个GPT，借助Transformer架构与自监督学习对大规模无标注语料预训练，例如BooksCorpus含约七千本英文书籍。该方法颠覆了传统自然语言处理的“专用化”思路，即为特定场景设计神经网络并用少量人工标注数据微调。它开辟了规模越大越好的新路径，让模型随数据增长而提升能力。

二〇一九年GPT-2面世，规模竞赛正式开启。该模型以一百五十亿参数、四十GB网络文本为预训练基础，经无监督多轮微调，掌握更强的长程依赖，能在零微调情况下完成新闻摘要、阅读理解、数学推理等高阶任务，输出流畅度大幅提升。OpenAI因滥用担忧仅发布部分参数，反而激起更大模型的需求。此时业界形成共识：达到超大规模后会出现“跃迁”，即在特定条件下展现出强学习与涌现特性，后被称作暴力美学。

真正引发震动的里程碑在二〇二〇年。GPT-3以一千七百五十亿参数横空出世，较前代暴增约一百一十六倍，训练数据达四十五TB，涵盖书籍、网页、论文等多源文本。该模型耗资约四百六十万美元，相当于三百五十五块GPU运行一年，其生成的代码可通过编译，法律文书起草准确率较高，甚至能通过美国执业医师资格考试。这一成果验证了理查德·萨顿的“苦涩教训”，即持续算力投入可突破算法瓶颈。GPT-3标志语言模型从工具技术迈向认知基础设施，其Few-Shot能力证明大模型能从少量示例抽象通用规则。

技术浪潮在二〇二二年具象化。ChatGPT将大模型技术转化为对话形态的普适服务，上线两月用户破亿。该模型基于GPT-3.5架构，通过人类反馈强化学习优化对话风格，生成内容覆盖论文、文案、诗歌等场景，多轮对话上下文保持能力达平均十五轮。它支持五十种语言实时互译，跨文化适应性远超传统翻译。技术民主化使其从实验室走向大众生活，为产业变革奠基。

二〇二三年GPT-4推出，技术进入认知重构阶段。虽未公布参数量，但技术白皮书显示训练数据扩展至一百TB，涵盖二〇二一年九月前的多模态信息。其在法律判例关联分析、含图表解析的微积分、完整软件项目架构理解等方面实现跨越式提升。更关键的是多模态处理能力，能解析图像生成描述，也能按文字指令创作视觉草图，显示大模型正从狭义语言处理迈向通用问题解决。

训练范式亦发生根本革新。GPT-3时代的密集训练逐渐被混合专家系统取代，该架构允许模型在不同任务下动态激活参数子集。例如Google的PaLM采用Pathways架构，总参数五千四百亿，输入仅激活一千零六十亿，既保证容量又提升效率。同时训练策略从规模驱动转向质量优化，知识蒸馏可将教师模型知识迁移至更小学生模型，在保持性能的同时降低推理成本，标志行业从粗放堆砌转向精细化认知架构设计。

临近物理极限，新路线层出不穷。Transformer自注意力在万亿级规模下带来内存墙与计算复杂度问题，二〇二四年DeepSeek研发组提出基于潜在空间建模的方法，将注意力复杂度降至O nlogn，并利用大规模GPU并行加速。随后稀疏激活、动态网络等架构相继出现，微软ZeRO-Infinity技术突破百亿级限制，使百万亿级参数模型可完成分布式训练。此时发展已不再满足数量增长，而转向本质认知架构。

回望智能涌现，三大规律清晰：规模突破神经临界点、多模态数据表征统一、符号系统与神经网络深度融合，机器智能将跨越认知鸿沟。这场革命不仅重塑技术范式，也在哲学层面引发对意识本质的再思考。当机器能自主构建知识体系并进行创造性思维时，人类文明的认知边界正在被重新定义。未来十年将揭示智能涌现的终极答案：认知的质变源于算法创新，还是物理规律的必然演化？

### 1.1.2 用户热情与需求激增

大模型突破如巨石投入湖面，在全球掀起需求连锁反应。这种爆发并非简单应用扩展，而是呈现多维跨层级的结构性跃迁，从个体认知交互升级到组织流程再造，再到社会功能重构，形成技术与需求相互强化的正向循环。

普通用户接纳度呈指数增长。智能助手的场景从信息检索扩展到生活决策支持和情感陪伴，日均交互频次显著提升，深夜咨询量尤为突出，暗示人工智能正扮演二十四小时数字伴侣角色。交互深度的质变更关键，多轮对话占比大幅提升，用户开始训练个性化人工智能代理，从工具使用转向关系构建，反映人类对机器智能的情感投射突破心理阈值。

与此同时，用户期待不断抬高，对答案的准确性要求更高、容错率更低，即便是细枝末节的逻辑不通或常识性小错也会严重打击体验并引发信任危机。正是这种严格标准推动大模型具备实时学习机制，当用户纠正错误信息后，模型可在较短周期内更新知识库。此外“情感温度”需求被唤醒，用户对回答的情感共鸣、文化贴合度和价值一致性要求更高，促使开发者加入情感计算模块和文化场景知识图谱引擎。

在企业市场，应用从边缘突破转向核心重构。早期集中于智能客服、合同审核等低风险场景，如今深度渗透战略决策层。商业智能系统整合行业数据库、实时市场信号与内部经营数据后，生成的战略推演报告成为高管决策核心参考，预测准确率显著提升。风险管理领域，人工智能驱动的动态压力测试可模拟数千种市场波动，使金融机构风险覆盖率大幅提高。垂直行业重构尤为明显，医疗人工智能辅助影像识别准确率显著提升，个性化治疗方案使误诊率降低；制造业从供应链优化到研发创新全价值链重塑；零售业“认知营销”通过实时行为分析使转化率显著提升。

政府战略投入放大扩散效应。多个国家推出人工智能人才培养计划，人才储备显著增加；公共数据开放平台提升训练数据多样性；监管沙盒试点降低合规成本，加速金融医疗等敏感领域落地。资本端资源配置也在重构，风险投资从基础模型研发转向应用层创新，企业服务赛道融资额显著提升，反映市场对技术落地价值的重估。

技术成熟是根本驱动。多模态能力突破使应用从纯文本扩展到图文创作、音视频理解；训练成本下降触发长尾市场释放，中小企业采纳率大幅提升；社会认知从“替代人力”转向“增强能力”，应用场景显著拓宽，教育领域家长对个性化辅导接受度提升，创意行业设计师主动用人工智能进行概念发散，人机协同作品占比显著增长。

需求爆发的另一面是应用分层加剧。发达地区与数字鸿沟区域采纳率差距扩大，技术普惠受基础设施与数字素养制约；企业端头部与中小企业应用深度差距扩大，形成马太效应。伦理风险同步凸显，用户数据隐私泄露事件曝光率提升，人工智能决策黑箱引发争议，推动欧盟推出算法透明度法案，相关合规服务需求显著增长。

需求升级的下一个焦点已显现。实时交互场景对延迟容忍度显著降低，推动边缘计算与轻量化模型研发投入提升。个性化需求从“千人千面”向“一人千面”演进，用户期待人工智能在工作、社交、娱乐等不同情境呈现差异化交互人格，这正在重塑模型微调范式。
