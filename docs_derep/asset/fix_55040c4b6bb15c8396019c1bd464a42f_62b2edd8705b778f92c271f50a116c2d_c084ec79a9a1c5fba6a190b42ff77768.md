从做法上看，InstructGPT 可以归纳为两条路线：一条是有监督微调 SFT，另一条是基于人类偏好的强化学习 RLHF，后者先训练奖励模型再做强化学习。下面分别展开。

在 Few-shot 模式下，GPT-3 面对同一个下游任务时往往使用同一套任务描述模板，这种用法和真实使用场景差异很大。实际用户不会刻意套用固定话术，而是按自己的表达习惯描述需求。InstructGPT 的监督微调就是为了缩小这一差距。训练时先从真实用户请求里抽取任务描述样本，再让标注员对描述进行续写，得到高质量的问题答案，最后用这些真实任务与对应答案对模型做微调。

RLHF 的核心思想是对模型产出打分，符合标准的回答给予高回报以鼓励生成，不符合标准的给予低回报以抑制生成。人工打分成本高效率低，于是用奖励模型来模拟人类评价。具体做法是让模型针对同一问题生成多篇文本，再请评分员按好坏排序，用排序数据训练奖励模型复现人类偏好。训练目标本质是回归，考虑到生成文本的多样性和复杂性，奖励模型通常会采用与主模型体量相当的设计。训练完成后即可用奖励模型替代人工对 GPT 进行强化学习。

流程是先用 GPT 生成一篇内容，再用奖励模型对摘要进行评分，并借助 PPO 算法优化 GPT。优化目标为

E_{(x,y)~π^RL_φ}[r_θ(x,y) − β log\frac{π^RL_φ(y|x)}{π^{SFT}_φ(y|x)}] + λE_{x~π_pretrain}log π^RL_φ

其中，第一项为 PPO 的优化目标，r_θ(x,y) 是训练好的奖励模型，π^RL_φ(y|x) 是强化学习模型，φ 是待优化参数。答案得分越高越贴合人类喜好，最大化第一项就是让模型更迎合偏好。随着模型更新，强化学习产生的数据会与奖励模型训练数据逐渐偏离。为避免偏离过大，引入 KL 散度惩罚 β log\frac{π^RL_φ(y|x)}{π^{SFT}_φ(y|x)}，其中 β 为超参数，π^{SFT}_φ(y|x) 来自监督微调模型。第二项是为了防止能力坍缩。单独使用 PPO 会导致模型在通用自然语言处理任务上大幅下滑，因此加入 λE_{x~π_pretrain}log π^RL_φ 使模型分布与预训练数据对齐，其中 λ 控制强度，

π\_pretrain 是训练前数据的分布。如图 8-16 所示，InstructGPT 模型 PPO-ptx 以及未混合预训练的变体 PPO 都明显优于 GPT-3 基线 GPT、GPT prompted。

# 8.2.5 Visual ChatGPT

前面提到的 GPT 技术基本都局限于纯文本，在生产生活里往往需要图文等多模态交互。Visual ChatGPT 是一种把 ChatGPT 与视觉基础模型 VFM 结合的多模态问答系统。VFM 通常指计算机视觉里的一组基础算法集合，比如 Stable Diffusion、BLIP、ControlNet 等，它们把通用视觉能力迁移到具体应用，并作为复杂系统的基石。

Visual ChatGPT 把一系列 VFM 接入 ChatGPT，让用户可以用文字和图像同时对话，并支持复杂的视觉指令，让多个模型协同工作。除了像普通 ChatGPT 那样的语言问答，它还能基于输入图片做视觉问答 VQA、生成与修改图片、去掉不需要的元素等。系统还能理解搜索、查询类指令，并具备修改和改进输出的反馈回路，可以根据反馈不断调整和提升。

图 8-17 是一个使用 Visual ChatGPT[325]的实例，用户上传了一幅黄色花朵的图，并输入复杂指令：“请基于预测深度生成一朵红色的花，然后让它像卡通画一样。请一步一步地完成”。在 Prompt Manager 的帮助下，Visual ChatGPT 启动了相关的视觉基础模型的执行链。具体是先用深度估计模型检测深度信息，再用深度到图像 Depth-to-Image 模型生成带深度信息的红花图像，最后用基于 Stable Diffusion 风格转换的视觉基础模型把图像风格转为卡通。在该管道中，Prompt Manager 作为 ChatGPT 的调度器，提供视觉格式类型并记录信息转换过程。最后当 Visual ChatGPT 从 Prompt Manager 获得“卡通”的提示时，结束执行管道并展示最终结果。

为了在 ChatGPT 和视觉基础模型之间建立高效连接，团队设计了一系列提示并把视觉信息注入 ChatGPT。新型 Prompt Manager 明确每个视觉基础模型的能力、输入输出格式，并把不同视觉信息转成语言格式以便 ChatGPT 理解和处理。它还能处理不同视觉基础模型之间的历史记录、优先级和冲突。Visual ChatGPT 利用这一模型集合的反馈，迭代地构建视觉理解和生成能力。图 8-18 为 Visual ChatGPT 的系统架构。

# 扩散模型 理论、应用与代码实践

## 8.3.1 算法研究

从算法层面看，扩散模型和 GPT、大模型一样都走生成式预训练路线，可能的研究方向包括：

- 当数据量和参数量持续上涨时，GPT 类大模型会出现性能持续提升并在某个节点跃迁，出现涌现能力。扩散模型是否具备同样的增长规律、是否会有涌现现象值得探索，但训练成本极高，如何在放大参数时控制优化难度也是关键。
- ChatGPT 等系统的重要提效手段是在训练中引入基于人类反馈的强化学习微调，用奖励模型对齐偏好。把这种做法迁移到扩散模型中，用基于人工标注的 Reward Model 进行强化微调，有望在 Human Evaluation 维度带来明显提升。
- LLaMA[326] 等大模型开源后，社区兴起只改少量参数的适配器微调思路，不动主干模型，通过指令集和适配器挖掘已有知识。类比来看，如何用低成本方式微调 Stable Diffusion 等扩散模型以适配新任务，比如 ControlNet，是值得深入研究的。

## 8.3.2 应用范式

从应用来看，GPT 类大模型已能覆盖大量任务，扩散模型的应用形态仍在探索中：

- 目前扩散模型在条件生成上表现突出，能输出逼真且符合提示语义的样本。但在认知推理、少样本泛化等领域的研究较少。把扩散模型拓展到更多应用范式，逼近 GPT 类模型的应用广度，对释放其潜力很重要。
- Visual ChatGPT 里扩散模型被当作 VFM 使用，多模态问答中自然语言和多模态特征都很关键。开发语言扩散大模型乃至多模态扩散大模型，以及研究不同模态的扩散模型如何与基于 LLM 的大模型协同，都是下一步方向。
