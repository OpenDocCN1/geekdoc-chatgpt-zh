优化器实战对比：SGD 与 Adam 的收敛差异

选优化器不只是参数设置，更是训练节奏的决定。下面的两组 PyTorch 小实验，用最直观的方式展示了不同策略在不同任务上的表现。

第一组在经典的鸢尾花数据集上做三分类。数据先做标准化和 7:3 划分，随机种子固定为 42，保证结果可复现。模型结构非常简单：输入层接一个 16 维的隐藏层，再映射到 3 个类别，激活用 ReLU，损失选用交叉熵。分别用 SGD 和 Adam，学习率都设为 0.01，训练 50 轮，每 10 轮记录一次损失。训练完后在同样的测试集上评估准确率。

结果很清晰：SGD 的损失下降缓慢平稳，从第 10 轮的 0.9899 慢慢降到第 50 轮的 0.8710。Adam 的下降则明显更快，第 10 轮就已经是 0.8359，第 50 轮降到 0.3383。有趣的是，尽管收敛速度差异很大，最终在测试集上的准确率两者都稳定在 86.67%，说明在小规模、相对平滑的任务上，优化器影响的是训练效率而非最终上限。

                                                random_state=42)

X_train_tensor=torch.tensor(X_train,dtype=torch.float32)

y_train_tensor=torch.tensor(y_train,dtype=torch.long)

X_test_tensor=torch.tensor(X_test,dtype=torch.float32)

y_test_tensor=torch.tensor(y_test,dtype=torch.long)

class SimpleModel(nn.Module):

    def __init__(self,input_dim,output_dim):

        super(SimpleModel,self).__init__()

        self.fc1=nn.Linear(input_dim,16)

        self.relu=nn.ReLU()

        self.fc2=nn.Linear(16,output_dim)

    def forward(self,x):

        x=self.fc1(x)

        x=self.relu(x)

        x=self.fc2(x)

        return x

# 初始化模型

input_dim=X.shape[1]

output_dim=len(np.unique(y))

model=SimpleModel(input_dim,output_dim)

# 定义损失函数

criterion=nn.CrossEntropyLoss()

# 定义优化器

optimizer_sgd=optim.SGD(model.parameters(),lr=0.01)

def train_model(optimizer,name):

    model.train()

    for epoch in range(50):

        optimizer.zero_grad()

        outputs=model(X_train_tensor)

        loss=criterion(outputs,y_train_tensor)

        loss.backward()

        optimizer.step()

        if (epoch+1) % 10 == 0:

model=SimpleModel(input_dim,output_dim)
