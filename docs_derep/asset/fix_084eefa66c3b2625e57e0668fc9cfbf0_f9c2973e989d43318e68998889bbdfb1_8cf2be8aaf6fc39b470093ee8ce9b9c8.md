# 第四章

**1．机器学习算法包含哪三大基本类型？**

答 机器学习算法的三大基本类型如下，具体详见 4.1.2 小节。

❶ **监督学习：** 基于已标注数据集进行训练。算法从输入特征与对应正确答案中学习，从而对新样本进行预测或决策。典型场景包括图像识别、语音识别等。

❷ **无监督学习：** 使用未标注数据。算法尝试挖掘数据内部结构与规律，例如通过聚类将样本分组。常用于市场细分、社交网络分析等。

❸ **强化学习：** 通过奖惩机制训练。智能体在与环境交互中学习最优策略以最大化累计奖励。常用于自动驾驶、机器人控制等。

**2．机器学习算法在社交媒体平台有哪些应用？**

答 主要应用如下：

❶ **情感分析：** 分析文本或用户生成内容判断情感倾向。算法可自动归类为正面、负面或中性，帮助企业了解用户反馈、跟踪舆情与制定营销策略。

❷ **用户推荐：** 基于用户历史行为预测兴趣并推送。个性化推荐可提升满意度与留存。

❸ **智能客服：** 站内客服对话常基于机器学习。系统自动解析用户输入，利用自然语言处理转化为结构化查询，并调用预训练模型给出答复或建议。
