### 2. 回归模型的显著性检验

对 $Y=\beta_0+\beta_1x$ 的显著性检验等价于检验 $H_0:\beta_1=0$ 与 $H_1:\beta_1\neq0$。若 $H_0$ 被否决，则认为回归显著，y 与 x 存在线性关系，方程具有解释力；反之回归不显著，线性模型不宜采用。本书介绍三种常用方法。

（1）F 检验法

在 $H_0$ 成立时，$F = \frac{U}{Q_e/(n-2)} \sim F(1,\,n-2)$。

其中，$U = \sum_{i=1}^{n} (\hat{y}_i - \bar{y})^2$ 即回归平方和。

若 $F > F_{1-\alpha}(1,n-2)$ 则拒绝 $H_0$，否则接受 $H_0$。

（2）$t$ 检验法

在 $H_0$ 成立时，$T = \frac{\sqrt{L_{xx}}\,\hat{\beta}_1}{\hat{\sigma}_e} \sim t(n-2)$。

当 $|T| > t_{\alpha/2}(n-2)$ 时拒绝 $H_0$，否则接受 $H_0$。

其中，$L_{xx} = \sum_{i=1}^{n} (x_i - \bar{x})^2 = \sum_{i=1}^{n} x_i^2 - n\bar{x}^2$。

（3）$r$ 检验法

设 $H_0: \rho = 0$，$H_1: \rho \neq 0$。

检验统计量 $r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \sum (y_i - \bar{y})^2}} = \frac{L_{xy}}{\sqrt{L_{xx}L_{yy}}}$。

拒绝域 $W = \{|r| > r_{1-\alpha}(n-2)\}$，其中 $r_{1-\alpha} = \sqrt{\frac{1}{1 + (n-2)/F_{1-\alpha}(1,n-2)}}$。

该法即相关系数的检验，当 $|r| > r_{1-\alpha}(n-2)$ 时，可有 $(1-\alpha)\%$ 的把握认为 x 与 y 存在线性关系。$R^2$ 常作为拟合优度的重要判别指标。

### 3. 预测和控制

预测问题是指在已知预测因子 $x=x_0$ 的条件下，求 $y_0=\beta_0+\beta_1x+\varepsilon$ 的点估计与区间估计。

（1）点预测：$\hat{y}=\hat{\beta}_0+\hat{\beta}_1x$。

（2）区间预测。当 $\varepsilon_1,\dots,\varepsilon_n$ 相互独立且服从 $N(0,\sigma^2)$ 时：

$T = \frac{y_0 - \hat{y}_0}{s\sqrt{1 + \frac{1}{n} + \frac{(x_0 - \bar{x})^2}{L_{xx}}}} \sim t(n-2)$ 其中 $s = \sqrt{\frac{S_E}{n-2}}$

由此 $y_0$ 的置信区间为：$\left[\hat{y}_0 - t_{1-\alpha/2}\,s\sqrt{1 + \frac{1}{n} + \frac{(x_0 - \bar{x})^2}{L_{xx}}},\; \hat{y}_0 + t_{1-\alpha/2}\,s\sqrt{1 + \frac{1}{n} + \frac{(x_0 - \bar{x})^2}{L_{xx}}}\right]$ （9-8）

当样本量较大且 $x_0$ 靠近 $\bar{x}$ 时，可用 $u_{1-\alpha/2}$ 代替 $t_{1-\alpha/2}$，得：

[ŷ₀−u₁₋α/₂ s, ŷ₀+u₁₋α/₂ s]

### 4. 计算推导案例

设数据为 $(x_1,y_1),\dots,(x_n,y_n)$，按以下步骤求模型。

(1) 先求：

$\bar{x}=1/n\sum x_i$    $\bar{y}=1/n\sum y_i$

$L_{xx}=\sum(x_i-\bar x)^2=\sum x_i^2-n\bar x^2$

$L_{yy}=\sum(y_i-\bar y)^2=\sum y_i^2-n\bar y^2$

(2) 再求：

$L_{xy}=\sum(x_i-\bar x)(y_i-\bar y)=\sum x_i y_i-n\bar x\bar y$

$\hat\beta_1=L_{xy}/L_{xx}$    $\hat\beta_0=\bar y-\hat\beta_1\bar x$

$S_E=L_{yy}-S_R$    $S_R=\hat\beta_1^2L_{xx}$

$F=S_R/(S_E/(n-2))$    $s=\sqrt{S_E/(n-2)}$    $r=L_{xy}/\sqrt{L_{xx}L_{yy}}$

什么是聚类算法？

聚类是指把数据集划分为若干子集，使得同一子集内对象相似度高，不同子集间差异大。相似性通常基于属性取值决定，常用距离度量来刻画。聚类分析的核心思想是类内相似最大化、类间差异最大化。
