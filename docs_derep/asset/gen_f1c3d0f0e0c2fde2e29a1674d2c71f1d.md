# 此在为何无法被自然化

第一，从本体论层面检视，自然化现象学承接的是自然主义的本体预设。自然主义坚持万物构成的一元论，认为一切要素与属性都归属于自然秩序。在这种思路下，自然化被视作弥合因果解释与现象描述、物理属性与生活属性之间鸿沟的核心诉求。要让此在在本体论上被自然化，就必须把它当作一个普通的自然人来处理，把意识还原为一种神秘的私人体验，而是大脑神经活动的自然产物，从而证明此在和其他存在者一样是可以被实存把握的。问题在于，这种处理抹去了此在与世界通过上手活动所建立的指引性关联，而上手恰恰是一种实践。海德格尔强调此在首先是实践性的存在而非认知性的存在者，其原初方式是栖居于世界中劳作，劳作蕴含着人类存在的不可化约的源始意义。

与此相反，自然化现象学试图把现象学分析的结果翻译成清晰的科学语言乃至数学语言。现象学描述只有在能够嵌入自然科学解释框架时才被视为被自然化，其前提是能够被严谨的数学形式替代。罗伊等学者把数学化看作自然化的关键操作，[^(\[31\])](#chapter005.html#m31)而数学化本身就是一种还原方式。马尔巴赫尝试用形式语言来表述第一人称的现象学报告，把个人的现象学描述符号化，使其具备主体间可共享性。从另一个角度看，这类现象学符号剥离了经验内容，只聚焦于经验的形式结构。数学作为中立且形式化的工具，具有较强的共识度，并且能够有效刻画连续与离散的动态系统，比如戈尔德对认知动力学的分析。因此，足够精密的数学被认为能把现象学材料与自然科学数据转化为一种共通的语言，[^(\[32\])](#chapter005.html#m32)自然化此在的理想图景如图 4-1 所示。

然而从此在的构成性来看，在世存在是绕不开的核心。海德格尔所说的在世存在并非指两个客体在空间中并置，也不是指物理上的连接，[^(\[33\])](#chapter005.html#m33)而是此在的基本结构。对海德格尔而言，存在于世的不是孤立的先验自我，而是多个体的生存活动。惠勒从经验角度描述此在的在世结构，认为人类主体是以具身方式嵌在科学描述的世界里。这种说法忽略了此在在世界中的存在方式即忧虑，更忽略了此在最根本的向死而在的特征。在世存在带给此在一种根本的畏惧体验，这种畏惧并非针对其他存在者，而是在被抛入世界后所感受到的不确定性，它构成了生存的结构可能性。

总的来看，站在海德格尔立场，此在的存在并非现成存在，形式化对象才是现成的存在物。把此在用数学方法形式化，就失去了进行恰当生存论分析的可能。海德格尔明确指出此在的概念不同于一切关于人的传统观念，人的认知与思维能力并非讨论重点，关键在于对存在的理解。本体论上，此在是肩负存在问题而前行的特殊存在者，需要在存在论上得到确定。海德格尔并非在做人类学研究，因此此在也不属于人类学范畴。在我们看来，自然化也是一种对象化与机制化，它把身心合一的人解释为具身嵌入的智能主体。但具象的“人”不是此在，肉体和心身统一体的自我都不是此在，[^(\[34\])](#chapter005.html#m34)自然化运作需要建立在关于人的因果和功能层面的理解之上，这与此在的本质定义相悖。由此，本体论上谈论此在的自然化是不可行的。

第二，从认识论层面看，自然主义主张知识的证成与解释与自然科学同步展开，科学方法是获取知识的唯一可靠手段，[^(\[35\])](#chapter005.html#m35)知识必须与自然事物、属性、法则相关。落在现象学上，就形成了三种自然化路径：罗伊与马尔巴赫提出的形式化现象学；瓦雷拉与汤普森提出的神经现象学；加拉格尔等提出的前置现象学。后两种在保留现象学材料、方法与洞见的前提下把现象学与认知科学结合，让现象学主动吸纳技术与实验方法，二者相互引导。它们都试图沟通现象学材料与神经生理学材料，前者依赖第一人称内省报告，后者借助功能核磁共振成像等实验，目标是通过把详细的现象学研究与神经科学实验方案结合，生成新的数据，以理解自身体验与大脑神经过程的复杂关联。

从认识论维度讨论此在的自然化，本质上是讨论我们如何认识此在。自然化现象学的常规做法是借助第一人称方法，把人当作自身体验的报告者与观察者，此在于是成为第一人称视角的体验主体。胡塞尔否认现象学语境中的意识结构或形式与神经科学语境中的自然因果结构或形式具有某种同一性，“意识的综合完全不同于自然要素的外部组合……而是关于意识生活的本质，而意识生活包含在一个意向的交织、动机，以及通过意义的相互蕴含，在其形式和原则上都与物理世界的方式毫不雷同”。[^(\[36\])](#chapter005.html#m36)他把一切事物的有效性甚至世界的存在置于先验主体之内，先验自我成为经验可能的必要条件，经过连续的现象学还原，最终走向先验唯心主义。海德格尔则认为此在不是先验主体性或意识流，也不是现成的主体或客体，不能作为已经发生的存在者被理解。他刻意回避从“我”这个主体角度切入。按照张祥龙先生的解释，海德格尔借用此在既保留了主体所指涉的人的关键存在论地位，又排除了人性观中的主体主义，此在就是诠释学化与现象学化的人本身。[^(\[37\])](#chapter005.html#m37)无论是胡塞尔的先验唯心立场还是海德格尔的存在论立场，此在都无法被自然化，因为它不是自然要素的综合。

第三，从方法论层面看，此在的自然化也是一个方法问题，即我们能否用一般的科学方法对概念本身进行分析阐明。强立场的方法论自然主义把自然主义当作元哲学，主张哲学研究应当采用或至少与自然科学方法及其证成标准如简约性、简明性、预测力、可重复性保持一致，[^(\[38\])](#chapter005.html#m38)这暗含取消哲学方法自主性的危险。更弱的立场认为，如果 X 是自然实体或属性，研究它的最恰当方法就是与自然科学方法相融贯或连续。[^(\[39\])](#chapter005.html#m39)接受弱方法论自然主义需要先拒斥本体论自然主义，只有在此前提下，前者才有意义。若接受自然主义的本体承诺，就等于取消了方法论自然主义成立的前提条件，适用范围不再是全部哲学话语，而是被视为自然实体或属性的对象。

笔者认为，海德格尔存在论语境中的此在与这种温和的方法论自然主义并不兼容。关于活生生的身体 lived body 与心智，我们同意弱方法论自然主义的介入，因为它们可以被视为具有自然属性的事物，甚至存在专门研究身心的自然科学，胡塞尔也设想了躯体学。但此在既不适合无身的描述，不能看作脱离身体的先验主体，也不是心智寓于肉身的心身统一体。与自然科学方法不同，海德格尔用现象学方法应对此在这一对象，此在并非对“人”这一名称的随意替换，而是对一种存在方式的特别限定。[^(\[40\])](#chapter005.html#m40)在他看来，身体首先必须作为人在世界中存在的根本方式被把握，它不是安置心智的容器，此在因而可被看作一种身体式存在。海德格尔反对传统方式对此在的说明，强调自己不是在做人类学研究，他认为诠释学才是研究此在的恰当方法。该方法不是为了描述历史或文化情境中的具体个人，而是“为我们摆明我们的自我解释着的存在方式之普遍的、跨文化的、超历史的结构”，[^(\[41\])](#chapter005.html#m41)对海德格尔而言，此在的自然化是对此在本身领会的误解。对此在的探究不等同于用规则与程式把诸多属性、因素与特征关联起来，通达此在涉及对存在的理解，这种理解不是纯粹的认知与心理过程，也不能通过自然科学实验还原为某一完备且被主体拥有的科学信念系统。自然化方法论的意图是把此在科学化，使其与认知科学概念体系相容，结果是使此在有名无实，此在面对的存在问题在自然科学视域中被忽略，它沦为奠基于科学认知机制的认知主体，这背离了海德格尔本意。

综上，从本体论、认识论与方法论三个维度审视，把此在自然化为适用于认知科学语境的概念面临巨大困难。不论立场强弱，借用自然科学理论研究此在甚至形成描述此在的科学机制，都会改写此在原有的生存论意义以及它作为追问存在问题的特殊存在者的存在论地位，此在的自然化可能只是水中月镜中花的幻象。

### 三 “自然化此在”只是一个“幻象”

在惠勒看来，同时持有科学实在论立场并认同海德格尔哲学并不矛盾。[^(\[42\])](#chapter005.html#m42)海德格尔并不反对科学本身，他反对的是以朴素眼光看待世界与存在者的态度，任何学科都必须在对存在有所理解的前提，即在一个“生物、社会和文化信念和实践的既定背景”[^(\[43\])](#chapter005.html#m43)下展开。惠勒的目的是建立一门新的“海德格尔式认知科学”，把海德格尔的某些哲学主张纳入自然主义解释框架，关键在于如何用认知科学概念术语描述并确定此在，如何在认知科学中为此在寻找合适位置。从某种意义上，对人类认知的考察既需要向外转向自然主义的因果解释，也需要向内转向个人经验的内省描述。丘奇兰德坚定认为我们的个体经验与认识是错误的，按其观点日常生活中应诉诸大脑与神经状态而非经验。同样，我们不能把对认知的理解束缚于某种科学或哲学解释，而应力图融合二者裂痕，寻求解释上的统一。人恰好处在交叉点，若要成功建构真正的“海德格尔式认知科学”，此在的自然化是重要一环。所谓自然化即用认知科学概念说明此在，说明他在认知科学领域的本体论地位。胡塞尔曾指出，“由于自然主义想将哲学建立在严格科学的基础上，并且想将哲学作为严格的科学构建起来，而它看起来又显得完全不可信，因此，它的方法目的本身也就显得不可信”。[^(\[44\])](#chapter005.html#m44)胡塞尔并不反对自然科学解释，他反对的是统摄一切的自然主义解释范式，有关意识、意向性本质的描述只能是现象学的任务，自然主义经验分析是现象学排除的对象。从此意义看，此在的自然化似乎违背了现象学最基本原则。

在前述中我们厘清了认知科学视域下此在的基本内涵。按海德格尔说法，此在首先不能被描述为一个意识主体，“我们应当指出，迄今为止以‘此在’为目标的提问与探索虽然在事实方面大有收效，但错失了真正的哲学问题，而只要它们坚持这样错失哲学问题，就不可要求它们竟能够去成就它们根本上为之努力的事业”。[^(\[45\])](#chapter005.html#m45)海德格尔要把关于此在的生存论分析同心理学、生物学与人类学区分开来，在他看来学科分立决定了它们只能独立研究此在的某一方面，因而未能指向“整个人的存在”。相较而言，自然主义把解释限制在物理事件与物理对象范围内，任何不能按物理过程解释的东西都是神秘的，需要被解释的一切尽在自然之中。若按自然主义信念理解，此在和其他事物一样，是服从严格自然法则的时间—空间存在者，是一个在世界中实在发生的实体。即便是心理现象也是依附于物理自然的变体，是“平行的伴随物”，任何东西都明白无误地受严格自然法则支配。[^(\[46\])](#chapter005.html#m46)

然而海德格尔会认为此在的生存论分析更为基本，在自然主义者眼中认知神经科学等研究同样基础。一些现象学家认为这两种研究不可通约与还原。海德格尔虽不赞同胡塞尔先验主体的转向，但接受了后者“悬搁一切预先设定”包括自然主义立场与态度的现象学方法。因此基于此分析，海德格尔不会赞成从自然主义视角诠释此在并将其自然化，我们认为这是现象学与认知科学对立关系的又一体现。[^(\[47\])](#chapter005.html#m47)此外，海德格尔认为实证科学与存在论现象学的研究领域存在重要差别，一个讨论事物的实存，一个关注作为奠基的存在。海德格尔给予此以特殊存在论地位，是能对主体与自我意识的存在问题进行追问的特殊存在者，存在问题只能从此在切入，它自身蕴含比主体性与意识维度更为丰富的内容。认知科学把此在定义为人间主体甚至重新解释为主体性，我们认为这在很大程度上掩盖了人的存在与一般存在的本质关系，并且《存在与时间》不是要对人类认知作出解释说明，更不是一部知识论与心智哲学著作，他要澄清的是关于人类认知与心智的传统解释没有考虑到此在基本的生存境况，即在世存在的生存结构。

在我们看来，自然化此在是以分析方法解读海德格尔哲学的产物，它有可能会贬低人类自身的经验。“分析性”不仅指分析训练的英美哲学家照搬照用海德格尔哲学，也指为推进新的认知科学范式而被利用的海德格尔哲学，因此只关注《存在与时间》第一篇中的特定部分且被选择性利用。这种接受是分析性的，构成了海德格尔哲学的一个程式化版本，而这恰恰背离了存在论语境。[^(\[48\])](#chapter005.html#m48)惠勒把海德格尔哲学的许多概念引入认知科学研究，虽然我们也认为不能依靠纯粹哲学思辨考察认知问题，真正的认知进路应为旧有模式产生的困难提供解决方案。但类似拿来式的概念引用很容易引起误解，比如他把人对用具的上手操作理解为以行动为导向的表征在亚主体层次解决在线问题求解。此在的自然化是海德格尔哲学与认知科学对话的关键，而对话本身意味着一定限度的矛盾消解或一方对另一方的退让，这里表现为存在论现象学对某种自然主义版本的妥协与屈服。

综上，此在的自然化是不可能的，至少目前仍有待商榷。我们多次强调海德格尔对以胡塞尔和笛卡尔为代表的哲学传统的批判是为了回答存在这一根本问题，他并非在主动意义上触碰人类认知、心智与智能的问题域，而是不自觉地反对以纯粹反思方式解释认知与心智现象。严肃地说，海德格尔无意使此在取代笛卡尔的“我思”成为认知活动的新的主体，而是视其为在世界中存在的日常实践能动者。相比之下，认知科学以截然不同的模式回答截然不同的问题，此在根本上表现为操劳与共在的生存现象，它适用于思辨式、现象学的先验解释与先验分析，而不适于形式化、模型化的科学解释。因此作为存在论概念的此在与事实层面的自然化描述并不相容，自然化此在没有现实层面的可能性，这对构建海德格尔式认知科学而言无疑是一个严重困难。同样，海德格尔式认知科学的另一维度，即存在论现象学与人工智能相结合的产物“海德格尔式人工智能”，面对框架问题也陷入了困境。
