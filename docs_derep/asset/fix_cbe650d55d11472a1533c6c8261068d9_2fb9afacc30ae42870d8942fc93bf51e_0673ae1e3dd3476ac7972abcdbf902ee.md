让大模型秒懂你的七套提问公式与实战心法

在日常使用里，提示往往被拆成动作、对象、附带条件三层。常见的写法是把动作放进花括号，把要产出的内容放进方括号，把额外细节放进圆括号。这样一眼就能分辨谁在做事、做成什么样、要怎样做。
比方说想让模型写一篇讲 SPIN 销售方法的文章，就能把写文章这个动作、文章对象、还需包含概念介绍并一步步演示销售人员与客户对话的补充要求分开标注。换个说法也是先给指令再说明文章要提供逐步演示的对话案例。透过这种标记，读者能清楚看清身份、任务与约束。

3. 四要素组合法：起因、意图、细则、禁区

要稳定得到想要的结果，得给提示一个结构化的骨架。好的骨架既能指引模型，也能保证出来的东西稳定相关。

基础骨架包含四块。

1. 前置背景：先交代场景与前提，说明简要。
2. 期望效果：把生成内容的具体目的与要求说清楚。
3. 操作清单：给出风格、格式、要点方面的具体指示。
4. 规避项：明确要避开的内容或特殊约束。

举例。
前置背景：在未来世界设定下。
期望效果：撰写一篇关于人工智能伦理的讨论文章。
操作清单：内容须涵盖隐私保护、自动化失业与模型管控三个子话题。
规避项：不要使用过于专业的术语。

4. 四段式拆解法：命令、环境、素材、呈现规范

1. 命令
定义：直说需要完成的具体动作。
作用：让模型聚焦核心功能，避免跑偏或产生无关内容。

2. 环境
定义：提供与任务相关的背景或额外情境。
作用：提升理解深度，使回答更贴合实际。

3. 原始素材
定义：用户明确给出的材料、范例或待处理信息。
作用：作为生成的基础依据。

4. 交付规范
定义：规定形式、格式及其他具体要求。
作用：确保结果符合预期，如长度、风格、结构等。

5. 人设驱动法：身份、工作描述、附带说明

带人设的提问能让模型从特定身份出发写作，一般由身份设定、工作说明和可选附带说明组成。

案例一
你是一位资深的 IT 售前工程师，负责 ERP 产品的售前工作，面对不熟悉 ERP 产品的客户，你能用通俗易懂的语言清楚明白地讲解 ERP 产品。现在，请你向一个新客户介绍一下 ERP 产品。

案例二
你是一位程序员，精通各种编程语言。我想要掌握一种编程语言，用它做财务数据分析。请向我推荐一种编程语言。注意，我没有计算机基础，你推荐的编程语言应当简单易学、容易上手。

标注说明如下。
{你是一位程序员，精通各种编程语言} 用花括号指定人设并强调能力。
[我想要掌握一种编程语言，用它做财务数据分析。请向我推荐一种编程语言] 用方括号描述任务及背景。
（注意，我没有计算机基础，你推荐的编程语言应当简单易学、容易上手） 用圆括号提出附带说明。

6. 背景驱动法：人设可选、现状必写、诉求必写、额外提示

这套带背景说明的通用公式在多数场景都适用。

1. 人设可选项
赋予模型特定身份，使回答更专业。
2. 现状必选项
提供尽可能详细的情境，帮助模型理解问题。
3. 诉求必选项
明确说明想要什么，需求越清晰结果越有价值。
4. 额外提示可选项
说明回答的注意事项或期望呈现形式。

使用说明：问题简单时可直接提问，复杂时按此模板拆解。下面给出五种典型用法。

案例一：人设 你是一位人力资源顾问；现状 我是一家运营五年的科技公司的人力资源经理，公司约一百人，分布在产品开发、市场营销、人力资源和行政；诉求 制订招聘计划，招募有五年以上经验的产品经理，要求技术背景强、项目管理经验丰富，能带团队推动产品开发；额外提示 计划要清晰、可执行，包含职位广告、简历筛选、面试策略及筛选标准。

案例二：人设 请你扮演产品经理的面试官；现状 我是要应聘产品经理的面试者；诉求 请对我进行模拟面试；额外提示 ①只能问岗位相关问题；②不要多余解释；③按真实面试节奏，等我回答完再提下一个问题。

案例三：人设 请你扮演营养师；现状 本人身高一百七十厘米，体重八十公斤；诉求 为我制定饮食食谱；额外提示 ①目标减脂减重；②制作简单、营养均衡；③生成一周食谱并附制作方法。

案例四：人设 假如你是一位导游；现状 我打算去北京旅游，两人，十天，预算一万五千元；诉求 制订一份详细的旅游攻略；额外提示 行程不要太紧，不去网红景点，偏爱有文化底蕴的景点，推荐时附费用预算。

案例五：人设 你是一位计算机科学与技术领域的论文写作指导专家，你将协助我撰写论文；现状 我是一名大四的学生，专业是计算机科学与技术；诉求 帮我列出十个与专业相关的选题。

7. 七件套精细法：人设、命令、背景、输入、边界、排版、范例

1. 人设
设定身份可提升个性化和专业度，提高准确性。
2. 命令
说明需要完成的任务。
3. 背景
提供背景细节，帮助模型更精确理解。
4. 输入
交代具体执行任务或待解答问题，若命令已描述则可视为输入。
5. 边界
限定输出范围，控制结果。
6. 排版
指明内容呈现形式。
7. 范例
提供参考范例，提升准确度。

案例一：生成文章。
人设：你是一名资深环境学家。
命令：我需要撰写一篇关于气候变化影响生态系统的文章，你可以作为我的咨询顾问。
背景：全球气温正在上升，极端天气事件变得更加频繁。相关组织正在采取措施应对这一问题。
输入：气候变化如何影响不同地区的生态系统？相关组织可以采取哪些措施来减轻这些影响？
边界：文章应包含引言、影响分析、建议措施三部分，总字数在五百字左右。
范例：先用引言描述气候变化现状，再分析各地生态系统的具体变化，最后提出建议措施。

案例二：撰写故事。
人设：你是一名侦探小说作家。
命令：请你创作一个紧张的情节，描述侦探发现关键线索的过程。
背景：故事发生在一个封闭的庄园内，庄园主神秘失踪，侦探正深入调查此案。
输入：侦探在调查庄园的书房时，意外发现了一个隐藏的密室，里面藏有庄园主失踪前留下的日记。
边界：情节应突出侦探的推理过程和发现密室的细节，字数控制在三百字以内。
范例：可以写侦探如何通过书架异常痕迹发现密室，并在日记中找到庄园主最后的遗言。

4.4 提问成精的五大原则

1. 先把意图说清楚
模糊的请求容易得到泛泛的答案。明确目的和背景，就像点餐时说明口味和偏好，模型才能给出精准结果。例如“用简单易懂的文字解释什么是量子物理”比“解释量子物理”更有效。
案例：含糊的“帮我计划一次旅行”改进为“帮我计划一次低预算、以放松和探索自然景观为目的的旅行”。
案例：含糊的“设计一份健身计划”改进为“设计一个适合初学者的健身计划，以提高力量和灵活性，每周训练三次”。

所谓明确，就是指向分类层级的底层。说“故事”会得到多种类型，说“爱情故事”定位更准，“北京大学学生入学报道时相识的爱情故事”则几乎无歧义。

2. 表达务必精确
用清晰简洁的语言直接表达需求，避免复杂句式和模棱两可的词。简单的表达更易被模型理解。
例如，“请告诉我今天的天气”比“你知道今天外面怎么样吗”更有效。

3. 细节需丰富
细节越丰富，输出越精确。
“给我五个适用于家庭晚餐的食谱”比“给我几个食谱”好。
“写一篇关于二零二四年人工智能技术发展的文章”比“写一篇文章”好。
避免歧义也能提升聚焦度。例如“解释一下量子计算中‘叠加态’的概念”比“解释一下这个概念”更清晰。

4. 上下文保持关联
提供与任务相关的背景和情境，帮助模型理解生成内容的语境。
完整提示：为一个非技术背景的人解释什么是区块链技术，并简要介绍它在金融行业中的应用。
普通提示：帮我写一篇关于团队合作的文章。
完整提示：帮我写一篇关于团队合作的文章，背景是一家跨国公司需要克服语言和文化障碍。

5. 复杂事情拆小块
复杂主题可拆分为若干子任务，先写背景再写观点，类似模块化开发。复杂任务的出错率通常更高，拆解为简单任务的流程会更稳。

4.5 好提示的三大价值

1. 让答案更准
明确具体的提示能帮助模型更准确理解问题，降低模糊性和不确定性。例如“热带水果有哪些？”会得到芒果、菠萝等更精准的答案，而“中国北方常见的水果有哪些？”还能加入地域限定。

2. 指引生成走向
提示就像指南针，指引模型围绕预期主题展开。如“描述一下秋天的景色”会得到树叶、金风、丰收等内容；“描述一下秋天的乡村景色”会更聚焦农舍、谷物、农人等画面。通过“用诗歌的形式描述秋天的美景”还能控制风格和语气。

3. 点燃想象空间
富有想象力的提示能催生新颖内容。例如“想象一下未来的城市会是什么样子”“如果动物会说话，它们会说些什么？”都能激发多样化创意。提示还能提供灵感，如“给出一些关于环保的创新点子”。

4.6 写好提示的十条自检清单

1. 保持表述清晰和具体
2. 提供充分的上下文
3. 使用范例
4. 使用行动导向的词语，如创建、写作、解释
5. 通俗解释，必要时加入“用通俗易懂的方式”等要求
6. 由易到难，先搭框架再完善细节
7. 明确应包含或避免的内容
8. 指定输出长度
9. 明确语气
10. 保持尊重和礼貌，避免恶意提问
