**6.3.2 字节级分词 BBPE 解析**

**1.BBPE 设计思路**

DeepSeek V3 里用的分词器是 BBPE，属于 BPE 的字节版。不同于在字符上操作，BBPE 直接把文本看成字节流来处理，从而能统一面对各种语言和任意编码。带来的好处很明显。

●**全语言覆盖：**字节是计算机最底层的存储单元，BBPE 天然可以拆解任何语言的文字。
●**规则统一：**不用为不同语种单独设计分词规则，统一在字节层工作。
●**迁移方便：**生成的词表可以在不同语言、不同任务间复用，对多语模型很友好。

整体流程和 BPE 很像，只是单位换成了字节：
●**准备阶段：**先把文本按 UTF-8 编成字节序列，每个字节单独作为一个符号进入初始表。
●**重复合并：**每轮找出出现次数最多的相邻字节对，将其合并成一个新符号，同时刷新词表和频率计数。
●**终止条件：**当词表达到设定大小或合并次数耗尽时停止。

**2.BBPE 算法的伪代码**

BBPE 算法的伪代码如下：

Python

def BBPE（text, vocab_size）:

  #将文本编码为字节序列

  text_bytes = text.encode（'utf-8'）

  #初始化词汇表

  vocab = {bytes（[b]）: freq for b, freq in count_bytes（text_bytes）}

  while len（vocab） < vocab_size:

    #统计所有相邻字节对的出现频率

    pairs = get_most_frequent_pair（vocab）

    #如果没有更多的字节对可以合并，停止迭代

    if not pairs:

      break

    #合并出现最频繁的字节对

    new_vocab = merge_pair（vocab, pairs[0]）

    #更新词汇表

    vocab = new_vocab

  return vocab

def count_bytes（text_bytes）:

  #统计每个字节的出现频率

  return Counter（[bytes（[b]） for b in text_bytes]）

def get_most_frequent_pair（vocab）:

  #统计所有相邻字节对的出现频率

  pairs = {}

  for word, freq in vocab.items（）:

    symbols = list（word）         #将字节序列拆分为单个字节

    for i in range（len（symbols） - 1）:

      pair = （symbols[i], symbols[i+1]） #获取相邻字节对

      pairs[pair] = pairs.get（pair, 0） + freq

  #返回出现频率最高的字节对

  return sorted（pairs, key=pairs.get, reverse=True）

def merge_pair（vocab, pair）:

  #合并字节对

  new_vocab = {}

  for word, freq in vocab.items（）:

    #将字节对合并为一个新字节序列

    new_word = b''.join（[word[:i], bytes（pair）, word[i+2:]]） if pair in word else word

    new_vocab[new_word] = freq

  return new_vocab

**4.BBPE 分词器的训练代码**

以下是 BBPE 分词器的训练代码（基于字节级别的操作）：

Python

from collections import defaultdict, Counter

class BBPETokenizer:

  def __init__（self, vocab_size=1000）:

    self.vocab_size = vocab_size

    self.vocab = Counter（）

    self.merges = [] #存储合并的字节对

  def train（self, text）:

    #将文本编码为字节序列，并初始化词汇表

    text_bytes = text.encode（"utf-8"）

    self.vocab = Counter（[bytes（[b]） for b in text_bytes]）

    #迭代合并字节对

    while len（self.vocab） < self.vocab_size:

      pairs = self.get_pairs（）

      if not pairs:

        break

      #合并出现最频繁的字节对

      most_frequent = max（pairs, key=pairs.get）

      self.merge_pair（most_frequent）

      self.merges.append（most_frequent）

  def get_pairs（self）:

    pairs = defaultdict（int）

    for Token, freq in self.vocab.items（）:

      for i in range（len（Token）-1）:

        pair = （Token[i], Token[i+1]）

        pairs[pair] += freq

    return pairs

  def merge_pair（self, pair）:

    new_vocab = defaultdict（int）

    forToken, freq in self.vocab.items（）:

      i = 0

      new_Token = b""

      while i < len（Token）:

        if i < len（Token）-1 and （Token[i], Token[i+1]） == pair:

          new_Token += bytes（pair）

          i += 2

        else:

          new_Token += bytes（[Token[i]]）

          i += 1

      new_vocab[new_Token] += freq

    self.vocab = new_vocab

  def Tokenize（self, text）:

    text_bytes = text.encode（"utf-8"）

    Tokens = [bytes（[b]） for b in text_bytes]

    #应用所有合并规则

    for pair in self.merges:

      Tokens = self.apply_merge（Tokens, pair）

    return Tokens

  def apply_merge（self,Tokens, pair）:

    new_Tokens = []

    i = 0

    while i < len（Tokens）:

      if i < len（Tokens）-1 and （Tokens[i][0], Tokens[i+1][0]） == pair:

         new_Tokens.append（b"".join（[Tokens[i], Tokens[i+1]]））

        i += 2

      else:

        new_Tokens.append（Tokens[i]）

        i += 1

    return new_Tokens

**6.3.3 分词器对模型性能的影响**

分词器是 NLP 模型里非常关键的一环，直接决定输入表示、训练效率和最终效果。

**1.词汇表大小**

●词表越大，嵌入参数越多，显存和计算开销随之上升。
●词表过小容易出现未登录词，低频或新词难以被模型理解。

**2.输入序列长度**

●粒度越细如字符或字节，序列越长，推理成本越高。
●粒度越粗如词级，序列变短，但可能损失对复杂形态的表达。

**3.泛化能力**

●字符或字节级分词靠子单元共享，能更好地处理 OOV 和形态变化，例如 running→run+ning。
●词级分词对稀有词的泛化明显更弱。

**4.多语言支持**

字节级分词器如 BBPE 天然适配多语言，而字符级方案往往需要为每种语言定制规则。

**6.4.1 什么是跨模态对齐**

跨模态对齐是指把不同模态的数据在语义或特征空间中对齐，让信息可以互相关联，是多模态 AI 的核心。前沿模型采用的对齐方式各不相同，主要取决于跨模态适配层。常见做法有：

1）MLP 投影层，一个或多个线性层做映射，比如 Qwen VL2。
2）注意力结构，比如 MiniCPM-V。

**6.4.2 DeepSeek VL2 模型对高清图像的处理**

多模态模型常面临高清输入难题。预训练视觉模型如 ViT、SigLIP 通常在 224×224 等低分辨率上训练，直接把 1024×1024 的高清图压缩会丢失细节，导致 OCR 等任务失效。

DeepSeek VL2 采用自适应切图方案，流程如下。

**1.输入高分辨率图像**

图像尺寸为（*H*,*W*），*H* 为高，*W* 为宽。

**2.定义候选分辨率集合 CR**

CR={（*m*·384,*n*·384）*m*∈*N*,*n*∈*N*,1≤*m*,1≤*n*,*m*·*n*≤9}

其中，*m*∶*n* 表示宽高比，*m* 和 *n* 为正整数。

**3.计算填充区域**

对输入分辨率（*H*,*W*），计算调整到每个候选分辨率（*m*·384,*n*·384）所需的填充。

填充区域=（*m*·384-*H*）×（*n*·384-*W*）

**4.选择填充最小分辨率**

挑选填充量最小的候选分辨率（*m**[i]*×384,*n**[i]*×384），*m**[i]*、*n**[i]* 为最优参数。

**5.调整图像大小**

把输入图 resize 到选定分辨率并补足必要区域。

**6.划分图像为图块**

将调整后的图切成 *m**[i]*×*n**[i]* 个 384×384 的局部图块，外加 1 个全局缩略图块补充整体信息。

**7.使用 SigLIP-SO400M-384 处理图块**

把 1+*m**[i]*×*n**[i]* 个图块送入 SigLIP-SO400M-384 编码器。

**8.生成视觉嵌入向量**

每个 384×384 图块输出 1152 维嵌入，最终得到 1+*m**[i]*×*n**[i]* 个向量。

**9.将视觉嵌入向量进行平铺**

对上述向量做 Flatten，其中缩略图向量置于最前，其余按图像二维顺序行拼接。

**10.汇总嵌入向量并输入跨模态适配层**

按顺序汇总所有图块嵌入形成视觉表示，再送入跨模态适配层。
