以 Gemini 3 Pro 為底層的 Nano Banana Pro，單次可同時參考十張圖片，讓創作者把人物造型和素材風格釘住，從而對畫面做細緻操控。

傳統生成工具在單張美圖上表現尚可，一旦拉進漫劇或短片的連續製作流程，就容易出現問題：不同鏡頭裡人物面目不一，道具細節走樣，文字與 UI 渲染常糊掉，多圖合併顯得生硬，對鏡頭語言的理解也有限。Nano Banana Pro 的更新恰好回應這些痛點，指令解析更到位，故事把握更準，畫面連貫度明顯提升，多圖融合更自然，文字和介面元素的可讀性也更佳。

下面用幾個實操案例說明具體用法。

### 5.5.1　三视图生成

Nano Banana Pro 在語義解讀、邏輯推演與視覺統一度上表現突出，做標準化的角色三視圖很在行。它能讀懂繁複的服飾描述與風格要求，一次出圖就能得到可直接落地的數位資產。

使用的提示词如下。

一张详细的角色设计图，角色三视图（包含正面、侧面、背面），纯白色背景，无阴影。

主体：一名 16 岁的滑板少年，戴着橙色的针织冷帽，黑色卷发。身穿宽松的国潮印花卫衣（印有醒目的醒狮图案），下身是多口袋工装束脚裤，脚踩高帮运动鞋，手里抱着一块涂鸦滑板，脖子上挂着头戴式耳机。

面部：圆脸，有些许雀斑，大大的眼睛，表情调皮自信，张嘴大笑。

风格：2.5D 波普插画风格，色彩饱和度高，线条清晰明快，不仅限于写实，带有一点 Q 版盲盒的质感，适合手办设计或 3D 卡通渲染。

尺寸比例 16 : 9。

### 5.5.2　多图融合

Nano Banana Pro 合併多張素材的能力很強，能把預先準備好的元素拼合得相當自然。雖然生成帶有隨機性，整體一致性仍能維持在較高水平。做漫劇時通常會先備好角色、武器、場景等素材，遇到特定分鏡可以直接組合生成。

假設有三張素材：一張角色圖、一張武器圖、一張背景圖。目標是合成「女武士在賽博巷弄中拔劍」的分鏡。上传这三张素材（见图 5-29～图 5-31）后，输入具体的提示词即可完成“组装”。
