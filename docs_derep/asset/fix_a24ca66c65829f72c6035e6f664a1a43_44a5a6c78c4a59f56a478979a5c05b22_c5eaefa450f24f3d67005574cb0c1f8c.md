#### 一、平台推流逻辑全拆解

##### （一）抖音推流三要素详解

抖音的推荐像个智能大脑。刚刷完美食，马上推同类，这背后是公式：Y=F（Xi，Xu，Xc）。

拆开说就是：

- Xi 内容：作品质量、文案、配乐是否达标
- Xu 用户：观众历史偏好建模
- Xc 环境：观看时间、地点等时空特征

总结：内容质量 + 用户兴趣 + 环境因素 = 播放频次

- 先小范围测试：系统先推给几百人，数据好就上热推
- 标签匹配：内容标签准，曝光翻倍
- 热度加权：点赞评论转发是硬指标，完看率决定飞多高

举例：发一条宠物视频，会先进初始池测试100~500次观看，再按宠物用户画像分发，若80%看完并互动，就会进入下一级曝光池。

**【操作清单】**

- 标题带爆款词，系统优先抓取
- 快速蹭当日热搜标签
- 冷启动期主攻互动，评论区引导回复
- 高峰时段：7~9点、18~22点
- 技巧：用抖音相机原生拍摄，获得原创加成

**【进阶技巧】**

八级曝光池：200 → 500 → 1000 → 5000 → 1万 → 10万 → 50万→100万以上
冷启动关键：前3秒完看率>30%才有二次推荐
账号权重 = 近期均播量 × 互动占比 × 垂直度

##### （二）快手“老铁”经济：关系链决定曝光

快手的核心口诀：先交朋友再变现。视频优先推给：

- 你的粉丝，哪怕只有100人，触达率30%~40%
- 共同好友圈的三度人脉
- 同城同兴趣的老铁

头部主播复购率高达67%。发布时加同城标签+地域关键词，播放可翻倍。快手变现精髓就是人情。

- 去中心化：关注页曝光占30%，粉丝粘性>播放频次
- 社交加权：评论区活跃=强推，标题带家乡名涨粉快
- 双列瀑布流：真实人设是王道
- 变现组合：直播打赏/小黄车/广告提成，平台抽取最低5%

**【快手致富三板斧】**

每发3条视频至少1条@老铁互动，粉丝到达率可达40%
标题公式：月入X万的窍门 + 感叹号 = 自然流量提升200%
凌晨发三轮车维修，抢早起汽修师傅流量
