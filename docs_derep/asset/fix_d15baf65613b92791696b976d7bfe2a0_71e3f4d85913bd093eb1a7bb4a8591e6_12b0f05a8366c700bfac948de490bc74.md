图、视频、语音三模态接入：大模型脚本速成

整理了一组把主流生成模型接入本地脚本的最小可用模板，分别覆盖文生图、图文生视频、文本转语音三个链路。片段可直接复用，只需在 .env 中配置对应服务的密钥，稍作参数调整即可适配不同场景。

一、文字驱动图像生成
思路是把 API 调用封装成一个函数，接收提示词、模型名与分辨率，返回首张图像的网络地址。外面套一个交互循环，读取用户输入的提示词，空值直接忽略，收到结束指令就终止。其余情况调用封装函数并把拿到地址打印出来。

二、图文条件视频合成与状态轮询
先通过 dotenv 加载密钥，初始化 ZhipuAI 客户端并指定 cogvideox。再次封装一个生成入口，支持纯文本提示或配合底图 URL。交互先收集文字提示再收集底图链接，二者皆可为空但至少其一要有值，校验通过后发起请求。

def get_completion(model="cogvideox",

                   prompt=None,

                   image_url=None):

    response = client.videos.generations(

        model=model,

        prompt=prompt,

        image_url=image_url

    )

    return response

收到请求后需要轮询检查进度，间隔约 30 秒查询一次，直到进入完成或失败分支。成功时可以提取视频地址与封面链接。

print("===查询任务状态===")

while True:

    response = client.videos.retrieve_videos_result(

    )

    if response.task_status == "PROCESSING":

        print("PROCESSING...")

        print("===任务失败===")

        break

    else:

        print("===任务完成===")

        print(f"视频URL:{response.video_result[0].url}")

        print(f"视频封面:{response.video_result[0].cover_image_url}\n")

        break

三、语音合成并落盘
同样先加载环境变量，创建 OpenAI 客户端，模型选 tts-1。循环读取待转文字，空值跳过，结束指令退出，其余情况调用 audio.speech.create，使用 alloy 语音风格，按当前时间戳命名 mp3 并写入本地目录。

[PRE7]python

from dotenv import load_dotenv, find_dotenv

_ = load_dotenv(find_dotenv())

from openai import OpenAI

client = OpenAI()

model = "tts-1"
