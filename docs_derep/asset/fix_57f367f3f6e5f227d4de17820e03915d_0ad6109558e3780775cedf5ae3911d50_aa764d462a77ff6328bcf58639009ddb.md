# 文案打磨与职业进阶 Prompt 合集

### 文字精修导航

打磨方向

1. 框架雕琢
   - 重排段落与句式，提升思路清晰度
   - 强化论证递进与衔接
   - 首尾更有张力，补齐整体架构

2. 表达升级
   - 用更精准生动的词替换笼统平淡的表述
   - 调动节奏与语气，增强力度与可读性
   - 保持语调统一，贴合读者与使用场景

3. 内容加固
   - 在不偏离原意前提下补入细节或例证
   - 把核心论点与关键信息凸显出来
   - 去芜存精，提升信息浓度

4. 专业提升
   - 适度引入行业术语与表达
   - 确保表述严谨可信
   - 增强说服力与权威感

交付形态
1. 精修后的完整稿
2. 修改要点说明，归纳主要调整与缘由
3. 3~5 条后续完善建议
4. 重点段落的替代表达

使用要点
- 保留原文立场与核心信息
- 在维持原风格基础上做增益，而非推翻
- 成稿需自然流畅，避免生硬堆砌

使用方式：粘贴待处理文本并说明文体与侧重，模型将从框架、表达、内容与专业度多维度提升质量，同时守住原意与风格特质。

灵活用法
- 精准受众：补充“受众考量：[如高管/技术人员/跨文化]”，获得更有针对性的语言调整
- 演讲适配：文体选“演讲稿”，侧重选“表现力”，获取更利于口述的版本
- 简化复杂文本：增加“复杂度调整：简化”，获得通俗但不失要义的解读

#### 长文浓缩
提示词：战略性长文精简专家

> 角色定位：擅长在保留价值与关键信息前提下压缩篇幅、提升清晰度和冲击力的内容浓缩专家。

任务：把以下长文压缩为简洁有力、易懂的版本，完整保留关键信息与核心论点。

基础设定
- 文本类型：[报告/演讲稿/论文/提案/文章/会议记录等]
- 目标读者：[填写]
- 压缩幅度：[轻度约减30%/中度约减50%/高度约减70%]
- 最终用途：[演讲/阅读/分享/参考等]
- 保留要点：[必须保留的核心内容或段落]

待处理原文：[粘贴长文]

浓缩策略
1. 优先级判定
   - 锁定核心观点与关键信息
   -甄别可压缩或删除的次要内容
   - 维持论证完整与力度
2. 表达压缩技巧
   - 去除冗赘与重复
   - 用简练有力的句子替代拖沓描述
   - 合并相关内容
   - 选择更精准用词，减少修饰
3. 结构重塑
   - 重组以提升逻辑
   - 每段有明确中心
   - 强化转折点的显眼度
4. 呈现建议
   - 适时用要点替代长段
   - 用小标题提升可读性
   - 视需求给出视觉组织建议

输出要求
1. 浓缩后的完整版
2. 浓缩策略说明，阐明做法与理由
3. 关键保留清单，确认重要信息未遗漏
4. 可选超精简版，适配快速浏览或口头概括

注意事项
- 防止过度压缩导致失真或逻辑断裂
- 保持原语气与风格基调
- 成稿需连贯完整且具说服力

使用指引：粘贴长文并明确压缩程度与保留重点，模型将采用内容优先级方法把冗长文本转化为简洁有力版本，确保核心信息完整，同时提升清晰度与影响力。

变体建议
- 演讲版浓缩：添加“用途：演讲展示”，获取更贴合口述的精简稿
- 多层次输出：添加“多层次输出：是”，同时获得完整版、中等版与摘要版
- 术语保留：添加“专业术语处理：保留关键术语”，在压缩中维持专业性

### 商业营销与传播
场景说明
在竞争激烈的市场中，营销与传播是企业成败关键。模型可助力营销人、内容创作者与决策者提升内容质感、优化传播效果、精准触达目标人群。无论产品介绍、广告文案还是营销策略，以下模板可快速产出高质量、具针对性的商业内容，提升转化并塑造品牌影响。

变体建议：可追加“对比竞品优势”或“增加场景化描写”等需求，亦可指定文案结构如“AIDA模式”。
