# 实战指南：特征工程核心技法与重要性评估全解析

在推荐系统与CTR预估的工程实践中，原始特征很难直接入模。我们需要对比率类指标做置信度修正，对数值类指标做尺度统一，还要通过交叉挖掘非线性关系，最后通过重要性分析精简特征集。本文系统梳理这套“组合拳”打法。

---

## 一、 比率类特征的置信度修正：让小样本“老实交代”

点击率（CTR）、转化率（CVR）等比率指标，最怕分母（曝光/点击）太小。新物品曝光仅几十次就点了一下，CTR=1%，这靠谱吗？显然不靠谱。我们需要数学手段，给小样本“降权”，给大样本“背书”。

### 1. 威尔逊区间法：取下界保平安

威尔逊区间给出了一个置信区间，**工程上直接取区间下界作为修正后的CTR**，相当于对不可靠的高估值打折。

**实战案例**：
| 物品 | 曝光数 | 原始CTR | 95%置信区间 | **修正后CTR(下界)** |
| :--- | :--- | :--- | :--- | :--- |
| A | 1000 | 3% | (0.021, 0.042) | **2.1%** |
| B | 300 | 3% | (0.016, 0.056) | **1.6%** |
| C | 100 | 3% | (0.010, 0.085) | **1.0%** |

**结论**：原始CTR皆为3%，但经修正后，曝光越少，衰减越狠。**任何概率/比值型指标均适用此法。**

### 2. 贝叶斯平滑：引入先验，公式更轻量

贝叶斯平滑思路直观：把当前物品的表现，与“全局平均水平”（先验）加权融合。

**公式定义**：
$$ \text{Smoothed\_CTR} = \frac{m + a}{n + a + b} $$
*   $m, n$：当前物品点击数、曝光数。
*   $a, b$：先验超参，通常取**全品类总点击数、总曝光数**。

**PK 威尔逊区间**：
*   **优点**：公式极简，计算极快，易于工程化落地。
*   **缺点**：需人工调节超参 $a, b$，不同业务场景敏感度不同，需反复实验调优。

## 二、 数值类特征的尺度统一：归一化 vs 标准化

为什么要处理？两大核心痛点：
1.  **量纲冲突**：如“用户年龄(0-100)”与“商品价格(0-10000)”直接加权，价格会彻底压制年龄。
2.  **梯度发散**：模型训练时，大尺度特征主导梯度方向，导致震荡、收敛慢。

### 1. 归一化 —— 压缩到 [0, 1] 区间

$$ x_{new} = \frac{x - \min(x)}{\max(x) - \min(x)} $$

*   **优点**：边界固定，便于后续处理（如作为权重输入）。
*   **致命伤**：**极不鲁棒**。一个极端脏数据（Max/Min）会挤压绝大多数正常样本到极窄区间。
*   **工程对策**：根据分布做分位数截断（如 1%-99%），或对结果做平滑。

[PRE1]

### 2. 标准化 —— 映射为标准正态分布 (均值0，方差1)

$$ x_{new} = \frac{x - \mu}{\sigma} $$
即经典的 **Z-Score**。

*   **优点**：受异常值影响相对较小；无上下界，适合假设数据服从正态分布的模型（如LR、NN）。
*   **本质**：两者都是**线性变换（压缩+平移）**，核心目的一致——**消除量纲与尺度差异，加速收敛**。
*   **选型建议**：没银弹，**跑离线实验看AUC** 决定用哪个。

## 三、 特征交叉：显式构建非线性记忆

单一特征是“点”，交叉特征是“面”甚至“体”。核心作用：**将原始空间映射到高维，实现非线性划分**，类似核函数思想。

### 业务价值：粒度细化，捕获复杂关系
*   `性别 x 城市 x 职业` → 精准画像“北上广女性程序员”。
*   `UserID x ItemCategory` → 直接建模用户对特定品类的偏好（协同过滤味儿）。

### 三大主流交叉算子（假设向量 $X=[x_1, x_2], Y=[y_1, y_2]$）

| 算子 | 操作 | 输出示例 | 特征数变化 | 别名/含义 |
| :--- | :--- | :--- | :--- | :--- |
| **内积** | 对应位相乘求和 | $Z_1 = [x_1y_1 + x_2y_2]$ | **1个标量** | 压缩信息，建模“整体匹配度” |
| **阿达马积** | 对应位相乘 | $Z_2 = [x_1y_1, x_2y_2]$ | **等于向量维度** | **Match特征**，保留各维度独立匹配信息 |
| **笛卡尔积** | 两两穷举组合 | $Z_3 = [x_1y_1, x_1y_2, x_2y_1, x_2y_2]$ | **维度相乘** | 表达力最强，挖掘所有共现模式 |

> **连续值特征**需先**离散化（One-Hot/Embedding）**，再做交叉。

### 实战对比：以 `User_Gender x Item_Gender` 为例

| 交叉方式 | 样本1 (男推男) | 样本2 (男推女) | 业务含义解读 |
| :--- | :--- | :--- | :--- |
| **内积** | `[1]` | `[0]` | 只有“是否匹配”一个信号，无法区分男/女差异。 |
| **阿达马积** | `[1, 0]` | `[0, 1]` | 拆解为“男匹配”、“女匹配”，模型能学到性别差异。 |
| **笛卡尔积** | `[1,0,0,0]` | `[0,1,0,0]` | 细分为“男男”、“男女”、“女男”、“女女”，**非线性表达最强**。 |

### 避坑指南：维度爆炸 & 过拟合
*   **笛卡尔积最猛，也最危险**：特征规模指数级增长，极易过拟合，工程存储/计算压力大。
*   **工程妥协**：高基数特征（如ID）做Embedding后内积；低基数类别特征做笛卡尔积。

### 显式交叉 vs 隐式交叉（模型自动学习）
*   **FM/DNN 确实能自动交叉**：FM显式建模二阶，DNN靠多层非线性隐式拟合。
*   **为何还要人工交叉？**
    1.  **突破阶数限制**：FM通常只做二阶，高阶靠人工预组合再喂给FM。
    2.  **可解释性与泛化**：DNN交叉是黑盒，可能学到虚假相关；人工交叉带业务先验，**显式先验 + 隐式学习 = 最强组合**。

## 四、 特征重要性分析：精简特征库，指导迭代方向

特征越多越好？错。**噪声特征拖累训练、推理延迟高、过拟合风险大**。重要性分析两大流派：

1.  **Leave-One-Out (LOO) 留一法**：看“少了你模型掉多少分”。
2.  **内在预测力法**：看“你自己能不能分清正负样本”（如 IV、信息增益）。

### 1. Shapley Value：博弈论视角的“公平分账” —— LOO流派巅峰

简单 LOO（全集减一）有盲区：若特征A是“全能选手”，去掉它模型跌得惨；但若特征B是“关键辅助”，只有配合C才有用，单独去掉B看不出贡献。

**Shapley 核心思想**：遍历**所有特征排列组合**，计算特征 $i$ 加入任意子集 $S$ 带来的边际贡献期望。

$$ \varphi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!(n-|S|-1)!}{n!} [v(S \cup \{i\}) - v(S)] $$

*   $v(\cdot)$：特征集对应的模型指标（AUC/Logloss）。
*   权重系数：保证每种子集规模被公平采样。

**经典比喻**：
4种食物，3种各补1种维生素，第4种**全补**。简单LOO：去掉任意一种，剩下3种都能活 → 重要性全一样（不公平！）。Shapley：第4种食物在所有子集中边际贡献最大 → 重要性最高。**完美识别“全能型”与“辅助型”特征。**

**计算瓶颈**：指数级复杂度 $O(2^n)$，跑不动。

**工程解法：蒙特卡洛采样近似** —— 随机打乱特征顺序，构造“有/无该特征”样本对，估算边际贡献均值。几千次采样即可收敛，已广泛落地。

### 2. Information Value (IV) & WoE：风控界的“黄金标准” → 推荐系统

**前置条件**：特征已离散化、填补缺失、任务为**二分类**。

#### Step 1：算 WoE (Weight of Evidence) —— 单分桶区分度
$$ \text{WoE}_i = \ln \left( \frac{N_i / N_{total}}{P_i / P_{total}} \right) = \ln \left( \frac{\text{该桶坏样本占比}}{\text{该桶好样本占比}} \right) $$
*   **物理意义**：后验概率对先验概率的**对数修正幅度**。
*   $|\text{WoE}|$ 越大 → 该分桶区分正负样本能力越强。
*   WoE 可正可负，表示正向/负向相关。

#### Step 2：算 IV (Information Value) —— 特征整体预测力
$$ \text{IV} = \sum_{i} \left( \frac{N_i}{N_{total}} - \frac{P_i}{P_{total}} \right) \times \text{WoE}_i $$
*   本质：各分桶 WoE 的**加权和**，权重是该桶正负样本分布偏离全局的程度。
*   **IV 恒 $\ge 0$**。

#### 经验判读阈值（业界通用）：
| IV 区间 | 解释 |
| :--- | :--- |
| $< 0.02$ | 无用特征，直接丢 |
| $0.02 \sim 0.1$ | 弱预测力 |
| $0.1 \sim 0.3$ | 中等预测力，**主力特征多在此** |
| $0.3 \sim 0.5$ | 强预测力 |
| $> 0.5$ | **疑似泄露标签/过拟合**，需排查 |

**优势**：可解释性极强（能看到每个分桶贡献）、计算极快、天然处理非线性（分箱后单调/非单调均可）。

### 3. SENet-block：深度学习里的“特征注意力”

在 Embedding 层之后、全连接层之前，插入 **Squeeze-and-Excitation (SE) 结构**：

1.  **Squeeze**：Global Average Pooling 压缩空间维度，得特征级描述符。
2.  **Excitation**：两层 FC + ReLU + Sigmoid，学习每个特征的**重要性权重 $w \in (0,1)$**。
3.  **Re-scale**：原始 Embedding 向量逐通道乘以 $w$。

**效果**：模型**显式、动态**地学习“当前样本下哪个特征重要”，并加权参与后续交互。比静态的 IV/Shapley 更灵活，是深度模型内部的“特征选择器”。

## 总结：特征工程“组合拳”打法建议

| 阶段 | 核心动作 | 推荐工具 |
| :--- | :--- | :--- |
| **清洗/修正** | 比率指标小样本降权 | **威尔逊区间(稳健)** / **贝叶斯平滑(高效)** |
| **尺度统一** | 消除量纲/加速收敛 | **标准化(首选)** / **归一化(需截断)** |
| **关系挖掘** | 显式建模非线性交叉 | **低基数笛卡尔积** + **高基数Embedding内积** |
| **精简筛选** | 离线评估特征价值 | **IV(极速筛选)** + **Shapley采样(核心特征精排)** |
| **动态加权** | 模型内部自动学习权重 | **SENet / FiNet / Attention机制** |

特征工程没有标准答案，只有**“业务先验指导显式构造 + 模型能力补全隐式交互 + 重要性分析驱动迭代闭环”**这一套经过验证的工程方法论。
