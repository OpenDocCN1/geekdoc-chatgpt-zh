# 推荐序 筑基图智 共享未来

智能化正重塑世界运行方式。从量子计算、基因编辑到智慧城市、数字外交，人工智能不仅在改写产业形态，也在更新人类的认知范式。迎接这场智能变革，既要有仰望星空的战略眼光，也要埋头夯实理论地基。北京大学出版社策划的“人工智能与人类未来丛书”应运而生，在理念层面与实践层面都对当下社会转型具有参考价值。

该套书最突出的特质是溯源求本。业界多聚焦于参数微调带来的即时收益时，《人工智能大模型数学基础》等奠基性著作梳理了支撑人工智能的计算脉络，涵盖线性代数、概率统计、微积分等核心分支。书中把卷积核解读为张量空间的变换，把损失函数牵引到变分法的最优控制视角。用这种把技术表象还原为数学本质的写法，帮助读者完善认知框架，也为后续创新开辟空间。全书采用的“数学考古”视角，带领读者追随高斯、牛顿等先驱的思路，在微分流形里理解Transformer，在泛函空间里体认大模型的涌现规律。

在工程维度，丛书提出“代码即理论”的写作主张。《人工智能大模型：动手训练大模型基础》等实战读物摒弃概念堆砌，以PyTorch为平台提供上百个可运行示例，将反向传播具象化为矩阵求导运算，把注意力机制呈现为概率图模型。《DeepSeek源码深度解析》由作者团队对国产大模型的核心设计进行逐层拆解，从分布式训练的参数同步策略到混合专家系统的动态路由，每个关键点都配有工业级实现。这种庖丁解牛式的解析，既呈现整体架构，也吃透模块精髓。

丛书着眼于中国与世界的长远图景。算力竞争白热化之际，《Python大模型优化策略：理论与实践》系统归纳模型压缩、量化训练、稀疏计算等核心方法，为突破算力壁垒提供方法论。《DeepSeek图解：大模型是怎样构建的》大量采用可视化图表，把万亿参数的训练过程转译为可理解的动力学系统，显著降低理解门槛。这些尝试既呼应“十四五”规划对底层技术突破的部署，也为构建自主可控生态储备人才。

作为行业见证者与参与者，我看到丛书实现了三重突破：学理上搭建起数学基础到技术前沿的知识通道；产业上铺设起理论创新到工程落地的转化路径；战略上回应新时代科技自立自强的国家诉求。它既可作为高校培养复合型人工智能人才的立体化教材，也可成为产业界攻坚技术瓶颈的参考宝典，还可作为公众认识智能的入门书目。

站在智能时代的关键路口，我们比任何时候都更需要兼具理论深度与实践智慧的启蒙之作。愿此丛书点燃更多探索者的思想火花，共同描绘人工智能赋能文明的美好图景。

## 1.2 核心产品与应用方向

DeepSeek的核心产品包括大语言模型DeepSeekChat与高效推理模型DeepSeekReasoning。产品已广泛应用于教育、医疗健康、金融等多领域，可为教育提供虚拟实验室与智能辅导，为医疗提供初步诊断与健康管理支持，为金融提供市场分析与风险评估等，助力行业智能化升级。

### 1.2.1 主要产品线

主要为大语言模型，核心产品如下。

1. DeepSeek对话模型系列
◎ DeepSeekLLM：2023年11月发布，参数规模67B，具备推理、编程、数学、中文等通用能力。
◎ DeepSeek-V2：2024年5月发布，第二代开源MoE架构，参数规模236B，推理成本低，性能强劲。
◎ DeepSeek-V3：2024年12月发布，采用MoE架构，共671B参数，每次推理仅激活37B，计算与训练成本较低，多项基准测试表现接近或超越国际顶尖模型，推理能力突出。

2. DeepSeek编程模型系列
2023年11月发布，是领先的开源代码大模型之一，由多个代码专用模型组成，支持多语言生成、调试、数据分析，采用MIT许可证开源。

注意：DeepSeek数学系列于2024年2月发布，基于DeepSeek-Coder-v1.5 7B初始化，以数学相关Token与自然语言及编程数据预训练，在MATH基准测试中表现优异，接近GeminiUltra与GPT-4水平。

3. DeepSeek视觉语言系列
2024年3月发布的多模态大模型，融合视觉与语言处理，能处理图像输入，支持视觉问答、图像描述生成、视觉推理等任务，开启多模态探索。

4. DeepSeek证明系列
专注数学推理的超大规模语言模型，已推出DeepSeek-Prover-V1、V1.5、V2等版本。

5. DeepSeek推理系列
◎ DeepSeek-R1：2025年1月发布，基于DeepSeek-V3-Base架构，采用MoE设计，总参数671B，每次激活37B，通过强化学习显著提升推理能力，具备自我校验、反思与生成长思维链能力。数学、代码任务表现优异，部分基准超越OpenAI-o1-1217，支持蒸馏至小模型。完全开源遵循MIT协议，支持免费商用与定制，API兼容OpenAI格式，长上下文达128KToken。
◎ DeepSeek-R1-Zero：完全通过强化学习训练，无监督微调，采用群体相对策略优化GRPO算法。训练使用基于规则的奖励，包括准确性与格式奖励，输出存在中英文混杂等可读性问题。该实验性成果为后续DeepSeek-R1优化提供重要参考。
