# 分诊分级速查

- 一级 濒危：心跳骤停、意识丧失、休克表现、血氧饱和度小于85%、活动性大出血
- 二级 危重：急性胸痛、急性脑卒中体征、高热伴抽搐、血氧饱和度85%至90%
- 三级 急症：中度疼痛 NRS≥7、高热≥39℃、需要缝合的外伤
- 四级 亚急：轻度急性不适、低热、轻微外伤
- 五级 非急：慢性病常规随访、健康咨询、轻微不适

# 联动启动机制

- 一级患者：自动激活抢救室 Agent、总值班主任 Agent、药房应急 Agent
- 二级患者：启动对应专科 Agent、检验 Agent、监护 Agent
