210. Dawes 与 Corrigan 合写《决策中的线性模型》。Wainer 在《线性模型中系数的估计》里深入讨论了等权问题，并指出“当关注点是预测时，回归系数不相等的情况极少出现”。Dana 与 Dawes 的《回归在社会科学预测中的简单替代方法的优越性》也在社科与当代语境下印证了该论点。↩

213. Paul Meehl 曾概括：在众多实践案例中，平均来看，少数关键变量的等权重往往胜过回归公式。相关展开与引文见 Dawes 与 Corrigan 的《决策中的线性模型》。↩

214. Dawes 的《决策中不当线性模型的稳健之美》之外，Wainer 在《线性模型中系数的估计》中补充：“即便缺乏操作标准，等权重线性模型仍能表现良好”。↩
