ChatGLM-6B 量化微调与推理实战拆解

这篇笔记把一套基于 ChatGLM-6B 的指令微调流程拆开讲清楚，从模型加载、量化改造、训练配置到推理采样，每一步都配上可直接复用的代码片段。整体思路是先用轻量封装快速把权重跑到显存，再通过量化降低显存占用，随后在 SPO 抽取任务上做前缀微调，最后用 Top-p 采样做离线评测。

量化改造的关键点

量化入口提供 bits 参数控制精度，bits 为 0 时直接跳过。第一次调用时标记 quantized，避免重复处理，同时把量化位数写回配置。实际转换由内部的 quantize 工具完成，针对 transformer 主体进行重参数化。

在模型层面，对每一层的注意力与 MLP 线性层进行逐层替换，用 QuantizedLinear 取代原始 Linear，权重张量先搬到当前设备，保留 bias、维度信息以及 half dtype，empty_init 控制是否延迟初始化。

def quantize(self, bits: int, empty_init=False, **kwargs):

    if bits == 0:

        return

    from .quantization import quantize

    if self.quantized:

        return self

    self.quantized = True

    self.config.quantization_bit = bits

    self.transformer = quantize(self.transformer, bits,

                                empty_init=empty_init,

                                **kwargs)

    return self

训练环境与微调配置

训练脚本先固定可见 GPU，随后导入数据、模型、加速库。配置里只动两个关键项：pre_seq_len 设为 16，prefix_projection 设为 False，其余保持默认。模型同样走 xiaohua 包装，半精度上显存并打印可训练参数量。

提示词固定为抽取格式的指令，数据准备阶段调用 get_train_data 统一做分词与截断，最大长度 288，源长度 256。DataLoader 采用 batch_size 2、drop_last、自定义 collate。加速器负责混合精度与设备调度，优化器选用 AdamW 学习率 2e-5，CosineAnnealing 衰减到 2e-6，T_max 2400。

训练循环跑 20 个 epoch，每步取 input_ids 与 labels 前进，返回的 loss 做反向传播，步进学习率并清零梯度，进度条实时展示 loss 与学习率，每三轮保存一次权重到 glm6b_pt.pth。

推理与采样细节

评估阶段实现 nucleus 采样 sample_top_p，对概率排序后累计求和，屏蔽超过 p 的尾部再归一化，最后用 multinomial 抽样并通过索引映射回原始 token。

配置与训练保持一致，pre_seq_len 与 prefix_projection 不变。最大总长 288，源长 256，目标最大长度据此推导。模型切到 eval，遍历 json 行逐条分词，提示词与文本拼接后做长度裁剪，保证在限制内进入生成流程。

def sample_top_p(probs, p):

    probs_sort, probs_idx = torch.sort(probs, dim=-1, descending=True)

    probs_sum = torch.cumsum(probs_sort, dim=-1)

    mask = probs_sum - probs_sort > p

    probs_sort[mask] = 0.0

    probs_sort.div_(probs_sort.sum(dim=-1, keepdim=True))

    next_token = torch.multinomial(probs_sort, num_samples=1)

    next_token = torch.gather(probs_idx, -1, next_token)

    return next_token
