**定理证明**  
已知 $F(x, h_1, k_1)=x^{n_1 m_1}$ 与 $G(x, h_2, k_2)=1-(1-x^{n_2})^{m_2}$，依据零级对偶的通用准则 $g(x)=1-f(1-x)$，可推导出：  
$G(x, h_2, k_2)=1-(1-x^{n_2})^{m_2}=1-(1-x)^{n_1 m_1}$，即 $(1-x^{n_2})^{m_2}=(1-x)^{n_1 m_1}$。  
若令 $h_1=h_2$，则有 $1-x^{n_2}=(1-x)^{n_1}$。该方程仅存在三组解：

1.  $n_1=n_2=1$，对应 $k_1=k_2=0.5$；
2.  当 $x \in (0, 1)$ 时，若 $n_2 \to \infty$，则 $1-x^{n_2} \to 1$；令 $n_1=0$，则 $(1-x)^{n_1} \to 1$。故 $n_2 \to \infty, n_1=0$ 为解，即 $k_2=1, k_1=0$；
3.  同理，若 $n_2=0$，则 $1-x^{n_2} \to 0$；令 $n_1 \to \infty$，则 $(1-x)^{n_1} \to 0$。故 $n_1 \to \infty, n_2=0$ 为解，即 $k_1=1, k_2=0$。

定理得证。

接下来，我们探讨纯指数型一级 T 范数/S 范数完整超簇在 $k$ 极限条件下的行为特征。

###### 定理 8.5.4  
在纯指数型一级 T 范数簇 $T(x, y, h, 1)$ 中，$T(x, y, 0.75, 1)$ 无唯一确定值，可在 $\mathbf{T_0}$ 与 $\mathbf{T_3}$ 之间任意取值；当 $h>0.75$ 时，簇内算子全数退化为 $\mathbf{T_3}$；当 $h<0.75$ 时，全数退化为 $\mathbf{T_0}$。

**证明**  
$k=1$ 意味着 $n \to \infty$：
- $h>0.75$ 时 $m<0$，$F(x, h, 1) = x^{-\infty} = \mathbf{F_3}$，进而 $T(x, y, h, 1) = \mathbf{T_3}$；
- $h=0.75$ 时 $m=0$，$F(x, 0.75, 1) = x^{mm}$（$mm \in (-\infty, \infty)$ 为不定式），故 $T(x, y, 0.75, 1)$ 介于 $\mathbf{T_0}$ 与 $\mathbf{T_3}$ 之间（工程应用中常设定为 $T(x, y, 0.75, 1) = \mathbf{T_2}$）；
- $h<0.75$ 时 $m>0$，$F(x, h, 1) = x^{\infty} = \mathbf{F_0}$，进而 $T(x, y, h, 1) = \mathbf{T_0}$。

定理成立。

###### 定理 8.5.5  
在纯指数型一级 T 范数簇 $T(x, y, h, 0)$ 中，除 $T(x, y, 1, 0)$ 可在 $\mathbf{T_2}$ 与 $\mathbf{T_3}$ 间任意取值、$T(x, y, 0, 0)$ 可在 $\mathbf{T_0}$ 与 $\mathbf{T_2}$ 间任意取值外，其余情况均退化为 $\mathbf{T_2}$。

**证明**  
$k=0$ 意味着 $n=0$：
- $h=1$ 时 $m \to -\infty$，$F(x, 1, 0) = x^{mm}$（$mm \ll 0$ 不定），$T(x, y, 1, 0)$ 介于 $\mathbf{T_2}$ 与 $\mathbf{T_3}$ 间（应用中可设为 $\mathbf{T_3}$）；
- $h \in (0, 1)$ 时 $m$ 有限，退化为 $F(x, h, 0) = \mathbf{F_2}$，即 $T(x, y, h, 0) = \mathbf{T_2}$；
- $h=0$ 时 $m \to \infty$，$F(x, 0, 0) = x^{mm}$（$mm \gg 0$ 不定），$T(x, y, 0, 0)$ 介于 $\mathbf{T_2}$ 与 $\mathbf{T_0}$ 间（应用中可设为 $\mathbf{T_0}$）。

定理成立。

**推论 8.5.2** 经约定可视纯指数型一级 T 范数簇 $T(x, y, 0, k)$ 全部退化为 $\mathbf{T_0}$。

###### 2. 混合模型的核心性质

非极限状态下，混合型超簇的演变规律与纯指数型大体一致，仅变化速率有别。主要差异集中在极限情况：

###### 定理 8.5.6  
混合型一级 T 范数超簇 $T(x, y, h_1, k_1)$ 与 S 范数超簇 $S(x, y, h_2, k_2)$ 存在零级对偶的充要条件为 $(1-\Phi(x, k_2))^{m_2}=(\Phi(1-x, k_1))^{m_1}$；若 $h_1=h_2$，则 $k_2=1-k_1$。

**证明**  
$F(x, h_1, k_1)=(\Phi(x, k_1))^{m_1},\ G(x, h_2, k_2)=1-(1-\Phi(x, k_2))^{m_2}$。依零级对偶条件 $g(x)=1-f(1-x)$，得 $G(x, h_2, k_2)=1-(1-\Phi(x, k_2))^{m_2}=1-(\Phi(1-x, k_1))^{m_1}$，即 $(1-\Phi(x, k_2))^{m_2}=(\Phi(1-x, k_1))^{m_1}$。若 $h_1=h_2$，则 $1-\Phi(x, k_2)=\Phi(1-x, k_1)$，解得 $\Phi(x, k_2)=1-\Phi(1-x, k_1)$，进而 $k_2=1-k_1$。证毕。

###### 定理 8.5.7  
混合型一级 T 范数超簇出现 $T_1$ 的条件为 $(\Phi(x, k))^m=x$；混合型一级 S 范数超簇出现 $S_1$ 的条件为 $1-(1-\Phi(x, k))^m=x$。

**证明**  
$F(x, h, k)=(\Phi(x, k))^m=x$ 时 $T=T_1$；$G(x, h, k)=1-(1-\Phi(x, k))^m=x$ 时 $S=S_1$。即得证。

##### 8.5.3 一级 T/S 完整超簇内范数分布的单调性

鉴于 $\Phi(x, k)$ 完整簇内算子随 $k$ 连续严格单调递减；$T(x, y, h)$ 完整簇内算子随 $h$ 连续严格单调递增；$S(x, y, h)$ 完整簇内算子随 $h$ 连续严格单调递减。故在 $T(x, y, h, k)$ 与 $S(x, y, h, k)$ 完整超簇内，算子均随 $h, k$ 连续严格单调变化。

- **T 范数超簇**：算子随 $h$ 严格单调增；$h<0.75$ 时随 $k$ 严格单调减，$h>0.75$ 时随 $k$ 严格单调增。
- **S 范数超簇**：算子随 $h$ 严格单调减；$h<0.75$ 时随 $k$ 严格单调减，$h>0.75$ 时随 $k$ 严格单调增。
