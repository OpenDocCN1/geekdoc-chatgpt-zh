**智能化知识传播的人设底层与运作方式**

**导师型角色**
智能体以学习陪伴者的身份出现，会结合个体现状给出针对性的学习建议，伴随受众逐步消化知识点，突破学习卡点。

**专家型角色**
智能体以行业专家或顾问的姿态提供高专业度的信息，帮助受众在决策或复杂难题上减少试错成本。

**陪伴型角色**
智能体通过模拟人类情感表达与行为模式，为用户提供情绪支持与精神鼓励，让知识传递更具温度。

三类角色的共同逻辑，都是依据目标用户与具体传播目的来校准智能体的性格与语气，从而强化共鸣感。

**场景感知：先读懂情境再回应**
传播效果很大程度上取决于智能体能否精准捕捉并适配不同情境。业务、学习、文化语境差异明显，内容呈现方式必须灵活切换。系统能够实时感知用户背景与需求，自动调整传播策略。

业务情境：在客服场景中，智能体需依据客户情绪与问题类型调节语气与建议；在销售场景中则更强调说服力与感染力。
学习情境：课堂教学侧重体系化讲解；自主学习时则按学习节奏与疑问提供个性化辅导。
文化情境：不同文化背景的受众对内容与表达有不同偏好，智能体会据此调整策略，提升理解度与接受度。

强场景感知让知识传递从单向输出变为动态适配。

**语言风格调校：用合适的语气说合适的话**
人格化传播的另一关键在于语言风格。智能体会分析受众的学习偏好、任务属性与情绪状态，定制表达方式。

正式风格：用于严谨规范的场合，如学术课程、法律文件解读。
亲和风格：用于需要推动行动的场合，如企业文化宣导、团队建设。
简洁风格：用于信息密集需快速消化的场合，如日报、简报、客户沟通。
情感化风格：用于情绪波动或需要激励的场合，如员工关怀、压力疏导。

通过对需求紧迫度、任务类型与情绪状态的动态判断，智能体实时切换语气，使信息传递既高效又有温度。

**构建智能传播人设模型的路径**
核心在于将受众需求、传播内容与智能体个性化特征结合。

**大模型加提示词设计话术**
个性化与精准传播的第一步是设计系统化的话术框架，通过提示词实现。
例如：
角色设定：将智能体设为企业培训师，输出更体系化、专业化。
场景设定：在客户服务场景下沟通，语言要简洁、有温度、富同理心。
风格设定：在销售推广场景下，语言需更具说服力与驱动力。
合适的提示词配合场景适配，能让智能体在传播中呈现理想人格，提升效果。

**建立动态学习知识库，持续优化**
保持长期有效必须构建可更新的知识库。智能体会依据学习进展、用户反馈与外部变化持续刷新内容与策略。
例如：
学习进度：依学员进度推荐合适模块，并自动调节难度与深度。
用户反馈：实时收集反馈评估效果，据此优化内容与策略。
外部环境：随市场与行业动向自动更新知识，保证内容与时俱进。
这种迭代机制让智能传播不是一次性交付，而是长期优化的过程。

**智能化知识传播的落地场景**
在内部学习、业务支持、客户沟通与组织文化建设中，人格化传播都能显著提升效率。

场景：个性化学习路径与知识定制
背景：传统培训多为统一大纲，全员同质化难以满足个体差异。
案例：某跨国公司为全球员工提供持续职业发展支持。引入人格化传播后，平台为每人配备专属学习教练，教练会结合岗位职责、学习进度与技能缺口，推送适配内容并实时给予反馈。
价值：
学习路径个性化：按角色与需求动态推荐，避免泛化培训浪费时间。
即时反馈与优化：学习过程中即时纠偏，提升学习成效。

### **第一节** **Day1** **智能体定位|找到知识 IP 的独特价值**

**今日目标**
厘清个人独特经验与价值坐标，搭建 IP 标签与赛道；学会借助智能体完成价值梳理与标签设计。

**一、清晨一学**
“思考 IP 方向时不妨记住两点：第一，精通一件事，成为该领域的专家。领域不重要，重要的是掌握成为专家的方法，这是起点而非终点。第二，尽量选择空白领域。未知领域意味着更大机会，没有既定规则也没有激烈竞争，你可以成为开创者。”——凯文·凯利

**一、经验盘点三环节：找到“我是谁”**

**1.经验盘点是什么**
经验盘点是打造 IP 的第一步。通过系统回顾工作、生活、学习经历，提炼出热爱、擅长、价值三大关键词，为后续产品设计、标签定位和智能体模型训练奠基。
从高光时刻切入，先发散再收敛：先展开成功事件的细节，挖掘喜欢与擅长的部分，再聚焦最具市场价值的经验。
可自问：
这件事为何重要？
当时克服了哪些困难？
如何操作，最终结果怎样？
最享受的是哪部分？
我的做法与他人有何不同？

**2.三环节解析：热爱点×擅长点×价值点**

**第一环节：从重复行为找热爱点**
关键词：愿意反复做、不觉累、充满热情的事。
看行为而非感受，看时间投入。
自问：
周末、深夜、假期会自发做的事有哪些？
不为钱也会投入时间的行为是什么？
做完后是否有强烈满足感？
是否期待并乐于钻研？
是否热衷分享相关经验？
是否为之投入金钱？

提示语示例：请列出我近三个月重复出现最多的行为关键词。可上传周报、工作记录或朋友圈内容。

**第二环节：从成就事件找擅长点**
关键词：做得好、受认可、成效显著的行为模式。
找到带来成就感的事件，提炼共性。
自问：
哪些事曾获老板、客户、同事高度评价？
是否有多个相似成功案例？
该领域是否有 5 年以上持续积累与刻意练习？
是否读过 20 本以上相关书籍并了解顶尖专家？
能否脱稿讲 30 分钟？

提示语示例：请基于以下项目经历，识别亮点能力与优势策略。写明项目名称、角色与成果。

**第三环节：从价值判断找价值点**
关键词：解决真实问题，为谁带来实际帮助。
IP 的商业价值取决于解决问题的能力。
自问：
何时感到自己真正帮助了他人/团队/组织？
哪些内容被反复请教？
目标人群基数是否足够大？
痛点是否强烈且难以自解，愿付费？
竞争对手是否不多？
身边是否有信任的受众？
市场是否具备长期可持续性？

提示语示例：请基于对话、邮件或培训反馈，提炼我提供过的价值类型。可粘贴文字。

**3.三点交汇：知识 IP 黄金三角**
热爱、擅长、价值的交集即 IP 原矿。
一句定位：
“我喜欢做 ____，我擅长做 ____，这正好能帮助 ____ 解决 ____ 问题。”

**4.案例：银行客户经理经验盘点**
身份：国有银行对公客户经理，10 年经验，业绩排前 10%。
热爱点：喜欢深度交流企业模式，研究成长逻辑；参加行业论坛会主动记录与分析趋势。
擅长点：能用简单图表讲清复杂融资方案；曾担任团队客户需求梳理内训讲师。
价值点：帮助数十家中小企业重构财务模型获融资；公众号《融资避坑指南》阅读超 2 万，咨询请求不断。
定位雏形：热爱金融行业，擅长用图解思维帮助企业理解融资逻辑，专注中小企业融资教育与策略优化。

**二、定位选择四维框架：打造 IP 坐标**

**1.为什么定位重要**
定位是战略起点，帮助回答：为谁服务？解决什么问题？凭什么是我？
定位清晰，用户 5 秒内就能记住、理解、找到你。

**2.四维框架结构（见表 9-1）：Inside×Outside×Client×Tag**
[PRE0]
四个维度构成坐标系，从想做什么到什么有价值，再到用户如何理解。

**3.四维定位实操**

**Inside——内在驱动挖掘**
思考：
哪些话题讲 3 小时不累？
哪些书/视频/课程反复学仍兴奋？
愿为哪个话题无偿输出？
提示语：请基于我的行为记录、笔记与兴趣清单，归纳我最有持续投入动力的方向。

**Outside——市场趋势雷达**
选择赛道时自问：想帮助哪类人群？若不计收入也能赢得人心吗？
不做大而全的原因：认知成本高、竞争成本高、交付成本高。
要找利基市场。
判断要素：
是否属于增长型行业如智能体、职业转型、健康管理？
需求是否显性、用户主动搜索？
是否蓝海、供给不足？
提示语：请分析某领域中增长最快、变现潜力大的 3 个赛道并说明原因。

**Client——客户画像定位**
基于上升赛道，精准划分客户，错位给价值。
维度：角色、场景、痛点、决策路径。
提示语：为我的知识服务领域如智能体办公生成 3 个典型用户画像，含性别、年龄、职业、痛点、内容偏好。

**Tag——标签锚定**
标签是 IP 名片。让人一眼看懂你在做什么。
设定方式：
关键词式：我是+行业+特色能力
场景式：我帮助+某类人+解决某问题
价值式：通过××方法，创造××结果
提示语：基于我的经验/专长/客户群，设计 3 种易记有传播性的 IP 标签，一句话即可。

**基于标签构建三大体系**
知识体系：围绕标签能解决哪些问题？
产品体系：咨询、课程、训练营等变现形态。
营销体系：海报、直播、短视频、文章等围绕标签展开。

背景：35 岁女性，从传统教育转行，10 年经验，擅长教案设计与公众演讲。
Inside：对表达训练和智能体辅助教学设计充满兴趣。
Outside：智能体时代转型培训需求大，表达力+智能体赛道相对空白。
Client：30-45 岁求职或转型的中年职场人，惧怕公开表达却想提升影响力。
Tag：专注智能体表达力训练的职场陪跑者，帮助转型者打造影响力表达系统。
