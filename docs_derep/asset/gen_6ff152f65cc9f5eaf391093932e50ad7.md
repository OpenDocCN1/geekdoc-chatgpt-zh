## 10.5 常见问题与解决思路
在初学阶段开发网站时常会遇到各类问题，下面汇总本项目的典型问题与应对思路。

### 1. 页面布局问题
向DeepSeek提问：元素无法按预期位置排列，特别是在响应式布局中。
解决思路：
1）理解 CSS 盒模型，掌握 margin、padding、border 的影响。
2）学习 Flexbox 与 Grid 布局，它们提供强大的对齐与分布控制。
3）借助开发者工具检查元素实际尺寸与位置。
4）采用移动优先思路，先适配小屏再扩展到大屏。
解决方案实例：
本项目团队成员展示区使用 Grid 布局，可在不同屏幕下自动调整列数。

[PRE10]

### 2. 图片显示与优化问题
向DeepSeek提问：图片尺寸不合适，加载速度慢，或在不同设备上显示效果不佳。
解决思路：
1）选用合适格式，照片用 jpeg，需要透明用 png，现代浏览器优先 webp。
2）实现响应式图片，为不同屏幕提供不同分辨率资源。
3）压缩图片以减小文件体积。
4）使用懒加载技术延迟加载视口外的图片。
解决方案实例：
本项目使用 picture 元素与 srcset 属性为不同设备提供适配图片。

### 3. 导航菜单适配问题
向DeepSeek提问：导航菜单在桌面端显示正常，但在移动设备上不易使用。
解决思路：
1）小屏下把水平菜单转为汉堡菜单。
2）保证触控目标足够大，便于手指点击。
3）加入适当动画，提供视觉反馈。
4）在多种设备上测试交互体验。

本项目通过媒体查询与 JavaScript 实现了响应式导航菜单。
