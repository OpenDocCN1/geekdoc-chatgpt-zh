模型瘦身后是否真的更快，硬件适配度说了算。同一套压缩思路搬到不同计算平台，效果会完全不一样。

GPU 天生为稠密矩阵运算而生，偏好规则、可并行的计算模式，所以结构化的裁剪方式更容易发挥出来。以 NVIDIA 安培架构为例，RTX 3090 等显卡原生支持 N:M 半结构化稀疏[128]，在算力基本不掉的前提下压缩比就能超过 50%。

CPU 的指令更细，基本到乘加操作层面，对裁剪是否规整不敏感，更关心模型最终能精简到什么程度。像 Deep Compression[67] 这类非结构化方案，以及为 CPU 定制的半结构化方案[129]，在 CPU 上都能高效运行。

专用芯片则会从调度与数据格式入手消化裁剪后的结构。比如 ESE[90] 通过计算负载均衡平滑非结构化裁剪带来的单元负载不均，明显提升处理速度。需要留意的是，这类硬件一般同时兼容结构化裁剪，具体选哪种要结合模型实际表现来判断。

### 4.8.3 压缩边界受哪些因素影响
要摸清在精度不掉的前提下能压到哪里，通常从任务类别、数据规模、主干网络三个维度拆开看，用控制变量法逐项分析。

（1）任务类型：同一模型在不同任务上的可压缩空间不一样。用同一裁剪方法处理 ResNet-50，分类任务的压缩率往往远高于目标检测。分类场景下 ResNet-50 可达 90% 以上[130]，检测场景下通常只能到约 70%[131]。

（2）数据集规模：训练数据越多，模型参数被有效利用的程度越高，可剪余量越小。同样网络在 ImageNet 上训练的压缩率，一般会比在 CIFAR 上训练时更低。

（3）主干模型：不同 backbone 的冗余度差异明显。以 VOC 数据集上 SSD 的通道裁剪为例，主干为 MobileNet 时压缩率可能仅约 30%[132]，换成 ResNet-50 则能超过 75%[133]。总体规律是冗余越多越好裁，VGG 比 ResNet 更易裁，ResNet 又比 MobileNet 更易裁[77, 133]。

def prune_conv_bn_relu(old_conv2d, old_batchnorm2d, threshold, in_channels=3, in_idx=None):

    # 计算当前层每个滤波器的2-范数权重

    w_l2_norm = torch.sqrt((old_conv2d.weight ** 2).sum(dim=1))

    # 创建掩码，2-范数大于阈值的滤波器保留

    mask = w_l2_norm.gt(threshold).float()

    out_idx = np.squeeze(np.argwhere(np.asarray(mask.cpu().numpy())))

    # 计算保留的滤波器数量

    out_filters = len(out_idx)

    # 根据保留的滤波器索引创建新的卷积层和批标准化层

    new_batchnorm2d = create_batchnorm2d(old_batchnorm2d, out_filters)

    new_conv2d.weight.data = old_conv2d.weight.data[out_idx.tolist(), :, :, :].clone()

    new_conv2d.bias.data = old_conv2d.bias.data[out_idx.tolist()].clone()

    if in_idx is not None:

def _fix_mask_for_one_depen(masks, dset):

    channel_remain = set()

    out_channels = None

    # 定义一个标志来表示依赖集合中的所有层是否全部被剪枝

    all_pruned = True

    # 遍历依赖集合中的卷积层

    for name in dset:

        if name not in masks:

            # 若当前层无对应掩码，则不被剪枝

            all_pruned = False

            continue

        # 提取当前层掩码

        w_mask = masks[name]['weight']

        if out_channels is None:

            out_channels = w_mask.size(0)

        shape = w_mask.size()

        count = np.prod(shape[1:])

        # 计算当前层的保留及被剪枝的滤波器索引

        all_ones = (w_mask.flatten(1).sum(-1) == count).nonzero().squeeze(1).tolist()

        all_zeros = (w_mask.flatten(1).sum(-1) == 0).nonzero().squeeze(1).tolist()

        # 将当前层保留的滤波器索引加入channel_remain集合中

        channel_remain.update(all_ones)

        # 若依赖集合中存在未被剪枝的卷积层，则集合中所有卷积层均不被剪枝

        if not all_pruned:

            channel_remain.update(range(out_channels))

    # 遍历结束后，更新依赖集合中所有卷积层的权重掩码

    self.set_mask_for_dset(dset, channel_remain)
