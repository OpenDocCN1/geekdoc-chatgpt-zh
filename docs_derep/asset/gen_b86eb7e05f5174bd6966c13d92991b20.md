## OpenClaw CLI 快速查用手册

这份清单把 OpenClaw 常用命令行操作按使用场景做了归类，macOS、Linux 以及 Windows 下的 WSL 2 都能直接用。遇到陌生的指令，直接对照这里就能快速定位。

需要最新用法时，执行 `openclaw --help` 查看全部顶级指令；想了解某个子命令的参数细节，用 `openclaw <命令> --help` 即可。

### C.1 基础操作与诊断

| 命令 | 作用 | 使用提示 |
| :--- | :--- | :--- |
| openclaw --version | 查询当前安装的版本号 | 安装完成后用来确认版本 |
| openclaw --help | 展示所有顶级指令的帮助信息 | 入门阶段的高频命令 |
| openclaw status | 汇总查看网关、渠道、会话的整体情况 | 日常排查的首选 |
| openclaw doctor | 自动检测问题并尝试修复常见故障 | 异常时先跑这一条 |
| openclaw health | 执行更细致的健康检查，信息量大于 status |  |
| openclaw onboard | 启动交互式首次配置向导 | 可加 --install-daemon 参数 |
| openclaw setup | 以非向导方式完成初始化与工作目录准备 | --wizard 参数的效果等同于 onboard |
| openclaw dashboard | 打开 Web 控制台 | 会自动复制链接并尝试唤起浏览器 |
| openclaw reset | 清除部分或全部配置与数据 | --scope full 为完全重置，使用需谨慎 |
| openclaw completion | 输出 Shell 自动补全脚本 | 例如追加到 ~/.bashrc |

### C.2 网关运维

| 命令 | 作用 | 使用提示 |
| :--- | :--- | :--- |
| openclaw gateway start | 启动核心后台网关服务 |  |
| openclaw gateway stop | 停止网关服务 |  |
| openclaw gateway restart | 重启网关，改动配置后必须执行 | 运维高频操作 |
| openclaw gateway status | 查看网关运行状态、监听端口与 RPC 健康度 | 可加 --probe 增强探测 |
| openclaw gateway enable | 注册为系统服务并设置开机自启 | Linux、macOS、Windows 均可 |
| openclaw gateway disable | 关闭开机自启 |  |
| openclaw logs | 查看运行日志 | 支持 -f / --follow / --tail 100 |
| openclaw logs --follow | 实时跟踪日志输出 | 排错时最常用 |

### C.3 模型管理

| 命令 | 作用 | 使用提示 |
| :--- | :--- | :--- |
| openclaw models list | 列出已配置及可用的模型 |  |
| openclaw models status | 查看当前默认模型、降级模型与认证状态 |  |
| openclaw models set < 模型名 > | 切换默认模型 | 例如 models set claude-sonnet-4-5 |
| openclaw models scan | 重新扫描并发现本地模型，如 Ollama |  |
| openclaw models aliases list | 查看已定义的模型别名 |  |

### C.4 渠道与配对

| 命令 | 作用 | 使用提示 |
| :--- | :--- | :--- |
| openclaw channels status | 查看飞书、Telegram、WhatsApp 等渠道状态 | 可加 --probe |
| openclaw channels login < 平台 > | 登录或配对新的通信渠道 | 例如 channels login telegram |
| openclaw pairing list | 列出等待审批的配对请求 |  |
| openclaw pairing approve | 批准配对请求 | 支持指定 ID 或 --all |

### C.5 技能与 ClawHub

| 命令 | 作用 | 使用提示 |
| :--- | :--- | :--- |
| openclaw skills list | 列出已安装的技能 |  |
| openclaw skills status | 查看技能加载情况与健康状态 |  |
| clawhub search < 关键词 > | 在 ClawHub 中搜索技能 | 例如 clawhub search github |
| clawhub install < 技能名 > | 从 ClawHub 安装技能到本地 | 例如 clawhub install github |
| clawhub list | 查看本地已安装的技能清单 |  |
| clawhub update --all | 批量更新所有已安装技能 |  |

### C.6 配置管理

| 命令 | 作用 | 使用提示 |
| :--- | :--- | :--- |
| openclaw config get < 路径 > | 读取配置项，支持点路径语法 | 例如 config get agents.defaults.model.primary |
| openclaw config set < 路径 >< 值 > | 修改配置项 | 例如 config set gateway.port 18790 |
| openclaw config unset < 路径 > | 删除配置项，恢复默认值 |  |

### C.8 高级测试

| 命令 | 作用 | 使用提示 |
| :--- | :--- | :--- |
| openclaw agent | 直接启动一个 Agent 实例用于测试 | 例如 agent --model deepseek/deepseek-chat |
| openclaw message send --to <目标> --message <内容> | 通过命令行向目标发送消息 | 适合脚本与自动化测试 |
| openclaw test api | 检测当前模型 API 的连通性与余额 | 消息无响应时先执行此项 |
