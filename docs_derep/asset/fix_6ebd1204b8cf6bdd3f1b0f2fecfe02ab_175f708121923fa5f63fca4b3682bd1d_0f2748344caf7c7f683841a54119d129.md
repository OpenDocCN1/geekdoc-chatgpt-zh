DeepSeek-R1 蒸馏版本地部署实战

想在本地复现 DeepSeek-R1 的蒸馏效果，我选用 Unsloth 来提速模型加载，用 ModelScope 完成权重获取，整体步骤很直接。以下记录从安装环境到第一次推理的完整流程。

pip install unsloth

pip install --force-reinstall --no-cache-dir --no-deps git+https://github.com/unslothai/unsloth.git

[PRE0]
随后安装实验追踪和模型下载依赖。

pip install wandb

[PRE1]

pip install modelscope

[PRE2]
先为 Qwen 7B 蒸馏版准备存放目录。

mkdir ./DeepSeek-R1-Distill-Qwen-7B

[PRE3]

modelscope download --model deepseek-ai/DeepSeek-R1-Distill-Qwen-7B --local_dir ./DeepSeek-R1-Distill-Qwen-7B

[PRE4]
再为 Llama 8B 蒸馏版创建目录。

mkdir ./DeepSeek-R1-Distill-Llama-8B

[PRE5]

modelscope download --model deepseek-ai/DeepSeek-R1-Distill-Llama-8B --local_dir ./DeepSeek-R1-Distill-Llama-8B

[PRE6]
权重准备完毕后，使用 FastLanguageModel 进行载入，max_seq_length 设为 2048，dtype 由框架自行判断，显存不足时可把 load_in_4bit 打开。

from unsloth import FastLanguageModel

max_seq_length = 2048

dtype = None

load_in_4bit = False  # 若显存不足，可以将此设置为 True，运行 4bit 量化版

model, tokenizer = FastLanguageModel.from_pretrained(

    model_name = "./DeepSeek-R1-Distill-Llama-8B",

    max_seq_length = max_seq_length,

    dtype = dtype,

    load_in_4bit = load_in_4bit,

)
