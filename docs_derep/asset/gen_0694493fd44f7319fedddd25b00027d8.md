### 6.1 大模型微调基础
本节介绍微调核心概念、常见方法，以及合理的软硬件环境如何支撑高效微调，并讨论不同规模模型所需的资源与操作系统选择，帮助在实际开发中搭建合适的环境。

#### 6.1.1 大模型为什么需要微调
在大规模预训练模型涌现的背景下，这些模型在海量数据上学习了通用语言规律与知识，具备较强的理解与生成能力，但仍属通用型，尚未针对特定任务优化。

微调是指在预训练大语言模型基础上，利用少量标注数据与有限算力，使模型向特定任务优化。那么为什么要微调呢？

##### 1. 提升模型在特定任务上的表现
通用预训练模型在文本生成上表现尚可，但在情感分析、医学问答等具体任务上可能不够准确。微调借助针对性数据，让模型学习任务所需的知识与模式，显著提升效果。

##### 2. 适应领域知识
不同领域的文本结构与背景差异大，通用模型难以覆盖。法律文本严谨且案例化，金融文本含复杂公式，医学文本含化学表达。微调可注入领域数据，帮助模型理解专业任务。

##### 3. 提高计算效率和节约资源
全量训练大模型成本极高，例如 GPT-3 含 1750 亿参数，需数千张 A100 分布式训练。微调仅在预训练基础上做少量调整，大幅减少算力与时间开销。

#### 6.1.2 微调基础概念介绍
##### 1. 微调
大模型微调是在已有预训练模型基础上，利用标注数据训练，进一步优化表现以适配特定任务或场景。与 RAG 或 Agent 通过工作流优化不同，微调是通过修改模型参数实现能力“固化”。

##### 2. 全量微调与高效微调
从方法划分，微调分为全量微调与高效微调。全量微调使用全部数据更新参数，改造彻底但算力消耗大；高效微调只更新部分参数，是一种“四两拨千斤”的策略。

##### 3. 全量指令微调
全量微调的核心应用是全量指令微调。预训练阶段输入大量无标签文本，模型学习语言结构、语法与上下文，具备“续写”能力，如图6.1所示。

##### 4. 高效微调：LoRA与QLoRA
全量微调可深度改造能力，但需训练全部参数，算力与门槛高。多数场景只需提升特定领域能力，高效微调更合适。

1) LoRA
LoRA 是一种高效参数微调方法，通过引入低秩矩阵减少需调整的参数量，降低显存与计算消耗。仅训练插入的适配器层，保留原始参数不变，适合显存受限设备。

2) QLoRA
QLoRA 在 LoRA 基础上引入量化，将权重量化为 INT4 或 INT8 等低精度，进一步降低存储与计算需求。在显存极度受限或需快速推理的场景下优势明显，适合边缘设备与低延迟需求。

LoRA 与 QLoRA 特性对照见表6.1。

表6.1 LoRA与QLoRA特性对照表

| 特性 | LoRA | QLoRA |
| :--- | :--- | :--- |
| 核心技术 | 低秩适配器 | 低秩适配器加量化技术 |
| 适用场景 | 显存受限但性能尚可的设备 | 极限显存受限或追求快速推理的设备 |
| 计算效率 | 提升效率，减少可调参数 | 进一步提升效率，减少内存并加快推理 |
| 量化技术 | 不使用量化 | 将权重量化为低精度如 INT4 或 INT8 |
| 内存消耗 | 较低，但高于 QLoRA | 显著降低，适配更小设备 |
| 训练复杂度 | 相对简单，通用微调适用 | 需额外量化和适配，适合超大模型与受限设备 |

#### 6.1.3 高效微调的应用场景
实际应用中，高效微调主要用在以下四个方面。

##### 1. 对话风格微调
可按需求调整对话风格，如客服系统、虚拟助理等场景，通过微调使模型适配不同语气、礼貌度或回答方式，提供更符合预期的交互体验。

##### 2. 知识灌注
将外部或领域特定信息快速注入预训练模型，无需从头训练。例如法律、医疗等专业领域，用少量标注数据微调，使模型掌握行业术语、规则与知识，提升专业问答能力。

##### 3. 推理能力提升
可用于增强复杂推理能力，帮助模型更好地理解长文本、挖掘隐含信息或提取逻辑关系，在多轮推理任务中提高准确度并减少错误。

##### 4. Agent能力提升
在多任务协作或功能调用场景中，微调能显著提升 Agent 能力，使模型更精准调用外部 API、解析参数与执行指令，在自动化服务、智能助手或机器人控制中表现更智能。

#### 6.1.4 主流微调工具介绍
学习微调会接触两类工具：一类是高层封装的微调三剑客 Unsloth、LLama-Factory、ms-SWIFT；另一类是底层库如 PEFT、LoRA、transformers。初学者建议优先尝试前三种。
