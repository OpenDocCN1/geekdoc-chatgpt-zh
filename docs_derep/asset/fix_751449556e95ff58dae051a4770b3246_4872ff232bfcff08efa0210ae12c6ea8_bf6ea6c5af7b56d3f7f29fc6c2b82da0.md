# RL 负载均衡环境 5分钟上手

想验证强化学习在调度上的效果，先从一个可复现的仿真开始即可。思路是模拟一批计算实例，每台实例都有处理上限并按 FIFO 排队，外部请求持续到来，Agent 每次为当前请求指定承接实例。环境以平均等待时长的负值作为反馈，排队越短反馈越积极。
