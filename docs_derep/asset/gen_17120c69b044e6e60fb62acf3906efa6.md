UniAD 系统的多任务模块体现了人类先验知识在导航规划中的关键作用。传统分层规划往往用多个独立网络分别处理不同任务，虽然可以单独优化各模块，却因模块间信息交互不足容易造成信息丢失和误差累积。为此 UniAD 采用端到端思路，把所有任务的优化目标与运动规划直接挂钩，并引入两阶段训练策略来提升训练效率与系统表现。

起步时系统加载预训练的 BEVFormer 权重，并在整个训练中保持冻结。第一阶段聚焦感知训练，确保感知模块 TrackFormer 与 MapFormer 稳定。这一阶段要求系统能准确检测并跟踪动态、静态目标如车辆、行人，同时对车道、交通标志等道路要素进行精细语义映射。感知效果高度依赖图像与 BEV 特征的准确性。此阶段 MotionFormer、OccFormer 与 Planner 等模块参数不参与更新，保持固定。完成感知训练后，第二阶段将感知、运动预测、占用预测和规划全部纳入联合优化，前期稳固的感知能为后续任务提供更精准输入，使系统在复杂环境下更稳健。

把感知与动作预测、规划分开训练，可以有效削弱感知误差的负面传导。若感知无法准确定位物体，后续路径规划的性能便会受损。两阶段策略先把感知精度夯实，避免误差在全系统扩散，从而提升整体性能。该策略既保证了效果，也兼顾了训练效率：第一阶段集中打磨关键感知，第二阶段在输入质量有保障的基础上做全模块协同优化，使系统在实际应用中表现更出色。

### 6.3.8 特斯拉FSD多任务架构解析
特斯拉全自动驾驶系统采用与 UniAD 相近的多任务端到端架构，但在多视角融合和高级语义理解上投入更大，时间维度的整合方式更接近多模态大模型的设计，因而在复杂交通场景中具备更高的精度与适应性。

如图 6.10 所示，FSD 的占用网络在摄像头特征提取后使用 Transformer 进行处理。图像特征映射时通过 MLP 产生 Key 与 Value，同时利用 BEV 坐标系下栅格坐标的位置编码生成 Query。与传统二维栅格不同，FSD 增加高度维度形成三维栅格，以生成更精确的占用特征。其主要特点如下。

- 1. 原始光子计数输入。FSD 使用未经 ISP 处理的光子计数图像，能够在低光照下提供超越人眼视觉极限的感知能力。
- 2. 时序对齐。借助里程计信息将上一时刻的占用特征进行时序拼接，并通过透明度调节反映不同时刻特征的权重，在通道维度上融合。

[PRE0]
- 3）亚像素几何输出。占用网络的输出不仅包含三维栅格特征，还会基于 Query 生成亚像素级的几何与语义信息。该设计借鉴了 NeRF 的变分辨率聚焦能力，增强了对不同空间细节的捕捉与理解。

此外，FSD 在全自动驾驶框架中加入了高级语义理解模块，如图 6.11 所示，系统融合低精度地图数据与视觉感知信息，对车道线及其几何拓扑关系进行精准识别与处理，涵盖车道数量、宽度、拓扑类型以及分叉点、合流点等关键属性。这些信息经 Dense World Tensor 编码后转化为供 Vector Lane 模块进一步处理的格式。

[PRE1]
Vector Lane 模块采用类似语言模型的向量空间编码方法，如图 6.11 所示，通过对车道线节点如起点、中点、终点、分叉点、样条曲线参数等进行编码，以类似处理语言 token 的方式来处理车道线信息。该架构与 Transformer 解码器相似，先通过自注意力机制处理车道线 token，再在交叉注意力中生成查询，结合向量空间中的 Key 与 Value 生成新 token。

该系统不仅能实时识别复杂路口的道路拓扑，还能随自车视角与环境变化实时调整关系。这种高级实时感知能力对自车路径规划与预测其他车辆行为至关重要。

### 6.3.9 具身任务迁移全景
具身机器人的运动规划复杂度远超自动驾驶，既包含导航规划，也涉及末端执行器如机械手或夹具的精细控制。对 Optimus 而言，特斯拉在导航部分直接迁移了 FSD 的技术，而末端执行器的动作规划则依赖类似的多任务轨迹生成方法。

如图 6.12 所示，Optimus 通过多视角摄像头输入构建三维环境的占用图，这对机器人在复杂环境中导航至关重要。特斯拉将自动驾驶领域积累的神经网络与计算机视觉系统调整并迁移到机器人平台，用于室内环境的动作规划。鉴于室内环境与任务要求与自动驾驶不同，需要重新采集并训练适用于室内场景的神经网络数据，这些数据有助于机器人在无 GPS 支持的室内环境中精确定位。

为提升室内导航精度，特斯拉研发了特征点跟踪神经网络，利用高频特征点在无 GPS 环境中精确确定机器人位置。FSD 中的占用网络技术被用于生成导航路径并确定最优或期望的行进路线。

然而对双足机器人而言，仅有导航路径远远不够，还需对其自身物理属性如肢体长度、重量分布等有准确认知，以计算精确的运动轨迹。设计步态时重点在于最小化能量消耗同时保证移动速度与稳定性。保持平衡是运动中的核心挑战，尤其在不平坦或动态变化的地面上。机器人使用自身的运动学与动力学模型生成参考轨迹，这些轨迹定义了步态、重心移动及躯干调整的具体细节，以维持平衡与动态稳定。

通过仿真技术，特斯拉能在虚拟环境中优化机器人的运动策略，包括步态调整、关节解锁和平衡控制。机器人需要实时处理大量环境输入数据，并灵活应对未知或变化场景。特斯拉通过集成高效计算平台与先进传感系统，使机器人能快速响应环境变化。

将自动驾驶技术应用于人形机器人平台的关键在于出色的技术整合能力以及对环境的深刻理解，这使得技术能在不同平台间高效迁移并实现适应性。

### 6.3.10 端到端架构优劣一览
多任务端到端架构通过直接处理从输入到输出的完整流程，避免了模块化架构中常见的信息丢失与错误累积问题。该架构整合多个任务，保持了高效准确的信息流，从而提升整体性能。与传统分层架构相比，端到端响应更快、实时处理能力更强，因为减少了中间步骤的传递与处理。此外，通过设计与训练方法的创新，端到端架构能有效整合人类先验知识，使模型更贴近实际应用需求。

然而端到端架构也存在局限。首先，设计时需同时考虑多个任务的特性与需求，网络结构变得更复杂。不同任务可能需要不同的特征表示与优化策略，系统设计时需在多任务间平衡协调，设计不当可能导致某些任务表现不佳，甚至出现任务干扰，尤其在各任务目标存在竞争或矛盾时。

其次，多任务端到端架构的性能高度依赖网络结构设计，不同结构在处理不同任务时表现差异显著，需要精细调整与优化以确保各任务均达满意水平。此外，处理多个任务通常需要更多计算资源与数据存储空间，尤其在资源受限环境中可能成为应用限制。

端到端架构的演进趋势更多指向构建能处理多任务、多模态的统一模型，基于共享底层表示执行分类、检测、生成等不同类型任务。这减少了为每个任务设计维护独立模型的开销，并提高泛化能力。例如 GPT-4、PaLM-E 等大模型可同时处理自然语言理解、生成、图像识别、推理等任务。针对具身动作规划的特点，可推测端到端具身大模型也必然朝多任务统一模型方向发展。

## 第7章 具身智能记忆机制
在基于大模型的具身智能系统中，记忆模块在环境理解、决策制定和经验学习中发挥关键作用。具身智能系统依赖记忆累积多模态信息并处理更新历史经验，从而实现动态适应。通过有效记忆检索，系统可将先前知识应用于当前任务，支持从任务级到动作级的规划。任务级规划依赖长时记忆积累，动作级规划则需要短时记忆的实时反馈，二者协同确保系统在复杂多变环境中做出合理行为选择与调整。

## 7.1 人类记忆体系
人类记忆作为大脑核心认知功能，经过进化发展为支持复杂行为与决策的关键机制。对人类记忆系统的研究为人工智能中记忆机制奠定了理论基础。如图 7.1 所示，按记忆持续时间，人类记忆可划分为感官记忆、工作记忆和长期记忆。

感官记忆是信息处理的第一阶段，负责对来自视觉、听觉等感官的输入进行短暂存储。容量大但持续时间极短，通常仅几百毫秒至数秒。尽管大部分信息迅速消失，感官记忆为工作记忆提供原始数据，支持后续推理与决策。例如横穿马路时，视觉感官记忆能快速捕捉交通状况，为是否安全通过提供依据。

[PRE3]
图 7.1 人类的记忆系统分类

工作记忆亦称短期记忆，具备临时存储与处理信息的功能。如图 7.1 所示，工作记忆位于感官记忆与长期记忆之间，不仅存储当前处理信息，还在认知任务中通过与长期记忆交互整合已有知识。工作记忆在学习、推理、理解和决策等复杂任务执行中至关重要，但容量有限，信息通常只能保持数秒，除非通过复述等策略维持。它不仅用于信息暂存，还提供动态平台对信息进行整合、排序和更新。

长期记忆可维持数天至数十年，进一步分为内隐记忆即程序性记忆和外显记忆即可述记忆。内隐记忆负责存储无需努力即可自动化的技能与习惯，如骑自行车或打字，通常经长期练习获得。外显记忆可被个体有意识提取与描述，进一步细分为语义记忆与情节记忆。语义记忆存储世界通用知识，如“巴黎是法国首都”；情节记忆与个人经历的具体事件相关，通常涉及时间与地点，如记忆在巴黎度假的细节。

长期记忆作为个体知识与经验的储备库，在决策中发挥重要作用。例如医生诊断病情时依赖长期记忆中的医学知识与临床经验支持判断。根据图 7.1，工作记忆与长期记忆存在双向交互，工作记忆不仅处理当前任务，还通过检索调用长期记忆信息增强任务有效性；同时长期记忆形成也依赖工作记忆中对信息的处理与编码。

深入分析人类记忆结构可为大模型记忆机制设计提供重要借鉴，该机制不仅需实现信息的短时或长时存储，还需在不同记忆系统间实现有效协同，以支持人工智能模型在推理、决策及任务规划中的表现。

## 7.2 大模型的记忆机制

### 7.2.1 参数即记忆
在大模型中，所谓的“长期记忆”可视为存储在亿万参数中的知识。这些知识通过预训练或微调积累，并隐含于模型参数权重中。这种隐含知识类似于人类语义记忆，即模型处理语言任务时所依赖的世界知识、事实与规则，为模型理解与生成文本提供基础。

大模型的情景记忆体现为其处理或生成文本时对特定上下文的依赖性。通过注意力机制，如图 7.2 左侧注意力热力矩阵所示，模型可在生成新内容时参考当前上下文信息，模拟对特定场景的记忆调用。该机制使模型在跨段对话或多轮推理中保持语义连贯，展现出类似人类情景记忆的特性。

研究表明，当模型接收详细具体上下文时，可能激活更复杂的推理模式，展现出类似因果推断与心智模拟的能力，该现象与程序性记忆相似，但内在机制与人类大脑处理方式并不完全一致。如图 7.2 右侧依赖树结构所示，大模型主要依赖基于图结构的注意力机制处理上下文间依赖关系并进行因果推理与逻辑判断，而非类似人类大脑的神经网络机制。

尽管参数记忆可存储大量知识并通过注意力机制调用，仍存在诸多挑战。首先，参数记忆的隐式特性使模型无法像人类一样清晰调用特定知识。预训练过程中知识通过权重隐式编码，而非显式记忆，模型需借助上下文激活与当前任务相关知识。这种隐式记忆导致模型对新任务适应性较差，尤其面对特定上下文或领域外任务时可能无法准确调用适当知识。

[PRE4]
图 7.2 注意力热力矩阵和依赖关系表示

其次，图 7.2 中的注意力热力矩阵虽展示大模型如何动态处理上下文，但该处理仍受模型参数限制。当上下文信息较少或不完整时，模型可能无法正确生成或推理预期结果。因为模型记忆不像人类大脑情景记忆那样灵活，而是依赖参数中隐式存储，难以在全新情境中做出适应性调整。

另外，图 7.2 右侧依赖关系表示展示模型如何在推理中通过依赖树处理上下文信息。然而该推理机制也依赖预训练时学到的语法与语义结构，无法真正模拟人类通过程序性记忆学会的技能。例如人类在学习掌握复杂技能时，程序性记忆能快速适应变化任务需求，而大模型参数记忆更为固定，需大量新数据才能实现类似适应。

深入研究大模型注意力机制与参数记忆可发现，尽管大模型在某些任务中表现出与人类记忆系统相似特征，本质上仍依赖静态参数存储与动态注意力机制结合。学术界尚未完全解决模型对复杂任务的自适应性问题，未来可进一步探索通过更多层次外部记忆机制或增强型注意力机制提升大模型在多样化任务中的表现。这也包括通过限制上下文范围或模块化设计，测试大模型在特定条件下是否能展现出类似人类记忆的灵活性与推理能力。

### 7.2.2 上下文与工作记忆
在大模型中，所谓的“工作记忆”可类比为模型处理输入时利用的上下文窗口。如图 7.3 所示，以 GPT-4 为例，其上下文窗口长度约 4096 个 token。英文中 token 通常指单词或单词部分，而在处理汉字时，一个 token 可能代表一个汉字。因此 GPT-4 一次处理上下文长度约 4096 个 token，约等于 4096 个汉字，相当于几页纸文本量，模型可在一次对话或生成任务中“回忆”或参考这些文本进行推理。

[PRE5]
人类工作记忆不仅能暂存信息，还能进行排序、整合、关联与更新。尽管大模型上下文窗口不具备人类工作记忆的动态处理能力，但可通过 prompt 设计与上下文管理优化推理能力。这类 prompt 设计旨在选择性提供关键信息，使模型聚焦于任务相关内容，类似于人类解决问题时优先回忆相关信息的过程。将相关信息按逻辑顺序组织在上下文中，有助于模型更有效地整合信息与推理。例如在对话或文本生成任务中，随着对话深入，更新上下文窗口以包含最新信息至关重要，这使模型能基于最近内容做出响应，确保话题连贯性与逻辑性。有效 prompt 设计还包括引导模型将新输入与已有上下文信息关联整合，从而拓展推理深度与广度。

在实际应用中，优化 prompt 与上下文能显著提升模型表现，增强信息处理准确性与相关性。合理上下文有助于模型适应复杂对话流与多变信息需求。例如在客户服务或长篇文本生成任务中，精心设计的 prompt 与上下文可帮助模型在不同任务间切换，保持信息连贯与一致。然而，如何有效操控大模型工作记忆，特别是在长对话或复杂任务中，使模型保持逻辑性并适应多样化信息需求，仍是提升模型性能的关键技术挑战之一。

### 7.2.3 外部记忆
大模型与人类大脑在记忆机制上存在显著差异。大模型依赖预训练过程获取与存储长期记忆，该过程不仅涉及大量计算资源，且模型部署后更新其内部长期记忆通常面临经济与技术挑战。因此，通过外部存储空间补充或替代大模型内部长期记忆成为主流技术，特别是在处理语义记忆时。该方法在降低成本的同时增强模型灵活性与准确性。

根据认知科学对记忆形成的普遍理解，记忆过程通常分为编码、存储与检索三个阶段。这一过程类似流水线，将外部刺激转化为可存储与回忆的有意义模式。在大模型中，外部存储机制设计同样需要模拟这一过程，通过有效编码、存储与检索机制，实现与人类记忆系统类似功能。

检索增强生成 RAG 技术是应用大模型外部记忆的有效策略。如图 7.4 所示，该技术通过在模型生成过程中引入外部知识库，使模型能访问不在其内部参数中的信息，从而弥补内部长期记忆不足。RAG 核心在于模型在生成响应前，通过生成查询从外部知识库如维基百科、数据库、文档库等检索相关信息，然后将检索到信息整合到生成任务上下文中，作为附加数据帮助模型提供更准确、时效性更强回答。

[PRE6]

通过引入外部知识库，模型能应对更广泛问题，并显著减少因训练数据不足引发的幻觉现象，即生成不准确或虚假信息。外部知识库还能动态更新，使模型在无需重新训练情况下获取最新信息。例如模型可通过外部知识库访问最新新闻、科学发现等，特别适用于快速变化领域。

外部记忆不仅弥补大模型在长期记忆更新上的局限性，还使模型在实际应用中表现出更高灵活性与准确性。通过不断改进外部存储与检索机制，模型将能更好地模拟人类记忆的编码、存储与检索过程，为复杂生成任务提供更丰富知识支持。
