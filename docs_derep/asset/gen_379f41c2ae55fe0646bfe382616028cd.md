# 第一章

# AI时代的财富规则在重写

从前赚钱的关键是信息差，谁先知道、谁先看到、谁先出手，谁就占便宜。现在AI把获取信息、生产内容、分析数据的门槛拉平了，人人都能快速拿到答案，靠信息差赚差价的空间正在迅速消失。

接下来的赢面在哪里？

[PRE0]
## 1.1 从用AI到用AI赚钱的思维切换

### 1.1.1 能力边界被重新丈量
过去一个人的价值看他会什么。现在会用好AI，你就能独立完成品牌文案全案、视觉方案、产品原型、商业提案。一个做跨境电商的朋友，靠AI三天就把选品调研、详情撰写、广告素材一起搞定，过去这活要三个人干一周。

今天的能力天花板，不再是个人知识储备，而是驾驭AI的能力。

### 1.1.2 一周完成一次快速试错
周一用AI做市场调研，找准细分需求；周二到周三让AI生成产品雏形，文案、课程、工具都能出；周四周五小范围投放，看数据反馈；周末复盘迭代，跑不通就换方向，跑通就放大。

过去需要团队几个月的工作，现在一个人借助AI一天就能闭环。试错成本被压缩到了极低。

### 1.1.3 从卖时间到搭建系统
打工本质是把时间卖掉，上限一眼可见。现在要做的是建系统。

一个人靠AI就能打理一套IP账号矩阵，通过广告和带货每月入账数万。把自己的行业经验喂给AI，结构化成在线课程或付费社群内容，实现一次制作、反复售卖。借助AI+自动化工具如Make、Zapier，把获客、转化、交付连成一条自动化链路，流转几乎不用人工。

一个个体+AI，已经能跑通过去需要一家小公司才能运转的商业闭环。把AI当成搜索引擎用是浪费，应该把它当合伙人：你负责方向与判断，它负责执行与效率。这个组合，才是当下最小的创富单元。

小贴士
人机协作里，人的判断力决定上限。AI输出的内容，需要你分辨什么是对的、什么是对但没用的废话、什么是读起来顺却经不起推敲的空话。判断力不足时，信息越多越容易跑偏。

### 1.2.1 内容代写与运营外包
这是需求量最大、入门最快的赛道。平台更新越来越快，中小商家和个人博主的生产能力跟不上。小红书每天要发笔记，公众号要保持节奏，短视频要脚本、直播要话术，叠加起来就是一份全职工作量。多数商家不愿为几篇文案养一个全职，外包按需采购，单价几十到几百元，性价比最高。

有两个切入口。一是通用内容外包，商业文案、小红书种草、公众号推文、短视频脚本、直播话术等，客户覆盖电商、传统企业、门店和个人博主，可在闲鱼、猪八戒或行业社群接单。二是电商内容外包，商品主图文案、爆款标题AB测试、竞品监控、评价挖掘等，对平台规则有认知的人客单价和复购率更高。先用两周吃透电商内容逻辑，再出手。

### 1.2.2 知识付费与培训
泛AI入门课已严重过剩，但垂直场景的应用培训需求仍在增长。
企业内训是代表，制造、零售等中小企业意识到AI提效，却不知如何落地。两小时定制内训报价通常在3000至8000元，远高于面向C端的业务。
职业陪跑也不错，帮律师用AI处理合同、帮教师用AI做课件、帮卖家用AI做选品分析。越垂直越值钱，需要你对行业有足够理解才能嵌入真实工作流。

### 1.2.3 数字产品销售
一次制作、多次售卖，是轻资产里复利最强的模式。
产品包括个性表情包、手机壁纸、行业专属提示词合集、AI工作流SOP模板、垂直内容框架包等。主流渠道有闲鱼、小报童、爱发电、视频号付费专栏，定价19到199元不等，积累口碑后可形成被动现金流。

### 1.2.4 垂直领域AI服务
天花板最高，但需要行业背景。
把自身专业与AI的生产效率结合，做难以替代的服务。法律从业者做合同初审辅助与科普，财务做财税内容与报表解读，医疗背景做健康科普与患者教育，教育从业者做题库教案。背景加持下，可轻松超越纯内容外包竞争者，客单价是普通代写的5到10倍。

这些赛道都不要求技术专家，也不需大额启动资金，起盘快，一周内能接到首单。

小贴士
新手建议从内容代写起步，先积累三到五个真实案例，再升级赛道或提价，风险低、启动快。

### 1.3.1 长文撰写与结构搭建
用好提示词可输出结构完整的长文，在内容代写、报告生成上表现突出。还能续写、纠错、润色、一键改写风格并生成摘要。

### 1.3.2 格式转换
把长文转成小红书笔记，把会议录音文字稿转成工作报告，把产品说明书转成种草文案，一份素材多次利用，效率翻倍。

### 1.3.3 网联搜索与信息整合
可实时联网抓取最新资讯并整理成所需格式，适合行业分析、竞品研究、热点选题，调研时间可压缩到原来的五分之一。

### 1.3.4 图片理解
上传图片后能识别内容、分析风格并生成对应文案。做电商详情页时，拍完图直接让豆包写描述，省去重复劳动。

### 1.3.5 角色扮演与对话模拟
让豆包扮演面试官或客户，练习销售话术、设计面试题、模拟用户提问，节省人力成本。

### 1.3.6 数据分析与报告生成
上传表格数据，让豆包提炼规律并输出报告，即使不懂分析也能产出专业水准的结论。

### 1.3.7 代码辅助
可完成代码补全、Bug检测与修复建议、注释生成。无编程基础也能借助它写简单的数据处理脚本或自动化工具雏形。

### 1.3.8 多语言翻译与本地化
会按目标语言习惯调整表达，接近人工翻译水平。翻译者可借助它突围内卷，跨境电商和海外内容运营也能省掉外包费用。

### 1.3.9 提示词自优化
不确定怎么问时，告诉豆包目标即可，它会反推更优的提示词，让复杂提问变得亲民。

### 1.3.10 智能体与插件扩展
支持接入专属智能体和第三方插件，覆盖SEO分析、财务解读、法律咨询辅助等专业场景，解决普通对话无法处理的难题。

# 零基础零成本，副业首个千元目标

AI赚钱的门槛没有想象中高，当前模型正变得更简单、更聪明。不用注册公司、不囤货、无需证书，一部手机就能开始，利用碎片时间把副业第一个1000元赚到手。

## 2.1 小红书代写变现：爆款公式与接单话术全流程
小红书代写门槛不高，一篇500至1500字笔记，熟练后用豆包辅助5到20分钟可出初稿。新手在闲鱼挂单，报价30到100元一篇，是验证能力和拿到首笔收入的最快路径之一。

### 2.1.1 小红书的推流逻辑
平台算法高度依赖互动数据：点击率、收藏率、评论率。笔记能否爆，取决于三点，如图2-1。

[PRE5]
图 2-1 小红书爆文笔记的三个要素

封面和标题决定要不要点进来，内容价值感决定是否收藏，互动引导决定是否留言。写笔记的目标不是写出高水平文章，而是写让人想点、想藏、想评的内容。

### 2.1.2 豆包辅助的万能结构
钩子标题：数字+痛点/利益点。例“月瘦8斤！我用这3步彻底戒掉奶茶！”
共鸣开头：1到2句描绘目标用户的真实困境，迅速代入。
干货主体：3到5个可操作的方法，用短段落加小标题呈现。
结果佐证：晒效果、数据或截图，增强可信度。
互动收尾：引导收藏并提问。

要求：（1）标题含数字突出利益点，20字内；（2）正文500-800字，分3-5点，每点加emoji；（3）开头制造共鸣，结尾引导互动；（4）语气亲切口语化。

### 2.1.3 从挂单到交付的四步
第一步，打造服务页。标题带“小红书代写、爆款笔记、种草文案”等关键词，初期定价30-80元/篇，附1-2篇优化过的样稿截图。
第二步，承接咨询。客户私信后快速回复，建立专业感并收集需求。
第三步，收集需求后用模板生成初稿，人工优化语气和植入。
第四步，交付时附简短说明，点出笔记亮点和针对性处理，提升复购。

## 2.2 表情包与壁纸变现：豆包一键出图，平台收授权费
表情包和壁纸上架后可持续产生被动收益，用户每次下载你就获得授权分成。上架一套8张表情包，卖1套和卖100套的制作成本相同，数量叠加后收入会滚雪球。这是零基础建立被动收入的直接路径。

豆包自带的AI绘图功能大幅降低制作门槛，不会PS也不用手绘，只需写好提示词就能批量产出商业可用素材。

### 2.2.1 主流变现渠道
微信表情开放平台：国内最大分发渠道，按发送量分成，长尾效应明显。
爱表情、斗图平台：用户活跃度高，适合风格鲜明的原创。
摄图网、千图网：壁纸和装饰素材按下载次数付费。
Etsy：海外创意市场，壁纸和数字贴纸售价普遍高于国内。
闲鱼、淘宝小店：适合打包售卖或定制接单。
