BiliAgent 检索评分工作流拆解

这套实现用 LangGraph 把检索、评分、改写、生成串成一条可控的问答链，并通过 FastAPI 暴露成在线服务。核心思路是先查后评，评不过就改写问题，生成后再用幻觉检测和代码评估做二次校验。

状态定义是整张图的基座，统一了问题、文档和生成结果的传递。

from typing_extensions import TypedDict

class GraphState(TypedDict):

    """

    Represents the state of our graph.

    Attributes:

        question: question

        generation: LLM generation

        documents: list of documents

    """

    input: str

    generation: str

    documents: str

        return "generate"

def generate(self, state):

    question = state["input"]

    documents = state["documents"]

    generation = self.generate_chain.invoke({"context": documents, "input": question})

    return {"documents": documents, "input": question, "generation": generation}
