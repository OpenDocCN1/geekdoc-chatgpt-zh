方差拆解关键要素

- SS：平方和，用来度量变异大小。组间部分反映不同组别间的离差，组内部分反映组内观测的离散，总量等于二者之和。
- df：自由度。组间自由度为组数减1，组内自由度为总样本量减去组数。
- MS：均方，平方和除以对应自由度得到。
- F：F统计量，检验组间差异是否达到统计上的差别。
- P值：判定F统计量的依据，惯例以0.05作为判断阈值。
- F crit：F临界值，F统计量超过此阈值时拒绝原假设，认为组间存在差别。

本例中P值为0.191289，高于0.05，在0.05水平下证据不足以拒绝原假设，即活动前后活跃度并无明显差别。

第5章 聚类与分类进阶

5.1 方法拆解

聚类与分类是数据挖掘的两大核心手段。聚类属于无监督学习，目标是将数据对象按相似性自动归为若干簇，全程不依赖预设标签，依靠内在相似度形成分组。

聚类的目的在于挖掘数据中隐含的自然群体，使簇内对象高度相似、簇间差异明显。例如基于年龄、性别、收入等信息，算法可将人群自动划分为青年、中年、老年等群体，分群依据完全来自数据本身。

分类则属于监督学习，利用已知的类别标签训练模型，对新数据进行预测。若有一组标注为玫瑰、郁金香、菊花的花朵图像，可训练分类器识别新图像所属类别。

两者区别在于：聚类发现内在分组，分类依赖既有知识进行预测；聚类无需标签，分类必须基于带标签数据训练。实践中二者常配合使用，实现更深入的数据理解。

5.1.1 聚类解析

聚类是一种基于相似性对数据集进行分组的统计方法，目标是簇内相似度高、簇间差异大。通过识别数据模式，将数据点划分为多个簇，广泛应用于市场细分、社交网络分析、图像分割等领域。

核心概念如下：

相似度

衡量两个数据点相似程度的指标，计算方式多样，如欧氏距离、曼哈顿距离、余弦相似度等，直接影响聚类结果。

距离度量

衡量多维空间中两点距离的方法，常见有欧氏距离、曼哈顿距离等，选择取决于数据类型与业务场景。

簇

聚类后形成的相似数据点集合，簇内点在特征空间中靠近，簇间相距较远，簇的数量与特征取决于算法与参数。

轮廓系数

评估聚类质量的指标，结合簇内相似度与簇间不相似度，取值-1到1，越接近1效果越好。

聚类输出通常包含每个点的所属簇、簇中心及簇特征描述，有助于理解数据结构并指导后续决策，见表5-2。

表5-2 聚类分析输出项

| 输出项 | 解释 |

| :--- | :--- |

| 轮廓系数 (Silhouette Score) | 衡量样本与其自身簇的相似度与最近簇相似度的差异，范围 -1～1，越接近1聚类越好 |

| D-B 指数 (Davies-Bouldin 指数) | 通过簇间相似度与簇内相似度评估聚类效果，值越小越好 |

| C-H 指数 (Calinski-Harabasz 指数) | 通过簇间离散度与簇内离散度比值评估，值越大越好 |

| 兰德指数 (Rand Index) | 基于样本匹配的评估指标，衡量聚类结果与真实标签一致性，取值0～1，越高越好 |

5.1.2 分类解析

分类是一种监督学习方法，依据特征对数据对象进行标记，目标是学习已有标记数据以构建模型，对未标记数据进行准确分类。广泛应用于金融欺诈检测、医疗诊断、文本分类等。

核心概念：

类别

预定义标签，每个类别代表一组特征相似的数据点，定义直接影响准确性。

特征

描述数据点的属性或变量，特征选择与处理对模型性能至关重要，包含数值型与类别型。

|---|---|

| 精确率（Precision） | 反映正例识别能力，对不平衡数据集重要 |

| 召回率（Recall） | 反映正例覆盖能力，对不平衡数据集重要 |

| ROC曲线和AUC值 | 反映不同阈值下综合性能，对二分类问题重要 |
