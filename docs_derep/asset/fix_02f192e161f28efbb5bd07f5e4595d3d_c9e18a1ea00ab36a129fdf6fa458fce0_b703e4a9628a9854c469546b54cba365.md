### 底层原理速览

Path 类充当虚拟轨道，算法核心在于：GetParam 在轨道上投影偏移量得到进度，GetPosition 再将进度映射为世界坐标。跟随流程本质是：Path 取点 → 刷新目标 → 交由 Seek 执行。
