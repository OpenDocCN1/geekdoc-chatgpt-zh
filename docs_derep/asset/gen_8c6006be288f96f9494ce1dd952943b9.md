修复后的逻辑：

- 生成开始时展示打字机效果；
- 效果持续至解析完成并生成卡片；
- 仅在卡片生成完毕、LLM API 请求结束后再替换打字机文本。

（2）文案风格差异不足。有时多平台生成的文案风格区分度低，可通过调整 System 提示词中的“风格标签”来增强多样性。
