从图4-17的示意可以看出，编码侧单层结构与解码侧单层结构在整体上相似，差异集中在注意模块的实现上。形式上编码侧采用的是去掉图4-5中填充子模块后的注意，解码侧则保留该填充，如图4-20所示。本质上训练时解码侧把输入当作样本组共用的列，只把列尾部的表示作为条件模块的查询；编码侧在训练与推理时都把输入视为独立样本的列，并让列中每个位置的表示轮流充当条件模块的输入。

[PRE0]

对照图4-20，当输入长度为 t 时，编码侧的注意等价于并行运行了 t 个图3-9的注意单元。每个单元都把同一份形状为 (t, d_main) 的输入矩阵里的一维表示拿去做 Q 路的线性映射。于是这 t 个单元各产生一个 d_main 维表示，整体组成 (t, d_main) 的矩阵，即该注意模块的最终结果。

结合图4-17可知，编码侧接收长度 t 的列时，输出是一张 (t, c) 的矩阵。矩阵中每列的 c 维表示都对应把输入列中某一个位置的表示送入条件模块后得到的结果。在序列分类里，任选其中一列的向量即可得到该输入列映射到 c 个类别的概率，区别仅在于挑选了列的哪个位置作为条件。

在单一编码层基础上堆叠更多层，可得到多层编码式结构。

实验4-7 以编码式结构做序列预测，莫尔斯码数据集 III 中每个单元的取值范围为 {0,1,2,3}，因此这里的预测实质是分类。为方便小批梯度下降，本次实验把输入列长度固定为 16。

### 4.5 编解码器型Transformer

编码侧在纯序列分类里显得有些浪费，因为 t 个输出向量往往只用其一；可一旦进入带条件列的预测场景，它就能充分发挥价值。条件列预测指预测结果不仅受主输入列影响，还受额外给定的条件列约束的任务。例如把每个词或汉字视作一步，给定条件句 “The longest journey begins with a single step”，去预测中文列 “千里之” 的后续，就是典型例子。

需要说明的是，条件列和目标输入本来都可以直接拼接喂给解码侧，但单独保留条件列有好处：二者词表可以不同；同时可以把部分信息抽出来作条件，从而缩短主输入列，让任务更简单。

条件预测要同时融合主列和条件列的表示。条件列在推理时完整已知且固定，用编码侧去编码它很合适。虽然编码侧的注意会对同一组向量反复聚合，但每次查询向量不同，得到的上下文表示也会各不相同。按照3.2节的结论，这种多样性能让模型从多个不同的聚合结果里挑选对下一步预测更有帮助的部分，所以条件任务正是编码侧的舞台。

聚合主列并做下一步预测这部分依然交给解码侧。关键是怎么把编码侧和解码侧联合起来完成条件列预测。

> 【想一想】怎样把编码侧和解码侧整合起来？

单层编码侧或解码侧都是靠注意来做向量聚合，所以自然可以再用一次注意把条件编码和解码侧状态桥接起来，这就形成了编解码结构。

单层编解码结构见图4-22。为图示简洁，残差、层归一化和 dropout 被省略，但实际架构里都有。图中 t' 是编码侧条件列长度，t 是解码侧输入长度。左侧编码层使用图4-20的无填充注意。右侧解码层包含两块注意：下面一块是图4-5的解码自注意，负责融合解码侧自己的历史；上面一块是跨注意，也是图4-20类型的编码注意，用来读取编码层输出的 t' 个 d_main 维向量。具体做法是把编码层输出当作 K、V，把下面自注意的结果当作 Q，用解码侧状态去查询条件表示。

### 4.6 本章小结

为减少重复计算，可以把存在包含关系的多个输入列合并成一个样本组。形式上像单一样本，实质是多个样本的组合。用样本组训练分类模型等价于用一批不含填充的列做梯度下降。

在样本组注意里，点积模块输出的是 Q 路与 K 路所有配对的点积构成的矩阵，softmax 前加了填充模块来屏蔽无效计算。为提升预测能力，在注意与 softmax 回归之间加入前馈网络，通常采用单隐含层结构。为加快训练，给注意与前馈网络各加一个残差连接，此时可把二者理解为逐步调整列的最后一个向量，使其在 softmax 上与标签对应的权重投影最大化。二者也可并联。

为进一步提速，对注意、前馈、softmax 输入的每个向量做层标准化，代价是模型复杂度下降。为防过拟合引入 dropout，随机关掉部分元素以扰动结构。由此得到单层解码型结构。增加层数得到多层解码型结构，适用于序列预测。

序列分类中训练样本输入间不一定有包含关系，通常无法用样本组，可用编码型结构完成。形式上编码侧用无填充注意，解码侧用带填充注意。本质上解码侧把输入视为样本组并只用末尾向量作条件，编码侧把输入视为单一样本并让每个位置向量轮流作条件。

条件列预测里，编码侧聚合条件列，解码侧聚合输入列并预测下一步，再用额外注意桥接二者形成编解码。编码侧与解码侧的连接不唯一：可把最后一个编码层输出送给所有解码层，也可逐层对应，还可省去编码层直接把嵌入后的条件向量送入解码侧第一层。

## 第5章 Transformer架构在自然语言处理领域的应用

经过前面4章的学习，读者应该已经掌握了Transformer架构及其原理。由于Transformer架构可用于多种序列的监督学习任务，其输入列既可以等长也可以不等长，并且还可以附带额外的条件列（条件列同样既可以等长也可以不等长），故能够使用Transformer架构完成的机器学习任务比较多。

从本章开始，将探索Transformer架构在一些领域中的应用。在第1章中提到过，Transformer架构最初用来解决机器翻译中的序列转换问题。机器翻译，即使用计算机将一种语言自动翻译成另一种语言，是自然语言处理领域中的任务之一。自然语言处理主要关注如何让计算机具有理解和运用人类语言的能力，其包括但不限于文本和语音处理。

除了机器翻译，本章还将探索如何使用Transformer架构完成文本分类、文本生成、语音分类、语音转文本等自然语言处理领域中的任务。
