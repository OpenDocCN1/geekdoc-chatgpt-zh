# 一、标准通知结构六要素

1. 题名
常规表述：单位名称+事由+文种，如《××公司关于2024年春节放假安排的通知》。
内部简写：《关于××事项的通知》。
紧急文件需在题名标明，如《××学校关于台风停课的紧急通知》。

2. 收文对象
顶格写明接收单位或个人：
单位类：××部门、全体员工；
个人类：张三同志、各项目经理。
多级收文规则：同级单位用顿号分隔，不同层级单位用逗号分隔。

3. 正文
开头依据段：
政策依据，如“根据《国务院办公厅关于2024年部分节假日安排的通知》”；
事实依据，如“因办公楼电路改造需要”。
主体事项段：
分条列述，可用“一”“二”“三”或“1.”“2.”“3.”；
需涵盖时间、地点、事项内容、具体要求。
结尾执行段：
联系人及电话；
执行要求及反馈截止时间。

4. 附录说明
列明附件名称及件数，如“附件：1.《参会回执表》；2.会议议程”。

5. 署名区
发文单位全称，需与印章一致；无单位可省略。
日期采用阿拉伯数字，置于单位名称下方或右侧对齐。

6. 印章签名
单位发文需加盖公章；
个人发文需手写签名。

# 四、常见误区提示

1. 收文对象错误
错误：向无管辖权单位行文。修正：明确发文权限，跨级需抄送上级。

2. 时效冲突
错误：发文日晚于执行日。修正：预留合理周期，一般不少于3个工作日。

3. 附件缺失
错误：正文提及附件但未附。修正：单独列明附件清单。

4. 盖章不规范
错误：仅签字未盖章。修正：正式文件须加盖公章。

5. 联系方式缺失
错误：要求反馈但未提供联系人。修正：至少提供电话与邮箱。

提示：正文多用仿宋三号，题名多用小标宋体二号，页边距上37mm、下35mm、左28mm、右26mm。
