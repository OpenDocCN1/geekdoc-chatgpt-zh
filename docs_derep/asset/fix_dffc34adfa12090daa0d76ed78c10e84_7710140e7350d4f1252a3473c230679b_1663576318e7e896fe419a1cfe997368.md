#### 3.2.3 DeepSeek-R1模型参数详解

调用 DeepSeek-R1 时，可通过 chat.completions.create 接口调节生成长度、多样性与逻辑严谨度等输出特性。R1 与 V3 共用该接口。

R1 在解析与推理机制上存在一些特有行为，调用时需注意。

##### 1. max_tokens参数
- （1）该参数仅限制最终回复正文，即 content 的最大 token 数。默认值 4096 token，约 3000 中文字符，上限 8192。
- （2）此限制不计入 reasoning_content。复杂任务下 reasoning_content 单独可达 32K，整段输出长度可能远超 max_tokens。官方计划后续推出 reasoning_effort 控制推理深度与长度。

##### 2. reasoning_content字段
- （1）R1 除了返回常规回复 content，还会同级返回 reasoning_content，即模型内部思考过程。
- （2）该字段记录推导思路与结论形成轨迹，适合解释类任务、教学演示与结果评估。

##### 3. 功能支持情况
- （1）当前已开放标准对话补全与对话前缀续写 Beta，可用于接续已有内容。
- （2）Function Calling、JSON 输出、FIM 补全 Beta 暂未开放，相关字段设置无效。

##### 4. 不生效的参数
temperature、top_p、presence_penalty、frequency_penalty、logprobs、top_logprobs 在调用 deepseek-reasoner 时会被静默忽略。为兼容 OpenAI 接口标准，设置不会报错。

#### 3.2.4 DeepSeek-R1基础开发应用

##### 1. DeepSeek-R1思维链执行过程

reasoning_content 是 R1 完成任务时自动生成的推理轨迹，以自然语言呈现问题拆解、逐步推导与中间判断，并与最终答案一并返回。其演化规律见图 3.30。

[PRE0]

DeepSeek-R1的思维链在多轮对话中呈现出清晰的阶段性演化规律。

- （1）第一轮对话通常体现为独立推理，模型基于用户的初始提问进行结构完整、逻辑自治的思考。

- （2）进入第二轮时，模型开始进行递进式推理，能够引用前文内容（前文的问答对）并进行自然衔接，展现出良好的承接性。

- （3）到第三轮及更复杂的轮次，模型则逐步发展为综合性推理，整合多轮信息与多个变量，输出具有清晰逻辑排序的推理链条。随着对话的深入，DeepSeek-R1不仅展现了强大的单轮分析能力，更体现出对上下文的记忆保持、逻辑递进与归纳整合能力，具备类人类的“思维连续性”与“对话一致性”。这使得它不仅适用于一次性问答，还能胜任复杂交互场景。
