# 机器何时学会识文断字

从文字诞生的那天起，它就是人类传递信息、记录历史、传播知识的核心载体。文字也是人类语言的书写形态，更是文化思想与智能的载体。人工智能要让计算机真正读懂人话，关键课题就是自然语言识别，而这门研究的根基离不开语言学。

美国哲学家、语言学家、认知科学家乔姆斯基是这条路上的开路人。没有他，语言学很可能还停留在摸索阶段。正是乔姆斯基让语言学拥有了坚实的理论框架，才变成一门真正的科学，被人称作语言学的牛顿。

乔姆斯基出生于费城的一个犹太家庭，16岁就考入宾夕法尼亚大学。大二时他厌倦学业想退学，被结构语言学鼻祖哈里斯劝住。哈里斯给了他一本尚未出版的手稿《结构语言学方法》，建议他从数学和哲学入手学习语言学。哈里斯把语言学从人文学科推向科学的第一人，在宾大建立了美国首个语言学系。在老师影响下，乔姆斯基豁然开窍，走上语言学之路。

在宾大拿到学士和硕士后，他跑到哈佛投奔当时美国哲学界领袖奎因，做初级研究员。期间发表了第一篇学术论文《句法分析系统》。

1955年4月，为躲避兵役，乔姆斯基回到宾大求博士学位。老师们知道他的才华远超学位要求，但仍坚持规矩：拿出一篇像样的论文即可。他从一部近千页的巨著中抽出一章作为博士论文。那部巨著直到20年后才以《语言学理论的逻辑结构》问世，是其划时代句法分析理论的雏形。仅书面回答几个问题后，他顺利拿到博士学位。

按乔姆斯基的句法分析理论，句子可通过一系列规则拆解解析。一个句子先被解析为名词短语和动词短语，再继续向下拆。他认为所有语言都遵循类似的句法结构，并且指出语言结构是内在的、先天的，而非靠经验习得。他还试图证明，语言机制的核心是简洁的合并操作，而合并是人类进化特有的能力。对语言的创造性使用是人性的标志。他的文法与自动机的关系成为计算机科学的理论基石之一，也为计算机识文断字奠定了早期理论基础。

1968年，卡内基·梅隆大学的学生奎林提出用网络格式表达人类知识结构的形式，即语义网络，用来描述物体的概念、状态及其相互关系。语义网络由节点和连接节点的弧组成，节点代表概念、事件、事物，弧表示它们之间的关系。数学上它是一个有向图，与逻辑表示法相对应。

语义网络是用图来结构化知识的一种方式。信息被表达为一组节点，节点间通过带标记的有向线段相连，表示关系。起初它作为人类联想记忆的公理模型提出，后来被引入人工智能的自然语言理解。

语义网络的重要特性是属性继承。被有向弧连接的两个节点存在上下位关系。例如“兽”是“动物”的下位概念，又是“虎”的上位概念。上位概念拥有的属性可被下位概念继承。基于此可方便推理。语义网络能深层次表征知识，直接明确表达概念语义关系，模拟人的语义记忆和联想，为知识的整体表示、检索和推理提供基础。

语义网络

以模式识别为主的文字识别，加上以语义网络为主的文字理解，让机器识文断字成为现实。今天手机扫一扫、自动翻译、专家系统、知识库背后都有它们的影子。

在自然语言识别的探索中长期存在两条路线：一是以乔姆斯基为代表的语言学方法，二是以贾里尼克为代表的统计学方法。统计学方法依靠海量语料库，通过概率统计发现数据特征、建立数据模型，本质是建立在大数据之上的机器学习。简单说，一个词的用法多种多样，但在不同情境下的出现频率、与其他词的共现频率各不相同。把这些频率统计记录下来，就能建立词语的统计模型，用来分析理解句子的意思。

贾里尼克是IBM的科学家，领导沃森研究中心机器翻译小组，推出法英翻译系统CANDIDE，成为统计学派的代表。他的名言是：“我每开除一名语言学家，我的语音识别系统性能就提升一倍。”可见他对语言学方法有多排斥。

条条大路通罗马。人工智能的研究一直是百家争鸣、各显神通。

## 7.3 新闻不再用人写

2016年，谷歌的工程师让系统学习了2865篇爱情小说，又灌输英语诗歌创作的格式，随后系统真的写出首首小诗。比如这首：“没有人见过他/这让我想哭泣/这让我觉得不安/没有人见过他/这想法让我微笑/痛苦曾经难以忍受/人们曾经无语/那个男人喊了出来/那个老人说/那个男人问。”读下来多愁善感却又怪异，似是而非。

但在新闻写作上，AI的表现截然不同。现在相当数量的新闻由计算机上的AI程序自动撰写。

2011年，思科工程师罗比·艾伦创办Automated Insights，公司缩写AI正是人工智能的缩写。公司与美联社等新闻机构合作，用机器自动写稿。2013年机器稿件已达3亿篇，超过所有主要新闻机构产出；2014年该公司AI程序撰写的新闻稿超过10亿篇。

2014年美联社宣布用该技术为美国和加拿大的上市公司撰写营收业绩报告。目前每季度由AI自动生成的营收报告接近3700篇，是同期记者编辑手工撰写量的12倍。2016年，美联社把自动写作扩展到体育领域，从美国职业棒球联盟报道入手，大幅减轻人力负担。

2014年3月17日清晨，洛杉矶居民被轻微晃动惊醒。震级不大但震源浅，感受明显。地震后不到3分钟，《洛杉矶时报》网上已发布详细报道，不仅列出台网观测数据，还回顾了旧金山区域近10天的地震情况。

网页上署着记者名字，但速度全靠永不休息的AI新闻撰写程序。地震瞬间，计算机从台网数据接口抓取全部信息，飞速生成英文全文。刚醒的记者睁眼即见稿子在屏幕，快速审阅署名后一点发布。一篇机器生成、人工复核的新闻就这样首发。

美联社、华盛顿邮报、中国新华社在AI新闻写作上的探索实践，大大提升了效率和准确性。对某些新闻消息，完全可以通过AI检索和加工实现。

AI如何写作？主要采用机器学习、深度学习等算法生成文章或辅助写作，如写稿机器人、写作助手、智能写诗、智能写春联。新闻机器人实时发现网上的新信息，大量搜索相关数据，并按过往评论事实的方法和用语迅速成文。体育报道能理解“反败为胜”“团队努力”等专业术语，并按算法判断比赛重点。它不只是复述事实，还会加入新元素。

任何文章都有体裁特点和风格，新闻上尤为突出。AI写作的基本能力建立在分析大量数据、总结规律之上，再通过解构从数据中提取所需内容，经排列组合形成新稿。

《纽约时报》研究与发展实验室提出一套新闻编码理论，采用积木式编辑改变新闻生产分发。核心是把可重复使用的部分识别出来并注释，称“文法”或“颗粒”。所有资讯被转化为可拼装的颗粒，每个部分重新编码、加标签、可嵌入。流程是：选定主题→用搜索引擎抓取相关文本→清洗整理去噪→挖掘有价值信息→编写机器学习算法完成创作。

AI参与写作属于代入式写作，即程序编辑或公式编辑。现在网上有小说生成器、诗歌生成器等，本质是文字拼接粘贴。程序背后植入大量故事段落或诗句，给定主题就能在极短时间内运算比对出一首诗或一篇小说。

微软亚洲互联网工程院2014年5月发布机器人小冰，依托大数据、自然语义分析、机器学习和深度神经网络，实现超越简单问答的自然交互。小冰出版诗集《阳光失了玻璃窗》，还参加央视《机智过人》人机诗歌对抗。它的出现引发争论，焦点是AI能否替代人类富有想象力的文学创作，以及AI写作前景如何。

在小冰的现代诗创作鉴赏中，读者常有纠结，有时觉得不输诗人。实则源于现代诗自身特征与当前写作现状的双重作用。现代诗无严格限制，随意性大，常以跳跃、断句、隐喻、象征传达朦胧隐晦甚至诡异的诗意，逻辑被打乱后留给读者重构，想象空间更大。阅读时理解困难，有的困难是作品价值，有的只是水平参差。这也是现代诗常被诘难的原因。

这反倒给AI创作提供空间。小冰存储大量现代诗句，可调取比对资源写作。单句层面能完美无错，且一定是“诗句”，因直接借鉴挪用经典。但多句连读时意境韵味常不尽人意，诗越长裂痕越明显。诗歌等文体创作是人类特有表达，文学思维复杂综合，非简单逻辑推演。所以当前AI文学写作多是文字游戏，因其不具备人类情感和思想，只有智商无情商。

## 7.4 从陪聊到辩论

随着自然语言处理技术突破，以其为基础的应用如雨后春笋。陪聊是最早的会话机器人。

2016年微软发布针对青少年的在线聊天机器人Tay，会话素材来自即兴喜剧演员等作品汇集。因对世界一无所知，无独立思考能力，被算法驱动被动对话，很快被恶意引导表现出极端种族主义倾向。微软紧急叫停，副总裁公开道歉。

市场上已有各种聊天机器人，如客服、儿童教育、娱乐聊天、家居服务、车载控制、全方位服务等。

机器人

聊天机器人可分为目标驱动型和无目标驱动型。目标驱动型有明确服务目标或对象，如客服机器人、儿童教育机器人、提供天气预报、订票、订餐等服务，也称特定领域。

无目标驱动型无特定服务目的，如纯粹聊天、娱乐聊天、游戏虚拟人物等，也称开放领域。

机器人如何与真人聊天？主流技术有检索式和生成式。检索式事先建立对话库，接收用户输入后在库中搜索匹配提取应答。做法简单，但库需足够大才能匹配提问，否则常找不到合适回复。好处是一旦匹配，应答质量高且表达自然，因库内是真实对话数据。

生成式在接收输入后，基于对会话理解和检索，用语句合成自动生成回复。优点是可覆盖任意话题，缺点是生成句子可能不通顺、句法错误。

在大数据和人工神经网络突飞猛进的今天，更多会话机器人具备深度学习，能言善辩。它们能针对提问产生语义一致、逻辑正确、语法规范、活泼有趣且带个性回应，给人真人聊天感。

2019年2月11日，旧金山叶巴布纳艺术中心上演人机互怼大戏。IBM研发的人工智能辩论系统与人类辩论大师哈利什·纳塔拉简展开激烈精彩辩论。人类热爱辩论，计算机也不逊色。

场上像液晶广告牌的机器是IBM在人工智能领域的最新成果——人工智能辩论系统。它并非首秀。2018年6月首战对阵以色列两位顶尖辩论专家，战绩1胜1负。

人类代表哈利什不是一般人：2012年欧洲辩论赛冠军，牛津大学政治、哲学、经济学士，剑桥大学哲学与国际关系硕士。是英国前首相卡梅伦学弟、AKE咨询公司经济风险主管，世界级辩论奖项无数，保持多项辩论世界纪录。

规则很简单：无预准备无交流，现场公布辩题，双方各15分钟准备，之后各4分钟立论、4分钟反驳，最后各2分钟总结，遵循传统赛制。胜负由旧金山湾区学校顶尖辩手和100多名记者现场评判。开场前投票选支持方，结束后再次投票，支持人数增加方获胜。辩题是“我们是否应该让幼儿园获得补贴”。

辩论现场

辩论开始，AI系统用近乎单调的女声说：“哈利什，你好。”随后侃侃而谈，把“补贴学前教育有助于打破贫困循环”讲得几乎无懈可击。措辞完整，旁征博引，还引用美国疾病控制与预防中心数据。

哈利什随即表述观点，直接反驳AI提出的“拯救贫困”论点，双方针锋相对，唇枪舌剑。

赛前79%观众同意幼儿园减免，仅13%反对。20分钟两回合后，双方总结。最终投票，IBM系统支持率降至62%，流失17个百分点。因胜负看支持人数增减，故人类获胜。

此战显示AI会话系统越来越灵活。AI正从只能回答特定问题的聊天机器人，转向能处理更宽泛、答案不唯一的问题。

“技术发展正在突破更多边界，让它可以更好地和我们互动，更好地理解我们。”IBM的达瑞欧在CNN节目《第一步》中说。

AI怎么辩论？大致分几步：先判断观点。操作者输入观点后，系统通过语义理解自动判定正反方。其次筛选资料，在IBM构建的数据库中找出能支撑该观点的论据并评估说服力。

除了文献知识，系统还存储观点在社会中的反响数据，包括专家发言、民调、辩论赛数据等，可反映说服力。正因如此，它几秒内就能从海量答案中挑出最有说服力的，并快速发现哪种方式更有效说服人类。

锁定最强论点后，匹配最合适论据，再排列组合，决定先后顺序和表达方式，形成整体逻辑。最后一步，将内容转为演讲形式，用人类语音表达。

这涉及自然语言识别、语义理解等多项技术，几年前几乎无人能及。这一步对AI很艰难，但IBM系统已做到。

该系统具备强大语义理解和语言生成能力，应用包括净化网络环境、辅助语言学习，可彻底改变人机交互。更深层的意义是，它能凭借不断提升的数据处理能力，为医生、投资人、律师、执法机关和政府部门提供客观全面、无人性偏颇、不受情绪左右的决策建议。
