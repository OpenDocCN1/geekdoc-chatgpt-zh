# 智能写作全景指南：从入门到精通

## 内容简介
本书以140个实操要点为骨架，搭配140集语音讲解视频、170余份素材与对话案例以及178页PPT课件，从提问生成、职场公文、润色修改、常用模板、实战案例五大方向切入，助力零基础读者快速成长为熟练的智能文案创作者。

全书覆盖：16种智能提问法、13种指令精炼法、11种高效提问法、7项公文排版规范、8种公文撰写思路、7种公文润色策略、9种文案改写技巧、7种文本润色手段、11类营销文案指令范例、12类办公文案指令范例、13类新媒体文案指令范例、12类教科研文案指令范例，并完整演示短篇小说创作流程与图书宣传文案创作流程。

适用人群：从事文字工作的专业人士；人工智能相关从业者；电商运营、新媒体编辑、广告策划、短视频编导、作家与艺术从业者；新晋公务员及有公文需求的政府工作人员；行政、文秘等岗位人员；文学、语言、计算机科学与技术等专业的在校学生。
