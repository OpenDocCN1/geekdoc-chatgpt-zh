**10.6 嵌套循环与跳出技巧**

**10.6.1 生活场景引入**

小乐便利店日常里，重复任务常出现层层套的情况。比如农产品区，要为排队的每位客人称重，这是外层循环，而为每位客人称量手里的每样蔬果则是内层循环。

同理，补货时按货架顺序逐个操作是外层，单个货架内逐层检查再补货是内层；验货时逐箱拆检是外层，箱内逐件核对型号与保质期是内层。

循环不必跑完全程。验货发现整箱受损污染时，可直接跳出当前箱的检查循环将整箱退回；若仅某件标签有误，则跳过该件继续检查下一件。
