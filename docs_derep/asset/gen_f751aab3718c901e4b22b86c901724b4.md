内网工具自动注册与动态调用实战拆解

很多团队在做企业内网的工具编排时都会遇到一个问题：新工具如何做到零侵入上线，又怎么在运行时安全地被调用。下面用两个可落地的示例，把注册、校验、调度、缓存和追踪的完整链路拆清楚。

先看函数级别的注册与动态调用。核心思路是先查表确认函数是否已登记，再校验入参是否符合预定义 schema，通过后再从映射表中取出真实实现执行。整个过程对异常做了分层兜底：没登记过返回登记错误，参数不合法返回校验错误，没有实现体返回实现缺失，执行期抛异常则统一捕获并返回调用错误信息。

在模拟演练里，先拿两个示例 schema 做自注册，注册完成后列出当前可用名称。随后用注入器依次发起四次调用：首次调用人事记录查询，带上员工编号，返回包含姓名、部门和状态的完整条目；第二次调开发票处理，带上发票号和金额，正常返回；第三次故意只传发票号省略金额，触发参数校验失败；第四次尝试调用一个从未注册的接口，触发未登记错误。最后的主流程记录整体耗时，方便评估执行效率。

再看面向外部工具的调度层，这里加入了缓存加速和调用链记录两个工程级能力。

外部工具被抽象为一个带随机延时的函数，模拟真实网络波动。缓存层用线程安全的字典存储结果，键通过工具名和请求数据的 SHA256 组合生成，保证相同输入只算一次。调用链追踪器同样加锁，记录工具名、请求、结果、耗时和时间戳，方便后续审计和定位。

调度器把两者整合：进来先算缓存键，命中则直接返回并提示缓存生效；未命中才真正发出去，测起止时间、写缓存、记链路，最后打印实际调用耗时。这种设计在高频重复请求场景下能显著降低尾延迟，同时保留完整的执行轨迹。

import time
import random
import threading
from queue import Queue
import hashlib
# 模拟外部工具调用函数
def external_tool_call(tool_name, request_data):
    """
    模拟调用外部工具的函数，返回处理结果。
    参数:
        tool_name: 工具名称 (str)
        request_data: 请求数据 (str)
    返回:
        result: 处理结果 (str)
    """
    # 模拟不同工具调用的延时
    delay = random.uniform(0.1, 0.3)
    time.sleep(delay)
    result = f"{tool_name} processed: {request_data}"
    return result
# 定义缓存类，用于存储函数调用结果
class ResultCache:
    def __init__(self):
        self.cache = {}
        self.lock = threading.Lock()
    def generate_key(self, tool_name, request_data):
        """
        根据工具名称和请求数据生成唯一缓存键。
        参数:
            tool_name: 工具名称 (str)
            request_data: 请求数据 (str)
        返回:
            key: 唯一字符串键
        """
        hash_input = f"{tool_name}:{request_data}"
        key = hashlib.sha256(hash_input.encode('utf-8')).hexdigest()
        return key
    def get(self, key):
        """
        根据缓存键获取缓存结果。
        参数:
            key: 缓存键 (str)
        返回:
            result: 缓存中存储的结果，如果不存在，则返回 None
        """
        with self.lock:
            return self.cache.get(key, None)
    def set(self, key, result):
        """
        将结果存入缓存。
        参数:
            key: 缓存键 (str)
            result: 要缓存的结果
        """
        with self.lock:
            self.cache[key] = result
# 定义调用链追踪器，记录工具调用路径和时间信息
class CallChainTracker:
    def __init__(self):
        self.chain = []
        self.lock = threading.Lock()
    def record_call(self, tool_name, request_data, result, exec_time):
        """
        记录一次工具调用的详细信息。
        参数:
            tool_name: 工具名称 (str)
            request_data: 请求数据 (str)
            result: 工具调用结果 (str)
            exec_time: 执行时间 (float)
        """
        record = {
            "tool": tool_name,
            "request": request_data,
            "result": result,
            "time": exec_time,
            "timestamp": time.strftime("%Y-%m-%d %H:%M:%S", time.localtime())
        }
        with self.lock:
            self.chain.append(record)
    def get_chain(self):
        """
        返回完整的调用链记录。
        """
        with self.lock:
            return self.chain.copy()
# 定义工具调用调度器，整合工具调用链追踪与结果缓存优化机制
class ToolCallDispatcher:
    def __init__(self):
        self.cache = ResultCache()
        self.tracker = CallChainTracker()
    def call_tool(self, tool_name, request_data):
        """
        调度工具调用。首先检查缓存，如果存在，则直接返回缓存结果，
        否则调用外部工具并记录调用链信息。
        参数：
            tool_name: 工具名称 (str)
            request_data: 请求数据 (str)
        返回：
            result: 工具调用结果 (str)
        """
        key = self.cache.generate_key(tool_name, request_data)
        cached_result = self.cache.get(key)
        if cached_result is not None:
            print(f"[Cache Hit] {tool_name} with request: {request_data}")
            return cached_result
        # 未命中缓存，执行调用
        start = time.time()
        result = external_tool_call(tool_name, request_data)
        exec_time = time.time() - start
        # 存入缓存
        self.cache.set(key, result)
        # 记录调用链
        self.tracker.record_call(tool_name, request_data, result, exec_time)
        print(f"[Call] {tool_name} processed request: {request_data} in {exec_time:.4f} seconds")
