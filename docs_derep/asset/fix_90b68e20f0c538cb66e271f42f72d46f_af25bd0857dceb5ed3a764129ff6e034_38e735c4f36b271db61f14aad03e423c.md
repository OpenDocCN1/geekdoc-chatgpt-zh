### DeepSeek-R1 输出控制与工程实践

#### 参数与输出控制要点
- max_tokens 仅限制 content 的长度上限。默认值 4096 token，约合三千字中文，上限可扩至 8192 token。
- 该上限不计入 reasoning_content。复杂任务里推理部分可扩展到 32K token，因而整体返回体量可能远超 max_tokens。后续计划推出 reasoning_effort 用于调节推理深度与规模。

##### 2. reasoning_content 字段说明
- DeepSeek-R1 除标准答案 content 外，还会输出与 content 同级的推理字段 reasoning_content。
- 该字段以自然语言呈现推导中间步骤，展示结论形成过程，适合教学演示、分析任务与模型评测。

##### 3. 功能范围
- 目前开放标准对话补全，以及 Beta 版的对话前缀续写，前者用于常规问答，后者便于在已有片段上续写完整对话。
- Function Calling、结构化 JSON 输出、FIM 补全 Beta 暂未提供，相关字段传入亦无效。

##### 4. 无效参数
调用 deepseek-reasoner 时，temperature、top_p、presence_penalty、frequency_penalty、logprobs、top_logprobs 会被静默丢弃。为兼容 OpenAI 接口，设置不会报错。
