在线 Agent 开发概览

当前市面上多数在线搭建平台都提供图形化操作，无需深入底层原理或手写代码即可快速成型，门槛大幅降低。平台覆盖聊天机器人、虚拟助理、自动化流程执行等多种形态，内置丰富的预训练模型和算法集合可灵活挑选并做定制，同时自带一键投放能力，可把成品推送到不同终端与场景，并提供监控与管理功能，实时查看运行状态、性能指标并做优化，明显提升交付效率与质量。

以字节跳动的扣子为例，可零代码或低代码迅速拼装基于大模型的各类 AI 项目，满足个性化需求并产生商业价值。

本节以扣子为样本，说明如何在在线平台搭建单 Agent、工作流与 AI 应用。选择扣子的理由有四点。

其一，工作流设计灵活。能够处理逻辑复杂且稳定性要求高的任务流，提供大量可组合的节点，涵盖大模型、自定义代码、判断逻辑等，拖拽即可完成搭建。例如可做一个撰写行业研究报告的流程。

其二，能力可无限扩展。内置丰富插件工具，大幅拓宽 Agent 边界。官方提供多款现成插件，也支持基于已有 API 快速配置自定义插件并发布到商店共享。

其三，数据源多样。提供简易的知识库来收纳与管理数据，支持 Agent 与用户数据交互。无论是海量本地文件还是网站实时信息，都能汇入知识库供检索作答。

其四，记忆能力强。提供数据库记忆，可长期保存对话中的关键参数或内容。例如记录阅读笔记的书名、进度、个人批注，Agent 即可查询数据库给出更精准回复。

### 5.1.1　扣子的 Agent 开发关键能力

扣子借助大模型简化了搭建流程，在发挥模型优势的同时，支持通过知识库、工作流等手段校准响应，确保输出符合预期。

#### 1．编排能力
平台提供多个大模型与多种调节项，覆盖不同复杂度的任务。

提示词编辑。提示词决定模型表现与生成时的上下文参考。可描述 Agent 的角色、不可回答的内容、输出格式等，获得更准确的回复。平台亦可借助 AI 自动润色提示词，使输出更结构化。

模型设置。提供多款模型，支持按业务场景调节参数如温度等，直至对话效果达标。

编排模式。默认单体模式，一台 Agent 独立完成全部任务。若需更复杂功能，可切换多体模式，为不同 Agent 配置不同提示词，将复杂任务拆分为若干简单子任务。

#### 2．搭建功能
可用知识、插件等解决幻觉与专业知识不足的问题，同时提供记忆功能，使 Agent 基于历史对话产生更准确回复。

技能。技能是 Agent 的基础能力，可通过插件、工作流、触发器等拓展模型边界。

### 5.1.3　使用扣子搭建智能体工作流

工作流是一组可执行指令的集合，用于实现业务逻辑或完成特定任务。它为应用/Agent 的数据流动与任务处理提供结构化框架。核心在于把大模型的强大能力与特定业务逻辑结合，通过系统化流程实现高效 AI 应用开发。

扣子提供可视化画布，支持拖拽节点快速搭建，并在画布中实时调试，可清晰看到数据流转与执行顺序。

#### 1．工作流与对话流
扣子提供两种类型。

工作流 workflow：用于处理功能类请求，通过顺序执行一系列任务实现某个功能。适用于数据自动化处理场景，例如生成行业调研报告、生成海报、制作绘本等。

对话流 chatflow：面向对话场景的特殊工作流，更适合处理对话类请求。通过对话与用户交互实现复杂业务逻辑，适用于聊天机器人、个人助手、智能客服、虚拟伴侣等。

#### 2．节点
工作流的核心是节点，每个节点都是具备特定功能的独立组件，代表一个步骤或逻辑，负责处理数据、执行任务、运行算法，并拥有输入输出。

每个工作流默认包含开始节点与结束节点。开始节点定义启动所需的输入参数，结束节点返回运行结果。通过引用节点输出可将节点串联成链路。例如代码节点的输入可引用大模型节点的输出，两节点在画布中相连，如图 5-5 所示。

#### 3．创建工作流
无论在 Agent 或应用中使用工作流，都需先创建可运行的工作流。

第一步：创建工作流。
登录扣子开发平台，在左侧导航顶部选择或创建目标工作空间；点“资源库”，在资源库页右上角点“+资源”并选择“工作流”；在弹框中设置名称与描述后确认。名称与描述清晰有助于大模型理解功能。创建后自动进入编辑页，初始包含开始节点与结束节点。

第二步：编排工作流。
在画布中添加节点并按执行顺序连接。平台内置多种基础节点，也可添加插件节点执行特定任务。若在插件商店收藏过插件，添加节点面板会自动展示收藏内容，便于直接调用，如图 5-6 所示。

### 5.1.4　使用扣子开发 AI 应用

AI 应用是指利用大模型技术开发的应用，可执行复杂任务、分析数据并做决策。AI 搜索、AI 翻译等都属于此类。

#### 1．用扣子开发的 AI 应用能做什么
基于扣子开发的 AI 应用具备可扩展性，支持与个性化用户界面绑定，依托大模型形成独立解决方案。

通过工作流或对话流实现复杂业务逻辑，内置丰富节点库提供逻辑处理、知识写入与检索、大模型服务、会话管理等功能，可灵活编排自动化流程、构建各类 AI 应用服务。

应用可适配移动端与网页端框架，兼容多种终端。能以 API 服务或 Chat SDK 形式嵌入现有应用或网站，也可发布为微信小程序、抖音小程序，或发布到社交平台，甚至部署为 Web 页面，供更广泛用户访问。

#### 2．开发流程
扣子提供高效快捷的复杂交互 AI 应用开发方式，流程如下。

创建 AI 应用项目。在扣子新建项目，完成后自动进入“扣子应用 IDE”，是业务逻辑编排与配置的核心场所。

编排业务逻辑。可用工作流编排业务逻辑，并通过变量、插件、知识库、数据库等与本地或线上数据交互。平台提供试运行功能，便于开发时调试。

设计用户界面。提供丰富组件与可视化编排界面，支持拖拽快速构建，所见即所得。组件可绑定数据与事件，实现前后端联动，非专业开发者也能上手。

测试应用。提供预览功能，可实时测试运行效果。

发布应用。开发测试完成后可发布到各平台，让更多用户使用。

#### 3．开发环境
扣子提供线上集成开发环境“扣子应用 IDE”。支持可视化编排与调试，让开发者聚焦创意与业务逻辑。

“扣子应用 IDE”由“业务逻辑”模块与“用户界面”模块组成。

“业务逻辑”模块用于业务逻辑开发，包含资源列表与配置区域两部分，如图 5-9 所示。

资源列表。包含工作流、插件、数据等。开发者可使用项目所属空间内已有资源，也可新建。

配置区域。对创建或添加的资源进行配置与调试，支持左右分屏展示。
