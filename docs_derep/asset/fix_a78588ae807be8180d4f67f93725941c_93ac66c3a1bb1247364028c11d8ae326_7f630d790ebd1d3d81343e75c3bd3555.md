RAG 问答调优：让检索与生成协同工作

生成侧的微调主要落在 `generate_optimized_answer` 之中。核心是联动调整 `top_p` 与 `repetition_penalty`。`top_p` 采用核采样的方式收窄概率区间，引导模型优先使用高置信度的词，减少跑题。`repetition_penalty` 设为 1.1，可有效抑制重复表述，使生成更流畅自然。

检索侧的增强体现在 `retrieve_optimized_context`。将 `top_k` 调到 2，放弃只取一条命中的做法，而是召回数条相关片段后拼接成一段输入。这样一次查询能带入更宽的语义背景，覆盖更充分，也避免单条证据导致回答偏颇。

上述两个优化由 `qa_optimized_system` 串联。先由检索模块提供富集上下文，再交由生成模块产出最终文本。检索更准、生成更稳，整体问答在贴题度和连贯性上明显提升，跑题与啰嗦的情况大幅降低。

运行示例：

>> 用户查询: 糖尿病患者如何管理饮食?
>>
>> 检索到的相关上下文: 糖尿病是一种慢性疾病，需要长期控制血糖。高血压患者应注意饮食，避免摄入过多盐分。

本节演示了通过调参与检索策略改进来提升 RAG 问答准确性的方法。生成参数的调整在保持连贯的同时让内容更丰富；检索优化则提供更完整的上下文支撑，保证信息完整与答案可信。经过优化的问答链路在 RAG 体系里能实现高效精准的响应，给用户更好的体验。

### 4.2 基于公开预训练模型搭建简易问答

在 RAG 架构中，生成模块负责把检索到的上下文转写为自然语言回答。本节介绍如何借助公开的预训练生成模型，例如 GPT-3 或 T5，搭建一个基础问答系统，将检索与生成串联，使系统能针对查询给出流畅准确的回复。

下面将具体说明模型加载与配置、如何把检索结果喂入生成器、如何控制回答风格与长度，以及如何提升生成的一致性与准确度。掌握这套流程后，读者即可基于向量检索的输出生成符合业务需求的问答内容，为构建实用 RAG 系统打下基础。

#### 4.2.1 模型选择与加载实操

生成模块的核心是把外部上下文转化为连贯回答，模型选择直接决定上限。GPT、T5 等模型在理解与生成上表现成熟，可适配不同任务。本节以一段完整代码为例，演示用 Hugging Face Transformers 加载 GPT-2 并进行简单生成，读者可在平台上按需替换为其他模型，如图4-2所示。

【例4-4】加载预训练生成模型。

```python

# 导入必要的库

from transformers import AutoTokenizer, AutoModelForCausalLM, pipeline

import torch

# Step 1: 选择生成模型

# 选择合适的生成模型，GPT-2在文本生成方面较为成熟且易于使用

model_name="gpt2"  # 可替换为更大的模型，如"gpt2-large" 或 "gpt-neo"

tokenizer=AutoTokenizer.from_pretrained(model_name)

model=AutoModelForCausalLM.from_pretrained(model_name)

print("生成模型加载完成:", model_name)

# Step 2: 检查设备配置

# 将模型加载到GPU（如果可用）以提升生成速度

device="cuda" if torch.cuda.is_available() else "cpu"

model.to(device)

print("模型已加载至:", device)

# Step 3: 定义文本生成函数

# 为方便使用，定义生成函数，将查询和上下文输入至模型生成回答

def generate_answer(prompt, max_length=50, temperature=0.7, top_k=50):

    """

    使用生成模型生成回答，基于输入的提示和生成参数

    参数:

    -prompt: 文本提示

    -max_length: 最大生成长度

    -temperature: 控制生成的多样性，值越高，生成越随机

    -top_k: 限制最高概率的词汇选择范围，以控制生成质量

    """

    # 对输入提示进行编码，限制最大生成长度

    input_ids=tokenizer.encode(prompt, return_tensors="pt").to(device)

    # 使用生成模型生成输出

    output=model.generate(

        input_ids,

        max_length=max_length,

        temperature=temperature,

        top_k=top_k,

        do_sample=True

    )

    # 解码生成的token，返回生成的文本

    answer=tokenizer.decode(output[0], skip_special_tokens=True)

    return answer

# Step 4: 测试生成功能

# 定义一个测试查询和上下文

context="糖尿病是一种慢性疾病，需要长期控制血糖。"

query="糖尿病患者如何管理饮食？"

# 结合上下文生成提示，输入至生成模型

prompt=f"{context} 问题：{query} 回答："

answer=generate_answer(prompt)

print("\n生成的回答：")

print(answer)

# Step 5: 优化生成结果

# 使用pipeline简化生成过程，也可指定多个生成参数来优化回答

generator=pipeline("text-generation", model=model, tokenizer=tokenizer, device=0 if device=="cuda" else -1)

custom_answer=generator(prompt, max_length=60, temperature=0.6, top_k=50,

num_return_sequences=1)[0]['generated_text']

print("\n优化后的回答：")

print(custom_answer)
```
