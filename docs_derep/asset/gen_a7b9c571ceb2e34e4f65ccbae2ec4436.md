# 结构化调教：用好问题换来精准答案

AI 即便功能强大，也必须在结构化思维的引导下才能发挥水平，模型能走多远，很大程度上取决于提问的思路。以 ChatGPT 这类自然语言模型为例，其本质仍是数学模型，可把它视作一个理工科的天才少年去沟通、训练。掌握结构化调教逻辑，就能吃到红利。

一迅最常用的是营销大师 Simon Sinek 的黄金圈：what、how、why。ChatGPT 的母语是英语，实际操作时可以把顺序微调为 why、what、how，先点明目的再给材料最后细化任务，入口清晰、一语中的，用三言两语拿到想要的答案。

比如让 AI 基于已有文章找答案再生成新文章的场景，一迅的提问框架是：

# 第四篇 交付篇——AI 助力交付，提速增质铸就传奇

WHY——开门见山讲需求：I want you to help me generate a new passage like this.(我想让你生成一篇这样的文章)

WHAT——给出样本指路：Here comes the passage.(这篇文章是这样的)

HOW——任务细化到可执行：

+   ( 1 ) Get the answers to the questions first.(先解出答案)
+   ( 2 ) Generate a different passage on a new topic with the same answers.(用相同答案写一篇新主题文章)

照此结构提问，回复的准确度会明显提升。若想升级，还可补充 who 和 where。who 指身份设定，可定义 AI 角色或说明提问者身份；where 指使用场景或用途。

加入这两个要素后可以如此表达：You're a teacher. Can you provide another passage with the same answers so that students can get more practice?(你是一位老师，能否用相同答案写一篇新文章，让学生多做练习？)

实操中一迅总结了几点小技巧：

a. 保持连贯，上下文要有关联。提问需层层递进，若出现跳跃或串台，可修改提示词重提，或另开新对话。
b. 这类属于长提示词，即在一次输入里把指令与要求全部交代清楚。长提示词像一串葡萄，以总分结构自上而下展开，线索可逐步叠加细化。
c. 当输出令你满意时不妨给予正向反馈，比如点赞表扬。虽然模型无情绪，但这相当于强化信号，有助于它更贴合你的偏好，产出更优结果。

# 百个 80 分不如一个 98 分怎么选

训练过程中难题接踵而至，两个典型最常见。

# 难题一：绿幕很美，却不适合 99% 的新手

建模可选绿幕或实拍。绿幕看似能随意换景，一次拍摄拥有无数形象，便于搭建矩阵。但亲测后发现，对小白而言缺乏专业棚拍很难得到清晰画面与干净边缘，眼镜反光等瑕疵也难处理。即便租专业棚，网上随手可下的背景也会让创始人 IP 显得廉价。这属于 80 分的数字人。

# 难题二：声音模拟能用，但仅此而已

内测的声音模拟本是期待点，若能用文本直接生成带情感朗读的视频，可大幅解放时间。实际听感却很怪，不像本人的声音，更像是抖音常见 AI 音频加上一点音色模仿。用作解说或生活妙招尚可，但对立体 IP 来说，语气、停顿、即兴表达尚未到位，机械感明显，粉丝易识破，对品牌有负面影响。

"一个 98 分的数字人，远胜过 100 个 80 分的数字人。" 最终选择实景拍摄训练数字人配合人工录音驱动生成视频的路线，得到接近 98 分的效果。

这里说明，不选绿幕和声音模拟只是因其不符合内容要求与人设，不代表不适合他人。如面向出海用声音模拟将脚本译成外语、保留音色，效果反而更标准。技术在快速迭代，保持开放学习心态即可不断升级。
