## 4.4 ChatGPT 智能聊天机器人：订阅变现

在人工智能发展历程里，OpenAI 推出的 ChatGPT 堪称里程碑。它不只是一个对话工具，更聚合了海量知识、理解与创造力的智能助手。

其背后是 OpenAI 的 GPT 架构，通过大规模文本预训练得到的深度学习模型。与传统机器人不同，ChatGPT 不依赖固定规则或模板，而是根据输入即时生成回复，交互因此更自然流畅。

各大社区经常出现关于如何使用 ChatGPT 的提问。有需求就有商机，如果能自建 ChatGPT 服务器、发放访问权限并收取订阅费用，就能形成不错的收入来源。

下面从服务器搭建的角度介绍一种实现方式。该方法不需要账号授权，也不需要调用官方 API，是上手最轻松的路径。

### 4.4.1 准备工作

需要提前注册 Discord 账号、GitHub 账号和华为云账号。

Discord 是面向社群的免费网络实时通讯与数字发行平台，游戏玩家、教育和商业用户都能通过频道进行消息、图片、视频和音频交流。

GitHub 则是开源代码托管服务平台，大量开源项目都基于它部署。

华为云是购买域名的入口，浏览器搜索名称即可进入官网。

Discord 注册完成后，加入奇美拉聊天群组。进入群组后先在左侧频道列表找到 #verify 完成简单的验证码验证。

验证通过后在左侧找到 #bot，在下方输入框里发送 /key get 即可获取一个 API Key，记得保存下来。若 Key 丢失或泄露，可返回该频道发送 /key regen 重新生成。这一环节只是为了获取免费 API Key，若已有自己的 ChatGPT 账号则可直接使用自己的 Key，跳过此步。

下一步在搜索引擎输入“华为云域名”进入官网。注册华为云账号后，可按需申请一个域名（图 4-5）：

[PRE11]

华为云申请域名第一年费用很低，后面的灰色数字为续费价格。建议申请“.cn”域名，价格比“.com”更友好，且审核速度更快。

购买完成后按提示创建域名。域名审核分两阶段，先审核身份资料，通过后再进行域名提交审核。审核时长一般在数小时到一两天不等，通过后即可使用。

准备工作就绪，进入实操。

### 4.4.3 服务器设置

进入控制台后点右上角的 “Domains”，进入域名管理（图 4-9）。

在输入框填写访问域名，采用二级域名形式，例如“mygpt.easytousegpt9981.cn”，其中“mygpt”为二级域名，“easytousegpt9981.cn” 为在华为云申请的一级域名。填写完成后点右侧添加，域名会出现在下方列表（图 4-10）。

接下来按指引添加 DNS 记录。点击框体右侧的复制按钮，然后切换到华为云管理后台。

打开左上角服务列表，在搜索栏输入“dns”，选择“云解析服务 DNS”（图 4-11）。

进入后点域名右侧的“管理解析”（图 4-12）。

在管理解析页面点“修改记录集”，按图 4-13 的方式依次填写：主机记录填之前设置的二级域名，类型选 CNAME，值填刚才复制的地址，确认添加。

此时域名即可登录。但要实现与 ChatGPT 的问答，还需完成环境变量配置。

回到 GitHub 项目管理界面（图 4-14），进入 “Environment Variables”，依次填入：

Key: OPENAI_API_HOST。

Value: https://chimeragpt.adventblocks.cc/api。

点 “Add another” 继续添加：

Key: OPENAI_API_KEY。

Value: 填写 Discord 获取的 Key。

全部完成后点右侧 “Save” 保存。

保存后点左上角的 “Deployments”，进入后点项目右侧的三个点，选择 “Redeploy” 重新部署，使修改生效（图 4-15）。

部署完成后，用域名登录即可访问 ChatGPT（图 4-16）。

服务器搭建成功后，为他人提供 ChatGPT 服务不再遥远。可以把工具分享给有需要的人，并从中获得一定经济回报，听起来很有吸引力。

这里提供的是一个简明可用的部署指引，所用 API 完全免费。实际操作中可能会遇到各种问题，建议在部署过程中结合实际情况对步骤做适当优化和调整，以提供更稳定流畅的体验。

随着人工智能深入日常生活，自建聊天服务器既能为他人提供便利，也能带来额外收入，既满足需求又创造价值，何乐而不为？
