## 扩散模型：直觉解释与数学推导

从直觉看，分数方向指向似然更高、噪声更少的区域，剔除加在原始数据上的扰动即可恢复样本并提升对数似然。根据 Tweedie 公式，若 y = x + σ ε，则 E(x|y)= y + σ² ∇_y log p(y)。该公式说明分数完整编码了原始数据的最小二乘估计信息。对含噪观测 y 再加 σ² ∇_y log p(y)，噪声在一定程度上被消除，这体现了分数与去噪的关联：沿着似然上升的方向移动数据即实现去噪。证明思路如下。首先，

\nabla_y p(y) = \frac{1}{\sigma^2} \int (x - y) g(y - x) p(x) dx\n= \frac{1}{\sigma^2} \int (x - y) p(y, x) dx

其中 g(·) 是标准高斯密度，p(x)、p(y)、p(x,y) 分别为 x、y、(x,y) 的密度。其次，

\sigma^2 \frac{\nabla_y p(y)}{p(y)} = \int xp(x|y) dx - \int yp(x|y) dx = \hat{x}(y) - y

又因 ∇_y log p(y) = \frac{\nabla_y p(y)}{p(y)}，代入即可得证。

在采样层面，SGM 可依序利用 s_θ(x_T,T)、s_θ(x_{T-1},T-1)…s_θ(x_1,1) 逐步构造样本。因为训练与生成解耦，涌现出多种采样策略，后续章节再展开。最先提出的策略是退火朗之万动力学 ALD [220]。设每步迭代 N 次，步长 s_t>0，先

ε^t ← N(0,I)
x_t^{i+1} ← x_t^i + \frac{1}{2} s_t s_θ(x_t^i,t) + \sqrt{s_t} ε^i

依据朗之万蒙特卡罗理论 [176]，当 s_t → 0 且 N → ∞ 时，x_0^N 会收敛到数据分布 q(x_0) 的真实样本。
