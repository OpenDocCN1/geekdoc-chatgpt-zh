# 上下文学习里的演示设计与轻量微调全拆解

在有限的示例池里，组织演示的本质就是挑对的样本、用对的顺序、配对的表达方式。

## （1）演示挑选
挑选演示回答的核心问题是哪些样本对上下文学习最有帮助。现有工作大致可以分成两类，一类依赖预设指标无需监督，一类依赖预设指标需要监督。

基于预设指标的无监督做法。文献 [183] 指出用最近邻样本作上下文很有效，距离常用句子嵌入的 L2 距离或余弦相似度。由此发展出 KATE，一种基于 kNN 的无监督检索器。距离之外，互信息也是常用的挑选标准 [195]，甚至能用来检索跨语言的 kNN 示例 [196]，帮助源语到目标语对齐，而且互信息不需要标注样本也不依赖特定 LLM。Gonen 等人 [197] 尝试挑困惑度更低的提示，Levy 等人 [198] 强调示例的多样性来提升组合泛化，而 Kim 等人 [199] 则让 LLM 自己生成示例，而不是从人工标注数据里挑选。

另一批无监督方法直接用语言模型的输出分数 $P(y|C, x)$ 来衡量质量。Wu 等人 [200] 按数据传输编码长度来排列 kNN 子集，最优排列能在给定 $x$ 和 $C$ 时压缩标签 $y$。Nguyen 和 Wong [201] 计算单个示例的影响力，即包含该示例与不包含该示例的子集平均性能的差距。Li 等人 [202] 定义信息分数为验证集中所有 $(x, y)$ 对上 $P(y|x_i, y_i, x) - P(y|x)$ 的均值，并加入多样性正则化。

基于预设指标的有监督做法。Rubin 等人 [203] 提出两阶段检索，先用无监督检索器如 BM25 召回相似候选，再用有监督检索器如 EPR 从候选中筛选。评分语言模型评估候选与输入的关联度，高分作正例低分作负例。Li 等人 [204] 用统一的示例检索器增强 EPR，实现跨任务统一选择。Ye 等人 [205] 不再逐个检索，而是检索整组示例来建模示例间的相互作用。训练的 DPP 检索器通过对比学习与语言模型输出分数对齐，再经后验最大化得到最优示例集。

从提示调整的角度，Wang 等人 [206] 把 LLM 视作主题模型，能从少量示例推断概念 $\theta$ 并以此生成 Token。任务相关的概念 Token 用来表征潜在概念，学习目标是最大化 $P(y|x, \theta)$，挑选的是按 $P(\theta|x, y)$ 最可能推断出概念变量的示例。Zhang 等人 [207] 还把示例选择建模为马尔可夫决策过程 [208]，用 Q-Learning 进行选择，动作是挑一个示例，奖励是验证集准确率。

## （2）演示排序
所选样本的先后次序同样关键。Lu 等人 [182] 证实排序敏感性在多种模型上普遍存在。早期无训练排序方法中，Liu 等人 [183] 按示例与输入的距离做适当排序。Lu 等人 [182] 提出全局和局部熵度量，发现熵度量与上下文学习性能正相关，于是直接用熵度量来确定最佳顺序。

## 2. 演示表达形式
常见的做法是把示例 $(x_1, y_1), ..., (x_k, y_k)$ 直接与模板 $T$拼接。但在数学、常识推理等需要复杂推理的任务里，仅用 $k$ 个映射学习 $x_i$ 到 $y_i$ 并不容易。除了模板工程 [154] 的研究，有人尝试在指令 $I$ 中描述任务，并在 $x_i$ 与 $y_i$ 之间加入中间推理步骤来设计更利于学习的格式。

### （1）指令表达
除了精心挑选的示例，清晰描述任务的指令对推理也很重要。与示例普遍存在于传统数据集中不同，任务指令多靠人工撰写。Honovich 等人 [209] 发现给定几个示例后 LLM 能自行生成任务指令。受生成能力启发，Zhou 等人 [210] 提出自动提示工程师，用于自动生成和挑选指令。Wang 等人 [38] 进一步用 LLM 从自身生成中提炼出初始指令示范。自动生成指令的效果不错，也为人工反馈与自动指令结合打开了空间。

### （2）推理步骤表达
Wei 等人 [83] 在输入输出之间插入中间推理步骤构建示例，即思维链。有了思维链，LLM 能逐步预测推理过程并给出最终答案。思维链提示研究涵盖提示设计和流程优化等 [211]。

与示例选择类似，思维链也需要挑选。不同于 [83] 的手工编写，AutoCoT [82] 用“让我们一步一步来思考”自动生成思维链。Fu 等人 [212] 提出基于复杂度的示例选择，挑选推理步骤更多的示例来做思维链提示。

当输入输出映射被拆解为逐步推理时，多阶段上下文学习被用于思维链提示，每个步骤使用不同的示例去查询 LLM。Self-Ask [213] 让 LLM 为输入生成后续问题并自问自答，问题与中间答案被加入链条。iCAP [214] 设计了上下文感知提示器，能动态调整各推理步骤的上下文。从少到多提示 [215] 是包含问题缩减与子问题解决的两阶段方法，第一阶段把复杂问题拆成子问题，第二阶段 LLM 逐个作答并把已回答的问题与答案累积到上下文中。

Xu 等人 [216] 在特定任务上微调小型 LLM 作为插件生成伪推理步骤。给定输入输出对 $(x_i, y_i)$，SuperICL 把小型 LLM 对 $x_i$ 的预测 $y'_i$ 与置信度 $c_i$ 当作推理步骤，通过串联 $(x_i, y'_i, c_i, y_i)$ 形成思维链。

## 3. 核心要点回顾
- 演示选择能提升上下文学习效果，但多数方法停留在实例层面。少样本评估下，数据库级别的选择更关键却研究不足。
- LLM 的输出分数或概率分布在实例选择中发挥重要作用。
- $k$ 个演示的排列空间是 $k!$，如何高效找到最优顺序或逼近最优排序仍是挑战。
- 思维链能把复杂推理拆解为中间步骤，多阶段演示设计有助于更好生成思维链，提升思维链提示能力值得继续探索。
- 除了人工编写，LLM 的生成能力可用于演示设计，可生成指令、演示、探测集、思维链等，降低人工模板成本。

### 2.6.4 评分机制
评分函数负责把语言模型预测转化为特定答案的可能性估计。直接估计法使用候选答案的条件概率，候选答案可用词汇表标记表示 [14]，选概率最高的作最终答案。此法对模板有要求，答案标记通常需放在序列末尾。

困惑度是另一常用指标。整体序列 $S_j = \{C, s(x, y_j, I)\}$ 的句子困惑度由演示 $C$、查询 $x$ 与候选标签 $y_j$ 的标记组成。因困惑度评估整句概率，可摆脱标记位置限制，但计算开销更大。生成任务如机器翻译中，上下文学习通过解码句子概率最高的标记预测答案，常配合波束搜索或 Top-p、Top-k [217] 等多样化策略。

Min 等人 [218] 提出用通道模型反向计算条件概率，即估计给定标签下输入查询的可能性。该方式需 LLM 生成输入各标记，在数据不平衡时更稳健。鉴于上下文学习对示例敏感，用空白输入减去模型先验来归一化分数，可提升稳定性与整体表现 [194]。

另一方向是校准超出上下文长度限制的信息。Structured Prompting [219] 用特殊位置嵌入单独编码示例，再通过重标注意力机制提供给测试示例。kNN Prompting [220] 先用训练数据查询 LLM 得到分布式表示，再以封闭表示的最近邻锚点预测测试实例。

直接用候选答案条件概率高效但仍受模板限制，困惑度简单通用。现有评分函数都基于 LLM 条件概率计算。校准偏差或减轻敏感性的研究仍有限，比如在模型预测中加入额外校准参数来调整结果 [194]。

## 2.7 模型微调
大模型在通用文本上训练后，对特定任务或领域知识可能不足。此时在更小、更专业的集上微调可提升领域内表现。主流做法分为适配器微调与任务导向微调。

### 适配器微调
如图 2.11(a) 所示，用神经适配器或模块化组件增强 LLM 在特定领域任务上的表现，而不对内部参数做大幅改动。适配器集成到现有结构中，支持特定任务学习同时保持原模型基本完整。

### 任务导向微调
如图 2.11(b) 所示，重点是修改 LLM 内部参数以对齐特定任务。但受硬件与性能下降限制，全面更新所有参数不现实，研究难点在于确定应改动的子集及高效更新方式。

两种方式都能让 LLM 按任务或领域定制化。

### 2.7.1 适配器微调策略
微调常用在三类场景：提升特定任务性能如开放世界目标检测、增强特定能力如视觉定位、指令微调以解决下游视觉任务如 InstructBLIP [221]。即使只微调线性层，性能也能提升，可用 ImageNet 等任务数据集改进预训练模型。也有工作在定位数据上微调预训练视觉语言模型，如 Minderer 等人 [222] 在检测数据上微调视觉 Transformer 得到开放词汇目标检测器。此外可把视觉数据集转为指令微调集，使视觉语言模型适配下游任务。

适配器微调的目标是为 LLM 加入少量额外参数，通常以简单模块形式存在，引导模型适应目标领域或任务。理想模块具备三个特点：
- 参数少且结构简单。
- 能扩展到原始语言模型。
- 在不同领域连续训练时保持灵活。

大部分满足上述特点的工作属于参数高效微调范畴，并在适配器框架 [223-224] 下构建。

部分工作探索适配器在无监督领域自适应 UDA 中的用法，旨在增强跨语言或多任务学习能力。文献 [225] 首次提出多领域自适应的两步策略，先在混合库上用掩码语言模型损失做领域融合，再在领域库上用任务损失微调。随后文献 [226] 提出 UDApter，同样两步训练但拆成领域适配器与任务适配器两模块。领域适配器先学习领域不变表示，再与冻结的任务适配器连接，结构源自 AdapterFusion [227]。AdapterSoup 在测试阶段仅用领域适配器的加权平均提升效率 [228]，选择策略包括穷举组合、文本聚类和语义相似性。在 GPT-2 [225-226, 228] 上验证后认为方法可迁移到更大模型。为此提出 LLaMA-Adapter，利用自指导演示在 LLM 与适配器上实现高效自适应，适配器含零初始化注意力机制，并在指令遵循与多模态推理上测试领域自适应能力 [229]。

随着适配器应用扩大，基于结构可分为神经适配器与低秩适配器，也有大量工作构建综合适应框架 [230-231]，集成适配器在多种下游任务上表现突出。

#### （1）神经型适配器
神经网络结构的适配器即神经适配器。最初设计 [223] 使用下投影、GeLU 非线性 [232]、上投影与前馈层作为骨干。随后 [233] 简化为单层隐藏层前馈网络并验证领域适应效果。模块通常插入 Transformer 的多头注意与前馈层，被称为瓶颈适配器或串行适配器，本书提及的 [223] 即为串行适配器。

发展受 ResNet、自动编码器、注意力等启发。文献 [227] 的适配器加入额外残差连接。文献 [234] 提出 MAD-X 框架，插入可逆适配器紧邻输入并反转传至输出嵌入，在高层语义空间类似自动编码器。Tiny-attention 适配器 [235] 探索小维度注意力层适配器的有效性。多数结构用全连接层做下投影与上投影，而 Compacters [236] 用参数化超复数乘法层 [237] 替代，其形式类似全连接但学习克罗内克积之和，参数效率更高。受网络修剪启发，SparseAdapter [238] 在初始化时修剪以减少训练参数，是适用于神经适配器的通用技术。

内部适应之外还有外部适应。K-Adapter [239] 在不同知识领域单独训练多个适配器，再通过连接把知识注入语言模型。Sung 等人 [240] 关注反向传播带来的内存开销，提出阶梯侧调节，只在一侧添加小模块并用快捷连接。两者都使用 MLP，但结构保持灵活。

#### （2）低秩适配器
低秩适配 LoRA [241] 源于“LLM 存在于内在子空间 [242]”的观察，认为参数可有效更新。LoRA 在子空间嵌入可学习奇异值分解块，低秩 $r \ll d$，$d$ 为输入维度。矩阵与预训练权重并行相加，微调时冻结原权重。LoRA 大幅减少训练参数且推理不增加延迟。

后续工作 DyLora [243] 用动态搜索解决固定块大小与最优秩穷举问题。LoRA 的表示能力受限，Kronecker 适配器 KronA [244] 用两个小矩阵的 Kronecker 乘积替代奇异值分解模块。虽然低秩适配后续研究不多，LoRA 作为重要构建块被纳入多种综合框架 [230, 245-247]。

#### （3）集成适配器框架
AdapterFusion [227] 在不同任务上训练多个适配器，用融合层组合各适配器的嵌入。UniPELT [246] 通过门控机制动态激活最适合当前数据或任务的子模块组合，包括串行适配器 [223]、LoRA [241]、前缀微调 [157] 与 Bitfit [248]。对应的 AdaMix [247] 堆叠多个同一类型适配器，用随机路由训练激活以避免额外计算成本。AdaMix 虽只在串行适配器与 LoRA 上验证，但可视为通用技术。
