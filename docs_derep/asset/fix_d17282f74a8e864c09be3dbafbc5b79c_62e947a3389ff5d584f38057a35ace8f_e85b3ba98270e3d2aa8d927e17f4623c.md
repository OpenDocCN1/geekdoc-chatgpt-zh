下面回顾一下常见的机器学习范式。

### 监督学习

监督学习处理的数据自带正确答案标签。模型基于有标签样本学习特征与规律，再对无标签数据进行预测。

按标签类型的不同可分为回归 regression 与分类 classification。

### 无监督学习

无监督学习面向无标签数据，目标是挖掘其内部特征、相似性与模式。省去了标注成本，但“不尝试就不知道能得到什么”。

主要分为聚类 clustering 与降维 dimensionality reduction。

### 其他机器学习算法（强化学习等）

还有一批难以归为监督或无监督的算法，例如强化学习，它会根据行为结果给予奖励，让模型逐步向更优行为演进。

### scikit-learn 中的机器学习算法

scikit-learn 收录的算法很多，大致可归为 4 类。

● **回归 regression**：基于历史数据预测连续值。常用算法有 SGD 回归、LASSO 回归等。
● **分类 classification**：依据带标签样本对新样本进行类别判断。常用算法有核近似法、k 近邻算法等。
● **聚类 clustering**：把相似样本归为一组以发现结构。常用算法有 k 均值算法、谱聚类算法等。
● **降维 dimensionality reduction**：压缩特征维度以揭示内在结构，也可作为后续算法的输入。常用算法有主成分分析 PCA、核 PCA 等。

### 第 2 部分　回归分析

回归分析是用统计方法刻画目标变量与解释变量之间关系的技术。目标变量是待预测的结果，解释变量是影响结果的因素。

scikit-learn 采用线性回归模型。线性回归在数据上拟合一条直线，最小二乘法求解直线方程。

解释变量只有一个时称为一元回归，多个时称为多元回归，二者均被支持。下面先做一元回归。

### 一元回归分析

在 scikit-learn 中可通过 linear_model.LinearRegression 创建线性回归模型，语法格式如图 1 所示。

| `sklearn.linear_model.LinearRegression(fit_intercept=True, normalize=False,copy_X=True, n_jobs=1)` |

| --- |

| 参数 || 说明 |

| `fit_intercept` || 指定是否包含求截距的计算 |

| `normalize` || 指定是否事先将解释变量归一化 |

| `copy_X` || 为了不在内存中重写，指定是否在复制`X`轴数据后执行 |

| `n_jobs` || 指定用于计算的作业数量。如果设为−1，则使用可用的所有`CPU` |
