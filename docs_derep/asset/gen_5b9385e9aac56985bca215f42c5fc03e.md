# 游戏AI跳跃轨迹解析：从二分查找到物理验证的完整实现

在游戏开发中，让AI角色精准完成跳跃动作是个硬骨头。这不仅要求算出合适的抛射角度，还得保证落点精准、速度达标。今天我们拆解一套核心逻辑：如何用二分法锁定发射角，再通过物理公式校验跳跃可行性。

## 核心流程：角度搜索与边界收敛

首先看角度确定环节。系统维护上下边界（`minBound`/`maxBound`），采用二分策略快速逼近最优解：

```csharp
direction, distance = checkAngle(maxBound)

if -margin < distance < margin:
    return direction

# 检查最长距离射击能否触达目标
if distance < 0:
    return null

# 二分搜索主循环
distance = infinity
while abs(distance) >= margin:
    angle = (maxBound - minBound) / 2
    direction, distance = checkAngle(angle)

    # 动态收缩搜索区间
    if distance < 0:
        minBound = angle
    else:
        maxBound = angle

return direction
```

**关键点解读**：
- `checkAngle` 返回的 `distance` 正负性直接指导边界更新：负值代表力度不足（需增大角度），正值则相反
- 循环终止条件 `abs(distance) < margin` 保证工程精度，避免无限迭代
- 若最大边界测试仍显距离为负，直接判定不可达，剪枝提效

## 方向向量构建：水平面投影与垂直分量合成

确定角度后，需转化为三维方向向量。`convertToDirection` 函数完成这步几何变换：

[PRE0]csharp

function convertToDirection(deltaPosition: Vector, angle: float):

    # 找到平面方向

    direction = deltaPosition

    direction.y = 0

    direction.normalize()

    # 添加到垂直分量中

    direction *= cos(angle)

    direction.y = sin(angle)

    return direction

[PRE1]

逻辑拆解：
1. **水平投影**：抹去目标位移的 Y 分量并归一化，得到纯水平朝向
2. **速度分解**：水平速度缩放为 `cos(angle)`，垂直速度赋值 `sin(angle)`，隐含单位初速度假设
3. **向量合成**：最终方向向量同时编码水平朝向与抛射仰角

## 跳跃行为类：状态机驱动的执行逻辑

`Jump` 类继承 `VelocityMatch`，引入跳跃点数据与可达性标记，形成"规划-校验-执行"闭环：

```csharp
class Jump extends VelocityMatch:
    jumpPoint: JumpPoint
    canAchieve: bool = false
    maxSpeed: float
    maxTakeoffYSpeed: float

    function getSteering() -> SteeringOutput:
        if not target: calculateTarget()
        if not canAchieve: return null

        # 到达起跳点触发跳跃
        if character.position.near(target.position) and
           character.velocity.near(target.velocity):
            scheduleJumpAction()
            return null

        # 未到达则委托基类修正速度
        return VelocityMatch.getSteering()
```

**执行策略**：
- 惰性初始化：首次调用才触发 `calculateTarget()`
- 双重守卫：不可达直接返回空，到达起跳点即切换动画/物理状态
- 复用基类：飞行阶段前的移动修正完全复用 `VelocityMatch` 能力

## 轨迹求解器：抛体物理与速度约束的博弈

`calculateTarget()` 是数学核心，利用抛体运动方程反解可行参数：

```csharp
function calculateTarget():
    target = new Kinematic()
    target.position = jumpPoint.takeoffLocation
    jumpVector = jumpPoint.landingLocation - jumpPoint.takeoffLocation

    # 方程：y = v0y*t + 0.5*g*t^2  求解 t
    sqrtTerm = sqrt(2 * gravity.y * jumpVector.y + maxTakeoffYSpeed^2)
    time = (maxTakeoffYSpeed - sqrtTerm) / gravity.y  # 较小根：低弹道
    checkCanAchieveJumpTime(jumpVector, time)

    if not canAchieve:
        time = (maxTakeoffYSpeed + sqrtTerm) / gravity.y  # 较大根：高弹道
        checkCanAchieveJumpTime(jumpVector, time)
```

**物理建模细节**：
- 竖直位移公式推导出一元二次方程，`sqrtTerm` 为判别式开方项
- 优先尝试**低弹道**（较小时间根），失败再试**高弹道**，符合自然运动偏好
- 重力 `gravity.y` 为负值，分母特征决定时间正根个数

## 可达性校验：水平速度上限的硬性约束

`checkJumpTime` 将时间转化为水平速度需求，与 `maxSpeed` 对标：

```csharp
function checkJumpTime(jumpVector: Vector, time: float):
    vx = jumpVector.x / time
    vz = jumpVector.z / time
    speedSq = vx * vx + vz * vz

    if speedSq < maxSpeed * maxSpeed:
        target.velocity.x = vx
        target.velocity.z = vz
        canAchieve = true
```

**判定逻辑**：
- 水平位移除以飞行时间得必要水平速度分量
- 平方和比较避免开根号开销，直接用平方阈值判断
- 通过即写入目标速度并置位标记，供 `getSteering` 使用
