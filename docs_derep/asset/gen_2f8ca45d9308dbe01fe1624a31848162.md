## 6.2 个人知识库背后的技术原理

为理解 6.1 节的操作及后续示例，需先了解一些基础概念，包括向量数据、数据向量化、RAG 技术等。

### 6.2.1 数据向量化

日常使用的结构化数据通常按预设结构组织，具有明确字段与记录，类似关系数据库表，常用表格存储。

向量是数学中的有序数值序列，可表示为一维数组。向量数据以向量形式表达，能够方便地表示图像、音频、视频等非结构化数据的特征与语义，具有表达简洁、表示统一、便于分析与可视化等优点，在数据科学与机器学习中成为基本形式。

数据向量化就是把数据转为算法可处理的向量形式。

个人知识库可整合多种数据源，Cherry Studio 为实现数据向量化提供了便利，支持多种格式与内容的向量化。

- 可直接将本地文件拖入知识库，自动完成向量化。
- 可整文件夹导入，系统会处理支持格式如 PDF、DOCX、TXT、MD 等文件并向量化。
- 可添加特定网页 URL，抓取内容后向量化。
- 可添加站点地图，批量抓取页面内容向量化。
- 也可在 Cherry Studio 中直接输入自定义文本作为知识库内容进行向量化。

在 Cherry Studio 中，数据向量化流程如下。

1. 文本提取：从文件或网页提取文本。
2. 预处理：分词、清洗等。
3. 嵌入模型处理：使用嵌入模型如 BGE-M3 将文本转为向量。
4. 存储向量：将向量保存到知识库中供后续检索与问答。

### 6.2.2 RAG技术

检索增强生成 Retrieval-Augmented Generation 是一种提升大模型回答质量与准确性的技术，可让模型在回答时参考外部知识库。核心流程如下。

1. 检索：用户提问后，嵌入模型先将问题向量化，再在知识库向量库中检索最相关的信息。
2. 增强：将检索结果作为上下文输入，提升模型对问题的理解。
3. 生成：把检索信息与原始问题结合作为新提示词输入大模型，生成最终答案。

RAG 通过检索-增强-生成流程融合信息检索与内容生成，有效减少幻觉，提升知识密集型任务表现。

### 6.2.3 在Cherry Studio中为RAG做数据准备

在 Cherry Studio 中构建知识库并实施 RAG 的具体步骤如下。

1. 构建知识库：新建知识库并选择嵌入模型如 BGE-M3。
2. 添加文件并向量化：将文档、文件夹、网址或纯文本加入知识库，系统自动向量化。
3. 检索与生成：在对话中引用知识库时，Cherry Studio 会通过向量检索找到相关片段。
