**云上运行需要哪些前提**
简单来说，云部署就是在云厂商租一台远程主机，把 OpenClaw 装上去。并不需要精通运维，但下面几个基础条件要先准备好：

● 系统环境：优先 Ubuntu 22.04 或 24.04，其次 CentOS 7 以上，全部使用 64 位
● 起步硬件：2 核 CPU、2~4GB 内存、40GB 磁盘可入门；想更流畅建议 4 核、8GB 内存起步，条件允许可加 GPU
● 网络端口：OpenClaw 默认监听 18789，买好机器后记得在控制台防火墙/安全组里放行，否则 Web UI 无法打开
● 费用：主流厂商的入门规格月租不高，多家有新用户优惠或免费试用

**部署流程：通用五步模板**
不管选哪家厂商，整体思路基本一致：

第一步：购买云主机。到官网注册账号，选择轻量应用服务器，入门规格即可，完成实名认证与支付。
第二步：装镜像。很多厂商已提供 OpenClaw 预装镜像或应用模板，直接一键安装最省事。若没有，选 Ubuntu 22.04 后按 2.4 节 Linux 安装步骤操作。
第三步：远程登录。用 SSH 工具连上，例如 Termius 或 FinalShell，填入公网 IP、用户名和密码即可。多数厂商也提供网页版终端，直接在浏览器操作。
第四步：配置模型。流程和本地一致，执行 openclaw onboard 选择 AI 模型并填入 API Key，详见 2.2 节。
第五步：验证。打开浏览器访问 http://你的服务器IP:18789，发一条消息，若龙虾能回复即部署成功。

**云上安全底线**
数据放到云端后安全配置不能马虎，部署完成后务必自检：

（1）设置强登录密码，避免 123456 这类弱口令。SSH 密钥登录比密码更安全，有条件优先用密钥。
（2）端口最小化，只开放 18789 和 22，其余全部关闭，减少攻击面。
（3）定期备份，建议每周一次。配置文件和记忆文件一旦丢失很难恢复。
（4）选择正规大厂。小众或海外不明服务商的稳定性和数据安全难以保障。
（5）避免存放高敏信息。不要上传银行卡密码、身份证照片等，OpenClaw 对话会经过模型商服务器，信息边界要清楚。

**常见问题**
**问题 1：云端部署安全吗？**
数据存放在你自己购买的服务器上，仅你可访问。但自有服务器不等于绝对安全，仍需做好上述配置。停用时可直接删除整台机器，数据会彻底清除。

**问题 2：会一直扣费吗？**
多数厂商支持按月或按量计费，机器删除后费用即停止。建议先买一个月试用，满意再续费。

**问题 3：手机如何访问？**
两种方式：一是通过飞书、企业微信、QQ 等聊天平台发消息控制龙虾，最便捷；二是用手机浏览器直接打开 Web UI http://服务器IP:18789。

**问题 4：本地配置能迁到云端吗？**
可以。将本地 ~/.openclaw 目录打包 tar -czf backup.tar.gz ~/.openclaw，上传到云服务器解压即可，配置、记忆、技能都能无缝迁移。

## **2.6** **更新与维护：保持龙虾在最佳状态**
OpenClaw 迭代很快，平均两周一个版本。及时更新可获得性能优化、新功能和安全修复，操作很简单，一行命令即可。

**检查与更新**
# 查看当前版本
openclaw --version

# 查看最新版本
curl -s https://api.github.com/repos/openclaw/openclaw/releases/latest | grep tag_name

# 方式一：安装脚本一键更新
curl -fsSL https://openclaw.ai/install.sh | bash

# 方式二：源码手动更新
cd ~/openclaw
git pull origin main
pnpm install
pnpm build

**备份数据**
长期使用的记忆和技能很宝贵，建议养成定期备份习惯。

# 备份配置和数据，推荐每周一次
tar -czf openclaw-backup-$(date +%Y%m%d).tar.gz ~/.openclaw

# 恢复数据
tar -xzf openclaw-backup-20260210.tar.gz -C ~/

**手动配置：接入 DeepSeek 等自定义供应商**
以 DeepSeek 为例，兼容 OpenAI 格式的国产模型配置思路一致，在 openclaw.json 的 models.providers 中添加：

{
"models": {
"mode": "merge",
"providers": {
"deepseek": {
"baseUrl": "https://api.deepseek.com",
"apiKey": "${DEEPSEEK_API_KEY}",
"auth": "api-key",
"api": "openai-chat"
}
}
}
}

在 ~/.openclaw/.env 中写入 Key，避免明文暴露：

DEEPSEEK_API_KEY=sk-你的API Key

配置完成后重启网关 openclaw gateway restart，再用 openclaw models list 确认模型已出现。

**本地模型：用 Ollama 离线运行**
有隐私顾虑或想离线使用，可用 Ollama 运行开源模型：

# 安装 Ollama
curl -fsSL https://ollama.ai/install.sh | sh
# 拉取中文优化模型
ollama pull qwen2.5:7b

启动后 OpenClaw 会自动发现 http://127.0.0.1:11434，执行 openclaw models scan 即可列出。本地模型数据不出机，但对内存要求较高，70 亿参数建议 16GB 内存，响应较云端慢，适合敏感文件和弱网场景。

**模型故障转移**
OpenClaw 支持配置备用模型自动切换，在 agents.defaults.model 中设置主模型与 fallback 链：

{
"agents": {
"defaults": {
"model": {
"primary": "zai/glm-5",
"fallbacks": ["openrouter/deepseek/deepseek-chat", "ollama/qwen2.5:7b"]
}
}
}
}

含义为：优先使用 GLM-5，不可用时自动切到 DeepSeek，再不行切到本地 Ollama，形成三层保障。

## **2.8** **本章故障排查手册**
基于大量用户经验汇总，遇到问题先对照，多数可在 5 分钟内解决。

**安装问题**
**问题 1：Node.js 版本不对**
# 检查版本，必须 ≥22.16.x
node --version
# 低于则升级
nvm install 22
nvm use 22

**问题 2：权限错误**
# macOS/Linux
sudo chown -R $USER ~/.openclaw
# Windows 以管理员 PowerShell 运行
takeown /F "$env:USERPROFILE\.openclaw" /R /D Y
icacls "$env:USERPROFILE\.openclaw" /grant"$env:USERNAME:(OI)(CI)F" /T

**问题 3：网络连接失败、下载慢**
（1）检查网络或开启代理重试
（2）使用国内镜像：curl -fsSL https://openclaw.ai/install.sh |bash -s -- --mirror=cn
（3）换手机热点尝试

**API 配置问题**
**问题 1：API Key 无效**
（1）确认完整复制，包含 sk- 前缀，无多余空格
（2）检查账户余额，余额为 0 无法调用

**问题 2：模型不可用**
（1）核对模型 ID 是否正确，不同平台命名有差异
（2）查看平台状态页是否正常
（3）尝试切换其他版本

**问题 3：Token 消耗快、费用高**
（1）切换到更经济的模型，DeepSeek 性价比较高
（2）优化指令，避免每次带入大量历史记录
（3）定期清理会话：openclaw cache clear

**Gateway 问题**
**问题 1：Gateway 无法启动**
tail -f ~/.openclaw/logs/gateway.log
openclaw gateway restart

**问题 2：18789 端口被占用**
lsof -i :18789
# 可修改端口
openclaw config set gateway.port 18790
