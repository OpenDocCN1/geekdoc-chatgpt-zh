### **2.4.3 函数闯关游戏**

DeepSeek 能够帮助教师零编程打造跨学科的函数闯关教具。

函数闯关游戏把二次函数、分段函数等数学知识与物理、密码学等内容结合起来，以“特工任务”的形式呈现。它的教学价值在于用游戏化激活探究欲望、在闯关中自然渗透函数核心概念、通过参数调节锻炼数形结合能力。

实操流程如下。

第一步：给 DeepSeek 发出精准指令。

● Why：初中函数教学常被诟病抽象枯燥，通过特工闯关把二次函数、分段函数学起来更有趣，实现玩中学。

● What：做一个科技感十足的 HTML 小游戏，命名为“函数特工局”，包含 3 个递进任务。

任务 1：滑动调节二次函数参数命中目标点。

任务 2：解读分段函数找到指定坐标。

任务 3：破解基于函数的加密密码。

● How：交互设计如下。

功能 1：实时绘制函数图像，参数支持滑块调节。

功能 2：答案校验与即时反馈，正确错误有特效。

功能 3：剧情以特工行动线串联。

每个任务都包含任务简报、交互式图像、参数区、答案输入框。

● How much：

任务 1：参数范围 a -2～2，b -5～5，c -20～20

任务 2：坐标误差允许 ±0.1

任务 3：字母密码自动换算，如 3*x+2=3×10+2=32 对应字母 F

### **2.4.4 思维导图**

### **2.4.5 统计图表**

统计图表类型丰富多样。柱状图以矩形柱的高度或长度表示数值大小，直观对比不同类别数据的数值差异；折线图通过折线的起伏变化，清晰呈现数据随时间或其他连续变量变化的趋势，便于受众观察数据的走向；饼图通过将圆形区域划分成扇形，展示各部分在总体中的占比，能让人快速了解各部分与整体的关系。在学科教学中，利用 DeepSeek 生成此类统计图表教学素材，可以将复杂数据直观呈现，助力学生理解现象和规律。

● Who：初中地理教师。

● How：以 HTML 代码形式输出，图表需具备交互功能，鼠标悬停时显示具体数据。
