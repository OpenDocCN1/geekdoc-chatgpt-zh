4. 零粉丝也能爆：小红书为何偏爱新手
想靠自媒体赚钱，先得有人看。很多平台现在门槛越来越高，公众号、头条类平台对文字功底要求高，抖音、快手等短视频平台对拍摄剪辑要求高，操作看起来不难，却挡住了大量想尝试的人。

拿秋叶小红书训练营里的案例来说，一位54岁的退休学员做读书号，第一篇笔记只是朴实记录自己要在小红书坚持读书，两天内点赞量就冲了上来。

小结
普通人做自媒体，小红书是更现实的选择，核心有四点。
1. 用户质量高、消费力强，能卖高价商品。
2. 种草属性强、内容领域多元、入门门槛低。
3. 用户购买意愿强、品牌投放需求大、对新手变现扶持力度大。
4. 算法友好，不露脸不拍视频，0粉丝也能出爆款笔记。
