雅思写作模块总共包含两个任务。第一项是图表描述 Task 1，考生要依据一张或一组图表提炼数据并进行描述；第二项是议论文 Task 2，考生需围绕给定话题展开论述。写作部分主要考察考生的书面表达与逻辑思维能力，整体用时为60分钟。

4. 口语考试（Speaking）

雅思口语共分三个阶段。第一阶段是自我介绍并回答若干基础性问题；第二阶段是就抽到的一个话题进行简短陈述；第三阶段则是在第二阶段话题的基础上进行深度探讨。口语考核的核心是考生的流利度、语音、语法以及词汇运用能力，考试时长大约在11到14分钟之间。

综合来看，雅思是一场覆盖听、说、读、写四项技能的综合英语水平测评，要求考生在四个维度都具备一定实力。认真实战准备，熟知流程与题型，才能提升分数。明显需要对听力、阅读、写作和口语四个板块进行系统深入的学习。若对上述内容仍有疑惑，可以继续提问；若不确定该问什么，也可以让ChatGPT提供提问建议。
