**1．Single Agent**

起初因模型能力边界、幻觉风险以及工程化经验不足，Agent 设计偏向保守。常见做法是在某个垂直场景里接入模型 API，挂载一些工具或交互组件，在对话之上完成特定任务，这类聚焦单一任务的 Agent 称为 Single Agent。例如 2023 年初 ChatGPT 爆火时，笔者就做过一个自动生成单元测试的 Agent，其架构如图 1-20 所示。

[PRE2]

图 1-20 单测 Agent 的架构设计

该架构包含几个工程模块：

（1）用户记忆：缓存短期与长期行为偏好，让 Agent 能实现千人千面的响应。

（2）规划：预置意图识别、思维链等策略，帮助模型在垂类里做出更符合预期的行为，随着模型自身增强，该部分权重逐步下降。

（3）工具／行为：工程化封装的能力函数，Agent 判断后由系统调用对应能力完成动作。工具与行为可同域设计，也可按需拆分为异构模块。

这正是 ReAct 架构的典型思路：先规划再行动。即使单元测试工具链复杂，也能整合成效高、可验证的输出。但该产品仅服务于单测这一个明确垂类，缺乏任务间的流转和多 Agent 协作，所以仍属 Single Agent 模式。

当场景节点增多、流程变复杂时，单一工程化手段已力不从心，LLM 的幻觉也会随节点传递被放大。

**2．Multi Agent**

LLM 单打独斗能完成部分垂类任务，却远未达到人们对 Agent 的想象。更激进的设想是，真正的 Agent 要像人一样主动拆解任务、串联节点、做校验，最终产出高质量结果，这就是 Multi Agent。尽管预期很高，受制于幻觉和工程范式不成熟，能称得上可用且效果好的产品并不多。

比较有代表性的是 Manus.ai，由国内 Monica.im 团队打造，于 2025 年 3 月上线。它是全球首个通用型 Agent，能覆盖旅游规划、股票分析、教育内容等 40 多个领域的复杂生成与交互，用户通过 Web 使用，如图 1-21 所示。

实际架构远比简图复杂，这是单次任务的宏观视角。例如 LLM 层需拆分出制定、执行、自校验等独立单元，以保证复合任务稳定。本节不展开，后续会通过案例说明。

受浏览器载体限制，其输入输出也有边界。比如生成 PPT 或文档类产物，需要借助 Python 的自动化生态以脚本完成，无法直接调起本地软件。部署时因无法打开用户本地端口，除 Python 产物外，多以静态页面交付。

综合来看，Multi Agent 的上限取决于：

· 模型能力：直接影响执行中的幻觉程度，token 规模越大，工程化的占比可越低，避免过度设计。
· 承载形态：不同形态决定控制面，浏览器沙箱限制了对用户电脑的操控，能力天花板相应受限。
· 工具链：Agent 本质是决策与规划，真正决定产出的是可调用的工具。丰富的工具链能抬高上限，社区因此推出 Function Calling、MCP、A2A 等机制来扩展工具生态，详见后文。
· 步骤调度能力：因模型仍有局限，需要工程化设计来抑制幻觉并有序调度节点，不同场景需定制。

可以看出，Manus.ai 在 ReAct 基础上加了节点流转的调度模块，即 Supervisor，在 Multi Agent 系统中应用广泛。但因其以浏览器应用承载，与用户电脑存在沙箱隔离，产物上限仍受制约。

谈到承载形态，就不得不提更优的 Multi Agent 载体——IDE。虽然 IDE 多用于编程，但作为 Agent 载体优势明显。相比浏览器沙箱，面向开发者的 IDE 在授权后可自由调用本地终端、绑定端口服务，并按机器环境做兼容性编程，产物形态与质量上限更高。

**3．Physical Agent**

复合型 Agent 或将在未来 3～5 年成为热点，但无论架构如何，其本质仍停留在软件层，产出主要是数字结果，难以直接作用于物理世界。

推动物理世界变革同样重要。比如宇树科技的 AI 机器人就是把 Agent 能力延伸到现实物理层的尝试，并因此获得数亿元融资。虽然当前模型与硬件协同还不足以大规模落地，但从长周期看，Physical Agent 极可能成为重要方向。

芝加哥大学 Fouad Bousetouane 于 2025 年 1 月发布的论文*Physical AI Agents: Integrating Cognitive Intelligence with Real-World Action*提出，Physical AI Agent 具有颠覆性潜力，并给出感知、Cognition、驱动三层架构范式，为 Agent 从虚拟走向现实提供参考，如图 1-29 所示。

[PRE19]

图 1-29 Physical Agent 架构范式

在该范式里，感知与驱动多属硬件层，提供视觉、听觉、触觉及机械动作等交互媒介；认知层则由复合型 Agent 承担，负责调度感知与驱动的高效联动。硬件关键技术已相对成熟，真正决定 Physical Agent 上限的仍是认知层的复合型 Agent。

因此，复合型 Agent 既是当前应用的核心，也是未来 Physical Agent 架构不可或缺的一环，将在虚拟智能体向真实物理世界演化中发挥变革作用。

**1.2 复合型 AI Agent 的市场前景**

前文梳理了 AI Agent 的演进，从 LLM 诞生到具备自主决策行动能力的智能体，经历了长期积累。如今复合型 AI Agent 如雨后春笋般出现，正重塑世界运行方式。无论是社区讨论还是各大开发者大会，都在为 Agent 布局提供支持，其重要性不言而喻。

在模型能力不变的前提下，复合型 Agent 的效率与上限主要取决于架构是否合理以及工具链是否完备。基于此共识，开发者社区自 2024 年起持续降低工程成本，并在 Agent 与工具之间建立稳定连接与共享。例如低代码构建工作流的 Coze，简化服务搭建的 LangChain、LangGraph，以及连接工具链与 Agent 通信的 MCP 和 A2A 生态，整体体系日益完善，为规模化落地奠定基础。

与此同时，2025 年 5 月的多场国际开发者大会把 Agent 放在核心位置。Microsoft Build 开发者大会、Google I/O 上均发布数十款全新 Agent 产品，全面押注该赛道。微软全球首席传播官 Frank X. Shaw 公开表示：“我们已迈入 AI 智能体时代。”

随着 LLM 的快速发展，人类对 AI 的使用不断深化：从早期对话交互，到链式调用的简单应用，再到能适配多场景多角色的复合型 AI Agent。如今的 LLM 如同一颗信息广博、思维紧密的大脑，却仍缺乏直接处理输入输出的能力，也需要人在侧监督以确保全流程正确执行。
