单字输出控浇水决策

让本地大模型干一件极简的事，往往比让它写长文更难。想让它只做浇水与否的二选一，关键是把输出空间压缩到极致，同时在代码侧做兜底，确保最终永远只落到一个字。

做法是先用提示词给模型上约束。角色被定义成专做浇水判断的助手，回答形式被限定为单一汉字，只能是肯定或否定两种写法，不附带任何说明、不带标点空格、不允许额外词汇。决策逻辑也被写死进提示：温度跌破冰点一律判定不浇；0℃到5℃区间只有在土壤极干且植株特别缺水时才可能考虑；湿度是核心依据，但必须和温度一起看；沙质基质失水快，可在低温时也不能浇水。最后收口明确，需要补水就出肯定，不需要就出否定。

提示词做完第一层收紧，代码再补两层保险。第一层是前置筛查，借助正则从提问里抽取“气温是 X℃到 Y℃”的区间，只要最高值不超过零度，就直接给出否定结果，根本不进模型调用。第二层是后处理净化，先把可能出现的 HTML 标签和多余空白清理掉，再检查净化后的文本是否干净地包含肯定或否定。若同时出现、或都没出现，就启动词表二次判断：命中“不需要、不建议、不必、不适合、不宜、无须、没必要、不要”等否定表述则判否定，命中“需要、应该、建议、必须、适合、适宜”等肯定表述则判肯定，兜底默认否定，偏向安全。

采样参数也调得很克制：temperature 0.1、max_tokens 50、repeat_penalty 1.2、top_p 0.5，让模型基本只负责吐一个字。请求异常或解析异常会以文字提示返回，便于排查。

演示用的两组提问能说明流程。被注释的那组 -21℃到0℃ 沈阳沙土干燥，是典型的极端低温，直接命中前置筛查返回否定；实际运行的那组 15℃到20℃ 晴天沙土干燥，则走常规路径交给模型并经后处理。

def force_yes_no_response(text):

    """强制只返回"是"或"否"的处理函数"""

    # 先清理文本

    text = clean_response(text)

    # 直接检查是否包含确切的"是"或"否"

    if "是" in text and "否" not in text:

        return "是"

    elif "否" in text and "是" not in text:

        return "否"

    # 如果同时包含或都不包含，进行更复杂的分析

    negative_terms = ["不需要", "不建议", "不必", "不适合", "不宜", "无须", "没必要", "不要"]

    for term in negative_terms:

        if term in text:

            return "否"

    positive_terms = ["需要", "应该", "建议", "必须", "适合", "适宜"]

    for term in positive_terms:

        if term in text:

            return "是"

    # 默认返回"否" (安全起见)

    return "否"

def clean_response(text):

    """响应清洗函数"""

    text = re.sub(r'<\/?[\w\s]+>', '', text)

    text = re.sub(r'\s+', ' ', text).strip()

    return text

def needs_preprocessing(prompt):

    """检查是否有需要预处理的极端条件"""

    temp_match = re.search(r'气温是：(-?\d+)°C到(-?\d+)°C', prompt)

    if temp_match:

        low_temp = int(temp_match.group(1))

        high_temp = int(temp_match.group(2))

        if high_temp <= 0:

            return True

    return False
