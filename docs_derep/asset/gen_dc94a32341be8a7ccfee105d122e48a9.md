3）变量命名规范

变量名属于 C++ 标识符体系，用来唯一标记变量。实际使用时应遵守以下约定：
（1）允许的字符。 名称只能包含英文字母、数字和下划线，且首字符不能是数字。如 count、_value、num123 合法，而 123var 不合法。
（2）区分大小写。 C++ 把不同大小写的名称视为不同标识，age 与 Age 会被当作两个变量。
（3）禁止使用关键字。 保留字不能作为变量名使用，例如 int、if、for、class 等，C++14 加入的 decltype、generic 等同样不可用。
（4）不允许特殊符号。 空格、标点、运算符等都不能出现在变量名中，如 my var、var@123 都是非法写法。

4）初始化变量
（1）含义。 初始化指在声明变量的同时就赋予初始值，此时内存已分配，变量拥有确定的起点值。
（2）价值。 创建时立刻给出合理初值，是良好习惯，能有效防止未初始化变量引发的不可预测问题。

**4.数据类型转换**
C++ 允许不同类型之间转换，大致分为显式转换和隐式转换两类。
1）显式转换
需要手动干预时，可使用显式转换，亦称强制转换。这是由开发者主动告知编译器进行转换，与编译器自动执行的隐式转换不同。
C++ 中常见的强制转换有两种写法。
（1）C 风格转换，兼容 C 语言的传统写法。
[PRE5]
（2）C++ 风格的函数式转换。
[PRE6]
显式转换不会改动源变量，而是基于其值生成临时新值，并按目标类型的精度规则做相应处理。
[PRE7]
转换方向决定安全性。从小范围到大范围，例如 char 到 int、float 到 double，属于安全转换，目标能完整容纳源值，不会丢数据。从大范围到小范围，例如 int 到 char、double 到 float，属于风险转换，可能出现截断、溢出等精度损失，因此需要谨慎把控。
2）隐式转换
又称自动转换，由编译器在类型相容且相对安全时自行完成，无需显式声明。例如程序期望某类型却得到另一类型时，编译器会介入转换。
[PRE8] [PRE9]
bool 只占 1 字节，向 bool 的隐式转换一般安全，具体规则如下。
（1）若原类型值为 0 或空，如 0、0.0、空指针 nullptr，转换为 false。
（2）若原类型值为非 0，如 5、3.14、非空指针，转换为 true。
需要注意，这里说的 0 是数值零或空字符 '\0'，而不是字符 '0'，后者的 ASCII 码是 48。示例略。
[PRE10]
若转换可能造成数据丢失、精度下降或逻辑模糊，编译器会报错或警告。隐式转换只是编译器提供的便利手段，仅在无风险的兼容场景下触发。
初学阶段不建议随意依赖隐式转换，其触发条件隐蔽，容易在混合运算中埋下截断、精度丢失或逻辑歧义的问题，排查成本高。
因此建议尽量少用隐式转换，优先使用显式转换明确意图，提升代码可读性并规避风险，形成严谨习惯。

**5.常量**
常量是程序运行期间不可更改的量，与可变的变量相对。const 是定义常量的核心手段，能提高安全性、可读性和优化空间。
1）常量的价值
（1）安全。 避免关键数据如数组长度、固定参数被误改，降低 Bug 风险。
（2）可读。 使用语义化名称如 PI 代替 3.14，让代码意图更明显。
（3）优化。 const 的值常在编译期确定，编译器可据此优化。
2）常量与变量区别
（1）变量。 直接声明即可，如 int a；值可随时通过赋值修改，如 a=5；a=10；
（2）常量。 定义后不可变，需用 const 或字面量声明，强行修改会编译报错。
3）const 用法
const 用于声明不可变数据，面对固定值如数学常数、配置项时优先使用 const，而非裸写字面量。常见写法如下。
（1）定义。 声明时必须初始化，后续不可更改。

4）特殊常量
（1）NaN。 Not a Number 的缩写，表示浮点运算中非法结果。
（2）NUL。 ASCII 0 的字符，等价于 '\0'，用于 C 风格字符串结尾。

**6.字面量**
在掌握类型、变量、常量后，再了解字面量。字面量是直接写出的固定值，无需变量或计算即可被编译器识别。
1）特点
（1）原值直现，无需推导。
（2）类型由写法或后缀决定，如 3.14 为 double，3.14f 为 float。
（3）运行时不可改。
2）常见类型及示例
（1）整数。 支持十进制、八进制、十六进制，如 100、0144、0x64、100L。
（2）浮点。 默认 double，f 后缀为 float，如 3.14、3.14f、1.23e5。
（3）字符。 单引号括起，对应 ASCII，如 'A'、'0'、'\n'。
（4）字符串。 双引号括起，本质字符数组末尾带 '\0'，如 "hello"。
（5）布尔。 true / false。
（6）指针。 nullptr 表示空指针。

（2）自增自减。前置 ++、后置 --。

（1）算术。+ - * / %。
（2）关系。== != > < >= <=。
（3）逻辑。&& ||。
（4）赋值。= += *= 等。
（5）位运算。& | ^ << >>。
