可以理解，间接效应裹着反事实的表象，即便在因果革命的拥护者眼里也显得有些玄。我的判断是，这种工具的实用价值最终会压过对反事实形而上学的种种疑虑。或许可以把它类比成无理数与虚数：起初让人不安，这也是“无理数”名字的由来，但长期来看，效用把不适转化成了理性之光。

为了展示这种价值，本章会列出若干案例，说明不同学科的研究者是怎样从中介分析里获得洞见的。有位学者研究“全民学代数”这项教育改革，起初看似失败，后来被证明有效。另有一项关于伊拉克与阿富汗战场止血带使用的研究，表面上提示止血带毫无益处，经过细致的中介剖析才明白结果很可能掩盖了止血带的真实效果。

# 第九章 中介效应：追踪看不见的因果链

因为掉了一只马掌，失了一匹战马……

因为败了一次战役，亡了一个国家。

[PRE0]
1912 年，南极冰原上的一座雪堆与一副交叉滑雪板搭成的十字架，是探险队长罗伯特·福尔肯·斯科特及其两名同伴的最终归宿。旅程中他们已饱受艰辛，队伍里还爆发了坏血病。假如那个年代的科学家清楚柑橘抵御坏血病的内在机制，这场悲剧本可避免。［资料来源：左图，特吕格弗摄（推测）；右图，赫尔伯托·邦汀摄，新西兰坎特伯雷博物馆提供。］

日常语言里的“为什么”其实有两层意思。第一层直白：看到现象找原因。你看到祖父躺在医院，便问：“为什么？他看起来健康，怎么会心脏病发作？”

第二层则更进一层，是为了弄清已知的因与已知的果之间如何连通。比如我们知道药物 B 能预防心脏病，或像詹姆斯·林德那样知道柑橘能预防坏血病后，就会追问其背后的机理。人类总是求知若渴，在确认事实后不久就会提出第二个版本的问题：“为什么？柑橘抗坏血病的机制到底是什么？”本章聚焦的就是这个第二层“为什么”。

厘清作用机制对科研与生活都极其关键，因为机制不同，行动策略就不同。假如橘子吃完了，只要知道其抗坏血病的真正中介，我们就能去找另一种含维生素 C 的食物继续预防。若无此认知，可能就会尝试香蕉等无效替代。

学界用“中介”来命名这个第二层“为什么”。医学期刊常写：“药物 B 预防心脏病的效应是通过调节血压水平来中介的。”这就编码了一个因果链：`药物→血压→心脏病`。药物先降血压，再降低发病风险。同样，柑橘与坏血病可概括为：`柑橘类水果→维生素 C→坏血病`。

关于中介，我们常问：它是否解释了全部效应？药物 B 是否只能经血压起作用，还是另有通道？安慰剂效应就是医学里典型的中介：若药物只靠病人信念起效，多数学者会认为它无效。中介在法律里也很重要。问某公司女性员工工资低于男性是否构成性别歧视，本质上是一个中介问题，答案取决于薪资差距是性别直接导致，还是间接经由职业资格等雇主不可控的中介因素产生。

这些问题都要求我们区分总效应、绕过中介的直接效应、经由中介的间接效应。过去一个世纪，即便给这些术语下定义都极难。有人因忌讳“因果”一词而用去因果化的语言定义中介；有人干脆否定中介分析，称直接与间接效应的概念更添混乱而非澄清。

我自己也曾为定义中介苦恼，这个难题的突破后来成为职业生涯最重要的收获之一。起初我认为间接效应没有操作意义，因为它不像直接效应那样能用干预语言定义。后来我意识到可用反事实来定义，且它具有重要策略意义，研究才迎来关键进展。只有登上因果阶梯的第三层，我们才能量化中介效应，这也是它被放在本书后段的原因。概念迁移到第三层新环境后，我们得以更频繁地从有限数据中估计由任意期望路径所介导的效应占比。

可以理解，间接效应披着反事实的外衣即便在因果革命的支持者那里也显得神秘。但我相信其巨大效用终将压倒形而上学的质疑。把它比作无理数和虚数也许恰当：起初让人不适，最终效用把它变为理性的光辉。

为说明这一点，本章将举例说明各学科如何从中介分析获益。教育改革“全民学代数”起初看似失败后又显成功；伊拉克与阿富汗战场止血带的研究表面显示无益，经细致中介分析后才理解该结果很可能掩盖了真实效果。

总体而言，过去十五年因果革命为学界提供了一套清晰简明的规则，用以量化给定效应中直接与间接的占比。它把中介从一个边缘化、合法性受质疑的概念，转化为广受欢迎且通用的科学工具。

## 坏血病：误认的中介招致灾难

我用一个震撼的历史真实案例开篇，以凸显理解中介的重要性。

詹姆斯·林德船长1747年发表的坏血病对照试验是早期对照试验之一。当时坏血病极其致命，1500至1800年间约有200万水手因此死亡。林德和同时代人都确信柑橘可预防该病。19世纪英国海军已规定船只必须携带充足柑橘，按理坏血病本应成为历史。通常历史书在此戛然而止，让人庆祝科学方法胜利。

然而一个世纪后，英国极地探险队里这一本可预防的疾病卷土重来，令人困惑。1875年英国北极远征、1894年杰克逊—哈姆斯沃思北极远征，以及1903年和1911年罗伯特·福尔肯·斯科特的两支南极远征，均惨遭坏血病侵袭。

为何出现这种悲剧？答案是无知与傲慢，二者常相伴。到1900年，英国医生似乎忘了百年前的教训。1903年斯科特远征队的医师科特利茨把坏血病归因于被污染的肉，并补一句：“所谓抗坏血剂带来的好处只是错觉。”1911年远征，斯科特特意带上无腐坏迹象的干肉，却未储备柑橘或果汁。盲从医生意见很可能酿成惨剧。史料显示抵达南极的五名队员全部死去，其中两人死因不明，很可能是坏血病；另有一人返程途中幸存却已患重症坏血病。

事后看，科特利茨的建议等同渎职。为何百年经验被彻底抛弃？因为医生并未真正理解柑橘如何起效，也就是不了解关键中介物。

从林德时代起，人们一直认为柑橘之所以有效是因其酸性，从未证实。用他们的因果图理解是：

柑橘类水果→酸性物质→坏血病

按此图示，任何酸性物质都可预防坏血病。若当时有可乐，恐怕它也会被视作良药。起初水手吃西班牙柠檬，后为省钱改用西印度酸橙，同样酸却只含四分之一的维生素 C。更糟的是，他们还加热烹煮柠檬汁“提纯”，进一步破坏维生素 C。换言之，他们一步步让中介失效。

1875年，饮用柠檬汁的水手仍患坏血病，医学界极度困惑。他们同时发现吃新鲜肉制品的水手未发病，吃罐头肉的却发病^([\[1\]](#part0014.html#note1n))。于是科特利茨等医生错误地把腌肉视为罪魁，阿尔姆罗斯爵士甚至编造被污染肉中细菌导致“尸碱中毒”进而引发坏血病的理论。柑橘预防坏血病的学说就此被扔进垃圾桶。

直到真中介被发现，混乱才终结。1912年波兰生物化学家卡西米尔·冯克提出微量元素存在，称其为“维生素”。1930年阿尔伯特·圣捷尔吉分离出能预防坏血病的特定成分，不是酸性物质，而是特殊酸，即维生素 C 或抗坏血酸。1937年圣捷尔吉因此获诺贝尔奖。多亏他，我们才知真正因果路径：柑橘类水果→维生素 C→坏血病。

我相信科学家不会再“忘记”这个路径。这个故事说明中介分析绝非抽象数学练习。

## 先天与后天：巴巴拉·伯克斯被遗忘的故事

据我所知，首个明确用因果图表示中介者的是斯坦福研究生巴巴拉·伯克斯，时间1926年。这位鲜为人知的女性先驱是本书的幕后英雄之一。她很可能独立于休厄尔·赖特发明了路径图，在中介议题上不仅早于赖特，且领先时代数十年。

伯克斯短暂职业生涯的核心兴趣是先天与后天对人类智力的作用。她的导师刘易斯·特曼以斯坦福—比奈智商测验闻名，坚信智力先天遗传而非后天习得。那正是优生学运动鼎盛期，尽管今日已知其谬误，当时高尔顿、皮尔逊、特曼等权威都在试图用研究证实它。

先天后天之争古老而持久。伯克斯的独特贡献是把它浓缩成一张因果图，据此提出并回答：“父母智力对子女智力的效应中有多少来自直接路径父母智力→子女智力即先天，又有多少来自间接路径父母智力→社会地位→子女智力即后天？”

[PRE2]
图 9.2 先天与后天之争，由巴巴拉·伯克斯设计的框架

图中伯克斯使用了双向箭头，表示互为因果或方向不确定。为简便假设双向箭头主要效果为左向右，即简化为单向箭头，于是社会地位成为中介，路径意指父母智力提升社会地位，进而为子女提供更好智力发展机会。变量 X 表示“其他未测量的间接原因”。

伯克斯在论文中采集了对204个寄养家庭的家访数据。假设这些儿童只从养父母得后天培养好处而无先天遗传优势。她对所有人做智商测验，并对105个非寄养对照家庭做同样测验，还用问卷评级儿童社会环境。借助数据与路径分析，伯克斯算出父母智商对子女智力的直接效应仅占总效应的35%，约三分之一变异来自遗传。换言之，父母智商高15分的，子女智力通常只高5分。

作为特曼弟子，看到先天影响如此之小，伯克斯必然失望。于是她开始质疑当时流行分析，即控制“社会地位”是否正确。她写道：“若我们错误地把某些变量视作常数，则因对果贡献的真实衡量将被扭曲，因为被设为常数的变量可能取决于先天与后天目标变量中的任一个或其他未测间接因素，且这些因素也可能影响目标变量。”换句话说，若关心父母智力对子女智力的总影响，就不应控制两变量间路径上的变量。

伯克斯更进一步。她强调的衡量标准译成现代语言即：若以某变量为条件，而该变量a受父母智力或子女智力影响，或b受父母智力或子女智力某个未测因影响，则会产生偏倚。

这些标准与赖特的语言毫无重合，且远超时代。标准b正是科学史上最早的对撞偏倚例子。看图9.2，社会地位是对撞点在路径父母智力→社会地位←X中。因此控制社会地位会打开后门路径父母智力→社会地位←X→儿童智力。由此得出的直接与间接效应估计都会偏倚。伯克斯前后统计学家未考虑用箭头与图示分析，沉迷于相关受控即偏回归系数更接近因果的虚假神话。

伯克斯不是首个发现对撞效应的人，但很可能是首个用因果图描述其特征者。她的标准b完全适用于第四章M偏倚的例子。这是首次对以预处理因素为条件这一操作的警告。几乎整个20世纪的统计学家视其为安全操作，至今仍有人坚信，令人诧异。

现在设身处地想象巴巴拉·伯克斯：你刚发现所有同事都在控制错误变量。你还面临两重劣势：学生身份与女性。你会低头假装接受普遍观点，并用同事缺陷语言与他们沟通吗？
