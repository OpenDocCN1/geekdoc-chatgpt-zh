# 克拉拉为何拥不了“人心”？缺的竟是这份“卑劣”

读完《克拉拉与太阳》，最扎心的问题来了：克拉拉到底有没有人心？

答案大概率是否定的。

别误会，她身上集齐了人类引以为傲的所有美德：善良、体贴、无私，为乔西倾尽所有。她甚至不乏情感，在与人的相处中，能精准捕捉并表达真挚的喜悦、激动与悲伤。但偏偏少了**唯一**一种人类通病——**自私**。

因为她是彻头彻尾的“利他主义者”。全书视角里，她的每一次思考、每一个起点，都指向别人；你找不到一丝一毫她为自己打算的痕迹。

也正因如此，克拉拉的一切高贵与深情，都无法用人类的坐标系去衡量。人心之所以沉重、纠结、痛苦，正是因为“卑劣的自私欲望”与“崇高的向上渴望”同在一具躯壳里打架。失去了自私这股“向下的地心引力”，所有向上的善良便失去了分量，飘成了虚无缥缈的轻烟。

自私，是人类的沉重枷锁；可或许在不远的将来，它反而成了证明“我是人”最关键的锚点。
