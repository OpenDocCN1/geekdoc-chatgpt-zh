### **5.3.5 AI 辅助查找引用函数**

数据匹配合并是 Excel 的高频需求，VLOOKUP、HLOOKUP 等函数可以实现跨表关联，在清洗、整合和报表制作时非常实用。

表 5-4 列出了常见查找引用函数的功能示例。

**1. VLOOKUP 使用要点**

VLOOKUP 的语法是 =VLOOKUP（查找值，查找范围，返回列序号，匹配方式）。使用时需注意：查找范围必须是纵向结构；查找条件为单条件且不区分大小写；查找方向只能从左向右；查找列内不能有重复值。

**2. MATCH 使用要点**

MATCH 用来定位指定值在数组中的位置，语法为 =MATCH（查找值，查找范围，匹配模式）。模式 0 为精确匹配，1、-1 为模糊匹配，默认不区分大小写，一般也不适合重复数据。

**3. INDEX 使用要点**

INDEX 可取出区域中指定行列交叉的数值。有两种形式：从单一区域取数 =INDEX（区域，行号，列号）；从多区域取数时增加区域序号。INDEX 常与 MATCH 配合，先定位行列再取值。
