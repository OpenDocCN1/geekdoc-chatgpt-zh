## Node.js 用 ExcelJS 生成表格

前端生态里 ExcelJS 是生成和美化 Excel 的利器。先装依赖，再创建 Workbook、建表、定列头、填随机数据，最后写文件。需要细粒度样式时还能遍历每一行给单元格加边框。

装包常用三种写法，按项目需求选其一即可，先装再用。

[PRE8]

npm install exceljs -g

[PRE9]

npm install exceljs --save

[PRE10]

npm install exceljs --legacy-peer-deps

[PRE11]

用 JavaScript 和 ExcelJS 创建一个 Excel 文档，文件名是 table.xlsx。然后新建一个工作表，名称是"表格"，在这个工作表中添加一个 10 行 4 列的表格，字段是 id、name、sex、salary。数据随机填充。给出详细的实现代码和中文注释。

基础骨架：导入库、建工作簿、加工作表、定义列头。

[PRE12]

// 导入 ExcelJS 库

const ExcelJS = require('exceljs');

// 创建一个新的工作表

let workbook = new ExcelJS.Workbook();

// 在工作表中添加一个新的工作表，命名为"表格"

let worksheet = workbook.addWorksheet('表格');

// 添加表头

worksheet.columns = [

  { header: 'id', key: 'id' },

  { header: 'name', key: 'name' },

  { header: 'sex', key: 'sex' },

  { header: 'salary', key: 'salary' }

];

填充 10 条随机数据并写入文件。

[PRE13]

// 生成随机数据并添加到表格中

for(let i = 1; i <= 10; i++) {

  let sex = Math.random() > 0.5 ? 'male' : 'female';

  let salary = Math.floor(Math.random() * 10000) + 1000;

  worksheet.addRow({id: i, name: 'Name' + i, sex: sex, salary: salary});

}

// 将工作表保存为名为 Table.xlsx 的文件

workbook.xlsx.writeFile('table.xlsx')

.then(function() {

  console.log('Excel 文件创建成功!');

})

.catch(function(error) {

  console.error(error);

});

## Java 把 Excel 导入 SQLite

后端场景里常需要把 Excel 转成数据库。用 Apache POI 读表，配合 JDBC 写入 SQLite，流程是：加载驱动→建库建表→打开文件→遍历行列→PreparedStatement 批量写入。

先导包。

[PRE16]

import org.apache.poi.ss.usermodel.*;

import org.apache.poi.xssf.usermodel.XSSFWorkbook;

import java.io.File;

import java.io.FileInputStream;

import java.sql.Connection;

import java.sql.DriverManager;

主类里完成连接、建表、读取并写入。
