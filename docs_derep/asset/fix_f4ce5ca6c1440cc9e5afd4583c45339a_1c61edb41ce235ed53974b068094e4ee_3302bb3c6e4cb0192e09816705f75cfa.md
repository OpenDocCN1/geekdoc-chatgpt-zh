# 第2章
# 图谱知识的表征与建模路径

漆桂林 东南大学，潘志霖 阿伯丁大学，陈华钧 浙江大学

在图谱研究里，表征的核心问题是如何挑选合适的形式语言，让知识能够被系统读懂并在后续计算中被利用。英文文献中 Knowledge Graph Representation 即指此。把视角放到结构上，图谱本质是一张语义网，通过相互连通的点与线来承载信息[1]。网络中点可以承载概念、属性、事件或具体对象，线则表达点与点之间的关联，线的标签说明关联的种类。语义的落脚点在于线的含义。想要让线条拥有明确解释，研究者先后提出术语语言并发展为描述逻辑。描述逻辑源自一阶谓词逻辑的可判定片段，推理的复杂度因此可控。W3C 以描述逻辑为逻辑基础制定了本体语言 OWL 作为 Web 术语的标准，同时发布了 RDF Schema 用以描述 Web 本体。近年来基于向量的表征成为主流，这类做法把三元组的头谓尾映射为数值向量，再借助统计或神经网络进行推理和对实体间直接关联的预测。本章先梳理常见表征思路，再说明如何依赖这些思路对知识进行建模。

## 2.1 知识表征的本质要义

上世纪九十年代，MIT AI 实验室的 R.Davis 总结了知识表征的五大功能：

+   * 机器替身 A KR is a Surrogate，即必须为客观实体在机器中建立可指认的替代形式。
+   * 本体承诺与概念框架 A KR is a Set of Ontological Commitments，即需要提供描述客观事物的概念与类别体系。
+   * 推理支撑 A KR is a Theory of Intelligent Reasoning，即需要给出机器推理的模型与方法。
+   * 计算载体 A KR is a medium for Efficient Computation，即表征本身是一种便于高效计算的数据结构。
+   * 人机共读媒介 A KR is a Medium of Human Expression，即表征要贴近人类认知，既能被机器读取也能被人类理解。

相关探索可追溯到人工智能早期。认知科学家 M. Ross Quillian 与 Allan M. Collins 提出语义网络来表达人类语义知识并支持推理[2-3]，以网络形式刻画概念间的语义联系。典型案例 WordNet 属于词典类知识库，主要定义名词、动词、形容词、副词间的语义关系。20世纪70年代专家系统兴起并商业化，知识库构建与表征受到更多关注。传统专家系统一般由知识库和推理引擎两大模块构成。

无论是语义网络、框架语言还是产生式规则，都缺乏严格的语义理论和形式化定义。为此研究者开始探索具备扎实理论基础和可控算法复杂度的表征框架。最具代表性的是描述逻辑语言 Description Logic[4]。描述逻辑是当下大多数本体语言如 OWL 的理论根基。首个描述逻辑语言 KL-ONE 由 Ronald J. Brachman 等人在1985年提出[5]。描述逻辑主要用于刻画概念、角色、个体、关系、公理等要素。与传统专家系统的表征语言不同，描述逻辑家族更关注表征能力与推理复杂度之间的权衡，并深入研究不同构造组合对查询、分类、一致性检测等任务带来的计算代价。

语义网的基础数据模型 RDF 的设计受到元数据模型、框架系统和面向对象语言等多重启发，最初为 Web 上发布结构化数据提供标准描述框架。随后语义网吸收描述逻辑的研究成果，发展出 OWL 系列标准化本体语言。现代图谱如 DBpedia、Yago、Freebase、Schema.ORG、Wikidata 等大多在语义网表达模型的基础上进行扩展或精简。

早期专家系统时代与语义网时代的表征方法都属于以符号逻辑为基础的知识表征。符号式表征擅长刻画显式离散知识，可解释性强。但人类知识中存在大量难以符号化的隐性知识，纯符号逻辑因知识不完备而鲁棒性不足，推理难以实用，这催生了用连续向量表征知识的研究。

向量表征的探索已有历史。受表示学习发展和自然语言处理中词向量等嵌入技术的启发，人们开始用低维稠密向量表征知识。将图谱中的对象和关联映射到低维连续空间，为每个对象和关联学习一个向量。基于连续向量的表征可通过数值运算发现新事实和新关联，更好挖掘隐式知识与潜在假设，这些隐式知识往往难以由人主观归纳。更重要的是，图谱嵌入常作为先验知识输入到各类深度神经网络中，用以约束和监督训练过程。如图 2-1 所示为离散符号式表征与连续向量式表征的对比。

总体来看，相较于传统人工智能，图谱时代的表征已发生明显变化。一方面，受规模化影响，现代图谱多采用以三元组为基础、较为简洁实用的表征方式，并弱化了对强逻辑表征的要求；另一方面，图谱已成为搜索、问答、大数据分析等系统的重要数据基础，向量化的图谱表征使其更容易与深度学习模型融合，因而愈发受到重视。

## 2.2 人工智能初期的表征范式

知识是智能的基础，人类智能常有意识或无意识地运用已有知识。人工智能系统同样需要获取并运用知识。这里涉及两个核心问题：知识如何表征？如何在计算机中高效存储与处理？本节主要围绕第一个问题展开。

### 2.2.1 一阶谓词逻辑

一阶谓词逻辑，也称一阶逻辑，是公理系统的标准形式逻辑。与命题逻辑不同，一阶逻辑支持量词和谓词。例如，命题逻辑中“John MaCarthy 是图灵奖得主”“Tim Berners-Lee 是图灵奖得主”是两个无关命题。

在一阶逻辑里，可用谓词和变量表达，例如图灵奖得主 x 表示 x 是图灵奖得主。这里图灵奖得主是一元谓词，x 为变量，图灵奖得主 x 是一个原子公式。¬图灵奖得主 x 是一个否定式公式。若 x 取 John MaCarthy，图灵奖得主 x 即为第一个命题；若 x 取 Tim Berners-Lee，则对应第二个命题。

- 结构性：可将事物的属性及事物间语义关联显式外化。
- 严密性：拥有形式化语法、语义和推理规则。
- 可实现性：可映射为机器内部形式，便于算法实现。
- 有限可用性：逻辑归结仅半可判定。
- 不擅长处理不确定信息。

### 2.2.2 霍恩子句与霍恩逻辑

霍恩子句以逻辑学家 Alfred Horn[6]命名。一个子句是文字的析取。霍恩子句最多含一个肯定文字，肯定文字指不带否定符号的文字。例如 ¬p₁∨⋯∨¬pₙ ∨ q 是一个霍恩子句，等价于 p₁∧⋯∧ pₙ → q。Alfred Horn 于 1951 年指出这类子句的重要性。

霍恩逻辑是一阶逻辑的子集。基于霍恩逻辑的知识库是霍恩规则集合。一个霍恩规则形如 B₁ ∧⋯∧ Bₙ → H，其中 H 为头原子公式，B₁…Bₙ 为体原子公式。事实是无体原子公式且无变量的特例。例如 →图灵奖得主 Tim Berners-Lee 是一个事实，可简写为图灵奖得主 Tim Berners-Lee。

- 结构性：可显式呈现事物的属性及语义联系。
- 严密性：具备形式化语法、语义和推理规则。
- 易实现性：可判定，可映射为机器内部形式便于算法实现。
- 表达能力受限：不能定义类表达式，不能任意使用量化。
- 不擅长处理不确定信息。

### 2.2.3 语义网络

语义网络由 Quillian 等人提出，用以表达人类语义知识并支持推理[3]。它在形式上是一个带标记的有向图。图中的节点用于表示事物、概念、情境、状态等，每个节点可携带若干属性。节点间的连接弧即联想弧，用于表示各种语义联系和动作。语义网络的基本单元是三元组：节点1, 联想弧, 节点2。例如 Tim Berners-Lee, 类型, 图灵奖得主 和 Tim Berners-Lee, 发明, 互联网 即为三元组。由于所有节点通过联想弧相互连通，语义网络可通过图操作实现知识推理。

### 1. 语义网络的优点

1）联想性。它最初作为人类联想记忆模型提出。
2）易用性。直观表达事物的属性及其语义联系，便于理解，自然语言与语义网络的转换较为容易，故在自然语言理解系统中应用广泛。
3）结构性。语义网络是一种结构化表示，对子图数据特别有效，能显式表达事物的属性及语义联想。

### 2．语义网络的缺点

1）缺乏形式化语法。语义网络表示手段多样，灵活性高，但表示形式不一致会增加处理复杂度。例如“每个学生都读过一本书”可有多种语义网络表示，如图2-2和图2-3所示。图2-2中 GS 表示一个概念节点，指具有全称量化的一般事件，g 为实例节点，代表 GS 中的具体例子，s 为全称变量，是学生概念的一个个体，r 和 b 均为存在变量，r 对应读概念的个体，b 对应书概念的个体，F 指 g 覆盖的子空间及其具体形式，∀ 代表全称量词。而图2-3 则把该命题表示为：任意学生 s₁ 均属于读过一本书这一概念的元素。

### 2.2.4 框架

框架最早由 Marvin Minsky 于1975 年提出[7]，旨在更好地理解视觉推理和自然语言处理。其基本思想是：人们对现实世界事物的认识以类似框架的结构储存在记忆中。面对新事物时，从记忆中调取合适框架并据实际情况修改补充，形成对当前事物的认知。

框架是描述对象属性的数据结构。在框架理论中，类是基本单元。每个类包含若干槽，每个槽又可分为若干侧面。槽用于表示对象的一个属性，侧面用于描述该属性的一个方面，槽和侧面均可赋予属性值，分别称为槽值和侧面值。此外，框架还支持默认值和触发器以维护框架一致性。

### 1．框架的优点

+   1）结构性：可将事物的属性及语义联想明确外化。
+   2）框架对知识描述较为全面，支持默认值及触发器。

### 2．框架的缺点

+   1）框架构建成本很高，对知识库质量要求极高。
+   2）默认值会增大推理复杂度。
+   3）无法表达不确定性知识。

### 2.2.5 描述逻辑

描述逻辑是一阶逻辑的可判定子集，最初由 Ronald J. Brachman 于 1985 年提出。它可以看作是对语义网络和框架进行形式化的产物。描述逻辑一般支持一元谓词和二元谓词，一元谓词称为类，二元谓词称为关系。其重要特征是兼具较强的表达能力与可判定性。描述逻辑近年广受关注，被选为 W3C 互联网本体语言 OWL 的理论基础。

### 1．描述逻辑的优点

+   1）结构性：可将事物的属性及语义联想明确外化。
+   2）严密性：具备形式化语法、语义和推理规则。
+   3）多样性：拥有大量可判定的扩展，以满足不同应用场景。
+   4）易实现性：可判定，可映射为机器内部形式便于算法实现。

### 2．描述逻辑的缺点

+   1）表达能力有限：不支持显式使用变量，不能任意使用量化。
+   2）无法表达不确定性知识。
