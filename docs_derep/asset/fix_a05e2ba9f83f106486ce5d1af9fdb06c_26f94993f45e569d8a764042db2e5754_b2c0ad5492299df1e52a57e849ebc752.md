# 机器学习框架与企业开放平台

## 4.6 主流机器学习框架盘点

### 4.6.1 TensorFlow：全民 AI 的基石

TensorFlow 完全开源，人人可用。上手极轻松，几行代码即可跑通模型，大幅降低神经网络入门门槛。

**部署无门槛：**
*   **Windows CPU 版**：终端执行 `pip install tensorflow` 即可。
*   **GPU 加速版**：终端执行 `pip install tensorflow-gpu` 一键部署。

框架就绪后，推荐安装 Jupyter Notebook 便于文档编程，命令 `pip install jupyter` 一键搞定。

除了命令行，Anaconda 这类“全家桶”式工具也能用。若把 TensorFlow 比作灶台，Anaconda 就是备齐食材调料的大厨房。官网下载安装包，傻瓜式向导点击安装即可。安装完成后进入 Environments 面板，搜索 TensorFlow 并勾选，点击 Apply 即可自动解析依赖完成部署。

但 TensorFlow 也有短板：计算流须构建为静态图，且缺乏符号循环，导致部分计算不便；性能上亦无绝对优势。尽管如此，凭借庞大生态与活跃社区，它依然是当下最热门的框架。

### 4.6.2 Caffe：计算机视觉的“老牌劲旅”

2013 年底问世的 Caffe（Convolutional Architecture for Fast Feature Embedding），是首个实现工业级落地的主流框架。该框架开源高效，擅长 CNN 建模。受限于 RNN 生态薄弱，早期定位聚焦图像识别、推荐引擎及自然语言处理，鲜涉语音、时序预测、图像描述等序列任务。凭借卓越卷积性能，Caffe 夺得 2014 ImageNet 冠军，长期稳居 CV 领域科研与生产部署首选。

2017 年 F8 大会，Facebook 发布升级版 Caffe2。

Caffe2 支持单机多卡及多机分布式训练，可在 iOS、Android、树莓派等边缘端部署，调用预训练模型仅需数行代码。英伟达、高通、英特尔、亚马逊、微软等云厂商均已适配。

### 4.6.3 PyTorch：动态图派的“灵活王者”

PyTorch 是基于 Python 的科学计算库，以极致灵活和高速著称，长期支撑 Facebook 内部 ML 与科研业务。开发者选择它的核心理由是原生动态图机制。

早期主流框架（如 TF 1.x、Theano、Caffe）多采用静态图：预先冻结网络结构，数据按固定流程跑。这要求在处理数据前预判并定义所有边界情况。PyTorch 动态图打破此限制，支持随时定义、修改模型，调试体验接近原生 Python，极大提升科研迭代效率。

### 4.6.4 CNTK：微软出品的“速度怪兽”

微软 CNTK（Cognitive Toolkit）内部孵化迭代，现已跻身主流第一梯队。核心优势在于“快”，训练推理速度极具竞争力。全面支持 CPU/GPU 异构计算，上手易学，新手也能快速处理分类、语音、图像识别等任务。

**部署指引：**
下载解压，运行 `Install.bat` 自动配置环境依赖；随后执行 `cntkpy35.bat` 激活环境即可运行。
