## 5.2.2 FFM 训练提速与 Bilinear-FFM 轻量化重构

FFM 采用在线学习迭代参数，为缩短训练周期，可在样本维度实施并行（对应算法首行循环）。引入 OpenMP 多线程机制充分榨取多核 CPU 性能，显著提升吞吐。图 5-6 记录了并行加速比：峰值约 3.5 倍；线程数超 8 后因内存总线争用等瓶颈，收益趋于饱和。

[PRE0]

图5-6 不同线程数下的加速情况

算法 5-3 中，第 4、5 行的大规模循环实仅需遍历非零特征；第 7 行向量内积则借助 SSE3 指令集完成 SIMD 向量化加速。上述工程手段对稀疏线性模型具通用性，但 FFM 本身仍面临参数膨胀、推理延迟高的痛点。

新浪微博算法团队从模型拓扑切入，提出双线性 FFM（Bilinear-FFM），定义如下：

$$\hat{y}(x) := w_0 + \sum_{i=1}^n w_i x_i + \sum_{i=1}^{n-1} \sum_{j=i+1}^n \boldsymbol{v}_i \boldsymbol{W} \boldsymbol{v}_j x_i x_j \quad (5-27)$$

隐向量 $\boldsymbol{v}_i$ 维持 FM 风格（每特征单一向量），交互时插入矩阵 $\boldsymbol{W}$ 显式建模域间关系。新增矩阵 $\boldsymbol{W}$ 支持三种生成策略：
1. **全局共享**：全特征交叉复用单一 $\boldsymbol{W}$，增量参数 $k^2$；
2. **域级共享**：同域特征共享一组 $\boldsymbol{W}$，增量 $f \cdot k^2$；
3. **域对独立**：不同域交叉配专属 $\boldsymbol{W}$，增量 $f^2 \cdot k^2$。

实战中按效果择优。Criteo 与 Avazu 实验表明：配合 LayerNorm 的 Bilinear-FFM 效果与 FFM 持平，参数量仅为后者 **2.6%**。

FM 系算法在工业界落地极广：除推荐召回/精排，搜索排序可融合 Pair-wise Ranking SVM 或 LambdaMART 思想；高实时场景亦可结合 FTRL 做在线更新。

### 5.2.3 GBDT 核心原理与标准流程

GBDT（梯度提升决策树）在深度学习崛起前，长期霸榜搜索排序及粗排阶段非线性高阶特征生成等任务。其回归任务计算管线如下图：

[PRE1]

图5-7 GBDT在回归任务中的一般计算流程

从全称 **Gradient Boosting Decision Tree** 可拆解三大基石：

1.  **决策树基学习器**：采用回归树而非分类树。构建期在非叶节点按特征切分样本，直至触及深度上限或节点样本量下限；叶节点输出该簇样本均值。推理期自根向下路由，落叶即得预测值。
2.  **提升策略**：以加法形式集成多棵弱回归树，逐步逼近真实目标，实现“弱学习器变强模型”。
3.  **梯度优化视角**：每轮拟合损失函数对当前预测值的**负梯度**。该视角统一了回归与分类：将预测值视作待优化参数，梯度下降即模型迭代。若损失取均方差则退化为拟合残差；梯度形式泛化性更强，兼容分类任务。

#### 算法 5-4 GBDT 标准伪代码

**输入**：训练集 $\{(x_i, y_i)\}_{i=1}^N$，学习率 $\alpha$

1.  **初始化常数模型**：$f_0(x) = \arg\min_\gamma \sum_{i=1}^N L(y_i, \gamma)$
2.  **迭代** $t = 1 \dots T$：
    *   **计算伪残差**：$r_i = -\left[\frac{\partial L(y_i, f(x_i))}{\partial f(x_i)}\right]_{f(x_i)=f_{t-1}(x)}$
    *   **拟合回归树**：以 $\{r_i\}$ 为目标训练第 $t$ 棵树 $h(x; w^*)$
    *   **线性搜索步长**：$\rho^* = \arg\min_\rho \sum_{i=1}^N L(r_i, f_{t-1}(x) + \rho h(x_i; w^*))$
    *   **更新集成模型**：$f_t(x) \leftarrow \alpha \rho^* h(x; w^*)$，$f(x) \leftarrow f_{t-1}(x) + f_t(x)$
3.  **输出**：强模型 $F(x) = f_T(x)$

[PRE2]

> 符号表：$y_i$ 真实标签，$r_i$ 负梯度，$f_t(x)$ 第 $t$ 轮弱模型，$F(x)$ 最终集成模型。

**多分类扩展**：为每个类别独立建树序列，预测时累加各类得分再经 Softmax 归一化得概率分布。

### 5.3.3 DIN：候选感知的动态兴趣激活

信息流广告 CTR 预估是商业化核心任务，模型亦可泛化至通用推荐。早期主流 Embedding & MLP（下图）将行为序列简单求和，导致用户兴趣表达与候选广告无关——恰似点菜全凭“随便”，难以精准匹配。

[PRE7]

图5-12 典型的Embedding & MLP结构

**DIN 核心创新**：引入注意力加权池化，兴趣向量随候选广告 $e_A$ 动态生成：

$$v_u = \sum_{j=1}^H a(e_j, e_A) e_j$$

其中 $e_j$ 为行为 Embedding，$H$ 为序列长度。注意力网络 $g(\cdot)$ 输入 $[e_j, e_A, e_j \odot e_A]$ 经 MLP 输出权重，**移除 Softmax 归一化**以保留兴趣强度信息。

图5-13 DIN的模型结构

**1. Dice 自适应激活函数**

**2. Mini-batch Aware 正则化**  
亿级稀疏参数下全量 L2 不可行；仅正则当前 Batch 出现的参数又会因频次差异导致高频特征过度衰减。DIN 推导出近似 Batch 级 L2：

$$\mathcal{L}_{reg} \approx \lambda \sum_{m=1}^B \sum_{j \in B_m} \frac{a_{mj}}{n_j} \|w_j\|^2$$

其中 $a_{mj}$ 指示特征 $j$ 是否在 Batch $m$ 出现，$n_j$ 为全局频次。梯度更新仅涉及当前 Batch 参数，频次自适应平衡衰减力度，实测优于 Dropout 与特征灌入。

### 5.3.4 DIEN：建模兴趣演进的时序动态

用户兴趣随时间衰减、演变，近期行为权重更大。DIN 静态注意力难捕捉此动态，DIEN 在 DIN 基础上引入 RNN 双层结构，显式建模**兴趣演进过程**，整体含三大模块：

[PRE16]

图5-16 DIEN三层架构：兴趣抽取层 → 兴趣演进层（GRU + AUGRU） → 预测层

- **兴趣抽取层**：GRU 编码行为序列得隐状态序列 $h_1 \dots h_H$。
- **兴趣演进层**：引入 **AUGRU**（Attention-based Update GRU），用候选广告相关注意力分数 $a_t$ 调节 GRU 更新门，实现“与目标相关的兴趣记忆保留更久”。
- **预测层**：同 DIN，最终加权求和接 MLP 输出 CTR。
