# 第 3 章 数据分析与可视化

在信息过载的时代，数据已成为驱动决策和推动创新的核心资源。无论是商业智能、科研分析，还是社交媒体趋势、公共卫生政策，海量数据持续产生。数据本身不产生价值，只有通过有效的分析与直观的呈现，才能转化为可执行的洞察，为各领域赋能。

数据分析能从复杂信息中抽离规律、趋势与关联，帮助理解现状、预测方向、优化决策。数据可视化则像一座桥梁，把冰冷的数字变成直观的图形，让数据“开口说话”，提升信息传递效率、揭示背后的故事、激发探索。两者相辅相成，共同构成从数据到洞察的完整链路。随着技术发展与应用场景扩展，其价值将进一步放大。

本章将系统介绍数据分析与可视化的基本概念、关键流程、常用方法与工具，以及它们在实际场景中的作用与实践要点。学习后能够从数据中提炼有价值的信息，并以通俗易懂的可视化形式传递，从而更好地理解复杂数据集、发现隐藏模式、支撑数据驱动决策，为后续深度挖掘与高级建模奠定基础。

## 3.1 描述性分析

### 3.1.1 描述性分析介绍

描述性分析是数据分析的基础类型，聚焦于对数据集基本特征的汇总与描述。通过统计方法与可视化手段，快速把握数据的分布、集中趋势、离散程度以及初步关联，为后续深入分析与建模做准备。

#### 1. 集中趋势的度量

集中趋势用来刻画数据集的中心位置或典型值，常见指标有平均数、中位数和众数。

（2）中位数需先将数据按从小到大排序，位于中间位置的数值即为中位数。若数据个数为奇数，中位数为正中间的那个值；若为偶数，则取中间两个值的平均。

（3）众数是数据集中出现频次最高的值。一个数据集可能有一个众数、多个众数或没有众数。例如：

- 数据集 1：1、1、1、4、5，众数为 1。
- 数据集 2：1、1、3、3、5，众数为 1 和 3，两者均出现两次。
- 数据集 3：1、2、3、4、5，无众数。

#### 2. 离散程度的度量

离散程度用来刻画数据偏离中心位置的程度，常见指标包括极差、四分位差、平均差、方差、标准差、异众比率和离散系数。
