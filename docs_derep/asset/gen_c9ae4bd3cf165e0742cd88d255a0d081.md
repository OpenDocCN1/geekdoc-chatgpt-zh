随着乐乐超市持续扩张，场内被划分为食品饮料区、生活用品区、学习用品区、蔬菜生鲜区等多个分区。假设各分区的货架数目和规格完全一致，并且为每个分区按先后顺序编上分区号。这样要锁定一个具体的格子，就需要四个定位信息：分区号、货架号、排号、格子号。

明白三维数组的构造思路后，四维数组的原理与之相通：把若干套规格相同的三维数组当作整体单元，按顺序串联起来，就得到了四维数组。

凡是借助三个以上维度来组织数据的结构，都可归为多维数组。直白地说，每多一层维度，就相当于对已有规格的数据再做一次有序排列，根本上都是数组套数组的层层嵌套，只不过嵌套深度不同而已。

**12.4.2** **知识精讲**

**1.理解多维数组**

多维数组在编程里十分重要，对初学者来说理解门槛也比较高。为了便于把握，下面用校园场景做个直观说明。

一个班级有 40 名同学，为每人分配唯一的学号，这就形成了一个长度为 40 的一维数组。要在班级里找到王妞妞，只需“学号”这一个坐标即可。

王妞妞→students［36］：学号 36

随后把多个班级按顺序排列并赋予班号，这时定位王妞妞就需要“班号”和“学号”两个坐标，这种一个年级下辖多个班级（一维数组）的组织方式就是二维数组。

王妞妞→students［7］［36］：班号 7，学号 36

再把多个年级按顺序排列并赋予年级号，定位王妞妞就需要“年级号”“班号”“学号”三个坐标，这种一个学校包含多个年级（二维数组）的结构就是三维数组。

王妞妞→students［5］［7］［36］：年级号 5，班号 7，学号 36

如果要做更大的学籍管理，把东城区所有小学按拼音首字母排序并编上学校号，那么找到王妞妞就需要四个坐标：“学校号”“年级号”“班号”“学号”。这种一个学区包含多个学校（三维数组）的结构就是四维数组。

王妞妞→students［16］［5］［7］［36］：学校号 16，年级号 5，班号 5，学号 36

把握多维数组的核心很简单：维度每提升一层，就把低一维的数组视作一个整体元素，再把这些元素按顺序排列成新的数组。维度越多，定位一个元素所需的信息越具体，本质仍是“数组套数组”的逐层嵌套。

**12.6.1** **小故事**

小乐在掌握 C 风格字符串操作后，已能处理超市大部分文本工作，如商品名称录入、地址整理等。但他发现基于字符数组的操作需要逐个处理字符，效率不高，还要时刻关注数组长度、防止越界，稍有疏忽就会出错。是否有更便捷的方式，能像操作普通变量一样简洁地处理字符串，而不必纠结繁琐细节呢？

后来，小乐了解到 C++ 标准库中的 string 类，专门用于处理字符串。它封装了操作细节，无需手动管理存储空间和字符数组限制，可像普通变量一样直接赋值、拼接、比较，简化了字符串处理。对于小乐而言，这意味着处理商品名称、地址等文本信息效率大幅提升，也减少了因字符数组操作不当导致的错误。

**12.6.2** **知识精讲**

**1.string 类的引入**

1）了解 string 类

在 C 语言中，用 C 风格字符串处理文本需要手动管理内存，操作复杂且易错。而 C++ 的 string 类是标准库提供的一种更高级、更方便的字符串处理方式。它封装了字符串操作，自动管理内存，避免了大量手动管理的问题，大幅提升开发效率。

2）string 类的优势

string 类提供丰富的内置函数和运算符重载，使字符串操作更直观。例如可直接用“+”进行拼接，用“==”进行比较。同时，string 类会自动处理内存分配与释放，降低内存泄漏风险。

3）与 C 风格字符串的对比

C 风格字符串基于字符数组，以 '\0' 结尾，需要手动管理内存。而 string 类是一个对象，隐藏了内存管理细节，使用更安全、更便捷。例如求长度时，C 风格字符串需用 strlen 函数，string 类用 length() 方法；复制或连接时，C 风格字符串需用 strcpy、strcat 等函数，string 类可直接用赋值运算符、“+”运算符或 append()，详细对比见表 12-5。
