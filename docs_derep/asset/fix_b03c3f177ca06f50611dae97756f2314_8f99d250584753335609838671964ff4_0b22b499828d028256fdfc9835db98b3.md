## 揭开情感分析的神秘面纱
太乙真人的“情感分析笔”本质上是情感倾向分析技术，即通过解析文本表达的含义判断其褒贬。随着互联网发展，社交网络、电商平台产生海量评论，篇章级、句子级、词语级等不同粒度的情感分析需求日益增加。法宝完成的是句子级分析，需要经过数据清洗与标注、中文分词、特征选择与表示、分类函数设计、模型训练与评估五个步骤。

## 数据清洗与标注
收集到的文本常混杂噪声，例如：
> “我真太敬佩#英雄小哪吒#了，是我的楷模.https://ww3.sinaimcn/.jpg”
其中 # 符号、网址链接、英文标点等对分析无用，需统一标点、去除特殊符号如 #、\t、删除 URL 等。清洗后得到：
> “我真太敬佩英雄小哪吒了，是我的楷模。”

随后为训练语料打标签，根据文本含义赋予“正向”或“负向”，构建训练集。每条数据包含文本内容和标签两部分。

| 文本内容 | 文本标签 |
| --- | --- |
| 我真太敬佩英雄小哪吒了，是我的楷模。 | 正向 |
| 哪吒有点法术就滥杀无辜，太嚣张了。 | 负向 |

## 中文分词
判断句子情感的关键在于抓住决定倾向的重点词，这就需要把句子切分为词。

早期常用基于词典的正向最大匹配，先设定最大长度 n，从句首取 n 个字与词典匹配，若匹配成功则切出该词，否则逐字删减末尾再尝试，直到匹配为止，再对剩余部分重复。

设词典为{“真”“敬佩”“太”“我”“英雄”“，”“小”“哪吒”“了”“楷模”“的”“是”“。”}，待分词句为“我真太敬佩英雄小哪吒了，是我的楷模。”，最大长度 4 时：
1. “我真太敬”匹配失败；
2. “我真太”匹配失败；
3. “我真”匹配失败；
4. “我”匹配成功，切出“我”，剩余部分继续处理。
最终结果：“我 真 太 敬佩 英雄 小 哪吒 了，是 我 的 楷模。”

## 特征选择与表示
并非所有词都对情感有帮助，例如“哪吒”“太”“了”在正负样本中都会出现。全量使用会拖慢训练并降低精度，需要筛选与情感分类更相关的词。

TF-IDF 是常用方法，词在一篇文本中出现频率高而在其他文本中稀少，则区分度高。可计算 TF-IDF 并选取值大的词作特征，如“我 真 太 敬佩 英雄 小 哪吒 了，是 我 的 楷模。”中“敬佩”“英雄”“楷模”被选为特征词。

特征选择还有互信息、信息增益等方法，本书主要介绍 TF-IDF。

选出特征词后需转为数值形式。早期用独热编码：先建词表编号，生成全零向量，文本中出现的词对应位置置1。缺点是维度极高且不含词间关系。

深度学习常用 Word2Vec 生成词向量，维度通常几十到几百，能保留语义并体现相似性，如“国王”向量 - “男人”向量 + “女人”向量 ≈ “皇后”向量。

Word2Vec 包含 CBOW 与 Skip-gram 两种神经概率模型，前者通过上下文预测中心词，后者由中心词预测上下文。

于是把该句特征词“敬佩”“英雄”“楷模”的词向量加权求和，得到文本特征向量。分类问题转化为对空间中点的划分。

## 分类函数设计
分类函数负责把特征向量映射到情感类别。可用线性判别 f(x₁,x₂,...,xₙ)=w₁x₁+w₂x₂+...+wₙxₙ+b，但输出值过大时阈值难定。常用 S 形逻辑斯蒂函数把线性输出从 (-∞,+∞) 压缩到 (0,1)，结果具有概率意义，如 0.8 表示 80% 概率为正向。
