ChatGPT 看似具备创作能力，根本上是训练阶段积累了海量的文本素材，得以在特定语境下模仿人类表达并产出符合语法规范、具备一定逻辑性的内容。这些素材涵盖故事、诗歌、对话等富有创造性的形式。实际运用时，只要提供明确的提示和上下文，它就能围绕主题进行相关创作。

##### 5. ChatGPT 的使用边界
ChatGPT 的短板主要集中在上下文把握、对话连贯、专业知识覆盖、情感理解以及道德伦理等方面。

- 上下文理解：ChatGPT 在自然语言处理上表现突出，但在面对复杂背景或表述含糊的问题时，常会捉襟见肘。它高度依赖问题本身给出的信息，对于多义词、歧义性提问容易产生误解。
- 对话连贯性：由于建模方式是序列式，长对话中容易出现断层。有时会遗忘前面提到的细节，或在连续追问中丢失主题一致性，导致回复不连贯或偏离用户预期。
- 领域知识局限：模型是通过大规模文本训练而成，并不具备深度的专业积累。遇到高度专业或细分领域的难题，往往只能给出泛泛之谈，难以提供深入洞察或精准解答。
- 情感情绪理解：对情绪和情感的感知能力有限，很难准确捕捉用户的情感底色和对话中的情绪变化。因此在涉及情感类话题时，回应常缺乏共情和敏感度。
- 道德伦理风险：模型基于预训练数据生成，在敏感或争议议题上可能输出不当内容。使用者需保持审慎，必要时引入人工判断或额外验证。

因此使用时应正视这些限制，关键信息最好通过可靠来源进行交叉核对。

#### 1.1.3 ChatGPT 的技术创新
ChatGPT 在理解与生成自然语言上实现质变，背后依托四大技术进展，即大语言模型、更大规模语料、更快算力以及更优的工程化优化，后者是 ChatGPT 的特色。

##### 1. 大语言模型 LLM
LLM 是一种基于大规模深度神经网络的人工智能模型，用于理解与生成自然语言文本。它在大规模文本上预训练，可从输入中学习语法、语义和上下文，并输出近似人类的语言。ChatGPT 正是生成式大语言模型的一种。

LLM 通过复杂计算把句子拆解为 token 集合，并对 token 的高维向量进行运算，语义理解与加工就在这个过程中完成。计算结束后，输出值再转回 token 即可实现语言生成，这正是 ChatGPT 的工作方式。它能以自然语言与人互动，正因其在 token 处理上的精细度，以及更大的语料、更快的算力和更好的工程优化。

##### 2. 更大的语料规模
token 的丰富度直接决定语义表达能力。衡量 LLM 规模最直接的指标是可处理的 token 数量，即支持多少种不同的 token。截至 2023 年 7 月，ChatGPT 可处理的 token 规模已达约 3000 亿个。

这意味着它能从 3000 亿种语义角度解析输入，也意味着底层神经网络至少需要同量级的训练样本。关于训练原理详见第 2 章，这里用个直观类比：LLM 如同一块未经打磨的钻石，训练就是打磨过程。打磨后，一束光以特定角度射入会折射出彩虹，这两束光可视为模型的输入与输出。训练时我们清楚每束光的折射结果，据此打磨钻石。若想让钻石具备 3000 亿个折射面，就需要在表面雕刻相应数量的平面。对 LLM 而言，每个平面对应一组参数，每一刀雕刻都需要一个训练样本。现代 LLM 能处理海量 token，关键在于其具备大规模快速计算能力。

##### 3. 更快的计算速度
深度神经网络推高了模型规模，而新世纪的并行计算设备与技术，特别是 GPU 及并行计算，提供了精准高效的加工手段。但随着模型体量膨胀，这把“刀”逐渐力不从心，促使深度学习向工业化演进。

当前大模型规模下，单机 GPU 已难以满足存储与训练需求，往往需要成千上万台高性能 GPU 服务器协同。普通用户既难以自行训练，也难以存储此类模型。于是 LLM 从计算模型演变为类设备生产资料：拥有算力资源的大公司在自有环境中完成预训练，再向公众开放模型。用户无需经历冗长训练，直接使用预训练成果，这就是“预训练大模型技术”，也是 ChatGPT 中的“P”。

ChatGPT 是将预训练大模型产品化的典型。对普通用户而言，无需关心背后海量参数，只需输入自然语言即可获得自然语言回应。

##### 4. 更好的工程优化
ChatGPT 取得广泛认可，部分源于出色的产品力，关键在于工程优化的创新。首先，它聚焦 token 解码而非编码。在 LLM 的三大功能中，ChatGPT 的 G 对应解码，即把无语义的 token 向量解码为有意义的自然语言序列。这使生成文本更贴近人类自然表达，而非机器生硬输出，更易被接受。

其次，训练中采用人机协同策略，即强化学习。第一步模型根据输入生成输出，第二步人工对输出打分，高分奖励、低分惩罚，模型据此趋利避害，产出更符合人类认知的语言。

再者，会话中保持 token 一致性。训练完成后，用户输入并非直接进入模型，而是先经过“包装”处理再输入，从而提升对话连续性，也便于用户定制会话场景，具体将在 1.3 节展开。

此外，ChatGPT 还提供丰富的产品接口扩展能力。这不属于 LLM 本身，而是产品设计带来的便利与可拓展性。

#### 1.2.3 ChatGPT 提示词的使用
实际使用中，提问的对齐度越高，语义越清晰，模型越容易给出准确答案。对齐性是上下文连续性和词汇指代一致性的综合体现。前者要求话题贯穿全程避免逻辑跳跃，后者要求名词与代词如他、你、我等指向唯一明确。提升对齐性可让模型语义更集中，提高对话质量。这种技术即提示词工程。

##### 1. 何为提示词
提示词是用户向 ChatGPT 提出的需求。会话虽以自然语言进行，但其中最精炼明确的语义信息即为提示词。例如会话 1.2 问题 4，“小王对 NLP 比较感兴趣，这本书的书名可能是什么？”中的关键提示词是“NLP”和“书名”，其余为承上启下的联系信息。问题 5 中，“这些著作”为连接提示词，将前文书名传递过来；“主要观点和贡献”则是规定回答内容范围的提示词。

会话 1.3 中“补全以下语句”和“请解释”即为提示词。

> 会话 1.3 问题 1：

> 补全以下语句，床前明月光

> 会话 1.3 回答 1：

> 疑是地上霜，举头望明月，低头思故乡。

> 会话 1.3 问题 2：

> 请解释，床前明月光

> 会话 1.3 回答 2：

> “床前明月光，疑是地上霜”，这是中国唐代诗人李白创作的《静夜思》的开头两句。这两句诗描绘了一个人在夜晚躺在床上，看到明亮的月光，心生疑惑是否是地上凝结的霜。

会话 1.4 显示，ChatGPT 并未直面颜色能否用数字表示的矛盾，而是纠结于“颜色的数字”是否准确，实际上它在回答“天空的颜色是()，转化为数字为()”。这说明“转化为数字”的分句起到了不当提示词的作用。

> 会话 1.4 问题 1：

> 天空是什么颜色的？请用数字回答我的问题

> 会话 1.4 回答 1：

> 天空在白天通常呈现蓝色，尤其是在晴朗的天气条件下。但是，天空的颜色并不是固定不变的，它会受到很多因素的影响，如日出、日落时的红、橙色，以及云层的遮挡和湿度的变化等。因此，无法用一个准确的数字来描述天空的颜色。

> 会话 1.4 问题 2：

> 一天有多少秒？请用数字回答我的问题

> 会话 1.4 回答 2：

> 一天有 24 小时，每小时有 60 分钟，每分钟有 60 秒。因此，一天总共有 24×60×60=86400 秒。

在问答 1 中，天空颜色无法用数字描述，故无法按要求作答；问答 2 中，一天秒数可用数字表示，故给出正确结果。

##### 2. 用好提示词的几个准则
提示词能有效约束模型反馈行为，被业界视为提示工程技术，即用户与 GPT 模型交互的方式。

- 好的提示词具有排他性，避免歧义。
- 好的提示词描述性强，多用类比举例界定问题范围。
- 好的提示词目标明确，需规定回复针对何问题、从哪方面展开、遇何情况应如何回复。
- 提供提示词时不必吝啬，可反复重申以包裹问题。
- 可尝试调整提示词与问题的顺序，因模型侧重点可能与预期不同，多试几种排列可找到最优方案。
