触发后，Agent 会在后台抓取指定的网页内容，通过 MCP 工具把原始材料同步到 NotebookLM，并自动生成摘要写入笔记。等待数秒，机器人就会返回“已成功将 DeepSeek API 计费标准保存到笔记”，操作步骤见图 14-3。

## 14.5 总结

本章说明了 OpenClaw 如何借助 MCP 机制接入外部优秀的 AI 服务，成功把 Google NotebookLM 接入 OpenClaw 生态，从而弥补本地 Agent 在超长材料解析与低价知识沉淀上的不足。介绍了 MCP 服务的部署配置方法，以及在 SOUL.md 文件里设定 Agent 优先检索外部知识库的配置思路，并以飞书搭建了一个简洁的信息采集-智能问答闭环。
