# 七、ChatGPT辩论陪练实用技巧总结

把 ChatGPT 当作庭审辩论的对练对手时，我们积累了几条可提升演练效率的做法：

- 明确角色与目标：将 ChatGPT 视为虚拟对手，并先定好使用目的。常用的提示方式是：“请你扮演 ××× 领域的专业律师，代理原告 ×××，我来代理被告 ×××”，这样角色分工和演练目的就能被迅速理解。
- 约定输出格式：可预先设定固定的交互方式，让 ChatGPT 有序列出反驳。例如提示：“我会依次提出观点，请逐条反驳，每次反驳不少于 3 点，每点约 250 字，逐条呈现。”从而来约束作答形式。
- 补充细节指引：提问时要交代清楚法律背景、案情要点及相关规范，以便模型基于这些信息作答。比如在刑事案件演练中，除了交代背景与事实，还会附上具体法条，以引导模型给出更具针对性的观点与反驳。
4. 核查观点与依据：ChatGPT 在演练中提供的观点与依据未必完全准确或完全适用。法律人仍需保持专业判断，对其观点与依据进行核实评估，确保引用准确可靠。

# 二、把编程看作与机器对话的外语
编程本质上也是外语，一种用来与计算机交流的语言。

人类使用自然语言，计算机读不懂，它只能识别莱布尼茨提出的“二进制”。二进制只能由 0 与 1 组成，即便能读，也极不高效。因此需要借助语言工具实现高效沟通，书中大量使用的 Python 就是其中一种“外语”。

人把思想和自然语言转为代码，如 Python，计算机再按规则把代码转为二进制并执行，对话就此建立。

大多数人的第一行代码都从“Hello World”开始，意为“你好，世界”。该说法源于经典教程《The C Programming Language》。以 Python 为例，要让计算机显示‘Hello World’，只需输入 “print(‘Hello World’)”。

拼写格式正确时，代码会被转为二进制，计算机“听懂”指令，并在输出界面打印出 Hello World。

无论代码多复杂，本质与 print 交互相同，都是用有规律的语言，让与你语言不通的计算机“外乡人”听懂指令，完成任务。所以编程就是一门外语。
