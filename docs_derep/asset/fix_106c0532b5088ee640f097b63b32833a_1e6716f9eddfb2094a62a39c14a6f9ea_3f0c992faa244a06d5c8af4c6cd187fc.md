#### 2.3.2 JSON 格式约束的在线调用

## 第3章 提示工程与DeepSeek提示库

在大语言模型的输入输出机制中，文本提示 在某些情况下会配合图像、音频等模态信息，共同构成模型生成特定输出的核心输入。值得注意的是，撰写提示并非数据科学家或机器学习工程师的专属工作，它对所有人开放。然而，要设计出最大化模型效能的提示，却是一项极具挑战的任务。

提示的有效性并非孤立存在，而是受多重因素共同影响。从模型本身，到训练数据；从模型配置参数，到提示的措辞；从语气风格，到结构布局；乃至更广的上下文环境，都深刻影响最终效果。正因如此，提示工程本质上是一个不断迭代优化的循环过程。

提示设计不当容易导致模型给出模糊或不准确的回应，进而削弱其提供有价值信息的能力。因此构建提示时需综合考量上述因素，确保在高质量输入下获得更精准、更有意义的输出。

### 3.1 提示工程核心原理

大模型在使用时可被视为一个预测引擎。该引擎以顺序文本为原料，依托于海量训练数据中学习到的知识与模式，精准预测下一个应出现的词元 token。大型语言模型如同永不疲倦的智者，被设计为反复执行这一预测过程，每一次预测都基于前文与自身的“学识”，逐步构建出连贯且逻辑自洽的文本序列。
