科幻影视里描绘的往往是能自主思考的强人工智能，可当下真正跑起来的成果，绝大多数都来自弱人工智能。强人工智能的探索才刚刚起步，学界大致分出两条线来走。

一条是从下往上堆能力，目标是造出能完成人类任何任务的通用智能体，让它先在跨领域的难题上自如应对，再顺着这条线追问人类智慧的本质。大家现在说的 AGI 基本就指这条路线。近几年靠着 ChatGPT 等产品的火爆，解决通用问题的“小目标”算是有了初步进展，但离真正摸清智慧是怎么产生的、“大目标”仍远得很。

另一条是从上往下拆解，先把人类的智慧拆开再模拟出来。比如对大脑做精细建模，把结构和功能扫描进计算机里复现全部认知；再比如做“人工意识”的理论研究，让机器具备自我觉察和主观体验。这一方向已经探索了七十多年，可到现在实质性进展几乎为零，连正经的学术活动都寥寥无几。

因此下面谈到的案例，度量标准都按弱人工智能来。把人工智能的效果拆成一个个单项技能，和人类在该项上的表现直接对比，看机器是落后多少，还是已经超前多少。只看解决问题的外部结果，不琢磨机器内部怎么“想”，也不讨论意识、情感、意志这些话题。

### 9.3 人机对决的赛场

接下来会从信息识别与理解、输入信息后的处理决策、艺术创作力、工程运动技能、对抗性竞技游戏这几个维度，挑出当前人工智能的顶尖案例，作为人与机器的竞技场，来判断在各自项目上谁更强。

#### 9.3.1 信息识别

机器的信息识别能力，指的是对图像、视频、声音等自然输入能否正确接收并解析。能准确识读外部信息，是任何智能体认知的起点。

常被提及的 ImageNet Large Scale Visual Recognition Challenge ILSVRC 就是全球计算机视觉的竞技场。2015 年微软研究院的残差网络 ResNet 把分类错误率压到 3.57%，首次低于人类平均水平 5.1%。2016 年和 2017 年错误率进一步降到 2.9% 和 2.3%，到 2017 年几乎所有决赛模型都超过了人类平均水平。

为避免像某些媒体那样一句话宣布机器打败人类，我们先弄清楚比赛到底在比什么。

自创办以来，ILSVRC 基本包含三大主题：

• 图像分类 Image Classification：判断图里最主要的物体，允许输出最多五个名称，只要命中正确答案就算对。
• 单物体定位 Single-object Localization：在分类基础上给出包围框，标出物体位置和比例。
• 物体检测 Object Detection：在定位基础上识别图里多个物体并分别框出。

图 9-1 是三项任务的测试样例，是一名铁匠打造铁桶的画面。分类要求输出 Steel drum，允许最多五项；定位要求在铁桶上画框；检测要求把画面所有主要物体都找出来。

#### 9.3.2 信息理解

即便承认机器在声音、图像“识别”上接近人类，“理解”能力，比如把图片中不同对象的常识关联起来，依然是人类优势。人类看图不止看出“是什么”，还会综合行为、逻辑关系，常识来自日常积累。

比如图 9-4 的两张图，人类立刻能理解成“棒球手准备挥棒”和“巴士停在高楼旁”。棒球手能击球、建筑相对汽车高相对山矮，这些常识并不在像素里。没有多模态大模型前，机器要生成文字描述，就必须依赖海量的常识库和上下文技巧，极度依赖人工建设。

2017 年 7 月，计算机视觉与模式识别大会 CVPR 以“超越 ILSVRC” Beyond ILSVRC 为主题召开研讨会，公布了当年的比赛结果。李飞飞宣布 ILSVRC 在图像分类上已达成目标，历经七年的 ImageNet 大规模视觉识别挑战赛在 2017 年正式结束。完结也是新起点，此后视觉研究更聚焦图像理解。接替方案之一是苏黎世理工与谷歌联合提出的 WebVision，目标从分类转向理解。

图 9-4　机器自动生成图像说明¹⁸⁸

近几年得益于大语言模型的突破，学者开始用“文字”这种高度压缩的知识载体来帮助理解图片，形成了视觉语言对齐 Visual Language Alignment 的思路，把图像实体映射到语言词汇，利用自然语言处理的语义技巧迁移到视觉。OpenAI 提出的对比语言-图像预训练 CLIP Contrastive Language-Image Pre-training 就是典型做法，通过正负样本对齐视觉和语言特征，实现多模态映射。

即便如此，最前沿的大语言模型对文字背后实体关系的深层理解也只是相对准确。2016 年斯坦福华人学者助理教授珀西 Percy Liang 建立了斯坦福问答数据集 SQuAD Stanford Question Answering Dataset，用来训练和测试英文阅读理解。数据集选自维基百科 536 篇文章，切成 23215 个段落，通过众包为每个段落提出 3 到 10 个问题，共产生 107785 个问答对。SQuAD 2.0 还额外加入了 5 万个看似合理但依据文章无法回答的问题，增加难度。

图 9-5 是 SQuAD 1.0 的公开样例，片段介绍降水成因，第一个问题“什么造成降雨”需从第一句推理出“重力”，第二个问题需理解“包括”和“其他形式……除了……”的逻辑，通过排除得出答案。答案词都来自原文。

[PRE5]

图 9-5　SQuAD 1.0 数据集的公开测试用例

评测用 F1 分数和精确匹配度 Exact Match。F1 是精确率和召回率的调和平均，表示模糊匹配度；精确匹配要求一字不差。

SQuAD 发布后成为机器阅读理解的权威基准，吸引了谷歌、卡内基梅隆、斯坦福、微软亚洲研究院、艾伦研究院、IBM、Meta 等参与，也包括后来的 ChatGPT。测试结果¹⁸⁹  显示 ChatGPT 在 SQuAD 2.0 上表现不佳，原因很快被定位：面对 5 万个无法回答的问题，模型仍自顾自编造答案，出现“幻觉” Hallucination。常见幻觉包括事实性错误、虚构引用、错误推理、技术性误导。幻觉看起来合乎逻辑更危险，尤其在专业、法律、医疗等敏感领域。

ChatGPT 界面下面也提示“也可能会犯错，请核查重要信息”。

在情感、价值取向类问题上，机器理解更弱，很多人类也答不好。比如理解朱自清《背影》蕴含的深意¹⁹⁰。

但限于说明文、科学文献、条款规定这类材料，SQuAD 测试显示机器的理解水平已接近甚至不低于人类。相比从 20 世纪 60 年代 ELIZA 开始的基于人工语料库的问答系统，机器能直接用面向人类的文字材料回答问题，已是巨大进步，让自然语言处理摆脱“有多少人工才有多少智能”的困境。

总体看，信息理解方面机器进步明显，但人类仍更强。大脑无时无刻在接收多类型信息并自动关联，形成知识和常识。在封闭领域且信息完整时机器能处理得和人类一样好；但在开放问题空间，缺少从出生就持续建设的常识库，机器处理就会捉襟见肘，甚至因幻觉给出错误答案，这是目前综合信息理解能力仍逊于人类的根本局限。
