## 4.1 AI 辅助搭建薪酬调研方案

问题情景
1. 公司正准备重塑薪酬体系，但外部薪资采集耗时、对手信息不透明，很难给出有说服力的定价依据该怎么办？
2. 过去的薪资研究多靠人工拼凑碎片数据，市场变化快、企业诉求不同，结论很容易过时或偏离经营实际。需要结构化的数据架构和动态研判能力，才跟得上业务节奏。
3. 体量小的公司负担不起深度定制，只能使用市面通用模板，落地效果自然有限。
4. 可以借助AI实现需求聚焦。先梳理核心职位清单，优先对高流失风险或战略关键岗位开展深度追踪，其余岗位以行业基准为参考。这样既控制花费，又先解决燃眉之急。
5. 管理层希望压缩人力开支，员工却普遍反映报酬偏低，这种拉扯用数据如何协调？
6. 客观的调查结果能打破主观博弈。用分位展示企业薪资在行业中的真实位置，再结合离职与薪资的相关性，用事实促成共识。调研的意义在于为决策提供公信力。

### AI 提问结构
通用提问模型 = 目标锚定 + 数据清单 + 分析视角 + 交付规范

#### 目标锚定
厘清研究要服务的经营诉求，确保模型输出直指决策点。

提问要素
- 调查边界：全员、单一部门或特定层级。
- 业务阶段：扩张期重人才吸引，成熟期重保留成本。
- 决策层级：高层要战略判断，中层要可执行方案。

#### 数据清单
明确所需数据种类、来源与精度，指引模型筛选有效信源。

提问要素
- 外部信息：行业薪酬报告、招聘平台、同业挂牌信息。
- 内部信息：职位评价结果、绩效分布、离职访谈记录。
- 特殊需求：区域差异、新兴职位对标等。

#### 分析视角
确定研究需覆盖的关键角度，实现结构化呈现。

提问要素
- 横向对比：同行业同职位中位数、分位分布。
- 纵向关联：薪资与绩效、职级的关联性。
- 风险预警：高薪职位冗余、低薪职位流失风险。

#### 交付规范
明确呈现形式与管理支持需求，将分析转化为工具。

提问要素
- 视觉化需求：图表类型、标注方式。
- 行动建议：调薪比例建议、职位优化清单。
- 附件需求：原始数据表、参考资料清单。

### 材料准备
| 要点 | 内容 |
| :--- | :--- |
| 公司基本资料 | 组织架构图、职位说明书、近三年薪酬档案等 |
| 业务战略材料 | 未来一年业务目标、关键人才需求清单等 |
| 行业参考数据 | 第三方薪酬报告、本地招聘平台截图等 |
| 内部痛点记录 | 近半年薪酬相关投诉、离职访谈案例等 |

### 实战案例
#### 目标锚定
我司为约500人规模的互联网 SaaS 企业，明年计划进入华南。销售团队现30人拟扩至80人，需设计薪酬研究方案，重点解决外部竞争力不足致招聘困难，以及老员工对新老倒挂的不满。

#### 数据清单
需获取以下资料
1. 外部信息：广州、深圳同业大客户销售职位的薪酬中位数及签约奖金政策。
2. 内部信息：现有销售近12个月业绩达成率、入职半年内新人离职率。
3. 特殊需求：对比无客户资源新人与自带客户空降高管两类人群的薪酬结构差异。

#### 分析视角
请协助分析
1. 横向对比：按城市、职级、客户类型分层计算薪酬分位。
2. 纵向关联：分析高绩效销售前20%的薪酬竞争力与留存率关系。
3. 风险预警：标注薪酬低于行业25分位的职位，并测算调至50分位所需预算增量。

#### 交付规范
请输出报告
1. 输出形式：含现状诊断、对标建议、成本测算三部分的 PPT。
2. 行动建议：提供3套调薪方案及配套沟通话术。
3. 附件需求：附数据来源链接与关键假设说明。

### 注意事项
| 要点 | 内容 |
| :--- | :--- |
| 动态校验 | 模型生成的分位需与本地市场面试反馈交叉核对 |
| 文化适配 | 方案要结合公司支付能力，避免过度对标导致成本失控 |
| 落地跟踪 | 方案中需预设3个月后的效果评估指标 |

## 4.2 AI 横向比对薪酬信息渠道

问题情景
近期薪资研究发现不同来源数据差异很大。行业报告称市场平均涨幅5%，猎头却反馈核心岗位至少涨8%才能留人，员工满意度调研又显示对现有体系不满。该如何统一口径？

薪资渠道众多，企业常只是堆砌数据，却未搞清各渠道的适用场景和偏差来源。行业报告体现宏观趋势，猎头数据偏向稀缺人才，员工调研则暴露内部公平问题。

盲目依赖单一来源会误导决策。去年仅参考行业报告调薪就导致关键人才流失。不同渠道在颗粒度、立场上差异明显：行业报告可能滞后，猎头报价常有水分，员工调研易受情绪干扰。核心是建立对比框架，明确各渠道的优势局限与适用场景。

手工横向对比耗时耗力，尤其要在区域、层级等维度细分。

借助 AI 可快速结构化比对渠道维度，如样本量、更新频率、职位覆盖度，并交叉验证关键指标如行业涨幅与离职率关联，帮助判断哪些渠道适合定战略，哪些适合战术调整。

### AI 提问结构
通用提问模型 = 背景定位 + 渠道痛点梳理 + 对比需求细化

#### 背景定位
描述公司行业、规模、薪酬现状与研究目标，帮助模型把握背景。

提问要素
- 公司特征：如制造行业/500人/快速扩张期。
- 职位类型：如研发岗需对标互联网行业。
- 区域分布：如覆盖一线及二线城市。
- 研究目的：如提升薪酬竞争力或控制人力成本。

#### 渠道痛点梳理
列出当前使用的渠道及其具体问题，明确模型重点分析的矛盾。

提问要素
- 渠道类型：第三方咨询报告、招聘网站、猎头反馈等。
- 问题表现：如报告未覆盖小微企业职位。
- 影响后果：如可能导致定薪低于市场水平。

#### 对比需求细化
指定模型输出的对比维度及结论形式，将需求转化为可执行任务。

提问要素
- 对比维度：数据时效性、职位覆盖度、成本等。
- 输出要求：按优先级排序各渠道适用场景。
- 决策支持：推荐3套性价比较高的渠道组合。

### 材料准备
| 要点 | 内容 |
| :--- | :--- |
| 内部薪酬数据 | 职级体系、近三年调薪记录、离职面谈薪酬抱怨等 |
| 外部渠道清单 | 已用研究渠道名称、订阅报告、合作猎头公司列表等 |
| 业务战略目标 | 未来一年招聘计划、重点保留职位清单等 |
| 行业特性 | 对标公司名单、区域薪酬差异政策等 |

### 实战案例
#### 背景定位
我是一家智能制造企业，高端装备制造行业，800人规模，业务覆盖长三角与珠三角。明年计划扩招200名研发人员，现有薪酬沿用传统制造标准，算法工程师招聘达成率仅40%，需重新定位市场水平。

#### 渠道痛点梳理
当前使用三个渠道
1. 行业协会报告：滞后半年，未细分算法职位子类，视觉算法与控制算法混同。
2. 招聘网站爬虫：样本不足15家公司，且含大量实习岗拉低均值。
3. 猎头反馈：集中于头部公司，报价偏高，如建议涨幅15%，实际市场仅8%。

#### 对比需求细化
请协助
1. 结构化对比三渠道在数据时效性、职位细分度、样本代表性的优劣。
2. 推荐补充渠道：需覆盖长三角新兴公司、季度更新、可区分算法子类。
3. 生成应用建议：针对资深专家与初级工程师分别推荐主备渠道组合，并估算年成本。

### 注意事项
| 要点 | 内容 |
| :--- | :--- |
| 多源交叉验证 | 模型对比结果需与内部离职分析、外部面试反馈交叉验证 |
| 警惕样本陷阱 | 标注各渠道样本量、公司规模分布，避免拿大公司数据指导中小企业 |
| 动态更新机制 | 快速变化行业每季度重跑对比，记录渠道质量变化 |
| 人工干预决策 | 模型输出优先级后，最终需结合公司支付能力决策 |

## 4.3 AI 生成薪酬调研问卷

问题情景
1. 公司准备调整薪酬体系，内部调研数据严重不足。员工对现有结构满意度不一，外部市场数据又难精准获取，方案缺乏依据。
2. 科学设计问卷能补足短板。传统薪酬问卷针对性弱、反馈模糊、收集效率低，难以及时匹配市场变化。优化结构和采集方式可为决策提供更可靠支撑。
3. 市场对标显示不同层级薪酬差异大，同一问卷难覆盖技术岗、职能岗等个性化需求。技术岗更关注绩效奖金，管理岗更看重长期激励，如何差异化处理？
4. 需要分层设计维度。先按职位类别拆分核心诉求，再结合职级设置权重。技术岗问卷侧重绩效占比、技能补贴，管理岗侧重股权激励、晋升通道。
5. 员工参与度低也是痛点。问卷过长导致敷衍填写，影响数据质量。如何兼顾深度与效率？
6. 可通过问题聚焦和交互设计提升质量。用选择题替代开放题，减少主观描述；借助逻辑跳转减少无效作答；结合匿名机制和结果回馈可提升参与意愿。

### AI 提问结构
通用提问模型 = 研究目标 + 行业特性 + 问卷结构

#### 研究目标
明确问卷想解决的核心问题，需聚焦可量化。

提问要素
- 目标类型：外部对标、内部公平、员工诉求等。
- 数据用途：用于薪酬体系调整、晋升标准制定或预算分配。
- 关键指标：基本工资、绩效奖金比例等需采集点。

#### 行业特性
描述行业薪酬特征与调研难点，帮助模型生成符合惯例问题。

提问要素
- 职位类型：技术、销售、职能等。
- 区域差异：一线与二三线薪酬基准差异。
- 行业痛点：如互联网行业35岁焦虑对应的长期激励需求。

#### 问卷结构
规划问题逻辑顺序与呈现方式，提升回收率与数据质量。

提问要素
- 问题类型：单选、多选、量表、开放题配比。
- 逻辑跳转：按职级跳转薪酬模块。
- 防偏差设计：设置反向问题验证回答真实性。

### 材料准备
| 要点 | 内容 |
| :--- | :--- |
| 公司薪酬基础数据 | 职级体系、薪酬带宽、历史调薪记录等 |
| 行业对标信息 | 目标调研公司名单、关键职位列表等 |
| 员工特征标签 | 司龄、职级、部门、绩效等级分布等 |
| 管理层诉求 | 本次调研需验证的核心假设等 |

### 实战案例
#### 研究目标
我司为500人规模跨境电商公司，计划20××年优化全岗位薪酬体系。需通过问卷明确
1. 核心职位在华南地区的薪酬竞争力。
2. 员工对现有福利满意度及改进诉求。
3. 高绩效员工连续两年A对长期激励的接受度。

#### 行业特性
1. 职位特征：运营岗存在旺季加班、淡季调休特性。
2. 区域差异：需对比广州、深圳、东莞薪酬水平。
3. 行业痛点：年离职率18%，需识别薪酬保留关键因素。

#### 问卷结构
请生成逻辑严谨的薪酬调研问卷，要求
1. 问题顺序遵循由浅入深认知规律。
2. 包含3处逻辑跳转，如高绩效员工跳转至长期激励问题。
3. 标注每个问题的设计目的及数据分析方法。
4. 分4部分：基础信息、薪酬模块、福利偏好、开放题。

### 注意事项
| 要点 | 内容 |
| :--- | :--- |
| 预测试验证 | 正式发放前抽10%员工试填，修正理解歧义问题 |
| 文化适配 | 避免行业黑话，如将薪酬带宽改为薪酬范围 |
| 结果解读 | 模型问卷报告需结合人工经验判断，如开放题吐槽需关联考勤数据验证 |

## 4.4 AI 驱动薪酬市场对标

问题情景
1. 招聘中发现候选人薪酬期望普遍高于预算，内部员工也抱怨薪酬缺乏竞争力。内忧外患如何平衡？
2. 可通过市场对标分析。把公司薪酬与行业报告、竞争对手数据对比，能精准定位竞争力。例如市场均价1.5万，公司仅1.2万，就需评估对招聘与留存的影响。
3. 但行业报告滞后、竞争对手数据难获，这样的分析能落地吗？
4. 对标不仅是数据对比，还可做趋势预判。即便数据不完美，也能通过头部公司薪酬涨幅、核心职位溢价等判断策略是否偏离市场。
5. 分析显示薪酬低于市场，直接加薪就能解决问题吗？
6. 不一定。对标的最终目的是差异化定位。技术壁垒强可降基础提绩效与股权，红海领域则需关键职位薪酬达到行业前20%。

### AI 提问结构
通用提问模型 = 业务背景描述 + 数据缺口说明 + 分析目标定义

#### 业务背景描述
描述薪酬策略底层逻辑与市场环境，帮助模型理解策略。

提问要素
- 公司规模：如500人互联网公司。
- 行业属性：如 SaaS 赛道。
- 现有薪酬结构：基础薪酬60%、绩效30%、福利10%。
- 关键职位清单：后端开发、大客户销售等。

#### 数据缺口说明
说明现有数据与对标所需数据的差距，明确模型需填补空白。

提问要素
- 缺失数据类型：如缺乏竞争对手校招薪酬数据。
- 数据时效性：如行业报告为20××年数据。
- 数据维度：如仅覆盖一线，未覆盖新一线城市。

#### 分析目标定义
将抽象需求转为模型可执行任务清单。

提问要素
- 竞争力评估：判断职位薪酬是否低于市场P50。
- 策略建议：推荐3种调整方案并测算成本。
- 风险预警：若明年涨幅达10%，需预留预算。

### 材料准备
| 要点 | 内容 |
| :--- | :--- |
| 各职位薪酬数据与结构 | 基础薪酬、绩效奖金、福利等 |
| 近三年调薪记录 | 调薪幅度、覆盖范围等 |
| 外部薪酬数据 | 权威行业调研报告、竞争对手薪酬信息等 |
| 公司战略与人才策略 | 未来三年扩张计划、关键人才保留目标等 |

### 实战案例
#### 业务背景描述
我司专注企业级 SaaS 初创公司，员工120人，研发占比60%。薪酬结构为基础60%+绩效30%+股权10%，研发反馈基础薪酬偏低，面试通过率不足30%。

#### 数据缺口说明
1. 缺乏竞争对手3~5年经验后端开发工程师薪酬数据。
2. 行业报告未覆盖杭州、成都等新一线城市水平。
3. 现有数据仅含基础薪酬，未涵盖绩效与福利综合竞争力。

#### 分析目标定义
请协助
1. 评估我司后端开发工程师3~5年经验在杭州、成都市场的竞争力，对比P50、P75。
2. 推荐3种调整方案如基础上调15%、增项目奖金、提供期权，并测算成本。
3. 预测明年行业涨幅12%时需预留预算以维持竞争力。

### 注意事项
| 要点 | 内容 |
| :--- | :--- |
| 数据可信度验证 | 模型结果需与权威报告如美世白皮书交叉验证 |
| 职位分类细化 | 明确职位具体要求，避免定义模糊导致对标失真 |
| 隐性成本考量 | 需补充社保基数调整、个税增加等隐性成本 |
| 动态调整机制 | 建议每季度重分析市场数据，观察趋势变化 |

## 4.5 AI 解读薪资分位

问题情景
