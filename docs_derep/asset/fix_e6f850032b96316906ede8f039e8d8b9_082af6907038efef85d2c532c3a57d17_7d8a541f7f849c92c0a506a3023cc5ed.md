# DeepSeek 本地界面 + Python 调用实操

想同时拥有图形化对话面板和程序化调用能力？下面把从隔离环境到跑通请求的流程拆开，每段都配好可直接复制的命令和示例。

一、搭建隔离的 Python 工作区
给自己划一块干净的 Python 3.11 隔离区，命名为 open-webui，避免与系统包冲突。先生成环境，随后让 Conda 初始化生效，重新载入用户配置文件，最后激活进入该区开始工作。

[PRE0]bash

# 创建一个名为 open-webui 的 Conda 虚拟环境，并指定 Python 版本为 3.11

conda create -n open-webui python=3.11

# 初始化 Conda

conda init

# 重新加载 shell 配置

source ~/.bashrc

# 激活刚刚创建的 open-webui 环境，进入该环境

conda activate open-webui

二、部署并启动 WebUI
在该隔离区内，用清华 PyPI 镜像把 Open WebUI 装上，安装完毕直接运行 serve 启动本地服务，浏览器即可打开对话界面。

[PRE1]bash

pip install open-webui -i https://pypi.tuna.tsinghua.edu.cn/simple

[PRE2]bash

open-webui serve

三、搭建 Python 调用通道
先装上兼容 OpenAI 的客户端库，随后用一段脚本演示如何写入密钥、指向 DeepSeek 官方地址、选用 deepseek-chat 模型发起一次简单问候并打印返回片段与完整对象。

[PRE3]bash

pip install openai

[PRE4]python

import os

from openai import OpenAI

from IPython.display import display, Code, Markdown

import requests

import json

# <YOUR_DEEPSEEK_API_KEY>替换为复制的 API key 字符串

ds_api_key = '<YOUR_DEEPSEEK_API_KEY>'

#实例化客户端

client = OpenAI(api_key=ds_api_key,

                base_url="https://api.deepseek.com")

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {"role": "user", "content": "你好，好久不见!"}

    ]

)

#输出生成的响应内容

print(response.choices[0].message.content)

#输出完整的响应

print(response)
