### 1.6 模型 API Key 是什么？怎么选模型、怎么填 Key？

装好 OpenClaw 只是有了外壳，要让它具备思考与执行能力，还需接入 AI 模型，这就需要 API Key，可理解为使用某家 AI 服务的通行证。

OpenClaw 并非大模型本身，而是一个把渠道、网关、记忆、技能、模型调用串起来的 Agent 框架。需要对接模型提供商完成推理，最常见的是 API Key，部分支持 OAuth 或本地模型。官方 FAQ 也说明：OpenClaw 既可用 API Key，也可跑本地模型。

简单说，OpenClaw 负责调度、记忆与工具，模型负责推理，二者通过 API Key 连接。好比你有一个秘书 OpenClaw，需要请教专家 AI 给出专业建议，API Key 就是专家的会员卡。

Key 通常是 sk-xxxxxxxxxxxxxxxxxxxxxxxx 这类随机字符。填入配置后即可调用，每次调用都会消耗额度，所以账户需有余额。新用户一般有免费额度，够试用一段时间，用完再充值。

#### 1.6.1 API Key 到底是什么

OpenClaw 负责运行 Agent、管理记忆、协调工具，模型只提供推理能力。两者靠 API Key 相连。拿到 Key 后填入配置即可使用，调用会扣费，建议先用免费额度体验。

#### 1.6.2 怎么选模型：官方支持哪些

选型基本两步：先完成 provider 认证，再把默认模型写成 provider/model 形式。官方文档中可直接确认的国内模型主要有：

- **MiniMax**：OpenClaw 有独立的 MiniMax provider 页面，推荐模型 ID 为 minimax/MiniMax-M2.5 和 minimax/MiniMax-M2.5-highspeed。国内可直接访问，速度快、价格适中，适合日常任务。
- **Moonshot（Kimi）**：官方 provider 页面明确支持，当前推荐写法是 moonshot/kimi-k2.5。Kimi 的长文本能力突出，上下文窗口达 200 万字，适合阅读文档、分析长材料、整理会议纪要。
- **Z.AI（GLM）**：智谱 GLM 通过 zai provider 使用，模型如 zai/glm-5。清华团队研发，中文理解强、代码能力也不错，处理中文材料的体验很好。
- **Qwen（通义千问）**：特别说明，当前官方 Qwen 页面主推 qwen-portal 的 OAuth 流程，而非直接用 DashScope API Key。官方建议启用 qwen-portal-auth 插件，然后执行 `openclaw models auth login --provider qwen-portal --set-default` 登录。

除此之外，还支持 OpenAI GPT 系列、Anthropic Claude 系列、Google Gemini 系列，以及 DeepSeek、豆包等国内模型。也可用 Ollama 在本地跑开源模型，完全免费，只是硬件要求更高。

#### 1.6.6 给新手的最靠谱建议

第一步：直接跑 openclaw onboard，让向导带完整流程，别自己猜、别手工改文件。
第二步：国内用户优先试 MiniMax、Kimi、GLM，访问快、价格合理、文档友好。
第三步：先用免费额度体验，熟悉后再充值。别一上来充几百，50~100 元足够起步。
第四步：配完一定要先对话测试，确认通畅再往下走，有问题及时解决。
