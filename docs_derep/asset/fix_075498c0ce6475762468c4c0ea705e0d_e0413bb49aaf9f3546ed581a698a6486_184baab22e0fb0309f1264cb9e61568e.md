与 VAE、GAN、归一化流这类以潜在表征为核心的生成范式相比，扩散模型本质上也是对隐变量做一连串的变换，让变换后的分布逐步逼近真实的数据分布。差异点在于 VAE 在拟合从隐空间到数据空间的生成器 qθ(x|z) 的同时，还必须用可学习的后验 qφ(z|x) 去逼近真实后验 qθ(z|x)，这一步对最终效果影响很大：后验假设太简单时很难逼近真实后验，导致生成质量受损；假设太复杂时计算开销会迅速膨胀。GAN 与归一化流不显式求解后验，但各有短板：GAN 依赖额外的判别器进行对抗训练，训练过程容易不稳定且收敛困难；归一化流要求隐变量到数据的映射严格可逆，这极大限制了表达能力，也难以直接复用现有的主流神经网络组件。扩散模型在继承前者优势的同时规避了这些问题，只需训练生成器，目标形式简洁、优化友好，无需判别器等辅助模块，表达能力也更为灵活。下面图 2-2 先给出扩散模型与其他生成范式结合的概览，具体关联将在第 6 章展开，此处仅作理解参考。

# 2.1 去噪扩散概率模型

去噪扩散概率模型 DDPM 的灵感来自非平衡热力学，它构建一条马尔可夫链，缓慢地给样本注入随机噪声，再学习该链的逆过程，从纯噪声中逐步还原目标数据。可以把加噪过程类比为水中小分子的布朗运动。一个 DDPM 由两条马尔可夫链构成，正向链把数据推向噪声，逆向链把噪声还原为数据。正向链一般是预先设定的，目标是让数据分布逐步变为简单的先验分布，比如标准高斯；逆向链的每一步转移核则由深度神经网络来学习，目标是让逆过程抵消正向过程，从而生成新样本。新样本的生成先从先验中抽取随机向量，再送入逆向链，通过祖先采样法生成新数据[125]。DDPM[90, 215] 的结构图见图 2-3。
