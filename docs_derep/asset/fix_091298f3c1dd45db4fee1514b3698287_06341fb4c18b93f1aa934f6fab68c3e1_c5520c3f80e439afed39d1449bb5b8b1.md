**【考点定位】**

入门级|C++程序设计|【2.3】程序基本语句、【2.9】函数与递归
入门级|数学|【5.3】初等数论

**【程序解读】**

1. 整体功能
读入上界 x，输出不超过 x 的素数个数与这些素数的和。

2. 段一解读
03 bool isPrime(int n){
04 if(n<=1){
05 return false;
06 }
07 for(int i=2;i*i<=n;i++){
08 if(n%i==0){
09 return false;
10 }
11 }
12 return true;
13 }
功能是判断 n 是否为素数。
要点：
（1）n≤1 直接返回否。
（2）试除法只遍历到 √n。
（3）一旦发现因子立即返回 false。

3. 段二解读
15 int countPrimes(int n){
16 int count=0;
17 for(int i=2;i<=n;i++){
18 if(isPrime(i)){
19 count++;
20 }
21 }
22 return count;
23 }
功能是统计 ≤n 的素数个数。
要点：遍历 2 到 n，借助 isPrime 计数。

4. 段三解读
25 int sumPrimes(int n){
26 int sum=0;
27 for(int i=2;i<=n;i++){
28 if(isPrime(i)){
29 sum+=i;
30 }
31 }
32 }
功能是求 ≤n 的素数总和。
要点：同样遍历并累加，注意函数末尾缺少 return sum，会产生警告。

5. 段四解读
34 int main(){
36 int x;
37 cin>>x;
38 cout<<countPrimes(x)<<" "<<sumPrimes(x)<<endl;
39 return 0;
40 }
入口函数读取 x，调用两个辅助函数并输出。

**判断题**

16. 输入“10”时，程序先输出“4”，后输出“17”。（ ）
**【说明】**
x=10，素数有 2,3,5,7，共 4 个，和为 17。输出为 4 17，正确。
**【参考答案】**
正确（√）

17. 若把 isPrime 中的循环条件改为 i<=n/2，输入“20”时 countPrimes 输出会变为“6”。（ ）
**【说明】**
改动仅影响效率，判定逻辑不变。≤20 的素数仍为 2,3,5,7,11,13,17,19 共 8 个，不会变成 6。
**【参考答案】**
错误（×）

18. sumPrimes 计算的是从 2 到 n 的素数之和。（ ）
**【说明】**
函数确实对 2~n 区间筛选素数并累加，描述正确。
**【参考答案】**
正确（√）

20. 若把 for(int i=2;i*i<=n;i++) 改为 for(int i=2;i<=n;i++)，输入“10”时的输出为（ ）
A. 将不能正确计算 10 以内的素数个数及其和
B. 仍然输出“4”和“17”
C. 输出“3”和“10”
D. 输出结果不变，但时间更短

循环会跑到 i=n，n%i 恒为 0，所有数都被判为非素数，最终输出 0 0。

**【小结】**
考点集中在函数的定义与调用、for 循环的使用、bool 类型返回值，以及素数的试除判定。

**【核心要点】**

一、C++ 函数与递归
函数是代码复用的基本单元，由返回类型、名称、参数和体组成。isPrime 通过条件与循环实现判定，return 直接给出结果。调用时实参与形参对应。

二、for 循环
固定次数迭代，结构为 for(初始化; 条件; 更新)。常用于遍历区间。

三、素数判定
素数大于 1 且仅有 1 和自身两个正因子。试除法只需检查到 √n。

**【程序解读】**

1. 整体功能
通过动态规划求解每次可走一步或两步的最低花费路径。

2. 段一解读
04 int compute(vector<int> &cost){
05 int n = cost.size();
06 vector<int> dp(n+1, 0);
07 dp[1] = cost[0];
08 for(int i = 2; i <= n; i++){
09 dp[i] = min(dp[i-1], dp[i-2]) + cost[i-1];
10 }
11 return min(dp[n], dp[n-1]);
12 }
状态定义：dp[i] 表示到达第 i 级台阶的最小花费。
转移：dp[i]=min(dp[i-1],dp[i-2])+cost[i-1]。
边界：dp[1]=cost[0]，dp[0]=0。

3. 段二解读
13 int main() {
15 int n;
16 cin >> n;
17 vector<int> cost(n);
18 for (int i = 0; i < n; i++){
19 cin >> cost[i];
20 }
21 cout << compute(cost) << endl;
22 return 0;
23 }
读入台阶数与花费，调用 compute 并输出结果。

dp[1]=10，dp[2]=15，dp[3]=30，返回 min(30,15)=15，正确。
**【参考答案】**
正确（√）

**【说明】**
i<3 时会越界，属于运行期错误，编译阶段无法捕获。
**【参考答案】**
错误（×）

23. 程序总是输出 cost 数组的最小元素。（ ）
**【说明】**
程序求的是最小路径总和，而非单个最小元素，错误。
