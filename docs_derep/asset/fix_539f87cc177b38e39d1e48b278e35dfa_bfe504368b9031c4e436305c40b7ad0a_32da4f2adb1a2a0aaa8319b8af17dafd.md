# 7.4.1 时间序列插补

时间序列插补指在序列出现空缺时，用算法对缺失点进行估计的方法[213,229,269]。在实际应用中[60,173,265,280]，缺失十分常见，插补因此成为时间序列处理的关键环节。常用方法包括：

+   1. 线性插值。借助缺失点前后两个已知值做直线连接，假设中间区间变化平稳，用直线逼近空缺段。
+   2. 拉格朗日插值。选取缺失点附近若干邻近观测，构造一个插值多项式，再以该多项式推算缺失值。
+   3. 平滑插值。思路与拉格朗日相近，但采用分段的二次或三次连续函数拟合，曲线过渡更平滑。
+   4. k-最近邻插补。取与缺失点最相近的 k 个邻居的均值或中位数作为估计。
+   5. 基于模型的插补。先用已知数据拟合自回归、ARIMA、VAR 等统计模型，再据此预测缺失位置。
+   6. 矩阵分解。将序列转成矩阵形式，利用奇异值分解、主成分分析等方法填补缺失条目。
+   7. 基于深度学习的插补。借助循环神经网络、长短时记忆网络等学习序列规律，再对空缺位置进行推断。

基于扩散模型的时间序列插补

近年来，确定性插补[23,27,154]与概率插补[165]都快速发展，扩散模型成为重要方向。CSDI[230]基于分数型扩散提出一种新插补方案。为更好地挖掘时序相关性并用于生成建模，该方法采用自监督训练来优化扩散模型。如图7-24所示，CSDI 在部分已知序列的基础上，利用扩散模型逐步恢复缺失的时序信号。Conditional observations 为输入条件信号，Imputation targets 为待填补的目标片段。

# 7.4.2 时间序列预测

时间序列预测是指基于历史数据，利用算法对未来一段时间的数值进行推断。预测是时间序列分析的核心，广泛应用于经济、金融、工业与社会等领域。常用方法有：

+   - 1. 移动平均法。利用序列的平均值进行预测，分为简单移动平均、加权移动平均等。
- 2. 指数平滑法。依据平滑后的序列值预测，常见单指数、双指数、三指数平滑。
- 3. ARIMA 模型。通过自回归、差分、移动平均三步构建模型，拟合能力强。
- 4. SARIMA 模型。在 ARIMA 基础上加入季节性差分与季节性自回归，处理周期性。
- 5. VAR 模型。将多个变量序列视为整体建模，刻画变量间的相互作用。
6. 预测 Prophet 模型。由 Facebook 提出，可自动处理季节性与节假日，具有较强可解释性。
7. 深度学习模型。包括循环神经网络 RNN、长短时记忆 LSTM、卷积神经网络 CNN 等，能自动提取特征并实现非线性建模。

基于扩散模型的时间序列预测

深度学习已被用于时间序列预测，常见单点预测[172]与单变量概率预测[205]。多变量场景下也有点预测方法[140]与概率方法，涉及 GAN[271]或归一化流[192]等生成技术，扩散模型也被引入其中。TimeGrad[191]提出一种自回归的多元时间序列预测方法，通过估计每个序列样本分布的梯度从数据分布中采样，模型搭建基于扩散概率模型。该方法与分数匹配及基于能量的模型密切相关，通过优化数据对数似然的变分下界学习梯度，推理阶段采用朗之万采样，并借助马尔可夫链将白噪声逐步转化为目标分布样本[220]，图7-26 为其预测结果。
