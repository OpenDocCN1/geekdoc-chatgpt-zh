### 14.8.6 Xception

Google 在论文《Xception: Deep Learning with Depthwise Separable Convolutions》中提出的 Xception，本质是对 Inception v3 的一次再进化，核心做法是用深度可分离卷积把 Inception v3 里原来的普通卷积全部替换掉。

设计思想
把深度可分离卷积用于替代 Inception v3 的卷积操作，和传统 DW 卷积相比有两处反转。
（1）传统 DW 先做逐通道卷积再接 1×1，Xception 把顺序调换，先做 1×1 再做逐通道。
（2）传统 DW 在两次卷积之间不加非线性，Xception 在 1×1 之后会加上 ReLU 激活。

网络架构
VGG 这类经典网络靠不断堆叠 3×3 卷积来提取特征，Inception 模块则把 1×1、3×3、5×5 卷积与池化并置，用更少的参数学到更丰富的表示。Inception 模块是 GoogLeNet、Inception v2/v3、Inception-ResNet 的通用单元，其思路是把空间相关性与通道相关性拆开学习。
（1）先用 1×1 卷核把特征图各通道映射到新空间，专注学习通道间关系。
（2）再用 3×3 或 5×5 卷核做卷积，同时涉及空间与通道关系，此时卷核仍是多通道输入，空间与通道并未彻底解耦。

从 Inception 到 Xception 的演化可划为三步。
（1）先对 Inception 做简化，只保留 3×3 卷积分支，得到如图14-21 所示的仅含 3×3 分支的 Inception 模块。

### 14.8.7 ShuffleNet-v1

《ShuffleNet: An Extremely Efficient Convolutional Neural Network for Mobile Devices》提出 ShuffleNet，主打手机等移动端部署。架构引入逐点群卷积与通道重排两大操作，在精度相当的情况下把计算量大幅压低。先前网络里点卷积分支会显著抬高算力，作者用点卷积分组来降本，但组间信息割裂会伤精度，随后用通道重排来恢复组间流通，在同等算力预算下容纳更多通道保留信息。

设计思想
ShuffleNet 延续稀疏连接的思路。分析 Xception 与 ResNet 可知，两者把卷积拆分后整体复杂度下降，但点卷积的算力反而上升，为此作者改用逐点群卷积来承接，原本的跨通道运算被限制在组内，算力明显降低。图14-24 展示了逐点群卷积与通道重排的流程。

隐患是，多层点卷积堆叠后，信息被锁在各组内部，组间没有交换，如图14-24（a）。这会损害表征能力与识别效果。因此在使用逐点群卷积的同时，必须补上组间信息交换机制。第二层卷积里每个卷核需要同时接收各组特征输入，如图14-24（b）。作者指出通道重排如图14-24（c）可便捷实现该机制，且操作可导，能嵌入网络做端到端训练。

[PRE3]

#### 网络架构
基于逐点群卷积与通道重排，作者设计出全新的 ShuffleNet 结构单元，沿用 ResNet 思想并针对效率做了改进。
（1）用逐通道卷积替换原来的 3×3 卷积，降低空间特征抽取的复杂度，如图14-25（a）所示。
（2）把结构里前后两个 1×1 点卷积分组，并在两者之间加入通道重排，进一步削减跨通道计算量，最终单元如 图14-25（b）所示。
（3）另提出一种单元图14-25（c），旁路加入 AVG Pool 以降低特征图分辨率，最后不做相加而是做拼接来弥补信息损失，专用于降采样。

### 14.8.8 ShuffleNet-v2

Face++ 团队的论文《ShuffleNet V2: Practical Guidelines for Efficient CNN Architecture Design》提出 ShuffleNet-v2，目标是在轻量化的前提下兼顾高精度与高速度。文中总结了 4 条高效 CNN 设计准则，并据此对 ShuffleNet-v1 进行修正。同等算力下，ShuffleNet-v2 要比 ShuffleNet 与 MobileNet-v2 更准。

#### 设计思想
- （1）高效 CNN 的 4 条准则。
    - G1 通道宽度保持一致能最小化 MAC，速度最快。
    - G2 过度使用分组卷积会抬高 MAC，使模型变慢。
    - G3 网络碎片化会降低并行度，分支越少越快。
    - G4 元素级运算成本不容忽视，需尽量减少 Element-wise 操作。
- （2）ShuffleNet-v1 的违背点。
    - a 大量使用 1×1 分组卷积，违背 G2。
    - b 采用类似 ResNet 的瓶颈层，输入输出通道不一致，违背 G1。
    - c 整体结构里分组卷积过多，违背 G3。
    - d 短路连接里元素级加法较多，违背 G4。
- （3）ShuffleNet-v2 的改进方向。
图14-26 为 ShuffleNet-v1 与 ShuffleNet-v2 的基础单元，其中 14.26（a）和 14.26（b）是 ShuffleNet-v1 的两类 block，后者对特征图尺寸做了缩小。14.26（c）和 14.26（d）是 ShuffleNet-v2 的两类 block。

图14-26 ShuffleNet-v1和ShuffleNet-v2的基础单元

从图14-26 可看出改进要点。
改进1：14.26（a）与 14.26（c）对比，14.26（c）在入口处增加了通道分离操作，先把输入特征图在通道维切成 c' 与 c-c' 两个分支，实际 c'=c/2，左分支走等价映射，右分支走 3 个连续卷积且输入输出通道相同，符合 G1。
改进2：14.26（c）去掉了 1×1 卷积层的分组，符合 G2。注意前面通道分离本身已具分组效应，两分支相当于两组。
改进3：通道重排被挪到拼接操作之后，符合 G3；同时首个 1×1 卷积不再分组，后接通道重排意义不大。
改进4：两分支输出不再做元素相加，而是直接拼接，符合 G4。

### 14.9.1 NCNN

- （1）首次公开时间：2017年7月。
- （2）开源团队：腾讯优图。
- （3）仓库链接：见参考链接[1]。
- （4）特点。
    - NCNN 针对手机端硬件与系统差异及调用方式做了适配，架构利于在手机端运行。
    - 无第三方依赖，跨平台，手机端 CPU 速度快于同期已知的开源框架。
    - 基于 NCNN 可把深度学习算法轻松移植到手机端高效执行，用来开发 AI 应用。
- （5）功能。
    - 支持卷积神经网络及多分支/多输入的复杂网络，如 VGG、GoogLeNet、ResNet、SqueezeNet 等。
    - 不依赖任何第三方库。
    - 全程 C/C++ 实现，采用跨平台 cmake 编译系统，可轻松移植。
    - 汇编级优化，使用 ARM NEON 指令集实现卷积、全连接、池化等关键层。
    - 精细数据结构设计，未采用 im2col+矩阵乘法，内存占用极低。
    - 支持多核并行，优化 CPU 调度。
    - 库体积小于 500KB，可精简到 300KB 以下。
    - 支持 8bit 量化和半精度浮点存储。
    - 支持直接内存引用加载网络模型。
    - 可注册自定义层实现扩展。
- （6）NCNN 在 Android 端的部署示例。

### 14.9.2 QNNPACK

- （1）全称：量化神经网络包 Quantized Neural Network PACKage，QNNPACK。
- （2）首次公开时间：2018年10月。
- （3）开源团队：Facebook。
- （4）仓库链接：见参考链接[2]。
- （5）特点。
    - 提供低密度卷积优化函数库。
    - 可在手机上实时运行 Mask R-CNN 和 DensePose。
    - 在性能受限的移动设备上 100ms 内完成图像分类。
- （6）性能优势。
测试显示 QNNPACK 在端到端基准上具有明显优势。量化 MobileNet-v2 架构上，基于 QNNPACK 的 Caffe2 算子速度约是 TensorFlow Lite 的 2 倍，在多款手机上均如此。除 QNNPACK 外，Facebook 还开源了 Caffe2 量化 MobileNet-v2 模型，其 Top1 准确率比对应的 TensorFlow 模型高 1.3%。

MobileNet-v1 采用深度卷积使模型更适配移动端，具有开创性意义。MobileNet-v1 包含大量 1×1 卷积与 3×3 卷积。研究者把量化 MobileNet-v1 模型从 TensorFlow Lite 转换，并在 TensorFlow Lite 与 QNNPACK 的 32bit ARM 设备上做基准测试，二者均使用四线程，研究者观察到 QNNPACK 运行速度的几何平均值是 TensorFlow Lite 的 1.8 倍。
