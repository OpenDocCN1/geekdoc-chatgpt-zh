AI并非要取代人，而是重塑工作方式

客观来看，以 DeepSeek 为代表的生成式智能确实能接管大量重复性操作，明显提升效率，比如常规的文字处理。但这并不等于人类会被完全替代。创造力、共情力、价值判断以及复杂情境下的决策智慧，仍是人独有的高地。技术的进步也在同步孵化新的岗位。未来的社会形态，更像是人机协同的主场，而非谁取代谁的战场。核心在于让技术为人的福祉服务，而不是反过来被技术牵制。

真正带来压力的对手，往往是同行。业内常流传一句概括：人工智能不会消灭人，只会淘汰不会用人工智能的人。大模型代表了当前最前沿的技术水准。虽然全面取代人类尚不现实，但拒绝拥抱它的人会被淘汰。企业亦然，脱离人工智能谈竞争优势几乎不可想象。举例来说，质检环节智能系统的速度与精准度远超人工；决策与创意环节，人工智能能在短时间内给出多套备选方案，而你还在苦等灵感时，结果高下已分。

工具越强，人越要守住主导权。面对 DeepSeek 带来的剧变，它一方面拉高了效率，另一方面也对综合素养提出更高要求。持续学习、掌握人工智能知识、提升工具使用能力，才能保持主体性，在浪潮中把握自己的命运。

### 10.3 DeepSeek 演进的重点方向
DeepSeek 横空出世后，人工智能产业进入此起彼伏的节奏。刚经历百模竞争抢占场景，转头就迎来百花齐放的工具潮。在大模型持续演进的过程中，哪些议题更值得关注？下面梳理几个重点方向。

#### 10.3.1 端侧大模型加速变革
DeepSeek 高性价比的特性，为终端侧大模型打开了突破口。它以更低成本、更高性能、更小体积打破了大模型的经典三难。随之各行业加快接入 DeepSeek，由其蒸馏出的各类轻量小模型也开始在终端设备上大规模落地。

##### （1）蒸馏技术推动模型下沉终端
模型开源能加速技术进入产品，让更多人共享进步红利。随着训练成本下降、边缘人工智能推理普及，以堆规模比拼参数的时代正逐渐落幕。焦点转向如何把人工智能高效落地到边缘和终端，并在真实生产中实现可感知的效益提升。高质量的小规模模型正获得更多关注。

支撑终端落地的底层技术不可或缺。蒸馏技术让大模型把知识传授给小模型，在保持较高准确率的同时大幅缩减体量，也催生出面向垂直行业和特定场景的定制小模型。

此外量化、压缩和剪枝等模型优化手段也能有效降低模型尺寸与功耗。算力与能耗的节省是终端发展的重要命脉。得益于这些方法，小模型的实际表现已逐步逼近前沿大模型。

##### （2）终端应用进入繁荣期
人工智能模型的训练范式正在被重塑，大规模推理模型的浪潮来势凶猛，新一轮边缘侧推理创新周期已启动。依托蒸馏及各类优化技术诞生的更小更快模型，正在加速进入行业，并向终端规模化集成。

从手机、个人计算机、智能穿戴、智能家居到汽车，终端和边缘运行的人工智能在质量、性能和效率上均实现明显跃升。终端能够承载的优质人工智能模型越来越多，高质量的小语言模型与多模态推理模型数量激增，随之带来应用场景的井喷。

因此从手机、个人计算机、汽车到工业物联网，从 CPU、GPU 到 NPU，从硬件、软件到生态，以 DeepSeek 为代表的大模型正从云端向终端迁移。终端侧人工智能以低延迟、高隐私、强实时著称，与云端形成互补。这一趋势将推动形成覆盖终端、边缘和云端的多层次人工智能技术栈，并在应用层面引发一轮爆发式增长。

#### 10.3.2 智能体快速普及
基于大语言模型，智能体具备自主思考、规划、调用工具并处理复杂任务的能力，无需人工持续干预。随着底层技术不断突破，人机交互方式正被重塑。2025 年被普遍视为智能体爆发的元年。

##### （1）智能体技术迭代快
进入 2025 年，围绕智能体的话题热度持续攀升。Anthropic 率先采用 MCP 范式，其快速普及引发广泛关注；OpenAI 推出的 Agents SDK 为开发者提供强大的工具包，使得创建和部署智能体变得更加容易；而谷歌发布的 A2A 协议则进一步拓展了智能体之间的互操作性。这些进展共同预示智能体的巨大潜力及其对未来科技发展的重要影响。

##### （2）智能体产品多元化
市场上涌现出一批代表性智能体产品。例如 OpenAI 开发的 Operator，Monica 公司的 Manus，以及智谱华章推出的 AutoGLM 沉思等。这些产品的问世不仅展示了智能体技术的多样性，还引发了关于应用前景的热烈讨论。尽管当前技术仍处发展阶段，但已显示人工智能领域核心竞争力正从硬件算力和单一技术创新转向生态协同与用户体验的综合提升。

智能体的快速发展得益于技术成熟度提高、市场需求激增以及生态系统协作增强。如今应用场景已从简单工具扩展到数字员工，成为企业实现成本节约和效率提升的关键工具。然而在追求更高层次人机共生时，可靠性、安全性和标准化仍然是亟须克服的重大障碍。展望未来，通过多模态融合、自主进化等技术的不断创新，智能体将进一步渗透至生产、生活和服务的各个角落，推动社会步入人机共生的新时代。

#### 10.3.3 通用与垂直之辨
大模型按设计目的、训练数据集及应用场景可分为通用大模型和垂直大模型。通用大模型通常通过大规模、多样化数据训练而成，旨在提供广泛适应性和跨领域通用能力。这些模型聚焦基础层，以技术攻关为目标，能在多种任务和不同领域表现出良好性能，具有较强通用性，不需要针对特定任务或领域专门训练。其中 DeepSeek 就属于此类。

垂直大模型则专注特定领域或行业，利用领域专业知识和数据进行优化训练，从而在特定任务上展现出超越通用模型的专业性和精准性。例如医学诊断、法律咨询、金融风控、生产制造等领域，都采用更强调针对性的垂直大模型。相比通用大模型，垂直大模型因对特定领域的深入学习，能够处理更为专业、复杂且需要深度领域知识的任务。

通用大模型聚焦一个广字，面向人群及场景适用范围十分广泛。垂直大模型聚焦一个专字，面向特定行业或者特定场景。两者对比如表 10-1 所示。

**表 10-1 通用大模型与垂直大模型对比**

| 对比维度 | 通用大模型 | 垂直大模型 |
| :--- | :--- | :--- |
| 实现技术 | 大规模预训练方式 | 特定领域训练、微调 |
| 场景 | 通用场景 | 专用场景 |
| 需求 | 满足用户多元化、非专业性的日常需求。以提供广泛的知识和功能为核心，追求全面性和普适性 | 满足行业内用户的特定需求。以深入理解和执行特定领域任务为核心，追求专业性和准确性 |
| 商业 | 开放平台或 SaaS 产品 | 企业内部定制开发或针对特定行业解决方案 |
| 模型规模 | 通常模型参数量巨大 | 可能有较大规模参数，但专业数据更重要 |
| 性能优势 | 具有广度优势 | 在专业领域，提供更专业、准确的答案和服务 |
| 资源投入成本 | 训练成本高，需要庞大的计算资源和高质量多元的数据集，维护和更新也需要持续投入 | 训练成本同样不低，但相比训练同等效果的通用大模型，在资源消耗上更为可控 |
| 特点 | 其强大的迁移学习能力、灵活适应新任务的能力以及在各类普通场景下的实用性 | 深厚的领域专业知识、对复杂领域问题的深入理解和高精度的决策支持能力 |
| 举例 | ChatGPT、Gemini、DeepSeek | 特定行业大模型 |

针对大模型未来的发展，行业普遍认为下半场在于具体行业中的落地。这似乎表明垂直大模型比通用大模型更具价值和发展潜力。然而事实上，通用大模型与垂直大模型同样重要，机会相当。

##### （1）技术同源各有侧重
不论通用大模型还是垂直大模型，它们技术同根同源，原理一致，但两者各有侧重。通用大模型更注重基础技术，其模型性能重点在于迁移性和全面性；垂直大模型则更注重专用数据的训练，其模型性能重点在专业性和准确性。

垂直大模型技术多继承于通用大模型。通用大模型以通用人工智能为目标进行发展，可以定义为智能，而垂直大模型以解决具体行业问题为目标进行发展，可以定义为工具。因此技术的突破更可能发生在通用大模型领域。

##### （2）商业版图各有空间
通用大模型和垂直大模型都具有广阔的商业市场。通用大模型适用于非专业领域的市场，如智能助手、在线问答系统、文本生成等，涵盖日常生活、工作、娱乐等多个方面。这类需求规模极为庞大。

垂直大模型应用于特定行业或场景，在具有行业门槛或特定场景的市场中大有可为，如医疗诊断辅助、金融风险评估、法律文档审查等。这类应用需要具备高度的专业知识和情境理解能力。这类需求种类繁多，整体市场规模也十分庞大。

在未来商业发展中，由于其通用性，通用大模型可能只需要寥寥几个即可，如搜索引擎领域的谷歌、百度一样，赢家通吃。然而垂直大模型面对的是千行百业的需求。由于特定行业的封闭性或者专业性，有多少种行业就可能有多少种垂直大模型。此外由于数据隐私保护问题，同一个行业可能会存在多个垂直大模型。

##### （3）商业挑战各有不同
通用大模型和垂直大模型虽然商业前景广阔，但都面临各自的商业难点。通用大模型高额的研发和运行成本使行业变成一个烧钱的游戏，可持续商业模式尚不明朗。垂直大模型的成本也不低，专业数据的获取、处理和理解对团队提出更高要求，远非收集公开数据那么简单。相比通用大模型，垂直大模型的应用范围相对有限，市场规模可能会受到限制，这将影响投资回报率及经济效益。

垂直大模型的存在是一种折中或无可奈何的选择，受制于通用大模型的算力需求，以及行业数据的隐私保护。为了解决现有行业问题，大模型不得不从通用走向专用。然而一旦通用大模型能够囊括更多行业的任务，垂直大模型的生存空间将缩小。那一天或许就是通用人工智能真正到来的时刻。

#### 10.3.4 伦理与道德
技术往往是一把双刃剑。DeepSeek 等大模型在广泛赋能各行各业并与人类社会深入融合的同时，它们在可解释性、公平性、隐私保护、知识产权归属、内容安全等方面的伦理与道德风险也逐渐凸显。面对伦理与道德约束，大模型存在如下挑战。

- （1）大模型滥用
诚然，大模型具有强大的数据理解和生成能力，是一把好剑。然而当大模型被恶意利用时，则会产生危害。例如当大模型的强大性能被用来伪造内容，进行欺诈、操纵舆论、制造假新闻等时，会严重损害公共利益和社会秩序。

- （2）责任归属与可控性
由于潜在的数据偏见和歧视，大模型的公正性会受到影响，即使大模型没有被刻意恶意使用，也可能产生一些有害言论。当大模型输出错误或有害的内容时，责任应由谁承担？是模型开发者、使用者还是其他相关方？如何确保模型行为可预测性和可控性？

- （3）透明度与可解释性
大模型的可解释性问题目前仍未完全解决。在医疗、法律、金融等领域，当公众有权了解某种决定或建议的依据时，大模型往往难以清晰解释其决策逻辑，这会带来信任问题。

- （4）知识产权与版权
大模型在生成文本、音乐、图像等创造性内容时，生成内容的版权归属问题尚无明确定论。版权究竟属于大模型背后的人类研发者，还是使用大模型的用户呢？一些国家尝试通过版权法对比进行规定，如将人工智能生成内容的版权归属于人类研发者或雇主。但是，当大模型生成的内容与人类作品极其相似时，可能涉及侵犯原作者的知识产权，而原作者如何申诉也是一个问题。

- （5）就业与社会公平
随着大模型在更多岗位上辅助甚至取代人力，可能会出现失业率上升和技能需求变化的情况，对未来社会产生深远影响。如何应对大模型带来的就业问题和社会公平性挑战，是值得人类深入思考的。

这些伦理和道德问题与挑战需要我们积极应对，应对思路有以下几种。

- （1）技术上
以上问题有一部分来自大模型技术本身。技术的问题就用技术来解决。例如在可解释性方面，可以使用可解释的模型来对决策进行解释，如决策树、规则模型等；在数据安全方面，采用数据加密、差分隐私和安全多方计算等技术，确保个人数据的隐私和安全。

- （2）法律上
制定合适的法律法规和伦理准则，确保人工智能大模型的使用符合道德和法律要求。开展公开和透明的讨论，促进社会对于人工智能技术的理解和参与。注重公平性和权益保护，进行数据脱敏和去偏倚处理，避免对特定群体的歧视和偏见。

这些应对思路可以帮助人类克服大模型所面临的技术挑战。然而具体解决方案仍需要根据具体的应用场景和问题进行定制。随着技术进步和实践积累，将有更多解决方案出现，以应对新的挑战，并且推动大模型的可持续发展。

### 10.4 小结
本章对 DeepSeek 大模型的技术和应用进行了总结，并对关于 DeepSeek 一些常见误区及未来发展方向进行了探讨。其中重点回顾了 DeepSeek 赋能千行百业的能力，特别是在制造业的应用场景。并且详细探讨了如何正确认识 DeepSeek 的能力与局限。最后细致展望了 DeepSeek 技术未来的重点研究方向。

在人工智能技术和大模型技术发展的历史长河中，DeepSeek 或许不会成为最终最先进的模型，但它曾在大模型的发展浪潮中掀起不小波澜。在经历 ChatGPT 首次惊艳亮相后，DeepSeek 再次让大模型技术的研究与应用变得炙手可热。大模型的洪流席卷了时代的每一个角落，无论哪个行业，无论企业主体还是个人从业者，无论大企业还是中小企业，无论制造业还是其他行业，都不可避免地感受到大模型带来的便利。

因此将 DeepSeek 等大模型应用于个人工作和企业运营管理中，已成为必然选择。通过 DeepSeek 变革现有的工作方式和管理模式，已成为不可逆转的历史趋势。只有拥抱新科技、使用新工具才能顺应时代潮流。正如从前从使用算盘到使用计算器，再到使用电脑一样，只有拥抱新技术才能实现新的发展。
