# 开源绘画的另一条路：认识 Stable Diffusion

上一章已经系统拆解了 Midjourney 的使用方法，这套方案上手快、风格覆盖面广、成图效果惊艳。除了它，市场上还有另一款常被拿来做横向对比的开源工具——Stable Diffusion，简称 SD。2022 年 8 月，Stability AI 宣布与慕尼黑大学合作研发的项目正式开源，源代码放在 GitHub 上，任何用户都能免费获取并在本地运行。相比前代绘画工具，SD 的核心优势是完全免费且没有使用次数限制，本地运行的硬件门槛相对友好，几秒就能产出高清图像，开源之后再次掀起 AI 绘画的热潮。

和 Midjourney 对比，取舍主要体现在：

+ (1) 费用：SD 属于开源免费，拉到本地后可长期无费用使用；Midjourney 则是付费订阅制。
+ (2) 定制自由度更高：依托开源基座与插件体系，可以自主微调风格、针对局部进行修改，可控性更强。
+ (3) 人像模型更丰富：尤其是女性人像模型储备充足，在人物刻画方面表现更好。

接下来按本地部署到生成数字主播的完整链路展开实操。

# 5.1.1 进行硬件部署和运行工程源码

要流畅运行 stable-diffusion-webui 及对应模型，显存是关键。最低可跑 4GB，日常可用 6GB，体验较好建议 12GB。系统内存最好超过 16GB，越大越稳。配置不足时会出现卡顿、响应慢等问题。

SD 的工程仓库放在 GitHub 上，更新频率很高，bug 修复和新功能会不断加入，建议定期去官网拉取最新版本。

具体操作如下。

(1) 安装 Git。打开 Git 官网下载，按照向导完成安装，保留默认组件即可。
(2) 搭建 Python 运行环境。stable-diffusion-webui 用 Python 编写，需要先装 Python 并配好环境变量，建议版本 3.10.6，可用 Anaconda 来管理多环境。
(3) 搭建 CUDA 环境。stable-diffusion-webui 主要走 GPU 加速，需要英伟达显卡。先安装 CUDA 驱动。右键桌面右下角 NVIDIA 图标进入控制面板，如图 5-1 所示。

# 5.1.2 安装权重文件和LoRa模型文件

(1) 下载 SD 运行所必需的基础权重，大小约 4GB。可在 Hugging Face 官网获取后放入 models/Stable-diffusion 目录。
(2) 下载 LoRA 模型。LoRA 全称 Low-Rank Adaptation of Large Language Models，是 SD 的插件方案。它无需改动原模型，只注入低秩矩阵，就能基于少量数据训练出特定画风或人物，比全量训练更省资源、更快。模型分享站 Civitai 上 SD 模型约 2000 个，LoRA 等小模型约 4 万个，可按喜好挑选。

# 表5-1 Stable Diffusion的主要参数

| 参数 | 说明 |
|------------|-----------------------------------------------------------------------|
| prompt | 正向提示词 |
| negative prompt | 反向提示词，用于排除不想要的元素 |
| width & height | 输出画布尺寸，尺寸越大耗时越长 |
| CFG scale | 提示词遵循强度，值越小越发散但逻辑性强，值越大越贴描述但易失真 |

| seed | 随机种子，-1 为随机，固定数值可复现相似画面 |

# 第5章 天工人巧日争新：生成你的数字人分身

写提示词是 SD 绘画的核心能力，整理了一些实用技巧：

技巧1：提示词结构为“正向描述 + 负向描述”。正向写想要的效果如 masterpiece、best quality；负向写不想要的效果如 bad hands、text error。
技巧2：越靠前的词权重越高，先写景会让人物占比变小，先写人物则占比变大。
技巧3：画幅越大，提示词越需详细。
技巧4：英文圆括号可提升内部词权重约 1.1 倍，中括号提升约 1.05 倍。
技巧5：‘+’ 与 ‘AND’ 可连接短语，AND 两边需空格。
技巧6：可采用三段式：第一段画质与风格，第二段主体内容及细节，第三段场景与人物细节。
技巧7：也可按“画质→风格→镜头→光照→主体及次要描述×系数→全局光照→全局镜头→滤镜”顺序组织。

不同模型对提示词敏感度不同，需不断调试组合。
