基座收敛，能力深耕

2025 年被公认为千模竞争的分水岭。基座模型的版图从此前分散竞争转向头部集中，算力与生态资源明显流向阿里千问、DeepSeek、字节豆包、百度文心、电信星辰等少数阵营。发展思路也在切换：早期偏重参数规模的扩张，如今转向对核心能力的精细化打磨。当下主线是为新一代代理系统提供更扎实、可用性更高的底层支撑，推动其从演示性质走向规模化商用。这一转向源于真实场景的更高期待——代理不仅要会交互理解，还要在复杂任务中呈现出清晰的规划、深入的剖析与高效的闭环执行，而基座正是承载这些素质的基础设施。

从能力视角看，支撑落地的关键方向愈发明确。

首要的是深度推理，相当于复杂任务的决策中枢。面对需要多步拆解和长期规划的诉求，比如为企业制定季度营销方案、为科研设计多阶段实验路径、为用户规划跨城深度游，基座需要跳出线性反应，通过推理、因果分析与全局统筹把大目标拆成可执行子项，并预判风险给出预案。这让代理从被动应答转向主动规划与动态调整。

二是数理素养，是保证精确分析的计算底座。在金融风控、科学计算、工程设计等对精度与严谨性要求很高的领域尤为关键。利用统计模型从海量交易中挖掘欺诈信号，用微积分与流体力学模拟设备运行，或用线性代数与概率模型优化供应链库存，基座能在数据处理、公式求解与逻辑推导上保持高准确率，避免计算误差引发决策失误。

三是编程与工具调度，是拓展边界、完成落地的执行双手。绝大多数真实任务离不开代码编写和工具调用。基座能够把自然语言需求转成可运行脚本，完成自动化开发，也能灵活调用数据分析、办公协同、云端 API 等专业工具弥补短板。例如调取数据接口清洗分析、调用办公软件生成排版文档、通过云端接口实现跨平台集成。两者结合让代理深入企业办公、工业生产、科研创新和日常生活，实现真正可用。

总体来看，围绕深层推理、数理素养、编程与工具调度的持续突破，形成了完整的代理支撑体系：推理定方向、数理保精度、编程与工具促执行。该体系的完善不断扩大代理的边界，也真正释放了其在真实场景中的价值，推动人工智能从技术探索走向产业应用。

**1.8.3 前沿趋势：超级代理成为落地焦点**

自 2025 年 3 月 Manus 发布成为里程碑后，市场呈现爆发增长，GenSpark、Coze、Skywork、MiniMax 等数十款超级代理相继出现，均以全领域任务执行专家为定位，通过网页或移动端提供跨领域处理能力，技术上多采用多代理协作或混合模型路径，市场初步繁荣。

繁荣下仍存在三重挑战：

第一，竞争同质化严重。多数产品核心功能集中在信息检索、数据分析与基础报告生成，差异化不足，用户平均留存率偏低，满意度有待提升。

第二，产业深度不够。产品多聚焦通用办公如问答、润色，对制造业、能源、交通等关键产业的深度应用较少。制造业虽在逐步应用，但在设备故障预测、供应链优化等方面仍存瓶颈。

第三，难以实现从基座大模型到代理框架的端到端联合优化。效果提升依赖全链路优化，需具备大模型训练调优能力，而基础大模型企业逐步收敛，限制了多数企业突破上限。

针对上述痛点，中国电信自研的星辰超级代理和星辰代理平台应势而生，旨在填补产业落地空白，打造标杆应用。战略路径清晰：

● 深度聚焦产业：立足真实需求，聚焦深度研究报告生成、海量数据分析、业务全流程自动化等专业场景。
● 端到端技术优化：打通从基础大模型到代理框架的全链路，实现技术栈深度整合与优化，达成可落地的领先效果。
● 打造国家级标杆：发挥在产业数据与场景的独特优势，构建安全可信高效的代理平台，为产业智能化升级提供核心动能。

该战略使星辰超级代理形成差异化优势，成为央国企产业化升级的优选伙伴。

**1.8.4 企业端场景的关键动向与代表案例**

代理正从概念验证转向推动生产效率与实际价值的实战生产力引擎，呈现三大趋势：

**1.与主营业务和系统整合**
代理需深度嵌入核心业务流程与 IT 系统才能产生关键价值。以银行为例，应从信贷风控、智能投顾、客户服务等核心场景切入，而非仅做简历筛选等边缘任务。通过与业务系统集成，实现从需求输入到结果输出的全流程自动化，成为业务中枢。

**2.单一任务走向综合流程**
代理正从单点小而美工具升级为解决业务全流程的六边形战士，实现端到端闭环。特斯特联迪拜世博会展示的代理机器人具备自主应对与协同交互能力，采用多模态感知与语音交互，自主规划路线串联接待、出行、配送等多场景，提升游客体验。

**3.企业生产力回报**
企业评价愈发务实，强调时间节省、人力释放、错误减少与体验优化等可量化成果。立项前需明确让谁的工作更轻松及带来哪些行为变化，确保落地价值明确可持续。核心意义在于稳定交付可衡量的业务改善，而非虚幻的技术创新。

代表性企业端产品已陆续出现：

● 办公领域：金山办公 WPS 灵犀原生 Office Agent 深度嵌入核心编辑流程，可自动完成文档与 PPT 创作，实现从内容输入到成品输出的闭环，节省人力并提升一致性与效率。
● 工业制造：西门子 Industrial Copilot 对接 CAD 与 MES 系统，打通设计制造链路，按指令生成工业设备图纸与操作指令，形成全流程自动化，缩短交付周期。
● 能源与工业：中国电信电力巡检专用代理集成巡检无人机与 SCADA 系统，秒级识别设备异常并自动派发工单，实现发现到响应的闭环，降低运维成本与安全风险。
● 金融行业：商汤科技 FinAgent 嵌入银行核心数据平台，实现智能数据生产、投研分析、合规管理到信贷风控的全流程闭环，提升风控效率与服务专业一致性。
● 消费电子：美的 COLMO 代理作为家电全场景 AI Agent，接入全屋 IoT 中枢，整合空气、用水、光影与安全系统，一键智控打通家庭场景端到端体验。
● 矿业领域：网易灵境矿山具身智能模型通过强化学习使挖掘机自主完成矿石分拣，提升作业效率，并与调度系统无缝对接，优化从挖掘到分拣全流程，减少人工依赖。
