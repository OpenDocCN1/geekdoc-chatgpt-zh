# 立体卷积核心三部曲：从数学定义到 C3D 落地

处理视频流或医学体积数据时，三维卷积是提取时空特征的利器。它沿深度、高度、宽度三轴同步滑动核函数，完成立体信息的聚合。本文将按“公式溯源 → 手写验证 → 工程落地”的路径，带你拆解这项技术的底层逻辑。

## 数学层面的本质描述

从数学视角看，立体卷积的核心是将输入体积与滤波器在三维空间内做逐元素加权求和。输出体积在坐标 $(i, j, k)$ 处的数值，等于核函数覆盖区域内所有对应位置乘积的累加，定义式如下：

[PRE0]

G(i, j, k) = \sum_{m=1}^{k_d} \sum_{n=1}^{k_h} \sum_{p=1}^{k_w} K(m, n, p) \cdot S(i-m, j-n, k-p)

## 纯 NumPy 手写内核

为彻底搞清计算细节，我们摒弃框架封装，用基础数组操作还原前向传播过程。下面的脚本包含测试数据构造与核心滑窗逻辑：

[PRE1]

import numpy as np

import pprint as pp

def generate_increasing_volume(d, h, w):

    """

    生成一个递增的张量，每个元素的值为其在张量中的索引值加 1

    参数:

    - d, h, w: 生成张量的深度、高度和宽度

    返回:

    - volume: 生成的递增张量

    """

    return np.arange(1, d*h*w + 1).reshape(d, h, w)

def conv3d(input_volume, kernel):

    """

    对给定的输入张量和指定的卷积核进行三维卷积操作

    参数:

    - input_volume: 三维 numpy 数组，维度对应深度、高度和宽度

    - kernel: 三维 numpy 数组，维度比输入张量阶数小，且每个维度的大小为奇数

    返回:

    - output_volume: 三维 numpy 数组, 卷积操作的输出张量

    """

    d, h, w = input_volume.shape

    kd, kh, kw = kernel.shape

    # 计算输出张量的阶数

    output_d = d - kd + 1

    output_h = h - kh + 1

    output_w = w - kw + 1

    # 初始化输出的张量

    output_volume = np.zeros((output_d, output_h, output_w))

    # 计算三维卷积

    for i in range(output_d):

        for j in range(output_h):

            for k in range(output_w):

                sub_volume = input_volume[i:i+kd, j:j+kh, k:k+kw]

                output_volume[i, j, k] = np.sum(sub_volume * kernel)

    return output_volume

# 生成一个 4x4x4 的三阶递增张量

input_volume_increasing = generate_increasing_volume(4, 4, 4)

kernel = np.array([[[1, 1], [1, 1]], [[1, 1], [1, 1]]]) # 一个 2x2x2 的核

# 对递增张量进行三维卷积操作

output_volume_increasing = conv3d(input_volume_increasing, kernel)

print("输入张量的部分:")

pp.pprint(input_volume_increasing[0:2, 0:2, 0:2])

print("核:")

pp.pprint(kernel)

print("输出张量的部分:")

print(output_volume_increasing[0, 0, 0])

## 实战验证数值正确性

实测阶段：构造边长为 4 的递增立方体作为输入，配合全 1 的 $2 \times 2 \times 2$ 卷积核。在无填充、步长为 1 的条件下，输出形状收缩为 $3 \times 3 \times 3$。首个输出单元对应输入左上角 $2 \times 2 \times 2$ 区域的元素求和，结果为 92.0，与理论推演完全吻合。

## 工程落地：搭建 C3D 骨干网络

掌握底层运算后，调用深度学习框架的高级 API 即可快速组装模型。下方展示基于 PyTorch 的 C3D 原型实现。网络通过交替堆叠立体卷积与下采样模块，逐步压缩空间分辨率、拓宽特征通道，广泛服务于动作识别等视频理解任务。特别留意首个池化层 `pool1` 仅在空间维（高、宽）施行下采样，保留时间轴分辨率，这是处理连续帧序列的关键设计。

[PRE3]

import torch.nn as nn

class C3D(nn.Module):

    """

    C3D, Convolution 3D, 即三维卷积

    """

    def __init__(self):

        super(C3D, self).__init__()

        # 注意到核函数为三维，符合三维卷积的要求

        self.conv1 = nn.Conv3d(3, 64, kernel_size=(3, 3, 3), padding=(1, 1, 1))

        self.pool1 = nn.MaxPool3d(kernel_size=(1, 2, 2), stride=(1, 2, 2))

        self.conv2 = nn.Conv3d(64, 128, kernel_size=(3, 3, 3), padding=(1, 1, 1))

        self.pool2 = nn.MaxPool3d(kernel_size=(2, 2, 2), stride=(2, 2, 2))

        self.conv3a = nn.Conv3d(128, 256, kernel_size=(3, 3, 3), padding=(1, 1, 1))

        self.conv3b = nn.Conv3d(256, 256, kernel_size=(3, 3, 3), padding=(1, 1, 1))

        self.pool3 = nn.MaxPool3d(kernel_size=(2, 2, 2), stride=(2, 2, 2))

        self.conv4a = nn.Conv3d(256, 512, kernel_size=(3, 3, 3), padding=(1, 1, 1))

        self.conv4b = nn.Conv3d(512, 512, kernel_size=(3, 3, 3), padding=(1, 1, 1))

        self.pool4 = nn.MaxPool3d(kernel_size=(2, 2, 2), stride=(2, 2, 2))

        self.conv5a = nn.Conv3d(512, 512, kernel_size=(3, 3, 3), padding=(1, 1, 1))
