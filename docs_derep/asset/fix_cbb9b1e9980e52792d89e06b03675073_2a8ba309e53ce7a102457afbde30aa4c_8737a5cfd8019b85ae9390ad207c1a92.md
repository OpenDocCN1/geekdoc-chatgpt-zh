# GPT-2 输入预处理全流程

想看懂 GPT-2 真正在跑什么，先看 forward 最前面的准备阶段。这里把各种可能的输入形态收敛成统一的隐向量，为首次全量推理和后续逐 token 自回归做好衔接。

整体脉络是先补齐默认值，再校验输入合法性，接着根据缓存状态决定长度和位置编码，最后把遮罩、头掩码准备好，完成词嵌入与位置嵌入的叠加并做一次丢弃，为后面各层的循环提供初始状态。

参数层面，几个开关如果调用时没给值，会回退到配置里的默认策略。输入来源上，原始 token id 和直接传入的嵌入只能二选一，不能同时出现。随后对 token id、类型 id、位置 id 做统一的维度拉直，保证后续操作能稳定进行。

缓存机制决定了输入长度的差异。没有历史缓存时视为首轮推理，序列长度为完整长度；已有缓存后进入自回归阶段，每一步只喂入一个新 token。past_key_values 为空时先用 None 占位，之后取历史缓存的最后一个维度作为已生成长度。位置编码在未显式提供时自动生成，从已生成长度开始连续递增，保证位置不会断裂。

注意力遮罩的处理是把二维的填充掩码升维到四维，方便与多头注意力进行广播相加。保留位置记为 1，被遮住的位置会映射成一个很大的负数进入 softmax，从而被实际忽略。交叉注意力开启且有编码器状态传入时，会同步构建编码器侧的掩码并做反转处理。头掩码则通过统一接口生成，用于后续对指定头的保留或屏蔽。

嵌入阶段先用词表嵌入把 id 转成向量，再加上位置嵌入；如果提供了类型信息，还会叠加类型嵌入。随后经过一次 dropout，得到本次步骤的隐状态，并据此推算输出的整体形状。缓存相关以及是否收集注意力、隐藏状态的标志在这里初始化，为后面的层级遍历做准备。
