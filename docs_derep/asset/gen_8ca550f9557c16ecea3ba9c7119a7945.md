### 从 BP 到 BPTT：揭秘 RNN 反向传播的核心差异

在标准前馈网络中，反向传播（BP）的流程相对直观：计算输出层损失对预测值的导数（记为 $\Delta_y$），即为输出层需修正的量；随后利用隐藏层输出 $h$ 的转置与 $\Delta_y$ 相乘得到 $\Delta_{p1}$，据此更新权重 $p1$；最后将误差继续向前传递，计算 $\Delta_h$ 并更新前序权重 $w1、w2$。

然而，循环神经网络（RNN） 引入了时间维度，彻底改变了梯度流动的路径。如图 9-6 所示，假设一个批次数据 A、B、C 依次进入网络。正向阶段，B 的计算融合了 A 遗留的隐藏状态 $h$；反向阶段，梯度则按 **C → B → A** 的逆序回溯。

关键差异在于隐藏层梯度 $\Delta_h$ 的来源：BP 中 $\Delta_h$ 仅取决于当前时刻的 $\Delta_y$；而 BPTT 中，某一时刻（如 B）的 $\Delta_h$ 需融合 **当前时刻的 $\Delta_y$ 与下一时刻（C）回传的 $\Delta_h$**。这种跨时间步的梯度累加，正是 RNN 能捕捉长距离依赖，也易遭遇梯度消失/爆炸的根本原因。

### 9.2 简单 RNN：从“裸写”核心逻辑到 TensorFlow 实战

#### 9.2.1 实战 55：纯 Python 手写 RNN —— 攻克二进制“退位减法”

**核心思路**：退位减法天然具备序列依赖性——低位借位状态必须传递给高位，这与 RNN 隐状态传递机制完美对应。我们将用 NumPy 从零实现前向、反向全流程，无任何深度学习框架依赖。

**1. 基础组件：激活函数与导数**
手写 Sigmoid 及其导数，为反向传播提供非线性映射与梯度计算基础。

**2. 参数初始化：三组核心权重**
- `synapse_0`：输入层 → 隐藏层
- `synapse_h`：上一时刻隐藏层 → 当前隐藏层（循环权重）

**3. 样本生成：二进制减法数据集**
随机生成整数对 $(a, b)$，保证 $a \ge b$，计算差值 $c$，将三者统一转为固定长度的二进制向量，低位在前（便于按位序处理）。

[PRE5]

**4. 前向传播：模拟“竖式减法”**
从最低位（个位）开始循环：
- 拼接当前位输入与上一时刻隐藏状态
- 计算当前隐藏状态与输出预测
- 记录每一时刻的隐藏层输出（`layer_1_values`）与输出层误差导数（`layer_2_deltas`），供反向回溯使用
- 累加总体误差
首次迭代无历史状态，隐藏层初始化为 0.1。

[PRE6]

**5. 反向传播：逆序梯度回溯 (BPTT 核心)**
从最高位（最后一步）向最低位反向遍历：
- 初始化“下一时刻隐藏层梯度”为 0（终点无后续）
- 当前时刻隐藏层梯度 = **输出层回传梯度 + 下一时刻隐藏层梯度经循环权重回传** —— 此处直观体现 BPTT 与 BP 的本质区别
- 按链式法则分解至三组权重，累加各时刻梯度
- 批量更新权重，清空中间缓存
