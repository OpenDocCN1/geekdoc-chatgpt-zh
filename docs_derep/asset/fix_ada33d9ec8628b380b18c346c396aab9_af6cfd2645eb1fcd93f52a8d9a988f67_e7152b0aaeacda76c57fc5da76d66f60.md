ID3 即 Iterative Dichotomiser 3 决策树算法，1986 年由 Ross Quinlan 提出，是一种基于信息增益的分类模型，广泛用于数据挖掘与知识发现。下面做简明介绍。

### 算法概述
ID3 的核心是通过挑选信息增益最大的特征来对数据集进行划分，从而逐步构建决策树。信息增益用于衡量某个特征对分类结果的区分能力，算法递归选择特征并分裂数据，最终形成完整树结构。

### 信息增益
信息增益是 ID3 选择特征的标准，根植于信息论中的熵。

1. 计算数据集的熵，熵越高不确定性越大。
2. 计算特征条件下的条件熵。
3. 信息增益等于整体熵减去条件熵。选择增益最大的特征作为当前节点分裂点。

### 算法步骤
1. 初始化：从根节点开始，计算当前数据集的熵。
2. 选择特征：计算每个特征的信息增益，选择最大值进行分裂。
3. 分裂数据集：根据所选特征把数据分成子集。
4. 递归构建子树：对每个子集重复上述过程，直至满足停止条件，如所有实例同类或无剩余特征。
5. 生成决策树：所有节点满足停止条件时得到完整树。

### 优缺点
优点：
- 简单易懂，易于实现。
- 生成的树具有良好可解释性。

缺点：
- 对噪声数据敏感，容易过拟合。
- 只能处理离散特征，连续特征需要离散化。
- 不支持缺失值处理。

### 应用场景
ID3 适用于需要解释性强的分类任务，如信用评分、医疗诊断等。实际使用常与其他技术结合，如剪枝或改用改进版 C4.5。

总之，ID3 是机器学习中经典的分类算法，虽有局限，但凭借简单与可解释性在诸多领域仍被广泛使用。
