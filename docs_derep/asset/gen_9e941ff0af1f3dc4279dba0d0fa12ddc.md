- (2) 调用情感分析接口获取语录的情感标签与分值；
- (3) 依据分值或直接使用后端返回的颜色更新 @State backgroundColor，达成背景色的动态切换；

### 6.2 多服务与硬件协同联动与控制

本章重点介绍 ProjectSymphony 项目如何借助大模型文本生成、情感分析、硬件设备控制以及数据库监测等多个环节，实现多服务协同与硬件联动，构建一个能实时感知情绪变化并同步刷新页面与硬件状态的综合系统。

项目采用模块化思路，各模块职责明确，以不同文件分散在工程目录中，为后续开发、维护与扩展提供支撑。整体主要由以下三个核心模块构成。

### 1. EmotionColorMapping模块

该模块承担情感分析、文本生成与颜色映射的工作。除处理系统配置如 Config.ets 外，还封装了 API 请求 ApiService.ets、情感分析及文本生成 EmotionService.ets 的核心逻辑。内部定义了 API 数据类型 ApiTypes.ets，并提供颜色映射 ColorUtils.ets、图片下载处理 DownloadUtils.ets、HTTP 客户端封装 HttpClient.ets 以及流数据处理 StreamingUtils.ets 等工具。
