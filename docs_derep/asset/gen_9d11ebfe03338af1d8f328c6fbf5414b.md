#### 2.2.2 分类评估指标速览

在二分类任务中，最常用的对照维度是精确率、召回率、F1、TPR 与 FPR。

表2-1中TP表示正样本被模型判为正样本，即真正例 true positive。

### 表2-1 TP、FN、FP和TN定义

| | 预测为真 | 预测为假 |

|---|---|---|

| 真实为真 | TP | FN |

| 真实为假 | FP | TN |

FN指正样本被判为负样本，即假负例 false negative。

FP指负样本被误判为正样本，即假正例 false positive。

TN指负样本被正确判为负样本，即真负例 true negative。

精确率 Precision = TP / (TP + FP)。
召回率 Recall = TP / (TP + FN)。
真正例率即正例被正确识别的概率 TPR = TP / (TP + FN)。
假正例率即反例被误认为正例的概率 FPR = FP / (TN + FP)。

精确率又称查准率，偏向对正确性要求高的场景，比如网页检索与推荐。召回率又称查全率，偏向需要尽可能不漏检的场景，比如信贷风险与逃犯筛查。两者存在此消彼长的关系，于是常用F1来做折中，F1是精确率与召回率的调和平均：

1 / F1 = 1/2 * 1/P + 1/2 * 1/R

### （1）错误率和准确率

错误率 e = 1/n Σ_{i=1}^n I(f(x_i) ≠ y_i)。
准确率 acc = 1 - e。

### （2）AUC与ROC曲线

对于0、1分类问题，部分模型输出的是概率分数，例如神经网络给出0.5、0.6等。此时需设定一个阈值cutoff，小于阈值归为0类，大于等于阈值归为1类，从而得到硬标签。不同阈值会带来不同的分类结果。

ROC曲线以False Positive Rate为横轴，True Positive Rate为纵轴绘制。曲线上的点刻画了灵敏度与特异度之间的权衡，假阳性越小则真阳性往往也越小。曲线下方面积越大，说明两类区分能力越强。AUC即ROC曲线下的面积。AUC可理解为随机抽取一对正负样本，模型将正样本排在负样本前面的概率。AUC越大，排序能力越好；AUC=0.5等同于随机猜测，模型无预测价值。如图2-1所示。

### 2.3 特征工程

在机器学习工程实践中有一句共识：“数据和特征决定了机器学习的上限，而模型和算法只是逼近这个上限而已。”可见特征工程的地位。整体工作可拆为四个方向：数据预处理、特征选择、特征降维、特征构造。

在面试交流中，面试官更关注结合过往项目，如何在每个环节挑选合适的算法并落地，例如在数据预处理、特征选择、特征降维中如何选型，以及如何从业务中抽象出有价值的构造特征。

#### 2.3.1 数据预处理核心操作

### 1. 无量纲化

无量纲化的目的在于消除不同指标量纲差异，让各特征落到同一尺度。常见做法有标准化和区间缩放。标准化的前提假设是特征近似正态分布，处理后变为标准正态。区间缩放依赖边界信息，将取值范围压缩到指定区间，例如[0, 1]。

### （1）标准化

工程中样本量足够大时，常直接用标准化做无量纲化。在深度学习里，将输入归一到特定范围有助于反向传播的收敛。若不做标准化，数值大的特征会主导损失函数，数值小的特征影响被压制。标准化能让各特征贡献更均衡。公式为：

x' = (x - μ) / σ

### （2）归一化/区间缩放法

归一化更适用于样本量较小的场景。思路是用最大值与最小值做缩放，公式为：

x' = (x - min) / (max - min)

### 3. 缺失值补充

常用的补全方式有均值填充、就近补齐、K最近邻填充等。注意缺失本身有时也是信息，可额外加一列标记缺失与否，是否采用需结合业务判断。

缺失值比例较高时，直接舍弃该列更稳妥，否则噪声会干扰结果。若缺失比例较低，如小于10%，可考虑填充，常见策略如下：

- 1. 用异常值填充并把缺失作为单独特征处理，如0或-9999。
- 2. 用均值或条件均值填充，数据不均衡时优先条件均值，即同标签下数据的均值。
- 3. 用相邻数据填充。
- 4. 利用插值算法。
- 5. 数据拟合，把缺失值补全视作预测问题，用随机森林等对有值样本建模，再预测缺失位置。

下面简要说明随机森林做降维的思路。

随机森林因抽样与特征随机选择，具有较小的系统误差与较好的分类表现。建树时采用有放回抽样保证样本随机性，分裂时随机挑选特征保证多样性。

评估特征重要性时，通常以基尼系数衡量每棵树中该特征带来的不纯度下降幅度并取平均。以基尼系数作为评价指标。

变量重要性评分用V表示，假设有m个特征X₁, X₂, …, Xₘ，则特征Xⱼ的Gini评分Vⱼ为其在所有树上节点分裂不纯度平均改变量。Gini指数计算为：

$Gini_m = 1 - \sum_{k=1}^{K} p_{mk}^2$

其中k为类别，pₘₖ为节点m中类别k的比例，K为类别数。

特征Xⱼ在节点m的重要性，即分裂前后Gini的变化：

$V_{jm}^{Gini}=Gini_m - Gini_l - Gini_r$

其中Giniₗ和Giniᵣ为分裂后两个子节点的Gini指数。

若特征Xⱼ在第i棵树出现的节点集合为M，则该特征在第i棵树的重要性为：

$V_{jm}^{Gini} = \sum_{m \in M} V_{jm}^{Gini}$

随机森林共有n棵树，则：

$V_{jm}^{Gini} = \sum_{i=1}^{n} V_{ij}^{Gini}$

最后归一化得到相对重要性：

$V_j^* = \frac{V_j}{\sum_{i=1}^{c} V_i}$

#### 2.3.3 特征降维方法

特征矩阵过大时训练耗时显著增加。降维是在保留信息的前提下压缩维度，其有效性取决于特征所含信息量与降维方法。常用方法包括PCA、LDA、奇异值分解SVD和局部线性嵌入LLE。降维可节省存储、加速计算并缓解过拟合。

### 1. 主成分分析法（PCA）

PCA是对数据做线性变换，使第一坐标上投影方差最大，称为第一主成分，第二坐标次之。目标是让降维后向量间尽可能不相关，并最大化保留原始信息。步骤如下：

- (1) 计算相关系数矩阵

$R = \begin{bmatrix} r_{11} & \cdots & r_{1p} \\ \vdots & & \vdots \\ r_{p1} & \cdots & r_{pp} \end{bmatrix}$

$r_{ij}(i, j=1, 2, \cdots, p)$为原变量$x_i$与$x_j$的相关系数，计算公式为：

$r_{ij} = \frac{\sum_{k=1}^{n} (x_{ki} - \bar{x}_i)(x_{kj} - \bar{x}_j)}{\sum_{k=1}^{n} (x_{ki} - \bar{x}_i)^2 (x_{kj} - \bar{x}_j)^2}$

- (2) 计算特征值与特征向量

解 $|\lambda I - R| = 0$，用雅可比法求得特征值并按降序排列 $\lambda_1 \ge \lambda_2 \ge \cdots \ge \lambda_p \ge 0$；对应特征向量为 $e_i$，且 $||e_i|| = 1$。

### （3）计算主成分贡献率及累计贡献率

单位特征向量 $e_i$ 即主成分 $z_i$ 的系数，$z_i = x e_i^T$。

贡献率：

$\alpha_i = \frac{\lambda_i}{\sum_{k=1}^{p} \lambda_k} \qquad i=1,2,\cdots,p$

累计贡献率：

$\frac{\sum_{k=1}^{i} \lambda_k}{\sum_{k=1}^{p} \lambda_k} \qquad i=1,2,\cdots,p$

通常选取累计贡献率达85%～95%的特征值 $\lambda_1$, $\lambda_2$, …, $\lambda_m$ 对应的前m个主成分。

### （4）计算主成分载荷

载荷反映主成分 $z_i$ 与原变量 $x_j$ 的关联程度。

$l_{ij} = p(z_i, x_j) = \sqrt{\lambda_i} e_{ij} \quad (i,j=1,2,\cdots,p)$

### 2. 线性判别分析法（LDA）

LDA是有监督降维，将高维样本投影到类间距离最大、类内距离最小的子空间，目标是让同类更紧凑、异类更分离。

LDA与PCA的主要区别：

- 1) LDA是有监督降维，PCA是无监督。
- 2) LDA最多降到类别数k-1维，PCA无此限制。
- 3) LDA选择分类性能最优的投影方向，PCA选择样本方差最大的方向。PCA追求发散性，LDA追求可分性。
