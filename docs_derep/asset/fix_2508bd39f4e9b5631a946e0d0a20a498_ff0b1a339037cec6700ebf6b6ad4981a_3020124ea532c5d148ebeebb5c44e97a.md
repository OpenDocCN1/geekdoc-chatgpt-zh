剪枝的核心作用，是把原本稠密的神经网络改造成稀疏结构。前面已经提到，稀疏矩阵的计算在 GPU 上提速有限，而可编程逻辑阵列在这一类负载下表现更顺手。2017 年的 FPGA 国际会议上，韩松团队发表了 ESE：Efficient Speech Recognition Engine with Sparse LSTM on FPGA，系统阐述了借助 FPGA 加速稀疏 LSTM 的思路，以及稀疏矩阵向量乘和单元乘法器的实现方法。把该方案实现在赛灵思 Kintex UltraScale 器件上后，对比英特尔 Core i7 5930k CPU 性能约高 43 倍，对比英伟达 Pascal Titan X GPU 约高 3 倍。得益于可编程逻辑的高能效，同等场景下能效比 CPU 约高 40 倍，比 GPU 约高 11.5 倍。

### 3.2.3 深度压缩
深度压缩是韩松 2016 年提出的整合方案，可看作前面几种手段的集合。整体分三步，如图 3-8 所示。第一步用迭代剪枝，在尽量保住精度的前提下剔除权重较小的分支。第二步做权重量化与共享，让多个连接复用同一个数值，只需保存有效权重和索引，不必保留完整的权重矩阵，同时共享权重也降低了位宽需求。第三步用霍夫曼编码对分布不均的权重做无损压缩。采用这套流程，AlexNet 被压缩 97%，从 240MB 降到 6.9MB；VGG-16 被压缩 98%，从 552MB 降到 11.3MB。正因效果突出且学术价值高，论文 Deep Compression：Compressing Deep Neural Networks With Pruning，Trained Quantization and Huffman Coding 获得 2016 年 ICLR 大会最佳论文。

深度压缩最直观的收益是大幅降低内存占用。其一减少了访存带来的时延和功耗，其二压缩后的参数可以直接放在片上存储，不必依赖片外存储。对 FPGA 加速单元而言意义尤其大。FPGA 的片上存储读写带宽很高但容量有限，片外存储容量大却带宽相对偏低，常成为传统深度神经网络加速的瓶颈。有了深度压缩配合，就能绕过片外带宽的制约，充分利用 FPGA 的片上存储，将系统能效大幅拉升。

## 3.3 下一个 Big Thing：FPGA 公司在 AI 时代的布局

### 3.3.1 赛灵思
2018 年，赛灵思新任 CEO Victor Peng 走马上任。这位出生台湾、在纽约皇后区长大、康奈尔大学毕业的掌舵人拥有深厚工程背景，上任后即宣布战略转型，把数据中心列为优先方向，其中人工智能是核心应用。

Peng 上任第一年，赛灵思推出了下一代计算平台 ACAP。发布时反复强调 ACAP 融合了硬件可编程逻辑单元、软件可编程处理器以及软件可编程加速引擎。与传统 FPGA 相比，ACAP 的关键创新之一是内置人工智能加速引擎系列，用来加速机器学习和无线网络中常见的数学与矩阵运算，这款产品明显是为人工智能定制。

同年七月，赛灵思收购了国内人工智能芯片初创公司深鉴科技，收购时间距离深鉴完成 A+轮融资不到 9 个月。深鉴由清华大学几位创始人创立，在 FPGA 与人工智能交叉领域积累深厚，研发实力突出。赛灵思此前一直是深鉴的 FPGA 供应商、主要合作伙伴和投资方，曾领投其 A 轮。

2019 年，赛灵思发布 Vitis 设计软件，包含面向人工智能应用的软件开发框架和库，并提供预训练和优化过的模型。其中深鉴的深度压缩、量化、剪枝技术，以及深鉴的 DNNDK 开发框架也被整合进 Vitis 的 AI 优化器。

### 3.3.2 英特尔
与赛灵思相比，FPGA 业务在英特尔整体营收中占比很小。但从公司层面看，英特尔在人工智能的布局更广。错过移动计算时代后，人工智能芯片成为英特尔不能再错过的赛道，尤其在数据中心面临巨大压力。英伟达 GPU 已基本垄断了数据中心人工智能训练计算，同时谷歌、亚马逊、微软、脸书等国外巨头，以及阿里、腾讯、百度等国内厂商都在加码自研深度学习加速芯片。英特尔必须尽快抢占份额，避免重蹈移动时代覆辙。

近年英特尔相继收购多家人工智能芯片创业公司：面向终端人工智能计算的 Movidius、面向自动驾驶的以色列公司 Mobileye、面向云端人工智能计算的 Nervana，以及 2019 年完成的 Habana Labs 等。这些公司已成为英特尔人工智能布局的重要推手。Mobileye 多个季度实现创纪录双位数增长，成为英特尔增速最快的业务；Movidius 与 Nervana 分别推出面向各自场景的 DNN 训练与推理 ASIC，如 NNP-I 与 NNP-T。2020 年初，英特尔大幅调整人工智能芯片路线图，将 Habana 的 Gaudi 系列 DNN 训练芯片和系统作为主打方案。

在传统强项数据中心 CPU 领域，英特尔也在 Xeon 可扩展处理器中加入深度学习加速引擎 DL Boost，用以加速人工智能推理。同时公司正加速自研高性能独立 GPU，旗下 Xe 产品已多次被提及。

FPGA 对英特尔整体占比不大，却在人工智能的数据传输、计算和硬件加速等场景中举足轻重。2019 年英特尔发布新一代 FPGA 旗舰 Agilex 系列，内置多项面向人工智能计算优化的硬件单元，如可变精度 DSP。

与赛灵思一样，英特尔也在通过收购补强人工智能技术储备。2019 年 4 月，英特尔收购英国公司 Omnitek。Omnitek 主营基于 FPGA 的视频图像处理 IP，涵盖超高清视频图像旋转、形变、3D 映射、编解码等，但在深度学习领域也有建树。2018 年底，Omnitek 发布自研深度学习处理器 DPU。

用户可基于 TensorFlow、Caffe 或 OpenVINO 等主流框架构建模型，或自行用高级语言编写模型，通过 DPU 编译器生成特定微代码，用以配置 FPGA 上 DPU 的数据处理流水线，这与微软 DPU 采用数据流图的方式不同。

### 3.3.3 Achronix
相较两家老牌厂商，Achronix 更像是 FPGA 领域近年崛起的新星。总部位于硅谷圣克拉拉的公司已有 16 年历史，但近两年发展迅猛，季度营收从 2016 年第四季度的 500 万美元，一年后跃升至 4000 万美元，成为当时全球增速最快的半导体企业之一。

2019 年 5 月底，Achronix 发布 Speedster7t FPGA，主打高速网络传输、机器学习加速等热门领域，有与赛灵思、英特尔正面竞争的势头。该款 FPGA 为人工智能计算做了专门优化，集成多个机器学习处理器，支持不同定点数及浮点数运算。片上内存最高可达 300Mb，与英特尔高端产品 Stratix10 相当。

Speedster7t 基于台积电 7nm 工艺制造，与 ACAP 一致，也对标 Agilex 系列。

架构上采用遍布芯片的 2D 片上网络，与 ACAP 的思路相似。片上网络用于应对高吞吐低延迟场景，例如数据中心、5G 需要 FPGA 线速处理高达 400Gbps 以太网流量。传统设计需 1024 位宽总线并以 724MHz 运行才能满足带宽。可编程逻辑单元常需在芯片不同位置传输数据，包括片上/片外存储器及各类加速模块，如机器学习加速器，必须采用新型片上网络。

Speedster7t 采用横向纵向 2D 片上网络，以 256 位宽 AXI 总线实现，运行频率高达 2GHz，提供单路 512Gbps、总计 20Tbps 的片上网络带宽。除满足带宽外，还能把片上逻辑划分为相对粗粒度的区域，降低布局布线复杂度，提升时序收敛速度。

历经 16 年积累，Achronix 已拥有与两大巨头抗衡的技术储备，其在人工智能时代的表现值得持续关注。

## 3.4 路在何方：FPGA 在 AI 时代未来的发展方向
人工智能与深度神经网络算法日新月异，相较 CPU、GPU、ASIC，FPGA 具备独特优势。与此同时，FPGA 及可编程逻辑技术也在持续演进，以适应不断涌现的新算法与新需求。

例如 FPGA 架构正集成越来越多人工智能相关硬件资源。传统 FPGA 片上 DSP 已从仅支持固定字长定点计算，扩展到支持多种精度浮点及可变精度定点，可按需灵活配置。人工智能专用的加速引擎也逐渐集成到 FPGA 与 ACAP 器件中。可预见未来会有更多面向人工智能加速的架构创新，如对矩阵运算与乘加运算的进一步支持、对访存的优化、利用片上网络提升数据传输吞吐等，这些都是学界与产业的热点。

除将人工智能加速单元以 IP 形式集成外，还可将人工智能处理子系统与 FPGA 异构集成。通过 EMIB 或芯片组桥接等方式，把 FPGA 与不同人工智能加速芯片互联并在系统级整合，形成多芯片封装 MCP。异构系统可发挥 FPGA 与 ASIC 的互补优势，提升性能并降低功耗与延迟。随着 FPGA 异构芯片能效不断提升，其用于 DNN 训练也将成为重要方向。

再好的芯片也离不开工具易用性。相较 CPU 与 GPU，FPGA 开发难度大、调试困难、学习曲线陡峭，始终是制约其推广的关键。在人工智能领域，要求软件工程师或算法专家掌握高性能 FPGA 开发并不现实。因此如何提升易用性与开发效率，如何用高层次语言编程 FPGA，如何封装复用现有人工智能 IP，将成为学界与业界共同关注的焦点。

目前英特尔与赛灵思均支持基于 OpenCL 的 FPGA 高层次开发语言，并发布各自 API 与 SDK，一定程度上降低了门槛，让软件工程师可用相对熟悉的语言在 FPGA 上开发。但开发者仍需了解 FPGA 基础架构与设计约束，才能引导工具实现有效优化。基于 OpenCL 的 FPGA 设计移植性不佳，严重依赖厂商工具与底层模块，调试也困难。高层次语言开发 FPGA 的更多问题与挑战将在下一章详述。

除 OpenCL 外，英特尔还推出基于 OpenVINO 的 FPGA 开发套件，专为计算机视觉应用优化，面向深度学习在边缘计算的场景。OpenVINO 支持英特尔全栈视觉加速方案与硬件平台，除 FPGA 外还包括 CPU、GPU、Movidius VPU 等，并兼容多种深度学习框架。提出领域专用的框架、语言、开发套件并以 FPGA 作为硬件加速单元，将是业界接下来重要方向。

同时 FPGA 在人工智能的应用正逐步向网络边缘与端点扩展，如智能安防、视频采集处理、自动驾驶与机器人等。边缘计算加人工智能一直是国内外初创企业切入市场的主要路径。用 FPGA 可在数据来源处完成人工智能模型推理与处理，并做硬件加速，这也是众多公司参与的热门领域。

## 3.5 本章小结
诞生 30 年后，FPGA 在人工智能时代重新焕发活力，这既源于其架构特性，也得益于技术不断迭代创新。人工智能及其应用已成为 FPGA 公司的战略方向。软件与互联网公司如微软也在积极拥抱 FPGA，将其作为加速人工智能应用的重要引擎。这些成果只是开端，FPGA 必将延续发展脚步，在人工智能时代创造新成就。

# 第 4 章 更简单也更复杂——FPGA 开发的新方法
美国加州大学洛杉矶分校丛京生教授是 FPGA 学术研究领域的领军人物，发明了多项高效 FPGA 设计工具与算法，并成功商业化，如 AutoESL、Falcon Computing 等。他在 2020 年 ASP-DAC 主旨演讲中指出，其学术生涯大致分两阶段：2009 年前聚焦面向硬件设计人员的电子设计自动化，帮助硬件工程师更快更好完成设计；过去十年则转向面向软件工程师的可定制电路 EDA。之所以转向，既因业界对可编程逻辑需求升温，也因 FPGA 开发伴随诸多难点与挑战。

FPGA 这一“特殊”芯片历经 30 余年发展，已成为集先进电路、逻辑单元、接口、封装、制造技术于一体的集大成者。芯片硬件不断进化，开发软件与设计工具也在持续迭代。一方面，设计工具不断整合前沿算法与创新成果，在基于硬件描述语言 HDL 的流程基础上，逐渐演化出基于高层语言的设计方法，其中最具代表性的是高层次综合 HLS。通过高层设计隐藏了 FPGA 的底层逻辑与实现细节，使软件与算法工程师能聚焦算法实现，在很大程度上让 FPGA 开发变得更简单。

另一方面，这些高层次设计工具也带来诸多难题。对使用者而言，FPGA 的高层次设计并不像 CPU 或 GPU 应用设计那样可以随意使用语言、框架或设计模式。FPGA 仍要求设计者在一定程度上理解内部架构，才能引导高层综合工具获得优化的系统性能，这反而让高层次开发变得更复杂。

本章将详细介绍近年涌现的 FPGA 开发新方法及其对开发流程的影响，并介绍 FPGA 厂商为顺应这一趋势推出的新型设计工具，以及开发工具与方法未来的发展方向。
