# RAG实战派：让大模型基于真实知识回答

## 内容提要

当生成式大模型已成为智能系统的核心驱动力，检索增强生成便成为补足模型先天局限、提升输出可信度的关键手段。本书以RAG全生命周期为线索，把架构设计和工程实现拆开讲清，帮助研发人员与企业搭建稳定、可控、可持续优化的问答能力。

首部分从多源资料接入、文本切分、向量化表示、向量库写入这条主线出发，梳理原始数据到结构化预处理的完整链路，并展开嵌入模型的选择逻辑、适配性微调思路以及多模态扩展方法；其后聚焦检索前环节的问法构建、意图改写、路由分发与索引优化，以及检索后的重排压缩，系统说明召回与相关性提升的做法；随后介绍多种生成策略及可落地的评测体系；最后面向前沿形态，解析GraphRAG、模块化RAG、Agent化RAG与多模态RAG的搭建路径。

适合AI研发工程师、企业技术负责人、知识管理从业者，以及关注RAG落地的高校师生。无论是快速搭原型验证想法，还是精细打磨检索性能，或是探索下一代AI系统形态，本书都能提供方法论与工程参考。

第一条是利用大模型的逻辑推理与工具调用能力，在业务与产品的各层构建具备代理性的应用。可参考我在《大模型应用开发 动手做AI Agent》中描述的“Agent演化5个层级”。A2A协议的出现为此注入新活力，它通过定义智能体间通信标准，如Agent Card、任务管理与消息传递，使不同框架下的智能体协同工作并动态协商交互。

第二条是做好大模型时代的知识检索。通俗说，大模型像汇聚人类历史智慧的水晶球，但获取知识有门槛。如何在特定时间、场景、企业需求下快速精准获取所需知识，是应用开发的核心课题。

基于大模型进行知识检索的开发复杂度可高可低。从简单的提示词对话，到万亿参数的训练与微调，只要借助大模型获取知识，即为大模型应用开发。随着需求提升，逐步引入更复杂技术以释放大模型潜力变得重要。

在这条演进路径上，从简单到复杂，从通用到专业，覆盖了提示工程、检索增强生成与模型微调三大领域。

### 突破：RAG驱动的知识跃迁

当应用需引入大量外部知识时，RAG成为关键。这是一种融合信息检索与生成式AI的技术框架，通过从外部知识库检索相关信息增强大模型生成能力，提升上下文相关性与回答准确性。

RAG的核心在于，面对问题时模型并非依赖训练时“记住”的知识作答，而是可访问外部知识库或文档集，检索相关片段，将最新或特定领域的外部信息纳入思考过程，再生成回答。换言之，RAG让大模型能“查资料”，把静态、受限于训练时间的语言模型转变为可动态获取信息、实时扩展知识的智能体。于是对大模型的“闭卷考试”瞬间变为“开卷考试”，其对应用效果的提升潜力可想而知。

RAG的核心组件包括知识嵌入、检索器与生成器。

- 知识嵌入：读取外部知识库内容并切分为块，通过嵌入模型把文本或其他形式知识转为向量表示，使其可在高维语义空间比较。这些向量捕捉句子或段落深层语义，并被索引存储在向量数据库中以支持高效检索。
- 检索器：负责从外部知识库的向量表示中查找与用户输入相关信息。检索器采用嵌入向量技术，通过计算语义相似性快速匹配相关文档。常用方法包括基于稀疏向量的BM25和基于密集向量的近似最近邻检索。
- 生成器：利用检索器返回的相关信息生成上下文相关的答案。通常基于大模型，在内容生成过程中整合检索到的外部知识，确保结果流畅可信。

从执行流程看，系统可进一步细化为以下10个阶段。

- 数据导入：将原始数据加载到系统中，通常包括多种格式文档、数据库与文件。
- 文本分块：把大文档切分为易处理的小块，以优化检索效率与信息嵌入。
- 信息嵌入：为每个文本块生成向量表示，捕捉语义信息，便于高效检索。
- 向量存储：存储生成的嵌入向量及其关联原始文本，常用工具包括Milvus、Pinecone等。
- 检索前处理：对查询进行预处理或转换，提升检索精度，例如通过查询扩展或语义重构。
- 基于索引的检索：基于知识库构建时设计的索引结构，从向量存储中查找最相关文档，并返回给生成器。
- 检索后处理：对检索结果进行清洗、排序或格式化，以便生成器更好地利用。
- 响应生成：生成器根据用户输入及检索结果生成最终答案。
- 系统评估：对生成结果进行质量评估，包括准确性、一致性与覆盖率。
- 复杂检索策略和范式：在特定场景下采取各种策略优化整体性能，如与知识图谱结合、与自主代理结合进行多轮检索或多知识源检索。

RAG是大模型时代应用开发的一项重要创新，它弥补了大模型单纯靠参数记忆知识的不足，使其在应对变化或高度专业化问题时更具适应性与灵活性。因此，RAG不仅提升了回答的准确性、时效性与权威性，也为大模型落地各垂直领域应用提供了广阔空间与技术基础（见图4）。图4 RAG在各类垂直领域的应用场景
