辛顿那篇开创性论文带出来的是一个叫做深度信念网络 DBN 的生成式模型。模型的本身功能并不是重点，真正让学界震动的是它把无监督学习正式拉进了神经网络的训练流程。

在误差反向传播盛行的年代，网络一开始的权重全靠随机撒点，随后靠梯度修正去找最优。两三层还能勉强收敛，层数一多各种问题就冒出来，训练难度陡增，这也是很长一段时间里神经网络只能停留在浅层的主要原因之一。具体深层卡在哪儿后面会展开，这里先留一个判断。

为了解开这个结，辛顿提出了逐层预训练 Layer-Wise Pretraining 的思路。先让每一层用无监督的方式把自己的初始权重训好，再进入整体微调。实操下来，先热身后精修的做法，比直接从随机起点开干要稳得多。

这样一来，训练被拆成两段，前半段模型自己摸数据结构，后半段再注入少量标签做监督强化。效果被实践证实不错，但和神经网络里许多经验法则一样，并没有严格的数学证明来保证它一定优于纯随机初始化。辛顿用一个生活化的说法来解释这种预训练的直觉：小孩学认牛，不需要看百万张标注好的照片，他先自己记住牛的样子，再问妈妈这是什么，得到确认后就记住了。深度学习也该如此。

DBN 的每一层本质上是受限玻尔兹曼机 RBM 的堆叠。RBM 是基于玻尔兹曼分布的概率模型，只由可见层和隐藏层两部分构成，层内没有连接，层间是双向无向的，所以叫受限。堆叠时，前一个 RBM 的隐藏单元直接作为下一个 RBM 的可见单元，层层接力就形成了整条信念链。

图 7-17 受限玻尔兹曼机

RBM 本身就是一种概率型的特征提取器。用它做预训练，相当于给每层权重一个更合理的初始位置，比纯随机起点更有利于后续学习。有了这个起点，语义相近的样本在网络内部更容易聚到一起，后面再做有监督时就更顺手。形象地说，模型先嘀咕“这两个长得像，先放一起”，等标签告诉它“这叫萨摩耶”，它就能推出“原来这类长相对应的就是萨摩耶”。

DBN 出现之前，自编码器 Auto Encoder 这类无监督特征方法已经在探索。

DBN 的一个标志性特征是随着层数增加，表现往往也跟着提升，这让很多人第一次认真看待神经网络的潜力。一旦深度与效果正相关，加深网络的价值就显而易见。随后它不仅能做特征识别与分类，还能按最大概率生成数据。用大量英文维基训练出来的 DBN，曾写出一段看上去像人类手笔、实则语义混乱的文字。放在 2006 年，这已经足够震撼；放到 2024 年的 GPT 时代就显得平平无奇。前 LLM 时代，Meta、谷歌、百度、今日头条等不少平台都用类似思路做自动写稿、配图文字。谷歌发表的《Neural Image Caption Generator》就是典型代表。

#### 7.5.4 2012 的破局
DBN 与深度学习在 2006 年提出后沉淀了六年，2012 年在 ImageNet 上彻底引爆。在当年的大规模视觉识别挑战赛 ILSVRC 上，深度方法不仅夺魁，而且是以碾压之势击败所有传统浅层方案。

ImageNet 由斯坦福的李飞飞和普林斯顿的李凯联合打造，自 2010 年起每年举办 ILSVRC，用来量化对比物体分类与检测能力。该赛事兼具对抗性和可量化性，很快成为学界与媒体关注的焦点。

2012 年，辛顿与学生伊利亚·苏茨克维、亚历克斯·克里切夫斯基一起带着 AlexNet 参赛，首次露面就拿下冠军。真正吸睛的不是冠军本身，而是方法论的彻底不同。核心是基于卷积神经网络的识别。

#### 7.5.5 深度一定更强吗
眼下我们正处在深度学习的顶峰，但“越深越强”仍是疑问。网络会随隐层增多而一直无往不利吗？继续加深最终会触及机器智能，还是像浅层方法一样撞上天花板？

一年后的 ILSVRC 2016，冠军模型依然比前一年更深，物体检测子项甚至出现了 1207 层的夸张结构。但与此同时，Facebook 研究院推出的广残差网络 Wide Residual Network 开始“返璞归真”，仅用 16 层就超过了前一年 152 层残差网络的成绩。

2014 年，来自 Facebook 与微软研究院的研究员发表《Do Deep Nets Really Need to be Deep?》，他们用模型压缩的方法让浅层网络模拟已训练好的深层网络，论证在特定条件下浅层可以达到相当表现。训练集上可能略逊，测试集与实际应用中却不相上下。

实践证明了深度学习的效用，说明它确实抓住了某些关键。但当下绝大多数模型、算法与技巧都靠试错堆出来，缺乏完备的理论支撑，我们并不清楚它到底抓住了什么。如果未来理论真正揭示智能本质，也许最优解会是一个浅层或中等深度的结构。现在说深度越深越好，有点像“头大的人比较聪明”——群体层面脑容量与智力可能正相关，但不等于通向最优的钥匙。

彼得·诺维格曾写道，当人类不再模仿鸟飞而开始研究空气动力学时，人工飞行的探索才真正成功。希望这一代人能在可见的未来摸清智能规律。深度学习在很多任务上确实优于浅层，这是事实，但它是否必然更优，多深才算最优，答案仍远未明确。

#### 7.5.6 为何越深越难训
深度是否更强尚无定论，但“越深越难训”可以暂时当作共识。结构越复杂、层次越多，牵涉因素越多。最经典的两大难题是梯度消失与梯度爆炸。

训练主要靠迭代优化，比如梯度下降。每次迭代按梯度负方向调整权重，逐步逼近最优。误差反向传播是其特例。梯度消失指从输出层往前传，每过一层梯度就变小，靠近输出层的权重更新正常，靠近输入层的权重更新几乎停滞。层数太多时梯度衰减到接近零，靠前的层形同虚设，网络退化成只有后几层在工作的浅层。

梯度爆炸则相反，每过一层梯度变大，靠近输入层的权重每次更新幅度剧烈，导致训练无法收敛，重则数值溢出。

本质是链式法则的连乘效应。以一个每层只有一个神经元的四层网络为例，输入层的梯度依赖于后面所有层的计算结果，最后是输出层导数乘以各层权重和激活函数导数的乘积。

权值通常随机初始化且小于 1，而早期常用的 Sigmoid 激活函数导数最大值只有 0.25，且大部分区域接近饱和，导数趋近于零。连乘之下，层数越多，梯度越容易衰减到零，这就是梯度消失的根源。反之若乘积大于 1，就可能出现梯度爆炸。

深度带来的训练困难，是深度学习早期难以发挥潜力的主因之一。应对方法主要有三类。

从初始化入手，如 Xavier、MSRA 等随机初始化，让乘积更稳定；从训练过程入手，如 2015 年谷歌提出的批量归一化 Batch Normalization，在训练中对隐层数据规范化，避免落入饱和区；从激活函数入手。2010 年后 ReLU 开始流行。

Sigmoid 函数的解析式是，对这个函数求一阶导数后的图像如图 7-22 所示，可见在零值时函数取得最大值 0.25，即的导数最大值为 0.25。从函数图像上我们还能看到，只有中间围绕零值的一小撮值才有作为梯度的意义，零值两侧的所有导数值都无限接近于零。我们把这两侧导数接近于零的部分，称为激活函数的饱和范围，一旦Sigmoid 函数的输入值落在这个饱和范围内，其输入的数值大小对激活函数的输出结果的影响就极小了，换言之，我们可以说在这个范围内的激活函数对输入数据不再敏感。

另外，误差反向传播算法在神经网络初始化的时候，其权值 w 通常会小于 1，譬如常用均值为 0、标准差为 1 的高斯分布来初始化网络权值。这样便使得整体将小于 0.25，再结合前面推导的连乘公式，使用链式法则求导，层数越多，势必会使得的求导结果越小，这就引发了梯度消失问题的出现。类似地，梯度爆炸问题出现的原因就是出现了的情况。到这里，我们就明白了梯度不稳定问题（梯度消失和梯度爆炸统称为梯度不稳定问题）产生的原因：前面的隐层梯度是后面的各个隐层梯度的连乘积，在神经网络的深度过深时，梯度在反向传播中的连乘效应会导致网络权值更新不稳定。

神经网络深度增加带来的训练上的困难，是深度学习在诞生前几年里难以充分发挥深度优势的主要原因之一。针对梯度不稳定问题，人们想了很多方法来补救。有从神经网络权值初始化着手的，使得整体尽可能避免梯度逐层减小或者增大，除了前文讲的辛顿的无监督预训练方法外，近几年还出现了一些效果很好的随机初始化方法，如 Xavier 初始化方法、MSRA 初始化方法等。也有从训练过程着手的，如谷歌在 2015 年提出的“批量规范化”(Batch Normalization)操作，这种方法是在训练过程中对隐层的数据进行规范化处理，避免训练过程里各网络层输入落入饱和区间进而导致梯度消失。还有一种易于操作的最简单方法，是直接从激活函数本身着手。既然梯度消失是由 Sigmoid 函数的导数最大值仅为 0.25，且不饱和区间非常狭窄所导致的，那么就着手去寻找更好的代替函数。

ReLU 函数虽然看起来非常简单，却是近几年在激活函数这方面取得的最大进步之一。相比 Sigmoid 函数，ReLU 函数具备了诸多优秀的特性，如由于函数简单，不需要进行幂运算，所以计算速度非常快，训练时收敛速度远远快于 Sigmoid 函数，也超过了其他常见的激活函数，如 Tanh 等。在解决梯度消失这个问题时，很明显 ReLU 函数的导数要么是 0 要么是 1，这样至少在正数区间上，就不会因为连乘效应导致梯度逐层减小了。
