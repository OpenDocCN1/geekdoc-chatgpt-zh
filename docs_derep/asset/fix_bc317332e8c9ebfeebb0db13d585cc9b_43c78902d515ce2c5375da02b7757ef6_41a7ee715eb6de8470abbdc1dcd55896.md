#### 8.4.2 推理和行动协同技术

与思维链类似，推理和行动协同 Reason and Act，ReAct 是一种基于少样本学习的提示工程方法[8]，用来教模型如何完成任务。思维链模拟的是人类思考的过程，ReAct 保留了推理的部分，同时还让模型能够与外部环境交互。人类既会通过推理制定策略记住要点，也会采取行动获取新信息达成目标，ReAct 就是建立在这一基础上。ReAct 的示例提示里同时包含带动作的示范、执行动作得到的观测，以及各步骤中的人类思考。于是模型学会把思考和行动结合起来更智能地工作。图8.6 展示了 ReAct 的流程，大模型在“思考→行动→观察”的循环中执行指令，直到认为任务完成。

### 8.5 案例分析
本节结合前面介绍的提示工程技巧，演示如何搭建一个面向编程新手的智能助手。用户用自然语言描述需求，助手就能自动生成、运行、调试代码并给出结果。示例实现基于 LangChain，突出核心技术点。

#### 8.5.1 案例介绍
如果你是程序员，肯定遇到过这样的场景：编程新手的朋友忽然找你帮忙写程序。

假设朋友想让你分析特斯拉公司年初至今的股票收益率并用图展示，可能就会出现下面这些来回：

- 你很忙，但还是赶紧写了一段 Python 代码发给他。
- 朋友跑代码时报错，把错误丢给你。
- 你一看是运行环境缺包，告诉他怎么安装。
- 包装好后再次运行，又报错来求助。
- 你排查发现代码里有 Bug，改完再发过去。
- 代码终于跑通，朋友很满意。

为了不再被反复打扰，可以用大模型的表达能力搭建一个智能助手，只要用自然语言描述需求，它就能自动完成全部流程并返回结果。

#### 8.5.2 工具设计
上述解决流程涉及三个工具。

- Python 代码生成工具：依据用户需求生成代码，或分析运行异常并修复代码。
- Python 代码运行工具：执行生成工具输出的代码并返回结果。
- Python 数据包安装工具：在环境缺少依赖包时自动安装。

#### 8.5.3 提示词设计
综合来看，完成该任务需要大模型调用三个工具：Python 代码生成工具、Python 代码运行工具和 Python 数据包安装工具。下面采用 ReAct 框架[9] 设计提示词，并在其中放入一个示例来辅助理解，即 One-Shot ReAct：

> 你是一名智能助手，为了完成用户给定的任务，你要使用代码助手为你生成可以完成任务的代码，执行任务的过程中你只能使用下面的工具：
> {tools}
> 你要使用下面的格式：
>
> Task:
> 你必须完成的任务
> Thought:
> 你要思考应该使用哪个工具
> Action:
> 你要使用的工具，必须是其中之一"{tool_names}"
> Action Input:
> 运行工具必要的输入
> Observation:
> 执行动作后观察到的信息
> ...（这里Thought/Action/Action Input/Observation的过程可以循环多次）
> Thought:
> 完成任务
> Final Answer:
> 结果
>
> 以下是一个例子，供你参考：
>
> -------
>
> Task:
> 今天是几号
> Thought:
> 我先询问Python代码助手，获取可以输出今天日期的代码
> Action:
> 询问Python代码助手
> Action Input:
> 今天是几号
> Observation:
>
> [PRE9]
>
> Thought:
> 我拿到了Python代码，现在我要运行这份代码
> Action:
> 运行Python代码
> Action Input:
>
> ```

>
> # 获取当前日期
