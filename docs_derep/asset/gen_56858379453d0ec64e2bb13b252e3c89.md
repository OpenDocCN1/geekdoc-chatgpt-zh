# RAG实战：检索与生成如何闭环

下面这份演示带你快速搭出一套轻量级 RAG 问答流程。整体思路是：先借助向量检索从知识库里挑出与用户问题相关的片段，再把这些片段交给生成模型，让它基于真实上下文给出答案。检索端用 Sentence-BERT 做向量化，生成端则用 GPT-2 完成自然语言的组织。

def generate_answer(contexts, query):

    context_text=" ".join(contexts) # 将多个上下文合并

    input_text=f"背景信息: {context_text}\n问题: {query}\n回答:"

    inputs=tokenizer_generation(input_text, return_tensors="pt")

    )

    # 解码生成的序列

    generated_answer=tokenizer_generation.decode(output_sequences[0], skip_special_tokens=True)

    return generated_answer

# 完整RAG系统流程

def RAG_system(query):

    # Step 1: 检索模块获取相关内容

    contexts=retrieve_context(query)

    print("检索到的上下文信息:")

    for i, context in enumerate(contexts, 1):

        print(f"{i}. {context}")

    # Step 2: 生成模块生成答案

    answer=generate_answer(contexts, query)

    return answer

## 3.2 向量检索: 将文本转换为向量

向量检索是 RAG 系统的核心环节，决定了模型能否在海量数据中迅速找到与用户意图相符的材料。通过把文本转成向量，系统能够把语言信息映射到高维数值空间，从而在该空间里快速计算相似度。与传统关键词匹配不同，向量检索借助嵌入模型保留语义，因此能捕捉到字面差异但意义相近的内容。

本节会先拆解向量化的原理与实现，再介绍基于距离计算的常用相似度匹配方法，最后通过实例说明如何在 RAG 中落地向量检索，为生成模块提供精准的外部信息支撑。

#### 3.2.1 文本嵌入的基本原理与技术

文本嵌入的本质是把自然语言映射为向量，使其具备数值计算能力。理想的嵌入会让语义相近的内容在向量空间中靠得更近，从而可以通过相似度度量找到与查询意图一致的文本。主流技术覆盖词级嵌入如 Word2Vec、GloVe，以及句级嵌入如 BERT、Sentence-BERT 等。基于深度学习训练的嵌入向量能保留丰富的语义特征，显著提升语义检索效果。
