### 5.1 数据抓取

网络上汇聚了大量关于社会行为、公众态度、政策反馈的信息，对把握社会现象与动态变化十分关键。在社会科学中，获取开放网络数据已成为分析群体行为与态度的基础。DeepSeek 能辅助研究者完成采集工作，无论新手还是有编程基础的研究者，都能用自然语言指令实现抓取。

#### 5.1.1 解析网页结构

在编写爬虫前，解析网页结构是关键。网页数据多嵌在复杂的 HTML 标签中，层级、加载方式与前端逻辑直接决定抓取策略与难度。目标信息可能分布在多层嵌套，或由 JavaScript 动态加载，需要一定的解析能力。

对缺乏编程背景的社会科学研究者而言，手工查看源码、理解 DOM、定位节点门槛较高。面对结构不规范、反爬或动态加载的页面，仅靠浏览器查看源代码或检查元素往往难以准确定位，容易遗漏或失败。

DeepSeek 可快速解析页面结构与内容，定位目标数据，为后续爬虫提供精准入口，提升效率与准确性。以豆瓣电影 Top250 为例，提示词 5-1 展示了结构分析需求。
