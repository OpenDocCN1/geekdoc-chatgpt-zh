# 让对话变成代码：Vibe Coding 实战全解

# 书籍概览

本书是一份以自然语言操控代码生成的实操手册，演示如何借助氛围式开发工具配合大模型来解决真实业务问题。书中准备了 9 个可动手项目作为入门切口与能力校验，帮助读者找到适合自己的工具与模型组合。

全书共分五块内容。第一块梳理氛围编程的核心概念与使用原则。第二块围绕智能体搭建、数据可视化、Excel 数据分析三个典型场景，横向对比扣子、DeepSeek、Claude、Trae、Cursor、Windsurf、通义等七套主流工具与大模型的协同编码表现。第三块演示用 Trae 制作微信小程序，以及借助 bolt 等方案快速搭建 Web 原型的流程。第四块讲解基于 GitHub Copilot 完成前后端分离的完整 Web 系统，并用 Cursor 进行自动化测试的实战。第五块汇总面向不同背景使用者的进阶策略、工具与模型横向评测，以及项目自检方法论。

适合三类人群：需要处理数据或做出产品原型的非技术背景用户、想掌握高质量代码产出的技术从业者，以及希望通过氛围式编程起步的 IT 新手。

# 氛围编程为开发开辟新通道

氛围编程是伴随大模型代码生成能力提升而兴起的以自然语言交互为核心的开发方式，本质是通过描述意图让 AI 产出代码，而非手工编写。也可称作自然语言编程。

回看编程语言演进，从机器码、汇编到高级语言，再到如今主张的自然语言，整体走向是不断远离机器、贴近人脑。这是技术对人的深度赋能，让编程回归人类表达，打造人人可参与的创造空间，释放创新动能。

当然，氛围编程并不完美。按传统软件开发标准看，仍有争议与待解问题：自然语言的模糊可能导致代码偏离需求；大模型幻觉会影响准确与可靠；在复杂业务下，自动生成的代码在规范、架构等方面仍有差距。但这些问题并不能否定其生命力。

我认为氛围编程不是颠覆传统开发，而是开辟新战场。就像当年 HTML/CSS/JavaScript 被认为不够严肃，却最终开创 Web 编程新赛道并占据半壁江山。

在这个新赛道里，传统开发的诸多铁律可能需要重新评估，比如可复用性、松耦合高内聚、可读性等。氛围编程更适合小规模、强即时性、用户参与共创的场景，它将与传统软件并存，形成一种用户可随时改造的“可塑软件”。

因此不要用传统开发的有色眼镜看氛围编程。随着大模型与编程语言融合加深，它将塑造出不同的流程、形态与技术哲学，为软件开发打开全新大门。

伍斌老师的这本书敏锐捕捉并剖析了这一趋势，拆解工具、呈现场景、演练实操、阐释价值。读它不仅是学习新范式，更是开启人机对话革命的新旅程。

李建忠
全球机器学习技术大会主席、ISO C++ 标准委员会委员

# 氛围编程释放全社会创新动能

2023 年 4 月我提出“软件工程 3.0”概念时，就预见到 AI 将重塑软件开发全流程。没想到变化如此迅猛彻底。

2025 年春节后 DeepSeek 横空出世，“氛围编程”概念爆火，再次让我感受到技术迭代的速度。深耕软件工程三十余年，我见证了从大型机到微机、汇编到高级语言、命令行到图形界面、单体到微服务的每一次变革。这一次不同，氛围编程不仅是工具升级，更是范式的根本性颠覆——让编程从技术精英专利变成人人可用的日常工具。

本书适时出现。作者以务实态度把抽象理念转化为可掌握的实用技能。全书通过 9 个精心设计的实战项目和 5 个核心应用场景诠释“所说即所得”的新范式。

最打动我的是作者对本质的理解。传统教学从语法起步，让人在枯燥规则中迷失，往往学几个月仍写不出解决问题的代码。氛围编程则颠倒路径——从解决问题开始，在实践中自然理解编程本质。这种问题导向更符合认知，也让编程回归工具本源。

我曾提出大模型将成为研发核心驱动力，现在这本书展示了另一维度——氛围编程让软件开发真正全民化。产品经理几分钟做出 MVP 原型，数据分析师用自然语言完成复杂可视化，没编程背景的小学生也能做智能聊天应用。我们正在见证全民编程时代，意义远超技术本身。

软件工程 3.0 时代的核心挑战已从“如何写代码”变为“如何用代码解决问题”。氛围编程正搭建这座桥梁，让每个人专注问题本身，把实现交给 AI。这不是对程序员的威胁，而是对全社会创新能力的极大释放。

书中对 9 款主流工具的详细对比和实战演示体现深厚功底。从扣子、DeepSeek 到 Cursor、Windsurf，每款工具各有优势场景。作者没有简单推崇“最好工具”，而是教会读者按需求选择组合，这种务实体现了真正的技术智慧。

本书不仅是工具介绍，更是方法论指南。从智能体到数据可视化、从微信小程序到全栈 Web 应用，项目覆盖面广。更重要的是强调思维转变——从“我要学什么技术”到“我想解决什么问题”。

任何新技术都有局限，氛围编程也不例外——概率生成带来不确定性，工具迭代带来学习成本。但正如作者所言，这些不是拥抱新技术的理由，掌握正确方法和思维模式才能快速适应。

我始终相信技术的最高境界是让所有人受益。从结构化编程到敏捷开发，再到大模型时代，每次进步都在降低门槛、扩大受益面。氛围编程完美体现这一理念，让编程成为像 Word、Excel 一样的通用技能。

在 AI 重塑一切的时代，掌握氛围编程不仅是技术人员的新技能，更是每个知识工作者的核心竞争力。无论是产品经理、数据分析师、创业者还是学生，这本书都能点燃创新火花，释放内在创造潜能。

朱少民
同济大学特聘教授、《软件工程 3.0》作者

在这个 AI 重新定义可能性的时代，掌握用自然语言驾驭代码生成，意味着掌握把创意加速变现的杠杆。这本书正是启动杠杆的操作手册，邀请每位读者参与并塑造这场生产力革命。翻开它，构建你的第一个自然语言驱动项目，你会真切感受到未来已来、触手可及。

补充一点：氛围编程是一场效率革命。借助 DeepSeek-R1 等大模型和 Trae 等 AI 原生工具，自然语言生成代码显著降低了语法门槛和初阶任务耗时。但我们必须清醒：软件工程的本质复杂性并未消失。氛围编程提升的是表达层效率，构建可靠、可维护、可扩展系统的挑战仍在——精准的需求抽象与分解、复杂架构设计、深层逻辑缺陷与边界处理、团队协作与知识管理。因此拥抱提效的同时，更需坚守工程根基——严谨设计思维、清晰架构规划、彻底测试验证、持续代码治理。新范式不是消除复杂性的灵丹，而是要求我们以更高阶的工程智慧驾驭它。工具在进化，工程的根本挑战永存。

# 第一次看到编程像聊天一样简单

年前我怀着忐忑走进北京工业大学计算机系教室，从未想过有一天会坐在电脑前，用自然语言和 AI 对话来编程。那时为了解决一个小语法错误，需要记忆复杂函数和规则，在绿色终端敲枯燥命令行，熬到深夜。编程似乎永远是少数技术精英的专利。

然而 2025 年春节刚过，一切变了。

DeepSeek 突然爆火，让我在编程圈摸爬滚打三十多年的“老程序员”感到震撼——不是因为技术突破，而是我目睹新时代到来。当“氛围编程”热词在社交媒体疯传，Trae 国际版高峰期排队几百人的消息传出，我知道编程世界正在被颠覆。

我迫不及待尝试新工具。用中文对话就能让 AI 生成完整 Web 应用，视频里 8 岁女孩用 Cursor 搭配 Claude Sonnet 3.5 生成自己喜欢风格的 AI 聊天应用，完全没有编程背景的人也能做出精美数据可视化图表。我写的这本“编程”书中所有代码清单里竟然没有一行传统编程语言代码，脑海里浮现氛围编程者与大模型对话时气泡纷飞的喜悦。当我看到编程真的像聊天一样简单时，内心五味杂陈：兴奋于门槛彻底降低，忐忑于传统方式或将式微，更多的是感动——编程真正实现全民化的可能出现了。

于是我决定写这本书。

氛围编程太值得书写。它不仅让编程人人可做，更能解决现实问题。我见过产品经理快速做出 MVP 原型，数据分析师几分钟完成原本需几天的可视化，小学生做出自己的智能聊天应用。这不是科幻，这是 2025 年正在发生的现实。

写作中我深深意识到氛围编程正在重塑两件事：“零基础编程入门”和“写代码解决问题”。传统入门先学语法再学算法，最后才能写出实用代码，往往耗时数月甚至数年。氛围编程让人直接从解决问题开始，在解决过程中自然理解编程本质。这是全新的学习路径，也是全新的问题解决方式。
