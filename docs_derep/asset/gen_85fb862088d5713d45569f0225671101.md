# 交付章节标题的反复沟通

针对“高效交付，优质课程设计”这一条，你指出仍显狭窄，交付不等于课程，受众是超级个体，交付对象可能是各类产品或服务，标题应围绕交付场景整体来写。于是我先改为“卓越交付策略：为超级个体提供高效的产品与服务体验”。

你又提醒，重点不是泛泛的高效，而是AI在交付中对质量和速度的双重提升。于是再调整为“AI赋能交付：提升质量与速度，助力超级个体成功”。最终定稿为本书第四篇大标题：

# AI助攻交付：提速增质，成就超级个体传奇

这个标题在书中一个字未动。

在撰写过程中，我大量调用“思维分身”。比如在“撰写品牌故事”一章里，“品牌故事也是最高级且最便宜的广告，能长期积累，为IP创业带来更大成功机会”这一判断，就是由“思维肖厂长”从150万字素材库中提炼出来的。

# ChatGPT进阶用法：自循环派

第一篇讲B.O.K.E.方法论时提到过ChatGPT的高阶玩法——自循环派。用编程思维在提示词里规定执行流程和分支，让模型自带发动机。

在“撰写品牌故事”章节的背景部分，我的引导思路包括：主打产品或服务、创业初期的时间缘起与困难、发展轨迹中的里程碑与转折、市场份额与独特优势、拿到的实际成果如案例评价奖项、服务人群与使命愿景、未来规划方向。以上内容都用自循环提示词产出，后续做了人工微调。

# AI超级个体提示词库共建

模型：GPT-4

LY 阅读以下说明，理解后回复“我们开始吧：”

请你担任我的Prompt Database Creator。目标是基于我给定的场景，制定详尽的提示词库。

流程如下：先判断场景主题，然后输出三部分：一级提示词，即该场景下可提问的类别归纳；三条改进建议；三到十个备选一级提示词。末尾提示四个选择：对一级提示词提出改进建议；输入“使用此提示”进入二级生成；输入“重新启动”重来；输入“退出”结束对话。

若选择生成二级，则基于最后确认的一级清单，穷尽该分类下的具体提示词。

场景示例：撰写品牌故事

初始一级清单：品牌背景、价值观与使命、核心产品与服务、成功案例、品牌未来愿景。建议围绕覆盖度、受众术语、目标匹配度给出。

备选补充：品牌创始人背景、品牌形象与风格、品牌发展历程、客户评价与反馈、社会责任与影响、市场地位与竞争力、企业文化。

按你的要求把七条备选全部并入后，一级清单扩充为十二项。随后你把清单精简为：核心产品、品牌背景（含创始人背景）、发展历程、市场地位（含市场竞争力）、品牌成果（含成功案例、客户评价与反馈）、使命愿景、展望未来。

确认后生成二级提示词：

核心产品：主要产品线、产品特点与优势、目标市场和消费者群体
品牌背景（含创始人背景）：创立时间和地点、创始人故事与经历、公司愿景与初衷
发展历程：重要历史事件、产品线扩展与创新、公司规模变化
市场地位（含市场竞争力）：行业地位与声誉、主要竞争对手、独特竞争优势
品牌成果（含成功案例、客户评价与反馈）：典型成功案例、客户评价与见证、获得的奖项与荣誉
使命愿景：公司核心价值观、长期发展目标、对社会环境的贡献
展望未来：未来发展计划、潜在市场机会、预期挑战与应对策略

有了这样的分层提示词库，面对具体任务时就无需反复整理思路，模型会先为自己生成提问框架，用户只需做选择即可。
