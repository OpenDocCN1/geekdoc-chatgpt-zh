#### 8.2.3 OpenAI JSON 模式与结构化输出

OpenAI 传统 JSON 模式可通过把 response_format 设为 { "type": "json_object" } 来开启。开启后模型只会输出能被解析为合法 JSON 对象的字符串。需要注意的是，该模式仅约束格式，不保证内容符合预设规范，字段名与类型仍可能出现偏差。

在当前版 Responses API 所提供的 Structured Outputs 功能里，模型能严格遵循用户给出的 JSON 模式生成结果。这就避免了键值缺失或枚举值无效的问题，也无需依赖强硬提示词来维持格式稳定。对能力较弱的模型而言，细致的提示设计依然重要。

#### 8.2.4 Pydantic 解析方案

Pydantic 是一个多用途框架，能把自然语言文本转为结构化的 Pydantic 对象。LlamaIndex 提供了几类 Pydantic 程序，各有侧重。

- 大模型文本补全型 Pydantic 程序：把输入文本映射为用户自定义的结构化对象，结合文本补全 API 与输出解析能力。
- 大模型函数调用型 Pydantic 程序：依据需求将输入文本转换为指定结构化对象，依赖函数调用 API 完成。
- 预置型 Pydantic 程序：把输入文本转换为已预先定义好的结构化对象。
