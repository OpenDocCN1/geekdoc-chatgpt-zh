2022 年 11 月底 ChatGPT 正式对外发布，瞬间点燃行业关注。步入 2023 年，生成式 AI 的热度迅速蔓延到全球。不少从业者总结道，如果 2023 年是公众第一次直观看到大模型潜能的 ChatGPT 年，那 2025 年极有可能是智能体集中兑现的元年。ChatGPT 打开了生成式 AI 的大门，智能体则在这一基础上迈出关键一步，让机器能够自行理解需求并落地执行，灵活调用外部工具、拆解复杂流程，像一位贴身的数字助手一样融入学习、工作与生活，为用户带来更具体的智能体验。智能体正以更快速度成长，成为大模型应用里不可或缺的环节。

可以这样理解：
大模型落地应用 = 基础大模型 + 多个智能体 + 外部能力集合

对大模型从业者而言，读懂并搭建智能体是把握技术走向的关键。本部分围绕 Agent 的定义、核心概念、价值主张、与大模型的关系、交互流程以及主流开发工具展开，并以 DeepSeek 大模型与 Dify 开发平台为例，演示如何搭一个简洁但可用的股票查询智能助手。

**1.3.1 什么是智能体**

**1. 智能体定义**

百度百科给出的说法是，智能体指能够感知外部环境并采取行动以达成特定目标的代理。它可以是软件、硬件或系统，具备自主、适应与交互的特质。智能体通过传感器或数据输入捕捉环境变化，结合自身知识与算法进行判断，随后执行动作去改变环境或达成目标。智能体在自动化系统、机器人、虚拟助手、游戏角色等场景里广泛出现，核心在于能够自主学习并持续进化，以更好完成任务并适应复杂环境。

智能体普遍拥有感知、规划、执行的能力，并具备一定程度的自主性，能够进行决策、学习与适应。这意味着它们不只是被动执行的程序，而更接近像人一样思考和行动，尽管当前技术离科幻描述仍有距离。把握这些概念对开发者很重要，因为它们界定了 Agent 的边界与演进方向。相较传统软件，Agent 更灵活通用，不依赖写死的规则做判断，更适合处理复杂、动态且需要与人互动的任务。

**2. 智能体核心特质**

1）自主性
自主性是智能体的基本特质，指其能在无需持续人工干预下，自行感知环境、做出判断并执行行动。强大的自主性让智能体能在不可预测的动态环境中独立运转并调整策略。自动驾驶汽车就是典型，它能感知周边车辆与行人，自主规划路径、控制车速并避障，减少人工监督，也保证了实时任务的高效可靠。

2）反应性
反应性指对环境变化做出迅速响应的能力。这种特质让智能体在突发或紧急情况下能快速有效应对。对实时系统与动态环境尤其关键，例如机器人需要即时感知障碍并立刻改道避撞。更高级的智能体还能结合历史数据与预测信息，让反应更智能灵活。

3）主动性
主动性体现在智能体能够自行设定目标、制定行动计划并为之努力，而非单纯被动应激。它能依据内在目标与动机积极行动。智能家居系统可主动学习用户习惯，提前调节温度或灯光以提升舒适度。具备主动性的智能体能在环境中探索、发现问题并提出方案，在长期目标达成上展现更高灵活性与创造性。

4）社会性
社会性指与其它智能体或人类进行互动、协作与交流的能力。社会性智能体能理解并遵循社会规范，协同行动完成复杂任务。多智能体系统中，各体通过通信协议共享信息、分工协作实现团队目标。在人机交互中，语音助手能理解指令并以对话形式反馈建议。社会性提升让智能体在团队工作与协作场景中效率更高。

5）进化性
进化性是指通过学习与适应实现长期能力提升的特性。智能体可在面对新环境或任务时自我调整优化，逐步提高性能。该特性常与机器学习、进化算法或强化学习结合，使其在变化环境中保持竞争力。例如强化学习智能体通过持续交互调整策略以最大化长期收益。进化性让智能体能应对不确定性，并在长期任务中越用越智能。

目前大模型常被视作智能体的“大脑”，提供理解、推理与行动的基础；智能体则被看作大模型的“手脚”，通过调用外部 API 与真实世界交互，拓展大模型能力，完成更多现实任务。

**3. 智能体的发展脉络**

智能体经历了三个阶段：

（1）规则驱动阶段（2010 年前）。以 If-else 逻辑为核心的有限场景自动化，如早期的客服机器人。

（2）机器学习阶段（2010—2020 年）。引入自然语言处理，实现初步语义理解，但对标注数据依赖较强。

（3）大模型驱动阶段（2020 年至今）。依托大模型的自主决策能力，支持动态任务拆解与外部工具调用。

**1.3.2 智能体的主要模块**

主流智能体多采用“感知—规划—执行”三层架构，并借助思维链 CoT 处理复杂任务。

**1. 三大基础模块**

1）感知模块
负责获取外部信息。通过物理或软件接口采集并解析环境数据，形式包括图像、音频、视频、文本等。开发者需明确智能体与何种数据交互、如何采集与处理。只有准确全面的感知，才能为后续决策提供可靠依据。

2）规划模块
是智能体的“大脑”，对感知信息进行分析、推理与判断，制定行动方案。大模型在此环节作用关键。推理是智能体体现“智能”的核心，尤其在需要逻辑推演与多步思考时。开发者需考虑如何让智能体具备系统化信息处理能力，并据已有知识与实时输入做出合理高效决策。

3）执行模块
负责对外部世界产生影响，通过执行器或对外接口如回答查询、处理请求、控制物理设备来完成实际操作。简言之，执行模块决定智能体如何作用于世界。开发者需明确智能体应执行哪些行动及如何执行。

除上述三模块，部分智能体还包含学习模块，使其能基于新信息、用户反馈与历史经验持续优化行为与决策机制，从而长期提升性能。这种自我进化是智能体区别于传统程序的重要标志。开发者可考虑引入强化学习、在线学习等机器学习机制，以增强适应性与智能化水平。

感知收集数据，规划处理数据并决策，执行落实决策，形成闭环。这种“感知—规划—执行”循环保证了智能体能动态响应环境变化并持续迭代。构建时需确保三者无缝衔接、协同工作，建议采用迭代设计，让智能体在循环中不断完善能力。

**2. 智能体与大模型的配合**

1）大模型扮演大脑角色
大模型是智能体构建的基础，提供理解、规划与行动能力。凭借强大的自然语言处理与日益增强的多模态支持，大模型让智能体能准确理解用户输入。其推理能力也使智能体可进行任务规划并决定何时调用哪些外部工具。理解大模型原理及其与工具的交互方式，直接影响智能体的智能水平与实用性。

2）利用大模型的规划、记忆和工具使用能力
（1）规划。大模型可把复杂任务拆解为更小可控的子任务并制定计划。例如 ReAct 框架融合推理与行动，让大模型在生成思考的同时交替执行可操作动作，高效解决问题。这意味着大模型不仅能理解任务，还能思考完成方式并拆解为执行步骤。开发者可借助其规划能力构建处理复杂任务的智能体。
（2）记忆。大模型能保留对话中的关键信息，增强上下文理解，让对话更连贯。记忆使智能体可回忆过往经验并据反馈调整行为。开发者据此可构建记住用户偏好与历史对话的智能体，提供更个性化持续的交互体验。智能体开发框架通常提供记忆管理功能，便于配置会话上下文与记忆窗口。
（3）工具使用。大模型驱动的智能体不仅能与外部工具如 API、数据库、知识库交互，还能扩展语言处理外的能力。借助工具可执行网络搜索、数值计算、数据检索等。工具调用能力是实用性的核心，打破了传统语言模型只能“说”不能“做”的局限。开发者可通过框架集成各类工具，使智能体承担更广泛的现实任务。

**3. 智能体的四种常见设计思路**

吴恩达教授于 2024 年撰写的博客总结了四种常见设计思路，具有参考价值。

吴恩达认为智能体主要有以下四种模式。
（1）反思 Reflection。智能体检查自身工作并提出改进建议。
（2）工具使用 Tool Use。大模型配备网络搜索、代码执行等工具，帮助收集信息、采取行动或处理数据。
（3）规划 Planning。大模型可根据任务描述制定并执行多步骤计划，例如先写文章大纲，再进行在线调研，最后撰写草稿。
（4）多代理协作 Multi-agent Collaboration。多个智能体以不同角色协同工作，分解任务、讨论思路，提出优于单个智能体的方案。

详情可参考 DeepLearning.ai 上的 Agent 系列文章。

**1.3.3 智能体开发框架**

最原始的开发方式是手写多条提示词并用 Python 编排。如先改写用户输入、识别意图并提取关键参数，再组织成 API 调用 URL 发送请求并返回结果，最后结合输入与 API 响应生成答案。这种方法可行但效率低、维护成本高。为此近年来出现了大量智能体开发工具与框架，显著简化流程。LangChain 作为早期的大模型提示词编排工具，提供封装良好的 Python 库，帮助开发者快速搭建上层逻辑。后起的图形化可视化平台则允许通过拖拽等直观操作配置功能，大幅提升效率与易用性。

**1. 常用框架盘点**

以下几种框架在业内较为流行，各有侧重。

1）LangChain：最早的大模型开发框架
（1）核心优势。模块化设计，采用 Chains、Agents、Tools 分层架构，可灵活组合提示词、记忆、工具调用等组件。提供统一接口简化多模型集成。文档与社区丰富，上手较平缓。
（2）典型应用。适合深度定制的复杂场景，如多轮对话系统、智能客服，集成多数据源与自动化数据分析等。

2）Dify：图形化操作，功能丰富迭代快
（1）核心优势。集成 RAG 引擎与插件市场，支持快速构建生产级应用。提供可视化工作流，降低开发门槛。支持无代码或低代码开发，适合非技术用户。
（2）典型应用。构建企业内部知识管理系统，快速开发定制化智能助手。

3）扣子 Coze：字节跳动推出的智能体工具，插件丰富
（1）核心优势。零代码或低代码开发，适合非技术用户快速上手。插件库丰富，支持调用各类外部 API。内置知识库与工作流引擎，支持复杂业务流程。
（2）典型应用。搭建企业内部知识库，开发虚拟助手、个人助理等对话型智能体。

4）Microsoft AutoGen：微软推出的多角色智能体工具
（1）核心优势。支持多智能体并行执行任务，提升处理效率。提供生产级监控与调试工具，方便部署维护。与 Azure 生态深度集成，适合企业级应用。
（2）典型应用。构建多智能体对话系统，实现自动化运维与任务调度。

5）CrewAI：创业公司推出的多角色智能体工具，上手容易
（1）核心优势。强调多角色协作，每个智能体拥有独立角色与任务。内置记忆与错误处理机制，提升系统稳健性。
（2）典型应用。模拟多角色对话协作，如虚拟团队协作，构建任务分解与协作执行流程。

**2. Dify 的智能体能力**

1）Dify 简介
最初 Dify 聚焦 RAG 应用的快速构建，随着技术发展与需求演进，其逐步增强了智能体开发支持，并自然融入现有架构与操作流程。如今 Dify 既可用于快速开发 RAG 应用，也能用于构建功能丰富的智能体应用。

2）Dify 用于智能体构建的关键特性
（1）智能体框架。Dify 提供灵活的智能体框架，允许开发者自定义智能体以独立使用多种工具处理复杂任务，支持函数调用、ReAct 等策略。该框架为构建自主运行智能体提供结构化方法，可定义目标、行为逻辑与可用工具，实现高度定制化交互。
（2）工具集成。Dify 支持无缝集成各类工具，包括内置工具如 Google 搜索、维基百科、DALL-E，以及通过 OpenAPI/Swagger 和 OpenAI 插件导入的外部工具，同时支持通过 API 连接外部知识库。强大的工具集成大幅扩展智能体应用场景，使其能与外部世界交互并执行操作。
