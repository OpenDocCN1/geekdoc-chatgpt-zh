#### 8.1.13 基于 LangServe 与 FastAPI 暴露 REST 接口

- 能迅速把 LangChain 或 LangGraph 的链和图挂载成 HTTP 端点；
- 提供异步运行、参数校验与 OpenAPI 文档自动生成能力；
- 支持带类型注解的流式返回与结构化输出。
