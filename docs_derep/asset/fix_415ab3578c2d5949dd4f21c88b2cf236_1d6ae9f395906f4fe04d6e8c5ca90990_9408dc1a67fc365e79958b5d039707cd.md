换个说法，受众就翻倍

美育绘本推荐方向：整套收录百余幅经典名作。
另一版表述是：
周末亲子艺术时光，我都押在这套书上。

第二版把使用场景和情绪价值提前，代入感一下就起来。不止原有目标人群会点进来，那些想过周末却对陪娃没灵感的家长也会被吸引。只是换了一种讲法，触达面至少扩了三倍。

## 使用方法

1. **数字手法：上学被孤立？三招让孩子更难被欺负**

   **理解门槛低：** 数字化呈现让人迅速抓住要点。
   **行动明确：** 数字类题目多暗示步骤与方法。
   **期待拉满：** “三招”让人觉得几步就能看到改变。

2. **先卖好处：天啊，学会向上社交，我的生活直接开挂**

   **效果前置：** 把结果放在前面，直说用户能得到什么。
   **好奇被点燃：** “开挂”这类强情绪词让人想点开看细节。
   **紧迫感增强：** 暗示错过就会落后，刺激立刻点击。

3. **对比冲击：同款上衣，体脂掉了八个点的实拍**

   **画面感强：** 数字对比制造直观视觉差。
   **结果先行：** 直接呈现效果，用数据说话。
   **行动被激励：** 看到明显变化更容易让人模仿。

4. **埋悬念：提醒孩子，这四种情形千万别轻易心软**

   **吊胃口：** “千万别”制造警示感，激发探究欲。
   **情绪牵引：** 利用担忧、害怕等情绪推动阅读。
   **互动提升：** 容易引发评论和转发。

5. **风险提示：别踩“让孩子跨越阶级”的误区**

   **击中焦虑：** 抓住家长对孩子未来的担忧。
   **敲响警钟：** “陷阱”等词传递风险感。
   **促发思考：** 引发对教育问题的深度讨论。

6. **疑问开场：阅读高手｜用三十天读透一本书怎么做**

   **模拟对话：** 像在跟读者说话，拉近距离。
   **求知欲被激发：** 围绕成长的话题更容易让人想知道答案。
   **引导探索：** 自然把人带进内容寻找解答。

7. **借势IP：安顺｜被《国家地理》评为最美小城是什么体验**

   **借势引流：** 借助知名IP的声量和权威。
   **信任加分：** 名牌背书提升内容可信度。
   **受众扩容：** 大IP自带流量池。

8. **搭热点：“三·一五”晚会曝光八大黑幕，你怎么看**

   **时效性强：** 贴合当下讨论话题。
   **社交属性强：** 热点易引发交流分享。
   **曝光更高：** 更容易被搜索和推荐。

## DAY5 内容怎么才能让人看完

- 如何写开头？
- 如何写正文？
- 如何写结尾？
- 如何用金字塔写作法？

好内容不是辞藻华丽，而是真实、击中痛点、讲到心里。经典三段式：开头—正文—结尾，能套用到绝大多数笔记里。

## 如何写开头？

**传播逻辑**

好的开头能让人多停留几秒。

除了笔记基础数据，还有完播率和5秒停留率。点进来只是流量，留下来才是留住流量。

好的开头通常具备：

1. **制造好奇**
   抛问题或热点，激发想知道答案的欲望。
   例：在斯坦福上学是什么体验？

2. **直戳痛点**
   点出普遍困扰，让人想找解决方案。
   例：人类所有痛苦都源于能力与梦想不匹配。

3. **展示成果**
   用个人经历建立信任。
   例：从“丑小鸭”到穿搭博主，我只用了1个月

4. **情绪共鸣**
   营造强情绪氛围。
   例：她大雪天走了六千米，只为给我送一锅热包子，这就是我的妈妈。

5. **反常识**
   用常识外的说法吸引继续看。
   例：越存钱越贫穷，我真信了。

6. **恐吓式**
   先放一个害怕的结果，让人必须看下去。
   例：千万不要让孩子睡前读这本书……

开头和标题往往同源，很多人笔记跳出率高，就是开头不够抓人。

摄影博主推自拍杆的开头示范：

**制造好奇：** 为什么审美不如你的人，照片反而更美？
**直戳痛点：** 风景再美拍不到自己也很浪费。
**展示成果：** 真没想到，拍出好看照片这么简单。
**情绪共鸣：** 太气了！打扮漂漂亮亮去旅行，被男友拍成这样！
**反常识：** 100多元就能请一个全程跟拍的“摄影师”。
**恐吓式：** 千万别让闺蜜看到这个，不然她……

## 如何写正文？

**传播逻辑**

好的正文能延长停留。

用户愿意把信息看完，你才有种草的时间。

正文常见两种结构：

**并列式**：把多个产品或要点并排呈现，适合攻略、种草、观点类。
**递进式**：按逻辑推进，是什么—为什么—怎么办—第一步—第二步—第三步……

摄影博主自拍杆的递进式示范：
想要旅行拍出好照片，这3件事一定要做。
第一，**定妆散粉修饰妆面**。一秒调自然，避免过度美颜变形。
第二，**巧用自拍杆**。可调角度、防抖动、一键快门，一个人也能拍好。
第三，**加装补光灯**。皮肤瞬间提亮，省去后期修图。

## 如何写结尾？

**传播逻辑**

结尾才是变现关键。

开头正文决定停留时长，结尾决定是否转化，要么指向产品，要么引导关注。

常见两种写法：
第一种，总结观点，用金句升华，让人认同并产生购买冲动。
第二种，祝福式，用“我希望……”共情，提供陪伴感，促成关注。

## 如何用金字塔写作法？

**传播逻辑**

金字塔写作法让内容更高级。

它强调信息呈现的逻辑性和层次感，提升沟通效率和说服力。

特点如下：

1. **层级分明**
   - 顶端是核心结论，是全文精华。
   - 由上到下逐步细化，从总到分、从抽象到具体。
   - 每层子观点都直接支撑上一层。

2. **先给结论**
   开头就亮出观点，让读者迅速抓住重点。
   后续用事实、数据、案例按重要程度依次论证。

3. **分类归纳与演绎**
   遵循归纳或演绎原则，保持连贯一致。
   可用问题—答案模式，预设读者疑问逐步解答。

4. **简洁明了**
   去掉冗余，每段都有明确作用。
   复杂概念先概述再展开。

摄影博主自拍杆的金字塔示范：
**标题：** 旅行必备！超便携自拍杆，轻松记录每一刻
**主题句：** 探索世界记录生活，这款自拍杆让旅行更轻松。
**第一层：** 一键收缩，快速收纳，不占空间，随身无负担。
**第二层：** 收缩后短小轻便，可放背包或口袋，旅行更自在。
**第三层：** 旅行达人推荐：“是我旅行的必备品，能轻松记录每个精彩瞬间。”
**结论：** 无论城市还是自然，这款自拍杆都是记录旅行故事的好伴侣，便捷让你更自在。
**行动号召：** 立即购买：点击链接带回家；了解更多：关注我获取更多摄影灵感。

## DAY6 如何做出好封面？

- 为什么封面很重要？
- 怎么做出优质封面？

选题、文案都不错，流量还是上不去，大概率封面有问题。封面就像脸，没吸引力就没人想聊。

## 为什么封面很重要？

**传播逻辑**

人是视觉动物。

在同等条件下，人们更愿意看美的事物。优质视觉是强加分项，能立刻抓住注意力。

封面作用：

1. **视觉吸引力**
   第一印象决定是否停留，吸睛封面提升点击率。
2. **信息传递**
   封面配合标题快速传达核心内容，提升阅读兴趣。
3. **内容营销**
   好封面促进传播分享，提升账号影响力和粉丝增长。
4. **增强记忆点**
