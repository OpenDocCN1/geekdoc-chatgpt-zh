# 几何视角下的优化差异

从几何本质来看，牛顿法利用二次曲面贴合当前位置的局部地形，而梯度下降仅用平面近似。通常而言，二次曲面的拟合精度更高，因此牛顿法规划的下降轨迹更贴近真实的最优路径。

### 5.4.3 贝叶斯分类体系

#### 核心基石：贝叶斯定理

贝叶斯分类器泛指一系列以贝叶斯定理为理论基石的分类算法。该定理由英国数学家托马斯·贝叶斯确立，核心在于揭示两个条件概率间的联系。

在正式推导前，需明确三个核心概念：

1.  **条件概率（后验概率）**：指事件 `B` 已发生的前提下，事件 `A` 发生的几率，记作 `P(A|B)`。
2.  **联合概率**：指事件 `A` 与 `B` 同时发生的概率，标记为 `P(A, B)`。
3.  **边缘概率（先验概率）**：单一事件发生的概率。它通过对联合概率中非目标变量进行“边缘化”操作获得——离散变量求和，连续变量积分。例如 `P(A)`、`P(B)`。

### 5.4.4 决策树：分而治之的艺术

*   **分支**：判断结果。

树包含根节点、内部节点、叶节点。根节点含全量样本，自顶向下递归测试属性。**根节点选择与内部节点顺序直接决定泛化能力。**

[PRE9]

**停止生长条件**：
1.  当前节点样本纯度 100% → 标记为叶节点。
2.  属性集为空或样本在所有属性上取值相同 → 标记为叶节点，类别设为父节点多数类（利用后验分布）。
3.  样本集为空 → 标记父节点为叶节点，类别设为父节点多数类（利用先验分布）。

#### 划分策略的较量

决策树构建的核心在于**如何选择最优划分属性**，目标是让分支节点样本纯度尽快提升（同类聚集）。

#### 剪枝：对抗过拟合的手术刀

过拟合树泛化差，需主动剪枝。

*   **预剪枝**：生长前判断是否继续，速度快但欠拟合风险大。
*   **后剪枝**：先生成全树再自底向上剪，泛化通常更优但耗时长。

**各算法剪枝策略**：
*   **ID3**：无剪枝，极易过拟合。
*   **C4.5**：**悲观剪枝**。递归评估用最优叶节点替代子树是否降低错误率（基于训练集错误率估算未知样本错误率）。
*   **CART**：**代价复杂度剪枝**。从最大树出发，迭代剪去对训练集熵贡献最小的分裂，生成嵌套剪枝树序列，再通过验证集选最优。

#### 缺失值处理：不弃一分数据

现实样本常有缺失属性，直接丢弃浪费严重。

1.  **划分选择时**：仅用无缺失样本子集计算增益，按比例折算权重。
2.  **样本归属时**：将缺失样本**同时**划入所有子节点，但赋予不同权重（概率），而非硬性归入单一分支。
