技术成熟后的稳定产出期
当一项技术完成普及并走向成熟，它已不再具有“新技术”的光环，而是进入了持续产出的稳定阶段。

不同技术的演进路径比理想化曲线要复杂得多。结合多年在技术与商业一线的从业、创业与咨询经验，我观察到绝大多数技术在前三个阶段的走势高度一致，但跌到谷底之后的走向则出现明显分化，可以概括为先猛涨后骤跌，低谷分路而行。

[PRE0]

### 骤升骤降，低谷分路
触及底部后，技术的后续发展大致可归为三种。

（1）趋于平缓的常规轨迹。经过调整后技术缓慢回暖并得到一定应用，但始终无法回到曾经的期望高峰，这是多数技术的归宿。

（2）偏向衰退的沉沦轨迹。实践证明该技术未达预期，适用范围远小于先前判断，逐渐边缘化。

（3）令人振奋的超常轨迹。技术在谷底后强力反弹，应用成效甚至超出最初设想的顶峰。互联网是最典型的例证。互联网在1999至2000年达到期望顶点，2000年末跌至谷底，随后数年逐步修复，如今已步入稳定产出期，现实成果比当初想象更高。我亲身经历了互联网光环曲线的五个完整阶段，感受尤深。

我判断人工智能将走出超常轨迹。正基于此判断，近几年我把主要精力投向人工智能领域，研究人工智能产品与人工智能商业模式并展开咨询，希望借本书分享部分心得。

### 1.1.3 X 技术和 X 技术商业的概念
以技术为基础的商业即为技术商业。能够走出超常轨迹的极少数技术，我称之为X技术，以之为基础的商业即为X技术商业。

X蕴含三层含义。

（1）X为未知数，意味着该技术想象空间极大。
（2）X为乘法符号，意味着该技术影响力极强，会对关联的商业要素产生重大冲击。
（3）X为向四面延伸的图形，意味着X技术应用场景极广。

技术种类繁多，多数影响面狭窄，少数影响面宽广。如化工领域制造某种化合物的工艺，仅影响化工行业乃至该行业的部分产品，便不属于X技术。总体而言，X技术只是少数。

集成电路、计算机、移动通信、互联网是二战后出现的少数X技术。它们影响深远，几乎波及所有行业，颠覆了一些行业，甚至催生全新行业。这些X技术彼此关联、相互促进。人工智能是近期出现的一项X技术，且影响力较大。以之为基础的人工智能商业也将成为全新行业。

本章聚焦于X技术商业的特质，这也是全书的基础。

### 1.1.4 X 技术的高度不确定性
X技术商业要素众多，其中X技术既是影响最大也是最不确定的因素。不确定性体现在三方面。

（1）技术本身的不确定。从科学到工程，从实验室到真实应用，充满不确定。
（2）技术间竞争的不确定。技术源源不断涌现，不同技术间可能竞争甚至相互取代。如显示技术的王者CRT已被LCD、OLED取代，模拟移动通信被数字移动通信取代，数字移动通信又经历了2G、3G到4G、5G的快速迭代。目前尚无明确技术能取代人工智能，但在人工智能内部不同路线和方向间可能存在竞争甚至相互替代。深度学习目前强势，基于它的公司估值很高，但未来是否会出现新的人工智能技术，无人能断定。
（3）技术对其他要素影响方式与程度的不确定。总体看，我国原创性更多体现在产品和商业模式上，而非技术本身。

X技术的高度不确定，让X技术商业同样充满不确定，这恰恰是其魅力所在。正如互联网商业中占据优势的公司，其成功多带有“意外”色彩。

正是这种高度不确定，打破了资源型公司长期占据优势的局面，也给新玩家创造了机会，让商业和社会更具活力。中国的人工智能商业既有百度、阿里巴巴、腾讯等互联网时代的巨头，也有科大讯飞等老牌企业，还有旷视、商汤、依图、云从、云知声等大量新面孔，并且会持续产出新机会。创业者、企业家、互联网公司和传统公司都有机会。

### 1.1.5 X 技术商业的特征
X技术的高度不确定，造就了X技术商业的一系列特质。

1. 高难度拼图
拼图游戏中我们知道最终效果，也拥有全部图块，只需正确拼合。若把商业比作拼图，X技术商业就是高难度拼图。初始阶段既看不到最终效果，也不知道图块有多少，但必须立刻开拼。因为只有开拼才有可能完成，等待只会被淘汰。

以移动互联网的拼图为例。诺基亚在中国推出支持WAP上网的手机，开启了移动互联网的希望。最初功能机上通过手机浏览器WAP上网，费用高、应用少、体验差。随后K-JAVA、Symbian、Windows Mobile应用等新图块加入，有所改善但仍不完整。业界把希望寄托在3G上，甚至出现“3G门户”这类产品。

3G到来后拼图仍未完成。直到iPhone 4进入中国，以小米为代表的安卓性价比手机出现，市场迅速从功能机转向智能机，所有图块才齐备，移动互联网拼图在极短时间内完成。

我2004年第一次创业定位3G内容平台，到平安，再到2010年第二次创业，跨度6年，移动互联网的图块才集齐，确实是高难度拼图。

当前人工智能遇到的问题与当年移动互联网很像。2016至2018年人工智能热潮中很多图块缺失，应用不理想。技术和资本是重要图块，但缺了人工智能产品和商业模式等图块，拼图无法完成。人工智能产品和人工智能商业模式正是本书讨论的核心。

2. 初期物种爆发，后期赢家通吃
物种爆发指企业、产品、商业模式在短时间内大量涌现。商业界无法容纳过多物种，如同自然界一样。

人工智能商业领域也已开始物种淘汰。曾经成立的互联网公司，大多数很快消失。当物种过多时，自然界会淘汰。

经过大爆发、大淘汰后就会出现赢家通吃，一些物种胜出成为优势物种。商业界同样如此，中国互联网最终只有少数公司占据了行业大部分价值。

3. 叠浪连击
X技术商业另一个重要特质是叠浪连击，第一波浪潮未退，第二波浪潮已叠加。

以零售为例，在线零售、移动零售、社交零售、无人零售多重浪潮叠加形成连环冲击。多数零售企业还没应付好前一波，下一波已到来。能扛住一波已不容易，能扛住叠浪连击更难。

人工智能技术正形成一股巨浪，它会与哪些浪叠加，叠加后冲击如何，很难预料。

4. 变化无处不在，意外频发
赢家通吃后，行业格局常相对稳定，像化学制药、燃油汽车数十年难有新玩家。但X技术商业不同，变化无处不在，意外频繁，赢家名单也会变动。

以电商为例，淘宝加天猫占据大半江山时，格局看似已定，京东靠自建物流颠覆认知崛起；当阿里巴巴加京东格局看似已定时，拼多多借助移动互联网新机会，以难以想象的速度崛起。电商又进化为新零售，持续变化，意外不断。

与传统商业相比，X技术商业看似大局已定，实则暗流涌动。人工智能大规模商业化时间尚短，更需借鉴其他X技术的商业化经验。人工智能产品经理在做产品规划和商业模式设计时，应充分考虑这些特质，在迷茫时从中寻找灵感和突破口。

## 1.2 X 技术商业的要素及其关系
1.1节从宏观层面讲了X技术商业的特质，本节从企业视角理解其要素与关系。

X技术商业的要素与结构如下图所示。图中三角形的核心是技术—场景，围绕其外是资源、产品及商业模式，为它们提供支撑的是组织能力。

X 技术商业的要素与结构

这是我长期从事X技术商业并不断迭代精简的原创框架。因篇幅所限，仅介绍要点。

1. 技术—场景
中心是技术—场景，二者用连字符组合。技术只有与合适的场景结合才能持续应用并产生商业价值。同一技术在不同场景下价值不同，同一场景用不同技术价值也不同。

场景源自戏剧术语，指特定的情境。结合技术商业理解，场景就是用户所处环境与用户自身状态的汇总。

场景包含用户与需求，脱离场景需求就难以把握。需求就是产品的机会，而用户时刻处于某种场景中。将用户经历的场景按时间串联，就能勾勒用户特征。需求深受场景影响，某种需求在特定场景强烈，在另一些场景微弱。

技术商业要实现技术与场景的适配，找到适配关系就找到了技术产品和技术商业的生长土壤。

人工智能产品经理需要将合适的人工智能技术与合适场景适配，发现技术—场景中的商业价值，识别商业阻力，据此规划产品、设计商业模式。

2. 资源
从事商业离不开各种资源，传统商业和X技术商业皆然。

X技术商业在资源获取上具有独特性，它用未来可能产生的重大收益换取当下的稀缺资源，如通过VC获取发展早中期的资金。VC让很多技术产品和商业模式得以实现。

3. 产品
X技术商业高度重视产品。产品是价值挖掘机，没有产品机会也无法兑现。产品是商业模式的基础，商业模式必须建立在产品之上。

2016至2018年人工智能应用遇阻，很大程度上不是领域选错，而是产品不够成熟。很多产品借人工智能光环上市，但用户实际体验很差，既无法让技术持续应用，也难以商业成功。

4. 商业模式
商业模式是企业商业运作的顶层方式。

管理学大师彼得·德鲁克说：“当今企业之间的竞争，是商业模式之间的竞争。”商业模式的重要性由此可见。它也是我研究的重点，我在两次创业中都做了商业模式创新，近年的咨询项目核心内容也是商业模式。

魏朱商业模式图

魏炜、朱武祥将商业模式分为六大要素：定位、业务系统、关键资源能力、盈利模式、现金流结构和企业价值。上图不仅列出六要素，还用箭头表示它们的关系。理解企业的商业模式，就是理解这六要素及其关系；设计商业模式就是设计这六要素及其关系。

传统商业模式创新难度很大，导致企业同质化竞争激烈，行业利润被压缩。X技术商业更有可能实现商业模式创新，相关企业可享受创新红利，互联网商业就是典型案例。

5. 组织能力
实现价值不仅靠个人能力，更靠组织能力。

很多有优势的传统企业进入X技术商业却未获预期成功，重要原因就是组织能力不足。传统企业的组织能力适配原有业务，并不适合新的X技术商业，需要快速提升和调整。

知名风险投资数据公司CB Insights调研上百家技术创业公司，总结出失败主因，与X技术商业要素结构高度吻合。

技术创业公司失败的主要原因

### 1.2.2 理解 X 技术商业要素及其关系的例子
1. 支付业务的五大要素及其关系
用支付业务说明X技术商业五大要素关系。

（1）技术—场景。长期以来国内支付主体是银行和银联，第三方支付仅为辅助。支付对银行只是基础业务，并非战略业务。互联网技术改变了局面，其与支付场景结合形成新技术—场景，蕴藏的巨大价值首先被蚂蚁金服等互联网公司发现。

（2）资源。支付宝一方面借助资本市场资金，另一方面充分利用阿里巴巴电商平台的用户和场景资源，起步就提供适合电商的担保交易，解决早期信任问题。此举带来海量用户和资金积累，为余额宝等产品创新奠定基础。银行则严重忽视了场景资源的价值。

（3）产品。银行长期认为支付产品无需改进，用户只需正确使用。支付宝却持续对支付做产品创新，使用更便利、安全系数提升，更受用户欢迎。银行卡等原本属于银行的资源，逐渐被用户后置为支付宝的资金来源。

（4）商业模式。很长一段时间内支付宝不向收付双方收费，开创支付领域新模式。该模式威力逐步显现，银行意识到时已难扭转。

用户绑定银行卡后，银行卡常被放在钱包里不再使用。支付宝通过一次次支付与用户关联越来越强，银行与用户关联越来越弱。银行最初认为用户仍需从银行卡扣钱，价值还在，直到支付宝推出花呗。

花呗是消费信贷产品，给用户额度先消费后还款。支付宝的花呗比信用卡更实用便捷，无需实体卡和高昂发卡成本，只需App即可使用。很多用户将花呗扣款优先级设高于信用卡，导致信用卡出现双降，已开卡支付额下降和新卡申请量下降，直接抢了信用卡生意。银行这才意识到价值空间被侵蚀，但已难以阻止。

随着支付宝用户增长和账户余额增加，支付宝推出余额宝，带动支付宝做大并催生互联网金融行业。

支付宝的价值不仅来自银行的转移，还有新价值来源。它依靠支付积累海量高价值数据，构建覆盖更广质量更高的信用评价体系芝麻信用。芝麻信用分可供用户使用，也可赋能合作企业，如免押金骑行、租用电子产品、入住酒店，既方便用户又增加合作企业业务量。至此，支付新技术—场景展现的价值已远超银行当初的理解。

（5）组织能力
做这么多新事需要强大组织能力。阿里巴巴的组织能力建设处于国内乃至全球领先，有系统方法构建组织能力。这是商业版图不断扩张的组织基础，只是相对产品和市场关注较少。

## 1.2.3 AI 商业的五大要素及其关系
`AI`商业与互联网商业同样是`X 技术商业`，互联网行业验证的规律已在`AI`行业初步显现。

### (1) 技术—场景
`AI`应用在一些场景受阻，但在人脸识别安防、语音技术智能音箱等场景已获初步认可。

### (2) 资源
起步阶段，`AI`技术公司获取资源能力比互联网公司更强，优秀公司拥有充足资源去发展和试错。

### (3) 产品
