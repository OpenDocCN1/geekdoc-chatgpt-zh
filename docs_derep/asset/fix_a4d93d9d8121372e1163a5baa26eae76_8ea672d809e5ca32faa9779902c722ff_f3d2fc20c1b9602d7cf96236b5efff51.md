Janus 多模态架构概览

统一框架：Janus 将视觉建模拆成理解与生成两条独立流，但整个系统仍在单一自回归 Transformer 体系中运行。统一的体系让训练与推理流程更简洁，提升多模态数据的处理效率，也方便向视频理解、多模态对话等任务延展。

### 7.2.3 多模态理解

该部分的目标是把图像中的丰富语义抽取出来，用于视觉问答、图像描述等。Janus 为此设计了专用的模块与流程。

#### 1. 视觉编码器
理解分支的核心是 SigLIP 编码器。它基于 Transformer 构建，重点在于捕捉图像的高层语义。

- (1) 富含语义的表征：该编码器能同时获得场景、物体类别等整体信息，以及细节纹理和局部关联的高维向量。既能概括整图内容，也能反映细微结构。
- (2) 便于与语言融合：SigLIP 在设计时已考虑语言端对接，输出的格式与分布经过调优，能直接匹配文本特征，为后续融合打下基础。

#### 2. 特征处理
SigLIP 输出的是二维特征图，由若干局部区域的向量组成网格。为让视觉信息在多模态建模中发挥作用，Janus 采用了两项配合策略。

- (1) 保留空间位置：为适配自回归 Transformer，二维图被拉平成一维序列。展平并非简单矩阵转线性，而是保留了原图的空间排列，这对把握局部与全局关系很关键。
- (2) 格式对齐：展平后的视觉序列与文本 Token 序列在形式上一致，自回归建模和跨模态融合可在同一输入空间进行，有助于模型同时兼顾图像与文字的上下文。

#### 3. 理解适配器
为把展平后的高维视觉向量映射到与语言模型相同的嵌入空间，引入了两层 MLP 作为理解适配器。

- (1) 向语义空间映射：适配器对视觉向量做非线性变换，使其语义更贴近文本表达。映射后视觉与文本在语义层面对齐，便于跨模态融合。
- (2) 顺畅融合：经映射后，图像语义可与文本数据合并为统一的多模态输入序列。在视觉问答、图像描述等任务中，模型能直接利用不同模态的互补信息，提升理解准确率与生成质量。

### 7.2.4 视觉生成路径

视觉生成旨在把图像离散为 ID 序列，并依据文本描述生成对应图像，解决传统模型在图像-文本对齐效率、生成质量与语义一致性上的难题。通过把图像离散为视觉 Token 并纳入语言模型输入空间，Janus 能以类似处理文本的方式生成图像。

#### 1. 视觉编码器：VQ Tokenizer
生成分支的核心是基于向量量化的 VQ Tokenizer，将图像切分为离散视觉 Token。

- (1) 图块划分。先把输入图像切成固定尺寸的小块，通常为 16×16 像素。图像被分解为多个局部区域，每个区域代表局部特征。
- (2) 向量量化。每个小块被编码为特征向量，再映射到离散码本空间。量化本质是把连续向量转为离散符号，相当于为每个图块分配一个 Token，在表达力与计算成本间取得平衡。
- (3) 离散化。量化后图像变为一系列离散 ID 序列，可像文本一样处理，每个视觉 Token 类似词或字符，便于对齐语言模型输入并借用其生成能力。

#### 2. 特征处理：生成适配器
VQ Tokenizer 输出的 ID 序列需进一步适配语言模型输入。

- (1) 序列拉平。输出本为二维对应行列，拉平为一维时保留空间顺序，使语言模型能理解局部与全局结构。
- (2) 码本嵌入映射。每个离散 ID 对应训练时学习得到的码本嵌入。生成适配器由两层 MLP 构成，负责把码本嵌入投射到语言模型的输入空间。
- (3) 交互融合。映射后视觉 Token 与文本 Token 在同一空间交互。语言模型据此能同时处理文本和视觉信息，例如在文到图生成时依据文本语义挑选合适的视觉 Token 构建图像内容。

#### 3. 向量量化模型
该路径的核心是基于向量量化的 VQ-VAE。开源实现 vq_model.py 包含编码器、解码器和向量量化器，支持图像压缩与重建。其思想是用 VQ-VAE 对输入编码、离散化，并通过向量量化学习更优表征，为图像嵌入与生成提供基础。

### 7.2.5 自回归 Transformer 模型

该模型是 Janus 的核心，负责处理理解与生成两路特征序列并产出结果，把多模态处理统一到序列生成框架。

#### 1. 输入融合
处理前需先融合两路特征。

- (1) 特征拼接：SigLIP 提取的图像语义特征与 VQ Tokenizer 生成的离散视觉 Token 嵌入按顺序拼接，保留不同模态的顺序信息，使模型能区分输入来源。
- (2) 上下文保留：保留顺序后，自回归 Transformer 能更好理解多模态上下文，明确哪些特征来自图像、哪些来自文本，从而在生成时更合理结合信息，提供更丰富的语义背景。
- (3) 统一输入：拼接后形成统一的多模态输入序列进入模型，使多种模态数据在一个框架下处理，简化训练与推理。

#### 2. 自回归生成
模型核心功能是生成输出序列，文本或图像均可，遵循自回归机制。

- (1) 逐 Token 预测：模型逐个预测下一个 Token，生成时参考已产生的历史序列，保持依赖连贯。
- (2) 依赖捕捉：自回归机制让模型捕捉序列依赖，例如生成描述时会依据前文决定下词，生成图像时会依据已生成的区域决定下一个视觉 Token，使输出更自然连贯。
- (3) 多模态生成：通过把视觉 Token 纳入输入序列，模型可在生成过程中同时处理文本与图像，实现文到图、图描述等复杂任务。

#### 3. 预测头
为支持多模态任务，Janus 在自回归 Transformer 上增加了多个预测头。

- (1) 语言模型自带预测头：用于文本生成，能根据多模态特征序列输出图像描述、视觉问答答案等，提升理解类任务的文本质量。
- (2) 视觉生成预测头：额外增加一个随机初始化的预测头，专门负责图像预测，把生成的视觉 Token 序列转为最终图像，保持对理解任务的支持。
- (3) 多任务支持：多预测头设计让模型同时兼顾理解与生成，在同一框架下高效处理多种多模态任务。

### 7.2.6 三阶段训练策略

Janus 采用三阶段训练逐步提升多模态理解与生成能力。各阶段目标与方法见表7-1。

表7-1 三阶段训练中每个阶段的具体目标和方法

| 阶段 | 目标 | 方法 |
| :--- | :--- | :--- |
| 适配器和图像预测头训练<br>(Training Adaptors and Image Head) | 在冻结大语言模型和视觉编码器参数的前提下，训练理解适配器、生成适配器和图像预测头，建立视觉与语言的有效连接 | 在ImageNet-1K上训练，学习从图像像素到语义的映射，确保视觉特征能被语言模型理解，为后续融合打基础 |
| 统一预训练<br>(Unified Pretraining) | 在多模态数据上联合训练，使模型具备扎实的理解与生成能力 | 模型使用纯文本、多模态理解、视觉生成等多类数据训练，学习模态间的关联，提升多模态任务表现 |
| 监督微调<br>(Supervised Fine-tuning) | 通过指令微调增强指令跟随与对话能力 | 使用混合数据集微调，包含多模态理解、纯文本对话、文到图生成等，全面提升理解生成能力并改善指令响应 |

三阶段策略让 Janus 在理解与生成上逐步增强，为多模态应用提供基础。

## 7.3 训练策略

多模态模型训练时合适的策略对性能、稳定性和泛化至关重要。若运营酒店预订平台，需要从海量酒店图片中挑出最吸睛的首页图以提高转化，人工筛选效率低且主观。借助多模态训练策略即可实现智能化筛选，如图7-6所示。

### 7.3.1 多任务学习

多任务学习指同时训练模型完成多个相关任务以提升泛化能力，例如一起做图像分类和文本生成，让模型更好把握图像与文本关系。实例7-1展示了使用预训练模型做多任务学习的过程，先用预训练 ResNet 提取图像特征，用预训练 BERT 提取文本特征，再用于图像分类和文本分类两项任务。
