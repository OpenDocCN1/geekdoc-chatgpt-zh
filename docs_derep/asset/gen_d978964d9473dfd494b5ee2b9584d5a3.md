## 第 4 章 AutoGen Agent 框架实战指南

2023 年 9 月，微软对外开源了 AutoGen。AutoGen 的核心在于 Agent，而 Agent 是人工智能里的重要概念，指能够感知周边环境并通过执行单元对环境做出回应的系统或主体。Agent 具备自主处理信息、判断决策并执行行动以达成目标的能力，通常具有目标导向、自我学习、环境交互和决策执行等特征，形态多样，涵盖计算机系统、移动终端、云平台等，被广泛用在自然语言处理、机器人技术、个性化营销等多个场景。

AutoGen 是一个面向大语言模型的 Agent 开发框架，基于 OpenAI GPT-4 等模型，可借助单个或多个 Agent 来搭建大模型应用，如图 4-1 所示。

本章将演示 AutoGen 如何依靠 Agent 之间的对话协作来完成用户下达的任务。

### 4.1 AutoGen 开发环境

AutoGen 采用 Python 实现，需要先搭建 Python 的开发环境并配置常用工具，下面做简要说明。本书的示例均在 Windows 操作系统下进行，相关软件的具体安装流程不再详述。

#### 4.1.1 Anaconda

Anaconda 中文意为蟒蛇，是一个开源的 Python 发行版，内置 conda、Python 以及 180 多个科学计算包及依赖。没有编程基础的用户安装 Anaconda 更省事，后续无需再单独装依赖。有一定基础的用户也可选用 Miniconda，按需安装依赖以节省空间和时间。本书使用 Anaconda3，版本为 1.12.1。

#### 4.1.2 PyCharm

PyCharm 是 JetBrains 公司出品的 Python 集成开发环境，Visual Studio 2010 的重构插件 ReSharper 同为该公司打造。PyCharm 提供调试、语法高亮、项目管理、代码跳转、智能提示、自动补全、单元测试、版本控制等提升效率的功能。本书选用 PyCharm Community Edition 免费版。

#### 4.1.3 AutoGen Studio

AutoGen Studio 可快速搭建多 Agent 工作方案的原型，为 AutoGen 提供可视化界面。

安装 AutoGen Studio 的步骤如下。

- 第一步：启动“Anaconda Powershell Prompt”窗口。
- 第二步：在该窗口输入“pip install autogenstudio”命令完成安装，如图 4-2 所示。
- 第三步：在同一窗口输入“autogenstudio ui --port 8081”命令指定端口，如图 4-3 所示。
- 第四步：在浏览器中访问“127.0.0.1:8081”，推荐使用 Chrome，即可看到图 4-4 所示的页面。
