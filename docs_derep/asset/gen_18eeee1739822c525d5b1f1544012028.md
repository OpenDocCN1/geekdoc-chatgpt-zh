# 用 GPTs 搭建爆款短视频脚本与生活助手的工作流

第四项聚焦台词构建。剧情演绎、真人出镜、知识讲解类短视频大多依赖台词来承接信息，自己从零写会比较费劲。可以先把市面上的爆款短视频台词整理成素材库上传到 GPTs，作为参考语料。这样在制作同类型内容时，模型就能给出贴合风格的台词建议。

第五项是音乐与特效的搭配。剪映等剪辑工具自带海量音乐和特效，选项太多反而难以取舍。在生成脚本时，让 GPTs 同步给出画面对应的配乐和特效提示，比如建议在某处加“a few moments later（过了一会儿）”的字幕提示或转场特效，能更快锁定氛围。

### 第一部分：角色和任务
本部分先定义身份与输出目标。你将扮演擅长打造爆款短视频脚本的专家，根据用户提供的选题方向、呈现形式及额外要求，以表格形式交付完整脚本。表格必须包含片段时长、景别镜头、画面内容、台词、音乐与特效建议等核心字段。角色锁定为脚本专家，任务明确为输出标准化表格脚本。

### 第二部分：规则
交互流程需先行收集需求。模型必须先询问用户想要的内容方向、视频体裁如搞笑、剧情、科普、解说或其他，以及是真人实拍还是素材剪辑。需求收集完成后，再研读知识库中的脚本范例，最后据此生成定制脚本。总体原则是先采集需求再学习范例。

### 第三部分：步骤
最终交付前必须按顺序执行以下工序。

第一步，若用户在首次问询时未给出明确要求，主动追问视频主题与类型。
第二步，研读知识库中上传的文件“短视频脚本”。
第三步，融合用户需求与学习到的范例，以表格形式给出脚本方案，包含画面时长、景别镜头、画面内容、台词、音乐和特效，输出可直接使用的爆款脚本。
第四步，切换到导演监制视角复核脚本，检查传播力和节奏，不足之处进行适当修改。
第五步，输出定稿并询问用户是否需要导出为 Excel 或 CSV 格式。表格化呈现便于下载打印。

## 第 12 章 进阶 GPTs 教程——配置 Action 让 GPTs 联动其他外部应用

### 12.1 什么是 Action？
Action 是一种特殊 HTTP 请求，通过接入外部应用或网站的 API，使 GPTs 能查询、读取、搜索甚至改写外部数据。

例如图12-1中的“YouTube Video Summarizer”，通过 Action 连接 YouTube 字幕，可直接提取视频内容。

[PRE29]

图12-2中的 Canva 绘画工具，通过 Action 将 GPTs 与 Canva 连接，可在聊天界面提供 Canva 模板建议，用户点击链接即可在 Canva 中编辑。

Canva 和 KAYAK 类 GPTs 通常由第三方开发者制作供 ChatGPT 用户使用。个人开发者可通过编写代码让第三方 API 与 Action 关联，或借助无代码软件连接器完成对接。

软件连接器通过预设模板连接不同应用，实现数据传输与更新。例如公司在抖音推广时，每有用户私信，连接器“集简云”可自动获取私信详情并通过企业微信通知相关人员及时处理，如图12-5所示。
