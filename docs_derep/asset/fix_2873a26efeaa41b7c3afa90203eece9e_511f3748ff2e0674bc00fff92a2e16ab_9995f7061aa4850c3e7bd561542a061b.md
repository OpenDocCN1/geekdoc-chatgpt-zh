SimpleVectorDB 的初始化会按序处理文档集，为每条文本调用 mock_vector_for_doc 生成伪向量，随后把编号与向量写入内部索引，同时在 doc_map 中保存编号到原文的对应关系。search 方法接收查询向量后，遍历索引中全部向量计算欧几里得距离，生成带 doc_id 与距离的列表，按距离从小到大排序后返回前 k 个结果。get_doc_text 依据编号从对应表中取出原文。最后在模块层面创建 VEC_DB 实例，用 DOCS 数据一次性完成建库，后续检索直接复用该实例。
