> **ID3 决策树算法概述**

ID3 即 Iterative Dichotomiser 3，是早期经典的分类型决策树方法。它依托熵值衡量子集纯度，并以增益最大者作为节点分裂依据，递归选择最优特征逐步生长出树形结构，用以完成数据分类 [Data: Entities (0); Reports (0); Relationships (0)].

**熵与增益**

熵用来描述数据集的混乱程度，数值越低代表纯度越高。增益则通过分裂前后熵值的差额来判断属性划分能力，ID3 每次都挑增益最大的属性进行切分，由此递进构建树 [Data: Entities (0); Reports (0); Relationships (27)].

**划分方式与离散限制**

ID3 仅能处理离散型特征，连续型特征必须先离散化例如分箱。其采用逐列展开的方式对数据进行拆分，这一点与 CART 寻找最优切分点的做法不同。比如针对 AGE 列的不同取值，ID3 会把样本拆成多个子集，再分别计算熵与增益 [Data: Sources (0, 1); Entities (6, 7, 8, 9); Relationships (10, 11, 12, 13)].

**ID3 的局限性**

尽管 ID3 在决策树发展历程中意义重大，但仍存在不足：

1. 无法直接处理连续变量，必须先离散化 [Data: Entities (0); Reports (0)].
2. 偏好多值属性：挑选分裂特征时容易倾向取值较多的属性，可能导致过拟合 [Data: Sources (1); Entities (0)].
3. 缺少剪枝手段：没有内置的剪枝机制防止过拟合，训练集表现好而泛化能力受限 [Data: Sources (1); Entities (0)].

**与 C4.5、CART 的关系**

ID3 是后续算法的基础，C4.5 和 CART 在其上做了增强。C4.5 加入了连续变量处理、剪枝以及信息值等改进，CART 则同时支持分类与回归，并采用二分分裂策略 [Data: Entities (1, 2); Relationships (0, 1, 4, 14)].

**总结**

作为决策树领域的开创性方法，ID3 通过熵与增益构建分类模型，虽然存在局限，但其核心思路为 C4.5、CART 等后续优化提供了重要基础，进一步提升了模型的性能与适用范围 [Data: Entities (0, 1, 2); Reports (0, 1); Relationships (0, 1, 4, 14)].

#### 5.2.8 构建GlobalSearch搜索引擎并进行问答

在前述的LocalSearch中，我们已经实现了基于具体实体的语义问答能力。然而，在实际应用中，用户常常会提出更高层次的问题，例如：

- 这些文档的主题是什么？
- 这个知识图谱的核心结构是怎样的？
- 有哪些值得重点关注的技术方向？

这类问题通常涉及整个知识图谱的结构与内容，不再局限于某一实体节点。为此，GraphRAG提供了GlobalSearch（全局搜索）模块，专门用于支持抽象语义概览类问答。
