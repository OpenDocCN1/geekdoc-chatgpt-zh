训练阶段使用 Accelerate 统一准备模型、优化器、数据加载器与学习率调度器。设定 20 个轮次的外层循环，内层用 tqdm 包装训练集。每次批次先把 input_ids 与 labels 送到 GPU，调用 model.forward 获取损失，之后走 accelerator.backward，再依次执行优化器步长、学习率调度器步长、梯度清零。进度条实时展示当前轮次、训练损失与换算成千倍的学习率。梯度裁剪代码保留但注释掉了。每当轮次能被 3 整除时，把当前权重持久化到 ./glm6b_pt.pth。

model, optim, train_loader, lr_scheduler = accelerator.prepare(model, optimizer, train_loader, lr_scheduler)

for epoch in range(20):

推理部分先实现了一个可复用的 Top-p 采样函数，对概率分布排序后累加截断并重归一化，再用 multinomial 抽样。配置上只动了两项：pre_seq_len 设为 16，prefix_projection 设为 False，其余保持不变。模型同样以半精度加载并进入 eval 模式。

生成任务以 SPO 抽取为例，最大长度 288，源文本上限 256，提示词为“按给定的格式抽取文本信息。\n文本:”。对每条输入先做分词，必要时截断，拼接提示、源文本、[gMASK] 与 <sop> 三个特殊标记。循环中每次取倒数第 3 个位置的 logits，用温度 0.95 做 softmax，再用 Top-p 0.95 采样下一个词，更新输入序列，遇到结束符 130005 则提前退出，最后解码输出。

def sample_top_p(probs, p):

    probs_sort, probs_idx = torch.sort(probs, dim=-1, descending=True)

    probs_sum = torch.cumsum(probs_sort, dim=-1)

    mask = probs_sum - probs_sort > p

    probs_sort[mask] = 0.0

    probs_sort.div_(probs_sort.sum(dim=-1, keepdim=True))

    next_token = torch.multinomial(probs_sort, num_samples=1)

    next_token = torch.gather(probs_idx, -1, next_token)

    return next_token

def quantize(self, bits: int, empty_init=False, **kwargs):

    if bits == 0:

        return

    from .quantization import quantize

    if self.quantized:

        return self

    self.quantized = True

    self.config.quantization_bit = bits

    self.transformer = quantize(self.transformer, bits,

                                empty_init=empty_init,

                                **kwargs)

    return self
