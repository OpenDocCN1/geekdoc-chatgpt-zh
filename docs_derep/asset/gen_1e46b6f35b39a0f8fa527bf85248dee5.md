## 6.5 甘特图：让项目进度一目了然

甘特图是项目管理中常用的进度呈现方式，用横向条形来表达任务在时间轴上的安排。它以时间作横轴、任务清单作纵轴，每项任务以一条色块表示，色块长度对应工期，位置对应起止时间。通过甘特图，团队可以实时跟踪进展、预判风险、调整优先级，并方便地与干系人同步计划。图 6-4 所示为 Todo List 项目的计划甘特图。

[PRE2]

图 6-4 Todo List 项目计划甘特图

甘特图的绘制既可以手绘，也能借助专业工具，常见选择有：

（1）Microsoft Project：微软出品的强大项目管理软件，支持复杂甘特图和计划编排，可与 Excel、Word 等 Office 应用联动，图 6-5 显示的是用 Project 制作的 Todo List 项目甘特图。

（2）Asana：团队协作平台，内置易用的甘特图，兼具任务指派、时长统计、依赖设置、进度报表和虚拟看板等能力。

（3）Trello：轻量协作工具，提供简化的甘特视图，支持清单、标签、备注、附件、截止期等信息，按时间表组织列表。

（4）Smartsheet：云端企业协作平台，界面类似 Excel，同时提供甘特图、时间表、任务分配、资源管理、自定义报表等项目管理功能。

（5）TeamGantt：专注甘特图的在线服务，便于团队制定和共享计划，支持分配、工时跟踪、进度报告、评论和文件共享。

（6）Excel 也能搭建甘特图，图 6-6 为 Excel 制作的 Todo List 项目甘特图，但灵活性有限。Excel 无法自动计算任务依赖，也缺乏完善的进度跟踪，在复杂项目中专业软件更实用。
