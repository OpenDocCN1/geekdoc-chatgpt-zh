# 背景是什么：我们说不清却离不开的底座

一言概括，德雷福斯把背景理解成一组活的实践、技巧与日常活动。背景是否清晰？在他那里答案是否定的。背景指人面对事实、话语和难题时所身处的处境，用最泛的说法它就是一种无法被规则框定的存在论规定；它也不能靠可表征的事实与规则完成形式化分析，它更像一种可能性前提，只要事物理论上还有意义，背景就始终在场。常态下背景既未被表征，也无法被任何认知系统转成一系列表征，人、动物乃至人工智能的认知系统恰恰靠表征来决定该怎么行动。可我们解释自身行为时，终究要落回日常实践，说白了“这就是我们干的事”“这就是人的意义”。于是所有可理解性、所有智能行为，最后都要追溯到“我们是什么”这一层意义，而这条追溯会坠入某种永远无法明确的东西。[^(\[38\])](#chapter003.html#m38)这不可知的东西就是背景。德雷福斯把海德格尔的“对存在的领会”读作一种模糊的背景，它是理解和认识能够发生的必要条件；我们的认知与行动并不依靠清晰的规则，也无法用清晰的规则对生活进行明智操控。规则只能在背景里起作用，而背景本身是模糊的，无法事先被拆成原子事实或信息再装进计算机描述。

提出背景概念，是为了反驳把心智等同于信息处理的心智认知主义。该模型把心智与世界的关系、理解自身与周遭的能力都看成处理信息的流程；世界被描绘成一串毫无意义的原子要素，像感官材料一样冲击心智，本身对主体毫无意义。[^(\[39\])](#chapter003.html#m39)按康德的说法这是杂多表象，心智的工作是对这些独立要素进行表征和信息化处理，进而建构一个有意义、符合规则的世界。德雷福斯认为把事物看成独立现存实体是不恰当的，这源于“独立”这一功能谓词制造的错觉。没有任何东西对我们可理解，除非它先以已融入我们的世界、已编入应对实践的方式显现。[^(\[40\])](#chapter003.html#m40)事物只有在背景里凸显、碍眼时才会被感知并成为注意焦点。正如荀子所说“目不能两视而明，耳不能两听而聪”，我们只能处理眼前突出的对象，而对象正是靠背景衬托才显现。意义是在背景中显出的，认知的可能性根植于此。

塞尔则从神经生物学出发谈背景，德雷福斯不愿把背景还原为心理过程的神经科学描述，于是两人分岔。塞尔把背景看成能生成意向状态的神经元结构，更愿意说背景是一组能力：“背景就是使一切表征得以发生的非表征性心理能力集合”。[^(\[41\])](#chapter003.html#m41)由此塞尔主张背景是心理的，以心理内容与外部事物的关系为基础，近似于一种信念系统，哪怕不是，也仍是心理性的东西，涵盖心智能力、倾向与立场。正是背景能力让我们能在恰当时地做恰当事，流畅应对具体情境，例如在餐厅用餐时，只要与服务员、菜单和食物相连的操作足够，就能在“餐厅”这一背景中自如。

在塞尔那里，理解语句字面意义要求一种前意向背景，字面意义不是去语境化的概念。[^(\[42\])](#chapter003.html#m42)只有在给定背景下才能确定句子的真值条件。举例：

主席召开了（opened）会议

炮兵开了（opened）火

比尔开了（opened）一家餐馆

三句里 opened 语义内容相同，但正确打开方式依赖塞尔所说的“前意向背景”，比如“炮兵开了火”在语法上是完美句子。[^(\[43\])](#chapter003.html#m43)我们能懂每个成分，却对整句理解毫无头绪。语法的拼接不给出意义，需要背景提供额外信息，背景差异造成对词句的不同理解。若没有背景参与，无论是“深层背景”还是“局部背景”，语言把握都只能停在孤立语义上。塞尔把人的身体技能也算入背景，但又坚持背景具有根本的心理属性，由心理现象构成。世界里堆满自然物与人工制品，我们作为生物与社会存在生活其中，塞尔拒绝把存在物间的关系纳入背景，而是心理化。背景不是物之集合，也不是人与物间神秘关系的集合。[^(\[44\])](#chapter003.html#m44)总之，塞尔描述的背景不是实在，而是指为意向状态提供满足条件的东西，本身无法被意向表征，像黑洞可猜不可见；比喻更直白：正如我们能看到眼前一切，却唯独看不到自己的眼球。

对照德雷福斯与塞尔，背景有三个共识特征：①模糊，难以清晰表征；②本身不是一种实在，而是“我们对实在的表象之特征，不是表象的实在特征”；[^(\[45\])](#chapter003.html#m45)③是理解与认知活动的启动条件，必不可少。本文的立场是，背景或许由实践、技能、习惯等构成，但很大程度上并非心理的。若像塞尔那样作心理主义解释，背景必然带上主观主义烙印，个人可凭心理内容随意塑造背景，背景便会丧失客观意义。背景虽属“我”，也具客观性。技能、实践、习惯这些要素看似主体化，行动时却鲜少被关注，它们在背景中固定下来，成为无意识运用的工具。比如学开车，教练会给出明确指令：“膝盖微屈”“前脚掌踩离合”“轻打方向”。每条指令都基于清晰表征与规则。练熟后不再僵硬遵循表征，而是“就是在开车”。塞尔认为此时规则被剥离，像儿童甩掉学步车。但我们认为规则并非无关，而是内化到背景中，甚至可以说规则本身就是背景。熟练司机与新手的区别，在于能否流畅、无意识地遵循规则。我们仍按规则行事，只是在无数次实践后规则被“遗忘”，变成身体的下意识本能。

海德格尔的存在论现象学指出，最切近“此在”的不是自然环境，而是周遭世界，是日常的实践世界。自然环境只有与“此在”相关后才进入“周围世界”范畴。海德格尔正是此义上使用“世界”。“此在”与世内存在者的相遇方式不在知觉认识或静观反思，而在日常打交道的上手活动，这种最切近的打交道不是觉知，而是与事物建立实践关联，即“此在”沉浸操作用具的“操劳”活动。操劳活动构成其周围世界，在用具整体指引下与我们照面。操劳的结果不是单一物件，而是一个由实践目的串联起的用具关联系统。[^(\[46\])](#chapter003.html#m46)用具与被用具制造之物都有可用性，能通达其他用具。我们正是在这种用具整体关联中看到世界现象，于操劳中与世界相遇。世界像无数用具相关系统构成的整体联结，我们对用具的理解先于对世界的理解，透过用具间的相属关系逐步显现更大的整体。虽然事物以整体呈现，不像胡塞尔的感觉综合，但世界是在事物自身的指向中被发现的，背景本身带有整体主义设定。背景是模糊的，不易被表征，但切近的世界不是如此，它是前理论的、实践性的。在世存在须越过操劳中上手的东西，才能推进到对现成在手之物的分析。[^(\[47\])](#chapter003.html#m47)也就是说，理论认知活动以“此在”在操劳中与上手事物打交道为基础。上手性操劳受阻或被切断，世界才展现在心智面前。这说明世界具有被表征的可能性，能成为意向对象，相较之下，背景是使意向状态成为可能的东西，没有背景就没有意向状态。它不处在意向性外围，而是渗透整张意向网络，缺乏它状态便无法运作。[^(\[48\])](#chapter003.html#m48)因此背景不具备被心智表征的可能性，这正是世界与背景的显著分野。

## 二 “世界”与认知视域下的环境

认知科学内部对环境有不同描述，不能一概而论。首先，颅内主义把大脑当作全部认知系统，于是大脑之外包括身体都可划入环境，我们称之为“环境 1”。问题在于，大脑作为生物学基础不等于认知主体内容，颅内主义混淆了认知意义上的环境与认知目标、主体与大脑。其次，为克服颅内主义缺陷，具身认知强调身体主体性与体验，认知系统被理解为包含身体的人，大脑加身体，身体之外属于“环境 2”。具身认知突破了颅内主义，但仍未区分认知环境与认知目标，对自身缺陷的克服不彻底。再次，延展认知在具身基础上把推理决策时使用的工具如语言、纸笔、计算机纳入认知系统，更强调主体离散特征。延展认知可看作具身的激进版，它所指环境是人及所用工具之外的境遇，我们称之为“环境 3”。认知系统扩展为大脑—身体—工具，但环境与认知对象、目标的关系仍模糊，后者未从前者剥离。根本原因在于主客二分的固有惯例，认知活动中主体与客体对立，对象与目标因异于主体被划入客体。最后，从认知系统观出发，在延展认知上再进一步，主张把认知的对象与目标纳入认知系统，于是认知系统成为人、工具、对象与目标构成的有机构成，大脑加身体加工具加目标，除此之外即为环境，我们称之为“环境 4”。经验与日常都强烈感受到环境对认知的影响，关键在于合乎逻辑地说明环境如何参与认知过程。

海德格尔的“世界”与认知科学重视的“环境”有相当差别，后者具空间广延性，环境像巨大容器，心智存在于其中。这是人们熟知的观念，也被物理学强化。海德格尔视其为一种现成理解方式，基于日常经验描述。对他而言，作为事物存在方式，“世界”的物理空间意义退后了，初始照面的是近在手边的上手之物。物理距离远近淡出考虑，器具与生存活动有亲缘关系，像“海内存知己，天涯若比邻”般存在论上切近。“世界”通过上手器具的相关性展开。[^(\[49\])](#chapter003.html#m49)世界总是上手的、贴近“此在”生存活动，具有上手状态这一特征，不能被远化为与生存无关的单纯认识对象。“此在”之所以有世界，原因在于它通过栖居构造周遭世界，世界对“此在”是一种被表象的有用之物，是“在-世界-中-存在”的环节。世界不是静观理论态度下的对象，而是通过自身活动组织而成，因认知与实践的分殊而具内在心智世界与外在周围世界两个维度。对海德格尔而言，世界本身不是存在者，而是从实践交互角度建构起来的指引网络，因通常不触目而无法被清晰巡视与关切。

从相关性看，海德格尔的“世界”与认知科学“环境”似乎有共同点，都反对方人世界彼此绝缘。具体说，认知研究强调环境在主体认知中的相关性，强调环境对延伸至大脑与皮肤之外的认知过程的承载与外包，比如嵌入认知主张，认知过程在很大程度上依赖有机体外部器具以及认知发生的外在环境结构。[^(\[50\])](#chapter003.html#m50)对新的具身—延展模型而言，基于感知的在线认知加工往往嵌入身体之外的环境背景，物理、社会/文化环境中的非神经资源被纳入延展的认知行为、倾向与活动，并可能在功能层面整合进更广的认知系统。环境不只是被放置等待认知的物集合，除反馈机制外，新模型主张它能产生更积极主动的影响，以克服心智认知计算模型的弊病，即把注意力集中于亚主体层次的神经编码与计算表征，从而建构超越认知主义的更大框架。外在环境因素能影响大脑皮层回路与网络的神经过程，因皮层是身体一部分，身体处于更大的物理/技术/社会环境中。认知加工可“卸载”到其中，也可内化于自身计算网络。从中可见，对认知科学而言空间性居于核心，而海德格尔哲学中对空间性的颠覆性理解并未获足够关注。

总之，对海德格尔来说，世界不是现成空间的无限延续，他反对笛卡尔把空间数学化，反对把客观坐标系加于世界以确定空间位置。“此在”从根本上把与对象的空间关系理解为远近关系，且这种远近在与“此在”实际目的的关系中被理解。[^(\[51\])](#chapter003.html#m51)事物总是以上手或不上手的面貌呈现，世界可能就是这些事物组成的相互关联整体，其根本意义是置于与“此在”的存在关系。某种程度上，海德格尔在实践意义范围内谈“世界”，世界是一个日常实践世界，事物之于“此在”的远近源于一般实践中的熟悉感。相较而言，认知科学视域下的“环境”仍在现成存在的意义上被谈论，未脱离康德甚至笛卡尔的空间范畴。

## 第三节 在世存在：使认知得以可能

若说海德格尔的存在论哲学为认知科学留下最重要的思想遗产，首先应是“在世存在”概念。[^(\[52\])](#chapter003.html#m52)它直观呈现主体与世界的相关性问题以及主体如何在世界中存在，因而不是一个简单概念，而是包含诸多可讨论内容。

在海德格尔视域中，“在世存在”作为“此在”的存在结构，不是人作为有形存在者在空间上被世界包容的状态。它不指人的血肉之躯在空间容器里现成可见的状态。[^(\[52\])](#chapter003.html#m52)由此可见，海德格尔在存在方式上刻意排除身体成分，同时拒绝把人视为笛卡尔式的心灵实体或胡塞尔主张的“纯粹意识”“先验主体”。海德格尔对身体问题的避让为梅洛-庞蒂的身体现象学留出空间，这也是梅洛-庞蒂的“在世存在”与海德格尔貌合神离的原因。此外杜威也表达过类似思想，[^(\[53\])](#chapter003.html#m53)但海德格尔与梅洛-庞蒂各自所指仍有明显差别。

### 一 “在世存在”与“身体朝向世界存在”

海德格尔“在世存在”的目标直指笛卡尔的“我思故我在”，他认为笛卡尔先设定我思者是荒谬的，未考量“我”的存在样式就孤立设定自我与思维主体是本末倒置。他说，“经过辨析可见，笛卡尔的‘我思故我在’意图恰在界定‘我思’与‘我思者’，却遗漏了‘我在’。与此相对，我们的考察首先将‘我思者’及其界定悬置，转而争取‘我在’及其界定”。[^(\[54\])](#chapter003.html#m54)那么“我”如何在此？海德格尔回答“在-世界-中-存在”，这是关于“此在”统一而原初的规定，是其根本枢机，作为其本身而整个在此，不由可分离要素构成。字面上“在世存在”表示“某物处在某物之中”，人似乎作为存在者居于另一个存在者之中。然而海德格尔指出，“在世存在”不是空间上一物被包容于另一物，即两种具广延的存在者的空间位置关系。[^(\[55\])](#chapter003.html#m55)空间位置关联只是“此在”存在的外观样式，更为基本的是，“在世存在”表达“此在”与世界之间更为基本的因缘关系，即“此在”总是依据与它打交道的事物来理解自身与世界。
