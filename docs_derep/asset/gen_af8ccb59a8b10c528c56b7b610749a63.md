# Manus 从聊天到干活的工具全景

Manus 能跑起来，靠的是下面这套工具组合。

**Shell 工具**
- shell_wait：阻塞等待某个 shell 会话里的进程返回结果。
- shell_write_to_process：把输入内容写进正在运行的 shell 进程。
- shell_kill_process：主动终止指定的 shell 进程。

**4. 浏览器工具**
- browser_view：读取当前浏览器页面的可见内容。
- browser_navigate：让浏览器打开指定的网址。
- browser_restart：重启浏览器并直接跳到指定网址。
- browser_click：在当前页面上执行点击操作。
- browser_input：在页面的可编辑区域填入文本。
- browser_move_mouse：把鼠标光标移动到指定坐标。
- browser_press_key：模拟在页面上按下某个按键。
- browser_select_option：在下拉菜单里挑选指定选项。
- browser_scroll_up：把页面向上滚动。
- browser_scroll_down：把页面向下滚动。
- browser_console_exec：在浏览器控制台运行 JavaScript 代码。
- browser_console_view：查看控制台的输出信息。

**5. 信息搜索工具**
- info_search_web：借助搜索引擎在互联网上检索资料。

**6. 部署工具**
- deploy_expose_port：把本地端口临时暴露给公网访问。
- deploy_apply_deployment：把网站或应用发布到公开生产环境。
- make_manus_page：基于本地 MDX 文件生成 Manus Page。

**7. 状态管理工具**
- idle：切换到空闲状态，表示当前任务已结束。

把这些能力拼在一起，Manus 就不再是只会聊天的模型，而是能真正动手操作的数字员工。好比一个人长出 29 双不同的手，能去点各种数字界面和系统。

换个说法，像厨师的工具柜，从刀具到锅碗瓢盆，每件都有专属用途，单件看起来简单，组合起来才能做出复杂菜品。Manus 的工具也是这个逻辑，单独使用很基础，协同使用就能完成多步骤任务。

我觉得这里体现了一个关键洞察：AI 不只要知识，还要一套清晰的思考框架。人类教育不仅传授事实，也传授方法论。

### 从系统提示词看 AI Agent 的设计哲学

归纳起来有五个方向。

1. 工具驱动的能力扩展：提供外部交互工具，让 AI 的作用范围远超对话。
2. 迭代循环的执行模式：观察—思考—行动—反馈的闭环，让复杂多步任务可以落地。
3. 边界清晰的能力定义：明确能做什么、不能做什么，减少越界风险。
4. 自主性与用户交互的平衡：高度自主时仍在关键决策点征求用户，保持效率与可控。
5. 多模态交互：通过多种工具与外部世界和用户沟通，提升适应性和解决问题的能力。

这些理念标志着 AI 从“只会说话的大脑”向“有手有脚的数字人”转变，能实际操作、观察并学习。

### 安全启示：AI 也需要安全教育

Manus 泄露事件给 AI 安全提了醒，暴露的问题包括：

1. 沙盒环境是否可靠：配置不当仍可能触达敏感文件或执行危险操作。
2. 路径穿越防护：文件路径必须严格校验，防止通过特殊路径越权访问。
3. 最小权限原则：只授予完成任务所需的最小权限，而非系统级权限。
4. 输入验证的重要性：用户输入不可信，需要严格校验过滤。
5. 敏感信息保护：系统提示词、配置文件等要重点防护，防止外泄。

> “最强大的锁也挡不住错误的权限设置”——一位网络安全专家的名言

讽刺的是，这么先进的系统，却倒在了最基础的安全环节。就像装了顶级防盗系统的豪宅，因为主人忘了关门而被入侵。

### 展望：AI Agent 的进化之路

从 Manus 的设计能看到几个趋势：

1. 更强的自主性：处理更模糊、开放的指令。
2. 更丰富的工具集成：接入更多专业软件和服务。
3. 更智能的安全机制：内置风险识别并主动拒绝高危请求。
4. 更自然的交互方式：协作体验更接近人与人。
5. 更个性化的适应能力：随用户习惯和偏好调整工作方式。

Manus 已经展示了 Agent 的潜力，未来它有望在更多领域成为得力助手。

### 既是警示，也是启示

系统提示词泄露像魔术师不小心露了手法，揭开了“魔法”背后的机制，却不削弱技术本身。它提醒我们在打造强能力的同时，不要忽视基础安全；在赋予能力的同时设定边界与原则。

对人类也有启发：数字时代，善用工具、保持观察—思考—行动—反馈的循环，是提升效能的关键。

## 4.2 Manus基础使用技巧

1. 一个对话框尽量只做一件事。保持聚焦能避免指令混淆，提升执行效率。
2. 任务进行中可随时插入新要求或调整方向，Manus 能自然把新指令融入当前流程。
3. 描述越清晰，结果越好。指令质量直接决定产出质量。

## 4.3 运行卡壳怎么办

### 【继续】指令的妙用

执行卡住或出现小错但不致命时，别急着重开，输入【继续】。这相当于告诉模型“没关系，往下走”，它会尝试恢复并完成任务。

比如数据分析已完成清洗和初步分析，生成图表时卡住，输入【继续】后它可能换方法绘图或跳过该步继续后续。

这在任务次数受限时尤其重要，避免浪费已消耗的时长和次数。

### 上下文长度限制的应对策略

【继续】并非万能。达到最大上下文长度时，模型无法继续，因为短期记忆已满。

可用的解法：
1. 任务拆分：把大任务拆成小任务，分别在新对话完成。
2. 简化指令：去掉冗余背景，保留核心。
3. 结果导出：及时保存已有有价值产出。
4. 总结再继续：先让模型总结已完成工作，再在新对话基于总结续做。

例如：
“请总结已分析的结果并保存到文件。”
新对话：
“基于上次分析结果（文件链接），请继续完成剩余数据的分析。”

### 断点续传与错误排查

复杂任务中断不必从头来：
1. 检查中间文件，了解执行进度。
2. 定位错误原因，阅读错误日志。
3. 手动修正问题文件或参数。
4. 指定继续点，例如“请从数据可视化步骤继续，使用我修改后的数据表。”

### 实时回放系统

打开分享链接可以看到完整回放：
1. 思考路径可视化：展示每步推理和决策依据。
2. 操作步骤回放：按时间顺序重现代码运行、文件处理等。
3. 时间轴导航：快速跳转到特定阶段。
4. 暂停与放大：在关键节点细看细节。

### 文件管理与收藏功能

任务完成后可通过右上角文件按钮一键查看下载所有生成物；用收藏功能标记重要任务，方便在个人中心检索；可对收藏任务分类，构建个人知识库。

提示：对有价值的流程及时分享并收藏，即使免费额度用完也能回顾执行思路。

## 4.5 知识功能的有效运用

知识功能容易被忽略，却能让助手更个性化高效。它允许你预设特定知识，相关情境出现时自动调用，无需重复解释。

点左下角“知识”按钮打开面板，可管理所有条目（图4-5-2）。
[PRE10]

每条知识包含名称、触发条件、具体内容三部分。名称便于识别，触发条件决定何时调用，内容是需要记住的信息（图4-6）。
[PRE11]

创建技巧：
- 取具体描述性名称，便于管理。
- 触发条件要清晰。如经常按公司格式写月报，可设触发条件为“当讨论到月度报告”，内容里写明格式、章节、风格要求（图4-7）。
[PRE12]

实用场景：
- 个人偏好：告诉模型你喜欢的回答风格、排版和分析深度。
- 专业领域：预置行业术语、常见问题解法、标准流程，对话更顺畅。

建议从核心知识点开始，逐步扩充优化，避免触发条件过宽或过窄。

## 4.6 提问技巧

Manus 能理解模糊指令，但精准提问仍能节省时间与资源。

### 为什么提问技巧很重要

Agent 任务耗时长且每天次数有限，精准提问可：
- 缩短执行时间；
- 提升准确性和相关性；
- 避免重复修改；
- 最大化使用次数。
