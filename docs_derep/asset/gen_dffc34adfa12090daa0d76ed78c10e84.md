#### 3.2.3 DeepSeek-R1模型参数详解

通过 API 调用 DeepSeek-R1 时，可以对文本长度、生成多样性、逻辑严谨度等输出特性进行灵活调节。chat.completions.create（）接口的核心参数已做说明，DeepSeek-R1 与 DeepSeek-V3 共用同一套接口。

另外，R1 在参数解析与推理机制上存在部分特有行为，调用时需特别留意。

##### 1. max_tokens参数
- （1）max_tokens 仅限制最终答案部分，即 content 字段的最大 Token 数。默认值 4096 token，约合 3000 个汉字，上限为 8192 token。
- （2）该上限不计入思维链内容 reasoning_content 字段。在复杂任务中，reasoning_content 单独可达 32K token，因此整段输出可能远超 max_tokens 的设定值。官方计划后续上线 reasoning_effort 参数来控制推理深度与长度。

##### 2. reasoning_content字段
- （1）DeepSeek-R1 的差异化设计在于，除常规回答 content 外，还会额外返回同级的 reasoning_content，即模型的思考过程。
- （2）该字段记录了模型推导思路与结论形成的轨迹，适合用于解释类任务、教学演示或结果评估。

##### 3. 功能支持情况
- （1）目前已开放对话补全标准 Chat Completion，以及对话前缀续写 Beta 功能，可用于已有内容的接续生成。
- （2）Function Calling、JSON 格式输出、FIM Fill-in-the-Middle 补全 Beta 等功能暂未开放，相关参数设置无效。

##### 4. 不生效的参数
参数 temperature、top_p、presence_penalty、frequency_penalty、logprobs、top_logprobs 在调用 deepseek-reasoner 模型时会被静默忽略。为保持对 OpenAI 接口的兼容，设置这些参数不会报错。

DeepSeek-R1的思维链在多轮对话中呈现出清晰的阶段性演化规律。

- （1）第一轮对话通常体现为独立推理，模型基于用户的初始提问进行结构完整、逻辑自治的思考。

- （2）进入第二轮时，模型开始进行递进式推理，能够引用前文内容（前文的问答对）并进行自然衔接，展现出良好的承接性。

- （3）到第三轮及更复杂的轮次，模型则逐步发展为综合性推理，整合多轮信息与多个变量，输出具有清晰逻辑排序的推理链条。随着对话的深入，DeepSeek-R1不仅展现了强大的单轮分析能力，更体现出对上下文的记忆保持、逻辑递进与归纳整合能力，具备类人类的“思维连续性”与“对话一致性”。这使得它不仅适用于一次性问答，还能胜任复杂交互场景。
