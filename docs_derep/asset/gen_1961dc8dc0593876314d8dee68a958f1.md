### 5.2 基于 DeepSeek-V3 构建企业知识问答实战

企业数据量持续攀升，传统关键词检索已难以满足复杂查询需求。依托 GraphRAG 与 DeepSeek-V3 组合的问答体系，能够理解上下文、推演关联，并结合实体与图谱给出更精准高效的答案。本节以项目实操形式，深入介绍如何使用 DeepSeek-V3 实现企业知识库问答。

#### 5.2.1 DeepSeek-V3 与 GraphRAG 概述

##### 1. DeepSeek-V3：国产开源大模型代表

DeepSeek-V3 是中国人工智能公司深度求索于 2024 年 12 月 26 日发布的开源大语言模型。采用 MoE 架构，总参数 6710 亿，单次推理激活 370 亿参数，基于 14.8 万亿 token 预训练。在多项基准测试中表现优异，代码与数学任务尤其突出，性能超越多数开源模型，与领先闭源模型相当。

##### 2. GraphRAG：面向知识库问答的检索增强方案

RAG 通过融合真实世界信息提升大语言模型输出质量，是 LLM 工具的重要组成。大多数 RAG 方法使用向量相似度检索，被称为基线 RAG。

RAG 在帮助 LLM 推理私有数据方面潜力巨大，如企业专有研究、业务文档或通信数据。但基线 RAG 在需要整合多片段信息并提炼新见解，或处理大量复杂数据做总结理解时，往往难以把握整体语义。

为解决这些问题，技术社区不断改进 RAG。微软研究院提出的 GraphRAG，利用 LLM 从输入文本构建知识图谱，并结合社区总结与图机器学习结果增强查询提示。GraphRAG 在复杂信息推理上改进显著，尤其在智能性上超越基线 RAG，适用于私有数据集分析。

> ### 说明
值得注意的是，GraphRAG 生成的知识图谱结构具有一定不确定性和动态性。不同大语言模型处理同一文档时，可能识别出不同实体节点或语义关系。即使同一模型在不同运行批次中，也可能因上下文边界切分、token 数量微调等因素生成略有差异的图谱结构。
GraphRAG 索引流程包含“社区总结生成”“节点描述生成”等 LLM 参与的生成性步骤，默认配置下为非确定性执行。因此，两个完全相同的数据源在不同时间点执行 graphrag index，也可能输出不同数量节点、不同权重关系，乃至不同社区划分粒度。
若对一致性有强依赖，如自动评测或持续集成场景，建议固定 temperature 以设定确定性参数，并保存图谱快照以便复用。
