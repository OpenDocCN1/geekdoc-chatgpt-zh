# LLM智能体工程落地全书

## 内容简介

本书以大型语言模型驱动的智能体为核心，系统呈现从模型接入、知识补强、参数优化到智能体架构搭建与商业化落地的完整实践路径。全书共分八篇，覆盖主流模型的在线调用与本地化运行、基于向量检索与图谱的检索增强生成构建、多轮交互与复杂任务编排等核心能力，以及高效微调的端到端流程。特别拆解了 LangChain 与 LangGraph 两大主流智能体框架的设计原理与使用范式。

案例篇甄选了贴近真实业务的工程范例，包含依托 GraphRAG 的本地知识问答、医疗垂域的高效微调、以及 BiliAgent——B站舆情分析智能体等。每个案例都深入讲解模型接入、知识增强、任务拆解、前后端联调等关键环节，既体现了智能体在不同行业的落地可能性，也提供了可直接复用、便于扩展的开发蓝本。

本书既可作为 LLM 应用开发者的实操参考，也适合高校人工智能、计算机相关专业的教学实践与毕业设计，同时对 AI 研发工程师、产品经理、IT 培训讲师等群体具有专业指导价值。

## 前言

随着大语言模型技术的快速演进，人工智能正从被动问答工具迈向以智能体为中心的自主系统。模型能力已从单轮应答拓展为具备感知、推理、决策与执行的闭环。智能体成为解决复杂业务、实现人机协作的关键手段，在客服、数据分析、代码辅助、智能检索等场景广泛应用。

本书从模型部署与调用切入，逐步展开智能体构建与应用全景。先介绍大模型的本地化部署与在线 API 接入，再详解检索增强生成的工程实现，并梳理当前主流的高效微调策略以提升表现。随后聚焦 LangChain、LangGraph 等生态成熟的智能体开发框架，说明如何以模块化方式搭建具备任务规划、工具调用与状态管理的智能体工作流。最后以 DeepSeek 系列模型为技术底座，结合企业级案例完整呈现大模型智能体的全流程。

全书每章均配有结构清晰、可运行的代码示例，读者可在本地复现并在此基础上扩展。通过学习，读者能够理解大模型智能体的核心机制，掌握搭建、优化、部署智能体系统的完整能力，并迁移到更广泛的实际任务中。

### 1.1 智能体发展历程

本节从人工智能的起源出发，回顾智能体的发展轨迹。先介绍智能体的定义，说明其如何从规则驱动的系统演化为具备自主决策与任务执行的智能体。再讲解智能体的构建思路，从 API 调用到基于大语言模型的智能体实现。最后通过现实世界的典型应用，展示智能体在现代企业中的价值创造与行业推动作用。

#### 1.1.1 从人工智能到现代智能体

1955 年，约翰·麦卡锡等人首次提出人工智能概念，标志着该领域正式起步。1956 年达特茅斯会议将 AI 定义为“让机器执行原本需人类智能的任务”。早期研究依赖符号主义与规则推理，通过人工知识库与逻辑规则解决数学推理、棋类等结构化问题。同期图灵提出的图灵测试，成为衡量机器智能的重要标准。

1969 至 1986 年，研究重心转向专家系统。专家系统借助规则库与推理引擎模拟专家决策，被应用于医疗、金融等领域，但受限于人工规则编写，难以处理不确定与模糊信息。

2000 年后，计算能力提升与数据积累推动深度学习快速发展。大规模数据与 GPU 等算力资源为深度学习突破提供支撑。

2017 年，论文《Attention Is All You Need》提出 Transformer 架构，成为现代大语言模型的基础。Transformer 凭借自注意力机制有效处理长序列数据，成为 NLP 的革命性进展。基于此，OpenAI 推出 GPT 系列，从 GPT-1 到 GPT-3 模型规模与能力持续提升。

2020 年，GPT-3 以 1750 亿参数发布，可完成文本生成、翻译、问答等多任务，引发学界与业界关注。2022 年底，OpenAI 推出 ChatGPT，将大模型带入大众视野，AI 从科研概念转变为日常可用的工具。

尽管 LLM 在生成与理解上表现突出，仍存在明显局限：

- 缺乏自主决策能力：LLM 输出完全依赖用户提示或上下文，无法主动发起任务或在动态环境中自主决策。
- 缺乏长期记忆与完整任务执行能力：LLM 多处理单步任务，缺乏持久记忆，难以衔接多步骤完成复杂任务。

近两年，随着基础 LLM 性能迭代，AI 逐步走向基于大模型的智能体体系。通过融合强化学习、规划、知识检索、多模态等技术，智能体正发展为能够自主决策、环境适应并执行复杂任务的系统。

#### 1.1.2 智能体演进路径

##### 1. 初期阶段：简单 API 调用与规则驱动系统

AI 早期系统通过编写规则与调用简单 API 执行特定任务，被称为智能体。约 2000 年后，智能体概念逐渐丰富。如 1997 年 IBM“深蓝”击败人类国际象棋世界冠军；2000 年 Cynthia Breazeal 发布可模拟人类表情的机器人 Kismet；2011 年 IBM Watson 在 Jeopardy! 中胜出，同年苹果发布 Siri，成为全球首个流行虚拟助手。

根据感知程度，罗素、诺维格等人将其分为五类：

- 简单反射智能体：仅依据当前感知选择动作，忽略历史信息。如温控空调，根据实时温度开关制冷。
- 基于模型的反射型智能体：在简单反射基础上结合环境模型，追踪状态并做出更合理反应。如带室内导航的扫地机器人，借助内部地图与历史运动经验规避障碍。
- 基于目标的智能体：结合目标信息，通过搜索与规划实现主动性。如导航应用为用户规划最优路线。
- 基于效用的智能体：引入效用函数衡量性能，选择效用最大化动作。如智能路线助手综合时间、路况、收费等指标选路。
- 学习型智能体：具备从经验中学习并优化行为的能力，通常包含学习元素、评估者、性能元素与问题生成器，可在上述各类智能体基础上提升性能。

##### 2. LLM 的引入：从 ChatGPT 到初步的智能体

大语言模型的快速发展显著提升了系统的语言理解与生成能力，可处理文本生成、翻译、对话等通用任务，为智能体发展奠定基础。但此时响应仍偏被动，缺乏自主决策与任务执行能力。

##### 3. AutoGPT 的出现：迈向自主执行的智能体

AutoGPT 的开源发布成为重要里程碑。它在 LLM 之上实现多轮推理与任务分解，可从目标设定到任务执行全流程自主运行，被视为实现自主 AI 智能体的关键一步。

##### 4. BabyAGI 的提出：通过自主学习向人工智能迈进

随后，学习型智能体思想被进一步融合。BabyAGI 模仿人类婴儿的学习与任务执行方式，具备自我学习与任务管理能力，可自动生成任务清单并根据完成情况动态调整优化，为智能体发展提供了新思路。

#### 1.1.3 智能体的应用

近年，智能体应用加速落地，从客服助手、代码生成工具到金融分析助手，成熟案例大量涌现，企业借此实现降本增效与创新。此处聚焦主流领域实践，分析智能体在企业场景中的价值体现。

##### 1. 智能客服领域的智能体

在客户服务场景中，智能体已广泛部署，典型代表为智能客服机器人。借助自然语言处理与语音识别技术，它可模拟人工客服解答用户问题，大幅提升服务效率与满意度，并实现多渠道 7×24 小时在线响应，缓解人工压力。例如阿里云智能对话机器人、百度基于“文心一言”与 UNIT 对话平台的端到端智能客服解决方案。
