让 LangChain Agent 既会调工具也能保留上下文

想把大模型的泛化能力扩展到检索和计算，并且让连续提问时能记住前文，LangChain 的 Agent 流水线是比较直接的做法。下面通过一个最小可用示例，展示模型初始化、工具加载、加入对话历史后的表现差异，以及去掉历史记录后会出现的指代失效问题。

先把语言模型和运行环境准备好。把 OpenAI 的密钥以及 SERPAPI 的密钥填入环境，实例化一个温度为 0 的 ChatOpenAI，并导入所需的链式组件。
