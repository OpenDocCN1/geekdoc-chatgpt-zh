def _on_sobel_sharpen(self):

            gray = self._pil_to_cv_gray(self.original_image)

            # Sobel gradients

            gx = cv2.Sobel(gray, cv2.CV_16S, 1, 0, ksize=3)

            gy = cv2.Sobel(gray, cv2.CV_16S, 0, 1, ksize=3)

            abs_gx = cv2.convertScaleAbs(gx)

            abs_gy = cv2.convertScaleAbs(gy)

            edge = cv2.addWeighted(abs_gx, 0.5, abs_gy, 0.5, 0)

            # Sharpen by blending original with edge map

            sharpen = cv2.addWeighted(gray, 1.0, edge, 0.7, 0)

            result = self._cv_to_pil_gray(sharpen)

            self.original_image = result

            self._display_image_to_fit()

**7.4.1**

**桌面应用系统的发布与部署**

对于基于 Python 的桌面应用而言，发行形式多以可执行程序如 .exe 为主，以简化用户环境配置并实现开箱即用。可采用 PyInstaller 等成熟打包工具，将依赖库、模型文件及程序逻辑统一封装，使应用在无 Python 运行环境的目标机上仍能稳定执行。打包过程涉及依赖收集、环境隔离、图标设定与执行权限配置等工程细节，需要遵循可靠性与可维护性要求。

CodeBuddy 可通过自动化脚本生成与环境配置提示降低发布难度，开发者仅需构造适当提示词，即可由大语言模型完成 PyInstaller 命令构建、配置文件撰写和路径校验逻辑生成。此外，系统部署需考虑模型权重体积、GPU 依赖、权限受控路径等实际问题，因此发布阶段建议采用相对路径管理资源目录，并加入发布前检查机制，防止核心文件缺失导致系统无法运行。

桌面应用系统的发布通常涉及以下步骤。

（1）代码整理与发布前测试。

（2）分发资源与第三方库确认。

（3）使用 PyInstaller 生成可执行文件。

（4）单文件打包或目录结构发布选择。

（5）在目标设备完成兼容性测试与用户验收。
