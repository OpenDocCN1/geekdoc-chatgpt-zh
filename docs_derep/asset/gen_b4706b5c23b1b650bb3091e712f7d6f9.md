2. 团队用：发布到飞书，拉个群，团队所有人都可以@它帮忙写东西。
团队场景里最顺手的打法是把智能体放到飞书工作区，建一个群聊进去后，成员随时 @ 它就能要文案、要总结、要润色。协作成本几乎为零，需求来了直接对话。

3. 对外服务：发布到扣子商店，或者通过 API 接入你自己的网站，让客户付费使用（比如代写文案服务）。
想面向外部收费的话，常用的两条路是一键上架扣子商店，或者把 API 接到自家网站后台。客户在你的站点里调用，相当于卖一份代写文案、客服问答等增值服务。

对于个人创作者，最简单的是发布到豆包。这样你手机上就有了一个24小时在线的“内容工厂”。
单人作战的话最省事的方案是直推到豆包，安装后手机里就常驻了一个不下班的内容生产线，随时开写。

#### 九、注意：版权与原创性问题
AI 生成的文字和画面，到底算谁的？国内法规目前还没有盖棺定论的说法，实践中普遍的理解是，只要没有直接照搬别人的作品，就能被使用人当作自有成果。但使用时仍要留心三点：
1. 智能体学习你上传的爆款模版属于正常复现，因为素材来源是你自己，无所谓问题。
2. 文生图插件偶尔会把他人的商标 Logo、知名人物形象放进画面，这种情况很可能踩侵权红线，上线前务必人工复核。
3. 如果是商业投放，建议在 AI 初稿基础上做二次加工，提升独创度，降低风险。

### 7.4 变现阶段：将智能体封装为付费服务或小程序，赚取被动收入
前几节我们练习的是把扣子智能体当工具自用，用来当客服、写文案、做配图，核心是省时增效。但你搭建好的这个智能体本身就能成为产品卖钱。
本节讲怎么把自用工具包装成收费产品。无需写代码、不用租服务器，把已有的智能体做个外层封装，让别人付费调用即可。一次搭建，持续售卖，这就是被动收入的逻辑。

#### 方式一：在扣子商店发布收费智能体
这是最直接的变现通道。扣子官方支持创作者把智能体上架商店并开启付费。

**第一步：检查你的智能体是否达标。**
并非所有智能体都能赚钱，上架需要满足基本门槛。
1. 功能完整：能稳定解决一类明确问题，比如小红书文案生成、法律初筛、英语陪练等。
2. 体验顺滑：响应快、答案质量稳，不频繁出错。
3. 有差异点：对比市场上同类产品，你的版本更懂细分人群、价格更优或功能更全。

**第二步：设置收费模式。**
进入发布页选择“发布到扣子商店”后，在定价区可选择：
1. 按次计费：每次对话扣费，适合轻度用户。
2. 包月/包年：周期订阅，适合重度用户。
3. 试用后付费：前几次免费体验，之后解锁收费。
定价可参考同类目。商店里包月常见区间是 9.9 元到 99 元，新品可先低价攒口碑，后续再提价。

**第三步：填写介绍和标签。**
用户第一眼看到的是名字、头像、一句话简介和标签，必须写清楚价值：
1. 名称要直观，例如“全能文案助手”“AI 法律顾问”。
2. 一句话简介说明能做什么，例如“帮你写小红书、抖音、公众号文案并自动配图”。
3. 标签选准关键词如“写作”“营销”“设计”，便于被搜索到。

**第四步：提交审核。**
扣子会对内容合规性和功能可用性做审核，通常 1—3 天出结果。通过后即可正式售卖。

**第五步：推广你的智能体。**
上架只是开始，需要分发。把链接发到朋友圈、社群、小红书、抖音，或写一篇使用测评稿。流量越大，收入越稳。

#### 方式二：封装成微信小程序或H5页面
不想分给平台，或想自己掌控用户和数据，可以把智能体做成自己的小程序/H5，收款全部归自己。

**第一步：获取智能体的API接口。**
在扣子后台进入发布→API，按指引创建密钥，会得到一个调用地址和密钥，这就是智能体的网络入口。

**第二步：找一个小程序开发工具。**
无需手写代码，可用低代码平台如微信小程序开发工具、即速应用、上线了等，用拖拽模板快速搭出聊天界面。

**第三步：把智能体接入小程序。**
在开发工具里找到数据接口配置，填入扣子的 API 地址和密钥，再调一下界面样式、头像、欢迎语即可完成接入。出问题时花几百元找个兼职技术把接口连上也很快。

**第四步：发布小程序。**
完成制作后提交微信审核，审核通过就上线。可命名为“AI 写作神器”“万能文案工坊”等。

**第五步：设置收费。**
常见收费形式：
1. 会员订阅：接入微信支付，设置 19.9 元/月 等会员，付费后解锁使用。
2. 次数包：例如 9.9 元 50 次对话，对接第三方支付插件即可。
3. 广告变现：免费使用但观看广告，体验感较差。
小程序支付一般需要主体资质，个人可先用付费社群模式过渡，群里提供智能体服务。

#### 四个注意事项
1. 版权问题。若售卖的是生成文案服务，用户商用时若出现抄袭，责任归属目前不清晰。建议在用户协议里明确“AI 输出仅供参考，使用者需自行核验，平台不承担法律责任”。
2. 隐私保护。智能体可能接触用户隐私信息，如法律咨询中的敏感内容。扣子有基础隐私机制，协议里仍需告知用户数据如何被处理。
3. 平台规则。扣子商店禁止赌博、色情等内容，微信小程序也有合规要求，上架前务必阅读规则避免封禁。
4. 税务问题。智能体收入属于经营所得，需依法纳税。个人可走平台代扣或自行申报，切勿因金额小而忽略。

做到这一步，你就从 AI 的使用者变成了创作者。扣子提供造物钥匙，如何把它变成持续现金流，取决于你解决问题的能力。

### 一、什么是Seedsnce 2.0？
Seedsnce 2.0 是一款 AI 视频生成工具。输入文字描述，它就输出对应的视频。类似 Midjourney 把文字变图片，它把文字变视频。

“傍晚海边，夕阳把天空染成橙红，海浪轻拍沙滩。穿白裙的小女孩在沙滩奔跑，回头笑得很开心。”

##### 1. 文字理解能力：听懂人话。
基础也关键。Seedsnce 2.0 能解析复杂场景、人物关系和动作逻辑。例如“橘猫趴在窗台，阳光照在身上，懒洋洋打哈欠后闭眼睡着”，它能识别主体、位置、光线、动作序列并逐一呈现。中文输入支持很好，说人话即可。

1. 画质高：支持 1080P 以上，分辨率高、无明显 AI 痕迹。
2. 动作连贯：人物步伐、衣摆飘动、表情变化自然。
3. 光影真实：阴影、反射、色温处理接近实拍。
4. 镜头可控：能做推进、拉远、摇移、环绕等镜头运动，不是固定死帧。
常规时长 5—15 秒，适合短视频素材，需要更长可分段拼接。

除中文外，也支持英文、日文等输入，描述语言会影响风格倾向。

## 8.2 快速上手：用 Seedsnce 2.0 生成第一条创意短视频
上一节看完原理，这一节实操。无需专业设备，只要联网的电脑或手机加一点想象即可。

准备工作：找到入口
目前主要有两种入口：
方式一：官网直用。访问 Seedsnce 官网，注册登录即可，使用界面最全。
方式二：云厂商平台。火山引擎、阿里云等接入了该服务，适合后续做批量或 API 调用。
新手建议直接官网。

#### 第一步：写一段“提示词”
视频质量一半靠模型，一半靠提示词。简易公式：主体 + 场景 + 动作 + 风格 + 镜头。
例如：
主体：一只橘猫
场景：阳光明媚的窗台
动作：伸懒腰、打哈欠、蜷缩睡觉
风格：写实、电影质感
镜头：慢慢推进
组合后：“一只橘猫在阳光明媚的窗台上伸懒腰，打了个哈欠，然后蜷缩着睡觉。写实风格，电影质感，镜头慢慢推进。”
提示词太空会导致画面无聊，动作和场景一定要写具体。可参考爆款视频的画面描述来模仿。

#### 第二步：设置参数
输入框下方通常有这些选项：
- 视频时长：5 秒、10 秒、15 秒可选，新手建议从 5 秒开始。
- 画面比例：16:9 适合 B 站、视频号；9:16 适合抖音、快手、小红书；1:1 适合朋友圈。
- 风格模板：部分平台提供预设如电影感、动漫、水墨等，可直接选。
- 生成数量：1—4 条，建议先单条测试。
- 画质：高清生成快，超清更细但耗时。

#### 第三步：等待生成
点生成后系统开始渲染，几十秒到几分钟不等，页面会显示进度。生成完成后可预览、下载、再生成。熟练后即可批量产出。
