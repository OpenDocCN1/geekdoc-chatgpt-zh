**RLHF 训练的实际走法**

从操作层面看，第一步是攒出一批人类偏好样本。随机抽取一批问题，让标注员给出高质量参考答案，形成“人类表达—任务结果”的标注对，喂给模型去学习。这批样本规模在数万量级，学习方式采用提示词模式，模型本体参数保持不变。

第二步是养一个反馈模型。同样随机挑题，让原始模型先生成答案，再由标注员依据“人类偏好标准”，比如相关度、信息饱满度、是否有害、是否带负面情绪等，对这些答案进行排序。

第三步是把前面标注好的偏好数据用来训练一个打分模型。这个打分器会对原始模型的结果打分，告诉模型哪个输出高分、哪个低分。

于是整个闭环就接起来了。反馈模型和原始模型被强化学习串联起来，原始模型一旦在打分模型里拿低分就会被惩罚并迫使重新学习。如此循环往复，原始模型持续迭代升级，最终学会人类的偏好，变成让人满意的模型，也就是我们看到的 ChatGPT。

**前台：对话即接口**

语言是人类独有的本质特征，也是多种智能的核心载体。人类逻辑思维以语言为形式，绝大部分知识也以文字沉淀和传播。人工智能要真正好用，语言能力几乎是核心。

长期以来，人们一直在追求用自然语言和计算机沟通，既有实用价值，也有理论价值：用习惯的语言操作机器，无需学习复杂的程序语言；也能借此探究人类语言与智能的机制。

实现自然语言通信，计算机既要读懂文本含义，也要能用自然语言表达意图。前者叫自然语言理解，后者叫自然语言生成。自然语言处理基本就由理解和生成两部分组成。历史上理解研究更多，生成相对薄弱，但现在已在改变。

无论是理解还是生成，都远比想象中复杂。从现有理论和技术看，打造通用高质量的自然语言处理系统仍是长期目标。不过面向特定场景、能力相当强的实用系统已经出现并走向商品化、产业化，比如多语种数据库和专家系统的自然语言接口、各类机器翻译、全文信息检索、自动文摘等，只是它们记忆力并不强。

当前研究已证明 LLM 在知识记忆上很强，但现实中记忆力强不等于聪明。判断聪明与否更看推理能力。推理的本质是把多个相关知识点整合起来推导出新知识或新结论。当模型规模足够大时，LLM 本身就具备相应的推理能力。

ChatGPT 最大的贡献在于把 LLM 的接口层搭好了。它让大模型去适配人类习惯的命令式表达，而不是让人类去适应模型，想尽办法写出能达成的指令。易用性和体验因此大幅提升。

这种交互演进是一种很理想的新型人机交互方式。不需要专业技能，不需要高端设备，只需开口说出诉求，人工智能就能理解并解答。

**算法**
ChatGPT 由 GPT-3.5 驱动。GPT 是一种基于互联网开放数据训练的文本生成深度学习模型。算法上采用“利用人类反馈的强化学习”RLHF，包括人问机答、机问人答并不断迭代，让模型逐渐具备对生成答案的评判能力。

RLHF 的训练流程可拆成三步。

**阶段 1：预训练语言模型**
先选用经典的预训练语言模型作为初始模型。预训练出现前，深度学习在自然语言处理上受阻，主要有两个原因：一是面向具体任务的训练数据总量不足，模型容量越大越需要数据支撑；二是特征抽取能力不够强，即便数据充足也吸收不了知识。GPT 预训练模型的出现，从学术到应用都是一次技术飞跃，推动了研究范式的转换。

**阶段 2：训练打分模型**
在此基础上，用初始语言模型产生的数据训练一个打分模型。打分模型的目标是评估输出在人类看来是否表现不错。输入是提示词 Prompt 与模型生成的文本，输出是一个评估文本质量的数值标记。

用于训练打分模型的 Prompt 数据通常来自一个预先富集的数据集，ChatGPT 的 Prompt 主要来自调用 GPT API 的用户。这些提示词被送入第一阶段的初始语言模型生成文本。打分模型可视为判别式语言模型，可以从预训练语言模型出发，在 [*x*=（Prompt，模型回答），*y*=人类满意度] 的标注语料上微调，也可直接随机初始化后在语料上训练。

**阶段 3：基于 RL 进行语言模型优化**
有了能生成文本的初始语言模型和能判断质量的打分模型，就可以用强化学习基于打分模型来优化初始语言模型。

把微调任务建模为强化学习问题，需要定义策略 Policy、动作空间 Action Space、观察空间 Observation Space 和打分函数 Scoring Function 等要素。策略指基于语言模型接收 Prompt 并输出文本序列或概率分布；动作空间是词表所有标记在所有输出位置的排列组合；观察空间是可能的输入标记序列，即词表所有标记在所有输入位置的排列组合；打分函数则基于训练好的 RM 模型配合策略层面的合约进行计算。有了打分模型，就能按策略优化算法更新模型参数。

**算力**
ChatGPT 成为新一代人工智能里程碑的背后，是算力发展和数字经济时代大数据共同支撑的大型语言模型训练。GPT-3.5 的训练在微软云计算服务 Azure AI 超算基础设施上完成，该集群由 V100 GPU 组成的高带宽集群，总算力消耗约 3640 PF-days。

这带来了巨大的算力需求与资金消耗。训练和运行模型都需要庞大算力，有研究估算训练 1750 亿参数的 GPT-3 需要上万个 CPU/GPU 24 小时不间断输入数据，能耗相当于开车往返地球和月球，一次运算花费约 450 万美元。

在大模型框架下，GPT 每一代参数量高速扩张，预训练数据量需求和成本同步攀升。ChatGPT 官网在 2023 年 1 月 27 日至 2 月 3 日吸引的每日访客高达 2500 万。按稳定状态估算，每人每天提约 10 个问题，每日咨询量约 2.5 亿次。

据国盛证券计算机分析师刘高畅、杨然 2023 年 2 月 12 日发布的报告《ChatGPT 需要多少算力》，2023 年 1 月 ChatGPT 平均每天约有 1300 万独立访客，对应芯片需求为 3 万多个英伟达 A100 GPU，初始投入约 8 亿美元，每日电费约 5 万美元。GPT-3 训练一次成本约 140 万美元，更大 LLM 的训练成本在 200 万美元至 1200 万美元之间。对全球科技巨头而言不便宜，但尚可接受。

Google、Meta 等头部公司迟早会掌握类似技术，但军备竞赛仍会继续。一方面 ChatGPT 推理成本高昂，算力消耗与用户体验高度正相关；另一方面搜索用户黏性低，用户会流向体验最好的产品，这将大幅抬高搜索算法成本，Google 赖以生存的搜索广告业务难以继续“躺赚”。微软营收更多元，冲击更小，还可能受益于 Edge 浏览器乃至 Windows 系统份额提升。直白说，微软正开启大模型军备竞赛，要“卷死”对手。

**数据**
资料显示，ChatGPT 拥有多达 1750 亿个参数的模型，并在 2023 年初完成训练。背后离不开大数据支持，OpenAI 使用的主要公共爬虫数据集拥有超过万亿词的人类语言数据库。正是这些海量数据，使 ChatGPT 展现出三种强能力：

● 语言生成：遵循 Prompt 生成补全句子的内容，是目前人机交互最普遍的方式。
● 上下文学习 In-context Learning：遵循给定任务的几个示例，为新测试用例生成解决方案。值得一提的是，GPT-3 虽是语言模型，重点却在上下文学习而非语言建模。
● 世界知识学习：包括事实性知识和常识。

以上能力都来自大规模预训练：在有 3000 亿个词的语料上预训练 1750 亿参数模型。训练语料 60% 来自 2016—2019 年的 Common Crawl，22% 来自 WebText，16% 来自书籍和报刊，2% 来自维基百科。Common Crawl 是 2008 年至今的网站抓取大型数据集，包含原始网页、元数据和文本提取，覆盖多语言多领域。研究实验室常选取其纯英文过滤版 C4。WebText 语料是从 Reddit 输出链接网络中爬取的大型数据集，每个链接至少有三个赞，代表流行内容风向，对优质链接和后续文本有指导意义。
