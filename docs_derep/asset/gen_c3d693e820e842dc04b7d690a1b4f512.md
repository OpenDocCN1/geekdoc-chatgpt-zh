# 第二章
# 短视频提示词实操攻略
在AI短视频创作中，提示词是驱动AI产出符合预期的核心要素。掌握提示词编写技巧，能确保内容精准高效生成，提升质量与效率。本章重点介绍AI短视频提示词的获取方法与编写技巧。

2.1 AI短视频提示词获取思路
在文生视频流程中，提示词是实现创作意图的关键；在图生视频或视频生视频流程中，提示词则是让AI生成动态效果的有力辅助。创作者可以从哪些渠道获取提示词？本节介绍五种获取方式。

2.1.1 按需定制原创提示词
[PRE23]
2.1.1 按需定制原创提示词
生成AI短视频时，提示词直接决定成片质量，需要兼顾画面细节、逻辑连贯与情感表达。
按需编写提示词，指创作者根据视频主题、风格、受众及想传达的情感或信息，有针对性地撰写与内容高度相关的提示词，作为AI生成视频的重要参考，帮助AI准确呈现预期视觉效果与故事脉络。
之所以需要按需编写，是因为每个短视频都有独特主题与风格，而AI虽强也需明确指引。通过提示词，创作者能清晰表达创作意图，确保生成内容围绕主题展开，同时契合目标受众的审美与偏好。
创作者可针对不同主题风格撰写差异化提示词，满足多样化需求。提示词还能提升情感表达与意境营造，让视频更生动有趣。
以“江边的一片油菜花海，唯美，浪漫，高清，意境美”为例，这是一组描述性强的提示词，构成清晰具体的创作意图，具体分析如下。
（1）江边：明确场景空间，指引AI将背景设定为江边自然环境，营造宁静悠远氛围。
（2）一片油菜花海：具体描述主要表现物，即盛开的油菜花。油菜花带来生机活力，“一片”强调广阔壮观，增强视觉冲击。
（3）唯美：强调情感色彩与审美风格，要求AI注重画面美感与情感表达，呈现温馨浪漫又不失优雅的氛围。
（4）浪漫：与“唯美”呼应，进一步明确情感基调，要求AI营造浪漫氛围与情感共鸣，让观众感受到甜蜜温馨。
（5）高清：强调画质，要求AI注重画面清晰度与细节表现，呈现细腻真实的视觉效果。
（6）意境美：对前述提示词的总结升华，要求AI不仅注重美感与情感，还要营造深远意境，让观众获得超越画面的审美享受。
基于该组提示词，AI可生成以江边油菜花海为核心、充满唯美浪漫气质的高清短视频，通过细腻镜头语言与情感表达，带领观众进入诗意梦幻的世界，视频效果如图2-1所示。

2.1.2 借助AI插件生成提示词
让AI生成提示词，是指利用人工智能技术，通过特定算法与模型，让AI依据创作者输入的关键词、主题或描述信息，自动产出一系列相关提示词，引导AI更准确理解意图，从而生成符合预期的短视频内容。
采用AI直接生成提示词，主要是因为AI能高效处理和分析海量数据，提取与短视频相关的关键信息与特征。此法可大幅节省手动编写时间，提升准确性与多样性。随着技术进步，生成质量不断提升，更好满足需求，同时能挖掘创作者未考虑的关联信息，注入新创意。
