GPT-2 增量推理的核心在于如何复用上轮的注意力缓存。past_key_values 整体上是一个包含12份子缓存的元组，对应模型12层 Transformer。每一份子缓存 layer_past 其实就是该层在上一轮前向结束后保存的 present，而 present 本质上是注意力模块把本轮新产生的 key 拼到历史 past_key 上、把本轮新产生的 value 拼到历史 past_value 上后得到的一对新张量。12层各自的 present 汇总成 presents，再作为下一轮的 past_key_values 重新喂入模型。下面的段落拆解新 key 与新 value 的具体构造方式。

序列长度在首轮和后续轮次的处理不同。第一次完整前向时，query/key/value 在序列维上仍是完整的 seq_len。从第二轮开始进入增量生成模式，这一维被固定为1，每一步只引入一个新 token 的信息。

<1> 本轮新 key 的生成
历史 key 缓存 layer_past[0] 需要先转置，让维度变为 批次 × 头数 × 头特征 × 序列长。此时本轮新产生的 key 维度是 批次 × 头数 × 头特征 × 1。转置后可在最后一个维度上拼接，把当前 token 的 key 接到历史 key 末尾，以便后续自回归时能看到完整上下文。拼接后新 key 的维度变为 批次 × 头数 × 头特征 × 序列长+1，记作 new_seq_len = 旧长度+1。

<2> 本轮新 value 的生成
历史 value 缓存 layer_past[1] 保持原形态 批次 × 头数 × 序列长 × 头特征，本轮 value 维度是 批次 × 头数 × 1 × 头特征。两者在倒数第二个维度上拼接，把当前 token 的 value 追加到历史 value 序列中。拼接后新 value 的维度变为 批次 × 头数 × 序列长+1 × 头特征，new_seq_len 同样为旧长度+1。

class Block(nn.Module):

    def __init__(self, n_ctx, config, scale=False):
        super().__init__()
        # config对应的GPT2Config()类中，n_embd属性默认为768，因此此处hidden_size即为768
        hidden_size = config.n_embd
        # config对应的GPT2Config()类中，n_inner属性默认为None，因此此处inner_dim一般都为4 * hidden_size
        inner_dim = config.n_inner if config.n_inner is not None else 4 * hidden_size
        self.ln_1 = nn.LayerNorm(hidden_size, eps=config.layer_norm_epsilon)
        # 此处n_ctx即等于config对应的GPT2Config()类中的n_ctx属性，其值为1024
        self.attn = Attention(hidden_size, n_ctx, config, scale)
        self.ln_2 = nn.LayerNorm(hidden_size, eps=config.layer_norm_epsilon)
        if config.add_cross_attention:
            self.crossattention = Attention(hidden_size, n_ctx, config, scale, is_cross_attention=True)
