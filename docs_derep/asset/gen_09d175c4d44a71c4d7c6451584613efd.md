# 第二章
# 提示词实战全解

要真正释放 ChatGPT 的潜能，关键在于构建精准的提示词 Prompt。好的提示词能引导大语言模型 LLM 输出高质量内容。本章将深入拆解提示词的构造、设计原则、实操技巧以及 PromptPerfect 优化器的用法，帮助你提升与 ChatGPT 的互动效率与内容质量，最大化模型价值。

## 2.1
## 提示词组成与撰写原则

[PRE5]

扫一扫，看视频

提示词是用户输入给大语言模型的文本信息，用来引导和激发模型生成特定回应。它可以是文字，也可以是图片、数据、音视频、PDF 等文件。

**1. 提示词的构成**

一个完整的提示词包含指令、背景上下文、输入数据、输出指示 四个要素。指令明确任务类型，如分类、撰写、翻译；背景提供额外信息，帮助模型更准确理解需求；输入数据是具体的问题或素材；输出指示规定期望的格式或类型，确保结果符合要求。

**提示词示例：**

**我是一名数据标注专员，正在标注文本中的地名，请帮我提取以下文本中的地名。输入：“寒假的一天早晨，小李收到了一封来自重庆老家的信，信中提到了他儿时的玩伴小王现在东莞一所高校工作。小李计划利用假期去东莞与小王重聚。他从重庆搭乘高铁到达广州，再换乘到达东莞。到达东莞后，小王热情地带小李参观了他的学校，两人谈笑风生。小王告诉小李，他有个梦想，想去北京看看那里的雄伟建筑和历史遗迹。小李被小王的热情所感染，决定陪他一起去北京。在北京，他们参观了故宫、颐和园，感受到了这座古都的厚重和底蕴。小李提议再北上去张家口，体验一下冰雪运动。在张家口雪场，他们尽情滑雪，享受着冬日的喜悦。此行让小李深感友情的可贵，也让他更加珍惜生活中的每一次相遇和经历。”**

**输出格式：地点：<逗号分隔的地名列表>**

其中，背景信息为“我是一名数据标注专员，正在标注文本中的地名”，指令为“请帮我提取以下文本中的地名”。指令之下分别对应输入数据与输出指示。

**2. 提示词的设计原则**

编写精准有效的提示词需遵循以下原则。

（1）清晰：表达要明确，避免复杂或歧义，专业术语需解释。例如，“重庆市有哪些知名火锅店？”表述清晰；而“2021 年苹果价格比 2020 年上涨多少？”就不够清晰，“苹果”指水果还是手机、地区也不明确，模型难以作答。

（2）聚焦：提示词应抓住重点，避免空泛。问题要具体，利于模型集中注意力。例如，“你知道人类的知识吗？”过于宽泛，可改为“你了解人类科技史的知识吗？”答案会更精准。

（3）相关：在多轮对话中，提示词应围绕当前话题，保持关联。无关提问会分散注意力，增加沟通成本。可加入关键词如“景点推荐”“路线规划”“食宿安排”等来保持相关性。

（4）简洁：尽量精简，避免冗余。多余词汇会干扰模型，影响高质量输出。

几个对比示例：

**#有效提示词**

**你能总结一下埃隆·马斯克的性格特点吗？#聚焦、相关**

**东莞市有多少个乡镇？#具体、目标明确**

**#无效提示词**

**你能告诉我关于这个世界的什么？#过于宽泛和开放**

**你能帮我做作业吗？#过于开放**

**你好#无目的、不聚焦**

掌握原则并反复练习，有助于让对话始终在正确轨道上，获得更有信息量和深度的结果。
