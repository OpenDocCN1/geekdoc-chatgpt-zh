从线性到可微：反向传播如何诞生

与早期的线性感知机对照，新型完全互联的前向结构采用 WSN 型人工单元。激励映射既可选用式 1.2e 的 Sigmoid，也可选用式 1.2f 的双曲正切，甚至式 1.2g 的 ReLU 等形式。于是整条通路的输入与输出都成了处处可微且连续的量。看似只是一点模型上的微调，却直接促成了误差反向传播这一核心机制的出现，也使纯有监督的训练能够逼近输入到输出之间的任意非线性关系成为可能。

因为权值修正遵循误差反向传播规则，学界习惯把这类结构称作反向传播网络，同时也叫做前向网络、多层前向网、浅层全互联网，或简写为 MLP。必须厘清的是，这个 MLP 与前面提到的那种不具备学习能力的早期 MLP 完全不同，这里每个单元都必须是 WSN 形式。

## 2）误差回传算法的改良

### （1）加入动量因子。
标准反向传播是一种简单的静态最快下降寻优，只用了 k 时刻的负梯度方向，未利用历史经验。加入动量因子的改良形式为

$w_{ij}^{(q)}(k+1) = w_{ij}^{(q)}(k) + \alpha [(1-\eta)D_{ij}^{(q)}(k) + \eta D_{ij}^{(q)}(k-1)]$ (1.23)

$D_{ij}^{(q)}(k) = -\partial E / \partial w_{ij}^{(q)}(k)$

其中 $\alpha>0$ 为步长参数，$\eta$ 为动量因子 $0\le \eta<1$。动量因子相当于阻尼，能削弱振荡、改善收敛，是应用最广的改良之一。

### （2）变尺度策略。
标准反向传播用一阶梯度收敛较慢。若用二阶梯度，迭代式为

$w(k+1) = w(k) - \alpha [\nabla^2 E(k)]^{-1} \nabla E(k), 0 < \alpha \le 1$ (1.24)

## 1.3.3 深度卷积神经网络模型
从结构上看，深度卷积网络也属于前向网络类型，但因其重要性单独展开。

受 Hubel 与 Wiesel 1959、1962 年关于猫视觉通路简单细胞、复杂细胞的计算神经科学模型启发，日本学者福岛邦彦于 1975、1980 年提出认知机 Cognitron 和神经认知机 Neocognitron。卷积、局部感受野、池化、ReLU 等核心思想即在此萌芽。1989 年 Y. LeCun 等把误差回传引入神经认知机。1995 年 Y. LeCun 与 Y. Bengio 提出卷积神经网络概念。1998 年 LeCun 等提出 LeNet-5，在 MNIST 上取得 0.39% 错误率，刷新纪录。MNIST 由 LeCun 等构建，世界纪录后降至 0.21%（Wan 等，2013）。2012 年 Krizhevsky 等提出基于 GPU 训练的 AlexNet，在 ImageNet-1K ILSVRC-2012 中取得 15.3% Top-5 错误率，比传统方法提升约 10.9%，由此开启 CNN 在视觉、语音、自然语言处理等领域的大规模应用。

### 1.深度卷积神经网络的基本原理
如图 1.22，一个典型的深度卷积网络通常包含卷积核运算、带非线性激励如 ReLU 的卷积层、池化运算、池化层、归一化层、带 ReLU 的全连接层以及 Softmax 层。若干卷积层加一个池化层组成一个结构模块或 stage，一个或多个全连接层加 Softmax 构成任务头，可把整个网络看作若干特征提取模块加一个或多个分类、检测、回归头的组合。为防止过拟合，常配合 Dropout、BN 等使用。

本质上，结构模块负责逐级扩大感受野、用有监督学习从训练样本中提取不同粒度的分层特征，包括底层、中层、高层及局部、全局特征；而带 Softmax 的全连接网络则是标准的可训练分类任务头。
