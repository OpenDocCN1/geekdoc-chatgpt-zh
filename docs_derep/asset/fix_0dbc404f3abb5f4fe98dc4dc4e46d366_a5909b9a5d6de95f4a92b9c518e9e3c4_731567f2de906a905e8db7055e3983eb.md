数据类型辨析：别让隐形偏差带偏模型

在真实业务数据里，还会常见到一种第三类取值，也就是独一无二的 ID。分析时这类字段通常会被直接舍弃，所以本文不做展开。

数值型和类别型其实还能再细分，每种都可拆成两个子形态，实践中需要区别对待。数值型可以归为离散型或连续型。判断标准很直观：取值个数能数得清的算是离散，数不清的算是连续。举例来说，0 到 100 的整数集合属于离散，因为可选值有限；而 0 到 1 之间的小数集合属于连续，因为理论上可选值无限。

这里容易混淆的是数学里的自然数集合。它虽然理论上无限，却仍被视作离散，因为任意抽出两个数后，中间的所有数都能一一列举。反观实数，也就是有理数与无理数之和，在数学上对应数轴上的点，任意两点之间都能再塞入无穷多个其他实数。

对机器学习而言，关键不在于数学意义上的无限，而在于在设定上下界后，区间内部的值是否能够逐项枚举。若能枚举，方法选择会偏向一类处理；若不能，则更适合另一类。

类别型则可分为有序与无序。有序意味着取值之间存在先后或强弱关系，部分取值彼此关联更紧密。例如用多地数据去预测某地时，邻近地区的样本理应获得更高权重，只有在人口统计特征高度相似时，远地样本才值得参考。这种权重或顺序的观念虽非数值，却能提升分析效果。位置信息通常不能直接转成数字，因为三维空间关系复杂，但底层系统往往会把许多其他有序类别映射为数字以便计算。

无序类别则完全相反，每个取值与其他取值的差异相同且不可度量。典型例子是原色集合，每种颜色之间的差异是等价的；二元标签真/假也是常见例子。这类取值与依赖相似度或邻近度计算的方法不兼容。

有些取值乍看难以定性，比如邮政编码。它虽以数字呈现也带有一点顺序感，但数值上的邻近并不总等于现实地理上的邻近，所以更合理的处理是把它当作类别型里的无序值。

以澳大利亚城市举例，系统不应认为阿德莱德邮编 5000 与布里斯班 4000 的距离比与霍巴特 7000 更近。更实用的做法是把邮编字段替换为州和郊区等列，或者把每个州抽象为城区、郊区、农村的范围。这样处理后，因为州与州相邻、农村到城市几乎都要经过郊区，这些取值在理论上就可以变成有序的。

学会这样对输入取值进行划分，并识别出更合适的类型，是挑选模型和数据、构建更稳健可用机器学习系统的关键。

### 10.2 分类

总体来看，分类是机器学习里出现频率最高的应用场景，尤其是在神经网络被广泛使用的今天。

很多人对技术趋势有感知，却不一定了解技术本身，甚至认为神经网络就是机器学习唯一的工作方式。其实并非如此。神经网络只是个名字讨喜的工具，人们可以配上酷炫的大脑艺术并宣称“没人知道它怎么工作的”，因为其内部最难解释。

随机森林就是为减少决策树不准确性而出现的方法。它在分支点随机选择具有同等效果的选项。不是用一棵树，而是用相同历史数据生成多棵树，每棵树使用不同的种子或权重，并在任意相等点加入随机选择。然后对每棵树用相同输入进行分类，并根据用途取最常出现的结果（有时取平均值）。

### 距离度量

下面花点时间聊聊很多分类方法必须遵循的一个概念：距离度量。因为大量机器学习方法依赖一组输入属性——本质上是表格中的一行，忽略其类别或结果——并将其映射为 n 维空间中的点进行比较，而这些点未必直观，所以我们需要衡量点与点之间的距离。

这些度量是专家争论的焦点，我们只介绍几种非常常见的。还有很多度量标准，它们大多源于这些或完全不同。
