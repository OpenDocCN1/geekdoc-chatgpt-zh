样本间的远近到底怎么衡量，关键先看属性本身有没有序。比如水果的含糖量 {0.12,0.5,0.75} 就是典型的有序属性，产地 {新疆,山东} 则是无序属性。有序属性可以直接套用前面提到的相似度或距离定义，无序属性则更适合用 VDM 距离。

设样本集合里第 u 个属性是无序的，取值只有 a、b 两种。$N_{u,a}$ 为该属性取 a 的样本数，$N_{u,b}$ 为取 b 的样本数。整体有 k 个类别，$N_{u,a}^l$、$N_{u,b}^l$ 分别表示第 l 个类别里属性取 a、b 的样本数，则 a 与 b 之间的 VDM 距离为

$\text{VDM}_p(a,b) := \sum_{i=1}^{k} \left| \frac{N_{u,a}^l}{N_{u,a}} - \frac{N_{u,b}^l}{N_{u,b}} \right|^p$

当集合里共有 $n_c$ 个有序属性、$n-n_c$ 个无序属性，且把有序属性放在前面时，可把闵可夫斯基距离与 VDM 距离融合处理混合属性。样本 $x_i$ 与 $x_j$ 的距离定义为

$\text{MinkovDM}_p(x_i,x_j) := \left( \sum_{u=1}^{n_c} |x_{ui} - x_{uj}|^p + \sum_{u=n_c+1}^{n} \text{VDM}_p(x_{ui},x_{uj}) \right)^{1/p}$

## 9.1.2 性能度量
不同策略设计的聚类方法会得到不同结果，怎么判断好坏？直观上希望同类内部越像越好，不同类之间越不一样越好。评估常用有效性指标，也称聚类性能度量。

大致分两类，一类是外部指标，与某个参考模型比较；另一类是内部指标，直接评价聚类结果本身。

用 $\lambda_j \in \{1,2,\dots,k\}$ 表示样本 $x_j$ 的类标记，即 $x_j \in C_{\lambda_j}$。于是样本集 $D$ 的聚类结果可用标记向量 $\lambda = \{\lambda_1,\lambda_2,\dots,\lambda_m\}$ 表示。设参考模型划分是 $C^* = \{C_j^* | j=1,2,\dots,k\}$，标记为 $\lambda^* = \{\lambda_1^*,\lambda_2^*,\dots,\lambda_m^*\}$。把样本两两配对，定义

SS := {(xi,xj) | λi = λj, λi* = λj*, i<j}, a := |SS|,
SD := {(xi,xj) | λi = λj, λi* ≠ λj*, i<j}, b := |SD|,
DS := {(xi,xj) | λi ≠ λj, λi* = λj*, i<j}, c := |DS|,
DD := {(xi,xj) | λi ≠ λj, λi* ≠ λj*, i<j}, d := |DD|,
(9-5)

SS 表示在两者中都同类的样本对，SD 表示在当前划分同类但在参考中不同类，DS 表示在当前划分不同类但在参考中同类，DD 表示两者中都不同类。每对 $(x_i,x_j)$ 只能落在一个集合，故 $a+b+c+d = m(m-1)/2$。

基于此可定义外部指标：

Jaccard 系数（Jaccard Coefficient, JC）
JC := a / (a+b+c)

FM 指数（Fowlkes and Mallows Index, FMI）
FMI := sqrt( a/(a+b) * a/(a+c) )

Rand 指数（Rand Index, RI）
RI := 2(a+d) / [m(m-1)]

三者取值都在 [0,1]，数值越大代表效果越好。

对划分结果 $C = \{C_j | j=1,2,\dots,k\}$，结合类别特征可得内部指标：

DB 指数（Davies-Bouldin Index, DBI）
DBI := (1/k) sum_{i=1}^{k} max_{i≠j} ( D_{Ci}^{avg} + D_{Cj}^{avg} / D_{ij}^{cen} ),

Dunn 指数（Dunn Index, DI）
DI := min { min_{1≤i≤k} ( D_y^{min} / max_{1≤l≤k} Diam_{C_l} )_{i≠j} }

DBI 越小越好，DI 越大越好。

## 9.2 原型聚类
原型聚类假设聚类结构可由一组原型刻画，在实际任务中很常见，代表算法有 k 均值、学习向量量化、高斯混合聚类等，这里聚焦 k 均值。

### 9.2.1 k 均值
k 均值的核心思路是：在类别数 $k$ 给定的前提下，先选 $k$ 个初始中心，按最近中心原则做初始划分；再用均值更新中心，把样本重新分配到最近中心；如此迭代直到满足停止条件。

假设把样本 $D$ 划分为 $k$ 个不相交类，$C = \{ C_l | l = 1,2,\cdots,k \}$，其中 $C_i \cap C_{l'} = \varnothing$ 且 $\cup_{l=1}^k C_l = D$。记 $\bar{x}_l$ 为类 $C_l$ 的中心。k 均值通过最小化损失函数寻找最优划分。

先确定距离，通常取平方欧氏距离：
d(x_i, x_j) := Σ_{i=1}^n |x_{i i} - x_{j i}|^2 = ||x_i - x_j||^2

损失函数为样本到所属类中心的距离平方和：
Loss(C) = Σ_{l=1}^k Σ_{x_i ∈ C_l} ||x_i - \bar{x}_l||^2   (9-6)

即求解
arg min_C Loss(C) = arg min_C Σ_{l=1}^k Σ_{x_i ∈ C_l} ||x_i - \bar{x}_l||^2

该问题是 NP 难题，实践中采用迭代求解。先给定 $k$ 个初始中心 $(\bar{x}_1^0, \bar{x}_2^0, ..., \bar{x}_k^0)$，在中心固定时把每个样本分到最近中心；再按新划分计算各类的均值得到新中心。重复直至划分不再变化。

基本流程：
- 1) 初始化。令 t=0，设定类别数 k，初始化 $k$ 个初始中心 $(\bar{x}_1^0, \bar{x}_2^0, ..., \bar{x}_k^0)$，其中 $1<k≤m$。中心可随机产生，也可从 $D$ 中按策略选取。
- 2) 聚类。对确定的中心 $(\bar{x}_1^t, \bar{x}_2^t, ..., \bar{x}_k^t)$，计算每个样本到所有中心的距离，将样本分配到最近中心的类，得到新划分 $C' = \{ C_l | l=1,2,\cdots,k \}$。
- 3) 更新类别中心。按 $C'$ 计算各类的均值，得到新的中心 $(\bar{x}_1^{t+1}, \bar{x}_2^{t+1}, ..., \bar{x}_k^{t+1})$。
- 4) 重复 2)~3) 步，直至中心不再变化或达到终止条件。

k 均值理解简单、运行快，在类近似高斯分布时效果较好。但它是启发式方法，无法保证全局最优，初始中心会显著影响结果，且 $k$ 需要预先指定，实际中常需多次试验。
