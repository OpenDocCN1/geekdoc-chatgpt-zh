相似度检索的性能加速指南

在海量检索业务里，算得快慢直接决定响应体验，而向量间距离的计算开销正是拉低效率的关键点。本章先拆解常用距离度量的成本规律，再讲高维场景下用空间划分和剪枝压缩计算量的思路，同时结合并行计算与加速硬件，演示如何借助现有算力提升相似度判断的整体表现，为搭建高效检索提供完整方法。

本部分聚焦提速与可扩展，为后续工程实践奠定理论与技术基础。

#### 7.2.1 向量间距离计算的时间复杂度分析

相似度判断的核心操作就是向量间的距离求解，其耗时由样本数 N 与每个向量的长度 D 共同决定。若对全部组合求欧氏距离或余弦度量，复杂度约为 O(N²·D)。当数据规模变大时，逐对穷举很快成为瓶颈，需要借助流程重构如分区剪枝，或依赖 GPU 等加速设备来缓解。

#### 7.2.2 减少距离计算的分区优化技术

高维检索中，分区优化的思路是把整体拆成若干子集，只在相邻或可能相关的子集内计算距离，从而大幅削减运算总量。典型做法包括网格划分、KD 树、BallTree 等，均利用空间分布特性进行划分并配合剪枝剔除不可能候选，降低计算负担。
