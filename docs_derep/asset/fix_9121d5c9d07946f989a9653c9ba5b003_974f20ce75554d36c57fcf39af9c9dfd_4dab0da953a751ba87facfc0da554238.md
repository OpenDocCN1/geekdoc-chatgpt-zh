## 表5-1 微调方法汇总表

| 微调方法 | 特点 |
| --- | --- |
| Adapter Tuning | 在网络层间植入少量可训练适配器实现微调，不改动原始权重，参数量小，微调高效且计算开销低 |
| LoRA Tuning | 采用低秩分解对大模型权重矩阵进行微调，降低可训练参数规模，保持原结构不变，适合快速迁移到新任务 |
| Prompt Tuning | 通过优化输入提示帮助模型更好理解任务，无需调整模型权重，适用于特定任务的提示词调优 |
| P-Tuning | 基于可训练参数的提示优化方案，通过额外提示序列嵌入提升适应性，适合任务复杂、灵活性要求高的场景 |

## 5.4 本章小结

本章梳理了多种高效微调策略，包括 Adapter Tuning、LoRA Tuning、Prompt Tuning 和 P-Tuning，均各具侧重。Adapter Tuning 通过插入适配器实现参数轻量化；LoRA Tuning 利用低秩分解压缩矩阵表示，减少可训练参数；Prompt Tuning 与 P-Tuning 依靠可训练提示序列提升大模型对任务的理解与适应。上述方法在保留原始结构的前提下降低资源消耗，使模型能迅速适配新任务，为落地应用提供灵活性与效率。
