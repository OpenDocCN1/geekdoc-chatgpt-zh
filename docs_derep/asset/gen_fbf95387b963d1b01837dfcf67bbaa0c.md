理财师专业能力画像是提升服务质量与团队效能的核心支撑。银行需设计整合历史交易业绩分析、客户全周期评价反馈、产品知识与合规素养测试的智能评估工具，结合显性业绩与隐性服务行为数据实现能力全景度量。评估体系涵盖客户留存率、适当性匹配准确度、产品配置收益率、合规操作达标率、客户满意度等维度，建立半年度动态更新机制，当关键指标偏离基准时立即触发专项能力提升与复盘。

#### 2. DeepSeek 提示词
角色 + 任务：建立专业理财师胜任力模型，应赋予哪些指标更高权重以适配财富管理服务场景？

#### 3. 追问提示词
- 风险错配事件后理财师责任系数如何量化核算？
- 从评估理解能力角度，如何界定产品复杂度标准？
- 评估服务能力时如何平衡客户投诉与业绩表现？

#### 4. 输出形式
能力雷达图，ECharts 格式；培训课程推荐列表，Excel 格式。
