# 第三章

提示词工程

在大模型普及的当下，提示词工程成为一项新兴研究方向。简单说，提示词即人与大模型交互时的表达。在人机对话场景中，优质提示往往能实现事半功倍的效果。

掌握提示词工程，相当于拿到释放大模型生产力的钥匙。任何输入都能得到回应，但要获得高质量输出则依赖高质量提示。同一模型在不同提示下表现差异显著，例如绘画模型在新手手中产出平庸，在高手手中却能生成吸睛甚至震撼的作品。

## 3.1　提示词工程概览

提示词工程是针对大模型的专项优化方法，目标是通过设计与调整输入提示引导模型产出更准确、更有针对性的结果。

交互过程中，提示对模型回应内容与质量影响巨大。提示词工程关注如何构建最有效提示，使模型准确理解意图并满足需求。这涉及场景理解、词汇语法选择，以及不同提示策略的试验与对比。

### 3.1.1　提示词工程的核心特质

提示词工程是引导大模型输出高质量内容的强有力手段，主要体现为以下五点。

（1）**控制精准**。精细设计的提示可更精确地约束输出，使其贴合特定需求或场景。
（2）**可扩展**。面对新模型出现，提示词工程能够适配不同架构与特性并做针对性优化。
（3）**实用性强**。能在实际应用中提升模型表现，改善用户体验，如提供更准确答案、生成更具吸引力的内容。
（4）**交互式学习**。模型可通过持续交互，从历史回应中改进对提示的理解与响应。
（5）**需要专业知识**。设计有效提示通常依赖领域知识与经验，以及对目标模型特性的了解。

随大模型演进，提示词工程的重要性持续上升，研究者与工程师正不断探索更优方法以充分发挥模型潜能。

### 3.1.2　提示词中的主要角色

早期提示仅为纯字符串，后续引入了模型可识别的占位符，如“USER:”、“SYSTEM:”等。模型可为多条消息分配不同 **角色**，从而丰富提示结构。每条消息的角色用于分类，帮助明确上下文与目的，提升沟通效率。

提示词通常包含四类主要角色。

（1）**系统**角色：用于设定 AI 工具的行为准则与回复规则，相当于对话开始前的说明。
（2）**用户**角色：承载用户提出的问题或指令，是生成回应的基础。
（3）**助手**角色：负责对用户输入的回应，保持对话连贯性；其历史消息帮助维持上下文，必要时可触发工具调用。
（4）**工具**角色：用于承载工具调用返回的补充信息。
