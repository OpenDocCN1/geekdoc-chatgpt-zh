**ID3 算法总览**
Iterative Dichotomiser 3，即 ID3，是树形分类的经典方法。它利用信息熵衡量子集纯净度，以信息增益挑选分裂特征，通过递归选优构建分类树 [Data: Entities (0); Reports (0); Relationships (0)]。

**熵与增益**
信息熵反映集合的混乱程度，熵值下降意味着纯度提升。信息增益等于分裂前后熵值的差值，用以评估特征划分效果。ID3 每次挑选增益最大的特征进行拆分，逐步形成树结构 [Data: Entities (0); Reports (0); Relationships (27)]。

**划分方式与离散化**
ID3 原生不支持连续特征，需要先离散化如分箱处理。其划分方式是一次展开一列形成多子集，与 CART 的寻优切分点不同。例如按 AGE 不同取值把数据拆分为多个子集，再分别计算熵与增益 [Data: Sources (0, 1); Entities (6, 7, 8, 9); Relationships (10, 11, 12, 13)]。

**主要短板**
1. 对连续变量不直接兼容，需预处理离散化 [Data: Entities (0); Reports (0)]。
2. 易偏好取值水平较多的属性，可能导致过拟合 [Data: Sources (1); Entities (0)]。
3. 缺乏内置剪枝，训练集表现好但泛化能力受限 [Data: Sources (1); Entities (0)]。

**与 C4.5、CART 的关联**
ID3 是早期分支，后续 C4.5 和 CART 在此基础上改进。C4.5 加入连续值处理、剪枝与信息增益率等，CART 支持分类与回归并采用二分分裂 [Data: Entities (1, 2); Relationships (0, 1, 4, 14)]。

**小结**
ID3 以熵与增益构建分类树，思想奠定了后续发展。C4.5 与 CART 在此基础上优化，提升了适用范围与稳健性 [Data: Entities (0, 1, 2); Reports (0, 1); Relationships (0, 1, 4, 14)]。
