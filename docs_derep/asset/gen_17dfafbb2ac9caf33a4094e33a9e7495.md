- “社恐”型朋友：单独约个见面，带上小蛋糕再准备一件对方之前提到过想要的小周边。

关键提醒：如果对方仍有情绪，给彼此一点消化时间，不要出现“我都道歉了还要怎样”的想法。真正的友情经得起波折，只是需要你用持续的行动重新累积信任。

Q

怎么才能挑到好吃的榴莲，有没有什么简单实用的小窍门？

A

挑选榴莲有几个实用技巧：
1. 看外形与颜色。果形饱满鼓包的更好，避免畸形凹陷；成熟外壳呈青黄或淡黄，过青可能未熟，过褐可能过熟。
2. 捏刺判断。相邻两刺能轻捏有弹性说明成熟，坚硬不动则可能未熟；刺稀疏粗壮的果肉更厚。
3. 闻气味。成熟榴莲香甜浓郁，未熟有青草味，过熟或变质会有酒味或酸味。
4. 听声音。轻摇能听到轻微晃动声，说明果肉与壳分离，成熟度高。
5. 看果柄与裂口。果柄粗壮湿润更新鲜，干枯则存放久；轻微自然裂口可接受，大裂口易污染不建议选。
