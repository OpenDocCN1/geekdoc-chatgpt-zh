#### 1. 指数平滑法

核心思想：对历史销量加权平均作预测，**近期权重高、远期指数衰减**。模型结构简洁，鲁棒性强，是业界人工辅助预测的常客。其延展版——**三次指数平滑（Holt-Winters）**，引入趋势与季节分量，能更精准捕捉数据规律。原理细节留待第 2 章展开，此处先跑通应用。借助 Python `statsmodels` 库 `ExponentialSmoothing` 模块即可落地，关键参数速查表 1-11。

#### 2. ARIMA 模型

**差分自回归移动平均模型（ARIMA）** 是时序预测里程碑。它融合自回归（AR）与移动平均（MA），引入差分（I）处理非平稳。标记为 **ARIMA(p, d, q)**：`d` 为差分阶数，`p`、`q` 分别为差分后序列的 AR、MA 阶数。传统建模需繁琐的差分后 ACF/PACF 分析（第 2 章结合原理详解），实战中可用 `pmdarima` 自动搜参。表 1-13 梳理核心参数。

**表 1-13 auto_arima 核心参数表**

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| y | array-like | 目标序列 |
| exogenous | array-like | 外生特征 |
| start_p / max_p | int | 非季节 AR 阶数搜索下/上界 |
| d / max_d | int | 非季节差分阶数 / 上界 |
| start_q / max_q | int | 非季节 MA 阶数搜索下/上界 |
| start_P / max_P | int | 季节 AR 阶数搜索下/上界 |
| D / max_D | int | 季节差分阶数 / 上界 |
| start_Q / max_Q | int | 季节 MA 阶数搜索下/上界 |
| max_order | int | 阶数之和上限，默认 10 |
| m | int | 周期长度（月度=12），m=1 关闭季节性 |
| seasonal | bool | 是否启用季节 ARIMA |
| information_criterion | str | 模型选择准则：aic/bic/hqic/oob |
| alpha | float | 检验显著性水平，默认 0.05 |
| method | str | 似然函数类型 |
| trend | str/iterable | 确定性趋势项 |
| maxiter | int | 最大迭代次数 |
| disp | int | 日志打印级别 |

#### 3. 机器学习路径——XGBoost 模型

机器学习在需求预测中广泛落地，本节以 **XGBoost** 为例——并行树梯度提升架构，兼具强预测力与鲁棒性。进阶篇将讲授多模型集成、融合策略，那是业界提升上限的关键。

**建模前置：有监督重构**。需将目标与特征按时间对齐，通过滑动窗口等方式挖掘序列内生特征。完成拼接后，引入 `tsfresh` 批量衍生特征。训练时采用基础参数，训练集随机划 20% 做验证，监控验证集误差下降确定早停轮数。最终 **XGBoost 实现 1—MAPE = 0.842**，可视化见图 1-10。**本轮实战中，XGBoost 表现略优于指数平滑法与 ARIMA。**
