对照 1.1.1 节的介绍可以看出，Seq2Seq 本质上是处理序列到序列问题的深度学习范式，依托编码器-解码器框架，模型能学会输入与输出序列之间的映射规律。这套架构在机器翻译、文本生成、问答系统等场景里应用非常广泛。

Seq2Seq 的组成可以拆解为：

- （1）编码器：把整段输入压缩成固定长度的上下文向量，通常用 LSTM 或 GRU 逐层遍历输入，最后一个隐藏状态保留了序列的核心信息并交接到解码器。
- （2）解码器：在编码器提供的上下文向量初始化下生成输出序列。解码器同样采用 LSTM 或 GRU，按步解码得到目标序列的每个 token。每一时刻的输入由上一步的输出和编码器传来的隐藏状态共同构成，生成的 token 依次填入目标序列。
- （3）教师强制：为加速收敛，训练阶段解码器可以借助真实的目标序列作为下一步的输入，而不是使用自己上一时刻的预测结果。

## 1.2 分词与嵌入层

分词与嵌入是把自然语言换成模型可读数值表示的关键环节。在文本任务里，分词器先把句子切成独立的词或标记，为模型提供基础特征；嵌入层再把这些标记映射为稠密向量，让词语间的语义关联得以被捕捉。

本节先说明分词器如何把文本转成嵌入向量，再介绍如何用 PyTorch 搭建嵌入层并把分词结果送入模型。

### 1.2.1 分词器：将文本转换为嵌入向量

分词器是把原始文本变为模型可接受输入向量的工具。其工作流程包括把句子拆分为词或子词单元、映射到词表索引，随后借助嵌入层把索引转成稠密向量以保留语义，供后续处理。常见的实现有 Casual Tokenizer 因果分词器、Casual 3D CNN 分词器等。因果分词器架构如图1-3所示。
