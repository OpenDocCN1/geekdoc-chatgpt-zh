人们往往下意识地觉得，只要给一个概念起一个好定义，就能把它完全框住，这种直觉其实需要被纠正。生日派对在字面上只是派对的一种，真正指向的是为某人生日而做的庆祝，我们脑中随之浮现的还有蛋糕、蜡烛、唱歌等画面，尤其在西方语境里更典型。威拉德·范奥曼·奎因在《从逻辑观点看》、路德维希·维特根斯坦在《哲学研究》中都反对仅用范畴定义来抓取概念，第6章用相当篇幅说明面对生日聚会这类事物时，除了必要充分条件，还必须兼顾哪些层面。

整篇论述的脉络明显受马文·明斯基推动。从研究起点起，明斯基对人类如何推演的关注就让他与约翰·麦卡锡拉开距离，《心灵学会》第323页写道：“麦卡锡更在意为推演搭起逻辑与数学的基础，而我更在意我们如何借助模式识别与类比来推演。”明斯基提供了构建基于知识的AI系统的另一种思路，最具标志性的是框架系统。核心引文来自他1974年6月在麻省理工人工智能实验室发布的备忘录306《知识表示框架》，原文可网查，也收进布拉赫曼与莱韦斯克编的《知识表示中的阅读》。想系统把握明斯基的整体看法，可看《心灵学会》。大象与树的例子取自布拉赫曼的《我撒谎关于树》。

把经验以定型方式记住，唤醒既有经验后再让记忆结构去适应当下情境，这一机制强化了智能研究中一个重要却常被低估的线索。这种记忆驱动的推演观念也渗入罗杰·尚克及其学生的研究，可见《语言和记忆》《动态记忆》，以及他与罗伯特·阿贝尔森合著的《脚本、计划、目标》。海梅·卡本内尔与史蒂文·明顿在《隐喻与常识性推理》中提出一个经验性推演假说，可能也源自明斯基：在日常、熟练、可循环的情境里进行的推演，与数学或解谜等抽象、实验性、非循环情境中那种显式的形式演绎，本质上不同，这一概括很到位。珍妮特·科洛德纳等人以案例式推演把记忆驱动的推演拓展到医疗诊断、设计、冲突解决、规划等具体求解领域，参考她1993年出版的《基于案例推理》。

到这里可以看出，概念与范畴相关的诸多问题都与语言和思维紧密相连，而心理学与哲学提供了关键资源。原型概念主要见于心理学文献，可参阅道格拉斯·梅丁与爱德华·史密斯的评论文章《概念和概念形成》，以及埃莉诺·罗什与芭芭拉·劳埃德主编的《认知和分类》。亚科·欣蒂卡在《知识与信仰》中讨论了“知道那个”与“知道谁”的差异。伯特兰·拉塞尔关于名字、名词短语与个体的观点见于《论指称》，这对我们接下来两章使用个体符号有影响。

布莱恩·坎特韦尔·史密斯在最后一节的引文来自《人工智能的承诺》第63页。罗德尼·布鲁克斯关于世界与其表征的论断摘自《无表示智慧》第139页。范畴可不断被细化或注释的想法常被称作细化容差，麦卡锡在1998年论文《细化容差》中讨论。关于概念与属性只在一定程度上适用的说法，可见乔治·克里尔与袁博在拉特飞·扎德文集《模糊集，模糊逻辑与模糊系统》中的论述。更多索引知识在智能系统中的应用，可看伊夫·莱斯佩兰斯与莱韦斯克1995年在《人工智能》发表的《索引知识与机器人动作》。第6章提到的儿童词典是约翰·特雷瓦斯基斯与罗宾·海曼的《孩子们的第一本词典》。儿童如何理解概念的议题也将在第10章展开。

# 第7章 常识符号化：上篇

第七、八章主要围绕常识性知识的符号化表征，以及在此基础上定义的推演操作。智能研究中这一分支通常称为知识表征与推演。早期重要合集是布拉赫曼与莱韦斯克编的《知识表示中的阅读》，近年综述合集有弗兰克·范·哈梅伦等人编的《知识表示手册》。第七、八章涉及的大多数问题在布拉赫曼与莱韦斯克的教材《知识表示与推理》中已有更深入介绍。

第七章聚焦世界表征与概念结构，强调个体事物及其相互关联。20世纪70年代，这种面向连接的表征范式在语义网络、概念网络、联想网络等总称下流行。尼古拉斯·芬德勒编的《关联网络》汇集相关论文，布拉赫曼的《论语义网络的认识论地位》反映了70年代末该领域进展。有人认为查尔斯·桑德斯·皮尔斯在20世纪初已提出以网络方式使用这些思想，见唐·罗伯茨的《查尔斯·S. 皮尔斯的存在主义图谱》。60年代最具影响力的研究之一来自罗斯·奎里安，其论文《语义化记忆》直接推动了AI的广泛探索。如奎里安所述，因其高连通性，语义网络支持基于路径的处理，比如沿链接传递标记以检验项目间是否相连。该思路后来在斯科特·法尔曼的《NETL》和斯图尔特·夏皮罗的论文《语义网络中基于路径和节点的推理》中得到充分运用。

语义网络的一个基本特征是范畴的层级分类及属性继承。但从节点与链接的视角看，这一看似简单的想法暗藏诸多微妙陷阱。威廉·伍兹的《链接中的内容》对网络中链接做了大量直观却有误的假设，布拉赫曼随后在《概念的含义》和《“IS-A”的区分》里提出相关观察与额外挑战。

为了理解其中涉及的问题，可以思考世界表征里使用的符号空间点#25：这个符号是指波士顿的某个具体地点，同时正好是事件#23约翰出生发生之处，还是指它本质上代表事件#23的发生地，而该地恰好位于波士顿某处？按伍兹的说法，从事件#23到空间点#25的位置链接，前者是断言性的，后者是结构性的。若发现事实错误，差异就会显现，假设约翰其实出生在匹兹堡。前一种解释下，我们希望把事件#23的位置链接改为另一个符号，比如空间点#37代表匹兹堡某地；后一种解释下，我们保留位置链接不变，只需把空间点#25的所属城市链接改为代表匹兹堡的符号。需要说明的是，第七章并未明确采用哪种解释，或是否存在其他解释，以及这会如何影响我们对所信内容的判断，这些问题将在附录中更精确地讨论世界表征的节点与链接所承载的信息。

正是这些分析催生了广为人知的KL-ONE知识标识系统，由布拉赫曼与詹姆斯·施莫尔策在《KL-ONE知识标识系统概述》中记录，并为后来的描述逻辑研究奠定基础。弗兰兹·巴德等人编的《描述逻辑手册》给出综合性视角。世界表征与概念结构的区别对应描述逻辑中A盒子与T盒子的分野[A为断言，T为术语]。第六章明斯基的框架概念与描述逻辑的符号表达密切相关。框架结构的诠释在查尔斯·菲尔莫尔的《框架语义学》与帕特里克·海斯的《框架逻辑》中展开，这项工作也关联到语言学早期所谓的案例框架，菲尔莫尔1968年的论文《格辩》为该领域作出突出贡献。这为本文与KL-ONE系统中使用的角色概念提供了重要基础。需注意，KL-ONE远超本文所呈现的表征，拥有丰富的结构描述语言来表达概念角色间的关系，如布拉赫曼与施莫尔策论文所述。

KRL是该谱系中较为复杂的表征框架，见丹尼尔·博布罗与特里·维诺格拉德1977年发表的《知识表示语言KRL综述》。KRL包含许多有趣构造，其中一种注释样式与本文讨论相近。KRL还探索了元层面的表征与推演。

第六章讨论了原型与范例。重构记忆的想法可追溯至弗雷德里克·巴特莱特爵士的经典著作《记忆》，附录中亦有提及。伊丽莎白·洛夫特斯的《目击证言》记录了关于目击记忆的重要论述。

我们对世界的认知在不断修正，因为默认假设会被证伪。马修·金斯伯格的《非单调推理中的阅读》强调了在典型性假设下处理例外时的棘手问题。无分支的简单更新相对容易，但许多推演依赖的基础信念一旦改变，处理就变得复杂。围绕信念修正的研究领域正在探索这一问题，其中彼得·古尔文编的《信念修正》与伯恩哈德·内贝尔的论文《信念修正的知识水平分析》尤为重要。智能系统通常借助真理维护系统来支持信念变更，约翰·德基勒的《基于假设的TMS》与乔恩·道尔的《真值维护系统》即为代表性贡献。

# 第8章 推演机制：下篇

前一章聚焦常识性知识可能需要的表征形式，即世界表征与概念结构，而第八章的重点是推演：基于给定表征进行演算，前提是需要一种“演算类型”的方法[源自莱布尼茨在第四章的表述]，它不仅能产生恰当的概念，还能“以高度自动化方式进行常规计算，无需过多精力或实时监控，即便面对庞大的知识库”，正如附录所述。

我们提出一种符号语言来表达我们打算相信的命题。此处引入的语言L是第四章提到的一阶谓词演算的变体，仅含一元与二元谓词，并且对常量有特殊处理方式，类似于赫克托与格哈德·拉克迈尔《知识库的逻辑》中对标准名称的处理。关于谓词演算的入门可参阅赫伯特·恩德滕的《数理逻辑》与埃利奥特·门德尔松的《数理逻辑概论》。由于使用了“之后”来谈论事件与变化，L语言更接近情境演算的方言，该语言由约翰·麦卡锡在《情境、行为和因果律》中提出。后期雷蒙德·莱特及其同事对情境演算进行了改编与形式化，见莱特2001年《行动中的知识》与林方真2008年论文《情境演算》。根据麦卡锡与帕特里克·海斯的论文《从人工智能角度看待一些哲学问题》，为处理时间与模态等概念，L需要进一步扩展。

下一步是将世界表征视为仅代表世界的基本属性，并借助涉及L语言公式的特殊子句来推导属性。这些子句使整个表征系统更像Datalog，处理数字与序列时常被视为编程语言，如Prolog。泽格·阿比特布尔等人《数据库基础》对Datalog有记载。阿兰·科尔默劳尔与菲利普·鲁塞尔《Prolog的诞生》、威廉·克洛克森与克里斯托弗·梅利什《Prolog编程》以及赫克托《思维即计算》介绍了Prolog的历史。

当用逻辑术语推演变化时，最先出现的问题是框架问题[见麦卡锡与海斯《一些哲学问题》及默里·沙纳汉《解决框架问题》]。简单说，在只处理受影响内容的前提下，如何对未受事件影响的内容做出结论。第八章提出的关于变化的推演方法基于莱特1991年论文《情境微积分中的框架问题》首次提出的解决方案，并在《行动中的知识》中详细阐述。粗略地说，这涉及对事件的逻辑量化，即能够影响某属性的事件只有那些被明确命名的事件。对莱特而言，这些陈述成为逻辑公理，即后继状态公理；在我们的例子中，它们表现为某种形式的派生子句。

需要指出，这种处理变化的方式并未讨论在无进一步干预下会发生什么，即自发进行的过程是什么。这需要把过程作为可见的复杂事件来表征，例如在情境演算中使用的Golog语言，详见莱特著作。

在规划方面，第一次将其归为逻辑推演形式的是麦卡锡的《情境、行为和因果律》。此后自动规划成为AI的长期主题，出现了大量专用表征与推演方案，其中极具影响力的STRIPS表征由理查德·菲克斯与尼尔斯·尼尔森在《STRIPS：应用定理证明问题解决的新方法》中提出。马利克·加拉卜、达纳·劳与保罗·特拉维索的教材《自动规划》介绍了部分专用规划方案。
