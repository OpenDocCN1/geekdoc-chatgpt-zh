▲图 3-67

在 ChatGPT 输入：“在 Excel 工作表中，D 列为产品优惠信息，需要在 D 列查找表格内容是否有‘折扣’，如果查找结果为有，便在 E 列单元格中返回结果为‘有折扣’，如果查找结果为无，则返回结果为空，可以用哪个函数公式？” 按 Enter 发送，ChatGPT 即可提供查找关键词的公式，[PRE28]

### 专家指点

ChatGPT 给出的公式里，IF 用于逻辑判断，本书已有介绍。这里补充 ISNUMBER 与 SEARCH 的作用。ISNUMBER 用于判断给定对象是否为数值，返回 TRUE 或 FALSE。SEARCH 属于文本函数，在文本中查找指定子串并返回起始位置，且不区分大小写。

#### 步骤 03

复制 ChatGPT 提供的计算公式，在 Excel 工作表中，[PRE29]选择 E2:E9 单元格区域；[PRE30]在编辑栏中粘贴复制的公式：`=IF(ISNUMBER(SEARCH("折扣",D2)),"有折扣","")`，如图 3-69 所示。

图 3-69
