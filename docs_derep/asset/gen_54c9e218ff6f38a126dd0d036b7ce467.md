### 6.2.2 智能体核心模块解析：代码实现与逻辑设计

出行助手的核心是工具与大语言模型的深度结合，推动智能体完成查票、购票等任务。本节会深入拆解智能体的核心模块与设计思路，涵盖 Prompt 模板、工具调用、记忆组件以及多轮推理的实现方式。

Prompt 指令是引导 LLM 与用户交互、执行任务并触发工具的关键。Prompt 作为智能体与大模型沟通的枢纽，承载任务描述、工具说明与执行规范，确保模型在多轮对话中高效完成目标。

对 Prompt 各部分的职责做下说明。

- 角色设定：开篇就把 LLM 定位为“AI火车票助手”，明确任务定位与目标。
- 任务描述：{task_description} 是占位符，会接收用户输入的具体需求，比如某天北京到上海的查票请求。
- 工具或动作说明：{tools} 会罗列模型可用的全部工具，例如查票与购票，帮助模型清楚可操作的范围。
- 任务执行记录：{memory} 用于展示当前智能体的执行轨迹，让模型参考历史步骤，保持逻辑连贯。
- 格式说明：{format_instructions} 告诉模型输出的格式规范，包括如何描述任务、思考过程与工具选择，使推理更结构化。

紧接着定义任务结束后的最终回复 Prompt，用于让智能体在完成任务后做收敛总结。该 Prompt 会要求模型忽略中间的思考与分析细节，只输出简明的结果，对用户体验很重要。
