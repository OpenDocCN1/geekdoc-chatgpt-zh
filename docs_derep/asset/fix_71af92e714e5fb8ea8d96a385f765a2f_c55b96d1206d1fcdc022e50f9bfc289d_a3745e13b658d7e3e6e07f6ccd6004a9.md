- 数据序列化：bochasearch 的返回结果为原始结构化数据，字典或列表形式，而协议要求 content 必须为字符串，回填前需通过 json.dumps 序列化。
- 退出机制：当模型判断已有足够信息回答用户问题时，tool_calls 返回 None，循环终止并返回最终生成的文本。

## 3.2.2 SearXNG：开源聚合搜索引擎的深度应用

在了解博查这类面向 AI 优化的商业化深度搜索方案后，本节介绍开源社区极受欢迎的免费替代方案 SearXNG。

与博查侧重搜索质量的深度加工不同，SearXNG 是一款元搜索引擎。它的核心优势是能同时向 Google、Bing、DuckDuckGo 等数十个上游搜索引擎并发请求，实现搜索维度的广度覆盖，并对汇总结果进行去重与重排序。

SearXNG 的核心特性总结如下。

- 隐私与可控性：支持私有化部署，开发者对搜索数据拥有完全控制权，有效避免商业引擎追踪。
- 高兼容性：提供标准化 API，能够轻松集成到各种 LLM 编排框架中。
- 高度可定制：允许开发者自行配置上游引擎列表、搜索分类以及结果过滤规则。

由于 SearXNG 属于自托管工具，开发者需要准备服务器进行私有化部署。接下来，将先后探讨其 Docker 部署流程及 Python 调用接口的具体实现。

下面介绍几个关键参数。

### （1）安全加固（Capability）类的参数

- --cap-drop ALL：移除容器内所有默认特权，最大程度降低潜在风险。
- --cap-add：精准补偿必要权限，如 CHOWN 允许修改文件所有权、SETGID/SETUID 允许进程身份切换。

### （2）日志管理相关的参数

通过 --log-opt 限制日志文件总大小不超过 1MB，防止因日志堆积占满磁盘空间。

### （3）端口与挂载的参数

- -p 18080:8080：将容器内部服务端口 8080 映射至宿主机的 18080 端口。
- -v ...:/etc/searxng:rw：将本地 data 目录持久化映射至容器配置路径，且赋予读写权限。
