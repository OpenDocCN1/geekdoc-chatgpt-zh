# Prophet 模型在供应链预测中的核心机制解析

Prophet 凭借其对多成分分解的精准刻画、对促销与节假日事件的灵活处理，以及非线性建模能力的引入，成为供应链预测领域的“常青树”。它通过融合多参数实现信息表征，允许用户凭借对数据的直观理解直接指定参数，并支持通过调参进一步挖掘模型潜力。针对多信息融合可能带来的计算效率瓶颈，Prophet 在底层对参数估计与推断流程进行了深度优化，显著提升了拟合速度。

从宏观视角看，Prophet 采用加法模型思想，将时间序列拆解为趋势、季节、节假日三大核心驱动项，并叠加噪声项，数学表达如下：

\(y(t) = g(t) + s(t) + h(t) + \varepsilon_t\)

其中，\(g(t)\) 捕捉非周期性的长期走势；\(s(t)\) 刻画周期性波动；\(h(t)\) 量化节假日等特殊事件引发的、可能持续数天的非规则冲击；\(\varepsilon_t\) 则代表服从正态分布的随机干扰。

### 6.4.1 趋势项：从线性到饱和的灵演进

Prophet 在趋势拟合上实现了关键突破，引入非线性机制打破传统模型局限。其核心提供两种增长范式：**线性增长**与**逻辑（饱和）增长**。

**1. 线性增长：分段变点的动态适配**
基础线性模型 \(g(t) = kt + m\) 假设斜率 \(k\) 与截距 \(m\) 恒定，但真实业务中增长率与基准常随时间漂移。Prophet 引入**变点集合 \(S\)** 显式建模这种结构性断裂。
*   定义增长率调整向量 \(\delta\)，任意时刻 \(t\) 的实际增长率为基础率 \(k\) 累加过往所有变点的调整量：\(k(t) = k + \sum_{j:t>s_j} \delta_j\)。
*   通过指示向量 \(a(t)\) 标记变点生效状态，配合对截距 \(m\) 的同步修正 \(\gamma\)（为保证函数连续，设 \(\gamma_j = -s_j \delta_j\)），构建出**分段线性趋势函数**：
    \(g(t) = (k + a(t)^T \delta)t + (m + a(t)^T \gamma)\)
这种机制赋予了模型“随时改变走势”的灵活度。

**2. 逻辑增长：拥抱业务上限的 S 型曲线**
现实场景中，许多指标（如汽车备件需求受车辆保有量上限制约）呈现饱和特性。基础 Logistic 模型为 \(g(t) = \frac{C}{1 + \exp(-k(t - m))}\)，其中 \(C\) 为承载上限。
Prophet 进一步将上限 \(C\) 与增长率 \(k\) **时变化**：
*   容量上限 \(C(t)\) 随时间演变；
*   增长率引入变点调整机制，同步修正平移参数 \(m\)。
最终形成**时变逻辑增长模型**：
\(g(t) = \frac{C(t)}{1 + \exp(-(k + a(t)^T\delta)(t - (m + a(t)^T\gamma)))}\)
这使得模型能精准贴合“快速增长-逐步放缓-触顶饱和”的完整生命周期。

### 6.4.2 季节项：傅里叶级数解码多周期叠加

面对日、周、年多重季节性耦合的复杂局面，Prophet 引入傅里叶级数构建周期基函数。给定周期长度 \(P\)，季节项展开为 \(N\) 阶谐波叠加：

\(s(t) = \sum_{n=1}^{N} (a_n \cos \frac{2\pi nt}{P} + b_n \sin \frac{2\pi nt}{P})\)

引入设计矩阵 \(X(t)\) 与参数向量 \(\beta = [a_1, b_1, \dots, a_N, b_N]^T\)，季节性表达简化为 \(s(t) = X(t)\beta\)。为控制模型复杂度，\(\beta\) 设定零均值高斯先验 \(\text{Normal}(0, \sigma^2)\)，超参数 \(\sigma\) 直接调控季节性强弱。**关键提示**：\(N\) 值不宜过大，否则极易陷入过拟合陷阱。

### 6.4.3 节假日与事件项：先验知识的显性注入

常规趋势季节无法解释“双十一”、“春节”此类强冲击事件。Prophet 将各节假日视为相互独立的效应模块，要求用户预先定义**影响窗口**（节前/节后天数）。
*   事件 \(i\) 的影响日期集合记为 \(D_i\)，构建指示矩阵 \(Z(t)\)。
*   事件效应系数 \(\kappa\) 服从先验 \(\text{Normal}(0, v^2)\)，模型估计 \(h(t) = Z(t)\kappa\)。
**实战要点**：同名节假日（如连续多年的“国庆”）共享参数估计，通过汇总历史同类事件经验，实现对未来冲击的鲁棒预判。

### 6.4.4 模型训练：贝叶斯框架下的自动化与不确定性量化

**1. 变点自动筛选：拉普拉斯先验的稀疏魔法**
不预设变点位置，而是在密集候选集上施加拉普拉斯先验 \(\delta_j \sim \text{Laplace}(0, \tau)\)。
*   **\(\tau\) 是灵活度旋钮**：\(\tau\) 越大，容忍更多变点，拟合越贴合历史（易过拟合）；\(\tau \to 0\) 时退化为无变点的基础增长模型。
*   **未来不确定性模拟**：基于历史拟合得到的变点率 \(\lambda\)，在预测期随机采样未来变点位置与幅度，通过蒙特卡洛模拟生成预测区间，直观呈现趋势演变的不确定性。

**2. 参数推断：Stan 驱动的高效后验估计**
全模型置于贝叶斯框架，利用 Stan 平台的 L-BFGS 优化器求解 MAP 估计（后验模式）。用户通过调节各组件先验超参数（如趋势灵活度 \(\tau\)、季节强度 \(\sigma\)、节假日影响 \(v\)）实现“软约束”控制。
*   **工程化便利性**：支持通过变点数量、比例或自定义日历指定变点先验；节假日采用结构化表格（名称、日期、前后窗口）批量导入。

**Prophet 优劣势速览**：
✅ **可解释性强**：输出趋势/季节/节假日分解图，业务归因清晰。
✅ **工程友好**：参数直观，支持先验知识注入，开箱即用。
⚠️ **单序列孤岛**：无法跨序列共享统计强度（如层级预测、冷启动场景无能为力）。
⚠️ **调参成本高**：超参数敏感，大规模场景下网格搜索计算开销大。

# 深度学习模型：从局部特征到长程记忆的架构演进

## 7.1 CNN 家族：一维视角下的局部模式捕手

### 7.1.1 1D-CNN：把时间序列当“单通道图像”看
核心思想：卷积核宽度覆盖全特征维，仅在时间轴滑动，提取**局部时序纹理**。
**标准化流水线**：
1.  **全连接升维**：低维序列 \(\to\) 高维表达空间。
2.  **Reshape 重塑**：转为 `[Batch, Channels, Length]` 多通道张量。
3.  **1D 卷积 + 池化**：交替堆叠，逐层抽象、压缩时序分辨率。
4.  **Flatten + 回归头**：展平接全连接输出预测值。
**进阶玩法**：引入残差连接缓解深层网络退化，显著提升长序列建模上限。

### 7.1.2 WaveNet：因果膨胀卷积构建的“感受野帝国”
DeepMind 之作，源自语音生成，天然适配**自回归预测**范式：\(p(x) = \prod_t p(x_t | x_{<t})\)。

**破解 CNN 短视痛点的三把斧**：
1.  **因果卷积**：输出 \(t\) 仅依赖 \(t\) 及之前输入，严守时间箭头，杜绝“穿越未来”泄露。
2.  **空洞/膨胀卷积**：在卷积核间插入孔洞，指数级扩大感受野（Layer \(l\) 感受野 \(\propto 2^l\)），**以常数参数量换取指数级历史覆盖**，完美规避加深层数带来的梯度消散与算力爆炸。
3.  **门控激活单元（Gated Activation）**：膨胀卷积输出分流经 \(\tanh\) 与 \(\sigma\)，逐元素相乘。借鉴 LSTM/GRU 门控思想，**动态筛选有效历史信息，屏蔽无关噪声**——这是纯 CNN 缺乏的“注意力前身”机制。
4.  **残差 + 跳跃连接**：残差块加深网络；跳跃连接汇聚各层特征直达输出，缓解长程梯度消失。

## 7.2 RNN 家族：循环架构下的状态演化艺术

### 7.2.1 ESN（回声状态网络）：只训练输出层的“懒惰智慧”
传统 RNN 反向传播训练隐层权重，痛点显著：收敛慢、易陷局部最优、超参敏感。Jaeger (2001) 提出 ESN，**冻结隐层（储备池），仅训练读出层**，实现极简线性回归式训练。

**架构三板斧**：
*   **输入层** \(W_{in}\)：稀疏随机投影，将输入映射高维。
*   **储备池** \(W_{res}\)：大规模、稀疏、固定随机递归矩阵，作为“非线性动态核”将历史压缩为高维状态 \(x(t)\)。
    状态更新：\(x(t+1) = f(W_{in}u(t+1) + W_{res}x(t))\)，\(f\) 通常为 \(\tanh\)。
*   **输出层** \(W_{out}\)：全连接线性映射，**唯一需训练参数**，通过岭回归/最小二乘闭式解直接得出。

**储备池“四大金刚”超参**：
| 参数 | 物理意义 | 调调建议 |
| :--- | :--- | :--- |
| **规模 N** | 神经元数量 | 越大表达力越强，但易过拟合且慢。 |
| **谱半径 SR** | \(W_{res}\) 最大特征值模 | 核心记忆调节阀。经典要求 SR < 1 保“回声状态性”，实践常微调突破。 |
| **输入缩放 IS** | 输入信号幅度控制 | 适配激活函数线性区，避免饱和。 |
| **稀疏度 SD** | 连接稀疏比例 | 类 Dropout，平衡动态丰富度与计算稳定性。 |

**三阶段训练范式**：
1.  **初始化**：按上表配置，生成固定 \(W_{in}, W_{res}, W_{fb}\)。
2.  **状态收集**：驱动储备池跑完训练集，记录状态矩阵 \(X\) 与目标 \(Y\)。
3.  **线性求解**：\(W_{out} = Y X^{\dagger}\)（伪逆/正则化），一步到位，无迭代烦恼。

> **ESN 启示录**：用海量固定随机特征替代精心学习的权重，以空间换时间，为后续“随机特征厨房”（如 Random Kitchen Sinks、ELM）开辟了新赛道。
