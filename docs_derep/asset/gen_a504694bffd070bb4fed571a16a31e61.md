#### 6.1.5 搭建小红书热点监控工作流
下面演示一套自动抓取小红书热点的方案，省去人工翻页。

在 Coze 资源库的工作流里新建空白工作流，命名为“xhs_keywords”。

##### 1. 配置开始节点
定义启动参数。

- 输入
  - foldUrl：提前创建好的飞书多维表格链接，用于存放采集结果。
  - cookie：小红书登录后的 cookie，是调用接口的必要凭证。
  - keywords：搜索词，可填产品名、行业词、竞品或话题。

##### 2. 如何获取小红书 Cookie
用 Chrome 登录小红书主页，按 F12 打开开发者工具。

- 切换到网络选项卡
- 选中文档标签
- 点开 explore 文档
- 打开标头选项卡
- 找到 Cookie 字段，复制全部内容

##### 3. 配置按关键词获取笔记插件节点
使用小红书插件的 xhs_search_note 工具批量拉取笔记。

- 输入
  - cookieStr：开始节点的 cookie。
  - keywords：从开始节点传入。
  - notType：查询类型，0全部 1视频 2图文，本例选 1。
  - sort：排序方式，0综合 1最新 2最热，本例选 2。
  - totalNumber：本次查询数量，填 20。

##### 4. 配置循环获取笔记详情节点
对搜索结果逐条处理，取出每条笔记的完整信息如标题、内容、作者、互动量。

- 输入
  - input：取自“根据关键词获取笔记”节点的 data。

##### 5. 配置获取笔记详情循环内插件节点
使用小红书插件的 xhs_note_detail 工具。

- 输入
  - cookieStr：开始节点的 Cookie。
  - noteUrl：从循环节点的输出中选择 noteUrl。

##### 6. 配置提取视频文案循环内插件节点
使用字幕获取插件的 generate_video_captions_sync 工具，自动转写口播内容。

- 输入
  - url：取自“获取笔记详情”输出的 video_h264_url。
  - lang：视频语言，不填默认中文。
