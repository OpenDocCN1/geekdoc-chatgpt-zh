+ 1. 州：地域覆盖差异明显。部分研究聚焦怀俄明、得克萨斯、北卡罗来纳、加州、亚拉巴马等少数州，其他则覆盖多州乃至全部 50 州加哥伦比亚特区。
+ 2. 样本量：差异悬殊。最小为 34 所学校，最大达 533 468 名学生，小样本多为特定校或地区，大样本多为州级或全国数据。
+ 3. 年级：涵盖小学、初中、高中。有的锁定特定年级，有的跨学段。
+ 4. 数据来源：多采用既有数据源，包括横断面、重复横断面、纵向学校数据及计算机模拟数据。
+ 5. 分析方法：以描述性统计与回归分析为主，部分使用工具变量、微观模拟等技术。
+ 6. 回应率 %：波动较大，从 43% 至 98%。计算机模拟研究无回应率。
+ 7. PE 和 PA 相关标准：评估指标多样，如体育课频次与时长、PA 频率与质量、各强度 PA、力量锻炼、体育课出勤率等。
