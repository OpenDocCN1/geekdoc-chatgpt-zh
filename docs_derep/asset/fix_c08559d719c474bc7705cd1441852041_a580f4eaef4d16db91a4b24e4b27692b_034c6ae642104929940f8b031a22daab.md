**4.数组与指针的差异**
（1）本质区别：存数据 vs 存地址。
数组是连续的固定容器，定义时大小就定，内存里直接存放同类型的值，像一排固定格子。指针是保存地址的变量，本身不保存数据，像一张写有位置的纸条，纸条上的地址可随时改写。
（2）占用空间：数组大小随元素类型与数量决定，指针大小固定。
数组占用为单元素大小乘以元素个数，定义后不可变。指针大小与指向内容无关，32 位平台一般 4 字节，64 位平台一般 8 字节，只负责保存一个地址。
（3）数组名与指针变量：前者地址固定，后者可变。
数组名代表首元素地址，但它是常量，不能改。arr++ 是错误的。指针变量保存的地址可以改，ptr++ 会让它指向下一个元素的地址，这正是扫描的原理。
（4）访问方式：下标 vs 解引用。
数组用下标访问，编译器会自动计算首地址加下标乘元素大小，直接定位。指针用解引用，先拿到地址再取值，遍历时 ptr++ 移动到下一地址，再解引用即可。
（5）关键提醒：别混淆数组名与指针。
数组名是固定地址，不能赋值，如 int arr［5］； int *p； arr=p； 是错误的。指针是可变地址变量，可以令 p=arr； 但指针本身不是数组。
