#### 3. 文本文件读写：按字符处理，编码为先

文本模式以**字符**为单位，**必须指定编码**（如 UTF-8）。核心方法速查：

| 方法 | 功能 | 关键参数/返回值 |
| :--- | :--- | :--- |
| `read(size=-1)` | 读全文或指定字符数 | `size=-1` 读全部，返回字符串 |
| `readline(size=-1)` | 读单行（含换行符） | 到达 EOF 返回空串 |
| `readlines()` | 全部行 → 列表 | 每行含换行符，列表元素为字符串 |
| `write(s)` | 写入字符串 | 返回写入字符数 |
| `writelines(lines)` | 批量写入列表 | **不自动加换行**，需自行处理 |
| `flush()` | 强刷缓冲区 | 数据落盘 |
