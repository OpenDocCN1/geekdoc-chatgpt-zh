Janus 统一架构概览

统一框架：Janus 虽把视觉编码拆成两条独立通道，整个系统仍运行在同一个自回归 Transformer 框架之上。统一的框架让训练和推理更顺畅，多模态数据处理效率更高，同时也为向视频理解、多模态对话等方向扩展提供了便利。

### 7.2.3 多模态理解

多模态理解的目的是从图像中抽取丰富语义，支撑视觉问答、图像描述等任务。Janus 在这一块采用了专门的模块与处理流程。

#### 1. 视觉编码器
理解路径的核心选用 SigLIP 编码器。SigLIP 基于 Transformer，设计重点在捕捉图像的高层语义。

- (1) 丰富语义表征：能够提取既包含场景、物体类别等整体信息，又兼顾细节纹理和局部关联的高维向量。这些向量既能概括全局内容，也能反映细微结构。
- (2) 与文本模型可对齐：SigLIP 在设计时已考虑与语言模型的融合需求，输出格式与分布经过优化，能直接与文本特征匹配，为后续融合奠定基础。

#### 2. 特征处理
SigLIP 的输出是一个二维特征图，由若干特征向量构成网格，每个向量对应图像的局部区域。为让视觉信息在多模态建模中发挥最大作用，Janus 引入两项配合使用的策略。

- (1) 保留空间位置：为了适配自回归 Transformer，二维特征图被展平为一维序列。展平过程不仅是矩阵到线性的转换，还保留了原始空间中的位置顺序，这对捕捉局部与全局语义关联很关键。
- (2) 格式统一：展平后的视觉序列与文本 Token 序列在形式上保持一致，自回归建模和多模态融合可在同一输入空间进行，有利于模型同时考虑图像与文本的上下文关联。

#### 3. 理解适配器
为把展平后的高维视觉特征映射到语言模型的嵌入空间，Janus 使用两层 MLP 作为理解适配器。

- (1) 特征映射：适配器对输入视觉特征做非线性变换，使其语义更贴近文本表达。映射后视觉特征与文本特征在语义层面实现对齐，便于跨模态融合。
- (2) 无缝融合：通过映射，图像语义信息能够与文本数据结合，形成统一的多模态输入序列。模型在视觉问答与图像描述等任务中可直接利用不同模态互补信息，提升理解准确性与生成质量。

### 7.2.4 视觉生成路径

视觉生成的核心目标是把图像离散化为 ID 序列，并依据文本描述生成对应图像。设计旨在解决传统多模态模型在视觉生成上的难题，如图像与文本对齐效率、生成质量与语义一致性。通过把图像离散为视觉 Token 并嵌入语言模型输入空间，Janus 能像处理文本一样处理图像，实现高效生成。

#### 1. 视觉编码器：VQ Tokenizer
视觉生成环节的核心组件是 VQ Tokenizer，基于向量量化技术把图像切分为离散视觉 Token，具体如下。

- (1) 图像分割。Tokenizer 先把输入图像切成多个小块，通常是固定大小的正方形，如 16×16 像素。图像由此分解为多个局部区域，每个区域代表局部特征。
- (2) 向量量化。每个小块被编码为特征向量，再映射到离散的码本空间。向量量化实质是把连续向量转为离散符号，相当于给每个图像块分配一个 Token，在表达力与计算开销间取得平衡。
- (3) 离散化处理。量化后图像变成一系列离散 ID 序列，可像文本一样被处理，每个视觉 Token 类似文本中的词或字符，便于对齐语言模型输入格式并利用其生成能力。

#### 2. 特征处理：生成适配器
VQ Tokenizer 输出的 ID 序列需要进一步适配语言模型输入。

- (1) 序列展平。输出原本是二维的对应图像行列，展平为一维序列时保留空间顺序，使语言模型能理解局部与全局结构。
- (2) 码本嵌入映射。每个离散 ID 对应一个训练时学习得到的码本嵌入。生成适配器由两层 MLP 构成，负责把码本嵌入映射到语言模型输入空间。
- (3) 交互与融合。经适配器映射后，视觉 Token 与文本 Token 在同一空间交互。语言模型据此能同时处理文本和视觉信息，例如在文到图生成时依据文本语义选择合适的视觉 Token 构造图像内容。

#### 3. 向量量化模型
视觉生成路径的核心是基于向量量化的模型，具体为向量量化变分自编码器 VQ-VAE。开源代码中 vq_model.py 实现了该模型，包含编码器、解码器和向量量化器，支持图像压缩与重建。其思路是用 VQ-VAE 对输入编码、离散化，并通过向量量化学习更好的表征，为图像嵌入和生成提供基础。

### 7.2.5 自回归 Transformer 模型

自回归 Transformer 是 Janus 多模态模型的核心，负责处理理解路径和生成路径的特征序列并产出结果，把多模态处理统一到强大的序列生成框架中。

#### 1. 输入融合
处理前需先融合两条路径的特征序列。

- (1) 特征序列拼接：SigLIP 提取的图像语义特征与 VQ Tokenizer 生成的离散视觉 Token 嵌入按顺序拼接，保留不同模态的顺序信息，使模型能区分输入来源。
- (2) 上下文关系的保留：保留顺序信息后，自回归 Transformer 能更好理解多模态上下文，明确哪些特征来自图像、哪些来自文本，从而在生成时更合理地结合信息，提升理解力与生成背景。
- (3) 统一的多模态输入序列：拼接后形成统一输入序列进入自回归 Transformer，使多种模态数据在一个框架下处理，简化训练推理。

#### 2. 自回归生成
模型核心功能是生成输出序列，文本或图像均可，遵循自回归机制。

- (1) 逐 Token 生成：模型逐个预测下一个 Token，生成时参考已产生的历史序列，保持依赖连贯。
- (2) 依赖关系的捕捉：自回归机制让模型能捕捉序列依赖，例如生成文本描述时会依据前文决定下词，生成图像时会依据已生成的区域决定下一个视觉 Token，使输出更自然连贯。
- (3) 多模态生成能力：通过把视觉 Token 嵌入输入序列，模型可在生成过程中同时处理文本与图像，实现文到图、图描述等复杂任务。

#### 3. 预测头
为支持多模态任务，Janus 在自回归 Transformer 上增加了多个预测头。

- (1) 语言模型自带的预测头：用于文本生成，能根据多模态特征序列输出图像描述、视觉问答答案等，提升理解类任务的文本质量。
- (2) 视觉生成任务的预测头：额外增加一个随机初始化的预测头，专门负责图像预测，把生成的视觉 Token 序列转为最终图像，保持对理解任务的支持。
- (3) 多任务支持：多预测头设计让模型同时兼顾理解与生成，在同一框架下高效处理多种多模态任务。

### 7.2.6 三阶段训练策略

Janus 采用三阶段训练逐步提升多模态理解与生成能力。各阶段目标与方法见表7-1。

表7-1 三阶段训练中每个阶段的具体目标和方法

| 阶段 | 目标 | 方法 |
| :--- | :--- | :--- |
| 适配器和图像预测头训练<br>(Training Adaptors and Image Head) | 在冻结大语言模型和视觉编码器参数的前提下，训练理解适配器、生成适配器和图像预测头，建立视觉与语言的有效连接 | 在ImageNet-1K上训练，学习从图像像素到语义的映射，确保视觉特征能被语言模型理解，为后续融合打基础 |
| 统一预训练<br>(Unified Pretraining) | 在多模态数据上联合训练，使模型具备扎实的理解与生成能力 | 模型使用纯文本、多模态理解、视觉生成等多类数据训练，学习模态间的关联，提升多模态任务表现 |
| 监督微调<br>(Supervised Fine-tuning) | 通过指令微调增强指令跟随与对话能力 | 使用混合数据集微调，包含多模态理解、纯文本对话、文到图生成等，全面提升理解生成能力并改善指令响应 |

三阶段策略让 Janus 在理解与生成上逐步增强，为多模态应用提供基础。

## 7.3 训练策略

多模态模型训练时合适的策略对性能、稳定性和泛化至关重要。举例来说，若运营一个酒店预订平台，需要从海量酒店图片中挑出最吸睛的首页图以提高转化，人工筛选效率低且主观。借助多模态训练策略即可实现智能化筛选，如图7-6所示。

### 7.3.1 多任务学习

多任务学习指同时训练模型完成多个相关任务以提升泛化能力，例如一起做图像分类和文本生成，让模型更好把握图像与文本关系。实例7-1展示了使用预训练模型做多任务学习的过程，先用预训练 ResNet 提取图像特征，用预训练 BERT 提取文本特征，再用于图像分类和文本分类两项任务。
