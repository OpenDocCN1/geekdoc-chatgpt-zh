數據入口全景

（6）API 接入：API 即應用程序編程介面，是一套規範不同軟件間交互與交換數據的規則與協議。依托 API 開展數據採集是一種成熟高效的方式，能讓程序直接向外部系統、服務或平台請求資料，特別適合需要從第三方網站或在線服務抓取信息的場景。

（7）專業數據庫調用：專業數據庫是面向特定領域的信息彙聚庫，收錄了海量的文獻、研究成果與統計資料。不同學科擁有不同的數據庫，例如 PubMed 覆蓋醫學與生命科學領域，Web of Science 是綜合性學術庫，萬得數據庫則專注於金融領域的數據服務。每個庫各有特色資源，為研究者、學生及行業從業者提供重要信息支撐。

（8）公開數據集：這類數據集由政府、機構或個人無償公開，可在公共數據庫、開放政府數據平台等渠道獲取。其優點是免費且覆蓋面廣，常被用於教學、研究與公共政策分析。使用時需注意數據質量、精準度、時效性，以及相關的使用條款約束。

（9）傳感器採集：傳感器能感知並測量物理量，結合目標對象即可獲取溫度、濕度、壓力、位置、速度等參數。傳感器數據體量大、頻率高且類型多元，處理時需兼顧實時性、準確性與安全隱私。

各類採集途徑各具特點與適用範圍，選對方式直接決定數據質量與關聯性。

**4. 數據採集標準流程**

基礎流程如下。

（1）明確研究問題與目標：在正式採集前先釐清待解決的問題及預期成效，從而確定需要哪些類型數據。

（2）規劃研究方法：決定採用何種途徑獲取數據，可能包括問卷、訪談、觀察、實驗、爬蟲或專業數據庫查詢等，選擇需與研究問題相匹配。

（3）制定採集方案：編制詳細計劃，明確採集方式、所需資源、時間節點，並涵蓋樣本挑選、採集工具如問卷設計等事項。

（4）選取抽樣方式與樣本：根據研究性質挑選合適的抽樣策略。分析師常用的四種方式為簡單隨機抽樣、分層抽樣、整群抽樣、系統抽樣，各有優劣。此環節對保障數據代表性與準確性至關重要，選對方法才能從目標群體中獲得可推廣的樣本。

（5）執行採集：按計劃開展工作，可能涉及問卷發放回收、訪談、實驗實施、爬蟲編寫等。過程中需持續關注數據質量，高質量採集是得出有效結論的前提。

（6）數據清洗：採集回來的數據通常需預處理，包括錄入、修正錯誤或不完整回復、編碼開放式問題等。清洗的本質是消除錯誤與不一致，確保準確。包括修正明顯錯誤如拼寫、範圍錯誤，處理缺失值是補齊、刪除或保留，識別並處理異常值。清洗質量直接影響後續分析。

（7）評估質量：在每個預處理步驟後都要評估質量，檢查是否完整、一致且能支撐研究問題。重點評估樣本代表性，即樣本是否充分反映總體的多樣性。若發現偏差，可能需要補充抽樣或調整方法。

上述框架完整，可根據具體研究需求靈活調整。

**3．數據增強**

數據增強是通過讓有限數據產生更多等價樣本來擴充訓練集的技術，是解決深度學習數據稀缺問題的關鍵，尤其在醫學影像分析中常見。它能提升訓練集規模與質量，幫助構建更強模型。計算機視覺中常見方法有幾何變換、顏色調整、旋轉翻轉、噪聲注入、卷積核濾波、圖像混合、隨機擦除、縮放平移等，多由 imgaug 等庫支持。基於深度學習的增強如特徵空間增強、對抗生成與 GAN 方法進一步提升多樣性。
