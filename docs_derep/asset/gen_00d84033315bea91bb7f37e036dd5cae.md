基于用户的协同过滤
先把用户-物品评分表转成用户相似度矩阵：`user_similarity_df = pd.DataFrame(user_similarity, index=user_item_matrix.index, columns=user_item_matrix.index)`，随后打印出来观察关系强度。

推荐函数 `recommend_items_user_based` 的核心流程是：取出目标用户在相似度表中的排序，跳过自己取最相似的若干邻居；把这些邻居的评分向量累加起来形成候选分数；剔除用户已经产生过评分的物品；最后按累加分从高到低取 top_n。调用 `recommend_items_user_based(1, user_item_matrix, user_similarity_df)` 即可得到该用户的个性化清单。

基于物品的协同过滤
物品侧的思路是先算物品间余弦相似度：`item_similarity = cosine_similarity(user_item_matrix.T)`，再包装成 DataFrame `item_similarity_df`。

`recommend_items_item_based` 的做法是：读取目标用户的历史评分，对每个已评分物品，将其相似度向量乘以该用户给的评分，得到加权贡献；把所有贡献累加；去掉用户已知的物品；返回分数最高的 top_n 物品。执行 `recommend_items_item_based(1, user_item_matrix, item_similarity_df)` 可得到基于物品的推荐结果。

矩阵分解的优化
为缓解稀疏问题，用截断 SVD 做低秩逼近：`svd = TruncatedSVD(n_components=2)`，`matrix_svd = svd.fit_transform(user_item_matrix)`，打印分解后的低维表示，可作为后续特征或打分依据。

### 10.2.2 基于内容的推荐算法实现

基于内容的推荐，核心是拆解物品的属性并匹配用户的偏好画像，而非依赖其他用户的行为。它更关注物品本身的描述、类别、价格、品牌等信息，在电商、内容分发和在线教育等场景应用广泛。

实现的关键在于把物品特征向量化，再根据用户历史交互合成兴趣向量，从而找出最契合的候选。

### 1. 基于内容推荐的基本原理

该方法建立在 “喜欢过 A，就可能喜欢和 A 属性相近的 B” 这一假设上。系统为每个物品建立特征向量，通过向量间的距离判断相似度，再据此生成推荐。

#### 1) 物品特征向量
特征可以是文本描述、标签、价格区间等。文本类特征常用 TF-IDF 编码，结构化特征则做标准化处理，最终得到可计算的向量表示。

#### 2) 用户画像
用户画像由其历史浏览、购买、评分物品的特征叠加而成，相当于一个加权平均的兴趣向量，用来刻画长期偏好。

#### 3) 相似度度量
常用余弦相似度衡量角度接近程度，也可使用欧氏距离衡量绝对差距。相似度越高，推荐优先级越高。

### 2. 基于内容推荐的实现步骤

数据预处理与向量化是基础。对文本做清洗、去停用词并 TF-IDF 化；对类别、价格等做标准化，确保不同维度可比。

## 10.2.3 混合推荐系统的设计与实现

单一策略都有局限，混合推荐通过融合协同过滤、内容推荐和深度学习等手段取长补短，提升覆盖率与准确率。结合大语言模型还能让推荐更自然、更可解释。

本节演示如何用 OpenAI API 构建一个可落地的混合智能体，涵盖策略设计、接口调用、系统集成到部署。

### 1. 混合推荐系统的原理与架构设计

混合系统的目标是弥补单一模型的短板。协同过滤捕获行为模式，内容推荐锚定物品属性，深度学习与 NLP 则能理解用户的自然语言查询和对话历史。

融合方式主要有三种：加权融合，把多路结果按权重合并；级联融合，用一路结果作为下一路的输入；切换融合，按场景动态选择策略。配合 API 与数据源的实时联动，系统可以快速响应并输出精准个性化结果。
