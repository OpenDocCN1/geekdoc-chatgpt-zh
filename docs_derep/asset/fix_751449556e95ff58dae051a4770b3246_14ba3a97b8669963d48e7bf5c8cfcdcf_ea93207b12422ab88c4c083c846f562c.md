# 快速上手的 RL 调度仿真

想让强化学习介入调度，首先要准备一个可复现的试验环境。下面以 Gym 为基础搭建一个极简的任务分发原型：集群由若干计算单元构成，各单元具备处理上限并以 FIFO 方式排队处理请求。请求随时间产生，智能体需为每个请求挑选目标机器承接，环境返回等待时长的反向得分，等待越短得分越高。
