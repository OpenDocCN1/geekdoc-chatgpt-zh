# 国家社科基金与教育部人文社科申报核心要点

申请书第二页是“申请人承诺”与“填写说明”。打印完成后务必在承诺栏“申请人（签章）”处亲笔签名，同时填写说明必须逐条阅读，否则容易在细节上失分。

整份申请书共分七大块：数据表、课题设计论证、研究基础、经费概算、申请人所在单位审核意见、省级社科规划管理部门或在京委托管理机构审核意见、评审意见。其中前四块由申请人本人完成。

### 1. 数据表
数据表用于呈现课题基本信息，含课题名称、关键词、项目类别、学科分类、研究类型、负责人及成员信息、预期成果类型与字数、申请经费、计划完成时间等。填写前必须对照“填写数据表注意事项”，未逐条核对极易出现低级错误。

要点提醒
1. 课题名称一般不设副标题，控制在40个汉字内含标点。
2. 关键词不超过3个，词间空一个汉字位。
3. 数据表里的学科分类填二级学科代码及名称，封面填一级学科名称，两者不同。
4. 课题组成员必须是实际参与研究的人员，不含负责人，也不含科研管理、财务、后勤类人员。
5. 预期成果字数以千字计，非万字。
6. 结项成果原则上要与预期成果一致，形式需提前想清楚。
7. 预期成果可多选但不宜过多，如已选专著不必再选研究报告，同时提交会提高结项难度。
8. 申请经费单位为万元，填阿拉伯数字。重点项目35，一般和青年项目20，写35或20，不要写35万。
9. 完成时限参考公告：基础理论3-5年，应用对策2-3年。跨度过长或过短都不合适。1-2年完成基础理论不现实，已有部分研究可考虑后续申请后期资助。
10. 成员信息需征得本人同意并在纸质申请书上签字。同年度申请人只能申报一个国家社科项目且不能作为成员参与其他项目；成员同年度最多参与两个项目；在研国家级项目成员最多参与一个项目。组建团队时要提前沟通确认。

### 2. 课题设计论证
这是申请书的核心，包含选题依据、研究内容、创新之处、预期成果和参考文献。内容与活页有重叠但不完全相同，不能直接复制。填写说明已提示活页与表二内容略有不同。

撰写时须按说明逐条论证，注意详略。选题依据的研究价值部分不能泛泛而谈，要写清本课题对已有研究的独特学术价值和应用价值，特别要对照国家社科已立同类项目的新进展。务必使用当年版本的申请书，公告发布后要下载最新空表研读后再填，避免因沿用旧版被认为态度不严谨。

二、课题设计论证
本表参照以下提纲，逻辑清晰，主题突出，层次分明，内容翔实，排版清晰。
1. 选题依据 国内外相关研究的学术史梳理及研究动态略写；本课题相对于已有研究的独到学术价值和应用价值等，特别是相对于国家社科基金已立同类项目的新进展。
2. 研究内容 本课题的研究对象、框架思路、重点难点、主要目标、研究计划及其可行性等。框架思路需列出研究提纲或目录。
3. 创新之处 在学术思想、学术观点、研究方法等方面的特色和创新。
4. 预期成果 成果形式、使用去向及预期社会效益等。略写。
5. 参考文献 开展本课题研究的主要中外参考文献。略写。

### 3. 研究基础
研究基础用于评判课题可行性与申请人驾驭能力，包括学术简历、前期成果、承担项目、与已承担项目或博士论文的关系。

特别注意底部说明：前期相关代表性研究成果限报五项，成果名称、形式须与课题论证活页一致，活页不能填写的作者、刊物、出版社、发表时间等信息要在本表注明；无关成果不能列入；合作者需注明排序。应从前期成果中挑选与拟申报课题关联最紧密、最具代表性的五项，且为申请人本人成果，课题组其他成员成果不可代替。按重要程度排序。项目类成果不要放入前期成果；合著需注明申请人排序。

公告要求以博士学位论文或博士后出站报告为基础申报的，需在申请书中阐明与学位论文或出站报告的联系和区别，并承诺在原基础上实质性修改，预期成果与原论文重复比例不得超过60%，实质上是后续研究而非简单修改。

三、研究基础
本表参照以下提纲，填写内容真实准确。
1. 学术简历 申请人的主要学术简历、学术兼职，在相关研究领域的学术积累和贡献等。
2. 前期成果 申请人前期相关代表性研究成果、核心观点及社会评价等。
3. 承担项目 申请人承担的各级各类科研项目情况，包括项目名称、资助机构、资助金额、结项情况、研究起止时间等。
4. 与已承担项目或博士论文的关系 凡以各级各类项目或博士学位论文博士后出站报告为基础申报的课题，须阐明已承担项目或学位论文报告与本课题的联系和区别。略写。

### 4. 经费概算
2023年度起经费概算表做了简化，使用自由度提升。填写前务必阅读《国家社会科学基金项目资金管理办法》财教〔2021〕237号，按办法填列金额。金额单位为万元，间接费用一般按申请经费总额的40%填写。

### A 表填写
填写时需点击按钮完成四项：项目基本信息、申请人基本信息、课题组成员信息、经费预算。填写后信息自动回填至评阅书并呈灰色，不可直接修改，需重新点击按钮编辑。

1. 项目基本信息
项目类别分基础研究、应用研究、试验研究。试验发展指利用既有知识开发新产品工艺的系统性研究，人文社科较少见，因设有交叉学科/综合研究门类才设此选项。研究期限为三年，计划完成时间据此填写。

2. 申请人信息
先确认资格，避免写完后才发现不符合。限全国普通高校申报，申请人须在编在岗教师，能承担组织研究，每人限报一项。规划基金申请人应具有高级职称含副高，青年基金申请人应具有博士学位或中级以上职称，年龄不超过40周岁。

设有“申请者本人近三年来主要研究成果”项，需注明刊物年期或出版社出版日期，限800字。注意该项不要求成果必须与拟申报课题相关，可列近三年所有主要成果。承担的项目信息不在此填，应填至“申请者作为负责人承担省级以上社科研究项目情况以及完成情况”栏目，该栏目无近三年限制。

3. 课题组成员信息
填写除负责人外的成员，职称年龄无限制，可不填成员，但团队合作更有优势，最多不超过9人。必须征询每位成员同意后填入，否则视为违规。不能因曾征求过就不再确认。

与国家社科不同，设有“课题组成员近三年来与本课题有关的主要研究成果”项，限800字，要求成员成果与本课题有关。这提示组建团队时要关注成员近三年的相关成果，成果过少则说明关注度或能力可能不足。

4. 经费预算
规划基金资助不超过10万元，青年基金不超过8万元。自筹经费项目经费由申请人自筹，不低于8万元，需在“其他来源经费”处填写数额并上传学校财务处提供的到账凭证或银行回单等证明。
