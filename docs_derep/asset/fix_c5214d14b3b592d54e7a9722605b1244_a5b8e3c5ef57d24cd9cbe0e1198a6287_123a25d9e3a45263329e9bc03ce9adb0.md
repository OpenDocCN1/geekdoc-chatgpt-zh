ARmedium % AR for medium objects: 32² < area < 96²

  ARlarge % AR for large objects: area > 96²

[PRE0]
目标检测的评估体系里，交并比 IOU 是衡量定位精度的通用标尺。阈值设定常见两种做法：一种是让 IOU 从 0.5 起每隔 0.05 上提到 0.95，逐点算出 mAP 再求平均值；另一种是仅在 0.5 与 0.75 两个锚点上分别给出平均精度。除了整体 mAP，指标还会按目标尺度拆成小、中、大三档分别呈现。平均召回率 AR 也是业内常用的汇总性度量。

视觉问答类基准在准确率之外，经常引入衡量预测分与人工打分吻合程度的相关性指标，比如皮尔逊线性相关系数 PLCC、斯皮尔曼秩相关系数 SROCC、肯德尔秩相关系数 KROCC，以及表征绝对误差的均方根误差 RMSE。
