计算机系统全貌与冯·诺依曼思想

把计算机视作有机整体并不夸张，其运作思路与大脑颇有共通之处。整套装置由硬体与软体两大部分搭起，如图 3.1 所示。它能够接收来自外部或使用者的信息并加以保存，自动完成各类信息的加工，再把结果反馈回去。相较生物智能，机器展现出运算速度快且精准、存储规模巨大、通用性强易于上手、可构建庞大网络的特性。如今已深度介入科研运算、工业流程控制与日常事务处理，重塑生活方式，推动社会发展。

## 3.1　冯·诺依曼体系结构

### 3.1.1　冯·诺依曼体系结构

冯·诺依曼被公认为计算机之父，关键在于他提出并设计了冯·诺依曼体系结构，如图 3.2 所示。该结构以二进制为基础，按程序顺序逐条执行指令。这一结构成为现代计算机的基石，也奠定了系统结构研究的起点。在该体系下，整机由控制器、运算器、存储器即内存与外存、输入设备、输出设备五大部件构成，如图 3.3 所示。

图 3.2　冯·诺依曼

[PRE2]

图 3.3　计算机五大组成部件

在冯·诺依曼式机器里，程序与数据共存于同一存储空间，指令与数据的位宽一致，通过地址实现线性存取，借助五个基本部件完成指令控制与数据搬运。该结构具备以下能力。

1. 将所需程序与数据装入机器。
2. 长期保存程序、数据、中间结果及最终运算结果。
3. 完成算术运算、逻辑运算与数据传送等加工处理。
4. 按需改变程序走向，并依据指令协调各部件协同工作。
5. 按要求把处理结果输出给使用者。

### 3.1.2　冯·诺依曼体系结构与哈佛体系结构的比较

哈佛结构与冯·诺依曼结构不同之处在于程序与数据分置于各自的存储器，程序计数器仅指向程序存储空间而不指向数据存储空间，因此无法自行修改运行中的程序。但分离设计让程序与数据位宽可以不同，整体效率更高，尤其在数字信号处理领域表现突出，例如 ARM10 系列、摩托罗拉公司的 MC68 系列、Zilog 公司的 Z8 系列等。

### 3.1.3　冯·诺依曼体系结构的局限

冯·诺依曼体系采用二进制表达数据，这既体现了进制本身的简洁，也符合当时物理器件的限制。然而人脑神经元的构造远超出二进制逻辑的表达范围，计算机依赖存储器的线性运算方式与人脑依托记忆的非线性运算也有本质差异，由此在一定程度上制约了计算机的发展。当前兴起的量子计算在逻辑单一性上实现了突破。

### 3.2.2　微型计算机的工作原理

依据冯·诺依曼的设想，计算机基本工作方式是存储程序与程序控制。

存储程序是指把程序和运行所需的数据通过一定方法送入并保存在存储器中。

程序控制是指机器运行时依序自动取出每条指令并加以分析执行。

从定义可知，运行过程涉及两种信息流动——数据流与控制信号。数据流指指令与原始数据，均以二进制编码，在执行前已置入主存。运行时数据送往运算器，指令送往控制器。控制器依据指令内容发出控制信号，各部件据此执行相应运算与操作，并推动流程推进。

计算机之所以能完成各类操作，核心在 CPU，即中央处理器。CPU 能控制一组操作程序的正常执行，比如从存储器中读取数据，或完成加减乘除并保存结果。每项动作对应一条指令，CPU 接收指令后就执行对应动作。程序就是指令序列，执行程序即让 CPU 依次完成一系列指令，从而实现复杂任务。抽象来看，执行过程是 CPU 不断循环取指令与执行指令，直到程序结束或遇到停止指令，有时也可能陷入无限循环即死机。

另一个核心部件是内部存储器。早期存储器仅保存正在处理的数据，CPU 执行指令时从中取出数据，执行后把结果写回。冯·诺依曼提出程序也应存入存储器，CPU 按需取出指令并执行，再循环往复。这样机器可摆脱外部干预自动运行。该基本思想称为存储程序控制原理。遵循此原理的机器称为存储程序控制计算机，也称冯·诺依曼计算机。

#### 1.CPU 的组成及工作

CPU 主要由运算器与控制器构成，包含运算逻辑部件、寄存器部件与控制部件，如图 3.13 所示。

[PRE12]

图 3.13　`CPU`组成及其与内存关系

运算逻辑部件可执行定点或浮点算术运算、移位运算、逻辑运算，也能进行地址运算与转换。

寄存器部件包括通用寄存器、专用寄存器与控制寄存器。通用寄存器用于保存指令中的寄存器操作数与操作结果，可分为定点与浮点两类，其宽度决定内部数据通路宽度，端口数量往往影响内部操作的并行度。专用寄存器用于特殊操作。控制寄存器用于指示机器运行状态或保存指针，包括处理状态寄存器、地址转换目录基地址寄存器、特权状态寄存器、条件码寄存器、异常处理寄存器与检错寄存器等。

控制部件即控制器，是指挥各部件按指令要求协同工作的核心，由指令寄存器 IR、程序计数器 PC 与操作控制 OCsange 部件组成。它负责指令译码并发出完成每条指令所需的控制信号。控制器有两种主流方式：以微存储为核心的微程序控制方式，以及以逻辑硬布线为主的控制方式。微存储中保存微码，每个微码对应一个基本微操作即微指令，各条指令由不同序列的微码构成，形成微程序。CPU 译码后按时序发出控制信号，以微周期为节拍执行微码确定的微操作序列，完成指令执行。简单指令由 3～5 个微操作组成，复杂指令则需几十甚至几百个微操作。逻辑硬布线控制器完全由随机逻辑实现，指令译码后通过不同逻辑门的组合发出控制时序，直接执行指令各操作。

部分 CPU 内置缓存，用于临时存放数据与指令，缓存越大运算速度越快，目前中高端 CPU 通常配备约 2M 的二级缓存，高端产品约 4M。

#### 2.CPU 主要性能指标

1. 字长：计算机一次能处理的二进制位数，常见有 8 bit、16 bit、32 bit、64 bit 等，越来越多微机采用 64 bit。
2. 运算速度：单字长定点指令的平均执行速度，即每秒执行指令数，也称工作频率，通常以 MH 与 GH 为单位，目前多数 CPU 主频已达 GH 级。
3. 时钟频率：CPU 外部时钟频率，直接影响 CPU 与内存间数据交换速度，也影响高速缓存 128 KB～2 MB 的速度。
4. 内存容量：计算机内存大小，通常以 MB 计，1 KB=1024 B，1 MB=1024 KB。

### 3.3.2 总线

微机系统采用以总线为中心的架构，总线是连接各功能部件的信息通道。按数据传送范围可分为四级：片内总线、片间总线、系统内总线、系统外总线，如图 3.14 所示。①片内总线在芯片内部连接各元件；②片间总线连接主板上各芯片；③系统内总线连接主板与扩展板；④系统外总线连接微机与外设。按功能分有三类：数据总线 DB，宽度等于字长，条数取决于 CPU 字长，传输双向；地址总线 AB，条数决定内存大小，传输单向；控制总线 CB。

[PRE13]

图 3.14　总线分级

总线性能指标包括：

1. 总线带宽：单位时间内总线可传输的数据量，单位为 B/s。
2. 总线位宽：总线能同时传输的数据位数，即数据总线 DB 的宽度。
3. 总线工作频率：总线时钟频率，单位为 MHz。

[PRE14]

常用总线标准有 ISA、EISA、VESA、PCI 总线，通常指系统内总线所遵循的标准。

### 3.3.3 内部存储器

内存是利用半导体技术制成的电子设备，用以存储数据，如图 3.15 所示。电子电路以二进制方式存储数据，存储器的每个单元称记忆元。按用途可分为主存储器与辅助存储器，主存储器即内存储器简称内存。程序与数据均存于存储器中，其容量与存取速度直接影响系统性能。

图 3.15　内存

主存储器包括随机存储器 RAM，运行时保存程序与数据，分静态 SRAM 与动态 DRAM；只读存储器 ROM、可编程只读存储器 PROM 与可改写只读存储器 EPROM。RAM 可读写，断电后数据丢失；ROM 不可写，断电后数据保留。

高速缓冲器 Cache 位于 CPU 与内存之间，如图 3.16 所示，读写速度高于内存。分为一级缓存 L1、二级缓存 L2、三级缓存 L3。

### 3.3.4 外部存储器

外部存储器是指除内部存储器与高速缓存外的存储器，断电后仍能保存数据，数据交换率较低但容量大、可移动、可靠性高。常见类型有硬盘、软盘、光盘与 U 盘，如图 3.18 所示。

[PRE18]

图 3.18　外存

硬盘是电脑主要存储介质之一。容量是最核心参数，以兆字节、千兆字节或百万兆字节计。除容量外，还包含以下关键指标。

1. 转速：硬盘盘片每分钟最大转数，转速决定档次与传输速率。硬盘传输速率指读写速度。硬盘内置一块内存芯片，作为内部存储与外界接口间的缓冲，调节传输速率。
2. 盘面号：又称磁头号，每个盘片有两面，每面对应一个读写磁头。盘片组通常 2～14 片，一般 2～3 片，故磁头号为 0～3 或 0～5。格式化后磁盘被划分为同心圆磁道，所有盘面同磁道构成圆柱即柱面。系统以扇区形式在硬盘上存储信息。
