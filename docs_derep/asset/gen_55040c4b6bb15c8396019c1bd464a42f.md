InstructGPT 是怎么学会真正听话的

来源：Long Ouyang, Jeffrey Wu, Xu Jiang, Diogo Almeida, Carroll Wainwright, Pamela Mishkin, Chong Zhang, Sandhini Agarwal, Katarina Slama, Alex Ray, John Schulman, Jacob Hilton, Fraser Kelton, Luke Miller, Maddie Siemens, Amanda Askell, Peter Welinder, Paul F. Christiano, Jan Leike, Ryan Lowe. Training Language Models to Follow Instructions with Human Feedback. In Advances in Neural Information Processing Systems

整体思路可以拆成两条技术路线，一条是监督式微调 SFT，另一条是基于人类反馈的强化学习 RLHF，后者要先训一个奖励模型再做强化训练。下面分别展开。

在 Few-shot 模式下，GPT-3 对同一任务往往用一套固定的描述模板，这和真实用户的使用习惯差距很大。真正的人不会刻意模仿模板，而是用自己的口吻表达需求。InstructGPT 的监督微调就是为了解决这个错位。训练时先从真实用户请求里抽样任务描述，再由标注员对描述进行续写，得到高质量的问答对，最后用这些真实任务和真实答案对模型做微调。

RLHF 的做法更直观，就是让模型生成的内容被打分，符合标准的回答给高回报，鼓励它多产出；不符合标准的给低回报，抑制它。人工给分成本高、效率低，于是用奖励模型来模仿人类评判。具体做法是让模型对同一问题生成多篇文本，由评分员按好坏排序，然后用排序数据训练奖励模型来复现人类偏好。训练目标本质上是回归，但为了适配生成文本的多样性，奖励模型通常会与主模型保持相近的体量。训好后，就能用它代替人工对 GPT 做强化学习。

训练时先用 GPT 生成一篇文章，再用奖励模型给摘要打分，并借助 PPO 算法优化 GPT。优化目标为

E_{(x,y)~π^RL_φ}[r_θ(x,y) − β log\frac{π^RL_φ(y|x)}{π^{SFT}_φ(y|x)}] + λE_{x~π_pretrain}log π^RL_φ

其中，第一项对应 PPO 的优化，r_θ(x,y) 是已训练的奖励模型，π^RL_φ(y|x) 为强化学习后的模型，φ 为待优化参数。答案得分越高，越贴合人类喜好，最大化该项就是让模型更迎合偏好。随着更新，RL 模型产生的数据会与奖励模型训练数据逐渐偏离。为避免偏离过大，引入 KL 散度惩罚 β log\frac{π^RL_φ(y|x)}{π^{SFT}_φ(y|x)}，β 为超参，π^{SFT}_φ(y|x) 来自监督微调模型。第二项是为了防止能力坍缩。只靠 PPO 会让模型在通用 NLP 任务上大幅下滑，因此加入 λE_{x~π_pretrain}log π^RL_φ 让模型分布与预训练数据对齐，λ 控制强度，

π\_pretrain 是训练前数据的分布。如图 8-16 所示，InstructGPT 模型（PPO-ptx）及没有预训练混合的其他变体（PPO）明显优于 GPT-3 基线模型（GPT、GPT（prompted））。

# 8.2.5 Visual ChatGPT

前面讲的 GPT 技术基本都局限在纯文本。实际应用往往需要图文等多模态的交互。Visual ChatGPT 就是把 ChatGPT 和视觉基础模型 VFM 结合起来做多模态问答的系统。VFM 通常指计算机视觉里的基础算法集合，比如 Stable Diffusion、BLIP、ControlNet 等，它们把通用视觉能力迁移到具体应用并作为复杂系统的基石。

Visual ChatGPT 把一系列 VFM 接到 ChatGPT 上，让用户可以用文字和图像同时与模型对话，并支持复杂的视觉指令，让多个模型协同。除了像普通 ChatGPT 那样的语言问答，它还能基于输入图片做视觉问答 VQA、生成与修改图片、去除不需要的元素等。系统还能理解搜索、查询类指令，并具备修改和改进输出的反馈回路，可以根据反馈不断调整。

图 8-17 是一个使用 Visual ChatGPT[325]的实例，用户上传了一张黄色花朵的图片，并输入了一个复杂的语言指令：“请基于预测深度生成一朵红色的花，然后让它像卡通画一样。请一步一步地完成”。在 Prompt Manager 的帮助下，Visual ChatGPT 启动了相关的视觉基础模型的执行链。在这种情况下，首先应用深度估计模型来检测深度信息，然后利用深度到图像（Depth-to-Image）的模型生成带有深度信息的红花图像，最后利用基于 Stable Diffusion 风格转换的视觉基础模型，将此图像的风格转换为卡通风格。在上述管道中，Prompt Manager 作为 ChatGPT 的调度器，提供了视觉格式的类型，以及记录了信息转换的过程。最后，当 Visual ChatGPT 从 Prompt Manager 获得“卡通”的提示时，它将结束执行管道并显示最终结果。

为了在 ChatGPT 和视觉基础模型之间创建一个高效的连接，团队设计了一系列“提示”，并将视觉信息“注入”ChatGPT。一种新型 Prompt Manager 指定了每个视觉基础模型的能力，以及输入、输出格式，并将不同的视觉信息转换为语言格式，以便 ChatGPT 能够理解和处理。此外它可以处理不同视觉基础模型之间的历史记录、优先级和冲突。Visual ChatGPT 利用这个视觉基础模型集合的反馈，迭代地构建其视觉理解和生成能力。图 8-18 为 Visual ChatGPT 的系统架构。

# 扩散模型：生成式AI模型的理论、应用与代码实践

## 8.3.1 算法研究

从算法层面看，扩散模型和 GPT、大模型一样都走生成式预训练路线，可能的研究方向包括：

- 当数据量和参数量持续上涨时，GPT 类大模型会出现性能持续提升并在某个节点跃迁，出现涌现能力。扩散模型是否具备同样的增长规律、是否会有涌现现象值得探索，但训练成本极高，如何在放大参数时控制优化难度也是关键。
- ChatGPT 等系统的重要提效手段是在训练中引入基于人类反馈的强化学习微调，用奖励模型对齐偏好。把这种做法迁移到扩散模型中，用基于人工标注的 Reward Model 进行强化微调，有望在 Human Evaluation 维度带来明显提升。
- LLaMA[326] 等大模型开源后，社区兴起只改少量参数的适配器微调思路，不动主干模型，通过指令集和适配器挖掘已有知识。类比来看，如何用低成本方式微调 Stable Diffusion 等扩散模型以适配新任务，比如 ControlNet，是值得深入研究的。

## 8.3.2 应用范式

从应用来看，GPT 类大模型已能覆盖大量任务，扩散模型的应用形态仍在探索中：

- 目前扩散模型在条件生成上表现突出，能输出逼真且符合提示语义的样本。但在认知推理、少样本泛化等领域的研究较少。把扩散模型拓展到更多应用范式，逼近 GPT 类模型的应用广度，对释放其潜力很重要。
- Visual ChatGPT 里扩散模型被当作 VFM 使用，多模态问答中自然语言和多模态特征都很关键。开发语言扩散大模型乃至多模态扩散大模型，以及研究不同模态的扩散模型如何与基于 LLM 的大模型协同，都是下一步方向。
