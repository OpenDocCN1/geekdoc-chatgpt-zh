机器学习是多学科融合的交叉领域，吸纳了概率论、统计学、近似理论以及复杂算法等知识体系，以计算机为实现工具，追求对人类学习方式的实时逼真模拟，并通过对已有知识进行结构化重组来提升学习效率。根据训练样本所提供的信息完整度与反馈机制的不同，机器学习可归纳为监督学习、无监督学习和强化学习三类。分类是机器学习的重要应用方向，其核心是在数据库对象中提取共性特征，再依托分类模型完成归类。聚类算法则基于“物以类聚”原理，通过测算个体或类群之间的相似程度，将相似度达标的对象归并为同一类，不达标的划分为不同类，最终实现类内高度同质、类间明显异质的划分结果。

## 12.1 Python 语言基础知识

### 12.1.1 Python 语言

Python 是一种兼具解释性、编译性、交互性和面向对象特性的高级脚本语言，其设计强调代码可读性，语法风格区别于其他语言。

Python 属于解释型语言，开发过程中省去显式编译环节，与 PHP、Perl 类似；同时具备交互性，可在提示符 “>>>” 后即时执行代码；作为面向对象语言，支持面向对象的编程范式与代码封装；对初学者友好，可用于从简单文本处理到 WWW 浏览器、游戏等多种应用开发。

Python 具有以下特点。

（1）易于学习：关键字少、结构简洁、方法明确，上手门槛低。
（2）易于阅读：代码可读性高。
（3）易于维护：可读性强使得维护成本降低。
（4）拥有丰富的标准库：库资源丰富且跨平台兼容性好。
（5）交互模式：可在终端直接运行调试。
（6）可移植：开源且可移植到多种平台。
（7）可扩展：不愿公开的算法可用其他语言实现后在 Python 中调用。
（8）数据库：提供主流商业数据库接口。
（9）GUI 编程：支持 GUI 开发并可移植到多系统。
（10）可嵌入：可嵌入 C/C++ 程序赋予脚本化能力。

## 12.1.5 列表、元组、字典和集合

Python 编程既需独立变量保存数据，也需序列保存大量数据。序列按特定顺序排列，可占用连续内存或分散存储。Python 序列类型包括列表 list、元组 tuple、字典 dict 和集合 set。

列表和元组都按顺序保存元素，占用连续内存，通过索引访问。区别在于列表可修改，元组不可修改。字典和集合存储元素无序，各元素占用不同内存，字典以 key-value 键值对形式保存。

### 1. 列表

列表是 Python 最常用的数据类型，可完成多数集合类数据结构，支持字符、数字、字符串，甚至嵌套列表。用 [] 标识，是最通用的复合类型。

创建格式为 listname=[e1, e2, e3..........en]，listname 为变量名，e1~en 为元素。例如：

list=['runoob',786,2.23,'john',70.2]

tinylist=[123,'john']

也可创建空列表。

列表支持切片，可取部分数据，格式为 [头下标:尾下标]，从左到右索引默认从 0 开始，从右到左默认从 -1 开始，下标可空表示取到头或尾。创建并读取示例代码如下：
