# 前言

ChatGPT这种可通过图灵测试、达到一定人类智能水准的对话智能体，于2022年末在自然语言处理领域实现突破。以深度学习为代表的弱人工智能历经十年积累后实现自我超越，通用人工智能时代已然临近。

上世纪九十年代初，我在博士后期间主要从事人工神经网络与强化学习研究。自2009年起，工作重心转向面向自动驾驶与移动机器人的计算机视觉。2017年6月，谷歌发布的Transformer模型以自注意力机制为核心，引起我的高度关注，并推动我在视觉领域开展相关研究。ChatGPT类大语言模型的核心任务主要集中在NLP，体系化撰写基础著作是否合适，始终是我思考的问题。

所幸，经过大量文献梳理发现，除NLP任务本身与评测外，大语言模型及其支撑方法、工具几乎都能用神经网络统一表述，这令我颇感惊讶。也印证了自2012年AlexNet问世、掀起以深度学习为代表的第三次人工智能浪潮以来，基于端到端数据驱动的深度神经网络学习方法已走得相当深远，不仅主导了NLP、CV、语音识别与合成等方向，还在逐步抹平学科边界，迈向统一。

人工智能的定义是模拟、延伸、拓展人类智能的理论、技术与应用的综合学科。判断标准在于任务完成的能力与水平，以及任务的广度、深度与厚度。若数据智能体能高效完成人类擅长的复杂任务，并在整体水平上达到或超越人类平均值，即可视为对人类智能的外在功能模拟。

ChatGPT等生成式模型在文本单模态上复刻了人类语言智能与思维，拥有更为宽广的常识储备，并具备自监督的开放域学习能力。算力进化远超生物算力，叠加外部工具使用能力、多模态与具身智能的加速演进，相当于为大脑与小脑装上眼耳口手脚。通用人工智能新物种的发展潜力令人期待，但也需在国际共识下加强安全监管，提前防范风险。

1943年，心理学家W. McCulloch与数理逻辑学家W. Pitts在论文*A Logical Calculus of the Ideas Immanent in Nervous Activity*中提出MP人工神经元模型，开启了以数学输入输出表达模拟人脑功能的历史。1957年，F. Rosenblatt基于MP模型提出“感知机”，被视为生物神经系统感知的简化模型。1986年，D. Rumelhart与G. Hinton等人提出多层感知机的误差反向传播算法，突破了多层前馈网络的监督学习难题。2012年，Hinton带领团队提出AlexNet，将LeCun与Bengio于1995年提出的卷积神经网络与大数据、GPU结合，在ImageNet竞赛中取得惊人表现。2016年AlphaGo及深度强化学习进一步强化了这一趋势。

序列建模方面，Elman网络在1990年引入记忆机制，1997年LSTM借助门控缓解梯度问题。2017年Vaswani等人摒弃递归与卷积，提出Transformer，并在编码器或解码器堆叠下完成序列表达、理解与生成。OpenAI于2015年12月11日成立后迅速改造语言模型，2020年5月推出1750亿参数的GPT-3。随后于2022年11月30日与2023年3月14日分别发布ChatGPT与GPT-4，文本单模态的ChatGPT与图文多模态的GPT-4均出现智能涌现，展现出接近人类水平的通用能力，并持续向物理世界拓展。

人类大脑约有860亿个神经元，每个神经元连接1000至1万个突触，总突触规模最高可达860万亿。GPT-4已达1.8万亿参数，在“超摩尔定律”下算力平均每两年增长约275倍，喂养更高阶多模态数据后，逼近百万亿量级、触及人类大脑天花板的时刻或许不会太久。大模型一旦越过临界规模，多任务求解能力是否会质变？是否会涌现符号级语义理解、逻辑推理、自主意图与意识等高级认知？仍待观察。

大模型的价值在于应用。唯有在多元场景中赋能智能经济与社会，才能显现产业价值，也才能反哺模型自身。具备语言智能与常识的大模型迭代需要下游任务适配、涌现、价值与安全对齐、幻觉矫正、混合专家等模块化设计，这些都依赖开放域的真实交互反馈。中国大模型发展应突出行业应用，打造定制化垂域大模型，依托行业专业数据形成优势。算力基础设施、智能云式分布式集群同样关键。算法与模型、数据与知识、芯片与算力、场景与产业需求共同构成AI生态，是国际竞争的决胜因素。

人工智能将带来辉煌未来，也将重塑就业、认知边界、价值、法律、伦理、道德等，并在学习与知识传承方式上引发反思。掌握并能利用人工智能基础知识的人，将在持续演进的世界中具备更强竞争力。

# 第1章 人工神经网络基础

本章学习目标与知识点
- 掌握四种人工神经元模型的区别
- 熟练理解全连接前馈神经网络结构及其误差反向传播算法
- 了解深度卷积神经网络的基本概念与原理

本章先介绍四种人工神经元模型与三种典型人工神经网络模型，重点阐述全连接前馈网络结构、误差反向传播算法及深度卷积神经网络，为后续章节奠定基础。

## 1.1 引言

1943年，心理学家W. McCulloch与数理逻辑学家W. Pitts提出首个人工神经元模型MP模型，开启了用数学模型模拟人脑部分功能的历史。1949年，D. O. Hebb提出突触可塑性原理，形成Hebb学习规则，成为无监督学习与记忆痕迹构建的基础。1957年，F. Rosenblatt提出感知机，将其视为生物感知外部刺激的简化模型，被誉为“神经网络之父”。早期单层与多层感知机使用二值MP模型。1962年，Widrow提出自适应线性元件adaline，实现连续取值线性网络，神经网络研究进入第一次高潮。1969年，M. Minsky与S. Papert出版《感知机》，指出线性感知机无法解决线性不可分问题，需引入隐层，但当时缺乏有效学习算法，神经网络研究进入低谷。

进入八十年代，J. J. Hopfield于1982、1984年发表论文，提出同层神经元全互联的网络并定义能量函数，可用于联想记忆与优化计算，后称Hopfield网络，曾成功求解旅行商问题。1986年，D. E. Rumelhart与G. E. Hinton等人提出多层前馈感知机的误差反向传播算法BP，成为深度卷积神经网络与Transformer的主流学习方法。Hopfield网络与BP算法的提出推动神经网络复兴，1987年美国召开首届国际神经网络联合大会，研究进入第二次高潮。Hopfield与Hinton因上述贡献获2024年诺贝尔物理学奖。

学术成功并未带来产业价值，研究在2000年前后再次低迷。2006年，G. Hinton提出深度置信网络等深度学习方法。2012年Hinton提出Dropout正则化方法，同年其博士生与Hinton将LeCun等人提出的卷积神经网络与大数据、GPU结合，推出AlexNet，在ImageNet上取得惊人成绩，掀起第三次研究热潮。随后出现NIN、VGG、GoogLeNet、Inception、批归一化BN、ResNet、空洞卷积、DenseNet、FPN、ResNeXt、ResNeSt等改进结构，分类性能不断提升并接近人类水平。

深度卷积网络的另一重要进展在目标检测与分割。典型成果包括R-CNN、Fast R-CNN、Faster R-CNN、U-Net、YOLO、SSD、R-FCN、MS-CNN、RetinaNet、YOLOv3、Mask R-CNN、PointNet、Complex-YOLO、全景分割、YOLOv4、EfficientDet、YOLOv5等。

2012年后的人工智能第一波核心突破是深度卷积网络，第二波是2016年谷歌DeepMind的AlphaGo，将强化学习、深度卷积网络与蒙特卡洛树搜索结合，实现从零自学的棋类通用人工智能，引发强烈关注。

从ChatGPT与大模型进展看，2017年谷歌提出的Transformer在NLP与CV任务中取得最佳结果。Transformer最突出的成就是GPT-3、ChatGPT、GPT-4。随着规模与泛化性能的单调增长、跨模态通用性及自注意力机制对token序列全局相关性的建模，Transformer可视为新一轮人工智能第三波里程碑。

## 1.2 人工神经元模型

人工神经元模型是模拟生物神经元结构与功能的数学范式。常见模型包括MP模型、加权求和非线性WSN模型、径向基函数RBF模型与发放spiking模型。

表1.1 人工神经元模型

| 人工神经元模型 | 名称 | 定义及主要特点 | 用途 |
| :--- | :--- | :--- | :--- |
| 基准神经元模型 | MP模型 | McCulloch-Pitts神经元：$y = f(w^T x)$，其中$x$、$y$为二值输入输出向量，$w$为输入连接权向量，$f()$为二值非线性激活函数 | 用于早期的单层与多层感知机，可实现简单逻辑运算，是WSN模型的最早雏形 |
