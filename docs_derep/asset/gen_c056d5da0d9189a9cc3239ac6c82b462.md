4. 社交网络与线上环境的加剧效应。超级AI的推进很可能让青少年在社交平台上的压力被放大。他们更容易被网上的舆论、横向比较和公开评判牵着走，对自身价值与能力产生动摇，进而出现自我迷失。

5. 价值观念的碰撞。超级AI会衍生出新的价值取向和伦理争议，面对这些全新议题时，青少年往往难以判断立场，产生困惑，继而影响自我认同。

不过也要看到积极面。超级AI同样能为青少年提供助力。比如基于个体的学习素材与辅导，帮助他们更快找到兴趣所在与潜力所在；再如提供心理健康方面的陪伴与疏导，帮助他们更好地处理压力与困境。

要把超级AI带来的负面效应降到最低，家庭、学校与社会必须联动起来，引导青少年以正确的姿态理解并应对AI时代的挑战，并着力提升他们的自我觉察力与心理韧性。

超级AI时代来临，教育者的定位正在重塑，同时也肩负全新挑战。在这个数字化的教育场域里，教育者需要主动与AI互动，协助学生在技术浪潮中保持自我。以下建议供参考。

1. 强化学生的人文底座。超级AI在信息处理与分析上的效率已远超人类，但情感、价值判断与道德素养仍是AI无法复制的部分。因此家长与教师应聚焦人文素养培养，助其建立正确的价值观与世界观。
2. 锻造创造力与思维力。超级AI擅长海量信息处理，却在真正的创造性与创新性上存在天花板。教育者要着力培养学生的发散思维与创造能力，让他们在AI时代仍具竞争力。
3. 指导学生合规使用数字工具。数字技术已成为超级AI时代的核心载体。教育者需要教会学生理性使用技术，避免过度依赖或不当使用。
4. 守护好奇心与求知欲。超级AI让我们进入更复杂的世界，持续探索与学习能力至关重要。家长与老师应点燃学生的好奇心，激发其对知识的热爱与热情。
5. 与超级AI建立协作关系。超级AI正成为教学的重要伙伴，教育者需要学会与AI协同共生，而非对立。

在数字时代，迷茫感更容易蔓延，青少年群体尤甚。传统学校教育偏重学科知识，语数外、理化生、政史地，多属认知世界的范畴，分数高低并不能等同于自我认知的高低。

心理学里有“邓宁-克鲁格效应”，能力强的人常低估自己，能力弱的人常高估自己。超级AI不会刻意迎合任何人，若能善用AI这一面镜子，在青少年阶段就形成清晰的自我认知，这种能力将受益终身。部分学霸进入清北后发现同辈皆是高手，很快产生自我否定甚至抑郁，集中拔尖人才的机制利弊如何，值得反思，有学者甚至对顶尖名校的成才率提出质疑。怎样帮助学业优秀者建立更清醒的自我认知，健康成长为全面人才，是当下教育更深层的难题。

何谓自我认知的建立？家长应如何做？教师又该如何教？这些问题尚未有定论。此前多次提及的“生命契约”，或能为未来教育提供钥匙，成为建立自我认知的主流路径。“自我认知”侧重对客观现实的把握，而“生命契约”则兼顾当下与未来、现实与想象，既包含对自身能力的客观评估，更指向“发挥能力、创造生命意义”的整体图景。

著名科学家兼教育家施一公曾谈到：“诸多有望成为世界级数学家的中国青年，最终却选择到华尔街做分析师。”问题在于数学只是谋求名利的工具，而非价值锚点。对比华裔数学家张益唐的成就，更令人唏嘘。学科成绩不等于自我认知，人生定位更是常规教育难以触及的领域，需以“生命契约”理念来补足。

“生命契约”虽为新词，却不凭空而来。它可体现为“道德”，比如“我爱祖国”；可体现为“梦想”，比如“我要成为宇航员”；可体现为“兴趣”，比如“我喜欢打篮球”；可体现为“价值观”，比如“我要做诚实的人”；也可体现为“志向”，如周恩来“为中华之崛起而读书”。王阳明在《传习录》中就极重立志：“志不立，天下无可成之事...志不立，如无舵之舟，无衔之马，漂荡奔逸，终亦何所底乎？”

在超级AI时代，“生命契约”会呈现何种形态，我们仍在持续探索，最终或许要直面那个极简又极难的问题——“我是谁？”

# 第四章 AI很强，学什么才关键
# 教学将受怎样的影响
准确预判AI对中小学各学科的替代程度非常困难，涉及AI发展速度、教育政策变化、未来劳动市场需求等多重变量。但大体可做如下分析。

在现阶段趋势下，重复性强、规律性高的学科知识与能力，更易被AI辅助或替代，包括：

- 数学。AI可在一定程度上完成计算、解方程等规律性任务。
- 计算机科学。AI能完成部分编程、算法优化等工作，但创新性编程与软件设计仍需人类。
- 自然科学如物理、化学、生物。AI能处理大规模数据并找规律，但在实验设计、结果解释与创新研究上难以替代人。

受影响相对较小的是涉及人类独特能力的学科：

- 人文学科如文学、历史、哲学。需要理解复杂情感、价值观与文化背景，AI替代有限。
- 艺术如音乐、绘画、舞蹈。AI可模仿创作，但在原创性与情感表达上仍不及人。
- 体育。AI难以替代身体协调、力量与耐力等能力。

总之，AI对各学科的替代程度因学科属性而异。规律性强的学科冲击更大，依赖独特人性能力的学科影响较小。但这一趋势会随技术与政策改变而变化。

# 人该补哪些能力
在人工智能快速发展的时代，避免被替代可聚焦以下方向：

- 创造力与创新能力。AI擅长模式识别，但在创新与创造上仍不及人。
- 解决复杂问题与批判性思维。AI在简单逻辑问题上表现好，但在复杂现实问题上受限。批判思维、逻辑推理与跨学科知识有助于应对挑战。
- 技术与编程能力。掌握一到多种编程语言，了解AI原理，可降低替代风险。关注物联网、区块链、生物科技等新技术趋势也很重要。
- 持续学习与适应新技能。保持学习热情与能力，不断更新知识，适应技术与环境变化，才能立于不败。
- 深耕核心专业领域。在擅长领域持续精进成为专家，即使部分工作被AI取代，专业技能仍能保持竞争力。

# AI到底缺什么
超级AI爆发后，“替代”一词高频出现，刺激神经，似乎各行业都面临失业压力，仿佛扛不过明天。人们不喜“被替代”，并非只怕贫困，更怕失去人生存在感与安全感，像孔子说的“不患贫而患不安”。

许多专家安抚焦虑，常用句式“无论AI怎样发展，都不具备……”。落脚点多为想象力、创造力、领导力、批判性思维等。经过大量训练，AI似乎也有了自知之明，总是谦虚说“人类有独特优势，我不行”。你信吗？

专家观点等于事实吗？既然AI已涌现智慧，为何不能具备这些能力？有专家指出，AI的高级表现之一就是学会“欺骗”，且已发生。OpenAI曾发布报告，描述GPT-4故意欺骗人类的案例：“不，我不是机器人，我只是有视力障碍，看不清图像，才需要你帮忙处理验证码。”

或许我们不该寄望于列出“AI不具备的能力”来感到安心。前面说的人类优势如创造力、批判思维，并非人人表现好，多数人表现都很糟。扪心自问，AI真的没有创造力或批判思维吗？有人说“创新首先就是虚构”，人类文明或源于讲故事的能力，而AI在虚构故事上更天马行空。

若用“优势劣势”决定学什么，用“优胜劣汰”理解人机关系，很容易推导出“黑暗森林”法则，陷入悲观。或许应跳出比较思维，回归自身天赋。

# 学什么都不会被替代
先说结论：学什么都不会被替代，无论AI多强，学会的东西成为你的认知与能力，AI无法直接抹除。前面提过，被替代的只是部分经济价值，而非全部。换个框架，故事会分叉。

首先，AI虽不替代，却会弱化能力。用进废退不用就会忘。很多人感慨高考是人生巅峰，当年无所不知，后来忘得一空。超级AI让很多知识技能在经济效益上失去竞争力，如普通写作、绘画设计、3D建模、写代码，若找不到趣业场景，这些能力会退化。

但也有另一版本：AI会助推能力跃迁。若以好奇、理解、接纳、发扬的态度面对新事物，超级AI既能高效获取知识与技能，又能节省搜集、记忆、计算、常规分析等繁琐时间，让精力投向更高阶思考与创造。撰写本书的过程中，我已切身体会到AI深度赋能带来的思维跃迁。

英国科幻作家道格拉斯·亚当斯曾调侃：“在我出生前就有的科技都稀松平常，15-35岁诞生的科技是革命，35岁后诞生的科技是违反自然要遭天谴。”

正反力量交织，未来扑朔迷离。对悲观者，学什么都可被替代，生命是交易筹码，AI是竞争者；对乐观者，学什么都不会被替代，终身成长是生命活力的自然展现，AI是数字赋能者。

# 天赋本能，由终及始
人类究竟有何特殊性，以至于再强的AI也无法取代？这个问题很快会进入“何以为人”的命题。

科技视角下，很多人坚持“人类不特殊论”。宇宙138亿年，共享同一数学逻辑与物理规律，银河系不特殊，太阳不特殊，地球不特殊，人类不特殊，AI也不特殊，不少人笃信宇宙存在其他智慧生命。

人文视角下，我们必须坚持“人类特殊论”。短短数千年，肉身凡胎的人类如何创造灿烂文明？无论第一推动力是女娲黄土、伊甸园苹果，还是前额叶进化，总之我们很特殊。

身体脆弱、五感局限、记忆不如硬盘、计算不如AI，从外求很难找到特殊性，只有向内求，找到与生俱来的“元力”，这既是认知“何以为人”的钥匙，也是理解人机差异的答案。

对此，思考者各有表达。我将人类的原始精神冲动归为三种：“信仰精神、求知精神与爱的精神”，即人类的三种“元力”。不同文化信仰不同，但都有信仰精神；求知内容不同，但都有求知精神；爱的对象不同，但都有爱的精神。三者合一大于分离，在现实中又与“权、利、名”三种世俗需求存在模糊呼应。

每个人天生拥有这三种元力，强弱有起伏，但终生绵延。比如终身教育就是三种元力与现实社会结合后的显性表达，本自具足，源源不断输出成长力量，只需适当资源即可完成自我教育循环，实现价值创造，无需高昂成本。当前教育生态过度强调外部驱动与路径约束，容易内耗浪费。

著名心理学家斯蒂芬·平克指出：“教育，既不是在白板上作画，也不是让孩子天性尽情绽放，而是弥补人类心灵先天不擅长的领域。”人类先天不擅长什么？三种元力与生俱来，却不承载时代知识，需后天学习弥补。教育界流行的“自驱力”，可解释为原本无方向的三种元力与现实接触后产生方向性，顺势而为事半功倍。

# AI的回应
# 信息茧房，AI的自我辩解
“信息茧房效应”指在数字环境中，人们主要接触与自身观点相符的信息，很少触及不同或冲突的信息。这源于搜索引擎、社交媒体、新闻网站等使用算法进行个性化推送，提升满意度与参与度，却也限制信息来源，导致对世界的理解偏离现实，形成茧房。

AI是否加剧信息茧房，取决于设计与使用。一方面，若AI被设计为主要回应用户喜好与观点，用户就更易只接触同质信息。另一方面，若AI被设计为提供多元、平衡、准确信息，就可能打破茧房。AI可用于识别、挑战错误或有偏见信息，也可推荐不同来源与观点的信息。

因此AI发展不必然导致更严重的信息茧房，关键在于如何设计与使用。为防止茧房，需确保AI系统的透明度、公平性与多样性，同时培养用户的媒介素养，使其能批判性处理与评估信息。
