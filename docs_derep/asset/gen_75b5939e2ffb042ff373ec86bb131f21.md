该公式用 TEXTJOIN 与 IF 组合，其作用是将满足条件的单元格内容拼接成字符串，用指定分隔符“、”分隔。详细解释如下：

#### 公式解析：
[PRE19]
- 1. TEXTJOIN 函数：
- 将多个文本串联成一个字符串。
- 语法：TEXTJOIN(分隔符，是否忽略空值，文本1，文本2，...)
- 参数：
- “、”：分隔符。
- TRUE：忽略空值。
- IF(C2:C10="录取", A2:A10, "")：生成数组作为 TEXTJOIN 的文本参数。
- 2. IF 函数：
- 条件判断。
- 语法：IF(条件，值1，值2)
- 参数：
- C2:C10="录取"：判断 C2:C10 是否等于“录取”。
- A2:A10：条件为真时返回对应值。
- ""：条件为假时返回空串。
- 3. 整体逻辑：
- 遍历 C2:C10，若为“录取”则返回 A2:A10 对应值，否则返回空串，再用 TEXTJOIN 以“、”连接。

图3-43

#### 能解决的问题：
这个公式可实现：
- 筛选并连接数据：从 A2:A10 中取出 C2:C10 为“录取”的对应数据并拼接。
- 动态生成列表：生成以“、”分隔的名单，方便展示或导出。
