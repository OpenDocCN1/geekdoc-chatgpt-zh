- 形式 1：穿戴整齐端坐镜头前做口播；
- 形式 2：一边赶地铁暴走一边举着手机边走边吐槽；
- 形式 3：起床洗漱通勤混乱实录，一天兵荒马乱的打工日常 Vlog

这三类画面估计已经在你脑子里自动播放了。举这个例子并不是要判定哪种更有趣，因为有趣的标准因人而异，我只是想提醒做内容时可以多换呈现方式，让表达更丰富。

#### 3. 内容有趣
感官上的好玩、形式上的切换终究是表层。想让内容真正戳人，需要在内核上下功夫，让读者刷到时心里舒坦、忍不住笑出来。做到这一点不是一蹴而就的，要靠日常有意识的积累和刻意练习，把自己养成熟人设里也自带趣味的人。

### （三）有用
身边常听到这样的抱怨：某某人或某某内容莫名火了，一点用都没有。互联网信息爆炸，垃圾内容很多，但能成为爆款的绝不会是完全无用的。像那些幽默短视频，看似没有提供硬核价值，可在用户划走前会心一笑的瞬间，已经给了情绪价值，只是这种获得感比较短暂。

想让用户多停留、更信任你，就要持续输出有用的信息，延长获得感和满足感。这里的“有用”不只是技能、干货、避坑、知识、经验分享，还包括信息差、以及音乐文学绘画等能满足审美的内容。

总结起来，**能提供情绪价值、实用价值、信息价值、审美价值的内容，都算“有用”。** 每次发之前可以自检一下，至少占到其中一种。

### （四）有共鸣
只要内容做到“有情”“有趣”“有用”之一，就容易引起共鸣。但在咨询中发现很多人不自觉掉进自我中心模式，只考虑自己想写什么，不考虑用户想看什么。

创作者当然有权表达，但个人品牌的内容不是纯艺术，只顾自己发什么很容易自嗨，数据惨淡还拉开距离。创作前不妨先问自己：

1. 这篇内容到底写给谁看？
2. 他们关注什么、关心什么？
3. 能不能给他们价值或解决某个问题？
4. 如果我是他们，不想看到什么？

**用用户视角发声，才能真正被共鸣。** 发声不是无底线讨好，而是在听懂需求后，用自己的知识经验真诚地分享更有情、更有趣、更有用的内容。

## 一人公司生存手册

# 打造长期复利的超级个体

把设计出来的产品服务卖出去，把个人品牌推销出去，一人公司才能真正盈利。看创业者故事、读商业书籍会发现，优秀的创业者和成功的企业家往往都是好销售。对没有销售团队支撑的一人公司来说，销售转化能力是必须刻意修炼的基本功。

怎么提升销售转化能力呢？**销售既是技术，也是心理营销战。** 本章会从销售原理、消费动机、消费心理出发，讲一些能激发购买欲、促进成交的技巧、转化公式和心理学效应。也将重点讨论知识产品、虚拟服务的销售，以及如何把“白嫖”用户转成付费用户。

## 一、万能成交公式：AITDA 模型
我见过很多产品设计、专业能力都很强的人，一到销售环节就无从下手。很多人以为必须口才好、有套话术才能卖东西，其实买卖没那么复杂，搞清楚自己是怎么买进来的，就知道怎么卖出去了。

### （一）怎么把东西买进来，就怎么卖出去
看我最近两次消费。

- 消费经历 1
午休前我在懒人沙发上刷社交平台，偶然点进一个卖秋装的直播间。主播看着顺眼，穿的卫衣也不错，我就在外面逛了一会儿。等主播把身上那件上链接、报了价，我觉得价格可以，就点进去看了详情页和店铺评价。看完后想着快入秋了，直接下单后退出了直播间。

- 消费经历 2
我跟学姐吐槽文科生学心理统计学太难，听课都怀疑智商。学姐给我推荐了一个 B 站 UP 主，说他讲统计学基础特别有意思。我去搜了关注，试听了两节，发现他讲得风趣幽默，就投币订阅了课程。

[PRE1]

[PRE2]
这两次，一次是无意种草，一次是有意寻找。无论有意无意，决定买之前通常具备这几个前提：

1. 产品或卖家先引起了注意和兴趣；
2. 有购买需求，或被创造出需求从而产生欲望；
3. 对产品或卖家产生了一定信任。

把买东西的路径反过来就是卖东西的路径。只要做到：

1. 让用户注意到我或我的产品服务；
2. 激起对我或具体产品的兴趣；
3. 强化或创造购买需求，刺激购买欲望；
4. 让用户信任我和我的产品服务。

距离成交就不远了。

### （二）万能成交公式：AITDA 模型
方法论万能。前文的销售步骤可以用用了上百年的爱达公式 AIDA 的变体 AITDA 来概括。

爱达公式由国际推销专家海英兹·姆·戈得曼总结，四个字母代表：

- A：Attention，在最短时间抓住注意力；
- I：Interest，激发兴趣，让人想继续了解；
- D：Desire，刺激购买欲望，把需求转成想买；
- A：Action，推动付费行动。

[PRE3]
随着场景变化，加入 Trust 信任因素的 AITDA 已成为各行业的成交秘籍。记住 Attention、Interest、Trust、Desire、Action 五个环节去策划宣传，就能让用户心甘情愿付款。

[PRE4]
了解模型后怎么落地？以一条卖本书的短视频脚本为例：

表 5-1 AITDA 模型实际应用示例

| AITDA 模型应用示例：销售本书的短视频文案脚本 |
| :--- |
| A：吸引注意 | 希望所有厌倦上班的人都能刷到这条！我有 8 年没去过公司，却写了一本关于“只干活不打卡”的书 |
| I：激发兴趣 | 若你正被失业焦虑、找不到合适岗位、工作内卷、同事相处难、客户难搞困扰，每天上班像上坟，一刻都想辞职；如果你渴望跳出一眼望到头的社畜 routine，过上不打卡也能赚钱的自在生活，这条内容值得看 |
| T：构建信任 | 我从双非普通本科的农村姑娘，到能只工作不上班的独立创业者，再到签约出版，走过逆袭的完整路径 |
| D：激发欲望 | 从义无反顾离职到如今 8 年自由，独立这些年既有收获也有坑，我都写进书里了。书里还覆盖了如何定位赚钱天赋、打造变现产品、找到客户、让客户主动掏钱、以及收入多元化等常见难题 |
| **A：促进行动** | 考虑到部分人读纸质书吃力，我建了共读群亲自陪读答疑。未来一周每晚 8 点我在某平台开直播，工作生活上的困惑欢迎进来聊 |

从示例能看出，吸引注意、激发兴趣相对容易，难的是建立信任、刺激欲望和促进行动。

关于建立信任，可参考麦肯锡信任公式及个人信任背书。销售文案和沟通中，这两句话术能快速拉近信任：

1. 我曾经__________（困境/迷茫/失败/交流），但是__________（和产品/服务相关的内容），我可以__________（改变/逆袭/成功），你也可以；
2. 我知道__________（目标客户的问题/困惑），我的产品、服务里有答案。

激发欲望和促进行动会在第二节、第三节展开。

## 二、促进用户付费的动机因素
销售中常有困惑：**客户反复咨询，就是不下单。**

主动问说明对产品感兴趣、有需求，不下单的原因可能是：

- 第一，还没建立信任；
- 第二，需求没被转化为强欲望；
- 第三，产品服务某些点不符合预期；
- 第四，价格超出心理价位。

信任和产品迭代前面已讲，价格策略因客群而异暂不展开。本节聚焦如何洞察消费动机，把需求转化为购买欲望。

### （一）需求不是购买理由，欲望才是
前面反复强调要以用户需求做产品和内容，到了转化环节要注意：**需求不是成交理由，欲望才是。**

需求和欲望的区别：

> 今天下班，我好想吃碗米线。——我想怎么样，这是需求。
> 小丽说公司楼下那家烧肉米线很好吃，下班后我要去吃一碗。——我要怎么样，这是欲望。

需求只是大致方向，欲望是有明确目标和路线的需求。

结合我被主播种草买卫衣的例子，可见外部诱因能唤醒内在需求，在内外共同作用下把需求变成欲望，最终变成购买行为；有些诱因直接激发欲望，直接促成成交。比如“小丽说烧肉米线好吃”就直接让我产生了要吃烧肉米线的欲望。

[PRE6]
因此在销售中加入能刺激欲望的外部诱因，会大幅提升成交概率。具体诱因可结合消费心理学中的购买动机来设计。

### （二）激励用户付费的七大动机
消费心理学把购买动机分为求实、求安、求新、求美、求廉、求名、求便、偏爱等。

[PRE7]
图 5-7 常见用户消费动机示意图

其中偏爱动机受个人喜好影响较难干预，剩下几类在实操中可转化为刺激欲望的诱因。

#### 1. 求实动机
用户看重使用价值和实用价值。实用、高效、耐用等关键词容易触发购买。若产品在这方面有优势，可用结果呈现、数据量化、对比举例等方式突出实用价值。比如 AI 写作课可直接展示为学员带来的收益和节省的时间。

#### 2. 求安动机
求安是渴望安全、安定、安心的动机。在安全感稀缺的时代更明显。若产品能带来身安或心安，可在宣传中强调。比如疗愈课程提供心安，职场规划提供成长安全感。

销售中可适当放大客户的不安，营造适度紧张后再给解决方案。常见文案写法是“未来某时代，什么样的人会第一批被淘汰”。注意把握度，别变成恐吓或挖苦。

#### 3. 求新动机
追求商品服务的新颖、奇特、时尚。年轻用户对新事物接受度高。若提供实物，可在视觉上做时尚新颖设计，宣发加入脑洞趣味活动。若是虚拟产品，可展示新知识、新观念、新生活案例刺激欲望，如写作训练营分享学员靠写作实现新生活的故事。

#### 4. 求美动机
重视艺术审美价值或期待美好体验。爱美是天性，把产品、物料、个人形象打扮精致，能提升价值判断。比如选美容院，更容易被做工大气、朋友圈赏心悦目的商家吸引。

也可以用描述美好未来的方式激起当下欲望，比如“这本书能帮你解锁不上班的生活”。

#### 5. 求廉动机
在意价格是否实惠，希望用更少钱买到更高价值。求廉不等于必须低价，折扣、优惠价、限时价、买赠等省钱机制同样有效。这也是网购常把红色优惠价与灰色原价并列的原因。

当客户因价格犹豫时，可给限时优惠或有价值的附赠，让客户感觉在省钱。

#### 6. 求名动机
追求能彰显身份地位的名牌和高档服务。一人公司初期知名度低，可用两种方式：

- 1）给对方一个高配身份
比如沟通时不说教，而是表达：我知道你是一个有远见/有规划/有野心……的创业者/企业家，你对目前企业、品牌的发展是不满足的，只是……专业的事交给专业的人做，我们一起……
- 2）制造稀缺
通过限时、限量、条件门槛等方式营造只有少数人能拥有的稀缺感。

#### 7. 求便动机
希望商品服务带来便利，追求省时省力。对于效率导向用户，节约时间、提升效率、简单上手等关键词是导火索。

销售时可突出高效、便利、简单易上手，同时精简沟通环节，提前准备高频问题，用选择题代替问答题，比如“针对你的情况我有方案 A、B、C，你选哪个”，帮用户省时省力做出决定。

## 三、给客户一个立马下单的理由
AITDA 成交模型最后一步是：促进购买行动。

注意，是**促进购买行动**，而不是直接完成付费行为！
