> **ID3 决策树算法概述**
ID3 即 Iterative Dichotomiser 3，是一类经典的决策树分类方法。它以熵来评估划分的纯度，并选择信息增益最大的属性做节点分裂。整体做法是通过递归挑选最优属性生长树，完成分类任务 [Data: Entities (0); Reports (0); Relationships (0)]。

**熵与增益**
熵用于衡量数据集的混乱程度，熵越低纯度越高。信息增益衡量分裂前后熵的差值，用以判断属性划分的好坏。ID3 在每一步都挑选增益最大的属性向下扩展，逐步形成树形结构 [Data: Entities (0); Reports (0); Relationships (27)]。

**划分方式与离散特征**
ID3 仅能处理离散特征，连续特征需先离散化，例如分箱。它按一列展开的方式进行划分，与 CART 寻找最佳切分点的做法不同。以 AGE 列为例，ID3 会按不同取值把数据拆成若干子集，再计算各子集的熵与增益 [Data: Sources (0, 1); Entities (6, 7, 8, 9); Relationships (10, 11, 12, 13)]。

**局限**
尽管 ID3 在历史上意义重大，仍存在不足：

2. 偏好多值属性：在挑选分裂属性时容易倾向取值较多的属性，易导致过拟合 [Data: Sources (1); Entities (0)]。
3. 缺乏剪枝：没有内置剪枝机制防止过拟合，训练集表现好时测试集可能退化 [Data: Sources (1); Entities (0)]。

ID3 是后续算法的基础。C4.5 在此基础上加入了连续变量处理、剪枝和信息价值等改进；CART 则支持分类与回归，采用二分分裂策略 [Data: Entities (1, 2); Relationships (0, 1, 4, 14)]。
