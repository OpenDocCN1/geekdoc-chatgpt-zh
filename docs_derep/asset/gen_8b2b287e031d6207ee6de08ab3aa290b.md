这套链路把一次搜索请求的原始输出，清洗成可用的链接，再和读取后的内容对齐，最后让模型按时间轴提炼关键节点，整个过程分三步走。

先做链接层面的去重和校验。把批量查询返回的各个结果集逐个遍历，遇到结构异常直接跳过并打印日志，确保不会因为一次格式问题中断。只保留字符串类型且以 http 或 https 开头的地址，并用集合记录已出现过的链接，最终汇总成 urlList 输出。

再做内容层面的对齐。LinkReader 读完后的 processed_content_list 和前面得到的原始 url 列表按位置一一配对，以两者长度的最小值作为安全边界。每次取出标题和正文字段，若索引越界或数据缺失则记录并跳过，形成包含 title、content、url 三个字段的 mergedList。

最后进入信息抽取阶段。针对指定的关键词集合，通读合并后的搜索文本，抓取事件发生的具体时间点及其描述，按照时间先后重新排序，并严格以 JSON 字符串形式返回，每条记录保留 date 和 event 两个键。

async def main(args: Args) -> Output:

    params = args.params

    batch_step_outputs = params['batch_node_output']  # 获取搜索结果列表

    all_urls = []

    seen_urls = set()

    # 遍历每个搜索查询的结果

    for step_output in batch_step_outputs:

        try:  # 添加错误处理以防数据结构不符合预期

            value_list = step_output['data']['webPages']['value']

            # 遍历单个查询返回的网页链接

            for result in value_list:

                url = result.get('url')  # 使用 .get() 更安全

                # 检查 URL 有效性并去重

                if isinstance(url, str) and url.startswith(('http://', 'https://')) and url not in seen_urls:

                    all_urls.append(url)

                    seen_urls.add(url)

        except (KeyError, TypeError, AttributeError) as e:

            print(f"Skipping entry due to error: {e}, Data: {step_output}")  # 记录错误

    ret: Output = {

        "urlList": all_urls

    }

    return ret

async def main(args: Args) -> Output:

    params = args.params

    processed_content_list = params["searchResultsList"]  # LinkReader 的结果

    url_list_input = params["urlList"]  # 原始URL列表

    output_array = []

    list_len = min(len(processed_content_list), len(url_list_input))

    for i in range(list_len):

        try:

            content_data = processed_content_list[i].get('data', {})

            title = content_data.get('title', '')

            content = content_data.get('content', '')

            url = url_list_input[i]

            output_array.append({

                "title": title,

                "content": content,

                "url": url

            })

        except (KeyError, TypeError, IndexError, AttributeError) as e:

            print(f"Skipping entry {i} due to error: {e}")

    ret: Output = {

        "mergedList": output_array

    }

    return ret
