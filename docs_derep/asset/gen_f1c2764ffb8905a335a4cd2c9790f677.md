#### 5. 方法上手指南

1.  **title()**：
    - 把人名、地名、书名等专有名词的首字母转为大写。
    - 典型场景是把用户随意输入的名字整理成规范格式。

2.  **upper()**：
    - 让警告或错误提示更醒目。
    - 先统一转大写再做大小写不敏感的比较。
    - 保持 HTML 标签等固定格式的一致性。

3.  **lower()**：
    - 保存邮箱等信息时统一小写。
    - 搜索或比对时先转小写消除大小写差异。

4.  **capitalize()**：
    - 将一句话的首字母大写其余小写。
    - 整理用户提交的句子开头。

5.  **swapcase()**：
    - 实现特殊的视觉效果。
    - 通过大小写互换来突出重点。

6.  **casefold()**：
    - 国际化场景下的大小写忽略比较。
    - 处理多语言文本时的稳妥方案。

7.  **检查方法（islower()、isupper()等）**：
    - 校验用户输入的格式。
    - 判定密码复杂度，比如是否包含大小写字母。
    - 根据检测结果做条件化展示。
