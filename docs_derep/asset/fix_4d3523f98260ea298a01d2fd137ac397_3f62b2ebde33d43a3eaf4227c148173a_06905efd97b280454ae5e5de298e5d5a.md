###### # 小结

GPT建立在Transformer之上，采用仅解码器的单向自回归预训练方式。整个过程在海量无标注文本上进行，核心目标是根据已有上下文推测下一个词。

预训练模型的架构并不统一。有只用编码器的比如BERT，也有只用解码器的比如GPT，还有编码解码兼备的比如T5。

■ 在训练阶段，自回归指的是把一段固定长度的历史输入模型，例如一句话的前半部分，让它预测紧接着的词或token，再把真实标签和预测结果对比，按误差反向更新参数，以提升整体预测准确度。随着训练步进，输入序列逐步延长，模型能捕获更长的依赖。

■ 在推理阶段，自回归指的是用已训练好的模型，给定一个起始提示，比如一个问题，模型先输出一个词或token并拼接到输入里，然后基于新序列继续预测，直到文本长度满足需求。这时不再参考真实标签，完全依赖自己已生成的历史进行续写。

GPT的生成特性保留了语言模型的本质，即学习条件概率分布来预测下一词。通过从大量无标注文本中学习上下文与词汇间的关联，GPT实现了续写和内容生成。

预训练完成后，GPT可在特定NLP任务上做精调，效果明显。从最初的GPT到GPT-2再到GPT-3，模型体量持续增长。GPT-3拥有1750亿个参数，具备零样本或少样本学习能力，在不少场景下无需微调，仅靠提示就能完成任务。

ChatGPT则承接了GPT系列的发展脉络，专注于对话与聊天机器人，借助大规模预先训练和强化学习，能产出更自然流畅的对话。

8.1 从GPT到ChatGPT的演进脉络
到这一课，我们可以先回顾NLP的发展。2010年前传统机器学习占主导。2013年后深度神经网络兴起，以循环神经网络为代表。2017年《Attention is all you need》提出Transformer，为大模型奠基。2018年BERT和GPT先后发布，预训练大模型初露锋芒。2020年后大模型迭代加速，应用范围快速扩大。

从初代GPT到GPT-3有几个关键节点。

**GPT**：2018年OpenAI发布，基于Transformer，参数约1.17亿。采用单向自回归生成，先在海量无标注文本上预训练，再在下游任务上微调，在多项NLP任务上取得进步。

**GPT-2**：2019年发布，参数提升到约15亿，训练数据和模型复杂度均提高。文本生成能力突出，但也引发了真实性与滥用方面的担忧。

**GPT-3**：2020年发布，参数达1750亿，当时最大的预训练语言模型。在生成、摘要、问答、翻译等多任务上表现强劲，并支持零样本或少样本学习，许多任务无需微调即可应对。

随着参数增长，可处理序列变长，生成质量明显提升。GPT-3输出流畅准确，质量接近人类写作。
