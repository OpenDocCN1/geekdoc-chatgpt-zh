ClawHub 技能 CLI 极速上手

ClawHub 技能注册表对应的命令行客户端是 clawhub CLI，作用类似 Node.js 生态里的 npm，先一次性装上，后续就能反复使用。

# 安装 clawhub CLI

npm i -g clawhub

装好之后必须先登录才有操作权限。先打开 clawhub.ai 注册账号 → 点击右上角头像 → Settings 设置 → API tokens → Create token，把生成的 token 复制下来：

# 登录，粘贴你的 token

clawhub login --token ＜你的 token＞

# 确认登录是否成功

clawhub whoami

登录通过后，常用的操作如下：

# 搜索技能

clawhub search [关键词]

# 安装技能

clawhub install [技能名]

# 查看已安装的技能

clawhub list

# 全部更新

clawhub update --all

# 卸载技能

clawhub uninstall [技能名]

[PRE0]

**小贴士**

装完技能后无需重启 Gateway，能立刻生效。装完可以试着说一句“我刚装了 XXX 技能，帮忙演示一下”，龙虾会自动识别新能力并给出使用示例。

**安全安装指南**

截至 2026 年 3 月 16 日，ClawHub 上架的技能已超过 23 000 个，质量参差不齐。2026 年初爆发的“ClawHavoc”事件里，341 个恶意技能被集中清除，这件事提醒大家随意安装包是有风险的。下面的流程可供参考。

**第一步：先验证，再安装**

clawhub info ＜技能名＞

# 也可以在 clawhub.ai 页面查看该技能的 VirusTotal 扫描报告

**第二步：遵循“1 000/3 原则”**

● 下载量大于 1 000 次，说明使用者足够多
● 上线时间超过 3 个月，经过一定时间的检验，不是刚上线的来路不明产物
● 作者明确且提供源码链接，可追溯、可审计

**第三步：高风险类型要特别谨慎**

● 名称与知名技能仅差一两个字母，比如“calwdhub”冒充“clawhub”，这是恶意伪装最常见的手法
● 要求很宽泛的权限，例如访问全部文件、发起网络请求，但功能描述却非常简单
● SKILL.md 为空、描述模糊、说不清它到底做什么

## 4.4 记忆系统：让助手真正记住你

没有记忆系统，每次对话都要重新介绍自己 —— 我是做什么的、喜欢什么风格、项目背景怎样，很麻烦。OpenClaw 的记忆分为两层：SOUL.md 管性格，MEMORY.md 管经历，配置好后龙虾就认识你了。

**SOUL.md：性格是长期的**

SOUL.md 在第三章已做过基础配置，这里讲进阶用法：让它随使用动态调整。

用一段时间后，若发现回复不合心意，比如太啰嗦、太保守、格式不对，无需重写文件，直接在对话里说：

**用户：**你最近回复太长了，我想要简洁一点，每次不超过 3 句话，除非我明确要求详细

[PRE6]

它会自动更新 SOUL.md，下次对话即生效。这就是可进化的助手和固定参数工具的区别。

**MEMORY.md：经历是累积的**

MEMORY.md 是 AI 的长期记忆档案。对话中产生的重要信息 —— 工作背景、项目细节、特殊偏好 —— 会自动写入该文件，下次打开依然记得。

典型结构如下：

## 用户信息

- 姓名：Alex，产品经理，做 SaaS 工具
- 时区：Asia/Shanghai，作息：晚 10 点后不回消息

## 项目背景

- 当前主项目：为客户做企业数字化转型
- 常用工具：Notion、飞书多维表格、Python

## 偏好记录

- 回复风格：直接，不要废话
- 报告格式：优先表格，其次列表
- 不喜欢：过度道歉和客套

## 经验教训

- 2026.03.09：搜索关键词加上“最新”效果更好
- 2026.03.07：处理 Excel 时先确认列名避免歧义

你也可以主动喂养信息，例如“记录这条内容”“使用 write 工具请长期保存这条信息”。

[PRE7][PRE8]

**Self-Improving-Agent：让 AI 从错误中学习**

上一节推荐的 Self-Improving-Agent 安装后，记忆系统会多出错误经验库这一维度。

每次 AI 犯错或被你纠正，它会记录问题是什么、正确做法是什么、下次如何避免。这些记录会沉淀到 MEMORY.md，形成踩坑经验，同类错误不再重复。你的龙虾真正开始成长。

**小贴士**

记忆文件会随使用逐渐变大。若 MEMORY.md 超过 1 000 行，可让 AI 帮忙精简：“帮我把 MEMORY.md 精简一下，保留关键信息并合并重复内容”。

## 4.5 会话管理：龙虾的短期记忆规则

长期记忆之外，还有更日常的一层 —— Session，会话，也就是短期记忆。

常见现象：聊久了变慢、今天说的话明天忘了、飞书说过钉钉不知道，都与会话机制有关。搞懂它是用好 OpenClaw 的必修课。

**Session 是什么 —— 对话的容器**

每次与 OpenClaw 的对话都被装进一个叫 Session 的盒子，里面包含当前对话内容、工具调用记录、token 消耗统计。

Session 与 MEMORY.md 的关键区别：Session 是临时的，会被清空；MEMORY.md 是永久的。可以这样理解，MEMORY.md 是写给龙虾的档案，Session 是今天的通话录音，档案常在，录音会被覆盖。

**Session 变慢怎么办**

用久了回复会变慢，因为历史越长处理成本越高。先用 /compact 压缩，90% 情况可立刻恢复。若话题已结束，直接用 /new 更干脆。养成“一件事做完就处理 Session”的习惯，能让助手始终保持轻快。

**小贴士**

MEMORY.md 中有时效性强的记录，如已结束的项目，要定期清理。Session 靠 /compact 和 /new 维护，MEMORY.md 靠定期整理，两层分开维护效果最好。

**Session 常见问题**

**问题 1：为什么群里 @ 它，它不记得私聊说的话？**

群聊与私聊 Session 隔离，属隐私设计。如需在群里使用私聊背景，需在群里重新说明。

**问题 2：怎么让它彻底忘掉某段对话？**

发 /new 清空当前 Session。若要删除 MEMORY.md 内容，需手动编辑文件。注意 /new 不会清理 MEMORY.md。

**问题 3：定时任务执行完会记住内容吗？**

不会。定时任务每次都是全新 Session，不共享历史。如需跨任务保留，需写入 MEMORY.md。

**问题 4：凌晨 4 点自动重置能关掉吗？**

可在配置文件 ~/.openclaw/openclaw.json → session.resetAtHour 调整时间，或改为纯空闲重置模式。

## 4.6 定时任务：让它自动替你干活

主动找它只是入门，最爽的是你不用找，它自己执行。每天早报、每小时股价监控、周一自动周报，设一次就能一直跑。

**cron 定时任务：设置一次，永久执行**

OpenClaw 定时任务基于标准 cron 语法，用 openclaw cron add 命令创建。

不懂 cron？有两种捷径：网页端定时任务面板可视化设置，或直接用中文描述时间由 AI 转成表达式。

[PRE18]

基本用法：

# 每天早上 8 点发送今日简报

openclaw cron add --name “早报” --cron "0 8 * * *" --message “发送今日简报，包含天气、日程提醒和今日重点任务”

# 每小时整点检查服务器状态

openclaw cron add --name “服务器巡检” --cron "0 * * * *" --message “检查服务器 CPU、内存、磁盘，有异常立即通知”

# 每周一早上 9 点生成周报

openclaw cron add --name “周报” --cron "0 9 * * 1" --message “根据上周任务完成情况生成周报，发到飞书”

# 每天下午 3 点提醒喝水、站起来动一动

openclaw cron add --name “健康提醒” --cron "0 15 * * *" --message “提醒我喝水，站起来活动 10 分钟”

管理任务：

# 查看所有定时任务

openclaw cron list

# 暂停某个任务

openclaw cron disable “早报”

# 重新启用

openclaw cron enable “早报”

# 删除任务

openclaw cron remove “早报”

**推送到聊天工具**

结果默认显示在 Web UI。如需推送到飞书，加上 --channel 参数：

# 推送到飞书

openclaw cron add --name “早报” --cron "0 8 * * *" --message “发送今日简报” --channel feishu

[PRE19]

**小贴士**

不会写 cron 没关系，直接告诉 AI 你想要的时间点，例如“每个工作日下午 6 点”“每隔两小时”“每月第一天早上 10 点”，它会生成正确表达式。

**主动推送与条件触发**

定时任务是时间触发，也可设置条件触发：

● 服务监控：每 5 分钟检查一次网站是否可访问，挂了立刻飞书告警
● 文件监控：监控 ~/Downloads 文件夹，有新文件就通知文件名和大小
● 价格提醒：查询特斯拉股价，跌破 200 美元就推送通知
● 邮件摘要：每天上午 10 点总结收到的邮件，按优先级排列
