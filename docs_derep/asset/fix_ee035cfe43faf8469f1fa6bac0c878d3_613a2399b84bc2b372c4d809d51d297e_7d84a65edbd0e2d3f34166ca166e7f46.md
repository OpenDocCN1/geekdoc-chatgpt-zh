# 认知存在论新论
# 文库总序
认知可理解为人类乃至灵长目动物所共有的模仿、学习与理解机能。认知如何产生，尤其是意识的来由，至今仍属未解之谜。尽管认知科学与神经科学积累了大量发现，人工认知体系——尤其是人工智能、认知机器人以及近年兴起的脑机接口——总体上仍停留在对大脑功能的模拟层面，很难像活体那样自发形成自我意识。此间差异或源于生物体与物体制之间的本质分野。之所以把人称之为人，核心在于文化，动物并不具备文化特质，特别是符号特质。

关于非生物的智能系统是否拥有认知能力，学界争论不休。争议焦点多集中于理解力。通行的看法认为，机器人具备机器学习之类的学习机制，却缺乏真正的理解力，因其没有意识乃至生命。若把人工智能视为一种另类的认知形态，那么对话机器人这类智能体便可被看作具有认知能力的，即便这种能力仅是表层的。如2022年12月初，OpenAI 公布的对话系统 ChatGPT，人机对话已逼近人与人对话的景象。这类现象不仅是科技与工程需要回应的难题，也是哲学必须深入追问的命题。

认知哲学是近十余年兴起的分支，研究范畴涵盖生物脑与人工脑所产生的各类智能行为，例如感知、意识、心智、自我、观念、思想、机器意识，以及人工生命、人工感知、人工意识、人工心智等。既关乎自然认知，也关乎人工认知，更涉及二者的交融，重要性极高而难度亦大，是认知科学、人工智能、神经科学与认知哲学共同面对的重大课题。

“认知哲学文库”聚焦自然认知与人工认知及其哲学议题，内容涉及现象学、符号学、语义学、存在论、涌现论与逻辑学分析，心智表征、心理空间与潜意识研究，以及人工认知系统的生命、感知、意识、心智、智能的哲学与伦理探讨，旨在构建认知哲学的中国话语、学术与学科体系。

本文库承续“认知哲学译丛”“认知哲学丛书”之后，是笔者主持的国家社科基金重大项目“人工认知对自然认知挑战的哲学研究”（21&ZD061）系列成果之一。鉴于项目跨学科且覆盖面广，同时获得山西省“1331 工程”重点学科建设计划与山西大学“双一流”学科建设规划资助。

# 摘要
借助存在论现象学路径审视人类认知，实质是对认知哲学问题的方法、样式与核心要义的回应。借鉴海德格尔关于“此在”的生存分析来阐释认知的要素，或可开辟新径，有助于认知科学与大陆哲学对话，以不同姿态摆脱既有研究范式。海德格尔存在论与认知科学的结合是否合理有效，由此衍生的存在论认知能否成为新进路，需要论证。

梳理既有认知科学纲领及其哲学基础可知，各路径均有局限。经典认知主义与联结主义深陷“计算至上”的形而上学迷思，遵循心物与心身二分，导致认知与世界、身体割裂，难以解释情感、意志活动，也无法恰当地说明人类认知的生成与演化，计算主义对情感体验、意志冲动与审美活动的描述亦不足；以“4E+S”为核心的第二代认知科学虽在批判笛卡尔主义方面有所进展，却难以统合，脑外因素的因果性与构成性分歧仍未弥合；胡塞尔现象学因先验唯心与反自然立场，与认知科学的实证原则相悖，其把意义全部归于先验主体，而该主体缺乏经验世界的支撑。

理论建构的基础是概念。本书围绕存在论认知的三个核心概念展开——“此在”、世界、在世存在，厘清“此在”所包含的身体、实践、情境三个维度，区分世界与背景、认知视界中环境概念的差异，并把在世存在视为人类认知成立的前提。海德格尔试图把人的存在理解为在世界中存在，却对身体维度关注不足，需修正。

在把海德格尔存在论现象学与认知科学结合方面，存在论认知提出三点主张：（1）以动态的原初上手活动取代静态的观照式认知；（2）以具身的情境性认知取代无身的离身认知；（3）把表征性认知拓展为行动导向认知，人类认知是表征与行动的叠加耦合。海德格尔把理论性认知看作对上手劳作的修正，操具的上手是通达事物自身的恰当方式，但这种直接上手也面临自动化、智能化延展实践的挑战。任何单一上手状态都发生在具体情境中，身体性的“在世界中存在”更符合真实生存境况。同时，上手并不必然排斥表征，认知具有行动导向，是对既有表征认知的拓展而非替代。

把存在论哲学引入认知研究亦面临困境。首先，“此在”作为存在论概念，与事实层面的自然化描述难以兼容，自然化“此在”在现实层面难以实现，它是思辨性的、现象学的先验解释与分析，不适于形式化、模型化的科学说明。其次，“海德格尔式人工智能”试图以“被抛”机制回应“框架问题”，却陷入非因果的现象学解释与因果自然主义解释不相容的矛盾，按“被抛”设计的 AI 也无法完整呈现人类智能整体结构。

存在论认知的理论困境与存在论现象学、诠释学在理论上的连续性表明，单靠存在论哲学难以支撑全部存在论认知，有必要把诠释学纳入框架以丰富内涵。其理由有三：其一，海德格尔的存在论现象学本身就是一种诠释学；其二，人类认知即是一种诠释，认知依附于诠释、充盈着诠释，二者在结构上具有“家族相似”；其三，诠释学可为认知科学提供助益。诠释学同时揭示了人类认知的复杂面向，凸显其动态性与自我超越性。存在论与诠释学可共同成为推动认知研究的新动能。

关键词：存在论认知；“此在”；在世存在；人工智能；诠释学

# 导论
## 一 选题意义
自1950年代起，人类认知的本质成为现代科学核心关切，认知科学由此诞生。短短七十余年间，其发展速度与覆盖范围罕见于其他学科。如今认知科学已成为21世纪前沿领域，依次出现计算隐喻与符号主义、脑隐喻与联结主义、交互隐喻与具身心灵等模型，并经历认知心理学、人工智能、人工神经网络、神经科学等主要阶段。认知哲学领域亦出现符号主义、计算主义、情境主义等学说并伴随相应反思与批判。本选题意义有三。

第一，就切入角度看，以符号主义、联结主义为代表的第一代认知科学纲领、以“4E+S”为核心的第二代范式、动力系统理论与现象学均从各自立场回应认知问题。经典范式之后的大多数进路都建立在对笛卡尔主客二元论的批判之上。海德格尔的存在论从世界的世界性与“此在”的生存分析出发批判笛卡尔，强调人是世界的参与者而非旁观者，摒弃超越性的“观照”，这种实践描述引起了科学家与哲学家的兴趣。从存在论进入认知科学，是一种新的研究路径。

第二，海德格尔的存在论与胡塞尔的现象学在西方现代哲学中影响深远，均与认知科学密切相关，对认知科学哲学基础的转换产生积极作用，甚至可能成为新的哲学来源。如“在世存在”、上手与现成之区分，为具身认知、情境认知提供启发。海德格尔把“此在”看作存在意义的显现场所，对存在意义的追问正是诠释学的任务，故其存在论与诠释学密不可分。理解与认知紧密相连，理解的前结构重视有助于阐明人类认知的澄明。海德格尔诠释学与伽达默尔受其推动的诠释学能为研究人类认知现象提供何种启示，值得考察。

第三，据笔者检索，国内学界对海德格尔与认知科学结合的关注较少，相关论文屈指可数；国外已有专著与论文，显示其重要性被国外学界重视。基于此，本书在梳理笛卡尔到海德格尔的转向作为认知科学哲学基础的基础上，将认知科学议题与海德格尔存在论哲学结合，在存在论分析认知的基础上提出一条可行的新路径。选题难度大、资料有限，但可拓展认知科学视野，推动认知哲学研究，弥补国内不足。

## 二 国内外研究现状
认知科学是研究心智、认知与智能的交叉学科，其源起包括1956年后的人工智能热潮、心灵哲学中的功能主义、认知心理学与语言学对激进行为主义的“认知革命”等。历经半个多世纪，认知科学已不再是泛泛而谈，不同领域的研究者贡献了新方法与新成果，如符号计算主义与联结主义、“4E+S”第二代纲领、现象学、实用主义、生态学介入等。国内对海德格尔存在论的研究成果丰富，多为文本解读。下面梳理与认知相关联的解读文献。

### （一）海德格尔与认知相关议题研究状况
海德格尔本人几乎未使用“认知”一词，但并不意味着轻视。《存在与时间》已讨论认识与真理，《时间概念史导论》进一步指出认知在存在论中的地位，但将其视为此在在世界中存在的一种派生方式。海德格尔在论述在世现象时即对传统认识论尤其是笛卡尔主义进行批判，认为传统认识论困于主体如何合理抵达客体的窠臼，必须把认识理解为“此在在世界中存在的一种方式”。国内对此域关注度高，多项新进路吸纳了这一思想。

#### 1. 海德格尔认识论研究状况
李龙博士论文《认识论的先验转向和生存论转向——以生存论维度重新理解认识论》认为海德格尔在批判先验哲学的独断性与传统形而上学实体性中开启了认识论的生存论转向，揭示认识论的生存论前提，强调从在世的生存论结构、人的生存领会出发研究认识可能前提。海德格尔的转向改变了认识论主题，核心不再是知识的客观性与真理性，而是通达存在意义。

丁蓓增《海德格尔对传统认识论的解构》认为，海德格尔哲学旨在摆脱以自然科学为模式的世界观，通过对存在的再分析突破狭隘的主客体认识关系，打开更为广阔的领域；张一兵《意蕴：遭遇世界中的上手与在手——海德格尔早期思想构境》认为意蕴非认识论范畴，而是遭遇性的存在，其展露表现为上手—在手状态与共同世界中的显现，存在即意蕴建构的相遇发生；余平《“朝向实事本身”之思——从笛卡儿到海德格尔》认为海德格尔以“在-世界-中-存在”打破意识哲学的壁垒，直指自在存在即席卷我们的“实事本身”；刘丽霞《心物关系问题的解决：从胡塞尔到海德格尔》论述海德格尔对胡塞尔认识论范式的批判，主张从此在领域出发理解“物自身的经验”；陈辉《海德格尔对“世界观”概念批判的多重意蕴》认为“世界观”表达主体形而上学，应被解构批判，人与世界关系不同于该概念所显示者。

#### 2. 关于认知的意向性问题
意向性经布伦塔诺创立、胡塞尔改造后被海德格尔用于研究此在“在世界中存在”，脱离了胡塞尔关于意识的原初路径。孙周兴《我们如何得体地描述生活世界——早期海德格尔与意向性问题》认为海德格尔借助意向性获得真正的实事域，并在视域到世界、理论化到生命体验等方面推进意向性；舒红跃《从“意识的意向性”到“身体的意向性”》认为海德格尔的批判不在于拒绝意向性，而在于否认其为第一性结构，意向性应回置于“在之中存在”基本结构，奠基于此在的超越性；杨晓斌博士论文《意识意向性、身体意向性与伦理意向性——胡塞尔、海德格尔与列维纳斯哲学中的意向性概念》认为海德格尔确立了与胡塞尔不同的身体意向性，以实存的人、此在为起点；陈攀文《现象学意向性理论的生存论转向：从胡塞尔到海德格尔》论述海德格尔从存在论立场对胡塞尔作出的三方面改造：主体是实践价值意义的此在而非先验自我，意义源于此在的实践与价值筹划，指向性根源于时间性而非意识本质结构。

#### 3. 关于认知的语言问题
语言作为认知特殊现象一直受关注。冯凯迪硕士论文《试论海德格尔的语言之思——基于语言与世界之关联的考察》从语言与世界内在关联阐释语言观；谢文静硕士论文《行走在“思”与“诗”的路上——海德格尔存在论的语言学诠释》在诗、语言、存在的框架下讨论二者关系；张贤根《语言：区分与道路——海德格尔语言思想研究》论述海德格尔批判流俗语言与技术语言后实现的语言转向；杨佑文《海德格尔的“语言转向”及其语言观》探讨“语言转向”意义并区分前后期的差别；张海洋《本体论语言哲学视域中的海德格尔语言观》从语言与此在、语言与意识世界、语言与存在三维度澄清其本质；王锺陵《论海德格尔的语言观》分析“道说”概念与老庄“道”的异同。总体看，海德格尔以存在论为基础追问语言本质，认为语言是存在自身的澄明与遮蔽，人栖居其中。

#### 4. 关于认知的情绪问题
