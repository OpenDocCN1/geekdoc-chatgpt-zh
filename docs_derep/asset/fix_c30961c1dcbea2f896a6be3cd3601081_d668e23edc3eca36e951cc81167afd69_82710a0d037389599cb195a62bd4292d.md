[PRE1]

本实现借助 FastAPI 构建了 Model Context Protocol 的服务端，其核心职责是集中管理模型的上下文数据。持久化层使用 Redis，同时内置了 API Key 鉴权、调用统计以及健康检查等功能。

作为常驻进程，启动时会以 0.0.0.0:8000 开启 Web 服务并保持监听，不会主动输出业务结果。只有在调用方通过 HTTP 访问到已定义的接口后，服务端随后返回对应的数据。验证效果时可使用 curl、Postman 或浏览器等工具向这些接口发送请求。
