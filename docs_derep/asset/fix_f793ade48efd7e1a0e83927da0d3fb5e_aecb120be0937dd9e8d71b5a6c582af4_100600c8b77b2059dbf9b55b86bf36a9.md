# 规章落地常见卡点与AI转化路径

推行卡点：规则条文与现场操作相悖，跨部门利益分配失衡。
员工感受：文字晦涩难懂，奖惩尺度不公开。

要把制度诉求转化为模型可直接执行的指令，才能落地。

+ 提问维度
- 架构：总则、适用边界、行为规范、奖惩办法、附则等。
- 条款细化：违规行为分级判定、配套申诉流程图等。
- 配套资源：制度解读演示稿范式、员工签收确认表等。

### 实战

目标3个月内将员工违纪率压降四成。

1. 报销漏洞：虚开发票、拆分报销，财务人工核验低效易错。
2. 考勤造假：靠虚假定位打卡，现行处罚仅200元，威慑不足。
3. 协作梗阻：跨部门项目因责任不清、流程不透明，延期率达35%。
4. 理解障碍：现行表述生硬，员工反馈看不懂、不会用。

#### 协助搭建管理规范

1. 结构包含总则目的与适用范围、行为规范涵盖报销考勤协作、奖惩机制分级与处置、申诉流程步骤与时效、附则生效与解释权归属。
2. 条款要点：
   - 报销单笔超500元须附合同协议，虚开发票按比例追责。
   - 考勤增加人脸识别加定位双重验证，造假累计三次以上解除劳动关系。
   - 协作细化项目责任矩阵表、跨部门沟通标准作业程序。
3. 配套物：解读演示含案例问答、签收表含条款摘要、修订记录表追踪变更历史。

# 第2章 人工智能赋能招聘管理升级
引入人工智能参与招聘，既能提速，也能通过数据分析为HR定制招聘方案。从撰写吸引人的招聘文案与岗位描述、制作吸睛海报与宣讲PPT，到渠道评估、简历智能筛选、面试题生成与录用决策支持，模型可贯穿全流程，让人岗匹配更高效、更精准，助力企业招到并留住合适人才。

## 用AI重塑招聘流程
**情境**
近期招聘效率下滑，简历筛选耗时，面试中候选人能力与岗位匹配不佳，用人部门投诉增多。如何改进？

清晰的流程能明确各环节职责、标准与工具。例如岗位画像拆解能力需求、结构化面试表统一评估，既提效又降风险。

不同岗位需求差异大，技术重专业、销售重沟通，流程能否兼顾？

可分层分类。按技术类、职能类、销售类划分，为每类设定核心能力项并匹配筛选工具。

周期紧张时，标准化会不会更繁琐？

恰恰相反。标准化是化繁为简，减少主观随意，提升质量。如“初面-复面-终面”分级评估，既压缩周期又避免重复沟通。

### 模型提问框架
通用公式=岗位需求拆解+流程痛点分析+优化目标定义

厘清岗位核心能力、经验与文化契合，为模型提供筛选简历、设计面试题的依据，避免凭感觉用人。

**提问要点**
- 能力项：如技术岗算法能力、管理岗团队领导力。
- 经验要求：行业年限、项目体量。
- 文化契合：创新型需开放思维，传统企业重执行力。

梳理流程中的效率、质量、体验问题，锁定优化方向。

**提问要点**
- 效率问题：简历筛选耗时、面试排期冲突。
- 质量问题：用人部门对候选人满意度低。
- 体验问题：候选人反映流程繁琐、反馈慢。

明确期望产出，将需求转为可执行指令。

**提问要点**
- 产出物：流程图、评估表、话术模板。
- 场景：校园招聘、社会招聘、紧急补位。
- 落地支持：是否需要配套培训、数据看板。

| --- | --- |
| 岗位说明书 | 职责、能力、经验要求说明。 |
| 历史招聘数据 | 通过率、转化率、用人部门反馈等。 |
| 现行流程文档 | 步骤、工具、耗时等。 |
| 用人部门诉求 | 隐性要求如抗压、学习能力等。 |
| 候选人反馈 | 往期抱怨环节如等待久、提问重复等。 |

### 实战案例
拟招聘高级数据分析师，核心要求：

1. 技术：SQL、Python、Tableau熟练，三年以上分析经验。
2. 业务：能独立设计分析模型，推动决策。
3. 文化：跨部门协作能力，适应快节奏。

痛点：
1. 筛选效率低：HR手工筛百份简历，耗三天。
2. 评估主观：面试官提问随意，能力差异大。
3. 反馈周期长：需等一周，优质候选流失。

协助工作：
1. 设计流程图：简历筛选、笔试、初面、终面。
2. 输出模板：
   - 筛选关键词表如“SQL高级”“用户增长分析”；
   - 结构化评估表含技术题、案例题、行为题；
   - 反馈模板含录用淘汰原因。
3. 操作建议：向业务方培训结构化面试技巧。

## 用 AI 制定招聘计划方案
**情境**
1. 业务扩张快，计划跟不上变化。用人部门临时提需求，HR疲于应付，空缺期拉长，业务受影响。
2. 根源是计划缺乏前瞻性。好计划需结合业务目标、岗位优先级、资源分配，既能预判又能动态调整。
3. 业务常称“需求紧急”，如何判断优先级？技术与销售同时缺人先补哪个？
4. 需评估岗位价值，按对业务目标贡献、紧迫性、市场稀缺性打分。
5. 预算有限只能招五人需求十人怎么办？
6. 采用“核心岗位+备选方案”：优先保障三个高价值岗位，其余通过内部转岗、外包或流程优化解决，明确优劣风险供决策。

### 模型提问框架
通用公式=业务目标对齐+资源约束分析+计划需求定义

明确战略对招聘的具体要求，避免脱节。

**提问要点**
- 战略方向：未来半年开拓华东市场，需组建本地化团队。
- 岗位优先级：优先保障研发算法岗，支撑产品上线。
- 时间节点：Q3前完成二十名销售招聘，支撑Q4冲刺。

梳理限制条件。

**提问要点**
- 预算限制：总预算五十万含猎头费渠道费。
- 时间窗口：四十五天内完成三十个岗位。
- 市场条件：算法工程师供需比1:50竞争激烈。

明确期望成果。

**提问要点**
- 输出形式：表格、甘特图、PPT方案。
- 核心指标：招聘周期、到岗率、成本。
- 动态规则：薪资涨幅超10%需重估预算。

### 准备资料

| 要点 | 内容 |
| --- | --- |
| 业务战略文档 | 未来6~12个月目标、重点项目、区域扩张等。 |
| 岗位需求清单 | 职责、优先级、紧急程度等。 |
| 历史招聘数据 | 周期、成本、到岗率、流失原因等。 |
| 市场供需报告 | 薪资水平、人才储备、对手策略等。 |
| 内部资源清单 | 渠道、团队能力、预算分配等。 |

### 实战案例
拟在202×年Q3进入华东市场，Q2完成本地化团队。

目标：
1. 业务：三月内覆盖三城组建二十人销售团队，支撑Q4营收增长30%。
2. 技术：同步招五名算法工程师，保障产品本地化适配。
3. 管理：提前储备两名区域经理，支撑2025扩张。

约束：
1. 预算八十万，猎头费占比≤30%。
2. 时间：销售六十天内到岗，算法九十天内到岗。
3. 市场：算法工程师供需比1:40，平均周期120天，薪资溢价15%。

协助输出计划表：
1. 含岗位、数量、优先级、渠道分配，如销售侧重直聘与内推，算法侧重猎头与高校合作。
2. 标记高风险岗位及预案，如提前储备实习生、启动外包。
3. 资源分配方案：猎头费、渠道费、推荐奖金预算划分。
4. 动态调整规则：若算法岗位周期超九十天，启动技术总监内训+外包过渡。

| 成本监控 | 定期对比实际成本与预算，及时调整渠道。 |

## 用 AI 编写招聘文案与职位描述

6. 可用“岗位名+核心价值”组合，JD中用数据量化价值。

## 用 AI 设计招聘海报与宣讲 PPT
**情境**
校招宣讲效果差，海报不吸睛，PPT让学生走神，提问浅层，未体现亮点。

问题在物料视觉表达。海报与PPT是企业名片，做成说明书无人看。好设计像预告片，用视觉冲击抓眼球，再用内容引发共鸣。

业务常要求要点全写，导致PPT堆砌文字、海报满屏条款。

内容需分层表达。如PPT先用数据成果吸引，再用图标展示技术实力，最后放招聘需求。海报同理，主视觉突出技术突破，底部二维码链接详情。

无设计团队时，如何做出高级感？

遵循三色原则，主色+辅助色科技蓝+点缀色亮橙。每页至少一张图，标题不超过12字，正文不超过3行。

### 模型提问框架
通用公式=设计目标+内容素材+输出要求

明确用途、受众与风格。

**提问要点**
- 用途：校招海报、社招宣讲PPT。
- 受众：985/211计算机专业学生、3~5年经验工程师。
- 风格关键词：科技感、活力、简约。

提供核心信息。

**提问要点**
- 核心文案：企业愿景、技术成果数据。
- 品牌元素：Logo、标准色、字体。
- 视觉素材：团队合影、产品截图、技术架构图。

明确格式与细节。

**提问要点**
- 格式：PPT分5页，海报尺寸1080×1920。
- 风格：主色蓝、点缀橙、思源黑体。
- 结构：第一页技术愿景，第二页岗位核心价值。

| 视觉素材 | 团队合影、产品截图、技术架构图、办公环境照等。 |

### 实战案例
需设计“AI算法工程师推荐系统方向”校招海报/宣讲PPT，需求如下。
