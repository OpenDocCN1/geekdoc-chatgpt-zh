如图演示，C3 最初存放的计算式为 =ROUND(A3/B3,2)，在把 B3 删除后，C3 的引用跟着左移指向了一个已经不存在的位置，于是返回了 #REF! 错误。提醒：公式确定之后，不要随意删改单元格或区域。

[PRE0]

（7）#VALUE!

#VALUE! 出现时多半是因为公式所引用的单元格数据类型混杂。如下例，A2 因为金额为 0 被手动填入了文本占位符 “-”，导致引用到 C2 的公式无法运算，返回 #VALUE!。因此，使用公式前要确保被引用的单元格保持统一的数字类型。

[PRE1]

（8）###

### 通常由两类情况触发：一是列宽过窄无法完整呈现内容，扩大列宽或调小字体即可；二是日期时间公式、格式或输入值本身有误。如下例，C2 使用 =A2-B2 计算两个日期的间隔，因 A2 早于 B2，得到负数，而 C2 被设为日期格式，于是显示 ########。把格式改为数值型即可正常显示。

## 第5章 财务凭证表单实战构建

财务凭证是记录经济业务的书面依据，按来源分为原始凭证和记账凭证。原始凭证是填制记账凭证的基础，记账凭证是登记账簿的关键。规范管理凭证才能为账簿和报表提供可靠依据。在不违背凭证管理原则的前提下，用 Excel 制作管理凭证成本低且灵活。本章先借助讯飞星火、ChatGPT、文心一言等 AI 了解设计思路，再详细讲解如何综合运用 Excel 制作规范的财务凭证表单。

### 5.1 原始凭证表单制作：多功能电子收据

原始凭证是在业务发生时取得或填制的证明文件，常见类型有收据、发票、借款单、报销单、入库单、发货单等。按来源可分为外来原始凭证和自制原始凭证。下面看讯飞星火给出的设计思路。

> 提问: 如何设计财务原始凭证表单?

讯飞星火

设计财务原始凭证表单应遵循以下要点。

(1)确定所需种类：依据单位实际业务明确外来和自制凭证种类。
(2)明确用途：弄清每种凭证记录的业务类型。
(3)拟定格式：包括凭证名称、填制单位、日期、编号、内容、金额、数量等。
(4)规定流转：明确从填制到归档的流程，保证信息完整。
(5)制定保管制度：确保凭证安全可查。
(6)填写内容：应含名称、日期、单位、业务内容、数量、单价、金额，外来凭证还需税务信息。
(7)遵循统一性原则：格式内容尽量标准化，便于核对。

从中可知表单设计需兼顾内容、外观、结构和数据准确性等。本节以常用的“收据”为例，制作一份可自动计算、自动编号、自动分栏、自动转大写的电子收据模板。
