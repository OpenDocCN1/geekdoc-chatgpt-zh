# 机器阅读理解演进史：数据集更迭与经典架构深度剖析

时间拨回 2015 年，DeepMind 的 Karl Moritz Hermann 团队率先推出了一款面向机器阅读理解任务、融合注意力机制的 LSTM 架构。次年，Danqi Chen 等人发布了 CNN/Daily Mail 大规模监督数据集。其构建逻辑颇具特色：将新闻全文视为单一段落，利用占位符替换文中的实体名称，强行将理解任务转化为“完形填空”形式。然而，这种自动化构造手法引入了大量噪声，客观上阻碍了后续模型研究的深入发展。

为突破这一瓶颈，Pranav Rajpurkar 等人精心构建了 SQuAD（斯坦福问答数据集）。该集合包含 536 篇文档及逾 10 万组问答，答案均精确定位于原文片段。凭借高质量标注与在线自动评测机制，SQuAD 迅速确立了领域首个大规模基准地位，吸引全球研究者竞相攻关。截至 2022 年底，榜单上领跑的模型均建立在深度学习框架之上，技术路线高度趋同：先对文档与问题分别编码，经交互层深度融合语义，最后直接回归答案的起止边界。

- **嵌入层**：分别将文档与问题的 Token 映射为稠密向量（可调用 Word2Vec、Glove 等预训练嵌入）。
- **编码层**：借助循环神经网络对双向序列建模，使各 Token 向量吸纳上下文语义。
- **交互层**：核心模块，计算问题与文档的关联度，输出注入问题感知信息的文档表征（即 Query-Aware 表征）。
- **输出层**：基于上述表征，通过指针网络或边界预测器定位答案区间。

在众多经典架构中，R-Net 与 BiDAF 最具代表性，下文逐一拆解。

### R-Net：双层交互机制与门控注意力协同

R-Net 由 Yuxin Wang 等人提出。其嵌入层融合 GloVe 词向量与字符级嵌入，强化输入表征；编码层沿用 RNN 对问题与文档建模。交互层采用双层设计：首层引入门控注意力循环网络，实现问题与段落的深度匹配，获取问题感知的段落表征；次层基于自匹配注意力机制，让段落自我对齐，完成全局语义的高效编码。输出层则由指针网络精准锁定答案边界。网络拓扑详见图 3-22。

### BiDAF：双向注意力流驱动的语义深度融合

BiDAF 出自 Minjoon Seo 之手（架构见图 3-23）。嵌入层混合词级与字符级表征：词级加载预训练 GloVe，字符级经 CNN 编码，拼接后送入双向 LSTM 深度编码。交互层创新性引入双向注意力流——先构建段落-问题相似度矩阵，据此计算 Query2Context 与 Context2Query 双向注意力，融合生成 Query-Aware 段落表征，再经双向 LSTM 聚合语义。预测端采用边界模型直接输出答案起止索引。

### 评价体系：精确匹中与词级重叠的双重考量

针对抽取式任务，学界沿用 Pranav Rajpurkar 等人确立的两大核心指标：

- **精确匹配（EM）**：预测串与标准答案字符级完全一致得 1 分，否则 0 分，判定极其严格。
- **F1 值**：将预测与标准答案视作 Token 集合，计算平均词级重叠度，兼顾精确率与召回率。

[PRE3]

对于生成式自由回答任务，目前尚无完美评价标准，常借用自然语言生成领域的 BLEU、METEOR、ROUGE 等指标辅助量化。

### 实战实验题

1. **自动作诗系统**：基于唐诗语料（给定或自爬），设计并实现基于 RNN/LSTM 的续写模型。要求覆盖数据加载、网络架构、模型训练与推理全流程，输出符合中文语法与意境的诗句（如接“湖光秋月两相和”）。
2. **影评情感分析**：基于电影评论数据集，构建 RNN/LSTM 分类器，实现正负向情感判别。完整复现数据处理、建模、训练与测试闭环。
3. **语言建模实战**：基于 Penn TreeBank (PTB) 语料库，训练 RNN/LSTM 语言模型，实现次词预测。涵盖数据读取、网络搭建、训练调优与评测全链路。语料官方源：https://www.ldc.upenn.edu/。
4. **机器阅读理解实战**：基于 SQuAD 数据集，从零构建抽取式问答系统。要求落实数据预处理、网络设计（编码-交互-预测）、模型训练与效果验证。数据集官方入口：https://rajpurkar.github.io/SQuAD-explorer/。
