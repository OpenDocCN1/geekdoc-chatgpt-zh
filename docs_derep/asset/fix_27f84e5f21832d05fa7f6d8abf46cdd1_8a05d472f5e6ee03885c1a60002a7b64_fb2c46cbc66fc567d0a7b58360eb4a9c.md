TRAE SOLO 如何确保用户只能访问自己的数据，依赖 PostgreSQL 原生的 RLS 机制，为每行数据设定访问规则。

[PRE4]

策略遵循三项原则：默认拒绝、用户隔离、操作细分。

- 默认拒绝：未明确授权时直接阻断访问。
- 用户隔离：通过 auth.uid() = user_id 的判断，保证只能操作归属自己的数据。
- 操作细分：对 SELECT、INSERT、UPDATE、DELETE 等操作分别定义独立策略。

auth.uid() 是 Supabase 内置函数，可在数据库层面返回当前已认证用户的唯一 ID，是连接认证状态与数据权限的关键，即使应用层出现漏洞也难以绕过。

若使用个人邮箱程序化发送，会存在明显局限：送达率偏低易被判为垃圾邮件、缺少打开率点击率等分析手段、需手动处理退订合规细节等。

因此专业邮件服务成为必然选择。API 密钥属于敏感信息，不可暴露在客户端，正确做法是把发送逻辑封装在服务端路由，通过环境变量安全管理。
