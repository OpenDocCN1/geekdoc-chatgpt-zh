现实工程里常见的网络模型，远不止电阻和电源这两类，电容与电感也大量参与其中。这两类器件的端口电压和电流关系并非代数式，而是带有微分或积分的形式，因其能暂存能量并与外界交换，常被归入储能型或动态器件。含有这类器件的网络即为动态网络，其运行规律可用电压或电流作为变量的微分方程来描述。

动态网络的阶次以描述方程的最高微分次数来衡量。只携带一个储能器件时，对应方程是一次微分，这类网络称为单阶网络；若网络中包含 n 个相互独立的储能器件，方程的最高阶数通常为 n，这类网络就叫做 n 阶网络。对动态网络的研究也常称为瞬态分析，本章先交代瞬态分析的基础，随后集中讨论仅含一个储能器件的单阶网络。

当运行条件被改变时，网络不会瞬间跳到新的稳态，而是要经历一段渐进过程才趋向新的平衡，这个过程叫做过渡过程或暂态。在分析语境里，电路拓扑的改动比如开关动作，或激励参数比如电源信号的改变，都统称为换路，换路等价于运行状态的改变。

暂态产生的外部诱因是换路，内部诱因是电容与电感的存在。这两类器件本身不消耗能量，只是把能量存起来再与外界进行交换。稳定工作下它们各自储存一定的能量，一旦发生换路，这些能量必须重新分配，能量的改变需要时间来完成。若没有过渡，就意味着电容中的电场储能、电感中的磁场储能会发生突变，这要求功率趋于无限大，在实际电路中是不可能出现的。

## 4.1 数制

数字电路所处理的各种数字信号都是以数码形式给出的。不同的数码既可以用来表示不同数量的大小，又可以用来表示不同的事物或事物的不同状态。用数码表示数量的大小时，一位数码往往不够用，因此经常需要用进位计数制的方法组成多位数码使用。多位数码中每一位的构成方法和从低位到高位的进位规则称为数制。数字电路中使用最多的数制是二进制，其次是在二进制的基础上构成的十六进制和十进制，有时也用到八进制。当两个数码分别表示两个数量时，可以进行数量的加、减、乘、除等运算。这一类运算称为算术运算。

### 4.1.1 几种常见数制
