# Arduino双位数码管倒计时器：从动态扫描到按键交互的完整实现指南

在单片机入门项目中，驱动数码管实现计时功能是极佳的练手案例。本文将带你拆解一个基于 Arduino 的两位共阴极数码管倒计时器，涵盖**动态扫描显示原理、余辉消除技巧、按键交互逻辑**以及**蜂鸣器报警机制**的完整代码实现。

---

## 核心硬件与段码定义

首先明确引脚映射与字形数据。我们使用数组 `ledpin` 记录段选引脚（a~g段对应 Arduino 3,4,5,7,6,9,8），`num` 数组存储 0~9 及“熄灭”状态的段码（共阴极编码，如 `0x3f` 对应数字 0）。

```c
[PRE3]
char ledpin[]={3,4,5,7,6,9,8};
// 设置数码管引脚对应的数字端口。

unsigned char num[11]={
0x3f,0x06,0x5b,0x4f,0x66,0x6d,0x7d,0x07,0x7f,0x6f,0x00
};
// 设置数字 0 ~ 9 对应的段码值，以及不显示数字对应的段码值。

int S1=0;// 定义整型变量 S1（个位），初始化赋值为 0。
int S2=0;// 定义整型变量 S2（十位），初始化赋值为 0。

void setup(){
  pinMode(9,OUTPUT);
  pinMode(10,OUTPUT);
  for(int i=0;i<7;i++){
    pinMode(ledpin[i],OUTPUT);// 设置数码管引脚的数字端口为输出模式。
  }
}

void loop(){
  S1=(S1+1)%10;
  if(S1==0){
    S2=(S2+1)%10;
  }
  for(int i=0;i<50;i++){
    digitalWrite(2,0);// 关闭十位数字显示。
    digitalWrite(10,1);// 开启个位数字显示。
    deal(num[S1]);// 显示个位数字。
    delay(10);// 延时 10ms。
    deal(num[10]);// 消除数码管余辉效应。
    digitalWrite(2,1);// 开启十位数字显示。
    digitalWrite(10,0);// 关闭个位数字显示。
    deal(num[S2]);// 显示十位数字。
    delay(10);// 延时 10ms。
    deal(num[10]);// 消除数码管余辉效应。
  }
}

void deal(unsigned char value){
  for(int i=0;i<7;i++){
    digitalWrite(ledpin[i],bitRead(value,i));
    // 将变量 value 的第 i 位数据传输给数组 ledpin 对应的第 i 个数字端口。
    // 共阳极数码管使用 !bitRead(value,i)。
  }
}
[/PRE3]

> **关键点**：`num[10] = 0x00` 是“熄灭码”，用于在切换位选时消除**余辉（鬼影）**，这是动态扫描显示清晰的关键。

## 动态扫描显示的底层逻辑

两位数码管共用一组段选线，靠**位选信号**（十位接 D2，个位接 D10）分时复用。核心流程如下：

1.  **拉低十位位选 (D2=0)，拉高个位位选 (D10=1)** → 送入个位段码 → 延时 10ms → 送入熄灭码（消影）。
2.  **拉高十位位选 (D2=1)，拉低个位位选 (D10=0)** → 送入十位段码 → 延时 10ms → 送入熄灭码（消影）。
3.  循环上述过程（示例中内层循环 50 次约 1 秒），利用视觉暂留效应实现双位同时亮起的假象。

基础扫描代码片段（不含消影的简化版）：

```c
[PRE0]
digitalWrite(2,0);// 关闭十位数字显示。
digitalWrite(10,1);// 开启个位数字显示。
deal(num[S1]);// 显示个位数字。
delay(10);// 延时 10ms。
digitalWrite(2,1);// 开启十位数字显示。
digitalWrite(10,0);// 关闭个位数字显示。
deal(num[S2]);// 显示十位数字。
delay(10);// 延时 10ms。
[/PRE0]
```

计数器自增逻辑配合扫描循环，即可实现 00-99 循环计数：

```c
[PRE1]
for(int i=0;i<50;i++){ 逐位显示语句 ;}
S1=(S1+1)%10;
if(S1==0){
  S2=(S2+1)%10;
}
[/PRE1]
```

## 倒计时核心算法：数值拆解与边界保护

倒计时变量 `val` 范围 0~99。每次递减后，需拆解为十位 `S2` 与个位 `S1` 供显示调用。边界处理防止下溢：

```c
[PRE4]
if(val==0){
  val=0;
}else{
  val=(val-1)%100;
  S1=(val)%10;
  S2=val/10;
}
[/PRE4]
```

同理，按键调整时间时的加减法逻辑（含边界钳位）：

**减少时间（按键防抖延时 200ms）：**
```c
[PRE5]
if(val==1){
  val=1;
}else{
  val=(val-1)%100;
  S1=(val)%10;
  S2=val/10;
  // 设置计时时间减少程序。
}
[/PRE5]
```

**增加时间：**
```c
[PRE6]
if(val==99){
  val=99;
}else{
  val=(val+1)%100;
  S1=(val)%10;
  S2=val/10;
  // 设置计时时间增加程序。
}
[/PRE6]
```

## 声光报警策略：最后一分钟与归零提醒

通过蜂鸣器（接 D11）提供两级报警：
- **倒=2（剩余 1 分钟）**：单次长鸣 1 秒。
- **值=0（倒计时结束）**：急促鸣叫 100 次（每次 1s 开 / 1s 关）。

```c
[PRE7]
if(val==2){
  digitalWrite(11,1);
  delay(1000);
  digitalWrite(11,0);
  // 距离倒计时结束还有 1 分钟，提醒 1 次。
}
[/PRE7]

[PRE8]
if(val==1){
  for(int i=0;i<100;i++){
    digitalWrite(11,1);
    delay(1000);
    digitalWrite(11,0);
    delay(1000);
  }
  // 倒计时结束，提醒 100 次。
}
[/PRE8]
```

## 系统集成：带按键设定的完整倒计时器

最终版融合**动态扫描主循环、按键中断式轮询（D12 减、D13 加）、倒计时递减、分级报警**。主循环每轮扫描 3000 次（约 60 秒），实现秒级递减；按键检测置于扫描内部，保证响应实时性。

```c
[PRE9]
char ledpin[]={3,4,5,7,6,9,8};
// 设置数码管引脚对应的数字端口。

unsigned char num[11]={
0x3f,0x06,0x5b,0x4f,0x66,0x6d,0x7d,0x07,0x7f,0x6f,0x00
};
// 设置数字 0 ~ 9 对应的段码值，以及不显示数字对应的段码值。

int S1;// 定义整型变量 S1，存放个位数。
int S2;// 定义整型变量 S2，存放十位数。
int val=11;// 定义整型变量 val，存放倒计时值，初始化赋值为 11。

void setup(){
  pinMode(12,INPUT);// 设置数字端口 12 为输入模式。
  pinMode(13,INPUT);// 设置数字端口 13 为输入模式。
  for(int i=0;i<14;i++){
    pinMode(ledpin[i],OUTPUT);// 设置数字端口 0 ~ 13 为输出模式。
  }
}

void loop(){
  if(val==0){
    val=0;
  }else{
    val=(val-1)%100;
    S1=(val)%10;
    S2=val/10;
  }

  for(int i=0;i<3000;i++){
    digitalWrite(2,0);
    digitalWrite(10,1);
    deal(num[S1]);
    delay(10);
    deal(num[10]);// 消除数码管余辉效应。
    digitalWrite(2,1);
    digitalWrite(10,0);
    deal(num[S2]);
    delay(10);
    deal(num[10]);// 消除数码管余辉效应。
    digitalWrite(12,1);
    if (digitalRead(12)==0){
      delay(200);
      if(val==1){
        val=1;
      }else{
        val=(val-1)%100;
        S1=(val)%10;
        S2=val/10;
      }
    }
    digitalWrite(13,1);
    if(digitalRead(13)==0){
      delay(200);
      if(val==99){
        val=99;
      }else{
        val=(val+1)%100;
        S1=(val)%10;
        S2=val/10;
      }
    }
  }

  if(val==2){// 距离倒计时结束还有 1 分钟，提醒 1 次。
    digitalWrite(11,1);// 数字端口 11 输出高电平。
    delay(1000);// 延时 1000ms。
    digitalWrite(11,0);// 数字端口 11 输出低电平。
  }

  if(val==1){// 倒计时结束，提醒 100 次。
    for(int i=0;i<100;i++){
      digitalWrite(11,1);// 数字端口 11 输出高电平。
      delay(1000);// 延时 1000ms。
      digitalWrite(11,0);// 数字端口 11 输出低电平。
      delay(1000);// 延时 1000ms。
    }
  }
}

void deal(unsigned char value){
  for(int i=0;i<7;i++){
    digitalWrite(ledpin[i],bitRead(value,i));
    // 将变量 value 的第 i 位数据传输给数组 ledpin 对应的第 i 个数字端口。
    // 共阳极数码管使用 !bitRead(value,i)。
  }
}
[/PRE9]

## 避坑指南与扩展建议

| 易错点 | 解决方案 |
| :--- | :--- |
| **数码管鬼影重** | 必须在切换位选前/后插入 `deal(num[10])` 熄灭操作，延时 10ms 够用。 |
| **按键抖动导致数值跳变** | 检测到低电平后 `delay(200)` 再次确认，软件消抖。 |
| **共阳/共阴极段码不通用** | 共阳极需取反：`!bitRead(value,i)`，段码表亦需取反（如 0 对应 `0xC0`）。 |
| **`pinMode` 循环越界** | 示例中 `i<14` 超出 `ledpin` 长度，实战应改为 `i<7` 或遍历数组长度。 |

**进阶方向**：
- 引入 `millis()` 非阻塞定时，替代 `delay()` 释放 CPU。
- 接入 RTC 模块（DS3231）实现掉电走时。
- 升级为 4 位数码管（TM1637 驱动）简化布线。
- 加入 OLED 同步显示、蓝牙/ WiFi 远程设定。
