当然，向量是数学里非常核心的概念，在物理、工程和计算机领域应用很广。下面是基础介绍和若干例题说明。

### 向量的基本概念

向量兼具大小和方向，常常用箭头表示。它可以在空间中平移而不改变自身属性。

向量可写成 **a** = (a₁, a₂, ..., aₙ)，n为维数。二维写作 **a** = (a₁, a₂)，三维写作 **a** = (a₁, a₂, a₃)。

### 向量的基本运算

1. **向量加法**：同维向量相加，分量对应相加。如 **a** + **b** = (a₁ + b₁, a₂ + b₂)。

2. **向量减法**：同维向量相减，分量对应相减。如 **a** - **b** = (a₁ - b₁, a₂ - b₂)。
