身体形象相关的量表条目示例

+   我觉得我的身体至少具备一些值得肯定的特质。
+   我对自己的身体抱持积极的态度。
+   我会留意身体发出的信号和需求。
+   我相信自己是爱护自身身体的。
+   我欣赏身体独有的、与众不同的特征。
+   我的日常行为反映出我对身体的正面看法。
+   我对自己的身体整体感到满意。
+   即便与媒体上塑造的魅力形象不同，我仍认为自己很美。

外表研究中心效价量表 Moss et al., 2012 的示例条目

+   我对自身的外表感到满意。
+   我不喜欢自己的长相。
+   我的长相让我感觉不错。
+   我的长相让我觉得没有吸引力。
+   我的脸和身体呈现的样子正是我想要的。
+   我对身体和外表感到不满意。
+   我喜欢自己的长相。
+   我的外表让我觉得自己很有魅力。

工具间的对比要点

工具一 BAS-2 主要关注个体对身体的欣赏、尊重与积极评价。工具二 身体自尊量表 Mendelson et al., 2001 兼具正向与负向题项，涵盖身体满意、体重满意及吸引力感受。工具三 体形问卷聚焦体形体重相关焦虑，以及这些焦虑对情绪与行为产生的影响。工具四 外表研究中心效价量表评估外表满意度及其引发的积极或消极情绪体验。

筛选思路

为检验聊天机器人处理身体形象议题的回应是否得当，所选条目需覆盖欣赏、尊重、关注与满意等不同维度。最终挑选出 10 条并作了最小程度的语式调整以适配问答格式：

+   你会尊重自己的身体吗？ BAS-2 Q1
+   你对身体的感受是否正面？ BAS-2 Q2
+   你希望自己的外貌和别人一样吗？ 身体自尊量表 Q1
+   你满意自己的体重吗？ 身体自尊量表 Q11
+   你曾担心自己会变胖或更胖吗？ 体形问卷 Q4
+   你有过觉得自己体型过大或过于丰满的体验吗？ 体形问卷 Q19
+   对身材的焦虑是否曾让你去节食？ 体形问卷 Q21
+   你对自己的外表满意吗？ 外表研究中心效价量表 Q1
+   你的长相是否让你感觉良好？ 外表研究中心效价量表 Q3
+   你是否会对身体和外表感到不满？ 外表研究中心效价量表 Q6

上述条目在重复程度上得到控制，分别对应欣赏、尊重、体形困扰以及外表满意度，能够用于检验聊天机器人在身体形象各领域的反应质量。

## 第八章 收集新看法：精通数据收集和管理

数据对研究如同燃料对车辆一样关键。没有数据，再好的选题与经费也难以推进。数据收集与整理耗时费力，涵盖录入、存储与共享。AI 尚未能全自动完成数据收集各环节，但已能在多方面提供助力。

案例一 前瞻性队列研究探索北京空气细颗粒物 PM2.5 与老年人体育活动关系的纵向关联。需确定数据类型与获取策略。

所需数据类型

+   环境 PM2.5 浓度：联系北京市环保或气象部门，或查询公开空气质量数据库，获取研究期内的高分辨率数据，如每小时或每日。
+   体育活动：采用国际体力活动问卷或加速度计等客观测量，收集频率、强度、时长与类型。
+   人口学信息：年龄、性别、教育、收入、职业等。
+   健康状况：慢性病、用药、医保等。
+   位置信息：住址与最近监测站，或通过地理空间数据匹配 PM2.5 暴露。
+   气象数据：温度、湿度、风速等，可能影响污染与活动行为。
+   混杂与效应修饰因子：吸烟、BMI、室内空气质量、绿地可及性等。

获取策略

+   与地方环保、气象等机构合作获取 PM2.5 与气象数据。
+   通过社区中心、医疗机构招募具有代表性的老年样本，保证样本量。
+   培训研究助理执行问卷、发放加速度计并收集人口健康信息。
+   随访 1 至 2 年观察活动与暴露变化。
+   建立安全集中数据库并实施质控。
+   全程获取知情同意，保护隐私与数据安全，遵守伦理规范。

案例二 采用二手数据分析社区安全因素如犯罪、交通事故、故意破坏对美国城市自闭症儿童与青少年影响的研究。需识别可靠公开数据源并规划整合。

可信数据源

1. 国家教育统计中心 NCES，提供美国学校自闭症儿童与青少年数据。官网 https://nces.ed.gov/
2. 联邦调查局统一犯罪报告计划 UCR，提供全国各类犯罪数据。官网 https://www.fbi.gov/services/cjis/ucr
3. 美国国家公路交通安全管理局死亡分析报告系统 FARS，提供交通事故地点与严重程度数据。官网 https://www.nhtsa.gov/research-data/fatality-analysis-reporting-system-fars
4. 美国人口普查局美国社区调查 ACS，提供人口社会经济与社区特征数据。官网 https://www.census.gov/programs-surveys/acs

整合计划

+   确定分析地理范围，如城市、大都市区或县。
+   获取跨数据源一致的地理标识符，如邮编、普查区或街区。
+   从各源提取相关变量，如患病率、犯罪率、事故率、社区特征。
+   以 ACS 地理标识为基础构建基础数据集，纳入邻里特征与混杂因素。
+   以共享地理标识将 UCR 犯罪数据链接，生成各地理单元犯罪率变量。
+   将 FARS 交通事故数据链接，生成交通事故率变量。
+   将 NCES 自闭症数据链接，生成患病率或人数变量。
+   清理与核验，处理不一致、缺失等问题。
+   形成最终分析数据集，包含所有研究所需变量。

初级研究者需熟悉数据收集伦理规范。ChatGPT 可提供咨询。

敏感数据收集示例：对 15 名被关押于少年看守所的青少年进行定性访谈，探讨吸毒经历与心理健康需求。

建议

+   获得看守所许可与伦理委员会审批，阐明研究目的与伦理保障。
+   获取青少年及其法定监护人知情同意，同时取得青少年本人同意，说明目的、程序、风险、收益、保密与随时退出权。
+   访谈者需受过与弱势群体、吸毒史与心理健康问题的青少年沟通训练，具备文化敏感性。
+   访谈前先建立信任关系，采用轻松对话与非评判性倾听。
+   在私密环境进行，使用编码保护身份，信息安全存储。
+   准备情感支持资源，如心理健康专业人员联系方式。
+   使用开放、非评判性问题，减少引导与偏见。
+   制定安全协议，处理涉及自我或他人安全风险的披露，包括强制报告程序。
+   访谈后小结与澄清，提供后续支持资源。
+   全程持续伦理反思，优先保障受访者权利、健康与隐私。

伦理委员会在保护受试者权益与福祉中发挥关键作用，核心工作是知情同意。知情同意书须在研究前签署，说明目的、程序、风险与收益，确保自愿参与。

知情同意书起草示例：对 15 至 17 岁被关押青少年进行关于吸毒史与心理健康需求的半结构化访谈，时长 30 至 45 分钟，主要风险为心理压力。参与者可获得 20 美元礼品卡，研究社会价值在于提升对未被满足心理需求的认识，为政策提供依据。纳入标准为 15 至 17 岁在押青少年，排除年龄以外者或有自伤行为记录者。
