## 6.5 进度可视化：甘特图

甘特图是把任务与时间对应起来的常用图形。横轴标示时间进度，纵轴列出具体工作，色块长度反映工期，位置反映起止。团队借助它可以追踪执行情况、提前发现风险点、重新安排优先级，也方便对外沟通计划安排。Todo List 的示例可参考图 6-4。
[PRE2]
图 6-4 Todo List 项目计划甘特图

绘制甘特图既可手绘，也可借助专业工具，常见选择如下：

（1）Microsoft Project：微软旗下的专业项目管理软件，能够搭建复杂计划并生成甘特视图，可和 Excel、Word 等办公程序联动。演示用的 Todo List 图见图 6-5。

（2）Asana：协作管理平台，内置甘特视图，支持任务指派、工时统计、依赖设置、进度汇报及虚拟看板。

（3）Trello：轻量级协作工具，提供简化的甘特展示，可创建清单、标签、备注、附件与截止时间，并按时间线归类。

（4）Smartsheet：云端协作平台，界面类似表格，同时提供甘特图、时间表、任务分派、资源调配与定制报表等功能。

（5）TeamGantt：专注于甘特图的在线服务，帮助团队制定并共享计划，支持任务分配、时长追踪、进度报告、评论与文件分享。

（6）Excel 也可绘制甘特图，Todo List 的示例见图 6-6，但其灵活性不及专用软件。Excel 不会自动推算任务依赖，也缺少完善的进度追踪，因此面对复杂项目时专业工具更合适。
