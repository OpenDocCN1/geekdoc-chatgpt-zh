# 第 6 章 触发器
触发器是搭建复杂数字系统的基本单元，与逻辑代数一起构成时序电路的基础。数字电路除做算术逻辑运算外，还需保存中间数据和结果，所以存储电路必不可少。只能存一位的叫存储单元，存一组数据的叫寄存器，存大量数据的叫存储器，寄存器和存储器都由多个存储单元构成。

触发器的本质是保存1位二值信息，也称半导体存储单元或记忆单元。n个触发器构成的寄存器可存储n位二值数据。

触发器应具备：
（1）两个稳定状态：0和1；
（2）不同输入下可置0或1；
（3）输入消失后状态保持不变。

按功能分，有RS、D、JK、T和T′触发器。按结构分，有基本RS、同步、主从、边沿触发器。

需注意，结构形式与逻辑功能是两回事，无固定对应。同一功能可用不同结构实现，同一结构也可实现不同功能。选用时不仅要知道功能，还必须明确结构类型，才能把握动作特性，完成正确设计。

工作状态分现态和次态。输入前状态叫现态，用Qn表示；输入后状态叫次态，用Qn+1表示，二者为相邻两个离散时刻的输出。

常用的时序逻辑描述方法有五种：逻辑图、状态转移方程、状态转移真值表、状态转移图、工作波形图。形式不同但本质相通，可互相转换。本章对各类触发器做以上五种描述。

## 6.1 基本触发器
基本触发器又称直接复位置位触发器，有时也叫锁存器，是结构最简单、构成其他触发器的基础。
