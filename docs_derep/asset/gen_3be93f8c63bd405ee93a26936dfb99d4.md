# 新浪财经自动采集 + DeepSeek 秒级研判

想把新浪财经的快讯变成可用的投资线索，核心是三件事：抓得稳、解得准、判得快。下面这套流水线把网页解析、异常兜底和大模型分析串成了一条可复用链路，适合自媒体和量化研究场景快速落地。

先说稳健抓取。请求回来后立刻把响应编码锁定为 utf-8，避免中文乱码。HTML 交给 BeautifulSoup 用 lxml 解析，解析速度和容错都更好。

标题提取做多层兜底，按优先级依次尝试 h1.main-title、h1.article-title、meta 标签 property 为 og:title，最后退到标准的 title 标签。拿到元素后优先取 content 属性值，若没有 get 方法则取文本内容，统一 strip 去空格，没抓到就返回“标题未找到”。

正文提取同样多套方案：先找 id 为 artibody 的容器，再尝试 class 为 article-content、content 的节点，最后用 itemprop 为 articleBody 的 div 兜底。找到容器后只取其直属子级 p 标签的纯文本，过滤空段落后以换行拼接，整体 strip。找不到则返回“正文内容未找到”，并把标题和正文组成字典返回。

异常处理分两层。网络层 RequestException 触发时返回标题“请求失败”、内容为“网络请求错误: …”、error 标记为 True；其它解析异常则返回标题“解析失败”、内容为“解析异常: …”、error 为 True。示例脚本里会打印状态 成功/失败、标题和内容，URL 以 https://finance.sina.com.cn/roll/2025-04-14/doc-XXXXXX.shtml 为例调用。

解析完进入 AI 分析。借助 OpenAI 客户端调用 deepseek-chat 模型，把新闻交给一个设定了完整人设的财经专家角色。提示词里明确语言为中文、背景为多年全球与 A 股经验、性格严谨细致、目标读者是投资者和分析师。技能拆分为行业识别、行业分析、影响评估、报告撰写等核心能力，外加数据收集、市场研究、政策解读和沟通等辅助能力。规则强调准确性、及时性、客观性和全面性，要求自动识别新闻行业并评估对 A 股个股和概念板块的影响。
