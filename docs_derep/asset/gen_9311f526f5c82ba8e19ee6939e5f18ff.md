> **小贴士**
> TensorFlow 中 `padding="SAME"` 的本质是：先对输入进行填充，再执行卷积运算。

#### 2. Batch Normalization 速览

批量归一化（`batch_normalization`）是当下最主流的数据标准化手段。它能显著加快模型收敛速度，同时有效抑制过拟合风险。

[PRE2]

核心参数详解：

*   **axis**：指定归一化的维度轴，默认 -1（即通道轴）。
*   **momentum**：移动平均的动量系数，默认 0.99。
*   **epsilon**：防止分母为 0 的微小常数，默认 0.01。
*   **center / scale**：分别控制是否添加偏移（Beta）与缩放（Gamma），默认均开启。若后接线性层，`scale` 可设为 False 以避免冗余计算。
*   **初始化器/正则化/约束**：分别针对 Beta、Gamma、移动均值/方差提供定制入口，默认均为标准配置（zeros/ones 等）。
*   **training**：标识训练/推理模式，默认 False。
*   **trainable**：是否纳入可训练变量集合，默认 True。
*   **fused / renorm 相关**：提供融合算子加速及 Batch Renorm 扩展支持。
*   **virtual_batch_size / adjustment**：虚拟批次大小与结果微调接口。

调用极简：直接 `tf.layers.batch_normalization(inputs)` 即可。
