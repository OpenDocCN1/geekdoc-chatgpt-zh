下面介绍 JavaScript 类的基础概念。

在讲解类之前，先用生活案例来类比。玩乐高时，每套都会附带组装说明书。这份说明书就相当于类。

再举一个贴近生活的例子：自行车。现实中“自行车”就是一个类，定义了该类共有的属性如颜色、车轮数，以及方法如骑行、刹车、按铃。而你手上的那辆自行车，就是该类的具体实例，配置可能各不相同。
