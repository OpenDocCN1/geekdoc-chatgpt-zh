把截距项 $x_0^j$ 固定为 1 后完成一次更新，再回到步骤（1）继续迭代。

这样就能看出，当前点的梯度是被全部训练样本共同决定的，式子 $\frac{1}{m} \sum_{j=0}^{m} (h_\theta(x_0^j, x_1^j, \cdots, x_n^j) - y_j) x_i^j$ 只是为了让这种整体依赖关系更直观。

### 2.7.4 梯度下降的典型短板
梯度下降在使用中容易碰到以下问题。
1. 靠近最优点时前进速度明显变慢。
2. 沿直线搜索时会出现不理想的情况。
3. 下降轨迹容易呈现锯齿状的“之”字形。

关于梯度本身，也需要留意三点。
1. 梯度是一个既有方向又有大小的向量。
2. 梯度所指的方向就是方向导数取得最大值的方向。
3. 梯度的模长等于该方向上的最大方向导数值。

### 2.7.5 让梯度下降更稳的调参要点
实际调参时很难一步到位，主要围绕以下三个方向优化。
1. 学习率 $\alpha$ 的选取：初始化时常凭经验取 1，具体数值要看数据。可以从大到小尝试多个取值，观察损失是否持续下降；若无效则需要增大步长。步长过大容易冲过最优解，步长过小则迭代迟缓、耗时增加。
2. 参数初值的选择：不同的初始点可能收敛到不同的极值，梯度下降容易陷入局部最优。只有在损失函数为凸函数时才保证全局最优。为降低风险，需要多次用不同初值运行，保留使损失最小的那一次结果。
3. 特征标准化处理：不同特征的取值范围差异会导致迭代不均衡。对特征做标准化使均值归零、方差为一，可有效加快收敛并减少运行时间。

### 2.7.6 SGD 与 BGD 的本质差别
随机梯度下降 Stochastic GD 和批量梯度下降 Batch GD 是两种常用变体，核心是在计算效率与稳定性之间做权衡。

设线性模型为：
$h_{\theta}(x_0, x_1, \cdots, x_n) = \theta_0 x_0 + \theta_1 x_1 + \cdots + \theta_n x_n$ (2-39)
损失函数为：
$J(\theta_0, \theta_1, \cdots, \theta_n) = \frac{1}{2m} \sum_{j=0}^{m} (h_{\theta}(x_0^j, x_1^j, \cdots, x_n^j) - y^j)^2$ (2-40)
其中 $m$ 为样本数，$j$ 为样本索引。

**随机梯度下降的思路**
损失可写成每个样本的粒度：
$J(\theta_0, \theta_1, \cdots, \theta_n) = \frac{1}{m} \sum_{j=0}^{m} (y^j - h_{\theta}(x_0^j, x_1^j, \cdots, x_n^j))^2 = \frac{1}{m} \sum_{j=0}^{m} \text{Cost}(\theta, (x^j, y^j))$ (2-41)
对参数按样本梯度更新：
$\theta_i = \theta_i + (y^j - h_{\theta}(x_0^j, x_1^j, \cdots, x_n^j)) x_i^j$ (2-42)
每次只用一个样本更新一次。由此带来的噪声比批量方法更大，并非每次迭代都严格沿整体最优方向前进。

**批量梯度下降的思路**
先求总体梯度：
$\frac{\partial}{\partial \theta_i} J(\theta_0, \theta_1, \cdots, \theta_n) = \frac{1}{m} \sum_{j=0}^{m} (h_{\theta}(x_0^j, x_1^j, \cdots, x_n^j) - y^j) x_i^j$ (2-43)
再沿负梯度方向更新：
$\theta_i = \theta_i - \frac{1}{m} \sum_{j=0}^{m} (h_{\theta}(x_0^j, x_1^j, \cdots, x_n^j) - y^j) x_i^j$ (2-44)
每步都需要遍历全量训练数据，样本越大迭代越慢。

**表2-4 随机梯度下降法和批量梯度下降法对比**

| 方法 | 特点 |
| :--- | :--- |
| 随机梯度下降 | 1. 采用所有数据来进行梯度下降。2. 在样本量很大的时候，训练速度慢 |
| 批量梯度下降 | 1. 用一个样本来进行梯度下降。2. 训练速度很快。3. 仅仅用一个样本决定梯度方向，得到的值有可能不是全局最优解。4. 就收敛速度来说，一次迭代一个样本，导致迭代方向变化很大，不能很快地收敛到局部最优解 |

## 2.8 线性判别分析 LDA 全解

### 2.8.1 LDA 的核心逻辑

步骤：
- 1. 计算类内散度矩阵 $S_w$。
- 2. 计算类间散度矩阵 $S_b$。
- 3. 计算矩阵 $S_w^{-1}S_b$。
- 4. 取矩阵 $S_w^{-1}S_b$ 最大的 $d$ 个特征值。
- 5. 取对应的 $d$ 个特征向量组成投影矩阵 $W$。
- 6. 对每个样本 $p_i = W^T x_i$。
- 7. 输出 $\bar{D} = \{(p_1, y_1), (p_2, y_2), \dots, (p_m, y_m)\}$。

## 2.9 主成分分析 PCA 详解
主成分分析是一种统计降维方法，通过正交变换把可能相关的变量转换为线性无关的主成分。
