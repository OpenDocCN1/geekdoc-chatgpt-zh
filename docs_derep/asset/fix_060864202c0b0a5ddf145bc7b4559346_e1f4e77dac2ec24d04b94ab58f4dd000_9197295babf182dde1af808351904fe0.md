- 多次提及对菜品熟度的需求，但存在熟度把控不准问题。
- 偏好肉汁充足的牛排，反感肉质干柴。
2. 酱汁偏好两极分化
- 喜欢浓郁调味但要求平衡 如 "酱汁偏咸""柠檬酱太酸"。
- 部分顾客认为酱汁喧宾夺主。
3. 食材新鲜度敏感
- 高频提及海鲜新鲜度问题 如 "虾不新鲜"。
- 对蔬菜状态要求高 3条批评配菜老化/不新鲜。
4. 甜点甜度争议
- 普遍反映甜品过甜 提拉米苏、马卡龙、焦糖布丁均被指"甜度过头"。
- 期待层次感 如"可可粉少""奶油带冰碴儿"。
