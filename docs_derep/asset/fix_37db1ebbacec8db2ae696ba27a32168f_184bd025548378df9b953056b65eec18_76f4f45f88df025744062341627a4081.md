# 第四章 数字时代劳动基准的再设计
沈建峰
中央财经大学法学院教授

先把研究边界划清。网络时代既可以当作一个时间标签，也可以当作一套技术语境。按时间看，就是互联网普及后深度改写生产生活的那段当下。若只按这个时间义来谈劳动基准创新，范围会大得抓不住重点。更有操作性的切入点是技术义：网络、信息、数字技术落地后，劳动基准的理论与制度出现了哪些新问题。本章聚焦的就是这种技术驱动的变动。

严格说，网络技术、数字技术、信息技术概念并不完全重合，网络更强调互联连接的面向。按最窄的理解，这章本可以只谈互联网带来的冲击。现实是，今天真正让工业时代规则承压的，是互联网与数字、信息技术叠加使用的综合效应。所以这里说的网络时代，实质是数字时代和信息时代劳动基准共同面对的议题，行文里也不刻意区分这几个词。

思路很清晰：先描摹数字劳动世界的主线变化和制度压力，再回头看劳动基准法怎么回应。过程中要先厘清劳动基准的边界，打破劳动基准法只是公法的刻板印象，在此基础上讨论具体制度如何创新。

## 一、数字用工全景与劳动法的新压力
### （一）学界如何概括用工关系的变局

# 去组织化的三重松动：保障、集体、权力
关于数字或网络时代雇佣关系的演进，学界表述很多。一种主流判断是，用工形态正在联动出现去保障化、去集体化、去权力化的转向。

去保障化说的直白点，就是技术变革可能让我们告别今天看得很重的岗位稳定^[([1]](#txt005.html#footnote_content_txt005_1))。数字技术让岗位更易波动，劳动法传统上强调的工作保障、薪酬保障、工时保障都更难兑现。

去集体化指的是数字工具把劳动者供给侧切得越来越细，绩效差异被放大，个体化增强，协同发声、争取共同利益的难度上升^[([2]](#txt005.html#footnote_content_txt005_2))。

去权力化描述的是数字工具放大了管理方控制力、压缩了劳动者自主空间。具体表现为用工管理朝着扩大和完善对雇员和受托人的监督可能性的方向；朝着更多地使用工作流程的数字化处理方法和对员工进行算法管控的方向；朝着人员、工作和生产过程中的数据、信息及知识资源的单向积累的方向^[([3]](#txt005.html#footnote_content_txt005_3))。
