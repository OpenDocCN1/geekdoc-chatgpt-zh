##### 2. 线性关联度量指标

Pearson 积差相关系数（$r$）用于量化双变量直线相关的紧密程度与方向。其数学定义为协方差除以两变量标准差乘积，式子如下：

$$r_{xy} = \frac{S_{xy}}{S_x S_y}$$

式中 $S_{xy}$ 为协方差，$S_x$ 与 $S_y$ 分别代表 x、y 的离散程度量。
