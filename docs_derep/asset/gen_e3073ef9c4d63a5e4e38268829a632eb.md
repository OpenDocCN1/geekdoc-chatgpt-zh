# 第1章 扩散模型概览

扩散模型在辅助人类完成各类任务上发挥着愈发关键的作用。自 DALL·E 2、Stable Diffusion 等图像生成模型以及 ChatGPT 等对话模型崭露头角以来，多模态交互正快速转向以文本为核心的驱动方式，例如文生图、文生视频、文生 3D 等。

- 文本生成图像：这是扩散模型最成熟也最受关注的方向。只需一段提示词或几个关键词，模型就能把文字描述转化为对应视觉作品。本章开篇提及的 DALL·E 2、Imagen 以及完全开源的 Stable Diffusion 等，均属于文本-图像多模态扩散范式。图1-19 展示了由 Imagen 生成的若干文字转图像案例，后文会集中展开相关应用。

### 2.2 Hugging Face 开源工具箱

除提供 Hub 便于社区分享模型和数据集外，Hugging Face 还在 GitHub 上开源了一系列机器学习库和工具，如图2-12 所示。简要列举如下。

- Transformers：提供一系列 API 与工具，使用者可轻松下载并训练 SOTA 预训练模型，降低计算成本与碳排放。支持 PyTorch、TensorFlow 与 JAX，并可互操作。模型还可导出为 ONNX、TorchScript 等格式以便生产部署。
- Datasets：只需一行代码即可加载各类数据集，支持音频、计算机视觉和自然语言处理等任务。借助 Apache Arrow 支持零拷贝读取与处理大型数据集，并与 Hub 深度集成，便于共享。
- Diffusers：操作扩散模型的工具箱，可方便地使用多种扩散模型生成图像、音频，并使用不同噪声调度器调节推理速度与质量，支持多种模型类型。
- Accelerate：添加 4 行代码即可在任意设备上运行原有 PyTorch 训练脚本，将多 GPU、TPU 等相关模板抽象出来，其余代码保持不变。
- Optimum：Transformers 的扩展，提供性能优化工具，可在特定目标硬件上高效训练与运行模型。
- timm：PyTorch Image Models，包含图像模型、优化器、调度器及训练验证脚本等。

除上述库外，常用的开源库还有 Tokenizers、Evaluate 等。Tokenizers 是基于 Rust 的高性能分词器，可在 20 秒内用 CPU 完成对 1GB 文本的分词。Evaluate 则使用数十种流行指标对数据集和模型进行评估。可在 Hugging Face 的 GitHub 组织页面查看全部开源库。
