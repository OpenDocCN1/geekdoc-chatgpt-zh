把形态迥异的子网连成一个整体，就是网络互连要解决的问题。互连一方面打破了物理距离和覆盖范围的限制，让远隔千里的节点可以共享资源；另一方面在布网时可以控制单网的规模，兼顾效率，也能降低管理复杂度。

### 1. 互连发生的层次
两个物理网只要在某一层的数据表示或格式相同或能互相识别，就能在该层实现互连。以两个 10BaseT 以太网为例，它们使用相同的总线和网卡，比特流的电信号形式一致，集线器把两段总线直接连起来，电信号就能通达，源主机物理层发出的信号经集线器到达目的主机物理层，被识别后提取比特，再逐层剥离首部，最终送达目的进程，这就是物理层互连。

如果一个网用双绞线、一个网用光纤，物理层的信号形态完全不同，集线器无法直接相连。但两者都是以太网，数据帧格式一致，就可以用网桥在数据链路层完成互连。网桥只负责帧的转发，帧内部的二进制是电信号还是光信号，由各自物理层决定。

再往上，若帧格式也不相同，网桥就不够用。可只要数据字段里的数据包格式一致，就能在网络层互连。互联网要求接入的设备都运行 TCP/IP，网络层的数据格式与处理方式因此得到统一。IP 协议是 TCP/IP 体系的关键协议之一，与地址解析协议、逆向地址解析协议、差错控制报文协议等一起规范网络层的数据交换格式与流程，借此把大量异构网连起来。

由此可见，不同层次互连的要求各不相同：①物理层互连要求设备兼容、信号相同；②数据链路层互连要求协议与帧格式相同；③网络层互连要求协议与数据包格式相同；④高层互连面向协议完全不同的两个网络。

按层次选择连接设备。物理层常用中继器和集线器。中继器对抗信号衰减后放大转发，让信号继续传播。集线器扩展局域网时把若干物理网段的总线连通，要求各段表达比特的信号格式一致，即必须采用相同的物理层协议。数据链路层的互连设备是网桥，按需把数据帧从一个网段转发到另一个网段，要求被连网段具有相同的数据帧结构，即使用相同的链路层协议。网络层互连设备是路由器，要求各物理网都遵循 IP 协议，按 IP 规定处理与传输数据。网络层以上互连统称高层互连，设备统称网关或应用网关，主要职能是协议翻译。

仅在物理层和数据链路层进行的互连只能算是局域网扩展。集线器和网桥连接的是同类物理网，连接后的网络只是规模更大的局域网，各主机仍共享同一个网络号。真正意义上的“网络互连”指的是不同类型的物理网相连，主要由路由器承担。

互连后的网络在逻辑上可看作一个整体，称为虚拟互连网络。物理上异构、设备差距很大，但在网络层看来像是单一整体，计算机由此连通。

### 2. 互连的实现思路
不同物理网差异可能很大，互连不仅要物理通，还要逻辑上相互认可。资源共享的基本前提是数据单元能在另一网中自由传输并被使用，因此要求数据单元格式一致。只有格式一致，对方才能识别并利用。但差异往往使这很难满足，例如 PPP 与以太网在数据链路层规定了各自的帧格式，单靠该层难以统一。

关键在于，两个采用相同网络模型、例如都用 OSI 模型或 TCP/IP 模型的物理网，本身具备相同的层次结构。只要在某层选用相同的协议，该层的数据格式就一致，两个网在该层得到统一，一个网在该层发出的数据单元可被另一网识别与处理。内部其他层的协议与实现方式不再影响互连。

换句话说，网络接收来自另一网的数据单元后，可按自身要求进行处理。例如以太网在网络层收到来自他网的数据包后，可在链路层按本网规则把数据包封装成以太网帧进行传输与使用。事实上，互联网正是借助 IP 协议在网络层把所有物理网统一起来的。

### 3. 互连的核心组件
路由器是互联网的标准组件，实现网间连接。若网络号不同则视为不同网络，不同网络的连接依靠路由器作为枢纽。路由器系统构成互联网的主体骨架，是通信子网中的交换节点，形成 Internet 的骨架。

一个网络可通过路由器接上各种类型、不同规模的网络，互联网正是这样逐步互连发展成覆盖全球的网络。当前制约网络发展的主要瓶颈之一是路由器的处理速度，路由器的可靠性也直接影响连接质量。因此在园区网、地区网乃至整个互联网研究中，路由器技术始终居于核心，其演进折射出互联网研究的大方向。

路由器是相连网络的共同边界，也是各网络的内部成员。路由器的一个端口连着一个网络的总线，该端口拥有属于该网络的 IP 地址。作为内部成员，它能像工作站一样广播与接收数据帧；作为另一网络的内部成员，当端口收到需要送往另一网络的数据帧时，会把数据包封装成该网络的帧，通过连接端口以广播形式转发。路由器同时属于多个网络内部，必须同时运行各网络采用的协议。

路由器是连接两个相邻网络的交换节点，反过来一个网络也是连接两个路由器的链路。若该网络足够简单，两路由器间无其他连接节点，则构成相邻节点。若两远程网络相连，可用通信链路把两边界路由器直接连通，此类链路是特殊直联网，与之相连的端口不需 IP 地址。

路由器与网桥在外观上相似，都具备处理器与内存、多个端口并按表决策转发。区别主要在：第一，路由器工作于网络层，实现网络级互连；网桥工作于链路层，连接不同局域网。第二，路由器构成的互连网可存在回路；网桥互连网若有回路易产生广播风暴，故必须避免回路，实践中难以完全杜绝。第三，二者在安全策略、实现技术、性能、价格等方面各异。第四，网桥扩展的局域网仍属一个局域网，具有相同网络号；路由器连接的网络通常是不同物理网，各自网络号不同。

## （三）互连网络协议
IP 即 Internet Protocol，其互连能力源于对 IP 地址和数据包格式的规范，为不同物理网互连提供了统一平台。各网只要运行 IP 协议，就能识别 IP 地址和数据包格式，并按 IP 规定处理。

### 1. IP 地址
IP 地址是互联网为每个网络连接即网卡分配的全球唯一标识。长度 32 比特，由网络号和主机号组成，为便于记忆划分为四个字节，用十进制点分表示，如 172.16.122.204。

#### （1）IP 地址的类别
按 32 位地址首字节的前几位分为 A、B、C、D、E 五类。A、B、C 类为单播地址，用来分配给计算机，可作源地址也可作目的地址；D 类为组播地址，用于组内广播，一个地址标识多台目的主机，只能作目的地址；E 类为保留地址，供特殊用途。

#### （2）特殊的 IP 地址
若干地址不分配给具体计算机，具有特殊用途，路由器据此选择路径：

第一，广播地址。主机位全为 1 的地址为广播地址，向指定网络所有主机发送数据。IP 全为 1 的 255.255.255.255 为有线广播地址，向本网络所有主机发送。

第二，零地址。主机号为 0 的地址表示该网络本身，是一个网络号；网络号为 0 的地址表示本网络上的某台主机。全零地址 0.0.0.0 代表本机自身。

第三，回送地址。任一以 127 开头的地址为回送地址。程序若把回送地址作目的地址，协议软件不会把数据报发往网络，而是直接返回本机，便于测试。

网络号与主机号全 0 或全 1 的地址均为特殊地址，不能分配。

#### （3）子网与掩码
网络内部主机过多会导致管理复杂、效率下降，可划分为若干子网。子网掩码用于在主机号空间划分子网，用主机号的高若干位作为子网号。对子网而言，网络号加子网号构成新的网络号。子网掩码为 32 位数字，与 IP 地址一一对应，可把 IP 地址中的主机号再分为子网号和主机号。掩码中为 1 的位对应子网号，为 0 的位对应主机号。划分后须对外公布掩码，外界路由器把各子网视作独立网络处理。

路由器寻址时视情况使用地址中的子网号或主机号。IP 地址与子网掩码做“与”运算得到所在网络的子网号，地址与掩码反码做“与”运算即可得到主机地址。

#### （4）IP 地址的分配
IP 地址作为资源由网络管理机构提供，以连续地址块分配给建设单位。建设单位可按计算机最大数量购买一个网络号，从而获得该号下的连续地址。也可通过设计子网掩码把地址分配给二级单位。二级管理员可把 IP 指定给用户，也可让用户共享地址，采用动态分配时上网计算机由系统临时分配空闲地址。

获得 IP 地址后需绑定到网卡，网卡通常有一个接电缆的接口，是网络的物理接口。IP 地址表示一个网络连接即网络接口。主机可插多块网卡，故可有多物理接口；一块网卡可绑定多个 IP，故可有多网络接口，理论上一台计算机可拥有多个 IP。

对外提供信息服务的物理网除大量客户机外，还应有多个服务器，如 Web 服务器、FTP 服务器、电子邮件服务器和 DNS 服务器，每台均需分配 IP。服务器的实质是一个管理资源并为用户服务的软件，通常分为文件服务器、数据库服务器和各类应用系统软件。一台性能足够强的计算机可安装多个服务器，但服务器需为大量客户服务，负载很高，若运行能力不足会成为瓶颈，拖慢整体性能。

运行服务器的计算机处理速度与系统可靠性远高于普通 PC，因其需不间断工作。普通 PC 死机仅影响自身，而服务器保存大量重要数据并提供代理上网、安全验证、邮件等服务，一旦故障将造成巨大损失并导致网络瘫痪。因此服务器计算机在稳定性、安全性、性能等方面要求更高，CPU、芯片组、内存、磁盘、网络等硬件均与普通机不同，被专用于服务器运行，久而久之被称为服务器。服务器是网络节点，承担约 80% 数据与信息的存储与处理，也被称为网络的灵魂。

一台超强计算机上可运行多个服务器，因每个服务器需各自 IP，这些 IP 都绑定在此机上。只有这种情况下计算机才需绑定多个 IP。大多数情况下一台计算机绑定一个 IP。

#### （5）IP 报文的格式
IP 协议规定了网络层传输的数据包格式。数据包由 IP 报文头和数据两部分组成，数据为传输层交付的负载。报文头是网络层为传递数据加入的控制信息，又称首部。IP 报文头前 20 字节为不可或缺的基础部分，即固定首部；其后可有若干选项。报文头大小以 4 字节为单位计数，随选项多少而变。填充项紧随选项之后，保证报文头长度为 4 字节的整数倍。

### 2. 数据包
#### （1）数据传输服务
在通信子网中网络层为最高层，在资源子网中其上层为传输层，网络层为传输层提供从源主机到目的主机的包传输服务。一般而言网络层可向传输层提供两种服务：面向连接的虚电路服务和无连接的 IP 数据报服务。

第一，虚电路服务。面向连接服务可在各层使用，虚电路服务特指网络层使用的面向连接服务。过程为源主机先发通信连接请求数据包，寻找并记录经过的一系列路由器，形成通往目的主机的最优路径；目的主机返回同一数据包，包中载有记录全路径的路由信息表，随后在源与目的主机间建立连接通路即虚电路；后续数据包按路由信息表在各路由器间传输；通信结束释放虚电路。

虚电路服务采用分组交换，与电话系统采用的电路交换本质不同。电话系统通过程控交换机在两电话间建立实际物理电路，通话期间线路独占，利用率低。虚电路是逻辑电路，一条物理线路可承载多条逻辑电路，同时服务多对通信。

虚电路适合大数据量传输，同一批数据包携带相同路由信息表，中间节点无需复杂路径计算，降低延迟。只有一个通道，目的主机接收顺序与源主机发送顺序一致，形成队列，彼此关联。若有包出错，需重传后续包。因此虚电路服务须检查传输是否出错，保证最终数据包及顺序正确，为可靠传输服务。

第二，IP 数据报服务。IP 数据报服务特指网络层使用的无连接服务。交换节点依据数据包首部中的目的 IP 地址，运用路径选择算法决定每段传输路径。适合小数据量通信。

IP 数据报即数据包，若强调差异，数据包常用于描述网络层数据单元流动，IP 数据报则用于具体格式讨论。在 IP 数据报服务下，每个数据包独立传输，可能走不同路径，可能出现后发先至，即目的主机接收顺序与发送顺序不一致，称为错序。由于各包彼此无关联，服务无法解决丢失、重复等错误，为不可靠传输。

在互联网中，网络层向传输层提供的基本服务是 IP 数据报服务，即 IP 头为 20 字节固定首部时提供的服务。网络层也可提供虚电路服务，需在 IP 首部增加松散源路由、严格源路由、路由记录等选项，属于特殊处理。一般认为网络层常规服务是 IP 数据报服务。

#### （2）数据传输技术
面向连接与无连接是两种不同的数据传输技术，各有优劣。

第一，面向连接传输数据技术。其工作模式类似电话系统，特点包括：①必须经过连接建立、维护、释放三个阶段；②各交换节点按包首部记录的路由信息表向下一节点转发；③传输连接类似管道，发送端在一端放入数据，接收端在另一端取出，保证顺序，传输相对可靠。

# 第二，无连接服务传输数据技术
无连接服务类似于邮政信件投递，特点主要有：①各数据包均包含源节点地址与目的节点地址，由沿途交换节点逐步向目的地址传输，来自同一报文的若干包彼此独立；②不涉及连接建立、维护、释放过程；③目的主机可能收到乱序、重复的数据包，也可能出现丢失。
