# 文献综述与泛逻辑运算模型公理体系构建

## 相关文献研究脉络梳理

既往研究对蕴含算子（i-norm）的探讨颇为深入。文献[149]对具体蕴含算子及其性质展开了实验考察；文献[150]揭示了Lukasiewicz蕴含在满足蕴含公理的同时兼顾同一律，且通过选取合适的非算子，可构造出一类兼容二值逻辑的强蕴含算子。文献[143]通过三种算子定义涵盖了常见蕴含算子，并分析了部分算子的表示形式。文献[151]提出了蕴含算子应遵循的若干准则，剖析了典型算子特性并将其应用于柔性推理。文献[152]聚焦三段论推理性质，考察了常用串行推理算子对事实可信度变化的敏感度。

文献[153]至[156]确立了柔性蕴含算子与柔性推理算子的互逆关系，在R蕴含基础上定义了广义蕴含算子，并给出了其退化为一般蕴含算子的条件。文献[157]进一步拓宽了定义路径：利用S蕴含与s-norm同样能定义广义蕴含算子，且Hamacher算子可实现R蕴含与S蕴含的统一。文献[158]将蕴含界定为条件概率测度，将推理计算转化为条件概率计算；文献[159]则将其定义为广义包含度。文献[160]提出用三个蕴含算子诠释推理规则的新思路；文献[161]则探讨了柔性分离规则中对蕴含算子的全局性约束。关于柔性等价算子（q-norm）的研究多与蕴含算子结合进行，不同蕴含对应不同等价，目前鲜见专门针对等价算子的独立研究。

### (2) 柔性平均算子演进历程

文献[162]率先从数值计算视角引入平均算子概念，证明Zadeh算子是唯一同时满足交换律与结合律的平均算子。文献[163]最早提倡研究柔性补偿算子，即与、或算子的加权几何平均与加权算术平均。文献[164]给出了补偿算子的通式。文献[165]认为评价算子实为平均算子。文献[166]利用t-norm构造补偿算子。文献[138]提出更宽泛的平均算子定义，并深入讨论补偿算子的性质、构造、生成函数及图像表示。文献[167]指出最常见的两类平均算子为加权几何平均与加权算术平均，给出了补偿算子的γ模型及其性质研究。文献[168]揭示了平均算子、t-norm、s-norm与非算子的内在联系，指出任意平均算子均同构于单位区间上自守函数的算术平均。文献[169]则专门研究了柔性算术平均的性质。

### (3) 柔性组合算子研究现状

组合运算（c-norm）研究肇始于可能性理论、证据理论、可信度理论、主观贝叶斯方法等著名不确定性推理模型，但这些模型多基于应用经验提出，理论支撑薄弱，存在局限性。1985年Hajek指出并行组合公理在(-1, 1)区间构成有序Abelian群。文献[170]借助似然比通过生成函数定义并行组合运算模型，但形式化研究仍显不足。文献[171]针对文献[172]的质疑，提出了类似并行组合运算的一致范数，并给出了其形式化表达及满足特定性质的生成函数。

## 5.3.3 三角范数理论与柔性命题连接词的张力

半个多世纪以来，三角范数理论在柔性算子研究上取得长足进展，但若对标建立完善柔性逻辑命题连接词的需求，仍存显著短板：

1.  **数学与逻辑割裂**：现有研究多孤立地从数学角度考察各类柔性算子，未将三角范数理论与逻辑学体系深度融合、系统推进。尽管早已发现算子的连续可变性，却鲜有人深挖其逻辑与物理意蕴，导致无法识别自然界普遍存在的关系柔性，亦无法借助广义相关性与自相关性解析逻辑运算模型的连续演变。这使得数学成果难以嵌入逻辑学框架，致使柔性算子研究长期停留在数学层面，难以直推柔性逻辑发展。
2.  **核心算子与逻辑规律脱节**：研究最多的n-norm、t-norm、s-norm虽定义、性质、构造已臻成熟，却难以与对立不充分世界的逻辑规律紧扣，无法理解其表现形式多样性与连续可变性的本源，从而缺乏底气用其取代Zadeh算子组在柔性逻辑中的核心地位，进而制约了其他柔性逻辑算子的研究纵深。
3.  **蕴含算子分歧最大**：逻辑学离不开蕴含算子（i-norm）、串行推理算子（r-norm）与等价算子（q-norm），其中蕴含算子争议最烈。各系统、各作者常基于特定应用需求自行定义，局限性与随意性大。主流观点认为蕴含算子与串行推理算子互逆，故后者处境相似；等价算子由蕴含算子与与算子合成，其状况亦与前二者类同。
4.  **平均算子逻辑地位缺位**：现有逻辑学体系未将平均算子（m-norm）纳入逻辑算子范畴，尽管三角范数理论中m-norm研究近期突飞猛进，已形成统一公理集与生成函数，但对其连续可变性及物理意义的挖掘尚浅。
5.  **组合算子理论匮乏**：除少数实用不确定性推理模型外，主流逻辑学亦未认可组合算子（c-norm）的逻辑地位，三角范数理论对此研究更是薄弱，基本停留在定性阶段。

**核心洞见**：三角范数理论最大特质在于其“柔性”——如儿童手中的橡皮泥，期望何种形态皆可塑造。这是优势亦是劣势。故三角范数虽是研究柔性算子的关键数学工具，却无法替代柔性逻辑学自主研究；反而需要柔性逻辑依据对立不充分柔性世界的逻辑规律，对逻辑算子提出恰当约束，以正确规范三角范数[119, 120, 173-175]。

**实践体会**：唯有将三角范数理论与逻辑学紧密耦合研究，方能得理想成果。我们发现的关系柔性及其广义相关性、广义自相关性，正是对立不充分柔性世界逻辑规律的体现；用其约束三角范数，即得本书各类泛逻辑运算模型。

## 5.4 命题泛逻辑运算模型：公理与基模型

### 5.4.1 泛逻辑运算模型公理体系

#### 1. 泛非运算公理
设一元含参运算 $N(x, k): [0, 1] \to [0, 1]$，若满足下列公理，即为泛非运算：
*   **边界条件 N1**：$N(0, k)=1, N(1, k)=0$。
*   **单调性 N2**：$N(x, k)$ 单调减，即 $\forall x, y\in[0, 1], x<y \Rightarrow N(x, k)\ge N(y, k)$。
*   **严格单调性 N2'**：$N(x, k)$ 严格单调减，即 $x<y \Rightarrow N(x, k)> N(y, k)$。
*   **连续性 N3**：$N(x, k)$ 连续，即 $\forall x\in(0, 1), N(x^-, k)=N(x, k)=N(x^+, k)$（$x^-, x^+$ 为左右邻元）。
*   **逆等性 N4**：$N(x, k)$ 具逆等性，即 $\forall x\in[0, 1], N(x, k)=N^{-1}(x, k)$（$N^{-1}$ 为逆运算）。

#### 2. 泛与运算公理
设二元含参运算 $T(x, y, h, k): [0, 1]^2 \to [0, 1]$，若满足：
*   **边界条件 T1**：$T(0, y, h, k)=0, T(1, y, h, k)=y$。
*   **单调性 T2**：关于 $x, y$ 单调增。
*   **连续性 T3**：关于 $x, y$ 连续。
*   **结合律 T4**：$T(T(x, y, h, k), z, h, k)=T(x, T(y, z, h, k), h, k)$。
*   **交换律 T5**：$T(x, y, h, k)=T(y, x, h, k)$。

#### 3. 泛或运算公理
设二元含参运算 $S(x, y, h, k): [0, 1]^2 \to [0, 1]$，若满足：
*   **边界条件 S1**：$S(1, y, h, k)=1, S(0, y, h, k)=y$。
*   **单调性 S2**：关于 $x, y$ 单调增。
*   **连续性 S3**：关于 $x, y$ 连续。
*   **结合律 S4**：$S(S(x, y, h, k), z, h, k)=S(x, S(y, z, h, k), h, k)$。
*   **交换律 S5**：$S(x, y, h, k)=S(y, x, h, k)$。

#### 4. 泛蕴含运算公理
设二元含参运算 $I(x, y, h, k): [0, 1]^2 \to [0, 1]$，若满足：
*   **边界条件 I1**：$I(0, y, h, k)=1, I(1, y, h, k)=y, I(x, 1, h, k)=1$。
*   **单调性 I2**：关于 $y$ 单调增，关于 $x$ 单调减。
*   **连续性 I3**：$h, k\in(0, 1)$ 时，关于 $x, y$ 连续。
*   **保序性 I4**：$I(x, y, h, k)=1 \Leftrightarrow x\le y$（$h=0, k=1$ 除外）。
*   **推演律 I5**：$T(x, I(x, y, h, k), h, k)\le y$（假言推论）。

#### 5. 泛等价运算公理
设二元含参运算 $Q(x, y, h, k): [0, 1]^2 \to [0, 1]$，若满足：
*   **边界条件 Q1**：$Q(1, y, h, k)=y, Q(x, 1, h, k)=x$。
*   **单调性 Q2**：关于 $|x-y|$ 单调减。
*   **连续性 Q3**：$h, k\in(0, 1)$ 时，关于 $x, y$ 连续。
*   **交换律 Q4**：$Q(x, y, h, k)=Q(y, x, h, k)$。
*   **保恒性 Q5**：$Q(x, y, h, k)=1 \Leftrightarrow x=y$（$h=0, k=1$ 除外）。

#### 6. 泛平均运算公理
设二元含参运算 $M(x, y, h, k): [0, 1]^2 \to [0, 1]$，若满足：
*   **边界条件 M1**：$\min(x, y)\le M(x, y, h, k)\le \max(x, y)$。
*   **单调性 M2**：关于 $x, y$ 单调增。
*   **连续性 M3**：$h, k \in (0, 1)$ 时，关于 $x, y$ 连续。
*   **交换律 M4**：$M(x, y, h, k) = M(y, x, h, k)$。
*   **幂等性 M5**：$M(x, x, h, k) = x$。

#### 7. 泛组合运算公理
设二元含参运算 $C^e(x, y, h, k): [0, 1]^2 \to [0, 1]$，$e\in[0,1]$ 为幂元，若满足：
*   **边界条件 C1**：
    *   $x, y < e \Rightarrow C^e(x,y,h,k)\le \min(x, y)$；
    *   $x, y > e \Rightarrow C^e(x,y,h,k)\ge \max(x, y)$；
    *   $x+y=2e \Rightarrow C^e(x, y, h, k) = e$；
    *   否则 $\min(x, y)\le C^e(x, y, h, k)\le \max(x, y)$。
*   **单调性 C2**：关于 $x, y$ 单调增。
*   **连续性 C3**：$h, k \in (0, 1)$ 时，关于 $x, y$ 连续。
*   **交换律 C4**：$C^e(x, y, h, k) = C^e(y, x, h, k)$。
*   **幂元律 C5**：$C^e(x, e, h, k) = x$。

### 5.4.2 泛逻辑运算基模型

当柔性测度 $m(*)$ 无误差（$k=0.5$），广义相关性处于最大相斥状态（$h=0.5$）时，命题连接词运算模型完整簇 $N(0, k)$、$T(x, y, h, k)$、$S(x, y, h, k)$、$I(x, y, h, k)$、$Q(x, y, h, k)$、$M(x, y, h, k)$、$C^e(x, y, h, k)$ 满足特定中心算子（图5.12），在泛逻辑学中定义为相应逻辑运算的**基模型**。

#### 1) 泛非运算基模型
$N(x)=N(x, 0.5)=N_I=1-x$

#### 2) 泛与运算基模型
$T(x, y)=T(x, y, 0.5, 0.5)=T_I=\max(0, x+y-1)$

#### 3) 泛或运算基模型
$S(x, y)=S(x, y, 0.5, 0.5)=S_I=\min(1, x+y)$

#### 4) 泛蕴含运算基模型
[PRE0]

依逻辑规律 $p \wedge (p \rightarrow q) \Rightarrow q$（即满足 $T(x, I(x, y)) \leqslant y$），定义 $p \rightarrow q$ 真值 $I(x, y) = \max\{z \mid y \ge T(x, z)\}$。令 $I(x, y)=z$，则 $T(x, z)=\max(0, x+z-1)=y'\le y$。若 $x+z-1\ge 0$，则 $y'=x+z-1, z=1-x+y'$；若 $x+z-1<0$，则 $y'\ge x+z-1, z\le 1-x+y'$。因 $T(x, z)$ 关于 $z$ 单调增且 $y'\le y, z\in[0,1]$，故 $I(x, y)=\min(1, 1-x+y)$。

#### 5) 泛等价运算基模型
$Q(x, y)=Q(x, y, 0.5, 0.5)=T(I(x, y), I(y, x))=Q_I=1-|x-y|$

依逻辑规律 $p \leftrightarrow q = (p \rightarrow q) \wedge (q \rightarrow p)$，定义 $Q(x, y) = T(I(x, y), I(y, x))$。当 $x\ge y$ 时，$I(x, y)=1-x+y, I(y, x)=1$；当 $x<y$ 时，$I(x, y)=1, I(y, x)=1-y+x$。综上得 $Q(x, y)=1-|x-y|$。

泛逻辑尚包含两大关键运算：一是反映对同一命题两真值 $x, y$ 进行折中的**平均运算** $p \oplus q$，要求结果 $M(x, y)$ 介于 $x, y$ 间且具幂等性。基于泛平均运算规律研究，特定义中心平均运算为算术平均。

#### 6) 泛平均运算基模型
$M(x, y) = M(x, y, 0.5, 0.5) = M_I = (x + y) / 2$

二是反映对同一命题两真值 $x, y$ 进行综合的**组合运算** $p \circledast q$。$e \in [0, 1]$ 为表示齐权的幂元。无误差时，综合决策结果 $C^e(x, y)$ 应满足：
*   $x, y < e$（均反对）$\Rightarrow C^e(x, y) \le \min(x, y)$；
*   $x, y > e$（均赞成）$\Rightarrow C^e(x, y) \ge \max(x, y)$；
*   否则（一赞一反）$\Rightarrow C^e(x, y)$ 在 $x, y$ 间变化：$x+y<2e$ 现与性质，$x+y>2e$ 现或性质，否则 $C^e(x,y)=e$。
