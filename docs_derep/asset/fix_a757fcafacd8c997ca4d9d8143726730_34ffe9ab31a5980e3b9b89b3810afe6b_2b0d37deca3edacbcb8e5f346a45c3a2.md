口语提问就能查询、作图、决策

在数据中台里，业务同学最常提的需求是：用大白话一句话问出来，系统能自动给出可执行的SQL，跑出结果还能推荐合适的图表，甚至把结构化表、文本、时序、知识图谱等多源信息一起综合判断。下面这套组合能把这条路走通，三部分依次是把表结构变成模型可读的描述并转SQL、可视化建议引擎、多维融合推理。

1. 让自然语言落地为可执行的SQL
先把数据库结构翻译成模型能理解的文本。用 inspector 拿到目标表的列清单、主键集合和外键关系，按表名、列名加类型、主键标记、外键约束到被引表的格式组织成一段 Schema 描述。把这段描述和业务提问一起喂给大模型，提示词约束模型只输出一条合法SQL，要求语法自洽、匹配提供的结构，字段或表名不确定时挑最可能的选项，必要时补全表连接，并覆盖过滤、排序、分组聚合等常用操作。生成后会先做可信度评估，只有分数高于0.7才真正执行查询，否则返回空结果并提示置信不足，避免误跑。

2. 让结果自动找到合适的图表
查询结果出来后，需要让表达更直观。可视化建议引擎会先对 DataFrame 做一次概览：记录行数、列数，以及每列的数据类型。数值列归为 numeric，时间列归为 datetime，其余列按唯一值占比判断，低于10%视作 categorical，高于则视作 text。把这些特征连同前5行样本一起组装成提示，交给大模型生成可视化方案，再解析成结构化建议返回。

    def analyze_data_features(self, df: pd.DataFrame) -> Dict[str, Any]:

        """分析数据特征"""

        features = {}

        # 基本统计信息

        features["row_count"] = len(df)

        features["column_count"] = len(df.columns)

        # 列类型分析

        column_types = {}

        for col in df.columns:

            if pd.api.types.is_numeric_dtype(df[col]):

                column_types[col] = "numeric"

            elif pd.api.types.is_datetime64_any_dtype(df[col]):

                column_types[col] = "datetime"

            else:

                # 检查是否可能是类别型

                unique_ratio = df[col].nunique() / len(df)

                if unique_ratio < 0.1: # 如果唯一值比例小于10%,认为是类别型

                    column_types[col] = "categorical"

                else:

                    column_types[col] = "text"

        features["column_types"] = column_types
