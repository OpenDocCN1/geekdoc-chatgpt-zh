#### 3.2.1 DeepSeek-R1模型介绍

DeepSeek-R1 由 DeepSeek 于 2025 年 1 月发布，旨在提升大模型的推理水平。评测显示，其在数学、编程、自然语言推理等任务上的表现可与 OpenAI o1 正式版媲美。

同时开源了 DeepSeek-R1-Zero 与 DeepSeek-R1 两款 660B 级模型，并基于 R1 输出蒸馏出 6 个小型模型，其中 32B 与 70B 版本在多项指标上接近 OpenAI o1-mini。

另外，article 标签也可用于呈现插件，使其看起来像页面内置组件。

需要明确的是，DeepSeek-R1 与 DeepSeek-V3 共享完全相同的架构，仅训练流程与数据不同。具体来说，R1 在 V3 base 上先做有监督微调，再进行强化学习；R1-Zero 则跳过有监督微调，直接在 V3 base 上强化学习得到。

因此 R1 项目未单独列出权重、推理脚本、部署说明等，因这些内容已包含在 DeepSeek-V3 项目中，详见 3.1 节。

#### 3.2.3 DeepSeek-R1模型参数详解

调用 API 时可调整多项参数控制长度、风格与逻辑严谨性。chat.completions.create（）接口的核心参数已说明，R1 与 V3 共用。

同时，R1 在解析与推理机制上存在部分特殊限制，调用时需注意：

##### 1. max_tokens参数

- （1）max_tokens 仅限制最终回答 content 字段的最大长度，默认值 4096 token 约 3000 汉字，上限 8192 token。

- （2）该限制不包含 reasoning_content。复杂任务中推理链可达 32K token，总输出可能远超 max_tokens。官方计划后续推出 reasoning_effort 参数以控制推理深度与长度。

##### 2. reasoning_content字段

- （1）R1 除返回常规答案 content 外，还会返回推理过程 reasoning_content，与 content 同级。

- （2）该字段记录模型得出结论的思考路径，适合解释、教学与评估场景。

##### 3. 功能支持情况

- （1）当前已支持标准对话补全及对话前缀续写 Beta，可用于续写已有内容。

- （2）暂不支持 Function Calling、JSON 输出、FIM 补全 Beta，相关字段无效。

##### 4. 不生效的参数

temperature、top_p、presence_penalty、frequency_penalty、logprobs、top_logprobs 在调用 deepseek-reasoner 时不生效，但为兼容 OpenAI 接口，设置后不会报错，仅被忽略。

##### 1. DeepSeek-R1思维链执行过程

reasoning_content 是模型完成任务时自动生成的推理轨迹，以自然语言描述处理过程中的逻辑展开与中间判断，并与 content 一同返回。其演进规律如图3.30。

[PRE14]

R1 的思维链在多轮对话中呈现明显阶段性变化。

- (1) 首轮多为独立推理，基于初始提问进行完整且自洽的思考。

- (2) 第二轮开始递进式推理，可引用前文问答并自然衔接。

- （3）第三轮及以后形成综合推理，整合多轮信息与多变量，输出逻辑清晰的推理链。随着对话深入，R1 展现出强单轮分析力以及上下文记忆、逻辑递进与归纳整合能力，具备类人的思维连续性与一致性，适用于复杂交互。
