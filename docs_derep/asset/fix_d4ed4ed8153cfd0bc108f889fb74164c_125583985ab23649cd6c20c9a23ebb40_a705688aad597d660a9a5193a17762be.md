### 5.2 DeepSeek-V3 驱动的企业知识库问答实践
企业资料规模快速增长，传统关键词检索已难以应对复杂查询。结合 GraphRAG 与 DeepSeek-V3 的问答体系，可实现上下文理解、关系推理并融合实体图谱，提供更精准高效的答案。下面以实操方式演示如何搭建企业知识库问答系统。

#### 5.2.1 DeepSeek-V3 与 GraphRAG

##### 1. 国产开源大模型代表：DeepSeek-V3
DeepSeek-V3 由中国人工智能公司深度求索于 2024 年 12 月 26 日开源发布。该模型采用 MoE 架构，整体参数 6710 亿，单 token 激活 370 亿参数，并在 14.8 万亿 token 上完成预训练。多项评测显示其表现突出，尤其在代码与数学任务上超越多数开源方案，性能接近业界领先的闭源模型。

##### 2. 知识库问答的检索增强方案：GraphRAG
RAG 通过融合真实世界信息提升大语言模型输出质量，是 LLM 工具的重要组成。多数 RAG 实现以向量相似度检索为主，称作 baseline RAG。

RAG 在私有数据推理上潜力很大，如企业专有研究、业务文档或沟通记录。然而 baseline RAG 在需要整合多片段信息并提炼新洞察、或处理海量复杂数据进行归纳时往往力不从心，难以把握大体量的整体语义。

为此社区持续改进 RAG。微软研究院提出的 GraphRAG 利用 LLM 从文本构建知识图谱，并结合社区摘要与图谱机器学习输出来增强提示。GraphRAG 在复杂信息推理上改进显著，智能性优于 baseline RAG，特别适合私有数据的分析。
