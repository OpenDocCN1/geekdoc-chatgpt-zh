# 玩转智能底盘：从基础驱动到多模态感知融合

## 一、 底层驱动逻辑：运动控制要诀

让车身后退并不复杂，核心在于反转驱动器旋向（由逆时针改为顺时针，具体正反取决于硬件布线），对应积木指令见 [PRE0]。若需实现转向，则采用差速原理——通过调节左右两侧驱动器的转速比即可，编程实现参考 [PRE1]。

## 二、 实战演练：模块化感知单元集成

### 1. 超声波测距避障系统
**硬件接入：** 将测距模块搭载至驱动板：信号线接 `P15`，供电正极接 `3V3`，负极接 `GND`（接线示意见 [PRE2]）。

**逻辑构建：** 搭载 [PRE2] 所示程序逻辑——主循环实时读取距离值，设定 10cm 临界阈值：距离不足时驱动器抱死制动，否则维持前行。烧录 `Micro:bit` 实测：路径无阻时平稳推进，遇障即时锁定。

### 2. 声控触发躲避模块
**硬件部署：** 固定拾音模块（实物参考 [PRE3]），信号脚对接 `P0`，共用电源轨。

**交互逻辑：** 依据 [PRE4] 编写响应程序：监测到声强突变（如拍手、呼喊）瞬间触发，驱动器全速反向运转持续 10 秒。上电测试，声响激活响应迅捷。

### 3. 光敏感应自旋模块
**硬件接入：** 光强检测模块（外观见 [PRE5]）就位安装，信号线接入 `P1`，电源并联至 `3V3` 与 `GND`（接线详情见 [PRE6]）。

**行为设定：** 编程逻辑参考 [PRE7]：环境光强超标时，驱动 M1 与 M2 反向同速输出（原地自旋）；光源撤离则双驱动器抱死静止。实测手电筒照射即旋转，遮光即静止，逻辑闭环验证通过。

### 4. 多模态融合决策系统
整合三大感知单元构建复杂状态机，核心流程见 [PRE8]：

*   **测距避障模式：** 推进中距离低于 10cm → 急停 1s → 后退 → 左偏转向 → 恢复巡航。
*   **声控躲避模式：** 推进中捕捉到声强超阈 → 急停 1s → 定时后退 2s。
*   **光控自旋模式：** 推进中感知到光照超阈 → 急停 1s → 双驱动器对转原地旋转。

**拓展性验证：** 预留接口兼容火焰、红外、灰度等模块，叠加状态机即可进化为消防侦察、循迹竞速等多形态终端。
