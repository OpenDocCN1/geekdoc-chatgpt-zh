# 双册精讲 FPGA：AI 时代的计算引擎与 Intel 实战入门

# 内容简介

现场可编程门阵列 FPGA 是一种能够在出厂后仍对内部电路进行重新定义以适配不同需求的特殊半导体器件。相较于其他类型芯片，它在灵活度上极具优势，同时在运算性能、功耗控制与开发成本之间实现了良好的兼顾，因而在电信、工业控制、高性能计算等多个领域被广泛使用。

本书系统梳理与剖析了 FPGA 在大数据、人工智能浪潮中的新技术进展、新开发手段，以及在异构计算时代涌现的新趋势与新方向，并着重讨论了 FPGA 的核心技术特征。

本书希望为产业决策者提供前瞻性的 FPGA 理念与可落地的实践范式，推动大数据、人工智能等新兴技术与各行业的深度融合与效率提升；同时为 FPGA 工程师处理实际工程难题提供体系化的思路与参考价值。书中内容亦适合学界、企业界及社会中对 FPGA 感兴趣的非专业人士或技术爱好者作为了解前沿理念与基础知识的入门读物。

# 推荐序 2

初见石侃博士的《详解 FPGA：人工智能时代的驱动引擎》，便勾起诸多回忆。我大约在 2005 年首次接触 FPGA，从此打开硬件世界的大门。

我的博士课题便研制了一套基于 FPGA 的内存总线监测装置 HMTT。它具备软硬件协同能力，可算是一套颇具特色的自研设备，相关论文于 2008 年被系统评测领域国际顶级会议 SIGMETEICS 收录，这或许是该会自 1973 年创办以来接收的首篇中国大陆论文。

即便相隔十五年，HMTT 的技术细节仍记忆犹新：硬件是一块自制带 FPGA 的 PCB，直接插入 DDR 内存槽，内存条则插在 PCB 上。总线信号被分两路，一路送往内存条读写数据，另一路送入 FPGA 实时还原为带物理地址的读写指令，随后经以太网发送至磁盘阵列保存。

软件部分设计了同步机制，让 FPGA 能识别软件操作如操作系统页表更新、函数调用等，从而将物理地址与软件操作关联，例如经页表映射即可把物理地址还原为进程虚拟地址。

如今 HMTT 已迭代至第四代，从早期支持 DDR-200 发展到现今支持 DDR4-2600，配套 FPGA 亦从 Xilinx Virtex-4/5 进化至 Kintex UltraScale XCKU035。HMTT 研制成功后的十余年，我们团队的科研工作始终离不开 FPGA。

常会思考，FPGA 这样硬科技为何会出现？为何多在美国诞生？中国未来何处可为？翻阅石侃博士此书，读到一个个 FPGA 与前沿技术深度融合的故事，对这几个问题有了更深入的思考。

石侃博士在书中将 FPGA 的诞生称作“历史的必然”。20 世纪 80 年代约三分之二的芯片项目因需求变化、设计漏洞、流片失败等原因亏损，只有三分之一能投入生产。业界亟需一种可在流片前充分测验验证的技术以降低失败率，于是 FPGA 应运而生。1984 年 Xilinx 发布全球首款 FPGA XC2064，仅有 64 个可编程逻辑单元、800 个晶体管。35 年后 2019 年英特尔推出当时全球最大 FPGA Stratix10 GX 10M，1020 万个可编程逻辑单元、433 亿个晶体管。如今 FPGA 已成长为约 60 亿美元规模的全球产业，在芯片产业链中占据不可或缺位置，甚至成为我国“卡脖子”的核心芯片之一。回顾硬科技发展，哪怕诞生之初再微小，只要真正解决市场需求，其出现便是必然。

为何 FPGA 先在美国诞生而非日本或欧洲？20 世纪 80 年代初日本半导体如日中天，1986 年日本半导体全球份额甚至超过美国。本书虽未直接解答，但结合书中 FPGA 与云计算、大数据、人工智能的融合案例，以及 80 年代美日产业差异，可得到一些启发。当时存在两点主要区别：

其一，需求侧：美国市场需求更旺盛、更前沿。日本半导体虽高速发展，但大部分出口美国，1980—1984 年日本对美出口增长 8 倍。换言之日本并未直接感知最前沿需求。

其二，供给侧：美国研发投入更具前瞻性、布局更合理。1984 年 Xilinx 成立，得益于政府支持的 MOSIS 项目所创造的 MPW 技术与 Fabless 模式，也得益于政府推动的一系列 CAD/EDA 项目。相比之下日本研发更聚焦于对现有产品的改良，追求更高品质、更低价格、更稳定供货，缺乏开拓性。当时美国还启动 SRC、SEMATECH 等机构，大力支持半导体基础研究与共性技术，培养大量高端人才，为产业提供深厚储备。

诚然中国错过 80 年代半导体黄金期，半导体产业成为今天中国与发达国家差距最大的领域之一。但从本书亦可见新机会：一方面，书中提及的云计算、大数据、人工智能在中国同样蓬勃发展，并产生前沿需求，甚至催生出达到国际先进水平的 FPGA 技术，如深鉴科技的 FPGA 人工智能加速技术、阿里巴巴弹性裸金属服务器神龙架构、我们团队研制的芯片敏捷设计 SERVE 云平台等。另一方面，中国对半导体领域的重视空前，社会各界积极投入于市场、科研、资本、知识产权、教育等多个维度，覆盖应用、设计、制造、封测、装备、材料等环节，采取引进消化、自主创新、开源共享等多种路径。相信只要持续投入，不久将来必见成效。

# 第 1 章 延续摩尔定律——FPGA 的架构革新

20 世纪 60 年代中期，英特尔创始人之一、当时的仙童半导体工程师戈登·摩尔在《电子学》杂志发表论文指出，芯片上晶体管密度会每年翻倍。1975 年他将周期修正为每两年翻倍，该规律后被称作“摩尔定律”。正如预测，过去 50 年每一年半到两年芯片晶体管密度翻倍，呈指数增长。性能随之指数级提升，计算成本与功耗则在五十年间呈指数下降。摩尔定律见证了半导体与集成电路的突破性发展，也是驱动人类社会过去半世纪飞速前进的根本动力。

FPGA 的发展始终与摩尔定律高度吻合。自 1984 年面世至今，FPGA 容量增长超万倍、运行速度提升超百倍，成本与功耗则下降超过千倍。这一演进一方面得益于半导体工艺持续进步，另一方面也源于 FPGA 本身不断创造新颖芯片架构与系统，以延续指数式发展轨迹。

随着工艺突破 10nm 节点并持续向原子极限推进，芯片架构设计思路与方法也需不断更新变革。对 FPGA 而言，其未来架构如何继续演进，已成为工业界与学术界持续探讨的重点。那么 FPGA 究竟是什么？它从诞生至今经历了哪些阶段？未来在何处？能否继续跟随摩尔定律脚步？需要何种技术支撑其延续？下文将尝试寻找答案。

## 1.1　什么是 FPGA

FPGA 的英文全称是 Field Programmable Gate Array，意为现场可编程门阵列。名称虽拗口，但从本质上看它就是一种半导体芯片，与我们熟知的 CPU 或 GPU 并无本质区别。

从名称即可看出其三大核心特征：门阵列、可编程、现场。

首先，FPGA 由海量逻辑门阵列构成。我们知道逻辑门是数字电路的基本单元，基于布尔代数对二进制 0/1 进行操作，完成与、或、非、异或等运算。例如非操作将 0 变 1 或 1 变 0；0 与 1 作或得 1；0 与 1 作与得 0。图 1-1 列出若干常见逻辑门电路符号。

有了这些基于逻辑门的通用单元，便可进一步设计复杂功能模块，最终形成各具特点的 IP。大部分数字芯片都是通过选用不同 IP 实现特定逻辑功能，经验证、集成、优化后流片制造。

需注意的是，一旦芯片生产出来，其逻辑功能即被固化。尽管许多芯片可通过片上寄存器编程改变配置，但这并不改变其本质逻辑功能。若需修改逻辑或修复缺陷，就必须重新设计、验证和制造，耗费大量时间、人力与资金，风险极高。

在此背景下，设计者提出与其将逻辑固化在芯片，不如设计一种通用芯片只内置最基础的逻辑门，并通过某种方式对这些门进行排列组合，使其逻辑结构可编程。这样一枚芯片即可实现多种功能。这个设想就是 FPGA 的雏形。

FPGA 最核心的构成是海量“逻辑门”，它们以特定方式组合成门阵列，并通过互连单元连接。由于逻辑门可任意组合成更复杂电路，FPGA 在理论上可实现任意数字逻辑功能。随着技术发展，现代 FPGA 集成了上千万个逻辑单元，因而可在某些领域替代专用芯片，具体将在后续章节深入介绍。

这里的“逻辑门”已加上引号，因为 FPGA 内的逻辑门实际以查找表 Lookup-Table 方式实现。简单说就是把某简单逻辑功能的全部可能结果写入存储单元，根据输入变化直接查表输出结果。除了部分中低端或较早 FPGA 采用 4 输入 LUT 结构外，大多数现代 FPGA，如英特尔 Arria10、Stratix10、Agilex 及赛灵思 6 系、7 系、UltraScale 与 UltraScale+ 系列，查找表输入通常为 6 个，即可实现任意 6 输入 1 输出的逻辑功能。

除查找表外，FPGA 最小逻辑单元还包含寄存器、选择器，甚至算术运算单元如加法进位链等。不同厂商命名各异，英特尔称 ALM 自适应逻辑单元，赛灵思称 CLB 可配置逻辑块。名称虽不同，主要构成类似，均包含上述要素。图 1-3 展示了英特尔 Stratix10 FPGA 芯片最小逻辑单元 ALM 的结构示意。
