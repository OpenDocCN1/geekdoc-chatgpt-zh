# 文献汇编

**2011** 年，Leo S. Olschki 出版社（佛罗伦萨）发行的《伽利略事件：历史、哲学、神学的再解读》（M. Bucciantini、M. Camerota、F. Giudice 编）第 47–74 页，收录了“耶稣会士：新科学的传播者”一章。

**2018** 年，Springer（Cham）出版的“波士顿哲学与科学史研究”系列第 333 卷《前经典力学的兴起与扩展》（R. Feldhay、J. Renn、M. Schemmel、M. Valleriani 编）第 29–53 页，刊发了关于前经典力学语境下实践与理论知识——主权、宗教与科学互动——的研究。

Rivka Feldhay 与 F. Jamil Ragep 合著的《哥白尼之前：十五世纪科学学习的文化与语境》于 **2017** 年由 McGill-Queen's University Press（蒙特利尔）付梓。

**2018** 年，Rivka Feldhay、Jürgen Renn、Matthias Schemmel 与 Matteo Valleriani 共同编辑的《前经典力学的兴起与扩展》问世，同样归属“波士顿哲学与科学史研究”第 333 卷，Springer（Cham）发行。

冯立生 **2017** 年在《中国科学技术史研究》创刊号（第 1 卷第 1 期）撰文，详细考察清华竹简乘法表的结构特征与功能，见第 1–23 页。
