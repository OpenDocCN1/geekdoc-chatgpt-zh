# 9.5 盲盒手办：萌趣玩物很吸睛

盲盒因开盒结果未知在年轻人中持续流行，核心吸引力来自盒内造型吸睛的手办模型，具有收藏价值。

机甲、时尚少女、萌宠卡通等随机角色都能满足年轻人多变审美。

盲盒手办可参考如下提示写法。

## 盲盒手办提示词

| 角色设定 | 比如少女、少年、美少女战士、孙悟空等 |

| --- | --- |

| 风格细节 | 涵盖体型、发型、服装、动作、表情等 |

| 例如：圆润可爱，长发，白色连衣裙，坐在沙发上，愉悦 |

| 描述词汇 | 顶级品质、杰作、8K 等 |

> 注意

在Vega AI里制作盲盒画面，建议先选用基础模型“3D二次元”，再叠加3D人物相关的风格标签，例如“人偶手办”“Q版盲盒”“3D卡通风格”“可爱美少女手办”等，这些标签均可在风格广场检索收藏。若想提升多样性，还可尝试“国风写真”“森系女孩”“高达机甲”等风格组合。

# 9.5.1 动漫角色联名手办

想要把喜欢的动漫形象做成联名盲盒，手办图也能用AI完成。主流模型训练时已覆盖大量经典角色，通常直接在提示中写出角色名即可引导生成，以下以美少女战士盲盒为例。

# 提示词

美少女战士，单人，站在白色圆形舞台上，最佳质量，大师之作

# 重点参数

基础模型：虚拟建模。风格：Q版盲盒。
