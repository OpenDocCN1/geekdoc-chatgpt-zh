# 第二章 数据权益守护

## 第一节 一般规定

### 第十二条 【通用原则】

本市依法保护自然人对其个人信息享有的人格权益。

本市依法保护自然人、法人和非法人组织在使用、加工等数据处理活动中形成的法定或者约定的财产权益，以及在数字经济发展中有关数据创新活动取得的合法财产权益。

[PRE0]

这一条款可以看作条例的定调之笔，它厘清了从采集到使用、加工再到交易等全链条数据处理中，个人和其他主体各自能够主张的人格性权益与财产性权益，以及这些权益如何产生。

[PRE1]

#### 一、对数据权益及其性质的分析

条文首先回答的是数据权益到底分成哪几种，《上海市数据条例》的基石就落在这里。第1款的指向是自然人对个人信息的掌控权，即数据中关于个人的那部分记录，而非把整块数据都当成人格权客体。第2款则凸显了两层突破：其一，在数据处理链条上，除了法定的权利来源之外，当事人可以通过约定创设权益，且地方性法规可以直接为这种约定提供保护，这在各地立法中较为少见；其二，专门为数字经济中的数据创新活动预留财产性收益空间，让在创新中形成的新价值也能被合法确认。这样既减小了市场主体的不确定性，又能释放数据要素的收益潜能，推动流通与市场建设。

把个人信息的人格保护与数据权益的财产保护拆开处理，是对数据归属问题的一种建设性尝试。放眼海外，欧盟《通用数据保护条例》并未明文确立个人数据的财产权，但其立法逻辑处处体现了财产化思维。其一，GDPR 建立了默认归属思路，处理个人数据必须有个人同意，默认情况下数据仍由个人掌握；其二，对控制者和处理者设定了严格责任，即使通过合同或同意取得数据也不能随意处置；其三，在救济层面采用了财产规则式的赔偿方式。总体看，欧盟并未直接命名财产权，实践路径却围绕数据作为财产展开。

国内的路径同样是人格与财产并行，而非提出一个确定的“数据权”。从中央层面看，数据权属涉及民法基本制度，属于全国人大专属立法事项，地方立法的空间受限；同时数据主体多元、权益交织，学界国内外尚无定论，中央对地方先行探索保持审慎。从地方实践看，近二十部数据和信息相关的规范大多采取抽象表述，有的细化到具体权利类型，有的仅概括为人格与财产两类，《上海市数据条例》选择了后一种概括化处理。

#### 二、对权益保障方式的探索

人格权益与财产权益的保护逻辑并不相同。人格权益更接近于一种不可剥离的人身利益，核心在于法律身份的认定。姓名、名誉、肖像等构成人格要素，保护上主要依靠民事法律关系来规制，情节严重时再介入刑事制裁。第1款正是按照这一常规思路来理解个人信息的人格保护。

数据财产权益的保护更为复杂，涉及主体资格、权益范围和属性定位这三重问题。第2款对此作了回应。首先，主体上明确自然人、法人和非法人组织均可成为财产权益享有者。其中自然人更强调其作为数据处理者的角色而非仅是信息主体，法人与非法人组织则只能就财产层面主张权利。其次，范围上既涵盖使用、加工等活动中所形成的法定或约定财产权益，也包括数字经济发展中数据创新活动所产生的合法财产权益。这一表述比《数据安全法》《个人信息保护法》以及《深圳经济特区数据条例》的规定更为宽松，也更贴合产业实际。再次，数据相关财产权益的清晰化是交易流通的前提。缺乏财产权支撑的买卖、开放、交换都会因法律基础不足而风险陡增，不利于要素市场成熟。

《民法典》第127条和第1034条将数据、网络虚拟财产列为民事权利客体，承认其上利益受法律保护，但并未明确具体权利形态。《数据安全法》《个人信息保护法》同样保持克制，《上海市数据条例》亦未做具体化。对此可行的进路是先建立覆盖交易全流程的行为规范，通过制度设计来稳定数据要素市场秩序；或者继续采用“保护利益”的抽象表述，暂时不作硬性赋权，待上位法完善后再予填补。

### 第十三条 【数据收集权益】

自然人、法人和非法人组织可以通过合法、正当的方式收集数据。收集已公开的数据，不得违反法律、行政法规的规定或者侵犯他人的合法权益。法律、行政法规对数据收集的目的和范围有规定的，应当在法律、行政法规规定的目的和范围内收集。
