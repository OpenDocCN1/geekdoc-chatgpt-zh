零框架 NumPy 实现截断BPTT

本例完全用 NumPy 从零搭建循环网络，不依赖任何深度学习库。三个权重矩阵在 0~1 之间随机初始化，隐藏层采用 Sigmoid 激活。每个 epoch 会先在训练集和验证集上分别做前向展开累积半均方误差并打印进度，随后进入带梯度裁剪的截断反向传播来修正 W1、W2、W3。训练结束后在验证集上重跑推理，用绿色曲线展示模型输出、红色曲线展示真实值，并在末尾以均方根误差给出量化评价。
