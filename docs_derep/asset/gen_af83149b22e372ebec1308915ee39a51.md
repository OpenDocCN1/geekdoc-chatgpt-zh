大家都知道，智能体本质上是一个对话式的 AI 项目，交互全靠语言用户界面来承载。一个 AI 应用的运转离不开工作流来串联，工作流就是把整体逻辑拆解成若干环节，每个环节就是一个节点。本案例的示例结构见图2-3，除去必须的开始和结束节点外，中间仅放了一个大模型节点来承接用户任务。用户的输入可以直接喂给大模型处理，再把结果原路返回。只要工作流里包含了大模型节点，就能为其单独设定各项模型参数，并借助附加的提示词来规范模型行为，让智能体在指定场景下运行更稳、输出更贴合预期。

每个工作流都包含一个不可删除的开始节点和结束节点。开始节点用于定义输入参数，包括参数个数、类型及用途，以便后续节点引用；结束节点用于定义输出参数，包括个数、类型及含义；其余节点则是处理过程，用来实现具体功能。整体来看，工作流就像一个函数，开始节点是输入，结束节点是输出，中间节点完成计算。

# 第3章 插件与卡片

扣子的插件相当于智能体的工具箱，涵盖资讯阅读、旅游出行、效率办公、图片理解等 API 及多模态模型，使用它们能极大拓展智能体的能力边界。扣子还支持智能体以消息卡片形式发送消息，卡片让输出格式更美观。本章介绍扣子插件和卡片的用法。

## 3.1 什么是插件
插件对应 Agent 的工具箱 Tools。一个插件可包含一个或多个工具（API）。目前扣子集成了丰富类型的插件，包括资讯阅读、旅游出行、效率办公、图片理解等 API 及多模态模型。使用这些插件能显著拓宽智能体的能力。例如在智能体中添加头条新闻插件，智能体便拥有新闻资讯播报能力；添加“必应搜索”插件，可赋予智能体联网搜索能力，能查询天气、股市、实时新闻、汇率等训练数据之外的信息。

很多人期待满血版 DeepSeek 具备多模态能力，一旦实现将非常令人兴奋。只需选择“图片理解”插件，就能让 DeepSeek 等模型拥有“眼睛”，帮助分析和理解图片。

扣子插件商店的插件皆可使用。若内置插件不满足需求，还可创建自定义插件集成所需 API。掌握工具调用能力，相当于拥有了“黑魔法”。开发者可在大模型上自由组合插件，打造专属 AI 助手，不仅能写代码、查资料，还能分析图片、视频，甚至更多。
