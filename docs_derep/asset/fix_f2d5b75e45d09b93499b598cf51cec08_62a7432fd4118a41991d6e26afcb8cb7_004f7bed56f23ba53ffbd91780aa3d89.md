## 用 OpenAI SDK 操控 DeepSeek 全流程

想复用现有的 OpenAI 写法直接连上 DeepSeek？下面把从环境准备到图文输入的步骤拆成可直接复制的片段，按顺序执行即可跑通。

先装依赖：
[PRE0]
pip install openai
[/PRE0]

下面是握手与首次交互的骨架，导入所需模块、填入个人密钥、指向官方接口建立连接，随后发起一次简短对话并把结果和全部对象打印出来。
[PRE1]
import os

from openai import OpenAI

from IPython.display import display, Code, Markdown

import requests

import json

# <YOUR_DEEPSEEK_API_KEY>替换为复制的 API key 字符串

ds_api_key = '<YOUR_DEEPSEEK_API_KEY>'

#实例化客户端

client = OpenAI(api_key=ds_api_key,

                base_url="https://api.deepseek.com")

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {"role": "user", "content": "你好，好久不见!"}

    ]

)

#输出生成的响应内容

print(response.choices[0].message.content)

#输出完整的响应

print(response)
[/PRE1]

接下来演示对话内容的组织方式。

先定义系统层面的行为偏好。
[PRE5]
system_message = {
    "role": "system",
    "content": "你是一位擅长编写 python 代码的助手。"
}
[/PRE5]

再准备用户的提问载体。
[PRE6]
user_message = {
    "role": "user",
    "content": "你好，请介绍下你自己。"
}
[/PRE6]

当需要图文一起输入时，把文字与 image_url 放在同一个 content 数组里传递即可。
[PRE7]
user_message_with_image = {
    "role": "user",
    "content": [
        {"type": "text", "text": "你能帮我介绍下这张图片里面的内容吗？"},
        {"type": "image_url",
         "image_url": {
             "url": "https://ml2022.oss-cn-hangzhou.aliyuncs.com/img/image-20241009205714055.png"}}
    ]
}
[/PRE7]

最后是带系统指令的调用示例，把系统消息与用户消息一起放入 messages，再次发起请求并取出回复文本。
[PRE8]
#创建用户消息

user_message = {
    "role": "user",
    "content": "你好，请介绍下你自己。"
}

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        system_message,
        user_message
    ]
)

#输出生成的响应内容

print(response.choices[0].message.content)
[/PRE8]

整体思路就是装好包、设定密钥与地址、建立连接、组织 messages、调用指定模型，后续的模型切换、指令设定、多模态输入都能沿用同一套框架。
