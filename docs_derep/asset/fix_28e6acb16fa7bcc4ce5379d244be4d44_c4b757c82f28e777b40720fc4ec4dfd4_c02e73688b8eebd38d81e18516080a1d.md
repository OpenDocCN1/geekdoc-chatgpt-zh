我们是豪华汽车经销商，现在想建立一套问答库，以便销售人员更好地解答客户各类问题。因为问答库会很大，所以一步步做。首先，请把豪华汽车领域客户在购买前关心的问题进行分类，并按分类列举，按关心程度从高到低排序。请尽量全面。

ChatGPT：
在豪华汽车领域，购买前客户关心的问题可按以下分类排列，按关心程度从高到低：

+ 1. 价格与购车成本：
• 车辆售价多少？
• 有哪些优惠政策？
• 需支付哪些费用？
• 保险费用大概？
• 有哪些融资与分期选项？

2. 性能与配置：
* 发动机性能如何？
* 油耗表现如何？
* 配置有哪些亮点？
* 内部空间大小？
* 座椅舒适度？
* 车载娱乐系统功能？

3. 安全性能：
* 安全评级如何？
* 主动安全系统有哪些？
* 被动安全系统有哪些？
* 是否提供驾驶辅助？
* 制动性能如何？

4. 售后与保养：
* 售后服务含哪些？
* 保养周期与费用？
* 原厂配件价格？
* 保修政策？
* 全国授权维修网点？

5. 品牌声誉与口碑：
* 品牌历史与口碑？
* 在豪华车市场的地位？
* 该车型市场表现？
* 有哪些奖项与荣誉？

* 是否符合当地排放标准？
* 该车型环保技术有哪些？
