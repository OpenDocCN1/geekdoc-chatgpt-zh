# 会做却说不清：隐性知识到底藏在哪

实践和经验每个人都懂，日常应付、临场判断、反复琢磨，都会随着时间推移和场景变化而演化。它不是一次性装满的容器，而是一种综合的、潜藏的、不断迭代的积累。

上世纪八十年代，学吉他曾是一阵风。我当时完全没接触过，还以为所有人都是抱着琴、看同一份谱子，最终弹出来的声音一模一样。后来才明白那是典型的外行想当然。显性知识可以把指法、和弦写清楚，真正让人能流畅演奏的，却是说明书里写不全的那部分隐性知识。背熟乐谱不等于能弹。

这些年很火的“注意力机制”，本质上也在碰隐性知识的问题。模型要知道该盯住什么，往往得靠领域专家反复反思后才能把关注点理清，甚至出现了“二次注意力”的讨论。

钱学森曾指出思维模拟的瓶颈在形象思维的模拟上，潘云鹤院士据此提出了综合推理的思路。我对隐性知识的兴趣就源于此。21世纪初我注意到心理学里的内隐记忆概念，后来又接触到波兰尼提出的默会知识观。中间的一系列实操支撑了这个想法：计算机辅助心电图诊断屡出偏差、形态描述很难讲清、脉象的可视化尝试以及与心电图的对照，还有书法学习里执笔手感的体会与反思。

隐性知识的学习很有意思，也很难找到现成教程。比如脱把骑车，只能在骑行里自己悟出来，教不了。儿子小时候我在他面前吹口哨、打响指，他觉得好玩，自己模仿却怎么也做不成，除了演示，我什么也帮不了。游泳和篮球我也给他买过书，他喜欢篮球，游泳却是去泳馆和我一起泡水时学会的，而不是靠书本。这像极了强调环境交互的增强学习。说“看书后下水就能游”不算错，但把所有实践都理解成理论先行的结果就不对了，基础知识是第一步的前提。若一开始养成了错误姿势，后续矫正会更难，进度也会慢。

王蒙说得直白：书能让人学问、聪敏、高尚，但书与实践、现实、生活之间存在距离。许多知识和本领根本没法从书里得来，比如游泳、打球、太极、把脉、开刀、锄地。

锄头用在地上才显效果。若只琢磨怎么造锄头，用坦克钢、花梨木做得漂亮过硬，甚至被神化，也不一定更顺手锄地，那样的锄头只能挂墙上当艺术品。更离谱的是，没琢磨过锄头就断言土地会因它高产。我曾参与评议人工智能的指南，里面有“实现量子力学精度”的考核项，意图不明，即便精度很高，到底要解决什么问题？交叉学科很热，还是要深度优先，聚焦点去解决某个或某类具体问题，“伤其十指不如断其一指”。攻克了关键困难、真正提升了教育质量，或在需要时达到另一学科专业人员的水平，才是对社会和科研有意义的成果。

创造是否一定要掌握隐性知识，不能一概而论。通常认为它是反复思索、综合经验、推陈出新的产物，但也有白纸作画、小孩突发奇想的情况。隐性知识如何显性化才是核心议题。我和同行曾有过这样的交流。

诸葛：所有隐性知识都能变成显性吗？
我：转化是目标，能否全转取决于领域专家的理解与努力程度。
诸葛：说清楚和能学会是两回事。游泳可以写，但变量太多写不全，除非做全程立体录像。
我：我学游泳不是靠书，后来买书翻阅，仍觉得只看书学不会。录像也许有帮助，但细节终究要靠自己体会。中医把脉模拟我这种外行只能希望中医说得更透，或被启发说透，才能建模，让机器学到，两步是相续的。
诸葛：感觉凡知识都应可言说，但学以致用则关乎个人实践。关键是写出来的东西能否被验证，若无法验证，可能就只是技能而非知识。
我：第一，我会却说不出来，给时间也不一定做得到。第二，如果是技能，中医把脉是否只能算技能？我亲历过两位教授先后把脉，结果完全相反。
诸葛：吹口哨这种是可以写出来的，比如口型、舌位、气息控制，但学会是另一回事。

看法各异，但说明了一个事实：理论上事情都可被表述，具体可操作性是另一回事。可操作性意味着把吹口哨的要领清晰写出，让读者照着能达到目标。

这并不意味着要放弃努力去言表知识。恰恰相反，言表对传承至关重要。胡适晚年说过老师讲解的重要性：“我才明白自己受了特别待遇……我一生最得力的就是讲书：父母为我讲方字，两位先生为我讲书。念古文而不讲解，等于念‘揭谛揭谛，波罗揭谛’全无用处。”

有些东西文字很简洁，体会却极难。比如“上瘾”。我爱吃辣，一顿能吃十个细红尖椒，也无法体会吸毒上瘾的感觉和后果，因为我不吃辣也能过得挺好，不是非吃不可。

隐性知识的学习首先指向领域专家的学习，以及互相对照，或机器辅助下的学习。有时解题的关键就是提出恰当的问题。下面是一些我有体会的学习方式示例。

✧同步感知：脉象分类缺乏像心电图那样明确的规则。先让医生在指下同步感知脉象并对应所见信息，概括特征与含义，再形成像心电图那样的推理规则，进而建模。

脑电图观测与数据挖掘有望更客观地提取一致诊断结论，不止依赖医生的主观经验。通过分析不同医生诊断时的脑电数据，可构建刻画症状的特征参数、诊断规则并形成客观标注依据。

有人认为有了数据和深度神经网络，隐性知识问题就能迎刃而解，事实并非如此。隐性知识并不会自然地呈现在数据上，标注过的数据只携带了部分经验，还有相当一部分未显现。其次，即使机器学习，也无法保证学到关键知识。神经网络会随认识深化而健全，但逻辑机制不可或缺，因为逻辑本身就是思维形式之一。推理包含推理方式与推理内容，前者如不确定性推理、模糊推理，后者包括规则优化和知识精化，都与隐性知识学习相关。

当前学习多与人工神经网络相关，除认知神经科学基础上的建模外，还涉及网络结构优化与训练方式探索。卷积操作就是对网络结构的一次重要创新。针对具体问题有多种形式和参数组合，没有固定规律，需要大量试验，结果往往达不到最优。训练上梯度下降是核心思想，有研究提示权重矩阵频繁改变时，只有少数奇异向量空间真正发生变化，若能据此优化，将大幅提升效率、减少资源消耗。

《荀子·儒效》说“故闻之而不见，虽博必谬；见之而不知，虽识必妄；知之而不行，虽敦必困”，正可用来反观隐性知识的学习。

## 3.5 直觉模式

认识的形成因人而异。内因有先天气质与后天实践，外因有学习输入与环境影响，如父母言传身教、书籍潜移默化。超出客观知识之外，反省能强化对知识的体会，比如主动纠正、深化、比较选择，是逐步精化的过程。人们的历史总结往往不够，却是迭代的基础。小朋友智力发展有快慢差异，教育要健康成长而非拔苗助长，更要引导、训练、接触社会和生活。

西蒙等对下棋、解物理、医疗诊断等领域专家的研究表明：达到高级技能时，一流专家在其领域至少掌握五万个模式，能一眼识别并从长时记忆中调取出相关信息。专家知识以五万到二十万个组块计量，看棋盘时不是看孤立棋子，而是看关系构成的组块。达到此水平往往需要十年以上时间。高级诊断医师面对症状能迅速辨认熟悉模式，联想到疾病假设，并决定后续检查与治疗，所有这些在几秒内完成。专家能看到新手看不到的东西。

华罗庚曾说学生看到的是数字，自己看到的是矩阵，别人能快算数字，他能像算术一样算矩阵，把握更复杂元素。钱学森的学生问他为何在黑板上算积分如此快，他答多练习，说不出道理，那是经验。诺贝尔奖得主纳什也能把数学问题在脑中看成一幅图画，数学家最终需要严谨证明，但答案出现的样子是直觉的拼接。

我中学时读到苏步青说，要掌握基本数学原理和方法，至少做两万道题。我当年练习很快，忽视了足够量的练习对原理掌握、理解和应用的作用，总以为懂了定义定理就能应万变。实际上举一反三的前提是丰富的经验和大量积累。书本结论是抽象陈述，无法涵盖现实问题的复杂和意外。理解定理与反复练习相辅相成，差距靠日常锻炼弥合。对数学学习而言，目的通常有二：锻炼思维、解决问题，二者不能割裂。没有一定量的解题经验，思维难练；没有良好思维方式，找解法也困难。

“学习”是个人成长的必然要求，也是人工智能的经典命题。学习不只是积累信息，更是“去粗取精、去伪存真、由此及彼、由表及里”的过程和能力。理论上，这个能力要么伴随成长而来，要么被告知。若是被告知，能告知什么内容？人自身也说不清从小到大的学习是怎样的神经机制。概略说，实现人工智能的长远目标可能需要人的设计与进化两者结合。

西蒙指出，几秒钟完成的诊断是一种直觉过程，直觉只对非常熟悉的东西才有。丘奇—图灵论题中，“有效步骤”是直觉概念而非形式概念。爱因斯坦认为日常思维基本概念与感觉经验的复合关系，只能靠直觉把握，无法用逻辑完全规定。科学大厦正是建立在这上面。他悼念居里夫人时说其伟大成就是靠大胆直觉；纪念哥白尼时说要让人信服太阳中心说的优越性，需要罕见的独立思考和直觉。文艺亦然，若缺少创造性直觉，作品可能成形却空洞；若直觉进入作品，作品便活了。

日常生活中，天空晴朗时下雨几乎不可思议，但时间长了，只要听到淅沥雨声和滴答水声，哪怕无乌云雷电，也能判断下雨。
