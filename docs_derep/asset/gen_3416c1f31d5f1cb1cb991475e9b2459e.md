### 路径优化与分层寻路核心算法解析

在游戏 AI 开发中，原始寻路结果往往显得生硬且不自然，而大型地图的搜索开销又极其惊人。本文将拆解两大核心技术：**基于视线检测的路径平滑算法**与**分层 A* 寻路架构**，并附带关键数据结构定义。

---

#### 一、 射线平滑：让转折点“隐形”

普通寻路返回的节点序列，常因网格限制出现大量不必要的拐点。`smoothPath` 函数利用**视线直通性** 原地“抹平”这些折角。

**核心逻辑重构：**
1.  **边界速返**：节点数不足 3 个时，无平滑空间，直接回传原路径。
2.  **锚点推进法**：
    *   以输出列表的**末尾锚点**为起点，尝试“瞄准”输入路径更远的目标节点（初始跳过紧邻节点，从索引 2 开始）。
    *   **视线受阻＝锁定拐点**：一旦射线碰撞，说明中间节点是必须保留的“关键转折”，将其写入输出列表。
    *   **视线通畅＝继续伸展**：索引后移，尝试跨越更多节点直达终点。
3.  **收尾封装**：循环结束后，强制追加终点，确保路径完整闭合。

[PRE0]
function smoothPath(inputPath: Vector[]) -> Vector[]:

    # 少于 3 个节点无需处理
    if len(inputPath) < 3:
        return inputPath

    # 初始化输出，首节点入列
    smoothed = [inputPath[0]]
    # 从第 3 个节点（索引 2）开始尝试“跨越”
    idx = 2

    while idx < len(inputPath) - 1:
        # 当前锚点与候选目标点连线检测
        anchor = smoothed[-1]
        target = inputPath[idx]

        if not rayClear(anchor, target):
            # 视线被挡，上一个节点为必经之路
            smoothed.append(inputPath[idx - 1])

        idx += 1

    # 补上终点
    smoothed.append(inputPath[-1])
    return smoothed

#### 二、 分层寻路：自顶向下的“粗定位 + 细修正”

面对宏大世界，`hierarchicalPathfind` 采用**层级抽象**策略：先在粗糙高层图中确定大致走向，再逐层下钻至地面层精修路径。

**执行流程复盘：**
1.  **同点速判**：起终点重合，直接返回空路径。
2.  **层级映射器**：维护 `startNode`、`endNode` 及其所在 `levelOfNodes`，初始指向原始节点（层级 0）。
3.  **自顶向下迭代**（从最高层 `maxLevel` 降至 0）：
    *   **节点投影**：将当前起/终节点“投影”到当前层级 `currentLevel`。
    *   **同节点剪枝**：投影后若重合，说明该层级无决策必要，跳过。
    *   **单层 A* 求解**：切换图层级上下文，执行标准 A*。
    *   **关键衔接**：**仅取本层路径的第一步落脚点**，作为下一层（更精细层级）寻路的新终点。
4.  **底层产出**：循环终止时，手中握着的正是第 0 层的完整精细路径。

[PRE1]
function hierarchicalPathfind(graph: Graph,
    start: Node,
    end: Node,
    heuristic: Heuristic
    ) -> Connection[]:

    # 起终点一致，无需寻路
    if start == end:
        return []

    # 追踪当前层级的起止节点
    curStart, curEnd = start, end
    curLevelIdx = 0          # 当前节点所在层级
    maxLevel = graph.getLevels() - 1

    # 从最高层向下遍历
    for lvl in range(maxLevel, -1, -1):
        # 将节点映射到目标层级
        curStart = graph.getNodeAtLevel(curLevelIdx, curStart, lvl)
        curEnd   = graph.getNodeAtLevel(curLevelIdx, curEnd, lvl)
        curLevelIdx = lvl

        # 映射后重合，该层无路径决策
        if curStart == curEnd:
            continue

        # 执行当前层级 A*
        graph.setLevel(lvl)
        segment = pathfindAStar(graph, curStart, curEnd, heuristic)

        # 仅保留第一步的到达节点，作为下一层的终点锚点
        curEnd = segment[0].getToNode()

    # 最终返回地面层完整路径
    return segment

#### 三、 分层图接口契约：`HierarchicalGraph`

支撑上述算法的基石，是图对象需实现的三大核心能力：

| 接口 | 契约含义 |
| :--- | :--- |
| `getLevels()` | 查询图包含的**总层级数**（含地面层 0）。 |
| `setLevel(level)` | **切换上下文**，后续 `getConnections` 仅返回该层级的连接关系。 |
| `getNodeAtLevel(inLvl, node, outLvl)` | **跨层节点映射**：将 `inLvl` 层的 `node` 转换为对应 `outLvl` 层的代表节点。 |

[PRE2]
class HierarchicalGraph extends Graph:

    # 继承基础连接查询 getConnections...

    # 获取层级总数
    function getLevels() -> int

    # 设置当前活动层级
    function setLevel(level: int)

    # 跨层级节点转换
    function getNodeAtLevel(inputLevel: int,
        node: Node,
        outputLevel: int) -> Node
