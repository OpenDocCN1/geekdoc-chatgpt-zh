第一部分第1～2章 以智慧造就智慧

学术界研究智能主要有符号主义、连接主义、行为主义三大路线，分别从逻辑、仿生、行为切入。有自顶向下从本质出发经由逻辑推演行为的，也有自底向上把智能当作黑箱由行为反推本质的。各学派在不同时期都曾成为主流，并各自留下不少成果。

第三部分第6～8章 第三次浪潮

数十年来人工智能始终伴随争论。这一人类最精密的创造物与人本身的关系值得审慎思考，本部分聚焦人类与机器在追求智能过程中取得的成果与引发的争议。

# 前言

人工智能这个词如今被提及的频率越来越高，各类音频、视频、文字内容抢占眼球。曾经只存在于实验室的学术概念，如今成了产品经理和市场人士的常用语，也成为大众茶余饭后的话题。拥有机器学习或神经网络的系统仿佛就具备了自我进化、独立思考甚至超越人类的潜力，谈及会思考的机器时，人们既带着科幻式的神秘和敬畏，又忍不住想窥探潘多拉盒子里的秘密，同时又担心释放出难以控制的力量。

与此同时，人工智能带来的改变正悄然发生。打开新闻，推送的栏目和内容往往是机器为你定制的，甚至文章本身可能由机器根据搜索引擎热点自动生成。网购时首页展示的商品是你最可能感兴趣的，这是基于你近期行为的自动推荐。打开邮箱，广告和垃圾邮件已被系统过滤。今日这些智能化体验早已融入工作生活，其背后的技术进步不亚于机器在棋盘上击败人类冠军。

无论是否察觉到这些潜移默化的影响，无论持保守还是乐观态度，在发表看法前，不妨先花几小时客观地了解这门学科，弄清“人工智能是什么、有什么、发展到哪一步”等基础问题，再去评判应用与展望未来。让没有专业背景的读者读懂这些，正是本书的初衷。学科背景、来龙去脉、60多年里的重要人物、关键事件、理论学说、弯路与成果，都在此讨论。

读者可在其中体会到缔造者与开拓者如何追寻智能，以及相关理论方法如何运作。无论是产业从业人员、专业研究者，还是信息与计算机科学爱好者，都能有所启发。

智慧的疆界

本书取名“智慧的疆界”，因其概括了全书主旨。笔者理解的疆界有三层：

1)探寻智能奥秘过程中“已知”与“未知”的分界。起于代表计算能力的图灵机，终于掌握意识思维的终极智能，人类沿途摸索，越走越知，越知未见越多，值得记录学习。

2)人工智能发展历程中贡献心血的开拓者。从图灵、香农、冯·诺依曼、维纳，到纽厄尔、司马贺、麦卡锡、明斯基、皮茨、麦卡洛克，再到辛顿、杨立昆、本吉奥、乔丹、尼尔森等，一代代学者拓荒开路，其传奇值得记录学习。

3)“人类智能”与“人工智能”之间仍难以逾越的鸿沟。模仿、学习并掌握人类智能的本质，凭智慧造智慧是终极目标。经过六十余年乃至两三百年的探索，已找到若干可行路径、总结出一些方法、取得改变世界的阶段性成果，也遭遇诸多巨大困难与挫折，这些经验教训值得记录学习。

本书面向的读者

笔者希望做成人工智能领域的入门书。入门不等同于浅薄，更不等同于粗糙。人工智能横跨数学、信息、生物、心理等多学科，门槛很高，容易阻挡爱好者。本书力求让无专业背景的读者也能进入门槛。

同时希望写出一本有温度的专业书。技术都有其背景、要解决的问题和未知方向。学习不应只记方法，更要了解方法如何被发现、前人怎样思考、犯过什么错、走过哪些弯路。站在巨人肩上，若不明“智能”本身的概念就直接从深度学习入手，易陷管中窥豹。

当前人工智能书籍大致两类：一类回顾历史并做商业社会经济分析预测，一类解析某个子领域算法工具尤其是机器学习。本书不落这两类，而是聚焦“人工智能学科到底包含什么”这一入门却必要的问题。希望作为学习大纲，帮助读者先建立整体印象，再针对分支深入。只要能让普通读者读完一本书就形成全面客观的理解，便是最大成功。

为便于选择，说明不适合的读者与主要对象。

本书可能不适合的读者

1)目的在于学习某一具体分支的技术细节、工具使用、代码解析的读者，如 Caffe、TensorFlow、Torch 等框架应用。本书会介绍理论、技术与应用，讲清“是什么、解决什么、为何这样解”，但“具体如何解”涉及较少，不足以直接用于生产实践。此类读者宜从教材或工具书入手。

2)目的在于探讨前沿模型算法的读者。若你已是资深学者或从业者想了解最新成果，读书并非最有效方式，前沿研究更依赖论文与交流。书籍存在出版滞后，适合系统学习而非追踪前沿。

本书的主要读者对象

1.人工智能领域产品经理、管理人员
可作为全景大纲，了解人工智能能做什么、用什么技术解决、哪些问题成熟、哪些不成熟、历史踩过哪些坑。

2.需要使用智能软硬件的研发人员
面向有工程经验但数学基础不足的人员，以历史与前人思路而非纯专业知识介绍人工智能，让使用者知其然亦知其所以然。

3.信息科学和计算机科学爱好者
既是近代科技史，也是科普书和思想技术书，可了解前人在探索路上的努力与分歧，开拓思维视野。

4.人工智能相关专业研究人员
通过本书对学科发展脉络、解决的问题与前人思考形成整体把握，有助于在各分支深入探索。

### 1.1 概述

“人工智能”作为专业术语首次出现于1956年，但人类对人造机械智能的想象源远流长。古代神话里工匠造人并赋予意识，如希腊神话中的黄金机器人赫淮斯托斯与皮格马利翁的伽拉忒亚，中国《列子·汤问》中也有西周偃师造人的记载。

这种凭空幻想持续到20世纪40年代。二战对计算与通信能力的迫切需求推动相关研究成为主流，信息科学诞生、电子计算机发明后，学者才得以严肃探讨人造智能的可能性。
