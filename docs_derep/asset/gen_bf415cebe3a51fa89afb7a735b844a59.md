1. **上下文（context）**：把与任务相关的背景尽可能讲细，模型才能抓住来龙去脉，给出的内容才更对味、更相关。
2. **目标（objective）**：把想让模型完成的任务说清楚，让它知道最终要交付什么。

5. **受众（audience）**：明确谁来读，避免出现目标读者看不懂的内容。
6. **响应（response）**：锁定格式与结构，比如要求 JSON 输出，或采用金字塔、清单式等常见写法。

## 3.2 提示词框架实战

提示词框架就是一套模块化、可复用的模板，按场景拆分关键要素，帮助你快速搭出更精准的指令。掌握框架后，歧义会减少，任务完成率会提升，也能应对更复杂的业务需求。

### 3.2.1 框架价值速览

用好框架能带来三层收益。

1. **打破模型的理解盲区**。大模型的效果很大程度上取决于输入是否清晰，结构化信息能帮助它更准确地读懂意图。
2. **减少反复试错成本**。数据显示，使用框架后人与模型的交互轮次明显下降。
3. **匹配行业场景**。编程、营销、教育等不同领域沟通逻辑不同，框架提供对应的表达范式。
