90秒短剧打磨到分镜落地的视听关键

| 发展（5～50 秒） | 约45秒的铺垫阶段，循序推进情节，埋设小冲突与小转折，为后续高潮做准备，可安排1至2个场景，需写明场景、人物行为与台词 | 场景一办公室：女主忽然笑出声，从包里掏出录音笔。“刚才那句话，再说一遍。”女二脸色骤变。场景二走廊：女二追出欲抢笔，女主轻松避开。“晚了，已同步到云端。” |
| 高潮（50～75 秒） | 约25秒情绪释放段，呈现核心矛盾的收束与爽点兑现，画面要有张力、情绪要到位，让观众获得宣泄感 | 场景三会议室：女主当众播放录音，女二丑事曝光。老板大怒，女二被当场开除。女主目送女二被保安带走，神色平静 |
| 结尾钩子（75～90 秒） | 约15秒留客段，埋下悬念并暗示续集，可用画面定格配合台词或旁白 | 女主回工位，桌上放着纸条：“做得漂亮，不过才刚开始。”她抬头，远处出现一个神秘人影。定格 |
| 下集预告 | 可选字段，用一两句文字预告下一集核心冲突，增强追更欲望，语气带悬念 | “她以为自己赢了，却不知更大的阴谋正在逼近……” |

单集剧本精细化写作要点

要保证各环节时长合理，避免开场拖沓、高潮单薄、钩子乏力。借助智能工具精细化时，必须做到细节落地、情绪精准且适配生成，同时契合人设与主线。

- 时长精准把控，段落衔接顺畅
以90秒单集为例，开场钩子0到5秒要迅速进入冲突。发展段5到50秒铺垫充足不冗余。高潮段50到75秒集中释放情绪。结尾钩子75到90秒简洁有力留下悬念。

- 内容精细化，细节拉满
场景描写：简练具体，明确办公室、走廊、会议室等地点，布景不要复杂，便于生成与低成本拍摄。人物动作：贴合人设，精准传达情绪，比如女二脸色大变、女主眼神平静，避免动作堆砌。对话设计：简洁有力，符合人设设定，推动剧情，不出现无关废话。旁白或内心独白：按需使用，补充心理或背景，最多两句，不干扰节奏。

- 与主线联动，避免单集孤立
单集要紧密衔接情感线、事业线、秘密线，为主线服务，比如铺垫关系、埋设伏笔、推动核心矛盾，保证全剧连贯。

- 适配智能生成，降低修改成本
写作时考虑画面生成可行性，避免复杂动作、宏大场景、细腻微表情，尽量用“简洁画面加明确动作”的写法，让模型快速生成，减少人工修改。

重点：避免自嗨式创作，先锁定平台和观众偏好的爆款题材，再创作。
实操方法：让模型分析短视频和小说平台的热榜，归纳热门题材共性，预测未来一到两个月的趋势。

- 【第 2 步】人物设定：用 智能体 生成主角 + 配角
核心：人物立体且有记忆点。
重点：打造贴合题材、有反差、有辨识度的角色，避免工具人式扁平人物，为冲突与情感线做铺垫。
实操方法：参考3.1的角色设定提示词模板，设计明确提示词，让模型快速生成女主、男主及核心配角女二、男二、反派，重点明确姓名、性格、外貌、动机、秘密、成长弧线，生成后人工调整优化，修正生硬设定。

- 【第 3 步】结构设计：搭建整体结构与详细节点
核心：框架清晰。
重点：搭建全剧骨架，确保逻辑通顺、节奏稳定，避免拖沓断层，为分集大纲提供指引。
实操方法：按三幕式结构让模型设计梗概，明确各阶段起止与核心任务，结合3.3的情节节点方法，设计13到25个关键节点，覆盖全剧。

- 【第 4 步】分集大纲：模型生成 + 人工筛选
核心：框架清晰。
重点：将结构与节点细化为每集核心剧情，确保每集有明确目标、冲突与钩子，避免空洞。
实操方法：输入题材、人设、三幕结构、关键节点，让模型批量生成30集分集大纲，每集约100字，明确单集核心事件。
人工筛选重点：①剧情是否贴合主线，有无冗余；②每集是否有冲突与钩子，能否促追更；③人物行为是否符合人设，逻辑是否通顺。

【第 5 步】节点优化：人工调整节奏
核心：爽点密集。
重点：优化节奏，保证爽点密度，避免爽点间隔过长或虐点堆积，贴合AI短剧强情绪快节奏。
实操方法：对照100集大纲，检查关键节点分布是否均匀，每5到10集是否有一个爽点；调整虐爽比例，一般遵循“虐1爽2”，虐点后紧跟两个爽点；补充缺失钩子，确保每集结尾都有留客点。

【第 6 步】支线设计：生成支线 + 融入主线
核心：丰富剧情层次。
重点：通过支线深化人物形象，推动主线，避免主线单薄，增加可看性与情感深度。
实操方法：套用支线设计模板，重点设计1到2条核心支线如好友线、亲情线、对手线，要求有明确冲突与结局，与主线深度联动，支线事件能推动主线、影响成长；模型生成后人工调整，确保不偏离主线不冗余。

【第 7 步】人物弧光设计：完善人物成长
核心：角色丰满立体。
重点：避免扁平化，让角色有成长与蜕变，促成共鸣，提升口碑与黏性。
实操方法：结合3.3人物弧光模型，给模型输入明确提示词，完善主要人物弧光，明确各阶段关键转变事件与情绪影响；人工优化时检查成长是否自然、是否贴合人设，避免突然蜕变或性格大改。

- 【第 8 步】单集细化：模型批量生成 + 人工审核
核心：脚本可落地。
重点：将分集大纲细化为可拍摄、可模型生成的单集脚本，保证规范、细节落地、情绪精准。
实操方法：套用单集脚本标准格式，输入批量生成提示词，让模型生成每集脚本，严格按“开场—发展—高潮—钩子”四段式，时长约90秒；人工审核重点：①格式规范、时长达标；②对话动作符合人设；③场景描述简洁适配模型；④情绪精准，爽虐到位；⑤贴合大纲无逻辑漏洞。

- 【第 9 步】节奏检测：爽点密度优化
核心：节奏达标。
重点：通过工具检测，确保爽点密度与情绪节奏符合市场需求，避免拖沓平淡。
实操方法：用模型工具检测每集爽点密度与情绪起伏，关注：①每集是否有明确核心情绪；②爽点间隔是否合理不超过10集；③结尾钩子是否有力。根据结果人工优化，删减冗余，补充爽点或钩子。

【第 10 步】终稿定版：整合交付
核心：剧本可落地。
重点：整合单集脚本，形成规范可交付文件，便于后续拍摄、画面生成、剪辑。
实操方法：将优化后的100集脚本按集排序，统一格式字体段落字段，补充人设汇总、核心脉络、场景注意事项，检查遗漏错误，最终形成可直接交付的剧本文件。

避坑指南

- 坑 1：完全依赖模型，忽视人工优化
切忌直接把模型生成内容当终稿，不经人工审核优化，会出现逻辑漏洞、情感生硬、人设脱节。模型是工具，人工把控质量。
- 坑 2：追求一次完美，忽视迭代优化
新手易陷入完美主义，反复修改导致周期拉长。应先完成100集初稿再优化，上线后根据评论与数据再调整。
- 坑 3：忽略视觉可行性，脱离生成与拍摄实际
只顾剧情情绪忽视画面能否实现，模型生成能力有限，复杂特效或宏大战争场景需及时修改。
- 坑 4：忽视平台特性，盲目创作
不同短视频平台观众偏好不同，必须按平台特性创作，否则播放低迷。

# 第4章 Seedance 2.0 分镜脚本视听语法

文字到画面之间隔着视听语言，分镜脚本是桥梁。模型视频生成能力强，但在镜头关系处理上仍有不足，需要创作者主动引导生成具备视听质感的分镜。很多创作者剧本文笔好，到分镜环节却无从下手，本章从零讲解短剧视听语言，并示范如何用模型快速生成专业分镜。

## 4.1 短剧必备五大景别运用

景别即镜头与拍摄对象的距离关系，决定观众看到什么、感受到什么。短剧常用五种景别，掌握后可精准控制情绪节奏。

### 特写

特写是镜头近在咫尺的景别，主要拍摄人物局部或物体细节，画面极小，聚焦核心细节，背景被忽略。

## 功能详解

- 放大情绪
特写能放大微表情与情绪变化，让观众更真切感受，提升感染力。
- 制造压迫感
近距离镜头带来压迫感，如惊悚中锈迹铁门占满屏幕，会本能紧张。
- 标记关键信息
突出关键物品，暗示其作用。

#### 适用场景
短剧中特写的使用与情绪作用如下表所示。
表 4-1 短剧中特写镜头的适用场景
| 场景类型 | 特写对象 | 情绪作用 |
| :--- | :--- | :--- |
| 发现秘密 | 瞳孔放大的眼睛 | 震惊 |
| 情绪崩溃 | 滑落的眼泪、颤抖的嘴唇 | 心疼 |
| 愤怒时刻 | 攥紧的拳头、咬紧的牙关 | 愤怒 |
| 关键道具 | 戒指、照片、合同、手机 | 悬念/提示 |
| 身份揭晓 | 面具摘下瞬间、胎记 | 震撼 |

### 实战技巧

- 技巧一：情绪爆发前用特写蓄力
示例：女主哭前先给眼睛特写，眼泪在眼眶打转睫毛颤抖，定住观众等待爆发。
- 技巧二：爆发时用特写定格
示例：眼泪滑落瞬间特写定格放大悲伤；耳光打到瞬间特写放大冲击。
- 技巧三：关键道具给足3秒
示例：照片、合同等重要物品给3秒特写，让观众看清内容，配合音效如心跳声、钟表声强化重要性。

### 近景

近景表现人物胸部以上，面部细节清晰，同时保留少量背景，是AI短剧常用景别。

## 功能详解

- 专注对话
排除环境干扰，观众只听角色在说什么。
- 捕捉表情
清晰呈现动作与情绪变化。
- 建立情感连接
拉近距离，提升代入感。

#### 适用场景
表 4-2 短剧中近景镜头的适用场景
| 场景类型 | 近景作用 | 情绪定位 |
| :--- | :--- | :--- |
| 两人对话 | 让观众专注听内容 | 叙事推进 |
| 表白场景 | 捕捉脸红、眼神闪躲 | 甜宠 |
| 吵架场景 | 捕捉愤怒表情、唾沫横飞 | 冲突 |
| 单人独白 | 感受角色内心 | 共情 |

### 实战技巧

- 技巧一：近景加轻微晃动
吵架时手持轻微晃动，增加紧张真实感。
- 技巧二：近景加柔光
表白时柔光滤镜让皮肤柔和眼神更深情。
- 技巧三：正反打交替使用
对话标准拍法，A说话拍A近景，B说话拍B近景，每2到3秒切换保持节奏。
- 技巧四：沉默比台词更有力
对话中插入沉默，对视不说话，用近景捕捉张力。

### 中景

中景表现人物膝盖以上，兼顾面部表情与上半身动作，能展现肢体、情绪及人物与场景关系，是叙事主力镜头。

## 功能详解

- 信息量大
一镜包含表情、动作与简单环境。
- 节奏适中
不压迫也不疏离，是舒适观看距离。
- 剪辑安全区
中景可持续3到5秒，观众不会腻。

#### 适用场景
表 4-3 短剧中中景镜头的适用场景
| 场景类型 | 中景作用 | 示例 |
| :--- | :--- | :--- |
| 日常互动 | 自然叙事 | 吃饭、走路、工作 |
| 轻微动作 | 展示但不放大 | 递东西、起身、坐下 |
| 多人场面 | 交代人物关系 | 三人对话、家庭聚餐 |
| 过渡镜头 | 连接情绪 | 从特写到全景的中间状态 |

### 实战技巧

- 技巧一：中景是安全区
不确定用何景别时用中景不易出错。
- 技巧二：中景可持续3到5秒
特写最多2秒否则压迫，中景可给观众喘息。
- 技巧三：用中景展示关系
两人并排行走可同时拍互动；一人坐一人站可展示高低关系。

### 全景

全景展现剧情整体场景，涵盖人物完整形象与主要环境元素，让观众明确发生地。

## 功能详解

- 人物出场
第一眼看清角色全貌、身高体型穿着气场。
- 环境交代
告知观众地点是豪宅、出租屋、办公室还是街头。
- 关系展示
体现人物与环境关系，是主人还是闯入者。

#### 适用场景
表 4-4 短剧中全景镜头的适用场景
| 场景类型 | 全景作用 | 示例 |
| :--- | :--- | :--- |
| 角色首次出场 | 建立第一印象 | 霸总从豪车下来 |
| 场景转换 | 告知到新地方 | 女主走进新公司大门 |
| 多人场面 | 展示位置关系 | 会议桌上所有人 |
| 动作戏开始 | 看清空间布局 | 打斗前展示场地 |

### 实战技巧

- 技巧一：霸总出场先给全景
豪车长腿西装保镖用全景一次性呈现，再切近景看脸制造期待。
- 技巧二：全景不超过3秒
观众看3秒足够，再多会无聊，之后切中景或近景进入细节。
- 技巧三：用全景制造反差
女主站在豪宅门口全景，推近到破旧运动鞋特写，用反差营造孤独、宏大、苍凉。

### 远景

远景将人物置于广阔环境中，突出渺小与氛围，用于情绪升华与时间过渡。

## 功能详解

- 升华情感
结尾拉远镜头，让观众抽离回味。
- 时间过渡
展示日出日落四季变化，暗示时间流逝。

#### 适用场景
表 4-5 短剧中远景镜头的适用场景
| 场景类型 | 远景作用 | 示例 |
| :--- | :--- | :--- |
| 回忆片段 | 制造距离感 | 童年回忆用远景开场 |
| 结局升华 | 让情绪扩散 | 男女主相拥镜头拉远到城市上空 |
| 孤独时刻 | 放大渺小感 | 女主独自站在天台背景万家灯火 |
| 宏大场面 | 展示规模 | 千军万马、皇宫全景 |

### 实战技巧

- 技巧一：远景一般不超过3秒
AI短剧中信息量少，观众3秒会走神，除非结尾升华可延至5秒。
- 技巧二：远景加音效强化氛围
雨夜远景配雨声雷声，孤独远景配风声心跳声。
- 技巧三：用远景制造“蚂蚁感”
让主角在画面中显得很小，强化无助孤独。
