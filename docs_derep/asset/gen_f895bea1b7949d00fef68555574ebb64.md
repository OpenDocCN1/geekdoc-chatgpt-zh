# 深度解析：从 DQN 变体到策略优化与模仿学习的进阶之路

## 1. Double DQN：破解价值高估的“双网络”妙招

标准 DQN 存在一个显著缺陷：倾向于高估动作价值（Q 值）。其根源在于目标值计算时，`max` 操作实质上包含两步——先用网络挑出最优动作，再用目标网络给该动作打分。若这两步共用同一网络，由于神经网络拟合必然伴随误差，挑出的往往是被“误判”为高价值的动作，导致正向偏差不断累积。动作空间越大，这类“过高估计”越严重，甚至让算法失效。

Double DQN 巧妙地引入双网络机制化解此难题：主网络负责“选动作”，目标网络负责“评价值”。即利用在线网络输出选择贪婪动作，再送入目标网络获取其 Q 值。即便一方对某动作给出虚高评分，另一网络的独立估计也能有效纠偏，大幅缓解高估偏差。

## 2. Dueling DQN：拆解 Q 值，洞察状态与动作的差异

受 Actor-Critic 中优势函数 $A(s,a) = Q(s,a) - V(s)$ 启发，Dueling DQN 将 Q 网络解耦为两路并行分支：一路输出状态价值 $V(s)$，反映“身处该状态本身有多好”；另一路输出优势函数 $A(s,a)$，刻画“在该状态下各动作的相对优劣”。二者共享前置特征提取层（参数 $\eta$），末端分别拥有私有参数 $\alpha, \beta$，最终相加得出 Q 值。

[PRE4]

这种结构（如图 8-7 所示）带来显著收益：在动作影响较小的状态下，网络能快速通过 $V(s)$ 传播价值，无需为每个动作单独学习相近的 Q 值，极大提升样本效率。

[PRE5]

不过，单纯相加存在“表示不唯一”隐患：$V$ 加常数 $C$、$A$ 减 $C$，Q 值不变，导致训练震荡。Dueling DQN 通过强制最优动作优势为零（或令优势均值为零）施加约束，锚定 $V$ 的唯一表示，保证训练稳健收敛。

## 8.5.2 TRPO：在“信任区域”内稳步前行

用神经网络参数化策略时，梯度步长过大易导致策略性能断崖式下跌。TRPO 核心思想是划定“信任区域”，仅在新旧策略接近的区域内更新，提供单调提升的理论保证。

推导起点是将新策略目标 $J(\theta')$ 写在旧策略 $\pi_\theta$ 分布下的期望形式，引入优势函数 $A$ 量化动作优劣。通过数学变换，可得新旧目标差距与优势期望相关。若能确保新策略在旧策略状态分布下的加权优势为正，性能便单调递增。

[PRE10][PRE11][PRE12]

直接求解困难（新策略未知却需用其采样），TRPO 采用两步近似：
1.  **忽略状态分布偁移**，沿用旧策略状态分布，构造代理目标 $L(\theta')$；
2.  **重要性采样**修正动作分布差异，将目标转化为仅依赖旧策略数据的可估计形式。

[PRE13][PRE14]

为约束更新幅度，TRPO 引入 KL 散度作为距离度量，限制新旧策略平均 KL 散度不超阈值 $\delta$，形成带约束的优化问题。

[PRE15][PRE16]

该问题通过二阶泰勒展开近似：目标函数取一阶（梯度 $g$），KL 约束取二阶（Hessian 矩阵 $H$），转化为二次规划问题，利用 KKT 条件求得解析解方向 $x = H^{-1}g$。

[PRE17][PRE18][PRE19][PRE20][PRE21][PRE22]

### 核心技术点

**共轭梯度法避大矩阵逆**：神经网络参数动辄百万级，显式求 $H^{-1}$ 不切实际。共轭梯度法仅需计算海森-向量乘积 $Hx$，迭代求解线性系统 $Hx=g$，极大降低算力与显存压力。步长 $\beta$ 由 KL 约束决定，更新规则为 $\theta \leftarrow \theta + \beta x$。

[PRE23][PRE24][PRE25]

**线性搜索保安全**：因泰勒近似引入误差，候选更新未必真满足约束或提升目标。TRPO 引入回溯线性搜索，按衰减系数 $\alpha$ 反复缩减步长，直至找到同时满足 KL 约束与目标提升的参数。

[PRE26][PRE27]

**GAE 估优势**：广义优势估计融合多步 TD 残差 $\delta_t$，以指数加权平均（参数 $\lambda \in [0,1]$）平衡偏差与方差。$\lambda=0$ 退化为单步 TD，$\lambda=1$ 接近蒙特卡洛估计。

[PRE28][PRE29][PRE30][PRE31][PRE32]

## 8.5.3 PPO：轻量级的“截断”大师

TRPO 理论优雅但工程繁琐（二阶优化、共轭梯度、线性搜索）。PPO 继承其核心目标，却用极简的**截断机制**替代硬性 KL 约束，实现一阶优化即可媲美甚至超越 TRPO，成为强化学习“常青树”。

PPO 优化目标基于重要性采样比率 $r_t(\theta) = \pi_\theta(a|s)/\pi_{\theta_{old}}(a|s)$。核心创新是 `clip` 函数：将比率硬性限制在 $[1-\varepsilon, 1+\varepsilon]$ 区间。
- 优势 $A>0$（好动作）：鼓励增大比率，但上限锁死 $1+\varepsilon$，防止过度贪婪；
- 优势 $A<0$（差动作）：压低比率，下限守住 $1-\varepsilon$，避免过度惩罚。

[PRE33][PRE34][PRE35][PRE36]

这种“软约束”既保留了信任区域精神，又规避了复杂二阶计算，兼顾稳定性与工程落地效率。图 8-8 直观展示了截断如何切除极端更新区域。

[PRE37]

## 8.5.4 DDPG：连续控制的“离策略先锋”

TRPO/PPO 属 On-policy，样本利用率低；DQN 因需遍历动作空间取 `max`，难适配连续动作。DDPG 融合 DQN 离策略经验回放与 Actor-Critic 确定性策略梯度，专攻连续控制。

DDPG 维护四网络：Actor（策略 $\mu(s)$）、Critic（Q 函数）及其各自的目标网络。Actor 输出确定性动作，Critic 评估其价值。确定性策略梯度定理给出 Actor 更新方向：$\nabla_\theta J \approx \mathbb{E}[\nabla_a Q(s,a)|_{a=\mu(s)} \nabla_\theta \mu(s)]$。

[PRE38][PRE39]

目标网络软更新是 DDPG 另一亮点：$\theta' \leftarrow \tau \theta + (1-\tau)\theta'$，以插值方式平滑跟踪主网络，比 DQN 的硬替换更稳定。算法流程见算法 8-8。

# 8.6 模仿强化学习：无奖励也能学会像专家一样行动

现实任务常面临奖励稀疏、难以手工设计的困境。若有专家演示数据，模仿学习可绕过环境奖励，直接从状态-动作轨迹中习得策略。

## 8.6.1 行为克隆：最直观的“照猫画虎”

行为克隆（BC）将模仿退化为监督学习：专家状态 $s$ 为输入，动作 $a$ 为标签，最小化预测损失 $\mathbb{E}_{(s,a)\sim \mathcal{D}_{exp}}[L(\pi(s), a)]$。

[PRE42]

优点显著：实现极简，数据足时收敛极快。AlphaGo 早期即用 3000 万专家落子数据预训练，棋力超越业余高手。工程上常作为策略预热手段，让智能体从“高起点”开始强化学习探索。

但 BC 存在**复合误差**致命伤：训练分布仅覆盖专家轨迹。策略微小偏差会把智能体带入未见状态，随机乱选动作，进一步偏离分布，错误像滚雪球般累积（图 8-10），最终失控。

[PRE43]

## 8.6.2 逆向强化学习：反推奖励，再按图索骥

IRL 不直接拟合动作，而是**从专家行为反推奖励函数**，再跑标准 RL 优化策略。核心假设：专家行为隐含近乎最优的奖励结构。

### 最大熵 IRL：概率视角的奖励推断

将奖励参数化 $R_\phi(\tau) = \sum_t r_\phi(s_t,a_t)$。最大熵原理下，轨迹概率 $P(\tau|\phi) \propto \exp(R_\phi(\tau))$。优化目标是最大化专家轨迹集合的对数似然。

[PRE44][PRE45]

梯度形式揭示本质：让模型访问频率匹配专家访问频率。利用动态规划（前向-后向算法）计算状态边际概率 $P(s|\phi)$，迭代更新参数。

[PRE46][PRE47][PRE48][PRE49]

### 指导性成本学习：采样替代动规，适配高维未知动力学

最大熵 IRL 依赖已知动力学与离散动规，难用于复杂连续任务。GCL 引入**采样+重要性采样**双重机制：
1.  当前奖励下训练策略，采样轨迹无偏估计梯度；
2.  重要性采样权重 $w$ 修正新旧策略分布偏移，消除估计偏差。

[PRE50][PRE51][PRE52]

## 8.6.3 GAIL：对抗博弈下的分布匹配大师

GAIL 从**占用度量** $\rho_\pi(s,a)$（状态-动作对访问频率）角度重构模仿：专家与学习者博弈，使两者占用度量分布一致。

结构借鉴 GAN：
- **判别器 $D_\phi(s,a)$**：输出“来自学习者而非专家”的概率。训练目标：专家数据输出 $\to 0$，学习者数据输出 $\to 1$。
- **策略 $\pi_\theta$**：将 $- \log D(s,a)$ 作为奖励，用任意 RL 算法（如 TRPO/PPO）最大化累积奖励。

[PRE53][PRE54]

对抗训练中，判别器不断抬高“专家像”的门槛，策略被迫生成越来越像专家的轨迹。最终纳什均衡处，两者占用度量分布重合，模仿完成。图 8-11、8-12 展示目标与架构。

# 8.7 集成强化学习：集思广益，打造“全能型”智能体

单模型易陷入局部最优或偏好特定场景。集成 RL 借鉴机器学习集成思想：**并行训练多个异质/同质智能体，决策时聚合其输出（投票、加权、蒸馏等）**。这不仅分散单一训练运气风险，还能融合不同策略的互补优势（如探索与利用、稳健与激进），产出更稳定、泛化更强的最终策略，且天然适配分布式计算架构。
