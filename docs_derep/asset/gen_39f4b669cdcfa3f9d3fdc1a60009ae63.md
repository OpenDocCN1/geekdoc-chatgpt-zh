## GPT-4 Turbo 核心解析

GPT-4 Turbo 是 OpenAI 于2023年11月发布的自然语言处理大模型系列，属于 ChatGPT 4.0 与 ChatGPT 5 之间的过渡产品，相较 GPT-4 智能性和文案表达能力更强。

GPT-4 Turbo 是对 GPT-4 的优化升级，主要特点包括：

1. 创造力：可生成、编辑并与用户协作完成创意与技术写作任务，如作曲、编剧或模仿用户写作风格。
2. 逻辑推理：推理能力超越 ChatGPT 4.0，可解决日程安排、数学运算、语言翻译等更复杂问题。
3. 学习能力：利用更多数据与计算资源构建更强大的语言模型，并根据用户反馈持续改进行为与输出。

与其它 NLP 模型的区别：

（1）规模：目前最大的模型之一，约120层共1.8万亿参数，是 ChatGPT 4.0 约1750亿参数的10倍以上。采用混合专家 MoE 架构，共16个专家模型，每个 MLP 专家约1110亿参数，前向传播使用2个专家。训练数据涵盖网页、书籍、论文、新闻、社交媒体等数百 TB。
（2）生成能力：可基于输入自动生成符合语法语义的回答，支持对话、故事、诗歌、代码、论文等多种文本，也能将文本转为图像或图文融合生成新图像。
（3）适应性：多模态多任务，支持文本、图像、音频等输入输出，可处理问答、对话、生成、理解、分类等任务，具备零样本学习能力，无需额外微调即可应用于新任务。

性能表现：

（1）视觉能力：可从纯文本生成图像，或基于图像与文本生成新图像，也能用字母或 SVG 绘图。
（2）代码能力：可根据文字描述编写、运行和分析 Python、C、Java 等语言代码，也能处理伪代码与算法。
（3）数学计算能力：可解应用题、代数、几何等，并借助计算器提升数值精度。
（4）工具使用能力：可调用搜索引擎、计算器、字符查找等获取信息、计算数值、定位字符。
（5）人机交互能力：对话自然流畅，可根据场景调整语气风格，基于上下文生成合适回复。
（6）专业考试能力：可通过司法考试、SAT、GRE 等各类专业考试。

训练成本据报道约需25000个 A100 GPU 训练90~100天，利用率32%~36%，单次训练成本估计约6300万美元，因成本高昂主要通过 API 与订阅服务提供有限访问。

# Sora 横空出世，意味着什么？

2024年2月15日，OpenAI 发布革命性视频生成大模型 Sora。该工具可根据简短文字指令生成长达60秒的高度逼真视频，涵盖多角色、丰富动作与详尽背景。Sora 不仅展现了 AI 理解复杂世界动态的巨大进步，也标志着内容创作方式的新篇章，对现代社会将产生深远影响。面对来势汹汹的 Sora，人们关注它对生活、工作、创业的影响，以及中美 AI 差距。

## Sora：本质解读
一句话，Sora 能根据文本提示生成现实或想象场景的视频。与前代相比，它能严格遵循用户指令生成长达1分钟的高质量视频，体现了赋予 AI 系统理解并与运动物理世界互动的能力。

## Sora：技术跃迁与产业先声
作为继 ChatGPT 之后的又一力作，Sora 基于 Transformer 架构的扩散模型，将视频图像分解为类似 GPT token 的数据单元，并采用 DALL·E 重述技术，增强对物体自然动态的理解，实现了视觉数据处理的卓越表现，标志着视频生成技术进入新时代。

## GPT5 展望

GPT5 尚未正式发布，但业界已开始讨论下一代大模型方向。本书借用“GPT5”名称介绍下一代模型，实际名称以 OpenAI 发布为准。出版前夕传出“草莓”“猎户座”等模型参数最高达五万亿，性能为 GPT4 的100倍，2024年9月13日凌晨提前发布的草莓预览版性能已远超 GPT-4 Turbo。

GPT5 将于2025年推出，是 GPT-4 Turbo 的升级版。

- 规模：参数高达5万亿，训练数据涵盖文本、图像、音频、视频等类型，规模达 PB 级。

- 学习能力：利用更多数据与算力构建更复杂模型，并根据用户反馈持续优化，可跨任务学习。

- 问答系统：自动回答查询并解释推理。

- 视频生成：文本转视频、视频编辑与优化。
