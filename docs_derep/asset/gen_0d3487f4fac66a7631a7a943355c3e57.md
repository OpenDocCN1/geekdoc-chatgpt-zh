- 提示词最前面就明确写出格式要求：“注意：最终输出必须是符合小红书平台规范的 Markdown 格式”，并在工作流程的最后一步或输出格式说明里再次强调同一项格式要求。
- 角色确定之后，要在工作流的每一个主要环节开始前提醒模型当前身份，例如：“作为一名资深美妆博主，现在请你开始分析产品特性……”
- 遇到极复杂任务时，可把核心目标或关键约束在提示词开头与结尾各重复一次。

##### 3. 技巧三：上下文管理与渐进式引导

1）原理/说明

对于篇幅极长或包含多个独立阶段的任务，一次性把所有指令堆在一起容易超出模型有效上下文窗口，或即便窗口足够大，模型也难以一次性兼顾全部细节。此时可采用分步提示或链式提示策略：先让 AI 完成任务的子集或某一阶段，再依据已有结果给出下一步指令并补充必要上下文。这要求对对话历史和累积信息做好管理。比如进入下一阶段时，主动梳理前序对话的关键结论或重要的中间结果，并将其作为新提示的一部分，以维持任务连贯性。

2）应用示例

- 第一步提示：“请阅读‘××品牌奇迹光感持妆粉底液’的产品资料，并以列表形式总结出 5 条核心卖点。”（AI 产出卖点列表 A）
- 第二步提示：“你是一位资深小红书美妆博主。基于核心卖点：[在此处粘贴 AI 产出的卖点列表 A]，结合夏日年轻女性常见的底妆困扰，撰写一篇 300～500 字的小红书种草初稿，需要包含痛点引入、卖点场景化解读和真实使用感受。”（AI 产出文案初稿 B）
- 第三步提示：“请审阅下面这份文案初稿：[在此处粘贴 AI 产出的文案初稿 B]，检查是否符合小红书爆款风格，语言是否生动，emoji 使用是否恰当，并做优化。同时为此文案创作 3 个吸睛标题。”

##### 4. 技巧四：模型参数的精细调控

1）原理/说明

LLM 的生成行为受多项可调参数影响。其中温度 Temperature 控制输出的随机性和创造性；数值偏低如 0.1～0.5 时，模型更倾向于确定、高概率的表达，输出更专注保守；数值偏高如 0.7～1.0 时，输出更具多样性和创造性，但也更难预测。Top-p 核心采样控制模型生成每个词时考虑的候选词集合的累积概率。对于必须严格遵循复杂指令的任务，适度调低 Temperature 或 Top-p 能有效遏制模型的自由发挥，让其更忠实执行指令，降低跑题或生成无关内容的概率。

2）应用示例

在执行对格式和规则要求严格的商业文案生成任务时，可把 Temperature 设为 0.3。这样既保证流畅性，又能让输出更贴合指令要求，减少因随机性过高导致的不稳定。

##### 5. 技巧五：利用“系统提示”（如适用）

1）原理/说明

部分 LLM API 支持设置“系统提示”System Message，用来定义模型的整体行为、核心角色、高级指令或持久上下文。相比普通用户提示，系统提示通常权重更高、持久影响更强，不易被后续用户输入稀释、覆盖或遗忘。将贯穿始终的全局性指令，如角色定位、行为准则、输出风格等，放在系统提示中，能确保 AI 在整个交互中稳定遵循。
