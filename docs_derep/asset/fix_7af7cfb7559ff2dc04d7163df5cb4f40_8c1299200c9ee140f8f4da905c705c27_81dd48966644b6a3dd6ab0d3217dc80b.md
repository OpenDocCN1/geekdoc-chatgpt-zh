## 5.3 爬虫进阶——高效率爬虫

具备网络基础与 Python 编程基础后，完成基础爬虫并不困难。但在大数据背景下需求量常超出预期。例如爬取北京朝阳区朝外街道周边饭店较为轻松，若要覆盖全国饭店，请求量可能达百万乃至千万级，此时需要高效率方案。本章介绍几种常用做法。

## 5.3.1 多进程

Python 自带的 multiprocessing 包使用门槛低，只需定义任务函数，其余调度由包完成。该包支持子进程管理、进程间通信与数据共享，核心组件包含 Process、Queue、Pipe、Lock 等。

Process 构造函数的常用参数为：
[PRE10]
- group: 进程组，不常用。
- target: 表示调用对象，传入要执行的方法。
- args: 表示调用对象的位置参数元组。
- name: 进程别名。
- kwargs: 表示调用对象的字典。

常用方法见表 5-1。

## 表 5-1 常用方法表

| 方法 | 说明 |
|---|---|
| start() | 进程准备就绪，等待 CPU 调度 |
| setName() | 为进程设置名称 |
| getName() | 获取进程名称 |
| setDaemon(True) | 设置为守护进程 |
| join() | 逐个执行每个进程，执行完毕后继续往下执行 |
| run() | 进程被 CPU 调度后自动执行进程对象的 run 方法，如果想自定义进程类，直接重写 run 方法即可 |

## 【例 5-3】 开启进程

[PRE11]python
def run(name):
    #获取当前进程的名字
    tname = multiprocessing.current_process().name
    print("{} is starting,worker is {}".format(tname,name))
    return
if __name__ == '__main__':
    numList = []
    for i in range(5):
        p = multiprocessing.Process(target=run, args=(i,))
        numList.append(p)
        p.start()
        p.join()

## 5.3.2 多线程

爬虫需下载海量页面，单线程下每个请求都要等待服务器响应，总耗时为各次等待之和，效率偏低。多线程可并行发起请求，缩短空闲时间。

多进程与多线程均可实现并发，线程是进程的一部分，可共享内存与变量，资源消耗更小，但同步与加锁处理相对复杂。Python 使用 threading 包创建线程，构造方法如下：
[PRE13]
- group: 线程组，不常用。
- target: 表示调用对象，传入要执行的方法。
- name: 线程别名。
- args/kwargs: 要传入方法 的参数。
