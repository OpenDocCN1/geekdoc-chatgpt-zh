**方法二：用文本编辑器直接修改**

偏好命令行操作，或是你的部署环境没有可视化界面时，直接打开配置文件编辑往往是效率最高的路径。按个人习惯挑选编辑器即可：

# nano 快速编辑
nano ~/.openclaw/workspace/SOUL.md

# vim 模式编辑
vim ~/.openclaw/workspace/SOUL.md

# VS Code 可视化编辑
code ~/.openclaw/workspace/SOUL.md

USER.md 的修改方式相同，只需要把文件名替换为 USER.md。想先确认工作区里有哪些配置，可执行：

# 列出配置目录
ls -la ~/.openclaw/workspace/

执行后除了 SOUL.md、USER.md 之外，还会看到若干其他配置文件。暂时不必理会，后续章节会逐一说明。

**提醒**

文件写入后会立刻生效，下一次对话就会读取新设定。若感知不到变化，请先检查路径是否准确、是否已正确保存。

**调试原则：一次只改一处**

在初期摸索阶段，建议每次仅调整一个点，随后立即发起对话验证效果。若一次性改动太多，回溯问题会变得困难。慢即是快，这个思路对“养虾”同样适用。

**SOUL.md 与 USER.md 的协作关系**

常见疑问是两份文件冲突时如何取舍。

OpenClaw 的处理逻辑为：SOUL.md 奠定不可动摇的核心原则；USER.md 在不违背原则的前提下叠加个人偏好；实际对话中两者会被动态平衡。

例如 SOUL.md 规定“简洁”，USER.md 要求“详细”，最终效果是默认简洁，同时在需要时提供展开说明的选项。两者互补而非对立。

这也正是“养虾”的乐趣所在，多次微调后，你的个体将逐渐形成独特的性格轮廓。

方式二：交互式向导

openclaw channels add
按提示依次操作：选择“Feishu/Lark（飞书）”渠道 → 输入 App ID → 输入 App Secret → 配置私聊策略（默认配对模式）→ 配置群组策略（默认白名单）。

完成后向导会自动重启 Gateway，终端会出现类似“Channels updated”的提示，表示 OpenClaw 已就绪。

方式三：命令行直配（熟手适用）
# 终端输入
openclaw config set channels.feishu.appId "cli_ 你的 AppID"
openclaw config set channels.feishu.appSecret "你的 AppSecret"
openclaw config set channels.feishu.enabled true
openclaw config set channels.feishu.connectionMode websocket
openclaw config set channels.feishu.dmPolicy pairing
openclaw gateway restart
