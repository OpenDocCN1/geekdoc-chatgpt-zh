## 模型头部架构解析

首先看下网络预测头的核心逻辑。模型尾部采用 1x1 卷积将特征图通道压缩至类别总数，紧接着通过 Sigmoid 激活函数输出逐像素概率分布，最终得到形状为 `[batch, num_ROIs, 2xMASK_POOL_SIZE, 2xMASK_POOL_SIZE, num_classes]` 的张量，这便是分割掩码的直接来源。

## 环境准备与推理配置定制

完成源码拉取与依赖安装后，首要任务是定义推理阶段的配置类。由于是单张图片测试，将 `GPU_COUNT` 与 `IMAGES_PER_GPU` 均设为 1。沿用 COCO 预训练权重，因此 `NUM_CLASSES` 必须固定为 81（包含背景类）。实例化配置对象并通过 `display()` 校验参数后，即可初始化模型并载入官方权重文件 `mask_rcnn_coco.h5`。

[PRE2]python

class SimpleConfig(Config):

    # 设定名称

    NAME = "coco_inference"

    # 设定 GPU 个数，指定每张 GPU 运行的图像数

    GPU_COUNT = 1

    IMAGES_PER_GPU = 1

    # MS COCO 数据集的类别数

    NUM_CLASSES = 81

config = SimpleConfig()

config.display()

model = modellib.MaskRCNN(mode="inference", config=config, model_dir=os.getcwd())

model.load_weights("mask_rcnn_coco.h5", by_name=True)
