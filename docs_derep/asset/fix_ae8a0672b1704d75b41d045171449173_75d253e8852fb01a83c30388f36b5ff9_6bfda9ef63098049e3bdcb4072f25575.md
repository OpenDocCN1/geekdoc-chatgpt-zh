**2.3.3 多头关注机制**

多头关注并行运行多组自关注，从不同子空间学习多样化的上下文依赖，提升复杂模式建模能力。以“你是谁训练的？”为例，不同头侧重不同关联：

❍头 1：捕捉疑问词与核心词的关系，如“谁”与“训练”。
❍头 2：捕捉主语与谓语的关系，如“你”与“是”。
❍头 3：捕捉修饰与被修饰的关系，如“训练”与助词“的”。

多头关注的优势：

①多视角建模：各头可关注局部依赖、长距离依赖、语法结构、语义角色等，增强表达。
②缓解单一模式局限：单头易固化在固定模式，多头通过多样分布提升鲁棒性。
③提升泛化能力：类似卷积网络多滤波器，多头组合不同子空间特征，更好泛化。
④并行化计算：各头可并行，充分利用 GPU 等硬件加速。

### 3.2 大模型的精度与量化

大模型精度指权重在存储和计算时的数值精确程度，通常由浮点数位数决定。常见类型包括 FP32、FP16、FP8、INT8、INT4 等，不同格式的指数位与尾数位分配不同。

精度选择直接影响数值稳定性、计算效率与内存占用：高精度如 FP32 能保持更精确的梯度计算与权重更新，在复杂运算中更稳定，但显存消耗约是 FP16 的两倍且计算吞吐量下降；低精度如 FP16/FP8 可提升 Tensor Core 利用率，显著提高训练速度并降低显存占用，但可能出现梯度消失、数值溢出等精度损失。实践中常采用混合精度训练配合损失缩放来平衡效率与稳定性。

**3.2.2 大模型量化技术**

大语言模型常用 FP16 与 BF16，而 DeepSeek-V3 与 DeepSeek-R1 采用 FP8 混合精度训练。大模型量化是通过降低神经网络数值精度，如把 16 位浮点转为 8 位整数，来减少存储空间、计算资源与功耗，同时尽量保持性能。通过量化可有效减小模型体积，例如 FP16 转 INT8 后模型大小可减至约一半，且整数运算更快，推理速度得以提升。
