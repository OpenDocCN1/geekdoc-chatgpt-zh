# 数字经济冲击下，劳动规则如何续航

# 绪论

张鸣起

中国社会法学研究会会长

近些年，网络连接、物联感知、数据运算、智能系统等新一代信息技术更迭速度惊人，彻底改写了就业形态、生活节奏乃至人与人互动的方式。这样的变迁一方面拉动经济社会持续向前，另一方面也在不断制造新的治理难题。对根植于社会经济运行的劳动法制而言，这既是新的压力测试，也是新的完善窗口。跟上时代步伐、回应新问题，是服务新发展阶段、落实新发展理念、塑造新发展格局、推动高质量发展的现实需要，更是劳动法学研究者应有的责任。本书聚焦劳动领域的新动向，着重剖析网络与智能技术对劳动法制带来的前沿议题，并给出对策思考。

## 一、新型业态催生的用工变局与权益保护升级

党的十八大以来，我国数字经济、大数据等重大战略推进有力，成效显著。随着网络平台与智能驱动的新经济蓬勃扩张，用工模式明显趋向弹性化，众多新颖的就业关系涌现，却大多落在了现有劳动规范的覆盖之外。新行业的产生让用工呈现碎片化、作业空间虚拟化等特点，对传统和谐的劳资关系形成冲击，也让劳资关系的认定变得复杂。

平台派单、居家办公等新模式下，劳动者与需求方之间的联系已非传统的人身隶属。平台上劳务供给相对独立，双方表面看缺少传统劳资关系的人身依附特征，但从业者收入高度依赖平台，经济上的依附关系并未削弱。尤其在算法调度、定位追踪等技术深度介入任务分配的背景下，从业者实质上仍受指令约束，人身依附性不降反升。如何为平台从业者提供接近劳动者的保障水平，已成就业政策与学界的热点。平台经济的重塑作用影响产业结构与社会结构，对劳资关系认定、规范调整范围与方式产生深远影响。国际劳工组织在2021年《世界就业和社会展望》指出，过去十年全球数字化劳动平台数量增长了五倍，它们创造了前所未有的机会，也对体面就业与公平竞争构成威胁。平台工人面临的工作条件不稳定、收入波动、社保缺口、结社谈判受限等问题，在国内同样突出。

## 二、平台从业者权益确认的堵点与路径

我国是网络大国，依托平台就业的人数巨大，普遍面临身份模糊、工作时长过长、职业伤害保障缺位等痛点。现行劳动规范对其覆盖明显不足。

2021年4月，习近平总书记在广西考察时要求完善多渠道灵活就业的社保制度，维护卡车司机、快递员、外卖骑手等群体的合法权益。《国民经济和社会发展第十四个五年规划和2035年远景目标纲要》明确提出建立多渠道灵活就业机制，加强劳动者权益保障，健全劳动合同制度和劳动关系协调机制，探索建立新业态从业人员劳动权益保障机制。

2021年7月16日，人力资源社会保障部等八部门联合印发的《关于维护新就业形态劳动者劳动保障权益的指导意见》提出，符合确认劳动关系情形的企业应依法签订劳动合同；情况未完全符合但企业对劳动者实施劳动管理的，应指导企业与劳动者签订书面协议明确权利义务；个人依托平台自主经营的，按民事法律调整权利义务。这是官方文件中首次出现“不完全符合确立劳动关系”的表述。

同年8月，国务院印发的《“十四五”就业促进规划》要求加快落实上述指导意见，建立适应灵活就业和新业态的劳动权益保障制度，提高社会保障水平，规范平台企业用工，明确其劳动保护责任。2021年12月24日，国家发展改革委等九部门发布的《关于推动平台经济规范健康持续发展的若干意见》进一步提出完善劳动关系认定标准，探索明确部分符合情形的认定规则，合理确定双方权利义务。

各地规章和指导意见强调把握尺度：既不能将所有关系都简单劳动关系化，忽视新业态特殊性、过度增加企业负担；也不能去劳动关系化，把本应受保护的主体挤出保障范围。当前需要细化平台经济下劳资关系认定标准，明确部分符合情形的规则，逐步探索职业伤害保障机制。从长远看，对平台工人权益保护进行专项立法、填补制度短板势在必行。除已明确劳资关系的群体，还应将虽未建立劳资关系但确需保护的主体纳入法律保障范围。

## 三、远程办公兴起后的规范空白

疫情防控期间，远程办公、在线协同成为新常态，也暴露了用工环境的新问题。

2020年2月，人社部、全国总工会、中国企业联合会、中国企业家协会、全国工商联联合印发《关于做好疫情防控期间稳定劳动关系支持企业复工复产的意见》，鼓励有条件企业通过电话、网络等方式居家作业。同期工信部也提出推行远程工作、居家办公、视频会议、网上培训等在线工作方式。

远程工作具备电子化、分离性、灵活性等特征，有望长期存在。它本身不改变原有劳资关系，仅是作业场所与形态的转变，但也在削弱劳资关系的从属性，与现有劳动规范调整的传统办公模式存在差异。现行法制明显滞后。

企业大规模推行远程办公后，用工时间如何认定、工伤如何认定、福利待遇如何保障成为难题。工作与生活边界模糊，劳动者实际工作时长可能被拉长，对工时制度提出挑战。远程劳动者休息权、个人信息权、集体劳动权益的保护，也成为当下重点议题。

美国、欧盟、日本等均已在推动远程工作相关立法与政策。我国《劳动法》尚未对远程工作作出回应，这种空白削弱了法治对经济社会发展的支撑作用。建议将远程工作纳入《劳动法》或《劳动合同法》，明确概念、类型与立法原则，厘清双方权利义务，对工作时间、工伤认定、劳动保护、劳动报酬等作出细化规定，切实保障休息权、个人信息权和集体权益，为用人单位规章制定、劳动者维权和司法裁判提供依据。政府亦应发挥政策引领作用，引导行业健康发展与和谐劳资关系构建。

## 四、数据权利、表达空间与劳动基准的三重压力

我国正处于个人信息保护立法的快速推进期，《民法典》《个人信息保护法》《数据安全法》相继出台，具有里程碑意义。但网络普及也给职场个人信息保护带来巨大挑战。简历投递到离职全过程，劳动者信息泄露风险高企。

2021年8月20日，《个人信息保护法》正式通过。该法如何适用于劳动场景值得深入探讨。普通语境下的个人信息保护以“消费者”为原型设计，与劳动关系中“资强劳弱”及人格从属性的特殊性并不匹配。在数字化背景下，用人单位对劳动者信息的处理更彻底、可达范围更广，监视、分析、预测的风险上升，可能侵害人格尊严与自由发展。

《个人信息保护法》仅在第13条第1款第2项中涉及劳动关系，即为订立履行合同所必需，或依据合法规章制度和集体合同实施人力资源管理所必需时可处理个人信息，为特殊安排预留了空间。

合法、正当、必要是处理个人信息的基本原则，知情同意是合法性前提。但在劳动关系中，劳动者难以真正自由自愿选择；反之，保护缺位又会让用人单位监督控制更加随意。企业掌握的劳动者信息可分为一般信息和敏感信息。《个人信息保护法》第28条将敏感个人信息定义为一旦泄露易导致人格尊严或人身财产安全受损的信息。人脸识别考勤、病假证明等均涉及敏感信息。第29条要求处理敏感信息须取得单独同意。但用人单位以风险管控为由要求提供敏感信息时，若劳动者未同意，能否援引第13条第2款依据内部规章在人力资源管理所必需时收集，尚不明确。

“单独同意”的具体形式与标准立法未明。知情同意规则在劳动场景下的适用路径需要制度设计。正当必要原则的适用也需与合法原则形成平衡，涉及目的限制与比例原则的具体解释。此外，信息主体的删除权、可携带权、算法解释权等权利如何在劳动关系中实现？《劳动合同法》第50条要求用人单位保存解除或终止劳动合同文本至少两年，离职后企业仍可留存个人信息；新用人单位背景调查时又需调取前任信息，三者冲突如何协调，删除权能否真正落实，都需要更细致的规则。

在网络化时代，劳动者言论自由与雇主利益的冲突日益突出。新生代劳动者维权意识增强，信息获取便捷，手机平台推动社会进入实时交互的高频微时代。碎片化、海量信息让现实与虚拟高度交织，维权行为呈现新形式。新科技虽推动发展，也让就业与职业发展更不确定。诉求内容更具体、范围更广，集体争议、集体维权事件增多，群体性停工等风险上升，处理难度加大，对劳动法律实施和争议调处机制形成严峻挑战。

劳动基准是国家以强制性规范保护劳动者的制度集合。互联网发展对工时、安全卫生、工资支付、休假等制度提出新要求，以应对“996”、平台工时长等现象。劳动基准旨在保护劳动者、促进企业健康发展，核心在于工作时间、安全卫生、工资、休假等。劳资力量失衡需要公权力介入。

我国尚无统一劳动基准法，相关规定分散在《劳动法》《国务院关于职工工作时间的规定》《关于工资总额组成的规定》《工资支付暂行规定》《最低工资规定》《全国年节及纪念日放假办法》《企业职工劳动安全卫生教育管理规定》《禁止使用童工规定》《女职工劳动保护特别规定》《未成年工特殊保护规定》等之中。传统条款难以覆盖互联网环境下的新型劳动关系。企业以截止日期替代在岗加班，隐性要求在家“996”，现有制度难以有效防范。

完善劳动基准制度是必要方向。认定加班不应仅看公司工时，还应关注工作强度与实质加班。对加班猝死等情形需建立合理追责机制，并强化用人单位的人性化管理。数字化推动去劳动关系化，但劳动关系用工、民事关系用工、经济依附性用工仍是主流。

2021年7月人社部等八部门的指导意见已确认数字时代用工关系的多元格局。涉及生命财产安全的劳动条件应适用于所有劳动力提供者，而非仅限于劳动关系。2021年修订的《安全生产法》第4条第2款明确，平台经济等新兴行业生产经营单位应建立全员安全生产责任制，加强安全教育培训，履行安全生产义务，表明安全生产类劳动条件不以法律关系性质为转移。

网络时代出现大量远程工作、计件工作、任务式用工，去组织化特征明显。劳动基准理念上可以适用，但需要针对性设计。对无劳动关系但存在经济依附性的劳动者，劳动基准亦有适用空间。可考虑专设章节调整新业态劳动形态，并将虽未建立劳动关系但具有保护必要性的群体纳入劳动基准保护范围。

## 五、智能系统介入下主体边界与市场制度的重构

智能系统时代，AI对解雇、职业培训、社会保障等就业市场制度的适用带来挑战，智能系统能否作为劳动法上的主体，已成为不可回避的问题。
