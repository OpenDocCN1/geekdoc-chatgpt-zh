# 第四节 爱荷华州自驾概念框架

## 第 1 条 新增321.514定义
本条及第321.515至321.519条中，除文意另有规定外：
1. “自驾系统”指无论是否限于特定操作设计域，均能持续协同执行全部动态驾驶任务的软硬件。
2. “传统人类驾驶员”指通过手动操作车内加速、刹车、转向及变速选择装置驾驶机动车的自然人。
3. “无人驾驶车辆”指配备自驾系统，可在其操作设计域内完成全部动态驾驶任务的机动车，包括在无传统人类驾驶员干预或监督下实现最低风险状态。
4. “动态驾驶任务”指自驾系统特定操作设计域内，机动车在道路交通中运行所需的所有实时操作与战术功能，不含出行规划、目的地与停靠点选择等战略功能。
5. “最低风险状态”指当自驾系统故障导致无法完整执行动态驾驶任务时，系统可使车辆达到的合理安全状态，包括在可行情况下移至最近路肩、制停并开启应急信号灯。
6. “随需无人驾驶车辆网络”指采用软件应用等数字方式调度无人驾驶车辆运载人员或货物的运输服务网络，包括第325A.1条定义的出租运输与公共交通工具。
7. “操作设计域”指为使自驾系统妥善运行而设的全套条件，包括道路类型、速度区间、天气或时段等环境条件及其他约束。
8. “配备系统车辆”指装有自驾系统的机动车。

## 第 2 条 新增321.515运行
