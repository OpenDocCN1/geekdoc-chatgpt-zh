# 软件篇 MicroPython 驱动智能开发

## 项目一 认识 MicroPython

### 第一节 MicroPython 总览

`MicroPython` 是 Python 3 语言的精简高效实现，内置了部分 Python 标准库并针对微控制器做了优化。通俗讲它就是“微型 Python”，也常被叫做“精简版 Python”。它基于 ANSI C 开发，语法与 Python3 保持一致。借助`MicroPython`，用户完全可以用 Python 脚本实现底层硬件的直接操控，例如点亮 LED、驱动 LCD、读取电压、控制电机、读写 SD 卡、操作摄像头等。

### 第二节 兼容 MicroPython 的开发板

`MicroPython`自发布以来就备受关注，适配的开发板也迅速涌现。主流板型有：Pyboard、Micro：bit、`ESP8266`和`STM32`等。

随着`MicroPython`的普及，国内厂商也参考开源 Pyboard 自行研发了国产板型。当前最受欢迎的非 TPYBoard 莫属。`TPYBoard`的功能与 Pyboard 相近，均采用`STM32`作为 MCU，即控制器也称单片机，板载 4 个 LED 灯和一个加速度传感器。目前 TPYBoard 已衍生出多个版本，包含`STM32`标准版、基于 LAN 的有线版、基于`ESP8266`的无线版。

### 第三节 智能开发的思路

### 活动一：智能设备构成

智能设备大致由两大部分组成：

一是机械结构系统。例如常见的行走机器人，机械部分包括驱动轮、手臂、摄像头、扬声器等，每一部分都是独立的机械单元。底座若缺少行走机构机器人就无法移动，手臂若缺少伸缩弯曲结构就无法像人一样操作。机械结构是智能设备的根基。

二是智能控制系统。机械结构配合传感器即可具备感知能力，将感知数据回传给微处理器，处理器据此分析后指挥执行系统做出相应动作。

### 活动二：智能控制系统

智能控制系统由三大部分构成（图 2-1-4）。控制系统：相当于大脑，负责“思考”。传感器系统：相当于眼、耳、舌、皮肤，负责感知。执行系统：相当于手脚，负责行动。

[PRE20]

图 2-1-4　智能控制系统数据传输

#### （1）微控制器

控制系统是智能设备的“大脑”，它如同微型家用电脑，可执行程序指令并向执行机构发出动作信息。智能设备的控制模块通常拥有多个输入输出接口，用来接收外界信息后再下发指令给机械部件。

前面介绍的`MicroPython TPYBoard`即为微处理器，俗称单片机。单片机是一种集成电路芯片，已广泛渗透到生活各领域：导弹导航、飞机仪表控制、计算机网络通信与数据传输、工业自动化实时控制与数据处理、各类智能 IC 卡、豪华轿车安全系统、录像机摄像机全自动洗衣机的控制、程控玩具电子宠物等都离不开它。

#### （2）传感器系统

真正的智能设备通常都具备一定的感知能力，能感应并把信息传递给控制器的电子器件称为传感器。类比人体的感觉器官，智能设备的电子传感器按功能分类。例如光源传感器、声音传感器、气体烟雾煤气传感器、压力传感器、温度传感器等。它们的灵敏度与感应范围甚至超越人，例如电子指南针、红外传感器等。

#### （3）执行系统

正如人体的骨骼和肌肉配合才能完成动作，机器人的动作表现也由特定的机械结构实现。

编译器通常接收由各类编辑器生成的源程序，并与编辑器及其他程序集成到交互式开发环境`IDE`中。这类编辑器称为结构化编辑器，已内置编译器的部分功能，因此错误可在编写阶段即被发现。从编辑器中可直接调用编译器及配套程序，无需离开编辑器即可运行。
