## 8.25 英语论文摘要

阅读英文文献时，ChatGPT 能提供多项助力。

传统阅读一篇英文论文一般要经历三步：获取原文、翻译、理解并写摘要。ChatGPT 能把三步合并。比如要了解 *Attention is all you need*。

请分析一下以下论文：Attention is all you need

> “Attention is all you need”是 2017 年由谷歌 Brain 的一组研究人员发表的一篇论文，提出了一种名为 Transformer 的新颖神经网络模型，该模型采用自注意力机制（Self-Attention）来实现序列到序列的建模，其表现优于之前的基于卷积神经网络和循环神经网络的模型。

在传统序列到序列模型里，如 RNN，每一步都要依赖前一步输出，处理是串行的。Transformer 让序列中每个位置的元素可以并行交互，自注意力机制显式刻画不同位置间的相关性，从而在没有循环或卷积的情况下捕捉长程依赖。

Transformer 的核心是多头自注意力 Multi-Head Attention，可把输入映射到多个子空间并分别计算注意力，获得多样化的表征。配合位置编码 Positional Encoding，模型能感知顺序信息。

该模型在机器翻译、语音识别、自然语言处理等领域表现突出，成为主流架构之一。这一思路也被迁移到计算机视觉，用于图像生成、分割等任务。

# 第9章 OpenAI API

## 9.1 API 概论

OpenAI API 由 OpenAI 研发维护，为开发者和企业提供基于人工智能的服务，便于把自然语言处理、语音识别、图像识别等能力接入自有应用。

平台提供多款预训练模型，如 GPT-3、DALL-E，可用于文本生成、分类、翻译、图像生成等任务。还提供文本摘要、语言翻译、内容生成、问答等工具，均基于最新研究成果。

整体由以下部分构成：

- 模型 API：最核心入口，提供对预训练模型的调用能力，代表作 GPT-3 支持生成、分类、翻译等。
- Playground：交互式体验界面，可输入文本观察模型输出。
- DALL-E API：把自然语言描述转为图像的接口。
- API 文档：包含端点说明、参数、示例代码等，地址 https://platform.openai.com/docs/introduction。

## 9.2 交互方式

目前支持三种方式：

- HTTP 请求：任何语言均可通过 HTTP 调用。
- 官方 Python 绑定：运行 pip install openai 即可。
- 官方 Node.js 库：在项目目录运行 npm install openai。

## 9.3 关键概念

### 9.3.1 提示语（Prompt）

提示语是用来引导 ChatGPT 生成响应的输入文本。提示的质量直接影响输出的相关性和准确度。好的提示应清晰、简洁、具体。

常见启发式提示：

- “你能告诉我更多关于……” 
- “请为我解释一下……” 
- “你有任何关于……的建议吗？” 
- “我应该如何处理……” 
- “你认为……是好的决定吗？”

实践中，若首次回答偏差，可尝试说一句 “let’s think step by step”，常能得到修正。

### 9.3.2 完成（Completion）

在 API 调用里，完成指模型根据输入生成的输出文本。输入是问题或句首，输出是续写、回答或摘要等。

完成是语言模型的关键能力，可用于自动回复、智能客服、摘要、翻译、内容生成、情感分析等场景。通过指定长度、温度等参数，可控制输出风格。

### 9.3.3 标记（Token）

标记是自然语言处理中的基本单元，可是一个词、标点、数字或子词。文本需先分词再转为索引输入模型。

以英文为例，the cat sat on the mat 会被切成 the、cat、sat、on、the、mat 六个标记。像 hamburger 可能被拆成 ham、bur、ger。

不同语言分词策略不同，中文常需专门工具。粗略经验：英文约 1 个标记≈4 个字符≈0.75 个词。提示与生成的总长度不能超过模型上下文上限，通常为 2048 个标记，约 1500 词。

### 9.3.4 模型

API 提供多类不同用途与价格的模型：

- GPT-3.5：一组改进自 GPT-3 的模型，可理解并生成自然语言或代码。
- DALL·E 测试版：根据自然语言提示生成与编辑图像。
- Whisper 测试版：将音频转为文本。
- Embeddings：将文本转为数字向量。
- Codex 限定测试版：理解自然语言并生成代码。
- Moderation：检测文本是否敏感或不安全。
- GPT-3：可理解并生成自然语言的基础模型。
