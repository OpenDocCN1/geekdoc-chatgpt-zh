深度学习的层数革命

严格来说，只要超过三层就可以被称作“深度”神经网络，但真正让网络变深的，是过去十年算力的暴涨。AlphaGo 当年的核心正是这样一座十三层的模型，2015 到 2016 年间凭借它击败了世界顶尖围棋手。想要让模型发挥作用，数据规模必须跟上，团队为此让每颗 CPU 每秒模拟多达上千局对局来做训练。到了 2017 年，AlphaGo Zero 完全自学，累计模拟约 2900 万局对局，换上 79 层的结构后，以 100 比 0 的比分完胜上一代 AlphaGo。如今不少项目已经迈向百层以上。

层数堆高不等于智能直线上升，把层数理解为对细微特征和抽象层次的叠加会更准确。当问题足够复杂且数据充足时，更深的网络往往能捕捉到浅层模型忽视的隐蔽规律。这个洞察已成为整个人工智能领域的关键思维，也解释了为何医疗、材料科学等传统行业正加速拥抱信息技术。算力价格的下降让深度网络的使用从梦想变成现实；数据采集与存储成本的降低，又让喂饱这些深网所需的大量样本变得可行。随着深度学习渗透的领域越来越多，这些行业有望迎来智能的指数级增长。
