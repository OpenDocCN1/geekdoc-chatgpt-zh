## 5.11 用列表模拟栈

Python 没内置栈类，但列表天然支持后进先出（LIFO）：
- **入栈** → `append(item)`（加到尾部）
- **出栈** → `pop()`（弹出并返回尾部元素）

实测一下：
[PRE8]

每次 `pop()` 都拿走并返回最后压入的值。对空栈 `pop()` 会抛 `IndexError`，所以实战前最好先判长度。若入栈持续快于出栈，内存也会撑爆。

> 同理，列表也能模拟**队列（FIFO）**，只需把“出队”改成 `pop(0)` 或用 `collections.deque` 效率更高。
