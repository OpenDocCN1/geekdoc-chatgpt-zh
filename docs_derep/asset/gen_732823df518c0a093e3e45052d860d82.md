在架构层面，这三个 Agent 同跑在同一个 OpenClaw 实例里，只是各自拥有独立的工作空间。它们之间的联动靠的是 OpenClaw 自带的 agent_send 工具来传递消息。使用者只要在飞书群里 @产品经理 下指令，后续的拆分、研究、撰写全程由各 Agent 自主推进，最终成果也会直接回写到飞书群里。这种做法让复杂任务的处理效率明显提升，同时全流程对用户来说既透明又可追溯。

## **12.2** **核心技能剖析与配置**

在这个多智能体团队里，Researcher Agent 承担的信息搜集与分析压力最大。为此我们为它挂载了 ClawHub 上的进阶搜索与分析能力。

**12.2.1** **exa-web-search-free 技能**

做深度市场调研时，普通关键词检索往往力不从心。exa-web-search-free 技能接入了专为 AI 设计的 Exa，原名 Metaphor，语义搜索引擎。它能读懂复杂自然语言提问，比如“2026 年最具创新性的 AI 硬件产品及其商业模式”，并直接给出高相关、高质量的网页内容。

这种语义级检索大幅压缩了 Researcher Agent 过滤低价值信息的耗时，让它把精力集中在提炼与分析上。

安装方式为在终端执行：

clawhub install exa-web-search-free

装好后需要在 openclaw.json 中填入 Exa 的 API Key 才能调用。市面上类似的网络搜索技能不少，部分免 Key，具体用法请看对应技能的 Skill.md 说明。

**12.2.2** **Agent-to-Agent 通信机制**

多智能体协作成败的关键是通信。OpenClaw 内置的 agent_send 工具支持 Agent 间直接互传消息与上下文，属于系统核心能力，无需额外从 ClawHub 安装。只要在 openclaw.json 里显式开启并列出可通信的 Agent 名单即可。

有了这套机制，Agent 之间不再信息孤岛，复杂任务可以像人类的团队一样开会、交接文档。同时每个 Agent 都在自己的独立工作空间运行，记忆状态相互隔离，避免上下文串扰。

# **第十三章 多智能体驱动的开发者工具链自动化**

在软件开发里，写代码只占开发者极小的时间，大量精力被代码审查、单元测试、构建部署以及修复构建错误等繁琐环节消耗掉。

本章面向开发者，展示如何借助 OpenClaw 独有的 Lobster 确定性工作流引擎，结合多智能体架构，搭建起“编码-审查-测试”全自动化的开发者工具链。以基于 HTML5 Canvas 的贪吃蛇游戏为例演示全流程。

## **13.1** **需求分析与架构设计**

一个典型的自动化开发工作流要解决以下核心痛点。

• 非确定性问题：LLM 输出存在随机性，若完全依赖 LLM 自动编排测试脚本、解析错误日志、修复代码的循环，很容易陷入死循环或产生不可预期副作用。

• 缺乏显式审批：代码提交或分支合并等关键操作必须设置人工显式审批关卡，不能任由 Agent 自动执行。

• 角色单一性问题：让同一 Agent 既写代码又自审，容易“当局者迷”，难以发现自身逻辑漏洞。

为此我们设计了一个由 3 个 Agent 组成的开发团队，并引入 Lobster 工作流引擎。角色分工如下。

• Coder Agent（全栈工程师）：接收开发需求，编写核心业务逻辑代码，如贪吃蛇的移动、计分、碰撞检测。

• Reviewer Agent（资深架构师）：对 Coder 提交的代码做静态审查，检查规范、潜在内存泄漏和逻辑漏洞，并给出修改建议。

• Tester Agent（测试工程师）：编写单元测试用例，并触发 Lobster 管道运行测试。

流程编排上，OpenClaw 引入 Lobster。Lobster 是一个类型化的工作流运行时引擎，能把多个命令行工具串联成确定性 Pipeline，并在其中插入审批关卡。Coder 与 Reviewer 完成迭代后，Tester 调用 Lobster 执行测试管道。若测试失败，管道把错误日志返回给 Coder 修复；若测试通过，管道暂停并向飞书发送审批请求，待用户确认后自动创建 Pull Request。

## **13.2** **核心技能与工具剖析**

本场景不再只依赖 ClawHub 第三方技能，而是深度使用 OpenClaw 内置的高级工具和多智能体通信机制。

**13.2.1** **Lobster 工作流引擎**

Lobster 不是普通技能，而是 OpenClaw 的可选插件工具。它通过解析 .lobster 格式的 YAML/JSON 文件执行多步骤命令。核心优势如下。

• 一次调用代替多次交互：Agent 只需调用一次 Lobster 即可执行一系列 Shell 命令，节省 Token 并减少往返时间。

• 内置审批机制：管道执行到带有 approval: required 的步骤时，会暂停并返回 resumeToken 给 OpenClaw，同时通过飞书向用户展示审批卡片。

• 保证确定性与安全性：管道执行逻辑硬编码在 YAML 文件中，限制 AI 自由发挥，确保构建测试过程绝对安全。

启用 Lobster 需要在 openclaw.json 中配置，并确保宿主机已安装 Lobster CLI。

**13.2.2** **GitHub 技能**

为让 Agent 能拉取代码、创建分支和提交 PR，需要安装 ClawHub 上最受欢迎的开发者技能之一：github。该技能封装了 GitHub 官方 CLI，即 gh，允许 Agent 用自然语言管理代码仓库，是实现完整 CI/CD 闭环的关键。

clawhub install github
