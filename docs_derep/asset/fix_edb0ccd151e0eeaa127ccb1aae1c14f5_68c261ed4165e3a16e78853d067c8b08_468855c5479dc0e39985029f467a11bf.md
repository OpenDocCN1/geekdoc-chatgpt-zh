结构化提示词，让大模型更懂你

STAR 把一次含糊的需求拆成情境、任务、行动、结果四个递进环节，用线性逻辑把意图讲透，帮助模型抓住要点并产出高质量回答。

# 表 4-1 STAR 法则的要素的说明

| 要素 | 说明 |
| :--- | :--- |
| Situation | 交代事件的背景与前提，为模型建立清晰的情境框架。例如面试准备时，需要说明目标岗位、企业背景以及客户画像 |
| Task | 点明需要完成的具体目标，让模型聚焦核心诉求。例如让模型产出一份面试作答，或完成论文的某一段落 |
| Action | 明确具体的做法或要求，指导模型如何推进。例如要求结合行业特点写作，或引用相关文献支撑 |
| Result | 预设希望达到的效果，让模型对齐输出标准。比如面试回答要能获得考官认可，论文段落要逻辑通顺、信息充实 |

#### 4.3.6 借助大模型优化提示词

在提示词设计和内容创作中，常出现不会写提示词或效果不达标的问题。本节介绍两种实用做法：借助大模型优化提示词，以及利用续写和扩写指令丰富内容。

### 1. 借助大模型优化提示词

当提示词无从下手或效果不佳时，可直接请模型帮忙。如图 4-18 所示，针对新品按摩仪广告文案，可提问：“我想为公司新款按摩仪设计广告文案，该如何编写提示词？”模型会给出可用框架和示例帮助定位。

若已有提示词效果不理想，也可让模型给出修改建议。如图 4-19 所示，将现有提示词提交给模型请求优化，可逐步提升精准度和效果。

### 2. 善用“续写”和“扩写”指令

创作中遇到卡壳或表达不清时，续写和扩写指令非常实用。

#### 如何编写提示词，借助大模型为公司最新款按摩仪设计广告文案？

要获得更精准有效的广告文案，需提供细节和明确指示。以下为编写框架：

1. 明确目标受众：
    * 目标人群：如白领、运动爱好者、老年人、孕妇等。
    * 痛点需求：如缓解肩颈酸痛、改善睡眠、放松肌肉等。
2. 突出产品特点和优势：
    * 核心功能：如3D按摩、热敷、多种模式等。
    * 技术优势：如仿人手按摩、智能感应、静音设计等。
    * 差异化卖点：如便携设计、高性价比、明星代言等。
3. 设定文案风格和传播渠道：
    * 文案风格：如科技感、温馨治愈、幽默风趣等。
    * 传播渠道：如电商平台、社交媒体、线下广告等。
4. 提供参考案例：
    * 优秀广告文案：如竞品文案或你欣赏的案例。
    * 品牌调性：如品牌形象、品牌故事等。

**示例提示词：**

> “你是一位资深广告文案策划师，请为我公司最新款智能按摩仪设计一则广告文案。目标受众是25-40岁的白领，长期伏案工作，饱受肩颈酸痛困扰。产品主打3D按摩、热敷功能和多种按摩模式，采用仿人手按摩技术，能精准按摩穴位、缓解肌肉疲劳。文案风格要求简洁明了，突出科技感和实用性，用于电商平台产品详情页。请参考以下优秀广告文案示例：[优秀广告文案示例]。”

我使用下面的提示词后生成效果不好，请给出一些对该提示词的优化建议。

提示词：“请为我公司最新款按摩仪设计一则广告文案。该按摩仪主打3D按摩、热敷功能和多种按摩模式，采用仿人手按摩技术，能够精准按摩穴位，缓解肌肉疲劳。”

你的提示词已给出产品基础信息，但可进一步优化以产出更有吸引力、更具针对性的文案。建议：

1. 明确目标受众
    * 提示词未说明面向谁。不同人群关注点不同，明确受众有助于提升针对性。
    * 优化建议：加入受众描述，例如“主要面向久坐的白领和运动爱好者”。

例如撰写旅游景点宣传文，可先写开头再让模型续写：“请根据以下内容续写一篇景点宣传文章。已完成内容：北京故宫位于北京市中心，是明清两代皇家宫殿，旧称紫禁城，坐落于北京中轴线上。”模型会基于已有信息推理并生成后续内容，如图 4-20 所示，可带来新灵感。
