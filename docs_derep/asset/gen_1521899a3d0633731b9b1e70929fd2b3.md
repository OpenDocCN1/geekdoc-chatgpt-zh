哥德尔的妙手在于把元语言的语法层与算术的数值层强行叠合。一旦逻辑上的意义与数论上的关系可以互换，可证性这个原本属于元语法范畴的判断就降维成了纯算术的性质。于是 WFF 集合能否拥有某种算术特征，直接决定了它是否可证；即便一个命题在直观上成立，只要不具备对应的算术刻画，就只能停留在不可证的状态。

**第三步：构造一个命题，它为真是因为它说它不可证明为真**

Pr（x）刻画的是数的可证属性。形式系统里的每个 WFF 都经哥德尔配数得到一个自然数，对任意有效断言 p，总有 GN（p）与之对应。对于能够被证明的定理，令 n=GN（p），此时 Pr（n）成立，即数字 n 对应的命题 P 是可证的。换句话说，Pr（x）只有真假两种取值：

Pr［GN（p）］当且仅当 p 可证。

表述的意思是，只要陈述 p 可证，其哥德尔数就具备 Pr 性质，反之亦然。

接下来定义数的另一个属性[PRE3]（x），它恰好是 Pr（x）的否定。它的真值对应命题 x 不是定理，也就是：

[PRE4]［GN（p）］当且仅当 p 不可证。

即当 p 是一个不可证的有效命题时，其哥德尔数的[PRE5]为真，这就是哥德尔意义上的不可证性。这里直接引用对角线引理：对任意单变量命题函数 F（x），都存在一个数 n 使得 F（n）的哥德尔数就是 n 本身。取 F（x）=[PRE6]（x）即可。于是引入数 g，由对角线引理得到 g=GN［[PRE8]（g）］。这句话断言 g 是“g 不具备 Pr 属性”这一命题的哥德尔数。注意 g 本身也是一个巨大的自然数。它对应的命题正是[PRE9]（g），记作 G，它在说 g 不可证，即 g=GN（g）。结合

[PRE10]［GN（p）］当且仅当 p 不可证。

令 p=G 代入可得：

[PRE11]（g）当且仅当 g 不可证。

也就是说，G 为真恰好等价于 G 不可证。

哥德尔展示的构造不仅适用于所讨论的算术形式系统，对任何包含算术的形式系统都成立。如果把 G 加入公理得到新系统，同样可以再造出新的不可证真命题。无论加入多少条有限公设，都无法根除这种现象。在任何自洽且包含算术的形式系统里，都存在真但不可证的命题。

这就是哥德尔第一不完备定理。

> 定理 1 形式系统如果是自洽的则是不完备的。

哥德尔第一不完备定理可拆成条件与结论：若算术形式系统自洽，则必有命题 G 真而不可证。若系统的自洽性本身能在系统内被证明，那么这一陈述就成为结论的证明，从而导致条件不成立。因此自洽性在系统内部是不可证的。

这就是哥德尔第二不完备定理。

> 定理 2 形式系统不能证明自身的自洽性。

G 不可证的事实说明元数学对 G 的描述为真，在《数学原理》中一个表达真理的命题 G 却无法被证明，说明《数学原理》不完备。即使把这个不可判定命题作为新公设加入系统，哥德尔指出仍可再造出新的不可判定命题，公设扩张的设想因此落空。由此可推，数论中存在无穷多个真理无法由数论公设和定理推出，不断引入外部定理也总会有剩下的数论真理无法被形式逻辑证明。

不幸的是，自洽性不可能在形式系统内部得到证明。系统自洽要求命题与其否定不能同为定理，这是无矛盾的必要条件。若不满足，则系统可证任意命题。因此“自洽性”等价于“系统里存在不可证的命题”。

## 对角线证明法

换一个程序员更熟悉的视角重述证明，不再显式使用哥德尔对角线引理，但思路同源。严格的证明往往省略了大量默认的推演规则，我们通常把它们当作常识而不加证明。下面先统一术语。

### 逻辑术语

定义：一个证明系统是自洽的，如果系统中的某个陈述 S 或其反命题[PRE14]可以被证明，但我们并不要求被推出来的陈述必然为真。

定义：一个形式系统是完备的，如果所有为真的命题都能在该系统中被证明，我们并不要求所有为真的陈述都可被证明。

哥德尔不完备定理：没有任何证明形式系统能同时做到自洽与完备。回顾一下形式化证明的构成。

一个形式化证明系统 Π 包含以下三要素：

> 1.有限的可用于证明的词汇组

> 2.有限的公设

> 3.有限的推演规则

“足够丰富”指形式系统能对任意 x 的取值做出判定。

定义：如果命题系统里 f 能被确定为真或假，那么该系统就是足够丰富的。

定义：我们用[PRE15]表示这样一个方程族——输入任意正整数，计算后输出 0 或 1。若方程 f 属于[PRE16]，则对任意正整数 x，f（x）必为 0 或 1。

定义：可计算。方程 f 是可计算的，意味着可以用有限长的程序，如 Python、C 等，在可执行设备上运行，给出任一正整数 x 的结果 f（x），且在有限时间内终止。

定义：[PRE17]是[PRE18]中所有可计算方程 f 的集合。

很容易看出[PRE19]中的方程有无穷多个。例如第一个方程在 x=1 时输出1，其余输出0：

f（1）= 1；f（x）= 0，x≠1

第二个方程在 x=2 时输出1，其余输出0：

f（2）= 1；f（x）= 0，x≠2

由于自然数无穷可枚举，这类方程也无穷多。

下面证明[PRE20]里存在不可计算方程，即可计算方程集合[PRE21]是方程集合[PRE22]的真子集。即[PRE23]严格小于[PRE24]，总有些方程有确定结果却不可计算。

### 证明

在任何形式系统中，只要证明存在，就对应一种算法。假定系统以有限字母表编写的符号语言表达，可把符号串按字典序排列：先按长度，再按字母。这就把所有合法证明排成序列，并由此得到系统全部定理的列表。

对可计算方程，写出其计算步骤，再按文档的字母顺序排列。程序常用换行符分隔，这不影响把整段程序视为一个字符串。如用某种语言编写的程序 Pf 计算可计算方程 f，对应字符串有限。我们先按长度排序，长度相同时按字母顺序排，就得到所有可计算程序的字典 L。每个可计算程序在 L 中都有固定位置。若同一方程对应多个程序，只保留序列中最靠前的一个。同一题不同写法在编程作业中常见，变量名不同但等价，我们只取最短字母序最靠前者作为代表。

补充“真”“假”的含义。

把陈述称为 f 陈述，对任意正整数 x，若表述为“f 是1”或“f 是0”，每一个 f 陈述都是对某个整数的判定。如 f（107）=1 就是一个 f 陈述。对任意输入，f 陈述只有 0 或 1 两个值。第一个是 f 陈述 Sf，第二个是反 f 陈述，[PRE51]f。

定义真值：若 f 等于1，则关于 f 的陈述 Sf 为真，其对面 [PRE52]f 为假；若 f 等于0，则[PRE53]f 为真，而 Sf 为假。对任意输入 x，Sf 与[PRE54]f 必一真一假。在有效证明体系中，不可能证明假命题为真。

形式系统足够丰富：任何 f 命题都可以被确定陈述。我们只要求它有确定值，未必已被证明或证伪。这一点很重要。

设系统 Π 是足够丰富的形式证明系统，且满足：

A. 任何假命题不能被证明；

B. 任何真的 Sf 命题，都存在属于 Π 的证明序列来证明 Sf 为真。

由于系统足够丰富，任一整数 x 都有 Sf 与[PRE55]f 的陈述，且只有一个为真。A 和 B 意味着总有一个有限证明序列证明 Sf 或[PRE56]f 为真。该证明序列本身可作为一个确定程序，在有限时间内给出结果，因而是可计算的。这与前述 f 不可计算矛盾。具体地，若 A、B 同时成立，可设计程序 P 在有限时间内计算出[PRE57]。对输入 x，P 在有限时间输出 0 或 1。再配上 P' 检测输出是否符合 1–f（x），不符合时用 P'' 检测否定，就得到能有限计算 f 的有限程序。但我们已证明[PRE58]不可计算，与之矛盾，故假设 A 或 B 不能同时成立。

因此，对任意足够丰富的形式系统 Π，若它自洽，则系统内必存在正确陈述不可被证明。等价地说，自洽系统里一定存在自然数命题，其正反两面都不可证。

类似地可得图灵停机问题的不可判定性，也即不存在能判定其他程序是否在有限时间内终止的超级程序。

# 第六章

哥德尔问题的延伸

[PRE60]

真理存在且持续。哥德尔不完备定理解释了为何我们始终需要感性部分的参与，总有些直觉认知无法被纯理性取代。这些感性认知构成了人之为人的重要维度。

《数学原理》是这次冲击的首当其冲者，但绝非唯一。哥德尔论文标题中“及有关系统”这几个字蕴含丰富内涵。简言之，哥德尔表明：无论何种公理系统，可证性始终弱于真理性。

——侯世达 Douglas R. Hofstadter

哥德尔不完备定理有几种等价表述：

> 1.任何自洽的数学形式系统都包含不可判定命题。

> 2.没有数学形式系统既是自洽的又是完备的。

> 3.没有定理证明机器或机器程序能够证明数学中所有的真命题。

> 4.数学在算法上是机械上不可穷尽的。
