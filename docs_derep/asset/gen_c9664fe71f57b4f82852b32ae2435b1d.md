PEST 分析是企业战略规划与市场研究中常用的宏观环境评估工具，由 Johnson·G 与 Scholes·K 于 1999 年提出，涵盖政治、经济、社会、技术四个维度。通过对这四个维度进行深入拆解，企业能更清晰把握外部环境，据此制定相应战略。

1. 政治层面：涉及政府政策、政治稳定、财政与产业政策、投资与税收规定、贸易限制等，对运营与盈利产生直接影响。
2. 经济层面：包括经济增速、汇率、通胀、失业率、消费结构、利率等，影响成本与消费者的购买力。
3. 社会层面：关注人口结构、生活方式、文化价值观、教育水平、地域分布等，影响市场需求与运营方式。
4. 技术层面：涵盖新技术、新工艺、新材料、商品化速度、供应链水平等，技术进步会重塑需求并带来机会或威胁。

PEST 有助于企业识别外部变化并做出适应，是制定有效战略的重要手段。常见的呈现方式以四象限图直观展示。
