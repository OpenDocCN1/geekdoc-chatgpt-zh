# 学习区才是进步的唯一入口

花样滑冰的案例说得很直白。训练时长相同，普通选手偏爱重复熟练的套路，顶尖选手却把时间耗在各种高难度动作上。业余打高尔夫图的是放松，职业选手则刻意挑最难受的站位去练最难打的球。练习的价值不在于数量堆砌，而在于反复啃自己啃不动的部分。

小孩一旦在同龄人中显得游刃有余，最容易就此停在原地。误以为现在的水准已足够，就不肯再承受不适继续往前，结果常常被后来者反超。

心理学家把技能发展划成三层同心环。最核心的是舒适区，已然熟练的本领；最外围是恐慌区，暂时根本达不到的范围；夹在中间的是学习区，只有在那里反复打磨，才能真正向上走。想要持续精进，就要逼自己不断离开舒适区，在接近极限的位置迎接挑战，再把新挑战内化成新的舒适区，如此循环。

# 别把聪明当标签，培养刻意精进

很多家长会把孩子在某项技能上的初步掌握误认成天赋。根源是急于求成，想要用聪明二字证明孩子优秀。其实技能成长并非直线。起初的快速提升多靠本能模仿，和真正吃透技能相差甚远。过早贴上聪明标签，会让孩子误以为所有东西都该轻松学会。

一旦被聪明观念裹挟的孩子撞上瓶颈，挫败感往往比困难本身更致命。害怕丢掉形象，他可能选择放弃；家长若顺势安慰说换个方向，就会固化遇挫即退的习惯。最后看似涉猎广泛，实则没有一项扎实，也丧失了熬过难关的能力。

真正的智慧在于清醒地看见不足，并持续努力突破局限。教育该培养的不是速度感，而是面对困难的韧性。要让孩子明白，短暂的吃力是成长的信号，不是失败的印记。只有经得起枯燥打磨，用刻意练习冲破瓶颈，才算真正的成长。

芭芭拉·奥克利的故事具有代表性。她曾在美军服役，后转入理工科读大学，很快跟不上进度。26岁时，她不得不和一群比自己小的学弟学妹一起补高一数学。摸索出合适的方法后，数学水平迅速提升，随后拿到电气工程学士、电子与计算机工程硕士以及系统工程博士学位，如今是奥克兰大学的工程学教授，还著有《学习之道》。

她把学俄语的方法迁移到数学上，不仅追求理解，更追求运用自如。比如学到牛顿力学 F=ma，她会像背新单词一样在各种情境下反复演练：若 F 很大、m 很小，对 a 会意味着什么？经无数次实战后，她能自如调用，也就真正理解了。这一思路对中国学生同样适用。

# 让刻意练习进入具体学科

刻意练习既能提升台球、网球等爱好，也能用在各科学习上。下面以数学、作文、英语为例说明。

数学像组装精密仪器，每个零件都要精修。题海往往低效，结构化拆解才是关键。可以把数学能力拆成概念理解、公式推导、解题思路、计算准确度四个模块，先定位薄弱点再针对训练。

函数题总错时，可以细分：图像是否偏移、定义域判断是否模糊、复合函数嵌套时逻辑是否断裂。有位同学在三角函数换元上屡败，后来集中做30道同类题，才形成条件反射。

选题要像选登山路线。既不能守在平缓的熟悉区，也不要一下子冲向垂直峭壁。从错题本挑踮脚刚好够到的题目：似有思路却总在某个环节卡住。比如一道需三种解法验证的几何题，先用熟悉的代数法尝试，再强制用向量坐标或空间投影重新拆解。

反馈常被忽略。养成习惯：每道题结束后用5分钟自检，步骤是否跳步、题干的隐含条件是否遗漏。

作文不能只靠灵感。朱自清《背影》中买橘子的场景就是精心设计的情感爆破点：青布棉袍的质感、月台的间距、橘子滚落的速度，每个细节都在蓄力。刻意模仿大家技法，如同书法临帖。

模块化训练很有效。比如每天早晨15分钟专门练开头：引用泰戈尔诗句的文艺式、用惊人数据制造悬念式、用对话场景营造沉浸式……

英语的刻意练习同样重要。俞敏洪创业初期只是一名北大的普通英语老师。他在休学一年里把词汇量堆到两万，后续深耕，成了当时北京GRE培训的第一名，借此站稳出国培训市场。

高考、考研都对词汇量有门槛。短板时没有捷径，需要像俞老师那样主动离开舒适区进入学习区。量变到一定程度会引发质变，英语水平自然跃升。

刻意练习的通用原则有三点。第一，时间管理，关闭干扰，每天安排1到2小时高度专注的练习，胜过低效刷题。第二，记录进步，用学习日志记下今天掌握了三角函数换元法等微小突破，保持动力。第三，心理韧性，把初期缓慢的进步视为常态，把错误当作改进信号。

如此，学习会从被动接受转向主动塑造，数理思维与语言能力都会显著提升。核心始终是：少而精的练习、持续迭代的反馈、主动突破舒适区。

# 智能浪潮中，持续学习是基本功

大模型和智能机器人的发展，对现有岗位构成前所未有的替代压力。这种迭代速度远超以往，引发了对孩子所学专业未来价值的焦虑。

历史上已有先例。自工业革命以来，手抄、珠算、传统耕作、马车驾驶等一度必需的技艺，都因更高效机器而淡出。每一次替代看似威胁就业，实则推动劳动力迁移。

创造就业的根本在于人类需求的无限性。机器接管基础生产后，被解放的人力并未大规模失业，而是流向因生产力释放而兴起的新领域：普及教育、全民医疗、专业服务、影视娱乐、信息技术等。

智能系统的应用会遵循同样的规律。替代现有工作本身就是挖掘和满足更深层、更精细化需求的过程。即便未来智能系统能执行已知的所有工作，人类开拓新价值维度也不可能枯竭。

空间价值将被开发：无人驾驶普及后，车内空间将用于工作、学习、娱乐，衍生新产业。虚拟世界将被构建：元宇宙里人们工作、交易、玩乐。人类会在新领域重新定义重要事务，创造新的价值体系与经济模式，今天的谷子经济就是预演。

工业革命证明，机器替代人力不可避免，但人类凭借创新和需求开拓始终能开辟方向，这是不会被智能系统彻底取代的根基。

总之，孩子未来要从事的许多工作现在并不存在。真正该担心的是他能否快速达到新岗位要求。应对未来的最好教育，是不让高压毁掉孩子的蓬勃生机，培养探索、实践、复盘、刻意练习的习惯，保持终身学习，持续迭代精进。

# 从记忆思维到实践思维

本书前言中提道，卡尔·纽波特认为，利用人工智能把工作做得漂亮并有创造性的人将获得时代红利。这类人可以被称作智能创造家，他们的创造力来自对人工智能的常年实践应用。

提升迭代智能能力，用得多是关键。教师、家长和中小学生不要想着先去阅读人工智能相关的课本和专业书，这样太慢了，要学习人工智能，最重要的就是用起来，先把市面上受欢迎的智能工具用熟、用透，行有余力再去了解人工智能的基础理论。

中国大力倡导实践教育的现代教育家是陶行知先生。陶先生被毛主席称为伟大的人民教育家。郭沫若曾赞道：二千年前孔仲尼，二千年后陶行知。

陶行知先生的实践教育理论，有哲学依据，同时也有自身实践的支撑。

## 陶行知实践教育的哲学源头

卡尔·纽波特强调的利用人工智能把工作做得漂亮并有创造性的人，不能靠传统教育模式培养。传统的教育强调课堂教学，忽视实践训练，但实践恰恰是创造力的源泉，忽视实践训练，就会使创造力缺乏源头活水。陶行知先生对此做过深入的研究。

明代思想家重新定义了格物致知：把格物的格定义为格斗的格。格斗就是正面、近距离地发生冲突，通过近距离接触、互动、冲突、博弈，获知对象的真实状况。所以，格物致知里的格物就是与物格斗、与物博弈、与物互动。他们认为，只有通过这种格物，才能够得到真正的认知。

陶行知原名陶文濬，大学期间他推崇明代哲学家王阳明的知行合一，认为其提出的知是行之始，行是知之成观念，是改革中国传统教育的一剂良方。为了表示对知行合一的信奉，他遂改名为陶知行。

王阳明有个著名的观点：人必须到事上磨炼，只有做事才能证明你是不是真的晓得了，未有知而不行者，知而不行，只是未知。

王阳明强调知行合一，不行就是不知。比如，嘴上说孝，却不去躬行实践的人，并不是真的知孝。就如称某人知孝、某人知弟，必是其人已曾行孝、行弟，方可称他知孝、知弟，不成只是晓得说些孝弟的话，便可称为知孝弟。又如知痛，必已自痛了方知痛；知寒，必已自寒了；知饥，必已自饥了。知行如何分得开？此便是知行的本体，不曾有私意隔断的。

43岁时，陶行知在生活教育上发文行知行，提出与王阳明先生不同的观点，行是知之始，知是行之成，突出了实践的意义和作用，推崇先行而后知。他从陶知行改名为陶行知，并将这一理念贯穿到当时他在晓庄学校、山海工学团的教育工作中，取得了明显的效果。

陶行知1927年在晓庄学校寅会上发表演讲行是知之始：

我们先从小孩子说起，他起初必定是烫了手才知道火是热的，冰了手才知道雪是冷的，吃过糖才知道糖是甜的，碰过石头才知道石头是硬的。太阳地里晒过几回，厨房里烧饭时去过几回，夏天的生活尝过几回，才知道抽象的热。雪菩萨做过几次，霜风吹过几次，冰激凌吃过几杯，才知道抽象的冷。白糖、红糖、芝麻糖、甘蔗、甘草吃过几回，才知道抽象的甜。碰着铁，碰着铜，碰着木头，经过好几回，才知道抽象的硬。才烫了手又冰了脸，那么，冷与热更能知道明白了。尝过甘草接着吃了黄连，那么，甜与苦更能知道明白了。碰着石头之后就去拍棉花球，那么，硬与软更能知道明白了。凡此种种，我们都看得清楚行是知之始，知是行之成。

富兰克林放了风筝才知道电气可以由一根线从天空引到地下。瓦特烧水，看见蒸汽推动壶盖便知道蒸汽也能推动机器。加利里翁伽利略在比萨斜塔上将轻重不同的球落下，便知道不同轻重之球是同时落地的。在这些科学发明上，我们又可以看得出行是知之始，知是行之成。

陶行知强调，我们拿行是知之始来说明知识之来源，并不是否认闻知和说知，乃是承认亲知为一切知识之根本。闻知与说知必须安根于亲知，方能发生效力。

再之后，陶行知又认识到，从行到知只是认识的第一阶段，再由知到行又是认识的更高阶段，于是写了一首小诗：行动是老子，知识是儿子，创造是孙子。这就是他的行知行理论。行知行不断循环往复，以至无穷。

## 教育学大师谈实践教育

根据这一认知哲学，陶行知认为，中国教育之通病是教用脑的人不用手，不教用手的人用脑，所以一无所能。中国教育革命的对策是手脑联盟，结果是手与脑的力量都可以大到不可思议。手和脑在一块儿干，是创造教育的开始；手脑双全，是创造教育的目的。

手脑联盟相比于锻炼分析能力的思辨教育，以及开发记忆力的知识教育，突出了动手的重度，可以说，创造教育的方法论是开展实践教育。

关于实践教育，陶行知曾提出不少著名的观点：

我们要活的书，不要死的书；要真的书，不要假的书；要动的书，不要静的书；要用的书，不要读的书。总起来说，我们要以生活为中心的教学做指导，不要以文字为中心的教科书。

教学做是一件事，不是三件事。我们要在做上教，在做上学。不在做上用功夫，教固不成为教，学也不成为学。

要学生做的事，教职员躬亲共做；要学生学的知识，教职员躬亲共学；要学生守的规则，教职员躬亲共守。

陶行知不是独行者，近现代有一批西方思想家抨击灌输式的知识教育，强调实践在教育中的重要性。

卢梭非常反对灌输式教育，主张鼓励儿童自己去获得知识，因为自己获得的观念比别人传授的观念更加清晰而深刻。卢梭向教师建议：教授儿童各种各类的科学，并不是你的职责；你的职责应是使他对于科学感到有趣味，以及当这些趣味较为成熟时，给他们学习科学的方法。做中学，玩中学，这样的实践教育自然是让孩子对科学产生兴趣的好办法。

19世纪英国教育家斯宾塞对灌输式教育进行了深刻的批判：我们对幼年儿童，常凭口授形式，灌输某种观念；教师惯用此法，且认为熟记了这些口授的教材，就已经掌握了其所包含的观念。但是一经简单的考查，即可以发现其结果相反。这种教法的结果，或者徒记其口语，未尝丝毫了解其意义；或者略似了解，其实是模糊不清的。

马克思主义哲学认为内因是变化的根据，灌输式教育正是强调了外因，而忽略了受教育者本身内因的作用。

美国教育家约翰·杜威阐述过为什么受教育者的内因是关键：思想、观念不可能以观念的形式从一个人传给另一个人。当一个人把观念告诉别人时，对听到的人来说，它就不再是观念，而是另一个已知的事实。这种思想的交流也许能刺激别人，使他认清问题所在，提出一个类似的观念；也可能使听到的人扼杀理智的兴趣，压制他开始思考的努力。只有当他亲身考虑问题的种种条件，寻求解决问题的方法时，他才算真正在思考……如果他不能自己筹划解决问题的方法，自己寻找出路，他就学不到什么；即使他能背出一些正确的答案，百分之百正确，他还是学不到什么。

根据上述教育理论，相比于灌输知识的传统教育，实践教育显然更能激发学习的内在动力，提升学习的实际效果，这是开展智能教育的一大要点。

## 越忙越要先用智能
