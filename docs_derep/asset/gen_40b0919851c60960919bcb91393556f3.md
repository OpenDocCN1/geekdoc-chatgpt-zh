# AI合规与知识产权实务指南

# 推荐序一
人工智能已上升为推动科技跨越、产业升级和生产力整体跃升的关键力量，习近平总书记对充分发挥新一代人工智能的驱动作用作出明确要求。技术创新在不断突破既有法律边界，法律既要跟进规范、引导和优化技术发展，也会被技术进步所重塑，进而改变生活方式和法治形态。2017年10月26日沙特授予汉森机器人公司生产的索菲亚机器人公民身份，便引发了对法律主体界限的深度讨论。

作为通用技术，人工智能正在经济社会各领域广泛渗透，也带来了根本性追问：人工智能的创新创造是否需要知识产权激励？人与机器创造的价值如何衡量取舍？现行知识产权框架是否需要因人工智能而重构？这些正是当前制度的核心议题。

2017年起清华大学法学院相继举办法律科技与人文论坛、智律论坛、大数据论坛、互联网治理全球论坛等系列活动，2018年率先设立计算法学并连续五年举办计算法学国际论坛，正是对大数据、区块链、云计算、人工智能等新兴议题的积极法律回应。

世界知识产权组织前总干事弗朗西斯·高锐在访谈中指出，知识产权制度的核心目标是促进新技术和创造性工作，为创新提供可持续的经济基础。人工智能的普及势必改写专利、外观设计、文学艺术作品等传统知识产权概念的外延。

近年来中国知识产权事业发展备受关注，理论与实践的互动尤为关键。学术界通过对实务争议的理论阐释提供解释，实务界则以前沿研究指导操作。一线知识产权律师的专业水准在很大程度上体现了行业水平，他们既要精研相关法律法规，也要准确理解技术本身。

中伦律师事务所合伙人王红燕邀请我为其著作《中国人工智能合规建设与知识产权法律实务》作序。该书聚焦近年来人工智能领域知识产权及关联法律的热点与实务操作，既有办案经验的提炼，也有典型案例下对法规的深入解读，呈现出律师对法律与实践的思考与钻研，体现了专业精神与职业素养，是理论联系实际的佳作，有助于提升从业人员业务能力。

党的十八大以来党中央高度重视企业合规，在人工智能行业健康快速发展与合规并重的问题上，企业主、法务与合规负责人关注度持续提升。本书从知识产权合规管理视角，就专利、商标、著作权等各类知识产权的申请取得维护、商业秘密、个人信息与数据安全保护、算法与科技伦理合规、科技创新成果许可转让、侵权防范应对等方面，提供了务实的合规建议。

作为以办案为主的律师，能在繁忙工作中对实践难点热点进行研究并总结分享，实属难得，祝此书出版。

# 上编 人工智能与合规建设

## 第一章 人工智能领域合规建设与出口管制

### 第一节 人工智能企业的数据合规挑战
人工智能是指利用计算机模拟人类思维与智能行为的科学，涵盖学习、推理、思考、规划等，并衍生出机器视觉、指纹与人脸识别、专家系统、自动规划、智能搜索、定理证明、博弈、自动程序设计、智能控制、机器人、语言与图像理解、遗传编程等功能，对生活产生广泛影响。

人工智能发展的基础之一是数据供给。要实现上述功能，必须在大规模数据上学习并优化。因此企业会从个人用户、合作方等渠道获取信息并进行分类融合与商业化，在此过程中出现多类合规风险。

一、人工智能技术与数据保护的冲突
企业获取的数据主要分为个人信息与运营数据、消费者行为数据等。采集渠道大致分为自行采集、数据交易共享、公开网络数据抓取三种，各自面临不同风险。

其一，通过产品设备、网站、App注册使用收集的个人数据与使用数据，用于优化体验与技术迭代，后续会回流至研发，价值较高。权属通常以隐私协议获得授权，后续需关注使用是否与协议一致，是否严格遵循最小必要原则。

其二，从第三方合作伙伴共享的数据多为已清洗整合的数据资产，双方签署协议共同或委托处理。此时需重点尽调数据来源清洁性与合作方合规能力，协议中权利责任分配是合规要点。

其三，技术抓取的数据量大来源广，除授权问题外，还需关注抓取行为本身是否构成不正当竞争。

二、数据融合带来的挑战与应对
企业对多方数据进行处理融合，可能发生在集团内部或与外部合作方之间。

内部融合风险相对可控，但实务中常有误区认为集团内部主体可自由使用数据。即使为管理或效率优化且非商用，不同子公司间也需签署授权与数据传输协议，在个人信息保护法强制场景下还需开展个人信息安全影响评估。

外部融合合规风险更高，核心在于文本处理与内控制度的可控性。监管部门对违法行为倾向于推定过错，企业作为处理方与责任方必须保证处理链路合规且完整留痕，需以合同、制度、评估与审计报告等形式固化证据，必要时采用数据分类分级、隐私影响评价、数据审计等工具。

从下游应用视角看，数据应用链条越长风险越大。应依据合作方角色如共同处理、委托处理、转让、共享等判断权限，对要求合规的合作方进行有效监督。

三、个人信息保护合规工具运用
前述提及的数据分类分级、隐私影响评价、数据审计是通行做法。对数据存量大形成核心资产的人工智能企业而言，产品上线、迭代、委托处理或提供等情形下，仅靠协议约定效力有限，需进行实质评估与后续监督。委托处理必须开展隐私影响评价并配套复核验证，确保受托方在权限内处理并具备足够安全能力。

根据《信息安全技术 个人信息安全影响评估指南》GB/T 39335—2020，新产品或服务设计、上线、法律法规变更、业务模式变更、发生重大个人信息保护事件后均需开展评估，重点产品还需年度评估。隐私影响评价并非一次性工作，需定期复核，在合作方发生数据安全事件时，评估报告是重要合规证明。

数据安全审计亦可定期开展。多数企业已委托外部机构修订合同、起草制度，但落地才是关键。需对文本与合同使用效果、制度执行情况、网络安全有效性进行回溯检查，确保措施真正落实。

总体来看，相较于传统行业，人工智能企业的数据更新更快、类型更多，需高度重视合规工作的时效性，确保制度与主营业务发展有效衔接，避免沦为空文。

### 第二节 人工智能企业的开源合规风险及管理建议
1956年计算机专家约翰·麦卡锡提出“人工智能”一词，被视为该领域诞生标志。此后数十年，机器人、语言识别、图像识别、自然语言处理等技术迅速进步，人工智能时代加速到来。

2022年6月第六届世界智能大会发布《中国新一代人工智能科技产业发展报告2022》，显示人工智能技术赋能19个应用领域。2021年排名前六的是企业智能管理、智慧城市、智能营销与新零售、智能制造、智能网联汽车、智能金融。自2017年以来，智能营销与新零售、智能制造、智能网联汽车、智能教育、智慧文旅与智能农业的技术合作关系增长较快。

技术发展同时带来社会问题，如部分工种消失、失业率上升、机器操控不透明等。2021年4月21日，欧盟委员会通过《人工智能法》提案，旨在建立统一规则。按欧盟定义，人工智能指采用列明技术方法开发的软件，能针对特定人群或目标产生影响交互环境的内容、预测、建议或决定。提案将风险分为不可接受、高风险、有限风险和极小风险，通过监督推动良性发展。

开源技术近年蓬勃发展，对各行业渗透加深。2005年谷歌收购安卓公司掌控开源终端操作系统Android，占据手机产业主导；2010年甲骨文收购开源数据库MySQL增强数据库领先地位；2018年IBM收购红帽增强服务器市场竞争力。长期抵制开源的英伟达近期也宣布以GPL/MIT双许可开源R515版Linux GPU内核模块，被视为更广泛开源计划的开端。上述巨头态度转变表明开源创新与协同能有力推动产业进程。开源技术在人工智能产业中的应用也将产生积极影响。
