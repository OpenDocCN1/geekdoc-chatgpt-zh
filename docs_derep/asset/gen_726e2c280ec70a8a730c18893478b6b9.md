说明
为什么选择 Parquet 来保存图谱？

1) 存储更高效
知识图谱数据高度结构化，实体、关系、向量等体量庞大。Parquet 的列式存储能大幅压缩磁盘占用，同时提升读写效率。
2) 读取更快
查询时需要把实体、关系、向量快速载入内存。Parquet 支持按列按需加载，只取用到的字段，避免全表扫描。
3) 生态兼容性强
Parquet 是开放标准，被 Pandas、Spark、Hadoop 等工具广泛支持。GraphRAG 在 Python 中可直接用 Pandas 读取这些文件。

模块作用如下。
1）索引器相关
索引数据加载器 read_indexer_*：从构建阶段生成的 .parquet 文件中读取实体、关系、社区报告、文本单元等。
实体语义嵌入处理器 store_entity_semantic_embeddings：将实体描述向量化并写入向量库。
2）LLM 相关
语言模型调用接口 ChatOpenAI、OpenAIEmbedding：完成问答交互与嵌入生成。
3）本地搜索相关
本地搜索模块 LocalSearch、LocalSearchMixedContext：基于图邻接结构与实体嵌入进行本地化问答。
4）向量存储相关
向量数据库接口 LanceDBVectorStore：管理语义向量的持久化与高效检索。
