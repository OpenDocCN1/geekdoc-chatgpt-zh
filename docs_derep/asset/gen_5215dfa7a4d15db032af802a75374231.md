## 1.3 DeepSeek 全景解读

DeepSeek 由杭州深度求索人工智能基础技术研究有限公司打造，公司成立于 2023 年 7 月，隶属于幻方量化，目标是通过高性能低成本的开源大模型技术推动 AI 在多领域的普及。2025 年初团队在 DeepSeek 大模型基础上推出同名推理型 AI 聊天机器人，上线后两周内全平台用户突破 1 亿，迅速登顶 140 多个国家苹果 App Store 与 Android 应用市场榜首。本书提及 DeepSeek 若无特别说明，均指 DeepSeek 大模型系列，其长期目标指向通用人工智能。

### 1.3.1 DeepSeek 的核心特点

DeepSeek 大模型具备四方面突出特质。

（1） 性能表现优异：DeepSeek-R1 在多项基准测试中与 OpenAI o1 旗鼓相当，且在中文理解与生成任务上更具优势。
（2） 成本优势明显：训练与推理成本相比同类方案大幅下降，企业应用门槛被显著拉低。
（3） 开源生态繁荣：模型架构与训练细节完全公开，吸引全球开发者参与打磨，形成活跃的技术社区。
（4） 应用场景广泛：覆盖教育、政务、医疗、电子工程等领域，可辅助教师备课、生成文旅宣传文案、解析电路图纸等。

具有代表性的两款模型为：

（1） DeepSeek-V3：支持 128K 即 128000 token 的超长上下文窗口，擅长多轮交互与复杂推理。
（2） DeepSeek-R1：基于强化学习的推理型模型，专攻代码生成与数学问题求解，并支持实时知识更新。

### 1.3.2 DeepSeek 的模型架构创新与训练优化策略

技术路线以效率与精准为核心，融合了多项架构创新与训练优化手段。

模型架构创新主要有三点。

（1） 混合专家 MoE 模型：采用稀疏激活的 MoE 架构，每个词元仅唤醒 8 个专家，计算开销大幅减少。
（2） 多头潜在注意力 MLA：借助低秩压缩技术降低键值缓存内存占用，提升长文本处理效率。
（3） 多词元预测 MTP：同时预测多个未来词元，增强生成连贯性并加快推理速度。

训练过程融合预训练、监督微调 SFT、强化学习与模型蒸馏，通过分阶段多轮迭代，最终形成兼具强大推理能力且与人类偏好高度对齐的开源对话模型。

训练优化策略包括四种。

（1） 混合并行策略：结合数据并行与模型并行，采用梯度压缩、异步通信及计算与通信重叠，降低节点间延迟，提升 GPU 利用率。
（2） 双向管道并行策略：优化数据传输与计算流程，实现前向与后向计算通信完全重叠，减少流水线空闲。
（3） 专家并行与负载均衡策略：智能分配计算任务，通过动态调整路由偏置或复制高负载专家，避免过载，提升资源利用。
（4） FP8 混合精度训练策略：使用 8 位量化降低存储与通信成本，大幅提高训练效率。

### 1.3.3 DeepSeek 的调用方式

根据需求可选择两种调用路径。

（1） 云端调用：通过官方或第三方如阿里云、火山引擎的 API 快速接入，适合轻量化场景。
（2） 本地部署调用：可下载满血版 671B 或蒸馏版如 7B，需配置高性能 GPU 服务器，适用于数据敏感场景。

1.5B 模型：显存大于等于 8 GB，如 NVIDIA RTX 3060。

### 1.3.4 DeepSeek 的生态

DeepSeek 在 Hugging Face、GitHub 累计被 140 多个国家开发者下载，注册量破亿。以“极致开源加极致成本”把大模型从烧钱重工业变为像水电煤一样可用的基础设施，并通过端云协同与行业深耕重塑国产乃至全球大模型格局。

核心模型永久免费，未来可通过企业级技术支持、订阅服务、行业定制方案实现商业闭环。目前在政务、金融、医疗、教育、交通等行业通过概念验证 POC 持续落地，让中小企业无需自建算力即可调用百亿参数模型。

生态可概括为开源内核加低成本杠杆加端云协同。

（1） 开源内核。模型、代码、训练方法全部开放。
主模型：DeepSeek-R1 对标 OpenAI o1，DeepSeek-V3 位于开源模型榜首，已开放权重与训练脚本，采用宽松 MIT 协议允许免费商用与二次开发。
专业分支：DeepSeek-Prover-V2-671B 数学定理证明、DeepSeek-Coder 代码生成等场景化模型持续开源。
蒸馏小模型：6 个尺寸 1.5B 至 70B 全部放出，API 定价约为 OpenAI 的 3%，大幅降低接入门槛。

（2） 低成本杠杆。架构创新极大降低训练成本，已适配华为昇腾、沐曦、天数智芯、摩尔线程、壁仞等国产 GPU，实现用得起跑得动，训练与推理成本处于行业低位。

（3） 端云协同。支持端侧部署与云侧服务。
端侧部署：通过模型压缩与量化，将 7B 至 30B 轻量模型部署到 PC、手机、车载设备、智能家居，实现本地推理与低延迟，保护隐私。
云侧服务：多家国产云平台已上架全系列模型，提供一键调用、弹性扩缩容及私有化落地方案。

凭借创新架构、低成本优势与开源生态，DeepSeek 正加速 AI 普惠。未来随多模态支持与因果推理能力突破，或将成为 AGI 发展的重要里程碑。
