### 9.1.2 层次聚类算法的实现与潜在类别发现
层次聚类以分层树的形式组织样本，按相似度逐步合并或拆分，最终形成聚类树。常见做法是自下而上的凝聚与自上而下的分裂。下面以 Python 的 scipy 与 sklearn 为例，先对语料做向量化，再执行层次聚类并做可视化。

本例采用凝聚策略，借助欧氏距离衡量嵌入向量间的远近。

[PRE1]
代码说明如下：

- （1）TfidfVectorizer：把原始文本映射为 TF-IDF 权重，降低常见词的干扰。
- （2）cosine_distances：利用余弦距离度量向量间的夹角，更适配文本相似性判断。
- （3）linkage：调用 scipy 的层次聚类接口，此处选用 ward 准则构建嵌套树状结构。
- （4）dendrogram：绘制层级树图，直观呈现文本合并的顺序与层级。

运行结果见图9-1，生成了层次树状图，反映了语料的层级分组。每一次合并代表两组间的相似度，合并高度越高距离越大。分支形态揭示了潜在主题关联，越靠下的合并说明文本越相近。
