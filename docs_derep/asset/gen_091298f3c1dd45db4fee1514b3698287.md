**【程序详解】**

1. 整体功能
程序用于统计并输出不超过给定整数的素数个数与素数之和。

2. 程序段一解析
03 bool isPrime(int n){
04 if(n<=1){
05 return false;
06 }
07 for(int i=2;i*i<=n;i++){
08 if(n%i==0){
09 return false;
10 }
11 }
12 return true;
13 }
功能：判定 n 是否为素数。
要点：
（1）n<=1 时直接判为非素数。
（2）试除法仅遍历到 sqrt(n)。
（3）发现因子立即返回 false。

3. 程序段二解析
15 int countPrimes(int n){
16 int count=0;
17 for(int i=2;i<=n;i++){
18 if(isPrime(i)){
19 count++;
20 }
21 }
22 return count;
23 }
功能：统计 ≤n 的素数个数。
要点：
遍历 [2,n]，调用 isPrime 判断，命中则计数。

4. 程序段三解析
25 int sumPrimes(int n){
26 int sum=0;
27 for(int i=2;i<=n;i++){
28 if(isPrime(i)){
29 sum+=i;
30 }
31 }
32 }
功能：求 ≤n 的素数和。
要点：
遍历区间累加素数，注意函数未写 return sum，会导致警告。

5. 程序段四解析
34 int main(){
36 int x;
37 cin>>x;
38 cout<<countPrimes(x)<<" "<<sumPrimes(x)<<endl;
39 return 0;
40 }
功能：读取上限 x，调用两个统计函数并输出。
要点：输出顺序为个数后接和。

**判断题**

16. 输入为“10”时，程序第一个输出为“4”，第二个输出为“17”。（ ）
**【讲解】**
x=10 时素数为 2,3,5,7，共 4 个，和为 17。输出为 4 17，命题成立。
**【参考答案】**
正确（√）

17. 若把 isPrime 中的条件改为 i<=n/2，输入“20”时 countPrimes(20) 的输出会变成“6”。（ ）
**【讲解】**
改成 i<=n/2 只影响效率，不改变正确性。≤20 的素数仍为 2,3,5,7,11,13,17,19，共 8 个，不会变成 6。
**【参考答案】**
错误（×）

18. sumPrimes 计算的是从 2 到 n 之间的所有素数之和。（ ）
**【讲解】**
函数确实遍历 2~n 并累加素数，描述准确。
**【参考答案】**
正确（√）

20. 若把 for(int i=2;i*i<=n;i++) 改为 for(int i=2;i<=n;i++)，输入“10”时程序输出为（ ）
A. 将不能正确计算 10 以内的素数个数及其和

**【考点识别】**

入门级|C++程序设计|【2.7】数组与数组下标、【2.9】函数定义与调用、【2.3】程序基本语句

入门级|算法|【4.8】动态规划：动态规划的基本思路

**【程序详解】**

1. 整体功能
通过动态规划求从起点到终点的最小花费路径和，每次只能走一步或两步。

2. 程序段一解析
04 int compute(vector<int> &cost){
05 int n = cost.size();
06 vector<int> dp(n+1, 0);
07 dp[1] = cost[0];
08 for(int i = 2; i <= n; i++){
09 dp[i] = min(dp[i-1], dp[i-2]) + cost[i-1];
10 }
11 return min(dp[n], dp[n-1]);
12 }
核心为 DP。
状态：dp[i] 为到达第 i 个台阶的最小花费。
递推：dp[i]=min(dp[i-1],dp[i-2])+cost[i-1]。
边界：dp[1]=cost[0]，dp[0]=0。

3. 程序段二解析
13 int main() {
15 int n;
16 cin >> n;
17 vector<int> cost(n);
18 for (int i = 0; i < n; i++){
19 cin >> cost[i];
20 }
21 cout << compute(cost) << endl;
22 return 0;
23 }
功能：读入台阶数与花费，调用 compute 输出结果。

**判断题**

21. 当 cost 数组为{10, 15, 20}时，程序输出为 15。（ ）
**【讲解】**
dp[1]=10，dp[2]=min(10,0)+15=15，dp[3]=min(15,10)+20=30，最终返回 min(30,15)=15。正确。
**【参考答案】**
正确（√）

22. 如果把 dp[i-1] 改为 dp[i-3]，程序可能会产生编译错误。（ ）
**【讲解】**
改写后当 i<3 时会越界，属于运行时错误，编译器无法捕获，不会编译失败。
**【参考答案】**
错误（×）

23. 程序总是输出 cost 数组中的最小元素。（ ）
**【讲解】**
程序求的是最小路径和，而非单元素最小值。说法错误。
