# 2.3 表格在架构中的作用
在架构设计中，表格被广泛使用，其作用主要体现在以下三点。

(1) 组织结构清晰：表格能把模块、职责和技术选型以清晰的结构呈现，让人一目了然地了解各模块职责和所用技术。

(3) 信息完整性：表格可提供更详尽的信息，包括模块名称、职责和所用技术，有助于保证设计方案完整，让人清楚系统各模块的功能与依赖关系。
