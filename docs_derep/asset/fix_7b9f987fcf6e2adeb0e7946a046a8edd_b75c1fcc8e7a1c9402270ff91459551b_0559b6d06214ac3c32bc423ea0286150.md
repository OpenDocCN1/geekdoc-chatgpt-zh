####### 十分钟剪映实操课

- **素材准备分门别类**
1. 自拍素材。按场景和情绪归档，例如“通勤焦虑”“居家放松”，调用时更快。
2. 模型生成素材。让DeepSeek配合AI绘画出图，比如指令“画一个程序员深夜加班的卡通背景”。
3. 剪映内置素材。平台自带大量特效和贴纸，免费可用。

- **新手四步剪辑法**
1. 存模板。第一条成片后保存为模板，后面直接套用改内容。
2. 替换素材。右键原图或原视频选替换文件，字幕特效会保留。
3. 加字幕。点智能字幕自动识别语音，挑一个在抖音上流行的字体。
4. 画面优化。打开自动美化功能，系统会提亮画面并增强色彩。

- **提升完播的小技巧**
1. 进度条贴纸。放一个缓慢填满的进度条，观众更容易看完。
2. 互动引导。片尾加上点赞关注转发的动态图标。
3. 转折音效。剧情反转时加乌鸦叫或刹车声等搞笑音效，氛围更足。

####### 多平台投放要点
