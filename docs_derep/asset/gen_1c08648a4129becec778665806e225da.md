# 约瑟夫·E·奥恩：人工智能时代的教育突围

# 开篇

过去，人工智能被视作低技能工人的威胁，如今各行各业都在争相借助人工智能提升竞争力。职业的消失潮正在到来，教育该怎样让学生为此后的职业生涯做好准备？

本书提出面向新一代大学生的培养思路：去发明、去创造、去发现连人工智能都无法满足的社会需求。作者主张以终身学习的方式帮助学生适应未来的变动。

# 主体论述

数千年前，农业革命让祖先拿起镰刀和犁；数百年前，工业革命把农民从田间赶进工厂；几十年前，科技革命让人离开车间进入办公室隔间。

今天我们正处在又一次革命之中，这次革命动摇了长期以来的确定性。驱动力来自新技术，但引擎已不再是培育的种子、轧棉机或蒸汽机，而是数字和机器。

我们活在科技奇迹的年代。计算机处理速度持续飙升，性能翻倍再翻倍。机器学习，也就是机器从数据而非显式编程中学习的能力，正推动人工智能发展。正如布莱恩·约弗森与安德鲁·麦卡菲在《第二次机器革命》中所说，计算机已进入改变世界的“全速”阶段，犹如瓦特蒸汽机改变牛车经济一样。劳工问题专家忧虑，计算机对人类能力的掌握程度已高到未来可能不再需要人力。

转折的迹象无处不在。无人驾驶汽车已在匹兹堡等城市街头行驶；新型机器人能轻松爬楼开门；顶尖机器人能在围棋对局中击败人类大师。与处理能力同步增长的还有连接器、传感器、GPS与陀螺仪。如今我们赋予计算机的不仅是人工智能，更是人造的眼、耳、手、脚。

于是计算机开始承担过去属于人类的角色。从分析股票、撰写生动的散文，到与顾客互动；半自动机器人可能很快与士兵共同作战。在中国，“协作机器人”已在多家工厂与人安全协作，支撑起制造业的神话。2015年全球工业机器人装机量同比增长12%，净增近25万台。

与此同时，大数据正在改写社会科学到商业的各个领域。组织搜集信息的能力几乎无穷无尽。算法在海量数据中挖掘，再把信息应用于新函数，实现自我学习。机器学习驱动着垃圾邮件过滤、亚马逊推荐清单、约会应用等，它告诉我们看什么、买什么、爱谁。在深度学习下，人造神经网络能识别模式，辨认图像、椅子、人脸，甚至在不读说明书的情况下学会玩视频游戏。

这些新技术也在创造令人惊叹的福祉，帮助减轻贫困、饥饿与疾病。IBM企业公民与事务副总裁斯坦·利韬督导了纽约纪念斯隆-凯特琳医院与沃森的合作。沃森正是击败“危险边缘”人类冠军的系统。医院医生提出合作构想后，沃森成为肿瘤学顾问。IBM科学家把医院全部临床资料植入沃森，训练它用数据分析回答肿瘤医生提问。

利韬形容使用过程如同与可能患病的患者对话，在移动设备上输入特征后询问是否有相关临床试验，沃森会用标准英语给出分析。临床信息庞大，很多医生无法触达，这项技术能帮助美国顶尖肿瘤医生更快更好诊断，并在癌症治疗中迅速制定方案。

沃森的下一步是改进纽约市公立学校的教学系统，建议教育者借助数据分析与沟通技术实施有效教学实践，该技术已在医院验证有效。像沃森这样的技术正在挽救生命、传递知识，也在做更琐碎的事比如找停车位。计算机正提升人们的工作效率。

至少目前如此。

自动化长期被视为低技术劳动者的威胁，现在连被称作“知识经济”的许多工作也被纳入计算机权限，包括医疗影像分析、法律研究与数据分析等高科技职能。

随着机器在投资决策、疾病诊断、自然语言交流上愈发娴熟，公众对能力边界的兴趣不断升高。这正是许多观察家认为科技扰乱经济、冲击文明潜力的原因。

近年来与应届生、雇主交流时，我反复想到：要在新经济现实中立足，高等教育必须大刀阔斧改革。21世纪大学不应培养学生从事科技浪潮终将淘汰的职业，而应把学生从过时职业模式中解放，让他们掌握自己的未来。大学要赋予学生应对技术定义新经济所需的读写与技能，并持续提供在多元全球环境中应对生活挑战的继续学习机会。高等教育需要新模式、新定位，不再只以培养本科生和研究生为目标，而应成为终身学习的引擎。

改变模式的证据比比皆是。牛津研究人员2013年指出，美国约半数工作在未来20年面临自动化风险。现实似乎来得更慢。新的机器人算法交易平台正席卷金融业，据估计未来十年可能取代三分之一至二分之一的金融岗位。麦肯锡2015年报告称，仅凭现有技术，45%的有薪工作即可自动化，每年可节省美国企业对人类员工超过2万亿美元的工资。

这并非首次。工业革命时期，受拖拉机与纺织机冲击的农民与织工经历痛苦转型，重培训后在新工厂找到岗位。信息技术浪潮时，许多人通过学习获得更高技术岗位。展望未来，教育仍是向上流动的阶梯，只是分工愈加复杂。难点在于全球劳动力供给持续增加，而高薪高效岗位净量在减少。要让更多人就业，就必须创造更多岗位，但我们并不清楚这些岗位在哪里。

当然新产业的出现必须填补空白。美国劳工部预计到2024年，计算机与信息科技就业总人数将达440万。同期16岁及以上劳动力预计达1.637亿。科技公司的卓越效率加剧问题：谷歌在2015年有61,814名全职员工，而通用汽车在1979年高峰时员工表上有60万人。要解决此问题，需要创造性方案。

除自动化外，全球化、环境不可持续、人口变化、不平等、政治动荡也在刺激经济，改变人们支配时间、赚钱养家、获得满足的方式。古老真理迅速消解，而补救手段并不明显。

“零工经济”增长给部分观察家带来鼓舞。人们通过Uber开车、TaskRabbit搬家、为Amazon Mechanical Turk录入文本等方式接活。但收入有限。自2014年起，以零工平台收入占其总收入50%以上的人数开始下降。这些平台可补充月度账单，但远不足以替代全职工作。

新兴的全职岗位多为混合型，不仅需要更多技能，还要求编程或数据分析等技术专长。50年前没人想到用户体验设计师会成为合法职业，今天它已真实存在。工作在不断变化，所有这些因素让求职者置身复杂未知领域，渴求答案：如何让人们为瞬息万变的世界做好准备？教育如何在职业与经济层面发挥作用？

作为大学校长，这对我不是小事。我领导的东北大学特别关注教育与工作的衔接。作为体验学习的先行者，以合作模式为基础，始终以培养学生胜任职场职责为使命。最近观察学生探索职业路径、聆听雇主对新员工的期待、阅读并倾听科技对全球专业工作的影响后，我愈发确信现有高等教育模式必须适应全球经济根基的剧烈震动。

我相信大学应塑造专业人士，也应培养创造者。创造力不仅是经济活动的基石，对人类未来亦然。智能机器将把数百万劳动力从重复劳动中解放，但仍有大量工作需要人类完成。治疗疾病、修复环境、消除贫困等伟大事业需要全人类智慧集中。机器可帮助探索宇宙，人类却要面对探索后的后果。人类仍会阅读人类作者的书籍，被源于人类想象的歌曲与艺术打动，仍会展现无私或勇敢的道德行为并改善世界与福祉。人类还会照顾婴儿、安慰病弱者、烹饪美食、酿造佳酿、游戏玩乐。我们能做的还有很多。

因此本书提出高等教育更新模式：培养新一代创造者，使其能借助本时代科技奇迹，在被人工智能改变的经济与社会体系中蓬勃发展；同时高等教育为已进入职场的毕业生持续提供学习成果，支持终身学习。这似乎是高等教育发展的新航道。

这并不意味着背离百年大学目标——让学生为当下与未来的积极生活做好准备。教育一直为社会需求服务。如今它必须如此，且比以往更彻底。因为高等教育是进步与改变的引领者，而改变正是这个时代的驱动力。

## 独特的人类教育

教育本身是一种奖赏，赋予精神家园，让人以富足受尊重的方式生活。对多数人而言，在先进社会与经济体系下，教育是进入白领工作的前提。没有大学学历的员工在收入阶梯上挣扎，收入很可能下行。

经济体系改变，教育也必须改变。这有先例。教育科目反映社会认为有价值的内容。18世纪殖民时期的美国大学向未来律师与神职人员传授经典、逻辑与修辞。19世纪科学与农业大学兴起，满足蒸汽与钢铁世界的工业化需求。20世纪专业学位激增，以适应公司经济下的办公室工作。

如今殖民与工业时代只剩历史书，办公室时代也将迅速褪色。我们身处数字时代，学生面对数字化未来，机器人、软件、人工智能驱动的机器正逐步吞噬大量人力工作。需要应用基本事实的常规工作需求减少，教育必须跟上。为了让毕业生具备“防机器人”能力，高等教育机构应重设课程体系。

防机器人模式的高等教育不应以塞满学生新颖事实为目标，而应重新校准思维引擎，用创造性心态与思维灵活性去发明、发现或创造对社会有价值之物。这可能是科学证明、一段嘻哈录音、新健身计划、网络滑稽视频、一种癌症疗法。无论何物，都需含有足够原创成分，避免被贴上“常规”标签，从而免受自动化威胁。不再培养劳动力，防机器人教育培养的是创造者。

机器人领域产出的是历史上最先进的机器，我们需要一个能同样作用于人类的学科。在后续章节，我将列出一个新学科框架——“人类学”，目标是培养人类独有的创造性与灵活性。它以内在力量为根基，让学生在与聪明的机器并肩工作的劳动力市场中保持竞争力。例如，今天法学院学生学习特定知识体系与法律思维，明天的人类学学生必须掌握特定内容，并实践人类独有的认知能力。

前几章将介绍人类学的结构与运行机制，首先解释其双重特质。一方面，其内容以我所称的新读写能力存在。过去读写与数学形成社会参与基础，即便受过教育的专业人士也不需技术专长，只需会点击拖拽鼠标即可。如今这些已不够。未来毕业生需在旧能力上叠加数据素养、科技素养与人文素养。因为仅用模拟工具无法在数字世界成功。人类生活与工作离不开大数据流动、连接、每次点击与触摸产生的即时信息流。他们需要数据素养来阅读、分析并使用前所未有的信息流。科技素养为编程与工程原理提供基础，帮助理解机器行为。人文素养则赋予沟通与设计能力，使其在人类社会中游刃有余。

正如前述，单纯知识已不足以应对未来工作。因此人类学的另一面不是内容集合，而是一套认知能力，即更高层次的思维技能。其一是系统性思维，能整体审视企业、机器或学科，在不同功能间建立联系。其二是创业精神，将创造性思维应用于经济，通常是社会领域。其三是文化敏捷性，让学生在全球化环境中游刃有余，能通过不同甚至矛盾的文化视角看待情境。其四是人文学科的老生常谈——批判性思维，即养成纪律性、理性分析与判断的习惯。

这些新读写能力与认知能力结合，能让学生超越智能机器的计算能力，具备创造力。他们可与他人与机器协调工作，同时凸显二者优势。简言之，人类学为人类提供强大工具。

本书还将探讨人类如何掌握这些工具。要获得更高层次认知能力，学生不能仅靠课堂阅读、案例研究或模拟。要让能力固化在思维中，需在真实、紧张混乱的工作环境中体验，比如合作与实习。体验式学习帮助蹒跚学步的婴儿破解语言与行走之谜，帮助学生学习阅读与计数，帮助运动员完善跳投，帮助音乐家完善琶音，也帮助大学生学会独特思考。这是传授人类学的理想方式。

然而高校新模式必须认识到学习不以本科毕业证书为终点。随着机器不断开疆扩土，人类必须持续磨炼思维能力、技术与科技知识，人们很少沿毕业时选择的职业道路一直走下去，因此需要终身学习支持。大学应走到学习者最需要的地方，提供终身学习。这意味着教育传播模式发生翻天覆地变化，我们对受教育时间的理解也会深刻改变。大学仅为本科生与研究生提供几年孤立学习已无法满足需求。高等教育必须拓宽视野，思考为谁服务、何时服务。它必须以服务人为理念，而不论其处于人生哪个阶段。

2025年地球将拥有80亿人口，他们都具备人类雄心、智慧与潜力。星球将比我们今天所知更紧密相连、竞争更激烈。鉴于科技进步速度，我们可预测计算机、机器人、人工智能将错综复杂地融入个人生活与职业。许多现有岗位消失，一些高薪工作尚未出现。唯一确定的是世界会变得不同——在变化中既有机遇也有挑战，在许多情况下二者难以区分。

## 教育，使之不同

# 第一章 对机器人未来的恐惧

结果只是时间问题，那一刻终会到来。机器将在世界上拥有真正霸权，而它的臣民是谁对此——具有真正哲学头脑的人不会产生一刻的质疑。

——塞缪尔·巴特勒，《机器中的达尔文》，1863

2015年，查普曼大学公布针对美国公众最恐惧事件的调查。恐怖主义与核袭击等“人为灾难”最普遍。但紧随其后，比犯罪、地震更令人可怕的是科技。事实上科技似乎比完全未知更能吓到我们。调查显示，美国人对机器人取代劳动力的恐惧超过对死亡的恐惧整整七个百分点。

当然，若它们真的出来吓人，这并非妄想。自燧石被证实比指甲锋利以来，机器就在取代人类劳动。工作场所的历史几乎与工作的历史一样古老。随着技术提升劳动能力，劳动性质也在变化。问题是，21世纪工作的演变是否与20世纪、19世纪甚至公元前10世纪有质的不同？

## 元素与工作

在物理学中，力作用于物体使其朝一方向移动时即为做功并消耗能量。在生物学中，所有生物体都要消耗能量获取营养以维持生存、消耗与喂养过程。

纵观历史，人类一生大部分时间花在工作上以获取食物。与其他生物不同，我们发明了利用比牙齿与肌肉更大力量的方式来放大能量。也许一百万年前祖先驯服了火元素。被人类控制的火是所有工作中最伟大的创新之一。通过烹饪食物，祖先能减少消化消耗，吃到小麦与大米等有用植物，破坏寄生细菌，减少咀嚼与加工负担。这让我们能把更多能量投入巨大大脑的进化。

更近些时，人类驯养植物与牲畜，极大增加可消耗能量，并役使牲畜工作。我们还通过风帆与风车利用空气元素。但直到我们驯服蒸汽力量，才发现真正可靠的元素力量。

工业革命开始时，人们意识到热量可引起运动从而完成工作。加热水至沸腾可移动活塞，而活塞又可带动18世纪工程师可附着其上的任何东西。从矿井水泵开始，机器开始做过去由强壮四肢与紧绷背部完成的工作。数十年内，这场工业化几乎改变人类社会的方方面面。

通过利用煤炭随后石油，世界将机械转化为看似无限的能量。工厂与磨坊轰鸣，火车隆隆穿行乡间，用砖块与钢铁建造并以煤气灯照亮的城市如春笋般崛起，人口因播种机与犁的使用迅速扩张。自农业时代以来，人类从未经历如此无可争议的变化。
