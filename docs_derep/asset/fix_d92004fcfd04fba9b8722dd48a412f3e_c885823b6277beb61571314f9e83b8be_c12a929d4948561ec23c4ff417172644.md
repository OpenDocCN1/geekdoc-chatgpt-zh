### 9.3 基于OpenClaw添加与使用Skills
OpenClaw 的价值不止于底层框架，更在于可高度扩展的 Skills 生态。除内置的联网检索、天气预报等基础能力外，还可借助自定义 Skills 拓展专业边界。

#### 9.3.1 玩转内置Skills
在飞书里向 OpenClaw 询问“介绍一下你目前具备的Skills技能”，它会列出当前已启用的核心能力，见图9-22。
实际上技能库比预期更丰富。打开扣子编程里 OpenClaw 的预览页，点击“技能”标签，如图9-24，可看到 WORKSPACE SKILLS、BUILT-IN SKILLS、EXTRA SKILLS 三大类，共 59 项内置 Skills。

## 图9-24 内置Skills
下面以天气 Skills 做演示，无需额外配置，直接在飞书里用自然语言发出：

今天北京的天气怎么样？

稍等片刻，系统会自行判断意图、调用天气 Skills 并返回精简结果，如图9-25。

## 2. 构建Cron定时任务
OpenClaw 内置 Cron 定时能力，无需编写 Python 定时脚本，只需用自然语言下达指令：

是否能基于stock-limit-up-screening Skills帮我实现在每个交易日的晚上20点，定时调用该Skills，抓取和筛选股票，然后把结果通过飞书推送给我

发出该提示后，OpenClaw 会解析 Skills 并用 Cron 配置定时任务，随后进行一次验证，具体过程见图9-27。

## 3. 调试与问题修复
开发中难免碰到异常。如图9-27所示，因在交易日中午进行开发，获取的数据并不理想，但更关键的是图9-27（a）中显示的问题：板块显示为未分类、封板比显示为0.000。
此时，只需把异常结果反馈给 OpenClaw，询问“为什么板块显示为未分类，封板比显示为0？”它会重新梳理 Skills 能力、Cron 脚本参数与逻辑，最后完成修复，如图9-28所示。
