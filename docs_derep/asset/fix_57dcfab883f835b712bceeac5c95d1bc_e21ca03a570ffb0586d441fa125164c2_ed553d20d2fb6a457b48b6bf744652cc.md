# 第二章 数据权益保护框架

## 第一节 基本要求

### 第十二条 【通用原则】

本市依法保护自然人对其个人信息享有的人格权益。

本市依法保护自然人、法人和非法人组织在使用、加工等数据处理活动中形成的法定或者约定的财产权益，以及在数字经济发展中有关数据创新活动取得的合法财产权益。

该款可看作条例的定调表述，厘清了从收集到使用、加工再到交易的全流程里，自然人等主体能够主张的人格性利益与财产性利益，以及这些利益的形成路径。

#### 一、数据权益的性质与构成

条文首要回应的是数据权益划分为哪些类型，上海条例的基础恰落于此。

第一款聚焦自然人对个人信息的支配权，即数据中关乎个人的记录部分，而非把整块数据整体纳入人格权客体。第二款则释放出两项明显突破。其一，在数据处理环节，除法定来源外，当事人还能通过约定创设权益，且地方性法规可以直接兜底保障这种约定，这在地方立法中并不多见。其二，立法专门为数字经济中的数据创新预留财产收益空间，让创新过程中产生的新价值也能被合法确认。这样既降低市场主体的不确定预期，也能释放数据要素的收益潜能，推动流通和市场培育。

把个人信息的人格保护与数据权益的财产保护分开处置，是对数据归属问题的一种建设性尝试。

海外参照可资借鉴。欧盟《通用数据保护条例》并未直接命名个人数据的财产权，但制度设计处处透露出财产化思路。其一，GDPR确立了默认归属导向，处理个人数据须有个人同意，默认状态下数据仍归个人掌握；其二，对控制者与处理者设定了严格责任，拿到数据的一方即便基于合同或同意取得，也不能随意处置；其三，在救济层面采用了更接近财产规则的赔偿方式。总体看，欧盟并未明示财产权，实践逻辑却围绕数据作为财产展开。

国内路径同样走人格与财产并行，而非提出一个确定性的“数据权”。从中央看，数据权属涉及民法基本制度，属于全国人大专属立法事项，地方操作空间受限；数据主体多元、权益交织，学界国内外尚无定论，中央对地方先行探索保持审慎。从地方看，已有近二十部数据与信息相关的规范，多采取抽象表述，或细化为具体权利类型，或仅概括为人格与财产两类，上海市条例选择了概括化处理。

#### 二、权益保障的路径差异

人格权益与财产权益的保护逻辑并不一致。

人格权益更接近不可剥离的人身利益，核心在法律身份的认定。生命、健康、名誉、姓名、肖像等构成人格要素，保护上主要借助民事法律关系来规制，情节严重时再介入刑事制裁。第一款正是遵循这一常规思路来理解个人信息的人格保护。

数据财产权益的保护更为复杂，涉及主体资格、权益范围与属性定位。第二款对此作出回应。其一，主体上明确自然人、法人和非法人组织均可享有财产权益。其中自然人更强调其作为数据处理者的角色而非仅是信息主体，法人与非法人组织则只能在财产层面主张权利。其二，范围上既涵盖使用、加工等活动中所形成的法定或约定财产权益，也包括数字经济发展中数据创新活动所产生的合法财产权益。这一表述比《数据安全法》《个人信息保护法》以及《深圳经济特区数据条例》更为宽松，也更贴合产业实际。其三，数据相关财产权益的明晰是交易流通的前提。缺乏财产权支撑的买卖、开放、交换都会因法律基础不足而风险陡增，不利于要素市场成熟。

《民法典》第127条和第1034条将数据、网络虚拟财产列为民事权利客体，承认其上利益受法律保护，但并未明确具体权利形态。《数据安全法》《个人信息保护法》同样保持克制，上海市条例亦未做具体化。可行的进路是先建立覆盖交易全流程的行为规范，通过制度设计稳定数据要素市场秩序；或继续以“保护利益”的抽象表述为主，暂时不作硬性赋权，待上位法完善后再予填补。

### 第十三条 【数据收集权益】

自然人、法人和非法人组织可以通过合法、正当的方式收集数据。收集已公开的数据，不得违反法律、行政法规的规定或者侵犯他人的合法权益。法律、行政法规对数据收集的目的和范围有规定的，应当在法律、行政法规规定的目的和范围内收集。
