ChatGPT 使用中的数据与隐私争议

ChatGPT 的隐私与数据保留做法一直备受政府与用户质疑。

隐私条款披露了公司如何收集与使用数据。例如付费升级或在对话中提供信息时，系统会采集 IP 地址、位置等各类细节。

这些采集本身并不特殊，是行业常见做法，但聊天机器人会在对话过程中持续记录用户行为。OpenAI 会保存姓名、联系方式、支付信息、交易记录、登录凭证等基础资料。联系客服或发送邮件时，姓名、地址、消息内容也会被留存。发表评论后，社交媒体互动以及主动分享的个人信息同样会被追踪。使用服务期间，还会收集浏览器类型、IP 地址、会话时长、操作系统与设备名称。

为追踪网站与聊天窗口中的浏览活动，OpenAI 使用 Cookie，并称数据用于统计分析和了解用户互动方式。

所有聊天内容都会被归档，系统会记录对话中出现的全部信息，包括个人隐私。用户在起草专业或个人文件时，往往无意中泄露了这些信息。

在工作中无防护使用 ChatGPT，可能将公司、员工、委托人等敏感细节暴露给系统。例如把客户反馈写入报告时，就可能意外泄露客户信息。

根据隐私政策，OpenAI 应提供充分说明，让用户清楚数据如何被收集使用，且需获得用户同意并依法处理。若要分享私密信息，建议联系 OpenAI 签署数据处理附录。

联系信息可能被广泛主体获取。政策显示 OpenAI 会与他人共享数据，服务商、供应商、法人实体等也可能收集这些信息，技术训练师等人员也可能审阅对话。

OpenAI 并未明确说明共享的具体方式，但表示可能与服务商共享信息以执行功能或满足商业需求，涉及云计算、分析、邮件、网络托管、活动管理等。

政策更明确的部分指出，在合作伙伴交易、并购、破产或清算时，或为保护用户、公众及自身免于法律责任而与执法部门共享数据时，也会进行信息共享。

训练人员会分析对话以改进模型，并检查内容是否符合公司规则。一旦向机器人提供个人信息，训练师即可看到。

总体来看，OpenAI 与 ChatGPT 收集的信息大多无害，多与设备与账户相关。

ChatGPT 使用相关的信息风险

负责法律合规的领导应评估公司使用 ChatGPT 面临的多重风险，并制定减缓措施。存在六类主要风险，若未防范，可能带来法律责任与经济损失。

需警惕的是，若未关闭聊天历史记录，收集的信息可能进入训练材料。弗里德曼指出，非企业用户的回复中可能包含敏感数据。法律合规部门必须建立技术使用框架，防止个人或组织数据被未经授权访问。

ChatGPT 或许成功，但法律合规部门仍需及时跟进人工智能偏见相关的法律，宜由主题专家与技术部门协作完成。

模型在大规模互联网数据上训练，可能涉及侵犯知识产权与版权。该程序在生成输出时不提供解释或来源参考，因此定期关注版权法变化很重要。

恶意行为者滥用 ChatGPT 已导致大规模虚假信息，例如虚假评论。基于大语言模型的应用程序还易受提示词注入攻击，这种黑客技术可诱导模型执行设计目的之外的任务。

法律与监管部门领导应定期与网络安全同行协调，降低人工智能使用相关风险。

若企业未向消费者披露 ChatGPT 的使用情况，可能承担法律后果并失去信任。

减轻数据隐私问题的思路

自2022年11月发布以来，ChatGPT 用户增长迅猛，已成为许多人生活的组成部分，但安全性如何？

尽管在安全措施与隐私政策加持下可安全使用，仍存在漏洞。本部分探讨这些问题及监管因素，帮助用户更清晰评估安全性并做出明智决策。

ChatGPT 的安全性由 OpenAI 维护，该公司开发了聊天机器人及 GPT 框架。这些功能旨在让输出更自然、更接近人类，并实施多项保护措施。更多细节可参考 OpenAI 官方说明。

GPT 服务器以加密格式存储数据，系统间传输也加密，确保数据免受未授权访问。

除安全措施外，OpenAI 还采用访问控制，包括授权与身份验证协议，防止未授权个人访问用户数据。

公司还聘请外部审计员每年检查 API，以发现并解决潜在问题，确保安全措施有效。

OpenAI 建立了漏洞赏金计划，鼓励技术爱好者、黑客与研究人员报告安全问题。

通过对话数据，OpenAI 可提升自然语言处理能力，同时遵循适当的数据处理做法。

收集用户数据的目的是通过分析和临时存储用户对 ChatGPT 的所有内容来改进自然语言处理。OpenAI 对收集与使用方式保持透明，用于改善体验并训练语言模型。

数据以安全方式存储，仅用于预期目的，并在达成目标所需时间内保留，期满后删除或匿名化以保护隐私。

仅在用户同意或有明确法律要求时，信息才会被与其他方共享。OpenAI 会确保第三方遵循适当的隐私与数据处理规则，确保数据安全处理。用户可期待 OpenAI 尊重隐私并对其信息保持控制，公司提供便捷方式访问与修改个人信息。

ChatGPT 平台并非保密，会记录每次对话并将数据用于训练。

关于 ChatGPT 的监管

隐私与数据保护规定适用于人工智能技术，在不同法域各有差异。

GDPR 适用于位于欧盟并处理欧盟居民个人数据的组织，确保隐私与权利受保护。

美国加州 CCPA 为消费者规定与个人信息相关的权利，要求企业告知数据收集方式及共享情况。

各国制定了自身法律以保护人工智能系统收集的信息，包括新加坡 PDPA 和巴西 LGPD。2023年3月意大利因隐私问题禁止 ChatGPT，一个月后 OpenAI 增加安全功能后禁令解除。

欧洲议会已关注 ChatGPT 等人工智能系统缺乏法律规制的问题。2023年通过《人工智能法案》，要求开发人工智能技术的公司披露训练数据版权来源。

这些法规按项目带来的风险程度分为不同类别，从低到高。法规不会禁止高风险工具，但将强制严格透明度措施。

《人工智能法案》是规范人工智能使用的综合立法。在正式落实前，用户仍应谨慎使用 ChatGPT。

尽管程序努力阻止非法或不合伦理提示，仍有许多人能轻松绕过限制。开发人员持续努力，但用户仍会挑战极限。

网络钓鱼
