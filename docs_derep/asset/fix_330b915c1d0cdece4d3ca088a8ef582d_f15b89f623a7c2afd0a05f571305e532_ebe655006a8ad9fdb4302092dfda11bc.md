## 核心机制速览：计算图的定义与执行
TensorFlow 采用「先定义图，后运行会话」的延迟执行模型。以基础算式 `f(1,2) = 1+2 = 3` 为例：
[PRE20]

引入更多运算节点构建数据流图：
```text
a=input1; b=input2
c=a*b; d=a+b
e=c+d
```
[PRE21]

当喂入具体数值 `a=5, b=3` 时，数据在图中按拓扑顺序流动并完成计算：
```text
e = a*b + (a+b)
  = 5*3 + (5+3)
  = 15 + 8
  = 23
```
[PRE22]

这一「构建图结构 -> 置入张量数据 -> 启动会话计算」的最小闭环，正是 TensorFlow 编程范式的核心精髓。
