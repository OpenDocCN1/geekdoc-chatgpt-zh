第三步：发布应用并验证
（1）配置完成后，你应该能在钉钉后台查到自己的机器人。
（2）打开钉钉客户端，手机端或电脑端均可，在顶部搜索框输入机器人名称，例如“小龙虾助理”，进入后发送一条“你好”。若搜不到，请等待 1-2 分钟，发布后有短暂延迟，手机端通常先生效。

**常见问题排查**
出现异常先查看日志：
openclaw logs | grep dingtalk
常见高发问题有三类。
（1）机器人完全没反应。排查三点：应用是否已发布，消息接收模式是否选 Stream，Gateway 是否在运行。
（2）群消息不回复。确认机器人已加入群且消息以 @ 机器人名称 的形式发出，群需为企业内部群，普通群不支持。
（3）连接频繁断开。多为网络抖动。插件内置指数退避自动重连，短暂中断可自恢复。若持续断开，请检查服务器能否正常访问钉钉 API。

**企业微信实用场景**
（1）群助手：把机器人拉进企业内部群，@ 即可提问、执行任务，仅支持企业内部群。
（2）智能表格联动：可在智能表格中开启接收外部数据，将 Webhook 地址告知机器人，说“帮我插入一条数据”即可自动写入，适合日报、客户信息录入。

**常见问题排查**
问题 1：找不到“智能机器人”入口。更新客户端，仍无则让管理员在管理后台→安全与管理→管理工具中开启功能。
问题 2：插件安装失败。大概率为网络问题，先设国内镜像源再重试。
问题 3：配对码过期。配对码有有效期，需重新触发消息获取新码再执行 pairing 命令。
问题 4：发消息收不到回复。检查 Gateway 是否运行：openclaw gateway status；检查 AI 模型 API Key 是否正确、余额是否充足，日志可通过 openclaw logs 查看。

[PRE21]

**安全提醒**
企业微信智能机器人权限较高，建议仅在可信环境使用。个人测试请合理设置可见范围，Bot ID 和 Secret 相当于钥匙，切勿泄露。
