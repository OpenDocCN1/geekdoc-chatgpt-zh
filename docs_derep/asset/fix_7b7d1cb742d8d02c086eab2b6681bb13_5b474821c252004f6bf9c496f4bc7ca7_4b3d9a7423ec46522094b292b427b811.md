### 6.4.3 RNN梯度消失的应对思路

前面提到的消失现象源于对历史信息的无限复用，而这恰恰是RNN的优势所在。常见缓解手段包括：

+   1. 选用更合适的激活函数，例如 ReLU。ReLU 左侧导数为0，右侧恒为1，可避免导数逐层衰减。但恒为1的导数也易导致梯度爆炸，可通过设定阈值来控制。

2. 引入BN层。BN可加速收敛、抑制过拟合，能减少甚至免去Dropout和正则化的需求，对权重初始化不敏感，同时允许使用更大的学习率等。

3. 改变传播结构。LSTM等门控结构能有效缓解此问题。6.5 节将详细展开 LSTM 相关内容。

## 6.5 长短期记忆网络 LSTM

长短期记忆网络 Long Short-Term Memory，LSTM 是为解决长程依赖问题而设计的特殊RNN变体，在众多任务上取得优异表现并被广泛应用。

### 6.5.1 LSTM诞生的背景

RNN在处理时间距离较远的节点时非常吃力，因为联系它们的计算涉及雅可比矩阵的多次相乘，容易产生梯度消失或爆炸。为此研究者提出了多种方案，比如 ESN 回声状态网络、Leaky Unit 泄漏单元等。其中最成功的是门控RNN Gated RNN，而 LSTM 正是其中最具代表性的一种。泄漏单元通过设计权重系数让RNN能够累积远距离的信息；门控RNN则在此基础上允许系数随时间动态变化，并能主动遗忘已累积的内容。

### 6.5.5 LSTM与GRU的区别

LSTM与GRU的区别如图6-30。

[PRE19]

图6-30 LSTM与GRU的区别

从上图可以看出二者结构非常相似，下面分析不同之处。

+   1. 新记忆均基于先前状态及输入计算，但GRU中有一个重置门 Reset Gate 控制先前状态的进入量，而LSTM没有类似门。

2. 产生新状态的方式不同，LSTM有两个不同的门，即遗忘门和输入门，而GRU只有一种更新门 Update Gate。

3. LSTM对新产生的状态可通过输出门进行调节，而GRU对输出无任何调节。

总体来看，LSTM已成为较为标准的RNN结构。对于大部分能运用在普通RNN的性质和变体，都能直接推广到LSTM。在绝大多数关于RNN的应用中，LSTM都能取得优于普通RNN的效果。

### 6.6.1 简单循环神经网络 SRN

SRN 的网络结构示意图如图6-31，其特点如下。

（1）SRN是一个三层网络，其在隐含层增加了上下文单元。图6-31 中的 y 是隐含层，u 是上下文单元。上下文单元节点与隐含层节点的连接是固定的，且权重也是固定的。上下文节点与隐含层节点一一对应，值是确定的。

[PRE20]

图6-31 SRN的网络结构示意图

（2）在每一步中，使用标准的前向反馈进行传播，然后使用学习算法进行学习。上下文每一个节点保存其连接隐含层节点的上一步输出，即保存上文，并作用于当前步对应的隐含层节点状态，即隐含层的输入由输入层的输出与上一步的自身状态决定。因此 SRN 能够解决标准多层感知机 MLP 无法解决的对序列数据进行预测的问题。

### 6.6.4 回声状态网络 ESN

ESN 的特点如下。

+   （1）ESN 的核心结构为一个随机生成且保持不变的储备池。储备池是大规模随机生成稀疏连接的循环结构，储备池稀疏程度通常保持在1%～5%，表示储备池中互相连接的神经元占总神经元个数 N 的比例。

+   （2）从储备池到输出层的权重矩阵是唯一需要调整的部分。

+   （3）简单的线性回归便能够完成网络训练。

ESN 的基本思想如下。
使用大规模随机连接的循环网络取代经典神经网络中的中间层，从而简化网络训练过程。

网络主要有如下参数。

+   （1）W：储备池中节点间的连接权重矩阵。

+   （2）W_in：输入层到储备池之间的连接权重矩阵，表示储备池中的神经元之间是相互连接的。

+   （3）W_back：输出层到储备池之间的反馈连接权重矩阵，表示输出层的一些信息会反馈到储备池。

+   （4）W_out：输入层、储备池、输出层到输出层的连接权重矩阵，表示输出层不仅与储备池连接，还与输入层和自己连接。

+   （5）W_outbias：输出层的偏置项。

### 6.6.5 时钟频率驱动RNN CW-RNN

CW-RNN 是 RNN 的改良版本，使用时钟频率来驱动。它将隐含层分为几个块/组，每一组按照自己规定的时钟频率对输入进行处理。为了降低 RNN 复杂度，CW-RNN 减少了参数数量，并提高了网络性能，以加速网络训练。CW-RNN 通过不同隐含层模块在不同时钟频率下工作来解决长时依赖问题。将时钟时间离散化，不同的隐含层组将在不同时刻工作。因此所有隐含层组在每一步不会全部同时工作，这样会加快网络训练，并且时钟周期小的神经元不会连接到时钟周期大的神经元，只允许周期大的神经元连接到周期小的神经元。周期大的速度慢，周期小的速度快，因此速度慢的神经元可连接到速度快的神经元，反之则不成立。
