##### 3. 安装编译工具环境

1) 安装gn
(1) 打开 Linux 编译服务器终端。
(2) 下载 gn 工具。
(3) 解压到 ~/gn 目录下：tar -xvf gn.1523.tar -C ~/。
(4) 编辑环境变量：vim ~/.bashrc，新增 export PATH=~/gn:$PATH。
(5) 使变量生效：source ~/.bashrc。

2) 安装ninja
(1) 打开 Linux 编译服务器终端。
(2) 下载 ninja 工具。
(3) 解压到 ~/ninja 目录下：tar -xvf ninja.1.10.0.tar -C ~/。
(4) 编辑环境变量：vim ~/.bashrc，新增 export PATH=~/ninja:$PATH。
(5) 使变量生效：source ~/.bashrc。

3) 安装gcc_riscv32（WLAN 模组类编译工具链）
(1) 打开 Linux 编译服务器终端。
(2) 下载 gcc_riscv32 工具。
(3) 解压到 /opt/gcc_riscv32 目录下：tar -xvf gcc_riscv32-linux-7.3.0.tar.gz -C ~/。
(4) 编辑环境变量：vim ~/.bashrc，新增 export PATH=~/gcc_riscv32/bin:$PATH。
(5) 使变量生效：source ~/.bashrc。
(6) 执行 riscv32-unknown-elf-gcc -v，若能正确显示版本号则安装成功。

4) 安装Scons
SCons 是用 Python 编写的开源构建工具，可替代 Make、CMake，采用 Python 脚本配置构建流程。
(1) 打开 Linux 编译服务器终端。
(2) 安装 SCons 包，需 root/sudo 权限：sudo apt-get install scons -y。
若软件源中无可用包，可下载源码包 https://scons.org/pages/download.html，推荐 3.0.4+，解压后执行 sudo python3 setup.py install，然后运行 scons -v 验证。

##### 4. 安装Samba服务

Samba 在 Linux/Unix 上实现 SMB/CIFS 协议，可与 Windows 共享文件与打印机。
- 安装：sudo apt install samba
- 编辑配置文件：sudo gedit /etc/samba/smb.conf，在末尾添加共享配置。
- 创建共享账号：sudo smbpasswd -a username，其中 username 为虚拟机登录账号。
