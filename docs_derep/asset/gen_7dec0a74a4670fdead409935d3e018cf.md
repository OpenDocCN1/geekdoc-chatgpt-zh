# 技巧05 组合图表：对比与趋势同屏

柱状图擅长横向对比不同类别的数值，折线图擅长表现数据随时间或其他变量的变化趋势。两者结合，可在一张图表中同时满足对比与趋势分析需求。当两组数据的量纲差异较大时，例如销售额与利润率百分比，可采用主次坐标轴分别呈现柱状与折线，避免数据被压缩失真。此外，组合图表还能帮助洞察两个变量间的潜在关联。

HTML 是构建网页与网页应用的标准标记语言，通过一系列标签对内容进行结构化，使文本、图像、视频等多媒体元素得以展示与交互。HTML 文档由标签定义，指导浏览器渲染页面内容。

JavaScript 简称 JS，是一种为网页添加交互式动态功能的编程语言，可让页面响应点击、表单提交、数据加载等操作。JS 可直接嵌入 HTML，也可通过外部文件引入。
