# ### 代码逻辑解释

1. **准备与遍历**：
   - `weight` 记录物品重量，`value` 记录价值。
   - `bagweight` 为背包容量上限。
   - `dp[i][j]` 表示前 i 件物品在容量 j 时能得到的最大价值。

2. **外层循环**：

[PRE8]
- 从第一个物品开始逐个处理到 `weight.size()`。

3. **内层循环**：

[PRE9]
- 容量从 0 遍历到 `bagweight`。

4. **状态转移**:

[PRE10]

- 否则比较两种选择：不取 `dp[i-1][j]`，取则 `dp[i-1][j-weight[i]]+value[i]`，取较大值。

# ### 功能说明

# ### 总结

- **输入**：物品重量数组 `weight`、价值数组 `value`、容量 `bagweight`。
- **输出**：容量受限下的最大价值。
- **方法**：动态规划，自底向上填表求最优解。
