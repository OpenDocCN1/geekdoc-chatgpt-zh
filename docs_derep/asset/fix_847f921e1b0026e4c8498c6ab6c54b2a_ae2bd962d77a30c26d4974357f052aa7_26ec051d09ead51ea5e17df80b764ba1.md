星载舰船目标：快速筛查与精细判别的工程化方案

面对海况多变、背景杂乱、虚警频出的遥感场景，提出一种融合形态学匹配与机器学习的星上舰船检测识别体系。先借助视觉增强手段做粗筛，挑出可疑目标从而大幅削减后续计算量；再借助机器学习深度挖掘有效特征，显著抑制虚警并完成类别细分。硬件层面划分为控制与运算两域：控制域选用高可靠宇航级抗辐照器件，运算域搭建 FPGA、DSP 与 GPU 异构高算力平台，充分利用 FPGA 的流水并行特性、DSP 的高密度算力以及 GPU 的大规模并行处理优势，提升算法工程化效率与检测识别实时响应，同时降低功耗、改善能效。试验显示，海况地形复杂、背景显著性较差的遥感舰船场景下，该方案的检测与识别准确性与实时性均表现优异。

## 1. 面向光学遥感卫星应用的舰船目标实时检测识别算法

光学遥感影像中感兴趣目标稀疏分散是典型特征。基于此，提出一种面向光学遥感卫星的舰船实时检测识别方法。如图 13-1 所示，整体以形态学匹配为前端、机器学习为后端，前端利用视觉增强迅速锁定可疑目标并截取切片，极大压缩后续数据规模；中端借助 FPGA 与 DSP 架构实现实时处理；后端引入卷积神经网络压制虚警并完成目标细分类。训练阶段采用剪枝、权重共享等手段压缩参数，推理阶段以 FPGA 与 GPU 协同实现并行计算，进一步提升实时性能。

### 1）目标检测算法流程

为兼顾在轨部署可行性，设计了以局部降维统计分类为基础的卷积鉴别网络 CDN。该网络较好解决了传统舰船检测计算量大、结构复杂难实现、复杂港口或恶劣海况适应性差的问题，易于部署于星上嵌入式硬件。

目标检测流程如图 13-2 所示。CDN 共分三部分：其一为背景噪声抑制。对原始影像先经高斯滤波、中值滤波去除周期与随机噪声，再通过形态学开闭运算消除噪声引发的目标内部空洞、邻近目标粘连及边界粗糙，实现目标增强。其二为可疑目标筛选分割。先对图像分块，比较当前检测区与邻域直方图方差特征，将场景划分为纯海域、陆地、可疑目标三类，再对可疑区实施自适应迭代分割，得到二值图后做连通域标注，输出可疑目标标记。其三为基于形状特征的目标鉴别。对标注结果计算圆形度进行甄别，剔除误报后得到最终舰船检测结果。

从流程可看出，CDN 由 7 个流水卷积核、自适应分割、局部统计分类构成的深度计算结构。单个卷积核单元为基础二维滤波结构。卷积层内部包含串联层与并联层，串联层逐层相连，并联层内以模加减为主；卷积层输出进入自适应分割网络，通过自适应迭代突出显著前景；局部统计分类器对目标上下文进行判决，最终判定是否为舰船并输出坐标与尺寸。

CDN 的优势在于层次化、参数可并行流水执行，尤其在卷积核计算后即做分割降维，相较传统方案可降低 90% 以上的计算量，大幅减少在轨应用对硬件资源的依赖。

### 2）目标识别算法流程

将舰船可疑目标的图像切片作为 CNN 分类器的待分样本，人工标注的切片作为训练输入。分类模型选用 VGG-16。VGG-16 由 Simonyan 与 Zisserman 于 2014 年提出，是典型深度卷积神经网络，在 ImageNet 2014 竞赛中 Top-5 错误率仅 7.4%，仅次于 GoogleNet，能有效提取深层特征，分类能力突出。

标准 VGG-16 结构如图 13-4 所示，包含 13 个卷积层与 3 个全连接层，采用逐层增大的 3×3 卷积核，并以 2×2 最大池化降低运算规模，随后是两个 4096 节点的全连接层与一个 Softmax 分类器，可实现 1000 类目标分类。

## 2. 硬件平台构建

### 1）硬件平台设计

高性能电子器件的应用长期受抗辐照要求限制。多数设计仅强调通用性与实时性，可靠性与抗辐照性难以满足宇航需求。为此提出一种面向遥感目标在轨检测识别的可重构处理平台。

基于 FPGA+DSP+GPU 异构处理架构的平台硬件拓扑如图 13-7 所示。设计思路为：采用 Space VPX 总线标准，各单元板卡使用 6U 标准结构；充分考虑宇航应用的高可靠、高效能、抗辐照、容错纠错能力，将装置分为控制与处理两部分，控制部分采用高可靠抗辐照宇航级器件，处理部分采用高性能大容量常规器件，在降低成本的同时提升可靠性和处理性能；采用网状处理节点设计，支持多单元协同，扩展性强；支持在轨刷新以提升抗辐照能力，通过各单元主控模块的反熔丝 FPGA 实现对处理 FPGA 的刷新控制；支持在轨重构更新，并可根据任务通过主控反熔丝 FPGA 切换不同处理程序，主处理器 FPGA、DSP、GPU 均有两种加载方式，由主控反熔丝 FPGA 控制加载模式，应用主备份，提升系统可靠性。

### 2）平台主要指标

#### (1) 处理能力。

FPGA 选型为 Xilinx 公司 Virtex7 系列 XC7 V690TFFG1761I。该器件含 3600 个 DSP48e、1470 个 BlockRam36k，逻辑与时钟资源丰富。

DSP 选型为 TI 公司 8 核处理器 TMS320C6678，采用 Keystone 架构，单核主频最高 1.4 GHz，单核算力达 22.4 GFlOPs，每核含 512kB L2 内存，8 核共享 4 MB 内存。

#### (2) 外接存储能力。

XC7 V690TFFG1761I 外挂 8 片 1GB DDR3、2 片 144Mb QDR-SRAM 等高性能存储器。

TX2 外挂 8GB DDR4，位宽 128 位，访问速率 1866 MHz。通过 SATA 接口外接 SSD 盘。

## 3. 算法流程分解

主要处理流程及任务分配如图 13-8 所示。处理单元 FPGA 通过光纤模块或 Serdes 接口接收载荷图像数据，接收后 FPGA 流水完成形态学增强等图像预处理，将结果经 SRIO 总线发送给 DSP。DSP 负责图像分割、连通域标记、HOG 处理等基于形态学的可疑目标提取及目标切片生成，必要时可对图像做降分辨率处理，在不影响检测效果的前提下降低数据量。DSP 根据检测到的可疑目标坐标在原始分辨率上截取目标切片，并经 SRIO 总线发送给 FPGA。

[PRE8]

图 13-8　主要处理流程及任务分配

FPGA 与 GPU 配合完成基于卷积神经网络的深度学习处理，对目标切片进行精分析以实现识别分类。其中 FPGA 主要负责卷积层并行加速，GPU 主要负责模式配置及分类层处理。目标切片处理完成后，DSP 对分类结果进行判定：若为感兴趣目标，则将切片与目标类型打包经交换单元发送至存储单元保存；若非感兴趣目标，则依预设规则丢弃或经 LVDS 接口发送给数传单元保存。

### 1）深度网络算法模型分析

如图 13-4 所示，标准 VGG-16 含 13 个卷积层与 3 个全连接层，使用逐层增大的 3×3 卷积核，并以 2×2 最大池化减小运算规格。先是 13 个卷积层，随后是两个 4096 节点和一个 1000 节点的全连接层，最后是 Softmax 分类器，可实现 1000 类目标分类。VGG-16 运算规律性强，便于硬件资源并行流水加速。

VGG-16 参数量与运算量巨大。如表 13-2 所示，参数量达 138M 个，采用单精度浮点形式参数数据量超 500MB，输入图像为 224×224 时模型运算量达 15.5 GOPs，1 OPs 等于一次乘法加法操作。
