# Claude Code Harness 工程指南

# 前言

2025年2月，Anthropic正式发布了Claude Code。初次接触的人大多会认为它只是一个跑在终端里的命令行程序：输入指令得到回应，偶尔写点代码，偶尔跑测试。不少开发者使用的习惯也停留在这里：打开终端、描述需求、拿代码、关闭窗口，循环往复。

这只是表象。

把视线放到水面之下，Claude Code的真实形态是一个可编程、可扩展、可组合的Agent编排框架。官方给出的定义是Agentic Harness，即Agent用具。

Harness本义是马具，马匹有力却需缰绳与挽具引导才能拉车。Claude Code的作用并非提升模型智力本身，而是改变智力如何被传递与控制。

水面之下藏着8套机制：记忆系统让模型不再遗忘上下文，Skills赋予领域工作方式，子智能体把复杂任务拆解执行，Hooks在关键节点植入确定性约束，MCP打通外部工具与数据源，Headless模式可接入CI/CD流水线，Agent SDK让你从使用者变为构建者，Plugins生态把上述能力打包分发。

不知道这些，开发者只能困在终端里反复对话，一遍遍复述项目背景，眼睁睁看着上下文窗口膨胀、注意力漂移，最后得出“Claude不够聪明”的结论。其实不是模型不行，而是Harness只被用到了大约10%。本书要交付的就是剩下90%的用法。

# 为什么 Harness 比模型更重要

2026年初出现了一个共识：同一模型在不同Harness下表现的差距，远大于不同模型在相同Harness下的差距。

TerminalBench上，仅靠优化Harness，同一模型的成绩就从基准线以下跃升到Top5。Vercel团队砍掉80%的Agent工具后，流程更简洁、Token消耗下降、响应加快。OpenAI给出极端案例：3名工程师、0行手写代码，产出100万行产品级代码，关键在于他们搭建的是Harness而非代码。

这打破了“等更强模型”的幻想。Claude的能力边界由Anthropic决定，无法改动；而Harness的配置权全在你手里：CLAUDE.md怎么写、工具权限如何设、Hooks怎么接入、MCP怎么连。书中每一种能力，本质都是调教Harness。

# 关于 Claude 一词的用法

Claude Code指Anthropic推出的Agentic Harness，即终端里启动并交互的应用程序，包含工具调用引擎、权限控制、子进程管理、上下文压缩、插件加载等工程组件。

不带Code的Claude，多指该程序内部负责推理生成的模型。

使用时两者紧密交织：你与模型对话，Harness在幕后管理上下文、调度工具、控制权限。正如驾驭马匹，你指挥的是马的意志，力量传导靠马具。本书在易混淆处会明确区分Claude Code与Claude，语义清晰时则统一简写。

咖哥连问三点：项目根目录有CLAUDE.md吗？六文件重构为何不拆给子智能体协同？代码规范为何不封装成Skill自动加载？

小冰答不上来。

“根源不是模型不聪明，”咖哥说，“你只用了它10%的能力，基础对话而已。Claude Code是一个完整Agent框架，内置记忆系统、Skills、子智能体、Hooks、MCP。你遇到的痛点，框架里都有解。”

对话持续两小时后，小冰感慨：原来自己只是在用高级聊天窗口。

## 1.1 从命令行助手到 Agent 框架

记忆丢失、风格漂移、长任务溢出，是工程化使用Claude Code的常见瓶颈。它们看似三个Bug，实则指向同一误区：把Agent框架当聊天工具用。

Claude Code的本质是可编程、可扩展、可组合的Agent框架。

可编程：可用Python或TypeScript直接驱动，嵌入CI/CD或自动化脚本，无需人工守终端。
可扩展：通过配置文件注入记忆系统、Skills、Hooks等能力，无需改动核心代码。
可组合：模块可灵活编排，像积木一样构建复杂工作流。

三者合一，形成基础设施，供开发者搭建专属AI工作体系。

“每个痛点在这里都有对应机制，”咖哥说，“问题不在工具不够强，在潜能未释放。”

小冰领悟：过去是手动写脚本——重复灌输信息、人工拆任务、肉眼审风格；框架化则是配置自动化——技术栈固化到CLAUDE.md，审查标准封装进Skill，提交检查配置为Hook。一次配置，Claude不会忘、不会懈怠、不随疲劳降标，这是把个体智慧沉淀为制度的工程思想。

### 1.2.1 记忆层——CLAUDE.md

地基决定承载。记忆层决定Claude对项目的理解深度。

本质上Claude是无状态模型，新对话开始时对技术栈、代码规范、团队约定一无所知。未配置时需要反复说明“用TypeScript不用JavaScript”“优先pnpm”“测试用Vitest”。这种每天入职式的重复效率极低。
