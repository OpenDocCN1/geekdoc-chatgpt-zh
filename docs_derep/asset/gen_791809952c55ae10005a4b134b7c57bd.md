## 9.4.15 RNN 专属优化技巧

通用神经网络优化手段（如权重衰减、学习率调度）在 RNN 上依然有效，但序列建模还拥有两大独门绝技。

### ① Dropout 的序列化改造

**误区警示**：直接套用 CNN 的 `tf.nn.dropout` 会切断时序依赖。

[PRE2]

**原理差异**：RNN 专用 Dropout 仅作用于**同一时间步的层间传递**，不触碰跨时间步的隐状态流动。因此暴露两个控制参数：
- `input_keep_prob`：当前层输入的保留率
- `output_keep_prob`：当前层输出向下一层传递时的保留率

典型模式：单层 RNN 后接 `DropoutWrapper`。

### ② Layer Normalization（LN）替代 Batch Normalization

BN 统计单批次样本的均值方差，但 RNN 每层输入 = 当前批次特征 + 上一时刻隐状态，批次维度无法覆盖全部分布，故 BN 失效。LN 沿特征维度归一化，天然适配序列结构。

**工程现状**：TF 官方 Cell 未内置 LN，需继承并重写 `GRUCell`/`LSTMCell` 的 `__call__`，在内部插入归一化逻辑。

## 9.4.17 CTC Loss：序列标注的专用损失

CTC 场景下，均方差与交叉熵均不适用，TF 提供 `tf.nn.ctc_loss` 封装。

### 1. 函数签名速览

[PRE10]

关键参数：
- `labels`：`int32 SparseTensor`，稀疏标签
- `inputs` (常用 `logits`)：`[batch, max_time, num_classes]`（`time_major=False` 时）
- `sequence_length`：每条序列真实长度
- `preprocess_collapse_repeated` / `ctc_merge_repeated`：控制重复标签合并策略，组合效果见下表

| 预处理合并 | 运行时合并 | 行为 |
|------------|------------|------|
| True | True | 彻底忽略所有重复 |
| False | **True (默认)** | 标准 CTC：运行时把连续重复视为单标签 |
| True | False | 预处理已去重，等同首行 |
| False | False | 全部重复均参与计算 |

**返回值**仍为逐样本 loss，训练时需 `reduce_mean` 聚合。

> 💡 **隐式规则**：`num_classes` 必须 **+1** 预留 `blank` 类。输出层多加一个 logit 节点，供对齐失败时归类。否则当标签索引等于 `num_classes-1` 会直接报错。

### 2. SparseTensor 速成

稀疏矩阵仅存储非零元素，三元组表示：

[PRE11]

- `indices`：`int64` 二维张量 `[N, ndims]`，记录非零坐标，如 `[[1,3],[2,4]]` 表示密集张量 `[1,3]` 与 `[2,4]` 处非零
- `values`：对应非零值
- `dense_shape`：原密集张量形状

这种存储在标签序列长度不一、类别稀疏时极大节省显存。
