# 从0到商业化落地，看懂AI产品经理真正要做的事

这不是一本堆砌原理的学院派书籍，而是一本围绕AI如何变成真金白银的商业产品来展开的实战手册。整本书的脉络都紧扣落地和规模化变现：既给出了不同品类的AI产品落地方案，也提供了可直接借鉴的方法和技巧，更用安防、制造、汽车等真实行业案例把思路讲透。

不管你是技术岗转AI产品、其他产品线转AI产品，还是已经在做AI产品，想补齐算法、中台、业务等维度落地方案的短板，都能从中得到方法论支撑。本书共分4篇13章。

第一篇第1-2章，把AI产品和AI产品经理的角色拆解清楚，帮助读者建立底层认知，也给出入行路径和职业规划建议。

第二篇第3-6章从机器学习出发，逐步拓展到以计算机视觉、语音识别、语义理解为核心的多模态理解、行为主义机器人学，以及AI云原生工程实践。内容以产品经理能用的方式呈现，只讲原理和应用方向，不钻技术细节。

第三篇第7-11章是核心。先梳理通用产品方法论，再结合AI产业链特点，深入剖析算法类、中台类、业务类三大AI产品的落地实践。算法和中台部分覆盖自动驾驶、元宇宙、企业智能、智能汽车、虚拟数字人等主流需求；业务类则从城市治理、企业服务、个人服务三个维度展开。

第四篇第12-13章从行业赋能和项目实战两个角度讲高效高质量交付。以安防、制造业、汽车为样本拆解高效落地方案，同时以B/G端项目和商机项目为例，给出可行性验证和交付环节的解决思路。

为什么写这本书
2013年前后，以深度学习为核心的人工智能浪潮开始试探商业化落地的边界。那一年作者开始接触深度学习，从校园课题论文，到入职做早期深度学习算法工程师，再转型AI产品经理，近十年亲历并参与了新一代AI产业从技术到产品落地的全过程。

2016年AlphaGo战胜人类棋手，深度学习路线被证明能带来智力跃升。但大规模数据和算力之外，如何真正商业化、怎么做产品，行业里缺乏清晰答案。技术只能到处找钉子锤，这是技术驱动、标杆项目驱动的阶段。

进入商业化深水区，AI企业开始纵向赋能传统行业，传统行业也希望用AI实现降本增效、拓展能力边界。连接技术与真实业务需求的角色就凸显出来，这就是AI产品经理。它要洞察行业痛点，用技术给出可落地的产品形态。

AI产品经理需要什么能力，如何打造好AI产品，是职业生涯的核心命题。作者在寻找答案时发现前人经验稀缺，只能自己摸索。这本书就是把摸索的历程、经验和方法论梳理出来，帮助后来者更快建立知识体系，掌握打造成功AI产品的方法。

第一篇 AI与AI产品经理
AI过去十年从学术走向产业，已形成较为完整的产业体系。过渡期里，如何理解AI、技术如何产品化、产品如何产业化、产业对人才的需求如何变化，是核心问题。本篇围绕AI概念、AI产品、AI产品经理展开。

第1章 深入理解AI和AI产品
先梳理AI概念的定义、三大流派、发展历程和产业现状，再介绍AI产品的发展脉络、形态演进与产业链。

全方位认识AI
AI的定义。1950年阿兰·图灵提出图灵测试，用对话来判断机器是否有智能。1956年达特茅斯会议上，John McCarthy、Marvin Minsky、Claude Shannon等人首次提出人工智能概念。

对AI的定义有多种说法：《人工智能：一种现代的方法》提出像人一样思考的系统、像人一样行动的系统、可理性思考的系统、可理性行动的系统。中国电子技术标准化研究院定义为利用数字计算机或由数字计算机控制的机器模拟、延伸和扩展人的智能，感知环境、获取知识并实现最优结果的理论方法技术及应用系统。从文明高度看，AI是人类理解和重构智能的产物，《荀子·劝学篇》“君子生非异也，善假于物也”可用来形容AI是人类可依托的最高智慧形态。

按智能程度可分弱AI、强AI、超AI。弱AI即狭义AI，只能解决特定问题，如IBM深蓝、AlphaGo，智能诊疗、智能客服等，迁移能力弱、无自我意识。强AI即通用AI，具备独立意识和知觉，能自主应对环境。共识能力包括感知结构化非结构化信息、自主思考、自主学习、制定目标和计划、交流沟通。Gartner2021年AI成熟度曲线预计通用AI成熟需10年以上，业界如DeepMind Demis Hassabis、谷歌AI Jeff Dean、斯坦福李飞飞等预测强AI或需到2099年。强AI在伦理道德上也有争议。各国标准正在预估风险。

超AI指智能远超人类或强AI。牛津大学尼克·博斯特罗姆定义为在几乎所有感兴趣领域都远超人类认知表现的智能。有人认为超AI是人与计算机高度融合，也有人认为通用AI出现后会在记忆、知识储备、并行处理上超越人类，成为新物种。博斯特罗姆指出生物神经元工作频率约200Hz，远慢于2GHz微处理器；信号传输速度也远低于电子通信，扩展协同能力上计算机更具优势。

AI的三大学派
符号主义又称逻辑主义、心理学派或计算机学派，认为AI源于数理逻辑。20世纪30年代数理逻辑用于表示智能行为，1956年前后艾伦·纽厄尔等人编写的“逻辑理论家”证明38个数学定理。20世纪80年代启发式程序、专家系统、知识工程蓬勃发展。代表人物艾伦·纽厄尔、希尔伯特·A.西蒙。

连接主义又称仿生学派或生理学派，认为AI源于对人脑模型的仿生。20世纪60-70年代感知机研究兴起后陷入低谷。1982年霍普菲尔德提出霍普菲尔德神经网络，1986年鲁梅尔哈特等人提出误差反向传播算法，随后卷积神经网络、深度信念网络、深度神经网络训练方法相继出现，21世纪初在计算机视觉、语音识别、语义理解带来突破。

行为主义又称进化主义或控制论学派，认为AI源于控制论，即感知、控制和行为反馈系统。20世纪40-50年代控制论成为重要思潮，模拟自寻优、自适应、自学习。推动智能控制和智能机器人发展，20世纪末作为新学派出现。21世纪智能机器人在工业制造等领域取得成功，如波士顿动力机器狗、行走机器人等。

AI的发展历程
第一阶段20世纪50-80年代，数字可编程计算机出现，符号主义繁荣，因运算能力不足，常识认知和推理难突破，1970年后进入低谷。

第二阶段20世纪80-90年代末，连接主义和符号主义共进，人工神经网络、反向传播算法突破，专家系统获得资本和研究热情，计算机发展带来第二波高潮，但数据获取、知识规则局限和构建成本高昂导致再次低谷。

第三阶段21世纪初至今，大数据积累、算力大幅提升、算法革新，以深度学习为代表的第三波热潮兴起。

从学派看，第一代AI对应符号主义，第二代AI对应连接主义。清华大学AI研究院院长张钹院士提出第三代AI理念，即融合知识、数据、算法、算力四要素的可解释和鲁棒的AI，发展安全可信可靠可扩展技术。

从智能化程度看，可分为计算、感知、认知、意识四个阶段。计算是基础，算力增长带来问题解决能力提升。感知智能让计算机理解数字化物理世界，会听会说会看会认。认知智能让机器理解思考解决问题。意识智能是Manuel Blum夫妇2020年提出的构建可计算意识模型。深度学习在感知智能和认知智能上带来飞跃，意识智能的到来只是时间问题。
