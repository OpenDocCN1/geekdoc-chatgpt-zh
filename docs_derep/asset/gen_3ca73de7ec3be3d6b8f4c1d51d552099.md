题目：有一个分数，分母比分子 3 倍的数值少 7，且该分数与 2/5 相等，求分子是多少？（答案：14）

步骤1：把分子记作 x。
步骤2：按照题意，分母可以写成 3x - 7。
步骤3：列出等式 x / (3x - 7) = 2 / 5。
步骤4：交叉相乘后得到 5x = 2(3x - 7)。
步骤5：化简得 5x = 6x - 14。
结论：解得 x = 7。
