# 第 7 章 BERT 微调数学原理深度拆解

这条评论一共 330 个单词，句子的总数是 20 句。

长文本怎么处理目前没有标准答案，需要结合数据实际情况来尝试。先看看《How to Fine-Tune BERT for Text Classification?》这篇论文，原文可在这里下载 https://arxiv.org/pdf/1905.05583.pdf。论文从输入构造、下游任务到预训练等环节都做了梳理。关于截断，最直接的做法就是丢弃一部分 token，赌剩下的信息足够完成任务。丢弃的方式有多种：只留开头、只留结尾、中间删掉。论文在 IMDb 电影评论上的实验发现，保留开头 128 个 token 再加上结尾 382 个 token 效果最好。这样加起来 510 个 token，留出位置给开头的 CLS 和结尾的 SEP。之所以这样好，可能因为人们写影评习惯把总的观感放在开头和结尾。

另一种思路是分块 Chunking，把超长文本切成多个 512 的片段分别得到 embedding，最后再融合，比如求平均。但实验里这些方法都没能超过简单的截断。

如果不想截断，还可以改模型本身。Longformer 来自 Allen AI，BigBird 来自 Google，两者都能处理比原版 BERT 长约 8 倍的序列。BigBird 是在 Longformer 之后的做法，基本保留了 BERT 的结构，只是用稀疏注意力换取更长的输入长度。
