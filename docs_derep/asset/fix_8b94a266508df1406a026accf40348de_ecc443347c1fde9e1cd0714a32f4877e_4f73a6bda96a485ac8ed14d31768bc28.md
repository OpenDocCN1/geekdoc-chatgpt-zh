# 精选页实现全拆解

这套示例把一个新闻类精选页的搭建思路讲得很透。数据层采用分批加载并累加的策略：先检查本次接口是否出错，出错就输出日志并停止；如果返回结果提示还有后续数据，就让页码自增、把新条目接在已有列表后面再继续拉取；当全部加载完毕后把最后一条数据合并进去并输出完整数组。

页面初始化阶段会把顶部导航标题设为“精选”。全局配置定义了三个可达页面，并统一了窗口的背景、导航栏颜色和文字样式；底部标签栏对应三个入口，图标会随选中状态切换。页面配置开启了下拉刷新能力。

首页视图以容器为根，依次排列广告条、轮播区和列表区。列表通过循环渲染，每项采用左右分栏，左侧展示标题、来源和日期，右侧放置缩略图。

视觉上整体底色为浅灰，卡片为白底，头部留有内边距，轮播区高度固定，列表项使用弹性布局横向排列，标题文字做了两行省略处理。

网络层被封装成独立工具对象，用 Promise 包装异步请求。提供两类接口：一条获取名言数据，一条分页获取微信文章。请求成功时把数据 resolve 出去，失败时 reject 异常，便于上层调用。

      pageSize:this.data.pageSize

    },

    success:(res) => {

      if (res.error){

        console.log("接口请求出错：" + res.error);

        return

      }

      //如果还有数据，则继续请求

      if (res.result.hasMore) {

        //继续请求

        this.data.page = this.data.page+1;

        this.data.dataArray = this.data.dataArray.concat(res.result.data);

        this.getTeachers();

      } else {

        //请求完所有教师数据

        this.data.dataArray = this.data.dataArray.concat(res.result.data);

        console.log(this.data.dataArray);

      }

    },

    fail:function(error) {

      console.log(error);

    }

  });
