#### 3.2.1 拆需求：从“货架争夺战”定技术指标

**业务痛点有多疼？**
线下终端是快消品的“主战场”，货架黄金位、排面占比直接决胜负。但执行端问题层出不穷：必销品断货、新品被挤冷宫、陈列歪瓜裂枣、物料摆设成摆设。数据说话：缺货会让品牌方流失 **46%** 购买意向者，零售商流失 **30%**。要管住成百上千家门店，靠人跑断腿不现实，必须上 AI——用商品识别技术辅助人工查陈列，才能实现“降本增效”。

**技术任务怎么定？**
业务需求落地为**目标检测任务**：给张货架图，把所有目标商品框出来，报出类别和坐标。选型直接锁定 **EasyDL 零售行业版**，零代码定制专属模型，最短路径拿结果。

#### 3.2.2 备数据：模型好坏，数据定乾坤

数据环节三板斧：**采、洗、标**。本项目核心素材就两类：**SKU 单品图** 与 **实拍场景图**。

> **一句话区别**：单品图非训练必选项，但能用“合成增强”技术低成本喂给模型学多角度特征，省下采集标注真实场景图的大钱；实拍图是训练的“主粮”，必须来自真实业务现场。

##### 1. 采集：标准不降，上限才高

**【单品图：平台库里现成，缺啥补啥】**
平台内置饮品、日化两大类成品库，上百个 SKU，每款自带 50+ 角度照。绝大多数情况**不用自己拍**，跑完首轮看效果，哪个 SKU 识别拉胯，针对性补拍死角照即可。若真要自拍，守住四条线：

| 维度 | 硬指标 |
| :--- | :--- |
| **内容** | 单图单品；纯色背景且与主体色反差大（参考 [PRE0]）；光照覆盖真实场景冷暖色温差异。 |
| **清晰度** | 分辨率 ≥ 1920×1080，器件 ≥ 200 万像素。 |
| **角度** | 货架场景必须覆盖**水平、俯视、仰视**三视角（参考 [PRE1]）；无人货柜主俯视；结算台以水平/俯视为主，酌情加仰视。 |
| **数量** | 起步建议：各角度 **10 张/款**（详见表 3-1）；地堆场景建议直接在实拍图里覆盖角度。 |

**【实拍图：源头一致，设备对齐】**
*   **设备对齐**：巡店用啥拍（手机/巡店机），采集就用啥拍；结算台用自带摄像头，货柜用货柜摄像头。分辨率建议见表 3-2。
*   **看得清才是硬道理**：肉眼能辨清每个商品特征（参考 [PRE2]）。
*   **角度别作死**：货架场景**正面硬刚为主，微倾斜能忍，大倾斜免谈**（参考 [PRE3]），透视变形会直接毁识别率。
*   **起训门槛**：首训每 SKU 至少 **20 张** 已标注实拍图。平台自动 7:3 切分训练/测试集；样本不足会导致 mAP、精确率、召回率“三连跪”。

##### 2. 洗数据：平台准入门槛
*   格式：PNG/JPG/BMP/JPEG
*   单图 ≤ 4MB
*   长宽比 ≤ 3:1，长边 < 4096px，短边 > 30px
*   压缩包仅 ZIP，≤ 5GB

##### 3. 标注：质量生命线，容错率极低
单品图免标注；实拍图标注规范执行力直接决定模型上下限。

*   **框选黄金律**：**紧贴目标外轮廓的最小外接矩形框**（参考 [PRE4]）。
*   **遮挡处理分场景**：
    *   货架/货柜：露出 **>70% 且保留核心识别特征** 才框。
    *   无人货柜/结算台：**只框露在外面的部分**（参考 [PRE5]）。
*   **相似品“强制分户”防混淆**（参考 [PRE6]-[PRE8]）：
    1.  同品牌不同系列/口味/包装；
    2.  同款不同规格（如 330ml vs 500ml）；
    3.  高度神似竞品（色/型/材质酷似）。
    > **铁律**：把相似品归同一类，误识别率飙升。
*   **避坑指南：拒绝“错标”与“漏标”**（参考 [PRE9]-[PRE11]）：
    *   **错标高发区**：同款不同规格/口味/包装，最易误贴同一标签。
    *   **漏标三大元凶**：
        1.  **角度偏见**：只标正面，侧面/背面视而不见（[PRE9]）。
        2.  **粗心大意**：目视扫描未全覆盖（[PRE10]）。
        3.  **遮挡误判**：明明露特征 >70% 却因犹豫漏标（[PRE11]）。

##### 步骤 1：新建模型 & 录入 SKU 库

1.  **进场**：登录实训系统 → 启动 “AI 平台实验” 中的 EasyDL 入口（[PRE13]）。
2.  **选型**：点 “立即使用” → 勾选 **“零售行业版”**（[PRE14]） → 登录账号。
3.  **建模**：左侧栏 “我的模型” → “创建模型” 填信息（[PRE15]-[PRE16]）。
    *   **模型名**：业务导向命名，如 “饮料检测”。
    *   **归属/场景**：个人 / 普通货架-货柜。

5.  **建 SKU**：点列表 “创建 SKU”，按提示填核心字段：

    *   **增强素材**：上传单品图用于合成增强，提升模型鲁棒性。
