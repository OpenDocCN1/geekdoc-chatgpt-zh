### 5.3 财务指标计算与自定义
财务指标是观察企业健康的窗口，反映运营效率、盈利能力和资本结构等核心信息。但手工算这些指标很容易被繁琐公式缠住，难以聚焦指标背后的真实含义。业务和市场变化快时，传统指标也常跟不上实际。AI的介入让计算更快更准，还能按企业特点定制指标，使分析更贴近经营现实。

#### 【演示 1】常规财务指标计算
算资产负债率、流动比率、净利润率这类基础指标是财务日常。像通义这样的工具可以自动完成。

假设拿到XX公司202X年的资产负债表，把文件上传或直接复制表格内容到通义对话框，要求它算偿债能力指标，如资产负债率、流动比率等。结果如图 5-16 所示。

通义读取后几秒内就给出完整结果，还顺带算了速动比率。财务人员可以直接复制到报告里，省去大量手工运算。

具体算式如下：

**资产负债率**
资产负债率 = 总负债 / 总资产
期末：总负债 330000元，总资产 800000元
330000 / 800000 = 0.4125 即 41.25%

**流动比率**
流动比率 = 流动资产 / 流动负债
期末：流动资产 340000元，流动负债 180000元
340000 / 180000 = 1.89

**速动比率**
速动比率 = (流动资产 - 存货) / 流动负债
期末：流动资产 340000元，存货 90000元，流动负债 180000元
(340000 - 90000) / 180000 = 250000 / 180000 = 1.39

通义会依据现金流、风险和周期自动算出加权回报，如图 5-18 所示。

好的，我们直接计算项目1的WROI。

$NPV_{adj} = 100,000$

$I = 50,000$

$R = 10$

$T^a = 1.5$

$CF_{score} = 0.9$

使用公式：

$WROI = \frac{NPV_{adj}}{I} \times (1 + \frac{R}{100}) \times (\frac{1}{T^a}) \times CF_{score}$

计算步骤：

基础ROI: $\frac{100000}{50000} = 2.0$

风险调整后的ROI: $2.0 \times 1.1 = 2.2$

周期加权后的ROI: $2.2 \times \frac{1}{1.5} = 1.4667$

最终WROI: $1.4667 \times 0.9 = 1.32$

项目1的WROI为 **1.32**。
