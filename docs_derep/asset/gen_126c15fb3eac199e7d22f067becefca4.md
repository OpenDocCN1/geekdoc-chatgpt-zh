## 2.6 鱼骨图：因果可视化工具

鱼骨图又叫因果图或石川图，用分支结构呈现结果与成因的关系。它以鱼头的形象承载结果，以鱼骨的分支展示影响因素，图 2-42 就是一个项目延期原因的分析示例。

[PRE1]

图 2-42 项目延期原因的分析鱼骨图

基本构成有三部分。

1. 鱼头：代表需要分析的问题或最终结果；
2. 主骨：代表影响结果的主要类别，常见有人员、机器、方法、材料、环境等；
3. 小骨：属于主骨下的具体影响因素。

核心价值体现在四点。

1. 直观呈现结果的潜在成因，尤其能挖掘容易被忽略的根源；
2. 梳理各因素间的关联，帮助锁定关键驱动因素；
3. 为解决问题提供清晰思路与行动方向；
4. 汇聚多方观点，形成共识。

### 2.6.1 项目管理中的鱼骨图实践

鱼骨图通过可视化因果链，帮助管理者快速定位项目偏离计划的根源并制定针对性改进。以项目延期为例，可以用鱼骨图拆解以下几类诱因。

资源短缺：专业人员不足或关键设备无法到位，导致工期被拉长。

任务冲突：多项任务争夺同一资源，相互制约拖慢整体进度。

沟通不畅：部门或人员间信息传递不顺，计划执行出现偏差。

风险事件：技术故障或质量问题频发，需追加工作量。

其他未知因素：尚需进一步追踪与分析。

借助鱼骨图，管理者能清楚看到哪些因素对延期影响最大，进而优化资源配置、调整任务顺序、强化沟通机制或加强风险管控，把进度拉回预期区间。

### 2.6.2 ChatGPT 如何辅助绘制鱼骨图

ChatGPT 在绘制鱼骨图时可以起到不错的辅助作用。

1. 提炼关键信息。模型能读懂人工输入的问题描述，从中提取结果、影响因素及其关联，为绘图提供素材基础。
2. 搭建框架结构。基于提炼的信息，模型会给出鱼头、主骨与各级小骨的初步框架，人工再结合业务知识修正补充。
3. 生成初稿。框架确定后，模型可自动输出鱼骨图的初稿，包括节点表述和关系箭头，人工据此调整表述与逻辑。
4. 分析与解读。模型还能基于鱼骨图分析关键成因、解释因素间的相互作用并给出改进建议，辅助决策。

不过模型在处理复杂概念与逻辑时仍有局限，自动生成的框架和内容必须人工复核，尤其在专业领域更需校对。此外，模型难以完全把握人工沟通背后的深层意图，这会影响分析的精准度。

因此 ChatGPT 适合承担初稿生成、信息抽取与初步分析的工作，而准确性校验、框架调整和最终决策仍要依赖人工。两者协同才能产出高质量的鱼骨图与解决方案。

总体来看，ChatGPT 是绘制鱼骨图的理想协作者，但人工主导不可替代。随着模型能力提升，人机协同在鱼骨图应用中的深度会进一步增强。

# 第 3 章 项目启动阶段的 ChatGPT 应用

ChatGPT 在项目启动期能提供较强支撑，尤其在选题判断、需求分析和文件生成方面效果明显。但其短板也很清晰：评估项目价值的能力有限，需求分析深度不足，生成的文件仍需团队精校细改。因此它更适合作为助手，关键判断与调整仍由人来完成。随着技术进步，其在启动阶段的作用会更突出，但人的核心角色不会被取代，人机协同是智能化项目管理的最佳实践。

## 3.1 ChatGPT 助力选题与范围界定

在启动阶段，ChatGPT 能帮助团队对多个备选选题进行研判，挑出最具可行性与价值的方向。主要作用有三点。

（1）优缺点对比。团队可向模型描述多个选题概念，模型会从技术难度、市场前景、资源可得性等角度进行优劣分析，辅助权衡决策，避免“眼高手低”。

（2）范围校准。选题确定后，范围界定也至关重要。模型可通过交互判断哪些任务属于项目必需，哪些属于外延风险较高的部分，建议剔除或延后处理，帮助锁定最佳范围。

（3）决策参考。模型能结合行业报告、市场数据、技术路线图等信息为每个选题提供参考依据，供团队对照决策，减少主观偏差。当然模型研判质量仍需提升，最终判断在人。

ChatGPT 在商业价值与潜在回报的判断上仍有局限，这需要更多数据积累与模型改进。因此在选题中它可作为有效助手，但关键决策必须人工把关。团队与模型协同互动，才能做出更优选择。
