# 第8章
# ChatGPT 在数据可视化中的应用

数据可视化即用图表呈现数据，让信息更直观。在分析流程中它必不可少，虽然 ChatGPT 暂时无法直接按要求绘图，但能在选型、建议、指导和解读等环节提供助力：

(1) 推荐图种：依据数据特征与表达目的给出合适的图表建议，如时间序列偏向折线图，分类数据可考虑柱状图或饼图。
(2) 给出可视化建议：结合数据集特点与使用场景，提示配色、图例、标注等做法。
(3) 指导制作：说明在不同软件中实现目标效果的操作路径。
(4) 图表解读：从图表中提炼趋势、异常点、关联等，以文字形式输出。
(5) 叙事化呈现：将图表与分析结论融合，形成连贯的故事。

下面逐步观察模型在可视化环节的发挥。

# 8.1 选择合适的图表类型
可向模型询问常见图种、适用场景与选型原则，整理结果如下。

## 104 | 第8章 ChatGPT在数据可视化中的应用
常用的图种及其适用情境与选择思路：

+ 1. 折线图：用于表现数据随时间或其他连续变量的变化轨迹，适合展示波动、长期走向或周期。
2. 柱状图：用于比较不同类别的数量或占比，纵向柱状图适合多类别，横向柱状图适合类别名称较长。
3. 饼图：用于展示各类别占整体的比例，类别过多时宜改用堆积柱状图或堆积面积图。
4. 散点图：用于探索两个连续变量之间的关系，识别相关性、聚类或离群点。
5. 箱形图：用于呈现分布特征，包含中位数、四分位数与异常值。
6. 热力图：用于表现两个类别变量的相关性或密度，适合大规模分布展示。
7. 地图：用于地理位置相关数据的分布或趋势呈现。

选型要点：

+ 1. 明确意图，确定想表达趋势、对比还是关系。
2. 结合数据类型，连续型与离散型对应不同图种。
3. 重视可读性，确保图表能清晰传达核心信息。
4. 匹配使用场景，如汇报或演示。
5. 保持简洁，避免过度复杂导致理解困难。

总体需综合数据类型、目标、场景与可读性综合判断。
