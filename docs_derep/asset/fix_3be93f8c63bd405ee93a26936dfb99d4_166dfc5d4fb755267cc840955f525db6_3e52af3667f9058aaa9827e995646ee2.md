# 新浪财经抓取与 DeepSeek 快速研判

把新浪财经的即时稿件变成可落地的投资线索，核心在于采集更稳、解析更准、推理更快。下面的工作流可以作为自媒体运营和量化研究的复用模板。

先做稳定采集。响应回来后立刻把字符集锁成 utf-8，避免中文乱码。HTML 交给 BeautifulSoup 配合 lxml 引擎处理，速度和容错都比较理想。

标题的取法做多层兜底。首选 h1.main-title，其次 h1.article-title，再去查 meta 的 og:title，最后才退到网页的 title 标签。拿到节点后优先读取 content 属性的值，没有 get 方法就用可见文本，统一剔除首尾空白，完全没命中就返回 标题未找到。

正文同样准备备选方案。先找 id 为 artibody 的容器，再尝试 class 为 article-content、content 的节点，最后用 itemprop 为 articleBody 的 div 收尾。定位到容器后只收其直属 p 标签的纯文本，去掉空段后用换行拼接，整体再清洗空白。找不到时返回 正文内容未找到，并把标题和正文封装成字典。

异常分两层处理。网络层 RequestException 时返回标题 请求失败，内容写 网络请求错误:… 并标记 error 为 True；其他解析类异常返回标题 解析失败，内容写 解析异常:… 同样标记错误。示例脚本里会打印状态 成功/失败、标题和内容，演示链接以 https://finance.sina.com.cn/roll/2025-04-14/doc-XXXXXX.shtml 形式调用。

解析完成进入模型研判。用 OpenAI 客户端连 deepseek-chat，把稿件交给一个角色清晰的财经专家。提示词明确语言中文、背景是多年全球与国内市场经验、人设严谨细致、受众为投资者和分析师。能力拆分为行业识别、行业剖析、影响评估、报告撰写等核心项，外加数据收集、市场调研、政策解读、沟通等辅助项。原则强调准确、及时、客观、全面，要求自动判定行业并评估对 A 股上市企业与主题板块的影响。
