步骤 1：将数据导入 Power Query

1. 在 Excel 中选中原始数据任意单元格。
2. 点击“数据” → “从表格/区域”或“Power Query” → “从表格”。
3. 确认范围并勾选“包含标题”，点确定，数据进入 Power Query 编辑器。

步骤 2：补齐地区列空值

• 在编辑器中选中“地区”列。
• 选择“转换” → “填充” → “向下填充”。
这样空的地区单元格会被上方最近的值填满。

步骤 3：逆透视年份列

1. 按住 Ctrl 依次选中 2020年、2021年、2022年、2023年、2024年。
2. 点击“转换” → “逆透视列” → “逆透视其他列”。
年份列会被合并为“属性”和“值”两列。

步骤 4：改名并调整顺序

• 拖动列顺序调整为 地区、商品、年份、销售额。
