# LangChain 实操：把《黑神话》数据变成可检索文档

把游戏设定表和维基资料变成可检索文档，LangChain 的加载器族正好能当搬运工。下面以《黑神话：悟空》的 CSV 和维基页为例，演示不同读取策略会得到什么样的数据。

## 1. 默认 CSVLoader 读取

直接调用 CSVLoader 读取指定文件，什么都不配置。此时会把第一行当作键名，后续每一行都封装成 Document 对象，内容是将列名与值拼接成一段文字，元信息记录了来源路径和行号。

from langchain.document_loaders import CSVLoader

file_path = "data/黑神话/黑神话悟空.csv"

loader = CSVLoader(file_path=file_path)

data = loader.load()

for record in data[:2]:

    print(record)

## 2. 自定义字段与分隔符

想改分隔符、引号或把列名改成中文，就用 csv_args 传参。下面示例把四列映射成 种类、名称、说明、等级。
[PRE1]python
loader = CSVLoader(

    file_path=file_path,

    csv_args={

        "delimiter": ",",

        "quotechar": "'",

        "fieldnames": ["种类", "名称", "说明", "等级"],

    }),
data = loader.load()

for record in data[:2]:

    print(record)

## 3. 用列名重写来源

## 7. 精准提取正文

通过 bs_kwargs 只保留 id 为 bodyContent 的主体区域，再用 bs_get_text_kwargs 统一分隔符并去除多余空格，得到的结果更纯净。
[PRE11]python
loader = WebBaseLoader(

    web_paths=[page_url],

    bs_kwargs={"parse_only": bs4.SoupStrainer(id="bodyContent")}, # 仅解析网页内容的主体部分

    bs_get_text_kwargs={"separator": " | ", "strip": True},

)

## 9. 恢复层级关系

利用 element_id 和 parent_id 把标题与其子节点关联起来，能保留原始层级。
[PRE16]python
from langchain_unstructured import UnstructuredLoader

from typing import List

from langchain_core.documents import Document

page_url = "https://zh.wikipedia.org/wiki/黑神话：悟空"

def _get_setup_docs_from_url(url: str) -> List[Document]:

    loader = UnstructuredLoader(web_url=url)

    setup_docs = []

    for doc in loader.load():

        if doc.metadata["category"] == "Title" or doc.metadata["category"] == "Table":

            parent_id = doc.metadata["element_id"]

            current_parent = doc # 更新当前父元素

            setup_docs.append(doc)

        elif doc.metadata.get("parent_id") == parent_id:

            setup_docs.append((current_parent, doc)) # 将父元素和子元素一起存储

    return setup_docs

docs = _get_setup_docs_from_url(page_url)

for item in docs:

    if isinstance(item, tuple):

        parent, child = item

        print(f'父元素 - {parent.metadata["category"]}: {parent.page_content}')

        print(f'子元素 - {child.metadata["category"]}: {child.page_content}')

    else:

        print(f'{item.metadata["category"]}: {item.page_content}')
