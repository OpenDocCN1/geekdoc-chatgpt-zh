7.1 Manus 如何引爆通用 Agent

2025 年 3 月，Manus 在中文互联网迅速走红。发布后舆论普遍看好，有人称其为 Agent 赛道的里程碑，也有人视作 DeepSeek 之后又一个现象级产品，认为它代表了人机协作的新阶段。

7.1.1 Manus 是什么

官方把 Manus 定位为首个通用型 Agent，本质是实现从指令到交付全流程闭环的 Agent 形态。用起来像一个自主性较强的助理，用户只需给出终极目标，后续的拆分与执行由系统自行完成。

和 DeepSeek 相比，Manus 更强调产品化打磨，比如任务拆分的可视化呈现和多模型按需切换，而非底层的模型原创。

以撰写带数据报表的股票研报为例，普通大模型需要用户一步步指路：先出大纲再填内容最后合并。而 Manus 能把复杂需求自动细化为若干子任务，几乎不用人工介入，最后交付一个带图带表的网页报告。

Manus 的主要意义在于让大众真正认识到 Agent 是什么，也为后来者提供了一种工程化落地的参考样本。走红之后，AutoGLM、Genspark、Skywork、扣子空间等一批通用 Agent 相继冒出。但受限于模型能力、架构设计与运行方式，目前的体验仍不成熟，响应慢、执行不稳、结果难预测都是明显短板。相信随着迭代，这一类产品会越来越接近改变生活的临界点。

7.1.2 Manus 的实现逻辑

Manus 在底层大模型之上做自主拆分，把复杂目标拆成可执行的子任务，并按需调用不同 Agent 或工具逐一完成。

架构层面依赖云上沙盒，AI 在隔离的独立机器里运行，不抢也不干扰用户本地设备，因此人下线后任务也能继续推进。

系统提示词里明确定义了回路机制、系统级权限与行为规范三层要素。

1. 推理行动回路
这是一个不断迭代的推理-行动闭环。收到指令后先分析拆解，选择合适工具如浏览器，在安全监控下执行并观察反馈。每个步骤结束后都会重新评估进度，决定继续、转向或求助，直至闭环完成。

2. 系统侧权限
根基是云端数字沙盒。Agent 在此环境中拥有近似管理员的权限，可跑命令行、开图形浏览器、装依赖、部署小应用，从而在标准化的数字环境里完成具体操作，为多步骤任务提供执行底座。

3. 行为准则
是一套用于约束决策的策略集。它规定了不同场景下的思考与行动方式，比如评估风险、优先用安全工具、规范汇报进度，并在遇到模糊或高风险操作时主动让用户接手。把原始能力转化为可预期、可靠的行为。

总体来看，Manus 是一个基于任务解析与结构化处理的多 Agent 协同架构。它先通过意图解析理解用户需求，抓重点、主动问清楚，再拆成可执行的小任务；借助浏览器操作、文件系统、命令行、通讯接口等工具集实现多模态处理，兼容 JavaScript、Python 等十几种语言与主流框架；执行引擎用动态规划与实时监控，遇到阻碍就自适应调整并给出备选方案；质检靠结果校验、代码测试与反馈学习闭环，同时严格遵守隐私、安全与道德红线。越用越熟的同时，受上下文窗口与沙盒隔离的限制，无法触达外部系统或越权操作。

7.1.3 开源替代路线

Manus 的付费加邀请制刺激了开源社区快速跟进。像 OpenManus 这样追求可控、低成本、技术透明的替代方案应运而生。

技术路线上，开源项目基本延续了 Manus 的多 Agent 协作思路：把自然语言指令自动拆解为逻辑子任务，分给搜索、编程、整理文件等专属 Agent 协同完成，并通过网络搜索、代码解释器、文件系统等工具链增强执行力。

与闭源产品的差异不仅是免费，更是透明和可演进。OpenManus 公开致谢了 Computer Use、Browser Use 等项目，技术来源清晰，开发者可以审计架构并做定制化优化，加速了整体生态迭代。

OpenManus 主要包含四块：
（1）Agent 模块。定义基础接口与核心实现，涵盖任务规划、ReAct 模式与工具调用。
（2）流程模块。定义工作流基类，管理 Agent 的获取、添加与状态流转，包含 not_started、in_progress、completed、blocked，并提供 FlowFactory 创建不同工作流。
（3）工具模块。提供各类工具脚本，同样基于 browser-use 库操作浏览器，支持导航、回退、刷新、网络搜索、元素互动、内容提取、标签管理等。
（4）提示词模块。内置 Manus、Planning、SWE、Toolcall 等 Agent 的系统提示词，以及指引下一步行动的 NEXT_STEP_PROMPT。

从 Manus 到开源替代品的演进说明，多 Agent 任务分解与工具调用已成共识，开源正在把 Agent 从封闭产品变为可审计、可修改的开放基础设施。

7.1.4 竞争格局

Manus 让市场清晰感受到通用 Agent 与对话大模型的本质差异：前者能自主操作电脑、调用浏览器、写代码。它的出现基本定义了这一品类的形态，也点燃了赛道竞争。

1. 扣子空间
2025 年 4 月 18 日，字节跳动推出消费级通用 Agent 扣子空间内测。定位是既像通用实习生又像领域专家，可无限扩展。它能自动分析需求、拆子任务、调用浏览器与代码编辑器，并以 PPT、网页、文档等形式交付。

在其发布前，字节于 2025 年 3 月开源了 TARS。TARS 界面左侧对话、右侧实时展示虚拟机操作，支持 MCP 协议并具备 GUI 交互能力。其视觉交互基于自研的 UI-TARS 模型，采用视觉-语言架构增强感知与推理，解析 GUI 元素并执行点击、输入等操作。扣子空间的浏览器调用与界面操作即基于此模型。整体来看，竞争焦点已从能不能操作转向怎么高效、开放地操作。

2. AutoGLM
智谱 AI 开发的移动端通用 Agent，核心是把大模型规划决策与机器人流程自动化 RPA 融合，让它像人一样直接操作手机 App 界面完成真实任务。

不依赖 API，而是依托 Android 无障碍服务，通过解析屏幕内容并模拟点击、滑动实现自动化，兼容性广但对 UI 稳定性敏感。

特点包括全流程自助、多模态环境感知与决策，以及在线强化学习带来的持续优化。它覆盖外卖订购、机票预订、新闻整理、论文摘要、手机清理、跨应用数据迁移等高频场景，并延伸出 AutoGLM-Web 与 GLM-PC，分别聚焦网页自动化与办公自动化，形成移动-网页-桌面全覆盖的解决方案。

3. Genspark
MainFunc 推出的超级 Agent，主打复杂数字与现实世界任务的执行。它不是单纯的对话接口，而是一个具备自主规划与执行能力的数字执行者。

架构采用混合 Agent 模式，不依赖单一模型，而是动态整合 DeepSeek 系列等多专属模型，形成内部专家委员会，按类型分派任务以平衡速度与准确性。

工具生态覆盖深度信息获取、现实世界交互如自动电话呼叫完成酒店预订与餐厅订座、内容与创意生成、数据分析等，并能直接生成个人页、交互网页、HTML 小游戏等可交付成果，体现思考即构建的能力。

4. ChatGPT Agent
2025 年 7 月 OpenAI 发布，由原 Operator 团队与 Deep Research 团队合并打造。它的突破在于技术路径：不是把浏览器、研究、代码执行等能力工程化拼接在模型外部，而是通过端到端统一训练将这些技能内化为单一模型的核心能力，更像一个能自主规划并使用多种工具的数字大脑。

它可集成文本与图形浏览器、终端命令行、图像生成器等工具。用户可用自然语言下复杂指令，如为下周客户会议准备简报，Agent 会自行检索、筛选、分析并生成 PPT 或文档；支持多轮对话与主动澄清，用户可随时打断、修改或接管控制权；高风险操作如购物、发邮件、处理个人信息默认需用户许可，模型内置严格防护，自动拒绝金融转账、法律建议等高风险请求，并对生物化学等领域风险采取最高级别处理。
