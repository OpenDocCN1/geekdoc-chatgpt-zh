科研提速全链路实战提示词手册

骨架搭好后，下一步要把抽象结构拆成可检验的预判。提示词在这一步的价值，是驱使大模型从多面给出假设备选，让研究者把潜在的研究方向尽数覆盖。

◎ 提示词示例：

请围绕已搭建的理论架构，生成一份假设产出矩阵。

+ （1）横向列出架构中的关键自变量。
+ （2）纵向列出架构中的关键因变量。
+ （3）对矩阵中每个交叉单元格：
   - 提出一条可检验的研究假设。
   - 简要阐述假设的理论依据。
   - 指出可能的边界条件或调节变量。
+ （4）对全部产出做初步筛选，标出最具潜力的3～5条。

二、研究设计阶段：从方法抉择到实验与数据采集的提示词设计

设计环节决定成败。恰当的提示词能让模型在方法挑选、方案制定与数据获取上提供更科学的支撑。下面围绕方法选型、实验调查设计、数据采集展开。

（一）方法选型与优化的模型决策支持

方法挑选直接影响议题回答的质量与后续执行。大模型可帮助研究者：

+ 依据议题推荐适配的手段。
+ 对比不同手段的优劣。
+ 给出手段组合的建议。
+ 针对特定情境优化手段应用。

要让模型有效完成上述任务，提示词宜遵循：

+ 明确给出研究议题与背景。
+ 要求模型考虑多种备选方案。
+ 引导模型进行适用性分析。
+ 鼓励模型提出创新性的手段组合。
+ 要求模型给出情境化的优化建议。

◎ 提示词示例：

请基于下列研究议题与背景，协助甄选并优化研究方法。

研究问题： [插入具体的研究问题]

研究背景： [简要描述研究背景和目标]

请完成以下任务：

+ （1）方法推荐：
   - 推荐3～5种或许可用的研究方法，涵盖定量、定性与混合。
   - 对每种方法简述其优势与局限。
+ （2）适用性分析：
   - 为每种方法对该议题的契合度打分1～5分。
   - 说明评分理由，兼顾目标、可行性与预期产出。
+ （3）方法组合建议：
   - 如有必要，建议2～3种方法的组合策略。
   - 解释组合如何互补以提升研究的全面性。
+ （4）创新方法探索：
   - 提出1～2种新兴或跨学科的方法。
   - 说明其可能带来的创新洞见。
+ （5）方法优化：
   - 针对最优方法或组合，提出3～5条具体优化建议。
   - 建议需贴合议题的特殊需求与潜在挑战。
+ （6）实施考量：
   - 点出选定方法在执行中可能遇到的主要挑战。
   - 为每个挑战提供应对策略。
+ （7）方法适配论证：
   提供不超过200字的简短论证，说明推荐方法为何最契合该议题。

请以结构化方式呈现，并在末尾给出简洁总结，强调所选方法如何最好地服务研究目标。

（二）实验/调查方案的模型协同设计与完善

方法确定后，需要落到具体的实验或调查方案。模型可提供创意性建议，提升方案的严谨与创新。有效提示词应覆盖设计要素、变量操作化、样本与质量控制等。

本环节模型可助力：

+ 生成多种实验/调查设计框架。
+ 协助变量定义与操作化。
+ 设计具体实验条件或问卷题目。
+ 提供抽样与数据收集流程建议。
+ 提出质量控制与伦理考量。

提示词设计原则：

+ 明确研究方法与目标。
+ 要求提供多套设计方案。
+ 引导深入思考变量操作与测量。
+ 兼顾实际可行性。
+ 关注数据质量与伦理问题。

◎ 提示词示例：

基于以下研究方法与研究目标，请协助设计并完善实验/调查方案。

研究方法： [插入选定的研究方法]

研究目标： [简要描述研究目标]

请完成以下任务：

+ （1）框架设计：
   - 提出3～5个可行的实验/调查设计框架。
   - 对每个框架简述优势与潜在局限。
+ （2）变量定义与操作化：
   - 明确自变量、因变量及可能的控制变量。
   - 给出每个变量的具体操作化方式。
+ （3）条件/题目设计：
   - 设计具体的实验条件或调查问题。
   - 解释其如何对应研究目标。
+ （4）伦理考量：
   - 指出可能的伦理风险。
   - 提供审查与保护措施建议。
+ （5）预实验建议：
   - 设计一个小规模预实验/预调查方案。
   - 说明如何利用预结果优化正式方案。
+ （6）方案评估：
   - 评估内部效度与外部效度。
   - 提出2～3个备选方案以应对局限。

请结构化呈现，并在最后给出不超过200字的总结，强调设计如何服务研究目标及需特别注意的关键点。

（三）数据采集策略与样本选择的模型助力方法

数据采集与抽样直接影响结果的可靠与代表性。合理策略能确保获取高质量、相关充分的数据。

本环节模型可助力：

+ 确定所需数据类型与来源。
+ 设计最佳抽样策略。
+ 建议样本规模与采集方式。
+ 提供质量控制与管理建议。
+ 识别潜在偏差与对策。

提示词设计原则：

+ 明确研究设计与目标。
+ 要求考虑多元数据来源与抽样方法。
+ 引导思考数据质量与代表性。
+ 考虑操作中的现实挑战。
+ 关注伦理与隐私。

◎ 提示词示例：

基于下列研究设计与目标，请协助制定数据采集策略与样本选择方法。

研究设计： [简要描述研究设计]

研究目标： [简要描述研究目标]

请完成以下任务：

+ （1）数据类型确定：
   - 明确所需的主要数据类型。
   - 列出每种类型的具体指标或维度。
+ （2）数据来源识别：
   - 建议3～5个可能的数据来源。
   - 评估各来源的可靠性与可获取性。
+ （3）抽样策略设计：
   - 推荐2～3种合适的抽样方法。
   - 说明各自的优势与局限。
+ （4）样本规模确定：
   - 建议合理样本量并给出理由。
   - 如适用，提供样本量计算方法。
+ （5）采集方法设计：
   - 设计具体采集方式如网络抓取、问卷、访谈等。
   - 给出每种方式的实施建议。
+ （6）纵向数据考量：
   - 如需纵向数据，提出减少流失的策略。
   - 建议有效追踪参与者的方法。
+ （7）多源数据整合：
   - 如涉及多源，提出整合策略。
   - 讨论如何保证一致性与可比性。
+ （8）数据质量控制：
   - 提出3～5条确保质量的具体措施。
   - 说明异常值与缺失数据的处理方式。
+ （9）伦理与隐私：
   - 指出采集过程中的伦理与隐私问题。
   - 提供保护措施建议。
+ （10）数据管理计划：
   - 建议存储与管理方式。
   - 提出安全保密策略。
+ （11）偏差识别：
   - 指出可能出现的采集偏差。
   - 提供降低偏差的具体策略。
+ （12）灵活性与应变：
   - 建议保持灵活性的做法。
   - 提出应对障碍的备选方案。

请结构化呈现，并在最后给出不超过200字的总结，强调策略如何保证代表性、可靠性与有效性，并指出关键环节。

三、研究分析阶段：定量、定性与可视化呈现的提示词设计

分析阶段是把数据转化为结论的核心环节。科学的提示词能帮助大模型高效完成定量分析、定性解读与可视化呈现。

（一）定量数据统计分析与假设检验的模型技巧

定量分析是把数字转化为洞见的过程。模型可助力数据清洗、描述统计、推断检验、高级建模与结果报告。

设计有效提示词的关键：

+ 明确数据格式与分析目标。
+ 要求解释每一步原理与结果含义。
+ 鼓励探索潜在模式与关系。
+ 引导评估统计显著性与实际意义。
+ 要求提供可视化建议。

◎ 提示词示例：

基于下列数据集与研究假设，请协助进行全面定量分析。

数据集描述： [提供变量、样本量等基本信息]

研究假设： [陈述待验证的假设]

执行以下任务：

+ （1）数据预处理：
   - 检测并处理异常值与缺失。
   - 进行必要变量转换如标准化。
+ （2）描述性统计：
   - 计算集中趋势与离散程度。
   - 生成相关矩阵识别初步关系。
+ （3）假设检验：
   - 选择并执行合适检验如t检验、ANOVA、回归等。
   - 报告检验结果、效应量与置信区间。
+ （4）高级分析：
   - 如适用，进行因子分析、聚类或其他模型。
   - 解释拟合度与关键参数。
+ （5）结果解释：
   - 详细说明结果与假设的关系。
   - 讨论统计显著性与实际意义。
+ （6）潜在问题识别：
   检查可能影响可靠性的统计问题如多重共线性。
+ （7）可视化建议：
   为关键结果提供2～3种可视化方案。

请提供结构化分析报告，并在末尾总结主要发现对假设的支持程度。

（二）定性资料编码与主题提取的模型协作方法

定性分析是对文本、访谈等非结构化数据的深度解读。

模型可助力：

+ 设计初始编码框架。
+ 执行文本自动编码。
+ 识别主题与模式。
+ 分析主题间关系。
+ 提供量化分析建议。

提示词设计原则：

+ 明确研究问题与数据性质。
+ 要求考虑多种编码方法。
+ 引导深入挖掘潜在模式。
+ 鼓励创新性解释。
+ 关注可信度与可转移性。

◎ 提示词示例：

基于下列研究问题与定性数据特征，请协助进行定性分析。

研究问题： [插入研究问题]

数据特征： [描述数据类型、来源、数量]

完成以下任务：

+ （1）编码框架设计：
   - 提出包含5～8个主要类别的初始框架。
   - 解释每个类别定义与编码标准。
+ （2）自动编码：
   - 对文本做初步编码。
   - 生成包含主类与子类框架。
+ （3）主题提取：
   - 基于编码识别主要主题。
   - 解释主题内涵与研究问题关联。
+ （4）主题关系分析：
   - 识别主题间关系与层级。
   - 构建主题网络图。
+ （5）定性量化策略：
   - 建议2～3种量化方法。
   - 说明如何增强说服力。
+ （6）创新解释视角：
   - 提出1～2个创新解释角度。
   - 说明其理论洞见潜力。
+ （7）可信度检验建议：
   - 推荐2～3种提升可信度的方法。
   - 说明应用方式。

请结构化呈现，并在最后给出不超过200字的总结，强调分析步骤如何全面回答问题及需注意的关键点。

（三）数据分析可视化呈现的提示词设计

可视化是将复杂结果转为直观图表的过程。具备多模态能力的大模型可提供建议并生成图表。

模型在可视化方面的能力：

+ 自动生成统计图表。
+ 创建交互式仪表板。
+ 辅助生成信息图表。
+ 制作动态或动画图表。
+ 优化布局与配色。

设计提示词关键点：

+ 明确数据特征与可视化目标。
+ 要求考虑多种可视化类型。
+ 引导优化清晰度与美观。
+ 鼓励创新技术探索。
+ 考虑受众与呈现环境。

◎ 提示词示例：

基于下列数据描述与可视化目标，请创建可视化系列。

数据描述： [插入数据集描述或链接]

可视化目标： [说明目的如趋势展示、比较分析]

生成以下内容：

+ （1）概览图：
   - 创建总体趋势概览图。
   - 清晰展示主要变量随时间变化。
+ （2）比较分析图：
   - 生成比较不同类别的图表。
   - 突出关键差异与相似。
+ （3）相关性可视化：
   - 创建展示变量相关性的图表。
   - 包含相关系数的表示。
+ （4）分布图：
   - 为关键变量生成分布图。
   - 标注中位数、四分位数等。
+ （5）高级可视化：
   - 创建创新可视化如桑基图、网络图。
   - 解释其独特洞见。
+ （6）交互式图表：
   - 如可能生成交互式仪表板。
   - 加入探索性交互元素。
+ （7）信息图表：
   - 设计综合性信息图表。
   - 兼顾信息量与视觉吸引。

对每个图表请提供标题、标签、配色说明及简短解读，并解释设计理念与传达效果。

四、研究完善阶段：结构优化、语言润色、格式规范的提示词设计

完善阶段提升报告整体质量，合理提示词可帮助调整结构、优化语言与规范格式。

（一）学术论文整体结构与逻辑优化的模型助力方法

论文结构与逻辑影响可读性与说服力。模型可评估结构优劣、提供重组建议、检查逻辑连贯、优化过渡、确保论点层次。

| 模型在结构优化中的作用 | 有效提示词设计 |
| :--- | :--- |
| 分析现有结构的优缺点 | 要求 模型 基于研究问题与论文目标，评估各章节相关性与重要性 |
| 提供结构重组建议 | 指导 模型 考虑学科规范并提出具体重组方案 |
| 检查逻辑流程连贯性 | 要求 模型 追踪主要论点发展并指出逻辑跳跃或断层 |
| 优化段落章节间过渡 | 引导 模型 识别关键连接点并提供改善建议 |
| 确保论点层次与递进 | 要求 模型 构建论点层次图并提出论证顺序优化建议 |

完成以下任务：

(1) 结构评估：
