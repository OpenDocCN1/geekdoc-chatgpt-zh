[PRE1]

这段实现里先确定了 Q、K、V 的维度大小，要做点积运算，K 与 Q 的维度必须保持一致。

`ScaledDotProductAttention` 类负责算出缩放点积注意力，把输入张量送进去后为每个位置生成一个权重向量。具体做法是先用三条不同的线性映射把输入投射到 Q、K、V 三个子空间，并把这些投射结果拆分成若干头。随后通过缩放点积注意力算出每个位置与其他位置的相关性分数，也就是先前提到的原始分数再做缩放得到 `scaled_weights`。接着用 softmax 对分数做归一化，得到最终的注意力权重 `weights`。该过程会计算 Q、K、V 之间的关联，并在 `attn_mask` 的指引下修正注意力分数。最后依据注意力权重合成上下文向量，这正是前面课程反复提到的 `attn_output`。

这段代码大家已经很熟悉了，唯一需要补充的是掩码的处理方式。在 `ScaledDotProductAttention` 类的 `forward` 方法里会接收一个 `attn_mask` 参数，这个掩码张量在编码器或解码器的输入阶段就已生成，用来标示哪些位置的注意力分数需要被忽略。它的形状与 `scores` 张量一致，可以逐元素操作。

代码里 `scores.masked_fill_(attn_mask, -1e9)` 是一次原地操作，会把 `scores` 中对应掩码值为 1 的位置替换成一个极小值 `-1e9`。这样在接下来的 softmax 中，这些位置的权重会趋近于零。于是计算上下文向量时，被掩掉的位置对结果的贡献几乎可以忽略。

实际使用里，注意力掩码可用来屏蔽填充位，也可在解码时防止模型窥探未来信息。这些掩码能够让模型集中在真实输入上，并在自回归任务中保证解码器不会提前接触到未来的内容。

代码一开始用全局变量设定了嵌入维度 `d_embedding` 以及注意力头的个数 `n_heads`，同时声明了批次大小 `batch_size`。

`MultiHeadAttention` 类实现了多头自注意力机制。其做法是将输入序列的 Q、K、V 分别映射到多个头上，对每个头单独执行缩放点积注意力，随后把各头的结果拼接起来，再经过一个线性层得到最终输出。为了让训练更稳定，这里加入了层归一化 LayerNorm。

小冰：还有个细节想确认一下，注释里说的“对输入做线性变换并重塑”，是不是就是为了得到多个头？

咖哥：没错，我展开讲一下。

- **线性变换**：在多头自注意里，Query、Key、Value 各自会经过三个不同的线性层 nn.Linear 进行变换。它们的作用是把输入的每个词向量即 d_model 维，映射到不同的表示子空间，以便模型从不同视角捕捉输入间的关系。三个线性层的输出维度分别为 d_k * n_heads、d_k * n_heads 和 d_v * n_heads，其中 n_heads 为头的数量，d_k 为每个头中 Key 与 Query 的维度，d_v 为每个头中 Value 的维度。
- **重塑与置换**：线性变换后，需要把输出张量重新整形以区分不同头。这里的 view 与 transpose 就是为此服务的。首先用 view 把每个输入的 (d_k/d_v * n_heads) 维度拆成 [n_heads, d_k] 或 [n_heads, d_v]。然后用 transpose 交换 seq_len 维与 n_heads 维，最终得到形状为 [batch_size, n_heads, seq_len, d_k] 的 Query 与 Key，张量、以及形状为 [batch_size, n_heads, seq_len, d_v] 的 Value 张量。这样就能把每个头的 Q、K、V 分开处理，实现多头并行计算。
