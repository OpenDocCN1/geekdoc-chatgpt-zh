把该条表达式拆开说明：

1. 地区补齐手法：
   - LOOKUP(ROW($A$5:$A$100), ROW(...)/(条件), $A$5:$A$100)
     通过行号回溯，让空置的地区单元格自动继承上方已填写的值，例如 A5 填“华北”，A6-A8 随之显示“华北”。

2. 行号定位思路：
   - MATCH(1, (地区=Q4)*(产品=Q5), 0)
     将两个布尔条件相乘，锁定同时满足地区与产品的唯一行。

3. 列号定位思路：
   - MATCH("2022年", $C$3:$Q$3, 0) 先在第3行找到年份起点，如2022年在 C3。
   - LEFT($Q$6,1)-1 从“2季度”取出数字2，再以年份起点向右偏移。

4. 区间收窄：
   - 仅使用 $C$5:$Q$100 这块真实区间，避免整列遍历，加快运算。
