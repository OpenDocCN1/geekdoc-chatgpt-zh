def semantic_enhancement(original, translation):

    model=SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

    original_embedding=model.encode([original])

    translation_embedding=model.encode([translation])

    similarity=cosine_similarity(

    original_embedding, translation_embedding)[0][0]

    if similarity < 0.8:

整体实现可以拆成五个递进环节来理解。

- 第一步，模型准备。load_translation_model 根据源语和目标语拼装 Helsinki-NLP/opus-mt 的名字，拉取对应的 Marian 分词器与模型，完成初始化。
- 第二步，初稿生成。translate_text 将待译内容编码成 tensor，调用 generate 得到译文序列并解码，产出第一版结果。
- 第三步，语法润色。grammar_correction 借助 language_tool_python 的 LanguageTool 对中文输出做检查与自动修正，使表达更符合目标语言规范。
- 第四步，语义校验。semantic_enhancement 使用 SentenceTransformer 的 paraphrase-multilingual-MiniLM-L12-v2 为原文与润色后译文生成向量，用余弦相似度衡量一致性，低于 0.8 时在尾部追加语义校正提示。
- 第五步，统一对外。/enhanced_translate/ 把模型推理、语法润色、语义校验串起来，一次返回源文本、初稿、润色稿和增强后文本。

这种分层递进的设计在保留原意的同时提升可读性，也为搭建可复用的多语言翻译服务提供了清晰思路。
