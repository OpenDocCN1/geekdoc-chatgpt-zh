3. 视觉素材先行：闲鱼用户浏览时先看图再看字，文案再出色，若主图不精或缺少短视频很难获得停留。
4. 互动必须闭环：不能只发信息不回音，回复速度与态度直接影响买家信任与成交达成。
5. 规则底线要熟：提前梳理平台禁止上架的品类与交易限制，避免违规导致下架或限权。
