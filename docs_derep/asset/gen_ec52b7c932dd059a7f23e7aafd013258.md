## 5.2.4 Q-Learning 原理拆解

该方法实质采用了 TD(0) 的估计思路。当前对 $Q^*$ 的估计通过 $\pi(x)=\arg\max_a \hat{Q}^*(x,a)$ 诱导出一个贪婪策略，即总是挑选估计 Q 值最高的动作。

Q-Learning 的目标是在动态环境中依据外部反馈学会挑选更优乃至最优动作，本质上是动态决策的学习。若智能体在完全未知的环境中靠试错探索，效率低下且容易产生次优结果，此时可以借助过往任务积累的经验来构建环境模型，以辅助动作选择并规避风险。环境模型可以看作把当前状态-动作对 $(s_t, a)$ 映射到下一状态和即时奖励 $(s_{t+1}, r)$ 的函数。

在标准框架上引入经验知识的变体，会额外加入一个经验函数 $E: S \times A \rightarrow R$，它在决策阶段影响动作选取，帮助加快收敛。

经验用一个四元组 $\{s_t, a_t, s_{t+1}, r_t\}$ 来刻画：即在状态 $s_t$ 采取动作 $a_t$，导致状态转移到 $s_{t+1}$ 并收到强化信号 $r_t$。

改进版里 $E(s,a)$ 负责保存在状态 $s$ 下执行动作 $a$ 的相关经验。难点在于学习开局如何获取这些先验，即如何构造 $E(s,a)$，这与具体应用场景紧密相关。比如路径规划任务中，撞墙事件即可产生负向经验。经验函数主要介入动作选择，规则写作：

$\pi(s_t) = \arg\max_{a_t} [\hat{Q}(s_t, a_t) + \varepsilon E_t(s_t, a_t)]$

其中， $\varepsilon$ 为一常数，代表经验函数的权重。

Q-Learning 衍生出不少变体，其中包括 Watkins 提出的 Q($\lambda$)-Learning。它本质上是策略无关的方法，学习用的策略可以与行为策略分离。在逼近贪心策略时，通常会搭配一种探索策略，偶尔根据当前 $Q_t$ 挑选非最优动作。

假设在 $t$ 时刻更新状态-动作对 $(s_t, a_t)$，随后智能体在接下来的两步都遵循贪心选择，即每次取即时奖励最大的动作，但到第三步时转而采取一次探索性非贪心动作。对于贪心策略下的价值评估，只要后续仍保持贪心，中间的回报就可以沿用。于是前两步的回报仍有效，而第三步及以后的回报对当前贪心目标已不再具有参考价值，n≥3 时均可忽略。

正因如此，Watkins Q($\lambda$) 与 TD($\lambda$) 和 Sarsa($\lambda$) 的追溯范围不同。它不会贯穿整个 episode，而是追溯到首次出现探索动作为止。若 episode 内完全没有探索，则追溯至 episode 结束。它会以首次探索动作之后采取的动作价值来反向更新该探索动作。

## 5.2.6 DP / MC / TD 方法对比

DP 指动态规划方法，借助环境转移概率模型，通过 Bootstrapping 计算各分支奖励的加权和。

MC 指蒙特卡洛方法，采样一次完整学习循环获得的累计奖励，然后经多次采样，用实际获得的累计回报逼近真实状态值函数。

TD 方法是时序差分方法，与蒙特卡洛类似，仍采样一次学习循环中的即时反馈，同时借鉴动态规划采用 Bootstrapping 估计状态值函数，再通过多次迭代逼近真实值函数。

## 5.2.7 DQN 如何理解

DQN 是强化学习领域里将深度学习与传统 Q-Learning 结合的开山之作，后续大量研究均以此为基础。不严谨地说，DQN 就是深度学习加 Q-Learning。在状态动作空间离散且维度不高时可用 Q-Table 存储每个状态动作对的 Q 值，而当空间高维连续时，Q-Table 已不可行。

于是把 Q-Table 的更新转化为函数拟合问题，让相近状态产生相近输出。如下式，通过更新参数 θ 使 Q 函数逼近最优 Q 值

Q(s, a; θ) ≈ Q' (s, a)

因此，高维且连续的状态使用深度神经网络自动提取复杂特征非常合适。

需要留意的是 DQN 使用了经验回放技巧，这是因为深度神经网络属于有监督学习模型，要求数据独立同分布，而 Q-Learning 产生的样本前后相关。为打破关联，经验回放通过存入经验池并从中随机采样来消除时序相关性。

## 5.3 策略函数学习思路

强化学习方法大致分为值函数学习、策略函数学习，或两者结合。

策略梯度方法不依赖值函数，主要流程是用梯度上升优化参数 θ，使目标函数 $J(\theta)=E_{\tau\sim p_\theta(\tau)}(G(\tau))$ 最大。

目标函数 $J(\theta)$ 关于策略参数 θ 的导数如下，其中 $G_{t:T}(\tau)=\sum_{t'=t}^{T-1} \gamma^{t'-t} r_{t'+1}$ 指从 t 时刻开始得到的总回报。

∂J(θ)/∂θ = ∂/∂θ ∫ p_θ(τ)G(τ)dτ = E_{τ∼p_θ(τ)}[∑_{t=0}^{T-1}(∂/∂θ log π_θ(a_t|s_t) γ^t G_{t:T}(τ))]

## 5.4 深度强化学习发展脉络

DRL 即深度学习与强化学习的结合，可直接从高维原始数据学习策略。这是因为状态动作空间低维离散时可用 Q 表存储对应值，而高维连续时则需借助神经网络通过参数更新让 Q 函数逼近最优值。
