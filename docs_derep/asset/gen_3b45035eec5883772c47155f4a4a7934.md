# PyTorch 显存与量化实战对比

在模型上生产环境部署时，显存占用和推理速度往往比精度更先卡脖子。下面用两组可复现的实测，把默认显存管理、自建内存池、以及 FP32 / INT8 动态量化 / FP16 三种精度放在一起看效果。

## 自建内存池能改变峰值显存吗

先在 GPU 上跑一个 DeepNet，输入是 32x3x224x224 的随机张量，连续推理 50 次。测试前会清空缓存并同步，保证计时干净。

默认方式直接使用 PyTorch 的显存分配，记录 50 次累加的总耗时和峰值显存占用 MB。

随后做一个简易的内存池：提前申请一块约 1e7 个元素的 cuda.FloatTensor 作为大块，内部用指针 ptr 顺序分配，reset 时指针归零。PooledDeepNet 在前向里先从池子里取一块临时存储，把输入展平复制进去模拟复用，再调用父类前向。

同样清空缓存、重置池子和峰值统计后，再跑 50 次，得到内存池方案的总耗时和峰值显存。最后输出四项指标：默认管理的总时间、默认峰值、池化管理的总时间、池化峰值，便于直接对比。

## 量化对体积、速度和一致性的影响

第二组实验用一个极简的 SimpleCNN：3 通道 3x3 卷积 + ReLU + 全连接输出 10 类，输入 1x3x32x32。

准备三份模型：
* FP32 原始模型
* 用 torch.quantization.quantize_dynamic 对 Linear 层做动态 INT8 量化
* 把 FP32 模型转为 half，得到 FP16

模型大小通过保存 state_dict 到临时文件 temp.p 再读文件大小估算，单位 MB。

推理时间测量统一搬到 cuda，100 次循环，开始和结束都同步，返回总耗时。INT8 模型推理时输入仍保持 float。

为了看精度损失，用 FP32 的输出作为基准，分别计算与 INT8、FP16 输出的绝对差值的最大值 diff_int8 和 diff_fp16。

最后打印三类精度的模型大小对比。

import torch
import torch.nn as nn
import torch.quantization
import time
import os
# 定义一个简单的卷积神经网络
class SimpleCNN(nn.Module):
    def __init__(self):
        super(SimpleCNN,self).__init__()
        self.conv=nn.Conv2d(3,16,kernel_size=3,padding=1)
        self.relu=nn.ReLU()
        self.fc=nn.Linear(16*32*32,10)
    def forward(self,x):
        x=self.conv(x)
        x=self.relu(x)
        x=x.view(x.size(0),-1)
        x=self.fc(x)
        return x
# 创建并准备模型
model_fp32=SimpleCNN()
model_fp32.eval()
input_tensor=torch.randn(1,3,32,32)        # 定义随机输入数据
# 定点量化（INT8）
model_int8=torch.quantization.quantize_dynamic(
    model_fp32,{nn.Linear},dtype=torch.qint8
)
model_int8.eval()
# 浮点量化（Float16）
model_fp16=model_fp32.half()
model_fp16.eval()
# 测量模型大小
def get_model_size(model):
    torch.save(model.state_dict(),"temp.p")
    size=os.path.getsize("temp.p")/1e6  # 转换为MB
    os.remove("temp.p")
    return size
size_fp32=get_model_size(model_fp32)
size_int8=get_model_size(model_int8)
size_fp16=get_model_size(model_fp16)
# 测量推理时间
def measure_inference_time(model,input_tensor,dtype=torch.float32):
    model=model.to('cuda')
    input_tensor=input_tensor.to('cuda').to(dtype)
    with torch.no_grad():
        torch.cuda.synchronize()
        start_time=time.time()
        for _ in range(100):
            output=model(input_tensor)
        torch.cuda.synchronize()
        end_time=time.time()
    return end_time-start_time
time_fp32=measure_inference_time(model_fp32,input_tensor,torch.float32)
time_int8=measure_inference_time(model_int8,input_tensor,
                                torch.float32)  # INT8模型输入仍为float
time_fp16=measure_inference_time(model_fp16,input_tensor,torch.float16)
# 比较输出一致性
output_fp32=model_fp32(input_tensor)
output_int8=model_int8(input_tensor)
output_fp16=model_fp16(input_tensor.half())
diff_int8=torch.abs(output_fp32-output_int8.float()).max().item()
diff_fp16=torch.abs(output_fp32-output_fp16.float()).max().item()
# 输出结果
print(f"模型大小-FP32: {size_fp32:.4f} MB,INT8: {size_int8:.4f} MB,FP16: {size_fp16:.4f} MB")
