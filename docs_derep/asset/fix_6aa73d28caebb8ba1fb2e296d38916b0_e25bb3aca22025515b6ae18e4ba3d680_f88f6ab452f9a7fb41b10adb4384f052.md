### 1. 格式合规性检查
通过 `wave` 模块解析文件头，仅校验采样率与声道数，不合格则标记需转码：

```python
def __check_wav_file(self, filePath):
    with wave.open(filePath, 'r') as wf:
        return wf.getframerate() == 16000 and wf.getnchannels() == 1
```
