# 军用AI的伦理边界在哪[^(\[1\])](#chapter014.html#m1)

徐英瑾[^(\[2\])](#chapter014.html#m2)

**摘要：**学界对把AI推向战场普遍担心三点：钻军控条约空子加速扩散、放低杀伤门槛提升平民伤亡、削弱战士职业武德等。文章指出这些批评多对传统平台与智能平台采用双重标准，同时夸大了智能武器对全球安全格局的重塑意义。作者认为，与其简单粗暴叫停研发，不如着眼于让装备具备类人的伦理推理能力，使其后果更契合现有价值体系；在研发路径上，如何处理各向同性难题也将成为绕不开的研究重点。

**关键词：**军用机器人 人工智能 伦理学 各向同性 心灵状态指派

## 导论：军用AI系统带来的伦理难题

普遍的认知是，AI的思路是通过编程让机器在行为上逼近人的智能。对何为智能学术界尚无定论，但一个共识是：成熟的AI应能在人干预最少的情形下，按使用者指令在特定环境中自主作业。一旦实现，人力在生产中的角色会被冲击，且冲击不仅限于体力岗位，也波及创造信息的脑力岗位。这与以通信技术为代表的传统信息技术不同，后者只负责传递已有信息，而理想的AI平台本身就是新信息生成的来源。

现阶段AI尚未能全面替代各行业人力，但在兵力紧张等资源稀缺场景里需求很迫切，部分试点也在推进。沃勒克与艾伦合著的《道德机器：如何教会机器人辨明是非》[^(\[3\])](#chapter014.html#m3)第三章指出AI三大高潜力方向：军用机器人以减少直接参战、性爱机器人以满足合法生理需求并降低性犯罪、工业机器人以应对老龄化用工荒。三种用途都涉及伦理，其中军用AI的争议最烈，因为其核心任务关联杀伤，直接触及军事暴力的正当性。美国空军退役上校、塔尔顿州立大学哲学与宗教教师哈尔嘎斯[^(\[4\])](#chapter014.html#m4)曾概括道：

军事冲突的语言即关于辩护（justification）的语言。军事冲突造成人员的死亡以及财产的受损，并造成各种形式的可以想象的大量伤害。不给理由就去做这些事情是疯狂的。不过，即使有了理由去做这些事情，如果同样的目标可以通过更少的人员与财产损失来达到，那么，相关的军事行动还是无法得到辩护。

该论点的核心是：军事行为可分为可辩护与不可辩护；若战争本身被认为正当，其造成的破坏在伦理上可被容许。但要论证某一具体行动的正当性门槛很高，需要将其损害收益比与其它可选手段对比，并证明其为最低。关于军事行动正当性的讨论由来已久，军用AI的加入又会在多大程度上改变问题性质？

变化体现在实践与理论两层面。先说实践。若开火等关键决策交由机器自主，责任归属就会模糊：人类指挥官失误可被军事法庭追责，机器战士犯错时该如何追究？现有法律体系对此尚无有效安排。
