SPARQL 的用法其实就围绕查询和更新两大场景展开，把常用写法串起来就能快速上手。下面把核心形态和典型问法梳理一遍，帮助你在自媒体笔记里快速复述。

先说最常用的查询形态。SELECT 用来拉取指定变量的结果集，可以配合数据源、图模式和过滤条件，还能加上排序、分页等修饰操作。
SELECT 变量 1 变量 2 ...
FROM 数据源
WHERE （基本图模式 [过滤条件]）
[修饰符]
[PRE0]
判断型查询 ASK 只返回真假，里面填入基本图模式并可附加条件约束。
ASK （基本图模式 [条件约束])
[PRE1]
如果想按模板生成新的 RDF 图，CONSTRUCT 就派上用场，先写图模板再用 WHERE 指定匹配模式和约束。
CONSTRUCT{图模板}
WHERE {基本图模式 [条件约束]}
[PRE2]
DESCRIBE 用来描述资源的大致信息，接受 IRI 或变量作为目标，并在 WHERE 中给出基本图模式和过滤条件。
DESCRIBE 资源标识符（IRI）或 变量 ...
WHERE {基本图模式 [过滤条件]}
[PRE3]
进入更新类语法，INSERT DATA 直接写入 RDF 三元组或整张 RDF 图。
INSERT DATA {RDF三元组（RDF图）}
[PRE4]
一个具体的写入示例：
INSERT DATA {
  f1333 released 1999;
  type film;
  language English
}
[PRE5]
删除数据同理，DELETE DATA 指定要移除的三元组集合。
DELETE DATA {RDF三元组（RDF图）}
[PRE6]
删除示例：
DELETE DATA {
  f1336 released 2003
}
[PRE7]

接下来是几类典型查询模式的实战写法，有助于理解不同拓扑的问法。

单原子查询的典型长这样，QC1：
Single-atom queries (QC1)
PREFIX res:<http://dpedia/resource/>
PREFIX prop:<http://dpedia.org/property/>
SELECT ?x
res:George_PC3A11 prop:academyawards ?x
[PRE8]
星型查询 QC3 的特征是多个三元组共享同一个主语，形成星状关联：
Star queries (QC3)
PREFIX lubm:<http://www.w3.org/ns/lubm#>
PREFIX rdf:<http://www.w3.org/...rdf-syntax-ns#>
SELECT ?x
?x lubm:takesCourse ?y.
?b lubm:publicationAuthor ?x.
<FullProfessors> lubm:teacherOf ?y.
?x lubm:memberOf ?z.
?a lubm:telephone "xxx-xxx-xxx"
[PRE9]
路径查询 QC2 强调变量间的链式连接：
Path queries (QC2)
PREFIX lubm:<http://www.exam...#>
PREFIX rdf:<http://www.w3.org/...rdf-syntax-ns#>
SELECT ?x
?x lubm:teacherOf ?y.
?z rdf:type lubm:FullProfessor
[PRE10]
实体查询的例子 QC4，基于属性值精确匹配实体：
Entity query (QC4)
PREFIX dbpedia:<http://dbpedia.org/Category>
PREFIX prop:<http://dbpedia.org/property/>
PREFIX rdf:<http://www.w3.org/...rdf-syntax-ns#>
PREFIX skos:<http://www.w3.org/2001/XMLSchema#>
SELECT ?x
?x prop:population "25089"^^xsd:integer.
?x prop:area "428"^^xsd:integer
[PRE11]
更复杂的实体关联查询 QC5，同时牵涉主演、导演、音乐等多重约束：
Entity query (QC5)
PREFIX dbpedia:<http://dbpedia.org/Category>
PREFIX prop:<http://dbpedia.org/property/>
PREFIX rdf:<http://www.w3.org/...rdf-syntax-ns#>
PREFIX skos:<http://www.w3.org/2001/XMLSchema#>
SELECT ?x
?x prop:starring ?y.
?y skos:subject dbpedia:Action_film_director.
?x prop:music<...resource/James_Wong>.
?x prop:director ?z.
?z skos:subject dbpedia:H_k_film_directors

掌握这六种基础语法和四类问法模式，就能覆盖日常 RDF 数据的检索、判断、构造、描述以及增删操作。
