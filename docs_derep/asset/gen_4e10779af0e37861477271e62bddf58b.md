## 9.11 有序数组快速建树

### 题目说明：

如何把一段已经排好序的整数序列组织成一棵二叉树？

### 分析与解答：

把有序数组映射进二叉树，得到的必然是一棵中序有序的树。核心思路是每次挑数组中点作为当前根，左右两段各自继续递归构造，层层向下即可完成。整体构建思路见图示。

## 9.12 逐层打印二叉树

### 问题描述：

给定一棵二叉树，要求从顶层开始一层一层输出节点数值，如图9-11所示。

### 分析与解答：

层序遍历的关键是记住当前节点的孩子以便按顺序访问。常用队列保存待处理的节点，先进先出正好保证从上到下、从左到右的访问顺序。具体步骤见图9-12。

# 方法功能：把有序数组转换为二叉树

def arraytotree(arr, start, end):

    root = None

    if end >= start:

        root = BiTNode()

        mid = (start+end+1)/2

        # 树的根节点为数组中间的元素

        root.data = arr[mid]

        # 递归的用左半部分数组构造 root 的左子树

        root.lchild = arraytotree(arr, start, mid-1)

        # 递归的用右半部分数组构造 root 的右子树

        root.rchild = arraytotree(arr, mid+1, end)

    else:

        root = None

    return root

"""

方法功能：用层次遍历的方式打印出二叉树节点的内容

输入参数：root: 二叉树根节点

"""

def printTreeLayer(root):

    if root == None:

        return

    queue = deque()

    # 树根节点进队列

    queue.append(root)

    while len(queue) > 0:

        p = queue.popleft()

        # 访问当前节点

        print(p.data, end=" ")

        # 如果这个节点的左孩子不为空则入队列

        if p.lchild != None:

            queue.append(p.lchild)

        # 如果这个节点的右孩子不为空则入队列

        if p.rchild != None:

            queue.append(p.rchild)

    printTreeLayer(root)

        返回值: 以 root 为根节点子树所有结点的和

        """

        def findMaxSubTree(self, root, maxRoot):

            if root == None:

                return 0

            # 求 root 左子树所有结点的和

            lmax = self.findMaxSubTree(root.lchild, maxRoot)

            # 求 root 右子树所有结点的和

            rmax = self.findMaxSubTree(root.rchild, maxRoot)

            sums = lmax + rmax + root.data

            # 以 root 为根的子树的和与前面求出的最大值

            if sums > self.maxSum:

                self.maxSum = sums

                maxRoot.data = root.data

            # 返回以 root 为根结点的子树的所所有结点的和

            return sums
