### 14.8.6 Xception

Google 在论文《Xception: Deep Learning with Depthwise Separable Convolutions》中提出的 Xception 是对 Inception v3 的再改进，核心思路是用深度可分离卷积替代 Inception v3 原有的普通卷积。

设计思想
采用深度可分离卷积替换 Inception v3 的卷积，与常规 DW 卷积有两点差异。
（1）常规 DW 先做逐通道卷积再接 1×1，Xception 顺序相反，先做 1×1 再做逐通道。
（2）常规 DW 两个卷积之间不加激活，Xception 在 1×1 之后引入 ReLU 非线性。

网络架构
VGG 这类传统网络靠堆叠 3×3 卷积提取特征，Inception 模块则把 1×1、3×3、5×5 卷积与池化组合，用更少参数学习更丰富的表征。Inception 模块是 GoogLeNet、Inception v2/v3、Inception-ResNet 的基础单元，其思路是把空间相关性与通道相关性拆开学习。
（1）先用 1×1 卷核把特征图的各通道映射到新空间，学习通道间关系。
（2）再用 3×3 或 5×5 卷核进行卷积，同时涉及空间与通道关系，此时卷核仍为多通道输入，空间与通道并未完全解耦。

由 Inception 向 Xception 的演化路径如下。
（1）先对 Inception 做简化，仅保留 3×3 卷积分支，得到如图14-21所示的仅含 3×3 分支的 Inception 模块。

（2）再把全部 1×1 卷积拼接，得到如图14-22所示的拼接后基础结构。

[PRE1]

图14-22 所有1×1的卷积进行拼接后的基本结构

（3）进一步提升 3×3 分支的数量，使其输出通道数与 1×1 卷积的输出通道数一致，得到如图14-23所示的 Xception 基础模块。

### 14.8.7 ShuffleNet-v1

《ShuffleNet: An Extremely Efficient Convolutional Neural Network for Mobile Devices》提出的 ShuffleNet 专为手机等移动设备设计。架构引入逐点群卷积与通道重排两种操作，在精度相近的前提下大幅降低计算量。既往网络中点卷积会显著增加计算，作者提出点卷积分组来降本，但组间联系弱化影响精度，于是引入通道重排来增强组间信息流动，在相同计算复杂度下容纳更多通道保留信息。

设计思想
ShuffleNet 继承稀疏连接的设计思路。分析 Xception 与 ResNet 可知，二者通过卷核拆分后计算复杂度下降，但点卷积的计算反而上升，为此作者用逐点群卷积替代原有结构，通过限制卷积在组内运算明显降低计算量。图14-24 展示了逐点群卷积与通道重排的操作。

然而多层点卷积堆叠时，信息被分割到各组内，组间无交换，如图14-24（a）。这会削弱表征能力与识别精度。因此在使用逐点群卷积的同时需要组间信息交换机制。第二层卷积中每个卷核需同时接收各组特征输入，如图14-24（b）。作者提出通道重排如图14-24（c），操作可导可嵌入网络实现端到端学习。

[PRE3]

#### 网络架构
基于逐点群卷积与通道重排，作者设计了全新的 ShuffleNet 结构单元，继承 ResNet 思想并做效率优化。
（1）用逐通道卷积替代原有的 3×3 卷积，降低空间特征抽取复杂度，如图14-25（a）。
（2）将结构中前后两个 1×1 点卷积分组，并在两层间加入通道重排，进一步减少跨通道计算量，最终单元如图14-25（b）。
（3）提出另一种单元图14-25（c），在旁路加入 AVG Pool 以降低特征图分辨率，最后不采用相加而采用叠加来弥补信息损失，专门用于降采样。

表14-24 ShuffleNet网络模型
网络主要由 16 个 ShuffleNet 结构单元叠加而成，分属 3 个阶段。每经过一个阶段空间尺寸减半，通道数翻倍；阶段内除步长外其他超参保持不变；每个单元的瓶颈层 3×3 卷积通道数为输出通道数的 1/4；整体模型计算量约为 140M FLOPs。通过放缩各层通道数可得到任意复杂度的模型。

### 14.8.8 ShuffleNet-v2

Face++ 团队论文《ShuffleNet V2: Practical Guidelines for Efficient CNN Architecture Design》提出 ShuffleNet-v2，目标是在保证高精度和高速度的前提下做轻量化。文中给出 4 条高效 CNN 设计准则，并据此对 ShuffleNet-v1 进行改进。同等复杂度下，ShuffleNet-v2 比 ShuffleNet 与 MobileNet-v2 更准确。

#### 设计思想
- （1）高效 CNN 的 4 条设计准则。
    - G1 相同通道宽度可最小化 MAC，模型速度最快。
    - G2 过度分组卷积会增加 MAC，使模型变慢。
    - G3 网络碎片化降低并行度，分支越少速度越快。
    - G4 元素级运算不可忽略，需尽量减少 Element-wise 操作。
- （2）ShuffleNet-v1 存在多处违背。
    - a 大量使用 1×1 分组卷积，违背 G2。
    - b 采用类似 ResNet 瓶颈层，输入输出通道不同，违背 G1。
    - c 整体结构分组卷积操作过多，违背 G3。
    - d 短路连接中存在大量元素级相加，违背 G4。
- （3）ShuffleNet-v2 的改进方向。
图14-26 是 ShuffleNet-v1 与 ShuffleNet-v2 的基础单元，其中 14.26（a）和 14.26（b）为 ShuffleNet-v1 的两种 block，后者对特征图尺寸做了缩小。14.26（c）和 14.26（d）为 ShuffleNet-v2 的两种 block。

图14-26 ShuffleNet-v1和ShuffleNet-v2的基础单元

从图14-26 可看出改进点。
改进1：14.26（c）在开头增加通道分离操作，先把输入特征图在通道维切分为 c' 与 c-c' 两个分支，实际 c'=c/2，左分支做等价映射，右分支做 3 个连续卷积且输入输出通道相同，符合 G1。
改进2：14.26（c）取消 1×1 卷积层的分组，符合 G2。注意前面的通道分离本身已具分组效果，两分支相当于两组。
改进3：通道重排移到叠加操作之后，符合 G3；同时首个 1×1 卷积不再分组，后接通道重排意义不大。
改进4：两个分支输出不再用元素相加，而是直接叠加，符合 G4。

### 14.9.1 NCNN

- （1）开源时间：2017年7月。
- （2）开源团队：腾讯优图。
- （3）GitHub 地址：见参考链接[1]。
- （4）特点。
    - NCNN 考虑手机端硬件与系统差异及调用方式，架构设计利于手机端运行。
    - 无第三方依赖，跨平台，手机端 CPU 速度快于同期已知开源框架。
    - 基于 NCNN 可将深度学习算法轻松移植到手机端高效执行，开发 AI App。
- （5）功能。
    - 支持卷积神经网络及多分支/多输入复杂网络，如 VGG、GoogLeNet、ResNet、SqueezeNet 等。
    - 无需依赖任何第三方库。
    - 全部使用 C/C++ 实现，采用跨平台 cmake 编译系统，可轻松移植。
    - 汇编级优化，使用 ARM NEON 指令集实现卷积、全连接、池化等关键层。
    - 精细数据结构设计，未采用 im2col+矩阵乘法，内存占用极低。
    - 支持多核并行，优化 CPU 调度。
    - 库体积小于 500KB，可精简至 300KB 以下。
    - 支持 8bit 量化和半精度浮点存储。
    - 支持直接内存引用加载模型。
    - 可注册自定义层实现扩展。

### 14.9.2 QNNPACK

- （1）全称：量化神经网络包 Quantized Neural Network PACKage，QNNPACK。
- （2）开源时间：2018年10月。
- （3）开源团队：Facebook。
- （4）GitHub 地址：见参考链接[2]。
- （5）特点。
    - 使用低密度卷积优化函数库。
    - 可在手机上实时运行 Mask R-CNN 和 DensePose。
    - 在性能受限移动设备上 100ms 内完成图像分类。
- （6）性能优势。
测试显示 QNNPACK 在端到端基准上具明显优势。量化 MobileNet-v2 架构上，基于 QNNPACK 的 Caffe2 算子速度约是 TensorFlow Lite 的 2 倍，多款手机均如此。除 QNNPACK 外，Facebook 还开源 Caffe2 量化 MobileNet-v2 模型，其 Top1 准确率比对应 TensorFlow 模型高 1.3%。

MobileNet-v1 采用深度卷积使模型更适配移动端，具有开创性意义。MobileNet-v1 包含大量 1×1 卷积与 3×3 卷积。研究者将量化 MobileNet-v1 模型从 TensorFlow Lite 转换，并在 TensorFlow Lite 与 QNNPACK 的 32bit ARM 设备上做基准测试，二者均用四线程，研究者观察到 QNNPACK 运行速度几何平均值为 TensorFlow Lite 的 1.8 倍。
