想把网页上的标题和段落抓下来做成摘要，并在独立窗口里展示出来，Python里三样工具就能搞定：requests 用来拉取页面源码，BeautifulSoup 用来解析 HTML 结构，Tkinter 用来搭建一个简易的图形界面。好在 Tkinter 是 Python 标准库的一部分，用起来不用额外安装。

下面这段完整脚本展示了从请求到展示的完整流程。

import requests

from bs4 import BeautifulSoup

import tkinter as tk

from tkinter import scrolledtext

# 抓取网页内容

url = 'https://example.com'

try:

    response = requests.get(url)

    response.raise_for_status() # 如果请求失败，将引发HTTPError异常

except requests.RequestException as e:

    print(f"Error fetching the webpage: {e}")

    exit()

# 解析HTML文档

soup = BeautifulSoup(response.content, 'html.parser')

# 提取标题

title_tag = soup.find('title')

title = title_tag.get_text() if title_tag else 'No Title Found'

# 提取段落（这里假设段落是<p>标签内的内容）

paragraphs = []

for p in soup.find_all('p'):

    paragraphs.append(p.get_text().strip())

# 将段落内容合并为摘要（这里简单地用换行符连接所有段落，实际应用中可能需要更复杂的摘要算法）

summary = '\n'.join(paragraphs)

# 注意：这里并没有真正的“摘要”生成，只是展示了所有段落。要生成真正的摘要，你可能需要使用自然语言处理库，如spaCy、NLTK或textrank4zh等。

# 创建Tkinter窗口来显示摘要

root = tk.Tk()

root.title("Webpage Summary")

# 设置窗口大小

root.geometry("600x400")

# 创建一个ScrolledText小部件来显示摘要

text_widget = scrolledtext.ScrolledText(root, wrap=tk.WORD, width=60, height=20)

text_widget.insert(tk.INSERT, f"Title: {title}\n\n")

text_widget.insert(tk.INSERT, summary)

text_widget.pack(padx=10, pady=10)

# 运行Tkinter主循环

root.mainloop()

- 脚本里 `requests.get(url)` 会向指定地址发起 GET 请求。若目标站有反爬策略，可能需要补充请求头或使用代理，此示例未做额外处理。
- BeautifulSoup 主要用来拆解 HTML 并拿到标题和段落。这里默认段落以 `<p>` 标签出现，真实页面结构可能不同。
- 脚本并未实现真正的摘要抽取，只是把所有段落拼接展示。若要做智能摘要，可考虑接入 spaCy、NLTK 或 textrank4zh 等 NLP 库。
- Tkinter 用于生成简易 GUI，ScrolledText 提供可滚动的多行文本框。
- 当前错误处理比较基础，仅捕获了请求异常，生产环境建议加强异常捕获与日志。

# 第8章 数字人：虚拟主播的新机遇

数字人是通过人工智能与先进算法打造的、高拟真且能模拟人类行为、表情和语言交互的虚拟形象。它融合了计算机图形学、深度学习、自然语言处理等前沿技术，可以为用户带来沉浸式和个性化的互动，广泛用于娱乐、教育、客服、虚拟偶像等领域。本章将系统介绍数字人的基本概念以及主流平台。

## 8.1 数字人入门全景

数字人是借助 AI 技术和计算机图形学创造出的，能够模拟外貌、动作、表情并实现自然语言交互的虚拟人物。下面从概念、特性和应用维度展开说明。

### 8.1.1 什么是数字人及核心优势

数字人是基于数字技术构建的、拥有类人外貌与行为的虚拟个体，通常集成 NLP、机器学习和情感计算，能理解并回应用户的语言与情绪，实现更自然的互动，适用于娱乐、教育、营销、虚拟助理等场景。

核心优势主要体现在：

- **高度拟人化**：通过 3D 建模、人脸识别呈现真实外貌，模仿人类声线口音与肢体、面部微表情，观感更自然。
- **智能交互**：能够理解用户指令、识别情绪并反馈，支持语音、文字、图像等多模态输入输出，交互体验丰富。
- **持续学习**：借助深度学习不断积累知识与能力，反应速度和情感识别等指标随技术演进持续优化。
- **个性定制**：外观、性格和行为均可按需定制，适配不同业务场景。

### 8.1.2 数字人怎么分、能干嘛

数字人已覆盖偶像娱乐、直播短视频、教育培训、数字化劳动与情感陪伴等多个方向，提供更沉浸、更个性化的体验。
