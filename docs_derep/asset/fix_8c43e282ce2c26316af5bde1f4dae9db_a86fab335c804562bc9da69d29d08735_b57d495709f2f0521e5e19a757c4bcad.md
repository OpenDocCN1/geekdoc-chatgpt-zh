## 6.2 分解任务

制定计划时需要做任务分解。任务分解是将整体项目拆分为更小、更具体、更易管控的任务的过程。它能把项目拆解为可执行的单元并分配给成员。常见步骤如下：

（1）明确项目目标：厘清目标与范围，将其拆分为可管理的子任务。
（2）列出任务清单：根据目标列出所有待完成事项，并确保成果可量化。
（3）确定依赖关系：理清任务间的先后关系，保证每个任务有前置条件且整体进度不受延误。
（4）估算任务时间：为每项任务估算所需时间和资源，以确定成本与周期。
（5）分配任务：把任务交予合适的成员，确保每项任务有责任人。
（6）制定时间表：据时间估算制定项目日程，包含起止日期、关键路径与里程碑。

### 6.2.1 PERT 图

PERT 图即 Program Evaluation and Review Technique 网络图，用于规划和控制项目进度的图形工具。它由节点与箭头组成，节点代表任务，箭头代表依赖关系，如图 6-1 所示。

[PRE0]

图 6-1 PERT 图

在 PERT 图中，每个任务通常包含三个时间参数。

最早开始时间 EST：无限制情况下任务可开始的最早时间。

最晚开始时间 LST：在不影响后续任务的前提下任务可开始的最晚时间。

最早完成时间 EFT：按最早开始时间执行时所需完成时间。

计算这些时间可得出总工期与关键路径，有助于掌握进度与规避风险，并及时调整。

PERT 图也可带条件，如图 6-2 所示。

[PRE1]

图 6-2 带有条件的 PERT 图

图 6-2 显示某项目的 7 项任务及其依赖与条件。例如，安装水电需在拆除旧装修后启动，涂料装饰需在地板与墙面材料安装完成后启动。

PERT 图的价值主要有：

（1）理清依赖与条件：清晰展示任务间的依赖与条件，便于规划进度与资源。
（2）确定关键路径：图 6-2 中关键路径为 A→B→C→D→E→F 或 A→B→C→D→E→G，其完成时间决定项目总时长。
（3）优化资源配置：分析依赖、条件与资源需求，提升效率与质量。
（4）促进沟通协作：绘制过程帮助团队成员理解任务与角色，提升协同效果。
（5）提高管理水平：便于经理更精准地规划与控制进度与资源，确保按时保质完成。
