#### 2.3.2 解码器自回归生成：掩码如何限制视野

解码器的生成是自回归的，靠自注意力和编码器-解码器注意力协同工作。生成一个新词素后立刻喂回模型作为下一步输入，天然保证只使用当前及之前的信息。自注意力掩码的作用就是物理上封住未来位置，防止偷看。

本节在前面编码器实现的基础上做了调整，重点展示自回归流程、掩码的构造以及在生成任务中的用法。

代码注解要点：

- 多头自注意力 MultiHeadSelfAttention。计算注意力时接入掩码，把未来时间步屏蔽掉，解码器只能看到已生成的历史。
- 掩码生成函数 generate_square_subsequent_mask。生成下三角矩阵形式的掩码，确保自回归时不会提前窥探未来。
- 解码器层 TransformerDecoderLayer。自注意力带掩码实现自回归特性，编码器-解码器注意力把编码侧的信息引入，前馈网络继续加工解码特征。
- 完整解码器 TransformerDecoder。数层解码器层堆叠，特征逐层传递，最终输出自回归生成的序列。

# 前馈神经网络

class FeedForward(nn.Module):

    def __init__(self, d_model, dim_feedforward, dropout=0.1):

        super(FeedForward, self).__init__()

        self.linear1=nn.Linear(d_model, dim_feedforward)

        self.dropout=nn.Dropout(dropout)

        self.linear2=nn.Linear(dim_feedforward, d_model)

    def forward(self, x):

        x=torch.nn.functional.relu(self.linear1(x))

        x=self.dropout(x)

        print("FeedForward Output:", x)

        return self.linear2(x)

# 残差连接与层归一化

class ResidualNormLayer(nn.Module):

    def __init__(self, d_model, dropout=0.1):

        super(ResidualNormLayer, self).__init__()

        self.layer_norm=nn.LayerNorm(d_model)

        self.dropout=nn.Dropout(dropout)

    def forward(self, x, sublayer_output):

        x=x+self.dropout(sublayer_output)

        print("Residual Connection Output:", x)

        return self.layer_norm(x)
