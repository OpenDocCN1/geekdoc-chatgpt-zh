# 2. 属性图模型

属性图是当前图数据库领域采纳面最广的图数据模型之一[3]。它由节点集合与边集合构成，满足下面 9 条定义：

+   (1) 每个节点都拥有独一无二的标识;
(2) 每个节点都关联若干条发出边；
(3) 每个节点都关联若干条进入边；
(4) 每个节点都携带一组键值对形式的属性；
(5) 每条边都拥有独一无二的标识；
(6) 每条边都指向一个头部节点；
(7) 每条边都源自一个尾部节点；
(8) 每条边都带有标签来描述关系类型；
(9) 每条边都携带一组键值对形式的属性。

# 3. Gremlin 概览

Gremlin 是 Apache TinkerPop 图计算框架[21]提供的属性图查询语言[22]。Apache TinkerPop 被设计为图数据库的通用访问 API，类似关系数据库上的 JDBC。Gremlin 定位为图遍历语言，执行过程如同在图中沿有向边导航，需要用户明确指明遍历步骤，属于过程式语言，可随时感知当前位置与到达路径，但需要“懂路”。与 SPARQL、Cypher 的声明式风格不同，Gremlin 更接近函数式编程接口。下面以 g 代表图 3-3 的属性图举例。
