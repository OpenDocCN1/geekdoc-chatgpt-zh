#### 3.4.3 性能调优方案

部署阶段的优化目标是提升推理效率、降低资源占用并维持输出质量。DeepSeek-V3 通过 KV 缓存、动态负载均衡与请求参数调优实现性能跃升。

KV 缓存保存中间计算结果，避免重复计算，在多轮对话中显著降低延迟。动态负载均衡按需分配计算资源，防止硬件瓶颈，提升整体吞吐量。此外，合理调整 temperature 等参数，可在生成质量与速度间取得最佳平衡。
