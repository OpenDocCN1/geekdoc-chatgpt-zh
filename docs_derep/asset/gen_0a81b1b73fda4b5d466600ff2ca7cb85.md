# 普通人也能搭建AI智能体团队

# 前言

# 为什么写作本书

当生成式AI进入爆发期，多智能体系统正成为技术圈最具想象力的方向。从ChatGPT到后来的Manus，一场从单一问答助手到可协同工作的智能体队伍的跃迁已经发生。这不只是能力提升，更是工作方式的底层重塑。

多智能体之所以被看好，原因在于三点。第一，它能把复杂目标拆成若干子任务，由不同专长的智能体分工完成。第二，系统容错性和适应性更强，某个节点卡住时，其他智能体可以补位。第三，它可以复刻真实团队的协作效应，产生1+1大于2的增益。伴随AutoGen、Manus、扣子等平台的落地，多智能体正从研究原型走向业务场景。

与此同时，新平台层出不穷，也让零编程背景的学习者感到迷茫：不同智能体平台该如何辨别优劣？没有代码基础能否做出可用产品？多智能体与大模型到底是什么关系？企业落地时又该如何起步？这些困惑正是制约普及的瓶颈。

本书就是为破局而来。写作重点放在零代码搭建的可行性和实操，因为并非人人都有编程经历，但每个人都有权用上AI红利。读完后你会发现，即使没有一行代码的经验，也能组建起通用型与企业级的多智能体体系。书中也会厘清一个核心关系：大模型负责“大脑”，多智能体则提供“手脚”和“协作机制”。

从企业落地的视角看，多智能体前景可期，但落地时会遇到真实难题，比如什么时候值得做智能体、选哪个平台更合适、怎么把企业内部数据和业务规则融合进智能体。本书会以真实案例拆解企业实践经验和典型坑点，帮助读者避开雷区。

# 本书特色

书的定位是在技术深度和入门门槛之间找平衡，力求做到看得懂、学得会、用得上，具体体现在五个方面。

1. 真正零门槛，全程无需代码：从非技术读者出发设计，零编程经验也能上手。
2. 主流平台全覆盖：涵盖Manus、AutoGen、扣子等，配对比分析和选型建议。
3. 场景驱动案例：案例均来自电商运营、教育创新、企业办公等真实工作场景。
4. 从单体到团队：循序渐进带你掌握从单一智能体到智能体团队的构建方法。
5. 覆盖前沿技术：包含MCP、AutoGLM沉思版、知识库等新技术的解析与演示。

## 1.1 Manus技术突破点解析与应用案例

未来是否需要上亿级智能体？AI先驱李开复曾描绘：当智能体接管大量事务，人无需打开任何App，智能体便能根据环境动态规划、自动处理繁琐操作，让人专注创造性工作。

这种图景在ChatGPT时代还显科幻。随着Manus等自主智能体出现，想象正逐步落地。

### 1.1.1 技术突破点解析

自主智能体与传统AI工具有何本质差异？要理解这一点，需要回看ChatGPT的发展脉络。

ChatGPT出现时常被视作增强搜索引擎，即便后来出现DeepSeek等具备深度推理的大模型，多数用户仍停留在“人主导、AI辅助”模式：人类规划任务、把片段交给AI、人工整合结果。AI更像工具而非伙伴。

自主智能体则实现范式切换，采用“任务全托管”模式。用户只需给出目标，智能体便可自主完成拆解、工具调用到交付全流程。用生活比喻，传统AI像需要时刻看顾的幼儿，离开视线就会停滞；自主智能体像能独立跑腿的孩子，给瓶子和钱说明任务，就能安心做自己的事。

图1-1的漫画很好体现了这种差异。

Manus是典型的自主智能体，其高自主性源于工程层面的多项创新。

1. 自主任务规划能力
通过定制大模型，Manus能把模糊需求转化为可执行序列。例如用户说“请帮我制定面试时间表”，它会自动生成包含读取Excel、安排会议、校验可行性等共8个子任务的工作流，如图1-2。

2. 多工具协同执行能力
Manus集成数十种专业工具模块，涵盖代码生成、浏览器自动化等，并具备“工具链自优化”机制，可在执行中实时评估工具表现并动态调整策略。

CodeAct是一种让AI通过动态生成与执行代码完成复杂任务的框架。Python是一种语法简洁、生态强大的通用编程语言。

当执行出现偏差，Manus会通过“观察-诊断-修正”循环自修复。其CodeAct架构支持直接执行Python代码，代码能力接近普通IT工程师，图1-3展示了编程执行过程。

3. 虚拟机执行环境
Manus为每个任务分配独立虚拟计算机运行环境，保证安全并实现工作空间透明化，用户可随时介入调试，形成良好人机协作。

因此非技术人员现在也能完成网站开发、数据分析等专业任务。即便零编程基础，也能用自然语言指令创建完整项目，且每一步操作都在虚拟机中清晰呈现，如图1-4。

## 1.2 主流应用类型
随着大模型普及，许愿式提示词成为常态，如“如何在3个月内赚到100万”。大模型答案往往不理想。若同样问题抛给Manus，结果会如何？即便对Manus而言，完成此类任务也相当困难。

使用过足够多的大模型和智能体后会发现，人类与自主智能体的核心关系可概括为两个字：协作。
