# 结语：存在论认知的新可能

——现象学与诠释学如何打开认知科学的另一扇窗

这本书大致做了两件事。

其一是梳理认知科学的主流路径，尤其是常被概括为“4E+S”的模型，并追溯其哲学来路，辨明它们对认知研究带来的助益与风险，为转向海德格尔的存在论现象学、乃至提出“存在论认知”这一提法做铺垫。我们发现，从计算—表征主义、认知主义到符号操作的神经网络，旧范式背后都站着笛卡尔式的身心二元论。4E+S 中的具身、嵌入、生成、延展、情境等取向，都把矛头指向了这个根源，核心共识是：旧研究忽视了身体与环境在智能活动中的关键作用。把它们归为一个模型，是因为它们都在不同程度上拒绝或重构了传统认知主义。不同理论在心智/大脑与身体/环境之间的分量取舍各有差异，这正是梅纳里试图整合“4E”的一大动机，但他也坦承这些取向在侧重点和方法上并不相同。对我们而言，其大趋势是从对等走向互补，“4E”想把每一种“E”所代表的立场厘清，再探寻彼此关联。实际上每种立场本身已提供一个清晰可用的研究框架，并不意味着认知科学必须套用一套统一模型，更合理的做法是保持多元开放的态度。用“4E”框架做研究时，要先问清研究目标。譬如脑科学的工具更适合探究杏仁核之类的神经机制，而延展认知的框架则更能帮助理解具身与离身的张力。

其二是认为向存在论现象学靠拢是有价值的。海德格尔注意到支撑人类主体更深层的“世界性”，这种世界性比胡塞尔的先验意识、笛卡尔的无身“我思”更贴近经验。他强调存在于世界中的并非俯瞰一切的纯粹意识，而是一个在世界中具事实性的存在者。把主体性理解为世界中存在的事实，这一洞见能够刷新我们对人类主体惯常的定义，使其被看作具身地嵌入科学所揭示的世界之中。惠勒正是沿着这条思路，将海德格尔视作认知科学新范式的哲学同盟，认为存在论现象学可以为嵌入—具身式认知科学提供根基，用以动态交互的具身嵌入系统取代孤立表征系统，把笛卡尔式的认知描述换成更“海德格尔式”的描述。简言之，就是筹建一种“海德格尔式认知科学”。

惠勒到底想做什么？他希望这条新路径能为“此在”在世存在的现象提供可能解释，把海德格尔思辨的特质剥离，换成可描述的因果状态与过程。因为认知科学要整合各类要素，厘清它们如何因果地组织、运行并生成心智现象，进而把握背后的因果机制。对人类认知的理解，需要哲学的构成性理解与经验科学的可实现性理解共同配合。哲学以现象学方式解释概念，比如上手、被抛、情绪等“此在”在世的种种现象；认知科学则提供可量化、可观察的实现方式。德雷福斯与惠勒把海德格尔所说的“对存在的领会”解读为“背景应对活动”，这种活动对人而言是直接可理解的，其可理解性来自相对易于描述的因果要素与结构。惠勒认为这正是海德格尔式认知科学家的任务：弄清我们在自己的世界里如何实现背景应对。[^(\[1\])](#chapter007.html#m1)但由此会带来两个麻烦：第一，经验性的可实现解释可能只够描述心理现象，对“此在”的存在方式无能为力；第二，存在论与科学自然主义是否相容，核心在于“此在”能否被自然化。

关于第一个麻烦，海德格尔早已区分了人作为“此在”与作为心理或意识主体的存在方式，拒绝用意识心理学去解释“此在”，他认为那是错误的路径。海德格尔式认知科学用因果机制有效描述心理现象，并不保证同样的机制能在人们在世存在这一根本生存境况中得到同等实现。从根本上说，“此在”的存在方式无法用因果关系来理解，在世存在呈现的是存在论层面的本质关联。对存在论现象学的方法与科学的自然主义方法而言，把“此在”设想为由因果机制实现是有问题的。给“此在”一个因果说明，实质上是对客观实体的形而上学依赖，而海德格尔明确指出，“此在”之在世既不是自然科学研究的客体，也不能化约为某种实体，更不能被自然科学解释。“此在”在世不是物理属性与心理属性的简单或复杂叠加。不论从本体论还是存在论看，“此在”在世都不是任何物理心理属性的组合。即使因果机制有助于揭示人类认知的具体过程，心理认知过程也不等于“此在”在世的存在方式，正如海德格尔所说，认知只是人在世界中存在的一种派生方式，而非根本方式。

关于第二个麻烦，如果可实现性理解对“此在”是不可能的，也就是说，“此在”并非可由因果过程实现的存在者，那么我们就不能按世界中对象的模式来理解人的本真存在方式，这说明强调因果性的自然化方法并不适用于“此在”。海德格尔对“此在”在世存在的论断，先验地描绘了人类最初面对的现象结构，说明这种存在方式为何能够理解存在。对“此在”而言，它是存在的唯一领会者，不可能被还原为世界中的实体。对海德格尔来说，能生存的只有能够自我解释的存在者，即人本身，石头甚至上帝都不在他的意义上生存。[^(\[2\])](#chapter007.html#m2)若剔除功能主义的影响，承认“此在”在本体论上不可还原为自然主义概念，就会发现海德格尔的存在论现象学与惠勒的形而上学解释之间存在不可调和的矛盾，“此在”在世与自然科学的研究对象本质不同，“此在”不能被自然化。海德格尔的一些先验概念有效地把人类经验的可能性条件与科学的影响区分开来，对人之在世存在的现象学理解不可能简单归结为因果反馈环。对实证认知科学的因果—机械解释而言，“此在”仍然难以把握，甚至可被视作一种“幻象”。这或许是海德格尔式认知科学与存在论认知面临的最大困境。

作为海德格尔式认知科学与存在论认知的重要内容，海德格尔式人工智能遭遇“框架问题”的拷问。与其他路径不同，它主要借用“被抛”的资源。这一存在论概念被德雷福斯和惠勒看作规避表征的有效手段，特别是惠勒认为动力学涌现机制可以为“被抛”提供细节描述。我们认为他们简化了“被抛”的哲学意蕴，把它当作情境化操作，人被抛入世界也体现出嵌入性特征。确实，用“被抛”的机制化来处理“框架问题”是一种有益尝试，意在说明日常智能主体总置身于有意义的语境，其行为都具语境敏感性，无须建立或检索亚主体层次的表征。但经分析我们认为，人类智能离不开表征，表征是智能的重要体现，其主动性也是智能的特征。按“被抛”设计的机器可能获得机器意义上的智能，却不一定产生类人智能现象，而机器智能的核心目标是在硅基物理符号系统上模拟再现人类智能。“被抛”呈现的是被动的智能，强调在外在世界作用下产生的交互，不属于主动智能的范畴。

从“被抛”的结果看，人被抛入了被语言裹挟的世界，“被抛”关涉“此在”的本真生存，不能被预先设定的抽象逻辑技术语言描述。惠勒对“被抛”作因果形式化说明，可能体现了自然主义对认知的影响，因果性构成了自然主义解释的“集—置”。技术集—置带有强迫性，把一切在场者纳入技术，并使语言形式化，在形式化语言中得不到真正的本质。[^(\[3\])](#chapter007.html#m3)自然主义的集—置用因果概念界定“被抛”这一生存现象，具身—嵌入机制的解释可能遮蔽海德格尔通过“被抛”所要表达的生存论意蕴。由此看，“被抛的机器”似乎难以完整呈现人类智能的全貌。

将海德格尔存在论现象学与认知科学结合，会产生两种结果：海德格尔式认知科学与存在论认知。共同点是都反对认知主义与联结主义内部持有的笛卡尔哲学假设，后者的难题在于如何解释人在适应情境时产生流畅灵活行动的相关性敏感度。正是对这一能力的解释催生了认知科学中的海德格尔转向，并迫使研究者放弃认知主体以去世界、离身的方式通过表征纯粹事实来应对无意义情境的假设。这里需要明确，二者不是同义反复。存在论认知不等同于海德格尔式认知科学，关键区别在于我们纳入了诠释学。我们推动存在论与诠释学同认知研究的结合，目的并非构建具有科学规范性的研究纲领，前文已论证这种尝试会立刻凸显“此在”自然化问题。也就是说，存在论与诠释学的某些观点方法虽能助益认知科学，却与构建海德格尔式认知科学并无绝对直接的因果关联，这由存在论现象学与认知科学之间的差异所决定。

对两者作简要区分：其一，惠勒的海德格尔式认知科学似乎做了科学上的考量，试图寻找与海德格尔哲学相呼应的思维心智的方式，他把“此在”在世界中存在的论断描述为认知主体对情境的嵌入性，描述为对不同情境或语境的敏感度，人类认知与智能产生于大脑、身体与环境之间巧妙的适应性耦合。他对情境作了空间意义上的解释，主张把认知放回大脑，把大脑放回身体，把身体放回世界。而存在论认知强调情境的整体性与统一性，强调认知主体与认知情境浑然一体的亲缘性。

其二，惠勒提倡行动导向的表征，把表征视作行动的先行准备，把行动视作表征的必然结果。存在论认知主张表征也是人们灵活流畅适应情境的方式之一，只是行动在存在论上优先于表征，表征与行动并不相互取代，后者并不排斥对认知的表征说明，及时的行动反馈保证着表征的有效性，行动是认知主体在表征之上的扩展与延伸，认知是行动与表征能力的叠加耦合。

惠勒的目的不是另起炉灶，而是基于海德格尔哲学改造正统认知科学并使二者联结。这与我们的目的做法不同。存在论认知是从认知研究中汲取海德格尔存在论现象学思想资源的产物，以“此在”“世界”“在世存在”为核心概念，强调“此在”是具身的、有实践意蕴的、情境性的存在者，具有身体、实践、情境三个维度；世界不仅具有空间维度，同时是通过实践构造起来的指引网络；“在世存在”是人产生认知经验的背景或场域，离不开人的身体，我们以“作为身体”和“拥有身体”的方式展开自身。

存在论认知有三个主要命题：以动态的原初上手活动取代静态的静观认知；以具身的情境性认知取代无身的离身性认知；由表征性认知扩展和延伸为行动与表征的叠加耦合。我们认为，存在论认知在“此在”能否自然化以及海德格尔式人工智能尝试解决“框架问题”这两个方面可能会遭到批评，前文已有具体讨论。这种形式的认知科学实质是把海德格尔对“此在”的生存论分析转变为一种科学解释。同时我们也要看到，仅从海德格尔的分析汲取资源是不够的，有必要把诠释学与认知科学结合，作为对存在论认知的有益补充。原因有三：其一，海德格尔的诠释学关注“此在”的生存，诠释学构成“此在”生存的一部分，因而与存在论具有紧密连续性；其二，诠释学自觉或不自觉地克服了笛卡尔的主体认知模式，理解活动同时也是人与世界关联的深化；其三，诠释学与认知科学都在寻求关于人类认知的普遍理解或解释，二者的某些问题域相互重合，如“他心问题”，而且在处理非形式化、具有不确定性的模糊认知活动方面，诠释学具有某种优势。这是在书中提出的一个新观点。“前见”是构成人类认知与理解的重要因素，后者同时离不开当下以及历史的情境关联，人的认知根基于一种行动与解释的可能性，同时，诠释学划分的前反思性的直接理解与反思性的叙事理解使我们对人类认知有了新的认识，我们有理由相信，诠释学对认知哲学的研究是有助益的。

总之，存在论现象学与认知科学的结合让我们看到一种不同于以往的“海德格尔式认知科学”，惠勒基于科学主义立场称之为具身—嵌入式认知，他自己也认为科学的可实现性解释同现象学的构成性解释之间不能相互还原。然而，他本人却有意或无意地违背了自己坚持的信条。严格说，与现象学自然化问题类似，惠勒关于海德格尔式认知科学的设想仍需进一步商榷。相比之下，我们持较弱立场，不主张构建类似惠勒的海德格尔式认知科学，而是试图提出将海德格尔存在论现象学与认知科学进行泛化结合的存在论认知，不谋求使之成为认知研究中的科学范式。我们认为，以“在世存在”这一整体性现象学描述说明智能主体的处境，以上手活动的实践领会说明关于人的具身性知识，以“被抛”的因果机制尝试解决人工智能的“框架问题”，这些都展现出海德格尔存在论哲学对认知研究的<|message|>
