2024 年微软提出的 Graph RAG，为检索增强打开了另一条新路。传统 RAG 处理“A 的电话是多少”这类局部问题很在行，却在“这批邮件到底在担心什么”之类的全局问题上力不从心。Graph RAG 先让大模型从文本里抽取实体、搭建知识图谱，再通过图聚类做摘要，让检索具备了俯瞰全局的能力。

Self-RAG、Agentic RAG 等范式则让 RAG 从被动走向主动。被动式 RAG 只要一有提问，无论多简单都得去库里查一遍；主动式 RAG 则由模型自己判断是否需要检索。问个“你好”，它直接回；问“2024 年财报”，它会先输出一个 `<Retrieval>` 标记触发工具。检索回来后它还会自评：“信息不够，得换个关键词再查”。检索因此从单纯的查找升级为思考，Agent 的雏形就出现了。

### 5.2.4 RAG 进化路径与组合策略

RAG 的发展史，本质上是 AI 从被动查阅走向主动认知的过程。工程上我们看到它从粗糙的向量匹配，演进到精密的流水线，最终嵌入 Agent 的认知闭环，成为 Agentic RAG 的核心能力。

#### 1. 从向量索引迈向知识图谱

朴素检索阶段，RAG 基本等同于“提问→向量检索→生成”。检索精度低、召回差，复杂问题容易被断章取义或因关键词不匹配而漏掉关键信息，最终出现典型的垃圾进垃圾出。

高级流水线阶段，引入了重写与重排序。借助 Cross-Encoder 把初步结果精细排序，提升信噪比，保证模型拿到的是高质量的黄金上下文，如今已是企业知识库的标配。

结构化与主动化阶段，Graph RAG 和 Agentic RAG 并行出现。Graph RAG 用知识图谱刻画文档间的语义关联，擅长回答“整个库在讲什么”这类全局任务；Agentic RAG 把检索当成 Agent 可调用的工具，由 Agent 决定何时、查什么、查完后是否够用。这一步标志着 RAG 从局部片段检索迈向全局知识理解。

#### 2. 典型组合方式

RAG 不再是孤立的管道，更像 Agent 大脑里的海马体，和感知、推理、记忆等模块深度协同。

RAG 与思维链的组合等于检索增强思考。把一次大检索拆成多步微检索，在推理的每一步动态引入外部知识来校准逻辑，有效压制幻觉。适合多跳问答，比如“马斯克收购 Twitter 时股价多少”。传统 RAG 是先检索后推理；检索增强思考则在链路中内嵌检索：先推断出需要收购日期→检索；再基于日期推断需要股价→再次检索。

RAG 与主动感知的组合等于自我修正检索。把检索从硬编码流程升级为按需调用的能力，让 Agent 具备拒绝回答或主动求知的自主性。不再一问必查，感知模块实时评估不确定性与置信度，低置信度就触发检索；检索结果不相关或不足时，反思模块会重写查询再查。

RAG 与分层记忆的组合等于语义长期记忆。RAG 为分层记忆提供非结构化数据的存储介质与访问协议。分层记忆定义了 L1 缓存、L2 缓存、L3 长期存储，RAG 作为 L3 中处理 PDF、Wiki 等非结构化文档的核心，让 Agent 能持久化并随时调用外部语义。

RAG 已不只是外挂知识库，而是连接世界的认知脐带。外部知识从 Prompt 的填充物变为驱动推理的燃料。未来参数记忆与外部存储的边界会越来越模糊，在统一的认知架构里深度融合，实现真正的知行合一。

### 5.2.5 设计哲学：知识解耦

RAG 最核心的洞见是把推理能力和知识存储解耦。

模型像 CPU，负责推理、逻辑、语言组织，可以不断升级从 GPT-3 到 GPT-4 再到 GPT-5。知识库像磁盘，负责存放事实、数据、细节，需要实时增删改。解耦后，系统时效性和专业度可以低成本维持，无需每次重训昂贵的大模型，这正是 AI 从实验室玩具走向工程落地的基石。

### 5.3 情节记忆模式

“经验不是发生在你身上的事，而是你对发生的事做了什么。”——奥尔德斯·赫胥黎

如果把 RAG 比作 Agent 的百科全书，那情节记忆就是它的飞行记录仪，记录经验轨迹。

光记录不够，高级架构还需要一个夜间模拟器。像自动驾驶用白天的危险接管做离线训练，Agent 也需要在空闲时做反事实推理，把一次性经历转化为可复用策略。每一次任务，无论成败，都是宝贵的情节。

[PRE0]
新手 Agent 遇到 bug 总像第一次见面。
老手 Agent 会去翻黑匣子感叹：“这个 bug 上周见过，是 API 超时，重试三次就好。”

情节记忆的核心是构建闭环系统，捕获带时空上下文的交互轨迹。通过压缩、泛化、双键检索，把非结构化日志变成结构化技能，让 Agent 越用越聪明。

#### 5.3.1 架构：经验的炼金

情节记忆本质是 ETL 管道，不能直接把所有交互倒进向量库，否则噪声大、检索慢，必须先提炼。

构建情节位于记忆层入口，像剪辑师。把执行层产生的原始日志切成语义完整的片段，整合为连贯情节，剔除 ls、pwd 这类无意义探索，只保留关键状态变化。

提炼成功位于学习层，像泛化器。对高价值成功案例做去语境化，变成可复用的通用技能。输入可能是“我在 /tmp/logs 删除了 error.log”，输出是“磁盘不足时优先清理 *.log”。

技能库位于学习层底部，是精华仓库，存放经验证的可执行代码或思维链模板。新任务进来会优先从这里检索，实现能力复用。

#### 5.3.2 核心机制

轨迹压缩与分层摘要：防止记忆膨胀。关键帧提取只保留决策点和结果点。分层摘要有 L0 原始请求体、L1 调用 GitHub API、L2 修复登录模块 bug。检索先命中 L2 再展开 L1。

双键检索策略：语义检索找目标相似任务，结构检索找报错相似轨迹。目标相似是“想做的事以前做过吗”，状态相似是“现在的报错以前见过吗”。综合相似度 = α×目标相似 + β×状态相似。

经验参数化：标准情节包含目标、轨迹、结果、反思。通过实例到抽象到约束的提炼，把 delete_file("report_2023.txt") 抽象为 delete_file(filename)，约束为文件存在且非系统文件。多情节对比后生成通用函数，实现举一反三。

压缩降成本，双键提相关性，参数化促迁移。

#### 5.3.3 工程实践

Voyager 2023 体现代码即策略理念，维护 skill_library.js，把砍树、合成木板封装成函数。新任务先查库，复杂任务自动组合已有函数，库中没有就生成验证后入库。

Devin 声称能从历史 bug 修复记录学习，下次遇到类似错误更快定位。

Cline 引入检查点，复杂编程时保存上下文快照，失败后回滚到记忆检查点，把情节记忆用于容错，等同存档。

DeepMind 的 SIMA 能在多种 3D 游戏环境执行任务，情节记忆如开门、找资源可在不同物理引擎间迁移，显示跨域泛化能力。

从日志到技能库再到跨环境泛化，情节记忆推动 Agent 从无状态脚本进化为有经验专家。

#### 5.3.4 演化与组合

从原始文本流到可检索语义快照，再到可执行技能库。

流水账日志阶段，像服务器日志按时间记录对话，检索困难，关键信息被噪声淹没，易灾难性遗忘。

语义快照阶段，向量数据库让关键交互节点可检索，产生似曾相识能力。

技能泛化阶段，系统不仅存轨迹，还提炼为代码或规则，成功任务抽象为函数或 SOP，记忆变成工具，能力库自主生长。

情节记忆与 RAG 组合构成完整长期记忆：RAG 提供读万卷书的世界知识，情节记忆提供行万里路的个体经验。

情节记忆与 ReAct 组合形成具身先验，构建感知-记忆-推理回路。感知结构化入库，记忆在 ReAct 思考阶段提供先验，推理结果再蒸馏回长期记忆。

情节记忆与反思记忆组合形成闭环成长。反思记忆负责生产语言化教训，情节记忆负责存储并索引，使教训变成可调用的肌肉记忆。

架构师的目标是让每次交互都成为下一次成功的垫脚石，把线性时间转化为指数级经验资产。

#### 5.3.5 设计哲学：做时间的朋友

没有情节记忆的 Agent 永远困在土拨鼠之日，次日醒来仍是新手。没有记忆的推理无根，未经蒸馏的记忆无形。情节记忆赋予时间感，能力随时间线性乃至指数增长。比算力更重要的是经历。

小结 平台与协议的一等组件

至此，Agent 架构的记忆拼图完成。记忆正从 Prompt 附件升级为平台与协议的核心组件。

现代上下文工程的共识是经营上下文，而非仅设计 Prompt，把有限预算投向最有价值的信息与结构。

分层记忆构建操作系统，RAG 构建图书馆，情节记忆构建日记本，三者构成现代上下文工程主体。

未来 Agent 记忆可归纳为三大类五种机制。短期有历史缓冲，长期有语义检索与情节记忆，策略有程序记忆与跨体共享记忆，后者依托 MCP 与 A2A 协议实现多 Agent 安全共享，正成为云端智能基础设施。从上下文工程到 MaaS 跃迁，标志着记忆从技巧升级为智能时代的核心基础设施。
