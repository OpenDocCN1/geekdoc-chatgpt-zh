# 一句话成型：发型试戴与产品虚拟拍摄

理发店里最常见的沟通难题是，剪之前怎样让顾客直观看到效果。传统做法是翻发型图册，但图上模特的脸型、肤色、发质往往和顾客不符，想象成本很高。是否可以让顾客上传一张自拍，AI基于同一张脸快速生成短发、长发、卷发、直发等多种效果图，直观对比不同方案？

这正是 3.1 节要落地的第二个原型——智能发型试换工具 VirtualStylist AI。它的核心作用是帮助美发师快速呈现多套发型方案，让顾客在下剪前预览结果，提升决策效率，同时降低试错与沟通成本。

#### 1. 用一句话把需求说清楚

想开发一个工具，上传人物照片后，AI能自动生成多种不同发型的效果图，让客户在剪发前就能看到效果。

这句话概括了工具的核心能力，但后续AI会自问：如何保持脸型不变？支持哪些发型？怎样保证自然真实？

Gemini 3 的思考会从明确目标开始：构建一个基于上传人像的智能发型试换工具，而非通用图像生成。整个过程分为以下5个阶段。

### 3.1.3 产品场景虚拟拍摄工具

3.1.1 节和 3.1.2 节介绍了用一句话想法开发应用的极简方式和参考文档写法迭代优化的中级技巧。本案例进入更复杂的场景：需要多模型协作、完整技术选型的商业级应用开发。3.1.3 节将引入架构思维，用完整的 MVP 文档定义产品，用技术选型说明实现方案。

在电商运营与品牌设计师的日常里，产品拍摄环节往往耗时耗力。传统专业拍摄需搭建场景、准备道具、协调摄影师，成本高且周期长。同一产品还需适配室内居家、户外、办公、日常使用等多种场景展示图，每个场景都要单独拍摄，进一步推高成本。那么，有没有办法只需上传产品图，AI 即可自动将其与生成的不同场景自然融合，快速制作电商宣传图、社交媒体广告及商业海报，而无需实景拍摄和复杂后期？

这正是 3.1 节即将构建的第三个工具：产品场景虚拟拍摄 MagicLens AI 工具。其核心价值在于摆脱对昂贵商业摄影与场景搭建的依赖，以低成本实现场景化营销，快速生成多种风格的产品宣传素材。与传统摄影相比，该工具可使平均成本降低 80% 以上，使制作周期从数天缩短至数分钟，助力每个品牌轻松获取专业级产品展示图。

##### 1. 典型用户画像
**独立电商卖家或个人创作者，他们急需高质量的商品宣传图用于上架或社交媒体推广，但既没有专业摄影预算，也不懂复杂的修图设计软件。**

##### 2. 场景故事
**用户随手在杂乱的桌面上拍了一张自制的香薰蜡烛照片，上传到工具后，一键选择了"温馨卧室"场景，30秒后就得到了一张仿佛是在精装样板间拍摄的、光影自然的专业级产品宣传图，并直接发到了小红书上。**

##### 3. 功能描述（MVP核心功能）
**图片上传：** 支持用户拖动或点击上传本地产品图片（仅限JPG/PNG格式）。
**智能自动抠图：** 图片上传后，系统自动识别主体并去除背景，仅展示保留的主体供用户确认（不提供手动修补功能，以降低开发和操作成本，依赖算法精度）。
**场景模板选择：** 提供6-10个高频预设场景标签供点选（例如：大理石展台、木质桌面、自然阳光、纯色极简棚拍、户外草地），**不支持**用户自定义输入文字提示词。
**一键生成：** 点击生成按钮，AI自动调整光影、透视，将抠图后的产品融合进选定场景，一次生成2张供选择。
**图片下载：** 支持将生成满意的图片下载到本地（标准分辨率）。

##### 4. 交互流程
##### 1. 典型用户画像
**急需为抖音/TikTok/小红书制作动态素材的电商卖家，他们拥有一张静态产品图，希望零门槛将其转化为具有运镜感或光影动态的高级短视频。**

##### 2. 场景故事
**用户生成了一张满意的“阳光下的香水”场景图后，觉得静态图不够吸引人，于是点击“生成视频”，选择了“缓慢推进”特效。1分钟后，一张原本静止的图片变成了镜头缓缓推进、光影在瓶身上流转的5秒短视频，用户直接下载并作为广告素材发布。**

##### 3. 功能描述（MVP核心功能）
- **图片上传与抠图：** 支持上传本地图片，自动完成主体抠图。
- **场景图生成：** 基于预设模板（如大理石、户外自然等）生成静态融合图。
- **视频动效预设：** 仅针对**已生成的场景图**提供3-4种基础运镜/动态模板（例如：缓慢推近、横向平移、环绕展示、光影流动），**不支持**自定义运镜轨迹。
- **一键转视频：** 点击选定的动效，AI基于静态图通过图生视频（I2V）技术，生成时长为4-5秒的MP4视频。
- **结果下载：** 支持下载JPG图片或MP4视频文件。

##### 4. 交互流程
1. **上传与场景化：** 用户上传产品 -> 自动抠图 -> 选择场景 -> 生成静态宣传图。
2. **满意度确认：** 用户在生成的静态图中，点击自己最满意的一张，进入详情/大图预览模式。
3. **视频转化：** 在大图下方点击“转为视频”按钮，弹出动效选择浮层（如：推近镜头、水平运镜）。
4. **等待生成：** 用户点选一种动效，系统进入视频渲染状态（显示进度条，30-60秒）。
5. **预览与下载：** 视频生成完毕，自动循环播放预览，用户点击“下载视频”保存MP4文件到本地。

如果还想要添加或者修改某些功能，可以继续在 Playground 界面的对话框中输入新的提示词。

#### 2. 视频链路的技术决策
视频生成的技术选型，需要重点考虑以下两个问题。

- 安全风险：Google AI Studio 生成的应用会在前端暴露 API Key。
- 成本压力：视频生成模型的使用成本较高，开发者统一支付压力巨大。

为此，可以使用如下解决方案。

- 创建设置界面，让用户填写自己的 API Key。
- 模型服务选用胜算云 API（Google AI Studio 默认不支持调用可灵模型来生成视频）。这样每个用户使用自己的 API Key 访问服务，开发者无须代付模型费用。同时，对于这个工具的用户来说，只需使用一个 API Key 即可同时使用 Gemini 系列模型和可灵模型。
