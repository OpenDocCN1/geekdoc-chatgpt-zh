### 4.4 释放 Hugging Face 自定义训练的掌控力

Hugging Face 的默认训练脚本上手很快，但在实际项目里，写自己的训练循环、定义专门的评估指标，才能更精细地优化效果并满足任务个性化需求。下面先讲如何搭建可控的训练循环并设定评估标准，随后深入迁移学习与微调，通过冻结参数和定制优化策略，让预训练模型更好地迁移到目标任务上。

#### 4.4.1 手写训练循环与可视化评估

深度学习训练想要更灵活的调节空间，自定义循环是关键。手工实现循环可以自由调整损失函数、优化器以及监控指标。下面示例基于 PyTorch 调用 Hugging Face 的模型接口，完成可控训练并以准确率等指标收敛。

- (2) train_model 负责自定义训练循环，按批次算损失并反向传播，通过 optimizer.step() 更新权重，每个轮次结束后输出平均损失。

#### 4.4.2 迁移学习与微调：站在预训练肩膀上做任务

迁移学习的核心思路是借用已在海量语料上学习过的预训练模型，再针对特定任务做精调。Transformers 库提供了大量现成预训练权重，可以直接拿来微调。

可以把迁移学习理解成“借力打力”。从零训练一个复杂模型耗时耗力，而迁移学习是直接使用已经“学会”语言理解的预训练模型，就像请一位有经验的员工，它已掌握句法、语义等基础能力。

微调则像“专项培训”。模型虽有通用语言基础，但要适配情感分析、问答等具体场景，还需在任务数据上继续学习，就像给员工做定向培训。微调让模型在不从头学起的情况下快速适应新需求，省时省料。

# 定义评估函数

def evaluate_model(model, dataset):

    model.eval()

    predictions, true_labels = [], []

    with torch.no_grad():

        for data in dataset:

            inputs = {key: value.to(device) for key, value in data.items()

                      if key in ['input_ids', 'attention_mask']}

            labels = data["labels"].to(device)

            outputs = model(**inputs)

            logits = outputs.logits

            predictions.extend(torch.argmax(logits, dim=-1).cpu().numpy())

            true_labels.extend(labels.cpu().numpy())

    accuracy = accuracy_score(true_labels, predictions)

    print(f"评估精度: {accuracy * 100:.2f}%")

# 开始迁移学习的微调训练与评估
