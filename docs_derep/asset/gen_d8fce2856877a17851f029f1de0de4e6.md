- (1) alpha 缩放系数：使用 LoRA 做变换时，实际等价于用 BA 矩阵去替代原始权重 W，操作中会引入一个缩放比例 scale，其计算方式为 lora_alpha 除以 r。该比例决定了适配器权重起步时的大小。
- (2) dropout：属于深度学习里的常规正则手段，通过随机丢弃部分神经元的输出来让训练更稳定、泛化更强，提升学习过程的鲁棒性。
- (3) taskType：因为目标是文本生成，所以选用 CAUSAL_LM 模式。PEFT 库提供多种高效微调方案，LoraConfig 就是其中一种，可以按任务需求直接配置。

## 10.2 大模型接入数据库

### 10.2.1 大模型挑战
大模型应用中面临的两大核心难题是知识库非实时以及对特定领域知识的匮乏。这源于通用模型知识更新滞后和专业领域覆盖狭窄。研究人员尝试的两条路径：一是借助提示技术在模型回应前补充情境信息，但受限于上下文长度的物理限制；二是参数微调实现信息持久化存储，此法虽有潜力，却技术门槛高、计算资源消耗大，且易引发原有知识遗忘。

鉴于此，探索能高效利用局部知识库进行问答的方案变得迫切。其中 Function Calling 作为一种新兴策略脱颖而出，它可动态触发外部函数，增强模型即时吸收和处理专业及新线的能力，对构建 SQL 代码解析器这类任务尤为关键。该工具让模型在面对复杂数据编程查询时，能结合内部知识与外部专业函数调用，加深对代码构造与逻辑的理解。

Function Calling 在 SQL 代码解析器中的应用，旨在弥补大模型在专业领域的能力鸿沟，尤其在技术快速迭代背景下，提供一个动态适应、灵活且具备专业洞察力的交互学习辅助工具，推动 AI 在软件开发、数据分析等领域实现更深广的应用。下面将深入探讨如何利用 Function Calling 特性创建高效的 SQL 代码解析器。
