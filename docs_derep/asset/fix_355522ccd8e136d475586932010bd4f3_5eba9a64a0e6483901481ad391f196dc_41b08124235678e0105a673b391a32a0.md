# 属性定位

自然提问里藏着大量口语化的字段指代，工作重心是把这些意图挖出来并统一到知识库里能识别的标准属性名。流程很清晰：先让 AC 自动机在整句上跑一遍收集所有命中，去除重复后如果打开映射开关，就借助同义词表把口语表达换成规范字段。

def _map_predicate(nl_query, map_attr=True): # 将同义属性映射到知识库中的属性 def _map_attr(word_list): ans = [] for word in word_list: ans.append(attr_map[word.encode('utf-8')][0].decode('utf-8')) return ans match = [] # 预先读取字典，通过匹配的方法找出问句的属性名 for w in attr_ac.iter(nl_query.encode('utf-8')): match.append(w[1][1].decode('utf-8')) if not len(match): return [] ans = _remove_dup(match) if map_attr: ans = _map_attr(ans) return ans
