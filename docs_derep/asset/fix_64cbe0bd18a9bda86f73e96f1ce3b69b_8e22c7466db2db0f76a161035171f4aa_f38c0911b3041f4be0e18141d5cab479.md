## 6.3 线性支持向量机
### 1. 原理模型
如图 6-3 所示，圆点代表正类，三角代表负类。当训练数据仅近似线性可分时，即存在少数异常点，无法找到一个超平面使正负类严格分离，约束式 (6-5) 不再恒成立，如图 6-4 所示。

[PRE10]

[PRE11]

此时，对每个样本 (x_i, y_i), i=1,2,⋯,N，引入松弛变量 ξ_i ≥ 0，则式 (6-5) 可松弛为

y_i(w^T x_i + b) ≥ 1 - ξ_i,     i=1,2,⋯,N  (6-20)

由此会出现几种情形：ξ_i = 0 时样本被正确分类且落在超平面②上方或③下方；0<ξ_i<1 时样本仍正确分类但已落在中间带内，如图 6-4 中的样本 1、2；ξ_i =1 时样本正好落在分界面①上，如图 6-4 中 3、4；ξ_i >1 时样本被误分，正类出现在①下方，负类出现在①上方，如图 6-4 中样本 5、6、7、8。显然 ξ_i =0 是理想情况，ξ_i ≠0 则意味着代价。

允许少数样本出现 ξ_i ≠0，但需加以惩罚。因此在式 (6-7) 目标上增加惩罚项：

min_{w,b,ξ} ½ ||w||² + C Σ_{i=1}^N ξ_i  (6-21)

其中 C>0 为惩罚参数，由问题性质决定，ξ=(ξ₁,ξ₂,…,ξ_N) 为松弛向量。C 越大，对误分的惩罚越重，可容忍的错误越少；C 趋于无穷时模型回到硬间隔。C 越小，惩罚越宽松，允许的错误越多。目标式 (6-21) 的含义是同时压低 ½||w|| 与 C Σ ξ_i，即增大间隔 2/||w|| 并减少误分，C 起协调作用，也称松弛因子，可在一定程度上缓解过拟合，增强对噪声的鲁棒性。

特别地，与超平面②和③相交、落在中间带内或被误分的样本，即图 6-4 中带圆形边界的点，对模型起决定性作用，称为支持向量。

### 2. 优化模型
据此得到 SVM 的软间隔最大化优化模型：

\begin{cases}
\min_{w,b,\xi} \frac{1}{2} \|w\|^2 + C \sum_{i=1}^{N} \xi_i \\
\text{s.t. } y_i(w^{T}x_i + b) \ge 1 - \xi_i, i = 1,2,\cdots,N \\
\xi_i \ge 0, i = 1,2,\cdots,N
\end{cases}
(6-22)

也称为线性支持向量机模型。此问题仍是凸二次规划，可证最优解存在但不唯一，其中 w 唯一而 b 在区间上变化。设式 (6-22) 的一个最优解为 (w*,b*)，则最大间隔分离超平面为 w*ᵀx + b* = 0，对应决策函数为 f(x) = sign(w*ᵀx + b*)。可见线性可分支持向量机是线性支持向量机的特例 ξ_i=0，而实际数据往往不是严格可分的，故软间隔模型适用范围更广。

### 3. 对偶算法
### (1) 对偶问题
该问题同样可用拉格朗日乘子法求解。原始优化问题式 (6-22) 的对偶问题为

\begin{cases}
\min_{\lambda} \frac{1}{2} \sum_{i=1}^{N} \sum_{j=1}^{N} \lambda_i \lambda_j y_i y_j x_i^{T}x_j - \sum_{i=1}^{N} \lambda_i \\
\text{s.t. } \sum_{i=1}^{N} \lambda_i y_i = 0 \\
0 \le \lambda_i \le C, i = 1,2,\cdots,N
\end{cases}
(6-23)

设其解为 λ* = (λ₁*,λ₂*,…,λ_N*) ∈ R_+^N，则原始解为

w^* = \sum_{i=1}^N \lambda_i^* y_i x_i, \quad b^* = y_j - \sum_{i=1}^N \lambda_i^* y_i x_i^{T}x_j
(6-24)

其中 j 满足 0 < λ_j^* < C。由此可得分离超平面 w*ᵀx + b* =0，以及决策函数

f(x) = sign( \sum_{i=1}^N \lambda_i^* y_i x_i^{T}x - \sum_{i=1}^N \lambda_i^* y_i x_i^{T}x_j + y_j )
(6-25)

### (2) 对偶算法
对近似线性可分的训练集，先求解对偶问题式 (6-23)，再用式 (6-24) 还原原始解，进而得到分离超平面与决策函数式 (6-25)，此即线性支持向量机的对偶算法。步骤如下。

设训练集 D = {(x₁,y₁),(x₂,y₂),…,(x_N,y_N)}，其中 x_i ∈ ℝⁿ, y_i ∈ {-1,1}, i=1,2,…,N。

- 1. 构造并求解约束优化问题式 (6-23)。
- 2. 利用式 (6-24) 计算 w^*，选取 λ^* 的一个满足 0<λ_j^*<C 的分量，利用式 (6-24) 计算 b^*。
- 3. 得到分离超平面为 w*ᵀx+b*=0，以及对应的分类决策函数式 (6-25)。

设原空间为二维，原正类为 |(0,0),(1,1)|，原负类为 |(1,0),(0,1)|，不存在线性超平面将其分开。定义映射 φ:T→ℝ³:x→z，

z=φ(x):=(x¹,x²,x¹x²),   ∀x∈T  （6-26）

该映射把正类变为 |(0,0,0),(1,1,1)|，负类变为 |(1,0,0),(0,1,0)|，平面

z¹+z²-2z³-1/3=0  （6-27）

即可将其分开，如图 6-6 黄色平面。
