# 7. 问答式提问：让AI精准作答

工作、学习和生活里常会遇到各种疑问，比如：

今天天气如何？
长期熬夜有哪些危害？
萤火虫为何会发光？
红酒的口感和品质是否受产地影响？
Irregardless 这个词是什么意思？

面对资讯查询或专业知识点类需求，用AI充当外脑式的搜索引擎，能更快获取信息、解决问题、提升效率。

怎样提一个好的问答式问题？

先弄清问答式问题的常见分类。

# 类型一：事实型提问（A是什么？）

眼泪为何偏咸？
一年总共多少天？
赤道周长是多少千米？

# 类型二：概念型提问（A的含义是什么？）

领导力指什么？
公约数是什么意思？

# 类型三：比较型提问（A和B有何区别？）

柏拉图与亚里士多德的政治思想有何不同？
印象派和立体派的艺术风格差异在哪？

# 类型四：因果型提问（A会对B产生什么影响？）

长期压力对身心健康会带来哪些影响？
气候变化与自然灾害如何影响地球环境？
原子和分子的运动方式如何决定物质的性质和状态？

# 类型五：假设型提问（假设A，会怎样？）

如果人类能飞，会催生哪些新职业？
假如世界没有摩擦力，会发生什么？
若AI拥有情感，它最先会做什么？

# 类型六：方法型提问（如何完成A事/解决A问题？）

- 如何开展一次有效的工作学习调查？
- 如何做好向上管理？
- 怎样提出一个高质量的问答式问题？

# 类型七：意义型提问（A对B有何意义？）

人类存在对地球而言意味着什么？
教育的价值是什么？

除此之外，可将不同类型的问答组合使用，得到更丰富的结果。

例如，事实型 + 意义型：
企业的社会责任是什么？企业对经济发展的贡献体现在哪里？

假设型 + 方法型：
假设世界上有哆啦A梦的记忆面包，人类记忆能否因此增强？我们该如何强化记忆力？

常见组合参考：

事实型 + 意义型：A是什么？它对B有何意义？
概念型 + 比较型：A的含义是什么？A和B有什么区别？
概念型 + 因果型：A的含义是什么？A会对B产生什么影响？
假设型 + 方法型：假设A会怎样？如何解决B问题？
……

问答式提问的适用场景很多，例如：

| 场景 | 示例 |
|------------|----------------------------------------------------------------------|
| 用 AI 生成配音 | 事实型 + 方法型：市面有哪些AI配音工具？这些工具该怎么用 |
| 用 AI 设计产品 | 假设型 + 比较型：假设你是一名设计专业大一新生，选购电脑时会更看重外观还是性能 |

# 延伸应用

使用问答式提问时，AI的优势在于：

◎ 知识覆盖面广
几乎能覆盖科学、历史、文化、技术等各领域，输出具备一定准确性。

◎ 擅长拆解复杂问题
能把难题用通俗的语言解释清楚，并生成连贯流畅的文本。

◎ 响应速度快
短时间内即可生成回答。

基于这些特点，可在以下场景使用问答式提问。

# 1. 知识查询：快速学习各学科

向AI提出特定学科问题，获取解释、定义、示例和背景，帮助快速理解。

示例。

科学：
量子力学的基本原理有哪些？
基因编辑技术是什么？它对人类有何影响？

历史：
古埃及文明有哪些特征和成就？
文艺复兴是什么？它对欧洲产生了怎样的影响？

文学：
最近哪位作家获诺贝尔文学奖？
现实主义文学的特点和代表作品有哪些？

艺术：
印象派绘画风格有何特点？代表画家是谁？
文艺复兴时期有哪些著名雕塑家？

经济：
哪些因素在影响经济增长？
现代经济学中有哪些重要思想家？

# 2. 语言学习：高效掌握外语

学习外语或翻译文本时，可围绕语法、词汇、翻译提出问答式问题，获取学习资源、方法和翻译支持。

可这样问：

英语主谓宾结构的使用规则是什么？有什么例子？
英语有哪些时态？各自怎么用？
“How are you?” 中文怎么说？
如何提升英语口语流利度？
怎样克服语言学习的困难和挫败感？

# 使用提醒

1. 虽然AI知识库丰富，但在法律、医疗等专业领域只能作参考，不能替代专业人士。
2. 遇到复杂问题时，建议用简洁、清晰、明确的表述，便于AI理解并给出更准确的答案。

# 摘要提问：

# 快速压缩长文本

摘要提问的典型场景包括：

阅读新闻报道、学术论文等资料并快速抓住核心时；
领导发来大段任务要求，自己抓不住重点时；
想快速了解一部小说的关键剧情时；
……

此时可用摘要提问让AI压缩长篇信息，提炼要点、节省时间、提高效率。

但提问方式不当，回复往往很笼统。

比如下面这个案例，原意是想让AI快速读完一本书，却因提问不精准导致回答空泛。

那么，怎样算好的摘要提问？

可借助“坐标轴思考法”来设计问题。

对比四个象限的示例不难看出，好的摘要提问应带有明确且量化的指令。

用优化后的问题提问，得到的回答会更符合预期。

> 请详细概括《哈利·波特》系列第一部的剧情。

> 《哈利·波特与魔法石》是系列首部，故事围绕哈利的成长与他在霍格沃茨的奇幻历险展开。

# 延伸应用

信息爆炸时代，我们接收大量资讯，其中很多是噪音。

用摘要提问可剔除冗余、抓取要点、提升学习工作效率。常见场景如下。

# 1. 知识库整理：让知识更清晰

建立知识库时常会堆积大量资料，文件、链接分散且过载。

例如搭建工作效率知识库，收集多篇长文时，可用摘要提问提炼精华或知识点。

可这样问：

> 请阅读以下关于工作效率的文章，围绕“如何提高工作效率”分点概括。（文章内容，略）

> 请精简以下文字，并用表格说明影响工作效率的因素有哪些。（文字内容，略）

再将AI生成的内容分类整理，就能得到条理清晰的知识库。

# 2. 目标梳理：让工作更有计划

面对繁杂的KPI、领导要求、客户需求，工作常显得混乱。

此时可用摘要提问提炼会议、报表等关键信息，从繁杂中梳理脉络，快速确定目标和计划。

# 例：提炼客户需求

我是一名平面设计师，客户要求做一张产品宣传海报，请从以下需求中提炼出海报风格。客户需求如下。

海报目的：宣传新上市耳机。
目标人群：运动爱好者，20~35岁。
产品特点：防汗防水、佩戴稳定、适合运动。
文案：无线自由，释放激情。
场景：运动场上，活力运动者戴着耳机投入运动。
尺寸布局：A3或A2，竖版。
投放渠道：微博、小红书等新媒体。
其他要求：吸睛、色彩鲜艳。

提炼结果：

1. 动感活力风格：传递运动感，用动态线条、流畅曲线、运动元素营造氛围，配合渐变色彩、流动图形表达无线自由、释放激情的概念。
2. 年轻时尚风格：运用时尚排版、流行图标、年轻化元素，突出潮流属性，提升与年轻受众的契合度。

综合以上，可设计一张兼具动感活力、年轻时尚并突出产品特点的海报，在新媒体平台吸睛传播。

# 例：提炼领导期望

领导的这几段话表达了对我工作的期望，请帮我提炼下一步目标。

今天找你聊聊近期表现和成果。很欣赏你的创意和设计风格，很独特，给项目带来新鲜感和视觉冲击，客户也常赞赏，有助品牌影响力提升。

不过也有待改进。和客户沟通时，有时没完全理解需求。充分理解需求才利于后续沟通和设计，希望加强。设计过程中你可能过度强调个人审美，忽视项目整体目标，比如此前给××公司做的包装设计。个人审美重要，但团队协作、跨部门配合更重要，满足客户期待才是核心目标。我相信你能克服挑战。

作为优秀设计师，在团队中角色重要。不断学习成长也很关键。希望你积极参加相关培训，保持对设计趋势和新技术的关注。多与部门同事交流，分享经验灵感，有助提升水平。

今天说了很多，我对你很有信心……

提炼目标：

1. 提升客户沟通能力：更深入理解客户需求，在设计中准确把握要求，给出更精准方案。
2. 平衡审美与项目要求：在个人审美和项目整体目标间取得平衡，强化团队协作与跨部门配合，以满足客户期待为核心。
3. 持续学习成长：积极参与培训，保持对设计趋势和新技术的敏感，提升专业能力。
4. 加强内部交流：与同事多沟通、分享经验灵感，提升个人和团队效能。
5. 保持信心并适时求助：展现自信，必要时向领导和团队寻求支持，相信自己能解决问题。

注意：提问时勿泄露公司和客户商业机密，并保护个人隐私。

# 使用提醒

1. AI可对各种长度文本进行精简和关键信息提取。
2. 使用摘要提问时，最好提供：原始文本、摘要长度或字数要求、摘要类型（概括式还是详细式）。信息越完整，指令越明确越好。
3. 若生成摘要有误或过长，可指令其继续修改。

# 9 对话式提问：

# 让沟通更人性化

是否遇到过领导在微信发来“辛苦了”三个字，不知如何得体回复？

不必苦想，可用对话式提问让AI生成回复备选，自行挑选。

你可能这样问：

- 领导说“辛苦了”，怎么回？
- 回复可根据情境和上下文决定，以下是常见方式。
  1. 谢谢，我会继续努力工作的。
  2. 没关系，这是我的责任。
  3. 感谢您的鼓励，我会持续为团队贡献。
  4. 辛苦是值得的，团队协力才能取得成果。
  5. 谢谢关心，您的支持对我很重要。
  选择方式取决于你与领导关系、工作环境和个人风格。

优化提问：

和团队一起加班完成工作后，领导对我说“辛苦了”，我该怎么回？要求有礼貌、简洁明了，同时表达感谢。

可回复：

非常感谢您的关心，这是我们团队共同努力的结果。

这个回复有礼貌、简洁，同时表达了感谢并强调团队合作，展现你重视协作而非个人英雄主义，让领导感受到你的格局。

具体来说，使用对话式提问时，为保障准确性和质量，可向AI提供：

· 对话主题：希望生成的对话主题是什么，例如旅游、科技、文化等。
· 对话角色：参与者的身份是什么，彼此关系如何。
· 对话场景：对话在什么情境下展开。
· 对话目的：希望达成什么结果。
· 对话语境：提供上下文，使AI生成连贯对话。
· 语言风格：期望的风格，如正式、轻松、幽默等。
· 对话长度：需要多长的输出。
· 参考资料：提供百科词条、相关文章、对话样本等。

实际使用时不必面面俱到，但心里要有数，随时调整优化问题，获得更满意的回复。

# 延伸应用

AI具备强大的文本分析能力，可在特定情况下替代人类完成部分自动化对话。

同时AI学习能力强、发散性“思考”能力出色，生成的对话常带来惊喜。

# 1. 小说创作：让对话更真实

创作小说时需考虑：角色何时开口、说什么、如何让不同性格角色说出合适的话、如何处理每位角色的特殊表达……

从读者角度，还需思考：如何通过对话传递角色动机，如何通过对话刻画内心世界……

可见编写小说对话并非易事，需要丰富阅历和想象力。

遇到瓶颈时，可借助AI生成对话，让角色交流更真实、更符合个性特征。
