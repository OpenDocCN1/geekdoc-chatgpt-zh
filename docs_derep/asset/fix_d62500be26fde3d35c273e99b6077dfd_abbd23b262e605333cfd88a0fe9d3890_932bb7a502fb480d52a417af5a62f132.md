2）检索环节：使用者提出问题后，平台先用一条 LLM 提示对原始提问做改写，把 LLM 作推理引擎对输入做语义校准，使意图和知识含义贴合并提升命中效果。接着再用另一条 LLM 提示生成检索路径，决定采用摘要式、向量式还是其他形式。最后依据该路径在向量库中执行搜索，结合索引做相似度比对，返回最相关的前 k 条结果。

3）重排环节：对第 2 步得到的候选集，采用既定排序方法进行二次排序。

4）作答环节：设计一条 LLM 提示，约束生成模型只能基于检索步骤获得的背景信息来回应使用者的提问。

### 10.2 结构化是 RAG 在法务场景落地的关键

在法务场景里，知识是否结构化直接决定检索和处理的效率。结构化法律知识即把法规、判例、实务文章以系统化、规范化的方式组织和表征。经结构化后，检索更便捷，利用率和精确度也明显提升。

结构化的法务知识库对 RAG 至关重要。RAG 将检索和生成结合，从海量文本中取用相关信息再生成内容。法律知识经结构化后，RAG 方案能更精准定位和抽取所需信息，为使用者提供更高质量的法律服务。

**10.2.1 结构化法律知识的构成要素**

❑ 法规：效力层级、适用地域、时效、颁布机关、发布日期、施行日期、标题、编章、节、条、款、项，以及援引法规、法条、法条沿革。

❑ 案例：案由、审理法院、地域、案件类型、审理程序、标题、法院观点、裁判结果、援引法条等。

❑ 实务文章：发布时间、标题、正文、援引法规法条、援引案例等。

**10.2.2 结构化的方法和技术路线**

❑ 信息提取：借助文本理解技术从法律知识里提炼结构化信息，例如法规的标题条款、案例的当事人案由法院观点等。常用手段有实体标注、关系抽取和规则分段提取。

❑ 索引与向量转换：对法律材料做检索词抽取和索引，同时做向量特征抽取并入库存储。

❑ 图谱化：对存在关联的知识进行实体标注和关系抽取，用图的方式呈现内在联系。

### 10.3 RAG 工程化的五步走法

在既有工作流基础上，RAG 的工程化通常包含以下环节。

1）数据准备：采集大量法规、判例与实务文章，经清洗、标注、分段、标准化后完成向量化。

2）检索模型训练：利用手工标注数据训练检索模型，使其能根据查询快速命中相关文档。

3）生成模型训练：在海量法律文本上训练，使生成模型具备高质量文本生成能力。常见模型如 GPT 系列、BERT 等。

4）RAG 方案集成：将检索和生成模型融合。收到的查询先由检索模型找相关文档，再送入生成模型处理并输出最终答案。

5）性能优化：通过反复测试和调参，让方案在回答法律问题的速度和精确度上持续提升。

### 10.4 法律文书自动生成的价值与架构

法律文书自动生成融合了前沿的文本理解和 AI，为行业带来革命性工具。它可自动撰写合同、法律意见书、诉讼文书等，大幅简化文档创建流程。

传统文书撰写耗时且对精确度与术语要求极高。基于大模型和 RAG 的自动生成能力，可理解法律语言的复杂性，并按使用者需求智能生成结构化、规范化的法律文本。

减少人工介入后，生成速度、精确度与一致性均得到提升。法律从业者可把精力投向需要专业判断的分析与策略。自动生成的文本结合专业知识库与实时更新的法律数据，确保合法合用，提供高效可靠的文档方案。

本节从技术实现角度拆解其架构、流程与落地细节。

**4. 数据层**

主要覆盖法规数据、案例数据、实务文章数据、企业主体数据，以及少量网络公开数据。

## 法律 AI Agent 的设计蓝图

第九章已简要提及 AI Agent，本章深入展开法律 AI Agent 的概念与延伸。

在法律的严谨领域里，AI 正如春风吹拂传统服务的边界。随着技术演进，法律 AI Agent 已非科幻概念，而是法律专业人员的得力助手。本章将探讨其设计哲学、演进脉络与效果评估方法，展现其在提升服务质量、效率与可及性方面的潜力。

### 11.1 法律 AI Agent 的发展历史

Agent 通常指能独立执行任务、做决策并与环境交互的智能体，可表现为聊天机器人、个人助手、推荐系统等，能理解指令并响应。

法律 AI Agent 的演进是逐步深化的过程。

**1. 早期探索**
❑ 专家式系统：早期可追溯至专家式系统，通过模拟专家决策提供建议，但局限于特定领域的简单任务。
❑ 文档检索：初期应用集中于文档检索，帮助律师快速找到相关法律文件与案例。

**2. 技术突破**
❑ 文本理解：文本理解进步后，Agent 开始理解并处理自然语言，提供更复杂的分析与建议。
❑ 知识管理：法律知识管理成为发展关键，通过构建与维护知识库提升信息准确性与建议质量。

**3. 现代发展**
❑ 深度学习：深度学习的引入大幅提升处理复杂法律问题与深入分析的能力。
❑ 多模态处理：现代 Agent 不仅处理文本，还能处理图像、音频等多类型数据，提供更全面的服务。
❑ 定制化服务：借助机器学习与使用者行为分析，提供量身定制的法律建议。

**4. 应用场景扩展**
❑ 法律咨询：快速响应使用者问题并提供初步建议。
❑ 合同管理：自动审查合同条款，识别风险与合规问题。
❑ 案件预测：基于历史案例与法律数据预测结果，为策略制定提供支持。

**5. 未来趋势**
❑ 集成化：与电子发现系统、法律文档管理系统等工具融合，提供一站式服务。
❑ 伦理与合规：日益突出，需在设计与应用中强化伦理与合规，确保服务符合法律与道德标准。

### 11.2 法律 AI Agent 的设计方法和步骤

设计过程是多学科融合，涉及法律知识、人工智能与人机互动等。

（1）使用者界面设计
❑ 互动性：支持语音、文本、图形等多模态自然互动。
❑ 可访问性：兼顾不同能力与背景使用者，提供视力或听力障碍辅助功能。
❑ 定制化：允许使用者按偏好与工作流自定义布局与功能。

（2）知识库构建
❑ 结构化：以结构化形式存储法律知识，便于检索与更新。
❑ 动态更新：设计实时或定期更新机制，反映最新法律动态。
❑ 多源整合：融合官方文档、学术文章与案例数据库等多源数据。

（3）算法与模型开发
❑ 深度学习：用于处理与分析海量法律文本。
❑ 文本理解：开发高级 NLP，使 Agent 能理解复杂法律语言与概念。
❑ 推理能力：集成逻辑推理算法，支持法律逻辑推演与案例分析。

（4）适应性与灵活性
❑ 模块化设计：采用模块化架构，便于按不同法律领域定制与扩展。
❑ 上下文感知：理解并适应不同法律情境与使用者需求。
❑ 使用者反馈学习：通过反馈持续优化性能。
