[PRE0]

If dictA(value) = 1 And Not dictB.Exists(value) Then

    cell.Interior.Color = RGB(255, 255, 0)

End If

End If

Next cell

' 标记列B中符合条件的单元格

For Each cell In dataB

    If Not IsError(cell.Value) Then

        value = cell.Value

        If dictB(value) = 1 And Not dictA.Exists(value) Then

            cell.Interior.Color = RGB(255, 255, 0)

        End If

    End If

Next cell

MsgBox "处理完成!"

End Sub

##### 代码说明：

###### 1）交互体验
- 借助 Application.InputBox 让用户交互式选取数据区
- 支持鼠标框选或点选，自动忽略非法操作

###### 2）范围解析
- 结合 Intersect 与 UsedRange 智能定位有效区域
- 自动剔除空白行列，仅处理真实占用区

###### 3）比对核心
- 用字典对象存储与检索，提升效率
- 两套字典分别统计两栏出现次数
- 自动跳过错误值单元格

###### 4）着色规则
- 仅满足以下条件才标黄：本栏内唯一一次出现，且在另一栏完全缺席
- 保留原有格式，只改符合条件的底色

### 6.3 在 Word 中对话式使用 DeepSeek
职场节奏快，文档处理占用大量时间。撰写报告、翻译文件、整理会议纪要都渴望更高效的工具。AI正带来革新，本节介绍如何把DeepSeek接入Word，实现对话式智能办公。

设想一下，把英文合同草稿快速翻成中文，让DeepSeek润色工作汇报，或在写方案时与AI头脑风暴，都可在熟悉的Word界面完成。

> **应用场景演示一：跨国合作，文档即时翻译**
**场景：** 外贸业务员小李收到海外客户的英文合同草稿，需迅速译成中文供团队审阅。
**传统做法：** 复制到在线翻译工具或用Word自带翻译，步骤多且易乱格式。

**场景：** 行政助理小王每次都要从冗长纪要里提炼要点和待办，耗时费力。
