#### 7.5.2 等待时间机制

线程处理完后通常要等待一段时间再参与调度，线程从就绪到运行也存在耗时。实际应用中如每 5 秒采一次温湿度，就需要借助延时实现周期执行。

系统时钟 Tick 是由定时器计数器产生中断形成的脉冲标记，系统对其计数。时钟周期是两个 Tick 间的时长。

Hi3861V100 每秒产生 100 个 Tick，每个 Tick 为 10ms。注意时钟周期 Cycle 与 Tick 不等价，Tick 是中断标记点，周期是间隔时长。延时相关 API 见表7-5。

### 表7-5

| API 名称 | 说明 |

| :--- | :--- |

| osDelay | 延时指定 Ticks |

| osDelayUntil | 延时至指定 Tick |

执行 osDelay 后线程从运行态转阻塞态，时间到后重新进入就绪态。若该线程为最高优先级，时间到即立刻运行。

osDelay(n) 从此刻起等待 n 个 Tick，精度要求不高时可近似认为 osDelay(n)=n×10ms。

#### 7.5.3 GPIO

##### 1. GPIO 概述

GPIO 即 General Purpose Input Output 通用输入输出，也称总线扩展器，由引脚与功能寄存器构成，不同架构封装差异较大，细节参考芯片手册 GPIO 章节。

GPIO 主要用于控制其上连接的外设。通过原理图找到板上引脚或排针位置，将外设接上去即可交互。驱动层通过读写功能寄存器改变外设状态。

Hi3861 集成 15 个 GPIO 引脚，内部 GPIO 模块实现数字 I/O。

##### 3. GPIO 输出高低电平

GPIO 工作模式主要有三种：

输入模式：读取外部信号。

输出模式：驱动外部设备。

复用功能：复用为 I2C、UART、PWM 等外设接口。

输出模式下可输出 3.3V 高电平，单个引脚最大驱动电流约 4mA，适合驱动 LED 等低功耗器件，不适合电机等大负载。

#### 7.5.4 ADC

模拟数字转换器 ADC 将连续模拟信号转为离散数字信号，便于数字电路处理。

##### 1. ADC 接口特性

通道数量：多路输入，具体取决于封装。

分辨率：12 位，可分辨 4096 个电平。

采样速率：最高 1Msps，满足实时采集需求。

输入电压范围：0～3.3V，兼容常见传感器。

低功耗设计：支持休眠模式，适合电池供电。
