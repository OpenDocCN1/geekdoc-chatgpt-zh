数据可视化即用图表呈现信息，让洞察更直观。分析流程中不可缺少，ChatGPT 暂时无法直接绘图，但在选型、建议、指导、解读等方面仍有帮助：

(1) 推荐图种：依据数据特征与表达目标给出图表建议，如时间序列常用折线图，分类数据可选柱状图或饼图。
(2) 给出可视化建议：结合数据特点与使用场景，提示配色、图例、标注等。
(3) 指导制作：说明在不同软件中实现目标效果的操作路径。
(4) 图表解读：提炼趋势、异常、关联等，以文字输出。
(5) 叙事化呈现：将图表与结论结合，形成连贯故事。

# 8.1 选择合适的图表类型
可询问常见图种、适用场景与选型原则，整理结果如下。

常用图种及其使用情境与选择思路：

+ 1. 折线图：表现数据随时间或其他连续变量的变化轨迹，适合展示波动、长期走向或周期。
2. 柱状图：比较不同类别的数量或占比，纵向适合多类别，横向适合类别名称较长。
3. 饼图：展示各类别占整体比例，类别过多时可改用堆积柱状图或堆积面积图。
4. 散点图：探索两个连续变量关系，识别相关性、聚类或离群点。
5. 箱形图：呈现分布特征，包含中位数、四分位数与异常值。
6. 热力图：表现两个类别变量相关性或密度，适合大规模分布展示。
7. 地图：用于地理位置相关数据的分布或趋势。

选型要点：

+ 1. 明确意图，是趋势、对比还是关系。
2. 结合数据类型，连续型与离散型适配不同图种。
3. 重视可读性，确保核心信息清晰传达。
4. 匹配使用场景，如汇报或演示。
5. 保持简洁，避免复杂导致理解困难。

综合数据类型、目标、场景与可读性进行判断。
