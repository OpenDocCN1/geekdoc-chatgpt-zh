# 第 5 章 法律文本预处理

## 5.1 正则表达式

### 5.1.1 正则表达式的作用

在数据预处理与低质量数据清洗环节，正则表达式（`Regular Expression`，简称 `Regex`）常被用于执行特定的字符串操作。它是一种规则匹配模式，广泛应用于文本信息处理中的字符串检索与替换。通过预先定义特殊符号及其组合，正则表达式能够描述一系列具有特定特征的字符串集合。

其核心应用场景主要集中在模式匹配与数据捕获两大方面。模式匹配用于判断给定的输入字符串是否符合正则表达式的匹配逻辑。例如，校验注册用户输入的密码是否满足复杂度要求——即字符串需包含大小写字母、数字且达到一定长度。这要求正则表达式具备代表英文大写、小写、数字以及重复次数的特殊符号。数据捕获则是从特定输入字符串中，提取用户所需、符合正则规则的具体片段。例如，从身份证号码中提取出生年份以计算年龄，正则表达式便能精准定位并返回身份证中的出生年份字段。

### 5.1.2 正则表达式基础

通常情况下，正则表达式既能匹配具体字符，也能匹配位置。其匹配模式支持对字符串进行模糊描述。例如，当字符串长度不固定时，`Regex:wil{1,3}` 表示字符 `l` 连续出现 1 到 3 次。

在匹配特定字符时，利用字符类可以代表多种可能的字符。例如 `Regex:m[ae]n` 表示中间位置出现 `[ae]` 中的任意 1 个字符，从而同时匹配 `man` 与 `men`。若字符类包含字符较多，可使用连字符 `-` 简写范围：小写字母写作 `Regex:[a-z]`，大写字母为 `Regex:[A-Z]`，数字为 `Regex:[0-9]`。符号 `-` 在此处具有特殊含义（表示范围），相较于普通字符，它被称为元字符。若需匹配 `-` 符号本身，需在前面加上转义符 `\`，即 `\-`。

另一种位置模糊匹配的情况是“排除特定字符”。例如 `Regex:c[^cu]u` 可匹配 `cau`、`cbu`、`cdu` … `ctu`、`cvu` 等字符串，但排除 `ccu` 和 `cuu`。字符类开头的 `^` 代表取反，意为匹配除 `c` 和 `u` 之外的任意单个字符。借助转义符，部分简写形式可快速表示特定范围和类型的字符：

- `Regex:\d` 等同于 `Regex:[0-9]`，匹配任意单个数字。
- `Regex:\d+` 匹配 1 个或多个连续数字。
- `Regex:\d?` 匹配 0 个或 1 个数字。
- `Regex:\d*` 匹配 0 个至任意个数字。
- `Regex:\D` 等同于 `Regex:[^0-9]`，匹配任意单个非数字字符。
- `Regex:\w` 等同于 `Regex:[0-9a-zA-Z]`，匹配任意单个单词字符（数字、大小写字母）。
- `Regex:\W` 等同于 `Regex:[^0-9a-zA-Z]`，匹配任意单个非单词字符。
- `Regex:\s` 等同于 `Regex:[\t\r\n\v\f]`，匹配任意单个空白字符（含制表符、换行、回车、换页等）。
- `Regex:\S` 等同于 `Regex:[^\t\r\n\v\f]`，匹配任意单个非空白字符。

匹配任意字符可使用 `[\d\D]`、`[\w\W]` 或 `[\s\S]` 中的任意一种。

关于重复次数的限定符用法：
- `Regex:of{1,}` 表示 `f` 至少出现 1 次。
- `Regex:of{2,2}` 表示 `f` 精确出现 2 次。
- `Regex:of?` 等价于 `Regex:of{0,1}`，即 `f` 出现 0 次或 1 次。
- `Regex:of+` 等价于 `Regex:of{1,}`。
- `Regex:of*` 等价于 `Regex:of{0,}`，即 `f` 可出现任意次数或不出现。

此外，`Regex:.` 匹配除换行外的任意单字符；`Regex:^` 匹配字符串开头；`Regex:$` 匹配字符串结尾；`Regex:\b` 匹配单词边界；`Regex:\B` 匹配非单词边界。

### 5.1.3 正则表达式实战

Python 的 `re` 模块通过正则表达式实现字符串的匹配与捕获，使用前需 `import` 导入。以字符串 `The policeman arrested 536 suspects.Some of them were set free after 36 days.Goodman is a company，not a man.` 为例，分别使用 `re.findall('\w+', text)`、`re.findall('\d+', text)`、`re.findall('[^\d\s]\w+', text)` 提取所有单词、数字词及非数字单词，结果如图 5.1 所示：

若需捕获匹配模式中特定的子串部分，可使用括号 `()` 进行分组捕获。例如，要查找上述字符串中同时包含字符 `s` 和 `e` 的单词，正则写为 `re.findall(r'\w*[sS]\w*e\w*', text)`。若进一步想知道这些单词中 `s` 与 `e` 之间夹着什么字符，可用带括号的表达式：`re.findall(r's(.*?)e', text)`（注：原素材此处表达式似有笔误，逻辑上应为捕获中间内容）。反向引用可用于查找字符串中的重复字符。例如正则 `re.findall(r'((\w)\2{1,})', text)` 中，`\2` 指向第二个括号捕获的内容（即 `\w`），从而匹配连续重复的字符。括号中的竖线 `|` 表示“或”关系（分支选择）。例如，查找包含子串 `man` 或 `rest` 的单词，可用 `re.findall(r'(\w*man\w*|\w*rest\w*)', text)`。效果如图 5.2 所示：
