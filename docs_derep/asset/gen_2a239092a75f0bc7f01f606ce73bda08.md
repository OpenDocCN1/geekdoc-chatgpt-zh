# FAISS 驱动的检索增强生成实战

想让大模型回答更靠谱，关键是给它喂对上下文。下面用 SentenceTransformer 做语义编码、FAISS 做近邻检索、GPT-2 负责续写，演示一个可手动调参、还能按查询长度自适应的 RAG 小流程。

先搭好向量库和生成器，再把检索结果拼成提示喂给模型。检索深度 top_k、生成长度 generate_length 和采样温度 temperature 三个旋钮，直接决定答案的覆盖面和创造性。后面再加入查询长度判断，实现长短查询的不同策略。
