## 使用提示

- 若环境中已装 WPS，可通过 `--app wps` 指定使用；不指定时默认走 Word。
- 想观察实时操作画面，可加上 `--visible true`。
- 本工具定位为单份文档处理，不建议拿来进行大规模批量作业。

环境依赖方面，文档明确要求在 Windows 平台运行，且必须预装 Microsoft Word 或 WPS Writer；同时环境里要配置好 Python 以及 pywin32 库，才能让底层 COM 自动化正常调用。

上手指南里挑选了三个高频场景作示范：提取正文内容、批量查找替换、以及导出 PDF。这三条示例把脚本的调用思路讲清楚了，新手也能立刻上手体验。

功能总览一共列出十条常用指令，涵盖读取文本、查找替换、插入文字、套用标题样式、管理页眉页脚、添加分页符、合并文件、按页码拆分、导出多种格式、尾部加图。每条指令都附带简要说明和完整调用范例，基本覆盖日常文档自动化的需求。

文档末尾还补充了操作建议：通过 `--app` 可在 Word 与 WPS 间切换；`--visible` 能打开界面方便调试；同时提醒不要在批量场景下过度依赖可视化操作，以免影响执行速度与稳定性。

def parse_ranges(s: str):

    ranges = []

    for part in s.split(","):

        a, b = part.split("-")

        ranges.append((int(a), int(b)))

    return ranges

def cmd_split(args):

    app = get_app(args.app, args.visible)

    doc = open_doc(app, args.input)

    outdir = Path(args.outdir)

    outdir.mkdir(parents=True, exist_ok=True)

    ranges = parse_ranges(args.pages)

    for i, (a, b) in enumerate(ranges, 1):

        new = app.Documents.Add()

        rng = doc.Range(doc.GoTo(What=1, Which=1, Count=a), doc.GoTo(What=1, Which=1, Count=b + 1))

        rng.Copy()

        new.Range(0, 0).Paste()

        out = outdir / f"part_{i}.docx"

        save_as(new, str(out))

        new.Close()

    doc.Close()

    app.Quit()

def cmd_export(args):

    app = get_app(args.app, args.visible)

    doc = open_doc(app, args.input)

    fmt = WD_FORMAT_PDF if args.format == "pdf" else WD_FORMAT_TEXT

    save_as(doc, args.output, fmt)

    doc.Close()

    app.Quit()

def cmd_image(args):

    app = get_app(args.app, args.visible)

    doc = open_doc(app, args.input)

    rng = doc.Range(doc.Content.End - 1, doc.Content.End - 1)

    doc.InlineShapes.AddPicture(os.path.abspath(args.image), False, True, rng)

    save_as(doc, args.save)

    doc.Close()

    app.Quit()
