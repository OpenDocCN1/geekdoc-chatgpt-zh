# 第 4 章 手势识读与交互

## 4.1 概述

把手部的运动翻译成设备可执行的指令，这正是手势交互的底层逻辑。借助摄像头等感知硬件捕捉肢体动作，再经解析识别驱动目标系统，它正成为继键盘鼠标、触控之后的新型人机交互范式。

用手势沟通几乎是天生的本能，语言文字出现之前人类就靠肢体表达。手在日常使用频率高、易于辨识，使其天然适配交互。一个完整的手势交互链条通常包含使用者、手势采集装置、分析识别模块以及被操控的设备或界面。

业界的判断由来已久。ACM SIGCHI 在 2005 年的未来界面设计工具研讨会上就提出下一代界面将摆脱桌面依赖，触控、触觉、视觉摄像头等新输入会成为主流。2009 至 2011 年 SIGCHI 年会连续三年举办相关研讨，2009、2010 两届尤其聚焦触摸与手势的自然交互。Gartner 在 2017 年的人机交互技术优先级矩阵中，把增强现实、混合现实、手势控制设备、对话式用户界面列为未来五到十年重点关注的新兴方向。

落地应用已经相当具体。
1. 虚拟场景操作，例如虚拟制造、虚拟装配、产品设计。装配环节能直接用手移动零件，并结合语音定义零件间的装配关系，也能通过手势输入复杂设计信息。
2. 手语识别。手语主要以手部动作为主，配合身体姿态、表情和口型构成相对稳定的符号体系。让机器读懂手语并与合成技术结合，可构建人机手语翻译系统。实现路径分为数据手套和视觉两类。
3. 多通道界面。手势很难单独替代键盘鼠标，既有技术限制，也因为手势本身存在多义、差异、不够精确等特性。更现实的做法是把手势与视线、语音等通道融合，提升交互的自然度和容错性。
4. 机器人机械手抓取。自然抓取一直是机器人领域的难题，基于数据手套的手势识别为解决该问题提供了重要思路。

学术价值同样突出。学界很早就搭建了交互基础理论与概念模型，比如手部运动信息的感知处理规律、把交互行为拆解为基本动作并研究其合理参数区间、通过统计稳定参数建立参数与任务的对应关系来指导设计。工业界也推出了采集、识别、合成、理解等关键技术，三维数据采集取得进展，但可靠性、精度、准确性、稳定性仍待加强，识别细微手势需要更高精度的传感器支撑。

当前仍有五大痛点待解：
1. 金手指困境。系统难以区分连续动作中哪些是有意指令、哪些是无意识摆动，也难以判断手势的起点与终点，容易引发误触与中断。
2. 动态手势识别滞后。多数方法要在完整动作结束后才判定类别，响应不够即时。
3. 功能适配模糊。界面哪些操作适合交给手势控制，尚未形成统一共识。
4. 学习成本。手势需要结合场景选取，部分信号型手势要求用户事先记忆定义，数量过多或跨应用不一致会增加认知负担。
5. 精细捕捉不足。人手姿态与动作的获取技术仍制约精细交互，在虚拟场景中精细编辑对象仍有难度，需要进一步提升捕获与识别精度。

无论是科研还是产业，都在加速投入。CMU、斯坦福、MIT、微软、苹果、谷歌、脸书、英特尔、法国 INRIA、德国马普学会等都在推进手势设备、技术与应用。国内中科院软件所、计算所、自动化所、清华大学、浙江大学、北航、北师大、北理工等也在手势获取、动态理解、VR/AR 人机交互等方面取得了可观进展。

总体看，手势理解与交互兼具理论深度与应用前景，是一个开放且极具挑战的研究方向。本章将围绕交互模型、人手检测、人手姿态估计、基于视觉的手势识别等核心问题，梳理代表性工作与思路。

## 4.2 手势交互中的核心概念与功用

### 4.2.1 手势的概念与意义

手臂尤其是手在沟通时伴随大量动作，身体姿态也会同步变化，这些统称为手势。它可能是人类最早的交流方式，历久弥新。随着历史演进，各种手势被赋予特定含义，表达力与灵活性不断增强，成为自然的情感表达工具，也是主体作用于外部世界的重要方式。

### 4.2.2 手势的分类

按运动特征可分为静态手势与动态手势。静态手势也称手形，仅靠手的外形轮廓传递信息，可视作动态手势的特例，也常被称作姿势。动态手势中手形与位置随时间变化，能承载更丰富准确的信息，是日常最常用的交流形式。典型动态手势可拆解为准备、起始、执行、收束、撤回五个阶段。

按交互目的可分为交际性手势与操纵性手势。操纵性手势用手部运动表征路径或位置。交际性手势多与言语相关，包含标志性手势、隐喻手势、调制符号手势、连贯手势、Butterworth 手势和 Adaptors 手势。标志性手势与语义紧密相关，用手大致勾勒谈及的对象辅助理解；隐喻手势代表抽象概念，如表示决定的切割动作；调制符号手势主要补充语音；连贯手势用于在语义相关但时间不连续时保持连贯，如被打断后重复动作；Butterworth 手势指说话时的失当动作，如忘词抓耳挠腮；Adaptors 手势则是无意义的习惯性动作。

指示手势是特例，用于标示预定动作方向或操纵方向。视语境不同可归入交际性中的标志性手势，也可归入操纵性手势。

按指令层级可分为规定手势与自由形式手势。规定手势基于预先定义的手势词典，具有固定含义，使用者需先学习才能触发功能，易带来学习负担。自由形式手势不触发预设动作，通常被原样映射进系统，用于绘制轨迹、曲面或在虚拟空间移动物体，因缺乏象征意义，应用范围相对有限。

本书讨论的手势主要指动态手势，涵盖单手或双手交互，含手指动作的精细操作也暂纳入手势范畴。
