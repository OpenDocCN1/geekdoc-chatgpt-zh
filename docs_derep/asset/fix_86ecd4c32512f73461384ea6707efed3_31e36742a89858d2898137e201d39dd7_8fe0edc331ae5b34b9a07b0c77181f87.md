## 4.8.2 UNIX 系统概览
UNIX 是一种多用户多任务的操作系统，自 1974 年面世后在全球范围内快速普及。它运行在硬件与应用软件之间，负责统一调度软硬件资源，并为上层应用提供简洁一致的调用接口，保证程序正确执行。UNIX 与其他系统的不同主要体现在实现方式与人机交互界面上。

### 1. UNIX 的构成要素
（1）kernel 内核：UNIX Kernel 是系统的核心，负责调度机器运行，直接管理硬件资源，屏蔽硬件细节对用户程序的影响。
（2）shell 外壳：UNIX Shell 是内核与用户的交互桥梁，同时充当命令解释器。
工具及应用程序

### 2. UNIX 的分层架构
UNIX 可分为五层，最底层为裸机，即未加载任何软件的硬件本体；第二层为 UNIX 核心，依托裸机实现文件管理、进程管理、存储管理、设备管理、网络管理等核心功能，核心程序不允许用户直接运行，用户只能通过系统调用按规范请求服务；第三层为系统调用，连接第四层应用层与第二层核心；第四层为应用层，包含编译程序、文本编辑处理程序、系统命令、窗口图形软件包、各类库函数及用户自编程序；最外层为 Shell 解释程序，是用户与操作系统的交互通道。

### 3. UNIX 的适用范围与特性
UNIX 基本适用于 16 位及以上的机型，涵盖微机、小型机、多处理器及大型机。

UNIX 的特点有：支持多任务多用户、运行稳定移植性强、并行处理能力突出、具备安全保护机制、拥有功能强大的 shell 以及良好的网络支持能力。

## 4.8.3 Linux 系统概览
Linux 是一款可免费使用并自由传播的类 UNIX 系统，于 1991 年 10 月 5 日诞生。它支持多用户、多任务、多线程及多 CPU，可运行主流 UNIX 工具、应用与网络协议，兼容 32 位与 64 位硬件。Linux 继承了 UNIX 以网络为核心的设计理念，是一个稳定可靠的多用户网络操作系统，主要部署在基于 Intel x86 系列 CPU 的机器上。Linux 以高效灵活著称，采用模块化结构，既能在高端工作站运行，也能在低价 PC 上完整呈现 UNIX 特性，具备多任务多用户能力。

Linux 发行包除完整操作系统外，还包含文本编辑器、高级语言编译器等应用软件，并提供 X-Windows 图形界面，配备多个窗口管理器，支持窗口、图标、菜单操作，使用感受与 Windows NT 相似。

Linux 与 UNIX 的最大差异在于源码开放性：Linux 为开放源代码的自由软件，UNIX 则是源代码受知识产权保护的商业软件。由此 Linux 用户拥有高度自主权，而 UNIX 用户多被动适应；Linux 开发在完全开放环境中进行，UNIX 开发相对封闭，仅核心开发者可接触原型。此外，UNIX 多与硬件捆绑销售，Linux 可运行于多种硬件平台；UNIX 为商业软件，Linux 为免费自由软件，源代码公开。

# 本章小结
本章第 1 节阐述了操作系统的概念、分类、演进历程及作用。操作系统是计算机系统中的重要系统软件，由多个功能模块构成，管理硬件与软件资源，合理组织工作流程，为用户提供功能完备、易用、可扩展、可管理且安全的环境，在计算机与用户间充当接口。总体而言，操作系统负责管理内部资源并提供友好界面。

第 2 节介绍了操作系统主要类型及应用场景，包括批处理、分时、实时、通用、网络与分布式操作系统。批处理系统使用户脱机作业，操作员分批处理，多道程序并发运行；分时系统为联机多用户交互式系统；实时系统强调即时响应与高可靠性；分布式操作系统将地理分散且具自治能力的处理系统或计算机互联，实现信息交换与资源共享。

第 3 节说明操作系统功能，其职责是管理控制软硬件资源，合理组织运行，为用户提供工作环境与接口。从资源管理与用户接口角度，操作系统具备处理器管理、存储管理、设备管理、信息管理及用户接口五大功能。

第 4 节介绍进程管理，明确进程是系统分配资源的基本单位，进程概念源于资源有限性与处理的并行性，进程是动态概念。本节需区分进程、线程与程序，重点掌握进程状态及状态转换，并理解死锁的成因与防范措施。

第 5 节介绍处理器调度，涵盖调度目标、策略与评价标准。调度方式分为进程调度、作业调度、交换调度和线程调度四种。常见算法有先来先服务、最短作业优先、时间片轮转、最高响应比等。需理解作业与进程关系，进程为执行实体与资源分配基本单位，一个作业由一个或多个进程组成，系统为作业创建根进程，运行中按需创建子进程。本节需会计算作业周转时间、平均周转时间、带权周转时间。

第 6 节介绍存储管理，主要讲解分区式、页式、段式、段页式管理。内存管理核心是解决内外存统一及数据交换问题。覆盖与交换是内存扩充的两种技术，需掌握其思想。需熟练掌握各类内存管理方法，理解页式、段式、段页式的基本原理及差异。

第 7 节介绍设备管理，其主要任务是控制设备与 CPU 间的 I/O 操作，提升设备利用率。数据传输方式有程序直接控制、DMA、中断控制和通道方式四种。

第 8 节介绍常见操作系统，包括 Windows 系列如 Windows 7、Windows 8、Windows 10，并简要介绍 Linux 与 UNIX 及二者差异。

## 5.1 多媒体技术的基本概念

### 5.1.1 多媒体与多媒体技术

#### 1. 多媒体与多媒体技术的定义
媒体是信息载体与传递媒介。超媒体一词源于媒体，指由超链接构成的全球信息系统。本章所论多媒体为超媒体的子集。

借助文字、声音、图像、动画、影片等两种及以上媒介，使计算机与人实现实时信息交互的系统称为多媒体。而在交互过程中，对文字、图像、声音、动画、视频等信息进行综合处理与管理的技术称为多媒体技术。

#### 2. 多媒体技术的历史与发展前景
多媒体技术的萌芽期可追溯至 1980 年至 1990 年间。早在 1984 年，Apple 公司为改善人机交互，加入图形处理功能，并在研发中采用 bitamp 位映射、window 窗口、icon 图标等技术，创造出备受青睐的图形用户界面 GUI。同时引入鼠标配合界面使用。美国 Apple 实现了操作便捷的目标，如图 5.1 所示。

## 3. 多媒体技术的特点

多媒体技术主要具有多样性、集成性、交互性、实时性四大特征。

### （1）多样性
指媒体类型丰富，信息处理手段多样。例如媒体类型包括视频、图像、音频、文本等，技术层面涵盖视频技术、图像压缩、音频技术等。

### （2）集成性
包括信息媒体的集成，即以计算机为中心对多种媒体信息进行综合处理；还包括软硬件设备的集成，即打印机、扫描仪、投影仪、音箱等外部设备协同使用。

### （3）交互性
指多媒体领域人机高效交互。计算机能及时识别外部控制指令，使用者操作简便，上手迅速。

### （4）实时性
指各类媒体信息具有动态变化特性。

此外，多媒体技术还存在数据体量庞大、数据类型多、数据类型差异大、输入输出复杂等特点。数据量庞大源于多媒体数字化需采样、数据存储、数据分析等过程，无论图片还是音乐，要保证高质量体验通常需处理海量数据。
