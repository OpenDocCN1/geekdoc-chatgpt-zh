# 人话变命令，故障可注入

这套实现围绕两个核心能力展开：一是把日常口头表述转为设备可执行的统一指令，二是通过可配置的异常注入检验多智能体在不稳定场景下的表现。

先看口语转指令的部分。设备类型被压缩为四个枚举：交通灯、摄像头、传感器、显示屏。命令结构用数据类承载，字段包括设备编号、类型、动作、参数字典、优先级和超时毫秒数。转换器在初始化时接收大模型客户端和设备注册表，并预载命令模板。调用过程是异步的：先让模型结合原句和上下文把意图拆成目标对象、操作、参数细节和优先级，再把抽象目标映射到注册表里的真实设备，最后按模板为每台设备填充完整命令并汇总返回。解析阶段的提示明确要求输出 JSON，包含目标、动作、参数、优先级四项信息。
