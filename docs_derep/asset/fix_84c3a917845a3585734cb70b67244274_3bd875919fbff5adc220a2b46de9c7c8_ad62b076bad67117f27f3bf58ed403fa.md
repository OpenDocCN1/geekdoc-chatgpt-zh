（1）法则。0 与任何数相乘恒为 0，例如 0×0=0、0×1=0；1 与任何数相乘保持数本身，例如 1×0=0、1×1=1。多位数相乘的思路与十进制相同，先以乘数的每一位去乘被乘数，再把各部分积错位相加。

（2）示范：101（5）×11（3）。

**8.4.4 进制转换实战技巧**

**1. 二进制 与 十进制 的互换**

1）由二进制推算十进制

（1）关键点。每位的值由该位对应的 2 的幂决定，全部相加即得结果。

（2）操作流程。由最低位向高位编号，第 1 位对应 2⁰，第 2 位对应 2¹，第 3 位对应 2²… 每一位上的 0 或 1 乘以对应幂值后求和。

（3）演示。

① 101 转成十进制。

从右往左逐位计算：

最低位：1×2⁰=1×1=1。

次位：0×2¹=0×2=0。

最高位：1×2²=1×4=4。

合计 1+0+4=5 → 101 等于 5。

② 1101 转成十进制。

逐位：

最低位 1×2⁰=1。

第 2 位 0×2¹=0。

第 3 位 1×2²=4。

第 4 位 1×2³=8。

合计 1+0+4+8=13 → 1101 等于 13。

2）十进制转二进制 整数段

（1）关键点。整数与小数分开处理。整数的核心是连除 2 取余，然后倒序排列。

（2）操作流程。把十进制整数反复除以 2 并记下余数，直至商为 0，再把余数自后向前排列。

（3）演示。

① 5 转二进制。

a.5÷2=2 余 1。

b.2÷2=1 余 0。

c.1÷2=0 余 1。

倒序 1 0 1 → 101。

[PRE1]

② 13 转二进制。

a.13÷2=6 余 1。

b.6÷2=3 余 0。

c.3÷2=1 余 1。

d.1÷2=0 余 1。

倒序 1 1 0 1 → 1101。

3）十进制转二进制 小数段

（1）关键点。小数采用乘 2 取整，顺序保留。整数与小数合起来才是完整数值。

（2）操作流程。将十进制小数不断乘以 2，取整数部分 0 或 1，直至小数归零或达到精度要求，按出现顺序排列。

（3）演示。

① 0.625 转二进制。

a.0.625×2=1.25 取整 1 余 0.25。

b.0.25×2=0.5 取整 0 余 0.5。

c.0.5×2=1.0 取整 1 余 0。

顺序 1 0 1 → 0.101。

[PRE2]

② 0.375 转二进制。

a.0.375×2=0.75 取整 0 余 0.75。

b.0.75×2=1.5 取整 1 余 0.5。

c.0.5×2=1.0 取整 1 余 0。

顺序 0 1 1 → 0.011。

**2. 八进制/十六进制 与 二进制 的互换**

1）八进制 → 二进制

（1）关键点。1 位八进制对应 3 位二进制，不足时前补 0。

（2）操作流程。将每位八进制数字换成 3 位二进制后拼接。

（3）演示。

① 37 转二进制。

a.3 → 011。

b.7 → 111。

拼接 011111，去掉前导 0 得 11111。

[PRE3]

② 54 转二进制。

a.5 → 101。

b.4 → 100。

拼接 101100。

2）二进制 → 八进制

（1）关键点。3 位二进制对应 1 位八进制，从右向左分组，不足前补 0。

（2）操作流程。右起每 3 位一组，换算后再连起来。

（3）演示。

① 110101 转八进制。

分组 110、101 → 101=5，110=6 → 65。

② 101011 转八进制。

分组 101、011 → 011=3，101=5 → 53。

3）十六进制 → 二进制

（1）关键点。1 位十六进制对应 4 位二进制，不足前补 0。0-9 对应 0-9，A-F 对应 10-15。

（2）操作流程。每位十六进制换成 4 位二进制后拼接。

（3）演示。

① 3A 转二进制。

a.3 → 0011。

b.A=10 → 1010。

拼接 00111010，去前导 0 得 111010。

② B5 转二进制。

a.B=11 → 1011。

b.5 → 0101。

拼接 10110101。

4）二进制 → 十六进制

（1）关键点。4 位二进制对应 1 位十六进制，从右向左分组，不足前补 0。

（2）操作流程。右起每 4 位一组换算后拼接。

（3）演示。

① 1011101 转十六进制。

分组 0101、1101 → 0101=5，1101=D → 5D。

② 111010 转十六进制。

分组 0011、1010 → 0011=3，1010=A → 3A。

**9.1 数据类型与变量**

**9.1.1 小故事**

小乐每天要整理乐乐超市的信息：价格、库存、折扣。他发现不同信息性质不同：库存是整数，如 10 瓶汽水；价格带小数，如橘子汽水 3.5 元、桃子汽水 4.2 元；商品名是若干字符组合。

因此他用不同“数据类型”记录，而且这些信息会变：桃子汽水剩 3 瓶需补货，补完成 100 瓶；橘子汽水上月 3.5 元本月 3.8 元；名称也会调整，如“橘子汽水”改成“橘汁汽水”。会变化的数据称为“变量”。

也有恒定不变的内容，如超市金字招牌，商品怎么变招牌永不变。这种固定量称为“常量”。

**9.1.2 知识精讲**

**1. 认识数据类型与变量**

写程序时要保存处理各种数据。超市里价格是小数，库存是整数，名称是字符。数据类型帮助区分种类，合理占用内存。变量是存放数据的容器，便于操作。

**2. 基本数据类型**

C++ 提供丰富的基础类型，选对类型对正确性和内存效率很重要。

**3. 变量声明、初始化与赋值**

1）何为变量

变量是程序运行期间存放可变数据的、带唯一标识符的内存区。标识符即变量名，通过它操作内存。创建时用声明语句，运行时分配空间。

2）声明变量

（1）目的。声明相当于向编译器报备：我要用一个变量，名字是 x，类型是 int，请分配对应内存。
