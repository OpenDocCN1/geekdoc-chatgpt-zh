NVLink 在带宽扩展上的做法很有弹性，链路可以进行捆绑聚合，以获得更高的吞吐。把多条 NVLink 通道合在一起使用，就能把数据传输速率拉升到更高水平，满足对传输速率要求极苛的场景。这种按需组合的思路，让 P100 在面对不同应用和负载时，能够动态调整传输策略，发挥更优的性能。

#### 3. NVLink 通信协议
在 NVLink 的链路架构里，“Brick”代表通道的基本构成单元。如图 4.6.6 所示，一个 NVLink 是双向接口，由 8 组差分对构成，共计 32 条信号线。这些差分对采用直流耦合方式，并在差分端配置 85Ω 的终端电阻，以提升信号完整性。

[PRE0]

图 4.6.6

为了增强布线的灵活性和兼容性，NVLink 引入了通道反转和通道极性这两个概念。也就是说，设备之间的物理通道顺序和极性可以依据实际布线需求进行调整，从而简化物理布局和走线难度。

如图 4.6.7 所示，NVLink 在数据传输层面采用基于 flit 的包结构。flit 即流控制数字。一个单向 NVLink 数据包由 1 至 18 个 flit 组成，每个 flit 为 128 位。该机制允许在同一个数据包中承载不同尺寸的数据，提升传输的灵活性与效率。

[PRE1]

图 4.6.7

头部 flit 的组成包含 25 位循环冗余校验、83 位事务字段以及 20 位数据链路字段。事务字段携带请求类型、地址、流控位和标记标识等信息；数据链路字段则涉及包长、应用编号标签和确认标识等内容。地址扩展机制通过保留静态位，仅发送变化位，进一步优化传输效率。

NVLink 协议借助 25 位 CRC 实现错误检测，保证传输可靠性。接收端会把收到的数据暂存于重放缓冲区中，进行包排序，并在 CRC 校验无误后向源端反馈。CRC 设计使最大数据包可容忍高达 5 个随机位错误，或在差分对发生突发错误时承受最多 25 个连续位错误的容错能力。

正是得益于精细的电气设计和数据结构，NVLink 既提升了传输速度与效率，也确保了高速场景下的稳定可靠，为高性能计算提供坚实支撑。

#### 4. NVLink 互联拓扑
要实现 GPU 之间高效的互联与协同计算，需要依据系统配置和性能成本要求，合理规划 NVLink 通道的物理布局和连接方式。

初代 DGX-1 通常采用类似图 4.6.8 的互联形态。IBM 在 Power8+ 微架构的 Power 处理器上引入 NVLink 1.0 技术，使得英伟达的 P100 GPU 能够绕过 PCIe 总线，直接通过 NVLink 与 CPU 通信。该方案实现了 GPU 与 CPU 之间低时延、高带宽的直连，对深度学习和高性能计算意义重大。

[PRE2]

在与最近的 Power8+ CPU 相连的节点中，4 个 GPU 可配置为全互联的 mesh 结构。GPU 之间可直接交换数据，并在深度学习和计算密集型任务中实现更高效的数据流通与协作。

另外，由于 GPU 所需的 PCIe 通道数超过芯片组供给能力，每一对 GPU 会先接入一组 PCIe 交换机，再连接至英特尔至强处理器。随后两颗英特尔处理器通过 QPI 总线互联。

这种构成确保每个 GPU 获得充足的 PCIe 带宽，满足深度学习和高性能计算的数据传输需求；同时 QPI 互联的双处理器也为系统提供高速的 CPU 间通信，进一步提升整体性能。

#### 5. 第五代 NVLink
总体来看，英伟达将 NVLink 的单 GPU 带宽从 900 GB/s 提升至 1800 GB/s，实现了翻倍增长。相比前代，这是 NVLink 带宽最大的一次跃进，因为 2022 年的 Hopper 架构仅比上一代提升约 50%。

另一个关键点是每个 GPU 的 NVLink 数量保持不变，Hopper 与 Blackwell 的 NVLink 数量均为 18 个。因此，NVLink 5 的带宽增益全部来自于链路内每条高速对的信号传输速率提升至 200 GB/s。这与历代 NVLink 的演进规律一致，每次迭代都将信号速率翻倍。

## 小结与思考
- NVLink 技术的重要性：随着神经网络模型参数规模激增，传统 PCIe 已难以满足 GPU 间及 GPU 与 CPU 间的高速传输需求，NVLink 以远超 PCIe 的速度和低时延，有效解除瓶颈。
- NVLink 的技术细节：通过创新通道设计和高效数据包结构，NVLink 实现高带宽利用率和错误检测能力，灵活的拓扑和对等通信支持为大规模 GPU 集群的高效协作提供可能。
- NVLink 的发展与演进：自 P100 首次引入 NVLink 以来，该技术已历经多代演进，最新一代在 Blackwell 架构中实现每个 GPU 1800 GB/s 的带宽，进一步推动高性能计算和神经网络训练能力。

## 4.7 NVSwitch 深度解析
在当今高性能计算领域，英伟达的 GPU 技术持续引领。随人工智能与机器学习的快速发展，计算需求不断攀升，GPU 间的互联变得至关重要。在此背景下，英伟达推出了 NVLink 协议，并基于此构建多 GPU 互联方案 NVSwitch。

本节将深入探讨 NVSwitch 的演进历程、工作原理及其在构建高性能服务器集群中的核心作用。

### 4.7.1 为什么需要 NVSwitch
随着单颗 GPU 的计算能力逼近物理极限，多 GPU 协同成为必然选择。

然而若要访问其他 GPU 的 HBM2，需经过 PCIe 接口。如图 4.7.1 所示，传统 PCIe 在速率和带宽上存在局限，导致 GPU 间通信常成为性能瓶颈。为此英伟达开发 NVLink，相比 PCIe 可提供高达 10 倍带宽，使单服务器内 8 个 GPU 通过点对点网络形成混合立方体网格。

NVLink 的核心优势在于绕过传统 CPU 分配调度，允许 GPU 之间直接交换数据，减少时延并大幅提升系统吞吐。此外，通过 NVLink GPC 既可访问卡间 HBM2 内存数据，也可访问其他 GPU 内的 HBM2 数据。

NVSwitch 在此基础上进一步发展，支持全无阻塞的 GPU 全互联，通过提供更多 NVLink 接口、无中间 GPU 跳数，实现更大规模 GPU 互联，构建更强计算集群。

[PRE3]

### 4.7.2 NVSwitch 的出现
回顾表 4.1.9，Volta 架构下 GPU 到 GPU 通信速率达 300 GB/s，Hopper 架构已发展至 900 GB/s。其背后是 NVLink 链路数的显著提升，从 Volta 的 6 路扩展到 Hopper 的 18 路，相当于在原有高速公路上增设立交与环岛，使数据更高效穿梭于各 GPU 之间。

DGX-2 引入英伟达第一代 NVSwitch，实现更高效的 GPU 间通信。在 Volta 架构中，每张 GPU 卡支持 6 条 NVLink 链路。通过引入 6 个 NVSwitch，服务器中所有 GPU 卡可全部互联，支持 8 对 GPU 同时通信且无需中间跳数，大幅提升传输效率与整体计算性能。

DGX-A100 使用第二代 NVSwitch 技术。相比初代，带宽更高、时延更低。A100 架构中每张 GPU 支持 12 条 NVLink 第三代链路，并通过 6 个 NVSwitch 实现全互联网络拓扑。虽然标准 DGX A100 配置为 8 张 GPU，但系统可扩展以支持更多 A100 GPU 和 NVSwitch，构建更大规模超算。

DGX-H100 采用第三代 NVSwitch 和第四代 NVLink 技术，每个 GPU 支持 18 条 NVLink 链路。H100 架构引入 4 个 NVSwitch，采用分层拓扑：每张 GPU 向第一个 NVSwitch 接入 5 条链路，向第二个接入 4 条，向第三个接入 4 条，向第四个接入 5 条，共 72 个 NVLink，提供 3.6 TB/s 全双工 NVLink 网络带宽，较上一代提升 1.5 倍。

### 4.7.3 NVSwitch 详解
英伟达的 NVSwitch 是实现高效 GPU 间通信的关键组件，尤其在 HPC 与 AI 加速系统中。

#### 1. 初代 NVSwitch
第一代 NVSwitch 提供 18 路接口，可支持多达 16 个 GPU 全互联，实现高效数据共享与通信。

如图 4.7.2 所示，在 V100 架构中，每块 GPU 拥有 6 条 NVLink 链路，可连接到 NVSwitch，形成高带宽通信网络。在 DGX-2 系统中，8 个 V100 GPU 通过 NVLink 通道与 6 个 NVSwitch 相连，构建强大基板。

[PRE4]

第一代 NVSwitch 支持 NVLink 2.0 技术，每个接口提供双通道，最高带宽达 50 GB/s。经由 NVSwitch，整个系统可实现约 900 GB/s 带宽，极大提升数据传输速率与计算效率。

NVSwitch 基于台积电 12 nm FinFET FFN 工艺制造，在 100 W 功耗下运行，集成约 2 亿晶体管。

在封装与 I/O 方面，NVSwitch 采用大型 BGA 封装，共 1940 个引脚，其中 576 个用于支持 18 路 NVLink，其余用于电源与各类 I/O，包括 ×4 PCIe 管理端口、I2C、GPIO 等，提供灵活管理与扩展能力。具体参数见表 4.7.1。表中显示每个 NVLink 双向带宽高达 51.5 GB/s，实际利用率达 80.0%。

#### 2. 初代 NVSwitch Block
如图 4.7.3 所示，左侧为 GPU XBAR，它是 NVLink 互联环境中的专业桥接设备，使数据包可在多个 GPU 间流动交换，同时对外呈现为单个 GPU。借助 GPU XBAR，客户端应用可感知并利用多个 GPU 的集合性能，降低 GPU 间通信管理的复杂度。

GPU XBAR 采用基于 SRAM 的缓冲技术，实现无阻塞数据传输。该缓冲机制保证传输连续性与效率，即使在高负载下也能保持高性能。

从 V100 GPU 起，英伟达重新使用 NVLink IP 块和 XBAR 设计，保证不同代产品兼容性，同时推动技术迭代并降低开发成本。

NVLink 传输使用物理地址而非虚拟地址，因物理地址可直接指向数据实际存储位置，加快索引与访问速度。

NVSwitch 作为 NVLink 桥接设备，不仅提供高带宽通信路径，还负责复杂的路由与缓冲机制，确保数据包按正确物理地址快速准确送达。使用物理地址进行 NVLink 通信可减少目标 GPU 上的地址转换需求，降低时延并提升传输速率。

#### 3. NVSwitch 简化原理与特性
##### 1) 无 NVSwitch 的直接 GPU 间连接
如图 4.7.5 所示，未引入 NVSwitch 时，GPU 间连接通常通过将 NVLinks 聚合成多个组 Gang 实现。多个 GPU 通过共享 NVLink 链路通信。

[PRE7]

##### 2) 引入 NVSwitch 后的改进
英伟达 NVSwitch 为 GPU 间通信带来革新。作为高速交换机，NVSwitch 允许所有链路数据互通。

在 NVSwitch 架构中，任意两颗 GPU 可直接互联，只要总带宽不超过 6 个 NVLink，单个 GPU 流量即可无阻塞传输。NVSwitch 的全互联架构支持系统轻松扩展以容纳更多 GPU，且不牺牲性能。每个 GPU 都能利用 NVLink 的高带宽实现快速数据交换。

NVSwitch 在多 GPU 互联上的优势包括：
- 扩展性与可伸缩性：通过增添 NVSwitch，集群可轻松支持更多 GPU，扩展计算能力。
- 高效系统构建：例如 8 个 GPU 可通过 3 个 NVSwitch 构建高效互联网络，数据可在各 GPU 链路间自由交互，最大化流通灵活性。
- 全双向带宽利用：在该配置下，任意 GPU 对均可利用完整的 300 GB/s 双向带宽通信，实现高速低时延数据传输。
- 无阻塞通信：NVSwitch 中的 XBAR 为数据传输提供从点 A 到点 B 的唯一路径，确保无阻塞、无干扰，提升可靠性和整体性能。
- 优化网络拓扑：NVSwitch 支持的网络拓扑为构建大型 GPU 集群提供优化方案，允许设计者依据计算需求灵活配置 GPU 间连接方式。
