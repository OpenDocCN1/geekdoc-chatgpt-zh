## 属性类型

数据库条目的常见属性格式：

- **标题:** `{"title": [{"text": {"content": "..."}}]}`
- **富文本:** `{"rich_text": [{"text": {"content": "..."}}]}`
- **单选:** `{"select": {"name": "Option"}}`
- **多选:** `{"multi_select": [{"name": "A"}, {"name": "B"}]}`
- **日期:** `{"date": {"start": "2024-01-15", "end": "2024-01-16"}}`
- **复选框:** `{"checkbox": true}`
- **数字:** `{"number": 42}`
- **URL:** `{"url": "https://..."}`
- **邮箱:** `{"email": "a@b.com"}`
- **关联:** `{"relation": [{"id": "page_id"}]}`

## 2025-09-03 版本的关键差异

- **数据库 → 数据源:** 查询检索改用 `/data_sources/` 端点
- **两个ID:** 每个数据库同时拥有 `database_id` 与 `data_source_id`
  - 创建页面时使用 `database_id` (`parent: {"database_id": "..."}`)
  - 查询时使用 `data_source_id` (`POST /v1/data_sources/{id}/query`)
- **搜索结果:** 数据库返回类型为 "object": "data_source" 并附带 `data_source_id`
- **响应中的父级:** 页面同时展示 `parent.data_source_id` 和 `parent.database_id`
- **查找data_source_id:** 可搜索数据库，或调用 `GET /v1/data_sources/{data_source_id}`

## 注意事项

- 页面/数据库 ID 均为 UUID 格式，可带或不带连字符
- API 不支持设置数据库视图过滤器，该功能仅限 UI
- 速率限制约为平均每 3 请求/秒
- 创建数据源时使用 `is_inline: true` 可将其内嵌到页面中

Notion Skill 的模板具备良好可扩展性：参数化设计让所有 curl 命令使用占位符如 `{page_id}`、`{data_source_id}`，便于 AI 动态替换；模块化结构将功能分类展示，AI 可按需选取；版本兼容性明确标注 API 差异，支持多版本 Notion API。

Notion API 集成 Skill 是数据查询模板的典型案例，展示了 OpenClaw 如何把复杂的外部数据服务封装为 AI 可理解使用的标准化能力。SKILL.md 实现了元数据管理、功能定义与操作指引的闭环，用自然语言清晰描述技能作用、调用方式与注意事项；package.json 则定义配置参数、依赖关系与入口文件。二者共同构成 AI 可自主理解并调用的能力单元。
