# 一、通知的标准构成（六大部分）

1. 标题

规范写法：
单位+事由+文种，如《××公司关于2024年春节放假安排的通知》。
内部简写法：《关于××事项的通知》。
紧急标识：需在标题标明，如《××学校关于台风停课的紧急通知》。

2. 主送机关/对象

顶格书写接收单位或个人：
单位：××部门、全体员工；
个人：张三同志、各项目经理。
多级主送：同级单位用顿号，不同级单位用逗号。

3. 正文

开头依据段：
政策依据，如“根据《国务院办公厅关于2024年部分节假日安排的通知》”；
事实依据，如“因办公楼电路改造需要”。

主体事项段：
分条列项，使用“一”“二”“三”或“1.”“2.”“3.”；
须涵盖时间、地点、内容、要求等要素。

结尾执行段：
联系人及电话；
执行要求及截止时间。

4. 附件说明（可选）

注明附件名称及序号，如“附件：1.《参会人员回执表》;2.会议议程”。

5. 落款

发文单位全称，与公章一致；无单位可省略。
日期用阿拉伯数字，右对齐或置于单位下方。

6. 印章/签名

正式文件需加盖公章，个人通知需手写签名。

# 二、通知撰写的5个步骤

1. 明确类型与目的

指示性通知：部署工作；
批转性通知：转发上级文件；
会议通知：召集会议；
任免通知：人事调整；
周知性通知：放假安排、地址变更等。

2. 收集信息

政策依据文件；
具体事项：时间、地点、参与人员；
执行要求与截止时限。

3. 选择模板与结构

4. 撰写与校对

语言规范，避免口语化；
数字用法统一，日期、金额格式规范；
逻辑检查，时序合理，权责清晰。

发布渠道：OA系统、红头文件、公告栏、微信群；

# 四、“避坑”指南（五大常见错误）

1. 主送对象错误
错误：向非管辖单位发文。修正：明确发文权限，跨级需抄送上级。

2. 时效冲突
错误：发文日期晚于执行日期。修正：预留不少于3个工作日的执行期。

3. 附件遗漏
错误：正文提及附件未附。修正：单独列明附件清单。

4. 盖章不规范
错误：单位通知仅签字。修正：正式文件须盖章。

5. 联系方式缺失
错误：要求反馈未留联系人。修正：至少提供电话与邮箱。

提示：正文仿宋三号，标题小标宋体二号，页边距上37mm、下35mm、左28mm、右26mm。
