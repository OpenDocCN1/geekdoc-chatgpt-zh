分布式图片去重爬虫的完整实现拆解

想做一个能持续抓取、本地化存储并自动过滤重复图库的爬虫，核心其实就是把任务分发、链接抽取、图片保存和相似度判定这四件事拆开，用流式拓扑串起来。下面这套实现正好示范了从正則抽链到平均哈希去重，再到 Hurricane 拓扑编排的完整闭环。

先看链接抽取与下载环节。任务产生后，UrlParseBolt 负责从原始 HTML 里把带 http 的 href 全部抠出来，紧接着把图片 URL 规范化成一个能写磁盘的文件名，过滤掉 \ / : * ? " < > | 等非法字符，预连接后通过 socket 接收数据，跳过 HTTP 头的 \r\n\r\n 之后把剩余字节直接写进 ./img/ 目录的 jpg 文件。这一块保证了抓到的资源能落盘且文件名唯一。

去重靠的就是平均哈希。先用 OpenCV 把原图缩到 8x8，灰度化后计算整体均值，再把每个像素与均值比较生成 64 位的 0/1 指纹。两张图的汉明距离小于等于 5 判定为 Similar，大于 10 判定为 Different，中间区间归为 SomeWhatSimilar，用来做保守过滤。
