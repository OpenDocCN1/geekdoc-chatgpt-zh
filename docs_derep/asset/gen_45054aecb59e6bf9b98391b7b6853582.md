### 2.1.8 流程中断技巧

学 switch-case 时就接触过 break，它能让程序提前退出结构。JavaScript 里常用的流程中断手段有 return、break、continue 三种。

return 主要用来结束函数并把结果抛出去，后续章节会系统讲函数返回值。break 既能跳出 switch-case，也能终止循环。匹配到 case 后，break 会让 switch 直接结束；在循环里，它会立刻停止当前循环的执行。[PRE1]

continue 用来跳过本次迭代的剩余代码。跳过不等于退出，循环本身会继续往下走。[PRE2]

### 2.1.9 异常处理机制

代码跑起来总会遇到各种意外，健壮的产品需要通过测试把风险降到最低。JavaScript 里写错关键字、用了未声明的变量、访问不存在的属性或方法，都会触发异常。[PRE3]

一旦异常产生，执行会停在出错的位置，并在控制台输出报错信息。比如下面是典型的未声明变量错误，运行后控制台会给出对应的提示：[PRE4]

如果一个应用包含多个功能，我们不希望一个地方出错就让整个应用瘫痪。try-catch 就能把风险局部化。[PRE5]

运行后即使内部抛出了异常，程序仍能继续往下走。

try 块里放可能出错的代码。没有异常时，try-catch 几乎没有额外开销；一旦出现异常，异常对象会被抛给 catch 处理，catch 执行完后程序恢复正常继续执行。

try-catch 最后还能加上 finally，这个代码块不论是否出错都会被执行，适合放清理类逻辑。[PRE6]

除系统自带的错误外，开发者也可以手动抛出自定义异常来中断流程。[PRE7]

在业务函数里，当调用方式不对或参数不合规时，主动抛出异常可以及早止损，避免更深的连锁问题，同时起到对调用方的警示作用。

### 2.1.12 类与继承

类可以看作对象模板或对象工厂，能更方便地批量生成对象。ES6 提供了 class 语法来定义类。[PRE19]

用 class 定义时类名通常首字母大写，内部需要实现 constructor 构造方法来完成对象的初始化，还可以定义其他自定义方法。创建实例时用 new 加类名即可。

JavaScript 的类支持继承。子类可以直接复用父类的属性和方法，让代码更可维护。比如教师属于人类，人类有问好的行为，就可以用 People 类作为 Teacher 类的父类。[PRE20]
