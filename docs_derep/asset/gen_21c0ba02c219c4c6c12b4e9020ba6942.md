### 9.8 核心篇：Seq2Seq 序列到序列建模全解析

本节正式进军 RNN 的另一大核心战场——**Seq2Seq（Sequence-to-Sequence）任务**。简单说，就是“一个序列映射到另一个序列”。生活中此类场景比比皆是：语言建模、语音识别、机器翻译、词性标注、智能对话等，本质均为 Seq2Seq 问题。下面系统拆解其处理范式。

#### 9.8.1 什么是 Seq2Seq？一张图读懂序列映射

Seq2Seq 即 **Sequence 2 Sequence**，泛指输入序列经过变换映射为输出序列的任务。序列可理解为字符串流，给定源序列，期望得到语义对应的目标序列（如译文、标注标签）。**Seq2Seq 不强制要求输入输出长度对齐**。

细分来看，分为**一一对应**与**非一一对应**两类：
- **一一对应**：语言模型、词性标注等，每个时间步输入对应一个输出，简单 RNN 即可搞定（结构参考图 9-26）。
- **非一一对应**：机器翻译、语音识别等，输入输出长度、节奏均不同，处理难度显著上升。除双向 RNN + CTC Loss 组合外，还有一种更主流的架构——

#### 9.8.2 Encoder-Decoder：Seq2Seq 的基石架构

##### 1. 核心机制拆解
Encoder-Decoder 的工作流分两阶段：
1.  **编码**：Encoder 将输入序列压缩为固定维度的**语义向量（Context Vector C）**，捕捉输入整体语义。
2.  **解码**：Decoder 以该语义向量作为 RNN Cell 的**初始状态**，逐步生成目标序列。若输出为文本，Decoder 本质上就是一个条件语言模型。

结构示意如图 9-27 所示。

[PRE8]

**数据流关键点**：
- 训练阶段有两路输入：`x` 喂 Encoder，`y` 喂 Decoder（作为 Teacher Forcing 的历史真值）。
- 标签 `y` **双重角色**：既参与 Loss 计算，又作为 Decoder 下一时步的输入（区别于普通监督学习仅用于 Loss）。
- Encoder 与 Decoder 之间的桥梁 `C`，承载了源序列的全部语义信息。

**架构优势**：
- **极致灵活**：不限定 Encoder/Decoder 网络类型（RNN/GRU/LSTM/Transformer 均可），不限定模态（Image Caption 中输入图像、输出文本）。
- **端到端建模**：语义理解与生成融为一体，摒弃了传统流水线分阶段处理的误差累积。

##### 2. TensorFlow 中的两代 Seq2Seq API
- **旧接口** (`tf.contrib.legacy_seq2seq`)：TF 1.0 前产物，静态展开图，功能基础但上手简单。
- **新接口** (`tf.contrib.seq2seq`)：TF 1.0+ 推出，动态展开，提供训练/推理两套 Helper 封装，灵活性强，但需手动组装 Encoder、Decoder 并连接。
