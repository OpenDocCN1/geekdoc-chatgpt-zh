## 4.2 Midjourney 的用户

使用人群远不止创意圈，精细化要求高的工业类从业者、NFT 创作者，以及一大批带着好奇心的个人爱好者都汇聚其中。

#### 4.2.1 创意设计从业者

这个群体体量庞大，覆盖面极广。①小 B 端，涵盖产品类设计师如玩具、墙纸等，图片类设计师如网站、广告、PPT、Logo、插画等，游戏类设计师如场景、角色、道具，以及自媒体创作者等；②企业端，可为广告公司、影视公司、品牌创意部门提供大量艺术效果图支持。

Midjourney 能明显提速创意工作。Discord 生态里专业设计师占比约 30%~40%，其中不乏 Nike、Adidas、New Balance 等品牌的内部设计师。调研显示，主要用途集中在前期，助力灵感迸发、快速验证思路并对图像反复迭代。品牌方一直在寻找提升效率的新方法与新工具，对 Midjourney 的付费意愿很强。

#### 4.2.2 工业设计行业从业者

该工具也渗入了对精度要求更高的工业设计领域，例如建筑设计。Instagram 上大量建筑师分享文生图案例，#Midjourneyarchitecture 标签下已有超过 72000 条帖子。

实践中，建筑师习惯在项目伊始用 Midjourney 搭建情绪板。目前生成的图像仅作为草图来激发灵感，随后被转译为图纸、建模并做结构分析，形成 3D 模型后再把图像回传给 Midjourney 迭代深化。近期上线的 ControlNet 有望让它更深入设计流程。

#### 4.2.3 NFT 从业者

NFT 从业者指在非同质化代币市场从事相关工作的群体。他们借助软件的多元风格与智能创意引擎来生产设计 NFT 艺术品，把想法转化为数字作品后挂在区块链市场交易。

创作时可以切换不同绘画风格与技法，做出差异化作品以吸引藏家与爱好者。借助智能算法获取独特灵感，再用软件的调节功能精修色彩与细节，提升艺术品质。

此外，社区平台也是展示作品、交流经验技巧的场所，互动能促进合作与学习，增加创作多样性与创新性。作为用户之一，NFT 从业者可以依托这些功能产出更具辨识度的 NFT，为市场注入更多创意，与同行共同推动行业进步。

#### 4.2.4 个人爱好者

个人玩家能通过软件获得以下体验。

创作乐趣：工具简单直观，绘画创作门槛很低。无论是抒发情绪、描绘风景还是尝试不同艺术风格，都能满足表达需求，带来绘画的愉悦感。

创意激发：智能创意引擎可在创作中提供灵感。输入关键词或风格偏好后，软件会给出相关元素与构图建议，帮助突破思维定式，开拓新思路。

学习与成长：平台提供丰富学习资源与交流社区，可学习技巧、探索风格并与同好分享作品。交流让水平持续提升，艺术素养随之增强。

开启自动生成后，技术能力得到充分展现。用户可输入关键词或指定风格，例如以画猫为例，可用“民族风”“数位板”“水彩画”等生成不同风格的猫，如图 4-12 所示。软件会迅速解析信息并按要求进行计算与推理，随后通过算法迭代将需求转化为绘画细节。

## 4.4 Midjourney 未来展望

#### 4.4.1 人工智能绘画的前景

人工智能绘画作为创新艺术形式，前景广阔，将持续影响艺术面貌。

-   创造新颖独特艺术风格：具备学习与模仿能力，可分析理解各艺术家风格与技巧。借助深度学习与生成模型，能产出令人惊艳的全新风格，为创作带来新可能，推动艺术家探索独特语言。
-   艺术与科技融合：把艺术与计算机视觉、机器学习等先进技术相连，为艺术家提供更丰富多样工具与媒介，推动艺术界创新发展。
-   个性化与定制化作品：可按个人喜好与需求生成定制艺术品。系统依据用户选择与输入，生成符合期望的独特作品，让每个人都能参与艺术创作。
-   艺术教育与创作学习革新：可模拟名家风格与技巧，帮助学习者更好理解与掌握绘画技巧，激发创作灵感，为艺术教育带来新可能。

人工智能绘画不仅拓展创作边界，也为用户提供更多互动方式，通过创新风格、个性化作品与革新教育，为艺术领域带来变革与机遇。

#### 4.4.2 Midjourney 的发展计划

Midjourney 致力于持续改进体验，拓展功能与应用。发展方向包括：

-   功能增强与创新：持续研发技术改进，提供更多有价值且富创意绘画工具，满足不同需求，增加创作可能性。
-   支持更多平台与设备：将应用扩展至更多操作系统与移动设备，实现跨设备无缝使用。
-   与其他软件与平台集成：与相关艺术创作工具与内容分享平台合作，实现无缝集成，提供便捷工作流与资源共享。
-   增强智能学习与推荐：提升智能学习与推荐算法，提供更个性化体验。系统可依据偏好与历史创作推荐工具、样式与技巧，帮助用户提升技能。
