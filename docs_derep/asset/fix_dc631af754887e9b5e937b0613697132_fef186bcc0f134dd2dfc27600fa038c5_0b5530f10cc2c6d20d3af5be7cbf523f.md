把单卡 LoRA 的启动脚本先放到 LLaMA-Factory 工作目录里，切换进去确认文件是否完整。
[PRE0]
cp single_lora_qwen.sh ~/LLaMA-Factory

cd ~/LLaMA-Factory/

ll
跨系统拷贝后脚本容易残留 Windows 换行，先把行尾的 \r 清掉，保证 Linux 能正常解析。
[PRE1]
sed -i 's/\r$//' ./single_lora_qwen.sh
清理完之后赋予执行权限，直接运行脚本开始微调。
[PRE2]
chmod +x ./single_lora_qwen.sh

./single_lora_qwen.sh

微调结束後需要把 LoRA 权重导出为推理可用格式，下面的例子以 ModelScope 缓存的 Qwen1.5-1.8B-Chat 作为基座，适配器来自本地 checkpoint，导出到 qwen_lora 目录。
[PRE5]
#!/bin/bash

python src/export_model.py \
    --model_name_or_path /mnt/workspace/.cache/modelscope/Qwen/Qwen1__5-1__8B-Chat \
    --adapter_name_or_path ~/LLaMA-Factory/single_lora_qwen_checkpoint \
    --template qwen \
    --finetuning_type lora \
    --export_dir /mnt/workspace/.cache/modelscope/qwen_lora \
    --export_size 2 \
    --export_legacy_format false

device = "cuda" # the device to load the model onto

    qwen_lora,

    torch_dtype="auto",

    device_map="auto"

)

tokenizer = AutoTokenizer.from_pretrained(qwen_lora)
