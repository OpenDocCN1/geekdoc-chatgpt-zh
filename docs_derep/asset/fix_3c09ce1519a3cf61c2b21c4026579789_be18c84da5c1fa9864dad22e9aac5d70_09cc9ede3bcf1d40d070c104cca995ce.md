# MoE 训练实战：带噪声的 Top-K 路由

训练过程中进度条会实时刷新本轮编号、训练误差以及把学习率放大 1000 倍后的数值。进入校验阶段时先让网络进入评估状态并停止梯度记录，随后依次读取验证加载器里的批次。

每批数据和标签都先搬到执行设备，标签转为长整型后送入网络得到 logits。交叉熵计算本批误差并累加到总和里，预测类别取 logits 的最大值并与真实标签对比累计正确样本。所有批次处理完毕后，用累加误差除以加载器批次数得到平均校验误差，用正确样本数除以验证集总样本得到校验精度，最后输出本轮的校验指标。

噪声 Top-K 路由的核心是在路由打分上引入可控扰动。路由器用两条线性投影分别产生原始分数和噪声尺度，尺度经 softplus 平滑后用于缩放标准高斯噪声并叠加到原始分数上。扰动后的分数保留每个样本 Top-K 大的值，其余位置置为负无穷，softmax 后形成稀疏的门控权重，同时返回被选中的专家索引。

class NoisyTopkRouter(torch.nn.Module):

    def __init__(self, n_embed, num_experts, top_k):

        super(NoisyTopkRouter, self).__init__()

        self.top_k = top_k

        self.topkroute_linear = torch.nn.Linear(n_embed, num_experts)

        # add noise

        self.noise_linear = torch.nn.Linear(n_embed, num_experts)

    def forward(self, mh_output):

        # mh_ouput is the output tensor from multihead self attention block

        logits = self.topkroute_linear(mh_output)

        # Noise logits

        noise_logits = self.noise_linear(mh_output)

        # Adding scaled unit gaussian noise to the logits

        noise = torch.randn_like(logits) * torch.nn.functional.softplus(noise_logits)

        noisy_logits = logits + noise

        top_k_logits, indices = noisy_logits.topk(self.top_k, dim=-1)

        zeros = torch.full_like(noisy_logits, float('-inf'))

        sparse_logits = zeros.scatter(-1, indices, top_k_logits)

        router_output = torch.nn.functional.softmax(sparse_logits, dim=-1)

        return router_output, indices

在该路由之上构建稀疏混合专家时，首先实例化噪声 Top-K 路由器并用模块列表保存若干专家。推理时由路由器给出每个 token 的门控分布和选中索引，随后把输入与门控一起拉平成二维便于掩码操作。依次处理每个专家，判断哪些 token 将其选入前 K，若存在则取出对应输入送入专家计算，再用该专家的门控分数加权，最后把加权结果累加回对应位置的输出张量。

##### 定义一个稀疏的混合专家 (MoE) 模型

class SparseMoE(torch.nn.Module):

    def __init__(self, n_embed, num_experts, top_k):

        super(SparseMoE, self).__init__()

        self.router = NoisyTopkRouter(n_embed, num_experts, top_k)  # 路由器，用于选择专家

        # 创建一个专家列表，每个专家都是一个Expert实例

        self.experts = torch.nn.ModuleList([Expert(n_embed) for _ in range(num_experts)])

        self.top_k = top_k  # 选择前K个专家

    def forward(self, x):

        # 通过路由器得到专家的概率分布和索引

        gating_output, indices = self.router(x)

        final_output = torch.zeros_like(x)  # 初始化最终输出为与输入形状相同的全零张量

        # 将输入和路由器的输出展平，以便后续处理

        flat_x = x.view(-1, x.size(-1))

        flat_gating_output = gating_output.view(-1, gating_output.size(-1))

        # 遍历每个专家，根据其概率分布对输入进行处理

        for i, expert in enumerate(self.experts):

            # 找出当前专家是前K个专家的token

            expert_mask = (indices == i).any(dim=-1)

            flat_mask = expert_mask.view(-1)  # 展平操作

            # 如果当前专家对至少一个token是前K个专家之一

            if flat_mask.any():

                # 选出这些token的输入

                expert_input = flat_x[flat_mask]

                # 将这些token输入给当前专家进行处理

                expert_output = expert(expert_input)

                # 获取当前专家对这些token的概率分布

                gating_scores = flat_gating_output[flat_mask, i].unsqueeze(1)

                # 根据概率分布对专家的输出进行加权

                weighted_output = expert_output * gating_scores

                # 将加权后的输出累加到最终输出中对应的位置

                final_output[expert_mask] += weighted_output.squeeze(1)

        return final_output  # 返回最终输出
