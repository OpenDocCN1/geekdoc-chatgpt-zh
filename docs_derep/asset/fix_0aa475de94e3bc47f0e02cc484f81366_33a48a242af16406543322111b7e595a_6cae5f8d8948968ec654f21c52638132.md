### 一、 DS3231 实时时钟：从串口调试到六位动态扫描上屏

DS3231 依靠内置温补晶振，成为高精度 RTC 首选。配合 Arduino 双线总线（Wire 库），读写时分秒仅需数行指令。

#### 1. 基础版：串口监视器看时间
首当其冲引入 `DS3231.h` 与 `Wire.h` 两大依赖包，前者驱动芯片寄存器，后者打通 IIC 通道。实例化 `Clock` 对象，预留 `h12`、`PM` 标志位以兼容 12/24 小时制切换。初始化阶段启动总线、开启 UART（115200 波特率），主循环以 1 秒周期轮询。

#include <DS3231.h>// 定义头文件 DS3231.h，这是时钟模块库函数。

#include <Wire.h>// 定义头文件 Wire.h，这是 I2C 通信库函数。

bool Century=false;// 定义布尔型变量。

注释掉。

void ReadDS3231(){// 时钟子程序。

int second,minute,hour;

second=Clock.getSecond();// 读取秒。

minute=Clock.getMinute();// 读取分钟。

hour=Clock.getHour(h12,PM);// 读取小时。

Serial.print(hour,DEC);// 显示小时。

Serial.print(":");// 显示字符 ":"。

Serial.print(minute,DEC);// 显示分钟。

Serial.print(":");// 显示字符 ":"。

Serial.print(second,DEC);// 显示秒。

Serial.print("\n");// 换行。

}

void loop(){

ReadDS3231();// 调用时钟子程序。

delay(1000);// 延时 1000ms。

}

> **核心要点**：`getSecond/Minute/Hour` 三连调即可拿走原始值，配合 `Serial.print` 格式化输出，调试极其直观。初次烧录需放开注释区的 `set` 系列指令对时，成功后务必再次注释防止上电复位覆盖。

#### 2. 进阶版：六位段码管动态扫描无余辉
要在硬件上跑起来，必须把时间值拆成六位独立数字，并通过动态扫描驱动共阴/共阳管。

**关键步骤拆解：**
*   **数值拆解**：利用取余（`%10`）与整除（`/10`）运算，将时分秒瞬间拆解为 `h2/h1`、`m2/m1`、`s2/s1` 六个个位变量。
*   **段码映射**：`num[10]` 数组预存 0~9 对应的段码（0x3F~0x6F），`ledpin[]` 绑定段选引脚（D7~D13）。
*   **扫描调度**：`scan()` 函数配合 `mod` 变量控制周期，`contro()` 负责位选信号（D1~D6 依次拉高），`disp()` 送段码数据，`disp0()` 全段拉低消除残影。
*   **时序微调**：各位亮灭停顿 3~4 毫秒，人眼视觉暂留效应下呈现稳定显示，差异化延时可平衡亮度一致性。

### 二、 分钟翻零触发：整点报时/指示灯最小逻辑

利用分钟变量归零瞬间作为边沿触发条件，代码极度精简。

[PRE4]cpp

pinMode(13,OUTPUT);// 设置数字端口 13 为输出状态。

if(minute==0()){

digitalWrite(13,1);

}

if(minute>0()){

digitalWrite(13,0);

}

> **实战解读**：`minute` 归零时 D13 输出高电平点亮板载 LED，其余时刻熄灭。工程中可替换为蜂鸣器驱动电路或继电器模块，零成本实现整点报时或定时任务触发。

### 三、 HC-SR04 声纳测距：从 TOF 原理到工程级滑窗均值

声纳测距本质是飞行时间（TOF）测量：`距离 = 高电平宽度 × 声速 / 2`。工程落地核心痛点在于**信号抖动**与**无效读数**，必须引入硬件时序保障与软件滤波算法。

#### 1. 触发时序与回波捕获
控制端需喂入 ≥10µs 高脉冲（代码给 20µs 更稳妥），模块内部自动发射 8 个 40kHz 方波并拉高接收端等待回波。`pulseIn` 阻塞式捕获接收端高电平宽度，单位微秒。

[PRE5]cpp

digitalWrite(TrigPin,HIGH);// 超声波 Trig 引脚输出高电平。

delayMicroseconds(20);// 延时 20 μs。

digitalWrite(TrigPin,LOW);// 超声波 Trig 引脚输出低电平。

[PRE6]cpp

EchoTime_us=pulseIn(EchoPin,HIGH);

#### 2. 距离换算与有效性门限
微秒转厘米系数约 **58.14**（推导：`1e6 / (340 * 100 / 2)`）。同时设定有效窗口 **1µs ~ 60000µs**（对应 ~1 米量程），剔除超时返回 0 及干扰大值，防止脏数据污染统计。

distance_cm=EchoTime_us/58.14;

if((EchoTime_us<60000)&&(EchoTime_us>1))// 如果时间大于1μs并且小于60000μs，那么执行语句1。

#### 3. 滑动窗口累加平均滤波
单次读数波动大，采用**连采 5 次求均值**机制：累加器 `total` 与计数器 `num` 配合，满 5 次即计算平均值 `average`，随后清零重启新一轮累加，有效抑制毛刺抖动。

[PRE8]cpp

distance_cm=EchoTime_us/58.14;// 距离 = 时间 x 声速 /2。

total=total+distance_cm;// 累加距离 = 原来的距离 + 新测量的距离。

num=num+1;//num 加 1。

if(num>=5)// 如果大于或等于 5，

{

  average=total/5;// 计算数组的平均数。

  num=0;//num 清零。

  total=0//total 清零

}
