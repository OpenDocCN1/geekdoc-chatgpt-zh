#### 1.2.2 编码器-解码器

编码器-解码器是一种在深度学习中广泛使用的通用框架，常用于翻译、对话生成等任务。其基本思路是先由编码器把输入压缩成紧凑的语义表征，再由解码器据此生成目标序列。

### 1. 核心思想：信息的压缩与生成
编码器的作用是理解输入语义并提炼为高维紧凑向量，通常称为上下文向量。解码器则以该向量为依据逐步生成输出。以机器翻译为例，法语句子进入编码器后，解码器生成对应的英语句子。编码器完成原文理解，解码器负责转化为目标语言。

这一过程可类比翻译官的工作：编码器对应理解原文，解码器对应输出译文。

### 2. 编码器的工作原理
编码器一般由多层网络叠加构成，基于 Transformer 的编码器最为常见。输入先映射为向量，随后经注意力与前馈网络处理，最终输出蕴含全局语义的向量。

例如句子“猫坐在垫子上”，编码器需要抽取主体“猫”、动作“坐”、位置“垫子上”等信息，并以高维向量保存。

### 3. 解码器的工作原理
解码器在结构上与编码器相近，但任务是序列生成。其输入包含两部分：编码器提供的上下文向量，承载输入整体语义；以及解码器已生成的上一个词，保证输出连贯。

例如翻译“猫坐在垫子上”时，解码器先生成“cat”，随后结合该词与上下文向量生成“is”，如此迭代直至句子完整。

### 4. 关键技术：注意力机制的桥梁作用
编码器与解码器通过注意力机制关联。注意力让解码器在生成每个词时聚焦输入序列中最相关的部分。例如翻译“Le chat est sur le tapis”时，生成“cat”时注意力会落在“chat”，生成“on”时注意力会落在“sur”，从而确保输出有依据。

编码器-解码器也可视作“摘要与扩展”：

（1）编码器把整篇文章压缩为核心摘要，用简洁语言概括要点。
（2）解码器据此摘要，用另一种语言或表达方式扩展为完整文章。

该架构最早在机器翻译中崭露头角，如 Google 翻译，但应用远不止此，还涵盖文本摘要、对话生成、图像描述生成等。例如在图像描述生成中，编码器可用卷积神经网络提取图像特征，解码器负责生成自然语言描述。

总体而言，该架构的核心在于把输入序列转化为中间表征，再据此生成目标序列。注意力机制的配合使编码器与解码器高效协同，使其成为自然语言处理与生成任务的重要基座。设计直观、适用面广，是现代深度学习模型的关键组成。

import torch

import torch.nn as nn

import torch.nn.functional as F

# 定义位置编码

class PositionalEncoding(nn.Module):

    def __init__(self, d_model, max_len=5000):

        super(PositionalEncoding, self).__init__()

        self.encoding = torch.zeros(max_len, d_model)

        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)

        div_term = torch.exp(torch.arange(0, d_model, 2).float() * -(

                            torch.log(torch.tensor(10000.0)) / d_model))

        self.encoding[:, 0::2] = torch.sin(position * div_term)

        self.encoding[:, 1::2] = torch.cos(position * div_term)

        self.encoding = self.encoding.unsqueeze(0)  # 扩展为批次维度

    def forward(self, x):

        return x + self.encoding[:, :x.size(1), :].to(x.device)
