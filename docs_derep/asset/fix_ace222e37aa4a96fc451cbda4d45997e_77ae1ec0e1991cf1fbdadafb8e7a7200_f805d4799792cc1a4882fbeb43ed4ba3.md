售后支撑的变化

在售后支持层面，买断制下想升级到新版本往往需要再次付费，而采用订阅式 SNS 后，按期续订即可持续使用最新迭代。不同厂商在过渡期的具体做法会有细微差别，方向却高度一致。

#### SNS 为什么被归入 SaaS

其一，云服务普及后，面向企业的 SaaS 在用户习惯培养上仍在推进，但在个人消费端已出现不少成功案例。传统盒装软件由此获得启发：卖产品并非唯一路径，卖服务同样可行，尤其是通用型软件可以先在 C 端建立使用习惯，再平滑切入 B 端。正是在这一背景下，SNS 作为一种可行的 SaaS 路径被提出。早期厂商只是把售后维护改为订阅，如今已把软件首次启用也纳入订阅体系。

其二，SNS 的覆盖并不局限于盒装软件，几乎囊括所有软件形态，可归纳为三类。第一类需借助介质预装到客户服务器或终端，经云端注册激活后即可使用，后续本地运行无需持续联网，如各类办公套件和大型专业工具。第二类完全运行在云上，用户凭授权账号登录即可使用，如邮件服务、网站发布服务。第三类是前两者的结合，如社交、内容类服务，客户端必须通过账号授权连通云端才能调用功能与内容。

其三，与 SaaS 理念相通，SNS 的本质是服务。要以客户为中心持续迭代，让客户像用水电气一样按需付费，规避一次性买断的高额投入风险。从已推行 SNS 的厂商实践看，大多数正从传统模式向完全 SaaS 过渡，不少同时上线了对应的 SaaS 版本，这也侧面印证了 SNS 只是 SaaS 的一种形态。

#### SNS 的得失

任何商业模式都有两面，SNS 尽管成趋势，优劣仍需清醒看待。

积极面：对使用者而言，按需付费使用更灵活，避免一次性大额支出；升级免费，不怕功能滞后，也不必重复购入不同版本。对提供方而言，能沉淀相对稳定的续费客群，保持研发节奏；收入曲线更平滑，便于资本和经营管理预测，避免业绩大起大落。

制约面：对使用者而言，需持续付费，逾期未续可能在关键时刻丧失使用权限；停止续费后，历史数据资产也面临沉没。对提供方而言，单次使用成本低，用户粘性不足易流失；需求变化时，升级与平滑迁移的技术风险上升，运营成本随之增加。

综合实践与趋势看，对使用者和提供方而言 SNS 总体利大于弊。降低不确定性冲击、实现业务敏捷是双方共同诉求，这种双赢模式更有利于软件市场良性发展。

——技术随笔：软件进入订阅时代，使用体验成为关键胜负手。

#### 语音助手指什么
语音助手是依托人工智能，通过自然语言交互与即时问答来帮助用户解决问题的人机交互系统。

当下主要有三种形态：一是嵌入在软件产品中的功能模块，如各类 App 的语音交互单元，可完成指令匹配与执行；二是硬件形态，如智能音箱、车载终端、智能机器人等，以语音控制为核心，使设备能听懂人话；三是服务形态，如智能搜索、自动驾驶、视频会议等系统，由前端设备、后端云服务及专家支撑，对任意语音请求实时响应、语义分析并呈现结果。

#### 典型用途有哪些
作为融合人工智能与语义分析的应用，语音助手具备强大的自然语言处理能力和操作便捷性，很适合作为新型交互界面，提升人与人、人与物、人与系统间的实时互动。实践中主要有三类场景。

其一面向家庭生活，以智能音箱为代表，可简化日常操作，如设备控制、餐厅预订、音乐播放、网购等，并能提前提醒无须手动干预，属于典型的辅助类应用，多见于设备到用户或系统到用户的交互。

其二面向客户服务，以客服响应为代表，如呼叫中心、智能售后助手、在线答疑等，能提高服务效率、减少人工配置，避免人工响应带来的个性差异，属于服务响应类应用，多用于企业面向客户。

其三面向虚拟空间，以虚拟人物互动为代表，如虚拟主播、网络社交、在线展会等，能带来新奇体验，是培育新商业机会、激发潜在需求的工具，属于自由拓展应用，多用于用户之间。

#### 如何落地
原则上各领域企业均可借助语音助手提升响应、拓展业务、增强粘性。实践中可借鉴三点。

首要明确目的。为降本可选用成熟的在线客服或外呼语音助手；为探新业务可定制专属虚拟 IP，吸引关注、获取市场反馈、孵化增长点；为提效可把自助语音助手作为新输入方式，便于客户和内部员工使用。

其次要积累知识。当前智能核心仍依赖已有知识与大数据，泛化能力不足是普遍问题，穷尽全领域知识不现实。不如聚焦特定领域深耕，通过梳理专业知识形成差异化优势。企业自身的业务模式与沉淀的专有知识是宝贵资源，将这些领域知识持续系统地喂给算法与机器学习，可让语音助手不断优化专业问题的理解与输出，实现更精准响应。

最后要循序渐进。语音助手作为新交互方式必然面临习惯培养阻力，需有定力与耐心，通过持续迭代找到最适合业务的互动形式。工具只是工具，核心仍是业务竞争力，要在实践中磨合匹配。

——技术随笔：当语音助手撞上 AI，声音本身变成诱惑与共谋。

### 第120篇 做失败者还是开拓者？——IT生存法则：5G 应用
防“踢”指数：★★★★★

#### 5G 应用究竟是什么
5G 应用是指以第五代移动通信技术为无线传输介质实现的各类场景，涵盖音视频、数据传输等，主要体现为各类手机 App，尤其需要高带宽、低时延、多连接的行业应用。

无论几代移动通信，都可作为无线传输介质实现音视频与数据传输，区别在于带宽、时延、并发连接数。5G 是分水岭，基于独立组网的 5G 将正式开启万物互联的高速时代。

正因特性大幅提升，业界对其应用领域寄予厚望，不断尝试将 5G 与各行业结合，期望挖掘杀手级应用，再掀移动通信高潮。

#### 如何发掘 5G 应用机会
一是从技术维度切入。针对无线高带宽，可在高速传输领域寻找场景，如 4K/8K 高清视频传输；针对海量互联，可在需要并发连接大量移动设备的方向探索，如移动电商；针对高可靠低时延，可在对实时性要求高的领域扫描，如无人驾驶。组合标签后排序验证。

二是从行业维度引导。5G 升级正逢传统行业数字化转型，可据行业特点与需求引导落地。例如能源行业监控巡检数字化，引导有线加无线模式，通过 5G 实现远端设备数据传输；公共服务应急管理数字化，引导随时随地实时化模式，实现公共对象实时监看与预警；生产制造哑终端数字化改造，引导可靠控制模式，实现实时化与智能化。在单行业验证成功后提炼通用方案跨行业复制。

三是从现实场景洞察。多数需求源于现实瓶颈，从影响体验、效率、效益的问题入手，或更易发现杀手级应用。例如为解决大型场馆直播效果不佳开发的 5G 直播，已成大型活动的标配；为解决重大事件处置时全场景监看难题开发的 5G 现场通，也取得良好效果。

#### 常见误区
误区一，盲目夸大效果。5G 虽有提升，但仍有高能耗、部署密度大等局限，推广时需客观呈现，否则错配资源并产生负面影响。

误区二，急于扩大规模。探索验证期应避免急功近利，未经论证就大规模复制推广，易因需求不符或体验不佳而夭折，打击创新积极性。

误区三，项目虎头蛇尾。IT 应用易犯重建设轻运营，5G 标准仍在演进，需持续与各领域技术标准融合。例如与传统虚拟专网兼容，需在运营中不断完善，全生命周期保障不足易成烂尾工程。

——技术随笔：5G 再一次证明带宽提升就是最大的杀手级应用。

“老公，我们家庭宽带套餐升级了，绑定的号也升 5G 了，我的手机是不是也该换个 5G 的，听说很快，更方便追剧。”

方经理拿定主意。
