# 序言 AI已潜入每个角落

[PRE0]
教人工智能调情绝不是我的常规操作。

当然我做过不少古怪的AI实验。在我的博客“怪奇人工智能”上，我曾让AI给猫咪起名，结果冒出叮当先生或呕吐者之类的败笔，也让它生成食谱，里头竟然出现去皮迷迭香和碎玻璃之类的配料。可让它说人类的甜言蜜语，感觉完全不一样。

AI靠样本学习——在我们这里就是研读一批现有的搭讪俏皮话，再据此造出更多新句子。问题是，我电脑里用来训练的数据集是我从网上各处搜集的俏皮话，质量都很糟。油腻的双关、带侮辱性的暗示都有。一旦模型学会模仿，只要点一下按钮，就会源源不断吐出上万条烂梗。就像一个极易受环境影响的孩子，它分辨不出哪些该学哪些不该学。从对搭讪一无所知的白板开始，它尽力捕捉样本里的规律，包括其中的粗俗部分。AI并不知道什么算好。

我一度想放弃这个项目，毕竟已经花了不少时间收集样本。于是还是开始训练。模型开始在样本里找规律，编出一些能预测俏皮话里字母顺序的规则。训练结束，我有点忐忑地让它生成几句：

你一定是一个三角形？因为你是这里唯一的东西。

嘿，宝贝，你会成为一把钥匙吗？因为我能够忍受你的嘟嘟声。

你是一根蜡烛吗？因为你看起来真热辣。

你真美，你对我和宝贝说蝙蝠。

你看起来像个东西，我爱你。

我既惊讶又觉得好笑。这个虚拟大脑的复杂度大概只相当于一条蚯蚓，它根本无法分辨数据集里的厌女倾向和粗鄙之处，它只是尽力复现发现的规律……然后给“逗笑陌生人”这个任务提供了一种完全不同、也许更妙的解法。

对我来说，能让它开口已是惊喜。但对那些只从新闻和科幻片了解AI的人，这种混乱的表现可能很出乎意料。我们常听公司宣称AI能像人一样辨别语言细节，甚至更好，或很快取代大量工作。媒体也说AI即将无处不在。这些说法既对又大错特错。

事实是AI已经无处不在。网上的体验依赖AI，它决定广告投放、推荐视频，同时检测社交媒体的机器人和恶意网站。许多公司用AI筛简历、决定面试对象，也用它判断贷款是否通过。自动驾驶里的AI已行驶上百万英里，卡壳时偶尔需人救援。我们手机里的AI能识别语音指令，给照片里的人脸打标签，甚至在视频里给我们加上兔耳朵滤镜。

但很快你就会体会到，这些我们每日使用的AI并不完美。广告系统会反复推送你已买过的靴子。垃圾邮件过滤器有时放过明显的骚扰，或在最糟的时机拦掉关键邮件。

[PRE1]
当生活的大量环节被算法支配，这些AI的“怪癖”就不再只是不便，还会产生严重后果。YouTube的推荐算法会把人引向更极端的内容，几步点击就能从主流新闻滑向仇恨团体和阴谋论视频。[^(\[1\])](#part0004.html#notef1)用于假释、贷款、简历筛选的算法标榜中立，却可能像它们要替代的人类一样带有偏见，有时更甚。AI监控不会受贿，但在被要求执行时，也不会因道德原因拒绝。研究者发现，一块小贴纸就能让图像识别把手枪认成烤面包机，而不安全的指纹识别被主人指纹骗过的概率高达77%。

人们常把AI吹得比实际更神，号称它能完成科幻才有的场景。另一些人夸它公正无私，尽管表现明显偏颇。更常见的是，号称AI完成的工作背后其实是人类在操作。作为消费者和公民，我们得提防被误导。我们需要弄清数据如何被AI使用，以及我们用的AI到底是什么。

在“怪奇人工智能”上，我用AI做了不少有趣的尝试。这意味着让它模仿一些奇葩事物，比如俏皮话。我也想把它逼出舒适区，比如给图像识别算法看阿纳金·天行者的照片，它回答是棵树，还跟我争论起来。从经验看，最直接的任务也可能让AI失效，就像跟它开玩笑。但把任务丢给它看它如何抓瞎，恰恰是了解AI的好办法。

事实上，正如书中会看到的，AI算法内部往往复杂怪异，观察它的输出可能是唯一能探索它理解了什么、哪里出错的手段。让AI画只猫或讲个笑话时，它犯的错与处理指纹或医学影像时的错本质相同，只是猫有六条腿、笑话没有包袱时，你更容易察觉。而且这些错真的很好笑。

我曾让AI写小说第一行、在奇异场景里识别绵羊、拟菜单、给豚鼠起名，结果都很离奇。但这些实验能学到AI的优缺点，以及它在我们有生之年几乎不可能做到的事。

我学到的东西可以总结为：

人工智能奇怪之处的五点原则：

·短板源于不够聪明，而非太聪明。
·智力水平大概相当于一条蚯蚓。
·它从未真正理解你想让它解决的问题。
·它会严格照做你给的指令，至少会拼命去做。
·它总是选择最容易的路径。

那么，一起进入AI的奇异世界吧！我们会知道AI是什么、不是什么。它擅长什么，在哪里必然失败。为什么未来的AI可能不像C–3PO[^(\[2\])](#part0004.html#notef2)那样，反而更像一群昆虫。为什么末日丧尸横行时自动驾驶不适合逃命。为什么永远不要自愿测试一个分三明治的AI，以及会遇到只想行走不想做事的行走AI。在这个过程中，我们会了解AI如何工作、如何“思考”，以及它为何让世界变得更怪异。

# 第 1 章 人工智能是什么

[PRE2]
AI看起来无处不在，部分原因是这个词的含义太宽泛，具体指什么取决于你在读科幻小说、在卖新应用，还是在做科研。有人说他们有个AI聊天机器人，我们该期待它像小说里的C-3PO一样有观点和情感吗？还是只是学会猜测用户回复的算法？是把问题词和数据库里算好的答案匹配的电子表格？是远方键盘前拿低薪的人？甚至是照本宣科念台词的戏剧演员？令人困惑的是，这些在很多语境下都被叫做人工智能。

出于本书的目的，我会像大多数程序员一样使用这个词，指代一类特定的计算机程序——机器学习算法。书中会提到的一些名词，以及它们是否属于这里定义的AI，会在表格里说明。

[PRE3]
本书里所有被称作“人工智能”的东西都属于机器学习算法——这到底是什么，让我们聊聊。

### 咚，咚，那是谁

要识别自然环境中的AI，理解机器学习算法，和传统程序也就是基于规则的程序的区别很有帮助。你做过基础编程或用HTML搭网站，就是在用基于规则的程序。你用计算机能懂的语言写下指令，计算机就严格执行。你必须事先知道每一步怎么描述。

机器学习算法则能通过试错和在程序员设定的目标上自我评估，自行找到规则。目标可以是一批待模仿的样本、一个游戏分数，或其他任何东西。在追目标的过程中，它会发现程序员可能都不知道的关联。与写传统程序相比，写AI更像教孩子。

我可以花更多时间设计更高级规则，找已有包袱并转化，发音、韵律、同义词、文化背景等都可写进程序，让电脑重新组合出有趣包袱。若做得聪明，甚至能生成从未有人见过的包袱。无论规则多复杂，我始终在告诉计算机如何具体解决问题。

#### 训练人工智能

我们只给它一堆现成的敲门笑话，和一句指令：“看这些，去造更多。”学习材料是随机的字和标点集合。
