### 13.3.1 并行计算底层原理

并行计算指的是多条计算任务或进程同时推进。串行计算则是任务依次完成。与串行不同，并行让多任务重叠执行，从而整体提升速度与吞吐量。

并行可在多类处理单元上展开，例如多处理器、多加速卡、多计算节点，如图 13.3.1 所示。加速硬件既包括昇腾 AI 处理器，也包括 GPU、TPU、FPGA 等。并行硬件擅长处理大规模计算密集型问题。并行技术被广泛用在科研、工程设计、图形处理、数据分析等领域。

本小节先对并行体系结构进行归类，再介绍大模型并行加速的基础思路，最后用量化方法分析并行效率。

#### 1. 并行架构分类全景

从硬件、系统到应用三个维度，可划分为指令级并行、线程级并行和请求级并行。

**指令级并行 ILP** 指处理器内部在同一时钟周期能够并发执行多条机器指令。该并行性无需程序员手工优化，由硬件自动管理。常用手段包括：

- **超标量 Superscalar**：每个时钟周期可向不同执行单元分发多条指令，内置整数、浮点、访存等多执行单元，实现多操作重叠。
- **流水 Pipelining**：把指令拆分为若干微阶段，不同指令的各阶段重叠推进。典型四段流水为取指 IF、译码 ID、执行 EXE、写回 WB。

**线程级并行 TLP** 通过创建多线程实现并行，在多核多处理器系统上各线程可真实并发。常见于操作系统、数据库、服务端应用，通常需要开发者显式创建和管理线程。

**请求级并行 RLP** 多见于服务场景，服务器同时接收多个独立客户端请求，为每个请求创建独立处理流程并行执行，可提升服务能力与响应速度。

从软件设计视角，并行可分为数据级并行与任务级并行。

**数据级并行** 把大数据块拆分为小块，在多个处理单元上以相同操作并行处理不同数据片段。适合数组、向量、矩阵等结构，常用于科学计算和图像处理。

**任务级并行** 把工作拆解为可独立执行的任务，在不同单元上同时运行。任务间可有依赖也可完全独立，需要设计适配并行硬件的算法结构，在软件工程、复杂事件处理和多媒体领域应用广泛。

以企业发薪为例帮助理解。假设每月需发放数百万员工工资。

数据级视角下，全部工资计算被切分为多个数据块分发给不同处理器。每个处理器执行完全相同的计算，但只处理分配到的数据块，例如处理器 A 负责员工 1~1000，处理器 B 负责 1001~2000，各自独立完成个税扣除、福利计算，最终生成对应工资条。

任务级视角下，各处理器承担不同任务，例如处理器 A 负责全体员工税务扣除，处理器 B 负责全体员工福利待遇。此时每个处理器读取完整工资数据集，但只执行特定任务，最后合并结果生成最终工资条。

此外，Micheal J. Flynn 于 1966 年提出 Flynn 分类法，按指令流和数据流组织方式对体系结构分类，相关内容已在第 3 章和第 12 章介绍。该分类对理解并行有帮助，但随着 GPU、众核处理器和异构计算兴起，已难以覆盖全部并行模式，于是出现更复杂的模型。例如单程序多数据 SPMD，在 SIMD 基础上扩展，当各处理器拥有独立控制部件时，可通过软件让各处理器并行执行同一程序但处理不同数据，Ascend C 正是基于昇腾 AI Core 构建 SPMD 编程模型。

### 13.3.2 Ascend C 编程体系

#### 1. Ascend C 编程概览

面向算子开发的 Ascend C 原生支持 C 与 C++ 标准，贴合用户习惯；依托多层接口抽象、自动并行计算、孪生调试等技术，大幅提升算子开发效率，帮助 AI 开发者低成本完成算子开发与模型调优部署。

使用 Ascend C 自定义算子的主要优势：

- 以 C/C++ 原语进行编程；
- 编程模型屏蔽硬件差异，范式提升开发效率；
- 类库 API 封装由简到繁兼顾易用与高效；
- 孪生调试可在 CPU 侧模拟 NPU 行为，优先在 CPU 侧调试。

#### 2. Ascend C 编程模型

AI Core 是昇腾 AI 处理器执行计算密集型任务的核心算力单元。本节先介绍 AI Core 硬件抽象中的计算、存储与 DMA 搬运，再介绍 SPMD 模型和流水编程范式，二者可有效提升 Ascend C 算子的并行效率与加速倍数。

##### 1) AI Core 硬件抽象

用 Ascend C 编写的算子运行于 AI Core，一个处理器内部包含多个 AI Core，每个 AI Core 包含计算单元、存储单元、搬运单元、控制单元等。为屏蔽硬件差异，统一做硬件抽象，如图 13.3.2 所示。

## 13.4 Ascend C 语法扩展

Ascend C 本质是标准 C++ 加上一组扩展语法与 API。本节先介绍基础语法扩展，再讨论基础 API 与高阶 API，随后对数据存储、任务间通信与同步、资源管理、临时变量等关键编程对象进行解读，为后续编程范式讲解奠定基础。

### 13.4.1 语法扩展总览

Ascend C 采用华为自研毕昇编译器，设备侧编程在 C/C++ 语法上扩展，允许函数执行空间和地址空间作为合法类型限定符，从而实现主机 Host 侧与设备 Device 侧独立执行，并提供针对不同地址空间的访问能力。

#### 1. 函数执行限定符

函数执行空间限定符指示函数在主机还是设备上执行，以及是否可被主机或设备调用，主要有三种声明方式：

第一类：`__global__` 执行空间限定符。声明 Kernel 函数，即 Ascend C 算子入口，特性如下：

- 在设备上执行；
- 只能被主机侧函数调用；
- `__global__` 仅表示设备侧函数入口，不指定具体设备类型；
- 必须返回 void，不能是类的成员函数；
- 主机侧调用需使用 `<<<>>>` 内核调用符进行异构调用；
- 调用是异步的，返回不代表设备侧已完成，需用运行时同步接口如 `aclrtSynchronizeStream(...)` 显式同步。

第二类：`__aicore__` 执行空间限定符。声明的函数可在 AI Core 设备上执行，只能被 `__global__` 函数或其他 AI Core 函数调用。

第三类：`__host__` 执行空间限定符。声明的函数通常默认在主机侧执行，只能被主机侧函数调用；`__global__` 与 `__host__` 不能共用。
