让大模型记住你是谁：LangChain 会话记忆与多语实践

如果只是单轮问答，LLM 很快就会忘记上下文。LangChain 提供了一条清晰的演进路径：先裸调用，再接入会话历史，最后加入长度裁剪。下面用一套可直接运行的脚本，把这三层能力依次演示出来。

from langchain_core.runnables.history import RunnableWithMessageHistory

store = {}

def get_session_history(session_id: str) -> BaseChatMessageHistory:

    if session_id not in store:

        store[session_id] = InMemoryChatMessageHistory()

    return store[session_id]

with_message_history = RunnableWithMessageHistory(model, get_session_history)

用内存版的 InMemoryChatMessageHistory 做暂存，通过 get_session_history 按 session_id 取回或新建历史对象。RunnableWithMessageHistory 会在调用前后自动读写这些历史。

长对话必然碰到 token 上限。自定义 token_counter 用 tokenizer 统计每个消息的真实 token 数，再用 trim_messages 按 last 策略保留最新几轮，同时保留系统提示。

[PRE13]python

from langchain_core.messages import SystemMessage, trim_messages

from transformers import AutoTokenizer

from typing import List

from langchain_core.messages import BaseMessage, ToolMessage

tokenizer = AutoTokenizer.from_pretrained("Your_model_path/Yi-1.5-34B-Chat")

def str_token_counter(text: str) -> int:

    return len(tokenizer.encode(text))

def token_counter(messages: List[BaseMessage]) -> int:

    num_tokens = 3  # 每个回复都带有 <|start|>assistant<|message|>

    tokens_per_message = 3

    tokens_per_name = 1

    for msg in messages:

        if isinstance(msg, HumanMessage):

            role = "user"

        elif isinstance(msg, AIMessage):

            role = "assistant"

        elif isinstance(msg, ToolMessage):

            role = "tool"

        elif isinstance(msg, SystemMessage):

            role = "system"

        else:

            raise ValueError(f"Unsupported messages type {msg.__class__}")

        num_tokens += (

            tokens_per_message

            + str_token_counter(role)

            + str_token_counter(msg.content)

        )

        if msg.name:

            num_tokens += tokens_per_name + str_token_counter(msg.name)

    return num_tokens

trimmer = trim_messages(

    max_tokens=50,

    strategy="last",

    token_counter=token_counter,

    include_system=True,

    allow_partial=False,

    start_on="human",

)

messages = [

    SystemMessage(content="你是一个会多种语言的聊天机器人，请用{language}和我对话。"),

    HumanMessage(content="你好，我是小明。"),

    AIMessage(content="你好，小明。"),

    HumanMessage(content="今天天气不错。"),

    AIMessage(content="是啊，你今天有什么计划吗?"),

    HumanMessage(content="我想去公园散步。"),

    AIMessage(content="真是一个好主意!有什么我可以帮助你的吗?"),

    HumanMessage(content="我想知道西安有什么适合散步的公园，你知道吗?"),

    AIMessage(content="当然，可以去劳动公园或者七夕公园。"),

    HumanMessage(content="好的，那我今天去劳动公园散步。"),

    AIMessage(content="好的，祝你玩得愉快。"),

]

trimmer.invoke(messages)

from operator import itemgetter

from langchain_core.runnables import RunnablePassthrough

chain = (

    RunnablePassthrough.assign(messages=itemgetter("messages") | trimmer)

    | prompt

    | model

)

response = chain.invoke(

    {

        "messages": messages + [HumanMessage(content="我叫什么名字?")],

        "language": "中文",

    }

)

response.content

把裁剪器嵌入链路，先用 RunnablePassthrough.assign 对 messages 做裁剪，再送入 Prompt 和模型。这样每次调用前都会自动瘦身。
