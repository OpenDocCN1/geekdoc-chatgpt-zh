2. 如何规范录入日期与时间？

- 日期录入：
  - 常用分隔符为 YYYY/MM/DD、YYYY-MM-DD、MM/DD/YYYY，具体依据区域设置。
  - 举例可写 2025/4/22 或 22-Apr-2025。
- 时间录入：
  - 24小时制写作 HH:MM:SS，12小时制写作 HH:MM AM/PM。
  - 举例 14:30 或 2:30 PM。
- 日期加时间录入：
  - 日期与时间用空格隔开，如 2025/4/22 14:30。
- 注意事项：
  - 单元格必须设为日期或时间格式，否则会被识别为文本。
  - 默认样式受控制面板区域设置影响，可在区域设置里调整。

3. 如何快速修改非法日期？

- 常见问题：
  - 文本格式日期，例如“2025年4月22日”未按规则输入。
  - 超出Excel支持范围，早于1900年1月1日或晚于10000年。
- 处理方式：
  1. 分列功能：
     - 选中数据 → 数据 → 分列 → 选日期格式 → 完成。
  2. 公式转换：
     - 用 =DATEVALUE(A1) 把文本转成日期，用 =TIMEVALUE(A1) 把文本转成时间。
  3. 条件格式标注：
     - 开始 → 条件格式 → 新建规则 → 使用公式 =ISERROR(A1*1)，设置颜色突出非法值。

图 5-41 DeepSeek 关于如何快速修改非法日期的回答

4. 如何设置日期和时间的自定义格式？

- 操作步骤：
  1. 选中单元格 → 右键 → 设置单元格格式 → 自定义。
  2. 输入格式代码：
     - 日期代码：
       - yyyy 表示四位年 2025
       - mm 表示两位月 04
       - dd 表示两位日 22
       - mmm 表示英文月缩写 Apr
       - mmmm 表示英文月全称 April
     - 时间代码：
       - hh 为12小时制小时
       - HH 为24小时制小时
       - mm 为分钟
       - ss 为秒
       - AM/PM 显示上下午
  - 示例：
    - yyyy-mm-dd → 2025-04-22
    - dd-mmm-yy → 22-Apr-25
    - hh:mm AM/PM → 02:30 PM

## 5. 常用的日期时间函数

| 函数 | 用途 | 示例 |
| :--- | :--- | :--- |
| TODAY() | 返回当前日期 | =TODAY() → 2023-10-05 |
| NOW() | 返回当前日期和时间 | =NOW() → 2023-10-05 14:30 |
| DATE(年,月,日) | 组合日期 | =DATE(2025,4,22) → 2025-04-22 |
| TIME(时,分,秒) | 组合时间 | =TIME(14,30,0) → 14:30 |
| DATEDIF(开始日,结束日,"单位") | 计算日期差值（单位如"Y"年、"M"月、"D"日） | =DATEDIF(A1,B1,"D") → 天数差 |
| YEAR(日期) | 提取年份 | =YEAR(A1) → 2025 |
| MONTH(日期) | 提取月份 | =MONTH(A1) → 4 |
| DAY(日期) | 提取日 | =DAY(A1) → 22 |
| HOUR(时间) | 提取小时 | =HOUR(A1) → 14 |
| EDATE(日期,月数) | 返回指定月数后的日期 | =EDATE(A1,3) → 2025-07-22 |

## 实际应用示例

- 计算年龄：
  `=DATEDIF(出生日期, TODAY(), "Y") & "岁"`
- 倒计时天数：
  `=目标日期 - TODAY()`
- 提取周末日期：
  `=IF(WEEKDAY(A1,2)>5, "周末", "工作日")`

## 注意事项

- 日期函数结果依赖系统时间，保持电脑时间准确。
- `Ctrl+;` 可快速填入当前日期，`Ctrl+Shift+;` 可快速填入当前时间。
- 跨区域协作时统一日期格式，避免混淆。
