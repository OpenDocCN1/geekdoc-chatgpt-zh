# DeepSeek 本地可视化上手攻略

想把 DeepSeek 模型快速接入可视化界面，同时用 Python 直接调用 API？下面是一套从环境隔离到实战调用的完整走位，照着跑就能立刻跑起来。

**一、先把运行环境隔离开**
为了避免依赖冲突，先用 Conda 起一个干净的 Python 3.11 环境，名字就叫 open-webui。建好后初始化 Conda、刷新 shell 配置，再激活环境进入工作区。

[PRE0]bash

# 创建一个名为 open-webui 的 Conda 虚拟环境，并指定 Python 版本为 3.11

conda create -n open-webui python=3.11

# 初始化 Conda

conda init

# 重新加载 shell 配置

source ~/.bashrc

# 激活刚刚创建的 open-webui 环境，进入该环境

conda activate open-webui

**二、装上 Open WebUI 并跑起来**
进入环境后，通过清华镜像源安装 Open WebUI，安装完成直接用 serve 命令启动服务，就能在本地打开 Web 界面。

[PRE1]bash

pip install open-webui -i https://pypi.tuna.tsinghua.edu.cn/simple

[PRE2]bash

open-webui serve

**三、准备 Python 调用 DeepSeek**
先装 OpenAI 兼容 SDK，后续所有请求都走同一套接口。把自己的 API Key 填进去，客户端指向 DeepSeek 官方地址，模型选用 deepseek-chat。

[PRE3]bash

pip install openai

[PRE4]python

import os

from openai import OpenAI

from IPython.display import display, Code, Markdown

import requests

import json

# <YOUR_DEEPSEEK_API_KEY>替换为复制的 API key 字符串

ds_api_key = '<YOUR_DEEPSEEK_API_KEY>'

#实例化客户端

client = OpenAI(api_key=ds_api_key,

                base_url="https://api.deepseek.com")

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {"role": "user", "content": "你好，好久不见!"}

    ]

)

#输出生成的响应内容

print(response.choices[0].message.content)

#输出完整的响应

print(response)
