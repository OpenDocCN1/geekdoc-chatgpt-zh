#### 7.2.2 批量拆分PDF文档

7.2.1节介绍了如何用AI和Python从扫描PDF提取信息并改名。本节解决另一个常见场景：长文档的拆分。

工作中常遇到篇幅很长的报告、手册或书籍，需要拆成小份便于管理、分享或归档。手动拆分费时易错，用Python即可实现程序化批量拆分与重命名。

下面示例演示如何把一份PDF从第1页起每7页拆成一个独立文件，并按序号批量命名。

##### 案例需求详解

目标脚本需实现：

1）读取指定PDF。
2）从第1页起每7页为一个单元，例如20页文档会拆成1～7页、8～14页、15～20页三份，最后一份不足7页也保留。
3）每个单元另存为新PDF。
4）按拆分顺序命名为“1.pdf”“2.pdf”“3.pdf”…
5）整体流程自动化、支持批量。虽然本例针对单文件，代码结构便于扩展到多文件批量。
