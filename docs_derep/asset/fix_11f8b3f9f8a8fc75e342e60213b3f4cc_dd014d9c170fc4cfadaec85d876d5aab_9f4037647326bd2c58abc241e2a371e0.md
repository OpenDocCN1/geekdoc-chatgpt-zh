大模型微调落地指南：选型、配置与核心思路

LLaMA-Factory 的定位是一个开箱即用的微调套件，面向大语言模型与视觉语言模型提供统一操作入口，帮助开发者把通用基座快速适配到具体下游任务。主要能力可以概括为：

- 模型兼容度高：已收录上百种 LLM 与 VLM，包含 Llama 3、GLM-4、Mistral Small、PaliGemma2 等近期热门版本。
- 参数高效方案：内置 LoRA、QLoRA 等低开销技术，让训练更快、显存占用更少。
- 跨模态覆盖：除文本外，还能处理图像识别、语音理解等多模态任务。
- 训练可视化：对接 LlamaBoard、TensorBoard、Wandb、MLflow 等工具，实现全程监控。
- 推理提速：提供类 OpenAI 接口、Gradio 页面与 CLI，并借助 vLLM 加速推理。

##### 3. ms-SWIFT
ms-SWIFT 源自魔搭社区，名称前置 ms 前缀，简称为 SWIFT。它打通了大模型训练、推理、评测、量化到部署的完整链路。

亮点包括：

- 模型覆盖极广：支持 450+ 个 LLM 与 150+ 个多模态模型，涵盖 Qwen 2.5、InternLM 3、GLM 4、Llama 3.3、Mistral、DeepSeek-R1、Yi 1.5、Baichuan 2、Gemma 2，以及 Qwen 2.5-VL、Qwen 2-Audio、Llama 3.2-Vision、Llava、InternVL 2.5 等。

- 友好交互：基于 Gradio 的网页控制台，简化训练、评测、量化与部署流程。

### 6.1 大模型微调基础

本节梳理微调核心概念、常用方法及软硬件搭建要点，帮助在实战中平衡性能与资源。

#### 6.1.1 大模型为什么需要微调

预训练模型在海量无标注文本上学习通用语言规律，具备较强理解与生成能力，但缺乏针对性。

##### 1. 提升模型在特定任务上的表现
通用模型在文本生成上尚可，但在情感分析、医疗问答等细分任务上可能不准。微调借助领域数据学习特定模式，显著增强任务表现。

##### 2. 适应领域知识
不同专业领域表述差异大，通用模型难以覆盖。法律文本严谨、金融含公式、医学含化学表达等，通过微调注入专业数据，提升问答质量。

##### 3. 提高计算效率和节约资源
全量训练成本极高，GPT-3 1750 亿参数需数千 A100 分布式训练。微调仅在基座上做小幅调整，大幅降低算力与时间。

#### 6.1.2 微调基础概念介绍

##### 1. 微调
在预训练基座上用标注数据继续训练，让参数适配特定任务。与 RAG、Agent 工作流不同，微调是改动模型参数，实现“永久”能力。

##### 2. 全量微调与高效微调
从策略看可分为全量与高效。全量更新全部参数，改造彻底但消耗大；高效仅改动部分参数，属于“四两拨千斤”。

##### 4. 高效微调：LoRA与QLoRA
全量微调改造强但门槛高，多数场景更适合高效方案。

1) LoRA
LoRA 通过低秩适配矩阵减少可训练参数，降低显存与计算负担。仅训练插入的适配层，原始权重冻结，适合显存紧张设备。

2) QLoRA
在 LoRA 基础上加入量化，把权重压缩至 INT4/INT8，进一步减少存储与计算。在极端显存受限或追求低延迟推理时优势明显。

表6.1 LoRA与QLoRA特性对照表

| 特性 | LoRA | QLoRA |
| :--- | :--- | :--- |
| 核心技术 | 低秩适配器（low-rank adapters） | 低秩适配器+量化技术（low-rank adapters + quantization） |
| 适用场景 | 显存受限，但设备性能较好 | 极限显存受限或需要快速推理的设备 |
| 计算效率 | 提高计算效率，减少调整的参数数量 | 进一步提升效率，减少内存使用并加快推理速度 |
| 量化技术 | 无量化 | 将权重量化为低精度（如 INT4 或 INT8） |
| 内存消耗 | 较低，但不如 QLoRA 低 | 显著降低内存消耗，适合更小的设备 |
| 训练复杂度 | 较简单，适用于大多数微调场景 | 需要更多的量化和适配工作，但适合超大模型和设备受限场景 |

#### 6.1.3 高效微调的应用场景

实践中高效微调常用于：

##### 1. 对话风格微调
针对客服、虚拟助手等场景调整语气、礼貌度与回答风格，让输出更贴合品牌调性。

##### 2. 知识灌注
把外部或领域专有知识快速注入基座，无需从零训练。法律、医疗等专业领域可用少量标注数据提升术语理解。

##### 3. 推理能力提升
通过微调增强长文本理解、隐含信息抽取与逻辑关联，提升多轮复杂推理准确率。

##### 4. Agent能力提升
在多任务协作与工具调用场景，微调可让模型更精准解析指令、调用 API、传递参数，提升自动化服务与智能助手的执行效果。
