**DeepSeek 本地部署实战指南**

把 DeepSeek 安在本地机器上，是实现功能个性化定制并守住数据隐私的核心做法。接下来系统梳理完整的本地搭建链路，涵盖部署前的准备、依赖安装、Ollama 与模型下载、前端配置等关键环节。依托清晰的操作指引和案例说明，就能在自有环境中顺利跑通 DeepSeek，为后续微调和商业化应用打下坚实基础。

**2.1.1 部署前的准备工作**

本地部署的优势在于数据全程不出内网，兼顾隐私安全；同时可以接入企业自有知识库和行业数据库做深度扩展。好消息是仅靠一张消费级显卡就能启动，长期使用下来比云服务订阅更经济。硬件需求会随模型体量变化，具体建议如下。

（1）入门配置：建议选用搭载 NVIDIA 英伟达显卡且显存不低于 8GB 的设备，足以承载 7B/8B 级别的模型。

（2）高性能配置：若要跑 14B 量级模型，建议显卡显存不低于 16GB。图 2-1 所示的 GeForce RTX 5090 D 显卡基于 NVIDIA Blackwell 架构，配备 32GB GDDR7 显存、21760 个 CUDA 核心，显存带宽高达 1792 GB/s，AI 计算能力非常强劲。

[PRE0]
图 2-1 GeForce RTX 5090 D 显卡

**知识扩展**
Blackwell 架构以数学家 David Blackwell 戴维·布莱克威尔命名，有助于提升系统的可靠性和集群间的通信效率。GDDR7 即 Graphics Double Data Rate 7，是 NVIDIA 与 DRAM 动态随机存取存储器厂商联合推出的低电压下一代显存标准。
CUDA 即 Compute Unified Device Architecture 统一计算设备架构，是 NVIDIA 提供的并行计算平台和编程模型，支持用 C/C++、Python、Fortran 等语言驱动 GPU 并行运算。

（3）无独显用户：即便没有独立显卡，也可切换到 CPU 模式运行，只是速度大约只有 GPU 模式的 20%。

内存建议不低于 16GB，处理长文本时 32GB 更流畅。存储方面预留至少 50GB 可用空间，优选 SSD 固态硬盘以加快模型加载。

DeepSeek 兼容 Windows 10/11 21H2 及以上、macOS Ventura 13.4+、Ubuntu 22.04 LTS/24.04 LTS。以 Windows 为例，部署前请确认显卡驱动已更新到最新版本，如图 2-2 所示。完成上述准备后即可正式进入部署流程。

**知识扩展**
Ollama 常用命令：
（1）serve：启动服务，使模型可响应请求。
（2）create：基于 ModelFile 创建模型。
（3）show：显示模型信息与状态。
（4）run：运行指定模型。
（5）stop：停止运行中的模型。
（6）pull：从仓库拉取模型到本地。
（7）push：将模型推送到仓库。
（8）list：列出已下载模型。
（9）ps：列出正在运行的模型。
（10）cp：复制模型。
（11）rm：删除模型。
（12）help：显示帮助。

常用参数：
（1）-h, --help：显示帮助概述。
（2）-v, --version：显示版本号。

**知识扩展**
DeepSeek-R1 的不同参数版本在性能、场景和硬件需求上各不相同，习惯上用大写 B 表示参数规模。
（1）1.5b、7b、8b：参数较少，资源占用低，适合本地轻量问答或简单助手。
（2）14b、32b：推理能力明显提升，可处理代码补全、数据分析等复杂任务，需高端 GPU。
（3）70b、671b：顶尖水准，70b 接近 GPT-4 级别，671b 面向大规模云端推理，硬件需求极大。

推荐配置：
（1）1.5b：4 核 CPU、8GB 内存，无需显卡。
（2）7b 与 8b：8 核 CPU、16GB 内存、Ryzen 7 或以上、RTX 3060 12GB 或以上。
（3）14b：i9-13900K 或以上、32GB 内存、RTX 4090 24GB 或 A5000。
（4）32b：Xeon 8 核、128GB 内存、2~4 张 A100 80GB 或以上。
（5）70b：Xeon 8 核、128GB 内存、8 张 A100/H100 80GB 或以上。
（6）671b：64 核、512GB 内存、8 张 A100/H100 80GB 或以上。
