### **2.2** **插件部署：让 DeepSeek 融入浏览器**

要让 DeepSeek 的应用场景更广、操作更便捷，部署浏览器插件是不错的方向。本节以 Page Assist 为例，介绍插件的安装、配置及功能验证。通过该插件，DeepSeek 可直接嵌入浏览器，实现更顺畅的智能辅助体验。

**2.2.1** **安装 Page Assist 插件**

Page Assist 是一款开源浏览器扩展，为本地 AI 模型提供可视化交互入口，主要特点如下。

（1）本地模型交互界面：插件可在浏览器侧边栏或 Web UI 中与本地 DeepSeek 模型对话，快速获取智能支持。

（2）多浏览器兼容：支持 Chrome、Edge、Firefox 等主流浏览器，按需选择安装。

（3）联网搜索能力：结合网络检索，可在查阅资料后生成更准确的回复。

（4）知识库构建：可快速搭建本地知识库，模型据此作答，适合专业领域场景。
