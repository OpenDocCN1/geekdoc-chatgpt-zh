Neurolab 三个最小实战

想零距离感受分类、拟合、量化在 Neurolab 里的差异？下面三段可直接运行的最小脚本覆盖了最常用的用法，代码保持不动，解读全部重写。

### 单层感知机做二分类
从 data_simple_nn.txt 读取表格，将前两个维度作为样本点，后面列作为类别指示向量。先用散点图看一眼点云分布，再统计两维各自的取值上下限，用来限定 newp 的输入区间。按标签列数确定输出单元数，搭建单层感知机。训练采用 100 次迭代，学习率 0.03，每 20 次保存一次误差。结束后绘制误差随迭代的变化，并在三组人工点 [0.4,4.3]、[4.4,0.6]、[4.7,8.1] 上做在线模拟输出。

text = np.loadtxt('data_simple_nn.txt')

### 前馈网络拟合抛物线
自行合成 130 个样本，x 在 -15 到 15 之间等距，y 按 3x²+5 生成后做 L2 归一化。把数据与目标分别塑形后先画散点。网络结构使用 newff，输入区间 [min_val,max_val]，隐藏层 10 个神经元、6 个神经元，输出 1 个。训练器换成梯度下降，最高迭代 2000 次，每 100 次打印一次误差，收敛目标设为 0.01。训练结束后在原样本上预测，绘制误差曲线，再在更密集的采样线上生成平滑曲线，与真实点和预测点一并展示。

[PRE10]
import numpy as np

import matplotlib.pyplot as plt

import neurolab as nl 
[PRE11]
# Generate some training data
min_val = -15
max_val = 15
num_points = 130
x = np.linspace(min_val, max_val, num_points)
y = 3 * np.square(x) + 5
y /= np.linalg.norm(y) 
[PRE12]
# Create data and labels
data = x.reshape(num_points, 1)
labels = y.reshape(num_points, 1) 
[PRE13]
# Plot input data
plt.figure()
plt.scatter(data, labels)
plt.xlabel('Dimension 1')
plt.ylabel('Dimension 2')
plt.title('Input data') 
[PRE14]
# Define a multilayer neural network with 2 hidden layers;
# First hidden layer consists of 10 neurons
# Second hidden layer consists of 6 neurons
# Output layer consists of 1 neuron
nn = nl.net.newff([[min_val, max_val]], [10, 6, 1]) 
[PRE15]
# Set the training algorithm to gradient descent
nn.trainf = nl.train.train_gd 
[PRE16]
# Train the neural network
error_progress = nn.train(data, labels, epochs=2000, show=100, goal=0.01) 
[PRE17]
# Run the neural network on training datapoints
output = nn.sim(data)
y_pred = output.reshape(num_points) 
[PRE18]
# Plot training error
plt.figure() 
plt.plot(error_progress)
plt.xlabel('Number of epochs')
plt.ylabel('Error')
plt.title('Training error progress') 
[PRE19]
# Plot the output
x_dense = np.linspace(min_val, max_val, num_points * 2)
y_dense_pred = nn.sim(x_dense.reshape(x_dense.size,1)).reshape(x_dense.size)
plt.figure()
plt.plot(x_dense, y_dense_pred, '-', x, y, '.', x, y_pred, 'p')
plt.title('Actual vs predicted')
plt.show() 

### LVQ 量化与决策边界
读取 data_vector_quantization.txt，取前两列为坐标，四列标签对应四类。对输入做 min-max 归一化后用 newlvq 初始化模型，代码本数量设为 10，输出通道 4 个且权重平均。训练 500 轮，不设提前停止。然后在 0~10 范围内以 0.2 为步长生成网格，送入网络得到每个网格点的类别判决。分别提取原始四类样本与对应网格区域，用黑色点标出样本，用不同符号上色网格区域，叠加展示量化边界。

[PRE20]
import numpy as np

import matplotlib.pyplot as plt

import neurolab as nl 
[PRE21]
# Load input data
text = np.loadtxt('data_vector_quantization.txt') 
[PRE22]
# Separate it into data and labels
data = text[:, 0:2]
labels = text[:, 2:] 
[PRE23]
# Define a neural network with 2 layers:
# 10 neurons in input layer and 4 neurons in output layer 
num_input_neurons = 10
num_output_neurons = 4
weights = [1/num_output_neurons] * num_output_neurons
nn = nl.net.newlvq(nl.tool.minmax(data), num_input_neurons, weights) 
[PRE24]
# Train the neural network
_ = nn.train(data, labels, epochs=500, goal=-1) 
[PRE25]
# Create the input grid
xx, yy = np.meshgrid(np.arange(0, 10, 0.2), np.arange(0, 10, 0.2))
xx.shape = xx.size, 1
yy.shape = yy.size, 1
grid_xy = np.concatenate((xx, yy), axis=1) 
[PRE26]
# Evaluate the input grid of points
grid_eval = nn.sim(grid_xy) 
[PRE27]
# Define the 4 classes
class_1 = data[labels[:,0] == 1]
class_2 = data[labels[:,1] == 1]
class_3 = data[labels[:,2] == 1]
class_4 = data[labels[:,3] == 1] 
[PRE28]
# Define X-Y grids for all the 4 classes
grid_1 = grid_xy[grid_eval[:,0] == 1]
grid_2 = grid_xy[grid_eval[:,1] == 1]
grid_3 = grid_xy[grid_eval[:,2] == 1]
grid_4 = grid_xy[grid_eval[:,3] == 1] 
[PRE29]
# Plot the outputs
plt.plot(class_1[:,0], class_1[:,1], 'ko', 
        class_2[:,0], class_2[:,1], 'ko', 
        class_3[:,0], class_3[:,1], 'ko', 
        class_4[:,0], class_4[:,1], 'ko')
plt.plot(grid_1[:,0], grid_1[:,1], 'm.',
        grid_2[:,0], grid_2[:,1], 'bx',
        grid_3[:,0], grid_3[:,1], 'c^', 
        grid_4[:,0], grid_4[:,1], 'y+')
plt.axis([0, 10, 0, 10])
plt.xlabel('Dimension 1')
plt.ylabel('Dimension 2')
plt.title('Vector quantization')
plt.show()
