# 第1章 初识DeepSeek

2025年春节期间，DeepSeek引发全民热议。这家由幻方量化于2023年7月创立的AI品牌，凭借技术突破与创新能力迅速获得全球关注。不仅在发展速度上创造纪录，也在技术路径、应用模式与产业影响层面带来启示，成为中国AI走向世界的代表力量。

媒体热议其以低成本训练实现接近OpenAI GPT-4o的性能，以及令人惊艳的“深度思考”模式，其技术原理如何？本章从大模型专业视角解读DeepSeek的技术优势与特点，并从互联网产品角度分析其带来的新机遇。

## 1.1 DeepSeek是什么？至少需记住三点

若要用最简标签概括，可以归纳为：国产AI领军者、具备思考能力的AI、技术落地的实干派。

### 1.1.1 中国AI领跑者：从本土生长出的世界级技术

在全球科技竞争中，DeepSeek作为中国代表于2023年崛起。不同于依赖海外技术的路径，其完全基于自主研发的深度学习框架，推出的DeepSeek-R1模型在数学推理与代码生成等核心能力上超越GPT-4，体现国产技术的突破。

例如询问“如何用Python实现斐波那契数列”，它不仅给出标准代码，还提醒递归效率问题；面对“小明有5个苹果，每天吃掉一半加1个，几天吃完”这类问题，其解题步骤比许多人工讲解更清晰。这种既专业又贴近实际的表现，成为国产AI弯道超车的标志。

回顾关键节点：

2023年7月，DeepSeek在杭州成立，启动AI探索。

2023年11月2日，首个开源代码大模型DeepSeekCoder发布，支持多语言代码生成、调试与数据分析。

2023年11月29日，通用大模型DeepSeekLLM发布，参数规模达670亿，包含7B与67B的Base及Chat版本。

2024年5月7日，第二代开源混合专家模型DeepSeek-V2发布，总参数2360亿，推理成本降至每百万Token1元人民币。

2024年12月26日，DeepSeek-V3发布，总参数6710亿，采用MoE架构与FP8混合精度训练，训练成本557.6万美元，在学术圈引发热议。

2025年1月底，推理模型DeepSeek-R1发布，性能与OpenAI GPT-4持平并宣布开源，迅速登上全球舆论焦点。

### 1.1.2 会思考的AI：从“黑箱”到“透明化”的转变

DeepSeek-R1的革新在于展示思考过程。不同于传统AI直接给出答案，它将“大脑活动”拆解为可读步骤，让用户既获得结果，也学会系统思考，成为具备思维教育功能的AI。

当询问“为什么全球变暖会导致极端天气增加？”时，它会展开推理：界定概念、海水蒸发加速与降雨强度提升的逻辑链、标注北极冰盖融化对洋流影响的学术争议等。

这种技术即思维链Chain-of-Thought，让AI先列出解题步骤再得出结论，提升逻辑性与可信度。

以数学题为例：“小明有一些苹果，先给了小红一半，然后自己吃了3个，最后剩下5个，问最初有多少个？”

DeepSeek会逐步推理：设初始为x，分给小红后剩余x/2，再吃3个得x/2-3=5，解得x=16。代入验证：16分一半剩8，吃3剩5，成立。逆向推算同样得到16。

如此，DeepSeek不仅提供答案，还呈现完整推理链，提升透明度与可验证性。用户可沿着步骤检验结果，也能借此学习更严谨的思维方式。

### 1.1.3 技术落地的实干派：显著降低算力要求

算力长期制约AI普及。DeepSeek通过高效架构设计与算法优化，显著降低模型对算力的需求。

采用稀疏注意力机制与MoE等技术，在处理海量数据时兼顾精度与效率，大幅减少计算资源消耗，推动AI向更广泛场景落地。
