## 10.3 线性判别分析

线性判别分析是经典的监督线性方法，既可做分类也可做降维。核心思想是把样本投到低维空间，让同类更集中、异类更分离。记样本为(x,y)，x∈R^n为特征，y∈R为标记。二分类时LDA把x投到一条直线上，多分类时则投到N-1维子空间上。

## 2. 多分类问题

### (1) 投影

设类别数N<n，LDA将样本投到N-1维子空间。取一组标准正交基w₁,…,w_{N-1}，W=[w₁,…,w_{N-1}]，则任意x的投影为

x' = Wᵀx = [w₁ᵀx,…,w_{N-1}ᵀx]ᵀ

### (2) 类内散度

数据集D=[(x₁,y₁),…,(x_m,y_m)]，x_i∈Rⁿ，y_i∈{0,1}。记X_j为第j类集合，|X_j|为样本数，u_j为均值，Σ_j为协方差阵。类内散度矩阵定义为各类别协方差之和：

S_w := Σ_{j=1}^{N} Σ_j

投影后类中心u'_j = Wᵀ u_j。投影后第j类方差为

σ_j² = Σ_{l=1}^{N-1} w_lᵀ Σ_j w_l

各类方差和为

Σ_{j=1}^{N} σ_j² = Σ_{l=1}^{N-1} w_lᵀ S_w w_l = tr(Wᵀ S_w W)

因此最小化类内方差即最小化tr(Wᵀ S_w W)。

### (3) 类间散度

全局中心u = 1/m Σ_x x。定义全局散度矩阵

S_t := Σ_{i=1}^{m} (x_i - u)(x_i - u)ᵀ

类间散度为

S_b := S_t - S_w = Σ_{j=1}^{N} |X_j| (u_j - u)(u_j - u)ᵀ

投影后类间度量采用

Σ_{l=1}^{N-1} w_lᵀ S_b w_l = tr(Wᵀ S_b W)

最大化类间“距离”即最大化tr(Wᵀ S_b W)。

### (4) LDA 模型（多分类）

目标函数为

arg max_W J(W) := tr(Wᵀ S_b W) / tr(Wᵀ S_w W)

令tr(Wᵀ S_w W)=1，转化为约束优化

min_W -tr(Wᵀ S_b W) s.t. tr(Wᵀ S_w W)=1

用拉格朗日乘子法可得

S_b W = λ S_w W

其中λ为S_w⁻¹ S_b的前N-1个最大特征值，W为对应特征向量矩阵。亦可把目标写成主对角线乘积形式，回归到广义Rayleigh商，从而取S_w⁻¹ S_b的前N-1个最大特征值及对应特征向量按行排列成W。
