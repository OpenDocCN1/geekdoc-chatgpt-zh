# 样本不平衡怎么破

模型表现只能跟训练数据一样好。现实中数据质量是常见痛点，为了让分类器工作良好，各类样本最好均衡。但实际采集时很难保证数量完全相等。若某类样本是另一类的十倍，模型就会偏向多数类。因此必须考虑不平衡的处理方式，下面演示具体做法。
