| TransG$^{[499]}$ | $\sum_{m=1}^{M_r} \pi_{r,m} e^{-\frac{\|u_h + u_{r,m} - u_t\|_2^2}{\sigma_h^2 + \sigma_t^2}}$ | $2 d_e n_e$ |

| KG2E$^{[203]}$ | $\frac12\{\mu^T \Sigma^{-1} \mu + \log \det \Sigma\}$, $\Sigma = \Sigma_h + \Sigma_t + \Sigma_r$ | $2 d_e n_e + 2 d_r n_r$ |

| SparseTrans$^{[229]}$ | $\|h M(\theta_r^h)_r^h + r - t M(\theta_r^t)_r^t\|$ | $d_e n_e + 2 + 2(1 - \theta)(d_r + 1)n_r n_e$ |

与张量分解相比，自定能量函数这一派更具弹性。能量形式的定义可以随具体的推理任务而调整，使优化目标更贴合真实任务需求，所以在实践中往往能取得更好的效果。实质上，这类方法更像是矩阵分解的延续，很多实现都会先用矩阵分解的结果来初始化。

目前以数值计算为核心的推理正在学界持续升温，新模型层出不穷。想跟踪进展，可以用 “Knowledge Graph Embedding”“Knowledge Embedding” 这类关键词检索最新论文。

## 9.5 符号与数值协同推理
获得知识图谱的分布式表示后，便能借助数值手段在图上展开推理。这种策略有两个明显优点：第一，推理本身极快，且耗时几乎不受图规模影响，规模主要影响学习阶段，速度常比逻辑或概率推理快数个数量级；第二，能在一定程度上缓解稀疏带来的冷启动问题。图谱中长尾实体大量存在，传统推理常因证据不足而失效，而表示学习通过迭代为这些实体注入隐式语义，使稀疏问题有所改善。对应的短板是精度不够，表示学习可以把正确答案推到靠前，但很难稳定排在第一，关键在于它无法利用图谱中显式的长程依赖，例如逻辑规则，而这类信息对推理很有帮助。

为兼收并蓄，研究者开始把表示学习和逻辑推理融合。Rocktäschel[406] 用实体与关系的向量估计元组概率，再以 t-norm 理论推算规则成立概率；Wang[474] 以整数线性规划把分布式表示与手工规则整合，但规则普适性仍存疑；Neelakantan[354] 用循环神经网络对关系路径的向量做循环编码，思路类似 PTransE[290]，后者在遍历路径时还引入了类似 PRA 的启发式策略；Gu[188] 等人则把逻辑规则本身向量化，用于判断两个实体间是否具备可迁移的规则模式。

以下以 PTransE 和 Gu 的思路说明如何把图谱元素的分布表示用于关系路径或规则体的分布式建模。这类工作把原子关系扩展到关系序列，认为一个关系序列的向量可以用来预测两实体间是否存在该序列构成的路径，这正是马尔可夫逻辑网等概率模型在规则实例化时的目标，所以融合是可行的。把逻辑规则写成 前提 ⇒ 结论，按 Horn 子句定义，规则体就是图上的一条路径。如公式 9.14，TransE 把关系视作实体空间的平移，假设 $E_h + E_r \approx E_t$。若把长度为 1 的路径 $r$ 推广到任意长度，则当路径 $p(h,t)$ 存在时有

$E_h + E_p = E_t$  (9.15)

在 TransE 假设下考察路径内部关系。以 $h \xrightarrow{r_1} x \xrightarrow{r_2} t$ 为例，可得 $E_h + E_{r_1} = E_x$ 且 $E_x + E_{r_2} = E_t$。把第二个式子改写为 $E_x = E_t - E_{r_2}$ 代回第一个式子消去中间变量，得到 $E_h + E_{r_1} + E_{r_2} = E_t$。与 9.15 对比可知 $E_p = E_{r_1} + E_{r_2}$，更一般地

$E_p = \sum_{r_i \in p} E_{r_i}$  (9.16)

由此可得进一步结论。对三元组 $r(h,t)$ 有 $E_h + E_r = E_t$，若 $h$ 与 $t$ 间存在路径 $P$ 且 $E_h + E_p = E_t$，则 $E_r \approx E_p$，即当两实体间存在路径时，该路径的向量表示应接近三元组关系的向量表示。

### 9.6 常识推理研究
常识在人工智能与自然语言处理中至今缺乏统一定义，通常认为常识是普通大众心智健全成年人应具备的基础知识，覆盖生存技能、基本劳作、基础自然科学与人文社会知识等。如鸟会飞、鱼会游、兔子多为四条腿、白兔眼睛常为红色。常识本身简单，但其来源、传播方式、置信度评估以及计算机表示仍是难题。因此对常识知识进行推理是重要前沿议题。例如，“一棵树把太阳能储存到果实中，这一过程是物理反应还是化学反应？”需要借助光合作用把太阳能转化为化学能、化学能参与的转化即为化学反应的常识。常识推理的形式取决于常识的表示方式。

ConceptNet^[441] 是知名常识库，以三元组形式存储常识并给出自然语言表达。如

- （兔子，痛恨，狼）
- （兔子，惧怕，狮）
- （兔子，惧怕，猎人）
- （兔子，惧怕，老虎）
- （兔子，喜欢，胡萝卜）
- （老虎，有，牙齿）
- （老虎，在，山洞）
- （老虎，惧怕，恐龙）
- （老虎，喜欢，抢地盘）
- （老虎，是一种，保育类动物）
- （老虎，痛恨，猎枪）
- （老虎，喜欢，肉）

三元组结构使 ConceptNet 可直接沿用三元组事实图谱的推理方法。例如可归纳出“兔子惧怕老虎，老虎喜欢吃肉，因此老虎会吃兔子”。

另一个著名库是 Cyc^[270]^，致力于集成各领域本体与常识并实现推理。Cyc 包含超过 630000 个概念、38000 种关系类型、超过 700 万条常识断言。Cyc 使用 CycL 语言表示，以一阶逻辑为基础并包含部分高阶逻辑，类似 Lisp。概念以 “#$” 开头，如 #$MapleTree、#$massOfObject，变量以 “?” 开头，如 ?OBJ。谓词如 #$isa、#$likesAsFriend、#$GovernmentOf。常识以括号形式书写，谓词在前，例如：

(#$isa #$EMRG #$Color)    EMRG 是一种颜色
(#$genls #$Tree-ThePlant #$Plant)    所有的树都是植物
(#$isa #$Obama #$USPresident)    奥巴马是美国总统

为支持推理，Cyc 定义了逻辑符号 #$not、#$and、#$or、#$implies，可构成一般命题，如

## 第十章 知识问答与对话系统
近年知识图谱在规模与领域上快速扩张，且大量高质量结构化数据可免费获取。这些数据在商品推荐、商业智能、决策支持等场景发挥重要作用。作为描述自然与社会知识的重要载体，知识图谱最直接的任务是满足用户精确信息需求，提供个性化服务。问答与对话系统是最典型的应用之一。例如

- （1）屠呦呦是哪里人？
- （2）华为公司创始人毕业于哪所大学？
- （3）被称为“六朝古都”的是中国哪座城市？
- （4）今天晚上有哪些从北京到上海的国航航班？

若无知识图谱，可借助搜索引擎等获得信息，如图 10.1 所示，搜索引擎对“哪些诺贝尔奖获得者的子女也得了该奖”的返回结果仅是相关网页集合，用户需自行阅读分析。本章聚焦面向知识图谱的问答与对话技术。系统可接受自然语言问题，经问句分析、知识抽取、知识推理等步骤得到精确答案，如上述四个问题可分别得到“宁波市”“重庆大学”“江苏省省会南京市”“CA1858”。目前多数系统仅能处理事实型问题，对“为什么天空是蓝色？”“如何制作宫保鸡丁？”“若殖民火星，哪些行业会最先发达？”等复杂问题仍难以应对。本章主要关注可回答事实型问题的相关技术，先简述自动问答发展历史与类型，再分别介绍面向知识图谱的实现。

### 10.1 自动问答发展概览
自动问答可追溯至上世纪五六十年代，代表系统有 Baseball[180] 与 Lunar[490]。Baseball 最早提出未来人机交互将以自然语言进行的目标；Lunar 为方便阿波罗计划月球岩石与土壤数据的查询、比较和分析而开发。这些系统多面向特定领域，数据规模有限，仅接受限定表达形式的自然语言问题，对自然语言处理依赖不大，性能与定制程度相关。因缺乏足够知识资源，它们难以在真实环境中推广。
