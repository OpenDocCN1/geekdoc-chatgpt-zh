智能体之所以能够读懂前后文、把握指代，根源在于它在对话窗口里学会了动态重建语义联系。Transformer 里的自注意力机制就是这套能力的执行器，它能在当前输入范围内实时筛选关键信息，并把各个输入单元关联起来。通过 Query、Key、Value 的映射，每个 token 都被赋予不同的关注度，相关性高的信息自然被放大。

自注意力是实现语境学习的工程核心，背后是一套清晰的数值流程。每个 token 先被转成可学习的 Q、K、V 三个向量。随后当前 token 的 Query 与序列里全部 token 的 Key 做点乘，得到原始得分；再通过 Softmax 归一化为注意力权重，用以衡量彼此的相关性。最后按权重对所有 Value 做加权求和，得到融合语境的表征。

举例来说，句子“AI理解机器学习，它很强大”。当模型处理到“它”时，会生成对应的 Query，并与句中“机器学习”等词的 Key 分别计算点积。因为“它”与“机器学习”语义贴合，得分相对突出，经过 Softmax 后“机器学习”这一位置会获得更高权重。于是模型把“它”与“机器学习”绑定，在“它”的表征里注入相关语义，从而做出连贯理解。

向量运算配合动态权重分配，让 Transformer 具备较强的语境语义建模力，而该能力建立在自注意力所支持的全局 token 交互之上。

### 2.2.2 上下文学习示例
在 NLP 实践里，语境学习不仅让人机对话更顺滑，还提供了一种新的任务适应范式。传统模型往往要靠海量标注数据再做任务微调，而具备语境学习能力的大模型可以借助预训练时期学到的语言知识，直接在推理阶段完成新任务，大幅降低对标注和定制的依赖，形成更灵活高效的处理方式。语境学习正是大模型实现少样本学习的重要路径，具备很强的技术价值和应用潜力。

#### （1）少样本学习
在应用中，零样本提示是常见用法。用户直接下指令，比如“把这段文字翻成英文”或“总结文章核心观点”，模型便依托通用语言知识作答，适合任务明确、结构清晰的场景。

但遇到专业领域或复杂任务时，零样本往往抓不住业务规则、行业术语和细微语义。这时少样本学习优势明显，只需给出 3~5 个典型示范，模型就能从中提炼模式，快速掌握逻辑，效果通常优于零样本。

以商品评论情感分类为例，零样本下模型容易把“手机拍照效果很好，但电池续航太差”误判为正面，因为转折和权衡没有被很好建模。

下面是一个典型的少样本用法。

> 根据以下示例判断商品评论是好评还是差评。
> 示例 1：
> 评论：“性能强劲但发热严重”
> 分类：差评
> 示例 2：
> 评论：“外观精美，系统流畅，性价比高”
> 分类：好评
> 请判断以下新评论的分类。
> 评论：“手机拍照效果很好，但电池续航太差”

在这种设定下，模型借助少量示例无需额外训练，就能推断出任务规则，更合理地判断新评论中负面因素占优，从而倾向差评。这种凭极少示例快速适应的特性，就是少样本学习的精髓。

#### （2）指令设计中的就近原则
受位置编码、训练数据分布和自回归生成等影响，模型在实际使用中对输入末尾的指令或信息更敏感，部分注意力头会给末尾位置更高权重，导致输出更容易受结尾内容牵引。

因此在写 Prompt 时，可以把关键要求放到文本末尾，增强关注度，提升相关性和指令遵循度。

比如诗歌创作指令“写一首关于春天的诗，要押韵，最后一行提问”，由于“最后一行提问”在末尾且表述具体，模型更可能满足；而“押韵”这种全局抽象要求即使在中间，也容易被弱化。

以量子计算解释为例，不同写法效果差异明显。

输入的分散指令如下。

> 请用幽默的语气解释量子计算，字数100以内，并举例说明。

我们得到的回答如下。

> 量子计算就像薛定谔的猫在玩俄罗斯轮盘赌——你的数据既是1又是0，直到你偷看时它才“喵”地随机坍缩成一种状态。比如传统计算机像老实的会计，一次算一笔账；量子计算机则是魔术师，能同时让所有账本在虚空中跳踢踏舞，瞬间找到答案（当然，也可能变出一群鸽子糊你脸上）。

按就近原则优化后，指令改为分点。

1. 用幽默的语气解释量子计算；
2. 限制100字以内；
3. 结尾添加一个例子（如“就像猫同时存在于箱子里面和外面”）。

我们得到的回答如下。

> 量子计算就像薛定谔的算盘：比特可以同时是0和1（叠加态），直到你偷看时它才“决定”变谁。比传统计算机“一枚硬币抛一次”快多了，它能一次抛完所有平行宇宙的硬币！不过别高兴太早——它目前比幼儿园手工还容易出错。就像你的减肥计划，既“正在进行”又“已经失败”。

两者差异印证了就近原则的重要性。线性表述没有区分优先级，末尾的“举例说明”更易被执行，前置的幽默和字数限制则可能被忽视，而且示例形式缺乏引导。

分点写法把“结尾添加例子”单独放在最后，使其更易被优先满足，同时结构更清晰，信息不易混淆，相关性和完整性都提升了。

这些例子说明，掌握位置编码、自回归特性、少样本学习和就近原则等关键因素，就能更好地引导模型理解需求，提升输出相关性和可控性，实现交互效率与质量的双提升。

## 2.3 模糊需求澄清策略
在自然语言交互中，本质是用户意图的传递与模型的解析。指令的清晰度和结构性直接决定输出的准确度。当指令模糊或要素缺失时，模型难以准确把握意图，往往给出范围过宽、针对性不足的答案，降低交互效率。

要获得高质量输出，需要建立系统化的指令优化方法，把模糊需求转化为要素完整、结构清晰的指令。这一过程可从需求澄清和角色设定两方面入手：前者通过细化目标、场景和约束，把抽象需求变成可操作的说明；后者通过为模型设定角色，引导其调用领域知识和表达风格。两者配合，能显著提升理解准确度和输出相关性。

下面用具体例子展示模糊指令如何优化。

### 2.3.2 角色设定
角色设定是提升输出质量的重要手段。操作上可双向进行：一是把模型设为专家、从业者等角色，驱动其调用专业知识；二是明确用户身份属性，让模型从用户视角理解需求。两种方式都能构建语境框架，帮助模型更精准地把握方向。

#### 1. 设定模型角色
给模型设定角色，本质是通过语境框架引导其定向调用预训练知识，从检索式输出转向策略式输出。核心价值有三点。

- **精准聚焦**：划定知识检索边界，减少冗余。
- **策略输出**：遵循行业逻辑给出解决方案，提升指导性。
- **个性适配**：模拟真实场景输出定制化内容，更贴合实际。
