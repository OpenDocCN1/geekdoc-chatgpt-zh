**进阶玩法：直接改文件**

如果你更偏好命令行，或服务器没有图形界面，手改配置文件往往更高效。按自己习惯选择编辑器即可：

# 用 nano 编辑器
nano ~/.openclaw/workspace/SOUL.md

# 用 vim 编辑器
vim ~/.openclaw/workspace/SOUL.md

# 用 VS Code
code ~/.openclaw/workspace/SOUL.md

USER.md 的修改方式相同，只需把文件名换成 USER.md。想先确认工作区里有哪些配置，可执行：

# 查看所有配置文件
ls -la ~/.openclaw/workspace/

执行后除了 SOUL.md 和 USER.md，还会看到若干其他配置文件。暂时不用管，后续章节会逐一介绍。

**小提醒**

**调试心法：一次只改一处**

初期摸索时，建议每次仅调整一个点，随后立刻对话测试。若一次性改动太多，效果不理想时根本无从定位。慢就是快，这个原则在“养虾”上同样适用。

如果 AI 不够专业，在 SOUL.md 加：

**SOUL.md 与 USER.md 的协作关系**

很多人会问两份文件冲突怎么办。OpenClaw 的处理逻辑是：SOUL.md 的核心原则不会改变；USER.md 在不违反原则的前提下补充个人偏好；AI 会根据具体情况动态平衡。

例如 SOUL.md 说“简洁回复”，USER.md 说“详细解释”，结果是 AI 会简洁回复，但必要时提供详细解释的选项。两者是互补，不是互斥。这也是“养虾”最有趣的地方，经过反复调试，你的龙虾会逐渐长出只属于你的性格轮廓。

**第三步：命令行向导完成接入**

方式一：交给 OpenClaw 自动配置（推荐新手）

# 把下面这段话填好你的 AppID 和 AppSecret 复制给 OpenClaw
帮我把 openclaw 接入飞书，教程：通过 openclaw plugins install @openclaw/feishu 来安装插件；openclaw config set channels.feishu.enabled true 来启用飞书通道；通过 openclaw config set channels.feishu.connectionMode websocket 设置连接模式为 websocket;openclaw config set channels.feishu.appId“你的 AppId”来配置 appid；openclaw config set channels.feishu.appSecret “你的 AppSecret”来配置 appsecret。中途遇到问题可以跟我说，配置完就 openclaw gateway restart

之后按指令一步步做，基本上 OpenClaw 自己就帮你配好了。

方式二：交互式向导
终端执行：
# 在终端输入
openclaw channels add
按提示依次执行：选“Feishu/Lark（飞书）”渠道 → 输入 App ID → 输入 App Secret → 配置私聊策略（默认配对模式）→ 配置群组策略（默认白名单）。

别漏掉最后一步：向导会再次回到“Select a channel”界面，这时不要再选，直接点击“Finished”结束。很多人这里愣住，以为没配完又重选，其实已配好。

完成后向导会自动重启 Gateway，终端会出现“Channels updated”提示，表示已就绪。

方式三：命令行直配（熟手适用）
# 在终端输入
openclaw config set channels.feishu.appId "cli_ 你的 AppID"
openclaw config set channels.feishu.appSecret "你的 AppSecret"
openclaw config set channels.feishu.enabled true
openclaw config set channels.feishu.connectionMode websocket
openclaw config set channels.feishu.dmPolicy pairing
openclaw gateway restart
