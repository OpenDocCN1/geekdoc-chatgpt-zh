然而，生搬硬套标准牛顿法会撞上两堵“拦路墙”：

- **收敛性无保障**：参数序列 $\{w^k\}$ 不一定能逼近最优解，目标函数值（式 5-7）也可能震荡上升，而非单调下降。
- **稠密 Hessian 存储爆炸**：虽说特征矩阵 $X \in \mathbb{R}^{l \times n}$ 很稀疏，但 Hessian 里的 $X^T D X \in \mathbb{R}^{n \times n}$ 却是妥妥的大规模稠密矩阵（实战中 $n$ 起步十万级）。常规牛顿法既要存这矩阵又要求逆，工程落地几乎不可行。

### 算法 5-2 共轭梯度解置信域子问题

- 0: 给定 $\xi_k < 1, \Delta_k > 0$，置 $s^0 = 0, r^0 = -\nabla f(w^k), d^0 = r^0$
- 1: for $i = 0, 1, \dots$ (内层迭代)
- 2: 若 $\| r^i \| = \| \nabla f(w^k) + \nabla^2 f(w^k) s^i \| \leqslant \xi_k \| \nabla f(w^k) \|$
   输出 $s^k = s^i$，停止
- 3: $\alpha_i = \| r^i \|^2 / ( (d^i)^T \nabla^2 f(w^k) d^i )$
- 4: $s^{i+1} = s^i + \alpha_i d^i$
- 5: 若 $\| s^{i+1} \| \geqslant \Delta_k$，求 $\tau$ 使 $\| s^i + \tau d^i \| = \Delta_k$
   输出 $s^k = s^i + \tau d^i$，停止
- 6: $r^{i+1} = r^i - \alpha_i \nabla f(w^k) d^i$
- 7: $\beta_i = \| r^{i+1} \|^2 / \| r^i \|^2$
- 8: $d^{i+1} = r^{i+1} + \beta_i d^i$

工程落地可直接用多核版或 Spark 版 **LibLinear**，轻松支撑百万级样本与特征。

### 5.2.2 FM：特征交叉维度的 LR 进化论

FM 可视作 LR 在特征交叉方向的进阶形态。本节先夯实 FM 基础，再引出其升级版 FFM [5]。

#### (1) FM 基石：稀疏大规模场景的“破局者”

FM 是推荐领域的“六边形战士”，排序、召回皆宜，衍生算法众多。先看二阶 FM 核心公式：

[PRE6]

$w_0$ 为全局偏置，$w_i$ 为特征 $x_i$ 权重；二阶交叉权重 $w_{ij}$ 由隐向量 $v_i, v_j$ 内积代理。关键点：**不直接学 $w_{ij}$，而是学 $v_i, v_j$**。矩阵视角下，等价于正定矩阵分解 $W = VV^T$。分解维度越高，捕捉复杂关联的能力越强。

FM 通过分解建模变量关联，天然适配高维稀疏。比如 “ESPN” 与 “Adidas” 共现仅 1 次，直接学 $w_{ESPN, Adidas}$ 置信度极低。但 FM 通过间接学习：Nike 与 Adidas 在 Vogue、NBC 上交互模式相似 $\rightarrow$ 二者隐向量靠近 $\rightarrow$ 推导出 $w_{ESPN, Adidas} \approx w_{ESPN, Nike}$。这比单靠噪声样本训练出的权重可靠得多。

此外，分解大幅压缩参数量：直接学 $w_{ij}$ 需 $n^2$ 参数，分解后二次项仅 $kn$（$k \ll n$）。

按式（5-18）直接算，复杂度 $O(n^2)$，大规模场景寸步难行。FM 二阶项巧妙改写：

[PRE7]

推导逻辑三步走：
1. 求和起始位置从 $i+1$ 挪到 $1$，引入冗余项 $\langle v_i, v_i \rangle x_i^2$，随后减去修正。
2. 向量内积展开为 $k$ 维累加。
3. 将 $k$ 维循环提至最外层（类似 $\sum_i \sum_j a_i b_j = (\sum_i a_i)(\sum_j b_j)$）。
4. 合并同类项。

#### (2) FFM 算法：引入“域”的精细化建模

FFM 由 Yu-Chin Juan 等提出，在 Criteo、Avazu、Outbrain、RecSys 2015 等多个 CTR 竞赛中屡获 Top 3。它在 FM 基础上引入 **Field（域）** 概念：特征交叉时，根据对方所属域选择对应隐向量。定义如下：

[PRE10]

$f_j$ 为第 $j$ 特征所属域。若共 $f$ 个域，每特征隐向量参数量 $f \cdot k$，是 FM 的 $f$ 倍。FM 与 FFM 结构对比：

[PRE11]

**图5-5 FFM 与 FM 结构对比**

FM 中，特征 $i$ 与所有特征交互共用一个 $v_i$，即在单一隐空间建模关联，难以区分不同交叉的差异。FFM 划分域、按域分配隐向量，建模粒度更细，有效抑制低相关域间的干扰，更精准刻画各域分布。其核心思想源自个性化标签推荐的 **PITF** [7]（用户/物品/标签三维独立分解），FFM 做了通用化扩展，并补全理论分析与工程优化。

FFM 效果提升符合预期，但副作用明显：参数激增导致存储压力大、收敛变慢。官方开源 C++ 实现（去掉常数项与一阶项）：

$$\hat{y}(v, x) := \sum_{i=1}^{n-1} \sum_{j=i+1}^n \langle v_{i_{f_j}}, v_{j_{f_i}} \rangle x_i x_j \quad (5-22)$$

损失函数含 $L_2$ 正则与 LogLoss：

$$L = \frac{\lambda}{2} \| v \|_2^2 + \sum_{i=1}^m \log(1 + \exp(-y \cdot \hat{y}(v, x))) \quad (5-23)$$

参数梯度：

$$g_{i_{f_j}} = \lambda \cdot v_{i_{f_j}} + \frac{\partial L_{err}}{\partial \hat{y}} \cdot v_{j_{f_i}} \cdot x_i x_j \quad (5-24)$$
$$\frac{\partial L_{err}}{\partial \hat{y}} = \frac{-y}{1 + \exp(\hat{y})}$$

得梯度后，采用 **Adagrad** [8] 自适应更新：

$$(G_{i_{f_j}})_d = (G_{i_{f_j}})_d + (g_{i_{f_j}})_d^2 \quad (5-25)$$
$$(v_{i_{f_j}})_d = (v_{i_{f_j}})_d - \frac{\eta}{\sqrt{(G_{i_{f_j}})_d}} (g_{i_{f_j}})_d \quad (5-26)$$

$\eta$ 为初始学习率（建议 $[0, 1/\sqrt{k}]$）；梯度累计 $G$ 初始化为 1 避免数值溢出。Adagrad 让参数自适应演进：初期大步快跑，后期收敛细调；低频特征虽更新少，但积累的梯度平方小，分母小、步长大，依然能充分学习，**极度契合大规模稀疏场景**。实测 Adagrad 收敛显著快于普通 SGD。FFM 完整训练流程：
