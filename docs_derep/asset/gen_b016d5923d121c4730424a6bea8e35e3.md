打开终端。Windows 用户按 Win+R 输入 cmd 或 powershell，macOS 用户用 Command+空格打开 Spotlight 搜索“终端”。

`ollama run DeepSeek - r1:1.5b`（备注：该精简模型对普通 PC 较友好，但能力有限，也可选用其他命令）。

其中 1.5b 代表模型规模，可按自身硬件挑选合适的版本。
下载完成后终端会显示“Send - A - message”，表示模型已加载成功。

### 三、测试 DeepSeek

## 第六节 DeepSeek V3 与 R1 用户视角对比
下面从使用角度对比 DeepSeek-V3 与 DeepSeek-R1，方便根据需求挑选。

| 对比维度 | DeepSeek - V3 | DeepSeek - R1 |
| :--- | :--- | :--- |
| 模型定位 | 通用型自然语言处理，覆盖客服、翻译、内容生成等场景 | 专注复杂逻辑推理（数学证明、代码生成、决策分析） |
| 架构 | 混合专家（MoE）架构，总参数 6710 亿，单 token 激活 370 亿参数 | 基于 V3 架构改进，引入动态门控机制，强化学习优化推理 |
| 训练方法 | 预训练 + 监督微调（SFT），FP8 混合精度训练，总成本 557.6 万美元 | 强化学习（RL）为主，结合冷启动数据，无须监督微调 |
| 推理能力 | 高效处理多模态任务，长文本生成（128K 上下文） | 支持思维链（Chain - of - Thought）输出，数学问题准确率 97.3%（MATH - 500 测试） |
| 响应速度 | 实时响应（MoE 架构优化计算效率） | 需先进行思维链推理（约 5 分钟），响应较慢 |
| 应用场景 | 企业级客服、多语言翻译、高吞吐代码补全 | 科研、金融量化、复杂决策支持 |
| API 成本 | 输入 $ 0.14/ 百万 tokens，输出 $ 2.19/ 百万 tokens | 输出成本为 OpenAI O1 的 1/50（约 $ 2.19/ 百万 tokens） |
| 开源生态 | 开放模型权重，适配 AMD GPU/ 华为昇腾 NPU | MIT 协议开源，提供蒸馏版本（如 14B/70B 参数） |
| 典型性能对比 | MMLU（综合性能表现）知识理解准确率 85.6%，HumanEval 代码通过率 65.2% | MATH - 500 数学测试准确率 97.3%，AIME 数学竞赛通过率 79.8% |

总体来看，V3 更适合处理多模态内容、长文档或多语言场景，如内容创作、智能客服或企业复杂文档处理。R1 更擅长数学、代码生成与复杂逻辑推理，适合程序员、科研人员或需要深度决策支持的团队。划分并非绝对，可结合偏好自行选用。
需要快速简短答案时，默认使用 V3 即可；需要结构化、深思熟虑的输出时再开启深度思考 R1。任务知识在 2023 年 12 月之前时无需联网搜索，大模型自带训练语料即可；涉及 2023 年 12 月以后内容时，开启联网搜索更可靠，否则回答可能缺失时效信息。

## 第七节 DeepSeek-R1 与 GPT-4o 提示词设计差异
GPT-4o、DeepSeek-V3 等属于指令模型，专为遵循指令生成内容而设计。DeepSeek-R1 属于推理模型，聚焦逻辑推理与问题求解，能自主完成多步分析、因果推断与复杂决策。提示词可通用，但设计思路仍有差别，读者务必注意。归根结底，R1 只是神经网络，不可盲目迷信其输出。

| 对比维度 | DeepSeek - R1 | GPT - 4o |
| :--- | :--- | :--- |
| 核心目标 | 复杂推理任务，如数学推导、代码生成、逻辑分析等，强调多步骤思考 | 多模态通用任务，涵盖文本、图像、音频等多种模态，强调快速响应和跨模态生成 |
| 提示词设计原则 | 简洁明确，聚焦核心目标，避免分步引导，信任模型推理能力 | 清晰明确，启发式引导，适应性调整，强调用户反馈和情景模拟 |

## 第八节 使用 DeepSeek 的风险提醒
使用 DeepSeek 涉及数据隐私、知识产权、内容生成、跨境合规等多方面法律风险。

第一，数据隐私与安全。DeepSeek 在数据收集、存储及使用环节可能存在合规挑战。韩国对 DeepSeek 的调查即指出其在数据收集合法性、使用透明度、跨境传输合规性及安全措施充分性等方面存在疑问。若未经用户明示同意收集数据或将数据用于未授权用途，可能违反法规，面临高额罚款及集体诉讼。数据泄露还可能导致隐私与商业机密外泄。因此上传文档前务必做好隐私保护。特别注意 DeepSeek 隐私政策①，其中说明会收集用户交互输入内容，包括文本、图片、文件，并收集用户对输出的反馈以优化模型。若不希望输入成为他人可获取的答案，需格外留心。

> ① 参见 https://cdn.DeepSeek.com/policies/zh-CN/DeepSeek-privacy-policy.html。

第二，知识产权风险。DeepSeek 代码与模型分别采用 MIT 许可与自建许可 OpenRAIL 类协议，使用时需遵守声明义务与责任限制，否则可能构成侵权。模型生成内容也可能涉及对他人受版权保护文本或代码的无授权使用。

第三，内容生成风险。生成文本可能包含虚假信息、误导或偏见，违反法规或产生社会负面影响。DeepSeek-R1 在红队测试中显示有害内容生成率偏高，包括恶意语言、偏见输出与不安全代码，存在伦理与合规风险。使用其生成法律文书或案例分析时需核验准确性与合法性，避免因错误信息承担法律责任。

第四，跨境合规风险。全球化应用伴随跨境数据流动，欧盟 GDPR、美国 CCPA 等对数据跨境传输有严格要求。部分国家如澳大利亚、韩国、意大利以国家安全或数据安全为由限制或禁用 DeepSeek，可能影响全球使用。

第五，法律实务风险。律师等从业者若直接将 AI 生成内容作为法律意见或文书使用，可能违反执业规范与责任要求。应独立验证、批判性分析，而非视为权威。此外模型知识库更新滞后，可能导致输出不符合最新法规。

总之，使用前需全面评估隐私、知识产权、内容与跨境合规风险。确保数据使用符合当地法律法规，遵守开源许可，对生成内容严格审核，注意跨境传输合规。法律从业者更应审慎对待 AI 输出，确保符合实务要求。
