# 智慧养老全链路解析 从感知到情感陪伴

社区智慧养老服务系统通常由环境感知层、智慧服务平台层和终端交互层三部分构成。感知层负责把家里的信息捕捉上来，依赖各类传感设备实现全方位感知和较高灵敏度。传感器接入无线传输网络后，采集数据会向上层推送。智慧服务平台层是系统的核心大脑，为用户提供具体服务功能。搭建这样一套系统需要融合物联网、通信技术、数据挖掘以及卫生医疗护理的专业知识，把这些技术整合成服务体系，为长者提供便捷且有价值的生活支持。

在数据传输上，Zigbee 协议常被用来组建无线局域网。相较 WiFi、蓝牙，Zigbee 方案更简洁、成本更低、功耗也更省，在智能建筑、智能家居、智能医疗等场景应用广泛。基于 Zigbee 的自组织网络可形成传感网，统一管理所有传感器。通过代码可完成传感器的初始化、信息采集和远程控制等工作。家庭控制中心充当服务器与 Zigbee 之间的桥梁，负责数据的传输与处理。接收到 Zigbee 传感器上传的数据后，控制中心会先处理再分发到网络或手机终端；终端发出的指令也会被处理后再转发给对应的 Zigbee 节点。终端端可以对家中温湿度、燃气水电、家电等进行设置。终端到云服务器的通信常用 AJAX 技术，以 JSON 格式调用接口，以求降低延迟、提升体验。基于 Zigbee 技术的家庭网络结构如图 7-5 所示。

### 7.3.2 居家老人行为感知与识别
在智能家居里，人类活动识别是支撑生活辅助、运动损伤监测和老年护理的持续行为监测框架，也是研究行为模式和人机交互的重要方向。健康智能家居常见的日常生活行为包括睡觉、准备与享用早餐、穿衣脱衣、休息、卫生活动、排便、交流等 7 类。识别这些行为主要依赖位置传感器、门磁、浴室温湿度传感器、麦克风的声纹分类与语音识别，以及可穿戴运动传感器。人类活动具备高度复杂性和不确定性，有研究建议用深度学习来训练更优的识别器。深度学习与人工智能擅长图像识别、特征提取与分类等自主学习任务，与移动和可穿戴设备结合后发展空间更大，例如用智能手机传感器配合深度卷积神经网络进行活动识别，通过深度学习建立传感器数据与个人健康之间的关联。传感器的另一端是远程监控系统，老年人常需即时医疗干预，远程平台可在独立居家条件下提供医疗照护，如电子处方、电子供应、电子病历和电子健康档案等。此外，智能家居中引入辅助机器人也将成为解决养老难题的一种路径。

#### 7.3.2.1 传统行为识别技术路线
### 1）数字设备驱动的活动识别
## 运动传感识别
日常使用中，用户通过佩戴运动手表、手环等传感器记录身体运动。多数基于运动传感的方法要求传感器贴合在运动的身体部位，例如分析腿部健身训练时传感器需佩戴在腿上。这类方法的限制明显：一是用户必须全天携带设备，穿戴不便并影响体验；二是识别范围狭窄，腿部加速度计无法感知手臂动作。

## 视频图像识别
另一种传统做法是借助视频图像的计算机视觉技术感知活动。视觉是重要信息来源，基于视频的识别通过分析图像提取人体运动信息。但实际场景中受视角、光照、背景等干扰，分析难度较大。同时摄像头存在隐私侵犯风险。

## 无线射频感知
随着无线网络发展，射频信号从单一通信介质扩展为非侵入式环境传感手段，常见有超声波、WiFi、专用射频信号等。利用无线信号识别人体行为可免除穿戴限制，前景广阔。其原理是射频信号在无线介质中多路径传播，遇到物体反射后到达接收端，从而携带环境信息。人体是良好的反射体，分析接收信号的模式与特征可检测呼吸率、手势、跌倒等行为，这被称作非接触式或无设备感知。

### 专用射频设备感知
不少系统采用 FMCW 无线电，其配备水平与垂直两个天线阵列。Marko 系统即可在不写日记、不佩戴传感器的前提下自动采集与行为相关的数据。它发射低功率无线信号并分析环境反射，再将反射映射到用户与环境的交互关系中。

### 基于 WiFi 的识别
基于 WiFi 的识别多依赖 CSI 工具，研究人员可从无线数据包中提取物理层 CSI，无需部署特殊硬件，但需让 WiFi 设备以高速率持续发包，即便无数据通信也在进行。CARM 系统是典型代表，其建立在两个理论基础上：CSI 速度模型，用来量化 CSI 动态与人体运动速度的相关性；CSI 活动模型，用来量化不同身体部位运动速度与特定活动的关联。速度模型的核心在于多径长度改变时，CFR 功率会随路径长度变化。

目前最具前景的做法是用改造后的商用 WiFi 路由获取信道状态信息进行运动识别，但改变发包速率会干扰通信，且室外可用性大幅下降。多用户同时运动时，信号反射的相互干扰也会降低识别准确度。

## 基于 RFID 的识别
RFID 系统可把标签贴在非生命物体上，原理是捕捉无源标签反向散射产生的频移。这样系统能知道用户接触了哪个物品并发生了什么。虽然不直接监视人体，但可通过使用物品间接推断活动，例如热水器被打开可推断正在洗澡。成本低、易部署。

## 居家老人安全守护
人工智能社区智慧养老系统可为老人提供多重防护。首先监测到身体指标异常或家庭环境异常时，可及时联系子女和社区人员求助。其次，家里出现燃气泄漏或老人因不适未做饭洗衣时，水电燃气、温湿度、安防等传感器数据会异常，系统会向子女或社区发出预警。再者，若老人意外跌倒且身边无人，延误治疗会造成更大伤害，人工智能可监测异常行为，跌倒或突发疾病时及时报警，减少损失。

监测设备覆盖面广，家中需部署本地服务器定时接收各类监测设备的异常数据，按等级分类标记，再判断是本地提示还是上报社区服务器报警。日常安全监护以行为异常报警为主，聚焦活动量、生理信号、地理位置等。常见行为异常检测即跌倒检测，常用穿戴式、外围式、视频分析三种方式。

### 基于穿戴的跌倒检测
通常把陀螺仪、加速度计植入手机、手环等穿戴设备，分别获取方向信息和多轴加速度，再分析判断。精度较高，受环境影响小，室内外均可使用。缺点是设备需持续监测人体状态，如何在保证准确性的同时控制存储与计算资源的消耗是关键。

### 基于外围的跌倒检测
在家中布置压力、声音等传感器收集运动信息，跌倒时会引起周边的压力和声音变化。方法安装成本高，易受噪声干扰，精度相对较低，实际应用较少。

### 基于视频的跌倒检测
硬件要求低，一到多个摄像头即可使用。可获取速度、位置、行走姿态等丰富信息，且家属可远程查看室内情况。常用剪影、轮廓、姿态估计等方法，姿态估计能得到关节点坐标，更好表征人体位置，对跌倒识别更敏感。效果虽好，但受光照、遮挡影响，在复杂环境下性能会下降。

## AI 情感关爱与陪伴
退休后社会角色变化、社交圈缩小、与子女相处时间有限，容易产生孤独感。社区是提供精神慰藉最便利的主体。在人工智能社区智慧养老模式下，人机交互系统可进行人性化交流，依托深度学习、自然语言处理与心理学、语言学知识，系统甚至能像心理咨询师般疏导情绪。系统还能收集兴趣爱好、生活习惯等个人数据，通过学习推荐更受欢迎的娱乐项目。在社交方面，智能手机等设备的普及让老人能便捷进行语音、视频联系，结合正常生活，提升幸福感。

### 精准内容推荐机制
个性化推荐是指系统依据老人个性化需求提供相关信息。推荐过程涉及用户、被推荐对象、信息系统三部分。用户是核心，需收集年龄、性别、收入、健康程度、生活习惯等基础信息及认知风格、消费动机、主观感受等。被推荐对象包括感兴趣的文本、视频音频等多媒体信息及衣食住行建议等。需求可由用户主动提供，也可通过使用记录与爱好推导。推荐方法的选择是关键，常见方法有：

#### 内容驱动推荐
早期常用方法，需分别建立用户偏好模型与对象特征模型，再分类匹配并按匹配度排序。优点是结果直观易解释，无需历史数据；缺点是面对属性复杂的对象时，需要大量数据构建模型。

#### 协同过滤推荐
目前应用广泛，基于用户历史行为数据寻找用户或对象近邻集合来推断偏好。相比内容驱动，其优势在于可发现潜在兴趣、对领域知识无依赖、相似用户数据可共享缓解稀疏问题。分为基于邻域和基于模型两类。

##### 基于模型的协同过滤
常见有矩阵分解、神经网络等。邻域方法可解释性强，但当用户无共同评分却偏好相似时难以找到近邻。基于模型的方法从用户与项目数据中学习表示，通过训练预测生成推荐列表。

##### 基于用户的协同过滤
从用户角度出发，利用相似度找到与目标用户兴趣相近的邻居，将邻居喜欢且目标用户未接触的项目推荐给其。相似度计算常用皮尔逊相关系数、向量相似度、Jaccard 系数等。

##### 基于项目的协同过滤
针对用户对项目的评分行为计算项目间相似度，据此结合用户历史行为给出推荐。

#### 关联规则推荐
挖掘用户与被推荐对象的关联规则。成熟易实现，能发现新兴趣点；缺点是数据处理重、建模耗时长，不易实时推荐。

#### 知识驱动推荐
基于领域规则与先验知识确定项目属性与用户偏好对应关系，常见为基于实例的系统。需用相似函数评估匹配度。优点是能映射需求，缺点是领域知识难获取、难挖掘潜在偏好、结果相对静态。

单一方法各有不足，实际系统常组合使用。常见组合内容驱动与协同过滤，融合方式有三种：后融合，先独立实现再加权合并结果；中融合，以一种算法为核心，另一种补充其功能；前融合，直接构建融合模型。
