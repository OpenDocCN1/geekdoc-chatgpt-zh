## 6.5 AgentExecutor 执行原理拆解

AgentExecutor 是 Agent 的运行环境，它先调用大模型并接收结果，随后执行模型挑选的工具，同时负责处理多种异常情况，包括调用不存在的工具、工具执行出错、模型输出无法解析为 Function Calling 格式，以及在决策与调用期间进行日志记录。

仅观察 LangChain 的日志不足以弄清执行细节，必须深入源码，通过断点调试的方式来探究 AgentExecutor 的运行机制。
