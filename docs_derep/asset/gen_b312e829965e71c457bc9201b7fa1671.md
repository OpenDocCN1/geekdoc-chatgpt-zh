# 8.3.5 多选路由查询引擎

有时我们并不想只选一个引擎，而是希望把一次提问同时派发给多个引擎，发挥不同索引的长处来提升答案质量。这就用得到多选路由查询引擎。它会依据语义挑选出若干可用工具，分别调用生成结果，最后再由大模型把多份结果融合，输出一份综合答案。不同索引、不同生成策略因此可以互相补位。
