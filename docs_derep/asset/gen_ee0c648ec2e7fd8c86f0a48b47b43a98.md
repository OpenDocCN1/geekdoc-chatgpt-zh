下面对这段实现做展开说明。

# **1. ModelSelector类**

该类承担根据任务类型如 chat、completion、translation 等，以及上下文是否需要多轮对话来判定最合适的模型。

select_model 方法会结合任务类型和上下文进行判断。以聊天任务为例，当上下文标记了多轮对话时，系统会选用 multi_round_chat_model。

# **2. ModelManager类**

ModelManager 负责与 DeepSeek 接口打交道，执行具体的模型调用。

call_model 方法接收任务类型、提示词和上下文，先通过 ModelSelector 确定模型，再发起 DeepSeek API 请求。
invoke_api 方法借助 requests 库向 DeepSeek 发送请求，并把返回数据交回上层。

# **3. 示例使用**

在程序主体里，用户需要提供 API 密钥、任务类型例如 chat、提示词例如“你好，今天天气怎么样？”以及上下文例如 `"multi_round": True` 表示开启多轮会话。

**调用 model_manager.call_model()** 完成实际调用，拿到结果后直接打印。

与 DeepSeek 交互时采用 HTTP POST。示例请求结构如下：

> * "prompt": "你好，今天天气怎么样?"  
* *"max_tokens": 100*

**DeepSeek** 的返回示例：

*

> *"choices": [  
*{  
 *"text": "今天的天气晴，适宜出行，温暖而不炎热。"  
}*

**案例要点解析如下。**

*(1) 获取 DeepSeek API 密钥：* 先在 DeepSeek 官网注册账号获取密钥。

*(2) 设置 API 密钥：* 将密钥填入 `api_key="your_api_key_here"` 位置。

*(3) 启动程序：* 运行 `python main.py`，系统会自动挑选模型并输出响应。
