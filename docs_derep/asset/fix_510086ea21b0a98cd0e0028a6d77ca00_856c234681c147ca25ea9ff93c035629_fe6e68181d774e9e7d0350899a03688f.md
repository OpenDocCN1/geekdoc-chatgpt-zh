LangChain Agent 工具调用 + 对话记忆实战

大模型单独使用时只能生成文本。要让它具备检索、计算等外部能力，并能在多轮对话里保持指代，需要把模型、工具、记忆串成一条 Agent 执行链。下面用一个最小可运行的例子演示如何搭建，以及记忆有无对代词指代的影响。

先初始化模型与运行环境。把 OpenAI 的密钥和 SERPAPI 的密钥写入环境，实例化温度为 0 的 ChatOpenAI，并导入相关链式组件。

from langchain.agents import ZeroShotAgent, Tool, AgentExecutor

from langchain.memory import ConversationBufferMemory
