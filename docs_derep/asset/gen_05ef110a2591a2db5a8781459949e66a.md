数据清洗是分析与科学工作的基础，直接决定结果质量与可靠性。在企业经营与科研场景中，常需处理海量数据，这些数据往往夹杂错误、缺失或不一致。未经清洗的脏数据容易引发误判。因此，高效精准的清洗既能提升数据质量，也为后续决策提供保障。

**1．数据清洗的基本概念**

（1）定义。数据清洗即数据清理，指在分析前对数据集进行修正的过程，涉及识别、纠正或剔除错误、不完整、不准确或无关的部分。其目标是提升准确性、完整性和一致性。

（2）目的与重要性。核心目的是让数据集为高质量分析做好准备。错误数据会导致分析偏差，影响决策。清洗还能提高处理效率，降低存储与计算成本，避免因质量问题浪费时间。

（3）常见问题。

①缺失值：字段为空或未记录，可能源于录入失误、丢失或信息不适用。

②异常值：与整体分布明显偏离的点，可能为录入或测量错误，也可能是真实变异。

③重复数据：同一记录多次出现，会扭曲结果。

④不一致数据：因格式、拼写或数据源标准不同造成的不统一。

⑤错误数据：因录入、理解或转换失误导致的不准确内容。

⑥格式问题：日期时间等格式不统一，不利于分析。

（4）清洗流程。

①数据审计：人工或程序化检查原始源，识别质量问题。

②制定清洗规则：确定策略、规则与方法。

③执行清洗：按规则操作。

④验证结果：检查是否全部修复且未引入新问题。

⑤回流干净数据：用清洗后的数据替换源数据，避免重复清洗。

## 5.2

## ChatGPT 助力数据转换

[PRE21]

扫一扫，看视频

数据转换指把数据从一种格式、结构或类型变为另一种的过程，常涉及清洗、映射、合并与拆分，以满足分析或业务需求。转换不仅是物理搬迁，更是结构与格式的调整，确保数据在新环境中保持意义与价值。

良好的转换流程可提升一致性与准确性，使分析更可靠。典型场景包括企业并购后的人员与流程整合、数据集成与管理，以及构建数据仓库时从业务系统抽取、清洗、转换并加载数据。

**1．非结构化数据转换**

业界估计，非结构化数据占总数据量 80% 以上，形式多样，包括文档、文本、图像、音视频与网页等，信息丰富但处理门槛高。结构化数据约占 20%，以表格、CSV 等规整形式存在，易于处理。

为弥合差异，需将邮件、消息、HTML、PDF 等非结构化内容转换为数据库表格、CSV 或 JSON 等有序格式，包含分类、排序与复杂格式化。

引入 ChatGPT 可大幅提升转换效率与准确度。它能理解文本、图像、视频等多源非结构化内容，利用强大的自然语言处理能力快速抽取关键信息，并整理为结构化表格、CSV 或 JSON 格式。
