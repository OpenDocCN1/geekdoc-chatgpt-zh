辛顿被称作深度学习的教父，靠的不仅是开创性的技术贡献，更在于他为整个圈子输送了大量人才，并主动把学生和合作者推向 IBM、Meta、微软、谷歌等巨头实习工作——这是在 OpenAI、DeepMind 等新锐独角兽出现之前，主导人工智能的四大公司。他心态极其开放包容，圈内许多项目的主创、负责人都或直接或间接与他有关，师生、合作的链条层层相连，他就像个枢纽，让技术和信息在不同群体间流通。他的实验室成果也完全对公众开放，任人拿去改进自家系统，这大大加速了从论文到产品的落地。辛顿自己在采访里说：“我们基本上对此毫无保留，因为我们着眼于证明我们技术的优势。”他还提到：“有趣的是，微软研究院和 IBM 先于谷歌得到这项技术，但是在将技术转变成产品方面，谷歌却比任何公司都更加迅速。”这里所说的速度，正是指后来名声大噪的谷歌大脑项目。

2007 年在谷歌总部所在的山景城，辛顿做过一场关于深度学习的内部技术分享，现场聚集了谷歌员工和大批外部极客，并同步 YouTube 直播，关注度很高，谷歌的技术领军人物杰夫·迪恩也在观看者之列。迪恩并非普通极客，他是谷歌的传奇人物。1999 年谷歌只有几十人时他就加入公司，早在学界已声名在外。加入后几年他主导了谷歌软件基础架构的搭建，BigTable、MapReduce 等定义大数据的核心系统都出自他之手，对谷歌技术走向拥有相当大的话语权。

2011 年，斯坦福人工智能实验室主任吴恩达对迪恩说：“现在风口变了，深度学习取得突破，神经网络表现非常好，如果谷歌能掌握大规模网络的训练方法，就会产生奇迹。”迪恩觉得有意思，亲自钻研半年后认同这将是未来互联网公司的必争之地。随后一年左右的时间里，他与吴恩达一起在“Google X”——谷歌内部负责高瞻远瞩研究的部门——立项了谷歌大脑。起初的目标很单纯：打造一个真正庞大的神经网络，去看看它能做什么。

# 谷歌大脑引爆深度学习

谷歌大脑起步时做的是无监督学习式的世界认知实验。为了这个实验，动用了 1.6 万个微处理器，搭建了一个拥有数十亿连接的神经网络，人类大脑的神经元连接大约有 1000 亿个。它观看了千万级别的 YouTube 图像和视频，试图自行归类所见之物。结果令人意外，完全没有人工标注的干预，系统自发辨认出了“猫”，甚至主动搜集猫科明星的片段。迪恩向《纽约时报》表示：“在训练中，我们从未告诉它‘这是一只猫’，是它自己发现并总结出了‘猫’这个概念。”“谷歌找猫”一度成为业界佳话，随后团队又打造更强的网络，开始尝试语音识别等任务。

项目运行一年后，谷歌已拥有当时全球规模最大的神经网络，并在内部产品中实现应用。对外看来已是亮眼成绩，但这其实只是起步。

2013 年谷歌大脑从 Google X 转入 Knowledge 部门，此后公司对外逐渐不用“大脑”这个说法，更倾向统一称呼为“谷歌深度学习项目”。迪恩曾半开玩笑说改名是为了“避免动物保护人士在总部门前抗议”，但实质反映了人工智能在谷歌战略中的地位变化，项目版图将容纳更多深度学习研究。2013 年谷歌在深度学习上的收购动作密集，连最乐观的投资者也难以预见这些投入几年后会迸发出多大价值。

2012 年辛顿率领学生苏茨克维和亚历克斯·克里热夫斯基拿下 ILSVRC 2012 后，三人创办了只有三名员工的 DNNResearch，这家公司几乎是空壳，2013 年 3 月被谷歌以 5000 万美元收购。收购后辛顿仍在多伦多大学任教，同时定期到山景城参与谷歌大脑工作。这一笔大手笔招聘只是当年谷歌动作之一，就在辛顿加入前数月，雷·库兹韦尔、彼得·诺维格、塞巴斯蒂安·史朗等人工智能界的标志性人物也先后被谷歌招揽或收购。

正是这次集中投入，让谷歌迅速占据人工智能热潮的高点。单说 2013 年收购英国 DeepMind，就带来深远影响和巨大宣传效应。世人后来熟知的 AlphaGo、Master、AlphaZero 与李世石、柯洁的围棋对决，其源头正可追溯到 2013 年的这一系列布局。

从 2012 年起，企业对深度学习的追逐全面展开。三大巨头中，辛顿已被谷歌聘用，另外两位也被各家争抢。

卷积神经网络之父杨立昆是法国人，博士毕业于匹兹堡大学医学中心，后在贝尔实验室工作，现任纽约大学教授。他曾在多伦多大学做博士后，导师正是辛顿，也因此被归入“三巨头”和“加拿大黑手党”。辛顿门徒众多，但博士后名额极难争取，连迈克尔·乔丹都曾被婉拒。

2013 年杨立昆以纽约大学教授身份兼职加入 Facebook，创立 Facebook 人工智能研究院 FAIR。实验室人才济济，除他本人外，还有弗拉基米尔·万普尼克、赖恩·布图、基思·亚当斯等都在其中工作。FAIR 自称 70% 资源投入基础科研和长期研究，Facebook 同时组建的应用机器学习部门 AML 由华金·坎德拉带队，负责把研究成果产品化。

FAIR 与 AML 的产出让 Facebook 在自然语言处理和人脸识别上处领先。DeepFace 可在不同图像中以 97% 的准确率辨认同一人，高于人类 96% 的水平。DeepText 能接近人类准确度的阅读理解，在 ACL 2017 上展示过通过阅读维基百科回答“17 世纪奥斯曼帝国有多少个省”“美国哪个州座右铭是 Live free or Die”“查德威克发现了原子中的哪个部分”等开放问题的能力。

另一位巨头本吉奥同样是法国人，生于巴黎，后在加拿大深造，现任蒙特利尔大学工程系教授。他的贡献遍布神经网络的多个细致角落，自然语言处理中的循环神经网络、长短期记忆网络、词向量等关键技术都与他有关。他主导的蒙特利尔大学机器学习算法实验室 MILA 产出 Theano，这套 Python 代数计算库是 TensorFlow 之前的工业主流。

2018 年，ACM 将图灵奖授予辛顿、杨立昆、本吉奥，表彰他们在深度神经网络和深度学习概念与工程上的突破。

本吉奥是三人中最年轻、低调的一位，长期不愿离开学界。2014 年在微软全球副总裁沈向洋长时间游说后，他才答应加盟微软研究院，出任人工智能战略顾问，微软高调宣布此事。

微软研究院在 20 世纪 90 年代曾是人工智能领军者，聚集大量顶尖学者，但在第二次人工智能寒冬和内部决策影响下，后续投入停滞，错失多年窗口。重新发力时已落后谷歌、Facebook、IBM。凭借雄厚资金和技术底蕴，微软后来推出了认知计算服务等成果，逐渐追赶。

上述三位巨头从学界走向产业，以及谷歌、Facebook、微软的激烈争夺，折射出近十年来学术界与工业界的良性互动。只要能招到一位优秀神经网络学者，大学就能获得百万级经费，高校掌握了更多自主研究资金。但这也需警惕前两次寒冬的教训，避免过度夸大。辛顿提醒道：“如今神经网络理论开始奏效，因而工业界及政府也开始将神经网络当作人工智能。以前整天嘲笑神经网络的人工智能研究者也乐在其中，并计划从中分一杯羹。”这句话带有明显警示：当所有人都追捧时，往往意味着顶点临近，更需要清醒认识挑战并审慎反思策略。

### 7.8 挑战与反思

深度学习虽已收获无数成功，但距离完善仍有很长的路，困境像一层层嵌套的谜题。

1.效率

当前深度神经网络的效率其实很低，某种程度上正因缺乏更好方案才被广泛采用。

深度学习是数据驱动的方法，精确模型需要海量数据支撑。如同人类靠经验学习，神经网络也需大量样本训练，模型越复杂参数越多，数据需求越大。训练一个语音识别系统，就要收集多种方言、时长、人口数据，过亿级数据喂入网络，经过漫长调优才可用。谷歌、Facebook、微软等都经过多年技术积累才达到今日水平。现今解决一个问题，本质是能否利用巨量数据。

处理海量数据需要强算力，训练时常依赖多卡 GPU 甚至超算，设备昂贵能耗高，这限制了应用范围。手机、无人机、可穿戴设备等场景更需要小型高效的神经网络处理单元，需要在效率、能耗、成本、可使用性之间权衡。

人们已普遍接受深度学习对数据和算力的依赖，但一个难以忽视的事实是，擅长海量数据和高性能计算的电子计算机在此领域适配性很差效率很低。神经网络模仿人脑，却远不如人脑省数据。人只要听老师讲解一两分钟就能辨认字母字体，见过几张图片就能区分雪狼和萨摩耶，而机器却要翻遍千万级影像。人脑神经元间靠化学递质传导，速度远慢于电子信号，却能更省地学习。

2.理论基础

人类模仿鸟类造出飞机，飞得更高更快，因为掌握了空气动力学理论。要让计算机智能实现跨越式突破，关键也在于发现理论基础。目前神经网络效率不高，正是缺乏理论指导优化的体现。寻找产生智能的理论，科学界已探索数十年，迷雾依然重重。
