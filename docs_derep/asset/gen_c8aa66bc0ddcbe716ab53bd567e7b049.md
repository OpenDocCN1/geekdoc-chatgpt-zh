### 4.1.3 LLM.int8 驱动的低秩误差补偿

大规模语言模型推理普遍采用 INT8 量化来降低显存占用并提升算力利用率，但降位量化不可避免地引入逼近误差，导致效果回落。引入低秩补偿机制后，可通过附加的低秩适配器对量化后的参数进行校正，弥补量化过程丢失的精度信息。

该思路的核心是学习一对低秩矩阵，让模型在低位表示下仍保持接近全精度的表现，从而在部署时兼顾质量与资源开销。

#### 1. 补偿原理拆解
低秩补偿基于一个直观假设：权重经 INT8 量化后丢失的部分信息，可以用一个低秩矩阵的乘积来近似还原。具体做法是在量化后的权重矩阵上叠加一个维度远小于原矩阵的低秩适配项，在计算成本几乎不变的前提下提升量化模型的精度。既保留了低比特的效率优势，又有效削弱了量化误差对推理结果的干扰，使整体效果逼近高精度模型。

#### 2. 工程落地与典型场景
工程实践中，该机制多在模型加载阶段注入，利用预训练好的低秩适配参数做动态补偿。适用范围覆盖 INT8 量化模型，也兼容 INT4 量化模型，还常用于边缘计算与高并发推理场景。结合量化感知训练、SmoothQuant 等手段，可以实现量化与补偿的协同优化，稳定推理质量与效率。

总体来看，LLM.int8 的低秩补偿通过在低比特模型中加入低秩校正项，有效恢复量化丢失的信息，为资源受限环境下的高质量大模型部署提供了关键支撑。

## 4.2 编译优化与图融合技术

大语言模型的高效推理，不仅取决于模型本身，也离不开编译优化与图融合的配合。该技术通过重构计算图并融合算子，对计算密集型任务实现更高效的调度与执行。编译优化侧重静态分析计算图，剔除冗余操作和不必要的内存读写，进而完成算子融合、内存布局调整与并行调度；图融合则把相邻或关联的算子合并为单一内核，降低跨算子数据搬运的延迟，充分调动硬件并行能力。

两者协同可显著减少中间结果的存储与计算开销，提升内存带宽利用率并压低整体延迟，在部署阶段尤为关键。以此为基础，系统可在低功耗设备或边缘环境实现实时推理，并让同一模型在不同硬件平台上均能发挥最佳水平。

### 4.2.1 ONNX 图优化 Pass 链设计

在推理部署中，ONNX 图优化发挥着核心作用。优化 Pass 链通过一系列对计算图的变换，降低计算冗余与内存占用，从而提速。构建链路时首先要对图结构做全面分析，随后依次应用算子融合、常量折叠、节点简化等操作。每个 Pass 都必须在不改变模型语义的前提下，尽可能消除无用计算与数据传输，以满足边缘设备与高并发推理的严苛需求。

**1. 优化 Pass 链设计原则**

- (1) 顺序执行与依赖管理：各 Pass 应按既定顺序运行，保证前一阶段的输出为下一阶段提供稳定输入，兼顾 Pass 间依赖以避免重复计算或冲突。
- (2) 模块化与扩展性：Pass 以独立模块形式设计，便于单独测试与维护，同时支持按需增删或调整顺序，适配不同场景的个性化优化需求。
- (3) 保留模型语义：优化全程必须保证原模型语义不变，每次图变换都需严格校验，防止数值偏差或逻辑错误。

**2. 实现与应用示例**
通过自定义 Pass 链，可以对 ONNX 计算图进行定制化优化。例如剔除冗余的 Identity 节点，将 Add 与 Relu 节点融合，对静态常量进行折叠，从而提升推理效率。
