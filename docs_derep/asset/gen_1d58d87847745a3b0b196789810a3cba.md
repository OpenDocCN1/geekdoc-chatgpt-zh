# 第二部分 学派之争

## 第 3 章 符号主义学派

Symbols lie at the root of intelligent action, which is, of course, the primary topic of artificial intelligence.

符号是一切智能活动的源头，它是人工智能中不容置疑的核心。

——艾伦·纽厄尔(Allen Newell)、司马贺(Herbert Simon)，《作为经验主义探究的计算机科学：符号和查询》，1975 年

### 3.1 概述

第一部分以时间线回顾了人工智能萌芽的过程。第二部分要做的，是梳理这条发展脉络里出现过的三大主流思想。本文从其中最先被系统实践的流派说起：也是图灵、香农反复追问的“如何让机器变得聪明”，在这一时期终于从设想走向实验。学界通常把研究视角相近、方法相近的学者归为一派。

在人工智能的早期相当长一段时间内，围绕符号展开的研究是主流方向，甚至有三十年左右的时间符号主义在全盘学科里占据主导。虽然今天纯符号路线已不再是中心，但其思想已深植于众多技术，成为相关领域的底层常识。

该派的观念可以追溯到图灵。它主张从功能层面去理解智能，把智能看成一个黑箱，只追问输入与输出，不追究箱子里是什么。为此，符号主义用符号对现实进行抽象，用逻辑推理和搜索来模拟人的思考认知，而不去触碰大脑的神经结构，也不去探究大脑是否真的在做逻辑运算。

按核心关切的迁移，这个学派的探索大致可分三步。起初大家默认知识已经准备好，存在于黑箱内部，重点放在如何用已有知识进行复杂推理、规划和判断，这一段被称作符号主义的推理期；随后发现推理并非全部，先验知识的获取与表征更为关键，研究重心转向知识的获取、表示和运用，进入知识期；最终人类专家手工提炼知识的方式难以应对现实的海量信息，方向转向让机器自行学习、自行发现知识，这就是学习期。

### 3.2 引言：五分钟逻辑学

本书不以数理背景为前提，也尽量避免用证明推导来讲清观点。但本章讨论符号主义，如果不先掌握现代逻辑最基础的概念，就很难理解这个学派的来由，甚至连名字的意思都讲不明白。下面用几分钟梳理逻辑学这门古老而又在近两百年翻新的学科。

远在公元前 5 至 3 世纪，墨家在中国的明辨、佛教的因明在印度的论证、亚里士多德学派在古希腊的三段论，各自形成了推论与证明的方法。现代意义上的逻辑学根源于亚里士多德的传统逻辑。

亚里士多德在《工具论》中奠定了三段论的形式。下面这个例子几乎见于所有逻辑教材。

[PRE0]

图 3-1　亚里士多德的《工具论》

所有人都是会死的； 大前提，确定普遍原则
苏格拉底是人； 小前提，确定个体事例
所以苏格拉底会死。 结论

三句话都叫命题，最后一句是结论，前两句是前提。直观地说，就是从前提演绎到结论。

把命题当作最小单元，研究“若 p 则 q”“若 p 且 q 则非 s”这类命题间关系的，称为命题逻辑。

再把命题拆开，按主项、谓项、联项、量项来分析，研究“所有 S 都是 P”“有些 S 不是 P”“a 是 P”这类词项间关系的，称为词项逻辑。传统三段论的前提多为直言命题，所以也叫直言三段论。形式虽简，现实中随处可见，比如“对中国首富来说赚一个亿是小目标；王健林是中国首富；所以王健林赚一个亿是小目标”。形式无误，对王健林成立，但小前提对其他人并不成立，所以公众不买账。

到这里的词项逻辑，后来被称作传统逻辑。经过斯多葛学派，尤其是亚里士多德学生泰奥弗拉斯的补充，传统逻辑统治了两千余年。康德曾断言逻辑在亚里士多德后已臻完善。但不到百年，逻辑迎来最大变革，诞生了谓词逻辑。

其中 S、P 分别指“属于 S”“属于 P”，“[PRE4]x”意为“对每一个 x 而言……”，符号“`→`”表示蕴含。通俗讲就是对所有 x，若 x 是 S 则 x 是 P。

谓词逻辑补足了表达力和精确性。词项逻辑缺乏量词和关系理论，无法严谨表达“某些猫被所有老鼠惧怕所以所有老鼠惧怕至少一只猫”这类直觉推理，也不利于数学化处理。谓词逻辑打破了逻辑与科学、尤其是逻辑与数学之间的隔阂。

看到像“[PRE5]x(S(x)→P(x))”这样的式子，不免会想：数学化的逻辑更容易被计算机处理，人脑的推理与逻辑推理是否共通？可以更具体地假设：既然语言能写成算式，那么世界的知识是否也能符号化？符号化后，人类思考是否也能用数学运算和定理完成？

在这一思路下出现了若干里程碑：

• 17 世纪中期，莱布尼茨设想一种通用语言和相应的推理演算，史称莱布尼茨之梦。
• 1847 年，乔治·布尔在《逻辑的数学分析》中用代数表示逻辑概念，形成布尔代数。
• 1879 年，弗雷格出版《概念文字》，引入全称与存在量词符号，使符号逻辑趋于完备。
• 1889 年，皮亚诺独立提出类似量词符号，试图以极简公理搭建数学体系，催生了《数学原理》和希尔伯特计划。命题演算、类演算并称数理逻辑，也称符号逻辑。
• 1910 至 1913 年，罗素完成《数学原理》三卷，试图证明所有数学真理可在数理逻辑公理下被证明。

至此，五分钟逻辑史结束。现代逻辑的概念若已可接受，再回头看莱布尼茨的问题：日常世界以视觉、声音、文字等非结构化形式呈现，这些内容能否精确定义为符号？人类理解世界的过程能否在符号基础上被精确描述和计算？符号主义的答案是肯定的，核心概括为五个字：认知即计算。

### 3.3 描述已知，推理未知

若直接面对莱布尼茨的问题仍感困难，可先看一个已基本完成自然语言到符号转化的领域——数学。

不仅仅是数学，今天大量形式科学都已走向符号化。拿欧几里得的《几何原本》举例，其公理包括：

1. 任意两点可连成一条直线。
2. 线段可无限延长为直线。
3. 以任一边为半径、以一端为圆心可作圆。
4. 所有直角相等。
5. 若两线与第三线相交且同侧内角和小于两直角，则这两线必相交。

小学生都能读懂，但欧几里得如何保证不同读者的理解一致？点、线、面的定义本身含糊，“点是没有部分的”何为无部分？这种模糊正是符号的价值所在。说“存在一个空集”需要先解释存在、空等，若用符号表达，则是“[PRE6]”。

希尔伯特在 1899 年的《几何基础》中建立了欧氏几何的形式化公理体系，即希尔伯特公理体系。随后他提出希尔伯特计划：把全部数学真理形式化，用符号表达，用规则推导，证明数学完备且一致。后来哥德尔不完备定理粉碎了这一美好愿景，但对常用数学的形式化仍是现代数学的重要工作。

回到人工智能。达特茅斯会议上纽厄尔和司马贺展示的最吸睛成果是逻辑理论家程序。它只能证明用形式语言描述的前提，且可通过有限步推理得到的定理。其思路是用计算机速度优势穷举形式化定理前提的变换，即树搜索配剪枝。根节点为已知前提，变换为分支，出现与结论一致即得证明路径。该方法与后来的归结原理、DPLL 并无直接关系，王浩教授也因此批评其技术含量有限。

1957 年不久，纽厄尔和司马贺发布更具普适性的一般问题求解器 GPS。名字里的“一般”意味着普适，目标是任何已形式化、信息完备的问题都能被求解，涵盖逻辑推理、定理证明、人机对弈等。项目持续十年，未形成突破性应用，但作为用心理学方法模拟智能的尝试具有历史意义。

GPS 的策略不同于逻辑理论家，它模仿人类启发式求解，基于手段-目的分析。司马贺正是该理论的顶尖专家。问题的分解与子目标的逐步实现被模拟为搜索树的构建，直至到达已知条件。之后纽厄尔和司马贺还提出 UNDERSTAND 处理非良好结构问题。

随着运算速度提升，问题求解在人工智能中取得若干实用成果，其中最具标志性的，是计算机在人类辅助剪枝修正下证明了当时世界三大数学猜想之一。
