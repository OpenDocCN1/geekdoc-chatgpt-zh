**偏好对齐的迭代闭环**

落到执行层面，第一步是先攒一批带人工评注的样本。随机抽取若干提问，由标注员给出高质量的参考答案，整理成“表达—结果”配对的训练集供系统学习。这批样例规模在数万级别，学习方式采用提示模仿，模型底座的参数本身并不改动。

第二步是培育一个偏好判别器。同样随机抽题，让当前的基础模型先行给出答案，随后标注员依据偏好判据，例如相关性、信息丰度、有害程度、负面情绪倾向，对这些答案进行排序。

第三步是用前面打过标签的偏好数据训练一个评分器。该评分器会对基础模型的输出给出量化打分，指出哪些结果分数高、哪些分数低。

到这里闭环就闭合了。判别器与基础模型通过反馈式优化连在一起，当基础模型在评分器的评估里拿到低分就会被惩罚并触发再学习。反复循环后，基础模型的表现持续升级，最终内化使用者的偏好，变成一个让人满意的系统，也就是公众熟知的 ChatGPT。

**台前：自然语言成为交互主干**

语言是人与其它物种的分水岭，也是多项智能的核心载体。人类逻辑以语言为形式，绝大多数知识也以文字沉淀与传播。人工智能要真正好用，语言能力几乎是关键要素。

长期以来人们追求用自然语言和机器沟通，既有实用价值也有理论价值：用习惯的语言操作设备，无需学习复杂的程序语法；同时也能借此探究人类语言与智能的运行机理。

要实现自然的人机交流，机器既要读懂文本的含义，也要能用自然语言表达意图。前者常被称作理解，后者常被称作生成。自然语言处理大体由理解与生成构成。历史上理解方向研究更深，生成方向相对薄弱，但近年格局正在变化。

无论理解还是生成，都远比直觉想象得复杂。以现有理论与技术判断，打造通用且高质量的语言处理系统仍是长期工程。面向特定场景、能力尚可的实用系统早已出现并走向商品化、产业化，例如多语种库与专家系统的自然语言入口、各类机器翻译、全文检索、自动文摘等，不过它们的记忆能力并不突出。

当前研究已证明大型语言系统在知识记忆上很强，但在现实判断里，记忆强不等于聪明。更关键的是推理能力。推理的本质是整合多个相关知识点，推导出新知或新结论。当规模足够大时，大型语言系统本身就会具备相应推理能力。

ChatGPT 最大的贡献在于把大型语言系统的接口层搭好了。它让系统去适应人类习惯的指令式表达，而不是要求人类去迁就系统、绞尽脑汁写出可执行的指令。易用性与体验因此大幅提升。

这种交互演进是一种很理想的新型人机交互形态。无需专业技能，也无需高端设备，只需口头说出诉求，人工智能就能理解并给出解答。

## 第四章 深度学习的核心技术

很多人发现 ChatGPT 在文本理解与生成、对话问答、机器翻译、代码生成等任务上的进步很大。技术层面看，这源于近年深度神经网络与大型语言模型研究的持续深入，通俗讲就是海量数据加上巨大算力催生了可落地的模型。

**算法**
ChatGPT 由 GPT-3.5 驱动。GPT 是一种基于互联网开放数据训练的文本生成深度学习模型。算法上采用“利用人类反馈的强化学习”RLHF，包含人问机答、机问人答并不断迭代，让模型逐渐具备对生成答案的评判能力。

RLHF 的训练流程可拆为三步。

**阶段 1：预训练语言模型**
先选用经典的预训练语言模型作为初始系统。预训练出现前，深度学习在自然语言处理上受阻，主要有两个原因：一是面向具体任务的训练数据总量不足，模型容量越大越需要数据支撑；二是特征抽取能力不够强，即便数据充足也难以吸收知识。这两个原因阻碍了深度学习在该领域的突破。而 GPT 预训练模型的出现，从学术到应用都是一次技术飞跃，推动了研究范式的转换。

**阶段 2：训练打分模型**
在此基础上，用初始语言模型产生的数据训练一个打分模型。打分模型的目标是评估输出在人类看来是否表现不错。输入是提示词与模型生成的文本，输出是一个评估文本质量的数值标记。

用于训练打分模型的提示数据通常来自预先富集的数据集，ChatGPT 的提示主要来自调用 GPT API 的用户。这些提示会被送入第一阶段的初始语言模型生成文本。打分模型可视为判别式语言模型，可以从预训练语言模型出发，在 [x =（提示，模型回答），y = 人类满意度] 的标注语料上微调，也可直接随机初始化后在语料上训练。

**阶段 3：基于 RL 进行语言模型优化**
有了能生成文本的初始语言模型和能判断质量的打分模型，就可以用强化学习基于打分模型来优化初始语言模型。

把微调任务建模为强化学习问题，需要定义策略、动作空间、观察空间和打分函数等要素。策略指基于语言模型接收提示并输出文本序列或概率分布；动作空间是词表所有标记在所有输出位置的排列组合；观察空间是可能的输入标记序列，即词表所有标记在所有输入位置的排列组合；打分函数则基于训练好的奖励模型配合策略层面的合约进行计算。有了打分模型，就能按策略优化算法更新模型参数。

**数据**
资料显示，ChatGPT 拥有多达 1750 亿个参数的模型，并在 2023 年初完成训练。背后离不开大数据支持，OpenAI 使用的主要公共爬虫数据集拥有超过万亿词的人类语言数据库。正是这些海量数据，使 ChatGPT 展现出三种强能力：

● 语言生成：遵循提示词生成补全句子的内容，是目前人机交互最普遍的方式。
● 上下文学习：遵循给定任务的几个示例，为新测试用例生成解决方案。值得一提的是，GPT-3 虽是语言模型，重点却在上下文学习而非语言建模。
● 世界知识学习：包括事实性知识和常识。

以上能力都来自大规模预训练：在有 3000 亿个词的语料上预训练 1750 亿参数模型。训练语料 60% 来自 2016—2019 年的 Common Crawl，22% 来自 WebText，16% 来自书籍和报刊，2% 来自维基百科。Common Crawl 是 2008 年至今的网站抓取大型数据集，包含原始网页、元数据和文本提取，覆盖多语言多领域。研究实验室常选取其纯英文过滤版 C4。WebText 语料是从 Reddit 输出链接网络中爬取的大型数据集，每个链接至少有三个赞，代表流行内容风向，对优质链接和后续文本有指导意义。
