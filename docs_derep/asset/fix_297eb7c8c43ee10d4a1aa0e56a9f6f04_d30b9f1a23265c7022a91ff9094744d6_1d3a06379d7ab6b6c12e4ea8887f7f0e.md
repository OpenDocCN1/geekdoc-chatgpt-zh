# OBLOQ物联网实战：从联网到云端控制全流程

# 第 15 课　自制超声波倒车雷达

## 活动目标
1. 掌握声波测距核心原理。
2. 完成模拟倒车雷达装置设计与制作。

## 核心原理
倒车雷达核心在于超声波探测器[PRE43]。工作时，发射端（`TRIG`）发波并启动计时；声波遇障碍反射，接收端（`ECHO`）捕获回波停表。利用时间差换算距离[PRE44]。
接线方案：`TRIG`接P12，`ECHO`接P8，电源共用P8的3V3与GND[PRE45]。
编程后可在Mind+串口监视器实时读取距离[PRE46]。
