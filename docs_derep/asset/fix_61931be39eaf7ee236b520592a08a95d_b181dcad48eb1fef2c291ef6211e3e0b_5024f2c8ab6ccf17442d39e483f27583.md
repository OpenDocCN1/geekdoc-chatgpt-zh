#### 计时薪资提问的三根支柱：背景、痛点、交付物

#### 背景拆解
先把企业现阶段计时薪资管理的真实状况讲清楚，让模型能把握业务复杂度。

#### 需提供的信息点
- 组织属性及规模：例如生产制造类企业，人员数在数百以上。
- 人员构成：正式编制、兼职、实习等。
- 出勤采集方式：门店打卡机、手工登记等。
- 现行计费标准：工作日、节假日费率，加班分段计价逻辑。

#### 关键痛点
聚焦计时核算里真正卡住的环节，并给出量化影响或冲突点。

#### 需提供的信息点
- 信息分散程度：出勤分属多个平台难以自动合并。
- 核算耗时情况：实习生阶梯费率需人工匹配，每月约耗3个工作日。
- 合规风险点：上个月节假日办法用错，收到劳动监察提醒。

#### 期望产出
明确模型需要产生的成果形态与关键交付内容，确保结果可直接用于管理决策。

#### 需提供的信息点
- 核心功能：自动产出计时薪资对照表。
- 校验功能：标注异常工时并给出修正建议。
- 合规功能：依据法规输出费率核算逻辑说明。

### 资料准备

| 项目 | 说明 |
| :--- | :--- |
| 出勤原始资料 | 打卡记录、排班表、请假换休审批单等 |
| 薪酬办法文件 | 各岗位时薪标准、补贴政策、税率表等 |

### 实战案例

#### 背景介绍
本人负责连锁餐饮的人事管理，全国200家直营门店，在岗约3000人，其中80%为计时制的服务员、厨师、清洁人员。门店通过打卡机采集出勤，未与总公司人事平台联通，需手工导出Excel汇总。计费标准为工作日20元/小时，周末25元/小时，22点后延长工时额外补贴5元/小时。

#### 现存问题
1. 信息分散：各店每周由店长邮件上报出勤，总公司3人需5天核对，发薪常出现延迟。
2. 核算失误：上个月某店打卡机未校时，导致200人出现8小时工时漏算，引发集体投诉。
3. 合规隐患：抽查发现实习生餐补未按法定标准执行，存在罚金风险。

#### 协助需求
1. 按上述计价办法设计可自动按时段划分并匹配费率的计薪模板。
2. 提供信息校验方案，能自动识别异常打卡，例如连续工作超过12小时。
3. 产出一份合规核查清单，确保实习生、兼职计薪符合法规。

### 注意事项

| 项目 | 说明 |
| :--- | :--- |
| 信息准确性校验 | 模型产出的薪资表需与过往手工表交叉核对，重点关注节假日与跨天班次 |
| 合规复核 | 办法须经法务确认，避免各地政策差异导致误用 |

| 异常处理机制 | 明确模型无法覆盖的场景，如临时调岗导致的费率变化 |

## 2.5 用AI优化计件薪资核算

问题探讨
1. 订单波动时计件核算复杂度上升，人员对薪资正确性提出质疑，如何应对？
2. 计件制的本质是多劳多得，成败取决于办法清晰与核算精确。智能助手可从办法建模与执行流程切入降低差错。
3. 工序众多且单价界定模糊，导致高价工序被争抢、低价工序无人承接，该如何平衡？
4. 这属于办法失衡。需构建工序难度系数模型，将操作时长、技能要求、设备损耗等纳入单价权重，用标准化公式取代主观定价，同时引入工序组合激励。
5. 旺季临时用工增加，手工对账耗时且失误率约5%，怎样改进？
6. 大规模计件必须依赖结构化信息管理。建议将生产流程拆分为最小作业单元，通过工序卡或电子工单实现实时采集，再按办法自动汇总。

### 提问框架
通用提问公式 = 生产背景说明 + 信息难点 + 核算目标

#### 生产背景说明
帮助模型理解业务背景，使算法贴合生产逻辑。

#### 提问要素
- 企业类型：制造业、服装加工等。
- 生产方式：流水线作业等。
- 计件办法：基础单价、阶梯单价等。

#### 信息难点
锁定计件信息采集与核算的问题环节。

#### 提问要素
- 信息体量：例如日均千条工序记录。
- 错漏类型：重复录入、工序遗漏等。
- 争议场景：返工品核算分歧等。

#### 核算目标
明确模型需完成的核算任务与呈现形式。

#### 提问要素
- 核算维度：个人、班组薪资、工序贡献率。
- 校验要求：出勤对照、合规检查。
- 输出格式：电子表格薪资表、可视化图表。

| 生产信息源 | 电子工单、质检报告、出勤打卡等 |

| 过往争议 | 常见核算纠纷及处理方式 |

### 实战案例

#### 生产背景说明
我是五金配件厂人事主管，主营螺丝螺母，采用流水线计件。工序计价：原材料切割0.5元/件、螺纹加工1.2元/件、质检包装0.3元/件。人员每日填写纸质工序卡，月底财务手工汇总。

#### 信息难点
#### 当前三大困境
1. 信息体量大：200名工人日均6000条记录，5人需7天核算，错误率约3%。
2. 办法冲突：返工件应扣原料成本0.8元/件，但工序卡未记录返工原因，人员质疑扣款。
3. 激励失效：螺纹加工单价三年未调，行业均价已到1.5元/件，核心岗位流失率升至15%。

#### 核算目标
#### 请协助
1. 设计含返工原因、工时的工序记录模板，推动纸质信息电子化。
2. 基于近半年行业信息验证现行单价合理性，给出调价建议区间。
3. 开发自动核算模型，输出个人薪资明细，含工序贡献占比与质量扣款明细。

## 2.6 用智能助手驱动延长工时费核算
