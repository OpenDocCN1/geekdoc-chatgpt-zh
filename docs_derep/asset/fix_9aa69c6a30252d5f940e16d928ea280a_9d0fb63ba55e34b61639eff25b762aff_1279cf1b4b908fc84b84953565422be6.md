# LangChain 双能力搭建：记忆与检索

让对话 Agent 既能记住多轮里出现的关键专有名词，又能基于外部资料作答，核心是把记忆模块和检索增强模块串起来。下面以可直接运行的片段展示如何自建基于 spaCy 的实体记忆、搭建 RAG 流程并带入历史对话。

### 用 spaCy 做实体记忆
先实现一个简易记忆类，解析用户输入、抽取命名实体并把整句累加到内部字典中，重复出现时追加文本。

        text = inputs[list(inputs.keys())[0]]

        doc = nlp(text)

        # For each entity that was mentioned, save this information to the

        # dictionary.

        for ent in doc.ents:

            ent_str = str(ent)

            if ent_str in self.entities:

                self.entities[ent_str] += f"\n{text}"

            else:

                self.entities[ent_str] = text
