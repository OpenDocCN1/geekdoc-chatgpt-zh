# 第 8 章 Keras 实战精要
人工智能难题不仅是计算机科学问题，更是数学、认知科学和哲学问题。

——François Chollet

Keras 是一套以 Python 为主实现的开源神经网络计算库，最初由 François Chollet 撰写。它被设计成高度模块化、可扩展的高层接口，让使用者无需深厚的专业背景就能快速搭建和训练模型。Keras 采用前后端分离的架构，前端是一套统一的抽象接口，后端可调用 Theano、CNTK、TensorFlow 等完成底层运算。编码完成后可方便切换后端，灵活性较高。正因如此，截至 2019 年 Keras 的市场份额达到 26.6%，同比增长 19.7%，在同类框架中仅次于 TensorFlow，数据来自 KDnuggets。

TensorFlow 与 Keras 既有竞争又有合作。早在 2015 年 11 月，TensorFlow 就被加入 Keras 的后端支持。从 2017 年起，Keras 的大部分组件被整合进 TensorFlow。2019 年 TensorFlow 2 版本中，Keras 被正式确定为 TensorFlow 的唯一高层接口 API，取代了 TensorFlow 1 时期的 tf.layers 等接口。也就是说，现在用 TensorFlow 搭建层式模型只能走 Keras 接口。在 TensorFlow 中，Keras 位于 tf.keras 子模块下。

Keras 与 tf.keras 有什么区别？可以把 Keras 理解为一套搭建训练神经网络的高层 API 规范，标准 Keras 库自身实现了该规范，可配合 TensorFlow、CNTK 等后端加速；而 tf.keras 是 TensorFlow 对该规范的实现，只能使用 TensorFlow 后端，并对 TensorFlow 的支持更完善。对 TensorFlow 开发者而言，tf.keras 就是一个普通子模块，和 tf.math、tf.data 等并无差别。下文如无特别说明，Keras 均指 tf.keras。

## 8.1 常用功能模块概览
