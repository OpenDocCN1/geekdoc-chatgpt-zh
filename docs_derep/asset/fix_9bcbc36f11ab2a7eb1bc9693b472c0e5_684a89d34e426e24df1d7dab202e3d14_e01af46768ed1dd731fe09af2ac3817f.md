# 第9章 提示工程驱动软件生态演进

在数字化全面渗透的今天，软件生态已成为生产生活的重要基础设施。与此同时，生成式AI技术正引发一场系统性变革。本章聚焦提示工程如何激活软件生态，并梳理其在各行业的落地形态。

## 9.1 金融科技与提示工程的共生演进

从金融视角观察，新一代生成式系统正在重塑金融科技甚至金融业态，尤其在强交互场景中释放出明显价值，因此金融垂类生成式系统正成为多方争夺的技术制高点。互联网平台、银行券商等机构，以及数据库厂商均已投入研发。相较于加速数智化与重建金融信任，该技术在长尾场景的落地更为突出，比如更专业的智能客服、融资项目实时监测等。依托生成式系统驱动的智能金融助手已率先进入支付类App，为投资者与从业者带来更顺畅高效的体验。

### 9.1.1 支付场景中的提示工程实践

提示工程在支付产品中的应用，能让用户获得更专业的财富服务。以支付宝为例，蚂蚁集团自研的金融垂类生成式系统已内置于蚂蚁财富，通过理解用户的自然表达，可精准调用体系内多种数字化金融工具。理财侧涵盖选品推荐、产品评测、行情解读、资产配置等六大类服务；保险侧则提供产品解读、家庭保障规划、智能核保、智能理赔等智能化服务。

生成式系统在支付风控层面同样价值突出。在消费金融领域，“双十一”等大促的参与集中在支付环节，这要求机构在极短时间内针对不同平台、不同客群作出精准风险判断。马上消费依托自研“天镜”系统，日均可基于用户千万级行为进行风险研判，日均模型计算上亿次，每秒处理一百五十万条特征，实现秒级风控。海量数据积累与强算力为风控策略提供了充足多元的支撑，使支付环节更安全可靠。

### 9.1.2 金融垂类生成式系统的竞争格局

率先进入金融垂类研发的以互联网厂商为主。金融垂类系统被视作塔尖技术，难点在于技术合规之外的数据与行业经验。百度、腾讯、阿里、360等长期深耕反黑灰产与AI，为其在金融垂类突破提供资源保障。

2023年5月下旬，度小满发布千亿级中文系统“轩辕”，也是国内首个开源的金融垂类系统。该系统在1760亿参数的Bloom模型上继续训练，语料覆盖通用内容与金融研报、股票、基金、银行、保险等专业知识，可完成金融名词理解、市场评论、数据分析、新闻理解等任务。

2023年9月，蚂蚁金融垂类系统上线。它在蚂蚁基础系统之上针对金融行业深度定制，基于万亿Token通用语料叠加千亿Token金融知识，并以300多个真实产业场景中提取的60余万条高质量指令数据进行训练构建。

现有资料显示，金融垂类系统在垂直领域具备良好泛化能力，能够辅助用户获取金融信息与开展金融活动。以下从三方面展开说明。

其一，金融名词解释能力突出。金融专业名词具有特殊规则，传统搜索引擎解释往往不够精准。如“涨停板”“跌停板”等受规则限制而异，金融垂类系统通过学习规则可准确理解并服务用户。

其二，数据分析能力强。系统可对海量数据进行计算挖掘规律，例如依据历史数据预测股票等金融工具走势，辅助决策。

其三，新闻解读及时准确。公司公告、政策变动等金融新闻是投资者判断的重要依据，系统能快速解析新闻内容，分析对股价、股市的影响，提供全面信息。

除互联网厂商外，数据库厂商也在布局。星环科技自研金融垂类系统“无涯Infinity”，并提供一站式自建大语言模型工具链，含向量数据库Hippo及数据库底层处理技术。恒生电子的LightGPT使用超4000亿tokens金融数据与超400亿tokens语种强化数据，可支持80多种金融专属任务微调，在专业理解上表现优异。

2023年8月28日，马上消费金融推出我国首个零售金融垂类系统“天镜”。目前已在汇聚智慧、唤醒知识、众创价值、数字分身四大方向落地产品，覆盖营销获客、客户运营、客户服务、风险审批、安全合规、资产管理六大零售场景。1）汇聚智慧，主要用于人工客服，提炼优秀人工服务经验形成群体智慧，实现一对多AI客服。截至2023年8月，意图理解准确率达91%，客户参与率达61%，显著高于传统模型与人工。2）唤醒知识，解决非结构化文档数据提取难题。招股书、财报、经济预测等文件上传后，天镜可解析专业术语、定位多文档、洞察图表信息并归纳总结。3）众创价值，降低数据使用门槛。SQL生成平台无需代码，用户用自然语言描述需求即可自动检索生成答案，完成数据挖掘。4）数字分身，打造“数字外表+智慧大脑+情感内核”三合一数字人。员工上传资料并设定参数，5分钟训练后即可拥有个人数字分身，代替完成大量工作。

### 9.1.3 用户体验提升的关键路径

AI系统的蓬勃发展，让财富管理有望破解传统服务痛点，如理财顾问门槛高、普通投资者难以获得定制化服务，让长尾用户享受到更专业、更有温度、7×24小时在线的服务。

2023年9月8日，蚂蚁集团发布智能金融助理“支小宝2.0”与智能业务助手“支小助1.0”。支小宝2.0面向C端，提供行情分析、持仓诊断、资产配置、投教陪伴等专业服务；支小助1.0面向金融机构与从业者，为理财顾问、保险代理、投研、营销、理赔等打造全链路AI助手。

知识力上，支小宝2.0实现金融领域有问必答，事件分析推理能力不输行业专家平均水平；专业力上，依托系统服务中枢，可像真人一样提供上百种理财服务；语言力上，金融意图识别准确率达95%，能读懂问题也能读懂情绪并个性化表达；安全力上，通过围栏技术保障内容安全与合规，带来透明可靠体验。

例如询问“人工智能这么火，会影响哪些行业”，支小宝2.0会实时整合50多个专业机构、权威智库与媒体信息后作答。若用户情绪化表达，AI会进行语料提炼、情绪识别与分类，尝试不同话术帮助缓解负面情绪。因此它不仅能回答“持仓新能源汽车最多的基金是哪个”等专业问题，也能回应“我又绿了怎么办”等情绪化提问并进行安抚与复盘。

支小助1.0包含服务专家版、投研专家版、理赔专家版、保险研究专家版等六个版本，可在投研分析、信息抽取、商机洞察、专业创作、金融工具使用等环节提供深度服务。以投研支小助为例，实测显示其每日可为每位投研分析师高质量提取100多篇研报资讯的逻辑观点、完成40多个金融事件的推理归因，大幅提升效率。

同时，支小助1.0基本可完成基础金融工程代码编写，提升量化研究效率。在服务支小助辅助下，理财顾问与保险代理人的人均有效管户半径可扩大70%以上。

正如蚂蚁集团财富事业群总裁、蚂蚁基金董事长王珺所言，“伴随金融服务从广度走向深度，财富管理正形成以用户为中心的新生态，结合生成式系统技术，将为用户创造更普惠、专业、透明且包裹式的新体验。”这正是系统驱动财富管理的重要方向。

## 9.2 提示工程与智能搜索的协同创新

生成式系统的出现对传统搜索引擎构成冲击，也为问答业务提供新思路。与此同时，搜索引擎正与生成式系统融合，借助其能力使结果表述更清晰，形成准确性与实用性更强的搜索新形态。为获得更强问答能力，生成式系统正向法律、医疗、金融等垂类延伸，满足用户长尾专业提问。今天生成式系统飞速演进，传统搜索也在不断革新。

### 9.2.1 生成式系统与传统搜索的竞争与互补

生成式系统初现时即被与传统搜索引擎对比，被认为对话式生成对搜索构成巨大挑战，甚至可能替代。但至今来看担忧有所过剩，系统火热但搜索用户并未衰减，因两者赛道本就不同。以ChatGPT为例进行对照。

相较传统搜索，ChatGPT并非机械罗列网页链接，而是调用训练语料直接生成整理优化后的答案，以对话形式呈现，并能基于上下文持续交互。还能进行文学创作、绘图、编程、调试等创作型工作。测试显示其在百科检索、数学计算、常识问答、文学交流、知识推理等对话任务上的意图识别率可达98%左右，生活闲聊约95%，语义理解能力良好。

与谷歌搜索对比，ChatGPT的直接答案展示更具实用性，对话方式更有人情味，可满足智能办公与AI创作需求。主流搜索引擎多基于问题本身检索，导致用户难以准确描述需求时受限。而ChatGPT可通过连续对话挖掘真实意图，提供解决方案，借助开放式生成机制循序渐进给出用户真正需要的答案。

不过传统搜索引擎历经数十年积累，仍具备不可比拟的优势：

- 海量数据库：已构建庞大数据库，可在海量信息中快速精准定位，并提供多条相关结果供用户选择。
- 可信可靠：仅展示公开网页，用户可自行判断来源可靠性，而ChatGPT直接给出答案，来源难以追溯。
- 实时稳定：限制更少，实时性与稳定性更高，用户可随时获取较准确结果。

因此生成式语言系统难以完全替代搜索引擎，“生成式系统+搜索引擎”的混合形态更可能成为新一代搜索方向，带来极大体验提升。

### 9.2.2 新一代智能搜索的兴起

2023年8月23日，昆仑万维推出国内首个融合大语言模型的搜索引擎——天工AI搜索。用户输入问题后，系统先以卡片形式展示信息源，再给出系统生成的回答，最后附上AI生成的追问，形成“链接-回答-追问”的呈现方式。

结果给出后，依托上下文理解，天工AI搜索可通过AI总结加多轮对话不断挖掘用户真实意图，对复杂问题深入研究。

例如询问“新加坡好玩吗”，天工AI给出有人情味的智能回答，并将各链接有机串联在上下文中，使用户清晰把握要点，同时保证答案可追溯、可考证、可信赖。搜索还会根据问题智能生成相关追问，便于用户进一步深入。
