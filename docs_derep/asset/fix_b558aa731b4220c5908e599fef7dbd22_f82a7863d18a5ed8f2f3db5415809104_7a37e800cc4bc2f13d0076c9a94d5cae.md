先做不带任何优化的对照实验。模型加载到显存后切到 eval 模式，最大生成长度、top-k 策略与温度都沿用配置文件的默认值，提示词统一设为“酒店的位置”，连续跑十轮记录显存占用与总耗时。这一版每次生成都把累积到当前步的完整序列重新喂给网络。

import torch

from tqdm import tqdm

import torch

import config

import gpt2_cached

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

gpt2config = config.GPT2Config()

tokenizer = config.Tokenizer()

model = gpt2_cached.GPT2(use_cache=True).to(device)

model.eval()

max_length = gpt2config.max_length

import time

start_time = time.time()
