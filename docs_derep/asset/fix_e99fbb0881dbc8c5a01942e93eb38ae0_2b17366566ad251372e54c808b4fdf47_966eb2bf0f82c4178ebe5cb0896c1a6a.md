把卷积核的滑动步幅调大，特征图的长宽就会按比例收缩，模型所需参数随之减轻。除了改步幅，网络里还有一类专门负责降维的结构——池化层。

池化建立在局部相关这一假设上，对一个局部窗口里的元素做抽样或聚合，得到新的代表值。最大池化挑窗口里的最大值，平均池化则算窗口的平均值。以 5×5 的输入 X 为例做最大池化，感受野边长取 k=2、步幅取 s=1，见图 10.34。虚线框标出首个感受野，其元素集合为：

{1，-1，-1，-2}

在最大池化规则下，该位置计算结果为

`x'=max({1，-1，-1，-2})=1`

写入对应位置。

若换成平均池化，同位置输出应为：

`x'=avg({1，-1，-1，-2})=-0.75`

算完当前位置后，感受野像卷积那样按步长向右平移，得到

`x'=max(-1，0，-2，2)=2`

### 10.8　BatchNorm 层

卷积神经网络兴起后，几十层的网络成为可能，但在残差结构出现前，层数增加让训练变得不稳定，经常出现长时间停滞甚至不收敛，对超参数极度敏感，微小扰动就会改变训练轨迹。

2015 年，Google 研究员 Sergey Ioffe 等提出参数标准化的思路，并据此设计了 Batch Normalization，简称 BN[^(\[6\])](#chapter10.xhtml#jz_12_6)。BN 的引入让超参数设置更宽松，比如可以用更大的学习率、更随意的初始化，收敛更快、效果更好。BN 提出后迅速成为通用组件，卷积、BN、ReLU、池化的堆叠成为许多模型的标准模块。

先思考为什么要对网络内部数据做标准化。理论上很难讲透，BN 作者的解释也不一定让所有人信服。不如用具体问题来感受标准化带来的好处。

先看 Sigmoid 激活函数及其梯度分布，见图 10.39。Sigmoid 在 x∈[-2，2] 区间的导数落在 [0.1，0.25]；当 x>2 或 x<-2 时导数迅速趋近于 0，容易出现梯度弥散。为了避免输入过大或过小导致的梯度消失，把函数输入 x 映射到 0 附近的小区间变得关键。从图 10.39 可见，标准化重映射后数值集中在 0 附近，导数不会过小，梯度弥散风险降低。这是标准化利好之一。

- Layer Norm：统计每个样本的所有特征的均值和方差。
- Instance Norm：统计每个样本的每个通道上特征的均值和方差。
- Group Norm：将`c`通道分成若干组，统计每个样本的通道组内的特征均值和方差。

上面提到的 Normalization 方法均由独立的几篇论文提出，并在某些应用上验证了其相当或者优于`BatchNorm`算法的效果。由此可见，深度学习算法研究并非难于上青天，只要多思考、多锻炼算法工程能力，人人都有机会发表创新性成果。

### 10.9　经典卷积网络

自 2012 年`AlexNet`[^(\[3\])](#chapter10.xhtml#jz_12_3)提出以来，各种各样的深度卷积神经网络模型相继被提出，其中比较有代表性的有`VGG`系列[^(\[8\])](#chapter10.xhtml#jz_12_8)、`GoogLeNet`系列[^(\[9\])](#chapter10.xhtml#jz_12_9)、`ResNet`系列[^(\[10\])](#chapter10.xhtml#jz_12_10)、`DenseNet`系列[^(\[11\])](#chapter10.xhtml#jz_12_11)等，它们的网络层数整体趋势逐渐增多。以网络模型在 ILSVRC 挑战赛 ImageNet 数据集上面的分类性能表现为例，见图 10.42，在`AlexNet`出现之前的网络模型都是浅层的神经网络，Top-5 错误率均在 25%以上，`AlexNet`8 层的深层神经网络将 Top-5 错误率降低至 16.4%，性能提升巨大，后续的`VGG`、`GoogLeNet`模型继续将错误率降低至 6.7%；`ResNet`的出现首次将网络层数提升至 152 层，错误率也降低至 3.57%。

本节将重点介绍网络模型的特点。

#### 10.9.1　AlexNet

2012 年，ILSVRC12 挑战赛 ImageNet 数据集分类任务的冠军 Alex Krizhevsky 给出了 8 层的深度神经网络模型`AlexNet`，它接收输入为 224×224 大小的彩色图片数据，经过 5 个卷积层和 3 个全连接层后得到样本属于 1000 个类别的概率分布。为了降低特征图的维度，`AlexNet`在第 1、2、5 个卷积层后添加了`Max Pooling`层，见图 10.43，网络的参数量达到了 6000 万个。为了能够在当时的显卡设备 NVIDIA GTX580（3GB 显存）上训练模型，Alex Krizhevsky 把卷积层、前 2 个全连接层等拆开在两块显卡上面分别训练，最后一层合并到一张显卡上面，进行反向传播更新。ImageNet 上，AlexNet 取得了 15.3%的 Top-5 错误率，比第二名在错误率上降低了 10.9%。

[PRE51]

图 10.43　`AlexNet`网络结构[^(\[3\])](#chapter10.xhtml#jz_12_3)

`AlexNet`创新的点有：

- 层数达到了较深的 8 层。
- 采用了`ReLU`激活函数，过去的神经网络大多采用`Sigmoid`激活函数，计算相对复杂，容易出现梯度弥散现象。
- 引入`Dropout`层。`Dropout`提高了模型的泛化能力，防止过拟合。

#### 10.9.2　VGG 系列

`AlexNet`模型的优越性能启发了业界朝着更深层的网络模型方向研究。2014 年，ILSVRC14 挑战赛 ImageNet 数据集分类任务的亚军牛津大学 VGG 实验室提出了`VGG11`、`VGG13`、`VGG16`、`VGG19`等一系列的网络模型（见图 10.45），并将网络深度最高提升至 19 层[^(\[8\])](#chapter10.xhtml#jz_12_8)。以`VGG16`为例，它接受 224×224 大小的彩色图片数据，经过 2 个`Conv-Conv-Pooling`单元和 3 个`Conv-Conv-Conv-Pooling`单元的堆叠，最后通过 3 层全连接层输出当前图片分别属于 1000 类别的概率分布，见图 10.44。ImageNet 上，VGG16 取得了 7.4%的 Top-5 错误率，比`AlexNet`在错误率上降低了 7.9%。

[PRE52]

图 10.44　`VGG16`网络结构

`VGG`系列网络的创新之处在于：

- 层数提升至 19 层。
- 全部采用更小的 3×3 卷积核，相对于`AlexNet`中 7×7 的卷积核，参数量更少，计算代价更低。
- 采用更小的池化层 2×2 窗口和步长`s=2`，而`AlexNet`中是步长`s=2`、3×3 的池化窗口。
