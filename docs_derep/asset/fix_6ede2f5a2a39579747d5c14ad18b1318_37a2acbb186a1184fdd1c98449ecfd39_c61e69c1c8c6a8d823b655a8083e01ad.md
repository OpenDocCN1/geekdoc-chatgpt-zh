在角上首次接触时必然会让某个系数被压至零，这正是 L1 范数产生稀疏解的几何根源。向更高维推广后，除了顶点，约束边界上的棱边也常常成为与损失等值面最早相交的位置，稀疏的倾向随之被进一步放大。相比之下 L2 范数对应的单位球在 p=2 时是光滑圆盘，图 6-25 便呈现出这种形态。

圆形边界缺乏尖锐的角，使得最优解落在坐标轴附近的概率变得很低，这从几何上直观说明了 L1 正则化容易得到稀疏解而 L2 正则化不具备该特性的原因。

L2 范数实质上是对各分量先平方再求和后开平方根，虽不带来稀疏，却因数值特性更稳定而被广泛采用，在物理、统计等众多学科里同样常见。

[PRE0]

图 6-25　`L2`范数与损失函数等值线的交点

在机器学习里，L2 正则常被称作岭回归 Ridge Regression，也有人称作权值衰减 Weight Decay。它是遏制过拟合的主力手段之一。L1 也能起到一定抗过拟合作用，但若以压制过拟合为目的，L2 通常更为稳健，因为它更平滑、更温和。从泛化角度看，L2 比 L1 更利于预测：面对两个都有帮助的特征，L1 更倾向于保留其中较大的一个，L2 则倾向于让两者共同起作用。

总体而言，L1、L2 或其他形式的正则化都是在目标里加入惩罚项，使偏差与方差在最小化意义下取得平衡，从而遏制过拟合。正则化是一种通用思路，并非唯一途径，神经网络中的 Dropout 就是面向结构设计的一种不同风格的防过拟合技巧。

#### 6.6.9 优化算法

目标函数一旦确定，学习策略也就随之确定，剩下的工作是求出模型涉及参数的最佳数值，本质上是一个最优化问题。实践中绝大多数模型没有解析解，只能靠逐步逼近获得数值解；同时训练样本规模往往巨大，优化算法的选择直接决定能否高效逼近全局最优。

梯度下降本身在算力层面也有限制。理论上求梯度只需一阶导，但实际数据是不连续的样本点。若每次都用全部样本计算梯度，当样本量很大且学习速率较小时，计算成本很高。实践中常只用一个样本估计梯度，这就是随机梯度下降 SGD，全部样本参与的原始形式称为批量梯度下降 BGD。SGD 训练速度快，但梯度方向波动大，可能在最优点附近振荡；BGD 更稳定但慢。为兼顾速度与精度，常用小批量梯度下降 Mini-Batch Gradient Descent MBGD，每次用一小批样本更新。

梯度下降只是优化家族中的一种，适用于无约束优化。常见的还有最小二乘法、牛顿法和拟牛顿法。最小二乘法在线性问题下有解析解，本质是解线性方程组，但样本量很大时矩阵求逆困难，梯度下降的迭代收敛往往更实用。梯度下降、牛顿法、拟牛顿法都是迭代法，前者用梯度，后两者借助二阶海森矩阵的逆或伪逆。牛顿类方法收敛更快，但单次迭代成本更高。

#### 6.6.10 终极算法

模型参数求出后，建模流程就走完了：数据采集、预处理、特征选择、损失函数确定、欠拟合与过拟合处理，再到优化求解。读者或许会觉得每一步都有很大自由度，充满不确定性。机器学习看似智能，实操中却处处需要人工权衡。

本章开头曾问是否存在一种通用步骤，能一劳永逸地解决所有机器学习问题。现实是目前并无完美通用的学习算法，未来是否会出现也未可知。但这种对终极算法的向往一直存在。

1997 年，数学家 William Macready 与 David Wolpert 通过数理逻辑严格证明了没有免费的午餐定理 No Free Lunch Theorem：

假设所有问题出现的机会相等，即所有问题同等重要，那么无论学习算法 A 多聪明、算法 B 多笨拙，它们的期望性能都是相同的。

换句话说，若一个算法在某类问题上效率更高，就必然在另一类问题上表现更差，甚至低于随机猜测。脱离具体上下文谈算法优劣没有意义，没有绝对最好的终极算法，某些问题上表现优异的算法，在另一问题上一定不尽如人意。

没有免费的午餐定理并非否定算法研究，它成立的前提是所有问题同等重要，而现实中我们只关心真正要解决的问题。为了解决真实问题，往往需要多种模型与多种训练算法，在准确度、效率和存储之间做权衡。盲目崇拜某种算法，如沉迷深度学习，是需要警惕的。更重要的是深刻理解问题本身，因地制宜地制定策略。

### 6.7 评估验证

在机器学习领域，模型完成训练之后，还有最后一个必要步骤：对建立的模型进行性能评估 Evaluation，得到可量化的指标，判断模型和训练过程是否合理。这一套方法在传统统计学中已有成熟体系。

#### 6.7.1 性能度量

根据任务类型，性能度量指标各不相同。分类问题常用正确率、精确率 Precision、召回率 Recall 和 F1 分数；回归问题常用平均绝对误差、均方误差、标准差等，还有 F2 分数、可释方差分数等。

下面以邮件分类为例说明正确率、精确率和召回率的含义。假设测试集有效邮件 8000 封，垃圾邮件 2000 封，共 10000 封。目标是找出所有垃圾邮件。模型挑选出 5000 封判为垃圾邮件，经核实其中 2000 封确实是垃圾邮件，另外 3000 封是有效邮件被误判。

0-1 分类器的输出可分为四种：

1) 将垃圾邮件识别为垃圾邮件，称为真正 True Positive, TP。
2) 将垃圾邮件识别为有效邮件，称为假正 False Positive, FP。
3) 将有效邮件识别为垃圾邮件，称为假反 False Negative, FN。
4) 将有效邮件识别为有效邮件，称为真反 True Negative, TN。
