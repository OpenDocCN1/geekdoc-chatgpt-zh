先看解码器的前向入口。输入是目标序列、源序列和编码器已算好的上游特征。第一步把目标 token 投进词嵌入，再套位置编码，让模型感知顺序。随后构造两类掩码：解码器自注意力掩码用于屏蔽 padding，跨注意力掩码用于在解码器第二层注意力里对齐源侧信息。进入逐层循环，每层返回更新后的解码表示以及本层的自注意力和编码-解码注意力图，最后汇总所有层的注意力供可视化或分析。

整体模型把编码器、解码器和投影头串起来。编码器先把源输入映射成语义向量，解码器再在该向量基础上自回归生成目标。投影层把 d_model 维隐藏态压成词表大小的 logits，用于挑选概率最高的词作为预测。

import numpy as np

sentences = []

src_vocab = {'⊙': 0, '>': 1, '<': 2}  #这个是汉字vocab

tgt_vocab = {'⊙': 0, '>': 1, '<': 2}  #这个是拼音vocab

with open("../dataset/zh.tsv", errors="ignore", encoding="UTF-8") as f:

    context = f.readlines()

    for line in context:

        line = line.strip().split(" ")

        pinyin = line[1]

        hanzi = line[2]

        (hanzi_s) = hanzi.split(" ")

        (pinyin_s) = pinyin.split(" ")

        #[><]

        pinyin_inp = [">"] + pinyin_s

        pinyin_trg = pinyin_s + ["<"]

        line = [hanzi_s, pinyin_inp, pinyin_trg]

        for char in hanzi_s:

            if char not in src_vocab:

                src_vocab[char] = len(src_vocab)

        for char in pinyin_s:

            if char not in tgt_vocab:

                tgt_vocab[char] = len(tgt_vocab)

        sentences.append(line)
