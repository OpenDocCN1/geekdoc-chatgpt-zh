FastAPI 驱动的 MCP 情境管理实现

[PRE0]

启动后终端仅呈现 Uvicorn 依据日志等级产生的输出。程序本身不向标准输出推送业务结果，而是一种需要持续驻留的网络进程，只有在外部发起 HTTP 调用后才会返回对应数据。

[PRE1]

该实现以 FastAPI 为框架构建 Model Context Protocol 服务端，核心职责是集中管控模型相关的情境资料。持久化选用 Redis，内置了基于 API Key 的鉴权、调用计数以及健康探针等能力。

作为常驻进程，启动时会以 0.0.0.0:8000 绑定 Web 服务并保持监听，不会主动呈现业务数据。只有调用方借助 HTTP 访问预设接口后，才会返回对应内容。验证时可使用 curl、Postman 或常见请求工具发起请求。

class MCPContext:

    """上下文对象封装"""

    def __init__(self, context_id: str, model_id: str, data: Dict[str, Any], created_at: str):

        self.context_id = context_id

        self.model_id = model_id

        self.data = data

        self.created_at = created_at

    def __str__(self):

        return f"MCPContext(id={self.context_id}, model={self.model_id})"

class MCPStats:

    """服务统计信息对象"""

    def __init__(self, stats_data: Dict[str, Any]):

        self.total_contexts = stats_data.get("total_contexts", 0)

        self.active_models = stats_data.get("active_models", [])

        self.avg_context_size = stats_data.get("avg_context_size", 0)

        self.uptime = stats_data.get("uptime", 0)
