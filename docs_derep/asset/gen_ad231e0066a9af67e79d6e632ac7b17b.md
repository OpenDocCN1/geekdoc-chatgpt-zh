# 第1章 智能体概述
大模型爆发前，智能体的功能和体验受AI技术制约，“大脑”不够聪明。如今大模型在生成、计算与逻辑推理上实现跃升，AI Agent也随之成熟并火热。本章介绍Agent背景，帮助读者建立一般性认知。

## 1.1 为什么需要一个智能体（Agent）
为突出当前Agent对大模型能力的依赖，常称之为AI Agent或人工智能体，也有文献直译为AI代理。业内通常统一译为智能体。

在信息技术高速演进下，智能体与DeepSeek大模型成为焦点，“智能体+DeepSeek”有望开启下一个IT浪潮。

### 1. AI的发展历程
讲清智能体概念需先了解人工智能基础。AI是通过程序模拟人类智能的技术，可执行学习、推理、规划、自然语言处理等任务。自上世纪50年代概念提出以来，经历多次突破。

发展大致分三阶段：
- (1) 初期发展阶段（20世纪50年代—20世纪70年代）：研究聚焦符号主义和逻辑推理。艾伦·图灵提出图灵测试，1956年达特茅斯会议确定“人工智能”概念，被视为起点。
- (2) 早期发展阶段（20世纪80年代—20世纪90年代）：专家系统成为主流，通过编码专家知识解决特定问题，取得成效但也暴露知识获取难和系统僵化问题。
- (3) 现代发展阶段（21世纪—）：计算与数据爆发推动机器学习尤其是深度学习崛起。AI从依赖规则转向数据训练，图像识别、自然语言处理、自动驾驶等复杂任务得以实现。

### 2. Agent能解决什么问题
大语言模型是近年AI的重要突破，基于海量文本训练，可实现总结、翻译、情感分析等任务。特点是基于神经网络与自然语言处理，多轮对话与写作能力突出。像GPT-4这样的模型在文本生成与理解上堪称“语言魔法师”，可适应多种场景。模型能生成高质量自然语言文本，宛如永不枯竭的写作助手。

既然已有DeepSeek、GPT、豆包等大模型，为何还要Agent，这只是概念营销吗？

举例：让大模型生成一部100万字的武侠小说。若直接提问，模型往往写不出所求字数也无法满足预期。并非模型不强，而是缺少关键步骤：无法借助搜索引擎获取最新外部信息；缺乏整体规划能力，如先列大纲再分章撰写再讨论完善；缺乏记忆能力，受上下文长度限制，前后容易脱节。

人类处理这类任务的常规流程是：先搜索相关资料打开思路，形成大纲并规划各章节内容，分章撰写并在过程中调整大纲，编写后续章节时回溯前面内容，初稿完成后请专业人士修改审阅，反复调整后定稿。

大模型直接完成存在短板：训练数据有时间限制，难以实时检索；缺乏任务规划；上下文窗口有限，无法承载百万字连贯创作。正是这些缺口催生了智能体。
