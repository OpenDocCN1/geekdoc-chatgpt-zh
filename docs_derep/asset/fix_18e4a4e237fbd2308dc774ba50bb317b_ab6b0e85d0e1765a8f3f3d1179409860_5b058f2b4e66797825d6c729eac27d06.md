### 14.9.3 Prestissimo

发布时间：2017年11月。
主推团队：九言科技。
代码仓库：见参考链接[3]。

核心能力概述。
①基础能力。
a. 可承载卷积神经网络，兼顾多输入与多分支结构。
b. API 设计精炼易用，上手成本低。
c. 提供调试入口，可输出各层的中间数据与耗时。
d. 不依赖第三方计算库，整体包体约500KB，32位约400KB，64位约600KB。

f. 模型为纯二进制，不暴露网络结构细节。

a. 从框架设计到汇编实现都做了全向优化，iPhone7 上跑 SqueezeNet 单线程仅需 26ms。

c. 内存排布经过优化，提升 CPU 缓存命中率，中低端机型依然强劲。
针对 float-arm32、float-arm64、int-arm32、int-arm64 四条分支均做细调，32 位与 64 位 ARM 都有不错表现。

### 14.9.4 MDL

（1）全称：Mobile-Deep-Learning。
（2）发布节点：2017年9月，已停止更新。
（3）主推方：百度。
（4）代码仓库：见参考链接[4]。
（5）核心能力。
一键部署，通过脚本参数即可切换 iOS 或 Android。
支持 iOS GPU 运行 MobileNet、SqueezeNet。
经验证可稳定运行 MobileNet、GoogLeNet-v1、SqueezeNet、ResNet-50。
包体极小，无第三方依赖，手工打造。
提供量化函数，支持 32bit float 转 8bit uint，量化后模型约 4MB。
与 ARM 算法团队多次沟通，持续针对 ARM 平台优化。
NEON 覆盖卷积、归一化、池化等全流程操作。
汇编层面针对寄存器做专项优化。
循环展开减少冗余判断，降低 CPU 消耗。
大量重计算前置到 overhead 阶段。

（6）框架结构。
[PRE0]
图14-27 MDL框架结构
MDL 框架主要包括模型转换模块 MDL Converter、模型加载模块 Loader、网络管理模块 Net、矩阵运算模块 Gemmers 以及供 Android 调用的 JNI 接口层 JNI Interfaces。
模型转换模块负责把 Caffe 模型转为 MDL 模型，并可将 32bit 浮点参数量化为 8bit；模型加载模块完成反量化、校验与网络注册；网络管理模块负责各层初始化与管理；JNI 接口层让开发者便捷完成加载与预测。

（7）性能与兼容性。
速度方面，iOS GPU 下 MobileNet 可达 40ms，SqueezeNet 可达 30ms。从立项到开源，体积、功耗、速度等移动端关键指标表现良好。百度内部对比显示 MDL 在保持高速低功耗的同时支持 MobileNet、GoogLeNet-v1、SqueezeNet 等模型，并提供 iOS GPU 版本，SqueezeNet 单次运行约 30~40ms。
兼容性上，MDL 可在 iOS 与 Android 稳定运行，iOS 10 及以上提供 GPU API，性能突出；Android 端为纯 CPU。覆盖高、中、低端机型，适配情况优于手机百度等 App。
MDL 支持直接把 Caffe 模型转换为 MDL 模型。
