## 1.4 提示词实战指南

在DeepSeek中，提示词是人与模型沟通的桥梁。掌握好提示词的编写方法，能显著提升使用效率并获得理想结果。

### 1.4.1 什么是提示词

提示词即用自然语言向DeepSeek下达的指令或任务。可以是简单提问，如“今天北京天气怎样？”也可以是复杂创作需求，如“请为我写一首关于春天的诗”。

用户通过清晰表达需求，DeepSeek借助自然语言处理与深度学习能力快速生成对应回答或内容。简言之，提示词就是告诉模型你要它做什么。用自然语言准确表达，模型就能更好地理解并执行。熟练运用提示词，能让信息获取、内容创作、任务执行都更高效便捷。

### 1.4.2 对话为何容易跑偏

交流看似简单，实操中却常出现“鸡同鸭讲”。用户提问后得到与预期不符的答案，以下是常见原因及解决思路。

#### 一、表达不够清晰明确
提问模糊、语义不清时，模型难以把握意图，易答非所问。如存在歧义词、指代不明或逻辑混乱等。

·示例：用户问“怎么写好文章？”
·DeepSeek可能给出“多读多练”等笼统建议，缺乏针对性。
·原因：未限定场景、受众、目标。
·解决：采用“角色+任务+细节”结构，例如“我是一名大学生，需写一篇关于‘AI伦理’的课程论文，要包含3个案例并用通俗语言解释技术风险，请给出框架和参考文献筛选建议”。

#### 二、上下文理解受限
多轮对话中，模型对上下文的记忆与理解存在局限，可能导致回答与前文不一致或无关。原因在于上下文处理机制的限制，或信息过长超出处理能力。

·示例：用户先说在学编程，后问编程语言选择，模型可能推荐过于高级或不相关的语言。
·解决：适当重复关键上下文信息，帮助模型更好记忆。也可将复杂对话拆分为若干简单轮次，避免信息过载。

#### 三、训练数据存在局限
模型基于海量文本训练，若某些专业小众领域数据不足或质量不高，回答可能宽泛不准。如量子计算最新纠错编码在医疗影像中的应用等交叉前沿话题。

·示例：询问“量子计算纠错编码在医疗影像的潜在应用”时，模型可能给出泛泛而谈的内容。
·解决：可逐步引导，先问基础概念，再问应用案例，最后结合具体领域提问。模型开发者也需持续扩充高质量多领域数据。

#### 四、知识更新滞后
训练数据有时间边界，对训练后出现的新事件、新知识捕捉不到，回答易过时。

·示例：询问刚发布的热门新品，模型可能只给出旧产品信息。
·解决：开启“联网搜索”获取最新信息。

模型本身的局限可暂时搁置。用户应学会构建精准提示词并善用功能，才能把“答非所问”变为“精准应答”。

### 1.4.3 写出高命中提示词

优质提示词能让模型更准确理解意图，提升交互效率；劣质提示词则浪费时间且难以得到期望结果。

#### 一、提示词组成结构
提示词 = 任务描述 + 参考信息 + 关键词 + 要求。

1. 任务描述：清晰说明想让模型完成什么。
2. 参考信息：提供背景资料或上下文，帮助模型更好理解。
3. 关键词：点明模型需关注的核心信息或问题。
4. 要求：列出字数、格式、语言、风格、情感色彩等特殊限制。可补充角色设定、示例等。

#### 二、不佳提示词示例

| 提示词 | 问题所在 |
| :--- | :--- |
| 生成一篇文章 | 缺乏关键信息，模型不知写何种文章 |
| 阅读这篇文章并给出意见 | 未说明具体任务和期望输出形式 |
| 讨论AI的风险 | 问题过于宽泛，输出易空泛 |
| 生成一张图片 | 未说明图片内容或类型 |
| 写一段对话 | 缺少背景与主题，无法确定方向 |

#### 三、优质提示词示例

·任务描述：生成一段对话，探讨环保重要性与可行性，并提出方案。
·参考信息：环境问题包括气候变化、污染、资源浪费。
·关键词：环保、气候变化、污染、资源浪费。
·要求：对话至少两位参与者，每人至少提出两个方案，总字数500~800字。

整合后提示词：
生成一段对话，讨论环境保护的重要性和可行性并提出方案。对话中需有两位及以上参与者，每人提出至少两个环保方案。同时详述环境保护、气候变化、污染、资源浪费等议题并给出不同观点。请控制总字数为500~800字。

### 1.4.4 写出好提示词的9个技巧

#### 一、使用明确语言
避免含糊或歧义表述。可在提示词中明确指定输出语言，如“请用中文回答”。清晰的语言有助于模型精准响应。

#### 二、说明输出形式
通过指定形式引导输出，如“请以表格形式呈现”。便于掌控结构，符合需求。

#### 三、使用标签指导对话
标签可限定主题或任务范围，让模型聚焦。例如主题型：

请创作一篇科幻短篇小说，描写高度发达科技城市的生活、景观与挑战。

# 未来科技城市

任务型：

# 网络搜索

请搜索“2025年最新科技趋势”，并总结前三个主要趋势。

使用标签后仍需审校结果以确保准确。

#### 四、限制字数或格式
用字数限制控制长度，如“请写一篇关于环保与可持续发展的短文，500字以内，需涵盖问题严峻性、环保意义及个人与社会可采取的行动”。

#### 五、用引号强调关键词
引号可突出重点词，引导模型关注，如“分析当前市场上最受欢迎的‘智能家居’产品及其主要特点”。

#### 六、提供模板供参考
提供模板可精确控制输出结构，如设计简历模板，模型即可按格式填充。
