2026 年年初，OpenClaw 一跃成为开源社区的热点。它的定位是能直接操作电脑和手机、在本地运行并独立完成真实工作的数字同事，和只能闲聊的传统模型相比，它可以读取邮箱、维护日历、驱动浏览器、批量处理文档等实操类任务。

项目强调本地优先、数据不出域的原则，支持在 WhatsApp、Telegram、飞书、钉钉、QQ 等即时通讯平台上交互，并拥有可扩展的技能生态。

到 2026 年 2 月，其 GitHub Star 在四个月内突破 25 万，超过 Linux、React 等长期领跑项目，成为当时增长最快的开源项目之一，如图 6.1 所示。

#### 6.1.2 三者的协作关系解析
此前已分别介绍扣子的运行方式、飞书的协作能力以及 OpenClaw 的基本概念，下面把三者的架构与协同机制串起来，帮助明确学习路径。

OpenClaw 本质上是一个具备自主要决策能力和持久记忆的开源智能体框架。它可以在本地或云端作为自动化引擎持续运行，维护跨会话的长期记忆，并自主编程与任务规划。

不过作为开源项目，原生部署通常需要服务器与环境配置，对普通用户门槛较高。

此时扣子承担了云原生底座的角色。凭借扣子提供的编程沙箱，OpenClaw 能实现一键云端部署，用户无需关心底层服务器。扣子还内置了大语言模型、联网检索、图像生成等工具插件，为 OpenClaw 提供必要的能力支撑。

概括来说，扣子是运行环境与工具链的整合平台，OpenClaw 则是运行于其上执行具体任务的智能引擎。

飞书则负责 się人机交互的入口。在整合方案中，飞书不再仅是协同办公工具，而是向智能体下发指令的控制终端。用户无需进入扣子后台，只需在飞书群聊或私聊中向 OpenClaw 发出指令即可。

任务完成后，OpenClaw 会把结构化结果回传至飞书会话，并可自动通知相关人员或更新飞书文档。

需要说明的是，在这种架构下 OpenClaw 运行于云端而非本地，会丧失操作本地文件、修改本地参数等功能。

理清逻辑后可以类推，扣子平台可替换为腾讯、阿里等同类平台，飞书也可换成钉钉、QQ 等通讯软件。

#### 6.1.3 为何迅速走红
要解释热度原因，先要区分它与传统 AI 助手的本质差异。

传统 AI 助手本质是对话系统，用户发出指令，模型返回回答，流程结束。即便能力很强，它始终无法直接介入用户的工作流，这是应用层面的核心瓶颈。

OpenClaw 把自己定义为 AI Agent，关键特征是具备自主执行力。

功能上看，传统助手能回答问题、生成文案，但网页搜索需要额外插件，读写文件、发送邮件、操控浏览器、定时执行任务都不可行，记忆也仅限短时对话。OpenClaw 在这些维度均可实现：搜索可自动完成、读写文件可行、邮件发送可行、浏览器可操控、定时任务可行，且具备永久记忆。

OpenClaw 让大家意识到，人工智能不仅能答疑，还能真正动手干活，从而大幅提升生产效率，这就是热度爆发的根本原因。

#### 6.1.4 核心架构拆解
OpenClaw 的核心架构可类比计算机操作系统，正如操作系统管理硬件、调度进程、控制权限一样，OpenClaw 在智能体层面完整复现了这一逻辑。

Gateway 网关相当于操作系统内核，是系统的大脑，统一管理所有功能模块、交互渠道与任务调度。

Session 会话则对应进程的概念，每一次独立对话都拥有专属状态、生命周期和上下文，保证不同场景的交互互不干扰。

#### 6.1.5 个人使用的价值
传统 AI 工具上手成本高，用户需要掌握复杂提示词、理解 API 调用，还要有一定技术背景才能发挥效果。

OpenClaw 通过产品设计大幅降低了门槛。用户只需像发微信一样告诉它想做什么，系统会自动解析需求、调用工具、执行任务并返回结果。

这种单句触发工作的体验，让 AI 从技术人员的专用工具，变成普通人也能便捷使用的办公与生活助手。

另一个重要价值是高度可定制。用户可以通过 SOUL.md、MEMORY.md 等配置文件定义 AI 的人格、语气、专业领域和知识背景，让助手真正“懂你”。这种个性化让每个人的 OpenClaw 都能贴合自己的工作方式和内容偏好。

#### 6.1.6 如何真正发挥效用
大多数普通用户安装 OpenClaw 的目的是提效，提升效率的最佳路径不是研究架构或学编程，而是成为高效的 Skill 搜寻者与组装者。

OpenClaw 的真正强项在于开放的 Skill 生态，可理解为一个庞大的数字工具箱，里面已备好处理各类专业任务的现成模块。用户只需明确“我要做什么”，找到并安装对应 Skill 即可完成工作。

比如处理数据与信息整合，可搜索安装智能表格分析、PDF 内容提取、网页数据抓取等 Skill。配置好后，在飞书里发一句“整理这份销售报表的关键趋势”，OpenClaw 就能自动完成数据清洗、图表生成与结论提炼，无需手动复制粘贴或学 Excel 高级函数。

再如内容创作，可安装爆款标题生成、长文结构化改写、多平台文案适配等 Skill，让 OpenClaw 基于一份长报告生成适配微信公众号、小红书、微博等不同风格的短文案，还能自动排版，甚至直接投递到公众号草稿箱。

建议养成习惯：遇到重复性工作先问自己 Skill 能否代劳，再把寻找某类 Skill 的任务交给 OpenClaw，它会列出相关选项。熟悉 3~5 个常用 Skill 后，可尝试串联成工作流，例如网页抓取 Skill→内容摘要 Skill→飞书通知 Skill，形成每日自动推送行业早报的自动化链条。

OpenClaw 让普通人可以用更低的学习成本，掌握过去需要精通提示词与参数配置才能使用的强力 AI 工具。

#### 6.1.7 新手入门指南
OpenClaw 本质上是为 AI 装上双手，使其不再局限于聊天框的文字游戏，而是能查资料、调接口、管理任务、操作外部工具的助手。

对刚入门的小白来说，不要一开始就追求复杂的技能组合，先建立工具思维：先梳理日常工作或学习中最重复、最耗时的环节，比如每日新闻摘要、批量表格处理、定时网站追踪，再把这些需求转化为 OpenClaw 可理解的 Skill 指令。

建议从官方现成 Skills 开始，像搭积木一样跑通一个简单的自动化流程，感受单句触发一串动作的效果。熟悉接口调用逻辑后，再用自然语言让 OpenClaw 帮你生成或组合新技能。

调试时保持耐心，每次报错都是理解工具边界的机会，大多数问题只是参数没对齐或权限未开启。OpenClaw 的价值在于能否无缝嵌入你的具体场景，不必急于追求全自动化，先让 AI 每天帮你省下半小时，就是成功的开始。

### 6.4 为 OpenClaw 安装 Skills 技能包
飞书接入后，OpenClaw 可支持基础对话与简单指令，但要处理多步骤任务、联动工具或执行专业操作，还需通过 Skills 机制扩展，本节介绍安装与配置方法。

简单说，Skills 是赋予 OpenClaw 执行特定复杂任务、调用多种工具或处理专业领域操作的能力模块。

目前可通过三种方式安装：按 Skills 名称或网址安装、通过压缩包安装、通过 find-skills 自动搜索，下面分别说明。

#### 6.4.1 按名称或网址安装 Skills
当已知所需 Skills 的名称或网址时，可直接在飞书对话中说明安装需求。例如发送“self-improving-agent, skill-creator, find-skills和skills-vetter和automation-workflows检查这些Skills有没有安装，没的话，装”，OpenClaw 会先检查是否已安装，如图 6.25 所示。若未安装则自动开始安装，完成后返回结果。
