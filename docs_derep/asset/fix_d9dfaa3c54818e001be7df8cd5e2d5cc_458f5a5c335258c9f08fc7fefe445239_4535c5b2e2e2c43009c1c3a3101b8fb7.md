# 长文本问答想要又准又全？试试层级切分加智能回填

处理城市介绍这类长文档时，往往既想要精准的细节，也需要上层的背景。一种可行的打法是先做层级化切分，再在最细的层做向量检索，最后根据命中结果把父层信息自动补回来。下面以南京的文本文件为例子，把整条链路过一遍，再补一个轻量的主题打标签环节。

先把原始 txt 读进来，用一个能产出三层结构的解析器把内容拆开。最粗的一层控制在 2048 左右，中间层 512，最细层 128，窗口不做重叠。这样既能保留大段的语义骨架，也能拿到可检索的细碎片段。解析完成后可以数一下总节点数，必要时用工具把最细层和最粗层的数量分别看一遍，确认结构合理。

把所有产出的节点先统一写入文档仓库，Chroma 这边建一个叫 auto_retrieve 的集合作为向量存储。向量索引只搭在最细的层上，检索器取相似度第一名。随后在该检索器外部包一层合并式检索，打开日志并把合并阈值设到 0.1，这样细层命中后会顺着父链往上回填，给出更完整的语境。

catalog_prompt_temp = """\n你是一个聪明的内容分类器。请把我的内容归类到以下类别之一:

-------

基本

历史

经济

文化

交通

旅游

其他

-------

我的内容是: {text}

直接输出类别，不要有多余说明。

"""

catalog_prompt = PromptTemplate(catalog_prompt_temp)

# 构造简单的函数生成一个元数据

def get_catalog(text: str):

    catalog = llm.predict(

        catalog_prompt, text=text

    )

    return catalog

# 定义一个用于数据摄取的转换器，把这个元数据插入 Node 中

class MetadataRicher(TransformComponent):

    def __call__(self, nodes, **kwargs):

        for node in nodes:

            node.metadata["catalog"] = get_catalog(node.text)

        return nodes
有了主题标签后，可以把切分与打标封装成摄取管线。这里用 500 字的句子切分器做分块，后面接上刚才的打标组件。第一次执行时把索引写到 ./storage/vectorindex/autoretrieve，后续直接加载持久化文件，避免重复计算。

def create_vector_index():

    if not os.path.exists(f"./storage/vectorindex/autoretrieve"):
