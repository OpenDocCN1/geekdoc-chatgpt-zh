◎ 分布式哈希表：利用哈希函数把数据分散存放到多个节点，既能降低单点压力又可实现快速查找，特别适合大规模分布式系统的数据治理需求。

◎ 群体智能：以粒子群优化、蚁群优化为代表，通过模仿生物群体的行为规律，让 Agent 群体在复杂环境中自发组织并做出自适应共识决策，广泛应用于优化求解和路径规划等任务。

总体来看，不同的通信协议与共识算法各有适用边界，依据场景和系统目标进行合理选型与设计，是构建高效可靠多 Agent 系统的关键所在。

## **7.2 竞争场景的博弈策略**

在多 Agent 竞争情境下，博弈策略指的是 Agent 为实现自身利益最大化而制定的行动方案，通常依赖于对其他 Agent 行为的预测与响应。常见的策略形态包括合作型、竞争型以及混合型。不同策略在不同竞争环境和目标下表现各异，Agent 需要根据实际状况做出选择与调整。

### **7.2.1 纳什均衡与博弈论框架**

在多 Agent 系统中，纳什均衡与博弈论模型是分析与设计行为的重要工具。纳什均衡描述的是非合作博弈中一种稳定状态：每个 Agent 在其他 Agent 策略不变的前提下均已选择最优策略。达到该状态后，任何一方单方面改变策略都无法获得更高收益。

**1． 纳什均衡概念**
纳什均衡亦称非合作博弈均衡，是博弈论中的核心术语，得名于约翰·纳什。在博弈过程中，若在其他参与者策略确定的情况下，某参与者所选策略为其最优，则该策略组合即为纳什均衡。此时各参与者均在对方策略下实现期望收益最大化，无单方面偏离的动机。

（1）分类。
依据策略是否包含随机性，可划分为两类。

◎ 纯策略纳什均衡：所有 Agent 采用确定性策略，如“坦白”或“抵赖”，且无人有偏离动机。例如在“囚徒困境”中，双方均选择“坦白”即构成纯策略纳什均衡。

◎ 混合策略纳什均衡：Agent 采用随机化策略，使对手难以获利。例如在“硬币博弈”中，双方以 50% 的概率选择“正面”或“反面”，即达到混合策略纳什均衡。

（2）对多 Agent 系统的启示。
◎ 非合作博弈的典型困境：Agent 独立决策时容易陷入次优解，如双方均坦白，而非合作的帕累托最优是双方均抵赖。
◎ 个体理性与集体理性的矛盾：需借助外部机制如通信协议或共识算法来引导 Agent 走向协作。

（3）在多 Agent 强化学习中的应用。

## **7.3 复杂环境中的群体智能**

复杂环境中的群体智能指在动态、不确定且高度复杂的环境里，由多个简单个体通过局部交互和自我组织展现出的集体智能。这种集体行为能够让群体在复杂任务中实现高效资源分配、适应性决策和问题求解。例如机器人协作、智能交通、分布式优化等领域，群体智能可有效应对环境变化。

### **7.3.1 群体路径规划与资源分配**

多 Agent 系统中的群体路径规划与资源分配是复杂协同任务的核心挑战，需结合协作机制、环境建模与优化策略来实现高效安全协同。

**1． 群体路径规划**
多 Agent 路径规划 Multi-Agent Path Finding, MAPF 的目标是为多个 Agent 找到从起点到终点且无冲突的最优路径集合。该问题在物流、军事、安防等领域应用广泛。根据最优性，多 Agent 路径规划算法可分为最优算法与近似算法两类，如图 7-9 所示。
[PRE19]
图 7-9 多 Agent 路径规划算法的分类

近年来基于学习的 MAPF 算法备受关注，主要分为结合专家经验的算法和基于图神经网络的算法。例如 PRIMAL 算法融合强化学习与模仿学习，能在部分可观测网格环境中实时规划路径并展现良好协同。PRIMAL-lifelong 在此基础上扩展，当 Agent 完成当前目标后，系统会分配新目标并通过识别有助于提升整体协同的方式优化学习效果。

**2． 资源分配**
在多 Agent 系统中，资源分配旨在提升资源使用效率，保证系统高效运行。可分为静态资源分配与动态资源分配。

（1）静态资源分配。
◎ 集中式资源分配：由中心节点或控制 Agent 统一管理，适用于任务明确、环境相对稳定的场景。
◎ 分布式资源分配：各 Agent 依据自身需求与环境信息自主决策，适用于环境动态变化的场景。

（2）动态资源分配。
◎ 基于博弈论的资源分配：利用博弈论模型如纳什均衡优化分配策略。
◎ 基于强化学习的资源分配：借助 DQN、策略梯度等算法动态调整分配策略。

在实践中，资源分配需结合任务需求与环境特点。例如智能交通系统中，多路口信号灯 Agent 需根据实时车流量动态调整时长以优化整体通行；在云计算环境中，多计算节点 Agent 需按任务负载动态分配算力，提升整体性能。
