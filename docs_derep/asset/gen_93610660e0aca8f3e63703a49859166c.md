# 2. 属性图模型

属性图可以说是当前图数据库领域采纳度最高的数据模型之一[3]。它由节点集合与边集合构成，并满足以下特征：

+   (1) 每个节点都拥有唯一的标识；
(2) 每个节点都关联若干条出边；
(3) 每个节点都关联若干条入边；
(4) 每个节点都携带一组属性，属性为键值对形式；
(5) 每条边都拥有唯一的标识；
(6) 每条边都指向一个头节点；
(7) 每条边都源自一个尾节点；
(8) 每条边都带有标签来描述关系类型；
(9) 每条边都携带一组属性，属性为键值对形式。

# 3. Gremlin 概览

Gremlin 是 Apache TinkerPop 图计算框架[21]提供的属性图查询语言[22]。Apache TinkerPop 定位为访问图数据库的通用 API，相当于关系数据库上的 JDBC。Gremlin 本质是图遍历语言，其执行像是一个人在图中沿有向边一步步导航。这种方式要求用户明确导航步骤，类似自驾需要知道路线，因此归为过程式语言，能够清晰感知当前位置与到达路径，但门槛在于“要懂路”。与 SPARQL、Cypher 的声明式风格不同，Gremlin 更偏向函数式编程接口。下面以 g 代表图 3-3 的属性图举例。
