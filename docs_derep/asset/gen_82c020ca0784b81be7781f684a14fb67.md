# 第2章 用AI实现选题发掘

从各层级课题申报公告来看，绝大多数都发布了申报指南，指南中的选题通常分为具体条目和方向性条目两类。对具体条目，申请人可从不同角度、方法与侧重点切入，也可以在文字上做适当调整或直接沿用该条目申报。方向性条目仅限定研究范围与方向，申请人必须据此自行拟定题目，不能把条目原句作为课题名称。2023年国家社会科学基金项目申报指南新设的综合性选题就属于方向性条目，而各学科的具体选题则类似具体条目，可直接使用或适当修改。以下以2023年国家社会科学基金年度项目为例，说明如何围绕指南借助AI挖掘拟申报课题。

## 第一节 用AI挖掘综合性选题方向

综合性选题只界定研究主题、范围与方向，申请人须基于要求，自不同学科、不同视角拟题申报，不得直接使用原条目作为题目。申报时需明确一个主要学科。针对综合性选题，可采用整体性提问与针对性提问两种方式，从综合性选题中提炼与自身学科相关的微观题。

### 一、SRGCD模型整体提问找综合性题目

课题申报属于AI的高端应用场景，使用时需综合多种提问模型以提升质量。

SRGCD模型即“情境-角色-目标-条件-调试”模型，要求提问时设定明确情境、为AI设定角色、指明目标、给出指向性条件并通过多次调试获得启发性答案。

以2023年度国家社会科学基金综合选题第21条为例说明整体性提问的方法。

参考选题：21. 中国式现代化进程中的共同富裕问题研究

> 提问模板：我是一名高校教师，已工作【填写年限】，职称是【填写职称】，目前【未承担/正在主持】【某级别】课题，【参与/主持过教育部课题，围绕某主题】，专业是【填写专业】，研究方向是【填写方向】，来自【高校/科研机构/其他】，请你扮演课题同行评议专家。我正准备申报【国社科/教育部人文社科/某省社科规划】的【年度重点/一般/青年】项目，需要你的指导。指南中有综合性选题，其中【指南具体条目】我很感兴趣，但综合性选题只明确主题范围方向，需申请人自拟题目申报，不能直接使用。请结合我的专业、研究方向、研究基础，我可以申报哪些具体题目？

解析：该提问为AI设定了同行评议专家角色，设定了为申请人提供指导的情境，设定了综合性选题的条件，设定了结合个人背景给出建议的目标。为获得更有价值的回答，需尽可能详实提供个人专业、方向、研究基础等信息。

示例提问：

我已工作10年，职称副教授，目前未承担国家级课题，但主持过省级社科规划项目，主要围绕××市非遗保护与传承展开，研究专业是新闻传播学，研究方向是文化传播，来自××大学。请扮演课题同行评议专家。我拟申报国社科年度一般项目，指南综合性选题中第21条“中国式现代化进程中的共同富裕问题研究”我很感兴趣，但综合性选题不能直接作为题目。请结合我的专业、方向和基础，推荐哪些具体题目？

示例回答给出了从文化传播视角切入的六个题目方向，如新闻传播视角下的共同富裕报道内容分析、中国式现代化进程中文化产业发展与共同富裕研究等，并提示可结合自身基础选择并进一步细化。

根据国社科要求，课题题目不得使用副标题、不能出现冒号，遂进行调试。

调试提问：课题题目不能出现副标题，请重新列出不含副标题的题目。

调试后回答给出十个不含副标题的题目，如“中国式现代化进程中文化产业的发展与共同富裕问题研究”“基于社交媒体的中国式现代化进程中的共同富裕问题研究”等，并提醒后续需细化目标方法。

AI回答较为宽泛，需要进一步追问。总结的追问模板为：我的研究方向为【方向】，研究兴趣为【兴趣】，研究基础是【课题和论文等，越详细越好】。请结合我的方向、兴趣、基础，以及【项目级别】要求的【具体要求】，对上述选题再细化。

沿用案例追问：研究方向是文化传播，研究兴趣是非遗数字化呈现与传播，研究基础是主持××市社科规划项目“京剧脸谱的数字化再造及数据库建设”和校级课题“××市大学生数字素养提升路径研究”。请结合国社科要求聚焦党和国家事业发展的重大理论现实问题，对选题再细化。

回答列出十个围绕非遗数字化的题目，随后指出这些题目偏离了“中国式现代化进程中的共同富裕问题”的限定，再次调试要求结合该综合性选题重新建议，得到将数字技术助力非遗与共同富裕结合的六个建议。

小结：SRGCD整体提问能提供一定启发，但若要更精准，还需结合选题类型进行针对性提问。

### 二、按选题类型定向提问更精准

针对综合性选题，SRGCD提问能给出启发但不够精准。基于选题类型的针对性提问，先认识课题题目构成，再据不同类型提问。

通过对历年国社科立项题目分析可知，题目一般由限定词、研究对象、研究问题组合而成，研究对象和研究问题必现，限定词不一定出现但多会体现。好的限定词体现创新性。

限定词可从时间、地点、范围、情境、理论等维度限定研究对象，使题目更聚焦，也体现视角、创新、方法与价值。

据此可将题目分为“新情境+研究对象+研究问题”型、“新理论+研究对象+研究问题”型、“新理念/思想+研究对象+研究问题”型、“新区域+研究对象+研究问题”型、“新方法+研究对象+研究问题”型、“新模型+研究对象+研究问题”型、“新学科+研究对象+研究问题”型、“新技术+研究对象+研究问题”型和“新对象+研究问题”型等。

#### （一）“新情境 + 研究对象 + 研究问题”型

情境指事件、现象所处的背景环境，包含时间、地点、文化、社会、经济等多重因素，是理解问题的关键。

2022年国社科立项题目示例：

1. 企业产品研发情境下知识协调的底层机理及优化模型研究。
2. “双碳”目标情境下我国碳审计协同机制研究。
3. 立体开发情境下三维土地产权范式及其实现机制研究。
4. 数字化情境下生产性服务业与制造业融合的模式、机制与策略研究。
5. 城市高质量发展情境下我国村改居社区融合性治理的实现路径研究。
6. 基于异构不确定情景的应急物资储备与供应体系规划研究。
7. 旅游式学习背景下博物馆服务管理模式创新研究。
8. 全球化语境下的罗伯特·潘·沃伦诗歌研究。
9. 全媒体时代“三国文化”英译模态重构与多维传播模式研究。

这些题目均立足新情境，有的用“情境”“情景”“背景”“语境”“时代”等词表达，体现创新发现。

为让AI理解该类型，先做类型输入。

提问：

2022年国社科有以下立项题目：企业产品研发情境下知识协调的底层机理及优化模型研究；“双碳”目标情境下我国碳审计协同机制研究；立体开发情境下三维土地产权范式及其实现机制研究；数字化情境下生产性服务业与制造业融合的模式、机制与策略研究；城市高质量发展情境下我国村改居社区融合性治理的实现路径研究；基于异构不确定情景的应急物资储备与供应体系规划研究。这些属于“新情境+研究对象+研究问题”型，请问其特点是什么？

回答指出共同点是以新情境为起点，结合对象与问题，研究新情境下的社会议题，探讨机理、模式、策略，强调理论实践结合，应用价值强，具有时代性与前瞻性，与政策导向密切相关。

解析显示AI已接受该类型，概括为以新情境为起点研究新问题，理论实践并重，时代感强，创新在于对新情境的关注。

提问：选择“新情境+研究对象+研究问题”型选题，通常要求申请人具备哪些能力和要求？

回答：
