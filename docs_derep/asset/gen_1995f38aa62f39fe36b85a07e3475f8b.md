# 第2部分 基础篇

## 第2章 智能体入门：零基础构建指南

智能体搭建是一项融合技术与场景的系统工程。本章将介绍构建智能体的“黄金七步法”，并重点阐释技术选型、提示工程两大核心环节，强调用户体验闭环与全生命周期数据管理，帮助读者从零打造高效智能体，实现技术落地与商业价值。

### 2.1 构建方法论：黄金七步构建法

构建智能体是覆盖需求梳理到部署运维的系统化流程。黄金七步包括需求梳理、技术选型、提示工程、知识库与记忆系统选型、构建交互界面、测试与评估、部署与运维，为打造高效智能体提供科学指引，如图2-1所示。

#### 2.1.1 需求梳理与目标明确
缺少清晰目标的智能体只会沦为摆设。对个人用户而言，可能需要日程安排、邮件整理的助手；对电商企业而言，可能需要客户咨询与售后处理的客服体；对科研团队而言，可能需要文献检索与研究动态汇总的科研助手。目标确定后，需梳理任务全流程，包括接收、理解、规划、执行与结果输出。需求不清会导致开发反复，因此梳理阶段要细致到位，确保交付效果与实际诉求一致。

智能体可单一可多元，但单一体的功能不宜过多、结构不宜复杂。智能体强调“专”“精”。若需多功能，可采用任务拆解策略，将大任务拆分为多个小任务，为每个小任务配置专属智能体，再由总控智能体协同调度。

#### 2.1.2 技术选型策略
技术选型是承上启下的关键，将抽象需求转化为可落地方案。从框架、大模型、工具三维度切入，为智能体筑牢技术根基。

- （1）框架选择。当前流行的AutoGPT、BabyAGI等框架均支持自主规划与定制开发。智能体灵活性越高，成本与难度也越大，选择适配框架是成功关键。读者可参考1.3节和1.4节进行甄选。
- （2）大模型选择。大模型是智能体核心，选择时需综合部署方式与预算。不同模型各有所长，如DeepSeek偏重推理、豆包偏重文本处理等。
- （3）工具集成。工具是智能体的“手脚”。集成方式主要有两种：一是API接入第三方服务，简单易用但功能受限；二是RPA模拟人工操作，能力更强但实现复杂。

技术选型应具备良好可扩展性与兼容性，便于后期维护升级，同时关注技术趋势，避免采用即将被淘汰的方案。

#### 2.1.3 提示工程设计
提示词是智能体的沟通语言，精准的提示词才能激活能力。需明确智能体身份、思维框架、行动规范、使用方法及输出格式。提示工程是构建核心，提示词应简洁明确、避免歧义，并结合实际表现持续测试优化，同时考虑不同场景下的适用性，确保回复始终合理。

#### 2.1.4 知识库与记忆系统构建
完善的知识库与记忆系统是智能体智慧的来源与驱动力。

- （1）知识库是专业能力的根基，可通过文档索引、结构化数据、外部API接入等方式搭建。
- （2）记忆系统对持续交互至关重要。智能体记忆分为短期、长期与工作记忆，记忆压缩与检索增强生成等关键技术可显著提升效率。一般可依据人设与工作职责配置记忆与知识库。例如科研智能体可将严谨细致的个性、论文表述规范作为长期记忆；若正撰写天体物理学中子星专题论文，相关素材可作为短期记忆或纳入知识库，任务结束后可清理，避免跨课题混淆。

#### 2.1.5 交互界面搭建
构建交互界面时可选择文字交互、语音交互、数字人视频交互等形式。文字交互最便捷；语音交互适用于讲故事、驾车通话等特殊场景；数字人视频交互更直观，如同与真人对话。

无论何种形式，设计均应以用户为中心，界面简洁易用，反馈迅速。若计算资源有限，可减少语音、图文视频交互量以降低等待。可设计“撤销”“重试”功能，提升用户掌控感。

#### 2.1.6 测试与评估
测试与评估是保障质量与可靠性的关键，如同为智能体做体检。可从测试维度与评估框架两方面展开。智能体测试内容如图2-2所示，涵盖功能测试、性能测试、安全测试、边界测试及用户体验测试。

可采用定量指标、定性评估、A/B测试及用户反馈收集等框架进行系统评估。测试应全面客观、模拟多类真实场景，发现问题及时记录分析并优化，同时持续关注用户反馈迭代改进。

#### 2.1.7 部署与运维管理
成功部署是智能体创造价值的起点。合理部署与高效运维可保障稳定服务。部署方式可根据需求与预算选择：云端部署可选用阿里云、腾讯云等平台，或集成于微信公众号、百度、豆包等；轻量级智能体可选择边缘部署。

稳定运维是持续发挥价值的保障，需实时监控系统状态与性能，管理版本，做好内容审核防止有害输出，同时优化API调用与资源使用以降低成本。部署前须确保环境配置正确；运维需常态化，定期检查维护，并根据业务与用户需求变化及时优化。

### 2.2 提示工程：提升智能体智能的核心手法

提示词是智能体的“灵魂”，是高效沟通的基石。以自然语言指令引导大模型，帮助智能体准确理解角色与回复逻辑。提示词越清晰，输出越贴合预期。

#### 2.2.1 提示词构建四步法
精准提示词是高效回复的起点。构建步骤如图2-3所示。

- 1. 人物设定：塑造交互形象。鲜明人设能赋予智能体独特个性。设定应基于应用场景与目标用户，明确角色=领域属性+职能定位，形成清晰概述，结合情境认知理论，使设定符合用户预期，为风格提供导向。
- 2. 功能和流程：规划任务执行逻辑。清晰逻辑是高效执行的指南。功能设计应将复杂任务拆解为基础能力单元，规划标准化流程，明确输入、输出与转换规则，确保任务有序高效完成。
- 3. 约束限制：规范行为边界。明确边界是可信赖基石。通过设定数据真实性、隐私保护等规则，禁止虚假信息传播，尊重用户意愿，保障安全合规运行。
- 4. 回复格式：确定输出形式。良好格式让输出一目了然。提示词中应规定输出形式，如分点列表、分段阐述、可视化图表等，并结合终端与阅读习惯设计模板。

#### 2.2.2 提示工程七大原则
提示词质量直接决定输出有效性与可靠性。科学原则有助于跨越表达与执行鸿沟。

- （1）目标导向原则：目标越清晰输出越精准，提示词需围绕明确目标展开，如“撰写突出环保材质的营销文案”。
- （2）精准简洁原则：语言短小直接，避免冗余模糊，聚焦核心指令，如“撰写朋友圈推广文案，控制在100字内”。
- （3）无歧义原则：语义清晰、无歧义，选用具体词汇，如用“5张自然风光高清图”替代“几张好看的图片”。
- (4) 迭代优化原则：好提示词需打磨，根据输出表现持续调整，通过反馈分析逐步提升匹配度。
- (5) 包容多样原则：设计需兼容多种表达，覆盖不同提问习惯，如“今天天气如何”“查看天气预报”等同义问法。
- (6) 测试验证原则：使用前需模拟正常与异常输入，检验不同场景有效性，及时修复问题，确保稳定可靠。
- (7) 合规守法原则：合规是底线，设计需符合法律法规，尊重隐私，杜绝歧视、攻击性或违法内容，处理用户信息时明确保护措施。

#### 2.2.3 提示词进阶技巧
在模型应用开发中，调试与优化至关重要，需注意场景适配与风险。

- 1. 提示词对比调试。通过设计多组相似提示词比较输出差异，精准定位优化方向。针对同一任务设计2~3组仅变动单一变量的提示词，如指令复杂度、上下文信息、输出格式，观察信息完整性与逻辑连贯性差异。调试时每次只改一个变量，建立标准化评估维度并记录token消耗与响应时间，对高频场景定期复测。
- 2. 模型对比调试。在相同提示词下测试不同大模型表现，找出最适配任务的策略。优先对比同类型或跨模态模型，重点考察专业准确性、创意能力、多轮连贯性；明确训练数据边界，关注上下文长度限制，至少用20组典型场景测试以避免偶发偏差。
- 3. AI生成提示词。利用深度学习模型学习优质提示词与任务数据，自动生成匹配提示词。需注意：生成结果可能存在逻辑漏洞或偏离需求，需人工审核匹配度；提示词易同质化，需结合场景优化；专业与敏感领域需严格把控，防止错误或违规；需保护用户隐私，防止数据泄露。
