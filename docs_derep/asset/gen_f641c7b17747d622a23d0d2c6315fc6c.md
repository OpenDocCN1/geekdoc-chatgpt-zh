##### 2. LMDeploy：国产模型轻量部署方案

LMDeploy 由昆仑芯与魔搭社区联合打造，定位为国产开源大模型的统一、简洁、高性能推理部署框架。它覆盖 INT4/INT8/FP16 等多种精度，并提供一键脚本、服务启动、QPS 压测等能力。

LMDeploy 的核心特性如下。

- 兼容 Qwen、Baichuan、InternLM 等众多国产模型。
- 原生支持 INT4 推理，大幅降低显存占用。
- 提供 CLI、Web UI、HTTP API 全套接口。
- 支持多线程调度与批量推理。

##### 3. vLLM：高并发 OpenAI 兼容服务引擎

vLLM 由 UC Berkeley 发布的高性能推理引擎，具备动态批处理、连续批调度、FlashAttention 2，并完整实现 OpenAI API 协议。

vLLM 的核心特性如下。

- 支持 Hugging Face 格式模型，如 LLaMA、Qwen、Baichuan 等。
- 推理吞吐极高，可达数千 token/秒。
- 支持流式输出。
- 原生兼容 chat/completions 接口。

##### 4. Ollama：一键本地部署平台

Ollama 面向开发者，提供轻量本地部署能力，支持下载和管理 GGUF 格式大模型，包括 LLaMA 2/3、Mistral、Qwen、Phi 等，核心理念是让本地部署像用 Docker 一样简单。

Ollama 的核心特性如下。

- 自动下载并注册模型，无需手动管理权重。
- 跨平台支持 macOS、Windows、Linux。

### 2.3 本地大模型部署与使用

本章围绕本地部署全流程，系统梳理算力、环境依赖、模型下载与推理验证等关键环节，并对比主流第三方部署工具，为后续 Agent 开发提供运行基础。

#### 2.3.1 本地部署需求概览

在实际应用中，出于数据安全、服务稳定性、成本控制与模型可控性等多重考量，开发者和企业越来越倾向于将大模型部署在本地或私有云。本地部署可掌控推理全过程，降低敏感数据泄露风险，减少长期接口费用，提升响应速度并支持离线使用。但与此同时，资源门槛与工程复杂度同步提升，部署前需对以下关键需求进行全面评估。

##### 1. 算力资源

在所有部署条件中，GPU 算力是能否成功运行大语言模型的决定性因素。极轻量场景下可用 CPU 模拟推理，但速度与效率远不及 GPU，对中大型模型基本不可行。因此，部署大模型必须具备相应规模的 GPU 硬件。

> **说明**
>
> 为何不能只靠 CPU？
>
> 大语言模型推理涉及十亿级参数的矩阵运算，Transformer 层内包含大量矩阵乘法、归一化、注意力计算等高强度并行任务。GPU 在并行数值计算上优势明显，CPU 更擅长逻辑控制与串行任务。相同条件下，CPU 推理速度可能仅为 GPU 的 1/100 至 1/10。

不同参数规模在推理时的显存需求见表2.2。

**表2.2 不同模型参数规模对应的显存需求**

| 模型规模 | 推理时显存需求（FP16） | 支持的典型GPU（单卡） |
| :--- | :--- | :--- |
| 7B | 14GB～16GB | RTX 3090 / 4090 / A500 |
| 13B | 26GB～30GB | RTX 4090（24GB）基本可运行 |
| 33B | 60GB～80GB | 多卡 A100 或 2×4090 并行 |

采用量化技术如 INT4、INT8、GPTQ 等，可将显存需求压缩约 1/4～1/2。以 7B 模型为例，FP16 约需 14GB～16GB，INT4 量化后仅需 4GB～6GB，可在 RTX 3060/4060 甚至笔记本 GPU 上运行。

当前主流训练与推理基本依赖 NVIDIA GPU，因其 CUDA + cuDNN + PyTorch 生态成熟。常见型号见表2.3。

| 类型 | 常见型号 | 适用说明 |
| :--- | :--- | :--- |
| 数据中心级 | A100, H100, A800, L40S | 高稳定性、高带宽，适合集群部署 |
| 消费级高端 | RTX 3090, 4090, 4080 | 适合个人开发与小模型推理 |
| 云租用平台 GPU | Tesla V100, T4 | 支持量化模型，成本可控 |

若本地无 GPU，可租用云端算力。AutoDL、阿里云 PAI、百度飞桨 Studio、Google Colab 等均提供在线 GPU 租赁。

##### 2. 操作系统与环境依赖

硬件到位后，还需搭建操作系统与软件栈。部署 PyTorch/Hugging Face 风格模型通用环境如下。

1) 操作系统

推荐使用 Ubuntu，其对 CUDA 支持完善且稳定。CentOS 或 Windows + WSL2 也能运行部分模型，但不建议用于生产环境，兼容性风险较高。

2) 软件依赖环境（PyTorch 栈）

所需组件及推荐版本见表2.4。

| 组件 | 推荐版本 | 安装说明 |
| :--- | :--- | :--- |
| Python | ≥ 3.9 | 建议用 Conda 虚拟环境隔离 |
| PyTorch | ≥ 2.0 | 需安装 GPU 版本 |
| CUDA | 11.8 / 12.1 | 与 PyTorch 安装包匹配 |
| cuDNN | 对应 CUDA 版本 | NVIDIA 官网或驱动自带 |
| Transformers | ≥ 4.35 | Hugging Face 核心推理库 |
