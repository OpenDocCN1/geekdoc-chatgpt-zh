**本地 DeepSeek 搭建实操**

将 DeepSeek 投放到自有硬件上，是兼顾个性化功能与信息保密的主流思路。下面把完整的本地化落地路径梳理一遍，涉及环境准备、依赖安装、Ollama 获取、模型拉取以及前端设置等环节。配合具体操作演示和案例，读者可在自己的机器上稳定运行 DeepSeek，为后续微调与业务化应用打底。

**2.1.1 部署前的准备工作**

在本地环境中运行，数据始终留在内网，隐私风险可控；同时能够对接公司内部知识库和行业数据库，实现深度定制。值得注意的是，一张消费级显卡即可启动，长期算下来比订阅云服务更划算。所需硬件会随模型规模变化，参考建议如下。

（1）入门级：建议使用搭载 NVIDIA 显卡且显存不低于 8GB 的主机，可流畅承载 7B/8B 规模的模型。

（2）高性能级：若要运行 14B 级别模型，建议显卡显存不低于 16GB。图 2-1 展示的 GeForce RTX 5090 D 基于 NVIDIA Blackwell 架构，配备 32GB GDDR7 显存、21760 个 CUDA 核心，显存带宽达到 1792 GB/s，AI 算力相当强劲。

图 2-1 GeForce RTX 5090 D 显卡

**知识扩展**
Blackwell 架构以数学家 David Blackwell 戴维·布莱克威尔命名，有助于提升可靠性和集群间通信效率。GDDR7 的全称是 Graphics Double Data Rate 7，是 NVIDIA 与 DRAM 动态随机存取存储器厂商合作推出的低功耗新一代显存规范。
CUDA 即 Compute Unified Device Architecture 统一计算设备架构，是 NVIDIA 提供的并行计算平台和编程模型，允许开发者用 C/C++、Python、Fortran 等语言调动 GPU 并行能力。

（3）无独显情况：没有独立显卡也能以 CPU 模式运行，只是速度约为 GPU 模式的 20% 左右。

内存方面建议至少 16GB，长文本处理推荐 32GB 以保证顺畅。存储空间预留 50GB 以上，优先选用 SSD 固态硬盘以提升模型加载速度。

**知识扩展**
Ollama 常用命令说明如下。
（1）serve：启动服务，使模型可接收请求。

（5）stop：停止正在运行的模型。

（8）list：列出已下载模型。
（9）ps：列出正在运行的模型。
（10）cp：复制模型。
（11）rm：删除模型。
（12）help：显示帮助信息。

常用参数说明如下。
（1）-h, --help：显示帮助概览。
（2）-v, --version：显示版本信息。

**知识扩展**
DeepSeek-R1 不同参数版本在性能、适用场景和硬件需求上各有差异，习惯上用大写 B 表示参数规模。
（1）1.5b、7b、8b：参数较少，资源占用低，适合本地轻量问答或简单助手。
（2）14b 和 32b：推理能力明显提升，可处理代码补全、数据分析等复杂任务，需高端 GPU。
（3）70b 和 671b：顶尖水准，70b 接近 GPT-4 级别，671b 面向大规模云端推理，硬件需求极高。

推荐配置如下。
（1）1.5b：4 核 CPU、8GB 内存，无需显卡。
（2）7b 与 8b：8 核 CPU、16GB 内存、Ryzen 7 或以上、RTX 3060 12GB 或以上。
（3）14b：i9-13900K 或以上、32GB 内存、RTX 4090 24GB 或 A5000。
（4）32b：Xeon 8 核、128GB 内存、2~4 张 A100 80GB 或以上。
（5）70b：Xeon 8 核、128GB 内存、8 张 A100/H100 80GB 或以上。
（6）671b：64 核、512GB 内存、8 张 A100/H100 80GB 或以上。
