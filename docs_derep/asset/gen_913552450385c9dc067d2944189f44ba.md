# 第 2 章 知识表示（续）：语义网络深度解析

### 核心语义关系分类

**成员关系**  
标识为 `A-Member-of`，描述“个体归属集体”的隶属逻辑，即“隶属于”。示例参见 [PRE0]。

> **核心机制：属性继承**  
> 具体层节点可自动获取抽象层节点的全量属性。

**属性关系**  
连接事物与其特征的桥梁，高频谓词包括 `Have`（拥有）、`Can`（能力）、`Age`（年龄）[PRE1]。
- **Have**：标注实体具备的静态特征（如“鸵鸟有翅膀”）。
- **Can**：标注实体具备的动态行为能力（如“鸟会飞”）。
- **Age**：标注实体的时间维度属性（如“小利 15 岁”）。

**聚类关系（包含关系）**  
聚焦“部分-整体”结构，核心谓词 `Part-of` 表示“构成一部分”[PRE2]。  
**关键区别**：区别于分类/成员关系，**聚类关系通常不具备属性继承性**（大脑不自动拥有人体的所有属性）。

**时间关系**  
刻画事件先后序列，`Before`（先于）、`After`（后于）[PRE3]。例：“北京奥运会在悉尼奥运会之后”。

**位置关系**  
空间拓扑的五维描述[PRE4]：
- `Located-on`（表面/上方）
- `Located-at`（具体位置）
- `Located-under`（下方）
- `Located-inside`（内部）
- `Located-outside`（外部）

**相近关系**  
度量形态或内容的相似度[PRE5]：
- `Similar-to`（形似/神似，如“猫似老虎”）
- `Near-to`（空间/数值接近）

**因果关系**  
事件间的推演链条，`IF-THEN` 结构表达“若……则……”[PRE6]。例：“下雨 → 小明留家”。

**组成关系**  
一对多构成逻辑，`Composed-of` 标识“由……构成”[PRE7]。**无属性继承性**（整数由正/负/零构成，但整数属性不直接等同于部分属性之和）。

### 语义网络推理双引擎

#### 1. 继承机制：自顶向下的属性流动
下层节点从上层概念汲取属性，符合人类归纳认知规律。

- **值继承（属性直传）**  
  适用于 `ISA`、`AKO` 等强关联。直接传递属性值：`青砖 → 砖 → 长方体`，青砖形状直接得出“长方体”[PRE8]。
- **过程继承（方法传递）**  
  仅继承计算规则而非具体数值。空心砖继承“重量=体积×密度”公式，而非直接继承实心砖的重量数值。

#### 2. 匹配机制：模式识别式求解
三步走策略[PRE9]：
1. **构造查询片段**：含“询问处”（空节点/弧）的网络模板。
2. **知识库比对**：用片段去匹配完整网络。
3. **提取答案**：匹配成功处的实体即为解（如“张飞工作在→理想公司”）。

> **实战案例：植物分类网络构建 (例 2.15)** [PRE10]  
> **对象层级**：植物 ←(AKO) 树/草；草 ←(AKO) 水草；树 ←(AKO) 果树 ←(AKO) 桃树。  
> **属性挂载与继承剪枝**：  
> - 根/叶属性挂“草”节点，水草自动继承不再重标。  
> - “结果”挂“果树”，“结桃子”挂“桃树”。  
> - 最终生成 6 节点有向无环图。

# 第 3 章 搜索策略：从盲目试错到启发式决策

## 导论：搜索是 AI 问题求解的内核

早期 AI 即“状态空间寻路”：给定初态与目标，在解空间寻找满足约束的最优路径。

**系统分野**：
- **知识贫乏系统**：依赖搜索技术（本章核心）。
- **知识丰富系统**：依赖推理技术（专家系统等）。
- **渗透性**：搜索技术已渗透 NLP、博弈、机器学习、模式识别等全谱系。

**搜索二要素**：
- **搜什么**（目标状态）
- **在哪搜**（状态空间/问题空间）

**两阶段模型**：
1. 状态空间生成（隐式展开）
2. 空间内目标搜索

**策略分水岭**：
- **盲目搜索（非启发式）**：无领域知识，按固定策略（DFS/BFS）穷举，易组合爆炸，效率低。
- **启发式搜索**：引入经验估价函数（A/A*），导向最优路径，效率高。

**策略评价四维指标**：
1. **完备性**：解存在 → 必能找到。
2. **时间复杂度**：寻解耗时。
3. **空间复杂度**：存储开销。
4. **最优性**：多解时能否保证最优。

**确定性 vs 非确定性**：
- 盲目搜索 = 确定性遍历（节点展开序固定）。
- 启发式搜索 = 非确定性（动态估价决定展开序）。

## 3.2 一般图搜索：显式与隐式的工程抉择

### 3.2.1 图搜索基础概念

**存储范式对决**：

| 维度 | **显式图（全量存储）** | **隐式图（按需生成）** |
| :--- | :--- | :--- |
| **内容** | 完整状态空间 + 全知识库 | 初态 + 算子集 + 部分知识 |
| **生成时机** | 离线预计算 | 搜索中动态扩展 |
| **存储压力** | 极大，易溢出 | 极小，仅保留必要路径 |
| **适用场景** | 状态空间极小/固定 | 大规模/无限状态空间（主流选择） |

**核心思想**：从初态出发，应用算子集逐步扩展后继节点，直到命中目标态。隐式图搜索是工程落地的标准形态。
