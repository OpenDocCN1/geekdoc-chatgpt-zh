Transformer 能在 NLP 领域脱颖而出，关键在于其创新的注意力设计。传统序列模型 RNN 与 LSTM 依赖逐项计算，长文本处理时并行度受限且长距离依赖难捕捉。Transformer 借助自注意力，可直接关注序列任意位置，大幅提升并行效率并增强长距离语义关联的建模能力。本书以直观的方式拆解这些机制，帮助读者建立清晰的工作原理认知。

随着模型从实验室走向工业，部署效率与推理性能成为关键。后半部分深入探讨 ONNX 与 TensorRT 的优化手段，通过量化、剪枝、动态批处理等技术显著提升实机推理速度，并以完整代码演示从导出到上线的全流程。

## 引言

Transformer 是一种基于注意力机制的神经网络，由 Vaswani 等人在 2017 年提出，最初用于 NLP 序列建模任务。凭借自注意力和并行计算，它克服了 RNN 与 CNN 处理长序列的局限，成为 GPT、BERT 等大模型的基础。

本节先梳理技术演进脉络并介绍基础开发环境，便于后续章节的学习。

### 一、从统计学习到 Transformer 崛起

NLP 发展可划分为若干阶段，每一阶段都重塑了技术方向。

#### 1. 统计学习与基于规则的方法（20世纪70年代至90年代末）

在算力受限的时期，NLP 主要依赖手工规则与统计模型。早期基于上下文无关文法的解析器由语言学家手工构建，扩展性差。随后 HMM、CRF 等统计方法流行于语音识别、词性标注、命名实体识别。HMM 以隐状态建模序列，受限于观测独立性假设；CRF 以条件概率建模，摆脱部分独立性假设，在序列标注上效果明显提升。

#### 2. 深度学习的兴起与 RNN 的主导（2010年前后）

数据与算力提升后，深度学习成为主流。RNN 通过循环结构捕捉上下文，是首个有效建模序列依赖的神经网络，但存在梯度消失，长距离依赖学习受限。为此出现 LSTM 与 GRU。LSTM 以遗忘门、输入门、输出门改善梯度流动，能记忆更长依赖；GRU 在此基础上精简参数，提升效率。尽管如此，RNN 族的串行处理限制了并行训练速度，难以应对大规模数据。

#### 3. Transformer 的诞生与自注意力机制（2017年）

2017 年 Google 发布的 *Attention Is All You Need* 改变了格局。Transformer 完全基于注意力，摒弃循环结构，带来三点优势：

- （1）全并行：自注意力可同时处理序列各位置，训练速度大幅提升。
- （2）长依赖建模：任意两位置可直接计算相关性，无需逐步迭代。
- （3）模块化：编码器-解码器堆叠结构易于扩展与改造。

核心是缩放点积注意力，通过 Query、Key、Value 的点积得到权重分布，再加权求和生成上下文表征，全部基于矩阵运算，适合大规模并行。

#### 4. 从 BERT 到 GPT：预训练与迁移学习的浪潮

Transformer 催生了一批革命性模型。

- （1）BERT：基于双向编码器，采用掩码语言模型与下一句预测进行预训练，能捕捉句内与句间双向依赖，成为分类、问答等任务的基准。
- （2）GPT：采用单向解码器架构，以自回归方式建模生成，擅长文本续写、生成类任务，成为生成式 AI 的代表。
- （3）T5：将多任务统一为文本到文本转换，通过预训练与微调在多任务上表现稳定。

#### 5. 预训练模型的时代：通用大模型与跨领域应用

从 BERT、GPT 起步，预训练与迁移学习成为主流范式。模型规模从百万级扩至千亿级，出现 GPT-4、PaLM、LLaMA 等通用大模型，并向多模态扩展至图像、视频、音频。

这一进程带来深远影响：

- （1）参数高效微调：Adapter Tuning、LoRA 等降低迁移成本。
- （2）多模态融合：结合视觉、音频拓展应用边界。
- （3）工具化生产力：ChatGPT、Hugging Face 生态使 Transformer 成为通用 AI 基础设施。

### 二、开发环境配置：构建高效的 Transformer 开发平台

高效的开发环境是落地 Transformer 应用的基础，涵盖硬件、软件与工具链。

#### 1. 硬件准备：支持高性能计算的基础设施

- （1）GPU：建议 NVIDIA 支持 Tensor Core 的型号，如 RTX 30 系列或 A100，显存建议 16GB 以上。
- （2）CPU：多核高主频处理器加速数据预处理，推荐 AMD Ryzen 5000 或 Intel Core i9。
- （3）内存与存储：内存 32GB 起，存储采用 SSD 以提升数据读写与模型保存效率。

#### 2. 软件依赖：搭建兼容性良好的开发环境

- （1）操作系统：Linux 为主流，推荐 Ubuntu 20.04 LTS 及以上。
- （2）Python 环境：建议 Python 3.10，使用 Anaconda 或 venv 隔离依赖。
- （3）深度学习框架：
    - PyTorch：灵活定义模型与训练，需按 CUDA 版本安装。
    - TensorFlow 可选，用于特定任务。
- （4）Transformer 相关库：
    - Transformers：Hugging Face 提供的模型加载、训练、部署库。
    - Datasets：简化数据集加载与处理。
- （5）其他工具：
    - scikit-learn、pandas、numpy 用于评估与数据处理。
    - torchmetrics 用于 PyTorch 中的指标计算。
