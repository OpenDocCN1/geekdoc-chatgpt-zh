## 8.4 OpenClaw Skill 用法

把 OpenClaw 想象成一部智能手机，Skill 就相当于手机里的应用。核心框架只提供运行环境与执行能力，真正让它适配不同场景、解决具体问题的，是丰富多元的 Skill 生态。掌握 Skill 的使用方法，是释放 OpenClaw 潜力的关键。下面系统介绍 Skill 的基本概念、安装管理流程以及常用技能，帮助快速找到合适的工具。

### 8.4.1 什么是 Skill

Skill 是 OpenClaw 的模块化能力扩展包，是一套清晰规范可执行的指令与代码集合，明确在何种情境下按何种步骤完成何种任务，等于为模型赋予垂直领域的专业能力。

- （1）核心作用：通过标准化封装，模型无需反复学习执行逻辑，就能快速完成邮件管理、PDF 处理、网页检索、数据分析等固定任务。
- （2）加载机制：OpenClaw 采用按需加载，只有任务需要时才挂载对应能力，不会常驻占用系统资源，也不会额外增加大模型的上下文负担。
- （3）低代码特性：绝大多数 Skill 安装后无需手写代码，用自然语言即可直接调用，新手也能轻松上手。

一个完整的 Skill 通常由必备的 SKILL.md 文件和可选的辅助资源组成，结构简洁，便于理解功能定义：

其中 SKILL.md 是技能的核心载体，先用 YAML 头部声明名称、描述等元数据，再用 Markdown 详细说明功能、适用场景、执行步骤和示例，模型可直接读取并掌握执行能力。

OpenClaw 从三个位置读取 Skill，优先级不同，高优先级的同名技能会覆盖低优先级内容，可按需管理：

- （1）工作区 Skills：优先级最高，放在当前项目工作区目录下的 skills 文件夹，仅本项目生效，适合定制专属技能。
- （2）本地托管 Skills：优先级中等，放在用户目录 ~/.openclaw/skills 下，全局生效，所有工作区均可调用，适合安装常用通用技能。
- （3）内置 Skills：优先级最低，随安装包自带，无需安装，开箱即用，是最基础的核心能力。
