## 3.1 客服聊天机器人总览

### 3.1.1 核心价值速览

在当下数智化营销浪潮中，客服聊天机器人已成为企业转型的关键抓手。凭借提速响应、降本增效、拉升体验三大亮点，它正快速从辅助工具升级为核心能力。

效率层面，人工坐席面对咨询高峰容易出现排队和延迟，而机器人可并行接管海量会话，秒级回复，让用户无需久等。

成本层面，相较于人力团队，机器人的运维开销明显更低，且7×24小时在线，无需轮班和休假，长期下来能大幅削减人力支出。

体验层面，机器人可依据用户的提问习惯和偏好推送定制化答案，并以稳定亲和的语气交流，让人感受到被重视和被理解。

伴随大模型能力持续进化，客服机器人的应用边界还在扩大，未来有望为企业创造更多增长点和商业机会。

##### 1. 利用 Voiceflow 工具设计前端功能

“迪哥的客服”前端功能编排设计流程如下。

- （1）Start：配置服务的启动节点，正式开启“迪哥的客服”对话。
- （2）Create Thread：创建对话线程并调用后端 API，若连通成功则进入交互流程，否则终止任务。
- （3）Capture User Input：进入交互阶段，先展示欢迎语，再根据用户输入调用后端对话 API 作答。若调用成功则进入多轮对话，否则结束。
