# 第三章 DeepSeek提示核心法则

提示词是什么，说白了就是用户递给AI的指令或问题，是让模型读懂意图、给出回应的起点和基础。

- 组成要素

  - 输入侧：用户提问
  - 输出侧：AI答复
  - 通道：提示框，是唯一的人机交互窗口

- 作用比喻

  - 好比钥匙，能打开模型的潜能
  - 好比魔杖，能点亮模型的可能
  - 好比咒语，能唤醒模型的奇能

核心判断：无论模型多强，离开提示词就无法运转。

## 第二节 传统提示词的“三大缺陷”

- 拉高了使用门槛
- 增加了学习负担
- 限制了复杂需求的表达

## 第三节 “通用提示词”的“三把黄金钥匙”

- 提问：打开入口

  - 关键：目标清晰，不留模糊空间
  - 举例：“你能帮我写一个关于‘未来城市’的科幻短篇吗？”

- 描述：供给上下文

  - 关键：丰富背景信息
  - 举例：“故事设在2150年，人类居于空中悬浮城...”

- 指令：明确执行

  - 关键：动作或任务要具体
  - 举例：“请用第一人称写，突出主角的内心挣扎...”

## 第四节 “通用提示词”的“三个标准”

- 清：清楚

  - 明确对象与意图
  - 避开空泛表述，如“给我写十万字小说”

- 通：通达

  - 让AI真正读懂
  - 不断调整表达直至得到正确回应

- 明：明白

  - 用明确而非含糊的语言
  - 把目的与要求说透

## 第五节 “通用提示词”的“三元定律”

- 核心思路：用三项关键要素搭建方案

  - 最低：三项
  - 最佳：六项
  - 最高：九项

- 应用例

  - 烹饪：食材、火候、调味
  - 写作：开头、正文、结尾
  - 办事：方向、路径、技巧

## 第四节 “通用提示词”的“三个标准”

通用提示词的标准，归纳为清、通、明。

- “清”即清楚。
- “通”即通达。
- “明”即明白。

第一，关于清楚。要明白提示写给AI，AI是工具。要像给新员工布置工作那样说明岗位、职责、目标、任务。你要清楚问谁，同时把意图表达清楚。

第二，关于通达。就是用顺畅的方式表达意愿，目的是让AI听懂。通顺不等于通达，只有达到目标、被对方接受才算通达。若AI听不懂，就要换说法，直到得到满意回复。

第三，关于明白。用明确而非宽泛的语言，用明显而非含糊的表述，简洁地表达目的、要求、愿望，让AI听懂并执行。

例如，有网友发了这样一条提示：

> 给我写一篇十万字的小说。

从语文角度看，这句话清楚、通达、明白，但DeepSeek却懵了。

原因有三：

第一，太宽泛，没说清题材；
第二，太抽象，没给出小说要素；
第三，太模糊，没指明人物与事件。

网友又补发提示，增加了时代、地点、人物等信息，结果AI仍回复“思考中，回复‘继续’以回答。”

## 第五节 “通用提示词”的“三元定律”

“三元”指构成事物的三个关键要素，如三脚架需三条腿。自然科学认为三元结构是复杂系统的最小单元。我们发现，无论指导AI还是解决现实问题，抓住三项核心要素即可化繁为简。

老子说“一生二、二生三、三生万物”，道出生成规律。通用提示词正是运用此规律，用三个核心要素构建完整方案，故称“三元定律”。

面对复杂任务，找准关联最紧密的三项核心要素，就能有效指导AI。就像：

烹饪把握食材、火候、调味。
写文章把握开头、主体、结尾。
做事情把握方向、路径、技巧。

在AI时代，三元定律极其实用。例如：

1. 提问时说清对象、要求、场景。
2. 制订计划时明确目标、步骤、标准。
3. 解决问题时分析现状、原因、对策。
