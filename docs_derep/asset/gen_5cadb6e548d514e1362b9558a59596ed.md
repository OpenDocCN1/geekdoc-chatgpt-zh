3. 规则式分词
规则式分词的思路是先人工定义好切分准则，再按准则把整段文本拆开。准则可以来自语言学和语法层面的先验知识，也可以是基于字符串模式的匹配规则。比如利用汉语的语法特征和词性信息来推断词的边界在哪。

4. 深度学习分词
随着深度学习技术成熟，数据驱动的分词方案成为趋势。这类方案不再硬编码规则，而是让模型从大规模语料里自己学出分界。常用的网络结构有循环神经网络 RNN、长短期记忆网络 LSTM、卷积神经网络 CNN，以及基于自注意力机制的 Transformer，目标都是从大量文本中学习出中文词语的边界。

2. 主流中文分词工具盘点
下面这几款是业界常用的中文分词工具，各有侧重，可按需求挑选。对一般文本预处理来说，用 Jieba 就够用了；如果需要更强的语言学分析或更高精度，THULAC、LTP 会更合适。

1. Jieba
开源、易上手、运行稳定。实现上基于前缀词典，支持精确模式、全模式、搜索引擎模式，还能加载自定义词典并做关键词抽取。

2. THULAC
由清华大学自然语言处理与社会人文计算实验室发布，分词准确率高、速度快。采用词和字联合标注模型，同时提供词性标注和命名实体识别能力。

3. 哈工大LTP
哈工大语言技术平台，集成了多种 NLP 组件，分词器即其中之一。其分词基于隐马尔可夫模型 HMM 和条件随机场 CRF，兼顾精度与速度。

4. NLPIR
前身 ICTCLAS，由中科院计算技术研究所开发，分词效果稳定。它结合词频统计与规则匹配，支持多种分词模式和自定义词典。

（5）斯坦福分词器 Stanford Segmenter
斯坦福大学出品，基于条件随机场模型，分词准确度较高。不仅支持中文，还能做英文及多语言分词。

#### 3. 英文分词实务
英文分词相对简单，因为单词通常靠空格或标点隔开，但特殊文本仍需处理。

- （1）基于空格分词
最直观的做法是按空格切分。对规范文本有效，但在网页抓取或非标准文本中会出现无空格的连续字符串。

- （2）基于标点符号分词
先用句号、逗号、分号等标点把文本拆成句子或短语，再对每个片段做词级切分，先切句后切词。

- （3）词干提取 Stemming 和词形还原 Lemmatization
把不同形态的词归一到同一形式。词干提取是去掉后缀得到词干，词形还原则是还原到词典原型。两者常用于统一同一概念的不同变体。

### 3.1.3 Token
Token 自然语言处理里的核心概念，读音 [ˈtəʊkən]，没有统一的中文译名。按语境可理解为：在当前分词策略下，最小的语义单元。分词方式不同，Token 也不同。英文里可能是完整单词如 upstair、半词如 up、stair、或字母 u、p、s、t、a、i、r；中文里可能是短语如 攀登高峰、词语如 攀登、高峰、或单字 攀、登、高、峰。分词本质上就是把连续文本切成一系列有意义的 Token，因此数据表中每一行样本就是一个 Token。

Token 是语义的最小组成，也是深度学习处理输入的基本单元。Token 数直接反映文本长度和计算量，影响资源消耗和模型表现。OpenAI 等厂商常以 Token 消耗计费限额，所以 Token 使用量已成为衡量大模型吞吐和数据量的标准。表3-1 为 OpenAI API 收费示例，实际标准以官网为准。

### 3.1.4 Embedding
NLP 需要把文本转成数字才能计算。无论哪种编码，相同词在同一规则下映射到相同数字序列，编码方式决定是单数字还是序列。

难点在于不仅要一一对应，还要语义一致：语义相近的词，编码后的数字在数学上也应相近。比如 女人 和 女孩儿 在语义空间里应该靠得近。没有唯一正确的语义空间，不同编码会构建不同空间。

实现上常见两种编码。

- （1）One-hot 编码
每个词或字符映射为稀疏向量，向量长度等于词表大小，仅对应位置为1，其余为0。

- （2）Word Embedding 编码
通过训练让词映射到低维实数向量，保留词间语义关系。

## 3.2 语言模型历史演进
### 3.2.1 语言模型历史演进
语言模型发展大致分三阶段，见表3-2。

- （1）统计语言模型
基于概率统计，通过词频、n-gram 等计算下一个词的概率，是语言模型的早期形态。

- （2）神经网络语言模型
深度学习兴起后，用多层非线性变换捕捉词间复杂关系，RNNLM、LSTM 等成为主流，提升了准确性和流畅度。

- （3）基于 Transformer 的大模型
以 Transformer 和自注意力为核心，实现并行处理和长距离依赖捕捉，模型规模指数增长。BERT、GPT-3、Turing-NLG 等在理解与生成上取得突破，开启预训练新纪元。

表3-2 语言模型发展的三个关键阶段

| 阶段 | 定义 | 成果 | 限制 |
| :--- | :--- | :--- | :--- |
| 统计语言模型 | 初期的语言模型，依赖于统计分布和概率来预测单词。起源于信息论和早期计算机科学 | （1）统计机器翻译。<br>（2）n-gram 模型和 HMM。<br>（3）最大熵模型 | （1）难以捕捉长期依赖性。<br>（2）需要复杂的特征工程 |
| 神经网络语言模型 | 神经网络在捕捉复杂模式方面的优势使其成为语言模型的一个进步。包括 RNNLM 和 LSTM 在内的模型被用于捕捉序列数据中的依赖关系 | （1）神经网络语言模型（RNNLM）。<br>（2）RNNLM 处理序列数据。<br>（3）LSTM 在语言模型中的应用 | （1）计算效率和扩展性有限。<br>（2）梯度消失或爆炸问题 |
| 基于Transformer的大模型 | Transformer 架构通过自注意力机制改进了长距离依赖问题的处理，并提高了并行化处理的效率 | （1）Transformer 架构。<br>（2）BERT 模型。<br>（3）GPT 模型家族等 | 计算资源消耗大 |

第一阶段可追溯到20世纪50年代，统计方法主导机器翻译，依赖人工知识，理论上限受人类认知限制。第二阶段神经网络出现后，数据驱动让模型摆脱手工特征，在视觉和 NLP 上超越人类。统计模型本质是按分布频率预测，进步受特征工程制约。

神经网络语言模型把神经网络用于语言建模，能捕捉复杂模式和隐含语义，与 One-hot 等早期编码相比有质的提升。但 RNN 因顺序处理效率低，且存在梯度消失/爆炸，长距离依赖仍受限。

第三阶段 Transformer 是当前焦点。自注意力让模型能聚焦关键词，即使序列长达 50 或 100 个词也能精准定位信息，提升效率。同时并行计算加速处理。但推理成本高，计算量随序列长度平方增长，且从无标注数据学习会放大训练数据的偏见。

### 3.2.2 统计语言模型
统计语言模型用于建模自然语言概率分布，核心思想是依据语料库中观察到的频率推断词间概率。

常见实现是 n-gram 模型和隐马尔可夫模型 HMM。

n-gram 假设词出现概率仅与前面 n-1 个词相关，通过统计大量文本计算条件概率，实现序列建模。

HMM 用于序列数据建模，词出现概率只与有限前驱相关。在 NLP 中用于词性标注、语音识别等，通过状态转移概率和发射概率建模序列。

统计语言模型可用于语言生成、识别、分类和机器翻译，但对复杂结构和深层语义处理有限，后来被神经网络模型逐步取代。

### 3.2.3 神经网络语言模型
从统计语言模型到神经网络语言模型是一次技术演进。统计模型多基于规则和概率，如 n-gram、HMM，依赖人工特征，在复杂结构和语义上受限。

神经网络语言模型利用深度学习捕捉复杂模式，减少手工设计，通过数据驱动学习分布，在建模能力上实现突破。
