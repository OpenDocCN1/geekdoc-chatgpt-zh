图示中输入层共3个单元，依次编号1、2、3；隐藏层共4个单元，编号4、5、6、7；输出层2个单元编号8、9。以隐藏单元4为例，它与输入层的3个单元全部相连，对应的连接权重记为w₄₁、w₄₂、w₄₃。

**a₄ = σ(wᵀa) = σ(w₄₁x₁ + w₄₂x₂ + w₄₃x₃ + w₄b) (3-4)**

式中w₄b为单元4的偏置。

同理可以求出单元5、6、7的输出a₅、a₆、a₇。

输出层单元8的输出y₁计算为：

**y₁ = σ(wᵀa) = σ(w₈₄a₄ + w₈₅a₅ + w₈₆a₆ + w₈₇a₇ + w₈b) (3-5)**

w₈b为单元8的偏置。y₂同理可得。由此可见输出向量的长度与输出层神经元个数一致。

### 3.2.6 更深网络的价值
前提是在一定范围内。相同神经元数下，深层结构具有更大表达能力，分层组合产生指数级表达空间，可组合出更多子结构，更易学习复杂特征。隐含层增多意味着激活函数带来的非线性变换嵌套更深，能够构建更复杂的映射关系。

## 3.3 激活函数
激活函数是神经元上运行的函数，负责把输入映射为输出。

### 3.3.1 引入激活函数的意义
深度网络中激活函数主要作用有：
激活函数对学习复杂非线性函数至关重要；
引入非线性，否则输出只是简单线性函数，线性模型能力有限，难以拟合图像、语音等复杂数据；
可将当前特征空间线性映射到另一空间，使数据更易分离。

### 3.3.2 非线性激活的必要性
通常使用非线性激活有两个原因：
若全网均为线性，线性组合仍是线性，等价于单一线性分类器，无法逼近任意函数；
非线性激活提升网络表达力，使其能学习复杂映射，实现输入输出间的非线性关系。
