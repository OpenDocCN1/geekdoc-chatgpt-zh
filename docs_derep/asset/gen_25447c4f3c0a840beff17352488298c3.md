# 反向传播核心逻辑与激活函数全景解析：从原理到TensorFlow实战

神经网络训练的核心在于“纠错”。反向传播算法的本质，是从输出层算起，层层回溯计算每个神经元的误差贡献度。因为当前层的误差依赖于下一层的误差传递，所以计算顺序注定是自顶向下、由后向前，直抵第一个隐藏层。

随着技术迭代，权值更新早已标准化为“求梯度、做下降”的套路。梯度指向误差增大最快的方向，参数更新自然要反着来，以此压缩误差。工程落地时，还会结合具体场景微调优化策略，比如动量法、自适应学习率等，以求收敛更快、更稳。

### 7.5 激活函数：赋予网络“非线性”灵魂

神经网络的本质任务，是通过参数与激活函数的组合，去拟合特征与标签间隐匿的真实映射关系。单层网络只能切分线性边界，但叠加两层并引入非线性，便能无限逼近任意连续函数——这是通用近似定理的基石。

神经元计算可拆为两步：**线性加权求和** 与 **非线性变换**。前者本质是矩阵乘法，若缺失后者，无论堆叠多少层，整个网络仍等价于单层线性模型，彻底失去拟合复杂曲面的能力。激活函数的引入，打破了线性束缚，同时将数值压缩至特定区间，既稳定了训练梯度，又降低了计算开销。主流选择包括 Logistic、Tanh、ReLU 及其变体 Leaky ReLU、Swish 等。

[PRE0]

#### 7.5.1 Logistic (Sigmoid) 函数：经典但逐渐退役的“S型曲线”

Logistic 函数将实数映射至 (0, 1) 区间，大负数趋 0，大正数趋 1，形似生物神经元的“兴奋/抑制”机制，公式为 $\sigma(x) = 1 / (1 + e^{-x})$。

[PRE1]

**为何工程上鲜用？三大硬伤：**
1.  **梯度消失重灾区**：曲线两端趋于水平，梯度接近 0。反向传播时，饱和区神经元权重停止更新，上游梯度也随之切断，导致深层网络难以训练。
2.  **输出非零均值**：输出恒为正，导致后层输入分布偏移，引发“之字形”震荡，收敛变慢。
3.  **指数运算开销大**：`exp` 计算比简单的阈值操作昂贵得多。

#### 7.5.2 Tanh 函数：零均值改良版，但难逃梯度消失

双曲正切函数将输出压缩至 (-1, 1)，解决了零均值问题，利于后层收敛。

[PRE2]
[PRE3]

然而，它继承了 Sigmoid 的饱和特性，两端梯度同样消失，深层网络中依然力不从心。

#### 7.5.3 ReLU 函数：深度学习的“标配”激活器

修正线性单元：$x < 0$ 输出 0，$x \ge 0$ 恒等映射。

[PRE4]
[PRE5]

**杀手级优势：**
- **缓解梯度消失**：正区域梯度恒为 1，信号原路回传无衰减，极大加速收敛。
- **极致计算效率**：仅需一个 `max(0, x)` 阈值操作，无乘除指数，硬件友好。
- **稀疏激活**：负区间硬性输出 0，天然诱导网络稀疏表达。

**两大短板：**
1. **非零均值**：同 Sigmoid，输出均值 > 0，影响后层优化动态。
2. **“神经元死亡”**：输入恒 < 0 时，梯度永为 0，权重冻结，该单元永久失活。

#### 7.5.4 Leaky ReLU：给“死神经元”留一线生机

在负轴保留微小斜率 $\gamma$ (如 0.01)：$x > 0$ 为 $x$，否则为 $\gamma x$。

[PRE6]

这一改动确保负区间梯度非零，彻底解决“死神经元”问题，参数更新永不停歇。常见变体 PReLU 将 $\gamma$ 设为可学习参数，进一步提升拟合上限。

#### 7.5.5 Swish 函数：自动搜索出的“平滑之王”

$Swish(x) = x \cdot \sigma(\beta x)$，引入门控机制，$\beta$ 可学习或固定。

[PRE7]

- $\sigma(\beta x) \approx 1$ 时，门开，输出 $\approx x$（类 ReLU）；
- $\sigma(\beta x) \approx 0$ 时，门关，输出 $\approx 0$。

曲线平滑无突变，结合了 ReLU 的非饱和性与 Sigmoid 的有界性，在深层模型（如 Transformer、EfficientNet）中常超越 ReLU 表现。

### 7.6 实战：TensorFlow 构建激酶抑制剂分类器

完整流程四步走：**数据预处理 → 网络搭建 → 模型训练 → 推理部署**。本节聚焦前两阶段。

#### 7.6.1 数据预处理：垃圾进，垃圾出

原始数据 `kinase_selected.csv` 含 5 列分子描述符特征，首列索引无意义，舍弃。

[PRE8]

**标准化是必须的**：将各特征缩放至 0 均值、单位方差量级。这不改变数据分布本质，却能消除量纲差异，让梯度下降沿最陡方向直达底部，大幅提速。处理后特征矩阵 `X_scaled` 形状为 (2013, 5)。

标签文件 `label_kinase_selected.csv` 最后一列 `Binding_Modes` 为 4 分类目标（I: 1399, I1/2: 377, II: 190, A: 47），样本量与特征集对齐。

[PRE9]

**标签编码管线：**
1. `LabelEncoder` 将字符串映射为整数（A:0, I:1, I1/2:2, II:3）。
2. `to_categorical` 做 One-Hot 编码，转为长度 4 的概率向量，完美匹配输出层 4 个神经元。

[PRE10]

**划分数据集**：`train_test_split` 按 8:2 分层抽样，固定 `random_state` 保证复现性。产出 `X_train`, `X_test`, `Y_train`, `Y_test` 四份数据。

[PRE11]

#### 7.6.2 网络架构搭建：Keras 顺序模型实战

借助 `Sequential` API 栈式堆叠层级，核心组件：
- `Dense`：全连接层，参数量 = (输入维度 + 1 偏置) × 神经元数。
- `Dropout`：训练时随机失活比例神经元（如保留 80%），强制学习鲁棒特征，对抗过拟合。

[PRE12]

**模型拓扑速览（`model.summary()`）：**
1. **Input/Dense-1**：输入维度 5 → 128 单元，ReLU 激活。参数量 = (5+1)×128 = 768。
2. **Dropout-1**：失活率 0.2，无参数。
3. **Dense-2**：128 → 64 单元，ReLU。参数量 = (128+1)×64 = 8,256。
4. **Dropout-2**：失活率 0.2。
5. **Output/Dense-3**：64 → 4 单元，Softmax 输出类别概率。参数量 = (64+1)×4 = 260。

总参数量约 9.3k，轻量级架构适配小规模表格数据，训练极快。后续将配置优化器、损失函数（分类交叉熵）启动训练循环。
