# 9.1.2 三款在线执行代码插件
原生 ChatGPT 仅负责生成代码，无法直接运行。借助第三方插件即可获得在线运行能力。本节介绍 Code Runner、CodeCast Wandbox 与 CoderPad 三种方案。
