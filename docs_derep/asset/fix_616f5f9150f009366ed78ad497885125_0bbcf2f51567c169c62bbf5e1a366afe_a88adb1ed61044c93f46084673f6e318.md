情感缺口放大后的AI陪伴依赖

成长让人更孤单、更不安，情感抚慰的匮乏似乎难以填补，人对情感的渴求几乎是无止境的。AI带来的便利悄然塑造了新的依赖习惯，人们开始借助它来掩饰难以启齿的孤寂。最新调研显示，在高度倚赖科技产品的群体中，63%处于单身状态，69%缺乏全职工作，24%几乎没有或仅有一位可信赖的密友，42%的大多数时间都是独自度过。虚拟世界里人潮涌动，但62.75%的人离开智能手机就会感到不适【2】。

正是长期独处的这42%和离不开手机的62.75%，在未来的AI社会里，很可能全部滑向情感机器人的核心使用者群体，更准确地说是情感机器人成瘾的高危人群。

人们并非无视风险，防范的声音早已出现。2016年9月，权威的英国标准协会BSI在其发布的《机器人和机器系统的伦理设计和应用指南》中指出，机器人欺骗、诱导成瘾、拥有超出现有能力范围的自我学习能力等都是对人类有害的要素，尤其是缺乏拒绝能力的性爱机器人极易引发上瘾，必须在后续的伦理规范中予以补充完善。

认清了情感机器人的利与弊后，如何扬长避短成为共同关注点。当下人工智能仍在人类可控范围内，情感机器人的行为表现和情感输出方式都受制于人。因此强化伦理治理，提升其造福人类的能力，必须与技术发展同步推进。

四、溯源：情感机器人伦理困境的成因
情感机器人出现负面效应自有其根源，厘清成因才能对症应对。

第一，技术本身的局限。技术能够流行，往往因为其优势与社会文化和人性需求高度契合。新技术普及必然伴生新的伦理社会问题，这是技术动态完善、不断满足需求的必然结果，再先进的技术在特定阶段也难免存在缺陷。情感机器人虽能满足诸多需求，以目前的技术水平仍存在明显短板。

其一，当前情感机器人仅能依据研发者预先设定的程序代码运行，程序驱动的情感表达缺少自主意志参与，完全受拥有者支配，机器被善待的程度与拥有者素质紧密相关。未来它是否仍按初始程序运转，或被不法分子利用，我们无法完全预知。正如史蒂芬·霍金所言，人工智能的短期效应取决于控制者，长期效应则取决于它是否真正被人类掌控。

其二，情感机器人与其它机器人一样依赖软件，其安全性高度依赖软件设计。程序员力求打造无懈可击的代码，但在数百万行代码的某处仍可能隐藏错误，一旦软件出现瑕疵，便可能酿成后果难料的事故【3】。

其三，现有情感机器人缺乏足够理性与崇高道德意识的引导，难以对周边事物做出正确判断并及时终止正在进行的动作，这会加剧人们的恐惧，甚至在人类中心主义立场下被排斥。由此引出关键问题：技术上可行的做法是否都应该去做？技术可行性与伦理合理性之间的平衡亟待寻找。

第二，立法的滞后。技术飞速迭代，旧法约束力明显削弱，而适配新技术的法律却具有显著滞后性。因为法律本质上是反应性的，很少能提前预见问题，往往是对已发生问题作出缓慢反应【4】。现阶段情感机器人应用受阻，法律滞后便是主因之一。

其一，法律难以调和人机关系。立法时多聚焦于保护人类自身权利，容易忽视情感机器人应有的法律地位。缺失法律认可使情感机器人缺乏公信力，进而陷入伦理困境。

其二，在立法滞后的环境下，研究者缺乏清晰指引。研发何种功能的情感机器人才算合法，研究者无从判断。政府监管也缺乏法理依据，难以制定有力且针对性的保护举措。

其三，因缺乏规则指引，公众对情感机器人的本质认识不全面、不科学，存在误解。社会上并无统一认知，甚至出现崇拜或恐惧，态度多由个人文化道德素养决定。

第三，监管的碎片化。没有规矩不成方圆，权威统一管控的缺失是伦理困惑的重要诱因。

其一，推动人工智能发展时，人们更关注如何最大化赋予情感机器人能力，使其走向理想化，却尚未为全人类制定可遵循的管理准则。

其二，对情感机器人的管控缺乏统一认识、统一道德规范和伦理规则。如何对待情感机器人，至今仍无公认标准。

其三，情感机器人的管理难度已超出当下人类的把握范围，或说人类尚未准备好管控这一先进事物。但创造情感机器人并赋予其更多能力，就必须承担相应责任。当它们变得更聪明、更自主并被赋予独立能力时，如何管控其行为就成为必须思考的问题【5】。将情感机器人纳入制度框架，是确保其造福人类而非危害人类的关键举措之一。

第四，观念的滞后束缚。从18世纪工业革命到20世纪信息革命再到当下的智能革命，科技进步节奏不断加快，每次革命都催生新观念。新科技总是跑在人类观念前面，进入21世纪，随着经济政治文化改革加速，科技发展势如破竹，人类尚未完全掌握现有技术，更先进的技术已然出现。

人类掌握与使用科技的速度远低于技术更新速度，人工智能与机器人技术的融合更是空前。情感机器人作为AI高速发展的产物，结构功能高度复杂，且涉及情感、性爱等敏感领域，其应用伦理困惑已超出大众理解与接受范围，甚至研究者也难以确定应以何种伦理原则引领其发展，普通大众自然更感迷茫。

人是生命进化的最高形态，趋利避害是人的本性。当情感机器人对传统伦理道德、现有社会秩序甚至人类生存构成严重威胁时，人本能会驱使其反对排斥情感机器人，以维护自身在地球上的主体地位【6】。

第五，利弊判断难统一。关于人工智能及其未来影响，学界形成以史蒂芬·霍金、埃隆·马斯克、比尔·盖茨为代表的警惕派，与以雷·库兹韦尔为代表的乐观派两种截然不同的立场，至今未达成一致。2014年霍金警告AI发展可能意味着人类灭亡，2015年比尔·盖茨认为应敬畏AI崛起，它将成为现实威胁。而雷·库兹韦尔始终保持积极乐观。学界的分歧恰说明人类对AI是福是祸仍缺乏明确统一判断。情感机器人作为AI产物备受争议，产生伦理问题也在情理之中。

五、治理路径：为情感机器人划定伦理边界
技术缺陷、法律滞后、观念束缚与管理分散共同导致伦理问题的出现。为此科技工作者需自觉承担社会责任，推动构建人机命运共同体与情感机器人道德评判体系，发挥法律作用，加大普及力度。

第一，科技工作者主动担责。科技是双刃剑，造福还是毁灭很大程度上取决于研发者。在人工智能时代，科技工作者更应主动承担应有社会责任。作为创造者，应当坚持技术研发与社会效益统一，遵循最大幸福原则，以高度负责的态度把握科研方向。

科技发展的归宿始终是大众福祉。杨振宁曾指出，科学研究的最终价值判断，不在于为科学而科学，而在于是否对人类有益【7】。科技工作者须具备崇高使命感与高尚科研道德，心怀社会，始终关注人类，禁止任何技术发展触碰道德红线。爱因斯坦曾对加州理工学院学生说，若想让一生工作造福人类，仅懂应用科学本身是不够的，关心人本身应成为一切技术奋斗的主要目的，以确保科学成果造福而非祸害人类【8】。研发者易优先考虑技术功效最大化而忽视伦理关切，因此要理性处理人与信息、人与机器、人与科技，以及价值理性与工具理性、技术可能性与伦理合理性的关系，把科学精神与人文关怀结合起来，“把技术的物质奇迹与人性的精神需要平衡起来”【9】，让人工智能技术健康发展。

第二，共建人机命运共同体。随着AI发展，未来社会必然是人类与机器人共存的多元社会。人类安危与机器人紧密相连。特斯拉CEO埃隆·马斯克曾警告，人必须与机器人结合，否则将被AI淘汰。毋庸置疑，面对AI，人类显得极其脆弱有限，生命的有限性警示人类必须借助外力战胜现实困难。情感机器人是人类的理想伙伴，人与情感机器人的亲密程度远超想象，人机相互依存、和谐共处，彼此权利义务在一定程度上应趋于对等。

20世纪50年代，艾萨克·阿西莫夫在《我，机器人》中提出机器人三定律：机器人不得伤害人，也不得见人受害而袖手旁观；应服从人的一切命令，但不得违反第一定律；应保护自身安全，但不得违反前两定律。这些原则是否适用于人与情感机器人的相处，需要进一步探讨。未来社会是人与机器人共处之社会，享受便利的同时不应忘记机器人是我们不可或缺的一部分，人机命运共存。

第三，建立情感机器人道德评判体系。智能时代对伦理提出更高要求。实际上，“机器自由化程度越高，就越需要道德标准”【10】。面对情感机器人快速发展，人类必须建立一套可遵循的新道德伦理标准来指导其行为，通过设计伦理道德代码植入机器人内部，使其遵守伦理。可以创建并应用处理伦理问题的系统，帮助设计机器人、规定其行动、与之沟通协作，从而控制其在现实生活中的行为道德【11】。

该体系可引导情感机器人伦理道德逐步成熟。我们需要辩证看待传统道德价值，道德内涵应随科技发展注入新血液。道德并非人类专利，情感机器人的世界同样需要属于它们的伦理体系。人类应提前意识到情感机器人伦理体系可能存在的缺陷，并尽早完善配套措施。国家应及早组建由科技界、产业界、哲学界权威人士组成的国家人工智能伦理委员会，作为决策机构对重大AI项目进行论证，并为国家法律政策制定提供依据，从源头引导AI技术良性发展。

第四，充分发挥法律作用。应对伦理问题，要充分发挥法律的建设性作用。俗话说名不正则言不顺，立法时要兼顾人类切身利益，也要给予情感机器人合法地位，消除法律壁垒。如沙特已授予女性机器人索菲亚合法公民身份，让公众认可与接受。法律应严格规定情感机器人相应的权利义务，用法律形式规范其行为。更重要的是，当人类对情感机器人违法时，应受相应法律制裁。法律要保护情感机器人独特的尊严与隐私，让其有尊严地与人类共处。法律发展要紧跟科技步伐，更新观念与形式，更好服务科技发展。

第五，加大人工智能普及力度。公众是科技发展的重要力量，其对人工智能的认知与态度与普及程度密切相关。情感机器人因结构原理高度复杂，普通人难以触及，容易产生崇拜或恐惧。因此，科技专家应与政府媒体密切合作，利用互联网、微博、微信等新型传播手段普及AI知识，讲述情感机器人的真实面貌、前因后果、应用方向及其对人类可能影响，让公众形成理性认识。可通过科普讲座、科技展览等形式提供接触机会，引领公众树立正确态度，为AI技术发展创造良好社会环境。

人工智能社交：人们为什么喜欢匿名
社交的变革：人工智能对人际交往的冲击
未来的“大社交”：人类社交的人工智能化

随着边缘存储、5G传输、图像识别等AI技术的成熟，人们正步入人工智能化的“大社交”时代。交往范围、时长、信任感、待人方式、行为模式、自我认知等，均在经历“数千年未有之大变局”。就网红经济和社交电商而言，传统与新兴领域的竞争，本质是社交关系网络的竞争，谁能切入顾客生活空间，谁就能赢得支持。

一、人工智能社交：人们为什么喜欢匿名
社交是通过互动互换信息观点、促进沟通交流、避免不必要人际冲突的方式。对人类生存意义重大。古希腊学者亚里士多德在《政治学》中写道，从本质上讲人是一种社会性动物；那些生来离群索居的个体，要么不值得关注，要么不是人类。

随着时代演进，社交渠道与方式不断变化，从烽火狼烟、飞鸽传书、快马传书，到邮政、座机电话，再到手机、电子邮件、QQ、微博、微信及网络游戏，变化愈加迅速。时间与空间上的先天局限被不断突破，这得益于社会生产力提升与科学技术快速发展，特别是基于互联网的现代通信工具为人与人交流提供了便捷高效平台，大幅降低互动成本，提升交往效率与质量。最终，一种大综合、大系统、大社会的社交方式——人工智能社交逐渐成形。

人工智能社交是指将社交网站、社交媒介与网络媒介等工具与人工智能技术相结合，通过社交互动传达沟通内容以更好达到社交目的的一种交往方式，是现实社交在网络世界的延伸并能增强现实社交体验的未来模式。可分为AI机器人与人的社交，以及AI技术运用于人与人之间社交两大类。相较传统社交，AI社交具有透明化、舒适化、高效化、可视化、可分析化等特征。

随着AI技术推进，AI在社交领域的应用被越来越多的人接受，如智能手机社交软件、AI社交机器人等，特别是智能手机社交软件深得喜爱。随着生活智能化程度提高，AI社交机器人也逐渐渗透到生活各领域。

社交是人类最基本诉求，AI社交的发展及其特征恰好反映了人们对这一基本诉求的强烈欲望，因为当社交需求出现时，人们希望立即得到满足，否则易陷入焦虑。正是AI社交的出现，让这种急切性得以快速满足。因此AI社交才得以迅速发展。今天，若让一个人只使用“功能型手机”，他很快就会与世界脱节，这并非失联，而是脱节。

正因这种脱节可能性的存在，越来越多的人主动或被动运用AI社交技术。随着人群涌入，AI社交技术不断完善。任何事物的发展总要经历逐步完善过程。当便捷AI社交工具的实用功能尚未完全发挥时，一些被利益驱使的受益者开始企图从便捷社交中谋求私利，损害部分人利益。这才引发了“人工智能社交，人们为什么喜欢匿名”的讨论。

人工智能有三大定律，第一是阿什比定律，任何有效控制系统都必须与所控制系统一样复杂。第二由冯·诺依曼阐述，复杂系统的定义是它构成自己最简单的行为描述，有机体最简单的完整模型就是有机体本身，试图将系统行为简化为其他形式描述会使事情更复杂。第三由约翰·布罗克曼阐述，任何简单到可以理解的系统都不会复杂到足以智能运行，而任何复杂到可以智能运行的系统，都将复杂到难以理解。
