##### 1. 数据管理的基本概念

日常生活中数据无处不在，文字、图像、音频、视频等信息层出不穷。若要在海量数据中快速定位所需内容，就必须借助专门的管理手段。数据管理借助计算机软硬件实现数据的采集、保存、加工与利用，其核心目标是发挥数据的最大价值，而数据组织是实现有效管理的关键。伴随计算机技术演进，数据管理先后经历了人工管理、文件系统、数据库系统三个阶段。数据库系统通过构建更精确的数据结构，清晰刻画数据间的关联，便于修改、更新和扩充，同时保障数据的独立、可靠、安全与完整，降低冗余，提升共享水平与管理效率。

计算机的快速发展推动了数据管理在各领域的广泛应用，例如学生学籍管理、办公自动化、铁路订票、图书管理等系统，见图 3-4-1。可预见，数据管理仍将是计算机应用的重要课题，数据库技术正是支撑此类应用的基础。数据库在物联网中的作用愈发突出，如何有序存储物联网产生的海量数据、如何借助数据库技术更好服务物联网，已成为关键研究方向。

##### 2. 数据库技术基本概念

数据库技术源于数据管理的实际需求，随着软硬件的进步而不断完善，主要经历了三个阶段：

1）第一阶段：人工管理阶段
20 世纪 50 年代中期以前，计算机主要用于科学计算，这一阶段数据管理的主要特征有：
（1）数据不做长期保存。当时计算机主要承担科学计算，数据仅在特定课题计算时临时输入，使用后即清除，用户数据和部分系统软件皆如此处理。
（2）由应用程序自行管理数据。数据的设计、描述与维护全靠应用软件完成，缺乏统一的软件支持。
（3）数据难以共享。数据面向特定应用，一组数据仅对应一个程序，导致程序间大量重复。
（4）数据缺乏独立性。数据的逻辑或物理结构变化后，必须同步修改应用程序，给程序员带来额外负担。

2）第二阶段：文件系统阶段
20 世纪 50 年代后期到 60 年代中期，磁盘、磁鼓等直接存取设备出现，操作系统中出现了文件系统，处理方式也从批处理向联机实时处理发展。用文件系统管理数据具有以下特点：
（1）数据可长期保存。大量用于数据处理后，数据需长期保留在外存中以便反复查询、修改、插入和删除。
（2）由文件系统统一管理数据。但文件系统也存在缺陷，主要是共享性差、冗余度大。一个文件基本对应一个应用，不同应用即使使用部分相同数据也需各自建立文件，无法共享，导致存储浪费且易出现不一致，给维护带来困难。

3）第三阶段：数据库系统阶段
20 世纪 60 年代后期以来，计算机管理对象规模增大、应用范围扩展，数据量急剧增长，多应用多语言共享同一数据集合的需求增强，数据库技术应运而生，出现了统一管理数据的专用软件——数据库管理系统。数据库管理系统使应用程序摆脱打开、关闭、读写文件等底层操作，数据存储细节独立于应用程序，应用可在更高抽象层访问数据，从而降低维护成本。

##### 3. 数据库产品介绍

###### 1) Access 数据库
Microsoft Office Access 是微软推出的关系型数据库管理系统，融合了 Microsoft Jet Database Engine 与图形化用户界面两项特点，是 Office 套件中的重要组件。Access 将数据以基于 Jet 的格式存放在本地数据库中，同时可直接导入或链接存储于其他应用和数据库中的数据。2012 年 12 月，Access 2013 随 Office 2013 发布。

###### 2) SQL Server 数据库
SQL Server 是一款关系数据库管理系统，最初由 Microsoft、Sybase 和 Ashton-Tate 共同开发，1988 年推出首个 OS/2 版本。Windows NT 推出后，Microsoft 将其移植到 Windows NT 并专注推广，Sybase 则侧重 UNIX 平台的应用。目前主流版本包括 Microsoft SQL Server 2008、2012、2016 等。其主要功能包括：
（1）NET 框架主机。借助 Visual C#.net、Visual Basic 等语言可创建数据库对象，并支持用户定义的类和集合。
（2）XML 技术。SQL Server 2005 原生支持存储与查询 XML 文件，便于异构应用间数据交换。
（3）ADO.NET 2.0 版本。提供对 SQL 类的新支持及 MARS，多活动结果集提升数据集访问与操纵能力。
（4）增强的安全性。新安全模型分离用户与对象，提供细粒度访问控制，系统表以视图实现以增强控制。
（5）Transact-SQL 增强性能。新增错误处理、递归查询、PIVOT、APPLY、ROW_NUMBER 等排行功能。
（6）SQL 服务中介。提供面向大型业务的分布式异步应用框架。
（7）通知服务。支持向各类设备推送个性化即时信息，如股市预警、新闻订阅等，与分析服务、 Management Studio 紧密集成。
（8）Web 服务。支持在数据库层开发 Web 服务，使 SQL Server 可作为 HTTP 监听器为网络服务提供数据访问。
（9）报表服务。提供报表控制，可通过 Visual Studio 2005 发布。
（10）全文搜索增强。编目更灵活，查询性能与可扩展性提升，管理工具对全文功能运行提供更深入洞察。

###### 3) Oracle 数据库
Oracle 数据库系统由美国 Oracle 公司提供，以分布式数据库为核心的产品群，是当前主流的客户/服务器或 B/S 体系结构数据库之一。Oracle 具有完整的数据管理功能，作为关系数据库完备，作为分布式数据库具备分布式处理能力，且跨平台知识通用。

#### 3.4.2 传感网数据管理技术

##### 1. 无线传感器网络数据管理技术
无线传感器网络数据管理系统负责对采集信息进行有效存储并建立查询处理机制，减轻用户负担，使其只需提出查询需求而无需关注物理细节。查询处理技术与数据存储技术是该领域最核心的两种技术。

##### 2. P2P 网络数据管理技术
P2P 网络即对等网，与传统 C/S 模式不同，P2P 不依赖中心服务器，而是依靠网络中各参与者的计算与带宽资源，架构对比见图 3-4-2。例如下载同时上传，节点越多速度越快，但对硬盘损耗较大。P2P 数据定位与数据复制是其重要处理技术。

图 3-4-2　P2P 和 C/S 网络架构对比

（a）P2P 对等网络；（b）C/S 网络

与 C/S 不同，P2P 网络无中心服务器，所有数据分散存储于各节点，如何高效搜索定位资源成为核心问题，数据定位技术直接影响可扩展性、性能与鲁棒性。P2P 节点兼负存储与计算，且节点可能随时离线、在线时间不固定，因此需要数据复制技术来保障可用性并加强管理。
