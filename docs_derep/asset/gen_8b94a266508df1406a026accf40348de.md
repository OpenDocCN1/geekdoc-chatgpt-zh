# 精选页小程序实战拆解

这套示例把一个新闻类精选页的骨架讲清楚了。核心是分页拉取与数据累加，先判断接口是否报错，报错直接打印并中断；有下一页就把页码自增、把新返回的条目拼到已有数组末尾再递归请求，没有下一页就把最后一批数据合并后打印完整列表。页面进入时通过 setNavigationBarTitle 把顶部标题固定为“精选”。全局配置里注册了首页、分类、收藏三个页面，窗口背景、导航栏颜色与文字样式一并定义，底部 TabBar 对应三个入口，图标随选中状态切换。首页结构用容器包裹广告条、轮播以及循环列表，列表项左右分栏，左侧放标题、来源与时间，右侧放封面图。样式上整体背景浅灰，卡片白底，头部留白，轮播固定高度，列表项使用 flex 横向布局，文字采用多行省略。网络层用 Promise 封装了两类请求，一个获取名言，一个分页获取微信文章，均通过 wx.request 发起并在成功时 resolve 数据，失败时 reject。

      pageSize:this.data.pageSize

    },

    success:(res) => {

      if (res.error){

        console.log("接口请求出错：" + res.error);

        return

      }

      //如果还有数据，则继续请求

      if (res.result.hasMore) {

        //继续请求

        this.data.page = this.data.page+1;

        this.data.dataArray = this.data.dataArray.concat(res.result.data);

        this.getTeachers();

      } else {

        //请求完所有教师数据

        this.data.dataArray = this.data.dataArray.concat(res.result.data);

        console.log(this.data.dataArray);

      }

    },

    fail:function(error) {

      console.log(error);

    }

  });
