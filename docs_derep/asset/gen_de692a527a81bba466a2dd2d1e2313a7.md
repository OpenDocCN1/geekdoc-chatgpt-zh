当我们写提示时，本质上是在和大模型展开一场精细的对话，试图把它的生成方向往我们想要的结果上 gently 拉一把。提示工程就是这场对话的操盘手，核心在于设计出足够好的指令，让模型输出更准、更稳。整个打磨过程像打磨一件工艺品，需要反复试错、精简信息、审视风格与任务是否匹配。

### 3.1.1 提示工程是什么
“工程”二字强调的是一套可复制的流程：设计、优化、评估、调试，环环相扣。先构思初版提示，再通过效果反馈优化，再用标准检验质量，最后做微调。目标就是让提示成为一套能稳定激放大模型潜力的方案。

打磨好的提示像一把通用钥匙，能打开不同任务的大门。日常里它们常用来做：
- 文本摘要：把长文压成要点清晰的精简概述
- 信息提取：从海量文本里精准抓出关键字段
- 问答交互：针对复杂问题给出完整准确的回答
- 文本分类：把内容归到正确类别
- 语言或代码翻译：实现跨语言、跨技术栈的转换
- 代码生成：按需求自动写出可运行代码
- 代码文档与推理：为代码补充说明并做逻辑推导

在科研、教育、商业里，提示工程正从辅助工具变成核心能力。它既能帮助我们更好地榨干模型的价值，也能像催化剂一样推动各领域创新。

### 3.1.2 提示工程的关键要素与DeepSeek配置
做提示工程时，先把模型配置理清楚很关键。面向不同任务微调参数，才能让输出更贴合预期。DeepSeek常用的通用对话调用示例如下：
[PRE0]
上面涉及的核心参数是输出长度和采样控制。

1. 输出长度 max_tokens
该参数决定一次响应最多产生多少个 token。令牌越多，算力、成本、响应时间都会上升。需要注意，单纯调小 max_tokens 只是硬截断，并不能让模型更简洁。想要精炼的答案，需要在提示里明确要求。像 ReAct 这类技术，限制输出长度尤其重要，能减少无效 token，提升效率。

2. 采样控制 Sampling Controls
模型预测下一个词时，先算出词表的概率分布，再从中采样。温度 temperature 就是调节这个分布的旋钮，控制确定性与多样性的平衡。

低温度 0.1～0.3：相当于给分布加聚焦。低概率选项被压制，模型偏向最高概率词，输出更稳定。适合医疗问诊这类场景，温度设 0.2 能让回答始终贴合指南；法律文书生成时也能避免奇怪表达。

高温度 0.7～1.0：相当于注入创意。尾部概率被放大，低概率词更容易被选中，输出更发散。广告文案用 0.8 可能出现“让味蕾跳探戈”这类新颖比喻；诗歌创作时也更容易出现“月光在键盘上发酵”这样的想象。

零温度 0：理论上总是选概率最大值，实际受上下文和其他因素影响并不绝对可能仍有变化。建议配合贪婪搜索 Greedy Search 这类确定性解码一起使用。

温度机制本质上是在精确和创造之间做动态权衡，开发者可按任务需求自由切换。

### 3.1.3 DeepSeek提示工程写作技巧与示例

1. 通用提示/零样本
定义：只给任务描述，不提供示例。
适用场景：任务简单且模型已有先验知识。
局限：复杂或格式要求严格的任务效果会打折。

### 3.1.4 系统、上下文和角色提示的进阶应用
在人机协同里，系统提示、上下文提示、角色提示构成三层控制框架，分别负责行为约束、情境适配、人格赋能。

1. 控制维度解析
系统提示：行为的刚性约束
通过预设规则、格式模板、伦理边界来保证输出可控。
- 医疗问诊：强制输出符合 HL7 标准的 JSON 结构化报告
- 风险防控：设定“禁止生成金融投资建议”等红线
- 知识溯源：要求优先引用《新英格兰医学杂志》数据

上下文提示：动态情境注入
把领域知识、用户画像、对话历史等喂进去，让回答贴合具体场景。
- 时序感知：客服记录“用户已尝试 3 次自助服务失败”
- 空间建模：导航整合实时位置、交通、POI 的四维信息
- 认知追踪：教育平台记录“学生已掌握微积分链式法则”

角色提示：人格化交互
通过设定知识领域、语言风格、情感温度来赋予模型人格。
- 专业权威：扮演投资经理输出合规建议
- 文化穿越：化身盛唐翰林学士适配平水韵
- 跨维度解构：扮演 22 世纪 AI 考古学家解读玛雅文明

2. 协同控制范式
三者配合形成约束-适配-赋能的体系。

智能创作协同案例
- 系统层：每段输出不超过 200 字
- 上下文层：注入用户偏好赛博朋克世界观
- 角色层：激活雨果奖得主创作人格

医疗决策支持协同案例
- 系统层：强制引用至少 3 篇 NCCN 指南
- 上下文层：嵌入 EGFR 基因突变阳性病理数据
- 角色层：模拟 MD 安德森肿瘤专家推理模式

3. 技术演进方向
- 动态权重调节系统：根据任务复杂度自动调整提示强度
- 神经符号混合架构：把逻辑规则编码为可微分模块
- 多模态提示融合：整合文本、语音、视觉上下文
- 自适应人格引擎：基于交互数据实时优化角色参数

可以说，精细的提示体系正在把大模型从随机生成器进化为情境化智能体。
