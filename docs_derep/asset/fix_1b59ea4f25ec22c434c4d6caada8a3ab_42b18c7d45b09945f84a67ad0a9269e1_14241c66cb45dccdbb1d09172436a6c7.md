# 本地 Open WebUI + DeepSeek 直连实操

想把管理界面和模型调用都放在自己的机器上跑，下面是一条从环境准备到发出请求的可直接复用的链路。

## 搭建独立环境
先用 conda 新建一个 Python 3.11 的隔离空间，降低依赖冲突。创建后初始化 conda、刷新 shell 并切进该环境。
[PRE0]bash

# 创建一个名为 open-webui 的 Conda 虚拟环境，并指定 Python 版本为 3.11

conda create -n open-webui python=3.11

# 初始化 Conda

conda init

# 重新加载 shell 配置

source ~/.bashrc

# 激活刚刚创建的 open-webui 环境，进入该环境

conda activate open-webui

## 安装 WebUI
在已激活的环境中通过清华源安装 open-webui，下载更顺畅。
[PRE1]bash

pip install open-webui -i https://pypi.tuna.tsinghua.edu.cn/simple

## 启动本地服务
安装结束直接执行 serve，服务起来后即可在浏览器打开。
[PRE2]bash

open-webui serve

## 接入 DeepSeek
使用 OpenAI 兼容的 SDK 调用 DeepSeek，先装 openai。
[PRE3]bash

pip install openai

下面是一个最简可用脚本，创建客户端、指向官方地址并发送一条问候，然后打印文本与完整对象。
[PRE4]python

import os

from openai import OpenAI

from IPython.display import display, Code, Markdown

import requests

import json

# <YOUR_DEEPSEEK_API_KEY>替换为复制的 API key 字符串

ds_api_key = '<YOUR_DEEPSEEK_API_KEY>'

#实例化客户端

client = OpenAI(api_key=ds_api_key,

                base_url="https://api.deepseek.com")

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {"role": "user", "content": "你好，好久不见!"}

    ]

)

#输出生成的响应内容

print(response.choices[0].message.content)

#输出完整的响应

print(response)

## 含系统指令的完整调用
实际对话一般先放 system 再放 user，下面演示一次带系统提示的请求并只输出生成文本。
[PRE11]

#创建用户消息

user_message = {

    "role": "user",

    "content": "你好，请介绍下你自己。"

}

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        system_message,

        user_message

    ]

)

#输出生成的响应内容

print(response.choices[0].message.content)
