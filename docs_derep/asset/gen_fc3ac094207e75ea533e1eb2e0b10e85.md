# 4.3 Tkinter 快速构建计算器

本节演示借助 ChatGPT 与 GitHub Copilot 完成一个 Tkinter 计算器的搭建。Tkinter 属于 Python 自带的图形界面库，使用时无需额外安装。

计算器形态多种多样，这里做一个基础版：在窗口中放置 0到9 的十个数字键，以及 + - * / . = 六个功能键，共 16 个按键，可排列成 4 行 4 列。图 4-6 给出 macOS 系统上的计算器参考。交互逻辑是：点击除 = 外的按键，字符会追加到上方输入框；点击 = 时，对输入框里的表达式进行实时求值；双击输入框则清空内容。

由此可归纳出实现要点：

+   - 布局：借助网格布局把按钮排成行列。- 按钮点击响应：非 = 按键追加字符，= 按键触发计算。- 输入框双击响应：双击后清空文本。

ChatGPT 可处理大量输入，但任务过复杂时容易只完成部分或遗漏。鉴于计算器业务逻辑并不简单，采用分步推进更稳妥。

# 图4-10 最终要实现的布局效果

初看布局显得杂乱，实际窗口在垂直方向被均分为上下两块，上块水平均分为三份，下块水平均分为两份。从左到右、从上到下，每个区域都有各自的排版规则，属于组合式布局。用一段文字完整描述会过于繁琐，ChatGPT 难以一次性准确实现。因此采用分治策略：先生成仅包含顶层 5 个区域的窗口框架代码，再为这 5 个区域各自生成布局，最后把各区域代码嵌入主窗口。为便于维护，每个区域单独放在一个 Python 文件，以类形式存在。借助 ChatGPT 与 Copilot 多步完成图4-10 的搭建。

# 4.4.1 先做总框架

生成总布局时，需要给 ChatGPT 的要点包括：

+   * 窗口尺寸是1000*800。

* 窗口在垂直方向等分为上下两部分，上半部分在水平方向等分为3部分，下半部分在水平方向等分为两。

# 4.4 PyQt6 分步搭建复杂布局

+   * 窗口缩放时，5 个区域仍保持相对位置。

+   * 每个区域使用 QFrame 作为容器，便于后续对接。QFrame 是模块与主程序的连接点，接口必须提前确定，否则多文件无法串联。

+   * 通过坐标与尺寸直接控制 5 个区域的相对位置，以提升兼容性。若某区域尺寸异常，强制控制可避免整体变形。

综合以上要点，可向 ChatGPT 发送如下指令。

使用PyQt6创建一个1000*800的窗口。将窗口在垂直方向上等分为上下两部分，将上半部分在水平方向上等分为3部分，将下半部分在水平方向上等分为两部分。一共将窗口分为5部分，每一部分是一个QFrame对象。每一部分随着窗口尺寸的改变，仍然保持水平和垂直等分布局。为每一部分设置不同的背景色，每一部分要直接使用QFrame对象的位置和尺寸控制，在resizeEvent中实现。给出完整的实现代码和中文注释。
