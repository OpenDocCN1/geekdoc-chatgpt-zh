### XGBoost 目标函数推导与树结构优化

XGBoost 的目标函数由损失函数与正则化项组成，正则化项定义为：

$\Omega\left(f_t\right)=\gamma T+\frac{1}{2} \lambda \sum_{j=1}^T w_j^2$

其中 $T$ 代表叶子节点总数，$w$ 为叶子权重。该项通过惩罚叶子数量及权重平方和，有效抑制模型复杂度，防止过拟合。

为简化计算，引入索引集合 $I_j=\left\{i| q\left(x_i\right)=j\right\}$，即落入第 $j$ 个叶子的样本索引集。利用二阶泰勒展开，目标函数近似为：

$L^{(t)} \approx \sum_{j=1}^T \left[ \left( \sum_{i \in I_j} g_i \right) w_j + \frac{1}{2} \left( \sum_{i \in I_j} h_i + \lambda \right) w_j^2 \right] + \gamma T$

$g_i, h_i$ 分别为上一轮模型预测值对应的损失函数一阶、二阶导数，在当前轮迭代中视为常数。令 $G_j = \sum_{i \in I_j} g_i, H_j = \sum_{i \in I_j} h_i$，目标函数重写为：

$L^{(t)} = \sum_{j=1}^T \left[ G_j w_j + \frac{1}{2} (H_j + \lambda) w_j^2 \right] + \gamma T$

由于各叶子节点项相互独立，可单独求解每个 $w_j$ 的最优值。对单项 $G_j w_j + \frac{1}{2} (H_j + \lambda) w_j^2$ 求导置零，得最优叶子权重：

$w_j^* = - \frac{G_j}{H_j + \lambda}$

将最优权重代回目标函数，得到该结构下的最优目标值：

$L = - \frac{1}{2} \sum_{j=1}^T \frac{G_j^2}{H_j + \lambda} + \gamma T$

此公式为评估树结构优劣提供了依据。若某节点分裂为左、右子节点，分裂前后目标函数变化量（增益）为：

$Gain = \frac{1}{2} \left[ \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} \right] - \gamma$

仅当增益大于 0 时才进行分裂，否则保持叶子节点。

#### XGBoost 的分裂寻优策略

**特征预排序**
为加速寻找最优分裂点，XGBoost 采用预排序机制：
1.  **预处理**：训练前对各特征列排序并存储索引。
2.  **层层遍历**：从根节点开始，对每个叶子节点枚举所有特征。
3.  **线性扫描**：利用有序索引，线性遍历特征的所有可能切分点计算增益。
4.  **最优分裂**：选取增益最大的特征及切分点分裂节点。
此法将寻找分裂点的复杂度从排序的 $O(ND\log D)$ 降至遍历的 $O(ND)$（N 特征数，D 样本数），显著提升效率。

**近似切分点策略**
面对海量数据，全遍历仍显吃力。XGBoost 提供近似算法，基于特征分位数将连续值离散化为桶，仅遍历分位点。
- **Global（全局）**：训练初一次性确定所有特征的分位点，全程复用。
- **Local（局部）**：每次分裂前重新基于当前节点数据计算分位点，精度更高但耗时稍长。

### LightGBM：高效梯度提升的实践者

#### 模型定位
LightGBM 同属 Boosting 阵营，在 XGBoost 基础上针对**训练速度**、**内存占用**及**类别特征支持**做了深度优化。其直方图决策、叶子优先生长等创新，使其在大规模数据上表现卓越，且原生支持类别特征（如“是否包邮”），免去 One-Hot 编码之苦。

#### 核心优化技术

**1. 直方图决策算法**
弃用预排序，改用直方图统计梯度信息。
- **离散化分箱**：将连续特征映射为 $k$ 个整数区间，构建宽度为 $k$ 的直方图，累积每个桶内的 $G, H$ 统计量。
- **降维搜索**：寻找分裂点时仅在 $k$ 个桶边界中枚举，复杂度由 $O(ND)$ 降为 $O(Nk)$。
- **差分加速**：子节点直方图 = 父节点直方图 - 兄弟节点直方图。仅需构建较小兄弟节点的直方图，大幅减少计算量。
实验表明，适度离散化不损精度，反而因基学习器弱特性及正则化效应，可能抑制过拟合。

**2. 单边梯度抽样 (GOSS)**
受 AdaBoost 样本重加权启发，LightGBM 引入梯度作为样本权重。GOSS 保留大梯度样本（欠拟合样本），随机下采样小梯度样本并乘以权重系数 $(N-A)/B$ 补偿分布偏移。
- **流程**：按梯度绝对值降序 -> 保留前 $A$ 个 -> 从剩余 $N-A$ 中随机抽 $B$ 个并加权 -> 共 $A+B$ 样本计算增益。
兼顾了“关注难例”与“维持数据分布”的平衡。

**3. 互斥特征捆绑 (EFB)**
针对高维稀疏特征（如 One-Hot 后的向量），利用“互斥性”（两特征不同时非零）将多特征合并为一维。
- **选对策略**：建模为图着色问题，贪心近似求解互斥特征组合。
- **合并编码**：为特征加偏移量错开取值范围（如特征A [1,2]，特征B [1,3] 偏移2变 [3,5]），合并后无信息损失，特征维度大幅压缩。

**4. Leaf-wise 叶子优先生长**
对比 XGBoost 的 Level-wise（层级生长，利于并行但产冗余分裂），Leaf-wise 每次寻找**全局增益最大**的叶子进行分裂。
- **优势**：同层数下误差降得最快，模型更紧凑。
- **防过拟合**：配合 `max_depth` 限制深度，兼顾泛化能力。

### 随机森林：Bagging 范式的集大成者

#### 模型概览
随机森林采用 **Bagging（Bootstrap Aggregating）** 框架，训练大量相互独立的决策树，通过**投票（分类）**或**平均（回归）**融合预测。与 Boosting 串行依赖不同，其并行训练特性赋予了极强的鲁棒性与抗过拟合能力。

**分类示例**：100 棵树，90 棵判“补货”，10 棵判“不补”，最终结果为“补货”。
**回归示例**：真实值 100，三棵树预测 105, 96, 98，集成均值 99.7，误差 0.3%，显著优于单模型。

#### 算法流程详解
1.  **自助采样**：对 $M$ 个样本有放回抽样 $M$ 次，生成新训练集（约 63.2% 覆盖率），重复 $T$ 次得 $T$ 个数据集。
2.  **特征随机性**：构建每棵树时，节点分裂不遍历全量特征，而是随机选取 $m \ll M$ 个特征子集，在其中寻找最优分裂。此举去相关化，增强集成多样性。
3.  **全量生长**：树生长至纯或不可分裂，**不剪枝**，保证单树低偏差。
4.  **集成预测**：分类用多数投票，回归用算术平均。

多样性（样本扰动 + 特征扰动）与独立性是随机森林泛化性能的基石。

#### 5.1.3 训练核心概念

权重优化依赖 **随机梯度下降 (SGD)** 与 **反向传播 (Backprop)**。但深层网络训练面临两大难题：
1.  **过拟合**：Hinton 提出 **Dropout** 随机失活神经元，强制学习鲁棒特征。
2.  **梯度消失/爆炸**：**预训练**（逐层无监督初始化）缓解早期深层网络训练困境，为后续 ResNorm、ReLU 等现代技术铺路。

这些基石概念构成了现代深度学习大厦的地基。
