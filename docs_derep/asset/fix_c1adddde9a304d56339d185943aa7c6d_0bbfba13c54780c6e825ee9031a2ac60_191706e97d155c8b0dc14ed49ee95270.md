# 扩散模型：原理到工程落地的完整拆解

能量基模型 Energy-Based Model, EBM [26, 48, 58, 64, 67, 68, 75, 78, 79, 120, 129, 132, 165, 170, 182, 196, 254, 281] 本质上可看作一种兼具生成与判别性质的建模思路 [79, 104, 131, 134]，它能够在无标注样本上完成学习。令训练样本 x ~ p_data (x)，p_θ(x) 为试图逼近

p_data (x)。EBM 的表达形式为：

pθ(x) = 1/Z_θ exp(f_θ(x))

其中 Z_θ = ∫exp(f_θ(x)) dx 为归一化系数，在高维情形下难以解析得到。对图像而言，f_θ(x) 由输出为标量的卷积神经网络来参数化。Salimans 等人 [204] 把受约束的分数模型与 EBM 放在同一评价体系下比较分数建模能力，最终发现受约束的分数模型实质上等同于一种 EBM。当模型结构保持可比时，EBM 的效果可以达到与无约束版本相当。图 6-5 展示了 EBM 训练前后的变化。

即便 EBM 具备不少理想特性，在高维数据上仍存在两大难点。一是经最大似然训练的 EBM 生成样本通常依赖 MCMC，计算开销往往很高。二是实践中非收敛的 MCMC 学习到的能量函数容易出现不稳定，长期链产生的样本与观测样本相差明显。Gao 等人 [69] 提出扩散恢复似然方法，在扩散模型的逆向过程中串联多组条件 EBM 来刻画样本分布。该串联中，上一组条件 EBM 产生的噪声较大的样本被下一组接收并进行去噪，从而得到噪声更小的样本。条件 EBM p_θ(x|ẋ) 使用恢复似然进行训练，即在给定高噪声样本 ẋ 的情形下，以低噪声数据 x 的条件似然为目标，最大化在更高噪声情形下低噪声水平数据的条件概率。

条件 EBM 更容易提升恢复似然，因为原始数据的边际分布常呈现多模态，而在加噪样本条件下，原数据的条件概率相较边际似然更易处理。从条件分布抽样远比从边际分布抽样简便。当每次加入的噪声增量足够小，条件 EBM 的条件似然可近似为高斯。于是扩散恢复似然中逐个条件 EBM 的采样过程近似于逆扩散中的逐次去噪。Gao 等人 [69] 还证明了在噪声增量足够小的条件下，扩散恢复似然的最大似然训练与 Score SDE 的分数匹配训练近似等价，从而搭建起 EBM 与扩散模型之间的桥梁。扩散恢复似然能够产生高质量样本，且长期 MCMC 得到的样本仍与真实图像相近。

# 第6章 扩散模型与其他生成模型的关联

扩散模型因其出色的生成能力与灵活性，被广泛用在各类挑战性任务中。按任务可划分成 6 个方向：计算机视觉、自然语言处理、时序建模、多模态学习、鲁棒学习以及跨学科应用。对每个方向都会先说明任务定义与经典方法，再讲述扩散模型的接入方式。此处先概括扩散模型在应用时的两种基本使用方式：无条件扩散模型 Unconditional Diffusion Model 与条件扩散模型 Conditional Diffusion Model。作为生成范式，扩散模型与 VAE、GAN、Flow 的演进路径相似，都是先做无条件生成再发展条件生成。无条件生成主要用于探测性能上限，条件生成更偏向实际应用，因为可以按需求调控输出。下面重点介绍条件扩散模型。如图 7-1 所示，相较无条件版本，条件扩散模型额外加入引导信息 c 和条件机制，二者共同引导反向采样过程 p_θ。引导信息形式多样，可包括类别、风格、图像、文本，甚至药物设计中的靶点蛋白、分类器梯度等人工定义的特征。条件机制的形式也多样，从简单拼接、交叉注意力到自适应层归一化不等，条件扩散模型在可控生成中作用愈加关键。

# 7.1 无条件扩散模型与条件扩散模型

扩散模型凭借强大的生成性能与灵活性，被用于解决多类现实难题。依据任务类型将其归为 6 大方向：计算机视觉、自然语言处理、时间序列建模、多模态学习、鲁棒学习和跨学科应用。对每个方向先交代任务定义与相关经典方法，再详述扩散模型的适配方式。此处先简要说明两种基本使用范式：无条件扩散模型与条件扩散模型。作为生成模型，扩散模型与 VAE、GAN、Flow 的演进相似，均由无条件到条件逐步发展。无条件生成侧重探索模型上限，条件生成更强调应用可控性，能按需求调控输出结果。下面聚焦条件扩散模型。如图 7-1 所示，条件扩散模型在无条件基础上增加了引导信号 c 与条件机制模块，二者对反向采样 p_θ 产生重要引导。引导信号可以是类别标签、风格、图像、文本，甚至药物设计中的靶点蛋白、分类器梯度等人工特征。条件机制的形式丰富，包括拼接、交叉注意力、自适应层归一化等，条件扩散模型在可控生成中愈发重要。

# 7.2 计算机视觉

# 7.2.1 图像超分辨率、图像修复和图像翻译

本节介绍图像超分辨率、图像修复与图像翻译的定义及常见算法。

图像超分辨率 Image Super Resolution 是指借助计算方法把低分辨率图像提升为高分辨率的过程。该技术在数码相机、视频设备、医学影像等领域有广泛需求。常见算法包括：

- 插值法。最基础的方法，通过低分辨率像素邻域的加权平均生成高分辨率图像。典型代表为双线性插值与三次插值。实现简单但易产生模糊与失真。
- 基于样本的方法。通过大量高分辨率图像学习特征，提升超分辨率效果。先训练低分辨率到高分辨率的映射，再用其预测。典型如最近邻算法。
- 基于稀疏表示的方法。利用低分辨率与高分辨率之间的稀疏线性组合实现超分。先构建字典，再用稀疏编码从字典中挑选最适配的样本。代表方法有 K-SVD 与 BM3D。
- 基于深度学习的算法。近年主流，使用卷积神经网络学习映射。需大量训练数据，但效果突出。代表有 SRCNN、VDSR、SRGAN 等。

图像修复 Image Inpainting 是指修复图像中缺失或损坏区域的方法。应用于图像编辑、计算机视觉、医学图像处理与数字文物保护等。常见算法：

- 基于插值的算法。用邻域像素平均值或线性插值填补缺失区。易实现但质量有限。
- 基于偏微分方程的算法。利用 PDE 描述图像边缘与纹理，通过优化能量函数生成修复结果。常用拉普拉斯、欧拉-拉格朗日方程等。
- 基于纹理合成的算法。利用纹理与结构信息生成缺失内容。可分为区域合成与像素合成。前者复制相似纹理结构区域，后者复制像素值相似的像素。
- 基于机器学习的算法。用神经网络等模型预测缺失像素。需大量数据与计算，但可得到高质量结果。

图像翻译 Image Translation 是指将一种图像转化为另一种图像的过程。可实现风格转换、色彩改变、分辨率转换等，在生成、风格迁移、增强等领域应用广泛。常见算法：

- CycleGAN。无监督图像翻译，保持内容不变将图像从一域映射到另一域。利用对抗损失与循环一致性损失训练生成器与判别器。广泛用于风格迁移。
- Pix2Pix。有监督图像翻译，用条件生成对抗网络学习输入输出映射。需要成对训练数据。
- StarGAN。多域图像翻译，可将图像转为多种风格。采用共享生成器与多任务判别器，无需成对数据，可同时学习多种风格。

# 扩散模型在图像任务中的实践路径

总体来看，以 GAN 为代表的深度学习方法长期主导图像生成。扩散模型的快速发展使其在超分、修复、翻译三大任务中的使用明显增加。例如实现迭代细化的超分辨率方法 Super-Resolution via Repeated Refinement, SR3 [202] 利用 DDPM 实现条件生成。SR3 通过随机迭代去噪获得超分辨率结果。级联扩散模型 Cascaded Diffusion Model, CDM [91] 由多个扩散模型串联，逐级提升分辨率。如图 7-2 所示，CDM 框架图 [294] 由多个级联的类别条件扩散生成模块与超分辨率扩散模块组成。SR3 与 CDM 均直接在输入图像上进行扩散，需更多生成步数。

为在有限算力下训练扩散模型，部分方法 [198, 234] 使用预训练自编码器将扩散过程迁移至潜在空间 Latent Space。通过在潜在空间扩散，潜在扩散模型 Latent Diffusion Model, LDM [198] 在不损失样本质量的前提下简化训练与采样。具体而言，LDM 用预训练自编码器把扩散从像素空间搬到潜在空间，大幅降低计算消耗。由于在语义空间进行扩散，引导信息与图像特征的交互更为充分。实验显示 LDM 的生成效果超越此前 SOTA 的 DALL·E 2 与 VQGAN。LDM 框架图 [295] 包含三部分：像素到潜在的转换模块、潜在空间扩散生成、用于条件控制的 Conditioning 模块，如图 7-3 所示。
