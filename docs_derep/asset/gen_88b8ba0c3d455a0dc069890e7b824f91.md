Transformer 在训练时，靠掩码来划定注意力边界，让编码器和解码器都不会超出当前任务允许的上下文范围。编码侧主要屏蔽填充产生的无效位置，避免模型浪费注意力；解码侧则使用自回归掩码，限定每个位置只能看到自身及前面已生成的 token，从而维持生成顺序。

简单说，掩码就是给注意力划禁区，禁止解码阶段窥探尚未产生的词，保证输出只基于已有的内容。它大致可归为两类：自回归用的自注意力掩码，和处理变长序列用的填充掩码。

- 自注意力掩码：在解码器的自注意力层中，掩码会把未来位置挡住，使得生成下一个词时只能依赖已生成的词，从而避免序列生成的信息泄露。
- 填充掩码：在批量处理长度不一的句子时，用填充值补齐短句，掩码会把这些填充位丢弃，让模型只关注真实内容，提升处理效率。

举个例子，模型正在把“我爱自然语言处理”译成英文。在生成 language 之前，掩码会遮住 processing 等尚未出现的词，只允许模型参考已经生成的 love natural。这样每一步的生成都建立在可靠的历史信息上，不会提前用上未来信息。

### 3.1 注意力机制的基础与实现原理

注意力核心在于用权重分配让模型聚焦序列的关键位置，从而捕捉重要上下文。本节从点积注意力的基本运算讲起，解释为何需要缩放，即用缩放因子抑制高维点积的极值，避免梯度不稳。

权重还需要符合概率分布的特性，Softmax 常被用来做归一化，通过指数放大突出显著特征。本节结合代码演示，帮助建立对注意力计算过程和关键组件的直观理解。

#### 3.1.1 点积注意力与缩放机制

点积注意力用于衡量序列不同位置的相关性。做法是把 Query 与 Key 做点积得到相似度分数，再用这些分数对 Value 做加权求和。为了防止高维下点积数值过大导致梯度不稳，通常除以特征维度的平方根进行缩放。

实际中，随着维度升高点积值会膨胀，Softmax 容易饱和。于是用 Query 与 Key 维度的平方根来缩放点积，使分布更稳定，便于训练。

好比在人多的场合找同好，Query 是你自己，Key 是别人，点积是相似度。若相似度过大则难以区分，缩放就像调节音量，让差异更清晰，从而更容易锁定目标。
