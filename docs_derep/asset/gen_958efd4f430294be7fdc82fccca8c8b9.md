- Top-P：用于限制模型在生成每个词时可供选择的词池范围。举例说把 Top-P 设为 0.7，模型只会在累计概率最高的 70% 词里抽样。数值越高，输出越发散、变化越大，但也更容易偏离预期；数值越低，输出越集中、越精准。
- Top-K：另一种限定词池的方式，只让模型在概率最高的 K 个候选词里挑选。如 Top-K 设为 50，就只从前 50 个最可能的词中选择。K 值偏大时生成更流畅，K 值偏小时更可控，也更易偏离原意。
- Frequency Penalty：用来抑制重复生成的倾向。设为 0 则不做惩罚，重复内容会更常见；调高后重复概率下降，文本多样性提升。

这三项参数能让使用者精细调节回答风格，比如拉长篇幅、增强创意，或追求更准确、不堆砌的表达。

#### 5.2 DeepSeek本地部署

当前大语言模型应用广泛，但多数被大厂以云服务形式提供，会限制开发者深度探索和个性化改造。比如在银行用 AI 分析客户数据，若上传云端，就像把金库钥匙交给陌生人；偏远地区网络不稳，每次提问都受网络制约；创业公司想定制专属系统，商业 API 却像租来的房子难以改造。正是这些痛点，推动越来越多团队选择本地部署。

##### 为什么要选择本地部署大模型？
- 数据隐私与安全：敏感数据留在本地处理，避免上传云端带来的泄露风险。
- 降低延迟提升响应：摆脱网络波动，本地推理更顺畅。
- 定制化与可控性：可按需微调、优化模型，灵活性更高。
- 成本更可控：前期投入硬件后，长期运行费用远低于持续付费的云服务。
