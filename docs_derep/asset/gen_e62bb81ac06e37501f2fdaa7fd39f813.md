## 第五章 综览文献：进行学术文献综述

本章说明 ChatGPT 如何辅助完成文献综述与总结。综述帮助研究者把握前人成果、厘清已知与未知、认识方法局限与知识缺口，并为后续研究提供方向。

综述可分为随意型与严谨型。叙述性综述常具选择性，而发表于同行评审期刊的系统综述通常遵循 PRISMA 指南。系统综述一般在 PubMed、Web of Science 等多个数据库全面检索，并按预设方案筛选、提炼。

按流程，综述方案的核心要素包括：

+ 1. 基于 PICOS 框架的人群、干预、对照、结局、研究设计等纳入标准，界定研究范围。
+ 2. 针对各数据库定制的检索式与策略，保证全面性。
+ 3. 筛选与选择流程，确保符合预设标准。
+ 4. 数据提取，收集研究特征、方法与结果。
+ 5. 质量评价，评估方法严谨性与偏倚风险。
+ 6. 数据综合与分析，定量或定性视问题而定。
+ 7. 报告发现、局限与未来建议。

在此框架下演示如何用 ChatGPT 降本增效。

首先，可与 ChatGPT 共建 PICOS。

提示词：
