# 第五章 法务文书的智能化撰写思路

任务的个性化拆分
在实操层面，可以把相对固定且偏运算的工作交给生成式模型来先行处理，例如本例中的利息累积核算。需要注意的是，未挂载计算插件时模型的算术稳定性不足，遇见跨月累加时建议调用第二章第三节提到的 Wolfram 插件进行复核。

下面以催款函的提示设计为例进行说明。

假设你是广东某律所的唐僧律师，受孙悟空委托向猪八戒发出催款函。案情要点为：2022年1月1日，猪八戒经银行转账收到孙悟空支付的100万元本金，双方签订的《借款协议》约定月利率1%、每月末结清当月利息，本息最迟须于2022年12月31日前清偿。截至发函日2023年6月1日，仅在2022年1月支付过1万元利息，后续本息均未履行。请在函件中写明自放款日至发函日的未结本金与利息金额。

## 法律人 ChatGPT 应用指南

+ 用语可调：需要更典雅的法言法语时可提示模型切换风格；
+ 法条补充：可要求模型依据事实列示适用条文；
+ 版式优化：可按“事实、法律分析、函告预警”重排，或删除函首收件人等要素。

## 写起诉状

起诉状的核心是诉讼请求加事实理由。描述方式与写函相近，但需提供标准状式框架，可参考法院官网或《民事诉讼文书样式》。指令示例为：

你是孙悟空的代理律师，按以下事实起草起诉状：猪八戒于2022年1月1日收到孙悟空转账100万元，协议约定月息1%、月末付息、2022年12月31日前还本付息。至2023年6月1日，仅支付2022年1月利息1万元，其余未付。

格式要求：原告信息、被告信息、诉讼请求、事实和理由、证据来源、证人信息等。

模型输出要点如下：

原告：孙悟空，汉族，住址XXX，联系方式XXX。委托诉讼代理人：唐僧律师，律师证号XXX，所在律所XXX。

被告：猪八戒，男，住址XXX。

诉讼请求：
+ 判令被告立即归还原告借款本金100万元；
+ 判令被告支付自2022年1月1日起至起诉日2023年6月1日止的利息，按月利率1%计；
+ 判令被告承担本案诉讼费、律师费等合理费用。

事实和理由：
+ 原被告签署《借款协议》，原告于2022年1月1日转账支付100万元；
+ 协议约定月息1%、月末付息、2022年12月31日前还本付息；
+ 截至2023年6月1日，被告仅付2022年1月利息1万元，未付本金及其他利息；
+ 原告多次催告未果，被告严重违约。

证据和证据来源：借款协议原件及银行转账记录、律师函及往来通讯、证人证言。

此致××人民法院

## 起草合同

### (一) 识别风险

合同的核心在于风险预控。代表出租人起草《房屋租赁合同》前，先让模型列出出租环节常见的法律风险。

提问：出租房屋过程中出租人可能遇到哪些法律风险？请列举。

模型给出的风险清单包括：
+ 违反租赁法规：租金收取、合同签订履行、房屋维护等需合规，违规会产生责任与损失；
+ 合同纠纷：条款不清或租金支付、义务履行产生争议需诉讼解决；
+ 房屋损坏与维护责任：出租人须确保房屋安全完好，维修不及时可能被索赔；
+ 侵权责任：因安全隐患导致承租人或第三方伤损需担责；
+ 违规出租：擅自改变用途、未按居住管理规定出租等会被处罚；
+ 税务风险：未按规定缴纳租赁税、个税等会被追缴处罚；
+ 背景调查不足：租客身份信用未核实易出现拖欠、违约。

iLaw 的风险提示更贴近本土视角：
+ 租赁合同纠纷：租金、租期、押金、维修责任等分歧；
+ 房屋权属纠纷：出租人并非真正所有人或存在共有问题；
+ 房屋质量问题：漏水、电路等引发投诉诉讼；
+ 房屋用途问题：用于赌博、吸毒等非法活动需担责；
+ 房屋安全问题：火灾、电梯事故等安全隐患；
+ 房屋违建问题：违法建筑被拆除；
+ 房屋租赁税务问题：未缴税费被追缴处罚；
+ 房屋转租问题：承租人擅自转租引发纠纷；
+ 房屋退租问题：提前退租或拖欠租金。

### 请你代表出租人，起草一份《房屋租赁合同》，保护出租人利益，覆盖上述全部风险点并对应设条款约束承租人。

模型生成的合同要点包含：
+ 乙方须妥善保管房屋及设施，发现损坏或需维修应及时通知甲方，未通知或擅自修理费用自负；
+ 因乙方过失导致损坏，乙方负责修复或承担费用；
+ 因房屋安全隐患或维护缺失导致乙方或第三方伤损，甲方承担侵权责任并赔偿；
+ 乙方不得转租或违反租赁用途，违约时甲方可解除合同并索赔；
+ 甲方按法缴纳税费并提供证明，乙方履行个税等义务，违导致甲方被追责的乙方赔偿；
+ 甲方有权进行背景调查，乙方须提供真实证件材料；
+ 其他补充协议同等效力，合同自签字盖章生效至租期届满。

### (三) 补充完善

模型生成的基础合同仍需按实务经验补强。例如要求补充：

1. 承租人在房屋内从事违法犯罪活动，出租人有权即时解除合同并要求赔偿损失；
2. 因承租人原因致房屋空置，出租人有权即时解除合同，出租人应向承租人赔偿6个月空置补偿；
3. 增加争议管辖条款。

模型可据此输出个性化条款。
