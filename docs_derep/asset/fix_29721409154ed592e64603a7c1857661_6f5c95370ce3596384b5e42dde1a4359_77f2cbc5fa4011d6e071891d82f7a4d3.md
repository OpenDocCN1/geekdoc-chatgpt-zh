## 图像分类的底层逻辑

哪吒的“虾兵蟹将识别眼”是怎么炼成的？

本质上就是用了人工智能里的图像分类技术，即根据每张图片的特征判断类别。炼制这个法宝要经历图像信息输入、特征选择与表示、分类函数设计、模型训练与评估四个环节。

### 图像信息如何被计算机读懂

人有视觉系统，能轻松获取图像信息，计算机又是怎么感知并提取信息的？

如图2-4所示，把图像放大到一定程度，会看到它由一个个等大的正方形格子构成，每个格子的颜色不同，这些格子叫像素。我们在电脑里看到的图像就是由像素组成的。常说的分辨率 592×394，就是横向 592 个像素、纵向 394 个像素。

图2-4 计算机中的图像

如图2-5所示的灰度图像，每个像素常用 0 到 255 的数字记录明暗。0 代表最黑，数值越大越亮，255 为最白。

图2-5 灰度图像

对于如图2-4所示的彩色图像，每个像素不再是单一数值，而是三个 0 到 255 的值，分别对应红、绿、蓝三种基础颜色的明暗，通过三色组合得到彩色像素，所以彩色图像也称 RGB 图像。凭借这些像素值，计算机就能获取图像所表达的内容。

### 特征选择与表示

要分辨虾兵和蟹将，就要观察各自的特点。它们虽同属十足目，但虾兵体形细长圆筒，蟹将体形扁圆，所以可用体态形状，即身体长度和宽度来区分。这种刻画事物某一方面特性的数字或属性，称为特征。

假设实测得到虾兵蟹将的特征：身体长度与宽度。在数学上可用 x₁ 表示长度，x₂ 表示宽度，方便起见写成（x₁，x₂）形式，这组数据在数学里叫向量，也是二维空间中的一个点，即 x 轴为 x₁、y 轴为 x₂ 的点。

向量就是若干数字按序排列，如（2，8，4）。数字个数叫维数，（2，8，4）的维数是 3，可看作 x、y、z 轴取值分别为 2、8、4 的三维空间点。

把描述事物的特征数值组织起来，形成特征向量。一般 n 维特征向量可表示为 x={x₁, x₂, ..., xₙ}，即 n 维空间中的一点。用此方法，每张虾兵蟹将照片都能转化为有意义的特征向量，即 n 维空间中的一点，从而把图片分类问题转化为数学几何中的点分类问题。

### 模型训练与评估

怎样选择合适的参数值才能准确分开虾兵蟹将？

这些参数的取值类似于人脑的处事原则和判断标准。人类并非天生就会识文断字，需要学习过程，人工智能亦然。我们称之为训练。对虾兵蟹将一无所知时，难以辨认；当有人反复告知这是虾兵、这是蟹将，积累足够信息后，神经系统会自动提炼特征，之后就能轻松辨认，甚至遇到从未见过的波纹龙虾也能判断为虾。

知识点

准确率（Precision）=正确识别的虾兵蟹将数/虾兵蟹将总数×100%

召回率（Recall）=正确识别为虾兵的数量/虾兵原本的数量×100%

F1值=（准确率×召回率）/（准确率+召回率）
