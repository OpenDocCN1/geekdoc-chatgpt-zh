多张参考图其实可以一起当垫图用，模型就会融合这些图的共同特征。把多张图链接都放到提示词的最前面，链接之间用一个空格隔开即可。

垫图部分的通用写法是：垫图链接 + 风格关键词 + 想要的效果 + 人物细节描述 + 参数。把垫图用起来，能让画面控制力明显提升。

## 6.4 创作故事绘本

绘本就是图画和文字搭伙的图书，精致的插画配上简短的文字，把故事或知识讲给读者。这样的形式很能点燃孩子的想象力、创造力和阅读兴趣，内容从童话寓言到科普知识都有，既能玩又能学，是亲子共读很理想的选择。

做绘本是专业活，尤其是插画，需要扎实的绘画功底和丰富的想象力。现在 AI 发展很快，用 Midjourney 这类工具，哪怕没有美术基础的人也能把自己的故事变成令人惊艳的绘本。

绘本的核心是故事和插画，这里只聊插画的部分。

和单张插画不一样，绘本是一组相互关联的画面。角色长相、场景背景、绘画风格都得保持统一，而 Midjourney 对细节的把控相对有限，所以要想连贯并不容易。

### 6.4.2 绘本创作要点

从例子可以总结出两点保证连贯性的方法：一是给角色做清晰设定，比如年龄、发型、穿着、标志性配饰，甚至直接套用知名人物或动物形象，给主角一个稳定的框架；二是指定艺术家或明确的绘画风格，让整组画面风格统一。角色描述和风格关键词要在所有画面中保持一致。

具体操作就像电影分镜一样，先把故事拆成若干镜头，为每个镜头提炼精简的提示词，再用 Midjourney 生成对应插画。

把这些插画串联起来，就能得到连贯的故事绘本。即便没有专业美术背景，也能顺利完成。

## 6.5 本章小结

本章梳理了 Midjourney 的进阶用法：用 Niji 模型画出动漫风格插画，用 /describe 命令从已有图片反推出提示词，用垫图来影响生成结果，最后用 Midjourney 创作多幅插画构成的故事绘本。

学完这些，对 Midjourney 的能力边界和操作方式会有比较全面的认识，能够画出各种精美的作品。

Midjourney 是一个很强的创作工具，目前仍有不足，但迭代速度很快，未来功能会更丰富、体验会更好。无论是专业设计师还是业余爱好者，把它用好都能获得更多灵感，让创意工作更高效有趣。

## 第 7 章

### Stable Diffusion 介绍

在最近的 AI 绘画浪潮里，Stability AI 开发的 Stable Diffusion 极具代表性。得益于出色的生成质量、完全开源以及能在消费级显卡上运行的门槛，它发布后迅速走红，开发者和公司纷纷参与共建，也催生了大量基于它的绘画应用。

技术上它基于扩散模型实现。迭代很快，截至本书写作时最新版是 2.1，1.5 版依然很常用。

如果把 Midjourney 形容成自动挡，Stable Diffusion 就像手动挡，上手门槛稍高，但熟练后自由度更大。

下面开始学习这个神奇的工具。

## 7.1

### 在本地安装和运行 Stable Diffusion Web UI

网上有不少基于 Stable Diffusion 的在线服务，AI 绘图耗资源，多为收费，也提供少量免费额度。如果本机配置够用，也可以本地安装运行，探索不受限制。

Stable Diffusion 本身没有图形界面，需要命令行调用，对普通用户不友好。社区里出现了很多图形化方案，其中最流行的是 Stable Diffusion Web UI，它是基于浏览器的操作界面，也是免费开源项目。

[PRE7]

后续案例都以 Web UI 为主，先介绍本地安装和运行的方法。

### 7.1.1 安装准备

Web UI 能在消费级电脑上跑，但对硬件和软件仍有要求。

- 1. 硬件要求

图像生成主要靠 GPU，要求独立显卡，NVIDIA 官方推荐，AMD 也可支持，苹果 M1/M2 芯片也可。

显卡性能直接影响速度，顶级卡几秒出图，性能弱的卡几十秒甚至几分钟。AI 绘画需要反复微调，速度影响效率。

显存影响画质和尺寸，显存小只能画小图，自行训练也受限，建议至少 8GB。

表 7-1 为参考配置。

表 7-1

|---|---|---|
| CPU | 无硬性要求 | 支持 64 位的多核处理器 |
