## 1.4 提示词的运用

在通义里，提示词是人与模型交互的桥梁，写法熟练度直接决定结果质量。

### 1.4.1 提示词是什么

提示词是用自然语言向通义下达指令的表达。可简单如“今天北京天气怎样？”，也可复杂如“帮我写一首关于春天的诗歌”。

借助清晰的提示词，用户意图更易被理解，通义依托自然语言处理与深度学习能力给出匹配回应。简单说，提示词就是告诉模型你需要它做什么。表达越明确，交互效率越高，获取信息、创作内容、执行任务都更顺畅。

### 1.4.2 如何构建优秀的提示词

优质提示词能让通义更精准把握意图，交互效果更好；模糊表述则浪费时间且结果不佳。

#### 1. 提示词的构成要素

提示词 = 工作指令 + 背景资料 + 要点词 + 约束条件。

- 工作指令：明确说明希望通义完成的具体事项，可是提问、主题或操作。
- 背景资料：提供上下文或前置信息，帮助模型更好理解需求。
- 要点词：突出模型需关注的关键信息或问题。
- 约束条件：列出字数、格式、语言、风格、情感等特殊偏好，也可补充角色设定或示例。

#### 2. 不好的提示词示例

| 提示词 | 问题点 |
| :--- | :--- |
| 生成一篇文章 | 缺少具体主题与关键信息，模型不知写什么 |
| 阅读这篇文章并给出意见 | 缺少明确目标与输出形式 |
| 讨论AI的风险 | 指向太宽泛，缺乏具体问题引导 |
| 生成一张图片 | 未说明画面内容与类型 |
| 写一段对话 | 缺乏背景与主题，模型无法定位 |

#### 3. 优秀的提示词示例

以生成环境保护对话为例：

- 工作指令：生成一段关于环境保护重要性与可行性的对话并提出方案
- 背景资料：环境议题包含气候变化、污染、资源浪费等
- 要点词：环境保护、气候变化、污染、资源浪费
- 约束条件：至少两位参与者，各自提出两个保护方案；总字数500~800字

整合后示例：生成一段对话，围绕环境保护的重要性和可行性展开并提出方案。对话中至少两位参与者，每人需提出至少两个保护环境的方案，同时深入探讨环境保护、气候变化、污染、资源浪费等议题，给出不同观点。请控制总字数在500至800字之间。
