## 8.5 实战案例：CrewAI 智能体的创建与管理

在 CrewAI 体系里，Agent 是承担任务执行、决策判断与协同配合的核心单元。每名 Agent 都有明确的角色定位、目标导向与能力边界，既可独立工作，也能与其他 Agent 协作。无论是信息处理、数据分析还是内容产出，Agent 都是推动项目前进的关键。

CrewAI 企业版提供可视化 Agent 构建器，无需手写代码即可直观搭建与配置 Agent，简化配置步骤并支持即时调试，便于快速调整行为。

Agent 在 CrewAI 中具有自主性，可完成以下工作：
- 1) 按角色与目标完成指定任务
- 2) 基于角色与目标进行决策
- 3) 调用工具辅助达成目标
- 4) 与其他 Agent 沟通协作
- 5) 保留交互历史以优化后续判断
- 6) 在允许范围内将任务委派给他人

可将 Agent 类比为具备专业技能与明确职责的团队成员，例如擅长信息收集与分析的研究型 Agent，或专注内容生成的写作型 Agent。

### 1. 可视化智能体构建器

CrewAI 的可视化构建器让 Agent 的搭建更直观：
- 1) 表单式配置界面，避免直接写代码的复杂性
- 2) 实时测试与校验，确保行为符合预期
- 3) 模板库，提供多种预设类型可选用并定制

用户可按实际需求灵活调整各项参数与行为。

### 2. 智能体的属性

每个 Agent 都包含必选与可选属性，用以定义角色、目标与行为。常见属性说明见表 8-5。

表 8-5

| 属性 | 参数 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 角色 | role | str | 限定 Agent 的职能与专业领域 |
| 目标 | goal | str | Agent 需达成的任务，对决策起引导作用 |
| 背景故事 | backstory | str | 提供上下文与个性，让行为更丰富 |
| 语言模型 | llm | Union[str, LLM, Any] | Agent 使用的语言模型，默认 GPT-4 |
| 工具 | tools | List[BaseTool] | Agent 可调用的工具，默认空列表 |
