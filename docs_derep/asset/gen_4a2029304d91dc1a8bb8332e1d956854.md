## 8.3 使用KTO微调DeepSeek-R1-Distill-Qwen模型

在当前大模型快速演进的背景下，如何让大型语言模型 DeepSeek-R1-Distill-Qwen 与人类偏好更好对齐成为关键课题。传统交叉熵最小化难以捕捉人类评价的复杂性。本节展示如何借助卡尼曼-特沃斯基优化 Kahneman-Tversky Optimization，KTO 来微调该模型，并探讨其对齐潜能。

### 8.3.1 KTO的概念

KTO 是一种受前景理论启发的全新优化范式，专为让 LLM 更贴合人类偏好而设计。其核心是模拟人类决策中的非对称偏好，从而调整损失函数，使优化过程更接近人类认知。

#### 1. KTO的核心思想

- （1）基于前景理论：前景理论由丹尼尔·卡尼曼与阿摩斯·特沃斯基提出，强调人类对“损失的感受强于收益”的损失厌恶特性。KTO 将这一非对称性引入 LLM 优化。
- （2）人类感知损失函数：KTO 引入人类感知损失函数，计算损失时更关注输出质量而非单纯的交叉熵误差，让模型更贴近真实人类认知而非数学最优。

#### 2. KTO与其他优化方法的区别

KTO与其他优化方法的区别如表8-2所示。

表8-2 KTO与其他优化方法的区别

| 方法 | 是否需要偏好数据 | 优化方式 | 特点 |
| :--- | :--- | :--- | :--- |
| 交叉熵 | 否 | 最小化标签与预测之间的误差 | 训练简单，但难以捕捉人类微妙的偏好 |
| DPO | 是 | 使用偏好数据进行对比学习 | 需要大量标注的偏好数据，成本高 |
| KTO | 否 | 仅依赖二元信号（好/坏）来调整损失函数 | 训练高效，无须昂贵的偏好数据，适用于数据稀缺场景 |

#### 3. KTO的优势

- 1. 无须高成本的偏好数据：仅需简单的“好/坏”标签，无需成对偏好数据。
- 2. 更符合人类决策模式：通过人类感知损失函数，训练更贴近人类实际认知方式。
- 3. 计算效率更高：相较于直接偏好优化 Direct Preference Optimization，DPO，KTO 流程更简洁，在有限资源下训练更高效。

#### 4. KTO的应用

KTO 目前主要用于 LLM 微调，尤其在人机交互、对话系统、代码生成等对人类偏好要求高的任务中。KTO 以低成本、高效率提升模型对齐能力，使 AI 更易理解并满足人类需求。

总之，KTO 是一种基于前景理论的新型优化方法，不依赖昂贵的偏好数据，而是利用简单的二进制信号调整模型，使其更符合人类偏好。相较于传统交叉熵和偏好优化方法如 DPO，KTO 更高效、更贴合人类认知，更适合实际应用。

### 8.3.2 DeepSeek-R1-Distill-Qwen模型介绍

DeepSeek-R1-Distill-Qwen 在 Qwen2.5-32B 基础上，通过更强的 DeepSeek-R1 模型生成的数据进行微调。DeepSeek-R1 本身融合强化学习与冷启动数据，显著增强推理能力。

该模型在多个推理基准上表现突出，超越 OpenAI o1-mini 等模型，在多项任务上达到 SOTA 水平，展现出强大的推理与问题解决能力。模型开源，研究者与开发者可自由访问其架构。开源地址已公布于 DeepSeek 官网，可自行下载。
