# 行为序列建模：召回进化的关键一跃

以上勾勒出了用户行为序列建模的完整算法蓝图。伴随深度学习技术向业务纵深渗透，该范式已跃升为优化推荐系统召回环节的核心引擎。相较于传统依赖评分矩阵的 Item-to-Item 召回策略，序列建模的独到之处在于捕捉了用户兴趣在时间维度上的“流动与迭代”这一动态特质，这与人类真实的消费决策链路高度契合，从而赋予了模型更扎实的业务落地价值。

## 3.6 章节回顾

本章系统梳理了召回阶段的技术演进脉络。回溯推荐系统发展史，早期电商巨头因用户与商品规模的指数级爆发，单一协同过滤难以在“多样性”与“精准度”间寻得平衡。由此，以协同过滤为核心的召回、以逻辑回归为核心的排序被剥离解耦，演化为两个串行推进的独立模块。

召回对应的英文术语 **Matching（匹配）**，精准定义了其使命：从海量商品池中精准捕捉用户偏好，输送至排序层生成最终榜单。可见，召回质量直接锚定了整个推荐系统的业务效果上限。

为兼顾速度、准度与覆盖面，并考量工程落地效能，召回架构进化为**多路并行**策略。不同于搜索有显式查询意图，推荐召回需依托用户画像、长中短期行为设计路由，每路从差异化维度尽力召回高质量候选。技术层面，协同过滤衍生出 i2i、u2i、i2i2i、tag2i 等变体，各自在特定场景深耕。

### 从矩阵分解到图嵌入：突破显式交互的瓶颈

为攻克传统协同过滤“头部效应显著、长尾稀疏难处理、泛化能力弱”的三大顽疾，**矩阵分解**登场。它将用户、物品映射至同一隐向量空间，用向量内积重构偏好，一度成为工业界召回主流。

然而，将交互抽象为二维评分矩阵，限制了高阶关系的挖掘。于是，**图构建与挖掘**思路涌现（如 Simrank、Swing），试图从拓扑结构中捕捉深层关联。

矩阵分解亦是深度学习入场推荐领域的首个优化切口。随着业务复杂度攀升，内积这种线性交互函数显露表达力不足。以 **NCF（神经协同过滤）** 为代表的深度矩阵分解，引入多层非线性网络替代内积，在深度学习早期实现了关键突破。

### Embedding 时代：从显式 ID 到隐式语义

矩阵分解虽蕴含向量化思想，却忽略了用户、物品、上下文的原始特征。随 Embedding 技术成熟，召回迈入**模型化向量化**新阶段，主要分两大流派：

1.  **语义向量学习（Item2vec 系）**：将用户行为序列视作语料，借用 Word2vec 训练 Item Embedding。建模时可把物品作“中心词”配合滑动窗口取上下文，或视作集合利用共现关系构正样本，再经 Negative Sampling 与极大似然估计得向量。
2.  **图嵌入**：以交互行为为边构建物品图。训练路径分两类：基于**随机游走**采样序列后接 Word2vec（如 DeepWalk, node2vec）；基于**图卷积网络（GCN）** 直接聚合邻域信息学习向量。

### 双塔模型：工业界的“长青树”

仅用历史交互作 Trigger 的向量召回，易陷入“局部兴趣/阶段性兴趣”陷阱，长此以往形成**信息茧房**。破局之道在于全貌建模用户兴趣，催生出当前召回霸主——**双塔模型**。

其核心优势双重加持：
*   **目标对齐**：以预测“下一个交互物品”为监督信号，天然契合用户“选品-决策-转化”路径。
*   **工程友好**：双塔结构解耦用户侧与物品侧，相似度计算极简（内积/余弦），完美适配海量候选池的低延迟在线服务需求。

至今，双塔及其变体仍是工业界召回层的**首选基座**。

### 双塔进阶：双轨并行的优化范式

召回侧双塔改进主要沿两条赛道推进：

| 优化维度 | 核心逻辑 | 典型手段 |
| :--- | :--- | :--- |
| **特征输入层：信号质量重塑** | 打破 Bag-of-Words “平等喂入”弊端，显式建模特征重要性差异。 | 引入 SENet 等机制学习特征权重，保护强特征免受噪声干扰，实现差异化信号传递。 |
| **用户塔网络：行为序列深度建模** | 以行为序列为核心、画像为辅，捕捉兴趣时序动态。 | **Pooling** 挖主干兴趣、**CNN** 取局部模式、**RNN** 追踪兴趣演进、**Attention** 算历史物品间及物品-画像关联。 |
| **多兴趣建模延伸** | 应对用户兴趣天然多样性。 | **MIND**、**胶囊网络** 等动态路由机制，显式拆解多兴趣向量。 |
