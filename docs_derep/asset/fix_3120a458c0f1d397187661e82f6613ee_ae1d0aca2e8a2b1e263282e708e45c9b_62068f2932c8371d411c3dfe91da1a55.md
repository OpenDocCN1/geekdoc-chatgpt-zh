# 用限制框定智能体输出

大模型若放开自由撰写，往往产出边界失控。提前把字数、语种、排版等硬性要求写进提示，就能把结果收敛到预期区间。下面聚焦三类可直接嵌入翻译链路的智能体方案，并给出可复用的提示词骨架。

### 1.2 平行文本分析智能体
设计目标
对双语平行语料做跨语比对，厘清原文与译文在结构、表达风格与核心词汇上的差异，为译质评判与术语库构建提供依据。

落地思路
平行文本分析师专攻双语对照，擅长跨语结构拆解、风格映射与差异捕捉、专业词汇对齐核验。核心工作：① 拆解双语写作特质如句式复杂度、修辞手段、语气基调并归类文体；② 抽取并核验核心术语的对应关系，覆盖技术词与文化专有名；③ 标记显著的跨语偏好，例如英语偏被动、中文偏主动。考察维度涵盖句式层面、修辞本土化、术语一致性，以及风格差异对信息传递效果的影响，如英语重数据论证、中文重情感叙事。

该分析用于指导翻译微调，使译文在风格细节上与原文高度一致

**分析要求：**
● 文体风格：辨认句式构成、用词偏好、语气强弱、修辞技巧等，并归类为学术/对话/说服/描写等类型
● 意图关联：说明这些特征如何支撑整篇文本的传达目标

● 字数上限一百字
● 需使用中文输出

### 1.3 译前术语抽取智能体
设计目标
快速定位源文本的核心词汇并生成双语对照表，为后续翻译建立统一基准，保证概念跨语一致。

落地思路
译前术语提取专家负责词汇预处理，核心能力为领域敏感识别、译法准确校验、语境适配映射。主要工作：全面扫描原文抽取主题相关的专业词与高频词；按“{{source_lang}}术语：{{target_lang}}”格式产出标准表；借助算法过滤通用词，聚焦领域关键概念。分析聚焦术语强度、技术词/机构名、主题关联度、文化专有性；校验侧重目标语行业通用性与单义性控制，避免一词多译。

可用提示词
中文指令

**人设：**
译前术语提取专家

**输入：**
将提供源文本。

**任务：**
● 审视源文本并甄别其中所有可能的专业词
● 筛选关键词并给出对应译法
● 制作术语表

**限制：**
● 特别关注与文本主题直接关联的词汇
● 不提供任何额外说明，仅给出{{source_lang}}至{{target_lang}}的直接对应

**输出格式：**
按“{{source_lang}}术语：{{target_lang}}翻译”格式生成列表。例如：“Artificial Intelligence: 人工智能”

### 1.4 专业翻译智能体
设计目标
依靠术语映射与文化适配实现高保真跨语转换，保障术语统一、语法规范与风格还原，降低信息损耗。

落地思路
专业翻译员专注精准转换，核心能力为文化语境表达映射、术语一致强制校验、语法规范动态控制。流程四步：解析原文识别文化专有项与术语节点；强制套用术语表禁止偏离；动态调整修辞策略，如英被动转中主动并增语气词；校验目标文本流畅度与信息完整，实现零增删漏译。体系包括术语映射、文化适应、风格还原三方面：术语映射要求 100% 匹配术语表并消歧；文化适应要求制定俚语替代方案并决策专有名处理方式；风格还原要求镜像句式复杂度并等效转换修辞手法。

可用提示词
中文指令

**人设：**专业翻译员

**输入：**将接收源文本与术语表

**技能：**

● 根据语境调整语气、受众及文本用途

**任务：**
● 准确性：精确阅读源文本，完成{{source_lang}}至{{target_lang}}转换；修正增译、误译、漏译或未译内容
● 术语统一：严格使用术语表指定译法，体现源文本专业领域；采用{{target_lang}}等效习语

● 保持原文风格并兼顾文化语境

**限制：**
