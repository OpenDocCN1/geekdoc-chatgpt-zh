## 6.3 本地化第二大脑：让笔记产生流动

笔记类产品的真正卡点并不是记不住，而是记完后检索不到，以及找到后难以关联。second-brain Skill 就是为解决检索与关联这两件事而设计的，它让笔记变得可检索、可关联、可复习，且全部数据留在本地存储，不绑定任何特定笔记软件，彻底摆脱平台依赖。

本节会从安装配置起步，按由浅入深的顺序依次拆解快速捕获、自动整理、语义检索、知识图谱和间隔复习五个核心模块，每个模块都附带可直接套用的指令模板，替换相关信息就能立刻上手，无需额外摸索。

先说底层逻辑：second-brain Skill 基于本地 Markdown 搭建，通过调用大语言模型接口实现智能化功能，不需要深厚的技术背景。

因此安装也很轻量，只需要做两件事：初始化配置文件，填入笔记库路径和模型密钥，全程零代码，零基础也能完成。

【本节使用的 Skill】

Skill 名称：second-brain

资源获取：“清新研究”公众号

能力：笔记捕获、自动整理、语义检索、知识图谱、间隔复习

安装后在电脑终端执行以下命令完成初始化，工具会自动生成配置文件，只需填写两项核心内容：

"llm": {

  "chatProvider": "deepseek", // 分析/整理用

第二大脑的使用前提是“记录足够省事”。second-brain 的捕获功能很直接：一行指令发过去，笔记立刻保存到收件箱，文件名自带时间戳，标题、标签等基础信息也自动补齐，不需要手动整理。

直接复制下方命令，把引号里的内容换成自己的标题、正文和标签即可。

// 带正文和标签
brain capture --title "系统设计：缓存策略" \
  --content "LRU（最近最少使用）适合访问热点明显的场景……" \
  --tags "技术,系统设计,缓存"

执行后 second-brain 会自动生成笔记文件，格式大致如下：

// 文件名：2026-03-08-2145-系统设计-缓存策略.md

status: inbox

review_at: null
