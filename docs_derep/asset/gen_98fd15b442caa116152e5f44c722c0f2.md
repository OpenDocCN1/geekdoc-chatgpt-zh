除了家庭类受限任务场景之外，学界也在探索基于大语言模型的智能体在开放世界环境中的探索能力，比如 Minecraft[580] 和真实互联网[370]。GITM[580] 就是一个典型代表，它借助任务拆解、规划与接口调用，让大语言模型能在 Minecraft 中应对多样化挑战。评估上既可依据生成的行动计划来考察其可执行性与正确性[575]，也可直接在真实环境中运行并以成功率[381] 衡量能力。GITM 的整体架构如图 11.8 所示。给定一个 Minecraft 目标 goal，LLM Decomposer 大语言模型分解器会将目标递归拆分为子目标树 Sub-goal Tree，整体任务随之被分解为逐步可达的子任务。LLM Planner 大语言模型规划器针对每个子目标产出结构化动作序列来驱动智能体，同时接收环境反馈并动态修正计划，其内部还配备了基于文本的记忆模块以辅助后续规划。与传统强化学习智能体直接操控键盘鼠标不同，LLM Interface 大语言模型接口负责把结构化动作映射为键盘鼠标操作，并将环境返回的观测信息提炼为可用的反馈。

面对复杂问题时，大语言模型往往需要按需调用外部工具。已有研究已接入搜索引擎[24]、计算器[387]、编译器[581] 等多种工具，这类增强能显著提升模型在特定任务上的表现。OpenAI 在 ChatGPT 中也开放了插件机制，让模型的能力超出单纯语言建模，例如 Web 浏览器插件即可获取实时信息。为检验工具使用能力，研究者常采用数学求解、知识问答等需要强推理的任务进行测试。当模型能有效调用工具补足自身短板，比如数值计算，就能更好地解决问题，其在这些任务上的表现也间接反映了工具使用水平。此外 API-Bank[582] 专门针对模型的外接工具使用能力做了直接评估，覆盖 53 类常见 API 工具，标注了 264 轮对话，共计 568 次 API 调用。

#### 3. 特定领域

当前大语言模型的研究不仅面向通用场景，也在医疗[583]、法律[429, 584]、财经[585] 等垂直领域展开，对领域模型的评估同样关键。在这些垂直场景里，模型通常被要求完成有针对性的专业任务。以 LegalAI 法律人工智能为例，典型任务包括合同审查、判决预测、案例检索、法律文书阅读理解等，不同任务需要对应不同的评测数据与方法。

合同审查常用数据集是 Contract Understanding Atticus Dataset CUAD[115]。合同内容稀疏且关键条款分散，律师手工翻阅数十页甚至上百页文档定位义务条款或警示条款成本很高。CUAD 收录了 500 余份合同，由 The Atticus Project 法律专家标注了 41 类重要条款，共计超过 13,000 条标注。

判决预测是 LegalAI 的核心应用之一。CAIL2018[586] 构建了大规模刑事判决预测集，包含 260 万条刑事案件，涉及 183 条刑法条文、202 种判决与刑期。由于 CAIL2018 样本偏短且仅限刑事，文献 [584] 提出 CAIL-Long 数据集，纳入民事与刑事案件且长度分布贴近真实。民事案件平均长度达 1286.88 个汉字，刑事案件平均 916.57 个汉字。全集包含 1,129,053 条刑事案件和 1,099,605 条民事案件，刑事样本标注了指控、适用法律与判决结果，民事样本标注了诉因与相关法条。

案例检索的目标是从海量案例库中依据关键词或事实描述找出相似案例，对司法一致性至关重要。中国法律案例检索数据集 LeCaRD[587] 为此构建了 107 个查询案例和超过 43,000 个候选案例，来源为中国最高人民法院发布的刑事判决。为解决相关性定义困难，LeCaRD 由法律团队制定相关性判定标准，并由法律专家完成候选案例标注。

财经领域由中国人民大学财政金融学院发布 FLAME 金融大模型评测体系[588]，系统评估模型在金融专业与实践方面的能力。FLAME 包含两大核心子集：

- (1) FLAME-Cer 金融认证：覆盖 CPA、CFA、FRM 等 14 类权威金融资格认证，共计约 16,000 道精选题，全人工审核以保证准确性与代表性。
- (2) FLAME-Sce 金融场景：涵盖 10 个一级核心业务场景、21 个二级细分场景、近百个三级金融应用任务的评测数据。

医学临床应用能力的验证方面，Google Research 等聚焦医学问答能力[583]，包括阅读理解、医学知识的准确回忆与专业运用。现有医疗数据集各有侧重：医学考试题集 MedQA[589] 与 MedMCQA[590]、医学研究问题集 PubMedQA[591]、面向普通用户的医学信息需求集 LiveQA[592] 等。文献 [583] 提出 MultiMedQA，整合 6 个既有医学问答集，题型涵盖多选与长问答，包含 MedQA[589]、MedMCQA[590]、PubMedQA[591]、MMLU[571]、LiveQA[592] 与 MedicationQA[593]，并在此基础上构建了基于常见健康查询的 HealthSearchQA。MultiMedQA 评测集所含数据集、题型、规模等信息见表 11.2。

## 11.3 大语言模型评估方法

在评测体系与数据集搭建完成后，评估方法要解决如何评、用什么指标评的问题。本节围绕指标选择与评估流程展开。

### 11.3.1 评估指标

传统自然语言处理方法多为单一任务，指标相对简单。HELM 评测[555] 则整合了 NLP 领域的多个数据集，形成 42 类评测场景，涉及 59 种指标。下面分别介绍分类与回归、语言模型、文本生成常用的评测指标。

#### 1. 分类任务与回归任务评估指标

**分类任务 Classification** 是将输入样本映射到离散类别的机器学习任务。分词、词性标注、情感分析等均可归为此类。例如情感分析需判断评论为正面或负面，即二分类；新闻分类则需依据内容将新闻划入经济、军事、体育等多类。常见评测指标有精确率、召回率、准确率、PR 曲线等，均通过对比系统预测与真实标签计算得出。

**回归任务 Regression** 是预测连续数值的任务。情感强度估计、作文评分、垃圾邮件识别等都可建模为回归。例如作文评分要求模型对给定的作文给出 1~10 分，与人工评分接近。常用指标聚焦预测值与真实值的偏差，包括平均绝对误差、平均绝对百分比误差、均方误差、均方根误差、对数均方误差、中位绝对误差等。

分类与回归是经典机器学习的基石，相关指标可参考传统教材，此处不再赘述。
