**6.2.2 GQA**

**1.MHA 和 GQA 的差异**

MHA 与 GQA 在 *Q*、*K*、*V* 上的区别如图 6-5 所示。MHA 中 *Q*、*K*、*V* 的数量都等于 num_heads。GQA 中 *Q* 的数量仍等于 num_heads，而把 num_heads 平均分成若干 Group，*K* 与 *V* 由组内所有头共享。**[图][6][-][5][M][H][A][和][G][Q][A][的]*****[Q]*****[、]*****[K]*****[、]*****[V]*****[对][比]**

[PRE9]

**2.GQA 的优势**

1）参数量与计算量均下降。

GQA 削减了 *K* 与 *V* 的参数，以 *K* 为例说明，*V* 同理。

若单个头 *K*[i] 为 [*l*,*h*]，多头拼接后 MHA 的 *K* 为 [*l*,num_heads*h]，GQA 的 *K* 为 [*l*,num_groups*h*]。

num_heads = num_groups * N，N 为组内头数，显然 num_heads > num_groups，故 num_heads*h > num_groups*h。又因 *K* = *X* *W^K*，所以 MHA 的 *W^K* 维度 [hidden_size,num_heads*h] 高于 GQA 的 [hidden_size,num_groups*h]。因此 GQA 能减少参数与计算。

2）KV-cache 占用下降。

KV-cache 的本质是用空间换时间缓存历史 *K*、*V*。

由上可知 GQA 的 *K*、*V* 为 [*l*,num_groups*h]，相较 MHA 的 [*l*,num_heads*h]，总参数降至 1/*N*，KV-cache 也降至 1/*N*，对推理很关键。

**3.GQA 的计算流程**

GQA 的流程如图 6-6 所示。

在 GQA 里每组头共用一个 *K* 与 *V*，则

*d*[Q]=n_group×*d*[K]

*d*[Q]=n_group×*d*[V]

[PRE10]

其中 *d*[Q] 为 *Q* 矩阵输出维度，*d*[K] 为 *K* 矩阵输出维度，n_head 为头数，groups 为分组数，n_group 为每组头数。**[图][6][-][6][G][Q][A][计][算][流][程][示][意][图]**

**6.2.3 MLA**

相较 GQA，MLA 在保持 KV-cache 节省的同时性能更好。计算流程如图 6-7 所示。**[图][6][-][7][M][L][A][的][计][算][流][程][示][意][图][（][不][考][虑][R][o][P][E][）]**

[PRE12]

图 6-7 中 low_rank<<*H*，low_rank 为低秩矩阵 *C* 的输出维，从而在 *K*、*V* 进入 *W^K* 与 *W^V* 前先降维。由于推理时 *K*、*V* 需被缓存，降低其维度可减少显存。

**1.MLA 和 GQA 的差异**

1）MLA 不执行 *K*、*V* 的 Repeat，模型能力提升。

GQA 组内头共享 *K*、*V*，计算时需 Repeat，使 *K* 从 [*l*,num_groups*h] 升至 [*l*,num_heads*h]：

Python

#GQA 的多头 k、v 获取是通过复制同组的 k、v 实现的

key_states = repeat_kv（key_states, self.num_key_value_groups）

value_states = repeat_kv（value_states, self.num_key_value_groups）

实验显示 GQA 的复制会削弱表现，故 MLA 旨在兼得 GQA 的小缓存与 MHA 的非重复 *K*、*V*。图 6-7 中 MLA 执行的是 Split 操作。

2）KV-cache 保存对象不同。

●GQA 保存 Repeat 之前的 *K*、*V*。

●MLA 保存图 6-7 中的低秩矩阵 *C*。

因为 MLA 的 *K*、*V* 不重复无法共享，若直接缓存 *K*、*V*，KV-cache 将与 MHA 持平，比 GQA 大 N_groups 倍。MLA 缓存 *C*，推理时用 *C* 与 *W^K*、*W^V* 相乘恢复 *K*、*V*。*C* 占用的显存小，额外计算有限，因而显存占用更低、吞吐更高。

**2.MLA 无法直接适应 RoPE**

（1）维度压缩冲突

设原始头维度 *d*[head]=128，压缩后 *d[C]*=64，标准 RoPE 作用于完整头维度，二者存在冲突。

低秩投影可表示为

*K*[rec]=*W*[up]·*C*

*C*=*W*[down]·*h*

其中，

[PRE14]
