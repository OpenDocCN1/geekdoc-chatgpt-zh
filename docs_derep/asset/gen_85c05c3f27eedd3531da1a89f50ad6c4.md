随后会调用第一层归一化 self.norm1，输出张量的形状保持不变，仍然是 [batch_size, seq_len, embed_dim]。

紧接着把归一化后的结果送入前馈网络进行变换，得到新的表征 ff_output，其维度也维持在 [batch_size, seq_len, embed_dim]。

最后执行一次残差相加，此处是 ***x*** 与 ff_output 的叠加，再经过第二层归一化 self.norm2，得到的最终结果形状依然为 [batch_size, seq_len, embed_dim]。

class Transformer（nn.Module）:

  def __init__（self, src_vocab_size, trg_vocab_size, embed_dim, num_heads, num_layers,

  ff_dim, max_seq_len, dropout=0.1）:

    """

    Transformer 模型初始化

    参数说明：

    - src_vocab_size:源语言词汇表大小

    - trg_vocab_size:目标语言词汇表大小

    - embed_dim:词向量维度

    - num_heads:多头注意力头数

    - num_layers:编码器/解码器堆叠层数

    - ff_dim:前馈神经网络隐藏层维度（通常为 4*embed_dim）

    - max_seq_len:最大序列长度

    - dropout:随机失活率

    """

    super（Transformer, self）.__init__（）

    #词嵌入层（将 Token 索引映射为稠密向量）

    self.Encoder_embedding = nn.Embedding（src_vocab_size, embed_dim）

    self.Decoder_embedding = nn.Embedding（trg_vocab_size, embed_dim）

    #位置编码（注入序列位置信息）

    self.positional_encoding = PositionalEncoding（embed_dim, max_seq_len）

    #编码器/解码器层堆叠（核心组件）

    self.Encoder_layers = nn.ModuleList（[

      TransformerBlock（embed_dim, num_heads, ff_dim, dropout）

      for _ in range（num_layers）

    ]）

    self.Decoder_layers = nn.ModuleList（[

      TransformerBlock（embed_dim, num_heads, ff_dim,dropout）

      for _ in range（num_layers）

    ]）

    #输出层（将解码器输出映射到目标词汇表空间）

    self.fc_out = nn.Linear（embed_dim, trg_vocab_size）

    self.dropout = nn.Dropout（dropout）

  def forward（self, src, trg, src_mask=None, trg_mask=None）:

    """

    前向传播流程

    输入：

    - src:源语言序列 [batch_size, src_len]

    - trg:目标语言序列 [batch_size, trg_len]

    - src_mask:编码器输入掩码（如 padding mask）

    - trg_mask:解码器输入掩码

    """

    #1.输入嵌入与位置编码

    #公式：token_embedding + positional_encoding

    src = self.dropout（self.Encoder_embedding（src） + self.positional_encoding（src））

    trg = self.dropout（self.Decoder_embedding（trg） + self.positional_encoding（trg））

    #2.编码器处理（特征提取）

    #每层包含多头注意力 → 残差连接&层归一化 → 前馈网络 → 残差连接&层归一化

    for layer in self.Encoder_layers:

      src = layer（src, src_mask） # [batch_size, src_len, embed_dim]

    #3.解码器处理（序列生成）

    #每层包含掩码多头注意力 → 编码-解码注意力 → 前馈网络（均含残差连接）

    for layer in self.Decoder_layers:

      trg = layer（trg, src, trg_mask, src_mask） #[batch_size, trg_len, embed_dim]

    #4.输出映射（词汇表概率分布）

    output = self.fc_out（trg）  #[batch_size, trg_len, trg_vocab_size]

    return output

以上为一个标准的 Transformer 实现，主要服务于序列到序列任务，例如机器翻译。该实现可拆分为以下核心阶段。

初始化部分涵盖词嵌入层 Encoder_embedding 与 Decoder_embedding、位置编码层 positional_encoding、若干堆叠的编码器层 Encoder_layers 与解码器层 Decoder_layers、输出投影层 fc_out 以及 Dropout 层。

前向流程如下。

●**输入处理：**先融合词嵌入与位置编码。
●**编码：**多层编码器提取源语言特征。
●**解码：**多层解码器在编码器输出基础上生成目标序列。
●**输出映射：**把解码结果投射到目标词表空间得到概率分布。

关键特性归纳如下。

●借助多头注意力捕捉长距离依赖。
●借助残差连接与层归一化提升训练稳定性。
●借助掩码机制实现解码时的自回归生成。
●参数可调，embed_dim、num_layers 等可按任务灵活配置。

**1.编码器与解码器的结构差异**

**2.Encoder 和 Decoder 的区分**

（1）Encoder
由于任意 Token 间都存在注意力交互，Encoder 更擅长对整句语义的理解，因而适合理解类任务，如完形填空、命名实体识别、句子分类等。以 Bert 为例，它就是基于 Transformer Encoder 训练得到的，常见用途包括命名实体识别、文本分类等，因本书聚焦大语言模型，Bert 细节不展开。

（2）Decoder
当 Bert 让 Encoder 名声大噪时，OpenAI 选择了 Decoder，并以 ChatGPT 让 Decoder 走向主流。Decoder 通用性更强，可覆盖各类 NLP 任务，因此当前主流的 Transformer 大语言模型多为 Decoder。

因为前向 Token 对后向 Token 的注意力为零，Decoder 更适合生成式任务，即基于已生成的前缀预测下一个 Token。由于生成式任务的可塑性，几乎所有 NLP 任务都能转化为生成形式。

Decoder 的应用示例如下。
a.任务类型:文本生成
模型输入:请以“伟大的人工智能”为题写一篇文章。
模型输出:我出生在一个人工智能起飞的伟大时代……

b.任务类型:命名实体识别
模型输入:请提取以下输入的人名和地名：刘丹出生在伟大的中国。请保持 json 格式。
模型输出:{刘丹:人名，中国:地名}。

c.任务类型:文本分类
模型输入:请对以下文本进行“积极”或者“消极”的二分类分析。我今天很开心，吃了很多汉堡，然后还打了很久的游戏。
模型输出:积极

d.计算
模型输入:请输出 2 的 4 次方等于多少。
模型输出:首先 2 的平方是 4，2 的 4 次方是 2 的平方的平方，也就是 4 的平方 16，最终答案为 16。

当下大语言模型基本采用 Decoder-only 架构，即仅使用 Decoder 搭建模型。早期也出现过 Encoder-Decoder 结构的 T5、Bart，以及 Prefix-Decoder 结构的 GLM 等，最终仍收敛到 Decoder-only，可能原因如下。

●大模型的核心优势是通用性，能适配各类 NLP 任务，而 Encoder 在生成任务上表现不足，限制了通用性。
●OpenAI 近年提出的 Scaling Law 指出参数量越大模型上限越高，但该规律对 Encoder 不成立。一种矩阵视角的解释引用苏剑林的观点：Encoder 的 Mask 是非上三角矩阵，可能导致注意力矩阵非满秩，而语言模型基本依赖矩阵乘法，降秩矩阵乘以任意矩阵仍是降秩。注意力矩阵形状为 [Length, Length]，于是有：

*r*（Attention_encoder）< *r*（Attention_decoder）<length_text

其中 *r*（Attention_encoder）为 Encoder 注意力矩阵的秩，*r*（Attention_decoder）为 Decoder 注意力矩阵的秩，length_text 为输入长度。

矩阵秩决定表达能力，进而影响模型上限，这也解释了 Decoder 上限更高的原因。
