## 7.3 文本 CNN 入门：字符级卷积建模

CNN 在视觉领域的成功源于“特征提取 + 任务训练”一体化架构，最大化利用原始信号反馈优化。迁移至文本，同样遵循：提取特征 → 计算权重 → 归一化 → 向量化 → 卷积建模。

本节在前文基础上实现分类，覆盖字符级与词嵌入级两大范式。二者本质可互转，此处奠基基础用法，进阶组合留待探索。
