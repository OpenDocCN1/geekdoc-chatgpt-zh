在卷积操作里，通过把步长 s 调大，就能让输出特征图的高和宽以倍数方式收敛，进而减少模型的参数开销。除了改动步长之外，还有一种为尺寸压缩而生的专用结构，那就是池化层。

池化同样建立在局部相关性的假设上，它对一个局部相关的元素集合进行采样或信息聚合，得到一个新的代表值。典型做法有两种：最大池化从感受野里挑出最大值，平均池化则计算感受野元素的均值。以 5×5 的输入 X 做最大池化为例，取感受野窗口 k=2、步长 s=1，如图 10.34 所示。虚线框标出第一个感受野，其元素集合为：

{1，-1，-1，-2}

[PRE0]

图 10.34　最大池化举例-1

在最大池化采样规则下，当前位置的输出由

`x'=max({1，-1，-1，-2})=1`

给出，并填入对应位置。

若改用平均池化，同一位置的输出应为：

`x'=avg({1，-1，-1，-2})=-0.75`

算完当前位置后，感受野像卷积那样按步长向右滑动，得到的输出

`x'=max(-1，0，-2，2)=2`

同理继续向右推移到最右端，输出`x'=max(2，0，3，1)=1`，此时窗口已触及输入边界，按卷积的边界处理方式把感受野下移一个步长并回到行首，如图 10.35 所示。

图 10.35　最大池化举例-2

如此循环往复，直至遍历到最下方、最右方，最终得到最大池化的输出，大小为 4×4，比输入 X 的高宽略小，如图 10.36 所示。

通过精心选择感受野高宽 k 和步长 s，可以实现不同程度的降维。常见做法是取 k=2、s=2，输出高宽正好是输入的一半。如图 10.37 和图 10.38 所示，当感受野 k=3、步长 s=2，输入 X 为 5×5 时，输出 O 的高宽只有 2×2。

### 10.8　BatchNorm 层

卷积神经网络的普及让数十层深网成为可能，但在残差网络出现前，网络越深训练越不稳定，经常出现长时间不更新甚至不收敛，同时对超参数极度敏感，微小的扰动就会改变训练轨迹。

2015 年，Google 研究员 Sergey Ioffe 等提出参数标准化的方法，并据此设计了 Batch Normalization，简写为 BatchNorm 或 BN[^(\[6\])](#chapter10.xhtml#jz_12_6)。BN 的引入让超参数设置更宽松，比如可以使用更大的学习率、更随意的初始化，收敛速度更快、效果更好。BN 提出后迅速成为通用组件，Conv-BN-ReLU-Pooling 的堆叠成为许多模型的标准模块。

先思考为什么要对网络内部数据做标准化。理论上很难讲透彻，BN 作者的解释也不一定让所有人信服。不如用具体问题来感受标准化带来的好处。

先看 Sigmoid 激活函数及其梯度分布，如图 10.39 所示。Sigmoid 在 x∈[-2，2] 区间的导数落在 [0.1，0.25]；当 x>2 或 x<-2 时导数迅速趋近于 0，容易出现梯度弥散。为了避免输入过大或过小导致的梯度消失，把函数输入 x 映射到 0 附近的小区间变得关键。从图 10.39 可见，标准化重映射后数值集中在 0 附近，导数不会过小，梯度弥散风险降低。这是标准化利好之一。

- Layer Norm：对每个样本所有特征做均值方差统计。

### 10.9　经典卷积网络

自 2012 年 AlexNet[^(\[3\])](#chapter10.xhtml#jz_12_3) 提出后，各种深度卷积网络相继涌现，代表性模型有 VGG 系列[^(\[8\])](#chapter10.xhtml#jz_12_8)、GoogLeNet 系列[^(\[9\])](#chapter10.xhtml#jz_12_9)、ResNet 系列[^(\[10\])](#chapter10.xhtml#jz_12_10)、DenseNet 系列[^(\[11\])](#chapter10.xhtml#jz_12_11) 等，整体层数逐年增加。以 ILSVRC ImageNet 分类任务为例，如图 10.42 所示，AlexNet 之前模型多为浅层，Top-5 错误率均在 25% 以上，AlexNet 8 层网络将错误率降到 16.4%，随后 VGG、GoogLeNet 进一步降至 6.7%；ResNet 首次把层数推到 152 层，错误率降到 3.57%。

本节重点介绍这些模型的特点。

#### 10.9.1　AlexNet

2012 年 ILSVRC12 ImageNet 分类冠军 Alex Krizhevsky 提出 8 层深度网络 AlexNet，输入为 224×224 彩色图，经过 5 个卷积层和 3 个全连接层输出 1000 类概率。为了降维，在第 1、2、5 个卷积层后加入 Max Pooling，如图 10.43 所示，参数量约 6000 万。为适配当时 NVIDIA GTX580（3GB 显存），作者把卷积层、前两个全连接层拆分到两块显卡训练，最后融合到一块显卡做反向更新。AlexNet 在 ImageNet 上取得 15.3% 的 Top-5 错误率，比第二名低 10.9%。

[PRE51]

图 10.43　`AlexNet`网络结构[^(\[3\])](#chapter10.xhtml#jz_12_3)

AlexNet 的创新在于：

- 层数达到 8 层，算得上深层。
- 使用 ReLU 激活，过去多用 Sigmoid，计算更复杂且易梯度弥散。
- 引入 Dropout，提高泛化、防止过拟合。

#### 10.9.2　VGG 系列

AlexNet 的优异表现推动业界向更深网络探索。2014 年 ILSVRC14 亚军牛津大学 VGG 实验室提出 VGG11、VGG13、VGG16、VGG19 等模型（见图 10.45），把网络深度提升到 19 层[^(\[8\])](#chapter10.xhtml#jz_12_8)。以 VGG16 为例，输入 224×224 彩色图，经过 2 个 Conv-Conv-Pooling 单元和 3 个 Conv-Conv-Conv-Pooling 单元堆叠，再经 3 层全连接输出 1000 类概率，如图 10.44 所示。VGG16 在 ImageNet 上取得 7.4% 的 Top-5 错误率，比 AlexNet 降低 7.9%。

[PRE52]

图 10.44　`VGG16`网络结构

VGG 系列的创新在于：

- 深度提升至 19 层。
- 全部采用更小的 3×3 卷积核，相对于 AlexNet 的 7×7 核，参数更少、计算更轻。
- 采用 2×2 窗口、步长 s=2 的池化，而 AlexNet 使用步长 s=2、3×3 的池化窗口。
