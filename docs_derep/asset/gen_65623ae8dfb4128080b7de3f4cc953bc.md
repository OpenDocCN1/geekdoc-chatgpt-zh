### 8.2 LM Studio 可视化本地部署

LM Studio 是一款提供图形化操作的本地模型工具，支持模型下载、运行，并内置聊天窗口。无需命令行即可管理 GGUF 格式模型，兼容 Windows 与 macOS。

#### 8.2.1 LM Studio 特点与安装

主要特点：

- 完全离线运行：可在本地设备上运行大模型，不依赖外部服务器，保障隐私安全。
- 兼容性广：支持 GGUF 格式的下载与管理，兼容 Hugging Face 等平台的模型。
- 内置 GPU 加速：适配 Windows 与 macOS，提升推理效率。
- 功能整合：除文本生成外，还提供本地文档对话、模型微调、文档交互等能力。

安装流程如下。

（1）进入 LM Studio 官网，根据系统下载对应安装包，例如 Windows 11 用户点击 “Download LM Studio for Windows” 按钮下载，如图 8-10 所示。

#### 8.2.4 Dify 调用 LM Studio 模型

Dify 是面向 LLM 的开发平台，支持接入多类大模型并通过工作流自动化协作，还能将流程封装为 Web 应用。在 Dify 中接入 LM Studio 的步骤如下。

（1）打开 Dify，点击左上角 “设置”，在设置面板左侧选择 “模型供应商”，并选用 “OpenAI-API-compatible”，如图 8-25 所示。

[PRE30]

（2）在弹出的模型配置页填写参数，如图 8-26 所示。具体配置如下。

- 模型类型：LLM。
- 模型名称：deepseek-r1-distill-qwen-7b。
- API Key：留空。
- API endpoint URL：http://<运行 LM Studio 设备的局域网 IP>:1234/v1。
- Completion mode：对话。
- 模型上下文长度：4096，与 LM Studio 中自定义值保持一致。
- 最大 token 上限：4096。
- Function calling：不支持。
- Stream function calling：不支持。
