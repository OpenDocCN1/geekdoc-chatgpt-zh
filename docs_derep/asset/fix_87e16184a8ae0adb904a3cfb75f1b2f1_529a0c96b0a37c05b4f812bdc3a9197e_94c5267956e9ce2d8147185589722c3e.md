# 偷听、记忆与“暂停”

西利娅先抛出了“怎么保持平衡”这个问题。对面那台机器给出的回答很干脆：它连单脚站立都做不到，所以对她的提问只剩意外。西利娅说，肌肉怎么配合可以慢慢教。机器却提醒她：这不是同一码事，她缺少能分辨其中差别的器官。她顺势追问：你连机制都没弄明白，又凭什么断定两者不同？机器便搬出望远镜作比——听觉和视觉都能截出一小块范围，再把那一块放大。

这一比让西利娅摸到了一点门道。她原先以为，机器身上有块类似“声音磁铁”的东西，只把目标声音吸过来；现在才懂，它是把周围杂音一并收进去，再从中挑出想听的那部分。她向机器求证，得到的却是一句“不知道”，外加反问：她为何非要弄明白这些？反正它替她做就行。西利娅说，有它在身边确实高兴，可父亲从她很小的时候就要求她学会照料自己，不靠外物，也不靠旁人；女童子军那句“自主与责任”，她一直记着。说完她自嘲：也许是自己想多了，毕竟她不可能真变成一架望远镜。她想看看机器会不会被逗乐，结果什么反应也没有。她不愿认定机器天生缺幽默感，只当它还没听懂这类笑话。至少到那时为止，卢、姬丝以及别的人，都没被她逗笑过。

机器接着提议：它有变焦装置，能像望远镜那样把目标放大，问她要把焦点落在谁身上。西利娅立刻说，窥探他人隐私不对。机器却替这种聚会辩解：大家来这儿，本来就是为了互相看、互相听，不然待在自己家里就够了。西利娅吃惊地追问：难道这些人就是来偷听别人，同时等着被别人监视？机器给了肯定答复。她又问：台下的人莫非和台上一样，都有暴露倾向？连看上去很爱聊天的卢和菲也如此？机器告诉她：不想被监听的人，会改用加密电子通信。西利娅再问：那此刻的你我呢？机器承认：可能正有人在听。她追问是谁，答复是“访问被拒绝”，无法知悉；比如ROBul，如果卢向它下了命令。

不安立刻漫过西利娅全身。她问机器：卢有没有让它把两人的谈话报上去？机器说：不可能，它只服从西利娅。这个答案很有说服力，却没能让她真正安心。回到卢身边后，她急着问：偷听别人的谈话，真的被允许吗？卢一脸困惑，她便解释：不是指刚才菲和卢那种交谈，而是随意窃听陌生人，哪怕对方根本没在跟自己说话。卢的反应很轻松：哦，你喜欢偷听？那当然行，亲爱的，想听就听。

西利娅本想说明：卢误会了，她并不喜欢偷听陌生人，那会让她不舒服，像在做什么亏心事。她原本还想弄清卢是否也这么看，以及自己若真这么干会怎样。可卢刚才那副反应，已经回答了一切，还顺带回答了许多别的问题。假如让自己快乐的事就算好事，那么让自己难过的事就算坏事吗？那种感觉，像一小片沙漠落进更大的沙漠里，又像一座小岛从大孤岛旁的死水中浮出来。西利娅感到孤独——一种由格格不入和巨大差异生出的新孤独，压在她初到新世纪时已经尝过的那层孤独之上。

# 13

博士把电子创新项目交给利奥监督之后，这名年轻人就被安置进克拉夫特公司最封闭的一块区域，独自占着一间隔间。关于那片神秘地带，他早听过各种版本。有些旧同事为了遮住酸意，故意说那里进去不容易，出来更难，好像真有人升上去之后还惦记着回原位。每逢他们拿借口绕开明摆着的事实，利奥都要顶回去：谁愿意连续几个星期不出来，只能说明里头的舒服和回报外头没法比；项目收尾后离开公司，常常还能拿到更合意的职位。至于“待久了会发疯”“没利用价值就被当废物丢出去”一类话，他连听都懒得听。

如今他终于能验证自己的判断。他已连续几天没回家，连眼都没合过。可只要这里吃住齐全、干活顺心，离开的理由似乎也不多。当然，理由还是有的：贝特，还有象棋。他始终没想透，自己为何偏要跟对手面对面较量。远程比赛里，他常输给从前赢过的人；更别扭的是，赢了也高兴不起来，仿佛远程对弈和过去让他兴奋的比赛压根不是同一件事。

先想起旧同事，接着满脑子贝特，现在又念着下棋……今天他的注意力怎么都拢不住。再这样下去，昨晚快收尾的程序也要停在那儿。也许是因为快离开隔间了，心里发虚。他明白，不管自己愿不愿意，一旦被淘汰、离开这里，脑中关于义体的资料都会被清掉，这也是他烦躁的另一个由头。克拉夫特博士向他保证：除了这段记忆缺失，别的变化他察觉不到。可合同里这一条实在让人发毛。就在他犹豫要不要改主意时，博士当着他的面演示了一次记忆消除。博士把那套东西叫“暂停”按钮，说系统相当复杂，隔间里装的只是简化版，但已经够显威力。利奥清楚记得那张决斗桌：木框上插着几把利剑，中间是一大块触摸屏。屏幕上曾跳出一道谜题，他读了一遍，还觉得挺有意思；可按钮一按，谜题不光从屏幕上没了，也从他的记忆里没了。事情如此要紧，他却讲不出半点原理。

利奥查过，植入大脑的加密波不会伤人，植入时和植入后都无副作用。所以从安全角度说，他并不慌。真正叫他发怵的是：自己正被一套完全不了解的机制拿捏着。博士简单讲过基本思路，还暗示他可以自行找答案，可他怎么琢磨都摸不到门，最后认定自己被骗了。毕竟，谁会把自己占优势的秘密交出来？克拉夫特公司的总裁不会，他熟悉的大多数人也不会，贝特尤其不会。公司警告他把发明从网上撤下之前，贝特已经提醒过不止一次。要说有哪个傻瓜会因为发明泄露还乐得合不拢嘴，那大概就是他本人——这跟他下棋非要对方面对面一样荒唐。要是他也能有一张博士那样的桌子，兴许就能弄懂每个组件如何运转。

可利奥仍然不明白，这套系统为何取名“暂停”。它不过是造出一段回想不起来的时间，而这种事并不稀罕。也许它指的是决斗因故推迟，所以“暂停”，但并非针对决斗者本人。真正对着人使用的“暂停”还没被发明出来，而他会很中意：世界照常走，他却能随时停住自己的时间，等那些伟大的技术幻想一一落地后再恢复，这样就能充分利用其间成熟的新技术。反过来也妙：先让整个世界停住，他就能溜进别的实验室和研究中心看个明白，没人拦，甚至没人发觉，因为相对于那些被暂停的可怜人，他等于以无限大的速度行动。

最初，他以为博士的设备能帮自己实现无线转化创意。他猜：把另一个人的脑电图记录注入某人脑中，前者的记忆会被清空；就算不清空，也会被屏蔽，免得互相干扰。很快他就发现不是这样。“暂停”装置不会真把记忆抹掉，它更像在添加记忆：发出加密波，与一个人读谜题或做别的事时形成的记忆叠在一起。要抹掉这部分，只需关掉加密发射器。一旦撤掉这套加密基础，先前的大脑信号哪怕再普通，也会变成认不出的噪声。几小时后，他离开隔间去接贝特，隔间里的记忆依旧存在，只是他手里没有解密的钥匙。

利奥陷在思绪里，完全没留意ROBco已经接管环绕屏幕。机器把屏幕拉到最大，铺满隔间四面墙，又请求解除全息墙功能，吓得他差点从椅子上弹起来。早上交给它的比对任务有结果了。它可不像他，不会因为马上要去郊游就分神。利奥自嘲自控力差，又觉得眼前这个有神经学习能力的机器笨蛋，居然还没学会在他像傻子一样胡思乱想时打断他。他抬头看了看监控摄像机那只时刻盯着他的电子眼，心想自己还算走运，起码它们读不到他的心思。紧接着，一个念头闪过：他梦想的感知转化，说不定真能让思想监控成真。不过他并不打算顺着这条道想下去。

眼前是一张尖端义体生成器的架构图，还有他一直在研究的想象力算法。这套算法是他故意在对生成器毫无了解的情况下开发的，为的是之后用后验方式比较两者，各取所长。

正如他所料，生成器遵循一种演进模式：不断把随机突变施加到同一个构想上，再从中挑出最佳变种。就好像盲目的达尔文式演化能站上创造力前沿似的。利奥绝不会让运气替他干活，毕竟有强大的自动推理工具来引导可能性的选择。多亏这些工具，他的算法把创造过程机械化了，避免了一切随意性和主观评估。他对此满意，但也得承认，它的作用范围有限且固定。如果能从生成器里引入一些随机却可控的数据，他或许能增强它的能力。

借助数据详尽的图表，他很快得到一张全球图像，可要准确分析哪些机制值得导入算法，还得耗费数小时。何况他现在没这个心情，哪怕ROBco就在旁边随时待命。

“如果我要马上离开，那就没必要现在开始。”他发现ROBco还在盯着自己，只好提醒，“我告诉过你，我没法像你一样，事情做到一半就关机，重启后还能接着停机前的进度。你可以试试把这功能建进你的模型里。”

“**确认：**此功能已运行17天4小时13……”

“停下，闭嘴……我说过多少次，没必要那么精确。既然你知道我的局限，干吗还坚持让我现在就开始？”

“**回放：**你刚才说‘我要马上离开’。**提问：**为什么？”

“我明白了，是我忘了告诉你，今天我要和贝特出去郊游。好吧，你不需要纠正什么，是我的错。”

“**请求：**需要我为你们准备什么？”

“我们需要一辆飞行车。博士保证过会有一辆专车。”

“**接受：**我会检查车是否备好。**询问：**还有其他任务吗？”

“有。你应该提前为工作做些准备。下一步是给这种形式主义填点内容。”他朝墙上的图表一挥手，“尽量多收集从事创造性工作的人的大脑记录：艺术家、设计师、发明家，还有证明定理的数学家和物理学家，用来验证我的猜想。我认为他们之间存在相似性。天才的数量要和普通人样本一样多。最重要的是，我们需要大量数据来处理并提取相关性。要是这些记录里还带反思性评注，那就更好了。”

“**接受任务。**候选人的选择标准是什么？”

“避免统计正态性很重要。或许可以把一个精神病患者纳入这个丰富多样的统计全集，但主体必须是没有成见、不受规则限制、讨厌按部就班、反感机械重复的人。记住，创意灵感的火花不仅取决于个人因素，还深受文化、环境和传统影响。要去找那些被转移到全新环境的人，不管转移原因是什么。都说天才是不断向前看的人，视野超越了他们的时代。”

“**提问：**我必须在网上搜索，还是去数据中心查阅？”

“先从网络开始。要是以后我需要给你……”他脑中忽然一闪，“你现在能把屏幕上的所有东西保存到绝对内存里吗？”

“**拒绝：**这是被禁止的行为。我以为你知道。”

“那你能把它存进一个永久存储设备，或者兼容的外部设备吗？”

“**拒绝：**克拉夫特公司的信息不能复制到外部存储设备。你为什么保存它？”

利奥本能地抬头看了看监控摄像头，却没意识到，这个动作加上ROBco刚才的话，已经触发了隐患警报。

仅仅10分钟后，一个虚拟的博士图像出现在他面前。

“你好，利奥。明天的初步版本义体演示准备好了吗？”

“下午好，克拉夫特博士。”他想掩饰惊讶，因为这次访问并没有列入控制日程，“演示还没准备好，不过机制图解已经完成了。你想看看吗？”

“别跟我讲空话，我要的是结果。按层次开发，每个层次都做演示。之前我已经说得够清楚了，不是吗？”

“是的，先生，可不准备好整体方案，我没办法添加内容。”

“我不会等你完成整个项目，才判断你对我有没有价值。”

“可增量式设计确实更费时间，最终产品往往也不完善。”

“别高谈阔论。别人都已经提交设计原型了，虽然性能有限，但对我有用。”

“别人？你是说还有其他人也在做这个项目？”

“你觉得呢？你以为自己是救世主？无敌神童？”

利奥总是那么天真。贝特要是在这里，肯定会把他臭骂一顿。他永远不会把这件事告诉她。

“如果你想开除我，那就开除吧。”他鼓起勇气，“如果你看一下我的整体设计，就不会想看那些毫无意义的演示了，何况做个演示还会拖慢义体研发。”

“别以为我不知道。你太喜欢自己的设计了，竟然想把它从克拉夫特公司偷出去。”

利奥脸涨得通红，把目光从屏幕挪到了地上。

“那只是一闪而过的念头，我一开始绝对没有这种预谋。”

“所以我才没开掉你。我不在乎你会不会违反规定，有创造力的脑子常这么干。让我受不了的是，你居然把时间浪费在这种没用的事情上。你给我记住，‘暂停’装置是我亲自监督的项目之一。”

屏幕里，博士那箭头形状的眉毛看起来有些模糊，不像面对面时那么咄咄逼人。语气同样缓和了些。他居然承认利奥有一颗富于创造力的头脑——这大概是从克拉夫特博士嘴里能听到的最高赞美。人真是善变。博士先把他逮个正着，又在呵斥他的同时表扬了他一番。于是利奥被放到了一个任人摆布的境地，想都没想就同意为十天后的进展控制会议制作演示。

现在比较明智的做法，是立刻取消郊游开始工作，可那样贝特绝不会原谅他。她坚持认为利奥故意隐瞒这个项目，已经够让人头疼。其实不是他不想解释，而是一出克拉夫特公司，他就不记得自己在公司里做过什么，偏偏很难让贝特明白这一点。利奥希望至少还能跟她分享一些日常琐事，让她高兴高兴，因为博士保证过，失忆只局限于这个项目的相关内容。

利奥迈步走出隔间，前所未有地关注自己的内心状态。他动作缓慢，忐忑不安，不理会四周，然后闭起眼睛，倾听内心，留意每一种微妙感觉，感受脉搏每一次不安的跳动。他担心脑袋会炸裂，担心无法控制思绪，担心认不出自己……可他也说不清到底该担心什么，该把怀疑放在哪里。紧接着，他已经站在隔间外了，却没察觉什么异样。他低头看看腿和脚，感受手臂，寻觅身体上某种未曾注意到的变化。

只有当利奥在脑海中搜索自己正在研发的项目细节时，才会发现记忆里有一片无法穿透的虚无空间。这个空间的存在，足以证明博士没有耍他。讽刺的是，那片曾令他不安的空白，现在反而成了一种解脱。他感觉更放松了，于是走向ROBco和飞行车所在的平台。

眼前是一辆超豪华双座飞行车，很有克拉夫特公司的气派：外观时尚大方，内部宽敞明亮，还为每位乘客的机器人准备了空槽。贝特见到一定会喜出望外。

他没猜错。接贝特上车时，利奥很荣幸地看到了她脸上有史以来最灿烂的笑容。一时间，他甚至考虑要不要为了加班制作演示而缩短两人的郊游假期。他紧握她的双手，扶她坐进前排，这样两人就能面对面商量相处安排。他们一贯如此，这也是他们爱情成功的秘诀：总是开诚布公地根据双方当前心情做决定，而不是拘泥于事先定好的安排。

“你今天的欲望如何？”这是两人的标准开场，因为欲望确实会影响其他东西。

“今天早上我的欲望值是6.7，我觉得下降了些。你呢？”

“我的也不高。今天就别去保健俱乐部了吧，好吗？”

“好的好的，我想好好玩玩这辆奇妙的飞行车。它能干些什么？”

“我不知道，平时都是ROBco驾驶。”

“**信息：**我总共驾驶了95分钟，因此只掌握了基本驾驶要领。”

“哦……”贝特不仅没掩饰失望，反而表现得很夸张。

“要不咱们今天来一趟短途飞行，把全部飞行经验留到下次再用？我肯定ROBco会百分之百专心飞行。”

“可我今天就想飞。何况你的机器人不是正忙于那个绝密计划，抽不开身吗？”

“你别那么刻薄。”

“我只是告诉你我的想法和感受，这是我们之前就达成一致的，对吧？”

“好吧，那我也跟你说说真实想法。”既然她也决定不保留任何想法，“总裁刚布置了一个演示任务给我，我得赶快回去。”

“你怎么不事先告诉我？”

“事先告诉你的话，你就会把我从联系人列表里永久删除。”

“要是你不告诉我那是什么项目，我现在就删。”

“我真的不记得。每次我离开公司，他们都会让我走过一个装置，那东西能擦除我的记忆。”

“别耍我，利奥尼克斯，这是我们俩共同的项目。”她的表情与其说生气，不如说严肃，像在怀疑伴侣是否还神志正常。

“共同？”一阵强烈的怀疑涌起，利奥大为震惊，机械地重复着这个词。随之而来的是对“暂停”机制的恐慌，他甚至分不清贝特到底在说哪个项目。

“别这么瞪着我！你吓着我了。你不记得咱们的项目了吗？他们连那部分也擦掉了？就是那个选择性记忆丧失的项目。”看到自己的话让利奥恢复正常，贝特继续说，“你给它起名叫‘幸福应用’，想起来了吗？”她朝他步步逼近，眼神调皮而警觉，“通过在我们还记得和遗忘的记忆之间调节过滤器，我们能为自己创造一段快乐的过去。你还说过要再进一步，引入虚拟的美好记忆……”

“这个我当然记得。”利奥已被“暂停”机制吓得六神无主，都没想过她可能是在说另一个项目。现在他如释重负：他清楚地记得那个应用的一切，对自己一直在完善的细节如数家珍，“可这跟克拉夫特的保护系统没关系啊。”

“没关系？你不是说他们抹去了你的一部分记忆吗？”

“你这么说也没错，但那是两回事。他们能删除记忆，是因为这部分记忆被以特殊方式存储起来，经过了加密。而我们的应用野心更大，它必须能在不干预录制过程的情况下删除内容，比如很久以前发生的事情。”

“你是说，你没把我们的设计给他们？”

“当然没有，亲爱的，那是另一个项目，他们在雇用我之前就在开发了。”

“那你怎么能确定，他们没有抹去这部分记忆？”

“因为在我替他们工作之前，他们给我演示过这个安全机制。”

“说不定他们已经抢先一步，知道怎么引入虚拟记忆了呢。”

“你怎么总是那么疑神疑鬼？那又怎样？难道他们会抄袭我们不成？”

“你瞧，我替你担心，你却生气了。这种侵入式保护系统肯定是非法的。马斯科特机器人公司也有一个类似机制，但它至少没有侵犯员工的权益。”

“你怎么知道他们是怎么做独家项目的？”

“哦，看来你有话要说。”

“没错。你知道吗，我更喜欢不断向前，而不是原地踏步。有话不说只会妨碍你取得成就。你看，”他瞥了一眼外面，“这辆车一直待在原地，都没绕着街区转一圈。”
