# 4bit 量化 LoRA 微调清单

显存受限时做指令微调，常见做法是把模型以 4 位量化载入，再通过低秩适配注入可训练参数，最后用 PEFT 完成包装。下面这份清单把策略定义、依赖引入和参数集中管理拆开，支持 Falcon 与 Llama 两类架构快速切换。

适配策略先行
先确定要改动的层集合以及 LoRA 的核心系数，再把配置套用到模型上。以下片段展示了适配层的约定方式和 PEFT 配置的写法。

[PRE0]python

from peft import LoraConfig, get_peft_model

lora_target_modules = [  # Which modules to apply LoRA to (names of the modules in state_dict)

    "query_key_value",

    "dense",

    "dense_h_to_4h",

    "dense_4h_to_h",

]

peft_config = LoraConfig(

    lora_alpha=16,

    lora_dropout=0.1,

    r=16,

    bias="all",  # "all" or "none" for LoRA bias

    task_type="CAUSAL_LM",

    inference_mode=False,

    target_modules=lora_target_modules

)

model = get_peft_model(model, peft_config)
依赖统一导入
数据读取、模型与分词器、量化设定以及训练器相关的类一次性引入，方便后续组装流水线。
