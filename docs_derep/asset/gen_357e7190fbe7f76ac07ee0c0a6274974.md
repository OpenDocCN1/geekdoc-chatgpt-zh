表情合成这一套系统由三个核心部件共同驱动，分别是负责对形状张量进行条件编码与解码的嵌入模型 `S`、负责表情图像编码与解码的图像生成模型 `G` 以及负责判别生成图像真伪的判别器 `D`，整体结构如图 6.12 所示。`G` 的网络骨架与 `U` 形网络相近，都采用了批正规化 `Batch Normalization`，`BN` 与 `ReLU` 激活。特别在首个卷积之后到倒数第二个反卷积之前，额外加了一条旁路，让 `G` 能够复用与身份相关联的低层面部特征。`D` 的内部使用层正规化 `Layer Normalization`，`LN` 并配合 `Leaky ReLU` 激活，最终输出 2×2 大小的特征图。条件嵌入模型 `S` 由五个全连接层堆叠而成，同样搭载批正规化和 `ReLU`。人脸图像[PRE0]与人脸形状[PRE1]分别经模型 `Gen` 和 `Sen` 编码成 `zi` 与 `zg`，两者融合为单一向量 `z`，再由 `Gde` 解码为目标表情图像。

##### 1) 几何引导
由面部关键点构成的人脸形状能够提供形状约束、空间几何线索以及表情信息，同一种表情的形状通常具有相似性，可以由此学习到形状的语义流形。将形状张量展平成一维向量作为条件嵌入模型 `S` 的输入，隐变量 `z` 再作为图像生成模型 `Gde` 的输入，就能让形状信息主导表情的生成方向。

## 训练集建立
建库时先用人脸校准算法自动定位眉毛、眼睛、鼻子、嘴唇、下巴附近的面部基准点；再以二维仿射变换，依据内眼点与下嘴唇位置对人脸图像进行裁剪校准并缩放到 64 像素×64 像素；随后将像素值与基准点位置归一化到 `[-1,1]` 区间；最后以三元组[PRE10] 作为训练样本，遍历所有用户身份的所有表情对，并从随机分布中采样参考形状张量。

## 6.5 实例
本节以一个具体的情感交互界面为例，解析其界面组成与技术原理。用户可通过该界面与计算机进行情感交互：计算机从实时捕获的面部表情视频中识别情感并以直观方式呈现，用户据反馈调整表情，进入下一轮交互。

情感交互界面示例如图 6.16 所示，包含四部分。

(1)视觉采集信息反馈区：逐帧回显摄像头视频，让用户像照镜子一样看到自己的表情，便于表达调整。
(2)人脸校准结果反馈区：对视频帧进行在线人脸校准与关键点跟踪后，逐帧在原视频上叠加人脸与关键点位置，让用户观察系统的感知结果。
(3)情感识别结果反馈区：识别出情感类型后，以带情感隐喻的表情图标、情感标签与识别概率组合输出，概率越高视觉效果越亮，如图 6.16 中的惊讶表情。
(4)一般操作区：提供控制应用程序的基础操作。
