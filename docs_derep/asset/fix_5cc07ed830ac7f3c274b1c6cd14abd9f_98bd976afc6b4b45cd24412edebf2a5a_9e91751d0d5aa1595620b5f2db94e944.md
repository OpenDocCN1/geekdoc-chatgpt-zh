Google 早期推出的 Universal Sentence Encoder 属于 Transformer 系句向量方案，核心是为句子与段落生成可复用的向量表达。在跨语言场景里表现稳定，常被拿来做文本分类、聚类、语义相似度判断等工作。

当前主流大模型普遍自带稳健的多语能力。OpenAI 的 text-embedding-3-small 与 text-embedding-3-large、BGE 家族的 M3-Embedding，以及 Cohere 提供的多语嵌入方案，都能覆盖接近甚至超过百种语言。

#### 3.2.5 图像和音频嵌入模型

图像反向检索在很多应用里是刚需。典型需求是用户想找更多与“悟空”相关的图，上传一张含该形象的照片后让搜索引擎返回相似结果。过去这类任务主要依赖微软 2015 年在 ImageNet 上训练的 ResNet50 卷积网络，擅长高效抽取图像特征并做相似匹配。

同理，反向视频搜索也能借助 ResNet50 做视频嵌入。做法是将视频拆帧为特征向量，再在帧特征库里检索相似片段，从而定位与输入视频最接近的片段。

音频侧则常用 PANN，即预训练音频神经网络。它在大规模音频语料上完成预训练，支持把一段音频输入后执行反向音频搜索，被广泛用在音频检索和声音分类系统里。

#### 3.2.6 图像与文本联合嵌入模型

能够同时建模文本、图像、音频甚至视频的多模态嵌入，为嵌入技术打开了新空间。这类模型既能用文本搜图，也能生成图像描述，还能完成反向图片搜索等任务。

2021 年 OpenAI 发布的 CLIP，即对比语言-图像预训练，成为该方向的基准架构。团队收集了超 4 亿对图文数据，通过对比学习把图像和文本映射到同一向量空间，从而建立跨模态关联，见图 3-9。借助这种跨模态嵌入，机器处理图文数据时能够更有效地关联不同模态信息，为多模态学习带来突破。图3-9 图像与文本联合嵌入模型的工作流程

#### 3.2.7 图嵌入模型和知识图谱嵌入模型

处理复杂关系与结构化数据时，图嵌入和知识图谱嵌入价值显著。图嵌入侧重节点间的结构关系，知识图谱嵌入更关注实体间的语义关系，如图 3-10 所示。

图3-10 图嵌入和知识图谱嵌入

[PRE1]

图嵌入把图中的节点、边及它们的关系映射到低维向量空间，同时保留结构信息。例如 Node2Vec 和 GraphSAGE 分别通过随机游走或邻居聚合的方式，把图的局部与全局结构编码为向量，可直接用于节点分类、聚类或图上的关系预测。

该技术在社交网络分析、推荐系统、金融网络、医疗网络等领域应用广泛，能有效刻画复杂关系与网络特性。系统通过学习节点的语义与结构信息，使相似节点在向量空间更接近，从而提升节点分类、链路预测等任务效果。

知识图谱嵌入如 TransE、TransR、DistMult 等，把实体和关系投射到同一向量空间，有效捕捉实体间的语义关联。常用于知识图谱补全与链路预测，帮助发现潜在关系。TransE 用简单的平移操作建模关系，而 TransR 与 DistMult 则在复杂多维关系的建模上进一步增强。

在智能问答、推荐、语义搜索等场景中发挥关键作用。以问答系统为例，嵌入能够帮助识别问题与知识库实体间的复杂关联，提供更精准的答案。

#### 3.2.8 大模型时代的嵌入模型

在 BERT、GPT 等大模型驱动下，传统嵌入架构被重塑，形成大一统态势。这些模型不仅生成文本能力强，其隐藏层输出也能作为强力的文本嵌入，有效捕捉深层语义，从而大幅提升相似度计算、分类与搜索性能。

除直接“裁剪” BERT、GPT 用作嵌入外，OpenAI 及其他厂商或开源组织还提供了大量专用的嵌入模型，通过 API 或开源代码供开发者使用。这些模型在自然语言处理任务中适应性强，可为文本提供丰富的语义表示，适用于相似度计算、分类和搜索。

因此，嵌入技术在过去几年取得显著进展，机器对语言与图像的理解能力增强，为下游任务奠定基础，也推动了 Scaling Law 的演进。

> OpenAI 联合创始人兼前首席科学家 Ilya Sutskever 指出，人类高质量语料基本已耗尽，Scaling Law 的下一步需探索新方向。文本数据可能已大量利用，但海量视频与多模态信息仍待大模型解析。未来 Scaling Law 还将涉及硬件扩展、资源与性能优化，以及 AI 主动生成高质量训练数据等。这些观点为后续探索提供了参考。

#### 3.3.2 用jina-embeddings-v3模型进行跨语言数据集聚类

jina-embeddings-v3 是一款前沿的多语言文本嵌入模型，基于 XLM-RoBERTa 并做了多项增强，擅长长文本编码。模型参数约 5.7 亿，支持阿拉伯语、汉语、法语、德语、日语在内的 89 种语言，在多语言任务上表现稳定。同时强化了长上下文能力，最长支持 8192 个 token，适用于长文档检索与长文本嵌入。

该模型采用任务特定的低秩适配技术，可为检索、聚类、分类、文本匹配等任务生成高质量嵌入，灵活性高。为提升效率并降低资源消耗，模型使用 FlashAttention2 与 DeepSpeed 架构，显著提高分布式训练效率并减少内存占用。

此外，模型集成 Matryoshka 表征学习，允许用户灵活调整嵌入维度，最低可至 32 维而不明显影响性能，对生产环境或边缘设备的大规模向量存储十分友好。

jina-embeddings-v3 提供 3 个主要 API 参数供定制：

- **task**：依据下游任务如检索、分类或文本匹配调整嵌入策略，优化特定任务表现。
- **dimensions**：用户可自行设定嵌入维度，在保证性能的同时优化存储成本。
- **late_chunking**：先嵌入后分块，专门优化长文档的嵌入表示，提升检索效果。
