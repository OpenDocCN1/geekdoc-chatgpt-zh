# 用智能工具重塑教学设计：从学习单到资源创编的实操路径

**案例缘起：** 承接前一轮教案打磨，王老师在完成四年级《精卫填海》教学思路后，思考如何给学生配齐一份学习单，让课前准备、课堂研讨与课后回望都能围绕学生展开，把教学重心从“怎么教”转向“怎么学”，真正落实以学为本。

**既有困境：** 过去的学习单多为知识点罗列加练习堆砌，样式单一、吸引力不足，很难带动深度思考与个性化探索，核心素养的培养过程也难以显性化。

**智能支持思路：** 借助 DeepSeek 产出结构清晰、任务驱动、问题导向、分层递进并融入素养审视的学习单初稿。

###### 操作流程拆解

###### （1）让 DeepSeek 产出学习单初稿

**提示词采用 STAR-AI 框架：**

（角色R）请扮演一位擅长以学生为中心的小学语文教师。

（情境S）我要为小学四年级配合《精卫填海》课堂教学设计一份学习单。

（任务T）请输出这份学习单的完整初稿。

（受众A）使用对象为小学四年级学生。

（方面/格式A）学习单应包含：

①学习要点：呈现本课希望学生达到的素养指向；

②课前准备：给出具体的预习动作，如朗读、识字、初步提问等；

③课堂研讨：设计层层递进的问题与任务单，兼顾基础理解与思维延伸；

④分层任务（可选）：为不同水平学生提供差异化拓展；

⑤课后回望/小结：通过引导性问题帮助学生梳理收获，体味精卫精神。

（指令/约束I）语言亲切活泼，符合儿童认知；问题要有启发性，能触及精卫精神、神话特质、想象力等素养；以便于打印的格式呈现。

示例框架
《精卫填海》神话故事学习单（四年级适用）

###### 一、学习要点
1. 语言运用：准确朗读并尝试复述故事，掌握堙、溺、衔等生字词；
2. 思维发展：剖析精卫行为的动因，理解神话想象的表达方式；
3. 文化传承：感受坚韧不拔的精神力量并联系生活；
4. 审美创造：发挥想象续写故事，绘制神话场景。

###### 二、课前小任务
- 朗读课文三遍，用△标出读不顺的句子；
- 借助词典理解炎帝、发鸠山、堙、誓曰并批注；
- 设问：若你是小精卫，会怎样向大海吐露心声？

###### 三、课堂大闯关
第一关：复述故事小能手。用自己的话讲给同桌听。
第二关：动作描摹大师。找出生动描写精卫动作的词语并体会。

###### （2）教师审阅与再设计
王老师仔细审阅模型初稿，确保问题难度与表述贴合学情，并按教学流程调整。她会补充动手操作或小组协作的任务单，使学习单更具可操作性。

###### （3）效果评估
**效果：** 初稿结构完整，涵盖要点、研讨、分层与回望，体现以学生为中心的理念，能有效驱动自主学习与深度思考，助力核心素养达成。
**注意：** 学习单须与教案紧密配合；教师要依据实际学情灵活调适难度；课堂上更需引导学生有效使用学习单，组织好探究与讨论。
从上述案例可见，生成式工具在教学设计中可承担灵感提供、细节优化、理论整合到面向学生材料生成的多种角色，是提升设计能力、落实核心素养的有力助手。

### 三、人工智能助力优质教学资源的创编
优质教学资源是高效教学的基础。课件、学习单、图文视频、针对性练习等，直接影响学习兴趣与理解深度。优质资源需科学精准、形式多样、贴合认知、能促思考与互动。教师可借助智能工具快速获取海量教学信息，为不同进度与能力的学生提供个性化学习体验，并及时反馈作业，提升整体效率。

传统创编常受资料查找、信息筛选、排版制作、多媒体生成耗时耗力困扰，资源分散且难快速定制。生成式智能与多模态工具如 DeepSeek、豆包、Kimi、ChatGPT、Gemini 的出现，为创编带来新机遇：
- 高效整合信息：快速搜集、筛选、归纳、翻译，供给创作“原材料”；
- 智能产出内容：按指令产出文本初稿、设计思路、习题甚至代码；
- 辅助多模态创作：产出 PPT、思维导图、图片、音频、视频；
- 支持个性化定制：按学情、难度、风格产出针对性资源；
- 激发创作灵感：提供多元视角与创意方案，打破思维定式。

#### （一）人工智能支持教学资源搜索与整合
创编第一步是搜集背景资料、案例、前沿信息与实验方法。传统搜索引擎信息庞杂，智能对话与搜索工具大幅提升效率。

##### 1 用对话式模型精准捕捉教学信息
策略：直接向 DeepSeek 或文心一言、豆包等模型提出具体需求，利用对话交互获得聚焦答案。可要求模型扮演学科专家以提升专业度。
提示词示例：
“请扮演初中生物老师，解释光合作用过程，并给出三项课堂演示的可行小实验。”
“作为小学语文老师，请列出几首描写春天的古诗，并说明意境与教学切入点。”

### 四、人工智能辅助教学课件 PPT 的设计与制作
PPT 是课堂教学常用视觉工具。智能时代提供高效解决方案。

#### （一）智能支持 PPT 制作思路
1. 内容产出 DeepSeek：快速产出大纲与每页标题要点；
2. 结构转化与初美化 AI PPT 工具：如 Kimi AI PPT 助手、WPS AI、希沃 Bloom，将 Markdown 文本转为排版初稿；
3. 视觉元素增强：用即梦、豆包文生图或 Canva 等产出配图、图标、背景；
4. 教师审核精修：核查内容、梳理逻辑、调整版式与视觉，最终定稿。
