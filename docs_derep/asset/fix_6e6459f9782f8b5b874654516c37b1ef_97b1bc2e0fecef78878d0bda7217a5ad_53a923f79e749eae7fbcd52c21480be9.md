FAISS 检索链路全景解析

下面这段实现把向量导入、索引搭建到持久化保存串成一条完整的流水线，与常规的嵌入生成存储流程高度吻合，整体可以概括为七个操作环节：

1. **向量读取**：打开 4.1.2 小节生成的 text_embeddings.pkl，文件中每个文档的向量最初以 Python 列表形式保存。经 pickle 解码后转成 NumPy 数组，为 FAISS 做准备。
2. **索引创建**：实例化 IndexFlatL2，这是一种基于 L2 距离的平面索引，对中小规模数据查询效率理想。若数据量更大，可换成 IndexIVFFlat 或 IndexPQ 等更复杂的结构来提升性能。
3. **数据写入**：先把向量统一转为 float32 的 NumPy 数组，再调用 add 方法写入索引。写入完成后通过 index.ntotal 查看向量总数，确认入库完整。
4. **查询封装**：编写 search_faiss 函数接收查询向量和 top_k，返回最相似的若干结果。FAISS 的 search 接口会同时给出距离值与索引位置，方便后续分析。
5. **功能试跑**：用一个示例向量执行检索，展示最相似的文档 ID 与距离。距离数值越小，语义相关度越高。
6. **索引落盘**：借助 faiss.write_index 将索引写入磁盘，服务重启后可快速恢复，适合线上部署。
7. **索引恢复**：用 faiss.read_index 重新载入文件，再次查询并比对结果，确保保存与加载过程一致。
