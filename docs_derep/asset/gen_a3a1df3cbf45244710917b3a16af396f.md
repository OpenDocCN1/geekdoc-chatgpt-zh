### 1.3.5 Agent的七大认知能力：从记忆到自进化

大模型驱动的这波人工智能热潮，包括 Agent 本身，终究会降温。但热度退去恰恰意味着技术更成熟、发展更快。

我们对基于大模型的 Agent 有信心，核心就落在这几个认知上。

先说知识底座。大模型在预训练时吃下了海量的世界知识，见图 1.11。训练集覆盖众多主题和语言，让模型对世界的复杂性形成表征和映射，从历史规律到当下事件都有洞见。它能解读细微话术，对超出训练范围的话题也能给出有意义的回应。碰到新场景或垂直领域信息时，Agent 可以靠这片广阔的知识库快速定位和响应。知识也不是一成不变的，持续学习让它不断充实，保持相关性。

这些预训练获得的知识，就是 Agent 大脑记忆的一部分。大模型通过调整神经元权重来理解和生成人类语言，可视为记忆的形成。任务执行时，Agent 会融合记忆内容和当下上下文。外部记忆也可以通过检索增强生成 RAG 和 Memory Bank 这类外部记忆系统整合进来，后面会展开讲。

再说理解表达的跃迁。此前 AI 在细分领域很强，但对自然语言和复杂概念的理解总显得笨拙。大模型的出现让 AI 真正理解并生成自然语言，也更深入理解人类沟通方式和知识体系。它被训练去把握广泛主题和上下文，能在各种情境下给出信息和解决方案。这是量级的变化，更是质的变化。现在的 Agent 能捕捉语境、把握语义，甚至在一定程度上理解人类情感和幽默，交流更自然更高效。

再说推理带来的自主性。传统 AI 依赖明确指令和固定规则，借助大模型的 Agent 能够自主学习、自主适应。它能阅读海量文本，理解世界复杂性，从而做出更合理的判断。看起来更像一个能独立思考和行动的主体，而非执行预设任务的工具。对 Agent 来说很关键，因为它需要理解所处环境并据此决策。比如集成大模型的自动驾驶 Agent，不仅能对路况反应，还能评估突发事件的严重性并制定策略；虚拟助理不仅能答疑，还能读懂用户需求和情绪，提供更个性化的建议。

## 1.4 Agent感知力拆解：会说话更会看

构建 Agent 时，感知力是关键特征，让它能与外界交互和理解。主要体现在语言交互能力和多模态能力上，这两项既提升交互体验，也增强对复杂环境信息的处理能力。

### 1.4.1 对话能力：听懂人话
语言交互是 Agent 与人类或其他 Agent 沟通的基础。它能理解指令、提问、表达观点情感、进行复杂对话。语言不仅是字词句子，还包含语境、隐含意义和社会文化维度。GPT-4 等大模型让 Agent 在语言交互上达到新高度，能捕捉语言细微差别，适配不同风格和方言，甚至理解使用幽默、讽刺等复杂表达。

Agent 的语言交互还体现为自然语言生成能力。不仅能答问，还能创造性地生成语言以适应新话题和情境。这种生成能力不止文本，还能延伸到语音及非语言交流如手势表情，让与人类的交互更自然。

### 1.4.2 多模态感知：不只听
多模态能力是指 Agent 能处理并解释来自不同感官的信息，如视觉、听觉、触觉，同时也能以文本、图片、音频、视频等多种格式输出，如图 1.16。举例来说，集成多模态模型的 Agent 能通过观察图片理解其中的情感和社会动态，也能通过声音判断语气和情绪。

[PRE4]
整合能力是多模态的关键。Agent 能把不同感官信息融合为统一理解，执行复杂任务。比如自动驾驶 Agent 需整合视觉数据如道路标识和交通灯状态、听觉数据如特种车辆警报声、触觉数据如车速和方向，以快速决策。

多模态能力还支持环境理解和场景构建。通过分析合成各感官信息，Agent 能构建对环境的全面认知，应用于救灾、医疗诊断、客户服务等领域。

### 1.4.3 融合感知：体验质变
语言交互与多模态能力结合，Agent 的感知力和适应力会大幅增强。例如，能理解口头指令并通过视觉识别表情的智能家居助理，能更精准把握用户需求。在教育场景中，结合语言理解和视觉识别的 Agent 可提供个性化互动学习体验。
