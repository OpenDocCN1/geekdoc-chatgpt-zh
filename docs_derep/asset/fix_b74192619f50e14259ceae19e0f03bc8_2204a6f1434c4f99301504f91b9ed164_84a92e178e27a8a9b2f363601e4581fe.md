## 6.7 用AI定制个人改进方案

### 问题场景
1. 季度复盘显示团队约三成成员连续两季未达预期，但照搬公司模板制定的改进计划落地不佳，多人敷衍或抵触，症结何在？
2. 计划缺乏针对性与可执行性。若借助智能体解析个人绩效波动原因与历史改进记录，可生成一人一策的方案，提升执行力。
3. 不同岗位重点差异大，智能体能否胜任？
4. 可以。输入岗位核心能力模型、当前能力雷达图及改进目标，智能体即可拆解任务、匹配资源、输出完整路径。输入质量决定输出。
5. 若员工消极执行或执行偏差，智能体如何应对？
6. 可在计划中预设里程碑检查点，定期回传执行情况，系统自动比对进展与目标并生成预警，管理者据此及时调优。

### 智能提问框架
通用公式 = 成员画像 + 改进目标 + 资源边界 + 输出需求

先详述个体信息，帮助智能体找到切入点。
**提问要点**
- 能力弱项：如数据分析薄弱、跨部门协作意识不足
- 行为倾向：如拖延、追求完美过度
- 历史改进记录：曾尝试方法及失败原因

再明确改进目标，避免方案偏离业务。
**提问要点**
- 量化指标：如季度销售额提升20%、代码缺陷率下降30%
- 优先级：如先解决态度再补技能
- 关联说明：改进对团队KPI的贡献

随后列出资源限制，确保方案可行。
**提问要点**
- 时间边界：如改进周期三个月，每月仅能脱产两天
- 预算边界：如培训费用上限五千元
- 权限边界：如无法调整架构，只能优化流程

最后明确输出形态。
**提问要点**
- 任务拆解：目标拆成周任务并标注责任人
- 资源匹配：推荐三种低成本培训方式
- 风险预案：员工中途离职时的交接措施

### 准备资料

| 关键项 | 说明 |
| :--- | :--- |
| 成员档案 | 能力评估报告、360度反馈、历史绩效数据 |
| 岗位说明书 | 核心能力模型、KPI/OKR定义、典型流程 |
| 资源清单 | 培训预算、内部导师名单、外部供应商条款 |
| 失败案例库 | 过往改进计划失败原因分析 |

### 实战案例
员工小李，28岁，入职两年，现任客户经理。近半年拜访次数达标但成交率偏低，平均12%，团队均值18%。评估显示需求挖掘能力仅3分/5分，且习惯过度依赖标准话术。

期望目标：
1. 三个月内成交率提升至18%
2. 强化需求挖掘与定制化方案能力
3. 与季度冲刺目标新增五家签约客户挂钩

资源约束：
1. 培训预算不超过三千元
2. 每月最多一天脱产学习
3. 优先使用内部资源，如销售总监担任导师

需求：
1. 将目标拆解为每周任务
2. 匹配低成本资源，如推荐三本销售类书籍与一门线上课程
3. 设计里程碑检查点，如每周提交一份客户沟通录音供导师点评
4. 生成风险预案，如第二个月转化率未达15%时启动影子计划，观摩高绩效员工拜访

| 关键项 | 说明 |
| :--- | :--- |
| 动态微调 | 计划需随实际进展每周调整，避免照搬 |
| 人文关怀 | 对能力短板明显的员工给予鼓励与支持 |
| 文化适配 | 智能体建议需结合团队文化本土化 |
| 隐私保护 | 输入前对个人隐私信息做脱敏 |

## 6.8 AI驱动技能提升方案设计

### 问题场景
1. 公司裁撤低效部门后，剩余员工绩效两极分化。老员工技能固化，新人跟不上业务迭代，如何应对？
2. 转型期常见痛点。低绩效多因技能与岗位需求错位，针对性提升可让不少人转为高绩效。
3. 过去由直线上级制定方案，要么过于笼统，要么脱离实际，如让一线工人学编程。
4. 传统方式依赖主观判断，易头痛医头。科学做法分三步：精准诊断缺口、设计阶梯式学习路径、匹配动态评估机制。
5. 诊断需大量数据，设计耗时，中小企业资源有限怎么办？
6. 可用智能体。智能体能快速扫描绩效问题、生成个性化学习地图、提供资源并预测培训后绩效提升幅度。

### 智能提问框架
通用公式 = 情境定位 + 缺口清单 + 提升目标 + 资源约束

先描述背景。
**提问要点**
- 行业属性：如快消品销售、技术研发
- 绩效问题表现：如续约率低于行业均值15%、代码缺陷超标30%
- 时间跨度：如三季度为冲刺期

再拆解缺口。
**提问要点**
- 硬技能缺口：如Excel数据透视不熟练
- 软技能缺口：如跨部门冲突解决能力弱
- 优先级：直接影响订单的技能优先

设定提升标准。
**提问要点**
- 量化指标：如三个月内客户投诉率降20%
- 行为改变：从被动接需求到主动提优化建议
- 阶段划分：基础夯实→实战进阶

明确资源。
**提问要点**
- 时间预算：每周最多投入四小时
- 成本限制：人均培训费不超过五百元
- 现有工具：内部学习系统或免费线上课程

### 准备资料

| 关键项 | 说明 |
| :--- | :--- |
| 绩效数据 | 近半年考核结果、项目复盘、客户反馈 |
| 岗位能力模型 | 岗位技能清单、高绩效行为特征 |
| 业务目标关联 | 未来三到六个月部门KPI与战略重点 |
| 培训资源库 | 现有课程清单、内部导师名单 |

### 实战案例
某SaaS企业华北区销售总监，管理25人团队，负责中大型客户拓展。近半年新客户签约率同比下降18%。

问题：
1. 新人占40%，硬技能不足：产品演示逻辑不清，客户留存率仅35%，行业均值52%；竞品对比表制作平均超四小时，错误率23%
2. 老员工占60%，软技能不足：需求挖掘深度不够，平均每次沟通仅获1.2个痛点，行业均值2.7个；需技术介入的方案平均响应5.8天

目标：
1. 新人：一个月内演示留存率提升至45%，竞品表制作效率提升50%
2. 老员工：两个月内单次沟通痛点数提升至2个，技术响应缩短至3天

资源限制：
1. 时间：新人每周最多六小时培训，老员工每周三小时
2. 成本：人均培训预算不超过八百元
3. 工具：可调用内部知识库与外部付费课程平台

请据此设计分阶段技能提升计划，包含培训形式、评估方式、资源分配及各阶段绩效改善预测。

| :--- | :--- |
| 动态校准 | 根据实施反馈持续迭代方案 |
| 避免替代人工 | 智能体仅提供建议，关键决策需管理者把关 |
| 隐性技能挖掘 | 抗压、创新等软性能力需人工补充评估 |

## 第7章 智能体助力绩效结果应用

绩效结果的应用是绩效管理的落点，关乎激励、发展等多方面。智能体可基于结果提供薪酬发放与调整、股权激励、福利、晋升、选人用人、组织诊断、业务改进、调岗培训等领域的智能建议，使应用更科学有效。

## 7.1 AI赋能绩效结果在薪酬发放中的应用

### 问题场景
1. 绩效推行后薪酬争议增多。员工反映奖金计算依据不透明，同部门相似绩效者薪酬差异超20%，申诉消耗大量精力，根因何在？
2. 绩效与薪酬关联规则不清。绩效含业绩、能力、价值观等多维度，发放时未明确权重与换算逻辑
3. 有评分细则，但领导主观调整权过大，90分与85分的员工奖金差距被拉大到30%，如何保证公平？
4. 需建立客观映射。采用强制分布分A/B/C档，每档对应固定奖金系数并公式化计算；管理者自由裁量仅限特殊贡献且需备案
5. 销售、研发、职能标准不同，统一规则会削弱激励吗？
6. 应分岗位设计映射关系和权重，如研发以交付质量为核心，再通过统一薪酬系数表衔接

### 智能提问框架
通用公式 = 场景锚定 + 核心矛盾 + 功能需求

**提问要点**
- 组织规模：团队人数与层级
- 薪酬体系类型：年薪、提成、项目奖金等
- 现有评估规则：考核周期、指标类型、数据来源
- 特殊限制：薪酬保密、合规要求

**提问要点**
- 数据整合难点：跨系统孤岛、人工录入误差
- 计算复杂度：多维度权重叠加、动态调整
- 员工痛点：申诉高频问题、激励不足

**提问要点**
- 分析类需求：绩效分布、薪酬成本模拟
- 规则设计类需求：绩效-薪酬映射模型、异常预警
- 输出形式：可视化图表、计算公式、操作流程图

### 准备资料

| 关键项 | 说明 |
| :--- | :--- |
| 绩效数据 | 近期考核表、评分规则、历史申诉记录 |
| 薪酬结构 | 岗位工资标准、奖金分配细则、调薪政策 |
| 员工信息 | 职级分布、绩效等级占比、薪酬满意度调研 |
| 对标数据 | 行业薪酬报告、竞品激励方案 |
| 业务约束 | 薪酬预算上限、合规红线 |

### 实战案例
任职于500人跨境电商公司，负责薪酬。薪酬结构为基本工资+季度绩效奖金+年终分红。绩效维度为销售业绩40%、团队协作30%、创新贡献30%，数据来自ERP、360度反馈与项目台账。现需解决销售与运营部门薪酬矛盾：销售认为业绩占比低，运营抱怨协作评分主观

现状：
1. 数据整合低效：销售业绩需从ERP导出后手工核对，协作评分依赖上级主观，导致核算周期长达两周
2. 激励偏差：顶级销售因协作分低被扣减奖金15%到20%，已有三名骨干提出离职
3. 合规风险：员工质疑评分黑箱，半年薪酬申诉增长120%

需求：
1. 识别ERP中异常交易记录
2. 建立销售与运营差异化绩效-薪酬权重模型
3. 生成薪酬对照表，展示规则调整前后头部销售、新员工、管理者收益变化
4. 输出薪酬沟通话术模板，解释规则变更逻辑

### 注意事项

| 关键项 | 说明 |
| :--- | :--- |
| 解释可视 | 提前公示标准与挂钩规则，用柱状图、瀑布图展示分数→系数→奖金链路 |
| 数据校验 | 智能体生成模型需抽样复核，对比历史数据防算法偏差 |
| 合规兜底 | 计算结果须符合法规，智能体建议经法务审核 |
| 渐进测试 | 新规则先在单一部门试点，按反馈迭代 |

## 7.2 AI支持绩效结果指导薪酬调整

### 问题场景
1. 薪酬调整时业务负责人抱怨绩效好的员工调薪不足留不住人，财务要求控成本，怎么办？
2. 核心矛盾是绩效与薪酬调整联动不足。若A级调薪5%、B级调5%，差距不明显。可采用差异化：A级10%、B级5%、C级不调，强化激励
3. 不同岗位贡献差异大，销售可量化，研发周期长，职能无直接成果，如何统一规则？
4. 销售挂钩业绩达成率超额提成；研发挂钩里程碑；职能关联对口部门绩效达成率。用岗位系数平衡，如销售1.2、研发1、职能0.8
5. 若负责人评分宽松，调薪差异会引发公平质疑，如何解决？
6. 可用智能体横向纵向对比历史数据，标记异常宽松的评分者，结合强制分布，避免平均主义与放水

### 智能提问框架
通用公式 = 绩效薪酬现状 + 挂钩规则需求 + 风险控制需求

**提问要点**
- 绩效评估周期：半年度、季度、年度
- 现有挂钩方式：绩效等级仅作参考
- 关键矛盾：调薪幅度小导致激励不足

**提问要点**
- 调薪比例：如A级15%、B级8%
- 岗位差异化规则：销售超额提成比例
- 特殊情况处理：新员工首年不参与强制分布

**提问要点**
- 主观偏差控制：强制分布比例
- 员工沟通方案：绩效-薪酬说明会模板
- 异常情况预案：市场突变时的薪酬缓冲期
