# ROC曲线与AUC：从雷达技术到模型评估的核心指标

ROC曲线的起源颇具传奇色彩，它诞生于二战时期的雷达信号处理技术，最初用于甄别敌机信号。到了20世纪60至70年代，该方法迁移至心理学与医学检测领域，随后被机器学习社区广泛采纳。其构建逻辑与P-R曲线颇为相似：依据学习器的预测得分对样本排序，逐个将样本视为正例预测，记录每一步的两个关键指标并绘制成图。不同之处在于坐标系的选取：ROC曲线以**真正例率（TPR）**为纵轴，**假正例率（FPR）**为横轴。

呈现ROC曲线的图表称为ROC图（见下图左）。显而易见，对角线代表随机猜测的基准线，而左上角的（0,1）点则象征着完美分类器——所有正例均排在反例之前。

实战中，受限于有限的测试样本，我们只能获得有限个（TPR, FPR）坐标点，无法绘制出理想的光滑曲线，只能得到如右图所示的近似折线。绘制步骤直观明了：给定$m^+$个正例和$m^-$个反例，按预测分值排序。初始阈值设为最大，所有样本均判为反例，起始点为（0,0）。随后依次降低阈值，每遇一个样本便将其划为正例。若当前为真正例，纵坐标上移$1/m^+$；若为假正例，横坐标右移$1/m^-$。连接所有标记点，即得近似ROC曲线。

模型比较时，若某学习器的ROC曲线完全包络另一条，则前者性能占优；若曲线交叉，则难以一概而论。此时引入**AUC（曲线下面积）**作为量化判据。

从几何定义看，AUC即坐标点围成的梯形面积之和。假设曲线由点$\{(x_1,y_1), ..., (x_m, y_m)\}$连接而成，AUC估算公式为：

## 5.3.4 比较检验：不止于“比大小”

有了评估方法与性能指标，似乎只需跑分比大小？实则远比想象复杂。核心难点在于：
1.  **目标不一致**：我们关心泛化性能，手中只有测试集性能，两者未必一致。
2.  **数据敏感**：测试集选取、规模、样本构成均显著影响结果。
3.  **算法随机性**：同一算法、同一参数、同一数据多次运行，结果亦有波动。

**统计假设检验**为性能比较提供了严谨依据，能推断：在测试集上观察到A优于B，是否意味着A的泛化性能在统计意义上显著优于B，以及置信度几何。本节介绍最基础的两种检验，另有McNemar、Friedman与Nemenyi事后检验等进阶方法。下文默认以错误率$\varepsilon$为度量。

### 1. 假设检验与t检验

假设检验的核心是对泛化错误率分布做判断（如$\varepsilon_A = \varepsilon_B$）。因不知真实泛化错误率，只能用测试错误率$\hat{\varepsilon}$估推其分布。直觉上，二者接近可能性大，偏离可能性小。

**二项检验**可用于检验“$\varepsilon \le \varepsilon_0$”这类单模型假设。而**t检验**同属单模型检验工具。实际更常需比较**多模型**性能，故引入成对t检验。

### 交叉验证t检验

以$k$折交叉验证为例，模型A、B在第$i$折上的错误率分别为$\hat{\varepsilon}_A^i, \hat{\varepsilon}_B^i$。若两者性能无异，则在同一数据分割下错误率应相等，即差值$\Delta_i = \hat{\varepsilon}_A^i - \hat{\varepsilon}_B^i$均值为0。据此构造t统计量进行检验。
