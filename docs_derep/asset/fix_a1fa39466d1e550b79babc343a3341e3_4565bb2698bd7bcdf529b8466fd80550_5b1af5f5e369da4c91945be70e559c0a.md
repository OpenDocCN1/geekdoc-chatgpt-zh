让AI真正动手：Web、桌面、移动三端自动化工具

## 7.2 AI 自动化工具
通用AI代理要落地，核心短板不是推理，而是执行。覆盖网页、桌面、移动三大场景的自动化方案，正把口语化指令转化为可落地的交互行为，让代理在真实数字环境里完成信息采集、流程推进和结果自检。

### 7.2.1 Browser Use
Browser Use 是专为AI代理打造的浏览器操控方案，提供一套标准化的网页交互接口，让没有物理操作能力的模型也能读懂页面并完成精细动作。

它与传统脚本式自动化有本质区分，并非提前写死流程，而是嵌入代理的决策链路。代理收到类似“查今日美股涨幅前十”这样的口语任务后，会自行拆解为打开页面、点击、滚动、填写表单、抽取数据等一系列浏览器动作，从而独立完成信息获取、任务推进和状态校验。

底层设计围绕赋能代理展开。引擎可接入GPT-4、Claude、DeepSeek等不同基座模型，由模型负责指令理解、页面结构解析与决策，以匹配不同复杂度与成本需求；感知层面兼顾DOM与XPath的结构定位，同时融合视觉与语义理解，能识别“那个蓝色提交按钮”等模糊描述，并在动态页面中保持操作稳健；任务调度支持多标签页协同切换，保证多任务并行与跨平台部署时行为一致；功能体系可扩展，开发者可挂载自定义插件如写入数据库，把浏览器动作接入企业内部流程，形成闭环自动化。

典型用法包括：作为自主信息采集器定期抓取指定网站的结构化数据，例如竞品价格、金融数据，为决策提供实时输入；模拟真实用户执行复杂的UI流程测试并动态校验结果，确保应用可靠；登录在线办公系统后自动完成文档撰写、报表生成与导出等原本依赖人工的数字化流程。

总体来看，Browser Use 把口语指令转译为底层浏览器操作，在代理与Web之间搭起桥梁，提升感知与执行的衔接，让代理在数字空间自主办事。

### 7.2.2 Computer Use
Computer Use 是Anthropic于2024年11月提出的操控范式，让AI像人一样使用电脑，完成点图标、输文字、管理文件等系统级操作。

该范式具备三项核心能力。感知层面依赖视觉语言模型解析屏幕截图，并结合OCR识字，精确定位按钮坐标等可交互元素；类人操作链遵循感知→决策→执行的闭环，例如截图分析、光标移动、点击、结果验证的连续动作；输入模拟直接调用操作系统API执行键盘鼠标操作，支持跨应用协作，如Excel表格处理、PPT制作。

因此它特别适合替代人工的常规电脑操作。跨软件任务中可自动从股票分析跳转到数据整理并调用Excel、PPT；端到端测试中能模拟用户全流程操作；隐私受限场景下可避开社交媒体API，用界面操作间接完成任务。

借助该技术，口语指令能被精确映射为复杂系统操作。未来用户无需学习各类专业软件的繁琐逻辑，用日常语言下指令即可完成电脑上的常见工作。

OmniParser是该范式的一种实现。2025年2月微软研究院发布的OmniParser V2能实时解析屏幕界面元素如按钮、图标，并转为JSON等结构化数据，使AI可理解指令并执行点击、输入等操作，无需针对特定界面做微调。效率与精准度明显提升，在复杂界面测试中达到领先水平，成为跨平台跨应用智能自动化的核心工具。

OmniParser的特点是UI解析精准，能从像素级图像中提取可交互区域的边界框、功能语义与文本，无需依赖HTML或视图层级，在复杂界面中可靠识别每个可交互点；同时具备多模态兼容，可与DeepSeek-R1、Qwen 2.5VL等主流基座模型无缝集成，扩大应用场景并提高代理任务的执行准确率。

### 7.2.3 DroidRun
