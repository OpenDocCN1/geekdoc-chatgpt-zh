# 内容简介

这是一本面向青少年的AI实践入门读物。全书以“感官系统”“超级大脑”“智能伙伴”等形象比喻拆解AI核心技术，通过猫狗识别、语音助手对话、作文改写等情境，让机器学习、计算机视觉、大语言模型的工作原理变得直观可见，并引导读者用图形化编程搭建语音魔法故事工坊、智能感应小夜灯、校园安全小卫士等趣味作品。

书中还安排了技术缺陷检验，例如人脸识别偏差、AI语言幻觉等，以及AI使用规范的内容，帮助读者培养批判性思维和技术责任感。

全书贯穿游戏化学习思路，“成就打卡”“成就贴纸”机制把抽象知识转化为可感知、可参与的实践挑战。案例兼顾经典技术如围棋对弈、图像识别，也覆盖学科融合创新如单词记忆游戏、数学解题推演、AI艺术创作，适合10～16岁青少年提升科技素养。同时也是教师设计STEM课程、家长开展亲子科技活动的参考指南，帮助学习者在创造中掌握面向未来的关键能力。

# 前言

当你对着智能音箱点歌、看着手机自动挑出猫咪照片、让AI帮忙梳理作文思路时，有没有想过这些“贴心”功能背后是什么逻辑？编写《有趣的人工智能：少年AI启蒙课》的出发点正是要让人工智能不再是课本里的生僻名词，也不只是专家的专属理论，而是像拼图积木一样触手可及的玩伴，在动手过程中悄悄点燃对科技的好奇与热爱。

我们明白，10～16岁的孩子很难直接理解抽象原理，所以本书始终围绕“让AI看得见、摸得着、用得上”展开。用“感官系统”讲计算机视觉，透过猫狗识别实验体会AI如何“看见”；用“超级大脑”讲机器学习，从围棋对弈到数学解题推演展现AI如何“学习”；用“智能伙伴”讲大语言模型，结合语音互动、作文修改让读者理解AI如何“听懂”与“表达”。这些不仅是知识传递，更是建立“AI源于生活、服务于生活”的认知。

本书跳出单向阅读模式，形成三大特色：第一，动手实验学习模式，读者不必死记硬背，可用图形化编程工具亲手完成语音魔法故事工坊、智能感应小夜灯、校园智能安全小卫士等项目，在做中学逻辑；第二，强调批判性思维，专门设置技术漏洞测试，如剖析人脸识别误差、拆解语言幻觉成因，并编写“AI使用守则”，让读者学会理性看待技术、承担使用责任；第三，游戏化设计贯穿始终，“闯关测验”“成就打卡”“成就贴纸”把知识点和实践任务变成可挑战的关卡，在成就感中消化抽象内容。

编写上坚持“有趣优先、实用其次”，不用复杂公式和专业术语，而是用比喻、场景、案例搭桥；既保留围棋对弈、图像识别等经典，也纳入单词记忆、AI艺术创作等跨学科实践，让不同兴趣的读者都能找到入口。本书不是一次性读完的资料，而是一本可反复翻阅、随时动手的科技工具箱。

读者不止青少年。10～16岁的小读者能从这里开启轻松启蒙；教师可直接把案例和项目用作STEM教学素材；家长也能借此开展亲子科技活动。我们希望合上书时，带走的不仅是对AI的认识，更是探索、思考、创造的勇气。未来的科技世界需要理性与热爱去塑造，而这本书就是送给你的钥匙。

# 第1章 初识AI：身边无处不在的智能伙伴

## 1.1 什么是人工智能

人工智能是计算机科学的重要分支，像给机器施法，让普通计算机模拟、延伸和扩展人类智能，完成原本只有人能处理的复杂任务。简言之，AI是用技术让机器具备感知、思考与行动的能力，让它“看得见、听得懂、想得通、做得到”，成为得力的智能伙伴。

### 1.1.1 AI的“感官系统”

AI让机器拥有感知世界的“眼睛”和“耳朵”。人走进陌生房间会用眼睛扫视、用耳朵捕捉声音、用手指触摸；AI的感官则是摄像头、激光雷达、麦克风、各类传感器。

例如，扫地机器人的顶部小圆盘激光雷达会像蝙蝠回声一样不断扫描房间轮廓，帮助避障；自动驾驶汽车的“眼睛”比细心司机更强，能同时观察四周，实时捕捉行人、车辆、交通标志等细节。这些智能感官把图像、声音、温度等转化为数字序列，像把真实世界翻译成计算机可读的密码，AI正是通过这些密码理解世界。

### 1.1.2 AI的“超级大脑”

AI拥有能像人一样思考、甚至更快更全面的“超级大脑”。大脑由神经网络等复杂算法构成，模仿人脑神经元互联传递信息，从海量数据中找规律、解问题。

输入目的地时，导航AI会瞬间分析上万条路线，同时考虑拥堵、施工、天气等，推送最优方案。刷短视频时，AI也在默默思考：“喜欢猫咪视频的，下一条推小猫打哈欠的萌瞬间”。这就是用专用程序分析信息、给出最贴合需求答案的过程。

### 1.1.3 AI的“超能行动”

思考之后就要行动，靠扬声器、屏幕、机械臂等“钢铁手脚”完成。比如对智能音箱说“播放李白的《静夜思》”，它会完成感知识别语音、思考匹配诗歌库、行动播放诗歌的全套流程。

更强的AI堪比“钢铁侠”，能完成高难度任务。工业机器人可精准焊接汽车零件，误差小于头发丝；医院AI手术机器人能稳准缝合血管，动作比资深医生更稳。

## 1.2 AI是如何“学习”的

你是如何认识猫的？第一次见小猫时，大脑像侦探搜集证据：毛茸茸的外表、尖耳朵、大眼睛、长胡须。反复见到后，大脑归纳出共同特征：四条腿、长尾巴、尖耳朵、圆眼睛、长胡须。下次看到新动物时迅速判断“很可能是一只猫”。这就是积累经验、归纳规律并应用规律的过程。

### 1.2.1 AI的“数据寻宝大冒险”

AI学习的核心叫机器学习，像一场数据寻宝。首先收集海量数据宝藏：文字、图片、声音、视频等，如你反复观察各种猫积累经验。接着用算法在数据中挖宝，总结出专属规律即模型，如你发现猫的共同特征。最后把规律转化为超能力，应用到全新场景，不仅能认出未见过的猫，还能判断它是否想玩耍。AI正是靠从数据中挖掘规律不断解锁新技能。人类学习与AI学习对比见图1-8。

### 1.2.2 AI学习的“第一招”：监督学习

监督学习像有老师指导，工程师为计算机准备带标签的数据，如大量标有cat、dog的动物图片。计算机分析颜色、形状、纹理等特征，找出特征与答案的联系，学会区分动物，再用以判断新图片，如图1-9。

例如教计算机认手写数字0-9，给它很多带答案的练习册。计算机分析笔画弯曲、点线位置等特征，慢慢分辨出潦草的7和一笔的1，找到规律后即可识别新图片中的数字，如图1-10所示。
