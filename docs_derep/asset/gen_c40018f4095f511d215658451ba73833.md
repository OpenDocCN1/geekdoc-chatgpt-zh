质性研究里，扎根理论和框架分析走的是两条不同的路。

扎根理论像是开探路，概念、范畴、关系边走边定，研究者要不断试错、回旋，创造性和灵活性是基本功。框架分析则更像按图施工，问题、框架先行，数据进来后按既定流程、固定顺序处理，过程稳定可预期。

把 ChatGPT 拉进来做手，两个路线都能提速，尤其是文本编码这块。过去访谈转录出来全靠人手一遍遍标码，现在可以用对话式助手实现半自动化。下面用盲人玩家玩电子游戏的访谈来演示一遍实操思路。

先把角色和任务说清。访谈文本是语音转录直出，错别字、口语冗余、排版混乱都很常见。第一步要给模型一个背景定位：

> 文字提示 你是一名社会科学学者，擅长使用访谈和扎根理论，擅长对访谈文本进行编码，你明白吗？
> prompt You are a scholar in the social sciences, skilled in using interviews and grounded theory, and adept at coding interview texts. Do you understand?

模型确认角色后，才开始喂数据。

喂数据要分段。ChatGPT 一次性可接受的输入大约 3 500 字，超了就得切片。把一段盲人 A 关于电子游戏的访谈拆成两块，先问它是否收到第一部分，再让它先做概括。模型会提炼出结识刘哥、长期玩两年的地下勇士类游戏、手机端操作、主要为了放松打发时间等要点。

第二部分继续补上关于声音游戏的体验。访谈者追问重复感、操作方式、社交变化等。

是的，我收到了这段盲人A访谈文本的第二部分。在这一部分，访谈者询问了盲人A关于他玩声音游戏的经验，以及游戏如何影响他的生活。盲人A表示，虽然这个游戏很重复，但它确实帮助他结识了很多朋友。在游戏中，他可以通过语音提示进行操作，并通过调整语速来提高游戏体验。他谈到了这个游戏的一些有趣功能，例如通过吹气来提高攻击力。虽然这款游戏不是特别复杂，但盲人A表示，它在一定程度上满足了他的需求。

盲人A还提到了他所了解的其他一些适用于盲人的游戏，例如《三国名将》《鸿蒙天书》《风云再起》和《青秀江湖》。他表示，《清流江湖》稍微有趣一些，但其他游戏可能需要在吸引力和完善性方面进行改进。

此外，盲人A表示自己喜欢探索新事物，喜欢阅读关于历史、军事和政治等方面的书籍。他认为，接受教育程度较高的盲人更倾向于对这些领域感兴趣。

收到两段后进入开放式编码。指令是把编码和原文出处一一对应，做成表格。第一次产出会得到游戏类型、操作方式、语速调节、生活影响、适配游戏清单、吹气功能等几类初码。如果觉得不够细，可以追问再挖掘一次，模型会补充出受众规模、内容重复性、声音设计、提示方式、社交效果、心理影响等更颗粒化的节点。

这里有几个实操教训。有人想一次把所有访谈全倒进去让模型一次性标完，不建议。首先记忆窗口有限，后面内容会挤掉前面信息；其次脏数据多了，批量输入错误率飙升；再者 GPT-4 的使用额度有限制，文本一多容易被迫降到 GPT-3.5。经多次对比，GPT-3.5 的编码准确度明显低于 GPT-4。

比较稳妥的做法是控量。单人访谈在 1 000 字以内时，可以同时放 4~5 个人一起处理；总体上单次输入最好控制在 1 万字以内，分批进场。批量指令可以这样写：

> 文字提示 现在你收到了盲人 A、盲人 B、盲人 C 的访谈记录，请对盲人 A、盲人 B、盲人 C 的访谈进行开放式编码，并把编码和文中所有具体语句出处一一对应，一个编码可以对应多个语句出处，请做成表格，表格包含 4 列，一列是编码，一列是语句出处，要求写出具体句子，一列是该编码对应了多少出处，一列是所对应的访谈对象。
> prompt Now you have received the interview records of blind persons A, B, and C. Please perform open coding on the interviews of blind persons A, B, and C, and correspond each code with all specific statements in the text. One code can correspond to multiple statement sources. Please make it into a table. The table includes four columns: one for the code, one for the statement source, one for the number of sources corresponding to the code, and one for the corresponding interviewee.

如果访谈很长，宁可一人一次、过长则再拆分。想快速核对节点也可以直接让模型列出全部编码和对应的原句。

编码有了，下一步是轴向处理。先让模型对比三个人编码的共性与差异，找出共享主题和个性主题。共享层面通常包括游戏对生活的整体影响、社交与友情的建构、以及游戏内的挑战与应对。个性层面则会体现个人侧重：A 可能突出克服挑战与自我效能，B 可能偏向身份探索，C 可能更强调竞争与人际互动。

随后进行归类。指令可以要求把所有节点归到合适的主题下，允许跨主题归属，一个主题下再细分子主题。例如游戏体验可拆为娱乐性与挑战性，社交维度可拆为结识、维持、情感支持，等等。模型会给出主题树，研究者再人工校对、合并、升维。

总结下来，ChatGPT 适合做重复性高的初筛和分拣，但质性研究的审慎和理论敏感度仍要研究者把控。设定好角色、分批喂料、迭代细化编码、最后人工做轴向整合，这套组合拳能让扎根理论和框架分析都跑得更快、更稳。
