## **第三节 终结性评价：总结学习效果并给予建设性意见**

教育信息化是国家教育教学的重要战略，教育管理信息化是其中关键一环。2021 年教育部发布加强新时代教育管理信息化工作的通知，要求以数据驱动，利用新一代信息技术提升教育管理的数字化、网络化、智能化水平，推动决策从经验驱动转向数据驱动、管理从单向管理转向协同治理、服务从被动响应转向主动服务，支撑治理体系与治理能力现代化。

基础教育阶段的日常成绩是教师反馈教学效果、学生定位反思的主要形式。通过分析阶段性成绩，教师能及时反思课堂、了解掌握程度并调整教学，学生也能通过排名与变化反思自身并调整状态。然而面对海量考试成绩，人工处理耗时耗力，给中学教师带来压力。进入信息化时代，GAI 具备高效处理数据的能力，可为成绩分析与学习效果评价提供便捷。

近年来，自动化程序处理学生成绩成为信息技术研究的热点，已出现多种案例，如利用 Python 分析大学物理实验课程成绩，实现多维度可视化与学业预警；利用 Python 与数据分析技术挖掘线上教学成绩相关学习行为特征，为教学方式与内容提供建议。

当前评估系统多依赖编程语言或专业软件，要求教师具备一定技术基础，学习成本高。大多数软件的个体数据相对独立，鲜少关联学生间、学生与科目间关系，难以挖掘成绩背后的深层信息，难以满足教师的普遍需求。

在现代教育体系中，GAI 已成为终结性评价的有力工具，尤其在成绩分析上优势明显。它依托强大数据算法，深入挖掘学生在各学科、不同题型与学习阶段的表现，生成个性化分析报告。报告涵盖知识强弱、方法优劣，并给出精准指导建议。操作界面简洁明了，教师无需专业技术背景即可快速获取详尽结果，大幅节省统计分析时间，使教师能聚焦教学优化、个体辅导与教育创新，提升工作效率。
