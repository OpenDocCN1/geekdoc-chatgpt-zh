PATTERN风险评估遭法官否决：种族偏见与程序瑕疵成关键

法院最终没有采纳 PATTERN 的判定结果，背后有三个主要考量：其一，该工具存在制造种族歧视的风险，可能让不同族裔在再犯危险性评估上承受不平等对待；其二，PATTERN 并未达到《第一步法案》所要求的标准与程序，缺乏独立的验证；其三，在本次评估中，PATTERN 所用因素的权重设定对克罗本人尤为不利。因此法院拒绝以 PATTERN 的结果作为判断克罗是否符合保外就医危险性条件的依据。

本案审理过程中，法官吸收了专家学者的论点与研究报告的分析，并参考了既有案件的裁判思路与理由。2018年12月《第一步法案》正式生效，其中第101条对风险与需求评估系统的构建与运行作出了规范。非营利组织“人工智能伙伴关系”于2020年4月发布了题为《算法风险评估和新冠肺炎：为什么不应使用 PATTERN 工具》的报告，对 PATTERN 作了简要介绍，并重点论证了该工具可能放大种族不平等、评估模式对特定类型囚犯尤为不利，以及在新冠疫情背景下使用不当的问题。^([\[4\]](#txt001.html#footnote_content_txt001_4))此外，布兰登·加勒特与梅根·史蒂文森于2020年2月在期刊发表的《开放风险评估》一文，也讨论了 PATTERN 数据样本与评估要素在实际操作中的不公平之处。^([\[5\]](#txt001.html#footnote_content_txt001_5))2020年3月，杰纳·德勒和卡伦·贝斯致函司法部指出 PATTERN 未按《第一步法案》第101节第3631条b款要求完成独立验证，^([\[6\]](#txt001.html#footnote_content_txt001_6))存在导致种族与性别不平等的潜在风险，且不适用于疫情特殊情形，故认为在判断是否对囚犯适用家庭监禁时使用 PATTERN 并不妥当。^([\[7\]](#txt001.html#footnote_content_txt001_7))由此可见，即便《第一步法案》对风险评估工具的适用作出较为明确的规定，其在避免评估结果不公方面的改进空间仍然很大，而本案法院对拒绝采用 PATTERN 的理由作出说明，也为此类工具的完善指明了方向。

2011年3月，克罗策划并参与了一起银行抢劫案和一起药房抢劫案，且在作案过程中携带有枪支。2013年3月21日，美国联邦密歇根州南部地区法院陪审团作出判决，认定被告人犯有密谋实施银行和药店抢劫、密谋持有枪支、密谋在联邦暴力犯罪中使用或携带枪支的罪名，一项抢劫银行罪名，一项抢劫药店罪名，两项在联邦暴力犯罪中使用或携带枪支罪名，以及两项持有枪支的重罪。法院据此判处克罗535个月监禁。2015年6月，第六巡回上诉法院维持了原审的定罪与量刑。2019年4月，密歇根州南部地区法院裁定对克罗案重新审判。2019年8月，法院将克罗刑期缩减至五年。2020年11月，法院作出指示性裁决并将刑期缩短至实际服刑期。2020年12月，密歇根州南部地区法院将刑期减为已服刑期，准许克罗保外就医并即刻释放，同时判处三年监督释放。关于 PATTERN 适用争议，即出现在2020年12月法院审理克罗保外就医申请期间。

PATTERN 软件由美国司法部于2019年7月提出，旨在服务《第一步法案》目标。该系统用于对囚犯进行风险与需求评估，为“减少再犯计划”提供指引，并作为分配生产性活动的参考。软件包含两套模型：一套预测被释放囚犯未来三年内因违法行为被重新逮捕的概率，另一套预测因暴力犯罪被重新逮捕的概率。两种模型采用相同的风险量表：最低、低、中、高。囚犯可能获得两份风险分数与分类，最终采用两者中较高者。^([\[8\]](#txt001.html#footnote_content_txt001_8))美国司法部于2019年秋季开展了为期45天的公众评议并据此对 PATTERN 作了修改。^([\[9\]](#txt001.html#footnote_content_txt001_9))修改中加入了部分动态要素，例如是否参与心理健康治疗项目，同时剔除了可能造成分类差异的因素，如首次被捕年龄、是否自愿投降等。尽管修改意图在于提升公正性与准确性，但相关报告并未实质性地探讨并验证这些调整能否降低原有不平等。

克罗出生于1981年的密歇根州底特律市，童年极不稳定，小学期间便更换了约15所学校，因而出现行为与适应问题。其父因吸毒与犯罪未能尽抚养责任，其母常对其实施虐待，导致精神健康恶化。12岁时克罗离家出走并开始贩毒与吸毒。

密歇根州南部地区法院在判断是否允许保外就医时需考察四方面：第一，依据《美国法典》第3582条c款i项，^([\[10\]](#txt001.html#footnote_content_txt001_10))克罗的保外就医申请是否已满足救济请求用尽要求；第二，是否具备“特殊且令人信服的理由”；第三，减刑是否与联邦量刑委员会政策一致；第四，依据《美国法典》第3553条a款，法院在量刑时须考量犯罪情节、行为人过往、犯罪史与人格特征等。第四点正是 PATTERN 评估结论与法院对克罗危险性认知冲突之处。

前三项条件均被认定满足后，法院对第四项的总结为：克罗童年与青少年经历在一定程度上促成其犯罪；其在狱中服刑时间已久，已接受足够教育；克罗已成为监狱管理的模范，其时已不构成对社会安全的威胁；此外，克罗的犯罪主要集中于青少年时期，成年后已有明显转变，未成年期的危险性与犯罪史不应作为当前危险性判断的依据。PATTERN 却将克罗归为高再犯风险囚犯，与法院判断明显相悖。法院认为 PATTERN 并非绝对正确，适用上仍存争议且极易导致不公，故不予采信。

### 【核心争议点】

1.在新冠疫情背景下，将 PATTERN 评估结果纳入保外就医裁量标准，是否加剧了种族不平等。
2.PATTERN 作为风险评估工具是否依照《第一步法案》规定完成独立验证。
3.在评估再犯风险时，PATTERN 所采用的参考因素是否对克罗这类人群存在系统性不利。

### 【裁判论证过程】

#### （一）在新冠病毒疫情背景下，将 PATTERN 评估结果纳入保外就医的裁量标准，加剧了种族不平等

密歇根州南区地方法院在裁量时援引了“人工智能伙伴关系”组织的观点，即其在《算法风险评估和新冠肺炎：为什么不应使用 PATTERN 工具》报告中指出 PATTERN 的使用会加剧种族歧视问题。报告首先论证了 PATTERN 输入数据中的偏见，随后强调疫情的特殊性，结论认为使用该工具可能扩大种族歧视。^([\[11\]](#txt001.html#footnote_content_txt001_11))

其一，PATTERN 输入数据存在种族偏见。一方面，罪犯被重新逮捕的数据本身带有种族歧视色彩。PATTERN 以被重新逮捕的数据进行验证与评估，但被逮捕数据不等同于实际再犯数据，警方是否获悉事件、受害者行为、警察个人意愿与判断等诸多因素都会影响逮捕结果，而这些因素又深受种族影响，导致输入数据存在不公。另一方面，低级别犯罪数据中同样存在种族偏差。人工智能伙伴关系采用的实证数据表明，在较低级别犯罪中黑人罪犯比例偏高，这与既有种族偏见及警务自由裁量权密切相关。^([\[12\]](#txt001.html#footnote_content_txt001_12))该组织认为，即使输入数据中仅存在少量种族偏见，也足以使 PATTERN 评估结果带有歧视与不公。^([\[13\]](#txt001.html#footnote_content_txt001_13))

其二，PATTERN 的开发并未纳入新冠疫情考量，也未在疫情背景下接受检验。监狱生活条件易使新冠病毒在囚犯中迅速传播，若采纳带种族偏见的风险评估模式来决定是否准许保外就医或监督释放，监狱中黑人的感染率与死亡率可能进一步升高，种族歧视从而危及生命安全。

#### （二）PATTERN 作为风险评估工具未依照《第一步法案》的规定进行独立验证

法院认为 PATTERN 评估结果仍存未解的合理怀疑。《开放的风险评估》与杰纳·德勒等人致司法部的信均对 PATTERN 提出质疑，法院在论证中予以采纳。PATTERN 开发者未公开验证数据。司法部主张 PATTERN 使用的逮捕与定罪信息由州地方司法机构直接提供，故公开受限，无法作进一步检验。因此开发者所称的预测准确性与公平性得不到验证，未达《第一步法案》采信标准。^([\[14\]](#txt001.html#footnote_content_txt001_14))

第二，开发者未公布风险阈值的设定方式。PATTERN 将再犯风险划分为最低、低、中、高四个等级，但不同等级间的概率确定标准及设定理由均未以透明方式公开，风险阈值的科学依据亦受质疑。^([\[15\]](#txt001.html#footnote_content_txt001_15))

第三，两种模型的直接预测对象为囚犯被再次逮捕的可能性，而非再次犯罪的可能性。逮捕与犯罪虽有重合，但并非所有犯罪都会被警方知晓并导致逮捕，且被逮捕不必然导致定罪，故不能以再次逮捕数据替代再次犯罪数据。

第四，囚犯难以通过参加监狱课程降低风险评分。根据 PATTERN 计分参考，参与监狱内培训课程是囚犯主动改善评估结果的唯一途径，但联邦监狱可提供的康复培训资源不足，难以满足需求。^([\[16\]](#txt001.html#footnote_content_txt001_16))这意味着即便囚犯有意愿降低评分，也难以完全实现，导致风险评估难以及时反映风险变化。

#### （三）PATTERN 工具在评估再犯风险时所采用的参考因素对克罗此类人群存有系统性不利

法院认为，由于评分过程中不同因素权重差异，克罗这类人群很难获得最低风险分类。克罗生于1981年，裁决时年约39岁。其15岁进入少管所，17岁因持械抢劫被判9至30年，假释后再次犯罪。年龄与犯罪史是 PATTERN 计算中最重要的考量。一方面，30岁以下男性囚犯几乎不可能被归入最低风险类别；另一方面，若男性囚犯具有犯罪史，除非已超过40岁，否则很难被划入最低风险。^([\[17\]](#txt001.html#footnote_content_txt001_17))
