# AI法学前沿案例精读

## 前言

本书系北京市教育科学规划课题“新时代人才强国战略与人工智能法治人才培养”（3030-0014）的阶段性成果

### 一、人工智能法学的兴起

近些年互联网、大数据、云计算与人工智能的创新步伐明显加快，已渗透到经济社会运行的各环节。技术推进的速度、覆盖的范围、产生的效应都达到前所未有的程度，正成为重组全球要素、重塑经济结构、改写竞争格局的关键变量。^([\[1\]](#fow001.html#footnote_content_fow001_1))中国自2017年起，以《新一代人工智能发展规划》《促进新一代人工智能产业发展三年行动计划（2018-2020年）》《“互联网+”人工智能三年行动方案》《国家新一代人工智能创新发展试验区建设工作指引》以及《国家新一代人工智能标准体系建设指南》等文件为依托，搭建起顶层设计框架，以技术标准、产业规划、安全伦理为抓手推动AI与实体经济的深度融合。^([\[2\]](#fow001.html#footnote_content_fow001_2))在国家部署的带动下，国内技术发展迅猛，社会样态随之发生多重变化。法学的发展与法治建设也从商业文明的赛道转向数字文明的赛道。放眼全球，中国在AI领域已由跟跑转为并跑乃至领跑。^([\[3\]](#fow001.html#footnote_content_fow001_3))这些前沿实践与现实需求不断倒逼法学研究与法学教育的变革。

当下，AI技术及其应用在法律层面已凸显出三重态势。第一，全球AI立法热度攀升，通过量创纪录。该报告统计了25个国家的立法轨迹，涉AI法案由2016年的1件增至2021年的18件。2021年西班牙、英国、美国各以3件居首。美国州级AI提案由2012年的2件激增至2021年的131件。中国自2017年《电子商务法》颁布后，涉AI立法明显提速，《个人信息保护法》《数据安全法》《互联网信息服务算法推荐管理规定》《互联网信息服务深度合成管理规定》等相继出台，治理框架初具雏形。欧盟2021年4月21日提出《人工智能法案》，2022年4月20日公布修正案草案。可以说AI立法已进入全球化阶段。^([\[4\]](#fow001.html#footnote_content_fow001_4))

第二，伦理议题日益凸显，法律与伦理的互动需求加强。报告指出，大型语言模型不断刷新技术基准的同时，也更鲜明地映射出训练数据的偏见。对比2018年参数1.17亿的最先进模型，2021年一个2800亿参数的模型所引发的毒性提升了29%。^([\[5\]](#fow001.html#footnote_content_fow001_5))随着系统能力不断迭代，算法偏见也在跨域蔓延。公平性、问责性、透明度已成为学界共同关切。顶级学术会议ACM FAccT与NeurIPS已连续就算法公平、问责、透明与隐私举办系列研讨，并成为长期关注重点，相关论文数量直线上升。^([\[6\]](#fow001.html#footnote_content_fow001_6))这表明AI伦理已成为技术、产业与政策界的共识议题。

第三，AI法学研究与法学教育迅速升温。数据显示，2020年一年里，北美每五名获计算机科学博士的应届生中就有一名来自AI或机器学习方向，相关专业已成为过去十年最热领域。^([\[7\]](#fow001.html#footnote_content_fow001_7))AI法学同样呈现蓬勃态势。研究显示，美国26%的法学院至少开设一门涵盖AI与法律的课程，13%的高校开设多门交叉课程。有观点建议将AI法律类学位项目纳入排名。^([\[8\]](#fow001.html#footnote_content_fow001_8))国内法学界自1985年杜飞进《信息法浅论》起步，2002年中国法学会信息法学研究会成立后，多位学者与高校在计算法学、数据法学、智能法学、AI法学等方向持续深耕，推动法学教育从案例走向代码。^([\[9\]](#fow001.html#footnote_content_fow001_9))作为新文科建设在法学领域的重要增长点，AI法学正形成政策引导、理论支撑、技术支持、实务依托相互配合的人才培养格局。

上述三大态势不仅指向全球发展方向，也预示全新学科的诞生。AI重新定义生产力与生产关系，演绎出数字化的新逻辑，催生算法社会，进而对现代法学产生釜底抽薪式的冲击。^([\[10\]](#fow001.html#footnote_content_fow001_10))因此AI法学的兴起绝非一时之举，而是承载信息革命诉求、反映数字时代行为规律、涵盖理论规范与司法实践的法学变革。^([\[11\]](#fow001.html#footnote_content_fow001_11))

### 二、人工智能法学教育的现状与展望

AI法学是“人工智能+法学”深度交叉形成的新型独立学科。^([\[12\]](#fow001.html#footnote_content_fow001_12))它不仅是技术与法学的融合，更耦合了新的研究范式与法治实践。^([\[13\]](#fow001.html#footnote_content_fow001_13))其研究涵盖“法治实践的智能化”与“智能技术的法治化”两大议题，聚焦智慧法治理论与实践、司法人工智能理论、智能算法风险及其规制、智能技术归责重构以及数据生成、共享与使用等六大核心问题，回应智能化时代挑战。^([\[14\]](#fow001.html#footnote_content_fow001_14))

从技术架构看，AI主要由要素层、平台层、应用层构成。^([\[15\]](#fow001.html#footnote_content_fow001_15))要素层中，算法、算力、数据是三大驱动要素。为帮助理解底层要素的法律属性，本书遴选了与算法性质、规制、问责与应用相关的前沿判例，勾勒算法司法实践的新动向。平台层与应用层，技术已深度嵌入公共与商业场景，搜索引擎、人脸识别、信用评价、智慧司法、智慧警务等均有广泛应用。本书挑选了这些领域具代表性的境外判例，每案以案件提要、案件要旨、核心争议点、裁判论证、审理结果五个维度呈现全貌，并配以思维导图，帮助读者快速把握案件脉络与层次。

作为新兴学科，其发展离不开系统化的科学与理论基础，需要内部逻辑一致、能够提炼成体系的法律结构和核心规范，并由此在整个法律部门中发挥作用。^([\[16\]](#fow001.html#footnote_content_fow001_16))这种一致性与映射性的实现，需要以成熟、自主的法学教育为底色。因此AI法学教育对课程、教材与师资均有较高要求。在新文科背景下，我国AI法学教育面向数字法治理念，根植数字法学体系，正探索彰显中国特色与自主性的互动路径。^([\[17\]](#fow001.html#footnote_content_fow001_17))综合来看，可从三个方向提升：

其一，适度扩大课程数量与规模，形成基础与研讨并重的阶梯体系。统计显示，美国U.S.News排名前197所法学院中，有51所开设法律与AI课程。哈佛法学院以9门居首，斯坦福与乔治城各8门，前30名院校几乎全覆盖。^([\[18\]](#fow001.html#footnote_content_fow001_18))课程既有概论也有研讨，如AI与国家安全、自动驾驶法律规制、AI法学研究的国际视角、AI与人权、AI与网络安全等。^([\[19\]](#fow001.html#footnote_content_fow001_19))相比之下，我国以网络法学、信息法学、科技法学、数据法学、计算法学、未来法学等为切入口初步形成数字法学课程体系，但整体规模有限，教材、师资与培养方案尚不成熟，多停留在零散探索阶段。加之学生法学功底与信息技术基础薄弱，研讨类课程起步较慢。未来需系统规划课程设置，扩大规模并发挥优势课程引领作用，推动多阶梯多模式培养。

其二，加大教材建设力度，探索体系化、特色化、前沿化兼具的形式。在美国等成熟地区，已有一套系统化的教学材料。例如伍德罗·巴菲尔德等《法律和人工智能高级入门》（2020年），萨米尔·抽普拉等《自主人工智能的法律理论》（2011年），帕特里克·林等人《机器人伦理：机器人技术的伦理和社会影响》（2014）和《机器人伦理2.0：从自动驾驶汽车到人工智能》（2019年），乌戈·帕加洛《机器人法：犯罪、合同和侵权行为》（2013年版）等。艾瑞克·古德曼突破传统纸质形式，以电子教材匹配网络课程，《互联网法》迄今更新至第十三版。^([\[21\]](#fow001.html#footnote_content_fow001_21))国内“信息技术+法学”教学最突出问题是教材匮乏。《网络法学》《信息法概论》等教材时效性与体系性不足，更新速率滞后。^([\[23\]](#fow001.html#footnote_content_fow001_23))技术艰深、问题多变、迭代迅速，给编写带来挑战。^([\[24\]](#fow001.html#footnote_content_fow001_24))未来宜从三方面推进：一是形式多元化，以概论教材引领、判例教材突破双轨并行。二是团队交叉化，法学与技术科学深度融合。三是保障更新频率，及时涵盖新议题与新理论。本书以判例集评析方式，是对教材建设的初步探索。美式案例教学法通过精选法官核心观点展现规则演化，本书在体例上借鉴了这一分析框架，希冀用前沿经典案例勾勒重要议题，培养批判性思维，与教学实践形成良性互动。^([\[25\]](#fow001.html#footnote_content_fow001_25))

其三，探索课程与技术科学的深度融合。AI法学具有文理交叉、跨域应用的特性。课程需要顺应学科规律，探索有效的知识融合机制。在哈佛访学期间，我观察到玛莎·米诺与辛西娅·德沃克联合开设的跨院系网络法课程“公平与隐私：来自法律和概率的视角”。该课以研讨与读书会形式实现法学与信息科学的深度交叉，学生来自法学院与工程与应用科学学院，团队协作完成阅读、讨论与论文。国内已有尝试，如清华大学法学院的计算法学课程，选课生来自法学院与计算机、自动化院系，主讲团队兼具理论与实务。未来应推动师资交叉，更充分调动两学科学生合作，实现全链条互动。

### 三、本书的缘起

面对全球科技竞争，习近平总书记强调AI是引领新一轮科技革命和产业变革的重要驱动力，要把握发展态势，培养大批创新型AI高端人才。为贯彻这一指示，推动新文科建设，探索世界水平、中国特色的卓越法治人才培养体系，我从课程与教材建设入手，回应AI时代需求，致力于培养复合型法治人才。

2017年，“信息技术+法学”教学科研开始兴起，虽缺乏成熟样本，但开设技术与法学前沿交叉课程的必要性与紧迫性十分清晰。在系统梳理几十门世界知名法学院网络与信息法学课程大纲与教材共性的基础上，我与梅夏英院长联合在对外经济贸易大学开设了首门“法学+科技”前沿课程“网络法理论与实务研究”。课程设计强调交叉化、前沿化、国际化，从基础概论到核心技术，从实体应用到法律规制，从软法到立法前沿，逐步带领学生领会各主题。

课程之外，教材建设同样关键。2019年教育部提出“三全育人”方针，科研育人是重要环节。如何让科研成为学生成长的沃土，是推进科研育人的核心思考。受互联网“众包”协作模式启发，我希望在课堂外构建激发科研兴趣、训练创新能力、延伸教学边界、参与教材建设的协作路径。在网络法理论与实务课程中，我鼓励学生参与《人工智能法学前沿案例评析》编写，讲解外文判例分析与法律脉络梳理方法，搭建案例分析框架。
