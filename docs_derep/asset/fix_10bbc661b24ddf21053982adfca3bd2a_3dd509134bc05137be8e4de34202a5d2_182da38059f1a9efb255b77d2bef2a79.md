### 9.3.3 进行登录操作
实际业务中多数场景都需要登录，小程序把登录流程封装得很简洁。先用 wx.checkSession 检查当前登录态是否仍然有效，该方法支持 success 与 fail 等回调。

若触发 fail，说明未登录或登录态已过期，此时调用 wx.login 发起登录，成功后会返回 code，code 是临时的登录凭证，后端可用其换取 openid 与 session_key 等信息。

一套完整的登录逻辑需要小程序前端、开发者服务器与微信服务端三方配合，流程如下：

- 1. 小程序端调用 wx.login 获取临时凭证 code。
- 2. 前端把 code 送到开发者自有服务端。
- 3. 服务端结合 code 及密钥向微信接口换取 openid 等信息。
- 4. 服务端把 openid 与自有体系用户关联，记录登录状态，并把自有 token 返回客户端。
- 5. 小程序端缓存 token，后续请求携带该 token 完成鉴权。
