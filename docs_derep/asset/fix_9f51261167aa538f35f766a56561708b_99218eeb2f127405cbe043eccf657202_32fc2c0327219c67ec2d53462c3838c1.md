# 第5章 绘画技巧速成

本章围绕文字生成图像与图像生成图像两条主线展开，手把手教你把想法变成画面，也能以已有图像做风格延展与创意重塑。还会拆解提示词的搭建方法、细节把控技巧以及画质提升思路，目标是实现出图快、准、好。即使没有绘画基础，也能借助可灵 AI 画得像、画得妙、画得快。

## 5.1 文生图

文生图就是把文字转化为图像，是 AI 绘画的基础环节。将描述性关键词或完整文本输入到可灵 AI，再配合相关指令与参数，就能得到精美的绘画结果。

在文生图中，提示词既是描述也是指令。模型会依据提示词判断色彩、构图、风格与细节。描述越清晰具体，生成的图像就越贴合预期。因此，学会科学搭建并优化提示词是掌握文生图的关键。可灵 AI 的图片生成页顶部提供 DeepSeek 选项，因其内置了 DeepSeek 深度思考大模型，可在创作时借助它拓展思维、深化创意，从而得到更精准的提示词。

### 5.1.1 文生图的使用场景

文生图是通过一段描述性文字，让模型理解后生成静态图像。常见用法包括：

- 角色设定：塑造人物长相、着装、姿态及场景氛围；
- 场景绘制：如古风庭院、奇幻世界、科幻都市等；
- 产品设计可视化：用关键词快速得到产品概念图；
- 插画与海报：迅速产出概念草稿，便于后续精修或灵感迭代。

可灵 AI 在这一块可操作性很强，能把不同维度的文字提示进行理解与组合，输出符合预期的画面。

### 5.1.2 提示词的构成要点

要让可灵 AI 准确呈现画面，提示词需要覆盖表 5-1 中的要素。不同项目和工具的写法可能略有差异，但核心思路相通。

表 5-1 提示词构成要素

| 要素 | 说明 |

| :--- | :--- |

| 主体 | 指明画面中心物或人，比如单只犬、身着汉服的少女、极具未来感的飞行器等。可补充种类、性别、动作、数量等信息，帮助模型锁定核心对象 |
| 场景/背景 | 交代主体所在的空间与情境，例如古老宫殿、赛博城市、田园乡野、海边夕阳等，有助于构建空间感并增强叙事性 |
| 外观特征 | 细化外观细节，如发色、瞳色、表情、衣装款式、配饰、动作等，描述越具体越能贴近预期，降低随机偏差 |
| 风格/艺术形式 | 确定整体画风，可以是写实、卡通、油画、蒸汽波、复古插画、赛博朋克等，也可参考某位艺术家的笔触，使色彩与纹理保持一致 |
| 光照与色调 | 说明光线与色彩偏好，如逆光、柔和暖调、烛光昏暗、日落金黄、霓虹映照等，光影与色调共同决定情绪氛围 |
| 质量和细节要求 | 明确画质标准，如高清晰度、细节饱满、面部清晰、线条细腻等，引导模型加强局部表现 |
| 排除项 | 列出需避免的元素，如噪点、冗杂人群、特定色块、意外杂物等，帮助模型规避负面影响 |

### 5.1.3 提示词示例

下面提供几个例子帮助直观理解写法。

#### 1. 日常场景

示例提示词如下：

> 一只金色短毛猫，坐在窗台上，看着窗外的雨景；画面整体清新明亮，带有小清新的插画风格；背景使用柔和的浅绿色和浅蓝色调，表现雨后的清凉氛围。

解读：
核心对象是金色短毛猫，背景为窗台雨景；整体走小清新插画路线，采用淡绿淡蓝调营造雨后清凉感。

#### 2. 未来科技风

示例提示词如下：

> 一位身穿银灰色金属机甲战衣的女性，身后的背景是巨大未来城市天际线，霓虹闪烁；画风赛博朋克；强烈的对比光，人物面部轮廓清晰；明亮的紫色和蓝色光线交错；高分辨率，细节刻画。

解读：
主体为身着机甲战衣的女性，背景是未来都市与霓虹；风格为赛博朋克；紫蓝对比光强调轮廓与分辨率，追求细腻画质。

#### 3. 童话插画

示例提示词如下：

> 一个身穿粉色纱裙的小女孩，正乘坐热气球飞过奇幻森林；背景中有巨大的蘑菇、漂浮的萤火虫；插画风格温暖，灯光柔和；给人童话般的奇幻与浪漫。

解读：
主体为粉纱裙小女孩乘热气球；场景为奇幻森林、巨型蘑菇与萤火虫；风格温暖柔和，营造童话浪漫氛围。

提示词既是作品的灵魂，也是与 AI 的沟通桥梁。只有设计层次分明、逻辑清晰的文字描述，才能让模型更好理解意图，产出高质量且富有创意的图像。

## 5.2 图生图

图生图不是从零创作，而是基于提供的参考图像进行再创作、扩展或变形，快速得到新图。无论是升级手绘草稿，还是把实拍照片转成特定风格插画，都能在短时间内获得惊喜效果。

### 5.2.1 图生图的应用场景

图生图能解决手绘、后期、摄影修图中耗时的问题，也便于创意迭代和视觉拓展。常见场景有：

- 风格转换：将原图转为不同艺术风格或笔触，例如把街景照片处理成油画，或给人像加上赛博朋克霓虹光影；
- 创意扩展：为已有卡通形象补充背景元素、加入新故事线，或向外扩展画面边界，让视野更宽、细节更足；
- 局部修饰与细节强化：在原图指定区域做调整，如修改角色表情、更换服饰、修复损坏或低清部分，同时保留整体结构并加入新元素；
- 色调与氛围改造：给照片或插画更换季节或情绪，例如把夏日绿地变成枫叶飘落的秋景，或让暗调画面变得明亮温暖，操作比手动调色更便捷；
- 草图快速成稿：提供简单线稿，模型即可自动填充细节、渲染风格，从粗概念一步到位生成完整图。

### 5.2.2 如何编写图生图的提示词

图生图区别于文生图之处在于需要同时提供参考图片。在可灵 AI 中，先上传基础图像，再配一段描述改动或重塑风格的提示词，模型会结合图文信息进行推理。

编写时可以参考以下思路：

1. 明确你想“保留”什么
是否希望构图与人物布局不变？原图中必须保留的元素有哪些，比如人脸特征、建筑基本形。可以在提示词里写明“保持角色姿态不变”“保留原有表情与动态”，让模型知道核心部分。

2. 强调你想“改变”或“增强”什么
若要调整色彩、风格、氛围，就要给出具体描述，例如：“把此古装人物变成现代街头装扮，画面偏二次元漫画风格”“将背景

3. 考虑局部替换或修饰
只想修改局部时，需在提示词里指明位置或范围，例如：“人物头部加一顶粉色帽子”“背后添加翅膀”“替换背景为太空星云”等。
