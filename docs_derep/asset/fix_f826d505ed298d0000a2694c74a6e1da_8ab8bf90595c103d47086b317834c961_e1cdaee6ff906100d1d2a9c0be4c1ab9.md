# 2 基础知识

## 2.1 优化问题

神经网络压缩可被视作一类优化问题，即在解空间中寻找满足约束条件的优解。以第 4 章的模型剪枝为例，从优化视角看，需在解空间中挑选权重位置置零，在硬件延迟、存储、功耗等指标不超过阈值的约束下，尽可能保留剪枝后模型的任务性能。第 7 章的神经网络架构搜索是在更灵活的架构空间中寻优，而第 5 章的模型量化涉及量化格式、量化参数与量化值的联合决策。本节先介绍优化基础。

按可行域类型划分：

离散优化与连续优化。离散问题的可行域通常有限但规模巨大，难以遍历，变量常为整数或图结构决策，如整数线性规划、旅行商问题等。连续问题的可行域不可数无限，如线性规划、二次规划。

按目标与约束的显式程度划分：

白盒优化与黑盒优化。白盒中目标与约束形式已知且具备可利用的全局结构如线性、凸性，或局部可微等特性。黑盒常见于：目标或约束形式未知，只能实验观测；形式被隐藏，只能通过接口调参；形式已知但计算复杂、缺乏易用结构。例如架构搜索的目标需训练测试神经网络，计算成本极高。通过近似与松弛可把问题转为白盒，如可微分搜索[19]第 7.5 节，用验证集损失近似精度，用权重共享超网络一步优化近似完整训练，并松弛离散架构约束，从而利用梯度快速求解。

### 2.1.2 优化方法的分类

按寻优目的分：

1. **局部优化方法** Local Optimization Method。目标是找到局部最优，通常利用目标函数的局部特性高效收敛。连续可微情形常用梯度下降等；离散情形局部特性不明确，常需先松弛为连续。
2. **全局优化方法** Global Optimization Method。目标是探索整个搜索空间以发现全局最优。凸优化等特殊情形局部即全局，多数实际问题全局结构复杂，难以保证在合理时间内找到全局最优，但可为部分结构问题估计最优界。

按对问题性质与接口的利用程度分：

1. **黑盒优化方法** Black-box Optimization Method。将目标或约束视为仅提供输入取值到输出值的评估接口。方法先采样候选解评估，再据历史结果生成新候选。分为基于模型与无模型两类。基于模型使用代理模型如贝叶斯优化、基于模型的强化学习；无模型包括种群进化算法、无模型强化学习等启发式方法。
2. **白盒优化方法** White-box Optimization Method。利用问题的结构特性求解。例如**基于梯度的优化方法** Derivative-based Method 利用梯度信息。针对白盒问题可选用凸求解器、整数线性规划分支定界、基于梯度的连续优化等。面对复杂白盒问题，有时仍选用通用性强的黑盒方法。

2. 激活层

卷积本身是线性运算，堆叠线性仍为线性，表达能力受限。因此在线性运算后引入非线性激活函数。常用形式包括：

- Sigmoid$(x) = \frac{1}{1+e^{-x}}$；
- Tanh$(x) = \frac{1-e^{-x}}{1+e^{-x}}$；
- ReLU$(x)^{[21]} = \max(0, x)$，使用最广；
- SiLU$(x)^{[22-24]} = x\sigma(x)$，$\sigma$ 为 Sigmoid。

3. 池化层

Fukushima 等人[25]提出池化以降低空间尺寸。常用无参数操作有：

- 平均值池化 Average Pooling，取滑窗均值；
- 最大值池化 Max Pooling，取滑窗最大值，反向传播时梯度沿最大值位置传递；
- 全局平均值池化 Global Average Pooling，取整张特征图均值。
