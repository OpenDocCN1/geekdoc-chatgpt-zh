（1）规律。零与任意数相乘结果始终为零，例如0×0＝0、0×1＝0；一与任意数相乘结果保持原数不变，例如1×0＝0、1×1＝1。多位数相乘的思路与十进制一致，先用乘数的每一位去乘被乘数，再把得到的部分积错位叠加。

（2）举例：101（5）×11（3）。

**8.4.4 进制转换妙招**

**1.二进制数↔︎十进制数**

1）二进制转十进制

（1）要点。采用按权展开累加的方式，权值即该位对应的2的幂。

（2）操作步骤。从右起数位，第1位的权是2⁰，第2位的权是2¹，第3位的权是2²，依次向左每进一位权值乘以2。转换时把各位上的0或1与对应权相乘再全部相加，即得十进制结果。

（3）示例。

①二进制101化为十进制。

自右向左逐位计算：

第1位：1×2⁰＝1×1＝1。

第2位：0×2¹＝0×2＝0。

第3位：1×2²＝1×4＝4。

总和：1＋0＋4＝5 → 101＝5。

②二进制1101化为十进制。

自右向左：

第1位：1×2⁰＝1。

第2位：0×2¹＝0。

第3位：1×2²＝4。

第4位：1×2³＝8。

总和：1＋0＋4＋8＝13 → 1101＝13。

2）十进制转二进制，整数部分

（1）要点。整数与小数处理不同，两部分合起来才是完整结果。整数部分的核心是反复除2取余，再倒序排列。

（2）操作步骤。把十进制整数不断除以2并记录余数，直至商为0。随后把余数从最后一次到第一次依次写出。

（3）示例。

①十进制5化为二进制。

a.5÷2＝2余1。

b.2÷2＝1余0。

c.1÷2＝0余1。

倒序余数：1→0→1 → 101。

[PRE1]

②十进制13化为二进制。

a.13÷2＝6余1。

b.6÷2＝3余0。

c.3÷2＝1余1。

d.1÷2＝0余1。

倒序余数：1→1→0→1 → 1101。

3）十进制转二进制，小数部分

（1）要点。小数做法与整数不同，核心是不断乘2取整，并按出现顺序排列。整数和小数两部分相加即为最终值。

（2）操作步骤。把十进制小数反复乘以2，取每次的整数部分0或1，直至小数变0或达到所需精度。整数部分按从前往后顺序排列。

（3）示例。

①十进制0.625化为二进制。

a.0.625×2＝1.25，取整1，余0.25。

b.0.25×2＝0.5，取整0，余0.5。

c.0.5×2＝1.0，取整1，余0。

顺序排列：1→0→1 → 0.101。

[PRE2]

②十进制0.375化为二进制。

a.0.375×2＝0.75，取整0，余0.75。

b.0.75×2＝1.5，取整1，余0.5。

c.0.5×2＝1.0，取整1，余0。

顺序排列：0→1→1 → 0.011。

**2.八进制数/十六进制数↔︎二进制数**

1）八进制转二进制

（1）要点。1位八进制对应3位二进制，不足补0在前。

（2）操作步骤。将八进制的每一位换成对应的3位二进制，再拼接。

（3）示例。

①八进制37转二进制。

a.3→011。

b.7→111。

拼接：011111 → 去掉前导0即11111。

[PRE3]

②八进制54转二进制。

a.5→101。

b.4→100。

拼接：101100 → 二进制101100。

2）二进制转八进制

（1）要点。3位二进制对应1位八进制，从右往左分组，不足补0在前。

（2）操作步骤。把二进制从右往左每3位分为一组，每组换成八进制后串联。

（3）示例。

①二进制110101转八进制。

a.分组：110、101。

b.101→5，110→6。

拼接：65。

②二进制101011转八进制。

a.分组：101、011。

b.011→3，101→5。

拼接：53。

3）十六进制转二进制

（1）要点。1位十六进制对应4位二进制，不足补0在前。十六进制0～9对应十进制0～9，A～F对应10～15。

（2）操作步骤。把每一位十六进制数换成4位二进制，再连接。

（3）示例。

①十六进制3A转二进制。

a.3→0011。

b.A即10→1010。

拼接：00111010 → 去前导0为111010。

②十六进制B5转二进制。

a.B即11→1011。

b.5→0101。

拼接：10110101。

4）二进制转十六进制

（1）要点。4位二进制对应1位十六进制，从右往左分组，不足补0在前。

（2）操作步骤。把二进制从右往左每4位分为一组，换成十六进制后串联。

（3）示例。

①二进制1011101转十六进制。

a.分组：0101、1101。

b.0101→5，1101→D。

拼接：5D。

②二进制111010转十六进制。

a.分组：0011、1010。

b.0011→3，1010→A。

拼接：3A。

**9.1 数据类型与变量**

**9.1.1 小故事**

小乐每天处理乐乐超市的各种信息，比如商品价格、库存数和折扣。在整理时他发现，不同信息属性不同：数量是整数，像10瓶汽水；价格常带小数，像橘子汽水3.5元、桃子汽水4.2元；商品名则是多个字符串联。

于是小乐用不同的“数据类型”来区分，而且这些信息会变：桃子汽水只剩3瓶要补货，补完变100瓶；橘子汽水上月3.5元本月涨到3.8元；商品名也会调整，如“橘子汽水”改成“橘汁汽水”。会变化的数据叫“变量”。

也有永不改变的内容，比如乐乐超市的金字招牌，不管商品如何变，招牌始终不变。这种固定量叫“常量”。

**3.变量的声明、初始化和赋值**

1）什么是变量

变量是程序运行时存放可变数据的、带唯一标识符的内存区域。标识符即变量名，程序员通过它操作内存。创建变量时使用声明语句，运行时为其分配空间。

2）声明变量

（1）目的。声明变量相当于“向编译器报备”：我要用一个变量，名字是x，类型是int，请分配相应内存。
