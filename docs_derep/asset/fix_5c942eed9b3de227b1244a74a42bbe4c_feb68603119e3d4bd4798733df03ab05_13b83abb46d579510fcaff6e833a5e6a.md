### 3.2 DeepSeek-R1 推理能力全景

本部分围绕 R1展开，梳理其核心功能、在线接口使用方式、参数配置思路以及典型落地场景。R1 属于超大规模推理型系统，除了文本生成与理解能力外，还原生支持函数调用，能够联动外部工具完成复杂任务。同时也会介绍各类环境下的本地化部署思路，以及借助主流推理框架进行性能调优的做法，以扩大适用范围。

#### 3.2.1 R1 体系概览

R1 由 DeepSeek 于 2025 年 1 月推出，目标是强化大语言模型的推理水平。评测显示，在数学解题、代码产出、自然语言推理等方向，其表现可与 OpenAI 正式版 o1 相当。

在发布 671B 级的 R1 与 R1-Zero 两大版本的同时，团队还基于 R1 的输出蒸馏出 6 个轻量版本供社区使用，其中 32B 与 70B 在多项指标上接近 OpenAI o1-mini 的水准。

另外，article 标签同样可作为插件容器，让插件看起来像是页面原生的一部分。

需要留意的是，R1 与 DeepSeek-V3 在架构层面完全一致，差异主要体现在训练流程与数据上。具体而言，R1 先在 V3 Base 上做有监督微调，随后进行强化学习；相对的，R1-Zero 省略了有监督微调环节，直接以 V3 Base 为起点开展强化学习。

因此 R1 项目仓库里找不到独立的权重、推理脚本或本地部署说明，因为这些内容已归入 DeepSeek-V3 项目，详见 3.1 节。
