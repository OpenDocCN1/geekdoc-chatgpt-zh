TFLite 极简推理实战速览

想在本地快速验证一个 TFLite 模型是否能跑通，可以用一段极简的 C++ 骨架把整个流程串起来。思路是先把模型文件读入内存，再生成解释器并分配资源，随后触发推理，并在执行前后把解释器内部状态打印出来，方便排查问题。

这段可执行程序的逻辑很直观：先校验命令行参数得到模型路径，用扁平缓冲读取器把文件解析为模型对象，再借助内置算子解析器初始化构建器得到解释器实例。张量内存分配成功后先dump一次解释器状态，调用推理接口后再dump一次，便于观察前后差异。
