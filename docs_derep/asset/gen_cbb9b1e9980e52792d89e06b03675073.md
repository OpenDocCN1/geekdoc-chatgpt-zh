# GPT-2 前向预处理：从原始输入到隐状态的完整准备链路

想真正读懂 GPT-2 是怎么跑起来的，先别急着看 Transformer 块，核心的第一段工作是把各种可能的输入形态统一、补齐、转换成模型能直接用的隐向量。下面这段逻辑决定了第一次全量推理和之后的逐 token 自回归生成在形状、位置、遮罩上能无缝衔接。

整体思路很清晰：参数缺省值先从配置里补齐，随后校验输入来源，然后根据是否已有缓存 past_key_values 决定序列长度和位置编码的生成方式，再把注意力遮罩、交叉注意力遮罩、头掩码准备好，最后完成词嵌入、位置嵌入、类型嵌入的叠加并做一次 dropout，为后续的层级循环铺路。

要点一句话概括：input_ids 和 inputs_embeds 不能同时出现；第一次迭代输入整段，之后每次只进一个 token；position_ids 会自动累加 past_length 保证位置连续；attention_mask 会被扩展成 4 维并用 -10000 压低无效位置的分数。
