# 内容精进与职业成长提示词合集

### 文本润色优化指引

优化维度如下：

1. 结构打磨
    - 调整段落与句式布局，提升逻辑清晰度
    - 强化论证的层次递进与连贯性
    - 打造更有冲击力的首尾，完善整体框架

2. 表达升级
    - 用更准确生动的用词替代模糊平淡的表述
    - 调整句式节奏与语气，增强力度与可读性
    - 保持风格统一，与受众及使用场景相契合

3. 内容加固
    - 在不偏离原意的前提下补充有力细节或例证
    - 突出核心信息与关键论点
    - 剔除冗余，提升信息密度与含金量

4. 专业度强化
    - 合理引入专业术语与行业表述，适度即可
    - 保证表述严谨准确
    - 增强说服力与权威感

交付格式：
1. 润色后的完整稿件
2. 修改说明，概括主要优化点及原因
3. 提出 3~5 条关键改进建议以便后续完善
4. 核心段落的替代表达示例

要点提醒：
- 不得改动原文的核心信息与基本立场
- 在保留原文风格的基础上做增益，而非推倒重写
- 润色后需自然流畅，避免生硬或过度修饰

使用方法：粘贴待润色文本，并指定文本类型与优化侧重，DeepSeek 将从结构、表达、内容与专业度等多维度提升质量，同时维持原意和风格特质，使文本更具影响力与专业感。

灵活变体：
- 精准受众：补充“特定受众考量：[如高管/技术人员/跨文化受众]”，获得更有针对性的语言调整
- 演讲适配：在“文本类型”选“演讲稿”，“优化重点”选“表现力”，获取更利于口头呈现的版本
- 简化复杂文本：增加“复杂度调整：简化”提示，获得通俗易懂但不失核心的解读

#### 长文精简
提示词：战略性长文精简专家

> 身份定位：你是擅长在保留核心价值与关键信息的前提下大幅压缩篇幅、提升清晰度与冲击力的内容精简专家。

任务说明：请将以下长文压缩为简洁有力、易于理解的版本，完整保留关键信息与核心论点。

基础设定：
- 原文类型：[选择：报告/演讲稿/论文/提案/文章/会议记录等]
- 目标读者：[填写]
- 精简幅度：[ 轻度（约减30%）/ 中度（约减50%）/ 高度（约减70%） ]
- 最终用途：[ 演讲 / 阅读 / 分享 / 参考等 ]
- 保留要点：[ 必须保留的核心内容或段落 ]

待处理原文：
[ 粘贴需要精简的长文 ]

精简策略：
1. 内容优先级判定
   - 锁定并保留核心观点与关键信息
   - 甄别可压缩或删除的次要内容
   - 维持论证完整与力度
2. 表达压缩技巧
   - 去除冗余与重复表述
   - 用简练有力的句子替代啰嗦描述
   - 合并相关相近内容
   - 选用更精准词汇，减少不必要修饰
3. 结构重塑
   - 重组材料以提升逻辑水平
   - 优化段落，确保每段有明确中心
   - 强化转折节点的显眼度
4. 呈现建议
   - 适时用要点式替代大段文字
   - 建议使用小标题提升可读性
   - 如需提供视觉组织建议

输出要求：
1. 精简后的完整版本
2. 精简策略说明，阐明如何精简及原因
3. 关键保留内容清单，确认重要信息未遗漏
4. 可选的超精简版，适用于快速浏览或口头概括

注意事项：
- 防止过度压缩导致失真或逻辑断裂
- 保持原文语气与风格基调
- 保证精简稿连贯完整且具说服力

使用指引：粘贴长文并明确精简程度与保留重点，DeepSeek 将采用内容优先级方法把冗长文本转化为简洁有力版本，确保核心信息与论点完整，同时提升清晰度与影响力。

变体建议：
- 演讲版精简：添加“用途：演讲展示”，获取更贴合口述表达的精简稿
- 多层版本输出：添加“多层次输出：是”，同时获得完整版、中等版与摘要版
- 术语保留：添加“专业术语处理：保留关键术语”，在压缩中维持专业性
