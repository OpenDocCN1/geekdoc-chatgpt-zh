## 3.3 DeepSeek 驱动的数据快速统计
数据统计是对原始信息进行收集、整理、分析和解释的完整过程，其目的是揭示事物的特征、规律与趋势，为决策提供支撑，是数据分析的基础环节。单独的数据明细没有价值，必须用科学的统计手段从不同维度加工，才能挖掘出隐藏的商业价值。因此数据统计在分析链条中至关重要。常用的统计手段主要包括函数法和数据透视表。

### 3.3.1 常用统计函数概览
在数据分析中，统计函数是理解和处理数据集的核心工具，可依据特定统计逻辑对数据进行计算，帮助提取有效信息。统计函数大致可分为三类：集中趋势类、离散程度类和数据汇总类。

#### 1. 集中趋势类函数
（1）平均数：把所有数据相加后除以个数得到的结果，最能反映整体水平，但对异常值敏感。
▶ 特性：
- 灵敏度高：每个数据点的变动都会影响平均值。
- 易受极端值拉动：极大或极小值会扭曲平均数的代表性。
▶ Excel 用法：average( 数据范围 )。

（2）中位数：把数据按大小排序后处于中间位置的数值，受极端值影响小，能更好体现中间水平。
▶ 特性：
- 抑制异常：对偏态数据更稳健。
- 分割性：上下各半的数据量。
▶ Excel 用法：median( 数据范围 )。

（3）众数：一组数据中出现频次最高的数值，可用于数值和分类数据，一组数据可能有多个众数、一个众数或无众数。
▶ 特性：
- 适用分类：能反映最常见类别。
- 不唯一：可能出现多众数或无众数。
▶ Excel 用法：mode( 数据范围 )。

#### 2. 离散程度类函数
（1）极差：最大值减最小值，反映总体波动跨度，计算简便但易受极端值影响，常用于质量控制中监测尺寸波动。
▶ 特性：
- 计算简易。
- 受极端值影响大。
▶ Excel 用法：max( 数据范围 )-min( 数据范围 )。

（2）方差：各数据点与平均数的离差平方的平均，值越大离散越强，广泛用于风险评估、实验误差分析等。
▶ 特性：
- 覆盖全部数据点。
- 单位为平方，不够直观。
▶ Excel 用法：var.p( 数据范围 ) / var.s( 数据范围 )。var.p 为总体方差，var.s 为样本方差。

（3）标准差：方差的平方根，单位与原数据一致，更直观。
▶ 特性：
- 单位一致，便于解释。
- 是离散程度最常用的指标。
▶ Excel 用法：stdev.p( 数据范围 ) / stdev.s( 数据范围 )。stdev.p 为总体标准差，stdev.s 为样本标准差。

（4）四分位差：上四分位数 Q3 减下四分位数 Q1，反映中间 50% 数据的离散情况。
▶ 特性：
- 抗异常。
- 仅关注主体部分。
▶ Excel 用法：Q3–Q1。四分位数用 quartile.exc( 数据范围 ,n) 计算，n=1,2,3…。
[PRE0]

#### 3. 数据汇总函数
（1）求和函数。常用 sum，类似的有 sumif 和 sumifs。sum 计算总和；sumif 按单条件求和；sumifs 按多条件求和。
Excel 用法：
- sum( 数据集 )。
- sumif( 数据集, 条件值, 求和范围 )。
- sumifs( 求和范围, 条件范围 1, 条件值 1, 条件范围 2, 条件值 2,… )。

（2）计数函数。count 统计数值型单元格数量，countif 为单条件计数，countifs 为多条件计数且条件为“与”。
Excel 用法：
- count( 数据集 )。
- countif( 条件范围, 条件值 )。
- countifs( 条件范围 1, 条件值 1, 条件范围 2, 条件值 2,… )。

（3）均值函数。average 求算术平均，averageif 为单条件平均，averageifs 为多条件平均。
Excel 用法：
- average( 数据集 )。
- averageif( 条件范围, 条件值, 求平均范围 )。
- averageifs( 求平均范围, 条件范围 1, 条件值 1, 条件范围 2, 条件值 2,… )。

（4）最大值函数。max 返回最大值，maxifs 返回满足多条件下的最大值。
Excel 用法：
- max( 数据集 )。
- maxifs( 求最大范围, 条件范围 1, 条件值 1, 条件范围 2, 条件值 2,...)。

（5）最小值函数。min 返回最小值，minifs 返回满足多条件下的最小值。
Excel 用法：
- min( 数据集 )。
- minifs( 求最小范围, 条件范围 1, 条件值 1, 条件范围 2, 条件值 2,...)。

### 3.3.3 数据透视表介绍
数据透视表是电子表格软件中的强力工具，尤其在 Excel 中被广泛使用。它允许用户通过拖拽快速对大量数据进行汇总与展示，帮助从多角度理解数据并辅助决策。主要功能包括数据汇总、动态调整汇总维度与方式、多维分析。
（1）数据汇总：自动按分类汇总，得到总计、平均等统计信息。
（2）动态调整：通过拖拽随时改变布局与汇总方式，无需重算。
（3）多维分析：支持行、列、值的多字段交叉分析。

#### 1. 数据透视表页面构成
页面主要由报表生成区、字段列表和字段设置区组成。
（1）报表生成区：展示汇总后的结果。
（2）字段列表：数据源字段，可拖入报表区。
（3）字段设置区：设置汇总方式与格式，字段可放入筛选器、行、列、值等区域。
[PRE14]

#### 2. 数据透视表常用分析功能
（1）数据汇总与分类。自动分类汇总；多级分类汇总，逐层深入。
（2）数据筛选与排序。灵活筛选子集；多字段排序。
（3）数据分组与聚合。按间隔或类别分组；自定义分组。
（4）计算字段与公式。新增计算字段；计算百分比、增长率等。
（5）条件格式与数据可视化。条件格式突出重点；与图表结合展示。
（6）数据钻取与联动。汇总与明细间切换；多表联动分析。
[PRE15]
（7）数据趋势分析。时间序列排列；环比与同比分析。
（8）数据占比分析。整体占比；分组内占比分析。

#### 3. 数据透视表优劣势
（1）优势：高效处理大数据；直观表格展示；布局灵活可调。
（2）劣势：对初学者操作偏复杂，公式设置易形成门槛；复杂需求下需结合其他工具。
