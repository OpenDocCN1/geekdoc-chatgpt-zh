### 21.2.3 定位中的实例迁移学习

### 21.2.4 定位中的模型迁移学习

本节介绍基于模型的无线定位迁移，重点涵盖非序列与序列两类代表性工作。

#### 非序列模型

以跨设备无线定位为例。LatentMTL 方法（Zheng 等人，2008b）将不同设备建模为独立任务，通过跨任务参数共享挖掘任务相关性以提升精度。定位建模采用回归函数 $ f(z) = w^T z + b $，其中 $ z = \varphi(x) \in \mathbb{R}^l $ 为变换后的信号向量，$ w $ 为权重，$ b $ 为共享偏置，$ \varphi $ 为特征映射。在多设备场景下，将 $ T $ 个设备视为 $ T $ 个任务（此处 $ T=2 $，即一源一目标），每个任务 $ t $ 对应权重 $ w_t $。借鉴 Evgeniou 和 Pontil（2004）的思想，将 $ w_t $ 分解为：

$ w_t = w_0 + v_t, \quad \forall t = 1, \cdots, T $

其中 $ w_0 $ 为全局共享参数，$ v_t $ 为任务特有参数。核心目标是寻找合适的映射 $ \varphi_t $，将原始信号投影到 $ k $ 维潜在空间，使得各任务假设函数在此空间相近（即 $ v_t $ 足够“小”）。

各项含义解读如下：

- **经验损失项**：$\xi_t, \xi_t^*$ 为 $\epsilon$-SVR 的松弛变量，$\pi_t$ 为任务权重。
- **知识共享项**：最小化 $\| v_t \|^2$ 旨在缩小潜在空间 $\varphi_t(x)$ 中任务假设的差异；最小化 $\| w_0 \|^2$ 对应最大化模型间隔增强泛化。通常设 $\lambda_1 > \lambda_2$ 以强制任务假设相似。$\Omega(\varphi_t)$ 惩罚映射复杂度，为求解方便，令 $\varphi_t(x) = \varphi_t x$ 视为线性变换，并采用平方 Frobenius 范数 $\|\varphi_t\|_F^2$。
- **约束条件**：遵循标准 $\epsilon$-SVR 设定，$b$ 为偏置，$\epsilon$ 为不敏感参数。

#### 序列模型

TrHMM 模型（Zheng 等人, 2008a）引入隐马尔可夫模型（HMM）利用轨迹信息（即图 21.4 中的带箭头线条），实现 HMM 参数在时段间的共享与更新。

对于 HMM $\theta = (\lambda, A, \pi)$，发射概率 $\lambda = \{P(x_i|y_i)\}$ 建模信号分布（如各位置的高斯分布 $P(x|y) = \frac{1}{(2\pi)^{k/2} |\Sigma|^{1/2}} e^{-\frac{1}{2}(x-\mu)^T \Sigma^{-1} (x-\mu)}$），依据 Ladd 等人（2002）假设 AP 相互独立，协方差 $\Sigma$ 可简化为对角矩阵。转移矩阵 $A = \{P(y_{i+1}|y_i)\}$ 编码位置转移概率，初始分布 $\pi$ 设为全位置均匀分布。

TrHMM 包含三阶段（见下图 21.5）：

1.  **源时段 0 学习信号相关模型 $\alpha$**：在全局位置网格上，用多元线性回归建模时段 0 数据，导出回归系数 $\alpha^k = \{a_{vj}^k\}$，刻画参考位置 $\{l_i\}$ 与非参考位置 $k$ 间的信号相关性：
    $s_j^k = a_{0j}^k + a_{1j}^k r_{ij} + \cdots + a_{nj}^k r_{nj} + \varepsilon_j$ (21.13)

2.  **迁移至目标时段 $t$ 并重估发射概率 $\lambda$**：利用 $\alpha$ 结合参考点新采集的信号强度，推算非参考点信号强度。考虑到回归参数随时间漂移，引入平衡因子 $\beta \in [0,1]$ 融合回归无线电图 $\lambda_t^{reg}$ 与基础无线电图 $\lambda_0$：
    $\mu_t = \beta \mu_0 + (1-\beta) \mu_t^{reg}$
    $\Sigma_t = \beta \Sigma_0 + (\mu_t - \mu_0)(\mu_t - \mu_0)^T + (1-\beta) (\Sigma_t^{reg} + (\mu_t - \mu_t^{reg})(\mu_t - \mu_t^{reg})^T)$

3.  **利用轨迹数据 $T$ 更新模型**：位置先验 $\pi$ 与转移矩阵 $A$ 自时段 0 起始终共享。先在时段 0 训练基础 HMM $\theta_0 = (\lambda_0, A_0, \pi_0)$，后续时段 $t$ 仅更新发射概率得 $\theta_t = (\lambda_t, A_0, \pi_0)$。

### 21.3 面向行为识别的迁移学习

#### 21.3.1 研究背景

行为识别旨在借助可穿戴传感器（加速度计）、GPS、基于物体的传感器（RFID 标签等）识别人类日常活动（如走、跑、骑行）。

**传统范式**：主流做法将其视为监督学习问题。流程为：多源传感器采集数据 $\rightarrow$ 依据领域知识提取特征（统计量：均值、方差、峰度；频域：MFCC、傅里叶/小波变换等） $\rightarrow$ 输入分类器（决策树、SVM、HMM、CRF 等）。Bao 和 Intille（2004）、Bulling 和 Roggen（2011）、Bulling 等人（2008）、van Kasteren 等人（2008）等工作均在多个基准集上验证了该流程的有效性。
