## 小 结

本章围绕智能体应用的构建思路展开，梳理了从基础到进阶的多套技术路线，并以真实案例进行对照。通读后，读者能够学会挑选合适的工具与框架搭建自己的智能体，同时体会到技术融合与持续调优对提升可用性与效能的价值。

开篇以 LlamaIndex 为切入点，演示从零搭建一个轻量级智能体的流程。内容涉及环境部署、模型获取、本地知识库搭建，以及在知识库加持下实现问答。配合分步讲解与代码片段，读者能迅速学会把本地资料接入智能体，为后续扩展奠定基础。

随后聚焦 Swarm 框架在分布式编排上的能力。示例演示了如何接入 DeepSeek 模型并挂载外部工具，从而让智能体承接更复杂的作业。这一部分突出了不同框架与模型的互通性，说明通过拼接多种组件可以显著增强系统的功能弹性。

最后介绍了两款在社区里较受关注的开源方案 Browser Use 与 Camel。Browser Use 让智能体直接操作浏览器完成信息抓取与处理；Camel 则在任务分发与数据流控制上提供更灵活的选择。两者共同体现了开源生态的多样形态，为希望动手实践的开发者提供了可借鉴的思路。

整体而言，本章既呈现了多套框架落地的具体做法，也强调了组合优化的思路，帮助智能体从可用迈向好用。
