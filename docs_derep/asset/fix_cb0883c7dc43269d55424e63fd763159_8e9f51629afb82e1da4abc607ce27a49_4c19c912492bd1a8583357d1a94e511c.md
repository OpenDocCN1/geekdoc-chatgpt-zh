从 Prompt 到多链协同：LLM 应用搭建要点

Prompt 和 LLM 是搭建 LLM 应用的基石。把 PromptTemplate、LLM 与 OutputParser 组合起来，就能衍生出多种实用能力。以下以 4.15.py 为线索展开。

1. 最简的 Prompt+LLM 衔接
先搭一条最基础的链路：把来自分用户的原始输入填进提示模板，生成加工后的提示交给大模型，再把模型未经处理的回复原样返回给调用方。

[PRE0]

2. 在链上挂载模型参数
创建链时可以为 LLM 注入额外配置，比如停止序列、函数调用等信息，用来更精细地调控生成行为和输出格式。

[PRE1]

3. 引入解析器实现结构化输出
光拿到模型生成的自由文本往往不够用。通过接入 OutputParser，就能把非结构化的结果拆解、抽取成可用结构。

[PRE2]

4. 针对函数签名的 JSON 解析
当要求模型严格按某个函数签名返回时，常用的选择是 JsonOutputParser 或 SimpleJsonOutputParser，其它解析器可参考 https://github.com/langchain-ai/langchain/blob/master/libs/core/langchain_core/output_parsers/__init__.py。

[PRE3]

5. 用 RunnableParallel 简化调用
借助 RunnableParallel，可以自动拼装提示所需要的输入字典，避免手动组装参数的繁琐。

[PRE4]

该示例说明了如何基于本地模型 Gemma 与向量库 FAISS 搭建会话问答。首先用 OllamaEmbeddings 把背景知识嵌入向量空间并存入 FAISS；随后准备两类提示模板，一类用于把对话历史里的追问改写为独立问题，另一类用于依据检索到的背景作答。执行时先并行处理历史与用户提问，用 CONDENSE_QUESTION_PROMPT 模板配合 Gemma 将后续问题改写为自足形式，再从 FAISS 检索相关背景并封装为 Document，最后把格式化后的背景、独立问题与 Gemma 组合成问答链生成最终答案。

#### 4.5.4 多链组合
Runnables 的设计让多条链的串联变得很顺手。通过管道操作符 “|” 把不同链拼接，即可组成复杂的工作流。

【例4-16】 多链组合（参考代码4.18.py）。

from langchain_community.llms import Ollama as OllamaLLM

from langchain_core.prompts import ChatPromptTemplate

from langchain_core.output_parsers import StrOutputParser

from langchain_core.runnables import RunnablePassthrough, RunnableParallel

prompt1 = ChatPromptTemplate.from_template("{product}的优点有哪些?")

prompt2 = ChatPromptTemplate.from_template("基于以下优点, 创作一条{product}的广告语:\n{advantages}")

model = OllamaLLM(model="gemma:2b")

chain1 = prompt1 | model | StrOutputParser()

chain2 = {"advantages": chain1, "product": RunnablePassthrough()} | prompt2 | model | StrOutputParser()

print(chain2.invoke({"product": "iPhone"}))

prompt1 = ChatPromptTemplate.from_template("以下是一家餐厅的基本信息:\n{basic_info}\n 请根据这些信息, 生成一段营销文案, 突出餐厅的特色和优势, 吸引顾客光临.")

prompt2 = ChatPromptTemplate.from_template("以下是一家餐厅的基本信息:\n{basic_info}\n 请根据这些信息, 提出3条经营建议, 帮助餐厅改进服务, 提高竞争力.")

prompt3 = ChatPromptTemplate.from_template("以下是一家餐厅的营销文案和经营建议:\n 营销文案:{marketing}\n 经营建议:{advice}\n 请对这两方面工作提出评价和指导意见, 帮助餐厅更好地开展营销和经营活动.")

model_parser = model | StrOutputParser()

chain1 = prompt1 | model_parser

chain2 = prompt2 | model_parser

chain = (

    {"basic_info": RunnablePassthrough()}

    | {

        "marketing": chain1,

        "advice": chain2,

    }

    | prompt3

    | model

)

basic_info = """

本餐厅是一家主打健康养生的中式餐厅。主要特色:

1. 食材新鲜, 有机蔬菜直接从农场采购。

2. 烹饪注重养生, 少油少盐, 保留食材原汁原味。

3. 环境雅致, 设有包厢, 适合家庭聚餐和商务宴请。

4. 服务友善专业, 定期举办针对老年人的健康饮食讲座。

5. 交通便利, 地铁二号线旁, 商圈附近, 车位充足。

"""

print(chain.invoke({"basic_info": basic_info}))

以上代码体现了借助 LangChain 与 Ollama 模型，结合管道符和 Runnables 组件搭建多阶段自然语言处理流程的做法。

首个演示是串行的两阶段流程：先让模型列出指定产品的优点，再以这些优点为依据创作广告语。chain1 负责产出优点，chain2 在接收优点并透传产品名后生成文案，RunnablePassthrough 完成额外输入的传递。第二份演示更为复杂，先并行生成餐厅的营销文案与经营建议，分别对应 prompt1 与 prompt2，随后把两份产出合并作为 prompt3 的输入，由模型给出综合评价与改进建议。并行产出与后续合并通过管道中的字典嵌套实现。
