目前 Python 官方已不再对 Python 2.x 系列做任何维护与更新。还在沿用旧版本的团队和个人，最好尽早迁移到 Python 3.x 并选用较新的发行版，这样才能保证项目保持最新、安全且稳定。Python 3.x 不仅修复了诸多历史问题，还带来了大量改进与新特性，更符合技术演进的方向。

伴随 Python 的普及，Python 3.x 生态的第三方函数库也在快速增长。本书以 Windows 系统下的 Python 3.x 作为代码实现环境，文中所引用的最高安装版本为 Python 3.11.5。

Python 的语法以清晰简洁著称，能让新手摆脱对语法细节的纠结，把精力放在问题拆解、程序逻辑和算法设计上。其主要特点如下。

- (1) 入门友好
语法结构简洁，遵循优雅、明确、简洁的设计思路，上手快、易读、易维护。

- (2) 解释执行
Python 解释器在运行时直接将源代码转换为可执行形式即可运行，无需用户关心编译、链接是否正确，操作更省心。

- (3) 面向对象
既支持过程式编程，也支持面向对象编程，编程方式灵活可调。

- (4) 免费开源
Python 属于 FLOSS 自由/开放源码软件的一种，用户可以自由分发、阅读源码、修改源码，并将其部分用于新的自由软件中。

- (5) 跨平台可移植
得益于开源特性，Python 已被移植到 Windows、Linux、Mac OS、Android 等多个平台。

- (6) 标准库丰富
除了官方提供的完善标准库外，还有海量第三方库，可覆盖输入输出、文件系统、数据库、网络编程、图形处理、文本处理等场景，省去大量重复编码。

- (7) 可扩展可嵌入
性能关键部分可用 C/C++ 编写后在 Python 中调用；反过来也可以把 Python 嵌入 C/C++ 程序，为其提供脚本能力。

### 1.3.2 第三方工具库概况
除了语言本身的优势，Python 还拥有大量优秀的第三方函数模块，对跨学科应用很有帮助。当前基于 Python 的技术正在高速发展，用户规模持续扩大，在软件开发领域的应用十分广泛。

- （1）操作系统管理与维护
Python 提供了应用程序编程接口 API，可方便地管理和维护操作系统。用 Python 编写的系统管理脚本在可读性、代码复用、扩展性上普遍优于普通 shell 脚本。

- （2）科学计算与数据可视化
Python 拥有众多科学计算、数据可视化和机器学习的库，如 NumPy、SciPy、SymPy、Matplotlib、Traits、OpenCV、Scikit-learn 等，可实现科学计算、数据分析、机器学习、二维图表、三维可视化、图像处理及界面设计等。

Python 中与机器学习关联紧密的主要库有：

NumPy 库：Python 科学计算的基础，提供矩阵处理与运算能力。

Matplotlib 库：常用的绘图模块，能快速把计算结果以多种图形形式呈现。

Scikit-learn 库：开源的 Python 机器学习工具包，提供从数据预处理到模型训练、交叉验证、算法实现与可视化的一整套接口，可大幅减少代码量。

- （3）图形用户界面开发
Python 支持 GUI 开发，可借助 Tkinter、wxPython、PyQt 等库开发跨平台桌面软件。

- （4）文本处理
Python 提供的 re 模块支持正则表达式，还提供 SGML、XML 分析模块，可用于开发 XML 程序。

- （5）网络编程及 Web 开发
Python 的 Socket 模块对 Socket 接口做了二次封装，支持网络编程。还提供 urllib、cookielib、httplib、scrapy 等大量模块用于网页读取与处理，结合多线程可快速实现 Web 应用。Web 框架方面，常见的有 Web2Py、Django 等。

- （6）数据库编程
Python 提供符合 DB-API 规范的模块，可与 SQLite、MySQL、SQL Server、Oracle 等主流关系数据库通信。此外自带 Gadfly 模块，可提供完整的 SQL 环境。

- （7）游戏开发
Python 在网络游戏开发中应用广泛，Pygame 模块可在 Python 程序中创建功能丰富的游戏和多媒体程序。

### 1.3.4 库的下载与安装

1. NumPy
NumPy 是 Python 科学计算的基础包，主要功能包括：

- 1) 高效的多维数组对象 ndarray。
- 2) 对数组进行元素级计算及数学运算的函数。
- 3) 读写硬盘上基于数组的数据集的工具。
- 4) 线性代数运算、傅里叶变换及随机数生成。

除提供快速数组处理能力外，NumPy 还作为算法与库之间传递数据的容器。对数值型数据，NumPy 数组比内置 Python 结构更高效，且由 C、Fortran 等编写的库可直接操作其数据，无需复制。因此许多数值计算工具以 NumPy 数组为主数据结构或与其无缝协作。

2. Pandas
Pandas 提供处理结构化数据的丰富数据结构与函数，自 2010 年出现以来推动 Python 成为高效数据分析环境。核心对象是面向列的二维表 DataFrame，以及一维标签化数组 Series。

Pandas 兼具 NumPy 的高性能数组计算和电子表格、关系数据库的灵活处理能力，索引功能细腻，便于重塑、切片、聚合与子集选取。

安装相对简单，先装好 NumPy 后执行 “pip install pandas” 或下载源码后执行 “python setup.py install” 即可。

3. Matplotlib
Matplotlib 是最流行的 Python 二维数据可视化库，由 John D. Hunter 创建，现由庞大团队维护，适合制作出版级图表。虽有其他可视化库，但 Matplotlib 使用最广且与生态工具配合良好。

安装通常执行 “pip install matplotlib” 或下载源码安装。需要注意的是其上级依赖较多，手动安装时需逐一部署依赖。

4. SciPy
SciPy 是一组解决科学计算标准问题的包集合，主要包括：

- 1) scipy.integrate：数值积分与微分方程求解。
- 2) scipy.linalg：扩展 numpy.linalg 的线性代数与矩阵分解。
- 3) scipy.optimize：函数优化与根查找。
- 4) scipy.signal：信号处理工具。
- 5) scipy.sparse：稀疏矩阵与稀疏线性系统求解。
- 6) scipy.special：SPECFUN Fortran 库的包装，提供伽马函数等常用数学函数。
- 7) scipy.stats：标准连续离散概率分布、统计检验与描述统计。

NumPy 与 SciPy 结合构成成熟计算平台。SciPy 依赖 NumPy，安装方式与 NumPy 相同，可通过 “pip install scipy” 完成。

5. Scikit-learn
Scikit-learn 于 2010 年诞生，是 Python 通用机器学习工具包，得到了全球 1500 多名贡献者的支持。其子模块包括：

- 分类：SVM、近邻、随机森林、逻辑回归等。
- 回归：Lasso、岭回归等。
- 聚类：k 均值、谱聚类等。
- 降维：PCA、特征选择、矩阵分解等。
- 模型选择：网格搜索、交叉验证、度量。
- 预处理：特征提取、标准化。

Scikit-learn 对 Python 成为高效数据科学语言起关键作用。依赖 NumPy、SciPy 和 Matplotlib，先安装这几个库后执行 “pip install scikit-learn” 或下载源码安装即可。
