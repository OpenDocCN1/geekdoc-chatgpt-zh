单图微调：保留场景只改动作

亮点
不用重搭多角色与场景融合的整套管线，能压住AI的随机发散，让人物长相、布景细节与源图保持高度一致，制作时间被明显压缩。

适用范围
手里已有人物加场景的分镜参考，只想调整姿势或互动，不想更换背景和主角。例如已有“女志愿者与奶奶并排坐在沙发上”的分镜，现在想要成“两人依偎坐在一起”的画面。

##### （二）实操步骤（以“女志愿者与奶奶依偎在沙发上”为例）

第一步，导入基准分镜：在ComfyUI空白画布搜索 Load Image 节点，新建一个实例，把此前制作的“女志愿者与奶奶坐在沙发上”的参考分镜上传，确认显示正常。

第二步，补充人像校准：如果参考里奶奶面部不清或与目标形象偏差较大，再新建一个 Load Image 节点，上传奶奶清晰正面照，用于形象对齐。

第三步，图像组合校准：新增 Image Batch 节点。若执行了第二步，把“基础参考图”和“奶奶正面照”两个加载节点分别接入该组合节点，得到组合A，完成人物校准，使奶奶与参考照一致；若未执行第二步，则直接以基础参考图的加载节点作为后续输入。

第四步，绑定生成节点与提示词：新建 OpenAI GPT Image1 节点，将其 Image 口与第三步得到的组合A或基础参考图的加载节点相连。

第五步，接入文本指令：新增 Multi Line Text 节点，与 OpenAI GPT Image1 节点的 String 口相连，输入指令：“女志愿者和奶奶依偎在一起，两张照片中的奶奶是同一个人，场景不变”。

第六步，增加预览：新建 Preview Image 节点，与 OpenAI GPT Image1 节点的 Image 口相连，完成流搭建。

第七步，执行生成与筛选：把 OpenAI GPT Image1 节点的 n 值设为4，挑选最贴合“依偎”姿势且人物保持一致的画面。若细节偏差，优化提示词后重新生成。

##### （三）实操注意事项

参考图挑选：优先选用人物位置、场景布局与目标高度相近的图，相似度越高改图越稳，AI自由发挥概率越低。

提示词侧重：必须强调“人物形象必须保持一致”，并明确点名校准对象如奶奶，避免改图后特征产生细微漂移。

节点精简：若参考图人物已足够清晰，可跳过“补充人像校准”“图像组合校准”两步，直接基于基础参考图改图，效率更高。

#### 二、AI图片去水印的局部重绘工作流

短剧制作中，AI生成的角色照、场景照和分镜常自带平台水印，如豆包水印，会干扰后续图生图、图生视频，导致精度下降，去水印是必要的前置处理。去水印本质是局部重绘，对水印覆盖区进行精准修复，使色彩、纹理与风格与周边融合，实现无痕去除。常用做法有两种。

##### （一）简易去水印方法

满足快速去水印需求，有两种便捷方案。

WPS会员工具：把图片导入WPS，使用会员版“智能消除”功能，用“消除笔”精准涂抹水印区域即可去除。

微信小程序工具：搜索“图片去水印”类小程序，上传图片后用涂抹工具覆盖水印区完成清除。

去水印后可把图片传到DeepSider扩展程序，生成角色多视角图和高清放大图，方便分镜多角度使用。

##### （二）ComfyUI高精度去水印工作流

ComfyUI是模块化的Stable Diffusion节点式界面，通过遮罩与Latent空间操作，能实现水印区域的高精度无痕重绘，具体流程如下。

第一步，新增 Load Image 节点上传待处理图，右键打开遮罩编辑器，用涂抹工具以纯色完整覆盖水印区，完成遮罩绘制。

第二步，新建 Set Latent Noise Mask 节点，连接加载图像节点的遮罩信号，使遮罩与Latent空间关联。

第三步，新建 VAE Encode 节点，同时接入遮罩节点的Latent信号和加载图像的图像信号，完成向Latent空间的转换。

第四步，新建 Dual CLIP Loader 节点，选择flux模型，提供提示词编码能力。

第五步，新建两个 CLIP Text Encode 节点，分别与双CLIP加载器的输出相连，用于输入正向和负向提示词。

第六步，新建 KSampler 节点，分别接入两个编码器的正负条件以及VAE编码节点的VAE输入端。

第七步，新建 Checkpoint Loader Simple 节点，接到K采样器的 Model 输入端，提供模型支持。

第八步，新建 VAE Decode 节点，分别接入K采样器的Latent信号和加载器的VAE信号，还原为可视图像。

第九步，新建 Preview Image 节点，连接VAE解码的图像输出，搭建预览窗口。

第十步，输入正向提示词“Remove white words”，根据水印颜色调整；负向提示词输入“watermark, text, blurry”。

第十一步，点击运行，确认水印被清除且画面自然后保存成图。

### 第四节 抠图法

#### 一、抠图的主要方法

网络获取的人物素材通常背景复杂，即使AI生成定妆照也常带冗余背景。这时需要把人物图导入批量抠图工具，彻底移除背景，只留下纯净的人物主体，为后续场景融合打基础。

人物抠图可借助PS等专业软件，也能用Comfy平台完成。该平台经二次开发后支持本地部署的人物抠图工作流，分为单张和批量两种模式，按需求切换。

单张抠图工作流逐张处理，适合数量少的情况，优势是保留更多人物细节，精度高。

批量抠图工作流可一次处理多张，适合数量多时提效。其中人物批量循环抠图工作流整合了循环、批量、精准抠图和开关判断四大功能，可灵活在单张和批量间切换，操作高效。需要注意，批量模式下细节保留会略低于单张单独处理，可根据需求选择。

#### 二、人物图像背景移除工作流

在Comfy平台搭建背景移除抠图流的操作如下。

第一步，点击空白画布，节点搜索栏输入 Load Image，找到节点后把需要去背景的人物图拖入，完成导入。

第二步，再次在搜索栏输入 Image Background Remove，添加该节点，并把 Load Image 节点的图像信号接到 Image Background Remove 节点的图像输入端口。

第三步，在搜索栏输入 Preview Image，添加该节点，用于实时查看抠图效果。

第四步，点击平台 Run 按钮，启动流程，完成后保存纯人物图，完成背景移除。

### 第五节 换图法

#### 一、角色换装及其工作流

角色换装的核心是通过精准的提示词描述服饰元素，实现同一角色的服装替换，示例提示词：“将图片中人物的服装换为粉色带帽卫衣+灰色运动裤+运动鞋”。该方法用于同一角色在不同场景、不同剧情中的换装，操作前提是准备好角色基础图，通过融合生图模型上传并配合精准提示词即可完成。

在AI短剧制作中，换装可通过多种工具实现，ComfyUI适配度最高、效果最准。其逻辑是借助成熟的AI模型组件，按提示词生成指定服装图，经提取处理、白底优化后结合人物多视角图完成换装，再用手动遮罩保证精准度，最后调整优化到理想效果，具体步骤如下。

##### （一）导入和准备图像

1. 打开ComfyUI主界面，进入空白画布。
2. 双击空白处打开节点搜索栏，输入 load，筛选导入 Load Image 加载图像节点。
3. 点击该节点 upload 按钮，上传需要换装的人物基础图。
4. 重复导入 Load Image 节点，上传提前准备好的目标服装图，完成素材准备。

##### （二）创建服装遮罩

1. 双击空白处搜索 grounding，导入 GroundingDinoSAMSegment 语义分割节点。
2. 继续搜索 sammodel，导入 SAMModelLoader SAM模型加载节点，并与语义分割节点链接。
3. 配置模型参数：在 SAMModelLoader 中按电脑配置选择适配模型；在模型输入框里输入目标服装关键词如“裙子”“卫衣”，确保能精准分割服装区。
4. 链接图像输入：将人物基础图的 Load Image 输出端口接到 GroundingDinoSAMSegment 的图像输入端口，完成遮罩基础配置。

##### （三）配置IP-Adapter

1. 搜索 ipadapter，导入 IPAdapter Advanced IP适配器高级版节点。
2. 搜索 clip，导入 Load CLIP Vision CLIP视觉模型加载节点。
3. 再次搜索 ipadapter，导入 IPAdapter Unified Loader IP适配器统一加载节点。
4. 链接节点：人物基础图的 Load Image 输出接到 IPAdapter Advanced 输入；Load CLIP Vision 与 IPAdapter Unified Loader 的输出分别接到 IPAdapter Advanced 的对应输入。
5. 设置参数：在 IPAdapter Unified Loader 中加载 CLIP-ViT-H-14-laion2B-s32B-b79K.safetensors 和 ip-adapter-plus_sdxl_vit-h.safetensors；在 IPAdapter Advanced 中把 weight_type 设为 style transfer，保证换装风格与人物匹配。

##### （四）生成换装图像

1. 搜索 ksampler，导入 KSampler 潜空间采样器节点。
2. 链接采样器：将 IPAdapter Advanced 输出连接到 KSampler 输入。
3. 配置采样参数：按需调整采样方法和步数，建议步数设20~30步，确保画面清晰。
4. 启动生成：点击ComfyUI的 Run 按钮，系统按配置生成换装后的人物图。

##### （五）修复服装细节

1. 若出现服装模糊或边缘不自然，双击搜索 facedetailer，导入 FaceDetailer 细节修复节点。
2. 链接修复节点：将 KSampler 输出接到 FaceDetailer 输入。
3. 启动修复：点击 Run，自动优化服装细节与边缘过渡，提升质感。

##### （六）保存和导出

生成满意图像后，可添加 Save Image 节点保存。

除ComfyUI外，还可通过其他工具换装。

Stable Diffusion：选用适配生图模型并配置参数，输入角色基础描述和服装细节提示词，切换图生图模式生成，最后用PS微调瑕疵和表情。

剪映：利用AI绘画或特效功能直接替换服装，操作简单，适合快速需求。

ViViD视频虚拟试穿技术：可直接替换视频中人物服装，生成自然换装视频，适配短剧视频阶段。

Animate Anyone：合成角色换装后的动画效果，适配短剧动画角色换装。

#### 二、角色换脸及其工作流

在AI短剧制作中，角色换脸主要用于保证角色形象一致、满足剧情或文化适配，比如分镜阶段调整外貌和动作、替换现有角色、短剧出海时把国内角色换成海外面孔等。目前换脸在复杂场景、多人同框时后期处理难度大，人工修正成本可能高于原制作。

为降低成本可借助ComfyUI搭建系统化换脸工作流，实现自动化优化。具体搭建如下。

1. 加载基础图像：添加 Load Image 节点命名为 加载图像1，上传需被换脸的模特1照片。
2. 配置VAE编码与加载：添加 VAE Encode 节点命名为 VAE编码1，与 加载图像1 链接；添加 VAE Loader 节点命名为 VAE加载器1，与 VAE编码1 链接。
3. 添加面部细节处理节点：添加 DZ_Face_Detailer 节点，与 VAE编码1 的Latent输出链接。
4. 配置VAE解码与预览：添加 VAE Decode 节点命名为 VAE解码1，与 DZ_Face_Detailer 的Latent输出链接；添加 Preview Image 节点命名为 预览图像1，与 VAE解码1 的图像输出链接，并勾选“保存输入图像至ComfyUI输出文件夹”。
5. 添加图像对比节点：添加 Image Compare 节点，将其 图像_B 输入与 VAE解码1 的图像输出链接，用于对比换脸前后。
6. 配置Checkpoint模型：添加 Checkpoint Loader Simple 节点，与 DZ_Face_Detailer 的VAE输入链接。
7. 配置CLIP文本编码：添加2个 CLIP Text Encode 节点，分别与Checkpoint节点的CLIP输出链接，用于输入正面提示词和负面提示词。
8. 配置InstantID高级：添加 Apply InstantID Advanced 节点，将其正负面条件分别与两个CLIP Text Encode输出链接；将Checkpoint节点与VAE解码1的VAE输入链接；将 加载图像1 与 Apply InstantID Advanced 链接。点的 图像_kps 输入端口进行链接。
9. 配置IPAdapterFaceID：添加 Apply IPAdapterFaceID 节点，与 DZ_Face_Detailer 的模型输出链接。
10. 添加遮罩预览：添加 Mask Preview 节点，与 DZ_Face_Detailer 的MASK输出链接，用于查看面部遮罩是否精准。
11. 链接图像对比：将 图像对比 节点的 图像_A 输入与 加载图像1 的图像输出链接，完成对比配置。
12. 加载换脸参考图像：依次添加4个 Load Image 节点，命名为 加载图像2 加载图像3 加载图像4 加载图像5，分别上传用于替换模特1的模特2照片。
13. 配置面部BBox：为四个加载图像分别添加 Face BBox 节点，命名为 面部BBox1~4，并与对应图像节点链接。
14. 配置组合批次：添加3个 Image Batch 节点，命名为 组合批次1~3；将 组合批次1 的图像1、2输入分别与 面部BBox1 面部BBox2 输出链接；组合批次2 的图像1、2输入分别与 面部BBox3 面部BBox4 输出链接；组合批次3 的输入分别与 组合批次1 组合批次2 输出链接。
15. 链接组合批次与换脸节点：将 组合批次3 的图像输出分别与 Apply InstantID Advanced 的图像输入、Apply IPAdapterFaceID 的正面图像输入链接。
16. 添加参考图像预览：添加 Preview Image 节点命名为 预览图像2，与 组合批次3 的图像输出链接，用于预览换脸参考图。
17. 配置面部分析模型：添加 Face Analysis Model 节点，将 面部BBox1~4 节点的面部分析输出均与该节点链接。
