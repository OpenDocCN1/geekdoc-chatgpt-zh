本次需要为四年级孩子讲解鸡兔同笼题型，练习题目为：[头共35个，脚共94只，求鸡兔各多少]。请按下面辅导框架输出：

- 核心概念：用生活化比喻揭示题目本质，可参考把鸡兔换成装有不同轮数的玩具车来类比
- 解法适配：提供两种四年级能理解的思路，排除方程法，优先假设法与抬脚法
- 知识衔接：说明该题与已学内容的关联，例如乘法分配律和两步计算应用题

# 第二步

在上述框架下，产出逐步讲解稿，具体要求如下：

1. 情境引入：选用孩子熟悉的生活场景切入，例如宠物店送货员统计脚数的动画

图表法：引导绘制简易鸡兔图并标注脚数

3. 思维支架：
◎ 引导提问：‘如果全部是鸡会怎样？多出来的脚归谁？’
◎ 误区预警：提前剖析‘用94除以4求鸡数’的错误逻辑
4. 表达技巧：
把‘假设’转化为孩子易懂的指令，每完成一步都以‘你看出什么规律？’提示观察

# 第三步

在原题基础上做拓展训练：

1. 分层练习：
基础档：头10个、脚28只，数字小便于心算

2. 游戏化练习：
角色扮演：孩子扮演鸡兔，家长清点脚数发现矛盾
配对卡片：通过头数卡与脚数卡配对，辨别错误组合
3. 生活迁移：
设计超市购物情境，例如5元面包与3元面包共花费32元

2. 纠正策略：
对类型1：用‘全鸡假设法’做分步动画演示

‘你发现了脚数变化规律，太棒了！再来试试…’
