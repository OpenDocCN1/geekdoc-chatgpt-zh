# 粗排：推荐链路的“减压阀”与“质检官”

在工业级推荐系统的流水线上，粗排坐落于召回与精排中间，承担着承上启下的桥梁职能。召回层聚合多路结果，候选池动辄上万；若直喂精排，不仅算力扛不住，也会拖慢整链路响应。粗排的使命就是**“大漏斗变小漏斗”**——将候选集压缩至百至千量级，在极大缓解精排算力压力的前提下，最大限度守住高价值物品。归根结底，这是一道**计算开销与排序精度的博弈题**。

---

## 4.1 重新审视粗排的定位与战略价值

粗排并非标配组件。长期以来，工业界对它的重视度与技术沉淀，远不及召回与精排。它夹在两者中间，显得有些尴尬。但随业务迭代，矛盾浮现：
*   **召回端**为探索与生态，拼命扩充通道、拉大池子；
*   **精排端**为效果上限，想堆更深的网、更多的参。

**冲突来了：** 海量候选若直冲精排，算力预算直接卡死模型复杂度。于是，粗排应运而生，专司**“预筛”**。

### 粗排的独特坐标系
*   **看向精排**：它是**算力的看门人**，必须轻量、极速；
*   **看向召回**：它是**排序的初筛官**，要有区分度、能打分；
*   **核心差异**：精排拼的是**头部精准度**（Top N 排得准不准）；粗排拼的是**中长尾召回率**（把“最不靠谱”的刷掉，护住真好货不误伤，把挑拣细活留给精排）。

> **一句话总结**：粗排不一定要把最优排第一，但绝不能把最差漏进去。

### 主流技术路线的“双轨制”
按与召回/精排的耦合紧密度，分两派打法：

| 技术路线 | 核心隐喻 | 典型手段 | 优势 | 痛点 |
| :--- | :--- | :--- | :--- | :--- |
| **路线一：统一度量的“后召回”** | **“统一货币兑换器”** | 多路召回分数不可比？用浅层/简单模型把所有候选映射到同一坐标系，再截断。 | 模型轻、推理快、上线灵活、解耦召回 | 表达力有限，效果易触顶 |
| **路线二：精排的“蒸馏压缩版”** | **“精排微缩模型”** | 目标与精排对齐，用知识蒸馏把精排的优质特征、复杂结构“压缩”到粗排。 | 表达力强、精粗一致性高、联动丝滑 | 算力成本倍增，预算内榨干表达力是核心难题 |

### 粗排建模的三次进化史
1.  **非个性化统计期**：物品质量分、热度分、人气预测。靠挖掘、统计归纳出离线静态指标，**不看用户、不看上下文**，胜在极省算力、部署灵活。
2.  **传统机器学习期**：LR、GBDT 登场。**兼顾了个性化表达与低算力**，尤其是 LR 配合 FTRL，还能轻松跑在线学习，是质的飞跃。
3.  **深度学习当道期**：双塔模型（向量内积极速推理）、精排大模型蒸馏。**成为当下主流**，在表达力与延迟间寻找最优解。

### 实战铁律：目标对齐，一致性为王
无论选哪条路，**粗排的优化目标必须与精排看齐**。只有目标一致，精排从粗排拿到的候选集里，Top N 才真的是全局最优。这就是工程上常挂在嘴边的**“精粗排一致性”**。

## 4.2 深度学习接管前的粗排江湖

早期粗排主打**“多路召回融合截断”**：锚定核心业务指标做目标，跑个模型（个性化或非个性化）打分，排序截 Top N 扔给精排。

### 4.2.1 非个性化离线评估模型：给物品发“身份证”

电商、视频、资讯平台都会为全量物品建一套**离线评估体系**，量化“质量”与“受欢迎度”。这套体系不光服务推荐，还能复用到搜索排序、运营筛选等场景，因此通常**独立建模、离线更新**（小时级或 T+1），与推荐主链路解耦。

*   **优点**：线上零推理开销，部署随心所欲；
*   **短板**：感知业务变化滞后、冷启动无力、缺乏个性化。

#### 1. 物品质量分模型：电商的“信用评级体系”
核心逻辑：**多维指标 + 专家规则/统计归纳 = 标准化分数**。用作推荐、搜索的通用底分。

**两大硬指标：**
*   **健壮性**：防刷单、刷好评。不能让单一指标线性拉升总分，要有抗作弊机制。
*   **保序性**：高分低分要拉开差距，在转化、人气等核心指标上显著分层。

**建模三步走：**

| 步骤 | 关键动作 | 电商场景实例 |
| :--- | :--- | :--- |
| **1. 定维度、找因子** | 结合业务拆解影响质量的核心维度 | 售前/售中/售后 + 消费体验/平台治理 → 最终落地 5 维度：<br>转化效果、商品属性、商品售后、店铺人气、店铺服务（详见指标表） |
| **2. 指标预处理** | 去噪、归一、时间衰减、冷门校准 | 借鉴协同过滤预处理套路（详见第 8 章），为融合打基础，同时抑制作弊导致的异常波动 |
| **3. 定权重、融合出分** | 量化指标权重，聚合成最终质量分 | **主观赋权法**：专家经验定档位、定阈值、设惩罚项（见下表）。可解释、落地快，但依赖人工、迭代慢。<br>**客观赋权法**：AHP、熵权法等（详见第 8 章）。 |

**表：基于主观赋权法的质量分设计示例（满分 100）**

| 评判维度 | 权重/分值 | 核心打分/扣分逻辑 |
| :--- | :--- | :--- |
| **转化效果分** | 30 分 | 核心转化指标分 10 档，每档 +3 分 |
| **商品属性分** | 20 分 | 标题/图片不合规各 -10，像素低 -5 |
| **商品售后分** | 10 分 | 好评率<90% 或 退款率>20% → -5 |
| **店铺人气分** | 20 分 | 销量/粉丝综合分 10 档，每档 +2 |
| **店铺服务分** | 20 分 | 好评率<90% 或 退款率>20% → -5 |
| **额外重罚** | - | 标题图片双不合规 -20；店铺好评<80% 且 退款>30% -10 |

#### 2. 物品热度分模型：内容池的“实时人气榜”

式中，$T_t$、$T_{t+1}$ 分别表示物品在 $t$ 和 $t+1$ 时刻的热度；$\alpha$ 代表冷却系数；$\Delta t$ 代表时间步长（按业务取天或小时）；$\Delta T$ 表示交互行为带来的热度增量。每一时刻的变化量，都是自然衰减与交互加热的叠加：新品发布初期，优质内容交互带来的增量远超衰减，热度持续攀升；一段时间后，交互量下降，衰减占主导，热度回落。

有三个关键超参需展开：

1.  **初始热度 $T_0$**：新内容发布的“起跑线”。通常取创作者热度与品类均值的加权平均，或运营人工干预（类似置顶）。
2.  **交互增量 $\Delta T$**：不同时刻交互行为加权求和。**资讯重消费互动（赞/评/转），视频重深度（完播/弹幕），新闻重广度（人数/转发）**。权重可用主观赋权/AHP + A/B 测试迭代。
3.  **冷却系数 $\alpha$**：控制“遗忘曲线”陡峭程度。如期望 15 天从 100 降到 1，$\alpha \approx 0.307$。想热度退得快就调大，慢就调小。

#### 3. 人气预测模型：用“未来眼光”解决冷启动
质量分、热度分靠“后视镜”（历史统计），新品数据不足、置信度低。**人气预测模型换成“前视镜”**——用物品属性+短期观察期表现，预测未来人气。

**电商商品人气预测建模四步法：**

1.  **特征工程（四大视角）**：
    *   物理属性（品牌、品类、价格…）
    *   先验人气（品类/商家历史大盘）
    *   近期业务表现（曝光、浏览、收藏、加购、购买 @ 1/3/7/14/30 天窗口）
    *   上下文（季节、大促、换季节点）

2.  **目标定义：从回归到分类，再到软标签**
    *   直接预测销量？上界不封顶、拟合难、难标准化 → **不可取**。
    *   **Hard Target（硬目标）**：设阈值 $S_0$，预测“周销量 > $S_0$ 的概率”（二分类）。缺点：阈值附近样本区分度丢失（略高略低同为正/负样本）。
    *   **Soft Target（软目标）**：引入温度系数 $T$，用类 Sigmoid 平滑映射，保留销量差异梯度（见下表）。

**表：Soft Target 转化函数设计**

| 实际销量 $S_i$ | 样本类别 | Hard Target | Soft Target $f(S_i)$ |
| :--- | :--- | :--- | :--- |
| $S_i \ge S_0$ | 正样本 | 1 | $\frac{1}{1 + e^{-\frac{S_i - S_0}{T}}} \cdot S_i + 0.001$ |
| $S_i < S_0$ | 负样本 | 0 | （隐含映射至接近 0 区间）|

*   $T$ 越大软化越充分，$T \to 0$ 退化为 Hard Target。
*   **效果**：基准值附近梯度变大、模型更敏感；极值区梯度收敛、抗噪鲁棒。
