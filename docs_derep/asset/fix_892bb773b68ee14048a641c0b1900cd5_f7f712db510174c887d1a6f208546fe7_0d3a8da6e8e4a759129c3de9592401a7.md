# 前言

### 回归常识的科学

我们习惯把科学神化，总想找条捷径一招把所有难题打通。可现实并非如此。每一次前进都是日拱一卒的积累加上种种不确定性的叠加，我们只能见招拆招地解决一个个具体问题。对科学本身也是同样的情形。人们渴望一种万能的办法与工具，让自然规律自动显形，人类坐享其成。这种设想暗藏危险：若真能代我们自动发现规律，那它也就可能取代我们。庆幸也遗憾的是，最终我们会发现，劳您大驾，您还是得亲自上。眼下更现实可行的，是探寻一种能解释“世界为何会是现在这个样子”的工具。若存在平行的地外文明，它也许能回答“他们为何没有比我们强太多”。我们可以随手抛出各种猜测，但那些猜测并不带来进展，因为先辈们一直都是这么做的。经不起检验的想法本质上价值有限，想怎么想都行。现代科学的重要之处在于，我们终于可以用朴素的方式检验哪些想法靠谱、哪些正确、哪些错误，并在其基础上生长出新的想法，逐步搭建起稳定的知识体系。

关于胡适研究《水经注》，有人说是走偏门求捷径。把胡适想小了。我认为胡适是用《水经注》做一个范例，示范如何用现代研究方法做学问。这本书里讲的哥德尔也是这种例子。从两千年前亚里士多德建立系统的理性工具起，人们就察觉到理性逻辑的困境，“说谎者悖论”“这句话是错的”这类表述会让逻辑陷入自洽的死胡同。但直到两千年后，才有人用严谨的理性工具证明这个悖论直指人类理性的灾难，这个人就是哥德尔。从他的工作开始，我们开始意识到用理性工具认识世界所带来的局限。而也从他开始，我们意识到问题比想象中更严重。

糟糕的是，我们这个历史悠久的文明对现代科学的认知出现了断层。

第一个断层是“名教”与经典科学的断层。今天我们虽然看到经典科学有这样那样的问题与未解之谜，但它敢于面对问题、审慎求证的态度是可靠的。而我们这个古老的文明长期带着近乎神秘的知识观。胡适在《名教》一文中承接冯友兰，“名”即文字，“名教”便是崇拜文字的宗教，相信写下的字像符箓一样有力量。很长一段时间里，做学问求知识就像巫师一样创造新名词、念咒式地理解新知识，听众往往也就满足了，囫囵拿去自己演绎。这种心态对现代科学的传播毫无助益，甚至打着科学的旗号行反科学之实。降维打击、混沌大学、奇点理论、未来简史以及所谓人类 3.0莫不如此，它们能有广泛受众，与“名教”与现代科学的断层有关，是这个文明尚未进入实证阶段的体现。钱钟书在《围城》里对这种怪象有个经典总结：喝着咖啡聊梅毒。

胡适那一代人为这个文明的现代化艰难努力的同时，人类对世界的科学认知已跨过第二个断层。20 世纪初，在人们以为物理和数学正凯歌高奏走向认识宇宙与人自身终极胜利的时候，量子力学与哥德尔不完备定理几乎在同一时间告诉我们人类认知的有限：要认识宇宙和人类自己，前路还很长很长，甚至可能根本没有终点。这也许同时在告诉我们，为什么感性的认知总是存在，为什么人类把认知统一到同一标准下的努力至今都还没成功，以及为什么这几千年来人们对真理的追求似乎总差那么一点点，而每次又正是这一点点把我们引向一个全然的新世界。这也解释了为什么 20 世纪初美国教育家、哲学家杜威和胡适所主张的务实主义具有合理性。但敌人的敌人未必是你的朋友，虽然新的理论解释了经典认知的不足，但它绝不是肯定古代神学和“名教”存在的意义，它是一个完全不同的新世界。

人工智能是这里的一个例子。严格说，人类先发现了它做不了的事，而后才发明了它。图灵 1936 年的那篇著名论文是对哥德尔不完备定理的物理化诠释，他提出了一个更简明且物理上可实现的机械装置来完成数学的逻辑推演，并在文中指出了哪些问题是图灵机做不了的，以此来拓展哥德尔的不完备定理证明。但图灵机是如此的强大和成功，那些“它做不了的事情”很快就被淹没在故纸堆里，而那里，正埋着我们应对人工智能局限的钥匙。

哥德尔的被遗忘，是现代科研游戏规则的直接后果。一个不申请经费、没有徒子徒孙的学问，如何能影响深远、众人周知呢？在今天的科研环境下，绝无可能。而不用申请经费也不用带学生正是普林斯顿高等研究院对第一批研究员的放纵。作为这些人中的两个典型代表，爱因斯坦和哥德尔是天真地相信了。在全球最近几十年以论文发表量来衡量学术工作是否有价值，学者是否有地位的评价体系下，即使哥德尔这样一个开辟了一个领域的大神，他的思想也是难以存活和传播的。他和他的好友爱因斯坦，像堂吉诃德一般成为科学殿堂里最后的骑士了。

于是我觉得我应该写一些文字，向这些人类历史上的伟大思考者致敬。尽管我自己对这门学问的认知还有很多的不成熟之处，但至少我希望它可以安抚我们面对未来的焦虑之心。当能够回溯认知的常识时，我们会发现竟然可以有更加平和的理解世界的态度。学问之道无他，求其放心而已矣。

燕园、清华园和伊河边上的小城牛津，我在象牙塔里进进出出，结识了很多好玩的人。光说姓李的，就有给我机会初试科研的李政道先生，有塑造我务实主义信条的李敖先生，有让我感受到音乐创造魅力的大哥李宗盛。跟越多的人交往，我越感觉到人类的可爱和伟大，这么好的世界，我们怎么忍心交给机器呢？

# 第一章

知无不言

[PRE9]

人工智能不能做什么？如果一本书在第一章就把答案说明白，就不好卖了。既然有整本书去写，就不妨慢慢来，至少要说清楚我们使用怎样的工具，才能得出怎样的结论。当我们这样做的时候，会发现这工具似乎并不可靠，于是只好继续讨论什么是可靠性。这至少能理清什么是有效的思维工具，也就是理性。

我所追求的全部知识，都更充分地证明我的无知是无限的。

——卡尔·波普

2018 年 3 月 20 日下午，我在台北街头的一家咖啡馆写下了这些文字：

近来很少写字，因为写作变得困难。哥德尔告诉你这也不能写那也不能写，在动笔前不免要先想这句话合不合逻辑。人常会被自己学的东西困住，定义了“定义”自己，那谁来影响“影响”呢？

雨后初晴，透过小店的窗能看见傍晚的阳光洒在街边的小树上，也被骑电动车的骑手头盔反射回来。骑楼柱子后面应该有人在抽烟，看不到人，却能看到那个高度从柱后飘出的白烟。我不得不加快喝完一杯味道还不错的淡奶茶。不得不说味道真不错，但师弟要过来，他不喜欢这家店，因为老板不喜欢。

阳光又斜了五度。师弟还没来，奶茶喝了一半，厚厚的泡沫看不出到底还要几口。点了一份千层蛋糕，味道很清淡，肉桂粉在碟子里撒出某种符号的样子。师弟说老板不喜欢这家店，是因为这是一家西藏店。我又看了看那图案，还真是。

旁边两个女孩在喝咖啡和果汁，聊着八卦。似乎是关于人扮成上流社会有多费劲，然后是女婿和岳母之间的微妙关系。

吧台后面四个店员在忙碌。虽然店里没什么人，总共四个顾客，包括正在打字的、不知道什么时候要离开的我。但他们似乎真的很忙，各有事做。一辆白色的车路边停着，双闪亮着。哦，不，两辆。我尽量描写眼前看到的东西，才发现其实少了时间这个维度。有车从窗外经过，店员走过来轻声说，“帮您加个水”。

一辆自行车是诡异的绿色。

阳光又斜了几度。店面已经打开霓虹灯，不是五颜六色的那种，是明亮的黄绿色，隔壁一家是深蓝色。

哥德尔说我永远也没法完整描述此刻的所有感受，即便我努力记录。

这是一条老板每天散步的路。在路边的一家咖啡店，我喝着一杯淡淡的奶茶，写着描述不了什么的字，而两天前他不在了。

作为人类，我们使用各种工具。也因为日常使用，我们常忽略工具本身的可靠性。比如我们可以花点时间了解一下人们每天都在用的语言。

人类语言很神奇。你可以通过语法理解字面意思，通过说话人的态度揣测内心想法。人们可以用同样的文字表达不同的内涵，有时沟通并不纠结于文字本身，面对面交流充斥着各种无法被词语编码的信息。语气、抑扬顿挫、眼神、味道和背景音乐，这些游离在词语之外的信息同样在传递交流时的内涵和情绪。

但我们仍用这些丢失了很多含义、残缺的语言，去进行对我们人类来说最至关重要的行为——沟通。因为残缺有时会带来误解，于是我们希望创造一个没有歧义的语言系统。在这样的系统之上可以更客观准确地交流。事实上，这本书要告诉我们这件事做不到。用天生不完美的工具人类依然能够彼此沟通是个逻辑的奇迹。我们可能最终依赖的是通过奇迹般的沟通而达成的信任，人和人可以原谅彼此，甚至因为理解沟通的缺陷而有了温情。这种温情，你从机器那里得不到，从法律条文里得不到，从敌人那里也得不到。但写到最后一句时，我觉得未必，你的敌人也是人群中的一部分。对手之间的惺惺相惜，往往成就历史佳话。但人类并不死心，我们试图用更多数据来还原这些场景，用录音还原语气，用影像还原表情和手势，来弥补文字的不足。

## 语言是可以理解的吗？

大多数人类语言通过声音传递，词汇表现为声频和强度的组合。语言里总有一些词出现的频次远高于别的词，即使不懂这种语言，对特定音频和强度组合出现的频率做统计，也能判断它是不是一个有意义的语言系统。比如中文里“的”字出现频率很高，其他字相对较少。当一种语言表达能力充分时，常用词的使用频率是递减的。不会出现某个音频和强度组合孤立地非常高，而其他又很低的情况。这样，仅凭词汇出现频率的统计就能判断一系列声音信号是否代表有意义的语言。这个原理我们称为齐普夫定律，近些年动物学家也用它来研究海豚的语言。

最早的动物语言研究是想了解动物间如何交流，人们尝试教给动物人类的语言，看它们是否能与我们交流。这样做的弊端在于，这个过程中人类很难学到动物语言。牧羊犬可以学会超过 1000 个人类单词，但人们能从狗身上学到多少狗的单词呢？到目前为止，人类总是试图通过教动物说人话来理解动物语言。然而跨物种交流有明显困难，想想我们学一门外语有多难，何况跨物种呢？

##### 图 1–1 齐普夫定律

今天人类的语言是从七万年前一支走出非洲的智人那里继承下来的。对比同时期的其他人类，这一支人群有着发达的声音语言系统。这种系统的基础是口腔、舌头和喉部的独特生理结构。这样的结构甚至连我们近亲猩猩都没有，更别说其他动物，它们根本没有能力发出人类复杂多变的语音。在研究用对方的语言与动物交流的过程中，人类不得不创造一些辅助工具，因为任何一端都无法直接用天然的生理结构复制对方的声音。学习海豚的语言就有这个问题，海豚叫声的超高音和鲸的超低音都超出了人类的听觉范围。海豚说不出人类的任何语言，而我们也不会吹超声波口哨。

借助齐普夫定律，人们在搜集了大量海豚叫声之后发现这些叫声确实在传递特定信息，而且是一种相当丰富的语言，能够让海豚之间进行复杂的交流，借助于人工智能技术人们甚至可以确定一部分海豚叫声所代表的具体含义。配合适当的演奏设备，人们甚至可以模仿这些声音，这使科学家和海洋生物之间实现信息的双向流动成为可能。如果真的可以理解足够多的海豚语言，人类对动物研究的现状将大大改善。海豚语言研究的成功可能使研究人员设计出与其他智慧生物交流的工具。不难想象，未来甚至会出现动物语言翻译设备。这项研究还有另外一个用处。当我们用射电望远镜瞄向遥远太空的时候，会接收到一些来自太空深处的无线电信号。如果恰好有外星人像我们一样可以看电视、听广播，他们扩散到太空中的无线电信号就会被我们接收到。这些信号有可能像自然语言一样由高频使用和低频使用的词汇组成，而我们可以翻译它。事实上，二战时的艾伦·图灵就通过类似的方法破译了德军的密码。如果我们接收到来自太空的无线电信号，并且判定它是否符合齐普夫定律，我们就可以知道发出这些无线电信号的宇宙深处是否有像我们一样的高等生物，甚至可以知道他们每天看的电视节目在说什么。

## 语言是可靠的吗？

描述一个真理，至少在描述本身上需要依靠语言。但语言可靠吗？如果不可靠，它的缺陷是可以避免的吗？

《论语》里说：“学而时习之，不亦说乎。”小时候课本上的解释是：学东西要时常拿出来复习复习，不是也很快乐吗？我一直怀疑这快乐的真实感。因为这种“学习的快乐”是课本灌输给我的，我小时候并不具有。“纳粹头子”戈培尔有句名言：“重复是一种力量，谎言重复一百次就会成为真理。”于是，在熟读百遍之后，我真的以为我有了快感。

后来长大了，学会了繁体字，才知道原来这个“习”字可以不这么写，繁体写作“習”。“羽”当作小鸟的翅膀，而“白”是指太阳。组合在一起可以解释为小鸟努力在天上学飞行。引申来讲，就是实践。学会了理论，要出去操演操演、实践实践，这样才能巩固，才能知行合一。纸上得来终觉浅，绝知此事要躬行。孔子讲的是做学问的方法。只有这样，放在《论语》的开篇才有意义。然而，我还是没有找到到底快乐在哪里。

到了人书俱老的时候，又想到了一个新的解释。这个“习”呢，不一定是学完了马上操练，可以是很久很久以后。“功不唐捐”是胡适晚年特别喜欢写给别人的题字。以前学的东西，很久很久以后在哪儿碰到了，拿出来用一用给旁人看，这个似乎才有别样的乐趣。学过，偶尔拿出来显摆一下，嘚瑟嘚瑟，收获一种倚老卖老的得意。

这些年我做新工科教育，希望培养与人工智能共存的新工程师。希望新的人才既懂得数字技术，又能动手做东西，所谓学而时习之，培养既能动脑又能动手的新型工程人才，此乃大快乐也。

然而这样就让我们产生了困惑：当我们说一句话的时候，这句话到底是什么意思？

#### 道可道非常道

语言是表达意义的工具。人类对于文字的敬畏可以追溯到很久以前，但古人也很早就认识到了自然语言的“不完美”。老子说“道常无名”，孔子也认为“书不尽言，言不尽意”，陆机在《文赋》中称“意不称物，文不逮意”。

但是老子的说法“知者不言，言者不知”，本身却是个悖论。而这个悖论都不是今天才被指出来的。白居易在《读老子》里说：“言者不如知者默，此语吾闻于老君。若道老君是知者，缘何自著五千文？”善言者不如智者善于沉默，这话是老子说的。如果老子真是“智者”的话，他干嘛还要写五千个字的《道德经》呢？

还没完。我们先不要管语言这么复杂的事情，一步一步来，先从定义一个关于某事物的名词开始。

### 如何定义事物？

#### 忒修斯之船（The Ship of Theseus）

在希腊传说中，英雄忒修斯与雅典战士们从克里特岛回到雅典，他们的船被雅典人保留下来作为纪念。随着时间推移船上的木材开始腐朽，雅典人便用新的木头来替换那些腐烂的木头。最后，船上的每根木头都被换过了。问题是，最终的这艘船是否还是原来的那艘忒修斯之船，抑或是一艘完全不同的船？如果不是原来的船，那么在什么时候它不再是原来的船了？

我们还可以对此问题进行延伸：如果用忒修斯之船上取下来的老部件来建造一艘新船，那么两艘船中哪艘才是真正的忒修斯之船？

这样的讨论同样适用于人类。人体每天都在进行新陈代谢，这样隔过一阵子组成身体细胞的全部原子都会被换掉，那么我们还是原来那个自己吗？如果不是，什么时候不是的？

当然，我们可以举出从精神、意志、社会关系等方面对个人的定义来说明，单纯依靠物理的实体来定义像人一样复杂的事物是不合适的，但对船而言呢？对花花草草而言呢？对猫猫狗狗而言呢？对猩猩猴子而言呢？接着就是复杂一点的人类了，这些物种之间什么时候产生了界限呢？

于是我翻开了词典。为了权威性，我翻开了《牛津英语词典》，为了避免翻译的误差，我翻开了英文版的。

### 词的互相定义

BOX，container made of wood, cardboard, metal, etc. with a flat base and use a lid, for holding solids.

我总要看看 container 是什么意思。

CONTAINER, box, bottle, etc. in which sth is kept, transported, etc.

这明显的是在用 container 来解释 box，用 box 来解释 container。看来，或者说至少，如果通过词典来定义我们说的每一个词，并试图以此理解人类的语言是有些问题的。到底这些语言有什么意义呢？它们完全可以是一些互相替代的符号。由此可见，理解一本词典，需要词典之外的常识。这些常识，来源于我们的生活、文化、教育，而不只是文字本身。常识的建立，可以通过大数据来实现吗？如果可以，那么到底要多少知识，才能构成人类交流的常识？事实上，人类的生活中存在很多默认的知识，但深究下去，为什么用这个，为什么这么用，我们并不十分清楚，但我们在交流中毫无障碍地用到了它们。
