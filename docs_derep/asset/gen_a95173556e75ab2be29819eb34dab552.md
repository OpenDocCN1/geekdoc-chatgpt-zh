流式生成核心机制

Rectified Flow Generation 是一种以 Flow Matching 为理论基础的图像生成范式，能够在现有的大语言模型体系内完成训练，不需要额外搭建复杂的子网络。其本质是借助常微分方程对图像进行逐步递归推演，从而在保持生成质量的同时大幅提升采样效率。

3. 解耦式编码器设计

JanusFlow 为理解与生成两条路径配备了各自独立的视觉编码器，来降低两类任务间的相互干扰。

● 理解任务编码器 Vision Understanding Encoder, f[enc]：选用 SigLIP-Large-Patch/16 预训练权重，专注于语义级特征抽取。
● 生成任务编码器 Generation Encoder, g[enc]：基于 ConvNeXt 架构构建，独立承担生成侧的表征学习。
● 生成解码器 Generation Decoder, g[dec]：把潜变量映射回像素空间，得到最终图像输出。

4. 三阶段训练策略

JanusFlow 采用分阶段训练，同时优化自回归模型与 Rectified Flow 生成部分。

阶段 1：适配期
对新加入的生成编码器、解码器以及线性变换层进行训练，使其与预训练的 LLM 与 SigLIP 编码器相匹配。

阶段 2：统一预训练
在海量语料上做端到端优化，数据构成包括视觉语言数据 Vision-Language Data、文本到图像配对 Text-to-Image Pairs 以及纯文本数据 Text-Only Data。

阶段 3：监督微调
借助高质量指令微调数据 Instruction Tuning Data，强化模型在对话、问答、文本绘图等任务上的指令遵循能力。

5. 实验结果

（1）多模态理解表现
在 POPE、VQAv2、GQA、MMBench 等多个视觉理解基准上，JanusFlow 的成绩超过了现有多模态模型，在文本图像对齐与复杂视觉推理上优势明显。

（2）文本到图像生成表现
● 在 GenEval 与 DPG-Bench 评测中，JanusFlow 的表现优于 SDXL 与 DALL·E 2 等专用生成模型。
● 在 MJHQ FID-30k 评测里，参数规模为 1.3B 的 JanusFlow 取得 9.51 的 FID 分数，优于同规模的 Janus 10.10 FID 与 Show-o 15.18 FID。
● 在语义一致性 Semantic Consistency 方面，颜色匹配、物体关系等细节点上得分较高。

总体来看，JanusFlow 通过自回归 LLM 与 Rectified Flow 生成的结合，在理解与生成两端均达到领先水平。任务解耦设计、三阶段训练配合表示对齐正则化，使其在同类方案中脱颖而出，为统一高效的多模态研究提供了新思路。
