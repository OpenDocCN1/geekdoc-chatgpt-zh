挖掘暗线因果：相关性与方差分析的实战用法

相关性分析的真正价值在于帮你找到经验覆盖不到的隐性关联。凭直觉我们往往能揪出几组看似相关的量，但真正起决定性作用的联系，很多时候肉眼根本捕捉不到。

这套思路的覆盖面很宽，既可以用在互联网产品，也能用在传统行业和线下场景。基本可以兼容所有业务量：取值连续的量、取值离散的量、以及带有顺序的离散量，后者常被叫做带权离散量。

######## 连续型指标

连续型量指的是数轴上可以无限细分、等距分布的数据，理论上看成无限集合也行。举个例子，App使用时长以秒计，0到几百秒之间任意取值；次日留存率在0%到100%区间内连续变化。日常里常见的还有新增用户数、DAU、转化率、点击率等。

这类量主要用来刻画业务的持续演进和趋势走向。对它们做关联，本质上是在找随趋势同步移动的方向与强度，是最普遍的分析形态。

######## 离散型指标

离散型量的取值集合是有限且可以穷举的。按形态可分为二分量和无序离散量。二分量只有两种可能，比如性别、是否VIP、图标是否显示角标等。无序离散量取值超过两种，各取值之间没有高低之分，比如画像里的年龄带【10~20岁少年、21~30岁青年】、设备品牌如小米华为、系统类型如iOS Android WP等。

这类量描述的是有限的状态集合，每个状态平级，常用来研究年龄、地域、设备、使用时段等画像特征的关联。

要特别注意，无序离散量要求各区间的跨度保持一致，必须满足等距约束。不合理的划分例如少年10~18岁、青年21~30岁就不合规，前者跨9年后者跨10年。

######## 有序离散型指标

有序离散量在形式上接近离散量，但每个取值都带有明确的先后顺序或业务权重。典型例子是满意度：非常满意、满意、一般、不满意，按此递减。它同样必须遵守等距约束。

其他例子包括偏好类型如内容签到打卡、城市梯队如一线二线三线、活跃频次如每日打开3次5次7次9次等。

可以把有序离散理解为给无序离散加上权重并按权重排序，目的在于让关联结论对业务决策更有指导价值。

####### 2. 具体方法

根据前三种量形态，两两组合即可得到三种常用关联算法：Pearson相关分析、Spearman相关分析、卡方检验。

######## 连续型指标和连续型指标：Pearson相关性分析

该方法可用于判断商品曝光量与购买转化率是否同向变动，两者均为连续量。输出的是Pearson相关系数，通常记为R。

R衡量的是两个量之间线性关系的紧密程度。使用前需满足两个前提：数据近似正态分布；两组观测一一对应。异常点对系数影响极大，必要时应先剔除再计算。

R取值范围为-1到+1。正值表示同向变动，负值表示反向变动。
- R为正时：0至0.3视为无关联，0.3至0.5弱关联，0.5至0.7中等关联，高于0.7强关联。
- R为负时：-0.3至0视为无关联，-0.5至-0.3弱关联，-0.7至-0.5中等关联，低于-0.7强关联。

R能否代表总体关系，还需要做显著性检验，通常用t检验。

在实务中，很多业务量既连续又近似正态，Pearson使用频率最高。例如分析不同操作系统的次日留存对整体留存的贡献、短视频各频道活跃度对整体活跃的拉动、投放周期与营销效果的关系等。

######## 有序离散型指标和连续型指标：Spearman相关性分析

该方法可用于评估商品评分与购买转化率的关联。商品评分通常为五星制，属于有序离散量，购买转化率是连续量。输出的是Spearman相关系数，通常记为Rs。

Rs同样落在-1到+1区间。正值表示趋势一致，负值表示趋势相反，强弱分级标准与Pearson一致：
- Rs为正时：0~0.3无关联，0.3~0.5弱关联，0.5~0.7中等关联，>0.7强关联。
- Rs为负时：-0.3~0无关联，-0.5~-0.3弱关联，-0.7~-0.5中等关联，<-0.7强关联。

在用户画像场景里，很多画像特征是有序离散且不服从正态分布，此时Spearman更合适。例如分析用户年龄段与活跃等级的关系，年龄段是有序离散，认知能力随年龄递减；活跃等级也有序递增，打开次数越多偏好越强。

######## 无序离散型指标和无序离散型指标：卡方检验

该方法可用于探测用户性别与购买偏好的关联，例如男性是否更倾向电子产品、女性是否更倾向化妆品。两端均为无序离散量，输出卡方统计量常用χ²表示。

使用前提包括：数据为分类数据且各类别样本不宜过少；样本为随机抽取；类别组合中不出现完全缺失，每个格子至少有一个观测值。

χ²衡量观察频数与期望频数的偏离程度，数值越大偏离越大，关联越强。当χ²超过基于显著性水平如α=0.05的临界值时，可认为两类变量存在关联。

在业务中，分类型量很常见，例如不同年龄段对产品类别的偏好差异、不同地区用户对服务满意度的差异等，都常用卡方检验。

###### 4.1.2 评判策略的效果：方差分析

####### 1. 基础概念

方差分析用于研究不同因素对观察变量的影响大小，通过比较组间差异来判断哪些因素带来显著影响。它能帮助决策者明确推动业绩的关键驱动。

在策略评估中，方差分析可以识别哪些因素真正推动业绩。例如对比不同市场、产品或渠道的业绩表现，判断哪种打法更有效。方差分析主要分三种：单因素方差分析、无重复双因素方差分析、有重复双因素方差分析。

######## 单因素方差分析

单因素方差分析检验单一因素的多个水平对结果的影响，核心是比较各组均值差异。

提示
什么是因素？什么是水平？
因素是实验中主动干预或观察的变量。研究网页设计对停留时间的影响，网页设计就是因素。
水平是因素的具体取值，如设计A、设计B、设计C。

例如比较三种教学方法A、B、C对90名学生的成绩影响，每组30人，平均分分别为80、85、90。不能仅凭均值判断C最好，可能受随机波动影响。单因素方差分析可判断三组成绩是否存在显著差异。

######## 无重复双因素方差分析

该方法同时考察两个因素对结果的影响，把两个因素的水平组合成二维试验设计，再比较各组合均值差异。适用于两个因素独立且互不干扰的场景。

例如研究年龄段与性别对产品喜爱度的影响，判断偏好差异更受年龄还是性别驱动。

######## 有重复双因素方差分析

与无重复形式类似，也考察两个因素的影响，但允许水平间重复，适用于因素间存在交互作用或相互影响的情境。也称有交互作用的双因素方差分析。

提示
方差分析对数据质量有要求，主要包括正态性、数据来自同一总体、随机抽样。

######### 稳健性
大样本时中心极限定理会削弱正态性要求，小样本时正态性更关键。若严重偏离正态，方差估计可能失真，影响检验结果。

######### 保证统计效力
数据来自同一总体或随机抽样时，结果更可靠。否则容易提高第一类错误，即错误拒绝原假设。

######### 提高统计结果的解释力
满足前提时，均值和标准差更能准确描述分布，结论解释更清晰。

提示
实践中数据很难完全正态。若峰度绝对值小于10且偏度绝对值小于3，或正态图呈钟形，通常可使用方差分析。方差分析对偏态和峰态不敏感，尤其在样本量大时。若峰度大于10或偏度大于3，建议改用非参数检验。

####### 2. 分析流程

######## 单因素方差分析

流程分三步：验证前提、计算F检验值、判断显著性。

######### 第一步：验证是否符合前提条件
按上述要求检验数据。

######### 第二步：计算F检验值
计算F值和F临界值，F值是检验统计量，F临界值是基线。

######### 第三步：判断差异显著性
若F大于F临界值，则组间差异显著；若F小于F临界值，则差异不显著。若显著，可计算效应强度R²=组间SS/总计SS，用以衡量显著程度。
