# 从符号操作到脑启发计算

听起来像自负，却无法否认麦卡锡和明斯基在该领域的影响力。二人共同创办了麻省理工的智能研究项目，后演变为麻省理工智能实验室。明斯基1961年发表的宣言《迈向人工智能》把符号运算确立为机器智能的基石，为随后半个多世纪的研究划定了方向。 ^(⁶⁵)

1970年到20世纪80年代中期被称作第一次智能低谷的时期，联结式计算几乎被搁置，不再用于解决模式识别、预测或学习新表征等任务。连接主义者退守，同时目睹神经科学的爆发式进展，尤其是哺乳动物视觉系统的功能组织、神经元放电与突触化学传递。算力呈爆炸式增长重塑了实验室和产业的边界。更关键却也出人意料的是，算力和存储的提升拉动了数据的指数级膨胀。这些力量叠加，为联结系统的复兴搭好了舞台，也让机器学习逐渐成为主导机器智能的主要力量。

## 从神经元、猫的大脑到联结系统

哺乳动物大脑的结构与认知能力长期为智能研究提供灵感，如今更成了技术评估的标准。定义现代计算的冯·诺依曼和图灵，都从神经连接中获得网络模型的启发。神经系统尤其是视觉信息处理的方式与原则，对当代技术贡献重大。然而单个神经元的复杂性，更不用说数千、数十亿单元构成的网络，要窥见大脑终极奥秘极其困难。我们能在眨眼后数十毫秒认出花朵，这种识别以及“花朵”意识的来源与形成仍是谜。由于对脑行为模式理解不足，部分人质疑基于神经生物学的机器智能。没有完整把握脑运行规律，就难以用计算机或数学模型模拟类似神经认知的过程。尽管如此，自然已进化出这种智能装置，即使存在缺陷也不适合工厂化量产，许多重要灵感仍源于此——用概率与统计方法建模神经元群体如何处理感觉信息。这与自顶向下的逻辑和符号操作截然不同。

早期机器智能中，罗森布拉特等联结系统的支持者先模拟单个简易神经元，后尝试对视觉系统部分功能建模。为何从视觉入手？大脑接收的感知通道各不相同，包括光、味、嗅、声、痛、热、触、平衡和本体感觉。承担重要感觉的感受器多集中在特定部位，例如光感受器在眼、化学感受器在鼻口、机械感受器在耳肤，其余遍布全身以感知本体感觉、温度和疼痛。视觉信息带有空间属性，只能由视网膜上按特定分布排列的感受野捕获。听觉信号的三维捕获与体感的二维捕获同样关键，对几乎所有感官而言时间都是重要维度。其中视觉研究最直观，因为感知与看见紧密相连。

由此可知视觉感官数据更容易采集解读，且特征丰富多样，涵盖对比度、边缘、深度、方向、轮廓和纹理。来自视觉神经生理学的实验数据可用于更新建模策略并检验结果。研究视觉的另一优势在于，计算机视觉所需的装置兼具科研、军事和商业用途。光学和投影系统处理光信号相对容易。正如罗森布拉特在Mark I感知机上的尝试，我们可以专门制造一台带摄像头的机器作为人造视网膜。

视觉在生物学上极其复杂，但掌握感受野、聚合与特征提取器等概念，理解感官信息从视网膜到初级视皮质再到高层皮质的层级处理流程，就把握了启发联结系统设计的核心思想。这些通路中绝大多数存在反馈或相互联系，后续章节会展开讨论。智能先驱们虽已知晓库夫勒、巴洛和哈特兰发现的感受野特性，却并不清楚大脑的层级处理方式与特征提取能力。不过20世纪70年代末到80年代出现的首批联结模型，已包含这些基本概念。

### 视网膜中的视觉信息加工

・哺乳动物视网膜后部的感光细胞可捕捉光子并将其能量转成电信号输出。
・视网膜内部的并行神经通道对信息进一步加工，最终由每只眼睛约120万个视网膜神经节细胞将结果送往大脑，该数值对应人体。
・视网膜神经节细胞以脉冲电位形式传递信号，并通过发放频率及脉冲序列的其他参数编码所感知的信息。
・视网膜神经节细胞的感受野以高度冗余的方式铺满整个视野，超过20种不同类型接收上游并行通道的输入。
・在某些条件下视网膜神经节细胞可扮演像素编码器，直接把原始像素数据送入大脑，例如中央凹中视锥细胞与神经节细胞呈1∶1对应时。
・大多数视网膜神经节细胞的感受野是信息聚合的产物，多对一映射形成比单个感光细胞更大的视野范围。随着信号向皮质传递，感受野持续聚合，表征也变得更抽象，对应更广的视野。
・视网膜神经节细胞也是特征探测器，其感受野的中心—周边拮抗特性赋予了边缘和方向的选择性。

在人类及其他灵长类中，超过三成的大脑皮质参与视觉与高级感知处理，凸显其对行为与生存的重要性。视觉信息由视网膜神经节细胞轴突经视神经送至下丘脑外侧膝状体核的神经元，再投射至后脑的视觉加工区V1，即视皮质层级处理的起始阶段。在V1，视觉场的神经表征相对外侧膝状体核输入扩大了两个数量级。通过研究猫初级视皮质V1的感受野，胡贝尔与威塞尔首次揭示皮质神经元偏好对边缘、方向性条纹刺激反应而非光点。依据对简单视觉刺激的不同反应，他们把皮质细胞分为简单细胞与复杂细胞。这些实验表明视皮质对输入信号进行了转换。借助局部网络输入的整合，神经元可编码方向、方向选择性、空间频率和双眼性等属性。这一假说对后续模型如新认知机的发展起到关键推动作用 ^(⁶⁷)

## 机器智能与深度学习的突破

只有一条证据能让我们相信机器智能能解决一个难题：通过进化，自然已经解决了它。

——特伦斯·谢诺夫斯基
《深度学习》

本书聚焦机器智能在生物医药领域的当下与未来应用。当下所谈的机器智能主要指机器学习。数据科学家与机器学习工程师设计算法处理数据、进行预测，并从计算机科学、统计学、认知科学等领域汲取技术。机器学习在药物开发中表现强劲，因其可借鉴各科学与工业领域的建模技术，避免重复造轮子。

联结系统亦然。20世纪80年代末，金融行业率先在商业应用中秘密使用神经网络与算法。算法交易深刻影响了金融市场，并改变了对冲基金、银行与柜台交易员的盈利能力。到2017年，量化对冲基金占据美国股票交易量的27%。20世纪90年代，大型企业迅速采用机器学习工具，利用海量数据库进行信用分析、欺诈检测与营销。在深度学习相关技术出现前，机器学习方法已在工业界广泛应用，从供应链预测到消费者行为分析，为后来的推荐系统奠定基础。1990到2010年的信息革命推动了机器学习模型与训练范式的完善，以及以GPU为代表的更强计算硬件的普及。

为适应海量数据集，机器学习方法日益复杂。部署这些方法使亚马逊等电商巨头主导零售业，也帮助谷歌与脸书基于社交网络数据挖掘投放广告。基于人工神经网络的深度学习在众多行业展现广泛应用。需要讨论深度学习为何能解决如此多问题，其背后的基本非数学逻辑。本书结尾的推荐阅读列举了多部权威著作与科学评论。

神经网络既是计算机器，也是分析工具。其核心优势在于对非线性现象建模，例如天气、股价、药物—靶标相互作用以及化学与生物学中的相变。神经网络设计灵活，部分最成功的模型模仿大脑中运行的神经网络。人工神经网络处理信息的第一步是利用节点即神经元模拟高度互联的结构。图2—6显示了神经网络的基本结构，即无隐藏层的感知器。在多隐藏层全连接的前馈网络中，信息单向流动，计算可支撑强分类器构建，输入层神经元数值只是简单初始数据，如实验数据点或房价。

### 神经网络信息处理基础

如图2—6所示，所有输入最终汇聚到同一输出神经元，输出值由输入与边权值相乘求和得到。激活函数的引入是另一重要特征。求和后的输入需经非线性函数修正才能得到最终输出。非线性函数可以是tanh(x)或S形函数如exp(x)/[exp(x)+1]。因此人工神经元可视为简单加权分类器叠加输出修正用的压缩函数。若输入数据存在线性不可分类别，则在输入与输出单元间插入非线性转换层至关重要。该流程与生物神经元运行相似，神经元活性取决于相邻突触前输入总和的函数。尽管网络只是高度简化版本，却异常有效。无论生物还是人工神经网络，其学习能力关键都在于改变突触输入即边的权重。

### 专家系统与机器学习的兴起

20世纪70年代，明斯基与佩珀特出版的《感知机》将单层神经网络描绘得一无是处，引发了首个人工智能寒冬。与此同时符号机器智能仍是主导范式。70年代到80年代，专家系统兴起。人们将精心设计的规则、知识或启发式方法写入程序，由程序分析输入数据执行任务并生成答案。这些系统在特定任务上表现良好，却不具备泛化能力，即为某一任务设计的系统无法直接用于新问题。生物学与医学领域的专家系统有斯坦福大学开发的用于临床诊断决策的INTERNIST、用于根据质谱数据确定有机化合物结构的Dendral，以及用于分子生物学的MOLGEN程序。开发者之一的定义如下：

“专家系统”是一种智能计算机程序，它使用知识和推理过程来解决需要大量人类专业知识的复杂问题，其所需知识水平与推理能力可与相关领域顶级从业者相媲美。

——爱德华·费根鲍姆
《20世纪80年代的专家系统》

与此同时，另一种机器智能方法复兴。认为机器可从大量经验中学习规则解决各类问题。其基本思想是设计系统接收输入数据与答案或标签，通过学习算法发现输入与答案间的对应规律。在机器学习范式中，系统通过训练而非显式编程实现输入到输出的映射。学习过程不涉及符号逻辑或层次决策树，而是采用统计学思维。当然，这类学习算法不等同于统计学。它们处理的是巨大复杂的数据集，每个数据集可能包含数百万甚至数十亿数据点。机器学习的各种技术与理论最终被佩德罗·多明戈斯归纳为“机器学习的五大学派”。多明戈斯著《终极算法》详述这些分类，表2—1简要展示各学派风格、算法与优势。除符号方法不一定需要数据参与学习外，其他现代方法都结合了基于大数据统计的机器学习。

### 反向传播与卷积神经网络

连接学派与神经网络研究者开发出利用输入—输出对训练前馈神经网络的新方法——反向传播算法。这种随机梯度下降法通过多次微小迭代调整神经元间边权重来降低输出误差。^(⁷²)

第二项创新是借鉴哺乳动物视觉系统的层级结构搭建新型网络——卷积神经网络。1989年，多伦多大学的杨立昆最早提出该概念。^(⁷³)
