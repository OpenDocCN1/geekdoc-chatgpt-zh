# Python 面向对象进阶与第三方库实战指南

## 类的继承机制

在 Python 中，通过 `class Student(University):` 这样的语法可以建立继承关系。这里 `Student` 是子类，括号里的 `University` 是父类。父类拥有姓名、年龄等通用属性，而子类 `Student` 扩展了分数属性，教师类则可能包含工资属性，实现了代码的复用与层级管理。

## 多态特性

多态的核心在于“同一接口，多种表现”。即便事先不清楚对象的具体类型，程序也能根据对象实际类型自动调用对应的方法。Python 的众多内置运算符、函数与方法天然支持这一特性，极大地增强了代码的灵活性。

## 14.4 网络爬虫入门

**本质**：模拟浏览器发送 HTTP 请求，解析响应（HTML/JSON/二进制），提取目标数据并持久化。

**核心流程四步走**：
1. **发起请求**：HTTP 库发 Request（可带 Header/Cookie）
2. **获取响应**：服务器返回 Response（HTML/JSON/图片/视频流）
3. **解析内容**：
   - HTML → 正则 / BeautifulSoup / lxml / XPath
   - JSON → `json.loads()` 反序列化
   - 二进制 → 直接写文件或进一步处理
4. **保存数据**：文本/CSV/数据库/文件系统

### 14.4.1 URL 与 HTTP 基础

**URL 结构**：`scheme://host:port/path?query#fragment`
- 协议（http/https）、域名/IP、端口、资源路径、查询参数、锚点

**HTTP 请求关键要素**：
- **Method**：GET（查）、POST（改/增）、PUT/DELETE 等
- **Headers**：`User-Agent`（反爬首要伪装）、`Referer`、`Cookie`、`Content-Type` 等
- **Body**：POST 数据载体（form/json）

**响应状态码速记**：
- 2xx 成功（200 OK）
- 3xx 重定向（301/302）
- 4xx 客户端错（403 禁访、404 不存在）
- 5xx 服务端错（500/502/503）
