## 6.1 DeepSeek 部署基础

出于成本效益、灵活性、数据安全与高性能等方面的考量，部分企业和个人开发者倾向于将 DeepSeek 在本地运行。

其一，成本效益突出。相较 GPT-4 等顶尖模型，DeepSeek 在训练成本、API 价格和硬件需求上优势明显。DeepSeek 团队通过创新架构与训练方法大幅压缩训练开销，例如 DeepSeek-R1 的训练费用仅约 557.6 万美元，远低于 GPT-4 等模型。

其二，API 定价极具竞争力，且保持与 OpenAI API 格式的兼容，便于开发者快速迁移。

其三，灵活性高。本地化部署可按业务特点深度定制，满足个性化场景。例如电商领域，本地部署的 DeepSeek 能优化商品推荐和客服话术，提升用户体验。

其四，数据安全性增强。本地运行避免敏感数据上传云端，降低泄露风险。在医疗、电力等高安全要求场景尤为关键。DeepSeek 在电力行业的应用中，通过本地部署新增 RAG 知识库，提供更精准的智能支持，满足国产化与自主可控需求。

### 6.1.1 系统环境要求与准备

部署前需明确系统环境、选择合适的部署方式并掌握安装配置要点，以顺利搭建运行基础。

**1.硬件配置**

（1）基础场景 7b～13b 参数模型。
● GPU：NVIDIA A10/A100 单卡，显存≥24GB。
● CPU：Intel Xeon Silver 4310，8 核以上。
● 内存：≥64GB DDR4。
● 存储：≥500GB SSD，建议 NVMe 协议提升加载速度。

（2）中等规模 13b～70b 参数模型。
● GPU：2～4 块 NVIDIA A100 80GB，需 NVLINK 互联。
● 内存：≥128GB DDR4 ECC。

（3）个人测试/轻量级。
最低配置：NVIDIA 显卡显存≥8GB 如 RTX 3060、16GB 内存、SSD 硬盘。

**2.软件环境**

（1）操作系统：推荐 Ubuntu 20.04/22.04 LTS，兼容性最佳；Windows、macOS 需额外适配。

（2）工具依赖。
● Ollama，开源本地大模型运行工具。
● Python 3.x 及必要库如 NumPy、Pandas。
● Docker，可选，用于容器化部署。

（3）网络要求。
本地部署需千兆以太网环境；云端部署需稳定公网带宽，建议上行≥100Mbps。网络硬件环境和存储要求见表 6-1 所示。

### 6.1.2 部署方式选择：本地 VS 云端

本地部署适用场景如下。
● 金融、医疗、政务等对数据安全要求极高的领域。
● 需离线运行的特殊场景。
● 对性能和延迟有严格要求的业务。

云端部署适用场景如下。
● 中小企业或个人开发者希望快速上线。

● 对成本敏感的项目。

选择建议：
● 若数据安全为首要因素，优先本地部署。
● 若追求快速上线且成本敏感，云端部署更合适。
● 混合场景可采用本地与云端结合的方式。
