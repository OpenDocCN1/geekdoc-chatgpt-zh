# Midjourney 从入门到精通：保姆级实操指南

想玩转 Midjourney，首先得找对“主场”。建议新手直接加入官方 Discord 服务器，随便进一个 `newbie-xxx` 频道潜伏观摩——看大神们怎么写词、出什么图，这是最直观的启蒙课。

## 搭建专属“创作工作室”

官方频道人太多、刷屏太快，干扰大。几步操作给自己盖个安静的小屋子：

1.  **新建服务器**：点左侧边栏最顶端的 “+” 号，选 “创建服务器” → “供我和朋友使用” → 起个名（比如 “我的 AI 画廊”）→ 确定。
2.  **拉进官方 Bot**：回官方服务器成员列表找到 **Midjourney Bot**，点开资料卡选 “添加到服务器”，目标选刚建好的 “我的 AI 画廊”，授权、验证码走一遍。
3.  **同理引入 Niji Journey**：重复上一步，把专攻二次元风格的 **Niji Journey Bot** 也拉进来。
4.  **确认到位**：左侧边栏点选你的服务器图标，右侧成员列表里同时出现两个 Bot，大功告成。
5.  **选定聊天频道**：左侧第二栏 “文字频道” 里随便点一个（或新建），光标一闪，就能开始跟机器人对话了。

> ⚠️ **避坑提示**：早期有免费试用额度，现已取消。想出图必须订阅。在输入框发 `/subscribe`，按弹出页面选套餐付费即可。

## 核心出图流程：三步走通关

付费后，在输入框键入 `/imagine prompt: 你的提示词` 回车，几十秒后会返回一张 **四宫格预览图**（如图 4-5）。

[PRE3]

图 4-5 四宫格预览界面

四张图默认编号左上 1、右上 2、左下 3、右下 4。每组图下方按钮分三类，掌握它们就是掌握了“导演权”：

| 按钮 | 全称 | 作用 | 俗称 |
|------|------|------|------|
| **U1~U4** | Upscale | 单张放大、细节增强 | **精修** |
| **V1~V4** | Variation | 基于该图风格再出四张 | **微调/变体** |
| **🔄** | Re-roll | 保持提示词不变，重新随机生成 | **抽卡/洗牌** |

### 分支玩法详解

**① U 分支——精修到底**  
点 `U2` 放大第 2 张，图下会新增：`Vary (Strong/Subtle)` 再变体、`Zoom Out 2x/1.5x` 扩画幅、`Custom Zoom` 自定义扩图、`Make Square` 改比例等。满意后右键 “保存图片” 落地。

**② V 分支——锁定风格微创新**  
点 `V3` 会弹 **Remix 提示词框**（如图 4-7），默认沿用原词，可直接改、可微调。

[PRE5]

图 4-7 Remix 弹窗：可二次编辑提示词

提交后生成的新四宫格（图 4-8）会**高度保持原图的穿搭、环境、光影风格**，只在构图、细节上微调——这就是 “V” 的精髓：**定调子，换细节**。

**③ 🔄 抽卡——不改词、不改种子，纯拼手气**  
同一提示词每次出图都有随机性。对 4 张都不满意？点 🔄 重抽，说不定下一组就有 “90 分作品”。文本类 AI 同理：让模型多跑两遍，常有惊喜。

# 提示词工程：把想法翻译成机器懂的语言

前面示例词极简，实战中 **提示词质量 = 出图上限**。Midjourney 官方定义的提示词结构为：

[PRE9]

图 4-11 提示词三段式解剖图

```
[Image Prompt(s) URL] + [Text Prompt] + [Parameters]
```

| 段落 | 别名 | 必填 | 位置 | 说明 |
|------|------|------|------|------|
| **Image Prompt** | 垫图/参考图 | 否 | **最前** | 图片直链，多张用空格隔开 |
| **Text Prompt** | 文本描述 | **是** | 中间 | 核心指令，自然语言或关键词均可 |
| **Parameters** | 参数后缀 | 否 | **最后** | `--ar 16:9 --v 6.0` 等控制开关 |

> 💡 以文生图时省略 Image Prompt；参数不写则走默认值。

## 文本提示词的 “积木式” 写法

沿用第 3 章通用结构：**主体 + 环境 + 艺术形式/风格 + 画面细节 + 拍摄/渲染参数**。  
例：“公园里一群孩子奔跑”  
→ 主体：kids running  
→ 环境：sunlit park, motion blur background  
→ 风格：street photography, Kodak Portra 400  
→ 细节：laughter, dynamic pose, golden hour  
→ 参数：`--ar 3:2 --style raw --v 6.0`

> 更多词法技巧见前文，此处不赘述。

## 必会的 11 个核心参数速查表

| 参数 | 取值范围/格式 | 核心作用 | 实战 Tips |
|------|---------------|----------|-----------|
| `--v` / `--niji` | `6.0` / `6` | 选模型：`--v` 通用实写，`--niji` 二次元 | 默认 `--v 6.0`；动漫改 `--niji 6` |
| `--ar` | 整数比 `16:9` `3:2` `9:16` | 画幅比例 | 禁止小数，竖屏短视频用 `9:16` |
| `--iw` | `0.5 ~ 2` | 垫图权重 | 越大越像原图，`2` = 几乎复刻 |
| `--q` | `0.25 / 0.5 / 1 / 2 / 5` | 质量/算力 | 高质量慢，测试用 `0.5` 省钱 |
| `--no` | 关键词 | **负向提示** | `--no text, watermark, ugly hands` |
| `--s` / `--stylize` | `0 ~ 1000` (默认 100) | 艺术性强度 | 低 = 听话，高 = 发挥/艺术感强 |
| `--tile` | 无数值 | 无缝拼贴 | 做纹理/壁纸/布料图案必加 |
| `--chaos` | `0 ~ 100` (默认 0) | 四宫格差异度 | 探索期拉高 `50+`，定型期归 `0` |
| `--seed` | 整数 | 固定随机种子 | 同词 + 同 seed = 几乎同图，系列化神器 |
| `::` | `词组::权重` | 词级权重 | `cat::2 dog::1` 猫的权重是狗 2 倍 |
| `--style raw` | 旗帜参数 | 降低默认审美干预 | 想要更“照片感/写实”加它 |

### 怎么拿到 `--seed`？
1. 生成图右上角点 “+表情” → 搜 `envelope` → 点最左边信封 ✉️  
2. Bot 发私信，点开含 `Seed: 123456789`（图 4-12/13）  
3. 复制数字，下次提示词末尾加 `--seed 123456789`

# 默认设置面板：可视化调参更直观

输入 `/settings` 唤出面板（图 4-14），上半部 **Midjourney**，下半部 **Niji Journey**。

[PRE13]

图 4-14 /settings 可视化面板

| 区块 | 关键项 | 说明 |
|------|--------|------|
| **Model Version** | 下拉选最新版 | 一般锁最新 |
| **RAW Mode** | 开关 | 开启 = `--style raw`，少修饰更写实 |
| **Stylize** | Low / Med / High / Very High | 对应 `--s 50/100/250/750` |
| **Public / Stealth** | 作品是否公开 | 隐私需求选 Stealth（高级套餐才有） |
| **Speed** | Relax / Fast / Turbo | 慢/快/极速，消耗不同 GPU 分钟数 |
| **Niji 专属 Style** | `Default / Cute / Scenic / Original / Expressive` | 二次元细分风格一键切 |

熟练后建议**直接在提示词写参数**，版本控制更精准、可复现。

# 神器 `/describe`：以图反推词，最快进阶捷径

`/imagine` 是 “词 → 图”，`/describe` 就是 **“图 → 词”**。看到绝美图却不会写词？丢给它，它吐 4 组现成提示词（图 4-17 → 4-18）。

[PRE16]

图 4-17 上传参考图触发 /describe

**实测某鹿插画反推词（节选）：**
```
a blue and white illustration of a deer,
in the style of fauna and flora accuracy, detailed dreamscapes,
english countryside scenes, golden age illustrations, ceramic,
birds-eye-view, peculiar fantasy --ar 64:63
```
```
a blue print featuring an elaborate tree and deer,
in the style of wildlife art with a satirical twist, realistic hyperdetail,
traditional british landscapes, cosmic symbolism,
historical illustration, high-contrast shading, fantasy illustration --ar 64:63
```

> **为什么一图出多词？** 图文是多对多映射，同一图可被不同风格词描述。

**进阶用法：**  
把第 2 组词里的 `deer` 改成 `unicorn`，其余不动，直接 `/imagine` → 得到 “独角兽版蓝图”（图 4-18）。

[PRE17]

图 4-18 微调词生成独角兽蓝图

**学习闭环：**  
见好图 → `/describe` 拿词 → 拆解陌生风格词（如 `golden age illustrations`） → 网上补课 → 写入自己词库 → `/imagine` 验证 → 循环。**这是从 “不会写” 到 “信手拈来” 的最短路径。**

# 以图生图第二式：`/blend` 混图融合

无需写词，上传 **2~5 张图**，Midjourney 自动融合特征出新图。

**实操：**  
输入 `/blend` → 依提示上传 “马” “虎” 两图 → 回车 → 得到 “马虎” 合成体（图 4-19）。

> 适合：IP 联名脑暴、风格迁移、角色融合、材质叠加等无需精准语义控制的场景。
