# 神经网络基石：从MP模型到BP算法的演进之路

MP模型的核心构思极为直观：它模拟生物神经元接收多路信号、经阈值判断后输出的机制。关键差异在于引入了**权重（权值）**，这是一个可正可负的浮点数。正权重模拟“兴奋”促进信号传递，负权重模拟“抑制”阻断信号。所有输入信号乘以对应权重后累加求和，得到总输入信号 $u$。

随后，激活函数 $f(\cdot)$ 登场，它赋予神经元非线性表达能力，决定最终是否“发火”输出。最经典的是阶跃函数：$u$ 超过阈值 $\theta$ 输出 1，否则输出 0；当然也可选用 Sigmoid 等输出连续浮点数的函数。

## 感知机：会“学习”的第一张网络

1958年，罗森布拉特推出**感知机**，这是首个具备学习能力的神经网络模型，能识别简单图像，将神经网络从理论推向工程，引发首轮研究热潮。虽然后来因局限性退潮，但它为后来的多层网络乃至深度学习奠定了基石。

### 单层感知机：线性分类的先锋

结构上是单层计算单元的前馈网络：输入节点经权重连接到输出节点，同层无连接。数学表达为加权求和后经功能函数 $g(\cdot)$ 输出。

[PRE6]

**实战案例：生鲜分类**
以颜色、形状、口感为三维特征（编码为 $\pm1$），预设权重全为 1，用符号函数做判别。豆角、茄子、洋葱判为蔬菜（-1），绿苹果、西瓜判为水果（+1），完美分类。

但这依赖于“碰巧”选对的权重。现实中，**核心任务就是寻找那组最优权重**，这个过程称为“学习”或“训练”，深度学习里的“调参”本质同此。

**训练流程：**
1.  权重初始化为微小随机数；
2.  送入样本 $\{输入, 期望输出\}$；
3.  前向计算得实际输出；
4.  若有误差，按**感知机学习规则**更新权重：$w_{new} = w_{old} + \eta (目标 - 实际) \times 输入$；
5.  循环直至收敛。

罗森布拉特证明了：对线性可分问题，感知机训练必收敛。但本质上这是线性回归，**无法解决异或（XOR）等非线性可分问题**。

### 多层感知机：破局隐藏层

在输入输出间插入隐藏层，构成多层感知机（MLP）。虽能解决非线性问题，但早期难题在于：隐藏层无明确目标输出，难以直接调整其权重。后续引入**偏置项**，并通过矩阵变换将非线性可分问题映射为线性可分，为深度学习铺平道路。

## BP算法：训练深层网络的利器

确定网络结构后，如何高效求得 $w$ 和 $b$？**反向传播算法**是里程碑式突破，其核心是**梯度下降**——沿损失函数梯度反方向迭代求极小值。

### 1. 激活函数之选：Sigmoid
因梯度下降需求导，激活函数须连续可导。Sigmoid 函数 $f(x) = 1/(1+e^{-x})$ 曲线平滑，且导数可用函数值本身表示：$f'(x) = f(x)[1-f(x)]$，极大简化推导。

[PRE9]

### 2. 网络拓扑与符号定义
以单隐藏层网络为例：

[PRE10]

设输入层 $m$ 个节点，隐藏层 $j$ 个，输出层 $n$ 个。权重分别为 $w_{ih}$（输入→隐藏）、$w_{ho}$（隐藏→输出），偏置为 $b_h, b_o$。

### 3. 前向传播计算
第 $k$ 次迭代中：
- 隐藏层输入：$h_i_h = \sum w_{ih} x_i + b_h$
- 隐藏层输出：$ho_h = f(h_i_h)$
- 输出层输入：$y_i_o = \sum w_{ho} ho_h + b_o$
- 输出层输出：$yo_o = f(y_i_o)$

### 4. 损失函数与反向梯度
用均方误差衡量偏差：$P = \frac{1}{2} \sum (d_o - yo_o)^2$。目标转化为最小化 $P$。

利用链式法则层层回传误差：
- **输出层误差项** $\delta_o = (d_o - yo_o) f'(y_i_o)$，权重梯度 $\frac{\partial P}{\partial w_{ho}} = -\delta_o \cdot ho_h$
- **隐藏层误差项** $\delta_h = (\sum \delta_o w_{ho}) f'(h_i_h)$，权重梯度 $\frac{\partial P}{\partial w_{ih}} = -\delta_h \cdot x_i$

[PRE11]（对应原文式4-19至4-21的推导过程）

掌握了梯度，配合学习率 $\alpha$ 即可按 $w \leftarrow w - \alpha \nabla P$ 迭代更新，完成网络训练。这就是 BP 算法的精髓所在。
