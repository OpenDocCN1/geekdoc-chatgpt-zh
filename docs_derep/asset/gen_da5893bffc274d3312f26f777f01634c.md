### 实战指南：百度AI开放平台与阿里云PAI平台核心操作全解析

#### 完善百度AI应用创建流程

在应用创建界面，还需完成两项关键配置：**适用平台**——勾选应用将运行的目标环境；**应用描述**——简述具体的业务应用场景。信息填报无误后，点击“立即创建”即可落地应用实例。创建成功后，可通过“应用列表”入口查看并管理已生成的应用。

[PRE0]

**Figure 4-66**

#### 凭证获取与签名生成

应用建立后，平台会自动下发三大核心凭证：`AppID`、`API Key` 与 `Secret Key`。开发者需利用这三项凭据生成 `Access Token`（即身份验证与授权的签名令牌），完成后便可正式接入 `百度AI开放平台` 的能力。目前平台主要通过 `API` 与 `SDK` 两种方式提供服务调用。

### 深度解析：阿里云PAI平台一站式建模实战

`阿里云PAI平台` 依托 `MaxCompute` 构建，集成了数据挖掘、建模预测全链路工具，覆盖算法开发、共享、模型训练、部署监控等全生命周期。其算法库沉淀自阿里大规模业务实战，不仅囊括聚类、回归等基础机器学习算法，更延伸至文本分析、特征工程等高阶领域，算法谱系十分丰富。

[PRE1]

**Figure 4-67**

平台标准化建模流程划分为七大阶段：注册开服 → 创建项目 → 数据准备 → 数据预处理 → 算法建模 → 数据可视化 → 模型评估。

#### 第一阶段：账号注册与服务开通

完成 `阿里云PAI平台` 账号注册后，进入 `Dataworks` 控制台开通机器学习服务。新手引导流程要求依次完成：实名认证、创建 `AccessKey`、选择 `Region` 与服务类型、创建项目。

1.  点击“实名认证”按钮，按引导完成认证并回原页面。
    [PRE2]
    **Figure 4-68**
2.  点击“创建 AccessKey”，按提示生成密钥对并返回。
    [PRE3]
    **Figure 4-69**

**注意区域限制**：当前PAI仅在华北2、华东2、华南1三个地域可用。不同地域功能与计费策略存在差异，且需同地域同步勾选购买按量付费的 `MaxCompute` 与机器学习 `PAI` 服务。

**Figure 4-70**

完成采购后，勾选“MaxCompute”与“机器学习 PAI”，点击“下一步”进入下一环节。

**Figure 4-71**

#### 第二阶段：项目空间构建

输入项目名称，点击“创建项目”，系统将自动初始化机器学习项目空间。

[PRE6]
**Figure 4-72**

此时项目已在 `Dataworks` 下建立，二者呈共享关联关系。

[PRE7]

[PRE8]
**Figure 4-74**

#### 第三阶段：多数据源接入与准备

PAI底层双轨制支持数据接入：
*   **MaxCompute 表数据**：主攻结构化表格数据，兼容稀疏/稠密格式，支持IDE可视化上传与命令行工具上传，主要服务于非深度学习算法组件。
*   **OSS 对象存储**：面向深度学习算法组件，可存储结构化或非结构化数据。

进入建模界面后，左侧菜单栏点击“首页”，在“新建”项目中选择“新建空白实验”。

[PRE9]
**Figure 4-75**

左侧组件面板展开“数据源/目标”文件夹，将“读数据表”组件拖拽至画布，右侧“表选择”栏填入对应 `MaxCompute` 表名。

[PRE10]
**Figure 4-76**

切换至“字段信息”标签，可预览输入表前100行数据的字段名、数据类型及取值范围。

**Figure 4-77**

#### 第四阶段：数据清洗与特征工程

数据就绪后，从“数据预处理”文件夹拖入“SQL脚本”、“类型转换”、“归一化”三个组件至画布并串联成线。

[PRE12]
**Figure 4-78**

1.  **SQL脚本**：右侧输入SQL语句，按字段业务含义将字符型转为数值型。
2.  **类型转换**：右侧“字段设置”全选字段，统一转换为 `double` 类型。
    [PRE13]
    **Figure 4-79**
3.  **归一化**：右侧“字段设置”全选字段，配置完毕后点击画布底部“运行”按钮启动实验。运行中可右键节点查看各组件中间输出结果。

此外，拖入“拆分”组件进行数据集切分，串联运行。

[PRE14]
**Figure 4-80**

在“机器学习”→“二分类”目录下，拖入“逻辑回归二分类”组件。右侧“字段设置”将“目标列”指定为 `ifhealth`，“训练特征列”勾选除目标列外的所有列，串联运行。
