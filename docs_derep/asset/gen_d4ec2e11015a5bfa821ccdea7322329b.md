在遗传算法的迭代流程里，选择环节决定了哪些个体有资格进入下一轮繁殖。它依据每个成员的适应度得分，从当前群体中筛选出部分优质个体作为父代，同时保留一定的随机扰动来维持群体多样性，避免过早陷入局部最优。常见的筛选策略主要有三种。轮盘赌选择是典型的概率抽取方式，个体的选中概率与其适应度占总和的比例成正比，适应度越高在轮盘上占据的面积越大，被抽中的机会也随之提升，如图 6-3 所示。锦标赛选择则随机抽取若干个体进行内部比拼，适应度最优者胜出并获得复制资格。排名选择先对群体按适应度排序，再根据名次赋予不同的选中权重。无论选用哪种方式，核心都在于既保留强者基因，又给弱势个体留下存活空间，以平衡 exploitation 与 exploration。

**6.1.3 差分进化：种群差分驱动的优化引擎**
差分进化 Differential Evolution, DE 是一种基于种群的全局优化算法，由 Storn 和 Price 于 1997 年提出。它在连续优化问题上表现突出，通过种群内部个体的差分来构造变异，再经选择更新种群。与传统遗传算法不同，DE 的变异直接来源于个体间的差异，搜索更具导向性，鲁棒性强，广泛应用于工程优化、机器学习参数调优等领域。

DE 主要包含初始化、变异、交叉、选择四个环节，图 6-26 展示了流程图。

首先是种群初始化。随机在解空间内生成 N 个个体构成初始群体，每个个体为代表解的向量。种群规模 N 影响搜索广度，规模越大候选解越多但计算开销也越高。DE 的初始化通常直接在变量范围内均匀采样，不依赖复杂启发式。

最后是选择操作。依据适应度函数评估新个体，若新个体更优则替换原个体进入下一代，否则保留原个体。选择保证种群单调改进，逐步逼近全局最优。

DE 的优势在于假设较少，适用于非线性、多峰、连续等复杂问题，在高维场景中表现稳定，常用于神经网络超参数与结构搜索。局限性也明显：计算复杂度随种群增大而上升；对缩放因子 F 和交叉率敏感，需要反复调参；在适应度梯度平缓时收敛可能较慢，需要更多迭代。

**6.2 生物智能算法总览**
**6.2.1 生物智能算法简介**
生物智能算法是一类受自然行为启发的计算范式，通过模拟生物在觅食、繁殖、协作等活动中的群体智能来求解复杂优化问题。其核心在于个体信息有限却能通过局部交互与环境反馈，在群体层面涌现高度优化的行为。算法强调协作、自适应与鲁棒性，在高维、非线性、多目标任务中优势突出。

这类算法源于对自然现象的观察。例如蚂蚁觅食时通过信息素标记路径，后续个体依据浓度选择方向，群体最终形成最优路线。粒子群优化则模拟鸟群飞行，每只粒子依据邻居位置与速度调整自身策略，逐步靠近最优目标。简单个体规则在群体中叠加，往往能产生超越个体的集体智慧。
