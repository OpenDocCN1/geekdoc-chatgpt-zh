### 6.2.7 合理进行限制

当任务不需要模型发挥联想，而是希望其严格贴近输入给出答案时，可在提示词里加入边界约束，以避免跑题和发散。

提示词加入限制的示例：

角色：资深美食爱好者。

要求：依据用户提问，准确给出地道食谱推荐。

返回格式：

- 菜名：<菜名>
- 材料清单：<材料列表>
- 做法：<步骤描述>

限制条件：

- 仅围绕美食主题展开，美食以外的问题一律不作回应。
- 全部输出须遵循既定格式，严禁偏离框架。

### 6.2.8 使用链式思维

链式思维提示是通过构建一组相互关联的指令，引导模型分步完成复杂任务，从而在多步处理中保持逻辑连贯与上下文一致，提升结果质量。

以撰写一篇介绍蛋炒饭的文章为例，提示词链可把整体任务拆解为若干子任务，每一步由专属指令驱动，保证思路清晰、内容连贯。

①引言，示例如下：

角色：资深美食爱好者。

要求：依据用户提问，准确作答。

输出：返回JSON结构，键使用"answer"，值为模型返回的结果。

- 只讨论与美食相关的内容，拒绝回答与美食无关的话题。

def send_message(messages, temperature=0.1, model='gpt-3.5-turbo'):

    client = OpenAI(

        base_url=OPENAI_API_BASE,

        api_key=OPENAI_API_KEY

    )

    if "GPT4" in model:

        response = client.chat.completions.create(

            model=model,

            messages=messages,

            response_format={"type": "json_object"},

            temperature=temperature,

            max_tokens=2048,

        )

    else:

        response = client.chat.completions.create(

            model=model,

            messages=messages,

            stop=None,

            temperature=temperature,

        )

    for choice in response.choices:

        if "text" in choice:

            return choice.text

    return response.choices[0].message.content

def do_request(prompt, role='user', temperature=0.1, model='gpt-3.5-turbo'):

    messages = [{"role": role, "content": prompt}]

    is_success = False

    try:

        content = send_message(messages, temperature=temperature, model=model)

        is_success = True

        return is_success, content

    except Exception as err:

        content = f"Error: {err=}"

    return is_success, content
