ChatGLM6B 用 LoRA 做 SPO 抽取的实战笔记

想让大模型在信息抽取上更听话，不一定非要全量微调。下面的流程展示了一套基于 LoRA 的轻量化训练方案，以 ChatGLM-6B 为底座，针对 SPO 三元组抽取任务做定向适配，整套过程可以快速复现。

整体思路是先把本地保存的 6B 权重装载到自研的 XiaohuaModel 包装类里，再用预先保存的 LoRA 配置挂载到模型上，打印可训练参数量确认注入效果，然后切到半精度并放到显存。任务提示被固定为「按给定的格式抽取文本信息。\n文本:」，随后通过 get_data 模块读取 spo_0.json，用相同的 48 个 token 作为输入与输出上限做编码，组装成序列到序列的数据集。

数据加载采用 DataLoader，批次大小设为 2，丢弃不完整的尾批，使用项目自带的 collate 函数，工作进程为 0。训练框架使用 Accelerate 统一管理设备与梯度，优化器选 AdamW，初始学习率 2e-5，beta 取 0.9 和 0.999，eps 1e-5。学习率调度走余弦退火，周期 T_max 为 2400，最低值压到 2e-6，last_epoch 从 -1 开始。模型、优化器、数据加载器、调度器全部交给 accelerator.prepare 包装。

训练跑 20 个轮次，每轮用 tqdm 展示进度。每个 batch 先把 input_ids 与 labels 搬到 cuda，再调用模型 forward 得到 loss，通过 accelerator.backward 回传，依次执行优化器步、调度器步、梯度清零，并在进度条上实时显示当前轮次、训练损失以及学习率乘 1000 后的数值。每训练 3 个 epoch 就把当前状态保存到 ./glm6b_peft.pth，方便中断恢复。

def forward(self,input_ids,labels = None,position_ids = None,attention_mask = None):
    logits,hidden_states = self.glm_model.forward(input_ids=input_ids,position_ids = None,attention_mask = None)
    loss = None
    if labels != None:
        shift_logits = logits[:, :-1, :].contiguous()
        shift_labels = input_ids[:, 1:].contiguous()
        # Flatten the tokens
        logits_1 = shift_logits.view(-1, shift_logits.size(-1))
        logits_2 = shift_labels.view(-1)
        loss = self.loss_fct(logits_1, logits_2)
    return logits,hidden_states,loss
