# 智能时代的曙光与暗流

计算机技术的飞跃式进步，正强力推动机器人技术、感知系统与机器学习的革新。这些突破让新一代系统具备了媲美甚至超越人类的能力。这或许预示着一个空前繁荣舒适的时代将至，但通往彼岸的过渡期漫长且残酷。倘若经济体制与监管政策不随之变革，社会动荡将难以避免。

危机信号早已四伏。困扰现代发达世界的两大顽疾——顽固的失业率与日益撕裂的贫富差距，即便在经济持续增长期也从未消退。若对这些现象熟视无睹，我们将面临一个悖论：在财富与舒适不断累积的背景下，大规模贫困却悄然滋长。本书旨在为您领航，梳理驱动此番变革的技术脉络，剖析其对社会结构的冲击，并提出一套以自由市场为基石、能在推动进步的同时收缩政府干预的解决方案。

### 智能正解放您的双手

人工智能研究已在两条赛道上取得关键性突破。首类系统已步入应用层，其核心在于“经验式学习”。但与人类受限于认知广度与深度不同，它们能以极高速度吞吐海量有效样本。它们不仅能解读我们熟悉的视觉、听觉与文本信息，更能洞察计算机与网络中流转、人类难以企及的数据图景。试想，若您拥有千里眼、顺风耳，且能阅尽世间一切出版物，您将如何从容品味并洞悉这个世界？这便是这些系统感知环境的方式。

我们从愈发广泛的`传感器`（监测空气质量、车流量、浪高等）与个人数字足迹（网页检索、博客日志、信用卡流水）中汇聚数据。这些系统能捕捉人类大脑触及不到的模式与洞见。您或许会误判它们拥有超人智能，但这在可预见未来绝对是谬论——它们无意识、不反思、无自主意志与个人欲望，简而言之，它们“无思”。它们在特定领域表现卓越，但我们往往不解其解。多数情况下，这是因为对我们这类简单生物而言，根本不存在可被理解的解释。

该领域尚无公认学名。依研究侧重与方法，学界称其为机器学习、神经网络、大数据、认知系统、遗传算法等。基于这些产品的通用目的，我将其命名为**“合成智能”**。

合成智能非传统编程所得。您从日益丰富的工具箱与模块库中拣选素材、设定目标，指向一系列实例，便将其“释放”。系统的最终形态不可预测，亦不受创造者掌控。很快，合成智能将比您母亲更懂您，比您自己更精准预判您的行为，为您预警那些难以察觉的险境。我将详述合成智能的运作机理，及其为何能超越我们对计算机的固有认知。

第二类新系统源于`传感器`与`执行器`的耦合。它们能看、能听、能感知、能与环境互动。当二者合一，您会称其为“机器人”，但将两者塞进同一物理躯壳并非必要，甚至在大多数场景下并非最优解。传感器可分布于环境中——路灯杆、智能手机，其观测端汇聚至远端服务器集群，以此制定方案。方案可直接执行（如远程操控设备），也可间接生效（如诱导您做出预期动作）。动作结果实时反馈，系统持续修正计划，恰如您伸手取物时的闭环调节。

当您遵循导航指引行驶，便身处此类系统中。该程序监控您的位置与速度（通常经`GPS`），向您发令。它聚合您与其他驾驶员的数据以研判路况，进而为各方规划更优路径。

这些系统愈强大，反而显得愈简朴，因其承担的是人类视为理所当然的任务。虽缺乏常识与通用智能，却能在混乱多变的环境中不知疲倦地完成海量任务。

迄今所谓的自动化，多指将专用机器集中于工厂车间执行重复单一作业，环境甚至为其专门设计。相比之下，新系统将走出厂房：它们将耕种、粉刷、清扫、洗涤叠衣；或与人类协作在音乐厅铺设管道、田间收割、工地建房；或独自深入危险或人迹罕至之地——灭火、巡检险桥、深海采矿、战场作战。我称这类系统为**“铸造劳工”**。

毋庸置疑，合成智能与铸造劳工可协同作业，完成修车、手术、烹饪佳肴等需高阶知识与技能的体力任务。

原则上，这些新系统不仅将您从繁重琐事中解放，更能提升您的效率——前提是您买得起。定制化`电子代理`可极大化维护您的利益，代表您谈判，甚至教授您微积分——但并非所有系统都为您效力。

人类易为眼前利益所惑。先见者贾伦·拉尼尔将此类系统称为**“塞壬服务器”**：它们依您的意愿定制短期诱惑，劝诱您做损害长远利益之举。冲动消费与极速达的无法抗拒，可能让您对珋视生活方式的缓慢毁灭视而不见。您今晚网购电饭煲，明日送达，但这价值不包含家门口逐渐闭店的实体店，也不包含即将失业的邻居。

让系统推荐音乐或牙刷是一回事，赋予其自主行动权则截然不同。因其反应速度远超人类感知阈值，一旦掌握人类无法理解或控制的海量数据，它们能在瞬间引发难以想像的灾难——瘫痪电网、全球航班停飞、注销数百万信用卡。

# 序章

您或许不解，为何要制造这般惊悚的系统。出于审慎，为防范小概率事件——如关键输电线路多点同步短路——我们必须设计兜底机制。令人不安的是，这些“百年一遇”的灾难似乎总按某种规律频发。事故发生时，人类在紧急状态下根本无暇反应，因为损失已在瞬息间完成。设想一个恐怖场景：核导弹发射后我们至少尚有数分钟思考对策，但针对核电站的网络攻击却能在瞬间瓦解其控制系统。所以我们别无选择，只能信任机器守护我们。

在混沌无序的网络空间，您无从得知两个或多个目的对立的自主系统何时相遇。它们交战的规模与速度堪比自然灾害。这非假想——实锤已落，后果惨烈。

2010年5月6日，证券市场无端暴跌9个百分点（道指暴跌1000点），大幅下跌在几分钟内完成。万亿美元资产价值瞬间蒸发，数百万工人的养老金等资金亦在其中。证券交易所经纪人难以置信。

美国证监会（SEC）耗时近6个月才厘清真相，却毫无安慰可言：代表各自所有者买卖股票的计算机程序在博弈中失控。在被称为高频交易的幽微世界里，这些系统不仅“收割”稍纵即逝的微利良机，更会探测并利用彼此的交易策略。[\[2\]](#part0031.xhtml#bz101)
