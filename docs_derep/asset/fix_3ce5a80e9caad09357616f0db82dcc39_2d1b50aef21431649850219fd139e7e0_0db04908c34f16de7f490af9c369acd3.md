# 用 LoRA 把 ChatGLM-6B 训练成抽取器

在显存吃紧的前提下，用低秩适配把 6B 级模型改造成结构化信息抽取工具，是性价比很高的路线。下面把数据准备、微调、保存以及推理的完整链路重新讲一遍，保留关键配置与逻辑，只是换了表达方式。

**数据与训练框架**

开训前先调用打印函数看一眼可训练参数规模。指令模板写成“按给定的格式抽取文本信息。\n文本:”，后续全程使用 THUDM/chatglm-6b 的分词器并打开 trust_remote_code。

训练用例取自 spo_0.json，通过 get_data.get_train_data 构造，最大输入长度 128、目标长度 96，随后包装为 Seq2SeqDataSet。DataLoader 的小批量设为 2，丢弃不完整批，num_workers 为 0，collate 由项目提供的 collate_fn 处理。

加速与调度交由 Accelerate 统一管理，获取当前设备。LoRA 参数单独打包成一组，AdamW 的学习率取 2e-5，betas 为 0.9 与 0.999，eps 为 1e-5，学习率衰减采用余弦退火，T_max 2400，eta_min 2e-6。模型、优化器、数据加载器、调度器一起交给 accelerator.prepare。

共跑 96 个 epoch，每轮用 tqdm 展示进度。每个 batch 取出 input_ids 与 labels 放到显存，前向得到 loss，经 accelerator.backward 反向后依次执行 optimizer.step、lr_scheduler.step、optimizer.zero_grad。进度条实时显示当前轮次、训练 loss 与即时学习率。结束时把完整权重存到 ./glm6b_lora_all.pth，同时用 get_lora_state_dict 把低秩部分单独导出为 ./glm6b_lora_only.pth。

**生成与 top-p 采样**

生成采用自实现的 top-p 采样，先排序累计概率再截断。输入由指令、原文、[gMASK]、<sop> 拼接而成，总长上限 288，源文本上限 256，自回归生成直至遇到结束符 130005。分词器依旧使用 THUDM/chatglm-6b。

[PRE4]python
def sample_top_p(probs, p):
    probs_sort, probs_idx = torch.sort(probs, dim=-1, descending=True)
    probs_sum = torch.cumsum(probs_sort, dim=-1)
    mask = probs_sum - probs_sort > p
    probs_sort[mask] = 0.0
    probs_sort.div_(probs_sort.sum(dim=-1, keepdim=True))
    next_token = torch.multinomial(probs_sort, num_samples=1)
    next_token = torch.gather(probs_idx, -1, next_token)
    return next_token

**低秩参数化实现**

核心类用两个低秩矩阵 A、B 近似权重增量，提供 dropout、缩放系数与前向钩子，同时兼顾线性层和嵌入层的内存布局差异。

[PRE5]python
class LoRAParametrization(nn.Module):
    def __init__(self, fan_in, fan_out, fan_in_fan_out=False, rank=4, lora_dropout_p=0.0, lora_alpha=1):
        super().__init__()
        # if weight is stored as (fan_out, fan_in), the memory layout of A & B follows (W + BA)x
        # otherwise, it's x(W + AB). This allows us to tie the weights between linear layers and embeddings
        self.swap = (lambda x: (x[1], x[0])) if fan_in_fan_out else (lambda x: x)
        self.lora_A = nn.Parameter(torch.zeros(self.swap((rank, fan_in))))
        self.lora_B = nn.Parameter(torch.zeros(self.swap((fan_out, rank))))
