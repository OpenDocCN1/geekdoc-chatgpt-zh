### 2.1.2 IDE 的选择

把编程视作手艺的话，IDE 就相当于手艺人的饭碗。

IDE 的全称是 Integration Development Environment，即集成开发环境，通常以代码编辑器为核心，围绕其配备若干外围组件与辅助功能。一个优秀的 IDE，关键在于能为特定语言提供各类快捷编辑手段，让开发者浏览、输入和修改代码都更顺畅、清晰。现代 IDE 一般都包含语法着色、错误提示、代码折叠、代码补全、代码块定位、重构，以及调试器和版本控制系统 VCS 的集成等能力。以插件、扩展系统为代表的可定制架构，也是当今 IDE 的流行趋势。功能并非越多越好，过多的功能会提升复杂度，分散注意力甚至引入错误。用合适的工具做合适的事，只要核心功能满足需求且符合个人使用习惯，就是一款好 IDE。正因如此，除了大而全的集成环境以外，单纯的文本编辑器配合独立调试器、交互式命令行等外部小工具也是一种常见的工作方式。Python 本身简洁，写小片段或借助示例学习时，这种轻量方式尤其适用。

Anaconda 自带 Spyder。完成 Python 安装后，需要挑选一个适合自己的 IDE 来学习，虽说使用 Python 默认的编辑器或文档编辑器也能做基础练习，但便利性明显不足。市面上能开发 Python 项目的 IDE 很多，例如 sublime text、PyCharm，本书示例代码均在 PyCharm 环境下完成。

## 2.2.3 列表、元组、字典

Python 中最基本的数据结构是序列。Python 内建 6 种序列，包括列表、元组、字符串、Unicode 字符串、buffer 对象和 range 对象。序列的通用操作有索引、长度、组合、重复、切片、成员检查、遍历、求最值等。每个元素都有序号即索引，第一个为 0，最后一个可标记为 -1，倒数第二个为 -2，依此类推。元素可以是基础数据类型，也可以是另一个序列或之后介绍的对象。最常用的序列有两类：元组 tuple 和列表 list。列表可修改，元组不可修改。

### 1. 列表

列表由特定顺序排列的元素组成。可以存放字母表、数字 0～9、家庭成员姓名，或任意对象，元素之间不必相关。
