# 小显存也能训7B：量化+LoRA 实操全流程

在显存受限的机器上做指令微调，常规思路是先把基座模型做压缩，再用低秩适配只更新少量参数。下面的流程把模型载入、分词器准备、数据构造、训练以及后续合并串起来，可以直接照搬。

量化策略由显存开关决定。开启 4bit 时用 BitsAndBytes 构造 nf4 配置，计算精度设为 float16 并启用双重量化来兼顾体积与效果；关闭 4bit 则使用 8bit 加载。两种分支都采用 auto 设备映射并信任远程代码，基座根据 model_type 在 Falcon-7B 与 Llama-2-7B-hf 之间选择。
# Load in the model as a 4-bit or 8-bit model

if load_in_4bit == True:

    bnb_config = BitsAndBytesConfig(

        load_in_4bit=True,

        bnb_4bit_quant_type="nf4",

        bnb_4bit_compute_dtype="float16",

        bnb_4bit_use_double_quant=True,

    )

    model = AutoModelForCausalLM.from_pretrained(

        "tiiuae/falcon-7b" if model_type == "falcon" else "meta-llama/Llama-2-7b-hf",

        trust_remote_code=True,

        device_map="auto",

        quantization_config=bnb_config

    )

else:

        "tiiuae/falcon-7b" if model_type == "falcon" else "meta-llama/Llama-2-7b-hf",

        trust_remote_code=True,

        device_map="auto",

        load_in_8bit=True,

    )

对话数据的格式统一为显式的角色标记，Human 与 Assistant 分别包裹问题与答案，便于模型学习指令跟随。
[PRE1]

#### Human: {question}#### Assistant: {output}

一条训练样本最终拆为三部分：编码后的 id 序列、用于计算损失的标签序列、以及注意力掩码。标签里对指令、输入和填充位置使用 -100 屏蔽，PyTorch 的 CrossEntropy 会忽略这些位置；掩码则阻止模型关注填充。
[PRE2]json

{
    "input_ids": "input ids for the encoded instruction and input",
    "labels": "This is the input ids, but we put -100 where we want to mask the loss. We want to mask the loss for the instruction, input, and padding. We use -100 because PyTorch CrossEntropy ignores -100 labels.",
    "attention_mask": "attention mask so the model doesn't attend to padding"
}
