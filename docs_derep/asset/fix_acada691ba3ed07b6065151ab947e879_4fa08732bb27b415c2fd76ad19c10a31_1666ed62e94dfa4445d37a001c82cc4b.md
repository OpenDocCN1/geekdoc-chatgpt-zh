根号2是无理数。

**详细论证：**

借助反证法来说明根号2的特性。

假定 √2 能写成最简分数 a/b，其中 a 与 b 为互质整数且 b≠0。

1. 对等式两端平方：

\[ (\sqrt{2})^2 = \left(\frac{a}{b}\right)^2 \]

可得：

\[ 2 = \frac{a^2}{b^2} \]

2. 等式两端同乘 b²：

\[ 2b^2 = a^2 \]

由此 a² 能被2整除，进而 a 本身也是2的倍数。记 a = 2k，k 为整数。

3. 代入上式：

\[ (2k)^2 = 2b^2 \]

得到：

\[ 4k^2 = 2b^2 \]

化简后：

\[ 2k^2 = b^2 \]

这说明 b² 亦能被2整除，因而 b 也是2的倍数。

4. 在 a 与 b 互质的前提下，同时被2整除会产生矛盾，故原假设不成立。

综上，√2 不可能是有理数，即为无理数。 < | end_of_sentence | >

上述片段实例化了训练器并配置了多项超参数，涉及的依赖如下：

- SFTTrainer（来自 trl 库）类：trl 即 transformer reinforcement learning，是 Hugging Face 推出的 trl 工具包，涵盖监督微调与强化学习能力。SFTTrainer 主要承担监督微调任务，支持 LoRA 等低秩适配方案。

- TrainingArguments 类（来自 transformers 库）：该类用于设定训练超参，例如 batch 大小、学习率、优化器、训练步数等。

- is_bfloat16_supported() 函数（来自 Unsloth）：用于检测当前 GPU 是否支持 bfloat16，若支持返回 True，否则返回 False。bfloat16 是一种更高效的数值格式，在 A100/H100 等新一代 NVIDIA 显卡上表现更佳。
