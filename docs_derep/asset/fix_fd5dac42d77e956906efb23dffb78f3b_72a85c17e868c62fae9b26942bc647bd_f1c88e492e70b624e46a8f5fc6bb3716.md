# 挑剔式审视：让方案经得起推敲

想用挑剔的眼光拆解方案，可以按三步推进。

1. **找破绽：** 将方案整体摊开，逐环检视，把隐含的风险、逻辑缝隙和落地盲区都揪出来。
2. **追问影响：** 对已发现的疑点，继续追问会带来什么后果、会牵连哪些连锁反应。
3. **给出对策：** 在问题厘清后，提供可落地、可验证的优化方向，让方案更完整。

示例提问可以这样组织：

请用挑剔的态度把这个方案盘一遍：

1. 列出所有可能出现的破绽。
2. 说明这些破绽会造成什么影响。
3. 给出具体的改进办法。

#### 2. 使用场景

挑剔视角最常用的工作场景有：

- **方案审阅：** 在评审或制定计划时，提前把坑找出来。
- **风险研判：** 梳理决策可能遇到的风险，为判断提供依据。
- **质量把控：** 确保最终的产品或服务能达到预期水准。

## 4.3.2 说人话模式

说人话模式的核心就是把专业、复杂的表达换成通俗易懂的说法。用生活化语言、具体例子和简单逻辑，让不同背景的人都能快速get到要点。

说人话模式的突出特点：

- 化繁就简：把术语和复杂概念拆成大白话。
- 贴近生活：用日常比喻增加亲和力。
- 增强互动：用轻松有趣的方式传递信息。

### 1. 基本用法

使用时建议把握三点：

- 生活化比喻：用日常场景解释专业概念。
- 减少术语：能少用就少用，必须用就简单解释。
- 增加例子：用具体情境帮助理解抽象内容。

示例提问可以这样写：

请把下面这段专业内容改写成大众能懂的说法：

- 用生活化比喻。
- 避免堆砌专业术语。
- 补充具体例子。

### 2. 使用场景

说人话模式主要适用于：

- 跨领域沟通：让专业人士向非专业人士解释概念。
- 教育科普：把科学知识讲得更易懂。
- 产品推广：用通俗语言介绍功能和卖点。

### 3. 真实案例

模型示例答复如下：

想象你们小区有一个公共记事本，记录每家快递的存放情况。这个本子的特别之处在于：

1. **集体记账：** 每家物业前台都有一本完全一样的本子。张阿姨帮李叔叔代收快递，所有前台都会写上：“11月5日，3号楼201代收包裹暂存2号楼302”。
2. **永久留痕：** 写完后每一页都被塑封。想把“代收包裹”改成“代收衣物”，就必须同时改掉小区200本记事本，几乎不可能。
3. **透明追溯：** 快递员质疑包裹去向时，直接翻任意一本就能看到从入库到代收再到领取的完整记录，每一步都有签名。
