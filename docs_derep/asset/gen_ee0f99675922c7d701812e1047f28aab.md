### 4.1 智能家居管家

智能家居管家是一个涵盖多传感器数据采集、AI 决策与设备控制的综合物联网方案。系统由 ESP32 微控制器采集光照传感器数据，以树莓派作为中央处理单元，再结合 DeepSeek 大模型的分析能力，实现家居环境的自动化监测与智能调控。

DeepSeek 推出的大语言模型 API 仍处于内测阶段，用户可通过多种渠道申请权限。申请者需前往 DeepSeek.ai 官网填写排队申请表，说明使用场景与计划；同时可关注官方 Twitter 了解发布动态，加入 Discord 社区获取测试机会。也可通过邮件联系团队咨询访问事宜。鉴于 API 尚未全面开放，建议开发者同步了解其他开源语言模型以保证项目进度。
