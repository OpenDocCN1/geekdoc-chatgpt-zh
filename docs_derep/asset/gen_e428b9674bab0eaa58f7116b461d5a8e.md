# **第二章**

# **让提问更精准**

ChatGPT 本质上是基于大语言模型的智能对话系统，通过自然语言与人交互。提问的准确度直接决定了返回答案的质量。本章将围绕角色设定、清晰指示与范围限定来讲解如何提问题更快更准。

## **2.1**

## **用提示词提高命中率**

[PRE9]
