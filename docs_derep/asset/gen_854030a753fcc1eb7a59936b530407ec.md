Faiss 实战拆解：IVF、PQ、IVF-PQ 选谁更快更准

向量检索做大了就离不开 Faiss。最近把几套主流索引跑了一遍，用 1 万条 128 维随机向量做小规模验证，再用 100 万条 126 维数据做大规模压力测试，结论很清晰：IVF 管粗筛，PQ 管压缩，IVF-PQ 合体才是生产环境的主力，分片则是水平扩容的平替思路。

小规模对比：倒排平面 vs 产品量化，效果几乎重合
先用 10000 条 128 维数据搭起 IndexIVFFlat，聚类数设为 100，nprobe 固定在 10。训练后加入全部向量，Top5 查询的第一名稳定在索引 2734 附近，距离约 1.27，后面几名依次是 9985、7356、5621、3459 左右，距离都在 1.27-1.28 区间。

换成 IndexPQ，同样 10000 条数据，子向量划分 8 维、8bit 量化，训练与写入流程一致。查询出来的前五名和 IVF 的排序高度一致，距离数值也只在小数点后产生微小波动。说明在数据量不大时，量化带来的压缩并不会明显牺牲召回，存储与查询速度却明显获得。

参数调优很直接：nlist 和 nprobe 一起拉
把倒排的聚类数从 100 提升到 200，nprobe 从 10 提到 20，索引重建后查准率更稳。聚类越细、搜索的聚类越多，召回提升的同时查询耗时线性增长，这个 trade-off 在实测中非常明显。

大规模场景：IVF-PQ 多级索引扛百万级
数据量拉到 100 万条、维度 126 时，直接用纯 IVF 会很重。用 IndexIVFPQ 把倒排和产品量化叠起来：1000 个倒排聚类，PQ 拆成 16 个子向量，每个子向量 6bit 量化。训练、写入 100 万向量后，nprobe 设为 20 做查询。Top5 结果出现的是 963427、453769、127354、765234、112234 这一类索引，距离大致在 1.43-1.47 之间，证明多级方案在百万级下仍能稳定返回相近邻。

分片策略：把一个大索引拆成多个小索引并行查
另一种扩容思路是分片。将 100 万向量均分 4 份，每份 25 万，分别建独立的 IndexIVFFlat，聚类数保持 1000，单片 nprobe 设为 10 保证速度。各片独立训练写入后，对同一查询向量逐片取 Top5，再把全局索引号做偏移校正并合并排序。最终合并后的全局前五名与 IVF-PQ 的结果完全一致，索引号和距离都对上，说明分片在保证一致性的前提下可以横向提速。

小结
1 万级验证里 IVF 平面与 PQ 在召回上几乎打平，PQ 更省存储。调大 nlist、nprobe 能有效提升查准。百万级生产场景，IVF-PQ 是性价比最高的组合，分片则提供更灵活的水平扩展路径。选型时先看数据量、延迟要求和内存预算，三者配合基本能覆盖大部分检索需求。

# 设置nprobe参数：nprobe越大，精度越高，但查询时间也会增加

index_ivf.nprobe=10  # 在10个聚类中搜索

import numpy as np

import faiss

# 设置随机种子和大规模数据集

np.random.seed(42)

dimension=126 # 向量维度

num_vectors=1000000 # 大规模数据集

data_vectors=np.random.rand(num_vectors, dimension).astype('float32')

# 查询向量

query_vector=np.random.rand(1, dimension).astype('float32')

# Step 1: 构建多级索引(倒排索引+产品量化)

num_clusters=1000 # 聚类数量

index_ivf_pq=faiss.IndexIVFPQ(faiss.IndexFlatL2(dimension), dimension, num_clusters, 16, 6)

# IndexIVFPQ参数: dimension(向量维度), num_clusters(倒排聚类数), 16(PQ的子向量数), 6(每个子向量的量化位数)

# 训练多级索引

index_ivf_pq.train(data_vectors) # 必须先训练索引

index_ivf_pq.add(data_vectors) # 添加数据

print("多级索引(倒排+产品量化)已添加向量总数:", index_ivf_pq.ntotal)

# 设置nprobe参数增加搜索精度

index_ivf_pq.nprobe=20 # 在20个聚类中搜索

# 执行查询, 查找Top-k最近邻

k=5

distances_pq, indices_pq=index_ivf_pq.search(query_vector, k)

print("\n多级索引(倒排+产品量化)查询结果(Top 5最近邻): ")

# Step 2: 使用分片策略构建索引

# 将数据分为若干分片, 每个分片构建一个独立索引

num_shards=4

shards=[faiss.IndexIVFFlat(faiss.IndexFlatL2(dimension), dimension, num_clusters) for _ in range(num_shards)]

# 将数据分配到各个分片

for i, shard in enumerate(shards):

    shard_data=data_vectors[i * (num_vectors // num_shards): (i+1) * (num_vectors // num_shards)]

    shard.train(shard_data)                 # 每个分片单独训练

    shard.add(shard_data)

    shard.nprobe=10                         # 设置较小的nprobe, 提升各分片内的查询速度

    print(f"分片 {i+1} 已添加向量数量:", shard.ntotal)

# 通过分片执行查询

results=[]

for i, shard in enumerate(shards):

    distances, indices=shard.search(query_vector, k)

    # 记录分片中的结果

    for j in range(k):

        results.append((indices[0][j]+i * (num_vectors // num_shards), distances[0][j]))

# 排序并返回整体Top-K结果

results=sorted(results, key=lambda x: x[1])[:k]

print("\n分片索引查询结果 (Top 5最近邻): ")

for idx, dist in results:

    print(f"全局向量索引: {idx}, 距离: {dist:.4f}")
