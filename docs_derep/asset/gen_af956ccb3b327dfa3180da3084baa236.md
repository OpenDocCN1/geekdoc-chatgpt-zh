区域销售差异的方差检验案例

> 设想一家电商企业想弄清楚北京、上海、广州、深圳四个市场的销售额是否真的有差别，从而调整投放策略。手头的样本数据如下：

地区 销售额（万元）
北京 120，130，110，140，125
上海 115，125，130，120，135
广州 105，110，115，120，125
深圳 130，140，135，125，130

需要你算出推理过程和结果。

DeepSeek 的处理路径是这样的：

1）整理数据并算均值：把数据归类后求各地区平均和整体平均。北京平均125万元，上海平均125万元，广州平均115万元，深圳平均132万元，整体平均124.25万元。均值初显了各市场销量的集中位置。

2）计算平方和：
① 组间平方和 SSB：反映地区之间波动，公式 $SSB = \sum_{i}^{n} n_i (X_i - \overline{X})^2$，算得 SSB = 733.75，用来量化地区间的差异幅度。
② 组内平方和 SSW：反映每个地区内部的离散，北京、上海、广州、深圳的组内平方和分别为500、250、250、130，加总 SSW = 1130，体现了内部波动。
③ 总平方和 SST：$SST = SSB + SSW = 1863.75$，概括了全部数据的变异。

3）自由度：组间 dfB = 4 - 1 = 3；组内 dfW = 20 - 4 = 16；总计 dfT = 20 - 1 = 19。自由度为后续检验提供依据。

4）均方：组间均方 MSB = SSB / dfB ≈ 244.58；组内均方 MSW = SSW / dfW = 70.625，为 F 值计算做准备。

5）F 检验与结论：F ≈ 3.46。在显著性水平 α = 0.05 下，dfB=3、dfW=16 的临界值约 3.24。因为 3.46 > 3.24，拒绝原假设，说明不同地区的销售额存在显著差异，为区域化营销提供了数据支撑。

整体来看，DeepSeek 先把数据摆成便于计算的形态，再算出各区均值，北京和上海同为125万元，广州115万元，深圳132万元，整体124.25万元，初步看出差异。随后给出 SSB 733.75、SSW 1130、SST 1863.75 及各自自由度，经均方换算得到 F≈3.46，结合临界值 3.24 得出地区差异显著的结论。流程体现了数据处理、统计推断和结果解读的高效专业。
