## 8.7 本章小结

模型与提示词是 Stable Diffusion 绘画的决定性要素，对成图质量影响极大，通常先要确定选用哪款模型。模型大致可分为大模型和 LoRA 等，基础大模型可独立使用，LoRA 类则需配合大模型使用。

提示词定义画面内容，可为关键词加权，也能让两组词在采样过程中交替作用，便于融合不同人物的特征。

本章通过若干实践案例展示了 Stable Diffusion 的表现范围与操作思路，让读者对能画什么、怎样画有了初步认知。受篇幅限制示例有限，实际上只要匹配合适的模型与提示词，几乎可以生成任意风格、任意类型的图像。Civitai 等社区汇聚了大量创作者分享，在那里可以观摩更多案例并学习技巧。

### 9.4 姿势控制

使用一段时间后会发现，仅靠文字很难精确控制人物姿势，部分动作难以描述，或即使描述了 AI 也理解不准。如何让人物摆出指定姿势？借助 ControlNet 就可以实现。

#### 9.4.1 什么是 ControlNet

ControlNet 是 Stable Diffusion 的一个扩展，提供了强大的控制能力，例如精确控制人物姿势、将线稿转化为精细图像等。

#### 9.4.2 安装 ControlNet

01 ControlNet 和其他扩展一样，可在 Web UI 界面单击顶部的“扩展”标签页，进入“扩展”界面进行安装。
