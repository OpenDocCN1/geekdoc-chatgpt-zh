树莓派与其它开发板相比，拥有 40 个可用于外设扩展的 GPIO 引脚。GPIO 即 General Purpose Input Output 通用输入/输出，这些引脚是树莓派与外部硬件交互的桥梁。

图 1-3-2　树莓派 GPIO 引脚功能介绍

图 1-3-2 中引脚编号有三种：依物理位置的编号、由 C 语言 GPIO 库 wiringPi 规定的编号、由 BCM2837 SoC 规定的编号。

基于 wiringPi 库用 C 语言操作 GPIO 时，需要采用 wiringPi 的编号。从图可知 wiringPi 中的 GPIO.0 对应物理编号 11。wiringPi 是用 C 编写的 GPIO 访问库，使用前需先安装。

使用 Python 控制 GPIO 则常用 RPi.GPIO。该库的 API 可实现 GPIO 编程，简言之它是一个控制树莓派 GPIO 通道的模块，系统默认已安装，可直接调用。Python 支持两种编号方式 Board Pin 与 BCM GPIO。

若选用物理编号 BOARD，可把引脚指定为“BOARD11”。

编写程序前要先设定编号类型，常用两种：

`GPIO.setmode(GPIO.BOARD)`　#设置 GPIO 模式为 BOARD

`GPIO.setmode(GPIO.BCM)`　#设置 GPIO 模式为 BCM

若系统中缺少 RPi.GPIO，先在终端执行 `sudo apt update` 升级系统，完成后执行 `sudo apt install python3-gpiozero` 安装 Python3 相关模块。

图 1-4-3　PCF8591 模块介绍

PCF8591 是单片单电源低功耗 8 位 CMOS 数据采集器件，含 4 个模拟输入、1 个模拟输出及 1 个串行 I2C 接口。A0、A1、A2 三个地址引脚可设定硬件地址，支持最多 8 个器件挂载 I2C 总线。器件通过两线双向 I2C 传输地址、控制和数据，具备多路复用模拟输入、片上跟踪保持、8 位 ADC 与 8 位 DAC 功能，转换速率受 I2C 总线速率限制。

引脚定义：

模块左右各扩展 2 路排针，左边 AOUT 为芯片 DA 输出，AIN0-AIN3 为模拟输入 0-3；右边 SCL 为 IIC 时钟接树莓派 SCL，SDA 为 IIC 数据接树莓派 SDA，GND 接地，VCC 外接 3.3V~5V。

PCF8591 模组集成热敏和光敏电阻，共有 3 个红色短路帽：
P4 套上后接入热敏电阻
P5 套上后接入光敏电阻
P6 套上后接入 0~5V 可调电压
