挑西瓜的直觉，如何变成机器学习的原理

想快速抓住机器学习的核心，可以先从日常选瓜的经验切入。夏天逛市场时挑甜瓜，多数人会先看后敲：看果皮的色彩深浅与蒂部的形态，敲则辨别回声是清脆还是沉闷。反复实践后，靠这几项线索挑中理想瓜的命中率会明显提升。把这种经验化的筛选整理成记录，就是下面这张表。

### 表 2.1 西瓜数据集

| 序号 | 色泽 | 根蒂 | 声响 | 是否好瓜 |
|---|---|---|---|---|

| 1 | 青绿 | 干缩 | 浊响 | 是 |
| 2 | 黑绿 | 干缩 | 浊响 | 是 |
| 3 | 青绿 | 硬挺 | 清脆 | 否 |
| 4 | 黑绿 | 硬挺 | 沉闷 | 否 |
| ... | ..... | ..... | ..... | ..... |

人脑在多次试错后会把零散的观察归纳成一条经验法则，比如“某种色泽配合某种根蒂和某种声响，更可能得到好瓜”。这种归纳实际上是复杂且非线性的神经元网络在起作用。

机器的处理方式则完全不同。计算机只能接受数字信号，只能执行大于、小于、不等于等明确规则，对模糊的感知类判断无能为力。用一个极简的加法训练来示范：

- 问：1+4 等于几？
- 答：20。
- 反馈：不对，偏高。
- 问：1+9 等于几？
- 答：13。
- 反馈：不对，偏高。
- 问：3+4 等于几？
- 答：7。
- 反馈：对了。
- 问：6+9 等于几？
- 答：13。
- 反馈：不对，偏低。

反复很多轮以后……
问：2+2 等于几？
答：4。
问：4+5 等于几？
答：9。

这正是机器学习里最常见的范式，被称为有监督机器学习。所谓监督，就是训练时数据会给出正误的回馈。前几次相当于模型校准，“偏高”“偏低”可视作误差信号，模型据此调整内部参数，这就是反向传播 back propagation 的通俗说法。

综合例子与专业教材的表述，可以把机器学习概括为实现人工智能的科学分支，其本质是通过数据让计算机算法自动提炼规律并持续提升表现。

## 2.1 机器学习概述

按样本是否附带标签，机器学习通常划分为有监督和无监督两大类。有监督需要的数据集除特征外，还必须包含每个样本的真实输出，即标注。若样本没有标注，则只能用于无监督。例如只收集股票的开盘价、收盘价、成交额、成交量、换手率，只能做无监督分析；若再加上涨跌信息用于预测，则适合有监督。

### 2.1.1 有监督机器学习

在有监督场景下，预测结果可能是连续数值，也可能是离散类别。由此可分为回归问题 regression 与分类问题 classification。回归的因变量是数量型，分类的因变量是离散型。

### 2.1.2 无监督机器学习

无监督学习不需要对样本打标签，也不需要验证结果是否正确。其目的是对原始资料进行分组，以便发掘内部结构。最典型的就是聚类，把相似对象聚在一起，我们并不关心这一类具体代表什么。图 2.3 简单展示了聚类的一般结果。

常见无监督方法有 K 均值聚类、主成分分析等。下面以简例说明使用方式。

[PRE7]python

from sklearn import datasets

iris=datasets.load_iris()

X=iris.data

y=iris.target

#1. KMeans 聚类

from sklearn.cluster import KMeans

est=KMeans(n_clusters=8)

est.fit(X)    # 使用 KMeans 算法进行聚类

print(est.labels_)    # 输出类别的标签

#2. PCA

from sklearn import decomposition

pca=decomposition.PCA()

pca.fit(X)    # 使用 PCA 算法进行主成分分析

print(pca.explained_variance_)    # 输出每个指标的解释方差,以便于计算累积贡献率

### 2.1.3 半监督机器学习

有监督学习的样本必须标注，且标注质量直接影响效果；无监督学习无需标注，但只能用于认识结构，无法做预测。现实中当样本量很大时，全部标注成本极高，常出现只有部分样本带标签仍需做回归或分类的情况，这时就需要半监督技术，图 2.4 为半监督机器学习示意图。

[PRE9]

图 2.4 半监督机器学习示意图

半监督机器学习是指学习器不依赖外部交互，自动利用未标注样本提升学习性能的一类方法。sklearn.semi_supervised 包中实现了基于标注传播 Label Propagation 原理的算法。下方以简例说明标注传播的使用方式。

[PRE10]python

import numpy as np

from sklearn import datasets

from sklearn.semi_supervised import label_propagation

rng=np.random.RandomState(0)

[PRE11]

iris=datasets.load_iris()

X=iris.data[:, :2]

y=iris.target

y_30=np.copy(y)

y_30[rng.rand(len(y))<0.3]=-1    # 去掉已有的标注(随机数小于 0.3 的索引)

y_50=np.copy(y)

y_50[rng.rand(len(y))<0.5]=-1    # 去掉已有的标注(随机数小于 0.5 的索引)

ls30=label_propagation.LabelSpreading(kernel='knn', alpha=0.8)

ls30.fit(X, y_30)                # 训练模型

ls50=label_propagation.LabelSpreading(kernel='knn', alpha=0.8)

ls50.fit(X, y_50)                # 训练模型

predicted_labels_ls30=ls30.transduction_    # 输出预测的标注

predicted_labels_ls50=ls50.transduction_    # 输出预测的标注
