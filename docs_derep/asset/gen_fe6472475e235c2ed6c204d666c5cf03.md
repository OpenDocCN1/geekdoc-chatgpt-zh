### 2.1.2 五大常用多模态模型

本节将深入探讨Google AI Studio提供的五大模型：Gemini 3系列、Nano Banana系列、Gemini Live、Veo 2和Gemini TTS。这些模型各有独特能力与应用场景，掌握它们的参数配置与使用技巧，是实现高质量Vibe Coding的关键。

#### 1. Gemini 3系列：最强大的推理引擎

Gemini 3系列是Google推出的高性能推理模型，参数配置丰富，可帮助开发者精细调控AI行为。无论是复杂数学推理、代码生成，还是多模态内容理解，该系列模型均能提供卓越性能。下面介绍其核心参数与功能。

(1) Temperature 温度。

- 参数范围：0～1.0。
- 默认值：1.0。
- 对Gemini 3，Google建议保持默认值1.0。与前代不同，Gemini 3的推理能力已围绕默认设置深度优化，调低温度低于1.0可能导致循环输出、性能下降等异常，复杂数学或逻辑推理任务中风险更高。若需要更保守、确定性更强的输出，需谨慎小幅度测试后再使用。

(2) Thinking level 思考等级。

- 可选值：低 Low、高 High。
- 默认值：高。
- 功能说明：控制模型在生成回答前内部推理的深度。
- 高：最大化推理深度。模型会花费更多时间分析问题，首个Token延迟略增，但输出经过充分验证，适用于复杂逻辑推理、数学计算、深度内容创作等需要精准结论的场景。
- 低：优先缩短响应延迟并降低成本，适用于简单指令执行、日常聊天、高吞吐量批量处理等无需复杂推理的场景，可更快返回结果。

(3) Media resolution 媒体分辨率。

- 可选值：低 Low、中 Medium、高 High、默认 Default。
- 默认值：默认。
- 功能说明：控制AI处理图片、视频等多模态内容的精细程度。分辨率越高，识别细小文字与微小视觉细节的能力越强，但Token消耗与处理延迟也会相应增加。
- 高：适用于需精准识别细小文字、复杂图表、精细视觉细节的场景，如光学字符识别OCR文字提取、医学影像分析、高精度图像内容解读等。
- 中：性能与成本平衡的通用配置，适用于大多数日常图像理解，如普通图片内容识别、常规图表分析等。
- 低：快速处理模式，适用于仅需识别大致内容的场景，如图片主题分类、视频关键信息提取等，可实现最低延迟。

(4) Structured outputs 结构化输出。

启用后，AI会按用户定义的JSON Schema格式返回结构化数据，适用于需将AI输出直接集成到应用的场景。可定义字段类型、必填项、字段描述等，确保输出符合预设数据结构。Gemini 3支持将结构化输出与内置工具如Google搜索、URL上下文结合，帮助获取实时数据并以结构化格式返回。

**注意：** 启用结构化输出后，不可同时启用代码执行功能，二者互斥。

(5) Code execution 代码执行。

允许Gemini 3在回答时自动编写并执行Python代码以解决复杂任务。例如要求“计算斐波那契数列第100项”时，AI会自动生成并运行代码并返回结果。适用于数学计算、数据分析、算法验证等场景。

**注意：** 此功能与结构化输出互斥，不能同时启用。

(6) Function calling 函数调用。

允许自定义函数，支持Gemini 3在需要时调用以获取外部数据或执行特定操作。例如定义“查询天气”函数后，用户询问“今天天气怎么样”时，AI会自动调用函数获取实时天气数据。这是构建智能应用的核心功能之一。

**注意：** 此功能与当前激活的部分功能不兼容，使用时需注意功能组合搭配。

#### 2. Nano Banana系列：将文字变成精美图像

Nano Banana系列是Google的图像生成模型，包括 Gemini 3 Pro Image Nano Banana Pro Preview 与 Gemini 2.5 Flash Image Nano Banana 两个版本。两者均支持文生图、图生图及多轮对话式编辑，可生成高质量图像，并能渲染清晰文字。

**重要提示：** Nano Banana Pro仅支持调用付费API Key，而Nano Banana版本中可调用免费API Key。

Nano Banana Pro与Nano Banana的共同参数配置如下。

（1）Temperature 温度。

- 参数范围：0～1.0。
- 默认值：1.0。
- 与Gemini 3系列相同，用于控制图像输出的创造性与随机性。温度越高，图像创意性、多样性越强；温度越低，输出越稳定、可预测。

（2）Aspect ratio 宽高比。

支持多种常见比例，可根据场景选择。

- 1：1 正方形：适合社交媒体内容、头像、图标等。
- 2：3、3：2：适合海报、印刷品等。
- 3：4、4：3：适合传统照片。
- 4：5、5：4：适合Instagram竖版图片。
- 9：16 竖屏：适合手机端展示、Instagram Stories等。
- 16：9 宽屏：适合网页横幅、视频缩略图等。
- 21：9 超宽屏：适合横幅广告、宽屏展示等。

Nano Banana Pro的独有参数如下。

（1）Image size 分辨率。

- 支持1K、2K、4K三种分辨率。默认生成1K图像，如需更高质量可指定2K或4K。
- 适用场景：更高分辨率适合印刷品、大屏展示或需要后期裁剪的场景。

**注意：** 参数中必须使用大写字母“K”，如1K，小写“k”会被系统拒绝。

（2）Grounding with Google Search Google搜索增强。

与Gemini 3系列参数相同。在图像生成场景中，可通过Google搜索进行事实核查，确保生成图像符合真实世界规律。

Nano Banana Pro与Nano Banana均支持对话式编辑与文字渲染，均可生成高质量图像，核心差异集中在生成速度、分辨率上限及高级功能支持上，可根据项目需求与预算灵活选择。

选择Nano Banana Pro可考虑：

- 需要高质量输出 2K、4K 分辨率。
- 需要借助实时数据增强 Google搜索增强。
- 需要模型具备复杂推理能力。
- 可接受稍长生成时间及付费API Key成本。
- 适用场景：专业级资产制作，如营销设计、数据可视化、产品原型等。

选择Nano Banana可考虑：

- 需快速响应与高吞吐量。
- 注重成本优化，使用免费API Key。
- 1K分辨率已满足需求。
- 适用场景：快速原型制作、社交媒体内容、游戏素材、电商配图等高频场景。
