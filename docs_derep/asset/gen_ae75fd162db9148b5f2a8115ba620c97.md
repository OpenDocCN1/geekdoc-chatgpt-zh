# AI大师们如何定义人工智能？

回顾发展历程，权威专家们从不同视角给出了经典注脚：

*   **Haugeland (1985)：** 视AI为让计算机具备思维、赋予机器智力的激动人心的探索。
*   **Charniak与McDermott (1985)：** 将其界定为利用计算模型来剖析智力行为的学问。
*   **Winston (1992)：** 认为核心在于研究支撑理解、推理与行动的计算机制。
*   **Kurzweil (1990)：** 强调其是能执行需人类智力任务的创造性机器技术。
*   **Rich与Knight (1991)：** 聚焦于如何让计算机完成工作以优化人类生活。
*   **Schalkoff (1990)：** 定义为通过计算过程理解并模仿智能行为的学科。
*   **Luger与Stubblefield (1993)：** 将其归类为计算机科学中专注于智能行为自动化的分支。

**Russell教授的“双维坐标系”**

在《人工智能》教材中，Stuart Russell教授从两个维度梳理了上述定义：
1.  **关注点维度：** 是着眼于机器内部的**思维推理**，还是外部的**行为表现**？
2.  **评判标准维度：** 衡量智能的准则，是**拟人化**（像人），还是**合理性**（做对事）？

由此衍生出四大经典流派：

| 流派 | 核心主张 | 关键路径 |
| :--- | :--- | :--- |
| **拟人行为** | 让机器在感知、交互、决策上“以假乱真” | 图灵测试 |
| **拟人思维** | 复刻人类大脑的认知过程 | 认知科学、脑成像、心理实验 |
| **合理思维** | 遵循严格逻辑法则进行正确推理 | 逻辑学、形式化推理系统 |
| **合理行为** | 以达成最优结果为唯一导向，不拘泥于人类模式 | 智能体理论、效用最大化 |

### 概念辨析：广义 vs 狭义，弱 vs 强 vs 超

**覆盖范围看：**
*   **广义AI：** 囊括感知、推理、学习、规划、适应、进化等全谱系能力，特征是多学派、多功能、多层次。
*   **狭义AI：** 将各细分领域、单一学派分支单独称为AI。

**发展阶段看：**
*   **弱人工智能（ANI）：** 单点突破的“专才”。如AlphaGo围棋称霸、Siri语音助手，**只在特定领域超越人类**。
*   **强人工智能（AGI）：** 具备人类级别的“通才”。拥有思考、规划、抽象理解、快速自主学习等**通用认知能力**。
*   **超人工智能（ASI）：** 全面超越人类智力的终极形态。

### 关系图谱：AI、机器学习、深度学习、机器人

**核心层级关系：**
> **人工智能 ⊃ 机器学习 ⊃ 深度学习**

*   **AI：** 打造智能机器的宏大目标与学科。
*   **机器学习：** 实现AI的核心**手段**——无需显式编程，从数据中自动学习提升性能（Samuel定义），将无序数据转化为有序信息，随经验积累自动改进。
*   **深度学习：** 模拟大脑神经网络的机器学习**进阶技术**，是当前第三次AI浪潮的核心驱动力。

**智能机器人 = AI大脑 + 物理躯干**
它是AI技术的“综合试验场”，不拘泥于人形，能感知-思考-行动，替代人类执行高危、极限任务。

### 学术流派演进：从四分法到“六大派系”

David Alangreil早年提出四类：传统符号AI、人机交互AI、集体智慧AI、机器学习AI。

立足未来发展，**现代学术界主流划分为六大流派**：
1.  **符号学派：** 逻辑推理、知识工程（传统AI正统）。
2.  **连接学派：** 神经网络、深度学习（当前主流）。
3.  **行为学派：** 智能体、强化学习、从环境交互中学习。
4.  **群体智能学派：** 蚁群算法、协同进化、多智能体系统。
5.  **统一人工智能学派：** 追求单一架构通解智能（如AGI路线）。
6.  **混合智能学派：** **人机混合增强智能**，强调人机协同，优势互补（**国家战略重点方向**）。
