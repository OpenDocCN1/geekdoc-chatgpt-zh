# 第八章 数据安全责任与保护

## 第七十八条 【数据安全责任主体】

本市推行数据安全责任制，数据处理者是数据安全责任主体。

数据同时存在多个处理者的，各数据处理者承担相应的安全责任。

数据处理者发生变更的，由新的数据处理者承担数据安全保护责任。

[PRE0]
本条对数据安全责任主体的一般情形、多主体共同处理情形等作了概括性安排，旨在明确权责边界。

[PRE1]
数据安全责任制是指数据处理者在数据处理全过程中，对数据安全负总责的制度安排。

[PRE2]
本条作为条例第八章的开篇条款，用三款分别对应一般情形、多主体共同处理情形、主体变更情形。从适用范围看，涵盖一切数据处理行为，公共数据与企业数据均在内，收集存储使用加工以及传输提供公开共享等环节均被纳入。从责任内涵看，主要指处理者在处理过程中对所处理数据的保护义务，不包括监管职责。

### 一、一般情形下的数据安全责任主体

根据《上海市数据条例》第3条与《数据安全法》的界定，数据安全是指通过必要措施使数据处于有效受保护且合法利用的状态，并具备持续保持安全的能力。数据安全不是一成不变的静态目标，而是状态与能力的动态组合。在大数据时代，数据安全的重要性愈发凸显，以“徐玉玉案”与滴滴网络安全审查为代表的案例，让数据篡改破坏、泄露毁损、不当使用防范成为社会共识，确立“数据安全责任制”具有现实紧迫性。安全责任制在我国最早可追溯至安全生产责任制，1997年《关于认真落实安全生产责任制意见的通知》及《安全生产法》确立的核心是“管生产必须管安全”“谁主管谁负责”，这一机制至今仍是生产规范的关键支柱。

在数据安全领域，责任制的基本逻辑与安全生产相近，旨在形成层层落实、人人尽责、各负其责的管理体系。号召“谁所有谁负责、谁存储谁负责、谁管理谁负责、谁使用谁负责、谁收集谁负责”，把安全责任压实压细。《数据安全法》第6条明确各地区各部门的数据安全主体责任，并以第四章第27条至第36条细化了主体责任的具体义务，包括公共利益遵循、风险处置、重要数据处理者的评估等。中国正加紧制定《网络数据安全管理条例》，以落实《网络安全法》《数据安全法》《个人信息保护法》等要求。2021年11月发布的《网络数据安全管理条例》征求意见稿第6条第1款规定：“数据处理者对所处理数据的安全负责，履行数据安全保护义务，接受政府和社会监督，承担社会责任。”同样强调了处理者的主体责任。安徽、山西、贵州等地的数据条例亦确立了数据安全责任制，由处理者承担保护主体责任。

总之，守牢数据安全生命线的前提是主体责任落地。条例首先明确由数据处理者承担数据安全主体责任，为后续具体保护义务筑牢基础，推动数据安全制度框架有效构建。

### 二、特别情形下的数据安全责任主体

第2、3款明确了多主体共同处理与主体变更情形下的责任归属。

数据处理活动中存在多个处理者时，各方承担相应安全责任。目的在于防止个别企业通过设立或联合多个主体规避保护义务，避免数据因多方共同处理而陷入监管空白。无论多方主体形成原因、关系紧密程度、处理行为是否一致，均须履行应有保护义务。所谓“相应责任”可从两个层面理解：一是各主体按其实际处理行为承担对应保护责任；二是因未履行义务造成损害，承担相应的损害赔偿责任。

首先，责任应与实际处理行为挂钩。数据安全风险贯穿处理全流程，须落实全生命周期保障。保护义务源于事实处理行为，由实际执行者承担与其行为相对应的责任，既能将安全保护嵌入处理过程，避免互相推诿，也更符合技术落地与经济可行性。

其次，除合规行政责任外，未尽义务导致损害还衍生民事赔偿责任。实践中可参照《个人信息保护法》第20条，通常应依据《民法典》承担连带责任，个别情形可按份责任。共同处理者之间对义务负担与责任分担的约定系内部安排，不能对抗受损个人。

另外，数据处理者变更时，由新主体继受保护责任。现实中处理者多为政府部门、企业法人或非法人组织，机构改革、企业合并分立解散破产等变更十分常见。条例明确安全责任不因主体变更而免除。类似规则在《个人信息保护法》第22条也有体现，处理者因合并分立解散被宣告破产等转移个人信息的，接收方须继续履行原处理者义务。需注意，本款仅适用于主体变更，若主体未变仍适用第2款，如委托处理中，受托方虽为主要处理者，委托方的数据安全保护义务并不免除，依据前款双方均应承担相应责任，违约致损的应依《民法典》承担连带责任。

## 第七十九条 【数据安全保护义务】

开展数据处理活动，应当履行以下义务，保障数据安全：

（一）依照法律、法规的规定，建立健全全流程数据安全管理制度和技术保护机制；
（二）组织开展数据安全教育培训；
（三）采取相应的技术措施和其他的必要措施，确保数据安全，防止数据篡改、泄露、毁损、丢失或者非法获取、非法利用；
（四）加强风险监测，发现数据安全缺陷、漏洞等风险时，应当立即采取补救措施；
（五）发生数据安全事件时，应当立即采取处置措施，按照规定及时告知用户并向有关主管部门报告；
（六）利用互联网等信息网络开展数据处理活动，应当在网络安全等级保护制度的基础上，履行上述数据安全保护义务；
（七）法律、法规规定的其他数据安全保护义务。

[PRE4]
本条对数据处理活动的合规性提出了明确要求，为不同主体设置了安全保护义务，并对风险管控和事件处置作出安排。

[PRE5]
数字经济时代，数据已成为驱动经济社会创新的关键要素，经济价值与战略价值快速提升，数据安全成为国际竞争与合作的核心议题，网络安全与数据安全上升为数据管辖的新焦点。

### 一、数据安全保护义务的履行方式

第1项“依照法律、法规的规定”主要对应《数据安全法》第27条要求建立全流程数据安全管理制度。其中“全流程”涵盖生产、加工、筛选、分析、整合、处理、转让等各环节，任一环节都可能出现泄露、遗失、窃取、篡改，要求过程管理贯穿始终。该项要求处理者建立健全管理制度与技术保护机制，重点保护国家安全和个人隐私相关数据，严格监管采集、存储、流动、使用各环节。

第2项要求组织开展数据安全教育培训。当前具备合规与保护能力的专业人才供给不足，企业难以满足实际需求。推进数据安全理念文化建设，依托专业培训服务定期开展人才培养与资质认证，是满足监管要求、补足能力短板的重要途径。

第3项要求采取技术措施与其他必要措施确保数据安全。结合《网络安全法》第21条，“技术措施”包括防范计算机病毒、网络攻击、网络入侵等危害的技术手段，以及监测、记录网络运行状态与安全事件的技术手段。“其他必要措施”在《计算机场地安全要求》GB/T 9361—2011中指向互联网数据中心的物理安全防护，包括供电系统、消防系统、网络接口安全等。通过技术支撑防止数据被篡改、泄露、毁损、丢失或非法获取利用。比较法上，GDPR第25条亦要求以技术设计实现数据保护，第30条明确处理活动记录责任。

### 一、网络安全等级保护义务

第6项要求利用互联网等信息网络开展数据处理活动时，应在网络安全等级保护制度基础上履行数据安全保护义务。《网络安全等级保护条例征求意见稿》第15条将网络划分为五个等级：一级破坏后影响公民法人合法权益但不危害国家安全社会秩序公共利益；二级破坏后造成严重损害或对社会秩序公共利益造成危害但不危害国家安全；三级破坏后造成特别严重损害、严重危害社会秩序公共利益或危害国家安全的重要网络；四级破坏后对社会秩序公共利益造成特别严重危害或对国家安全造成严重危害的特别重要网络；五级破坏后对国家安全造成特别严重危害的极其重要网络。

因此处理者应根据网络遭破坏后对社会与国家的影响，采取相应的安全保障措施，满足等级保护要求，在此基础上切实履行本条规定的各项保护义务。

### 二、风险处置义务

第4、5项对应《数据安全法》第29条，分别规定风险监测义务与安全事件应急响应义务。要求加强风险监测，及时发现缺陷漏洞并补救；发生安全事件时立即处置、及时告知用户并向主管部门报告。
