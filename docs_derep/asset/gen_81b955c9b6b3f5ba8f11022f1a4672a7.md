## 6.4 别只盯着向量索引

向量存储索引是 RAG 的主流，但在很多场景下需要结合其他索引类型提升检索能力。下面介绍几种常见类型及其用法。

### 6.4.1 摘要索引实战

文档摘要索引的工作方式是借助大模型把传入的 Node 列表生成摘要 Node，并将其向量化后存入向量库，提供摘要 Node 的向量检索能力，同时支持从摘要 Node 回溯到原始 Document 和基础 Node。
