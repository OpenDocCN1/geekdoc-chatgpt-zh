## 对话实录

通俗解析

先看第二个式子：

② x + y = 5

比较直接，可以先把y用x表示，再代入第一个方程。

第一步：由②式变形。

x + y = 5

→ y = 5 - x

第二步：代入①式。

把 y = 5 - x 代入第一个方程

x² + y = 7

→ x² + (5 - x) = 7

→ x² - x + 5 = 7

→ x² - x - 2 = 0

这是一个一元二次方程，用因式分解法求解：

x² - x - 2 = 0

→ (x - 2)(x + 1) = 0

→ x = 2 或 x = -1

第三步：回代求y。

当 x = 2 时，y = 5 - 2 = 3

当 x = -1 时，y = 5 - (-1) = 6

答案

该方程组得到两个解：(2，3) 和 (-1，6)。

类似题目练习

解方程组：

- ① x² + y² = 13

- ② x + y = 5

解方程组：

- ① x² - y = 3

- ② x - y = 1

需要这两题的详细讲解也可以继续提问。

## 使用贴士

- (1) 描述越具体，效果越好：建议以“题目+卡壳点+已知条件”的组合输入，如“初中物理，动能计算题，不清楚公式如何选用”。
- (2) 善用错题库：将平时做错的题目定期导入错题知识库，智能体可帮助复盘易错点，形成个性化讲解路径。
