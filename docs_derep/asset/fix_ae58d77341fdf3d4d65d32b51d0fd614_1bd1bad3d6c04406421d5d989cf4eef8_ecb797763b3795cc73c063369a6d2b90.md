# 9.5 盲盒手办：萌系潮玩新风口

盲盒因开盒结果不可预知而在年轻人群中持续走红，核心卖点正是盒内那只造型独特的手办，这类模型本身就具备收藏价值。

从酷炫机甲到时尚美少女，再到呆萌卡通动物，随机掉落的角色总能契合年轻人善变的审美偏好。

盲盒手办可使用如下提示词。

## 盲盒手办提示词

| 角色设定 | 一个女孩、一个男孩、美少女战士、孙悟空等 |

| --- | --- |

| 风格细节 | 包括：体型、发型、穿着、动作、表情等 |

| 例如：胖嘟嘟，长发，白色连衣裙，坐在沙发上，开心 |

| 描述词汇 | 最佳质量、杰作、8K 等 |

> 注意

在 Vega AI 中制作盲盒手办画面，通常先选用基础模型 “3D 二次元”，再配合 3D 人物相关的风格标签，比如：“人偶手办”“Q 版盲盒”“3D 卡通风格”“可爱美少女手办” 等，这些标签都能在风格广场里检索并收藏。若想提升多样性，还可以尝试 “国风写真”“森系女孩”“高达机甲” 等不同风格组合。

# 9.5.1 动漫角色联名手办制作

想要把心仪的动漫形象做成联名盲盒，手办图也能交给 AI 完成。因为主流模型训练时已覆盖大量经典角色，通常直接在提示词里写出角色名称即可引导生成对应画面，下面以美少女战士盲盒设计为例。

# 提示词

美少女战士，单人，站在白色圆形舞台上，最佳质量，大师之作

# 重点参数

基础模型：虚拟建模。风格：Q版盲盒。

[PRE12]

若需调整手办的服饰或细节，只需在风格描述里追加对应关键词即可。
