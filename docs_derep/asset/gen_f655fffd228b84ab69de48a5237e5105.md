# 用DeepSeek打开AI世界：学习·创作·职业三合一指南

# 本书速览

这是一本面向AI新手的实操入门，以市场热度极高的模型DeepSeek为主线，依托大量案例和通俗化讲解，对AI知识进行系统梳理，帮助读者跳出认知误区，快速掌握可用技巧，抓住时代机遇。书中不仅拆解DeepSeek的特质与影响，也把AI延伸到学习、生活、内容创作等场景，帮助提升学业与工作效率、实现自媒体表达。另为想进入AI行业的人准备了岗位认知与转型攻略。

读完后能把方法直接落地。不论是学生还是职场人，都可以跨过技术门槛，在浪潮中抢占先机。

# 前言

作为一名长期做科技直播的博主，我在分享AI工具使用心得时，明显感受到大家对AI的热度与求知欲。

可当我被问到“能推荐一本靠谱的AI入门书”时，我却犹豫了。市面上有偏重操作的，方法论不足；也有偏重方法论科普的，实操讲解不够。两者各有亮点，但我希望能找到一本既授人以鱼又授人以渔、方法与实践兼顾的作品。这个想法促使我决定动笔。

在构思不久后，我做的一期DeepSeek使用教程视频在视频号获得超600万人次播放，其他AI相关内容反响也不错。读者的认可给了我很大信心。

正式写作前，我和两位合伙人做了扎实调研。在多个内容平台检索并梳理了1000多篇与DeepSeek相关的视频和文章，基于标题与评论提炼出用户最关心的痛点，再据此整理可用的实操技巧，让本书更具实用性。

书中除DeepSeek外，也会推荐其他AI产品。我们的原则很简单：只有自己愿意推荐给亲友使用的产品，才会写入书中。

全书共四个板块。

第一板块是第一章，围绕DeepSeek展开，解析其特性和对AI乃至未来的影响，为后续学习打底。

第二板块是第二章，聚焦AI的学习思路，同时介绍AI在日常生活中的用法，让读者建立正确的方法观并感受AI与生活的联结。

第三板块是第三章至第五章，分别从学习、职场、内容创作三个视角，详解AI的具体应用，用真实案例展示如何提效、激发创意、解决实际问题。

第四板块是第六章，面向有意进入AI行业的读者，介绍门槛相对低的岗位与可操作的转型路径，帮助把握职业机会。

“纸上得来终觉浅，绝知此事要躬行。”AI是极强的实践型技术，理解概念后仍需不断练习，将其融入生活与工作。若你此前未接触过AI也不必紧张，日常问题其实并不难用AI解决。

本书得以完成离不开团队协作。调研与整体规划由三位作者共同完成。案例收集与初稿阶段，张世锟负责第一、二章，郑瑞菲负责第三章，郭浩然负责第四、六章，第五章由三人合力完成。郭浩然统筹全书梳理，张世锟整理案例与配图，郑瑞菲负责润色与审校。

最后感谢编辑林舒媛老师的悉心指导，也感谢师弟黄琪兴和同学张一航在写作期间提出的宝贵建议，正是有了他们的帮助，内容才更完善。

愿本书成为你探索AI的得力伙伴，带你开启AI世界的大门。

### 1.1.1 解读DeepSeek爆火背后的底层逻辑

DeepSeek发布前，全球主流思路是“砸钱买芯片、堆算力提能力”，成本极高。以ChatGPT为例，订阅价每月20美元，约合百多元人民币，对普通用户不友好。而DeepSeek从发布到成书期间一直免费。

以下拆解DeepSeek的独特之处，以及它如何做到又好用又便宜。

❶技术创新提升能力
DeepSeek的强劲表现是多项技术叠加的结果，这里用通俗比喻介绍三项，技术细节可跳过。

1. 设计巧妙的模型结构
传统AI像一位博览群书的“通才”，面对任何问题都全盘思考，模型全量运行，成本高。DeepSeek更像一支专家团队，每位“专家”擅长不同领域。用户提问时，系统只唤醒相关“专家”，部分运行即可，高效省资源。

2. 强大的推理能力
DeepSeek具备“自主学习”能力。它会尝试多种解法，错了就调整，对了就记忆，像人一样举一反三。传统大模型往往直接输出结果，而DeepSeek在给出答案前会进行深度思考，在数学、编程等复杂任务上表现更优。图1.4为不同模型在典型任务上的得分对比。

多数公司训练模型依赖英伟达显卡，受限于采购，国内企业难以获得最先进卡。受限条件下，DeepSeek另辟蹊径，通过技术手段优化显卡使用效率，大幅提升算力，有观点认为其对显卡的理解甚至超过硬件厂商。
