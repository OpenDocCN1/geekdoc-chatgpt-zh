（1）设计思路
以释意理论为核心，构建以意义优先为导向的评估框架，通过多模块协同实现自动化评测。系统侧重原文意义重构、术语准确性、语言流畅度及策略运用，结合AI生成的参考译文与术语表，输出多维评估报告与改进建议。

（2）工作流
1）输入：source_text（英语原文）与 interpreted_text（学生口译译文）。
2）参考译文生成（Deepseek-V3）
输入：source_text
输出：target_text_ref（参考译文）
【提示词】
你是一位精通“释意理论”的英汉专业口译员。请通读整段英语文本，识别其主旨、结构、情感及文化特征，跳脱字面结构提炼核心意义，用地道、自然、连贯的汉语进行整段式重构。译文需相对正式，避免逐句对应。
输出格式：
【参考译文】：[译文内容]
【释意说明】：[处理文化比喻、语义偏移的策略说明]
3）术语提取（Deepseek-R1）
输入：source_text 与 interpreted_text
输出：glossary（英汉术语表）
【提示词】
从英语原文提取专业术语，生成英汉对照表（格式：英语，汉语），无须参考学生译文。
4）译文评估（Deepseek-R1）
输入：source_text, target_text_ref, interpreted_text, glossary
输出：evaluation_report（评估报告）
【提示词】
基于以下维度评估口译质量：
a.准确性（信息完整度、逻辑一致性）
b.流畅性（语言自然度、逻辑衔接）
c.词汇语法（专业术语、句式结构、文化适应性）
d.策略应用（交替传译策略分类：TypeA 推荐/TypeB 较推荐/TypeC 不推荐）
e.术语规范性（对照术语表检查一致性）
输出：结构化报告，包含评分（X/5）、优缺点总结及改进建议。
注：交替传译策略库
TypeA（推荐）：意义重组、文化负载词替换、逻辑显化
TypeB（较推荐）：信息补全、冗余省略
TypeC（不推荐）：逐词直译、结构硬套
