# 第二章 存在论认知：核心概念拆解

上一章梳理了认知科学里主流的研究路线和进路，可以看出对传统认知主义和联结主义的质疑，背后其实在发生一次哲学底层的换血。批判的潮流不再停留在技术层面，而是把笛卡尔理性主义的框架慢慢替换成现象学、维特根斯坦的日常语言哲学以及杜威经验自然主义的混合体，其中现象学的分量被看得最重。

先前我们聊过胡塞尔的先验现象学和自然化现象学，这两者在对待自然主义的立场上就自相矛盾。现象学最核心的立场，是反对把世界劈成主客二分的自然主义认识论和随之而来的客观主义倾向，它把主体与客体相互依存的意向性关系确立为比二分更原初的基础联系。[^(\[1\])](#chapter003.html#m1)

在我看来，胡塞尔滑向先验唯心主义之后，现象学很难再承担实证认知科学的哲学基座。他把一切意义的根源都收归到先验主体性里，这种主体性本质上是笛卡尔“我思”的升级版。世界的一切都在主体性的创造里生成，都是先验自我的成果，先验自我成为世界可能性的必要条件。正是因此，胡塞尔把一切独立于心智而存在的属性都剥离掉了。他认为笛卡尔的“自我—我思—我思对象”结构失误在于把自我当成自然世界的一部分，一种“我思物”，一种思维实体，我并非世界的一个物件，世界也并非我的一部分。[^(\[2\])](#chapter003.html#m2)

现象学还原把与自我相关的身体与心理体验全部扫清，只留下作为意义绝对源头的纯粹自我。海德格尔正是对此不满，他追问“存在”的意义，就是要把那种飘忽的先验光环褪去，让人回到具体的生活现场。在他看来，人早已在日常言行里展现了对存在意义的初步领会。自我只能在“此在”的生存流中显现。海德格尔没有像胡塞尔那样把意向性塑造成主动创造的力量，而是从人类生存的角度来理解意向关系，挖掘出意向认知背后更根本的行动维度。

正是这种转向，让存在论现象学为认知科学提供了一种不同于笛卡尔主义的基石。有的学者用一个戏剧比喻来形容：从“心身对立”的笛卡尔剧场，切换到“心灵—大脑—身体—环境—世界”的海德格尔剧场。[^(\[3\])](#chapter003.html#m3) 海德格尔在对“此在”做生存论分析时重新界定了认知，提出“此在”“在世存在”“上手”“现成在手”等全新概念，也重新诠释了“世界”等旧概念。搞清楚核心概念是研究的基础，所以先把几个关键概念的内涵厘清。

## 第一节 此在的三维画像：身体、实践与情境

“此在”源自海德格尔《存在与时间》，德文 Dasein，是他反复使用的关键词。Da 有此时此地、那里、那么等多重指向，sein 就是存在、是。海德格尔刻意选这个生僻词，是为了避开“意识”“心灵”“灵魂”这类容易误导的前见。[^(\[4\])](#chapter003.html#m4)

不能把此在简单等同于“在这里存在”。它的第一义是指人的特殊存在方式，指人这种特殊的存在者。作为此在，人根本的任务是追问存在。海德格尔给出的定义是：在其存在中关怀存在本身意义的存在者。他毕生在追问存在的意义，而要回答这个问题就必须从人即此在出发，因为只有此在能提出存在问题。他说：我们所言、所指、所关联的一切都在存在着，我们自己的所是和如是也在存在着。在实在、现成性、持存、有效性、“此在”、有之中，都蕴含着存在。[^(\[5\])](#chapter003.html#m5)

在一切存在者中，此在享有阐释存在意义的优先权。它与他物存在者的差异在于，只有此在能够理解存在，其他存在者的意义只能通过此在对存在的追问与理解才被打开。所以在我看来，此在是解开存在之谜的唯一钥匙。

当进入认知科学的视野，尤其是具身认知、情境认知等新流派也借用了此在概念时，一个问题就出现了：海德格尔意义上的此在和认知科学意义上的此在是同一回事吗？它能等同于认知主体吗？如果不同，分歧在哪？

### 一 此在的“身体”维度

我的判断是，海德格尔的此在和认知科学语境里的认知主体并不等同，不能随意互换。海德格尔的论述里并没有突出身体的特殊重要性，也几乎不谈“主体”“主体性”。而以具身认知为代表的新认知科学，则把身体放在核心位置，主张用具身机制来描述人的认知过程。身体不是被动旁观、只能注视现象面纱背后东西的旁观者，而是一个主动搭建界面与能力的建筑师。[^(\[6\])](#chapter003.html#m6)

若用海德格尔的视角看，过度强调身体的重要性，可能会错过此在本质的把握。他认为此在的本质在于其生存，此在不能被看作现成存在的存在者。他的关注点不是人的肉体，而是存在方式。海德格尔要削弱的正是占据主导的笛卡尔式主体观，即人本质是自主、封闭的心灵与自我，人与世界的原初关系是认知——感知、相信、理解等等。[^(\[7\])](#chapter003.html#m7) 他用对日常状态的现象学描述来反驳这种传统观念，因为此在生存的基本结构是在世，它深陷现实环境，实践交互才是人与世界的最原初关系。

存在论现象学关涉的是包含身体的具身实践，触摸、抓取、手写、拥抱这类活动都以身体为前提，没有身体这些活动就失去意义。人的根本活动是用身体熟练地使用器具来完成任务，笛卡尔式的理论沉思才建立在这种基础上。然而《存在与时间》里几乎没有对此在的身体性做专题论述，所以人们怀疑他疏忽了身体，或根本不关心身体。

因为《存在与时间》关于身体的文字寥寥无几，质疑声就更大了。有人把此在形容为“离身的”，说海德格尔的描述更接近康德从笛卡尔继承来的无身体先验主体。[^(\[8\])](#chapter003.html#m8) 德雷福斯也提出，海德格尔似乎暗示拥有身体不属于此在本质结构，此在不必然具身，身体不是根本。[^(\[9\])](#chapter003.html#m9)

我认为，海德格尔略过身体是有意为之。他真正关心的问题不是此在有没有身体，而是具身性能否牵涉到此在存在的本质方式。他用中性的“此在”替代“人”，某种程度上就表明身体不是讨论中心，因为身体总是一个“我”的身体，被主观化后带有主体性特征，而这正是笛卡尔二元论的痕迹。他自始至终试图超越笛卡尔区分，因此不以一般意义谈论身体，而是认为现身情态与情绪遮蔽了身体，身体在最原初意义上是一种非本质的现象。

在20世纪60年代的泽利康讲座里，海德格尔提出新的身体观念，反对把身体看成可分解、可还原的结构，否则人就会滑向“人是机器”的极端。他提醒：身体现象是完全独特的，不能还原为机械式系统。[^(\[10\])](#chapter003.html#m10) 此在是能够显现存在意义的存在者，它不是现成意义上的存在者，只有在自己的生存中才能显现自身。海德格尔说，此在不能把自己理解为现成性，作为此在不可分割的部分，自然也不能只盯着身体的生物学意义。他写道：若要恰当地理解身体，人类身体的存在从根本上绝对不能仅被看作成成在手之物。[^(\[11\])](#chapter003.html#m11)

如果把身体的事实性和实在性抬得太高，就容易把身体也当成非此在的存在者。这或许也是海德格尔区分“身体”和“躯体”，要求区分两者界限的原因。对他来说，躯体以皮肤为界，身体则是无界限的，二者分属不同维度，前者属于存在者层面，后者需在存在论分析中阐明。比如我用手指指向远处的高塔，指尖是躯体边界，但我的身体并不止于此，高塔被纳入我的存在视域，与我建立了生存意义上的关联。身体不是内嵌于世界的实体，相反它为人们与世界实体相照面设定了可能性条件，身体的界限是动态变化的。[^(\[12\])](#chapter003.html#m12) 某种意义上，海德格尔以特有的方式解构了作为科学和生物学概念的身体。

总的来看，面对身体问题，此在与认知主体存在明显差异。认知科学范式转换的一个本质特征就是对身体的重视提升，从无身的认知主义、联结主义到把身体纳入核心的具身认知。到了某些强立场，身体甚至成了认知的来源，自我意识就是身体体验，心智内容取决于身体结构。相比之下，海德格尔的身体观更深刻新颖。在具身认知等理论里，认知主体的身体更接近他所说的“躯体维度”。用身体结构来考察认知功能会让研究更精确，但也可能把身体当成可量化的物来处理。

在我看来，延展认知关于身体界限的争论之所以激烈，一个原因就是它仍在生物学意义上使用身体概念，想通过与技术工具的耦合纠缠来突破身体与世界的绝对限制，这种强行突破违背了我们关于身体的常识。把身体从存在论角度视作此在本质的存在方式，让身体成为动态存在，依照海德格尔的说法就是“身体化”，身体界限即此在存在视域的界限。从这个角度，倒是有可能为延展认知提供某种可行性论证。

因此，海德格尔并非抛弃或轻视身体。不能因为《存在与时间》里关于身体的论述不多就判定他觉得身体无关紧要，也不能因此说此在是无身或离身的。此在当然是具身的，需要身体支撑。只不过在他那里，身体已隐入此在的生存，隐入此在的上手活动，隐入此在与世内存在者的实践因缘。此在并不是像使用工具那样“拥有”身体，正如他所言：并非我们拥有一个肉身，而是我们就是肉身存在。[^(\[13\])](#chapter003.html#m13)
