## 聊天机器人里的数据流向与隐私争议

ChatGPT 的隐私说明与日志保留机制一直饱受官方与使用者质疑。

说明文件披露了公司如何采集与使用信息。例如付费版本或在对话中提供内容时，系统会记录 IP、地理位置等多种细节。

这类采集本身并不罕见，属于行业常规。但聊天过程会持续记录行为轨迹。OpenAI 会留存姓名、联系方式、支付凭证、交易记录、登录凭证等基础档案。联系客服或发送邮件时，姓名、地址、对话内容同样会被保存。发布评论后，社交媒体互动及主动分享的个人资料也会被追踪。在使用期间，还会获取浏览器类型、IP、会话时长、操作系统与设备名称。

为追踪网站与聊天窗口的浏览，OpenAI 部署 Cookie，并表示这些资料用于统计分析与互动研究。

全部对话都会被归档，系统会完整记录一次会话里出现的内容，包括敏感片段。用户在起草专业或私人文件时，往往不经意泄露了这些内容。

在工作中没有防护地使用 ChatGPT，可能把公司、员工、委托方的细节暴露给模型。例如把客户反馈写入报告，就可能意外外泄客户资料。

按说明，OpenAI 应当给出清晰告知，让使用者明白信息如何被采集与利用，并获得明示同意后依法处理。若要分享被视为私密的内容，建议先与 OpenAI 签署数据处理附录。

联系方式可能被诸多主体获取。说明显示 OpenAI 会把资料提供给他人，服务商、供应商、法人实体等也可能接触到，技术训练师等人员也可能审阅对话记录。

OpenAI 并未细说明共享的具体路径，但表示出于执行功能或满足商业需求，可能把信息提供给服务商，涉及云计算、分析、邮件、网络托管、活动管理等。

说明中更明确的部分指出，在合作伙伴交易、并购、破产或清算情形下，或为维护使用者、公众及自身免于法律风险而向执法部门提供数据时，也会进行共享。

训练人员会分析对话以优化模型，并核查内容是否符合公司规则。一旦向机器人提供个人资料，训练师即可看到。

总体来看，OpenAI 与 ChatGPT 收集的大多属于设备与账户层面的无害信息。

## 使用 ChatGPT 可能带来的信息风险

负责合规的领导应评估企业采用 ChatGPT 可能面临的多重风险，并制定缓解措施。存在六类主要风险，若未防范，可能带来法律责任与经济损失。

需要警惕的是，若未关闭历史记录，收集到的内容可能进入训练材料。弗里德曼指出，非企业使用者的回复中可能包含敏感数据。合规部门必须建立技术使用框架，防止个人或组织数据被未经授权访问。

ChatGPT 即便表现突出，合规部门仍需跟进人工智能偏见相关的法律，宜由主题专家与技术部门协作完成。

模型在大量互联网数据上训练，可能涉及侵犯知识产权与版权。程序在生成输出时不提供解释或来源参考，因此定期关注版权法规变化很重要。

恶意行为者滥用 ChatGPT 已导致大规模虚假信息，例如虚假评论。基于大语言模型的程序还易受提示词注入攻击，这种技术可诱导模型执行设计目的之外的任务。

法律与监管部门的负责人应定期与网络安全同行协调，降低人工智能使用相关风险。

若企业未向消费者披露 ChatGPT 的使用情况，可能承担法律后果并失去信任。

## 缓解数据隐私问题的思路

自2022年11月发布以来，ChatGPT 用户增长迅速，已成为许多人生活的组成部分，但安全性如何？

尽管在安全措施与隐私条款加持下可安全使用，仍存在漏洞。本部分探讨这些问题及监管因素，帮助使用者更清晰评估安全性并做出明智决策。

ChatGPT 的安全性由 OpenAI 维护，该公司开发了聊天机器人及 GPT 框架。这些功能旨在让输出更自然、更接近人类，并实施多项保护措施。更多细节可参考 OpenAI 官方说明。

GPT 服务器以加密格式存储数据，系统间传输也加密，确保数据免受未授权访问。

除安全措施外，OpenAI 还采用访问控制，包括授权与身份验证协议，防止未授权个人访问用户数据。

公司还聘请外部审计员每年检查 API，以发现并解决潜在问题，确保安全措施有效。

OpenAI 建立了漏洞赏金计划，鼓励技术爱好者、黑客与研究人员报告安全问题。

通过对话数据，OpenAI 可提升自然语言处理能力，同时遵循适当的数据处理做法。

收集用户数据的目的是通过分析和临时存储用户对 ChatGPT 的所有内容来改进自然语言处理。OpenAI 对收集与使用方式保持透明，用于改善体验并训练语言模型。

数据以安全方式存储，仅用于预期目的，并在达成目标所需时间内保留，期满后删除或匿名化以保护隐私。

仅在用户同意或有明确法律要求时，信息才会被与其他方共享。OpenAI 会确保第三方遵循适当的隐私与数据处理规则，确保数据安全处理。用户可期待 OpenAI 尊重隐私并对其信息保持控制，公司提供便捷方式访问与修改个人信息。

ChatGPT 平台并非保密，会记录每次对话并将数据用于训练。

## ChatGPT 相关的法规图景

隐私与数据保护规定适用于人工智能技术，在不同法域各有差异。

GDPR 适用于位于欧盟并处理欧盟居民个人数据的组织，确保隐私与权利受保护。

美国加州 CCPA 为消费者规定与个人信息相关的权利，要求企业告知数据收集方式及共享情况。

各国制定了自身法律以保护人工智能系统收集的信息，包括新加坡 PDPA 和巴西 LGPD。2023年3月意大利因隐私问题禁止 ChatGPT，一个月后 OpenAI 增加安全功能后禁令解除。

欧洲议会已关注 ChatGPT 等人工智能系统缺乏法律规制的问题。2023年通过《人工智能法案》，要求开发人工智能技术的公司披露训练数据版权来源。

这些法规按项目带来的风险程度分为不同类别，从低到高。法规不会禁止高风险工具，但将强制严格透明度措施。

《人工智能法案》是规范人工智能使用的综合立法。在正式落实前，用户仍应谨慎使用 ChatGPT。

## 安全使用建议与防护要点

为保护用户数据，OpenAI 落实了多种安全功能，但用户仍需采取必要步骤降低风险。

应始终避免在对话中泄露敏感信息。使用任何接入 ChatGPT 的应用程序前，应仔细查看隐私政策，了解对话如何存储与使用。

为降低未经授权访问与使用风险，应始终使用假名或匿名账户，防止真实身份与对话关联。

使用服务或应用程序前，应熟悉保留对话的政策，了解对话在删除或匿名化前保留多久。

遵循 OpenAI 的隐私与安全政策，并持续更新做法以确保安全。了解其安全功能有助于获得更安全体验。

在使用语言模型的同时，还应采取必要措施保护个人信息与隐私。

为降低风险，应限制共享信息并审阅隐私政策，使用假名账户、监控数据保留，并及时了解安全措施变化。

随着人工智能日益普及，用户在使用过程中优先考虑隐私与安全至关重要。
