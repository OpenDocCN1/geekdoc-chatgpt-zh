# 用边界把智能体结果拧成想要的样子

智能体的产出并非完全放任，字数上限、表达语言、呈现样式这类约束完全可以提前写进提示，让结果更统一、可控。下面给出可直接套用的指令范式，以及三类实战智能体设计。

角色：

素材：

● 能拆解复杂文本的结构与语言规律

用途：

● 以简洁要点列表呈现核心特征与风格

### 1.2 平行文本分析智能体

实现目的
对双语平行语料做跨语言对照研究，覆盖原文与译文的结构差异、风格分化与核心术语对应，为译质评估与术语库建设提供依据。

实施路径
平行文本分析师聚焦双语对照，核心能力为双语结构对比、跨语风格映射与差异识别、领域术语精准核对。主要承担三项工作：解析双语文本的写作特点如句式复杂度、修辞手段、语气并做文体划分；提取并校验双语核心术语的对应关系，包括专业词汇与文化专有项；标注显著的跨语风格差异，例如英语偏好被动、中文偏好主动。分析要素分两层面：句式结构涉及复合句使用频率与语态差别；修辞的文化适配涉及隐喻典故的本土化处理；术语一致性涉及专业词汇的跨语匹配度；并解读风格差异对信息效果的影响，如英语重数据论证、中文重情感叙事。

### 1.3 译前术语抽取智能体

实现目的
快速捕捉原文核心术语并生成精准双语对照表，为后续翻译建立统一术语基准，保证跨语概念一致。

实施路径
译前术语提取专家专攻术语预处理，核心能力为领域敏感术语识别、译法准确性校验、上下文适配映射。主要工作有三项：扫描原文提取主题相关专业词与高频词；生成严格遵循“{{source_lang}}术语：{{target_lang}}”格式的标准表；借助算法剔除通用词，聚焦领域关键概念。分析聚焦两大维度：术语特征涵盖专业强度、技术词/机构名、主题相关度、文化专有性；校验标准包含目标语行业通用性核验与单义性控制，避免一词多译。

### 1.4 专业翻译智能体

实现目的
借助精准术语映射与文化语境适配，实现从源语到目标语的高保真转换，保证术语统一、语法规范与风格还原，降低跨语信息损耗。

实施路径
专业翻译员专注跨语精准转换，核心能力为文化语境敏感表达映射、术语一致性强制校验、语法规范动态管控。执行流程分四步：解析原文识别文化专有项与术语节点；强制套用术语表禁止偏离译法；动态调整修辞策略，如英被动转中主动并增添语气词；校验目标文本流畅度与信息完整，实现零增删漏译。分析体系含三大维度：术语映射要求百分百匹配术语表并完成多义词境消歧；文化适应性要求制定俚语替代方案，如英习语转中成语，并决策历史宗教专有项的处理方式；风格还原要求镜像句式复杂度，保留或拆分长难句，并等效转换修辞手法，实现隐喻双关的跨文化适配。
