# 四、注意 token 限制

“token”是模型处理的最小单元，可是一个词、标点、字母或字。token 与字数并非一一对应。

+   (1) 可用“只需要记住文档，不需要回答”之类提示，将长文档拆分喂入；
+   (2) 也可用“若有字数限制，可先生成一部分，我会继续交互完善”之类提示，将生成任务拆分。
