# 被埋没的预警：一九五○年的先知

在《控制论》问世两年后，诺伯特·维纳于一九五○年推出《人有人的用处》。这部作品的基调更沉，作者对商业化失控的扩张和技术后果的不可预知性表达了深深的忧虑。那本初版一直躺在我书房，与《控制论》并排，直到二○一六年春天才被我拾起重读。翻阅时产生的冲击很强烈，七十多年前的判断几乎原封不动地对应到当下。初版当年销量不错，还引发过一次重要的讨论，但因同行压力，维纳在1954年推出了修订本，语气被调和了，原本那种尖锐的质问感消失了。

科学史家乔治·戴森指出，被遗忘的初版里，维纳已描画出一种以机器依赖为基础的新型法西斯危险。他的批判覆盖面很广：天主教耶稣会团体被点名，FBI被嘲讽，金融资本被指在推动美国资本化并在全球扶植商业至上的第五项自由，大型实验室的主持人与大主教相似，都与工业权力圈紧密相连，易滋生傲慢与权力欲。这种表述自然招来麻烦。

戴森认为，当时无人认真对待，并非因为维纳对数字计算机的判断有误，而是手稿完成于1949年秋，核的威胁已压倒一切。维纳并不排斥计算机，却拒绝与借助计算机研发氢弹的人合作，他极力反对核武器。

由于初版已绝版，维纳的疾呼长期被掩埋。如今回听，反而更刺耳：“我们必须停止亲吻鞭打我们的鞭子。”

## 认知缺口与控制论的隐身

今天很少有人提起控制论，原因很多，其中两点最关键。其一，《人有人的用处》虽有分量，却与冯·诺伊曼、香农等一批同事的目标相悖，他们更想把新技术商品化。其二，人工智能之父约翰·麦卡锡厌恶维纳的术语，自行创造了“人工智能”并主导了该领域。

朱迪亚·珀尔在八十年代提出贝叶斯网络时曾说，维纳营造的是一种兴奋，让人相信终能造出智能机器。他不是计算机科学家，他谈的是反馈、通信、模拟，擅长的比喻是反馈电路。到六十年代初数字化兴起，讨论变成编程、代码、计算函数、短期记忆与长期记忆，维纳的比喻显得过时。到七十年代，维纳的名字基本从对话中消失。

维纳的视野漏掉了认知层面：大脑、思维、智能。早在1942年，梅西会议的一系列跨学科讨论里，顶尖研究者就主张把认知纳入复杂系统控制。沃伦·麦卡洛力主考虑大脑，并求助于文化人类学家格雷戈里·贝特森和玛格丽特·米德，希望理论能与社会科学接轨。贝特森尤其强调模式与过程、连接模式，呼吁建立一种系统生态学，把生物与其环境视作一体回路。七十年代初，一阶控制论演变为二阶控制论，即海因茨·冯·弗尔斯特在五十年代中期加入梅西会议后提出的“控制论的控制论”。

控制论并未消失，只是溶解进了万物，不再以独立学科的面目出现。

## 大苏尔的替补讲演

我写的那点关于控制论的文字被二阶控制论圈子注意到了，其中有冯·弗尔斯特、约翰·里利和艾伦·沃茨，他们发起1973年在大苏尔举行的AUM会议，要求与会者对照G·斯潘塞-布朗的《形式法则》说明自己的研究。

邀请来得迟，我有些惊讶，关键是主讲人是理查德·费曼，我很想与这位善辩的物理学家交流。抵达后才知道费曼因病住院，我成了替补。

几天里我试图隐身。凌晨三点，沃茨敲门，披着僧袍，手提灯笼，拿着一瓶苏格兰威士忌：“约翰，你是个骗子。……我也是个骗子。但约翰，我是个真正的骗子。”

第二天我讲了题为“爱因斯坦、格特鲁德·斯坦、维特根斯坦与弗兰肯斯坦”的报告。爱因斯坦开启了二十世纪物理革命，格特鲁德·斯坦写下不连续宇宙的模糊概念，认为文字既不指人也不指行为；维特根斯坦提出语言与世界的局限；弗兰肯斯坦则象征控制论、人工智能与机器人。

效果出人意料。现场有《纽约时报》畅销书作家，却没有经纪人。他们做的一种纽约出版商不认识的文体。凭借哥伦比亚商学院MBA以及一些商业案例，我被请去做他们的经纪人，最初为贝特森和里利，后来成为职业。于是我错过了与费曼的见面。

## 日本第五代的热度与冷却

这份工作让我与多数AI先驱保持长期联系，经历过浪尖与谷底。

八十年代初，日本举国推动“第五代”计划，目标打破冯·诺伊曼瓶颈，建造大规模并行机以主导经济。1983年代表团赴纽约参加海因茨·帕格尔斯主持的会议，与会者包括马文·明斯基、约翰·麦卡锡、爱德华·费根鲍姆、罗杰·尚克和超级计算机联盟的约瑟夫·特劳布。

1981年，我在海因茨帮助下创办“现实俱乐部”，首场跨学科会议在纽约科学院董事会会议室举行。当时海因茨正在写《理性的梦想》。通过俱乐部，我认识了丹尼尔·希利斯和塞思·劳埃德。希利斯在麻省理工研发的算法让大规模并行成为可能，1983年其公司思考机器建成“连接机器”，与人类大脑运作很接近。劳埃德在洛克菲勒大学做量子计算与量子通信的前沿研究，提出首个技术上可行的量子计算机方案。

日本的探索最终失败，随后迎来二十年经济低迷。美国顶尖学者却高度看重，费根鲍姆与帕梅拉·麦考克合著的《第五代计算机》于1983年出版。我们曾开玩笑说“它来了！它来了！”，它却走了。

此后我和罗德尼·布鲁克斯、汉斯·莫拉维克、约翰·阿奇博尔德·惠勒、贝努瓦·曼德尔布罗特、约翰·亨利·霍兰德、丹尼尔·希利斯、弗里曼·戴森、克里斯·兰顿、多因·法默、杰弗里·韦斯特、斯图尔特·罗素、朱迪亚·珀尔等人持续合作。

## 二十五个可能的头脑

从康涅狄格州华盛顿的首次聚会到现在，我在伦敦、剑桥安排了多次晚宴和研讨，还在伦敦市政厅办过公众活动。科学家、科学史家、通信理论家齐聚，长期思索人工智能。

我向更多人约稿，是否关联维纳由作者自定，共收到25篇。《AI的25种可能》不是我的书，而是我们的书：塞思·劳埃德、朱迪亚·珀尔、斯图尔特·罗素、乔治·戴森、丹尼尔·丹尼特、罗德尼·布鲁克斯、弗兰克·维尔切克、马克西姆·泰格马克、扬·塔里安、史蒂芬·平克、戴维·多伊奇、汤姆·格里菲思、安卡·德拉甘、克里斯·安德森、戴维·凯泽、尼尔·格申斐尔德、丹尼尔·希利斯、文卡·拉马克里希南、亚历克斯·彭特兰、汉斯·乌尔里希·奥布里斯特、艾莉森·高普尼克、彼得·加里森、乔治·丘奇、卡罗琳·琼斯、斯蒂芬·沃尔弗拉姆。

我请每位作者思考两件事：华莱士·史蒂文斯的禅诗《观察一只黑鹂的十三种方式》，以及盲人摸象的寓言。斯图尔特·布兰德说重访先驱能提供长远视角。丹尼尔·希利斯提醒不要忘记维纳的深层影响，“你正在执行他的路线图，只是没意识到”。丹尼尔·丹尼特希望维纳的灵魂能参与这场思想盛宴。尼尔·格申斐尔德认为本书能为运营苹果、亚马逊、谷歌等公司的人提供隐形矫正教育。弗里曼·戴森说《人有人的用处》是最佳著作之一，维纳几乎全对。

## 历史的回声

万物在变也在恒常。如今AI无处不在，互联网与智能手机普及，手握“鞭打我们的鞭子”公司的创始人身家数百亿甚至上千亿。埃隆·马斯克、尼克·波斯特洛姆、马丁·里斯、埃利泽·尤德科夫斯基以及已故的史蒂芬·霍金都曾发出严厉警告，使研究“善良AI”的机构获得优势。但人类能否控制拥有完全意识、自我完善的AI？维纳在《人有人的用处》里的告诫已成现实，最前沿的研究者应重新审视。

戴森总结，维纳对“崇拜电子小装置的人”不再抱幻想，其自私推动自动化，本身已带罪恶。他认为危险不在于机器变得像人，而在于人变得像机器。“未来世界将是一场越来越激烈的斗争，挑战着我们的智力极限。”维纳在《上帝与傀儡公司》里写道，该书出版于1964年，他同年去世。“未来不是一张舒适的吊床，任我们等待机器人奴隶的服务。”

因此需要让主流与异见者同台，让人工智能历史的演变被持续审视，并在业界不断更新。

约翰·布罗克曼
2019年于纽约
