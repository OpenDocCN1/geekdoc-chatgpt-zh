# 第五章 数据要素开发与应用

## 第五十八条 【总体目标】

本市支持数据资源开发和应用，发挥海量数据和丰富应用场景优势，鼓励和引导全社会参与经济、生活、治理等领域全面数字化转型，提升城市软实力。

[PRE0]

第五章关于数据资源开发运用的条文，是《上海市数据条例》中最受关注的部分之一，印证了市里把数据视作核心生产要素的定位，也体现出拥抱创新、用科技赋能城市发展的开放姿态。第58条作为该章的开篇，承担起为数字技术定调子的任务，从场景化的落地视角出发，凸显信息技术在推动经济增长、改善市民生活、辅助政府治理等方面的积极意义。

[PRE1]

条例第2条把数据界定为“任何以电子或者其他方式对信息的记录”，在这一定义之下，牵涉到法人、非法人组织的各类记录之外，最受关注也最具争议的是个人信息。它既有人格属性，也具备明显的财产属性。^([\[1\]](#txt005.html#footnote_content_txt005_1))个人信息的财产属性，本质上来自它作为技术研发原材料和商业模式基石的资源功能。在PC和智能手机普及的数字社会，数据驱动的数字经济已成为当下社会价值创造的主流方式。在更好地保障个人信息权益和数据安全的前提下如何释放数据价值，成为数字转型阶段的关键命题。近几年《网络安全法》《个人信息保护法》《数据安全法》相继出台，表明国内已搭建起迎接数字时代的基础制度框架。

第58条从数据要素的特性与数字技术的作用两个维度来阐释开发利用的总体方向。一方面，数据技术研发依赖海量样本支撑，不同场景对功能设计与安全要求也各不相同。条例对数据特点与使用前景的判断，与国务院办公厅2021年12月21日发布的《要素市场化配置综合改革试点总体方案》中“拓宽规范化数据开发利用场景”的部署高度契合，显示出较强的前瞻性。另一方面，从产业数字化的层面看，条文提出借助数字技术全面提升上海在经济发展、居民幸福感、公共治理效率等软实力指标上的表现。

### 一、数据的产业应用

数据处理同时关乎个人隐私保护与数据价值挖掘，涉及个人、信息产业企业与国家三方力量，立法追求的是“两端兼顾、三方平衡”的治理效果。^([\[2\]](#txt005.html#footnote_content_txt005_2))对照征求意见稿，最终版第58条在坚持政府支持数字化产业的基调下，明显弱化了行政干预的色彩，更多体现尊重市场规律、支持技术向善的务实态度。与《深圳经济特区数据条例》相比，上海本章更突出数据要素的市场属性，意图激活各类数据的开发潜能，动员全社会参与数字经济和数字技术的升级换代。^([\[3\]](#txt005.html#footnote_content_txt005_3))

在我国数字信息赛道，产业走在规则前面是明显特征。腾讯、百度等头部企业诞生于千禧年左右，而全国层面的立法响应直到2012年全国人大常委会通过《关于加强网络信息保护的决定》，聚焦网络信息侵权问题，此后才出现围绕个人信息展开的维权诉讼。^([\[4\]](#txt005.html#footnote_content_txt005_4))负面看，早期规则缺位客观上放大了个人信息滥用风险；正面看，也为互联网行业赢得了十年的高速成长期，技术与商业体量实现爆发式增长。有研究对美国、中国、欧洲的人工智能发展做横向比较，认为中国势头强劲，与美国的差距在不断收窄。^([\[5\]](#txt005.html#footnote_content_txt005_5))面对新兴数字技术，法律宜采取底线思维，以不损害个人尊严、不威胁个人财产和人身安全为边界，为技术与商业划定原则性框架。即规则要尊重科技与市场的客观进化规律，留出必要的自由发展空间。相比草案，正式发布的《上海市数据条例》第58条显示出行政部门在技术开发与应用领域适度退后，让位给科技界和产业界，避免过度计划与干预，在保障个人权益和公共安全的前提下倡导包容发展。

## 二、丰富数据的场景化应用

第58条专门提出场景化探索，是本条例区别于已实施的地方条例的鲜明特色。作为千万人口的国际化大都市，上海拥有极其丰富的数字技术落地场景。法规的作用在于从数据产品的归属、数据活动的规则出发，保障创新者的权益，同时划清场景应用的边界，鼓励技术人员大胆尝试，开拓数据技术的新场景。

### 第一，为拓宽数据的场景化应用创新，应率先解决数据权属问题
