### 14.8.6 Xception 深度可分离卷积的再设计

Google在论文《Xception: Deep Learning with Depthwise Separable Convolutions》中提出的Xception是对Inception v3的再改进，核心做法是用深度可分离卷积替代Inception v3原有的普通卷积。

设计思想
采用深度可分离卷积替换原Inception v3的卷积，与传统DW卷积存在两处差异。
（1）传统DW先做逐通道卷积再接1×1卷积，Xception顺序相反，先做1×1卷积再做逐通道卷积。
（2）传统DW两个卷积之间不加激活，Xception在1×1卷积之后加入ReLU非线性。

网络架构
与VGG这类将3×3卷积堆叠的传统网络不同，Inception模块通过组合1×1、3×3、5×5卷积和池化来提取特征，用更少参数实现更丰富的表征。Inception模块是GoogLeNet、Inception v2/v3和Inception-ResNet的基础。它的思路是把空间相关性和通道相关性拆开学习。
（1）先用1×1卷核把特征图的各通道映射到新空间，学习通道间关系。
（2）再用3×3或5×5卷核做卷积，同时学习空间和通道关系，此时卷核仍是多通道输入，空间与通道并未完全解耦。

从Inception到Xception的演化路径如下。
（1）先对Inception模块做简化，只保留3×3卷积分支，得到如图14-21所示的仅含3×3分支的Inception模块。

（3）进一步提升3×3卷积分支的数量，使其输出通道数与1×1卷积的输出通道数一致，得到如图14-23所示的Xception基础模块。

### 14.8.7 ShuffleNet-v1 极致轻量移动结构

《ShuffleNet: An Extremely Efficient Convolutional Neural Network for Mobile Devices》提出的ShuffleNet专为手机等移动设备打造。架构引入逐点群卷积和通道重排两种操作，在精度相近的前提下大幅降低计算量。前面网络中PW卷积会显著增加计算，为此作者提出逐点群卷积来降本，但组间联系弱化影响精度，于是引入通道重排来增强组间信息流动，在相同计算复杂度下容纳更多通道保留信息。

设计思想
ShuffleNet继承稀疏连接的设计思路。分析Xception和ResNet可知，二者通过卷核拆分后计算复杂度下降，但逐点卷积的计算反而上升，为此作者用逐点群卷积替代原有结构，通过限制卷积在组内运算明显降低计算量。图14-24展示了逐点群卷积与通道重排的操作。

然而多层逐点卷积堆叠时，信息被分割到各组内，组间无交换，如图14-24（a）。这会削弱表征能力和识别精度。因此在使用逐点群卷积的同时需要组间信息交换机制。第2层卷积中每个卷核需同时接收各组特征输入，如图14-24（b）。作者提出通道重排如图14-24（c），操作可导可嵌入网络实现端到端学习。

[PRE3]

#### 网络架构
基于逐点群卷积与通道重排，作者设计了全新的ShuffleNet结构单元，继承ResNet思想并做效率优化。
（1）用逐通道卷积替代原有的3×3卷积，降低空间特征抽取复杂度，如图14-25（a）。
（2）将结构中前后两个1×1逐点卷积分组，并在两层间加入通道重排，进一步减少跨通道计算量，最终单元如图14-25（b）。
（3）提出另一种单元图14-25（c），在旁路加入AVG Pool以降低特征图分辨率，最后不采用Add而采用叠加来弥补信息损失，专门用于降采样。

### 14.8.8 ShuffleNet-v2 面向实践的轻量化准则

Face++团队论文《ShuffleNet V2: Practical Guidelines for Efficient CNN Architecture Design》提出ShuffleNet-v2，目标是在保证高精度和高速度的前提下做轻量化。文中给出4条高效CNN设计准则，并据此对ShuffleNet-v1进行改进。同等复杂度下，ShuffleNet-v2比ShuffleNet和MobileNet-v2更准确。

#### 设计思想
- （1）高效CNN的4条设计准则。
    - G1 相同通道宽度可最小化MAC，模型速度最快。
    - G2 过度分组卷积会增加MAC，使模型变慢。
    - G3 网络碎片化降低并行度，分支越少速度越快。
    - G4 元素级运算不可忽略，需尽量减少Element-wise操作。
- （2）ShuffleNet-v1存在多处违背。
    - a 大量使用1×1分组卷积，违背G2。
    - b 采用类似ResNet瓶颈层，输入输出通道不同，违背G1。
    - c 整体结构分组卷积操作过多，违背G3。
    - d 短路连接中存在大量元素级Add，违背G4。
- （3）ShuffleNet-v2的改进方向。
图14-26是ShuffleNet-v1和ShuffleNet-v2的基础单元，其中14.26（a）和14.26（b）为ShuffleNet-v1的两种block，后者对特征图尺寸做了缩小。14.26（c）和14.26（d）为ShuffleNet-v2的两种block。

改进1：14.26（c）在开头增加通道分离操作，先把输入特征图在通道维切分为c'和c-c'两个分支，实际c'=c/2，左分支做等价映射，右分支做3个连续卷积且输入输出通道相同，符合G1。
改进2：14.26（c）取消1×1卷积层的分组，符合G2。注意前面的通道分离本身已具分组效果，两分支相当于两组。
改进3：通道重排移到叠加操作之后，符合G3；同时首个1×1卷积不再分组，后接通道重排意义不大。
改进4：两个分支输出不再用Add元素相加，而是直接叠加，符合G4。

    - 基于NCNN可将深度学习算法轻松移植到手机端高效执行，开发AI App。

### 14.9.2 QNNPACK

- （1）全称：量化神经网络包 Quantized Neural Network PACKage，QNNPACK。
- （2）开源时间：2018年10月。
- （3）开源团队：Facebook。
- （4）GitHub地址：见参考链接[2]。
- （5）特点。
    - 使用低密度卷积优化函数库。
    - 可在手机上实时运行Mask R-CNN和DensePose。
    - 在性能受限移动设备上100ms内完成图像分类。
- （6）性能优势。
测试显示QNNPACK在端到端基准上具明显优势。量化MobileNet-v2架构上，基于QNNPACK的Caffe2算子速度约是TensorFlow Lite的2倍，多款手机均如此。除QNNPACK外，Facebook还开源Caffe2量化MobileNet-v2模型，其Top1准确率比对应TensorFlow模型高1.3%。

MobileNet-v1采用深度卷积使模型更适配移动端，具有开创性意义。MobileNet-v1包含大量1×1卷积和3×3卷积。研究者将量化MobileNet-v1模型从TensorFlow Lite转换，并在TensorFlow Lite和QNNPACK的32bit ARM设备上做基准测试，二者均用四线程，QNNPACK运行速度几何平均值为TensorFlow Lite的1.8倍。
