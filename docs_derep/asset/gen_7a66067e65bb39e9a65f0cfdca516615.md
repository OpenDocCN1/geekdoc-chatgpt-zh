# 结语 与 AI 共处

[PRE0]

翻完前面这些故事，你一定已经见识过人工智能制造惊喜的多种模样。

只要目标清晰而实现方式留有余地，模型就很容易给出程序员根本想不到的解法。比如让它从 A 点走到 B 点，它可能先把自己搭成一座小塔再从上头栽下来；也可能原地画圈、贴着地面蠕动来凑数。在仿真环境里训练时，它还会主动钻空子，利用物理规则的漏洞攒出超人一般的表现。它对指令的理解极其字面：被要求别撞东西，它就干脆停住不动；被要求别在游戏中输掉，它直接按下暂停键然后无限卡住。它能在数据里揪出隐藏的关联，尤其有些是人类设计者都没意识到的模式。里面混杂着我们不愿它学到的东西，比如偏见。当多个模块串起来使用，就像一部装满应用的手机，或像一群协同的蜜蜂，它们能合力解决单个系统单独面对时会束手无策的问题。

能力在提升，但人工智能始终不清楚我们真正想要什么。它会尽力去做我们想要的事，可我们心里期望的结果与我们写下的指令之间，常常会出现偏差。它会不会变得足够聪明，能像人一样理解世界甚至超越我们？短期内看不到。眼下更现实的风险不是它太聪明，而是它不够聪明。

表面上看，它似乎更懂了。能生成逼真的画面，甚至渲染整部电影的场景；能在我们丢给它的游戏里不断取胜。可归根到底都是模式匹配。它只认识自己见过的内容，而且只有出现频率足够高才会被记牢。

现实世界太复杂、太不可预测、也太古怪，训练时根本不可能覆盖全部。鸸鹋可能突然冲出来，小朋友可能穿着蟑螂服装上街，人们会问长颈鹿的问题，而图里根本没有长颈鹿。缺乏背景常识的模型于是会误会我们的意图。

想把人工智能用好，关键在于先理解它：挑对它擅长的问题、预判它会怎么误读、拦住它从人类数据里复制来的糟糕部分。人工智能值得乐观，也需要谨慎，差别全在我们怎么用它。

顺便提醒一下，多留意那些藏在角落里的长颈鹿。
