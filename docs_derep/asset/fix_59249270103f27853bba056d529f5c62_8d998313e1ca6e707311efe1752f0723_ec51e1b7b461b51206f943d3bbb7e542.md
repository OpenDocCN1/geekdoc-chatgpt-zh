GPT-2 掩码机制与交叉注意力流程对照

在 GPT-2 的前向路径里，attention_mask 充当注意力掩码，把带 [PAD] 填充的位置对应的分数压到接近零，因此这些位置的词向量在多头聚合阶段基本被忽略，贡献可以视为无。

self.crossattention 触发的交叉注意和 self.attn 触发的自注意在 block 内部的计算骨架非常接近，两者的分歧主要出现在进入 block 之前的张量准备。

自注意分支并不会直接复用 LayerNorm 后的 hidden_states，而是先把原始的 input_ids、token_type_ids、position_ids 等 id 类张量送入词嵌入层 self.wte 与位置嵌入层 self.wpe，得到词向量、位置向量以及可选的类型向量再叠加，形成可进入网络的初始表示。交叉注意的路径则跳过这一步的重新嵌入，直接在已有的表征上进行。
