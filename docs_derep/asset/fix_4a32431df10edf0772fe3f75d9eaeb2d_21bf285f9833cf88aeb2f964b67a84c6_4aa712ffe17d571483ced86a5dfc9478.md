# 大模型通识：技术革新、商业落地与产业重塑

# 推荐序

大模型无疑正酝酿迄今为止继网络变革之后的又一次关键技术拐点。它已成为人工智能产业的关键节点，标志着人类步入智能化新阶段。从ChatGPT到Sora，技术演进既体现了单模态向多模态的跨越、文生文向文生视频的延伸，也意味着从单纯内容生产到理解并模拟物理世界的推进，迈向“世界模型”的核心一步。在泛化能力与垂直应用两条线上均出现明显跃升，智能涌现的现象愈加突出。它的出现为通往通用人工智能开辟了新路径，点燃了全球新一轮AI创新浪潮，几乎所有行业都将经历前所未有的重塑。

以大模型为代表的生成式AI正在加速演进，成为培育新质生产力的关键引擎。AI与社会全要素的深度交融，正推动泛在算力向泛在智能过渡，成为新质生产力的重要驱动。AI作为新生产工具，已经渗透到生产链的各个环节，以数据作新要素、以算力作新能源，依托人机协同的新范式，推动要素配置创新和全要素生产率的大幅提升。产业端，大模型能够高效解析生产数据，提前预判设备故障与维护窗口，优化排产与资源调配，实现流程自动化与智能化，提升整体效率。人力端，由大模型催生的AI智能体等新型“劳动者”，以及具备一定自主性的智能机器人，已成为人类的得力伙伴。与此同时，大模型也潜藏数据滥用、算法偏见、技术性控制等风险，推进新质生产力必须同步创新治理模式。

从人类发展视角看，生成式AI将把人类从重复性体力劳动中解放，推动劳动形态向智力化迁移。人类劳动经历了体力、技能到智力的演进：农耕时代以体力为主；工业革命时期技能劳动占据主导，体力逐步被机械替代；信息技术时代以来，人工智能重塑劳动属性，大模型与人形机器人承接更多生产任务，人类则聚焦研发、创意与产品创新等智力活动。未来生产将拥有更广阔的创造空间，智力劳动将占据主导，开启全新社会生产力时代。

数字信息基础设施在模型发展中发挥决定性作用。模型算力需求随技术迭代而快速攀升。OpenAI数据显示，AI训练算力需求约每3-4个月翻倍，自2012年以来累计增长超30万倍。智算中心作为算力集中载体增长迅猛。截至2023年底，我国在用数据中心机架规模超810万标准机架，算力总规模达230 EFLOPS，智能算力达70 EFLOPS，增速超70%。规模扩张伴随能耗提升，数据中心的绿色低碳转型已成趋势。此外，模型训练对海量数据和算力提出更高网络带宽与低时延要求。构建面向智算的AIDC间高速无损确定性网络，对模型的实时响应与高效运行至关重要。

大模型的快速扩散将对通信行业产生深远影响。一方面，运营商通过布局模型产业、推进“AI+”战略，可实现存量业务智能化升级、拓展增量业务、打造新增长点。另一方面，借大模型抓手，可深入推动企业数字化转型、提升运营管理效能。以智算中心为例，模型技术的加速渗透正在重塑行业。借助网络大模型实现网络自感知，提升效率与运维质量；借助研发大模型提速软件开发；借助客服大模型实现更精准的语义理解与情感分析，提供更个性化服务。

中国电信坚定践行央企使命，立足科技自立自强，依托云网融合优势，推动数字信息基础设施向智能化演进，致力于成为智能算力的主服务商、基础通用大模型先行者、行业大模型主导者，持续深耕智算云、通用大模型、数据底座、内部大模型、行业大模型五大方向。中国电信已规划“2+3+7+N+M”智算布局，启用单集群万卡级智算资源池，自研星辰大模型完成境内深度合成服务算法与生成式人工智能服务“双备案”。在面向个人、家庭、行业客户推出首批“AI+”产品、全方位推进业务AI化的同时，还面向交通等行业研发数十个垂类大模型，深度赋能场景应用。

在大模型技术日新月异、行业走向不断演化的背景下，中国电信天翼智库大模型研究团队长期追踪前沿进展，研判行业脉动并前瞻未来方向，开展系统性产业趋势、影响与策略研究，形成大量原创成果，以此为基础完成本书写作。我相信本书出版，有助于读者更准确把握大模型产业趋势与深远影响，更深刻理解如何以大模型驱动产业创新，更主动适应大模型带来的重大变化，在智能化时代实现自我提升。

# 前言

## 为何写作本书

在人类智慧的星空中，人工智能如一颗新星照亮未知。以ChatGPT为代表的大模型为通用人工智能开辟了新路径，被视作AI王冠上的明珠，以独特光芒引领新一轮技术革新。微软创始人比尔·盖茨曾表示，ChatGPT的意义不亚于互联网诞生。

我们已进入大模型时代。拥抱这一时代，首要任务是认识这一时代。

大模型作为一种新物种，仍在快速进化。训练策略、参数规模、数据规模与算力持续升级。GPT-1参数约1.17亿，GPT-4已超万亿；Gemini 1.5 Pro可稳定支持高达100万Token上下文。在技术驱动下，模型在理解、生成、推理、记忆等方面的能力突飞猛进。如Sora可根据文本提示生成最长60秒视频，深度理解并模拟真实物理世界；GPT-4在多项评测中达到人类专家水平，在复杂问题求解与创新方案提供上展现巨大潜力。

在技术与政策双轮驱动下，模型产业迅速壮大。国家大力支持通用人工智能与大模型，各地密集出台政策。头部企业纷纷入局，截至2024年3月28日，国家互联网信息办公室备案模型达117个。产业体系日趋完整，从GPU、智算中心、数据集到基座模型、模型平台与应用，企业快速集聚，MaaS成为主流，AI产业规模快速扩张。

大模型的颠覆性影响才刚刚开始。核心在于对人类智力的替代甚至超越。一方面，它将重塑社会治理、产业发展与生活方式。目前模型已在金融、传媒、教育、软件等知识密集行业落地，显著提升效率、降低成本。未来随AI Agent普及，以大模型为核心的智能机器人、智能汽车将在多方面减少人类干预。另一方面，它带来不确定性与焦虑，对隐私保护、知识产权、伦理等提出严峻挑战。

越来越多个人、企业与政府部门在了解或应用大模型。在此阶段，一本内容全面、观点客观、分析深入的著作对认知、技术创新与产业升级具有重要价值。笔者希望借助本书激发讨论，推动模型技术向更利于社会的方向发展。正如斯图尔特·罗素在《人工智能：现代方法》所阐述，AI是覆盖面广、持续进化的学科，需要多角度探索。基于此，本书力求成为连接过去与未来、理论与实践、专家与公众的桥梁，为读者提供全新理解方式。

# 第1章 AI与人类智慧的边界

我们开启一段关于人工智能与人类智慧关联与差异的探索。本章追溯智慧起源，从人类对自然的初步模仿到AI在当代的自主创造。历史长河中智慧之光愈加璀璨。我们将剖析AI演进，从规则驱动逻辑处理，到以数据为核心的智能化，再到具备高级决策与生成能力的复杂系统。本章重点讨论AI在模拟人类认知上的进展，并探讨自我意识等认知科学的挑战与潜力。同时展望AI未来，研判其是否能达到或超越人类认知边界，甚至演化为具有硅基生命特征的新实体。让我们共同揭开智慧面纱，洞悉AI潜能与方向。

## 1.1 智慧的核心在于创造

### 1.1.1 人类早期智慧始于对自然的模仿

人类早期智慧源于对自然的深度观察与模仿。史料有限，据考古推测约250万年前古人类已使用原始石器。如东非奥杜威遗址出土石器显示早期人类模仿自然、学习利用资源。虽简陋，却是智慧之旅起点，体现初步理解与应用自然规律的尝试。

石器时代创造曙光初现。新石器时代标志着从简单模仿向创造性发展转型。约公元前1万年，末次冰期结束，人类开始定居，形成初步社会结构与农业。在此阶段，人类不仅制作更精细石器，还开始制陶。如中国仰韶文化彩陶，既体现技术进步，也是艺术审美发展的见证。这些创造展现智慧本质：不满足现状，持续探索创新。

青铜与铁器时代标志技术与思维飞跃。青铜时代约始于公元前3000年，人类首次用金属打造工具武器，显著提升效能与耐用性。青铜技术最初在中东普及，如古巴比伦铭文与工艺品。铁器时代约始于公元前1200年，铁具更坚固。这一阶段人类不再仅模仿自然，而是创造超越自然的器物，成为智慧里程碑。

工业革命时代，创新追求达新高度。英国成为革新中心，出现约翰·凯飞梭、詹姆斯·哈格里夫斯珍妮机、理查德·阿克赖特水力纺纱机等发明。这些不仅是技术飞跃，更体现对高效便捷生产方式的渴望与不懈探索。持续创新推动社会进步，为后续技术与产业转型奠基，展现人类适应与引领变化能力，成为推动历史的核心动力。

### 1.1.2 从改变到创造：智慧的跃迁

信息时代，人类智慧与创造无限扩展。20世纪是标志性时期，1947年贝尔实验室发明晶体管为现代电子奠基。此后计算机与互联网改变全球信息流动。阿兰·图灵在计算机科学的贡献与蒂姆·伯纳斯-李1989年发明万维网，不仅改变沟通方式，更极大促进知识传播共享。信息时代的创新再次证明智慧本质：永不满足现状，持续追求新知新技术。

科技时代迎来新篇章。21世纪展示智慧新高峰。如2003年完成人类基因组计划，标志生物科学重大突破，为医学研究开辟新路径。人工智能也取得显著进展，如谷歌AlphaGo于2016年击败世界围棋冠军，标志机器学习进入新里程碑。能源领域，可再生能源技术大规模应用，解决能源危机并为可持续发展铺路。这些进步充分体现创造力。

如图1-1所示，回顾人类智慧历程，可清晰看到各阶段演进。从模仿自然，到创造适应环境工具，再到深度探索信息技术，每一步创新都体现对环境条件深刻理解与转化。这一历程验证“从模仿到创造”观点，也展示智慧通过探索超越推动文明进步的过程。智慧本质在于不断探索未知、超越已知、创造新可能。

探讨智慧本质时需认识到，智慧既是基于神经器官的高级综合能力，也是融合认知、反思与情感的人格特质。这种双重属性使智慧成为人类独特复杂特征。

深入理解智慧本质，有助于认识人类如何通过创新推动文明。正如发展历程所示，从模仿自然到创造技术，每一步都是对世界深刻理解与适应的结果。如今新挑战是：如何将智慧精髓融入机器，使其更高效、更智能地思考与解决问题。

## 1.2 AI演进的四个阶段

将AI发展与智能化水平映射，可划分为四个阶段。AI 1.0对应20世纪70年代计算智能，依赖预设规则执行任务，功能受限、灵活性不足，体现早期计算机科学成就，也暴露高度依赖人工编程问题。AI 2.0对应感知智能，决策式与生成式AI兴起。机器学习使机器具备基础感知能力，如语音与图像识别，扩大自动驾驶、医疗诊断等场景应用。AI 3.0以大模型为标志，引领认知智能崛起。21世纪20年代，AI能处理海量数据，实现知识表达与逻辑推理，在某些领域达到或超越人类认知。如GPT-4展示强大语言理解与生成能力，能自主学习并解决复杂问题。AI 4.0预示通用人工智能到来，标志自主智能阶段。AI可在无人类干预下自主决策、学习、适应环境，具备自我驱动与进化能力。

当前AI已进入以大模型为标志的3.0阶段，经历第三次技术升级，迈入“认知智能”新阶段。展望未来，随认知智能深化，AI将迎来第四次革命性升级——自主智能，详情如图1-2所示。

- 计算智能：涉及机器超强存储与超快计算。基于海量数据深度学习，以历史经验指导当前决策与行动。如AlphaGo采用强化学习战胜世界围棋冠军，电商平台依据用户购买习惯进行个性化推荐。

## 1.2 AI发展阶段

- **感知智能**：涉及机器视觉、听觉、触觉等感知能力。机器可将非结构化数据结构化，并以人类沟通方式互动。如无人驾驶汽车与波士顿动力机器人通过传感器感知环境，处理信息并指导行动。

- **认知智能**：指机器具备人类理解、归纳与推理能力，能运用知识。面对理解、推荐、预测、交互等认知需求，机器通过多模态学习从多源数据中提取信息，增强理解。借助知识融合、知识表示与推理、认知规划与决策，实现复杂任务处理并寻求最优解。情感计算、生成式AI等核心技术亦在提升多维数据理解能力。
