# AI安全：技术与实战 一本书把AI的危险面讲透

本书名叫《AI安全：技术与实战》。开篇先把人工智能与AI安全是怎么起来的、世界主要经济体的AI战略是怎么布局的理清，给出AI安全技术的发展脉络与总体框架。随后从实战切入，重点拆解对抗样本、数据投毒、模型后门这三类攻击的手法与案例，并做技术详解。之后再深入预训练模型的安全风险、AI数据隐私被窃取的路径、AI应用失控的隐患，并配上实战案例与数据佐证。最后对AI安全的未来走向进行展望，讨论风险、机遇、发展理念与产业构想。

这本书适合AI和AI安全领域的研究人员、管理人员，以及想靠实战案例学习的爱好者阅读。

# 四位业内前辈的推荐视角

**张正友 腾讯首席科学家、腾讯AI Lab和腾讯Robotics X实验室主任**

人工智能被视作引领第四次工业革命迈向智能化的核心引擎。理论和技术日趋成熟，应用场景不断扩张，它把数字世界、物理世界和生物世界打通，形成我所说的“虚实集成世界”。AI正在帮助各行各业完成智能化跃迁，并创造大量新机会，未来可期。

但问题也很清晰：今天这波以深度学习为主的技术，高度依赖大模型、大数据与云服务。大模型参数庞大、可解释性差，容易被对抗样本攻击；大数据噪声多、质量难控，给攻击者留下数据投毒的空间；云服务虽带来低成本算力与便利，却也为攻击者提供了便利渠道，导致隐私泄露与应用失控。

腾讯同事朱雀实验室的小伙伴从2019年起就深耕AI安全，涵盖模型安全、AI滥用、AI伦理，并构建完善AI安全蓝图并落地应用。这本书是他们多年研究与实践的沉淀。那些踩过的坑和成功的案例，对AI安全的研究与管理者帮助极大。

**江勇 清华大学教授 2022年7月于南国清华**

得益于硬件与算法的快速演进，以深度学习为代表的人工智能已广泛进入人脸识别、自动驾驶、物联网等关键应用。因其内生的脆弱性，AI的发展也带来了新的安全问题。而这种内源性安全问题，传统信息安全手段很难直接解决，系统性研究与对应解法变得必要。

AI内源安全探索可追溯到上世纪中叶对传统机器学习算法鲁棒性和稳定性的研究。近现代的研究聚焦于以深度神经网络为代表的深度学习，覆盖数据采集、训练、部署、预测等全生命周期，目的多为误导模型输出或窃取用户隐私。误导类研究包括数据投毒、后门攻击、对抗攻击、深度伪造等；隐私窃取类包括成员推断、属性推断、深度梯度泄露等。这些新威胁给AI系统带来重要挑战。

国内关于人工智能安全的专著并不多。腾讯安全朱雀实验室编著的《AI安全：技术与实战》以应用场景为视角，除了简要回顾重要技术，还提供了含代码在内的多个代表性实战案例。书既可作教材供高年级本科生与研究生学习，也可作白皮书供研究、开发与管理者及AI爱好者查阅，有助于更快更深地理解AI安全技术在真实场景中的部署。

**吴石 腾讯安全科恩实验室负责人**

AI安全应分两面看：一是用AI解决安全问题，二是确保AI系统自身安全。前者目前很热，随着移动互联网与云计算普及，数据井喷，如何从中挖掘信息助力安全建设已有成熟方法，如垃圾邮件分类。恶意代码判别、恶性行为识别等领域也在稳步推进。

朱雀实验室这本书讲的是后者——AI系统本身的安全性。市面上相关著作不多，此书及时填补了空白。

AI系统的演进大致分三阶段。最早是专家系统，把专家经验变成确定规则，在安全产品中广泛应用，如AV、WAF、防火墙、IDS，但专家经验有限，大量场景可被绕过，二进制攻防领域20年来的努力也证明这是难以完成的任务。

第二阶段是传统数据处理算法，如SVM、贝叶斯分类。垃圾邮件分类是典型成功案例，但前提是基于人工标注数据训练并用专家经验提取特征，掌握原理后绕过、误导并不难。

第三阶段是当下流行的深度学习系统，最大的痛点是不可解释，原理不明却往往很准，出错时却无法修正也无法解释为何出错。2020年左右对多款电动车自动驾驶系统做的安全测试触目惊心，大多数系统存在严重安全问题，可被轻易误导导致严重交通事故。

此书对AI本身安全问题做了全面梳理，并对AI安全测试方法做了细致分类讲解，实用性强。无论研究AI还是安全，价值都高。随着AI推广，AI安全将成为安全研究的中心议题，本书是进入该领域的良好向导。

**欧阳欣 阿里云安全负责人**

AI技术发展影响生活，甚至安全产品检测攻击也广泛应用AI。但AI本身安全吗？

本书并非纯理论著作。作者团队在AI安全领域深耕多年，总结了针对数据、算法、模型的多种攻击技术，用具体案例证明了AI在安全上的脆弱性，也给出了防御方案。攻与防永远是螺旋上升，“AI安全”只是开始。

我将此书推荐给每一位安全从业者。除此之外，最优秀的程序员一定懂得写出安全的代码，因此我也推荐给每一位AI从业者，共同打造安全的AI。

# 作者序与前言：从黑产到蓝图

**杨勇 腾讯安全平台部负责人 2022年6月于深圳**

2016年Google AlphaGo横空出世，让大众对AI能力改观，AI技术迅速渗透各行各业，带来商业繁荣的同时也带来担忧。AI赋能的内容平台让我们更了解世界，也制造信息茧房；商业平台带来便捷，也带来“大数据杀熟”等副作用。我们被AI计算，同时也被AI算计。

多年前团队曾遇到一个特殊黑产团伙，使用当时流行的Caffe深度学习框架与卷积神经网络，攻击效率远超竞争者。这让我们意识到未来AI将成为安全攻防两端的兵家必争之地。

此后团队在AI安全方面开展大量探索，覆盖：AI技术本身安全性、AI技术为攻击赋能、AI技术为防守助力、AI技术以攻促防攻防联动。走了弯路也有收获，站在前辈肩上，我们将点滴工作总结成书。

本书锚定AI安全通用技术，包括对抗样本攻击、数据投毒攻击、模型后门攻击、预训练模型风险与防御、AI数据隐私窃取攻击、AI应用失控等。对各类攻击原理与实现过程、案例总结做了分析，保持原汁原味便于参考。

安全与技术日新月异，本书内容会过时，我们会持续探索更新。希望以管中窥豹抛砖引玉，结识更多志同道合者。科技的力量会让文明更美好，虽道阻且长，行则将至。

**腾讯安全朱雀实验室前言**

朱雀实验室2019年起着手AI安全研究，涉猎对抗样本攻击、模型安全、AI应用失控等。开始从对抗样本入手，多场景实现通过微小篡改欺骗模型，并在腾讯业务中寻找落地。然而实验反复显示对抗样本迁移性有限，A模型生成的样本很难在B模型上生效。2019年底转向研究高迁移性对抗样本，并在ECCV、CanSecWest等会议分享成果。产业落地仍显困难。

2020年后研究拓宽至模型安全、AI滥用、AI伦理，并完善AI安全蓝图。模型安全方面，在XCon2020、ICLR2021安全研讨会、CVPR2022等会议分享非数据投毒式模型后门攻击，验证在掌握少量模型信息下通过精准修改网络参数重建后门的可能性，进一步揭示算法脆弱性。

AI应用失控方面，围绕深度伪造带来的风险，一方面揭露安全隐患，一方面落地检测工具并连续两年在安全会议分享成果。除语音攻击、文本攻击外也做了大量实验。

与AI算法打交道发现，当前基于深度学习的系统易受对抗样本攻击。业务侧重功能，安全滞后，往往出现案例后才补救，修补成本高，需反复调整训练数据与优化；AI研发过程也未引入安全把控，理论上攻击方法丰富，即便系统仅提供API，攻击者也可通过模型窃取拟合线上决策，建立本地白盒模型后再迁移攻击。

总体看，攻击方法目前领先防御。总结攻击可寻找有效防御，也可把网络安全防御思想引入AI建设，在研发中引入SDL规范，如敏感数据检测、对抗样本训练、及时更新库和框架。

本书第1章概述AI安全发展；第2-3章从数据层面讨论对抗样本与数据样本安全；第4-5章从模型层面讨论模型后门与预训练模型安全；第6-7章从应用角度讨论隐私窃取与应用失控。精选多个实战案例，力求把数据、算法、模型、应用层面的安全问题呈现。

AI安全未来挑战更严峻，愿与同行共同推动发展。感谢电子工业出版社支持，以及杨勇、朱季峰、唐梦云、徐京徽、宋军帅、李兆达、骆克云等同事的付出。

# AI安全发展概述

近年来AI上升为国家战略，成为推动产业数智化与智能化的重要依托。在经济利益驱动下，对抗样本攻击、数据投毒攻击、模型后门攻击等针对AI系统的算法与数据攻击频繁出现，AI的可用性、可靠性、可知性、可控性遭遇挑战，严重影响技术发展与产业实践。

国内外安全研究组织与学术工程界对AI安全的重视达到新高。本书结合政策与技术发展趋势，对主流攻击手法进行原理分析与技术实践，以提升行业风险认知与防范能力。

**AI与安全的衍生**

AI学术起源较早，直至近20年计算资源长足进步才为其从理论走向实践奠定基础。各国普遍认可AI是第四次工业革命关键领域，在科研、产业、市场多方面布局。然而只有同步发展AI安全，才能有效控制安全、隐私与伦理风险，形成良好产业生态。

**AI发展图谱**

1956年美国达特茅斯学院研讨会上，麦卡锡、明斯基等人提出“人工智能”概念，标志学科诞生。60余年来，AI应用程度与范围不断深化，成为第四次工业革命战略性基础技术，在机器人、自动驾驶、智慧交通、智能制造、智慧医疗、智慧城市等领域产生深远影响。

21世纪以来，文字、语音、视频信息通过网络爆炸式增长，芯片与计算技术带来的算力提升，为特征降维、人工神经网络、概率图形模型、强化学习、元学习等新理论技术提供数据与算力基础。以图像识别、语音识别、自然语言翻译为代表的技术已普遍部署。

AI安全随之发展并重塑传统安全。现阶段其内生特征与伴生特性正从模型安全、数据安全、系统安全演进为泛安全领域重要基础。数据隐私、算法偏见、技术滥用已成为智慧社会治理与产业数字化转型中的重要挑战。AI安全不仅带来技术与隐私变革，也带来伦理与秩序的深思，已成为产业安全、经济安全、社会安全乃至国家安全的重要基础要素。

**各国AI发展战略**

全球AI蓬勃发展，各国纷纷布局战略并构建安全标准规范体系。

美国方面，2016年奥巴马政府发布3份AI发展报告，从AI对网络安全影响、重点领域及自动化对经济影响布局。2017年特朗普政府发布新版《国家安全战略报告》，提出在AI研发、技术、创新方面发挥领导作用，并出台6份AI战略，从AI在情报体系应用、研发重点、AI与国家安全布局。2021年拜登政府设立国家AI倡议办公室，负责监督实施国家AI战略。同年6月，白宫科技政策办公室与美国国家科学基金会宣布成立国家AI研究资源工作组，打造共享研究基础设施，提供算力、数据、教育工具与用户支持。

中国方面，2017年7月发布《新一代人工智能发展规划》，从战略态势、资源配置、立法、组织等层面规划，要求加强AI标准框架体系研究，到2020年初建成包括AI网络安全与隐私保护等技术标准。工信部在《工业和通信业“十三五”技术标准体系建设方案》中提出到2020年完善AI网络安全产业布局，形成防控体系框架。2020年7月27日，国家标准化管理委员会联合中央网信办、发改委、科技部、工信部等五部委印发《国家新一代人工智能标准体系建设指南》，要求到2021年明确顶层设计，完成含AI安全和伦理在内的重点标准预研，到2023年初步建立AI标准体系。

欧盟也在同步推进相关战略布局与标准建设。
