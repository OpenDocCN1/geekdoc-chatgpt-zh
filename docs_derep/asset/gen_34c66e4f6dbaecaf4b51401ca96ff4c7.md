# 第 7 章　人机言语交互与计算

## 7.1　概述

口语交流是人类连接彼此、传递信息的核心方式\[1\]。在真实对话里，人们不仅要辨识字面所说的词句，还会调动常识与专业知识去揣摩语境，推算出言语背后的意图，并在此基础上实现思想与观点的互通。进入互联网时代后，这套交互范式被延伸到人机场景，成了人与机器沟通的主要通道，也被视作智能时代自然交互的关键表现。

对照第 1 章的论述，传统计算机多以图形用户界面为主，依赖窗口、按钮、菜单与键盘鼠标完成多轮操作。相较之下，言语交互让用户的想法与意图可以直接表达，无须经由图形符号转译，从而跳过了 GUI 原语的限制，也降低了转译过程中产生的歧义与理解偏差。言语交互还能解放双手，支持多通道协同。举例来说，用户在对某张图片下指令时，往往需要鼠标指向目标、甚至做出演示手势，这时用语音发出指令就能不干扰其它通道的动作，多个信息流可以并行配合。对可穿戴等新形态设备而言，传统 PC 式交互已难以落地，而语音交互正因其自然、贴合人类使用习惯，被赋予更重要的角色，能明显提升生活与工作的效率与体验。

这里的言语可指口语化文本，既可直接以文本输入产生，也可经语音识别后再转化为文本。要让言语交互在具体场景中可用，必须靠语音采集、语音识别、自然语言理解、语音合成等多环节协同。每个环节都需要领域知识支撑，并在鲁棒性、灵活性、可整合性、实时性等方面面临挑战。本书聚焦智能人机交互层面，本章不追求搭建完整的言语交互系统并逐项展开实现细节，而是从交互角度对言语交互过程进行建模，给出意图理解与计算的通用思路与框架。

本章先简要回顾语音识别的技术演进；随后提出言语表示模型与基于语义三角形的交互模型，用以刻画知识迁移过程，实现人机双方的知识空间共享；在该基础上结合自然语言理解技术，重点阐述“开发-探索融合”式的言语交互意图理解与计算方法；最后以金融审计的实际案例说明上述理解方法在落地中的表现。

## 7.2　语音识别技术

语音识别横跨语言学、声学与计算机科学，其基本任务是将人类发音自动转为可读文本，为言语交互提供底座。20 世纪 90 年代后，研究重心从标准朗读语音转向更不规则的真实语音\[2\]。近二十年里，伴随深度学习的爆发，语音识别从实验室走向产业，已渗透工业、家电、通信、车载、医疗、家庭服务、消费电子等多个领域，重塑了人们的生活方式。

传统方法大致包含特征提取、模式匹配、模型训练三块，痛点集中在噪声环境下的识别、语音情感识别与多说话人识别。面向噪声的稳健特征提取，常见做法有人耳听感相关的特征提取方法\[3，4\]、子带能量归一化方法\[5\]与特征归一化方法\[6\]。声学建模与训练方面，以最小音子错误准则为导向的判别训练\[7\]与高斯子空间建模\[8\]成为主流，二者兼顾模型空间与特征空间，在多个任务上得到广泛应用。后来将深度信念网络 DBN 与隐马尔可夫模型 HMM 结合的建模思路\[9\]显著提升了系统性能。语言模型层面，目前多采用大规模分布式语言模型\[10\]。解码器上，基于加权有限状态转换器 WFST 的方案\[11,12\]逐步取代动态扩展搜索网络，能把语言模型、词典与声学共享音字集整合成统一解码网络，大幅加快解码速度，为实时应用奠定基础。

2009 年后，在机器学习尤其是深度学习以及海量语料积累的推动下，语音识别迎来了跃进\[13,14\]。一方面，研究者把深度学习引入声学模型训练，用带 RBM 预训练的多层神经网络取代繁琐的人工特征工程，准确率明显提升。微软的研究团队率先用深层神经网络 DNN 将错误率降低约 30%，成为近二十年最具代表性的突破之一\[15\]。随后涌现出卷积神经网络 CNN、基于长短时记忆 LSTM 的循环神经网络 RNN、带注意力机制的深度网络以及面向语音识别专门设计的深度架构\[16\]等一系列表征与建模方法。另一方面，互联网与移动终端普及带来了大量语音与文本语料，部分语料已有人工标注，为语言模型与声学模型的训练提供了充足样本，使通用大规模模型构建成为可能。GPU 的并行能力也加速了大规模深度网络的训练，推动语音搜索与语音人机交互快速发展。

作为一种简便易用的自然交互手段，语音识别在移动端的应用日趋火热。语音对话机器人、语音助手、互动工具等产品层出不穷，众多互联网公司投入资源抢占市场。国外以苹果 Siri 为代表，国内科大讯飞、云知声、盛大、捷通华声、搜狗语音助手、紫冬口译、百度语音等均采用了基于深度学习的最新识别技术，并在多种场景落地，准确率已达到较高水平，为后续的语义分析与理解提供了坚实基础。

鉴于本书重点在于智能人机交互，本章不深入展开语音识别与语音合成等机器学习细节，主要关注口语化文本的分析理解，说明人与计算机知识的表征、迁移与计算如何在交互中协同。

## 7.3　言语表示与交互模型

要构建言语交互模型，首先需要对言语信息做统一规范的表征。语义三角形在表征与建模两方面都发挥关键作用。本节先梳理言语信息的特点，再介绍语义三角形相关概念，随后定义言语表示模型，该模型既可用于人机交互，也可用于互联网用户的言语表示；在此基础上提出基于语义三角形的言语交互模型，用以刻画交互中的知识转移与共享。

### 7.3.1　言语信息的特点

无论是人机交互还是互联网用户间的交流，言语交互行为都以言语碎片形式出现。它包含语音与口语化文本两个层面。例如，用户向计算机发送的一条文字指令就是一个言语碎片，网络聊天中的一段对话也可视为言语碎片。与书面长文本不同，言语碎片通常是短文本，语法与语义往往不够规范，单纯依赖传统自然语言理解技术效果有限。但其中蕴含的副语言信息对行为分析与意图理解具有重要价值。言语信息的主要特征可归纳为：

(1)交互双方的身份信息与关系信息，可由用户 ID 及 ID 间的关联网络获取。该信息有助于建立群体言语交互模型，分析群体共有的与特有的交互习惯、方式、偏好，以及群体间相互依赖关系，并预测未来行为。其中计算机可被视为具有特殊 ID 的用户，纳入关系网络中。

(2)交互的时间与地点信息，可通过言语碎片发布时间、用户 IP 地址及文本内容分析获得，形成多变量时间序列，建立时空数据库，为人机协同的交互式多尺度可视化分析提供基础数据。

(3)交互的类型信息，可分为原创、回复、转发三类，会影响言语碎片的重要性及其与交互模型的关系。在人机言语交互中，类型可用来区分计算机构成的参与程度，例如被动回复、主动提问、主动回复等。
