## 3.3 LlamaIndex 究竟指什么

在以大模型为核心的开发赛道上，LangChain 并不独占。LlamaIndex 同样是备受好评的开源 AI 应用开发框架，它于 2022 年 11 月公开发布，与 ChatGPT 同期问世，比 LangChain 晚出约一个月。两者都深受 ChatGPT 影响并获得广泛采用。

### 3.3.1 来历与定位

LlamaIndex 由 Jerry Liu 发起，并于 2023 年 6 月完成 850 万美元种子轮融资。它直面大模型缺乏训练外知识的局限，因此在 AI 社区获得不少关注。

与 LangChain 走“大而全”路线不同，LlamaIndex 更聚焦先进的基于 AI 的 RAG 技术以及多租户 RAG 系统的构建。依托 LlamaIndex 的企业方案强调消除技术与安全壁垒，提升企业数据利用与服务能力。其工作不仅限于技术研发，也重视把技术落地到真实业务场景，提升运营效率与客户体验。

> 小雪：多租户到底指什么？
> 
> 咖哥：在一个 RAG 系统里，用户 A 和用户 B 各自拥有独立的文档集合。多租户机制保证 A 查询时只调取自己的资料，不会被 B 的数据干扰，反之亦然。这是保障数据隔离与安全的基本手段。

另外值得一提，LlamaIndex 在文档结构与可执行性方面明显优于 LangChain，体现了其在用户体验、接口设计和工程实现上的投入。对开发者与终端用户而言，这类优势有助于技术普及与使用效率提升。

或许正因 LangChain 功能过于庞杂，面面俱到反而显得繁琐，细节处理不够细致。查阅 LangChain 的 GitHub 主页，未解决的 Open Issues 超过一千条。因此若核心需求是文档检索与生成增强，选择“小而美”的 LlamaIndex 更契合。

### 3.3.2 LlamaIndex 与 RAG 驱动的 AI 开发

RAG 是当前 AI 应用开发的重要方向，与 Agent 同等重要。RAG 的核心是检索加生成：先从相关数据源检索信息，将其作为上下文注入用户提问，再由大模型基于丰富提示生成答案。与 Agent 类似，RAG 也有大量落地案例，从某种角度看，RAG 应用本身也是一种 Agent，或可作为 Agent 构建的关键组件。

先从宏观角度解释 RAG 的价值。将大模型应用于特定行业，从难到易大致有四种路径：从零训练或重建模型、微调、动态提示 ——RAG 属于此类，以及最简单的提示工程，见图 3.18。RAG 处于中间地带，比重训或微调轻松，比直接提问复杂。它规避了直接微调的三大痛点：成本高、信息更新难、可观察性差。RAG 无需训练成本更低；数据实时获取始终新鲜；检索文档可展示，结果更可信。

具体包含的组件如下：

- 数据连接器：从原始来源和格式中抽取已有数据，API、PDF、SQL 等均有对应读取接口。

- 应用集成：将 LlamaIndex 接回其他生态系统。

RAG 与 Agent 紧密相关。LlamaIndex 通过 RAG 管道、框架与工具，为 Agent 补足可控性与透明度短板。其 Agent API 支持逐步执行，可处理更复杂的任务。同时在 RAG 循环中支持用户反馈，特别适合长期任务，实现用户与 Agent 交互及中间执行控制的双循环。

整个流程共 6 步。

1. 用户提交查询：用户向系统提出问题或请求。
2. Agent 搜集相关信息：Agent 根据查询检索相关信息，可能来自互联网或特定数据库，企业内部信息通常存于向量数据库。
3. 检索信息：从搜索结果中抽取具体信息，作为生成回答的上下文。
4. 将相关信息传给大模型：Agent 把检索结果与原始查询一起交给大模型。
5. 大模型生成响应：大模型利用这些信息生成丰富且信息化的答案。
6. 返回用户请求：最后将大模型生成的答案交还用户，答案基于原始查询与检索到的信息。

过程也可以循环，每次查询都会优化后续交互。如需更多信息或有追问，系统会提示额外查询，并利用前次回答丰富新上下文。这样能提供更动态、交互式的体验，让用户用自然语言完成复杂交互。

借助 LlamaIndex 搭建上述基于 RAG 的 Agent 十分轻松。它面向从新手到资深的开发者，高级 API 允许初学者用 5 行代码完成数据提取与查询；底层 API 则让高级用户按需定制与扩展模块。

## 3.4 小结

OpenAI 等大模型头部厂商的创新，为开发者构建类 Agent AI 应用提供了新工具，推动 LangChain、LlamaIndex 等生态发展。这些工具各有侧重，但都致力于更高效灵活的 AI 应用开发，从而推动行业创新与协作，带来更丰富场景和更强开发能力。

两者各具特色：LangChain 是“大而全”，LlamaIndex 是“小而美”。它们既竞争又合作，可相互调用。竞争促使其不断优化，合作则让整个生态更进步，最终让开发者和用户受益。

随着大模型技术持续演进，这些工具也在不断迭代。它们让构建复杂智能 Agent 成为可能，并不断拓展 AI 的边界和应用领域。

借助这些工具，我们能打造更智能、更高效的 Agent，在各种复杂环境中执行任务和提供服务。随着技术进步，会有更多创新应用出现，推动人工智能边界持续拓展。

当然，大模型应用开发仍处“婴儿期”，开发者和组织面临诸多挑战：API 调用频率与性能、程序稳定性与效率、未来可扩展性与维护，以及数据隐私、安全、伦理与效率等问题。同时机遇也巨大，可以创造更智能、更有用的工具和服务，为各行业带来变革。
