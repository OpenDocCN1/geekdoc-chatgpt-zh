### 9.3 Skills 拓展：内置够用，自定义更好
OpenClaw 的价值不止于框架本身，其 Skills 生态极具延展性。除开自带的联网搜索、天气查询等基础能力，还能通过自定义 Skills 把专业边界不断拓宽。

#### 9.3.1 内置技能快速上手
在飞书里问 OpenClaw“目前有哪些 Skills 技能？”它会列出当前启用的核心技能，如 图9-22。
实际上技能库远比预期丰富。在扣子编程 OpenClaw 的“预览”页点开“技能”标签，如 图9-24，能看到 WORKSPACE SKILLS、BUILT-IN SKILLS 与 EXTRA SKILLS 三类，共 59 项内置 Skills。

## 图9-24 技能总览
以天气 Skills 为例，几乎零配置就能用。直接在飞书里用自然语言发送：

今天北京的天气怎么样？

稍等片刻，OpenClaw 会自动识别意图、调用天气 Skills 并给出精简结果，如 图9-25。

## 2. 用自然语言创建定时任务
OpenClaw 内置 Cron 定时支持，无需手写 Python 定时脚本，只需用自然语言下指令：

是否能基于 stock-limit-up-screening Skills 帮我实现在每个交易日的晚上 20 点，定时调用该 Skills，抓取和筛选股票，然后把结果通过飞书推送给我

发送后 OpenClaw 会解析 Skills、用 Cron 配置任务并立刻做一次验证，具体过程见 图9-27。
