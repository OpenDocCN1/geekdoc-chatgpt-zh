让 BERT 更快：ONNX+量化+FastAPI 上线全记录

在项目落地时，推理速度和可调用性往往比模型本身更关键。下面以 BERT 为例，先把模型做成 ONNX 再尝试动态量化压测，最后用 FastAPI 把 DistilBERT 情感分类封装成在线接口并容器化，整个链路可直接复用。

ONNX 导出与校验
先把 bert-base-uncased 转为 ONNX，输入端口取名 input_ids、attention_mask、token_type_ids，输出端口用 logits，运算符集选 12，batch 维设为动态以便不同批大小。导出后用 onnx.checker.check_model 做一次结构检查，通过后再借助 ONNX Runtime 加载同一文件推理。张量搬运用一个小工具把需要梯度的张量先 detach 再搬到 CPU 转 NumPy，不需要梯度的直接搬运，喂给会话得到的 logits 与原 PyTorch 结果基本一致。

动态量化对比
量化只动线性层。调用 PyTorch 的 quantize_dynamic 接口把模型先搬到 CPU，目标模块限定为 torch.nn.Linear，量化精度用 INT8。量化完再搬回设备跑同样的输入，输出数值漂移很小。实测原始模型单次前向约 0.0241 秒，量化后降到约 0.0153 秒，整体提速接近 1.58 倍。

第一个示范基于 distilbert-base-uncased-finetuned-sst-2-english，自动检测 CUDA，加载分词器与模型后定义请求体 TextRequest 和响应体 TextResponse。/analyze 接口先校验文本非空，再做截断填充编码，推理后经 softmax 得到概率，标签映射为 negative 与 positive 并返回置信度。应用元数据里带上标题与说明，本地开发用 uvicorn 热重载启动。

[PRE2]python

from fastapi import FastAPI, HTTPException

from pydantic import BaseModel

from transformers import AutoTokenizer, AutoModelForSequenceClassification

import torch

# 检查 CUDA 设备

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

print(f"当前设备: {device}")

# 加载预训练模型和分词器

model_name = "distilbert-base-uncased-finetuned-sst-2-english"

tokenizer = AutoTokenizer.from_pretrained(model_name)

model = AutoModelForSequenceClassification.from_pretrained(

    model_name).to(device)

print(f"已加载模型: {model_name}")

# 定义 FastAPI 应用

app = FastAPI(title="情感分析 API",

    description="基于 FastAPI 的 RESTful 接口实现情感分析", version="1.0")

# 定义请求体

class TextRequest(BaseModel):

    text: str

# 定义响应体

class TextResponse(BaseModel):

    sentiment: str

    confidence: float

# 定义 API

@app.post("/analyze", response_model=TextResponse)

async def analyze_sentiment(request: TextRequest):

    # 获取输入文本

    input_text = request.text

    if not input_text:

        raise HTTPException(status_code=400, detail="输入文本不能为空")

    # 文本编码

    inputs = tokenizer(input_text, return_tensors="pt", truncation=True,

        padding=True, max_length=128).to(device)

    # 模型推理

    with torch.no_grad():

        outputs = model(**inputs)

        logits = outputs.logits

        probabilities = torch.nn.functional.softmax(logits, dim=-1)

    # 解析结果

    labels = ["negative", "positive"]

    predicted_index = torch.argmax(probabilities, dim=1).item()

    sentiment = labels[predicted_index]

    confidence = probabilities[0][predicted_index].item()

    return TextResponse(sentiment=sentiment, confidence=confidence)

# 启动服务

# 使用以下命令运行服务: uvicorn script_name:app --reload

if __name__ == "__main__":

    import uvicorn

    uvicorn.run(app, host="0.0.0.0", port=8000)

精简版实现
如果只想快速上线，还可以用更短的写法，接口改成 /predict，逻辑等价，同样先装依赖。

[PRE8]

pip install fastapi uvicorn transformers torch

[PRE9]python

from fastapi import FastAPI, HTTPException

from pydantic import BaseModel

from transformers import AutoTokenizer, AutoModelForSequenceClassification

import torch

# 加载模型和分词器

model_name = "distilbert-base-uncased-finetuned-sst-2-english"

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

tokenizer = AutoTokenizer.from_pretrained(model_name)

model = AutoModelForSequenceClassification.from_pretrained(

    model_name).to(device)

# 创建 FastAPI 实例

app = FastAPI()

# 请求体

class TextRequest(BaseModel):

    text: str

# 响应体

class TextResponse(BaseModel):

    sentiment: str

    confidence: float

@app.post("/predict", response_model=TextResponse)

async def predict(request: TextRequest):

    text = request.text

    if not text:

        raise HTTPException(status_code=400, detail="输入文本不能为空")

    # 文本预处理

    inputs = tokenizer(text, return_tensors="pt", truncation=True,

        padding=True, max_length=128).to(device)

    # 模型推理

    with torch.no_grad():

        outputs = model(**inputs)

        probabilities = torch.nn.functional.softmax(outputs.logits, dim=-1)

        label = torch.argmax(probabilities, dim=1).item()

        confidence = probabilities[0][label].item()

    sentiment = "positive" if label == 1 else "negative"

    return TextResponse(sentiment=sentiment, confidence=confidence)

# 运行服务

if __name__ == "__main__":

    import uvicorn

    uvicorn.run(app, host="0.0.0.0", port=8000)

容器化
生产环境建议用 Docker 固化环境。基于 python:3.9-slim，先拷 requirements 安装依赖，再拷源码，最后用 uvicorn 启动。

[PRE11]dockerfile

# 基础镜像

FROM python:3.9-slim

# 设置工作目录

WORKDIR /app

# 安装依赖

COPY requirements.txt .

RUN pip install -r requirements.txt

# 复制代码

COPY . .

# 启动服务

CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "8000"]
