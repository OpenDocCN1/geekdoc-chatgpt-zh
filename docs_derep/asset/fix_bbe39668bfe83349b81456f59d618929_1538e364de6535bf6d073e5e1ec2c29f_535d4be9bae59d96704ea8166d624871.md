决策树分类是通过分层决策对新样本进行类别预测的常用方法。以下介绍其基本原理、构建流程与使用要点。

**1．基本原理**
决策树采用树形结构，内部节点用于测试属性，分支对应测试结果，叶节点对应类别。分类时自根节点出发，根据实例特征与节点条件对比沿分支下移，直至抵达叶节点，叶节点所代表的类别即为预测结果。

**2．构建流程**
构建通常包含属性挑选、树生成与剪枝三部分。

（1）属性挑选：为当前节点选择最优分裂属性。常用方法有 ID3 的信息增益、C4.5 的增益率、CART 的基尼指数等。
（2）树生成：从根节点开始，利用属性挑选方法确定最优属性，按该属性不同取值生成子节点；随后对子节点递归执行相同过程，直至满足停止条件，如节点样本全属同一类别或达到预设深度，生成结束。
（3）剪枝：为避免过拟合，需对树进行剪枝。预剪枝在构建过程中提前终止树的生长；后剪枝则先生成完整树，再自底向上检查非叶节点，若合并子节点可提升验证集准确率，则将该节点转为叶节点。

**3．分类应用**
构建完成后即可用于新样本分类，具体为：
（1）从根节点开始：将待分类实例特征与根节点测试特征对比。
（2）沿分支移动：依据对比结果选择相应分支进入下一节点。
（3）重复操作：不断重复，直至抵达叶节点。
（4）确定类别：到达的叶节点所对应的类别即为预测类别。

决策树易于理解与解释，可处理数值与类别数据，对预处理要求较低。不足在于易过拟合、对类别不平衡等问题处理有限，实际中常与其他方法结合，如随机森林等集成算法可提升性能。

SVM 是一种在分类任务中表现优异的机器学习方法。其核心思想是寻找最优超平面以分隔不同类别样本。SVM 的独特优势在于能处理线性不可分数据，主要得益于核技巧的应用。通过将数据映射到更高维空间，原本线性不可分的样本可能变得线性可分，从而实现有效分类。

**1．关键概念**

（1）超平面：SVM 用来分割不同类别数据的决策边界。二维中为直线，高维中为平面。目标是找到间隔最大的超平面，该间隔由支撑向量决定。
（2）支撑向量：距离分割超平面最近的数据点，决定超平面位置与方向。只有这些点变化才会影响边界。支撑向量是训练过程中唯一起作用的点，使 SVM 在大规模数据上更高效。
（3）松弛变量：实际数据往往不完全线性可分。引入松弛变量允许部分数据点违反最大间隔要求，通过惩罚项控制违背程度，在准确性与泛化能力间取得平衡。
（4）软间隔与硬间隔分类：处理线性不可分数据的两种策略。硬间隔要求所有数据点完全符合分类规则；软间隔允许一定违背，通过松弛变量实现，提高灵活性和鲁棒性。
（5）样本不均衡：数据集中类别样本数量差异大。SVM 通过调整不同类别的惩罚参数 C 处理不均衡，为少数类样本分配更大惩罚，使模型更关注少数类。

**2．核函数**

核函数在 SVM 中起关键作用，可在不显式映射数据到高维空间的情况下找到最优分割超平面，即核技巧，极大提升处理非线性问题的能力。核函数选择直接影响模型性能，常见核函数如下。
（1）线性核函数：最简单，不做映射，直接在原始空间寻找最优超平面，适用于线性可分数据。
（2）多项式核函数：通过多项式变换将数据映射到高维空间，参数包括多项式度数，可根据数据特点调整。
（3）径向基函数：又称高斯核，是常用选择之一。通过指数函数将每个数据点映射到无限维空间，适合处理非线性问题。

**3．利用 ChatGPT 进行 SVM 分类分析**

（4）Sigmoid 核函数：将数据映射到 Sigmoid 函数定义的空间，形式类似神经网络激活函数。
（5）复合核函数：通过组合不同核函数以适应数据特殊需求，提升模型灵活性和准确性。

核函数选择取决于数据分布与特性，没有通用最优核。通常可通过交叉验证评估不同核函数对模型性能的影响来挑选最佳方案。例如线性核适合特征维度高于样本数的情况；多项式核与 RBF 适用于非线性可分数据，其中 RBF 因灵活且参数少而更受欢迎；Sigmoid 核与复合核提供了更多试验空间以适应复杂关系。
