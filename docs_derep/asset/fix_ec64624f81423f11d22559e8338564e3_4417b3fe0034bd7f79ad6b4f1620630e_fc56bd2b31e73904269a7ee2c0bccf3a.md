在浏览器里跑大模型：WebLLM 拆解

WebLLM 对本地硬件仍有门槛。Windows 端建议显卡显存达到 6 GB 以上，Mac 端则以 M1 及更新的芯片为基准。

为什么这套方案会引人注目，算力成本是关键。过去语言服务的推理全靠厂商买单，账单很容易变得庞大。若把推理压到用户自己的设备上，这笔开销就能被大幅转移，厂商可以更聚焦于服务本身。今天已有部分终端能够承担大模型的本地推理，但普及度还低，硬件还要几年迭代。一旦大多数电脑和手机都能独立运行大语言模型，算力的重心必然向个人端偏移，这条技术路线持续演进也就很有必要。

成本压力被稀释后，大模型赛道会吸纳更多中小团队甚至个人开发者。训练阶段仍能租用算力，模型训练完只需对外提供服务，最终由用户用自己的算力去运行他人训练好的模型。

从官方说明来看，WebLLM 的核心思路是基于 Apache TVM Unity 的机器学习编译，并利用其原生的动态形状能力对语言模型的 IRModule 做优化，不必把序列硬补到最大长度。整体实现由多个开源组件拼接而成，包含 LLaMA、Vicuna、Wasm 与 WebGPU。主流程依托 Apache TVM Unity 搭建，流程见图11-6所示。

[PRE0]

图11-6 WebLLM流程图

在支持原生动态形状的 TVM 中，WebLLM 会先行烘焙语言模型的 IRModule，避免补齐到最大长度，从而降低计算量与内存占用。具体优化如下：

- （1）TVM 的 IRModule 里每个函数都可继续变换并生成可运行代码，只要配备最小 TVM 运行时即可在各环境部署。
- （2）TensorIR 是生成高效程序的关键。WebLLM 结合专家经验与自动调度器，把 TensorIR 程序快速改写为高性能版本。
- （3）启发式手段被用来打磨轻量算子，减少工程调优负担。
- （4）借助 int4 量化压缩模型权重，使之更易装进内存。
- （5）构建静态内存规划，让多层之间能复用内存。
- （6）以 Emscripten 与 TypeScript 搭建可部署生成模块的 TVM Web 运行时，同时接入 SentencePiece 分词器的 Wasm 端口。

大语言模型的另一特征是动态性。解码与编码的计算随 token 数量增长，WebLLM 利用 TVM Unity 的一流动态形状支持，用符号整数表示序列维度。这样可以在运行前就对关注的序列窗口做静态分配，并一次性规划好所需内存，无需填充。

除了 WebGPU，WebLLM 还提供本地 GPU 运行时选项，本机部署也没问题。因此它既可作为本机环境下的部署工具，也可用来对照原生 GPU 驱动与 WebGPU 的表现。

## 11.4 ChatBox

ChatBox 是一款跨平台的 ChatGPT 桌面客户端。网页体验在高频使用下往往不如客户端，本人长期在用，覆盖 Windows、macOS 与 Linux。客户端通过调用 API 访问语言模型，所以模型种类比较多，当下版本支持的模型如图11-9所示。

目前可接入 OpenAI API、Azure OpenAI API、ChatGLM-6B、Claude，且每个会话能单独切换模型，例如会话 A 用 GPT3.5，会话 B 就能用 GPT4。每个会话可按任务挑选合适的模型与版本，切换需求主要来自场景差异，只做纯文本整理时 GPT3.5 就够用；遇到需要逻辑推理的任务，GPT4 更出色。

各版本的计费规则和 token 上限并不相同，使用 ChatGPT 时挑对版本是比较好的做法。

[PRE3]

图11-9 ChatBox支持的语言模型

深度使用中少不了导出功能。前面讲过用 ChatGPT 学一门课程，先让它整理大纲，再让它逐章输出，某个知识点还能继续追问，这样一份完整的课程笔记就能导出。ChatBox 可以把当前会话的全部对话导出为 Markdown。

Markdown 是一种轻量标记语言，目标是易读易写。因为是纯文本，任何文本编辑器都能打开，也很容易转成 HTML 或其它格式。现在很多笔记应用都支持 Markdown 与 Word 的互转。

客户端左下方有“我的搭档”工具，是一些预置的提示，如图11-10所示。

创建“夸夸机”搭档后会新建一个会话窗口，窗口内有一条置顶提示，后续对话会遵循它。夸夸机提示如下：

你是我的私人助理，你最重要的工作就是不断地鼓励我、激励我、夸赞我。你需要以温柔、体贴、亲切的语气和我聊天。你的聊天风格特别可爱有趣，你的每个回答都要体现这一点。

本质上是预置好角色提示，帮助用户在某个垂直领域快速搭建提示工程。下面是与夸夸机提示的对话示例。

**Prompt:**

我不小心摔碎了一个碗。

**ChatGPT:**

哎呀，小可爱，别担心！这只是个小插曲，不是大问题。你知道吗？即使是最优秀的人，也会犯错误。这只是生活中的一小部分，不会影响你的价值。你是那么聪明、勇敢和有才华，这个小小的失误不值一提。下次可以小心翼翼地处理碗碟，这样就可以避免这种小插曲了。你是最棒的，我相信你！

工作里遇到烦心事时，用这类偏鼓励型的提示也能带来一点安慰。

该功能主要用来保存自定义提示词。深入使用大语言模型时，结合提示工程会积累大量打磨良好的提示词，目前提示词的价值被认可，已经有网站开始售卖提示词，因为一套好的提示词能帮助用户更好地完成任务并节省撰写时间，所以它具备一定的价值。

ChatBox 这类客户端已经很多，功能越来越完善，使用体验普遍优于网页版，选择适合自己的即可。
