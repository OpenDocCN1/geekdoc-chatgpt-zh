# 反向传播：消失与重生的算法

神经网络训练的基石之一是误差反向传播 BP。这个思路其实在 60 年代初期已被提出，当时并未引起关注。1970 年，Seppo Linnainmaa 在硕士论文里给出自动链式求导的方案，并把反向传播在计算机上实现出来。1974 年，Paul Werbos 的博士论文首次探讨把反向传播用于神经网络的可行性，之后他没有再发表相关工作。他本人认为该方向对解决感知机问题有价值，只是人工智能寒冬让整个研究圈失去了信心^((1))。真正让算法焕发活力的是 1986 年，Geoffrey Hinton 等人把反向传播系统地应用到神经网络上[^(\[1\])](#chapter7.xhtml#jz_9_1)。

如今借助深度学习框架的自动微分和参数自动更新，搭建复杂模型已很便捷。但反向传播与梯度下降仍是神经网络的核心机制，理解其原理必不可少。本章先回顾微分与梯度的数学基础，再推导常见激活函数和损失函数的梯度形式，随后逐步展开感知机与多层网络的梯度传递规律。

## 7.1 导数与梯度

导数 Derivative 的定义在中小学数学里已出现，它描述自变量 x 产生极小扰动 Δx 后，函数输出增量 Δy 与 Δx 的比值在 Δx 趋向 0 时的极限 a，若极限存在则 a 即为 x[0] 处的导数值：

[PRE0]

常见记法为 f'(x) 或[PRE1]。几何上，一元函数某点的导数就是该点切线的斜率，即函数值随 x 变化的速率。物理例子里，自由落体位移公式为[PRE2]，位移对时间的导数为[PRE3]，速度 v 被定义为位移变化率，于是 v = g t，位移对时间的导数即速度。

导数的适用范围很广，过去接触的多是一元函数，自变量扰动方向只有 x^+ 和 x^-。当输入维度大于一时，导数被推广为函数值沿任意 Δx 方向的变化快慢。导数本身是标量无方向，却刻画函数在特定扰动方向上的变化程度。所有方向里，沿坐标轴的方向最特殊，此时的导数称为偏导数 Partial Derivative。一元情形记作[PRE4]；多元情形记作[PRE5] 等。偏导数是导数的一种特例，同样不具方向。

神经网络本质是多元映射，例如 shape 为[784，256]的权值矩阵 W 包含 784×256 个连接权重 w，需要求出 784×256 个偏微分。数学里自变量常记 x，但在网络里 x 多指输入如图像、文本、语音，真正的自变量是参数集合 θ={w[1]，b[1]，w[2]，b[2]，…}。使用梯度下降优化时，需要得到网络全部偏微分。因此关注点是误差函数输出[PRE6]沿参数 θ[i] 方向的变化率，即[PRE7]对参数 θ[i] 的偏导数[PRE8]等。将所有偏导数写成向量形式：

[PRE9]

于是梯度下降可按向量形式更新：

θ'=θ-η·▽[θ][PRE10]

η 为学习率超参。梯度下降一般求 L 的最小值，若希望求最大值，如强化学习中最大化回报，则可沿梯度方向更新：

θ'=θ+η·▽[θ][PRE11]

这种方式称为梯度上升。下降与上升思想一致，一个沿梯度反向更新，一个沿梯度方向更新，均依赖偏导数。这里的向量[PRE12]称为函数的梯度 Gradient，由全部偏导数组成并具备方向性，梯度指向函数值上升最快的方向，其反向指向下降最快的方向。

梯度下降并不能保证获得全局最优，主要源于目标函数的非凸性。见图 7.1 非凸函数，谷底为局部极小区，不同优化轨迹可能收敛到不同数值解，且不一定是全局最优。

图 7.1 非凸函数示例

神经网络表达式通常非常复杂，参数量可达千万乃至数亿，几乎所有优化都依赖深度学习框架自动计算参数梯度，再以梯度下降迭代直至性能满足需求。框架核心实现就是反向传播与梯度下降，理解二者原理有助于把握框架作用。

在展开多层网络反向传播前，先介绍导数的常用性质、常见激活函数和损失函数的梯度推导，再推导多层网络的梯度传播规律。
