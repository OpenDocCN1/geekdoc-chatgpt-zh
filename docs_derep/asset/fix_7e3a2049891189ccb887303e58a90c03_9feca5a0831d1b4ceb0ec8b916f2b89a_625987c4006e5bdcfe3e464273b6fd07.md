# 第 12 章 OpenAI API 模型全景与使用要点

选型时通常会从四个视角来判断：模型主要擅长的任务类型，像 GPT-3 系列偏向文本任务而 Codex 系列偏向代码任务；所属的模型家族，比如 GPT-3 家族下包含 ada 阿达、babbage 巴贝奇、curie 居里和 davinci 达·芬奇四个子系列；向量类模型是否仅接受嵌入输入，例如文本搜索嵌入要区分 doc 与 query 两种输入形态；以及具体的版本标识，即模型编号本身。

在嵌入向量方面，推荐使用 text-embedding-ada-002。API 提供了三类嵌入系列：相似性嵌入、文本搜索嵌入、代码搜索嵌入。每类均有 ada、babbage、curie、davinci 规格，维度分别为 1 024、2 048、4 096、12 288。davinci 能力最强但速度慢费用高，ada 仅能应对基础问题却最快最便宜。

相似性嵌入擅长捕捉多段文本间的语义相似度；文本搜索嵌入用于判断长文档与短查询的相关性，输入分为 doc 嵌入待检索文档、query 嵌入搜索查询；代码搜索嵌入与文本搜索类似，输入分为 code 嵌入代码片段、text 嵌入自然语言查询。
