# 扣子要不要付费？看这篇就清楚

最近关于扣子是否需要掏钱的提问很多，结论是看使用场景。

先说体验档。通过抖音、微信、飞书等常用入口去调试或试用入门版智能体时，平台会先赠送一批免费调用次数。配额消耗完毕后就无法继续触发，相当于用完即止。

再说商业档。切换到付费版本后，成本主要由两部分构成：一是智能体被调用产生的次数费用，二是知识库所占用的存储费用。最终的账单结算都由付费账号统一处理。

在资源上限上，两者差异明显。付费版提供的团队协作空间容量更大，附带的免费知识库额度也更宽裕，更适合团队规模化使用。

另外调试接口时可以用返回码判断成败。成功的情况返回结果里的 code 会是 0，只要出现非零数值就代表请求异常，需要结合官方说明排查原因。
