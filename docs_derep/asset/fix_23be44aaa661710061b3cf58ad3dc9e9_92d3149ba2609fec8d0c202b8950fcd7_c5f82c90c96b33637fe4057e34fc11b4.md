#### 8.2 DeepSeek+飞书：百本名著速览
飞书具备即时通讯、协同文档、云盘、会议和日程等能力，跨平台协作流畅。借助其中的多维表格，就能让 DeepSeek 驱动一套全自动的数据分析流程。

##### 8.2.1 配置飞书
下面以名著分析为例，演示这套组合的落地办法。

首先进入飞书工作台，点击“多维表格”→“新建多维表格”，如图8-14所示。

在新建的表格里，右键点掉不需要的列，选择“删除字段/列”清除，如图8-15所示。

[PRE1]

▲图8-14 新建多维表格

[PRE2]

▲图8-15 删除不需要的列

保留一列，将表头改名为“提示词”，随后在该列里写入希望 DeepSeek 分析的书籍名称，如图8-16所示。

接着点列头右侧的“+”，新增第二列，在字段类型搜索框里输入“DeepSeek”，并挑选“DeepSeek R1”，如图8-17所示。

[PRE3]

▲图8-16 添加第一列数据

[PRE4]

▲图8-17 添加第二列数据

点“确定”完成基础设定。

##### 8.2.2 配置DeepSeek
选定 DeepSeek R1 后，拉到窗口下方找到“配置”区，在“选择指令内容”下拉框里指定第一列的列名，本例即“提示词”，这样模型就知道读取哪一列。同时在“自定义要求”文本框里写清楚任务细则，让模型按要求作答，如图8-18所示。

[PRE5]

图8-18 填写“自定义要求”

确认后在弹出的提示框点“生成”，这时若干 DeepSeek 实例会并行启动，如图8-19所示。

[PRE6]

图8-19 DeepSeek实例开始工作

结果会自动写入后面的两列“DeepSeek R1.思考过程”和“DeepSeek R1.输出结果”，如图8-20所示。

[PRE7]

图8-20 AI生成的结果

把鼠标移到“提示词”列任意单元格上，会弹出“查看”按钮，如图8-21所示。

[PRE8]

图8-21 “查看”按钮

点击“查看”可进入阅读模式的页面，详细呈现思考轨迹与最终结果，如图8-22所示。

[PRE9]

图8-22 详细查看DeepSeek的思考过程和输出结果

把多维表格与 DeepSeek 结合后，每列可视作独立的智能单元，每行构成一条完整的工作流，各单元协同运转，极大释放了数据处理和决策支持的效能。

#### 8.4 DeepSeek+PyCharm编程
PyCharm 由 JetBrains 发布，是一款面向 Python 开发的强大 IDE，提供代码补全、调试、版本控制、系统集成、单元测试、项目管理等功能，能大幅提升编码效率。无论新手还是资深工程师，都能从其简洁界面和丰富插件中获益。将 DeepSeek 引入 PyCharm 可在本地实现智能编程，无需担忧隐私与费用。

本节介绍接入流程，演示环境为 PyCharm 2023.1、Python 3.9.16。

打开 PyCharm，点击“File” → “Settings” → “Plugins”，搜索“Continue”，点“Install”安装，如图8-43所示。
