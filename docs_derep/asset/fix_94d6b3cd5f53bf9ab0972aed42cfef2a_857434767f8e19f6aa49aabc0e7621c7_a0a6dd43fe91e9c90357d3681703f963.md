与生成式助手首次沟通，如果想让它帮忙起课名，可以先这样给指令。

先把一批参考标题喂进去，让它先提炼规律：

1. 高效【核心词】的【数字】步骤，如“高效学习的7个步骤”。
2. 【数字】天掌握【核心词】窍门，如“14天掌握创业窍门”。
3. 最全指南：【数字】步骤掌握【核心词】，如“最全指南：6个步骤掌握营销技巧”。
4. 【数字】步骤轻松掌握【核心词】技能，如“3个步骤轻松掌握摄影技巧”。
5. 【数字】招帮你攻克【核心词】，如“一招帮你攻克面试的挑战”。
6. 【核心词】的【数字】必杀技，快速成为【核心词】成功者，如“创业的6个必杀技，快速成为创业成功者”。
7. 揭示【核心词】的【数字】个秘密，如“揭示健康饮食的7个秘密”。
8. 你绝对不知道的【核心词】【数字】个真相，如“你绝对不知道的科技行业10个真相”。
9. 【数字】天变成【核心词】专家，如“30天变成健康饮食专家”。
10. 【爆款】【产品解析】：成功案例，如“爆款手机解析：了解成功的×××产品策略”。

助手给出的归纳大致是：

1. 大量使用数字
几乎每条都带明确数量，如“7个步骤”“14天”“6个步骤”，数量让表述更具体可信，也更容易吸睛。
2. 核心词前置
标题里都有清晰的核心词，如“高效学习”“创业窍门”“营销技巧”，读者一眼知道内容范围。
3. 突出产出与收益
常点出可获得的结果或效果，如“掌握”“轻松掌握”“攻克”“成功者”，让读者明白学完能得到什么。
4. 营造紧迫与稀缺
有的用时间限定制造紧迫，如“14天掌握”“30天变专家”，有的用“你绝对不知道的”凸显独家性，形成稀缺感。
5. 激发好奇
通过解密、真相类表达，如“揭示健康饮食的7个秘密”“你绝对不知道的科技行业10个真相”，诱发点击欲望。
6. 结构分明
多数标题遵循固定结构，如“【数字】步骤轻松掌握【核心词】技能”，信息层级清晰，阅读负担低。

第二次对话可以这样问：

你现在是一位女性创业导师，正在筹备一套课程，主题是教上班族女性做有效副业创收。现在需要为这套课程拟定名称；名称里要体现目标人群、内容要点以及学完后的收获。

请参照刚才给你的标题的风格和特点，为“上班族女性副业创收”设计5个吸睛的课程名称。

助手回复如下。

好的。依据你给的风格和特点，我为“上班族女性副业创收”设计了5个名称。

这些名称均包含目标人群在职女性、内容副业创收方法以及学习后的效果。

1. 五大招助力在职女性：轻松实现副业月入过万
亮点：用具体数字提升可信度，承诺明确结果月入过万，并强调轻松实现。
2. 30天掌握副业创收秘诀：在职女性的4步成功指南
亮点：设定明确时间节点30天，采用结构化表达4步，指向成功指南。
3. 最全副业创收攻略：在职女性必学的3个关键技巧
亮点：主打全攻略概念，用数字3个增强说服力，突出关键词副业创收、关键技巧。
4. 揭秘在职女性副业成功的3个秘密：你可能不知道的赚钱方法
亮点：以揭秘秘密为钩子，制造好奇你可能不知道，明确指向赚钱方法。
5. 21天变身副业达人：在职女性的高效变现策略
亮点：限定时间21天，强调结果变身副业达人，点明高效变现策略。

从这两个案例能看出，在没有样例参考时，助手输出常显得平淡、吸引力不足，或者不符合微信生态爆款标题的调性。

一旦提供样例，就不需要再逐条细化要求，助手也能自动对标生成。在有样例支撑的情况下，助手产出的内容结构更完整、风格更统一，大体符合预期。

根本原因在于助手的模仿学习能力强。手头有喜欢的范例，不妨拿来喂给助手，让它消化吸收后，基于你的应用场景产出同类内容。

总结触发助手潜能的六式如下。

激活助手潜能的六式 表达方式
身份赋能法 假设“你是谁 + 你会什么 + 任务内容”
角色匹配法 告知“我是谁 + 我的背景 + 任务内容”
情境定制法 告知“角色 + 任务场景 + 任务内容”
问题重塑法 提出需求/问题 + 建议更好的版本
问题组装法 提出需求 + 你可以提出一系列关于×××等的附加问题来问我，然后根据我的回答帮我完成某项任务
案例借鉴法 学习案例+总结案例的优点+模仿案例中的××完成任务

用好这六式，就能让助手在课程开发等各场景提供更精准实用的支持，助力产出高品质课程。无论是写大纲、搭内容、创案例、设计教学形式，都能与助手高效协同，事半功倍。

工具的价值不只在功能，更在你能否把它激活。

试着用六式与助手对话，感受它们在课程开发中的实战效果。

# 第二章 精准定焦，打造吸睛的课程定位

本章聚焦如何借助助手确定让人上头的定位，重点讲定位目标、挖掘卖点、打磨标题的方法。

## 2.1 先定终点再倒推课程定位

某讲师的“久坐人群脊柱功能重建”系列在千聊上已有4万多学员。

起初他选的是“增肌减脂”赛道，销量一直上不去。经过多次调研，他发现自己的医学背景、运动康复经验、对办公室人群的深度洞察，这三者的交集才是不可复制的壁垒。

于是他把定位收敛为“久坐人群的脊柱功能重建”，销售额很快迎来拐点。

现在做课门槛越来越低，但能爆的课都遵循同一底层逻辑——先锁定买家再搭建课程，而不是先做内容再找人买。认知错位是大多数知识产品失败的根因。

残酷的真相是：知识付费最大的误区是觉得专业就能卖。

专业只是入场资格，定焦才是生死线。

记住这个公式：

有竞争力的课程定位=讲师画像（擅长点+兴趣点）+需求定位（刚性需求+聚焦领域）+优势锚点（锚定用户+有护城河）

爆款课的共性是，精准定位筑起三位一体的护城河：既体现讲师独特价值，又解决用户真实痛点，还能支撑持续变现的产品体系。

### 2.1.1 课程定位的两大常见坑

做定位前，先避开两个坑，避免方向跑偏导致效果与商业双输。

坑1：伪兴趣区，即擅长却不热爱。
伪兴趣区是你有能力但缺乏热情的领域，看似能做课，实则难以持久。
案例：李律师擅长劳动法，她的粉丝很爱看她怒怼无良老板的短视频，专业又带情绪共鸣；但她却执着做合同审查课，选了擅长却无热情的方向。
结果：课里干货不少，偏理论，因她投入度低而频繁断更，用户大量流失。
解法与成效：把合同审查重包装成“3招让黑心老板跪着改合同”系列视频课，用怒怼不良企业的剧情带出审查要点，专业中注入情绪价值。找回热情后报名上涨，后续更有32%的学员转化为合同审阅咨询客户，实现课程与高客单服务的联动。

坑2：伪擅长区，即热爱却无壁垒。
伪擅长区是你热情高但缺乏差异化专业壁垒的领域，靠个人经历很难说服付费。
案例：瑜伽教练林老师做产后修复课，也有二胎亲身经历。被问为什么选你时，她答我生过二胎，恢复得很好。用户心里会想我闺蜜生三胎也恢复不错，为什么要付费。
问题与结果：课程定价299元，上线3个月仅38单，核心是缺乏专业壁垒的信任感。
解法与成效：帮她梳理知识资产，从个人经历转向专业价值，重塑品牌故事与壁垒，并搭建产品矩阵。
引流资料：制作产后修复价值自测表并附专业解读，用免费工具吸客。
核心课程：推出产后修复避坑实战营：7天能避万元坑录播课含答疑，定价299元，聚焦用户痛点避坑。
高客单服务：上线800元三甲医院方案诊断、2980元半年修复陪跑。
调整后首月课程售出86份，部分用户客单价从299元提升至4079元。现已与3家母婴平台合作提供专属咨询，版图持续扩张。

在帮林老师把个人经历转化为可验证的专业壁垒时，我只做了三件事：
深挖她的知识资产，找到差异化亮点；
重构教学目标，从知识搬运转向解决实际问题；
搭建产品矩阵与商业闭环，实现从流量到高价值用户的转化。

### 2.1.2 讲师画像：挖掘你的知识资产

很多人以为做课是无中生有，于是拼命找资料搭框架。

其实更接近打捞：把早已藏在生活里的碎片捞出来——写过的文章、被反复追问的回答、讲起来停不下来的话题。它们零散却已生长，只需拼成完整拼图。

这拼图就是你的知识资产。可从三角度挖掘。

角度1：输出过的内容，是已验证的知识路径。
文章、视频、分享、朋友圈长文，都是你自然表达的核心知识。
筛选方法：盘点过去一年高频输出主题，
写过3篇以上文章的主题，标★；
直播或分享讲过2次以上的主题，标▲。
重复输出的主题，就是你最熟的赛道，不靠灵感，靠积累。

角度2：被反复提问的问题，是市场验证的需求。
反复被问同一个问题，不是打扰，是信任的信号，说明你在这件事上是默认咨询对象。
梳理三步：
翻3个月聊天记录，收集被问5次以上的问题；
分类，如技能类、心理类、决策类；
提炼背后核心痛点。
高频问题就是真实需求，直接决定课程好不好用。
例如反复被问怎么写周报不被批、怎么拒绝老板额外加活，课程就该叫职场人的低耗生存术，而不是宽泛的沟通技巧。

角度3：最想表达的内容，是课程的灵魂。
有些内容你还没公开，却最想讲：看到同主题内容就想我想讲，而且能讲得更透。
来源可能是独特经历、长期思考、深刻感悟，或你发现的市场空白。
自问三问：
如果只能做一门课，我会选什么主题？
哪个话题一开口就停不下来，越讲越兴奋？
看到别人讲哪个主题，我总想能讲得更透彻更实用？
答案指向的，就是你的热情核心，能让课程成为灵魂表达，而非单纯产品。

明确讲师画像是第一步，三种常用方法：
兴趣清单打分法；
成就事件萃取法；
榜样对标法。

### 2.1.3 需求定位：定义用户的学习产出

需求定位就是明确：做什么课、给谁做、解决什么问题、学完能拿什么结果。

很多创作者忽略了这一步。
有人只挑自己感兴趣或擅长的点，没考虑市场与竞争。
有人没搞清目标用户是谁、痛点是什么。
有人没突出差异，导致同质化严重。

做定位就是做取舍。
知识付费的常见误区是大市场=大机会。真相是，刚性需求=可感知的痛点+可量化的改变。
以写作培训为例。
泛定位：新媒体写作课，市场大但同质化。
精准定位：社群电商从业者的变现内容指南，用户小但直击痛点，一击即中。

做需求定位，要判断：需求是否刚性、是否聚焦特定领域、对特定人群是否学了即用。

开发课程时，请先回答5个问题：
你要做哪种类型的课程？
面向什么学员？
能解决哪些具体问题？
学员为什么要跟你学？
学完能获得什么好处？

课程的终点不是你讲完，而是学员做出成果。教学的核心不是我讲了，而是他做到了。

因此必须先厘清：学完后用户能独立完成什么具体任务？成果需满足三条件。
可感知的：不是模糊的提升效率，而是每天少加班1小时。
可验证的：不是抽象的学会思维，而是独立写出一份符合职场标准的周报。
可展示的：能通过截图、分享甚至主动炫耀呈现，如学员把周报发到社交平台，既是证明也是传播。

用一句话描述需求定位：这门课是给【特定人群】的，帮他们【解决某类具体问题】，最终让他们能【做出可落地的成果】。

你要做好卖的课程，而不是把知识全倒出来。

战略比思路重要，思路比努力重要，努力比苦耕重要。

做课不是搬运知识，是放大价值。从讲师画像与需求定位双维度复盘，或许下一个爆款的基因就藏在未被发现的组合里。

### 2.2.1 第一步：锚定用户，从用户视角定课程

小李计划做一门成人烘焙课。初期她发现不同人群需求差异很大，于是做需求分层。

她总结出4类潜在学员。
1. 烘焙新手。对烘焙零基础，想学基础操作。痛点是不懂工具材料、步骤和技巧。
2. 兴趣爱好者。对烘焙有热情，想在家做点心。痛点是选食谱、控时间温度、提升口感。
3. 聚会组织者。需要为家庭朋友聚会自制糕点。痛点是选适合各年龄口味的食谱、批量制作。
4. 想做副业的人。希望把烘焙变现。痛点是控成本、保品控口味、做营销。

据此她把课程拆成4个模块，分别对应不同人群。
1. 基础入门模块：面向新手，重工具材料与基础技法。
2. 兴趣提升模块：面向爱好者，重食谱优化与口感改善。
3. 聚会实用模块：面向组织者，重快手食谱与批量技巧。
4. 副业专项模块：面向副业人群，重成本、品控与营销。

看出来了吗？同一门课，不同用户的痛点和要的结果不一样。用户买的不是知识，而是改变后的自己。

要精准定位课程结果，可自问：
他们是谁？
需求和痛点是什么？
目前面临什么挑战？
出于什么目的来学习？
