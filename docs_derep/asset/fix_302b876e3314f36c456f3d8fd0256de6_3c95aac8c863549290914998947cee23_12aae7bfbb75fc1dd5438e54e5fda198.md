数据仓库与数据挖掘分析平台

把多学科的数据挖掘方法与多维数据仓库架构结合起来，是为管理层打造的高阶分析型数据库平台。核心逻辑是依托挖掘模型从海量仓库中抽取出具备决策价值的信息，从而为更高层次的知识表达与业务洞察提供支撑。

该类平台已在银行业务分析预测、保险风险评估、电信服务分析预测、证券投资研究等多个领域落地，成为数据库技术应用的重要方向。

## 6.6 主流数据库管理系统盘点

市场上常见的商用数据库产品主要集中在 IBM、Oracle、Microsoft、MySQL、Sybase 等厂商，下面对几款常用系统做简要介绍。

### 6.6.1 DB2

DB2 由 IBM 研发，是一款兼顾多媒体与 Web 的关系型数据库，既能满足大型企业的需求，也能灵活适配中小型电商方案。企业级应用广泛，全球使用者超过 6000 万，分布在约 40 万家机构。

1968 年 IBM 面世的 IMS，即信息管理系统，是层次型数据库的典型代表，也是首个大型商用数据库。1970 年 IBM 研究员首次提出关系模型，开创了关系方法与理论研究，为行业奠基。至今 IBM 仍是数据库产品的主导供应商，在大型机市场占据主导，100% 财富世界百强企业与 80% 财富世界五百强企业均在使用 DB2。生态方面，众多应用软件厂商围绕 IBM 展开。2001 年 IBM 收购排名第四的 Informix，将其先进特性整合进 DB2，进一步提升性能与功能。

DB2 采用多进程多线程架构，可跨多种操作系统运行并做平台化优化。支持从 PC 到 UNIX、从小型机到大型机、从 IBM 到非 IBM 环境，可在主机上以主从方式独立运行，也可部署于客户机/服务器环境。服务端可运行于 OS/400、AIX、OS/2、HP-UNIX、SUN Solaris 等，客户端可运行于 OS/2、Windows、DOS、AIX、HP-UX、SUN Solaris 等。

主要特色如下。

（1）面向对象能力。支持复杂数据结构及非结构化文本对象，对非结构化文本可做布尔、近似、任意匹配检索，支持用户自定义类型与函数。
（2）多媒体支持。支持大二进制对象 BLOB，可在库中存放二进制大对象与文本大对象，二进制大对象用于多媒体存储。
（3）备份恢复能力突出。
（4）存储过程与触发器。建表时可定义复杂的完整性规则。
（5）兼容标准 SQL，并提供 ODBC、JDBC 连接方式。
（6）异构分布式访问。内置与异种数据库互联的网关，便于互访。
（7）数据复制功能。
（8）并行性良好。采用并行多节点环境，数据库分区自带数据、索引、配置与事务日志。

### 6.6.2 SQL-Server

SQL Server 是微软推出的大型关系型数据库，功能完备、效率较高，可作为中大型企业的数据平台。该产品在伸缩性与可靠性上投入较多，近年来在众多企业高端服务器上广泛部署，同时继承了微软产品界面友好、易学易用的特点，在操作与交互上具备优势。可与 Windows 操作系统深度集成，充分利用系统特性，提升开发速度与事务处理速度。还可借助浏览器查询，支持扩展标记语言 XML，并提供全面支持 Web 的数据库解决方案。对于在 Windows 平台开发的企业信息系统，无论是 C/S 还是 B/S 架构，SQL Server 都是较好的选择。局限在于仅能在 Windows 环境下运行。

主要特点：

（1）高可用性。借助日志传送、在线备份与故障群集，最大化业务应用可用性。
（2）伸缩性。可扩展至 32 个 CPU、64 GB 系统内存的硬件方案。
（3）安全性。基于角色的安全特性与网络加密，确保在各种网络环境下安全。
（4）分布式分区视图。可在多台服务器间分配工作负载，获得额外伸缩性。
（5）索引化视图。通过存储查询结果缩短响应时间，提升现有硬件性能。
（6）虚拟接口系统局域网。借助 VI SAN 的内部支持改善整体性能。
（7）复制功能。实现与异类系统间的合并、事务处理与快照复制。
（8）纯文本检索。可对结构化与非结构化数据进行管理，并在 Microsoft Office 文档间执行搜索。
（9）丰富的 XML 支持。简化后端系统与跨防火墙数据传输的集成。
（10）与 Microsoft BizTalk Server 和 Microsoft Commerce Server 等 .NET 企业服务器集成，提供电子商务解决方案。
（11）支持 Web 的分析功能。可分析 Web 访问的远程 OLAP 多维数据集。
（12）Web 数据访问。无需额外编程即可快捷实现与 SQL Server 和 OLAP 多维数据集的网络连接。
（13）应用托管。多实例支持使硬件投资得到充分利用，多个应用可在单台服务器稳定运行。
（14）点击流分析。深入理解在线客户行为，助力更优业务决策。

### 6.6.3 Sybase

Sybase 成立于 1984 年 11 月，主要产品包括旗舰数据库 Adaptive Server Enterprise、Adaptive Server Replication、Adaptive Server Connect 及异构数据库互联选件。Sybase ASE 是核心数据库产品，可运行于 UNIX 与 Windows。移动数据库产品 Adaptive Server Anywhere、Sybase Warehouse Studio 在客户分析、市场细分与财务规划方面提供专门分析方案。Warehouse Studio 核心为 Adaptive Server IQ，其专利化底层存储技术可快速查询海量数据，并配有完整工具链，包括数据仓库/数据集市设计、数据源集成转换、信息可视化分析及元数据管理。

互联网应用产品包括中间层应用服务器及强大的 RAD 开发工具 PowerBuilder 和业界领先的 4GL 工具。

特点：

（1）完整的客户机/服务器体系结构，满足 OLTP 需求，可为数百用户提供高性能服务；
（2）采用单进程多线程技术进行查询，降低系统开销，提升内存利用率；
（3）虚拟服务器体系结构与对称多处理器 SMP 技术结合，充分发挥多 CPU 平台性能；
（4）DBA 可在线调整、监控系统性能；
（5）提供日志与数据库镜像，提升容错能力；
（6）支持计算机集群环境下的快速故障切换；
（7）通过存储过程与触发器由服务器约束数据完整性；
（8）支持多种安全机制，可对表、视图、存储过程和命令授权；
（9）分布式事务处理采用 2PC 技术，支持 Image 与 Text 数据类型，为工程数据库与多媒体应用提供基础。

### 6.6.4 FoxPro

Visual FoxPro 由微软开发的微机平台关系型数据库系统，支持网络功能，适用于客户机/服务器及 Internet 环境下管理信息系统开发。其设计工具、面向数据的语言机制、快速数据引擎和组件创建能力使其成为功能强大的开发工具，可用于开发基于 Windows 的分布式内部网应用 DNA。

Visual FoxPro 源于 dBASE 与 FoxBase。80 年代初 dBASE 成为 PC 上最流行数据库管理系统，多数学信息系统以其为平台。FoxBase 几乎完全兼容 dBASE 并具备强大数据处理能力。Visual FoxPro 是 xBASE 系列的飞跃，为 PC 数据库开发带来革命性变化。不仅在图形用户界面设计上引入新技术，还提供所见即所得的报表与屏幕格式设计工具，并引入 Rushmore 技术，使系统性能实现本质提升。仅能在 Windows 环境下运行。

主要功能：创建表与数据库并进行数据管理；使用查询与视图按筛选条件检索数据；使用表单设计强大用户界面；使用报表与标签将统计结果打印为文档。

开发应用需创建表、数据库、查询、视图、报表、标签、表单与程序等，提供了大量可视化设计工具与向导，配合项目管理器便于文件组织、连接与调试。

主要特点：

（1）增强的项目与数据库管理，提供集中管理环境，便于控制与更改对象外观；
（2）简便快速灵活的开发，配备应用程序向导，界面与调试环境可操作性强；
（3）无需编程即可创建界面，组件实例提供常用应用组件；
（4）支持面向对象程序设计，在过程式基础上提供继承、封装、多态等 OO 能力；
（5）使用 Rushmore 优化技术，可将查询响应时间从数小时降至数秒；
（6）支持项目组协同开发，多人可同时访问数据库组件，并可使用源代码管理跟踪更改；
（7）可开发客户机/服务器解决方案并增强性能；
（8）支持多语言字符集，包括英语、冰岛语、日语、朝鲜语、汉语等，支持国际化应用开发。

### 6.6.5 Access

Access 隶属于微软 Office 套件。自 1992 年起售以来已售出超过 6000 万份，成为全球最流行的桌面数据库管理系统。与 Visual FoxPro 相比，Access 更简单易学，普通用户亦可掌握，同时足以应对一般小型数据管理需求。无论是个人独立桌面数据库，还是部门或中小公司共享数据库，都可使用 Access 作为平台提升工作效率，如处理客户订单、管理个人通讯录、记录科研数据等。仅能在 Windows 下运行。

最大特点是界面友好、简单易用，与其他 Office 产品一致，易于接受，常作为低端数据库应用平台，也多作为数据库学习的入门系统。

主要功能：

（1）以向导或自定义方式建立数据库，完成表创建与编辑；
（2）定义表结构及表间关系；
（3）图形化查询与标准查询；
（4）建立与编辑数据窗体；
（5）报表创建、设计与输出；
（6）数据分析与管理功能；
（7）支持宏扩展 Macro。

### 6.6.6 Oracle

Oracle 数据库被视为业界较为成功的商业化关系型数据库管理系统。Oracle 公司是世界第二大软件厂商，也是数据库软件领域第一大厂商，不含大型机市场。其产品以运行稳定、功能齐全、性能出众著称，定位高端。适合数据量大、事务繁忙、安全要求高的企业，但费用较高。互联网兴起带动网络经济，Oracle 及时将产品与网络计算结合，成为互联网应用领域领先厂商。

可运行于 UNIX、Windows 等主流操作系统，完全支持工业标准并获得最高级 ISO 安全认证。采用开放策略，便于客户选择方案并支持开发商。

特点：

（1）无范式强制，可按实际需求构造数据库；
（2）采用标准 SQL 结构化查询语言；
（3）开发工具丰富，覆盖开发全周期；
（4）数据类型支持数字、字符，最大达 2 GB 二进制数据，为面向对象存储提供支持；
（5）具备第 4 代语言开发工具，如 SQL*FORMS、SQL*REPORTS、SQL*MENU 等；
（6）提供字符界面与图形界面，Oracle 7 后版本提供面向对象开发环境 CDE2；
（7）通过 DBA 控制用户权限，提供数据保护并监控运行状态，调整数据缓冲区；
（8）分布优化查询功能；
（9）数据透明、网络透明，支持异种网络与异构数据库，并行处理采用动态数据分片技术；
（10）支持客户机/服务器及混合体系结构；
（11）实现两阶段提交与多线程查询；
（12）支持多种平台 Linux、HP-UX、SUNOS、OSF/1、VMS、Windows、OS/2；
（13）保护措施无读锁，采用快照 SNAP 消除分布式读写冲突，自动检测并解决死锁；
（14）数据安全级别为 C2 级；
（15）内部模型支持多字节码制，支持多种语言文字编码；
（16）具有面向制造系统的管理信息系统与财务应用系统；
（17）服务器用户支持超过 10000 个。

## 本章小结

数据库在日常生活与工作中发挥重要作用，掌握数据库基础知识并会使用相关软件，已成为现代社会对大学生的基本要求。

本章旨在帮助读者理解数据库、数据库系统、数据库管理系统的概念及相互关系；掌握数据库的重要作用、构成系统的四个部分及 DBMS 主要功能；了解常见数据模型并重点掌握关系数据库概念、基本运算与关系完整性约束；认识实时数据库；了解数据库系统应用的主要领域；熟悉常用数据库管理系统及其特点。
