## 第5章 DeepSeek API 打造专属智能助手

本章聚焦如何接入 DeepSeek API。先讲大模型 API 的概念和优势，明白为什么调用 API 能提升智能助手性能；再梳理调用时必须掌握的关键要素；随后手把手教申请密钥；最后通过实例演示真实调用，把理论变成能力。学完后，你能灵活运用 DeepSeek API，并在后续办公自动化中发挥价值。

### 5.1 大模型 API 到底是什么

大模型 API 是一种让开发者在自己的应用或服务中集成大型预训练模型能力的接口。通过它，无需自建模型、也不用准备算力，就能调用文本生成、图像识别、自然语言处理等能力。

打个比方，大模型像发电站，各种应用像电器，都需要电。API 就像插座，把电接入每个电器。正是通过 API，各类互联网产品接入 DeepSeek，为用户提供服务。

#### 5.1.1 API 的核心优势

基于大模型能力开发应用，API 的灵活性很突出：

##### 1. 自动化与批量处理
调用 API 可实现海量数据批量处理，例如一次性分析上千篇文献，效率大幅提升。详见第4.12节及第6章。

##### 2. 定制化与扩展性
可串联其他工具链实现功能集成。比如第4.11节中，ima 与 DeepSeek 结合构建 AI 知识库。
也能支持多模型协同，像第4.4节～4.8节介绍的图片、海报、视频、音乐等 AI 大模型，通过 API 集成到同一工作流里，真正做到一键生成。

#### 5.1.2 API 调用关键要素

##### 1. Token 机制
Token 是大模型处理文本的最小单元，约等于词或子词，直接影响成本和速度。简单说，大模型按 Token 计字数，不是按字数。API 计费也按 Token 来算。

##### 2. API 密钥
相当于数字钥匙，用于身份验证。想成功调用，必须填写正确的密钥。

##### 3. 调用限制
部分 API 对单次请求 Token 数有限制，如 128000 个，超限会报错。速率和并发也可能受限。

## 第6章 DeepSeek + Office 智能办公实战

职场中 Office 是高频工具，但重复手工操作很消耗时间。VBA 作为 Office 的效率引擎，能实现自动化，却因学习门槛被很多人搁置。如今借助 DeepSeek，你不用写代码，只需用自然语言描述需求，就能快速生成 VBA 代码，一键实现自动化。未来自动化办公将成主流，咱们能把精力放在更有创造性的工作上。

### 6.1 VBA 是什么

VBA 即 Visual Basic for Applications，是运行于 Microsoft Office 套件如 Excel、Word、Access 等中的编程语言和开发环境，用来实现自动化、扩展功能和自定义解决方案。WPS 安装插件后也能用，脚本常被称为宏。

#### 1. VBA 语言特点
VBA 与 Office 高度集成：

- 易学易用： 无编程基础也能掌握基础语法，快速完成单元格读取、格式设置等任务。
- 强大自动化： 可批量处理重复任务，如 Excel 大量数据格式化、计算、筛选，编写宏自动排序、筛选，省时省力。
- 高度集成： 能访问工作表、单元格、图表、文档、段落、表格等对象，深度定制，如 Word 自动生成带公司logo、页眉页脚的模板。

#### 2. VBA 应用场景

- 数据处理与分析自动化：Excel 中连接外部数据库、清洗转换数据、定期更新报表图表。
- 文档自动化处理：Word 中批量生成合同，按客户信息自动填充；批量加页码、改格式。
- 自定义用户界面：添加自定义菜单、工具栏、对话框，让参数输入和操作更友好。

补充说明：VBA 在 Windows 上运行良好，macOS 支持大部分场景，但如访问网络等操作可能困难，必要时可用 Python 替代。Python 介绍见第7章。
