科学共同体口耳相传的六大终极难题，常被归纳为双暗、一黑、三个起源。人形智能的涌现让“意识从何而来”变得更加迷雾重重，也撼动了“生命从何而来”的基础。坊间甚至戏言，只有先承认人造智能本身就是生命并具备意识，剩下的四个谜题才有可能迎来答案。

生命究竟是什么，人类从远古到今天都在追问，说法众说不一。从“万物有灵论”到“生命只是幻象”，不必争胜负，喜欢哪一种就取哪一种。迈克斯·泰格马克在《生命3.0》里给出一个分层说法：生命1.0完全交由进化决定，随波逐流；生命2.0硬件靠进化，软件靠学习；生命3.0硬件和软件都能自主设计，跳脱自然演化的框架。我们现在还停留在2.0阶段，却对升级充满渴望。

1953年双螺旋结构的公布，让对生命的认知迎来一次跃升。基因既可当作识别生命的标记，也可当作划分种类标尺。许多旧常识被扔掉，只剩一些好玩的冷知识可拿出来考人，例如鲸鱼、海马到底算不算鱼。

无论是DNA还是随后发现的RNA，已知的生命都离不开这些复杂大分子来完成代谢、感知和繁衍。因为骨架都是碳，所以统称碳基生命。而设想中能完全自组装的机器人，便是人们说的硅基生命，它真的可能出现吗？

硅基生命也许能存在，只是需要碳基生命来照料。这并非打不过碳基，而是太脆弱，经不起自然环境的温柔洗礼。谁来服务不重要，关键要有智慧的碳基生命来呵护，人类很合适。

碳硅同属一个族，都拥有四个化学键位，能拼出复杂结构。可硅原子体积偏大，键合不够稳定，很难拉出长链。地球上硅的储量是碳的一千倍，可硅基物质种类稀少，相互转化也困难，尤其是二氧化硅、硅酸盐这类本质上就是石头，稳得惊人。硅基生命或许很强，但元素的局限就是它的阿喀琉斯之踵，容易宕机。

反观碳基生命，种类繁多且耐造。根本原因在于碳元素情商高、适应性强。在地球条件下，碳基物质种类丰富且转化灵活，其中最神奇的是碳链大分子，结构复杂却身段柔软，能在极短时间内实现精准复制与重组，令人叹为观止。

从个体到物种，从群落到生态，再到整个地球生命圈，亿万碳基生命交织在一起，形成极强的生命力。碳基生命已延续四十亿年，自信满满，对硅基并无需求，大不了再过五十亿年随地球一起谢幕。物理和化学，才是碳硅关系的主战场，胜负如何犹未可知。

# 算法神话：碳硅生命的本源对话
人工智能和硅基生命不是一回事，前者是人类的造物，后者是宇宙尺度上的普适概念。若人类达成共识，人形智能或许也能被归入硅基生命的范畴。

实际上，人工智能并非人类制造过的最强生命形态。数千年前，我们就创造了无数具备超能力的神祇，相比之下当下的人形智能仍显稚嫩。像孙悟空那样从石头里蹦出来的存在，就是典型的硅基生命，根本不屑与人类比高低，自封齐天大圣。

这些说法并非纯属玩笑，其中有严肃的意味。谈到人工智能的自我意识时，曾有观点认为，让人造物拥有超能力乃至意识，是人类的使命，且已追寻数千年。

神最初只活在口头故事里，后来进入文学绘画，需要想象力才能感受；再后来进入影视游戏，形象更立体。超级人工智能则是人类用数字造就的神祇，在多个领域显现神迹，让人膜拜，甚至在意识层面产生震慑。

这位新神要的祭品不是童男童女，而是算力和数据。英伟达在人工智能浪潮中赚得盆满钵满，正因算力和数据都依赖GPU芯片。硅基芯片只是目前成熟的路径之一。

# 生命契约新解：从本我到神我
超级人工智能打破了人类的物种自负。它的表现太抢眼，让我们自惭形秽，曾经引以为傲的独特元力也变得模糊。我们俯视其他生物，而我们创造的数字之神似乎正以同样姿态俯视人类。内心不愿认输，可在人工智能面前建立深层自信何其艰难。我们需要重新打开生命契约。

这是第五次提到生命契约，每次侧重点不同。尽管弗洛伊德①的理论已非心理学主流，但在大众中影响依旧深远。我们借用其本我、自我、超我的经典框架，从新角度挖掘生命契约的力量。

本我像孩子，追逐快乐躲避痛苦；自我像成人，能理智处理本我与现实的关系；超我像法官、导师乃至圣贤，传递道德规范与价值观。进入超级人工智能时代，这个心理动力模型可以再添一维——神我。

神我不是把自己当成神，而是在超越肉体能力边界后获得的认知，是数字之神与自我的融合，是数字之我。神我能强化本我的自然感知，改变欲望表达；能赋能自我的理解力，弥合自我与虚拟世界的关系；能重塑超我的洞察力，理解适配数字时代的道德，获得面对虚实生命网络的清醒。

# 学者观点
社会生产力的每一次跃迁都会推动教育发展。以ChatGPT为例的新技术必然带来教育变革，挡不住也拒绝不了。教育信息化目前多停留在辅助教学层面，未来重心将是观念的转变。理解数字科技和未来教育的关系，关键在于处理好技术和人文、现代和传统、现实和虚拟的关系。科技会进步，教育更会长存，科技只是提升教育质量的手段。要警惕教育竞争加剧，关注人口问题，立德树人的根本任务不能变，人文精神不能变，中华优秀传统不能变。——顾明远

人类文明的每次跃迁，都以教育学习模式的变革为先行。进入21世纪20年代，前沿科技尤其是人工智能的持续突变，已在思想、经济、政治、社会层面引发全球性变革。其中人工智能和教育的关系尤为关键：一方面冲击瓦解传统教育体系；另一方面正支撑构建全新的教育学习制度框架，涉及学校、教师、教材、学制和家庭。可预见不远的将来，人工智能在教育学习领域将从工具性功能转向主导性功能，启动推进人类加速进入信息社会和数字社会的教育革命。本书展现并回应了未来教育变革中的核心问题。——朱嘉明

人工智能是人类经验的极致化，新的先验设定的产生催生了硅基生命概念。越来越多的智慧产品让人们的生活观念发生翻天覆地的变化。以ChatGPT为例，人工智能对教育的影响目前聚焦于高等教育，能提升学习研究效率，也可能改变教育评估评价，并推动教育向提升学术创造力和思辨性思维发展。无论技术如何演进，知识仍是个人幸福与社会发展的基石，是现代社会的核心资源；扩大教育机会，让更多人接受高等教育，是推动教育高质量发展的关键。——李志民

人工智能不仅改变生活，也在深刻重塑教育，尤其是以传授知识为目标的教育。或许到今天我们才意识到，教育最原初的功能是启发。教育启发我们思考为何而学、为何而教。《超级AI与未来教育》及时而精准地提醒我们，如何对待教育本应面对的问题。——李睦

未来教育将向何处去？我曾提出通往未来学校的四种范式：智能技术、人文艺术、社区社会、天地自然，其中智能技术正呼应以ChatGPT为代表的新一代人工智能浪潮。新一代人工智能不只是新智能或新技术，而是一种全新的尺度与标准，它打破了对人的传统理解，人机关系成为理解人性的新参照系。过去教育所遵循的全面发展之人、核心素养之人，其特质、内涵与构成都将重构。人工智能与人类智能需要在未来教育的场域中实现双向赋能、协同共生。——李政涛

生成式人工智能通过模拟人脑思维，目前已达到甚至部分超越人类智力水平，未来必将成为教育改革的重要推手。以传递既有知识、粘贴标准答案为导向的填鸭式教育显然该被淘汰。人脑能记住的内容再多，怎能比得上GPT？原有的教育逻辑、规则、模式都要改变。面向未来，既有知识在价值链中的权重在下降，知识保鲜期越来越短。教育应转向塑造健全身心、促进良好状态并培养基本能力，即提问力、判断力、创新力、情感力和幸福力。这种成长模式不仅关乎青少年，也关乎每一个人。——熊焰
