### 10.1.3 LLMOps 概览
大语言模型的快速发展让技术与应用模式与传统机器学习、深度学习产生明显差异，主要体现在以下几个方面。

- 训练数据规模：大模型的训练集通常达到 TB 到 PB 级别，数据处理复杂度远高于传统机器学习。
- 训练过程：现有大模型的规模多在十亿、百亿甚至千亿参数量级，分布式训练往往需要成千上万张显卡，涉及调度、容错、节点通信等与传统方法截然不同的技术挑战。
- 模型评估：经典深度学习多依赖人工标注的测试集和客观指标来评判效果，而大语言模型输出海量多样，缺乏标准答案，难以完全通过人工判定质量，需要新的评测基线和方法。
- 模型部署：参数动辄数十亿到数千亿，部署时必须精细规划计算资源的分配与优化，通常依赖高性能 GPU 或 TPU 集群，运行中要兼顾稳定性、安全性和效率，并持续监控优化。
- 模型推理：通过提示词引导生成更符合需求的输出，这种方式在自然语言处理和多模态场景里大幅提升了灵活性和精准度，与传统机器学习推理形成鲜明对比。

正如英伟达官方博客所说，世界正迅速进入由基础模型和大语言模型驱动的新一代 AI 时代，ChatGPT 的出现更是加速了这一进程。

伴随 MLOps 的演进，LLMOps 应运而生，覆盖人工智能的全生命周期。它聚焦于在生产环境中开发和管理大语言模型应用所面临的挑战，包括基础模型的预训练、监督微调实现对齐、人类反馈强化学习、针对特定场景的定制，以及与其它基础模型和 API 的集成。同时，LLMOps 还涉及目标与 KPI 的制定、团队组织、进展度量和运营流程的持续改进。

## 10.2 大模型量化部署实操
本节先简要介绍阿里巴巴 Qwen 团队推出的 Qwen 大模型，它支持自然语言理解、文本生成、视觉理解、音频理解、工具使用、角色扮演、充当 AI 代理等多种能力。随后会介绍推理部署中常用的量化技术，帮助模型在实际应用里兼顾效率与性能。

### 10.2.1 Qwen2-0.5B 模型速览
相比动辄数十亿参数的大模型，0.5B 到 1B 参数量级的模型在资源受限或微调前小批量验证时非常实用。

Qwen2 是基于 Transformer 架构的新一代 Qwen 系列大语言模型，涵盖多种基础模型和指令微调模型，参数规模从 0.5 亿到 720 亿不等，其中还包含 MoE 结构。

与 Qwen1.5 相比，Qwen2 在整体表现上超越了多数开源模型，在语言理解、语言生成、多语言、编码、数学、推理等基准测试中展现出与专有模型相抗衡的竞争力。Qwen2 的主要特征包括：

- 提供 Qwen2-0.5B、Qwen2-1.5B、Qwen2-7B、Qwen2-57B-A14B、Qwen2-72B 共 5 种规模。
- 每种规模均有基础版和指令版，均对齐人类偏好并支持多语言。
- Qwen2-7B-Instruct 与 Qwen2-72B-Instruct 的上下文长度提升至最高 128K Token。

### 10.2.2 ChatGLM3-6B 快速认识
ChatGLM 是智谱 AI 推出的大语言模型系列，以出色的性能和友好的开源协议著称，在中英双语领域认可度很高。

2023 年 3 月首发的 ChatGLM-6B 因开源且性能优秀而备受关注。
2023 年 6 月发布的 ChatGLM2-6B 在保持对话流畅、部署门槛低的基础上，性能更强、上下文由 2K 扩展到 32K。
2023 年 10 月的 ChatGLM3 系列包含 ChatGLM3-6B-Base、ChatGLM3-6B 和 ChatGLM3-6B-32K，采用全新提示词格式，原生支持多轮对话、工具调用、代码执行和 Agent 任务等复杂场景。
2024 年 6 月发布的 GLM-4 开源系列包含 GLM-4-9B、GLM-4-9B-Chat、GLM-4-9B-Chat-1M 和多模态模型 GLM-4V-9B。GLM-4-9B 及其对齐版本 GLM-4-9B-Chat 在性能上超越 Llama-3-8B，且支持多轮对话、网页浏览、代码执行、自定义工具调用和最长 128K 的长文本推理。GLM-4-9B-Chat-1M 与 GLM-4V-9B 支持 1M 上下文长度，约 200 万中文字符。

### 10.2.4 ChatGLM3-6B 的 GPU 量化推理
大语言模型应用广泛，但庞大的参数量会带来较高的内存消耗。量化技术通过用更低位数的数值表示模型参数，减少内存占用和计算压力，从而优化推理效率。常见做法包括 INT4、INT8、FP16、FP32 等，内存和计算降低的同时会伴随一定精度损失。

## 10.3 大模型部署实战
部署大语言模型的典型目的，是为用户提供服务或作为接口供其它系统调用。因此多数服务采用 B/S 架构，便于用户通过浏览器访问，开发者也能轻松集成到其它平台。

### 10.3.1 Gradio 网页部署方案
#### 1. Gradio 是什么
Gradio 是一个开源 Python 库，面向数据科学家、算法工程师以及不熟悉 Web 开发的用户，支持快速构建机器学习模型、API 或任意基于 Python 函数的 Web 应用。

借助内置的分享功能，可在数秒内生成可通过浏览器访问的 Web 应用，无需掌握 JavaScript、CSS 等前端技术。Gradio 提供简洁高效的开发接口，让使用者专注于核心模型和算法的呈现。
