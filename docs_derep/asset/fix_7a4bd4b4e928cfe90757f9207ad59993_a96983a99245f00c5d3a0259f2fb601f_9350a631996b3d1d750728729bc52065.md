# 手工并行与声明式张量并行

一种思路是自己划分子模块到具体的设备并手动搬运激活。示例中把 ResNet50 的前半网络绑定到第一张 NPU，后半网络加上分类头绑定到第二张 NPU，推理时需要显式地把中间特征搬到后者才能继续计算。

另一种思路是使用声明式的分布式张量并行。示例在多卡 CUDA 环境下通过分布式启动工具拉起进程，先用设备网格构建并行上下文，再用一份层级映射表为 Transformer 的归一化、注意力、FFN、词嵌入和输出层分别指定序列并行、列向切分、行向切分以及输入布局的转换，最后通过统一的并行化接口一次性把整套计划应用到模型上。

    def __init__(self, *args, **kwargs):

        self.seq1 = nn.Sequential(

            self.conv1, self.bn1, self.relu,

            self.maxpool, self.layer1, self.layer2

        ).to('npu:0')

        self.seq2 = nn.Sequential(

            self.layer3, self.layer4, self.avgpool,

        ).to('npu:1')

        self.fc.to('npu:1')

    def forward(self, x):

        x = self.seq2(self.seq1(x).to('npu:1'))

        return self.fc(x.view(x.size(0), -1))
