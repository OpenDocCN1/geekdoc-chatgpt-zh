### 11.2.3 使用 Llama-factory 进行 LoRA 微调

### 1. Llama-factory 简介
Llama-factory 面向机器学习与深度学习开发者，提供一套简化大模型微调的工具集，尤其擅长低秩适配 LoRA 这类参数高效技术。它把常用功能集成在一起，让用户在算力有限的情况下也能高效完成大模型的微调任务。

核心能力概括如下。

（1）高效的 LoRA 微调：聚焦低秩适应，通过引入低秩矩阵大幅减少可训练参数，在资源受限时仍能保持训练效率。

（2）简洁的 API 设计：接口直观易用，少量代码即可完成预训练模型的 LoRA 微调。

（3）兼容性强：兼容 PyTorch、TensorFlow 等主流框架，并能无缝集成 transformers 等库。

（4）配置选项丰富：可自定义 LoRA 的秩 rank、缩放系数 alpha、dropout 率等参数，适配不同场景需求。

（5）社区支持完善：拥有活跃的社区和详尽文档、教程与示例。前往 GitHub 搜索 Llama-factory 即可查阅相关资料。

### 4. 数据集配置
1）数据集文件的格式
在 Llama-factory 或其他机器学习框架中进行微调时，数据格式十分关键。常见格式包括 CSV、JSON、TSV 以及 Hugging Face 的 Dataset。

- （1）CSV：逗号分隔的纯文本，每行一个样本，每列一个特征，结构清晰。
- （2）JSON：键值对存储，支持嵌套，适合结构复杂的数据，常用于 API 与配置。
- （3）TSV：制表符分隔的文本，避免数据中出现逗号带来的冲突。

### 6. 损失折线图在模型训练中的意义和参考点
损失折线图是训练过程的重要可视化手段，展示训练与验证损失随轮数或步数的变化。借助它可以评估训练效果并及时修正问题。

图 11-24

（1）监控收敛情况。
收敛：损失随训练不断下降并趋于稳定，说明模型在学习并接近最优解，曲线表现为下降后平稳。
未收敛：损失未明显下降或波动很大，说明学习效果不佳，需调整超参数或优化器。

（2）识别过拟合与欠拟合。
过拟合：训练损失持续下降，验证损失下降到某点后回升，说明模型在训练集上表现好、在验证集上变差。
欠拟合：训练与验证损失均维持高位且几乎不变，说明模型复杂度不足，难以捕捉数据规律。

（3）调整学习率和超参数。
学习率过高会导致曲线剧烈波动，过低则收敛缓慢。批处理大小也影响收敛速度与稳定性。

（4）提供实时反馈。
损失曲线能实时反映训练进度，若某阶段损失骤升，可排查数据或参数异常。

示例分析：
曲线 A 持续下降趋稳，训练集表现良好。
曲线 B 先降后升，出现过拟合，需做正则化或早停。
曲线 C 长期高位，存在欠拟合，需提升模型复杂度或调整超参数。

## 11.3 模型量化

### 11.3.1 量化的概念与优势
模型量化指把权重与激活值从高精度转为低精度格式，如 Int8。核心优势在于压缩与提速，以及降低部署成本。

### 1. 模型压缩与加速
量化通过降低参数位数，显著减小模型体积；低精度计算在现代硬件上更快，从而加速推理。

### 2. 部署成本降低
量化后推理所需内存与算力大幅下降，运行效率提升，尤其在移动设备和嵌入式系统等资源受限场景中优势明显。
