# 事件评测的演进脉络

1998 年首届 TDT 问世，首批试验只涉及中文与英文，聚焦新闻分段、主题识别与主题追踪，评判标准选用错误识别代价，后续各届沿用此标准。1999 年第二届在原任务上追加全新事件识别与报道关联识别。2000-2004 年间，五个子任务保持不变，评测语言扩至中文、英文、阿拉伯文三语。

Linguistics Data Consortium, LDC 为 TDT 系列提供 TDT-pilot、TDT-2、TDT-3、TDT-4、TDT-5 共五套语料，其中 TDT-3 兼顾 1999、2000、2001 三届。因 TDT 里话题颗粒度比事件粗，其标注逻辑与 ACE 等项目差异明显。TDT-2 与 TDT-3 使用 YES、BRIEF、NO 三档标签，分别表征报道与话题完全相关、部分相关、不相关；TDT-4 与 TDT-5 则简化为 YES 与 NO 两种标签[213]。

### （3）ACE 评测会议

Automatic Content Extraction, ACE 评测自 ACE 2004 与 ACE 2005 起开设中文和英文事件挖掘赛道。对应语料包含英文 599 篇、中文 633 篇。ACE 所指的事件与 TDT 不同，属于预先定义类型且句级定位，标注内容包括事件类型、触发词、事件要素及其角色。ACE 2005 的标注集至今仍是应用最广的事件挖掘基准。

ACE 将事件解释为动作发生或状态转变，由触发词和要素构成。触发词通常是能体现事件的动词或动词性名词，要素则指参与事件的实体、时间、地点等，不同要素在事件中承担不同职能，角色可等价视为要素本身。共定义 8 大类 33 小类，具体见表 7.1，不同类型对应的角色各异，部分示例见表 7.2。

标注采用 Extensible Markup Language, XML 方式。每条事件记录触发词、类型、子类型、要素及角色，并额外标注四类属性：
- ① 极性 polarity，即肯定或否定。
- ② 时态 tense，过去、现在、将来或不确定。
- ③ 指属 genericity，特指 specific 与泛指 generic。
- ④ 形态 modality，肯定 asserted、信念 believed event、假设 hypothetical event 等。

Ahn[27] 在公开会议上最早报道 ACE 事件挖掘工作，将其拆分为触发词识别、触发词分类、要素识别、要素分类四个子任务，方法使用 K-Nearest Neighbors, KNN 与 Maximum Entropy, ME 分类器。此后学界在该数据集上的工作主要集中于有效特征挖掘、抽取模型改进、降低对标注语料依赖三方面。

### （4）KBP 评测会议

Knowledge Base Population, KBP 属于 Text Analysis Conference, TAC[资源 7-1] 的核心任务，研究从自然语言文本抽取信息并链接至已有知识库。事件相关任务始于 2014 年，迄今举办 2014、2015、2016、2017 四届[343]。

KBP 2014 的事件挖掘要求识别指定事件的 event argument 并判定其 argument role，类型与角色沿用 ACE 2005 定义，每类子事件有各自要素。提供 599 篇标注文档，多为新闻及数据，经人工筛选保证每类事件均有实例，长句被截断。评测指标为 F₁ value，仅有英语语料。

2015 年任务在 2014 基础上扩展为五个子任务，仍限英语：
- ① event nugget detection，识别文本中的事件指称 event mention，特别是多词触发如 take away、go over，需找出句子中全部相关指称，定义与标注遵循 ACE 标准，同时标注 Actual、Generic、Other 三种属性。
- ② event nugget detection and coreference，需识别指称并做事件共指消解，不处理子事件关联。
- ③ event nugget coreference，在已标注指称基础上仅判定共指关系。
- ④ event argument extraction and linking，抽取要素及角色并链接到指定事件或实体。
- ⑤ event argument verification and linking，对抽取与链接结果进行校验。

2016 年在 2015 基础上加入文档级识别，每个子任务均提供英语、中文、西班牙语评测。提供 200 篇英文标注文档、20 万词中文文档、12 万词西班牙文档，但未附训练数据。

### （5）BioNLP 评测会议

Ryan McDonald 等[319] 2005 年首次提出面向生物医学的事件挖掘，目标是从生物医学文献中获取触发词、类型、要素等生物事件信息。由东京大学组织的 BioNLP 评测是该方向最权威的会议，2009 至 2013 年举办三次：BioNLP 2009[239]、BioNLP 2011[240]、BioNLP 2013[241]，共含三个子任务，各自针对不同特异性水平的生物分子。

该系列极大推动了生物医学事件挖掘，三届评测出现大量优秀系统。代表方法分两类：分阶段系统，如图尔库大学的 TEES 系统[56]、UTurku 系统[57]、EVEX 系统[189] 和 TEES-2.1 系统[58] 以及 Miwa 提出的 EventMine 系统[344] 等；联合系统，如曼彻斯特大学提出的 UMass 系统[397] 和 FAUST[398] 系统等。

### （6）TimeBank 语料库

TimeBank 语料[388] 起源于 Time and Event Recognition for Question Answering Systems, TERQAS 会议，由 National Regional Research Centre, NRRC 与 Advanced Research and Development Activity, ARDA 主办。时间标注采用 TIMEX3 格式的 XML 标签，TIMEX3[387] 在 TIMEX2 基础上提升了时间表达精度。

语料来源于 DUC、ACE、PropBank 的新闻报道。事件用 event class、event tense、event aspect 三属性描述。可标注词包括时态动词 tensed verbs、静态形容词 stative adjectives、事件名词 event nominal。划分为 Occurrence、Perception、Reporting、Aspectual、State、Intensional State、Intensional Action、Modal 八类。TimeBank 专注事件时间要素及事件间时序，不涉及其他要素，共 300 篇新闻，推动了时间要素与时序研究的发展。

### （7）其他相关语料

上述公开评测与语料是当前事件挖掘最具影响力的资源。中文标注工作较少，Meng 等[325] 基于 200 篇中英文突发事件新闻构建 Chinese Event Corpus, CEC[325]。Lin 等[289] 提出面向中文的 TIMEX2 标注系统，用于自动标注时间短语。Yuan 等[515] 从 80 篇突发语料中标注地震、火灾、中毒、恐怖袭击四类，每类 20 篇。Ding 等[129] 从新浪 2008-2009 年半年音乐新闻中标注 6000 句音乐事件。Meng 等[326] 标注 4000 句金融事件。

总体看，事件挖掘在国际评测与公开语料推动下发展。不同资源关注领域与粒度差异大，受事件结构复杂及语言表达多样性影响，事件框架尚未统一。现有语料多为人工标注，成本高导致类型少规模小，评测显示性能仍偏低，亟需更大规模语料与评测以支撑海量事件知识图谱构建。

## 7.2 限定域事件抽取

在评测与语料驱动下，事件挖掘持续受关注。按类别确定方式可分为限定域与开放域。限定域在抽取前预先定义目标事件类型及每种类型的结构，即要素构成，常提供一定标注数据。受结构复杂性影响，数据规模普遍较小但能保证每类事件都有样本。ACE 事件挖掘是最具代表性的限定域任务，共定义 8 大类事件，例如：business 商务事件、conflict 冲突事件、transaction 交易事件等，进一步细分为 33 类子事件。

该方向是信息抽取与知识图谱构建的关键环节，研究多集中于方法改进。按实现方式可分为基于模式匹配和基于机器学习两类。

### 7.2.1.1 有监督的事件模式匹配

模式完全依赖人工标注语料，需预先完整标注，效果受标注质量制约。一般包括语料人工标注、模式学习、模式匹配三步。

代表系统是 AutoSlog。Ellen[400] 等从 MUC-4 语料观察得出事件角色关系多可从短语上下文获得，据此提出假设：要素首次出现处即确定其与事件关系，且要素周围语句包含角色描述。1993 年据此开发 AutoSlog，定义 13 个模式，例如：
- （1）< 主语 > 被动式动词，例如：< 受害者 > 被谋杀了。
- （2）< 主语 > 主动动词，例如：< 嫌犯 > 制造了爆炸。
- （3）< 主语 > 动词不定式，例如：< 嫌犯 > 试图杀死。
- (4) 被动式动词 < 直接宾语 >，例如：被杀死的 < 受害者 >。
- (5) 主动式动词 < 直接宾语 >，例如：摧毁 < 目标 >。
- (6) 被动式动词 + 介词 + < 名词 >，例如：被用 < 工具 > 杀死了。

除模式外还需词典支持，如模式 “< 主语 > 被动式动词” 在 MUC-4 语料中动词词典为谋杀、爆炸等。基于人工标注语料提取模式大幅缩短了 CIRCUS[268] 领域词典构建时间。

Kim 和 Moldovan[242] 用语义框架与短语模式表示特定领域模式，开发 PALKA parallel automatic linguistic knowledge acquisition 系统，融入 WordNet 语义信息后，用 MUC 恐怖主义标注语料训练，抽取效果良好。
