#### 1.9.5 绑定完了还是沉默，常见原因

原因一：模型配置不对。网关在跑、渠道也通了，但模型 API Key 写错或余额不足。发消息后看日志：
[PRE7]
若出现 “API Key invalid” 或 “insufficient balance” 之类提示，说明模型调用失败，回头核对 Key 和余额。

原因二：网络可达性。机器人收到了消息，去调模型却连不上，比如需要科学上网的海外模型。日志里会出现 “network timeout” 或 “connection refused”。换一个可访问的模型试试。

原因三：平台权限不足。部分平台对机器人有权限要求。比如 Telegram 开启 Privacy Mode 时群里只能看到 @ 的消息；飞书机器人需要开启对应权限才能收发。回到开放平台检查设置。

原因四：消息格式不被支持。第一次发的是图片、文件、语音等，机器人未配置对应能力就不会有反应。先用纯文本测试，确认基础对话正常，再测其他类型。

#### 1.9.6 发消息不回的排查顺序
- 先确认绑定状态：`openclaw pairing list <channel>`
- 再确认渠道是否连通：`openclaw channels status --probe`
- 然后看日志是否有报错：`openclaw logs --follow`
- 最后确认模型是否可用：去控制面板测试，若面板能回，说明模型正常；若也不回，说明模型有问题

走完这四步基本能定位。绑定多一步是为了保护额度不被滥用，熟练后几秒搞定。第一次成功收到回复时，就像养的宠物终于开口了。恭喜，你的龙虾活了。

### 1.10 怎么让它记住你，成为专属助手
装好、配好模型、能对话后会发现它“记性差”——每次都要重复背景、解释需求。这像招了个新人，能干活但不了解习惯。本节讲如何积累记忆。

#### 1.10.1 记忆原理：靠文件存，不是靠模型脑补
很多人以为 AI 记忆存在模型里，用久了自然记住。这是误解。OpenClaw 的长期记忆不是模型自己记，而是工作区里的 Markdown 文件。

官方表述很明确：OpenClaw memory is plain Markdown in the agent workspace. The files are the source of truth; the model only “remembers” what gets written to disk。翻译过来就是记忆是磁盘上的纯文本，文件才是真相，模型只能记住写进磁盘的内容。

好处是记忆可见、可编辑、可备份。你随时能打开文件查看、修改或删除，不像黑盒系统。

#### 1.10.2 工作区里要关注的关键文件

##### USER.md：关于你的档案
存用户的结构化信息，包括称呼、偏好、工作习惯、人际关系等。新工作区默认会创建 USER.md 等 starter 文件。
适合写相对稳定的个人信息，比如想被怎么称呼、工作领域、沟通偏好、时区作息。

##### MEMORY.md：长期记忆精华
可选的长期记忆文件，不会自动创建。官方说它是 curated long-term memory，仅在 main 和 private session 加载，不在群聊等共享上下文加载。
适合记长期决策、项目背景、反复提到的人和事、长期目标和约束。官方模板建议记录：durable facts, preferences, decisions, constraints, open loops。

##### memory/YYYY-MM-DD.md：每日对话日志
按日期自动生成的对话日志，比如 `memory/2026-03-11.md`。官方建议 session 开始时读取今天和昨天的日志，帮助保持短周期上下文连续。
该文件只追加不修改，长期下来就是完整的互动历史。

##### AGENTS.md 和 SOUL.md：身份与人格
AGENTS.md 定义行为规则、回复风格、工作原则；SOUL.md 定义不可变人格内核。
虽然不直接记录关于你的信息，但决定了互动方式。比如可在 AGENTS.md 写“用户技术背景，可直接说术语”“回答简洁，除非要求详细”。

#### 1.10.3 让它更懂你的三招

方法一：对话中明确要求记忆
直接说“记住这个”。例如：

方法三：靠每日日志自动积累

#### 1.10.4 记忆系统的几个关键细节
细节一：私聊和群聊记忆分开。MEMORY.md 只在 main/private session 加载，绝不在群组上下文加载。这是隐私保护，私聊里的个人信息不会自动暴露到群聊。
细节二：记忆文件是纯文本，可备份。用 Git 管理、定期备份、在不同机器间同步都方便。
细节三：记忆不是越多越好。文件过长每次对话都要加载，会占用上下文窗口，增加 token 消耗。建议定期清理过时信息，提炼核心。

#### 1.10.5 新手入门三步走
第一步：完善 USER.md。花 10 分钟把基本信息、工作背景、沟通偏好写进去。
第二步：在对话中主动要求记忆。遇到重要信息时明确说“记住这个”。
第三步：定期回顾每日日志。每周或每月看一次日志，把有价值内容提炼到 MEMORY.md。
做好这三步，一个月后会明显感觉它懂你了，不用反复说明背景偏好，能记住上次说过的事，并按习惯调整回复。

使用时偶尔会遇到“权限不足”“无法执行”“工具不可用”。通常是权限设置挡住了。OpenClaw 的权限不是单一开关，而是多层机制。
