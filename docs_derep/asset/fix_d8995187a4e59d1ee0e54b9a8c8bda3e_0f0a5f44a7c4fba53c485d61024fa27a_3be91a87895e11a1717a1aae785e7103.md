## 4.6 第四节回顾

前馈架构是智能领域最常用算法之一。本节介绍了多层前馈与 `RBF` 两大网络族，二者均适用于归类与回归。

前馈网络层级分明：入口层接收程序数据，出口层返回处理结果，中间层单元负责识别入参模式并产出正确输出。

`RBF` 网络隐层使用径向基函数群，除连接强度外，还可调节函数宽度与中心。虽均具备通用近似能力，但处理机制迥异。

迄今为止我们仅见如何根据参数推算输出。调优是依据目标调整参数的过程，需配合考核手段——即按预期产出评估实际表现。下一节将详述调优与考核体系。

# 第 5 章 调优与考核机制

本章核心看点：
*   平均平方误差（MSE）考核体系
*   灵敏度与特异度的权衡艺术
*   ROC 图谱与 AUC 指标解读
*   退火优化策略入门

前文已掌握按既定参数推算输出的方法，但参数从何而来？**调优**即不断修正参数使输出逼近目标的核心流程。**考核**则是依据预期产出为实际表现打分的环节。

本章系统拆解调优考核体系。鉴于手段多样，亟需统一判断基准——**评价函数**。它为模型表现量化打分，调优据此迭代修正参数。通常评价函数倾向“分值越低越好”，称作**求极小值**问题；反之若需分值越高越好，则为**求极大值**问题。主流调优器均兼容双模式。

理论上，任意连续域搜索算法（退火策略、群智能 PSO、进化策略、贪婪搜索、Nelder-Mead、盲目乱猜等）均可用于参数优化。本章重点剖析**退火策略**这一入门级调优器。除优化器外，**梯度回传**是另一核心调优范式，相关进阶算法将在第 6 章“梯度回传调优”与第 7 章“其他传播调优”中详细展开。

## 5.1 归类任务的考核体系

归类任务旨在将入参划归至一个或多个预设品类。最直观的考核方式是计算**误判率**——即训练样本中被错误归类的占比，这与答题计分逻辑如出一辙。例如十道判断题判错一道，得分即为 90%。但机器归类往往不直接给出确定标签，而是输出各品类的**似然度分布**。

[PRE3]

如上图：考生直接勾选“B”；模型给“B”八成把握、“A”一成，其余分散。若答案为“B”，模型得 0.8 分；若为“D”，仅得 0.05 分。这种分布式输出要求更精细的考核指标。

### 5.1.1 二分判别：在“权衡利弊”中寻平衡

当输出仅两类（如是/否、买入/卖出）时，涉及**二分判别**。以信贷审批为例：系统仅需决定“通过”或“拒绝”。考核核心指标为**误报（FP，第一类错误）**与**漏报（FN，第二类错误）**。

*   **误报（FP）**：本该拒绝的高风险客户被通过（放过坏人）。
*   **漏报（FN）**：本该通过的优质客户被拒（错杀好人）。

银行通常视误报危害远大于漏报（坏账损失 > 机会成本），故倾向压低误报率。这引出两个关键特性指标：
*   **灵敏度**：倾向判“通过”（通过率高），代价是误报增加。
*   **特异度**：倾向判“拒绝”（拒绝率高），代价是漏报增加。

[PRE4]

移动**决策边界**可动态调节二者平衡：边界左移→特异度增强（真拒区域缩小）；边界右移→灵敏度增强（真命中区域缩小）。

#### 业务场景决定边界选择
并非总要最大化整体准确度。预测结构失稳案例中：
*   **误报（虚警）**：浪费技术人员排查工时。
*   **漏报（漏判）**：实乃悲剧，酿成灾难。
此时必须大幅提高特异度（压低漏报），宁愿多检几座安全桥，绝不漏报一座危桥。

### 5.1.2 多分识别：多出口架构与最大值决策

预测三个以上品类（如艾里斯花品种 Setosa/Versicolor/Virginica）需**多出口单元**。单单元仅能二分，双出口极少用，通常品类数匹配出口数。

**核心逻辑**：损失 = $-\log(\text{正确品类的似然度})$。

| 正确品类似然度 | 交叉熵值 | 解读 |
| :--- | :--- | :--- |
| 1.0 (完全把握) | $-\log(1)=0$ | **零损失**，完美拟合 |
| 0.8 | $\approx 0.22$ | 小惩罚 |
| 0.5 (五五开) | $\approx 0.69$ | 基准惩罚 |
| 0.1 (一成把握) | $\approx 2.30$ | **重罚** |
| $\to 0$ | $\to +\infty$ | **无限大惩罚**，模型崩溃 |

这倒逼模型诚实表达：**别虚高把握踩空，宁可谦虚给五成一**。这正是交叉熵胜过硬正确率的关键——它考核**概率校准质量**而非仅硬判别。

## 本节小结
1.  **调优本质** = 评价函数驱动的参数求极值（求极小/极大）。
2.  **二分判别核心**在于误报/漏报权衡，通过边界调节灵敏度/特异度，用 AUC 量化综合能力。
3.  **多分识别**采用多出口 + 最大值决策。
4.  **交叉熵**通过对数惩罚强制模型给出可靠分布，是判别任务首选评价函数。
