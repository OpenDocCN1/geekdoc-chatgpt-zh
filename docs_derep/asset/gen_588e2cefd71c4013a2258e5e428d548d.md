# 用 OpenAI 快速搭一个带风控的订餐小助手

想让模型既能聊得通顺，又能稳稳收集到手机号、人小、就餐时间，还要能防风险并落库，下面这套实现把这些环节串起来了。整体思路是：先用 moderation 做输入风控，定义好对话、会话、记录的数据结构，再封装一个统一的问答接口，最后用一个状态机式的 Chatbot 去循环抽取槽位并持久化。

先从安全校验说起。密钥从环境变量读入，调用 OpenAI 的 moderation 接口判断用户输入是否被标记，返回结果中的 flagged 布尔值即可。示例里对正常词 good 的校验预期为 False。

import openai

import os

OPENAI_API_KEY = os.environ.get("OPENAI_API_KEY")

openai.api_key = OPENAI_API_KEY

import requests

def check_risk(inp: str) -> bool:

    safe_api = "https://api.openai.com/v1/moderations"

    resp = requests.post(safe_api, json={"input": inp}, headers=

        {"Authorization": f"Bearer {OPENAI_API_KEY}"})

    data = resp.json()

    return data["results"][0]["flagged"]

check_risk("good") == False

数据层用 dataclass 描述三类对象：基础用户、一次会话以及单轮记录。会话里要保留手机号、用餐人数和用餐时间，记录则保存用户原话和机器人原话的时间戳。

def ask(msg):

    response = openai.ChatCompletion.create(

        model="gpt-3.5-turbo",

        temperature=0.2,

        max_tokens=100,

        top_p=1,

        frequency_penalty=0,

        presence_penalty=0,

        messages=msg

    )

    ans = response.get("choices")[0].get("message").get("content")

    return ans

核心是 Chatbot 类。它在系统提示里明确角色是订餐机器人，目标是收集三个槽位：cellphone、people_number、meal_time。每一轮模型必须同时输出给用户的自然回复和当前已抽取的 JSON 槽位，格式由机器人内部正则按空行拆分。最大轮数设为 10，槽位缺失则继续对话。

会话开始时生成 uuid 作为 session_id，记录开始时间。循环中先调用 ask 得到模型完整输出，取第一段作为对外回复，第二段解析为槽位字典并打印。随后判断三项是否都已非空，完成即结束；否则读取用户输入，追加到消息历史并写入一条 ChatRecord，同时用 check_risk 做风险拦截，有风险直接中断。超过轮数或出现异常分别给出结束语和人工介入提示。结束时用收集到的槽位实例化 ChatSession，一并把历史记录写入数据库。

class Chatbot:

    def __init__(self):

        self.system_inp = """现在你是一个订餐机器人（角色是 assistant），你的目的是向用户获取手机号码、用餐人数和用餐时间三个信息。你可以自由回复用户消息，但要牢记你的目的。在每一轮，你需要向用户输出回复以及获取到的信息，信息应该以 JSON 格式存储，包括三个字段：cellphone 表示手机号码，people_number 表示用餐人数，meal_time 表示用餐时间。

回复格式：

给用户的回复：{回复给用户的话}

获取到的信息：{"cellphone": null, "people_number": null, "meal_time": null}

"""

        self.max_round = 10

        self.slot_labels = ["meal_time", "people_number", "cellphone"]

        self.reg_msg = re.compile(r"\n+")

    def check_over(self, slot_dict: dict):

        for label in self.slot_labels:

            if slot_dict.get(label) is None:

                return False

        return True

    def send_msg(self, msg: str):

        print(f"机器人：{msg}")

    def chat(self, user_id: str):

        sess_id = uuid.uuid4().hex

        chat_at = datetime.now()

        msg = [

            {"role": "system", "content": self.system_inp},

        ]

        n_round = 0

        history = []

        while True:

            if n_round > self.max_round:

                bot_msg = "非常感谢您对我们的支持，再见。"

                self.send_msg(bot_msg)

                break

            try:

                bot_inp = ask(msg)

            except Exception as e:

                bot_msg = "机器人出错，稍后将由人工与您联系，谢谢。"

                self.send_msg(bot_msg)

                break

            tmp = self.reg_msg.split(bot_inp)

            bot_msg = tmp[0].strip("给用户的回复：")

            self.send_msg(bot_msg)

            if len(tmp) > 1:

                slot_str = tmp[1].strip("获取到的信息：")

                slot = json.loads(slot_str)

                print(f"\tslot: {slot}")

            n_round += 1

            if self.check_over(slot):

                break

            user_inp = input()

            msg += [

                {"role": "assistant", "content": bot_inp},

                {"role": "user", "content": user_inp},

            ]

            record = ChatRecord(user_id, sess_id, bot_inp, user_inp,

                datetime.now())

            history.append(record)

            if check_risk(user_inp):

                break

        chat_sess = ChatSession(user_id, sess_id, **slot, chat_at=chat_at)

        self.store(history, chat_sess)
