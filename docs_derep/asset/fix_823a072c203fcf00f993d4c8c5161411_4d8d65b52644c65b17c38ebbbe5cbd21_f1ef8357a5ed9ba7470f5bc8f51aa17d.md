## 无监督挖主题

第三组是主题挖掘。读取纯文本文件后对每行进行正则分词、停用词剔除、词干化，用 Gensim 建立词典与词袋矩阵，训练两主题的 LDA，最后打印每个主题的核心词及其占比。

# Load input data

def load_data(input_file):

    data = []

    with open(input_file, 'r') as f:

        for line in f.readlines():

            data.append(line[:-1])

    return data
