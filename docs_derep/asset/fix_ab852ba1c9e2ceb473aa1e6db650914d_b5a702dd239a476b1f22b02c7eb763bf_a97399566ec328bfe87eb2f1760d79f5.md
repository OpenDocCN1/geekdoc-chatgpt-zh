# 客服系统三件事：分流、状态、周报

一个好用的智能客服，本质上要把意图送到正确的执行单元、让一次对话的全程可追踪可回放、并把运营指标自动讲成周报。下面这套实现围绕这三点展开：先做保守的分流，再做状态管理，最后做数据叙事。

分流逻辑先保证不瞎猜。识别信心不足时，系统不会强行拍板，而是退回到路由配置里写好的默认处理器，并把原因记为信心不足走知识库兜底。紧接着做一次身份校验，如果 user_info 标记为 VIP，就按一级意图调取专属处理器覆盖已有选择，决策说明更新为走 VIP 专属通道。整段路由最终会落一份记录，包含最终使用的处理器和对应的说明。

对话状态由 ConversationStateManager 来维护。它把一次完整交互拆成十个可观测节点：greeting、intent_recognition、info_collection、slot_filling、confirmation、knowledge_retrieval、task_execution、answer_generation、follow_up_check、closing。启动或重启会话时会调用 reset，生成唯一的 conversation_id，起步状态定为 greeting，并清空对话历史、槽位、当前意图、实体记忆、主题列表、情感评分、系统动作、外链上下文和状态快照，为回滚保留现场。

update_state 采用增量写入。用户输入和系统回复都会带时间戳追加到 conversation_history；收到 intent_data 时更新 current_intent 并触发内部的状态转换；entities 到达时写入槽位和记忆区。返回的对象始终是同一份 state，保证上下游看到一致的视图。

# 智能客服数据分析报告生成器

class ServiceAnalyticsReportGenerator:

    def __init__(self, model_name="deepseek-ai/deepseek-7b"):

        self.tokenizer = AutoTokenizer.from_pretrained(model_name)

        self.model = AutoModelForCausalLM.from_pretrained(

            model_name,

            device_map="auto",

            torch_dtype=torch.float16

        )

    async def generate_weekly_report(self, analytics_data):

        """

        生成周度分析报告

        Args:

            analytics_data: 包含各项指标和数据的字典

        """

        # 构建报告提示词

        prompt = self._build_report_prompt(analytics_data)

        # 调用 DeepSeek 模型生成报告

        inputs = self.tokenizer(prompt, return_tensors="pt").to(self.model.device)

        outputs = self.model.generate(

            **inputs,

            max_new_tokens=2048,

            temperature=0.7,

            do_sample=True,

            top_p=0.9

        )

        report = self.tokenizer.decode(outputs[0], skip_special_tokens=True)

        # 提取报告部分(去除提示词)

        report_only = self._extract_report_content(report, prompt)

        # 格式化为 Markdown

        markdown_report = self._format_to_markdown(report_only)

        return {

            "report_markdown": markdown_report,

            "report_text": report_only,

            "report_timestamp": datetime.now().isoformat()
