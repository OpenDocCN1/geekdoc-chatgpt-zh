# 第四章 数据要素市场新局

## 第一节 一般规定

### 第四十七条 【建设目标】

市人民政府要对照国家部署，加快推进数据要素由市场主导调配的改革步伐，制定配套政策，培育公平、开放、有序、诚信的市场生态，建立起资产评估、登记结算、撮合交易、争议解决等运行体系，推动数据要素在法治轨道上实现合规有序流动。

[PRE0]

本条旨在规定数据要素市场建设的目标。

[PRE1]

数据要素市场化配置：数据要素市场化配置是指将尚未完全由市场配置的数据要素转向由市场配置的动态过程，其目的是形成以市场为根本调配机制，实现数据流动的价值或者数据在流动中产生价值。

[PRE2]

#### 一、政策脉络简述

当数字经济体量攀升到一定高度，推动数据要素走市场化路径就成为大势所趋，也是供需两端资源与需求累积到临界点后的自然演进。2014年，政府工作报告首次把大数据纳入部署，拉开国家顶层设计的序幕。十三五时期围绕大数据的政策文件密集出台，为数据作为生产要素进入市场提供了制度土壤，带动产业升级、技术进步、设施完善和应用深化，各地也展开了先行先试，形成了本土化探索之路。

数据在国民经济中的权重持续上扬，其要素特征愈加明显。2020年4月，中共中央、国务院印发《关于构建更加完善的要素市场化配置体制机制的意见》，明确把数据纳入生产要素范畴，提出加快培育数据要素市场，并指明了改革方向。首要任务是推动政府数据开放共享，优化经济治理基础数据库，加快跨地区跨部门数据互联互通。另一任务是提升社会数据资源价值，孵化数字经济新业态新模式。还需强化资源整合与安全保护，探索建立统一规范的数据管理制度，提升质量与规范水平，丰富数据产品形态，并研究按数据属性理清产权归属。国务院办公厅《要素市场化配置综合改革试点总体方案的通知》提出，到2023年试点要取得阶段性成效，在土地、劳动力、资本、技术等要素市场化配置的关键环节实现重要突破，数据要素市场化配置的基础制度建设也要取得积极进展。

建设数据要素市场的深层逻辑，是弥合信息鸿沟与信任鸿沟，推动数据资源要素化，促成各方协同开发、综合利用，最终实现价值最大化。

#### 二、建设要求要点

让数据在流通中创造价值或释放价值，是市场主导调配的核心要义。2021年12月，国务院办公厅印发《要素市场化配置综合改革试点总体方案的通知》，对数据要素流通规则提出了明确要求：

第一，完善公共数据开放共享机制，激发公共数据在要素市场中的活力。建立高效的公共数据共享协调体系，打造公共数据基础支撑平台，推动归集整合、有序流通与共享。健全公共数据共享、开放、运营服务、安全保障的管理体制。优先向社会开放企业登记监管、卫生健康、交通运输、气象等高价值数据集，探索开展政府数据授权运营。

第二，健全数据流通交易规则，让数据资产的交换价值得到充分体现。探索“原始数据不出域、数据可用不可见”的交易范式，在保障个人隐私与数据安全的前提下，分级分类、分步有序推进重点领域数据流通应用。探索建立数据用途与用量控制制度，实现数据使用可控可计量。规范培育数据交易市场主体，发展数据资产评估、登记结算、撮合交易、争议仲裁等运营体系，稳妥推进数据资产化服务。

第三，拓展规范化开发利用场景，以大数据与人工智能产业发展助力城市数字化转型。发挥龙头企业与行业组织作用，推动人工智能、区块链、车联网、物联网等领域数据采集标准化。深化人工智能社会实验，开展区块链创新应用试点。在金融、卫生健康、电力、物流等重点领域，以数据为核心探索产品与服务创新，打造统一的技术标准与开放的创新生态，促进商业数据流通、跨区域数据互联与政企数据融合应用。

#### 四、夯实安全根基

强化网络安全等级保护要求，推动完善数据分级分类安全保护制度，利用技术手段构建数据安全风险防控体系。探索完善个人信息授权使用制度。探索建立数据安全使用承诺制度，探索制定大数据分析和交易禁止清单，强化事中事后监管。探索数据跨境流动管控方式，完善重要数据出境安全管理制度。

# 三、数据要素市场运营体系

营造公平开放有序诚信的数据要素市场，需要以清晰的产权界定、交易规则、定价机制、分配机制、监管机制及法律保障为支撑。未来市场演进需要在这些保障机制上持续动态调整，最终形成成熟的市场化配置格局。

## （一）数据资产评估

数据资产已成为企业数字化转型的关键载体，基于数据驱动的资产运营是转型的基石。数据资产化是要素市场发展的核心环节，涵盖价值评估与定价。中国信息通信研究院《数据资产管理实践白皮书》将数据价值评估分为成本评估与价值评估两大维度，成本评估包括采集、存储、计算、运维四类，价值评估涵盖活性、质量、稀缺性、时效性、经济性五类。实践中仍面临多重挑战：其一，权属不清导致交易稳定性不足，随着交易频次增加数据售价迅速衰减，且数据无形、易复制，难以追踪后续使用与再交易，法律约束困难；其二，数据的无限复制性与非排他性衍生出个人隐私与数据安全问题，制约开放流通；其三，数据价值具有高度不确定性，潜在应用广阔但不同环节需求各异，交易定价难以实现合理化。

## （二）数据登记结算

以上海数据交易所为例，数据在场内交易前须完成登记，仅登记入库的数据产品方可挂牌。各地实践显示，尽管多地已设立数据交易机构，但场外交易仍占主流。为引导数据进场，北京、山东等地相继出台数据交易登记细则。登记制度的核心在于以登记为依据强化场内监管：一方面确保可交易数据的可控、可追溯、合法合规；另一方面降低交易成本与安全风险，激励供需双方入场。随着区块链、隐私计算、多方安全计算等技术成熟，登记流程也需与技术深度融合，以保障登记过程安全、合规、可信。

## （三）数据撮合服务

各地数据交易中心大多扮演第三方平台角色，承担撮合供需职能。平台上，供给方发布数据产品，需求方发布数据需求，双方匹配后向平台发起交易，平台居中服务。目前政府主导、企业或高校创办的平台均采用相近模式。据《数据安全法》第33条，数据交易中介机构负有要求数据提供方说明数据来源、审核双方身份并留存记录的法定义务。条例第53条进一步细化，鼓励交易服务机构发展新业态，提供数据资产、合规性、质量等第三方评估，以及交易撮合、交易代理、专业咨询、数据经纪、数据交付等专业服务，丰富要素市场生态。
