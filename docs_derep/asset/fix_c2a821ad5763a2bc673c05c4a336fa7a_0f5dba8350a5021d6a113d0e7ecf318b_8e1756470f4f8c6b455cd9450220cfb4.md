# 第5章 DeepSeek本地化安装部署

在线使用 DeepSeek 时可能遇到网络延迟、数据隐私不安全等问题。为了解决这些问题，可将 DeepSeek 部署到本地计算机，获得更便捷、高效且安全的体验。

## 5.1 认识和安装Ollama

要在本地部署 DeepSeek，需要先安装 Ollama 软件。

Ollama 是一个专为本地便捷部署和运行大语言模型而设计的开源框架。它简化了大语言模型的部署流程，提供轻量且可扩展的架构，让研究人员、开发者和技术爱好者都能在本地环境中方便地运行和定制大语言模型。借助 Ollama，用户可在本地实现文本生成、翻译、问答、代码生成等功能，大幅扩展模型的应用范围。

Ollama 的特点如下：

- **预构建模型库。** 提供一系列预训练大语言模型的库，可直接用于应用，无需从头训练或自行寻找模型源。
- **API 支持。** 提供简洁 API，方便开发者创建、运行和管理大语言模型实例，降低交互门槛。
- **跨平台支持。** 支持 Windows、macOS、Linux 等操作系统，也可用于 Docker，确保多平台顺利部署。
- **自定义提示词。** 允许为模型添加或修改提示词，以引导生成特定类型或风格的内容。
