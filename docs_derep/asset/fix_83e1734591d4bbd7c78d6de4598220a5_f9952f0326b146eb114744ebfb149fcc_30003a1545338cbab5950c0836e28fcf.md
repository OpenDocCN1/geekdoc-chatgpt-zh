LoRA 驱动的 ChatGLM6B SPO 抽取实战

想让大模型快速具备结构化抽取能力，全量微调成本太高。下面的做法以 ChatGLM-6B 为底座，用 LoRA 做轻量适配，目标是对文本做 SPO 三元组抽取，整套流程可以在本地复现。

先把保存在本地的 6B 权重装进自研的 XiaohuaModel 包装里，再挂载预先保存好的 LoRA 配置，打印可训练参数量确认注入位置，随后把模型转成半精度并移到显存。任务提示被固定为要求模型按指定格式从输入文本中抽取信息，后面接文本占位。数据方面通过项目里的工具模块读取 spo_0.json，用同为 48 的输入输出上限进行编码，得到序列到序列格式的样本，并封装成数据集。

加载器每批处理两条样本，末尾不足一批直接舍弃，使用项目自带的合并函数，单进程读取。训练统一使用 Accelerate 管理设备与梯度，优化器选用 AdamW，初始学习率 2e-5，动量系数 0.9 与 0.999，epsilon 1e-5。学习率调度采用余弦退火，最大周期设为 2400 步，最低值压到 2e-6，从起始状态开始。模型、优化器、加载器、调度器一起交给加速器包装。

共跑 20 轮，每轮用进度条展示。每个小批先把输入 id 与标签搬到 GPU，再调用模型前向得到损失，由加速器完成反向传播，随后执行一次参数更新、一次学习率更新、一次梯度清零。进度条实时显示当前轮次、训练损失以及学习率乘以 1000 后的数值。每训练三轮就把当前权重写入 ./glm6b_peft.pth，便于中断恢复。

下面保留了前向函数的几种实现变体供对照。

def forward(self,input_ids,labels = None,position_ids = None,attention_mask = None):
    logits,hidden_states = self.glm_model.forward(input_ids=input_ids,position_ids = None,attention_mask = None)
    loss = None
    if labels != None:
        shift_logits = logits[:, :-1, :].contiguous()
        shift_labels = input_ids[:, 1:].contiguous()
        # Flatten the tokens
        logits_1 = shift_logits.view(-1, shift_logits.size(-1))
        logits_2 = shift_labels.view(-1)
        loss = self.loss_fct(logits_1, logits_2)
    return logits,hidden_states,loss
