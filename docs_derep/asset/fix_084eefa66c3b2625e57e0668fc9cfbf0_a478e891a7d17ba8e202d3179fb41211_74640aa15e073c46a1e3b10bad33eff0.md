# 第四章

**1．机器学习算法有哪 3 个基本类型？**

答 机器学习算法的三个基本类型如下，具体见 4.1.2 小节。

❶ **监督学习：** 利用已有标注数据训练。算法从输入特征与对应正确标签中学习，从而对未见数据进行预测或决策。常用于图像识别、语音识别等。

❷ **无监督学习：** 使用无标签数据。算法尝试发现数据的内在结构与模式，例如通过聚类对数据点分组。常用于市场细分、社交网络分析等。

❸ **强化学习：** 通过奖惩机制训练算法。智能体在与环境交互中学习最优行为策略以最大化累计奖励。常用于自动驾驶、机器人控制等。

**2．机器学习算法在社交媒体平台上有哪些应用？**

答 主要应用包括：

❶ **情感分析：** 通过分析文本或用户生成内容判断情感倾向。算法可自动识别正面、负面或中性情感，帮助企业把握用户反馈、追踪舆情与制定营销策略。

❷ **用户推荐：** 基于用户历史行为预测兴趣内容并推送。个性化推荐可提升满意度与留存。

❸ **智能客服：** 站内客服聊天常基于机器学习。系统自动解析用户输入，利用自然语言处理转化为结构化查询，并调用预训练模型给出答复或建议。
