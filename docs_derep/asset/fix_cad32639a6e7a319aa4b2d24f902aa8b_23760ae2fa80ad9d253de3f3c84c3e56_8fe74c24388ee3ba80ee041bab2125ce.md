# 深度解析：CNN 池化降维与 Softmax 机制，实战 MNIST 手写数字识别

完成卷积特征提取后，核心任务转为利用这些特征分类。理论上可将所有特征送入 Softmax 等分类器，但算力压力巨大。以 96×96 像素图为例，若习得 400 个 8×8 卷积核，单核输出 7921 维（(96-8+1)²），拼接后向量长达 316 万维。如此高维输入训练分类器不仅低效，极易过拟合。[PRE0]

根因在于卷积特征的“平稳性”：某区域有效的特征，别处往往也适用。故而对不同位置特征做区域汇总（均值或最大值），成为描述大图的自然思路。如图 4.4 所示，这类聚合操作即**池化**，分均值池化与最大池化。[PRE1]

若池化窗口取连续区域，且仅汇总同一隐藏单元的重复响应，输出即具**平移不变性**——图像微小位移，池化结果不变。物体检测、语音识别等任务中，我们常只关心特征“存不存在”，而非“像素级在哪”，此时该性质极具价值。如人脸判别，只需确认左眼在左、右眼在右，无需精确坐标。

TensorFlow 池化接口关键参数：[PRE2]
- `pool_size`：窗口大小，默认 `[2, 2]`。
- `strides`：滑动步长，默认 `[2, 2]`。
- `padding`：填充策略，`'VALID'` 或 `'SAME'`，输出保持 `[batch, height, width, channels]` 结构。

池化核心价值是赋予特征表示**近似不变性**。局部平移不变性让模型在确认特征存在性时，对微小位移免疫，显著增强鲁棒性。

### 4.1.4 Softmax 激活函数：把原始输出映为概率分布

Softmax 并不陌生，前文已用 NumPy 手写实现。其本质是将模型原始打分（Logits）转为概率分布——现实判断非黑即白，而是各类别概率和为 1。[PRE3]

前向计算常定为 `z = wᵀx + b`，偏置 `b` 注入适度噪声。Softmax 通过指数运算放大差异：`softmax(z)_i = exp(z_i) / Σexp(z_j)`。大数值对应高概率，小数值对应低概率，强制输出非负且归一化求和为 1，构成合法概率分布。最终模型形式 `y = softmax(wᵀx + b)`，结构如图 4.5。[PRE4] [PRE5]

矩阵化表达 `Y = softmax(XW + B)` 便于调用 TF 底层高效算子，大幅提速。

### 4.1.5 卷积神经网络（CNN）架构全景

CNN 本质是**二维离散卷积与神经网络的融合**，擅长自动提取图像特征。典型流程（图 4.7）含四大模块：[PRE6]
1. **输入层**：接收原始像素。
2. **卷积层**：多层堆叠，层层递进提取从边缘到语义的特征。
3. **池化层**：降维压缩特征图，保留关键信息，扩大感受野。
4. **全连接层**：基于压缩特征输出分类概率。

**卷积层：参数共享与局部感知**
卷积后图像分解为同尺寸局部块（图 4.8），各块经小型网络处理（图 4.9，即展平向量）。关键机制是**参数共享**：同一组滤波器全图滑动，对所有局部执行同一计算。[PRE7] [PRE8]

依据二：图像局部像素高度相关，易形成可检测模式；图像统计特性与位置无关，特征在一处存在则处处可现。数学上这正是离散卷积，CNN 因此得名。

**池化层：压缩与不变性强化**
以 `[2,2]` 窗口为例，可将特征图压缩至 1/4（图 4.10），大幅降参数量与计算量，同时强化平移不变性。[PRE9]

**全连接层：决策分类器**
池化输出展平接入全连接层（图 4.11），加权求概率最大值，完成分类。[PRE10]

**通俗类比**：CNN 如读报——卷积层“逐字识笔画”，池化层“段落提核心”，全连接层“通读定结论”。从边缘、结构、位置层层感知物体形态。

每样本含**图片特征 (x)** 与**标签 (y)**。图片展平为 28×28 矩阵（图 4.17），展开顺序任意但需统一。整体训练集形状 `[60000, 28, 28]`（图 4.18），像素归一化至 0~1。[PRE16] [PRE17] [PRE18] [PRE19] [PRE20]
