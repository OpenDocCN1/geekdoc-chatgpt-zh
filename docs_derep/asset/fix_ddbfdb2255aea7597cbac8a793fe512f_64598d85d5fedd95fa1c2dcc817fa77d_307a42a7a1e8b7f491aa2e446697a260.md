# 智能杠杆：法律工作的十倍提速手册

# 序Ⅰ
“法智觉醒，与你共建新秩序。”

这句话是我借助生成式模型写给读者的问候。

当生成式模型公开登场，法律圈的反应颇为复杂，既有惊奇也有戒备。

律师这个行当历史久远韧性强，对传统格外珍视，把保守视作守护秩序的姿态。像一座经历风雨仍规律报时的高楼，像一口沉静却记存万千变迁的深潭，工业浪潮来袭只让立法需求、交易结构、纠纷形态变得更繁复，为从业者提供了更多施展技艺的空间，并未动摇职业的根本根基。法律人的百年实践一直以纸笔、法典、法庭为线索，技术从未真正主导过价值观。

智能来了。

没有智能的旧图景已经终结。

它触动了从业者的精神内核，搅动了沉寂的水面，宣告一个全新阶段的开启。

它是吞噬行业的洪流，还是可被智慧驯服的工具？是通向衰亡的岔路，还是指向新一轮胜势的信号？会让生活更单调，还是让职业与家庭更厚实？是挤压还是托举？会削弱人的主体性，还是彰显人的价值？是技术定义人，还是人来定义技术？会抹去荣光，还是赋予新的高度？

这本书尝试给出回应。

从法律实践者的视角，本书审视智能带来的机遇与风险，展开了一场技术、法理、坚守、变革、理性与人性的对话。无论是好奇、震撼、憧憬，还是迷惑、焦虑、抗拒，都必须承认，智能的时代已经拉开帷幕，法律行业的渗透或将在十年甚至五年内遍及每个角落。谈论智能不是猎奇，而是关乎生存和发展。

合伙人、非合伙律师，以及律所的管理者，都应看到，智能正以罕见的广度与深度重塑实务，既改变职业属性，也改变商业属性。没有人能置身事外。它会把人从旧的安全区推出来，若能携手，它也能带人进入更高层的舒适地带。它并非律师的黄昏，而是可 24 小时不间断协作的伙伴，是新质生产力，是高质量发展的重要力量。

与智能结盟，是当下法律从业者的必然选择。拒绝合作，就是对抗时代，也是背离初心。

但盲目迷恋智能的能力等于玩火。现阶段的系统在数据处理与模式识别上很强，却缺乏真正的理解与创造，只能基于已有材料推演，难以做到类人的深度思考。伦理、隐私、安全等难题依然存在。对完美智能的执念，最终会像当年对基因技术的盲信一样幻灭。

可以说，智能绝非万能，但没有智能寸步难行。

这是一本不想在新时代被淘汰的从业者应该细读的材料。

它也为法学教育提出新的历史课题。当智能已深度介入实践之时，法学院还能独善其身吗？忽视智能的教育培养出来的只能是毕业即过时的从业者；拥抱智能的教育才能实现产品的差异化，从内卷走向重生。

# 序Ⅱ
法律科学的科学品格集中在法律理性，它是学科的技术内核，也是良法善治的关键。法律理性有科学的确定性，也有伦理的可检验性。进入二十一世纪，以人工智能为代表的技术革命高速迭代，既在书写科技史，也在书写人类史，而执笔者已不只人类，正如Alpha Zero能自行生成围棋谱系一样，新的历史图景将由人类与智能共同描绘。

面对技术浪潮，任何专业工作者都会焦虑，法律科学研究者也不例外。所幸法律科学因规范化的知识、体系化的路数与程式化的适用，比其他社会科学更接近自然科学。其实践留下的案例数据本身就是标准化的海量库，为科学检验提供了基础。因此在法律科学的运用中引入智能不仅可行，而且相当便利。

解决可能性后，下一个问题是：我们是否需要一个被智能武装的法律科学？不妨让智能自己作答。北京新橙科技有限公司在编写本书时，智能给出的概括是：

“这本关于法律AI产品运用的参考书，是应对智能时代挑战、把握发展机遇的重要指南。它系统论述了法律AI产品的职能与使用方式，并深入剖析了AI对审判、法学教育及整体法律体系的影响与挑战。法律AI依托大数据与机器学习的优势，能迅速精准解析案情，为法官提供智能化建议与决策辅助，大幅提升审判效率、减轻负担。在教学上，可通过模拟法庭、智能案例解析等创新手段，帮助学生理解法理、掌握技能、培养实践与创新能力。通过阅读，读者能更全面领略法律AI的潜力，掌握使用技巧，更好迎接挑战与机遇。”

智能的表述底气十足，但能否兑现，取决于人类在设计之初是否以法律理性奠定底层逻辑，是否明确告知智能必须遵循的知识、方法与价值。法律理性是知识、方法、价值的统一，条文、解释路径与条文所载价值是实施的首要依据，执法司法都必须体现法律理性，否则便缺乏正当性。在从决疑术到法律科学的长程中，法学家坚持科学法的进路，对纷繁的决疑体系进行系统化与类型化。十九世纪中后期，法律科学形成了形式主义理性化的知识体系，日益趋近理性法。AI作为科学智慧体，已具备相当的自主思辨能力，若在底座注入法律理性的构成，是否就能如法律工作者般具备法律理性？值得期待。对此智能也信心满满：

“让我们携手前行，以法律智慧为灯塔，照亮司法与教育的革新之路。在智能浪潮中共同书写法律事业新篇，为社会公正与和谐贡献智慧与力量！让我们共启法律智慧新纪元，迎接更美好的未来！”

拭目以待。

曹士兵
浙江大学国家制度研究院副院长
2024年11月11日

# 序Ⅲ
以人工智能、大数据、区块链为代表的新一轮科技革命席卷全球，深刻改变生产生活方式。传统行业必须拥抱变革，推进数字化智能化转型，才能在竞争中占据先机。

法律服务业同样面临转型升级的紧迫任务。人工智能正在重塑服务形态，带来前所未有的机遇与挑战。其一，智能合同审查、案件预测、法律咨询、司法辅助等应用展现出强大潜力，正在改写工作面貌。其二，智能化转型也困难重重。麦肯锡全球研究院预测，到2030年，全球约73%的工作将被AI替代或改变，法律领域的比例可能更高。如何在驾驭AI的同时引导其在法治轨道上规范发展，是每一位法律从业者必须面对的新课题。

本书的出版正是积极回应。本书系统解析AI在法律领域的创新应用，为法律人驾驭新技术、提升专业素养提供了全面指引。

本书有三方面特点。

第一，直面挑战拥抱未来。AI、大数据、区块链正深刻改变法律服务业态。法律人唯有保持开放心态，紧跟技术前沿，才能立于不败之地。本书为读者了解AI发展提供窗口，介绍基本概念、发展历程与典型应用，为智能法律服务奠基。同时围绕法律知识图谱构建、案例推理模型构建等前沿议题展开理论分析，对法学研究有启发，对推动服务模式变革有参考。

第二，学用结合知行合一。当前法律服务的智能化转型尚处于起步阶段。法律人在学习理论的同时，更要注重实践应用。本书在理论层面借鉴前沿成果，剖析智能体构建、检索增强生成等热点，揭示原理与路径；在实践层面紧扣实务痛点，提出系统性应用方案，涵盖文书分析、辅助决策、模型构建、场景应用全流程，并以案例详解，为实务工作者提供可操作的行动指南。

第三，立足当下放眼未来。AI在释放生产力的同时，也带来知识产权、数据安全、个人隐私、虚假信息等法律风险与伦理挑战。本书在介绍现状与场景的基础上，系统梳理相关法律问题，吸收国内外研究成果，总结各国立法实践经验，为立法与学术研究提供参考。

本书由一线研发人员、技术专家与法律人共同撰写，以真实需求为导向，将前沿科技与实务经验融合，用通俗语言呈现，价值显著。可预见，它将成为法律人认知、学习、运用AI的重要参考。

本书在描绘工作模式转型蓝图的同时，也对AI时代法治建设的诸多课题进行深入思考。AI进一步融入法律工作的各个环节，跨学科融合将成为大势，多学科交叉创新将开辟法学知识发现的新疆域。本团队持续关注AI法律问题研究，曾起草发布《人工智能法（示范法）》，并于2024年8月由中国社会科学出版社出版《〈人工智能示范法〉释义》，旨在为AI立法提供学理基础与实践样本，推动社会各界对AI法治的重视与讨论。

展望未来，愿更多同仁参与AI法律治理研究，共同推动法律服务高质量创新与AI法治高水平建设。

周辉
中国社会科学院法学研究所网络与信息法研究室副主任

# 序Ⅳ
我很早就认识iCourt团队，他们充满激情，专注于为法律人服务。2021年与iLaw合作开设数据合规与人工智能课程后，经引荐认识了张萌总，参加过一次关于法律服务行业迎接AI冲击的直播，认识了小武老师和周辉老师。那时了解到iCourt正在研发专为法律人服务的大模型，试用后印象深刻。2024年夏天，我组织的北京律师协会人工智能学习班上，邀请iCourt团队分享产品，得到了律师们的广泛好评。

因专业与客户需求，我很早接触AI。2018年的STM项目让我思考AI识别的法律问题及知识产权与数据合规；2019年的医疗AI项目让我惊叹其诊断治疗能力，并开始自学算法演进。2020年我主笔了《中国人工智能产业知识产权白皮书2020》中的相关章节。

随后，大语言模型与生成式人工智能时代到来，这在计算机应用领域是一次历史性突破。2022年出门问问IPO启动时，李志飞博士带来的硅谷消息令人难忘。

从我观察，变化已悄然开始。我个人阅读咨询机构长篇报告时，用生成式AI检索分析抓取要点并锁定重点；我的团队用各种生成式AI工具处理“体力活”，并横向比较优劣成为日常话题；国外同行已大量使用生成式AI进行证据归类、检索、标注，大幅提升效能并改变商业模式。

AI正在把重复低效工作从律师工作中剥离，推动律所数字化转型。

我现在正尝试用生成式AI改造团队知识体系，建立知识库并定向培养律师，让他们在信息爆炸时代能精准快速找到学习素材，为客户提供贴身服务。

# 前言
历史上每一次重大技术变革来临前，总伴随不同声音，但敢于拥抱变革、敢于创新的人往往成为时代引领者。

十八世纪末至十九世纪的工业革命以蒸汽机为标志，保守派担心机器取代人力导致失业与动荡。但敢于尝试的企业家利用蒸汽机提高效率，推动工业飞跃，创造新就业，带动繁荣。瓦特的蒸汽机因推动进步而被铭记。

二十世纪末至二十一世纪初互联网兴起，彻底改变生活方式。初期有人担忧隐私侵犯、传统行业冲击、监管削弱。但亚马逊、谷歌、阿里巴巴、腾讯、抖音、美团等积极拥抱互联网、创新商业模式、提升服务质量，不仅取得巨大成功，也推动行业转型，为社会创造价值。

今天，面对人工智能浪潮，法律服务行业该何去何从？2023年春，美国高盛公司估算不同行业就业岗位在美欧面临AI自动化取代的比重，法律职业位居第二高风险，约44%的任务可能被自动化。

这意味着未来一段时间，法律人和法律服务市场将承受巨大技术冲击。律师助理、实习律师的大量工作可能被机器取代，按时收费模式可能受挑战。入门门槛可能被AI抬高，传统金字塔层级可能被扁平化。过程或需数年甚至数十年，但不适应变化者将被无情淘汰。
