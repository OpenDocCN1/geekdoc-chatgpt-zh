**知识扩展**

“添加知识库”对话框中的“重排模型”用于优化搜索结果排序，“请求文档片段数量”用于平衡信息量与 token 消耗，通常保持默认即可。

token 是文本分词后的最小单元，可是一个词、词组或单个字符。AI 处理文本时会先切分为 token，再进行分析，token 数量也是计费依据，用量越多费用越高。
