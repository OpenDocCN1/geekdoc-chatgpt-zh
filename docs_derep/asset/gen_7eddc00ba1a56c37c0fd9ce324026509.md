## 核心网络结构一瞥

先看看模型头部分的关键实现。最后一层通过 1x1 卷积将特征图通道数调整为类别数，再配合 Sigmoid 激活输出逐像素的概率图，形状为 `[batch, num_ROIs, 2xMASK_POOL_SIZE, 2xMASK_POOL_SIZE, num_classes]`，这便是分割掩码的来源。

## 环境就绪，定制推理配置

克隆完仓库、装好依赖后，得先定义一个配置类。咱们这回是做推理，所以 `GPU_COUNT` 和 `IMAGES_PER_GPU` 都设为 1。继承自 COCO 预训练模型，类别数 `NUM_CLASSES` 固定写 81（含背景）。实例化配置并打印确认后，就可以初始化模型并加载官方权重 `mask_rcnn_coco.h5` 了。

[PRE2]python

class SimpleConfig(Config):

    # 设定名称

    NAME = "coco_inference"

    # 设定 GPU 个数，指定每张 GPU 运行的图像数

    GPU_COUNT = 1

    IMAGES_PER_GPU = 1

    # MS COCO 数据集的类别数

    NUM_CLASSES = 81

config = SimpleConfig()

config.display()

model = modellib.MaskRCNN(mode="inference", config=config, model_dir=os.getcwd())

model.load_weights("mask_rcnn_coco.h5", by_name=True)
