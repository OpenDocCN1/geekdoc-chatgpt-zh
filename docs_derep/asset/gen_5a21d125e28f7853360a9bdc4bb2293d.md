从这段实现来看，除了把业务接口全部挂载上，还要额外加上全局错误回调。通过一套统一的错误处理，可以在接口调用中实时捕捉异常并进行处理，对提升系统稳定性和用户体验很关键。

### 8.3.2 请求中间件开发

中间件是 HTTP 请求前后做预处理或后处理的组件，它不需要侵入核心业务，也能复用通用逻辑。只要接口涉及到统一的账号校验、参数清洗等场景，中间件就是最合适的方案。
