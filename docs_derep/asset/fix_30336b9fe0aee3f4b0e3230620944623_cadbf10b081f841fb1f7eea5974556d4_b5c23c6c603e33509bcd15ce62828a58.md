# 把个人写作习惯变成可复用模板

职场写东西时很多人会不自觉地把以前写过的同类材料当参照，把新内容往里面套。借助 AI 助手可以把这种习惯系统化，大致分两步：先把自己的表达特征拆出来，再把特征迁移到新主题上。

以周报为例，先找一份自己过往的周报让助手解析，指令可以是：“请帮我拆解这份文档，归纳出标题的层级写法、数据的呈现习惯、常用的过渡表达。”

助手返回的画像大致是：

1. 标题层级
- 一级标题偏好中文数字加顿号，例如“一、本周聚焦事项”，用于概括大块内容。
- 二级标题偏好括号加中文数字，例如“（一）客户访谈”，对一级进行细分。
- 三级标题偏好阿拉伯数字加点，例如“1. 资料整理与归档”，进一步展开具体工作。
- 整体遵循总分思路，层级靠缩进和换行区分，不用项目符号，仅靠数字体现逻辑。

2. 数据呈现方式（略）
3. 常用衔接词（略）

实际操作下来效果更直观。

拆解完就迁移。把本周要点输入：“按上面的风格帮我写周总结。内容有：①访谈了4家意向客户需求；②升级了数据报表样式；③配合了2次跨组会议。”

生成的文本会带上个人味道：

一、本周聚焦事项

（一）客户需求访谈

执行与记录
围绕业务目标，对4家核心客户开展需求调研，覆盖使用痛点、产品反馈及后续合作方向。线上沟通结合问卷收集了需求文档[×]份，梳理出关键点[×]条，为产品迭代提供依据（略）

（二）数据报表样式升级（略）
（三）跨组协同（略）

二、本周成果

客户访谈价值显现：精准锁定核心诉求，推动[×]项优化建议进入下季度开发排期（略）

三、问题与优化方向

访谈深度不足：部分反馈表述模糊，需增加二次确认环节（略）

其余省略，亲手试一遍感受最清晰。

### 2. 招式二：把初稿抬到汇报标准
助手输出的初稿通常需要二次打磨。譬如它写出“完成项目进度管理优化”，可以追加要求：“①凸显资源受限下的应对；②加入可量化的结果；③说明经验是否可迁移；④自然融入‘流程再造’‘效率提升’‘标准模型’等术语；⑤控制在120字以内。原文：完成项目进度管理优化。”

优化后会变成：“在人力紧张情况下，通过流程再造整合跨组协作节点，建立弹性资源池，使用率上升82%，并上线标准模型预警功能，关键里程碑准时率达95%。效率提升：周期压缩22%，人力开销下降15%。经验可迁移：模型适配多场景，工具包加培训已赋能12个项目，周期缩短18%至25%。”

### 3. 招式三：人工过手增添人味
不能照搬生成内容，必须结合实际手工调整。例如：①在成本段落加上“这笔波动很反常，跟财务组老张说的最新税规有关”；②把“流程优化建议”改为“采用了上月头脑风暴时小王提出的点子，审批明显加快”；③把书面语改为口语：“那款被吐槽像老年机的产品，靠短视频翻红了。”

## 4. 总结
最高效的人机配合是让成品难以分辨。机器负责结构化生产，人负责注入行业洞察与个人印记。就像手冲咖啡，七分靠豆子品质，也就是AI生产力，三分靠手法，也就是人工调味。

#### 试一试
给助手补充背景后输入：“我是一名[岗位]从业者，需要撰写2025年Q1总结，重点包含[3项核心成果][2个改进方向]，请给出结构建议。”

#### 小贴士
1. AI痕迹过重就不真实，建议建立禁用词库，像“赋能”“抓手”这类空词直接拉黑。
2. 正式文件预留约5%人工创作，用于插入临时事件或个人观察。
3. 保留1到2处口语，比如“这个结果确实没想到”更显真人。
4. 涉及业务机密的收尾段落务必手工撰写。

## 技巧15
## 用助手快速写出专业又吸睛的新闻稿

新闻稿要兼顾准确与吸引力，专业却不枯燥。时间紧、资料杂、要求高，改到最后容易审美疲劳。AI助手能帮忙整理信息、搭初稿、润表达。

### 1. 步骤一：快速提炼核心信息
新闻稿最怕重点不清。面对产品资料、会议纪要或访谈记录，直接让助手抽关键点。例如上传智能手环新品材料后提问：“这是智能手环新品发布材料，含技术参数、使用场景和竞争分析。请提炼核心，要求：①突出3个亮点；②每个亮点配真实使用场景；③少堆技术术语。”

助手可能给出：
1. 亮点一：超长续航，告别充电焦虑
   (1) 典型场景：商务人士出差三天不带充电器。
   (2) 技术支撑：新一代低功耗芯片，续航提升40%。
2. 亮点二：健康监测更精准
   (1) 典型场景：夜间睡眠质量分析误差低于同类。
   (2) 技术支撑：医疗级传感器加AI算法优化。
(其余略)

### 2. 步骤二：搭新闻稿初稿
产品发布、企业合作、峰会、获奖等，核心结构都离不开5W1H。整理完要点后，用通用问法：
请按以下信息写专业新闻稿：
1. 事件类型：[产品发布/战略合作/获奖/峰会/社会责任等]。
2. 核心信息5W1H：
   Who：[公司/机构/个人]。
   What：[一句话概括事件]。
   When：[具体日期或今日]。
   Where：[线上/线下地点]。
   Why：[行业或用户价值]。
   How：[技术/合作模式]。
3. 补充信息：[上一步提炼结果]。
4. 要求：按金字塔结构，标题→导语→核心→细节→背景；导语含5W1H，不超过100字；每段只讲一个信息点，不分点；避免形容词堆砌如“颠覆性”“革命性”。

示例提问后，助手可能输出类似：
××科技发布全球首款AI翻译手表
【2024年10月15日】今日，××科技线上全球直播发布全球首款AI翻译手表，搭载自研神经机器翻译引擎，可实现95种语言实时翻译，解决商务旅行沟通障碍。产品同时具备超长续航与精准健康监测。
该表采用新一代低功耗芯片，续航较同类提升40%。商务场景下，用户出差三天无需充电，摆脱电量焦虑。
健康监测依托医疗级传感器与AI算法优化，测试显示夜间睡眠质量分析误差明显低于主流产品。
××科技称，这是可穿戴与AI交叉的突破，随着全球化商务需求增长，实时翻译将成为智能硬件重要方向。

### 3. 步骤三：优化标题和导语
标题和导语决定阅读意愿。可以让助手改写，例如：“我们发布了AI翻译手表，现有标题××科技发布全球首款AI翻译手表，感觉平淡，请优化。补充信息：见前一步。要求：①加入数据或对比；②带点紧迫感；③专业不营销化。”

可能得到：
【商务效率版】“××科技发布全球首款AI翻译手表：72小时超长续航加医疗级健康监测，商务差旅终极方案。”
【技术突破版】“突破瓶颈！××科技AI翻译手表：续航提升40%加睡眠监测误差降低50%。”
【场景痛点版】“告别充电焦虑与健康误判：××科技AI翻译手表重新定义穿戴标准。”

## 4. 总结
写新闻稿靠“明确需求加结构化指令”。提炼、成稿、优化标题，提示越清晰输出越贴合。

#### 试一试
优化一段现有稿件，输入：“请把下面新闻片段改得更简洁有力（原稿：……）。要求：①删冗余形容词；②每句不超过20字；③加一个数据支撑。”

#### 小贴士
1. 不满意就让助手多出几个版本再挑。
2. 可加一句“请用《人民日报》风格改写”，模仿专业媒体口吻。
3. 助手生成的数据要二次核对，防错。

## 技巧16
## 项目报告：三招让助手快速生成大纲

项目报告难的不是内容，而是组织。没大纲数据就是碎片。反复调顺序、想逻辑很耗时间，整合多部门信息时统一格式更头疼。AI助手能按需生成清晰、严谨的大纲。

### 1. 招式一：需求定位—三步锁定核心
指令越模糊输出越通用。比如直接说“帮我写市场报告大纲”，只会得到模板。要当精准导航，需要“政策定位、市场定位、财务定位”三组坐标。试试：“请生成光伏储能站市场拓展报告大纲，要求：①最新政策分析（2023年文件）；②竞品对比（服务范围、价格策略、专利）；③财务测算（投资回报、风险），用标准章节层级格式。”

助手可能给出：
光伏储能站华东市场报告
一、政策指引
1.1 2023补贴新政（附财政部23号文要点）（略）
1.2 长三角站建设地图（略）
二、竞争对手擂台
2.1 头部企业PK（A公司vsB公司）……
(略)

### 2. 招式二：智能汇总—跨部门信息拼图
技术、用户、财务数据维度不同，手拼易错。用结构化指令让助手找业务逻辑：“你作为项目经理，整合：①技术部传感器测试数据；②市场部一线城市家庭画像；③财务部研发成本测算，按‘技术靠谱吗-市场买账吗-赚钱路径’排序。”

可能输出：
一、技术靠谱吗？—传感器可行性验证
1. 核心性能数据
   精度误差±0.5%（优于行业±1.2%）。
   极端环境-20℃~60℃正常运行。
   使用寿命实验室模拟5年无衰减。
   专利：3项核心发明已获批。
2. 技术风险预警
   量产良率88%需提至95%。
   多设备协同需追加蓝牙Mesh开发，增加2个月周期。
   电磁兼容需补测欧盟CE标准。
二、市场买账吗？—需求匹配度（略）
三、赚钱路径—财务模型测算（略)

### 3. 招式三：个性调优—读懂领导心思
不同领导风格需要不同呈现。可预设关键词让助手自动调整：“公司报告要求：①首页3条核心结论；②风险分析单独成章；③图表占版面不低于1/3，请按此优化跨境电商物流方案大纲。”

可能输出：
跨境电商物流方案优化大纲
一、首页核心结论页
1. “海外仓+边境仓”组合可降末端配送成本30%（配成本对比柱状图）。
2. 智能通关系统清关时间缩至48小时内（配时效折线图）。
3. 区块链溯源降低货物争议率30%（配流程图）。
(略)

## 4. 总结：从“文档民工”到“框架大师”
用助手列大纲就像用导航画路线。记住：需求越具体框架越准，信息越整合逻辑越顺，调优越智能返工越少。

#### 试一试
上传AI客服项目报告，输入：“生成AI客服升级报告大纲，需要：①新旧系统SWOT对比；②客户满意度目标（标注2024年数据）；③实施时间表框架。”

#### 小贴士
