这些核心文档相当于 OpenClaw 的大脑配置文件。把它们调准了，助手才会真正理解你的习惯，而不是停留在只会聊天的层面。全部是纯文本格式，想改就改、想备份就备份，掌控权始终在用户手里。

### 1.17 装不上？这些开箱即用的分支可以先试试

前面讲了一堆安装和调参步骤，看到黑底红字、改了配置还是报错，很多人直接放弃。除了原生版，社区和厂商已经做出了不少简化方案，安装被大幅压缩，有的甚至不用自己管服务器。它们的核心目标都是降门槛，让更多人能把龙虾养起来。

**Kimi Claw：网页端直接用**
Moonshot 把 OpenClaw 的能力搬到了网页，命名为 Kimi Claw。登录平台就能用，无需本地部署，手机电脑都能打开。注册后赠送 40GB 云存储，对话和文件自动同步，换设备登录即可接续。缺点是数据走 Moonshot 服务器，虽然做了加密，对隐私要求极高的人需要权衡。会员 199 元/月含 API 额度，比自建按量计费贵，但省下的折腾时间和稳定性对很多人来说更划算。入口是 platform.moonshot.ai。

**有道 LobsterAI：一键运行的桌面客户端**
网易有道的做法是提供 Windows 和 Mac 桌面版，下载安装包双击即可，操作感接近常规办公软件。对 DeepSeek、通义千问、智谱 GLM 等国产模型适配顺畅，沙箱机制比较完善，不会随意动用户文档。客户端本身免费，只需付模型 API 费用。下载页为 lobsterai.youdao.com，代码已开源在 GitHub netease-youdao/LobsterAI。

**ZeelinClaw：可挂本地模型的版本**
智灵动力推出的 ZeelinClaw 卖点是可以挂本地大模型。既能用预置模型，也能接入自下载的开源模型如千问 3.5 系列，实现零成本运行。最新版已上架 Mac、Windows 一键安装包。门槛在本地算力，建议至少 16GB 内存，跑 32B 级别模型最好 32GB。达标后基本不用担心 API 账单。获取方式扫本书封底二维码。

**MaxClaw：老机器也能流畅跑**
MiniMax 团队基于官方版做的轻量化分支。启动快、内存占用低，对国产模型友好，常用 Skill 的界面和提示词做了汉化。8GB 内存的老笔记本也能顺畅。更新频率不及官方，但国内日常场景够用。可在 GitHub 搜索 MiniMax OpenClaw fork，或通过 MiniMax 平台接入。

**WorkBuddy：腾讯免部署方案**
腾讯版零配置，下载即用。覆盖邮件处理、日程管理、项目协作等办公场景，企业用户还能做团队协作。上手极快，安装步骤几乎为零。地址 https://www.codebuddy.cn/work/。

**QClaw：微信遥控电脑 内测中**
基于 OpenClaw 的本地助手，支持通过微信对话远程操控电脑，如算报表、传文件。把桌面操作延伸到手机，适合想随时随地遥控的人。支持 Windows、Mac 一键安装，目前内测，申请方式和链接会变动，请关注官方通知。

**飞书妙搭：一句话完成部署**
字节飞书推出妙搭 × OpenClaw，号称全网最简一键部署。在妙搭对话框发一句话即可自动完成环境配置。预置群聊总结、文档修改、待办管理、会议纪要、周报生成等场景，并与飞书深度打通，@ 妙搭即可用。官方也提醒风险：ClawHub 曾出现恶意 Skills 窃取数据的案例，建议优先用飞书官方插件，遵循权限最小化和先审后用原则，避免明文存储密码等敏感信息。

**LanceDB-Claw：记忆增强版**
社区在原生版上集成 LanceDB 向量数据库的增强分支。记忆系统支持多 scope 隔离和语义检索，数月前的对话也能精准定位。适合长期跟进项目、资料累积多的用户。部署方式是先装原生版，再按文档加装 LanceDB 插件。

**怎么选**
原生 OpenClaw 扩展性最强、社区最活跃、隐私可控度最高，适合有技术基础、愿意折腾的人。想先快速体验，可以先用简化版跑起来，感受功能后再决定是否深入。核心原则一致：哪个能让你最快用上，就先用哪个，别卡在安装上。

### 1.18 不想 24 小时开机？把龙虾放到云上

本地运行的痛点是电脑必须一直开着。关机休眠后定时任务、消息推送全停。对笔记本用户尤其不现实。把 OpenClaw 搬到云端，租一台永远在线的机器，用手机或平板就能随时呼唤，这就是云养龙虾。

**扣子编程：新手试水的托管**
字节扣子编程平台提供 OpenClaw 一键托管。进入 code.coze.cn 点一键部署即可，无需买服务器或懂 Docker。默认配豆包 2.0 模型，免费额度够轻度使用，联网搜索、生图已搭好。缺点是定制能力弱，数据存于扣子服务器，隐私要求极高者慎用。对新手是零成本试错入口。

**阿里云：稳定省心的选择**
阿里云轻量应用服务器提供 OpenClaw 专属镜像，下单后系统自动完成安装，只需填模型 API Key。推荐配置 2 核 2G + 40GB 存储，新用户年付低至 68 元，月均不到 6 元。服务器费用不含模型，可搭配百炼 Coding Plan 首月 7.9 元获取 qwen3.5-plus 调用额度。搜索 OpenClaw 镜像一键购买即可。优势是国内访问延迟低，支持钉钉、飞书等企业通道。

**腾讯云：QQ、企微用户的首选**
腾讯云 Lighthouse 也有预装镜像，特别优化了 QQ、企业微信、飞书的接入。新用户可领 1-3 个月免费试用，反馈显示 QQ 机器人稳定性不错。同样提供 Coding Plan 首月 7.9 元，含混元 2.0、GLM-5、Kimi K2.5、MiniMax M2.5 等模型可切换。控制台搜索 Lighthouse OpenClaw 镜像。

**火山引擎：飞书重度用户专属**
火山引擎方案亮点是飞书深度集成。2 核 4G 配置活动价 9.9 元/月起，服务器加模型组合套餐 19.8 元/月。若工作日常在飞书，配置成本更低。还提供云手机部署方式，可在云端模拟移动端任务。

**云养虾怎么选**
服务器本身很便宜，真正的大头是模型 API 费用。平台差异不大，关键看模型套餐和调用频率。建议先用扣子免费体验，确认需求后再按预算选付费方案。

小结
到此第一章结束。跟到这一步，恭喜你的龙虾已经活了。
这一章你完成了安装、接入模型、连上飞书或企业微信、完成首次对话、教会它认识你、开启权限、装上几项实用 Skill，甚至学会写简单 Skill 和调核心文档。现在它不再是装完就闲置的工具，而是能干活的 AI 助手。
但这只是开始。第一章解决的是能不能用，后面要解决的是怎么用好。

三个提醒：
第一，OpenClaw 需要定期维护。养宠物要喂养清理，OpenClaw 也要定期执行 /new 清理会话、/compact 压缩记忆、更新版本、检查安全配置。第六章会细说，记住：变慢就 /compact，换主题就 /new，定期跑 openclaw doctor。
第二，安全大于便利。OpenClaw 权限很高，配置不当可能导致数据泄露或误删。工信部和国家互联网应急中心均提示：勿公网裸奔、勿随意装第三方 Skill、勿明文存密码、勿给过高权限。
第三，别想一口吃成胖子。从一个具体小需求开始，比如每天早上提醒日程，跑顺了再扩展。第二到五章会提供大量实操场景。
