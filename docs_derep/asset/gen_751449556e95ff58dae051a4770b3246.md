# 手搓一个负载均衡强化学习环境

想用 RL 来做任务调度，首先得有一个可训练的仿真环境。下面给出最简的起步依赖和一个自定义 Gym 环境的骨架，假设集群里有 N 台节点，每台都带 CPU 容量和排队逻辑，每来一个新任务智能体要挑一台节点放进去，环境以负的平均排队时延作为奖励，延时越小奖励越高。
