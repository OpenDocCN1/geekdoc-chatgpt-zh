要把机器学习的逻辑讲清楚，先从人类最本能的学习方式看起。夏天逛超市挑西瓜，大家基本都会上手看外观、敲一敲听声音。看主要判断外皮颜色和根部形态，敲则是听清浊。反复练习后，用这几招挑到甜瓜的命中率会越来越高。把这种经验积累抽象出来，就是下面这张西瓜数据表。

### 表 2.1 西瓜数据集

| 序号 | 色泽 | 根蒂 | 声响 | 是否好瓜 |
|---|---|---|---|---|

| 1 | 青绿 | 干缩 | 浊响 | 是 |
| 2 | 黑绿 | 干缩 | 浊响 | 是 |
| 3 | 青绿 | 硬挺 | 清脆 | 否 |

借助大脑不断归纳总结，我们会形成类似“某色泽+某根蒂+某声响=好瓜”的判断模型。人的归纳本质上是一个复杂且非线性的神经元学习网络。

机器怎么学呢？计算机只能处理数字信号，只能执行大于、小于、不等于这类确定规则，对感知、感觉等模糊信息无能为力。用一个极简的加法训练来演示：

- 问：1+4等于几？
- 答：20。
- 规则反馈：不对，多了。
- 问：1+9等于几？
- 答：13。
- 规则反馈：不对，多了。
- 问：3+4等于几？
- 答：7。
- 规则反馈：对了。
- 问：6+9等于几？
- 答：13。
- 规则反馈：不对，少了。

重复很多轮以后……
问：2+2等于几？
答：4。
问：4+5等于几？
答：9。

这就是机器学习最常见的情形，叫做有监督机器学习。“监督”指的正是训练过程中来自数据集的规则反馈。最开始的几次就是模型训练阶段，“多了”“少了”可以看成误差监督信号，模型据此调整自身参数，这就是反向传播 back propagation 的最直观解释。

综合上述例子和专业定义，可以这样理解：机器学习是实现人工智能的重要科学路径，核心在于让计算机算法通过数据自动归纳规律并不断提升表现。

## 2.1 机器学习概述

按样本是否带有标注，机器学习通常划分为有监督和无监督两大方向。有监督学习所需的数据集不仅包含特征，还必须附带每个样本的准确输出值，即标注。没有标注的数据集只能支撑无监督学习。比如仅收集股票的开盘价、收盘价、成交额、成交量、换手率，只能做无监督分析；如果再加上涨跌标签用于预测，就属于有监督场景。

### 2.1.1 有监督机器学习

有监督学习的输出可以是连续数值，也可以是离散类别，因此细分为回归问题 regression 和分类问题 classification。回归的因变量是数量型，分类的因变量是类别型。

### 2.1.3 半监督机器学习

有监督学习要求全部样本都标注，且标注质量直接决定效果；无监督学习虽免标注，却无法做预测。现实中样本量巨大时全量标注成本极高，常出现只有部分样本有标签、仍需做回归或分类的场景，这时半监督技术就很有用。图 2.4 所示为半监督机器学习示意图。

[PRE9]

图 2.4 半监督机器学习示意图

半监督机器学习是指学习器无需外界额外交互，自动利用未标注样本来提升学习性能的一类方法。sklearn.semi_supervised 包提供了基于标注传播 Label Propagation 的实现。下面以简单示例说明标注传播的使用。

[PRE10]python

import numpy as np

from sklearn import datasets

from sklearn.semi_supervised import label_propagation

rng=np.random.RandomState(0)

[PRE11]

iris=datasets.load_iris()

X=iris.data[:, :2]

y=iris.target

y_30=np.copy(y)

y_30[rng.rand(len(y))<0.3]=-1    # 去掉已有的标注(随机数小于 0.3 的索引)

y_50=np.copy(y)

y_50[rng.rand(len(y))<0.5]=-1    # 去掉已有的标注(随机数小于 0.5 的索引)

ls30=label_propagation.LabelSpreading(kernel='knn', alpha=0.8)

ls30.fit(X, y_30)                # 训练模型

ls50=label_propagation.LabelSpreading(kernel='knn', alpha=0.8)

ls50.fit(X, y_50)                # 训练模型

predicted_labels_ls30=ls30.transduction_    # 输出预测的标注

predicted_labels_ls50=ls50.transduction_    # 输出预测的标注
