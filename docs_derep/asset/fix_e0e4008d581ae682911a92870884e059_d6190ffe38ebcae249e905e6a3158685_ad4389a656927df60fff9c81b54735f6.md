### 4.1.2 逐步思考
我们知道 GPT-4 在计算方面表现一般。例如让它算 369 × 1235：
[PRE13]

模型给出的答案为 454 965，真实答案是 455 715。GPT-4 真的无法处理复杂数学吗？要理解这一点，需要记住模型是通过逐个预测 token 来生成完整答案的。它先生成最左边的数字，再把该数字作为上下文生成下一个数字，如此循环直到答案成形。难点在于，每个数字独立预测，与最终正确值无关。GPT-4 把数字当作标记，并不具备数学逻辑 1。

1 本章使用数学逻辑计算的示例来介绍思维链策略的有效性，但在面对复杂的数学计算类问题时，GPT 这类文本模型的可靠性难以通过提示工程技术得到保证。因此，建议结合函数调用和数学计算插件（如 Wolfram）来提高输出的准确性。——译者注

> [PRE14]　第 5 章将探讨 OpenAI 如何通过插件增强 GPT-4。一个例子是计算器插件，可用于进行精确的数学运算。

提升语言模型推理能力的一个常用办法是鼓励中间推演。比如要求计算 369 × 1235 时，模型倾向于直接给出结果。可即便是人类，没有纸笔也很难算出。因此，可通过指引让模型先进行中间推导。就像使用纸笔一样，只要给予足够推演时间，模型也能解决更复杂的问题。

在指引末尾加上“让我们逐步思考”这类表述，已被证实能让模型解决更复杂的推理问题。这种技术被称为零样本思维链策略，由 Takeshi Kojima 等人在 2022 年发表的论文“Large Language Models are Zero-Shot Reasoners”中提出。

思维链是指通过指引鼓励模型逐步模仿推理过程的技术。零样本意味着模型无需特定任务的示例就能进行推理，它凭借通用训练成果处理新任务。这与后面讨论的少样本学习不同，后者依赖示例来泛化。

如你将看到，给指引末尾加上逐步思考的引导语，比如示例中的“Let's think step by step”，模型会开始拆解问题。它需要一些时间进行推演，从而解决原本一次尝试无法解决的问题。具体效果：

> [PRE21]　少样本学习是 LLM 的一个强大特性，因为它让模型高度灵活、适应性强，只需有限的额外信息即可执行各种任务。

在指引中提供范例时，务必确保背景清晰且相关。清晰的范例有助于模型匹配所需输出格式并解决问题。反之，信息不足或模棱两可的范例可能导致意外或错误结果。因此，精心编写范例并确保其传达正确信息，对模型准确执行任务至关重要。

指导 LLM 的另一种方法是单样本学习。顾名思义，单样本学习只提供一则范例来帮助模型完成任务。指导量比少样本少，但在任务简单或模型已有丰富背景知识的主题上可能依然有效。单样本学习的优点是更简洁、生成更快、计算成本更低，进而 API 使用成本更低。然而，对于复杂任务或需要更深入理解所需结果的情况，少样本学习的效果通常更好。
