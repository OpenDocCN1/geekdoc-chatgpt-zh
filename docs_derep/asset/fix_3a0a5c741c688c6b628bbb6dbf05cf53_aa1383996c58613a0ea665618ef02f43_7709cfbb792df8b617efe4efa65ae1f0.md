张量的形状由维数以及每一维的大小构成，可用一个形状元组来描述。元组的长度等于维数，元组里的每个值对应该维的元素个数。例如形状为 3,4 的张量是二维的，第一维容纳 3 个元素，第二维容纳 4 个元素，总元素数为 12。数组维数与向量维数的含义不同：数组维数表示取出一个元素需要提供的下标个数，而向量维数表示向量本身包含的元素个数。于是 n 维向量常以形状为 n 的一维张量保存，m 行 n 列的矩阵则用形状为 m,n 的二维张量保存。

轮椅数据集
> 该数据集用于判断老年人或患者在轮椅上的坐姿是否正确。每个样本来自轮椅上 3 个压力传感器与 1 个超声波传感器，输入维度为 4。压力传感器的读数范围 0~1023，超声波传感器范围 0~15cm，分辨率 0.3cm。标签取 1 到 4 四个整数，1 表示坐姿正常，2 表示偏右，3 表示偏左，4 表示前倾。全部共有 308 个样本。

【实验1-1】对轮椅数据的输入向量做标准化并划分训练集与测试集
要点说明：
- 数据以 308 行 5 列的表格给出，每行对应一个样本，前 4 列为输入，后 1 列为标签，标签取值集合为 {1,2,3,4}。
- 随机抽取 200 个样本作为训练集，剩余 108 个作为测试集。
- 按列进行标准化 z_ij = (x_ij - μ_j)/σ_j，其中 μ_j、σ_j 为训练集中第 j 维的均值与标准差。
- 通过 import torch 引入框架。
- 用 torch.tensor 从已有数据复制构造张量，可用 dtype 与 device 设定类型与设备。
- 为后续运算方便，输入用浮点类型如 torch.float，标签用长整型如 torch.long，并把标签映射为 {0,1,2,3}。
- 均值与标准差可用 torch.mean 与 torch.std，计算矩阵各列时 dim 设 0，计算各行时 dim 设 1。
- 随机重排可用 torch.randperm，之前先用 torch.manual_seed 固定种子以保证可复现。
- 用 torch.cuda.is_available 判断 GPU 是否可用。
- 若后续在 GPU 上训练，需把数据集搬到显存，可用张量的 to 方法完成。
遇到困难可参考附录 A 的注释程序。

首次在 GPU 上运行 PyTorch，启动时间会偏长，因为框架会对函数进行即时 JIT 编译。

【实验1-2】用 PyTorch 搭建单隐含层多分类网络
要点说明：
- 隐含层设为 8 个神经元，采用 ReLU 作为激活；输出层 4 个神经元，不加激活。
- 网络可直接用 torch.nn.Sequential 拼装，也可继承 torch.nn.Module 自定义，本书采用继承方式以获得更大灵活性。
- 在 __init__ 中创建并初始化各层参数，在 forward 中实现前向计算，反向由框架自动完成。
- 仿射变换用 torch.nn.Linear，激活用 torch.nn.functional.relu。
- Linear 的权重与偏置默认采用均匀分布初始化，通常无需手动干预。
- Linear 的 in_features 对应输入最后一维大小，out_features 对应输出最后一维大小。
- 使用 GPU 时需把模型对象同样迁移至显存，用 to 方法即可。
实现参考附录 A。

【实验1-3】用轮椅数据在 PyTorch 上训练上述网络
要点说明：
- 采用批梯度下降，即每次用全部训练样本更新参数；优化器选用默认的 AdamW，通过 zero_grad 与 step 调用。
- 多分类任务常用交叉熵损失，用 torch.nn.CrossEntropyLoss 计算。注意其输入应为输出层仿射结果而非经过 softmax 的结果，这也是输出层不加激活的原因；目标值需为 torch.long 类型，取值 0 到 c-1，与实验 1-1 的标签映射一致。
- 学习率取 0.1，训练轮次取 60。
- 迭代顺序为：前向 → 计算损失 → backward → optimizer.step。每次 backward 前必须执行 optimizer.zero_grad 清零梯度，否则梯度会累加。
- 建议调用模型对象而非直接调用 forward，以便触发已注册的钩子。
- 批训练时输入为 200×4 的二维张量。
- 记录每次迭代的损失以便绘图，保存时需从计算图分离，可用 item 或 detach。
- 绘图可用 Matplotlib。
