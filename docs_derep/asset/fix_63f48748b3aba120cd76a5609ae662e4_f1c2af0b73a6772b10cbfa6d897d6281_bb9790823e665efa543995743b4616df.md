朱自清：诗性笔端里的家国情怀

1898年11月22日至1948年8月12日，朱自清的一生横跨中国近现代动荡的半个世纪。本名为朱自华，成年后更名自清，字佩弦，别号实秋。祖籍浙江绍兴，出生于江苏东海县平明镇，后随父亲迁居扬州。他既是新诗与现代散文的实践者，也是古典文学的研究者，更以坚定的民主立场参与社会。

1916年中学毕业后进入北京大学预科学习，1919年起在刊物上发表诗歌。1921年加入文学研究会，投身“为人生”的创作主张。1922年与叶圣陶等共同创办新文学史上首份诗刊《诗》月刊，推动新诗发展。次年长诗《毁灭》出版，引起诗坛注意，随后写下《桨声灯影里的秦淮河》，以白话呈现写景美文的艺术，被誉为白话美文的范例。1924年诗文合集《踪迹》问世。1925年受聘清华大学中文系执教，写作重心逐步从诗歌转向散文，同时持续研究古典文献。

社会关切贯穿他的学术生涯。1926年“三·一八”惨案后，他撰写《执政府大屠杀记》等文章，抨击军阀政府的暴行。1928年散文集《背影》推出，成为现代散文的经典文本。1930年暂任清华中文系主任，次年赴英国留学并漫游欧洲多国，著有《欧游杂记》《伦敦杂记》。1932年回国后重返清华，担任中文系教授并兼任系主任。1935年“一二·九”运动中，他与学生一起走上街头示威。抗战爆发后随校西迁，在国立西南联合大学任教。1946年10月返回北平，受校方委托主编《闻一多全集》，并积极参与各项民主活动。1948年8月12日因胃穿孔在北平病逝，年仅五十岁。《背影》《荷塘月色》等篇章与后来的《朱自清全集》，奠定了中国现代散文早期的风貌。

from typing import List

from langchain_core.pydantic_v1 import BaseModel, Field

class HypotheticalQuestions(BaseModel):

    """生成假设的问题"""

    questions: List[str] = Field(..., description="List of questions")

chain = (

    {"doc": lambda x: x.page_content}

    | ChatPromptTemplate.from_template(

        "生成一个列表，其中包含5个可以用下边文档回答的问题:\n\n{doc}"

    )

    | ChatOpenAI(max_retries=0, model="gpt-4o-mini", temperature=0).with_structured_output(

        HypotheticalQuestions

    )

    | (lambda x: x.questions)

)
