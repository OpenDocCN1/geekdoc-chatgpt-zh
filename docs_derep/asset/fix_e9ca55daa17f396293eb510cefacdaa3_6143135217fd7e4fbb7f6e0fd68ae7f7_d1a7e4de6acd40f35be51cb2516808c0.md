### 10.2.1 本地知识库搭建七步走

下面是可落地的完整路径。

#### 1．需求分析与场景定义

#### 2．技术架构设计
硬件层面关注 CPU 多核并行能力、是否需要 GPU 训练、存储选 SSD/HDD 并搭配 RAID。网络层面要保证局域网带宽和防火墙策略，保障内网安全访问。
软件层面，操作系统多为 Linux CentOS Ubuntu 或 Windows Server；检索存储常用 Elasticsearch Solr 做文本检索，Neo4j 做图谱；框架可参考 Haystack LangChain 等开源方案，按需选开源或商业。

#### 3．数据准备与处理

#### 4．框架部署与模型训练
以开源为例，先部署 Elasticsearch 集群并配置 IK 分词器，再部署 Haystack 搭建检索加生成的流水线：用户提问→召回相关文档→大模型生成回答。

#### 5．系统集成与测试

#### 6．部署与上线
先在测试环境试运行收集反馈，再逐步推向生产。数据迁移建议增量同步，避免业务中断。上线时配置管理员普通用户等角色权限，并记录访问日志以便追溯合规。
