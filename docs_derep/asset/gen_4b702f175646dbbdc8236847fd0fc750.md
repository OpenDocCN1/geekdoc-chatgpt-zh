### 1. RDF 简介

在 RDF 中，知识始终以三元组呈现。每一条知识都可以拆分为 主语、谓语、宾语 三个部分。例如，“IBM 邀请 Jeff Pan 作为讲者，主题为知识图谱”可表示为 (IBM-Talk, speaker, Jeff) 与 (IBM-Talk, theme, KG)。RDF 的主语为个体，个体是类的实例；谓语为属性，可连接两个个体，也可连接个体与数据类型实例。于是宾语可以是个体，如 (IBM-Talk, speaker, Jeff)，也可以是数据类型实例，如 (IBM-Talk, talkDate, "05-10-2012" ^xsd:date)。

若把三元组的主语与宾语视作图节点，谓语视作边，则整个 RDF 知识库即形成一张图或知识图谱，如图 2-6 所示，三元组是图的构成单元。

## 2.3.2 OWL 和 OWL2 Fragments

RDF 与 RDFS 已能表达部分语义，但在复杂场景下表达力不足，主要缺失体现在：

-   (1) 属性的局部值域定义。RDF(S) 的 rdfs:range 仅提供全局值域，无法针对特定类给出属性的特殊限制，例如无法声明父母至少有一个孩子。
-   (2) 类、属性、个体的等价性。RDF(S) 无法声明多个类、属性或个体等价或不等价，例如无法断言 Tim-Berns Lee 与 T.B.Lee 为同一人。
-   (3) 不相交类的定义。RDF(S) 只能表达子类关系，无法声明男人与女人互不相交。
-   (4) 基数约束。对属性取值数量的限制无法表达，例如一个人有两个父母，一门课至少有一名教师等。
-   (5) 属性特性的描述。无法声明传递性、函数性、对称性，或属性间的逆属性关系，如大于的逆关系是小于。

为提升本体表达能力，W3C 提出 OWL 在 RDF(S) 基础上扩展，作为语义网表示本体的推荐语言。W3C 于 2002 年 7 月 31 日发布 OWL Web 本体语言工作草案。

选择原则如下：

-   - OWL Lite 与 OWL DL 的选择取决于用户对约束可表达性的需求程度；
-   选择 OWL DL 与 OWL Full 主要取决于是否需要 RDF 的元模型机制，如为类型定义类型并赋予属性；
-   使用 OWL Full 而非 OWL DL 时，推理支持可能受限，因目前尚无完全支持 OWL Full 的系统实现。

OWL 子语言与 RDF 的关系为：OWL Full 可视为 RDF 的扩展；OWL Lite 与 OWL Full 可视为对 RDF 的约束化扩展；所有 OWL 文档 Lite、DL、Full 都是 RDF 文档，所有 RDF 文档都是 OWL Full 文档；只有部分 RDF 文档才是合法的 OWL Lite 与 OWL DL 文档。

## 2. OWL 的重要词汇

(1) 等价性声明。声明两个类、属性和实例等价。如：

exp:运动员 owl:equivalentClass exp:体育选手

exp:获得 owl:equivalentProperty exp:取得

exp:运动员 A owl:sameIndividualAs exp:小明

上述三元组分别声明类、属性、个体等价，exp 为命名空间 http://www.example.org 的别称，用以避免命名冲突。

(2) 属性传递性声明。声明属性为传递关系。例如，exp:ancestor rdf:type owl:TransitiveProperty 表示 exp:ancestor 为传递关系，可由 a exp:ancestor b 与 b exp:ancestor c 推导出 a exp:ancestor c。

(3) 属性互逆声明。声明两个属性互逆。例如，exp:ancestor owl:inverseOf exp:descendant 表示二者互逆，可由 exp:小明 exp:ancestor exp:小林 推导出 exp:小林 exp:descendant exp:小明。

(4) 属性函数性声明。声明属性为函数。例如，exp:hasMother rdf:type owl:FunctionalProperty 表示一个生物只有一个母亲。

(5) 属性对称性声明。声明属性对称。例如 exp:friend rdf:type owl:SymmetricProperty 表示若 exp:小明 exp:friend exp:小林，则反之亦成立。

(6) 属性全称限定声明。声明属性取值范围的全称限制。例如：

exp:Person owl:allValuesFrom exp:Women

exp:Person owl:onProperty exp:hasMother

表示在主语属于 Person 类时，hasMother 的宾语只能来自 Women 类。

## 3. OWL 版本

目前 OWL2 为最新版本，旧版常称为 OWL1。OWL2 定义了多个子语言以便实现与应用，三个主要子语言为 OWL2 RL、OWL2 QL 与 OWL2 EL。

OWL 2 QL 为最简形式，QL 代表 Query Language，专为基于本体的查询设计，查询复杂度为 AC⁰，适合大规模处理，基于描述逻辑 DL-Lite。表2-6 给出 OWL 2 QL 核心词汇。

| 允许的核心词汇       | 对应的描述逻辑公理举例                     |

|----------------------|--------------------------------------------|

| rdfs:subClassOf      | Mother ⊑ Person                            |

| rdfs:subPropertyOf    | hasSon ⊑ hasChild                          |

| rdfs:domain          | ∃hasSon.T⊑ Person                         |

| rdfs:range           | T⊑ ∀hasSon.Person                         |

| owl:inverseOf        | hasChild⫤hasParent                        |

| owl:disjointWith     | Women ⬜ Man ⊑ ⊥                           |

OWL2 EL 专用于概念术语描述与本体分类推理，在生物医疗领域应用广泛，如 SNOMED CT。分类复杂度为 Ptime-Complete，基于描述逻辑 EL++。表2-7 给出 OWL2 EL 核心词汇。
