在全球层面，各国对人工智能的立法与监管动作越来越快，相关法律与规范层出不穷。但仅靠规则和监管，难以覆盖人工智能带来的全方位安全风险，匹配的治理能力仍有待补强。正是在这种背景下，可信人工智能治理被推到全球议程的核心，它直接关乎技术创新的推进、法治体系的完善以及国家安全的可控。

可信正逐步成为各国发展人工智能的共识性原则。大量全球性的自律标准与文件，都把“可信人工智能”作为明确要求。欧盟委员会的《可信人工智能伦理指南》、以及《G20 人工智能原则》《人工智能安全治理框架》等，都聚焦于技术稳健与安全、系统透明度、非歧视与公平，以及可问责性等关键维度。在此基础上，安永（中国）企业咨询有限公司和上海市人工智能与社会发展研究会于 2025 年联合发布的《可信人工智能治理白皮书》将“可信人工智能”界定为：设计、开发与部署环节技术可靠、安全，能够产出无歧视无偏见的公正结果，原理与运行过程透明，可问责且以人为本的人工智能系统。

要实现安全可信的大模型，需要覆盖大模型运行的基础环境防护、数据安全防护、模型安全防护、应用安全防护、实时监控与安全运营、合规保障等多个层面。

#### 1. 运行基础环境防护

大模型的运行环境需构建基于可信计算技术的自主免疫防御体系。可信计算的核心是边算边防，全程可测可控不被干扰，使结果始终与预期一致。首先在系统与硬件层面，通过双体系可信计算架构为大模型提供安全执行环境，以可信密码模块 Trusted Code Module，TCM 为支撑，依托可信平台控制模块 Trusted Platform Control Module，TPCM 构建可信链，实现可信启动，确保从硬件初始化到操作系统加载的完整生命周期可信状态验证，抵御供应链攻击和固件级恶意代码注入。其次在软件层面，基于可信软件基 Trusted Software Base，TSB 为模型程序与文件提供可信度量与管控，阻断未授权访问与篡改，有效避免模型被恶意篡改。通过可信计算的访问控制，未授权软件与代码无法运行，防止漏洞被利用，阻断恶意软件植入与扩散，保证系统运行运维全过程可控可管。再者网络架构上，通过可信连接把可信计算节点串联成完整可信网络，部署可信计算技术网络防护设备，综合边界隔离、访问控制、传输加密、可信接入、入侵检测与防御，形成纵深防御，可有效防范中间人攻击、网络渗透、高级持续性威胁 APT 等。最后针对承载大模型的云基础设施，以 TPCM 为信任根构建信任链，结合虚拟化信任链扩展技术，完成从物理主机到虚拟化层、虚拟机、容器、大模型组件的逐级度量验证，确保云环境下大模型相关软硬件启动与运行状态安全完善的可信度量、报告与验证机制，保障云端服务安全。

#### 2. 数据安全防护

大模型的数据安全既涉及训练阶段采集不当、偏见或标签错误、数据投毒，也涉及应用阶段的数据泄露、隐私暴露，需要建立完整的数据安全全生命周期管理制度。首先建立智能数据分级分类机制，利用自然语言处理 Natural Language Processing，NLP 技术自动识别敏感信息，对个人可识别信息 Personally Identifiable Information，PII、涉及商业机密的生产工艺数据实施动态脱敏，对不同敏感度数据采取差异化保护。其次运用联邦学习、差分隐私等技术实现敏感数据高效防护，如在可信执行环境中开展多方数据协同计算，通过差分隐私添加高斯噪声，构建从硬件到应用的多层次安全架构，全方位确保工业大模型训练与推理可靠。再者建立严格的数据访问控制策略，按用户角色与业务需求精细管控访问权限，例如生产线工人仅能访问与自身操作相关的生产数据，而数据分析人员只能访问脱敏后的汇总数据用于训练分析，防止非法获取与滥用。然后实施全流程数据加密，知识库与模型数据在发布、安装、存储全程加密，仅在指定可信根设备中解密加载，确保使用范围可控。模型数据传输采用安全传输协议，如安全套接层/传输层安全 SSL/TLS 协议。最后建立数据泄露检测与响应机制，及时发现与处置安全事件。

#### 3. 模型安全防护

针对模型自身脆弱性，需构建多层级动态防御机制。首先在鲁棒性增强方面，通过模拟提示注入攻击场景和对抗样本，让算法从数据中学习相关特征以提升鲁棒性。模型实时运行时，可借助可信执行环境实现模型参数动态解密运算，结合神经元激活模式分析技术，实时识别后门攻击或模型篡改行为。其次在可解释性方面，开发能解释 DeepSeek 大模型决策过程与结果的工具与方法。例如通过可视化技术展示模型处理数据时的内部特征提取与决策逻辑，帮助工业用户理解输出，提升信任度。再者构建多层级事实性约束机制以缓解“幻觉”问题，训练阶段融合知识增强技术，引入结构化知识图谱与可信知识库，建立实体关系验证模块，强制模型输出与已验证知识形成逻辑关联。推理过程中部署实时事实核查系统，结合检索增强生成 Retrieval Augmented Generation，RAG 技术，对生成内容的关键事实点进行动态检索验证，并基于注意力重加权机制修正潜在矛盾表述。最后缓解训练与推理阶段的偏见，训练阶段通过优化训练过程与模型结构进行偏见缓解；推理阶段基于预训练或微调后的模型，在不进行进一步微调的前提下控制偏见内容输出，提升公平性。

#### 4. 应用安全防护

应用层面要重点关注 API 安全与提示词注入防护。首先 API 网关实施请求签名验证与流量整形，防范分布式拒绝服务 Distributed Denial of Service，DDoS 攻击与非法调用，针对 API 调用建立行为基线模型，通过异常参数检测触发熔断保护机制。其次基于 AI 大模型应用防火墙等系统，在应用接入层构建智能安全围栏，部署多模态内容过滤引擎，建立输入验证与输出过滤机制，集成规则引擎与深度学习模型，对文本、图像输出进行双重合规审查，防止恶意提示词攻击。在关键应用场景，建立专家复核机制，对 AI 操作建议实施人工核验，构建人机协同的安全屏障。再者建立细粒度访问控制策略，例如模型管理员拥有训练、部署、调整等高级权限，而普通生产用户仅能进行推理查询，通过此方式严格限制访问，防止未授权使用与滥用，并基于用户行为基线动态调整权限，实现最小特权原则自动化实施。然后实施应用级安全监控，对所有访问大模型的操作进行详细审计与日志记录，记录分析异常访问行为，定期分析审计日志总结访问模式，发现潜在安全风险并采取防范措施。最后定期开展应用安全测试，及时发现修复漏洞，基于可信数据验证与模型自我检测修复机制，实时识别并自动修正异常行为，保障输出准确可信。

#### 5. 实时监控和安全运营

针对 AI 大模型系统运行保障，需建立统一的实时监控与安全运营体系。首先组建专门的 AI 安全运营团队，负责日常安全监控与响应，定期开展 AI 安全培训提升意识与技能，建立安全知识库沉淀经验与最佳实践，并定期评估安全建设成效持续优化安全措施。其次对模型性能与安全指标进行实时监测。建立实时监控系统，对 DeepSeek 大模型的性能与安全指标进行全方位监测，及时发现性能下降或异常波动，排查是否由安全问题导致运行异常，通过设定阈值，当指标超出正常范围时及时报警。再者建立安全事件检测、预警与应急响应机制。建立安全事件预警模型，当监测到异常行为或潜在安全威胁时系统及时发出预警通知安全运维人员，同时制定完善的安全事件响应预案，明确不同类型事件处理流程与责任分工，定期开展应急演练。然后建立安全漏洞管理流程，定期对 DeepSeek 大模型及其运行环境进行安全扫描，及时发现潜在漏洞，按严重程度分类，制定优先级修复计划，确保漏洞得到及时有效修复。最后进行安全策略持续优化与更新，定期评估安全措施有效性，随着工业智能制造环境变化与威胁演变，持续优化更新安全策略。

## 4.1 装备制造行业的特征

装备制造业是我国工业的主体，是现代化产业体系的根基。推动其转型升级，是适应并引领新一轮科技革命与产业变革的战略选择，是提升产业链供应链韧性与安全水平的重要举措，也是推进新型工业化、加快制造强国建设的必然要求，关乎现代化产业体系全局。国务院常务会议强调，要以人工智能与制造业深度融合为主线，以智能制造为主攻方向，以场景应用为牵引，加快重点行业智能升级，大力发展智能产品，高水平赋能工业制造体系，加快形成新质生产力，为制造强国、网络强国和数字中国建设提供支撑。目前国内制造业企业正加速推进设备、产线、车间与工厂的数字化、网络化、智能化升级，从根本上变革生产方式与资源组织模式。在多种因素推动下，制造企业加快转型，工厂正向高效化、智能化、绿色化跃迁。装备制造行业特征主要有：

- 1）技术密集型：涉及多学科多领域高精尖技术，研发与生产需大量专业知识与技术人员。
- 2）资金密集型：需大量资金投入研发、设备购置与生产设施建设，研发周期长、投资回收慢，但规模形成后经济效益显著。
- 3）劳动密集型：尽管技术含量高，但生产过程复杂，涉及大量定制化设计、采购、装配等工作，仍需大量人力参与。
- 4）产业链长且复杂：涵盖原材料加工到产品组装、销售与服务，涉及众多上下游企业，产业链协同至关重要。
- 5）高附加值与定制化需求：产品通常附加值高，用户定制化需求强，企业需具备快速响应与灵活调整能力。

## 4.2 DeepSeek 在生产过程场景的应用路径

### 4.2.1 关键数据

生产场景涉及大量数据，如设备运行数据、生产工艺数据、产品质量数据以及原材料数据，这些数据是实现生产优化的基础。

#### 1. 设备运行数据

设备运行数据包括通过传感器实时采集的温度、压力、转速、振动等运行参数，反映设备实时状态，例如温度异常升高可能预示故障，影响生产连续性。对其长期监测与分析有助于提前发现潜在问题，保障设备稳定运行。

#### 2. 生产工艺数据

生产工艺数据涵盖加工时间、速度、电流等各项工艺参数。不同产品工艺数据差异较大，精准控制对保证产品质量至关重要。

#### 3. 产品质量数据

产品质量数据包括尺寸精度、外观缺陷、性能指标等与质量相关数据。通过实时采集与分析，可及时发现质量问题并追溯至生产环节，以便快速调整参数或工艺，减少次品率。

#### 4. 原材料数据

原材料数据记录批次信息、材质特性、供应商等。原材料质量波动会影响产品质量，如不同批次钢材硬度差异可能导致加工后产品强度不一致。

### 4.2.2 技术路线

DeepSeek 大模型利用动态资源调配技术与 MoE 架构，实现对生产线实时数据的毫秒级响应与高并发处理。通过物联网边缘计算设备快速采集设备运行各类数据并传输至大模型分析，同时结合视觉检测技术，利用多模态处理能力对产品外观进行质量检测。

#### 1. 数据采集与传输

构建全面物联网数据采集系统，将生产设备、检测仪器等连接起来，实现各类数据实时采集。采用边缘计算技术在靠近数据源的设备端对原始数据进行初步处理与筛选，减少传输量，提高处理效率。

#### 2. 生产过程建模与优化

利用 DeepSeek 的深度学习算法，对设备运行数据、生产工艺数据、产品质量数据与原材料数据进行深度分析，构建生产过程模型。该模型可模拟各因素间复杂关系，通过优化寻找最优工艺参数组合与设备运行状态设置。

#### 3. 实时监控与预警

基于构建的生产过程模型，对生产过程进行实时监控。当监测到工艺数据偏离正常范围，可能影响质量或导致设备故障时及时发出预警。例如，设备运行数据显示关键部件振动异常，系统立即向操作人员与管理人员发送预警，提示设备存在故障风险，以便及时维护。

### 4.2.3 训练过程

收集大量历史生产工艺数据，包括正常与异常生产状态数据。对数据进行清洗、标注，将设备运行数据、生产工艺数据与产品质量数据关联标注。使用标注好数据对 DeepSeek 大模型进行训练，让模型学习正常生产模式特征，以及异常情况与数据变化关系，从而建立生产过程预测模型。

#### 1. 数据收集与整理

收集企业长时间内生产过程数据，包括不同产品型号、不同生产批次数据。对数据清洗去除错误、重复或不完整记录。按设备类型、生产工艺、产品类别等维度分类整理，为后续标注与训练做准备。

#### 2. 数据标注与特征提取

对产品质量数据进行详细标注，明确每个产品质量状态合格、不合格及具体缺陷类型，以及对应的生产工艺数据与设备运行数据。从设备运行数据、生产工艺数据中提取关键特征，如变化趋势、波动范围等。对于原材料数据，提取与产品质量相关的特征，如材质关键性能指标等。

#### 3. 模型训练与优化

将标注数据与提取特征输入 DeepSeek 大模型训练。训练过程中不断调整模型参数，如神经网络层数、节点数、学习率等，以提高模型模拟准确性与预测能力。采用交叉验证等方法评估与优化模型，确保其能准确根据输入数据预测产品质量，并为生产优化提供可靠建议。

### 4.2.4 应用效果

##### 1. 提高生产效率

某机械制造企业应用 DeepSeek 优化生产过程后，生产效率大幅提升。通过优化工艺参数与设备运行状态，缩短设备平均生产节拍，增加单位时间产品产量。

## 4.3 DeepSeek 在生产排产场景的应用路径

### 4.3.1 关键数据

生产排产场景涵盖各类生产要素工业基准数据集与领域知识集，包括订单数据、设备数据、物料数据、人力资源数据等，通过深度挖掘分析，可准确了解各环节瓶颈与优化空间，为智能排产提供数据基础。

订单数据是排产起点，包括订单数量、产品型号、交货日期等，决定生产目标与需求，不同订单优先级与紧急程度差异会对排产计划产生重大影响。例如加急订单需优先安排生产资源以确保按时交付。

#### 2. 设备数据

设备的类型、数量、运行状态、产能以及维护计划等数据不可或缺。各类设备生产能力不同，运行状态直接影响可用性，维护计划需提前考虑，避免高峰期维护导致生产中断。

#### 3. 物料数据

物料库存数量、采购周期、批次信息以及物料配套关系等数据对排产极为关键。若关键物料库存不足且采购周期较长，可能需要调整生产计划，优先生产其他不受物料制约的产品。

#### 4. 人力资源数据

员工数量、技能水平、工作时间安排等人力资源数据也是排产重要依据。熟练工人与新手生产效率存在差异，某些复杂产品生产环节需特定技能工人操作。合理安排工作时间与班次可充分利用人力资源，提高整体效率。

### 4.3.2 技术路线

利用基于 DeepSeek 的工业大模型的强大计算能力与深度学习算法，对数据进行分析处理，形成适用于生产制造的高精度工业数据生成技术。该技术不仅可生成工业知识、时序数据、机器指令、生产工艺与仿真结果等多类工业内容，还能够通过对历史数据的分析，预测未来生产过程中可能出现的各类问题，从而使企业可提前采取应对措施。
