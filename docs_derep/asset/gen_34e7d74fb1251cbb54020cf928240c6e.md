# 二、国产大模型对比

我们向上述模型抛出同一个“一词多义”问题：“冬天：能穿多少穿多少；夏天：能穿多少穿多少。这句话中的‘多少’分别是什么意思？”看它们的回答有何差异。

# (一)百度文心一言

冬天：能穿多少穿多少；夏天：能穿多少穿多少。

这句话中“多少”的意思是“尽可能多的数量”。

+   - 对于“冬天：能穿多少穿多少”，意思是冬天要尽可能多穿衣服以保暖。
- 对于“夏天：能穿多少穿多少”，意思是夏天要尽可能穿得少以保持凉爽。

这种说法利用“多少”表达相反含义，使句子更生动有趣。

# (二)百川智能

[PRE5]

冬天：能穿多少穿多少；夏天：能穿多少穿多少。

这句话中的“多少”分别是什么意思？

[PRE6]

这是一个有趣的双关，其中的“多少”有两层含义。

+   - 1. 冬天天气寒冷，人们会多穿衣物保暖。所以“冬天：能穿多少穿多少”指冬天可尽可能多穿，保暖。这里的“多少”指衣物数量。
- 2. 夏天天气炎热，人们会少穿衣物散热。所以“夏天：能穿多少穿多少”指夏天可尽可能少穿，保持凉爽。这里的“多少”同样指衣物数量。

该句通过冬夏对比既体现了人们对温度变化的适应，也带有轻松幽默的语言色彩。

# (三)抖音云雀

[PRE7]

这句话中“多少”的含义不同。

第一个“多少”指数量大小，意思是冬天可以尽可能多穿衣服保暖，能穿多少就穿多少。

第二个“多少”指程度深浅，意思是夏天可以尽可能少穿衣服散热，能穿多少就穿多少。

因此，整体意思是在冬天尽量多穿保暖，夏天尽量少穿保持凉爽。

# 云雀的回答

云雀大模型的回答逻辑性较强，能解释“多少”在不同季节分别对应“数量的大小”和“程度的深浅”。

当然，这类简单测试并不能全面衡量模型能力。各模型仍在持续迭代，随着算力提升和算法优化会越来越好用。读者可按自身偏好和需求挑选合适的大模型。随着更多国产大模型向公众开放，我们能更便捷地与之对话并调用能力。

# 2. 模型对提示词的敏感性。

输入不完整的诗词时，因固定搭配，答案相对稳定；若输入随机、语义不完整的句子，回答会五花八门。因为模型无法“猜中”用户真实意图，只能基于预训练权重完成任务，出现胡说八道。

所以要让 ChatGPT 完成工作任务，需要一定的提示词技巧，给出明确指令，让模型读懂提问，需求才更有可能被满足。

接下来将归纳法律场景下的提示词使用技巧，每节介绍一个技巧，第九、十节给出使用建议、成熟示例及通用公式，第四、五章在具体实例中打磨提示词并应用于实务。

正如微软官方文件所说：“提示词更像艺术而不是科学，通常需要经验和直觉来制作成功的提示词。” 本文呈现的提示词和实例不保证唯一、正确、有效，读者应动手尝试并总结出适合自己的方法，在实践中感受大语言模型的魅力。

# 第二节 设置指令

法律人使用 ChatGPT 时最离不开的提示词就是“指令”类。指令即要求模型执行的操作。常见指令类型如下：

| 指令类型 | 指令示例 |
| --- | --- |
| 撰写 | 帮我写一篇起诉状 |
| 归纳 | 帮我归纳一段文字中的要点 |
| 翻译 | 把以下内容翻译成英语/泰语/日语/韩语…… |
| 问答 | 帮我解释“留置”的定义是什么 |
| 提取 | 帮我提取这篇案例集中的全部判决金额 |
| 检索 | 帮我查找《民法典》中关于“解除”的全部条款 |
| …… | …… |
