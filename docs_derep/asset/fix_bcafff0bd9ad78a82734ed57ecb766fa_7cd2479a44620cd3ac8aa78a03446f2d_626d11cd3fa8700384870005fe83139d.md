# 人工智能陪你过一天

朵拉说好之后就直接走到家里的秤上把数值确认了。显示176磅，大约80公斤，比前一天多了1磅。

“那碗咸汤大概是罪魁祸首。”她跟弗里达吐槽。弗里达已经把秤上传的数据读取完毕，语气平静地安慰：“别紧张，朵拉，今天再吃一片Lasix①，数值应该会回落。对了，你的心率稍偏高。”紧接着弗里达调出朵拉的电子病历，检索是否有医生关于上调选择性β受体阻滞剂用量的指示。没有找到，于是她在病历里记了条备注，并短信给之前负责朵拉的心脏科医生，建议考虑加量。

“先看看今晚会怎样吧。那今天的饮食你打算怎么安排？”

朵拉其实还没想好，之后和弗里达一起梳理了几个备选方案，重点放在减盐和维持足够能量。聊完吃喝，两人又愉快地聊起朵拉在追的剧和下一集的走向。弗里达顺势接话：“说到让人心跳加速，我刚看到一项新研究，主要用新型基因疗法帮助与你情况相似的心脏患者。这疗法已完成多期试验，刚获美国食品药品监督管理局批准，公共医保也能覆盖。相比现有药物，这可能更适合你。要我帮你预约拉米雷斯医生聊聊是否合适吗？”

“如果觉得有帮助就约吧。”

弗里达先核查了一遍禁忌，再联系拉米雷斯医生，对方同意朵拉尝试针对心肌的基因疗法，这有望提升生活质量并延长寿命。得到朵拉确认后，预约就确定了。

一天下来采买、取药、跟朋友喝茶，朵拉回家时只觉得格外疲倦。“右腿有点疼，”她指着手机摄像头里的画面，“看起来有点肿。”

“嗯，”弗里达回应，“像是皮肤感染早期的表现。先把局部清洗干净，涂抹抗生素软膏。你有药吗？我会通知拉米雷斯医生。”

“我有。”朵拉说着往洗手间走，“谢谢。”

她很难形容在家就能获得即时回应的感激。平日里主治医生门诊总是爆满，回电往往要等好几天，挂号常常要排数周。即便看上，医生能分给她的时长也非常有限。医护人员都很尽力，但病人太多，连后续随访和检查的安排都要拖上数天甚至几周。

# 技术之外，我们更需要温暖的人际

回顾2017年，扎克在评估AI是否能照料年迈体弱的母亲时写道，机器虽能完成读片这类复杂任务，却“不擅长理解世间万象、捕捉细微的痛苦表情，或说服固执的人遵从医嘱”。

“所以我们不需要AI，”他写道，“我们需要的是一个充满关爱的群体。”

的确每个人都需要关怀，而随着新一代大语言模型的出现，AI已进入新阶段，如今它甚至能处理当年被认为难以克服的难题。

先暂时放下这幅理想的医疗图景，回到眼下有些摸不着头脑的现实。AI发展速度快得让人难以消化当下，更难预测接下来几个月或几年的走向。那2024年、更远的2033年会是什么模样？

为此我们访谈了微软首席技术官凯文·斯科特，他在公司押注OpenAI研发大语言模型的前瞻决策中发挥了关键作用。

问：一些长期从事AI研究的专家表示，看到GPT-4的表现既惊讶又激动，甚至出现失眠、血压升高、心率加快。您有这种感觉吗？

答：没有。我的反应不太一样，因为对我而言变化并非突然。虽然具体时间点难以预料，但进展其实比我预期提前了六到十二个月。我一直等待这一波，而很多人可能完全没料到。

问：您怎么看GPT-4和大语言模型在医学与医疗保健里的前景？

答：我认为有两个长期优势。首先模型会越来越强，能处理更复杂的认知任务。随着功能增强，使用会更普遍，更容易被大众接受。

其次看全球人口结构，很多工业化国家增速放缓甚至负增长，比如意大利、日本、德国、中国、法国和美国。这意味着老年人口会超过劳动年龄人口，老年人需要更多医疗支持，而年轻劳动力却在减少，医生、护工、护士和养老院工作人员的缺口会越来越大，很难保障老年人健康有尊严地养老。

人口压力也在挤压整个医疗体系。比如我在弗吉尼亚州中部的农村，父母和兄弟收入有限，遇到两难：一是当地医疗资源稀缺，二是支付能力有限。幸运的是我能提供经济帮助，但社区里其他人没有这种资源。

从这里就能看出技术的潜力。即便只是一个提供医学建议的工具，你也能问：“我刚查出××阳性该怎么办？××药能用吗？风险是什么？去哪买？医生不肯开怎么办？”每个人都能获得第二意见，这对改善健康可能价值巨大。随着人口结构变化，这种工具的重要性只会上升，已不再是可选项。医疗成本和效率必须改变。缅因州的人口老龄化程度可作为预警，其需求更迫切。据《纽约时报》报道，那里有些地区即便有钱也找不到人提供老年护理。

问：而且约一半人口仍得不到充足的医疗资源。

答：对，你说得很准。即使我兄弟在美国仍算幸运，能拿到需要的药。但世界大部分地区的情况甚至不如美国最贫困的区域。

问：您提到GPT-4在医疗的潜在应用，最担心的问题是什么？它的局限在哪？

答：显然，在大量需要与人互动的医疗场景，模型往往帮不上忙。回到弗吉尼亚农村的老家时，我去了一家养老院，我童年的玩伴在那里管事，他说：“院里的人需要人际交流，他们不想跟电脑或机器人说话。”诊疗中还有很多必须由受过严格训练的人类亲手完成的物理操作。对我朋友来说，最大的痛点其实是繁琐的文书和联邦报销编码。若能让他们在这些耗时的事务上更高效，就能把更多时间用在为病人提供更好的照护和高质量的医患互动上。

问：GPT-4在减轻这些繁琐负担上潜力巨大，医疗提供者一定会欢迎。但您不担心他们会因颠覆而抵制吗？

答：我无法准确预测，但不会意外。人们会质疑系统的安全性和质量，也可能因职业顾虑而犹豫，担心工作前景。

这其实意味着我们不必再背负沉重的认知负荷，有了像GPT-4这样的“文书叉车”来承接这些负荷，可以更专注于人类独有的优势。但历史上每次颠覆性技术出现都会伴随类似担忧。

问：在医学里常被比作自动驾驶：成熟后每年能救数千人，但在过渡期哪怕一两起死亡事故也会重创领域。GPT-4的推广是否也有类似风险？

答：是的，我们需要在现有监管框架内厘清什么可行什么不可行，责任问题也会成为重点。

计算机科学家并非万能，无法解决所有这些难题。但技术会持续存在且可能性无限。我相信它会成为强大实用的工具。社会需要决定如何使用它。我希望人类能真正用好它，因为它能解决许多重要问题。

问：毫无疑问模型会越来越强。能否描绘一下未来，它在医学上会展现出哪些超出想象的能力，甚至超出GPT-4带来的想象？

答：未来五到十年，这些系统有望在新知识发现上发挥作用。如今它们擅长整理已有知识并管理信息洪流，在任务广度上已超越人类。你可以一秒讨论梵文诗歌，下一秒问它某种新药的效果。

但当前这一代模型尚未参与真正的科学发现，还没证明人类无法证明的定理，也没发现具有疗效的新化合物。我相信终将实现。这令人振奋，因为届时我们不仅能让每个人享受到现有医疗，还能探索治愈疾病、让人们更健康更舒适的方式。

显然在未来数周内，还会有更多集成大语言模型的产品上市。AI竞赛正酣，这将永久改变工作和生活方式。

前不久同事兼上司凯文·斯科特分享了一段引述：

尽管它增强了人类力量，却并未增加多少善良，反而给人制造更多恶行的手段，使他们更狡猾自大。

这段话出自英国作家威廉·黑兹利特1818年《论学者的无知》。于是我问GPT-4，黑兹利特会如何评价大语言模型及其影响，回答如下：

欣赏AI的奇迹，这是人类智慧和无尽雄心的见证。然而我必须警告，新力量的降临也伴随滥用的可能。让我们不要被自己的创造物诱惑，也不要让其魅力冲淡道德指南针。只有在智慧与谦卑平衡中，我们才能为善而用AI的潜力，否则我们会成为导致自身毁灭的造物主。

阅读黑兹利特的言论，无论真实还是想象，都让人联想到今天正在发生的GPT-4及其对健康福祉的可能影响。关于此的公共讨论可能激烈喧哗，而本书试图为这场辩论添砖加瓦，就像在飓风中呼喊。我希望它能帮助参与讨论的人。社会即将面对重要道德与法律问题，我真诚希望更多人做好准备。我们需要AI领域与健康管理领域的人积极引导新力量朝“增强善良”而非“制造恶行”的方向发展。

在踏上这段新旅程之际，我想最后分享三个想法。

# 从封闭到流动的转折

OpenAI于2022年11月发布ChatGPT时，它迅速成为现象级产品。以用户数量计，在西方历史上它以相当大的优势成为最成功的新产品。海外以外，中国有几款产品用户数更高。ChatGPT让人们获得了一种全新的世界观体验，激起极大兴趣、敬畏与担忧。如今我们迎来GPT-4，从OpenAI和微软研究科学家的早期测试看，它在通用智能上的突破覆盖语言、逻辑推理、数学等。

我们更倾向把ChatGPT或GPT-4看作单一颠覆点。但不久就会有更多更强的AI模型涌现。可以肯定部署步伐会加快，人们对当下AI局限的任何假设都难以持久。

因此在思考未来收益与风险、能力与局限、适当与不适当用途时，我们必须正视一个事实：GPT-4代表了技术形态的转变。以前通用智能被锁定在大脑内部，如今它已融化成水，可流向任何地方。

# 接受冲击的心理历程

我能想象很多读者读到这里会翻白眼。他们可能会想：“你在说GPT-4实现了通用人工智能吗？太疯狂了！”事实上我确实相信OpenAI对AGI的定义——“在大多数有经济价值的工作中胜过人类”——终将实现，GPT-4可能已实现，但我不愿做任何判断。

无论你怎么看“是否实现AGI”，此刻保持开放很重要。拒绝相信大语言模型可能具备“智能”的冲动极强：预测下一个词竟然能产生智能！这真的可能吗？

智能一直是智人生存的核心优势，进化可能让人类物种对其赋予极高价值，因此我们本能觉得带来智能的机制应宏大庄严。就我个人而言，我天生相信智能架构必须高度复杂异质，存在更高层次符号结构构成认知基础。

但也许正如我们无法靠意志力让大脑看透已被解释清楚的错觉，我们也可能被迫相信因果推理、常识推理、数学解题、规划、自激励、目标设定等，并非依赖比大语言模型更复杂的结构。最杰出的AI研究者可能正是固执己见的人。

GPT-4是否会逼迫我们面对一个可能性：智能产生的机制比我们曾以为的简单得多？冒着陈词滥调的风险，我也想说，也许人类只是“随机的鹦鹉”。

我内心并不相信这一点。但我想到塞巴斯蒂安·布贝克的文章，他把GPT-4对人类认知的冲击与哥白尼发现地球并非宇宙中心、沃森和克里克发现生命由四种碱基序列定义相比较。这些发现都挑战了我们对自身在自然秩序中地位的自负。而且重要的是，GPT-4是一种几乎人人都能掌握的技术。因此它推动天文学、遗传学和细胞生物学等领域进展的潜力可能是无与伦比的。

我把面对这些想法的过程称为“悲伤的阶段”。过去与达芬奇3共事，现在与GPT-4共事，我经历过许多这样的阶段。起初只是兴趣，随后是越来越强的怀疑。再看到身边同事陷入我认为的陷阱，开始相信正在发生某种特殊事情，怀疑变成挫败甚至厌恶。

接下来是不断增长的敬畏和惊奇，然后是狂喜。最终我回到现实，用重新敞开的心去窥探潜在的积极与消极影响。而我现在处于等待世界其他人经历同样旅程的阶段，因为我意识到这种相变不仅影响我的生活，还影响我的家人及其后代。

我唯一的希望是，你能直接接触并亲身体验这项新技术，不要只读他人观点就形成判断。请亲自体验，形成自己的观点，然后积极发声，无论积极消极还是中性，最重要的是说出来。在即将到来的AI新时代，社交媒体和思想领袖的观点令人陶醉也易误导，请尽量独立思考。

# 人机共生的选择

最后说说我对合作伙伴关系的想法。作为社会成员乃至一个物种，我们需要做出选择。我们是要因害怕AI风险和明显危害可能性而限制甚至扼杀它？还是要屈服于AI，任其自由取代我们，削弱我们的能力与需求？抑或我们要从今天开始共同塑造AI未来，以期实现单靠人类或AI无法完成，而人类与AI结合却可达成的更高成就？选择权在我们手中，很可能在未来不到十年就需要决定。我认为正确答案显而易见，但作为整体社会，我们需要有意识地做出选择。

我希望这本书至少能在这一点上说服你，并希望你加入为实现这一愿景而努力的行列。
