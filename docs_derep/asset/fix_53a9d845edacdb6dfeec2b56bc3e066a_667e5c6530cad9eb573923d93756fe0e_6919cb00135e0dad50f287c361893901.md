GraphRAG：为检索注入结构化的图谱思维

微软开源的 GraphRAG 给出一个新思路：不再把料库当成一堆孤立文档，而是先把散落在各处的事实连成一张实体关系网。建网之后，检索时既能读实体本身的描述，也能顺着连线去触达邻居节点，从而获得更开阔的语义面，答案也就更连贯、推理路径更清晰。

整体工作可拆成两大阶段。

第一阶段是建库。做法分两步。先把原文切成段落或句子，让大语言模型识别出人物、地名、事件等要素以及它们之间的关联，用来搭出初始网络。再用 Leiden 算法做层次聚类，把关系紧密的节点聚成若干簇，并自底向上为每个簇写出概括。比如在论文集合里，数学和物理通常会各自形成独立的簇，每个簇都会产出一份主题小结。

第二阶段是问答，提供两种检索姿势。全局检索面向整体性问题，例如“过去五年生成式 AI 研究走向”，系统会汇总多个簇的概括，分批整合后给出综合回应。局部检索聚焦具体对象，例如“微软 Cosmos DB 的新能力”，先靠向量库定位相关节点，再结合簇报告提炼精准答案。

GraphRAG 的好处和代价都很突出。它能明显扩大覆盖面，显露出目标与其关联节点之间的链路，但计算开销较大，生成时也容易混入无关信息。针对这些痛点，业界已给出多条更轻的路线。

LazyGraphRAG 简化了建图。它不用大模型抽关系，而是基于名词短语和共现统计搭建轻量网络，索引开销约为传统方案的千分之一。查询时才动态调用大模型做相关性判断，并结合最佳优先与广度优先搜索，最终质量接近全量版，而查询成本明显下降。

OG-RAG 引入领域本体，把文档映射成超图，利用贪心策略挑选覆盖最多相关节点的超边，产出紧凑的上下文。比如在农业场景预定义“作物-土壤”关联，就能提升垂直领域的查准率。

HyBGRAG 则把向量检索与图结构检索融合，通过路由器与反思模块动态调整策略。若首轮结果不佳，大模型评论器会给出反馈并切换模块，提升可靠性。

总体来看，GraphRAG 把结构化网络与大语言模型深度结合，正在改写查找与生成的范式。随着效率与质量的平衡，医疗、金融等场景已开始落地。未来配合多模态扩展与自适应架构，它有望成为 AI 感知的核心底座，支撑更可信的生成应用。

### 10.2 语境增强检索：终结分块割裂困境

语境增强检索由 Anthropic 提出，目标是解决传统 RAG 因文本切分导致语义割裂的问题。核心做法是在嵌入前为每个单元补上解释性描述，以此提升召回与生成的质量。

检索时系统不仅看查询本身，还会融合对话历史、使用者偏好、任务目标等语境因素。连续对话中，用户问“公司 2025 年 Q2 营收增速”，若块里只有“营收增长 3%”而缺少主体与时间，就很难匹配。语境增强检索会自动把这些缺失要素纳入检索范围。

落地方式主要有两类。语境向量化，利用大语言模型为每块生成约 50 到 100 token 的描述，例如把“营收增长 3%”扩展为“该片段来自公司 2025 年第二季度财报，上季营收 3.14 亿美元，本季增长 3%”。语境 BM25，则把原文与描述合并建索引，增强术语匹配能力。

Anthropic 的实验显示，采用混合策略结合向量语义与 BM25，前 20 条相关块的失败率下降约 49%，再加入重排可额外降低 67%。借助 Prompt Caching，可一次性把文档载入缓存，减少重复调用大模型的 token 消耗。面对动态更新的挑战，可结合增量图谱构建或滑动窗口策略进行优化。

### 10.4 代理式RAG：让系统从被动应答变主动决策

从 RAG 到 Agentic RAG 的演进，标志着系统从被动响应转向主动参与查找与决策。它不仅回应查询，还能自主制定查找计划、挑选信息源、质疑结果并迭代优化，逐渐演化为具备策略思考的智能信息交互体。

核心模式可归纳为四类。

- 反思模式：代理通过迭代评估自身决策和输出质量来优化策略。例如医疗诊断中，根据患者反馈调整查找范围，提高诊断准确性。
- 规划模式：把复杂查询拆解为子任务实现多步推理。金融分析代理可按“数据查找→趋势分析→风险评估”流程生成投资建议。
- 工具使用模式：接入外部 API、数据库等工具扩展能力。法律代理可调用合同库与合规规则库生成法律意见书。
- 多智能体协作模式：多个专业代理协同完成复杂任务。客服场景下，FAQ 查找、工单处理、情感分析代理可协同提升效率与体验。

CRAG、Self-RAG、RRR 等改进也可视作迈向 Agentic RAG 的阶梯。其典型特征包括对查找到的文档进行相关性打分、必要时重写查询、利用网络查找补充信息。当初始查找不充分时，系统可根据查询复杂度切换单步或多步查找，显著增强复杂问题的回答能力。

### 10.5 多模态RAG：当检索不再只看文字

当信息扩展到图像、音频、视频等多种模态，Multi-Modal RAG 成为必要。它能从图像提取特征、从视频截取片段、从音频提取关键词，并与文本查找结果融合，提供更全面的知识支撑。

技术架构主要包括三层。多模态编码器，如 CLIP，把跨模态语义对齐，例如将“红色跑车”文本与对应图像关联。动态查找策略根据查询类型优先处理模态，视觉问答中优先查找图像并辅以文本。跨模态融合则借助注意力机制整合异构信息，医疗报告分析时同时考虑影像与文本。

代表框架有阿里巴巴的 OmniSearch 和 HyBGRAG，均支持文本、表格、图像混合查找，减少幻觉并增强复杂推理。典型场景包括医疗影像分析结合 CT 与病历生成诊断建议、工业质检整合产品图像与缺陷库实时报警、教育实现视频与原理文本联动查找、零售推荐融合评论、图片与购买记录实现定制化推荐。

未来轻量化多模态模型将降低算力门槛，使消费级硬件也能高效运行。动态路由机制可按任务自动选择最优模态组合，例如优先语音输入后转为文本。Agentic RAG 与 Multi-Modal RAG 的融合更具潜力，自动驾驶中多模态代理可实时整合路况图像、传感器数据与交通规则库进行动态路径规划；医疗、制造等垂直领域的专用 MM-RAG 框架也前景广阔。

### 10.6 小结

除本章所述进展外，RAG 生态仍在快速演化。

- 图灵完备 RAG，TC-RAG：让查找流程可编程，通过嵌入算子和逻辑，动态组合查询与数据处理，完成复杂推理。
- 迭代式查找，如 ITER、CRAG、Self-RAG、RRR：多次调用查找模块，利用上轮结果与生成器反馈修正查询，逐步逼近使用者期望。
- 自适应查找，如 FLARE：依据系统状态、使用者反馈和语境变化动态调整策略，通过在线学习持续改进准确性。
- IRCoT：将思维链引入查找，不仅返回文档，还呈现查找路径与中间推理，降低盲目性。
- PlanRAG：在查找阶段加入规划，先查领域核心知识再拓展上下游，使结果更条理，便于生成利用。
- T-RAG：引入任务分解与角色分工，多查找器分别处理子任务后汇总，供给生成器多维度材料。
- AutoRAG：自动化优化流程，自动选择策略与参数并闭环调优，减少人工干预。
- RAFT：把查找知识融入大模型微调训练，使推理时具备“知识植入”特性，提升回答实用性。

小冰：这些策略让 RAG 不再只是海量内容里捞信息，而是具备分层思考、灵活适配与多模态融合的能力。未来的 RAG 更像全能信息经纪人，自动筛选、分析并整合有价值信息。

咖哥：没错，这些复杂范式的加入，把 RAG 从单一查找升级为多维度、多策略的知识获取与利用框架。它将与 AI Agent、MCP 等技术协同，为更高阶的智能交互铺路。
