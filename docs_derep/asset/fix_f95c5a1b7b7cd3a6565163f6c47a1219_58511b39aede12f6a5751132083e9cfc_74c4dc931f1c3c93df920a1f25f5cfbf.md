**10.3.2** **直线折旧法计提折旧**

直线折旧法也叫平均年限法，核心思路是把固定资产的历史成本扣除残值后在预计可使用年限内均匀摊销，各期计提的年额或月额保持一致。

**1．SLN 函数**

SLN 是 Excel 里专门做线性折旧计算的函数。

在不考虑减值准备的情形下，直线法的计算逻辑为：

固定资产年折旧率 = （1 - 预计净残值率）/ 预计使用年限（年）

固定资产月折旧率 = 年折旧率 / 12

固定资产月折旧额 = 固定资产原值 × 月折旧率

1）函数含义及说明

SLN 用来求取某项资产在某一期间的直线折旧金额。

2）语法及说明

SLN(cost,salvage,life)

■ cost：资产的取得成本。
■ salvage：折旧结束时的预计残值。
■ life：折旧总年限，即使用寿命。

**2．直线折旧法计算折旧额**

按直线法批量生成折旧额的操作如下。

❶点选 I3 单元格，在公式栏里写入：
=SLN(E3,G3,D3*12)
回车后即可得到第一项固定资产按直线法计算的折旧数，如图 10-33 所示。

**10.3.3** **年数总和法计提折旧**

年数总和法属于加速折旧范畴，又称总和年限法。做法是把原值扣除残值后的净额乘以一个逐年递减的比例系数来确定当期折旧。

**1．SYD 函数**

SYD 用于返回某项资产按年数总和法在指定期间的折旧值。

系数分子为尚可使用年数，分母为 1 到 n 的数字之和，设年限为 n 年，分母为 1+2+3+…+n = n(n+1)÷2。相关关系如下：

年折旧率 = 尚可使用年数 / 年数总和 ×100%

年折旧额 = （固定资产原值 - 预计净残值）× 年折旧率

月折旧率 = 年折旧率 / 12

月折旧额 = （固定资产原值 - 预计净残值）× 月折旧率

该方法多用于技术迭代快、产品更新迅速，或长期处于强震动、高腐蚀环境下的资产。

1）函数含义及说明

SYD 按年数总和法计算固定资产指定期间的折旧金额。

2）语法及说明

SYD(cost,salvage,life,per)

■ cost：资产取得成本。
■ salvage：折旧期末的预计价值，即残值。
■ life：折旧总年限，即使用寿命。
■ per：期间，单位必须与 life 保持一致。

如图 10-35 所示，按年数总和法计算某项固定资产各年折旧，金额逐年递减。先得出年折旧额再除以12即可得到月度金额。

**10.3.4** **双倍余额递减法计提折旧**

双倍余额递减法是不考虑残值的加速折旧方法，按每期期初账面余额乘以两倍的直线折旧率计提。

**1．DDB 函数**

DDB 用于以双倍余额递减法计算某项资产在给定期间的折旧额。

计算关系：

年折旧率 = 2 / 预计使用年限 ×100%

年折旧额 = 该年年初账面净值 × 年折旧率

月折旧额 = 年折旧额 / 12

该方法在计提时不考虑净残值，若某期按双倍余额递减法算出的金额小于直线法金额，则应改用直线法。

1）函数含义及说明

DDB 采用双倍余额递减法计算一笔资产在指定期间的折旧额。

2）语法及说明

DDB(cost,salvage,life,period,factor)

■ cost：资产取得成本。
■ salvage：折旧期末的预计价值，即残值。
■ life：折旧总年限，即使用寿命。
■ period：需计算折旧的期间，单位要与 life 相同。
■ factor：递减倍数，省略时默认为 2。

如图 10-38 所示，用双倍余额递减法计算某项固定资产各年折旧，呈现加速递减特征。为便于操作，通常在折旧年限到期前两年将账面净值扣除预计净残值后的余额平均摊销，公式中通过 IF 判断年限。

**11.2** **编制科目汇总表**

记账凭证数据按会计对象分为以下几类。

**1．资产类科目（首位数字1）**
按流动性分为流动资产和非流动资产。流动资产如“现金”“原材料”“库存商品”“应收账款”；非流动资产如“长期股权投资”“固定资产”“无形资产”。

**2．负债类科目（首位数字2）**
按偿还期限分为流动负债和长期负债。流动负债如“短期借款”“应付账款”“应交税金”；长期负债如“长期借款”“应付债券”“长期应付款”。

**3．所有者权益类科目（首位数字4）**
分为资本类和留存收益类。资本类如“实收资本”“资本公积”；留存收益类如“盈余公积”“本年利润”“利润分配”。

**4．损益类科目（首位数字6）**
反映收入和费用的科目。收入类如“主营业务收入”“其他业务收入”；费用类如“管理费用”“财务费用”“营业费用”“所得税”等。

科目汇总表即把本期记账凭证按科目汇总后以表格呈现。
