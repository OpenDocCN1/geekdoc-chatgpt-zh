本地部署 DeepSeek：选型与私有化实战指南

除了蒸馏系微型版，也可以考虑体量更轻的非蒸馏版本。截至成稿，QwQ-32B 与 Gemma3-27B 是可参考的备选，它们在有限规模下表现尚可，综合实力仍不及 DeepSeek-R1。

前文已提到 DeepSeek-R1 官方发布的几款蒸馏小模型。经验来看，编程类任务对规模的依赖相对偏弱，知识密集型问答则更吃规模。以评测为例，1.5B 蒸馏版在代码能力上能超过 GPT-4o 并压过多数国产非推理大模型，但在其他场景往往达不到预期。无论大小，蒸馏版始终逊于原版满血模型，选型务必结合真实使用需求。

动手本地化前，先确认显卡型号并查询显存大小，再结合整机配置决定选用哪个版本。

影响本地运行的关键硬件有四项：

**CPU**：规模越大核心需求越高，多核高端处理器可缓解推理瓶颈。

**GPU（显卡）**：模型越大对显卡要求越高，显存与算力是核心，若单卡显存不足需多卡协同。

**内存**：需承载参数、中间计算结果及缓存，需求随参数量线性增长。

**磁盘空间**：由模型本体与推理临时文件决定，模型越大占用越高。

以下为 DeepSeek-R1 各蒸馏小模型的大致硬件门槛，B 为 Billion 即十亿，1.5B 约等于十五亿参数，供参考。

- 1.5B：最低4核CPU、8GB以上内存、3GB以上存储，显卡可不配，若需加速建议4GB以上显存，适合资源受限环境。
- 7B：8核以上CPU、16GB以上内存、8GB以上硬盘，显卡建议8GB以上显存，适合本地开发测试。
- 8B：需求与7B相近略高，适合对精度要求稍高的轻量任务。
- 14B：12核以上CPU、32GB以上内存、15GB以上硬盘，显卡16GB以上显存，可用于企业级简单任务。
- 32B：16核以上CPU、64GB以上内存、30GB以上硬盘，显卡24GB以上显存，适合对领域任务有一定要求的场景。
- 70B：32核以上CPU、128GB以上内存、70GB以上硬盘，显卡需多卡并行，适合较高复杂度生成，但仍不及原版671B满血模型。

## 实现私有化部署

本地化私有化方案很多，这里介绍一种最简快捷、适合大多数人的做法，即用 Ollama。Ollama 专为本地运行大模型设计，目标是让部署与运行变得极快。无需繁琐依赖，也不需专业背景，几步即可在自己的电脑上跑起深度学习模型。

与依赖云端的服务不同，Ollama 坚持本地化，数据与交互全在设备内部完成，隐私更可控。同时兼容 Windows、Linux 和 Mac，覆盖主流使用环境。其设计理念是化繁为简，无论安装还是启动都追求快速上手，从入门用户到专业开发者都能顺利使用。

下面说明如何安装 Ollama 并用它完成私有化部署。操作前请确保硬件满足要求，并在合适的机器上进行。若条件不足或暂不使用，可跳过后续内容。

## 搭建本地对话界面

直接用 Ollama 命令行对话虽然可行，但界面朴素不够直观。若想要更好的体验，可在 Ollama 基础上配合第三方客户端 ChatBox，增加美观且功能丰富的图形界面。

ChatBox 是一款 AI 大模型桌面客户端，为各模型提供统一交互界面，使用更直观。它设计简洁、功能强大，支持 DeepSeek、ChatGPT、Claude、Gemini API 等在线模型，也支持通过 Ollama 本地化部署的全部模型，可在一工具中切换使用，实现更高效的工作流。

## 更多使用DeepSeek的途径

除官方 App、网页版和私有化部署外，还有其他方式使用 DeepSeek，可归为两类。

#### 通过第三方应用接入

DeepSeek 模型开源免费，已被大量第三方应用接入。许多应用将 DeepSeek 接入自有知识库，通过 RAG 等技术增强输出，在垂直领域效果更好。例如百度、腾讯元宝、微信搜索、秘塔搜索、纳米 AI 搜索等均可使用 DeepSeek-R1 进行 AI 搜索，自动汇总全网信息生成答案；腾讯 ima.copilot 支持基于 DeepSeek-R1 构建个人知识库等。目前接入的应用已超百款，可按自身领域挑选工具。

此外，部分 AI 工具平台支持多家大模型混合接入。虽然 DeepSeek 很强，但在某些场景下并非最优。灵活组合国内外工具能进一步提升效率，如百言 AI 提供 AI 对话、AI 绘图等多种工具。

#### 通过云服务接口（API）接入

对开发者或希望深度定制、接入自有知识库的用户，深度求索提供 API 开放平台，可获取接口使用权限。

拿到 API 后，可在 ChatBox 等工具中接入云端版 DeepSeek，也可接入 Dify、AnythingLLM 等本地知识库工具，实现定制化使用，还能通过编程调用实现自动化。

除官方外，火山方舟、阿里云、腾讯云、百度智能云等第三方云服务商也已接入 DeepSeek，提供兼容官方接口的 API，可自由互换使用。
