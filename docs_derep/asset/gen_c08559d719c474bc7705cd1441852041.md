**4.数组与指针的区别**

（1）本质：一个存数据，另一个存地址。

数组是用来放数据的连续空间，创建时大小就定死，内存里直接躺着一串同类型值，像一排固定抽屉。指针只是保存地址的变量，本身不放数据，像一张写地址的便签，便签上的地址可以随时改写。

（2）占用的内存空间大小：数组的大小由元素类型和个数决定，指针的大小固定。

数组占用等于元素大小乘以元素个数，定义后就不变，想再扩容也不行。指针大小与指向内容无关，32 位平台通常占 4 字节，64 位平台通常占 8 字节，它只负责存一个地址。

（3）数组名与指针变量：数组名是固定地址，指针是可变地址。

数组名代表首元素地址，但它是常量，不能改。arr++ 是错误的，不能把这排抽屉整体挪位。指针变量存的地址可以改，ptr++ 会让它指向下一个元素的地址，这正是指针遍历的原理。

（4）访问数据的方式：索引与解引用。

数组用索引访问，编译器会自动算出首地址加索引乘元素大小，直接定位。指针用解引用，先拿到地址再取值，遍历时 ptr++ 移动到下一地址，再解引用即可。

（5）关键提醒：别混淆数组名和指针。

数组名是固定地址，不能赋值，如 int arr[5]; int *p; arr = p; 是错的。指针是可变地址变量，可以指向数组首地址，如 p = arr; 但指针本身不是数组。
