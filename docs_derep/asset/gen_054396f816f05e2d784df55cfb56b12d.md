# AI绘画主模型选型与Liblib AI实操指南

主模型Checkpoint在AI绘画中起着决定性作用，挑选合适的基础模型是出图的先决条件。模型的能力来自训练素材的数量与质量、训练轮次和周期，以及后续在实际使用中的持续打磨。即便是同一种画风，不同作者训练的版本表现也会有明显差异。下面汇总几款经过验证、相对稳妥的主模型，帮助你少走弯路。

###### 1. GhostMix 鬼混模型
GhostMix聚焦写实动漫方向，角色不限于真人，机甲、科幻等机械类场景也能呈现得相当到位。装饰感和画面华丽度是它的特点，细节丰富、放大后依旧通透，参考图 6-2 和图 6-3。

图 6-2 的提示词：“highest detailed, best quality, official art, (beautiful and aesthetic:1.2), girl, (fractal art:1.3), colorful”[最高细节，最佳品质，官方艺术，（美丽和美学：1.2），女孩，（分形艺术：1.3），色彩丰富]。

###### 2. majicMIX realistic 麦橘写实模型

### 6.1.2 Liblib AI界面速览
登录Liblib AI后，首页展示大量模型作品，风格多样。左侧功能导航包含在线生成、训练我的LoRA、个人中心等，点击“在线生成”进入绘图参数页。

对初次使用者来说，Liblib AI的学习成本高于仅提供几套风格和简单提示词输入的网站。它的参数界面与Stable Diffusion Web UI高度一致，熟悉Web UI的用户上手很快，新手则需要一定适应时间。平台已内置主流实用插件，模型资源可直接调用，使用便捷。

总体而言，有经验的用户可在云端完成部分专业工作，但生成数量和排队等待会限制效率，大工作量仍建议本地部署。新手可借此完整体验专业AI绘画软件的操作感及主流效率插件，为日后本地使用Stable Diffusion Web UI做准备。

### 6.1.3 收藏与借鉴技巧
AI绘画已成为设计潮流，网络上模型层出不穷，新品更新极快。本地使用Stable Diffusion Web UI的用户常抱怨好模型太多、旧模型频繁迭代。下载全部心仪模型会占用大量硬盘并面临过时风险。Liblib AI由作者上传维护，支持线上体验或下载，方便收藏避免资源浪费。

看到满意的模型，点击“加入模型库”即可收藏；想立即试用，点击“立即生图”进入绘制页。使用前注意阅读作者参数建议，不同模型参数习惯不一；同时注意模型的创作与商业使用许可，务必在授权范围内使用。

### 6.2 云端修图魔法
Liblib AI的在线生成操作与Stable Diffusion Web UI基本一致，文生图、图生图不再赘述。其核心竞争力在于开源兼容与开发者持续贡献的附加功能与插件，下面介绍部分辅助功能如何支撑设计流程。

### 6.2.1 提示词逆向提取
设计中常需对已有图像进行二次加工，获取生成信息很有帮助。PNG图片信息功能可查询提示词、随机种子、主模型、LoRA、VAE及参数等，但对非AI生成图无效，此时需要提示词反推。Liblib AI提供三种反推方式，各有侧重，分别是CLIP反推、DeepBooru反推和WD1.4标签器。

###### 1. CLIP反推
在图生图的正向提示词输入框旁有“CLIP反推”按钮。先将图片上传至图生图区域，点击“CLIP反推”后，输入框会自动填入与图像相关联的提示词。
