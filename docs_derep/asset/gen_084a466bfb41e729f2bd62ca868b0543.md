## 8.6 LangChain 智能体核心能力全解

在 LangChain 里，智能体是最具想象力的模块。它让大语言模型不再只回答问题，而是能根据用户的指令现场判断该做啥，通过调用外部工具把任务落地。LLM 在这里充当推理中枢，赋予系统自主决策和处理复杂流程的能力。

### 8.6.1 智能代理是什么

智能代理的核心是把大语言模型当作“大脑”。它结合用户输入和当前情境，从自带的工具箱里挑选合适的工具去执行，达成自动化的决策与行动，典型场景有在线客服、智能家居控制等。

广义上，人工智能代理是能感知环境、自主判断并采取行动的程序。在 LangChain 的语境里，它被理解为一套基于工具和知识库自主完成任务的 AI 系统。常见的构成有：

- 工具：Agent 可调用的功能模块。
- 记忆：保存过往交互的历史信息。
- 决策引擎：判断下一步该做什么。
- 执行器：把选定的动作真正跑起来。

### 8.6.3 多智能体框架 LangGraph 概览

LangGraph 是 LangChain 生态的多智能体编排方案，可以把多个智能体串成协作网络，共同处理复杂任务。它支持 ReAct、Plan-and-Execute、Reflection & Critique、RAG 以及代理切换、群体协作等多种范式。定位上，它是 LangChain 的扩展，用于搭建有状态的多智能体协作系统。关键特性包括：

- 用图拓扑来定义工作流。
- 支持循环迭代和条件分支。
- 内置持久化状态管理。
- 完全兼容 LangChain 现有的工具链。

### 8.6.4 LangGraph 中的图

在 LangGraph 里，图用来描述工作流，通过增添节点即智能体、边即流转关系来搭建，比如设置 Supervisor、Researcher、Emailer 等角色，再用边协调执行。图本质上是智能体网络的结构，由节点与边组成，节点可以是智能体或工具，边是通信路径。常见结构有：

- 线性图：任务按固定顺序推进。
- 树状图：把大任务拆成子任务树。
- 有向无环图：表达复杂的依赖关系。
- 循环图：支持迭代和反馈。

### 8.6.8 LangChain 中的工具

- API 工具：调用外部接口，如天气、股票、定位等。
