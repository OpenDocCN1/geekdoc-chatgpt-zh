## **5.2 AI 驱动的数据清洗**
把外部数据导进 Excel 后，通常要做清洗以保证准确和一致。清洗涵盖缺失值处理、重复值剔除、格式统一等，能消除错误、补齐空缺、校正不一致，使分析结果更可靠。

### **5.2.1 补齐与清理缺失值**
缺失值表现为空白单元格或特殊符号占位。图示数据导入后部分单元格为空，可批量填 0 或整行删除。

在 Excel 或 WPS 中，先选中数据区域，按 Ctrl + A 全选，再按 Ctrl + G 或“开始 > 查找和选择 > 定位条件”，打开“定位”对话框，点“定位条件”，选择“空值”，确定后即可选中所有空白单元格。

[PRE21]

图 5-27　“定位条件”对话框

直接输入 0 后按 Ctrl + Enter 完成批量填充。若要删除含缺失值的行，在步骤 3 选择“开始 > 单元格 > 删除 > 删除单元格”，在弹出的对话框选“整行”确定；WPS 中可通过“开始 > 行和列 > 删除单元格 > 删除行”实现。
