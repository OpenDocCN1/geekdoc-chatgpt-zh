### 核心技术：规则空间与属性层次模型的诊断逻辑

规则空间模型（RSM）依托贝叶斯判别或马氏距离，将被试的观察反应模式与预设的纯规则点（理想反应模式）逐一对照，完成个体分类。这一方法突破了单纯能力估计的局限，实现了对学习者属性掌握模式的精准画像：哪些知识点已掌握、哪些存在薄弱环节、整体能力处于何种水平，一目了然。基于此，教师可制定分层干预策略，落地“因材施教”。

在 RSM 基础上演进而来的属性层次模型（AHM）虽同源但异途。Gierl 指出，AHM 革新了分类基础：它计算观察模式偏离理想模式（由失误或猜测导致）的概率，将个体归入错误期望概率最高的那类模式。其显著优势在于，能基于 Q 矩阵与技能层级，产出更精确的理想反应模式。Almond 等展望 AHM 未来将引入人工神经网络（ANN）训练替代 RSM 的异常值处理，视为测量理论的重大跨越。

AHM 致力于用概率方法分类，并强化属性依赖关系的形式化表达。开发者认为 RSM 多忽视属性间依赖，而 AHM 将其显性化，专为评估场景设计，支持对属性依赖的理论预设。

在分类算法上，AHM 探索多元统计程序，近期引入神经网络。为阐释算法本质，聚焦其源自 IRT 的原始分类流程（寻优工作仍在进行中）：

1.  **生成期望样本**：依属性层级推导各属性的期望反应模式，复制扩充生成大样本，使总分服从特定分布（通常为单变量正态）。
2.  **IRT 校准**：以生成数据校准单维 IRT 模型（如 2PL），获取题目参数。关键差异：AHM 用期望反应数据而非观测数据校准，导致参数估计与潜变量值区别于 RSM。
3.  **多元分类**：
    *   法一：结合 IRT 滑动与猜测概率，全维度比对观察与期望模式。
    *   法二：仅用滑动概率。
    *   法三：滑动概率配合属性档案的逻辑包含规则。
    *   比对量级取决于被试数、题量及唯一反应模式数（如 1000 人答 22 题，最多 22000 次比对，重复模式会减少计算量）。

**比对微观机制**：逐题比对观察与期望响应。匹配项无误差；期望为 1 实为 0（失误），按对应潜变量值算滑动概率；期望为 0 实为 1（猜中），同理算猜测概率。依分类法选用单一或双重概率，或叠加逻辑规则，将全题概率相乘得似然值。每个观察模式对应一组似然值，分配至最大值对应的属性配置。

### 4.3.2 分级反应聚类诊断法（GRCDM）

GRCDM 由康春花团队在 0-1 计分 K-means 基础上拓展至多级计分。核心在于构建**属性合分**与**能力向量**。因属性分层，不同得分对应属性加权不同，公式为：
$$W_{ik} = \sum_{j=1}^J y_{ij} \rho_{ijky} q_{jk}$$
$W_{ik}$ 为被试 $i$ 属性 $k$ 合分；$y_{ij}$ 为项目得分；$\rho_{ijky}$ 为得 $y$ 分时属性 $k$ 权重；$q_{jk}$ 指示项目测量属性。能力向量元素 $B_{ik} = W_{ik} / \sum q_{jk}$（属性考核次数）。

**K-means 聚类流程**：
1.  依 R、Q 矩阵得 IRP，算出合分与能力向量，设为初始聚类中心。
2.  算被试 ORP 能力向量，测距离，分入最近中心。
3.  全量分配后，重算聚类中心。
4.  迭代至分配稳定。

### 4.3.3 距离判别法：免校准、强推广的非参数路径

此类方法引入汉明、马氏、欧氏、曼哈顿等距离，无需预设 CDM、无需复杂参数估计，极大拓展操作空间。

#### 1. 汉明距离判别（HDD 及其变体）
Chiu 和 Douglas 将汉明距离 $d(x_i, y_t) = \sum |x_{ij} - y_{jt}|$ 用于认知诊断，寻找 ORP 与 IRP 最小距离分类。针对“一题对多理想模式同距”误判，提出加权汉明距离（WHDD），权重 $1/[\bar{p}(1-\bar{p})]$，实证证明判准率超参数法。HDD 免参数、形式简、推广性强。

罗罗盛等融合 Q 矩阵理论，开发朴素 HDD，按冲突处理分 **R 法（随机分配）** 与 **B 法（贝叶斯后验）**。B 法利用唯一匹配被试的知识状态分布作先验，解决多匹配冲突，充分挖掘后验信息。康春花综合实证发现 R、B、W 三法结果无显著差异。

#### 2. 曼哈顿距离判别（MDD）：多级计分的原生适配
康春花等将曼哈顿距离 $MD = \sum |x_{ij} - y_{jt}|$ 推广至混合计分。MD 随元素差值增大而增，直观反映“差异量级”。

**HDD 与 MDD 关键分野**：
*   0-1 计分下等价。
*   多级计分下 **MDD 优于 HDD**。例：ORP=(2,3,3,4,5)，IRP1=(2,4,4,3,5)，IRP2=(3,3,3,3,2)。HDD 仅计不同元素个数（均为 3），难分优劣；MDD 计绝对差值和，IRP1 距离 3，IRP2 距离 5，精准锁定 IRP1。HDD 只数“错几个”，MDD 量“错多远”，符合“寻找差异最小”原则。

MDD 同步推广 R/B/W 三法（R-MDD 等）。模拟与实证显示：三法表现相当，MDD 鲁棒性更佳，计算简便，受样本量、测验长度影响小，免建模、免估计、免特殊算法，极利于一线教师落地新课改。

### 非参数 AI 认知诊断：优势与短板并存

**优势**：
1.  产出技能级诊断报告，学习者明知长短。
2.  对属性/题量要求低，适配课堂小样本场景。
3.  计算轻量，易部署。

**不足**：
1.  属性定义与关系确立难度大。
2.  仅支持单向依赖，双向关系无解。
3.  属性二分（掌握/未掌握），颗粒度粗糙。

### 第 4.4 章 深度学习驱动的静态认知诊断：破解非线性与稀疏性

计算算力跃升推动深度学习入局，擅长挖掘非线性交互、处理稀疏数据、预测成绩，旨在解决传统 CDM 对学习者-试题复杂关系拟合乏力的痛点。核心思路：用神经网络训练交互函数（替代人工设计），诊断知识状态。代表作有 NeuralCDM、ECD、RCD。

#### 4.4.1 NeuralCDM：可解释性与拟合力的统一框架
NeuralCDM 融合神经网络与心理测量假设，用多维参数刻画认知状态与任务特征（难度等），用网络学异构数据中的复杂关系。为守可解释性，两步走：
1.  **技能对齐**：用技能关联向量将认知状态维度锚定到具体技能。
2.  **单调性约束**：多层神经元施加单调假设，保证认知状态升高 $\rightarrow$ 成功概率升高，符合 IRT 逻辑。

**框架通用性强**：
*   兼容异构数据学习。
*   涵盖传统 CDM（如 DINA、IRT）。视角上看：① 参数从一维升维；② 引入技能关联向量对齐；③ 将单 Sigmoid 交互函数升级为多层神经网络。拟合力增强，可解释性保全。
*   关键符号：$Q_{c,1}$（习题-技能关联）、$h^s$（技能熟练度）、$h^{diff}$（技能难度）、$h^{disc}$（区分度）。IRT 用 $\sigma$ 函数保单调，NeuralCDM 用全连接层实现。

#### 4.4.2 RCD：关系图建模“内部结构+层间交互”
过往研究聚焦层间交互（用户-任务、用户-技能），忽视知识概念间的教育依赖（内部结构）。Gao 等提出 RCD，以多层关系图统一捕获：
1.  **节点化**：用户、任务、技能作层级节点。
2.  **三大局部图**：用户-任务交互图、任务-技能关联图、技能依赖图，全景建模三元关系。
3.  **递归聚合**：节点递归吸纳邻居信息。
4.  **融合层+注意力**：节点级/图级双重聚合，注意力网络平衡多层级信息。
5.  **即插即用**：关系驱动表征可融入现有 CDM，提升诊断性能。

#### 4.4.3 ECD：显式作答+隐式语境的双轨诊断
学校、家庭、地域等环境深塑隐性认知状态。Zhou 等构建 ECD，将教育情境特征纳入 CDM：
1.  **领域划分**：异构上下文按类归域。
2.  **情境建模**：层次化注意力网络刻画各领域个性化影响，生成学习者外部特征向量。
3.  **诊断增强**：认情境影响全面非特异，自适应融合外部特征与内部认知状态（历史作答隐含）。
4.  **通用增强器**：该框架即插即用，显著提升主流 CDM 性能。实验揭示跨国跨域教育背景差异等洞见。

### 4.5 章末综述：从概率建模到深度融合的演进史

本章梳理认知诊断理论内涵与演进，聚焦建模方法：概率建模 $\rightarrow$ 数据挖掘 $\rightarrow$ 深度融合，呈现代表性模型谱系。

**概率模型本质**：根植认知心理与教育测量，离散潜变量模型，识别属性模式或掌握程度（潜变量可为认知技能、心理特质、态度）。核心价值：透过作答回溯领域掌握，**非排名定位，而是输出优劣势具体反馈**。

**深度融合转折**：算力瓶颈突破后，神经网络与 CDM 融合催生 NeuralCDM。其不止用得分矩阵与 Q 矩阵，更用网络挖掘文本修正 Q 矩阵，三元建模（学习者、试题、交互），大幅提升学习能力。

**总结**：认知诊断经历“传统 CDM $\rightarrow$ 深度 CDM”范式跃迁，实现认知心理学与神经网络技术深度融合双赢：
*   **认知模型赋能深度学习**：注入可解释性。
*   **深度学习赋能认知诊断**：挖掘非线性交互，强化拟合性能。
