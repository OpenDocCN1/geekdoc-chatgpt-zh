根号2为无理数。

**推导说明：**

利用反证思路说明根号2的性质。

假定根号2可表为互质整数 a/b 的最简形式，其中 b≠0 且 a、b 互素。

1. 对等式两边进行平方：

\[ (\sqrt{2})^2 = \left(\frac{a}{b}\right)^2 \]

可得：

\[ 2 = \frac{a^2}{b^2} \]

2. 等式两边同乘 b²：

\[ 2b^2 = a^2 \]

由此 a² 能被2整除，进而 a 可被2整除。记 a = 2k，k 为整数。

3. 代入前式：

\[ (2k)^2 = 2b^2 \]

得到：

\[ 4k^2 = 2b^2 \]

化简为：

\[ 2k^2 = b^2 \]

由此 b² 也能被2整除，故 b 亦可被2整除。

4. 在 a 与 b 互素的前提下，二者同时被2整除会产生矛盾。因此该假设不成立。

综上，根号2不可能是有理数，即为无理数。 < | end_of_sentence | >

- SFTTrainer（来自trl库）类：trl 即 transformer reinforcement learning，是 Hugging Face 推出的 trl 工具包，涵盖监督微调与强化学习能力。SFTTrainer 主要承担监督微调任务，支持 LoRA 等低秩适配方案。
