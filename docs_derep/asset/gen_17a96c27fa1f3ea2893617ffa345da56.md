#### 1. Fermi 架构

2010 年 NVIDIA 推出 Fermi 架构，示意见图 4.1.1。最高可集成 16 个 SM，单个 SM 搭载 32 个 CUDA Core，满载时合计 512 个核心。设计主线面向游戏，原片由多个图形处理簇 GPC 构成，一个 GPC 内含 1 个光栅引擎和 4 个 SM。

内存侧提供 6 组 64 位分区，总线位宽 384 位，最多支持 6 GB GDDR5。GPU 与主机通过 PCIe 相连。GigaThread 全局调度器把线程块派发给各 SM 的本地调度器。核心规模扩大后，L2 Cache 被放在芯片中部，便于 CUDA Core 之间快速搬运数据。

Fermi架构：16个 SM 围绕一个的L2 Cache部署。每个SM是一个垂直的矩形，包含一个橙色部分（调度器和分派单元）、一个绿色部分（执行单元）以及浅蓝色部分（寄存器文件和L1 Cache）

恩里科·费米是意大利裔美国物理学家，20 世纪核物理、量子力学与统计力学领域的代表人物，被称为原子能时代之父。主要贡献包括：
- 提出费米子统计，即费米-狄拉克统计，用以描述半整数自旋粒子的统计规律。
- 主导芝加哥大学“费米堆”计划，实现了全球首座自持核链式反应堆。
- 参与曼哈顿计划，在原子弹研发中发挥关键作用。
- 因在放射性同位素研究上的卓越成就，获 1938 年诺贝尔物理学奖。

Fermi 采用第三代流处理器，每个 SM 配备 16 个加载/存储单元 LD/ST，可为每个时钟的 16 个线程计算源地址与目标地址，并把数据搬入缓存或 DRAM。特殊功能单元 SFU 负责超越函数如正弦、余弦、求导、平方根，每条线程每时钟执行一条 SFU 指令，一个 Warp 需 8 个时钟周期完成。SFU 管线与调度单元解耦，调度单元在 SFU 占用时可向其它执行单元发指令。双精度是 HPC 核心，每个 SM 每时钟可执行多达 16 次双精度融合乘加。

每个 SM 拥有 2 个 Warp 调度器与 2 个指令调度单元，可同时发出并执行 2 个 Warp。CUDA 内核以并行方式运行，每个 CUDA 处理器包含完整流水线的整数 ALU 与浮点单元 FPU，可选 FP32 或 INT8 计算，但浮点与整数单元不并行执行。

一个并行 Kernel 由三层线程组织，见图 4.1.3：Thread、Block、Grid。线程层可使用本地内存，块层使用共享内存，网格层使用全局内存，对应线程私有、块共享、应用全局的存储空间。

#### 2. Kepler 架构

2012 年 NVIDIA 发布 Kepler 架构。Kepler GK110 由 71 亿晶体管构成，在台积电 28 nm 工艺下双精度吞吐量超过 1 TFLOP，单位功耗性能约为 Fermi 的 3 倍。如图 4.1.4 所示，架构最多支持 15 个 SMX 单元和 6 个 64 位内存控制器，内存子系统增加额外缓存，各层存储带宽提升，DRAM I/O 更快并为编程模型提供硬件支持。

约翰内斯·开普勒是德国天文学家、数学家，被视作现代天文学奠基人之一，主要成就包括：
- 提出行星运动三大定律。
- 通过观测确立椭圆轨道理论，颠覆了传统圆周运动观念。
- 在光学、天文学与数学领域贡献突出，为牛顿引力理论奠定基础。

如图 4.1.5 所示，Kepler 把流式多处理器更名为 SMX，概念上沿袭 Fermi。每个 SMX 集成 4 个 Warp 调度器与 8 个指令调度单元，可同时发送并执行 4 个 Warp。Fermi 每 SM 32 核，Kepler 提升至 192 核，并行能力大幅提高。Fermi 最大线程数 1536，Kepler 提升到 2048。每个 SMX 配备 64 个双精度单元、32 个 SFU 与 32 个 LD/ST 单元，完全覆盖 HPC 需求。

Kepler 支持动态并行，可在无需 CPU 干预的情况下自动同步，并在运行时灵活调整并行数量与形式。Hyper-Q 让多个 CPU 核心共用单张 GPU，提升利用率并减少 CPU 空闲，支持 32 个硬件管理连接，允许多 CUDA 流并行处理。网格管理单元 GMU 用于动态并行和调度控制，可挂起或暂停网格直至运行环境就绪。

#### 3. Maxwell 架构

2014 年 NVIDIA 推出 Maxwell 架构。如图 4.1.6 所示，相较 Kepler 并无颠覆性改动，流式多处理器名称恢复为 SM，整体核心数降至 128，通过超额分配线程数来增强并行能力。

Maxwell 的 SM 采用象限设计，每个 SM 由 4 个处理块构成，每个处理块 32 核并拥有专属 Warp 调度器，可在每个时钟调度两条指令。每个 SM 提供 8 个纹理单元、1 个几何处理引擎，以及专用的寄存器文件与共享内存。单核性能比 Kepler 高 1.35 倍，性能功耗比约为 Kepler 的 2 倍。

詹姆斯·克拉克·麦克斯韦是 19 世纪英国物理学家，电磁理论之父。主要成就包括：
- 提出麦克斯韦方程组，统一电磁与光学规律。
- 发展统计力学，提出麦克斯韦-玻尔兹曼分子速度分布。
- 提出色散理论，解释光的色散现象。
- 预言电磁波存在，为无线电通信奠基。

与 Kepler 对比，Maxwell 拥有更大专用共享内存，共享内存与 L1 Cache 分离，每个 SM 可配置 64 KB 共享内存，GM204 提升至 96 KB。与 Fermi、Kepler 相同，每个线程块最大共享内存仍为 48 KB。Maxwell GM204 的 L2 Cache 是 Kepler GK104 的 4 倍，对带宽受限应用提升明显。每个 SM 可并发的线程块从 16 个增至 32 个，有助于小线程块内核的利用率。32 位整数的本机共享内存支持原子操作，线程块内列表与栈类数据处理更高效，同样支持动态并行。

#### 4. Pascal 架构

2016 年 NVIDIA 发布 Pascal 架构，图 4.1.7。架构在应用场景、内存带宽与制程上实现多项创新，系统内存由 GDDR5 升级为 HBM2，可在更高带宽下处理更大数据集。采用 16 nm FinFET 工艺，集成 153 亿晶体管，相同功耗下算力提升一个数量级，并首次引入第一代 NVLink，实现跨机带宽扩展。

GP100 由图形处理簇 GPC、纹理处理簇 TPC、流式多处理器 SM 与内存控制器构成。完整 GP100 包含 6 个 GPC、60 个 Pascal SM、30 个 TPC，每 TPC 含 2 个 SM，以及 8 个 512 位内存控制器，共 4096 位。每个 GPC 含 10 个 SM，每个 SM 有 64 个 CUDA Core 与 4 个纹理单元。GP100 共 60 个 SM，合计 3840 个单精度 CUDA Core 与 240 个纹理单元。每个内存控制器连接 512 KB L2 Cache，每个 HBM2 DRAM 由一对控制器管理，整体 L2 Cache 4096 KB。

Pascal 在 SM 内部做精简，SM 数量随工艺提升而增加。单个 SM 仅保留 64 个 FP32 CUDA Core，远少于 Maxwell 的 128 核与 Kepler 的 192 核，并分为 2 个区块，每区块 32 个单精度 CUDA Core、1 个指令缓冲区、1 个 Warp 调度器与 2 个调度单元。寄存器文件规模不变，每个线程可使用更多寄存器，单个 SM 可并发更多 Thread、Warp、Block，进一步提升并行处理能力。

#### 5. Volta 架构

2017 年 NVIDIA 推出 Volta 架构，GV100 GPU 集成 211 亿晶体管，采用 TSMC 12 nm 工艺。主要创新包括：
- CUDA Core 拆分，FPU 与 ALU 分离，取消整体 CUDA Core 硬件概念，一条指令可同时执行不同计算，提升 CUDA 应用的灵活性、生产力与可移植性。
- 独立线程调度，改进 SIMT 模型，每个线程拥有独立程序计数器与栈，支持并行线程间更细粒度同步与协作。
- 为深度学习优化 SM 架构，首次引入 Tensor Core 加速卷积计算。
- NVLink 升级为第二代，一个 GPU 可连接 6 个 NVLink，16 GB HBM2 内存子系统峰值带宽 900 GB/s。
- 提出 MPS 概念，允许多个应用共享 GPU 执行资源，客户端数从 Pascal 的 16 个提升到 48 个，支持多推理任务并发。
- 优化 GPU 加速库 cuDNN、cuBLAS、TensorRT，提升深度学习推理与 HPC 应用性能。

亚历山德罗·伏特是 18 世纪意大利物理学家，被誉为电池之父。主要成就包括：
- 发明伏特电堆，产生持续电流，是首个实用化学电池。
- 提出静电感应理论，推动电学理论发展。
