# 人工智能时代序言

## AI爆发期：人类将何去何从？

很荣幸《人工智能时代》能与中国读者见面。书中虽多引美式案例与数据，但我冀望能为华语圈关切的议题注入启发，或为窥见异文化图景开启一扇窗。书中探讨的自动化如何重塑工作本质、加剧贫富悬殊等命题，绝非美国独有；对中国而言，区别仅在于演变速度更疾，而AI技术极可能进一步按下加速键。

### 国富民不富：财富增长掩盖下的生存焦虑

美国用近两百年完成从农业向制造业的跨越，中国却在短短数十年内压缩完成了同质转型。美式节奏缓慢，劳工得以在相对平稳的环境中适应新生态，个体一生鲜经剧变；反观中国，工业化狂飙带来的后遗症也同步显现：海量农民进城催生的就业错配、技能供需脱节、以家庭为核心的传统生活版图被撕裂。

身处中国的每一个人，都切身感受着这场深刻变革。客观而言，中国适应高速工业化的韧性与成效，冠绝西方。这段经验或将助力中国更从容地接住AI带来的额外冲击。

但也必须直面：相较美国，中国高速发展衍生的某些顽疾更为棘手、陌生——贫富鸿沟持续扩张、对他者需求的漠视。自动化替代劳动力资本，导致掌握资本的富人收益膨胀。社会虽推崇拼搏、创新、冒险，使贫富差距看似合理，实则暗流涌动。

包括我在内的许多人深信：无限拉大的贫富差距，其毁灭性威胁或超越战争、恐怖主义等显性危机。美国过去半个世纪的痛史警示我们：社会总财富暴增，却不等于大多数人生活得更好。

因此，必须保障全体成员，不分阶层身份，均拥有公平合理的向上流动通道。惟公平，方能致稳。

### 工作本质的蜕变：从“体力竞赛”转向“人性高地”

即将到来的机器人、机器学习与电子助理，将开启全新世界：大量由人类承担的岗位将移交机器。但这不足为惧，因为人类专属的工作绝不会消失。现实是工作内核将重构，焦点转移至人类比机器更擅长的领域——建立情感连接、施予共情、展现独门绝技、创造美感、启迪青春、点燃有意义的行动。我坚信，未来工作的主旋律，必是需要人类独有技能的任务。

两百年前的美国农夫难以想象今日图景：仅2%人口养活全美，绝大多数人从事他们无法想象的职业——编程、房产交易、手机组装、网络广告、婚姻咨询、整形手术、售货机维修……这些不依赖重体力的劳动，在彼时根本不被视为“工作”。

同理，今天预测未来同样艰难。我们难以描绘：未来世界里，许多人或将从事设计基因花卉、主持云端聚会、电竞竞技、用VR带老弱病残“云游”、售卖适配3D打印的产品设计等市场化工作。
