2. 任务集合：`tasks` 收纳项目全部工作项，每项记录编号、名称、当前状态、预计耗时和对应负责人。
3. 进度汇总：`project_progress` 展示整体态势，统计已完成、在进行、未启动的任务数量，并标注项目现行状态。
4. 风险汇总：`project_risks` 列出可能出现的风险等级以及对应的潜在隐患。
5. 报告生成：`generate_task_report()` 通过 DeepSeek-V3 接口，把任务清单、进度汇总和风险信息一起送入模型，输出一份综合项目管理报告。
6. 调用执行：执行 `generate_task_report()` 即可得到报告并展示。
