## 12.10 示例

### 12.10.1 PGVector简介

本节示例选用 bert_base_uncased 模型生成词向量，并把向量存入 PGVector。

PGVector 是专为 PostgreSQL 设计的扩展插件，目标是在现有的 PostgreSQL 环境中直接完成向量检索与计算，无需额外引入独立的向量数据库。这样可以简化集成难度，尤其是对已经在使用 PostgreSQL 且希望快速增加向量支持的用户而言非常友好。

PGVector 的主要能力包括：

- （1）深度集成 PostgreSQL：作为 PostgreSQL 的扩展，PGVector 能在数据库内部存储和查询向量数据，无需迁移数据或调整应用架构。
- （2）SQL 易用性：使用标准 SQL 语法查询，方便习惯 SQL 的用户上手。
- （3）灵活的数据模型：可与普通表结构组合，查询时仍能用标准 SQL 表达。
- （4）新型索引：例如 Hierarchical Navigable Small Worlds（HNSW）索引，其核心思路是通过邻近向量间的连接提升性能和召回率，从而在近似查询中更精准地定位邻居。
- （5）快速距离计算：支持在 HNSW 等索引上加速距离计算。
- （6）并行构建索引：允许并行写入索引，便于多源数据同时加载。
- （7）更新与删除：支持对向量的更新和删除操作，而很多其他 HNSW 实现并不具备此功能。
