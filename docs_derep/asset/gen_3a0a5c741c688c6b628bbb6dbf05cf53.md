轮椅数据集
> 该数据集用于判断老年人或患者在轮椅上的坐姿是否正确。每个样本由轮椅上 3 个压力传感器和 1 个超声波传感器采集而来，输入维数是 4。压力传感器的量程是 0~1023，超声波传感器量程 0~15cm，分辨率 0.3cm。训练样本的标签取 1~4 四个整数，1 为坐姿正常，2 为偏右，3 为偏左，4 为前倾。整体共 308 个样本。

【实验1-1】给轮椅数据的输入向量做标准化并划分为训练集与测试集
要点可以参考：
- 数据是 308 行 5 列的表格，每行一个样本，前 4 列是输入，后 1 列是标签，标签取值 {1,2,3,4}。
- 随机抽 200 个样本做训练，剩下 108 个做测试。
- 按列做标准化 z_ij = (x_ij - μ_j)/σ_j，μ_j、σ_j 来自训练集第 j 维的均值和标准差。
- 用 import torch 导入框架。
- 用 torch.tensor 通过复制构造 tensor，可通过 dtype 与 device 指定类型与设备。
- 为了后续计算方便，输入向量用浮点型如 torch.float，标签用长整型如 torch.long，且把标签映射到 {0,1,2,3}。
- 均值标准差可用 torch.mean、torch.std，注意矩阵按列计算时 dim 设为 0，按行计算时 dim 设为 1。
- 随机打乱可用 torch.randperm，先用 torch.manual_seed 固定随机种子以便复现。
- 用 torch.cuda.is_available 判断是否可用 GPU。
- 若后续要在 GPU 上训练，训练集和测试集需搬到显存，可用 tensor.to 完成迁移。
若手写仍有困难，可参考附录 A 的带注释程序。

首次在 GPU 上跑 PyTorch，运行会相对慢一些，因为框架会对函数做即时 JIT 编译。

【实验1-2】用 PyTorch 搭建单隐含层多分类网络
要点可以参考：
- 隐含层 8 个神经元，用 ReLU 激活；输出层 4 个神经元，不加激活函数。
- 网络可用 torch.nn.Sequential 直接拼，也可继承 torch.nn.Module 自定义，本书采用继承的方式，更灵活。
- 在 __init__ 里创建并初始化各层参数，在 forward 里实现正向计算，反向由框架自动完成。
- 仿射映射用 torch.nn.Linear，激活用 torch.nn.functional.relu。
- Linear 的参数默认用均匀分布初始化，一般无需手动干预。
- Linear 的 in_features 对应输入在最后一维的大小，out_features 对应输出在最后一维的大小。
- 若使用 GPU，需把模型对象也搬到显存，同样用 to 方法。
参考实现见附录 A。

【实验1-3】用轮椅数据在 PyTorch 上训练上述网络
要点可以参考：
- 采用批梯度下降，即每次用全部训练样本更新参数；优化器用默认的 AdamW，通过 zero_grad 与 step 调用。
- 多分类常用交叉熵损失，用 torch.nn.CrossEntropyLoss 计算。注意其 input 应是输出层的仿射结果而非 softmax 之后的结果，这也是输出层不加激活的原因；target 需为 torch.long 类型，取值 0~c-1，与实验 1-1 的标签映射一致。
- 学习率取 0.1，epoch 取 60。
- 每次迭代顺序为：前向 → 计算损失 → backward → optimizer.step。每次 backward 前必须 optimizer.zero_grad 清零梯度，否则梯度会累加。
- 通常应调用模型对象而非直接调用 forward，以便触发已注册的钩子。
- 批训练时输入是一个 200×4 的二维数组。
- 记录每次迭代的损失便于绘图，保存时要把损失从计算图里分离出来，可用 item 或 detach。
- 绘图可用 Matplotlib。

当隐含层 8 个、学习率 0.1、epoch 60、随机种子 0 时，损失随迭代的变化如图 1-3。整体看损失随迭代递减，说明训练在推进；过程中有波动是因为神经网络的损失通常不是凸函数。本例并未手工给出偏导公式，却能借助 PyTorch 的自动微分完成有效训练。
