2. 生产部：两极分化突出
中位数 5,000 元与修剪均值 5,277.78 元接近，但技术总工 25,000 元为明显离群点。剔除后中位数保持 5,000 元，基层多集中在 4,200～6,500 元。技术岗薪资约为普通员工 5 倍以上，存在公平性质疑，建议通过透明化绩效奖金或优化职级体系缓解。

3. 后勤部：分布较为均衡
中位数 3,500 元与修剪均值 3,400 元相近，薪酬相对均匀。保安、保洁等岗位差异小，约 2,200～3,500 元，部长 5,500 元高于基层，符合常规层级差异。

中位数与修剪均值同为 4,200 元，部门仅 3 人，分布简单。部长 6,500 元与质检员 4,200 元差距合理，需关注质检员薪酬是否贴合市场以保持竞争力。

整体来看，高层薪资显著高于其他部门，生产部内部差异最大，后勤部最平均，质保部层级分明。通过对比中位数与修剪均值的偏离，可识别分布偏态及异常值影响，企业应审视薪酬合理性、公平性与市场匹配度，并据此制定优化方案。
