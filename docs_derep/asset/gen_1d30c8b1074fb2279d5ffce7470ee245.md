数据采集常用路径

（6）API 获取：API 即应用程序编程接口，由一组规范和协议构成，用来约定不同软件之间如何交互、如何交换数据。通过 API 抓取数据是行之有效的做法，能够让程序直接向其他应用、服务或平台索取信息，特别适合需要从外部网站或服务拉取数据的场景。

（7）专业数据库查询：专业数据库是聚焦特定领域的知识库，汇集了大量资料、文献、研究成果和统计数据。不同学科有不同的数据库，比如覆盖生物医学和生命科学的 PubMed，综合性的学术库 Web of Science，以及深耕金融的数据服务平台万得数据库等。各库各有侧重，为科研人员、学生和从业者提供了关键的信息支撑。

（8）公开数据源：这类数据集由政府、机构或个人免费公开，可在公共数据库、开放政府数据平台等渠道找到。优势在于免费且覆盖面广，常用在教学、科研和公共政策分析中。选用时要注意数据的质量、准确度、时效性以及对应的使用条款。

（9）传感器数据：传感器能感知并测量物理量，与目标对象结合后可采集温度、湿度、压力、位置、速度等多种参数。传感器数据体量大、频率高、类型多样，处理时需兼顾实时性、准确性和安全性。

每种取数方式都有各自特点和适用范围，选对方法直接关系到数据的质量和相关性。

**4. 数据收集的标准流程**

基础的数据收集流程如下。

（1）明确研究问题与目标：在动手采集前，先厘清想解决的问题和期望达成的目的，这决定了需要采集何种类型的数据。

（2）设计研究方法：确定采用哪种方式采集数据，可能包括问卷调查、访谈、观察、实验、爬虫、专业数据库查询等，方法选择要与研究问题和目标相匹配。

（3）制定采集计划：做出详细方案，明确采集方式、所需资源、时间安排，同时包括样本甄选、数据采集工具如问卷设计等。

（4）选择抽样方法与样本：根据研究性质挑选合适的抽样方式。数据分析师常用四种：简单随机抽样、分层抽样、整群抽样和系统抽样，各有优劣。此环节对保证数据代表性和准确性至关重要，选对抽样方式才能从目标群体中获得可推广的样本。

（5）执行数据采集：按计划开展工作，可能涉及发放回收问卷、开展访谈、实施实验、编写爬虫程序等。整个过程要持续关注数据质量，高质量采集是得出有意义结论的前提。

（6）数据清洗：采集回来的数据通常需要预处理，包括录入、修正错误或不完整的回答、编码开放式问题等。清洗的本质是消除错误和不一致，保证准确。包括修正明显错误如拼写、范围错误、处理缺失值是填补删除还是保留、识别并处理异常值。清洗质量直接影响后续分析。

（7）评估数据质量：在每个预处理步骤后都要评估质量，检查是否完整、一致、能否支撑研究问题。重点还要评估样本代表性，即样本是否足够反映总体的多样性。若发现偏差，可能需要补充抽样或调整研究方法。

以上框架完整全面，可根据具体研究需求灵活调整定制。

**3．数据增强**

数据增强是通过让有限数据产生更多等价样本来人工扩充训练集的技术，是解决深度学习数据稀缺问题的关键，医学影像分析等领域尤为常见。它能提升训练集规模和质量，帮助构建更强的模型。在计算机视觉中常见做法有几何变换、颜色调整、旋转翻转、噪声注入、卷积核滤波、图像混合、随机擦除、缩放平移等，多由 imgaug 等库支持。基于深度学习的增强如特征空间增强、对抗生成和 GAN-based 方法进一步提升多样性。
