## 6.5 进度一目了然：甘特图怎么用

甘特图，又称 Gantt chart，核心就是把工作内容与时间轴对应起来。横向是时间刻度，纵向是任务清单，每项工作用一条横向色块表示，色块长度对应工期，位置对应开始与结束。团队借此可以掌握执行状态、提前发现风险、重新排定优先级，也便于对外同步计划安排。Todo List 的示例可参考图 6-4。
[PRE2]
图 6-4 Todo List 项目计划甘特图

甘特图既能手绘，也能借助专业软件来做，市面上常用的选择有：

（1）Microsoft Project。微软出品的专业项目管理套件，甘特图功能强大且可定制，能与 Excel、Word 等办公软件联动。演示用的 Todo List 效果见图 6-5。

（2）Asana。团队协作平台，自带甘特视图，支持任务指派、工时统计、依赖设置、进度汇报以及虚拟看板。

（3）Trello。轻量协作工具，提供简化的甘特展示，可建立清单、标签、备注、附件并设定截止时间，按时间线归类。

（4）Smartsheet。云端协作平台，界面类似表格，同时提供甘特图、时间表、任务分派、资源调配与自定义报表。

（5）TeamGantt。专注甘特图的在线服务，帮助团队制定并共享计划，支持任务分配、时长追踪、进度报告、评论与文件共享。

（6）Excel 也能绘制甘特图，Todo List 示例见图 6-6，但灵活度不及专用软件。Excel 不会自动推算任务依赖，也缺少完善的进度追踪，面对复杂项目时专业工具更可靠。
