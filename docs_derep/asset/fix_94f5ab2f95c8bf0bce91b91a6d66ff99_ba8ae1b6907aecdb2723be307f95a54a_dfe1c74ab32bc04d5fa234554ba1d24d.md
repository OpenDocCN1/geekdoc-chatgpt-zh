# 导言
在2005年出版的《奇点临近》里，我提出若干收敛且指数增长的技术动向正在驱动一场彻底改写人类社会的转型。计算愈发廉价，人类生命科学愈发清晰，工程尺度愈发微小。随着人工智能能力攀升与信息获取更便捷，我们正将这些能力与天生的生物智能愈加紧密地结合。最终，纳米技术将把趋势推向顶点，直接以云端虚拟神经元层扩展我们的大脑。我们将与人工智能融合，获得远超生物本能数百万倍的计算增强，从而极大拓展智力与意识，以至于难以想象。我所说的奇点，便是指此。

“奇点”一词源自数学中函数无定义点，如除以零，以及物理学中黑洞中心无限密度的点，常规物理定律在此失效。但需记住，我的使用是隐喻。关于技术奇点的预言并不意味着变化率会真正无限，指数增长不等同于无限，物理奇点亦不等同于无限。黑洞引力足以捕获光，但量子力学并无解释真正无限质量的机制。我借用此隐喻，是因它捕捉了以当前智力水平无法理解根本性转变的困境。但转变一旦发生，我们的认知能力会迅速提升以适应之。

正如《奇点临近》所详述，长期趋势指向约2045年。书出时那仍是四十年后，两代人之遥。在那种距离上，我只能对带来转型的宏观力量做推断，而对多数读者而言，2005年的话题仍很遥远。当时许多评论者认为时间表过于乐观，甚至认为奇点不可能。

此后发生了非凡之事。进步无视怀疑持续加速。社交媒体与智能手机从近乎不存在变为无处不在的伴侣，如今连接全球绝大多数人口。算法创新与大数据的出现让人工智能以专家未料的速度取得惊人突破，从掌握《危险边缘！》到自动驾驶、撰写文章、通过律师资格考试、诊断癌症。如今GPT-4、Gemini等强大灵活的大语言模型能把自然语言指令转为计算机代码，大幅降低人机隔阂。你读到此文时，或已有数千万人亲身体验这些功能。与此同时，人类基因组测序成本已下降约99.997%，神经网络通过数字化模拟生物学解锁重大医学发现。我们甚至已能让计算机直接连入大脑。

这些发展的基础是我称之为加速回报定律：如计算等信息技术呈指数级变便宜，因每次进步都让设计自身下一阶段的进化更易。因此在我动笔时，一美元可买到的计算能力经通胀调整后，已是《奇点临近》上架时约11200倍。

下图概括了推动技术文明的最重要趋势：在对数尺度上近似为直线的长期指数增长，即恒定美元可购买的计算能力。我将在书中后文深入讨论。摩尔定律观察到晶体管持续微缩，使计算机愈强，这只是加速回报定律的一种表现，该定律早在晶体管发明前就已成立，并在晶体管触及物理极限被新技术取代后预计仍将延续。此趋势定义了现代世界，且本书讨论的几乎所有即将到来的突破都将直接或间接由它驱动。

为提高机器可比性，该图聚焦可编程计算机时代的性价比，但早期机电计算设备的近似值表明，这种趋势至少可追溯至19世纪80年代。[\[2\]](#18_Notes.xhtml#EndnoteNumber1 "note")

因此我们一直沿着奇点的时间表前行。本书的紧迫性源于指数变化的本质。本世纪初尚显微弱的趋势，如今正积极影响数十亿人的生活。2020年代初，我们已进入指数曲线急剧陡峭段，创新步伐以前所未有的方式冲击社会。便于理解，你此刻阅读的时点，可能比我2012年出版的《如何创造一个心灵》更接近首个超人类人工智能的诞生。也可能比1999年出版的《精神机器的时代》发行时更接近奇点。以人类寿命衡量，今天出生的婴儿在奇点到来时正好大学毕业。从个人层面看，这与2005年相比，是截然不同的“近”。

这正是本书缘起。人类数千年走向奇点的征程已变成冲刺。《奇点临近》导言中我写道，当时我们正处于“这一转变的早期阶段”。现在我们正进入高潮。那本书是关于遥远视野的瞥见，而本书是关于沿着道路抵达最后几英里。

幸运的是，这条道路如今更清晰。虽然实现奇点前仍有诸多技术挑战，但其关键先兆正迅速从理论科学转向积极研发。未来十年，人们将与看似可信的类人人工智能互动，而简单的脑机接口将像今日智能手机一样影响日常生活。生物技术领域的数字化革命将治愈疾病，并有意义地延长健康寿命。但与此同时，许多工人将感受到经济冲击的刺痛，我们所有人都将面临因意外或故意滥用新能力而带来的风险。2030年代，自改进人工智能与成熟纳米技术将以前所未有的方式把人类与制造物结合，进一步加剧希望与危险。若我们能应对这些进步带来的科学、伦理、社会与政治挑战，到2045年，地球上的生命将被深刻改善。若我们失败，生存本身将受质疑。因此，本书关乎我们最终逼近奇点——在这一代人所知的世界中，机遇与必须共同面对的危险。

首先，我们将探讨奇点如何发生，并将其置于我们物种长期重塑自身智能的背景下。用技术创造知觉会引发重要哲学问题，因此我们将探讨这种转变如何影响身份与目标感。然后，我们将转向未来数十年显现的实际趋势。正如我将展示，加速回报定律正在推动反映人类福祉的各类指标指数增长。然而，创新最明显的副作用之一是自动化带来的失业。虽然危害真实存在，但仍有充分理由对长期保持乐观——我们最终不会与人工智能竞争。

随着技术为文明解锁巨大物质财富，我们的焦点将转向克服充分繁荣后的下一个障碍：我们生物学的脆弱性。因此，接下来我们将展望未来数十年将使用的工具，以获得对生物学本身日益强大的掌控——首先战胜身体衰老，然后增强有限的大脑并迎来奇点。然而，这些突破也可能带来危险。生物技术、纳米技术或人工智能领域的革命性新系统可能导致生存灾难，例如毁灭性流行病或自我复制机器的连锁反应。最后，我们将评估这些威胁，它们需要审慎规划，但正如我将解释，有非常有希望的方法可以减轻风险。

这是历史上最激动人心且意义重大的数年。我们无法确信奇点后的生活会是什么模样。但通过理解并预测导致奇点的转变，我们可以帮助确保人类的最终路径安全且成功。

# 第一章：进化链上我们身在何处

在《奇点临近》中，我把意识的基础描述为信息。我列出自宇宙诞生以来的六个纪元或阶段，每个阶段都以前一个阶段的信息处理为基础创造下一个阶段。因此，智能的进化是通过其他过程的间接序列实现的。

第一个纪元是物理定律及其促成的化学的诞生。大爆炸后几十万年，原子由围绕质子中子核心旋转的电子形成。原子核中的质子本应因电磁力而猛烈排斥，然而恰好存在一种称为强核力的独立力量将质子结合在一起。“无论谁”设计了宇宙规则，都提供了这种额外力量，否则原子的演化不可能发生。

数十亿年后，原子形成了能够承载复杂信息的分子。碳是最有用的组成部分，因为它可形成四个键，而许多其他原子只能形成一个、两个或三个键。我们生活在一个允许复杂化学反应的世界，这是极其罕见的。例如，若引力稍弱，就不会有超新星创造构成生命的化学元素。若引力稍强，恒星会在智能生命形成前燃尽死亡。仅这一物理常数就必须处于极狭窄范围内。否则我们不会在此。我们生活在一个非常精确平衡的宇宙中，这种平衡允许一定程度的秩序，从而使进化展开。

几十亿年前，第二纪元开始：生命。分子变得足够复杂，可在一个分子中定义完整有机体。因此生物得以进化与传播，每个生物都有自己的DNA。

在第三纪元，由DNA描述的动物形成了大脑，这些大脑本身存储和处理信息。这些大脑提供了进化优势，有助于大脑在数百万年间发展出更多复杂性。

在第四纪元，动物利用高级认知能力，以及拇指，将思想转化为复杂行动。这就是人类。我们的物种利用这些能力创造了能够存储和操纵信息的技术——从纸莎草到硬盘驱动器。这些技术增强了我们大脑感知、回忆和评估信息模式的能力。这是进化的另一个来源，其本身远大于之前的进步水平。有了大脑，我们大约每10万年增加一立方英寸脑物质，而有了数字计算，我们大约每16个月就能使性价比翻一番。

在第五纪元，我们将直接把生物人类的认知与数字技术的速度和力量融合起来。这就是脑机接口。人类神经处理速度是每秒几百个周期，而数字技术是每秒几十亿个周期。除了速度和内存大小，用非生物计算机增强我们的大脑将使我们能够在新皮层中增加更多层——释放出比目前能想象的更复杂和抽象的认知。

第六纪元是我们的智能遍布整个宇宙的时期，将普通物质转化为计算物质，即以最终计算密度组织的物质。

在我1999年出版的《精神机器的时代》中，我预测图灵测试——即人工智能可通过文本交流且与人类无法区分——将在2029年通过。我在2005年的《奇点临近》中重申了这一点。通过有效图灵测试意味着人工智能已掌握人类所拥有的语言和常识推理能力。图灵在1950年描述了他的概念，[\[1\]](#18_Notes.xhtml#EndnoteNumber2 "note")但未具体说明测试方式。在我与米奇·卡普尔的赌局中，我们定义了自己的规则，比其他解释更困难。

我的预期是，为在2029年通过有效图灵测试，我们需要在2020年前通过人工智能实现各种智力成就。事实上，自我做出该预测以来，人工智能已掌握人类许多最严峻的智力挑战——从游戏如《危险边缘！》到放射学和药物发现等严肃应用。在我写作时，像Gemini和GPT-4这样的顶级人工智能系统正在将能力扩展到多个性能领域——这是通向通用智能道路上令人鼓舞的步伐。

最终，当程序通过图灵测试时，它实际上需要在许多领域让自己显得远不如智能，否则很明显它是一个人工智能。例如，若它能立即正确解决任何数学问题，它将无法通过测试。因此，在图灵测试水平，人工智能将在大多数领域实际上远超最优秀的人类。

人类现在处于第四纪元，我们的技术已产生一些我们无法理解的任务结果。对于人工智能尚未掌握的图灵测试各方面，我们正在取得快速且加速的进展。通过我一直期待在2029年实现的图灵测试，将使我们进入第五纪元。

2030年代的一项关键能力是将我们新皮层的上层范围连接到云端，这将直接扩展我们的思维。这样，人工智能将不再是竞争对手，而将成为我们自身的延伸。到那时，我们思想的非生物部分将提供比生物部分多数千倍的认知能力。

随着这种情况呈指数增长，到2045年，我们将把思想扩展数百万倍。正是这种难以理解的速度和转变的幅度，使我们能够从物理学中借用奇点这一隐喻来描述我们的未来。

# 第二章：重塑智能

## 重塑智能

### 智能重构的核心含义是？

如果宇宙的整体故事是一个不断演变的信息处理范式的过程，那么人类的篇章是从中途开始的。在这个更大的叙事中，我们的阶段最终关乎从拥有生物大脑的动物向超越存在的转变，这些存在的思想和身份不再受基因提供的束缚。在2020年代，我们将进入这一转变的最后阶段——在更强大的数字基质上重塑自然赋予的智能，然后与之融合。通过这样做，宇宙的第四个纪元将孕育出第五个纪元。

但这一切将如何更具体地展开？为了理解重塑智能的含义，我们将首先回顾人工智能的诞生以及从中产生的两个广泛学派。为了了解为何其中一个学派胜过另一个，我们将把它与神经科学告诉我们的关于小脑和新皮层如何产生人类智能的认识联系起来。在调查深度学习目前如何重新创造新皮层的能力之后，我们可以评估人工智能仍需达到何种程度才能达到人类水平，以及我们如何知道它何时达到。最后，我们将转向在超人人工智能的帮助下，我们将如何设计脑机接口，从而通过虚拟神经元层大大扩展我们的新皮层。这将释放全新的思维模式，并最终将我们的智力扩展数百万倍：这就是奇点。

### 人工智能的诞生

1950年，英国数学家艾伦·图灵在《心灵》杂志上发表文章“计算机械与智能”。[\[1\]](#18_Notes.xhtml#EndnoteNumber3 "note")其中，图灵提出了科学史上最深刻的问题之一：“机器能思考吗？”虽然思考机器的想法至少可追溯至希腊神话中的青铜自动机塔洛斯，[\[2\]](#18_Notes.xhtml#EndnoteNumber4 "note")图灵的突破在于将这个概念提炼成可经验检验的东西。他提出使用“模仿游戏”（我们现在称之为图灵测试）来判断机器计算是否能执行与我们大脑相同的认知任务。在这个测试中，人类评委通过即时通讯采访人工智能和人类陪衬，但看不到他们正在与谁交谈。然后，评委们提出关于他们希望的任何主题或情况的问题。如果在一段时间后，评委无法分辨哪个是人工智能回复者，哪个是人类，那么就说人工智能通过了测试。

通过将这一哲学想法转化为科学想法，图灵激发了研究人员的极大热情。1956年，数学教授约翰·麦卡锡提议在新罕布什尔州达特茅斯学院举行一项为期两个月、十人参与的研究。[\[3\]](#18_Notes.xhtml#EndnoteNumber5 "note")目标如下：

> 这项研究将基于这样的推测进行：学习或任何其他智能特征的每个方面原则上都可以被精确地描述，以至于可以制造一台机器来模拟它。将尝试找到如何使机器使用语言，形成抽象和概念，解决现在为人类保留的各种问题，并改进自身。[\[4\]](#18_Notes.xhtml#EndnoteNumber6 "note")

在为会议做准备时，麦卡锡提议将这个最终将自动化所有其他领域的领域称为“人工智能”。[\[5\]](#18_Notes.xhtml#EndnoteNumber7 "note")鉴于“人工”使这种形式的智能看起来“不真实”，我并不喜欢这个名称，但它是经久不衰的术语。
