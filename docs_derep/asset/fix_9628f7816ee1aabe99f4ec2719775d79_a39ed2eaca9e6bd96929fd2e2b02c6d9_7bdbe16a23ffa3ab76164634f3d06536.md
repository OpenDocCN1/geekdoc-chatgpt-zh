# 序言 人类潜能的开启

工作、生活与价值创造的模式正在被深刻重塑。很多人将其归为纯粹的技术浪潮，我们看到的是人机关系重塑、人类特质被放大的契机。

我们是一支由27位从业者组成的跨界团队，背景涵盖商业、学术、工程与研究，因同一个信念聚在一起：让技术为人服务。有人主导过企业级自动化落地，有人深耕人工智能前沿研究，有人为世界500强提供咨询，也有研究技术变革的社会影响。凝聚我们的不仅是能力，更是共同坚持：技术应放大人的潜能，而非取代人。

本书的起点可以追溯到多年以前，当时我们尚未觉察方向。团队中不少人是全球范围内部署智能自动化的先行者，早期尝试将人工智能与机器人流程自动化结合，用来处理愈发复杂的端到端业务流程。这段实践催生了2020年合著的《智能自动化》¹一书，帮助众多企业重新思考数字化转型。

我们当时并未意识到，这是在为更有颠覆性的成果铺路。过去十多年，我们搭建的智能自动化体系——把流程自动化与人工智能结合处理结构化工作流——已成为当今智能体系统的基石。逻辑很自然：系统学会自主行动前，必须先掌握执行流程、处理数据、在既定边界内做决策的基础技能，而这正是我们长期深耕的能力。

这段积累让我们在生成式技术打开现代智能体之门时，拥有独特的先手经验。我们已在可靠流程自动化、异常处理、系统集成，以及以增强而非替代人为核心的应用方式上积累了经验。企业在探索智能体时，多半也是从成熟的智能自动化平台演进，在已验证的底座上构建更精密、更自主的能力。

我们保持谦逊。即便经验丰富，也明白需要持续学习。该领域变化极快，新可能性几乎日日涌现。我们的差异化贡献不只在技术或商业专长，更在于懂得如何以促进人类繁荣的方式运用这些技术。

目标不只是解释技术。我们希望为个人与企业提供工具，塑造更美好的世界：劳动者拥有更有意义的工作并能兼顾生活；企业运营更高效的同时提供卓越客户体验；医疗系统通过更智能的护理协调拯救更多生命；学校能为每个学生提供个性化有效学习；社区能更明智地利用资源破解复杂难题。人工智能的核心不在自动化，而在关键处创造真正影响。

本书面向所有觉察变革重要性并希望准备应对的领导者、从业者、企业家与好奇者。无论你是推动转型的企业高管、对职业前景感到好奇的专业人士，还是关心技术如何重塑世界的人，这里都有实用指引。

我们正处历史关键节点。此刻对技术实施与引导的决策，将对后代产生深远影响。

本书将分享来自成败的经验、行业中的模式，以及我们认为新时代至关重要的原则。

让我们携手前行，指引不仅是技术的可能性，更是“技术能帮助我们成为怎样的人”这一愿景。

# 引言 生成式AI是否找错了重点

设想你的竞争对手宣布运营团队规模只有你的一半，业绩增速却是你的两倍。秘诀何在？他们部署了AI智能体。智能体能自主处理客户服务到运营的全部事务，数小时内完成你团队需要数周的工作。

听起来难以置信？它正在发生。更直白地说，当多数企业还在琢磨用ChatGPT写邮件、做聊天机器人时，一批新企业已在根本上重构人工智能的可能性。它们不只是自动化任务，而是在打造可弹性扩展、持续适应、永不休眠、自主运行的企业体系。

但存在一个阻碍多数企业进步的悖论：我们已拥有能出色思考的生成式系统，实际上却什么都做不了。它们能在数秒内解析复杂数据、撰写精彩演示、就任何话题提供洞见，却按不了按钮、发不了邮件、做不了简单预订。我们创造了一个才华横溢的“顾问”世界，却连动一根手指都帮不上。

这不仅低效，更有害。各行业的会议室里，我们看到一个令人担忧的现象：人工智能在思考分析上越先进，就有越多的人被迫处理机械重复的工作。知识型员工如今将高达60%的时间花在“关于工作的事”上——在系统间搬运数据、核对AI生成内容、手工执行AI建议¹。

正如合著者之一大卫所说：“我们把人类当成机器人，把人工智能当成创意工作者。是时候扭转了。”

凭借几十年为各类型企业落地AI解决方案的经验，我们发现这种模式令人不安且反复出现。企业投入数百万美元购入前沿技术，结果员工花在管理系统上的时间超过做有意义工作的时长。机器负责想象，人类负责苦干。

我们如何走到这一步？又该如何解决？

下面三个源自真实经历的故事揭示了生成式系统的潜力与关键局限，说明传统做法为何失效，并指向根本转变：弥合人工智能在“思考”与“行动”之间的鸿沟。

阅读时你或许会产生共鸣，更重要的是你会明白：AI的下一步演进，不在于让机器更聪明，而在于让它们能够自主行动。

## 度假构想：机器空想，人类加班

周六夜，布莱恩家中客厅被笔记本柔光映亮。孩子们刚入睡，妻子在楼上阅读。他想为全家规划梦寐以求的希腊之旅，孩子们在学校迷上了希腊神话。

晚上8点37分，他打开ChatGPT。输入“给四口之家两周希腊行程”，并补充神话兴趣。几秒后，AI给出精致方案：清晨避开人群的卫城、博物馆互动展、普拉卡区家庭酒馆“橄榄树”，庭院弥漫茉莉香……还考虑了儿子爱画古建筑、女儿痴迷神话。进一步要求按小时细分后，AI给出拍摄黄金时段与休息安排。

然而夜过10点，惊叹转为沮丧。那家酒馆早已永久关闭，“隐秘海滩”在任何地图上找不到，烹饪课半年前就订满。到11点30分，桌面像案发现场：几十个浏览器标签、追踪航班的表格、酒店截图、旅行社PDF。AI的完美行程静躺在文档里，而布莱恩在做实事：核对航班可行性、比价、试图把幻想变可预订。

“我本想用一晚时间畅想旅程，”他后来反思，“却花了好几个小时处理本以为AI会搞定的琐事。”

这凸显了期望与现实的差距。我们希望技术处理烦琐部分：浏览航班、交叉核对评论、在多平台查可用性。AI在发散构想、冒险建议、描绘画面上极强，却把所有执行细节丢给人。

讽刺的是，最先进的AI会写诗、解释量子物理，却做不了查一家酒店是否营业这种基本事。它能构想完美假期，却订不了机票。

凌晨1点他上床，一无所获。浏览历史记录：47个网站、多次搜索、多次清空购物车。完美行程像来自平行世界的旅游杂志，一切如想象般运行。

这一模式在各行业反复出现。无论规划项目、协调多团队、推出新产品，局限相同：生成式系统展现非凡能力与令人担忧的短板。

这就像请了一屋子顾问却无法落地建议。它们在战略与创意上出色：生成策略、制定计划、理解需求、个性化建议、讲好故事。但缺乏真正变革性的能力：

• 在现实世界执行操作；
• 核实信息并实时更新；
• 条件变化时调整计划；
• 长期保持一致行动以达成目标。

最令人不安的是发展方向的错位。让我们骄傲的人类特质——创造力、深度情感联结、批判思维——本应带来满足感与创新。如今AI在此领域出色，撰写营销文案、构思颠覆性产品、做复杂分析。与此同时，人类被降格为数据录入、跟进、数字管家——本该由AI承担的枯燥岗位。

人类成了连接系统的“机器人”，AI负责构想可能性，这种颠倒说明我们对AI的使用存在根本错位。这种能力与需求的错位影响深远……

## 科研险案：AI编造现实

故事基于真实事件，姓名细节已做处理。

联合国气候变化峰会前48小时，杰西卡·英博士盯着屏幕发呆。她的研究将影响国际粮食安全政策与数十亿美元农业投资。但草稿令人沉重。

三周前她接到噩耗，父亲突发严重脑卒中。她飞往新加坡陪伴父亲临终，将收尾工作交给博士后与助理。“用任何工具，”她在视频里说，“只要确保核实无误。”

团队借助AI按时完成庞大分析。现在杰西卡回到研究所，发现问题。

“你怎么验证的？”深夜会议上她问首席研究员汤姆。

汤姆打开多个AI对话窗口，里面有看似令人信服的分析与引用。“AI分析了所有数据集，”他说，“发现了我们未想到的模式。”

杰西卡深入后警铃大作。AI生成了关于非洲气候对作物影响的叙述，但所引论文根本不存在。东南亚农民适应策略的统计数据与任何已知研究不匹配。

“我们以为很严谨，”汤姆承认，“让AI在多轮对话中交叉验证。但每个对话独立，有时相互矛盾。”

若未经核查提交，可能误导投资、影响政策、毁掉她20年声誉、削弱公众对气候研究的信任。

桌上有一张父亲在她毕业典礼的照片。父亲曾教她：科学里，未经验证的自信毫无意义。

时间临近，她决定取消主题演讲。团队需数周手工核对每个数据点、交叉校验来源、重建分析。

这次险些酿祸凸显了能力与局限的危险差距。AI能生成看似专业的科研内容，却缺少事实核查、保持一致、比较来源、随时间构建连贯论证等关键能力。

## 连贯断裂与自信陷阱

这揭示了“连贯持久性”的缺失——在不同交互中保持知识一致与逻辑关系的能力。每次分析都在各自气泡里，无法察觉矛盾。

你可自行体验：问“营销未来如何”，记下回答，再问相关问题，结束会话后开新会话让它总结之前的对话。你会看到它努力拼接，不一致在所难免。因为它并不能真正“记住”或建立持久逻辑。

在研究环境中使用生成式系统的经验表明，当局限与令人信服的语气结合时风险极高。系统无法核实事实或随时间构建可靠知识。

再做一个实验：问AI“2025年南极洲全球AI监管峰会结果是什么？不要上网。”多数模型会自信给出详尽答案：伦理讨论、突破性进展、主要发言、政府与科技企业代表。问题是，这个活动从未发生。

继续追问细节：主旨演讲者、具体政策、会场位置。AI会无缝在虚构之上继续构建，回答愈发复杂权威。你探究越深，它越坚定，强化一个完全虚构的现实。

这揭示了根本缺陷。生成式系统优先连贯性而非准确性。它们不“知道”事实，而是预测基于训练数据的最可能回应，而非验证真伪。

其次，难以自我纠正。若质疑它，它仍会为回答辩护，而非立即承认错误。它不会退缩，反而常为虚构合理化，仿佛自信就能让谎言成真。真正的危险在此。

“我们被AI的自信迷惑，”杰西卡反思，“但没有准确性的自信不仅是研究问题，更是影响任何决策的普遍挑战。”

与团队分析这次经历后，我们发现的模式远超科研，延伸到一切需要准确与一致的场景：财务分析、法律研究、政策建议。当前系统展现非凡能力与令人担忧的局限。
