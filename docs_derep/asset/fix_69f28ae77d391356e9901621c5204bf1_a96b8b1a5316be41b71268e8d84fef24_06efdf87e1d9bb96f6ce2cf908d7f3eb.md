# 部门法视野

## 大数据隐私治理：原则要义与实现路径[^(\[1\])](#chapter003.html#m1)

赵万一 樊沛鑫[^(\[2\])](#chapter003.html#m2)

**摘要：**与传统隐私侵害相比，大数据语境下的隐私权呈现出波及面更广、被侵害可能性更高、觉察难度更大、救济门槛更高、定性更复杂等特征。为此需要建构更具针对性的保护目标与规范框架，核心指向包括以人为本的人格权优先原则、信息伦理原则、正当性原则、利益平衡原则和必要性原则等。在制度设计上要充分保障个人信息自决权，恪守信息伦理底线，建立科学合理且合法合规的数据使用规则，并将“被遗忘权”提升为隐私权体系中的特殊权利。落实现述目标必须综合施策，完善救济机制，加大技术防护力度，同时提升企业的信息保护意识和合规使用责任。

**关键词：**个人隐私 大数据 人格权优先 被遗忘权

网络日益普及、技术持续迭代，中国已全面步入以数据驱动开发、分析与应用为核心的大数据阶段。其运行方式是通过专业分析工具对海量数据进行归纳、交换与融合，衍生出多种知识关联、知识耦合与仿真场景。一方面，虚拟社会成为现实社会的必要延伸与重要组成部分；另一方面，强势的数据采集与分析能力使个人信息长期暴露在数据视域之下，对隐私权的冲击空前严峻。近期，因“滴滴出行”App 被指严重违规使用个人信息，国家互联网信息办公室依据《网络安全法》对其启动网络安全审查，并要求下架整改、保障用户数据安全。[^(\[3\])](#chapter003.html#m3)即便官方通报未披露具体违法细节，但用户在平台预约出行时须填写起止地点等信息，通常难以拒绝授权，这些数据被自动抓取入库后存在不当利用的潜在风险。该事件也从侧面揭示出传统法框架在隐私保护上的滞后。尽管《民法典》对个人隐私及数据隐私作了原则性表述，但因数据隐私的复杂性，仅靠民法典难以实现全方位保护，亟需制定更细化的单行法规来回应大数据时代的保护需求。

### 一 大数据语境下隐私保护的特殊困境

人类天生具备自我庇护本能，长期以来通过调整行为方式来维护私密空间。隐私保护的本质是通过遮蔽、隔离与迷惑等方式隐藏行为轨迹与生活习惯，避免他人窥探并攫取个人信息，从而获得信息独占收益、保持神秘感、规避羞耻感并确保生活不受干扰。我国2020年出台的《民法典》对隐私权予以高度重视，将人格权单独立编并作出系统保护。[^(\[4\])](#chapter003.html#m4)《民法典》第1032条将隐私权界定为公民私人信息依法受保护、不被他人知悉、收集、非法侵扰、利用和公开的人格权，其内容涵盖个人信息保密、生活不受干涉、私事决定自由。第1034条则对未上升为隐私的个人数据同样予以法律保护。[^(\[5\])](#chapter003.html#m5)然而，现行以《民法典》为代表的法律体系对传统隐私的规制更为充分，对大数据时代隐私的特殊性关注不足，缺乏针对性的细则支撑，亟需专门立法来填补空白。

#### （一）隐私在大数据面前面临更高可损性

传统数据往往分散孤立，而大数据时代的算法能够对海量信息进行全域利用，不仅可以回溯已发生的个人生活场景与行为轨迹，还能对未来事件作出预测，使生活被量化拆解。卡内基梅隆大学隐私研究指出：“即便剔除姓名与社会安全号，仅凭性别、生日与邮编三个变量，数据挖掘技术也能识别全美87%的人口。”[^(\[6\])](#chapter003.html#m6)大量本应私密的信息在大数据面前几乎无处遁形，可预测性极强。新兴互联网技术延长了信息存储周期，同时大幅提升了检索便捷度。用户在特定情境下发布的信息，发布后或许已被遗忘，却可在事件触发时被瞬间调取并扩散。丰厚商业利益也难以阻止掌握数据库的组织对个人数据的整合与再利用。一旦信息以数据形式被存储，无论掌握主体是政府机构还是商业组织，都可能成为监管依据或商业行为的数据基础，尤其在商业利用场景中，个人几乎无法有效阻止，隐私受侵风险显著放大。

#### （二）侵害行为呈现高频普遍化

在大数据阶段，数据已成为生产要素与经济社会价值的重要来源。数据采集触角遍布日常生活各个环节，客观上导致隐私侵害行为高发常态化。搜索记录映射关注偏好，电商行为记录消费模式，手机定位呈现出行轨迹，银行交易反映金融往来，社交通信揭示人际关系等。对这些数据的简单计算即可勾勒个人爱好、生活习惯甚至财务状况。学界曾形象描述为“一入网络深似海，从此隐私是路人”[^(\[7\])](#chapter003.html#m7)。在技术驱动下，隐私还出现了整合型的新形态，即通过数据挖掘将网络留痕进行收集、整理并生成新的私密信息[^(\[8\])](#chapter003.html#m8)。由此数字社会的隐私呈现出“隐私信息化”与“信息隐私化”双重特征：前者指隐私在信息时代以数据形态显现，传统边界被数字延伸；后者指原本非隐私的信息在关联加工后转化为私密信息，个人信息与隐私利益高度重合。[^(\[9\])](#chapter003.html#m9)可见大数据时代的隐私保护既具时代特征，也更显特殊复杂。

#### （三）数据侵权难以被及时救济

大数据环境下数据共享常态化，隐私侵害的不确定性与不透明性同步增强，事后救济难度大幅上升。传统隐私侵权往往伴随直接可感的后果，而数据侵权发生后，通常不会立即造成身体伤害、人格贬损或财产损失，被侵权者感知也较弱。信息不对称使个人对泄露的判断易出现不精确与非理性，商业利用多以信息集成方式呈现，很少直接涉及原始个人信息的使用，个人难以对后果作出理性评估。可以说，传统侵权中可量化、可识别的损害在数据侵权中出现的概率极低，权利人更多承受的是隐私泄露后潜在的未来风险，即“焦虑风险”，这种无形损害难以举证也难以感知。[^(\[10\])](#chapter003.html#m10)即便损害已经发生，基于大数据强大的预测、推断与分析能力，以及反向身份识别的技术难题，信息收集与结论之间的因果链条难以清晰证明，受害者提起诉讼并胜诉的可能性极低。[^(\[11\])](#chapter003.html#m11)
