### 用AI把培训需求问清楚的提问模型

#### 通用提问结构=情境铺垫+目标诉求+现实限制+交付规格

先把培训要解决的来龙去脉讲明白，让模型迅速进入情境。

**需要说明的信息**
- 经营背景：公司正在做的转型、业务上卡住的痛点。
- 人群画像：现有团队的能力段位、岗位分布、过往学习经历。
- 时间窗口：年度滚动、季度聚焦还是阶段冲刺。

把要达成的目标说透，必须可衡量、可追踪。

**需要说明的信息**
- 能力诉求：员工最终要掌握哪些技能、要补强哪些短板。
- 业务诉求：培训结束后要带来哪些可感知的经营改善。

在现实限制里给出可行解，避免纸上谈兵。

**需要说明的信息**
- 经费上限：整体预算、单次活动成本封顶。
- 时间上限：整体周期、员工每周可投入时长及形式。
- 师资情况：内部讲师储备、外部合作资源是否可用。

对交付形态做明确约定，确保能直接用。

**需要说明的信息**
- 方案形态：整体架构、实施方式组合。
- 内容细化：课程设计逻辑、验收方式。
- 最终产出：企划文档、课件包、成效报告。

### 资料准备

| 要点 | 内容 |
| :--- | :--- |
| 经营背景 | 企业现状、团队能力水位、历史学习记录等。 |
| 方案目标 | 员工应习得的技能、能力提升点、业务改善点等。 |
| 条件边界 | 总预算、单次上限、员工可投入时间等。 |
| 交付规格 | 方案模板、优秀案例参考等。 |

### 实战示例

我方是一家传统制造企业，计划12个月内完成向智能制造的切换。现在产线技术员和设备维护员的能力很不均衡，数据分析、设备调试等短板明显。过去一年做过几次专项学习，同事普遍说“学完没法用”。

1. 希望人员掌握数据分析、设备调试，产线效率提升10%。
2. 学完能独立完成设备故障自检、数据采集与分析。

培养周期为年度滚动，分基础、进阶、实操考核三段。

1. 经费上限：整体50万，单次不超10万。
2. 时间上限：同事每周可投入1天线下，其余线上自学。
3. 师资：内部讲师3名，设备厂商可提供免费外援。

**请帮我输出培养方案，包含**
1. 方案框架：课程大纲含数据分析、设备调试，阶段时间表。
2. 实施方式：线上理论每周2小时+线下实操每月1天+季度案例研讨1次。
3. 验收方式：线上理论测验+线下实操考核+项目实绩评估。
4. 最终产出：培养企划文档、课程材料、成效报告。

### 使用提示

| 要点 | 内容 |
| :--- | :--- |
| 需求复核 | 模型输出后请与业务部门对齐，确保贴合实际。 |
| 持续优化 | 建议每季度复盘，结合反馈与业务变化迭代。 |
| 人性化补充 | 模型容易忽视接受度，需要负责人做二次判断。 |

## 用AI判断学习是否真正见效

### 常见困惑
1. 公司花大钱请外部讲师做领导力学习，结束后大家反应平平，业绩也没起色，投入产出失衡怎么破？
2. 很多公司只看过程数据，比如出勤率、讲师评分，却忽略行为改变和绩效变化。没有科学评估就无法判断是否匹配业务。
3. 同事说内容太理论，业务部门说不够落地，如何证明价值？
4. 可从能力提升、行为转化、业务结果三个层面切入，用数据说话才能让学习服务经营。
5. 若评估发现效果差，是不是直接砍掉项目？
6. 评估的核心是找根因。它是起点不是终点。如内容与岗位脱节就优化课程；若缺少实操机会就增加导师制或行动学习。

### 提问思路

#### 通用公式=学习概况+评估卡点+分析诉求

为评估提供基础上下文。

**提问要点**
- 主题：如销售技巧、跨部门协作。
- 形式：线上、线下或混合。
- 参与人群：新员工、管理层或特定岗位。
- 周期：单次还是系列。

聚焦可量化的评估难题。

**提问要点**
- 方法缺陷：仅靠问卷，缺乏行为数据。
- 效果断层：技能分提升但业绩不动。
- 资源限制：评估成本高难以全员覆盖。

明确希望模型完成的具体分析任务。

**提问要点**
- 评估维度：如柯氏四级、ROI分析。
- 数据来源：学习记录、绩效数据。
- 交付形式：轻量化评估工具、低成本数据采集建议。

### 资料准备

| 要点 | 内容 |
| --- | --- |
| 学习基础信息 | 目标、大纲、讲师、参训名单等。 |
| 评估数据 | 训前训后测评、满意度、绩效等。 |
| 业务场景描述 | 学习对应的业务目标、当前痛点等。 |
| 资源限制 | 评估预算、周期、可用工具等。 |

### 实战示例

我们为50人销售团队做了2天线下“客户谈判技巧”，讲师是外部行业专家。目标是提升成交率，但没设量化指标。

**当前卡点**
1. 方法单一：只做课后问卷，平均4.5/5，但谈判成功率未升。
2. 数据割裂：学习记录与业务数据未联通。
3. 资源有限：希望少花钱评估，缺工具和人手。

**请协助**
1. 基于柯氏四级设计轻量方案，重点覆盖行为层是否在工作中应用技巧、结果层谈判成功率与客户复购率。
2. 给出低成本采集方式，如从客户管理系统中提取谈判记录、设计3分钟快速调研问卷。
3. 输出评估报告框架，含核心指标、数据来源、分析逻辑及改进建议。

### 使用提示

| 要点 | 内容 |
| :--- | :--- |
| 多维度验证 | 模型输出需结合真实业务数据验证，避免只靠理论。 |
| 简化执行 | 优先用Excel、问卷星等已有工具，降低成本。 |
| 持续迭代 | 建议每季度刷新指标，跟随业务变化优化。 |
| 关注隐性价值 | 信心提升、协作改善等非量化价值，需用观察或访谈补充。 |

## 用AI搭建清晰的职业成长地图

### 常见困惑
1. 同事常说“看不到晋升希望”，技术骨干离职率一年涨30%。有晋升规则但透明度不足，怎么办？
2. 很多公司把晋升标准等同于发展通道，忽略路径可视化与能力阶梯化。清晰的通道能让每个人知道位置、方向与路径，降低流失。
3. 不同岗位要求差异大，如研发重技术深度、销售重业绩转化，如何统一设计？
4. 通道要分层分类。例如技术岗设初级工程师→专家→架构师纵向通道，并叠加技术与管理双通道；销售岗可分客户深耕与市场开拓两个方向。
5. 若员工达标却无晋升席位，通道是否失效？
6. 通道需与战略动态匹配，建立容量预警。当某层级饱和时触发横向轮岗或项目制晋升，保持通道活力。

### 提问思路

#### 通用公式=组织画像+设计难点+实现目标

避免脱离实际。

**组织画像**
- 行业属性：互联网、制造、服务等。
- 岗位分类：技术、管理、职能等。
- 人群规模与分布：总部/分支、全职/外包。
- 现有通道：规则与问题。

**设计难点**
- 员工痛点：标准不透明、横向机会少。
- 组织痛点：关键岗位断层、流失率高。
- 资源限制：预算有限难大面积培养。

**实现目标**
- 通道类型：单轨、双轨、多轨。
- 能力模型：岗位能力词典、晋升里程碑。
- 配套机制：动态调整规则、晋升答辩流程。
- 交付形式：可视化图谱、低成本落地路径。

### 资料准备

| 要点 | 内容 |
| :--- | :--- |
| 岗位基础信息 | 岗位说明书、能力模型、现有晋升规则。 |
| 人员数据 | 能力评估、晋升记录、离职原因。 |
| 业务场景描述 | 三年战略目标、关键岗位需求。 |
| 资源限制 | 设计预算、可调用工具、管理层支持度。 |

### 实战示例

我们是500人互联网公司，技术驱动。岗位构成技术60%、产品20%、职能20%。现规则为“满2年+主管评分≥80”，标准模糊，技术岗只有管理通道，资深工程师被迫转管理，技术停滞，核心骨干流失率25%。

1. 通道单一：无技术专家路径。
2. 标准模糊：依赖主管主观。
3. 缺前瞻性：未来两年聚焦AI与大数据，通道未覆盖。

**请协助**
1. 为技术岗设计管理+专家双通道，明确晋升标准。
2. 生成岗位能力词典，含各层级核心能力。
3. 设计动态调整机制，如AI岗位需求增30%时自动扩容。
4. 输出可视化图谱及低成本实施建议。

### 使用提示

| 要点 | 内容 |
| --- | --- |
| 员工参与 | 模型输出需经访谈或焦点小组验证实用性。 |
| 简化落地 | 先覆盖核心岗位，逐步迭代。 |
| 避免固化 | 每年根据业务调整规则。 |
| 文化适配 | 结合企业价值观调整。 |
| 配套资源 | 需与培养、薪酬体系联动。 |

## AI助力搭建人才储备梯队

### 常见困惑
业务扩张快，关键岗位空缺就手足无措，外招成本高，内提又怕能力不足，如何破局？缺失梯队规划是根因，没有提前储备继任者，核心人才流失即被动。
不同岗位继任要求差异大，技术重深度，管理重协同，如何统一规划？
技术可按技术骨干→架构师→CTO设计，管理可按主管→总监→事业部负责人设计，并为每层级配能力雷达图。
若梯队人才达标却不愿接岗怎么办？需双轨并行并评估意愿度，对高潜低意愿者通过轮岗、项目参与引导，而非强制提拔。

### 提问思路

#### 通用公式=组织画像+核心堵点+落地需求

**组织画像**
- 行业属性：制造重工艺传承、互联网重迭代。
- 关键岗位清单：技术、销售、运营核心岗。
- 现有梯队机制：规则与问题。
- 人力结构：年龄、司龄、高潜占比。

**核心堵点**
- 岗位风险：继任储备不足、人才断层。
- 能力缺口：能力与战略不匹配。
- 资源矛盾：培养预算有限。

**落地需求**
- 梯队结构：3级技术梯队、5类关键岗位。
- 培养机制：90天培养计划、跨部门轮岗方案。
- 评估工具：胜任力评估表、潜力评分卡。
- 交付形式：建设路线图、低成本培养路径。

### 资料准备

| 要点 | 内容 |
|---|---|
| 岗位基础信息 | 关键岗位说明书、能力模型、现有继任者名单。 |
| 人员数据 | 能力评估、绩效、学习记录、职业倾向。 |
| 业务场景描述 | 三年战略目标、岗位需求预测。 |
| 资源限制 | 培养预算、内部资源、管理层支持。 |

### 实战示例

我们是制造业800人，以工艺研发为核心。关键岗为研发工程师、生产经理、销售总监。现机制为部门推荐后备名单，无能力标准，研发总监空缺时内部候选因技术方向与战略不匹配被否，外聘成本超预算30%。

1. 岗位风险：研发总监、生产经理无明确继任。
2. 能力缺口：高潜人才技术强但缺技术商业化思维。
3. 资源矛盾：预算有限，需性价比培养。

**请协助**
1. 为研发岗设计三级梯队，明确能力标准。
2. 生成高潜人才90天培养计划，含技术+商业化任务。
3. 设计继任者潜力评分卡，含能力、意愿、文化适配，并推荐低成本评估方式。
4. 输出路线图，含里程碑与资源估算。

| :--- | :--- |

# 第4章 AI+绩效管理

绩效管理关乎贡献衡量与团队激发。借助AI可让流程更科学、公正、高效。从体系设计到程序细化，从指标拆解到目标制定，从问题定位到评价方法，从辅导话术生成到改进方案，再到结果应用机制，AI贯穿全流程，助力以绩效为导向的文化建设。

## 用AI设计绩效管理体系

**问题场景**
年度考核流于形式，员工认为指标不合理，管理者打分凭感觉，结果与调薪晋升关联弱，如何破局？
很多公司把绩效等同于打分，忽略其价值——战略落地与行为引导。指标与战略脱节则员工为考核而工作。
不同岗位性质不同，销售重结果，技术重过程，如何统一？
销售可设业绩达成率+客户满意度+回款周期三维，技术可设交付质量+创新贡献+协作效率三维。将战略拆解为可落地行为指标。
若员工认为结果不公怎么办？
需配套过程反馈如季度面谈和结果申诉机制，并通过跨部门校准会评审异常评分，避免主观偏差。

### 提问思路

#### 通用公式=组织画像+核心堵点+实现目标

描述管理现状，为设计提供土壤。

**组织画像**
- 行业属性：服务重体验、制造重效率。
- 战略目标：如三年市场份额提升至30%、成本降15%。
- 现有绩效机制：指标类型、考核周期、结果应用。
- 人员结构：岗位类型、层级、平均年龄。

**核心堵点**
- 指标问题：与战略脱节、不可量化。
- 流程问题：周期过长、反馈缺失。
- 结果应用问题：与薪酬脱钩、高绩效流失。

**实现目标**
- 指标体系：销售三维指标、技术岗OKR模板。
- 流程设计：季度考核优化、申诉机制。
- 工具支持：面谈话术库、校准会评分表。
- 交付形式：管理制度草案、低成本数字化工具推荐。

### 准备资料

| 要点 | 内容 |
| --- | --- |
