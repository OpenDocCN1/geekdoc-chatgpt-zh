PREAMBLE
开源字体授权的核心目标是推动全球协作型字体项目的蓬勃发展，助力学术与语言学群体的字体创作，同时提供一个自由开放的框架，让字体能够在合作中被共享与改进。
在 OFL 框架下，被授权的字体可以被自由使用、研究、修改和再分发，唯一限制是不能单独售卖。字体本身及其衍生版本可以与任意软件一起打包、分发或售卖，前提是衍生作品不得使用被保留的字体名称。字体及其衍生作品不得以其它类型的许可对外发布。但这一要求不适用于使用该字体或其衍生作品所创制的文档。

定义
Font Software 指版权持有人依据本许可对外发布的、明确标注的文件集合，可包含源文件、构建脚本及说明文档。
Reserved Font Name 指版权声明后特别指明的保留名称。
Original Version 指版权持有人最初对外分发的字体软件组件集合。
Modified Version 指对 Original Version 的任何衍生，即通过增删或替换部分或全部组件、改变格式或将字体移植到新环境而产生的版本。
Author 指为该字体软件做出贡献的设计师、工程师、程序员、技术撰稿人等人员。
