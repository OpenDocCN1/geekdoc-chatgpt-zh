## 8.5 表情包设计

表情包是轻量化的传播利器，靠贴合日常互动场景如打招呼、庆祝，再结合品牌或 IP 的核心特征来提升使用意愿。

### 8.5.1 IP形象表情包设计

IP 形象表情包的关键在于传递鲜明的性格标签，比如活泼、治愈等，把 IP 的识别特征嫁接到“开心”“点赞”这类通用情绪上。

**案例拆解：职场精英 IP“阿Ken”商务表情包**

商务向表情包要兼顾职场真实感和幽默感，如图8-16所示，指令原文为“创作职场精英IP‘阿Ken’的商务表情包，包含8个工作场景表情。要求保持阿Ken西装革履的精英形象。融入领带飘动、咖啡杯蒸汽等动态细节”。

## 8.6 壁纸设计

壁纸是用户每日都会看到的视觉背景，靠屏幕适配和 IP 核心元素的统一，才能实现润物细无声的品牌渗透。壁纸设计参数提示词见表 8-8。

表 8-8 壁纸设计参数提示词

| 提示词类型 | 示例词库 |
| :--- | :--- |
| 屏幕适配 | 竖屏(9:16)/宽屏(16:9) |
| 主体聚焦 | IP特征(如头盔反光/狐狸眼镜)，如星野(头盔反光)、小联(眼镜) |
| 背景设计 | 渐变深空/办公场景，如深蓝→紫渐变、文件堆+咖啡杯 |

### 8.6.1 IP 形象手机壁纸设计

手机壁纸曝光频率高，是提升 IP 日常触达的有效载体，核心在于让角色更醒目，背景保持简洁不抢戏。

**案例拆解：星空旅者 IP “星野” 手机壁纸**

IP 形象为戴宇航头盔的少年，头盔面罩有反光，主题定为“探索”。深空渐变深蓝到紫色符合夜间使用，星云粉蓝渐变增加浪漫感，指令原文为“壁纸设计，主体为戴宇航头盔的少年（IP 特征），面向正前，右手向前伸出，手套带星星挂饰，背景为渐变深空，从深蓝（#0A192F）过渡到紫色 #6A0DAD，远处有星云，粉色 #FF69B4+蓝色 #00BFFF 渐变，整体风格为科幻插画（背景设计），色彩梦幻、线条流畅，8K 高清，适配手机屏幕分辨率”，在 9:16 幅面生成，效果如图 8-20 所示。
