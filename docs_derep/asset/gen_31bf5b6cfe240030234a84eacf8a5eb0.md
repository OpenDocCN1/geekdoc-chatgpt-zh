# 第 9 章 ChatGPT 助力 CI

### 9.1 CI 为何不可或缺

在现代软件开发里，CI 已从可选项变为必选项。其核心是让开发团队频繁地把代码变更合并到主干，通过自动化构建和测试尽早发现并修复错误，从而在更高层面保障质量与稳定。具体好处有：

- 1）降低风险：频繁集成和测试能及早揪出错误，减少后期大规模排错的难度和成本，也减轻了项目后期的压力。
- 2）提高质量：自动化测试覆盖代码多方面，降低人为疏忽遗漏错误的可能，确保每段代码都经过严格检验。
- 3）加快开发速度：自动化构建和测试节省手工测试时间，让团队把精力集中在编码和新功能上。
- 4）提升协作效率：频繁更新代码保持主干一致，减少集成冲突和沟通成本。
- 5）CI 与 CD：CI 是实现 CD 的基础，加快新版本交付速度，形成更快反馈和迭代。

实施 CI 也面临挑战：

- 1）测试用例编写与维护工作量大：需要大量用例并随项目持续更新。
- 2）调试失败测试耗时：自动化测试失败后定位修复往往费时，尤其在复杂系统。
- 3）测试覆盖率难确定和提升：难以确认代码覆盖情况，低覆盖率会留下隐藏缺陷。

CI 作为关键实践，提升了效率和质量，为持续改进和快速迭代奠定基础。它不仅是技术改进，也涉及团队文化和工作方式的转变，在快速变化的技术环境中成为软件开发的重要支柱。
