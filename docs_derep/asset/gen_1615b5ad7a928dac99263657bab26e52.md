1. 定义
变量 x 朝向某个定值 x₀ 靠近，或向正负无穷延伸时，若对应的函数值能无限逼近 0，就把这个函数称作无穷小。

举例：x 趋于 0 时，x 本身、sin x 都满足这一特征。

2. 核心要点
- 无穷小是随过程变化的量，不是像 0.001 这样固定很小的数。
- 唯一能恒为无穷小的常数是 0。
- 必须明确写出趋向方式，例如 x→0 或 x→∞，脱离过程就谈不上无穷小。

（二）无穷大
1. 定义
当自变量趋近某点或趋向无穷时，函数值的绝对值可以变得任意大，这类函数称为无穷大，可表现为正无穷或负无穷。

举例：x→0 时 1/x 为无穷大；x→∞ 时 x² 为无穷大。

2. 核心要点
- 无穷大是过程量，不是 100 万这类很大的数值。
- 无穷大分正无穷 +∞ 和负无穷 -∞ 两种方向。

二、无穷小与无穷大的关系
1. 二者互为倒数关系。
2. 若 f(x) 是无穷大，则 1/f(x) 是无穷小。
3. 若 f(x) 是无穷小且恒不为 0，则 1/f(x) 是无穷大。

举例：x→0 时 1/x 是无穷大，其倒数 x 是无穷小。

三、运算性质
（一）无穷小的运算
1. 加减乘性：有限个无穷小的和、差、积仍保持无穷小。
   比如 x→0 时 x + x² 仍是无穷小。
2. 常数倍性：常数与无穷小的乘积仍是无穷小。
   注意：无穷多个无穷小的和或积不一定仍是无穷小。

（二）无穷大的运算
2. 高阶无穷小：若 lim(β/α)=0，则 β 是比 α 高阶的无穷小，记 β=o(α)。例如 x² 相对于 x 是高阶无穷小。
3. 同阶无穷小：若 lim(β/α)=c 且 c≠0，则 β 与 α 同阶。
4. 等价无穷小：若 lim(β/α)=1，则 β~α，如 x→0 时 sin x~x。
   应用：极限计算中可用等价无穷小做替换简化过程。

五、预习建议
（一）核心公式与定理
1. 极限与无穷小的关系：lim f(x)=A 可写成 f(x)=A+α，其中 α 为无穷小。
2. 无穷小的运算规则：有限项的加减乘以及常数倍仍保持无穷小。
3. 常用等价替换：sin x~x，1-cos x~x²/2 等。

（二）易错提示
1. 无穷大不是数值，不能直接做算术，如“无穷大+1”无意义。
2. 取倒数时要保证原无穷小不为零，否则结论不成立。
3. 无穷大与无穷小的乘积结果不确定，例如 x·1/x²=1/x 当 x→∞ 时趋于 0。

六、课堂练习预测
1. 判断在指定趋近下的函数是无穷小还是无穷大。
2. 利用等价无穷小求极限，如 lim_{x→0} sin3x/2x=3/2。
3. 论证无穷大或无穷小的运算结果，如证明 x→∞ 时 x+sin x 为无穷大。

> 提示：结合教材例题吃透概念，重点掌握等价替换与运算规则的实际运用。
