# 泛逻辑算子模型与核心推理法则速览

## 核心参数设定
在展开具体算子之前，先明确贯穿始终的两个关键参数族：
- **指数参数**：$k=2^{-1/n}$（$n \in \mathbb{R}^+$），或反推 $n=-1/\log_2 k$（$k \in [0, 1]$）。
- **偏移参数**：$m=(3-4h)/(4h(1-h))$（$h \in [0, 1]$），或反推 $h=[(1+m)-\sqrt{(1+m)^2-3m}]/(2m)$（$m \in \mathbb{R}$）。

## 二、泛析取连接词 $\vee_{h,k}$ 运算模型

### 2) 多元扩展形式
[PRE0]

该模型涵盖四大核心算子簇：
- **最小/扎德析取** ($h=1$)：$S_3 = \max(x_1, \dots, x_l)$
- **中极/概率析取** ($h=0.75$)：$S\Phi_{2k} = \big(1 - \prod_{i=1}^l (1-x_i^n)\big)^{1/n}$
- **中心/有界析取** ($h=0.5, k=0.5$)：$S_1 = \max\big(0, \sum_{i=1}^l x_i - (l-1)\big)$
- **最大/突变析取** ($h=0$)：$S_0$，仅当 $l-1$ 个输入为 0 时输出最大值，否则为 1。

## 四、泛蕴含连接词 $\rightarrow_{h,k}$ 运算模型
[PRE1]

四大特征算子定义如下：
- **最小/扎德蕴含** ($h=1$)：$\mathbf{I}_3$，若 $x \le y$ 则为 1，否则为 $y$。
- **中极/概率蕴含** ($h=0.75$)：$\mathbf{I}_2 = \min(1, y/x)$。
- **中心/有界蕴含** ($h=0.5, k=0.5$)：$\mathbf{I}_1 = \min(1, 1-x+y)$。
- **最大/突变蕴含** ($h=0$)：$\mathbf{I}_0$，仅当 $x=1$ 时输出 $y$，否则为 1。

## 五、泛等价连接词 $\leftrightarrow_{h,k}$ 运算模型
[PRE2]

注意：$h > 0.75$ 取正号，否则取负号。四大算子为：
- **最小/扎德等价** ($h=1$)：$\mathbf{Q}_3$，若 $x=y$ 则为 1，否则为 $\min(x,y)$。
- **中极/概率等价** ($h=0.75$)：$\mathbf{Q}_2 = \min(x/y, y/x)$。
- **中心/有界等价** ($h=0.5, k=0.5$)：$\mathbf{Q}_1 = 1 - |x-y|$。
- **最大/突变等价** ($h=0$)：$\mathbf{Q}_0$，若 $y=1$ 则为 $x$；若 $x=1$ 则为 $y$；否则为 1。

## 六、泛平均连接词 $\oplus_{h,k}$ 运算模型

### 1) 二元基础模型
[PRE3]

- **最大/扎德平均** ($h=1$)：$\mathbf{M}_3 = \max(x,y)$（等同于析取 $S_3$）。
- **中极/概率平均** ($h=0.75$)：$\mathbf{M}\Phi_{2k} = \big(1 - [(1-x)^n(1-y)^n]^{1/2}\big)^{1/n}$。
- **中心/有界平均** ($h=0.5, k=0.5$)：$\mathbf{M}_1 = (x+y)/2$（标准算术平均）。
- **最大/突变平均** ($h=0$)：$\mathbf{M}_0 = \min(x,y)$（等同于合取 $T_3$）。

### 2) 多元推广模型
[PRE4]

- **最大/扎德平均** ($h=1$)：$\mathbf{M}_3 = \max(x_1, \dots, x_l)$。
- **中极/概率平均** ($h=0.75$)：$\mathbf{M}\Phi_{2k} = \Big(1 - \big[\prod_{i=1}^l (1-x_i)^n\big]^{1/l}\Big)^{1/n}$。
- **中心/有界平均** ($h=0.5, k=0.5$)：$\mathbf{M}_1 = \frac{1}{l}\sum_{i=1}^l x_i$。
- **最小/突变平均** ($h=0$)：$\mathbf{M}_0 = \min(x_1, \dots, x_l)$。

## 七、泛组合连接词 $\circledcirc_{h,k}^e$ 运算模型
[PRE5] *(注：素材原标记为 7，此处保留序号)*

通式：$C^e(x, y, h, k) = \text{ite}\{\dots\}$，含阈值 $e$ 及其补 $e^t = N(e, k)$。

四大特征算子：
- **上限/扎德组合** ($h=1$)：$\mathbf{C}^3_e$，视 $x+y$ 与 $2e$ 大小切换 $\min/\max$。
- **中极/概率组合** ($h=0.75$)：$\mathbf{C}^{\Phi}_{2k}$，乘积形式与补形式分段。
- **中心/有界组合** ($h=0.5$)：$\mathbf{C}^1_e = \Gamma[\Gamma x + y - e]$（$\Gamma$ 为截断函数）。
- **下限/突变组合** ($h=0$)：$\mathbf{C}^0_e$，根据 $x,y$ 与 $e$ 位置输出 0、1 或 $e$。

# 第十章·第四节：命题泛逻辑常用公式体系

将二值逻辑公式拓广至泛逻辑后，呈现三种生存状态：
1. **普适成立**（如化简律、析取三段论）；
2. **有条件成立**（如分配律需 $h=1$，补余律需 $h<0.5$）；
3. **仅二值域成立**（如等价式展开、否定等价互换）。

泛逻辑特有的非算子、平均、组合公式尤为丰富，故专节梳理。

## 10.4.1 泛非连接词公式体系

### 1. 等级泛非公式（同一误差水平 $k$）
仅需三条核心性质：
1. **对合律**：$\sim_k \sim_k p \Leftrightarrow p$。
2. **泛非性**：$k \rightarrow_{h,k} p \Leftrightarrow \sim_k p \rightarrow_{h,k}$；$p \rightarrow_{h,k} \Leftrightarrow k \rightarrow_{h,k} \sim_k \sim_k p$。
3. **对偶律**：$\sim_k \sim p \Leftrightarrow \sim_{1-k} p$。

### 2. 阈元量词 $^k$ 模型与性质
跨误差层级推理需引入阈元量词标识真值误差水平。

**运算模型**：
- $^k x = \Phi^{-1}(x, k) = x^{1/n}$（特例 $k=0.5$ 时为恒等）。
- 符号 $^{\Theta^k}$ 模型：$^{\Theta^k} x = \Phi(x, k) = x^n$。
- **关键联结**：$\sim_k p \Leftrightarrow ^{\Theta^k} \sim ^{\Theta^k} p$。

#### (1) 六大移位规则
1. **一移**：$^k \sim p \Leftrightarrow \sim_k ^k p$。
2. **二移**：$^k p \Leftrightarrow q \implies p \Leftrightarrow ^{\Theta^k} q$。
3. **三移**：$^k_1 ^k_2 p \Leftrightarrow ^k_2 ^k_1 p$（可交换）。
4. **四移**：$\sim_k p \Leftrightarrow ^k \sim ^{\Theta^k} p$ 或 $\sim p \Leftrightarrow ^{\Theta^k} \sim_k ^k p$。
5. **五移**：$\sim_{k_2} ^k_1 p \Leftrightarrow ^k_2 \sim ^{\Theta} k_1 ^k_2 p$。
6. **六移**：$^k_2 \sim \sim ^{\Theta} k_2 ^k_1 \sim \sim ^{\Theta} k_1 p \Leftrightarrow \sim ^{\Theta} k_2 ^k_1 \sim \sim ^{\Theta} k_1 ^k_2 p$。

#### (2) 阈元运算代数
- **逆运算**：$\Theta k = 2^a (a=1/\log_2 k)$，满足还原律 $\Theta \Theta k = k$。
- **和运算**：$k_1 \oplus k_2 = 2^a (a=-\log_2 k_1 \log_2 k_2)$，满足对偶律 $k_1 \oplus k_2 = \Theta(\Theta k_1 \Theta k_2)$。
- **差运算**：$k_1 \Theta k_2 = 2^a (a=-\log_2 k_1 / \log_2 k_2)$，满足吸收律 $k \Theta k = 0.5$（即 $^k \Theta ^k x = x$）。

### 3. 不等级泛非公式（跨水平 $k_1 \neq k_2$）
1. **合成律**：$\sim_{k_2} \sim_{k_1} p \Leftrightarrow \sim_{k_3} p$，$k_3 = k_1 \Theta k_2 = \frac{k_1(1-k_2)}{k_1+k_2-2k_1k_2}$。
2. **吸收律**：边界 0、1 吸收中间层（如 $\sim_k \sim_0 p \Leftrightarrow \sim_0 p$ 等四式）。
3. **互补律**：$\sim_{\Theta k} \sim_k p \Leftrightarrow \sim_k p$，其中 $k' = k^2/(1-2k+2k^2)$。
4. **交换律**：$\sim_{k_2} \sim_{k_1} p \Leftrightarrow \sim_{k_1} \sim_{k_2} p$。
5. **对偶律**：$\sim_{k_1} \sim \sim_{k_1} p \Leftrightarrow \sim_k p$（$k_2 = N(k, k_1)$）；$\sim \sim_k \sim p \Leftrightarrow \sim_{1-k} p$。

## 10.4.2 永真蕴含公式集（排除 $h=0, k=1$ 退化情形）

### 1. 化简律
- **Im1/Im2**：$p \wedge_{h,k} q \Rightarrow p / q$（合取推出分支）。
- **Im3/Im4**：$\sim_k (p \Rightarrow_{0.5,k} q) \Rightarrow p / \sim_k q$（中心蕴含否定推出前件/后件否定）。

### 2. 附加律
- **Im5/Im6**：$p \Rightarrow p \vee_{h,k} q$ / $q \Rightarrow p \vee_{h,k} q$（分支推出析取）。
- **Im7**：若 $p \Rightarrow q$ 或 $h=0.5$，则 $\sim_k p \Rightarrow p \Rightarrow_{h,k} q$。
- **Im8**：$q \Rightarrow p \Rightarrow_{h,k} q$（真后件律）。
- **Im9**：$p, q \Rightarrow p \wedge_{h,k} q$（合取引入）。
- **Im10**：蕴含保合取单调性：$p \Rightarrow_{h,k} q \Rightarrow (r \wedge p) \Rightarrow_{h,k} (r \wedge q)$。
- **Im11**：蕴含保析取单调性：$p \Rightarrow_{h,k} q \Rightarrow (r \vee p) \Rightarrow_{h,k} (r \vee q)$。

### 3. 推论规则
- **Im12**：$\sim_k p, p \vee_{h,k} q \Rightarrow q$（**析取三段论**）。
- **Im13**：$p, p \Rightarrow_{h,k} q \Rightarrow q$（**假言推理/分离规则**）。
- **Im14**：若 $p \Rightarrow q$ 或 $h=0.5$，则 $\sim_k q, p \Rightarrow_{h,k} q \Rightarrow \sim_k p$（**拒取式**）。
- **Im15**：$p \Rightarrow_{h,k} q, q \Rightarrow_{h,k} r \Rightarrow p \Rightarrow_{h,k} r$（**假言三段论/传递性**）。
- **Im16**：$p \vee q, p \Rightarrow r, q \Rightarrow r \Rightarrow r$（**二难推理**）。

### 4. 结构性定律
- **Im17**：$(p \Rightarrow r) \wedge (q \Rightarrow r) \Rightarrow (p \wedge q) \Rightarrow r$（合并律·合取版）。
- **Im18**：$r \Rightarrow (p \wedge q) \Rightarrow (r \Rightarrow p) \wedge (r \Rightarrow q)$（泛与性/前件分配）。
- **Im19**：$\sim_k p \wedge_{h,k} p \Rightarrow k$（**广义矛盾律**，不再为 0 而是误差下界 $k$）。
- **Im18**\*：$(p \vee q) \Rightarrow r \Rightarrow (p \Rightarrow r) \wedge (q \Rightarrow r)$（合并律·析取版，素材编号重复，此处归类为泛或性）。
- **Im19**\*：$k \Rightarrow \sim_k p \vee_{h,k} p$（**广义排中律**，不再为 1 而是误差上界 $k$）。
- **Im20**：$p \Rightarrow (p \wedge q) \vee p$（吸收变体）。
- **Im21**：$(p \vee q) \wedge p \Rightarrow p$（吸收律）。
- **Im22**：$(r \Rightarrow p) \wedge (r \Rightarrow q) \Rightarrow r \Rightarrow (p \vee q)$（合并律·逆向）。
- **Im23**：$p \wedge q \Rightarrow p \vee q$（强弱关系）。
- **Im24**：$p \Rightarrow p \Rightarrow_{h,k} (p \wedge q)$（附加律变体）。
- **Im25**：$p \Rightarrow_{h,k} q \Rightarrow (r \Rightarrow p) \Rightarrow_{h,k} (r \Rightarrow q)$（蕴含的传递性嵌套）。
