# ChatGPT驱动的数据采集与清洗实战

数据分析里，采集与清洗是地基工程。就像大楼需要坚实基础，优质分析也离不开完整准确的数据源。

当下数据无处不在，从社交媒体的点赞评论，到每笔交易记录，再到医疗、交通、环境等领域的数据。这些信息既是知识宝库，也混杂着噪声、缺失和异常。如何从海量复杂数据中提炼价值，是每个分析师的必修课。采集不仅是收集，更要挑对数据源，保证质量与完整；清洗则是预处理，去重、补缺、纠错，确保后续分析可信。

本章将演示如何把 ChatGPT 的能力与数据采集、清洗的知识结合，在真实案例中落地。

### 数据采集是什么

数据采集是指收集、获取并记录特定主题、领域或对象信息的全过程。数据可以是数字化的、定量的、定性的或混合的，取决于采集目的。应用场景覆盖科研、市场调研、医疗、工程开发等。采集是分析与挖掘的基础，思路再好、模型再强，没有优质数据源也无从落地。

基本原理很简单：借助工具与方法，从不同数据源获取所需信息。数据源可以是网站、数据库、传感器、问卷等。好比去超市购物，按需求从货架挑选商品，超市即数据源，商品即数据，自己即采集工具。

### 5.2.2

### 网络爬虫原理

网络爬虫是自动化、系统化收集互联网数据的技术，爬虫不生产内容，只搬运内容。把互联网比作蜘蛛网，爬虫就是在网上爬行的蜘蛛，节点是网页，沿着链接不断爬行。

客户端发出任务指令后，爬虫 IP 通过互联网抵达目标服务器，从某个页面开始读取内容、提取源代码中的任务信息，回传客户端存储，再继续抓取，直至完成任务。

先了解几个基础概念。

（1）HTTP 请求。超文本传输协议是互联网传输网页的标准协议。输入网址即向服务器发送 HTTP 请求，获取页面内容。

（2）GET 请求。HTTP 请求的一种，用于请求数据。访问网页时浏览器会发送 GET 请求获取页面。

（3）HTML。超文本标记语言，用于描述网页结构，用标签定义文本、链接、图片等。

（4）URL。互联网资源的唯一地址，指向特定文件或服务。如 http：//blog.example.com/articles/summer-travel-tips？sort=date&user=alice#comments 指向某篇关于夏季旅行建议的文章。
