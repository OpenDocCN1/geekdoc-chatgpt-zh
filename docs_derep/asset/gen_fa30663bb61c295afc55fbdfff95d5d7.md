无论是网格搜索还是随机搜索，动辄成百上千次的试错不仅效率低下，下一步的搜索方向更像是在“盲人摸象”，完全无法预判效果，且严重损害在线用户体验，根本不适合线上评测场景。因此，改进的核心思路很明确：利用历史搜索结果指引下一步方向，提升迭代速度；同时引入在线搜索机制，加速业务闭环。为此，我们将在下一节深入剖析一种极具潜力的在线贝叶斯调参方法，详细拆解其原理与工程落地实践。

## 6.3 贝叶斯优化

针对上一节遗留的离线搜索痛点，本节引入另一把利器——贝叶斯优化算法 [2]。这是一种典型的黑盒优化手段，其核心任务可形式化定义为：

$x^* = \arg\min_x f(x)$ (6-2)

其中，$x$ 代表参数向量；$f(x)$ 映射为该参数下的线上业务指标，本质上反映推荐系统对用户行为的影响。这个函数形式极其复杂、难以显式建模，且获取真实评估值的代价高昂。贝叶斯优化正是此类“黑盒、高成本、不可导”问题的最优解之一，已在工业界广泛落地。

其核心逻辑在于：**基于已有样本构建先验，预测潜在极值点，实测真实反馈，循环迭代**。区别于网格/随机搜索的“盲目性”，贝叶斯优化每一步探索都极具目标导向，能显著压缩搜索空间，大幅提效。

算法流程如下：首先，依据采集函数 $\alpha$ 在现有数据集 $D_n$ 中选出最具潜力的候选点 $x_{n+1}$（潜力评估依赖概率代理模型与采集函数）；其次，获取该点的真实业务值 $y_{n+1}$；最后，用新样本扩充数据集至 $D_{n+1}$，同步更新代理模型。

[PRE0]

上述循环包含贝叶斯优化的两大基石：

- **1) 概率代理模型**：顾名思义，它充当“替身”逼近难以建模的真实目标函数 $f$。随着迭代持续更新，预测精度逐步提升。主流选择包括高斯过程 [3]、随机森林 [4]、深度神经网络等。
- **2) 采集函数**：基于代理模型的预测分布，量化每个候选点的“探索价值”，输出下一轮的参数向量 $x$。

### 6.3.1 概率代理模型：聚焦高斯过程

给定观测数据 $X = \{ x_i|i=1, ..., n \}, Y = \{ y_i|i=1, ..., n \}$，代理模型的任务是对新输入 $X_*$ 预测目标值 $Y_*$。

传统机器学习倾向于用逻辑回归或神经网络参数化目标函数，而**高斯过程（GP）** 另辟蹊径——它将目标函数建模为**非参数化的分布**，直接学习函数的分布特性。这赋予了 GP 天然适配黑盒优化、量化预测不确定性的能力。

我们从一维高斯分布切入理解 GP：
- 一维变量 $\sim \mathcal{N}(\mu, \sigma^2)$ (6-3)
- 多维变量 $\sim \mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ (6-4)
- 函数 $f(x) \sim \mathcal{GP}(m(x), k(x, x'))$ (6-5)

高斯过程可视为无限维随机变量的联合分布，函数上的每一点均对应一个高斯变量。如图 6-2 所示，每条曲线代表 GP 的一次采样，集合体现了函数的随机分布特性。

GP 预测均值与协方差的推导公式如下：

\]

式中 $k$ 为核函数，$\overline{Y_*}$ 为预测均值，对角线元素即预测方差。

### 6.3.2 采集函数：探索与利用的博弈

采集函数的使命是挖掘潜在最优解。GP 回归呈现特性：已观测区域方差小（利用价值高），未观测区域方差大（探索价值高）。采集函数需在“深挖已知高价值区”与“试探未知高不确定区”间动态平衡。主流三大策略如下：

- **（1）置信区间上限 (UCB) [5]**
  推荐场景“常青树”，形式简洁：
  `UCB(x) = u(x) + \beta \sigma(x)` (6-8)
  $u(x), \sigma(x)$ 为 GP 预测均值/标准差；超参 $\beta$ 控制探索激进度，$\beta$ 越大越倾向探索。

- **（2）提升概率 (PI) [6]**
  核心逻辑：计算候选点超越历史最优 $f(x^+)$ 的概率。
  [PRE4]
  通过 Z-score 标准化映射至标准正态分布，利用累积分布函数 (CDF) 量化“超越概率”；$\xi$ 调节探索强度，趋近 0 时退化为纯贪婪。

- **（3）提升期望 (EI) [7]**
  进阶版 PI，不仅问“能不能超越”，还问“能超越多少”。
  [PRE5]
  引入概率密度函数 (PDF)，对提升幅度加权求期望，决策更稳健。

**选型建议**：UCB 直观高效，PI 语义清晰，EI 理论最优但计算稍繁。实战中可结合数据均值/方差分布特征，通过 A/B 测试定夺。

## 6.4 进化策略：从自然进化中汲取优化智慧

本节转向另一条技术路线——进化策略 (ES)。进化算法家族源于达尔文“优胜劣汰”思想，主流分支涵盖遗传算法 (GA)、遗传规划 (GP)、进化策略 (ES)、进化规则等。我们将先梳理 GA 与 ES 基础原理，再聚焦多目标融合场景下的 ES 进阶实践。

#### 2. 简单进化策略 (ES)
同期诞生，同宗同源，核心差异在于**子代生成无“交叉”操作**，仅靠变异驱动。

- **$(1+1)$-ES**：单亲单子，固定步长高斯扰动，优则替劣。名中的 “+” 实为“精英保留”语义。

## 4. OpenAI ES：进化策略的“深度学习化”范式

OpenAI ES [9] 在经典 ES 框架内植入**参数化模型**（可接入 DNN 等复杂架构），实现了两大质变：
1.  **个性化建模**：像精排模型一样，输入用户/物品特征，输出个性化参数，打破“全局唯一最优”枷锁。
2.  **黑盒优化模型参数**：摒弃 BP/Adam 等梯度下降，改用**进化扰动**——在参数空间加噪，朝奖励升高方向更新。

**工程化难点与破局**：
直接存储扰动后的全量参数开销巨大、难分布式。OpenAI ES 巧妙利用**随机种子共享机制**：
- Worker 端仅存种子，按需重构扰动参数（极致压缩通信/存储）。
