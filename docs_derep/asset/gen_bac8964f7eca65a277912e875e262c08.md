### 8.5.2 一键生成正则表达式

正则表达式用于匹配和提取文本模式，由字符与操作符组成，可识别邮箱、手机号、日期等。基础概念包括：

字符匹配：如 "cat" 直接匹配该串。
通配符："." 匹配任意单字符，"c.t" 能匹配 cat/cut/c1t。
字符类：方括号 [] 定义集合，如 "[aeiou]" 匹配任一元音。
重复：* 表示 0 次以上，+ 表示 1 次以上，? 表示 0 或 1 次。
边界：^ 匹配开头，$ 匹配结尾。
转义：\ 用于转义特殊字符，如 "\." 匹配句点。
分组：() 用于捕获子串。
选择：| 表示或，如 "cat|dog"。
