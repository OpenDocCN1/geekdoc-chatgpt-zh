# 浏览器自动化抓次日天气实战

把页面打开、信息结构化抽取、自然语言归纳串成一条流水线，借助 Playwright 做页面驱动，browser_use 代理做决策，DeepSeek 模型做理解，就能实现定时抓取并输出可读简报。下面以上海为例走一遍完整链路。

准备环境
先通过命令安装依赖并下载浏览器二进制，确认驱动可用。
[PRE0]
pip install playwright
[PRE1]
playwright install

验证驱动
同步示例演示在 Chromium、Firefox、WebKit 三个内核下启动、开新标签、访问示例站、截图并输出标题，确认基础操作正常。
[PRE2]
from playwright.sync_api import sync_playwright

with sync_playwright() as p:

    for browser_type in [p.chromium, p.firefox, p.webkit]:

        browser = browser_type.launch(headless=False)

        page = browser.new_page()

        page.goto('https://www.baidu.com')

        page.screenshot(path=f'screenshot-{browser_type.name}.png')

        print(page.title())

        browser.close()

搭建抓取任务
使用 LangChain 封装的 ChatOpenAI 接入 DeepSeek，创建文本抽取优先的代理，关闭视觉以聚焦结构化信息。任务目标是访问 Bing 中文搜索结果页获取指定城市天气，并提炼次日变化与使用建议。
[PRE3]
from langchain_openai import ChatOpenAI

from browser_use import Agent

from dotenv import load_dotenv

import os

load_dotenv()

import asyncio

api_key = "sk-282074c41d594514aee6fx6f179ed292"    #从DeepSeek获取的API

base_url = "https://api.deepseek.com/beta"

model = "deepseek-chat"                          #调用的DeepSeek模型

city = "上海"

task = f"""

从下面的网页地址：

https://www.bing.com/search?q={city}天气&mkt=zh-CN

获取天气情况，并总结出明天的天气变化和注意事项。

"""

llm = ChatOpenAI(model=model, api_key=api_key, base_url=base_url)

async def main():

    agent = Agent(

        task=task,

        llm=llm,

        use_vision=False,

    )

    result = await agent.run()

    print("----------------------------------------")

    print(result)

    print("----------------------------------------")

asyncio.run(main())
