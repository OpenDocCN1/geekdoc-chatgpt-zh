# 9.1.2 三款在线执行代码插件

下面是加入早停条件的冒泡排序代码：

[PRE30]
优化版引入了 `swapped` 变量，用来记录本次遍历是否发生交换。若整轮未交换，则 `swapped` 保持 False，直接结束排序。
在最佳情况下，即输入已是有序数组，该优化可将时间复杂度降至 O(n)。但平均和最坏情况下仍为 O(n^2)，对于大块数据建议选用快速排序、归并排序或堆排序等更高效的算法。
