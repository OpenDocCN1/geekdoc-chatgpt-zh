**完整推导：**

采用反证法来说明根号2的无理性。

假定根号2是有理数，则可写成最简分数 a/b 的形式，其中 b≠0 且 a、b 互质。

1. 两边平方：

\[ (\sqrt{2})^2 = \left(\frac{a}{b}\right)^2 \]

可得：

\[ 2 = \frac{a^2}{b^2} \]

2. 同乘 b²：

\[ 2b^2 = a^2 \]

说明 a² 能被2整除，进而 a 可被2整除。令 a = 2k，k 为整数。

3. 代入上式：

\[ (2k)^2 = 2b^2 \]

得到：

\[ 4k^2 = 2b^2 \]

化简为：

\[ 2k^2 = b^2 \]

说明 b² 也能被2整除，于是 b 也可被2整除。

4. 与 a、b 互质的前提矛盾，故根号2不可能是有理数。

综上，根号2是无理数。 < | end_of_sentence | >

这段代码实例化训练器并配置了多项超参数，涉及的库包括：

- SFTTrainer（来自trl库）类：trl即transformer reinforcement learning，是Hugging Face旗下的trl库，涵盖有监督微调与强化学习功能。SFTTrainer主要承担有监督微调任务，适配LoRA等低秩微调方案。

- TrainingArguments类（来自transformers库）：用于设定训练超参，比如batch大小、学习率、优化器、训练步数等。

- is_bfloat16_supported()函数（来自Unsloth）：用于判断当前GPU是否支持bfloat16，若支持返回True，否则返回False。bfloat16是一种更高效的数值格式，在A100/H100等新一代NVIDIA显卡上表现更佳。
