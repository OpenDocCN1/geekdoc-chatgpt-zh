在常见写作场景里，职称类文章与职业晋升挂钩最紧密，对规范性和专业度要求也最高。评审时通常要递交一份符合格式的技术报告作为能力证明，这份材料必须结合岗位实际、具备一定专业深度，同时满足评审规范，是职称评审的核心附件之一。

下面以一份初级职称技术报告为例，展示如何借助结构化指令快速拿到初稿。

**身份定位：** 担任数据分析岗位的初级专业技术人员，掌握基础AI知识，需要撰写一份用于初级职称评审的技术报告，符合初级技术报告的写作规范。

**背景信息：** 近年信息技术快速演进，互联网、物联网、云计算的普及推动全球数据量指数级膨胀。传统分析手段在复杂数据环境下效率低、准确性不足。AI的引入为数据分析带来新可能，其中AI多智能体可自动抽取特征、挖掘潜在规律，显著提升效率与精度。构建基于AI多智能体的数据分析平台已成为研究热点。

**任务目标：** 撰写题为《基于AI多智能体的数据分析技术》的初级职称技术报告，结合多智能体的核心组成与应用流程，体现个人对该技术的理解与研究能力，满足初级职称评审要求。

**输出要求：** 结构完整、语言严谨专业、文风正式；篇幅8000～10000字，格式规范、段落清晰、无语法错误；贴合初级技术人员的水平，不涉及艰深理论推导，重点展现技术理解与学习能力。

收到上述结构化指令后，系统不会直接输出全文，而是先生成一份完整的大纲。大纲会依据输出要求明确各章节要点、逻辑顺序与侧重点，并细化子标题与撰写提示。用户可据实调整结构与内容方向。

“论文”功能的一大亮点是引用机制，正文中会出现真实文献的角标，点击可查看出处，并在文末按标准格式列出全部参考文献，对用户十分友好。

以限于篇幅仅展示摘要为例：

### 基于AI多智能体的數據分析技术

**摘要：** 信息技术飞速发展，全球数据量呈指数增长，传统分析方法难以应对复杂环境，AI带来新的契机。多智能体作为AI重要分支，能自动提取数据特征并发现规律，大幅提升效率与准确性。其核心主要由智能体模块、通信机制和协作策略构成。应用流程涵盖数据预处理、模型构建、结果分析。但实际使用中仍面临数据隐私安全、智能体协作冲突等难题，可借助加密技术、访问控制及优化协作机制缓解。未来多智能体有望与更多新兴技术融合，拓展数据分析应用场景。

**关键词：** AI多智能体；數據分析；核心组件；应用流程；隐私保护

需要特别强调，论文写作必须由本人主导创新设计与关键环节，AI仅作辅助。生成的草稿主要用于参考与启发，不可直接套用。

## 3.2 文本优化

文本优化是办公与学习中的高频琐事。职场中报告、通知、邮件、推广文案都需要反复打磨，既要纠错、顺句，也要按场景调整语气与结构，否则会影响信息传递效率与工作成果。

为此，AI写作模块提供了专属快捷入口，无需复杂操作即可进入优化界面。在首页找到“AI写作”，进入后可按需选择优化类型。

[PRE2]

目前支持五类优化，分别为仿写、润色、扩写、缩写、续写，覆盖不同痛点。对应场景与作用如下表所示，便于快速匹配需求。

### 表 3-6 千问文本优化功能汇总

| 优化类型 | 适用场景 | 核心作用 |
| :--- | :--- | :--- |
| 仿写 | 需要模仿特定风格或句式，如优秀文案、正式公文、学术表达 | 提取目标风格的语言逻辑与特点，快速生成符合要求的文本，降低创作难度 |
| 润色 | 文本存在语病、表达不通顺、语气不当、用词不准 | 修正错误、优化结构，提升流畅度与专业性，适配使用场景 |
| 扩写 | 原文简略内容单薄，需补充细节，如通知、报告片段、演讲稿 | 在保留核心信息前提下补充细节与解释，使文本更完整、更有说服力 |
| 缩写 | 文本冗长冗余，需提炼要点，如会议纪要、论文摘要、工作报告 | 去除多余信息，保留核心要点，缩短篇幅且不失关键内容 |
| 续写 | 文本未完待续，需保持逻辑与风格，如活动方案、演讲稿、故事片段 | 基于原文思路与风格自然延展，确保衔接流畅无断层 |

下面分别以结构化指令形式给出各类型的实操案例。

### 3.2.1 仿写

面向需要快速掌握不同文案表达逻辑的场景，如市场推广或行政公文撰写。关键在于提取参考文本的风格与句式，再结合自身需求输出。

**身份定位：** 互联网公司市场推广人员，负责智能办公软件新品的微博文案撰写，需借鉴行业优秀文案风格。

**背景信息：** 新品核心功能为文档协同编辑、会议纪要自动生成、多平台同步，目标用户为职场人群，卖点为“高效、便捷、省时”，具备可供模仿的优秀参考文案。

**任务目标：** 模仿参考文案的风格与逻辑，结合产品功能与卖点，撰写适合微博发布的推广文案，突出卖点吸引目标用户。

**输出要求：** 风格句式与参考一致，包含三个核心功能，150～200字，语言简洁通俗、语气积极，契合微博调性。

### 3.2.2 润色

适用于已成稿但表达欠佳的文本，提升规范性与感染力。

**身份定位：** 企业员工，需提交一篇以冬奥精神为主题的心得体会，用于内部学习交流，已有初稿。

**背景信息：** 初稿围绕“更快、更高、更强——更团结”展开，结合工作经历谈感受与践行思路，约2000字。但在语句、衔接与情感表达上存在不足。公司要求文稿正式真挚、逻辑清晰，突出精神要义。

**任务目标：** 对初稿进行润色，修正表达不畅与逻辑问题，加深冬奥精神与工作的结合，增强感染力，达到提交标准。

**输出要求：** 语言规范得体、逻辑严谨、情感充沛，清晰呈现精神核心要义并结合实践提出践行方向，篇幅与初稿相当，核心信息完整，文风正式。

### 3.2.3 扩写

用于内容单薄的文本补充细节与说服力。

**身份定位：** 企业行政人员，负责拟写内部垃圾分类推行通知。

**背景信息：** 为响应环保政策，公司计划于202×年×月×日起在全办公区推行垃圾分类。初稿仅写“各位同事，公司将于×月×日起推行垃圾分类，请大家严格遵守相关规定，规范投放垃圾。”内容过于简略。

**任务目标：** 扩写通知，补充分类标准、投放点位、投放要求与注意事项，便于员工明确操作规范。

**输出要求：** 结构清晰段落分明，语言正式简洁，补充可回收物、其他垃圾、有害垃圾的具体品类、各楼层投放点及时间要求、违规说明等，衔接自然，约500字。

### 3.2.4 缩写

用于提炼长文本的核心要点。

**身份定位：** 高校本科生，已完成课程论文初稿。

**背景信息：** 论文约8000字，包含摘要、引言、AI办公应用场景、存在问题、优化建议、结论等部分，含文献引用与数据说明。需提炼成符合规范的摘要。

**任务目标：** 基于上传论文进行缩写，提炼核心要点，形成完整摘要，满足课程提交要求。

**输出要求：** 摘要简洁凝练，300字以内，包含研究目的、内容、主要结论与优化建议，逻辑清晰、语言正式，无冗余与口语化表达。

### 3.2.5 续写

用于延续原文逻辑与风格完成未竟内容。

**身份定位：** 企业市场部人员，负责撰写新品发布新闻稿，已完成开头，后续未完善。

**背景信息：** 科技企业于202×年×月×日发布全新智能办公一体机，主打“高效协同、智能便捷”。已完成开头已明确发布会主题与产品定位。

# 第 3 章 千问助力高效办公

**任务目标：** 基于已完成开头与发布会速记稿，续写新闻稿后续内容，重点突出，符合正式文风，满足对外宣传需求。

**输出要求：** 与开头衔接自然，贴合“智启办公新世代”主题，补充产品核心功能、发布意义、市场定位及研发规划等，语言正式严谨，结构清晰重点突出。

文本优化功能通过五类操作覆盖办公场景的各类需求，用户按“角色+背景+目标+要求”格式输入，即可快速获得符合预期的优化结果，大幅提升效率与质量。

## 3.3 PPT制作

PPT是汇报、展示、培训的必备工具，逻辑清晰、设计简洁的演示文稿能快速传递信息并体现专业素养。传统制作耗费大量时间在内容梳理与版式调整上，AI PPT功能降低门槛，快速生成符合职场需求的演示稿。

进入方式为首页下方的“PPT”快捷入口。界面包含“我的历史”“全部模板”“给我灵感”三大标签，支持按工作汇报、培训课件、毕业答辩、商业计划、产品演示等场景筛选，也可按颜色、风格搜索。

页面中部展示模板卡片，底部支持输入主题、大纲、长文本或上传文档生成PPT，并可设定页数、语言等参数。

| 制作方式 | 适用场景 | 操作核心 | 优势 |
| :--- | :--- | :--- | :--- |
| 根据主题生成PPT | 主题明确但内容未梳理，适合快速制作小型培训或汇报 | 输入主题加详细提示词，自动梳理内容与框架 | 操作最简、耗时最短，无需提前准备 |

### 3.3.1 根据主题生成PPT

最便捷的方式，适用于主题明确但未展开内容的场景。用户输入清晰主题与提示词后，系统自动梳理核心内容、搭建框架并设计版式，特别适合紧急的培训或小型汇报。

以“新员工职场礼仪培训”为例：

**身份定位：** 具5年企业新员工培训经验的培训师，擅长职场礼仪课程设计。

**背景信息：** 某互联网公司50名应届生入职，缺乏职场礼仪经验，需开展1小时培训，帮助其快速掌握礼仪要点，树立职业形象。

**任务目标：** 基于主题生成完整培训PPT，梳理核心内容、搭建讲解框架，匹配培训场景。

**输出要求：** 逻辑清晰，结合简单职场案例，避免过度理论化。

发送后系统先输出大纲供确认，确认无误后再进入下一步生成，确保内容可控。
