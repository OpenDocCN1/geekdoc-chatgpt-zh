## 4.2 编码

用不同的数码来标记不同事物或状态时，数码本身已不再表示量的大小，而只是代号。把这类数码称为代码。如长跑比赛给运动员编号，编号仅用于区分身份，不具备数量含义。为便于记忆和查找，编码时需遵循一定规则，该规则即为码制。编码规则可因人而异，但为了信息互通，还需制定通用的标准，如国际上通用的美国信息交换标准代码 ASCII。

8421 码又称 BCD，即二进制编码的十进制码，是最常用的十进制编码。在该码中，每一位上的 1 代表一个固定权值，各位权值相加即得到代表的十进制数码。8421 码的各位权依次为 8、4、2、1，故称 8421，属于恒权码。
余 3 码的构造与 8421 不同，若把余 3 码视作 4 位二进制数，其数值比所代表的十进制数大 3，因而得名。两个余 3 码相加，结果会比十进制和对应的二进制数多 6，所以作十进制加法时，若和为 10，恰好等于二进制的 16，从而自动产生进位。此外，0 与 9、1 与 8、2 与 7、3 与 6、4 与 5 的余 3 码互为反码，便于求 10 的补码。余 3 码是非恒权码，代码中每一位的 1 并非固定权值。
2421 码是一种恒权码，其 0 与 9、1 与 8、2 与 7、3 与 6、4 与 5 也互为反码，特点与余 3 码相近。
余 3 循环码属于变权码，每一位的 1 在不同代码中权值不固定。其显著特征是相邻两码仅有一位不同。

#### 2. 格雷码
格雷码亦称循环码。由表 4 - 3 的 4 位格雷码可见其生成规律：每一位的取值按一定顺序循环。由 0000 起，最低位按 0110 循环变化，次位按 00111100 循环，第三位按 0000111111110000 循环，由右向左，每位的 0、1 连续段数翻倍。4 位共 16 个码，最高位仅半个循环，即 0000000011111111。按此原则可扩展到更多位数。
与常规二进制相比，格雷码的最大优点是相邻码之间仅有一位发生变化，因而代码转换时不会产生过渡噪声。普通二进制在转换时可能出现短暂的中间态噪声，例如 0011 转 0100 时若变化不同步，会瞬间出现 0101，而格雷码 0010 转 0110 则不会出现此类现象。该噪声在某些电路中会干扰正常工作。

#### 3. 奇偶校验码（检错码）
奇偶校验位用于指示一组数中 1 的个数是奇数还是偶数。很多系统都借助奇偶校验位检测位错误。任意位组中 1 的个数可能是奇数也可能是偶数。通过附加一位校验位，可使整组 1 的个数始终为偶数或始终为奇数。偶校验使总数为偶数，奇校验使总数为奇数。
系统只能工作于偶校验或奇校验其一。例如偶校验系统会检查接收到的每组数中 1 的总数是否为偶数，若出现奇数则判定出错。

## 4.3 逻辑代数
上一节提到，数码既可表示数量大小，也可表示不同事物。在数字逻辑电路中，常以二进制的 0 和 1 表示某一事物的两种对立逻辑状态，如真/假、有/无、通/断、亮/暗、开/关等。这种只有两种状态的逻辑关系称为二值逻辑。
“逻辑”在这里指事物间的因果关系。当两个二进制数码代表不同逻辑状态时，可按既定因果关系进行推理运算，这就是逻辑运算。
1849 年乔治·布尔提出布尔代数，后因其在开关电路和数字逻辑中的应用而被称为开关代数或逻辑代数。本节讨论的是布尔代数在二值逻辑电路中的应用。逻辑代数中用字母表示变量，称逻辑变量，其运算表示的是状态间的推理，而非数值运算。
二值逻辑中每个变量只有 0、1 两种取值，但多变量组合可表示多种逻辑状态，从而处理复杂问题。
逻辑代数的基本运算有与、或、非三种。
