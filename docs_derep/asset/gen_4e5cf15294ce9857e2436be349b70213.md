    1. 考虑一个直角三角形，直角边分别为 a 和 b，斜边为 c。

    2. 将该三角形复制三个，拼接成一个大正方形，其边长为 a+b。

    3. 大正方形的面积为 (a+b)²。

    4. 在大正方形内部，由四个三角形围成一个小正方形，其边长为 c，面积为 c²。

    5. 因此，大正方形的面积也可以表示为小正方形的面积加上四个三角形的面积，即 c²+4*(1/2*a*b)。

    6. 将两种面积表示方式相等，得到 (a+b)²=c²+2ab。

    7. 展开并简化，得到 a²+2ab+b²=c²+2ab。

    8. 消去 2ab，最终得到 a²+b²=c²。

因此，勾股定理得证。

### 11.3.3 高并发场景的吞吐提升与并发控制

在流量激增时，使用 DeepSeek-R1 API 需要同时兼顾吞吐和稳定性。以下策略可供参考：

批处理请求把多条请求合并为一次传输，减少网络往返，提升整体吞吐。代价是单次响应可能变慢，需要根据业务权衡批次大小。

异步请求利用异步编程模型，在等待模型返回时继续处理其他任务。Python 里可用 asyncio 配合 aiohttp 等异步客户端实现。

连接池管理复用 HTTP 连接，避免频繁建连拆连带来的开销。requests 的 Session 或 aiohttp 的连接器都内置了该功能。

负载均衡在服务端将请求分发到多个实例，避免单点过载，提升系统整体承压能力。

缓存机制针对高重复度的查询进行本地或服务端缓存，减少无效调用，降低时延和费用。

资源限制与流量控制设定并发上限和 QPS 上限，为不同用户或服务分配配额，防止过载导致崩溃。

性能监控与调优持续采集响应时长、错误率、吞吐量等指标，及时定位瓶颈并优化，保证高并发下的稳定运行。
