#### 1.3.2 并行与异步处理：Multiprocessing与Asyncio

在 AI 系统与检索增强项目中，一旦面对海量数据处理、模型训练或大规模网络请求，单线程很容易成为瓶颈。引入并行与异步机制可以明显提升执行效率。Multiprocessing 依靠多进程实现计算并行，Asyncio 则利用协程应对大量 I/O 场景，例如网络请求与文件读写。

下面通过两个示例分别说明 Multiprocessing 与 Asyncio 的应用思路，对应计算密集型与 I/O 密集型任务。

Multiprocessing 更适合 CPU 密集型工作，能够发挥多核优势。示例演示如何借助 multiprocessing.Pool 在多个进程中并行计算一组数据的平方值，提升处理速度。
