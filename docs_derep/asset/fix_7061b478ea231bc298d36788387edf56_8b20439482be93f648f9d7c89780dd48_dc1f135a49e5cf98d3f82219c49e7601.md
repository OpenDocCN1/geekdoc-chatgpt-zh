## 12.2 Python 程序设计基础

## 12.2.1 流程控制
与其它语言相同，Python 程序包含顺序、选择与循环三大结构。

顺序结构：自始至终依次执行，不会重复也不会跳过。

选择结构：依据条件决定执行哪一段代码。

循环结构：在条件成立时反复执行同一段代码。

### (3) 嵌套循环
Python 允许在循环体内再嵌套循环，`while` 与 `for` 均支持。外层控制整体次数，内层在每次外层迭代中完整执行。

执行流程为：

①外层条件为真时执行外层循环体；

②外层体中包含内循环，内层条件为真时反复执行，直至为假；

③外层条件仍为真则继续，至外层条件为假；

④内层与外层条件皆为假时嵌套循环结束。
