### 7.2.1 Python 程序的输入/输出

输入输出是程序与使用者交互的基础，可从用户处收集数据并把处理结果呈现出来。

1. 获取用户输入
Python 内置 input() 用来接收用户输入，返回值统一为字符串。若需要数值类型，需用 int() 或 float() 转换。

例如：
name = input("请输入你的名字：")
print("你的名字是：" + name)
age = int(input("请输入你的年龄："))
print("你的年龄是：" + str(age))

2. 输出结果
输出统一使用 print()，可传入字符串、数字、变量或其它对象，会自动转为字符串在控制台显示。

例如：
print("Hello, World!")
name = "Alice"
print("Hello, " + name + "!")

3. 文件输入/输出
通过 open() 打开文件得到文件对象，再用 read() 读取或 write() 写入。推荐用 with 管理上下文自动关闭。

例如：
# 写入文件
with open("test.txt", "w") as f:
    f.write("Hello, World!")
# 读取文件
with open("test.txt", "r") as f:
    content = f.read()
    print(content)

### 7.2.2 变量

变量相当于一个可以存取数据的容器，用来暂存中间结果。Python 采用直接赋值方式，无需显式声明类型。

1. 变量的使用
用等号 = 进行赋值，左侧为变量名，右侧为值。

例如：
x = 5
name = "Alice"

2. 变量的命名规则
· 只能由字母、数字和下划线组成，且必须以字母或下划线开头，不能以数字开头。例如 variable1 合法，1variable 不合法。
· 不能包含空格，可用下划线连接单词，如 my_variable。
· 不能使用 Python 关键字，如 for、if、and、or 等。
· 名字最好具有描述性，如 name 比 n 更清晰。
· 区分大小写，Name 与 name 是两个不同变量。

例如：
my_name = "Alice"
age = 20
_is_student = True

### 7.2.5 Python 语法规则

语法是理解程序的关键，下面介绍缩进、注释和多行语句三项基础规则。

1. 缩进
Python 用缩进界定代码块，if、for、while 等语句体必须缩进。习惯上每层 4 个空格。

例如：
if True:
    print("This is true")  # 缩进表示属于 if 代码块

2. 代码注释
注释不参与执行，用来说明意图。单行注释以 # 开头，多行注释可用三单引号 ''' 或三双引号 """ 包裹。

例如：
# 这是一个单行注释
print("Hello, World!")  # 行尾注释
'''
这是一个多行注释
可跨越多行
'''
print("Hello, World!")

3. 多行语句
语句过长可用反斜杠 \ 续行，或借助括号自动换行。

例如：
total = 1 + 2 + 3 + \
        4 + 5 + 6 + \
        7 + 8 + 9

控制语句分为条件、循环和跳转三大类。条件语句有 if、elif、else；循环语句有 for、while；跳转语句有 break、continue、pass。具体语法见表 7-8。

1. 简单的 if 条件语句
条件为真时执行代码块。

例如：
age = 20
if age >= 18:
    print("你是成年人了。")

2. if else 语句
条件为假时执行 else 部分。

例如：
age = 16
if age >= 18:
    print("你是成年人了。")
else:
    print("你是未成年人。")

3. if elif else 语句
多条件分支判断，先满足即执行。

例如：
age = 16
if age >= 18:
    print("你是成年人了。")
elif age >= 13:
    print("你是青少年。")
