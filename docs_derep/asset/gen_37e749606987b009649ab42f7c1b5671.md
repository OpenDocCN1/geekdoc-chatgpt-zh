### 8.1.3 反池化机制

本节重点解析反池化操作，主要包含反平均池化与反最大池化两大类。

**(1) 反平均池化**
平均池化的过程是将窗口内数值求和取均值，而反平均池化则是将这一均值逆向传回上一层。具体做法是把计算出的平均数值均匀分配给池化窗口对应的每个位置，从而保证池化前后梯度总和维持不变。图8-9直观展示了这一分配过程：反向传播时，窗口内每个位置均获得相同的数值。

[PRE2]

**图8-9 反平均池化的计算过程**

**(2) 反最大池化**
最大池化仅保留窗口内的最大值并丢弃其余值。反最大池化的任务是将这个最大值原路返回，精准填回池化前的原始位置，其余位置则补零。与反平均池化不同，此操作**必须**在正向传播时记录下最大值的坐标索引，否则无法保证反向传播的位置正确性。如图8-10所示，还原后的数组中，最大值位置与输入阶段完全对齐，其余位置均为“0”。

**核心提示**
- 池化层本身不包含可学习参数，训练过程中无需计算梯度，仅负责传递残差项。
- 最大池化需缓存最大值坐标，便于反向时定点填值、其余补零；平均池化反向时则将均值平铺至窗口所有位置。

### 8.1.4 激活函数层

激活函数构建了上下层神经元间的非线性映射关系。若缺少它，网络将退化为单纯的线性叠加，表达能力等同于传统感知机，难以应对复杂任务。引入非线性激活，赋予了模型逼近任意复杂函数的能力。

常见激活函数沿用前馈网络经典体系，主要包括 ReLU、Softmax、Sigmoid 等。

**ReLU（线性整流函数）**
当前深度学习领域的“主力”激活函数。其分段线性特性表现为：输入大于零时原值输出，小于零时归零。

*优势：*
1.  正区间梯度恒为1，有效缓解梯度消失难题。
2.  计算仅涉及阈值判断，执行效率远超 Sigmoid 等指数运算函数。

*短板：*
负半轴梯度为零，导致神经元“死亡”，参数停止更新。

**Softmax**
专为多分类任务设计，将输出向量映射为概率分布（值域 0~1），概率最大的类别即为预测结果。

*局限：*
1.  零点处不可导。
2.  输入为负时梯度消失，阻碍反向传播中的权重迭代。

**Sigmoid (Logistic函数)**
输出压缩在 (0,1) 区间，大输入趋近1，小输入趋近0，常用于二分类场景。

*特性：*
- 优点：曲线平滑，求导简单（导数可用函数值本身表示）。
- 缺点：两端饱和区梯度趋近于零，极易引发梯度消失，导致深层网络训练受阻。

### 8.1.5 全连接层

全连接层通常部署于网络尾端，扮演“分类器”角色。前序的卷积与池化完成特征提取，全连接层接管这些扁平化后的一维特征向量，执行最终分类。连接前需将多维特征图展平为向量，随后与全连接网络输入层逐元素连接，形成稠密拓扑。输出端通常配合激活函数给出预测概率。

### 8.2.2 感受野分析

**感受野** 定义为输出特征图上单个像素点在原始输入图像上对应的映射区域大小。这类似人类视觉：单个神经元仅感知局部，通过层层叠加局部特征，最终构建全局认知。正如反复观察物体细节后能识别整体，网络亦是通过积累局部信息获取全局语义。

**实战指南**
1.  **以小代大**：用多层小卷积核替代大卷积核，可减参数、加深度、扩感受野；网络越深，感受野越大，性能通常越优。

4.  **计算规则**：感受野大小计算**不考虑** padding 影响。

### 8.2.3 填充策略

直接卷积会导致边缘信息流失：边缘像素参与计算次数少，且无法与卷积核中心对齐，造成特征提取不足。为保持输入输出尺寸一致、保护边缘特征，引入**填充** 机制，常用常数 0 扩展边界，使边缘像素获得更多卷积机会。图8-13演示了零填充示意。

[PRE8]

图8-13 填充示意

图8-14列举三种主流模式：

[PRE9]

图8-14 填充的3种模式

1.  **Full 模式**：卷积核与输入刚接触（仅1个元素重叠）即开始计算，外围全量填 0 直至卷积核完全覆盖填充区。
2.  **Same 模式**：卷积核中心对准输入首元素时启动计算，外围填 0 保证输出尺寸与输入一致（步长为1时）。
3.  **Valid 模式**：卷积核完全落入输入区域内才计算，无填充，输出尺寸缩小。

**问题与对策**
- 连续卷积导致特征图急剧缩小，边缘信息衰减。
- 全零填充旨在锁定输出尺寸，防止边缘特征被忽略。
