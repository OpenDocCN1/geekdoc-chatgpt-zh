## 1.4 提示词的运用

在通义里，提示词是人与模型沟通的核心桥梁。掌握好写法，就能更高效地用好通义，拿到更符合预期的结果。

### 1.4.1 提示词是什么

提示词是用日常自然语言向通义下达指令或提出任务的表达。可以是简单的问答，比如“今天北京天气如何？”，也可以是复杂的创作需求，比如“帮我写一首描写春天的诗”。

借助提示词，用户能清晰传达意图，通义则凭借自然语言理解与深度学习能力快速给出匹配的答案或内容。简而言之，提示词就是告诉通义你要它做什么。表达越清晰，交互效率与便利性就越高，获取信息、完成创作、执行任务都会更轻松。

### 1.4.2 如何构建优秀的提示词

高质量的提示词能让通义更精准理解意图，提升交互效果；反之，模糊的提示词会浪费时间，得到的结果也难以满意。

#### 1. 提示词的构成要素

提示词=任务说明+背景资料+关键词+具体要求。

- (1) 任务说明：清楚描述希望通义完成的具体事项，可以是问题、主题或明确任务。
- (2) 背景资料：提供相关上下文或资料，帮助模型更好把握需求。
- (3) 关键词：点明模型需要关注的核心信息或问题。
- (4) 要求：列出格式、字数、语气、风格、角色扮演、示例等特殊限制和偏好。

#### 2. 不佳的提示词示例

| 提示词 | 主要问题 |
| :--- | :--- |
| 生成一篇文章 | 任务和方向缺失，模型无法判断文章类型和主题 |
| 阅读这篇文章并给出意见 | 缺少明确的评价维度与输出形式 |
| 讨论AI的风险 | 问题过于宽泛，缺乏限定方向，输出容易发散 |
| 生成一张图片 | 未说明画面内容与风格，指向不明 |
| 写一段对话 | 没有背景和主题，无法确定对话人物和情境 |

#### 3. 优秀的提示词示例

例如要让通义写一段关于环保的对话，可以这样组织：

- 任务说明：生成一段关于环境保护重要性与可行性的对话，并给出方案。
- 背景资料：当前环境议题涉及气候变化、污染、资源浪费等。
- 关键词：环境保护、气候变化、污染、资源浪费。
- 要求：对话至少两位参与者，每人提出至少两个保护方案，总字数控制在500~800字。

整合后的完整提示词：

生成一段对话，围绕环境保护的重要性与可行性展开并提出具体方案。对话中需至少两位参与者，每人至少给出两个环保建议。同时深入探讨环境保护、气候变化、污染、资源浪费等议题，呈现不同观点。请控制总字数在500~800字之间。
