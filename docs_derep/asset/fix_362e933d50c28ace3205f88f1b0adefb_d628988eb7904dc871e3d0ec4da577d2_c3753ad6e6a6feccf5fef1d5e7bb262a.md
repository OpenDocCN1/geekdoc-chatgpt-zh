Stable Diffusion 作为一款人工智能绘画工具，其本身是一个开源的模型，使用它需要具备一定的计算机语言和编程基础，这对于大多数不熟悉代码的用户来说构成了使用门槛。因此 Github 社区出现了 Stable Diffusion Web UI 的开源项目，旨在为 Stable Diffusion 编写 Web UI 版本，以降低其使用门槛，使普通用户也能通过可视化界面轻松使用。从此，Stable Diffusion Web UI 就在广大用户中流传起来。本节将介绍 Stable Diffusion 软件的配置及相关基础知识。
