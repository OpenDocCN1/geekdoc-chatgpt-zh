#### 8.3.2 客户端概览

Chroma 的客户端是与服务或数据库交互的实例，主要包含 EphemeralClient、PersistentClient、HttpClient、Client。

##### 1. EphemeralClient

EphemeralClient 在内存中创建临时 Chroma 实例，适合测试与开发。生产环境不建议使用。

##### 2. PersistentClient

PersistentClient 会把数据持久化到磁盘，便于测试与开发调试。同样不推荐在生产环境使用。

path 参数决定数据目录，默认是 ./Chroma。

##### 3. HttpClient

HttpClient 用于连接远程 Chroma 服务器，支持多客户端并发，生产环境推荐。

参数说明如下。

- host：服务器主机名，默认 localhost。
- port：服务器端口，默认 8000。
- ssl：是否使用 SSL，默认 False。
- headers：发往服务器的请求头字典，默认空。

#### 8.3.3 数据操作方法

Chroma 的数据操作与传统数据库类似，功能丰富。

##### 1. count()

统计已写入数据库的嵌入对象总数，返回整数。

##### 2. add()

把数据写入集合。

参数说明如下。

- ids：嵌入的 ID。
- embeddings：可选嵌入向量，未提供时由集合的嵌入函数根据文档自动计算。
- metadata：可选元数据，查询时可作筛选。
- documents：可选文档。

执行后不返回内容，返回值为 None。

使用方法如下。

[PRE11]

##### 3. get()

按条件检索嵌入及其关联数据。若不指定 ID 或筛选条件，则从偏移量开始返回全部数据，受限制控制。

参数说明如下。

- ids：可选，要检索的 ID 列表。
- where：可选筛选字典，如{"color": "red", "price": 4.20}。
- limit：可选返回上限。
- offset：可选起始偏移，用于分页。
- where_document：可选按文档内容筛选，如{"$contains": {"text": "hello"}}。
- include：可选指定返回内容，允许“嵌入”、“元数据”、“文档”，ID 始终包含，默认包含“元数据”和“文档”。

返回 GetResult 对象。

##### 4. peek()

获取数据库前若干结果，受 limit 控制。

limit 指定返回数量。返回 GetResult 对象。

##### 5. query()

查找与提供的 query_embeddings 或 query_texts 最接近的 n_results 个邻居。

参数说明如下。

- query_embeddings：可选近邻检索用的向量。
- query_texts：可选近邻检索用的文本。
- n_results：可选每个查询返回的邻居数。
- where：可选筛选字典。
- where_document：可选按文档内容筛选。
- include：可选指定返回内容，允许“嵌入”、“元数据”、“文档”、“距离”，ID 始终包含，默认["metadatas", "documents", "distances"]。

返回 QueryResult 对象。

使用方法如下。

[PRE12]

##### 6. modify()

更新集合的名称或元数据。执行后不返回内容。

参数说明如下。

- name：可选更新后的名称。
- metadata：可选更新后的元数据。

##### 7. update()

更新指定 ID 的嵌入、元数据或文档。

参数说明如下。

- ids：要更新的 ID 列表。
- embeddings：可选新向量，未提供时由嵌入函数根据文档自动计算。
- metadata：可选更新后的元数据，可用于筛选。
- documents：可选更新后的文档。

执行后不返回内容。

##### 8. upsert()

对已存在 ID 进行更新，不存在则创建。

参数说明如下。

- ids：ID 列表。
- embeddings：可选新向量，ID 不存在时由嵌入函数根据文档计算。
- metadata：可选更新或创建时的元数据。
- documents：可选更新或创建时的文档。

执行后不返回内容。

##### 9. delete()

基于 ID 或 where 筛选器删除嵌入。

参数说明如下。

- ids：要删除的 ID 列表。
- where：可选筛选条件字典，如{"color": "red", "price": 4.20}。
- where_document：可选基于文档内容的 WhereDocument 字典，如{"$contains": {"text": "hello"}}。

组合使用可精确控制删除范围。

#### 8.3.4 使用集合

Chroma 支持用原生集合原语高效管理嵌入集合。

##### 1. 创建、检查和删除集合

集合名称在 URL 中起作用，需遵守规则。

- 长度 3~63 个字符。
- 以小写字母或数字开头和结尾，中间可含点、破折号、下画线。
- 不得出现连续两个点。
- 不能是有效 IP 地址。
