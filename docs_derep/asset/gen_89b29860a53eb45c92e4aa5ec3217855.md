# 技巧03 获取DeepSeek API密钥

DeepSeek官网或App在访问量过大时常出现“服务器繁忙，请稍后再试”提示。为更顺畅使用，可考虑通过API访问。

API是连接DeepSeek网络服务的“通行证”，获取后可在各类第三方应用中使用DeepSeek。

因DeepSeek为开源AI产品，除官方提供API外，多家专业云平台与AI服务商也提供其API。

## 获取DeepSeek官方API

进入DeepSeek官网，点击页面右上角的【API开放平台】命令，如图1-6所示，即可进入API开放平台。

图1-6 API开放平台

按提示注册登录后，先点击左侧窗格【API keys】，再点击右侧【创建API key】按钮，随后在弹框中输入自定义API名称，最后点击【创建】按钮，如图1-7所示。

图1-7 创建API key

弹出如图1-8所示对话框后，点击【复制】按钮，将API key复制后粘贴至记事本保存备用。

图1-8 复制API key

点击左侧窗格【充值】选项，先完成实名验证，再进行充值，如图1-9所示。需注意充值金额仅用于调用API服务，网页对话与App对话免费，无需充值。

图1-9 充值
