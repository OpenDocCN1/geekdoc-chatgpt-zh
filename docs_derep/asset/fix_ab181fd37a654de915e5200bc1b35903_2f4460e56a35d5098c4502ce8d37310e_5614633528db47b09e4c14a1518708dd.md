#### 6.1 CLIP 原理与实践

CLIP 通过对文本与视觉模态的联合建模，实现了跨模态语义对齐与嵌入生成。本节先探讨图文联合嵌入的核心技术，包括多模态特征抽取、嵌入空间共享与优化方法。随后分析 CLIP 的预训练目标及其迁移表现，重点阐述其如何借助大规模对比学习实现通用化与高效适配。

##### 6.1.1 图文联合嵌入技术

图文联合嵌入的目的是学习跨模态的统一语义表征，实现图像与文本的深度关联。做法是将文本与图像分别编码为向量后映射到共享空间，使语义相近的配对在空间中更靠近。该架构通常采用双分支设计，分别包含文本编码器与视觉编码器。预训练阶段通过对比学习优化目标，最小化匹配配对的距离并拉大不匹配配对的距离。此外，温度系数调节与对比损失权重等正则化手段可进一步提升训练效果。

CLIP 借助对比学习完成文本与图像的联合嵌入，如图6-1所示，在多模态任务中表现突出。图像编码器与文本编码器分别将输入映射为高维向量，通过提升匹配样本相似度、降低非匹配样本相似度来优化嵌入空间。
