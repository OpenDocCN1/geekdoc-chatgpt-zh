### 第 14 章 爆款图文批量制作

在互联网时代打造个人 IP 至关重要，个人内在特质是 IP 的核心竞争力，清晰独特的定位能帮助脱颖而出。

打造成功 IP 除明确定位外，还需关注内容、流量、转化、产品四大要素，其中内容是基础，贯穿转化与产品，对 IP 建设起决定作用。

特色图文自带鲜明 IP 属性，众多自媒体正是借助创意图文迅速建立个人品牌。AI 可批量生成内容，但只有能提供高质量、稳定可控的 AI 工具，才能在 AI 时代帮助用户建立有价值的个人 IP。

借助扣子平台的可视化设计与编排能力，用户可通过零代码或低代码方式快速搭建基于大模型的多类 AI 工具，高效产出精准可控内容，尤其在图文编辑方面更能满足个性化需求。

本章介绍如何利用扣子 Agent 批量生成爆款图文。

#### 14.1 场景概述

以下以自动生成长期热销且自带流量的“古人穿越”系列图文为例，说明如何搭建 Agent 并批量生成兼具幽默与古今碰撞的 IP 风格图文。

##### 14.1.1 场景描述

“古人穿越”系列的关键在于选用高辨识度的古代人物形象，如关羽、张飞、林黛玉、哪吒等，并将其与现代元素结合，如手机、办公室等，配以引发共鸣的职场吐槽或生活化文案。

古今反差带来的幽默效果，既适合日常输出，也可结合传统节日进行热点营销。其视觉冲击、情感共鸣与传播便捷性，有助于持续吸流并强化个人 IP。

##### 14.1.2 痛点分析

自媒体在创作此类图文时常遇到：

- 传统图像编辑软件需美术功底，普通用户难以实现古今元素的自然融合，即便专业人士也耗时耗力。
- 普通软件无法批量生成同一主题系列图像，难以快速产出多样内容。
- 专业软件需支付高昂许可费用。

#### 14.2 需求分析

##### 14.2.1 场景分析

本场景核心目标为批量生产爆款图文，基于古代名人穿越现代的创意设定，结合反差文案，打造具有中国特色的幽默视觉效果。

采用 5W2H 分析：

- What：以古代人物穿越现代为主题，从古人视角解读现代人典型话语，采用中国水墨画风，通过古今混搭增强反差。
- Why：经典 IP 自带流量，反差内容易引发共鸣，互动性强。
- Who：面向年轻网民如 Z 世代、二次元爱好者、传统文化爱好者及偏好古今反差与冷幽默的用户。
- When：适合日常更新，也可结合传统节日做系列运营。
- Where：需适配小红书、微信公众号等平台规范。
- How：操作步骤一般为收集用户需求如人物、场景、情绪；利用 AI 生成文生图提示词；基于提示词生成图像；将图像与文案合并。
- How Much：追求高性价比，优先免费或低成本方案。

##### 14.2.2 解决方案梳理

现有 AI 图像生成平台如即梦、豆包等虽可实现功能，但存在局限：平台一次性生成图像，图文混排易出现乱码；每次生成需重新输入提示词；批量图文稳定性难以保证。
