手写自动微分：从框架用法到自制 Tape 的对照

用框架求导是日常训练的标配，但如果把 PyTorch、MindSpore 这类库的自动求导剥开来看，其实就是正向记录、反向链式的组合。下面用同一个目标函数先看现成的实现，再看一个极简的手写版本。

先看 PyTorch 经典的 Variable 模式，设置 requires_grad 后调用 backward 就能得到梯度。
[PRE0]python

import torch

from torch.autograd import Variable

x = Variable(torch.Tensor([2.]), requires_grad=True)

y = Variable(torch.Tensor([5.]), requires_grad=True)

f = torch.log(x) + x * y - torch.sin(y)

f.backward()

print(f)

print(x.grad)

print(y.grad)

输出与预期一致，函数值和两个偏导都被算出来了。

def ops_mul(self, other):

    # forward

    x = Variable(self.value * other.value)

    print(f'{x.name} = {self.name} * {other.name}')

    # backward

    def propagate(dl_doutputs):

        dl_dx, = dl_doutputs

        dx_dself = other # partial derivate of r = self*other

        dx_dother = self # partial derivate of r = self*other

        dl_dself = dl_dx * dx_dself

        dl_dother = dl_dx * dx_dother

        dl_dinputs = [dl_dself, dl_dother]

        return dl_dinputs

    # record the input and output of the op

    tape = Tape(inputs=[self.name, other.name], outputs=[x.name], propagate=propagate)

    gradient_tape.append(tape)

    return x

用一个具体函数来说明整体流程：
$f(x_1, x_2) = \ln(x_1) + x_1 x_2 - \sin(x_2)$
在基于操作符重载的自研实现里，自变量先被包成 Variable，再通过 `f = Variable.log(x) + x * y - Variable.sin(y)` 这种写法触发前向计算并记录 Tape。反向时沿 Tape 倒序传播，就能得到与框架一致的梯度。
