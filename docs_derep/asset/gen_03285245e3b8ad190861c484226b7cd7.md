### 5.3 经验与注意事项

5.2 节详细说明了如何让 ChatGPT 成为英语学习助手，本节将重点讲清如何设定语言难度、如何把英语能力结合 ChatGPT 应用到工作场景，并提醒人类教师仍有 AI 无法替代的优势。

#### 5.3.1 如何指定难度级别

5.1.1 节基于“第二语言习得”理论强调了难度匹配的重要性，5.2.1 节也在提示词中多次涉及指定难度技巧。

本节将详细介绍常用的语言能力分级标准，并说明如何借助不同风格实现英语进阶练习。

##### 1. 从标准的语言能力分级入手

（1）为什么需要标准语言能力分级

市面上的英语学习材料种类繁多，如何找到合适的材料一直是学习者的难题。AI 工具的出现让个性化定制成为可能，学习者可按自身需求让 AI 生成专属材料。5.2 节的案例中，不少材料都是按学习者水平生成的，而量身定制的关键在于对难度的精准把控。

若不对 ChatGPT 提出难度要求，生成的文本可能对一部分人太难，对另一部分人又太简单。因此学习者需要一个 AI 能充分理解的标准分级体系来精确控制输出难度。

（2）什么是 CEFR 标准

此时就需要引入 CEFR 语言能力标准。CEFR 是国际上广泛认可的语言能力评估体系，起源于欧洲，适用于任何语言的学习、教学与评估。这套标准被 ChatGPT 深度理解并能快速应用，5.2 节多次使用 CEFR 等级。

CEFR 将语言能力分为三大类：基础使用者、独立使用者、熟练使用者，每类再分两个子级，共六个等级：A1、A2、B1、B2、C1、C2。

CEFR 语言能力分级见表 5-1。

表 5-1 CEFR 语言能力分级

| CEFR 等级 | 使用者能力 |

| :--- | :--- |

| A1 | 基础使用者，初级。能理解和使用日常表达和简单句子来满足基本需求 |

| A2 | 基础使用者，初中级。能理解和使用常见的句子和表达，在简单直接的交流中能满足具体需求 |

| B1 | 独立使用者，中级。能理解关于工作、学习、休闲等方面的主题，能应对大多数旅行遇到的情况 |

| B2 | 独立使用者，中高级。能理解复杂的文本，能进行流畅的交流，能在专业、学术或社交场合清晰有效地表达自己 |

| C1 | 精通使用者，高级。能理解大量长篇和难度大的文本，能流畅、自然地使用语言在任何复杂的情况下有效沟通 |

| C2 | 精通使用者，超高级。几乎相当于母语者的水平，能理解任何形式的语言，能精准、流畅地表达和描述复杂的主题，包括对细节的处理和对含义的理解 |

在 CEFR 框架下，每个等级都有对应的词汇表和语法技能对照。因此在使用 ChatGPT 时，只需指定 CEFR 语言等级，ChatGPT 即可准备相应难度的词汇和语法材料。

那么如何判断自己的 CEFR 等级？事实上，主流英语考试都已与 CEFR 做过对标。以雅思和托福为例，网上很容易找到对应的能力对照表。用户可依据自己的考试成绩推算出大致的 CEFR 等级。
