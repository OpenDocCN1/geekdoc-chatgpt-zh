**8.1.2 了解 C++**

**1.C++的起源与发展**

C++是在 C 语言之上演进的。20 世纪 70 年代，C 语言面世，以简洁高效著称，在计算机领域迅速普及。进入 20 世纪 80 年代，为满足面向对象编程的需求，Bjarne Stroustrup 在 C 语言基础上引入类与对象等机制，创立了 C++。此后语言持续演进，形成了 C++98、C++11、C++14 等多个标准版本，每个版本都新增特性与功能。

NOI 科学委员会对 NOI 系列活动包含 CSP-J/S 的编程语言使用作出说明：C++程序编译默认采用 C++14 标准。信息来源：NOI 官网。

**2.C++的特点**

（1）性能优异，编译后运行迅速，内存消耗低，适合高性能场景。
（2）支持面向对象编程，通过类、继承、多态实现代码封装与复用。
（3）向后兼容，完全兼容 C 语言语法，可直接调用 C 代码及库。
（4）兼具灵活性与功能性，提供指针、模板等机制，兼顾底层操作与泛型编程。
（5）标准库丰富，内置数据结构、算法、输入输出等基础组件，降低开发门槛。

**3.C++的应用领域**

（1）操作系统。操作系统核心在于高效管理硬件资源。C++具备强大的底层操作能力，可直接与硬件交互，精确控制内存、处理器、输入输出设备等，因而成为开发 Windows、Linux 等系统核心代码的常用语言。
（2）应用软件。C++广泛应用于桌面与专业软件。这类软件需要兼顾功能复杂度与运行流畅度，C++的高效、跨平台与可扩展性使其成为首选。例如 Office 套件的排版与计算模块、Adobe 系列、AutoCAD 等，其图形渲染与数据处理逻辑多由 C++实现，能在处理大规模数据时保持稳定高效。
（3）嵌入式系统。在资源受限、实时性要求高的终端设备中，C++的性能与内存控制能力得到充分发挥。如智能门锁需快速响应指纹与密码验证并控制锁具；自动驾驶汽车的视觉感知系统借助 C++驱动硬件实时分析图像，识别行人车辆等目标，保证有限资源下的稳定运行。
（4）尖端科技。C++是前沿高科技的底层支撑语言，以极致执行效率、精准内存控制与硬件交互能力满足严苛要求。中国国家航天局、NASA、ESA 的航天器软件，如卫星操作系统、姿态控制系统等均有 C++参与开发。
（5）游戏开发。C++因高效性成为游戏开发主流语言，能满足高性能需求。众多大型游戏采用 C++开发，可直接控制硬件、管理内存，保证流畅稳定。例如可开发一个购物模拟小游戏，玩家体验挑选商品、结算付款，C++的高性能确保运行不卡顿。

**8.2.1 小故事**

超市开业前，小乐准备了一套记账工具：一张大桌子整理单据，一台计算器算总价，几本账本分别记录进货、销售与库存，再配上一支笔随时记录。这些工具组合起来构成了他的账务处理环境。

**8.2.2 安装 C++编程环境**

**1.认识 C++编程环境**

计算机只能识别特定格式的代码，编程环境的作用就是把人类编写的代码转为机器指令。可以说它是程序员与计算机之间的桥梁，是代码发挥价值的前提。

C++环境主要由代码编辑器与编译器构成。
（1）代码编辑器。用于编写、查看与修改 C++代码，通常提供语法高亮、自动补全、缩进提示、实时错误标记等功能。常见编辑器有 Visual Studio Code、Vim 等。
（2）编译器。负责将 C++源代码转换为可执行的机器语言。常见编译器有 GCC、Clang、MSVC 等。

程序员在编辑器中编写代码，经编译器转换后即可执行。此外，集成开发环境 IDE 将编辑器、编译器、调试器等整合为一体，提供统一界面，方便完成编写、编译、调试等流程。例如 Dev-C++、Code::Blocks 等。以下以适合初学者的 Dev-C++为例说明搭建流程。
