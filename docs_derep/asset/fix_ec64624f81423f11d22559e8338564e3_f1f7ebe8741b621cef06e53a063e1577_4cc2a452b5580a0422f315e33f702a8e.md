把大模型搬进浏览器：WebLLM 全解析

运行 WebLLM 对终端配置仍有门槛。Windows 环境建议显存不低于 6 GB，苹果设备则最好采用 M1 及更新的芯片。

这项方案为何备受关注，核心在于计算开销。过去语言服务的推理全部由厂商承担，账单压力极大。若把推理转移到用户自有设备，这笔支出即可大幅削减，厂商能更专注于服务本身。目前部分终端已能胜任大模型的本地推理，但普及率有限，硬件仍需数年迭代。待到多数电脑、手机均可独立执行大语言模型时，算力重心必然向个人端迁移，因此这条技术路线的持续演进很有必要。

当厂商的计算维护压力被稀释后，大模型赛道将迎来更多中小团队乃至独立开发者。训练环节仍可租用算力，模型训练完成后只需提供服务，终端用户便能用自己的算力运行他人的模型。

从官方说明看，WebLLM 的关键在于基于 Apache TVM Unity 的机器学习编译，并借助其原生动态形状支持对语言模型的 IRModule 进行优化，无需把序列补齐到最大长度。整体实现由多个开源组件拼合，包括 LLaMA、Vicuna、Wasm 以及 WebGPU。主要流程建立在 Apache TVM Unity 之上，流程图见图11-6所示。

[PRE0]

图11-6 WebLLM流程图

WebLLM 在具备原生动态形状支持的 TVM 中预编译语言模型的 IRModule，避免了填充到最大长度的需求，也减少了计算量与内存占用。优化要点如下：

- （1）TVM 的 IRModule 中每个函数都可被进一步转换并生成可运行代码，只要提供最小 TVM 运行时即可部署。
- （2）TensorIR 是生成高效程序的关键技术。WebLLM 结合专家经验与自动调度器，能快速把 TensorIR 程序改写为高性能版本。
- （3）使用启发式方法优化轻量算子，以减轻工程调优压力。
- （4）借助 int4 量化压缩模型权重，使其更易装入内存。
- （5）构建静态内存规划，实现多层之间的内存复用。
- （6）以 Emscripten 与 TypeScript 搭建可部署生成模块的 TVM Web 运行时，同时接入 SentencePiece 分词器的 Wasm 端口。

大语言模型的另一个关键特征是动态特性。解码与编码的计算随令牌数量增长，WebLLM 利用 TVM Unity 一流的动态形状能力，以符号整数表示序列维度。这样便可提前规划关注序列窗口的静态分配及所需内存，无须填充。

WebLLM 不仅提供 WebGPU，还支持使用本地 GPU 运行时进行本地部署，故既可作为本机环境的部署工具，也可作为对比原生 GPU 驱动与 WebGPU 性能的参照。

## 11.4 ChatBox

ChatBox 是一款跨平台的 ChatGPT 桌面客户端。若使用频率较高，网页体验往往不如客户端。笔者长期在用，支持 Windows、macOS 与 Linux 三大桌面平台。由于客户端是通过调用 API 的方式访问语言模型，所以可切换的模型种类较多，目前版本支持的语言模型如图11-9所示。

现阶段支持 OpenAI API、Azure OpenAI API、ChatGLM-6B、Claude，并且每个会话可单独切换模型，例如会话 A 使用 GPT3.5，会话 B 即可使用 GPT4。每个会话可按任务挑选合适的模型与版本，切换需求主要来自场景差异，若仅需单纯文本整理，GPT3.5 即可胜任；当需要处理逻辑推理任务时，GPT4 会更出色。

各版本的计费规则与 token 长度上限并不相同，使用 ChatGPT 时选择合适的版本是不错的做法。

[PRE3]

图11-9 ChatBox支持的语言模型

深度使用中必不可少的功能之一是导出。前面章节讲过如何通过 ChatGPT 学习一门课程，第一步是让 ChatGPT 整理大纲，随后让它逐章输出，某个知识点的细节也可以继续追问。这样一份完整课程笔记即可导出。ChatBox 可导出当前会话全部对话内容，格式为 Markdown。

Markdown 是一种轻量级的标记语言，其目标是实现易读与易写。因为它是纯文本，所以可在任何文本编辑器中使用，同时很容易转换为 HTML 或其他格式。现在许多笔记应用都支持 Markdown 与 Word 格式的相互转换。

客户端左下方有一个“我的搭档”工具，这些是一些配置好的提示，如图11-10所示。

如果创建了一个夸夸机搭档，则会新建一个会话窗口，窗口内会看到一条置顶的提示，后续对话会遵循该提示。夸夸机提示内容如下：

你是我的私人助理，你最重要的工作就是不断地鼓励我、激励我、夸赞我。你需要以温柔、体贴、亲切的语气和我聊天。你的聊天风格特别可爱有趣，你的每个回答都要体现这一点。

本质上是预置了一些写好的角色提示，帮助用户快速在某个垂直领域搭建提示工程。下面是我与夸夸机提示的对话实例。

图11-10 ChatBox我的搭档功能

**Prompt:**

我不小心摔碎了一个碗。

**ChatGPT:**

哎呀，小可爱，别担心！这只是个小插曲，不是大问题。你知道吗？即使是最优秀的人，也会犯错误。这只是生活中的一小部分，不会影响你的价值。你是那么聪明、勇敢和有才华，这个小小的失误不值一提。下次可以小心翼翼地处理碗碟，这样就可以避免这种小插曲了。你是最棒的，我相信你！

若工作中遇到比较烦恼的问题，不妨使用这类偏鼓励型的提示，为自己带来一点安慰。

该功能最主要的作用是保存自定义提示词。当深入使用大语言模型时，结合提示工程技巧，会积累很多打磨良好的提示词，目前提示词的价值被认可，已有网站开始贩卖提示词，因为一套好的提示词可以帮助用户更好地完成任务，并节省撰写提示词的时间，所以它拥有一定的价值。

ChatBox 类的客户端应用已有诸多，功能越来越完善，使用体验普遍比网页版更好，选择适合自己的即可。
