人脸比对的核心任务，就是给两张人脸打一个相似度的分数。它的输入是两份人脸特征，也就是两张人脸图像，输出则是这两个特征之间的相似度数值。实际使用时，会把从图像中提取出来的特征数据拿去和数据库里保存的特征模板做搜索匹配，并事先设好一个阈值，只要相似度超过阈值就判定为匹配成功。

这个过程大致分两种模式：一是对一的确认，相当于把两张图直接比一比；一是对多的辨认，相当于把一张图去库里挨个找最像的。比如验证是否为同一人时，输入的是两份人脸特征，通过比对得到相似度，再与预设阈值比较来决定是否同属一人。再比如人脸搜索，输入是一份人脸特征，和库中 N 个身份对应的特征逐一比对，挑出相似度最高的那个，再用这个最高值和阈值对比，大于阈值就返回对应身份，否则说明不在库中。

### 11.2 人脸定位与关键点实战

先厘清概念：人脸检测解决的是图像里有没有脸，人脸识别解决的是这张脸属于谁。前者是后者的前提工作。本节要用的 Dlib 是个老牌的 C++ 人脸识别库，跨平台可用的公共库，内置大量图形模型算法，并提供 Python 接口，里面自带人脸检测器、训练好的关键点检测器以及训练好的识别模型。

Dlib 里的人脸检测基于 HOG，即方向梯度直方图。思路是用 HOG 特征来刻画人脸。HOG 本质上是对图像局部区域像素做运算后得到的一种描述子，对几何和光照的变化保持较好的鲁棒性。它经常和支持向量机 SVM 搭配用于目标检测。举例来说，一张 64×128×3 的图像经过 HOG 描述后会得到长度为 3780 的特征向量。用向量本身看不懂图像，但在识别和检测任务里非常实用，分类效果往往很好。

## 11.3 表情识别与情绪分析实战

本节利用 OpenCV 与 Dlib 在视频流中检测人脸，并把眼睛、嘴巴等区域标识出来，均基于已训练好的数据。

根据大量面部表情统计，嘴巴张开距离占人脸框宽度的比例越大，通常说明情绪越激动，可能是开心也可能是愤怒。眉毛上扬程度越高越显惊讶，不同倾斜角度对应不同情绪，开心时眉毛上扬，愤怒时眉毛压下皱起。眼睛也能传递信息，大笑时眼睛会不自觉眯起，愤怒或惊讶时眼睛会睁大。

仅靠这些粗略特征只能大致判断开心、愤怒、惊讶或自然等，需要更准确的判断就得捕捉细微表情变化，再结合心率、语音等做综合评估。
