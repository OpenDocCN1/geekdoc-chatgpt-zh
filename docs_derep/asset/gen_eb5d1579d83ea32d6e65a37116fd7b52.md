# 中国AI治理观与仍待解答的问题

观察中国近期提出的人工智能治理准则，不难发现其总体上契合了国际通行的主线：把技术对社会的影响放在首位，对相关产业和从业者施加限制，并保持规则的动态更新。放在中国自身背景下，文件对安全可控及防止数据平台形成垄断的表述尤为突出，这与其在信息科技领域的国际处境紧密相关。综合国内外实践来看，治理路径仍有若干关键议题未得到清晰答案。

## 未来待解决的问题

其一，联合国在AI治理中应扮演怎样的角色。核武、生化武器等高破坏性颠覆性技术的管控，传统上由联合国主导，并通过严格规则约束其扩散与使用。就目前而言，人工智能并未被纳入这一类技术清单，但其在军事上的部分用途已引发类似的警惕。这就带来一个未决问题：联合国是否有必要成为AI领域专门治理的牵头机构。

其二，治理手段中是否需要惩戒性措施，以及如何弥合技术差距。现阶段各国对AI的规范多以正面指引为主，靠激励推动技术与社会和谐共存。但风险信号已经浮现。长远来看，AI的普及很可能制造新的技术鸿沟：能熟练运用AI的个人、企业乃至国家，在生产效率、治理能力和安全韧性上会形成明显优势。这样的鸿沟与AI本应带来的普惠价值相冲突，也是争议的核心。国际社会对此尚未找到有效对策。有观点提出征收“机器人税”来削弱AI带来的经济红利，但该方案的可行性和普适性仍需验证。

其三，怎样搭建政府、科研、产业和公众四方之间顺畅的对话机制。四个主体在AI治理中的定位和诉求各不相同，讨论自然会各有偏重。公众往往是治理落空的直接承受者，政府则承担安全兜底的最终责任，学界更关注技术本身的演进与边界，而产业则优先考量商业回报。因为利益诉求难以完全重合，四方协商很难实现全员满意。即便某种政策在多数人中获得支持落地，仍可能遭遇少数群体的规避或抵制。如何在政策出台前就建立可检验、可预判影响的互动与评估流程，是一个值得深入探索的方向。

# ·AI 与军控新挑战·

## AI正引领战争智能化进程[^(\[1\])](#chapter010.html#m1)

朱启超[^(\[2\])](#chapter010.html#m2)

**摘要：**阿尔法围棋升级版在棋坛的强势表现，触发了人们对人工智能军事价值的讨论。在博弈更激烈的战场上，AI自上世纪计算机诞生以来就逐步渗透，推动战争形态向智能化演进。当新型武器、技术、作战概念与编制结构协同作用显著提升作战效能时，就可能触发新一轮军事变革，并进一步扩大AI在国防领域的运用空间。

**关键词：**人工智能 军事领域 智能化战争

2017年，谷歌DeepMind推出的AlphaGo升级版在短短一周内连胜中日韩多位顶尖棋手，战绩为60胜0负。[^(\[3\])](#chapter010.html#m3)这场胜利让外界惊叹人类棋手是否已无回天之力，也促使军事观察者重新审视AI在战争中的意义和走向。自上世纪下半叶起，随着信息技术尤其是AI的进步，人机棋类对抗屡见不鲜，此次对决不过是神经网络深度学习、高性能算力与大数据等技术集成的最新展示。事实上，在较量更为残酷的军事场景中，人工智能伴随计算机的诞生便不断进入战场，正在推动智能化战争的到来。

### 一 人工智能正大踏步走上战场

AI是当代信息技术的核心分支之一。广义上，它探索如何让机器完成过去依赖人类智力的工作，以及用计算机模拟人类智能行为的相关理论方法与技术；狭义上，则聚焦于机器人及其相关技术。二战期间，英国研制的第一台可编程“巨人”计算机，其初衷就是为破解德军密码服务。从那时起，以算力为核心的信息技术持续重塑军事形态，AI的战场渗透日益深入，重塑了作战图景。总体来看，其军事化应用可归纳为五个方向。

第一，智能感知与信息融合处理。MEMS、无线传感网、云计算与低功耗嵌入式技术同步突破，推动战场探测从被动采集转向智能融合。例如，多国军队都在试点“智能微尘”式传感网络，通过撒布数以万计的节点实时捕捉区域内的人员装备动向。美俄法德等均已列装具备智能感知与处理能力的数字化单兵系统，如美军“夜之勇士”、俄军“战士”。美国国防部高级研究计划局在2015财年启动“大脑皮层处理器”计划，模仿人类皮层结构研制传输与运算效率提升数个量级、功耗极低的类脑芯片，可用于实时感知、目标识别和高速目标的即时控制，未来将显著增强机器人、无人机、无人车、无人船的自主水平。[^(\[4\])](#chapter010.html#m4)

第二，智能化指挥控制辅助决策。各国军队通过构建各类军事信息系统，形成网格化网络信息体系，提升智能评估与辅助决策能力。美苏等大国自20世纪50年代起就持续发展指挥自动化系统，追求信息与决策优势。例如，美军在“军事信息高速公路”基础上发展出C4ISR系统，2001年后依托“网络中心战”升级全球信息栅格，打造联合作战信息环境。近年来，美军组建网络司令部[^(\[5\])](#chapter010.html#m5)，强化网络攻防，重点借助云计算、大数据分析研制能自动溯源入侵、评估损毁与恢复能力的智能诊断系统。

第三，无人化军用平台。西方在一战时期已开始探索小型无人机、遥控无人车与无人艇。当前已有70多个国家在研无人系统，各类无人机、无人车、无人船、无人艇和无人潜航器在军事应用中愈发普遍。例如，美军制定了面向2040年的无人化作战路线图；截至2017年，美军无人机保有量超过7000架，在伊拉克、阿富汗部署的地面轮式或履带式机器人超12000个；未来地面机器人占比拟达陆军兵力三分之一，舰载X-47B察打一体无人机占比拟达舰载机总量三分之一，推动有人平台与无人平台协同演训。[^(\[6\])](#chapter010.html#m6)

第四，仿生机器人。21世纪以来机器人技术呈现井喷，类人机器人、机器狗、机器骡、机器蛇、机器鱼、机器鸟、机器昆虫等不断涌现，并在军事领域获得更多应用。美军曾在阿富汗试验“大狗”机器人，承担补给伴随保障。根据试验结果，国防部于2013年将其升级，负重提升至200千克、时速12千米并具备防弹静音能力，升级版于2015年投入演练。[^(\[7\])](#chapter010.html#m7)俄罗斯近期计划加速研发可驾驶车辆的类人机器人、组建可与人类并肩作战的机器人部队，以及研发集群作战指挥信息系统。[^(\[8\])](#chapter010.html#m8)

第五，扩展人的体能、技能和智能。信息技术、新材料与生物技术的交叉使人类对自身认知加深，AI的进步也让人的体能、技能与智能获得延伸。外军正通过机械外骨骼打造体力倍增的“机甲战士”；借助生物信息芯片植入提升记忆与反应能力，以适应高度信息化的作战环境与海量数据；通过脑机接口技术提高对装备系统的操控效率。例如，俄罗斯2011年提出“2045计划”，致力于攻克“脑控”“仿脑”“控脑”技术，拓展脑机接口军事应用；美国国防部2013年提出“阿凡达”计划，目标是构建可由人脑远程操控的机器人军团，实现战场“零伤亡”。[^(\[9\])](#chapter010.html#m9)

### 二 人工智能将推动新一轮军事变革
