[PRE0]

此处的 M 与 N 取值视业务实况而定。其中，精排 Top M 指代精排阶段得分靠前的物品集合，粗排 Top N 则是粗排需向下游传递的候选数量。因此，HR@ N 的物理意义即为：在精排高分物品中，被粗排成功召回的占比。该比值越大，说明两者排序结果的一致性越强。

PRAUC 与 Hit Rate 虽均可作为衡量粗精排一致性优劣的整体指标，但二者的考量侧重点截然不同。PRAUC 的判定标准较 Hit Rate 更为苛刻。下面结合图 4-20 的示例，详细剖析这两个指标的差异。

[PRE1]

图4-20 PRAUC与Hit Rate在粗排中的区别（详见彩插）

如图 4-20 所示，三个各异的粗排模型 A、B、C 作用于同一精排模型打分的样本集上。从排序结果来看，三者的 HR@ N 指标数值一致，均为 0.75，且在 Top N 列表中均误判了一条精排负样本（此处以某一阈值划分精排正负样本，得分超阈值为正样本，反之为负样本）。然而在 PRAUC 指标上，三者呈现 A > B > C 的层级差异。原因在于 B、C 两个模型将本该靠后的精排负样本排在了高位，将本该靠前的精排正样本排在了低位，顺序错位十分严重。

但若站在粗排于推荐链路中的职能与定位来审视：粗排只需保证输出的 Top N 结果尽最大可能覆盖精排高分物品即可。Top N 内部的相对顺序，以及被过滤掉的剩余样本内部排序是否合理，均不会干扰最终的推荐效果，也不会削弱粗排在链路中的作用。基于此，上述三个模型在实际推荐业务上的表现完全等价。因此，我们认为计算更为轻量的 HR@ N 指标更契合业务落地需求。当然，二者并非割裂关系，提升 PRAUC 必然带动 HR@ N 上涨，但 PRAUC 定义更严、优化难度更大、往往需要更复杂的模型结构，而粗排本身追求的是效率与精度的平衡，故在粗精一致性考核上，倾向于采用更简易的 HR@ N。

基于 HR@ N 的模型效果分析框架下，我们还可依据业务实际，在不同粒度上开展评估。例如，先计算每个用户维度的 HR@ N，再按加权聚合为整体指标。因为实际推荐服务是针对每位用户的每次请求单独进行粗排打分与过滤的，所以我们期望模型更多地增强用户内部的排序质量，而非过度关注用户间的打分分布差异（这与 GAUC 对 AUC 的补充逻辑一致）。

此外，在粗排模型训练过程中，还可在 Batch 粒度上实时计算 HR@ N，从而动态监测粗精一致性变化，便于模型调优把控。

## 4.5 本章小结

随着信息流产品形态与功能模块日益丰富，用户与内容规模持续攀升，粗排模型在整个推荐链路中的战略地位愈发凸显。本章沿着粗排模型的演进脉络，进行了系统性的复盘与介绍。

不同于精排模型始终锚定 CTR、CVR 等目标持续迭代，粗排的建模目标在演进历程中经历了多次范式更迭：早期依赖人工规则与静态模型，预估物品质量分、热度、人气值，侧重挖掘物品的综合质量评价体系；继而进入 LR、GBDT 等浅层模型阶段，发掘用户与物品的相关性与偏好度，强化个性化表达与实时预测能力；直至当下，核心诉求转向了与精排的一致性对齐。

然而，受限于打分性能的硬性约束，粗排模型始终是在精度与效率的博弈中寻找平衡点的产物。这一定位决定了其模型架构与特征体系天然比精排更为精简。在这样的约束边界内，粗排走出了一条差异化的技术演进之路：以双塔架构为基座，在发挥其高效检索优势的基础上，通过行为序列建模深化用户兴趣表达、引入注意力机制作特征重要性加权、利用特征交叉与多层 MLP 提升非线性拟合能力、借助知识蒸馏最大程度逼近精排模型。

本章可视为对粗排模型当前阶段工程实践的阶段性总结。当前，业界对粗排的探索优化仍在持续深入：如何实现粗排与召回、精排的全链路联合建模？如何突破粗排自身的性能天花板？如何在模型复杂度与业务收益间寻得最优解？这些均是值得持续攻关的技术前沿方向。

## 5.2 前深度学习时代的精排算法

在深度学习浪潮来袭之前，LR、FM 与 GBDT 是工业界应用最广泛的三大精排基石算法。三者各具优势，下面逐一展开详述。

### 5.2.1 LR

虽名为“回归”，LR 实则是一个二分类模型。在推荐场景中，常用于预估概率值，表征用户点击商品的可能性、对视频点赞的概率等业务指标。深度学习普及前，LR 凭借“万金油”般的通用性备受青睐：无论何种业务场景，只需结合业务理解做好特征工程，配合 LR 往往即可取得可观效果。LR 的核心特质在于简洁高效、可解释性强。本节将先阐释 LR 基础原理，再介绍工业界大规模 LR 训练的利器——LibLinear [4] 库。

##### (1) LR基本原理

记函数 $f(x, \theta)$（后文简写为 $f(x)$）为样本 $x$ 被预测为正例的概率 $P(y=1|x)$，则其为负例的概率为 $P(y=0|x) = 1-f(x)$。将二者合并为统一表达式：$P(y|x) = (f(x))^y (1-f(x))^{1-y}$。给定数据集 $X=\{x_1, ..., x_n\}$ 与 $Y=\{y_1, ..., y_n\}$，对模型参数 $\theta$ 施行极大似然估计，可得似然函数：

$$L(\theta)=\prod_{i=1}^{n} P(y_i | x_i)=\prod_{i=1}^{n} (f(x_i))^{y_i}(1-f(x_i))^{1-y_i} \quad (5-1)$$

该式为连乘形式，取对数后得对数似然：

$$\log L(\theta)=\sum_{i=1}^{n} (y_i\log(f(x_i))+(1-y_i)\log(1-f(x_i))) \quad (5-2)$$

最大化似然估计等价于求解最符合数据分布的参数 $\theta$。机器学习惯以最小化目标求解，故对上式变形得损失函数：

$$J(\theta)=-\frac{1}{n} \sum_{i=1}^{n} (y_i\log(f(x_i))+(1-y_i)\log(1-f(x_i))) \quad (5-3)$$

上述推导从二分类概率定义出发，经极大似然估计逐步导出 LR 损失函数。其中，$f(x_i)$ 通常定义为 Sigmoid 函数：

$$f(x_i)=\frac{1}{1+e^{-\theta^T x_i}} \quad (5-4)$$
