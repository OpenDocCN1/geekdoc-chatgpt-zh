# 2.2 网格化世界构建

网格结构因其直观易懂、落地简单，成为游戏世界建模的首选方案。但在进阶到更高级的图表达之前，我们有必要先夯实图论基础。

## 核心架构设计

为实现寻路算法与底层数据结构的解耦，首要任务是定义一个抽象基类 `Graph`。无论内部如何存储顶点与边，上层寻路逻辑仅依赖这组统一接口，从而避免为每种图结构重复造轮子。该类不仅是本章所有图实现的父类，也为后续扩展未覆盖的图类型预留了标准入口。

继而，我们派生出 `GridGraph` 子类，在内部以网格形式管理数据。
