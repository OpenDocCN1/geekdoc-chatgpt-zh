现代生成式AI能够产出连贯自然的文本，关键就在于自注意力机制叠加多层Transformer架构，并辅以自回归式的解码器设计。正是这种组合让模型对上下文的理解明显增强，生成结果读起来更顺畅，也因此成为当前生成类系统的核心技术支柱。

#### 2.1.2 生成检索结合

RAG可以看作是生成式AI的一种进阶形态，它把生成模型和检索模块联动起来，显著提升了输出的准确性与时效性。单纯依赖预训练的生成模型，其知识边界基本被冻结在训练阶段，面对新出现的信息就显得无力。RAG引入外部检索能力，可以在生成时实时从知识库里抓取最新相关内容来弥补模型的知识盲区，从而应对更复杂的提问。

下面用两个代码片段来演示检索为生成提供即时知识支持的完整过程。

##### 【例2-2】检索增强生成的基本流程。

本例通过简单的FAISS向量检索搭配GPT-2生成模型来呈现RAG的核心运作。整体分为两步：先把文档集合编码成向量并写入FAISS库，再在用户提问时检索最相似的片段作为上下文喂给生成模型。

from transformers import GPT2LMHeadModel, GPT2Tokenizer

from sklearn.feature_extraction.text import TfidfVectorizer

import faiss

import torch

# 初始化 GPT-2 模型与分词器

model_name="gpt2"

tokenizer=GPT2Tokenizer.from_pretrained(model_name)

model=GPT2LMHeadModel.from_pretrained(model_name)

# 示例文档集合

documents=[

    "人工智能是通过模拟人类智能来完成特定任务的技术。",

    "机器学习是人工智能的一个子领域，主要关注通过数据训练模型。",

    "深度学习是一种利用神经网络进行数据处理的机器学习方法。",

    "自然语言处理使得计算机能够理解和生成人类语言。" ]

# 使用TF-IDF将文档编码为向量

vectorizer=TfidfVectorizer()

doc_vectors=vectorizer.fit_transform(documents).toarray()

# 将文档向量插入FAISS索引中

dimension=doc_vectors.shape[1]

index=faiss.IndexFlatL2(dimension)

index.add(doc_vectors.astype('float32'))

def retrieve_document(query, top_k=1):

    """

    检索最接近的文档

    """

    query_vector=vectorizer.transform([query]).toarray().astype('float32')

    _, indices=index.search(query_vector, top_k)

    retrieved_docs=[documents[i] for i in indices[0]]

    return retrieved_docs

def generate_response(query):

    """

    结合检索结果生成回答

    """

    # 1. 检索与 query 最相关的文档

    retrieved_docs=retrieve_document(query)

    # 2. 将检索到的文档作为上下文提供给生成模型

    context=" ".join(retrieved_docs)

    prompt=context+" "+query

    # 3. 使用 GPT-2 生成响应

    inputs=tokenizer(prompt, return_tensors="pt")

    outputs=model.generate(inputs.input_ids, max_length=30,

                           do_sample=True, temperature=0.7)

    response=tokenizer.decode(outputs[0], skip_special_tokens=True)

    return response

# 测试查询

query_text="什么是机器学习？"

response=generate_response(query_text)

print("生成的回答:\n", response)

上述实现先用TfidfVectorizer把示例文档转成向量并存进FAISS索引。retrieve_document函数会把输入问题向量化后在索引中查找最相近的文档，再把检索结果拼接到问题前面作为提示词输入GPT-2，从而得到回答。

运行结果如下：

>> 机器学习是人工智能的一个子领域，主要关注通过数据训练模型。它能够帮助计算机在没有明确编程的情况下进行学习。

在这个演示里，RAG借助检索模块拿到与问题最吻合的文档片段作为上下文，让生成模型给出更精准的回复。

#### 2.1.3 检索增强与传统生成模型的区别

RAG和传统生成模型在结构、运作方式及数据利用上差异明显。像GPT系列这类传统模型，语言生成能力强，但实时性和知识准确性不足。RAG通过接入检索模块，回答时可实时获取最新外部知识，从而提高内容准确性和更新频率。

##### 1. 数据源与信息获取方式

传统生成模型依赖训练阶段学到的静态知识。训练完成后，其输出基本局限于当时的训练语料，无法自动跟随时间更新，因而对新知的理解有限，时效性和准确性较差。

RAG则引入了动态检索机制，生成前后能从外部知识库、文档库等来源实时拉取最新数据。它不仅靠模型内置记忆，还能通过检索模块访问海量外部信息，实现知识的流动式更新，从而覆盖更广的信息需求。

##### 2. 架构与工作机制

传统生成模型多基于自回归或序列到序列生成，逐步拼凑输出。上下文主要来源于输入本身和训练时积累的内部知识，生成完全依赖参数分布和已有记忆，知识覆盖受限。

RAG在生成过程中把检索到的外部内容作为上下文注入模型。检索模块先根据用户输入找到最相关信息，再将其动态加入提示词，生成模型据此产出内容。这种检索加生成的双轨机制，提升了回答的精准度和知识广度。

##### 3. 知识广度与深度

传统模型的知识广度取决于训练数据的规模和质量，扩展新知识需要重新训练或微调，成本高昂。其深度体现在句法语义理解上，但在处理复杂背景时易泛化，准确性不足。

RAG借助外部检索显著扩大知识面和准确性。检索模块可从知识库、数据库、网页等多源获取数据，使模型在专业化、多领域场景下更具适应性。知识广度不再固化于训练集，且能通过检索获取更详细的背景，挖掘更深层次的信息。

##### 4. 适应性与拓展性

传统模型适应性较弱，尤其在需要最新信息或专业知识的任务中，回答常缺乏时效性和精准度。每有新知识就需要昂贵的重训练，限制了其在高频更新场景的应用。

RAG通过实时检索提供高效适应方案，无需频繁重训生成模型即可调用外部数据。在处理新兴知识或需要即时响应的任务上表现更好，也便于在知识库中扩充专业、时效性强的内容，让输出始终贴近实际。

##### 5. 性能与计算资源

传统生成模型往往需要大规模参数和复杂架构才能在大规模数据上取得好效果，训练与更新成本高。生成长文本时计算量也随之激增，影响效率。

RAG的检索模块分担了知识记忆压力，生成部分只需把检索结果组织成流畅语言。生成模型可以精简，计算成本下降。检索与生成还能分布式并行部署，提升响应速度。
