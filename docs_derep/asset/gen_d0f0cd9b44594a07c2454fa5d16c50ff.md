BERT 实战：命名实体识别全流程拆解

命名实体识别的核心就是把句子里的每个词贴上标签，IOB 格式是常见做法。O 代表非实体，B- 开头表示实体开始，I- 开头表示实体内部延续。

拿 “My first name is John and my full name is John A. Smith” 来看。My first name is 这些词都与命名无关，统一标 O。John 作为人名出现，前一个词是 O，所以它作为该实体的首词被标为 B-Person。and 之后脱离名字，继续是 O。and my full name is 这段同样全是 O。随后 John A. Smith 连续出现，John 仍是 B-Person，A. 和 Smith 都属于同一人名，于是分别标为 I-Person、I-Person。

手工标注一句话就要如此逐词判断，工作量很大，往往需要专业规则辅助，也支持自定义标签体系。比如餐饮场景就能细分为 Amenity、Cuisine、Dish、Hours、Location、Price、Rating、Restaurant_Name 等。

再看一个餐饮检索句：“a four star restaurant with a bar any bbq places open before 5 nearby”。表 8-2 NER 示例里，“four star”构成评分实体，four 是 B-Rating，star 是 I-Rating；bbq 是 B-Cuisine；open before 5 是 B-Hours 与 I-Hours 的延续；bar 是 B-Amenity；with a 以及 nearby 归入 Location 相关位置信息，其余词为 O。

从 BERT 角度看，输入是按模型规范编码的文本，NER 通常处理一句话，也可多句。预处理本身没有特殊之处，关键是有标签，模型在顶层加线性分类器做分类，产生误差后通过反向传播让 BERT 适配餐饮等具体任务。
