# 第二章
# ChatGPT 提示词

要充分挖掘 ChatGPT 潜力，关键在于精确构建提示词。精心设计的提示词能引导大语言模型产出高质量内容。本章深入探讨提示词构成、设计原则、实操技巧以及 PromptPerfect 优化器的应用，帮助提升互动效率与质量。

## 2.1
## 提示词结构与设计原则

[PRE5]

扫一扫，看视频

提示词是用户向大语言模型输入的文本或多模态信息，用于引导生成特定回应。可为文字、图片、数据、音视频、PDF 等。

**1．提示词的构成**

提示词包含指令、背景、输入素材与输出指引四个要素。指令明确期望执行的任务，如分类、撰写或翻译；背景提供补充信息帮助模型更精准理解；输入素材是具体内容或问题；输出指引规定类型或格式，确保响应符合要求。

提示词示例：

**我的工作是数据标注，任务是提取文本中的地名，请对以下内容进行地名抽取。输入：“暑假出发前，小林收到苏州表亲的来信，信中提到表亲在杭州的大学任教。小林打算去杭州探望，然后前往厦门度假。从苏州出发先坐动车到上海，再转车到杭州。到杭州后表亲带他参观校园，两人聊得很开心。表亲表示想去青岛看看海，小林决定同行。抵达青岛后，他们逛了栈桥和五四广场。之后又北上到大连，体验滨海风光。整个旅程让小林收获很多。”**

**输出格式：地点：用逗号分开的地名**

其中背景为“我的工作是数据标注，任务是提取文本中的地名”，指令为“请对以下内容进行地名抽取”。其余为输入数据与输出指示。

**2．提示词的设计原则**

编写精准有效的提示词需遵循以下原则。

（1）清晰：能够明确传达意图，避免歧义，术语需解释。例如“重庆市有哪些知名火锅店？”表达较为清楚；而“2021 年苹果价格比 2020 年上涨多少？”表述模糊，因“苹果”不明且缺少地区。

（2）聚焦：应具备针对性，避免宽泛。如“你知道人类什么知识？”过于开放，应改为“你了解人类科技史吗？”

（3）相关：在多轮对话中保持话题一致，无关提示会分散注意力。可使用相关关键词如“景点推荐”“路线规划”“食宿安排”。

（4）简洁：去除冗余词句，有助于获得针对性回复。

有效示例：

**#有效提示词**

**你能总结一下埃隆·马斯克的性格特点吗？#聚焦、相关**

**东莞市有多少个乡镇？#具体、目标明确**

无效示例：

**#无效提示词**

**你能告诉我关于这个世界的什么？#过于宽泛和开放**

**你能帮我做作业吗？#过于开放**

**你好#无目的、不聚焦**

遵循原则并练习，有助于编写精准提示词，保持对话在正确轨道上。
