# 角色动图一键生成：从MVP定义到架构拆解

**1. 角色上传**
用户在首页打开「上传角色」，挑选一张参考人像素材，并在下方填写动作描述，例如「大笑拍手」。

**2. 启动制作**
点击「制作表情」后，前端进入处理态，触发大模型调用。

**3. 结果呈现**
- 左侧或上方展示模型产出的动作网格图，可直观看到分解帧。
- 右侧或下方同步展示自动裁切后拼接成的 GIF 试看。

**4. 确认与导出**
用户检查动态效果，满意则点「下载GIF」保存到本地；不满意则修改描述文字，再点「重新生成」。

#### 2. 技术搭配说明
在复杂系统里，选型直接影响开发难度。下面是基于 React 纯前端方案，结合 Gemini 3 能力、在控制复杂度前提下给出的核心组合，模型生成的示意如图3-22。

##### 2. 核心依赖
为压低复杂度，我们刻意避开 fabric.js、pixi.js 等重型图像库，只用浏览器原生能力+单功能轻量库：

- **GIF 合成：gif.js 或 gif.js.optimized**
  作用：在浏览器端借助 Web Worker 把多张 Canvas 图像合成 GIF。
  好处：不阻塞界面线程，纯前端即可完成。

- **文件处理：浏览器原生 API FileReader / Canvas API**
  作用：完成图片裁切。
  原因：这是降复杂度的关键点。裁切无需后端，只要模型产出规则网格图，前端就能用 `<canvas>` 的 `drawImage` 按坐标截取，实现零依赖。

#### 4. 案例归纳
本案例体现了架构思维在文档驱动开发中的价值：先从核心需求出发，用MVP文档明确用户画像、场景、核心功能与交互流程；发现描述偏差时迭代修正，比如把功能改为生成雪碧图；再让AI基于MVP文档输出技术选型，最后把MVP与选型指令一起喂给Google AI Studio Build生成应用。全程遵循“先规划后实现”，而规划本身是迭代的。

对复杂商业应用，投入时间打磨MVP文档意义重大，细颗粒度文档能有效降低实现风险，保证AI产出的代码符合商业与技术标准。

**让AI做技术选型**是本案例方法论。让Gemini基于MVP文档给出选型，再挑选关键点整理成提示词。选型始终围绕“降低实现复杂度”：通过提示工程约束AI输出格式，比如强制3×3网格雪碧图，从而简化前端处理，避免边缘检测与图像分割等复杂算法。

雪碧图生成+自动裁切是本案例的技术核心。相比逐帧生成再合成，先生成一张包含完整动作序列的网格图，再自动裁切合成，可减少API调用次数与生成耗时。一致性也因此自然保证——同一张图内的网格保证角色外观统一。这种“用技术方案解决业务问题”的思路，正是架构思维的核心：主动设计最优实现路径。

### 3.2.5 小结
3.2节用4个案例介绍了Vibe Coding在创意设计领域的应用，以及如何根据复杂度选择文档驱动方法。

四种方法分别是：

- **敢于模糊**：一句话核心想法，让AI推荐设计系统方案。
- **视觉引导**：先用AI生成设计稿，再结合功能描述生成应用，优化系统提示词提升代码质量。
- **迭代优化**：先出基础版，让AI制定迭代计划，再挑选功能落地。
- **架构思维**：用MVP文档打磨需求，让AI制定技术选型并约束输出格式，降低复杂度。

无论哪种方式，本质都是把“我想要什么效果”讲清楚，再让AI生成对应代码或内容。在Vibe Coding里，文档即代码，需求即产品。

## 3.3 产品开发与商业应用
AI产品开发与商业运营常遇到三类痛点：

- **提示词不稳定**：同一功能不同提示词效果差异大，缺乏系统化测试手段。
- **审核效率低**：广告文案需对照《广告法》，条款繁多，人工易遗漏，违规风险高。
- **技术门槛高**：创业者有想法，却被实现复杂度卡住。

共同点是需求清晰，却缺少系统化工具。Vibe Coding提供答案——通过AI驱动工具快速搭建满足业务需求的应用。

3.3节用两个案例展示商业级应用工具的构建。第一个是提示词批量测试与评估工具，帮助建立工程化提示词优化思维；第二个是广告文案合规智能审核工具，自动识别违规内容，提升效率并降低法律风险。均从需求到实现完整呈现。

##### 项目功能文档
**PromptForge** 是一个基于Google Gemini API开发的专业级提示词批量评估与优化工具。旨在帮助提示词工程师和开发者高效地测试不同的**System Instruction**在多种 **User Case**下的表现，并通过AI自动评分快速筛选最佳方案。

---

###### 核心功能模块
####### 1. 方案管理
- 用户可定义多个系统提示词变体，对比不同人设、语气或指令约束的影响。
- 多方案对比：支持方案A、方案B等对照组。
- 实时编辑：支持增删改查，快速调整System Instruction。

####### 2. 测试用例管理
- 用户可定义一系列测试用例，覆盖常见问题、边缘情况或复杂指令。
- 批量测试集：一次设置，多次复用，确保所有方案在同一基准下运行。
- 场景覆盖：可添加代码生成、逻辑推理、创意写作等不同类型输入。

####### 3. 自动化批量执行
- 一键触发 N个方案 × M个用例的全量测试。
- 并发处理：自动调度API请求，生成所有组合回复。
- 实时进度：进度条直观显示执行状态。

####### 4. AI智能裁判
- 工具核心亮点。系统不仅生成回答，还会自动进行自反思或裁判。
- 自动评分：调用Gemini模型作为裁判，对回答打分1～10分。
- 多维评估：
    - 遵循度：是否遵守System Instruction约束。
    - 准确性：是否正确解决问题。
    - 清晰度：表达是否清晰易懂。
- 理由输出：AI给出评分理由，帮助理解得分原因。

####### 5. 可视化结果矩阵
- 测试结果以二维矩阵Heatmap呈现，便于快速识别最优方案。
- 直观色阶：高分绿色，低分红色，一眼看出表现。
- 详情透视：点击单元格弹窗查看指令、输入、完整回复及评分理由。

####### 6. 配置导入与导出
- 支持保存工作流，便于协作或版本回溯。
- JSON导出：将提示词和Test Cases打包导出。
- JSON导入：一键恢复配置，无需重复输入。
