\theta \leftarrow \theta - \frac{\varepsilon}{\delta + \sqrt{r}} \odot \tilde{g}

RMSProp 在实践里补足了 AdaGrad 容易在深层网络里过早收敛的痛点，对目标随时间变化的非平稳问题更适应，不过它也带来了衰减系数这类新超参数，整体步长依然要靠全局学习率来控制。

### （3）Adam 自适应矩估计详解

Adam，也就是 Adaptive Moment Estimation，是深度学习里使用频率极高的优化器。相较 AdaGrad，Adam 能让每次迭代的步长维持在相对稳定的区间，训练过程更平稳。

具体实现需要先设定几个超参：步长因子 ε，初始参数 θ，数值稳定项 δ，一阶动量衰减系数 ρ₁，二阶动量衰减系数 ρ₂。常规默认值是 ε=0.001，δ=10⁻⁸，ρ₁=0.9，ρ₂=0.999。

中间会维护两个变量：一阶动量 s，二阶动量 r。

迭代步骤如下：

\tilde{g} \leftarrow \frac{1}{m} \nabla_{\theta} \sum_{i} L(f(x_{i};\theta),y_{i}) 

s \leftarrow \rho_{1} s + (1-\rho_{1})\tilde{g} 

r \leftarrow \rho_{2} r + (1-\rho_{2})\tilde{g} \odot \tilde{g} 

\theta \leftarrow \theta - \varepsilon \frac{\frac{s}{1-\rho_{1}}}{\delta + \sqrt{\frac{r}{1-\rho_{2}}}} \odot \tilde{g}

没有放之四海而皆准的优化器，没有绝对的优劣之分，选择要看具体任务。实际调参时常会同时跑 Adam 和 RMSProp，对比效果后再决定用哪一个。

#### 2.6.5 牛顿法与梯度下降法对比解析

先看牛顿迭代的核心思想：在当前极小点估计 x_k 附近，用二阶泰勒展开近似 f(x)，再在该邻域内寻找下一个更优估计。设当前估计为 x_k，则二阶近似为，忽略高阶项：

$\varphi(x)=f(x_k)+f'(x_k)(x-x_k)+\frac12 f''(x_k)(x-x_k)^2$

极值需要在驻点取到，即

$\phi'(x)=0$

得到

$f'(x_k)+f''(x_k)(x-x_k)=0$

解出

$x=x_k-\frac{f'(x_k)}{f''(x_k)}$

于是从初值 x₀ 出发得到迭代式

$x_{k+1}=x_k-\frac{f'(x_k)}{f''(x_k)}\qquad k=0,1,\cdots$

由此生成的序列 {x_k} 可逼近 f(x) 的极小点。

推广到二维，泰勒展开写成

$\varphi(X)=f(X_k)+\nabla f(X_k)(X-X_k)+\frac12 (X-X_k)^T\nabla^2 f(X_k)(X-X_k)$

其中 ∇f 为梯度，∇²f 为 Hessian 矩阵：

∇f = [ ∂f/∂x₁ ; ∂f/∂x₂ ; … ; ∂f/∂xₙ ]

∇²f = [ ∂²f/∂x₁² … ∂²f/∂x₁∂xₙ ; ⋮ ⋮ ; ∂²f/∂xₙ∂x₁ … ∂²f/∂xₙ² ]

记 X=X_k 时的梯度和 Hessian 分别为 g_k 和 H_k。由驻点条件

∇ φ(X)=0

gₖ+Hₖ • (X-Xₖ)=0

若 H_k 可逆，则

X = Xₖ - Hₖ⁻¹ · gₖ

于是得到迭代式

Xₖ₊₁ = Xₖ - Hₖ⁻¹ · gₖ  k=0,1,…

其中 dₖ = -Hₖ⁻¹ · gₖ 称为牛顿方向，完整算法如下：

- 1) 设定初值 X₀ 和精度阈值 ε，并令 k=0。
- 2) 计算 gₖ 和 Hₖ。
- 3) 若 ||gₖ|| < ε 则终止，否则确定搜索方向 dₖ = -Hₖ⁻¹ · gₖ。
- 4) 更新 Xₖ₊₁=Xₖ+dₖ。
- 5) k=k+1，回到步骤2）。

可见梯度下降只用到一阶导数信息，牛顿法则同时利用了一阶和二阶导数。

牛顿法的优势是收敛速度快，往往迭代次数更少即可逼近最优解；缺点是每步都要求解 Hessian 矩阵的逆，计算开销非常大。

## 常见面试笔试题盘点

以下说法错误的一项是（ ）。

- A. 相比起 AdaGrad 算法，RMSProp 算法在非凸优化中效果更好
- B. 当目标函数是凸函数时，梯度下降法的解是全局最优解
- C. 梯度下降比牛顿法收敛速度快
- D. 拟牛顿法不需要计算 Hessian 矩阵

解析：答案为 C。牛顿法借助二阶信息，梯度下降仅用一阶信息，所以在收敛速度上牛顿法通常更快于梯度下降。

### 2.7 延伸专题精讲

#### 2.7.1 常用损失函数汇总

（1）0-1 loss
统计分类错误的样本个数。

（2）Hinge Loss
广泛用于 SVM 的最大间隔分类。对输出 t=±1 和分类器分数 y，定义为：

$L(y)=\max(0,\,1-t*y)$

（3）Log Loss 对数损失
对数函数单调，在优化时不会改变最优解；对于乘积形式的目标例如极大似然，取对数后可化为求和，大大简化求解。

（4）Squared Loss 平方损失
即预测值与真实值差的平方和，常用于线性回归等线性模型。

（5）Exponential Loss 指数损失
误差越小损失下降越快，AdaBoost 即采用指数损失。缺点是误分样本的权重会指数级放大，异常点容易干扰后续弱分类器的学习。

#### 2.7.2 函数凸性如何判定

先定义凸集，若 x,y 属于集合 M，且任意 θx+(1-θ)y 也属于 M，则 M 为凸集。若定义域为凸集且满足

$f(\theta x+(1-\theta) y)\leqslant \theta f(x)+(1-\theta) f(y)$

则函数为凸函数。可推广为

$f\left(\sum_{i=1}^{k}\theta_i x_i\right)\leqslant \sum_{i=1}^{k}\theta_i f(x_i)$

$\sum_{i=1}^{k}\theta_i=1,\theta_i\geqslant0$

若函数二阶可导且二阶导数恒正，或多元函数 Hessian 矩阵半正定，则函数为凸。

#### 2.7.3 数据不平衡问题及解决思路

数据不平衡指样本比例失衡。二分类中正负样本理应相近，但在电商恶意差评检测、金融反欺诈、医疗肿瘤诊断等场景，正负样本比例可能悬殊。

常见对策：

1）数据采样。
上采样通过重复少量类样本或加入微小随机扰动来平衡比例，容易过拟合。下采样从多数类中抽取部分样本平衡比例，可能丢失重要信息，需多次随机进行。

- 2) 数据合成是依据已有样本的特征相似性生成新样本。
- 3) 加权是对不同类别的错误赋予不同代价，让模型更关注样本少且易错的类别。
- 4) 一分类。
当比例极度失衡时，采样和合成会严重扭曲真实分布，可用一分类方法。例如 One-class SVM，利用高斯核将样本映射到高维，在核空间找一个包住所有数据的超球体，测试点在球内归为多数类，否则归为少数类。

#### 2.7.5 主成分分析 vs 因子分析

数据挖掘中变量高度重叠相关会带来分析困难，因此需要在减少变量个数的同时尽量保留信息。

主成分分析的核心是将相关指标 x₁,x₂,…,xₚ 重新组合成少数彼此无关的综合新指标，尽可能保留原变量信息且各成分不相关。

因子分析的核心是按相关性大小对原始变量分组，使组内变量相关性高、组间相关性低。分解后得到公共因子和特殊因子，公共因子反映各变量共性，特殊因子反映个体特有部分。

区别：

- 1) 主成分分析从空间生成角度寻找能解释变量变异主要部分的几组不相关成分；因子分析是寻找解释变量的公共因子和特殊因子及对应系数。
- 2) 因子分析把变量表示为因子的线性组合，主成分分析把主成分表示为变量的线性组合。
- 3) 主成分分析无需假设，因子分析有假设，如公共因子与特殊因子不相关。
- 4) 主成分由协方差或相关矩阵特征值唯一确定；因子分析可通过旋转得到不同解。

#### 2.7.6 最小风险贝叶斯决策原理

贝叶斯定理用先验知识推算后验概率：

P(A|B)=\frac{P(B|A)P(A)}{P(B)}

最小风险贝叶斯决策步骤：

- 1) 已知 P(ω_i)、P(X|ω_i)，i=1,…,c 及待识别 X，计算后验概率 P(X|ω_i)。
- 2) 结合决策表，用公式计算采用动作 a_i 的条件风险。
- 3) 比较各条件风险 R(a_i|X)，取最小者对应的决策 a_k，即 R(a_k|x)=min_{i=1,…,a}R(a_i|x)。

R(a_i|X)=\sum_{j=1}^{c}\lambda(a_i,\omega_j)P(\omega_j|X)

此时 a_k 即为最小风险贝叶斯决策。

#### 2.7.7 贝叶斯最小错误率与最小风险

设病症正常为 ω1，不正常为 ω2，P(ω1)=0.9，P(ω2)=0.1，检查结果 x 对应 P(x|ω1)=0.2，P(x|ω2)=0.4。风险矩阵 L=[L11 L12; L21 L22]=[0 6; 1 0]。

P(ω1|x)∝P(ω1)P(x|ω1)
P(ω2|x)∝P(ω2)P(x|ω2)

由于 l=P(x|ω1)/P(x|ω2)=1/2 > P(ω2)/P(ω1)=1/9，故 x∈ω1。

r_j(x)=\sum_{i=1}^{2}L_{ij}P(x|ω_i)P(ω_i),j=1,2

由于 l' = P(x|ω1)/P(x|ω2)=1/2 > P(ω2)/P(ω1) * (L21 - L22)/(L12 - L11)=1/54，所以 x∈ω1。

### 3.1 线性回归和逻辑回归入门

### 3.1.1 线性回归模型与实现

线性回归用于探究因变量 y 与自变量 x₁,x₂,…,xₙ 的关系，利用训练数据总结规律并预测未知样本。

设训练样本 m 个，(x⁽ⁱ⁾, y⁽ⁱ⁾)，i=1,2,…,m，其中 x⁽ⁱ⁾=(1, x₁⁽ⁱ⁾, x₂⁽ⁱ⁾, …, xₙ⁽ⁱ⁾)。回归函数为：

h_θ(x) = θ₀ + θ₁x₁ + θ₂x₂ + … + θₙxₙ = θᵀx

其中 x = (1, x₁, x₂, …, xₙ)ᵀ，θ = (θ₀, θ₁, …, θₙ)ᵀ。

代价函数衡量预测与真实的差距：

J(θ) = 1/(2m) Σᵢ₌₁ᵐ (h_θ(x⁽ⁱ⁾) - y⁽ⁱ⁾)²
