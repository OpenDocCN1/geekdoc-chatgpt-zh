**8.1.4 采购入账处理要点**

企业采购时，货物到库与款项支付时间往往不同步，结算方式不同导致账务处理也不同。

发生采购时，按应付价款借记材料采购、在途物资等，按发票增值税借记应交税费-应交增值税 进项税额。款项已付则贷记银行存款或库存现金，未付则贷记应付账款。物资验收入库时，借记原材料、库存商品等，贷记材料采购、在途物资等。

**8.2 销售全流程管控要点**

**8.2.1 创建销售明细表**

零散的销售单据无法直接分析，需要把一段时期单据汇总成销售记录表，才能借助 Excel 完成计算与分析。创建思路与 8.1.2 节的采购入库明细表类似。

❶ 新建工作表并命名为销售记录表。录入标题与列名，设置字体、对齐、底纹与边框，见图 8-27。
