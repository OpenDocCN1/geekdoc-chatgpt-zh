# 3. Udio

## 3.1 认识Udio

Udio 来自一批前 DeepMind 的研究员，它的定位是基于文字提示生成高品质音乐的 AI 工具，而且能够直接做带人声的歌曲创作。

主要能力集中在这些点上。

**文本转音乐：** 根据用户输入的风格、情绪等描述快速成曲，也能基于歌词合成人声，中文、英文、日文等多语种都支持。

**混音与延伸：** Mix Mode 可以在已有曲子上做微调，衍生出相似的新内容；还有片段延展功能，可为现成音乐补前奏、拉长主旋律或拖尾，做出更长的版本。

**社区浏览：** 通过 Library 能逛到其他创作者上传的作品，借鉴灵感。

**封面自动生成：** 输入提示词后会自动生成专辑封面，样式多样，质量也还不错。

**操作简洁：** 界面干净，新手也能很快上手。

**免费额度：** 登录后每月提供一定次数的免费创作配额。

Describe Your Song 就是写需求的区域，例如可以写 “为 AI 作曲教材写一首配套歌曲”。风格标签也可以直接写，边输入时平台会联想关键词，比如输入 Chinese 就会提示 chinese folk music、chinese classical music，对英文不熟的人很友好。文本框下方依次是上传音频、歌词开关、纯音乐开关，功能一眼就能看懂。

# 4. Mubert

## 4.1 认识Mubert

Mubert 把 AI 和真实音乐采样结合起来，为内容创作者、开发者和品牌提供即时生成的免版税音乐，常见用途是视频、直播、App 背景等。

它的核心差异在于人机协作。平台用数百位真实音乐人的作品和超过 250 万个采样训练模型，既保证独特性也兼顾音质。

主要特点如下。

- AI 协作模式，基于真实音乐人采样生成。
- 风格丰富，提供上百种流派和情绪分类，可按风格、情绪、BPM 生成片段。
- 产品矩阵包含面向创作者的 Mubert Studio、面向听众的 Mubert Play，以及可接入项目的 API。
- 场景广泛，适合音乐人、视频制作、广告等快速配乐。
- 全站生成音乐可商用，无版权顾虑。
- 贡献者能获得分成，激励音乐人与平台共建。
- 支持 API 集成，实现自动化生成与分发。

这种模式既降低创作门槛，也能以低成本获得原创可商用的音轨。

[PRE22]

## 4.2 Mubert的使用方法

在必应等搜索引擎搜索 “Mubert”，打开官网即可。第一次使用可点右上角 Sign Up 注册，用 Google 等账号或邮箱均可，需验证。也可以直接点 Generate a track now 先试用。

[PRE24]

界面很清爽。左侧是功能区，生成的作品会收在这里；中间上方是创作入口，点击展开。页面大部分是试听区，Popular playlists 是官方或用户推荐歌单，Explore Artists 列出合作音乐人，点击封面或头像可进播放列表感受音色。

要点进 Generate track 展开创作区，整体很紧凑。

“1. Enter prompt or upload image” 是提示词区，和其他 AI 一样写风格、乐器、情绪就行，只能英文。还能上传图片，点相机图标即可，我后面会演示。这里举例输入 Piano Pop Romantic，即钢琴流行浪漫。也可以点下面的 or choose 里的 Genre、Moods、Activities 直接挑选，Activities 相当于场景标签。

“2. Set type” 决定生成类型。点 Track 会展开四个选项：Track、Loop、Mix、Jingle。Track 是完整曲子，Loop 是 8 或 16 小节循环，Mix 结构更灵活，Jingle 用来做很短的开场收尾。

“3. Set duration” 设置时长，可手动输入，提示 5 秒到 25 分钟之间，限制很宽松。

设置好后点 Generate track 即可。示范作品听 “试听音频8-14”。

图片生音乐是 Mubert 的特色。点相机图标上传本地文件或拖拽图片，也支持粘贴链接。上传后点 Continue，提示词区会显示 Image is selected，图片就作为创作依据。时长示例设 00:45，类型保持 Track，再点 Generate track。等待时间会稍长些。示例用一张云雾栈道、略显阴森的照片生成的曲子，氛围对得上。

页面左边的 EXPLORE 菜单与 Suno 的探索类似，按 Moods、Genres、Themes、Playlists、Instruments、BPM 分类，点选词即可把标签复制进提示词。点击这些词会出现已有的作品试听，喜欢的话点右侧闪电图标，设定类型和时长后点 Generate track，就能快速得到相似新作。
