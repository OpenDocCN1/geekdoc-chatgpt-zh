## 5.11 拿列表当栈用

Python 没内置栈，但列表天生支持**后进先出（LIFO）**：
- **压栈** → `append(item)`（扔到尾巴上）
- **弹栈** → `pop()`（弹走并返回尾巴元素）

跑个例子验证一下：
[PRE8]

每次 `pop()` 都把最后压入的值吐出来。空栈强行 `pop()` 会炸 `IndexError`，实战前先判 `len > 0`。要是压栈速度持续快于弹栈，内存早晚不够用。

> 同理，列表也能充当**队列（FIFO）**，把“出队”改成 `pop(0)`，或者直接上 `collections.deque` 性能更强。
