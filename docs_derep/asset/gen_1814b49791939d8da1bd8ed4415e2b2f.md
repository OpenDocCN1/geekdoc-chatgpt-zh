保险与民事责任的基本规则

2. 英国《1988年道路交通法》第145条规定，任何在路上使用的车辆都必须持有保险，保险范围须涵盖因车辆使用而可能对第三方造成的人身伤害或财产损失。人身伤害的赔偿没有上限，财产损失的保障额度为100万英镑。

3. 伤害或损失的归责属于民事范畴。若受害人因他人过失而受损，有权要求过错方作出恢复原状的赔偿。实际操作中，绝大多数索赔由保险公司代保单持有人处理并庭外和解，只有无法协商的责任认定或金额争议才交由法院裁决。除极个别例外，保险公司必须履行法院对保单持有人的赔偿判决。

（三）自动化车辆技术的测试

1. 在测试阶段，《1988年道路交通法》关于强制投保的要求同样适用。开展测试的制造商或企业，要么自行使用车辆而自行投保，要么对测试驾驶员承担连带责任。虽然未来产品允许驾驶员在自动模式下执行其他任务，但在测试过程中，测试驾驶员必须始终保持对路况的实时监控，随时准备接管控制权。安全运行的最终责任由测试驾驶员全权承担，其同样需要具备有效保险。

2. 鉴于测试风险的特殊性，开展此类测试的企业应从市场上获得与风险匹配的保险产品。英国保险业在为创新型企业提供商业保险方面具有全球领先优势，自动化车辆测试亦属其覆盖范畴。

（四）高度自动化车辆的生产和销售

1. 若用户选择手动驾驶高度自动化车辆，则沿用现行民事责任规则，并须依据《1988年道路交通法》为该车办理或确保具备适当保险。

2. 在高度自动化车辆进入公众市场前，必须厘清自动模式与手动控制之间切换时，制造商、使用者与驾驶员之间的责任如何以及何时转移。现有法律需要检视，并依据运行模式明确责任划分。

3. 上市的自动驾驶汽车极可能配备事件数据记录器。该设备可记录车辆在事故发生时处于自动或手动状态，以及模式切换发生于碰撞前的具体时间间隔。该信息对事故定性具有高度参考价值，必须向相关主管部门提供以判定责任与保险义务。车辆处于自动驾驶状态导致事故时，制造商应承担责任。

4. 最终救助基金。欧盟汽车保险指令的核心在于保障碰撞受害者获得赔偿，要求各成员国设立基金，用于由无保险或身份不明司机造成的未投保事故。英国亦设有由汽车保险公司共同出资的最终救助基金，发挥相同功能。

行动：检视现行立法，结合运行模式明确驾驶员与车辆制造商之间的责任转移节点。

（五）全自动汽车的生产和销售

1. 全自动车辆的出现将引发新的保险议题。例如，完全取消驾驶员操控装置的全自动车辆，其使用者是否仍需投保。若车辆为私人所有，车主或许仍需购买盗抢险，但第三方责任险可能转由制造商承担。

2. 对于仍配备手动驾驶控制装置的全自动车辆，即使用户无意手动介入，是否仍须履行投保义务，也是一个待解问题。

行动：立法机构须与保险业协作，制定适用于高度自动化与全自动化车辆的保险规范，并在自动化车辆规划上与欧盟保持合作。

# 十一、数据保护和隐私

凡涉及可识别个人身份的自动驾驶汽车数据处理，均须遵守数据保护规则，其法理基础体现在1995年10月24日欧洲议会与理事会通过的关于个人数据处理及自由流动的指令95/46/EC。

## （一）事件或碰撞的数据记录器

### 1.定义

1.1 事故数据记录器即车载事件记录装置。在事故或异常事件发生前后，其会记录车速、加速度、制动使用等信息。数据可从记录器中提取，用于复原事故时车辆的驾驶状况，服务于科研、技术分析与法律举证。

### 2.安全影响

2.1 欧盟委员会资助的VERONICA项目基于智能碰撞评估的车辆事件记录研究指出，驾驶员知晓记录器存在时驾驶行为会趋于改善，从而降低事故风险与严重性。

2.2 同项目还发现，EDR可作为研究新安全技术的有效工具，用于监测撞击速度并分析数据以重建事故。

### 3.技术要求

3.1 VERONICA建议的技术标准包括至少保存三次导致人身或重大财产损害的碰撞记录，并可通过OBD接口下载数据；出于安全目的，制造商可在事件相关范围内记录额外信息。

3.2 项目建议欧洲在记录频率、精度、结果可用性等方面设定高于美国的标准。数据下载不应仅限于制造商，在车主同意或基于合法需求时，如经正式授权的执法机关，也应能够获取。

## （二）自动化车辆技术的测试

1. 在自动化技术测试阶段，研发和实施方必须确保数据处理符合现行数据保护要求。

2. 测试期间产生的大量数据对安全验证与技术迭代极具价值，因此安装车辆数据记录器很可能成为常规要求。发生碰撞时，需保留数据以便事后分析，数据应能清晰区分自动系统与测试驾驶员的行为。

3. 美国国家公路交通安全管理局建议EDR采集的数据应受安全标准约束以保证完整性，并制定最佳实践准则以保护车主与运营商隐私。内华达州规定自动驾驶汽车须捕获事故前30秒数据并以只读形式存储，且保存期限不少于事故发生日起三年。

4. 上述立法要求意味着必须审慎考量数据记录器中数据的存储安全与使用方式。在试驾前，应向试驾人员充分告知将被收集的数据种类及用途。

## （三）高度自动化车辆的生产和销售

1. 大规模生产的车辆若安装EDR，有助于事故中厘清责任。关键在于碰撞时控制权在驾驶员或车辆系统手中。事故前行为数据有助于划分保险责任、刑事责任与产品责任，因此在高度自动化车辆上安装EDR具有充分理由。

2. 除碰撞或类似事件触发外，数据通常持续记录于不可访问的易失性存储介质中。

3. 公众普遍认为只有发生碰撞时才应提供数据，而制造商与保险公司则认为其对经匿名化处理的日常数据具有合法利益。保险公司希望利用此类匿名数据评估风险与保费，制造商则希望借此了解车辆在真实场景中的表现以提升安全性。

行动：尚需制定自动化车辆数据记录标准，并在隐私议题上与利益相关方协同推进。

## （四）全自动汽车的生产和销售

为更精准判定责任，全自动车辆可能被要求强制配备电子记录系统与影像记录设备。由于车辆绝大部分时间处于自动运行，制造商极可能依赖EDR记录碰撞时的证据。

# 十二、盗窃和网络安全

## （一）车辆盗窃

1. 目前车辆安全要求以欧盟汽车型式认证规则为基准，在新车销售与首次注册前进行评估。新车必须符合联合国规则第116条关于防止机动车辆未经授权使用的规定，即配备机械防盗装置，通常为转向锁，以及电子防盗器。

2. 1998年防盗器的推广遏制了上世纪90年代上升的汽车犯罪趋势，因破解需专业设备与知识。汽车保险维修研究中心等机构亦推动制造商在法规最低要求之外增设额外安保措施。

3. 传统机械钥匙正向电子化转变，无钥匙进入通过射频通信解锁车门，可由遥控钥匙或车辆接近感应触发。

4. 在集体豁免框架下，欧洲制定了维修权规定。ECRegulation715/2007要求制造商以与特许经销商同等条件向独立维修厂提供维修与维护信息访问权限，导致制造商在安全漏洞防范上出现不确定性。

## （二）网络安全

1. 随着电子控制与自动化水平提升，车辆连接网络范围扩大，安全风险随之复杂化。

2. 过去车辆多采用机械连接的油门、转向与液压制动。现代车辆已出现线控油门，2014年首辆线控转向汽车面世，车辆依据电信号完成加速、制动与转向。

3. 网联汽车可连接互联网、其他车辆与基础设施，电子控制系统与网络连接的增多提升了恶意干扰的可能性。

4. 遥控钥匙、无钥匙进入、蓝牙、Wi-Fi、移动网络连接甚至胎压监测系统，理论上均可成为通向车辆控制系统的入口，被统称为攻击面。

5. 制造商在设计安全相关电子控制系统时强调其鲁棒性，例如电子制动失效时仍可实现完全手动制动。首批线控转向系统保留了传统机械转向柱作为电子系统失效时的备份。

6. 制造商需确保车辆具备抵御网络攻击与恶意干预的韧性，并持续排查电子系统潜在漏洞，以应对最新网络犯罪技术。

7. 联合国规则第116条旨在防止未经授权使用，若认为需进一步监管以确保网络安全，规则应予更新。

8. 车辆采集的GPS与摄像头数据若被非法提取，将影响隐私并可能助长犯罪。

## （三）自动化车辆技术的测试

测试条件之一应包括对黑客攻击或其他恶意干预的防御能力评估。提供测试车辆的制造商须确保原型自动控制器及其他系统具备适当安全等级，同时满足现有的防止未经授权使用的全部要求。

行动：与制造商及利益相关方对接，确保参与测试的自动车辆免受未经授权进入、控制或干扰。

## （四）高度自动化车辆的生产和销售

1. 随着网联程度提高，高度自动化车辆面临新的或更高的黑客与恶意干扰风险。

2. 监管机构需审慎考量以何种形式监管方能在促进市场繁荣的同时将负担降至最低。制造商应认识到产品须应对相关挑战。

行动：探讨如何完善现有监管框架，以确保自动驾驶与网联汽车技术免受网络威胁。

## （五）全自动汽车的生产和销售

完全自主运行的全自动车辆将更大程度依赖网络连接，部分车型甚至不设人工操控装置。因此前述安全与安保问题愈发关键。制造商应据此设计系统，政府应持续关注是否需要监管介入以保障公众安全。

# 十三、咨询答复摘要

2014年8月4日至9月19日开展的公众咨询，聚焦公共道路上测试高度自动安全系统汽车时需解决的监管问题，以及为保障道路安全、为新技术引进提供保障而需制定的新法规。

## 法规和制度

1. 利益相关方对原型高度自动化车辆是否符合现行型式批准或制定法规的态度不一，但普遍认为法规需随技术发展而调整。需修改的法规包括：

1.1 1968年维也纳公约第8条。

1.2 1986年道路车辆建设与使用条例第104条与第109条。

1.3 联合国规则第13H条与第79条。

1.4 1988年道路交通法第41D条。

2. 建议新增的规定包括：

2.1 明确驾驶员恢复车辆控制所需的最小操作刺激量。

2.2 明确传感器与控制技术的现场评估要求。

2.3 对车辆软件、网络安全、网络及外部通信进行监管。

2.4 规范碰撞时用于判定责任的数据收集、保存、访问与分析。

2.5 要求所有高度自动化车辆强制配备高级紧急制动系统，并考虑未来对新兴自动化安全系统的监管。

# 第三部分 为无人驾驶汽车开辟道路

## 一、具体内容

### （一）自动化汽车的测试

1. 拟在公共道路测试高度自动化车辆的组织须遵守所有现行法律。

2. 《1988年道路交通法》与《1986年道路车辆建设与使用条例》均要求在公共道路使用的车辆处于安全状态。

3. 现行立法默认驾驶员始终在车内并对其行为负责，原则上驾驶员对车辆行为及其后果负责，除非系统故障，此时车辆制造商、维修商或维护方依据产品责任法承担责任。

### （二）在测试期间提高安全性的选项

在公共道路上测试高度自动化车辆时，公共安全至关重要。主要责任由测试组织与执行方承担，政府亦可发挥作用。本次审查考虑了政府可采取的几种做法：

1. 车辆认证：为自动驾驶车辆设立测试与认证体系。

2. 许可制度：建立测试许可制度。

3. 行为准则：以政府倡导的最佳实践指南形式发布建议。

4. 不作为：在无进一步指导下允许在公共道路测试自动驾驶汽车。

### （三）测试期间提高安全性的选项比较

1. 在推动新技术研发的同时，需在公共安全与社会受益之间取得平衡。自动驾驶技术上市后最重要收益应是道路安全显著改善。

2. 在原型测试阶段实施过于严格或耗时要求，可能延缓提升安全技术的开发与推广，反而损害整体车辆安全。

3. 引入难以修订、过时或不合适的规定可能迫使技术沿次优路径发展，对安全产生负面影响。

4. 可依据四个标准评估最合适的政府做法：

4.1 安全性；

4.2 实施时效；

4.3 易于更新；

4.4 成本与资源影响。

5. 因此，制定行为准则，列出公共道路测试自动驾驶技术期间应遵循的一系列建议，是较为理想的选择。

### （四）行为准则的实施

基于上述分析，DfT的主要建议是政府应尽快启动自动驾驶技术公共道路测试行为准则的起草工作。

为获得更广泛认可，政府应与相关方协作制定准则，并参考其他国家强制性条件、美国各州立法经验，以及安全与行业机构的指导意见。

### （五）批量生产与向公众销售自动化汽车

#### 1. 汽车标准

1.1 鉴于高度自动化系统的特性，其不太可能完全符合欧洲现有车辆型式认证规则，需修订欧洲法规，修订范围预计涵盖安全、安保与数据记录标准。

1.2 在高度自动化与全自动化车辆无法依据欧洲法律获批的情况下，可采用国内立法批准。

1.3 目前尚无适用于高度自动化与全自动化车辆的统一标准，修订国内立法为时过早。该等规则宜在欧洲或国际层面形成。当国际标准草案趋于成熟时，可允许个别国家基于草案先行在国内实施，以加快车辆投入使用，无需等待正式采纳。

#### 2. 其他规定

2.1 修改部分现行国内制度是可取的，主要在于界定驾驶员与受控车辆的边界，明确各自责任与潜在法律义务。

2.2 对于全自动车辆，实际操控者并非司机，其有时可能远离车辆，因此制造商需承担更多合规责任，确保车辆不违反任何规定。车主亦可能需承担额外责任，如车辆维护的适当性。

## 二、行动计划

### （一）促进安全测试的计划

1. 该行为准则将涵盖驾驶员行为、其他道路使用者、产品责任与车辆安全使用等章节所确定的若干个人行为。政府将与主要利益相关方及其他机构合作制定准则，以吸收其意见与专业知识。

2. 准则还将借鉴全球最佳实践，包括其他国家强制规范、美国各州法案分析，以及安全与行业机构指导建议。

### （二）修订国内立法的行动

1. 为满足高度自动化车辆生产与营销，需采取多项国内立法调整。

2. 涵盖驾驶员行为与保险的立法或需修改，以适应驾驶员将控制权委托给车辆且不再专注驾驶任务的情况，并需考虑车辆碰撞后责任的判定方式。

3. 车辆安全使用的章节可能需通过次级立法调整，以确定车辆责任人在未驾驶的情形下实施被禁行为的责任程度。

### （三）修正国际立法的行动

需在安全、人体工学、事件数据记录与安全领域的型式批准标准制定上开展国际行动。因需国际合作，确切时间表难以设定，但政府间一旦就主要目标达成一致，应尽快启动。

### （四）其他行动

1. 应审视修订现有驾驶许可制度的必要性，可能包括调整驾驶考试以提升驾驶员对高度自动化车辆的认知。该工作宜在积累若干自动化车辆经验后、在大规模生产前开展。

2. 应持续审视产品责任法在保险方面的潜在问题。若认为相关顾虑不必要地延缓高度与全自动车辆引入，从而未能实现预期安全改善，则应考虑修订相关立法。

### （五）结论

此次审查明确了政府需采取共31项具体行动，以促进高度自动与全自动车辆的测试、开发与最终市场化。

## 三、总结

### （一）发现

1. 主要结论是：现行法律与监管框架并非在公共道路上测试高度自动化车辆的障碍。在英国，只要测试驾驶员在场并负责车辆安全操作，且车辆使用符合道路交通法律，即可开展自动化技术实路测试。

2. 在其他许多国家，现行立法似乎并不允许此类测试。已开放测试的国家通常仅限于特定地理区域并要求申请许可。美国有四个州立法允许自动驾驶汽车测试，但有15个州否决了相关法案。
