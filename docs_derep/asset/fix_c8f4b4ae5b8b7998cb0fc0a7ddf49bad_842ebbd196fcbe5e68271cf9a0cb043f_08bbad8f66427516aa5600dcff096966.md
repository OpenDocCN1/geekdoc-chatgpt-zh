本书在讲解 Qwen3、DeepSeek 等大模型工程实践时，PyTorch 承担了底层的支撑角色，负责模型载入、推理运行、参数微调以及分布式训练等关键工作。大模型要实现高效上线与精细微调，实质上依赖 PyTorch 提供的张量运算、自动微分能力以及对 CPU 与 GPU 的统一调度能力。因此把 PyTorch 运行环境搭好，是后续所有工作的基础前提。

在部署层面，PyTorch 提供了 CPU 线与 GPU 线两种方案，以匹配不同的硬件条件与性能诉求。

- CPU 线：适用于本地调试、轻量推理或暂无显卡资源的场景，配置简单，兼容性较好。
- GPU 线：能够调用 NVIDIA CUDA 加速，明显提升训练与推理效率，特别适合 Qwen3 这类超大模型的落地与调优。

相对而言，GPU 线的部署会牵涉到 CUDA 驱动、cuDNN 等底层依赖的版本对应，难度更高。鉴于 Qwen3 对算力的较高需求，建议在配备 NVIDIA 显卡的机器上优先部署 GPU 版 PyTorch，以发挥并行计算优势，加快训练与推理。接下来重点说明 GPU 版的部署流程与常见问题的处置思路。

1. 核心概念厘清

动手之前，先把三者的关系理清非常重要。

(1) CUDA：NVIDIA 发布的并行计算平台与编程模型，让开发者能够利用支持 CUDA 的 GPU 进行通用计算，而非仅限图形。简言之，PyTorch 在 NVIDIA 显卡上跑计算，需要 CUDA 作为桥梁。

(2) cuDNN：即 CUDA Deep Neural Network library，是 NVIDIA 针对深度神经网络提供的 GPU 加速库，内部实现了卷积、池化、归一化等常用操作的高度优化版本。cuDNN 构建于 CUDA 之上，是专用加速层，PyTorch 等框架会调用它来极致提升训练与推理效率。

(3) PyTorch：一个开源机器学习框架，本身并不直接与显卡对话，而是通过 CUDA 接口调用显卡算力。部署了 CUDA 版 PyTorch 后，框架即可借助 CUDA 与 cuDNN 在 NVIDIA 显卡上高效运行。

调用顺序可概括为：PyTorch→cuDNN→CUDA→NVIDIA GPU Driver→NVIDIA GPU。

因此部署顺序应为：先装显卡驱动，再装 CUDA 与 cuDNN，最后装对应版本的 PyTorch。

2. 部署前的准备

1) 核实显卡是否在 CUDA 支持范围内

确认电脑装有 NVIDIA 显卡且型号受支持。几乎所有现当代 NVIDIA 显卡，如 GeForce、RTX、Quadro、Tesla 等，均已支持。

官方支持清单可参考：https://developer.nvidia.com/cuda-gpus。

2) 查看显卡驱动版本

此步骤用于确定可用的 CUDA 版本。

(1) 按 Win+R 输入 cmd 回车打开命令提示符。
(2) 执行命令：nvidia-smi。
(3) 查看右上角的驱动版本与最高支持的 CUDA 版本。

例如输出中显示 CUDA Version:12.4，表示当前驱动最高可支持 CUDA 12.4，需部署不高于 12.4 的 CUDA 版本。

3. CUDA 的部署

CUDA 是 NVIDIA 的并行计算平台，PyTorch 的 GPU 加速依赖于它。

1) 核实显卡支持情况

访问 NVIDIA 官网核对型号，或在命令行执行：wmic path win32_VideoController get name 来查看。

2）获取 CUDA Toolkit

- 访问 NVIDIA CUDA 下载归档页：https://developer.nvidia.com/cuda-toolkit-archive。
- 选择适配系统的版本，建议选用 PyTorch 兼容的版本，目前常用 11.7 或 11.8。
- 按系统类型挑选安装包。

3）完成 CUDA 安装

运行下载的 .exe，建议使用默认安装路径。安装过程中务必勾选 CUDA Toolkit。

4）校验安装

命令行输入：nvcc -V，若能返回版本信息，则部署成功。

4. cuDNN 的部署

cuDNN 是 NVIDIA 的深度神经网络加速库，是 PyTorch GPU 加速的必要组件。

1）获取 cuDNN

(1) 访问：https://developer.nvidia.com/rdp/cudnn-download。
(2) 需要注册 NVIDIA 开发者账号。
(3) 选择与已部署 CUDA 版本匹配的 cuDNN 版本。

2）完成部署

解压 ZIP 包，将 bin、include、lib 文件夹复制到 CUDA 安装目录，默认路径为：C:\Program Files\ NVIDIA GPU Computing Toolkit\CUDA\vxx.x。

3）校验

查看 CUDA 安装目录下的 cudnn_version.h 文件确认版本。

### 2.2.1 ModelScope（魔搭社区）

ModelScope 由阿里巴巴牵头，联合多家国内顶尖科研机构与高校推出，是一个面向“模型即服务” MaaS 的共享平台。核心目标是降低人工智能模型应用门槛，促进开源模型的共享、协作与创新。

1. 核心定位与愿景

ModelScope 的愿景是成为人工智能模型领域的 GitHub。如同 GitHub 托管代码，ModelScope 致力于托管、分享与运行人工智能模型。它不仅是模型仓库，更提供从模型探索、体验、微调到部署的一站式生态。

主要用户包括：

- 人工智能研究人员：发布与验证自有模型。
- 应用开发者：快速找到并集成现成模型，无需从零训练。
- 学生与爱好者：学习前沿人工智能技术并动手实践。
- 企业用户：寻找商业化方案，降低研发成本。

2. 主要功能与核心组成部分

ModelScope 提供从模型探索、体验、部署到再开发的全链路服务。

1）庞大的模型库

（1）汇聚阿里巴巴、清华大学、北京大学、浙江大学、商汤科技、澜舟科技等顶尖实验室与高校的开源模型。
（2）覆盖范围广：自然语言处理、计算机视觉、语音识别与合成、多模态、科学计算等。
（3）模型类型多样：从基础图像分类、文本 Embedding，到大语言模型如 Qwen、Baichuan，文生图模型如 Taiyi、SD，语音合成模型等。

2）在线体验与 Demo

几乎每个模型都提供在线试玩 Playground 功能。用户无需本地部署环境，直接在网页上传图片、输入文本或录音，即可立即看到推理效果，大幅降低体验门槛。

3）Notebook 开发环境

平台提供集成好的云端免费 Jupyter Notebook 开发环境，基于 PAI-DSW，预装 ModelScope SDK 及常用依赖。用户可在浏览器中直接打开 Notebook，编写少量代码即可加载运行模型，进行原型开发与实验。

4）ModelScope Library（Python SDK）

这是 ModelScope 的核心组件，一个开源 Python 库。开发者可用极简代码，通常 2～3 行，即可在本地或云端下载、加载、推理模型。
