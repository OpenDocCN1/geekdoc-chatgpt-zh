# 别再盯着“灯塔”看了：真正的创新，源于逃离过去

我们总爱把目标当成远方的灯塔，拼命往前冲。可这灯塔最不靠谱——它只亮结果，不亮路。指引莱特兄弟造飞机的灯塔，没提过要先搞定感应线圈；指引计算机诞生的灯塔，也没暗示要先发明真空管。那些通往伟大的“踏脚石”，往往长得跟终点毫不相干，甚至看起来像是在浪费时间。

既然盯着未来看容易走歪，不如回头看看过去。过去已成定局，清晰无比。拿“当下”跟“过去”比，不用猜，也不用信运气，只需判断：**我们到底甩掉了多少过时的包袱？** 这把问题从“离终点近不近”，变成了“离起点远不远”。一旦目标是“逃离旧路”，全新的可能性反而自然而然地打开了。

**新奇，是进化的“自动导航仪”**

任何新奇的事物，都是通往“更新奇”事物的潜在跳板。别小看“有趣”，哲学家怀特海早说：“一个命题的趣味性比真实性更重要。”斯塔斯更直白：觉得“有趣”微不足道，是价值观倒挂了。新奇有趣的想法，能重塑思维模式，触发级联反应——一个新奇引出一串新奇，像滚雪球一样，把未来从“固定终点”变成了“无限延展的荒野”。

图片孵化器网站上的玩家最懂这套逻辑：他们选“外星人脸”繁育图片，不是因为它能变出汽车，纯粹因为它**够怪、够有意思**。这种“看不见尽头的潜力”，才是创新真正的燃料。

**“漫无目的”才是最高级的目的**

有人急了：没目标瞎转悠，不就是碰运气？错。最伟大的创新，从来不试图“去某个特定地方”。新奇性包含的信息量不比目标少，区别只在于：目标常给你个**坏指南针**，新奇性只让你**对照坐标（过去）确认当下位置**。告别“已知区”，比追逐“未知标”简单、可靠得多。

**偶然？那是“准备好的头脑”在捡漏**

别信“苹果砸中牛顿”那套童话。牛顿、巴斯德、阿基米德，哪个不是顶尖专家、跨学科大拿？巴斯德说得好：“机会只青睐有准备的头脑。”真正的偶然发现，是**敏锐的直觉 + 深厚的积累**捕捉到了“这个方向有戏”，哪怕终点在哪儿还不知道。这种对“有趣”的嗅觉，才是通往突破的隐形地图。

**为了证明这套理论，我们教电脑“瞎折腾”**

光说不练假把式。AI 领域有个铁律：理论不写成代码跑通，不算数。于是我们设计了**“新奇性搜索”算法**——灵感就来自那些在图片孵化器里“乱选一气”却玩出新花样的用户。

实验场景：让机器人穿越走廊出门。
*   **目标导向模式**：离门越近奖励越高。结果？容易卡在“指铢陷阱”里——明明要倒退才能绕过障碍，但算法死不让分数降，直接卡死。
*   **新奇性搜索模式**：**只要动作跟以前不一样，就有奖。**

一开始机器人满屋子**撞墙**——这新奇，奖励！撞遍了所有墙、所有角度，撞墙不再新鲜了怎么办？**只能学着不撞墙**。再后来，走廊里的新花样玩尽了，**唯一的“新”就是走出那扇门**。

全程没人教它“出门”，没人给“避障”打分，它却把“避障”、“导航”、“出门”全自学会了。这不是穷举法（那得试到宇宙灭亡），而是**自动按“从简单到复杂”的顺序进化**——简单的撞墙耗尽了，复杂的避障自然涌现。

**这才是反脆弱的创新逻辑**

目标导向迷信“从坏到好”，一遇欺骗性陷阱（指铢陷阱、局部最优）就翻车。新奇性搜索不认“好坏”，只认“新旧”。它天然免疫欺骗性，**强迫系统在耗尽简单可能后，被迫进化出复杂能力**。

下次再焦虑“目标在哪里”时，别抬头找灯塔了。低头看看脚下：**有没有条没走过的路？有没有个念头让你觉得“挺有意思”？** 跟着那个“劲儿”走，踏脚石会自己长出来，路也会越走越宽。
