## JSON 数据交换格式深度剖析

JSON（JavaScript Object Notation）号称“轻量级”，对比 XML 标签满天飞，字符少、体积小、传输快，早成 Web/移动端接口标配。

### 7.5.1

### JSON 文档的两大基石

JSON 世界里只有两种结构：**对象** 与 **数组**。

| 结构 | 对应 Python | 语法特征 |
| :--- | :--- | :--- |
| **对象** | `dict` | `{ "键": 值, ... }` 无序键值对，键必加双引号 |
| **数组** | `list` / `tuple` | `[ 值, 值, ... ]` 有序序列 |

值类型：字符串（双引号）、数值、布尔、null、对象、数组，**任意层级嵌套**。
