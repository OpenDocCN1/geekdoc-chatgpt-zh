# 用自然语言操控 QGIS：QGIS MCP 实战全景

QGISMCP 的核心在于用自然语言提示来辅助搭建 QGIS 项目、加载地理数据图层并执行 Python 代码。借助 Claude AI 的指令，用户可以对 QGIS 项目进行创建、加载、保存等全流程操作，并管理项目内的图层，包括增删矢量或栅格图层，如图 3-13 所示。系统还可调用 QGIS 地理处理工具箱里的各类算法。更进一步，它允许用户通过 Claude AI 在 QGIS 内部运行任意 PyQGIS 代码，为进阶用户带来极高的灵活性和定制空间。此外还内置了一批实用功能：ping 命令检查服务器连接、获取 QGIS 安装信息、加载与新建项目、查询项目信息、添加与移除图层、缩放至图层范围、读取图层要素、渲染地图、保存项目等。

QGISMCP 的出现正在重塑地理空间分析的工作方式。用户不必精通 QGIS 的繁琐操作，只需用日常语言就能让 AI 完成从数据加载、可视化到复杂空间处理与分析的各类任务，大幅降低使用门槛，让非 GIS 专业人员也能发挥 QGIS 的强大分析能力。结合任意 PyQGIS 代码的执行能力，也为构建高度定制化、自动化的地理空间流程提供了几乎无限的可能性。

借助自然语言交互，以往需要复杂操作和专业知识的 GIS 任务变得轻松。AI 在后台把用户指令转化为 QGIS 可执行的动作，极大提高效率和便捷度。无论城市规划、环境保护还是资源管理等领域，QGISMCP 都可能带来革命性变化。

#### 3.3.3 利用 MCP 增强 LLM 的能力

MCP 为大语言模型提供了访问外部工具与数据的标准化通道，从而显著扩展其能力边界，使其不再受限于训练数据。Claude 与 OpenAI Agent SDK 等平台均已支持 MCP，让开发者更容易构建更强大的 AI 应用。MCP 解决了 LLM 的根本限制，为模型提供了与真实世界交互并获取最新信息的机制，使其在更广任务上更可靠、更有用。将 LLM 与外部知识和操作联通，是打造实用可信 AI 应用的关键。

##### 1. Claude 对 MCP 的支持

Anthropic 的 Claude 桌面应用对 MCP 提供了全面支持。核心特性包括完整的资源支持，可把本地文件和数据作为上下文附加；支持提示模板，便于构建结构化 AI 交互；集成工具执行能力，让 Claude 能通过 MCP 调用并运行外部命令与脚本；支持本地服务器连接，提升隐私与安全性。此外，Anthropic 推出 Claude Code，这是一款交互式智能编程工具，不仅支持 MCP 的提示与工具集成，还可充当 MCP 服务器，与其他 MCP 客户端互通。Anthropic 还提供丰富文档和教程，指导开发者为 Claude 搭建基于 SSE 的 MCP 服务器和客户端。

Anthropic 在 Claude 桌面应用和 Claude Code 中的强力支持，体现了其把 MCP 视作扩展 LLM 能力的关键技术。通过 MCP，Claude 可深度集成外部工具与数据源，打破自身训练数据的限制，实现更广泛的应用。全面文档与教程旨在降低开发者构建 MCP 集成的门槛，鼓励更多参与者加入 MCP 生态。

##### 2. OpenAI Agent SDK 与 MCP

OpenAI 的 Agents SDK 内置 MCP 支持，由该 SDK 创建的智能体可直接连接 MCP 服务器。智能体能无缝访问 MCP 服务器提供的外部工具、数据和提示模板，无需额外定制集成。SDK 会自动处理 MCP 服务器的发现、工具执行和响应路由。同时支持本地 STDIO 服务器和远程 SSE 服务器。社区还开发了 openai-agents-mcp 扩展库，进一步简化集成。OpenAI 的支持被视为提升 AI Agent 互操作性、推动 MCP 成为 AI Agent 标准协议的重要一步。

OpenAI 与 Anthropic 的共同支持，强烈显示出行业对 MCP 作为让 AI Agent 与现实世界交互、访问外部资源的关键协议的共识。openai-agents-mcp 的出现，反映了社区为简化并增强 MCP 与 OpenAI 生态集成所做的努力，让更多开发者能便捷利用 MCP 的能力。

#### 3.3.4 基于 MCP 的工具互操作性：Zapier

Zapier MCP 展示了 MCP 在实现超 8000 种工具和软件生态系统无缝互操作方面的强大能力。这让 AI Agent 无需为各类功能做定制集成，从而大幅加速 AI 驱动自动化方案的研发。借助 Zapier 等平台，MCP 让 AI 应用触达海量工具，开发者可轻松把各种功能集成到 AI Agent 中。广泛的互操作性促进创新，允许开发者以新颖方式组合不同工具与服务。

##### 1. Zapier MCP：连接数千个应用程序

Zapier MCP 允许 AI 助手与 8000 多个应用交互，执行超过 30 000 个操作，且无需复杂的 API 集成。它本质上是 AI 工具与应用之间的“翻译器”，让 AI 能代表用户执行操作。用户可生成唯一的 MCP 服务器 URL，安全地将自己的 AI 连接到 Zapier 的集成网络，并可精细限定 AI 在连接应用中能执行的具体操作。支持 Cursor、Claude Desktop、OpenAI 等主流 AI 平台。

Zapier MCP 的出现标志着 AI 执行真实任务能力的重大突破。通过无需单独 API 集成就把 AI Agent 连接到庞大的应用生态，AI 助手可超越简单对话，真正融入用户的数字生活。Zapier 作为领先集成平台，通过 MCP 拓展能力，成为推动 MCP 在工具互操作领域应用的关键力量。其庞大的应用集成网络为 MCP 兼容的 AI Agent 提供丰富工具集，让开发者轻松构建功能强大的自动化方案。

##### 2. Zapier 作为领先的 MCP 服务提供商

Zapier MCP 简化了将 AI 连接到数千个应用的过程，无需自定义 API 编码。它在所支持应用中提供超过 30 000 个预设操作，并内置身份验证、速率限制和端点安全机制。此外提供操作命名、AI 值猜测、开关切换等功能来管理 MCP 操作，在一定速率限制内可免费使用。

其易用性、安全性和海量预构建操作库使其成为主流 MCP 服务提供商。它极大降低开发者把真实世界功能集成到 AI 应用的门槛。通过降低 API 集成复杂度并提供简易配置界面，Zapier MCP 让 AI 开发者轻松利用其强大功能。

#### 3.3.5 基于 MCP 的数据集成与共享：Supabase

Supabase MCP 展示了如何通过 MCP 简单且安全地实现 AI 模型的数据访问，让 AI 模型能直接与数据库交互。这消除了复杂数据管道的需求，让 AI Agent 实时访问和操作数据。MCP 为 AI 应用提供标准化且安全的与数据源交互方式，简化数据集成并实现更复杂的 AI 驱动数据分析与管理。直接访问数据使 AI Agent 能执行需要最新信息和修改数据能力的任务。

##### 1. Supabase MCP：连接 AI 与数据库

Supabase 推出官方 MCP 服务器，旨在把 AI 工具连接到其平台。AI Agent 可执行启动数据库、管理数据表、获取配置、在 Supabase 中查询数据等任务。Supabase MCP 暴露超过 20 种工具或功能用于数据库交互，充当 MCP 客户端与 Supabase 服务之间的桥梁，提供数据库操作、存储管理、边缘函数调用等。

Supabase MCP 直接满足 AI Agent 与数据交互和管理的诉求，催生新一代可无缝访问和操作后端数据的全栈 AI 应用。通过为 AI 提供与数据库交互的标准化方式，Supabase 简化了数据驱动型 AI 应用的开发。

##### 2. Supabase MCP 的架构与功能

Supabase MCP 使用 TypeScript 构建，采用模块化架构。关键组件包括处理客户端请求的服务器类以及所有操作的类型定义。支持通过环境变量和 config.json 文件进行广泛配置，提供创建、读取、更新、删除数据库记录、执行 SQL 查询、调用边缘函数、管理项目和组织等工具，还具备数据库分支功能以支持更安全的开发流程。

全面工具集体现了官方对 AI Agent 可能需要执行的常见数据库操作的深刻理解，使其成为 AI 驱动后端开发的强力工具。丰富的功能让 AI Agent 能以非常精细的方式管理和交互数据库。
