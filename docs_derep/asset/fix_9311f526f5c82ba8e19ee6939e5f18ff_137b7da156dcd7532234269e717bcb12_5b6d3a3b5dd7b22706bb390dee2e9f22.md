[PRE0]

首先构造一个形状为 `[50, 32, 32, 32]` 的输入张量，喂入 `conv2d` 接口。此处将输出通道数设为 32，核尺寸选 3×3，跨度采用缺省值 1。填充策略选择 `SAME`（按核尺寸自动补零）。执行后，结果形态变为：

`(50, 32, 32, 64)`

若将跨度调整为 `[2, 2]`，结果形态则变为：

`(50, 16, 16, 64)`

当然，填充策略也可改为 `"VALID"`，感兴趣的同学可自行验证差异。

> **贴士**
> TensorFlow 中 `padding="SAME"` 的本质是：先对输入进行补零，再执行卷积运算。

此外，该层还支持指定非线性函数、内核初始化策略或禁用偏移项等配置，建议动手尝试。

#### 2. BN 层速览

批归一化（`batch_normalization`）是当下最主流的归一化手段。它能显著提升模型收敛速度，同时有效抑制过度拟合风险。

[PRE2]

核心配置项详解：

*   **axis**：指定归一化的轴，缺省 -1（即特征图轴）。
*   **momentum**：移动平均的动量系数，缺省 0.99。
*   **epsilon**：防分母为零的微小常数，缺省 0.01。
*   **center / scale**：分别控制是否添加偏移（Beta）与缩放（Gamma），缺省均开启。若后接线性层，`scale` 可设为 False 以避免冗余计算。
*   **初始化器/正则约束/约束条件**：分别针对 Beta、Gamma、移动均值/方差提供定制入口，缺省均为标准配置（zeros/ones 等）。
*   **training**：标识训练/推理阶段，缺省 False。
*   **trainable**：是否纳入可优化参数集合，缺省 True。
*   **fused / renorm 相关**：提供算子融合加速及 Batch Renorm 扩展支持。
*   **virtual_batch_size / adjustment**：虚拟批大小与结果微调接口。

调用极简：直接 `tf.layers.batch_normalization(inputs)` 即可。

[PRE3]

输出维度验证：

`(50, 32, 32, 32)`
