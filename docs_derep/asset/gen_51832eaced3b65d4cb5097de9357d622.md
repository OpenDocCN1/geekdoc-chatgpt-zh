2. AGDISTIS 开源框架全景

`AGDISTIS`[11] 是一款由德国莱比锡大学开发维护的多语言、基于 Java 的开源实体链接框架。凭借不错的效果与活跃的社区支持，它已成为当前最受欢迎的开源实体链接方案之一。框架扩展性较强，官方默认对接 `DBpedia`，使用者也能基于自有数据源搭建知识图谱或知识库，将 `AGDISTIS` 迁移到自定义数据源上，完成更贴合场景的任务。

`AGDISTIS` 的特点是把超文本诱导的话题算法 `HITS` 与标签扩展策略、字符串相似度度量等方法结合起来，实现输入文本实体与知识库实体的准确对齐。其主要架构如图 6-19 所示，整体流程与 6.5.2 节介绍的方法基本一致。

图 6-19　`AGDISTIS` 的主要架构[10]

先由命名实体识别对输入文本做标注，再进入候选实体生成模块。对文本中抽取出的每个实体指称，`AGDISTIS` 会进行表面形式扩展，以尽可能扩大候选集合。候选集合生成后会用来构建用于消歧的图结构，并借助基于知识库的图搜索算法做初步消歧。最后对前序构建的图结构应用 `HITS` 算法，确定指称的最终链接对象并生成置信度。框架假设置信度最高的实体即为与文本指称正确对应的实体。

### 6.2.4 实体链接的实践价值

实体链接的应用主要集中在以下两方面。

1. 信息抽取与知识扩充

信息抽取得到的关键信息往往存在歧义，通过实体链接可将抽取到的实体指称映射到知识库中的实体以消除歧义。同时，指称能否成功链接到知识库也能作为判断抽取准确性的依据。实体链接可作为具备校验与对齐能力的后处理模块，串联在实体抽取系统下游。通过将抽取实体与知识库实体链接，既能消除歧义，也能判断抽取是否正确。

如图 6-21 所示，句子“中华民族的图腾通常被描绘成龙的形象。”中，实体抽取系统抽取出了“中华民族”“图腾”和“成龙”三个指称，但直观上“成龙”在此语境下不应作为实体出现，这正是由于“成龙”在常见语料中常指向人物导致模型误判。将句子与三个指称一起输入训练好的实体链接系统后，可发现“中华民族”“图腾”都能在知识库中找到得分较高的对应实体，而“成龙”则找不到高分匹配。由此，实体链接模块在完成链接的同时，也能识别出上游抽取错误，提升信息抽取的正确率。实际应用中，经过实体链接校正后，抽取准确率往往会有显著提升。
