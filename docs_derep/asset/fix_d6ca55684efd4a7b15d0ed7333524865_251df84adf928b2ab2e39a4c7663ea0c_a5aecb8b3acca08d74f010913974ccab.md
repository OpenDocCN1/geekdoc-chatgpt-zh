#### 3.2.1 R1 模型概览

官方同时开源 DeepSeek-R1-Zero 与 DeepSeek-R1 两个 671B 模型，并基于 R1 输出蒸馏出 6 个小模型，其中 32B 与 70B 在多项能力上对标 OpenAI o1-mini。
