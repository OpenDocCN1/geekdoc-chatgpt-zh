销售总额 = -5236.25 + 2.89 × 广告投入 + 0.84× 社交曝光量 + 243.75× 折扣幅度 + 96.25× 线下参与人数

系数明细表：

| 变量 | 系数 | 标准误 | t值 | P值 | VIF |
|---|---|---|---|---|---|

模型表现指标：
- R² = 0.99
- 调整后 R² = 0.98
- F 值 = 256.73 (p=0.000)

核心结论：

- 模型有效性
  - 决定系数达0.99，销售波动几乎被完整捕捉，外推能力也较强。
  - 四项自变量的显著性均通过检验，P值均小于0.05；VIF最高2.03，远低于5阈值，共线性问题可忽略。

- 变量作用
  - 广告投入：每多投入1元，销售平均抬升2.89元，是拉动最强的杠杆。
  - 社交曝光量：每次新增曝光对应销售约增0.84元，作用稳定。
  - 折扣幅度：每提升1个百分点，销售平均增加243.75元，需注意过度让利侵蚀毛利。
  - 线下参与：每多1名参与者，销售平均上浮96.25元。

- 风险点
  - 样本仅10组，极易过拟合，需要更大样本复核稳定性。
  - 折扣对利润的负向效应未计入，实际决策应结合成本核算。
  - 缺少竞争强度、季节等外部扰动因子，长期预测可能失真。

预测建议：
- 短期优先扩大广告预算与线下活动规模，边际回报更高。
- 长期应收敛对折扣的依赖，优化促销组合，并持续监测社交曝光向成交的转化效率。
