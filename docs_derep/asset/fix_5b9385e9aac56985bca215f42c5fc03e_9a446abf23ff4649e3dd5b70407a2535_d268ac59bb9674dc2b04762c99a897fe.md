# AI跳跃导航核心逻辑深度拆解：从角度求解到落地执行

实现智能体精准跳跃，关键在于解决两个核心问题：朝哪跳、能不能跳到。本文剖析一套成熟的技术方案，涵盖发射角折半查找、三维向量合成、抛射轨迹解析解与行为状态机驱动。

## 发射角确定：折半查找快速收敛

系统维护角度上下限，通过迭代逼近最优发射参数。优先测试上限边界，若偏差在容差范围内直接采纳；若最大角度仍触不到目标，则判定不可达。

```csharp
direction, distance = checkAngle(maxBound)

if -margin < distance < margin:
    return direction

# 检查最长距离的射击是否能够到达目标
if distance < 0:
    return null

# 现在已经有了最小边界和最大边界，可以使用二分搜索
distance = infinity
while abs(distance) >= margin:
    angle = (maxBound - minBound) / 2
    direction, distance = checkAngle(angle)

# 改变合适的边界
if distance < 0:
    minBound = angle
else:
    maxBound = angle

return direction
```

**机制要点**：
- `checkAngle` 反馈的距离正负驱动区间收缩：负值意指劲道不足（需抬高角度），正值则降低上限。
- 循环以 `abs(distance) < margin` 为终止条件，平衡精度与性能。
- 边界预检实现快速剪枝，省去无效迭代。

## 三维方向向量合成：平面朝向与仰角解耦

锁定角度后，`convertToDirection` 负责将平面位移与仰角合成为单位方向向量。

[PRE0]csharp

function convertToDirection(deltaPosition: Vector, angle: float):

    # 找到平面方向

    direction = deltaPosition

    direction.y = 0

    direction.normalize()

    # 添加到垂直分量中

    direction *= cos(angle)

    direction.y = sin(angle)

    return direction

[PRE1]

**步骤解析**：
1. **平面化处理**：置零 Y 分量并归一化，获取纯水平朝向基向量。
2. **速度分量分配**：水平模长缩放为 `cos(angle)`，竖直分量直接赋值 `sin(angle)`，默认单位发射速度。
3. **向量组装**：合成向量同时携带朝向与抛射角信息，供后续运动学使用。

## 跳跃行为类：基于标志位的执行调度

`Jump` 继承 `VelocityMatch`，引入跳跃点引用与可达性标记，构建“规划-验证-触发”闭环。

```csharp
class Jump extends VelocityMatch:

    # 要使用的跳跃点
    jumpPoint: JumpPoint

    # 跟踪跳跃是否可以实现
    canAchieve: bool = false

    # 角色的最大速度和垂直跳跃能力
    maxSpeed: float
    maxTakeoffYSpeed: float

    # 检索该跳跃的转向
    function getSteering() -> SteeringOutput:

        # 确保已经达到要实现的速度
        if not target: calculateTarget()

        if not canAchieve: return null

        # 检查是否已经命中跳跃点
        # 角色从 VelocityMatch 基类继承
        if character.position.near(target.position) and
           character.velocity.near(target.velocity):

            # 执行跳跃，并返回无转向
            # 因为角色已经腾空，所以无须转向
            scheduleJumpAction()
            return null

        # 委托给转向行为，以到达起跳位置
        return VelocityMatch.getSteering()
```

**调度策略**：
- **延迟初始化**：首帧调用才触发轨迹计算，避免冗余开销。
- **双重守卫**：不可达直接空转；到达起跳点即切换动作状态，停止转向输出。
- **复用基类能力**：起跳前的移动修正完全交由 `VelocityMatch` 处理。

## 轨迹求解器：解析解反推飞行参数

`calculateTarget` 利用竖直位移公式建立一元二次方程，直接求解飞行时间，而非数值积分。

```csharp
    # 计算出轨迹
    function calculateTarget():

        target = new Kinematic()
        target.position = jumpPoint.takeoffLocation
        jumpVector = jumpPoint.landingLocation -
        jumpPoint.takeoffLocation

        # 计算第一个跳跃时间，并检查是否可以使用它
        sqrtTerm = sqrt(2 * gravity.y * jumpVector.y +
                        maxTakeoffYSpeed * maxTakeoffYSpeed)
        time: float = (maxTakeoffYSpeed - sqrtTerm) / gravity.y
        checkCanAchieveJumpTime(jumpVector, time)

        if not canAchieve:
            # 否则尝试其他的时间（平方根）
            time = (maxTakeoffYSpeed + sqrtTerm) / gravity.y
            checkCanAchieveJumpTime(jumpVector, time)
```

**物理建模细节**：
- 由 `y = v0y*t + 0.5*g*t^2` 推导判别式 `sqrtTerm`，重力 `gravity.y` 为负值保证实根存在。
- 优先取**较小根**（低弹道、飞行时间短），符合自然移动偏好；失败则尝试**较大根**（高弹道）。
- 双根兜底设计覆盖平跳、上高、跨坑等多样地形。

## 可行性核验：水平速度上限硬约束

`checkCanAchieveJumpTime`（代码中为 `checkJumpTime`）将飞行时间换算为所需水平速度，与阈值比对。

```csharp
    # 检查跳跃是否可以在给定时间实现
    function checkJumpTime(jumpVector: Vector, time: float):

        # 计算平面速度
        vx = jumpVector.x / time
        vz = jumpVector.z / time
        speedSq = vx * vx + vz * vz

        # 检查速度
        if speedSq < maxSpeed * maxSpeed:
            # 已经获得一个有效的解决方案，所以存储它
            target.velocity.x = vx
            target.velocity.z = vz
            canAchieve = true
```

**判定逻辑**：
- 水平位移除以时间得必要速度分量 `vx`、`vz`。
- 平方和比较规避开根号运算，直接对比 `maxSpeed^2`。
- 通过即写入目标速度并置位 `canAchieve`，供行为驱动层读取。

### 设计经验总结

1. **职责正交**：角度搜索、向量合成、轨迹解算、行为驱动四模块解耦，利于单测与替换。
2. **解析解优先**：二次方程直接求根替代数值积分，确定性强且极快。
3. **兜底机制**：双弹道尝试 + 边界预检，鲁棒应对复杂地形。
4. **显式状态**：`canAchieve` 标志位将规划结果固化，避免重复计算与指令抖动。

该架构在多款 3D 动作大作中均有落地变体，堪称 AI 跳跃导航的参考范式。后续可探讨动态障碍规避、落地滚翻衔接等进阶扩展。
