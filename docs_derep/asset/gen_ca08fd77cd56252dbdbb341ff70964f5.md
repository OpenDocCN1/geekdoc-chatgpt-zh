\(P^{(i,i)}\) 与 \(Q^{(i,i)}\) 可在随机游走中分别模拟基于当前特征访问样本、及基于当前样本访问特征的概率。此外，基于矩阵 \(A^{(s,t)}\) 列归一化，可构建维度为 \(m_s \times m_t\) 的矩阵 \(F^{(s,t)}\)，其列和亦为 1。需注意，因部分特征不共现，\(F^{(s,t)}\) 某些列可能全为零。此时将该列所有元素设为 \(\frac{1}{m_t}\)，意指随机游走访问各样本概率均等。\(F^{(s,t)}\) 用于建模从目标域当前特征跳转至源域特征的概率。鉴于 \(A^{(t,s)}\) 对称，故有 \(F^{(t,s)} = F^{(s,t)}\)。

虽 \(A^{(i,i)}\) 与 \(A^{(s,t)}\) 元素含义不同，但借助耦合马尔可夫链模型，可将对应的概率矩阵 \(P^{(i,i)}\)、\(Q^{(i,i)}\)、\(F^{(s,t)}\) 及 \(F^{(t,s)}\) 融合，构建用于随机游走的混合样本-特征联合转移概率图。

## 11.3 基于隐性特征表示的传导式迁移学习

11.2 节介绍了一种 TTL 算法，通过引入中间域利用跨域特征相似性迁移知识。但在实际场景中，中间域往往不止一个，且难以预判哪个真正有效。加之源、目标及中间域数据来源各异，分布差异显著。本节将介绍一种新算法，分两步走：第一步筛选连接源、目标域的合适中间域；第二步在各域间高效迁移知识。首步引入概率模型，依据域难度、域间相似度等特征选域；次步综合域关系与分布差异，学习共同特征子空间以传播标签。

### 11.3.1 问题定义

设有标签源域 \(S = \{(x_i^s, y_i)\}_{i=1}^{n_s}\)，无标签目标域 \(T = \{x_i^t\}_{i=1}^{n_t}\)，及 \(k\) 个无标签中间域 \(D_j = \{x_i^{d_j}\}_{i=1}^{n_j} (j=1, \cdots, k)\)，\(x^* \in R^m\) 为 \(m\) 维特征向量。不同域数据维度可异。\(S\) 与 \(T\) 分布差异大，直接迁移会严重损害目标域性能。算法旨在选取合适中间域连接 \(S\) 与 \(T\)，并最小化 \(T\) 上的训练损失。

形式化而言，给定度量分布差异的函数 \(g(\cdot, \cdot, \cdot)\)，首步需选中间域使 \(g(S, T \| D_i) < g(S, T)\)；次步借助 \(D_i\) 实现 \(S\) 到 \(T\) 的迁移。通过学习特征聚类函数 \(p_{sd}(\mathbf{S}, \mathbf{D}_s)\) 与 \(p_{du}(\mathbf{D}_t, \mathbf{T})\)，分别获得 \(\mathbf{S}\) 与 \(\mathbf{D}_t\)、\(\mathbf{D}_t\) 与 \(\mathbf{T}\) 间的最大公共子空间，源域标签信息经此传播至中间域与目标域。
