## 第2章 DeepSeek 助力数据表单设计

供应商分析、数据筛选及预警方案

##### 一、供应商分析维度

- 1. 基础属性分析
  - 关注字段：营业执照到期日、生产许可证到期、资质/环境/职业健康认证到期日、危化品经营许可证到期日。
  - 目的：识别资质即将过期或已失效的供应商，避免因资质问题导致合作中断或法律风险。

- 2. 风险评分分析
  - 关注字段：风险评分、法律风险、环保处罚。
  - 目的：划分高、中、低风险供应商，优先监控高风险对象的稳定性。

- 3. 合作能力分析
  - 关注字段：合作潜力、首次合作日期、当前合同截止日期。
  - 目的：锁定核心供应商并制定长期策略，同时跟踪合同到期时间。

- 4. 财务与稳定性分析
  - 关注字段：注册资本、成立日期、企业性质。
  - 目的：评估财务实力和持续经营能力，筛出高潜力或潜在风险点。

- 5. 地域分布分析
  - 关注字段：地区、国家、省份、城市。
  - 目的：分析供应商的地理集中度，评估政策变化、自然灾害等外部影响。

##### 三、供应商提前预警机制

- 1. 资质到期预警
  - 触发条件：各类资质到期前1年、6个月、3个月。
  - 动作：
    - 自动发邮件提醒采购部门跟进续期。
    - 在系统内把供应商标记为“待处理”。

- 2. 合同续签预警
  - 触发条件：合同到期前6个月。
  - 动作：
    - 生成续签任务清单，分配给采购负责人。
    - 复盘合作表现，决定是否调整条款。

- 3. 风险动态预警
  - 触发条件：
    - 风险评分上涨超过10分。
    - 新增法律风险。
  - 动作：
    - 启动供应商复查流程，必要时暂停合作。

- 4. 财务变动预警
  - 触发条件：注册资本大幅变动或企业性质变更。
  - 动作：
    - 更新供应商档案，重新评估合作风险。

##### 四、输出建议

- 1. 供应商看板
  - 整合各表数据，展示资质状态、风险等级、合同到期等关键信息。
  - 示例字段：

- 2. 自动化预警报告
  - 每周产出预警清单，包含到期资质、高风险供应商及待续签合同。

- 3. 数据清洗与补全
  - 统一日期格式，去除时间戳；注册资本单位统一为“万元”。
  - 补全缺失字段，如 UNFO 的企业性质。
