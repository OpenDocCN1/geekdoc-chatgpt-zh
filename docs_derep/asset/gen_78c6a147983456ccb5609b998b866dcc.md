# 前言

几年前，“通用人工智能”仍像科幻小说里的概念，落地路径尚未明确。到了 2022 年，基于大语言模型的 AIGC 迅猛发展，让通用人工智能的实现更显逼近。研究者发现，当模型规模跨越阈值后，AIGC 系统能够理解自然语言指令，并生成真实高质量的文本、图像、音视频等多模态内容。扩散模型正是在这一波浪潮中脱颖而出的代表。

基于此背景，我们编写了这本扩散模型实战指南。书中详述扩散模型的原理、演进与应用，并以 Hugging Face 与 Diffusers 为依托展开模型实践。希望读者通过本书掌握扩散模型的核心知识，探索其无限可能。

## 第1章 扩散模型简介

扩散模型是一类基于扩散思想的先进深度学习生成模型。除扩散模型外，生成模型还包括较早的 VAE 与 GAN 等。两者虽有渊源，但本书不展开讨论，也不深入数学细节。即便如此，读者仍可依本书内容通过代码生成精美图像。

本章要点如下。

+   * 扩散模型的原理，说明其如何实现“扩散”。
* 扩散模型的发展，梳理图像生成领域的迭代与生态演进。
* 扩散模型的应用，介绍除图像生成外的其他用途。

### 1.1 扩散模型的原理

扩散模型运用物理热力学中的扩散思想，主要包含前向扩散与反向扩散两个阶段。下文在不涉及复杂推导的前提下介绍其原理。

#### 1.1.1 生成模型

在深度学习里，生成模型的目标是依据训练样本生成新样本。给定训练集 X，假设其服从真实分布 p(x)，则样本可视为该分布的观测。若能估计出真实分布，便可不断采样。生成模型即学习估计分布 q(x) 逼近 p(x)，此过程即网络拟合。

如何衡量 q(x) 与 p(x) 的差距？一种直观思路是让训练样本在 q(x) 下的采样概率最大化，这源自统计学中的最大似然估计，也是生成模型的基本思想之一。

#### 1.1.2 扩散过程

最大似然估计思想已在 VAE 等模型上取得成效。扩散模型可视为更深层次的 VAE，其表达能力更强，核心在于扩散过程。

扩散思想源自物理学非平衡热力学分支。该分支研究非平衡物理系统，典型案例是一滴墨水在水中扩散。初始时墨水形成斑点，其概率分布复杂。随着时间推移，墨水逐渐均匀扩散，水色趋同，此时分子分布变得简单易于描述。

非平衡热力学可刻画墨水在每个离散时间步的状态分布。若将过程逆转，便可由简单分布逐步推断复杂分布。

公认最早的扩散模型 DDPM 的原理由此而来。仅有扩散条件不足以反推，DDPM 做了若干假设：扩散过程为马尔可夫过程，即当前步状态仅依赖前一步并加入高斯噪声；逆过程亦假设为高斯分布等。

1）前向过程

前向过程是对数据逐步加噪。设训练数据分布为 x₀～q(x₀)，0 表示初始未扩散状态。将加噪过程离散为 T 步，每步 t 对 x_{t-1} 加入高斯噪声得到 x_t，再送入下一步。噪声方差由区间 (0,1) 内的固定值 β_t 决定，均值由 β_t 与当前带噪分布确定。经过足够多次迭代后，数据趋近纯随机噪声，对应稳定墨水系统。

单步加噪的数学表达为：

q(x_t| x_{t-1})=\mathcal{N}(x_t; \sqrt{1-\beta_t}x_{t-1}, \beta_t I)

整体噪声分布为：

q(x_{1:T}| x_0)=\prod_{t=1}^T q(x_t| x_{t-1})

## 4 扩散模型从原理到实践

2）反向过程

前向是噪声化，反向则是去噪，即由随机噪声迭代恢复清晰数据。

从 x_t~N(0, I) 恢复 x_0 需要知道每步的分布转移。DDPM 将反向过程同样建模为马尔可夫链，由神经网络参数化的高斯分布序列构成。

单步去噪表达为：

q(x_{t-1}| x_t, x_0)=\mathcal{N}(x_{t-1}; \tilde{\mu}(x_t, x_0), \tilde{\beta}_t I)

经贝叶斯推导可得均值与方差：

\tilde{\beta}_t=1/\left(\frac{\alpha_t}{\beta_t}+\frac{1}{1-\overline{\alpha}_{t-1}}\right)=1/\left(\frac{\alpha_t - \overline{\alpha}_t + \beta_t}{\beta_t(1-\overline{\alpha}_{t-1})}\right)=\frac{1-\overline{\alpha}_{t-1}}{1-\overline{\alpha}_t}.\beta_t

\tilde{\mu}_t(x_t,x_0)=\left(\frac{\sqrt{\alpha_t}}{\beta_t}x_t + \frac{\sqrt{\overline{\alpha}_{t-1}}}{1-\overline{\alpha}_{t-1}}x_0\right)/\left(\frac{\alpha_t}{\beta_t}+\frac{1}{1-\overline{\alpha}_{t-1}}\right)=\left(\frac{\sqrt{\alpha_t}}{\beta_t}x_t + \frac{\sqrt{\overline{\alpha}_{t-1}}}{1-\overline{\alpha}_{t-1}}x_0\right)\frac{1-\overline{\alpha}_{t-1}}{1-\overline{\alpha}_t}.\beta_t=\frac{\sqrt{\alpha_t}(1-\overline{\alpha}_{t-1})}{1-\overline{\alpha}_t}x_t + \frac{\sqrt{\overline{\alpha}_{t-1}}\beta_t}{1-\overline{\alpha}_t}x_0

方差为定值，均值依赖 x_0 与 x_t，需由扩散模型优化。

## 5 扩散模型从原理到实践

3）优化目标

扩散模型预测噪声残差，要求反向预测的噪声与前向施加的噪声距离最小。
