## ◎第一节 与Python初次见面

同学们，人工智能已经深度融入我们的学习、生活与工作，例如交通导航、语音识别、智能机器人……在人工智能的发展路上，Python 功不可没，我们可以通过它与计算机交流，让计算机执行各种任务。

学习 Python 首先要认识“IDLE”编辑器。IDLE 相当于我们和计算机之间的“翻译官”，可以很方便地新建、运行和调试 Python 程序。

下面就从认识 IDLE 开始吧！

在安装好 Python 开发环境的电脑上，点开“开始”菜单，找到 IDLE（Python 3.7 64-bit）并启动，打开后的界面如下：

### 方法二：新建项目文件

如图 1-1-2 所示，IDLE 的“`>>>`”区域可以直接输入代码做测试，但若要编写多行代码，最好新建一个“项目”来写，这样便于保存代码。

新建项目的步骤如下。

1.点击 IDLE 界面左上角的`File`（文件）按钮，选择`New File`（新建），在编辑区输入：

`print（"大家好，我是某某"）`

2.选择运行（`Run`）菜单下的运行模块（`Run Module`）。按提示保存项目，注意保存到自己记得的位置，文件名可自行设定，再查看运行结果。

[PRE9]

图 1-1-3　新建项目界面

3.测试完成后，点击窗口右上角的×关闭退出。

上面这些操作里，我们编写的代码已经被保存在电脑上了。以后想重新打开，可以在 IDLE 编辑器里点左上角的`File`（文件）菜单，选择`Open`（打开），定位到保存的文件夹，找到文件并打开即可。

**小结：**

`print（）`函数是 Python 里最常用的函数之一，字面意思是“打印”，在编程里可理解为“输出”。

编写与测试代码主要有两种做法：

1.直接在 IDLE 的`>>>`后面写代码并执行，适合实时调试。

2.新建“项目”，把代码保存成文件，便于保存、修改和重复使用。

特别提醒：代码中的括号或引号，必须使用英文半角。
