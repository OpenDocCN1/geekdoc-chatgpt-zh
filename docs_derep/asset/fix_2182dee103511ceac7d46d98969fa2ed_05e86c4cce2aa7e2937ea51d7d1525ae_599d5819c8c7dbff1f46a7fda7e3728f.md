- kernel.py：聚焦量化与矩阵乘法等核心算子，利用 Triton 库加速并针对 FP8 精度做了优化。Triton 是面向 GPU 自定义算子的开发框架，支持 Python 与 PyTorch，少量代码即可实现高效 GPU 核。
- model.py：定义了 DeepSeek-V3 的整体架构。

图3.7 DeepSeek项目模型权重相关说明

DeepSeek-V3 的权重包可在 Hugging Face 获取，整体约 650GB，魔搭社区亦提供镜像下载。官方列出的本地运行方案有：

- (1) DeepSeek-Infer Demo：轻量演示程序，兼容 FP8 与 BF16 推理。
- (2) SGLang：完整支持 DeepSeek-V3 在 BF16、FP8 模式下运行，多标记预测 MTP 功能即将上线。
- (3) LMDeploy：提供高效的 FP8、BF16 推理，适合本地与云端部署。
- (4) TensorRT-LLM：当前支持 BF16 推理及 INT4/8 量化，FP8 支持正在推进。
- (5) vLLM：可在 FP8、BF16 下实现张量并行与流水线并行。
- (6) AMD GPU：借助 SGLang，可在 BF16、FP8 模式下于 AMD GPU 运行。
- (7) 华为 Ascend NPU：支持在华为 Ascend 设备上运行。

原生框架以 FP8 训练，因此仅发布 FP8 权重，约 700GB 以上显存即可启动。若转为 BF16 半精度，需 1400GB 以上；压缩至 INT4 约需 450GB 以上。参考半精度场景：约占用 490GB 显存，相当于 7 张 80GB A100，按市场价租赁约 1000 元/天。

#### 3.1.5 DeepSeek-V3 Function Calling

##### 1. Function Calling功能简介

Function Calling 是大模型迈向通用智能体的关键能力，允许模型在生成自然语言的同时，根据用户意图调用预定义函数或工具，实现更具交互性和实用性的任务处理。其流程示意见图3.14。

传统对话系统仅能输出语言，缺乏真实外部调用。Function Calling 通过结构化接口，通常以 JSON Schema 描述函数，使模型具备

##### 2. 外部工具API

先解释外部工具 API 的含义。API 即应用程序接口，例如 Python 中使用的 ChatCompletion.create 函数，本质上是 OpenAI 提供的 GPT 系列模型的调用接口，通过该接口或 openai 库即可调用模型并实时得到结果，其他应用也有类似接口。

本节示例采用可实时查询天气的 OpenWeather API。先调用该 API 获取实时天气，再借助 Function Calling 调用，相当于赋予模型实时获取天气的能力。之后可通过模型查询天气或获取穿衣建议等。此类接入相当于构建了一个简易的天气查询助手。

使用 OpenWeather 服务与 OpenAI 类似，需先注册账号并获取 API key。多数在线服务均需 API key 鉴权，即使 OpenWeather 提供大量免费额度，身份验证仍不可少以防滥用。获取步骤如下。

- (1) 访问 OpenWeather 官网，选择 Sign in→Create an Account 完成注册，可使用国内邮箱或 QQ 邮箱。官网截图见图3.15，注册页截图见图3.16。
