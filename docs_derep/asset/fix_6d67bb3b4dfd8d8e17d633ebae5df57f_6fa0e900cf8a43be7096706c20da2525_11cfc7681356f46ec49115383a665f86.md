# 本地运行 Open WebUI 并接入 DeepSeek

想在自己的电脑上体验可视化对话界面，同时调用 DeepSeek 的模型能力，整体可以分为三段：准备运行空间、启动 Web 服务、编写调用示例。下面给出可直接复用的最小流程。

**搭建运行空间**
先用下面这组命令搭建独立的 Conda 工作区并载入：
[PRE0]bash

# 创建一个名为 open-webui 的 Conda 虚拟环境，并指定 Python 版本为 3.11

conda create -n open-webui python=3.11

# 初始化 Conda

conda init

# 重新加载 shell 配置

source ~/.bashrc

# 激活刚刚创建的 open-webui 环境，进入该环境

conda activate open-webui

随后使用清华镜像提速安装本体：
[PRE1]bash

pip install open-webui -i https://pypi.tuna.tsinghua.edu.cn/simple

**启动前端**
安装完成后直接启动服务，即可在本地打开 Web 界面：
[PRE2]bash

open-webui serve

**Python 调用 DeepSeek**
若想在代码里直接调用，可先装 OpenAI 兼容的 SDK：
[PRE3]bash

pip install openai

下面这段示例展示如何填入 Key、生成客户端对象、请求 deepseek-chat 并打印结果。把占位符换成自己的凭证即可：
[PRE4]python

import os

from openai import OpenAI

from IPython.display import display, Code, Markdown

import requests

import json

# <YOUR_DEEPSEEK_API_KEY>替换为复制的 API key 字符串

ds_api_key = '<YOUR_DEEPSEEK_API_KEY>'

#实例化客户端

client = OpenAI(api_key=ds_api_key,
                base_url="https://api.deepseek.com")

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "你好，好久不见!"}
    ]
)

#输出生成的响应内容

print(response.choices[0].message.content)

#输出完整的响应

print(response)

**进阶用法**
查看当前账号可用的模型列表：
[PRE6]python

models_list = client.models.list()

print(models_list.data)

返回示例：
[PRE7]

[Model(id='deepseek-chat', created=None, object='model', owned_by='deepseek'),

常会先设定系统角色再发用户提问，系统消息写法如下：
[PRE8]python

system_message = {
    "role": "system",
    "content": "你是一位擅长编写 python 代码的助手。"
}

普通用户消息示例：
[PRE9]python

user_message = {
    "role": "user",
    "content": "你好，请介绍下你自己。"
}

若要做多模态输入，可把文本与图片链接一起传给模型：
[PRE10]python

user_message_with_image = {
    "role": "user",
    "content": [
        {"type": "text", "text": "你能帮我介绍下这张图片里面的内容吗？"},
        {"type": "image_url",
         "image_url": {
             "url": "https://ml2022.oss-cn-hangzhou.aliyuncs.com/img/image-20241009205714055.png"}}
    ]
}

把系统消息与用户消息组合调用的完整示例：
[PRE11]python

#创建用户消息
user_message = {
    "role": "user",
    "content": "你好，请介绍下你自己。"
}

#调用 DeepSeek-V3 模型
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        system_message,
        user_message
    ]
)

#输出生成的响应内容
print(response.choices[0].message.content)

按照上述三步，先准备好隔离的工作区并跑起该服务，再用 OpenAI SDK 以兼容方式接入 DeepSeek，就能在本地完成从界面到代码的验证。
