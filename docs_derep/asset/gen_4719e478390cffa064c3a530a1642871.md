ChatGPT有一次对企鹅的介绍是这样的：陆地上看起来笨拙的企鹅，实际上是游泳高手。流线型的体型、致密的羽毛帮助它们在水里保持平衡和浮力，翅膀演化成类似蹼的桨，骨骼结构也更利于推进而非奔跑，所以水里速度很快，陆地上反倒显得缓慢。

这个回复明显偏离了提问本意。ChatGPT会从对话中不断学习，在试过一些方言表达后发现，很多口语化词汇它都能理解，但仍然不建议在提示里大量使用方言词。

网络上一些另类的书写方式，比如以火星文为代表的流行写法，最好也避免使用。倒是颜文字和emoji它能正常识别，因为第一章提到过，模型先把文字转成Unicode编码再计算，颜文字和emoji本质上也是Unicode字符。

### 【示例3-5】Unicode
Prompt: o (^_^) o前面这个表情的含义是什么?

ChatGPT: 这个o (^_^) o一般被理解为一种笑脸，通常用来表达轻松愉快、可爱或心情不错。也有人觉得它带着一点羞涩，因为眼睛半闭嘴角上扬，看起来有点害羞。总体上，在社交媒体或聊天场景里，它多用来传递积极友好的情绪。

用段落和空行把不同的意思分开，能让对话更有条理、更易读懂。想突出某个重点时，把它单列一段，模型就更容易抓住权重。

### 【示例3-6】主题思想
Prompt: 古人常以比喻说明对理想的追求，涉及基础、方法、路径、目标及其关系等。如汉代扬雄就曾以射箭为喻，他说：“修身以为弓，矫思以为矢，立义以为的，奠而后发，发必中矣。”

上述材料能给追求理想的当代青年什么样的启示?

ChatGPT：这则射箭比喻其实在讲，追理想需要打好根基、选对方法、找准路径、明确目标并持续维系。给当代年轻人的启发可以归纳为：

- （1）根基要扎实：修身以为弓，指要有良好的品德、知识和技能作为支撑。
- （2）思维要纠偏：矫思以为矢，指要调整错误观念，保持正确心态。
- （3）目标要清晰：立义以为的，指要设立明确目标并不断优化。
- （4）准备要充分：奠而后发，指先做好积累和稳定准备再行动。
- （5）追求高水平：发必中矣，指要以卓越为方向持续提升能力。

总结来说，青年人在追理想时要兼顾基础、方法、路径和目标的构建与优化，保持耐心与恒心，朝着更高标准不断提升自己。

尽量避免情绪化的词，用平实的语气表达，这样不容易被当成强调或愤怒，影响模型对意思的判断。

## 3.2 语法

想突出某个词或句子，可以在前后加上两个星号、下划线或引号。

## 3.3 拆分任务
生活中做一道复杂的菜或组装机器时，我们会自然把它拆成若干小步骤。计算机领域也是如此，函数就是把复杂工作拆成更小单元的工具，让代码更易读维护。

对GPT类模型也一样，拆分任务能带来帮助：

1. 理解更到位：每一步都是独立小问题，模型能集中处理而不是一口气想太多。
2. 上下文受限：模型窗口有限，任务拆小后每段都能完整留在视野里。
3. 降低出错率：简单任务出错概率更低。
4. 反馈更及时：每步完成后可以纠偏，后续回答更贴合需求。

下面是一个拆分示范。

### 【示例3-14】任务拆分1
Prompt (bad)：
将三重波浪号包裹的文本总结文本摘要，提炼文本中的3个核心关键词，然后起个标题，最后将标题、核心关键词、文本摘要翻译成英文。
Prompt (good)：
按照下面的步骤处理三重波浪号包裹的文本：
1. 总结文本摘要。
2. 提炼文本中的3个核心关键词。
3. 为文本起个标题。
4. 将标题、核心关键词、文本摘要翻译成英文。
～～～文本～～～

提示太复杂容易跑偏，拆任务能让结果更精准。若自己拆不好，也可以先让ChatGPT帮忙拆，下面是示例。

### 【示例3-15】任务拆分2
Prompt：
下方三重波浪号包裹内容为一个复杂的任务提示，请将任务提示拆分为多个子提示。
~~~
将三重波浪号包裹的文本总结文本摘要，提炼文本中的3个核心关键词，然后起个标题，最后将标题、核心关键词、文本摘要翻译成英文。
~~~
ChatGPT：
1. 将三重波浪号包裹的文本总结为文本摘要。
2. 提炼文本中的3个核心关键词。
3. 为文本起个标题。
4. 将标题翻译成英文。
5. 将核心关键词翻译成英文。
6. 将文本摘要翻译成英文。

让模型拆出来的子任务通常比手工拆更细，再用整理后的步骤去执行，效果会更好。

## 3.4 细化关键词
交流时要尽可能把核心概念限定清楚，避免发散，给出足够信息能减少模型的猜测，提升质量。

### 【示例3-16】收敛

Prompt (good)：

Prompt (bad)：

Prompt（bad）：总结会议记录
