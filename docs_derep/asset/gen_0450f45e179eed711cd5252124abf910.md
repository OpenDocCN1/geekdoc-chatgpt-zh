# 巧用 INDEX 与 MATCH 组合，实现 Excel 数据精准定位

在 Excel 中，`INDEX` 函数能根据指定区域返回单元格数值或区域引用，而 `MATCH` 函数则擅长在区间内查找特定值并反馈其相对位置。将两者结合，便能高效完成数据定位、信息检索及录入校验等任务。下面通过实战案例，演示如何借助 ChatGPT 快速生成 `INDEX` 与 `MATCH` 组合公式，查找员工档案信息。

**步骤 01** 打开工作表（参考 [PRE0] 图示）。界面呈现两张表单，右侧表格的缺失数据需从左侧表格中匹配获取。

[PRE0]

**步骤 02** 启动 ChatGPT 对话窗口，在输入框键入指令：“Excel 表中，`A:C` 列为查找源区域。需定位 `F` 列单元格提供的姓名在源区域的行号，以及 `I` 列表头在源区域首行的列号，最终将交叉结果输出至 `I` 列单元格。请用 `INDEX` 配合 `MATCH` 函数编写完整查找公式。” 发送后，ChatGPT 将输出组合公式（见 [PRE1]、[PRE2] 图示）。

### 035 ChatGPT 写 FREQUENCY 函数，秒统计奖金区间人数

[PRE13]

统计区间人数，`FREQUENCY` 函数是专业之选。作为统计函数，它能计算数据集的频次分布，将数值按自定义区间分组计数。实战演示如何让 ChatGPT 编写公式，快速完成奖金分层统计。

**步骤 01** 打开工作表（见 [PRE14]）。任务是统计各奖金区间人数。注意：录入区间条件时，仅填各段上限值（如 0-800 区间仅录 800）。

[PRE14]

**步骤 02** 发指令给 ChatGPT：“需按 `E2:E5` 单元格的区间上限，统计 `C2:C9` 数据的分布频次，请用 `FREQUENCY` 函数写公式。” AI 回复公式（见 [PRE15]）。

[PRE15]

**步骤 03** 复制公式，选中 `F2:F5` 目标区域，粘贴至编辑栏：`=FREQUENCY(C2:C9,E2:E5)`，随后按 `Ctrl+Shift+Enter` 组合键确认为数组公式，分布统计即时出结果（见 [PRE16]）。

[PRE16]

#### 专家提示

Excel 中输入数组公式必须用 `Ctrl+Shift+Enter` 确认。此类公式可对多区间数据并行运算并返回多结果，常用于批量计算、汇总或筛选。确认后公式两侧会自动加花括号 `{}` 标识数组属性，切勿手动输入。
