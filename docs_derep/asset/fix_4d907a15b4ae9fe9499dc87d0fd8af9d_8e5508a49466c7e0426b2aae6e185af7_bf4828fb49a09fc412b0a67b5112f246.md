根号 2 为无理数。

**证明过程如下：**

采用反证法说明根号 2 不是有理数。

设根号 2 为有理数，则可写成互质分数 a/b 的形式，其中 b 不为 0 且 a、b 互素。

1. 两边平方：

\[ (\sqrt{2})^2 = \left(\frac{a}{b}\right)^2 \]

得到：

\[ 2 = \frac{a^2}{b^2} \]

2. 乘以 b²：

\[ 2b^2 = a^2 \]

由此可知 a² 能被 2 整除，进而 a 能被 2 整除，记 a = 2k，k 为整数。

3. 代回：

\[ (2k)^2 = 2b^2 \]

化为：

\[ 4k^2 = 2b^2 \]

即：

\[ 2k^2 = b^2 \]

于是 b² 也被 2 整除，故 b 也能被 2 整除。

4. a 与 b 本为互质，却同时含有因子 2，产生矛盾。故根号 2 不可能是有理数。

因此可以断定根号 2 是无理数。 < | end_of_sentence | >

这段代码实例化了训练器并配置了关键超参，涉及的组件有：

- SFTTrainer 类来自 trl 库：trl 即 Transformer Reinforcement Learning，是 Hugging Face 推出的工具包，覆盖有监督微调与强化学习，SFTTrainer 专注于有监督微调，兼容 LoRA 等低秩适配方案。

- TrainingArguments 类来自 transformers 库：该类用于设定训练超参数，例如批大小、学习率、优化器以及训练步数等。

- is_bfloat16_supported() 函数来自 Unsloth：用于判断当前 GPU 是否支持 bfloat16，若支持返回 True，否则返回 False。bfloat16 是一种更高效的数值表示，在 NVIDIA A100/H100 等新一代显卡上表现更好。
