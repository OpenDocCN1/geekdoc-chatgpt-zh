长上下文注意力提速：从查询侧索引到子空间计算

在查询侧先做桶筛选，生成 Query 之后并不直接与全量 Key 对齐，而是先查索引，把计算范围限定在少数几个 Key 子集内。随后子空间注意力只在这些候选 Key 上展开，矩阵规模被压小，执行效率随之提升。

这样做从根本上砍掉了 Query 与无关 Key 之间的大量冗余相似度计算，同时让硬件访存更集中、局部性更好。

### 1.3.4 稀疏注意力vs线性注意力

Transformer 的自注意力是核心模块，但标准形式对长度为 N 的序列时间与空间复杂度都是 O(N²)。在长序列推理和训练里这非常吃力，对 QwQ-32B 这类百亿参数级别的模型，瓶颈更突出。因此研究者提出了两类主流优化：稀疏注意力和线性注意力。

两者改造思路不同：前者以结构化选择压缩计算区域，后者从核函数层面重构计算路径，各自在不同任务和硬件环境下各有优势。

#### 1. 稀疏注意力（Sparse Attention）：区域限制与可控计算

稀疏注意力的核心是在权重计算中加入位置选择，不再让每个 Query Token 与全部 Key Token 求相似，而是只关注重要或相关的部分位置，通过稀疏化注意力矩阵来降低复杂度。

常见稀疏模式有：

- （1）局部窗口注意力（Local Attention）：仅在固定长度的局部窗口内算注意力，适合语义连贯的文本。
- （2）滑动窗口注意力（Sliding Window）：每个 Token 关注邻近区域，并通过跨段连接保持全局连通。
- （3）块稀疏注意力（Block-Sparse）：把输入分块，只在选定块对之间建立连接，兼顾局部性和远程依赖。
- （4）自适应稀疏注意力（Learned Sparse Attention）：动态挑选连接路径，如 BigBird、Longformer 采用的混合稀疏结构。

优点是结构可控、实现灵活、能和原生 Attention 格式兼容；缺点是稀疏模式设计难度大、对硬件稀疏优化依赖强，且对完全非结构化文本适应性有限。

在 QwQ-32B 里，稀疏注意力主要用在 KV Cache 压缩和多段文档融合推理，能有效降低解码阶段注意力热区的密度，减少无效计算。

#### 2. 线性注意力（Linear Attention）：核函数重构与并行优化

线性注意力从核函数入手，把复杂度从 O(N²) 降到 O(N)。关键是用可加性核函数替代 softmax 归一化，如 ReLU、ELU 或带正性约束的变换，并让 Q、K、V 融合计算，重组为线性组合，避免显式构造完整相似度矩阵。

典型代表包括 Performer、Linformer、CosFormer/DAGFormer 与 Retentive Networks。

- (1) Performer：用随机特征映射把 softmax 近似为线性核。
- (2) Linformer：对 K/V 做低秩投影，实现序列压缩。
- (3) CosFormer/DAGFormer：引入傅里叶变换或图结构建模长程依赖。
- (4) Retentive Networks：将线性注意力和记忆机制结合，增强语义保留。

最大优点是可扩展性强、硬件并行友好，适合超长序列，推理效率高，内存随长度线性增长。缺点是缺少 softmax 聚焦，信息对齐、生成质量和细粒度控制会打折，不适合跨段交互频繁的任务。

QwQ-32B 并未把线性注意力设为默认结构，但在多轮长上下文推理实验中把它作为可选优化路径，在大于 32K 窗口、KV Cache受限的场景下表现出较好的资源友好性。两者对比如表1-2所示。

表1-2 稀疏注意力vs线性注意力综合对比

| 比较维度 | 稀疏注意力 | 线性注意力 |
| :--- | :--- | :--- |
| 复杂度 | O(N × k)，k 为局部连接数 | O(N)，线性 |

## 1.4 模型压缩与结构稀疏性优化

随着模型参数持续变大，压缩和结构稀疏优化成为提升部署效率和推理性能的关键。QwQ-32B 在保持表达力的前提下引入多种压缩策略和稀疏重构，包括参数高效微调 LoRA、低比特量化 QLoRA、分层剪枝和学生-教师蒸馏框架等，显著降低实际部署的算力消耗。本节聚焦其结构稀疏建模与压缩技术的工程实践。

### 1.4.1 LoRA在QwQ-32B中的精调集成

大模型参数规模快速增长，全参数微调已难以满足算力、存储和训练周期要求。LoRA 通过在 Transformer 关键矩阵中注入低秩可训练模块，实现参数冻结下的高效微调，本质是参数高效微调 PEFT，只训练少量新增参数即可迁移，显存开销和训练时间大幅下降，特别适合 QwQ-32B 这类百亿级复杂结构。

在 QwQ-32B 中，LoRA 模块深度集成于 Attention 子层和前馈网络的线性变换，支持模块级精细插入、多任务共享配置，并具备动态图插拔、热更新、分租户 LoRA 加载等工程特性，广泛用于行业定制模型构建、轻量级多任务适配和推理时的在线个性化微调。
