# 企业并购尽调清单全景版

做尽调不是走流程，而是把风险点一件件拎出来核实。下面把股东、股权、出资、投资、治理、内控、资产、人力、业务等核心模块的核查要点，按实操表格顺序梳理清楚，便于快速对照执行。

### 股东与股权基础核查
**股东架构与性质**
5. 各股东的股权结构图，如股东为公司主体。
核查路径：向目标公司索取资料，现场访谈核实，并走访工商等登记部门，调阅营业执照、公司章程、财务报表及审计报告等，交叉印证真实性。
6. 各股东的股权属性清单，国有与非国有划分。
核查路径同上，通过工商、章程、财报与审计资料互相对照确认。
7. 股东权利行使情况。
重点看选举权、决策权、分红权是否实际行使、行使是否合规。
8. 个人股东身份及履历、法人股东基本情况。
要求尽可能详实，不足部分需补充说明。

每项均需形成调查结论，并将原始文件或谈话记录作为附件后置，保持关联，调查人签字确认。

### 表6-5 股东出资专项核查
调查项目为股东出资，出资比例、方式、期限、到位及权属是核心。

1. 各股东出资比例与金额汇总表。
方法：访谈会计师事务所等中介、公司高管及财务人员，查询工商档案，查阅验资报告及股东与公司间的资金往来凭证。1至6项可合并呈现。关注点：出资是否按时足额、方式是否合法、有无出资不实、虚假出资、抽逃资金；非货币出资的房屋、土地、车辆、商标、专利等产权是否清晰；资产过户是否规范。
2. 各股东出资方式清单。
3. 各股东出资期限及分期安排清单。
4. 各股东出资实际到位情况清单。
5. 各类出资资产移交或过户手续清单。
6. 各类出资资产权属明晰情况清单。
7. 非货币出资是否存在不足值情形。
8. 股东权利行使情况。

附调查结论、备注、附件目录及调查人签字。

### 表6-6 股权对外投资核查
调查项目为对外投资情况。

1. 子公司情况。
要求公司提供资料并到工商查询，取得营业执照、财务报告、投资协议等，了解被投资方经营状况。需审计的被投资方须获取审计报告，重大投资须取得投资合同及目标内部审批文件。
2. 其他关联方情况，指直接或间接持股5%以上或存在实际控制关系的公司。
通过访谈、咨询中介，调阅公司及控股股东、实际控制人的股权结构与组织架构、重要会议纪要及合同，按《公司法》及会计准则确认关联关系，并调档查阅关联方工商登记。

汇总调查结论、备注、附件目录及签字。

### 6.3.4 内部管理与经营风险控制
内部管理与经营风险控制的相关模板见表6-12至表6-14。

### 表6-12 组织架构与制度管理核查
调查项目为组织结构与规章制度。

1. 内部组织结构图。
与管理层沟通，索取规章制度，必要时查阅历史事件相关文件。
2. 各岗位职责说明。
与相关管理人员交流，索取公司正式文件。
3. 规章制度汇编。
了解公司是否建立知识产权等管理与保护制度，有则要求提供。
4. 近三年经营管理说明，涵盖业务、人员、财务变化。
要求提供分支机构设立变更文件及对分公司的管控文件。

形成调查结论、备注、附件目录及签字。

### 表6-13 合同管理风险核查
调查项目为合同管理。

1. 各项买卖、租赁及业务是否均签订书面合同。
向经办人员了解，要求提供合同文本、管理制度及凭证，关注制度执行。OA系统使用者需查阅系统记录。
2. 合同审批权限及流程是否明确。
3. 合同签署前是否经专业法律人员审查。
4. 合同签署后是否统一归档并做好保密。
5. 合同执行是否明确责任人，确保及时履约。
6. 送货单、收货凭证、委托书、结算单、质量处理协议、发票、付款清单等原件是否保存完整。
7. 违约情形下是否留存补充协议或协商备忘录。

备注：本项仅核查制度是否建立，不评价制度合法性与执行效果。

### 表6-14 借贷担保风险核查
调查项目为借贷、担保风险。

1. 借贷、担保是否履行股东会、董事会决策程序及内部规章。
与管理层沟通，查阅协议文件，了解借入、借出款项情况。OA系统使用者查阅系统记录。
2. 借贷、担保金额占净资产及总资产的比重。
分析发生损失时对生产经营及盈利的影响。

本表侧重风险防范体系建设，与后续债权债务重大合同调查存在交叉。

说明：印章管理、知识产权管理、劳动管理等其他经营风险在对应表格中体现。

### 6.3.5 资产
资产相关模板见表6-15至表6-17。

### 表6-15 不动产核查
调查项目为不动产。

1. 不动产清单，要求公司提供，必要时向主管部门核查。
2. 加盖查询章的土地信息表。
3. 不动产权证书。
4. 不动产使用权证书。
5. 不动产共有证书。
6. 其他权利证书，需调取主债权协议、抵押合同及抵押登记文件。
7. 房屋租赁、出租协议。取得租赁协议与登记文件，评估出租房屋是否可解除及解约成本，查阅强制措施文件，判断合法有效性。
8. 司法措施文件。
9. 无偿使用他人土地或房屋情况，说明原因、使用期限，判断是否属于拆迁范围或近期拆迁风险。
10. 房屋是否被拆迁。

仅限公司自有土地使用权、建筑物、工程信息，不含承包等方式取得的资料。

### 表6-16 设备与车辆核查
调查目的为产权、担保、租赁、进口合法性。

1. 设备及车辆清单。
要求公司提供，至车辆管理部门核对登记资料。设备需含名称、型号、购入时间、使用地点、原值、使用年限、累计折旧、净值、取得方式；车辆需含行驶证、牌照等，由财务提供发票、付款记录佐证。
2. 设备及车辆取得证明资料。
3. 设备或车辆设定担保的合同及登记证明。
4. 进口设备海关、商检及免税等文书，如报关资料、发票、装箱单。
5. 租赁、出租、免费出借或使用他人设备情况。
6. 是否被查封、冻结等强制措施。
7. 其他相关资料。

### 表6-17 在建工程核查
调查项目为在建工程。

1. 建设用地规划许可证。要求提供并必要时核查，区分自建取得与权属转移取得，并提供对应文件。
2. 建设工程规划许可证。注意查阅附件，梳理强制招标原因及依据，取得招标文件、中标通知书，取得抵押协议及登记，核查是否放弃或明确有限受偿权约定，确认总包方资质及是否存在转包情形。
3. 建筑施工许可证。
4. 施工单位资质文件。
5. 是否属强制招标项目。
6. 是否开展招投标。
7. 在建工程抵押情况。
8. 优先受偿权是否另有约定。
9. 是否存在总包。
10. 专项竣工验收文件。

仅限自有土地使用权、建筑物、工程信息，不含承包等方式取得资料。

### 6.3.7 业务
业务相关模板见表6-20至表6-23。

### 表6-20 主营业务核查
调查项目为主营业务。

1. 主营业务描述。
2. 主营业务是否在登记经营范围内。公司说明并提供文件。
3. 主营业务是否需要行政许可、批准、资质或授权。公司说明并提供文件。
4. 产品或服务是否发生投诉或索赔。取得相关记录与文件。

### 表6-21 主营业务核查以房地产项目为例
调查项目为主营业务。

1. 公司主营业务总体说明。
2. 项目政府批复文件，包括立项批复、环评批复、投资备案证、用地预审、规划意见书、设计方审定通知、设计批复、用地规划许可、工程规划许可等。
3. 征地拆迁相关文件，如涉及需取得征地拆迁批复、补偿协议、补偿价款支付凭证、公告及方案、拆迁许可证、总结报告。均要求公司提供，必要时向主管部门核查，未能取得需说明原因。
4. 相关部门审批：环保环评、消防设计审核及审批、交通影响评价、人防工程设计审核及施工图备案、文物保护、超限高层防震审批、节能审批、树木伐移、绿化园林审批、矿产资源核查或地质灾害评估批复等。不同项目要求差异，如污水处理特许经营以特许批文及环保要求为主；在建工程参照在建工程资产核查。
5. 项目运营资质，如房地产开发资质或暂定资质。
6. 商品房销售相关文件，如销售预售许可证、合同范本及补充协议、与银行按揭合作协议等。

### 表6-22 主要供应商核查
调查项目为主要供应商。

1. 主要供应商清单，含基本情况、合作年限、近三年交易金额。要求公司提供，与采购负责人及业务人员沟通，必要时访谈供应商。关注供应渠道是否过度集中、合作稳定性、股权变动是否导致合作中断或条件恶化、合同中是否存在因股权变动可解除条款。
2. 采购管理是否建立制度及固定模式。
