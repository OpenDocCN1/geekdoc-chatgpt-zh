## 利用人工智能整理知识导图

随着学习内容增多，知识体系变得庞杂，导图能帮助理清脉络和逻辑。结合 DeepSeek 与 Xmind，制作各式导图变得轻松，下面一起学习。

**知识小链接**

Xmind 是一款功能强大的思维导图与头脑风暴软件，可帮助创建导图。

Markdown 是一种轻量级标记语言，用于排版纯文本，阅读编写都很方便，可转为有效 HTML 文档。

### 案例：用 DeepSeek 与 Xmind 生成动物分类导图

第一步 在 DeepSeek 里输入如下指令：

我是一名小学生，我想了解动物的不同分类和典型代表，请帮我生成可以导入 Xmind 的 Markdown 格式文本。

思考后 DeepSeek 会按指令生成 Markdown 格式内容。

[PRE5]

你可以把上述 Markdown 文本导入 XMind 或其他导图工具，生成相应导图。

第二步 点击右上角的 **复制**，把生成内容拷到粘贴区。新建一个空白文件，把内容粘贴进去保存，命名为“动物.txt”。

[PRE6]

第三步 把“动物.txt”的后缀改为“.md”，即“动物.md”。

/ 提醒 / 若文件不显示后缀，可按 Win+E 打开资源管理器，在工具栏点开“查看”，在“显示/隐藏”里勾选“文件扩展名”，即可显示后缀。（具体操作详见39页）

第四步 打开 Xmind 官网 https://xmind.cn/，下载安装软件，或直接点网页上的 **在线导图** 功能在线生成。

[PRE7]

第五步 在线导图需要登录，登录成功后，点“我的导图”，再点 [PRE8] 新建一个思维导图。

[PRE9]

第六步 出现默认导图后，点击左上角的 ☰ 图标，在弹出菜单中选择“导入文件”。

[PRE10]

第七步 在导入文件界面，选中之前保存的“动物.md”并点导入。

[PRE11]

第八步 一个可编辑的美观导图就生成了，可下载、编辑或分享。

## 借助人工智能制作吸睛海报

又到学校一年一度义卖活动，你一定希望生意兴隆吧？一张美观海报能吸引不少目光。下面学习如何用 DeepSeek 配合即梦 AI 快速生成专属炫酷海报。

### 案例：用 DeepSeek 与即梦 AI 制作义卖宣传海报

**知识小链接**

即梦 AI 是抖音旗下的一站式 AI 创作平台，通过人工智能技术降低创作门槛，提供图像生成、视频创作及编辑等多样功能。

第一步 在 DeepSeek 中保持选中状态，输入以下指令：

我是 5 年级 4 班的一名学生，我们学校要组织一场爱心义卖活动，我准备的物品有 1 个汉诺塔玩具、2 个哪吒玩偶、1 本《三体》科幻小说，还有一些精美的徽章，请帮我生成一份符合即梦 AI 要求的海报中文提示词。

第二步 思考后 DeepSeek 给出了绘制海报的中文提示词。

以下是专为即梦AI设计的海报中文提示词，突出5年级4班义卖特色与童趣氛围：

【画面构图指令】

1.  主视觉：卡通风格校园场景，中央放置巨型爱心存钱罐，金币从罐口洒落成彩虹桥

2.  左侧悬浮层叠的汉诺塔玩具，金色圆环自带旋转光效，塔顶站立Q版哪吒玩偶

3.  右侧立体书造型展示《三体》封面，书本周围环绕星系徽章，每个徽章自带星云光效

4.  底部手绘课桌摆放：哪吒双人玩偶摆出功夫造型+徽章展示板（闪烁收集进度条特效）

【文字排版指令】

标题：「5.4星球爱心舰队」起航！

副标：益智汉诺塔/酷炫三体书/哪吒兄弟/星际徽章 超值兑换爱心能量

卖点气泡：

- 挑战智慧王者（汉诺塔+三体套组）

- 收集哪吒兄弟解锁隐藏剧情

- 限量星系徽章每日随机掉落

【风格参数】

色彩：科幻蓝+中国红渐变，爱心使用半透明果冻质感

字体：标题采用太空陨石斑驳字，正文使用蜡笔手写体

动态效果：徽章自动旋转展示双面图案，书籍悬浮页自动翻动

【情感化提示】

在汉诺塔底部隐藏班级秘密祝福纸条彩蛋，营造寻宝氛围需要补充具体活动时间/地点时，建议在AI生成后添加至海报右下角火箭尾焰位置，保持画面灵活修改空间。

第三步 选中提示词并复制，打开即梦 AI 网页 https://jimeng.jianying.com/，首次登录需注册。

[PRE13]

第四步 登录后，点击左侧“图片生成”，打开图片生成页面。在左上角输入框粘贴刚复制的提示词，在“比例”栏选择“9 : 16”。

[PRE14]

第五步 设置完成后，点击下方“立即生成”。若提示“当前仅支持中文或英文描述，请修改后再试”，请检查提示词，删除特殊符号、表情等，改为逗号，再次点击立即生成。

[PRE15]

第七步 精美的义卖海报完成了，可挑选一张喜欢的保存后打印。

[PRE16]

想制作其他海报，可修改给 DeepSeek 的指令。比如把**爱心义卖活动**改为**主题演讲**，再描述海报具体内容。也可根据需要改变图片精细度和尺寸。若对生成图片不满意，可调整提示词，或在生成图下方点击🔄按钮，即梦 AI 会重新生成供选择。
