三模态生成最小可用脚手架

把主流的文生图、图文生视频、文本转语音接入到本地交互脚本，只需要一个环境变量文件和几十行代码就能跑通。下面是三条独立可复用的最小实现，参数位置对齐后可以直接换模型或换服务商。

一、提示词生成图片
把一次请求封装成独立函数，入参是提示词、模型标识和尺寸，返回首个结果的网络地址。外层用无限循环收命令行输入，空内容直接跳过，遇到退出关键词就结束，其它情况调用封装函数并把拿到的链接打印出来。

二、图文驱动视频与轮询结果
先通过 dotenv 载入密钥，实例化 ZhipuAI 客户端并锁定 cogvideox。提供一个生成入口，可接受纯文本提示或配合底图链接。交互阶段先后收集文字描述和底图地址，允许二选一但不能同时为空，校验通过后提交任务。

from dotenv import load_dotenv, find_dotenv

def get_completion(model="cogvideox",

                   prompt=None,

                   image_url=None):

    response = client.videos.generations(

        model=model,

        prompt=prompt,

        image_url=image_url

    )

    return response

三、TTS 合成并落盘
同样先加载环境变量，创建 OpenAI 客户端，选用 tts-1。循环读取待转写文字，空白直接略过，收到退出指令即停止。调用 audio.speech.create，使用 alloy 音色，按当前时间戳生成文件名写入本地目录。

[PRE7]python

from dotenv import load_dotenv, find_dotenv

_ = load_dotenv(find_dotenv())

from openai import OpenAI

client = OpenAI()

model = "tts-1"
