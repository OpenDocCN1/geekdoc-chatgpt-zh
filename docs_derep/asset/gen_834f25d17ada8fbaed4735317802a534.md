回看多模态融合的技术线，能很清楚地看到从松耦合到紧耦合，再到试图做物理模拟的递进。

以 CLIP 为代表的判别式时代 Discriminative Era，某种程度上是看图说话的远古阶段。做法是双塔结构 Dual Encoder，视觉和文本各自编码，再用对比损失在向量空间里强行拉近。好处是能算相似度做检索分类，硬伤也很明显：它不会生成描述，也做不了逻辑推理。你可以让它确认这张图里有猫，却问不出猫在做什么。

生成式时代 Discriminative Era 由 LLaVA、GPT-4V 这类模型点燃，视觉对话开始爆发。核心是投影式架构。底座大模型被冻结住，通过一个轻量适配器线性层或 Q-Former 把视觉特征投到 Token Embedding 里，视觉信息就直接变成语言的一部分。于是 Agent 能基于画面做思维链推理，解读图表、梳理因果。

Sora、Nano Banana、World Labs 则指向世界模型时代 World Model Era，也就是物理模拟的未来。这里的主角是时空补全 Spatiotemporal Completion。模型不再满足于描述像素，而是去预测像素。Agent 不仅能看到桌上的杯子，还能凭物理常识推演如果一推，杯子会倒下并摔碎。这是通向通用人工智能 AGI 的关键一步：从拟合统计规律转向理解物理规律。

落到产品上，GPT-4V 代表了适配器路线的巅峰，高性能视觉编码器配上强语言基座。Google 的 Gemini 则打开了原生多模态的新纪元。它不是两个模型拼起来的，而是从预训练开始就喂入图像、文本、视频、音频的交错序列 interleaved sequence，没有显式的视觉编码器和对齐层，视觉信号直接参与推理的梯度下降。模态转换的损耗被抹掉后，细粒度的时间与空间关系也能被捕捉，比如电影里两个镜头的因果联系。

空间智能的标志性突破是 Tesla FSD V12。它用端到端自动驾驶把超过 30 万行 C++ 规划控制规则代码全部撤掉，换成一个统一神经网络，实现从光子输入到控制指令输出的直接映射。系统通过 BEV 鸟瞰图向量空间精确感知环境，更深层的意义在于海量数据训练后学会了类人驾驶直觉，流畅、拟人、能应对复杂场景。强有力地证明在足够数据下，神经网络可以隐式学习物理世界的拓扑结构和运动规律，大幅降低对手工特征工程的依赖。

### 4.2.4 多模态融合模式的演化与组合

多模态融合已从早期的独立编码后拼接，发展为基于适配器的深度跨模态交互，最终走向全模态原生的统一表征。今天的设计者不再把视觉当成语言的外挂，而是当作 Agent 与生俱来的原生感官。

#### 1. 演化路径：从拼接适配到原生统一

后期拼接 Late Fusion。做法是用 YOLO、BLIP 这类视觉模型当独立工具，由 LLM 发出文本指令调用，再把模型返回的文本描述拿回来用。核心痛点是信息损耗，光影变化、纹理特征、空间关系等大量视觉细节在转成文本的路上丢失，语义就不完整，理解深度和精度受限。

适配器对齐 Alignment Adapter。LLM 和视觉 Transformer ViT 保持冻结，只训练一个轻量投影层 Projector，把视觉特征映射到文本嵌入空间。于是出现视觉即语言的效果，Agent 能直接看懂图像，无需中间文本。目前这是开源社区的主流做法。

原生统一 Native Unified。以 GPT-4o 和 Gemini 1.5 Pro 2024 年 2025 年为代表，从预训练阶段就把 Token 拓展成多模态单元，包含文本、图像块、音频波形。模型天生多模态，不需要后期适配。结果是零延迟的多模态交互，视觉、音频、文本在网络内部无缝融合、自由流动，Agent 能对语调起伏、微表情、环境音效等细微变化做即时感知与响应。

#### 2. 模式组合示例

多模态融合模式常作为 Agent 的感官前台和中台，为下游记忆模块和行动模块提供高带宽、高语义密度的输入。

多模态融合模式与情节记忆模式见 5.3 节的组合 = 视觉日记。组合后 Agent 拥有一种似曾相识的视觉直觉，能靠视觉类比识别情境、迁移经验、学习新技能，适合具身智能或个人助理这类需要长期环境感知和个性化交互的场景。机制是任务执行时既记文本日志，又用多模态融合模块保存关键时刻的视觉快照 Visual Snapshot；下次遇到相似场景，从情节记忆库里检索视觉最相似的过往经历，触发类比推理或策略复用。

多模态融合模式与 ReAct 模式见 7.1 节的组合 = 手眼协调。这是走向 VLA Vision-Language-Action 模型的关键路径，实现从多模态感知到具体行动的端到端映射。适用于 GUI 操作、机械臂控制等需要实时理解画面并精准执行动作的任务。机制上，Observation 不再是纯文本，而是屏幕截图或摄像头实时画面；解析定位阶段，Agent 用多模态融合解析画面，定位 UI 元素坐标或物理环境中物体的空间位置；行动反馈阶段，在 ReAct 循环里基于视觉反馈生成精准操作指令，如鼠标点击、拖曳或机械臂运动控制，形成感知与行动的闭环。

多模态融合的演进，标志着 Agent 正从符号计算迈向物理感知。当它能原生理解光影、声音等真实世界信号时，就不再是数字世界的幽灵，而是拥有真实在场感的智能实体。

### 4.2.5 设计哲学：从“看”到“在”

多模态融合的终点，不是让 AI 认出图里有一只猫，而是建立在场感 Presence。

当一个 Agent 同时具备视觉、听觉和空间感，它就不再是处理文本的聊天机器人，而是一个存在于物理世界的实体。它会理解这里、那里、重、远这些物理概念，并具备物理常识推理能力，比如预判物体是否会掉落、门能不能被推开。

这不只是感知的升级，更是心智的具身化。AI 从符号的计算者进化为世界的观察者和参与者。

## 4.3 主动感知模式

> “系统会努力最小化其自由能函数，不断根据外界环境输入的新信息，调整内部对外部环境的信念。”

——卡尔·弗里斯顿 Karl Friston

传统认知框架默认人类给的输入真实且完整。模型不会质疑 Prompt 的来源、可靠性和偏差，而是尽力在已有内容上补齐推理链。一旦信息缺页，在必须给出答案的压力下就会产生幻觉。

因此在 RAG 或简单模型调用里，经常潜藏一个危险假设：上下文窗口里已经有了回答所需的一切。

主动感知模式打破了这个假设。它把 Agent 从被动的答题者转为主动的调查员。当现有信息不足以支撑可信结论时，系统会暂停生成，转而执行操作去获取新证据。

从架构看，这是从输入即输出的静态模式，转向感知-行动持续迭代的动态闭环。

### 4.3.1 模式架构：信息觅食环

工程上主动感知不能变成死循环，需要一个具备元认知能力的控制流。图 4-8 展示了实现流程，包含 4 个关键组件。

不确定性探针 Uncertainty Probe。是系统的刹车片，不负责生成，只负责判断能不能回答。可基于 Logprobs 的 Token 生成概率统计判断，也可用轻量分类模型，或一次专门的 Self-Reflection Prompt 调用。

查询生成器 Query Generator。把模糊的知识缺口转成具体的工具指令。例如把分析这家公司的财务风险拆解为 search_engine("2023 财报") 和 code_interpreter("计算流动比率")。

信息过滤器 Information Filter。主动找回的信息噪声很多，必须有过滤层，只把校验通过的事实写入短期记忆，避免污染上下文。

预算控制器 Budget Controller。工业级系统最容易忽略的部分。为防止 Agent 陷入搜索-失败-再搜索的循环，必须设最大跳数或 Token 消耗上限。

### 4.3.2 主动感知核心机制

实现的核心是解决两个问题：何时停，停止感知开始回答；去哪儿找，路径规划。

1. 基于元认知的触发机制

不能对所有请求都开启主动感知，成本不可接受，系统需要识别认识论不确定性。

当用户查询包含查询、分析等动词时，显式触发自动感知。
若模型在尝试回答时发现关键实体缺失，隐式触发自动感知。此时可在 System Prompt 中加入指令：如果你不知道答案，请输出 [SEARCH_NEEDED: 具体问题]，而不是编造。

2. 渐进式信息觅食

类似人在图书馆找书，Agent 的感知路径通常遵循：

后退一步 Step-back Questioning。如果问题太具体查不到，比如××公司 2023 年 Q3 的服务器折旧费，Agent 会主动生成更宽泛的查询，比如××公司 2023 年 Q3 财报，先拿到大文档。

深挖一步 Drill-down Reading。拿到大文档后不再搜索，而是通过机器阅读理解 Machine Reading Comprehension, MRC 精确定位数值。

实践中架构师需要警惕以下工程黑洞。

上下文污染 Context Pollution。Agent 搜到一篇错误博客并当成事实，导致回答出错。对策是在写入上下文前做交叉验证。对股价、医疗建议等关键事实，强制要求至少两个独立信源一致。

注意力发散 Distraction。搜索过程中被无关信息带跑题。对策始终把用户原始问题钉在 Prompt 最下方，提醒 Agent 勿忘初心。

非必要的昂贵调用。用户问简单问题，Agent 却去调用 Google Search。对策是引入极低成本的 Router 模型，如 Qwen 开源小模型或规则引擎，作为前置网关拦截闲聊和通用常识问题。

### 4.3.3 主动感知工程实践

工程实践已分化出三类标杆产品。

Perplexity.ai 定义了搜索即生成的范式。它不是把 Top 10 链接丢给用户，而是走理解意图、多步并行搜索、阅读理解与去重、合成带引用的答案的全流程。证明主动感知可以做到毫秒级实时响应，并大幅降低幻觉率。

OpenAI 的 Deep Research 展示了另一极端，用时间换质量。面对写一份 50 页行业分析报告的任务，Agent 可能花费 30 分钟，自主执行数百次搜索、阅读上千篇文档。它展示了 System 2 慢思考在主动感知中的潜力：不急于回答，而是走规划-执行-修正的流程。

Voyager Minecraft Agent 在虚拟世界展示了主动感知的最高级形式——好奇心 Curiosity。它没有人类指令，却会因为我还没见过钻石而主动设计课程 Curriculum 去地下挖掘。这种由内在动机 Intrinsic Motivation 驱动的感知，是通向 AGI 的重要路标。

从架构演进看，我们正经历从被动检索到认知型探索的第三次跃迁。

被动检索代表架构为 RAG，逻辑是 Retrieve Query → Answer。用户问什么，系统查什么。查不到就两手一摊或干脆瞎编，没有再试一次的能力，极度依赖检索系统的召回质量。
