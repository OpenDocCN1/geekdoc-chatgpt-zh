插件模块通过 API 接口把外部平台和服务接入进来，为智能体拓展额外能力。扣子自带大量常用插件可直接使用，同时也允许用户自行制作自定义插件，把需要的接口封装成工具在平台内调用，比如用新闻类插件检索资讯，用搜索类工具获取网络资料。

工作流模块负责规划和落地复杂逻辑。用户可以拖拽不同的任务节点拼装流程，让智能体处理多步骤任务时更高效。

触发器模块让智能体在特定时间点或满足特定条件时自动跑任务。

知识模块用来给智能体补充本地或线上数据源，提升大模型回答的可用性和准确度。
· 文本类知识支持基于内容片段进行检索召回，大模型在召回结果基础上生成最终回复，适合知识问答场景。
· 表格类知识支持按行划分的索引列匹配，也兼容 NL2SQL 查询与计算。
· 图片类知识支持 JPG 等常见格式，可借助图片标注实现检索与召回。

记忆模块解决模型对话轮次受限的问题，提供可反复调用的长期记忆，使回复更具个性。
· 变量可用来保存语言偏好等用户信息，实现个性化输出。
· 数据库以简洁高效的方式管理结构化数据，支持用自然语言进行数据写入与查询，还能开启多用户模式做更灵活的读写管控。
· 长期记忆模仿人脑对用户个性化信息的积累，基于这些记忆给出更贴合的回复，提升体验。
· 文件盒子为多模态数据的合规存储、管理与交互提供载体，智能体可反复调用已保存的多模态素材。

语音对话模块在文字交互之外提供语音通道，扣子提供多款音色供选择。

对已上线的智能体，开发者可通过分析看板跟踪运行状态。数据分析涵盖基础用户量、用户意图访问情况、消息记录使用情况等，帮助定向优化以更好地满足需求。

### 5.1.3　使用扣子搭建智能体工作流
工作流是可执行指令的集合，用于实现业务逻辑或完成特定任务。它为应用/智能体的数流和任务处理提供结构化框架。核心是把大模型的强能力与具体业务逻辑结合，通过流程化手段实现高效 AI 应用。

扣子提供可视化画布，支持拖拽节点快速搭建，并可在画布内实时调试，直观看到数据流转与执行顺序。

#### 1．工作流与对话流
扣子提供两种工作流形态。
（1）工作流 workflow：处理功能型请求，通过顺序执行多个任务实现某项功能。适合数据自动化处理场景，如生成行业调研报告、制作海报、绘制绘本等。
（2）对话流 chatflow：面向对话场景的特殊工作流，适合处理对话类请求。通过对话交互实现复杂业务逻辑，常用于聊天机器人、个人助手、智能客服、虚拟伴侣等。

#### 2．节点
节点是工作流的基本单元，每个节点代表一个独立步骤或逻辑，负责数据处理、任务执行与算法运行，均具备输入输出。

每个工作流默认包含开始节点和结束节点。开始节点定义启动所需的输入参数，结束节点返回运行结果。通过引用节点输出可将节点串联成操作链，例如让代码节点使用大模型节点的输出，在画布上即可看到两节点相连，如图 5-5 所示。

### 5.1.4　使用扣子开发 AI 应用
AI 应用是基于大模型技术构建的应用，能执行复杂任务、分析数据并做决策，如 AI 搜索、AI 翻译等。

#### 1．用扣子开发的 AI 应用能做什么
基于扣子开发的应用可扩展性强，可绑定个性化界面，依托大模型形成独立解决方案。通过工作流或对话流实现复杂业务逻辑，内置节点库覆盖逻辑处理、知识写入检索、大模型服务、会话管理等，帮助灵活编排自动化流程。

应用可适配移动端与网页端多种框架，也能兼容各类终端。支持以 API 服务或 Chat SDK 形式集成到现有产品网站，也可发布为微信小程序、抖音小程序，或投放到社交平台，甚至部署为 Web 页面供更广泛用户访问。

#### 2．开发流程
（1）创建 AI 应用项目。在扣子新建项目，创建完成后自动进入“扣子应用 IDE”，用于业务编排与配置。
（2）编排业务逻辑。可用工作流编排流程，并通过变量、插件、知识库、数据库等与本地或线上数据交互，平台提供试运行功能便于调试。
（3）设计用户界面。提供丰富组件与可视化编排界面，支持拖拽快速搭建，所见即所得。组件可与资源数据和事件绑定，实现前后端联动，非专业开发者也能上手。
（4）测试应用。提供预览功能，实时验证运行效果是否符合预期。
（5）发布应用。开发测试完成后可发布到各平台，扩大用户覆盖。

#### 3．开发环境
扣子提供线上集成开发环境“扣子应用 IDE”，支持可视化编排与调试，让开发者聚焦创意与业务实现。
