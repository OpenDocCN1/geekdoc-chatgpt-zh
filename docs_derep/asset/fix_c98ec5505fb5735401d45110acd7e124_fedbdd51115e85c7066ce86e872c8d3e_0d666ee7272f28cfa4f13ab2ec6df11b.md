（10）常见问题排查
- 脚本找不到文件：检查路径是否正确，执行前可用 `exec:ls -la data/` 确认文件存在。
- pandas 模块缺失：确保 Python 环境已安装 pandas 和 openpyxl，可通过 `exec:python -c "import pandas"` 测试。
- 邮件发送失败：检查 SMTP 账号、密码或授权码是否正确，并确认邮箱已开启 SMTP 服务；可在脚本中增加异常捕获以处理认证失败或连接被拒。
- 定时任务未触发：检查时区与时间设置，可用 `openclaw cron list` 查看任务状态。
- exec 工具被禁用：检查配置中的 `tools.deny` 或 `tools.allow`，确保 exec 未被禁用。
- 端口占用：确认 Gateway 服务端口未被占用，可用 `openclaw gateway status` 检查。

### 4.3.1 OpenClaw 中的 Skills 回顾
OpenClaw 是一个高度可扩展的机器人智能体框架，其核心设计理念之一是“技能即插件”。Skills 以独立模块的形式存在，每个 Skill 封装一项特定技能，如控制机械臂、识别图像、调用 API 等。用户可根据任务需求，灵活组合多个 Skills，构建复杂的自主行为链。

#### 1. 核心 Skills 分类
根据功能层级，Skills 可分为以下两类：

（1）基础操作 Skills。
- 移动控制：实现导航、避障、路径规划等底层运动技能；
- 机械臂控制：支持抓取、放置、旋转等精细操作；
- 传感器数据处理：融合摄像头、激光雷达、IMU 等多源感知信息。

（2）高级技能 Skills。
- 计算机视觉：提供物体识别、人脸识别、场景理解等技能；
- 自然语言处理：涵盖语音识别、语义解析、对话管理等；
- 任务规划：将高层目标分解为可执行的子任务序列。

> 提示：
Skills 的复用性与组合性是 OpenClaw 具备强大生产力的关键。
