# 从口语指令到可测故障的交通控制双件套

整体拆成两条主线来看：一条把日常口述转成设备可执行的统一指令，另一条用可配置的异常注入检验多智能体在不稳定环境下的表现。

先看指令翻译这块。终端类别被收敛成四种枚举值：信号灯、摄像机、感应器、显示屏。指令结构用 dataclass 描述，一条记录保存设备标识、所属类别、期望动作、参数集合、优先级等级以及超时时长。翻译器实例化时接受大模型客户端和设备注册表，同时载入指令模板。实际调用走异步流程：先让模型基于原始表述和上下文拆解出目标对象、操作意图、参数细节和优先级，再把抽象目标定位到注册表里的实体设备，最后依据模板为每台设备填充完整指令并汇总返回。解析用的提示明确指定以 JSON 形式返回四项：targets、action、parameters、priority。
