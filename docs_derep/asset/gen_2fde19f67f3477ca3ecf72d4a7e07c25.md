# TensorFlow 实战：布尔张量、类型转换与 NumPy 互通全解析

在 TensorFlow 开发中，逻辑判断是绕不开的基本功。比如训练分类模型时，评估准确率离不开将模型输出与真实标签逐元素比对，这正是布尔张量大显身手的场景。

## 一、 布尔张量：批量逻辑运算的利器

TensorFlow 原生支持 `bool` 类型张量，直接传入 Python 的 `True/False` 即可自动完成转换。

**核心优势在于“批量化”处理**。假设手头有预测值张量 `vec_actual` 和标签张量 `vec_pre`，计算准确率的流程极其丝滑：
1.  用 `==` 触发逐元素比较，生成同形状的布尔张量（`True` 为命中，`False` 为偏差）。
2.  **关键一步**：TensorFlow 与 NumPy 不同，**布尔张量不能直接求和**。必须借助 `tf.cast()` 将其转为 `float32`，此时 `True→1.0`，`False→0.0`。
3.  对转换后的张量调用 `tf.math.reduce_mean` 求均值，结果即为准确率。

> **实战案例**：序列 `[True, False, False, True, True]` 转为 `[1.0, 0.0, 0.0, 1.0, 1.0]`，均值 0.6 精准对应 3/5 的命中率。

这种 **“张量进，张量出”** 的整体运算思维，正是摆脱 `for` 循环、发挥硬件并行加速的关键。

## 二、 tf.cast()：数据类型的“万能铸造厂”

`tf.cast(x, dtype, name)` 是类型转换的核心 API。其原型参数简洁明了：`x` 为源张量，`dtype` 为目标类型。

### 1. 数值精度的升降级
- **低精→高精（安全）**：如 `float16 → float64`，类比“小房间搬进大房间”，数据零损耗。
- **高精→低精（有损）**：`float64 → float16` 如“大房间挤进小房间”，尾数截断或溢出在所难免。

### 2. 布尔与数值的双向通道
遵循 Python/C/C++ “非零即真”传统：
- **Bool → 数值**：`True` 映射 `1/1.0`，`False` 映射 `0/0.0`。
- **数值 → Bool**：**仅 0 为 `False`**，其余任意正负数均判定为 `True`。

## 三、 TensorFlow 与 NumPy：深度绑定的“表里关系”

TensorFlow 底层深度依赖 NumPy 的数值计算体系，二者数据类型体系**完全对齐**。

### 1. NumPy → TensorFlow：零门槛接入
任何合法 NumPy 数组（0D 标量、1D 向量、2D 矩阵……）均可直接作为 `tf.Variable` 或 `tf.constant` 的数据源。
- **TF 2.x 体验升级**：无需 `Session.run()`，`print(tensor)` 即可直观查看，甚至用 `tf.print()` 仅输出纯数值。

### 2. TensorFlow → NumPy：一键导出
每个张量对象自带 `.numpy()` 方法，瞬间转回 NumPy 数组，无缝衔接 Python 科学计算生态。

### 3. 通用转换入口：`tf.convert_to_tensor`
面对 Python 原生 `list`、`tuple` 等非 NumPy 容器，该方法可统一“收编”为标准张量。
- **典型数据流**：`List/Tuple →(convert_to_tensor)→ Tensor →(计算)→ Tensor →(numpy())→ NumPy Array → 业务逻辑`
