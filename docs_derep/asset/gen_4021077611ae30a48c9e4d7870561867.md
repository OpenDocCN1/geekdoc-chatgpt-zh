# 对象检测 API 与 JNI 封装实现概览

这套实现把底层模型推理和 Java 调用层做了清晰的分离。先看最核心的单目标与多目标检测入口。

ApiDetect 负责一次只取一个结果的场景。进入函数时先把错误码置为成功，随后从 DetectorPool 里按句柄取到实际的 MlDetector。如果池子里找不到对应资源，直接把错误改成句柄未找到并返回 0。找到之后调用 MlDetectObjects，传入图像指针、宽高、步长 width * 3、通道相关参数 24、置信阈值 0.7f、最大返回数 1 等固定参数。推理有结果时再把内部的 MlLandmarkResult 转成对外统一的 ObjectLandMarks 结构，最后把检测到的对象个数原样返回。

ApiDetectMany 的思路一致，只是为了批量输出。同样先校验句柄有效性，接着按 maxCount 申请一个 MlLandmarkResult 数组，一次性向 MlDetectObjects 请求最多 maxCount 个结果。返回后对每个索引位置执行一次转换，把内部结果填入 detectionResult 指针数组，再交回实际检测到的数量。

JNI 层把上面的 C 接口暴露给 Android Java。初始化时把模型路径转成 std::string 调用 ApiCreateDetector，并把拿到的句柄写入 Java 对象的 handle 字段。销毁、设置参数、单张检测、批量检测等方法都遵循同一套模板：先从 Java 对象读出句柄，必要时把 jbyteArray 映射为 unsigned char*，调用对应的 ApiDetect / ApiDetectMany，释放字节数组后根据返回数量构造 Java 对象或对象数组返回。

 58 JNIEXPORT jobject JNICALL CLASS_METHOD(detectObject)(JNIEnv* env, jobject object, jbyteArray jImageBytes, jint imageWidth, jint imageHeight) {
 59     ApiHandle detectorHandle;
 60     GetObjIntField(env, object, "handle", &detectorHandle);

 61     unsigned char * imageData = (unsigned char *)env->GetByteArrayElements (jImageBytes, 0);

 62

 63     ObjectLandMarks result;
 64     ApiError error;
 65     int objectCount = ApiDetect(detectorHandle, imageData, imageWidth, imageHeight, &result, &error);

 66     env->ReleaseByteArrayElements(jImageBytes, (jbyte*)imageData, 0);

 67

 68     if (objectCount) {
 69         return CreateJObjectDetectResult(env, result);
 70     }
 71     else {
 72         return nullptr;
 73     }
 74 }

 83     ApiHandle detectorHandle;

 87     ObjectLandMarks* results = new ObjectLandMarks[maxCount];
 88     ApiError error;
 89     int objectCount = ApiDetectMany(detectorHandle, imageData, imageWidth, imageHeight, results, maxCount, &error);

 90     env->ReleaseByteArrayElements(jImageBytes, (jbyte*)imageData, 0);

 91

 92     jobjectArray jObjectDetectResults = CreateObjArray(env, "com/am/api/ObjectDetectResult", objectCount);
 93     for (int objectIndex = 0; objectIndex != objectCount; ++objectIndex) {
 94         jobject jObjectDetectResult = CreateJObjectDetectResult(env, results[objectIndex]);
 95         env->SetObjectArrayElement(jObjectDetectResults, objectIndex, jObject DetectResult);
 96     }

 97     return jObjectDetectResults;
