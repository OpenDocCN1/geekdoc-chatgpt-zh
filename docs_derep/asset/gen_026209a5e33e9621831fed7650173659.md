LangChain：知识图谱全链路的加速器

知识图谱的搭建过去常被繁琐的数据清洗和模型训练拖住脚步。LangChain把这一套流程拆成了可复用、可组合的工具，让抽取、融合、存储到应用都能用更轻的方式完成。

灵活的知识抽取
借助 Prompt 模板配合大模型，可以按需设计任意复杂的抽取逻辑，不再受限于人名、地名这类固定标签。GPT 等模型凭借强大的语言理解与常识补全，能够从文本里挖掘出更精准、更完整的结构化信息。

多源融合与推理
在 LLM 与 Agent 的配合下，可以对来自不同来源的知识进行对齐、链接和纠错，沉淀出高一致性的知识库。在此基础上还能做逻辑推演，把隐含的关联显式化。

向量化存储
LangChain 可接入 Redis、Pinecone、Chroma 等主流向量库，把原始文本和对应的语义向量一起保存，检索与语义匹配的速度和质量都大幅提升。

端到端应用链
Retriever、ChatVectorDBChain、RetrievalQAChain 等开箱即用的 Chain，让基于知识图谱的智能对话、问答、推荐等场景可以直接组装上线。

与前沿大模型的深度联动
从抽取到推理，大部分环节都依赖语言理解和生成能力。LangChain 原生对接 GPT-3、LLaMA 等主流模型，能把前沿 LLM 的能力完整带入知识图谱构建，打造更聪明的图谱应用。

总体来看，LangChain 为知识图谱提供了从数据到落地的完整工具链，尤其是 Prompt 机制，让知识抽取与推理这类复杂任务变得简洁可控。开发者可以把精力放回业务逻辑，而不是耗在底层的数据处理和模型调参上。

#### 7.2.3 知识图谱构建的核心步骤和组件

把 LangChain 助力下的图谱构建拆开，大致可分为数据准备、知识抽取、知识融合、本体构建、知识存储、知识应用六个环节，如图7-2所示。

（1）数据准备。
- DocumentLoader：内置 CSVLoader、JSONLoader 等多种加载器，能方便地从不同格式源里读入原始资料。例如用 JSONLoader 载入 .json 文件。
- TextSplitter：处理长文本时可用 CharacterTextSplitter 等切分器，把文档切成便于管理的片段。例如将长文按句子拆分。
- Embeddings：通过 HuggingFaceEmbeddings 等把文本转成语义向量，加速后续语义分析。例如把一段描述映射为向量以便处理。

图7-2 知识图谱构建的核心步骤

（2）知识抽取。
- Prompt：可自定义提示模板，明确要求模型从文本中抓取关键信息。例如设计一个 Prompt 要求抽取地名和人名。
- LLM：调用 OpenAI 等语言模型执行 Prompt，完成结构化抽取。例如用 GPT 模型抽取事件描述。
- Chain：将 Prompt 与 LLM 串联形成可复用的抽取链。例如用 SequentialChain 依次完成多步抽取任务。

（3）知识融合。
- Agent：通过子任务拆分与调用编排，实现复杂的融合逻辑。例如让 Agent 判断文本间的相似度。
- Vector Store：存储文本及其向量，加速相似内容的检索。例如用 Pinecone 保存文本向量以便快速查找。
- Chain：组合不同组件实现融合的子目标。例如搭建一个专门做文本摘要的 Chain。

（4）本体构建。
- Prompt：定义专门的提示，引导模型抽取本体相关要素。例如让 Prompt 提取某领域的核心概念。
- LLM：调用大模型生成本体的细节信息。例如用语言模型为概念补充属性定义。
- Agent：把概念提取、属性定义等多步子任务整合起来，形成完整的本体构建流程。

（5）知识存储。
- Graph Database：用图数据库保存三元组，构建图谱。例如用 Neo4j 存储实体间关系。
- Vector Store：保存语义向量，支持语义检索与相似度计算。例如在 Redis 中存放实体的向量表示。
- LangChain Integration：为图数据库提供连接与操作能力。例如通过 WeaviateVectorStore 实现语义搜索。

（6）知识应用。
- Chain：依据场景组合 LLM 与图数据库，形成应用链。例如用 ChatVectorDBChain 实现智能对话。
- Agent：编排多个 Chain 构建复杂代理。例如用 RetrievalQA Agent 整合问答与检索。
- Memory：让 Chain 具备多轮对话能力，维持上下文。例如用 ConversationBufferMemory 保持对话连贯性。

LangChain 的组件覆盖了从数据到应用的完整链路，尤其 Prompt、Chain、Agent 这套组合拳，为定制化需求提供了灵活且强大的实现手段。

### 7.3 知识抽取和实体识别

知识抽取是图谱构建的起点，目标是从非结构化或半结构化数据里提炼出实体、关系、属性等结构化要素。实体识别是其中关键一环，即从文本中定位实体并标注类别。LangChain 既可调用现成的 NER 工具如 spacy、Stanza，也能基于 Prompt 与 LLM 自定义抽取方式。

#### 7.3.3 基于规则和few-shot的知识抽取

通用 NER 与 RE 工具适合常见模式，但业务图谱往往需要定制化抽取，如医疗领域的疾病、药品、副作用，电商领域的商品、品牌、优惠等。

一种做法是用领域规则总结抽取模式，通过 Prompt 引导 LLM 按规则提取；另一种做法是提供少量样例，让模型以 few-shot 方式学习并泛化。LangChain 在 Prompt 工程与 few-shot 上都有成熟支持。
