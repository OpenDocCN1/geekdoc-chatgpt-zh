BERT微调实战：用分层解冻做到省算力又高效

想让大模型快速适配新任务，又不被计算成本拖垮？关键在于怎么“聪明地解冻”。下面把常用的分层解冻思路拆成可直接上手的操作。

选择性解冻顶层参数
要让模型聚焦新任务的语义细节，可以只放开最后几层来学习。具体做法是用 model.bert.encoder.layer[-2:] 把倒数两层挑出来更新，其余保持静止，这样高层就能针对特定任务调整表征。

优化器只喂可训练参数
选用 AdamW 只对 requires_grad=True 的权重生效。通过 filter 筛选出解冻的部分供给优化器，能大幅减少显存和算力开销。

简易训练循环
整体流程就是前向算损失、反向传播、一步更新，循环迭代解冻层级的参数即可。

只放开最顶一层做极简微调
在部分任务里，把底层全部冻结、只释放顶层就能获得不错的效果。下面是一段只解冻最后一层的示例。

import torch

from transformers import BertTokenizer, BertForSequenceClassification, AdamW

# 加载预训练的BERT模型和分词器

tokenizer=BertTokenizer.from_pretrained("bert-base-uncased")

model=BertForSequenceClassification.from_pretrained("bert-base-uncased")

# 示例数据

sentences=["I loved the food at this place.", "The service was poor."]

labels=[1, 0]  # 1表示正面，0表示负面

# 预处理数据

inputs=tokenizer(sentences, return_tensors="pt",

                 padding=True, truncation=True)

# 冻结所有层的参数

for param in model.bert.parameters():

    param.requires_grad=False

# 解冻最后一层

for param in model.bert.encoder.layer[-1].parameters():

    param.requires_grad=True

# 定义优化器，仅更新解冻层的参数

optimizer=AdamW(filter(lambda p: p.requires_grad,

                       model.parameters()), lr=2e-5)

# 训练过程

model.train()

for epoch in range(2):  # 假设训练2个周期

    outputs=model(**inputs, labels=torch.tensor(labels))

    loss=outputs.loss

    loss.backward()

    optimizer.step()

    optimizer.zero_grad()

    print(f"Epoch {epoch+1}-Loss: {loss.item()}")

要点回顾：
1. 仅激活顶层：先把整网冻结，再把 model.bert.encoder.layer[-1] 放开，使微调集中在高层语义。
2. 优化器聚焦：只对解冻权重复训，既省资源又让模型跟新任务靠拢。
3. 训练闭环：每轮计算损失并回传，参数迭代更新。

逐层解冻：从上往下逐步放开
当数据量较大或领域差异明显时，可以采用逐层解冻。先只训顶层，稳定后再逐个释放下层，避免过早过拟合。下方代码演示了每轮放开一层的流程。

import torch

from transformers import BertTokenizer, BertForSequenceClassification, AdamW

# 加载预训练的BERT模型和分词器

tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")

model = BertForSequenceClassification.from_pretrained("bert-base-uncased")

# 示例数据

sentences = ["I love learning about AI.", "Deep learning is fascinating."]

labels = torch.tensor([1, 0])  # 1表示正面，0表示负面

# 预处理数据

inputs = tokenizer(sentences, return_tensors="pt",

                   padding=True, truncation=True)

# 冻结所有层的参数

for param in model.bert.parameters():

    param.requires_grad = False

# 定义优化器，仅更新解冻层的参数

optimizer = AdamW(filter(lambda p: p.requires_grad,

                         model.parameters()), lr=2e-5)

# 逐层解冻的训练过程

model.train()

for epoch in range(3):  # 假设逐层解冻3个周期

    # 每个周期解冻一个新的层

    if epoch < len(model.bert.encoder.layer):

        for param in model.bert.encoder.layer[-(epoch + 1)].parameters():

            param.requires_grad = True

    # 定义损失计算和优化步骤

    outputs = model(**inputs, labels=labels)

    loss = outputs.loss

    loss.backward()

    optimizer.step()

    optimizer.zero_grad()

    # 输出每个周期的损失值

    print(f"Epoch {epoch + 1}-Loss: {loss.item()}")

# 显示当前解冻层

print(f"Unfrozen Layer: -(epoch+1)")

要点解读：
1. 逐层释放：每轮通过 model.bert.encoder.layer[-(epoch+1)] 解冻一层更底的网络。
2. 优化范围递增：每轮只优化当前及之前已放开的层。
3. 过程可视化：输出损失与当前解冻层，便于观察效果演进。

### 11.1.2 微调中的参数不对称更新
参数不对称更新的核心思想是只动一部分权重，让模型在保持通用能力的同时适应新任务，进而压缩训练时间和内存。这种做法通常把底层的通用表征锁住，只让顶层可学习，特别适合预训练任务与下游任务相近的场景。冻结底层保留了已学到的通用特征，更新顶层则注入任务特异性，在精度与成本之间取得平衡。

- （2）定义优化器：优化器只更新不冻结的层，保证计算的效率。

## 11.2 使用领域数据微调BERT模型
通用 BERT 在金融、医疗、法律等专业领域直接使用时，往往对术语和句式理解不足。领域微调就是用行业数据对模型再训练，让它掌握专业表达和知识。关键在于高质量的领域数据准备、标签分布的处理以及超参的合理设置，这样才能提升领域内的准确率和稳定性。

### 11.2.1 金融与医学领域数据的预处理与标签平衡
专业文本富含术语和特殊结构，通用模型容易误判。因此需要在进入微调前对数据做针对性清洗，去除噪音、统一术语表达，保证输入一致性。同时不同类别样本往往不均衡，借助重采样等手段实现标签平衡，可以避免模型偏向多数类。为 BERT 的领域微调提供干净均衡的数据，是后续精调效果的基础。
