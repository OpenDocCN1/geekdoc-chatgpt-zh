先把问题拆开。无理数的定义是不能写成两个整数的商，也就是不存在 a/b 这样的分数表示。假设相反的情况成立，先试试看会发生什么。

设 √2 可以写成最简分数 a/b，a 和 b 互质。两边平方后得到 a² = 2 b²。右边显然是偶数，所以 a² 也是偶数。平方值偶数意味着底数本身偶数，于是可以写成 a = 2k。

把 a = 2k 代回去，2 b² = 4 k²，化简为 b² = 2 k²。这说明 b² 同样是偶数，进而 b 也必须是偶数。

于是 a 和 b 同时被 2 整除，和最开始 a、b 互质的设定直接冲突。矛盾只能来自初始的假设，所以 √2 不可能是有理数。

从推导的角度看，假设成立时会产生一对更小的正整数解，过程可以不断向下延伸，形成在正整数里不可能存在的无限递减链，这正是无限下降的思路在起作用。把关键步骤再整理一遍就更清晰：

1. 预设 √2 = a/b 且 a、b 互质。
2. 平方得 2b² = a²。
3. 由 a² 偶数推出 a = 2k。
4. 代入后得到 b² = 2k²，可推出 b 偶数。
5. a、b 同时含因子 2，与互质矛盾。
6. 故 √2 为无理数。

整体推理是自洽的，没有其他分支可以绕开这个矛盾。

首先，假设√2是有理数，也就是说它可以表示为两个互质的整数a和b的比值，即√2 = a/b，其中a和b的最大公约数是1。

将这个式子两边平方，得到：

\[ 2 = \frac{a^2}{b^2} \]

两边同时乘以b²，得到：

\[ 2b^2 = a^2 \]

这说明a²是偶数，因此a必须是偶数。设a = 2k，其中k是一个整数。

将a = 2k代入上式，得到：

\[ 2b^2 = (2k)^2 = 4k^2 \]

两边同时除以2，得到：

\[ b^2 = 2k^2 \]

这说明b²是偶数，因此b也是偶数。
