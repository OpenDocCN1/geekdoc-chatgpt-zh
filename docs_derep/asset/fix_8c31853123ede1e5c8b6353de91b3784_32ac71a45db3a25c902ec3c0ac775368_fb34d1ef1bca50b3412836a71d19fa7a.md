代码 9-17 总结了四类能够显著提升模型调用效率的实用做法，具体如下。

- 1）结果复用与缓存校验：将高频查询的返回结果写入 Redis，后续相同请求可直接命中缓存。
- 2）输入精简：先借助轻量模型对超长提问进行摘要压缩，再交由主模型处理。
- 3）请求合并：把多个待处理的查询累积起来统一调用，降低接口调用频次。
- 4）按需唤起：依据任务优先级动态决定调用时机，避免无谓触发。

把上述手段组合使用，能明显减少调用次数、控制 token 占用并加快响应。
