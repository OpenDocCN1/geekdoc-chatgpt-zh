把一次从加速训练、Prefix-Tuning 微调、Top-p 采样生成到部署量化的完整链路整理成可复用的笔记，重点保留可运行的关键参数和流程。

训练采用 Accelerate 统一处理设备分配，把模型、优化器、数据迭代器和学习率调度器一次性交给框架管理。外层跑 20 轮，每轮用 tqdm 包装训练集。进入一个批次后把输入和标签搬到显存，前向得到损失值，再由 Accelerate 完成反向传播。随后依次执行优化器步进、学习率调度步进、梯度清零。进度条实时展示当前轮次、训练损失以及换算成千倍的学习率，梯度裁剪保留了注释。每当轮次是 3 的倍数，就把当前权重写入 ./glm6b_pt.pth。

微调权重恢复时，先用 XiaohuaModel 实例化原始基线，传入自定义配置并关闭严格校验，再载入本地的微调文件，最后切到半精度放到显存。

推理先封装了一个 Top-p 采样，做法是对概率排序后累加截断、重归一化，再用多项式抽样。配置只改动两项：pre_seq_len 设为 16，prefix_projection 设为 False。其余保持默认，模型同样以半精度加载并进入评估模式。

以 SPO 抽取为例，整体上限 288，源文本上限 256，提示语为“按给定的格式抽取文本信息。\n文本:”。对每条样本先分词并按上限截断，拼接提示、源文本、[gMASK] 与 <sop]。生成时每次取倒数第 3 个位置的 logits，用 0.95 温度做 softmax，再以 Top-p 0.95 抽取下一个词并更新序列，遇到结束符 130005 提前退出，最后解码输出。
[PRE1]python

def sample_top_p(probs, p):

    probs_sort, probs_idx = torch.sort(probs, dim=-1, descending=True)

    probs_sum = torch.cumsum(probs_sort, dim=-1)

    mask = probs_sum - probs_sort > p

    probs_sort[mask] = 0.0

    probs_sort.div_(probs_sort.sum(dim=-1, keepdim=True))

    next_token = torch.multinomial(probs_sort, num_samples=1)

    next_token = torch.gather(probs_idx, -1, next_token)

    return next_token

[PRE4]python

def quantize(self, bits: int, empty_init=False, **kwargs):

    if bits == 0:

        return

    from .quantization import quantize

    if self.quantized:

        return self

    self.quantized = True

    self.config.quantization_bit = bits

    self.transformer = quantize(self.transformer, bits,

                                empty_init=empty_init,

                                **kwargs)

    return self
