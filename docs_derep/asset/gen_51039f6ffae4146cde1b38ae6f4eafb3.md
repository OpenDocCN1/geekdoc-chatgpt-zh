#### （二）情感共鸣：让提示语触发情绪共振

在商业文案创作中，情感共鸣对消费者行为具有显著影响，品牌传播中不可或缺。情感营销理论认为，购买选择多受情感驱动，而非完全理性。要在文案中点燃目标受众的情感反应，已成为传播的核心课题。借助AI创作商业文案时，构建能引发情感回应的提示语，是实现高效情感营销的有效路径。

情感共鸣的本质是共情与感染。共情要求创作者深入把握受众的情绪需求与心理状态；感染则依赖恰当的语言与叙事手法来激活情绪。设计提示语时需融入心理学与叙事学的原理，引导AI产出更具感染力的内容。表6-2梳理了情感共鸣的关键特质及对应的提示语构建方法。

| 优秀文案的情感共鸣特质 | 提示语设计技巧 |
|---|---|
| 1. 情感基调明确 | 指定情感关键词：在指令中明确文案应呈现的核心情绪 |
| 2. 多感官体验描述 | 要求使用感官词汇：使用视觉、听觉、触觉等多感官描写 |
| 3. 情境代入感强 | 设定场景指令：要求创设与产品使用或品牌相关的具体情境 |
| 4. 情感层次丰富 | 递进情感层次：设计从基础情绪到高级情绪的递进结构 |
| 5. 共情叙事表达 | 指引叙事结构：要求以故事化方式呈现品牌或产品价值 |

#### （三）行动引导：用提示语推动转化决策

### 二、营销策划：创意、传播与执行的提示语方法

当下营销环境中，有效的营销策划决定品牌成败。市场竞争激烈、用户注意力分散，如何打造差异化创意、精准传播策略与可落地方案成为关键。借助AI优化营销策划流程，已成为提升效率与效果的新趋势。

设计高质量营销策划提示语的核心在于创新、精准与可行。创新需激发AI创造力，产出独特创意概念；精准需引导AI制定符合受众与市场环境的传播策略；可行需确保AI生成的执行方案具备实操性。

#### （一）创意概念：激发创新灵感的提示语设计

设计能引导AI产出独特性强、相关性高、易记且具情感触发力的创意概念的提示语，帮助AI生成既能脱颖而出又与品牌价值和受众需求高度契合的内容，同时易于传播并引发情感共鸣。

理论层面：优秀创意概念应具备：

1. 独特性：在市场中脱颖而出，吸引关注。
2. 相关性：与品牌价值和受众需求高度契合。
3. 记忆点：易于记忆与传播。
4. 情感触发：能引发受众情感共鸣。
5. 时效性：与当前社会热点或趋势关联。

方法层面：可采用以下技巧设计提示语。

1. 跨领域联想指令：要求AI融合不同领域元素，激发独特创意。例如：将 [品牌] 核心价值与 [不相关领域] 概念结合，创出独特营销创意。
2. 品牌DNA融入：在提示语中明确品牌核心价值，确保创意相关性。例如：设计体现 [品牌] 的 [核心价值1] 和 [核心价值2] 的创意概念。
3. 记忆点设计：要求AI创造易记口号或视觉元素。例如：创造朗朗上口、含双关语的口号，概括创意概念。
4. 情感地图构建：基于受众情感需求设计创意。例如：基于 [目标受众] 的 [核心情感需求]，设计能引发强烈共鸣的创意元素。
5. 趋势融合要求：指示AI将热点话题与品牌创意结合。例如：将 [近期热点话题] 与 [品牌特性] 结合，创出时效性强的概念。

#### （二）传播策略：精准触达的策略提示语设计

设计目标明确、受众精准、渠道多元、内容匹配且互动性强的传播策略提示语，确保信息在各平台有效传递，促进与目标受众深度互动，提升沟通效率，实现精准个性化营销。

理论层面：优秀传播策略应具备：

1. 目标明确：具备清晰可衡量的传播目标。
2. 受众精准：准确锁定目标受众，了解其特征与需求。
3. 渠道多元：选择适合受众的多样传播渠道。
4. 内容匹配：为不同渠道设计匹配内容形式。
5. 互动性强：设计提升用户参与度的互动机制。

方法层面：

1. 目标量化指令：要求AI设定具体可衡量目标。例如：运用SMART原则，设定3个具体传播目标，涵盖品牌知名度、用户参与度与转化率。
2. 受众画像详述：在提示语中提供详细受众特征。例如：基于[人口统计学特征]、[行为特征]、[需求痛点]和[媒体使用习惯]描述目标群体。
3. 全渠道思维引导：要求AI考量线上线下多种渠道。例如：设计包含至少5个不同类型渠道的传播矩阵，并说明选择理由。
4. 内容形式多样化：指示AI为不同渠道设计匹配内容形式。例如：为每个主要渠道设计内容策略，指出适合形式如短视频、图文、直播等。
5. 互动机制设计：要求AI提出增强参与度的策略。例如：设计2至3个提升用户参与度的互动方式，兼顾线上线下。

#### （三）执行方案：落地执行的计划提示语设计

设计提示语时应确保引导生成步骤清晰、职责明确、时间可控、资源合理且风险可控的执行方案，帮助制定详细可操作的行动计划，确保任务顺利执行并达成预期目标。

理论层面：优秀执行方案应具备：

1. 步骤清晰：具备明确可执行的行动步骤。
2. 职责明确：各执行环节均有明确负责人或部门。
3. 时间可控：有详细时间表与关键节点。
4. 资源合理：合理分配人力、物力、财力资源。
5. 风险可控：识别潜在风险并提供应对策略。

方法层面：

（1）行动步骤分解：要求AI将执行过程分解为具体可执行步骤。例如：将整体过程分解为10至15个具体步骤，标明预计耗时。
（2）角色分配指令：指示AI为每个环节分配负责角色或部门。例如：为每个主要执行步骤分配负责角色或部门，明确职责。
（3）时间节点设定：要求AI制定详细时间表，包括里程碑事件。例如：设计包含准备期、执行期与评估期的时间表，标注关键里程碑。
（4）资源分配引导：引导AI考量人力、物力、财力合理分配。例如：列出所需主要资源，包括人力、物力、财力，并给出数量或预算。
（5）风险评估要求：要求AI识别风险点并提出应对策略。例如：识别3至5个可能风险点，提出预防与应对措施，兼顾内部外部因素。
