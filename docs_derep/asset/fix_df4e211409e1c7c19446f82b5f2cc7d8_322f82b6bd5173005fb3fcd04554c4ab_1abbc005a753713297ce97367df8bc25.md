## 5.1 创建一个 MCP Server

一个功能完整的 MCP Server 需要具备以下能力。

- 资源管理：管理应用配置等静态资源，以及基于用户 ID 生成的用户资料等动态资源。
- 工具集成：执行基础数学运算的计算工具、通过字节跳动 API 调用 LLM 的 API 集成工具。
- 提示词模板：用于生成面向特定用户问候消息的问候模板。
- 会话管理：支持会话创建与维护、初始化、请求处理与终止。
- 通信管理：基于 HTTP/SSE 的通信机制，并支持流式响应。
