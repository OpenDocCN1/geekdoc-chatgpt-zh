数据类型别弄混，模型才不会跑偏

在实务数据里，经常会碰到一种只为标记记录的字段，即唯一标识符。建模时这类列通常会被丢弃，所以本文不展开。

数值和类别仍可再细分，每种形态都对应两种子类型，实践中处理要分开。数值可分离散与连续。判断很直观：取值能否逐一列举，能就是离散，不能就是连续。比如 0 到 100 的整数集合是离散，因为可选值有限；0 到 1 的小数集合是连续，因为理论上可以无限细分。

这里容易混淆的是自然数集合。数学上它无限，却仍算离散，因为任取两数，中间的整数都能一一数出。实数即有理数加无理数，在数轴上对应点，任意两点之间总能再找到无限多个其他实数。

对机器学习来说，核心不是数学意义上的无限，而是设定上下界后，区间内部的值是否可以逐项枚举。可枚举与否会决定方法选择。

类别可分有序与无序。有序指取值间存在先后或强弱，部分值关联更紧密。例如用多地数据预测某地时，邻近地区的样本应获更高权重，只有人口结构高度相似时远地样本才有参考价值。这种权重或顺序虽非数值，却能提升分析效果。位置信息通常不能直接转成数字，因三维空间关系复杂，但底层系统往往会把其他有序类别映射为数字以便计算。

无序则相反，每个取值与其他取值差异相同且不可度量。原色集合是典型，每种颜色差异等价；二元标签真/假也是常见例子。这类取值与依赖相似度或邻近度的方法不兼容。

有些取值不易直觉判断，比如邮政编码。它虽以数字呈现且带模糊顺序，但数值邻近不代表现实距离，所以更合理视作类别中的无序值。

以澳大利亚城市为例，不应让系统认为邮编5000的阿德莱德比邮编7000的霍巴特更接近邮编4000的布里斯班。更实用的做法是把邮编拆成州和郊区，或把每个州抽象为城区、郊区、农村的范围。这样因州相邻、农村到城市几乎都要经过郊区，取值在理论上会变成有序。

学会这样划分输入并识别更合适的类型，是选模型和数据、构建更稳健机器学习系统的关键。

### 距离度量

下面花点时间聊聊很多分类方法必须遵循的一个概念：距离度量。因为大量机器学习方法依赖一组输入属性——本质上是表格中的一行，忽略其类别或结果——并将其映射为 n 维空间中的点进行比较，而这些点未必直观，所以我们需要衡量点与点之间的距离。

这些度量是专家争论的焦点，我们只介绍几种非常常见的。还有很多度量标准，它们大多源于这些或完全不同。
