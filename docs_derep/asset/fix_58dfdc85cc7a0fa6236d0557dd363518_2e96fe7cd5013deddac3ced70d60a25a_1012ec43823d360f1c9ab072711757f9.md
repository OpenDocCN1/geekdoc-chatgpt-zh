2. 如何规范录入日期与时间？

- 日期录入：

  - 推荐分隔符：YYYY/MM/DD、YYYY-MM-DD、MM/DD/YYYY，具体按系统区域决定。

  - 示例：可填写 2025/4/22 或 22-Apr-2025。

- 时间录入：

  - 用冒号分隔：HH:MM:SS 为 24 小时制，或 HH:MM AM/PM 为 12 小时制。

  - 示例：14:30 或 2:30 PM。

- 日期与时间合并录入：

  - 日期和时间之间以空格分隔：2025/4/22 14:30。

- 注意事项：

  - 单元格必须设为“日期”或“时间”格式，否则会被当成文本。

  - 默认格式受区域设置影响，可在控制面板 → 区域设置 → 日期/时间格式 中调整。

3. 非法日期如何快速修正？

- 常见问题：

  - 文本型日期，如“2025年4月22日”未按规则输入。

  - 超出 Excel 支持范围，如早于 1900 年 1 月 1 日或晚于 10000 年。

- 处理办法：

  1. 分列工具：

     - 选中数据 → 数据 → 分列 → 选择“日期”格式 → 完成。

  2. 公式转换：

     - 使用 =DATEVALUE(A1) 将文本转为日期，=TIMEVALUE(A1) 将文本转为时间。

  3. 条件格式标注：

     - 开始 → 条件格式 → 新建规则 → 使用公式：=ISERROR(A1*1)，设置颜色突出非法值。

图 5-41 DeepSeek 关于如何快速修改非法日期的回答

4. 日期时间的自定义格式如何设定？

- 操作步骤：

  1. 选中单元格 → 右键 → 设置单元格格式 → 自定义。

  2. 格式代码输入：

     - 日期代码：

       - yyyy：四位年份 2025

       - mm：两位月份 04

       - dd：两位日期 22

       - mmm：英文月份缩写 Apr

       - mmmm：英文月份全称 April

     - 时间代码：

       - hh：12 小时制小时

       - HH：24 小时制小时

       - mm：分钟

       - ss：秒

       - AM/PM：上下午标识

  - 示例：

    - yyyy-mm-dd → 2025-04-22

    - dd-mmm-yy → 22-Apr-25

    - hh:mm AM/PM → 02:30 PM

## 5. 常用的日期时间函数

| 函数 | 用途 | 示例 |
| :--- | :--- | :--- |
| TODAY() | 返回当前日期 | =TODAY() → 2023-10-05 |
| NOW() | 返回当前日期和时间 | =NOW() → 2023-10-05 14:30 |
| DATE(年,月,日) | 组合日期 | =DATE(2025,4,22) → 2025-04-22 |
| TIME(时,分,秒) | 组合时间 | =TIME(14,30,0) → 14:30 |
| DATEDIF(开始日,结束日,"单位") | 计算日期差值（单位如"Y"年、"M"月、"D"日） | =DATEDIF(A1,B1,"D") → 天数差 |
| YEAR(日期) | 提取年份 | =YEAR(A1) → 2025 |
| MONTH(日期) | 提取月份 | =MONTH(A1) → 4 |
| DAY(日期) | 提取日 | =DAY(A1) → 22 |
| HOUR(时间) | 提取小时 | =HOUR(A1) → 14 |
| EDATE(日期,月数) | 返回指定月数后的日期 | =EDATE(A1,3) → 2025-07-22 |

## 实际应用示例

- 计算年龄：

  `=DATEDIF(出生日期, TODAY(), "Y") & "岁"`

- 倒计时天数：

  `=目标日期 - TODAY()`

- 提取周末日期：

  `=IF(WEEKDAY(A1,2)>5, "周末", "工作日")`

## 注意事项

- 日期函数结果依赖系统时间，请保持电脑时间准确。

- 使用 `Ctrl+;` 可快速填入当前日期，`Ctrl+Shift+;` 可快速填入当前时间。

- 跨地区协作时，请统一日期格式以免混淆。
