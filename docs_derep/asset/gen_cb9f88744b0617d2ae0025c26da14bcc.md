## 4.2 Tensor Core 基本原理

在 NVIDIA 通用 GPU 架构中，主要存在 CUDA Core、Tensor Core、RT Core 三种核心类型，其中 Tensor Core 作用极为关键。

Tensor Core 面向深度学习与 AI 工作负载设计，可实现混合精度计算并加速矩阵运算，尤其擅长半精度与单精度的矩阵乘法与累加。Tensor Core 在深度学习训练与推理加速中发挥重要作用。

本节将逐步探讨卷积与 Tensor Core 的关联、Tensor Core 工作原理，并结合代码示例帮助读者理解框架层面如何利用 Tensor Core 实现训练加速，并对 CUDA 编程建立初步认知。

### 4.2.1 卷积计算

卷积计算是深度学习与神经网络中常用的操作，用于从输入数据中提取特征。Tensor Core 是 NVIDIA 推出、专为加速深度学习矩阵计算的硬件加速器。理解卷积与 Tensor Core 的关系，需先把握卷积计算本质。

### 1. CNN 与 GEMM

卷积神经网络通常包含大量卷积层，通过卷积提取特征。在算法层面，卷积加速的关键步骤是数据重排，即 Im2Col 操作。

Im2Col 主要包含两步：首先将输入矩阵展开为大矩阵，每一列对应卷积核所需的一个输入数据；其次对转换后的矩阵执行 MatMul，得到最终卷积结果。

经 Im2Col，输入数据重排为大矩阵，卷积权重亦转为另一矩阵，原卷积计算转化为两矩阵乘法。转换后的矩阵乘法可利用 Tensor Core 等现代计算架构实现高效加速。

GEMM，即通用矩阵乘法，是一种高效矩阵乘法算法，适合大规模矩阵运算。将卷积转为矩阵乘法后，多次矩阵乘法可合并为单个更大矩阵乘法执行，即批量处理，可进一步提升效率，因批量处理能同时处理多个样本，更好利用 GPU 并行资源。

借助 Im2Col 与 GEMM 批量处理，CNN 中卷积层计算可显著提速，既提高训练效率，也加快推理速度，为神经网络模型开发与部署带来实质收益。

### 2. 混合精度训练

在探讨 Tensor Core 对训练加速作用前，需明确混合精度训练概念。直观理解常被误解为模型中同时使用 FP16 与 FP32，并非真正含义。

混合精度训练是一种优化技术，通过在训练过程中灵活选用不同数值精度以加速训练、减少内存占用。具体包括：

- 计算精度分配：在前向传播与反向传播中使用较低精度如 FP16 计算，以加快速度并降低内存占用。FP16 内存与带宽需求低于 FP32，可显著提升处理效率。
- 参数更新精度保持：模型参数更新仍使用较高精度如 FP32，以维持训练稳定性和最终性能。若直接用 FP16 更新参数，可能导致训练不稳定甚至不收敛，因 FP16 表示范围与精度有限，易出现梯度消失或溢出。

混合精度的实现通常需要硬件支持与软件优化。例如 NVIDIA Tensor Core 专为加速 FP16 计算设计，同时保持 FP32 累加精度，使混合精度训练成为可能。软件层面，PyTorch、MindSpore 等 AI 框架提供混合精度训练支持，通过自动化工具简化实现。如图 4.2.1 所示，相较 FP32，FP16 在整数位与小数位上表示范围小得多。
