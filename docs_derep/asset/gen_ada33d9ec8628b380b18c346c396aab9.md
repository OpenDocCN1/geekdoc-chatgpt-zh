ID3 即迭代二分器 3 决策树算法，1986 年由 Ross Quinlan 提出，是一种基于信息增益的分类模型，广泛用于数据挖掘与知识发现。下面是对该算法的要点介绍。

### 算法概述
ID3 的核心是通过挑选信息增益最大的特征来对数据集进行划分，从而逐步构建决策树。信息增益用于衡量某个特征对分类结果的区分能力，算法递归选择特征并分裂数据，最终形成完整的树结构。

### 信息增益
信息增益是 ID3 选特征的依据，根植于信息论中的熵。

1. 先算数据集整体熵，熵越高不确定性越大。
2. 再算在给定特征条件下的条件熵。
3. 信息增益 = 整体熵 - 条件熵。增益最大的特征被选作当前节点的分裂点。

### 算法步骤
1. 初始化：从根节点出发，计算当前子集的熵。
2. 选择特征：为每个候选特征计算信息增益，取最大值进行分裂。
3. 分裂数据集：按所选特征把数据分成若干子集。
4. 递归建子树：对每个子集重复上述过程，直至满足停止条件，如样本全部同类或无可用特征。
5. 生成决策树：所有节点都停止后得到完整树。

### 优缺点
优点：
- 逻辑清晰，实现简便。
- 生成的树可解释性强。

缺点：
- 对噪声敏感，易出现过拟合。
- 仅支持离散特征，连续特征需先离散化。
- 不处理缺失值。

### 应用场景
ID3 适合对可解释性要求高的分类任务，例如信用评估、医疗诊断等。实际使用时常结合剪枝或改用改进版如 C4.5 来缓解过拟合问题。

总的来看，ID3 虽有局限，但凭借简单与可解释的优势，仍是机器学习领域的经典分类方法。
