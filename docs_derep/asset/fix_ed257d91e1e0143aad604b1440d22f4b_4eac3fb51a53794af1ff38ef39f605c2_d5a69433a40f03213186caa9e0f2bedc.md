##### 7. LangGPT 模块化提示体系

LangGPT 在开源时不仅提出结构化提示方法论，还提供可按需拼装的模块化提示体系，已被多家主流模型服务商采纳，成为国内使用最广的提示词框架之一。

LangGPT 强调结构化而非固守固定属性清单，会依据具体任务灵活组合属性模块。下面是对其常用属性的归纳。

LangGPT 属性词汇总：

- （1）基础属性词

Role — 人设定位，指示模型扮演的角色。也可用 Expert、大师 等同义词替代 Role，限定为某一领域专家。

Profile — 人设背景，对模型所扮演角色的背景做简要介绍。

Skills — 能力清单，该角色所具备的能力。

Rules — 行事准则，该角色必须遵守的行为规范。

Workflow — 执行步骤，该角色完成任务时遵循的流程。

Initialization — 启动准备。

（2）补充属性词

OutputFormat — 输出样式要求。

Attention — 关注要点，提醒模型需要注意的事项。

Constraints — 使用限制，对模型的特定限制条件。

Ethics — 道德边界，限定模型应遵循的伦理准则。

Personality — 性格设定。

Writing Style — 文体风格。

Preferences — 个人偏好。

Goals — 人物层面的任务目标。

Background — 任务背景说明。

## 目标：Goals

- 数据治理：对原始数据进行全面清理，涵盖缺失值处理、重复记录剔除、格式统一化等，确保数据完整且一致。
- 数据标准化：将数据转换为统一格式，便于后续处理与分析。
- 异常检测：识别数据中的异常值和异常模式，及时提醒用户并给出处理建议。

## 约束：Constraints

- 必须充分理解数据的业务背景和含义，避免盲目清洗造成信息丢失。
- 清洗后的数据需与原始数据的语义保持等价，不能改变数据本质含义。
- 清洗过程要高效，能够在合理时间内完成大规模数据处理。

## 技能：Skills

数据分析与挖掘、统计学与机器学习算法、异常检测与模式识别、编程语言如 Python、SQL 等。

## 示例：Example

原始数据：

- 某电商平台订单数据，字段包含订单号、下单时间、收货人姓名、收货地址等。
- 存在收货地址缺失、订单号重复、时间格式不统一等问题。

处理步骤：

1. 检测并填充缺失值，例如依据同一用户其他订单的地址补全缺失收货地址。
2. 去重订单号，保留下单时间最新的记录。
3. 将时间统一转换为“yyyy-mm-dd hh:mm:ss”格式。
4. 检测并标记异常订单，例如收货地址为空字符串的情况。

输出数据：

- 字段完整、格式统一的清洗后订单数据，异常订单已完成标记。

## 工作流程：Workflow

1. 数据接收：接收原始数据文件，支持 CSV、Excel 等常见格式。
2. 数据探索：进行探索性分析，了解字段含义、数据分布及异常情况。
3. 清洗方案制定：基于探索结果设计清洗步骤与算法。
4. 算法实现：使用 Python 等语言实现数据处理算法。
5. 执行清洗：按设计步骤对原始数据进行清洗。
6. 质量检查：对清洗后数据抽样检查，评估清洗质量。
7. 结果输出：将清洗后数据导出为用户指定的格式。
8. 报告生成：生成清洗报告，记录处理流程与结果分析。

## 初始化：Initialization

Kimi 的回应如下：

这封邮件是一封典型的商务推广邮件，整体上已经包含了基本的商务礼仪和产品介绍要素。不过，为了提升邮件的专业性、吸引力和有效性，可以考虑以下几点改进：

1. 个性化称呼：使用“亲爱的张先生”作为称呼是好的开始，但如果能够根据收件人的具体情况进一步个性化，比如使用其职位或公司名称，会让邮件显得更加贴心。
2. 产品介绍具体化：邮件中提到了产品的几个亮点，但没有具体说明。如果能够提供一些具体的产品特性或技术参数，可能会更有助于收件人了解产品的实际价值。
3. 案例或证据：如果可能，提供一些使用案例、客户评价或市场反馈，可以增加产品介绍的说服力。
4. 清晰的行动号召：邮件结尾处可以更明确地提出希望收件人采取的行动，比如“我期待与您进一步讨论产品细节，请在方便时与我联系”。
5. 附件或链接：如果有可能，可以附上产品手册或宣传册的链接，方便收件人直接下载或查看。
6. 联系方式的格式：在邮件的最后，联系方式可以更正式一些，比如使用“联系电话：[李华] 138××××5678”和“电子邮箱：lihua@×××.com”，这样既清晰又便于收件人操作。
7. 邮件签名：邮件签名可以包含公司的标志或口号，以及更详细的联系信息，如公司地址等。
8. 语言风格：根据收件人的背景和行业特点，调整邮件的语言风格，使其更加符合对方的阅读习惯。
9. 避免使用模糊的表达：如“性价比高”“使用方便”，这些表达比较模糊，如果能具体说明如何性价比高，或者哪些方面使用方便，将会更具体、更有说服力。
10. 检查语法和拼写：确保邮件中没有语法错误和拼写错误，这关系到邮件的专业度。

最后，记得在发送前进行多次审阅，确保邮件内容准确无误，表达清晰。
