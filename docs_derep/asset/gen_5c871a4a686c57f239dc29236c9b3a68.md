向量嵌入：让文字进入数学空间

嵌入的本质，是把一段文本字符串映射成数字向量，用来衡量语义上的远近。借助这种表示方式，机器可以判断哪些文本意思相近、哪些差异明显。典型应用包括：

搜索
根据查询语句的相关度对结果重新排序
推荐
为用户推送包含与查询相似内容的文章
聚类
按照语义相似度把字符串归到同一组
异常检测
找出与其他文本明显不相关的离群字符串

嵌入如何让模型读懂语言

在机器学习里，尤其是语言模型中，嵌入是一个关键概念。它把分类性质的数据，比如词元或词元组，转化为实数向量。因为模型只能直接处理数值，文本必须先被编码成数字。

可以把嵌入想象成一种语言转换器，把丰富的词汇和句子翻译成模型可读的数值语言。它的突出特点是保留语义邻近性：含义相近的词或短语，在向量空间中的位置也更靠近。

信息检索正依赖这一特性。检索是从海量数据里抽取相关信息，而嵌入因为捕捉到了语义相似性，成为执行这类任务的理想工具。

大语言模型大量使用嵌入。通常模型处理大约512维的向量，用高维数值表征语言数据。维度足够深，模型就能分辨复杂的模式，因此在翻译、摘要、生成类人对话等任务上表现稳健。

嵌入具备一个直观属性：含义越相似，向量越接近。例如图 2-8 中的三个句子，“猫在房子周围追着老鼠跑”和“在房子周围，老鼠被猫追着跑”语法不同但大意一致，嵌入表示也接近。而“航天员在轨修理了宇宙飞船”与猫老鼠的例子无关，主题完全不同，嵌入表示也明显分开。示例为清晰起见用二维展示，实际使用通常是512维以上。

## 3.1 应用程序开发总览

构建基于 LLM 的应用，核心是将模型与 OpenAI API 集成。这要求开发者妥善管理 API 密钥，兼顾数据安全与隐私，并降低集成带来的特定攻击风险。

### 3.1.1 管理 API 密钥

如第 2 章所述，使用 OpenAI 服务必须持有 API 密钥。密钥的管理方式会直接影响应用设计，因此需从一开始就重视。第 2 章展示了个人或测试用途的管理方法，本节聚焦于应用开发场景。

无法穷举所有管理方案，因为方案与应用类型强相关：独立解决方案、Chrome 插件、Web 服务器或终端启动的 Python 脚本，各自策略不同。建议先了解最佳实践和常见安全威胁。以下提供整体建议供决策参考。

对于 API 密钥有两个选择：

* 让应用用户自行提供密钥
* 使用你自己的密钥

两者各有利弊，且都必须把密钥视为敏感信息。

1. 用户提供 API 密钥
如果你设计应用调用 OpenAI 服务时使用用户密钥，好处是不会产生意外费用，且测试只需一个密钥。缺点是需要在设计上保护用户安全。

此时有两个做法：

* 仅在必要时要求用户提供密钥，且绝不通过远程服务器存储或使用。密钥永不离开用户设备，API 调用在用户设备运行的代码中完成。
* 在后端维护数据库并安全存储密钥。

第一种做法每次启动都可能要求用户输入密钥。也可在用户设备上本地保存，或采用环境变量如 `OPENAI_API_KEY` 的约定，但并非所有用户都熟悉环境变量操作。

第二种做法密钥会在设备间传输并远程存储，增加攻击面和风险，但后端安全调用可能更容易管理。

无论哪种方式，若攻击者获得应用访问权限，就可能访问目标用户可访问的任何信息。安全设计需整体考量。

设计时可遵循以下原则：

* Web 应用把密钥保存在用户设备内存中，避免写入浏览器存储。
* 若选择后端存储密钥，需实施高安全措施，并允许用户自行管理密钥，包括删除。
* 传输中和静态存储时都加密密钥。

## 2. 你自己提供 API 密钥
若使用自己的密钥，请遵守以下实践：

* 不要直接把密钥写进代码。
* 不要把密钥存放在应用源代码文件中。
* 不要在用户浏览器或个人设备上使用你的密钥。
* 设置使用限制以控制预算。

常规做法是通过后端服务使用你的密钥，具体方案取决于应用设计。

> [PRE12] API 密钥安全问题不限于 OpenAI，互联网上有大量关于密钥管理的资料，推荐参考 OWASP Top Ten 的内容。

### 3.1.2 数据安全与数据隐私

通过 OpenAI 端点发送的数据受 OpenAI 数据使用规则约束。设计应用时，确保不会把包含用户敏感信息的输入发送到端点。

若应用部署在多个国家，需注意与 API 密钥关联的个人信息及发送的输入数据可能从用户所在地传输到 OpenAI 位于美国的服务器，这可能带来法律影响。

OpenAI 提供安全门户页面，展示其在数据安全、隐私和合规方面的承诺，门户中列出最新合规标准，可下载渗透测试报告、SOC 2 合规报告等文件。

## 3.2 软件架构设计原则

建议在构建应用时将系统与 OpenAI API 解耦。

OpenAI 服务可能变更，且你无法控制其 API 管理方式。最佳实践是确保 API 变化不会迫使你重写整个应用，这可通过遵循架构设计模式实现。
