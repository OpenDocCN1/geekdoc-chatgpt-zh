GPT-2 增量推理：注意力缓存的滚动更新

GPT-2 做自回归生成时，关键在于把上一次算好的注意力状态保留下来复用。past_key_values 是一个装有 12 个 layer_past 的元组，和模型里 12 层 Transformer Block 一一对应。每个 layer_past 都是该层在上一轮前向结束后留下的 present 快照，而 present 的实质是注意力模块把本轮新产生的 key 与历史 past_key 融合、把本轮新产生的 value 与历史 past_value 融合后得到的一对张量。12 层各自的 present 汇总成 presents，再作为下一轮的 past_key_values 重新送入模型。下面拆解新 key 与新 value 的构造细节。

序列轴在首轮与后续轮次的行为不同。第一次完整前向时，query/key/value 在序列维度上仍保持完整的 seq_len，从第二轮起进入增量生成，序列维度被固定为 1，每一步只引入一个新词元的信息。

<1> 本轮新 key 的生成方式
历史 key 缓存 layer_past[0] 需要先经 transpose(-2, -1) 调整为 批次、头数、头特征、序列长 的排列。此时本轮新产生的 key 排列为 批次、头数、头特征、1。调整后可在最后一个维度上拼接，把当前词元的 key 接到历史 key 尾部，以便后续自回归仍能看到完整上下文。拼接后新 key 的排列变为 批次、头数、头特征、序列长+1，记为 new_seq_len = 序列长+1。

<2> 本轮新 value 的生成方式
历史 value 缓存 layer_past[1] 不做变形，保持 批次、头数、序列长、头特征 的排列，本轮 value 的排列为 批次、头数、1、头特征。两者在倒数第二个维度上拼接，把当前词元的 value 追加到历史 value 序列。拼接后新 value 的排列为 批次、头数、序列长+1、头特征，new_seq_len 同为序列长+1。

class Block(nn.Module):

    def __init__(self, n_ctx, config, scale=False):
        super().__init__()
        # config对应的GPT2Config()类中，n_embd属性默认为768，因此此处hidden_size即为768
        hidden_size = config.n_embd
        # config对应的GPT2Config()类中，n_inner属性默认为None，因此此处inner_dim一般都为4 * hidden_size
        inner_dim = config.n_inner if config.n_inner is not None else 4 * hidden_size
        self.ln_1 = nn.LayerNorm(hidden_size, eps=config.layer_norm_epsilon)
        # 此处n_ctx即等于config对应的GPT2Config()类中的n_ctx属性，其值为1024
        self.attn = Attention(hidden_size, n_ctx, config, scale)
        self.ln_2 = nn.LayerNorm(hidden_size, eps=config.layer_norm_epsilon)
        if config.add_cross_attention:
            self.crossattention = Attention(hidden_size, n_ctx, config, scale, is_cross_attention=True)
            self.ln_cross_attn = nn.LayerNorm(hidden_size, eps=config.layer_norm_epsilon)
        self.mlp = MLP(inner_dim, config)
