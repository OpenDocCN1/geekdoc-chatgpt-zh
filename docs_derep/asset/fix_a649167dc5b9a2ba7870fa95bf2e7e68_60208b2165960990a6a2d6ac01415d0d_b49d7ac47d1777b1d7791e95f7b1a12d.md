# ## 6.3 会话摘要与支持向量存储

会话摘要和向量存储是 Memory 模块的高级能力，用于长对话和海量信息处理。摘要通过压缩历史生成简明概览，让模型快速把握核心而无需加载全部记录；向量存储则借助向量化技术保存对话，便于在海量内容中快速定位相关信息。

本节将介绍如何生成与更新会话摘要，以及如何配置向量存储，帮助你在复杂应用中实现更高效的背景管理，特别适合长对话、内容回溯和个性化检索的企业级场景。
