从BART到UL2：预训练如何走向统一

在序列分类场景里，BART的做法是把同一份输入同时喂给编码器和解码器，然后取出解码器最后一个位置的最终隐状态送入一个全新的多分类线性层做判断。这个思路与BERT里[CLS]标记承担的汇总角色非常相近。额外的是，BART会在序列尾部补上一个特殊的标记，让整段输出能够聚合来自序列中每个token的信息。

### 6.3 UL2：统一语言学习的框架

T5和BART率先用“文本到文本”的思路尝试把不同任务统一，UniLM则展示了单模型多目标训练的可行性。如今可选的预训练模型越来越多，最终架构的选择却高度依赖任务：到底用编码器-解码器还是纯解码器？预训练目标该怎么设？是BERT风格的掩码还是前缀语言模型？这些细节差异带来的困扰，推动了谷歌提出的统一语言学习框架UL2，它在多种任务和设定下保持了稳健的高效。

通用模型的需求很明确，集中资源升级单一模型比分散维护多个模型更划算，尤其在设备资源受限时，一个能跨类别表现的预训练模型更有价值。UL2把过去常被混为一谈的模型架构与预训练目标拆开，重新梳理了自监督任务的统一视角，并展示不同目标之间的可转换性。随后提出混合去噪器Mixture-of-Denoisers，将多种预训练范式融合，形成统一的学习范式。

#### 6.3.1 预训练任务的统一视角

现有预训练可以概括为“输入到目标”形式，输入是模型所依赖的记忆或上下文，目标是期望输出。主流可归为三类：语言模型、片段损坏和前缀语言模型。语言模型用之前所有时间步预测下一个token；片段损坏利用前后未损坏的token预测被破坏的片段；前缀语言模型用过去token作输入但对输入做双向编码，建模能力比单向更强。

从去噪任务的角度看，三者内在相连。片段损坏中若损坏片段恰好是整段序列，问题就退化为语言模型；把损坏片段长度调大，也能模拟局部语言模型的目标。

UL2用统一公式把这些去噪任务收敛。输入和目标由SpanCorrupt生成，参数为μ、r、n，分别代表平均片段长度、损坏率、损坏片段数。n可设为L/μ的函数，也可固定。函数基于均值μ的正态或均匀分布采样损坏长度，损坏后输入参与去噪预训练，被损坏片段作为恢复目标。

以因果语言模型为例，取μ=L、r=1.0、n=1即可得到单一长度等于整段输入的损坏；类似前缀语言模型则取μ=L-P、r=1.0-P/L、n=1，并限制损坏片段必须延伸到序列末尾。

这种输入到目标范式适用于编码器-解码器和纯解码器结构。UL2聚焦于预测下一个目标token而非当前token的模型，因为前者更通用，能覆盖更多任务，避免为特定下游任务引入[CLS]等专用头和投影层。

#### 6.3.2 混合去噪器融合多重视角

若预训练阶段就能以一个强通用框架解决多样问题，就能大幅降低为每个任务设计架构和目标的成本。UL2认为自监督目标里应注入多样性，否则模型可能缺失长文本连贯生成等能力。

基于此，UL2定义了三种主流范式，如图6-12所示，灰色块为被遮挡的预训练目标。

1) R-去噪器：标准片段损坏，损坏片段多为2~5个token，约遮挡15%输入。短片段有助于学到文本知识而非流畅生成。
2) S-去噪器：严格遵循序列顺序的去噪特例，即前缀语言模型。输入被拆成上下文和目标两部分，目标不依赖未来信息，且上下文保留双向感受野。记忆很短的S-去噪器与标准因果语言模型特性接近。
3) X-去噪器：极端去噪，模型需从少量或中等输入恢复很大比例原文，模拟从有限记忆生成长目标。UL2通过增大损坏片段或损坏率让约50%输入被遮挡。当片段长度≥12或损坏率≥30%时即视为极端任务，用来填补标准片段损坏与语言模型之间的空白。

R对应T5的片段损坏，S与GPT类因果语言模型关联，X则兼具两者。图6-13显示，无论是纯解码器前缀模型还是编码器-解码器，都能用混合去噪器预训练，并在有监督微调、上下文学习、零样本等范式下，以及语言生成、理解、结构化知识和长程推理等任务上取得最优。

X-去噪器还能提升样本效率，因每个样本可预测更多token。UL2最终把任务融合为混合自监督目标，共7个去噪器的组合，配置见表6-4。

表6-4 UL2混合式去噪器的配置

| 去噪器 | 配 置 |
| --- | --- |
| R-去噪器 | $(\mu=3, r=0.15, n) \cup(\mu=8, r=0.15, n)$ |
| S-去噪器 | $(\mu=L / 4, r=0.25, 1)$ |
| X-去噪器 | $(\mu=3, r=0.5, n) \cup(\mu=8, r=0.5, n) \cup(\mu=64, r=0.15, n) \cup(\mu=64, r=0.5, n)$ |

X和R的片段长度从均值μ的正态分布采样；S使用均匀分布，损坏片段固定为1并强制其在原文末尾结束，之后不再出现未损坏token，近似序列到序列去噪或前缀语言模型。由于语言模型是前缀语言模型的特例，UL2未把因果语言模型单独纳入混合。各任务参与度大致相等，也试验过把S提升到总量的50%。

实验表明混合去噪预训练在广泛任务上表现突出，而单一去噪器会损害性能。早期T5曾尝试50%损坏率的X设置，效果并不理想。

UL2还引入模式切换概念，在预训练时为模型提供额外范式标记[R][S][X]，帮助切换去噪模式。微调和少样本学习时，再加入描述下游任务设定需求的范式标记，使下游行为与上游训练模式绑定。
