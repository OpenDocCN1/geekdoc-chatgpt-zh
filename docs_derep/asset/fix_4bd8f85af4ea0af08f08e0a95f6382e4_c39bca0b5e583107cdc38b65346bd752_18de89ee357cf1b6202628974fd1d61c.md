### 5.2.1 认证机制与请求结构

认证与请求结构是高效交互的基础，前者保障接口调用安全，后者为多场景应用提供灵活兼容。

## 1. 身份认证

DeepSeek API 采用密钥式身份认证。开发者需在开放平台生成唯一 API 密钥作为访问凭证，每次请求须在 HTTP 请求头中携带，平台校验其合法性与权限。同时支持 OAuth 协议实现更精细的多用户权限管理，适配企业级场景。

## 2. 请求结构

API 请求遵循 RESTful 规范，支持 POST 与 GET。请求体需包含以下核心字段：

- **(1) model**：指定调用的模型版本。
- **(2) messages**：对话内容或任务输入，采用包含用户与系统角色的 JSON 数组格式。
- **(3) max_tokens**：限定生成内容的最大长度。
- **(4) temperature**：控制生成多样性的参数。
- **(5) top_p**：用于概率分布裁剪，提升生成准确性。

请求格式清晰可扩展，支持多轮对话、JSON 生成、函数调用等定制化场景。
