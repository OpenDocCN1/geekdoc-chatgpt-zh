## 第2章 提问有技巧，DeepSeek 更懂你

本章旨在帮助读者快速成为 DeepSeek 的熟练使用者。首要任务是分清两个常用模型：DeepSeek-V3 与 DeepSeek-R1。

DeepSeek-V3 更适合标准化的任务，比如文献撰写、会议纪要整理。DeepSeek-R1 则偏向复杂推理场景，例如数学求解、创意文案产出。

两者在指令方式上也不相同。V3 更适合用 RTGO 框架来提问，R1 则更依赖四要素指令法。

此外，本章还将介绍三大实用功能。

- **多轮持续对话**：可像聊天一样逐步完善答案。
- **联网搜索**：可获取实时新闻资讯。
- **文件解析**：可直接上传文档进行分析。

掌握这些方法后，DeepSeek 才能真正成为你的智能助手。

### 2.1 V3 与 R1 的提示语用法大不同

使用 DeepSeek 时是否遇到过这种尴尬：让它写会议纪要，它却写的花里胡哨、漏掉重点；让它出创意文案，它却照搬模板毫无新意。

根源往往在于提示语设计和模型选型不当。V3 和 R1 各有侧重：

- **V3 是模板专家**，擅长处理需要明确流程和框架的规范化任务，比如会议纪要、报告撰写。
- **R1 是创意大师**，更适合开放性任务，如广告文案策划、策略建议等，只需给出模糊目标就能激发其创造力。

用错模型效果大打折扣，用对模型则事半功倍，关键在于掌握提示语设计方法。

#### 2.1.1 V3 与 R1 的适用场景对比

从任务属性看，可分为规范性任务和开放性任务。

- **规范性任务**：执行时必须遵循既定框架、模板或结构化步骤，结果确定性高、路径固定。例如按学术规范写文献综述、按公司模板写会议纪要、按章节结构制定课程大纲等。这类工作对准确性和一致性要求高，DeepSeek-V3 因其结构导向和规范性强，更为合适。

- **开放性任务**：没有固定框架，以结果为导向，强调创意和突破。例如新媒体文案创作、广告语构思、品牌故事叙述、探索性市场预测等。DeepSeek-R1 在此类任务上表现更佳，能给出更灵活创新的解法，不过输出的可预测性相对 V3 较低。

#### 2.1.2 V3 与 R1 在提示语上的差异

两类模型对指令的理解方式不同，因而提示语设计原则也不同。

1. DeepSeek-V3 的提示语设计
V3 更擅长理解基于明确指令和具体框架的内容。设计要点为：
- 明确性：清晰说明每一步骤和格式要求。
- 结构化：使用分点、编号、示例模板。
- 限制性：用约束指令排除无关内容，如“禁止添加主观评价”。

例如，让 DeepSeek 根据提供的课程大纲，按照指定教案格式完成后续章节。提示语要求严格依据给定标题，不得随意更改，并附上完整大纲。关闭“深度思考”后使用 V3，输出会严格遵循示例结构，如图 2-1 所示。

### 2.2 非推理大模型的提问技巧

非推理大模型的提示语相当于一份详细的工作说明书。以 DeepSeek-V3 为例，提示语需说明扮演什么角色、完成什么任务、达到什么目标、如何输出，例如角色是经验丰富的老师，任务是写科普文章，目标是让小白看懂，输出要求通俗语言、限定字数、特定结构、Word 格式等。

#### 2.2.1 角色定义：构建精准的人物形象

角色设定是对话的基础，决定了模型以何种身份、视角和专业深度作答。角色不仅包含职业身份，还应涵盖经验水平、专业领域和沟通风格，从而提升回答的专业性和实用性。

1. 角色定义的重要性
- **激活特定知识库**：通过设定角色可让模型聚焦相关领域知识。例如设定为“经验丰富的营养师”，模型会优先调用营养学相关信息。
- **限定范围和深度**：无角色的提问易导致回答宽泛。明确角色后，如“对糖尿病管理有深入研究的营养师”，回答会聚焦饮食控制血糖的具体方法。
- **提升场景适配性**：不同角色会产生不同解决方案。如“帮助职场人士改善睡眠的治疗师”会给出针对加班压力的建议，而“专注老年人健康的睡眠专家”则更关注生理特点和常见障碍。

2. 如何设计有效角色
- **专业背景**：明确职业身份，如数据分析师、心理咨询师、市场营销专家。可进一步细化为“专注社交媒体营销的数字营销专家”。
- **经验水平**：用“新手”“资深”“10 年经验”等关键词设定资历，提升可信度。
- **特定专长**：进一步限定领域，如“专注糖尿病管理的营养师”，提高针对性。
