语义网与人工智能领域里常谈的语义网络并非同一个概念。语义网的根源在万维网，甚至它的初衷就是为万维网补强，让网络具备更高的智能化能力，正因如此外界也习惯把语义网称作 Web 3.0。这项构想由万维网联盟 W3C 提出，创始人 Tim Berners-Lee 希望通过它来更高效地组织与检索信息，让计算机能够调动互联网上庞大的资源完成真正的智能化任务。

现实中的互联网，大量信息仍以弱结构存在，文本、音视频、网页应用大多只是靠简单链接串起。这种松散的组织方式在检索、抽取、管理等环节明显拖后腿。与 IPv6 那样的互联网变革一样，语义网的推动并非依赖科学上的突破性发现，更多是工程层面的难题：标准化、规模化、系统开发与集成、用户交互等都要一一攻克。所以语义网或 Web 3.0 本质上是一个宏大的愿景，本书则从自然语言处理的视角来讨论人们如何借助语义网来表达知识。

### 2.2.2 语义网知识描述体系
本小节聚焦语义网的知识表述方式。目前的知识表示体系大致可分为三层：

- XML：可扩展标记语言。作为语义网最早的表达语言，它标志着从网页式标签向语义表达的跨越。XML 以文档为单位，本身并不显式约束标签的语义，其扩展 XML Schema 则负责描述文档的结构与元素形式。

- RDF：资源描述框架。可看作是 XML 的简化与延伸。RDF 对资源、属性、类别的描述，以及类别间的上下位语义，都由 RDF Schema 来定义。

- OWL：网络本体语言。OWL 建立在 RDF 与 RDF Schema 之上，用来做本体的语义表达，能够刻画属性间的关系如逆关系、函数约束、有且仅有等，并吸收了描述逻辑等逻辑语言以便更好地描述推理知识。

下面分别展开这三种方法。

#### 2.2.2.1 XML
XML 并非为语义网专门设计，它最早在 20 世纪 80 年代初被提出，用于处理动态内容的展示，并为了解决 HTML 在数据表达上混乱的问题。HTML 在传输内容时只能使用预设的标记集合，而 XML 允许使用者自行定义标记集合，可扩展性大幅提升。1998 年 XML 1.0 规范正式确立。

#### 2.2.2.2 RDF
XML 的优点在于灵活，设计者可以自由定义元素与属性的标签，只要共享标签含义，使用者就能管理和利用。相比通用标签的 HTML，表达力更强，但通用性受限。若设计团队离职或缺乏说明文档，个性化标签的含义就难以辨识，对维护十分不利。随着链接开放数据 LOD 项目的出现，不同时期或不同组织的语义知识需要互通，于是统一无歧义的语义定义变得迫切，W3C 因此提出资源描述框架 RDF。RDF 假设任何复杂语义都可以拆成若干三元组的组合，形式为“对象-属性-值”或“主语-谓词-宾语”。其中公开通用的资源都会绑定一个可识别的通用资源表示符 URI。DBpedia 中用 RDF 三元组表示的例子如下：

## 2.3 知识图谱中的知识表示方法

### 2.3.1 表示框架
一个知识本体通常涵盖以下内容：

- 事物：客观世界中的实体或对象，如“莫泊桑”“曼谷”“唐山大地震”；
- 概念：具有相似本体特征的一类事物，也称类型，如“作家”“城市”“地震”；
- 属性：事物或概念的特征，如“国籍”“地理位置”“震级”；
- 关系：概念与实体间的关联方式，如“类-子类”“类-实例”；
- 函数：事物或概念间转化的形式表达，如国籍(莫泊桑)=“法国”中的国籍(X)；
- 约束：断言成立的限制条件形式化描述，如属性“国籍”的值必须为“国家”类型实体；
- 规则：依据断言进行逻辑推论的形式化描述，通常为“如果…那么…”；
- 公理：永远为真的断言。

目前大部分知识图谱主要建模前四类，即事物、概念、属性与关系，只有少数涉及简单规则结构，这也反映出不同层次知识在表示上的复杂程度差异。
