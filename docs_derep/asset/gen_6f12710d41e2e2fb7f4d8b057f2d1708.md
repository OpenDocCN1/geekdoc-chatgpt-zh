# 第1章 DeepSeek崛起：掀起AI新浪潮

2025年科技浪潮涌动，来自东方的“蝴蝶”DeepSeek扇动翅膀，在全球AI版图激起千层浪。其崛起堪称传奇，DeepSeek-R1发布仅一周即新增1亿用户，增速远超ChatGPT等产品初期。它的推理大模型把“提问—回答”二阶模式升级为“提问—拆解—回答”三阶模式，树状推理赋予其强大的解题能力，正开启人工智能变革的大幕。

## 1.1 蝴蝶效应引爆AI变革

2025年1月27日，纽约交易所电子屏上刺目的红色数字格外醒目，英伟达股价单日暴跌近17%，市值一日蒸发5890亿美元，创下美股历史上最大单日市值损失纪录。美媒认为，引发这场风暴的关键因素，竟是1月20日才发布的中国AI产品DeepSeek。

全世界都在问：这款仿佛凭空出现的产品为何能震动美股？

看一组用户增长数据：据QuestMobile统计，DeepSeek-R1于2025年1月20日发布，当月累计用户达1.25亿，其中超80%的增量集中在月末一周，7天内实现1亿新增。

横向对比：ChatGPT达成1亿用户用了2个月，TikTok用了9个月，拼多多用了10个月，微信用了1年2个月。

更具影响力的是DeepSeek的开源低价策略：开放多款百亿参数级模型，API定价极低，吸引微软、英伟达、华为、百度等多家巨头接入，对其技术实力投下信任票。

一场由DeepSeek掀起的AI变革序幕已然拉开。

## 1.2 DeepSeek的创始故事与团队基因

DeepSeek由杭州深度求索人工智能基础技术研究有限公司推出。公司成立于2023年7月，位于杭州，被誉为“杭州六小龙”之一，出身即瞄准通用人工智能这一前沿赛道。

目前深度求索已发布多款产品，代表作包括2024年5月的DeepSeek-V2、同年12月的DeepSeek-V3，以及2025年1月的DeepSeek-R1，后者凭借技术与体验成为标志性产品。

大众常问，研发AI需要巨额投入，初创公司如何支撑？答案要从创始人梁文锋说起。梁文锋1985年生于广东湛江，17岁入浙大读电子信息工程，硕士期间研究机器视觉。2008年金融危机期间，他敏锐捕捉到机器学习在量化交易中的潜力，主导全自动量化交易探索并取得成果。

这次经历让他认识到技术对金融的价值。2015年他创立杭州幻方科技有限公司，聚焦数学与AI量化投资，简称“幻方量化”。在他的带领下，幻方快速成长为国内国际知名的量化机构，2021年管理私募规模达千亿级。

量化投资对算力要求极高，幻方投入2亿元自研“萤火一号”AI超算，既提升投资策略精度，也为DeepSeek诞生铺路。

2023年，梁文锋决断转型AGI并创立深度求索。这并非冲动跟风，而是源于对技术趋势的深刻判断与对科技改变世界的信念。幻方量化为深度求索提供资金、技术、人才与产品支持，让新公司起步即具备独特资源优势。

深度求索的独特驱动力在于团队构成与管理哲学。成员多来自清华、北大等顶尖高校，以应届博士硕士、在读生及毕业2-3年的年轻人为核心，年龄25-35岁，工作经验1-5年，呈现“名校背景+高潜年轻”特征。团队规模约140人，工程师与研发占比超90%，多名成员获国际竞赛奖项并在自然语言处理等领域发表顶会论文。

管理上采用扁平化自组织模式，去KPI化，梁文锋明确表示没有传统指标，考核聚焦技术突破而非量化产出，员工可自由选择研究方向，资源分配依据技术潜力而非短期效益。

这样的组合赋予团队持续创新的活力。DeepSeek在技术上亦有显著突破，研发出DeepSeek MoE架构与多头潜在注意力等前沿技术，大幅提升性能。以DeepSeek-V3为例，训练成本仅557.6万美元，便大幅缩小与GPT-4的差距，成本约为行业平均的1/20。核心在于算法优化而非堆砌算力，例如动态路由算法降低了专家模型间通信开销，提升资源效率。

## 1.3 DeepSeek如何重塑大模型操作体验

人工智能可按功能目标与输出形式划分。丁磊在《生成式人工智能：AIGC的逻辑与应用》中将之分为决策式与生成式。

决策式AI依据既定条件判定，人脸识别是典型代表，通过采集图像、提取特征并与库中数据匹配实现识别，便利但受限于规则，缺乏创造。

生成式AI则在2017年Transformer技术提出后兴起。谷歌论文《Attention Is All You Need》点燃研究热情，OpenAI相继推出GPT-1，2022年基于GPT-3推出ChatGPT。ChatGPT两月内用户破亿，极大改变人机交互，成为里程碑。如今ChatGPT、豆包、通义千问等均属此类。

DeepSeek横空出世后带来新类型：推理大模型。与ChatGPT类模型相比，其差异在用户体验端尤为明显：DeepSeek在提问后增加拆解环节，将“提问—回答”升级为“提问—拆解—回答”，形成显性化的认知中间层。用户不仅能看到答案，也能看到分析与推导过程，获得感显著增强。

这种可视化源于底层技术创新。ChatGPT类模型多用链式推理 Chain-of-Thought，如同沿直线行走，把复杂任务拆成依次相连的步骤。若中间某步出错，后续推导会像多米诺骨牌般全盘错误。

DeepSeek采用树状推理 Tree-of-Thought，构建类似大树的思考结构。面对复杂问题，它并行探索多个推理路径，每个分支代表一种思考方向，模型评估各分支合理性并筛选最优路径深入，最终综合得出答案。

尽管同属生成式AI，二者在推理技术与体验上差异明显。可将ChatGPT类模型归为链式推理大模型，DeepSeek归为树状推理大模型，形成清晰分类图谱。
