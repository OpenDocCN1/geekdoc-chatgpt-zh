- 缺少 pandas：确认 Python 环境装了 pandas 与 openpyxl，可用 `exec:python -c "import pandas"` 检查。
- 邮件发不出去：检查账号、密码或授权码是否正确，确认 SMTP 服务已开启；建议在脚本里加入异常捕获，处理认证失败或连接被拒。
- 定时任务没执行：核对时区设置，用 `openclaw cron list` 查看状态。
- exec 被禁用：检查配置里的 `tools.deny` / `tools.allow`，确保 exec 未被阻止。
- 端口冲突：确认 Gateway 端口未被占用，可用 `openclaw gateway status` 查看。
