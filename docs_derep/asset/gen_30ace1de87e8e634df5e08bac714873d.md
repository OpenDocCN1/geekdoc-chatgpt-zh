### 12.2.4 图书录入功能实现

图书录入的核心是让用户扫条形码就能拿到书的详细信息、阅读心得与评论，还能一键收入个人书房。扫码这块小程序本身就提供了开箱即用的 API。

wx.scanCode 会唤起微信自带的扫码面板，把 scanType 设为 EAN_13 就只认条形码，不会被二维码误触。扫码成功后，就用之前封装好的接口去拉取图书数据。顺带一提，拉取方法会把新书自动写入云数据库，连续扫几本后再去数据库里就能看到记录。

//pages/book/book.js

import db from '../../tools/database.js'

Page({

  data: {

    book:null,

    isbn:null

  },

  onLoad: function (options) {

    let isbn = options.isbn;

    db.getBook(isbn).then((res)=>{

      this.setData({

        book: res[0],

        isbn:isbn

      });

      wx.setNavigationBarTitle({

        title: res[0].title,

      })

    }).catch((error)=>{

      wx.showToast({

        title: '获取不到图书信息',

      })

    });

  },

  onReachBottom: function () {

collect:function() {

    db.collectBook(this.data.book.isbn).then(()=>{

        wx.showToast({

            title: '添加收藏成功',

        })

    }).catch(()=>{

    });

}
