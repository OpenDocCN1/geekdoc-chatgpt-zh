挑选订阅档位时，建议把业务规模和资金预算放在一起衡量。个人练习或小型验证，免费档或入门档即可满足；面向生产环境时，付费档更合适，调用额度更高且能获得官方支持。后续使用过程中，方案也可以按需灵活调整。

9. 了解 API 使用限制和配额

不同套餐的调用上限和频率限制各不相同。上线前请先到账号中心查看当月的允许调用次数、每秒请求数等用量规则，提前规划调用节奏，避免因为超出限制而中断开发。

10. 完成账户配置

到这里 OpenAI 账号的注册与基础设置已经结束。该账号将作为后续申请访问密钥、发起调用的入口，请妥善保管登录凭证并把安全设置补齐。

访问密钥是调用 OpenAI 大模型服务的核心凭证。持有密钥后即可把文本生成、翻译等能力集成到自有应用中。以下介绍密钥的创建与管理要点，以保证开发顺畅且安全可控。

> 1. 登录 OpenAI 账户

>
> 登录后点击右上角头像，在下拉菜单中选择 API Keys 或 API 管理，名称可能随平台迭代而变化。进入后可见已有的密钥清单，或新建密钥的入口，如图 2-5 所示。

> 图 2-5 API 密钥管理页面

>
> 在管理页找到 Create new secret key / 生成新密钥 按钮，点击后系统会即时生成一串以 sk- 开头的字母数字组合，并在页面展示。
>

>

>
> （3）密码管理器：使用 1Password、LastPass 等工具加密保存，便于统一管理。

> 5. 管理 API 密钥
>
> 开发中常需多密钥协同，常见操作包括：
>
> （1）查看已生成的密钥：在管理页可列出全部密钥，显示创建时间及部分掩码信息以便区分。
>
> （2）命名密钥：建议为每个密钥加上用途说明，如“测试项目密钥”“生产环境密钥”，多人协作时更清晰。
>
> （3）密钥配额和调用情况：管理页会展示各密钥的调用量与剩余配额，需定期检查以避免受限。

> 6. 删除 API 密钥
>
> 密钥废弃或出于安全考虑可删除，步骤如下：
>
> 01 在密钥列表中定位目标密钥。
>
> 02 点击旁边的 Delete / 删除。
>
> 03 系统会弹出不可恢复的确认提示，确认后密钥立即失效。
>
> > 提示 删除前确认无项目仍在依赖该密钥，删除操作不可撤销，密钥无法恢复。

> 7. API 密钥安全管理建议
>
> （1）禁止在代码中写死，建议存于环境变量或安全存储，运行时读取。
>
> （2）避免把密钥推送到代码仓库，即使是私有库也不宜上传；若误传需清理历史记录并重建密钥。
>
> （3）定期轮换密钥，团队共享场景下更应高频更换并同步更新配置。
>
> （4）持续监控调用次数与异常行为，发现异常立即停用并重新生成。
