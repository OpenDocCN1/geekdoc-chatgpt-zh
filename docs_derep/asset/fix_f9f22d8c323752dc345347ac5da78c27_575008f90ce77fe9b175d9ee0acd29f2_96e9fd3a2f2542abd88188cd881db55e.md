对话中出现了一个经典提问：是否能把 √2 写成两个整数的比值，对方记得可能涉及归谬或递降的思路却记不清细节。

下面给出一种常用的推导思路。首先把“可写成分数”具体化，设 √2 = p/q，其中 p 与 q 互为素数关系且 q>0。两边平方得到 2q² = p²，可知 p² 被2整除，于是 p 本身能被2整除，写成 p = 2r。代入后化简为 q² = 2r²，由此 q 也能被2整除。

这样 p 与 q 同时含有因子2，与起初的互素设定冲突，说明最初的假定不成立。换种说法，若真存在这样的 p、q，就能构造出更小的正整数对，这一过程可以无穷进行下去，在自然数范围内是不可能的，于是原假设被排除。

再次回顾：由等式推出 p 可被2整除，再推出 q 可被2整除，矛盾成立。由此可以断定 √2 不能表示为分数，属于非有理数。

根号2是无理数。

**证明过程：**

采用反证法。假定根号2是有理数，则存在一对互质的正整数 a、b 使得根号2 = a/b。

1. 平方两边：
\[ (\sqrt{2})^2 = \left(\frac{a}{b}\right)^2 \]
即
\[ 2 = \frac{a^2}{b^2} \]

2. 乘以 b²：
\[ 2b^2 = a^2 \]
于是 a² 为2的倍数，a 必为偶数，记 a = 2k。

3. 代入可得：
\[ (2k)^2 = 2b^2 \]
即
\[ 4k^2 = 2b^2 \]
化简为
\[ 2k^2 = b^2 \]
所以 b² 也为2的倍数，b 同样为偶数。

4. a 与 b 同时被2整除，与互质的前提矛盾，故原假设不成立。

因此根号2不属于有理数，是无理数。 < | end_of_sentence | >
