局部线性嵌入的核心假设是，每个样本都可以由它周围邻居的线性加权组合来重建，这种方式能让降维后的数据更好地保留原有的流形结构。实现上大致分为三步：为每个样本寻找 k 个近邻，基于这些邻居计算局部重建权重，再利用权重和邻居得到该样本的低维输出。尽管理论上合理，但在真实的工业落地里，局部线性嵌入的应用并不算多见。

#### 2.3.4 特征构造的关键作用
特征构造要紧扣项目业务属性和数据本身的特点，从中提炼出对模型真正有用的信号。这是提升效果最直接的环节，但这类经验很少靠书本就能学会，多靠真实项目积累。下面用三个例子说明。

比如要预测商场的未来销售额，周末与节假日就是很强的信息，需要用独热或单独编码的方式把它提炼成独立特征。

比如客户关系管理场景，最近一次消费的间隔时长、消费频率、消费金额这三项指标很关键。如果原始表里没有，就得基于原始记录自行算出来。

比如预测交通流量，早晚高峰时段、道路宽度、红绿灯数量都是典型的重要特征。

### 2.4 过拟合、欠拟合与正则化
训练过程中很容易出现过拟合：训练误差持续下降，但验证误差却开始上升。起初训练不足时，模型拟合能力弱，偏差较大。随着训练加深，模型逐渐学会训练数据的扰动，拟合能力增强。再训练下去，模型对训练数据的细微噪声都过度敏感，就出现了过拟合。

#### 2.4.1 过拟合与欠拟合怎么区分
欠拟合是指模型在训练集上都无法得到足够低的误差，往往因为特征维度太少，拟合函数表达力不足。

过拟合是指训练误差和测试误差的差距过大，模型在训练集上表现不错，在测试集和新数据上泛化能力差。

所有旨在降低测试误差的策略都可归为正则化方法，只是代价可能是让训练误差升高。

#### 2.4.2 如何缓解欠拟合
降低欠拟合风险主要有三类做法。

- 1) 引入新特征，深度学习里常借助因子分解机、子编码器等手段。
- 2) 提升模型复杂度，线性模型可加入高次项，深度模型可增加网络层数和神经元数量。
- 3) 减小正则化项的系数，从而增强模型的学习能力。

#### 2.4.3 过拟合常用对策
### 1. 正则化手段
正则化包括 L₁ 正则化、L₂ 正则化以及二者的混合。

L₁ 正则化的目标是减小参数绝对值之和，定义为：
‖x‖₁ = Σᵢ |xᵢ|

L₂ 正则化的目标是减小参数平方之和，定义为：
‖x‖₂ = Σᵢ xᵢ²

混合 L₁ 与 L₂ 正则化的定义为： α‖x‖₁ + (1−α)/2 ‖x‖₂

坐标轴上，因此每一维的参数都不会是0。

正因为 L1 会让参数趋向于零，它常被用于特征选择。而机器学习里最常用的正则化是对权重施加 L2 范数约束。

L1 与 L2 还有一个本质区别：L1 可由假设权重 w 的先验分布为拉普拉斯分布并用最大后验概率估计导出，L2 可由假设权重 w 的先验分布为高斯分布并用最大后验概率估计导出。

事实上，后验概率函数是在似然函数基础上加上 logP(w)：
MAP=logP(y|X,w)P(w)=logP(y|X,w)+logP(w)

P(w) 的含义是对权重系数 w 的概率分布先验假设，收集到训练样本后，可据 {X,y} 下的后验概率对 w 进行修正，从而得到更好的估计。

假设权重 w 的先验是 0 均值的高斯分布，即：
w_j ~ N(0, σ²)

则有：
log P(w)=log ∏_j p(w_j)=log ∏_j [1/√(2πσ) e^{-w_j²/(2σ²)}]= 1/(-2σ²) Σ_j w_j² + C

此时 logP(w) 的效果等价于在代价函数中加入 L2 正则项。

假设权重 w 的先验是均值 0、参数为 a 的拉普拉斯分布，即：
P(w_j)=1/√(2a) e^{-|w_j|/a}

则有：
log P(w)=log ∏_j p(w_j)=log ∏_j [1/√(2a) e^{-|w_j|/a}]= -1/a Σ_j |w_j| + C

此时 logP(w) 的效果等价于在代价函数中加入 L1 正则项。

### 2. 批归一化
Batch Normalization 是一种在深度学习中降低泛化误差的正则化手段，主要通过缓解梯度消失来加速训练、遏制过拟合，并降低对参数初始化的依赖。

训练数据与测试数据的分布差异会损害泛化能力，所以需要在训练前对输入做归一化。由于神经网络各隐藏层的参数不同，下一层的输入变化会导致每批数据的分布也随之漂移，使得网络每次迭代都要去适应不同的分布，增加训练难度和过拟合风险。

Batch Normalization 通过对数据分布施加额外约束来增强泛化，同时破坏了之前学到的特征分布，因而也会削弱拟合能力。为此引入重构变换来恢复最优输入分布：
$y_k = BN(x_k) = \gamma \hat{x}_k + \beta = \gamma \frac{x_k - E[x_k]}{\sqrt{var[x_k] + \varepsilon}} + \beta$
其中 $\gamma$ 和 $\beta$ 为可训练参数。

### 3. Dropout 随机失活
Dropout 是通过修改网络结构来避免过拟合的技巧，它不改变损失函数，而是随机删除部分神经元，从而降低网络复杂度，在训练大模型时非常有用。

具体做法是：每次迭代随机丢弃一部分隐层单元，输入输出层保持不变并更新权重；下一次迭代再随机丢弃另一批单元，如此循环直至训练结束。

使用 Dropout 相当于训练了海量的仅含部分隐层单元的子网络，每个子网络都能给出分类结果，随着训练进行大部分网络都能给出正确结果。

### 4. 早停策略
迭代截断即在模型对训练集收敛前主动停止迭代以防止过拟合。实现方式是在训练中记录目前为止的最佳准确率，当连续 n 个 Epoch 都没有刷新最佳准确率时就停止，n 可根据实际情况取 100、200 等。

### 5. K 折交叉验证
k-fold 交叉验证把训练样本分成 k 份，进行 k 次训练验证循环，每次用其中一份作验证集，其余 k-1 份合并作训练集。每个样本会在一次实验中作为验证样本，在 k-1 次实验中作为训练样本。每次实验都用交叉验证过程决定在验证集上表现最佳的迭代次数并选择合适参数。

### 6. 面试题速览
机器学习中 L1 正则化和 L2 正则化有什么区别（ ）。

- A. 使用L1可以得到平滑的权值，使用L2可以得到平滑的权值
- B. 使用L1可以得到稀疏的权值，使用L2可以得到平滑的权值
- C. 使用L1可以得到平滑的权值，使用L2可以得到稀疏的权值
- D. 使用L1可以得到稀疏的权值，使用L2可以得到稀疏的权值

#### 2.5.2 偏差方差从哪来
偏差往往源于模型复杂度不足或对学习算法做了错误假设。例如真实模型是三次函数，却假设为二次函数，就会导致欠拟合，偏差增大；训练误差主要由偏差造成。

方差通常由模型复杂度过高引起。例如真实模型是简单二次函数，却假设为五次函数，就会导致过拟合，方差增大；由方差引起的误差主要体现在测试误差相对训练误差的波动上。

#### 2.6.1 SGD 与小批量 SGD
标准梯度下降每次用全部训练样本的平均损失来更新参数，若样本量巨大计算成本很高。随机梯度下降每次只用单个样本的损失来近似平均损失。

由于 SGD 只用部分样本估计梯度，估计精度不高，常出现偏差，导致收敛不稳定甚至不收敛。

小批量随机梯度下降为降低随机梯度的方差、使迭代更稳定，使用一批随机数据的损失来近似平均损失。批量训练还能利用矩阵运算和并行计算框架。通常批大小取 2 的幂，如 32、64、128、256 等，以充分利用矩阵运算。
