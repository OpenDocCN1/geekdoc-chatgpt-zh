## 4. 社交互动

ChatGPT 也可作为闲聊伙伴，是一个不错的倾诉对象或谈话搭子。通过调用 OpenAI 的开放接口，还能将其集成到第三方应用中提供聊天机器人服务。它还能辅助现实中的人际互动，提升社交技巧与自信心。比如你认识了新朋友，不知聊什么，就可请它提供话题建议。

> 我认识了几位新朋友，请给我五个聊天互动的主题。
与新朋友交流时挑选合适的话题能让氛围更轻松，也能让对话自然流畅。下面是五个适合多数场合的主题。
1. 旅行经历：几乎每个人都有旅行向往或经历。可以询问对方最近的或最难忘的旅行，来开启愉快对话。你可以问：“你最近去哪里玩过？” 或 “你的理想旅行目的地是哪里？”
2. 美食分享：美食是安全共识的话题。可聊近期尝试的新餐厅，或交流烹饪技巧与食谱。例如：“你最爱的菜是什么？” 或 “最近在家尝试过什么新做法？”
3. 电影、剧集或书籍：文化作品总能引发谈资。可问对方近期看过的影视作品，或是否有书单推荐。比如：“最近有什么好看的电影或剧集？” 或 “有值得推荐的书吗？”
4. 兴趣爱好：了解对方的业余爱好有助于找到共鸣点。可问：“你平时喜欢做什么？” 或 “你有什么特别的爱好？”
5. 时事新闻：谈论时事能促成深度交流，但应避开争议性议题。最好选择轻松正面的新闻。例如：“你有关注最近的科技新进展吗？” 或 “最近有什么好消息吗？”
不同社交场景需要不同的话题。总体原则是保持轻松积极，寻找共同点，同时注意观察对方反应，若对方不感兴趣应及时转换话题。

## 第2章 提示词从入门到精通

决定 ChatGPT 对话成败的关键之一，就是启动和引导对话的提示词质量。

提示词定义得越清晰，对话就越能保持方向并覆盖用户关心的主题。反之，提示词模糊会导致对话混乱、缺乏重点，信息价值下降，体验也不佳。

本章将详细讲解如何设计有效的提示词，以生成高质量对话，获得想要的结果。

### 2.1 设定提示词的原则

提示词的质量会显著影响对话的成功与否。明确的提示词能帮助对话保持正确方向，获取更有价值的信息。那么提示词到底是什么？

#### 2.1.1 什么是提示词

在与 ChatGPT 交流时，用户提供的指令、问题或关键词短语即为提示词。它们用来引导模型生成相关回复或提供对应信息。

使用提示词的目的是让模型理解用户意图，从而给出符合需求的答案。提示词可以指明对话方向、主题或提出具体问题，使模型更准确地把握需求并作出回应。

例如，若想了解太阳系信息，可用“太阳系的行星”或“太阳系中的天体”作为提示词，这有助于模型理解你的具体关注点并生成相关回答。

#### 2.1.2 设定提示词的 3 个原则

设定有效的提示词是进行有趣且有用对话的关键。以下三个原则可帮助你打造更丰富有效的提示词。

1. **提示词要清晰明确**
使用清晰明确的提示词能确保 ChatGPT 准确理解意图并给出相关回复。设定时应避免过于复杂或含糊的表达，选用具体明确的说法。
例如：
不清晰的提示词：我想烤个东西，怎么做？
清晰的提示词：请给我一份一小时内可完成制作的巧克力蛋糕食谱。
第一个提示词模糊，“烤个东西”范围太大且未说明具体需求。第二个则明确要求快速制作巧克力蛋糕，便于模型给出针对性答案。

2. **要有明确的目的和焦点**
明确的提示词应具备清晰的目的和焦点，引导对话并保持轨道。避免使用过于宽泛或开放的提示词，否则对话易跑偏。应选择能限定范围和主题的表达。例如想了解某国文化，可用“……的传统节日”或“……的美食特色”来聚焦。

3. **要保持相关性和连贯性**
提示词应与用户及对话上下文相关。避免引入无关主题分散内容。提示词最好延续已讨论的内容或用户的兴趣，以便模型提供相关有用的信息并保持连贯。例如前文在谈旅行，可用“最佳旅行目的地”继续展开。

遵循这些原则可设定更有效、连贯的提示词，提升互动质量。

#### 2.1.3 有效提示词 vs 无效提示词

为更好理解设定原则，下面对比有效与无效提示词的示例。

1. **有效提示词**
“你能概括文章《运动的好处》的主要观点吗？”
该提示词目标明确、相关性强，模型易于提供所需信息。
“重庆有哪些知名的火锅店？”
具体且相关，模型可给出有针对性的回答。

2. **无效提示词**
“你能告诉我关于世界的什么信息？”
过于宽泛开放，模型难以给出有重点的回答。
“你能帮我做作业吗？”
虽清晰具体但缺乏具体指令，无法产生有用输出。更有效的说法应指定具体主题或任务。
“你好吗？”
常见开场白，但并非明确提示词，没有目的和重点。

通过对比可更清晰地把握有效提示词的设定要点。

#### 2.1.4 如何编写清晰简明的提示词

基于前述三个原则，编写清晰简明提示词应遵循以下要求。

1. **设定对话的目的和重点**
开始前先明确希望通过对话实现什么，即是获取信息、解答问题还是非正式聊天。明确目的有助于制定具体相关的提示词。
例如原提示“你能帮我做作业吗？”可改为：
> 你能帮我解答一道数学题吗？题目是：小明有50个苹果，教室里有7个小朋友，他每人分3个，还剩几个？
> 小明分出7×3=21个，剩50-21=29个。所以还剩29个苹果。
这样便能得到期望答案。若仅问“你能帮我做作业吗”，模型无法判断具体需求，可能仅回答“能”，并非想要的结果。

2. **使用具体和相关的语言**
为让模型理解并作出恰当回应，应使用具体相关的语言，避免术语或模糊表达导致混淆。
例如“你能给我一些关于互联网的最新动态吗？我正在努力掌握时尚潮流”，中“最新动态”“互联网”“时尚潮流”未作清晰界定，可能让模型困惑。
可改为聚焦具体领域提问，如人工智能在自动驾驶的最新进展：
> 你能介绍人工智能在汽车自动驾驶领域的最新进展吗？
> 以下是我从网络整理的相关进展...
信息显示该领域技术不断突破并在实际应用中展现潜力。

3. **避免使用开放式或过于宽泛的提示词**
开放式或宽泛问题虽可能获得全面回应，但常导致对话不连贯或失焦。能限定范围的提示词更有利于设定清晰目的与重点。
例如“你能告诉我关于这个世界的一些事情吗？”话题太宽。可改为“你能告诉我地球是如何形成的吗？”
> 地球约在45亿年前形成，下面是简化的形成过程...
过程涉及星云收缩、太阳诞生、原行星盘形成、行星胚胎凝聚、行星形成、分化冷却、大气与海洋形成等多个环节。

4. **让对话保持在正确的轨道上**
交流时应聚焦当前主题，避免离题或引入无关内容。保持方向一致有助于模型覆盖用户感兴趣的主题并提供有用信息，提升体验。
沿用地球形成的问题，若对原行星盘不理解可继续追问：
> 原行星盘形成：太阳周围形成旋转盘状结构，包含岩石、冰等固体微粒。请解释这个过程。
> 原行星盘是行星形成的关键阶段...包括太阳诞生、角动量守恒、盘状结构形成、温度化学分布、物质凝聚、行星胚胎形成等步骤...
通过连贯问答即可逐步建立对地球形成的知识体系。

遵循以上要求即可设定清晰简明的提示词。
