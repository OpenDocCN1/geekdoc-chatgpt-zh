### 3.3.5 小结

## 1. 函数和数据透视表的区别

函数和数据透视表是数据分析中两种核心工具，二者在功能、操作、使用场景等方面存在差异，见表 3.6。

表 3.6 函数和数据透视表的区别

| 方面 | 函数 | 数据透视表 |

| :--- | :--- | :--- |

| 功能特性 | 用于执行特定计算或操作并返回结果值 | 用于快速汇总、分析和展示数据，提供动态视图 |

| 操作方式 | 需手动编写公式，输入函数名与参数 | 通过界面拖拽字段至行、列、值区域操作 |

| 使用场景 | 适合精确计算与单点数据处理 | 适合对海量数据做快速汇总与多维分析 |

| 灵活性 | 函数种类丰富，可嵌套实现复杂计算 | 布局与汇总方式可灵活调整，适应不同分析需求 |

| 结果展示 | 直接返回计算结果，常为单值或数组 | 以表格形式呈现，直观展示数据关系 |

函数适用于需要精确计算的场景，可通过公式实现复杂运算；数据透视表更擅长对大量数据的快速汇总与多维洞察，仅需拖拽即可生成动态视图。实践中可根据需求选择或组合使用。

## 3.4 DeepSeek 数据可视化

### 3.4.1 数据可视化介绍

数据可视化是将数据转化为图形或图像的技术，帮助人们直观理解信息、模式、趋势与洞察。通过图表、图形、地图、仪表盘等视觉元素，复杂关系与海量数据变得易于解读。

借助柱状图、折线图、饼图、散点图、热力图等，数据更直观。现代可视化工具支持交互，允许用户缩放、筛选、排序以深入探索。优秀的可视化能讲述数据故事，突出关键信息。

因此，数据可视化具备视觉效果佳、可交互、故事性强的特点。

### 3.4.2 常见的数据可视化图表

常见图表包括柱状图、折线图、散点图、条形图、饼图和漏斗图，其特点与应用场景如图 3.70 所示。

[PRE29]

各图表的具体特点如下：

#### 1. 柱状图 Bar Chart

柱状图用于比较不同类别数据，通过柱长直观呈现数值大小。适用于离散数据对比，能快速发现差异。也可做簇状与堆叠以呈现更复杂关系。

#### 2. 折线图 Line Chart

折线图擅长表现数据随时间或连续变量的变化趋势，通过连线展示上升、下降或平稳。常用于时间序列，如股价波动；多条折线可比较不同系列的关联与差异。

#### 3. 散点图 Scatter Plot

散点图在坐标系中绘制数据点，展示两个变量间关系。通过点分布可判断相关性、强度与方向，适用于探索性分析，为后续建模提供依据。

#### 4. 条形图 Bar Chart

条形图以水平条形展示数据，适合类别较多或名称较长的情况，通过条长比较数值大小。例如用于展示各产品市场份额，直观看出主导产品。

#### 5. 饼图 Pie Chart
