1. 用户质量高、消费力强，能卖高价商品。
2. 种草属性强、内容领域多元、入门门槛低。
3. 用户购买意愿强、品牌投放需求大、对新手变现扶持力度大。
4. 算法友好，无需出镜拍视频，零粉也能出爆款笔记。
