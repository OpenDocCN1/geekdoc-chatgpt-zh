void quickSort(int arr[], int l, int r) {

    if (l >= r) return;

    int pivot = arr[l], i = l, j = r;

    while (i <= j) {

         while (arr[i] < pivot) i++;

         while (arr[j] > pivot) j--;

         if (i <= j) swap(arr[i++], arr[j--]);

    }

    quickSort(arr, l, j);

    quickSort(arr, i, r);

}

3. 复杂度分析
平均水平约为 O(n log n)。最坏情形会退化到 O(n²)，通常出现在数组接近有序的状况。递归调用栈所耗空间为 O(log n)。

1）全局变量声明

int n, m; // n 为串长，m 为最大子集大小

int dp[1 << M]; // 状态压缩 DP 表
P 用作取模常数防止溢出。dp 的规模为 2^M，用来存放所有压缩状态的结果。

2）solve 函数——状态压缩动态规划
int solve() {
    dp[0] = 1;
    for (int i = 0; i < n; ++i) {
         for (int j = (1 << (m - 1)) - 1; j >= 0; --j) {
              int k = (j << 1) | (s[i] - '0');
              if (j != 0 || s[i] == '1')
                   dp[k] = (dp[k] + dp[j]) % P;
         }
    }
    int ans = 0;
    for (int i = 0; i < (1 << m); ++i) {
         ans = (ans + 111 * i * dp[i]) % P;
    }
    return ans;
}
外层按字符遍历，内层逆序遍历状态，左移一位再拼接当前字符实现转移，并在非空或当前字符为 1 时累加。最后对所有状态按权重 111*i*dp[i] 求和取模。

功能说明：
外层遍历模拟 2^n 个子集的生成，内层通过位运算 i&(1<<j) 判断选取情况并构造二进制数值。仅当子集元素数不超过 m 时才计入累加。

3）solve2 函数——枚举法
int solve2() {
    int ans = 0;
    for (int i = 0; i < (1 << n); ++i) {
         int cnt = 0;
         int num = 0;
         for (int j = 0; j < n; ++j) {
              if (i & (1 << j)) {
                   num = num * 2 + (s[j] - '0');
                   cnt++;
              }
         }
         if (cnt <= m) (ans += num) %= P;
    }
    return ans;
}
子集枚举：用 i 的二进制位表示是否挑选字符。元素组合：把被选字符拼接成二进制数。筛选条件：选中个数要 ≤ m。最后把合格数值累加取模。

4）主函数——输入与流程控制
int main() {

    cin >> s;
    if (n <= 20) {
         cout << solve2() << endl;
    }
    cout << solve() << endl;
    return 0;
}

【编程魔法师讲解考点】
一、状态压缩动态规划
定义：用整数二进制位压缩状态，减少空间与时间开销。
核心思想：用一位二进制表示一种选择，通过左移、按位与或实现转移。

复杂度：O(n×2^m)。

二、枚举法
定义：穷举所有可能情况寻找满足条件的解。
关键技巧：用二进制表示子集，结合位运算快速判断。
本例应用：solve2 用 i 的二进制位决定字符是否被选，再拼接数值并按 cnt≤m 筛选。
复杂度：O(2^n×n)。
