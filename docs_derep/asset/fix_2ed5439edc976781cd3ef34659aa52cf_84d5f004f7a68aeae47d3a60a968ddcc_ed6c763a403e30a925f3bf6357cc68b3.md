从法理层面理解，司法就是国家凭借公权力，对已进入诉讼程序的纠纷作出终局性裁判的活动。平实地说，司法等同于国家的审判工作，司法权即审判权，其要义在于居中裁判并借助个案实现法律价值的最终保障，承办机构即审判机关。^([\[38\]](#txt006.html#footnote_content_txt006_38))实践中法官多因技术壁垒难以有效约束技术的滥用与失控，于是技术人员便可通过算法设计与植入，实质上瓜分司法权，部分扮演起“影子法官”的角色。更为棘手的是，此类算法在技术上难以解释，形成黑箱；在价值上又不可避免地渗入研发者的先入之见乃至偏见，即算法偏见，并以机器规模化运行推动司法进程，这种状态既不为现行司法制度所容纳，也难以获得公众认同。相关风险已现端倪。威斯康星州的 State v.Loomis 案即为例证，州最高法院虽驳回被告以 COMPAS 量刑系统侵害正当程序与平等保护为由的上诉，但学界仍持续质疑：公共职能的过度算法化，将因法律黑箱与技术黑箱冲击正当程序、平等保护与透明度，把公共权力无限制且未经审查地外包给人工智能，会侵蚀人权与法治根基。^([\[39\]](#txt006.html#footnote_content_txt006_39))《哈佛大学法律评论》的研究进一步指出其中的悖论，要求法官对本就用于矫正司法偏见的工具再作“偏见审查”本身就令人不安，法官并不具备相应的信息与能力。故需采取更严格的遏制手段，例如先排除算法黑箱风险、在充分研究后才允许使用，以抵消新技术带来的负面效应。^([\[40\]](#txt006.html#footnote_content_txt006_40))除价值层面外，技术人员在司法逻辑内部开发的“要素式审判”“知识图谱”等应用，也因认知局限易陷入简化实体审判的误区。比如道路交通事故损害赔偿纠纷中的精神损害抚慰金确定，就不宜套用程式化逻辑推演，而应结合侵权人的主观恶性、受害人实际损害情形等具体情境综合权衡。目前我们更多停留于直观感受人工智能司法应用的高效逻辑及其潜在负面影响，却在理论上尚未给出有力回应：司法改革强化人工智能，是否会使司法权分裂为司法权力与技术权力；法院组织层面如何对司法权作出有效配置；人工智能技术人员是否将成为新型司法辅助人员，其与法官关系如何定位。回溯 2017 年《人民法院组织法》《法官法》修订时，就已有学者呼吁，人工智能时代的变化并未充分反映在立法文本中，具体涉及数字信息处理部门、电脑工程师等司法辅助机构及其人员权利义务、在法律与计算机程序编码及大数据算法主导下如何坚持法官“有思考的服从”、判决自动生成技术如何与法律解释和法律沟通相兼容等问题。^([\[42\]](#txt006.html#footnote_content_txt006_42))未来立法与司法实践中，这些问题无法回避，会在不同环节具体显现，司法必须提前准备并作出正确反制，从而把人工智能的司法运用限定在可接受的合理区间。

### 三、基于国家安全的反制
从长周期视角看，依托大数据智能分析以及信息论、系统论的思维方式，人工智能将强力推动司法功能的转型。传统上，定分止争被视为司法核心功能。若以系统观审视，司法不仅是对个案的裁判，更是社会治理体系的重要构成。通过个案裁判产生制度性外溢，往往是拓展司法社会治理职能的关键路径。因各国司法制度与法律传统差异，这种拓展呈现不同样态：判例法国家里，判例本身构成具有法律效力的规则体系，司法直接介入社会治理；非判例法国家则多更间接迂回，如我国法院体系便通过司法解释、指导意见、司法建议、调研报告、新闻发布等方式参与其中。在人工智能的推动下，司法的定分止争功能将被进一步拓展为更宽广的社会治理功能。相关研究虽少，但国内已有法院利用人工智能形成社会纠纷根源的数据研究报告，并积极参与府院联动的源头治理。源头治理很好地发挥了人工智能的信息工具优势，摆脱了“案海战术”的困境，从社会治理层面最大化提升了司法效率。

然而福祸相依，司法社会治理功能的扩展以大数据为支撑，难免产生外溢风险，进而威胁国家安全。其一，司法大数据与商业大数据不同，具有极强的公共属性，其公开、存储、流转、开发、利用应以何种主体为载体、以何种方式进行，都是亟待深入探讨的关键问题。令人担忧的是，商业领域的数据垄断与“数据杀熟”逻辑也可能复制到司法领域，一旦智慧法院建设中的平台设施及相关数据受制于或依赖于网络技术公司，则当事人信息乃至审判秘密的安全都可能受威胁。侯猛对此指出：“利用互联网技术进行网上审判的创意，最早就来自于阿里巴巴公司，且杭州互联网法院是依托阿里巴巴建立诉讼平台来运行的……这既影响了阿里巴巴等平台公司与其他公司之间的非对等地位，如阿里巴巴公司的竞争者为防止数据被监控或泄露，会拒绝在该法院进行网上审理，也增加了法院自身被技术公司俘获的可能。”^([\[43\]](#txt006.html#footnote_content_txt006_43))其二，司法作为国家政权体系中的一种权力，必然带有政治烙印与意识形态色彩，这决定了对司法大数据的智能化运用必须具有正当目的，尤其要考虑国家安全维度。利用大数据等智能分析手段策划“颜色革命”或开展政治渗透，已不再是传闻，而是现实存在。在民族国家博弈的背景下，政治斗争与经济竞争长期并存，他国完全可能利用可轻易获取的司法大数据，并经由人工智能处理后，进行政治渗透与意识形态层面的“造势”。更进一步，从现实来看，我国大数据等相关技术目前多停留在应用层面，而网络基础设施、芯片、操作系统与网络服务等更关键的底层要素仍主要掌握在美国手中^([\[44\]](#txt006.html#footnote_content_txt006_44))，此类风险更应引起决策层的高度警惕。严格而言，技术俘获司法、意识形态输入等外溢风险已超出司法自身范畴，关乎国家安全。但正因司法是社会治理的重要组成，以国家安全为基础对人工智能司法应用划定边界，实属必要。
