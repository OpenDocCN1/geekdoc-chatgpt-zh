# 原码、反码、补码 一眼分清

原码的结构是最高位做符号，其余位放绝对值。正数符号位写0，负数符号位写1，剩下 n-1 位为真值绝对值的二进制表示。零在原码里出现两种写法：+0 的原码为 00000000，-0 的原码为 10000000

直观上，原码和真值来回转换几乎无脑，乘除这类运算也很顺手。加减就麻烦了，遇见同号相减或异号相加时必须先比大小，用数值大的去减小的，符号沿用数值大的那一方。这种额外判断会让运算器变复杂，双零并存也会带来判断上的歧义。

## 2.2　计算机信息编码

数字化信息编码是用少量二进制符号按约定规则组合，来表达大量复杂信息的方法。按信息种类可分为字符编码、数值编码、汉字编码、多媒体编码等。

### 2.2.1　字符编码

计算机处理的不仅是数值，还有大量符号文字等非数值信息，必须把字符映射到二进制。给字符编号再用二进制表示编号的过程即字符编码。

#### ASCII 编码

ASCII 即美国信息交换标准代码，后被 ISO 采纳为国际通用字符方案。用7位二进制表示128个字符，2⁷=128。每个编码转成十进制后的数称为该字符的 ASCII 值。ASCII 表见表 2.2。

128 个字符分两类：可显示或可打印的95个和控制字符33个。可显示字符包含0～9数字、a～z、A～Z字母、+ - ≠ / 等运算符号、。、？，； 等标点、# % 等商用符号，共95个，可通过键盘输入并在屏幕或打印机呈现。

控制字符用于数据通信的传输控制、打印或显示格式控制、外部设备操作控制等特殊功能，本身不可见。ASCII 共33个控制字符，例如编码7DH 的 DEL 用于删除，编码08H 的 BS 用于退格。ASCII 编码表共24行、23列，低4位 d4d3d2d1 做行编码，高3位 d7d6d5 做列编码。

数字0到9的编码集中在第3列011，从第0行0000到第9行1001排列，即“0”的ASCII 为 (0110000)₂=(30)₁₆，“9”的ASCII 为 (0111001)₂=(39)₁₆。屏蔽高3位后，低4位恰好是0～9的二进制，转换很方便。

#### EBCDIC 编码

EBCDIC 即扩展的二/十进制交换码，采用8位表示一个字符，可表示2⁸=256个符号。实际使用并未全部占用，部分预留扩充。EBCDIC 常用于 IBM 大型机。该码制里数字0～9的高4位均为1111，低4位依次为0000到1001，屏蔽高4位后即可方便得到二进制数值。

### 2.2.2　数值编码

数值编码是用二进制按一定规律描述十进制数。最常用的是8421码，也称 BCD 编码。用4位二进制表示一位十进制数，从高到低位权为2³、2²、2¹、2⁰，即8、4、2、1。

BCD 编码既能以二进制满足数字系统要求，又保留十进制特点，仅有10种有效状态，部分场合可直接运算。

常见 BCD 编码有以下几种。

#### 8421 BCD 编码

8421 BCD 是最广泛使用的 BCD 编码，是一种有权码，各位权从高到低为8、4、2、1。有效编码只有0000～1001共10个，1010、1011、1100、1101、1110、1111这6个编码为无效编码。

#### 2421 BCD 编码

2421 BCD 也是有权码，从高到低权为2、4、2、1，也可用4位二进制表示一位十进制数。

#### 余3码

余3码是无权 BCD 编码，每个码值与对应8421 BCD 相差3，故称余3码，使用较少，仅作了解。

### 2.2.3　汉字编码

汉字数量庞大，常用字符数千个，一个字节8位不足。现有的汉字编码方案有2字节、3字节甚至4字节。在汉字处理系统中，输入、内部处理、输出对汉字要求不同，需要进行输入码、国标码、机内码、字形码之间的转换。

#### 国标码

1981年国家标准局制定了 GB2312-80，即《信息交换用汉字编码字符集》。该编码称为国标码。字符集共收录7445个字符符号，其中一级常用汉字3755个，二级常用汉字3008个，西文和图形符号682个。

GB2312-80 规定所有国标汉字与字符符号组成94×94的矩阵。每行称为一个区，区号01～94；每个区内有94个位，位号01～94。分布如下：1～15区为图形符号区；16～55区为一级常用汉字区；56～87区为二级常用汉字区；88～94区为自定义汉字区。

#### 输入码

输入码又称外码，是通过各种输入设备把汉字输入计算机时使用的编码。每种输入码对应一种输入方案。按方案可分为数字编码如区位码、字形码如五笔字型编码、音码如拼音编码以及音形混合码等，用户可自行选择。

#### 机内码

计算机内部存储和处理汉字采用统一的机内码。机内码与国标码有区别，若直接用国标码作内码会与ASCII冲突。输入时依据输入码通过计算或查表完成到机内码的转换。

#### 字形码

汉字在显示和打印时以字形信息呈现，每个汉字可写在同样大小的方块中，以点阵方式构成图形。字形码即确定汉字字形点阵的代码，也称汉字字模。

图 2.1 所示为16×16点阵的汉字“中”，用“1”表示黑点、“0”表示白点，黑白信息可用二进制表示。每个点用一位二进制表示，一个16×16字模需32字节。国标码中的6763个汉字及图形符号约需261696字节。所有汉字字形信息的集合称为汉字字库。点阵越大所需存储越大，质量越好成本也越高。当前屏幕显示一般用16×16点阵，打印输出常用32×32点阵，质量要求高时可采用更高点阵。

### 2.2.4　多媒体信息编码

信息大爆炸时代，多媒体信息无处不在。手机、影音播放器等设备都依赖多媒体编码。多媒体编码大致分为音频编码和图像编码。

## （1）音频编码

音频本身是模拟信息，时间上连续。数字声音是数据序列，需对模拟声音进行采样、量化和编码。采样即每隔一定时间间隔在波形上取一个幅度值，该间隔为采样周期，其倒数为采样频率。

### ①MIDI

MIDI 即音乐乐器数字接口，始于1982年，是数字音乐的国际标准。它以数字方式记录乐器发声，回放时使用调频或波表合成。标准多媒体PC可通过内部合成器或外接MIDI端口录入MIDI文件。用MIDI文件演奏音乐，存储需求很小，例如两分钟乐曲的MIDI文件不足8 KB。

### ②WAVE

WAVE格式记录声音波形，处理速度快、采样率高、采样字节长时，音质可接近原声。缺点是不压缩数据，文件体积巨大。

### ③MOD

MOD格式大约始于20世纪80年代初，利用Modplayer通过LPT口自制声卡或直接使用机内喇叭播放。MOD是这类音乐文件的总称，后来衍生出ST3、S3M、XT、669、FAR等扩展格式，基本原理相同。文件里既存乐谱也存音色样本。

### ④MP3

MP3基于MPEG Audio Layer 3技术，通过压缩人耳不敏感部分实现高压缩比。它是有损压缩，但能在音质损失很小的情况下大幅减小体积，因而成为网络音乐的通用格式。

## （2）图像编码

图像格式可分为矢量类和位图类。前者由几何元素和数学方法描述，后者以像素形式描述。图像主要指标为灰度、分辨率与色彩数。分辨率分为输出分辨率和屏幕分辨率，前者用每英寸像素点数表示数值越小越差，后者用每英寸行列数表示数值越大质量越好。常见色彩位有2位、4位、8位、16位、24位、32位、64位。16位可显示65536种颜色，24位可显示约1677万种颜色，即真彩。代表性格式有：

### ①BMP（bit map picture）

BMP是PC上最常用的位图格式，有压缩和不压缩两种，是Windows画图程序默认格式。通用图像软件都可访问，但文件容量相对较大。

### ②PCX（PC paint brush）

PCX由Zsoft公司创建，可压缩以节约磁盘空间，最高可表现24位图像。

### ③GIF（graphics interschange format）

GIF是一种跨平台的压缩图形格式，可在IBM、Macintosh等机器间移植，优点是兼容性好，但色彩上限为256种。因此除Animator Pro和Web网页等二维图形场景外，应用已很少。
