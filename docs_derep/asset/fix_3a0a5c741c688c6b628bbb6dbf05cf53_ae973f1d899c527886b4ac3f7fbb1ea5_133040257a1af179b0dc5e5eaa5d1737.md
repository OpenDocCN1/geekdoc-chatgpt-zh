张量的形状由维数和每维长度共同决定，通常用形状元组表示。元组长度即维数，元组里每个数对应该维的元素个数。举例说，形状 3,4 的张量是二维结构，第一维 3 个位置，第二维 4 个位置，总计 12 个元素。数组维数和向量维数的含义并不相同：数组维数指定位一个元素所需下标的个数，向量维数指向量本身包含的元素个数。因此 n 维向量常保存在形状为 n 的一维张量中，m 行 n 列的矩阵则用形状 m,n 的二维张量表示。

轮椅数据集
> 该数据集用于识别老年人或患者在轮椅上的坐姿状态。每个样本由轮椅上 3 个压力传感器与 1 个超声波传感器采集，输入维度为 4。压力传感器数值范围 0~1023，超声波传感器范围 0~15cm，分辨率 0.3cm。标签取自 1 至 4 四个整数，1 代表坐姿正常，2 代表偏右，3 代表偏左，4 代表前倾。整体样本数 308。

【实验1-1】对轮椅数据输入向量做标准化并划分训练测试集
要点：
- 数据为 308 行 5 列的表格，每行一个样本，前 4 列为输入，后 1 列为标注，标注取值 {1,2,3,4}。
- 随机抽 200 个样本作训练集，剩余 108 个作测试集。
- 按列标准化 z_ij = (x_ij - μ_j)/σ_j，其中 μ_j、σ_j 为训练集第 j 维的均值与标准差。
- 用 import torch 引入 PyTorch。
- 用 torch.tensor 复制已有数据构造张量，可通过 dtype 与 device 指定类型与设备。
- 输入建议用浮点类型如 torch.float，标签用长整型如 torch.long，并把标签映射为 {0,1,2,3}。
- 均值、标准差可用 torch.mean 与 torch.std，算矩阵各列时 dim 取 0，算各行时 dim 取 1。
- 随机重排可用 torch.randperm，之前先用 torch.manual_seed 固定种子以保证可复现。
- 用 torch.cuda.is_available 判断能否使用 GPU。
- 若后续在 GPU 上训练，需把数据搬到显存，可用张量的 to 方法。
如遇困难可参考附录 A 的注释程序。

首次在 GPU 上运行 PyTorch 时启动会稍慢，因框架会对函数做即时 JIT 编译。

【实验1-2】用 PyTorch 构建单隐含层多分类网络
要点：
- 隐含层 8 个神经元，激活函数 ReLU；输出层 4 个神经元，不加激活。
- 网络可用 torch.nn.Sequential 快速拼接，也可继承 torch.nn.Module 自定义，本书采用继承方式以便扩展。
- 在 __init__ 中创建并初始化各层参数，在 forward 中实现前向计算，反向由框架自动完成。
- 仿射变换用 torch.nn.Linear，激活用 torch.nn.functional.relu。
- Linear 的权重与偏置默认按均匀分布初始化，一般无需手工干预。
- Linear 的 in_features 对应输入的最后一维大小，out_features 对应输出的最后一维大小。
- 使用 GPU 时需把模型对象迁移到显存，用 to 方法即可。
实现细节见附录 A。

【实验1-3】基于轮椅数据在 PyTorch 中训练上述网络
要点：
- 采用批梯度下降，即每次用全部训练样本更新参数；优化器选用 AdamW，通过 zero_grad 与 step 调用。
- 多分类常用交叉熵损失，用 torch.nn.CrossEntropyLoss 计算。注意其输入应为输出层仿射的原始结果而非 softmax 后的结果，这也是输出层不加激活的原因；目标值需为 torch.long 类型，取值 0~c-1，与实验1-1 的标签映射一致。
- 学习率设为 0.1，训练轮次设为 60。
- 迭代顺序：前向 → 计算损失 → backward → optimizer.step。每次 backward 前必须 optimizer.zero_grad 清零梯度，否则梯度会累加。
- 建议调用模型对象而非直接调用 forward，以便触发已注册的钩子。
- 批训练时输入为 200×4 的二维张量。
- 记录每次迭代的损失以便绘图，保存时需从计算图分离，可用 item 或 detach。
- 绘图可用 Matplotlib。

当隐含层为 8、学习率 0.1、轮次 60、随机种子 0 时，损失随迭代的变化如图 1-3。总体上损失随迭代下降，说明训练有效；过程中有波动，因神经网络损失一般非凸。本例未手工给出偏导，却能借助 PyTorch 自动微分完成有效训练。

【实验1-4】评估模型在训练集与测试集上的分类准确率
要点：
