## 2.2 Docker 容器的基础知识

回顾计算机行业发展，Docker 被普遍视作一次关键性技术革新，标志着软件交付方式的分水岭。它采用 Client/Server 模式，核心要素包括客户端、守护进程、镜像、仓库和容器。Docker 依托操作系统内核的 namespaces、cgroups 等技术，为容器提供资源隔离与安全保障，从而实现应用的快速自动化部署。随着云原生逐渐成为主流，Docker 与 Kubernetes 已成为基础设施的事实标准，身为开发者有必要持续关注。

本节聚焦 Docker 容器的基础概念，目标是让读者掌握容器相关技能完成服务部署。若你已熟练 Docker 与 Kubernetes 编排，可直接跳过本节。

### 2.2.3 Docker 容器编排

随着 B/S 架构演进，应用从单体逐步转向微服务与分布式形态。对个人开发者而言，把应用容器化能大幅提升开发部署效率，规避环境差异与依赖冲突。在企业生产场景中，容器数量激增后，创建、调度、扩缩容、监控与安全等运维问题凸显，容器编排技术因此成为关键解法。

## 2.3 大语言模型与 NLP

人工智能一直是人类的美好憧憬。2016 年人机围棋大战让人们讨论机器是否会超越人类。几年后，2022 年 11 月 ChatGPT 3.5 发布，其强大的自然语言处理能力让人感觉模型在某种程度上“理解”了人类语言。本节先梳理自然语言处理的研究任务，再回顾传统实现路径，最后探讨大语言模型带来的改变。

### 2.3.1 NLP 的研究任务

自然语言处理是计算机科学与人工智能的重要分支，目标是让机器像人一样正确处理与理解自然语言。然而人类语言丰富复杂，存在歧义、情感与多样性，给研究带来挑战。经过长期积累，NLP 在多个领域取得进展，而大语言模型的出现进一步推动了其发展，使商业应用更简便精准。

在大语言模型主导的当下，熟悉 NLP 的经典任务对落地商业应用仍很关键。常见研究任务见表 2-6。

表 2-6 常见的 NLP 研究任务

| 研究任务 | 描述 |

| :--- | :--- |

| 分词 | 将文本分割成单词、标点符号或标记的过程 |

| 词性标注 | 赋予文本中的词对应的词性标签，如名词、动词、形容词、感叹词等 |

| 语法分析 | 分析文本中句子的语法结构，识别句子成分等 |

| 语义分析 | 分析文本中句子的含义，如情感色彩分析、消除歧义和标注角色等 |

| 信息抽取 | 从文本中提取关键信息，如关系抽取、命名实体识别等 |

| 文本分类 | 将文本标注为不同的类别，如垃圾邮件分类、新闻类别分类等 |

| 机器翻译 | 将一种语言的文本翻译成另一种语言，如英汉互译等 |

| 文本生成 | 使用算法和模型自动生成文本，如文本摘要、文案润色等 |

| 知识图谱 | 对文本进行知识抽取、知识表示、知识融合和推理 |

### 2.3.2 传统 NLP 的技术实现路径

有机器学习经验的人会发现，NLP 流程与机器学习大体相似，但在细节上有差异。下面以典型流程为例，如图 2-3 所示。

[PRE18]

（1）定义和理解研究问题

先深入业务，明确主题、目标与范围，锁定待解决的具体问题，再将其转化为可操作的 NLP 技术问题。

（2）获取语料 / 数据集

语料即语言材料，是研究的基石。语料库按来源可分为企业内部积累的数据，以及从网络下载或爬取的标准数据集、新闻等信息。

（3）语料预处理 / 清洗

对语料进行加工、清洗，保留关注内容，剔除噪声。包括提取标题、摘要、正文，去除网页广告、标签、HTML、JS 代码与注释等。

常见预处理方式有手工去重、对齐、删除、标注，基于规则抽取，正则匹配，按词性与命名实体抽取，以及脚本批量处理等。

（4）分词 / 去停用词

NLP 期望以词或词组为最小单元，因而需调用分词工具。停用词是指对特征贡献不大的字词，如标点、语气、人称等。一般分词后会去停用词，但中文需因场景而定，例如情感分析中语气词与感叹号应保留，因其承载语气与情感强度。

（5）特征工程

将分词后的词转化为计算机可计算形式，常见方法有词袋模型、One-hot 编码、Word2Vec 与 Embedding 等。实际使用时还需做特征选择，保留表达力强的特征。

（6）模型训练 / 基于规则

选定特征后进行模型训练，依据需求选择不同算法。传统机器学习包括 KNN、SVM、Naive Bayes、决策树、GBDT、K-means 等；深度学习包括 CNN、RNN、LSTM 与 Seq2Seq 等。

（7）模型评价

上线前需评估泛化能力，常用指标有错误率、精度、准确率、精确率、召回率、F1 等。

（8）部署上线

主流做法是线下训练，线上部署为接口服务，供业务系统调用。

以上即为传统 NLP 的实现路径。

### 2.3.3 大语言模型对传统 NLP 的影响

当前大语言模型在零样本或少样本条件下，仅靠提示词工程即可完成大部分传统 NLP 任务，并具备较强泛化能力，这对传统技术路径形成明显冲击。但大语言模型也存在局限：结构复杂参数庞大导致训练耗时耗资、推理难以解释、可解释性差，并可能出现幻觉、伦理与合规风险。

因此大语言模型并非包打天下，传统 NLP 在特定场景仍具重要价值。未来两者融合将共同推动 NLP 发展。
