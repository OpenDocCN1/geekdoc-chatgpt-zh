# OpenClaw：让 AI 真正会干活的本地助手

OpenClaw 在不同桌面系统上做了专门适配，文件读写、进程调度等底层操作在 Windows、macOS、Linux 上表现保持一致，兼容性问题被压到最低。同时提供命令行 CLI 和图形 GUI 两种交互形态，能兼顾习惯终端的老手和偏好可视化操作的普通用户。

任务调度打破设备边界，指令可以在手机上发出，由家里的电脑或公司的服务器去落地执行，形成“想在哪发就在哪发、想让谁干就让谁干”的灵活协作。

把这些能力叠加起来，OpenClaw 的定位就很清晰：一个能动手干活的 AI 伙伴。本地优先的架构守护数据隐私，从聊天到落地的真实执行力把对话变成行动，模型无关的设计让大模型可自由切换，模块化的技能体系降低上手成本，全平台覆盖实现场景无缝衔接，开源社区的持续贡献保证迭代速度。正是这些相互支撑的特质，让它既能服务开发者，也能给普通职场人群带来可感知的效率提升，推动 AI 工具真正走向平民化。

## 8.2 OpenClaw 安装部署

### 8.2.1 OpenClaw 安装

OpenClaw 兼容 Windows、macOS、Linux 等主流系统，其中 Windows 是大众用户使用最广泛的环境，下文以 Windows 为例演示完整部署流程。

正式安装前需要先准备 Node.js 20.0.0 及以上版本。Node.js 是 OpenClaw 核心程序与网关服务运行的基础运行时。可前往 Node.js 官网 https://nodejs.org/ 下载 Windows 安装包 .msi，双击后在安装向导中勾选“Add to PATH”，完成环境变量的全局配置。

本教程采用官方推荐的一键脚本方式，自动化完成依赖安装与程序部署，无需手动调整环境，体验更友好。

1. 步骤 1：以管理员身份启动 PowerShell
PowerShell 是 Windows 自带的终端，OpenClaw 安装脚本必须在管理员权限下运行，否则易因权限不足失败。打开开始菜单搜索“PowerShell”，在结果中右键选择“以管理员身份运行”。

2. 步骤 2：放开 PowerShell 脚本执行限制
Windows 默认会阻止第三方脚本运行，初次安装前需先修改执行策略，否则会出现“在此系统上禁止运行脚本”的提示。

### 8.3.1 批量处理文件

日常下载目录常混杂文档、视频、图片，手动整理耗时易错。OpenClaw 可通过自然语言完成识别、分类与搬迁。

示例指令：
> 分类整理 “C:\Users\xxx” 目录下的所有文件，要求：
> 文档（Word、Excel、PPT、PDF 等）存到 “文档” 文件夹，
> 视频存到 “视频” 文件夹，
> 图片存到 “图片” 文件夹，
> 其他文件存到 “归档” 文件夹，
> 不要删除文件。

在聊天界面输入上述要求后，OpenClaw 如图 8-23 所示会自动调用文件系统工具，遍历源目录、识别类型、创建四个目标文件夹，并按后缀生成 PowerShell 脚本执行迁移，源文件保留。
