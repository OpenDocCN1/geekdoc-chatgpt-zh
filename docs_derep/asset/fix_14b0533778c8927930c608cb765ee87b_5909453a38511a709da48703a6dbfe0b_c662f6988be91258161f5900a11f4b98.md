三、小红书种草类提示词构建

（一）平台特点与分发机制
小红书三大核心特征是种草氛围、社区感和垂直专业。分发主要依赖关注流、兴趣标签、搜索发现。关注流对封面和标题吸引力要求高，搜索发现则重视关键词布局与信息完整度。

这些特点对提示词提出以下要求：
- （1）社区化与UGC。平台高度依赖用户生成内容，鼓励分享个人经历、旅行故事、购物心得。提示词应注重个性化与真实感，引导生成真实且有辨识度的内容。
- （2）情感共鸣。用户偏爱情绪浓度高的内容，尤其生活、成长、情感相关。提示词应促使内容融入温暖、真诚的情感，增强认同。
- （3）视觉优先。笔记强调图文并茂，图片视频权重高。提示词除文字外，还需为视觉部分提供描述与搭配建议。
- （4）消费决策引导。平台对购物、测评、品牌推荐影响大。提示词要引导生成具备推荐价值的内容，激发尝试欲望。

（二）小红书内容制作的核心原则
核心在于实用性与分享性，情感共鸣与个性表达，文字视觉协同，以及简洁有力突出重点，适配快速阅读。
- （1）重视实用与可分享。提示词需明确要求生成能解决问题的内容或具体产品生活建议，并具备传播性。
- （2）强化情感与人设。受众偏年轻化，情感化与人设化表达更易吸睛。提示词应引导融入共鸣点与个人视角。
- （3）文字配合视觉。视觉属性强，提示词要帮助生成能与图片互动的画面感描述。
- （4）简洁突出重点。阅读多为快速浏览，提示词应引导产出标题抓人、正文要点清晰的稿件，避免冗长。

四、抖音短视频提示词设计

（一）抖音平台内容特性分析
1. 高度视觉化与短时吸引力。开场3秒决定留存，提示词需引导生成强视觉与冲击力的开头。
2. 情绪饱满与娱乐性。用户偏好情绪化娱乐内容，提示词需强调情感表达与趣味性。
3. 强互动性与挑战性。挑战赛、话题、评论区互动是核心，提示词应鼓励生成易参与的内容。
4. 剧情与故事性。短小完整的剧情更易传播，提示词需注重故事结构与连贯性。

2. 引导参与和互动。提示词应引导生成设问、挑战式内容，提升参与感。
3. 节奏鲜明与简洁高效。时长受限，提示词要促成节奏快、表达精炼、无冗余。
4. 贴近热点与用户需求。需关注时效话题，提示词应引导结合当下流行与用户痛点。
