综合前面三组测试可以判断，LLaMA-Adapter V2 的表现相当突出，既能处理中英文双语的多模态输入，对图像的阐述和描述也非常准确，基本与预期一致。下面对该模型的构建思路做简要说明。

LLaMA-Adapter V2 的源头是 LLaMA-Adapter。LLaMA-Adapter 是一种引入可训练适配提示集合的 Transformer 结构，并加入新的调控机制，以便在高效吸纳新知识的同时保留预训练时的能力。该方法使训练效率更高，也更容易向多模态输入扩展来提升推理效果。

在前代基础上，LLaMA-Adapter V2 主要围绕三点展开改进。

+   (1) 线性层的偏置微调。LLaMA-Adapter 依靠可训练的适配提示与零初始化注意力机制融合新知识，并把指令提示融入 LLaMA 以完成指令跟随任务。但可更新的参数仅限于适配提示和门控系数，难以实现深度微调。因此 V2 采用偏置调节策略，新增可学习的偏置与缩放因子，并允许对 LLaMA 中全部归一化层进行动态调整，使得 Transformer 的每个线性层都能自适应指令跟随数据。
+   (2) 为避免视觉微调与语言微调相互干扰，研究者提出一种简易的早期融合思路，用来防止输入视觉提示与适配提示直接交互带来的负面影响。LLaMA-Adapter 里，视觉提示先经过冻结的视觉编码器配合可学习视觉投影层做顺序编码，再逐步叠加到各插入层的适配提示中。V2 则另起两个独立的 Transformer 层分别处理编码后的视觉标记和适配提示，不再将两者混合。
+   (3) V2 调用字幕、目标检测与 OCR 等专家模块来增强视觉指令遵循能力。

这三项改进共同赋予了 LLaMA-Adapter V2 强大的能力，目前它是少见的高性能多模态大模型之一。

# 7.2 国外多模态大模型介绍

国内已有不少优秀多模态模型，国外同样涌现出一批表现强劲的方案。本节重点介绍三款知名模型：Visual ChatGPT、InstructBLIP 与 MiniGPT-4。

# 7.2.1 Visual ChatGPT

微软亚洲研究院于 2023 年 3 月 9 日发布可视化版 ChatGPT，命名为 Visual ChatGPT（详见 Chenfei Wu 等人论文“Visual ChatGPT: Talking, Drawing and Editing with Visual Foundation Models”），并把基础代码上传至 GitHub，首周即获 19700 个 Star。通过把 ChatGPT 与一系列视觉模型串联，Visual ChatGPT 允许用户在文本与图像间与 ChatGPT 互动并执行更复杂的视觉指令，促进多模型协作融合。该模型能有效理解文本与视觉输入，消除文本转图像的信息损耗，大幅提升 AI 工具间互操作性。因其以 ChatGPT 为核心语言模型，故归入国外多模态大模型。

当前 ChatGPT 仅能通过接口访问，而 Visual ChatGPT 本质上是 ChatGPT 与视觉模型的串联，但其热度体现了较大影响力。从论文案例可见，它能有效发挥语言模型与视觉模型各自优势，实现文本与视频的多模态生成。

Visual ChatGPT 强大的多模态处理能力源于其巧妙设计。与传统重训练不同，它仅需一组特殊提示即可引导 ChatGPT 学习来自 22 个视觉模型的能力。这些提示清晰描述了各视觉模型的能力及输入输出格式，并把不同类型的视觉信息转化为语言形式，使 ChatGPT 能更深入理解图像内容。研究与评估表明，Visual ChatGPT 在零样本迁移任务中也表现优异。

# 7.3 多模态大模型评测数据集

工业界与学术界在发布多模态大模型的同时也构建了大量评测数据集。借助这些数据集，研究人员可了解各模型性能与缺陷，便于后续优化。本节介绍国内外四个知名评测集。

# 7.3.1 国内评测数据集

mPLUG-Owl 发布时附带了评测集 OwlEval。OwlEval 主要评估文本生成能力，仅含 50 张图片与 82 个问题，却覆盖故事生成、广告生成、代码生成等多任务，部分图片伴随多轮对话问题。该集全面考察指令理解、视觉理解、图像文字理解及视觉推理等维度。

MME 由腾讯优图实验室联合厦门大学构建，用于衡量现有多模态大模型能力，以便统一比较（详见 Chaoyou Fu 等人论文“MME: A Comprehensive Evaluation Benchmark for Multimodal Large Language Models”）。MME 涵盖感知与认知两类测试。感知测试除 OCR 外，还包括粗粒度与细粒度目标识别，前者考察物体存在、数量、位置与颜色，后者可识别电影海报、名人、场景、地标与艺术品等。认知测试包括常识推理、数值计算、文本翻译与代码推理等。

MME 的指令-答案对均由工程师手工设计，指令简洁，避免提示工程对输出的影响，保证公平。为便于统计，结果设计为“请回答是或否”，可直接根据模型输出“是”或“否”进行量化统计，实现客观准确。

# 7.3.2 国外评测数据集

COCO 全称为 Common Objects in Context，由微软构建，包含多项检测任务，如 Object Detection、DensePose、Keypoints、Stuff、Panoptic 与 Captions。

VQA 即 Visual Question Answering，是一个关于图像的开放式问答数据集。回答问题需要深入理解视觉、语言与常识知识，涉及计算机视觉、自然语言处理与知识表示推理等领域。VQA 包含 265 016 张图片，每张至少 3 个问题，平均 5.4 个，每个问题附 10 个事实答案与 3 个合理但可能不正确的答案。

# 7.4 多模态大模型的评测标准

7.3 节介绍了四个评测集，本节侧重评测标准。通过分析这些数据集的评测细则，可进一步了解多模态大模型的测试规范。

# 7.4.1 国内评测标准

OwlEval 主要依赖人工标注打分，因缺乏合适的自动化指标，采用参考 Self-Instruct 的人工评测，规则为 A=“正确且令人满意”，B=“存在不完美但可接受”，C=“理解指令但回复明显错误”，D=“完全不相关或错误回复”。

MME 的评测结果分为“是”或“否”二分类，便于衡量 Accuracy 与 Accuracy+。Accuracy+ 更能反映模型对整张图片的全面理解。除此之外，构建者将准确率与准确性融合得到子任务分数，感知分数为各子任务分数之和。
