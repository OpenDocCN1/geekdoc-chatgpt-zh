内存检索生成流程的简化演示

这段代码的核心是把一次「先把历史塞进记忆库，再用当前输入去检索生成」的完整链路跑通，用最小的可运行示例来验证接口。整体思路是先定好规模参数，再造一个临时的词表映射，随后把样例输入和三条历史对话分别转成索引喂给模型，最后用 argmax 取最高分词并打印中间状态，同时记录总耗时。

在模拟函数里，词表规模取 5000，Token 嵌入用 64 维，生成器隐藏层是 128 维，输出层同样对齐词表大小，记忆维度与嵌入保持一致。随后实例化 MemoryRetrievalGenerationModel 并切换到推理模式。词典是人工构造的 word1…word5000 与数字 1…5000 的一一对应，逆映射也一并准备好。

样例输入是 word10 word20 word30 word40 word50，按词典拆分为索引序列 [10, 20, 30, 40, 50]，包装成张量后作为当前查询。记忆更新环节准备了三条历史文本：history one word100 word200 word300、history two word150 word250 word350、history three word120 word220 word320，逐条切词转索引后调用 model.update_memory 写入记忆库。

推理阶段在无梯度模式下拿到 logits，用逐位置最大值的索引作为生成结果，再通过逆词典还原成可读词。程序会输出输入原文、输入索引、记忆库条目数、预测索引张量以及还原后的生成词，最后 main 函数用 time 记录整段模拟的执行时长。

# 1. 定义动态缩放注意力模块

class SlidingAttention(nn.Module):

    def __init__(self, embed_dim, window_size, step_size):

        """

        初始化 Sliding Attention 模块。

        参数:

            embed_dim: 输入 Token 的嵌入维度

            window_size: 注意力窗口大小

            step_size: 窗口滑动步长

        """

        super(SlidingAttention, self).__init__()

        self.embed_dim = embed_dim

        self.window_size = window_size

        self.step_size = step_size

        # 线性变换用于生成查询、键和值

        self.query_proj = nn.Linear(embed_dim, embed_dim)

        self.key_proj = nn.Linear(embed_dim, embed_dim)

        self.value_proj = nn.Linear(embed_dim, embed_dim)

        # 输出投影层

        self.out_proj = nn.Linear(embed_dim, embed_dim)

    def forward(self, x):

        """

        前向传播过程。

        参数：

            x: 输入 Token 嵌入序列，形状为 [batch, seq_len, embed_dim]

        返回：

            output: 处理后的序列，形状为 [batch, seq_len, embed_dim]

        """

        batch_size, seq_len, _ = x.size()

        # 计算查询、键和值

        Q = self.query_proj(x)

        K = self.key_proj(x)

        V = self.value_proj(x)

        # 初始化输出张量

        output = torch.zeros_like(x)

        count = torch.zeros(batch_size, seq_len, device=x.device)

        # 计算滑动窗口下的注意力

        for start in range(0, seq_len, self.step_size):

            end = min(start + self.window_size, seq_len)

            # 提取窗口内的查询、键和值

            Q_window = Q[:, start:end, :]  # [batch, window, embed_dim]

            K_window = K[:, start:end, :]

            V_window = V[:, start:end, :]

            # 计算注意力分数：点积后除以缩放因子

            attn_scores = torch.matmul(Q_window, K_window.transpose(-2, -1)) / np.sqrt(self.embed_dim)

            # 动态缩放机制：根据窗口内查询向量的标准差计算缩放因子

            scale_factor = torch.std(Q_window, dim=1, keepdim=True)  # [batch, 1, embed_dim]

            scale_factor = torch.mean(scale_factor, dim=-1, keepdim=True)  # [batch, 1, 1]
