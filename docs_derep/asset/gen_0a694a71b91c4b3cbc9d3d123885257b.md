### 2.9 数据科学起步：核心描述性统计速览

数据科学离不开统计指标来刻画数据全貌。本节先讲五个最基础的描述性统计量：

- **最小值**——数据集的下限；
- **最大值**——数据集的上限；
- **极差**——最大值与最小值之间的跨度；
- **计数**——数据点的总个数；
- **求和**——所有数值的累加结果。

后续章节会详细拆解计数与求和的实现。极差这类离中趋势度量（即离散程度指标）能直观反映数据分布的宽窄，方差、标准差等更高阶指标留待后文介绍。

#### 极差：直观量程数据分布

## 3.1 章节导读

本章逐一拆解 Python 的七大控制语句：`if`、`if...else`、`if...elif...else`、`while`、`for`、`break`、`continue`。

- **序列控制迭代**：`for` 遍历序列，迭代次数由序列长度决定；`range()` 可按需生成整数序列。
