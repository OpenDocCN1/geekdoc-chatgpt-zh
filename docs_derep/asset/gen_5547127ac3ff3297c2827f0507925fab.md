# BeautifulSoup 进阶：CSS 选择器、正则与树遍历实战

## CSS 选择器：精准定位兄弟与属性节点

在 BeautifulSoup 中，`select()` 方法支持标准 CSS 选择器语法，极大增强了元素定位的灵活性。其中，**波浪号 `~` 与加号 `+`** 是处理同级关系的利器：前者匹配指定节点之后**所有**符合条件的兄弟元素，后者仅锁定**紧邻的下一个**兄弟元素。

### 实战案例：问卷题目提取

假设需从问卷页抓取题目。首先用 `find()` 定位首题容器（`id="q1"`），再结合选择器分层获取：

*   **全量后续题**：`select('#q1 ~ .survey')` 命中首题之后所有 `class="survey"` 的兄弟节点。
*   **仅下一题**：`select('#q1 + .survey')` 仅返回紧跟其后的那一个。

运行效果直观对比：第一条指令返回包含性别、偏好、编程能力三题的列表；第二条指令仅输出“侧好侦探小说”这一道紧随其后的题目。

### 复合属性与多值匹配

`select()` 还能组合 `id`、`class` 甚至标签名进行精准打击：

1.  **ID 精准查找**：`select('#q1')`、`select('span#email')` 直接锚定唯一元素。
2.  **多 ID 并集**：`select('#q1, #q2')` 配合循环可批量收割多道题目文本。
3.  **层级下钻**：先 `find('div')` 定位容器，再 `select('p.question a')` 提取段落内超链接的 `href`。
4.  **Class 部分匹配**：`select('[class~="selected"]')` 可筛选 class 列表中包含 `selected` 的任意标签（注意 `~=` 与 `~` 的区别：前者是属性值包含单词，后者是兄弟选择器）。

## 属性存在性与值模糊筛选

除了结构定位，`select()` 支持基于属性名、值的模糊查询，语法借鉴正则直觉：

| 选择器模式 | 含义 | 典型场景 |
| :--- | :--- | :--- |
| `a[href]` | 拥有 `href` 属性的 `<a>` | 清洗无效链接 |
| `a[href="exact"]` | 属性值**完全等于** | 定位固定跳转 |
| `a[href^="http:"]` | 以 `http:` **开头** | 筛选外链/绝对路径 |
| `a[href$=".pdf"]` | 以 `.pdf` **结尾** | 采集文档下载链接 |
| `a[href*="keyword"]` | **包含** 关键字 | 模糊匹配业务参数 |

实测数据印证：某页面中含 `href` 的链接共 3 个；以 `http:` 开头的 1 个；以特定后缀结尾的 1 个；包含特定字段的 3 个。这种“漏斗式”筛选极大提升了数据清洗效率。

## `select_one()`：单例模式的轻量替代

当确信目标唯一或仅需首个匹配时，`select_one()` 避免了列表解包的开销。它与 `select()` 语法完全一致，但直接返回首个 `Tag` 对象而非列表。例如 `soup.select_one('a')` 即刻拿到文档首个超链接节点，代码更简洁、意图更明确。

## 正则表达式：突破标签边界的文本猎手

`find()` / `find_all()` 接受 `re` 模块编译的正则对象，解决了**标签夹杂文本**、**非结构化内容**等 CSS 选择器难以企及的场景。

### 核心语法速查

| 元字符 / 结构 | 作用 | 记忆锚点 |
| :--- | :--- | :--- |
| `\w` / `\W` | 单词字符 / 非单词 | **W**ord |
| `\d` / `\D` | 数字 / 非数字 | **D**igit |
| `\s` / `\S` | 空白 / 非空白 | **S**pace |
| `^` / `$` | 字符串首 / 尾 | 锚定边界 |
| `.` | 任意单字符（除换行） | 通配符 |
| `*` / `+` / `?` | 0多 / 1多 / 0或1 | 量词阶梯 |
| `{n,m}` | n 到 m 次 | 精准计数 |
| `[abc]` / `[^abc]` | 字符集 / 反向字符集 | 定制菜单 |
| `\|` | 或逻辑 | 分支选择 |
| `(...)` | 分组捕获 | 单元打包 |

**常用模板实例**：
*   邮箱：`[\w\.-]+@[\w\.-]+\.\w+`
*   HTTP 链接：`^https?://`
*   手机号：`^1[3-9]\d{9}$`

### 实战：从混合内容中抽取邮箱与链接

```python
import re
pattern = re.compile(r'[\w\.-]+@[\w\.-]+\.\w+')  # 编译一次，复用多次
soup.find_all(string=pattern)        # 直接匹配文本节点
soup.find_all(href=re.compile(r'^https?://'))  # 匹配属性值
```
第一行代码能穿透 `<p>联系我们: a@b.com</p>` 这类混合结构，直接命中邮箱文本；第二行则精准筛选外部超链接，避免相对路径干扰。

## 树遍历：在对象森林中自由穿梭

当选择器与正则只能“缩小范围”时，遍历属性提供了**像操作文件目录一样**操作 DOM 树的能力。BeautifulSoup 将 HTML 解析为层级分明的 Python 对象树，支持三维导航：

| 方向 | 核心属性/方法 | 适用场景 |
| :--- | :--- | :--- |
| **向上（父/祖先）** | `.parent`, `.parents` | 从叶子节点回溯容器上下文 |
| **向下（子/后代）** | `.contents`, `.children`, `.descendants` | 展开容器内所有节点，`descendants` 递归深入 |
| **水平（兄弟）** | `.next_sibling`, `.previous_sibling`, `.next_siblings`, `.previous_siblings` | 同级节点间顺序遍历 |
| **线性流** | `.next_element`, `.previous_element` | 按解析器读取顺序逐个访问，跨层级 |

> **提示**：`.contents` 返回列表（含换行文本节点），`.children` 返回生成器（惰性、内存友好）；遍历兄弟节点时需留意换行符产生的 `NavigableString` 空节点，通常配合 `if tag.name` 过滤。

### 典型遍历模式：从题目定位到选项收集

以图 5-5 所示的问卷结构为例，第 2 题的 `<div>` 为起点：
1.  **向下**：`div.find_all('p', class_='option')` 或 `div.descendants` 筛选 `input[type=radio]` 收集所有选项。
2.  **向上**：`div.parent` 确认所属 `<section>` 或 `<form>` 归属。
3.  **水平**：`div.next_sibling` 快速跳转至第 3 题容器，实现分页式采集。

## 小结

| 技术维度 | 核心工具 | 适用边界 |
| :--- | :--- | :--- |
| **结构定位** | `select()` / `select_one()` + CSS 选择器 | 类名、ID、层级、兄弟关系明确时首选 |
| **文本/属性模糊匹配** | `find_all(string=re_obj)` / `find_all(attr=re_obj)` | 内容非结构化、属性值有规律变化时 |
| **精细节点漫游** | `.parent`, `.children`, `.next_sibling` 等遍历属性 | 需按文档顺序/层级逐个处理、或选择器无法表达的复杂相对位置 |

实战中，**“选择器粗筛 → 正则细滤 → 遍历补全”** 的组合拳最稳健：先用 `select('#container .item')` 圈定区块，再用正则清洗文本/属性，最后用遍历处理异常结构或跨层级关联。掌握这三把斧头，任意复杂网页皆可随心所欲地“拆解重组”。
