# 掌握这套"反向投喂"法，让ChatGPT帮你问出高质量答案

还在为不知道怎么问ChatGPT而发愁？其实最聪明的用法，不是你绞尽脑汁想提示词，而是**让它自己生成标准化问题，再反手“喂”回去**。这招在选股、学AI、读报告等场景里屡试不爽。

---

## 一、 别自己憋问题，让AI帮你“定标准”

### 核心逻辑：用开放式问题启动，再把生成的“标准化问题”投喂回去

**实战案例：判断一只股票值不值得买**

*   **你问：** “帮我生成一个判断股票投资价值的标准化问题。”
*   **它回：** 给出一个结构化清单——财务健康、行业前景、护城河、管理层、估值体系、风控指标……并解释如何综合评分。
*   **你接下来：** 满意就直接让它按这套标准分析某只票；不满意就追加限制条件（如“只看基本面”、“加入技术面指标”），让它重写。

> **小技巧**：把“帮我想个问题”升级为“帮我生成一个包含X、Y、Z维度的标准化评估框架”，得到的骨架更硬。

---

## 二、 进阶玩法：从“简单到复杂”，像搭积木一样建问题库

别指望一句提示词解决战斗。分六步走，每一步都在为下一步铺路：

| 步骤 | 动作 | 关键动作 |
| :--- | :--- | :--- |
| **1. 定主题** | 抛个极简引子 | “关于人工智能，能告诉我点基础信息吗？” |
| **2. 抓关键词** | 盯着它的回答提炼 | 提取：AI、计算机科学、模仿人类智能、系统构建…… |
| **3. 让它出题** | 扔给它关键词，要标准化问题 | “基于以上关键词，生成一个关于AI的标准化问题。” |
| **4. 反向投喂** | 把它生成的问题原封不动发回去 | 它会按自己的大纲，输出一份结构化长文。 |
| **5. 看答案** | 核对覆盖面、深度、准确度 | 漏了？浅了？错了？记下来。 |
| **6. 循环迭代** | 盯着薄弱环节追问 | “你提到的医疗诊断系统能展开说说吗？”→ 再走一遍 3-5 步。 |

**实测效果**：从“AI是啥”到“AI怎么落地医疗影像分级”，短短几轮对话，拿到的比你自己查半天资料还全。

## 三、 换场景、换角度、换技巧——把“问题包”做厚

同一个主题（如股市），不同身份、不同任务，问题包长相完全不同：

### 场景 A：小白入门——**分层级 + 落应用**
1.  市价单vs限价单有啥区别？（基础概念）
2.  PE、PB怎么算？对决策有多重要？（核心指标）
3.  标普500、道指代表什么？怎么影响大盘？（宏观坐标）
4.  **实战转折：** “普通人怎么用这些指数选ETF？”（理论落地）

### 场景 B：从业者研策略——**问知识 + 问分析 + 问求证**
*   知识层：技术分析vs基本面分析，本质区别在哪？
*   分析层：结合两套分析结果，怎么动态调仓、控险？
*   求证层：止损单、期权对冲到底怎么保钱？历史回测靠谱吗？

### 场景 C：管理者看报表——**扣关键词 + 探细节 + 要演示 + 做对比**
*   关键词直击：“哪几个财务指标最能反映公司造血能力？”
*   探细节：“毛利率、净利率具体怎么算？红线在哪？”
*   要演示：“手把手演示一下PE-TTM的计算过程。”
*   做对比：“价值投资vs成长投资，胜率回撤怎么选？”、“金叉死叉实战里到底管不管用？”

> **一句话总结**：**新手问“这是什么”，高手问“怎么用、怎么验、怎么比”。**

## 四、 把“读长文”外包给AI：给它定标准，要它出摘要

### 标准化 SOP（四步走）

1.  **喂全文/片段** —— 别怕长，上下文窗口够大。
2.  **定参数** —— “300字以内”、“提取5个关键词”、“重点关注对学生学习的影响”。
3.  **点关键点** —— “重点帮我总结VR/AR在沉浸式教学里的落地案例”。
4.  **二次打磨** —— “再精简50字”、“把挑战单独列出来”、“改成要点式汇报给领导看”。

### 实战对话复盘

*   **用户：** 给我总结这段“新技术对教育的影响”，重点看对学生学习的冲击。
*   **AI：** 输出四大红利（资源普及、个性化、沉浸式、协作无界）+ 三大坑（数字鸿沟、技术迭代追不上、老师累）。
*   **用户追问：** 没全文了，但知道文里提到在线教育未来趋势，帮我脑补一下。
*   **AI：** 基于常识补全——交互更强、时间地点更自由、全球名师零距离。

### 两套万能追问模版

*   **定条件追问：** “把第二段的实验数据单独拎出来”、“只保留对K12阶段的影响”、“用‘机遇-挑战’双栏表格呈现”。
*   **探深度追问：** “你提到的‘个性化学习’具体靠什么技术落地？”“有没有失败案例反面教材？”

## 五、 避坑指南：三个“不要信”

1.  **不要信“一次成型”** —— 标准化问题、摘要输出，最少改两轮才像样。
2.  **不要信“全知全能”** —— 它会一本正经胡说八道，关键数据、专业结论必须人工复核。
3.  **不要信“通用提示词”** —— 场景换了、角色换了、输出格式换了，提示词结构必得重拆重组。

## 六、 明日行动清单

1.  找一个你正在研究的具体课题（选股、行研、学新知、写方案）。
2.  按“六步搭积木法”跑一遍，沉淀出一套**专属标准化问题集**。
3.  把这套问题集存成“提示词模板”，下次同类任务直接调用。
4.  手头有长文档？扔给AI，按“四步SOP”要三版摘要：给领导看的极简版、给同事用的详细版、给自己存的结构化笔记版。

**工具从来不产生价值，驾驭工具的流程才会。** 把“会提问”变成“会设计提问流程”，ChatGPT 才真正成了你的得力参谋。
