## 3.1 公式是什么
公式是 Excel 数值计算的核心工具，在财务处理中几乎必用。它本质是一个等式，必须以“=”开头，后面可接函数、引用、运算符和常量。

## 3.2 公式对数据源的引用
公式运算离不开引用，只有引用单元格区域计算才能体现灵活性。引用方式可分为相对、绝对，也可跨工作表或工作簿引用。

### 3.2.1 相对引用及应用
编辑公式时默认采用相对引用，显示形式为 A1、A3:C3 等。下面以例说明相对引用的使用场景。

- ❶ 选中 E2 单元格，在公式栏输入：=SUM(B2:D2) 如图3-4所示，公式引用了 B2、C2、D2 的数据。
- ❷ 按 Enter 确认后，将鼠标移至 E2 右下角出现黑色十字，向下拖动复制公式，释放后即可批量得到结果。

复制完成后查看公式可理解相对引用的含义。
