+   1. 平行趋势前提：DiD 核心要求是在未受干预的情境下，处理组与对照组的结局轨迹保持一致。判断该前提是否成立，可先对干预前时段两组的走势进行图形化检视，再用统计检验比较前期斜率的差异。
+   2. 选择偏差：若两组在可观测特征上不可比，DiD 的因果估计容易受选择偏差污染。可考虑借助倾向得分匹配或加权手段，依观测变量构建更具可比性的样本。
+   3. 未观测混杂：若存在影响分组及结局却未被记录的因素，估计值会产生偏差。可采用工具变量策略，或开展敏感性分析，检验结论对潜在未观测混杂的稳健程度。
+   4. 溢出效应：经典 DiD 假定处理组与对照组互不干扰。为探索可能的外溢，可估计空间或网络依赖模型，或通过重新界定处理与对照集合进行稳健性检验。
+   5. 多重或动态效应：当干预强度分层或效应随时间演变时，标准 DiD 的测量能力受限。此时可转向广义双重差分框架，如事件研究或合成控制方法。
+   6. 流失与缺失：非随机的样本流失或数据缺失会扭曲 DID 结果。可使用面板数据插补或逆概率加权等技术加以校正。

妥善处理上述问题并落实对应对策，能显著提升双重差分因果推断的可信度与稳健性。

# 第七章 工具配备：构建研究测评与仪器

研究仪器与工具是数据采集、测量与分析的基础。设计精良且可靠的工具能确保数据准确、有效且相关，从而提升研究结论的可信度与影响力。

工具选择需与研究设计紧密配合，以保持结果一致性并最大化效度。不同设计常需主客观方法结合。例如饮食干预研究中，可选用生物标志物作客观指标，也可用 24 小时回顾等自述问卷采集主观数据。

选择合适工具需权衡优缺点与研究问题、目标、资源的相关性。生物标志物客观可靠但成本高、侵入性强，需专业设备与技术；自述问卷成本低、易操作，但易受回忆与报告误差影响。研究者需在可行性、实用性与伦理间作出明智取舍。

效度与可靠性是工具质量的核心。效度指测量是否恰当反映目标构念；可靠性指在不同时间或情境下的一致性。两者皆重要且不可互换。未校准的磅秤可能高度可靠却无效；对温度敏感的传感器可能有效却不可靠。以体育活动测量为例，国际体育活动问卷 IPAQ 可接受效度，但易受回忆与社会期许影响而可靠性不足；计步器与加速度计客观性强，但对游泳、力量训练等测量受限。研究者需审慎评估工具的效度与可靠性。
