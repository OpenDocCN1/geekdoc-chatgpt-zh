## OpenAI SDK 调用 DeepSeek 实战

已经在用 OpenAI SDK 的同学，可以直接复用现有写法，把请求地址切到 DeepSeek 就能交互。下面把环境准备、首次对话、模型查询、消息组织以及图文输入拆成可复制的片段，顺序执行即可跑通。

先把需要的库装进当前环境。
[PRE0]
pip install openai
[/PRE0]

接下来是连接与首次调用的骨架。导入模块、填入个人的 DeepSeek 密钥、创建指向官方接口的客户端，然后用 chat.completions.create 发起一次简单对话并打印结果。
[PRE1]
import os

from openai import OpenAI

from IPython.display import display, Code, Markdown

import requests

import json

# <YOUR_DEEPSEEK_API_KEY>替换为复制的 API key 字符串

ds_api_key = '<YOUR_DEEPSEEK_API_KEY>'

#实例化客户端

client = OpenAI(api_key=ds_api_key,

                base_url="https://api.deepseek.com")

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {"role": "user", "content": "你好，好久不见!"}

    ]

)

#输出生成的响应内容

print(response.choices[0].message.content)

#输出完整的响应

print(response)
[/PRE1]

消息构造
系统角色用来设定行为基调。
[PRE5]
system_message = {
    "role": "system",
    "content": "你是一位擅长编写 python 代码的助手。"
}
[/PRE5]

用户角色放置具体的提问内容。
[PRE6]
user_message = {
    "role": "user",
    "content": "你好，请介绍下你自己。"
}
[/PRE6]

视觉能力

带角色的对话示例
把 system 与 user 一起传入 messages，模型会按设定进行回复。
[PRE8]
#创建用户消息

user_message = {
    "role": "user",
    "content": "你好，请介绍下你自己。"
}

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        system_message,
        user_message
    ]
)

#输出生成的响应内容

print(response.choices[0].message.content)
[/PRE8]

整体流程就是安装库、配置密钥与地址、创建客户端、组织 messages、调用 deepseek-chat。模型切换、系统指令、视觉输入都能在此框架下直接复用。
