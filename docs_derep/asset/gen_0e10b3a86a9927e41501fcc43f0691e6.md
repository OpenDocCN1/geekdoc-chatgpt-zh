## 1.6 开发环境安装

体验过框架带来的便利后，就可以着手在本地搭建 TensorFlow 的运行环境。TensorFlow 支持 Windows 10、Ubuntu 18.04、macOS 等主流系统，同时提供基于 NVIDIA 显卡的 GPU 版本和仅 CPU 版本。下面以最常见的 Windows 10、NVIDIA GPU 与 Python 环境为例说明安装思路。

整体来看，本地环境一般包含四个环节：部署 Python 解释器 Anaconda、安装 CUDA 加速库、安装 TensorFlow 框架、配置常用代码编辑器。

### 1.6.1 Anaconda 安装

Python 解释器是执行 Python 代码的桥梁。官方网站 https://www.python.org/ 可下载最新版解释器，如同普通软件安装后即可运行 .py 文件。

这里选用集成了解释器、包管理和虚拟环境的 Anaconda。从 https://www.anaconda.com/distribution/#download-section 进入下载页，选择对应 Python 版本的安装包。安装过程中勾选 AddAnacondatomyPATHenvironmentvariable，这样就能在命令行直接调用 Anaconda。安装向导会询问是否捆绑安装 VSCode，选择 Skip 跳过即可。整个过程约五分钟，具体时长取决于机器性能。

### 1.6.2 CUDA 安装

当前主流深度学习框架都借助 NVIDIA GPU 加速，因此需要先装 CUDA。若本机显卡为 AMD 或 Intel，则无法使用 CUDA，可直接跳到 CPU 版 TensorFlow。

CUDA 的安装包含三部分：CUDA 主程序、cuDNN 神经网络加速库、Path 环境变量配置。

（1）CUDA 软件安装：访问 https://developer.nvidia.com/cuda-10.0-download-archive，这里以 CUDA 10.0 为例，按 Windows、x86_64、10 系统、exe 本地安装包的顺序选择后点击 Download。运行安装包后选择 Custom，进入组件列表。可取消 Visual Studio Integration。Driver components 下需对比当前显卡驱动 Current Version 与随 CUDA 提供的 New Version，若当前版本更大则取消 DisplayDriver 的勾选，否则保持默认。
