代码 9-17 归纳了几类能大幅提升模型调用效率的关键手段，具体如下。

- 1）缓存复用与结果沉淀：把高频查询的返回结果写入 Redis，后续相同问题直接命中缓存。
- 2）上下文精简：先用小模型对超长提问做摘要压缩，再输入主模型处理。
- 3）合并批量执行：将多个查询累积起来统一发起，减少 API 调用次数。
- 4）条件式触发：依据任务优先级动态决定调用时机，避免无谓唤醒。

把这些方法组合使用，可以明显降低模型调用频次、减少 token 消耗，同时让响应更快。
