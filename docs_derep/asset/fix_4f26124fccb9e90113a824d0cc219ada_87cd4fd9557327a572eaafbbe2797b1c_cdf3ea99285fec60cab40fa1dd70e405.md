# 第10章 固定资产管控与折旧计提实务

[PRE0]

扫码看教学视频

固定资产是指企业为生产产品、提供劳务、对外出租或日常经营管理而持有、使用年限超过12个月且达到价值标准的非货币性资产。它是企业开展经营的物质基础，也是费用分摊与利润形成的重要依据，使用过程中的价值损耗需要通过折旧进行摊销，所以财务人员有必要对资产进行系统化管理。

- 搭建固定资产台账
- 资产信息检索
- 按月计提折旧
- 折旧相关的账务处理

## 10.3 按月计提折旧
