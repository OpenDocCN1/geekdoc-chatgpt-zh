# 开源绘画的另一条路：Stable Diffusion 入门

上一章节完整拆解了 Midjourney 的使用逻辑，这款产品上手快、风格覆盖广、成图惊艳。除了它，市场上还有一个常被拿来对比的开源方案——Stable Diffusion，简称 SD。2022 年 8 月，Stability AI 联合慕尼黑大学发布并开源了该软件，全球用户可通过 GitHub 免费获取源码在本地运行。相较早期同类工具，SD 最打动人的地方是完全免费、无使用次数限制、本地运行的硬件要求相对友好，高清图几秒即可出。开源后它再次掀起一轮 AI 绘画热潮。

SD 与 Midjourney 的取舍主要体现在三点：

+ (1) 成本：SD 采用开源免费模式，本地部署后长期使用都不需要付费；Midjourney 则是订阅制收费。
+ (2) 定制空间更大：依托开源基座和丰富的插件，用户可自行微调风格、对局部进行重绘，控制更精细。
+ (3) 人像资源丰富：尤其是女性人像模型储备量大，在人物刻画上表现更为突出。

下面按本地部署到生成数字主播的完整链路展开实操。

# 5.1.1 硬件准备与源码启动

要顺畅运行 stable-diffusion-webui 及对应模型，显存是关键指标。最低建议 4GB，常用配置 6GB，体验较好的推荐值是 12GB。系统内存最好大于 16GB，越大越稳定。配置不足时启动容易卡顿、响应迟缓。

SD 的工程仓库托管在 GitHub，迭代速度很快，漏洞修复和新功能上线频繁，建议定期访问官网拉取最新版本。

具体步骤如下。

(1) 安装 Git。打开 Git 官网下载，按向导完成安装，勾选默认组件即可。
(2) 配置 Python 环境。stable-diffusion-webui 以 Python 开发，需要先安装 Python 并配置环境变量，推荐 3.10.6 版本，搭配 Anaconda 管理多环境更方便。
(3) 配置 CUDA 环境。stable-diffusion-webui 主要依赖 GPU 加速，需要英伟达显卡。先安装 CUDA 驱动。右键桌面右下角 NVIDIA 图标进入控制面板，如图 5-1 所示。

# 5.1.2 模型与 LoRA 插件部署

(1) 下载 SD 运行所必需的基础权重文件，大小约 4GB。可在 Hugging Face 官网获取后放入 models/Stable-diffusion 目录。
(2) 下载 LoRA 模型文件。LoRA 全称 Low-Rank Adaptation of Large Language Models，是 SD 的插件方案。它无需改动原模型，仅注入低秩矩阵，即可基于少量数据训练出特定画风或人物，比全量训练更省资源、更快捷。模型分享站 Civitai 上 SD 模型约 2000 个，LoRA 等小模型约 4 万个，可按喜好挑选下载。

# 表5-1 Stable Diffusion 的主要参数

| 参数 | 说明 |
|------------|-----------------------------------------------------------------------|
| prompt | 正向提示词 |
| negative prompt | 反向提示词 |
| width & height | 输出画布尺寸，尺寸越大耗时越长 |

# 第5章 用SD打造专属数字分身

写提示词是 SD 绘画的核心能力，整理了一些实用技巧：

技巧1：提示词结构为“正向描述 + 负向描述”。正向写想要的效果如 masterpiece、best quality；负向写不想要的效果如 bad hands、text error。
技巧2：越靠前的词权重越高，先写景会让人物占比变小，先写人物则占比变大。
技巧3：画幅越大，提示词越需详细。
技巧4：英文圆括号可提升内部词权重约 1.1 倍，中括号提升约 1.05 倍。
技巧5：‘+’ 与 ‘AND’ 可连接短语，AND 两边需空格。
技巧6：可采用三段式：第一段画质与风格，第二段主体内容及细节，第三段场景与人物细节。
技巧7：也可按“画质→风格→镜头→光照→主体及次要描述×系数→全局光照→全局镜头→滤镜”顺序组织。

不同模型对提示词敏感度不同，需不断调试组合。
