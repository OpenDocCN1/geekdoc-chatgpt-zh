### 4.2 用人工智能制定写作计划，让论文推进更高效

大纲确定后就进入正文撰写阶段，为提升效率可列出进度表，确保按期完成。常见的规划模型有两种。

#### 1. SMART模型
- 具体：明确每个写作阶段的具体任务。
- 可衡量：为每个任务设定可追踪的进度指标。
- 可达成：在现有资源与时间限制下目标可行。
- 相关性：各目标均与研究目的和论文要求相符。
- 时限性：为每个任务设定明确截止时间。

#### 2. GROW模型
- 目标：明确写作过程中期望达成的具体成果。
- 现实：评估当前面临的实际状况与挑战。
- 选择：探讨可采取的不同策略与行动方案。
- 总结：梳理讨论结果，形成清晰的行动计划。

### 4.3 论点提炼受阻？人工智能可提供思路

论文各章节常遵循金字塔结构。核心观点先用一句话概括，再逐步展开论证，通过分类与层层推演，引导读者按逻辑顺序理解思路，实现观点传递与影响。论文体量大、论点多，写作者需要严密逻辑与文字敏感度，容易出现卡壳。

在提炼论点时常遇到的困难有以下几类。

**一是论点拆分。** 指依据金字塔模式把总论点拆解为逻辑一致的子论点，表现为章拆为节、节拆为段。借助人工智能拆分的提示词示例：

问：
我的论文主题是“人工智能技术对大学生劳动教育的影响”，总论点拟为“人工智能技术对大学生劳动教育的积极作用”，请按金字塔模式将其分解为3个子论点，要求逻辑连贯且呼应总论点。

人工智能回答：
总论点：人工智能技术对大学生劳动教育的积极作用。
子论点一：提升劳动教育的个性化与定制化水平。
子论点二：增强劳动教育的实践性与互动性。
子论点三：优化劳动教育的评价与反馈机制。
这三个子论点从不同维度呈现人工智能的正面影响，彼此关联，可为写作提供参考视角。

**二是论点补充。** 当论点不足或缺口时需增补以保持完整性。提问方式示例：

问：
我的论文主题是“人工智能技术对大学生劳动教育的影响”，拟从3个方面分析“人工智能技术对大学生劳动教育的负面影响”，其中第一个是“可能引发教育不平等”，第二个是“导致学生对人工智能技术产生依赖”。请补充第三个方面，保持逻辑一致性。

人工智能回答：
在已有的两个负面影响基础上，第三个方面可聚焦人工智能技术对大学生职业技能发展与就业前景的影响。
随着人工智能技术发展，许多传统岗位正在变革。若学生在劳动教育中过度依赖人工智能，可能错失掌握未来就业市场所需核心职业技能的机会。人工智能虽能提升效率，却无法完全复制真实工作环境中的复杂挑战。此外，新的职业领域不断涌现，对技能与素质提出新要求。若缺乏实践经验与创新思维，学生可能难以适应，从而制约职业技能发展与就业。

**三是论点修正。** 当论点在逻辑或形式上出现偏差时需优化。提示词示例：

问：
我的论文主题是“人工智能技术对大学生劳动教育的影响”，拟从3个方面分析“人工智能技术对大学生劳动教育的负面影响”，初步论点为：“1.可能引发教育资源分配问题”“2.导致学生对人工智能技术依赖”“3.削弱学生创新能力”。请从社会层面、学校层面、学生层面对其进行优化，使层次分明、形式统一。

人工智能回答：
社会层面
论点一：人工智能技术可能加剧劳动教育资源分配的社会不平等。
论证：社会层面，人工智能的快速应用导致资源分配不均，高成本设备与软件使经济条件较好的学生更易获得优质资源。

学校层面
论点二：学校过度倚重人工智能可能导致劳动教育内容同质化与局限性。
论证：学校层面，过度依赖人工智能辅助可能使教学内容与方法趋同，虚拟平台的过度使用限制学生在真实环境中的实践体验。

学生层面
论点三：学生对人工智能的过度依赖可能抑制创新能力与实践能力发展。
论证：学生层面，过度依赖人工智能会削弱独立思考与解决问题能力，学生更倾向于使用现成解决方案而非自主探索。

### 4.4 论证空洞？人工智能助力论证更有力

正文写作中论证组织至关重要。初学者易忽视论证方法的重要性，导致分析停留在表面或方法单一，削弱说服力。提高论文水平需运用多样化论证方法，有助于多角度阐发观点并提升学理性。常见论证方法如下表。

表4-1 常见论证方法

| 论证方法 | 定义及特征 |
| :--- | :--- |
| 举例论证 | 通过列举具体事例或案例支持论点，使抽象理论具体化，便于理解与接受 |
| 道理论证 | 引用已有理论、公理作为论据，增强论点说服力 |
| 类比论证 | 比较相似事物属性，推导出另一属性的相似性，帮助理解复杂概念 |
| 因果论证 | 分析事物因果关系，指出原因与结果的关联 |
| 对比论证 | 对比异同突出优势或劣势，彰显论点重点与独特性 |
| 归纳法 | 从具体事实或案例归纳出一般性结论，揭示普遍规律 |
| 演绎法 | 从一般原理推导出具体结论，注重逻辑严密性 |
| 归谬法 | 假设论点成立推导出荒谬结论，从而反证论点不成立 |

遇到论证瓶颈时可借助人工智能辅助。提示词示例：

问：
我的论文主题是“人工智能技术对大学生劳动教育的影响”，在论述“人工智能技术对大学生劳动教育的负面影响”一节中，论点是：人工智能技术可能加剧大学生劳动教育资源分配的社会不平等。请用举例论证的方法展开论证。

人工智能回答：
论点：人工智能技术可能加剧大学生劳动教育资源分配的社会不平等。
举例论证：
人工智能在教育领域应用日益广泛，但分布并不均衡，常集中于经济条件较好的地区学校。经济薄弱尤其是偏远地区学校因资金有限难以接入先进人工智能技术。
这种不均衡带来机会不平等、教育质量差异与教育结果不平等。拥有人工智能的学校能提供更丰富高质量的劳动教育机会，缺乏技术的学校只能停留在理论层面。
例如某知名高校投入大量资金购置VR设备用于模拟工作场景，学生可沉浸式体验劳动技能；而另一所偏远学校仅能依靠传统教材，体验差距直接影响学习效果与职业发展。
因此，人工智能可能加剧资源分配不平等，需引起关注。政府与教育部门应加大对薄弱学校的投入，推动资源均衡。
