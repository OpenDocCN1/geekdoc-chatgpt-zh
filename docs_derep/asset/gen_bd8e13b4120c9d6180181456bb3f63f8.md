v1 版的官方 Action 对配置做了大幅精简。现在所有 Claude Code CLI 的选项都收敛到 claude_args 一个入口里。Beta 时代单独存在的 max_turns、allowed_tools 等字段已经被废弃，无法再使用。

3. 并发控制策略

开启 cancel-in-progress: true 之后，并发就能被高效管控。同一 PR 频繁推送、触发多次提交时，系统会自动终止仍在运行的旧任务，只保留最新一次提交对应的审查。借助这套机制重复执行被避免，API 费用也随之下降。
