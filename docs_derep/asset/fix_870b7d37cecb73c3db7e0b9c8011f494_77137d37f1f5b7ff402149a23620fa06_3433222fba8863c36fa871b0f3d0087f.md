### 2. 切片工作方式
用下标定位单个元素，或用下标范围取出一段序列，称为切片，如图 3-2 所示。

切片语法原型是 [start:stop:step]，即 [起始位置:终止位置:步幅]。

- 起始位置从 0 起算，左到右第一个为 0，最后一个为 -1
- 终止位置切片取到该位置之前，不包含该位置
- 步幅默认为 1，设为 2 即隔一取一。正值从左向右，负值从右向左，步幅不能为 0
