三、谈判收尾与落地执行 [总结评估、合同签订、后续跟进]
（注：方括号里的写法仅作示范，可根据自身需求进行替换）

从这里就能看出来，指令是让 AI 把大纲里“方法、技巧”这一块展开细化。目的很直观：让 AI 输出的大纲更充实、更能直接上手。另一个关键点是强制要求以 Markdown 代码格式输出。这一步是为了衔接下一步操作：把内容复制到专门制作 PPT 的 AI 工具里，标准格式能帮助工具更精准地识别课程结构和文字，之后就能直接一键生成演示文稿，效率和成品质量都更有保障。

Markdown 其实是一款轻量级的标记语言，核心理念就是用通俗易懂的纯文本来完成文档排版。它生成的文件一般使用 .md 或 .markdown 作为后缀。下面是一些常用的 Markdown 语法示例：

（1）标题层级
● # 一级标题
● ## 二级标题
● ### 三级标题
● 以此类推

（2）文字强调
● 粗体
● 斜体

（3）链接与图片
● [链接文本]（URL）
● [替代文字]（图片链接）

（4）无序列表
● 列表项一
● 列表项二
● 列表项三

（5）有序列表
● 1. 第一项
● 2. 第二项
● 3. 第三项

（6）代码块
