# 第 6 章

## 插画与流行视觉

当大众传媒日益成熟，插画与流行视觉从过去的边缘位置迁移到中心舞台，已然成为当代视觉生态中举足轻重的元素。相较于学院派艺术追求的崇高与恒久，这类图像更看重传播效率、场景适配以及辨识鲜明的风格肌理，应用触及童书绘本、游戏美术、广告创意乃至社媒表达等多个层面。

插画之价值并非逼真复制，而是借由画面展开叙事、传达情绪、塑造角色的世界观。凭借鲜明的功能取向，它在数字创作与生成式图像领域占据核心位置。各类插画语言皆可视作特定文化背景下的审美提炼，具备明确的视觉规范和象征体系，能迅速触达观者的情感共鸣。

所谓流行视觉，是指在某段时期高频出现并带有符号特征的视觉范式，例如孟菲斯设计、酸性图形、黏土动画等。这类范式多源自广告、影视、动画、时尚与网页设计等场域，短时间内经历大规模复制扩散，进而倒逼主流设计审美的转向。
