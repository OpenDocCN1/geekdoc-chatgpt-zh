#### 7.3.4 火山引擎
火山引擎是字节跳动的云平台，已预部署 DeepSeek-R1，下面演示调用流程。
### 1. 打开火山引擎官网
在浏览器搜索“火山引擎”进入官网，如图 7-37。
### 2. 进入火山方舟平台
依次点“大模型”和“火山方舟”，进入火山方舟一站式大模型开发平台，如图 7-38。
### 3. 开通模型服务
在平台点“立即体验”可在线试用；点“控制台”进入控制台，如图 7-39。
调用 API 前需先开通模型。选择“开通管理”，右侧开通 4 个 DeepSeek 模型。新用户有 50 万 Token 免费额度，用完后按费率付费。
开通后选择“在线推理”，在“预置推理接入点”里选“自定义推理接入点”，点“创建推理接入点”，如图 7-40。
### 4. 配置接入点并指定模型
进入配置页，如图 7-41，在“接入点名称”填名称；点“模型选择”→“添加模型”。
在模型选择页，如图 7-42，点“DeepSeek”，模型选“DeepSeek-R1”，版本选“250120”，点“确定”。也可换其他 DeepSeek 模型，不同模型费率不同。
返回配置页，如图 7-43，“模型选择”会显示刚才的模型，选择计费方式“按 Token 付费”，点“确认接入”。
