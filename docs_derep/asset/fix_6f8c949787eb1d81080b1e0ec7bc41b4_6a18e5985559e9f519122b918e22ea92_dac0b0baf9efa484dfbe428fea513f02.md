**2. PyTorch 中的 Agent 扩展**
在 PyTorch 中，有多个优秀的库可用于开发和训练强化学习 Agent，其中最著名的是 Stable Baselines3 和 RLlib。

（1）Stable Baselines3。
Stable Baselines3 是基于 PyTorch 的一个强化学习库，作为早期 Stable Baselines 的重大升级版本，它通过完全重写代码以充分发挥 PyTorch 的优势。Stable Baselines3 的主要特点如下。
◎ 实现了一系列先进的强化学习算法，包括 A2C、PPO、SAC 等。
◎ 强调代码质量和可复现性，提供了详细的文档和示例代码。
◎ 高度模块化的设计使用户可以轻松地定制自己的算法或修改现有算法。

（2）RLlib。
RLlib 是 Ray 项目的一部分，专注于分布式强化学习训练，它不仅支持单机多 GPU 训练，还支持大规模分布式训练。RLlib 的特点如下。
◎ 支持多种强化学习算法，包括但不限于 IMPALA、APPO、R2D2 等。
◎ 强大的分布式架构，适用于需要大量计算资源的大规模应用场景。
◎ 易于集成到现有的 Ray 生态系统中，方便与其他机器学习任务协同工作。
