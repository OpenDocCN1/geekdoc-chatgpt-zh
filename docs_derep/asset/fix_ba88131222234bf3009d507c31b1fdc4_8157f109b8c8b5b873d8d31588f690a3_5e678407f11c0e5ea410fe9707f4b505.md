相关性分析用于检验两个或多个变量的变动是否同向，从而判断一个变量能否在一定程度上推断另一个变量，例如身高与体重、气温与袜子销量、满意度与投诉率等。

**1．相关性系数**

常用记号为 r，取值 -1 到 +1。越接近 ±1 相关越强，越接近 0 相关越弱。

常用三种：皮尔逊、斯皮尔曼、肯德尔。

皮尔逊用于两个连续变量的线性关系，数据近似正态时适用。
斯皮尔曼用于等级或非正态数据。
肯德尔同样适用于非参数情境，在样本较小时更稳健。

符号与强弱判断：

正相关：一个变量升高，另一个也升高，系数为正。
负相关：一个升高另一个降低，系数为负。
无相关：线性关联不明显。

强度分级：
|r|>0.95 极强
|r|≥0.8 高度
0.5≤|r|<0.8 中度
0.3≤|r|<0.5 低度
|r|<0.3 弱

相关不等于因果。

**2．相关性分析适用的情况**

探索多个变量间是否存在联系且不区分自因变量时。
判断变量变化是否相互影响时。
初步筛选值得深入研究的变量，例如回归前先做相关。

**3．相关性分析的步骤**

先画散点图观察规律。
根据数据类型与分布挑选系数并计算。皮尔逊要求近似正态，需先检验。
做显著性检验并解释 p 值。
以文字报告数据来源、方法与结论。

低重要性高满意度：满意但影响有限，可维持。
