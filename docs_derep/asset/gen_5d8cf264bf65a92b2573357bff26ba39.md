## JSON 数据交换格式深度解析

JSON（JavaScript Object Notation）号称“轻量级”，相对 XML 标签冗余，字符少、体积小、传输快，早已成为 Web/移动端接口标配。

### 7.5.1

### JSON 文档的两大基石结构

JSON 世界里只有两种结构：**对象** 与 **数组**。

| 结构 | 对应 Python | 语法特征 |
| :--- | :--- | :--- |
| **对象** | `dict` | `{ "键": 值, ... }` 无序键值对集合，键必须加双引号 |
| **数组** | `list` / `tuple` | `[ 值, 值, ... ]` 有序值序列 |

值的类型可以是：字符串（双引号包裹）、数值、布尔值、null、对象、数组，**支持任意层级嵌套**。
