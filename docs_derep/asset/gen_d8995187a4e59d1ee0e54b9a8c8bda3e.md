在前几章中，我们已经掌握了如何依据既定权重推算神经网络的输出结果。然而，这些权重究竟源自何处？**训练**正是通过不断调整权重，使网络输出逼近预期目标的核心过程。而**评估**则是依据预期输出，对网络实际表现进行“打分”的环节。

本章将系统拆解训练与评估的体系。鉴于神经网络的训练评估手段多样，我们亟需一套统一的判断基准——**目标函数**。它负责为网络表现量化打分，训练过程则依据此分数迭代优化权重。通常目标函数倾向于“分数越低越好”，这称为**最小化**问题；反之若需分数越高越好，则为**最大化**问题。主流训练算法均兼容这两种模式。

理论上，任何连续优化算法（如模拟退火、粒子群优化 PSO、遗传算法、爬山算法、Nelder-Mead 算法或随机游走等）均可用于权重优化。本章将重点剖析**模拟退火**这一入门级训练算法。除优化算法外，**反向传播**是另一大核心训练范式，相关进阶算法将在第 6 章“反向传播训练”与第 7 章“其他传播训练”中详细展开。

## 5.1 分类任务的评估体系

分类任务旨在将输入数据划归至一个或多个预设类别。最直观的评估方式是计算**误分率**——即训练集中被错误归类样本的占比，这与人类考试的评分逻辑如出一辙。例如十道单选题答错一道，得分即为 90%。但机器分类往往不直接给出确定标签，而是输出各类别的**置信度概率分布**。

### 5.1.1 二值分类：在“两害相权”中寻找平衡

当输出仅为两类（如是/否、买入/卖出）时，涉及**二值分类**。以信用卡发卡审批为例：系统仅需决定“通过”或“拒绝”。评估核心指标为**假阳性（FP，Type I Error）**与**假阴性（FN，Type II Error）**。

*   **假阳性（FP）**：本该拒绝的高风险用户被发卡（放过坏人）。
*   **假阴性（FN）**：本该发卡的优质用户被拒绝（错杀好人）。

银行通常认为 FP 危害远大于 FN（坏账损失 > 机会成本），故倾向于降低 FP 率。这引出两个关键特性指标：
*   **敏感性**：倾向于判“阳”（通过率高），代价是 FP 增加。
*   **特异性**：倾向于判“阴”（拒绝率高），代价是 FN 增加。

[PRE4]

通过移动**判定阈值**可动态调节二者平衡：阈值左移→特异性增强（TN 区域缩小）；阈值右移→敏感性增强（TP 区域缩小）。

#### 业务场景决定阈值选择
并非总要最大化 TPR。预测桥梁坍塌案例中：
*   **FP（虚警）**：浪费工程师排查时间。
*   **FN（漏报）**：桥梁实坍塌，酿成悲剧。
此时必须大幅提升特异性（降低 FN），宁可多查几座安全桥，不可漏报一座危桥。

### 5.1.2 多类分类：输出层扩展与 Winner-takes-all

预测 3 个以上类别（如鸢尾花品种 Setosa/Versicolor/Virginica）需**多输出神经元**。单神经元仅能二分类，双输出极少用，通常类别数 = 输出神经元数。

[PRE11]

鸢尾花数据集：4 维特征（萼片/花瓣长宽）→ 预测 3 类别。网络结构为 **4 输入 → 隐藏层 → 3 输出**。
[PRE12]

输出层 3 个神经元分别对应 3 个品种，**输出值最大者即为预测类别**（Winner-takes-all 机制）。

### 5.1.3 对数损失：惩罚“自信且错误”的概率估计

简单准确率将分类视作非黑即白的选择题，但模型输出的是概率分布。若模型对正确类别给出 80% 置信度，理应得 0.8 分。然而**对数损失** 引入非线性惩罚，严厉打击“高置信度错误预测”。

其中：
*   $y_i \in \{0,1\}$ 为真实标签（训练集无概率，仅硬标签）。
*   $\hat{y}_i$ 为模型预测的正类概率。
*   负号将对数负值转为正，便于**最小化**优化。
*   两项互斥：$y_i=1$ 时仅保留首项 $-\log(\hat{y}_i)$；$y_i=0$ 时仅保留次项 $-\log(1-\hat{y}_i)$。

**核心逻辑**：损失 = $-\log(\text{正确类别的预测概率})$。

| 正确类别预测概率 | 对数损失值 | 解读 |
| :--- | :--- | :--- |
| 1.0 (完全正确且自信) | $-\log(1)=0$ | **零损失**，完美预测 |
| 0.8 | $\approx 0.22$ | 较小惩罚 |
| 0.5 (随机猜测) | $\approx 0.69$ | 基准惩罚 |
| 0.1 (自信犯错) | $\approx 2.30$ | **重惩罚** |
| $\to 0$ | $\to +\infty$ | **无限大惩罚**，模型崩溃 |

这迫使模型：**宁可谦虚给 0.51，不可自信给 0.99 却踩空**。这正是对数损失优于单纯准确率的精髓——它评估的是**概率校准质量**，而非仅是硬分类结果。

## 本章小结
1.  **训练本质** = 目标函数驱动的权重优化（最小化/最大化）。
2.  **二值分类评估**核心在于 FP/FN 权衡，通过阈值调节敏感性/特异性，用 ROC-AUC 量化综合能力。
3.  **多类分类**采用多输出神经元 + 最大值决策。
4.  **对数损失**通过对数惩罚机制，强制模型输出可靠的概率分布，是分类任务首选目标函数。
