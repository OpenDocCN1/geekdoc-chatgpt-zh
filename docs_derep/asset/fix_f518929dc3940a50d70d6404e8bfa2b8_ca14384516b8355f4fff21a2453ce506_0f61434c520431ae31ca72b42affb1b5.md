从纺织到像素：先导产业如何定义时代

棉纺织一度是工业革命的发动机，因为它具备四项关键条件：可容纳的市场极为宽广，需求看不到天花板，上下游环节足够绵长能够引发连锁反应，所需技术门类繁多足以让技术成熟并向外溢出。

在第一次工业革命到来之前，荷兰造船业的分工已非常精细。但造船无法打开能够承载工业革命的超大市场，最多只能培养出一批精湛手艺人。若想靠造船掀起连锁浪潮基本不现实。17世纪荷兰国力曾一度压过英国，可最终扛起第一次工业革命旗帜的仍是英国。历史把先导产业的选择给了棉纺，而不是渔业之类。

## 游戏，看似元宇宙的雏形

大变局往往伴随一个现象级赛道提供示范。今天游戏产业的基因与当年棉纺惊人相似。

其一是容量。2020年12月17日中国游戏产业年会上，中国音像与数字出版协会第一副理事长张毅君发布《2020年中国游戏产业发展状况》。数据显示行业仍在快跑，2020年总收入2786.87亿元，比2019年多出近500亿元，用户规模继续稳步上行。正如人人都要御寒保暖，人人也都有娱乐的精神刚需。

其二是弹性。爱美者一天可换一套穿，消费主义常说衣橱永远差一件合适的单品。游戏同理，玩家追求新鲜和差异化体验，需求近乎无限。

其三是链条。棉纺上游有种植、采摘、轧棉、纺纱、织布、印染等。游戏软件端有策划、开发、发行，硬件端有主机、芯片、操作系统，支撑通信则依赖5G、光纤等。

其四是外溢。棉纺拉动了农业、机械、运输、化工。玩家直观感受是内容总跑在硬件前面，需要更强的3D引擎、CPU、GPU、显示屏、VR、AR来托底。

大型游戏通常具备五大元宇宙雏形特征。

1. 基础经济运行：内建接近现实的经济规则，虚拟权益受保护，用户创造的虚拟资产可在游戏内流通。
2. 虚拟身份认同强：身份一致性高、代入感强，玩家通过定制形象、皮肤和独有属性获得归属感。
3. 社交属性突出：内置社交网络，支持文字、语音乃至视频实时互动。
4. 开放共创：世界内容庞大，主要靠海量用户创新，开放式共创是主导。
5. 沉浸式呈现：交互顺畅、信息密集、沉浸感强，既是元宇宙主要的内容载体，也是VR等设备最佳用武之地。

国盛证券研究报告从开放创作、沉浸体验、经济系统、虚拟身份与强社交五维度，评估了Roblox、Decentraland、Soul、《我的世界》《魔兽世界》《堡垒之夜》《王者荣耀》与元宇宙概念的关联[^(\[2\])](#part0020.xhtml#comment_7844)。结论是Roblox创作自由度极高，平台经济完备且可与现实经济互通，虚拟资产与身份可在不同内容间互通，创作者可自建商业模式，已显现元宇宙轮廓。《我的世界》在开放创作上接近元宇宙，其余维度仍有差距。《魔兽世界》在身份代入、社交与体验上接近概念。《堡垒之夜》人气极高。Decentraland在经济系统上更贴近。 《王者荣耀》有一定虚拟社交属性，与概念仍有距离。Soul仅在社交性与虚拟身份上与概念有少量交集。

元宇宙核心特质在游戏世界得到精彩演绎，但没有一款游戏能完全达标。由此可见游戏只是雏形，却足以帮助理解元宇宙。

### 游戏与 5G

视频之于4G，正如游戏之于5G，二者相互促进。若没有游戏对大带宽、低时延、高并发的强需求，5G部署会明显放缓，看视频4G已足够。业界曾把自动驾驶视作5G杀手级应用，但普及仍需时日。工业、矿业的5G案例已不少，单靠生产场景难以拉动整体产业，必须有消费级普及应用。游戏成为关键抓手。

真VR离不开5G。

影响体验的核心指标有视频分辨率、帧率、头部MTP时延、操作响应时延、肢体MTP时延等，后三者可通过算力、传感器、数字接口、操作系统优化改善，分辨率与帧率则直接关系临场感、逼真度与眩晕感。

VR要达到肉眼无法察觉纱窗效应的完全沉浸，需16K。16K约1.3亿像素，按24位真彩色、140Hz计算，每秒原生视频流量约138Gbps。随着硬件提升，要摆脱有线束缚，必须探索大带宽低时延无线网络与高效压缩算法。

华为测试报告显示，在110度水平视域、6 DOF、H.264编码下，单眼1.5K、60FPS为入门级，需带宽约25Mbps；单眼2K、90FPS为未来提升目标，需带宽约153Mbps；理想体验需单眼6K、90FPS，需带宽1.4Gbps，因此5G、千兆宽带、Wi-Fi6等下一代接入不可或缺。

### 游戏与数字货币

从经济视角看，每款游戏都是体验加消费，具备元宇宙特征的游戏还需加入创造。创造与消费推动基础价值循环。现代游戏本质上是虚拟经济体，内部需流通的货币。

氪金指游戏中充值行为。拥有氪金的游戏即为独立经济体。

商业模式经历变迁：初期如软件销售，售光盘一次性付费终身使用；盛大代理《传奇》开启点卡按时长收费时代；随后转向道具付费，游戏免费无限玩，需付费购买宝贝或皮肤，充值常态化，形成氪金一词。付费从一次性转向持续性，且通常不退款，玩家默认会消费掉充值。

Roblox做出大胆创新：充值后可提现。即便在美国金融创新活跃的环境下也颇具争议，引发洗钱监管等讨论。

Roblox内部发行Robux，简称萝卜币。游戏内购买道具仅能用萝卜币，制造道具可出售，玩家可赚取萝卜币，退出时可兑换美元。与出国兑换外币类似，机场可换汇，手续费与限额约束兑换规模。

货币是国家主权的象征，无独立货币难以构成独立国家。统一货币可形成紧密经济体，欧元即例。

在Roblox中，Robux让平台像经济体运行。有人为消费进入，有人为谋生而创作，设计新皮肤出售，玩家用萝卜币支付，卖家可随时兑换美元，形成买有卖有闭环。萝卜币展示了元宇宙经济雏形。

熟悉比特币、以太坊的读者会想到ETH，确可用以太坊实现萝卜币。具备元宇宙特征的游戏天然形成数字货币应用场景。随着元宇宙扩张，数字货币交易量快速上升。

以太坊可成为元宇宙通行货币，二者相互促进。DC/EP作为基础数字货币，也可成为元宇宙通行货币，二者同样相互促进。

### 理解数字孪生

2003年，迈克尔·格里夫斯教授在密歇根大学课程上提出与物理产品等价的虚拟数字化表达概念，定义为一个或一组特定装置的数字复制品，可抽象表达真实装置并据此在真实或模拟条件下测试，希望整合数据进行更高层次分析。

2011年，Michael Grieves在《几乎完美：通过产品全生命周期管理驱动创新和精益产品》中引用合作者约翰·维克斯提出的名词——数字孪生，并沿用至今。[^(\[2\])](#part0022.xhtml#comment_9298)

数字孪生最大突破在于物理实体与数字孪生体相互映射、相互影响。物理实体主要功能是采集数据并传给数字孪生体，数字孪生体汇聚数据、关联分析并给出动作指令，物理实体接收指令执行并再次采集数据。数字孪生体负责分析决策，物理实体负责执行。用文学化说法，数字孪生体是物理实体的灵魂。
