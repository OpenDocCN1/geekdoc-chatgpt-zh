打通最后一公里：平台工具层需要解决的几大关键卡点

让智能体从实验室走向真实业务，关键看平台工具层能否把分散能力串联起来。首要攻坚点是新一代低代码/无代码编排引擎，将可视化流程绘制、自然语言意图识别与多智能体协同结合，把繁复的业务逻辑自动转译为可执行并且能够自优化的行为链，降低复杂场景的接入门槛。随后需要提供标准化的组件开发能力，依托 API 网关中间层与异构系统适配器完成内外系统联通，使智能体在生产环境中形成完整闭环。再者对模块化功能组件实施原子级封装，避免重复造轮，沉淀行业知识，让智能体实现持续进化。针对多智能体协同，还需搭建分布式协作底座与全链路调试观测体系，引入基于强化学习的任务分派与冲突化解机制，并通过状态可视化追踪、意图偏离即时告警、异常回溯分析来保障交付安全可靠。最后要设计动态知识增强体系，以在线学习引擎与实时反馈回路为核心，结合检索增强生成和增量训练，把隐性经验自动提炼并动态注入，打破传统工作流知识更新固化的局限。上述能力相互融合，将推动开发模式从手工编排转向自主演进，最终形成具备感知、判断与自我进化的企业级智能体操作系统。

5）应用层面

中大型政企正在规模化引入 DeepSeek 大模型，并围绕 AI 驱动的业务升级进行前瞻规划与落地实践。对于已经在多场景部署智能体的用户，模型应用从单点延伸到多点，对集成提出新要求，涉及数据、技术内容与集成边界，如表 4-5 所示。在数据层面，AI 不再仅依赖结构化数据接入，需要统一处理文本、图像、音频、视频等非结构化内容及多模态感知信息，并进一步融合行业知识库、领域本体等复杂知识形态。在技术层面，AI 驱动的集成架构对数据访问与语义融合提出更高需求，除基础的数据贯通与标准化处理外，还需构建跨模态统一语义理解能力，支撑多源异构数据的动态感知与智能调度。同时集成往往伴随外部工具链协同调用、模型全生命周期集中管控、智能体间任务编排与联动执行，并叠加安全合规、权限管控、隐私保护等系统性约束，整体复杂度与耦合度明显提升。在集成边界上，传统集成多为固定业务系统间的点对点连接，刚性较大。AI 时代的集成呈现平台化、网状化趋势，借助智能中台与服务编排框架，可按需动态组合异构组件与作业单元，构建自适应、高弹性、强韧性的智能作业网络，更好支撑多变业务与智能决策。

**4.技术架构与创新突破**

深耕政企 IT 服务二十余年的中软国际，长期聚焦业务数字化提质增效，不仅提供方案与产品，还提供包含集成的全栈服务，助力客户持续释放数据价值，在大模型与智能体政企落地方面形成了有效探索与实践。

公司自 2023 年初全面启动 AI 战略，以 AIGC 研究院等创新组织为载体，快速搭建大模型相关基础设施。AIGC 研究院基于对技术发展趋势的深入研究与场景实践，总结出大模型落地的共性规律：以 ROI 价值为导向、以数据知识能力为前提、以持续优化运营为关键。基于此定位，公司致力于帮助客户打通大模型落地的“最后一公里”，提供覆盖算力基础设施运营、数据治理、模型训练、推理部署、端侧智能及智能体行业应用的全栈 AI 产品与服务。

在垂直行业深耕中，公司借助 DeepSeek 加速大模型与用户核心场景融合，构建起聚焦智能体构建与集成的关键技术与产品体系，覆盖算力与模型相关产品服务。公司发布自研的 JointPilot 灵析 AI 应用构建与集成平台，并推出“问”系列场景大模型、灵析问数等，形成“问”系列智能体产品矩阵。DeepSeek-R1、DeepSeek-V3 开源后，智能体“大脑”得到全面升级，“问”系列能力获得优化拓展，能更好地服务各行业专业场景与任务。面对企业级复杂需求，公司不仅关注智能体设计与构建，还通过数据资产接入治理、知识融合、大模型选型与多模型整合、智能体运营服务及 AI 新集成，形成体系化优势与差异化竞争力，真正释放大模型应用价值。

（2）智能体构建与运行管理。针对开发与运行痛点，公司基于 JointPilot 平台与 IFPEE 多智能体框架，发挥 DeepSeek 强推理能力，打造具备企业级复杂度、低幻觉、可信赖、安全且具备自我学习进化能力的智能体应用。平台提供智能体高效构建与一体化运行管理 AgentOps 核心能力，具备直观无代码可视化编排界面并支持团队协作开发，可无缝对接内部能力插件并集成 MCP 调用等各类外部第三方服务；将意图识别、对话管理等通用能力组件化，便于快速复用与沉淀；提供强调试观测能力，支持端到端全流程节点级精细化调试，确保运行状态透明可观察，提升问题定位效率；支持 PC、移动等多终端部署，以及公有云 SaaS 与私有化部署等灵活模式。

公司计划在智能体开发工具环境中进一步拓展 MCP 服务，与合作伙伴提供更多工具服务，并持续迭代 IFPEE，通过多智能体协同、智能体与人协同及智能体与传统系统协同，帮助政企客户突破数字化转型瓶颈。
