LLM 应用搭建手记：从基础组合到多链协作

搭建 LLM 应用，最核心的两个零件就是提示词和模型本身。把 PromptTemplate、LLM 再叠加上 OutputParser，就能组合出各种实用玩法。下面以 4.15.py 为线索展开。

1. Prompt 与 LLM 的最小闭环
先做一条最简链路：把用户的原始输入填进模板，得到加工后的提示词送给大模型，最后直接把模型的原始回复返回给调用方。

[PRE0]

2. 为模型绑定运行参数
在链创建的阶段就可以给 LLM 额外挂载配置，比如停止词、函数调用信息等，从而更精细地控制生成行为和输出格式。

[PRE1]

3. 接入解析器让输出结构化
拿到原始文本后往往还需要提炼。加上 OutputParser，就能把非结构化的生成结果拆解成可用的结构化信息。

[PRE2]

4. 用 JSON 解析器对齐函数签名
当需求是让模型按指定函数签名返回时，JsonOutputParser 或 SimpleJsonOutputParser 是常用选择，其他解析器可参考 https://github.com/langchain-ai/langchain/blob/master/libs/core/langchain_core/output_parsers/__init__.py。

[PRE3]

5. 让链调用更省心
借助 RunnableParallel，可以自动拼装提示所需的输入字典，避免手工组装参数的繁琐。

#### 4.5.4 多链组合
Runnable 的设计让多条链串联变得很顺滑。通过管道操作符 “|” 可以把不同链拼接起来，组成复杂的工作流。

【例4-16】 多链组合（参考代码4.18.py）。

from langchain_community.llms import Ollama as OllamaLLM

from langchain_core.prompts import ChatPromptTemplate

from langchain_core.output_parsers import StrOutputParser

from langchain_core.runnables import RunnablePassthrough, RunnableParallel

prompt1 = ChatPromptTemplate.from_template("{product}的优点有哪些?")

prompt2 = ChatPromptTemplate.from_template("基于以下优点, 创作一条{product}的广告语:\n{advantages}")

model = OllamaLLM(model="gemma:2b")

chain1 = prompt1 | model | StrOutputParser()

chain2 = {"advantages": chain1, "product": RunnablePassthrough()} | prompt2 | model | StrOutputParser()

print(chain2.invoke({"product": "iPhone"}))

prompt1 = ChatPromptTemplate.from_template("以下是一家餐厅的基本信息:\n{basic_info}\n 请根据这些信息, 生成一段营销文案, 突出餐厅的特色和优势, 吸引顾客光临.")

prompt2 = ChatPromptTemplate.from_template("以下是一家餐厅的基本信息:\n{basic_info}\n 请根据这些信息, 提出3条经营建议, 帮助餐厅改进服务, 提高竞争力.")

prompt3 = ChatPromptTemplate.from_template("以下是一家餐厅的营销文案和经营建议:\n 营销文案:{marketing}\n 经营建议:{advice}\n 请对这两方面工作提出评价和指导意见, 帮助餐厅更好地开展营销和经营活动.")

model_parser = model | StrOutputParser()

chain1 = prompt1 | model_parser

chain2 = prompt2 | model_parser

chain = (

    {"basic_info": RunnablePassthrough()}

    | {

        "marketing": chain1,

        "advice": chain2,

    }

    | prompt3

    | model

)

basic_info = """

本餐厅是一家主打健康养生的中式餐厅。主要特色:

1. 食材新鲜, 有机蔬菜直接从农场采购。

2. 烹饪注重养生, 少油少盐, 保留食材原汁原味。

3. 环境雅致, 设有包厢, 适合家庭聚餐和商务宴请。

4. 服务友善专业, 定期举办针对老年人的健康饮食讲座。

5. 交通便利, 地铁二号线旁, 商圈附近, 车位充足。

"""

print(chain.invoke({"basic_info": basic_info}))

这段代码演示了借助 LangChain 与 Ollama 模型，通过管道操作符和 Runnables 组件搭建多步骤自然语言处理流水线。

第一个例子是一个两步流程：先让模型列出指定产品的优点，再基于这些优点生成一条广告语。实现上把 chain1 和 chain2 用管道连接，并用 RunnablePassthrough 透传额外输入。第二个例子更为复杂，先并行产出餐厅营销文案和经营建议，分别对应 prompt1 和 prompt2，然后把两份结果合并作为 prompt3 的输入，由模型给出综合评价和指导。并行生成与结果合并都通过管道中的字典嵌套完成。
