三指标协同交易笔记：均线定势、RSI定区、MACD抓点

相对强弱指数
RSI 主流用6日短线版和14日常用版，30与70是两个关键分水岭。
基本买卖信号
RSI 回落到30之下后出现抬头，说明超卖状态，杀跌动能接近耗尽，多半迎来反弹，可作为低吸时机；RSI 冲上70之上后出现掉头，说明超买状态，上涨动能减弱，后续回调概率加大，可考虑减仓落袋。
使用提醒
不能只看数值。牛市中股价持续向上，RSI 常长时间盘踞在70之上形成钝化，这时贸然离场容易错过主升浪，需要结合均线趋势研判；熊市中股价持续向下，RSI 也会长期徘徊在30以下形成钝化，盲目抄底极易被套，应等待趋势扭转的迹象。

MACD 作为趋势动量探测器
MACD 由快线DIF、慢线DEA和红绿柱构成，可同时观察方向与力度。
方向判断
DIF 从下方穿越DEA形成金叉，若落在零轴之下代表由弱转强，落在零轴之上代表强势延续，均偏多；DIF 从上方穿越DEA形成死叉，若在零轴之上代表由强转弱，在零轴之下代表弱势延续，均偏空。
力度判断
红柱持续放大说明多头能量在累积，趋势上行可继续持有；红柱开始缩窄并转绿，说明多头乏力，需警惕回撤；绿柱持续放大说明空头占优，应回避；绿柱缩窄并转红，空头衰竭，可留意反弹机会。
顶底判断
顶背离：股价创出新高，而DIF或红柱并未同步创新高，显示价格涨不动，是见顶提示，应止盈；底背离：股价创出新低，而DIF或绿柱并未同步创新低，显示价格跌不动，是见底提示，可布局低吸。

三者配合
单一指标易踩坑。思路是均线定大势、RSI定区间、MACD定转折。
低吸组合：均线显示股价运行在年线之上处于长期牛市 + RSI 回落至30到50区间且未出现超卖钝化 + MACD 出现底背离或零轴下方金叉，三者共振可放心吸筹。
止盈止损组合：均线显示股价跌破60日线或年线趋势受损 + RSI 在超买后掉头向下 + MACD 出现顶背离或零轴上方死叉，三者共振应果断止盈止损。
小结：均线管方向，决定是否参与；RSI 管进出点位，决定何时动手；MACD 管变盘确认，提高判断精度。

交易纪律与策略
趋势跟随：价格向上突破前期重要阻力时进场，向下跌破重要支撑时离场，做趋势的追随者。
波段操作：在上升通道下沿附近买入、上沿附近卖出；震荡市中在支撑位吸筹、在阻力位派发。
必须设置止损。技术分析建立在趋势延续的假设上，一旦判断错误要立刻认错离场，避免小亏拖成大亏。

5.量化思维在个人投资中的应用——打造你的“投资机器”
不需要会编程，借鉴量化精髓就是系统化、规则化、纪律化。
把逻辑转化为明确规则，例如当全市场A股PE低于15倍且广义货币增速大于10%时，将股票仓位提升至80%。
建立检查清单，买入前逐项核对：商业模式是否优秀、估值是否合理、管理层是否可靠等。
定期复盘，按季度或年度回顾决策，分析成败原因，不断完善规则手册。
任何策略都有适应环境，牛熊震荡时都会失效。要清楚局限，在持续失效时保持警惕，但不要轻易放弃长期有效的策略。

### 8.4 防御武器体系——固收类与现金类
权益类负责进攻，固收与现金负责守护根基，保障稳定与流动性。

8.4.1 债券：不仅仅是“保守”的选择
债券本质是借条，向发行人出借资金收取利息并在到期收回本金，风险收益特征与股票迥异。
利率风险是最大风险。债券价格与市场利率反向变动，手中3%票息的存量债，若新发同类利率升至4%，吸引力下降，只有价格下行使实际收益率接近4%才会被买走。久期衡量价格对利率的敏感度，久期越长波动越大。
信用风险是违约风险。国债、政策性金融债有国家信用背书，风险极低，被视为无风险资产。信用债如企业债、公司债按评级从AAA、AA+、AA递减，评级越低违约可能越大，利息越高。
流动性风险是急用钱时能否以合理价格快速卖出，部分冷门或低等级债券可能有价无市。
国债/政金债是组合压舱石，也是衡量其他资产收益的基准，波动主要反映利率预期。
高等级信用债AAA/AA+承担微小信用风险换取更高收益，是平衡型组合的主力。
可转债兼具债性和转股权，下有债底保护，上可分享股价上涨，风险收益介于纯债与股票之间，行情不明时可作试探。
心法：远高于同类收益率往往暗含信用风险。预期降息可适当拉长久期，预期加息应缩短久期或持有现金。股债跷跷板效应下，股市大跌时资金涌入债市推升价位，均衡配置可自然对冲。

8.4.2 现金管理工具的升级：别让钱“睡觉”
现金目标是安全与流动性前提下的效率提升。
第一层T+0/T+1近卫军。货币基金收益高于活期，风险极低，快速赎回通常有1万元额度，适合存放3到6个月应急金与日常流动资金。银行T+0理财功能类似，注意起购门槛与银行实力。
第二层7天到3个月机动部队。同业存单指数基金主要投银行同业存单，风险略高于货币基金收益也略高，净值有小幅波动，适合未来数月不用但仍需流动性的资金。短期纯债基金投期限较短债券，收益波动均高于货币基金，可作升级替代。
第三层3个月以上战略储备。期限较长的国债回购在季末年末资金紧张时收益率可能显著抬升，可在利率高位选择28天、91天锁定阶段性收益。银行定期存款与大额存单受存款保险保护，绝对安全，降息周期提前锁定长期利率有价值，适合为学费等特定目标准备资金。小技巧：节假日前最后一个交易日操作1天回购可吃到整个长假利息，节后即可用；货币基金通常在周四下午3点前申购可计入周五周六周日收益。
现金是期权，是组合最宝贵的灵活性来源。市场缺乏机会时持现金不是妥协，是在积累未来开火的权利。熊市里现金为王。

8.4.3 “固收+”策略：稳健中的进取
对风险承受偏高但不愿承受股价大幅波动的投资者，“固收+”是折中方案。以债券为底仓获取稳健收益，少量配置权益或打新衍生品做增强。常见形式为偏债混合、二级债基、固收+主题银行理财。
预期收益率高于纯债低于股票，波动回撤大于纯债远小于股票，年度最大回撤通常在3%到8%之间。
选择时看清加法内容是股票、可转债还是打新，风险各异；关注历史最大回撤与波动率，选择回撤控制好的产品；管理预期，不要指望牛市中跑赢股市，核心是稳中有进。

### 8.5 辅助与特殊武器——理解边界，恪守禁区
进攻与防御之外，武器库还有功能独特但使用条件苛刻的特种装备。成熟的标志是了解其存在、敬畏威力、明确边界。

8.5.1 黄金：穿越千年的“终极避险图腾”
黄金不是生息资产，不派息不分红，价值来自人类长期赋予的抽象属性，可视作极端情况的保险单。
金融属性：在信用货币时代，对政府信用或货币购买力怀疑加深时，黄金货币属性会回归。
避险属性：黑天鹅事件爆发市场系统性恐慌时，需求急升。
商品属性：工业与装饰需求占比很小。
能做什么：对冲货币信用贬值风险，如2022年俄乌冲突初期金价飙升；对冲尾部风险，在滞胀等股票债券可能同时失效时独立走强；作为低相关补充，组合中少量配置可适度降波动。
不能做什么：不创造财富，长期真实回报微薄，远低于股票；波动巨大，可能经历多年熊市如2013到2018；机会成本高，大量配置会放弃生产性资产的长期复利。
配置铁律：整体占比不超过5%。工具首选实物黄金ETF，兼具支撑、流动性与低成本；备选银行积存金或纸黄金，避免高溢价饰品金、识别难的实物金条、带杠杆的期货或T+D。心法是买在焦虑卖在狂热，视其为压箱底的终极保险。

8.5.2 房地产投资属性的当代审视
指以增值目的的非自住房产。过去二十年从居住消费品演变为金融投资品，但本质决定其无法成为纯金融资产。流动性差、单体特异性强、持有成本高、政策敏感。
曾有的功能：在高速城市化信用扩张期核心城市房产是储值工具；低首付杠杆放大收益；租金提供被动收入。
当下风险：人口结构逆转、老龄化少子化、城镇化放缓；房住不炒政策定力，投机属性被压制；总量过剩分化，普涨结束仅少数核心城市核心地段可能保值；机会成本与流动性陷阱，资金沉淀错失机会且急用时可能卖不掉。
投资性房产需同时满足城市、物业、财务三重条件，构成严苛筛选器。城市必须是人口持续净流入、产业有活力、财政健康的强一线强二线核心区域；物业必须是顶级地段、优质配套、好物业好户型的不可替代好房子；财务上租金收益率需覆盖大部分利息与持有成本，现金流接近打平或为正，拒绝负现金流赌暴涨模式。
绝对禁止：月供超过家庭稳定收入50%的高杠杆；投资陌生城市的旅游地产海景房概念盘；小产权房、产权不清商铺、高额返租陷阱。
对大多数人，投资房产已不友好。第一套房应基于居住需求。若想参与周期，可关注REITs，提供分红、专业管理与高流动性，更纯粹的金融工具。

8.5.3 理解另类投资：高门槛的“专业竞技场”
私募股权、风险投资、对冲基金、大宗商品期货、艺术品、加密货币等看似诱人，实为专业领域，普通人贸然入场风险极高。
私募股权/VC投非上市公司，锁定期5到10年，起点百万元级，信息不透明成功率低，依赖管理人眼光。对普通人几乎无关。
大宗商品期货押注原油、铜、大豆等价格，高杠杆高波动，纯零和博弈不产生现金流，需精准判断短期方向，属于专业交易员领域。

8.5.4 明确禁区：必须坚决远离的“财富坟场”
加密货币是价格由投机情绪、监管消息、技术叙事驱动的高风险投机资产，波动极致，监管不确定，欺诈操纵盛行，不产生现金流不代表生产性资产所有权。
高息理财与民间借贷是以高回报诱饵的庞氏骗局或信用陷阱。铁律是风险与收益匹配，任何远高于无风险利率且宣称保本保息的产品都在觊觎本金。P2P网贷集体崩盘是血的教训。
你不理解的东西是能力圈原则的终极体现，坚决不碰。
