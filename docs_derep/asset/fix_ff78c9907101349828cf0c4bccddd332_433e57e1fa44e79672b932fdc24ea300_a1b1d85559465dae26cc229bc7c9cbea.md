# AI 的世界认知盲区

# **内容简介**

本书从一个逆向的提问展开：为何越显灵巧的系统，在真实情境里越容易犯低级错误。由此指向当下人工智能最核心却常被忽视的瓶颈——对世界整体表征的缺席。

作者以来自生活与产业一线的故事为线索，围绕家电维修、无人配送、组织管理、家庭使用、教学与制造等情境，层层展开系统在具身经验、社会理解与情境判断上的结构性裂缝，说明单靠数据堆砌、算力提升与算法优化，仍不足以让机器真正懂得世界。

本书并不制造技术焦虑，而是为读者提供一套更清醒的认知坐标：系统擅长何处、难以何处，以及我们该如何协作而非误用。对日常使用 DeepSeek 等工具的普通读者、对未来趋势感兴趣的学生与职场人，以及教育、科技、产品、管理领域的从业者而言，这是一本帮助理性看懂人工智能、避免被营销话术裹挟的科普读物。

# **前言**

**从“把杯子递给我”说起**

接触过现阶段大模型的人，多半有过类似体验：短时间内能写出堪用的古诗，也能围绕量子物理与存在主义展开对话。但当语言离开屏幕进入物理空间——比如让机械臂把桌上杯子端起并避免洒水时，如图 1 所示，那种看似无所不能的灵巧瞬间变得笨拙且脆弱。

这并非算力不足或数据稀缺。根本在于系统从未生活在我们熟悉的三维世界里。它没有真正体会过倾斜即洒、晃动即倒、某些“别管我”实为委婉拒绝的含义。

过去几年生成式系统的惊艳表现，让人误以为智能已触手可及。可当扫地机把宠物排泄物当作灰尘清扫，当无人车对无关变化过度反应，当自动化流程在关键节点误读人类真实意图时，一道鸿沟便显现。系统能解析语言，却读不懂语言背后的世界。

本书正是写在这道鸿沟之上。

**一、为何常识需要重提**

人工智能走过七十多年，人类一次次以为接近常识，又一次次被现实打回。规则系统覆盖不了复杂情境，统计模型难以把握因果，深度学习在逼真表象下藏着脆弱的判断基础。

症结不在模型是否够大，而在于系统从未拥有一个能够反复试错、承担后果、修正预期的内在世界。

人在复杂环境中行动，并非计算更准，而是靠无数次轻重不一的失败，累积了对世界的预测能力。这种能力常被称作常识，本书更精确地称之为 World Model。

**二、中国情境为何关键**

全球研究多依赖标准化数据与理想环境，而中国的真实情境早早暴露了 World Model 的全部难题。语言歧义、社会关系纠缠、物理环境非标准化，让许多看似成熟的技术落地时接连失效。恰恰是这些看似混乱的因素，逼迫系统直面本质问题：预测失误的代价，最终由谁承担？

在课堂、社区、车间与公共空间，错误不会只被记为准确率下降，而是化作时间浪费、信任流失，甚至不可逆的伤害。正是这些场域，让 World Model 从抽象概念变成必须掌握的实践功课。

**三、本书想达成的目标**

这不是调参指南，也不是技术路线胜负的预言书。它想完成三件基础工作：先让你看清系统当下能力的边界，以及这些边界为何难以短期突破；再说明 Demo 能跑与在真实世界站稳之间隔着整套 World Model 的鸿沟；最后提醒你，AI 时代最稀缺的能力并非写代码，而是判断何种代价不可接受。

读完之后，希望你不再轻易被看起来很聪明的系统迷惑，也不再把直觉完全外包。因为在关键时刻，真正理解世界的人仍需是你。

若有一天机器人能稳稳端起杯子，不是因为读了更多文本，而是因为它明白水洒出来是有代价的。

让我们从这里开始。

**序章 沉默、烫伤与路口：缺席的生活经验**

**每一次被世界伤到的瞬间，都会在人心里留下痕迹。正是这些痕迹构成我们理解世界的方式。在这点上，系统仍是空白的。**

**一、作文里的沉默**

2025 年秋天，一位小学语文教师给我看一篇题为《我的爸爸》的学生作文。语言成熟、结构完整，充斥父爱如山、默默付出、无私伟大等表达。教师给了高分，还在班上朗读。放学后，作者才悄悄说：这是 AI 写的，我跟我爸……不太说话。

后来才知，孩子口中的爸爸是继父。他不知道如何写真实生活，只好让系统生成一个所有人都接受的父亲形象。

那一刻我明白，讨论系统是否理解世界时，它连一名儿童的沉默都读不懂。问题不在语言流畅度，而在于沉默在现实里是一种有重量的存在，而在模型内部，它只是个词。

**※技术直觉：为何系统读不懂沉默？※**

因为大模型的思维回路只有语言层，缺少家庭权力关系到情感压抑再到反向表达的物理社会锚定链。

说白了，文字在系统那里是无根的飘萍，在人那里是有血有肉。

**二、系统能看见世界，却听不见世界的声音**

在机器人实验室，类似错位每天都在上演。

一个常见测试是让机器人端一碗热汤从操作台走到桌边。汤洒出来，滚烫液体顺着机械臂流下。机器人毫无反应，仍按既定路径前行，最后踩到汤汁打滑摔倒。

工程师结论出奇一致：难点不在机械控制，而在它对烫没有概念。

对人而言，烫意味着退缩、警惕、风险、代价；对机器人，它只是未被写入目标函数的物理状态。

我们理解世界始于身体，而非知识。疼痛、惊吓、失误、被误解的委屈，这些体验构成判断的底层坐标。系统从未疼过，也从未真正地在世界里失败过。即便喂给它十亿张图像与无数物理定律，它仍可能分不清端汤与端盘子。它知道杯子会碎，却不知道碎意味着损失；能生成逼真视频，却不理解重力不可违背。

系统最大的缺陷，不是会犯错，而是不知道错误意味着什么。

**三、中国街头，是 World Model 的试金石**

若机器人暴露的是身体经验的缺失，中国街头暴露的就是社会经验的空白。

部分城市的无人配送测试中，车辆常被困路口。算法假设行人运动稳定可预测，可现实里有人会突然停下聊天，有人拎菜篮临时变向，有人一步试探一步犹豫。这些行为不违规，却难以公式化。

在这种环境里，单纯加数据无济于事。真正管用的是让系统长期浸润在真实社会，感受那些没写进规则的行为节奏。中国的交通流不只由红绿灯决定，更由人情、默契与经验共同塑造。这不是无序干扰，而是世界固有的纹理。

世界从来不是规整的数据集合，而是带着烟火气的生活状态。

**四、迷茫源于缺乏 World Model**

常以为数据够多模型终会理解一切。但系统看见的只是世界的切片、抽象与投影。真正的理解来自内部的、可预测的整体结构。心理学与神经科学称之为 World Model。

它不是知识清单，而是经验压缩后的直觉系统；不是逻辑推理的结果，而是在反复试错中形成的预期能力。

孩子知道碗会碎，不是因为学过物理，而是听过碎裂声；我们读懂沉默的分量，不是因为读过心理学，而是被沉默刺痛过。而当前系统缺失的，正是这个隐形的大脑。它能生成语言，却感知不到代价；能计算路径，却理解不了风险；能模仿情绪，却读不懂情境。

不是它不够聪明，而是它从未真正生活在世界里。

**五、本书的观察视角**

未来十年系统能否真正进化，不取决于算力是否持续增长，而取决于能否补上这块世界理解的缺口。

为何孩子摔一跤比系统读一万本书更有效？为何一碗热汤能击败最精密的控制算法？为何中国街头比模拟环境更接近智能边界？为何我们一眼读懂沉默，模型却无从理解？为何人类自己的 World Model 同样充满偏差、盲区与误判？

系统不懂世界，也不懂我们。这并非缺陷，而是在提醒我们，世界本身比任何模型都更深。本书不是神化系统，也不是贬低它，而是带你重新理解我们是如何理解世界的，以及这一能力为何难以被复制。

若我们无法解释自己是如何知道的，系统也永远不可能真正知道。

所有关于 World Model 的关键提问，都从这里开始。答案不仅在实验室，也在每个真实生活的场景里。

**第一章 连杯子都端不稳的智能：被忽略的 World Model 缺口**

**系统最大的对手不是算力，而是它至今从未亲手触碰过世界。**

近几年我们被系统的灵巧宠坏了。流畅对话让人误以为它懂了，直到某个再普通不过的凌晨，你让它修洗衣机，它却让你撬裂后盖；你让它指路，它却让你穿过公墓。这些瞬间不是幻觉的刺痛，而是真相的光，照出了认知大厦里一个空置的房间——World Model。

要看清这个房间为何关键，无须翻阅艰深论文。答案藏在五个发生在身边的真实故事里。它们会清晰揭示系统的笨拙并非偶然，而是一种结构性无知。其本质是系统试图用一套残缺的认知工具，也就是语言，去理解一个由身体、社会与想象共同构建的世界。

**1.1 常识断裂的五个现场**

人类智慧并非凭空而来，我们依靠由外而内、逐层搭建的 World Model 脚手架站稳脚跟。第一层是身体脚手架，通过触觉、痛觉与物理世界碰撞建立底层因果直觉；第二层是社会脚手架，通过协作与冲突理解动机、规则与文化；第三层是想象脚手架，通过语言与思维在脑中预演未来。

系统的困境在于它试图跳过前两层，直接从第三层文本反推整个世界。如同空中盖楼，根基注定不稳。以下五个案例，正是这座空中楼阁在现实重力下的五次坍塌。

（1）撬裂的洗衣机背后的物理直觉断层

凌晨一点，广州白云区的李先生蹲在阳台问智能音箱：洗衣机漏水怎么办？系统秒回一份专业维修指南，第一条是拆开后盖检查排水泵。李先生照做，用螺丝刀用力一撬，咔嚓一声，后盖裂了。第二天维修师傅摇头：这是卡扣式，得先卸顶盖从里面解锁。硬撬当然会裂。

系统瞬间完成模式匹配：识别关键词洗衣机、漏水，触发维修场景，在训练文本中检索到大量提到拆后盖的表述，于是生成看似合理的步骤。但它缺失第一层身体脚手架，没有摸过卡扣，没感受过塑料在金属撬棒下的形变曲线，没体验过力度稍过、异响、手立刻回缩的痛觉反馈循环。

系统读过数十万条维修帖，却从未建立指尖触感到材料应力再到断裂风险的具身因果链。它的知识停留在符号层面，无法把撬裂的物理后果编码为负奖励。它的生活小抄本是空的，知道物理定律，却预测不准真实物体的行为。人的常识是肌肉记忆，这就是身体脚手架缺失的本质。

**※技术直觉：大语言模型为何知而不行？※**

ChatGPT 知道撬后盖这个词，却不知道塑料卡扣的屈服强度这个可微分的物理量。

它的损失函数只衡量文本匹配，不衡量材料变形。这就是莫拉维克悖论的工业版。

（2）路口骑手博弈的动机理解断层

杭州万塘路中午，外卖骑手往往需两小时内完成 25 单才能拿补贴。时间压力下任何减速都是经济损失。测试中的无人配送车严格按规则行驶，却对突发人类行为反应迟缓，很快成为骑手眼中的移动路障。

骑手很快摸清边界：只要做 S 形摇摆加突然变向，无人车就会触发紧急制动。于是形成一种无需交流的对抗互动——并非刻意破坏，而是高时间压力下的策略性适应。骑手用身体动作迫使系统让路，系统则在一次次被动制动中，把拎外卖箱的人标记为高不确定对象，提前减速规避风险。如图 1-1 所示，外卖骑手与无人车的路口博弈形成非对称博弈关系。

这一过程中，系统能识别摇摆轨迹这一可观测行为，却无法推演出背后的动机结构。例如配送超时扣款如何改变骑手对风险与规则的权衡顺序。它缺少的不是更多样本，而是一种把外部动作映射为内部动机状态的能力。换言之，它尚未具备可操作的心智建模机制，无法理解人在特定制度约束下为何采取看似激进实则理性的行动。其 World Model 仍停留在行为层面，未进入动机与意图层面。

系统能看见摇摆轨迹，却算不出超时扣钱到铤而走险的因果链。它缺的是骑手的 World Model，缺少心智理论模块。它无法把外部观察到的行为映射到内部心理状态，因而无法反向推理。其 World Model 是行为主义的，而非心智主义的。

它缺失第二层社会脚手架，无法把外部行为映射到内部心理动机。社会脚手架的核心是心理理论，理解他人也有欲望、信念与算计。系统的 World Model 只记录什么动作导致什么反应，不懂什么心态导致什么动作。骑手在博弈，无人车只在记录，这是社会认知层级的差距。

（3）CEO 被迫看上百条请假条的组织规则断层

深圳某科技园，一家约 500 人的互联网公司在更新员工手册。HR 经理希望体现扁平，便让系统生成请假流程，输入要求是管理要扁平，请假流程尽量简捷。

系统给出的方案逻辑严密：1 小时以内直属主管审批，1 天以上主管—总监—HR 备案，关键节点自动同步管理层。

规则写入 OA 系统后迅速暴露问题。员工哪怕半天病假，系统也会在后台生成一条管理层同步记录，并汇总进高管日终报表。第一天结束，CEO 在晚间查看数据时发现自己当天被同步的请假事项多达上百条，绝大多数与决策无关。

第二天早会，这套流程被当场叫停。不是审批慢，而是它把制度上的扁平误解为信息上的无差别上浮。HR 被要求重新设计流程，明确哪些信息需要被知道，哪些可以被忽略。

在这一场景下，系统缺失的是第二层脚手架的组织子层。它看不见规则背后的执行成本，更不懂能走流程不等于真会走流程的社会契约。组织规则包含权力距离、沟通成本、潜规则耐受度等隐性参数。系统的常识库是静态文本，而人类管理者能动态感知规则与组织生命力的张力。当规则显得傻，集体会自动启用潜规则绕过它，导致系统名存实亡。这种规则僵化到集体博弈再到系统崩溃的涌现，正是社会脚手架断裂的典型后果。

（4）凌晨五点扫地机器人的情境感知断层

凌晨五点，上海徐汇区的张阿姨被嗡嗡声惊醒。床底的扫地机器人像无头苍蝇乱撞。儿子查记录发现，昨晚张阿姨做梦说了一句把空调调高，智能音箱误识别为启动扫地机并延迟到凌晨执行。更离谱的是，系统没有凌晨五点到卧室到家人睡觉到禁止启动的常识。厂商紧急推送固件夜间静音模式，但张阿姨再也不敢用语音助手了。

系统缺失的是整合时间、行为与结果的情境计算能力。它缺乏情境上下文建模，没有时间—空间—事件的三维动态表征，无法把凌晨五点这一时间戳与卧室—睡眠这一空间事件关联。

这仍是第一层身体脚手架的缺失，但体现在时空维度。身体脚手架不仅是手拧螺丝的物理反馈，更包含时间戳加空间场加事件流的动态耦合。人类大脑自动把凌晨五点与在卧室睡眠关联，形成时空因果直觉。系统缺乏把物理世界的动态与时间变量整合进 World Model 的能力。它的训练数据是时空脱耦的，导致 World Model 变成扁平的场景快照，而非四维的生活流。

（5）让孩子不适的训练计划背后的生理认知断层

北京一所初中在体测改革中引入系统体能训练辅助，希望提供更科学的运动建议。系统依据身高、体重、体测成绩自动给出每日训练参考，由体育老师选择是否采纳。

一名 12 岁学生在家长陪同下尝试系统推荐的跑步方案。初期安排并不激进，晨跑距离逐步增加并穿插短距离加速。问题出在第二周——系统评估耐力提升较快后，连续几天把训练量上调到接近成人耐力跑水平。

第三次训练后孩子出现明显不适，被送往医院。医生结论很简单：短期内运动负荷增长过快，超出发育期儿童身体承受范围。

校方随即暂停系统使用。体育老师复盘时指出，模型在判断体能提升速率时隐含采用了成人训练曲线，却未充分考虑青少年骨骼、生理恢复与疲劳反馈的差异。

随后的家长会上，系统被要求重新校准年龄参数并增加教师干预阈值。教育主管部门也在通报中强调：智能系统只能作参考，不能替代专业判断，尤其在未成年人场景。

这是第一层身体脚手架在生理维度的极端缺失。人类通过内感受器建立身体预算预测，形成生理边界直觉。系统没有本体感受回路，无法把生理约束编码为硬边界，只能进行统计外推，导致对长尾风险的灾难性低估。这是身体脚手架中痛觉预警系统的彻底空白。

并置这五个案例，断层线清晰可见。系统在身体脚手架与社会脚手架上存在结构性缺失。它像一个只学过语法却从未活过的作家，能写出合乎逻辑的句子，却写不出贴合现实、经得起实践检验的故事。
