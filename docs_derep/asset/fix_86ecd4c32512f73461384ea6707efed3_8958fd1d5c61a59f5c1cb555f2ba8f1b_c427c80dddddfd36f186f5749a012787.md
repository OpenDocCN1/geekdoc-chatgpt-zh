## 4.8.2 UNIX 操作系统简介
UNIX 是一款多用户多任务的操作系统，1974 年问世后在全球迅速推广。它运行于硬件与应用程序之间，负责统一调度和管理各种软硬件资源，并向上层提供简洁统一的调用接口，保证程序正确运行。UNIX 与其他系统的差异主要在于内部实现方式与用户交互界面的不同。

### 1. UNIX 操作系统的组成
（1）kernel 内核：UNIX Kernel 是系统的核心，负责指挥调度机器运行，直接掌控硬件资源，屏蔽硬件细节对用户程序的干扰。
（2）shell 外壳：UNIX Shell 是内核与用户的中介，兼具命令解释功能。

### 2. UNIX 系统基本结构
UNIX 共分为五层。最底层为裸机，即没有任何软件的纯硬件；第二层为 UNIX 核心，依托裸机实现文件管理、进程管理、存储管理、设备管理、网络管理等关键功能，内核程序不可被用户直接调用，只能通过系统调用以规范方式请求服务；第三层为系统调用，作为应用层与核心层的接口；第四层为应用程序层，包含编译程序、文本编辑处理程序、系统命令、窗口图形软件包、各类库函数及用户自编程序；最外层为 Shell 解释程序，是用户与操作系统的交互通道。

### 3. UNIX 应用范围及特点
UNIX 基本适用于 16 位及以上的各类机器，涵盖微机、小型机、多处理器和大型机。
其主要特点为：支持多任务多用户、稳定性好移植性强、并行处理能力突出、具备安全保护机制、Shell 功能强大且网络支持能力完善。

## 4.8.3 Linux 操作系统简介
Linux 是一款可免费使用并自由传播的类 UNIX 系统，诞生于 1991 年 10 月 5 日。它支持多用户、多任务、多线程和多 CPU，可运行主流 UNIX 工具软件、应用程序和网络协议，兼容 32 位和 64 位硬件。Linux 继承了 UNIX 以网络为核心的设计思想，是一个稳定可靠的多用户网络操作系统，主要面向基于 Intel x86 系列 CPU 的计算机。Linux 以高效灵活著称，采用模块化设计，既可在高端工作站运行，也可在低价 PC 上完整呈现 UNIX 特性，具备多任务多用户能力。
Linux 发行包除完整操作系统外，还包含文本编辑器、高级语言编译器等应用软件，并提供带多个窗口管理器的 X-Windows 图形界面，支持窗口、图标、菜单操作，使用体验与 Windows NT 相近。
Linux 与 UNIX 的最大区别在于源代码开放性：Linux 为开放源代码的自由软件，UNIX 为源代码受知识产权保护的商业软件。由此 Linux 用户拥有高度自主权，UNIX 用户多被动适应；Linux 开发在开放环境中进行，UNIX 开发相对封闭。另，UNIX 多与硬件捆绑，Linux 可运行于多种硬件平台；UNIX 为商业软件，Linux 为免费自由软件且源代码公开。

# 本章小结
本章第 1 节介绍了操作系统的概念、类型、发展历程和作用。操作系统是计算机系统中的重要系统软件，由若干功能模块构成，负责管理和控制硬件及软件资源，合理组织工作流程，为用户提供功能完备、易用、可扩展、可管理且安全的环境，在计算机与用户间起到接口作用。总体而言，操作系统管理内部资源并提供友好界面。
第 2 节介绍了操作系统的主要类型及使用范围，包括批处理、分时、实时、通用、网络和分布式操作系统。批处理系统使用户脱机，操作员分批处理作业，多道程序并发；分时系统为联机多用户交互式系统；实时系统强调即时响应与高可靠性；分布式操作系统将地理分散且具自治能力的处理系统或计算机互联，实现信息交换与资源共享。
第 3 节介绍了操作系统功能，其职责是管理控制软硬件资源，合理组织运行，为用户提供工作环境与接口。从资源管理与用户接口角度，操作系统具有处理机管理、存储管理、设备管理、信息管理、用户接口五大功能。
第 4 节介绍了进程管理，需明确进程是系统分配资源的基本单位，进程概念源于资源有限性与处理的并行性，进程是动态概念。本节需区分进程、线程与程序，重点掌握进程状态及状态转换，并理解死锁产生条件与防范措施。
第 5 节介绍了处理机调度，涵盖调度目标、策略与评价标准。调度方式有进程调度、作业调度、交换调度和线程调度四种。常见算法有先来先服务、最短作业优先、时间片轮转、最高响应比等。需理解作业与进程关系，进程为执行实体与资源分配基本单位，一个作业由一个或多个进程组成，系统为作业创建根进程，运行中按需创建子进程。本节需掌握作业周转时间、平均周转时间、带权周转时间的计算。
第 6 节介绍了存储管理，主要讲解分区式、页式、段式、段页式管理。内存管理的核心是解决内外存统一及数据交换问题。覆盖与交换是内存扩充的两种技术，需掌握其思想。需熟练掌握各类内存管理方法，理解页式、段式、段页式的基本原理及差异。
第 7 节介绍了设备管理，其主要任务是控制设备与 CPU 间的 I/O 操作，提升设备利用率。数据传输方式有程序直接控制、DMA、中断控制、通道方式四种。
第 8 节介绍了常见操作系统，包括 Windows 系列如 Windows 7、Windows 8、Windows 10，并简要介绍了 Linux 与 UNIX 及二者差异。

### 5.1.1 多媒体与多媒体技术
#### 1. 多媒体与多媒体技术的定义
媒体是信息载体与传递媒介。超媒体一词源于媒体，指由超链接构成的全球信息系统。本章所论多媒体为超媒体的子集。
借助文字、声音、图像、动画、影片等两种及以上媒介，使计算机与人实现实时信息交互的系统称为多媒体。而在交互过程中，对文字、图像、声音、动画、视频等信息进行综合处理与管理的技术称为多媒体技术。

## 3. 多媒体技术的特点
多媒体技术主要具有多样性、集成性、交互性、实时性四大特征。
### （1）多样性
指媒体类型丰富，信息处理手段多样。例如媒体类型包括视频、图像、音频、文本等，技术层面涵盖视频技术、图像压缩、音频技术等。
### （2）集成性
包括信息媒体的集成，即以计算机为中心对多种媒体信息进行综合处理；还包括软硬件设备的集成，即打印机、扫描仪、投影仪、音箱等外部设备协同使用。
### （3）交互性
指多媒体领域人机高效交互。计算机能及时识别外部控制指令，使用者操作简便，上手迅速。
### （4）实时性
指各类媒体信息具有动态变化特性。
此外，多媒体技术还存在数据体量庞大、数据类型多、数据类型差异大、输入输出复杂等特点。数据量庞大源于多媒体数字化需采样、数据存储、数据分析等过程，无论图片还是音乐，要保证高质量体验通常需处理海量数据。
