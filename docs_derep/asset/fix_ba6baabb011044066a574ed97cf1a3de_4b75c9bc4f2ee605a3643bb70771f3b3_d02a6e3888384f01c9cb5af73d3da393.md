**9.2.2 设置消息接收回调与可信 IP**

企业微信接收用户消息采用传统的 Webhook 回调，而非 WebSocket 长连接。因此云服务器必须拥有可公网访问的 URL，供企业微信服务器推送消息。

在 AI 智能助手应用详情页向下找到“接收消息”板块，点击“设置 API 接收”。配置页需填写三项信息。

第一项 URL，即消息推送目标地址，标准格式为：
http://你的服务器公网 IP:3000/wecom/message
若已配置 Nginx 反向代理和自定义域名，建议使用 HTTPS：
https://你的域名/wecom/message

第二项 Token，可点“随机获取”由系统生成，或自行输入复杂字符串。

第三项 EncodingAESKey 消息加密密钥，直接点“随机获取”即可。

特别注意，填写完毕后请勿立即点底部“保存”。保存后企业微信会立即向该 URL 发送验证请求，若此时 OpenClaw 未配置启动则验证失败。因此需先完成服务器侧配置。

此外，在应用详情页还需设置“企业可信 IP”，将云服务器的公网 IP 准确填入，否则 OpenClaw 发出的消息会被企业微信安全策略拦截。

**9.2.3 手动安装插件并完成 OpenClaw 配置**

9.1 节飞书是通过 onboard 初始化流程安装插件的，企业微信可采用更直接的方式：手动安装插件并修改配置文件。

终端执行：
openclaw plugins install @sunnoy/wecom@latest

安装完成后在 ~/.openclaw/extensions 目录下会新增 wecom 文件夹，与之前的 feishu 并列。

随后打开 ~/.openclaw/openclaw.json，在 channels 节点下新增 wecom 配置，结构参考如下：

{
  "其他配置": {}
      ....
  "channels": {
    "feishu": {
        "xxx": "之前飞书的配置"
    },
    "wecom": {
      "enabled": true,
      "corpid": "你的企业 ID",
      "corpsecret": "你的应用 Secret",
      "agentid": 1000002,
      "token": "你在企业微信后台设置的 Token",
      "encodingAESKey": "你在企业微信后台生成的 EncodingAESKey"
    }
  },
      ....
  "其他配置": {}
      ....
  "plugins": {
    "entries": {
      "feishu": {
        "enabled": true
      },
      "wecom": {
        "enabled": true
      }
    }
  }
      ....
  "其他配置": {}
      ....
}

**注意：**请逐项核对并替换占位参数。agentid 必须为整数类型，不要加引号；token 与 encodingAESKey 必须与企业微信后台填写的内容完全一致。

保存后执行 openclaw gateway restart 重启服务。

确认服务正常运行后再返回企业微信管理后台的“接收消息”页面点击“保存”。配置正确时会提示“保存成功”，通信链路正式建立。

**9.3.2 部署钉钉插件与参数配置**

回到云服务器终端执行：
openclaw plugins install @soimy/dingtalk

若网络环境下载缓慢，可使用国内镜像加速：
NPM_CONFIG_REGISTRY=https://registry.npmmirror.com && openclaw plugins install @soimy/dingtalk

安装完成后打开 ~/.openclaw/openclaw.json，在 channels 节点下新增 dingtalk 配置块：

{
  "其他配置": {}
      ....
  "channels": {
    "feishu": {
        "xxx": "之前飞书的配置"
    },
    "wecom": {
        "xxx": "之前企业微信的配置"
    },
    "dingtalk": {
      "enabled": true,
      "clientId": "你的 Client ID AppKey",
      "clientSecret": "你的 Client Secret AppSecret",
      "robotCode": "你的 RobotCode",
      "corpId": "你的企业 CorpId",
      "dmPolicy": "open",
      "groupPolicy": "open",
      "showThinking": true,
      "messageType": "markdown"
    }
  }
      ....
  "其他配置": {}
      ....
}

将占位符替换为钉钉后台的真实数据。

配置中值得关注的选项：

• showThinking 设为 true 可提升体验，复杂问题推理时插件会先发送“思考中，请稍候……”提示，避免长时间沉默。
• messageType 建议设为 markdown，AI 回复可使用加粗、列表、代码高亮等富文本，大幅提升阅读体验。

配置完成后在钉钉开发者后台进入“版本管理与发布”，新建版本并发布。最后在服务器终端执行 openclaw gateway restart 重启服务使配置生效。

此时打开钉钉客户端搜索机器人发送测试消息即可对话。该插件支持文本、图片、视频及文件收发，手机端语音消息也会自动转文字发送给机器人。
