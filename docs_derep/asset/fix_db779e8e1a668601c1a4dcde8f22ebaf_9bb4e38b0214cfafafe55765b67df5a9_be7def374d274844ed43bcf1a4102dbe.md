# 知识图谱：原理与实战指南

## 书籍速览
知识图谱属于多学科融合的方向，涵盖知识工程、自然语言处理、机器学习以及图数据库等分支。本卷将核心技术串联起来，覆盖知识建模、关系提取、图数据存储、自动推演、图嵌入学习、语义检索、问答系统、图分析挖掘等要点。既兼顾前沿进展，也强调工程落地，让读者把握脉络并形成实践能力。可供人工智能与计算机领域的科研人员、企业研发与应用人员阅读，也可作为高校相关专业的参考资料。

## 编者序
知识图谱作为人工智能的重要分支，对可解释AI具有关键意义。近年来得益于知识表示与机器学习等基础进展，构建、推理、计算与服务化等环节均取得突破性提升，工业界关注度与应用成效同步提高。谷歌、微软、百度等先行企业已搭建大规模通用图谱，并基于实体关系提供语义检索，显著改善查询理解效果。图谱在智能决策、个性化推荐与问答中发挥核心作用。既具备巨大应用价值，也具有深层理论价值，为传统知识表示与推理提供落地场景，同时提出新挑战。

本书对理论、技术与应用做了系统梳理。理论层面呈现各类表示方式与推理方法，构成根基。技术层面涵盖存储查询、挖掘构建、知识融合，以及基于图谱的语义检索与问答。应用层面汇集工业界典型场景，为后续发展提供养分。目前专业著述相对稀缺，本书期望为研究者与从业者提供帮助。

作者团队在知识图谱研究与产业应用中深耕多年，成功融合学术探索与工程落地，相信出版后对技术普及与进展有积极作用。

## 前言导读
知识图谱的雏形来自万维网之父 Tim Berners-Lee 提出的语义网构想，核心是用图结构刻画事物间关联与知识，以实现更精准的对象级检索。相关技术已在搜索引擎、智能问答、语言理解、推荐计算、大数据决策分析等领域广泛使用。近几年伴随自然语言处理、深度学习与图数据处理加速发展，知识图谱在自动化知识获取、表示学习与推理、大规模图挖掘分析等方面迎来新突破，已成为认知级人工智能不可或缺的技术支柱。

## 出版缘起
知识图谱是交叉学科，涉及知识工程、自然语言处理、机器学习、图数据库等。构建与应用需要掌握知识建模、关系提取、图存储、自动推演、图嵌入学习、语义检索、智能问答、图计算分析等一系列关键能力，需要整合多领域知识。

本书首要目标是梳理这些知识点，帮助读者以全局视角掌握技术。早期典型应用以谷歌、百度等公司的通用搜索引擎为主，并衍生出天猫精灵、小米小爱等基于图谱的问答，主要依赖百科类通用图谱。近年来医疗、金融、安全等垂直领域不断深化，图谱从通用向垂直拓展。新进入者更需以应用为切入点开展研究开发。

第二个目标是为应用开发人员提供工具型参考。每章末尾安排常用开源工具介绍，并配套网站提供实操教程。

技术前沿追踪。伴随人工智能深化，知识图谱在深度知识抽取、表示学习与机器推理、基于知识的可解释AI、图谱挖掘与图神经网络等方向取得系列新进展。本书第三个目标是整理这些前沿，帮助读者把握演进方向。

## 全书结构
全书共 9 章。

第 1 章介绍基础概念、发展脉络、代表项目、技术要素及核心价值。
第 2 章围绕知识表示与建模，先讲传统人工智能的谓词逻辑、描述逻辑、框架系统等，再介绍互联网时代的 RDF、OWL 等框架，并概述向量表示，最后以 Protégé 为例演示建模实操。
第 3 章聚焦知识存储，先阐述存储特点与难点，再介绍常用索引与存储技术及原生图数据库原理，并简述主流图数据库，以 Apache Jena 与 gStore 为案例展开实操。
第 4 章围绕知识抽取与挖掘，先介绍多源数据获取方法，再重点展开实体提取、关系提取、事件提取，最后以 DeepDive 为案例演示关系提取实操。
第 5 章围绕知识融合，介绍概念层融合与实体层融合，包括本体映射、语义映射、实体对齐、实体链接，最后以 LIMES 为案例演示实体融合实操。
第 6 章围绕知识推理，先讲推理基本概念，再分别介绍基于演绎逻辑与基于归纳的推理技术，最后以 Apache Jena 与 Drools 为案例演示推理实操。
第 7 章与第 8 章分别聚焦语义检索与知识问答，介绍语义索引、基于图谱的问答等技术，并以 gAnswer 为案例演示精准检索与问答的实现。
第 9 章为应用案例，选取电商、图情、生活娱乐、企业商业、创投、中医临床、金融证券等 7 个场景，介绍技术落地过程与方法。

# 知识图谱总览
陈华钧 浙江大学，漆桂林 东南大学

1.1 什么是知识图谱
知识图谱可被理解为借助图模型刻画知识、描述万物关联关系的方法[1]。
图谱由节点与边构成。节点可表征实体，如具体的人或书籍，也可表征抽象概念，如人工智能、知识图谱等。边则体现属性或关系，如姓名、书名、朋友、配偶等。其思想源于语义网[2,3]，目标是把基于文本链接的万维网转变为基于实体链接的语义网。

1989 年 Tim Berners-Lee 提出以“链接”为中心的全球信息系统，认为以图组织比树状层次更适配开放互联网。这一思路逐步演变为 World Wide Web。1994 年他提出 Web 不应局限于网页互链，网页描述的是现实实体与概念，链接本身蕴含语义。1998 年提出语义网概念，节点代表客观实体，超链接附加语义描述，标明实体间关系，如出生地、创办人等。相对于传统网页网，语义网本质是数据网或物联网。

随后涌现大量语义知识库。Freebase 成为谷歌知识图谱后端，DBpedia 与 Yago 支撑 IBM Watson，True Knowledge 支撑 Amazon Alexa，Wolfram Alpha 支撑苹果 Siri，Schema.ORG 成为开放语义网 Schema，Wikidata 目标成为最大开放知识库。2010 年谷歌收购 MetaWeb，基于 Freebase 于 2012 年推出知识图谱搜索服务。此后图谱在语义检索[10,11]、智能问答[12-14]、语言理解辅助[15,16]、大数据分析辅助[17-19]、机器学习可解释性增强[20]、图卷积辅助图像分类[21,22]等领域作用日益凸显。

如图 1-1 所示，图谱旨在从数据中识别、发现和推断事物与概念的复杂联系，是可计算的关系模型。构建涉及知识建模、关系提取、图存储、关系推理、实体融合等技术，应用涉及语义检索、智能问答、语言理解、决策分析等。利用好图谱需要整合知识表示、图数据库、自然语言处理、机器学习等多方面技术。

1.2 知识图谱的发展历史
知识图谱并非凭空出现，而是语义网络、知识表示、本体论、语义网、自然语言处理等技术长期演进的成果，兼具 Web、人工智能、自然语言处理等多源基因。语义网是传统人工智能与 Web 融合的结果，RDF、OWL 是面向 Web 设计的标准知识表示语言，知识图谱可视作语义网的商业简化实现，如图 1-2 所示。

哲学家柏拉图将知识定义为“有根据的真信念”，需满足合理性、真实性与可信性。简言之，知识是人类对客观世界现象观察、学习、思考后总结的事实、概念、规则或原则集合。人类用自然语言、绘画、数学语言等手段描述与传承知识。人工智能的核心也是研究如何用机器可处理的方式表示、学习与处理知识。

[PRE2]
知识表示是现实世界的可计算模型，广义上神经网络也是一种知识表示形式，如图 1-3 所示。

符号派聚焦知识表示与推理。早在 1960 年认知科学家 Allan M.Collins 提出用语义网络研究人类语义记忆。WordNet 是典型语义网络，定义词间语义关系，广泛用于语义消歧。

1970 年专家系统兴起，知识库构建与表示受到重视。专家系统认为专家决策基于大脑知识，人工智能核心是符号化知识并用推理机模拟人脑处理。系统由知识库与推理机组成。早期常用方法包括框架语言与产生式规则。框架语言描述类别、个体、属性、关系，多用于自然语言理解。产生式规则描述类似 IF-THEN 的逻辑结构，适合过程性知识。

知识图谱与传统专家系统时代的工程有显著差异。传统专家系统依赖人工构建，现代图谱规模巨大，无法仅靠人工。如图 1-4 所示，1984 年起创建的常识库 Cyc 仅约 700 万条事实。WordNet 依赖语言学专家，约 20 万语义关系。Marvin Minsky 起始的 ConceptNet 早期百万级，5.0 版约 2800 万 RDF 三元组。谷歌、百度等现代图谱已超千亿三元组，阿里 2017 年发布的商品核心数据图谱达百亿级。DBpedia 约 30 亿 RDF 三元组，BabelNet 约 19 亿，YAGO3.0 约 1.3 亿，Wikidata 约 4265 万条目，数十亿三元组。开放链接数据项目统计约 2973 个有效数据集，合计约 1494 亿三元组。

大规模需求源于知识完备性难题。冯·诺依曼曾估算单个大脑全量知识需 2.4×10^20 bits 存储。客观实体与主观概念数以不计，其间关系更庞大，导致大多数图谱面临不完备困境。在语义检索、智能问答、知识辅助决策分析等实际场景中，知识不完备是主要难题。
