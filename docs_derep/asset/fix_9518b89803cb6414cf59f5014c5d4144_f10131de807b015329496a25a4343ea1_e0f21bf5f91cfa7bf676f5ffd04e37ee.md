# 第五章 从存在论到诠释学：认知研究的另一条入口

前几节用海德格尔的存在论来梳理认知科学的主流路径，提炼了关键概念，也暴露出把存在论现象学直接搬进认知研究时会卡住的两处理论难题。那就自然会问：单靠存在论这把钥匙，视野会不会太窄？存在论确实为审视人类认知提供了新切口，启发是实用的。但存在论如果单独充当认知科学的“智库”是不够的，存在论认知需要额外思想资源的注入。恰好诠释学与存在论有深层亲缘，这就为存在论认知向诠释学延伸提供了可能性。我们相信，认知科学乃至人工智能可以从诠释学获得有价值的提示，两者之间是可以连通的。

## 第一节 为什么要把诠释学纳入存在论认知

### 诠释学在谈什么

诠释学原意关乎宣告、转译、阐释的技艺，词源指向希腊神话里为众神传讯的赫耳墨斯，他的工作不是原封不动复述，而是把神语译成人语。由此发展出关于理解与解释的理论实践，核心是意义的呈现与转换。早期它扎根于法学解释和圣经文献解释两条主线。施莱尔马赫和狄尔泰的工作让诠释学摆脱教义束缚，成为一门通用的理解学说，研究重心也从文本历史转向对理解活动本身的反思，其任务被理解为调和不同解释的冲突，并为人文科学提供方法论支撑。[^(\[1\])](#chapter006.html#m1)

把诠释学视作存在论认知的延伸，并非无来历的联想，而是有逻辑依据。对海德格尔来说，存在论的核心追问是此在存在的意义，不论是早期以此在为中心的本基存在论，还是后期对存在意义本身的追问，使用的操作手法都是诠释学。要论证诠释学能进入认知的某些领域，需要给出合理的过渡理由。

### 一 海德格尔的存在论现象学本质上就是诠释学

海德格尔改变了诠释学的用法，不再仅讨论理解本身，而是把理解当作此在一种根本的存在方式。此在正是在理解中意识到自己身处世界。某种程度上，海德格尔对此在的现象学刻画就是一部诠释学，此在被定义为理解的此在，对其生存结构的分析自带诠释性质。换句话说，现象学的方法论内核是解释，经由诠释，此在存在的本真意涵与基本结构才显现出来。此在的现象学因此等同于诠释学。[^(\[2\])](#chapter006.html#m2)

此在一直把把握存在意义当作自己的课题，而意义的领会与阐发属于诠释学范畴。于是可以推出，此在的现象学即诠释学，而此在的现象学正是基础存在论的工作。所以此在的诠释学也就是基础存在论。[^(\[3\])](#chapter006.html#m3)

海德格尔提出诠释学意在揭示此在自身存在的样态。此在从一开始就在理解与解释，不断产生对存在的主题化或非主题化理解，这种理解活动的本质是此在对自身的反思。这样的反思不是胡塞尔式的意识操作，而是此在的一种存在方式，牵涉到此在如何理解自己与他人存在。海德格尔不把理解窄化为认知操作，而是视其为我们在世界中存在、与世界互动的基本能力，简单说就是“我知道怎么处理正在做的事，在不同情境下做出恰当反应”。[^(\[4\])](#chapter006.html#m4)后来的伽达默尔把这一思路明确化：诠释学就是实践哲学，解释从一种形式转向另一种形式，体现了人在不同生存境况中的应对方式。与世界打交道的过程本身就是对世界的敞开，呈现出人在时空维度上与他物的交互。海德格尔所说的理解涵盖感知、实践性的 know-how、认知性知识，以及与他人的日常交往，而非仅限于认知现象。

总体看，海德格尔的存在论现象学与诠释学是同一回事，因为人始终对存在保有本真或非本真的理解，如何让恰当的理解浮现，正是诠释学与基础存在论共同的使命。诠释学由此从文本解释的方法上升到哲学高度，成为关于存在理解的学问。既然海德格尔的存在论现象学与诠释学不可分，而伽达默尔在整体上承接了这一脉络，就有充分理由把存在论与认知研究的结合进一步扩展到诠释学，让诠释学的思想资源进入认知研究。

### 二 认知本身就是一种诠释行为

海德格尔提出诠释学是为了突破近代主体认识论那种孤立无世界的认知主体图景，这种图景遮蔽了人与世界之间原始关联。存在论现象学的任务正是在世界中来理解人与事物的关系。理解是世界与此在关系的具体化，存在离不开此在的理解，存在是在此在的理解中显现。[^(\[6\])](#chapter006.html#m6)

人不仅是行动的存在，更是诠释的存在。人的认知与行动在先行层面已被理解。某种意义上认知即行动，因其具有表征性：认知对象的模型或对应物的生成本身就是一次解释性呈现。认识具体事物、形成理论、设计模型，都可看作诠释过程。或许可以这样说，诠释是对认知对象的一种解释性呈现。人总是以诠释的方式、以不同视角面对世界，思维、认知、行动都浸透着诠释，缺乏合乎逻辑的诠释就无法思考、判断与评价。[^(\[7\])](#chapter006.html#m7)

除了渗透性，诠释对认知的依赖性也很深。细想就会发现，我们绝大多数关于事物与事件的认知、思考、判断都暗含诠释。日常生活中面对的多是可理解的事实，维特根斯坦曾言世界是事实的总和，事实只有经过诠释才进入我们的认知，事实的存在可被视为某种诠释的产物。任何事物要被认识必须先作为对象进入诠释过程，甚至可以推断，诠释的范围界定了认知的范围，人的认知世界是在诠释中被理解与建构的。认知活动所产出的结果，本身也是诠释的结果。我们既以认知方式又以诠释方式朝向世界，作为一个不断诠释的存在，我们在思维、认知与行动中始终依赖这一要素。
