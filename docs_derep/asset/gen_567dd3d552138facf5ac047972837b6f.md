#### 情感表达控制

##### AI 配音的情感维度

人类情感细腻，在短剧配音中需重视六大基础情感维度，每种情感都有独特的声学特征及适用场景，具体见表 6-1。

表 6-1 不同情感维度下的配音特征及其在短剧中的适用场景

| 情感维度 | 声学特征 | 短剧应用场景 |
| :--- | :--- | :--- |
| 喜悦 | 语速偏快、音调高、音量起伏大、声音明亮 | 重逢、告白、成功、甜蜜日常 |
| 悲伤 | 语速缓慢、音调低、音量弱、气息声重、哽咽 | 离别、失去、绝望、回忆过去 |
| 愤怒 | 语速快或咬牙切齿的慢、音调高、音量爆发强、气息粗重 | 对峙、背叛、复仇、争执 |
| 恐惧 | 语速不稳颤抖、音调忽高忽低、音量忽大忽小、倒吸气 | 遇险、惊吓、悬疑、噩梦 |
| 惊讶 | 语速骤停、音调突升、音量突增、吸气声 | 发现真相、身份揭晓、意外转折 |
| 厌恶 | 语速缓慢、音调低、音量压制、带鼻音或冷哼 | 反感、鄙视、拒绝、嫌弃 |

情感控制方法一：提示词驱动

提示词驱动是最直接常用的方式。在台词后附加情绪状态、语气强度、说话方式等描述，Seedance 2.0即可还原对应情绪。核心技巧是“台词+情绪副词+语气状态”，描述越具体还原度越高，避免仅用“开心”“难过”等模糊词，需细化强度与表达方式，见表 6-2。

表 6-2 描述情绪强度的提示词示例

| 情绪强度 | 关键词示例 | 效果 |
| :--- | :--- | :--- |
| 轻度 | 温柔地说、轻声说、淡淡地 | 情感含蓄，适合日常对话 |
| 中度 | 激动地说、哽咽着说、生气地说 | 情感明显，适合情绪戏 |
| 重度 | 歇斯底里地喊、绝望地哭诉、咬牙切齿 | 情感爆发，适合高潮戏 |

情感控制方法二：音频参考驱动

## 6.2 音乐与音效设计

音乐是AI短剧的灵魂。背景音乐、音效设计及适当的留白，对呈现效果影响极大。AI生成的画面常在情绪张力与细节感染力上吃亏，优质音频正好弥补短板——音乐定调铺氛围，音效增强真实感放大细节，留白制造悬念。三者协同让画面有温度、有冲击力，避免“画面有了，情绪不到”的尴尬。
