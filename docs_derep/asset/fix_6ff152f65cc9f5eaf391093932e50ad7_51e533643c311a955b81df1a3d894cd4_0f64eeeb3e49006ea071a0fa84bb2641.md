### 1. 页面布局异常
向DeepSeek提问：元素位置未按预期排列，尤其在响应式场景中。
解决思路：
1）掌握 CSS 盒模型，理解 margin、padding、border 的作用。
2）学习 Flexbox 与 Grid，它们提供强大的对齐与分布能力。
3）借助开发者工具核查元素的实际尺寸与位置。
4）采用移动优先策略，先适配小屏再扩展到大屏。

### 2. 图片展示与性能问题
向DeepSeek提问：图片尺寸不匹配、加载慢或在不同终端显示不佳。
解决思路：
1）选用合适格式，照片用 jpeg，需透明用 png，现代浏览器优先 webp。
2）实现响应式图片，为不同屏幕提供不同分辨率资源。
3）压缩图片减小体积。
4）使用懒加载延迟加载视口外资源。
