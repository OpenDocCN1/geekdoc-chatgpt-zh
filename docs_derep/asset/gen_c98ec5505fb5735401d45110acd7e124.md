（10）常见问题及处理
- 找不到文件：核对路径是否准确，执行前可用 exec:ls -la data/ 确认文件存在。
- 缺失 pandas：确认环境已装 pandas 与 openpyxl，可用 exec:python -c "import pandas" 测试。
- 邮件发不出：检查 SMTP 用户名、密码或授权码是否正确，邮箱是否已开启 SMTP；建议在脚本里加异常捕获，区分认证失败与连接被拒。
- 定时任务不跑：检查系统时区设置，执行 openclaw cron list 查看状态。
- exec 工具不可用：检查配置文件中 tools.deny / tools.allow，确保 exec 未被禁用。
- 端口被占用：确认 Gateway 端口未被其他进程占用，openclaw gateway status 可查看。

### 4.3.1 Skills 机制回顾
OpenClaw 是一个高度可扩展的智能体框架，其核心思路是“技能即插件”。每个 Skill 以独立模块存在，封装某一项特定能力，如机械臂控制、图像识别、API 调用等。用户可按需组合多个 Skill，串成复杂的行为链。

#### 1. 核心 Skills 分类
按功能层级可分为两类：

（1）基础操作类 Skills。
- 移动控制：实现导航、避障、路径规划等底层运动；
- 机械臂控制：支持抓取、放置、旋转等精细操作；
- 传感器融合：整合摄像头、激光雷达、IMU 等多源感知数据。

（2）进阶能力类 Skills。
- 计算机视觉：物体识别、人脸识别、场景理解等；
- 自然语言处理：语音识别、语义解析、对话管理等；
- 任务规划：把高层目标拆解为可执行子任务序列。

> 提示：
Skill 的复用与组合是 OpenClaw 生产力强的关键。
