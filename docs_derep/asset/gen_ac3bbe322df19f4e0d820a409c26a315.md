下面依次介绍这 11 种技巧。

结构化提示词的核心是给提示加上明确的框架和格式，引导模型按需输出。想让模型写一段有趣对话，可以这样设定：“两个[人物]在[地点]做[活动]，先聊[话题]，其中一人抛出一个有趣观点，让对方好奇并回应……”。写旅行故事也可以用类似模板：“请写一个旅行故事，主角叫[姓名]，在[地点]经历[具体事件]，最后得到[收获]。”

提示词生成器的思路是多试几种写法，选出效果最好的。比如要写烹饪相关内容，可以分别尝试“描述烹饪过程”“写一个烹饪故事”“解释烹饪的重要性”等，看哪个结果更满意。写诗时对比“写一首关于春天的诗”“描述春天的美”等指令，择优使用。

具体化提示词强调细节和明确要求。例如解释“叠加原理”这类专业概念时，不要只说解释一下，而是写：“请用通俗语言解释量子力学中的叠加原理，并举一个生活中的例子。”

在复杂推理任务里，可以用思维链逐步推进。比如先问：“如果我先吃苹果，香蕉吃完苹果后会变熟吗？”帮助模型处理逻辑。产品经理规划在线学习平台时，可以先问平台应提供哪些功能，得到视频课、测验、学习追踪等建议后，再追问界面怎么设计、如何获取和留住用户、发布后如何收集反馈。每一步都在前一步基础上深入，答案会更全面。

自我提问提示词是让模型先给自己提问题再作答，从而挖掘更深层次的信息。例如设定角色为气候专家，先问“我了解哪些气候变化的信息？”再追问“气候变化如何影响海平面”“怎样减缓影响”。研究碳基生命和硅基生命时，依次自问基本事实、硅基生命的可能性、可能存在环境、探索方法，能得到更系统的内容。这种交互更像引导模型自我展开，而非单纯问答。

协同思考和动作 ReACT 的流程是反思-提问-协作-再尝试。遇到复杂编程优化问题时，先让模型反思已给建议的不足，主动提出需要更多输入输出信息，再让它查阅资料或调用工具，最后重新给出方案。

失败后自我反思是指当回答不准确或不相关时，让模型检讨“错在哪里”“如何改进”，从而修正输出。

连接知识库主要指用 LangChain。把本地文档、食谱数据库等作为外部知识接入，让 ChatGPT 基于这些资料作答。例如用户问“怎么制作炸鸡”，系统通过 LangChain 在食谱库中检索，再返回步骤。还可接入食材营养数据库、保存问答记录以便优化。
