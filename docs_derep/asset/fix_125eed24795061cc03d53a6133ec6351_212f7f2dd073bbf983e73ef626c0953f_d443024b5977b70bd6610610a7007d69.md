调用写法：
`top [选项] [PID|time|...]`
用途：Linux 系统性能分析工具，可动态实时呈现整体运行态势，是一个集成了多项系统监测信息的实用工具。
表 5-10 汇总了 top 的常见参数。[PRE9]

界面交互常用指令：
➢ `q`：退出程序；
➢ `m`：切换内存信息显示；
➢ `c`：在命令名与完整命令行之间切换；
➢ `i`：忽略空闲与僵尸进程，开关式指令；
➢ `k`：结束指定进程；
➢ `M`：按常驻内存大小排序；
➢ `P`：按 CPU 占用百分比排序；

## 12. `ps` 进程状态查询
调用写法：
`ps [选项]`
用途：显示当前时刻系统的进程状态。
表 5-15 汇总了 ps 的常见参数。[PRE16]

实操演示
列出此刻系统上全部进程的详细信息。
[PRE17]

输出列的解释：
➢ `USER`：进程所属用户；
➢ `PID`：进程唯一标识号；
➢ `%CPU`：进程占用的 CPU 资源占比；
➢ `%MEM`：进程占用的内存占比；
➢ `VSZ`：进程使用的虚拟内存量，单位 KB；
➢ `RSS`：进程使用的实际物理内存量，单位 KB；
➢ `TTY`：进程运行的终端，若与终端无关则显示“？”；
➢ `STAT`：进程当前状态；
➢ `START`：进程启动时间；
➢ `TIME`：进程累计使用 CPU 的时间；
➢ `COMMAND`：进程执行的命令。

`STAT` 列常见状态：
➢ `R`：运行中，程序正在执行；
➢ `S`：睡眠，可被唤醒；
➢ `T`：停止，已暂停工作；
➢ `Z`：僵尸状态。

## 13. `netstat` 网络状态检测
调用写法：
`netstat [选项]`
用途：输出网络系统的状态信息。
表 5-16 汇总了 netstat 的常见参数。[PRE18]

实操演示
列出所有正在监听的 TCP 端口信息。
[PRE19]

TCP 端口字段说明：
➢ `Proto`：网络连接协议，一般为 TCP 或 UDP；
➢ `Recv-Q`：已接收但尚未被进程取走的数据，暂存于本地缓存；
➢ `Send-Q`：已发出但对方未确认的数据，仍在本地缓存中；
➢ `Local Address`：本机 IP 与端口；
➢ `Foreign Address`：远程主机 IP 与端口；
➢ `State`：链路状态。

`State` 列常见状态：
➢ `LISTEN`：监听状态，TCP 需要，UDP 不需要；
➢ `ESTABLISHED`：连接已建立；
➢ `SYN_SENT`：主动发起连接的 SYN 包；
➢ `SYN_RECV`：收到主动连接请求；
➢ `FIN_WAIT1`：正在中断的连接；
➢ `FIN_WAIT2`：已中断，等待对方确认；
➢ `TIME_WAIT`：连接已断，套接字仍在等待结束；
➢ `CLOSED`：已关闭的连接。
