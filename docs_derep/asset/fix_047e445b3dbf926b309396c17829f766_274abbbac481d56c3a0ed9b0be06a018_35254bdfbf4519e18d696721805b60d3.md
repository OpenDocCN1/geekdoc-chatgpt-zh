3. 让愿景变得可感知：让用户和团队都觉得自己在其中

只有当愿景具体到能够被看见、被行动时，人才会产生“我也在推动它”的归属。把朦胧的理想转化为可感知的行动坐标，靠的是结构化的拆解提问。

借助 DeepSeek 提炼愿景的提问示例：

> “请为家具电商品牌暖舍撰写一段有温度的品牌愿景。
> 背景：暖舍目前体量不大，但创始团队希望打破‘年轻人租房就得凑合’的固有认知。
> 请完成以下六项：
> 1. 愿景陈述：用一句话概括暖舍5到10年后的理想图景。
> 2. 行业改变：暖舍希望在组装体验、环保标准、定价逻辑等环节如何重塑规则。
> 3. 社会价值：在环保、城市青年居住尊严、循环经济层面能做出哪些贡献。
> 4. 团队愿景：理想的企业文化是什么，员工因什么而自豪。
> 5. 激励口号：一条简短有力的内部打气语。
> 6. 视觉符号：一个能代表未来暖舍的图标或意象。
> 要求愿景既有前瞻性又不流于空话，能真正引发共鸣。”

DeepSeek 能把模糊的梦想转化为可传播、可落地的愿景表达。

4.4 平台定制：公众号、抖音、小红书的内容打法

不同平台的用户心智、内容形态和分发逻辑差异很大，必须为每个阵地设计专属的提问策略。

4.4.1 公众号：深度阅读与专业信任

公众号仍是长图文阅读的核心场域。读者愿意花5到10分钟，说明他们要的是专业度、深度与实用性。

公众号内容的三大特质：

| 特质 | 要点说明 | 提示词设计要点 |
| :--- | :--- | :--- |
| 结构清晰 | 长文需要分段落、有小标题、思路层层推进 | 预设“引子-论点一-论点二-论点三-收束”的骨架 |
| 内容扎实 | 需要数据佐证、案例细节、方法论，而非空泛议论 | 要求“每个论点配1个数据+1个案例+1个专家观点” |
| 互动设计 | 在文中或文末设置提问、投票，引导留言 | 要求“结尾放一个开放性问题，促发评论” |

公众号深度文提示词模板：

“请围绕[主题]写一篇面向[读者画像]的公众号深度稿，约2500字。
结构要求：
- 开头300字：以具体故事或现象切入，点出痛点并提出核心判断。
- 正文1800字：拆成3到4个分论点，每个采用‘观点+数据/案例+洞察’的写法。
- 结尾400字：总结观点，给出3条可执行的建议，并设置互动提问。
质量要求：
- 数据需来自权威统计或知名报告，不确定则标注‘待核实’。
- 案例要包含人物、时间、地点与结果细节。
- 语言专业易懂，流畅不水。
互动要求：
- 开头埋一个与读者相关的情境问。
- 结尾邀请读者分享经历或看法。
输出用 Markdown，二级标题与三级标题区分层次。”

4.4.2 抖音：3秒抓人与情绪张力

抖音是注意力黑洞，3秒内抓不住就会被划走。

短视频脚本的关键要素：

| 要素 | 说明 | 提示词要点 |
| :--- | :--- | :--- |
| 开场钩子 | 前3秒需有冲突、悬念、反差或情绪点 | “第一句必须是反问或惊句” |
| 节奏紧凑 | 信息密度高、剪辑快、语言精炼 | “每5到8秒切画面或切换观点” |
| 情绪共鸣 | 喜悦、感动、愤怒、惊讶等强情绪易扩散 | “脚本中至少设置一个情绪爆发点” |
| 互动引导 | 结尾引导点赞、评论、关注或参与挑战 | “结尾用祈使句引导互动” |

抖音30秒脚本提示词模板：

“请为抖音写一个30秒脚本，主题是[主题]。
开头0-3秒：要有悬念或反常识判断。示例格式：‘你以为XX就是XX？错了。’
主体3-25秒：快节奏呈现2到3个知识点或剧情反转。每句台词不超过15字。可加入演员反应、快剪、音效提示。
结尾25-30秒：明确互动指令，如‘关注我，下期讲XX’或‘你有XX经历吗？评论区聊聊。’
额外要求：标注每镜头的时长、画面要点、台词、BGM/音效建议。情绪基调：[搞笑/感人/震惊/实用]。”

4.4.3 小红书：种草社区的信任与审美

小红书用户来找的是“值得买、值得做”的真实体验分享，而非广告。

种草笔记的核心要素：

| 要素 | 说明 | 提示词要点 |
| :--- | :--- | :--- |
| 真实感 | 像用户自述，有个人感受与细节 | “用第一人称，加入主观体验细节” |
| 审美调性 | 文案有品，图片精致，符合平台气质 | “语言亲和细腻，有网感不低俗” |
| 信任建立 | 包含缺点、对比、真实过程 | “必须写一个真实的缺点或翻车经历” |
| 搜索友好 | 标题与正文嵌入用户常用搜索词 | “标题需含核心关键词，如平价、测评、学生党” |

小红书种草笔记提示词模板：

“请写一篇小红书种草笔记，推荐[产品]。
标题：核心关键词+数字+情绪词，如‘自用1个月！这款XX真的绝了’。
正文结构：
- 开头50字：说明自身肤质/场景/需求，塑造真实人设。
- 开箱第一印象80字：包装、颜值、初感。
- 使用过程150字：详细步骤、感官体验，需含一个小插曲或缺点。
- 效果总结80字：使用一段时间后的变化，尽量前后对比。
- 购买建议50字：适合人群、购买渠道、优惠信息。
- 标签：5到8个，含品类词、场景词、人群词。
额外要求：语气像闺蜜分享，可少量使用‘我真的会谢’‘绝绝子’‘谁懂啊’等流行语。最后建议配图类型：封面、细节、场景、效果对比。”

4.5 一人公司内容系统：从单篇到矩阵

做自媒体不只是写几篇好文章，而是构建可持续、高效、可复制的内容生产体系。

4.5.1 内容创作的三级火箭

| 层级 | 形式 | 频次 | 目标 | AI 辅助重点 |
| :--- | :--- | :--- | :--- | :--- |
| 一级 高频 | 朋友圈/微博/社群短内容 | 每天3-5条 | 保持存在感，连接私域 | 生成灵感、金句、互动问题 |
| 二级 中频 | 公众号/小红书/知乎回答 | 每周2-3篇 | 累积粉丝，建立专业影响力 | 选题辅助、初稿生成、润色 |
| 三级 低频 | 电子书/课程/报告/线上活动 | 每月1次 | 深度价值输出，主力变现 | 大纲设计、内容扩充、营销文案 |

核心策略：让AI承担一级和二级的80%工作量，人类聚焦三级内容的深度与用户互动。

4.5.2 个人AI内容生产流搭建

第一步 建立选题库
用DeepSeek批量生成50个相关选题。示例指令：
“请为‘职场沟通’生成50个公众号选题，覆盖痛点、热点场景、争议话题。”
每周从库中挑3到5个启动创作。

第二步 构建个人风格指南
让DeepSeek分析你过往3篇优质文章，提炼句式、用词、案例偏好、情感基调。
示例指令：“请分析我上传的3篇文章，总结写作风格特征，形成风格指南，含常用开场、段落长度、金句模式、修辞偏好，后续创作自动匹配。”

第三步 半自动化创作流程
1. 语音初稿：手机录音口述选题想法10-15分钟。
2. AI转录扩展：转文字后让DeepSeek扩展为1500字文章，补充案例数据，并按风格指南执行。
3. 人工点睛：加入个人洞察、真实故事、情感温度。
4. AI润色：再次交由DeepSeek检查语法、优化句式、提升可读性，不改观点。
5. 分发改编：把核心内容改写为小红书图文、抖音脚本、知乎回答、社群短评。

此流程可把原本4-5小时的创作压缩至1小时内，质量稳定。

4.6 实战案例：从0到1打造知识类小红书账号

背景：营养学爱好者，想做“上班族健康饮食”，3个月涨粉1万并开启变现。

第一阶段 定位与规划
提示词输出：账号定位一句话、人设画像、3-5个固定栏目及频次、首月20个选题标题、视觉风格建议。

第二阶段 首篇爆款创作
选题“上班族10分钟搞定一周便当”。提示词要求标题含关键词+emoji，正文含过往外卖党人设、5天搭配方案、踩坑提醒、工具推荐、标签，语气活泼，配图九宫格建议。

第三阶段 矩阵与引流
提示词：从10篇笔记提炼3个核心观点作朋友圈金句；将便当笔记改写为60秒抖音脚本；制作“健康便当食材清单”PDF目录；设计21天带饭挑战社群活动规则与每日话术。

第四阶段 商业变现
提示词：为“便携式电热饭盒”写软植入种草笔记，卖点是不插电保温6小时、可预约加热、陶瓷内胆易洗，粉丝为上班族带饭群体，标题自然如“被同事问链接的便当神器”。

本章小结：创作的本质是思考的深度，AI负责成文与填充，人负责灵魂与温度。掌握方法后，创作从负担变为与AI的协作。

第五章：一人公司——用 DeepSeek 搭建自动化商业系统

内容创作只是工具，真正的生意要完成产品设计、流量获取、销售转化、客户交付全流程。

5.1 一人公司的认知革命

5.1.1 什么是一人公司

过去一人公司被理解为单打独斗。AI时代，一人公司=个体+AI智能体团队。

你担任CEO，AI是虚拟员工：文案助理、设计师、运营助手、客服、研发助手。它们不用工资、不请假。管理方式就是提示词设计。

一人公司核心公式：
利润 = 流量 × 转化率 × 客单价 × 复购率 - 成本

AI在各环节的作用：

| 环节 | AI作用 | 传统vsAI |
| :--- | :--- | :--- |
| 流量获取 | 批量生成社媒内容、优化SEO、分析爆款规律 | 手写盲发 → AI批量生成+数据驱动选题 |
| 转化率 | 优化销售文案、设计高转化页、24小时回复咨询 | 凭感觉写作、人工回复 → AI A/B方案+全天响应 |
| 客单价 | 设计产品组合、推荐升级、生成增值内容 | 单一产品 → AI行为分析智能推荐 |
| 复购率 | 自动化跟进、个性化内容、社群运营 | 跟进遗漏、无系统 → AI定期触达+内容自动生成 |
