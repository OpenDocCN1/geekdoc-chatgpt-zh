模型会先给出整体回应，围绕民法典的两条做逐条拆解，并在需要时辅以案例。

**第三十五条 监护人应当按照最有利于被监护人的原则履行监护职责。监护人除为维护被监护人利益外，不得处分被监护人的财产。**

要点归纳如下：

1. **监护人角色**：对未成年人或无、限制行为能力人负有照护责任的人，主要任务是保障被监护人的身心与财产权益。
2. **最有利于原则**：履职时必须把被监护人的最大利益放在首位，涵盖生活、教育、医疗、安全等基本需求的满足。
3. **财产处分边界**：原则上无权处分被监护人的财产，只有为了维护被监护人利益，例如支付生活费、医疗费、学费等合理情形下才可操作。
4. **案例提示**：若监护人以被监护人名义卖掉财产，将款项用于个人消费，就违反了最有利于原则。

**第五百三十五条 因债务人怠于行使其债权或者与该债权有关的从权利，影响债权人的到期债权实现的，债权人可以向人民法院请求以自己的名义代位行使债务人对相对人的权利，但是该权利专属于债务人自身的除外。**

核心说明：

1. **代位权启动**：债务人怠于行使自己的债权或从权利，导致债权人到期债权受损时，债权人可请求法院以自己的名义代为行使。
2. **适用前提**：债务人怠于行使、怠于行使造成债权人债权无法实现、且该权利并非债务人专属。
3. **例外情形**：专属于债务人本人的权利不属于代位范围，债权人不能代为行使。
4. **案例提示**：借款人欠债同时拥有一项专属合同权利，债权人只能就其他可代位权利申请行使，以保障自身受偿。

最后模型会提醒，法律适用因案而异，遇到具体问题仍建议咨询执业律师。
