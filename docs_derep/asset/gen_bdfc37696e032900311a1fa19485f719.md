想把 DeepSeek 的推理能力接进自己的工具链，同时给 VS Code 加上点代码解释的快捷能力？下面是一套可以直接照抄的最小可行流程，涵盖环境配置、非流式与流式调用、Streamlit 会话初始化，以及 VS Code 扩展脚手架与 CodeLens 提供者的核心骨架。

环境变量准备好后，封装一个常规的补全函数，默认走 deepseek-chat，温度调得很低以保证回答稳定。
[PRE1]python
from dotenv import load_dotenv, find_dotenv

_ = load_dotenv(find_dotenv())

from openai import OpenAI

client = OpenAI()

def get_completion(prompt, model="deepseek-chat", temperature=0.01):

    messages = [{"role": "user", "content": prompt}]

    response = client.chat.completions.create(

        model=model,

        messages=messages,

        temperature=temperature

    )

    return response.choices[0].message.content
需要实时展示思考过程就换成流式模式，这里把模型切到 deepseek-reasoner 并打开 stream。
[PRE2]python
from openai import OpenAI

client = OpenAI()

def get_stream_completion(messages, model="deepseek-reasoner"): # 更改模型为 deepseek-reasoner

    response = client.chat.completions.create(

        model=model,

        messages=messages,

        stream=True  # 启用流式输出

    )

    return response
