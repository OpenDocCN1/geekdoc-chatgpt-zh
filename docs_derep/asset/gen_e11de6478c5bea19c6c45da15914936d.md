RT-H 为具身多模态大模型的探索提供了重要参考。首要一点是，它的整体表现已经在大量且多元的数据集上跑出了领先水平，可即便是经过修正训练，任务完成的绝对成功率仍旧存在提升余地。值得注意的是，它提出的语言化动作表征，能够起到桥梁作用，比如打通 OXE[907] 这类汇聚了多种具身数据的集合，甚至可以从仅有语言描述的视频里汲取行动知识。第二点在于层次划分，RT-H 虽然拆解了不同层级的动作结构，但中间层究竟该抽象到什么粒度，仍需进一步厘清。第三点聚焦于压缩与上下文，语言动作本质上为动作预测提供了上下文语境，同时也压缩了动作空间。借助 RT-H 的上下文特性，把语言动作预测当作先验，就能有效收敛强化学习以及策略探索时的搜索范围。这样的表征既让策略学习更省力，也便于理解和人工干预。模仿学习领域里，Mobile ALOHA[908] 等工作已表明机器人动作与演示者保持一致很关键，而引入语言动作压缩空间后，动作一致性会进一步增强，策略学习效率自然也会提高。

## 5.6 本章小结

多模态大模型赛道正以极快速度迭代，新方法新视角层出不穷。正因如此，本书不可能穷尽所有前沿议题。作者的初衷是希望这本书能给从事多模态大模型研究的同行和开发者一些借鉴与灵感，助力社区共同进步。现阶段多模态大模型尚处萌芽期，缺乏统一完备的框架，但沿着新一代人工智能的技术路线，深度挖掘其跨领域的潜力，未来很可能迎来一批令人激动的突破，AGI 的到来也会越来越近。当计算机视觉、自然语言处理、因果推理、世界模型、具身智能等方向与 Agent 深度融合，真正普适的通用 Agent 将诞生，并对社会发展产生深远推动。
