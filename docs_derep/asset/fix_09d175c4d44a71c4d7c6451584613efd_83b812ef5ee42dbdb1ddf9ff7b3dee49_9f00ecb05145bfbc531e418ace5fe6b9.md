# 第二章
# 提示词实战指南

要发挥 ChatGPT 最大价值，关键在于提示词的构建。 精准的提示词能引导大语言模型产出高质量内容。 本章拆解提示词构成、设计原则、实操技巧以及 PromptPerfect 优化器的用法，帮助提升互动效率与质量。

## 2.1
## 提示词构成与撰写规范

[PRE5]

扫一扫，看视频

提示词是用户向大模型输入的文本或多模态信息，用于引导生成特定回应。可为文字、图片、数据、音视频、PDF 等。

**1．提示词的构成**

提示词包含指令、背景、输入素材和输出指引四要素。指令明确期望执行的任务，如分类、撰写、翻译；背景提供补充信息帮助模型更精准理解；输入素材是具体内容或问题；输出指引规定类型或格式，确保响应符合要求。

提示词示例：

**我是一名数据标注专员，正在标注文本中的地名，请帮我提取以下文本中的地名。输入：“寒假的一天早晨，小李收到了一封来自重庆老家的信，信中提到了他儿时的玩伴小王现在东莞一所高校工作。小李计划利用假期去东莞与小王重聚。他从重庆搭乘高铁到达广州，再换乘到达东莞。到达东莞后，小王热情地带小李参观了他的学校，两人谈笑风生。小王告诉小李，他有个梦想，想去北京看看那里的雄伟建筑和历史遗迹。小李被小王的热情所感染，决定陪他一起去北京。在北京，他们参观了故宫、颐和园，感受到了这座古都的厚重和底蕴。小李提议再北上去张家口，体验一下冰雪运动。在张家口雪场，他们尽情滑雪，享受着冬日的喜悦。此行让小李深感友情的可贵，也让他更加珍惜生活中的每一次相遇和经历。”**

**输出格式：地点：<逗号分隔的地名列表>**

其中背景为“我是一名数据标注专员，正在标注文本中的地名”，指令为“请帮我提取以下文本中的地名”。其余为输入数据与输出指示。

**2．提示词的设计原则**

（1）清晰：要明确传达意图，避免歧义，术语需解释。如“重庆市有哪些知名火锅店？”较为清晰；“2021 年苹果价格比 2020 年上涨多少？”则模糊，因“苹果”不明且缺少地区。

（2）聚焦：要具体、针对性强，避免宽泛。如“你知道人类什么知识？”过于开放，应改为“你了解人类科技史吗？”

（3）相关：在多轮对话中保持话题一致，无关提示会分散注意力。提问时可用相关关键词，如旅游建议可用“景点推荐”“路线规划”“食宿安排”。

（4）简洁：去除冗余词句，有助于获得针对性回复。

有效示例：

**#有效提示词**

**你能总结一下埃隆·马斯克的性格特点吗？#聚焦、相关**

**东莞市有多少个乡镇？#具体、目标明确**

无效示例：

**#无效提示词**

**你能告诉我关于这个世界的什么？#过于宽泛和开放**

**你能帮我做作业吗？#过于开放**

**你好#无目的、不聚焦**

遵循原则并练习，有助于编写精准提示词，保持对话在正确轨道上。

## 高效提示词的实用技巧

除遵循原则外，掌握技巧可显著提升效果。

**1．“以……形式”获取结构化回复**

在提示中加入“以……形式”，可让回复更有条理。例如制表、清单等。后续可要求修改或导出为 Excel 可读格式。 [PRE7]

**我想要在 4 周之内减脂 5kg，请以表格的形式，为我列出一份每周运动和饮食计划。**

**2．“以……风格”控制语气**

默认语气平实。可加入“以……风格”指定语气，如模仿某作家。 [PRE9]

**我想要写一份企业宣传文案，请以海明威的语言风格，为我输出百度公司的企业宣传文案。**

**ChatGPT：** 输出采用简洁有力、意象鲜明的海明威式笔法，围绕探索、信息、云、智能等意象展开企业宣传，整体风格硬朗直接。

**3．限制生成范围**

限定字数、语言、受众等条件时，表现会更可控。若未遵守可要求重写。 [PRE10]

**请为我写一篇关于汉光武帝刘秀的传记，字数为 200 字左右，要求语言是英语。**

**ChatGPT：** 给出约 200 字的英文传记，概述刘秀出身、起兵、昆阳大战、建立东汉等关键节点，语言简洁符合限制。
