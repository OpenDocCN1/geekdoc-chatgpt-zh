## 量化改造的关键点

量化入口以 bits 控制精度，bits 为 0 时直接返回。首次进入时会标记已量化状态并把位数写入配置，避免重复处理。实际的重参数化委托给内部的 quantize 工具，作用范围是 transformer 主干。

逐层替换时，注意力和 MLP 里的线性层全部换成 QuantizedLinear。权重先搬到当前设备，保留偏置、输入输出维度、半精度格式以及空初始化开关，替换后显存压力明显下降。

def quantize(self, bits: int, empty_init=False, **kwargs):

    if bits == 0:

        return

    from .quantization import quantize

    if self.quantized:

        return self

    self.quantized = True

    self.config.quantization_bit = bits

    self.transformer = quantize(self.transformer, bits,

                                empty_init=empty_init,

                                **kwargs)

    return self

## 训练脚手架搭建

脚本开头固定可见显卡，随后引入数据、模型与加速库。配置里仅调整前缀相关两项，前缀长度 16，投影关闭，其余沿用默认。模型采用同一封装，半精度上显并打印可训练参数规模。

提示词使用统一的抽取指令，数据准备函数负责分词与截断，总长度 288，源文本部分上限 256。DataLoader 批次设为 2，丢弃余数并使用自定义 collate。训练借助 Accelerate 完成设备调度，优化器选 AdamW，初始学习率 2e-5，betas 0.9/0.999，eps 1e-5，学习率调度用 CosineAnnealing，周期 2400 步，末值 2e-6。

共跑 20 个 epoch，每步取出输入与标签前向求损，反向传播后执行优化步与调度步并清零梯度，进度条实时显示损失与学习率，每三轮保存一次权重到 glm6b_pt.pth。

## 生成采样与评估

评估阶段采用 Nucleus 采样实现 Top-p。概率先按降序排序并累加，超出阈值的尾部置零后归一化，再用多项式采样抽取下一个 token 并映射回原始索引。

配置与训练保持一致，前缀开关不变。最大总长 288，源文本上限 256，目标长度据此推导。模型切到 eval 后逐行读取 json，文本与提示词拼接并做截断，保证输入在限制范围内进入生成。

def sample_top_p(probs, p):

    probs_sort, probs_idx = torch.sort(probs, dim=-1, descending=True)

    probs_sum = torch.cumsum(probs_sort, dim=-1)

    mask = probs_sum - probs_sort > p

    probs_sort[mask] = 0.0

    probs_sort.div_(probs_sort.sum(dim=-1, keepdim=True))

    next_token = torch.multinomial(probs_sort, num_samples=1)

    next_token = torch.gather(probs_idx, -1, next_token)

    return next_token
