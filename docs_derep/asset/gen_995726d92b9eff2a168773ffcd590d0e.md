# 提示词这样写，老年人也能一键查社保卡

想给60岁以上的长辈做一份查社保卡的手机使用说明书，提示词可以直接这样组装：“面向60岁以上用户，结合‘视力不好、手机操作不熟练’的使用背景，输出‘查询社保卡’的操作指南，重点围绕‘步骤尽量少’‘图标如何认’‘常见问题怎么排’这三个要点展开，必须做到‘不用专业词、每一步都配大白话说明’，以‘分步骤+配图文字说明’的格式呈现，每步控制在两句话以内。”这条指令跑出来的结果，会把老年人的操作习惯考虑进去，步骤拆得很细、语言很通俗，还会额外补上易错点的排查，长辈能直接照着做。

#### 5. 角色代入式提问
想让结果带上特定风格或专业视角，比如儿童科普要活泼有趣、职场邮件要得体专业，就可以用这个思路。它本质是给豆包先定一个身份，确保输出的语气和角度不会变成千篇一律的AI腔。通用写法是：

> 假设你是 [ 具体角色 ]，从 [ 角色视角 ] 出发，完成 [ 核心任务 ]，体现 [ 角色特质 / 专业要点 ]，以 [ 输出格式 ] 输出，符合 [ 场景调性 ]

举例，给小朋友写一篇讲星星的科普小文，可以这么写：“假设你是儿童科普老师，从‘贴近孩子认知、语言生动好玩’的角度出发，写一篇介绍星星的短文，要体现‘用生活例子把复杂知识讲明白’的特质，避免使用天文术语，以‘开头抓人+知识讲解+互动提问’的结构呈现，全文不超过400字，符合低龄儿童的阅读感觉。”生成的短文会用孩子能懂的比喻和例子，读起来不枯燥，还会加入提问环节，激发阅读兴趣。

#### 6. 小结
前面这5个基础方法，分别解决了场景匹配、目标明确、约束把控、细节把控、角色适配这五大常见卡点。它们的共同逻辑都是把模糊的需求翻译成清晰指令，不用死记硬背，只要把通用模板里的关键词换成自己的实际需求，就能让豆包的输出从可用变好用。日常工作和生活里的大多数基础需求，用这5招基本就能搞定，省去大量反复修改的时间。

> 试一试
从5个方法里挑一个，对应你当前的需求。比如用“角色代入提问法”让豆包扮演“美食博主”写家常菜教程，或用“约束明确提问法”写一篇150字的产品点评，替换模板里的关键词，感受输出是否更贴合预期。

> 小贴士
1）模板里带“[]”的位置信息越具体，结果越准。比方说“具体场景”不要只写“线下活动”，要写成“商场年终促销活动”；“目标人群”不要只写“年轻人”，要写成“18～25岁的大学生”。
2）限制条件别堆太多，抓住核心即可。写文案时重点标明“字数、语气、核心卖点”就够了，约束太多反而会限制发挥。
3）如果结果不理想，先回头检查模板里有没有遗漏关键信息，比如受众、约束条件是否写清楚了，针对性补全比重新提问更高效。

### 技巧 5 豆包通用提问进阶篇（下）
上一节的5个基础方法能覆盖日常高频需求，本节再补充6个进阶用法，帮助你把更复杂的需求问得更准。

#### 1. 问题拆解提问法
适合处理复杂任务或多步骤问题。核心思路是把大难题拆成小问题，让解决路径更清晰，避免得到笼统的答案。通用写法：

> 将 [ 复杂问题 / 任务 ] 拆解为 [ × 个核心子问题 ]，分别给出每个子问题的解决思路和具体步骤，明确子问题之间的关联逻辑，以 [ 输出格式 ] 呈现

比如用户留存率低的问题，可以这样问：“把‘产品用户留存率低’拆成3个子问题——留存低的核心原因、新用户留存的优化手段、老用户唤醒策略，分别给出思路和步骤，原因列出3个关键方向，措施要包含执行步骤，体现‘先找原因→再做新用户留存→最后唤醒老用户’的递进关系，以‘子问题+思路+步骤’的分点形式呈现，总字数控制在800字以内。”输出会先定位原因，再给出可落地的动作，不会只出现“提升用户体验”之类的空话。

#### 2. 数据支撑提问法
当需求需要数据证明或量化分析时，用这个方法能让结论更有说服力。通用写法：

> 基于 [ 数据范围 / 维度 ]，分析 [ 核心主题 ] 的变化趋势和关键结论，列出关键数据指标，说明数据背后的原因和影响，以 [ 输出格式 ] 呈现，避免纯数据罗列

例如分析某产品近三个月销售，可以上传表格后提问：“基于某产品1～3月的销售数据（1月800件、2月1200件、3月900件，客单价均为199元），分析销售表现，列出‘月销量、环比增速、销售额’三个指标，解释2月增长和3月回落的可能原因，并说明对4月销售的影响，以‘数据呈现+原因分析+影响建议’的结构输出，语言简洁专业。”结果会把数据、解读、建议串起来，而不是简单罗列数字。

#### 3. 创意发散提问法
需要灵感或多方案时用这个方法，能跳出固有思维，得到不重复且易执行的点子。通用写法：

> 围绕 [ 核心主题 / 需求 ]，发散 [ × 个 ] 创意方案，每个方案需包含核心亮点和实施要点，符合 [ 约束条件 / 风格要求 ]，以 [ 输出格式 ] 呈现

比如为奶茶店夏季水果茶做宣传，可以问：“围绕‘奶茶店夏季新品水果茶’发散6个宣传创意，每个方案包含亮点和执行要点，符合‘年轻时尚、低成本、易落地’的要求，避免大型活动，以‘方案名称+核心亮点+实施要点’分点呈现，每个方案不超过80字。”输出会覆盖线上线下不同形式，比如话题挑战、限定打卡周边等，贴合年轻用户且成本可控。

#### 4. 总结提炼提问法
面对长报告、多信息时，用这个方法快速抓重点。通用写法：

> 提炼 [ 长文本 / 多信息 ] 的核心内容，聚焦 [ 关键要素 ]，剔除 [ 无关信息类型 ]，以 [ 输出格式 ] 呈现，确保核心信息不遗漏

例如提炼行业报告，可以说：“提炼我上传的《2024年短视频行业发展报告》核心观点，聚焦‘行业规模、用户特征、主流趋势、面临挑战’四个要素，去掉具体案例、数据来源等冗余信息，以‘分点列出，每点不超过3句’的形式呈现，总字数控制在300字以内。”结果会用简洁语言把重点浓缩，快速掌握全貌。

#### 5. 迭代优化提问法
已有初稿不满意时，用这个方法做针对性修改，避免推倒重来。通用写法：

> 基于现有 [ 初稿类型 / 内容 ]，针对 [ 现有问题 ]，按 [ 优化标准 / 期望效果 ] 进行修改，保留 [ 需保留的核心内容 ]，以 [ 输出格式 ] 呈现

比如优化一段网店文案，可以指令：“基于现有商品文案初稿，针对表达平淡、卖点不突出的问题，按‘强化噪强、续航久、价格低3个核心卖点、语气更有感染力、增加行动引导’的标准修改，保留场景化开头，以‘修改后文案+3点修改说明’的格式输出，总字数不超过200字。”修改版会精准解决痛点，同时说明改动逻辑。

#### 6. 对比分析提问法
在多个选项中做决策时，用这个方法能客观比较。通用写法：

> 对比 [多个选项]，从 [对比维度] 进行分析，明确每个选项的优势和劣势，结合 [决策标准] 给出推荐结论，以 [输出格式] 呈现，保持客观中立

例如对比办公软件：“对比WPS、石墨文档、飞书文档3款工具，从‘协作效率、功能丰富度、使用成本、兼容性’四个维度分析，指出各自优劣，结合‘中小团队日常协作、低成本使用’的决策标准给出推荐，以‘表格对比+推荐说明’形式呈现，语言简洁客观。”输出会用表格清晰呈现差异，推荐结论贴合实际需求。

#### 7. 小结
这6个进阶方法分别对应拆解问题、数据分析、创意发散、信息提炼、迭代优化、对比决策六大场景。核心是“深挖需求+设定边界+给出精准指令”，无论是专业分析、创意 brainstorm，还是理性选型，都能让输出更精准。

> 试一试
从这6个方法里选一个应对当前复杂需求。比如用对比分析法比较3款育儿App的适用性，或用迭代优化法润色一份工作汇报初稿，体验精准解决问题的效果。

> 小贴士
- 复杂需求可以组合使用公式，比如先用问题拆解法拆分任务，再用数据支撑法补充分析，结果会更全面深入。
- 创意类需求的约束要适度，比如只限定低成本、易落地，给AI留出发挥空间，过度限制会窄化灵感。
- 对比时维度要统一且关键，比如比产品就聚焦价格、功能、售后，避免混入无关维度，才能快速找到差异。

### 技巧 6 豆包特色功能：六大类能力帮你提效
开会记了半本笔记还是漏待办、做海报调十次还不对、讲方言怕AI听不懂、复杂问题理不清——这些效率堵点，豆包已从单纯的信息助手升级为全能智能体，六大类功能能把这些卡点逐个打通。

#### 1. 大模型底座升级：AI更“懂事”
作为底层能力，豆包会自动选择适配的专项模型，无需手动切换。比如输入“写一段清洗数据的Python代码”，会自动调用编程模型输出带注释的代码；发一张产品设计图问“这个按钮位置合理吗”，会自动启动视觉分析模型指出“按钮离底部太近，单手操作不便”；整理销售数据时，又会切换到统计模型生成分析结论。全程无需在多个工具间跳转。

#### 2. 智能办公助手：告别重复劳动
覆盖协作、分析、存储全流程：
- 会议记录：可自动将录音转文字并识别发言人，标注“研发部周三前出原型”这类待办；跨国会议可实时生成中英双语纪要；视频通话协作时，对准设计图即可实时得到“此处接口易卡顿”等建议。
- 文档智能处理：上传PDF、Excel或流程图，可提取重点、生成脑图并做深度分析，如定位流程图中“审批节点过多”的瓶颈，或对文献自动生成综述。
- AI云盘：支持大容量存储，还能“加工文件”。视频可问答，如“第5分钟提到的方案细节”；表格可自动生成可视化图表。
- 共享应用/屏幕：不再反复复制粘贴。支持PC和手机双向共享整个屏幕、单个应用窗口或浏览器标签页，可同步系统音频和麦克风。边改Excel公式、修图就能直接问“这个函数返回值为什么错误”“图表怎么优化”，比截图提问高效数倍。
- AI视图：网页增强功能，看新闻点“AI总结”3秒抓核心；看B站、抖音视频点“AI看视频”，可得带时间轴的摘要。
- AI浏览器：可导入旧浏览器的书签、登录记录和表单数据；英文网页可划词对照翻译并保留排版。

#### 3. 创作与内容生成：零基础也能出作品
- AI生图：上传参考照片加文字描述，如“带蝴蝶结的国风短毛猫，工笔画风格，红色蝴蝶结”，生成的图既保留神态又贴合风格。
- AI编程：输入“做一个粉色风格的水果接落小游戏”，会生成带注释代码并提示“下落速度调成0.5秒更适合新手”；代码报错可直接复制错误信息求修复。
- 视频与播客生成：文本转视频时人物动作更自然；文档可一键转为播客音频，方便知识分享。

#### 4. 智能交互升级：沟通更自然
- 方言与语音交互：支持13种方言，识别率超92%，延迟低至200ms。用粤语问“广式早茶经典点心”，会补充“虾饺选皮透亮的”等实用建议。
- AI划词工具栏：网页、PDF、Word中划词即出现翻译选项，支持对照翻译并保留格式；遇到不可复制文档也能翻译。
- 实时视觉问答：拍实物、截图即可提问，如拍零食包装问热量、拍数学题求解题步骤、拍电路图问元件作用，解读更精准。
- 商品卡：问答时同步推荐相关商品并带用户评价。如问“露营装备推荐”，会弹出带防水系数和评分的帐篷、睡袋卡片，一键跳转购买。

#### 5. 内容理解与知识服务：刨根问底
- 深度思考推理：遇到复杂问题会先查数据再分析原因，如“为什么今年露营热度下降”，会给出销量数据并解释周边游多元化等原因。
- 视觉推理：从图片找隐藏逻辑，如指出数学题“第一步公式列错了”，或提醒“此处材质不适合户外”。
- 视频解析：粘贴B站、抖音链接可提取文案、总结要点，效率远高于手动笔记。

#### 6. 安全与隐私保护：用得安心
- 未成年人保护模式：开启后默认关闭视频展示、第三方网页浏览、智能体对话、AI创作，翻译、深度研究等功能仍可用；退出需输密码。
- 隐私数据管控：可手动删除单条或批量清理对话历史；导入浏览器书签时可选择跳过网银、工作平台等敏感登录信息。

#### 7. 小结：从“能回答”到“能办事”
豆包现在能打通“提问-处理-落地”全流程。比如问露营装备，既给建议又推商品；做会议记录，既转文字又标注问题并协作文档。多模态协同、方言识别、视觉推理等细节让使用更贴近真实场景。
