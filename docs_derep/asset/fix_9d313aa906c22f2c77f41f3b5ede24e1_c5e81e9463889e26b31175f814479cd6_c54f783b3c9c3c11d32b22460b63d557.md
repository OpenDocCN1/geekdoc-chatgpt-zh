长序列注意力提效：先定位桶再算分

生成查询后不直接对全量 Key 做全量对齐，而是先借助索引把计算范围收敛到少数几个 Key 子集。随后注意力只在候选子集上展开，参与运算的矩阵被压缩，执行更快。

这样可以砍掉 Query 与无关 Key 之间大量冗余的相似度计算，同时让硬件访存更集中，局部性明显改善。

### 1.3.4 稀疏注意力与线性注意力的取舍

Transformer 自注意力是核心模块，但标准形式对长度 N 的序列时间与空间复杂度均为 O(N²)。在长序列推理与训练中负担很重，对 QwQ-32B 这类百亿参数级模型瓶颈更明显。因此研究者提出稀疏注意力和线性注意力两条主线，前者以结构选择压缩计算域，后者从核函数重构计算路径，各自在不同任务与硬件上各有优势。

#### 1. 稀疏注意力：可控的区域计算

核心是在权重生成时引入位置筛选，不让每个 Query Token 与全部 Key Token 全量求相似，而是聚焦重要或相关的部分位置，通过稀疏化权重矩阵降低开销。

常见模式：
- （1）局部窗口注意力：仅在固定长度邻域内计算，适合语义连贯文本。
- （2）滑动窗口注意力：每个 Token 关注邻近区域，并通过跨段连接保持整体连通。
- （3）块稀疏注意力：把输入分块，仅在选定块对之间建立连接，兼顾局部与远程依赖。
- （4）自适应稀疏注意力：动态挑选连接路径，如 BigBird、Longformer 采用的混合稀疏结构。

优点是结构可控、实现灵活、可与原生 Attention 兼容；缺点是模式设计复杂、对稀疏硬件依赖强，对完全非结构化文本适应有限。

在 QwQ-32B 中，稀疏注意力主要用于 KV Cache 压缩和多段文档融合推理，能有效降低解码阶段注意力热区密度，减少无效计算。

#### 2. 线性注意力：核函数重写

从核函数层面把复杂度由 O(N²) 降至 O(N)。关键是用可加性核函数替代 softmax 归一化，如 ReLU、ELU 或带正性约束变换，并让 Q、K、V 融合计算，重组为线性组合，避免显式构造完整相似度矩阵。

典型代表包括 Performer、Linformer、CosFormer/DAGFormer 与 Retentive Networks。

- (1) Performer：采用随机特征映射把 softmax 近似为线性核。
- (2) Linformer：通过对 K/V 进行低秩投影实现序列压缩。
- (3) CosFormer/DAGFormer：引入傅里叶变换或图结构进行长程依赖建模。
- (4) Retentive Networks：将线性注意力和记忆机制结合，增强语义保留能力。

最大优点是可扩展性与硬件并行友好，适合超长序列建模，推理效率高，内存随长度线性增长。缺点是缺乏 softmax 带来的信息聚焦，在对齐、生成质量与细粒度控制上表现弱于标准注意力，且不适合跨段交互频繁的任务。

QwQ-32B 并未把线性注意力作为默认结构，但在多轮长上下文推理实验中将其作为可选优化路径，在大于 32K 长度窗口、KV Cache 受限场景下展现出较好的资源友好性。两者对比如表1-2所示。

表1-2 稀疏注意力vs线性注意力综合对比

| 比较维度 | 稀疏注意力 | 线性注意力 |
| :--- | :--- | :--- |
| 复杂度 | O(N × k)，k 为局部连接数 | O(N)，线性 |
| 表达能力 | 接近原始 Attention | 可能缺失 softmax 聚焦特性 |
| 灵活性 | 结构设计强依赖任务 | 结构统一，可以广泛替换 |
| 硬件友好性 | 需要稀疏矩阵优化 | 高度并行，硬件友好 |
| 多模态适配性 | 更适合文本/图文混合 | 适合纯序列、连续数据流 |
| QwQ-32B 应用 | 默认支持局部+块状稀疏结构 | 可选线性 Attention 模式 |

稀疏注意力和线性注意力分别代表结构稀疏化与核函数重构两条路线，是大模型缓解注意力瓶颈的重要补充。QwQ-32B 中两者并非对立，而是按任务形态和输入规模灵活选用，在保持语义建模能力的同时兼顾推理效率与生成质量。

## 1.4 模型压缩与结构稀疏性优化

随着参数规模持续增长，压缩与结构稀疏优化成为提升部署效率与推理性能的关键路径。QwQ-32B 在保持表达能力前提下引入多种压缩策略与稀疏重构，包括参数高效微调 LoRA、低比特量化 QLoRA、分层剪枝与学生-教师蒸馏框架等，显著减少实际部署的算力消耗。本节系统阐述其工程实践。

### 1.4.1 LoRA 在 QwQ-32B 中的精调集成

大语言模型参数快速膨胀，全参数微调已难以满足算力、存储与训练周期要求。LoRA 通过在 Transformer 关键矩阵中注入低秩可训练模块，实现参数冻结下的高效微调，本质是参数高效微调 PEFT，只需训练少量新增参数即可实现性能迁移，显存开销与训练时间大幅下降，尤其适用于 QwQ-32B 这类百亿参数复杂结构。

在 QwQ-32B 中，LoRA 模块深度集成于 Attention 子层和前馈网络线性变换，支持模块级精细插入、多任务共享配置，并提供动态图插拔、热更新、分租户 LoRA 加载等工程特性，广泛应用于行业定制模型构建、轻量级多任务适配与推理在线个性化微调。
