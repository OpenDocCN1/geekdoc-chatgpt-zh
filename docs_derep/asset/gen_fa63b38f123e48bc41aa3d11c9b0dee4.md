# 第三章 司法人工智能的边界在哪

极限在数学里指无限逼近却永远达不到的界线，在工程分析中用得很多。对以概率和数据为根基的司法人工智能而言，极限同样关键。先把理论边界划清楚，就能在框子里做事，少一些不切实际的幻想和无效投入，集中发挥机器优势，再与人的能动性结合，达到人机耦合的最佳状态。也就是说，厘清边界是应用落地的起步。目前大家已有感觉，但整理和总结得不够透彻。

## 第一节 理论边界为何模糊

从现有的讨论看，学界和实务界对司法人工智能的极限并非无知，而是把握粗糙、缺乏系统梳理。

### 一、被忽视的边界与学界警示

检索可见的文献里，鼓吹、研发和推广的声音远大于审慎的声音。国家导向、站位和思维习惯都在推着它往前走。对做产品的公司来说，渲染前景、抢占市场是本能，理论上限就容易被有意无意忽略。照搬经验的类推也很常见：人工智能在商业领域成功了，便想自然延伸到相对保守的司法场域，把边界问题给掩盖了。

对此学界已有不少提醒。马长山从社会风险切入，指出伦理风险、极化风险、异化风险、规制风险、责任风险等交织，需要以风险社会理念建立多元互动的规制体系，实行过程与结果双重监管，让人工智能健康发展、法治秩序不失衡。^([\[1\]](#txt006.html#footnote_content_txt006_1))王禄生捕捉到技术话语与司法话语的分离，关注技术权力对司法权力的浸入边界^([\[2\]](#txt006.html#footnote_content_txt006_2))，并呼吁警惕片面技术理性，对大数据与人工智能开发进行反思^([\[3\]](#txt006.html#footnote_content_txt006_3))，主张回到司法属性对技术进行规训。季卫东以电脑量刑为例说明，电脑法律实证主义的预设排除了自然法、权利保障、天理人情等思辨要素，也轻视了司法运行中的背景条件与地方性知识，而这些恰恰勾勒出计算机专家系统与人工智能审判的疆界。^([\[4\]](#txt006.html#footnote_content_txt006_4))

### 二、厘清极限需要双重视角

上述研究从法理、社会和审判微观层面都提供了启发，但仍有不足。一方面多停留在抽象表述，对司法自身的属性缺乏系统反思，因而难以说明司法应如何规训技术；另一方面，工具背后的技术原理并未充分展开，工具本身的局限性以及与司法的错配也就难以看清。

因此需要更系统地回应几个连环问题：司法人工智能因工具属性决定了做不了什么；它能做的范围内，司法改革、制度、审判、法院管理、社会服务要如何配合改动；成本、收益、风险能否被准确认知、可控；技术改造后的司法还是我们想要的司法。这些问题指向三个层面：客观上做不到，即工具本身的不可能；场景上不匹配，即工具与司法场景的适配问题；主观上的司法反制，即司法本身对技术扩张的制约。三者相互缠绕。人工智能在司法中的应用是主客观统一的过程，既要承认工具的固有属性和潜能，也要容纳主体的价值判断。为此，本文尝试站在前人基础上，把理论极限梳理得更清晰。

## 第二节 人工智能的三大不可能

技术极限源于人工智能自身的不可能性。相比传统工具，人工智能迭代快、自我适应性强，但从原理看并非万能，有三重不可逾越的限制。

### 一、理性计算之外无能为力

工具主义的定位不谈科幻式的威胁论，而是看工具的潜能与边界。从原理上说，人工智能是计算机工程，活动范围被限制在理性计算之内。图灵设计的图灵机为今天乃至很长时间的计算机划定了不可突破的线。它提出的核心疑问是：并非所有数学问题都有解，有解的问题中只有一部分能用有限步计算，有限步可解的问题中只有一部分能被理想图灵机解决，能被理想机器解决的又只有一部分能被现实计算机解决，而人工智能能解的只是计算机可解范围的子集。^([\[5\]](#txt006.html#footnote_content_txt006_5))清华未来实验室的马兆远强调，图灵机实际上印证并拓展了哥德尔不完备定理，只能处理人类能清晰描述、能认识的问题；^([\[6\]](#txt006.html#footnote_content_txt006_6))工程院院士邬贺铨也认为人工智能本质是统计学，只是包装得更华丽。^([\[7\]](#txt006.html#footnote_content_txt006_7))希勒的“中文房间”很好地验证了这一点：房间里的人按对照表机械应答，看似理解中文，实则一窍不通。程序只能处理符号关联，对思考本身无助于事。^([\[8\]](#txt006.html#footnote_content_txt006_8))

表象上，语音识别对应听觉，图像识别对应视觉，自然语言处理对应读写，但实质只是把感知转化为数据的收集、汇聚，再用算法程序输出。机器只是机械地复现人脑智能，并不懂得其运作机理。感知类技术相对成熟，却仅落在感性层面，要进入理性认知阶段还有很长的距离。^([\[9\]](#txt006.html#footnote_content_txt006_9))至于情感、价值、意志、信仰等非理性维度，康德说过要为信仰留空间^([\[10\]](#txt006.html#footnote_content_txt006_10))，人工智能更难触及。可以说，这类领域天然应是应用禁区。人工智能的基础是信息程序，以0和1、真与假为边界的逻辑，还没有涵盖情感逻辑。^([\[11\]](#txt006.html#footnote_content_txt006_11))

### 二、脱离三大条件无法自生

与传统工具不同，人工智能具有自我改进性，这来自机器学习尤其是神经网络驱动的深度学习。与线性建模不同，深度算法能根据输入自行模拟构建模型，具有自优化特征。^([\[12\]](#txt006.html#footnote_content_txt006_12))这种自我改进容易让人产生它会越学越强、最终取代人类的错觉。但发展并非无条件的逍遥游，而是被大数据、算法、算力三重条件牵制。

大数据要求海量、高速、多样、真实^([\[13\]](#txt006.html#footnote_content_txt006_13))。海量是体量，高速是更新及时，多样是来源与内容的立体，真实是可靠性。四者兼备才接近全样本。关键在品质，而非单纯大小，这也是 big data 与 large data 的区别。现实采集、汇聚、加工的数据与理想状态有距离，既有客观不完整，也有主体道德偏见。IBM 研究者奥尔泰努指出，数据决定决策方式，而采集与测量方式本身会带来偏见与不完整；社会数据的偏差很难完全消除，甚至不可接受。^([\[14\]](#txt006.html#footnote_content_txt006_14))

算法依赖前端训练样本，后端形成模型并测试，再循环优化。理想如此，实践中常出现过度拟合、欠拟合。机器学习还有“无免费午餐”定理：不存在在所有分类问题上都最优的算法。序列1、2、4既可以是递增规律，也可以是指数规律，任何单一算法都无法同时满足。^([\[15\]](#txt006.html#footnote_content_txt006_15))算力方面，摩尔定律和硬件发展的确提升了深度神经网络的可行性，过去数天都算不完的任务现在可以进行，但算力作为外部制约始终存在。姚海鹏等指出，在算力突破前，多层神经网络几乎没有实用价值。^([\[16\]](#txt006.html#footnote_content_txt006_16))

### 三、技术创新不能跳出既定历史

人工智能的目标不只是解释已有样本，更在于预测未知样本。看似前瞻，实则仍属归纳推理：从有限样本推广到整体。^([\[17\]](#txt006.html#footnote_content_txt006_17))它处理的是已存在或正在生成的数据，而非尚未生成的数据。依据的是既有经验，即所谓有多少人工才有多少智能，垃圾进垃圾出。人工智能无法超越既定历史而创新。人类能感知经济社会变化，以非程序化的方式摆脱既定模式并创造性推动历史，这是机器不具备的。

综合来看，张钹院士的总结很到位：当前技术适合的场景，一般要有充分数据和知识储备，且是确定性问题、信息完备、静态、任务有限、领域特定。^([\[18\]](#txt006.html#footnote_content_txt006_18))
