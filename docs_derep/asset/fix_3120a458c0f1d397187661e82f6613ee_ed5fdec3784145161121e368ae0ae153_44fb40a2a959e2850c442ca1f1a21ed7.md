# 给智能体加框，输出才听话

让大模型自由发挥往往得到一堆不可控的答案。提前把字数、语言、排版等硬性条件写进提示，就能把产出收敛到想要的区间。下面是三类可在翻译流程中直接落地的智能体方案，含可复制的提示词模板。

### 1.2 平行文本分析智能体

设计目标
对双语平行语料做跨语对比，梳理原文与译文在结构、文风、核心词上的差异，为译质评估和术语库搭建提供依据。

落地思路
平行文本分析师专注双语对照，擅长跨语结构拆解、风格映射与差异捕捉、专业术语对齐核验。主要完成：① 解析双语写作特点如句式复杂度、修辞手法、语气并归类文体；② 抽取并校验核心术语的对应关系，涵盖技术词与文化专有名；③ 标注显著的跨语风格偏好，例如英语偏被动、中文偏主动。考察维度包括句式层面、修辞本土化、术语一致性，以及风格差异对信息传递效果的影响，例如英语重数据论证、中文重情感叙事。

### 1.3 译前术语抽取智能体

设计目标
快速定位源文本的核心术语并生成双语对照表，为后续翻译建立统一基准，保证概念跨语一致。

落地思路
译前术语提取专家负责术语预处理，核心能力为领域敏感识别、译法准确校验、语境适配映射。主要工作：全面扫描原文抽取主题相关的专业词与高频词；按“{{source_lang}}术语：{{target_lang}}”格式产出标准表；借助算法过滤通用词，聚焦领域关键概念。分析聚焦术语强度、技术词/机构名、主题关联度、文化专有性；校验侧重目标语行业通用性与单义性控制，避免一词多译。

可用提示词

中文指令

**人设：**
译前术语提取专家

**输入：**
将提供源文本。

**任务：**
● 分析源文本并识别所有可能的术语

### 1.4 专业翻译智能体

设计目标
依靠术语映射与文化适配实现高保真跨语转换，保障术语统一、语法规范与风格还原，降低信息损耗。

落地思路
专业翻译员专注精准转换，核心能力为文化语境表达映射、术语一致强制校验、语法规范动态控制。流程四步：解析原文识别文化专有项与术语节点；强制套用术语表禁止偏离；动态调整修辞策略，如英被动转中主动并增语气词；校验目标文本流畅度与信息完整，实现零增删漏译。体系包括术语映射、文化适应、风格还原三方面：术语映射要求 100% 匹配术语表并消歧；文化适应要求制定俚语替代方案并决策专有名处理方式；风格还原要求镜像句式复杂度并等效转换修辞手法。
