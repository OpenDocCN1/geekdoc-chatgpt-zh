#### 1. Fermi 架构
2010 年 NVIDIA 推出 Fermi，示意图见图 4.1.1。最大配置可集成 16 个 SM，单 SM 32 个 CUDA Core，全开 512 核心。设计偏向游戏，芯片由多个图形处理簇 GPC 构成，每个 GPC 含 1 个光栅引擎及 4 个 SM。

内存采用 6 组 64 位分区，总线 384 位，最高 6 GB GDDR5。GPU 通过 PCIe 与主机相连。GigaThread 全局调度器将线程块分发给各 SM 的本地调度器。计算单元增多后 L2 缓存置于芯片中央，便于 CUDA Core 之间高速交换。

Fermi架构：16个 SM 围绕一个的L2 Cache部署。每个SM是一个垂直的矩形，包含一个橙色部分（调度器和分派单元）、一个绿色部分（执行单元）以及浅蓝色部分（寄存器文件和L1 Cache）

恩里科·费米是意大利裔美国物理学家，20 世纪核物理、量子力学与统计力学的代表人物，被誉为原子能时代之父。主要贡献：
- 提出费米-狄拉克统计，用于描述半整数自旋粒子规律。
- 主持芝加哥大学费米堆计划，实现首座自持核链式反应堆。
- 参与曼哈顿计划，为原子弹研发作出关键贡献。
- 因放射性同位素研究获 1938 年诺贝尔物理学奖。

Fermi 使用第三代流处理器，单 SM 配备 16 个 LD/ST 单元，可在每个时钟为 16 个线程计算源地址与目的地址并搬入缓存或 DRAM。SFU 负责正弦、余弦、求导、平方根等超越函数，每线程每时钟一条指令，一个 Warp 需 8 个时钟。SFU 管线与调度解耦，调度器在 SFU 忙时可向其它单元发指令。双精度是 HPC 核心，单 SM 单时钟可完成最多 16 次双精度融合乘加。

每 SM 有 2 个 Warp 调度器与 2 个指令调度单元，可同时发出并执行 2 个 Warp。CUDA 内核并行执行，每个处理器拥有完整流水线的整数 ALU 与浮点单元，可选 FP32 或 INT8，但整数与浮点不并行。

并行 Kernel 由 Thread、Block、Grid 三层构成，见图 4.1.3。线程层使用本地内存，块层使用共享内存，网格层使用全局内存，对应线程私有、块共享、应用全局的存储空间。

#### 2. Kepler 架构
2012 年 NVIDIA 发布 Kepler。GK110 含 71 亿晶体管，采用 28 nm 工艺，双精度吞吐量超 1 TFLOP，单位功耗性能约为 Fermi 的 3 倍。如图 4.1.4 所示，最多支持 15 个 SMX 与 6 个 64 位内存控制器，内存子系统增加额外缓存，各层带宽提升，DRAM I/O 更快并为编程模型提供硬件支持。

约翰内斯·开普勒是德国天文学家、数学家，现代天文学奠基人之一。主要成就：
- 提出行星运动三大定律。
- 以观测确立椭圆轨道理论，推翻传统圆周观念。
- 在光学、天文学、数学方面贡献，为牛顿引力奠基。

如图 4.1.5 所示，Kepler 将流式多处理器更名为 SMX，概念继承自 Fermi。每 SMX 集成 4 个 Warp 调度器与 8 个指令调度单元，可同时发送并执行 4 个 Warp。Fermi 每 SM 32 核，Kepler 提升至 192 核，并行能力大幅提升。最大线程数由 1536 提升到 2048。每 SMX 配备 64 个双精度单元、32 个 SFU 与 32 个 LD/ST 单元，满足 HPC 需求。

Kepler 支持动态并行，无需 CPU 干预即可自动同步，运行时可灵活调整并行数量与形式。Hyper-Q 使多 CPU 核心共享单张 GPU，提升利用率并减少 CPU 空闲，支持 32 个硬件管理连接，允许多 CUDA 流并行处理。网格管理单元 GMU 用于动态并行和调度控制，可挂起或暂停网格直至环境就绪。

#### 3. Maxwell 架构
2014 年 NVIDIA 推出 Maxwell。如图 4.1.6 所示，相较 Kepler 改动有限，流式多处理器名称恢复为 SM，整体核心数降至 128，通过超额分配线程提升并行能力。

Maxwell SM 采用象限设计，由 4 个处理块组成，每个处理块 32 核并拥有专属 Warp 调度器，可在每个时钟调度两条指令。每 SM 提供 8 个纹理单元、1 个几何处理引擎，以及专用的寄存器文件与共享内存。单核性能比 Kepler 高 1.35 倍，性能功耗比约为 Kepler 的 2 倍。

詹姆斯·克拉克·麦克斯韦是 19 世纪英国物理学家，电磁理论之父。主要成就：
- 提出麦克斯韦方程组，统一电磁与光学。
- 发展统计力学，提出麦克斯韦-玻尔兹曼分布。
- 提出色散理论，解释光的色散。
- 预言电磁波存在，为无线电通信奠基。

与 Kepler 对比，Maxwell 共享内存与 L1 Cache 分离，每个 SM 可配置 64 KB 共享内存，GM204 提升至 96 KB。与 Fermi、Kepler 相同，线程块最大共享内存仍为 48 KB。Maxwell GM204 的 L2 Cache 是 Kepler GK104 的 4 倍，对带宽受限应用有利。每 SM 可并发线程块从 16 个增至 32 个，有助于小线程块内核利用率。32 位整数的本机共享内存支持原子操作，线程块内列表与栈处理更高效，同样支持动态并行。

#### 4. Pascal 架构
2016 年 NVIDIA 发布 Pascal，图 4.1.7。内存由 GDDR5 升级为 HBM2，可在更高带宽下处理更大数据集。采用 16 nm FinFET，集成 153 亿晶体管，相同功耗算力提升一个数量级，并首次引入第一代 NVLink。

GP100 由 GPC、TPC、SM 与内存控制器构成。完整 GP100 含 6 个 GPC、60 个 Pascal SM、30 个 TPC，每 TPC 含 2 个 SM，以及 8 个 512 位内存控制器，共 4096 位。每 GPC 含 10 个 SM，每个 SM 有 64 个 CUDA Core 与 4 个纹理单元。GP100 共 60 个 SM，合计 3840 个单精度 CUDA Core 与 240 个纹理单元。每个内存控制器连接 512 KB L2 Cache，每个 HBM2 DRAM 由一对控制器管理，整体 L2 Cache 4096 KB。

Pascal 在 SM 内部精简，SM 数量随工艺提升而增加。单个 SM 仅保留 64 个 FP32 CUDA Core，远少于 Maxwell 的 128 核与 Kepler 的 192 核，并分为 2 个区块，每区块 32 个单精度 CUDA Core、1 个指令缓冲区、1 个 Warp 调度器与 2 个调度单元。寄存器文件规模不变，每个线程可用寄存器增多，单个 SM 可并发更多 Thread、Warp、Block，进一步提升并行能力。

布莱斯·帕斯卡是 17 世纪法国数学家、物理学家、哲学家与神学家，被视为文艺复兴时期重要思想家之一，现代概率论与流体力学奠基人。主要成就：
- 发明帕斯卡三角形，广泛用于组合数学与概率论。

- 发展概率论，为概率统计学奠基。

多机环境下 InfiniBand 与 100 Gb 以太网通信导致 PCIe 成瓶颈，Pascal 首次提出 NVLink，用于多 GPU 与 GPU-to-CPU 的高带宽连接。NVLink 实现单机内多 GPU 点对点通信，带宽达 160 GB/s，约是 PCIe 3.0 x16 的 5 倍，降低传输时延，避免数据反复经 CPU 内存搬运，实现 GPU 网络拓扑互联，见图 4.1.8。分布式训练中带宽常为瓶颈，NVLink 的引入意义重大。

#### 5. Volta 架构
2017 年 NVIDIA 推出 Volta，GV100 GPU 集成 211 亿晶体管，采用 TSMC 12 nm 工艺。主要创新包括：
- CUDA Core 拆分，FPU 与 ALU 分离，取消整体 CUDA Core 硬件概念，一条指令可同时执行不同计算，提升 CUDA 应用的灵活性、生产力与可移植性。
- 独立线程调度，改进 SIMT 模型，每个线程拥有独立程序计数器与栈，支持并行线程间更细粒度同步与协作。
- 为深度学习优化 SM 架构，首次引入 Tensor Core 加速卷积计算。
- NVLink 升级为第二代，一个 GPU 可连接 6 个 NVLink，16 GB HBM2 内存子系统峰值带宽 900 GB/s。
- 提出 MPS 概念，允许多个应用共享 GPU 执行资源，客户端数从 Pascal 的 16 个提升到 48 个，支持多推理任务并发。
- 优化 GPU 加速库 cuDNN、cuBLAS、TensorRT，提升深度学习推理与 HPC 应用性能。

亚历山德罗·伏特是 18 世纪意大利物理学家，被誉为电池之父。主要成就：
- 发明伏特电堆，产生持续电流，是首个实用化学电池。
- 提出静电感应理论，推动电学理论发展。
