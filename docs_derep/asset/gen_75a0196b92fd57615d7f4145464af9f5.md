想用 ChatGPT 来做象限分析，核心就是把需要分析的数据和关键指标先整理好投喂进去。比如把产品表里市场增长率和相对市场份额这些维度交给模型，它就能帮你判断每款产品落在哪个象限，并解读不同象限的联系与特征。

象限分析的精髓在于可视化，把数值放到四个象限里分布规律立刻一目了然。现在的 ChatGPT 没法直接画出四象限图，但它能精准识别归属并给出象限间的洞察。下面看一个实操例子。

| 产品 | 市场增长率 | 相对市场份额 |
|---|---|---|
| 产品 A | 0.25 | 0.6 |
| 产品 B | 0.15 | 0.35 |
| 产品 C | 0.4 | 0.75 |
| 产品 D | 0.05 | 0.2 |
| 产品 E | 0.3 | 0.55 |
| 产品 F | 0.1 | 0.15 |

把上面这段信息发给模型后得到如下思路：

以均值为界划分四类：

+   1. 星级产品，高增长高份额：增长率 > 0.2083 且份额 > 0.425
2. 现金牛产品，低增长高份额：增长率 ≤ 0.2083 且份额 > 0.425
3. 问号产品，高增长低份额：增长率 > 0.2083 且份额 ≤ 0.425
4. 瘦狗产品，低增长低份额：增长率 ≤ 0.2083 且份额 ≤ 0.425

2. 现金牛产品：产品 A
3. 问号产品：产品 E
4. 瘦狗产品：产品 B、产品 D、产品 F

# 9.9 SWOT分析实战指南

SWOT 是咨询里常用的战略框架，业务分析里也经常借用。先让模型解释概念并给案例。提示词可以这样写：

> 假如你是一名资深数据分析师，请给我讲讲数据分析中常用的SWOT分析，需要包括具体的概念、案例以及如何借助ChatGPT进行SWOT分析。

模型给出的核心定义：SWOT 是 Strengths 优势、Weaknesses 劣势、Opportunities 机会、Threats 威胁的缩写，用来识别内部和外部的关键因素从而制定策略。

+   1. 优势：组织或产品在竞争中的内部强项，如核心能力、资源、技术、人才等
+   2. 劣势：内部短板，如资源不足、流程低效、技术滞后等
+   3. 机会：外部环境带来的利好，如需求增长、政策支持、技术突破等
+   4. 威胁：外部环境带来的风险，如竞争加剧、政策变动、市场波动等

案例：手机制造商的竞争定位。

+   1. 优势：技术领先、研发团队专业、产品品质高、品牌口碑好
2. 劣势：生产成本高、营销资源受限、全球化经验不足
3. 机会：智能手机需求持续增长、新兴市场可拓展、技术创新带来差异化
4. 威胁：市场竞争激烈、价格战、政策变化、供应链不稳

怎么让 ChatGPT 帮忙做 SWOT？把行业背景、竞争对手、目标市场等信息给它，让它基于这些信息梳理四象限并给出策略建议。

# 138 | 第9章 ChatGPT参与数据分析全流程

继续明确四个字母的具体含义后，模型承认 SWOT 涉及对业务和行业的深度理解，它无法直接替你完成分析，但能提供思路框架。举例提示：

> 我在一家聚焦AI的初创游戏公司工作，现在要开展SWOT分析，请告诉我如何一步一步开展工作。

返回的工作步骤如下：

+   1. 收集信息：先掌握公司、市场、竞争对手、行业趋势的相关资料，包括产品服务、企业文化、资源能力、市场规模、技术发展与政策等
2. 确定优势：内部强项，例如：
+   - 团队经验丰富
- 与发行商合作关系良好
- 对目标市场理解深入
3. 确定劣势：内部短板，例如：
+   - 资金来源有限
- 市场推广经验不足
- 对特定引擎或平台依赖度高
- 品牌知名度和影响力弱
- 时间和资源紧张
4. 确定机会：外部利好，例如：
+   - 游戏行业需求持续增长
- 新兴市场可开拓
- 跨平台发行与云游戏发展
- 合作伙伴网络可拓展
- AI 技术进步带来创新空间
5. 确定威胁：外部风险，例如：
+   - 竞争激烈
- 技术迭代快
- 法规政策变化
- 用户数据隐私安全问题
- 知识产权保护与侵权风险
6. 制定策略和行动计划：基于分析结果强化优势、补足劣势、抓住机会、抵御威胁。例如加大研发投入优化 AI 与游戏设计，寻求战略投资解决资金问题。
7. 监测与评估：执行后定期跟踪销售额、市场份额、用户满意度等指标，动态更新 SWOT 并调整策略。

借助 ChatGPT 时，每个环节都可以提问求助，如信息收集阶段查竞争对手资料，策略制定阶段咨询推广方案，通过互动让分析更全面。

# 9.10 PEST环境扫描

PEST 和 SWOT 思路相近，也是常用的宏观分析框架。提示词示例：

> 假如你是一名资深数据分析师，请给我讲讲数据分析中常用的PEST分析，需要包括具体的概念、案例以及如何借助ChatGPT进行PEST分析。

模型解释：PEST 用于评估政治 Political、经济 Economic、社会 Sociocultural、技术 Technological 对公司和市场的影响，帮助发现机会与挑战。

案例：考虑在新市场推出智能家居产品时的环境扫描。

# 9.10 PEST 框架拆解 | 141

# 1. 政治因素：
+   - 当地政府对智能家居行业的支持政策
- 法规与标准，如数据隐私和安全要求
- 可能的贸易限制或关税

# 2. 经济因素：
+   - 当地市场消费能力与购买力
- 经济增速与通胀水平
- 利率与汇率走势

# 3. 社会因素：
+   - 目标市场的消费需求与偏好
- 人口结构与家庭构成
- 社会价值观

在没有数据可直接输入时，ChatGPT 仍能提供帮助：梳理分析思路、给出可视化建议、把分析结果数据故事化并撰写易懂报告、基于反馈给出优化迭代建议、推荐培训与学习资源。虽然无法处理大量多源数据做专题分析，但可以辅助整个流程提升效率与质量。
