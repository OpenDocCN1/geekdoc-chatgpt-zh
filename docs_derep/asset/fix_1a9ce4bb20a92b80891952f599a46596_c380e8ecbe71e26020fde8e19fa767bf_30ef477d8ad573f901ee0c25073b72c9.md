# 手写 CUDA 算子 vs TensorFlow 原生：MNIST 实测

最近想验证一个直觉：把全连接里的矩阵乘换成自己写的 CUDA 核，数值结果会不会跑偏、训练耗时会不会明显变化。于是用最简的三层网络做对照，同一套超参、同一份 MNIST 数据，分别跑一次官方算子和自研算子，把全流程记录下来。

**实验配置**
网络是 784 输入 → 256 隐藏 → 10 输出的全连接结构，优化器用 Adam，学习率 0.001，批次大小 128，训练 5 轮。MNIST 原图展平成一维向量后归一化到 0~1，训练集随机打乱后分批，测试集只做评估。两组模型结构完全相同，唯一区别是前向时是否调用自定义算子。

**实现思路**
训练部分用 GradientTape 自动微分，每批先算交叉熵损失再反向更新，同步累加损失和准确率并计时。评估部分只做前向推理，汇总各批准确率得到最终水平。主流程负责数据预处理、Dataset 构造、模型与优化器初始化，然后按标准算子、自定义算子两组顺序执行训练与测试。

**自定义算子搭建**
为了让 TensorFlow 能调用手写矩阵乘，先用 CUDA 写一个简单的累加核，再用 C++ 封装成 TensorFlow Op，注册输入输出与形状推断，并在 Compute 里校验维度与属性后分配输出。脚手架如下：
