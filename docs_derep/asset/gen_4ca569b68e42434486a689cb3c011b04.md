# 第五章　数字职场里劳动者个人信息怎么护
吴文芳　上海财经大学法学院教授
王　倩　上海政法学院司法研究所教授

个人信息保护在国内正进入密集立法的快车道，《民法典》、个人信息保护法和数据安全法接连落地，堪称里程碑式的制度升级。对一个就业人口规模庞大的国家而言，这波立法浪潮直接撞上了劳动者群体的数据权益。正当技术重塑生产方式之际，工作设备、作业流程乃至工作对象都在加速数字化，用人单位对员工信息的采集和使用变得更深、更广。被全天候监测、画像、预判乃至操控的风险明显抬头，个人人格尊严、自由发展以及其他人身和财产利益都可能因此受损。劳动关系天然带有从属性和依附性，劳动者个人信息不能简单套用一般私法规则，需要专门化、更有针对性的保护安排来兜底。
