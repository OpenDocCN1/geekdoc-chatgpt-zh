CInnerProduct 层：带稀疏手术的内积升级版

Caffe 原生的 InnerProduct 在这里被扩展成了 CInnerProduct，计算骨架仍然是把输入从指定轴之后压平成向量再做矩阵乘法，但额外挂载了一套掩码驱动的动态稀疏机制，借助临时缓存和若干可调超参来控制剪枝强度。整体工作可拆成结构声明、参数装配、形状推断和前向准备四个环节。

作为 Layer<Dtype> 的模板子类，该层对外标识为 “CInnerProduct”，底部和顶部 Blob 均只接受一路。受保护接口同时声明了 CPU 与 GPU 的前向后向实现。公开状态里 M_ 用来保存批次前缀的样本数，K_ 保存展平后的特征维度，N_ 保存输出单元数，bias_term_ 决定是否带偏置，bias_multiplier_ 用于偏置广播。私有区保留了 weight_tmp_、bias_tmp_ 两块临时存储，以及 rand_weight_m_、rand_bias_m_ 这类手术过程中产生的随机量，再加上 gamma、power、crate、mu、std、iter_stop_ 等调节稀疏行为的超参。

搭建阶段首先从 inner_product_param 读取输出单元数和偏置开关，确定 N_。再根据用户指定的切分轴算出轴之后所有元素的累计量得到 K_，也就是每个样本压平后的长度。

若参数尚未创建，则以 N_×K_ 的形状分配权重，以 1×N_ 的形状分配偏置，并用配置的填充器写入初值，所有参数的梯度传播标记设为开启。随后进入动态稀疏准备，读取 cinner_product_param 的配置。带偏置且已有两组参数时，Blob 列表扩容到四组，为权重和偏置分别新建同形掩码并用对应掩码填充器填充；不带偏置时扩容到两组，仅为权重新建掩码。随后把 weight_tmp_ 与 bias_tmp_ 重塑为参数同形，最后把 gamma、power、c_rate、iter_stop_ 写入成员，mu 与 std 清零，完成初始化。

 81         const vector<Blob<Dtype>*>& top) {

 82     // 获取维度

 83     const int axis = bottom[0]->CanonicalAxisIndex(

 84         this->layer_param_.inner_product_param().axis());

 85     const int new_K = bottom[0]->count(axis);

 86     CHECK_EQ(K_, new_K)

 87         << "Input size incompatible with inner product parameters.";

 88     // 第一个轴的维度与内积无关，其总数为 M_

 89     

 90     M_ = bottom[0]->count(0, axis);

 91     // 输出数据的形状是输入数据平坦化后的形状（丢弃了一些特征）

 92     // 需要使用 num_output 这个维度

 93     vector<int> top_shape = bottom[0]->shape();

 94     top_shape.resize(axis + 1);

 95     top_shape[axis] = N_;

 96     top[0]->Reshape(top_shape);

 97     // 初始化偏置系数

101         caffe_set(M_, Dtype(1), bias_multiplier_.mutable_cpu_data());

102     }

重塑时先校验本次输入在切分轴之后的元素总数是否与之前算出的 K_ 匹配，再用 0 到轴前的累计计数得到 M_。输出张量的构造保留输入前段结构，仅把轴位置替换为 N_，完成维度映射。若启用偏置，则把 bias_multiplier_ 调整为 M_ 并全部置 1，为广播求和做准备。

CPU 前向入口取出权重指针、权重掩码指针和临时权重缓冲，偏置开启时同步取出偏置指针、偏置掩码指针和临时偏置缓冲，为后续带掩码的内积计算提供就绪的指针。

总体来看，该实现在保留经典内积语义的基础上，通过掩码 Blob 与手术相关超参，为剪枝与稀疏化提供了可插拔的扩展点。
