物联网节点通过搭载的传感器采集数据，可原样发送给其他机器，也可在本地做简单处理后再转发。传感器分辨率越高，产生的数据量越大；采用无线传输时，丢包风险必须重点防范。

相比个人电脑和服务器，物联网设备所用CPU功耗更低、高速内存也更少。因此在规划数据处理架构时，要明确哪些计算留在终端，哪些交给接收端。例如在微控制器mbed上搭载语音识别，即使云端部署了识别服务，也必须严格把握波形提取的时机与质量，否则因规格不符而无法正常处理。

# 探索脑功能

与机器人研究并行的另一条线是对脑功能的解析。研究人员在开发和应用新技术，以厘清脑细胞与复杂神经回路如何高速互动，这有助于理解脑功能与行为的关联机制。

2013年，美国总统奥巴马宣布启动“脑计划”Brain Research through Advancing Innovative Neurotechnologies Initiative，由美国国立卫生研究院主导。

2014年，日本理化学研究所脑科学综合研究中心启动日本脑计划 Brain/MINDS，使用整合性神经技术绘制有助于疾病研究的脑图谱。

将生物体内部要素的互动与功能进行测量、分析后再迁移到人工制品的做法由来已久。人脑仅消耗约30瓦的能量，相当于一盏灯泡，却能达到媲美超级计算机的运算速度，因此脑功能研究为节能计算提供了重要启示，见图14-8。

# 图14-8 机器人和脑神经研究

近期，日本电气通信大学山崎助理教授团队公布了基于小脑模型的计算机仿真成果。

脑研究常让人联想到意识、记忆、思考等与大脑相关的话题，而小脑的研究深度反倒更高。小脑受损会导致运动失调并丧失运动技能学习能力，说明其主要负责运动协调与技能习得。启动新动作或进行精细操作时，小脑会校正来自大脑的指令；在重复性简单任务中，小脑可自主支配身体。

关于小脑的工作机制，最具说服力的假说是小脑构成了一个关于身体的内部模型，该模型根据大脑指令和外界输入通过反馈不断更新，见图14-9。

# 小脑模型

小脑体积约占全脑的10%，却集中了全脑约80%的神经元。其神经元主要由两个输入系统——背景信号与标记信号——以及一个输出系统构成，并未形成复杂回路。

背景信号是一种运动相关信号，经脑桥核神经元的苔状纤维传递至颗粒细胞和小脑核。标记信号则经下橄榄核的爬行纤维投射至浦肯野细胞，对其产生强兴奋。随后小脑核将信号输出。模拟这种结构网络可在计算机上再现动物眼动，见图14-10 与 图14-11。

# 通过自主学习来理解概念：元认知

小脑主导运动功能，大脑负责更高阶的复杂功能，因此完整解析大脑需要更长时间。

在既往人工智能研究中，研究者一直在让机器理解词语含义。本体和语义网等语义网络的表达方法主要用于解决符号接地问题。

然而解释“石头”时往往仍需用“石头”本身作说明，见小贴士。循环定义让机器难以真正掌握含义，因此自主学习成为掌握词义的关键。

# 小贴士 在解释“石头”的含义时，不可避免地需要用到“石头”
按体积相对大小，石头可称岩石或砂粒，却缺乏对石头本身的独立表述。若用“由矿物质构成之物”来定义，则同样适用于地球。

# □ 元认知
人类通过自主学习理解概念是自然行为。对自身思维与行为进行客观把握即为元认知。

机器的元认知能力在2010年后仍不明确，但在工业机器人领域，PFN等公司已开发出基于深度学习的程序，让机器人自行学会抓取装配零件。零先验条件下学习8小时后，抓取效率即可达到人类水平。

随着机器具备元认知能力，它们能依据情境与上下文理解词义，逐渐演变为具备类人沟通能力的符号创新系统。

未来若能解析并在计算机上模拟更多脑功能，机器产生智能与意识也并非不可能，见图14-13 与 小贴士。
