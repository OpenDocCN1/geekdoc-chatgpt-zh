# 让模型学会“该看什么、不看什么”，再学会“多感官共鸣”

在长文本和多模态时代，Agent 的核心能力不再是塞进更多信息，而是把有限的算力和注意力投到真正值钱的地方。

### 四个关键角色决定信息流的生死

**评分器 Scorer，既是守门人。** 流水线最前头的工作站，不需要读懂故事，只做价值计价。常见做法是用一个轻量小模型或者统计规则，给每一个 Token、甚至整句话贴上一个分数，分数越高代表含金量越高。

**策略路由 Router，负责分流。** 拿到分数后做资源分配：高价值的核心数据原样保留，背景类信息做语义压缩降噪，纯噪音直接丢弃，不进后端。

**重排序器 Reranker，兼任拼装工。** 压缩后信息会变得碎片化，它按逻辑而非原始顺序重新拼接上下文，并在必要处插入特殊标记，提示模型“这里被压缩过，请注意上下文连续性”。

**质量探针 Quality Probe，发挥质检员作用。** 在把 Prompt 交给昂贵大模型之前，先算一次压缩后文本的语义完整性，判断是否删过头，形成闭环反馈。

注意力聚焦并不是一次性截断上下文，而是一条可管控的信息加工流水线。靠“评分、分流、重排、质检”构成的闭环，把有限注意力精准投向高价值信息，在成本、效果和语义完整度之间做工程化权衡。

### 4.1.2 精准打分的双重逻辑

要把注意力聚焦做到位，Agent 必须先建起一套严谨的评估体系。本质上是在回答两个老问题：凭什么删，删多少。

工程上很少单指标决策，多采用双重校验来构建打分策略。

第一重是基于惊奇度的静态筛查。依据香农信息论，信息量与事件概率成反比。在大模型内部这体现为困惑度 Perplexity，简称 PPL。模型对 the、is、的 这类高频停用词预测性极强，熵值很低；而专有名词、具体数值、反常识描述会让模型困惑升高，正说明它们承载了高价值信息。在日志分析或无明确查询的长文档摘要里，找“惊奇点”往往能抓住关键细节。

第二重是基于相关性的动态锚定。当用户查询意图明确时，信息价值不再绝对，而是相对查询而言。做法是计算查询向量与上下文各片段向量的相似度。类似图书馆检索，只保留与当前课题相关的书架。

有了分数，下一步是选压缩算子。最激进的是剪枝 Pruning，直接切掉低分 Token。压缩比可达 5 倍乃至 20 倍，但风险极高，容易切断长距离逻辑依赖，让模型语义失联。更温和的是摘要 Summarization，用一个辅助模型把冗长段落重写成精炼句子，语义保留但会增加延迟。特定领域还能把文本转成人类不可读、机器可用的密集向量，实现百倍级压缩。

这个过程常被称作上下文蒸馏 Context Distillery。流程从双重评分出发，经算子选择，再由预算管理器自适应调节压缩强度。

领先的 Agent 已不再用固定压缩率。它们借鉴视频流媒体的自适应循环 Adaptive Loop：内置一个预算管理器，根据任务复杂度动态下发压缩参数。对简单的寒暄大胆压缩省钱，对复杂的代码审计则小心保留每个字符。

### 4.1.3 工程落地，常有三条路线

对上下文“提纯”已演化出三条差异明显的技术路线，分别对应中间件、存储和模型底层。

第一条是中间件模式，典型代表是微软的 Lingua。思路是分级处理：先用 Llama-2-7b 这类小而便宜的模型做看门人，计算 Prompt 各 Token 的信息熵，剔除低价值部分，再把精华送入昂贵的 GPT-4。在 RAG 场景下效果突出，企业知识库召回常带大量噪音，中间加一层 Lingua 能以极小延迟换来约 80% 的 Token 节省，同时因去噪提升最终答案准确率。

第二条是存储优化模式，代表是 Anthropic 的 Prompt Caching。针对 SOP 强的垂直 Agent，例如法律助手每次都要加载同一部法典。重复计算静态内容的注意力矩阵是浪费。Prompt Caching 把公共前缀的 KV Cache 服务端缓存，后续请求前缀一致时直接复用。长文档对话的首字延迟可降 80%，也让“全量背景知识在线”在经济上可行。

第三条是原生架构模式，代表是 DeepSeek-V3 的多头潜在注意力 MLA。这是一次底层革新。传统注意力下 KV Cache 随长度线性甚至指数增长，MLA 在架构层面极致压缩缓存。于是应用层甚至无需压缩，直接喂入上百份财报，成本极低且信息保真度接近 100%。这标志着全量信息分析时代的到来。

除此之外，学界 2024 年提出的 System 2 Attention 提供了新视角。传统注意力是直觉式 System 1，基于统计。System 2 Attention 让模型有意识审视上下文，显式决定忽略哪部分。虽慢，但在含误导信息 Sycophancy 的复杂推理里鲁棒性惊人。

使用时要警惕两类工程黑洞。

其一是过度压缩导致的逻辑断裂。剪枝容易“杀红眼”，把 Therefore、However 等连接词或 It、He 等指代词删掉。对人类只是读起来别扭，对模型则是因果链崩塌。在思维链场景应禁用 Token 级剪枝，改用句子级或段落级保留。

其二是位置偏差 Position Bias。早期模型对 Prompt 头尾记忆好，中间易遗忘。简单截断中间会加剧遗忘。成熟做法是 U 型保留策略：强制保留 System Prompt 的头部约束和 User Query 的尾部指令，只对中间历史做强压缩。

总体看，注意力聚焦不是万能药。它适合“大海捞针”场景，比如从数百页合同里找风险条款，或基于数千文件理解代码架构，信息密度极不均匀，压缩收益远大于损失。

但对“全息关联”场景如密码学分析、复杂数学证明，每个符号都可能改写结果，任何有损压缩都危险。医疗诊断、安全审计等对召回率要求极高的领域也应谨慎，漏看的代价远高于多看。

### 4.1.4 演化与组合：从截断到原生

注意力聚焦是 Agent 的预处理中间件。工程目标已从单纯缩短输入转向提升信息密度。发展轨迹是滑动窗口 → 语义压缩 → 原生优化。

#### 1. 演化路径：从粗暴截断到架构内化

- 滑动窗口 Sliding Window：原始阶段，用 FIFO 或首尾保留。痛点是灾难性遗忘，早期指令或中间逻辑链被丢弃，Agent 呈现金鱼记忆式短视。
- 语义压缩 Semantic Compression：中间件阶段，Prompt 进入 LLM 前，先用轻量模型算困惑度或互信息，保留高惊奇度 Token，剔除废话，实现信噪比的工程化控制。
- 原生架构 Native Architecture：底层阶段，不靠外部工具压缩，而是革新 Transformer。例如低秩投影大幅降低 KV Cache 显存。实现全量即聚焦，模型本身能以极低成本处理百万级 Token，外部压缩逐渐内化为本能。

#### 2. 模式组合示例

注意力聚焦作为前置过滤器，与其他模式结合可大幅提升效率。

注意力聚焦与 RAG 组合形成漏斗形 RAG。传统 RAG 为省 Token 只取 Top5，容易漏关键；检索 Top100 又会爆窗口且噪音大。引入注意力聚焦可在检索后对候选做语义筛选与压缩，用少量算力换取质量，缓解召回数与窗口大小的矛盾。具体做法：

### 4.1.5 设计哲学：主动忽视

注意力聚焦是信息爆炸时代的生存法则。它传递的核心哲学很简单：智能不在于处理所有信息，而在于识别关键信息。

随着上下文窗口向亿级、十亿级演进，注意力聚焦将从优化手段变为基础能力。设计 Agent 时，不要以“能记住多少”自豪，而要以“能精简多少”为傲。优秀的感知层应像人脑，主动过滤掉 99% 的噪声，只在 1% 的关键信号上迸发智慧火花。

## 4.2 多模态融合模式

> “人类从不只用一种感官理解世界，AI 也不应该。真正的理解，是视觉、听觉与语言在思维空间中的共鸣。” ——李飞飞

想象一个具联觉 Synesthesia 的大脑。看到“苹果”图像时，同时激活甜味、清脆声和水果概念。传统 AI 割裂成 CV 和 NLP 两条线，多模态融合要打破模态孤岛，不是简单 Concatenation，而是建一个统一语义场 Unified Semantic Field。像素向量与 Token 向量在此可互相转化、互相解释，成为同一种思维语言。

### 4.2.1 架构：统一语义场

多模态融合既是算法问题，更是数据流对齐 Alignment 问题。典型架构像漏斗，把物理信号收敛为统一语义表征。图4-5 展示实现流程。

漏斗中除输入输出层外，三大组件关键：

- 编码层：各独立编码器是 Agent 的不同感官。视觉编码器如 ViT 负责“看”，音频编码器如 Whisper 负责“听”，把波形像素转为高维特征。
- 对齐层 Alignment Layer：融合灵魂，解决语义鸿沟，让像素里的猫形和文本里的 cat 指向同一实体。
- 融合层：决定融合时机。可像 CLIP 那样各自解码后在输出握手，也可像 Gemini 那样在深层网络逐层交织。

### 4.2.2 核心机制：三种对齐思路

工业界主流有三种对齐机制。

- 对比学习对齐 Contrastive Learning Alignment，以 CLIP 为代表。隐喻是磁铁，通过大量图文配对训练让匹配向量靠近、不匹配推远。高效适合检索分类，但缺乏生成描述能力。
- 生成式对齐 Generative Alignment，以 LLaVA 为代表。隐喻是翻译官，用投影层 Projector 把视觉特征转成模型可理解的 Token Embedding。对模型而言图像是另一种语言，赋予“看图说话”能力，是当前主流构建思路。
- 交叉注意力对齐 Cross-Attention Alignment，以 Flamingo 为代表。隐喻是拉链，不把图像转成 Token，而是保持视觉特征独立，在每层插入交叉注意力门控，生成时可随时查询视觉细节。适合高分辨率图像和长视频。

### 4.2.3 工程实践：从拼接到原生

我们正见证从拼接式到原生式的演进。

早期如 VQA、ViLBERT 是拼接式：一个指挥官模型外加独立视觉模型 Detection、Segmentation，通过 Prompt 调用。灵活但慢且割裂。

当前如 GPT-4V、Gemini 是原生式。尤其是 Gemini，预训练阶段即多模态，视觉与语言生长在同一神经树上，无需额外对齐层。带来惊人理解力和推理速度，但训练门槛大幅提高。
