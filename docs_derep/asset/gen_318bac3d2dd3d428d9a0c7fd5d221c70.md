# 前言

**为何写下这本书**
2022 年 ChatGPT 横空出世后，大语言模型的发展浪潮席卷全球，AI 竞争格局被彻底改写。短短两年间，GPT、Llama、Claude 等海外模型与 Qwen、GLM、Kimi、MiniMax 等国内模型展开激烈角逐。DeepSeek 从首代产品起步，到二代在中文开源圈追平 Qwen，再到 V3 与 R1 引发全球关注，复刻了 ChatGPT 时代的爆发势能，展现出强劲的技术创新力。

即便如此，通用人工智能的实现仍在路上。当前主流技术多聚焦于特定任务，距离真正的“智能”尚有差距。行业迭代加速，挑战与机遇并存。

在这一背景下，深入剖析领先模型的技术原理，既能把握 AI 前沿动向，也能为职业发展提供关键支持。无论是算法研发、产品设计还是战略规划，对新技术的透彻理解都是核心竞争力。同时，大模型的落地潜力正从教育、医疗延伸到金融、娱乐等诸多领域。

### 1.1 DeepSeek 的模型介绍
DeepSeek 是由杭州深度求索人工智能基础技术研究有限公司开发的一系列 AI 模型的统称，旨在通过深度学习探索未知领域。其核心是强大的语言模型，可理解自然语言并生成高质量文本，广泛应用于问答、推理、代码生成、数学任务和视觉语言处理等。

**1.DeepSeek V3**
通用型大模型，采用 MoE 架构，总参数 6710 亿，推理时仅激活 370 亿参数，显著降低计算成本。在知识问答、长文本处理、代码生成和数学能力上表现突出，尤其在数学竞赛与长文本任务中超越多项开源与闭源模型。训练成本约 557.6 万美元，体现了经济性。

**2.DeepSeek R1**
专注复杂推理任务的模型，采用强化学习训练，舍弃了传统监督微调 SFT 步骤。在数学、代码和逻辑推理上表现优异，在 AIME 2024 中通过率达 79.8%，超越 OpenAI o1 模型。推理过程包含大量反思与验证，思维链长度可达数万字，适用于科研、工程计算与复杂问题求解。

**3.DeepSeek Math**
专注数学任务的模型，参数仅 70 亿，却在数学基准榜单上超过多款 300 亿至 700 亿参数的开源模型。基于 DeepSeek Coder V1.5 初始化，并引入群组相对策略优化 GRPO 技术，提升泛化与推理性能。在中英文数学基准上表现优异，逼近 GPT-4 水平。

**4.DeepSeek VL2**
MoE 架构的视觉语言模型，支持最高 1152×1152 分辨率图像处理及极端长宽比。在视觉问答、光学字符识别 OCR、文档表格图表理解及视觉定位等任务中表现突出。采用多头潜在注意力 MLA 与 MoE 架构，降低训练与推理成本的同时提升性能。

**5.DeepSeek Coder**
专注代码生成与编程任务的模型，基于 Transformer 与 MoE 架构。在代码补全、代码生成与编程竞赛中表现优异，支持多种编程语言与复杂逻辑推理。训练数据覆盖广泛代码库与编程任务，在编程领域应用潜力巨大。

**6.Janus**
多模态模型，专注跨模态任务处理，如图像生成文本、文本生成图像等。融合视觉与语言处理能力，可实现复杂的多模态推理与生成，适用于创意设计、内容生成等领域。

### 1.2 DeepSeek 的重要突破

DeepSeek 在自然语言处理 NLP 与强化学习 RL 领域做出突出贡献。

**1.2.1 为开源做贡献**
DeepSeek 自创立以来深耕开源社区，在 Hugging Face 上开源了 DeepSeek V3、DeepSeek R1、DeepSeek Coder、DeepSeek Math、DeepSeek VL 等模型，涵盖语言、推理、代码、数学、多模态等多类方向，且每个模型均有多尺寸版本。以 DeepSeek VL2 为例，开源了 VL2、VL2-tiny、VL2-small 三种规格，适配不同设备与场景。

在推动技术发展的同时，DeepSeek 还针对每代版本发布了详尽技术报告。在大模型普遍“黑盒化”的当下，这一透明做法为技术发展、教育普及与行业解读树立了新标杆。

开源不仅是技术共享，更是价值观输出。DeepSeek 以“热爱与好奇心”为人才选拔标准，激发科研探索热情，呼应“兴趣驱动创新”的理念。

**1.破除科技垄断**
通过开源策略，DeepSeek 打破闭源巨头的技术壁垒，推动 AI 从“寡头垄断”转向“多元协作”。例如其开源模型被华为、百度等企业采用，加速技术普惠与产业落地。此模式不仅挑战 OpenAI 等企业的商业垄断，也在技术伦理与安全性上提供了更优解，为全球 AI 治理贡献中国方案。

**2.推动大模型技术发展**
大模型的复杂性导致其内部机制难以完全理解，形成“黑盒”阻碍。DeepSeek 通过发布详尽技术报告公开设计思路、训练方法、性能评估与改进方向，为研究者与开发者提供宝贵参考。透明化促进迭代创新，帮助社区更好理解模型局限，推动更高效可靠的解决方案。

**3.激发本土创新信心**
DeepSeek 的成功印证了中国在顶尖人才培养与原创创新上的潜力。团队主要由国内高校毕业生构成，依托扎实人才储备与产业闭环实现技术到应用的反哺。正如《人民日报》评论文章指出，DeepSeek 的诞生为审视中国创新模式提供了生动样本，展现从“跟随”到“引领”的决心。

**4.助力教育和学术研究**
对教育与学术界而言，DeepSeek 的技术报告是丰富素材。学生与研究人员可通过报告深入了解大模型核心细节，从架构到训练策略，从数据预处理到性能优化。开放资源降低学习门槛，促进人才培养。

**5.建立行业信任**
在医疗、金融、法律等敏感领域，模型透明性与可解释性至关重要。DeepSeek 通过公布工作原理与性能表现，增强用户信任，也为行业标准制定提供参考。

**6.对“黑盒”现象的突破**
DeepSeek 的开源与透明是对大模型“黑盒”的一次重要突破。通过详细解读与公开评估数据，展示开放态度推动技术进步，为其他机构树立榜样，有助于消除公众疑虑。
