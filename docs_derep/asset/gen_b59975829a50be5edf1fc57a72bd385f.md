先来看一类典型的加减消元。由 $a + b = 10$ 可得 $a = 10 - b$，把这个关系带入 $a - b = 2$ 得到 $(10 - b) - b = 2$，化简为 $10 - 2b = 2$，再得 $8 = 2b$，于是 $b = 4$。回代到 $a = 10 - b$ 中，$a = 10 - 4 = 6$。最终解是 $a = 6$，$b = 4$，对应选项 A。

为了巩固同类解法，再练两组结构一致的题。

题目1：
已知 $x$ 和 $y$ 满足 $x + y = 15$ 和 $x - y = 3$，则 $x$ 和 $y$ 分别为（  ）。
A. $x = 9, y = 6$  B. $x = 7, y = 8$  C. $x = 10, y = 5$  D. $x = 8, y = 7$

从 $x + y = 15$ 得 $x = 15 - y$，代入 $x - y = 3$ 得 $(15 - y) - y = 3$，即 $15 - 2y = 3$，$12 = 2y$，$y = 6$。再回带 $x = 15 - 6 = 9$。答案为 A：$x = 9, y = 6$。

题目2：
已知 $m$ 和 $n$ 满足 $m + n = 20$ 和 $m - n = 4$，则 $m$ 和 $n$ 分别为（  ）。
A. $m = 12, n = 8$  B. $m = 14, n = 6$  C. $m = 10, n = 10$  D. $m = 16, n = 4$

由 $m + n = 20$ 得 $m = 20 - n$，代入 $m - n = 4$ 得 $(20 - n) - n = 4$，即 $20 - 2n = 4$，$16 = 2n$，$n = 8$。回代 $m = 20 - 8 = 12$。答案为 A：$m = 12, n = 8$。

下面是对一道成语辨析题的拆解：

题目：以下句子中，哪个成语使用得当？

- A. 小明对这次考试成绩胸有成竹，因为他已经复习得非常充分了。
- B. 这次的晚会真是人山人海，几乎每个角落都空无一人。
- C. 老师对小华的批评苦口婆心，但小华却左耳进右耳出。
- D. 妈妈做的菜太好吃了，我简直吃了一大桶。

正确答案：C

解析：
A里“胸有成竹”本义是行事前考虑周全，用来表达对考试的信心在语义上可以成立，但不是最精准的选项。
B里“人山人海”本指人极多，后半句却说“几乎每个角落都空无一人”，自相矛盾，误用。
C里“苦口婆心”指耐心反复劝诫，用来形容老师的批评恰当。
D里“一大桶”并非成语，且题干要求辨成语，本身不符合要求。

因此选C。你原先选D，D中并不含成语，自然错误。

> 问：
我是一名初二的学生，最近物理学习遇到不少困难，我把错题整理好了，请帮我解析并出一些相似题巩固。错题如下：（1）物体在做匀速直线运动时，速度的大小（），方向（）。我填成了“增加”“变化”。（2）气体的压强与温度的关系是（），即温度越高，气体的压强（）。我填成了“成反比”“增加”。

1.物体在做匀速直线运动时，速度的大小（），方向（）。
你的错误答案：“增加”，“变化”
正确答案：“不变”，“不变”
解析：
匀速直线运动的定义是沿直线以恒定速度前进。速度大小不随时间增大也不减小，运动方向始终沿同一条直线。因此大小不变，方向也不变。

类似题目：
1.物体做匀速圆周运动时，速度的大小（），方向（）。
- 可能的错误答案：增加，变化
- 正确答案：不变，变化
2.一个物体做匀速直线运动时，所受合力的方向和大小是（）的。
- 可能的错误答案：不变
- 正确答案：不变

2.气体的压强与温度的关系是（），即温度越高，气体的压强（）。
你的错误答案：“成反比”，“增加”
正确答案：“成正比”，“增加”
解析：
在体积一定时，温度升高分子运动更剧烈，碰撞更频繁，压强随之增大。查理定律也表明压强与热力学温度正相关，所以是成正比，压强随温度升高而增大。

类似题目：
1.气体的体积与温度的关系是（），即温度越高，气体的体积（）。
- 可能的错误答案：成反比，增加
- 正确答案：成正比，增加
2.在恒温条件下，气体的压强与体积的关系是（）。
- 可能的错误答案：成正比
- 正确答案：成反比（玻意耳定律）

> 问：
请根据以下例题，生成相似类型的初级难度选择题1道。例题：抽取扑克牌，从一副标准的52张扑克牌中随机抽取一张牌，求以下事件发生的概率：（1）抽到一张红心的概率；（2）抽到一张皇后的概率。

题目：从一副标准的52张（不包括大小王）扑克牌中随机抽取一张牌，求以下事件发生的概率：
- A. 抽到一张黑色的概率
- B. 抽到一张A的概率
- C. 抽到一张既是红色又是偶数的概率
- D. 抽到一张既不是K也不是Q的概率

现在，请选择以下哪个选项的概率值最大：
- A. A选项的概率最大
- B. B选项的概率最大
- C. C选项的概率最大
- D. D选项的概率最大
答案：D
解析：
A选项：黑色牌26张，概率$\frac{26}{52}=\frac12$。
B选项：A牌4张，概率$\frac4{52}=\frac1{13}$。
C选项：红色偶数牌4张，概率$\frac4{52}=\frac1{13}$。
D选项：非K非Q的牌$52-8=44$张，概率$1-\frac8{52}=\frac{44}{52}=\frac{11}{13}$。
比较可知$\frac{11}{13}$最大，故选D。
