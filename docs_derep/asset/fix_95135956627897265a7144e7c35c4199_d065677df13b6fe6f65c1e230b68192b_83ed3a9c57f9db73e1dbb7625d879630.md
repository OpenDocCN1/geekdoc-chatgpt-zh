### 9.5.3 RRT 快速探索
RRT，即 Rapidly-exploring Random Tree，是一种基于树结构的规划方法。它在自由空间随机采样，逐步连接采样点扩展树结构，从而搜索起点到目标的可行路径。其核心理念是用随机采样快速覆盖空间，提升搜索效率并降低耗时。

（1）文件 rrt.py 实现了 RRT 算法，在给定地图中寻找起点到目标的路径。包含生成随机点、构建 RRT 图、搜索与可视化等函数。调用 find_path_RRT() 可在指定地图中完成规划并返回路径与 RRT 图。

[PRE29][PRE30][PRE31][PRE32][PRE33]

（2）文件 rrt_single.py 实现单棵 RRT 规划，具备快速生成随机树、节点连接与路径搜索能力。算法在指定地图上随机采样并逐步建立连接，最终输出可行路径。用户可在图形界面选择起点与终点，实时观看规划过程与结果。

[PRE34][PRE35][PRE36][PRE37][PRE38][PRE39]

（3）文件 autonomous_rrt.py 是一个基于 RRT 的自主探索器，主要功能如下。

◎ 接收 /odom 与 /map 获取里程计与地图信息。
◎ 使用 RRT 规划路径，并在 RViz 中可视化。
◎ 通过 /cmd_vel 推送速度指令，沿规划路径驱动机器人。
◎ 支持选择起点与终点进行规划。
◎ 实时显示地图并以 ROS Marker 形式推送路径点供 RViz 展示。

### 10.2.1 RL 环境构成
项目使用深度强化学习训练，其环境包含以下组件。

◎ 动作空间：描述 Agent 可执行的动作。假设股票池有 N 只，使用列表 [a[1], a[2], …, a[N]] 表示各股票权重，其中每个 a[i]∈(-1,1) 且满足 a[1]+a[2]+…+a[N]=1。例如苹果公司权重 10% 可表示为 [0.1,…]。
◎ 奖励函数：作为学习反馈，奖励函数 r(s,a,s') 定义为从状态 s 执行动作 a 进入 s' 时组合价值变化，即 r(s,a,s')=v'−v，其中 v' 与 v 分别为状态 s' 与 s 的组合价值。
◎ 状态空间：描述 Agent 接收的观测值。交易代理如同人类交易员，在交易前分析多类市场特征以学习有效行为。
◎ 环境数据：环境采用道琼斯工业平均指数 DJIA 成分股作为标的，数据来自 Yahoo Finance API，包含开盘价、最高价、最低价、收盘价与成交量等信息。
