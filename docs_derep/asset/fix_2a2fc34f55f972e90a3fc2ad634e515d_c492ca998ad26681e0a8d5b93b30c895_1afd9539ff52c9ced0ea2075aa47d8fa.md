LCS 状态转移速览

在比较到 x 的第 i-1 个字符与 y 的第 j-1 个字符时，递推关系可以写成：
if (x[i-1] == y[j-1]) {
v[i][j] = v[i-1][j-1] + 1;
} else {
v[i][j] = max(v[i-1][j], v[i][j-1]);
}

边界约定令 v[0][j]=0 和 v[i][0]=0，表示空串与任意串的最长公共子序列长度为 0。最终结果落在 v[m][n]，其中 m 为 x 的长度、n 为 y 的长度。

实现要点
先建表：
vector<vector<int>> v(m+1, vector<int>(n+1, 0));
for (int i = 1; i <= m; i++) {
for (int j = 1; j <= n; j++) {
if (x[i-1] == y[j-1]) {
v[i][j] = v[i-1][j-1] + 1;
} else {
v[i][j] = max(v[i-1][j], v[i][j-1]);
}
}
}
表格 v 记录了全部子问题的最优值。字符相等时沿左上递推并累加 1；字符不等时只能舍弃 x 的当前位或 y 的当前位，取两者较大值。

二、旋转串快速判定
判断旋转是否成立的思路是：
1. 构造 x+x。
2. 检查 y 是否完整包含于 x+x 并且长度一致。

若 y 确为 x 的某一种旋转，则必然以连续段的形式出现在 x+x 中。拼接串保留了 x 的全部旋转形态。例如 x="abc"，x+x="abcabc"，其中可找到 "bca" 与 "cab"。实现上用 f(x+x, y) 检验包含关系，再配合长度相等即可判定。

三、vector 下标越界的隐患
vector 对下标的合法范围有严格限制，越界访问会触发运行时异常导致程序退出。
vector<int> v(10, 0); // 合法下标 0~9
v[10] = 1; // 越界，异常终止

在本题里，若把 v[m][n] 写成 v[n][m]，当 m≠n 时就会触及未分配区域产生越界。结论是二维数组下标写错很容易造成非正常退出。
