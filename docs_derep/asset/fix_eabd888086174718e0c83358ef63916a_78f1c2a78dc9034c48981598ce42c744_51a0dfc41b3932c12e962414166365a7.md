# MindIE Service TLS 配置与部署实操

## 一、TLS 相关参数概览

业务面 RESTful 接口
- tlsCaFile —— 业务面 RESTful 接口所用 CA 证书的清单，相关文件由用户自行准备，安全保管责任由使用者承担。
- tlsCert —— 业务面 RESTful 接口的服务端证书，文件由用户提供，安全由用户负责。
- tlsPk —— 业务面 RESTful 接口的服务端证书私钥，文件由用户提供并负责安全，建议采用加密后的私钥存储。
- tlsCrlFiles —— 业务面 RESTful 接口使用的证书吊销列表清单，文件由用户提供，安全由用户自行把控。

管理面 RESTful 接口
- managementTlsCaFile —— 管理面 RESTful 接口的 CA 证书清单，由用户自行提供并承担安全责任。
- managementTlsCert —— 管理面 RESTful 接口的服务端证书，由用户自行提供并负责安全。
- managementTlsPk —— 管理面 RESTful 接口的服务端证书私钥，由用户自行提供并负责安全，建议使用加密形式。
- managementTlsCrlFiles —— 管理面 RESTful 接口的吊销列表清单，由用户自行提供，安全由用户负责。

PD 分离场景节点间通信
- interCommTlsCaFiles —— PD 分离场景下 PD 节点互通所用的 CA 证书清单，文件由用户提供，安全由用户保管。
- interCommTlsCert —— PD 分离场景下 PD 节点通信的服务端证书，由用户提供并负责安全。
- interCommPk —— PD 分离场景下 PD 节点通信的服务端证书私钥，由用户提供并负责安全，建议使用加密私钥。
- interCommTlsCrlFiles —— PD 分离场景下 PD 节点通信的吊销列表清单，由用户提供，安全由用户自行保障。

多机场景主从节点通信
- interNodeTlsCaFiles —— 多机部署时主从节点通信的 CA 证书清单，由用户自行提供并负责安全。
- interNodeTlsCert —— 多机场景主从节点通信的服务端证书，由用户提供并负责安全。
- interNodeTlsPk —— 多机场景主从节点通信的服务端证书私钥，由用户提供并负责安全，建议采用加密存储。
- interNodeTlsCrlFiles —— 多机场景主从节点通信的吊销列表清单，由用户提供，安全由用户承担。

#### 8.3.3 使用场景

MindIE LLM 是华为昇腾面向大模型推理推出的组件，目标是在昇腾硬件上提供通用的大模型高性能推理能力。整体架构见图 8-9。
[PRE8]

图 8-9

LLM Manager：负责运行状态维护与任务调度，按策略对用户请求做批处理，统一管理 KV 缓存，并对外提供状态监控接口。
Text Generator：负责模型配置、初始化与加载、自回归推理及后处理，为 LLM Manager 提供统一的自回归推理入口，支持并行解码与插件化运行。
Modeling：提供深度定制的模块与内置模型，兼容 ATB Models 与 MindFormers 两种框架。内置模块包括 Attention、Embedding、ColumnLinear、RowLinear、MLP 等，支持权重在线 Tensor 切分加载。用户也可基于内置模块自行组网，编译优化后即可在昇腾 NPU 上加速推理。
MindIE LLM 适用于对大模型推理性能有较高要求的场景，例如自然语言处理、智能客服、文本生成等。其服务化形态如图 8-10 所示。

| 服务化框架 | MindIE LLM 子组件范围 | 能力说明 | 接口示意 | 接口形式 |
| :--- | :--- | :--- | :--- | :--- |
| MindIE Service | LLM Manager+TextGenerator+Modeling | LLM Manager+TextGenerator 提供完整的 CB+PA 自回归推理调度能力 | ITF 0.L1 | C++ API |
| Triton | LLM Manager+TextGenerator+Modeling | LLM Manager+TextGenerator 提供完整的 CB+PA 自回归推理调度能力 | ITF 0.L1 | C++ API |
| TGI | TextGenerator+Modeling | 提供 TextGenerator 前后处理+Modeling 推理能力 | ITF 0.G1 | Python API |
| vLLM | TextGenerator+Modeling | 提供 TextGenerator 前后处理+Modeling 推理能力 | ITF 0.G1 | Python API |
