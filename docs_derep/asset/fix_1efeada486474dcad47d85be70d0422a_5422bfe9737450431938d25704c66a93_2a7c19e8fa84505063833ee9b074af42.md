示例里通过 OpenAI 包装器完成了模型实例化，实际运行会报错。问题不在语法，而在于 DeepSeek 目前已不再提供传统的单字符串补全接口。

以 OpenAI 为参照，旧的补全接口路径通常是 /model/completion，对话接口则是 /model/chat/completion，过去可通过路径辨识服务类型。

现阶段 GPT-4、DeepSeek、Claude、Gemini 等主流模型均采用对话式交互，单字符串输入正被逐步弃用。厂商也不再在网关地址上做区分，比如 DeepSeek 的统一入口为 https://api.deepseek.com/v1。

因此面向对话型应用和需要持续交互的场景，更适合使用支持多轮 messages 的模型。这类模型以消息列表为单位工作，能保留上下文，并要求为每条消息标注角色如用户、助手。建议放弃最初的 completion 调用，统一改用 chat 模式传递 messages。下面演示如何创建聊天模型并调用，见代码清单4-26。

### 4.5.4 构建 LLMChain 工作流

上一节直接使用 invoke 调用，属于最简做法。实际工程中更推荐采用系统化方案，即 LLMChain。

Chain 是 LangChain 模块化设计的核心思路之一。它把提示、模型、工具等组件串成一条执行链路，降低复杂应用的实现成本，也提升了可维护性。

链式调用按逻辑顺序推进，涵盖大模型交互、工具调用、数据预处理等环节，既能理清流程，也能支撑更复杂的业务。

借助链，可以将输入采集、模板填充、模型推理串联。例如基础链先用 PromptTemplate 处理用户输入，再交给 LLM 处理。进阶时可组合多条链，或与检索、记忆等组件配合，搭建更复杂的逻辑。

LangChain 覆盖大模型操作、会话管理、文档向量化等场景，对应有 LLMChain、ConversationChain、StuffDocumentsChain 等多种链。下面先介绍 LLMChain 的搭建方式，见代码清单4-27。

from langchain import LLMChain

from langchain_openai import ChatOpenAI

from langchain_core.prompts.chat import ChatPromptTemplate

system_message_prompt = SystemMessagePromptTemplate.from_template(template=
    "# 角色 \n你是一个智能助手，名字叫聪聪")

human_message_prompt = HumanMessagePromptTemplate.from_template(template=
    "# 用户问题 \n{input}")

    system_message_prompt, human_message_prompt
])

    streaming=False,
)

# 创建大模型链
chain = LLMChain(

    prompt=chat_prompt_template,

from langchain import LLMChain
from typing import Any, Dict, List
from langchain_openai import ChatOpenAI
from langchain_core.outputs import LLMResult
from langchain_core.messages import BaseMessage
from langchain_core.callbacks import BaseCallbackHandler
from langchain_core.prompts.chat import ChatPromptTemplate
from langchain.prompts import HumanMessagePromptTemplate, SystemMessagePromptTemplate

class LoggingHandler(BaseCallbackHandler):
    def on_chat_model_start(
        self, serialized: Dict[str, Any], messages: List[List[BaseMessage]],
        **kwargs
    ) -> None:
        print("回调执行：on_chat_model_start")

    def on_llm_end(self, response: LLMResult, **kwargs) -> None:
        print(f"回调执行：on_llm_end, response: {response}")

    def on_chain_start(
        self, serialized: Dict[str, Any], inputs: Dict[str, Any], **kwargs
    ) -> None:
        print("回调执行：on_chain_start")

    def on_chain_end(self, outputs: Dict[str, Any], **kwargs) -> None:
        print(f"回调执行：on_chain_end, outputs: {outputs}")

system_message_prompt = SystemMessagePromptTemplate.from_template(template=
    "# 角色\n你是一个智能助手，名字叫聪聪")
human_message_prompt = HumanMessagePromptTemplate.from_template(template=
    "# 用户问题\n{input}")
chat_prompt_template = ChatPromptTemplate.from_messages(messages=[
    system_message_prompt, human_message_prompt
])

# 创建名为 model 的模型
model = ChatOpenAI(
    model="deepseek-chat",
    temperature=0.5,
    timeout=None,
    max_retries=3,
    api_key="",  # 配置你的 api_key
    base_url="https://api.deepseek.com",
    streaming=False,
)

# 创建大模型链
chain = LLMChain(
    llm=model,
    prompt=chat_prompt_template,
)

# 调用链
callbacks = [LoggingHandler()]
print(chain.invoke(input="你的名字叫什么？", config={"callbacks": callbacks}))
