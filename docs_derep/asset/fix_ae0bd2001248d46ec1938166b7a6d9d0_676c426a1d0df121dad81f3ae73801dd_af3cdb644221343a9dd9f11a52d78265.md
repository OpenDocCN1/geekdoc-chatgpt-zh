视觉处理技术概览

• 降噪平滑：抑制随机噪声干扰，常用手段为均值滤波与高斯滤波。
• 边缘定位与特征提取：捕捉目标轮廓及关键点，典型算子有 Sobel、Canny。
• 空间变换：实现缩放、旋转、镜像、透视校正等几何操作。
• 色彩空间切换：在 RGB、HSV、灰度等空间之间转换。
• 图像分割：区分前景与背景，如阈值分割等。

图像识别
面向语义理解与类别判定，系统能够自动判断画面中出现的对象及其属性。早期方案多依赖手工特征，例如 SIFT、HOG、LBP。随着深度学习发展，卷积神经网络 CNN 与 Vision Transformer ViT 等模型被广泛采用，实现了从特征学习到分类推理的端到端流程。识别能力已成为 AI 产品落地的关键支撑，人脸识别、车牌识别、文字检测与 OCR、缺陷检测等场景已实现规模化部署。

识别聚焦语义解读与目标推断，常见形式包括：

• 整体分类：判定整张图像的类别，如猫与狗的区分。
• 目标检测：在图像中定位目标并给出边框，如 YOLO 系列。
• 目标跟踪：在视频序列中持续跟随目标轨迹。
• 语义分割：逐像素标注场景构成。
• 人脸识别与验证：进行身份比对与特征提取。
• OCR 文字识别：提取图像中的文字内容。

def _on_open_image(self):
        """Open local image and display, scaling to fit the image area while keeping aspect ratio."""
        filetypes = [
            ("Image Files", "*.png *.jpg *.jpeg *.bmp *.gif *.tiff *.tif *.webp"),
            ("PNG", "*.png"),
            ("JPEG", "*.jpg *.jpeg"),
            ("Bitmap", "*.bmp"),
            ("GIF", "*.gif"),
            ("TIFF", "*.tif *.tiff"),
            ("WEBP", "*.webp"),
            ("All Files", "*.*"),
        ]
        filepath = filedialog.askopenfilename(
            title="Select an image",
            filetypes=filetypes,
        )
        if not filepath:
            return
        try:
            image = Image.open(filepath)
            # Convert to RGB to avoid mode issues (e.g., palette or RGBA)
            if image.mode not in ("RGB", "L"):
                image = image.convert("RGB")
            self.original_image = image
            self._current_image_path = filepath
            self._display_image_to_fit()
            self._set_window_subtitle(os.path.basename(filepath))
