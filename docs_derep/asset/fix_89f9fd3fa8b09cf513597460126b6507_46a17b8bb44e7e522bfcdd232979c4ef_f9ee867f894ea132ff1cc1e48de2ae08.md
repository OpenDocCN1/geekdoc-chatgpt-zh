大模型在人机协同的翻译场景里，凭借很强的适应性与对话能力，在以人类反馈为驱动的强化训练加持下，能够让译者依据项目要求或个人偏好与系统展开互动，持续拉升译文水平。初稿生成后，通过精细的提示词继续打磨，就是实现迭代式优化的典型做法。翻译实践总体可分为继承、改良、原创三类，其中改良型在源材质量偏低或文本复杂度偏高时尤为关键。译者需要在多套表述中挑出最合适的译法，也能在此基础上提出更优方案。实务中常见的改良手段有术语校准、文体调适、结构重组、歧义厘清和文化对接，配合 RAG 也能明显提升初译质量。这些做法凸显了译者在技术环境中保持主导并发挥创造性的作用。

二、RAG 辅助下的译文优化

RAG 的思路是将用户提供的知识拆分为文本块并向量化存入数据库，检索时把查询也向量化后按语义相似度召回相关上下文，再与提示词共同驱动模型生成。优势在于能调用词典、术语库、翻译记忆库、平行语料等外部资源，提升检索精度，最终输出更高质量译文。常见的本地实现方式有 AnythingLLM 与 CherryStudio，支持文件夹、网址、XML 站点地图、纯文本等多种导入方式，通过创建知识库即可实现 RAG 翻译。

2.3 信息的查询与验证

在翻译流程中，信息核查与语言转换同等重要。传统检索依赖搜索引擎的高级语法；生成式 AI 时代，大模型具备跨域检索能力，可通过提示词实现术语与背景知识的联网检索与生成。

## 3.AI 在译后阶段的应用

依托强大的自然语言理解能力，大模型可对译文进行深度分析，识别常见错误并生成多维度质量评估报告，需结合人工复核修正。

3.1 生成多维度译文质量评估报告

译后质量评估是核心环节。人工评估适合小批量但耗时且易受译者水平限制。机器评估更系统客观。王均松等（2024：136-138）将机器翻译质量评估分为人工评估、有参考译文的自动评估、无参考译文的自动评估，各有优劣。

为提升客观性，可采用“机器指标+人工框架”的提示词。机器指标选用 BLEU，用以衡量 N-gram 匹配度；人工框架选用 MQM，多维质量指标体系，错误分为准确性、流利度、术语、区域惯例、风格、真实性、格式、国际化八类，严重程度分轻微、重大、严重，最终得分=总分–译文扣分+原文扣分。（田朋，2020；杨博超、冷冰冰，2024）
