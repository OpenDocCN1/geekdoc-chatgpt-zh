[PRE0]

**输出示例：**

>> 生成的概述：机器学习是一种通过数据训练模型，使计算机能够自动识别模式的技术。

>> 基于 API 数据的生成内容：机器学习的最新应用数据在行业中的广泛应用。

>> 最终生成的详细内容：机器学习在金融、医疗等行业中广泛应用，例如自动化交易、疾病预测和个性化教育。

该片段里，`multi_step_chain` 把多个 LLM 实例和一个 API 模块按顺序串起来完成产出。先由模型生成概览，再通过 API 抓取外部数据，最后用细节描述收束整个流程。

把多个大模型与工具模块串进序列链，再叠加 API 调用、数据库查询或多模型协同，就能做出更丰富、层次更清晰的内容生产线。

### 5.3 路由链

路由链本质上是带决策能力的动态链条，靠条件判断和分支分流，让模型在运行时依据输入内容或上下文自动挑选合适的执行路径。相比走固定顺序的序列链，路由链能根据任务类型、输入特征或用户指令灵活切换路线，实现更具响应性的生成与处理。尤其在需要多分支、多条件处理的场景，比如客服里按问题类型走不同回复流程，或按数据特征动态选择处理方式时，效果非常明显。

下面会从原理到实操拆解路由链的搭建思路，手把手演示如何设计与配置，帮助你在真实项目里快速落地自适应处理。

#### 5.3.1 根据输入内容动态选择链路径

路由链的核心就是依据输入或条件即时挑选子链。LangChain 的 `RouterChain` 正是基于规则自动匹配子链执行的机制，能让内容生成和数据处理更灵活，特别适合需要按用户请求类型或内容特征走不同流程的场景，例如把咨询、投诉、建议区分开来分别处理。

##### 1. 定义条件判断函数

第一步是写一个路由判断函数，根据输入的文本特征返回不同的标识，从而决定走哪条处理线。

[PRE1]

这个函数会扫描输入是否包含“投诉”、“咨询”或“建议”等关键词，匹配到就返回对应标签；若都不命中，则 fallback 到“default”默认路径。

##### 2. 为不同路径定义各自的链

拿到路由标识后，需要为每条分支准备专门的子链。不同分支可以配不同的提示词和模型参数，确保输出贴合任务需求。

[PRE2]

这里为投诉、咨询、建议各准备了一套提示模板，比如“处理客户投诉”“处理客户咨询”等，保证每条链的产出风格和内容都对得上任务。

##### 3. 使用路由链根据条件选择子链

把判断函数和子链连起来，就能实现自动化分流。LangChain 里用 `RouterChain` 完成这一步，通过映射表把判断结果指向具体子链。

[PRE3]

`route_map` 把“complaint”“inquiry”等标签映射到对应的子链实例，`RouterChain` 会根据 `determine_route` 的返回值自动激活相应分支。

##### 4. 执行路由链任务并查看结果

跑通路由链后，只要喂入不同输入，就能看到自动分流和生成效果。

[PRE4]

**输出示例：**

>> 投诉处理结果：针对产品质量问题，建议客户与售后部门联系，并提供详细的损坏描述以便快速处理。

>> 咨询处理结果：该产品的保修期为一年，请在购买日期起计算。

>> 建议处理结果：增加支付选项的建议已收到，我们会将其反馈给产品部门以供参考。

>> 默认处理结果：您可以通过我们的客服热线或网站联系我们的客服团队。

从结果可见，输入带“投诉”会走投诉链，带“咨询”会走咨询链，系统实现了输入驱动的自动选择。

##### 5. 增强判断逻辑：添加更多条件和复杂判断

实战中往往需要更细的判断，比如组合条件或多级分层。可以把判断函数做得更复杂，让路由更贴合业务。

[PRE5]

**输出示例：**

>> 紧急投诉处理结果：请立即联系技术支持团队，并尽快更换故障产品。

丰富判断条件后，路由链能覆盖更多任务类型，让输出更符合复杂业务需求。

通过定义路由函数、配置多条子链并不断细化判断逻辑，就能让系统具备多路径处理的灵活性。

## 5.3.2 设置不同的模型和任务路径以适应复杂需求

面对复杂场景，单一模型很难兼顾。给不同任务配专属模型和路径，能显著提升效率，比如根据任务类型调整生成策略，甚至接入不同的 API 或数据源来支撑。

#### 1. 定义多任务场景中的模型实例

先准备几套模型，每个模型侧重不同任务。比如简答用低温度模型保证稳定，创意任务用高温度模型提升发挥。

[PRE6]

示例中 `llm_brief` 负责简洁回答，`llm_detailed` 负责深度展开，`llm_creative` 负责创意输出。这样分工让多任务场景下的生成更匹配需求。

#### 2. 定义不同任务路径的提示词模板

在路由链里为每个任务配专属提示词，能更精准地控制输出风格和范围。

[PRE7]

`prompt_brief` 引导模型做精简总结，`prompt_detailed` 鼓励给出完整解答，`prompt_creative` 则激发想象力。不同模板让同一模型在不同路径下产出差异化内容。

#### 3. 创建子链并映射至任务路径
借助前面准备好的模型和提示模板，为每个任务路径组装子链，再接入路由链进行映射。这样系统就能按任务类型自动调度最合适的生成链来执行。
