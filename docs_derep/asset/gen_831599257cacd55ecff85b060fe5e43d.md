历史反复表明，通用型技术想要在社会里实现真正意义上的普及，注定是一场持久战，而非一次性的投放。技术从实验室诞生到商业成熟，再到形成规模化产业，往往要拉开相当长的时距。瓦特对蒸汽机进行改良之后，真正意义上的商业化应用要等到八十年后；计算机在上世纪四十年代面世，却一直到八十年代末才进入社会化阶段并走向全球。通用技术在扩散过程中，必须在主干技术之外持续加码投入，并不断进行补充性工程创新，才能把潜力完全释放。电力取代蒸汽动力就是一个典型：电力本身才能发挥效率，还要围绕电力的传输特性和使用方式重新设计生产流程、管理模式和厂房布局。蒸汽动力受制于远距离输送，只能以动力需求为核心来安排生产；电力突破了输送瓶颈，才允许按照工艺流程来布设设备，效率因此大幅跃升。蒸汽机、电力、计算机等通用技术除直接提升生产力外，也带动了机械、航运、铁路等一系列配套创新的出现。人工智能的发展轨迹与之相似，技术效用的兑现同样存在滞后。眼下智能算法很难满足多用途需求，单一模型擅长解决特定任务，跨任务迁移能力有限。因此人工智能仍需经历持续的应用转化和工程化适配，才能与各行各业深度对接。未来作为底层技术基础，人工智能将由个性化走向通用化，应用门槛不断下降，为经济社会提供更广泛的智能支撑。对国家而言，抢占先发只是起点，关键在于保持持续投入和补充性应用创新，把技术优势转化为实力优势。早期哪怕只有微小领先，在规模效应的累积下也可能被不断放大，最终拉开差距。^([\[44\]](#txt002.html#footnote_content_txt002_44))蒸汽机不仅提供动力，还催生了机械、轮船和火车等交通工具的发明，人工智能的发展路径也在很大程度上遵循此类规律，技术效用的发挥存在滞后效应。^([\[45\]](#txt002.html#footnote_content_txt002_45))

2. 赋能型嵌入与系统融合
溢出效应和赋能效应是通用目的性技术的重要表现。在实际场景里，人工智能并不单独存在，而是作为信息系统的一个组成部分，通过与其他技术的集成实现价值。它不是单纯的产品或服务，而是一种基础升级能力，可以叠加到既有系统和服务之上，使其更智能、更高效、更精准。^([\[46\]](#txt002.html#footnote_content_txt002_46))这并不削弱其核心赋能角色，也不能简单等同于传统自动化。根据美国专利商标局统计，1976 年至 2018 年间，人工智能相关专利在整体专利中的渗透率从1%上升到25%，四分之一的专利持有者拥有人工智能相关专利，反映出该技术在各产业的广泛渗透和认可度。^([\[47\]](#txt002.html#footnote_content_txt002_47))

因此，人工智能通过微观层面的融合渗透来推动整个经济社会发展，对生产力和国家实力产生整体性提升。要发挥作用，人工智能必须与其它技术协同。对国际关系的影响亦遵循此逻辑。以军事力量为例，人工智能的潜在用途仍建立在传统军力基础之上，并非对常规武器系统的绝对替代。尽管人工智能具有军民两用特性，与炸药、飞行器、雷达、GPS 等传统双用途技术不同，它难以作为独立变量直接改写某一领域的相对优势。核武器是反例，其破坏力巨大，对国家实力的影响几乎脱离其他技术创新的联动。即便在其他领域落后，拥有核武器的国家在国际权力结构中的地位也会显著提升。^([\[48\]](#txt002.html#footnote_content_txt002_48))这种优势在人工智能领域难以复现。现阶段人工智能更多是通过赋能提升效率，很难推导出某国能凭借人工智能获得代际技术优势的结论，数量优势和规模效应依然关键。在同等技术起点下，国家往往需要依靠数量在战场上取胜。^([\[49\]](#txt002.html#footnote_content_txt002_49))因此大国更有可能率先获益。赋能形式和强度的差异会带来效果的不确定性，可能在同等实力国家间产生非对称优势，但目前来看尚未达到指数级提升。

3. 全球化协同与制度联动
全球化生态是当前新兴技术集群创新的显著特征，研发、应用、安全、监管等环节都在全球化环境中展开，影响自然也是全球性的。一方面技术复杂度急剧上升，任何国家都难以独力完成。对人工智能而言，理论、研发、设计、制造、生产等环节都需要全球科学家团队依托产业链合作，政产学研多方共同参与。标准和治理规则也必须协同制定，这正是人工智能全球治理成为国际组织和专业机构关注热点的原因。另一方面商业推广层面，互联网的全球普及带动信息技术产品和服务在世界范围内扩散。信息服务推广成本极低，形成全球一体化的市场竞争，头部效应明显催生了超级科技公司的崛起。与二十世纪洛克菲勒、卡耐基等行业巨头的垄断形态相比，人工智能借助网络空间的规模效应，其影响远超单一行业边界，在全球范围内产生跨领域冲击。第三，技术发展的全球性要求治理的全球协作。人工智能暴露的风险和隐患需要多边各方借助全球治理机制对话协商，形成共识性规范，避免风险外溢至政治军事领域。

4. 虚拟属性与隐性博弈
人工智能依赖数据资源，高度依托网络空间发展。随着5G/6G通信网络的大规模商用，更多智能无线终端接入互联网，现实世界产生的数据将极大拓展人类视野。一个全新的信息空间正在形成，其中大量数据和信息并非人类主动产生，而是来自物理世界的被动采集。这种虚拟性带来了应用效果的隐蔽性，这是人工智能区别于航空、核武器等传统通用技术的鲜明特征。人工智能的应用复制性强、复制成本低、开放性高，难以形成绝对排他性垄断，无论大小国家或非国家行为体都可能以较低门槛使用相关系统和应用；另一方面，模型训练和推理依赖强大算力的硬件，人工智能并非纯粹的软件。^([\[50\]](#txt002.html#footnote_content_txt002_50))本研究将人工智能视为整体，纳入全生命周期分析，但特别强调虚拟性特征，因为算法需随场景和数据不断迭代，赋能国家实力的作用更为关键。技术背后的标准与规则是控制力的衡量尺度，最终将传导至国际关系，成为各行为体影响力的重要来源。正因如此，各国围绕影响力的争夺和博弈可能呈现更隐性的形态。

人工智能在全球范围的广泛应用构建了一种力量，使人可以借助非强制手段影响他人的行为，甚至影响其利益的定义。^([\[51\]](#txt002.html#footnote_content_txt002_51))社交媒体已成为施加政治影响的重要平台，人工智能将通过公共网络平台影响舆论走向。算法可自主生成内容“子弹”、实施个性化“靶向”锁定和密集“信息轰炸”，以操纵他国内部舆论，实现意识形态层面的战略目标。^([\[52\]](#txt002.html#footnote_content_txt002_52))虚假新闻依赖算法自动生成，已成为新兴信息对抗手段。人工智能手段难以察觉，也导致自主武器、武装无人机等新型武器难以核查、难以监管，加剧大国猜疑，形成新的安全困境。技术发展的不透明性和应用边界的模糊性增加了管控扩散的难度。^([\[53\]](#txt002.html#footnote_content_txt002_53))目前各国和国际社会仍在探索监管，难点在于作为应用、程序和软件，其定义、边界和作用往往难以清晰界定和准确评估。与此同时，基于人工智能驱动的网络情报分析能力已成为各国竞相发展的重点。人工智能的虚拟性还体现在与移动互联网、大数据、物联网、云计算、边缘计算等的深度耦合，应用场景的综合复杂性也提升了治理难度。

本章小结
本章在梳理不同定义的基础上，将人工智能界定为一组能够模拟机器智能行为的技术集合，认为其应具备实时性、自主性和适应性等基本特性，即能够依据实时数据决策、随进程自主学习并对外部变化保持适应。鉴于当前应用在归纳、抽象、推理等方面仍显不足，并结合演进态势的研判，研究重点限定在面向特定领域和单一任务的专用人工智能阶段。

人工智能迄今经历了三轮发展浪潮。2010年以来，以深度学习为代表的技术路线加速，推动人工智能再次崛起。此轮突破得益于海量数据积累、硬件性能提升带来的算力升级，以及深度学习算法在理论和路径上的可行性，实现了商业化普及。尽管高度依赖算力和数据的深度学习仍面临技术天花板，但发展潜力犹存。目前专用人工智能在数据存储、人机翻译、图像识别、数据分析和完全信息条件博弈等领域已接近甚至超越人类水平。在现实需求和产业驱动下，技术从实验室到落地的周期大幅缩短，不断向各领域渗透，对国家政治、经济、军事产生深远影响。

人工智能与蒸汽机、电力、信息技术等重大技术一样具有强赋能性和外部性，是推动社会从数字化、网络化迈向智能化的关键引领力量。与工业时代科技革命相比，其影响不仅限于物质层面，还可能直接作用于思想意识层面；与信息革命相比，人工智能会加速数字权力的集中，技术强国和科技巨头的话语权进一步增强；与5G、物联网等前沿技术相比，人工智能需求导向更强，落地更快，赋能性更显著。

人工智能并非能独立产生影响的离散技术，必须与其他领域融合才能赋能发展，由此对国际关系影响的评估变得复杂。历史经验显示，率先取得突破的国家往往能建立经济发展和军事技术优势，转化为国家竞争力并提升国际地位。作为通用目的性技术，人工智能将对各领域产生持续广泛的赋能。同时，本轮发展依托全球技术产业生态，从研究、标准制定到设计、制造、软件开发均依赖国际分工，加深相互依存。而人工智能作为信息技术的虚拟性特征，也使其在技术监管和技术扩散层面带来更复杂的挑战。上述特性和属性构成了进一步分析其影响路径和效果的基础。
