## 第 4 章 AutoGen Agent 实战开发

2023年9月，微软公布了 AutoGen 开源项目。项目核心围绕 Agent 展开，在 AI 范畴里 Agent 指能够感知外部环境并作出响应的系统或实体。它可以独立处理信息、做出判断并采取行动来实现目标，通常具有目标导向、自主学习、环境交互和决策执行等属性，可用于计算机、移动设备、云平台等多种形态，广泛应用于自然语言处理、机器人技术、个性化营销等方向。

AutoGen 是一个基于大语言模型的 Agent 开发框架，依托 OpenAI GPT-4 等模型，可用单个或多个 Agent 构建语言模型应用，如图 4-1 所示。

[PRE0]

本章将展示 AutoGen 如何通过 Agent 间的对话来完成用户交办的任务。

### 4.1 AutoGen 开发环境

AutoGen 采用 Python 开发，使用前需要准备 Python 环境并安装常用工具，下面做概览介绍。本书项目在 Windows 系统下完成，安装细节不再详述。

#### 4.1.1 Anaconda

Anaconda 中文译为蟒蛇，是一款开源 Python 分发版，内置 conda、Python 及 180 多个科学计算包及其依赖。没有编程基础的读者安装 Anaconda 更省事，后续无需单独安装依赖；有一定基础的读者可选用 Miniconda，按需安装依赖以节省空间和时间。本书选用 Anaconda3，版本 1.12.1。

#### 4.1.2 PyCharm

PyCharm 是 JetBrains 公司开发的 Python 集成开发环境，Visual Studio 2010 的重构插件 ReSharper 同样出自该公司。PyCharm 包含调试、语法高亮、项目管理、代码跳转、智能提示、自动补全、单元测试、版本控制等提升效率的功能。本书使用 PyCharm Community Edition 免费版。

#### 4.1.3 AutoGen Studio

AutoGen Studio 可快速搭建多 Agent 工作流原型，并为 AutoGen 提供可视化界面。

安装步骤如下：

- 第一步：启动 Anaconda Powershell Prompt 窗口。
- 第二步：在该窗口输入 pip install autogenstudio 进行安装，如图 4-2 所示。
- 第三步：输入 autogenstudio ui --port 8081 指定端口，如图 4-3 所示。
- 第四步：在浏览器打开 127.0.0.1:8081，建议使用 Chrome，可看到图 4-4 所示界面。
