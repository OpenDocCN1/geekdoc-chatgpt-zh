下面这份示例用 PyOpenCL 在 Python 里演示一套完整的跨平台并行计算流程，适合想快速上手 OpenCL 设备调用的开发者参考。

#!/usr/bin/env python3

# -*- coding: utf-8 -*-

"""
8.4.2 OpenCL 跨平台加速的 Python 示例

本段演示借助 PyOpenCL 在 Python 环境下完成跨平台并行计算的完整流程：

1. 枚举并挑选可用的 OpenCL 平台与设备，支持多平台多设备场景下的按需选择；
2. 基于所选设备实例化上下文 Context 及命令队列 CommandQueue；
3. 在目标设备上开辟缓冲区并完成初始数据写入；
4. 编写一个并行核函数 Kernel，实现对数组元素的常数值累加；
5. 将计算完成的数据从设备搬回主机并打印。

使用提示：

- 运行前请先安装依赖：pip install pyopencl
- 建议 Python 版本 3.7 及以上
- 不同机器的设备列表可能不同，输出信息会随之变化
- 代码量偏大，注释丰富，便于学习与复现
"""

import pyopencl as cl
import numpy as np
import sys

# 1) 查找平台与设备
def select_device():
    """
    负责探测可用的 OpenCL 平台与设备，返回对应的上下文、命令队列以及设备对象。

    当环境中存在多个候选时，可在此基础上扩展选择逻辑。
    """
    # 枚举全部平台
    platforms=cl.get_platforms()
    if len(platforms) == 0:
        print("未检测到任何OpenCL平台！",file=sys.stderr)
        sys.exit(1)
    # 简化起见直接取首个平台
    platform=platforms[0]
    # 获取该平台下的所有设备列表
    devices=platform.get_devices()
    if len(devices) == 0:
        print("未检测到任何OpenCL设备！",file=sys.stderr)
        sys.exit(1)
    # 暂时只使用第一个设备
    device=devices[0]
    print("选择的OpenCL平台：",platform.name)
    print("选择的OpenCL设备：",device.name)
    # 实例化上下文
    context=cl.Context([device])
    # 队列属性保持默认，可按需开启 Profiling 或 Out-of-order
    queue=cl.CommandQueue(context,
                          properties=cl.command_queue_properties.NONE)
    return context,queue,device

# 2) 定义加法核函数
KERNEL_CODE=r"""
__kernel void add_constant(__global float* data,const float value)
{
    int idx=get_global_id(0);
    data[idx]=data[idx]+value;
}
"""

# 3) 主程序：数据准备、运算、回传
def main():
    # a) 选定设备并创建上下文与队列
    context,queue,device=select_device()
    print("设备类型: ",cl.device_type.to_string(device.type))
    print("设备计算单元数: ",device.max_compute_units)
    print("设备最大工作组大小: ",device.max_work_group_size)
    print("")

    # b) 编译核程序
    program=cl.Program(context,KERNEL_CODE).build()
    kernel_add_constant=program.add_constant

    # c) 在主机侧用 NumPy 生成待处理数组
    host_array=np.linspace(0,9,10,dtype=np.float32)
    print("原始数组 host_array: ",host_array)

    # d) 在设备上分配缓冲区并拷贝初始数据
    mf=cl.mem_flags
    dev_buffer=cl.Buffer(context,mf.READ_WRITE | mf.COPY_HOST_PTR,
                         hostbuf=host_array)

    # e) 传递核函数参数
    add_value=np.float32(5.0)

    # f) 计算全局工作项数量
    global_size=(host_array.size,)
    # g) 提交核函数执行
    kernel_add_constant.set_args(dev_buffer,add_value)
    cl.enqueue_nd_range_kernel(queue,kernel_add_constant,global_size,None)

    # h) 把设备结果复制回主机数组
    cl.enqueue_copy(queue,host_array,dev_buffer)

    # i) 等待队列全部指令结束
    queue.finish()

    # j) 打印结果，校验每个数均增加5
    print("执行加法常量5后的数组: ",host_array)
    print("")
