## 量化改造要点

量化入口以 bits 控制精度，传入零时直接返回不做处理。首次执行时会写入已量化标记并把位数同步到配置，避免重复量化。真正做重参数化的工作交给内部的 quantize 工具，作用对象是 transformer 主干。

逐层替换时，把注意力与 MLP 中的线性层全部换成 QuantizedLinear。权重先搬到当前显卡，保留偏置、输入输出维度、半精度类型以及空初始化开关，替换完后整体显存占用明显下降。

def quantize(self, bits: int, empty_init=False, **kwargs):

    if bits == 0:

        return

    from .quantization import quantize

    if self.quantized:

        return self

    self.quantized = True

    self.config.quantization_bit = bits

    self.transformer = quantize(self.transformer, bits,

                                empty_init=empty_init,

                                **kwargs)

    return self

## 生成与采样

评估阶段使用 nucleus 采样实现 Top-p。概率先按降序排序并累加，超出阈值的尾部置零后再归一化，最后通过多项式采样抽取下一个 token 并映射回原始索引。

配置与训练保持一致，前缀相关开关不变。最大总长 288，源文本上限 256，目标长度据此推导。模型切到推理模式后逐行读取 json，文本与提示词拼接并做截断，保证输入在限制范围内进入生成流程。

def sample_top_p(probs, p):

    probs_sort, probs_idx = torch.sort(probs, dim=-1, descending=True)

    probs_sum = torch.cumsum(probs_sort, dim=-1)

    mask = probs_sum - probs_sort > p

    probs_sort[mask] = 0.0

    probs_sort.div_(probs_sort.sum(dim=-1, keepdim=True))

    next_token = torch.multinomial(probs_sort, num_samples=1)

    next_token = torch.gather(probs_idx, -1, next_token)

    return next_token
