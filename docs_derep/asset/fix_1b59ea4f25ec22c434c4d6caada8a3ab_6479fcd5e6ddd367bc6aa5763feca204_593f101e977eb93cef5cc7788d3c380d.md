# Open WebUI 本地部署 + DeepSeek 直连指南

想在自己的机器上跑 Open WebUI，再用官方 OpenAI SDK 去调用 DeepSeek，整个链路其实很顺。下面把从建环境到发请求的关键步骤串起来，按顺序操作就能跑通。

## 环境搭建
建议先开一个专属的 conda 环境，把 Python 版本固定在 3.11，降低依赖冲突。创建完成后执行一次初始化，重新载入 bash 配置，然后激活进入该环境。
[PRE0]bash

# 创建一个名为 open-webui 的 Conda 虚拟环境，并指定 Python 版本为 3.11

conda create -n open-webui python=3.11

# 初始化 Conda

conda init

# 重新加载 shell 配置

source ~/.bashrc

# 激活刚刚创建的 open-webui 环境，进入该环境

conda activate open-webui

## 安装核心包
环境激活后，用国内镜像安装 open-webui，下载速度更稳定。
[PRE1]bash

pip install open-webui -i https://pypi.tuna.tsinghua.edu.cn/simple

## 启动界面
安装完成即可执行 serve 命令，服务起来后浏览器就能打开本地页面。
[PRE2]bash

open-webui serve

## 对接 DeepSeek
调用 DeepSeek 不需要额外封装，装好 openai 库即可。把 API Key 填入变量，base_url 指向 DeepSeek 官方地址，就能以标准 OpenAI 格式对话。
[PRE3]bash

pip install openai

下面是一段最小可用脚本，先构造客户端，再用 deepseek-chat 发一条问候，最后打印文本和完整对象。
[PRE4]python

import os

from openai import OpenAI

from IPython.display import display, Code, Markdown

import requests

import json

# <YOUR_DEEPSEEK_API_KEY>替换为复制的 API key 字符串

ds_api_key = '<YOUR_DEEPSEEK_API_KEY>'

#实例化客户端

client = OpenAI(api_key=ds_api_key,

                base_url="https://api.deepseek.com")

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {"role": "user", "content": "你好，好久不见!"}

    ]

)

#输出生成的响应内容

print(response.choices[0].message.content)

#输出完整的响应

print(response)

## 带 system 的完整调用
实际对话一般先放 system 再放 user。先定义 user_message，再把 system_message 与 user_message 一并传入模型，最后只打印生成的文本。
[PRE11]

#创建用户消息

user_message = {

    "role": "user",

    "content": "你好，请介绍下你自己。"

}

#调用 DeepSeek-V3 模型

response = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        system_message,

        user_message

    ]

)

#输出生成的响应内容

print(response.choices[0].message.content)

按此链路，本地 WebUI 与 DeepSeek 的代码调用都能顺畅衔接，后续可继续扩展工具调用、历史记录等功能。
