在不改动其余设置的前提下，HuggingFace Transformers 里的 Trainer 对经过 PEFT 定制的 PeftModel 兼容得相当好，能直接将其作为训练主体使用。这一特性把基于大模型预训练权重做个性化微调的门槛拉得很低，也体现了 PEFT 在提升调优效率与实现模型定制方面的价值。

后面几节会系统梳理多种大模型微调思路，并结合 PEFT 做成可复现的操作演示。理论拆解配合实操，能帮助读者建立对大模型微调机理的整体认知，同时直观感受到 PEFT 如何把复杂流程变得简洁高效，为科研和工程落地提供更实用的工具路径。在 PEFT 的加持下，各种微调范式都变得容易上手，讲解与实现会同步推进。

## 5.3 Prefix Tuning

### 5.3.1 背景

前缀调优是一种增量式调整做法，给模型输入前拼接一组为特定任务设计的连续向量，再只对这组“前缀”参数做梯度更新，并让它参与到 Transformer 每层的隐藏状态计算中，而原网络主体保持冻结。

2021 年斯坦福团队提出了一个新思路：在 Transformer 前端植入专门的特征向量 Prefix，随后锁住模型其余所有参数，让 Prefix 来负责生成新的 Token，从而适配下游任务。这一做法与人工设计的 Prompt 模板高度相似，可以说人工 Prompt 正是对 Prefix Tuning 原理的离散模拟，也反映了人类引导模型行为的间接性。

从实际使用感受看，Prompt 的设计存在很大的不确定性，研究者往往靠不断试错来寻找最优写法。但手工模板受制于主观偏好与微小变动的高敏感性，哪怕词序或用词的轻微改动，也可能导致输出质量明显波动。

因此斯坦福在 2021 年提出了 Prefix Tuning，用更自动化的方式去寻找最优 Prompt。核心做法是固定预训练大模型的参数，只训练面向特定任务的前缀，并为每个任务保存独立的前缀参数集合，从而大幅降低微调的算力成本。更关键的是，这些 Prefix 本质上是连续可微的虚拟词元，相较于离散词元，优化过程更平滑，效果也更优。

总体而言，Prefix Tuning 的价值在于用极小的成本完成大模型的个性化调整，因为它不触碰底层参数，减少了对 GPU 的依赖和训练时长，实现了无需载入完整模型参数即可高效改造的目标。

### 5.3.2 核心技术解读

如图5-6（该图引自论文 Prefix-Tuning: Optimizing Continuous Prompts for Generation ）所示，该方法把 Prefix 机制嵌入 Transformer 架构，关键步骤如下。

[PRE0]

（1）Prefix 模块集成：在预训练的 Transformer 前端接入一个专门的 Prefix 模块，为输入提供任务相关的先导信息，而不改动模型深层结构。

（2）针对性训练策略：仅对新增的 Prefix 参数进行学习，Transformer 其它部分全部冻结。这种差分训练把优化聚焦在微调层面，提升了效率与针对性。

（3）资源优化与成本控制：借此大幅减少对 GPU 计算资源的依赖，缩短训练周期与费用，为大模型的快速部署和迭代创造条件。

（4）大模型的微调突破：对 GPT-3 这类超大参数模型尤其有吸引力，让这些“庞然大物”的微调变得可行且可控。核心优势是避免了全量参数的逐项调整，显著减轻计算负担。

与传统全量微调 Full-finetuning 相比，该技术在输入序列开头构造任务适应的虚拟词元作为 Prefix 来引导训练目标。Prefix 参数通过前馈网络动态调整，而 Transformer 主体保持稳定，这与人工 Prompt 的差异很明显：Prompt 是外显固定的引导信息，缺乏学习能力；Prefix 则是内隐可学习的提示，能在训练中自我优化，更精准匹配任务。

为了保证训练稳定与效率，研究者在 Prefix 模块前端加入了多层感知机 MLP 结构，为 Prefix 参数的学习提供更平滑的路径。实践表明，这一设计有效避免了直接优化 Prefix 可能带来的不稳定，同时训练结束后只需保留优化好的 Prefix 参数，降低存储与部署成本。

论文结果显示，尽管参数量被压缩到原模型的千分之一左右，Prefix Tuning 的性能仍能逼近全量微调，尤其在数据有限的场景下表现更优，为高效模型调优提供了新方向。

## 5.4 Prompt Tuning

### 5.4.1 背景

Prefix Tuning 在落地时暴露出两方面限制。

（1）其方式是在原输入 Prompt 前额外拼接前缀，直接占用了模型的输入长度预算。因为前缀信息会进入模型处理的序列，难免压缩生成任务的有效输入空间，可能影响生成质量与多样性，尤其在对精度与上下文理解要求高的任务上。

（2）Prefix Tuning 依赖离散 Prompt 设计，落地成本较高，实效有限。引入的 MLP 结构也增加了复杂度与训练难度，限制了模型可塑性与效率。

在此背景下，Prompt Tuning 作为一种精炼变体出现。核心区别在于，Prompt Tuning 只在模型输入嵌入层加入提示参数，而不是在所有层都插入 Prefix。这一改动简化了结构调整，规避了 MLP 训练的难题，转而依靠精心设计的 Prompt Token 在输入层面驱动模型对特定任务的响应。仅更新这些 Token 的嵌入参数，就能在保持预训练权重不变的前提下实现任务适应，显著降低训练负担并提升灵活性。

Prompt Tuning 的理论基础是赋予 Prompt Token 独立可更新的参数，使模型以更低算力完成任务优化，同时兼容大规模预训练模型。实验显示，其性能虽不一定全面超越 Fine Tuning，但已非常接近，实现了以低成本获得接近高成本方案的效果。随着模型规模持续增加，Prompt Tuning 的潜力有望进一步放大。

因此 Prompt Tuning 的主要贡献包括：

- （1）引入了一种直观自然的语言引导方式，提升大模型的操控性与透明度。

- （2）特别适合已积累丰富通用知识的成熟大模型，利用规模化优势挖掘潜能。

- （3）继承 Prefix Tuning 的优点，通过避免加载整个庞大模型显著降低资源需求，为大模型高效部署与任务定制提供可行路径。
