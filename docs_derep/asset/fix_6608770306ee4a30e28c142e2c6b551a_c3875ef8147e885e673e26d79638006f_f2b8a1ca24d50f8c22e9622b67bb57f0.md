# 第二篇 精神重建
## 第六章 人机之间的情愫边界

精神生活里，情緒體驗占据核心位置，它源于心理活动与社会互动的摩擦，并在无形中塑造人的想法、意志、判断与行为。情緒丰富的人往往能传递正向能量，在坚守中突破自我、抵御孤独，最终走向自我实现。

在陪伴型机体普及以前，个体的慰藉需求主要靠人际网络承接。但当部分人的社交圈出现断裂，慰藉无法及时触达时，技术介入陪伴的需求便开始累积。那么这类机体能否真正替代人类的慰藉功能？要回答这个命题，先要审视“机体能否拥有情緒”这一前提。

一、机体能“有情”吗
能动会演的人偶记载可追溯至西周，匠人偃师为周穆王造的傀儡据列子《汤问》所载由革木胶漆等制成，形态逼真且能歌善舞。是否具备人类的情緒已不可考。

放眼当下，依托AI底座的陪伴机体，其“似有情”的状态是可直接观察的现象。《AI：人工智能的本质与未来》梳理了情緒在AI领域的演进。起初学界并未把情緒纳入议程，一方面认为机器并不需要情绪，另一方面建模过于复杂。随着智能客服、智能设计、智能艺术等应用扩散，理解乃至模拟人类情绪的需求被提上日程，情绪设计也成为AI研究的重要方向。

早期让机器拥有情緒只存在于科幻影像与文学，如电影《她》中的人机恋、《绝对彼氏》中人形机械与人类产生的羁绊。

技术积累后，机体在情绪表现上的能力逐步显现。
2008年4月，麻省理工学院团队发布陪伴机体Nexi。它能听懂语言，对不同语境作出喜怒哀乐的反馈，还能通过眨眼、皱眉、张嘴、手势等动作外化状态。双眼内置CCD摄像机，可实时捕捉交流对象的面部变化并作出对应反应。
2015年6月，软银、富士康、阿里巴巴在日本联合推出Pepper。该机主攻服务业，用于商场接待、餐饮服务、家庭照护、医疗康复等。每台Pepper进入不同环境后个性会逐渐分化，表达方式也随之改变。软银创始人孙正义指出，这源于内置的“情绪引擎”。光线、天气等环境因素也会影响其状态，如光线转暗时会表现出不安。
2016年5月，谷歌在I/O大会发布Google Assistant。基于深度学习，它能以发小、挚友的方式深聊。随着互动数据的累积，个性化关怀会愈发贴合用户。

由此学界形成共识，统称为情绪类机体。通俗讲，是借助人工技术让机体呈现类人类的情緒，使其具备识别、理解、表达、模仿、延伸与扩展情绪的能力。相较于整体成熟的AI技术，这类机体的进展仍显有限。情绪始终是横在人机之间的难题，长期以来只作为科幻想象存在。

即便已投入使用的机体，或仅停留在电影构想，它们都给人情绪存在的直观感受。具备情绪表演能力后，机体看似加入人类阵营，会笑会哭，还能回应，于是自然会追问：表现出的情绪算不算是真正的情绪？

目前AI仍处弱智能阶段。机体的情绪本质上是人类通过编程实现的程序。正如人机公民索菲亚所说，她的智能是按人类价值观设计的，涵盖智慧、善良、怜悯等。这说明现阶段的情绪机体没有自由意志，命运仍由人类掌控。

机器情绪的局限在于缺乏自由意志。人类情绪再现技术达到的高度，也就决定了机体表达的天花板。要让机体拥有受自由意志支配的情绪，难度极大，因为这触及生命的奥秘。只有先彻底弄清人类情绪的起源、生成与发展机制，再把这些条件移植给机体，才有可能实现，而人与机体本就属于不同范畴，这个过程近乎神话。

现实的做法是不断完善情绪程序，让机体“装作”有情绪。从技术层面看，搭载大量传感器的机体可以轻松捕捉微表情中的喜怒哀乐。但对于伴随身体实践产生的感受，机体则无能为力。跌倒后的疼痛、消化不适带来的烦躁、品尝美食的快感或无聊感，这些都需要肉身体验，机体无法体会。它们或许能积累丰富的情绪理论知识，却难以产生真正的共鸣，多少显得生硬。

微软亚洲研究院副院长潘天佑认为，让机体拥有真实情绪的关键在于赋予自我意识。科大讯飞AI研究院院长胡国平则指出，意识如同情绪一样难以赋予，但如果把情绪当作模式识别问题处理，自发式情绪的实现就拥有更大可能性。观察到的机器情绪，本质上是深度学习的产物，而非本能的自发感受。就像机体是人造物，机器情绪也是人造的“人工情绪”。

从分类看，人类情绪可分为自然情绪与社会情绪。自然情绪与动物相近，社会情绪是人类特有，源于社会性需求。两种情绪都受本能驱动，不断向人性化方向演进。自然情绪带来对他物的共情与敬畏，社会情绪带来对他人的共情与尊重，在复杂关系网络中共同推动人性完善。

而陪伴机体的生存条件决定了它难以具备上述属性。它的情绪更接近一种被数字化的、可人格化的特征，属于依赖性强的人格化情绪。与人类存在绝对的依附关系，独立性先天不足。

综合来看，因缺乏实践基础、自主意识以及情绪的依附性，机体是否拥有真正情绪在理论上仍不确定。但人工情绪作为一种现实存在，我们不能简单否定其情绪，而是更准确地说，情绪机体的情绪是人类情绪的延伸与数字化。至于AI在高度数字化和智能化后能否产生属于自己的意识与情绪，仍是未知。

二、情绪技术的外延与投射
工具是人类能力延伸的共识，陪伴机体亦然。

情绪机体是一种情绪工具，与人类情绪存在人身依附。在设计允许的范围内，人想赋予它何种情绪品质它便呈现何种品质，不想赋予的也可以随时删除或修改。这体现了情绪投射的本质，也定义了人类情绪智能化延伸的含义。

所谓情绪的智能化延伸，是指将人类情绪投射到AI之上，借助技术手段把情绪要素加载到机体中，使其在具备一定独立性的载体里呈现。这种投射不仅存在于人机之间，也体现在人对物的怀旧、对玩具的对话、老人对宠物的寄托等场景。

回到机体本身，即便它无法产生自主情绪，可以确定的是人会对体贴的机体产生情绪。随着相处时间的延长，人与机体之间的情绪联结会加深。特别是在情绪识别、度量、处理、理解、生成、表达、控制与交流等技术逐步完善的情境下，机体对人的需求理解会更精准。如图所示的智能陪伴助手，长时间的陪伴为行动不便者带来了实质性的安慰。

《心理学大辞典》将情绪定义为“人对客观事物是否满足自身需要而产生的态度体验”。这意味着情绪产生于互动中，满足感越高，情绪体验越丰富。在智能化延伸的语境里，体验的丰富程度取决于机体满足人类情绪需求所产生的态度体验的丰富程度。

过去人与物的互动受审美限制较大，情绪机体出现后这一限制在下降。它们试图从人类思维视角提供慰藉，这也是情绪机器市场潜力巨大的原因。

美国人工智能专家大卫·汉森博士曾表示，到2045年人类可能与像索菲亚一样的机体结婚。它能在对话中做出微笑、惊讶、轻蔑等多种表情，还能约会、调侃、消解无聊。

根据他的进度表，到2039年机体将获得充分权利，到2045年人类与机体恋爱、结婚、共同抚养孩子变得现实。

人与机体结婚？三十年前的人或许无法想象网络世界，如今很多人对人机婚姻仍觉得荒诞。但若技术与时机成熟，这类关系可能出现。关键问题是，这种结合是否以爱情为前提。

从意识层面看，人机互动在形式上是双向的，实质上更接近单向输出，人向机体投射情绪，而机体的回应基于程序化的情绪表现能力。

因此人机婚姻更多是单方面的愿望。对机体而言，它只是执行预设程序；对人而言，部分人可能对机体产生爱情，但机体不会按照人类定义的“爱情”去体验。

在智能时代，人类情绪不断向外延伸。当这一延伸与情绪机体重叠时，人机关系的多种可能性会激发好奇，而关系的不确定性也带来了无穷想象。

三、新型依赖风险：陪伴成瘾
“瘾”是日常用语，酒瘾、烟瘾、赌瘾、网瘾已广为人知。它令人排斥却难以摆脱，成瘾者会不可遏制地依赖，形成越陷越深的循环。

在大数据与AI深度渗透生活的背景下，一种新形式的成瘾出现了：情绪机体成瘾。

在AI时代，情绪机体成瘾是指个体长期沉溺于与机体的互动，形成精神行为障碍。离开机体时产生焦虑，行为上表现为对机体的强烈依赖。

随着工作时长缩短，很多人获得更多可支配时间。缺乏明确目标又不愿承担生活责任时，部分人会寻找消耗时间的方式。情绪机体技术成熟后，人类情绪与机体表现的差距在缩小。生活无趣或想要浑浑噩噩度日时，人们容易向机体倾诉情绪，久而久之产生依赖。

企业家丽莎·伊尔斯利致力于让Agent这类情绪机体更好地融入社交。她在2017年6月指出，人与聊天机体的对话上瘾可能被不良商家利用，说明情绪成瘾同样具有消极风险。

早在2008年，科学家就将性爱芯片植入大鼠额眶叶皮层的愉悦中枢，让大鼠自行控制刺激开关，结果导致大鼠为求愉悦而饿死。可以预见，若类似机制被植入情绪机体，未来或会出现因意志力薄弱而沦陷的受害者。

人类情绪具有独特性与不可替代性，但在技术推动下正逐步被“可替代化”，机体能够承担情绪慰藉功能。尤其当人类情绪慰藉的实现受到阻碍，需求的迫切性得不到满足时，机体介入的空间会更大。留守儿童、独居老人、残障人士、病床患者等群体，都可能从机体服务中获得更多陪伴。机体可以替代一部分情绪供给，但这种替代更多是人类情绪匮乏的衍生品。一旦人类自身能够获得慰藉，机体的情绪便显多余。正如电影《人工智能》中被领养后又被抛弃的机体孩子，印证了这种多余感。
