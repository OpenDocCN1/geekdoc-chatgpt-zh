# 调整优化后的“六套黄金魔方”思维导图

1. **一元树标魔方**
    - 核心特点：适用面广，用最少要素达到最优效果
    - 生成句式：请仿照我给出的XXXX样本，制作XXXX
    - 练习方向：
        - 建军节文章标题
        - 《沁园春·海》诗词仿作
    - 要点：依托范本，驱动模型进行模仿再创

2. **二元定位魔方**
    - 核心特点：先定身份再定任务
    - 生成句式：你是XXX，我是XXX，请你帮我完成XXX，要求XXXX
    - 练习方向：
        - 广告公司电视广告文案
        - 儿童睡前小故事
        - 泰戈尔风格散文诗
    - 要点：扮演特定角色，产出对应品质内容

3. **三元万象魔方**
    - 核心特点：三个要素拼装指令，灵活应对多类需求
    - 基础结构：XX关于XX的XX
    - 练习方向：
        - 励志经典语句
        - 环保节能主题文章
    - 设计思路：
        - 哲学来源：《道德经》一生二，二生三，三生万物
        - 设计原则：简洁、普适、具文化感
    - 要素速查：信息类、结构类、控制类

4. **三要万通魔方**
    - 核心特点：通用型结构，覆盖绝大多数需求
    - 生成句式：我要做XX，供XX使用，要求达到XX效果，但担心XX
    - 练习方向：三天掌握DeepSeek学习规划
    - 实战参考：健康管理公众号涨粉案例

5. **三维聚焦魔方**
    - 核心特点：以三个维度收束同一主题
    - 维度：历史、现实、未来
    - 使用流程：
        - 明确主题
        - 三维拆解
        - 形成逻辑闭环
        - 优化表达
    - 典型主题：
        - 减肥
        - 心理健康
        - 职场发展
        - 环境保护

6. **三问探幽魔方**
    - 核心特点：提问、追问、反问层层递进
    - 基础结构：（提问）XXXX有什么问题？（追问）这些问题会XXXX？（反问）否则是否会XXXX？
    - 实操步骤：
        - 提问：明确探讨方向
        - 追问：深挖问题根源
        - 反问：挑战边界假设
    - 适用场景：学术研究、问题探索、决策分析、日常思考
