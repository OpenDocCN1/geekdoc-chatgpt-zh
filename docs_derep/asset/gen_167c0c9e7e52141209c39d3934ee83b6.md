### 9.2.2 下载基础开发平台
开源社区沉淀了大量成熟的 Java 起步框架，这些框架已经封装了注册登录、权限管理等通用能力，让开发者把精力集中在业务本身。项目选用若依平台作为底层基座，并搭配 Vue.js 构建前端交互。

语法简洁、扩展性强，组件化思路很适合搭建购物车、商品卡片等界面。结合 Vue Router 与 Vuex，可实现页面无感切换和集中式状态管理，整体使用体验更流畅。

> 向 Cursor 提问

2. 表结构 SQL 写入 ry_20250417.sql 文件。

Cursor 按需求产出以下表：

- 商品分类表（shop_category）：支持多级分类，包含图标、排序、状态等。
- 商品品牌表（shop_brand）：保存品牌名称、logo、描述及官网。

- 商品 SKU 表（shop_goods_sku）：记录 SKU 具体信息，含价格、库存、规格。
- 商品评价表（shop_goods_comment）：保存用户评价，支持图片与商家回复。
- 促销活动表（shop_promotion）：支持满减、折扣、秒杀、特价四种类型，含规则与时间。
- 促销商品关联表（shop_promotion_goods）：关联活动与商品，支持促销价与限购。
