### 7.5 门控循环单元（GRU）

#### 7.5.1 核心思想：双门控制信息流

GRU 由 Kyunghyun Cho 团队于 2014 年提出。它在标准 RNN 基础上引入**重置门**与**更新门**两大门控机制，显著提升了长序列建模能力，同时参数量更少、训练更快。

*   **重置门**：决定“遗忘”多少过往信息。
*   **更新门**：决定“保留”多少历史状态。

这两扇门协同调节信息流向，有效缓解了梯度消失/爆炸难题。GRU 结构精简，仅含单隐藏状态，无显式输出，计算流程分为三步：重置门、更新门、候选状态计算。门控值由 Sigmoid 生成（映射到 0~1），候选状态经 tanh 约束在 -1~1 区间。该模型在 NLP、语音、视觉等任务中表现优异。

### 7.6 长短期记忆网络（LSTM）

#### 7.6.1 从诞生到霸主：专为长依赖而生

1997 年，Hochreiter 与 Schmidhuber 发表奠基之作《Long Short-Term Memory》。针对传统 RNN “长期记忆难、短期输入易丢” 及梯度异常痛点，LSTM 引入**记忆细胞**与**三大门控**（输入门、遗忘门、输出门），实现信息的“写、忘、读”精细化管理。

早期用于语音识别（2014 年大放异彩），随算力提升与深度学习浪潮，现已成 NLP（分类、翻译、情感）、视觉（分类、生成、分割）等领域的基石模型。

### 7.7 注意力机制：让模型学会“聚焦”

#### 7.7.1 打破固定向量瓶颈

传统 Seq2Seq 将整序列压缩为定长向量，长序列信息严重失真。注意力机制借鉴人类视觉认知，**动态分配权重**，让解码器每一步都能“看清”编码端的关键位置，显著增强长距离建模与泛化能力。广泛应用于 NLP、CV、语音等领域。

#### 7.7.3 五大主流变体速览

| 类型 | 核心逻辑 | 优势 / 代价 |
| :--- | :--- | :--- |
| **点积注意力** | `Q·K^T` 直接做相似度 | 计算极快，但受向量模长影响大 |
| **缩放点积注意力** | `Q·K^T / √d_k` | 缩放因子稳定梯度，**Transformer 基石** |
| **多头注意力** | 多组 Q/K/V 并行计算再拼接 | 多子空间建模，表达力强，参数量↑ |
| **自注意力** | `Q=K=V=X` 序列内部交互 | 捕捉全局长依赖，并行度高，显存/算力↑ |
| **局部注意力** | 仅关注窗口内 Key | 线性复杂度，适合超长序列，可能丢全局信息 |

### 7.8 章节小结

本章系统梳理了深度学习两大支柱架构：
1.  **空间建模**：CNN / ResNet 统治图像、视频、音频领域。
2.  **序列建模**：深度 RNN 及变体 **GRU、LSTM** 攻克长依赖，成为文本/语音首选。
3.  **通用增强器**：**注意力机制** 以“动态加权”打破信息瓶颈，赋能编码器-解码器与自注意力架构。

深度模型虽结构多样（输入-隐藏-输出三层范式），但训练极度依赖算力（小时至天级）。其核心价值在于**端到端表示学习**，自动解决“信用分配”难题，免去人工特征工程。若欲深入神经网络理论体系，推荐研读《Deep Learning》（花书）。

## 第 8 章 强化学习：智能体的决策进化论

### 8.1 核心范式：序贯决策问题

机器学习中一类关键任务——**序贯决策**：智能体在离散时间轴上与环境持续博弈。每一步决策不仅影响即时收益，更重塑未来状态分布。

#### 8.1.1 标准流程建模

**循环范式**：
1.  **观测** 当前状态 `s_t`。
2.  **决策** 依策略 `π` 选动作 `a_t`。
3.  **交互** 环境转移至新状态 `s_{t+1}`，反馈奖励 `r_t`。
4.  **迭代** 目标：最大化累积回报 `G_t = Σ γ^k r_{t+k}`。

**三大分类视角**：
*   **有模型 vs 无模型**：是否知环境转移概率。
*   **在线 vs 离线**：边学边用 vs 利用历史日志。
*   **基于价值 vs 基于策略**：学价值函数选动作 vs 直接参数化策略。

本章将依次拆解：马尔可夫决策过程（MDP）基础 → 价值法（DQN 等）→ 策略法（REINFORCE, PPO）→ 深度强化学习（DRL）→ 模仿学习 → 集成强化学习。
