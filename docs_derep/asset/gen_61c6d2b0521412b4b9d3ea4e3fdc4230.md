### 全连接神经网络（多层感知机）

全连接神经网络，亦称多层感知机（MLP），是神经网络家族中最基础、应用最广的架构之一。无论是卷积神经网络（CNN）还是循环神经网络（RNN），其内部往往都包含全连接模块，因此深入掌握其原理与实现，是进阶深度学习的必修课。

#### 1. 非线性核心：激活函数

全连接网络能够拟合复杂函数的关键，在于引入了非线性映射——即激活函数。以下介绍几大主流选择。

**Sigmoid 函数**
其数学表达及图像如下：

该函数将任意实数输入压缩至 (0, 1) 区间。输入趋向负无穷时输出趋近 0，趋向正无穷时输出趋近 1；在输入接近 0 时，导数取得最大值。引入 Sigmoid 可有效抑制梯度爆炸，但深层网络中易引发梯度消失。

# BP 神经网络：反向传播的奠基之作

BP（Backpropagation）神经网络是深度学习发展史上的关键转折点，其训练范式奠定了后续所有深度模型优化的基石。本节将深度剖析标准算法流程及改进策略。

### 标准 BP 算法流程

BP 网络属于多层前馈网络，架构上可视为多层神经元堆叠：首层为输入层，末层为输出层，中间层统称隐藏层。结构示意见图 6-10。

[PRE18]

图 6-10 BP 神经网络结构图

**运行分两阶段**：
*   **推理阶段**：前向传播，直接得出输出。
*   **训练阶段**：核心在于**反向传播**更新参数，这也是 “BP” 名称由来。

训练遵循 “前向传播计算误差 -> 反向传播计算梯度 -> 更新权重” 的迭代循环，直至满足收敛条件。完整流程图见 6-11，关键五步解析如下：

[PRE19]

图 6-11 BP 神经网络算法流程图

1.  **参数初始化**：无先验知识时，权重 `w[ij]` 通常采用均值为 0 的均匀分布（区间 [-1, 1] 或 [-0.5, 0.5]）。
2.  **样本乱序**：每个 Epoch（全量样本一轮）打乱样本顺序，充分利用数据特性，防止陷入坏局部最优。
3.  **前向传播**：输入经网络层层变换至输出层，记录各层局部诱导域（净输入）与激活输出。
4.  **反向传播**：自输出层向输入层，逐层计算局域梯度（误差项）。
5.  **参数更新**：基于梯度下降法修正各层权重与阈值。

循环终止条件：误差达标或达到最大迭代次数。BP 的精髓在于高效完成权值迭代，其展现出的非线性映射、泛化与容错能力，使其无需显式数学方程即可学习复杂输入-输出映射，这是深度学习“从数据中学习”范式的雏形。

### BP 算法局限与改进进阶

#### 1. 两大核心痛点
*   **局部最优陷阱**：误差曲面极小点密集，梯度下降易提前收敛于非全局最优解。
*   **平坦区训练停滞**：误差曲面平坦区域（对应激活函数饱和区）导致梯度接近零，参数更新极其缓慢，严重拖慢收敛。

#### 2. 主流改进方案

**针对局部最优：先进优化器与初始化策略**
随着深度学习理论成熟，Adam、Adagrad 等自适应优化器成为标配，能动态调整学习率跳出浅层极小值。

# 卷积神经网络（CNN）：视觉智能的基石

### CNN 设计动机：为何 MLP 不适合图像？

全连接网络（MLP）面对图像数据遭遇**维度灾难**：图像像素动辄百万级，全连接参数量爆炸，算力与存储双重不可承受。CNN 通过三大数学特性破局：

1.  **稀疏交互**：卷积核尺寸远小于图像，仅关注局部感受野，大幅削减参数量与计算量。
2.  **参数共享**：同一卷积核在图像上滑动复用，仅需学习一组参数，而非每个位置单独学习，实现指数级参数压缩。
3.  **平移等变性**：参数共享天然赋予网络对平移变换的等变特性——先平移再卷积，等价于先卷积再平移。注：缩放、旋转等变换不具备此性质。

### CNN 核心组件架构

典型 CNN 包含：输入层 -> 卷积层 -> 激活层 -> 池化层 -> 输出层（常接 MLP 分类头）。重点解析卷积层与池化层的关键超参。

#### 1. 填充与步幅：控制特征图尺寸

卷积操作涉及核在输入上如何滑动，直接决定输出特征图大小。

*   **无填充**：输入 `n×n`，核 `k×k`，步幅 1 → 输出 `(n-k+1)×(n-k+1)`。边缘像素利用率低。

*   **有填充**：输入周围补 `p` 层 0 → 输出 `(n-k+2p+1)×(n-k+2p+1)`。作用：保持空间分辨率不变（如 `p=(k-1)/2`），并强化边缘特征提取。
