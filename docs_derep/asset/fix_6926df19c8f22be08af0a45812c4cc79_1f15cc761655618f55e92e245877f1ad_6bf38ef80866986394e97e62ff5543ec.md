**3.4.1 AI 当助推器，别当替身**

智能模型的价值在于把学习过程推得更顺，而不是把成品直接塞到手上。只习惯让它完整输出程序或直接给出解题答案，看起来任务完成快、省了不少时间，其实把真正长本事的环节一起省掉了。算法推导时卡住、反复梳理直至豁然开朗的那段体验，是让知识扎根的关键；调试程序时不断试错形成的敏感度，能让以后更快定位问题；拆解题目时的自问自答，是解题能力生成的基座。这些思考的堆积才是从懂原理到会实现的质量跃迁，一旦被跳过，学习效果会明显打折。

要认清，编程能力的证明不是练习数量，而是逻辑思维、算法设计、代码落地等核心素养。每次让助手直接给答案，等于把训练机会让给机器，自己只剩复制粘贴。等到考场或竞赛现场没有辅助时就会底气不足。只有把能力内化成自己的，才能经得住检验。

**3.4.2 先自己冲一冲，再让 AI 补位**

遇到难题时，先给自己一段独立思考的时间。可先把需求拆开，结合已学知识点梳理可能的思路，尝试推演算法走向。即便卡住，也别立刻求助，先在草稿纸上画流程、写几行伪代码，用自己的方法突破。实在没有方向、思考到瓶颈时再请助手，且要明确索要思路提示而非现成成品。

比如可以询问助手在处理边界条件时通常关注哪些情形，以及为何优先考虑它们，背后的判断逻辑是什么。带着自己的思考去对照助手的讲解，把未覆盖的点补齐，这样助手才是辅助独立思考的工具，而非被动接受答案的替代品。

**3.4.3 提问的质量决定学习的质量**

做到上面两点，很大程度上取决于提问方式。若想用助手理解算法思路，可以这样问。 [PRE0]
请把 Dijkstra 求最短路径的思路拆成三个阶段，分别说明每个阶段在做什么、为什么这样安排，禁止直接输出代码。
若想让助手帮忙排查程序，可以这样问。 [PRE1]
我在遍历数组时程序异常，请先归纳此类错误常见的三类诱因，再给出分步排查的流程。
这种指向明确、要求具体的提问，能让助手给出更有价值的内容。更关键的是，组织问题本身就是梳理需求、明确目标的训练，也是独立思考的练习。

由此可见，提问的好坏直接决定助手能否真正助益提升。下一章将聚焦信息学奥赛学习中的关键环节——如何写出好 Prompt。只有指令合理，助手才会成为提升能力的帮手，而不是让人变懒的拐杖。

**第四章 提示词 Prompt：与 AI 沟通的钥匙** [PRE2]

小贴士：
阅读本章时，建议先准备常用的智能模型，如豆包和 DeepSeek。看到“ [PRE3]Prompt”标识时可实操感受效果。电子版 Prompt 的获取方式见 5.3 节。

**4.1 认识 Prompt**

**4.1.1 Prompt 的本质**

Prompt 说白了是一段注入式指令，是开启与智能模型交互的入口。它能触发回应、引导对话走向、影响最终输出，也能通过预设思考框架指挥模型如何分析、如何组织内容。核心目的就是用精准的指令或问题，让模型生成更贴合预期的结果。

在这个 AI 已成日常的时代，豆包、DeepSeek、元宝这些名字并不陌生。每天可能会用它们构思作文、解数学难题、把报错程序丢进去求助、整理单词。简单说，Prompt 就是输入给模型的话术，也就是你平时问它的那些问题，用来告诉它想要什么、引导它输出什么，是沟通的桥梁。

Prompt 的尺度差异很大。最简单的像随口一问，如学生常问： [PRE4]
C++ 里数组下标为何从 0 开始。
复杂的则像一份任务清单，比如： [PRE5][Prompt 为信息学奥赛学员制定一份关于二分查找的学习规划。具体要求：1.用生活场景类比二分查找原理。2.包含 C++ 实现。3.设计两道练习题，适合中小学生理解。]

模型是如何读懂 Prompt 的？原理很复杂，粗略理解就像和同学讨论：先听清需求。输入后，模型会拆解文字、抓取关键词如二分查找、生活场景类比、C++ 实现、中小学生，理解真实意图，再调取相关知识，结合上下文组织输出，最后返回结果。

举个熟悉的例子：调试 C++ 程序卡了半小时，打开豆包输入以下 Prompt。 [PRE6][Prompt 帮我看一看这段代码为什么在运行时会崩溃？] [PRE7]
模型会先识别“运行时崩溃、代码片段”这些信息，调用对 C++ 数组越界的认知，指出数组 a 大小为 3，下标最大是 2，访问 a［5］越界导致内存错误。正因为 Prompt 包含了具体现象和代码，模型才能快速定位问题。这就是 Prompt 在交互中的核心作用：描述越清晰，协助就越到位。

**4.1.2 写好 Prompt 是新时代的核心能力**

有人会说，不就是输入一段话吗，随便写不行吗？其实不是。体验过就会发现：同样的需求，模型有时答非所问，给出一大段理论看得云里雾里，有时又精准命中，连没说出口的细节都考虑到了。差别就藏在输入的 Prompt 里。

对信息学奥赛学习者而言，无论是掌握 C++ 基础、刷题复习还是备赛，高质量的 Prompt 能让效率翻倍。价值主要体现在三方面。

1.提升效率：少走弯路，省下时间
比如整理语文笔记，只输入： [PRE8]
整理课文《背影》的知识点。
模型会把主旨、作者生平、段落大意全堆出来，需要你再筛选。若换成： [PRE9][Prompt 整理《背影》三个核心要点：按父亲言行细节→情感表达→写作手法展开。每点配一句课文原句，重点标注细节描写相关内容。]
生成的笔记就能直接用，省去反复修改。
在奥赛学习中，让模型出动态规划练习题，若只说： [PRE10]
出几道动态规划编程题。
很可能得到大学难度或面试题。若输入： [PRE11][Prompt 输出两道适合信息学奥赛练习的线性 DP 题，需包含题目描述、输入输出样例和思路提示。]
题目就能直接进入练习计划，无需再调难度。好 Prompt 就像导航，让模型直奔目标。

2.实现个性化定制：打造专属学习助手
学习节奏各不相同。学一元二次方程，有人要补因式分解基础，有人想挑战含参讨论；练编程，小学生需要积木比喻，竞赛选手需要复杂度分析。模型通用，Prompt 专属。
比如讲解循环：
小学生： [PRE12][Prompt 用生活化的例子解释 for 循环的执行机制，不要写代码，用小学生能听懂的语言。]
竞赛选手： [PRE13][Prompt 分析模拟退火算法中温度参数的循环调整逻辑，用伪代码表示温度从初始温度 T0 下降到最终温度 Tf 的过程（T=T0*0.95^k，k 为迭代次数），并说明循环终止条件的设计对算法结果的影响。]
不同的 Prompt 给模型不同剧本，让输出更贴合身份与目标。

3.拓展应用边界：成为探索新知的脚手架
模型不再只是答题机器，可梳理时间线、辅助调试、设计实验、分析真题趋势。要发挥这些作用，Prompt 是前提，能把工具变成探索知识的支架。
比如 C++ 知识点零散时，可问： [PRE14][Prompt 用表格对比 C++ 中的数组、字符串、指针，并说明它们之间的转换关系。]
会得到结构化表格，帮助融会贯通。
再如函数参数传递： [PRE15][Prompt 对比讲解 C++ 中值传递和引用传递的区别，含定义说明、内存分配差异、对实参的影响三个维度，并用代码示例分别演示，重点标注引用传递时形参前的“＆”符号作用。]
卡在最短路径时，可输入： [PRE16][Prompt 我刚学完图的存储、邻接矩阵和邻接表，想入门最短路径算法，请帮我设计一个 3 步学习计划：第一步，推荐 1 个适合初学者的算法，用城市间修路的例子讲解原理。第二步，给出一段简化的 C++ 代码，只保留核心逻辑，注释关键步骤。第三步，出 1 道入门级练习题。]
模型就像教练，引导你逐步深入，而不是直接丢手册。

总之，Prompt 只是段文字，却藏着沟通密码。学会清晰、具体地下指令，能省时、定制内容、打开新可能。下次对话前花一分钟自问：需求说清楚了吗？模型往往会因此“懂你”。

**4.2 如何构建优质 Prompt**

什么是优质 Prompt？通过几个生活学习场景来看标准与优化方法。

1.标准一：目标具体，明确要做什么 [PRE17]
帮我写一篇五年级课外阅读分享发言稿。
修改建议：任务不能模糊，需说明类型、场景、受众。修改后： [PRE18][Prompt 为小学五年级语文课外阅读分享撰写发言稿，受众为同班同学，核心内容为《少年中国说》，时长 3～5 分钟，需包含时代背景、作者创作目的及全书中心思想。]

2.标准二：结构清晰 [PRE19]
帮我设计一个三年级主题班会方案。
修改建议：用分层逻辑组织需求，明确任务与要求。修改后： [PRE20][Prompt 设计小学三年级“交通安全主题班会”方案，需包含 3 个部分：1.流程（20 分钟，含观看安全视频、3 名学生分享过马路注意事项、班长总结）。2.准备物品（视频、3 张安全标语卡片）。3.班会目标（让学生明白红灯停、绿灯行，不横穿马路）。]

3.标准三：信息完整，细节足够具体 [PRE21]
帮我改一下这道数学应用题。
修改建议：补充任务细节。修改后： [PRE22][Prompt 协助修改七年级数学应用题解题过程：1.题目：商店将进价为 120 元的商品按标价的 8 折出售，仍可获利 10%，该商品的标价是多少元？2.原解错为：“120×10%+120=132，132÷80%=165”。3.指出解题出错点，具体是哪一步问题。4.给出正确解题步骤和每步说明，标注易错点，格式按“分步算式、每步说明”两列呈现。5.从数学老师视角做错题归因分析，说明可能未掌握的知识点，并总结后续提升建议。]

4.标准四：风格与格式明确 [PRE23]
帮我写一个“探究植物光合作用”的科学实验报告。
修改建议：明确文体、语言要求与输出模块。修改后： [PRE24][Prompt 为初中八年级撰写“探究植物光合作用需要光”的科学实验报告，需满足：1.写作风格采用说明文，语言正式书面化。2.用词准确，全程不用口语化表达和网络词语，表述严谨。3.输出格式：全文约 600 字，包含 6 个固定模块，每模块单独成段并标注标题。1）实验名称居中。2）实验目的。3）实验器材分点列出。4）实验步骤用序号分点，写清操作动作。5）实验现象描述遮光与未遮光部分颜色差异。6）实验结论明确光合作用与光的关系。]

从案例可见，优质 Prompt 有四个核心原则：任务目标具体明确，避免模糊宽泛，需界定场景、人群、核心内容、时长字数等约束；结构清晰，用分点编号组织需求；信息完整，提供背景与关键数据；风格格式明确，确保输出可控。低效 Prompt 多因需求模糊、细节缺失，导致输出偏差、反复修改。遵循“目标具体、结构清晰、信息完整、风格格式明确”才能让模型稳定达标。

**4.2.1 先把指令讲清楚**

写 Prompt 时，指令的清晰度就像给船定航向。模糊的说法会让模型靠猜测，输出自然偏离预期。
