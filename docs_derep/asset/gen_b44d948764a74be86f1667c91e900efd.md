顺带提一句，当时还有一种完全不同的方法叫做“最近邻算法”。它不依赖形状的改造来做识别，原理很朴素：把待测图像和另一张图像直接比较。电脑内存里存着所有训练图像，识别时就把输入图与内存中的图逐一对比，比如统计不同像素的个数，找出最像的那一张，再把该图的类别作为输出。若输入的是 D，就输出“D”。这种做法只适用于印刷体字母这类简单图像，对手写字符的效率会下降且成本高昂。若想用最近邻识别狗或椅子，就要把数百万张在不同位置、光线、场景下拍摄的照片全部存入电脑，这显然不现实。

## 10 泛化原理

学习型机器的标志是泛化，能举一反三，对训练时未见过的样本给出正确判断。只要训练集里包含足够多、样式各异的 C 和 D，感知器就有机会认出从未见过的 C 和 D，前提是差异不要太大。

可以用乘法来类比。人们能算出 346×2067 并不是因为记住了所有乘法结果，而是掌握了乘法规律。感知器的工作更精细，它并不是把所有可能的 C 形状都存下来，而是建立一个专门的模型来完成识别。下面看看它怎么做。

操作人员在训练前会收集大量样本，也许是数百到数千个大小字体不同的字母 C，并把它们放在 25 像素网格的不同位置。D 也是同理。

若希望感知器对 C 输出 +1、对 D 输出 –1，学习过程中它会给 C 图中黑色的像素和 D 图中白色的像素分配正权重，给 C 图中白色的像素和 D 图中黑色的像素分配负权重。权重本质上就是区分 C 与 D 的信息。

从这里可以看出学习的力量：训练好的机器能够超出输入的示例，识别出全新的图像。

## 11 感知器的局限性

当收集到的 C 或 D 样本差异不大时，前面描述的方法是有效的；但如果形状、大小或方向差别过大，例如极小的 C 出现在图像角落，感知器就找不到合适的权重组合。此外，某些类型的形状变化本就无法被感知器识别。所有线性分类器都受此限制，感知器只是其中一种。

线性分类器的输入是一串 `n` 个数字，也可看作 `n` 维向量。数学上向量就是空间中的一点，数字是其坐标。对一个两输入的神经元来说，输入空间是二维平面，输入向量就是平面上的点；三输入对应三维空间。我们描述的 C、D 例子输入空间有 25 个维度，图像的 25 个像素值对应 25 维空间中的一点。这是一个无法视觉化的超空间。

线性分类器把输入空间切成两部分，如 C 图与 D 图。若空间是平面，分界就是一条直线；三维则是平面；25 维则是 24 维超平面。总体来说，输入个数为 `n` 时，分离面是 `n–1` 维的超平面。

为验证这一点，重写二维加权和：`S=w[0]*x[0]+w[1]*x[1]`。当加权和为 0 时，恰好跨过分界，边界点满足 `w[0]*x[0]+w[1]*x[1]=0`，亦可写成 `x[1]=–w[0]/w[1]*x[0]`，这就是直线方程。

两个向量的点积为 0 时正交，夹角小于 90° 时为正，大于 90° 时为负。因此 `x` 的集合就是与 `w` 正交的所有向量，在 `n` 维中构成 `n–1` 维超平面。

问题就出在这里。设想一个只有 2 个输入的感知器，再额外加入一个恒为 –1 的“虚拟”输入。若没有这个附加参数，分隔线必过原点；有了它，边界线就能自由平移。

这里涉及的是二维空间中的点，对应函数中两个像素的两种输入图像，人类可以直观看到这个平面。

真正的感知器工作在多维空间。当我们希望它区分更复杂、变化更大的形状或位置时，往往会遇到上述情况，只是维度更高。

对感知器而言，输入向量与权重向量呈锐角时加权和为正，钝角时为负。正负的分界是与权重向量 `w` 正交的点 `x` 的集合，因为 `w` 与 `x` 的点积为 0。在 `n` 维空间中边界方程为：

`w[0]*x[0]+w[1]*w[1]+w[2]*w[2]…w[n–1]*x[n–1]=0`

它是一个 `n–1` 维超平面。

感知器用一个超平面把空间劈成两半。我们希望 C 图像检测器活跃的点全在超平面一侧，非活跃的点在另一侧。若这样的超平面存在，感知器通过不断学习就能找到；若不存在，即点不是线性可分的，无论如何调整权重也无法收敛到稳定唯一的配置。

为什么要做这个论证？因为它解释了 20 世纪 60 年代初困扰模式识别研究者的难题，研究者据此认为感知机的能力有限，无法识别自然图像中的物体。

事实上，当输入维度足够大、样本丰富且复杂时，如成千上万张狗、猫、桌子、椅子的照片，其类别很可能不是线性可分的，无法被直接连到像素上的感知器识别。即使在简单的 C、D 例子里，若字母的形状、位置或大小差异很大，感知器也无法分类。

西摩尔·帕普特与马文·明斯基在 1969 年出版的《感知器：计算几何学概论》^[〔1〕](part0055.html#note35n) 给感知器的发展画上了句号，加剧了研究者的挫败感。这次机器学习研究的停滞在人工智能史上扮演了重要角色，导致我们陷入了其中一个人工智能寒冬，研究方向被迫转移。

对今天的读者来说，这个论证提供了理解机器学习的另一个切入点。

## 12 特征提取器

最简单的感知器无法区分某些形状。因此从一开始研究者就采用了沿用至今的方案：在输入图像与神经层之间加入中间模块，即“特征提取器”。它能在输入图像中侦测特定区域，生成描述这些区域是否存在、强度的向量，再交给感知器处理。

回到前面的论证。

把感知器直接连到图像例如 C 的像素上，它很难跳出“增强模板”的模式。由权重编码的像素类别区分了 C 与其他图像。一旦样本变化过大，罗森布拉特的感知器就会“饱和”，权重不再能识别。若用差异极大的 C 图像训练，就会发生这种情况。若图像分辨率足够识别所有字符（约 20×20 像素），C 的大小、字体、印刷还是手写、在图像角落还是中心就不再是问题。若形状、位置或尺寸差异过大，感知器无法分类，因为没有单一的增强模板能覆盖所有变化（见图 3—7）。

[PRE3]

#### 图 3—7 特征提取器

特征提取器检测输入图像中存在的独特图案，并把结果送往可训练的分类器如感知器。第一个模板检测笔画的线尾作为“C”的末端，另外两个模板检测拐角如“D”的拐角。该层信息作为感知器的输入。训练后，只要存在相关特征，感知器就能在大小和位置不同时区分 C 与 D。在这个例子中，一个 C 两个位置不同的 D 下，提取器可看作一层二进制神经元。白色像素代表 –1，灰色像素代表 0，黑色像素代表 +1。上述三个特征检测器是 5×5 像素的“模板”，与输入图像比对。对模板的每个位置，用模板的 25 个权重计算输入窗口 25 个像素的加权和。结果是一组图像，当窗口内容与模板相似时像素变黑。然后把加权和与阈值比较生成特征图，若在相应位置检测到图案则值为 +1，否则为 0。

无论字体或书写风格怎样，在 20×20 像素图像中分辨 C 与 D 的关键是检测拐角和笔画末端。D 是带两个角的闭合图形，C 是一条两端各有一个端点的开曲线。于是可构建一个特征提取器检测端点或拐角的存在，而不必关心 C、D 在图像中的位置。我们可以设计第一层为一组二进制神经元集合，其输入是图像上 5×5 像素的小窗口，并手工赋予权重（而非学习算法确定）。可得到三种感知器神经元：一种端点神经元和两种角神经元。图像上的每个 5×5 窗口提供三个神经元，各一类型。当输入窗口看起来与权重图像相似时，神经元输出 +1，否则输出 0。若 C 形状良好，端点检测器会被激活；若 D 形状良好，角检测器会被激活。最后一层是一个简单感知器，只需计算角和端点的数量来区分 C 与 D，其位置、大小和样式不再重要。

我们可以改造感知器架构，使其执行更复杂的操作。具体做法是在感知器层前放置一个手工构建、未经训练的“特征提取器”。特征提取器的设计既复杂又耗时，2015 年以前的文献中充满了这类构造方法。

因此一种常用方案是让特征提取器检测输入图像中细微的简单图案。对字母而言，它不仅能标出末端和角，还能标出竖线、横线、环线等。提取器的输出是一串数字，代表这些简单图案是否存在及其位置。此时感知器并不是直接连到输入像素，而是通过更抽象的特征连接。

若想用感知器检测汽车，其特征提取器就是一组模板，分别检测车轮、挡风玻璃角度、散热器格栅等。用这些模板扫描整幅图像，扫描到图案时模板会“亮起”，所有扫描到的特征一起输入感知器。对人脸的处理方式相同，只需检测眼睛部位的深色区域、鼻孔中的两个小黑点、嘴唇间略深的一条线，就能构建合适的面部感知器。

在最初的感知器里，特征提取器实际上是一串二进制神经元，它们随机连接到输入图像的小像素组（当时没有更好的办法）。这些神经元的权重无法通过学习改变，是固定的且随机。由于连接随机，我们永远无法确定哪个是有用的。为了让第一层发挥作用，必须设置大量特征提取器神经元，从而使最终神经元（唯一可训练的神经元）的输入数量急剧增加。在一些 2013 年后就很少使用的分类与模式识别系统里，特征提取器的输出可达数百万。特征越多，对后续分类越有帮助，但成本也越高。

研究人员受视觉皮层连续区域组织启发，希望通过建立更多神经元层来提升感知器效率：系统第一阶段提取非常简单的特征；下一层尝试检测这些特征组合的轮廓或直接连接特征，形成圆形或角等基本形状；再下一层检测这些组合构成的物体局部；如此层层递进。

另一种更精明的构建特征提取器的方法是 `SVM`，这是伊莎贝尔·居永（自 2015 年起在奥赛^[〔1〕](part0056.html#note36n) 任教授）的发明，其合作者弗拉基米尔·瓦普尼克和伯恩哈德·伯泽尔都是我在贝尔实验室时的组成员。1995—2010 年，`SVM` 一直是分类最常用的方法。我对朋友和同事心怀敬意，但必须承认我本人对该方法并不特别感兴趣，因为它并未解决特征提取器自动训练的关键问题。不过 `SVM` 方法吸引了大批关注。

`SVM` 是核机器的典型代表。虽然支持者不喜欢做对比，但本质上它就是一种两层神经网络。第一层单元数与学习集合中的样本数相同，第二层像普通感知器一样做加权和计算。第一层单元借助核函数 `k(x,q)`，把输入 `x` 与所有学习样本 `X[0]`、`X[1]`、`X[2]`、…、`X[p=1]` 做“比较”，式中 `x` 代表输入向量，`q` 是一个学习样本。例如第一层单元号为 3，则输出 `z[3]=k(x,X[3])`。

一些数学专著的主题就是探讨这些极简单的模型，数学之美掩盖了方法的局限，因而吸引研究者，使得 `SVM` 与核方法大行其道。虽有一定成果，核机器并没有比感知器强大多少，我与同事曾试图用这一点说服同行，但未果。部分人仍不相信多层架构的有效性，其中包括弗拉基米尔·瓦普尼克。

不管怎样，在 20 世纪 90 年代中期样本数量不多的情况下，`SVM` 确实可靠且易于操作。而且当时正值互联网初期，`SVM` 程序开放源代码，可免费使用。它“新且好”，很快获得成功。在 20 世纪 90 年代，核方法使神经网络黯然失色，多层网络的使用在人们脑海中渐渐消失。

但增加一层或多层人工神经元可以计算单层神经元难以有效计算的更复杂函数。数学定理表明，仅需两层神经元就能进行任意计算，这也是 `SVM` 能够成功的原因之一。只不过需要庞大的中间层。正如我们看到的，第一层神经元数量远大于原始图像像素数，即使输入是 25 像素的小图像，也可能需要数百或数千个神经元处理。

20 世纪 60 年代的研究者总是困惑于多层网络的训练。在感知器的学习过程中，只有最后一层经过训练，特征提取器的第一层无法训练，必须手工确定。
