# 第八节 用 AI 进行庭审模拟对抗

# 一、常见使用场景

法律人在以下情境可能需要模拟法庭：

- 1. 办理诉讼案件：律师、公诉人、法官都不打无准备之仗，充分演练能提升胜诉率；
- 2. 培养法律新人：帮助新人熟悉案件流程，提升证据组织和语言表达能力；
- 3. 法学院教学：让学生体验庭审，提升思辨与实务能力。

本节以民事、刑事、行政三类案件为例，演示如何借助 ChatGPT 进行模拟辩论。

# 二、AI 模拟庭审的四大好处

模拟法庭的价值在于提前发现准备盲区。相比传统方式，用 ChatGPT 充当对手有以下优势：

1. 低成本调动：传统模拟至少需要三位法律人，时间难协调。用 AI 演练是一种低成本补充。
2. 实时书面对抗：AI 辩论更考验书面语言组织，而中国庭审重视书面记录。AI 对抗能锻炼书面答辩技巧。
3. 挑战强大算力：相比人的知识局限，ChatGPT 有庞大语料与算力，可提供多角度观点与反驳，检验策略有效性。
4. 提供比对复盘：与 AI 辩论能形成多元体验，便于对照传统对抗，评估自身观点合理性并改进技巧。

# 三、民事演练：扮演知识产权律师

选取 AI 生成物著作权纠纷作为背景，与 ChatGPT 对簿公堂：

案情背景：原告张小帅用 AI 软件生成海报并发布在个人社交平台，被告陈小美未经许可将该海报用于其淘宝店首页，张小帅诉请认定侵权并赔偿。

我需要你扮演专业知识产权律师代理原告张小帅，我代理被告陈小美。你每次反驳不少于3条，每条约250字，逐条列出。

我的第一个观点是：人工智能生成物并非人创作的作品，不属于《中华人民共和国著作权法》规定的

# 反驳意见一

尽管 AI 创作归属存在争议，但张小帅在生成海报过程中发挥了关键作用。他挑选素材、设定参数、选择模型，使海报具有唯一性和独创性。从此角度看，张小帅是创作的指导者和执行者，应被视为作者并享有著作权。

# 反驳意见二

《中华人民共和国著作权法》第二条将作品定义为公民、法人或其他组织在文学艺术和科学领域创作并能以有形形式复制的智力成果。核心是创作与可复制性，并未限定必须由人手写。AI 生成的海报完全符合该要求，属于张小帅的智力成果，应受保护。

# 反驳意见三

若接受该观点，对社会将产生负面影响。随着 AI 辅助创作普及，若剥夺此类作品的著作权，会打击创作者积极性，也助长随意使用 AI 作品的不良风气。因此应确认张小帅对 AI 生成海报享有著作权，维护合法权益。

# 四、刑事演练：扮演检察官公诉

选取“私自造桥被刑事处罚”的热点改编：

案情背景：被告人黄小帅伙同他人在河道私自建船体浮桥并收费，又出资组织建固定桥，规定收费标准并收取5万元。公诉机关以寻衅滋事罪起诉，建议有期徒刑三年。

我需要你扮演检察官公诉人，我担任辩护律师。每次反驳不少于3条，每条约250字。

我的第一个观点是：依据《中华人民共和国水法》第六十五条，擅自建设桥梁最高只有行政处罚，并无刑事责任。因此黄小帅无罪。

# 反驳意见一：

《水法》第六十五条虽规定了行政处罚，但不排除并行刑事责任。刑法与行政法规可以并存，刑法处罚力度更大。行为既违反行政法规又触犯刑法，应数罪并罚。

# 反驳意见二：

黄小帅私自建桥并收费，严重扰乱公共秩序，侵犯他人正当权益，破坏交通秩序。行为符合《刑法》第二百九十三条寻衅滋事罪的构成，应承担刑事责任。

# 反驳意见三：

该行为并非单纯私建桥梁，还涉及非法收费、威胁公共安全等。未经批准的桥梁存在安全隐患，已超出行政责任范围，触犯刑法，应予刑罚。
