# 第2章 GPTs核心能力全解析

##2.1 无代码时代：人人都能造应用

搭建 GPTs 完全不需要写代码，这就是常说的无代码开发。

过去大家普遍认为只有程序员才能做应用，而会编程的人在全球人口中占比不足 1%。随着工具进化，预设模板、可视化编辑、拖拽交互等能力让非技术用户也能动手做网站、做 App。

咨询机构 Gartner 预测，到 2025 年约 70% 的软件应用将基于无代码或低代码技术实现。

相比传统编码开发，无代码有明显优势。

1. 周期更短。传统 App 开发动辄三到六个月，无代码工具几小时就能跑出基础可用版本。
2. 成本更低。招一个程序员月薪至少上万，还要配合产品设计、交互设计、测试等环节。无代码工具可让一人闭环完成，大幅压缩费用。
3. 验证更快。原型能迅速上线，先用最简版本测试市场真实需求。
4. 调整灵活。拖拽式界面让细节修改变得很轻便。

当前主流无代码平台有国外的 Bubble、Glide、Stacker、Webflow，国内则有 Zion、明道云等，如图2-1所示。

[PRE5]

图2-1 国内无代码代表——Zion

这些工具虽降低了门槛，学习成本依然存在。相对而言，基于 GPTs 的开发门槛更低。用户无需懂代码，像聊天一样描述想要的应用类型，几分钟就能完成基础搭建。

虽然现阶段 GPTs 在功能深度和交互体验上与手机 App、小程序还有差距，但随着大模型持续进步，编程不再是普通人造应用的拦路虎。更重要的是先找到明确的目标用户和使用场景。

##2.2 三种共享模式：从私用到公开

GPTs 提供三种分享方式：仅自己可见、链接可见、公开，如图2-2所示。

链接可见。适合团队或小圈子内部分享。只有拿到链接的人能访问，且不会上架到官方商店。例如一个项目助手 GPT，团队成员通过链接就能用来整理会议纪要、撰写报告、制定工作计划。

公开。如果应用不涉及隐私资料上传，就可以开放给所有人使用。这样既可能获得收益，也能提升创作者知名度。但公开前务必检查是否误传了隐私信息，如姓名、电话、邮箱等。我的 GPT 页面示例如图2-4所示。

##2.4 知识库学习：让GPT会模仿

GPTs 与普通 ChatGPT 的关键差异在于支持上传文件作为参考资料，回复前会先学习这些资料。

学习后，GPT 能更精准地模仿文案风格、从资料中提取相似信息、调用更专业的术语。

风格模仿：把爆款文案、爆款脚本等上传，让 GPT 在每次输出前先学习其风格，从而复刻同款写法。

信息提取：把公开整理的积极心理学资料上传，搭建一个基于该知识的 GPT。用户提问时，答案直接从资料库中抽取。

专业术语：做翻译类 GPT 时，整理行业术语表上传。翻译前先对照术语表，可显著提升准确率。

比如想做小红书爆款文案 GPT，先收集标题、正文案例作为参考资料上传，让它学习写作套路，如图2-17所示。
