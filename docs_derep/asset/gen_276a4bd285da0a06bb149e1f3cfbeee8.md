## **5.1**

## **大数据概述**

大数据是指规模、增速与种类均已超出传统数据处理软件在合理时间内采集、管理和处理能力的数据集合。该定义揭示了大数据的关键特征，通常概括为“3V”模型，即 Volume、Velocity 和 Variety，三者构成最基础的核心特征。

（1）Volume 海量：指数据规模的巨大性。衡量单位已从 GB 或 TB 躍升至 PB 乃至 EB 级别。

（2）Velocity 高速：指数据生成与流转的瞬时性与持续性。不仅产生速度极快，也要求处理与分析具备近乎实时的响应。

（3）Variety 多样：指数据类型与来源的广泛性与复杂性。不仅包括结构化数据，还涵盖文本、图像、视频、音频及日志等非结构化与半结构化数据。

三大特征共同构成大数据时代区别于传统处理的根本挑战。随着数据科学演进，业界认识到“3V”已不足以全面描述大数据的复杂性。因此学界与业界相继增补新维度，其中 Veracity 真实性 与 Value 价值 获得了最广泛认同，形成了“5V”模型，如图 5-1 所示。
