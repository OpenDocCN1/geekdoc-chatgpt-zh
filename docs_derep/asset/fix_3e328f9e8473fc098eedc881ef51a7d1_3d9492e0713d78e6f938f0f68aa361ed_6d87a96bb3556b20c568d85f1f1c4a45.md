# Unsloth 加速医学推理微调实战

在单卡显存受限的环境下，把一个通用基座改造成具备链式推理能力的医学问答模型，核心思路是用 Unsloth 加速的 LoRA 方案，对公开的 medical-o1-reasoning-SFT 语料做指令式微调。整体流程可分成模板构建、数据整理、低秩适配、训练调度与推理校验五步，思路清晰且方便复现。

模板与数据整理
先把任务描述、专家角色、问题占位和答案占位拼接成统一的指令格式，并在末尾补上结束符。预处理函数读取原始表的 Question、Complex_CoT、Response 三列，组装成模型可直接消费的文本。

train_prompt_style = """Below is an instruction that describes a task, paired with an input that provides further context.

Write a response that appropriately completes the request.

Before answering, think carefully about the question and create a step-by-step chain of thoughts to ensure a logical and accurate response.

### Instruction:

You are a medical expert with advanced knowledge in clinical reasoning, diagnostics, and treatment planning.

Please answer the following medical question.

### Question:

{}

### Response:

{}"""

EOS_TOKEN = tokenizer.eos_token  # Must add EOS_TOKEN

def formatting_prompts_func(examples):

    inputs = examples["Question"]

    cots = examples["Complex_CoT"]

    outputs = examples["Response"]

    texts = []

    for input, cot, output in zip(inputs, cots, outputs):

        text = train_prompt_style.format(input, cot, output) + EOS_TOKEN

        texts.append(text)

    return {

        "text": texts,

    }

低秩适配器设定
通过 FastLanguageModel.get_peft_model 注入 LoRA，秩设为 16，alpha 16，dropout 0。覆盖的投影包括 q_proj、k_proj、v_proj、o_proj、gate_proj、up_proj、down_proj 七组，采用 unsloth 模式的梯度检查点，随机种子固定为 3407。

训练调度
使用 trl 的 SFTTrainer，文本字段为 text，序列长度由 max_seq_length 控制，并行处理数为 2。TrainingArguments 配置单卡每步 batch 2，梯度累积 4 等效全局 batch 8，训练 3 个周期，预热 5 步，学习率 2e-4，fp16/bf16 按硬件自动选择，日志间隔 10，优化器 adamw_8bit，weight_decay 0.01，线性学习率调度，seed 3407，输出目录 outputs。
