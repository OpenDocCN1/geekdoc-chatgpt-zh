大语言模型属于机器学习家族中的一个分支，底层普遍采用 Transformer 架构的深度神经网络 [10]。其核心训练目标是下一个词的预测。早期阶段这种预测基本依赖于词的分布概率；随后训练流程引入了额外的人工反馈来塑造奖励函数，使模型在概率之外还要兼顾指令遵循、安全等目标 [15]。围绕因果能力的探索也在进行 [859]，例如文献 [858] 构建了由 3 到 4 个节点构成的简易图结构，检验模型能否把该结构还原到正确形式。研究者逐对考察变量 A、B，要求模型对两条竞争性表述打分，一条暗示 A 导致 B，另一条暗示 B 导致 A。文献 [839] 采用更具挑战性的医学疼痛诊断数据，发现基于 LLM 的诊断准确率偏低。

因果发现指的是学习变量间因果关系结构的任务 [848]。通常输出是一个有向图，边既表明因果效应的存在，也标明方向。该图刻画了数据生成机制的本质特征，说明一个变量的变化如何传导至其他变量。此后该图会作为效应推断、预测或归因等下游分析的基础。选用正确的图来编码因果假设，是保证下游分析可靠的前提。换句话说，因果发现是所有因果相关任务的根基。

难点在于，仅凭观测数据很难得到唯一正确的图。因为在同一数据分布下，存在多个结构等价的图，它们构成马尔可夫等价类 [811]。过去二十年里出现过两类主流对策。第一类是把数据生成过程限定为特定函数形式，从而实现可识别 [852]。例如在线性生成过程上叠加非高斯噪声 [860]，或假设所有函数均为带加性噪声的非线性形式 [861-862]。即便如此，线性方程加高斯噪声等简易情形仍不可识别。第二类是借助深度学习联合建模所有变量的协方差，期望提升学习图的质量。然而识别问题并未得到根本解决，因而在真实世界数据集上最前沿因果发现方法的表现仍令人意外 [863-864]。LLM 的新思路在于关注变量相关的元信息而非变量本身的数据取值。这与人类领域专家在构建因果图时依赖的元数据推理方式相似。

### 5.2.5 多模态因果开源框架 CausalVLR

CausalVLR [865] 由中山大学人机物智能融合实验室 HCP-Lab 搭建的多模态因果开源系统，面向因果发现与因果推理，采用 Python 实现，覆盖 AIGC、问答推理、图像视频标注、模型泛化与鲁棒性分析、具身交互、医疗问诊与决策等多种典型多模态认知推理任务。目前它是唯一面向多模态认知推理的因果推理开源框架，提供丰富的案例、基座模型、模块插件与模型仓库，支持灵活配置各类多模态因果推理方法并提供长期技术支持。

CausalVLR 框架具备以下关键特质。

#### 1. 统一结构
CausalVLR 搭建了多模态因果推理模型的统一代码骨架，支撑多类典型多模态任务，如图 5.6 所示。已开源因果自洽思维链推理、视觉问答、医学报告生成、医疗问诊和模型鲁棒性的示范案例。系统将视觉语言任务的因果范式拆分为可组合的组件，通过不同组件的组合，研究人员可快速搭建定制化的因果推理框架，如图 5.7 所示。此外还提供海量数据集和预训练模型供参考。

#### 2. 通用模块插件
CausalVLR 支持因果干预、因果关系、反事实推理、因果图生成等通用模块插件。开发者可参照通用模块的开发教程与代码，迅速部署相关模型。

#### 3. 灵活配置
CausalVLR 提供多类多模态任务基座模型，通过修改配置文件即可完成指定任务模型的实现，如图 5.8 所示。各基座模型会定期更新以保持时效性。

#### 4. 交互式推理
CausalVLR 采用统一定制的模块结构，仅需数行代码即可完成模型部署与验证，并提供可视化 UI 用于监控与校验效果。系统提供交互式推理过程，可呈现因果推理的动态变化。如图 5.9 所示，已实现问答推理任务的因果干预可视化、医学报告生成任务的因果干预可视化、因果关系发现基座模型生成因果图，以及因果自洽的交互式思维链推理过程可视化，便于技术人员直观调试模型，推动多模态因果推理技术与社区发展。

## 5.3 世界模型

2022 年 6 月，被誉为卷积神经网络之父的 Yann LeCun 提出世界模型概念 [866]，并抛出三个长期难以解答的问题。

- （1）机器如何像人类和动物那样高效学习？
- （2）机器如何学会推理与规划？
- （3）机器如何在多重抽象层级上学习感知与行动规划的表征，以在不同时间跨度内执行推理、预测与规划任务？

Yann LeCun 并未否定当代 AI 的价值，他认为 AI 在与训练数据对应的特定领域如翻译、图像识别上依然非常实用。但就以 GPT、BERT 为代表的 LLM 而言，他认为其本质是自回归生成模型。大致流程是先预测序列的下一个 Token，再把预测结果加入序列继续预测下一个。Token 可以是文本、图像块或语音片段等。Yann LeCun 指出，由于现行 LLM 大多仅在文本上训练，对世界的理解相当浅表。即便在大规模参数与数据的加持下展现出强大的文本理解能力，捕捉到的仍是文本的统计规律，而非文本在现实世界中真正的含义。这种底层现实知识的缺失会导致模型出错，有时错误十分离谱。他认为若模型能利用更多感官信号如视觉来学习世界运行规律，则能更深刻地理解现实。这也是他更关注图像、音频等多模态研究的原因。本节介绍世界模型概念及基于该思想设计的模型。

### 5.3.1 世界模型的概念

人类与动物似乎能够通过观察与少量互动，以任务无关、无监督的方式积累大量关于世界运行的背景知识。可以假设这些累积的知识构成所谓的常识。常识可视为世界模型的集合，能告诉智能体什么可行、合理或不可行。借助世界模型，动物能在少量训练后学习新技能。智能体可以预测自身行为的后果，进行推理、规划、探索并想象问题的全新解法。更重要的是，它们能在面对未知情境时避免危险错误。

人类、动物与智能系统使用世界模型的观念在心理学中已有悠久历史 [867]。自 20 世纪 50 年代起，将预测世界下一状态的前向模型作为当前状态或即将发生行动的函数，已成为最优控制的标准做法 [868]，即模型预测控制。在强化学习中使用可微世界模型的做法曾长期被忽视，但在 LLM 时代正重新兴起 [869]。一辆自动驾驶汽车可能需要数千次强化学习训练才能理解“转弯时车速过快会打滑”并学会减速。相比之下，人类凭借对物理世界的掌握即可预测该结果，在学习新技能时规避大部分致命行为。

世界模型正是关于认识世界的抽象概念与感受的集合，无需专门训练即可自发认知常识。如图 5.10 所示，婴儿在早期认知中仅通过非任务特定的感知即可完成对世界的认识 [866]，在此基础上结合简单的先天行为与内在动机快速学习新任务。

常识不仅可用于预测未来结果，还能填补时空上的信息缺口。因此 Yann LeCun 认为可设计能在无监督或自监督方式下学习的世界模型，并借助这些模型进行预测、推理与规划。其核心技术难题是如何设计可处理复杂不确定性任务的可训练世界模型，为此他提出了图 5.11 的世界模型框架。

假设框架中所有模块均为“可微”，即把一个模块的输出送入另一个模块可获得关于自身输出的梯度估计，下面分别说明各模块。

- （1）**配置器模块**：汇总来自其他所有模块的输入，通过调节参数与注意力回路为当前任务进行参数配置。具体可激活感知器、世界模型与代价模块以满足特定任务需求。
- （2）**感知器模块**：接受配置器的信号以估计当前世界状态。但在特定任务中，感知到的状态中只有一小部分相关且有用。因此配置器会预先调节感知系统，从感知器中提取与当前任务相关的信息。
- （3）**世界模型模块**：架构中最复杂的部分，承担两项功能：补全感知器提供的世界状态缺失信息，并预测合理的未来世界状态。它既能预测世界的自然演化，也能预测执行器提出的一系列动作所导致的状态。这些状态由表征世界状态不确定性的潜变量参数化。哪些状态方面相关取决于当前任务，因而配置器会让世界模型在包含任务相关信息的抽象表征空间内进行缺失信息或未来状态的预测。理想情况下，世界模型应能决定世界状态的多重抽象层级表征，从而在多时间尺度上进行预测。实现的关键在于世界模型必须能表示多种可能的预测，而自然界并非完全可预测，尤其是其中可能存在具有对抗性的其他智能体。即使世界仅包含混沌行为或状态不完全可预测的无生命物体，仍需解决两大问题：如何让世界模型进行多轮合理预测并表征预测中的不确定性，以及如何训练世界模型。
- （4）**代价模块**：以能量这一标量量化智能体的“不适感”。能量由两个子模块之和构成，分别是内在代价模块与可训练的评价者模块。智能体的整体目标是采取行动，使自身处于能最小化平均能量的状态。内在代价模块不可变、不可训练，计算内在能量标量，用以衡量瞬时“不适感”——可理解为痛苦、高内在能量；愉悦、低或负内在能量；饥饿等。其输入可以是感知器对当前世界状态的理解，或是世界模型预测的潜在未来状态。智能体的最终目标是长期最小化内在代价，这构成基本行为驱动与内在动机。内在代价模块的设计决定了行为性质，例如鼓励四足机器人行走时感觉“好”、与人类互动以激励社交时感觉“好”、察觉他人喜悦以激励共情时感觉“好”、能量充足时感觉“好”、经历新情境以激发好奇与探索时感觉“好”、履行特定计划时感觉“好”等，此时能量较低。反之，面对痛苦或易识别的危险如极端高温、火灾，或使用危险工具时，能量会升高。一方面内在代价模块可被配置器调制以在不同时刻驱动不同行为；另一方面可训练的评价者模块用于预测未来内在能量的估计值。其输入同样可以是当前世界状态或由世界模型预测的可能状态。训练时，评价者模块从短期记忆模块中检索过去状态，并从代价模块中获取对应的内在代价，通过前者训练自己预测后者。代价模块的两子模块均可微，能量的梯度可通过其他模块反向传播。
- （5）**短期记忆模块**：存储过去、当前与未来世界状态相关信息，以及对应的内在代价价值。世界模型在时间上预测未来的世界状态，同时在空间上找回当前状态的丢失信息或纠正不一致信息，访问并更新短期记忆。世界模型可向短期记忆发送查询指令并接收检索值，或写入新的状态值。评价者子模块可通过从记忆中检索过去状态及其内在代价进行训练。该结构类似著名的键值记忆网络 Key-Value Memory Network [870]。
- （6）**执行器模块**：计算一系列动作的提案，并将首个动作或短期动作序列输出给执行器，此过程为循环迭代。世界模型根据动作序列预测未来状态序列并传递给代价模块。代价模块估计与所提动作序列相关的未来能量。执行器可访问估计成本相对于候选动作序列的梯度，因而可用基于梯度的方法计算使估计成本最小的最佳动作序列。若动作空间离散，则可用动态规划寻找最优序列。优化完成后，执行器输出首个动作或短期动作序列。该过程类似最优控制中的模型预测控制 [868]。

### 5.3.2 联合嵌入预测结构

Yann LeCun 认为训练世界模型是自监督学习的一个典型案例，基本思路是利用有限的感知信息预测未来输入或未观测输入。然而存在三个待解决问题。

- （1）世界模型的质量取决于状态序列的多样性。
- （2）世界并非完全可预测，即在当前执行器动作提案下可能存在多个合理的世界状态。
- （3）世界模型须能在不同时间尺度和抽象层次上做出预测。

为此他提出联合嵌入预测结构 Joint Embedding Predictive Architecture, JEPA，如图 5.12 所示。

JEPA 并非生成式模型，不能轻易用来从 x 预测 y。它仅捕捉 x 与 y 间的依赖关系，而非显式生成 y。图 5.12 中两个变量 x、y 分别输入两个编码器得到表征 s_x、s_y。两个编码器可以不同，无需同构也不必共享参数，这使得 x 与 y 本质上可以不同，例如视频与音频。预测模块基于 x 的表征预测 y 的表征，可能依赖潜变量 z。此处能量只是表征空间中的预测误差：

E_w(x, y, z) = D(s_y, Pred(s_x, z)) (5.10)

通过对 z 最小化得到总能量：

\hat{z} = arg min_{z in Z} E_w(x, y, z) = arg min_{z in Z} D(s_y, Pred(s_x, z)) (5.11)

F_w(x, y) = min_{z in Z} E_w(x, y, z) = D(s_y, Pred(s_x, \hat{z})) (5.12)

JEPA 的主要优点是可在表征空间中进行预测，无需还原 y 的每个细节。Enc(y) 为抽象表征提取函数，可消除无关细节。为表征状态序列的多样性，s_y 作为不变部分，潜变量 z 作为条件即执行器的动作。此外 JEPA 可采用非对比式方法训练，可由以下四条准则实现。

- （1）s_x 应最大化提供关于 x 的信息含量。
- （2）s_y 应最大化提供关于 y 的信息含量。
- （3）s_y 应更容易从 s_x 预测出来。
- （4）最小化用于预测的潜变量 z 的信息含量，以表征不确定性。

准则（1）（2）（4）共同防止能量模型崩溃：准则（1）（2）保证 s_x、s_y 携带更多与输入相关的信息，确保准则（3）能在表征中正确预测 \hat{s}_y；准则（4）通过让 z 离散、低维、稀疏或带噪声，迫使模型在尽可能少的潜变量帮助下预测 \hat{s}_y，使模型无法忽略 s_x。

此外 JEPA 学习的是使世界可预测的抽象表征，而不可预测细节被编码器消除或由 z 表征，因而可分层堆叠以对世界状态的更粗略描述进行长期预测，即 Hierarchical-JEPA。以驾驶汽车为例，基于接下来几秒的方向盘与踏板操作步骤，驾驶员可准确预测一段时间的轨迹；在更长时间尺度上轨迹细节难以预测，但驾驶员仍可在更高层次准确预测：忽略细节、其他车辆、信号灯等影响，汽车将在可预测的时间内到达目的地。该层面的描述省略了详细轨迹，但可保留地图上的大致路线。可使用离散潜变量表征多条备选路线。

提出 JEPA 理论概念后，Yann LeCun 在计算机视觉领域验证世界模型并提出基于图像的联合嵌入预测结构 Image-based Joint Embedding Predictive Architecture, I-JEPA [871]，如图 5.13 所示。

I-JEPA 核心思想简明：利用单一样本上下文信息预测同一图像中各类目标图像块的表征。为引导 I-JEPA 生成语义表征，核心设计是掩码策略：选取尺度足够大具语义的目标图像块，以及信息足够丰富、空间分布广泛的上下文图像块。与 JEPA 中的 z 类似，I-JEPA 随机采样 4 个目标块掩码，尺度范围在 (0.15,0.2)，长宽比在 (0.75,1.5)。这 4 个掩码可作为提示帮助预测器预测对应区域的语义表征，并保证世界状态多样性。结合 ViT 使用时，Yann LeCun 发现 I-JEPA 具有很强可扩展性。例如在不到 72 小时内用 16 块 A100 GPU 在 ImageNet 上训练 ViT-Huge/14 模型，在线性分类、物体计数、深度预测等下游任务上表现强劲。与 MAE [7]、CAE [872]、iBOT [873] 相比，I-JEPA 在更低计算成本下取得更好表征学习效果。

I-JEPA 预测空间上缺失的信息，而世界模型亦可在时间上预测未来状态。过去自监督视觉表征多专注于学习内容特征，未捕获物体运动信息或位置，侧重识别与区分。另一方面光流估计任务不涉及对估计所依赖图像内容的理解。Yann LeCun 将两者统一，提出运动-内容联合嵌入预测结构 Motion-Content Joint-Embedding Predictive Architecture, MC-JEPA [874]，见图 5.14，用于在共享编码器内联合学习光流与内容特征，证明光流估计目标与自监督学习目标可相互受益，从而学习包含运动信息的内容特征。该方法在现有无监督光流基准及图像视频语义分割等下游任务上取得与常见自监督方法相媲美的性能。
