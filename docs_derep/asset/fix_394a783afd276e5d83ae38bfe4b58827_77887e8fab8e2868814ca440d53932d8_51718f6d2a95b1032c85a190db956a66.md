资讯供给呈爆发式增长并被多层筛选机制重塑的语境里，受众在加工信息时为追求效率，往往会出现对确定性答案的心理依赖，这种倾向可归为认知闭合需求。依据该需求的强度，受众可划分为强依赖型与弱依赖型，前者强烈追求明确结论，后者相对能够容忍模糊与开放。在加工流程中，认知闭合可拆分为抢占与固化两个环节，前者体现紧迫性，后者体现稳定性。抢占期受众并无清晰目标，倾向迅速形成初步推断；固化期则在既有推断基础上维持原有认知。认知闭合究竟指向何种内容选择？是偏好一致信息还是冲突信息？对框架的依赖程度如何？在供给过剩叠加算法过滤的情境下，认知闭合压力使新闻生产者面临更高要求。

新工具与新载体的持续涌现使资讯环境愈发复杂，随信息权力下放，大量冗余内容占据平台，新闻从业者的专业价值因此被重新凸显。移动终端与网络的融合延伸了传播链路，传统筛选手段在新形势下已难奏效。在技术与生态剧烈变动的背景下，新闻专业规范对实践仍具重要意义。如今进入传播生态的主体日益增多，新闻业的传统边界被消解，但边界的瓦解并不意味着从业者消失，反而对从业者提出更高诉求，召唤专业主义在新语境下回归。数字时代，专业主义从纯粹专业性转向介入性，探索协同式生产以推动议题落地，构建更具建设性的专业主义，有助于多主体在协同环境中实现协调发展。

#### 协同主体分析

##### 1. 新闻工作者
生成式系统是对新闻从业者的一次重大能力增强。传统生产强调时效，人类在时效维度长期落后于机器，尤其在早期的写作机器人阶段，机器已在体育、财经等对时效要求极高的领域替代普通记者。以 ChatGPT 为代表的生成式系统内容生成水准已超出社会平均，且 AIGC 文本与人工创作的差异正不断缩小。从业者可依据实际需要为系统设定情境、语气、风格等参数以调节稿件调性，不过生成式系统的产出本质仍是基于海量数据的统计规律，缺乏对现实世界的深刻理解与独特洞察。

##### 2. 新闻消费者
提示技巧已成为新形势下人人需要掌握的核心技能，受众同样应学会运用该能力以提升阅读便捷性、在场感与沉浸度，即提升消费幸福感。面对纷繁报道，受众若想高效获取信息，离不开生成式系统的介入。未来生成式系统有望扮演智能管家角色，自行整合网络新闻并以用户自定义的样式汇报。有人担心由此产生信息茧房，但随着技术成熟，其内容生成机制有望从源头缓解该问题。目前生成式系统尚呈分散状态，未来文生文、文生图、文生视频、图生视频等路径将进一步整合，成熟系统将以多模态方式强化在场感与沉浸度。《伯尔尼公约》规定著作权不保护时事新闻或仅具新闻性质的事实。对媒体报道而言，大部分构成受著作权保护的作品，即使属于时事新闻，其采集者与制作者仍可能受反不正当竞争法保护。AIGC 新闻的著作权归属如何判定，目前学界尚无定论，有观点认为 AIGC 内容不受著作权法保护。若从生成文本前一环节的提示工程师介入视角看，从业者作为提示工程师参与 AIGC 生产，贡献了想法与高质量提示词。从鼓励创新的角度，部分 AIGC 新闻的著作权或可归于提示工程师。随着生成式系统与提示工程的完善，著作权归属将在司法实践中逐步明确。但当前新闻管理者需加强对扮演提示工程师角色的从业者监管，避免低质量、虚假新闻扩散。

#### 协同过程分析
传统协同视角并不完整，多集中于生产环节，多名记者围绕同一主题协同报道。新闻生产由封闭形态转向共同参与、协同生产的活动，新闻把关人以开放合作、广泛参与的方式开展生产。迭代式生产的“新闻游戏”印证了新闻生产走向社会协同的趋势。未来生成式系统将深度赋能新闻生产的协同。

在生成式系统浪潮下，AIGC 将引发生态级变局。其一推动生产权力、传播权力、审核权力进一步下沉，让大众在生产、消费、管理等环节拥有更多平等机会与权力，与分布式社会的权力结构相匹配；其二推动新闻生产、消费、管理全流程逻辑的智能化，在算法、算力、算据全覆盖的过程中，传统倚重的专业经验将逐步让位于便捷、高效、精准、全面的人工智能，进一步提升协同发展与治理水平。

### 第四节 生成式AI浪潮下新闻工作者的逻辑重构

#### 未来新闻工作者的赋能价值
未来新闻从业者将扮演提示工程师角色，借助生成式系统革新传统生产与分发模式。以 ChatGPT 为代表的技术整合信息检索、对话与内容生成，可帮助从业者高效获取采访对象信息、了解背景、撰写提纲、生成或润色文本。当前生成式系统不同于新闻写作机器人，既能高效生成体育、财经新闻，也能撰写深度报道。其潜能的挖掘离不开提示工程师，高质量提示词能激发意想不到的效果。随着技术介入程度加深，系统与从业者分工将更细，重复性、简单性工作交由系统，认知资源密集型工作由从业者承担。生成式系统未来将取代搜索引擎，成为新的流量入口与分发渠道。ChatGPT 等系统具备理解文本指令、多轮对话、主动认错、提出质疑、认知自身边界的能力，在很大程度上模拟了人际交流。如今重返部落化时代的用户与这种模拟人际交流高度契合。

## 第六章 生成式AI对重要传播内容的生态赋能与价值迭代
纵观传播发展脉络，媒介正渗透社会结构与文明进程。从 Web 1.0 到 Web 3.0，人工智能、关联数据与语义网络构建了人与网络的全新链接，内容消费需求快速增长。若仅将生成式系统视作功能性信息载体，便忽视了其作为能动力量对社会知识传播与社会结构完善的重要价值。保罗·莱文森从心物互动视角论述，技术除主要功能外，还是人类理性与幻想力追求知识的物质载体。没有技术，人类知识将无处依托。当下智能化、网络化、互动化的传播技术加速了社会知识生产与传播流程，知识媒介功能得到前所未有的凸显。1986年马克·斯特菲克提出知识媒介概念，用以描述人工智能与互联网结合后的后果。知识媒介将焦点由知识产品转向知识生产过程，为知识生成、传播、消费提供半自动化服务的信息网络，其特点是标准化交流语言与交互式数字媒介对知识的表征。在宏观层面，知识媒介作为平台为人类社会的知识管理与交流提供场域。塞缪尔·N. 艾森斯塔特认为理想化的知识媒介用于捕获、存储、传输、共享、访问与创造知识。简言之，知识媒介可为系统亦可为网络，凸显技术与知识的相互依存。

从可供性看，生成式系统可视为知识媒介的典型形态，不仅是社会知识传播的载体与渠道，还能在发展中形成新的传播主体、新组织逻辑与新建构力量，影响获知与求知模式。作为知识媒介的生成式系统为理解传媒行业的生态重塑与价值迭代提供新视角。

随着智能终端普及，短视频成为数字时代最受欢迎的媒体形式之一。短视频在日常生活知识分享与知识显性化方面不断拓展边界，其生成与发布在生成式系统助推下形成新颖方式。2023年1月，美国奈飞公司发布实验性动画短片《犬与少年》，部分内容由生成式系统完成。可见生成式系统已成为 Web 3.0 时代全新的内容生产工具。作为知识媒介的生成式系统具有何种特性？该特性如何从底层逻辑赋能短视频信息生态？本研究结合信息生态学视角，提出生成式系统赋能短视频“异构资源整合-竞争演化关系-信息生态繁衍”的底层迭代逻辑，以把握短视频在技术赋能、赋权、赋魂机制下的社会革命，进一步审视生成式系统作为一种知识媒介对短视频生产的作用。

### 第一节 生成式AI型塑短视频信息新生态
新技术的出现都有历史逻辑，反映技术演变规律。生成式系统的应用不仅为个体提供创作新工具，也在一定程度上重塑日常生活，信息与知识获取与学习密切相关。作为知识媒介的生成式系统利用人工智能学习知识图谱、自动生成内容，不仅提升生产效率、丰富多样性，也为知识经济发展提供动力。生成式系统赋能短视频生产实现三方面功能：一是内容孪生，帮助快速建立现实世界到数字世界的映射；二是内容编辑，实现现实世界与数字世界双向交互，系统学习现实信息图谱并反作用于数字信息生产；三是内容创作，将算法驯化为创作工具，使其具备自我演化能力。综上，生成式系统既是信息生产者，也是信息生产方式，更是信息自动化生成的技术集合。由此塑造短视频信息新生态。

#### 整体协调与局部协调的统一
基于技术原理，生成式系统在短视频信息生产上具天然优势。其一赋能内部运行机理协调，其二实现人与机器的整体协调，使思想、经验、方法的交流成为可能，并通过信息通信技术聚集知识。

从局部协调看，首先是自动化的信息生产协调。预训练模型提升了系统的工业化水平与普遍化能力，同一模型可高质量完成多样化内容生产。同时生成式系统带来多模态信息融合与感知。随着算法迭代，人借助多通道与计算机的感官融合加深，多模态融合、跨模态生成、智能场景落地成为新方向。

从整体协调看，人与机器交互能力在短视频生产中提升。当前技术社会是“联结的社会”，现代化本质是联结。在传统环境下，短视频生产依赖信息输入与输出，人、机器、环境彼此独立，互为工具，通过机械点击、触控实现交互。生成式系统加持带来更多样化协同交互，人机可通过文本、语音、视觉识别等形式完成传统生产过程，生成式系统成为人与机器沟通的媒介。

#### 长期发展与短期表现的统一
生成式系统赋能短视频非短期表现，其塑造的新模式、新机制将长期存在于信息生态。从人类使用短视频历程看，Web 1.0 时代接受平台内容，Web 2.0 时代参与内容生产，Web 3.0 时代将创造的数据与价值确权，形成自下而上向周边辐射的信息力量。在此过程中，生成式系统带来全新的人类组织协同方式“DAO”，其统一法则为整合、协和、融合。生成式系统模糊“人类要素”与“非人类要素”界限，成为信息生产场域的结构性要素。生成式系统技术超越单一线性话语生产框架，打通内容生产表征与非表征逻辑通道，在人类要素与非人类要素交互关系及技术、社会制度、社会文化的动态迭代中建立多维度、多元化、多向度的动力系统模式与面向未来的内容生产体系，使生产与传播更有价值。

短视频信息生产是传播系统再生产的重要部分，规则要素发挥重要作用，既决定短期表现，也决定生产到传播全流程，更确定信息社会的分布状态。安东尼·吉登斯将社会系统资源分为权威性资源与配置性资源。生成式系统更像配置性资源，以“非人类要素”身份平等进入信息生产主体。生成式系统赋能短视频生产本质是直接介入人类社会的信息生产，未来信息形态、格局、传递将在系统加持下发生短期变革，但从长远看，生成式系统作为强有力的非人类要素将直接介入生产，其社会长期效应更为显著。

### 第二节 基于知识媒介生成式AI赋能的质性描述
进化法则是所有客观事物的生命属性。生成式系统赋能短视频进化并非替代 PGC、UGC 生产模式，而是通过新技术融合与协同的补偿路径，将内容与技术连接补偿，解决一体化进化问题。从“空间-权力”关系视角看，生成式人工智能是一种“权力”媒介，通过不断创造涌现重新分配权力，其性质早已超出技术工具。

从知识角度看，生成式系统改变了短视频性质，短视频不再是对象，新内容的出现是过程而非产品，不在个人思想中产生，而在多要素相互作用中产生。生成式系统通过技术构造两条内容选择路径。其一外部选择，主要体现为用户选择与关联。符合用户需要的内容不断被选择使用，生成式系统拓展用户选择内容池，进而获得更多物质能量快速进化。生成式系统促进有机体与工具手段整合，扩大认识论层面交流潜力。同时因资源相互关联，生成式系统驯化的算法将更全面、更丰富的资源关联，生产更高质量内容。其二内部选择，主要体现在要素与关联网络的进化。在更高效生产模式下，短视频资源不断被修订、选择、编辑，优质要素与关联网络被筛选保留。该赋能选择具有很强创造性，不仅是内容优胜劣汰，更是强化关联网络优质基因，改善信息生态质量。在进化法则驱动下，生成式系统赋能短视频进化呈现渐进性、群智性、循环性三大特征。

#### 渐进性
