### 语音指令获取与交互逻辑实现

当语音识别模块捕捉到有效指令后，`asr.get_res()` 方法会返回对应的关键词编号，供后续逻辑判断使用。

[PRE0]python

def asr_test(sel): # 语音识别回调处理函数

    # 根据返回的编号执行对应的灯光控制动作
    if sel == 1:          # 指令：红
        led.red.on()
        led.green.off()
        led.blue.off()
    elif sel == 2:        # 指令：绿
        led.red.off()
        led.green.on()
        led.blue.off()
    elif sel == 3:        # 指令：蓝
        led.red.off()
        led.green.off()
        led.blue.on()
    elif sel == 4:        # 指令：开灯（全亮）
        led.red.on()
        led.green.on()
        led.blue.on()
    elif sel == 5:        # 指令：关灯（全灭）
        led.red.off()
        led.green.off()
        led.blue.off()

while True:
    # 循环轮询获取识别结果，并传入处理函数
