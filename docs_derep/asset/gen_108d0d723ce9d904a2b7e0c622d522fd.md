下面这套实现拆成两块来看，先是把人话转成设备能执行的标准化指令，再是用可配置的故障注入来检验多智能体在异常情况下的表现。

第一部分负责自然语言到设备命令的转换。定义了设备类型枚举，包含交通灯、摄像头、传感器、显示屏四类；用数据类封装设备命令，字段涵盖设备 ID、类型、动作、参数字典、优先级和超时毫秒。转换器在初始化时接收大模型客户端和设备注册表，并预加载命令模板。转换流程是异步的：先调用内部解析方法让大模型从指令文本和上下文中抽取目标、动作、参数、优先级等结构化信息，随后把目标映射到具体设备实例，最后按模板生成每台设备的标准化命令并返回列表。解析阶段的提示词明确要求输出 JSON 格式的 targets、action、parameters、priority。
