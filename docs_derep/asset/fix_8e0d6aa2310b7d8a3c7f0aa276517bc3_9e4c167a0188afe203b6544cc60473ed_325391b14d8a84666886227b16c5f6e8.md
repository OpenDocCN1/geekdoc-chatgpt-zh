# 让大模型学会中文新闻分类的小样本实践

通用模型要分清中文新闻类别，靠的不是更长的提示词，而是给它一批带标签的示范样本。下面的流程展示从数据准备到效果验证的完整链路，核心代码保持不变。

两种调用方式各有场景。补全接口适合 text-davinci-003，聊天接口适合 gpt-3.5-turbo，超参数保持一致，最后从返回的首个结果取出文本。如下实现聊天调用。

封装一个统一的 completion 调用，参数与前面保持一致。

[PRE16]
def complete(prompt: str, model: str, max_tokens: int) -> str:

    response = openai.Completion.create(

        prompt=prompt,

        temperature=0,

        max_tokens=max_tokens,

        top_p=1,

        frequency_penalty=0,

        presence_penalty=0,

        model=model

    )

    ans = response["choices"][0]["text"].strip(" \n")

    return ans

未适配时基座给出的类别偏向社会，适配后模型在简化提示格式下返回 agriculture，贴合农业新闻的语义。
