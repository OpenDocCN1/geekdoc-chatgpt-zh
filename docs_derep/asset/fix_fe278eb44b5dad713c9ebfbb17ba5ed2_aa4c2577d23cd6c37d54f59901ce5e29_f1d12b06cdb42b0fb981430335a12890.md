# **序言**

当今数据洪流席卷各行各业，从海量信息中提炼价值、把握趋势已成为共同诉求。人工智能的快速演进，尤其是以 ChatGPT 为代表的大模型突破，为数据分析带来全新变革。作为长期深耕数据科学与 AI 的研究者，得知文之易、蔡文青、屈秀伟合著《ChatGPT 数据分析（视频案例版）》付梓，倍感欣慰。作为计算机科学家，很荣幸为本书作序，共同探讨这一领域的新进展。

1980 年我进入清华大学计算机系，与数据科学结缘。从获计算机科学一级荣誉学士，到成为清华首批硕博连读，再到赴英帝国理工攻读计算逻辑博士并留校任教，每一步都凝聚着对本学科的热爱。学术生涯中，我致力于推动数据挖掘、机器学习与信息系统在生物学、化学、地球物理、医疗健康、环境、经济、金融、社交媒体、创意设计、安全等领域的落地，力图在科学海洋中发掘隐含价值。

科研之路荆棘遍布，每一次挫折都在锤炼意志。我参与并牵头多项国际重点项目，如英国 EPSRC 平台旗舰计划“发现网”Discovery Net、惠康信托基金支持的胰岛素抵抗生物图谱 BAIR，并持续引领香港生成式人工智能研发中心 HKGAI，聚焦多模态多语言大模型、垂直大模型及本地应用。这些经历印证了数据科学作为时代引擎，在加速科学发现与推动社会进步中的关键作用。

大模型日益成熟，ChatGPT 等生成式工具正重塑分析范式，以自然语言为桥梁，使分析不再局限于专业人士。其优势主要体现在三方面：

第一，免代码操作。无需编程背景，通过自然语言指令即可完成复杂任务。

第二，高效便捷。可快速清洗处理海量数据、执行各类分析、可视化、建模与报告撰写，大幅提升效率。

第三，灵活可扩展。支持个性化定制，可与其他分析工具协同，满足多元场景需求。

本书通俗地展示了如何用 ChatGPT 进行分析，从入门到熟练，覆盖全流程。既介绍基础使用，也深入提示词设计与优化，并结合数据采集、预处理、特征工程、基础分析、可视化、回归、分类、聚类等实操案例，帮助读者掌握精髓。对提示词沟通技巧的强调，对缺乏编程背景但希望进入分析领域的人尤为重要。

# **前言**

信息爆炸时代，数据已成为企业与个人决策的重要支撑。数据分析把原始信息转化为可行动洞察，已渗透到商业智能、市场研究乃至日常决策。庞杂的数据、专业软件及编程门槛，让许多人却步。人工智能的快速发展，特别是生成式预训练 Transformer GPT 模型的出现，正改变这一现状。

ChatGPT 以强大的语言理解与生成能力重塑分析边界。通过对话交互，可辅助完成数据采集、预处理、建模到报告撰写的全流程，大幅降低门槛。对专业人士而言是强力助手，对非专业用户则是轻松上手的入口，让数据驱动决策更迅速。

本书旨在系统介绍如何不依赖传统分析工具、不手写代码，仅用 ChatGPT 完成分析。涵盖 ChatGPT 基础使用、高效提示词构建，到数据采集、预处理、特征工程、分析、可视化及报告撰写，提供一套完整指南。

第一章介绍 ChatGPT 的注册、登录及升级。后续章节深入提示词的结构、原则与优化技巧，帮助读者更好地驱动大模型完成复杂任务。

分析流程涵盖采集、预处理、建模、可视化及报告。第四章起逐环节展开。采集部分介绍如何生成模拟数据、设计问卷及抓取数据；预处理部分聚焦清洗、转换、集成及脱敏，确保准确与安全。

特征工程是模型性能的关键，本书通过案例讲解特征选择、衍生及降维，说明如何借助 ChatGPT 优化特征，为后续建模做好准备。

在分析章节，通过实际案例展示对比分析、分组分析、交叉分析、相关性分析、漏斗分析等多种方法，让读者看到大模型在真实场景中的作用。

可视化是分析的重要环节，本书介绍基本原则，并详解如何用 ChatGPT 绘制构成类、比较类、趋势类、分布类、关系类等多种图表，助力需求匹配。

进阶方法如回归、分类、聚类，对解决复杂问题至关重要。书中通过讲解与案例，呈现 ChatGPT 处理复杂分析的强大能力，深化对应用场景的理解。

最后讨论如何用 ChatGPT 撰写分析报告，涵盖日常工作类、专题分析类、综合研究类，帮助读者有效呈现结果，提升沟通与应用效果。

本书以实例驱动，力求为读者提供全面详实的使用指南，帮助简化流程、提升效率与质量。希望读者不仅掌握技能，更能在工作中落地解决实际问题，提升个人及组织的决策水平。

**1．注册前准备条件**

（1）国际网络环境：IP地址需处于非中国大陆地区。部分 IP 可能已被 OpenAI 封锁，无法访问。

（2）境外邮箱：注册需填写邮箱用于接收验证邮件。Gmail 需在国际网络环境下注册。

**2．注册流程**

打开 ChatGPT 官网，会看到如图 1.2 所示的欢迎页，包含“登录”与“注册”两个入口，点击“注册”进入下一步。

[PRE35]

图 1.2 ChatGPT 欢迎页面

（1）进入注册页填写邮箱。注册页如图 1.3 所示，在 Email address 栏输入常用邮箱，如 Gmail。国内邮箱如网易、QQ 邮箱可能受限导致注册失败。

图 1.3 输入邮箱

（2）设置密码。在 Password 框中输入密码，如图 1.4 所示，密码长度至少 8 个字符。完成后点击 Continue。

（3）邮箱验证。输入账号密码后会跳转至图 1.5 所示页面，表示 OpenAI 已向用户邮箱发送验证邮件。
