LoRA 小因子，大效果：QLoRA 实操与简单网页抓取

LoRA 的出发点很直接，不对整张权重做大规模改写，而是引入一对低秩因子 A、B 用它们的乘积来近似更新量。推理时这个增量可以一次性合并回原权重，训练时只需要动 A、B 两个小表，计算和显存开销都降下来。下面一对式子展示了前向时如何注入增量，以及参数在更新后怎样累加。

[PRE0]
$h = Wx + \frac{\alpha}{r} BAx$
[PRE1]
$W = W + \frac{\alpha}{r} BAx$

反向时 B 的梯度可以拆成下游传回的梯度、输入向量以及低秩项自身导数的乘积形式。

[PRE2]
$\frac{\partial L}{\partial B} = \frac{\partial L}{\partial h} x^T \frac{\partial W_{\text{lora}}}{\partial B}$

下面是一个能直接跑的四位量化微调模板，以 Gemma2 做序列分类为例。依赖涵盖量化、Tokenizer、模型、训练器与 PEFT，配置用 dataclass 集中管理。实验名固定为 qlora-gemma-9b-4bit，输出目录自动带上当前时间戳；预训练权重指向 unsloth 发布的 4-bit 版本，序列截断 4096，优化器用 8 位 AdamW，单卡每批 2 条。

import requests

from bs4 import BeautifulSoup

import re

# 百度搜索页面URL

url = 'https://www.baidu.com'

# 发送请求获取HTML内容

response = requests.get(url)

response.raise_for_status()  # 确保请求成功

# 解析HTML内容

soup = BeautifulSoup(response.text, 'html.parser')

# 找到logo的URL

# 百度的logo通常在一个名为 'logo' 的img标签内

logo_tag = soup.find('img', {'id': 's_lg_img'})

if logo_tag and 'src' in logo_tag.attrs:

    logo_url = logo_tag['src']

    if not logo_url.startswith('http'):

        # 如果URL不是完整的，请补全URL

        logo_url = 'https:' + logo_url

    # 下载logo

    logo_response = requests.get(logo_url)

    logo_response.raise_for_status()

    # 将logo保存到文件中

    with open('baidu_logo.png', 'wb') as file:

        file.write(logo_response.content)

    print('Baidu logo has been downloaded successfully.')

else:

    print('Baidu logo not found.')
