# 附录 C　CNN 时序预测实操

第三部分主要围绕两类常用神经网络展开：全连接密集网络 DNN 与循环网络 RNN。DNN 的优势在于通用近似能力强，书中强化学习部分就借助 DNN 来拟合最优行动策略。RNN 对序列信息有天然适配性，尤其是时间序列，这对金融时序的未来点预测很有价值。

不过在实际应用中，**卷积神经网络** CNN 同样是主流基础模型，特别是在计算机视觉方向表现突出。它在 ImageNet 等权威评测和竞赛中多次刷新纪录，相关背景可参考《经济学人》2016 年报道或 Gerrish 2018 的综述。视觉技术的落地场景涵盖自动驾驶、安防监控等多个领域。

本附录聚焦 CNN 如何迁移到金融时间序列预测任务上。想深入了解 CNN 原理，可查阅 Chollet 2017 第五章以及 Goodfellow 等人 2016 第九章。
