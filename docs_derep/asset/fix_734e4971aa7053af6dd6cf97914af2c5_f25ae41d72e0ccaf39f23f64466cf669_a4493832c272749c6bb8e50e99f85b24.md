编程与数学相关的语料，Meta 单独设计了专属的数据处理线。分类环节使用在 Llama 2 标注数据上微调的 DistilRoBERTa 模型，并对提示词做针对性调优，核心是捕捉自然语言表述与代码、数学演绎之间的互动特征。

多语言资料的治理思路也比较系统。先用语言识别模型把文档归到 176 种语言并做去重，随后融合语言专属的启发式规则与模型筛选剔除低质内容，再由多语言版 Llama 2 分类器对剩余文档打分，确保优质内容优先进入训练。为了让英语与多语种在评测上的表现更均衡，团队还实验性地统计了预训练阶段多语种 token 的使用量。

为了提升语言模型质量，Meta 对训练语料的混合比例做了专门设计。先训练文本类别分类器来调节组合，压缩在互联网上占比极大的娱乐与艺术类内容，并在小规模模型上测试不同配比的效果。最终大模型训练的混合比例确定为通用知识 50%、数学与推理 25%、代码 17%、多语言 8%。

实践还发现，预训练收尾阶段用数学、代码等高质量数据做退火训练，能明显提升最终表现。

Llama 3 的上下文很长，输入往往是多文档拼接而成。因此训练时引入了特殊的注意力掩码，避免模型把不同文档里的 token 互相关注。

Llama 3 的预训练分为初始预训练、长上下文预训练和退火训练三部分。

以 405B 为例，初始阶段采用 AdamW 优化器，初始学习率 8×10^{-5}，前 8000 步线性预热，随后余弦衰减到 8×10^{-7}，总共 120 万步。起步时批量较小，为 4M tokens 且序列长度 4096，后续逐步放大到 8M 和 16M，以提高训练效率。训练过程中会动态调整数据组合，提高非英语比例、上采样数学数据、补充更新的网页数据并削减低质数据。

长上下文阶段逐步拉长序列长度，以支持最高 128K 的窗口。共分 6 个阶段从 8K 升到 128K，让模型在每个阶段都能适应新的长度。该阶段使用约 800B 的训练 tokens。

退火阶段用 40M tokens 训练，学习率线性降低至 0，同时保持 128K 的上下文长度，数据侧重高质量来源。最终模型通过对检查点的平均生成。

Llama 3 后期打磨与横向对标

Llama 3 经历了多轮后期训练来提升能力。每轮都包含监督微调 SFT 和直接偏好优化 DPO。数据来自人工标注样本和合成样本。流程是，先用预训练模型基于人工偏好数据训练一个奖励模型；再用奖励模型对人工提示做拒绝采样，结合合成数据后以标准交叉熵损失对预训练模型做监督微调；微调后用 DPO 进一步对齐人类偏好。DPO 计算开销更小，在指令遵循类基准上表现更好。

2024 年 9 月 25 日，Meta 发布了 Llama 3.2，其中包括面向移动端的纯文本小模型 Llama 3.2 1B 和 3B。更值得关注的是首次发布的 11B 与 90B 多模态大模型，为开源生态的智能应用提供了更多可能。该多模态版本支持图像推理，能够理解图表、图片文字等，例如询问柱状图哪一年销量最高，或让模型描述图片内容。

为了给原本训练的纯文本 Llama 增加视觉输入，Meta 训练了一组权重适配器，把预训练图像编码器的输出映射到大语言模型中。这组适配器由多层交叉注意力组成，负责把图像编码器的表征传递给语言模型。训练时图像编码器的参数可以更新，而大语言模型的参数完全冻结，以此保留原有语言能力。

多模态模型的训练分阶段进行。从 Llama 3.1 文本模型出发，先接入图像适配器与编码器，在大规模带噪声的图文配对数据上做预训练；接着在中等规模高质量的领域与知识增强图文配对数据上继续训练。后期采用与纯文本模型类似的方法，通过多轮对齐的监督微调、拒绝采样和直接偏好优化来完成后训练。

## 3.1 Hugging Face 平台概览

Hugging Face 是一家深耕自然语言处理和人工智能的公司，以开源工具和平台著称。公司成立于 2016 年，总部在纽约，致力于让 AI 技术更易获取和使用。

Hugging Face 是一个开源人工智能平台，汇聚了 40 多万开源模型、10 多万开源数据集以及 15 万个应用。几乎所有开源大模型厂商都会优先在此发布，例如 Llama、ChatGLM、Qwen、Yi 等。

平台还提供了一系列易用开源库，最知名的是 Transformers，可快速从头训练或微调预训练模型。此外还有用于分布式训练的 Accelerate、参数高效微调的 PEFT、强化学习训练的 TRL 等。

Hugging Face 拥有活跃社区，用户可在其中分享模型、数据集和经验，或发布自己的模型、体验他人的作品。
