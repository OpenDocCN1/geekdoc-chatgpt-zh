（7）搭建一页式多媒体资源速查页，让教师和学生能迅速摸清现有数字素材的全貌。
（8）梳理两到三类容易出现的技术风险，并给出对应可行的应对策略。
（9）拟订一份资源维护计划，包含：
  - 推荐的更新节奏
  - 本次更新涉及的素材类别
  - 向使用者推送信息的渠道
（10）策划一至两个依托多媒体资源的拓展学习任务。
（11）给出三至五种检验多媒体资源使用成效的评价手段。
（12）提供一个纸质教材版面示意，说明如何恰当嵌入资源链接。

### 三、习题生成：题型布局、知识覆盖与难度调控的提示词方案

练习题是教材与教学资源的重要组成部分。科学编制的题目能够帮助学习者巩固知识、迁移理论、提升问题解决能力，并提供客观的学习反馈。习题设计必须与教学目标和内容紧密衔接，以支撑有效学习。

习题的核心价值：
- （1）知识内化：通过实操把抽象概念转化为具体运用，推动学习者实现深度理解。
- （2）能力培养：多样化的题型锻炼学生的多元认知，如分析、综合和评价。
- （3）学情诊断：题目反馈帮助师生成像学习优势与薄弱环节。
（4）思维拓展：开放性问题激发创造性思维，培养批判性思考能力。
（5）动机提升：适度挑战的题目提高学习兴趣，激发自主学习热情。

优质习题的特征：
- （1）目标一致：紧密呼应教学目标与核心素养要求。
- （2）情境真实：贴近生活或科学实践的真实应用场景。
- （3）层次分明：难度梯度合理，兼顾不同水平学习者。
- （4）思维驱动：着力培养高阶思维，如批判性思维与创造力。
- （5）知识关联：体现知识点间的联系，助力知识体系构建。
- （6）形式多样：题型丰富，匹配不同学习风格与能力特点。
- （7）评估可靠：效度信度良好，真实反映学习结果。

#### （一）题型设计提示语

题型选择直接影响学习体验与效果。不同题型考察不同的认知与思维过程。编题时，题型多样化与合理配比有助于全面达成学习目标，设计时可参考以下原则：
- 构建多元题型。
- 融合题型与学科特色的结合。
- 借助题型培养学生多方面能力。
- 合理分配各题型占比。
- 鼓励创新性变形设计。

◎ 提示语示例：

为 [学科] [年级] [具体单元/章节] 制定一套综合练习，需求如下：

（1）题型规划：
- 至少涵盖六种不同题型，例如选择、填空、简答、计算、应用、探究等。
- 说明每类题型的测评目的与占比。
- 确保题型覆盖布鲁姆认知分类的各层级，记忆、理解、应用、分析、评价、创造。
- 设计一到两个体现学科特色的创新题型并阐明设计思路。

（2）各题型的具体要求：
- 选择题：提供四个选项，其中至少一个具有迷惑性的干扰项。
- 填空题：重要概念要求写出完整定义；公式可适当挖空。
- 简答题：要求用学生自己的语言解释概念或现象，字数控制在五十到一百字。
- 计算题：给出详细解题步骤，注意单位规范。
- 应用题：基于真实生活情境，要求综合运用所学知识解决问题。
- 探究题：提出开放性问题，鼓励学生提出假设、设计实验或论证。

（3）为每类题型各提供两到三个具体例题。
（4）设计一到两道需小组协作完成的题目。
（5）在练习中融入两到三个核心素养培养要素。
（6）给出各题型的评分细则与参考答案。

#### （二）知识点覆盖提示语

习题设计需确保教学重点知识得到充分覆盖，既能帮助学生全面复习巩固，也能凸显知识点的重要性与联系。设计提示语时可考虑：
- 全面性：涵盖教学中的全部重点知识。
- 分配比例：依据知识点重要程度分配题量。
- 关联性：设计体现知识点间联系的题目。
- 重点突出：对核心知识进行强化。

◎ 提示语示例：

为 [学科] [年级] [具体单元/章节] 编制一套覆盖关键知识点的练习，要求：

- 列出本单元/章节所有重要知识点，至少十个，按重要程度分为核心、重要、一般三类。
- 为每个知识点配题，数量为：
    - 核心知识点：每点五到七题。
    - 重要知识点：每点三到五题。
    - 一般知识点：每点一到三题。
- 设计三到五道整合多个知识点的综合题，体现关联。
- 为每个核心知识点设置一个强化小专题，包含：
    - 知识点概述五十到八十字。
    - 三到五道针对性练习。
    - 一个应用实例。
- 绘制一个知识点分布图，直观展示各点题量分布。
- 设计两到三道跨单元/章节题目，体现螺旋上升。
- 为每个知识点标注教材对应页码，便于查阅。
- 设计三到五道反映知识结构的问题，如概念图、知识树等。
- 提供一份知识点覆盖核查表，防止遗漏。
- 设计一到两道开放性问题，鼓励拓展思考。
- 用一百到一百五十字说明习题如何体现教材的知识结构与逻辑。
- 提供三到五条利用本套练习进行复习巩固的建议。

#### （三）难度控制提示语

难度把控是习题发挥作用的关键。合理的难度递进让人进步，同时避免挫败感。设计难度提示语时需注意：
- 难度分级：设基础、中等、挑战三级。
- 平滑梯度：确保难度逐步递进。
- 能力层次：依据布鲁姆目标分类设计不同难度题目。
- 区分度：题目能有效区分不同水平学生。
- 挑战性：在保证基础题量的同时提供足够挑战题。
- 自适应：考虑允许学生自主选择难度的机制。

为 [学科] [年级] [具体单元/章节] 开发一套难度合理的习题集，要求：

- 将题目分为基础、中等、挑战三级，比例分别为五十%、三十%、二十%。

    - 难度界定标准五十到八十字。

- 用一百到一百五十字说明如何通过题目设置引导学生逐步提升解题能力。

### 四、评价反馈：学情诊断、个性化反馈、激励机制提示语设计

在教育培训中，评价反馈是教学环节的重要组成。科学的反馈机制帮助学习者了解学情、明确改进方向、提升学习动力，并为后续学习提供参考。本节从学情诊断、个性化反馈和激励机制三个维度，探讨提示语的设计策略。

#### （一）学情诊断提示语设计

学情诊断是反馈的基础，需全面准确分析学习状况，为后续个性化反馈和激励提供依据。

关键设计策略：
- 多源数据整合：引导AI收集学习行为、作业表现、测验结果等多维度数据。
- 能力图谱构建：绘制学生知识结构与能力发展图谱。
- 学习模式识别：识别学生的学习风格、习惯与偏好。
- 问题归因分析：深入剖析学习困难的根源。
- 进展追踪：建立长期学习进展跟踪机制。

◎ 提示语示例：

为 [学科] [年级] [具体单元/章节] 设计一套完整的学情诊断方案，要求：

- 设计多维学习数据采集方案，包含：
    - 课堂参与度指标三到五个。
    - 作业完成质量评估维度四到六个。
    - 测试表现分析框架涵盖五个到七个角度。
    - 学习行为采集点六到八个关键点。
- 制作动态能力图谱模板，包含：
    - 核心知识点掌握度可视化方案。
    - 关键能力发展轨迹呈现方式。
    - 学习进度与目标对比机制。
- 设计学习风格识别算法，考虑：
    - 四到五种主要学习风格特征。
    - 行为指标与风格的映射关系。
    - 风格判定的量化标准。
- 开发错误模式分析系统，包含：
    - 常见错误类型分类至少八到十种。
    - 错误频率与严重程度量化方法。
    - 错误原因推断逻辑框架。
- 构建学习策略评估模型，涵盖：
    - 五到七种核心学习策略的定义与特征。
    - 策略使用效果评估指标。
    - 策略优化建议生成逻辑。
- 设计综合学情诊断报告模板，包含：
    - 整体学情摘要一百到一百五十字。
    - 优势领域分析三到四点。
    - 待改进领域三到四点。
    - 学习风格与策略建议四到五点。
    - 未来学习重点与目标建议三到四点。
- 提供两到三个基于诊断结果的个性化学习路径建议。
- 设计一个可视化面板，直观展示诊断关键结果。
- 制定诊断准确性评估与持续优化机制。

#### （二）个性化反馈提示语设计

个性化反馈将诊断结果转化为具体学习建议，有助于学习者明确改进方向并获得策略参考。

创新策略：
- 反馈结构模板：设计完整系统化反馈模板。
- 语言风格指导：提供适配不同年龄与阶段的语言风格。
- 数据解释框架：把学习数据转化为有意义反馈。
- 建议生成机制：依据表现生成具体改进建议。
- 正面强化策略：指出不足同时鼓励进步。

◎ 提示语示例：

请为 [学科] [年级] [具体学生] 撰写个性化反馈，要求：

- 反馈结构设计：
    - 创建反馈模板，包含：
        - 总体表现概述三十到五十字。
        - 优势领域两到三点。
        - 需改进领域两到三点。
        - 具体改进建议三到四点。
        - 鼓励性结语二十到三十字。
    - 为每个部分提供两到三条写作要点。
- 语言风格指南：
    - 提供三种语言风格示例，如鼓励型、指导型、激励型。
    - 列出十到十五个积极鼓励的关键词或短语。
    - 列出五到七个应避免的消极表达。
- 基于学情的反馈定制：
    - 设计决策树，指导依据学生表现选择反馈重点。
    - 提供三到五个常见学习问题的反馈模板。
    - 创建诊断结果向具体建议转化的指导框架。
- 改进建议生成器：
    - 为五到七个常见学习困难提供改进策略库。
    - 设计依据学生强项推荐发展方向的逻辑框架。
    - 提供三到四种设定可达成短期目标的方法。
- 反馈时机与频率建议：
    - 列出三到五个适合提供反馈的关键时间点。
    - 提供日常反馈与阶段性反馈的频率建议。
    - 设计确保反馈持续连贯的计划。
- 反馈效果跟踪：
    - 设计三到四个评估反馈效果的指标。
    - 提供两到三种收集学生反馈回应的方式。
    - 创建反馈调整优化的循环模型。
- 家长沟通策略：
    - 设计将学生反馈转化为家长沟通内容的框架。
    - 提供三到五个分享学习进展的有效方式。
    - 列出两到三个促进家校合作的建议。
- 反馈可视化建议：
    - 提供两到三个可视化进步的图表模板。
    - 设计简洁的反馈总结卡片模板。
    - 建议一到两种长期进展可视化方法。
- 创新反馈方式：
    - 提出两到三种新颖反馈呈现方式，如音频、视频反馈。
    - 设计将反馈融入日常教学的策略。
    - 建议一到两种利用技术增强反馈效果的方法，如AR。
- 教师培训建议：
    - 列出五到七个提升教师个性化反馈能力的要点。
    - 设计教师自评量表以改进反馈质量。
    - 提供两到三个提高反馈效率的实用技巧。

#### （三）激励机制提示语设计

激励机制是评价反馈的补充，适度激励能积极影响学习动力。设计应基于教育心理学，注重适度与多样性，聚焦学习本身。

创新策略：
- 动态目标设定：按进度与水平调整学习目标，保持适度挑战。
- 个性化奖励：基于兴趣与动机设计个性化奖励。
- 社交化激励：引入同伴互助与小组竞争，增强互动趣味。
- 进度可视化：用生动方式展示进度与成就，增强成就感。
- 智能提醒与干预：在动力下降时及时干预。

◎ 提示语示例：

为 [学科] [年级] [具体单元/章节] 设计智能激励机制，要求：

- 创建动态目标设定系统，包含：
    - 设计三到四个层次的学习目标模板。
    - 制定目标难度动态调整算法逻辑。
    - 提供两到三种目标达成度评估方法。
- 开发个性化奖励系统，要求：
    - 设计五到七种奖励类型，如徽章、积分、奖品等。
    - 创建学生兴趣与奖励类型匹配矩阵。
    - 提供三到四个奖励发放时机与频率建议。
- 构建社交化激励模块，包含：
    - 设计两到三种同伴互助机制。
    - 创建小组竞赛系统，含规则与奖励设置。
    - 提供一到两个促进学习社区互动的功能。
- 设计学习进度可视化系统，要求：
    - 创建三到四种进度展示图表模板。
    - 设计虚拟成长系统，如知识树、技能图谱。
    - 提供两到三种长期进步可视化方式。
- 开发智能提醒与干预系统，包含：
    - 设定四到五个需干预的关键触发点。
    - 创建三到四种不同强度的干预措施。
    - 设计干预效果评估与调整机制。
- 创建激励效果分析系统，包含：
    - 设定四到五个衡量激励效果的关键指标。
    - 提供学生激励偏好分析方法。
    - 设计激励策略A/B测试。
- 设计两到三个长期激励策略，培养内在动机。
- 提供家长参与的激励机制设计，含三到四个具体建议。
- 创建激励机制管理界面原型，便于教师监控调整。
- 设计确保激励公平性与避免过度竞争的机制。

## 第10章 文学创作中的提示语设计

与技术任务不同，文学创作更依赖想象力、情感与表达。本章探讨在小说、诗歌、剧本等创作中，如何通过提示语激发创意、塑造人物、推动情节、营造氛围，构建生动作品。

### 一、小说创作：人物、情节、场景的提示语设计

小说创作涉及人物塑造、情节发展与场景描绘，提示语可有效引导生成连贯故事。本节探讨如何通过有效提示语塑造鲜明人物、构建紧凑情节、描绘富有表现力的场景，提升小说质量。

#### （一）人物提示语设计
