### 胶囊网络迭代机制与多兴趣向量生成

经过加权求和聚合后，第二层胶囊经 `squash` 函数非线性变换，输出深层胶囊集合 $\{ u_1, u_2 \}$，即 $u_j = \text{squash}(z_j)$，这便是胶囊网络最终产出的用户多兴趣向量。

**图3-44 胶囊网络迭代计算流程**

`squash` 函数的核心作用是将上层胶囊的模长压缩至 $[0, 1]$ 区间。通过对兴趣向量模长的缩放，它能加速模长向 1 或 0 收敛。每轮迭代结束后，参数按以下规则更新：

[PRE1]

更新逻辑的核心在于：利用兴趣向量 $u_j$ 与浅层胶囊向量的内积累加来修正 $b_{ij}$，再经归一化得到动态路由权重 $w_{ij}$。显而易见，浅层胶囊与某兴趣向量 $u_j$ 的内积越大，下一轮迭代中它向该兴趣向量分配的贡献权重就越高。

如图3-45所示，若换用“聚类算法”视角审视此过程：$\{e_i\}$ 为空间点集，$u_j$ 为簇心。但动态路由并非硬分配，浅层胶囊不会唯一归属某簇，而是通过动态权重将“能量”软性分配给所有簇心，属于**软聚类**范畴。若某兴趣向量 $u_j$ 靠近部分 $\{e_i\}$，迭代中它从这些点获取的能量增多，距离随之拉近；在 `squash` 作用下，其模长趋近 1。反之，若远离大多数点，分配能量减少，距离拉大，模长趋近 0。因此，最终深层胶囊的**模长表征兴趣存在的概率，方向编码兴趣的具体细节**。

[PRE2]

**图3-45 聚类视角下的用户兴趣向量更新**

关键在于，胶囊网络动态路由中的参数 $b_{ij}$ **不依赖反向传播更新**，而是遵循 $b_{ij} = b_{ij} + u_i \cdot e_j$ 迭代更新——这正是动态路由算法的灵魂所在。

胶囊网络由 Hinton 于 2017 年提出，初衷是解决图像领域底层局部特征在高阶特征中的空间位置关系（如面部五官的相对布局）。同理，在用户兴趣挖掘中，行为序列蕴含大量局部细节特征，我们期望捕捉这些底层特征在高阶语义空间的关联，输出更抽象的兴趣表达。例如，用户连续观看探险、露营、赛事视频，背后可能隐含对运动、旅游及感官刺激的偏好，这种高阶抽象兴趣的提取，正是胶囊网络的用武之地。

式中，$K$ 为预设超参，$|L_u|$ 为用户行为序列长度。结合深层胶囊“模长即置信度”的特性，亦可动态调整：仅保留模长显著的兴趣向量。

**损失层的多兴趣对齐难题**：标签仅有一个，但输出却有 $K_u$ 个兴趣向量。双塔框架下会产生 $K_u$ 个内积，MIND 引入 **Label-aware Attention** 机制：以目标物品向量为 Query，多兴趣向量为 Key/Value 加权融合为单一向量，再与目标物品交互。

[PRE4]

融合公式中引入 $\text{pow}(*, p)$ 函数（$p$ 次方运算），用于调节相似度差异。$p$ 需结合业务调优：
- **$p > 1$**：放大差异，使高匹配兴趣获得更大梯度，收敛更快，倾向训练出**差异大、单兴趣准确度高**的模型。
- **$p < 1$ (接近 0)**：压缩差异，梯度均匀回传，收敛变慢，倾向输出**贴近主干兴趣、整体准确率高**的向量。

Label-aware Attention 巧妙解决了**训练期标签对齐**与**服务期多兴趣召回解耦**的矛盾：训练融合单向量对齐 Label，线上直接使用融合前的多兴趣向量各自 ANN 检索，避免过早交互。

实践中，这并非唯一解。另一思路源于**兴趣独立性**：期望多兴趣向量训练时向不同方向收敛，形成合理区隔。假设每条样本 Label 仅关联一个兴趣向量，处理逻辑如图3-46。

[PRE5]

**图3-46 用户多兴趣向量替代处理方案**

计算内积 $s_j = e_i \cdot u_j$ 后，不接 Softmax，而是引入**硬门控**：
$s'_j = 1$ 若 $s_j$ 为最大值，否则 $0$。

仅内积最大的兴趣向量参与后续交互及反向传播，其余向量梯度置零。用户融合输出 $v_u$ 即为该最大内积向量，交互概率与目标函数定义如下：
$P(i|u) = \frac{\exp(v_u \cdot e_i)}{\sum_{j \in I} \exp(v_u \cdot e_j)}$
$L = \sum_{(u,i) \in \mathcal{D}} \log P(i|u)$

这本质是一种 **Mask 机制**：$v_u$ 硬选取最匹配向量，其余向量参数更新权重为 0。

最终，模型输出自适应数量的兴趣向量。线上服务时，基于各兴趣向量并行从物品 ANN 索引召回 Top-N，融合后作为最终兴趣召回结果。

## 2. 长短期偏好的协同建模

若多兴趣建模关注“表达维度”，长短期融合则聚焦“形成机制”。用户当前兴趣受长短期行为共同驱动，但影响权重与维度各异。例如，一位习惯比价用券的“节俭型”用户，因特殊需求选购高端商品时，短期意图虽指向高端，但长期决策习惯（找折扣、用券）依然生效，二者共同塑造当下决策。

### 3.5.3 序列建模方法论总览

综上，用户行为序列召回建模可抽象为统一范式：**双塔骨架 + 用户塔序列建模 + 交互层相似度优化**。统一算法框架如图3-50。

[PRE19]

**图3-50 行为序列建模统一算法框架**

各层核心职责解析：

1.  **特征输入层**：会话切分策略、用户画像与上下文 Side Info 选取（基于前期数分）。
2.  **特征编码层**：位置编码，引入绝对/相对位置信息，强化行为偏序关系对兴趣提取的指导。
3.  **特征组合层**：Side Info 处理。常规做法：Item ID 与 Side Info Average Pooling 融合为单向量；或平行作为独立序列输入。
4.  **兴趣编码层 —— 核心引擎**：本节详述诸路方法——Pooling 捕捉关键兴趣、CNN 提取局部连续模式、GRU 建模时序演进、胶囊网络抽取多峰兴趣。**无绝对优劣，需结合业务场景选型**。
   - *工程增强*：实践中常加残差模块与 MLP 提升拟合力，输出向量 L2 归一化加速收敛。
5.  **兴趣输出层**：输出单/多兴趣向量。训练期送交互层优化 Loss；Serving 期直接作为实时兴趣表达。
6.  **交互层**：用户塔与物品塔输出经全连接或内积计算相似度优化 Loss。若用户塔输出多兴趣，训练期需预处理对齐 Label：
   - **Attention 融合**：多兴趣与 Target Item Attention 加权求和得单向量再交互。
   - **Mask 硬选**：仅保留内积最大兴趣向量回传梯度，其余 Mask 掉。
