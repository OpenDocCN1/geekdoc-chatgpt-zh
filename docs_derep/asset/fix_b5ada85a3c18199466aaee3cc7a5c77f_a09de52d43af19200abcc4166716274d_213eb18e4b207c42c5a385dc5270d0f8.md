# 第五章 数据资源开发利用

## 第五十八条 【总体目标】

本市支持数据资源开发和应用，发挥海量数据和丰富应用场景优势，鼓励和引导全社会参与经济、生活、治理等领域全面数字化转型，提升城市软实力。

[PRE0]
数据开发与应用专章可视作《上海市数据条例》的突出亮点，折射出市政府对数据生产要素属性的高度重视，以及鼓励创新、让科技为城市赋能的开放姿态。第五十八条承担起全章的引领作用，勾勒出数字技术的发展方向，以场景化应用为切入点，强调信息技术在推动经济发展、改善民生服务、提升治理效能方面的积极意义。
[PRE1]
条例第二条把数据表述为“任何以电子或其他方式对信息的记录”，在法人及非法人组织数据之外，个人数据因其敏感性与争议性成为规范重点。个人信息除承载人格属性外，还蕴含显著的财产属性，这种财产性主要来自其作为研发原材料与商业模式底层资源的价值。在PC与智能手机普及的数字社会，依托数据的数字经济已成为当前社会核心的价值创造方式。如何在兼顾个人权益保护与数据安全的前提下释放数据效能，已成为数字转型期的关键命题。近几年《网络安全法》《个人信息保护法》《数据安全法》的相继出台，显示国家已就迎接数字时代作出基础性制度布局。

该条从要素属性与技术功能双重视角阐释发展指向。其一，技术研发依赖大规模数据样本，并需随不同应用场景动态校准功能与安全要求。条例对数据特征及应用前景的判断，与国务院办公厅2021年12月21日发布的《要素市场化配置综合改革试点总体方案》所倡导的“拓展规范化数据开发利用场景”高度契合，体现出较强的前瞻性与吻合度。其二，从产业数字化出发，提出借助数字技术整体提升上海在经济活力、市民幸福感、治理效能等软实力维度的发展目标。

### 一、数据的产业应用
数据治理在实践中往往需要在隐私保护与价值释放之间寻求平衡，使用者、运营方与监管方构成三方博弈，立法追求的是公众权益与产业活力双增强、利益相关方动态平衡。对照征求意见稿，正式稿在确认政府对数字产业提供支持的基调下，明显淡化了行政干预色彩，更多体现出尊重市场自律、倡导技术向善的治理取向。相较深圳方案，上海本章更强调数据要素的市场属性，意在激发各类数据的开发潜能，推动全社会共同参与数字经济与数字技术的升级。

腾讯、百度等头部企业诞生于千禧年左右，但全国性规范直至2012年人大常委会通过《关于加强网络信息保护的决定》才开始触及网络信息侵权问题，之后个人信息相关诉讼才逐渐增多。消极来看，早期规则空白加剧了个人信息滥用；积极来看，也为互联网赢得约十年的快速成长窗口，技术能力与商业规模实现爆发式扩张。相关研究对美、中、欧人工智能赛道横向比较后指出，中国发展动能强劲，追赶美国的步伐加快。面对新技术，法律宜采取底线思维，以维护人格尊严、保障财产人身安全为边界，为产业划定原则框架。规范应当顺应科技与市场的内在规律，保留适度探索空间。相较草案，现行条例第五十八条明显让出技术研发与落地的空间给科技界与产业界，减少过度规划，在守住个人权益与公共安全底线的条件下体现包容发展态势。

## 二、丰富数据的场景化应用
该条特别突出场景化探索，成为区别于既有地方立法的特色所在。上海作为千万人口的国际化大都市，市场中蕴含着极为丰富的技术落地场景。法规的核心作用在于通过厘清数据产品归属与数据行为规则，为创新提供确定性，并划定应用边界，激发研发人员大胆试错，开拓数据技术的新型场景。

### 第一，为拓宽数据的场景化应用创新，应率先解决数据权属问题
