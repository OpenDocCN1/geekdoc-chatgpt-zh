# 从 BKT 到 ERAKT：时序认知诊断模型的演进与多维突破

作为时序认知诊断领域的奠基之作，贝叶斯知识追踪（BKT）[169] 早期应用极广。但其核心假设——学习者一旦掌握知识点便永不遗忘——显与真实教学场景背离。随深度学习浪潮兴起，将时序建模与神经网络融合成为主流，深度知识追踪（DKT）便是典型代表。DKT 修正了 BKT “永不遗忘”的硬伤，能更精准刻画学习者技能掌握度。然而，DKT 仅用单层隐藏表征技能状态，被认为精度不足，导致技能追踪困难。为此，Zhang 等人引入记忆网络提出 DKVMN，实测性能显著超越 BKT 与 DKT。近期，中科大团队在现有范式基础上，主张将习题记录与题目材料双轨并行融入诊断，推出 EKT、qDKT（question-centric deep knowledge tracing）[170] 等模型，在可解释性与预测效能上均实现跃升。

然而，主流时序认知诊断模型多聚焦答题序列，以知识技能代替习题实体，忽略了习题公式、文本及知识技能对知识状态的显性影响。我们认为，除答题序列外，习题的多维信息均深度作用于学习者表现。针对上述痛点，本章构建了一种融合习题表征的时序认知诊断模型，旨在弥补传统模型因忽视多维习题表征与关联导致的信息流失，显著提升预测精度。核心贡献三点：

- **创新框架 ERAKT**（context-aware knowledge tracing integrated with exercise representation and association）：统筹答题序列、题目文本与知识技能，自动化预测学习者下一次作答表现及技能掌握程度；
- **多维习题表征方法**：深度融合题目文字、数学公式及关联知识技能；
- **基于双向神经网络的序列关联挖掘**：深度捕获习题间隐性关联模式。

#### 8.1 国内外相关研究

##### 8.1.1 语义表征技术演进

文本处理的首要环节是向量化——将自然语言转为机器可计算的向量形式。从早期的词袋模型到如今的深度神经网络，代表性里程碑包括 Word2Vec、TextCNN、FastText 与 BERT 等。

**Word2Vec**[171] 由 Google Mikolov 团队开创，是神经网络服务语义表征的早期范式，以固定维度向量编码单词。针对句子级建模，其衍生出 **Doc2Vec**[172]：引入段落向量参与联合训练，实现文档级向量化。二者均属典型无监督深度文本表征模型，相较词袋模型，能更充分捕获语境、语义与语序等内在信息。

受卷积神经网络（CNN）在视觉领域大捷启发，Kim[173] 于 2014 年改造 CNN 输入层，提出 **TextCNN**。其采用循环结构建模上下文，配合最大池化提取文本关键成分。架构轻量化带来参数量少、算力低、训练快的优势，实测效果优异。

**FastText**[174] 亦是文本分类常客。它将全文词汇与 n-gram 向量叠加平均生成文档向量，再经 Softmax 分类。免去预训练词向量依赖，自主训练词向量，在保精度前提下大幅提速训练与推理。

**BERT**[175] 由 Google 团队推出，旨在攻克一词多义难题。引入具备 Self-Attention 与 Multi-Headed Attention 的 Transformer 编码器，结合上下文动态确定词义。Self-Attention 让每个词融合全序列加权信息；Multi-Head 机制则在多子空间并行捕获语义。BERT 天然双向、迁移学习友好，成就了更精准的语义建模。

上述 NLP 领域的语义表征技术，为认知诊断任务中精准编码习题文本等内部信息提供了坚实技术底座。

##### 8.1.2 融合习题语义与知识技能的时序认知诊断

深度学习推动下，学界开始重视习题自身特征对时序诊断的影响。习题多维特征核心涵盖文本材料与关联知识概念。

**融合知识概念的时序诊断路线**：多数将知识概念等同于习题，忽视习题独有属性。DKT 与 DKVMN 仅建模知识概念，同知识点习题视为同质；DKVMN 虽用 Key-Value 矩阵扩展隐藏特征，本质仍锚定知识概念。**PDKT**（prerequisite-driven deep knowledge tracing）引入 Q 矩阵融合概念结构，显性建模前置关系。**SAKT** 以习题为概念，引入 Self-Attention 量化概念关联。**AKT** 创设单调注意力机制，综合题目相似度、指数衰减、上下文相对距离计算权重；并用 Rasch 模型正则化概念与习题嵌入，以低参数量捕获同概念下习题个体差异。**GKT** 以知识点为节点构建图谱，配合 GRU 更新知识状态。

**融合题目材料的时序诊断路线**：聚焦文本材料与知识概念双轨融合。**EERN**[176] 利用练习记录与题目文本预测表现。**EKT** 基于 EERN 演进，首创三元融合（练习记录、概念知识点、题目文本）建模学习者表现，假设知识状态随时演变且受文本与概念双重驱动。但 EKT 用 LSTM 编码文本，受限于 RNN 串行机制，并行度低、耗时长、效果受限。**qDKT** 建模学习者在单题上随时间成功概率，仅需题目材料与答题序列，采用 FastText 编码文本，配合图拉普拉斯正则化计算题目相似度。**EHFKT**[177] 以知识点、难度、语义三层级表征习题，前两者用 TextCNN，语义层用 BERT 提取。**HGKT** 引入层级图神经网络学习习题图结构，双 Attention 挖掘知识状态，配合 K&S 诊断矩阵输出结果。

综上，**融合习题语义已成认知诊断模型演进主流趋势**。本章将结合前沿 NLP 手段表征习题语义，赋能时序认知诊断效能跃升。

#### 8.2 练习表示与关联集成框架

时序认知诊断本质是：通过观测学习者在不同习题上的交互序列追踪知识掌握态，属有监督序列预测范畴。本节先定义问题并揭幕 **ERAKT** 框架，再由核心模块层层剖析内部架构。

##### 8.2.1 问题定义

设定单学习者独立作答场景。定义学习者集合 $S$ 与习题集合 $E$。学习者序列 $S=\{s_1,s_2,\cdots,s_{|S|}\}$，单序列 $s=\{(e_1,r_1),(e_2,r_2),\cdots,(e_t,r_t)\}$，$e_t \in E$ 为 $t$ 时刻作答习题，$r_t \in \{0,1\}$ 标识正误。习题序列 $E$ 中每题含文本内容，因选用数学数据集，题目含文字与数学符号，故文本拆解为 $e=\{w,f\}$：$w=\{w_1,\cdots,w_M\}$ 为文字，$f=\{f_1,\cdots,f_M\}$ 为符号。另每题关联知识技能 $k=\{k_1,\cdots,k_M\}$，汇总为矩阵嵌入后，学习者序列升维为 $s=\{(e_1,k_1,r_1),\cdots,(e_t,k_t,r_t)\}$。模型终极目标：预测 $t+1$ 时刻学习者对习题 $e_{t+1}$ 的响应 $r_{t+1}$，即知识掌握程度。

统筹答题记录、题目文本、知识技能三元信息，本章提出全新模型实现知识状态动态更新与预测（见图 8.1），架构包含**习题表征**、**习题关联**、**表现预测**三大支柱。

##### 8.2.2 习题表征方法

习题信息包含材料本体与关联知识技能。统一数学习题表征，先分维建模（材料表征 + 技能表征），再多维融合输出统一特征向量。

###### 1. 习题公式预处理

数学题材混杂文字与 LaTeX 公式，需先将公式转为文本表述。利用 LaTeX 统一编码规范，先做文本替换规范化，再与普通文本联合预处理。

[PRE1]

预处理遵循“实体优先、属性在后”顺序识别替换，以字典存储映射关系，将公式序列 $f=\{f_1,\cdots,f_M\}$ 规范化为 $\tilde{f}=\{\tilde{f}_1,\cdots,\tilde{f}_M\}$。替换映射表见表 8.1。

| 原符号 $f$ | 替换文本 $\tilde{f}$ |
| :--- | :--- |
| complement | 补集 |
| sqrt | 根式 |
| ^ | 幂 |
| + | 加号 |
| cm | 厘米 |
| pi | 圆周率 |
| lg | 对数 |
| cdot | 点乘 |

替换完成后，按原始位置拼接（$\oplus$）文字 $w$ 与规范化公式 $\tilde{f}$，得习题文本表征 $\tilde{w}$：

$\tilde{w} = w \oplus \tilde{f}$ (8.1)

###### 3. 知识技能表征
