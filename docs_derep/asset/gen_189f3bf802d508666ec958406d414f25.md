接下来定义状态和图骨架。State 用 TypedDict 声明，messages 字段借助 add_messages 做自动累加，这样每一次交互都会沿着图传下去。StateGraph 在这里初始化以后就可以开始加节点了。

[PRE1]
python

#Chapter9/Agent.ipynb

from typing import Annotated

from typing_extensions import TypedDict

from langgraph.graph import StateGraph, START, END

from langgraph.graph.message import add_messages

class State(TypedDict):

    #messages 的类型为 list

    #messages 通过 add_messages 方法来进行更新

    messages: Annotated[list, add_messages]

graph_builder = StateGraph(State)
[/PRE1]

模型接入部分用 ChatOpenAI，密钥通过 getpass 交互式读取避免明文。chatbot 函数接收当前 State，调用 llm.invoke 并把结果放回 messages。节点注册时第一个参数是唯一的名字，第二个参数是可调用对象。

[PRE2]
import getpass

import os

from langchain_openai import ChatOpenAI

os.environ["OPENAI_API_KEY"] = getpass.getpass()

llm = ChatOpenAI(temperature=0)

def chatbot(state: State):

    return {"messages": [llm.invoke(state["messages"])]}

#第 1 个参数必须是全局唯一的节点名

#第 2 个参数是这个节点可调用的一种方法或者对象

graph_builder.add_node("chatbot", chatbot)
[/PRE2]

把起点和终点连起来，形成最简单的线性流：START -> chatbot -> END。

[PRE3]
graph_builder.add_edge(START, "chatbot")

graph_builder.add_edge("chatbot", END)
[/PRE3]

编译成可运行的图对象。

[PRE4]

交互循环用 stream 逐条投喂用户输入，结束词 quit exit q 直接退出。下面这段示例展示了最基础的聊天能力，它能接话算数，但对长程记忆没有处理。

[PRE6]
python

while True:

    user_input = input("用户: ")

    if user_input.lower() in ["quit", "exit", "q"]:

        print("再见!")

        break

    for event in graph.stream({"messages": [("user", user_input)]}):

        for value in event.values():

            print("Assistant:", value["messages"][-1].content)

如果要让模型具备算术工具，先定义统一的输入模型，再写四个基础函数并封装成 StructuredTool，最后把工具绑定到 LLM 上。

[PRE8]
from langchain_core.pydantic_v1 import BaseModel, Field

class Calculation_input(BaseModel):

    op1: int = Field()

    op2: int = Field()

    pass

def calculate_sum(op1: int, op2: int) -> str:

    print("调用加法",op1,op2)

    return str(op1 + op2)

def calculate_mul(op1: int, op2: int) -> str:

    print("调用乘法", op1, op2)

    return str(op1 * op2)

def calculate_div(op1: int, op2: int) -> str:

    print("调用除法", op1, op2)

    return str(op1 / op2)

def calculate_sub(op1: int, op2: int) -> str:

    print("调用减法", op1, op2)

    return str(op1 - op2)

sum_tool = StructuredTool(

    name='calculate_sum',

    func=calculate_sum,

    description="计算两个数的和",

    args_schema=Calculation_input,

)

mul_tool = StructuredTool(

    name='calculate_mul',

    func=calculate_mul,

    description="计算两个数的积",

    args_schema=Calculation_input,

)

sub_tool = StructuredTool(

    name='calculate_sub',

    func=calculate_sub,

    description="计算两个数的差",

    args_schema=Calculation_input,

)

div_tool = StructuredTool(

    name='calculate_div',

    func=calculate_div,

    description="计算两个数的商",

    args_schema=Calculation_input,

)

tools = [sum_tool,mul_tool,div_tool,sub_tool]

llm_with_tools = llm.bind_tools(tools)
[/PRE8]

工具绑定完成后，用同样的方式重建图，把 chatbot 换成带工具的 llm。

[PRE9]
graph_builder = StateGraph(State)

def chatbot(state: State):

    return {"messages": [llm_with_tools.invoke(state["messages"])]}

#添加 chatbot 节点

graph_builder.add_node("chatbot", chatbot)
[/PRE9]
