ViT 流水线并行实战拆解：ColossalAI 配置与分段构建全流程

这份案例把 Vision Transformer 在 ColossalAI 上的流水线并行落地拆成可复用的配置、参数、模型分块与启动流程。整体思路是先固定并行与精度策略，再定义训练与模型尺寸，随后用注册机制实现可切分的 ViT，最后在分布式环境中按 rank 均匀分配层段并组装成完整模型。

并行与混合精度基础
流水线规模决定微批次数量，张量形状依据全局批次与微批次共同推导，fp16 采用朴素 AMP，梯度裁剪阈值统一控制以保证训练稳定。

    chunk = module_cls(**_filter_kwargs(module_cls.__init__, kwargs)).to(device)

if len(models) == 1:
