图灵已经给出一个斩钉截铁的结论：不存在任何一台图灵机能够判定另一台通用图灵机是否会停下来。停机问题因此是不可计算的，这意味着数学与信息学里没有一个终极的理论或程序可以包打天下，必然存在着一批问题根本算不出来。停机不可解的证明是决定性的——没有任何程序，仅靠阅读另一个程序的源代码，就能断定它最终会停下还是无限跑下去。这一论证其实就是哥德尔不完备性的图灵机表述。相比哥德尔在《数学原理》逻辑语法规格上的函数构造，图灵的版本要直观得多，甚至可以用一段简单的代码来呈现。

哥德尔第二不完备定理则进一步指出，不存在通用算法来甄别哪些命题系统是自洽的。对一个不可判定命题，你无计可施，只能写一个程序去检验它。程序本身很容易把命题表达出来，却可能耗费无穷时间才完成。只要这种不可判定性本身不能被证明，你就永远无法证明对应的程序是否会停机。

停机问题的难度已经暗示机械计算的力量是有限的。但要把结论严格化，似乎仍然绕不开哥德尔证明里那种魔幻的自指。把自指搬到图灵机上，自指的复杂性会扩散到图灵机所能覆盖的一切可描述算法。推论让人不寒而栗：人们常像鸵鸟一样承认哥德尔不完备定理难以避免，却幻想它只困扰极少数特殊命题，视而不见即可。而经由图灵机，哥德尔的不完备性被推广到了所有可以描述的问题，即我们能够理解并表述出来的全部问题；不可描述的才是真正的未知。这样一来，哥德尔的不完备性就伴随图灵机延伸到了现代计算机所处理的全部领域，其中也包括人工智能。

### 计算复杂性之谜
1956 年，哥德尔在给冯·诺依曼的信中谈到他对计算复杂性的直觉。对任意命题公式 F 和自然数 n，人们总能轻易构造出一台图灵机来判断 F 是否拥有长度为 N 的证明。基于这台机器，可以定义一个关于 F 和 n 的函数 ψ，让 ψ(F,n) 等于判定所需的步数 N。N 随 n 的增长速度有多快？若只是 n 或 n² 的量级，那将意义非凡。哥德尔的这一洞察事实上是最早的计算复杂性表述，也成为计算机科学的另一核心未解难题。

对一个算法，我们通常会分析运行时间与输入规模之间的函数关系，这就是时间复杂度，它定量刻画算法的效率。

以排序 n 个数为例，初级的冒泡排序耗时与 n² 成正比，更快的方法约为 n log n。最不切实际的做法是随机打乱输入直到恰好有序，这被戏称为“猴子排序”。前两种的时间复杂度记作 O(n²)、O(n log n)，后者平均达到 O(n·n!)。前两种是 n 的多项式，后一种是阶乘。当 n 很小，多项式已比指数更快；当 n 极大，人类根本等不到指数级算法结束。若一个问题存在多项式时间算法，就归入 P 类，即便数据规模庞大，人类仍能相对容易地得到解。NP 类则指能在多项式时间内验证解的正确性，但寻找解往往需要极长时间和计算量。电子邮箱密码就是典型：验证一个字符串是否等于密码是多项式时间的，而暴力破解需要按键盘有效字符数 K 的 l 次方量级的猜测，因而“破译密码”属于 NP 问题。

图 7–10 中最小的框 P 代表传统计算机可快速解决的问题集合，NP 则是传统计算机未必能迅速求解，但一旦给出答案就能快速验证的问题。NP 再向外延伸是 PH，多项式层次结构，可理解为传统计算机在现今与未来可能解决的所有问题的总和。下一章将结合量子计算说明量子 NP 问题。数学界著名的悬而未决在于 NP 是否最终等价于某一类 P 问题。若证明二者等价，今天看起来困难的问题终将找到有效解。这绝不是好消息，一旦 P 等于 NP，基于计算复杂性的通用密码与区块链等体系都会失去安全性。大多数科学家相信二者不等价，但近年的神经网络算法确实让一些曾被视为 NP 的问题出现了更简洁的解法，比如围棋曾被认为属于 NP，而 AlphaGo 在一定程度上给出了相对简洁的解法。

1993 年，计算机科学家伊桑·伯恩斯坦与优曼许·沃兹内尼为“有界误差量子多项式时间”提出了一个新复杂度等级 BQP。该类囊括量子计算机能够有效解决的所有判定问题。两人同时证明量子计算机可以解决传统计算机能够解决的所有问题，即 BQP 包含 P。

人们尚无法确定 BQP 是否包含 NP。若 P 在可解问题类上被证明与 NP 等价，不计复杂度，则可把 NP 看作传统计算机能解决的所有问题的集合。比较 BQP 与 NP 的目的，最终是判定量子计算机是否优于经典图灵机。

### 随机数的真相
经典计算机不擅长做一件事：像人一样抛硬币产生理想随机数。这件事看似简单，计算机却做不到。计算机产生的随机数本质上是确定的，多次询问同一问题总是得到同一答案。可以通过算法编程产生所谓的“随机”数字，但机器始终受程序支配，经过精心设计甚至可以消除随机性。在完全确定的机器上，无法得到真正意义上的随机数序列，因为生成遵循确定的算法。通常从一个共同的种子 N0 起步，按程序迭代。结果可能足够复杂难以看出模式，但由于是由预先定义的算法规划，产生的并非真随机，因而被称为伪随机数。

伪随机数发生器需要一个生成第 i 个数的算法 Rand(i) 与一个初始值种子 N0。冯·诺依曼 1946 年给出一个简单例子：取一个 2s 位整数 N0 为种子，平方得到 4s 位整数，不足时高位补 0，再取其中间 2s 位作为下一个种子，如此迭代可得到一系列随机数。当 N0=1234 时，产生的序列如表 7–4 所示：

完全基于确定性逻辑的伪随机数发生器永远不被视为纯粹的真正随机源，但在实践中常足以满足严格的安全关键应用。精心设计实现的伪随机数生成器可用于安全加密，大多数计算机生成的随机数即基于此。这些算法能自动创建具有良好随机属性的长数字序列，但最终受内存限制而重复，因而并非理想随机数。它们在多数场景下表现良好，却不及以电磁大气噪声为源的数字那样随机。对计算机模拟的大多数应用，伪随机数已足够。例如对海量数据随机抽样，只需把随机数字输入程序使样本位置大致均匀分布即可。iPod“随机”模式下的歌单也是伪随机顺序播放，循环可预测，但不妨碍享受随机聆听的美妙。

通过适当设计，计算机并非完全无法突破限制。结合物理世界的真实随机，机器可通过多种方式生成真正随机数。真正随机数在实际应用中价值重大。例如在线扑克网站，若黑客知晓随机数生成算法与种子，便能编写程序预测将出现的扑克牌。真正随机数使此类攻击不可能。我们可以依赖自然制造真实随机数，方法包括测量大气噪声、热噪声、外部电磁及量子现象等。例如短时间尺度上的宇宙背景辐射、放射性衰变、电路热噪声经放大截取后可获得真正随机数。

从天然来源获取随机数的速度取决于所测物理现象本身。自然产生的“真实”随机数有时很慢，需要收集大量数据直至满足需求。也可以采用混合方法，在可用时从自然源收集随机性，将其用作种子触发基于软件的伪随机数发生器，避免纯环境方法速率受限。利用机器时钟作为随机函数发生器的种子，以避免相同种子产生相同随机数，即是这种策略的例子。

### 混沌与不可预测
混沌很早就被经典物理与数学发现，却长期被刻意忽略。从经典数学视角看它不够干净，它告诉我们有些事物天生不确定，小概率可能带来大影响。这是牛顿力学与经典物理不愿多谈的议题，尽管经典力学在处理多体问题时早已看到混沌痕迹，它真正进入主流是在 20 世纪 60 年代以后。计算机数值能力的大幅提升让人们有信心以模型为基础，用数值模拟重现并预测任何现实事件。然而 20 世纪 60 年代的天气模拟发现，即使在确定模型基础上，也能产生非线性的不确定结果，无法准确预言。

南美洲一只蝴蝶扇动翅膀可能引发北美洲的风暴，理论上是可能的。麻省理工学院气象学家爱德华·洛伦茨长期研究天气预报，他用一组简化模型在计算机上模拟天气演变，原计划利用高速运算提高预报精度。但多次计算表明，初始条件的极微小差异会导致结果的巨大不同。1963 年的一天，为节省时间，他把输入值 0.506127 改写为 0.506 再算一遍。两个数值相差不大，按理结果也不该差太多，然而每一步的差异很快呈指数增长，没多久输出结果便天差地别。

混沌的发现与计算机密不可分，它也揭示了一类计算机无法完成的问题。动力学本身具有不可预测性，任何细微差别在演化一段时间后会导致完全不同结果。有限容量的计算机在表达数字时不得不近似，舍去小数点后微小位数，而这点差别会造成大相径庭的结果，计算机无法判断哪个更接近真相。因此混沌系统的长期演化准确结果无法用计算机精确计算，计算值与真实会相差甚大。研究表明，这种不确定性源于系统内在的动力学性质，与测量精度关系不大。由此物理学发展出非线性混沌理论，并延伸至分形数学、耗散系统与自组织行为。

### 量子随机与自由意志
雕塑家罗丹说作品早已埋在石头里，我只是把它挖出来。这引出了一个重要话题：什么是自由创作，或什么是自由意志？

• 我们是否因为自由意志创造了作品？

• 或者作品早已存在，我只是去除了周围的石头？如果是这样，作品是注定的。

我们无法通过检查证据来回答这个问题。在哲学术语中，它“在经验上是无法回答的”。这是哲学家们争论的内容。宗教人士可能会援引经文支持某一结论。然而在物理学中，量子随机性为自由意志提供了启示，甚至可能本身就是我们拥有自由意识的源头。

牛顿给出了经典物理中运动、力、重力等原理的优雅描述，用以诠释上帝的伟大设计。人们相信，只要知道物体此刻的运动状态与受力情况，就能准确预言其未来所有运动状态。从苹果到行星，都可在人类掌握的数学工具里精确把控。在经典物理世界，随机性甚至不存在。抛硬币正面背面各 50% 只是方便的统计模型，它给出大致预期，假设硬币均匀且无干预。现实中硬币翻转受制于拇指推力、风与气流、硬币两面物理特性等，这些因素都是确定的，硬币运动可由经典物理定律描述。可以说，经典物理所说的随机性，只要数据足够仔细、采集充分、模型精确、运算能力强大，就是确定性的。

因此爱因斯坦不喜欢量子力学声称的纯粹随机性。他 famously 说“上帝不掷骰子”。爱因斯坦认为量子系统坍缩到某状态的概率必须像掷硬币一样。在硬币被抛起前，我们只能概率性推测结果，正反面。在空中之后，结果由环境决定，通过好的数学工具与足够预先测量，我们总能知道确定性结果。实践中多次翻转硬币会得到一半正面一半反面，这不是因为环境不确定，而是确定环境不会让任一面占优。

爱因斯坦认为量子力学也必须遵循类似规律。宇宙中存在更深层次的未知规律，应该有一套更好的理论解释量子力学的所有问题并预测新现象，他称之为隐变量理论。因为我们不知道它们是什么，能做的最好就是用概率模型解释观察。如何确信没有我们尚未知道的隐藏东西呢？

问题在于，我们所做的事是注定的还是由自由意志选择的？量子波函数坍缩时，是否因一个未知的潜在原因而坍缩，正如爱因斯坦所想？这种坍缩是否与观测者自身行为无关？这些问题启发我们思考自然中自由意志的含义。若它是伪随机的，我们今天的意识可能在数千年前就可被计算与预测，暂且忽略计算复杂性。若量子随机真的在底层起作用，这些行为将永远无法预测，我们具有自由意识。

20 世纪 60 年代，英国工程物理学家约翰·贝尔提出了检验量子随机性的关键证明。贝尔定理最终证实量子随机并非被更深层次规律决定。大自然不可预测的自由行为不由先验可追溯的算法决定。通过量子坍缩，宇宙不断产生新信息。在贝尔定理下，经典力学描述的翻转硬币机制不再适用于量子力学。在量子世界，完全相同条件下翻转相同硬币，有时正面有时反面，宇宙中没有任何因素决定其随机结果。

这是否意味着量子随机性导致了我们思维的独立与自由？尽管量子随机性作为大脑工作原理的解释仍大胆且证据不足，它确实启发了密码学方面的有价值应用，例如使在线金融交易更安全。伪随机数生成器生成随机数字串作为交易代码源，甚至能通过随机性安全测试。但如果用于生成的确定性规则可被逆向工程，一旦算法与种子被知晓便可被破解或准确预测。若系统被黑客入侵，这些信息会被获取，可靠性无法保证。相较之下，由于量子世界确实是随机的，量子随机数发生器是一种潜在解决方案。这并非抽象，当你在网上转账时，手机会从银行收到一串交易代码以保证可靠性，但这串代码迄今仍多由伪随机函数生成，有足够能力的黑客可确定地获知数值，从而威胁交易安全。

牛津大学物理学家罗杰·彭罗斯认为，人类思维的非算法即不可计算特征，如创造力，源于大脑微管中的量子坍缩。若他正确，我们的大脑正在创造真正新鲜的新信息。但有一个问题：量子坍缩产生的信息只是随机的，若缺乏一定意义上的关联，便是随意且无用。仅凭随机性无法在创造性思维中产生明显复杂性，神经元中随机的嗡嗡作响不会解决哪怕最简单的数学问题或写出一部伟大小说。会有一群猴子在打字机上打出莎士比亚著作吗？数学上只要猴子足够多、时间足够长，总有机会，但物理上我们无法让大脑每个原子的状态都随心所欲地坍缩，而让行为与意识被这些随机的不良结果控制。要知道只有那一部莎士比亚是有用的，其他都是废物，而产生它的概率极其微小。因此要形成有意义的自由想法与意识，大脑必须为一般目的组织量子坍缩形成的新信息，我们仍无法解答创造力如何在思维中发生。我不认为大脑是单纯达尔文方式进化出来的，简单机械系统产生不出大脑，生命力是宇宙元素的组织形式，它遵循特定的作用规律，这些规律既不是简单的也不是机械的。
