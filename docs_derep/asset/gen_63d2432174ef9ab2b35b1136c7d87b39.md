# 前言
PREFACE

## 迎接 AI Agent 的生产力革命

初次对话 ChatGPT 时，我有种在和一位博学智者交流的惊喜感。历史典故、科学原理，它都能娓娓道来，文字润色也能轻松完成。可这种惊喜很快被落差取代——一旦需要真正上手做事，ChatGPT 就像一位只会出谋划策的军师，思路清晰，却从不伸手执行。

这种感受很常见。如今数百万人每天用 AI 聊天，却掉进同样怪圈：建议很完美，执行全靠自己。身边坐着一位知识渊博的顾问，他能给出专业点评，却不能替你整理数据、生成图表。最后袖子还是得自己挽起来，或者求助懂编程的同事。

这不是 ChatGPT 或 DeepSeek、Claude、文心一言 等大模型本身的失误，而是先天局限。它们被困在文字构成的平行空间，只能用语言沟通。会“说”不会“做”，缺的是真实执行力——打不开电脑、读不了本地文件、完不成实际任务。

举个例子，市场部的小李手头有一份 2000 条销售记录的 Excel，明早就要汇报区域趋势和图表。传统 AI 能告诉他该用哪些函数，甚至写好 Python 代码。但之后复制、运行、整合演示，仍要小李亲力亲为，本该轻松的活被执行断层拖得很繁琐。

AI 研究里把这种现象称为“执行鸿沟”。调研显示，知识工作者每周平均浪费 10.5 小时在可自动化的重复事务上，折合下来一年白丢 500 小时以上。

正是在此背景下，AI Agent 出现并推动 AI 从“理解”走向“行动”。如果说传统 AI 是囚禁在笼中的超脑，AI Agent 就是长出身体的智能体，能在数字世界自主行动，弥合理解与执行的距离。

AI Agent 不仅能听懂指令，更像办公室的数字同事，自主拆解任务、调用工具资源，最后把结果交付。从网页浏览、文档处理、数据分析，到预约会议、发送邮件，都能一气呵成。模式从“我告诉你怎么做”变为“我帮你做完”。

本书的主角 Manus，便是这一类通用 AI Agent。名字源自拉丁语“手”，寓意把双手延伸到数字世界。分析销售数据时，你只需说“读这个 Excel、清洗数据、画月度趋势图”，它就会自动读取、分析、制图、汇总，最终给出完整报告。你可以去喝杯咖啡，或专注更有创造性的工作。

Manus 的日常用途覆盖面广：

- 营销人员让它监控社媒反馈并自动输出分析报告；
- 研究人员让它检索整理最新论文并提炼要点；
- 开发者把它当编程助手，不仅给建议还能直接测试调试；
- 家长也能用它规划假期行程，自动比价航班和酒店评价。

设想一下，如果你每天有 30% 时间被必要却机械的事务占据，Manus 能把这些时间全部释放，一年下来相当于多出近两个月的高效工作。这就是 AI Agent 带来的生产力跃迁。

本书将带你快速上手 Manus，掌握核心功能与实操技巧。无论是技术新手还是资深玩家，都能迅速让 Manus 成为得力助手。通过大量案例与手把手教程，立刻感受 AI Agent 的效率飞跃。

初识AI Agent

清晨醒来，智能助手已为你汇总睡眠数据、推送天气、筛出重点邮件，还按日程规划了最优通勤路线。更让人意外的是，下午会议的材料已被整理好，潜在问题与答案也提前列出。这不是科幻情节，而是 AI Agent 正在塑造的日常体验。

## 1.1 什么是AI Agent？

### 不仅仅是聊天

“这不就是 Siri 或 ChatGPT 吗？”很多人会这么问。实际上 AI Agent 的能力远超熟悉的语音助手和聊天机器人。

传统 AI 助手像只会纸上谈兵的教练，告诉你怎么做，自己却不动手。AI Agent 则像既懂策略又能上场的队友，不仅理解指令，还会主动思考并付诸行动。

通俗讲，它是一个具备感知、思考和行动能力的智能系统。

[PRE2]
图1-1 AI Agent 的四大核心能力

- **感知环境：** AI Agent 有自己的“眼”和“耳”。能读懂指令、理解屏幕内容、浏览网页信息、感知时间与系统状态。你说“准备明天的演讲”，它就知道要收集资料、梳理要点、制作幻灯片。
- **思考判断：** 这是其“大脑”。研究发现，顶尖 AI Agent 解决问题的神经网络激活模式与人类思考惊人相似。它会分析现状、规划步骤、预估结果，再择优行动。
- **采取行动：** 最大的差异点——它能真正“动手”。打开应用、处理文件、发送信息、编写代码、分析数据、生成报告，都可独立完成，相当于把虚拟助手从聊天框解放出来。
- **达成目标：** 所有能力都服务于结果。无论整理混乱邮箱还是推进复杂项目，AI Agent 都能像尽责助理一样逐项击破。

## AI Agent与其他AI应用的区分

“智能音箱算 AI Agent 吗？”不完全算。想象三种数字助手。

简单聊天机器人：像只会查菜谱的厨师助理，你问做法它告诉你，但你得自己做。

基于规则的系统：像按固定食谱炒菜的自动炒菜机，只能执行预设流程，遇突发状况就卡住。

真正的 AI Agent：像能根据冰箱食材、口味偏好和健康需求，创造性设计并烹饪完美晚餐的星级大厨。它能学习、适应、创新，而非单纯执行。

## 1.2 进化之路：从聊天机器人到推理模型，再到通用智能体

把 AI 发展比作文明史，我们正处从“青铜”迈向“铁器”的关键期。回溯一下演进脉络（图1-2）。

[PRE3]
### 最初的雏形：早期聊天机器人

1966 年，麻省理工的约瑟夫·维森鲍姆创造了 ELIZA，一个模拟心理治疗师的程序。200 多行代码，仅做简单句式替换，却让不少用户产生情感依赖，形成了著名的“ELIZA 效应”。早期机器人像会鹦鹉学舌的助手，能回音却不理解，缺乏主动思考。

### 智能的进阶：规则系统与专家系统

20 世纪 80 年代起，人们开始把专家知识编码进系统。MYCIN 能诊断血液感染并推荐治疗，准确率超过部分医学院学生。该阶段系统有初步“判断力”，却像背台词的演员，只能在固定剧本里表演。

### 理解的飞跃：推理模型与语言理解

21 世纪初机器学习浪潮重塑 AI。2011 年 IBM Watson 在《Jeopardy!》击败人类冠军，证明复杂问题处理能力。此时 AI 已具备“思考”能力，能处理自然语言、识别模式、做分析，却仍像困在象牙塔的学者，知识丰富但现实互动有限。Watson 想查最新信息却打不开浏览器，需要分析数据却无法操作 Excel，“懂却做不到”是传统 AI 的最大短板。

### 行动的革命：智能体 AI 的崛起

近年随着 ChatGPT、Claude 等大语言模型兴起，AI 从被动响应转向主动行动。现代 AI Agent 如从书中走出的角色，获得了与现实交互的能力。不仅理解需求，还能规划路径并执行。AutoGPT 可连续完成复杂任务，Claude 能直接操作用户电脑，Operator 可自主浏览网页并填表。

这相当于从“画建筑图纸”到“亲手盖楼”。AI 不再只给建议，而是能直接帮你把事做完。

### 智能的分级：AI的发展阶段

要判断当前所处阶段，OpenAI CEO 萨姆·奥尔特曼提出的五级分类很有参考价值（图1-3）。

[PRE4]
1. 对话式 AI：能与人自然交流的聊天助手。
2. 推理者：能解决复杂问题的思考者。
3. 代理：能独立采取行动的执行者。
4. 创新者：能产生新想法与发明的创造者。
5. 组织者：能管理整个组织工作的协调者。

我们正处在从推理者向代理过渡的关键期。虽然完全自主的代理仍在进化，但现有版本已能显著提升效率。

想想日常里那些费时又机械的事务：整理邮件、汇总数据、查找资料、格式化文档。研究表明知识工作者每天约 2.8 小时花在这些事上。若 AI Agent 接手释放的时间，你会用来做创新、学习还是陪伴家人？

AI Agent 未来或将不只是个人助手，更成为团队协作枢纽。想象研究型代理收集数据、创意型代理提出方案、实施型代理执行计划、监控型代理追踪成果的虚拟团队，这种协作可能重构工作方式。

## 1.3 AI Agent的魔力：自主、智能与目标导向的完美结合

为什么有些 AI 只会答题，有些却能主动把事办好？来看 AI Agent 与普通 AI 的关键差异（图1-4）。

[PRE5]
### 自主性：主动执行，而非被动响应

普通 AI 像被动的图书管理员，有问才答；AI Agent 像私人助理，你说出目标，它自行规划并完成所有步骤。

> 周一早晨，你匆忙出门，随口说“帮我整理收件箱，把重要邮件标记”。洗漱回来，所有邮件已分类，会议邀请已进日历，垃圾邮件已过滤。你甚至没教它流程。

传统系统需要一步步指令：“打开邮箱”“找今天邮件”“分类”“标记”。AI Agent 只要目标，中间路它自己走。就像好厨师，你说“做份意面”，他从切洋葱到煮面一条龙完成。

### 智能性：不只是听懂语言，更懂意图

AI Agent 的智能体现在理解语言，更在于洞察需求背后的逻辑。

> 你说“下周去上海开会，帮我安排行程”。智能 Agent 会考虑你偏好早班还是晚班、航空公司、酒店离会场近还是市中心，甚至记得你上次抱怨某酒店 WiFi 差，这次自动避开。

这种“记住喜好”的能力很人性化。它不像传统 AI 每次失忆从零开始，而像老朋友，越相处越懂你。科技作家凯文·凯利说过：“最好的技术是比我们更懂自己的技术。”AI Agent 正朝此方向迈进。

### 目标导向性：始终聚焦终点

打电话给客服被转接五次，每次重复问题，最后仍未解决，这就是缺乏目标导向。AI Agent 始终牢记目标，所有行动为之服务。

> 你提出“找一份适合初学者的五日健身计划”，它不会只甩链接或泛泛而谈。它会考虑适合度、所需装备、每日安排、伤病预防，所有思考围绕一个核心：为你找到最合适的计划。

这种聚焦让它高效，不被无关信息干扰。像经验丰富的猎人，盯住猎物而非每片树叶（图1-5）。

[PRE6]
### 行动能力：执行者，而非建议者

最不同的是行动力。传统 AI 像只会说话的智能书架，AI Agent 是能干活的数字助手。

> 对传统 AI 说“我要订明天去北京的机票”，它会回“可通过官网或平台预订”。然后没然后了。换成 AI Agent，它会连到订票系统、查航班、比价格、按历史偏好选座位并完成预订，最后告诉你：“10:30 的航班已订，登机牌发邮箱了。”

与外部世界的交互让它真正有用。不仅提供信息，更是行动执行者。像科幻里的管家机器人，不仅答问题，还会做事。

这些特质结合起来，AI Agent 成为改变生活与工作的工具。日常可订餐厅、排会议、筛信息、管理日程；专业上可助研究、写报告、分析数据、制定策略。随着技术演进，能力边界仍在扩张。

不过也需思考：越强大越要可控。正如“能力越大，责任越大”，我们要确保 AI Agent 始终按人意运行，既强大又安全。

你更期待一种帮你消解枯燥工作的助手，还是能激发创意的伙伴？无论哪种，AI Agent 的未来已开启，这场革命才刚刚开始。
