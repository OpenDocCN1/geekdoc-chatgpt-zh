在处理合同、规范或技术文档时，快速定位编号条款往往是第一步。我们先用正则把形如 1.、1.1、1.1.1 的层级编号和后面紧跟的正文拆出来，得到一个编号到文本的清单。随后这个清单会被整理成两种检索形态：一种是把每个编号直接映射到内容的一维字典，查询时只要键名是否存在；另一种是按点号拆分层级，逐层构建嵌套结构，让父级节点可以携带子节点，形成树状索引。查询函数在平铺结构里做直接取值，未命中返回 Not Found；在层级结构里则沿编号路径下探，返回对应节点的完整信息。

如果只有抽取还不够，跨语言检索往往需要更鲁棒的向量表示。这里给出一个简化的多源嵌入融合实验思路，用三个占位模型分别模拟 BGE、LaBSE 和 Qwen 的输出，每个模型都是 300 维输入到 128 维的线性投影加 ReLU。融合模型把三路向量在通道维度拼接，再用一个全连接层压回 128 维，得到统一的多语言表征。数据是随机生成的 300 维特征，训练时以输入前 128 维经 tanh 变换后的信号作为伪监督，用 Adam 优化 MSE 损失，打印每轮损失以观察收敛。

import torch

import torch.nn.functional as F

import random
import time
# 设置随机种子，确保结果可复现
torch.manual_seed(42)
np.random.seed(42)

# 模拟 BGE 模型：生成随机多语种嵌入向量
class DummyBGE(nn.Module):
    def __init__(self, embed_dim=128):
        super(DummyBGE, self).__init__()
        self.embed_dim=embed_dim
        self.linear=nn.Linear(300, embed_dim)
    def forward(self, x):
        # x: [batch, 300] 模拟预训练文本特征
        out=self.linear(x)
        return F.relu(out)
# 模拟 LaBSE 模型：生成随机多语种对齐嵌入向量
class DummyLaBSE(nn.Module):
    def __init__(self, embed_dim=128):
        super(DummyLaBSE, self).__init__()
        self.embed_dim=embed_dim
        self.linear=nn.Linear(300, embed_dim)
    def forward(self, x):
        out=self.linear(x)
        return F.relu(out)
# 模拟 Qwen 模型：生成领域适配嵌入向量
class DummyQwen(nn.Module):
    def __init__(self, embed_dim=128):
        super(DummyQwen, self).__init__()
        self.embed_dim=embed_dim
        self.linear=nn.Linear(300, embed_dim)
    def forward(self, x):
        out=self.linear(x)
        return F.relu(out)
# 定义混合嵌入模型，将 3 种嵌入进行融合
class MultiLanguageEmbedding(nn.Module):
    def __init__(self, embed_dim=128):
        super(MultiLanguageEmbedding, self).__init__()
        self.embed_dim=embed_dim
        self.bge=DummyBGE(embed_dim)
        self.labse=DummyLaBSE(embed_dim)
        self.qwen=DummyQwen(embed_dim)
        # 融合层：拼接后通过全连接层降维
        self.fusion=nn.Linear(embed_dim * 3, embed_dim)
    def forward(self, x):
        # x: [batch, 300] 输入特征向量
        emb_bge=self.bge(x)
        emb_labse=self.labse(x)
        emb_qwen=self.qwen(x)
        # 拼接 3 个嵌入
        concat_emb=torch.cat((emb_bge, emb_labse, emb_qwen), dim=1)
        fused_emb=self.fusion(concat_emb)
        return fused_emb

# 定义简单的训练函数
def train_embedding_model(model, data, epochs=20, lr=0.01):
    """
    训练多语种混合嵌入模型，使用 MSE 损失模拟监督目标
    参数：
        model: MultiLanguageEmbedding 模型示例
        data: 输入数据，形状为 [batch_size, feature_dim]
        epochs: 训练轮数
        lr: 学习率
    返回：
        model: 训练后的模型
    """
    optimizer=optim.Adam(model.parameters(), lr=lr)
    # 模拟目标为原始数据的一个非线性变换，作为伪监督信号
    target=torch.tanh(data[:, :model.embed_dim])
    loss_fn=nn.MSELoss()
    for epoch in range(epochs):
        model.train()
        optimizer.zero_grad()
        output=model(data)
        loss=loss_fn(output, target)
        loss.backward()
        optimizer.step()
        print(f"Epoch {epoch+1}/{epochs}, Loss: {loss.item():.6f}")
    return model
