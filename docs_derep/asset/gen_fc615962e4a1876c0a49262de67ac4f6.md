线性回归从点积到迭代收敛的四段实操笔记

线性模型的核心就是用参数对特征做加权求和，得到对样本的估计值。下面这段最简实现展示了预测是如何通过矩阵点积完成的。

h_pred = np.dot(x, theta)

接下来是误差的量化方式。能量函数把所有样本的预测结果汇总起来，以平方误差的形式衡量整体偏离程度，并通过一次矩阵运算得到标量损失。

[PRE1]python

def error_function(theta, x, y):

    h_pred = np.dot(x, theta)

    j_theta = (1./2*m) * np.dot(np.transpose(h_pred), h_pred)

    return j_theta

为了让几何意义更直观，可以把参数空间可视化。代码里用向量 A 定义一条过原点的直线，用点 C 表示一个待投影的目标点，通过最小二乘投影得到 P。图中同时标出了原点 O、直线方向、点 C 到 P 的垂线以及原点到 C 的连线，便于理解投影的本质。

最后是梯度下降的实际训练流程。这里有三维特征的数据集，学习率设为 0.02，收敛阈值设为 0.002。每次遍历全部样本时根据预测误差对三个参数同步修正，并用累加的半平方误差判断是否收敛。迭代停止后打印最终参数、损失以及迭代次数。

[PRE3]python

x = [(2, 0, 3), (1, 0, 3), (1, 1, 3), (1,4, 2), (1, 2, 4)]

y = [5, 6, 8, 10, 11]

epsilon = 0.002

alpha = 0.02

diff = [0, 0]

max_itor = 1000

error0 = 0

error1 = 0

cnt = 0

m = len(x)

theta0 = 0

theta1 = 0

theta2 = 0

while True:

    cnt += 1

    for i in range(m):

        diff[0] = (theta0 * x[i][0] + theta1 * x[i][1] + theta2 * x[i][2]) - y[i]

        theta0 -= alpha * diff[0] * x[i][0]

        theta1 -= alpha * diff[0] * x[i][1]

        theta2 -= alpha * diff[0] * x[i][2]

    error1 = 0

    for lp in range(len(x)):

        error1 += (y[lp] - (theta0 + theta1 * x[lp][1] + theta2 * x[lp][2])) ** 2 / 2

    if abs(error1 - error0) < epsilon:

        break

    else:

        error0 = error1

print('theta0 : %f, theta1 : %f, theta2 : %f, error1 : %f' % (theta0, theta1, theta2, error1))

print('Done: theta0 : %f, theta1 : %f, theta2 : %f' % (theta0, theta1, theta2))

print('迭代次数: %d' % cnt)
