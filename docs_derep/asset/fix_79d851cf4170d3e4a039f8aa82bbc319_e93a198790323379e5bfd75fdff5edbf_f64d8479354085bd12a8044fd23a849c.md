第一步：理解提示词的基本概念与作用
+ 1. 什么是提示词
定义：输入模型的指令或问题，用于引导特定输出。
作用：决定回答方向、风格、深度与格式。
类比：如同给模型一份任务说明书，越清晰完成度越高。
+ 2. 重要性
影响输出质量：设计直接决定内容质量与相关性。
提高交互效率：好提示减少反复调试。
解锁模型潜力：精心设计可完成复杂任务。
如何开始实践？
+ 1. 观察示例：阅读高质量示例，分析结构。
示例：“你是一位历史老师，请用浅显语言解释工业革命影响。”
+ 2. 简单尝试：从简单任务起步。
示例：“写一段夏天的描述。”
+ 3. 记录反思：记录提示与输出，分析改进点。
示例：若描述过短，可补充细节：“写约 100 字的夏天描述，重点写阳光与海滩。”
