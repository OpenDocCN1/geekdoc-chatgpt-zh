openclaw config set security.sandbox.allowedPaths '["~/workspace", "~/Documents/projects"]'

# 直接禁止删除文件
openclaw config set security.permissions.delete false

# 停用 Shell，进入只读模式
openclaw config set security.permissions.shell false

**用权限白名单做精细授权**
沙箱只能限定目录范围，要对各类操作做分级裁决就用白名单。下面这份配置把不同行为拆开设定：放行、需确认、直接拒绝。

{
 "security": {
  "permissions": {
   "fileRead": "allow",
   "fileWrite": "confirm",
   "fileDelete": "deny",
   "shellExec": "confirm",
   "networkRequest": "allow",
   "sendMessage": "allow"
  },
  "confirmThreshold": {
   "description": "需要用户确认的操作阈值",
   "fileSize": "10MB",
   "batchSize": 10
  }
 }
}

处置方式只有三种：allow 直接执行、confirm 执行前弹窗询问、deny 直接拦截。把写文件和 Shell 执行设为 confirm，关键操作必须经你同意；删除设为 deny，从源头切断风险。
[PRE0]

**注意**
新接入的渠道尤其是群聊，建议先用最严配置跑一段时间，确认行为可控再逐步放开。群里一次 @ 就可能触发 Shell，这个风险点必须提前封堵。

**行为审计，掌握实际运行情况**
进阶用法建议定期翻看行为日志，特别是存在定时任务时，不监控等于盲飞。

# 只看 Shell 执行记录

# 开启实时操作通知
openclaw config set security.audit.notify true
openclaw config set security.audit.channel feishu

开启后每次写文件、跑脚本、发消息等操作，飞书都会推送一条提醒。前期建议先开几天，等行为稳定后再决定是否关闭。
