### 7.5 Hopfield 神经网络

上世纪 60 年代初至 80 年代初，神经网络研究曾陷入漫长的“冰河期”。直到 80 年代中期，霍普菲尔德凭借在网络建模与应用上的突破性成果，在全球范围内重燃了该领域的研究热情。1982 年与 1984 年，他先后建立了离散型与连续型 Hopfield 网络，创造性地引入“计算能量函数”概念并给出稳定性判据，更给出了电子电路实现方案，为神经计算机奠基；同时开辟了联想记忆与优化计算的新赛道，极大推动了学科发展。这两大模型至今仍是神经优化计算的基石。

#### 7.5.1 离散型 Hopfield 神经网络

#### 7.5.2 连续型 Hopfield 神经网络

离散模型中神经元的二态输出与生物神经元的连续特性及时滞效应存在差距。1984 年，Hopfield 提出连续时间模型，允许神经元状态在 0~1 之间连续取值。

其电子电路实现原理图如图 7.11 所示。

[PRE25]

图中，每个神经元由电阻 $R_i$、电容 $C_i$ 及饱和非线性运放模拟，输出 $v_i$ 反馈至其他神经元（无自反馈）。$u_i$ 为膜电位，$v_i$ 为输出，$C_i$ 模拟膜电容，$R_i$ 模拟跨膜电阻，$R_i C_i$ 并联决定时间常数，输出 $v_i$ 对 $u_j$ 的影响模拟突触连接，运放的非线性饱和特性模拟神经元激活函数。

基于基尔霍夫电流定律，连续型网络的动力学方程为：

$\frac{1}{R_i}u_i + C_i \frac{du_i}{dt} = I_i + \sum_{j=1}^N w_{ij} v_j \quad (7.86)$

$v_i = f(u_i) = \frac{1}{1 + e^{-\frac{2u_i}{u_0}}}, i = 1, 2, \cdots, N \quad (7.87)$

式中 $I_i$ 为偏置电流（外部输入）；$w_{ij} = 1/R_{ij}$ 表征突触连接强度；$f(u_i)$ 为近似 Sigmoid 的运放传输特性。

该模型在简化生物细节的同时，保留了四大关键特性：Sigmoid 传输特性、膜电位时空整合、大量兴奋/抑制反馈连接、兼容脉冲与渐进编码神经元。因此它更忠实地保留了生物网络的动态非线性本质，有助于揭示大规模神经元协同产生计算智能的机理。

连续型网络的计算能量函数 $E(t)$ 定义为：

$E(t) = -\frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N w_{ij} v_i(t) v_j(t) - \sum_{i=1}^N v_i(t) I_i + \sum_{i=1}^N \frac{1}{R_i} \int_0^{v_i(t)} f^{-1}(v) dv \quad (7.88)$

**定理 7.4** 对于连续型 Hopfield 网络，若 $f^{-1}(\cdot)$ 为单调递增连续函数，$C_i > 0, w_{ij} = w_{ji}$，则 $\frac{dE(t)}{dt} \leqslant 0$；当且仅当 $\frac{dv_i(t)}{dt} \leqslant 0 (1 \leqslant i \leqslant N)$ 时，$\frac{dE(t)}{dt} = 0$。
