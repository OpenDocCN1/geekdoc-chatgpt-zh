该项目基于 FastAPI 实现了 MCP，即 Model Context Protocol 的服务端，核心作用是统一管理模型的上下文数据。数据持久化依赖 Redis，并且内置了 API Key 鉴权、调用统计以及健康检查等常用能力。

作为一个常驻服务，程序不会主动输出业务结果，启动时会在 0.0.0.0:8000 上起一个 Web 服务并持续监听请求。只有当客户端以 HTTP 方式访问到预定义的接口时，服务端才会返回对应结果。想验证效果，可以用 curl、Postman 或浏览器等工具向这些接口发起请求查看反馈。
