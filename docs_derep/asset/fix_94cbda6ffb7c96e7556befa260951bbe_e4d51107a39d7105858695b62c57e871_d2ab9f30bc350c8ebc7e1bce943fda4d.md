自注意力机制的核心思路，是把序列里所有向量的信息按相关性加权融合为新的表征。下面先聚焦 Transformer 的编码流程，因为扩散模型主要依赖图像特征来拟合分数函数或逆向转移核的参数。让 Transformer 处理图像，先用 Patch 切分把空间信息变成 token 序列，再叠加位置编码。每个 token 经过可学习的线性投影得到各自的查询向量、键向量、值向量 Q_i、K_i、V_i，随后计算两两配对分数 <Q_i,K_j>/√d_k，d_k 为键的维度。对分数做 softmax 得到注意力权重 a_ij，最终输出 z_i = Σ_j a_ij v_j，再送入前馈网络继续加工。

查询、键、值的概念来自信息检索。例如用户在电商平台搜索“深度学习代码参考书”，输入即为 Query，系统匹配的关键词“深度学习”“代码”“参考书”是 Key，按相似度返回的商品信息是 Value。因此 <Q_i,K_j> 可视为向量间的相关性，a_ij 表示 i 对 j 的关注程度。为防训练退化，自注意力引入了残差连接。一个向量可以产生多组 QKV，对每组分别计算后拼接，这就是多头注意力，如图2-9 所示[293]。堆叠多个 Transformer 块即可构成可训练网络。在扩散场景中，可用 Transformer 对每步加噪图像编码，以编码结果预测下一步转移核的均值与方差，从而替代 U-Net。

# DiT 用 Transformer 重塑扩散生成

Peebles 等人在 Scalable Diffusion Models with Transformers 中提出 DiT，用 Transformer 取代 U-Net。实测吞吐更高、Gflops 更优，条件生成质量也更强。该 DiT 框架如图 2-10 所示，核心是在潜在扩散 Transformer 的基础上设计三种条件注入方式，把每步的 temb、label 等引导信息送入网络：（1）自适应层归一化。把标准 Layer Normalization 换成 Adaptive Layer Normalization，用条件信息动态生成缩放和偏移参数；（2）交叉注意力。让引导信息直接与中间特征在注意力层里混合；（3）上下文条件。把引导信息作为额外输入拼在序列前端。其中 AdaLN 效果最好、速度也更快。ImageNet 上的生成实验验证了 Transformer 式扩散架构的优越性。

+   * （1）自适应层归一化。把标准层归一化替换为 AdaLN，由条件信息实时生成缩放与平移系数；
* （2）交叉注意力。条件信号与网络中间特征在注意力机制中直接融合；
* （3）上下文条件。把条件信息作为附加输入接在序列前端。
