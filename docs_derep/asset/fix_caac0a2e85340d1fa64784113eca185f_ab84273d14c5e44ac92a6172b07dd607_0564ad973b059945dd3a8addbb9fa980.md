# 第 5 章 智能网联驾驶碰撞预警应用

[PRE14]

智能网联驾驶碰撞预警应用

碰撞类事故在各类交通事故中占比较高，且碰撞会造成车体较大破坏，往往后果严重，对乘员伤害高于其它类型。如何持续有效减少碰撞事故发生并降低危害，是交通从业者的难题。

从成因看，碰撞事故源于驾驶员、车辆与环境三要素共同作用。如驾驶员因接打电话、疲劳或环境影响注意力分散，或车距过近前车急刹反应不及易导致追尾、剐蹭；车身或障碍物遮挡造成视野盲区，在变道或复杂路口易因看不到盲区内的车辆、行人而碰撞；恶劣天气如浓雾、暴雨限制观察距离并影响制动效果，也易引发碰撞。

因此针对潜在碰撞风险提前预警十分必要，通过提醒驾驶员未注意到的风险，避免事故或降低伤害。

在 V2X 场景下，搭载智能车载终端的车辆可相互通信，共享驾驶状态与意图，有效减少车车碰撞，如追尾、盲区剐蹭、交叉路口相撞，并通过车载 HMI 预警驾驶员。

此外，V2X 落地应用具有传统 ADAS 不可比拟的优势。V2X 对碰撞事件的预测主要依赖高精度 GNSS 的采样频率、精度及预测算法精度，对数据交互频率与时延要求并不极高，只要与 GNSS 采样大致匹配即可，从而降低时间同步要求，减少设备计算消耗。

## 5.2 前向碰撞预警技术

### 5.2.1 前向碰撞预警的定义

前向碰撞预警 Forward Collision Warning，FCW 指主车 HV 在车道行驶，与前方同车道远车 RV 存在追尾碰撞危险时，对 HV 驾驶员进行预警。本应用适用于普通道路或高速公路等车辆追尾碰撞危险的预警。FCW 辅助驾驶员避免或减小前向碰撞危害，提高道路行驶安全系数。

### 5.2.2 前向碰撞预警的主要场景

根据功能定义，当 HV 与同车道 RV 相对距离小于阈值时 FCW 触发。FCW 包括如下四种主要场景。

### 5.2.3 前向碰撞预警的基本原理与算法实现

## 5.2 前向碰撞预警技术

若 HV 行驶过程中与同一车道前方 RV 存在碰撞危险，则 FCW 应用会向 HV 驾驶员发出预警。触发 FCW 功能的 HV 与 RV 位置关系如图 5.5 所示，其中 HV 与 RV 同车道，RV 在 HV 前方。

FCW 基本工作原理如下。

① HV 车载通信单元接收 RV 发送的 BSM，分析接收到的消息，筛选出位于同一车道前方区域的 RV，并进一步筛选出处于一定距离范围内的 RV 作为潜在威胁车辆。
② 计算每一个潜在威胁车辆的碰撞时间 TTC 或防撞距离，筛选出与 HV 存在碰撞危险的威胁车辆。
③ 若有多个威胁车辆，则筛选出最紧急的威胁车辆。
④ 系统通过 HMI 对 HV 驾驶员进行相应的碰撞预警。

[PRE19]

图 5.5　触发 FCW 功能的 HV 与 RV 的位置关系

本节实现 FCW 算法的具体思路如下。

① 定义函数 doFCW，接受三个参数——hvInfo、rvInfo 和 fcwTTC，其中 hvInfo 与 rvInfo 表示主车与远车信息，fcwTTC 表示前向碰撞预警时间阈值。
② 函数内部首先初始化两个变量：warning_flag 与 adviser。warning_flag 表示预警等级，其中 0 表示无需预警，1 表示需要减速预警，2 表示需要紧急停车预警。adviser 表示建议类型，其中 keep 表示保持当前状态，slow_down 表示减速行驶，emergency_stop 表示紧急停车。
③ 分别从 hvInfo 与 rvInfo 中提取主车与远车的 x 坐标与 y 坐标、速度、航向角、尺寸与车辆类型，并赋值给相应变量。
④ 判断主车是否静止，速度小于 0.1，则直接返回 warning_flag 与 adviser，即无需预警。
⑤ 调用 my_gps2xyz_ver2、my_calc_distance、determineTCType 三个自定义函数，分别计算主车与远车之间的纵向、横向与直线距离以及相对位置关系。
⑥ 判断远车是否在主车正前方，若是则进行前向碰撞预警判断。
⑦ 计算两车之间碰撞时间，若该时间小于 fcwTTC，则将 warning_flag 设为 1，并将 adviser 设为 slow_down，然后计算两车之间除去各自长度一半后剩余距离 d，若该距离小于 10，则将 warning_flag 设为 2，并将 adviser 设为 emergency_stop。
⑧ 最终返回 warning_flag 与 adviser 作为函数输出。

## 5.3 交叉路口碰撞预警技术

### 5.3.1 交叉路口碰撞预警的定义

交叉路口碰撞预警 Intersection Collision Warning，ICW 指主车 HV 驶向交叉路口，与侧向行驶的远车 RV 存在碰撞危险时，ICW 应用将对 HV 驾驶员进行预警。本应用适用于城市及郊区普通道路及公路的交叉路口、环道入口、高速路入口等碰撞危险的预警。

ICW 应用辅助驾驶员避免或减小侧向碰撞危害，提高交叉路口通行安全系数。

### 5.3.2 交叉路口碰撞预警的主要场景
