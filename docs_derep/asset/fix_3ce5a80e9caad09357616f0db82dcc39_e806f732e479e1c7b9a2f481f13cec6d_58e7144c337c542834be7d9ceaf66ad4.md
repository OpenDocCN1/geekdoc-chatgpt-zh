# ChatGLM-6B 以 LoRA 做信息抽取的实操记录

想让 6B 级模型在有限显存下学会结构化抽取，LoRA 是性价比最高的做法。下面把从数据准备到训练再到推理的完整链路重新梳理一遍，重点保留关键参数与操作逻辑，表述全部换写。

**训练准备与调度**

先打印可训练参数量确认规模。提示词固定为要求模型按规定格式输出抽取结果，后续统一使用 THUDM 的 chatglm-6b 分词器并开启 trust_remote_code。

训练集来自 spo_0.json，通过 get_data.get_train_data 切分，最大长度 128、目标长度 96，封装成 Seq2SeqDataSet。DataLoader 采用 batch_size 2、drop_last 为真、num_workers 0，并使用项目提供的 collate_fn。

加速部分使用 Accelerate 统一管理设备。收集 LoRA 参数单独建组，AdamW 学习率 2e-5，betas 0.9/0.999，eps 1e-5，配合余弦退火 T_max 2400，eta_min 2e-6。调用 accelerator.prepare 将模型、优化器、数据加载器、学习率调度器一起准备好。

循环 96 个 epoch，每轮用 tqdm 展示进度。对每个 batch 取 input_ids 与 labels 送显存，前向得到 loss，经 accelerator.backward 反向后执行 optimizer.step、lr_scheduler.step、optimizer.zero_grad。进度条显示当前 epoch、训练 loss 与即时学习率。训练结束保存完整权重到 glm6b_lora_all.pth，同时通过 get_lora_state_dict 抽离低秩部分保存为 glm6b_lora_only.pth。

**推理流程与采样**

生成采用自定义 top-p 采样，先排序累计概率再做截断。输入由提示词、原文、[gMASK]、<sop> 拼接，最大总长 288，源文本上限 256，自回归生成直到遇到结束符 130005。分词器同样使用 THUDM/chatglm-6b，trust_remote_code 开启。

[PRE4]python
def sample_top_p(probs, p):
    probs_sort, probs_idx = torch.sort(probs, dim=-1, descending=True)
    probs_sum = torch.cumsum(probs_sort, dim=-1)
    mask = probs_sum - probs_sort > p
    probs_sort[mask] = 0.0
    probs_sort.div_(probs_sort.sum(dim=-1, keepdim=True))
    next_token = torch.multinomial(probs_sort, num_samples=1)
    next_token = torch.gather(probs_idx, -1, next_token)
    return next_token

**低秩参数化骨架**

class LoRAParametrization(nn.Module):
    def __init__(self, fan_in, fan_out, fan_in_fan_out=False, rank=4, lora_dropout_p=0.0, lora_alpha=1):
        super().__init__()
        # if weight is stored as (fan_out, fan_in), the memory layout of A & B follows (W + BA)x
        # otherwise, it's x(W + AB). This allows us to tie the weights between linear layers and embeddings
        self.swap = (lambda x: (x[1], x[0])) if fan_in_fan_out else (lambda x: x)
        self.lora_A = nn.Parameter(torch.zeros(self.swap((rank, fan_in))))
