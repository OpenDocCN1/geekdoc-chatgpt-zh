# 面向海量数据时代的私密信息保护法理与运行机制

Zhao Wanyi，Fan Peixin

摘要
与传统侵害相比，海洋数据环境下私密信息的特征表现为覆盖面更广、易受侵害、救济困难、侵害隐蔽、认定难度大。因此需要构建更具时代性的保护目标与原则体系，包括以人权益为先的人本原则、伦理原则、合法性原则、利益衡量原则、必要性原则等。制度层面应充分保障个人数据的自主决定权，恪守数据伦理，建立数据应用合规的科学规则，并将“被遗忘权”提升为私密保护的特殊安排。为落实上述目标，需综合运用多种保护手段，重点完善救济机制，在技术层面强化私密防护，同时提升企业合规意识与数据利用自律水平。

关键词
私密权；海量数据；人本优先原则；被遗忘权

# 政府数据开放流通的法律秩序构建

Li Jiahang，Shao Bin

摘要
在数据生产理论视角下，政府数据属于“公共数据产品”。其开放既是数字人权保障的应有之义，也是数据要素市场化运行的现实要求。厘清开放内涵、外延与权属是构建流通秩序的基础。政府开放数据仅为政府数据子集，且限定于非个人数据。依政府角色差异，可区分为行政开放数据与政府生产数据。权属争议与流通规则的核心在于政府角色判断：就前者而言，政府仅为数据披露方，公共数据资产可无偿公开，非公共资产可经协商或法定程序开放；就后者而言，政府为受托代理人，采用知识许可以协议形式开放更为妥适，既可降低侵权风险，又能促进数据多元应用。

关键词
政府开放数据；数据归属；数据流通秩序；数据可用

# 从利益平衡视角看法定数字货币的私密信息保护

Chang Ye

摘要
私密信息在立法层面的保护相对滞后，主要源于其法律地位与权利属性争议。海量数据时代，信息安全与权利确认亟待法律回应。我国数字货币试点亦引发对信息采集的广泛关切。信息兼具人格与财产属性，机关处理信息须服务公共利益。另一方面，法定数字货币中的信息保护具有强技术迭代性，难以静态固化于法律。因此为提升公众接受度，需制定更高位阶的统一立法，将现行静态的“可识别性”定义标准更新为动态的“私密风险”标准，摒弃“知情”标准。强化“同意”原则以消除处理合法性的不确定性，构建“立法规范+技术国家标准”的双层架构，严格配置信息安全责任主体的法律义务与侵权后果，并考虑为信息存储设定法定期限。

关键词
法定数字货币；信息保护；利益平衡
