| :--- | :--- | :--- | :--- |

| 原始 PyTorch 格式 | .bin | Transformers 默认格式，文件较大，占用显存高 | Transformers/vLLM/TGI |

| 安全张量格式 | .safetensors | 安全、加载更快、支持并发加载的张量格式 | Transformers/vLLM/TGI |

| 量化格式-INT4 | .bin, .pt (压缩) | 通常通过 GPTQ/AWQ 等量化工具压缩后发布 | AutoAWQ/GPTQ-for-LLaMA/vLLM |

| 量化格式-GGUF | .gguf | llama.cpp/Ollama 使用的统一格式，支持 CPU/GPU 部署 | llama.cpp/Ollama/KoboldCpp |

挑定模型后，先确认几个关键点：是否开源、有没有 Hugging Face 或 GitHub 地址、是否提供 INT4/INT8/GGUF 等版本、官方或社区是否给出部署脚本或 Docker 镜像。

### 2.3 本地部署全攻略
本节围绕本地部署核心流程，系统介绍算力、环境依赖、模型下载、推理测试等关键环节，并对比主流第三方部署工具，为后续 Agent 开发打基础。

#### 2.3.1 部署前需求评估
在实际应用里，因数据安全、访问稳定、成本控制、模型可控等需求，越来越多的开发者和企业选择把大模型放到本地或私有云。本地部署能掌控推理过程，降低隐私数据泄露风险，减少接口长期费用，还能提速并支持离线运行。与此同时，本地部署门槛更高、工程更复杂，动手前需要对以下关键需求做全面评估。

##### 1. 算力资源
在所有本地部署条件里，算力尤其是 GPU 是能否跑起大语言模型的决定因素。轻量场景可尝试 CPU 模拟推理，但速度和效率远不如 GPU，对中大型模型基本不可行。所以部署大模型首先要具备相应规模的 GPU 硬件。

> **说明**
>
> 为什么不能只用 CPU？
>
> 大语言模型推理涉及十亿级参数的矩阵运算，尤其在多层 Transformer 架构里，有大量矩阵乘法、归一化、注意力计算等高强度并行任务。GPU 在并行数值计算上优势明显，CPU 更擅长逻辑控制和串行任务。同等条件下 CPU 推理速度可能只有 GPU 的 1/100 到 1/10。

在推理场景下不同模型参数规模对应的显存需求如表2.2所示。

**表2.2 不同模型参数规模对应的显存需求**

| 模型规模 | 推理时显存需求（FP16） | 支持的典型GPU（单卡） |
| :--- | :--- | :--- |
| 7B | 14GB～16GB | RTX 3090 / 4090 / A500 |
| 13B | 26GB～30GB | RTX 4090（24GB）基本可运行 |
| 33B | 60GB～80GB | 多卡 A100 或 2×4090 并行 |

若采用量化如 INT4、INT8、GPTQ 等，显存通常可减少 1/4～1/2。以 7B 为例，FP16 需要 14GB～16GB，INT4 后只需 4GB～6GB，可在单张 RTX3060/4060 甚至笔记本 GPU 上运行。

当前大模型训练或推理绝大多数基于 NVIDIA GPU，因其 CUDA+cuDNN+PyTorch 支持体系成熟。大模型领域的主流 GPU 型号如表2.3所示。

| 类型 | 常见型号 | 适用说明 |
| :--- | :--- | :--- |
| 数据中心级 | A100, H100, A800, L40S | 高稳定性、高带宽，适合部署集群 |
| 消费级高端 | RTX 3090, 4090, 4080 | 适合个人开发与小模型推理 |
| 云租用平台 GPU | Tesla V100, T4 | 支持量化模型，成本可控 |

若本地没有 GPU，可租用云平台算力。AutoDL、阿里云 PAI、百度飞桨 Studio、Google Colab 都提供在线 GPU 租赁。

##### 2. 操作系统与环境依赖
硬件充足后，还需配置操作系统与软件依赖栈。以下是部署主流 PyTorch/Hugging Face 风格模型所需的通用环境说明。

1) 操作系统
建议优先用 Ubuntu，其稳定且兼容 CUDA，是主流 Linux 发行版，能完整支持 NVIDIA 工具链。虽然 CentOS 和 Windows+WSL2 也能跑部分模型，但不推荐在生产环境使用，会有兼容问题。

2) 软件依赖环境（PyTorch 栈）

| 组件 | 推荐版本 | 安装说明 |
| :--- | :--- | :--- |
| Python | ≥ 3.9 | 建议使用 Conda 虚拟环境隔离 |
| PyTorch | ≥ 2.0 | 需安装 GPU 版本（pip/conda 安装） |
| CUDA | 11.8 / 12.1 | 与 PyTorch 安装包版本匹配 |
