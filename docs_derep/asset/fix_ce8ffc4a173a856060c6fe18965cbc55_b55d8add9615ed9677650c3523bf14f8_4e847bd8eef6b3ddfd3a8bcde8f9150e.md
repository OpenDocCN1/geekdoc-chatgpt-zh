### 3.3 把 ChatGPT 嵌入到 Excel

在 Excel 中安装 ChatGPT 插件后，可在工作表内直接对话，利用其自然语言理解和生成能力执行任务，无需切换应用，大幅提升效率。下面介绍接入流程。

#### 3.3.1 安装 ChatGPT 插件

Excel 插件可通过“开发工具”选项卡的“加载项”入口接入，具体如下。

- 步骤 01 打开空白文档，在“开发工具”功能区“加载项”面板中点击“加载项”按钮，如图 3-42。
- 步骤 02 弹出“Office 加载项”对话框，展示多款热门插件，有免费也有付费，如图 3-43。
- 步骤 03 在搜索框输入 ChatGPT，如图 3-44。
- 步骤 04 点击“搜索”按钮 🔍，找到 ChatGPT for Excel 后在其右侧点“添加”按钮，如图 3-45。
- 步骤 05 弹出“请稍等”对话框，点击“继续”按钮，如图 3-46。
- 步骤 06 等待加载完成，ChatGPT for Excel 图标会出现在“开始”功能区最右侧，如图 3-47。
- 步骤 07 点击图标展开插件面板，如图 3-48，用户需在 Settings 选项卡的 Your OpenAI API Key 文本框填入密钥后才能使用。

#### 3.3.2 熟悉 AI 函数使用方式

OpenAI 官网获取密钥的方法见本书第 2 章 2.3.1 节。❶ 在插件面板 Settings 选项卡的 Your OpenAI API Key 文本框输入密钥；❷ 点击 SAVE 按钮，如图 3-49。

执行后即可成功应用 API 密钥，并提示可在工作表中使用对应 AI 函数，如图 3-50。

插件中提示的 AI 函数作用如下。

##### 1. AI.ASK

用户可在任意单元格用 AI.ASK 向 ChatGPT 提问并获取答案。例如 B1 输入问题，B2 输入 =AI.ASK(B1) 即可得到结果，如图 3-51。

##### 2. AI.LIST

AI.LIST 的作用是把一系列数值或文本合并成一个字符串，便于后续处理。例如把 A 列文本合并到 B 列并用顿号分隔，可用公式 =AI.LIST("合并文本",A2:A6)，如图 3-52。

##### 3. AI.FILL

AI.FILL 可自动生成连续序列或按规律填充单元格。例如 A2 为起始值 1，在 A3 输入 =AI.FILL(A2,10)，表示以 A2 为起点向后填充 10 个单元格生成序号，如图 3-53。

注意，若生成失败可多按几次回车刷新，或在 Premium 选项卡付费升级。

##### 4. AI.TRANSLATE

AI.TRANSLATE 可按指定词典翻译文本。例如用 =AI.TRANSLATE(A2,"中文简体") 把 A 列内容译为简体中文，或用 =AI.TRANSLATE(A4,"英文") 译为英文，如图 3-54。

##### 5. AI.FORMAT

AI.FORMAT 主要用于把数值或日期转换为指定格式，可自定义小数位、千位分隔符、货币符号和日期格式等。例如 =AI.FORMAT(A2,B2) 把 A 列数据按 B 列指定的格式转换，如图 3-55。

##### 6. AI.EXTRACT

用户可用 AI.EXTRACT 从文本中抽取指定类型信息，自动识别关键词、日期、地址等。例如 =AI.EXTRACT(A2,B2) 从 A 列文本中提取 B 列指定的内容，如图 3-56。

插件面板还提供 Examples Spreadsheet 示例电子表格，可在跳转网页中学习函数示例。
