## 第3章

向量嵌入

向量嵌入是向量数据库的核心基础，把非结构化数据转化为高维向量，使其可在向量空间中完成存储、检索与分析。通过嵌入技术，文本、图像、音频等被映射为语义相关的向量表示，为相似性搜索与数据挖掘提供可能。

本章先介绍静态与动态向量嵌入的原理与实现，分析它们在捕捉语义关系上的优劣。再通过嵌入质量评估，探讨均匀分布与空间覆盖率对检索性能的影响。最后讨论数据降维在嵌入优化中的关键作用，展示如何在降低复杂性的同时保留语义信息。本章为高效嵌入生成与优化提供理论依据和实践指导，奠定向量数据库系统的技术基础。

### 3.1 静态向量嵌入

静态向量嵌入是早期自然语言处理的重要突破，通过把词汇映射为固定长度向量来捕捉语义关联，为文本任务提供基础。本节以经典的 Word2Vec 与 GloVe 为例，阐述其生成静态嵌入的基本原理与实现机制。

#### 3.1.1 传统词向量模型: Word2Vec与GloVe

传统词向量模型旨在把离散文本映射为连续高维向量，以刻画词汇间的语义关联。Word2Vec 与 GloVe 是两类代表，分别基于预测式与统计式思路。

- (1) Word2Vec：借助 Skip-gram 或 CBOW 方法，利用神经网络预测上下文词或目标词，把语义信息编码进向量空间。Word2Vec 通过优化局部上下文关系生成高质量嵌入。
- (2) GloVe：基于词对共现矩阵构建全局语料统计，生成嵌入向量。GloVe 强调全局共现特性，适合大规模语料的语义分析。

传统词向量模型如 Word2Vec 与 GloVe 是把单词数值化的经典手段。核心目标是把语言的语义关系映射到数学空间，使得词语相似性可通过向量运算体现。

可把一个巨大图书馆想象成词表，每本书代表一个词，书间关系由共同章节或主题衡量。Word2Vec 就像图书管理员，通过记录哪些书常出现在相邻章节来归纳联系。例如“苹果”与“水果”常共现，模型会把它们置于相近位置。这种方法即上下文窗口预测，通过预测上下文或由词预测上下文来训练。

GloVe 更像统计学家，不只看相邻出现次数，而是建立全馆范围的共现统计表，分析每本书与其他书的共同出现概率。借助全局信息，GloVe 构建出兼顾局部与整体语义的向量空间。例如它不仅知晓“苹果”与“水果”相近，也能区分“苹果”在公司语境下的不同含义。

最终产物是一个多维空间，词被映射为带数值的点。语义相近的词彼此靠近，可通过向量运算验证“国王-男人+女人=女王”等关系。这种数学化语言表达成为后续 NLP 的基础。
