# 思考越深、越易中招？多任务时代的假新闻认知陷阱

通常被视为深度思考的“精细加工”模式，在辨别谣言时竟适得其反，反而助长了“动机性推理”。实验中，受试者典型言论如：“听说教师编制考试要提难度，改革消息多半是真”、“早年见过故意传播艾滋的恶性案例，这条新闻看着挺像那么回事”。这揭示了大众倾向于用既有经验框架去消解新信息的认知惯性[17]。

从受众侧反观生产端，二者不谋而合：虚假内容擅长编织符合常理的生活叙事，配合高频推送制造“似曾相识”的错觉，以此瓦解防线。这正是微信生态中，医疗养生、校园安全、亲子教育类谣言屡禁不止、极易裂变的根源[40]。

研究进一步指向日常根深蒂固的“多线程处理”习惯，正是这一认知失守的深层推手。有观点悲观地将传谣归因于大众“懒惰”[19]，但我们更应深究：这种“认知吝啬”究竟是技术环境塑造的产物，还是人性本身的弱点？

---

## 研究短板与后续展望

1.  **测量主观性**：多任务频度依赖自陈量表，客观度不足；后续可接入手机端埋点日志，实现行为级客观记录；
2.  **中介路径待拓**：注意广度仅解释约两成方差，认知负荷等核心变量仍待纳入模型深度剖析；
3.  **核心人群缺位**：作为转发谣言主力军的老年群体[41]，其心理机制研究亟待补强。
