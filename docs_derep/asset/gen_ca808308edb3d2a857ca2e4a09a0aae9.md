输入信息较为稀疏时，比如整张图都是大片海面，就没必要让感受野密集地遍历每一处。控制感受野密度的常用做法是调整移动步长 Strides。

步长指感受野窗口一次平移的距离单元。在二维情形下，分别对应 x 轴向右和 y 轴向下的位移。为简化说明，这里假设两个方向的步长相等，这也是神经网络里的常见设定。如图 10.22 所示，实线表示当前感受野的位置，虚线表示上一次的位置，两者之间的位移就是步长。图中的 x 方向步长为 2，记作步长 s=2。

[PRE0]

图 10.22　移动步长

当感受野走到输入 X 右侧边界后，会向下平移一个步长 s=2，然后回到行首继续扫描。如图 10.23 所示，感受野向下移动 2 个单位并回到首列，再做乘加运算。

图 10.23　卷积运算步长示意图-1

可以看出，步长 s 能有效调节信息抽取的密度。步长设置得越小，感受野移动越精细，捕获的特征越丰富，输出张量也越大；步长设置得越大，感受野跳跃越粗，计算量下降、冗余被过滤，输出张量相应变小。

### 10.2.5 填充

做完卷积后，输出 O 的高宽通常会小于输入 X 的高宽，即便步长 s=1 也会稍小一点。很多网络设计希望输出的高宽与输入保持一致，以便做参数规划、残差连接等。为此常在输入 X 的高、宽维度上额外补上一些无效元素，得到扩大的输入 X'。通过合理设计补零的数量，就能在 X' 上卷积后得到与原输入大小相同甚至更大的输出。

### 10.5　表示学习

卷积神经网络本质上是卷积层的堆叠。研究发现网络越深，表达能力越强。那深层网络到底学到了什么？

2014 年 Matthew D. Zeiler 等人[^(\[5\])](#chapter10.xhtml#jz_12_5) 用可视化尝试解释。他们把各层特征图经“反卷积”网络映射回输入图像，可观察特征分布，如图 10.32 所示。第 2 层对应边、角、色彩等底层信息；第 3 层开始捕捉纹理等中层特征；第 4、5 层则呈现物体部件，如小狗的脸、鸟的脚等高层特征。可视化帮助我们感受网络的学习过程。

[PRE29]

图 10.32　卷积神经网络特征可视化[^(\[5\])](#chapter10.xhtml#jz_12_5)

图像识别可看作表示学习过程：从原始像素出发，逐步提取边缘、角点等底层特征，到纹理等中层，再到头部、部件等高层，最后基于学习到的抽象表示做分类。学到的特征越高级越准确，分类器效果越好。从表示学习视角看，卷积网络通过逐层堆叠提取特征，训练即特征学习，基于高层抽象表示完成分类。

基于此思想，训练好的网络学到的特征往往具有通用性。例如在猫狗上学到的头、脚、躯干表示，可在其他动物上复用。于是可把在任务 A 上训练好的深层网络的前段特征提取层迁移到任务 B，只训练末端分类逻辑，即迁移学习，也称网络微调 Fine-tuning。
