### 8.1.2 LangChain 应用开发框架总览

LangChain 由 LangChain AI 推出，是面向大模型驱动应用的开源框架。其核心理念是通过标准化、结构化的模块抽象对大模型输入输出进行统一规范，进而构建可组合、可插拔的开发流程。以“Chain”为核心，强调链式组织模型调用、上下文管理、工具执行、内容解析等操作，帮助开发者搭建从数据输入到智能响应的完整路径。

本质上，LangChain 从模型能力出发，结合实践经验对涌现能力做高级抽象，并通过统一接口适配多种底层服务，形成通用开发范式。

目前 LangChain 已演进为通用大模型应用开发框架，模块设计体现了对 LLM 的深刻理解，并在 Agent 标准化中发挥关键作用。核心模块如图 8.4 所示。

[PRE16]

图 8.4 LangChain 核心模块

##### 1. Prompt

Prompt 是构建大模型应用的起点。LangChain 通过 `PromptTemplate` 提供标准化的提示模板定义机制。开发者可自定义输入变量，为大模型提供精确背景信息与任务说明；`PromptTemplate` 结构化封装支持变量插值、输入校验与模板复用，可通过模板填充生成动态提示内容。

##### 2. Models

Models 模块封装主流大语言模型并提供统一调用接口。只需配置模型信息，即可在不改动业务逻辑的前提下切换底层大模型。

##### 3. Output Parser

大语言模型通常返回自然语言，工程实践中常需特定格式如 JSON、列表、表格、代码块等。Output Parser 模块为此设计，LangChain 内置字符串解析器、列表提取器、Pydantic 格式校验器等，帮助规范每步输出，提升链式调用鲁棒性。

##### 4. Memory

Memory 模块是对话场景下实现多轮上下文记忆的关键组件。区分短期与长期记忆，支持用户输入历史与模型输出的存储与复用。

##### 5. Callbacks

Callbacks 提供事件监听机制，使开发者能够对大模型调用链路各环节进行监控、调试与可视化。支持日志输出到终端、写入文件，甚至接入可观测性平台，实现系统执行路径的全链路追踪。

##### 6. RAG

LangChain 对 RAG 深度封装，涵盖 Retriever 构建、向量数据库接口集成如 Chroma、FAISS、Milvus，以及上下文压缩与匹配度过滤等组件。开发者可按需组合，快速构建适用于特定语义检索场景的增强生成链。

##### 7. Agent

Agent 模块是实现复杂任务自动化执行的核心引擎。允许大模型以工具调用者身份动态决策是否调用外部工具、API 或其他链条任务。LangChain 提供多种内置 Agent 类型，支持复杂任务流程的自动分解与执行。

在 LangChain 中，七大模块如积木般各自承担明确职责，可灵活组合构建多样化大模型应用。如图 8.4 所示，既可实现基础问答，也可构建具备上下文记忆、知识增强、结构化输出与多工具协同的高级 Agent 系统。
