# 序二

“元宇宙”与“区块链”

得知中译出版社将推出《元宇宙》和《元宇宙通证》两本著作，我感到十分振奋。我长期关注元宇宙概念，它与区块链密不可分，却意义更为宏大，二者相得益彰。可以说，正因区块链存在，元宇宙才由平淡的虚拟世界跃升为开天辟地的宇宙。

区块链是一个全球化、安全、点对点的网络，但在全球范围内，它并非首个点对点网络，也不是首个使用密码技术的网络，更不是首个支持远距离交流的网络。全球P2P文件共享网络BitTorrent已存续15年，让各地人共享网络资源，也让相距遥远的人便捷交流。区块链也不是首个实现这一点的技术，互联网数十年来已取得长足进步。

密码学即让人互信的技术，已有近40年历史，它允许远程交互而无需信任每位参与者。上网时，几乎所有电脑或手机与运行应用的服务器间的通信都已加密。

密码学很有价值。它能保证信息仅被预期读者阅览，内容在传输中不被篡改，并能确认发送者身份。

但密码学做不到很多事。例如无法说明信息何时创建或发布，不能证明某信息在某一时间点前就已存在，也不能证明某人是否确认过该信息。它无法促成参与者达成共识。在金融体系里，若各方对资产共同价值无共识，体系便无法运行。密码学无法提供经济激励，因其无法证明股权与支付通道，而许多技术高度依赖经济激励。密码学无法证明来自现实世界的信息。你无法用数学证明香港气温是华氏100度，也无法证明美元兑港币汇率为1:7.18。现实世界大多数事务无法被证明。

区块链无法解决所有问题，却补足了密码学未能解决的诸多难题。

区块链技术并非简单的点对点网络与密码技术的线性叠加，关键在于让整个网络参与者达成一致。区块链网络的每个节点都是历史的见证者，从而避免因缺乏信任导致操作失败。

我们现有的大部分应用都试图使用某种中心化数据库。因为部分互联网应用拥有庞大数据库，如QQ、微信、支付宝等，近年来垄断现象增多。

应用用户越多，希望查阅数据库的人越多，其他用户越容易与既有用户快速互动。这意味着小公司即便产品再好也难以与大公司竞争。

区块链的账本与数据库不依赖特定公司存在。不同公司可借助分布式数据库与密码学保护隐私，共享网络效应带来的好处，规避大公司垄断，使行业被单一巨头主导的情况不再易发生。

许多网站已产生明显网络效应，但数据不被特定公司控制，维基百科是典型例子。人们不仅分享信息，还可分享共识、余额、账户。

因此，当你在一个建立在区块链之上、完全开放的平台时，其强大的网络效应会让你更容易享受应用的好处。这不仅限于单一行业，可跨越行业与国界。

区块链应用领域极广，涵盖支付、预订、个人身份认证等。

支付最先显现价值。人们对代币、货币、各类金融工具兴趣浓厚。例如在追求透明的领域，如慈善组织，对公开预算使用有需求的国家，区块链支付大有裨益。

虽可用区块链订火车票、酒店、机票，但流程中仍存在诸多低效待改进，而区块链最能发挥作用的是协调多方参与的场景。

这些年“上链”推进并不明显，重要原因是上链资产与实物可能不一致，且无法由区块链网络自身保证。但在元宇宙中，所有资产都是数字化的，天生存在于网络上。严格来说，元宇宙的全部资产都可基于区块链网络。上述优势尤其能防止元宇宙数字资产集中于大公司，使创新小企业举步维艰。区块链保障了元宇宙居民对数据的自主权，把数据权利归还给居民。

## 当经济学“遇见”元宇宙

理论突破很少从大而全的概括中产生。世界纷繁复杂、万物普遍联系。因此研究理论、总结规律需要几个条件：其一，合理取舍，从万物联系中分离出最具代表性、先进性、变化最快的典型案例。其二，研究这些案例，找到原子级不可再分的构成要素；研究这些要素的特征与要素间关系，甚至定义原子级操作。其三，回归整体，整体问题仍需整体求解，检验结论是否经得起时间与其它要素的考验。

元宇宙经济即数字经济的最佳范例，从元宇宙入手，可得出与传统经济学，包括秉承新自由主义经济学与新制度经济学的经济学家完全不同的结论。虽然不能说彻底推翻传统经济学教条，但一个完整、先进的经济学体系正在建立。元宇宙经济学的先进性，恰恰在于元宇宙实践的特殊性。

元宇宙是一个完整、自洽的经济体系，是纯粹数字产品生产、消费的全链条。从商品属性看，元宇宙经济学与传统经济学相同，遵循相似供需规律，但从商品生产、消费全链条看又完全不同。元宇宙中的商品完全在元宇宙中制造与消费，层层剖析到最后，无非是“0”“1”的排列组合。从某种意义上说，元宇宙的商品是脱离物理世界的单独存在，尽管它们之间可发生千丝万缕的联系。
