## LDA 主题抽取实操

第三段是无监督挖掘。读取纯文本文件后对每行进行分词、去停用词、词干化，用 Gensim 构建词典与词袋矩阵，训练两个主题的 LDA 模型，最后输出每个主题贡献最大的词及其占比。

导入工具

[PRE20]
# Load input data

def load_data(input_file):

    data = []

    with open(input_file, 'r') as f:

        for line in f.readlines():

            data.append(line[:-1])

    return data

# words, and stemming

def process(input_text):
