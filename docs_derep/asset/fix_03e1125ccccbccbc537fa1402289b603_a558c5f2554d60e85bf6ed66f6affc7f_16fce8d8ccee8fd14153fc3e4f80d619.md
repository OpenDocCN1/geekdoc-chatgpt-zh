2. 聚拢顶尖的研究者，在开放、平等的协作氛围里共事，让每个人都能互相切磋、共同成长；
3. 开展能够造福人类的工作，让每位成员都为源自自己团队的创新结果感到骄傲；
4. 保持长远眼光，选择具有吸引力的研究题目，让工作本身让人热爱；
5. 领导既理解研究又给予支持，在把握公司整体方向的同时，保留足够的自由度，让个人才能得以发挥，梦想得以追求。

我认为单纯用高薪酬，只能招到一部分人。只有打造出真正令人向往的工作环境，才能吸纳并长期留住最优秀的人才。

在微软全球各研究院，人员保持率很高，流失比例长期低于百分之一，而美国硅谷的平均水平则在三成左右。微软面试时给我最深的体会是，每个人都显得特别快乐，对自己的工作充满热爱与珍惜。所以我在国内给自己的目标，就是在中国建立起同样优秀的研究环境，让大家在微软中国研究院安心追寻梦想，一方面助力微软研发关键技术，另一方面推动国内信息产业的发展。

# 教育观：合中西，育均衡人才

## 写在前面

我自幼在浓郁的中华文化氛围中长大，十一岁赴美时英语几乎不会，性格腼腆内向。在美国求学、研究、工作三十多年，我逐步适应了美国式的思维习惯，融入当地社会，成长为一个开朗、善沟通、有领导力的研发管理者。期间我有机会回国参与微软中国研究院的创建，并结识了大量优秀的国内管理与研发人才。这段经历让我深知东西方文化的差异，也坚信在当下“扁平”“开放”的世界，唯有兼取中西之长、融合各自先进思维，才能立于信息网络时代的前沿；也只有“融会中西、完整均衡”的教育理念，才能提升教育水平、优化教育生态，培养出助力国家历史性跨越的国际化人才。

我一直想把这些思考分享给国内的学子和教育工作者。早在《第二封信》中我就提过，要把国人谦虚坚韧的美德与西方优秀思想结合；在撰写《做最好的自己》时，我对这一问题思考得更深。我想告诉读者，我们该保留哪些优秀的传统，该吸收哪些先进的西方观念，当两种思维冲突时如何取舍，以及我个人经历中哪些经验、方法与理念，对学生、家长、教师有所启发。

过去二十余年，我参与过前沿的科研、教学与开发，指导过卡内基梅隆大学的优秀学生，亲历苹果的辉煌与低谷，体验过SGI的先进图形技术并见证其兴衰，还创办了微软中国研究院，并在2005年重返国内，协助谷歌开创并领导中国研发团队。作为兼具高校教学经验与一流企业研发管理经验的IT从业者，作为受东西方教育熏陶的实践者，我持续关注国内青年的成长环境与教育发展，愿意尽一份力。

如果为国内教育建言，我更想分享三点：
1. 国内年轻一代非常优秀，同时也急需引导与帮助；
2. 国家跃升的关键在于教育；
3. 教育的核心在于如何把年轻一代培养成“融会中西、完整均衡”的国际化人才。

本文结合这些观点与我亲身经历的真实案例，分享二十余年职业生涯中的思考与探索。

## 充满希望的年轻一代

1998年8月，受微软董事长比尔盖茨委派，我来到北京组建微软中国研究院并担任院长。当时公司内外多持怀疑态度，我却坚信中国不缺优秀人才，只要汇聚海内外华人智慧，这件事一定能成。不到一年，我便邀请到张亚勤、沈向洋、张宏江等在全球计算机领域颇有建树的学术带头人，并在国内发掘出不少极具潜力的青年才俊。短短三年，我们成为亚洲最优秀的研究团队之一。2004年，美国MIT《科技评论》将微软亚洲研究院评为“全球最火的研究机构”。在北京的两年里，每一天都令人振奋，每一刻都难忘。

2000年8月，微软将我召回总部，任命为全球副总裁，负责开创新产品部门。此后，国内发生的一切始终牵挂着我，牵挂着那片生机勃勃的土地和与我血脉相连的子孙后代。

国内的年轻人，尤其是高校学子，最让我难以忘怀。清华园的激情演讲，未名湖畔的思想碰撞，从南到北、从沿海到内地，每一所校园、每一个年轻人，都让我感慨万千。他们身上既有朝气与活力，也有不安与躁动。我深感有责任也有义务为他们提供思想与方法上的帮助，让他们从我的成功经验中汲取智慧与力量。

正是这份责任感推动我，在2005年前的五年里，身居美国却十五次回国，做了五十余场演讲，写了四封《给青年学生的信》，并创办了面向大学生的公益交流平台“开复学生网（`www.kaifulee.com`）”，每天与国内青年探讨成长、排解困惑。2005年中，我用十个月完成《做最好的自己》，由人民出版社出版，很快成为青年读者推崇的畅销书。无数中学生、大学生及职场新人来信来邮件，让我确信为国内青年和教育所做的付出是值得的。

国内青年有过人的智慧、扎实的基础和勤勉的作风。若有一位掌握成功法则的良师给予贴心帮助，让他们更积极、更勇敢、更自信，他们必将在不远的将来成为国家栋梁。

国内青年很优秀，却常陷入极度困惑：面对期望过高的父母、偏重应试的学校与老师、以及浮躁的社会心态。若有一位经验丰富的引路人指明方向，他们将走得更稳、更坚实，并成为中华民族实现历史性跨越的最大动力。

国内青年有幸成长于第一次能接受完整先进教育、能专心读书并拥抱信息时代的年代。但在全球化与信息化抹平时空差异的世界里，国内青年必须成为融会中西文化的精英，才能在国际人才竞争中脱颖而出。他们生于拥有广泛选择权的时代，却未必获得足够指导选择的智慧。

我在热爱中国的家庭中出生，又在美国进步的学校受教，是跨越中西文化的代表。我教过勤奋的中国学生，也教过活力的美国学生，看到了融合中外优势的绝佳机会。作为体验过西方文化的炎黄子孙，我愿做指路人，帮助青年远离困惑走向卓越，也愿把我在指导学生过程中积累的方法与经验，为致力于发展国内教育的人提供借鉴。

## 国家跃升的核心在教育

三十多年的蓬勃发展，让世界看到一个理智、自信、充满活力的亚洲大国和平崛起。从神舟五号的飞天，到2008年北京奥运，从每年逾万亿美元的国民储蓄，到全球最大的移动通信市场，这些事实彰显了中国巨大的市场前景、开明的治国方针以及勤奋向上、坚持不懈的拼搏精神。

制造业的成功令人惊叹：中国是名副其实的“世界工厂”。在沃尔玛、开市客、塔吉特、梅西百货等美国大型商场，约九成的商品为“中国制造”；在加州的Fry’s，约半数商品来自中国；跨太平洋的巨轮源源不断为美国市场供货；中国电信的一次政策调整就能让美国高通股价波动；1984年成立的民企联想竟收购了IT巨头IBM的PC业务。中国已成为任何强国都必须重视的经贸伙伴。

但我们必须清醒：制造业利润极低，绝大部分利润流向研发、市场、进出口、销售、运输等环节。形象地说，中国赚一元，外国公司可赚九元。“劳心者治人，劳力者治于人”，这恰好反映了当代世界经济的核心规律。

今天的中国正处十字路口：未来是继续赚取每十元利润中一元的低端产业，还是能获取九元？是继续做世界工厂，还是成为研发中心？中国人是做世界工人，还是世界人才？是满足于经济成功，还是在成功基础上向卓越迈进，全面接近或超越美国的科技、教育与国民收入水平？

美国二十世纪的奇迹，固然是综合因素的结果，但教育是最关键的驱动。美国建立了以人才为核心的良性循环：政府大量投入教育科研，为人才成长创造氛围；高校与科研机构输送人才与领先科技，进入企业制造出最具竞争力的产品；企业向全球销售创造财富，税收增加后反哺教育科研。教育产生人才，人才催生科技，科技催生企业，良性互动使国家强盛，而成功的人才战略是关键。

因此，中国能否从成功走向卓越，主要取决于是否拥有当今世界最优秀的人才，而最优秀的人才来自最优秀的教育。中华民族要成为最具创造力的民族，必须发展教育，培养年轻一代，因为只有最优秀的青年才是腾飞的希望。

为什么是年轻一代？

首先，他们是高素质人才的代表。二世纪的中国多灾多难，直到改革开放后社会稳定、经济蓬勃，才有完整教育的一代。今天的大学生是在这一环境下成长的第一代，他们是未来希望。随着高等教育快速发展，越来越多年轻人进入大学，MBA、MPA等现代管理教育延伸至企业继续教育。崇尚教育的热潮使青年自然成为社会中坚与优秀分子，唯有他们才能承担改变未来的责任。

其次，他们是信息与网络时代的生力军。互联网改变生活方式，网络成为主要交流渠道，电子商务取代传统商业，虚拟世界作用日益增强。青年是网络文化的创造者与推动者，唯有知识、技术、勇气与智慧兼备的年轻人，才能快速适应转型、融入新文化与交流方式。

最后，他们是孕育国际化人才的“兵工厂”。经济科技全球化一体化的浪潮要求我们培养能适应东西方文化环境的国际化人才。归国成功人士中，既受西方文化科技熏陶又能弘扬中国文化者，往往取得更大成就。越来越多中国青年走出国门学习西方先进思想与技术，最有希望成为真正的国际化人才，为中西交流贡献力量。

年轻一代是中国腾飞的希望。能否为他们提供最优越的教育环境，能否培养出融会中西、完整均衡的国际化人才，正是中国崛起的关键。

## 培育融会中西、完整均衡的国际化人才

中国加入WTO，互联网与光纤连接人与人，无线网络、VOIP等技术增强了联通。电子邮件与办公软件促进协作，从工厂外包到软件外包，全球形成国际化人才市场与工作流。

世界经济与科技高度融合，全球化带来一体化。人才需要承受东方与西方两种意识、哲学与文化的冲击。另一方面，东方国家追求现代工业化时，西方人却在回归东方价值理念；中国更强调个性与个人价值，西方却在倡导集体主义。东西方差异正在逐渐磨平，人才国际化的现代理念正逐步形成。

怎样的人才是优秀的国际人才？最核心有三点：以诚信为基础、以融会中西为前提、以完整均衡为路径。

诚信是做人之本、立业之基。无论是中国说的“德才兼备，以德为先”，还是《圣经》里“诚信比财富更有价值”，都强调基于诚信的价值观。品格决定社会价值，而诚信是最重要因素。未来工作越来越依赖合作，人与人合作必须以诚信为前提，这是中西方共同推崇的基础。

融会中西是国际化人才的先决条件。东方文化强调自上而下的管理与秩序，中国人更讲纪律、服从、谦虚、毅力，更善于“接受不可改变之事”；西方文化强调个人意识、平等与自由，培养出更善于创新、积极主动、敢于“改变可改变之事”的人才。两者各有优势，互为补充。融合中西精髓的国际化人才更易取得成就。

比如在中西方，卓越的企业领导者往往兼具两种特质。中国的吴鹰敢于冒险创业、柳传志善于有效沟通、张亚勤积极进取，都体现了值得学习的西方果敢。而比尔盖茨的谦虚谨慎、杰克韦尔奇的锲而不舍，也证明中国崇尚谦虚、强调毅力的传统美德值得西方借鉴。

完整均衡是走向成功的必由之路。成为兼具中西方优势的国际化青年并不容易。年轻人最关键的是努力成为完整、均衡发展的个体，在复杂情境中做出判断，在对立统一的两极间找到最佳平衡。

要达到完整均衡，既要“有胸怀接受不可改变之事”，也要“有勇气改变可改变之事”，更要“有智慧分辨两者区别”。必须善于运用经验与智慧精准判断：何时应满怀激情积极勇敢面对问题，何时应谨慎从容地服从或接受现实，何时应坚持不懈直面挑战，何时应求同存异权衡折中。

## 青年学子需要指导与帮助

我的经验表明，中国青年拥有聪慧头脑与积极进取心，却常在学习与生活中陷入困惑迷茫。

从1998年首次在大学演讲起，我一直与国内高校学生保持深入接触。几乎走过各所名校，曾为微软中国研究院面试数千名学生，在高校做过上百场演讲，与上万名大学生面对面交流，通过网络回复三千多封学生邮件，为近百位优秀留学生写推荐信。这些经历让我触动很大，也促成了“开复学生网”与《做最好的自己》的诞生。

在交流中我逐渐认识到，中国大学生与年轻人常遇到困难，亟需来自社会的帮助。这种帮助应体现在理想、道德、人生、心态、思想与方法层面，而不仅限于考试、分数、名校、出国与就业。主要原因有三：

家庭压力让年轻人沮丧悲观。家长过高期望易诱发社会攀比，让学生过早进入盲目竞争氛围，忽视沟通表达能力的培养，丧失学习生活的乐趣。若学习目的仅局限于考试分数与名校，一旦某个环节受挫，许多孩子会变得极度沮丧、过早失去天真与浪漫。

教育现实与理想存在差距。部分教师因成长于封闭环境，社会知识面甚至窄于学生，难以提供适应现代社会的知识信息。此外，评价体系不健全，高校教师多热衷科研与著书，个别教师只想赚钱而忽视教学。总体看，中国高校教育虽有长足进步，但教师素质与世界一流大学仍有差距。

转型期社会环境带来负面影响。快速发展的市场经济带来财富，也带来诱惑与不良风气，这些因素进入校园影响青年学生。一元化的追名逐利思潮泛滥，导致部分学生浮躁，产生零和竞争、道德缺失等严重问题。处在转型期的青年必然面临更多困难与挑战。

面对过高的社会期望、不善沟通的家长、应试导向的教育体系、参差不齐的教师素质、充满诱惑的社会环境与名利至上的价值取向，正处于高度可塑期的青年最需要社会帮助，最渴望教育改善。只有建立先进的教育体系，提供与国际接轨的学习环境，并有更多人无私地给予思想与方法上的指引，中国的年轻一代才能度过人生最单纯美好、最富幻想、最勇于创新的黄金时代，真正走向多元化的成功。
