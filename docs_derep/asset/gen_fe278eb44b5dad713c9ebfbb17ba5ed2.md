# **序言**

在数据洪流席卷全球的今天，信息规模空前庞大，如何从中提炼价值、洞察趋势，已成为各界共同关注的命题。人工智能的迅猛发展，尤其是 ChatGPT 等大模型的突破，为数据分析带来了全新变革。作为长期深耕数据科学与 AI 的研究者，得知文之易、蔡文青、屈秀伟三位合著《ChatGPT 数据分析（视频案例版）》付梓，倍感欣慰与难得。作为一名计算机科学家，很荣幸为本书作序，共同探寻这一领域的未来篇章。

科研之路坎坷而坚韧，每一次挫折都在淬炼意志。我有幸主持并参与多项国际重磅项目，如英国 EPSRC 平台旗舰计划“发现网”Discovery Net、惠康信托基金支持的胰岛素抵抗生物图谱 BAIR，并继续引领香港生成式人工智能研发中心 HKGAI，聚焦多模态多语言大模型、垂直大模型及香港本地应用。这些经历深深印证了数据科学作为时代引擎，在加速科学发现与推动社会进步中的核心作用。

随着大模型成熟，ChatGPT 等生成式工具正在改写数据分析的规则，用自然语言作为桥梁，让数据分析不再局限于专业人士。ChatGPT 在数据分析场景的优势主要体现在三方面：

一是零代码操作。无需编程基础，仅靠自然语言提示即可完成复杂任务。

# **前言**

信息爆炸时代，数据已成为企业与个人决策的重要支撑。数据分析把原始数据转化为可行动的洞察，渗透到商业智能、市场研究乃至日常决策之中。然而庞杂的数据、专业软件与编程门槛，让许多人望而却步。人工智能的快速发展，特别是生成式预训练 Transformer GPT 模型的出现，正在改变这一现状。

ChatGPT 以强大的语言理解与生成能力重塑数据分析边界。通过对话交互，它可辅助完成数据收集、预处理、分析到报告撰写的全流程，大幅降低门槛。对专业人士而言是强力助手，对非专业用户而言则是轻松上手的数据分析入口，让数据驱动决策更迅速。

本书旨在系统介绍如何不依赖传统分析工具、不手写代码，仅用 ChatGPT 完成数据分析。涵盖 ChatGPT 基础使用、高效提示词设计，到数据收集、预处理、特征工程、分析、可视化与报告撰写，提供一套完整指南。

第一章介绍 ChatGPT 的注册、登录及升级。随后章节深入提示词的结构、原则与优化技巧，帮助读者更好地驱动大模型完成复杂任务。

数据分析流程涵盖收集、预处理、分析、可视化与报告。第四章起逐环节展开。数据收集部分介绍如何生成模拟数据、设计问卷与抓取数据；预处理部分聚焦清洗、转换、集成与脱敏，确保准确与安全。

特征工程是模型性能的关键，本书通过案例讲解特征选择、衍生与降维，说明如何利用 ChatGPT 优化特征，为后续分析做好准备。

在分析章节，通过实际案例展示对比分析、分组分析、交叉分析、相关性分析、漏斗分析等多种方法，让读者看到大模型在真实场景中的作用。

可视化是数据分析的重要环节，本书介绍基本原则，并详解如何用 ChatGPT 绘制构成类、比较类、趋势类、分布类、关系类等多种图表，助力需求匹配。

进阶方法如回归、分类、聚类，对解决复杂问题至关重要。书中通过讲解与案例，呈现 ChatGPT 处理复杂分析的强大能力，深化对应用场景的理解。

最后讨论如何用 ChatGPT 撰写数据分析报告，涵盖日常工作类、专题分析类、综合研究类，帮助读者有效呈现结果，提升沟通与应用效果。

本书以实例驱动，力求为读者提供全面翔实的数据分析指南，帮助简化流程、提升效率与质量。希望读者不仅掌握技能，更能在工作中落地解决实际问题，提升个人与组织的决策水平。

**1．注册前准备条件**

（1）国际网络环境：IP地址需处于非中国大陆地区。部分 IP 可能已被 OpenAI 封锁，无法访问。

（2）境外邮箱：注册需填写邮箱用于接收验证邮件。Gmail 需在国际网络环境下注册。

**2．注册流程**

打开 ChatGPT 官网，会看到如图 1.2 所示的欢迎页，包含“登录”与“注册”两个入口，点击“注册”进入下一步。
