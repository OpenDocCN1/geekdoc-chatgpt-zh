# 数据交易所的职能边界

数据要素能否顺畅进入市场，关键在于交易场所的权限划分与功能边界。现有立法并未对交易所的职能不能直接作出界定。2020年9月，《北京国际大数据交易所设立工作实施方案》在实践层面给出五项定位：充当权威的数据信息登记窗口，成为市场广泛认可的交易载体，搭建覆盖全链条的数据运营管理服务体系，以数据为核心开展金融创新服务，并依托新技术构建数据金融科技平台。该方案在制度设计上对交易所定位的法理需求作出了回应。

当下数据交易已成为要素市场建设的突出瓶颈。北京、贵州、上海等地虽已落地大数据交易所，但成交体量与预期差距较大，且多数并非真正意义上的数据交易所。学界看法分歧明显：一派主张交易所最终应向平台型企业演进，通过制度化的避风港安排坚持稳定供给导向，在与互联网平台的竞争中形成差异化优势，同时强化公共数据供给的公益属性；^[[\72\]](#txt004.html#footnote_content_txt004_72))另一派强调阿罗信息悖论，指出交易需要信息披露而披露会削弱数据价值，因此更适合采取数据服务合作模式而非完全市场化的合同模式，类比上更接近婚姻介绍所式的撮合与安全认证，而非商场或证券交易所的模式；^[[\73\]](#txt004.html#footnote_content_txt004_73))^[[\74\]](#txt004.html#footnote_content_txt004_74))还有从公共治理角度的分析，认为交易所是数据要素市场主体开展流通交易的指定空间，可区分为国家级交易所与区域或行业数据交易中心两类。国家级应坚持公共属性与公益定位，突出合规监管与基础服务，可由证监会会同发改委等部门联合审批，定位为全国性法定场所；区域或行业中心则负责本地区或本行业公共数据授权运营及公共数据与社会数据融合流通等职能。^[[\75\]](#txt004.html#footnote_content_txt004_75))由此可见，学界常将数据交易所、大数据交易所、国家级与区域级概念混为一谈。

对照《上海市数据条例》草案历次演变及《证券交易所管理办法》《期货交易所管理办法》的相关规定，可以判断条例所指的数据交易所并非业内常见的大数据交易所，也不是区域行业级交易中心，而应指向国家级交易所。立法主旨是推动数据产品服务交易并保障安全，可参照上交所模式赋予行政与市场双重职能，确保数据有效流通。因为数据交易与证券交易本质相近，均属数字交易，证券交易所并不流通实物，而是股票、债券等证券的流通。由此，交易所宜承担以下五方面功能：（1）数据资源汇聚载体，汇集海内外各类资源；（2）数据信息登记载体，为交易提供高效便捷登记；（3）高效安全交易载体，营造安全高效的交易环境；（4）价值开发载体，以数据为核心生产要素打造价值开发平台；（5）金融开放载体，以数据为核心促进数据与金融服务的深度融合。

## 第五十七条 【数据交易定价】

从事数据交易活动的市场主体可以依法自主定价。

市相关主管部门应当组织相关行业协会等制订数据交易价格评估导则，构建交易价格评估指标。

[PRE1]

本条是数据交易中的重要条款，通过确定市场主体可以依法自主定价，以及市相关主管部门与相关行业协会等制定数据交易价格评估机制，为数据交易提供定价支撑。

[PRE2]

### 一、数据交易定价的法治需求

当前各类数据交易快速扩张，但规范活动的制度供给明显滞后。^[[\76\]](#txt004.html#footnote_content_txt004_76))价格与评估指标是交易运转的基础。随着智能化技术普及，数据的开发、共享、交换、流通已成常态，数据交易正成为挖掘数据价值的关键驱动，而流动性好、价格发现能力强的场所将成为重要支撑，^[[\77\]](#txt004.html#footnote_content_txt004_77))因此定价问题愈发关键。

数据资产的法律地位与估值标准尚未明晰，导致交易落地困难。^[[\78\]](#txt004.html#footnote_content_txt004_78))在数据市场中，价值高低很大程度上取决于各方对数据的分析挖掘能力，故定价难度较大。其一，若价格长期不确定，将制约交易高效开展；其二，随意定价、掠夺性定价、垄断定价等行为会扰乱秩序，削弱市场稳定。缺乏有效的定价机制与评估指标，就难以形成规范有序的市场，也难以从市场和制度层面激励交易目标的实现。可见，规范化定价制度是数据要素市场法治建设的重要一环。

### 二、数据交易的定价体系

在实践层面，上海数据交易中心与贵阳大数据交易所的做法具有代表性。两者虽非《上海市数据条例》意义上的数据交易所，而是交易中心与大数据交易所形态，但均依托资产评价指标由系统自动生成参考价，需求方可在参考价基础上结合自身需求与供给方确定成交价，并提供集合竞价、拍卖等市场化方式。不足在于协商流程可能拉长，时间成本升高，不利于效率提升。数据交易的核心在于缩短资产变现周期、降低机会成本，不能单纯以交易量估值。^[[\79\]](#txt004.html#footnote_content_txt004_79))在市场厚度与流动性不足时，集合竞价难以发挥作用，^[[\80\]](#txt004.html#footnote_content_txt004_80))拍卖也仅适用于存在多名潜在需求方的情形，否则难以起拍。^[[\81\]](#txt004.html#footnote_content_txt004_81))

《上海市数据条例》从两方面完善定价体系：第一，以合意为核心的自治方式，明确市场主体可以依法自主定价。条例第 15 条规定“自然人、法人和非法人组织可以依法开展数据交易活动”，据此市场主体有权依法自主定价；第二，建立价格评估机制，明确市相关主管部门应组织行业协会等制定价格评估导则并构建评估指标。价值评估是定价与交易的前提，只有厘清价值才能定价并促成交易。第 2 款通过明确主管部门责任并赋予行业协会自律权，推动多方协同构建交易价格评估体系。在此基础上完善静态与动态定价模式，探索更多定价方式，形成统一、规范、有序的定价规则。^[[\82\]](#txt004.html#footnote_content_txt004_82))总体而言，数据交易属于民事行为，与一般买卖并无本质区别，应遵循意思自治。主体可自由作价，本条强调的“可以依法自主定价”体现的是对参与方意思自治的尊重，而非限制。市场主体只需按“自定+评估”原则确定协议价即可。

### 三、数据交易的定价目标

科学定价应同时实现两项目标：一是反映数据本身价值并尊重交易双方合意，确保定价准确；二是适应数字经济对大规模快节奏交易的需求，提升定价效率。为此需确立合理的数据资产定价指标，按类别开展评估并对不同指标赋予差异化权重，以体现各类数据的效用特征，保证评估准确性。^[[\83\]](#txt004.html#footnote_content_txt004_83))

具体操作上，可先由交易场所依据资产定价指标给出价格区间，形成指导区间，交易双方在此区间内协商细化。既能降低磋商成本、提高效率，也可避免信息不对称导致的单方定价或歧视定价，保障公平性。制度设计上应以市场自主定价为主、政府指导规制为辅，发挥市场无形之手与政府有形之手的作用。同时善用法律、经济、行政等宏观调控手段，防止价格盲目走高形成泡沫或过度压低抑制发展，及时规制价格欺诈、价格歧视、掠夺性定价等扰乱秩序行为，维护市场平稳运行。
