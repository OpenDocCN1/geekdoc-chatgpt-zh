Beam Search 的运作逻辑是在解码时并行维护多条候选序列，而非只追一条贪心路径。通过逐步保留得分靠前的前若干条分支，最终从中选出累计得分最高的完整输出，相比单路径贪心更容易在表达空间里找到更符合预期的表述。

在广告文案创作里，模型可以一次性产出多个版本，再由 Beam Search 从中挑出最贴合受众需求的那条。

- 领域词表与模板：
给模型设定限定词库或固定模板，强制输出必须包含指定用词或遵循既定结构。例如推荐运动装备时，要求文本里必须出现“舒适性”“透气性”等表述；模板可规定为“推荐适合跑步的轻便跑鞋，其特点包括轻便、缓震、透气。”

案例：用户兴趣是“健康饮食”时，生成结果需要严格带入“营养均衡”“低脂肪”等表述。

##### 4. 无约束 vs 有约束：生成质量的跃迁
场景：某用户的兴趣标签是“跑步装备”，需要生成推荐内容。

（1）无约束生成：模型可能给出：
“推荐高性能跑步鞋，适合长跑。”
“推荐家用烘焙设备，满足家庭需求。”
第二条明显偏离用户意图。

(2) 有约束生成：引入强制词汇约束、语义相似度筛选后，输出变为：
“推荐轻便跑鞋，适合长跑，具有出色的缓震性能。”
“推荐专业运动服，透气性强，适合高强度运动。”
加入约束后，内容更贴合需求，整体质量明显提升。

#### 4.4.2 基于 RLHF 的生成质量优化技术
人类反馈强化学习把人工偏好注入模型优化闭环，通过引导生成行为更贴合人类审美，提升相关性、质量和满意度，在生成式推荐中价值突出。

##### 1. RLHF 的基本原理
RLHF 融合强化学习框架，以人类反馈为奖励信号优化模型，通常包含：
（1）生成初始内容：用预训练生成模型如 GPT 产出初稿。
（2）收集人类反馈：将结果展示给评审人员，获取评分或排序。
（3）奖励模型训练：基于反馈训练奖励模型，用来评估优劣。
（4）强化学习优化：把奖励模型的输出作为奖励，用策略梯度等算法继续优化生成模型。

##### 2. RLHF 如何优化生成内容
(1) 借人类反馈改进内容质量：传统模型质量取决于预训练语料，可能偏离用户偏好。RLHF 能据评审或用户反馈动态调整行为。例如推荐场景下用户更偏好含“舒适性”“高性能”的描述，RLHF 会引导模型优先生成此类内容。
(2) 动态适应个性化需求：RLHF 可捕捉个体差异。有人偏好详尽突出特性的文案，有人偏好简洁明了。优化后模型能在生成时自适应风格。
(3) 减少有害或无关内容：模型可能产出跑题或不合规范的信息。RLHF 通过负奖励抑制这类输出，推动更安全、更相关的内容。
