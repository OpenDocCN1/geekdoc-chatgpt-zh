# 9.5 盲盒手办：萌系收藏

盲盒，因为开盒前不知道具体款式，反而在年轻人里持续走红，核心吸引力就在于盒内那只造型抢眼的手办，这类产品本身就适合收藏把玩。

机器人、潮流美少女或呆萌卡通萌宠都能入盒，随机的角色切换恰好迎合了年轻人群体多变的审美偏好。

盲盒手办可使用如下提示词。

## 盲盒手办提示词

| 角色设定 | 一个女孩、一个男孩、美少女战士、孙悟空等 |

| --- | --- |

| 风格细节 | 包括：体型、发型、穿着、动作、表情等 |

| 例如：胖嘟嘟，长发，白色连衣裙，坐在沙发上，开心 |

| 描述词汇 | 最佳质量、杰作、8K 等 |

> 注意

在 Vega AI 里做盲盒手办图，通常先选基础模型 “3D 二次元”，再叠加 3D 角色相关的风格标签，比如：“人偶手办”“Q 版盲盒”“3D 卡通风格”“可爱美少女手办” 等，这些都能在风格广场里找到并收藏。追求更多变化时，还可以尝试 “国风写真”“森系女孩”“高达机甲” 等不同风格组合。

# 9.5.1 动漫联名盲盒制作

想把喜欢的动漫形象做成联名盲盒，手办图也可以交给 AI 完成。因为主流模型在训练时已接触大量经典角色，通常直接在提示词里写上角色名称就能得到对应风格的画面，下面就以美少女战士的盲盒设计为例。

# 提示词

美少女战士，单人，站在白色圆形舞台上，最佳质量，大师之作

# 重点参数

基础模型：虚拟建模。风格：Q版盲盒。

[PRE12]

若要调整手办的服饰等细节，只需在风格描述里加入对应的关键词即可。

# 9.5.2 零散描述生成手办

大多数盲盒手办走的是可爱胖嘟嘟的 Q 版路线，也有按真人比例还原的版本。

# 提示词

一个可爱女孩，白色短发，红色的眼睛，戴着耳环，穿着白衬衫，黑裙子，站在舞台上，面带微笑，最佳质量，杰作

# 重点参数

基础模型: 虚拟建模。风格及强度: Q版盲盒，0.8。

[PRE13]

Vcga AI 里常见的 Q 版盲盒风格还有“卡通3D形象”“3D小孩子”“人偶手办”“可爱美少女手办”等，使用时按需挑选即可。

用 Vega AI 做盲盒手办，除了单用一种风格外，还能叠加多种风格标签，通过混合搭配做出更具辨识度的作品。
