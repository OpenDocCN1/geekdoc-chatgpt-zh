**4.接入飞书：价值与隐患**

实际用下来，把 OpenClaw 接进飞书远不止是多一个聊天入口，整体使用习惯都被改写了。以前必须单独打开终端或 Web UI 去操作，现在它直接沉到你日常的工作协作环境里。电脑端打开飞书能用，手机端打开也能用，指令随时随地就能发出。

更关键的是工作流被打通了。整理资料时可以让它直接写入飞书文档，通知团队时可以让它把消息投到指定群组，配合自动化后还能每天把汇总报告自动推送到固定会话。AI 不再是需要专门点开的网页或程序，而是融入沟通场景里的一个成员。

便利的同时也要关注风险。接入之后 OpenClaw 会获得一定的账号操作权限。如果授予读取文档、发送消息或访问日历等权限，理论上它就能代表你去执行这些动作。所以授权时务必审慎，只给当前任务所需的最小权限，避免一次放开太多。

AI 能成为高效助手的前提，是对权限和行为保持精准可控。

## **4.4 管理记忆：让偏好与历史持续积累**

用其他 AI 工具时很容易碰到记忆短板：刚说过职业背景，聊几轮后又要重问；刚解释完项目背景，换个问题又要从头梳理。这不是能力问题，而是大多数聊天 AI 只依赖当次会话上下文，结束即丢。

OpenClaw 在设计时专门处理了这点。它有一套本地持久化记忆，会把关键信息写入本地文件，后续任务再读回，经验会不断累积。换句话说，它不会每次都从零开始，而是在已有基础上学习调整，用得越久越懂你的习惯和工作方式。

## **4.5 设置心跳：实现持续在线的办法**

前面我们让 OpenClaw 会聊天、会记忆、能通过飞书接收指令、能执行任务。但仔细看会发现一个特点，你的“龙虾”是被动的。只有收到消息才会思考执行，没有新指令系统就一直等待。

这种模式聊天没问题，但要做长期助手就不够用了。比如定期检索行业新闻、持续监控信息源、自动整理每日数据，这些任务不需要你随时发指令，而是需要系统主动运行。

OpenClaw 提供了心跳 Heartbeat 机制来实现这一点。

**1.什么是 Heartbeat**

Heartbeat 可以看作自动触发机制。系统按固定周期运行一次心跳循环，每次循环 AI 会重新检查环境，判断是否需要执行任务。从设计上看更像自动巡检，像值班人员一样定时巡视，发现事就立刻行动。

**2.通过飞书对话设置心跳**

OpenClaw 大部分配置都可以用自然语言完成，设置心跳也不例外。接入飞书频道后可以直接在飞书里设置，示例如下。

添加心跳任务，从现在开始，每半分钟给我发一次内容为“测试”的信息，直到我发送“stop”指令时，停止此心跳任务。把此任务写进后台配置文件中。

实际应用远不止示例。定期整理行业资讯就是典型场景，设置心跳规则让 OpenClaw 每次触发时检查指定信息源，发现新重要信息就自动生成摘要发到飞书，每天打开飞书就能看到整理好的动态。

自动化资料积累也很实用，让它每次心跳时搜索主题最新文章，把有价值内容保存到本地，时间推移就形成持续更新的资料库。

内容创作领域同样适用，设置规则让它定期整理热点话题、提取选题灵感或生成灵感清单，写作时素材已准备好。

合理利用 Heartbeat 后，OpenClaw 不再只是被动响应工具，而是后台持续运行的自动化系统，会不断巡视、检查、整理，并在必要时主动提醒。随着规则完善，自动化能力会越来越强。

## **4.6 设置定时任务：实现每日自动早报**

在自动化体系里，定时任务是常见机制。它能让系统在指定时间自动执行任务，比如每天固定时间生成报告、发送提醒或整理数据。

**1.什么是 Cron**

OpenClaw 的定时任务通常通过 Cron Job 实现。Cron 是 UNIX 系统的经典调度机制，几十年里一直用于服务器自动化，例如定时备份、日志清理和数据同步。

原理很简单：系统持续运行调度程序，不断检查当前时间，时间匹配预设规则时自动执行对应任务。

Cron 使用一种特殊时间表达式，由 5 个字段组成。

分钟 小时 日期 月份 星期

例如：

0 8 * * *

从左到右含义为：0 分钟，第 8 小时，任意日期，任意月份，任意星期。即每天 8:00。

**2.创建定时任务的两种方法**

可以通过与机器人对话创建，也可以在 Web UI 手动创建。

**（1）通过对话创建**

OpenClaw 不需要手动写 Cron 表达式，机器人可以根据自然语言自动生成。

例如这样下达：

每天早上 8 点给我发送一份 AI 行业早报。写进后台配置里。

## **4.7 安装技能：拓展能力边界**

前面我们让 OpenClaw 具备了聊天、飞书接入、记忆记录、心跳和定时任务等基础能力。但深入使用会发现 AI 能力并非无限，比如网络搜索结果不理想，想让 AI 联动邮件日历却不知如何操作。

这时就需要通过 Skill 拓展能力边界。

**1.什么是 Skill**

可以把 Skill 理解为一种能力说明包。它通常由一个目录组成，基本结构如图 4-38 所示，核心文件是“SKILL.md”，用 Markdown 编写，描述 AI 如何完成某项任务，例如需要调用哪些工具、执行步骤、输出格式。

从形式上看，Skill 更像一份操作手册。OpenClaw 启动时会扫描已有 Skill 并加载说明，执行任务时若判断某 Skill 有用，就按其中规则执行。

**2.安装 Skill 的几种方式**

接触 Skill 时容易只关注怎么装，但更重要的是装什么、来源是否可靠。Skill 背后可能涉及工具调用、外部链接甚至本地环境访问，来源不明或描述模糊就会成为风险入口。

稳妥的顺序是先看来源可靠，再看是否匹配需求，最后才安装。

目前最常见也值得优先掌握的两种方式是 OpenClaw 官方的 ClawHub 和腾讯公司的 SkillHub。

**（1）通过 ClawHub 安装**

ClawHub 是 OpenClaw 官方推荐的 Skill 注册中心，可发现 Skill 也可上传自己的 Skill。
