## 第一节 常规寻优手段的困境

[PRE7]

生活、学业与职场中，我们时常面临“如何做到最好”的抉择，这类问题学术上称为“寻优问题”。

比如，质量达标的前提下如何压缩成本？预算固定时如何榨干效益？这些都是典型的寻优场景。这里的“前提”即约束条件，“成本”与“效益”则是优化目标。因为目标值 $y$ 由参数 $x_1, x_2, ..., x_n$ 共同决定，即 $y=f(x_1, x_2, ..., x_n)$，故 $y$ 又称目标函数。

寻优的本质：在约束范围内，寻觅一组最佳参数，使目标函数触及极值（最大或最小）。

主流寻优路径主要有三派：梯度法、枚举法、随机搜索法。

### 梯度法：盲人下山的隐忧

[PRE8]

图10-1 展示了三维目标函数地貌：峰谷起伏，处处不同。数学引入“梯度”量化变化趋势——正值为上坡，负值为下坡，绝对值大小代表变化率。梯度为零之处，即“山顶”或“谷底”。理论上，找到梯度为零的参数组，即获最优解。

梯度法逻辑恰似“盲人下山”：脚下哪边最陡往哪走，走一步测一步，直至谷底。

[PRE9]

图10-2 多峰谷目标函数示意

但现实地貌常极其复杂（图10-2），遍布“山顶”与“谷底”，它们同为梯度零点。梯度法高度依赖起点，盲人极易误入半山腰的“局部极小点”，自以为触底，实则错失“全局最优”。

### 枚举法：穷举的代价

[PRE10]

从10首新歌中选冠军，枚举法要求全听一遍再定夺。虽必得全局最优，但效率低下令人望而却步。实际问题中，可能性往往呈指数爆炸，穷举根本不可行，一旦规模稍大、结构稍繁，枚举法便束手无策。

### 随机搜索法：碰运气的妥协

前两者短板明显，随机搜索法遂成宠儿。它在解空间随机漫游，实时记录最佳战绩。为求效率，往往一旦结果“及格”即收工，故所得仅为“可用解”，而非“最优解”。

## 第二节 进化论与遗传学的算法启示

### 进化论：自然选择的优化逻辑

[PRE13]

达尔文指出：物种特征遗传且变异，造就多样性。环境筛选下，不适者出局，适者生存并遗传优势特征——这就是“自然选择，适者生存”。

生物经遗传、变异、自然选择，自简入繁、由低进高。工程视角下，这漫漫长程实为高明的优化过程，核心机制即：自然选择、优胜劣汰、适者生存。

### 遗传学：基因层面的博弈

[PRE14]

孟德尔奠基遗传学，佐证进化机制。竞争的本质是基因角力。遗传指令封装于细胞，编码于染色体基因。每基因占专属位点，调控特定性状，赋予环境适应性。基因重组与突变或催生更强后代，经自然选择筛选，高适应值基因结构得以留存。

## 第三节 遗传算法：模拟进化的求解利器

遗传算法（GA）汲取优胜劣汰、自然选择、适者生存及基因遗传精髓，成为攻克高复杂度难题的新范式，广泛服役于函数优化、自动控制、图像识别、机器学习、神经网络、分子生物、调度优化等疆域。

### 核心原理：编码与进化

[PRE15]

GA 用编码串（染色体）表征候选解。流程始于一群染色体置入问题“环境”，依适应度筛选优者复制，经交叉、变异基因操作繁育新一代种群。迭代推进中，优良基因保留重组，劣质特性逐代淘汰。子代承袭亲代信息，却在整体性能上超越前辈，群体持续进化——对寻优而言，即不断逼近全局最优。

### 基本操作实录：以 $f(x)=x^2$ 为例

求 $x \in (0, 31]$ 整数时 $f(x)=x^2$ 最大值。枚举法虽稳但笨。GA 如何破局？

**步骤零：编码与初始化**
将 $x$ 编码为定长二进制串（5位覆盖 0-31）。如 $x=10 \to 01010$，$x=31 \to 11111$。串中每位为一基因位。
随机抽取 4 个串组初始种群（规模4）。假设掷硬币得：`01101, 11000, 01000, 10011`。

**操作一：选择（轮盘赌机制）**
依适应度（Fitness，本例直接用目标函数值 $F$）抉择留淘。适应度越高，留给后代的名额越多——模仿“适者多留子孙”。

| 1 | 01101 | 13 | 169 | 14.0% | 0.56 | 1 |
| 2 | 11000 | 24 | 576 | 49.0% | 1.96 | 2 |
| 3 | 01000 | 8 | 64 | 6.0% | 0.24 | 0 |
| 4 | 10011 | 19 | 361 | 31.0% | 1.24 | 1 |

| **最大** | | | **576** | **49%** | **1.96** | **2** |

构建轮盘赌盘（图10-4），扇区面积按适应度占比划分。旋转 4 次，落入谁家谁就复制入“匹配池”。
[PRE16]
图10-4 选择操作的轮盘赌转盘

本轮结果：串1复制1次，串2复制2次，串3出局，串4复制1次。新种群：`01101, 11000, 11000, 10011`。

**操作二：交叉（基因重组）**
两步走：匹配池中随机配对 $\to$ 设交叉点 $k \in [1, l-1]$，交换 $k$ 位之后的子串。

例：父代 `01101` 与 `11000`，$k=4$（交换第5位）$\to$ 子代 `01100`, `11001`。

表10-2 交叉实录

| 新编号 | 父本 | 母本 | 交叉点 | 子代串 | x值 | 适应度 F |
|---|---|---|---|---|---|---|
| 1 | 01101 | 11000 | 4 | 01100 | 12 | 144 |
| 2 | 11000 | 01101 | 4 | 11001 | 25 | 625 |
| 3 | 11000 | 10011 | 2 | 11011 | 27 | 729 |
| 4 | 10011 | 11000 | 2 | 10000 | 16 | 256 |
| **总计** | | | | | | **1754** |
| **平均** | | | | | | **439** |
| **最大** | | | | | | **729** |

**操作三：变异（防早熟保鲜）**
以微小概率（如千分之几）随机翻转某基因位（0$\leftrightarrow$1）。虽居次要地位，却是防止优良基因丢失、跳出局部最优的关键。本例 20 个基因位，变异率 0.001，期望变异 0.02 位，故本轮无变异。

**对比可见**：一轮迭代后，种群最大适应度从 576 升至 729，平均值从 293 跃至 439。解已朝最优迈进。重复此过程，终抵全局最优，且每步运算轻快、弱依赖问题细节。

### 狼群算法：残酷分配背后的生存智慧

捕猎得手后，狼群不搞“平均主义”，实行“论功行赏、强食弱补”：首功者与强壮者优先饱餐，残羹冷炙留给弱小者。这看似冷酷的分配，实则精准保障了核心战力的体能恢复，确保下次狩猎仍有主力军，从而维系群体延续。

学者借此启发构建**狼群算法**。将捕猎抽象为三大智能行为——**游走、召唤、围攻**，辅以“胜者为王”的头狼更迭规则与“强者生存”的种群更新机制。

#### 1. “胜者为王”头狼更迭
初始空间中，目标函数值最优者称霸为头狼；迭代中，若新一代最优狼超越旧头狼，即废旧立新，头狼位置动态更新。

#### 2. “强者生存”种群更新
按“强食弱”分配，弱狼饿死概率大。算法中直接淘汰适应度最差个体，随机生成新个体注入鲜血。

头狼、探狼、猛狼默契联动成就完美围猎，“强食弱”规则更引导种群向再次捕获概率最高的方向繁衍进化。
