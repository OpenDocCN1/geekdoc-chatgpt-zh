## 别把算法当权威

自动化确实已经渗进日常，并带来了看得见的好处。算法如今能辅助病理医生挑出乳腺癌病灶，帮警方锁定惯犯，把空难概率压到极低，人类累积的智慧被压缩成随时可用的工具，全球即时互通的旧理想也早就实现。但越是想用技术去解决宏大难题，就越容易被新工具制造出新麻烦。强大到近乎无所不能的系统，最终留下的却是一团难以理清的乱绪。

司法、医疗、警务乃至网购，都在隐私、偏见、失误、问责和透明度上露出难以弥合的裂口。看今天在跑的系统，公平议题已经触及自我追问：我们到底是谁？社会该呈现什么模样？我们愿意把多少决策权交给冰冷的代码？

根源或许在于起点就错了——把算法直接视作权威。

不愿质疑这种权威，正好给了投机者可乘之机。写书期间我接触过形形色色的推销者，他们兜售各种神奇产品想骗钱。明明已有大量研究可以证伪，仍有人向警政部门推销系统，声称仅凭面部特征就能“预测”恐怖分子或恋童癖者。也有团队宣称自己的模型能改写剧本台词，让电影票房飙升*。甚至有人理直气壮地说，自己的算法能帮人找到真爱。

* 一次访谈中，我见到这家公司的首席执行官，问他是否验证过算法真的像宣传那么神奇，他却讲起一个传闻——一位好莱坞知名明星因神经网络的分析而错失参演一部剧集。我立刻指出，这个案例只证明有人买了他的产品，并不能证明算法有效。他回道：“我们又不是做学术的。”

名声在外的系统，往往更暴露滥用权威的乱象。本书收录了大量“算法伤人”的例子：某预算工具随意削减了爱达荷州行动不便者的财政补助；以历史数据为基础的累犯风险模型更倾向把黑人被告划为高风险；肾损伤筛查系统让数百万人未经知情或授权就放弃了最核心的个人隐私；超市推荐算法无情地剥夺了一名少女向亲生父亲坦白怀孕的机会；而本为拯救犯罪受害者的战略目标名单，在警方手中却变成了抓捕名单。不公的现象无处不在。

指出算法的瑕疵也会带来另一风险：仿佛暗示存在完美解法在等我们找到。我曾苦思寻找一个公平的算法，但即便看似完美的系统——比如飞机自动驾驶或诊断癌症的神经网络——也藏着解不开的问题。正如《汽车》章节里所见，自动辅助驾驶会让习惯依赖系统的司机或乘客陷入极度危险；《医疗》一章里那些神奇的肿瘤查找模型，也有人担心并不适用于所有种族。就算把算法全剔除，公平的系统也寥寥无几。深入任何领域，偏见的痕迹总会冒出来。

* 我给垃圾算法起了一个检测办法，叫“魔法测试”。读到一篇关于某算法的报道，试着把“机器学习”“人工智能”“神经网络”换成“魔法”，如果句子读起来依然顺畅、没有语义损失，那这篇报道很可能在故弄玄虚。在我看来，可预见的未来里，“用魔法解决全球饥饿”“用魔法写出精彩剧本”和用人工智能去做同样的事，效果并无二致。

既然接受完美不存在，明白算法注定会犯错、注定不公平，我们仍会想办法提升准确率、降低偏见。认识到算法和人一样不完美，或许能降温我们对算法权威的期待。

设想一下，既然做不到以绝对公平打造算法，我们能否把重心转向建设纠错机制？能否把同样多的时间和精力花在挑战和善用自动化系统上？或许应该从一开始就造一个会提问的算法。算法可以协助而非命令人类做选择；它能说明推导出某个决定的依据和理由，而不是直接给出结果。

在我看来，最理想的算法是始终把人放在眼里的算法。它清楚我们习惯过度信任机器的判断，也承认自身的局限，坦然面对不确定性。

赢得《危险边缘》的IBM沃森就具备这种特质。题目只有一个正确答案，该系统却会把思考过程中出现的其他选项一起列出，并标注可信度分数。如果累犯风险评估也有类似机制，法官就能更好地解读信息；如果人脸识别能给出若干可能匹配而非单一人像，误判或许就不至于发生。

神经网络在筛查乳腺癌切片时也靠这个思路。系统不会直接判定谁有肿瘤，而是在大量细胞中圈出可疑区域，供病理学家观察诊断。这样算法不易出错，医生也能减少误诊，双方相互补位。

还有本书开头的象棋案例。输给深蓝后，加里·卡斯帕罗夫并未排斥计算机，反而大力推动“半人马象棋赛”Centaur Chess，倡导人机组队对抗。算法负责评估每个走法的可能性，人类棋手掌控整体战略。

卡斯帕罗夫说过：“计算机的辅助减轻了我们的计算负担，让我们有更多的时间专心研究策略布局。在这种情况下，人类的创造力反而变得更加重要。”² 借此，象棋水平达到前所未有的高度，步法精细、布局缜密，是人机合一的极致。

我期望的未来是这样的：本书里那些“傲慢”“独裁”的算法不再存在。我们不再把机器奉为客观事实的化身，而是像对待任何权力来源一样，可以质疑它的决定、审视它的动机、让它感知我们的情绪、追踪利益走向、为错误负责，并不再盲目乐观。我认为，把算法转化为社会的纯粹正能量，并让它承担起应有的责任，才是关键。因为毋庸置疑，算法时代的到来，恰恰让人类显得更为重要。
