# 第6章 多目标融合策略

上一章我们系统梳理了精排阶段的主流算法，其中多任务学习在复杂业务场景下的应用尤为关键，特别是在短视频流式推荐中，它已确立为标准建模范式。多任务学习的核心在于同步建模多个与核心指标挂钩的精排目标，推理时需并行输出多个目标的预估分。然而，最终呈现给用户的排序序列只有一个，因此如何将多目标预估分有效融合以最大化业务收益，成为精排后至关重要的一环。本章将先剖析多目标融合的必要性，继而讲解基于搜索的启发式参数确定方法（含贝叶斯优化），最后深入探讨通过进化策略（ES）与强化学习实现融合参数的自动化学习。

## 6.1 为何需要多目标融合

在落地场景中，产品的核心业务指标往往具备宏观性，直接建模难度极大。以短视频信息流为例，核心指标通常是“日人均有效播放时长”，该指标反馈周期长（需等待一日结束才能获取完整正负样本），无法满足流式数据环境下精排模型实时迭代的需求。精排模型可直接优化的目标，往往是反馈迅速的信号，如单次视频播放时长、点赞率、评论率等，这些信号通常在秒级至分钟级内即可闭环。业务认知普遍认为，这些短周期反馈指标与长期核心指标存在正相关性。

因此，工业界通行的做法是：利用多任务学习联合建模多个短周期反馈目标，再通过特定公式或模型将多路预估分融合为最终排序分，而该最终排序的优化导向正是核心业务指标。这便是多目标融合建模的由来与逻辑闭环。

## 6.2 启发式多目标融合实战

### 6.2.3 落地实战：离线调参全流程

理解原理后，我们聚焦推荐精排多目标融合场景下的离线调参实战。整体流程如图 6-1 所示，关键环节拆解如下：

1.  **全量日志落盘**：沉淀融合现场全貌，含候选物品集及其多目标精排分、曝光物品的用户行为反馈、融合后策略所需上下文（如多样性打散特征等）。
2.  **参数生成策略**：为规避参数剧烈波动带来的负面冲击，新参数生成锚定对照组基线，在其邻域内通过网格/随机搜索采样。
3.  **离线流式模拟**：调整融合参数得出新融合分，重排序后的物品列表仅为中间态。需进一步模拟后续策略（如多样性打散等重排逻辑），还原最终用户侧曝光列表。
4.  **离线指标评估**：无真实交互介入，需设计合理代理指标并充分利用落盘日志。可行方案：假设精排分校准良好，基于最终列表计算加权得分评估参数优劣：

$$score = \sum_{i=1}^k f(w_k, s_k) \tag{6-1}$$

其中，$w_k$ 为第 $k$ 个目标的融合权重，$s_k$ 为对应预估分，$f$ 为聚合函数（可为乘法、除法（针对负反馈目标）、取最大值等）。权重初始值需融合业务先验与聚合函数形式确定，并结合线上实验持续迭代。评估环节是离线调参的核心，需不断打磨以最大化离线指标与线上效果的对齐度。

尽管离线搜索较人工经验调参已大幅前进，但仍存两大痛点：

1.  **试验间割裂，缺乏指导性**：每轮搜索相互独立，历史结果无法指导后续搜索方向，样本利用率低。
2.  **离线在线天然鸿沟**：强行对齐线上指标评估易引入偏差，甚至损害用户体验，这是启发式搜索难以根治的结构性短板。
