1. 32 位 int 类型的存储范围是（ ）。

A. -2147483647～+2147483647

B. -2147483647～+2147483648

C. -2147483648～+2147483647

D. -2147483648～+2147483648

**【考点识别】**

2 C++程序设计|2.2 基本数据类型|【1】整数型：int，long long

**【分析讲解】**

C++中 int 在 32 位环境下采用补码表示：

最小值 -2³¹ 即 -2147483648。
最大值 2³¹-1 即 2147483647。

因为最高位为符号位，所以实际区间为 -2147483648～2147483647。

**【参考答案】**

C. -2147483648～+2147483647

**【编程魔法师讲解考点】**

**一、什么是 int 类型**

int 是 C++最常用的整型，长度随平台而定，现代主流系统多为 32 位即 4 字节。

范围为何如此？因采用补码存储：

（1）正数部分：符号位为 0，数值位全用，最大为 01111111 11111111 11111111 11111111 = 2³¹-1 = 2147483647。
（2）负数部分：符号位为 1，补码表示，最小为 10000000 00000000 00000000 00000000 = -2³¹ = -2147483648。

**二、负数为何多一个**

补码下 0 仅占一个编码，负数比正数多一个表示。

**三、使用注意**

1. 防溢出
运算超出范围如 2147483647+1 会回绕到 -2147483648，建议改用 long long。
2. 选型
范围小可用 short，范围远超 20 亿则用 long long。

**【题目总结】**

此题考查基本类型与补码，记住 32 位 int 为 -2³¹ 到 2³¹-1，对位运算和负数理解很有帮助。

**一、进制简述**
