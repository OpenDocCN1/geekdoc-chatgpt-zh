用 FAISS 把十万篇医学论文秒查出来

医学文献每天都在爆炸式增长，靠关键词匹配已经找不到真正相关的研究。把摘要转成向量、用 FAISS 做近似检索，才能在毫秒级从海量论文里挑出语义最接近的内容。下面是一套从嵌入生成到增量更新、再到压缩索引的生产级落地思路，代码细节已保留可直接复现。

检索的核心是把查询也变成向量，再在索引里找距离最近的邻居。拿到距离和下标后，依据 id 到原始行的映射取出标题和摘要，组装成带 id、distance、title、abstract 的结果列表返回。测试时用 “cancer treatment methods” 作为查询，打印前几条命中即可快速验证效果。

数据准备与基础索引搭建

先把清洗好的 DataFrame 加载进来，里面必须包含 id、title、abstract 和 embedding 四列。嵌入维度由第一条向量的形状决定，之后用 IndexFlatL2 建立平面索引，把全部向量一次性 add 进去。创建完成会输出当前向量总数，这一步适合小规模验证。

知识库要持续新鲜

文献每天都在更新，需要定时拉取、清洗、生成嵌入并追加到索引。函数 update_knowledge_base 接受 API 地址和更新间隔，默认一天一次。每次循环尝试 fetch_medical_data，拿到新数据后 clean_data，再用抽象生成嵌入，转换成 float32 数组 add 到 index，同时更新 id 到索引位置的映射，最后打印当前向量总数。没有新数据时只提示并等待下一次。

从平面索引到倒排加速

数据量上来后，IndexFlatL2 会吃内存。改用 IVF，把空间分成 100 个聚类，用一个量化器先训练再把向量分配到最近的簇。查询时只扫部分簇，速度大幅提升。训练和添加完成后会打印倒排索引的向量数。

# 创建倒排索引结构 (IVF), 将数据分为 100 个聚类

index_ivf=faiss.IndexIVFFlat(quantizer, embedding_dim, nlist, faiss.METRIC_L2)

# 训练索引

index_ivf.train(embeddings)

index_ivf.add(embeddings)

print("倒排索引结构创建完成,向量数量:", index_ivf.ntotal)

接入语义模型并封装查询

查询也要走同一套嵌入。选用 distilbert-base-uncased 的 tokenizer 和 model，对文本做截断到 512 并取 CLS 位置的隐藏状态作为向量。search_medical_documents 先生成查询向量，设置 nprobe=10 控制检索范围，再在 index_ivf 上搜索，最后把结果映射回 DataFrame 的 id、title、abstract 和距离。

from transformers import AutoTokenizer, AutoModel

# 加载同样的嵌入模型

tokenizer=AutoTokenizer.from_pretrained("distilbert-base-uncased")

model=AutoModel.from_pretrained("distilbert-base-uncased")

def generate_embedding(text):

    """生成查询文本的嵌入向量"""

    inputs=tokenizer(text, return_tensors="pt", truncation=True, max_length=512)

    outputs=model(**inputs)

    embedding=outputs.last_hidden_state[:, 0, :].detach().numpy()

    return embedding.flatten()

def search_medical_documents(query, top_k=5):

    """

    使用FAISS进行相似度查询，返回最匹配的top_k个文档

    """

    # 生成查询的嵌入向量

    query_embedding=generate_embedding(query).reshape(1, -1).astype('float32')

    # 在倒排索引中检索

    index_ivf.nprobe=10  # 设置nprobe值以控制检索效率

    distances, indices=index_ivf.search(query_embedding, top_k)

    results=[]

    for dist, idx in zip(distances[0], indices[0]):

        result={

            "id": cleaned_df.iloc[idx]["id"],

            "abstract": cleaned_df.iloc[idx]["abstract"],

            "distance": dist

        }

        results.append(result)

    return results

压缩存储与最终优化

当向量数达到数十万，IVFFlat 仍占内存。改用 IndexIVFPQ 做倒排产品量化，聚类数保持 100，子向量数 m=8，每个子向量 8 bit。训练后添加向量，内存大幅下降且召回可控。

[PRE8]python

# 使用倒排产品量化 (IndexIVFPQ) 索引

nlist=100          # 聚类数量，与10.2.1节保持一致

m=8                # 产品量化的维度

n_bits=8           # 每个子向量的比特数

# 创建IndexIVFPQ索引

quantizer=faiss.IndexFlatL2(embedding_dim)

index_ivfpq=faiss.IndexIVFPQ(quantizer, embedding_dim, nlist, m, n_bits)

# 训练并添加向量到索引

index_ivfpq.train(embeddings)

index_ivfpq.add(embeddings)

print("倒排产品量化索引 (IVFPQ) 创建完成。索引中的向量数量:", index_ivfpq.ntotal)
