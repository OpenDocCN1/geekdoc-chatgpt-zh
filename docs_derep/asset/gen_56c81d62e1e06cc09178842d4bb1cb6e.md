从舞会配对例子可以看出，推导出来的式子并不能锁定具体的舞伴是谁，它只能说明三个男孩的舞伴或许是某位女孩，三个女孩的舞伴或许是某位男孩，并附带三条限制：鲍勃的舞伴不可能是盖尔，盖尔的舞伴不可能是布拉德，加比的舞伴只能在布拉德或比尔之间选择。

这两种写法该怎么比较？生动版与范围更宽的非生动版，哪个更合适？在纯逻辑上，二者是等价的：一个成立，另一个必然成立。以生动版为起点，已知鲍勃的舞伴是吉娜等信息后，非生动版的陈述自然也成立，比如鲍勃的舞伴不是盖尔，加比的舞伴可能是布拉德或比尔。反过来，从非生动版出发，已知鲍勃的舞伴不是盖尔等条件，解开配对谜题后，生动版的结论也会出现，比如鲍勃的舞伴是吉娜，盖尔的舞伴不是比尔，布拉德的舞伴是加比。

二者显然不等同。前者分析鲍勃的舞伴几乎是直观看出来的，后者则必须先把谜题解开才能得到。

总体而言，每个世界模型都对应一个包含相同明确信息的 L 表达式，反过来不成立。L 表达式可以省去世界模型里必须细化的部分。事实上，还能构造出比上面那个非生动式子省略得更多的非生动式子。

比如把图 3 的生动式子中不同性与最多性去掉，仍可得到一个成立的世界模型：仍然可能得出鲍勃的舞伴是吉娜，但同时存在其他可能。鲍勃可能与布拉德共享属性，例如二人舞伴都是加比。鲍勃的舞伴也可能是三位女孩之外的其他人，男孩同理。在这种设定下，仅靠解谜无法确认鲍勃的舞伴是吉娜之外的某位女孩，因为所需信息并未被确认。

回到最初的问题，表示知识时 L 表达式能否替代世界模型？答案是肯定的。在封闭世界解释下，每个世界模型都有一个涵盖相同明确信息的生动 L 表达式，且包含相关的不同与最多子表达式。但某些 L 表达式已超出世界模型的表示能力。L 这类语言的表达力取决于它保留了哪些可能性，以及留下了哪些未解的谜题。用世界模型、概念模型与派生子句来表示知识，实际上把可表示的知识类型限制在了特定范围内。

为什么要把可表示与可推理的知识类型限制在生动表达式里？这将在最后一节讨论。下面先用一个更简单的例子，深入比较生动与非生动表达式的差异。

## 生动与非生动的界限

从第六章的舞会例子可以看出，非生动表达式本质上是逻辑思考题的形式，包含的信息例如：

鲍勃的舞伴不是吉娜。
加比的舞伴是布拉德或比尔。

这类表述可以用不是、或者、存在等逻辑运算符来写。我们也可以不用运算符来出题。例如：

杰克、安妮和乔治在同一个房间。杰克看着安妮，安妮看着乔治。杰克已婚，乔治离异。

房间里是否存在已婚人士正在看着未婚人士？

乍看答案并不明显。心理学家做过测试，大多数受试者觉得陈述不足以得出唯一答案，因为安妮的婚姻状况未知。

实际上，根据给定信息答案是可以确定的。考虑安妮的状态：如果安妮已婚，那么已婚的安妮正在看未婚的乔治；如果安妮未婚，那么已婚的杰克正在看未婚的安妮。我们不知道安妮是否已婚，但这不影响结论：无论如何，都存在一位已婚人士正在看着一位未婚人士。这个思考题与舞会题类似，都需要先解开谜题才能作答。注意，这里并不足以判断是否存在未婚人士正在看着已婚人士。

如果上节的分析成立，就无法用世界模型或生动表达式来表示这些给定信息。但看下面这种写法：

人#31是一个人，人#31的名字是杰克。
人#32是一个人，人#32的名字是安妮。
人#33是一个人，人#33的名字是乔治。
人#31正在看着人#32。
人#32正在看着人#33。
人#31的婚姻状况是已婚。
人#33的婚姻状况是离异。

这似乎把信息都表示出来了。这样的世界模型能得出答案吗？

不能。问题出在封闭世界解释下，以下断言：

人#33的婚姻状况是已婚。

在该模型中被判为错误，因为乔治是离异。同样，以下断言：

人#32的婚姻状况是已婚。

也为错误，因为模型里根本没说明安妮的婚姻状况。TEST 操作在这两种情况下都会返回错误。换句话说，在这个世界模型里，安妮和乔治都没有被赋予已婚属性，而谜题只说明了乔治的状态，并未说明安妮的状态，也不能由此断定安妮未婚。因此，这个世界模型或对应的生动表达式未能正确刻画给定信息。可以用非生动表达式如实表示，比如用存在来表达安妮具有婚姻状况，却不具体说明。

以上说明，导致谜题难以解答的原因，并非问题中出现了不是或或者等运算符，而是遗漏了在世界模型中表示信息并解开谜题所必需的细节。

注意，如果问题明确给出安妮的婚姻状况，推理会完全不同。例如：

杰克、安妮和乔治在同一个房间。杰克看着安妮，安妮看着乔治。杰克已婚，安妮单身，乔治离异。

是否有一位已婚人士正在看着一位未婚人士？

现在可以明确已婚的是杰克，未婚的是安妮。即使把安妮的状态改为已婚、丧偶或离异，答案依然不变。

在每种情况下，都能轻松判断出：有一位已婚人士正在看着一位未婚人士。对我们而言，包含安妮婚姻状况的变量之所以好推理，是因为相关信息能在世界模型里被准确找到。

## 可供常识参考的经验教训

可以观察到，人们更习惯用世界模型中足够具体的信息来推理，这正是本书提出的常识机制的核心。

再看舞会例子。下面这个式子能说明鲍勃的舞伴是吉娜：

存在人 x 和人 y，其中人 x 的名字是鲍勃，人 y 的名字是吉娜，且人 x 的舞伴是人 y。

舞会的两个版本都让该式子在逻辑上成立。也就是说，给定生动版或非生动版，都能按逻辑规则判定上述式子是否成立，二者逻辑意义一致。

区别在于计算。生动版下，可用世界模型配合 TEST 程序轻松验证该式子是否成立。TEST 也可以直接作用于生动表达式得出答案，难度不大。

在非生动版下，上述捷径失效。判断该式子是否成立，需要先分析非生动版提供的信息，再采取措施解开谜题。一般而言，没有生动限制时，判断一个式子是否为另一个式子的逻辑结果，需要相当重的逻辑机制，接近教科书里的形式逻辑，且超出本书范围。这种计算适合逻辑谜题，不适合日常常识。

关键在于，我们需要足够简单的常识推理，能够全自动常规运行，无须大量劳动或人工监控，即便知识库很大。我们认为，存在一种基于受限经典逻辑的一般推理形式。这种逻辑必须以限制形式为前提：生动表达式。若放弃世界模型的封闭世界解释，逻辑推理会变得过于沉重，难以实现判断什么成立、什么将成立或如何使之成立等目的。更具联想性的推理，如 x 与 y 有何关联，或更具类比性的推理，如 P 如何近似 Q，则需另行分析。

这正是使用世界模型并以概念模型和派生子句扩展，作为常识推理依据的关键计算原因，也是常识可以基于逻辑推理却无需复杂逻辑的原因。总之，逻辑专业知识并非常识的先决条件。

这也有助于理解一个奇怪现象：在逻辑谜题之外，人们似乎倾向于为给定信息补充遗漏的细节。例如，听说一只狗围着树追一只猫，若不想象狗是顺时针还是逆时针，脑中很难形成画面。听说一位年轻女孩与前总统里根拍照，若不想象女孩在总统的左边还是右边，也很难形成画面。这与心理学家所说的重建记忆有关：回忆时我们会补上当时并未注意的细节。原则上逻辑表达式可以不加额外细节就表示信息，但人们更倾向于用更具体的心理表征。有人会从视觉图像解释，认为我们在脑中想象视觉场景，而场景呈现了方向。然而正如第四章所述，视觉图像本身并非最适合常识推理的表现。也许更准确的说法是，真实或想象的场景会生成或连接世界模型，这些模型是对世界的类比，可以通过易处理的计算进行推理。

值得一提的是，逻辑与常识之间存在微妙联系。当我们说一个表达式可信时，指的是它能通过世界模型经 TEST 计算判定成立。因此存在两个概念：一种是可以直接表示在世界模型中的信息，其逻辑形式受限；另一种是可信的表达式，集合更大，可更自由使用逻辑运算符。需记住：一个可信的、逻辑复杂的表达式，一定有一个简单的世界模型支撑。例如，鲍勃的舞伴不是盖尔这个表达式之所以可信，只是因为世界模型里指定了鲍勃的舞伴，且恰好不是盖尔。

这种信念方式带来一个惊讶的结论：

如果表达式 P 可信，且 P 逻辑上蕴涵 Q，那么 Q 也可信。

这就是逻辑蕴涵的封闭性信念。但必须强调，这不意味着主体是逻辑全知，能够从 P 推导出所有被蕴涵内容。我们并未说主体能从 P 推导出相关内容；P 必须从世界模型开始。正确结论是：如果主体能从世界模型或生动表达式得出 P，那么也能从同一世界模型得出 Q。从外部看，P 到 Q 有逻辑联系，但并不要求常识主体自己看到这条联系。

## 某些混乱和局限性

本节认为，从世界模型得出结论是一种可行的常识推理形式，通常无需从表达式得出结论。但在表示与推理上，我们忽略了许多微妙之处，靠部分观察下结论。

先说推理。TEST 与 FIND-ALL 相对于不受限逻辑推理已相对容易，但在某些情况下对常识应用仍要求过高。

例如，涉及 5 个变量时，用 TEST 判断一个存在式是否成立，可能需要在含 1000 个常量的世界模型里搜索 10^15 个组合，才能找到一个成立的实例，即便每秒检查十亿个组合，也需要十多天。

缓解因素之一是，很少需要找 5 个相互关联变量的组合。常量多以成对或三元组出现，很少超过 3 个。另一个是 TEST 可以由下而上增量计算，例如表达式是一个合取且包含人 x 的朋友是人 y，则答案只需取世界模型中朋友属性对应的 x、y 值，无需检查全部 10^6 个组合。若表达式还包含仅涉及这两个变量的其他合取，检查量会进一步减少。若再有变量人 z 且合取为人 z 的兄弟是人 y，则答案只需取兄弟为人 y 的人 z，无需检查 10^9 个三元组。以此类推。这就是数据库合取查询评估的依据，在实践中即使对庞大数据库也很有效。

TEST 的另一个难题是递归。虽然可以通过 TEST 查看父母关系链，但工作量很大。我们能否保证 TEST 总能停止并给出最终答案？不能。具有递归定义的属性会导致 TEST 永久运行。缓解因素是，常识中递归只以有限方式使用，如传递闭包，可用专用机制处理。

数字也带来复杂性。TEST 可以判定无变量算术式成立，但不应期待它作为常识推理的一部分去评估含变量的算术式。例如除 2 外，是否有偶数不是两个质数之和？连专家也不知道。缓解因子是，当涉及变量时，把 TEST 与 FIND-ALL 限制为只查找世界模型中出现的常量。例如表达式 6 小于数 x 的 FIND-ALL 只返回模型中出现的大于 6 的有限数字，而不会尝试列举无限多个大于 6 的数。

序列也有同样问题，不能靠 FIND-ALL 定位实现目标的动作序列，除非世界模型中已有这些动作的常量。我们期待模型中已有被证明有用的行动表示。若动作非原始动作，会与一系列原始动作关联。FIND-ALL 应能定位记忆中的动作序列以便规划。根据基本原理构建全新序列要求过高，适合逻辑谜题，不适合常识。

再看表示问题。我们提出，基本知识应在世界模型中表示，而以表达式表达的信念应从模型中派生。这样就不用处理不完整知识，即缺少具体事物细节却涉及属性的情况。本章论述处理不完整知识需要解开逻辑变量，超出常识范围。

然而还有其他形式的不完整知识。例如一本推理小说有三名嫌疑人。世界模型中有三个常量代表嫌疑人及其事实。凶手确定后方案即告失败。某种意义上，这本小说也是一个谜题。我们承认，在找出凶手前可能需要处理无法提前得出的线索，与舞会例子相同。

尽管如此，在解开谜题前仍需推理凶手是谁。例如常识包括凶手出生在某地、有母亲、需要呼吸等，与其他两人无异。若必须等到找出凶手后才能得出结论，就无法深入理解小说。例如故事开头说凶手早餐吃了格兰诺拉麦片，就能得出凶手早餐吃了什么，而不必先弄清凶手是谁。

如何在世界模型中表示不完整知识？最直接的想法是使用第四个常量代表凶手，然后将凶手信息表示为一个人，并像对三名嫌疑人那样得出结论。

这会带来问题。首先，不能假设 L 表达式成立或不成立。例如，若第一个嫌疑人是人#92，凶手是未知人#17，则式子人#92 是人#17 不能仅因常量不同就判定为不成立。迄今为止这是惯例。在该虚构世界里有三个人，但有四个常量。因此显然应修改 TEST 操作。类似地，约翰的出生地点可表示为空间点#25，但我们并不知道该点是否不同于已知的波士顿其他空间点。

要理解复杂性，注意以下式子：

存在人 x，其中人 x 是一个人，且人 x 不是未知人#17。

即使无法指定四个常量之一替代人 x 使内层式子成立，该式子也应被判定为成立。因此等式与其他表达式上的 TEST 运作都需要改变。

现在考虑不完整知识。假设后院有几只狗，被告知它们是吉姆的狗。若已知有四只狗，就能构建模型并说明每一只是吉姆的狗。若狗的数量未知，如何表示所有狗都是吉姆的狗这一事实？似乎应该能处理这一事实，而不必列出每只狗。前面章节讨论过类似问题：

约翰地下室的所有油漆罐都被灰尘覆盖。

似乎应该能表示此信息，而不必识别单个油漆罐并说明其属性。在以下情况下更明显：

银河系中所有的恒星都比海王星大。

这涉及千亿颗恒星。

这也是不完整知识，存在逻辑谜题。以下示例改编自心理学家菲利普·约翰逊·莱尔德：

假设后院有几只狗，有两个事实：

1. 后院所有的狗都是吉姆的。
2. 后院没有小的狗。

那么哪种说法一定正确？

3. 有几只小的狗不是吉姆的。
4. 吉姆养的狗不小。
5. 吉姆养的狗没有一只是小的。

正确答案是 4。如前所述，不应期待仅凭常识就能从 1 和 2 得出这一结论。

这与第六章提出的问题相同：对于 1 这样基本事实，究竟该怎么处理？莱尔德提出了一种类似世界模型的表示，并加上额外功能，可用符号表示可能存在或不存在的假设物体。例如，用一些符号表示后院的狗，全部标记为吉姆的狗，用另一些符号表示吉姆拥有的其他物体，且这些物体不在后院。换言之，表示假设存在许多单个事物，生成一个或多个世界模型，根据模型得出包含全部、一些、没有等一般结论。这与如何处理鸟类会飞的一般问题有关。从推理角度看，该建议很有吸引力，尽管作为一般表示机制仍需研究。例如，如何避免根据世界模型得出关于存在或不存在物体的虚假结论？

在常识方面，处理不完整知识的另一种可能是，允许任意一般表达式作为知识库组成部分，仅用于得出肤浅结论，过于肤浅无法解开复杂谜题，但足够肤浅便于计算。对生动知识库，肤浅推理可能与 TEST 同功。对含 1 这样表达式的知识库，可能能得出明显结论，如后院所有棕色的狗都是吉姆的狗，但无法结合 2 这样其他事实得出 4 这样结论，至少需要额外思考。该建议需要进一步研究。

顺便说一句，人工智能知识表示与推理领域很大一部分研究涉及在逻辑和概率推理中寻找其他易处理信息，着眼于常识。换言之，除本书所述形式外，还有哪些具有逻辑和概率意义、可足够高效自动化运行、对庞大符号知识也有效的自动化推理形式？这与理论计算机科学中计算复杂性项目更广泛的努力相呼应，即理解何种原因使计算任务变得容易或困难。
