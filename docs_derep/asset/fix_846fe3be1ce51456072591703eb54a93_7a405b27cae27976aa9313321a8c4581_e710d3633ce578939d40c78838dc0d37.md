# 3.1 Transformer预训练语言模型原理

ChatGPT 的底座是在 Google 提出的原始 Transformer 上演化而来的变体。原始 Transformer 是一种基于自注意力机制的深度神经网络，相较 RNN，能高效并行处理序列数据，因而精度更高。

原始模型采用编码器-解码器结构，核心由编码器和解码器组成，结构示意如图3-1。编码器把输入序列映射为中间矩阵，解码器再把中间矩阵转为目标序列。两者均由自注意力层与前馈神经网络层构成。

自注意力层负责捕捉序列内部不同位置的关联，使模型能处理长距离依赖。前馈层对特征做非线性变换，提升网络表达能力。Softmax 把多分类输出归一化到0~1之间且总和为1，经 Softmax 映射即可得到下一个词的预测概率。

输出: I like playing football

输入：我喜欢踢足球

图3-1

编码器结构如图3-2所示，每个编码器包含一层多头自注意力与一层前馈神经网络，每层输出均会经过残差连接与归一化处理。

残差连接把原始输入矩阵 X 与经多头自注意力处理后的新矩阵相加，即 X+MultiHeadAttention(X)。残差连接是业界应对深层网络梯度爆炸或消失的常用手段，让网络只需学习残差，从而挖掘更深特征。归一化让每层神经元输入分布保持一致的均值方差，有助于加速收敛、提升建模效率。

前馈神经网络结构相对简单，通常由一个或多个线性与非线性变换构成，主要用于获得更丰富的特征。在原始 Transformer 中，前馈网络采用两层全连接，第一层线性变换使用 ReLU 激活，第二层线性变换不使用激活，示意如图3-4。经多头自注意力后再经前馈网络处理，可获得更丰富的语义信息，有效提升性能。

在原始 Transformer 基础上，NLP 领域逐渐形成三种构建预训练语言模型的常见方式。

(1) 仅含编码器的预训练语言模型，典型代表是 BERT。这类模型通常以掩码语言建模为预训练目标，预测被遮挡的词。基于双向编码，可同时利用上下文信息，全局可见性较好，因而广泛应用于自然语言理解。主要局限是难以进行可变长度文本生成，不适用于生成类任务。

(2) 仅含解码器的预训练语言模型，如 ChatGPT。思路是先构建具备较强泛化能力的模型，再针对下游任务做有针对性的微调，以获得良好迁移效果。缺点是基于解码器的架构一般采用单向自回归模式，信息是有序可见的，难以有效利用后续信息，因此更擅长文本生成。

(3) 同时包含编码器与解码器的预训练语言模型，如 BART。该类模型兼顾前两者的优点，既能保证信息的全局可见性，又能借鉴单向自回归模式，文本生成能力更强。

# 3.2 提示学习与指令微调

提示学习的核心是通过改写下游任务的输入，使其在形式上贴近指令训练集，从而挖掘更多信息、提升学习效果。换句话说，将下游任务输入按预训练格式重写，使其分布向预训练数据分布靠近，从而提高模型适应能力。下面以两个例子说明。

示例 A：情感判断。
文本：最近总下雨，只能在家待着。
提示：最近天气很好，可以出去玩，让人十分开心，最近总下雨，只能在家待着，让人十分____？

# 2. 第二个阶段：训练 RM

有监督微调使模型理解了指令含义，但尚未判断哪些回复更受用户青睐。需要让用户对同一指令下的多个回复进行完整排序，使模型学会区分高质量、逻辑合理、安全无害的回复。

具体做法是从指令集中随机抽样提问，基于第一阶段微调后的模型生成多个候选回复，再由人工按质量排序。使用 pairwise-loss 作为损失函数，该损失在推荐与排序任务中常见，每次取两样本组合评估先后顺序，累积得到整体排序。训练 RM 使用的人工标注数据约 2 万至 3 万条。训练好的 RM 可有效引导模型输出更符合用户偏好的结果。原理示意图如图 3-7 所示。
