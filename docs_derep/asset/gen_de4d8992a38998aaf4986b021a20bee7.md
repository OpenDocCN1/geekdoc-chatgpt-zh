# 从路径到指令：FDM 打印 G 代码生成全解析

在数控编程的世界里，G0 与 G1 是构建 FDM 打印轨迹的两大基石。前者是**快速定位指令**，负责驱动喷头在空运阶段以最高效率跨越空白区域，期间熔丝静止；后者则是**直线插补指令**，掌管喷头在挤出熔丝的同时，沿直线轨迹精准沉积材料。二者在调用时均需搭配速度参数（F）与目标坐标（X、Y、Z），而 G1 独有的 E 参数（进丝长度）则直接掌控着材料的吐出量。

### 指令的“记忆特性”与坐标模式

值得注意的是，G0 与 G1 均属于**模态指令**，这意味着它们拥有“记忆功能”。若当前行代码的某参数值与上一行保持一致，便可大胆省略，极大精简了代码体量。例如，连续两段打印速度、Z 高度不变时，第二行仅需更新变化的 X、Y 与 E 值即可。

坐标系的选择同样关键。G90（绝对编程）与 G91（相对编程）决定了坐标数值的解读方式。绝对模式下，坐标直指空间唯一位置；相对模式下，坐标则表示相对上一位置的位移增量。FDM 领域主流采用 G90 绝对坐标，逻辑直观，便于调试与回溯。

### 核心难点：E 值如何算得准？

喷头直径通常小于丝材直径，这导致“进丝长度”与“出丝长度”存在固定比例关系（公式 11-7）。既然 G1 累加的路径总长即为出丝长度，那么只需引入喷头与丝材截面积比值的平方（$nf^2$）作为换算系数，对路径长度进行累加换算，即可精准得出每一步所需的 E 值。这一逻辑，是切片软件“会打印”的数学基石。

### 代码层面的“翻译官”：pathToCode 函数

`pathToCode` 函数承担了将几何多段线“翻译”为标准 G 代码文本的重任。其逻辑清晰分为两步走：
1.  **起点跳转**：首个顶点使用 G0，搭配 `g0Speed` 快速就位，不挤出。
2.  **轨迹打印**：后续顶点依次使用 G1，按 `g1Speed` 移动，同时根据段长与 $nf^2$ 累加计算 E 值实现挤出。

函数设计巧妙之处在于：将累计进丝量 `e` 与换算系数 `nf2` 作为参数传入。前者保证了跨路径、跨层调用时挤出量的全局连续性；后者避免了重复计算，兼顾性能。

### 统筹全局的后处理流水线：postProcess

有了单条路径的转换能力，`postProcess` 便成了调度中心。它接收切片层序列 `layers` 与工艺参数 `pp`，按层循环，按既定优先级串联五类路径：
> **支撑轮廓 → 支撑填充 → 模型轮廓 → 密实填充 → 稀疏填充**

这种“先支撑后模型、由外向内”的策略，有效保障了悬空结构的成型成功率与壁面质量。每层开头自动插入层号注释，方便事后追踪；首尾分别拼接 `startCode` 与 `endCode`，完成打印机初始化与收尾动作（如回零、加热、关风扇）。

最终入口 `genNcCode` 仅两行代码：先生成路径，后转码输出。它是全书算法链条的终点，将几何建模、切片、填充、支撑等上游成果，最终汇聚为打印机可执行的文本流。

# 附录：Marlin 固件串口控制实战指南

为了让生成的 G 代码真正“动”起来，我们必须跨越上位机与下位机的通信鸿沟。Marlin 作为 FDM 领域最主流的开源固件，其串口交互协议遵循严格的**“发送-应答”同步机制**。

### 通信协议核心规则
- **指令终止**：每条指令必须以 `\n` 结尾。
- **缓冲限制**：控制器缓冲区极小（仅几百字节），不可一次性倾倒全量代码。
- **握手同步**：上位机发送指令后，**必须阻塞等待**下位机返回 `ok` 字符串，方可发送下一条。`\n` 与 `ok` 的数量始终严格对等。

### Python 上位机控制核心流程

```python
import serial

def wait_for_ok(ser):
    """阻塞读取串口，直到捕获 'ok' 才返回"""
    while True:
        line = ser.readline()
        print(line)  # 调试用：监控下位机反馈
        if b'ok' in line:
            break

if __name__ == '__main__':
    # 1. 建立串口连接（端口号、波特率需与硬件匹配）
    conn = serial.Serial("COM3", 115200)
    
    # 2. 等待固件启动就绪信号
    wait_for_ok(conn)
    
    # 3. 发送回零指令（打印前必做）
    conn.write(b"G28\n")
    wait_for_ok(conn)
    
    # 后续即可循环读取 G 代码文件逐行发送...
```

此流程为自动化打印、远程监控、闭环控制奠定了通信基石。掌握它，你就掌握了让代码驾驭机械的“神经中枢”。
