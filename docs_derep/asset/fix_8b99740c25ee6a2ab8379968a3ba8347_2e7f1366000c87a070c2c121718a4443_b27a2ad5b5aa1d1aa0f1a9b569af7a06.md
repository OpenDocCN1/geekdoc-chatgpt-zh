WEEKDAY（指定日期，返回值类型）
第二参数为 1 或省略时，1~7 代表星期日到星期六；为 2 时，1~7 代表星期一到星期日；为 3 时，0~6 代表星期一到星期日。

=IF(WEEKDAY(C3,2)>=6," 公休日"," 平常日") 解析：内层 WEEKDAY 计算星期数，外层 IF 判断是否大于等于 6，是则返回“公休日”，否则返回“平常日”。
