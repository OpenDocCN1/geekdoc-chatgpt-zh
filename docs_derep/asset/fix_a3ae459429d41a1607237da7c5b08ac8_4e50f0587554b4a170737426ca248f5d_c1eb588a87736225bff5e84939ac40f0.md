#### 2.3.5 第三方部署工具概览

在本地部署大模型时，除了直接用 Transformers 等基础库加载权重，还可选择工程化程度更高的第三方工具。这类工具在加载优化、推理加速、服务化封装、多模型托管等方面优势明显，特别适合对性能、可维护性、并发能力要求较高的企业级或产品级场景。

##### 1. SGLang：智谱发布的 GLM 系列推理框架

SGLang 由智谱 AI 发布，是专为 GLM 系列模型如 GLM-4、ChatGLM 设计的开源推理与服务框架，原生支持对话模板、多轮历史缓存、函数调用、结构化输出等能力。

SGLang 的核心特点如下。

- 与 GLM 结构高度适配，支持 multi-turn memory。
- 支持并发调度与动态上下文构建。
- 内置类 OpenAI 的 API 接口。
- 可结合 fastapi/uvicorn 快速部署服务。

##### 2. LMDeploy：国产模型的轻量部署方案

LMDeploy 由昆仑芯与魔搭社区联合开发，目标是为国产开源大模型提供统一、简洁、高性能的部署方案。支持 INT4/INT8/FP16 多精度推理，并集成一键脚本、服务启动、QPS 压测等功能。

LMDeploy 的核心特点如下。

- 支持 Qwen、Baichuan、InternLM 等众多国产模型。
- 原生适配 INT4 推理，显存需求低。
- 提供完整的 CLI、Web UI、HTTP API。
- 支持多线程调度与批量推理。

##### 3. vLLM：高并发 OpenAI 兼容引擎

vLLM 由 UC Berkeley 发布的高性能推理引擎，支持动态批量调度、连续批处理、FlashAttention 2，并实现了完全兼容 OpenAI API 协议的服务接口。

vLLM 的核心特点如下。

- 支持 Hugging Face 格式模型如 LLaMA、Qwen、Baichuan 等。
- 实现高吞吐推理，可达数千 token/s。
- 支持流式输出。
- 原生兼容 chat/completions 接口格式。

##### 4. Ollama：一键本地部署平台

Ollama 面向开发者，提供轻量本地部署能力，支持下载、管理、运行 GGUF 格式大模型如 LLaMA 2/3、Mistral、Qwen、Phi 等，目标是让本地部署像用 Docker 一样简单。

Ollama 的核心特点如下。

- 自动下载并注册模型，无需显式管理权重。
- 支持 Mac/Windows/Linux 系统。
