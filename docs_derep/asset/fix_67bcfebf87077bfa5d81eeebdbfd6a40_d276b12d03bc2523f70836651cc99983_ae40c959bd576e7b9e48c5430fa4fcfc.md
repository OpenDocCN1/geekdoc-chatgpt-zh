✓ 画面要活。跟拍、推拉等运动镜头配合面部/细节特写是基本盘，减少像相册封面那样一动不动的静止帧，平台分发更偏爱有节奏感的动态表达。

## 四、颜色要亮 信息要快 手机屏更吃香

（1）呈现方式
- ✓ 色彩和构图：整体饱和偏高，比如火锅红油的浓红、灯笼的暖红、熊猫黑白的高对比，在小屏上冲击更强。字幕用黄白粗体加黑描边，强光弱光下都能快速辨认。
- ✓ 信息直给：每段画面只承载一句要点，如“白天去春熙路逛”“吃一顿地道的川味火锅”，把理解成本降到最低。

（2）可参考点
- ✓ 字幕即卖点：字幕本身就要完整成句，即使用户静音也能获取关键信息，抖音上约三成用户习惯静音浏览。
- ✓ 统一色调：旅游类作品建议主打暖色系，比如成都的红与黄，用色传递热情与烟火氛围。

## 五、评论私信双引流 撬动算法推荐

（1）呈现方式
- ✓ 评论区钩子：结尾引导“把你的出行时间和同行人数留在评论区”，以“免费定制行程”作利益点刺激留言，评论量过千更容易触发二次推荐。
- ✓ 搜索词布局：标题里埋“成都旅游”“三日攻略”等高频词，字幕里反复出现“宽窄巷子”“春熙路”等地名，提高搜索曝光。

（2）可参考点
- ✓ 关键词埋点：把核心词“成都攻略”放在开场前三秒、中段、结尾，契合平台的搜索分发机制。

## 六、价值交付 既解效率焦虑又给情绪价值

（1）呈现方式
- ✓ 实用价值：围绕“不走冤枉路”“上手即抄”“直接照搬”等表达，直击怕踩坑、怕浪费时间的核心焦虑。
- ✓ 情绪价值：以“沸腾的火锅”“卖萌的熊猫”“挂灯笼的老街”等画面释放烟火气与治愈感，激发向往。

（2）可参考点
- ✓ 旅行内容公式：干货攻略解决痛点 + 画面文案制造共鸣 + 本地人身份增强可信度。
  - 例：博主着汉服开口“我来自××”，强化本地向导人设，提升信任。

（3）高曝光原因与总结
- ✓ 算法友好：结构清晰节奏快完播率高，评论指令明确互动率高，标题字幕重复关键词搜索更精准，三者共同推动进流量池。
- ✓ 痛点精准：用“省时攻略”“路线直达”直击旅游用户焦虑，内容具备强收藏转发价值，收藏在算法中权重很高。
- ✓ 生态适配：短视频形态 + 网感语言 + 视觉符号，贴合短视频平台碎片化、情绪化、强互动的特点。

（4）实操建议
- ✓ 视频开头三秒必须给出用户收益，例如“这样玩能省两小时”。
- ✓ 每十五秒植入一次互动指令，例如“点赞收藏，旅行不迷路”。
- ✓ 拍摄前先梳理三个城市专属符号，如成都的熊猫、火锅、老街，确保差异化。

拆解的目的是学逻辑和运营手法而非照搬，结合自身定位和风格创新才是关键。千问可作快速提炼辅助，节省拆解时间，但最终创作仍需创作者的思考与个性表达，才能形成独特风格并实现账号长效运营。持续关注同圈层爆款并定期拆解，能把握最新趋势，不断优化内容。把拆解结果整理成笔记便于复用，进一步提升创作效率与质量。

## 6.4 撰写爆款文案

上一节讲了如何借助千问拆解同类爆款并提炼规律，本节聚焦微信公众号、小红书、抖音等主流平台，说明如何用千问产出可直接落地的爆款文案，并给出提示词范例与实操方法。

千问的写作逻辑是依托语义理解与生成能力，把创作需求转成精准优质的文案。提示词建议遵循“人物定位+情景背景+创作目的+交付标准”的结构，确保方向清晰、贴合平台、满足需求。其中人物定位明确身份与风格，情景背景说明平台特性、受众与基础，创作目的锁定用途与预期效果，交付标准界定形式、字数、结构等细节。

### 6.4.1 公众号职场类文案撰写

公众号职场爆款的特点是精准击中人群痛点，提供可落地的实用价值，结构清晰、语言专业简洁，易引发共鸣与传播。

明确受众细分后，可借助千问把拆解结果转为创作思路。示例提示词如下：

> 人物定位：公众号职场文案撰写专家，拥有十年人媒体运营经验，熟悉公众号职场爆款创作逻辑，擅长结合真实职场场景写出简洁务实、具感染力的文案，语言专业不晦涩，突出实用性与共鸣，避免堆砌术语。
> 
> 情景背景：文案用于职场账号，定位为职场新人成长导师，平台以深度图文为主，受众为入职一到三年的职场新人，痛点包括适应困难、技能不足、沟通欠缺、职业规划模糊等，需要接地气的成长建议。已上传职场爆款拆解结果，需借鉴其选题逻辑、结构、风格与共鸣点。
> 
> 创作目的：撰写一篇公众号职场爆款文章，聚焦职场新人“沟通能力不足”痛点，围绕“职场新人高效沟通技巧”展开，既传递可落地方法，又引发情感共鸣，提升打开率、点赞率、收藏率与转发率。
> 
> 交付标准：字数控制在1500字以内，适合碎片化阅读，借鉴拆解逻辑，避免抄袭，结合新人实际需求优化内容，确保实用与可读。

输入后可快速获得初稿，选题聚焦高频痛点，结构采用清晰三段式，风格兼顾专业与接地气，内容搭配真实案例与实用技巧。具体初稿示例围绕“话别乱说、事别乱应、人别乱怼”展开，分别讲明开口前思考、承诺前评估、情绪上来先冷静，并给出职场沟通铁律与高情商沟通公式，结尾引导评论互动。

初稿生成后可继续优化：标题生成三到五个备选提升打开率，案例替换为更贴近新人真实场景的情节增强代入感，补充具体话术模板提升收藏转发价值。

### 6.4.2 小红书图文设计

小红书是月活数亿的消费决策社区，美食是热门赛道，爆款图文重视觉呈现与实用分享，内容真实、易引发尝试欲与互动。

示例提示词如下：

> 人物定位：小红书美食图文设计专家，熟悉平台特性与美食类爆款逻辑，擅长撰写真实接地气、实用性强的文案，并提供清晰的图片设计建议，风格贴合用户偏好，注重视觉与文字的协调。
> 
> 情景背景：用于美食账号，定位新手家常美食分享者，受众为二十到三十五岁年轻女性，以一线新一线城市为主，需求为简单易做、耗时短、颜值高、食材常见的家常菜。已上传美食爆款拆解结果，需借鉴标题设计、图文搭配、文案逻辑、标签运用要点。
