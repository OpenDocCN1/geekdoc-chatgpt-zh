皮尔逊相关系数也就是相关分析中常用的 r，用来刻画两个定距变量之间线性联系的强弱，其数值限定在 -1 到 1 之间。r 的绝对值越大，意味着用一个变量去估计另一个变量时的精度越高，因为两者共享的变异比例越大，由一个变量的变化就能推断出更多关于另一个变量的变化信息。当 r 等于 1 或 -1 时，两变量呈完全线性关系，x 的取值足以唯一确定 y。若 r 为 0，则两者不存在线性关联。正相关表现为 x 增大时 y 随之增大，r 位于 0.00 至 1.00 之间；负相关表现为 x 增大时 y 减小，r 位于 -1.00 至 0.00 之间。绝对值越靠近 1，相关越强；越靠近 0，相关越弱。计算公式见式（3-6）。

distance(x_i, x_j) = [E(x_i x_j) - E(x_i)E(x_j)] / [ sqrt(E(x_i^2) - (E(x_i))^2) sqrt(E(x_j^2) - (E(x_j))^2) ] = cov(x_i, x_j) / (σ_{x_i} σ_{x_j})  (3-6)

式中，E(x_i) 表示向量 x_i 的数学期望值；σ_{x_i} 表示向量 x_i 的标准差；σ_{x_j} 表示向量 x_j 的标准差；cov(x_i, x_j) 表示向量 x_i, x_j 的协方差。

### 7. 杰卡德相似系数（Jaccard similarity coefficient）

杰卡德相似系数适用于符号度量或布尔度量数据的相似比较，核心在于判断两个对象共同具备的属性是否一致。设集合 A 与集合 B，其计算方式见式（3-7）。

distance(A, B) = |A ∩ B| / |A ∪ B|  (3-7)

### 8. 马氏距离（Mahalanobis distance）

马氏距离反映协方差意义上的距离，能够在消除量纲影响的同时体现特征之间的相关性，常用作两组未知样本的相似度评估。与欧氏距离相比它具有尺度无关性。$x_i = (x_i^{(1)}, x_i^{(2)}, \dots, x_i^{(n)})^T$，均值为 $\mu_i = (\mu_i^{(1)}, \mu_i^{(2)}, \dots, \mu_i^{(n)})^T$，协方差矩阵为 $S$，则计算公式见式（3-8）。

distance($x_i$) = $\sqrt{(x_i - \mu_i)^T S^{-1} (x_i - \mu_i)}$

(3-8)

## 3.3 搜索优化方法

3.1 节指出，当样本量和特征维度都较大时，K-近邻的距离计算负担会明显上升。实际上邻居查找过程本身的开销也不小。为提升检索效率，可借助专门的数据结构存储训练样本，从而减少不必要的距离计算。下面介绍两种常见做法。

### 3.3.1 k-d 树

k-d 树是针对暴力搜索效率不佳而提出的一种树形结构。其基本思想是：如果 A 距 B 很远而 B 距 C 很近，那么 A 与 C 很可能也很远，无需精确求距。对 k 维特征、n 个样本的数据，近邻搜索的开销可降至 $O[k n \log(n)]$ 以内，在大数据集上效果显著。

k-d 树是每个节点都保存 k 维点的二叉树，每个节点对应一个与当前切分维度垂直的超平面，将空间分为左右两部分。若当前节点的切分维度为 F，则左子树中所有点的 F 维坐标小于该节点，右子树则大于等于该节点。构建时不需计算距离，只需按轴划分，速度很快。构建完成后，查询的复杂度约为 $O[\log(n)]$。在低维情形下非常高效，但维度 k 很大时性能会下降。

以下用一个直观例子说明。

假设数据有 2 个特征、6 个样本，$T = \{(2,3),(5,4),(9,6),(4,7),(8,1),(7,2)\}$，可视为二维平面上的点。k-d 树的任务是确定这些点的空间分割线。

先选切分维度。分别计算 X 轴和 Y 轴方向的方差，X 轴方差更大，先按 X 轴划分。

再确定分割线的 X 坐标。X 特征取值 2、5、9、4、8、7，中位数为 6.5，最接近的是 $(7,2)$。于是分割线取 $x=7$，即过 $(7,2)$ 且垂直于 X 轴的直线。

划分左右子空间。$x\le7$ 为左子空间，包含 $\{(2,3),(5,4),(4,7)\}$；右子空间包含 $\{(9,6),(8,1)\}$。

随后按 Y 轴划分。左子空间纵坐标 3、4、7，中位数为 4，切分点为 $(5,4)$；右子空间仅 2 个样本，随机取 $(9,6)$ 作为切分点。

k-d 树的构建可总结为：

- 1) 构造根节点，使其对应包含全部样本的 k 维超矩形区域。
- 2) 递归地对 k 维空间切分生成子节点。在当前超矩形上选择一个坐标轴和该轴上的一个分割点，确定一个垂直于该轴的超平面，将当前区域分为左右两个子区域，样本随之归属。
- 3) 重复切分直到子区域内无样本为止，终止时为叶节点。过程中把样本保存在对应节点上。
- 4) 通常按坐标轴轮流切分，例如 3 维数据根节点用 X 轴，子节点用 Y 轴，孙节点用 Z 轴，依次类推，并取中位数作为分割点，这样得到的树是平衡二叉树。

[PRE2]

k-d 树每个节点是一个向量，与普通二叉树按数值大小划分不同，k-d 树每层需指定一个维度，按左小右大的规则划分。构建时涉及两个关键问题：

- 1) 选择哪一维进行划分。
- 2) 如何进行划分。

简单做法可随机或顺序选取，更优的做法是在数据离散程度较大的维度上划分，离散程度可用方差衡量。合理的划分能使树更平衡，常用中位数划分，这样第二个问题也得到解决。

构建完成后，介绍如何用 k-d 树进行最近邻搜索。总体思路是维护一个当前全局最佳点和全局最短距离，从根节点开始按树的生成规则递归遍历。若当前节点到查询点 Q 的距离更小，则更新最佳点和最短距离；若 Q 到当前节点切分维度的距离小于当前最短距离，则另一子树中可能存在更近的点，需继续探索。具体步骤如下：

- 1）初始化全局最佳点为空、全局最短距离为无穷大，用来保存离 Q 最近的点及其距离。
- 2）从根节点开始，将其设为当前节点。
- 3）若当前节点为空，则结束。
- 4）若当前节点到 Q 的距离小于全局最短距离，则更新全局最佳点和最短距离。
- 5）若 Q 在切分维度上的值小于当前节点的值，则进入左子节点，否则进入右子节点，继续执行 3）、4）、5）、6）。
- 6）若 Q 到当前节点对应分割线的距离小于全局最短距离，则可能在另一子树中存在更近的点，切换到另外的子节点继续执行 3）、4）、5）、6）。

递归结束后，全局最佳点即为最近邻。

在 K-近邻中，搜索流程类似，只是需要维护一个大小为 K 的有序候选列表，首位为当前最近，其余按距离升序排列。

当维度极高时，k-d 树效率会下降。一般规律是，只有当样本数远大于 $2^k$ 时，k-d 树才明显优于全量扫描。

### 3.3.2 球树

k-d 树在非均匀分布和高维数据上仍可能低效，于是提出了球树。

k-d 树沿坐标轴切分，球树则用一系列超球体划分空间。虽然构建成本更高，但在高维场景下表现更稳定。球树将数据递归划分为由质心 c 和半径 r 定义的节点，每个节点代表一个包含若干样本的空间，中心点可以是样本点或该空间的质心，并记录该节点内所有样本到中心的í最大距离。

构造方式与 k-d 树类似，首先找到包含全部数据的超球体，球心作为根节点，或直接以使样本到质心距离和最小的点为根。然后递归：

- 1) 选距离质心最远的点作为左观测点，再选离它最远的点作为右观测点，或直接取最远的一对点作为左右子节点。
- 2) 把样本分配到距离最近的观测点所属类中。
- 3) 记录质心位置和包含该节点的最小半径。
- 4) 对每个子节点重复上述过程。
