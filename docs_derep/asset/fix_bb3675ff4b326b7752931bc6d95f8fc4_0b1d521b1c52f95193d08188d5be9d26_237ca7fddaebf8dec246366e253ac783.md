在真实的对话与决策里，逆着思路提问往往比顺着思路追问更能把关键点逼出来。

对比思考模式
我们的打法与竞争方的打法到底有何不同？在哪些维度我们更占优，哪些维度我们吃亏？这些得失该如何取舍和平衡？

反转思考模式
如果双方的位置互换，我们的谈判策略需要怎样调整？站在对手角度会暴露出哪些风险或机会？

对立观点模式
假设对方给出截然不同的诉求或看法，我们该怎样回应与反驳？能够用来支撑立场的论据和策略有哪些？

反问模式
这个条件对我们而言真的算公平吗？

# 3. 用 AI 找准科技创新突破口
研发和产品创新经常卡在盲区里，借助逆向提问可以把问题拆得更细、看得更全，也更快找到新解法。

反面思考模式
假如这项技术最终失败，推手的因素可能有哪些？要怎样提前规避这些风险点？

反向思考模式
如果想靠逆向工程来造一个同类产品，会遇到哪些难点？背后需要攻克哪些技术关卡？

对比思考模式
这项技术与市场上已有的方案相比强在何处弱在何处？如何塑造差异化优势来赢得竞争？

反转思考模式
如果研发预算为零，还能怎样把这项技术做出来？有哪些替代路径或资源可以借助？

对立观点模式
有人担忧这项技术会对环境产生负面影响，支持这种说法的依据是什么？能采取哪些措施来降低负面效应？

反问模式

# 注意事项
+ 1. 使用逆向提问时，最好先给模型足够的背景情境，让它能兼顾更多变量和场景。
+ 2. 可以同时从多个角度设置逆向问题，帮助模型更立体地探索问题。
+ 3. 提问者要把自己的观点表达清楚，意图越明确，得到的回答越精准。

# 15 归纳提问：把信息快速分类
日常里错过例会想补全信息，怎样问下属效率最高？

提问一：小王，今天会上了啥？
这种问法通常会得到流水账复述：先是市场部李经理讲……接着销售部刘主管说……最后研发部王主任……

提问二：小王，今天会上市场部、销售部、研发部各自本周重点是什么？月底大促最终定了哪个方案？我们部门有没有新增待跟进事项？
这样问，下属会主动把繁杂内容分门别类，筛掉噪音，只把你关心的要点提炼出来，沟通更清晰高效。

这里的小王相当于模型，掌握归纳提问就能拿到想要的答案。

归纳提问和摘要提问有什么区别？

| 归纳提问 | 摘要提问 |
| --- | --- |
| 从相关事实中提炼共性规律，归纳出新认知和结论 | 从长文本里抽取核心信息，在原有信息上做提炼概括 |
| 涉及分类、归纳、概括等思维加工 | 侧重筛选和总结能力 |
| 多用于逻辑推理、思维训练等场景 | 多用于文本摘要、信息检索等任务 |

举例说明
| 归纳提问 | 摘要提问 |
| --- | --- |

核心思路是通过反馈不断改进答案，得到更优解。

例如写诗的迭代过程

这首比前一首更有创意和感情，因为用了想象手法，把自己化作柳枝与心爱的人共舞，表达了对春天和爱情的向往。

这首更深刻更有哲理，用对比手法把春光美好与人生虚幻对照，表达对生命和时间流逝的感慨。

+ ④ 重复②③，直到满意或无法再改进
