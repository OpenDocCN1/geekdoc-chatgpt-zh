> **ID3 决策树算法概述**

ID3 即迭代二分器 3，是早期经典的决策树方法，主要用于分类任务。它借助信息熵衡量数据集划分的纯度，并挑选信息增益最大的属性进行节点分裂，递归构建树以完成分类 [Data: Entities (0); Reports (0); Relationships (0)].

**熵与增益的计算**

ID3 用信息熵评估数据的混乱程度，熵值越低代表纯度越高。信息增益则为分裂前后熵值的差，用来衡量属性对划分的贡献。算法每一步都选择增益最大的属性进行分裂，逐步形成决策树 [Data: Entities (0); Reports (0); Relationships (27)].

**划分方式与离散特征处理**

ID3 仅能处理离散变量，连续变量需先离散化例如分箱。它采用一次展开一列的方式对数据进行划分，这与 CART 寻找最优切分点的策略不同。以 AGE 列为例，ID3 会按不同取值把数据拆分为多个子集，再计算各子集的熵与增益 [Data: Sources (0, 1); Entities (6, 7, 8, 9); Relationships (10, 11, 12, 13)].

**算法局限性**

尽管在发展史上地位重要，ID3 仍存在以下不足：

1. 不支持连续变量：连续特征必须先离散化才能使用 [Data: Entities (0); Reports (0)].
2. 易偏向多取值属性：在挑选分裂属性时倾向选择取值较多的特征，可能导致过拟合 [Data: Sources (1); Entities (0)].
3. 缺少剪枝机制：没有内置剪枝，过拟合风险较高，训练集表现好而测试集可能下降 [Data: Sources (1); Entities (0)].

**与 C4.5、CART 的关系**

ID3 是后续算法的基础。C4.5 在此基础上加入了连续变量处理、剪枝以及信息值等改进；CART 则同时支持分类与回归，采用二分策略划分数据 [Data: Entities (1, 2); Relationships (0, 1, 4, 14)].

**小结**

ID3 通过熵与增益构建分类模型，其核心思想为决策树发展奠定基础。C4.5 和 CART 等后续工作在此之上做了优化，提升了模型的性能与适用范围 [Data: Entities (0, 1, 2); Reports (0, 1); Relationships (0, 1, 4, 14)].
