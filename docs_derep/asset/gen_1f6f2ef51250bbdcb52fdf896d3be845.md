它到底值不值得讨论，不在于改了几次名字，而在于它验证了一个判断：AI 不必困在聊天窗口里当嘴巴，它完全可以变成能干活、能自己思考、能持续学习的数字员工。

不用写代码，不必订阅动辄上万的企业版，也不用把隐私数据喂给大厂。你只要在自己的电脑上装好 OpenClaw，配好相关技能，它就能上手做事：

● 每天自动整理邮箱，把真正重要的邮件筛出来给你看
● 盯着你关心的信源，按时推送精简摘要
● 帮你管日程，会前提醒、会后自动整理纪要
● 写代码、跑测试、完成部署上线
● 控制智能家居和各类机器人

它像一个从不睡觉的助手，用得越多，它对你的理解就越深。

这就是 OpenClaw 的来龙去脉。接下来会讲怎么把这只“龙虾”养起来，让它真正成为你的数字员工。

**龙虾外号从何而来？**

社区给它起了昵称 Molty，萌萌的，像叫宠物。中国用户叫“龙虾”或“虾总”，日本用户叫“エビちゃん”，德国用户叫“Krebs”。还有个“Crab Cult 蟹教徒”的梗，最早是 Reddit 上有人开玩笑说 OpenClaw 用户像个神秘组织，见面暗号是“Are you a crab？”。这个梗越传越广，线下聚会有人穿龙虾图案的衣服，Discord 服务器里龙虾表情包满天飞。

2026 年 2 月，首届 ClawCon 在旧金山举办，超过 2000 人到场，现场售卖的“I’m raising a lobster”T 恤 3 小时就卖空。维也纳的技术社区甚至把 OpenClaw 的龙虾图标印在了社区旗帜上。

一个工具软件为何能形成如此强的认同？因为“养虾”这个说法太形象了。安装、配置、教它干活，用得越久它越懂你，就像养一只宠物，而且这只宠物 24 小时在线，还能帮你赚钱。这种拟人感让 OpenClaw 从冰冷的软件变成了有温度的伙伴。

## 1.2 OpenClaw 的三大核心能力：从会聊到会干

前面提到 OpenClaw 与传统 AI 的差异，这些差异是怎么实现的？为什么 ChatGPT 做不到的事它能做到？答案就藏在三种核心能力里。

**核心能力一：会用电脑**

传统 AI 困在封闭的对话框里。你问它，它只能回文字，看不到屏幕，打不开浏览器，触不到文件，也点不了鼠标。

OpenClaw 能真正“用”电脑：

● 直接操控浏览器：打开页面、点图标、填表单、截图、下载
● 操作终端：执行命令、跑脚本、查日志
● 管理文件：读写文档、整理目录、解压打包
● 调用 API：连 Gmail、QQ 邮箱、Google Calendar、GitHub、即梦等任意有接口的服务

这背后的意义很大。让传统 AI 查网站价格，它只能回一句“无法访问网页”。OpenClaw 会自己打开网站、定位价格、读出数字并告诉你。让它把数据做成图表，传统 AI 只会给段代码，OpenClaw 会直接运行、生成图表并保存发送。

技术基础是 Anthropic 在 2024 年 10 月发布的 Computer Use API，Claude 能通过它控制电脑，OpenClaw 把这项能力开源、本地化，让普通人也能用上。这就是它能“干活”的原因——不是在框里说话，而是在替你操作电脑。

**核心能力二：有长期记忆**

传统 AI 的记忆很短。今天告诉 DeepSeek“我最喜欢 Python”，过几天再问它可能就忘了。对话结束就失忆，即便有历史记录，本质也是把上下文硬塞进去，没有真正的长期记忆。

OpenClaw 有两层记忆：

**第一层：SOUL.md 魂文件**
这是它对你的永久认知，手动配置，长期有效。比如你的名字、职业、工作习惯、代码偏好、常用工具、沟通方式等。每次推理都会先注入这个文件作为系统提示。

**第二层：MEMORY.md 记忆文件**
使用过程中自动积累的事实。比如老板邮箱、每周一的团队会、关注的股票代码、常去的网站、处理邮件的习惯。第一次你说“发邮件给老板”，它会问邮箱，你告诉它后记在 MEMORY.md，下次直接就发。周一你说“帮我准备明天的会”，它会记住“团队周会”，之后每周一早上主动提醒。

这种记忆让 OpenClaw 越用越熟练，第一天像新手助理，一个月后比你更懂你的工作流。更重要的是，全部存在本地，可随时查看、修改、删除。

**核心能力三：会主动行动**

传统 AI 被动，你不问它不说。OpenClaw 能主动。

它依赖三种机制：

**定时任务 Cron Jobs**
一次设定，持续执行。比如每天 8 点推送当日日程、每周一下午 3 点抓行业新闻、每小时检查股价、每天 23 点备份文件。

**事件触发 Event Triggers**
条件满足就行动。比如收到含“紧急”的邮件立刻推送、股价跌超 5% 发送预警、GitHub 有新 issue 自动回复并打标签、日历出现冲突立刻提醒。

**心跳机制 Heartbeat**
默认每 30 分钟自动唤醒一次，读取 HEARTBEAT.md 清单，做一次轻量推理，判断是否需要处理。没事就返回“HEARTBEAT_OK”，有事就主动推送或执行小任务。

# Heartbeat checklist
- 检查收件箱是否有紧急邮件，关键词包括紧急/老板/会议
- 查看未来 2 小时日历是否有冲突或即将开始的事件
- 若有后台任务完成，汇总结果并询问是否需要报告
- 若你已闲置 8 小时以上，发一条轻提醒：“最近忙吗？需要我帮忙做什么？”

这让它从工具变成助理。工具只在你用时工作，助理一直在盯着。

有用户让它监控 Hacker News，只要 AI 智能体话题上首页就推送到 Telegram。凌晨 3 点有个热帖被推送，他第一时间参与讨论，评论被顶上后个人网站流量当天涨了 10 倍。传统 AI 你只能自己刷网页，很容易错过深夜讨论。

**数字员工：三种能力的合体**

单独看，每项都不复杂：操作电脑是 API 与自动化、有记忆是本地文件存储、主动行动是定时与触发。但三者合起来就产生质变。

早上 8 点它会主动推送今日 3 个会议并附上准备资料，提醒 2 封紧急邮件，其余 47 封已归类，还把 AI 行业新闻摘要发到 Notion。

工作中你随口说“查一下竞品 A 最新价格”，它打开网站、提取价格、对比历史，告诉你已降价 5% 至 299 元。

下午 3 点推送：“你关注的英伟达跌了 6%，主要是……要不要设止损提醒？”

晚上 10 点自动完成备份、归档邮件、更新待办、生成工作总结。你一条指令都没发，它已完成十几件事。

它能处理的范畴覆盖重复性、规则性工作：

**信息管理类** 清理邮箱、监控信源、抓取文章并归档到 Notion
**日程协作类** 冲突检测、会前准备、自动纪要、任务跟踪
**开发工作类** 写代码、测试、CI/CD 部署、Bug 修复并提 PR
**内容创作类** 定期发布、翻译本地化、生成数据可视化
**商业运营类** 客服自动回复、监控股价流量竞品、自动化营销

这不是设想，是真实用户在用。AI 范式正在转变：从传统 AI 的“你问它答、一次性交互”到 OpenClaw 的“你设规则、它持续执行、长期协作”。前者让你更聪明，后者让你更高效。这也是为什么有人说 OpenClaw 可能动摇自己的 PDF 帝国——下一阶段的 AI 不是更大的模型，而是更有用的代理。

## 1.3 OpenClaw 的底层架构：越用越像老搭档的原因

操作电脑、长期记忆、主动行动并不是凭空而来，背后是一套让系统既像精密机器又像慢慢成长的数字生命的架构。整体可拆成 Gateway、Skills、Memory、Agent Brain 四部分，形成闭环：下指令→中枢分发→技能执行→记忆更新→反思改进→下次更好。

**Gateway：大脑指挥部**

Gateway 是控制中枢，WebSocket 服务器默认监听 127.0.0.1:18789。你在 Telegram、微信、飞书、iMessage、WhatsApp 等任意支持的 App 里 @ 它，消息会实时推送到这里。

收到指令后它会解析意图、路由到合适的 Agent 或 Skills，并把结果实时推回，支持 Markdown、图片、PDF、Excel 等附件。

它支持多通道并行，每个通道有独立 Session，不会混淆。就像公司前台加总机，知道该转给谁、优先级如何、怎么回复最合适。

**Skills：工具箱**

Skills 是能直接干活的模块库。官方 ClawHub https://clawhub.ai 上有上万个现成技能，已做安全扫描和社区审核，可一键安装：天气查询、股票监控、邮件总结、网页爬取、GitHub 操作、Notion 同步等。

更强的是可自写。写一个 Skill 就是一个文件夹，包含 Prompt 模板和执行逻辑的 Python 或 Shell 脚本，放进 ~/.openclaw/skills/ 目录，Gateway 会自动加载。Skill 还能递归调用其他 Skill，形成链条，比如写周报会串联会议纪要、邮件归档、代码提交记录再合成报告。

**Memory：让你被记住**

记忆全存本地 Markdown，可随时打开编辑。

● SOUL.md 人格核心，一次配置长期有效，写入职业、偏好、禁忌、沟通风格
● MEMORY.md 事实记忆，自动追加，可手动编辑
● 日志层加可选的 LanceDB 向量库，增强长程语义检索

你说“我讨厌长邮件”，它会记下，下次自动用简洁模板。你常问周一重点任务，一个月后它会周日晚上主动推送本周前五大任务并问是否调整。

**Agent Brain：自生长循环**

每次任务完成后会进行反思：成功吗？卡在哪？用户反馈如何？是否可优化？

基于反思它会自动更新 MEMORY.md、热更新 Prompt、生成新 Skill 草稿供你审核、尝试自我修复 Bug。社区常说第一周你在教它，第二周它开始帮你想，第三周它开始优化自己。不是模型参数变大，而是行为、记忆、技能在持续迭代，像养宠物一样越养越贴心。

Gateway 负责听与分发，Skills 负责干活，Memory 负责记住，Agent Brain 负责反思进化。四者闭环，让 OpenClaw 从工具变成伙伴。
