# API 借力术：ChatGPT 调用入门与实战

API，Application Programming Interface 的简称，本质上是一套让不同软件组件能够互相对话的规范、规则与工具集。它的作用是让开发者可以调用某个系统或应用已有的功能，而不必去翻阅底层源码，也不用理解内部实现细节。这样就能把精力集中在自家产品的创新点上，而不是重复造轮子。

举个常见场景，地图类应用要展示实时天气，通常不会自己搭气象站。它会直接调取天气预报服务或国家天文台提供的 API，把返回的数据整理后叠加到地图上。开发者自己没有做预报，也没有收集数据，但借由别人的接口就把功能实现了。

通俗说，就是时间精力有限的人，可以直接拿来用技术大拿的能力来完成自己的任务。

2023 年 3 月 1 日，OpenAI 正式对 ChatGPT 开放 API。之后任何人都能把 ChatGPT 嵌入自己开发的产品、服务或流程里做二次开发，不用从零训练类似模型，也不再受限于官网网页的使用场景。需要说明的是，官网免费体验与 API 调用是两回事，API 按调用时发送的 prompt 与返回结果的 Token 数量计费。以最常用的 GPT-3.5-Turbo 为例，定价为每 1000 Token 收取 0.002 美元。

Token 在 ChatGPT 里并非等同于字或词，而是可拆分的字符块，不同语言的拆分方式不同。OpenAI 提供了 Token 计算工具，实测“法律人”三个字里，“法”“律”各自占 2 个 Token，“人”占 1 个 Token，可见计算方式并不简单粗暴。粗略估算，1000 Token 约等于 500 个中文汉字。

正式创建新密钥前，有两点要先记住：

+   1. 密钥与账号绑定且唯一，相当于账号密码的级别。所有用这把密钥产生的费用都会计入归属账号，由账号主付费。所以不要外传，不要放到浏览器或客户端代码里公开。
+   2. 密钥生成后只展示一次，之后就隐藏且无法再次显示。请在创建时立刻妥善保存，比如本地文本文件，否则丢失就只能重新申请并在代码里替换。
