## 3.2.2 SearXNG：开源聚合搜索引擎的深度应用

在了解完面向 AI 优化的商业方案博查后，本节介绍开源社区里很火的免费替代品 SearXNG。

不同于博查对搜索质量做深度加工，SearXNG 是一款强力的元搜索引擎。它能同时向 Google、Bing、DuckDuckGo 等几十个上游引擎并发请求，实现广度覆盖，并对汇总结果做去重和重排序。

SearXNG 的核心特性总结如下。

- 隐私与可控：支持自托管部署，搜索数据完全由开发者掌控，避免商业引擎追踪。
- 高兼容：提供标准 API，可无缝接入各类 LLM 编排框架。
- 强定制：允许自定义上游引擎清单、搜索分类和结果过滤规则。

SearXNG 属于自托管工具，需要自备服务器做私有化部署。接下来将分别介绍 Docker 部署步骤和 Python 调用接口的实现。

### （1）安全加固（Capability）类的参数

- `--cap-drop ALL`：移除容器内所有默认特权，最大程度降低潜在风险。
- `--cap-add`：精准补偿必要权限，如 CHOWN 允许修改文件所有权、SETGID/SETUID 允许进程身份切换。

### （2）日志管理相关的参数

通过 `--log-opt` 将日志文件大小限制在 1MB 以内，避免日志堆积耗尽磁盘。

### （3）端口与挂载的参数

- `-p 18080:8080`：将容器内部服务端口 8080 映射至宿主机的 18080 端口。
- `-v ...:/etc/searxng:rw`：将本地 data 目录持久化映射至容器配置路径，并赋予读写权限。
