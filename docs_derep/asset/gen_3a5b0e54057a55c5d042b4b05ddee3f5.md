#### 3.2.3 DeepSeek-R1 参数详解与调用限制

通过 API 调用 DeepSeek-R1 时，可灵活设置参数以控制文本长度、风格多样性与逻辑严谨性。chat.completions.create 接口的关键参数与 V3 相同。

R1 在参数解析与推理机制上存在部分特有特性与限制，调用时需注意如下内容。

##### 1. max_tokens 参数

（1）max_tokens 用于限制最终回答部分即 content 字段的最大长度。默认 4096 token，约 3000 汉字，最大支持 8192 token。

（2）该限制不包含思维链内容 reasoning_content。复杂任务中，思维链可达 32K token，因此总输出长度可能远超 max_tokens 的设定值。官方预计将上线 reasoning_effort 参数以控制推理深度与长度。

##### 2. reasoning_content 字段

（1）R1 的特点是除常规回答 content 外，额外返回推理过程字段 reasoning_content，与 content 平级。

（2）该字段记录模型思考并得出结论的过程，适用于解释型任务、教学与评估场景。

##### 3. 功能支持情况

（1）已支持的功能包括对话补全标准 Chat Completion 和对话前缀续写 Beta，适用于接续已有内容生成完整对话。

（2）暂不支持 Function Calling、JSON 格式输出、FIM 补全 Beta 等功能，设置相关字段无效。

##### 4. 不生效的参数

temperature、top_p、presence_penalty、frequency_penalty、logprobs、top_logprobs 在调用 deepseek-reasoner 模型时不生效。为兼容 OpenAI 接口标准，设置它们不会报错，仅被静默忽略。
