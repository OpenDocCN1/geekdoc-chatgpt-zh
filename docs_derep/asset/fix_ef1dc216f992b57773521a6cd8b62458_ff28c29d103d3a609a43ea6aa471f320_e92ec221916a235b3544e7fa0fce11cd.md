Python 支持用 as 为导入的模块起一个更短的别名。例如把 requests 写成 req 之后，就可以通过 req.get() 来调用原模块的 get 方法。

当只需要用到模块里某一个函数时，也可以用 from 模块名 import 函数名 的方式单独引入。比如 from requests import get，之后就可以直接调用 get()，无需每次都写模块前缀。
