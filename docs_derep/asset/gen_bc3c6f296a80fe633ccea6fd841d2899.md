### **1.2 数字员工的办公室选飞书**

**1.2.1 先给数字员工找个“办公室”**

弄清陪聊型 AI 与干活型 Agent 的不同后，下一个问题是：数字员工该在哪儿办公？

招一个真人，你会安排他去办公室，因为办公室能提供信息入口、协作工具、沟通渠道、任务管理和知识沉淀。数字员工也需要同类支撑，它要能接收指令、调取信息、执行任务、反馈结果，这就要求一个“数字办公室”。

什么样的数字办公室最匹配？答案指向飞书。

**1.2.2 飞书为什么能当数字员工的主场**

飞书是字节跳动在 2019 年推出的企业协作平台，经过多年迭代，已成为国内较为成熟的协作工具。之所以适合做数字员工的办公室，主要体现在四个方面。

**优势一：消息、文档、日历、任务打通**
在飞书里，聊天就能起文档，文档里可 @同事，消息里可一键建日程，日历里能看待办。信息流动因此非常顺畅。数字员工可经消息收指令、在文档读写、在日历排期、于任务系统跟进进度，全流程不出一个平台。

**优势二：开放性与扩展力足够强**
飞书提供丰富的 API 与开发组件，开发者可以自建应用、机器人、工作流。对数字员工来说，即可通过机器人收发消息、读写文档表格、操作日历日程、调用审批考勤等功能。截至 2025 年，飞书已接入超 10 万个第三方应用，开发者社区超过 50 万人。

**优势三：AI 能力原生且开放**
飞书是较早把 AI 深度嵌入产品的协作平台，且接口开放。用户可以接入自有模型如 DeepSeek，通过飞书机器人与数字员工对话。可以把 DeepSeek 当作“大脑”，飞书当作“身体”，数字员工在飞书里办公，通过消息与人交流，就像同事间聊天一样自然。

**优势四：企业级安全与合规**
飞书通过了等保三级、ISO 27001、SOC 2 Type II 等多项认证，在数据加密、访问控制、审计日志上都有完整机制，因此可放心让数字员工处理敏感内容。需要注意的是，随着企业智能体工具应用加深，安全风险也在上升。工信部网络安全管理局对类似 OpenClaw 这类智能体工具发布了“六要六不要”安全使用指引，强调使用官方正版、限制互联网暴露、遵循最小权限、审慎使用第三方技能、防社会工程与浏览器劫持、建立长效审计机制。部署飞书机器人时也应对照上述原则，确保加密、权限、审计到位，让数字员工在合规框架内运转。

**1.2.3 飞书机器人的三大核心能力**

在飞书生态里，机器人相当于数字员工的“手脚”，它可通过 API 收发消息、操作文档、触发工作流。

**能力一：消息收发**
机器人能接收文字、图片、文件等消息，向用户或群组推送消息、在群内 @ 指定人、发送卡片式富文本与按钮表单。于是可以用聊天的方式指挥数字员工，比如发“帮我整理今天的销售数据”，机器人调用 AI 处理后把结果回传。

**能力二：文档操作**
机器人可读取飞书文档、表格、多维表格，插入、修改、删除内容，创建新文档表格，并导出为 PDF、Word 等格式。数字员工因此能自动从表格取数、生成报告写入文档、更新项目进度表、整理会议纪要归档。

**能力三：事件触发**
机器人可监听消息、日程、审批等事件，按事件自动触发工作流并与其他系统如 CRM、ERP 集成。数字员工就能在新审批进来时自动分析并提醒、在会前自动准备资料、在表格更新时自动推送通知，具备主动性。

**1.2.4 三个典型办公场景**

**场景一：智能日报助手**
每天早上 9 点，数字员工自动从销售系统抓取昨日销售数据、从客服系统抓取工单数据，分析后生成日报并标注关键指标、趋势与异常，推送到销售管理群并 @ 销售经理。经理点开即看，异常处可直接回复，数字员工会继续深挖。

**场景二：会议纪要自动化**
会后数字员工自动获取飞书会议室录音，转写并提取要点，生成包含议题、决策、待办的结构化纪要，写入飞书文档并分享到会议群，为每个待办创建任务并指派责任人及提醒。参会人无需手动整理。

**场景三：知识库问答**
员工在飞书中 @ 数字员工问“公司年假政策是什么”，数字员工会在飞书知识库检索《员工手册》相关条款，用自然语言作答并附原文链接。员工无需翻找文档。

这三个例子体现了数字员工的办公方式：消息收发指令与反馈、文档处理信息、任务跟进进度、日历安排时间、知识库检索沉淀。

**1.2.5 数字员工的一天**

**早上 8:00——自动早报**
数字员工抓取行业热点、竞争对手社媒动态、昨日销售与客户反馈，整理成结构化简报发送至管理团队群并 @ 相关负责人。9 点打开飞书，简报已在。

**上午 10:00——会议纪要自动化**
重要会议结束后，数字员工自动拉取录音、转写、提炼议题决策待办，生成纪要写入文档并分发到群组，同时为待办创建任务并 @ 责任人并设提醒。

**下午 2:00——客户跟进提醒**
数字员工检查 CRM，发现超 7 天未跟进客户、今日生日客户、即将到期报价单，自动生成跟进建议并推送给销售负责人，同时准备客户资料卡片并在日历创建跟进安排。

**下午 4:00——知识库问答**
新员工询问“报销流程是什么”，数字员工在知识库找到《财务报销制度》，提取流程要点并附文档链接与报销表单，直接作答。

**晚上 8:00——数据报表自动生成**
数字员工汇总各业务系统当日数据，分析销售额、订单量、客户数等指标，对比历史识别异常与趋势，生成可视化报表推送至数据看板群并 @ 数据分析师，可直接在飞书内追问分析。

数字员工 24 小时在线，不疲劳、不出错，你只需在飞书查看成果并偶尔下指令。

**1.2.6 用飞书要花多少钱**

飞书提供免费版、标准版、专业版、旗舰版。对个人与小团队，免费版已够用，包含无限消息记录、无限文档表格多维表格、100GB 云盘、完整日历任务、机器人与 Webhook 等开发能力，可零成本搭建数字员工办公环境。

企业用户可选标准版，约 50 元/人/月。相比数字员工带来的效率提升，该成本几乎可忽略。

本章完成四件事。

第一，区分概念。陪聊 AI 是“会思考的聊天机器人”，干活 Agent 是“会行动的数字员工”。前者只能说，后者能做，本质不同。
