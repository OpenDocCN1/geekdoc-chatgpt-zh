## 7.3 Python 高效编程入门

Python 由荷兰开发者 Guido van Rossum 创立，1991 年首次对外发布。语言设计以可读性为核心，语法简洁直观，编写与阅读都较为轻松。它兼容过程式、面向对象等多种思路，适用范围广。
