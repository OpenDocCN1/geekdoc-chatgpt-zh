# 第五章 数据资源开发和应用

## 第五十八条 【总体目标】

本市支持数据资源开发和应用，发挥海量数据和丰富应用场景优势，鼓励和引导全社会参与经济、生活、治理等领域全面数字化转型，提升城市软实力。

[PRE0]
该章被视作《上海市数据条例》的亮点，显示出市政府把数据当作生产要素来培育、以创新为导向并以科技赋能城市的开放姿态。第五十八条居于全章之首，统领数字技术的发展方向，以场景化运用为切口，强调信息技术在推动经济增长、改善市民服务和提升治理效能方面的积极价值。
[PRE1]
条例第二条将数据界定为“任何以电子或者其他方式对信息的记录”，在组织数据之外，个人数据因敏感性与争议性成为规范重点。除人格属性外，个人信息还具备明显的财产属性。^([\[1\]](#txt005.html#footnote_content_txt005_1))这种财产性主要来源于它在研发环节作原材料、在商业模式中作基座的资源价值。随着PC与智能手机普及，依托数据的数字经济已成长为当代社会主要价值创造方式。如何在守住个人权益与数据安全底线的同时释放数据效能，已成为数字化转型期的关键命题。近几年《网络安全法》《个人信息保护法》《数据安全法》相继落地，显示国家已为数字时代做足基础制度准备。

该条从要素特征与技术能力两个维度阐释发展取向。一方面，技术研发依赖海量样本支撑，并需随不同场景动态调整功能与安全标准。条例对数据特性与应用前景的判断，与国务院办公厅2021年12月21日印发的《要素市场化配置综合改革试点总体方案》中“拓展规范化数据开发利用场景”的部署高度一致，呈现出较强前瞻性。另一方面，从产业数字化视角出发，提出借助数字技术整体拉升上海经济活力、市民幸福感与治理效率等软实力。

### 一、数据的产业应用
数据处理实践同时承载隐私保护与价值挖掘两重需求，个人、企业与国家构成三方关系，立法追求的是双端受保护、三方动态平衡的治理效果。^([\[2\]](#txt005.html#footnote_content_txt005_2))对比征求意见稿，正式文本在确认政府支持数字产业的基调下明显淡化行政干预，更强调遵循市场规律、倡导技术向善。与深圳条例相比，上海本章更突出数据要素的市场属性，意图激发各类数据的开发潜力，推动全社会共同推进数字经济和数字技术的升级。^([\[3\]](#txt005.html#footnote_content_txt005_3))

我国数字信息行业呈现产业先行的鲜明特征。腾讯、百度等巨头诞生于千禧年左右，而全国层面相关规范直到2012年人大常委会发布《关于加强网络信息保护的决定》才开始触及网络侵权，后续个人信息维权案件才逐步增多。^([\[4\]](#txt005.html#footnote_content_txt005_4))消极看，早期规则空白助长了个人信息滥用；积极看，也为互联网争取了约十年的高速成长窗口，技术与商业规模实现爆发式扩张。研究对美中欧人工智能赛道横向比较后指出，中国发展势头强劲，正快速缩小与美国的差距。^([\[5\]](#txt005.html#footnote_content_txt005_5))面对新技术，法律应坚持底线思维，以维护个人尊严、财产与人身安全为红线划定发展边界。法规应当顺应科技与市场的内在逻辑，预留探索空间。相较草案，现行条例第五十八条明显将研发与落地空间交给科技界和产业界，减少过度规划，在守住个人权益与公共安全底线的条件下展现包容姿态。

## 二、丰富数据的场景化应用
该条着力于场景化探索，成为与既有地方立法相区别的特色。上海作为千万级人口的国际化都市，市场中蕴藏着极为丰富的技术落地场景。法规的核心在于通过明确数据产品归属与活动规则，为创新提供确定性，并划定应用边界，激励研发人员大胆试错，开拓数据技术的新型场景。

### 第一，为拓宽数据的场景化应用创新，应率先解决数据权属问题
