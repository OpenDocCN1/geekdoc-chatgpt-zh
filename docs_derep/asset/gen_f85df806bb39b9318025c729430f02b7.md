2019 年 10 月的赛灵思开发者大会 XDF 上，Vitis 软件框架正式亮相。赛灵思对外披露，这套框架前后打磨了 5 年，累计投入约 1000 人·年。换算一下，假如公司 1984 年成立之初就启动 Vitis，目前至少需要 28 位工程师连续 35 年全职堆代码才能完成。虽是调侃，却也侧面印证了背后的工程体量之大。

Vitis 面向的是软件开发者群体的使用习惯。它搭建在 Vivado 工具集之上，负责把设计、调试、运行 FPGA 所需的一整套组件打包给用户。框架并不绑定某种固定 IDE，反而可以嵌入到各种主流的软件开发工具链和框架里，通过一系列硬件加速库与赛灵思生态底层相连。赛灵思强调这些库和硬件 IP 对外开源，不过这种开源是面向自家硬件架构的，移植到竞品平台难度很高，但业界仍视其为一次大胆的尝试。

在架构图里，Vitis 的核心开发工具包 Core Development Kit 坐落在运行库之上，包含编译器、分析器与调试器。运行库的作用是调度各类硬件加速计算与子系统。最底层是与硬件相关的目标平台，它由目标 FPGA 器件或开发板决定，定义了基础的软硬件架构及运行环境，涵盖存储器接口、定制 I/O、数据传输协议与接口等细节。

Core Development Kit 上方是硬件加速库，由 8 个面向不同领域的子库构成，分别是 AI 模型、视频编解码、视觉与图像处理、数据分析、金融量化、基础线性代数、求解器和数据库操作。8 个子库内共提供 400 多个预先优化的开源应用，能显著降低这些方向的应用开发门槛与周期。对软件工程师和算法工程师而言，可以基于这些库快速做高层建模，并直接借助可编程逻辑对应用做硬件加速。

其中适合在 FPGA 上落地的部分，底层已经完成 RTL 实现、调试、综合、映射、布局布线以及时序收敛，调用时后端步骤会自动执行。对外以开源的 C/C++ 函数或 API 形式提供，并针对赛灵思 HLS 编译器做了预优化，开发者无需关心这些函数底层的硬件细节。

在 Vitis 顶层则是面向特定领域的开发环境。以 AI 为例，它兼容 TensorFlow、PyTorch、Caffe 等主流框架，并提供一批预训练并经优化的 AI 模型。

通常 AI 模型训练在数据中心用高精度浮点完成，而推理部署时会进行并行化、量化、剪枝，并在时间、空间和能耗三个维度做权衡优化。Vitis AI 正是为了让这些优化在 FPGA 上落地并获得可观收益。

总体看，Vitis 符合当下技术潮流，对赛灵思而言是重大进步。它为硬件工程师、软件工程师与算法工程师三类人群，提供了一条清晰、可用的 FPGA 硬件加速路径与熟悉的开发环境。作为一个开源取向的 FPGA 开发框架，它有望吸引更多人进入 FPGA 设计，推动生态持续发展。

## 4.4 无晶体管被遗漏：英特尔 oneAPI 策略

2018 年底，英特尔芯片首席架构师 Raja Koduri 公开表示，公司正在全力打造 oneAPI 编程框架，计划以此整合旗下 CPU、GPU、ASIC、FPGA 等各类芯片，构建完整的软硬件生态。

顾名思义，oneAPI 的目标是为不同计算架构提供统一的编程模型和应用接口。对开发者而言，一次编码即可让程序在跨平台异构系统上运行。口号 “No transistor left behind”，即“晶体管一个也不能少”，形象概括了其终极追求。

oneAPI 要解决的核心痛点是简化异构系统的可编程性。跨平台优化一直是业界热点，英特尔希望通过 oneAPI 提供通用开放的编程体验，让开发者自由挑选架构而不牺牲性能。同时统一的编程环境也能大幅降低因代码库、语言、工具、流程各不相同而带来的复杂性。

英特尔把自家芯片架构划分为 SVMS 四类：
· 标量架构 Scalar：CPU；
· 矢量架构 Vector：GPU；
· 矩阵架构 Matrix：AI 芯片；
· 空间架构 Special：FPGA。

四类架构各有优势和编程范式。以 FPGA 为例，可编程性是其最大差异点，但编程难度同样突出。需要用硬件描述语言做寄存器传输级建模，且抽象层次很低。开发者要把目标算法拆分、并行化、设计流水线，变成数据通路或控制电路，同时处理存储读写、跨时钟域同步、时序收敛等，以满足功耗、吞吐、精度、面积等需求，还要做仿真调试和软件层工作。

真正做出优化的 FPGA 设计，往往需要经验丰富的团队协作。哪怕是最常见的 for 循环嵌套，硬件实现与性能调优也可能耗费数月时间，这从近几年学术会议上大量关于循环展开与优化的论文可见一斑。

应对复杂度，业界常见两种做法：一是将优化好的硬件封装成 IP 供调用；二是使用高层次综合，直接把高层语言描述的模型转为 FPGA 硬件。

高层次综合的初衷是服务硬件工程师，而非软件和算法开发者。目前业界成功的 HLS 工具仍要求使用者具备硬件知识。在数字电路工程师手中，HLS 能大幅压缩周期，有时甚至接近或超越手工 RTL。但对没有硬件背景的软件工程师来说，用 HLS 设计 FPGA 就像让 C 罗去湖人打篮球，噱头有余，效果难达预期。

oneAPI 在很大程度上可视为 HLS 的延伸，但受众明确指向软件与算法工程师，这是它与传统 HLS 工具的最大分野。oneAPI 提供统一的软件编程接口，让开发者在底层 SVMS 架构间自由切换优化，而无需关注具体电路结构与实现细节。

具体实现上，oneAPI 的核心是 Data Parallel C++，即 DPC++。DPC++ 本质是 C++ 的扩展，增加了对 SYCL 抽象层的支持。SYCL 由 Khronos 组织开发，原本为 OpenCL 设计，旨在让用户用简洁的 C++ 对 GPU 等进行开发，避免 OpenCL 的繁琐。

除编程接口外，oneAPI 还涵盖完整的开发环境、软件库、驱动、调试工具等，且加速库都针对底层硬件做了优化。这一思路与赛灵思的 Vitis 如出一辙，也代表了行业走向。如今生态为王，要掌握生态、吸引开发者，就必须持续提供各类开发库和 IP，让开发者聚焦应用，避免重复造轮子。

为了覆盖 SVMS 四大类硬件，oneAPI 目标极高。英特尔在 2019 年第四季度发布了开发者测试版。除基础开发包外，还推出面向高性能计算、深度学习、物联网、视觉与视频四个领域的专用开发包，实现针对性优化。本阶段开发者仍需手动指定 SVMS 四类中的目标器件类别，其余子类别的优化则由 oneAPI 自动完成。

## 4.5 小结

业界普遍认为，英伟达和 GPU 在人工智能时代的成功，很大程度上归因于其对 GPU 编程方式与环境易用性的提升。相比之下，FPGA 虽在单位功耗性能上占优，应用范围也在不断扩大，但其编程模型仍以硬件工程师做 RTL 开发为主，对软件与算法工程师并不友好。

随着高层次综合理论与工具的成熟，FPGA 的高层次设计将成为必然趋势。Vitis 与 oneAPI 等工具正在不断演进完善。从某种意义上看，它们像当年 CUDA 之于英伟达一样，将让普通软件工程师也能借助非传统硬件架构进行高性能编程。对 FPGA 阵营而言，人们亲眼目睹英伟达和 GPU 多年主导硬件加速。值得欣慰的是，Vitis 与 oneAPI 走在正确方向上，或许能为赛灵思与英特尔提供更多对抗英伟达的筹码。

可以预见，随着高层次综合难题逐步被攻克，用高层语言高效编程 FPGA 将得以实现，这也将是 FPGA 更广泛应用的最后一块拼图。

# 第 5 章 FPGA 学术研究与未来展望

站在巨人肩上——FPGA 发展的新动向

很多世界顶尖的“建筑师”可能鲜为人知，却设计出了我们日常生活中无处不在的芯片内部结构。只要使用手机、电脑或互联网，就在受益于他们的创造。

FPGA 领域同样有一群才华横溢的“建筑师”。在他们推动下，FPGA 从简单的可编程门阵列发展为基于大量可编程逻辑的复杂片上系统。开发工具与应用场景也取得了长足进步。

站在巨人肩上才能识清全貌。要深入理解一个领域，就必须了解该领域的重要人物与关键成果。本章将带你认识 FPGA 研究领域的杰出学者，回顾过去几十年涌现的重要成果，并探讨未来发展趋势。

## 5.1 百花齐放、百家争鸣：FPGA 学术研究概况

科学技术的发展离不开企业研发与高校科研院所的学术研究，二者互补、互动。FPGA 行业亦然。除英特尔、赛灵思等公司的投入外，世界顶尖大学与研究组在过去数十年取得了一系列突破，从架构到工具，现代 FPGA 的许多技术都源自学术研究。

普通读者对工业动态更熟悉，对学术界了解有限。本节将介绍国内外 FPGA 学术领域的知名高校与专家、研究方向与主要贡献，并简要梳理主要学术会议。因篇幅限制，选择四所代表性高校做重点介绍，以帮助建立初步认知。

### 5.1.1 多伦多大学

多伦多大学的 FPGA 研究长期被认为世界顶尖。聚集了 Jonathan Rose、Vaughn Betz、Jason Anderson、Paul Chow 等知名教授，见图 5-1。研究覆盖 FPGA 各层面，包括架构、开发工具、应用，广度与深度均属一流。

该校研究兼顾前瞻与实用，成果常成功转化为工业产品。许多教授曾在 FPGA 公司担任高管或高级工程师，回归学术后仍与产业保持紧密联系，使研究更具实用价值。例如 Jonathan Rose 与 Vaughn Betz 创办 Right Track CAD，专注 FPGA 自动化设计与布局布线，后被 Altera 收购并发展为 Altera 多伦多研发中心，二人也在 Altera 担任多年高级管理职位。正是基于其技术，Altera 将 Quartus 升级为 Quartus II CAD 工具套件并持续发展。

再如 Jason Anderson 曾在赛灵思工作十年，专注 FPGA 自动化设计与优化技术，担任过主任工程师、资深经理等职。学界回归后，他于 2015 年与学生联合创办 LegUp 公司并任首席科学顾问。LegUp 是目前业界领先的高层次综合工具之一，公司曾获英特尔资本领投的种子轮融资。
