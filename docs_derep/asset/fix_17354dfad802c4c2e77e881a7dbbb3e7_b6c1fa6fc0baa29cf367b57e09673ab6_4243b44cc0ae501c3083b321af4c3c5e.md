# AI时代因果律失效？重构责任归属的五把钥匙与未来图景

在算法与数据称霸的当下，以人类行为为基石的传统因果规则体系，正遭遇前所未有的拷问。算法架构师未必精通垂直领域，但他们写下的学习规则，却能训练出击败人类顶尖高手的模型——AlphaGo完胜围棋世界冠军便是铁证。**“程序员仅搭建学习框架，真正拍板决策的是吞吐海量数据后的算法模型，最终结果与开发者初衷并无直接因果牵连。”**^([\[166\]](#txt005.html#footnote_content_txt005_166))

相关性，本质是变量间的统计关联。算法利用的正是相关性而非因果性，将输入转化为输出或新模型。大数据时代，建立在数据挖掘之上的决策，还能用因果逻辑解释吗？**“大数据最震撼的冲击，在于逼迫社会从对因果关系的执念中抽身，转而拥抱简单的相关关系。模型不懂‘为什么’，只知‘是什么’。”**^([\[167\]](#txt005.html#footnote_content_txt005_167))二者分水岭在于：因果具确定性，相关带不确定性。**“因果要求状态间必然联结，而从相关推演因果的逻辑链条并不闭环，相关性天然带有不确定性。”**^([\[168\]](#txt005.html#footnote_content_txt005_168))因果的确定性契合行为可预期，回应社会秩序诉求；相关的不确定性则导致机器决策可能引发不可控后果，使法律的教化、惩戒、引导功能难以施展。以相关替代因果易陷不可知论，引发规则失效质疑。以智能驾驶为例，车辆经感知设备采集数据，经算法分析海量信息后决策。是相互关联的数据整体，而非单一数据点，与行为决策形成对应。**“数据化让因果量化得以呈现强度与正负属性，代价却是丧失了原本的必然性与方向性。”**^([\[169\]](#txt005.html#footnote_content_txt005_169))行为与后果的关联由此变得晦涩复杂。

## 二、范式迁移：从“描述”走向“创构”

**“描述是对既存客体的符号化摹写；创构则是基于需求，按预设结果反推因素体系，调控因素互动以达成目标的生成过程。”**^([\[170\]](#txt005.html#footnote_content_txt005_170))传统因果立足既有经验，属描述范畴。大数据与AI时代，描述性因果的解释力衰退，范式向创构性因果转型。

在描述视角下，因果与相关并列，是质与量的关系：因果重质，相关重量。转入创构视角，二者转为包含关系：相关不排斥因果，而是算法世界中因果的定量表达——以量把握因。创构过程将认知焦点从因果转向变量相关性；量化关系中，相关取代因果，起因转化为因素互动的过程。创构认知下的因果，与“高度盖然性”证明标准契合。**“高度盖然性源于‘情景不可复现’，借海量证据关联重构事物原貌。”**^([\[171\]](#txt005.html#footnote_content_txt005_171))

区分描述与创构，非谓二元对立、毫无瓜葛。创构层面同样包含“为什么”，且可能与描述共享因果根基。**“技术上，创构是通过组合操作生产满足需求的产出；哲学上，它建立在对客体存在模式及人类需求发展的因果性认知之上。”**^([\[172\]](#txt005.html#footnote_content_txt005_172))创构视角下，因果基础由线性转为因素关系。传统因果无论单因单果或多因一果，皆呈线性，体现必然或方向性关联；算法世界的因果立足因素分析，体现量级关联。**“在创构因果观下，无人驾驶的自主决策归功于融合大数据的深度学习算法，虽可能切断行为与结果的传统因果链，但模糊的因果仍存特定相关性，不妨碍责任主体锁定与主观归责。”**^([\[173\]](#txt005.html#footnote_content_txt005_173))

## 三、破局因果困境：五大新型认定规则

### （一）识别规则：强制留痕与定期报告，穿透“黑箱”迷雾

查明事实是责任认定前提。技术漏洞、设计瑕疵、制造缺陷、管理失误、使用不当，乃至AI超越原设计的“自主行为”，皆可能诱发侵权，需全链路剖析因果。算法的专业性、复杂性、不透明性，让致损事故陷入“难以解释”困境：加害行为与损害结果的因果关联模糊化。决策逻辑与过程的发现、证成依赖专业人员与设备，成本高昂。即便算法公开透明，受害方因专业门槛亦难举证、质证。维权成本与收益严重失衡，呈显著非经济性。破解因果证明难与不经济之困，须建立**强制操作留痕与定期报告制度**。强制留痕固化智能主体行为轨迹，定期报告降低轨迹识别成本，保障行为透明度。

### （二）法定/行业标准规则：以合规性为缺陷推定锚点

过错推定下的举证责任倒置，对制造方过于苛刻。**“让设计制造方证明‘无缺陷’，即令其对‘不存在’担责，等同于让其为几乎所有自动驾驶事故买单，实质上废弃了缺陷要件。”**^([\[174\]](#txt005.html#footnote_content_txt005_174))缓和此弊端，需引入**法定或行业标准规则**。不合标准即为产品缺陷的初步证据。设计、制造、生产方需证明实害与不合标准间无因果关联，方可免责。

依“事物自证其因”原则，**“受害人仅证损害为智能机器人行为的事实上结果，法律因果即成立，无须证其为唯一或直接原因。”**^([\[175\]](#txt005.html#footnote_content_txt005_175))制造方须存储运行中涉安全数据，保证可视化、可解释性，确保致害过程透明，事故发生时作为免责证据。

### （三）可预见性规则：以预见性为责任归属分水岭

按程序设计者对智能行为的可预见程度，行为分为可预见与不可预见两类。前者中，机器行为与程序设计存在对应关系；后者中，算法黑箱加大识别难度。Jenna Burrell 指出三重不透明：商业/国家机密导致的不透明、技术文盲导致的不透明、源于机器学习特性与测量要求的结构性不透明。^([\[176\]](#txt005.html#footnote_content_txt005_176))

结合不可预见行为与设计者主观意图，再分**目的性不可预见**与**非目的性不可预见**。
*   **目的性不可预见**：行为虽超出设计者预料，但“超出预料”本身是设计目的。深度学习赋予自主学习力，使机器能基于算法数据作出不可预见决策，这种不确定性在设计者预案内。具体行为不可预测 ≠ 风险不可预测。数据算法驱动的机器行为仍在人类掌控中。**“允许机器自主决策者，应预见机器必然失控并承担责任。”**^([\[177\]](#txt005.html#footnote_content_txt005_177))
*   **非目的性不可预见**：源于两类因素——一、智能主体自我进化（高度智能产品运行中自行修改代码）；二、外来因素介入（如黑客植入代码）。外来介入致损时，AI沦为工具，真凶藏身系统背后，适用**穿透规则**，由幕后操纵者承担一般侵权责任。

综上，智能主体自主程度是责任承担的关键考量。可预见性是设计者、制造者、使用者等主体担责的前提；不可预见性阻却设计者责任，却可能切断受害人救济路径。^([\[178\]](#txt005.html#footnote_content_txt005_178))

### （四）合理期待规则：化繁为简的缺陷判断标尺

以合理预期为标准判断缺陷存否，化繁为简。此举破解智能技术复杂性导致的缺陷举证难题，降低证明门槛，扩大产品责任覆盖面，免去各方围绕复杂学习算法缺陷存否的繁复论证，是在既有规则框架下实现实质正义的理性政策选择。

### （五）替代原因切断规则：自主决策何时能切断因果链？

深度学习算法让机器能感知环境、自主决策。具自主学习力的AI系统，决策随环境动态变化，出现设计者未预见之况，人类设定目的与机器运行结果产生偏差。机器自主学习与适应力，让控制权归属扑朔迷离，机器决策可预见性、可控性的理论基座动摇。机器自主性增强，人类控制力相对减弱。无论研发设计多审慎，均无法完全掌控具自主学习力的AI系统随环境变化作出的决策。基于学习算法的机器自主决策介入，作为**替代原因**，切断了人类程序设计者或使用者与损害结果的因果链。

何种条件下，机器自主决策构成切断因果的替代原因？Hart与Honoré探讨法律因果时，判断人行为是否构成介入（替代）原因的核心标准，在于是否**体现了介入者的自由意志与自主选择**。^([\[179\]](#txt005.html#footnote_content_txt005_179))即：介入行为体现独立自由意志 → 构成替代原因；反之 → 不构成。

在机器意识未觉醒的当下技术条件下，AI不具独立自主意识。智能主体在交互环境中自主决策，是设计者/制造者预先设定或追求的结果。其行为的不确定性与不可预测性，是设计者预置的结果。具体行为不可预测 ≠ 风险不可预测。数据算法驱动的机器决策，本质仍处于人类管控之下。

# 第四节 AI时代民事责任承担：双轨制与深层质疑

## 一、责任承担方式的双重图谱

AI时代民事责任承担方式大致分两类：一类以**人类为联结点**，系传统法制规定，侧重规制人类行为，财产赔偿为核心；另一类以**智能机器（人）为联结点**，系AI时代可能涌现的新型方式，侧重规制机器“行为”，不限于财产责任。

## 二、以智能机器为联结点的四种责任形态

主要涵盖四种形态：
1.  **缴出赔偿**：溯源罗马法 *noxae deditio*，要求将实施加害行为的智能主体交付受害人或其家属处置。^([\[180\]](#txt005.html#footnote_content_txt005_180))
2.  **召回与销毁**：制造商/销售商发现产品不合格或存瑕疵，通过召回、销毁规避损害扩大。
3.  **智能主体自付赔偿金**：智能主体以其独立财产承担赔偿责任。
4.  **限制智能主体自由**：智能主体致人损害时，相应限制其自由权利，以示惩戒。

## 三、深层质疑：形式指向机器，实质仍由人买单

学界存疑：该方式形式上指向智能主体，实质上仍由所有人/使用者最终买单。

**第一，财产权利的归属现实。** 智能主体无独立收益或财产，系所有人/使用者财产一部分。缴出、召回销毁、自付赔偿、限制自由，归根结底都是在限制或剥夺所有人/使用者的财产权益。

**第二，法律调整对象的本质错位。** 法规范约束的是“人的行为”，而非机器“行为”。民事责任的惩戒、教育、威慑功能，建立在行为人具备理性特征基础上；趋利避害本能驱动人规避责任从而调整行为。**“民事责任除补偿外，对承担者具警示与道德否定功能。但AI尚未发展到让机器具备羞耻心与道德感的程度。”**^([\[181\]](#txt005.html#footnote_content_txt005_181))智能主体不会因担责而担忧财产损失或自由受限，进而调整行为。法律调整面对机器主体时失效。**“智能机器无法理解回应法律规范、无法接受法律调整、无法理解财产对自身的意义。”**^([\[182\]](#txt005.html#footnote_content_txt005_182))**“强AI将实现物理意义上‘永生’——数据保留下，物理载体毁灭不等于消亡。这将导致法律剥夺生命、自由的惩罚手段对强AI失效，强AI将处于绝对优势地位。”**^([\[183\]](#txt005.html#footnote_content_txt005_183))
