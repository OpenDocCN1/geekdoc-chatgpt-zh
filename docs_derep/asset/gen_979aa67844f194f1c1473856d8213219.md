### 5.2.8 小结

本小节梳理了内容管理在现代应用中的价值以及演进思路。不同成熟度的项目可挑选匹配的方案，兼顾开发效率与产品水准。

- **MVP/原型阶段：** 建议直接硬编码文案，这也是习惯追踪器 App 当前的做法。实现起来简洁高效，有助于聚焦核心业务逻辑，迅速验证功能点与产品想法，与 App 现状相符。

- **产品成长阶段：** 推荐采用 Supabase 驱动的数据库方案。可复用现有的 API 层与数据库资源，与技术栈无缝衔接，投入成本可控。把易变的文案从代码里抽离存入数据库，能大幅提升更新灵活性且不影响系统稳定。

- **团队协作阶段：** 可引入专业的 CMS 如 Keystatic，或自建一套完善的管理后台。这类系统一般提供权限管控、可视化编辑、版本控制、审批流等能力，满足多角色协作的复杂需求。产品、设计、运营即可独立完成文案优化、A/B 测试或公告更新，无需等待开发介入。

在进行技术决策时，应综合团队规模、内容变更频率、技术栈契合度等因素。小型团队可从轻量方案起步，大型团队则更适合专业 CMS；更新越频繁越需要专业工具的支持；方案选型优先匹配现有技术栈。

落地时建议遵循渐进式升级原则。初期先把变动频繁的内容迁移到数据库，建立基础管理能力。随着业务增长和需求变化，再逐步接入功能更完整的 CMS。演进过程中始终要保障用户体验，确保内容管理不会拖累核心性能与使用流畅度。

掌握这些思路后，即可为全栈应用从 MVP 到成熟产品的全周期，规划出科学合理的内容管理技术选型策略。

### 6.1 项目规划：构建商业级图像生成平台

本节将整合过往所学，完成一项综合任务：从零搭建一个功能完备、可商业运营的全栈 AI 应用。

我们沿用熟悉的基础技术栈，并加入多款高效新工具，包括 AI 模型调用工具 Replicate、AI 编码助手 Cursor、AI UI 生成工具 v0.dev、邮件服务 Resend。

在动手编码前，严谨的产品规划是成功的关键。我们先明确商业定位、核心功能与页面结构，确保技术投入精准服务商业目标。

#### 6.1.1 产品商业定位分析

本项目核心服务依托 Replicate。Replicate 是面向开发者的云平台，通过统一 API 大幅简化数千种开源 AI 模型调用，让开发者无需管理底层 GPU 基础设施。

在众多模型中，我们选用 Google DeepMind 推出的 Nano Banana 模型，官方名为 Gemini 2.5 Flash Image。该模型在图像编辑上表现突出，尤其在多轮编辑中能保持人物、宠物、品牌吉祥物等主体的高度一致性。对需要维持视觉统一的设计师、营销人员和内容创作者极具吸引力。

据此，产品定位为：面向创意工作者与内容创作者，聚焦角色一致性与高阶图像编辑的专业级 AI 图像生成与编辑工具。该定位避开通用绘画工具的红海竞争，聚焦专业用户的工作流痛点，在细分市场建立壁垒。

#### 6.1.2 核心功能规划

围绕定位，我们规划 4 项贴合用户痛点的核心能力：

- **文生图 (Text-to-Image)**：图像生成工具的基础能力，支持用户通过提示词将创意概念快速转化为视觉图像，Replicate 提供简洁的 API 支持。

- **图生图 (Image-to-Image)**：专业工作流的关键环节，包含两种模式。

    - **单张编辑**：上传基准图后，通过文字指令进行精细修改，如“把产品图背景换成海滩”或“把人物服装颜色调为红色”。

    - **多图融合 (Multi-image Fusion)**：高级创作功能，允许上传多张参考素材，结合文字指令生成融合多源元素的全新图像，如将产品 A 无缝置入场景 B，或把人物 C 与宠物 D 自然合成合影。

- **风格迁移 (Style Transfer)**：借助 Nano Banana 的多图处理能力，将一幅画作的艺术风格，如梵高的《星空》，迁移到另一张照片，如城市风景，创造独特视觉效果。

- **图像优化 (Image Optimization)**：关键商业化功能。AI 原图体积常过大，不适合网页或营销物料使用。该功能自动压缩并格式优化，如转 WebP，在保持视觉质量的同时提升加载性能，直接影响体验与 SEO。

#### 6.1.3 页面架构设计

为承载上述功能并引导用户完成从认知到付费的闭环，我们设计 5 个核心页面：

- **落地页 (Landing Page)**：产品门户，通过视觉冲击的作品展示与清晰价值主张吸引用户注册。

- **生成工作台 (Generation Workbench)**：核心操作区，用户在此完成全部图像生成与编辑，界面以直观高效为原则。

- **图库管理 (Gallery Management)**：个人资产库，支持查看、管理、复用与分享创作成果。

- **用户中心 (User Center)**：账户管理中心，处理个人信息、剩余积分、订阅升级或取消。

- **定价页面 (Pricing Page)**：商业转化页，清晰展示各付费套餐价值并集成无缝支付入口。
