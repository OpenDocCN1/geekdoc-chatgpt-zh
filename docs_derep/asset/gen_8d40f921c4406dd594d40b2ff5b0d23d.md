LangChain 的定位是快速搭建并且能灵活对接多种外部工具的 Agent。像自动化客服、内容生产平台、大规模数据处理这类需要智能体频繁跨系统调用、反复做任务拆解与规划的场景，它都能发挥比较好的效率。

##### 2. LangGraph

LangGraph 是在 LangChain 基础上演进的方案，于2022年发布，更强调用图状结构来组织复杂的多步骤任务，适合多任务协同与分派。

- ✅ 图结构为核心：最大的特点是原生支持图结构设计，任务或操作被抽象成节点，节点间的依赖关系用边来表达，形成可视化的执行流程，逻辑关系更直观。
- ✅ 多任务并行协作：能够让多个 Agent 或多个子任务同时运行，通过图来统一管理交互，特别适合多层级、多步骤的业务自动化、跨部门协作等复杂场景。
- ✅ 扩展性灵活：允许开发者自定义节点和边的类型，按业务需求扩展执行与交互方式，同时可以动态调整图结构，优化执行顺序与效率。
- ✅ 高级能力更强：相较 LangChain，多了动态任务生成、任务优化、依赖管理等能力，在大规模任务调度与多 Agent 协作时更有优势。

总体上，LangGraph 适合需要复杂任务协作、图形化流程管理、跨部门流程与多 Agent 协同的场景。

##### 3. LlamaIndex

LlamaIndex 原名 GPT Index，是2020年推出的经典开源框架，专注于以大语言模型为基础的 Agent 构建，在大规模数据集处理与信息检索上表现突出。起步早于 LangChain，但上手门槛相对较高，更适合对数据处理与查询优化有明确要求的开发者。

- ✅ 检索与查询效率高：擅长对海量数据进行快速索引与查询，适用于搜索引擎、知识图谱等对检索响应速度要求高的应用。
- ✅ 数据结构灵活：提供多种数据结构来存储与组织异构数据，可同时处理文本、结构化与多模态数据，支持高度自定义的查询方式。
- ✅ 查询优化能力强：内置更复杂的查询优化机制，能在海量数据中实现高效匹配，为数据密集型应用提供较好的性能与扩展性。

LlamaIndex 最适合以大数据与信息检索为核心的 Agent 应用，需要高效处理和检索海量信息的场景。

#### 1.3.4 Multi-Agent框架

Multi-Agent 的思路是，当单个智能体难以独立完成复杂任务时，用多个智能体分工合作。每个 Agent 专注任务的一部分，通过协作达成整体目标。

例如做一个 App，需求分析、代码编写、功能测试、性能优化等角色都可以拆成不同 Agent，通过协同完成完整开发流程。这种拆解能提升效率与执行精度。

实际开发中，Multi-Agent 系统既可以手工编排，也可以用现成框架加速。

##### 1. CrewAI

CrewAI 是一个轻量级的多 Agent 协作框架，开发者通过定义任务、角色与目标就能快速组建团队。它支持顺序执行、层级结构、异步工作流等多种协作模式，适用于自动化写作、客户支持、项目管理等场景。框架强调性能与低延迟，对响应速度要求高的应用比较友好。

##### 2. OpenAI Swarm

OpenAI 于2024年开源的 Swarm 是一个轻量级多 Agent 协同框架，旨在简化 Agent 间协调与执行。它围绕 Agent 和 handoff 两个核心概念设计，Agent 承载指令与工具，handoff 负责把任务交接给另一个 Agent。这种设计让复杂对话流与任务委派更顺畅，代码简洁也适合学习参考。

##### 3. OpenAI Assistant API

OpenAI 的 Assistant API 能力很强，可以构建处理多种任务的 Agent，但它是闭源服务。开发者只能通过在线接口调用，无法完全掌控内部逻辑，在需要高度定制化的场景下会受限制。

##### 4. 微软的AutoGen

AutoGen 是微软开源的定制化多 Agent 对话系统框架，支持工具使用、任务分配与复杂操作。

- ✅ Agent 协作：强调多 Agent 间的协作与动态角色分配，可在执行过程中根据流程与需求调整分工，角色可以是数据采集、代码生成、数据分析等。
- ✅ 工具集成与扩展：支持接入多种外部工具与 API，如数据库查询、数据分析、代码生成等，同时允许按需定制 Agent 行为与交互方式。
- ✅ 无代码开发环境：配套 AutoGen Studio 提供可视化构建与调试环境，无需大量编码即可搭建原型、验证与优化多 Agent 系统。

##### 5. MetaGPT

MetaGPT 是一个开源多 Agent 框架，用来模拟软件公司内部协作。它把产品经理、架构师、项目经理、工程师等角色抽象为 Agent，并通过标准化操作流程 SOP 协同工作，把复杂的软件开发任务拆解为多个子任务由不同 Agent 分别处理。

> 说明
本书的实践以代码层面的工程化开发为主，侧重可部署、可扩展的 Agent 构建。虽然市面上也有 Coze、Dify 等优秀低代码平台，可以通过可视化配置快速搭建 Agent，但本书不涉及这些平台的具体操作，有兴趣的读者可自行查阅官网。

### 2.1 主流大模型发展概览

自 ChatGPT 引爆生成式 AI 热潮以来，大语言模型成为通用人工智能发展的核心动力。当前大致分为两类：一类是以 OpenAI、Anthropic、Google 为代表的闭源商用模型，通过在线 API 提供强大通用能力；另一类是以 Meta、DeepSeek、阿里云、智谱等推动的开源模型体系，强调透明性与本地部署。本节围绕在线大模型与开源大模型，梳理全球及国内主流模型的技术演进与生态。

#### 2.1.1 全球主流在线大模型

##### 1. OpenAI系列

OpenAI 成立于2015年，自2022年11月发布 ChatGPT 起成为行业领跑者。ChatGPT 建立在 GPT-3.5 与 GPT-4 之上，模型体系从基础语言逐步演进到多模态，覆盖语言、图像、音频、视频等。

1）基础语言模型（GPT系列）
GPT-3 于2020年发布，在多项 NLP 任务中表现突出。GPT-3.5 于2022年优化，对话连贯性与准确性提升，被集成进 ChatGPT。2023年发布的 GPT-4 在自然语言能力上大幅跃升，并引入多模态输入。同年发布的 GPT-4 Turbo 在保持能力的同时提升速度与效率、降低成本。2025年4月发布的 GPT-4.1 在编程、指令遵循、长上下文理解上更强，上下文最长支持100万 token。

2）Omni系列模型（GPT-4o系列）
为实现更自然交互，OpenAI 推出了成本更低的多模态 Omni 系列。2024年5月发布的 GPT-4o，“o”寓意 omnipotent，可处理文本、图像等多模态数据，是当前 Agent 开发的主流选择。同年7月发布的轻量版 GPT-4o mini 面向资源受限与低成本场景。

3）推理模型（o系列）
专注于复杂推理与逻辑能力的 o 系列，2024年12月发布 o1，提升数学与科学问题的推理能力；同年9月发布轻量版 o1-mini 适配对响应速度要求高的推理任务。2025年4月发布的 o3 在 o1 基础上进一步增强推理能力并支持图像输入。

4）多模态输出模型
除输入多模态外，输出侧也在同步推进。2025年4月发布的 GPT-image-1 在 DALL·E 基础上迭代，支持图像生成、编辑与修复。2024年12月发布的 Sora 可将文本转为视频，支持视频生成、动画制作与内容重混，在影视制作领域引发关注。语音生成方面，TTS 从 TTS-1 迭代到 GPT-4o mini TTS，提升了文本到口语的自然度。

5）向量模型（Embedding Models）
用于把文本转为数值向量，便于相似度计算与信息检索，广泛应用于搜索引擎、推荐系统与 RAG 等工程任务。

##### 2. Claude系列

2021年，部分 OpenAI 研究人员因对 AGI 安全的理解差异离职创办 Anthropic，主张通过“宪法式人工智能”从根本上提升可控性、可解释性与对齐性。Claude 系列以启蒙思想家 Claude Adrien Helvétius 命名。

2023年3月，Claude 1 与 GPT-3.5 几乎同期上线。2023年7月迭代的 Claude 2 在基础 NLP 能力上提升并开放网页试用。2024年3月发布的 Claude 3 系列在安全机制增强的同时新增图像输入与工具调用。2025年5月发布的 Claude 4 系列包含 Opus 4 与 Sonnet 4，其中 Opus 4 在复杂逻辑编程任务上表现尤其突出。

##### 3. Gemini系列

Google 在大模型浪潮中加速布局。2023年3月推出基于 LaMDA 的 Bard 作为轻量对话工具，初期反响平淡。2023年12月宣布 Bard 升级为 Gemini 并发布 Gemini 1.0 系列，标志着由 DeepMind 主导的大模型战略全面启动。
