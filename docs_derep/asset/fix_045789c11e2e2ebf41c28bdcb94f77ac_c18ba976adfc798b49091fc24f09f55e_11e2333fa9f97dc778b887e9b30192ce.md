# 第 1 章 ChatGPT 的含义

## 1.1 什么是 ChatGPT

### ChatGPT 的诞生经过
ChatGPT 于 2020 年底开始在全球走红，有人借助它完成论文拿到高分，有人依靠它通过面试，还有人由此实现商业变现。那么它到底是什么？

ChatGPT 由美国 OpenAI 公司推出，基于强化学习的自回归大语言模型，用于文本生成。它通过海量语料训练模拟人类表达，从而实现问答、内容生成、任务执行等能力。

### ChatGPT 的主要特性
核心开发语言是 Python。

模型基于大规模语料训练，语料来自真实对话，因而既能兼顾广博知识，也能结合上下文进行互动。

使用过程中具备持续学习能力，会依据过往交互和偏好给出个性化回复。

支持多语言输入，不受单一国家或地区限制，同时可并发服务多位用户。

### ChatGPT 的优缺点
任何技术都有两面，ChatGPT 也不例外。

表 1-1 ChatGPT 的优点

| 优点 | 说明 |
| --- | --- |
| 应用场景多 | 可覆盖客服、教育、金融、社交等多个领域，跨界适应性强 |
| 智创能力强 | 具备较强的学习与创造力，能生成诗歌、小说、新闻稿等内容 |
| 对话更拟人 | 能够输出更接近人类的文本，与用户进行自然交流 |

表 1-2 ChatGPT 的缺点

| 缺点 | 说明 |
| --- | --- |
| 训练成本高 | 需要海量数据支撑，对数据多样性和质量要求较高 |
| 输出可能失实 | 有时会出现编造不存在的知识的情况 |
| 社会争议大 | 大范围应用后，部分人士担忧其被用于网络攻击等场景 |

## 1.2 如何对 ChatGPT 提问
ChatGPT 会基于上下文作答，有时需要开启新会话以避免旧信息干扰，点击 New Chat 即可启动新对话，见图 1-3。

图 1-3 开启新对话

网络上“弱智吧”对战 ChatGPT 的话题常被热议，正是因为把弱智吧的问题原样输入后，答案往往出人意料。这说明提问方式至关重要，掌握技巧才能获得预期结果。

提示词工程的核心在于提示，ChatGPT 的生成正是基于用户提供的 prompt。用户给出一段对话作为提示，模型据此生成连贯回应。

交流时提问建议遵循表 1-3 的原则。

表 1-3 提问的正确示例和错误示例

|  | 问题明确无歧义 | 问题具体不宽泛 | 问题简洁扼要 |
|---|---|---|---|
| 正确示例 | 我想买一个苹果手机 | 我要一份蛋炒饭，不要辣，在店内吃 | 我想去理发 |
| 错误示例 | 我想买一个苹果 | 我要一份炒饭 | 现在天太热，所以我打算做手术把身体里无用的组织切除一部分 |

例如一家三口想在暑假去山东旅游三天，如何提问更有效？

错误示范：给我推荐一些景点。

正确示范：我们一家三口在 7 月份想去山东旅游三天，给我推荐一些景点，我们打算把花费控制在 3000 元以内，景点要适合 12 岁的孩子。

两种表述获得的答案差异明显，精准提问会得到泰山、青岛等低成本亲子推荐，而宽泛提问则得到希腊、澳洲等无关结果，见图 1-4、图 1-5。

再如教师想让 ChatGPT 出题：

错误示范：给我的学生出一份练习题。

正确示范：你现在是一名数学老师，给小学五年级的学生出 10 道练习题，要求有 5 道选择题、3 道填空题和 2 道应用题，开始吧。

后者能得到结构清晰、分类型明确的小学五年级数学练习题，而前者仅给出零散题目，见图 1-6、图 1-7。

多尝试不同表述，可以看到同一问题的不同答案。

常用技巧是让模型扮演角色，格式为角色 + 背景 + 问题，见图 1-8。

让模型以辛弃疾口吻写被贬边境的心情，回答会模仿词风进行文言抒发。

需要注意的是，ChatGPT 不知情时会胡编乱造，不可盲目采信。例如询问“为什么诸葛亮去世时刘备没有哭泣”，模型会编造原因，而事实上刘备早于诸葛亮去世，见图 1-9。

## 2.2 使用 ChatGPT 给宝宝起名

> 家人期望：希望孩子平平安安健健康康长大，将来成为一名科学家报效祖国。
