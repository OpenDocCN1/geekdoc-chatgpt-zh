#### 4.1.6 缓存层入门

LangChain 为大模型提供了可选的缓存机制，主要带来两点好处：

- 避免对相同提示重复发起 API 请求，从而降低开销。
- 让应用整体响应更快。

常见的实现有内存缓存、SQLite 缓存等。

##### 1. 内存型缓存

内存缓存能提升 LangChain 应用的运行效率，减少读写开销，加快返回速度。
