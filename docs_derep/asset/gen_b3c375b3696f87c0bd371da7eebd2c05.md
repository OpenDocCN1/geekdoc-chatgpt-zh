# Arduino 传感器与显示驱动实战指南：从温度采集到点阵屏控制

在 Arduino 开发中，掌握核心传感器的数据读取与多样化的输出设备驱动是进阶的关键。本文将通过一系列由浅入深的代码实例，带你完整梳理 DS18B20 温度传感器的三种典型应用场景、基础 GPIO 控制技巧，以及 8x8 LED 点阵屏的动态扫描显示原理。

---

## 核心库与总线初始化：奠定通信基础

一切的起点在于库文件的引入与单总线对象的构建。DS18B20 依赖 OneWire 协议，仅需一根数据线即可实现双向通讯。

[PRE2]cpp

#include <OneWire.h> // 引入单总线协议库

// OneWire 协议特点：单根线缆承载时钟与数据双向传输

#include <DallasTemperature.h> // 引入 DS18B20 专用驱动库

#define BUS 2 // 指定传感器数据引脚接在数字口 2

OneWire onewire(BUS); // 实例化单总线对象，绑定引脚

DallasTemperature sensors(&onewire); // 实例化温度传感器对象，关联总线

void setup() {
  Serial.begin(9600); // 启动串口通信，波特率 9600
  sensors.begin(); // 初始化传感器总线
}

void loop() {
  sensors.requestTemperatures(); // 发起全局温度转换请求
  Serial.write("当前温度是："); // 串口输出提示文本
  Serial.print(sensors.getTempCByIndex(0)); // 读取并打印首个设备的摄氏度
  Serial.println("°C"); // 补充单位并换行
  delay(1000); // 延时 1 秒，控制采样频率
}

## 进阶应用：非阻塞模式与温控报警

实际项目中，避免 `delay` 导致主循环卡顿至关重要。利用 `setWaitForConversion(false)` 开启异步转换，配合阈值判断驱动 LED 指示器，实现高效的温控逻辑。

[PRE3]cpp

#include <OneWire.h>
#include <DallasTemperature.h>

#define BUS 2
OneWire onewire(BUS);
DallasTemperature sensors(&onewire);

void setup() {
  Serial.begin(9600);
  sensors.begin();
  pinMode(12, OUTPUT); // 配置数字口 12 控制 LED
  sensors.setWaitForConversion(false); // 关键：设置为非阻塞/异步转换模式
}

void loop() {
  sensors.requestTemperatures(); // 发送转换命令，立即返回不等待
  float temp = sensors.getTempCByIndex(0); // 获取上一次转换的结果
  
  Serial.write(" 当前温度是：");
  Serial.print(temp);
  Serial.println("°C");

  // 温度区间控制逻辑：滞回比较防止阈值附近抖动
  if (temp > 28.00) { // 超过 28°C
    digitalWrite(12, HIGH); // 点亮 LED 报警
  }
  if (temp < 26.00) { // 低于 26°C
    digitalWrite(12, LOW); // 熄灭 LED
  }
  delay(1000);
}

## 交互升级：LCD1602 液晶屏实时显示

脱离电脑串口，利用 LCD1602 实现独立设备的本地化温度显示。注意液晶屏引脚占用较多，需合理规划 IO 口。

[PRE4]cpp

#include <LiquidCrystal.h> // 引入液晶库
#include <DallasTemperature.h>
#include <OneWire.h>

#define BUS 2
OneWire onewire(BUS);
DallasTemperature sensors(&onewire);
// LCD 引脚顺序：RS, E, D4, D5, D6, D7 (对应接线 3,4,5,8,9,10,11)
LiquidCrystal lcd(3, 4, 5, 8, 9, 10, 11);

void setup(void) {
  lcd.begin(16, 2); // 初始化 16列2行 显示规格
  delay(1000);
  sensors.begin();
}

void loop(void) {
  sensors.requestTemperatures();
  lcd.clear(); // 清屏刷新，防止残影
  
  // 第一行显示 "Local Tempera-"
  lcd.setCursor(0, 0);
  lcd.print("Local Tempera-");
  
  // 第二行显示 "ture is" 及数值
  lcd.setCursor(0, 1);
  lcd.print("ture is");
  lcd.setCursor(8, 1); // 定位到数值起始列
  lcd.print(sensors.getTempCByIndex(0)); // 打印温度值
  lcd.print((char)223); // 打印度号符号 (°)
  lcd.print("C"); // 打印单位 C
  
  delay(1000);
}

## 基础巩固：模拟口作数字口的 LED 闪烁与序列控制

Arduino 的模拟输入引脚 (A0-A5) 完全可以作为数字输出口使用，这为引脚紧张的项目提供了扩展可能。

### 单路 LED 闪烁骨架代码

[PRE5]
void setup() {
  pinMode(A0, OUTPUT); // 将 A0 设为输出模式
}

[PRE6]
void loop() {
  digitalWrite(A0, HIGH); // 点亮
  delay(1000);
  digitalWrite(A0, LOW);  // 熄灭
  delay(1000);
}

### 多路 LED 顺序流水灯

通过数组或依次操作多个模拟口，实现流水灯效果。

[PRE8]
void setup() {
  pinMode(A0, OUTPUT);
  pinMode(A1, OUTPUT);
  pinMode(A2, OUTPUT);
  pinMode(A3, OUTPUT);
  digitalWrite(A3, LOW); // 预设 A3 初始低电平
}

[PRE9]
void loop() {
  // 依次点亮 A0, A1, A2，每个亮灭间隔 1 秒
  digitalWrite(A0, HIGH); delay(1000); digitalWrite(A0, LOW); delay(1000);
  digitalWrite(A1, HIGH); delay(1000); digitalWrite(A1, LOW); delay(1000);
  digitalWrite(A2, HIGH); delay(1000); digitalWrite(A2, LOW); delay(1000);
}

## 硬核挑战：8x8 LED 点阵动态扫描与汉字显示

点阵屏驱动是考验底层时序掌控能力的经典案例。通过“行列扫描”实现视觉暂留效果，配合点阵取模数据显示图形或汉字。

### 引脚映射与扫描驱动核心逻辑

定义 8 行 8 列的引脚连接，核心循环采用“逐列拉低、逐行送数据、延时、清屏”的时序。

[PRE10]
int ROWS[] = {13, 8, 2, 10, A3, 3, A2, 5}; // 8 行引脚映射
int COLS[] = {9, A1, A0, 12, 4, 11, 7, 6}; // 8 列引脚映射

[PRE7]
// 动态扫描核心伪代码逻辑：
for (int c = 0; c < 8; c++) {
  digitalWrite(COLS[c], LOW); // 选中当前列（低电平有效/依硬件定）
  for (int r = 0; r < 8; r++) {
    digitalWrite(ROWS[r], dat[r][c]); // 向当前列的 8 行送入对应行数据
  }
  delay(1); // 视觉暂留维持时间
  Clear(); // 消隐处理，防止重影，准备下一列
}
