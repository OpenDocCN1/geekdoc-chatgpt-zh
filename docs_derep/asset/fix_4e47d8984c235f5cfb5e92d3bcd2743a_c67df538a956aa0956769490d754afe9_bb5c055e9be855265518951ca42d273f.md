**第三十五条 监护人应当按照最有利于被监护人的原则履行监护职责。监护人除为维护被监护人利益外，不得处分被监护人的财产。**

要点梳理如下：

1. **监护人定位**：指承担对未成年人或无、限制行为能力人照料责任的主体，核心任务是保障被监护人的身心与财产安全。
2. **优先利益原则**：履职时必须把被监护人的最大福祉放在首位，涵盖基本生活、教育、医疗、安全等需求的满足。
3. **财产处分的边界**：通常无权处置被监护人财产，仅在维护被监护人利益的合理情形下，例如支付生活费、医药费、学费等才可操作。
4. **案例提示**：监护人冒用被监护人名义出售资产并将款项用于个人消费，就违背了最有利于原则。

**第五百三十五条 因债务人怠于行使其债权或者与该债权有关的从权利，影响债权人的到期债权实现的，债权人可以向人民法院请求以自己的名义代位行使债务人对相对人的权利，但是该权利专属于债务人自身的除外。**

核心说明：

1. **代位权触发**：债务人怠于行使自身债权或从权利，导致债权人到期债权受损，债权人可向法院申请以自己名义代为行使。
2. **适用前提**：债务人怠于行使、怠于行使造成债权无法实现、且该权利并非债务人专属。
3. **例外情形**：专属于债务人本人的权利不在代位范围，债权人不得代为行使。
4. **案例提示**：借款人拖欠债务却持有专属合同权利，债权人只能就其他可代位权利申请行使以保障受偿。

最后模型会提醒法律适用因案而异，具体问题仍建议咨询执业律师。
