GROUPBY 是 Excel 365 与 Excel 网页版的新函数，用于按列分组并做聚合，作用类似 SQL 的 GROUP BY，可按指定列分组后对每组应用求和、平均、计数等聚合。

基本语法

=GROUPBY(row_fields, values, function, [field_headers], [total_depth], [sort_order], [filter_array])

- row_fields：分组依据的列，可单列也可多列。
- values：需要聚合的列。
- function：聚合函数，如 SUM、AVERAGE、COUNT 等。
- [field_headers]：是否保留标题，默认 TRUE。
- [total_depth]：是否输出总计行，默认 0 不输出。
- [sort_order]：排序方式，默认 0 不排序。
- [filter_array]：筛选条件，默认不过滤。

1. 多列分组：row_fields 可为数组，支持多维度分组。
2. 聚合函数：function 支持 SUM、AVERAGE、COUNT、MIN、MAX 等。
3. 总计行：通过 total_depth 可添加汇总行。
4. 排序：sort_order 可设 1 升序、-1 降序。
5. 过滤：filter_array 可先过滤再分组聚合。
6. 动态数组：返回结果会自动溢出填充。
7. 兼容性：仅 Excel 365 与网页版可用，旧版不支持。

注意事项

* 数据范围：row_fields 与 values 的范围要一致，否则易报错。
* 数据类型：values 需与聚合函数匹配，例如 SUM 要求数值。
* 性能：大数据集下可能变慢，建议先小范围测试。
