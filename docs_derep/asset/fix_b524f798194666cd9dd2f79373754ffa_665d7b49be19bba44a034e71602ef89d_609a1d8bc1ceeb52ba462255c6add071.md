#### 7.1.5 大模型驱动的重排：RankGPT 与 RankLLM

Cross-Encoder 与 ColBERT 类的重排方法属于 ChatGPT 出现之前的主流深度学习方案。进入大模型时代后，重排思路出现了新的发展。

RankGPT 由 Weiwei Sun 等人在论文 “Is ChatGPT Good at Search? Investigating Large Language Models as Re-Ranking Agents” 中提出。该方法利用 ChatGPT 或 GPT-4 等大模型强大的语义理解能力，以零样本方式对初筛候选文档进行精细化排序，提升相关性与准确度。RankGPT 通过生成候选文档的不同排列并结合滑动窗口策略，实现段落级的高效重排。其优点在于无需专门微调，直接使用预训练大模型即可完成重排。

RankLLM 是开源社区 Castorini 推出的一款 Python 工具包，聚焦可复用的列表式重排任务。与 RankGPT 类似，它也调用大模型执行重排，但更倾向于使用经过微调的开源模型，例如 RankVicuna、RankZephyr，以换取更优表现。

LlamaIndex 中也有相似实现，称为最近性过滤，解决多版本文档的时效问题。当存在不同版本时，优先返回最新版本内容。其原理是依据文档时间戳判断最新版本，并在排序或加权时提升其优先级。
