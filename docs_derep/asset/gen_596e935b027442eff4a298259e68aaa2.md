### 2. 流式渲染性能优化

流式渲染的痛点在于高频 DOM 更新带来的卡顿，可通过以下手段缓解。

- 1）批量更新：累积一定数量 token 后再统一触发渲染。
- 2）节流更新：限制 UI 刷新频率，避免过度渲染。
- 3）虚拟化：仅渲染可视区域内容，应对长对话历史。
- 4）Web Worker 卸载：在后台线程执行复杂解析，降低主线程压力。
