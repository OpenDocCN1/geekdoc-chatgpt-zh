【实战拆解】邮件分类背后的机器学习逻辑

邮件过滤这个案例就是一个典型的分类问题。分类一般要靠监督学习来做，也就是先用带标注的样例训练模型。准备邮件样本时必须额外加上标签，训练向量里要带上 `y` 来表示类别，整个训练集可以写成：

`T={(x11, x12, x13, y1),(x21, x22, x23, y2),(x31, x32, x33, y3),…,(xn1, xn2, xn3, yn)}`

#### 6.6.3 任务类型

数据到底是“样本”还是“样例”，直接决定了能做哪些机器学习任务。只拿到一组没有标签的样本，模型通常只能做聚类 `Clustering`。聚类是让模型依据训练集里的特征，自动把输入集合划分成若干个簇 `Cluster`，同一簇内的样本特征相似。生活里，淘宝、京东会依据年龄、地域、消费行为等刻画用户画像，把用户分成不同群体来做推荐，这就是聚类。聚类的目的在于发掘数据内在规律，为后续分析做准备。用纯样本训练的过程一般叫做无监督学习。

像邮件过滤这样，训练集由样例构成，任务就偏向分类 `Classification` 和回归 `Regression`。有了标签，聚类反而没有必要，因为标签本身就能指引分组方向。

分类和回归都是从样例的历史经验推断新样本的类别或强度，让机器代替人工给出标记。区别在于，回归做定量预测，输出连续值；分类做定性判断，输出离散类别。以本实战为例，判断一封邮件是否垃圾，二分类就是分类任务；如果要输出属于垃圾邮件的概率，那就是回归任务。分类的重点是找决策边界，回归的重点是找最优拟合。这类基于样例的训练方式属于监督学习。

既然这里已经提到监督[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)学习和无监督学习的概念了，再顺带说一个更流行的任务类型——强化学习。它不依赖历史数据，而是根据环境对行为的收益评价来不断改进模型。类似婴儿学语，婴儿一开始发出随机声音，一旦声音被大人理解并得到喂食奖励，他就会重复类似发声。学习依据的不是历史数据，而是一个裁判来打分激励。

AlphaGo Zero 就是典型。DeepMind 在与李世石对弈后宣布放弃人类对局图谱，抛弃历史数据和监督方法，从零开始让机器自对弈训练。棋盘每步优劣可由最终结果评判，本质上就是强化学习。现在游戏、无人车等很多训练也都基于强化学习。

#### 6.6.4 数据预处理

讲完样本、样例和任务类型，邮件过滤就可以进入训练阶段。第一步是数据预处理 `Data Preparation`，统一度量标准、去掉噪声，保证数据正确、描述统一且包含关键影响特征。保证正确叫数据清洗 `Data Cleaning`，保证描述恰当叫特征选择 `Feature Selection`。

数据清洗很形象，样本可能来自数据库、传感器、摄像头等，收集方式不同会导致误差、缺失或错误，即噪声；不同来源的数据在结构、单位、精度上不一致，需要做规范化 `Normalization`，去掉单位限制，变成无量纲数值，便于比较和加权。

机器学习的数据清洗大致包括：

• 数据集成，把多源数据整合成一致结构，存入统一存储；
• 基础清洗，如去重；
• 分层采样，在样本多差异大的情况下抽取有代表性的样本，保持类型平衡；
• 数据分配，按比例划分为训练集、验证集、测试集；
• 数据规范化，把量纲转成纯量，缩放到同一数量级，如 0 到 1；
• 平滑化，降低统计噪声，典型做法是分箱，按特征值把样本划到子区间，特征值处于某个子区[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)间内就放到该箱子里统一处理；
• 数据填补，如生成 ID、用统计方法补全缺失值。

更贴近机器学习的步骤是特征选择，即放弃影响微弱的特征，保留对结果有决定性作用的关键特征做建模输入。

如果特征只有三五项，不做选择也行。现实里特征往往几十上百，这时选择就必不可少。一个模型用到几十个参数，就需要数十亿量级的样本才能训练好。举例，30 个特征，样本空间有 30 条坐标轴，即使每个特征只有布尔取值，组合也有 `2³⁰` 种，超过十亿。我们需要多少数据才能描绘分布？

更一般地，输入每多一个特征，决策函数就多一个参数，问题空间升一维。在训练数据量固定时，维度越高数据越稀疏，相似性难以捕捉，这就是维度灾难 `Curse of Dimensionality`。图 6-8 显示了从一维到三维时，训练数据占样本空间比例的快速下降。

要得到统计上稳定可靠的结果，数据量通常要随维度指数增长。从算法角度，穷举带来的时间复杂度也是指数级。因此特征选择既关乎可行性，也关乎效率：特征多训练慢，且很多特征贡献极小。

特征选择属于数据降维 `Dimension Reduction` 的一种，另一个主流方法是特征提取 `Feature Extraction`。提取是在原特征基础上创造新特征，用一个新特征反映多个旧特征的共同变化来实现降维；选择只是在原特征中挑最有用的，一般不变换特征值。

1) 特征的离散度：方差接近 0，样本在该特征上几乎无差异，就没有区分力。

### 6.6.4.2 特征与目标的相关性

与目标相关性高的特征更适合做分类依据，如何判断相关性是核心。

常见的人工选择方法有：

- 按发散性或相关性打分，设阈值筛选。第 3 章决策树里提到的信息熵、基尼不纯度都可作依据；
- 试错法，每次选或剔除若干特征，用模型性能评分，保留最优组合；
- 用自带评分能力的模型筛选，如随机森林、逻辑回归会输出特征权重，按权重排序选取；
- 用 L1 正则项筛选。L1 天然产生稀疏解，可做特征选择，但需注意高相关的两个特征可能只保留其一。

数据降维本身是数学问题，已有 SVD `Singular Value Decomposition`、PCA `Principal Component Analysis` 等成熟算法，可自动剔除相似信息少的特征。实际中常把自动降维与人工筛选结合。

收件人数量从 1 调到 2 的变化说明，建模要根据效果来决定用哪些特征、什么阈值。衡量效果最直观的是正确率 `Accuracy` 或错误率 `Error Rate`，即 1[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)\-正确率。实际任务中也可能用精确率、召回率、F1 分数等，具体标准依需求而定。

这个粗糙例子已揭示监督学习的核心思路：通过选策略、优化算法等手段，利用训练集信息找到相关特征和合理结构，让模型输出与真实结果差异最小。

推广到通用情形，用符号 `f` 表示决策函数，输入真实世界的 `x`，输出记为 `y′`。模型只是模拟，`y′` 与真实值 `y` 总有差距。机器学习追求把这个差距最小化。衡量 `y` 与 `y′` 差距大小的函数叫损失函数 Loss Function，也称成本函数或代价函数，记作 `Loss(y, y′)` 或 `Loss(y, f(x))`。

损失函数是统计机器学习的精髓，线性回归、逻辑回归、SVM、Boost、神经网络等，本质都是基于不同损失函数构建。过拟合处理、L1 正则等惩罚项也都作为损失函数的修正项存在，理解它们离不开损失函数这一核心概念。
