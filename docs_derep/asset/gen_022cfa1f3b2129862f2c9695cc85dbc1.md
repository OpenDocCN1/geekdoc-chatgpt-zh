CInnerProduct 层拆解：带剪枝掩码的内积实现

Caffe 原生的 InnerProduct 被在此扩展成了 CInnerProduct，核心仍是把输入在指定轴后展平再做矩阵乘，但额外引入了动态网络手术相关的掩码、临时缓冲与超参控制。整体结构围绕参数初始化、形状推导与前向指针准备展开。

类骨架是模板化 Layer<Dtype>，对外暴露 type 为 “CInnerProduct”，严格约定 1 个 bottom、1 个 top。受保护的 Forward/Backward 同时提供 CPU 与 GPU 路径。状态变量里 M_、K_、N_ 分别记录批量前缀、展平特征长度与输出通道数，bias_term_ 控制是否带偏置，bias_multiplier_ 用于偏置广播。私有区则放了 weight_tmp_、bias_tmp_ 两块临时 Blob，以及 rand_weight_m_、rand_bias_m_ 等手术时使用的随机量，最后是 gamma、power、crate、mu、std、iter_stop_ 这组控制剪枝强度的超参。

参数搭建与手术掩码初始化

LayerSetUp 先读取 inner_product_param 里的 num_output 与 bias_term，确定 N_。根据用户指定的 axis 计算从该轴开始的累计元素数得到 K_，这正是每个样本被压成的一维长度。

若 blobs 尚未创建，则按 N_×K_ 建立权重，按 1×N_ 建立偏置，均使用配置的 Filler 填充，并把 param_propagate_down 全部设为 true。

随后进入动态网络手术部分，读取 cinner_product_param。若原本有偏置且 blobs 为 2，则扩容到 4，并为权重与偏置各新建同形状的掩码 Blob，用 weight_mask_filler 与 bias_mask_filler 填充；若无偏置则扩容到 2，仅建权重掩码。接着把 weight_tmp_ 与 bias_tmp_ 重新塑形为对应参数形状。

最后把手术超参 gamma、power、c_rate、iter_stop_ 写入成员，mu 与 std 归零初始化，完成一次完整的准备。

 81         const vector<Blob<Dtype>*>& top) {

 82     // 获取维度

 83     const int axis = bottom[0]->CanonicalAxisIndex(

 84         this->layer_param_.inner_product_param().axis());

 85     const int new_K = bottom[0]->count(axis);

 86     CHECK_EQ(K_, new_K)

 87         << "Input size incompatible with inner product parameters.";

 88     // 第一个轴的维度与内积无关，其总数为 M_

 89     

 90     M_ = bottom[0]->count(0, axis);

 91     // 输出数据的形状是输入数据平坦化后的形状（丢弃了一些特征）

 92     // 需要使用 num_output 这个维度

 93     vector<int> top_shape = bottom[0]->shape();

 94     top_shape.resize(axis + 1);

 95     top_shape[axis] = N_;

 96     top[0]->Reshape(top_shape);

 97     // 初始化偏置系数

 98     if (bias_term_) {

 99         vector<int> bias_shape(1, M_);

100         bias_multiplier_.Reshape(bias_shape);

101         caffe_set(M_, Dtype(1), bias_multiplier_.mutable_cpu_data());

102     }

形状与前向准备

Reshape 先校验本次输入在 axis 之后的元素数是否与之前计算的 K_ 一致，随后用 count(0,axis) 得到批量前缀 M_。输出形状复制 bottom 的前 axis 部分，并在 axis 位置换成 N_，完成张量重排。若开启偏置，则把 bias_multiplier_ 塑形为 M_ 并全填 1，便于后续广播相加。

Forward_cpu 的开头即取出权重指针、权重掩码指针、临时权重缓冲，并在有偏置时同步取出偏置、偏置掩码与临时偏置缓冲，为后续带掩码的内积运算做好指针就绪。

整体来看，该层在保留经典内积语义的基础上，通过掩码 Blob 与手术超参为剪枝、稀疏化提供了可插拔的钩子。
