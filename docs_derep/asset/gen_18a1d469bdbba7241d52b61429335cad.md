位运算与函数调用实战拆解

（6）当输入为 64 时，执行完第 5 行后 x 的值为（ ）。

A. 8256
B. 4130
C. 4128
D. 4160

【思路拆解】

把 64 用 16 位无符号形式表示为 00000000 01000000。先做左移 6 位，得到 00010000 00000000。再与原值进行异或，得到 00010000 01000000，转成十进制就是 4160。

【参考答案】

C. 4160

【考点精讲】

一、位运算
位运算直接作用于二进制位，常用有与 &、或 |、异或 ^、左移 <<、右移 >>。优势在于执行迅速且贴近硬件，经常用于代码优化。异或的特性：数与 0 异或不变，数与自身异或为 0，且满足交换律和结合律。

二、函数定义与调用
函数由返回类型、函数名、参数列表和函数体组成。调用时实参传给形参，函数执行后把返回值交回主程序。本题中 f 接收一个 x 进行位运算，主程序把用户输入传进去并输出结果。

三、基本数据类型
unsigned short 为无符号短整型，取值 0～65535，只存非负数，适合自然数和位操作。本题限定输入范围，避免符号位干扰。

【小结】
本题综合考察位运算、模块化函数以及合适类型的选用，体现了高效处理与结构清晰的编程思想。

埃氏筛与幂次记录阶段，对 2 到 sqrt(n) 的数，若仍为质数则生成其幂次序列并倒序排列，再用这些幂次标记倍数，同时记录对应质因数与幂次。

long long solve2(int n) {
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += i * (n / i);                   // 用整除统计倍数和
    }
    return sum;
}
作用：通过 n/i 的整除特性快速得到加权和。

bool f0(vector<int>& a, int m, int k) {
    int s = 0;

}
