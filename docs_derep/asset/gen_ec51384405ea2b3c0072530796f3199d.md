# 一、提示要点：设定特定身份

设定特定身份，即为模型“分配”一个明确的角色。模型接收到身份设定后，会以该角色的语言风格完成任务。

在法律场景辅助办公时，设定身份几乎是必备步骤。因为法律对话与文书要求专业性、实用性和严谨性。若不加限制，模型输出的不确定性会很高。

## 第六节 任务拆分

向ChatGPT提交复杂任务而不拆分，错误率会升高。例如指令：“请根据我提供的文本，写一篇给公司法务培训用的发言稿”。

即便是人类，也需要阅读→归纳要点→形成观点→撰写。模型更依赖关键词引导，单靠一句指令无法稳定产出高质量答案。
