# 序言

欢迎来到《零基础玩转AI写作》。本书将带你进入人工智能写作的实践现场。在信息持续激增的当下，智能技术正以前所未有的速度与深度改变学习与工作方式，既在科研、医疗、娱乐等领域释放出强劲动能，也从根本上重塑了文本创作的范式。本书意图打消对智能写作的神秘感，引导读者进入实践空间，让每个人都能迅速上手智能写作工具，提升产出效率与质量。

全书共七章，系统呈现智能技术在写作场景的多元用法。

第1章梳理了多款智能写作产品的特质与功能，既提供产品清单，也给出依据个人需求挑选的思路。

第2章聚焦与智能体高效沟通的方法，围绕关键词提问、条件限定提问、示例式提问等策略，帮助读者获取更精准的信息与答案。

第3章面向学习场景，通过智能工具提升论文、实习报告、读书笔记、课题申请报告等材料的撰写水平。

第4章面向职业写作，提供具体建议，涵盖简历、行业分析报告、工作小结、会议纪要等，助力以更少投入获得更高质量成果。

第5章关注新媒体创作，涉及平台文案、拍摄脚本等内容，说明智能工具如何提升效率与创意表现。

第6章深入商业营销领域，探讨智能工具在产品测评、推广、品牌传播、新媒体销售、活动策划等文案创作中的应用。

第7章聚焦生活社交与虚构写作，从日常回复、节日祝福、旅游攻略，到小说创作、睡前故事、朋友圈文案，展现智能工具提供个性化表达的能力。

本书面向所有对智能写作感兴趣的读者，不论是学生、在职人员，还是关注新媒体创作与商业营销的人群，均可从中获益。我们将一起体会智能写作的乐趣，激发创造力，拓展思维边界。

智能技术迭代迅速，写作类软件层出不穷且更新频繁，书中难免存在疏漏，敬请读者与专家指正。

## 1.1 智能对话平台：常驻的写作搭档

### 1.1.1 ChatGPT

#### 1. 概览
ChatGPT由美国OpenAI推出的一款智能聊天程序，发布后迅速在全球引发热议。模型通过海量训练模拟人类语言行为，能与用户进行多轮互动，结合上下文给出恰当回应。

#### 2. 核心能力
ChatGPT可基于用户输入进行推理分析，生成符合语境的表达。

##### （1）文本生成
可按需求产出各类文本，例如概括、摘要、点评等。

##### （2）语言翻译
支持跨语言转换，并可依据用户要求优化表达，使译文更流畅自然。

##### （3）语义理解
对输入文本进行解析与说明，帮助用户把握深层含义。

##### （4）情感分析
识别输入内容的情感倾向，并作出贴合的回应。

##### （5）快速检索
因实时性有限，ChatGPT无法完全替代传统搜索引擎，但可作为补充，快速提供简短答案或建议，减少筛选成本。

##### （6）图文识别解析
支持上传图片进行互动，可解答与图像相关的识别、解读与搜索问题。

##### （7）语音对话
支持语音输入理解，无需打字，降低使用门槛，提升便捷度。

## 1.2 翻译校对助手：翻译与校对的贴身伙伴

### 1.2.1 有道写作

1. 概览
有道写作由网易开发的在线写作工具，依据中文用户英语写作习惯构建批改体系，覆盖小学、初中、高中、四六级、考研、雅思、托福等多场景。支持macOS、Windows、iOS、Android。

网页端基础功能免费，会员可使用高级纠错与详细报告。

2. 登录方式
访问 https://write.youdao.com 。支持网易邮箱、手机号、微信、QQ登录。

3. 核心能力

（1）设置写作偏好与自定义术语库
建议在账号设置中调整写作偏好并创建术语库。通过设置职业与默认写作类型，获得更具针对性的批改建议；自定义术语库可避免不常见词汇被误判。

（2）自由写作模式
适合日常练习与写作。可边写边批改，实时查看修改建议与权威例句。

新建文档后进入编辑页，完成标题与正文后点左上角保存。点词数旁下拉可查看字符数、词数、阅读时长、朗读时长等信息。

点右上角翻译可逐句译文；点批改可在右侧给出评分，并提供基础纠错、句子润色、权威例句三类建议，可展开查看并在原文定位。

可开启实时批改功能，通过左上角菜单设置语言类型后，写作过程中同步纠错。

右下角写作助手提供翻译查词与例句检索。翻译查词支持中英文即时释义；例句检索可按自定义语料库与章节来源筛选权威例句。

（3）模拟考试模式
面向备考与限时训练，具备计时功能。

进入模拟考试后新建并选择考试类型，点击开始考试开始计时，完成后再点交卷提交。提交后系统自动批改，纠错后可点再次批改查看效果，未清零基础错误时该功能锁定。

（4）扩展下载服务
主页右上角头像旁点插件下载进入下载页，可获取浏览器扩展、Word加载项及有道词典移动端，提升使用体验。

浏览器扩展可在邮件等场景辅助准确表达；Word加载项支持在Word中专业写作；手机安装有道词典后可拍照上传纸质作文批改。

（5）外接智慧学习API
外接英文批改API与中文批改API，由网易有道智云基于深度学习提供自动作文批改。

登录后点主页上方对应入口可跳转体验页，基础功能免费体验，核心功能需付费。
