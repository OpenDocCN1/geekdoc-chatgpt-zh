## NLP 的核心工作與技術地圖
自然語言處理 Natural Language Processing, NLP 是讓電腦讀懂、詮釋並產出人類語言的跨領域主題，結合人工智慧與計算語言學，廣泛用於語音辨識、機器翻譯、情緒分析與問答等情境。以下系統化整理主要任務與對應技術。

#### 1. 文字摘要

#### 定義
把龐大文字濃縮為簡潔且具代表性的概要，協助使用者快速掌握核心。

### 範例
把五千字研究報告壓縮成兩百字重點摘要。

#### 技術
- 抽取式摘要：挑選原文中具代表性的句子或段落組合。
- 生成式摘要：利用深度學習重新生成語意流暢的新摘要。

#### 常用模型
- **BART**（Bidirectional and Auto-Regressive Transformers）：生成式摘要的強勢選項之一。
- **PEGASUS**：專為摘要任務設計，能有效捕捉關鍵資訊。

#### 2. 資訊擷取

#### 定義
資訊擷取 Information Extraction, IE 從文本中抓取關鍵要素，如人名、地點、日期，供後續分析使用。

### 範例
從新聞稿中找出所有被提及的人物與地點。

#### 技術
- 命名實體識別 NER：辨識文本中的實體名稱。
- 關係抽取：挖掘實體間的關聯。
- 事件抽取：自動辨識文本描述的事件。

#### 常用工具
- **Spacy** 與 **Stanford NER**：實體識別常見工具。
- **OpenIE**：開放式資訊抽取框架，可自動化提取各類關係。

#### 3. 問答系統

#### 定義
問答系統 Question Answering, QA 依使用者提問，從知識庫或文件中找出精確答案。

### 範例
回覆「2024 年奧運會在哪裡舉行？」這類具體問題。

#### 技術
- 檢索型 QA：倚賴檢索技術，從大量文件挑出可能含答案的段落。
- 生成型 QA：倚賴生成技術，直接產出答案而非僅抽取。

#### 常用模型
- BERT：適合上下文理解的問答系統。
- GPT 系列模型：生成型問答的典型代表，能給出語意豐富的回答。

#### 4. 文字分類

#### 定義
依主題、情感或特定特徵，將文本自動歸入不同類別。

### 範例
把社群媒體評論分類為「正面」、「中立」或「負面」。

#### 技術
- **Naive Bayes**：基於機率的簡易分類方法。
- **支持向量機 SVM**：常用於高維資料分類。
- **深度學習模型**：如 **LSTM** 或 **BERT**，適合長文本與語意關係捕捉。

#### 5. 對話系統

#### 定義
模擬人類對話，提供智慧且自然的互動體驗，常應用於客服與虛擬助理。

### 範例
線上客服回答「如何重設我的密碼？」等常見問題。

#### 技術
- **Seq2Seq 模型**：傳統生成式對話系統架構。
- **Transformer 模型**：如 GPT 系列，能更好處理上下文並生成流暢回應。
- **預訓練語言模型**：如 **ChatGPT**，先在大規模資料上預訓練，再針對特定任務微調。

#### 6. 程式碼生成

#### 定義
依自然語言描述產生對應程式碼，提升開發效率。

### 範例
依使用者提供的功能需求，自動產生 Python 程式碼實作該功能。

#### 技術
- **Codex**：能依自然語言生成多種程式語言的模型。
- **GPT-4**：其生成能力亦可應用於程式碼撰寫。

#### 7. 推理

#### 定義
利用既有知識與資料，對未知情境或未來事件進行推測與決策支援。

### 範例
依歷史銷售資料預測未來銷售趨勢。

#### 技術
- **規則推理**：依預定義規則進行邏輯推演。
- **貝氏網路**：以統計方法處理不確定情境下的推理。
- **深度學習**：如 LSTM 等模型用於時間序列預測。

#### 結語
NLP 技術涵蓋從資訊抽取到推理預測的廣泛應用，能顯著提升資訊處理與理解效率。隨深度學習與預訓練技術持續進步，NLP 的能力與應用範圍將不斷擴大，推動智慧系統發展。掌握核心技術後，開發者可設計更智慧、更強大的應用，滿足多元場景需求。

**應用場景**：從大規模文本中提取關鍵資料點，如人物、地點、日期，有助後續數據分析與決策。

1. 使用 Gemini API 分析輸入文本。

3. 回傳並驗證資料點準確性。

1. 初始化問答系統，調用 Gemini API 檢索知識庫。
2. 設定回答格式與精確度要求。
3. 回傳並檢查回應正確性與可讀性。

#### 4. 文字分類

開發步驟：
1. 調用 Gemini API 分析文本情感。
2. 設定分類標籤與閾值。
3. 回傳已分類文本並驗證結果準確性。

#### 5. 對話系統
**應用場景**：模擬人類對話，用於客服或智慧助理，提供即時互動。例如處理「如何重設我的密碼？」等常見問題。

開發步驟：
1. 使用 Gemini API 設定對話流程與回答模式。
2. 依使用者輸入呼叫對應回應模組。
3. 驗證系統對不同問題的處理效果。
