- （1）词袋模型：Bag of Words，简称 BoW，把文本当成一个装满词的袋子来处理，完全舍弃词元的先后顺序和语法关系，只保留词是否出现以及出现次数。落地时先把文本中所有不重复的词整理成一份词典，再为每篇文档生成一个向量，向量每个分量对应词典里一个词的计数值。优点是搭建简单、思路直观；不足是丢失了词序和上下文。

（3）词嵌入
词嵌入把每个词映射到低维向量空间，能够体现词与词之间的语义关联。常见方案有 Word2Vec 和 GloVe。Word2Vec 采用 Skip-Gram 通过上下文预测中心词，或采用 Continuous Bag of Words CBOW 用中心词预测上下文进行训练。GloVe 即 Global Vectors for Word Representation，基于词在语料中全局共现的统计矩阵来学习向量。
优点是能捕捉上下文和语义关系，有助于提升语义理解；缺点是训练相对复杂，对语料规模要求较高。

（4）N-gram 模型
N-gram 模型把文本切分成连续 N 个词构成的片段，以此保留序列顺序信息。

（5）主题模型
主题模型是挖掘文档中潜在主题的统计方法，典型代表是隐含狄利克雷分布 Latent Dirichlet Allocation，简称 LDA。

#### 6.2.3 语音数据特征提取
从预处理好的语音中提取可用的特征，是语音识别、语音合成、说话人识别等任务的关键环节。

##### 1. 传统特征提取方法
（1）梅尔频率倒谱系数
梅尔频率倒谱系数 Mel-scale Frequency Cepstral Coefficients，MFCC 借鉴人耳听觉特性，把语音信号转成梅尔频域的倒谱参数。流程包括预处理、分帧、加窗、快速傅里叶变换、Mel 滤波器组、取对数能量及离散余弦变换 DCT。MFCC 能保留语音的核心信息，在语音识别上表现稳定。可借助 Python 的 Librosa 库提取。

（2）线性预测倒谱系数
线性预测倒谱系数 Linear Predictive Cepstral Coefficients，LPCC 用线性预测模型刻画语音的声道特性，适用于识别和合成。可使用 Pydub 与 Librosa 等库进行提取。

（3）F0 音频
基频对语音合成和语音转换至关重要，影响自然度和情感。F0 音频反映音高，即声带振动频率。可使用 Pyworld 库提取基频特征。

（4）声强
声强用于语音活动检测和语音分割，帮助区分语音段与非语音段。它体现响度，是语音能量的一种度量。可使用 Librosa 库提取。

（5）韵律特征
韵律特征在情感合成和情感识别中表达情感与语义，包含节奏、重音、语调等要素。可用 Librosa 和 Pyworld 等库提取。

##### 2. 深度学习方法
深度学习借助 CNN、RNN 或 Transformer 自动学习语音特征，可获得更高级的表征，适用于识别、合成等任务。实现上常用 PyTorch 或 TensorFlow 搭建并训练模型。

#### 6.2.4 传感器数据特征提取
传感器数据形态多样，特征提取策略需根据数据类型调整。

##### 1. 传统特征提取方法
（1）时域特征提取
从时间序列中提取统计量，如均值、方差、最大值、最小值、峰值等，反映数据的整体统计特性，适合简单分类与回归。可使用 Numpy 或 Pandas 计算。

（2）频域特征提取
频域能揭示周期性模式和频率成分，适用于振动分析、心率变异分析等。通过傅里叶变换把时序转到频域，可提取功率谱密度、频谱峰值等。可用 Numpy 或 Scipy 实现变换。

（3）小波变换
小波变换把信号分解为不同频率的子带，用于捕捉局部特征，擅长分析非平稳信号和瞬态变化。可使用 Pywt 库。

（4）PCA
主成分分析是一种降维手段，把高维数据投影到低维子空间保留主要信息，减少计算量同时保留核心结构。可使用 Sklearn 库。

##### 2. 深度学习方法
CNN 能自动学习局部模式与复杂特征，适用于图像化或时序数据。可使用 PyTorch 或 TensorFlow 构建。
RNN 及变体如 LSTM 能捕捉时序中的长期依赖，适合传感器时序分析。也可基于 PyTorch 或 TensorFlow 构建。

#### 6.2.5 视频数据特征提取
除文生视频外，大多数视频来源于传感器。视频特征提取在 3.3.2 节已有述及。除传统与深度学习方法外，还可借助开源工具。

##### 1. Video Features
Video Features 是视频特征提取工具包，支持从原始视频抽取视觉外观、光流、音频等多模态特征。集成了多套主流预训练模型，覆盖不同场景①。

##### 2. Video_Feature_Extractor
Video_Feature_Extractor 是基于 Python 的工具包，利用 2D 或 3D CNN 高效提取视频特征。通过 FFmpeg 实时解码，并以 PyTorch 为后端，支持高效 GPU 多进程提取②。

### 6.3 模态融合
模态融合指把文本、图像、音频、视频等不同模态数据整合，形成联合表征或直接输出预测，核心目标是通过跨模态互补提升感知与理解。

其作用在于：一是综合多模态信息，使模型对数据理解更全面，提升预测精度；二是不同模态相互补充，降低单一模态噪声与缺失的影响；三是支撑多模态任务，如多模态情感分析、视听语音识别等。

#### 6.3.1 数据级融合
数据级融合指在模型输入前，把不同模态的原始数据或已提取特征合并，形成统一表示。适用于原始数据相关性强、互补性高的情形，如图像与深度图。常见做法是直接拼接或叠加。

##### 1. 拼接
拼接把多个特征向量首尾相连得到更长向量。实现简单，能保留各模态原始信息。适用于模态间维度与尺度差异较大且需保留完整信息的情况。

##### 2. 加法
加法是对不同模态特征做线性加权求和，以降低维度，可能损失部分细节。适用于模态维度与尺度相近且希望压缩表示的场景。

> ① 维度指数据集中特征的数量，即表格中的列数。每个维度代表一个独立属性。例如成绩表中的学号、姓名、数学、语文等；图像中可能是像素数。维度影响复杂度、可视化难度和模型性能，高维易导致维度灾难。
> ② 尺度指数据的度量类型，即取值如何量化。常见分为定类、定序、定距、定比。定类仅作分类，无顺序，如性别；定序有顺序无固定间隔，如满意度等级；定距有数值与固定间隔无绝对零点，如温度；定比有绝对零点可比比率，如身高、收入。尺度决定可用统计与可视化方法。

以下为生物特征识别中人脸与掌纹融合的示例。
单一模态生物特征易受环境或质量影响，多模态融合可提升鲁棒性。例如融合人脸与掌纹实现更精准身份验证。
先用 PCA 对人脸图和掌纹图降维得到特征向量，再对两向量归一化到同一尺度，分配不同权重后做线性加权求和，得到融合向量。随后用最近邻分类器分类并转成后验概率，加权融合后输出最终结果。

##### 3. 乘法
乘法把单模态向量逐元素相乘融合到统一张量中，增强模态间交互，但可能增加维度。适用于需要强化交互的场景，如多模态情感分析。

在图像描述生成、视觉问答等任务中需同时处理图像与文本。可先用 CNN 提取图像视觉向量，用预训练语言模型如 BERT 提取文本语义向量，再经归一化后做逐元素相乘，得到融合向量供下游模型使用。可在 COCO 等公开数据集上验证。

[PRE4]

##### 4. 双线性融合
双线性融合先对两个模态特征做张量外积得到二维矩阵，再展平池化为一维向量，能捕捉高阶交互。

在视觉问答任务中，可对图像与文本向量分别归一化后做外积，展平并归一化，再经线性映射得到最终融合向量。可在 VQAv1 等数据集上验证。

[PRE5]

##### 5. 基于 Transformer 的方法
利用 Transformer 的自注意力和交叉注意力，把不同模态映射到统一空间并交互。适用于复杂多模态任务，如多模态情感分析、视听语音识别。

在 VQA 中，先分别提取图像和文本特征并线性投影到相同维度。用自注意力捕捉图像内部关系和文本内部关系，再以图像为 Query、文本为 Key/Value 做交叉注意，反向亦然。融合自注意与交叉注意结果后，通过加权求和或拼接输入分类器预测答案。可在 VQAv1 等数据集上验证。
