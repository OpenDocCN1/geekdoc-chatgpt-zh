### 支持向量机：对偶问题、KKT 条件与 SMO 求解

代入拉格朗日函数并消去原始变量 $\boldsymbol{w}$、$b$、$\xi_i$ 后，我们得到仅含乘子 $\alpha_i$、$\mu_i$ 的对偶优化目标：

$$\max_{\alpha} \sum_i \alpha_i - \frac{1}{2} \sum_{i,j} \alpha_i \alpha_j y_i y_j \mathbf{x}_i^{\mathrm{T}} \mathbf{x}_j$$
$$\text{s.t. } \sum_i \alpha_i y_i = 0, \quad 0 \leqslant \alpha_i \leqslant C$$

该问题与原始问题等价，最优解相同。求得 $\alpha$ 后，权重向量由支持向量线性组合给出：
$$\boldsymbol{w} = \sum_i \alpha_i y_i \mathbf{x}_i$$

偏置 $b$ 的计算依赖 KKT 条件。根据互补松弛性，$\alpha_i$ 的取值揭示了样本位置：
*   **$0 < \alpha_i < C$**：样本落在间隔边界上（$\xi_i=0$），可直接解出 $b = y_i - \boldsymbol{w}^T \mathbf{x}_i$。
*   **$\alpha_i = 0$**：样本在边界外或边界上，不参与模型构建。
*   **$\alpha_i = C$**：样本在边界内或被误分（$\xi_i \ge 0$）。

**核心性质**：仅当 $\alpha_i > 0$ 时样本才是“支持向量”。训练完成后，绝大多数样本可丢弃，模型仅由极少数支持向量决定。

**SMO 算法**通过坐标下降高效求解：每次选取两个乘子 $\alpha_i, \alpha_j$，固定其余变量，利用线性约束 $\sum \alpha_i y_i = 0$ 将问题降为一维二次规划，迭代更新直到收敛。常用启发式策略选择间隔最大的变量对加速收敛。最终 $b$ 通常取所有支持向量计算结果的均值以增强鲁棒性。

### 核函数：破解线性不可分

现实数据常线性不可分。核心思路是映射到高维特征空间 $\phi(\mathbf{x})$ 使其线性可分。对偶目标函数中仅出现内积 $\phi(\mathbf{x}_i)^T \phi(\mathbf{x}_j)$，无需显式求出 $\phi$。

定义**核函数** $\mathcal{K}(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T \phi(\mathbf{x}_j)$，即可在原空间完成高维内积计算。常用核函数如下：

| 核函数 | 表达式 |
| :--- | :--- |
| **线性/多项式** | $\mathbf{x} \mathbf{x}_i$ 或 $(\gamma \mathbf{x} \mathbf{x}_i + c)^\alpha$ |
| **RBF (高斯核)** | $\exp\left(-\frac{\|\mathbf{x}_i - \mathbf{x}\|^2}{2\sigma^2}\right)$ |
| **Sigmoid** | $\tanh(\mathbf{x} \mathbf{x}_i - \gamma)$ |

核函数具备封闭性：正线性组合、直积、以及 $f(\mathbf{x})\mathcal{K}_1(\mathbf{x},\mathbf{z})f(\mathbf{z})$ 仍为合法核函数。

### 浅层神经网络：基础架构与前向计算

区别于深层网络，浅层神经网络仅含 1~2 个隐藏层，是理解深度模型机制的基石。

以单隐藏层为例（输入层 $\to$ 隐藏层 $\to$ 输出层）：
*   输入 $\mathbf{a}^{(0)} = \mathbf{X}$。
*   隐藏层权重 $\mathbf{W}^{(1)}$ 维度为 (神经元数, 输入特征数)，偏置 $\mathbf{b}^{(1)}$ 维度为 (神经元数, 1)。
*   **神经元计算两步走**：
    1.  线性变换：$z = \boldsymbol{w}^T \mathbf{x} + b$。
    2.  非线性激活：$a = \sigma(z)$。常用 **ReLU**：$\sigma(z) = \max(0, z)$。

浅层网络参数量大，表达能力受限；深层网络则能用更少参数组合出更复杂的功能。

### 贝叶斯分类器：从决策论到参数估计

#### 1. 贝叶斯决策论：最小化风险的准则
给定 $N$ 个类别，误分损失 $\lambda_{ij}$。样本 $\mathbf{x}$ 分为 $c_i$ 的条件风险：
$$R(c_i|\mathbf{x}) = \sum_j \lambda_{ij} P(c_j|\mathbf{x})$$
**贝叶斯判定准则**：选取使条件风险最小的类别，即 $h^*(\mathbf{x}) = \arg\min_c R(c|\mathbf{x})$。对应的总体风险 $R(h^*)$ 为**贝叶斯风险**，$1-R(h^*)$ 即分类精度理论上限。

若目标是最小化错误率（0-1 损失），准则简化为**最大后验概率 (MAP)**：
$$h^*(\mathbf{x}) = \arg\max_c P(c|\mathbf{x})$$

难点在于后验概率 $P(c|\mathbf{x})$ 通常未知。机器学习分两派解决：
*   **判别式模型**（决策树、SVM、BP网络）：直接建模 $P(c|\mathbf{x})$。
*   **生成式模型**：建模联合分布 $P(\mathbf{x}, c)$，利用贝叶斯公式 $P(c|\mathbf{x}) = \frac{P(c)P(\mathbf{x}|c)}{P(\mathbf{x})}$ 推导后验。核心任务转为估计**先验** $P(c)$ 与**似然** $P(\mathbf{x}|c)$。

先验易估计（频率法），但似然涉及高维联合分布，直接计频率因维度灾难不可行。
