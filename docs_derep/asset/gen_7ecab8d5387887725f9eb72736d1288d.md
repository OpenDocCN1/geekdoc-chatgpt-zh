#### 6.5.1 什么是单元测试

单元测试是一种针对最小可测试单元的验证手段，通常指向函数、方法或类。核心目的是确认该单元在预期输入下输出正确，以便在早期发现缺陷，提升代码质量和可靠性。

常见测试维度有：

- 正常场景测试：使用符合预期的合法输入，检查输出是否正确。
- 边界场景测试：用最小值、最大值、空值等极限数据，验证极端情况下的稳定性。
- 异常场景测试：传入会触发错误的数据，确认是否能妥善处理并抛出合理异常。

### 7.1 模块基础

#### 7.1.1 模块基本概念

模块就是一个以 .py 结尾的 Python 文件，文件名即模块名。它是组织代码的方式之一，可以把相关的函数、类和变量打包在一起供其他地方调用。

模块的核心价值有：

代码复用：将常用功能封装到模块中，不同程序可直接引用，避免重复造轮子。

命名空间隔离：每个模块拥有独立的命名空间，减少名称冲突，模块内变量不会互相污染。

结构更清晰：把大项目拆成多个模块，便于维护和管理。

新建一个 Python 文件，文件名即模块名，例如 mymodule.py。
