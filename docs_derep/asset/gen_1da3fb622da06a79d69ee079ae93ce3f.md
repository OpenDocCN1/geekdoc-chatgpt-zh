# 深度解析：从DIEN到SIM，点击率预估模型如何进阶建模“动态兴趣”？

在点击率预估（CTR）的演进史中，如何精准捕捉用户随时间流转的兴趣动态，始终是核心课题。本文将深度拆解 DIEN、DSIN 与 SIM 三大里程碑式模型，揭示它们是如何层层递进、破解“长序列建模”难题的。

## DIEN：双层GRU架构，显式建模“兴趣演进”

DIEN（Deep Interest Evolution Network）的核心主张是：**用户兴趣不是静态的标签，而是随着行为序列动态演变的过程。** 为此，它设计了“兴趣提取层”与“兴趣演进层”双GRU架构，并引入辅助损失解决长序列训练痛点。

### 1. 兴趣提取层：从行为序列中“蒸馏”兴趣状态
传统方法常直接用行为 Embedding 当兴趣，DIEN 认为行为只是兴趣的载体。该层采用 **GRU** 而非 LSTM，权衡了梯度消失缓解能力与训练速度，将长行为序列压缩为一系列隐状态 $h_t$，作为“兴趣状态”的时序表达。

**破解“前时刻训练不足”顽疾——辅助损失函数**  
GRU 存在天然缺陷：前期隐状态训练不充分，却要作为后层输入，误差累积。DIEN 借鉴 Word2Vec 负采样思想，构造三元组 $(h_t, e_b^i[t+1], \hat{e}_b^i[t+1])$，强制当前兴趣状态 $h_t$ 去预测下一时刻真实行为 Embedding。

[PRE7]

这一设计三管齐下：增强各时刻表达能力、缓解梯度回传衰减、给 Embedding 层施加额外监督信号。

### 2. 兴趣演进层：引入目标广告，聚焦“相关兴趣”
提取层得到的兴趣状态往往分散（如先看手机、再看衣服）。演进层任务是：**结合目标广告 $e_a$，筛选相关状态、抑制噪声。** DIEN 探索了三种 Attention 融合 GRU 的方案：

*   **AIGRU**：用 Attention 权重 $a_t$ 直接门控输入 $\tilde{h}_t = a_t h_t$。缺陷：零输入仍会干扰后续状态更新。
*   **AGRU**：将 $a_t$ 直接替代 GRU 更新门 $u_t$。优势：赋予更新门“遗忘/记忆取决于相关性”的物理意义，可解释性强。短板：标量 $a_t$ 替代向量 $u_t$ 易丢失维度信息。
*   **AUGRU（终极形态）**：保留原始更新门向量 $\tilde{u}_t$，用 $a_t$ 按元素级缩放：$\hat{u}_t = a_t \circ \tilde{u}_t$。兼顾 GRU 原生记忆控制力与目标广告导向的筛选能力，效果最优。

## DSIN：会话视角重塑建模，捕捉“会话内同构、会话间异构”

DSIN（Deep Session Interest Network）敏锐洞察：**用户行为天然按时间切片形成“会话”，会话内兴趣聚焦（同构），会话间兴趣跳跃（异构）。** 它抛弃单一长序列视角，引入会话级建模范式。

[PRE13]
[PRE14]

### 四层架构，层层递进

#### (1) 会话分割层：硬性切片
按 30 分钟无操作间隔切分长序列 $S$ 为会话集 $Q = \{Q_1, ..., Q_k\}$。每个会话 $Q_k$ 保留 $T$ 个行为 Embedding。

#### (2) 会话兴趣提取层：Self-Attention + 偏置编码
弃用 GRU，改用 **计算并行效率更高的 Self-Attention** 建模会话内行为交互。创新引入 **偏置编码 (BE)** 显式注入三层位置先验：
*   会话级偏置 $w^K$：区分不同时段会话
*   会话内位置偏置 $w^T$：保留行为先后序
*   Embedding 维度偏置 $W^c$：补充特征内部结构

[PRE15]

会话表示更新为 $Q + BE$，经 Self-Attention 输出会话兴趣向量 $[I_1, ..., I_k]$。

#### (3) 会话兴趣交互层：Bi-LSTM 建模跨会话演进
会话序列本身具有时序性。DSIN 选择 **双向 LSTM (Bi-LSTM)** 而非 Self-Attention 捕捉会话间兴趣流转（或为效果调优所致）。前向、后向 LSTM 分别编码历史与未来上下文，拼合得最终会话序列表示。

#### (4) 会话兴趣激活层：显式对齐目标广告
参考 DIEN 思想，单独设计激活单元。利用目标广告向量 $X'^l$ 对会话兴趣 $I_k$ 做 Attention 加权求和 $U^1$，再经 MLP 融合，完成“会话级兴趣→广告相关兴趣”的最终提炼。

## SIM：两阶段检索范式，攻克“全生命周期超长序列”

当行为窗口拉长至全生命周期（长度达千/万级），DIN/DIEN/DSIN 皆力不从心。SIM (Search-based User Interest Modeling) 引入 **“检索+精排”两阶段级联范式**，实现工业界超长序列建模的工程化落地。

[PRE26]

### 第一阶段：GSU (General Search Unit) —— 粗筛降噪
目标：从原始超长序列 $B$ 中召回 Top-k 相关子序列 $B^*$，过滤噪声。

提供双检索模式：
*   **硬检索（非参、工程友好）**：按 **类目 ID 精准匹配**。候选物品类目 $C_a$，召回长序列中同类目行为。实现极简，无额外模型开销。
*   **软检索（参数化、效果上限高）**：**向量近邻检索 (ANN)**。训练辅助网络学习物品 Embedding $e_i, e_a$ 及投影矩阵 $W_b, W_a$，内积打分召回 Top-k。需离线导出向量建索引，工程复杂度高。

[PRE23]
[PRE24]
[PRE25]

> **辅助网络设计**：简化版 DIN 结构，输入截断/采样的长序列，输出用户兴趣向量 $U_r$ 与候选 $e_a$ 拼接进 MLP 训练，仅服务于软检索 Embedding 学习。

### 第二阶段：ESU (Exact Search Unit) —— 精排建模
输入：GSU 召回的百级子序列 $B^*$ + 近期短期序列。
*   **长期兴趣**：沿用 **DIEN 结构** 建模演进；另辟 **Multi-Head Attention** 分支，融合 **时间间隔 Embedding $\Delta$** 显式衰减远期行为权重，捕捉多样化长期兴趣 $U_{lt}$。
*   **短期兴趣**：常规建模。
*   最终拼接长短期兴趣及其他特征进 MLP 输出 CTR。

[PRE27]
[PRE28]

### 线上部署：权衡后的“硬检索”胜出
离线实验软检索略胜一筹，但 Top-k 结果与硬检索高度重合。综合**效果、延迟、存储、开发成本**，SIM 选择 **硬检索上线**：

[PRE29]

*   **架构**：分布式 KV 存储 “用户行为树”（多层 Key：UserID → CategoryID → Value: 行为序列）。
*   **资源**：几十 TB 存储，更新频次低，可预部署。
*   **流程**：请求到达 → 依候选物品类目 & UserID 实时查 KV 取子序列 → 送入 ESU 精排打分。

## 总结与展望

| 模型 | 核心范式 | 关键创新 | 适用序列长度 | 工程复杂度 |
| :--- | :--- | :--- | :--- | :--- |
| **DIEN** | 双层 GRU 演进 | 辅助损失 + AUGRU 门控 | 中长序列 (百~千级) | 高 (GRU 串行瓶颈) |
| **DSIN** | 会话级分层建模 | 会话切分 + 偏置编码 + Bi-LSTM 跨会话交互 | 长序列 (天然会话切片) | 中 (并行度优于 GRU) |
| **SIM** | **两阶段检索精排** | **GSU 召回降维 + ESU 精建模 + KV 树工程落地** | **超长序列 (全生命周期/万级)** | **高 (需额外存储/检索链路)** |

从 DIEN 的**微观状态演进**，到 DSIN 的**中观会话结构**，再到 SIM 的**宏观检索范式**，CTR 模型对“用户兴趣”的理解愈发立体、工程化。未来，如何在 SIM 框架下融入更强的序列建模器（如 Transformer 变体）、探索软硬检索融合、以及解决超长序列的增量更新与实时性，将是工业界持续攻关的前沿。
