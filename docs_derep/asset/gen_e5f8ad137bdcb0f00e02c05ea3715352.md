# 第六章
## AI赋能课堂：促进深度学习的教学创新
前几章已论述AI如何助力课前学情分析、教学设计和资源创编，为高质量教学奠定基础。但课堂是动态生成与互动的场域，如何把AI能力融入实时教学、提升互动质量、创新教学方式并支持深度学习，是AI赋能教学的关键所在。

### 一、重构课堂生态：构建“教师—AI—学生”三元协同教学新范式
课堂互动是教学的灵魂，是师生与生生思想碰撞、意义建构的关键空间。有效互动能激发学习兴趣并促进深度思考。传统课堂常受参与度不均、教师精力有限、互动形式单一等困扰。AI深度融入后，不再只是辅助工具，而是具备“功能性主体”特征的准参与者，深刻改变课堂生态。

当教育目标从知识传递转向核心素养培养时，教学要素的角色关系需重新审视。人工智能作为认知伙伴与智能助手，与教师、学生共生共创，这就要求打破传统的“教师—学生”二元结构，构建“教师—AI—学生”三元协同新范式。在此模式下，AI作为新参与者融入课堂，共同服务于核心素养培养目标。

#### （一）从“二元”到“三元”：AI“主体性”的再认识
在三元互动教学新范式中，核心转变是将AI从纯粹工具提升为具有某种主体性的智能伙伴。“三元”不是两个人类主体加一个被动工具，而是在动态教育生态中互动的三个不同性质主体。

为清晰辨析三者在教学活动中的角色与协同关系，需先辨识人类主体与AI主体在本质上的差异。表6-1 人类主体与人工智能主体的特征维度比较
| 特征维度 | 人类主体(教师和学生) | 人工智能主体(AI) |
| :--- | :--- | :--- |
| 意识与意向性 | 拥有自我意识、情感、信念和内在动机。行为由真实理解和意图驱动。基于“生命体验” | 本质是算法驱动的计算过程，不具备真实意识、情感或主观体验。“理解”是数据模式的统计关联。基于“数据计算” |
| 认知与学习 | 基于具身体验、社会互动和文化背景的深度语义理解。学习是主动建构意义的过程，伴随情感与价值观形成。 | 基于海量数据的模式识别和概率预测。学习是权重调整和模型优化，是“无身体、无情境”的知识处理。 |
| 价值与伦理 | 拥有内在价值体系、道德直觉和伦理责任感。教师行为受教育伦理和人文关怀约束。价值理性 | 缺乏内在价值观和伦理判断能力。行为由设计目标和训练数据决定，可能放大偏见。工具理性 |
| 发展与成长 | 追求认知、情感、社交、道德的全面整体成长。目标是成为完整的“人”。 | “成长”是模型迭代与性能提升，是功能性、可量化的优化。目标是更高效完成特定任务。 |
| 创造性来源 | 源于想象力、直觉、情感驱动和对现有知识的颠覆性重构。 | 源于对现有数据元素的重新组合与生成，是“计算创意”，而非源于生命体验的“原创灵感”。 |

表6-1揭示人类主体的优势在于价值引领、情感关怀、意向驱动与原创灵感，AI的优势在于高效知识处理、数据计算与逻辑推理，二者互补而非替代。正因此，三元互动新范式得以成立，各主体可发挥不可替代的作用。

#### （二）三元协同：教师、AI与学生的角色新定位
新课堂生态下，教师、AI与学生的角色需重新定义，形成以学生为中心、以教师为主导、AI赋能的动态协同，共同服务核心素养培养。表6-2 三元主体的主体性定位与核心角色
| 主体 | 主体性定位 | 在核心素养培育中的核心角色 |
| :--- | :--- | :--- |
| 教师 | 价值引领与设计主体 | 学习体验的“总设计师”与“智慧启迪者”：设计驱动高阶思维的真实复杂问题情境；在关键节点介入激发分析、评价与创造性思维；示范批判性思考，守护传递正确价值观与学术伦理。 |
| AI | 功能性赋能主体 | 认知过程的“智能催化剂”与“认知伙伴”：信息伙伴，提供远超个人能力的广博知识与多元视角；思维伙伴，通过苏格拉底式提问、模拟辩论等方式激发思维品质；能力伙伴，辅助学生将创造性想法快速转化为现实。 |
| 学生 | 能动建构与创造主体 | 知识意义的“主动建构者”与“价值创造者”：探究者，主动发起探究、定义问题、主导学习进程；合作者，与同学、AI高效交流协作解决复杂问题；创造者，综合信息形成独特见解并创造新作品或解决方案。 |

在此定位下，教师转向学习体验设计者与引导者，聚焦激发高阶思维与核心素养；AI作为认知伙伴提供信息、辅助思考、分担任务，扮演信息提供者、智能助教、讨论伙伴、个性化辅导员等角色，协同教师，让教师更专注思维点拨与价值观引导及情感关怀。学生从被动接受者变为主动探究者与创造者，与教师、同学、AI协作建构知识，在互动中发展自主学习、合作探究、创新实践等关键能力，优化教学互动，使教师更聚焦深层次育人，促进核心素养全面发展。

#### （三）引导学生与AI有效互动的方法
实现有效的“学生—AI”互动，教师引导至关重要。可采取以下策略，也有助于提升学生的AI素养。
- （1）教授基本的提示词技巧：在合适时机如信息技术课、项目式学习启动阶段，向学生介绍基本的提示词原则与结构，让他们学会清晰表达需求。事实上，不论哪一学科教师都有责任培养学生的AI素养。
