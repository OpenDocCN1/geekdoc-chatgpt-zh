## 第 10 章 列表、元组与字典

场景：某专业 180 人考试，若逐个建变量存分，代码量堪比写小说。Python 的**序列**类型正是为批量存储而生。序列里的每个数据叫**元素**，自带编号（索引），从 0 开始往后排。最常用的序列是**列表**和**元组**，此外还有键值对神器**字典**。本章逐个击破。

### 10.1 列表

#### 10.1.1 核心概念速览

列表（`List`）是 Python 出镜率最高的容器。用 `[]` 括起来，逗号分隔，类型随意、可嵌套、长度无上限。

**定义模板：**  
`变量名 = [项1, 项2, 项3, ...]`  
成员类型统一或混搭皆可。

### 10.2 元组

#### 10.2.1 核心特性：生而不可变

元组（`tuple`）长得像列表，但**创建后锁死**，不能增删改。用 `()` 定义，逗号分隔，类型随意、可嵌套。

**定义模板：**  
`变量名 = (项1, 项2, 项3, ...)`

**关键坑：** 单元素元组**必须**加尾随逗号，如 `(x,)`，否则括号被当成优先级运算符。
