##### 5.1.2 轻量级微调

轻量级微调的核心是在大模型预训练基础上，只动很少的参数来适配新任务。基本思路是把主体权重锁住，仅对特定层或模块进行更新，从而避开高昂的算力与存储开销。常见做法包括 Adapter 结构、LoRA 策略以及其他相近技术，即保留预训练主权重的同时引入极少量新参数来调节表示。如此既能显著压缩可训练参数规模，也能降低过拟合风险，还便于多任务复用。

在实际应用中，该思路展现出很强的灵活性和性价比。典型落地形式是 Adapter 层的叠加和低秩矩阵的引入，例如 LoRA 的动态注入机制。其目标是让资源消耗与模型效果达到平衡，通过精简更新路径来降低计算复杂度。

图5-3 呈现了轻量级微调体系里 QLoRA 层、OALoRA 层和 EfficientDM 框架的核心做法。QLoRA 在全精度矩阵运算中叠加 LoRA 的低秩分解，降低参数更新复杂度同时保持输出质量。OALoRA 更进一步，采用整数矩阵运算配合量化手段，通过量化操作提升效率。EfficientDM 则把前向与反向分别交给量化模型和全精度模型处理，实现量化数据与全精度数据的高效协同，并以均方误差来优化模型。这一套方式在轻量化场景下明显削减了存储与计算成本，同时维持任务表现的稳定，适合算力受限环境下的大模型调优。

#### 5.2 参数高效微调

参数高效微调 PEFT 的目标是用极少的参数改动换取可接受的性能，显著减少算力和存储开销，同时保留模型能力。本节围绕 PEFT 的工作原理展开，剖析核心实现手段，并通过与传统全量微调的对比，从效果和资源利用角度进行综合评估，为复杂的多模态任务提供实用方案。

##### 5.2.1 PEFT 原理与实践

PEFT 在微调预训练模型时引入少量额外参数即可完成高效适配，如图5-4所示。其基本思想是不对大模型整体进行更新，而是选择性地调整关键模块或借助轻量化组件来完成任务定制。这样既能大幅压缩存储与计算需求，又能保留原有的性能与泛化能力。

[PRE6]

图5-4 PEFT 框架的模块化实现

主流 PEFT 方法包括 Adapter、LoRA、Prefix Tuning 等。它们的共同点是冻结预训练主体，仅训练附加参数或特定子模块，比如通过低秩矩阵的动态注入或仅修改提示相关部分。正因如此，PEFT 非常适合多任务学习和跨领域迁移，是多模态场景下重要的优化手段。

PEFT 框架借助模块化设计降低了大模型训练成本，图5-4 展示了多种方法的集成架构。

Adapter 方法在前馈层与注意力层中插入非线性小模块，用小规模可训练参数替代大参数的更新，保留原始权重，利于多任务共存。LoRA 方法聚焦注意力机制中的 Q、K、V 矩阵，注入低秩参数，通过矩阵分解压缩训练规模，实现动态注入与更新。Prefix Tuning 则在输入序列前加入可训练前缀标记，作用于嵌入层，用最小改动适应不同任务，并与上下文紧密配合。

在具体实现上，Compacters 与 LoRA 注入模块被整合进注意力计算和前馈计算路径，而 Prefix Tuning 通过特定标记直接作用于嵌入生成阶段。三者组合形成统一的微调框架，大幅提升模型在多任务与跨领域场景下的适配效率。

BERT 与 GPT 是两类经典预训练架构，前者采用双向自注意力，后者采用单向自注意力，因而在任务适应性上差异明显，如图5-5 所示。

BERT 基于双向 Transformer 编码器，能同时捕捉上下文的双向依赖，训练时对输入词进行掩码预测，借助掩码语言模型和下一句预测任务优化参数，擅长全局语义理解类任务，如分类和命名实体识别。GPT 基于单向 Transformer 解码器，按从左到右顺序生成序列，通过因果语言模型训练，生成依赖前文，特别适合文本生成和对话生成等场景。

[PRE7]

两者在输入形式上也有区别，BERT 使用掩码标记处理输入，GPT 则直接使用完整文本并配合因果自注意力掩码。BERT 的强项在于深度语义理解，GPT 则在生成任务中更占优势。两种设计体现了对不同语言处理需求的针对性优化，为多样化自然语言任务提供了高效的基础模型。
