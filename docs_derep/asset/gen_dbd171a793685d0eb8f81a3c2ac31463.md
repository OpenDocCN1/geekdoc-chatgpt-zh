在搭起模型架构之前，最先要落定的就是词表。词表里每一个单元我们称之为 token，它直接决定模型能够识别哪些基本符号。以英译法为例，目标就是让模型尽可能覆盖英文和法文的词汇。仅英文本身就有数十万词，且新词持续出现。人会借助词根来推理词义，认识了 high 就能推断 higher、highest，认识了 low 就能推断 lower、lowest。若让模型也学会依词根拆分，就能把词表做小。只用学会 low、high、er、est 这四个 token 的含义，就能组合出派生词。按词根切分 token 还能为每个单元带来更多训练样本，从而提升训练后模型的泛化能力。

字节对编码最初是为数据压缩提出的，通过不断合并高频字节对来减少体积。后来被迁移到分词和词典构造上，并在 Transformer 中被用来生成词典。

### 2.1.2 词嵌入

分词后，一句话被转成 id 序列，每个 id 对应一个 token。因为神经网络处理的是向量，id 需要映射为向量。

训练后，每个 token 都落在 512 维向量空间里。语义相近的 token 在空间中距离更近，语义相远的则更远。进一步地，嵌入还具备语义运算性质，例如国王、皇后、男人、女人这四个 token 的向量满足：国王减男人大致等于皇后减女人。可见经过嵌入的向量也支持语义计算。

通过神经网络学习得到的 token 嵌入具有良好的语义表征。早期的 Word2Vec 等方法也能得到不错的嵌入，但有一个局限：嵌入在训练完成后就固定不变，无法随上下文调整。而 token 的实际语义在不同上下文中可能差异很大，例如：

- 1. 我喜欢吃苹果。
- 2. 我喜欢苹果手机。

两句都有苹果这个 token，但在第一句指水果，第二句指品牌。希望第一句里的苹果能注意到前面的吃，从而改变自身表示；第二句里的苹果能注意到手机，从而改变自身表示。

### 2.1.3 自注意力机制

为让每个 token 能依据上下文不断更新自身表示，Transformer 引入了 token 间的注意力，即自注意力机制。

每个 token 在初始嵌入的基础上，经过共享的三个线性层映射，分别得到 query、key、value 三个向量，简记为 q、k、v。

- (1) q 向量用于向其他 token 的 k 向量发起查询。
- (2) k 向量用于对其他 token 的 q 向量做出回应。
- (3) v 向量用于更新其他 token 的表示。

例如图2-9 中的“苹果”，经三层映射后得到 q_4、k_4、v_4。q_4 分别与 k_1、k_2、k_3 以及自身 k_4 做相似度匹配，Transformer 使用点积。若 q_4 与 k_3 的相似度最高，则 v_3 在更新“苹果”表示时获得最大权重，如图2-9所示。
