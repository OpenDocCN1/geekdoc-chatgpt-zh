第二阶段的训练，说白了就是让模型在数据的牵着走中不断校准自己，形成一个以误差为信号的闭环。数据准备到位后，整个核心流程大致可以拆成四步走。

（1）前向推演：先来一次试探。把图片喂进网络，层层运算后得到一个初步定位，比如图1-9方框所示的猫脸位置。因为初始权重是随机设定的，这次输出往往不靠谱。

（2）误差衡量：用损失函数算差距。把预测框和人工标注的真实框，比如图1-10所示的猫脸位置进行比对，通过损失函数把空间上的差别转成可计算的数值。通常会看两个框的偏移、重叠面积等，最终得到一个量化误差。

[PRE1]

图 1-10 标注的真实标签

（3）反向修正：从失误里学习。误差像个警报，指出模型错在哪儿。借助反向传播，误差从输出层一路往回推到每一层，驱动神经元之间的连接权重调整，让下一次的预测更接近真实。

（4）轮回收敛：在重复中逼近理想。把上面四步循环上万次，每一轮迭代都让误差小一点。随着训练推进，模型对猫脸位置的判断越来越准，最终能在一个复杂场景下稳定检测。

4. 深度学习为何这十年才爆发，算力是幕后推手

人工神经网络的理论很早就有，为何深度学习直到本世纪初才起势。核心卡点在训练本身的门槛，具体体现在两方面。

（1）早期算力吃紧。深层网络的训练对计算量需求极大，当年的硬件根本扛不住。
（2）数据资源稀缺。高质量、带标注的大规模数据集过去很少，模型难以吃饱。

现在，擅长并行运算的 GPU 普及，大数据技术成熟，深度学习才真正松绑，在视觉、语音、自然语言等赛道掀起浪潮。

知识扩展

GPU 即图形处理器，起初为图形绘制和图像处理而生，具备很强的并行运算能力。早期多用于游戏、动画的渲染。随着发展，其并行优势被迁移到人工智能、深度学习、科学计算等领域，处理速度和效率显著提升。

1.1.5 模型压缩的主流做法：量化与蒸馏

所谓大模型，通常指参数规模达到数十亿乃至数千亿级别。以 GPT-4 为例，其参数规模超过 1.8 万亿，与其能力相当的 DeepSeek-R1 可训练单元也达到 671 亿。

落地时，部署成本高、推理慢是两大痛点。为此出现了压缩技术，其中量化与蒸馏是最常用的降本增效手段。

1. 量化：用低精度换效率

量化的思路是精简参数的表达形式。大模型由海量参数构成，如 GPT-3.5 约有 1750 亿参数，图 1-11 为其应用示例。每个参数以特定数据类型存储，常见的 float32 占 4 字节。量化就是把数值精度降下来，用更小空间近似表示。

[PRE2]

图 1-11 GPT-3.5 模型的应用示例

举个例子，原值 1.2768 可以压缩成 1.28 或整数 1，前者用 float16 占 2 字节，后者用 int8 占 1 字节，存储分别降到原来的 1/2 和 1/4。

把高精度转成低精度，可带来：

（1）存储大幅缩小，如 70 亿参数模型从 float32 的 28GB 降到 int8 的 7GB。
（2）推理提速。低精度运算对硬件要求更低，在 GPU 或 CPU 上的速度可提升 2～4 倍。
（3）成本下降。模型更小意味着显存占用减少，部署算力需求降低。

量化不可避免会损失部分信息，可能影响准确率。可以通过动态量化分层调精度，或混合精度保留关键层高精度来平衡压缩与精度。目前量化已成为大模型落地的标配，LLaMA 2、GPT 的轻量化版本均采用了不同程度的量化。

2. 蒸馏：让小系统模仿大系统

蒸馏的本质是知识迁移与行为模仿，即以大带小。把教师系统学到的知识浓缩传给学生系统，如图 1-12 所示。主要包含：

[PRE3]

图 1-12 模型蒸馏的过程举例

（1）教师系统：已训练好的高性能大系统，如 GPT-4、Gemini。
（2）学生系统：待训练的小系统，目标是在缩小规模的同时保留核心能力。

知识扩展

蒸馏的基本流程：
（1）把同一数据如用户提问同时输入教师与学生系统。
（2）教师给出标准答案，学生给出初始预测。
（3）通过损失函数计算输出差异，指导学生优化参数，直至逼近教师。

优势与场景：
（1）轻量化部署。学生系统可缩到教师的 1/10 甚至 1/100，如把千亿级系统蒸馏为百亿级，适配手机、笔记本等终端。
（2）效率提升。小系统推理更快、能耗更低，适合实时交互如智能客服、对话机器人。
（3）知识复用。利用开源大系统如 Llama、GPT-3 的蒸馏数据，中小团队可快速训练出高性能系统，降低研发门槛。

进入后千亿参数时代，压缩愈发关键。单卡万元级 GPU 费用与海量训练迫使企业降本，而智能汽车、智能家居等场景要求系统端侧运行，轻量化势在必行。蒸馏还能让中小团队基于开源大系统快速迭代，推动技术普惠。

未来，压缩将与架构优化如稀疏注意力、训练策略如数据增强深度融合，推动大模型从参数竞赛转向效率比拼。无论是量化的精打细算，还是蒸馏的师徒传授，最终目标都是让人工智能轻装上阵，走向各行各业。

1.2 大模型工作机理拆解

随着技术演进，各类大模型以强性能和广应用前景重塑认知。从文生到图像识别，从数据分析到决策支持，大模型在多个领域释放潜力。

本节聚焦大模型的工作逻辑，通过 GPT 等典型代表的工作流程、优势，以及神经网络、Transformer 等关键技术在大模型中的应用，深入了解其强大之处与解决实际问题的能力。

1.2.1 GPT 运行机制全解析

与 ChatGPT 对话时，背后进行的是精密的文字接龙游戏。GPT 本质是训练有素的语言接龙专家，流程如下：

（1）初始输入：完整问题送入系统。
（2）首词预测：系统输出第一个词，如“我”。
（3）语境拼接：将预测词与原始输入组合，如“你的名字是什么？我”。
（4）迭代接龙：持续预测后续词汇，直到对话结束，如图 1-13 所示。

[PRE4]

图 1-13 GPT 模型的对话示例

每个预测都基于概率，系统评估候选词出现概率后优先选择合理者。为避免刻板重复，GPT 引入随机抽样，具体作用如下。

（1）概率扰动：不总是选最高概率词，而是采纳次优选项。
（2）温度参数：调节随机性强度，平衡确定性与多样性。
（3）多样性增强：可生成“这个问题值得深入探讨”，而非千篇一律的“我不知道”。

在持续对话中，GPT 通过动态语境拼接维持连贯，具体作用如下。

（1）会话记忆：将历史对话与当前问题组合输入，如“昨天你说……今天我觉得……”。
（2）长度限制：GPT-3 保留 2048 个 token 的上下文窗口，GPT-4 扩展至 8000 个 token。
（3）注意力聚焦：自注意力机制自动识别关键信息，避免语境过载。

支撑这一游戏的是深度神经网络的 Transformer 架构，使 GPT 能同时处理句首与句尾的隐含关联，实现全局语义理解。GPT 的接龙能力通过海量数据的自监督学习炼成，后续可通过强化学习等技术微调风格与安全性。具体如下。

（1）预测训练：在海量文本中练习预测下一个词。
（2）误差修正：将预测结果与真实文本对比。
（3）参数微调：通过反向传播算法优化神经网络。
（4）迭代优化：在万亿词库中完成知识内化。

每个流畅回答背后，都是千亿次浮点运算的结果。

1.2.2 GPT 为何能一骑绝尘

在大语言模型进化中，2018—2020 年间出现分化。当主流探索监督学习、强化学习时，GPT 在自监督学习中前行，这体现了对语言本质的洞察。

OpenAI 前首席科学家伊利亚·苏茨克维曾说：“神经网络本质上是并行的自动编程计算机。”GPT 不依赖人工标注的标准答案，而是在 45TB 未标注互联网文本中自学成才，其蕴含的语言模式远超人工标注体系。

研究团队用长短期记忆网络预测评论下一个字符，将原始模型改造用于情感分类时取得当时最优效果。研究发现网络中特定单元对情感极性变化高度敏感，为“无监督学习能自动捕获与下游任务相关语义特征”提供了早期证据。

自监督学习为 GPT 注入灵魂，Transformer 为其塑造躯体。相较于传统 LSTM 只能回溯约 512 个词，Transformer 的自注意力实现全局语义捕捉，具体作用如下。

（1）并行计算革命：突破 RNN 序列计算瓶颈，训练速度大幅提升。
（2）注意力可视化：能同时关注“苹果”作为水果和科技公司的双重语境。

成功密码可归纳为：

（1）自监督学习：用预测替代标注，释放数据潜能。
（2）架构创新：用注意力机制突破计算瓶颈。
（3）规模法则：用参数海洋孕育智能岛屿。
（4）涌现设计：用简单规则触发复杂认知。

这种简单与复杂的辩证法，为通用人工智能探索指明方向。

1.2.3 用强化学习补齐大模型的推理短板

GPT-4、DeepSeek 等大模型在对话生成、文本理解中能力惊人，但在逻辑推理、复杂决策上仍显短板，如事实性错误、数学计算偏差或多步逻辑断片。

例如输入“我希望昨天是明天，那么今天就是星期五。今天是星期几？”，GPT 经过长串推理仍给出错误答案，如图 1-15 所示，而正确答案应是星期三。

[PRE6]

图 1-15 GPT 的错误回答示例

针对这些痛点，强化学习成为核心方向。它通过试错-反馈-优化循环让模型自主进化，补上动态决策的关键拼图。

传统监督学习依赖输入-标签明确对应，像学生照标准答案做题，能掌握已知规则却缺乏应对未知的灵活性。强化学习核心是行动-奖励-策略优化，更接近人类实践积累经验，具体如下。

（1）智能体：基于大模型开发的 AI 应用，如 ChatGPT，在特定环境中采取行动。
（2）环境：用户输入、任务规则、外部知识库等一切影响决策的因素。
（3）奖励函数：定义好决策的标准，如回答准确得 +1 分，逻辑错误得 -1 分。
（4）策略：模型根据环境状态选择行动，通过最大化累计奖励不断优化。

以数学推理为例，监督学习可能记住“1+1=2”，但面对“(3×5)-2÷2”时若无完全一致样本易出错；强化学习会尝试分步计算，每步根据中间结果是否符合规则获得奖励，最终学会正确运算顺序。

在大模型领域，强化学习主要用于：

（1）行为对齐：让模型学会听话。以 OpenAI 的人类反馈强化学习 RLHF 为例，核心步骤如下。

收集人类反馈：让标注者对多个回答打分。
训练奖励模型：将人类评分转为可计算奖励函数。
策略优化：用奖励模型指导大模型调整生成策略，减少幻觉、增强逻辑连贯性。

通过此过程，模型不仅记住知识，还能理解人类价值偏好，实现能力与合规双重提升。

（2）复杂决策：让模型在多步推理中走对路。面对法律案例分析、科学实验设计等任务，强化学习帮助模型构建推理链条，其核心步骤如图 1-16 所示。

（1）奖励函数的精准性陷阱。人类反馈模糊或存在偏见，导致奖励函数无法准确反映真实目标，如过度追求回答长度会产生冗长无意义内容。可引入自动奖励模型或对抗性强化学习提升鲁棒性。
