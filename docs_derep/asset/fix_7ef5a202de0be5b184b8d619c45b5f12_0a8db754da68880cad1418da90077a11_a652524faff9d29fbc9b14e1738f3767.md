**把 DeepSeek 部署到本地：一整套能跑起来的实操清单**

把 DeepSeek 模型放到自己的硬件上运行，是同时兼顾个性化定制与数据不出域的常用做法。下面的流程把环境准备、依赖安装、Ollama 获取、模型拉取以及前端设置串成一条线，并配上具体操作演示。照着做就能在自己的机器上稳定运行 DeepSeek，为后续微调与业务化应用打好底。

**2.1.1 部署前的准备工作**

在本地环境里运行，数据全程留在内网，隐私可控；也能直接对接企业内部的知识库和行业数据库，实现更深度的定制。而且借助消费级显卡就能启动，长期下来比订阅云服务更划算。硬件需求随模型规模变化，具体建议如下。

（1）入门档：推荐使用搭载 NVIDIA 显卡且显存不低于 8GB 的设备，足以流畅承载 7B/8B 级别的模型。

（2）高性能档：若要跑 14B 级别模型，建议显卡显存不低于 16GB。图 2-1 展示的 GeForce RTX 5090 D 基于 NVIDIA Blackwell 架构，配有 32GB GDDR7 显存、21760 个 CUDA 核心，显存带宽高达 1792 GB/s，AI 算力非常强劲。

图 2-1 GeForce RTX 5090 D 显卡

**知识扩展**

NVIDIA Blackwell 架构以数学家 David Blackwel（戴维·布莱克维尔）命名，有助于提升可靠性和集群间的通信效率。GDDR7 的全称是 Graphics Double Data Rate 7，是 NVIDIA 与 DRAM 动态随机存取存储器厂商合作推出的超低电压显存标准。

CUDA 即 Compute Unified Device Architecture 统一计算设备架构，是 NVIDIA 的并行计算平台和编程模型，允许开发者使用 C/C++、Python、Fortran 等语言调用 GPU 的并行计算能力。

（3）无独显情况：没有独立显卡也能以 CPU 模式运行，只是速度大约只有 GPU 模式的 20%。

内存建议至少 16GB，处理长文本时推荐 32GB 以保证顺畅。存储预留至少 50GB，可用空间，优先选用 SSD 固态硬盘以加快模型加载速度。

**知识扩展**

Ollama 常用命令及其作用：

（1）serve：启动 Ollama 服务，使模型可接收请求。
（2）create：基于一个 ModelFile 创建模型。ModelFile 是定义模型参数和设定的配置文件。
（3）show：显示模型信息，包括配置、状态等。
（4）run：运行指定模型。
（5）stop：停止正在运行的模型。
（6）pull：从模型仓库拉取模型到本地。
（7）push：将模型推送到模型仓库。
（8）list：列出已下载或可用的模型。
（9）ps：列出正在运行的模型。
（10）cp：复制模型到另一位置或设备。
（11）rm：删除不再需要的模型。
（12）help：显示所有命令的帮助信息。

常用参数：
（1）-h, --help：显示帮助信息，提供命令行工具概述。
（2）-v, --version：显示版本信息。

**知识扩展**

DeepSeek-R1 不同参数版本在性能、适用场景和硬件需求上各有差异，习惯上用大写 B 表示参数规模。

（1）1.5b、7b、8b 版本：参数较少，资源消耗低，适合本地轻量问答或简单 AI 助手。
（2）14b 和 32b 版本：推理能力明显提升，可处理代码补全、数据分析等复杂任务，需高端 GPU。
（3）70b 和 671b 版本：顶尖水平，70b 接近 GPT-4 能力，671b 面向大规模云端推理，硬件需求巨大。

推荐配置：
（1）1.5b：4 核处理器、8GB 内存，无需显卡。
（2）7b 与 8b：8 核处理器、16GB 内存、Ryzen 7 或更高、RTX 3060 12GB 或更高。
（3）14b：i9-13900K 或更高、32GB 内存、RTX 4090 24GB 或 A5000。
（4）32b：Xeon 8 核、128GB 内存、2～4 张 A100 80GB 或更高。
（5）70b：Xeon 8 核、128GB 内存、8 张 A100/H100 80GB 或更高。
（6）671b：64 核、512GB 内存、8 张 A100/H100 80GB 或更高。
