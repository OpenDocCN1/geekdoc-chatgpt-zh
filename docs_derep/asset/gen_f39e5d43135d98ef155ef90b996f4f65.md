最近在复盘一些高频 Python 小练习，从计数、去重到字符串反转，很多问题都能用一两行表达清楚，也容易在细节上踩坑。下面这组片段基本覆盖了这些常见场景，思路沿用，但写法更紧凑，也把容易写错的地方单独拎出来。

先看一个最基础的字符统计。把输入转成小写后，只保留 a e i o u 这五个元音，再用生成式累计出现次数，逻辑直接、性能也够用。
[PRE0]python

def count_vowels(s):

    vowels = "aeiou"

    return sum(1 for char in s.lower() if char in vowels)

合并两个列表并去重是列表处理的经典需求。先把两个序列拼接成一个，再用集合去掉重复元素，最后排序输出。若想保留相对出现顺序，也可以改用 dict.fromkeys 的技巧。
[PRE1]python

def merge_unique(list1, list2):

    merged = list1 + list2

    return sorted(set(merged)) # 或保留顺序的写法：sorted(list(dict.fromkeys(merged)))

字符串反转经常被拿来练手，下面这个循环版本就是典型错误示范。range 从 len(s) 开始往回走，第一步索引就越界，而且 s[i] 在 i=0 时会取到最后一个字符之前的空位，实际运行会报错或结果不完整。
[PRE2]python

def reverse_string(s):

    reversed_s = ""

    for i in range(len(s), 0, -1):

        reversed_s += s[i]

    return reversed_s

正确的等价写法可以用切片一步到位，也可以用修正后的循环范围。切片 s[::-1] 可读性最好，手动循环的话索引应该从 len(s)-1 开始到 -1 结束。
[PRE3]python

def reverse_string(s):

    return s[::-1] # 或修正循环索引为 range(len(s)-1, -1, -1)

筛选偶数并求平方也很常见。遍历列表，判断 num % 2 == 0 成立时把平方追加到结果。这里最后的 return result if len(result) > 0 else [] 其实多余，因为 result 初始化就是空列表，始终可以直接返回。
[PRE4]python

def square_evens(numbers):

    result = []

    for num in numbers:

        if num % 2 == 0:          # 行 1

            result.append(num ** 2)    # 行 2

    return result if len(result) > 0 else []  # 行 3

最后是从一段混排文本里把数字字符挑出来求和。利用 str.isdigit 判断每个字符是否可转整，生成式收集后直接求和，适合处理类似订单号、身份证号中的数字累加需求。
[PRE5]python

def extract_numbers(s):

    digits = [int(char) for char in s if char.isdigit()]

    return sum(digits)
