# 第8章 学以致用：从预训练到微调的完整链路

预训练模型的成长通常分两步走。预训练阶段，模型在海量未标注文本上做无监督学习，沉淀语言的通用规律与语义能力；微调阶段，则在少量标注的特定任务数据上继续优化，把通用能力转化为任务能力。两者结合，既有大数据的泛化底座，又有针对任务的精准校准。

> 学而时习之，不亦说乎。

这句《论语》精准概括了这一过程。预训练相当于“学”，微调相当于“时习”，通过在具体任务上反复练习，模型才能真正掌握并运用知识。没有持续的实践，学到的知识难以转化为能力。

## 8.1 预训练与微调核心概念

预训练模型是指已在大规模语料上完成初步训练的基础模型，比如DeepSeek开源的DeepSeek-V3、DeepSeek-R1等，它们在多个下游任务上具备很强的基础表现。预训练和微调是深度学习落地中的关键环节。

举个例子，如果你要做一个智能写作助手，可以先基于DeepSeek-V3这类预训练模型，再针对写作需求进行训练和微调，让它更懂风格、更会组织表达，如图8-1所示。

### 8.1.1 预训练阶段解析

预训练是在通用大数据上让模型学会数据通用的表征，例如语言的语法、词义关联，或图像的纹理、形状等。

#### 1. 目标
让模型掌握可迁移的通用表征，为后续任务提供坚实基础，提升泛化与适应性。

#### 2. 主要步骤
- 选择模型架构：如BERT、GPT、CLIP等。
- 准备数据：选用维基百科、书籍语料等大规模通用语料。
- 模型训练：采用无监督或自监督方式学习通用特征。
- 权重保存：保留预训练权重供后续复用。

#### 3. 技术方法
- 掩码语言建模MLM：随机遮挡部分词，让模型去预测。
- 因果语言建模CLM：依据已生成内容预测下一个词。
- 对比学习：如CLIP，通过图像文本配对的对比学习对齐多模态表示。

#### 4. 优点
- 泛化强：大样本训练带来跨任务迁移能力。
- 省资源：免 buiten 从零训练，可直接作为起点。

### 8.1.2 微调阶段解析

微调是把预训练模型迁移到具体任务的过程，在任务数据上继续训练以提升专项表现。

#### 1. 目标
让模型适应特定场景，例如把BERT用于文本分类，使其更敏感于类别特征。

#### 2. 主要步骤
- 加载预训练权重。
- 冻结部分层，保留通用表征。
- 按需添加分类头、回归头等自定义层。
- 调整学习率、优化器等超参数。
- 用任务数据训练并更新权重。
- 用验证集评估，防止过拟合。

#### 3. 技术方法
- 全量微调：更新所有参数，适合数据充足。
- 选择性微调：仅更新部分层，适合数据稀缺。
- 数据增强：通过变换扩充训练样本。
- 早停：验证指标不再提升时终止训练。
- 学习率调度：逐步降低学习率实现精细收敛。

#### 4. 优点
- 精度更高：在特定任务上更准确。
- 成本更低：相比从零训练，计算开销大幅下降。

### 8.1.3 两者要点对比

表8-1 预训练与微调的对比

| 特性 | 预训练 | 微调 |
| :--- | :--- | :--- |
| 目标 | 学习通用特征，泛化到多种任务 | 适应特定任务，提高特定任务的性能 |
| 数据集 | 大规模通用数据集 | 特定任务的数据集 |
| 训练方法 | 无监督或自监督学习 | 监督学习 |
| 模型更新 | 更新所有层和参数 | 更新部分层或所有层，根据任务需求 |
| 计算资源 | 需要大量计算资源 | 计算资源需求较少 |
| 适用场景 | 通用特征学习，适用于多种下游任务 | 特定任务，如文本分类、问答、图像分类 |

### 8.2.1 实例概览

该实例基于PyTorch Lightning实现，主要功能如下。

- 支持从头训练和微调两种模式。

整体流程遵循CLIP自监督原理，通过最大化图像文本相似度学习语义关系。
