# Excel + AI 财务日常实战

# **内容简介**

本书定位为面向财务实务的入门级 Excel 指导书，重点讲清如何借助 Excel 完成日常会计与财务的工作流程。同时整本书引入 DeepSeek 这款 AI 工具，用来配合 Excel 进行数据清洗、数据分析与计算，提供定制化解答和建议，从而把学习门槛降下来。

全书覆盖财务数据录入与编辑、整理与分析、常用函数公式计算、财务部门高频表单、公司行政费用支出管控、填制记账凭证并自动记入日记账、往来账款管理与账务处理、进销存数据管理与账务处理、员工薪酬数据管理与账务处理、固定资产管理与折旧计提、月末结账与总账建立、财务报表编制以及财务分析等内容。

随书提供案例教学视频、源文件与 PPT 课件，读者可通过书中二维码及封底的文泉云盘二维码在线学习并下载素材。

本书适合希望提升 Excel 应用能力的财务从业者，尤其对初入职场或即将入职的新人友好，也可作为高校相关专业的参考资料。
