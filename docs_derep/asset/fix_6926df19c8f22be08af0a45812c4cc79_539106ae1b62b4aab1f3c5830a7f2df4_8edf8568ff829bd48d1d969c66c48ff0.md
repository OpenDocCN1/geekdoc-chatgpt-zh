**3.4.1 让AI打助攻，别让它代打**

AI真正的意义是把学习推得更顺，而不是直接把成品递到手里。只习惯让它给出整段程序或标准答案，看似把任务完成得快、省了力，实则把最能长本事的环节一起丢了。推导算法时卡住、反复梳理直到思路通畅的那段体验，是让知识扎根的关键；调试时通过试错积累的敏感，会让以后更快定位问题；拆解题目时不断自问，是解题能力形成的根基。这些思考的累积，才是从懂概念到能实现的能力跃迁。一旦跳过，学习效果会大幅打折。

要明白，编程学习的成果不是做题的数量，而是逻辑、设计与实现等核心素养是否掌握。每次直接拿答案用，看似轻松，实则偏离了学习的本质，不仅学不到真本事，到了没有辅助的考场和竞赛现场就会没底气。只有把能力练成自己的，才靠得住。

**3.4.2 先自己冲，再让AI补位**

碰到难题时，先给自己一段时间独立琢磨。把需求拆开，结合已学知识梳理可能的思路，再尝试推演算法走向。即使卡住也别急着求助，先在草稿纸上画流程、写几行伪代码，尽量靠自己突破。实在没有方向、思考到瓶颈时再请AI帮忙，而且要明确索要思路提示，而不是现成成品。

比如可以问AI在处理边界情况时通常会关注哪些情形，为什么会优先考虑它们，背后的判断逻辑是什么。把自己的思考与AI的讲解对照，把没覆盖到的点补齐，这样AI才是辅助独立思考的工具，而不是被动接受结果的替代品。

**3.4.3 学会看AI是怎么想的**

做到上面两点，很大程度上取决于提问方式。若想用AI理解算法思路，可以这样问。 [PRE0]
分 3 步拆一拆最短路径问题的 Dijkstra 算法思路，说一说每一步的核心逻辑和为什么这么设计，不用直接给代码。
若想让AI帮忙排查程序，可以这样问。 [PRE1]
我的代码在遍历数组时报错了，请先分析一下可能导致这个错误的 3 类常见原因，再说一说怎么一步步排查。
这种指向明确、要求具体的提问，能让AI给出更有价值的内容。更关键的是，组织问题本身就是梳理需求、明确目标的训练，也是独立思考的练习。

由此可见，提问的好坏直接决定AI能否真正助益提升。下一章将聚焦信息学奥赛学习中的关键环节——如何写好提示词，只有指令合理，AI才会成为提升能力的帮手，而不是让人变懒的拐杖。

**第四章 提示词 Prompt：与 AI 沟通的钥匙** [PRE2]

小贴士：
阅读本章时，建议先准备常用的智能模型，如豆包和 DeepSeek。看到“ [PRE3]Prompt”标识时可实操感受效果。电子版 Prompt 的获取方式见 5.3 节。

**4.1 认识 Prompt**

**4.1.1 Prompt 的本质**

Prompt本质上是一种注入式指令，是开启与AI交互的入口。它能触发回应、引导对话走向、影响最终输出，也能通过预设思考框架指挥模型如何分析、如何组织内容。核心目的就是用精准的指令或问题，让模型生成更贴合预期的结果。

在这个AI已成日常的时代，豆包、DeepSeek、元宝这些名字并不陌生。每天可能会用它们构思作文、解数学难题、把报错程序丢进去求助、整理单词。简单说，Prompt就是输入给模型的话术，也就是你平时问它的那些问题，用来告诉它想要什么、引导它输出什么，是沟通的桥梁。

Prompt的尺度差异很大。最简单的像随口一问，如学生常问： [PRE4]
C++中数组下标为什么从 0 开始。
复杂的则像一份任务清单，比如： [PRE5][Prompt 请帮我设计一个信息学奥赛中二分查找算法的学习方案。具体要求：1.用生活场景类比二分查找原理。2.包含 C++代码实现。3.设计两道练习题，适合中小学生理解。]

模型是如何读懂Prompt的？原理很复杂，粗略理解就像和同学讨论：先听清需求。输入后，模型会拆解文字、抓取关键词如二分查找、生活场景类比、C++代码、中小学生，理解真实意图，再调取相关知识，结合上下文组织输出，最后返回结果。

举个熟悉的例子：调试C++程序卡了半小时，打开豆包输入以下Prompt。 [PRE6][Prompt 帮我看一看这段代码为什么在运行时会崩溃？] [PRE7]
模型会先识别“运行时崩溃、代码片段”这些信息，调用对C++数组越界的认知，指出数组a的大小为3，下标最大是2，访问a［5］越界导致内存错误。正因为Prompt包含了具体现象和代码，模型才能快速定位问题。这就是Prompt在交互中的核心作用：描述越清晰，协助就越到位。

**4.1.2 写好 Prompt 是新时代的核心能力**

有人会说，不就是输入一段话吗，随便写不行吗？其实不是。体验过就会发现：同样的需求，模型有时答非所问，给出一大段理论看得云里雾里，有时又精准命中，连没说出口的细节都考虑到了。差别就藏在输入的Prompt里。

对信息学奥赛学习者而言，无论是掌握C++基础、刷题复习还是备赛，高质量的Prompt能让效率翻倍。价值主要体现在三方面。

1.提升效率：少走弯路，省下时间
比如整理语文笔记，只输入： [PRE8]
整理课文《背影》的知识点。
模型会把主旨、作者生平、段落大意全堆出来，需要你再筛选。若换成： [PRE9][Prompt 帮我整理《背影》的 3 个核心知识点：按父亲言行细节→情感表达→写作手法整理。每个知识点都配备 1 个课文原句例子，重点标注细节描写相关内容。]
生成的笔记就能直接用，省去反复修改。
在奥赛学习中，让模型出动态规划练习题，若只说： [PRE10]
出几道动态规划编程题。
很可能得到大学难度或面试题。若输入： [PRE11][Prompt 出 2 道适合信息学奥赛练习的线性 DP 题，要求包含题目描述、输入/输出样例和解题思路提示。]
题目就能直接进入练习计划，无需再调难度。好Prompt就像导航，让模型直奔目标。

2.实现个性化定制：打造专属学习助手
学习节奏各不相同。学一元二次方程，有人要补因式分解基础，有人想挑战含参讨论；练编程，小学生需要积木比喻，竞赛选手需要复杂度分析。模型通用，Prompt专属。
比如讲解循环：
小学生： [PRE12][Prompt 请你用生活化的例子告诉我 for 循环的执行机制，不用写代码，要用小学生也能听懂的话。]
竞赛选手： [PRE13][Prompt 分析模拟退火算法中温度参数的循环调整逻辑，用伪代码表示温度从初始温度 T0 下降到最终温度 Tf 的过程（T=T0*0.95^k，k 为迭代次数），并说明循环终止条件的设计对算法结果的影响。]
不同的Prompt给模型不同剧本，让输出更贴合身份与目标。

3.拓展应用边界：成为探索新知的脚手架
模型不再只是答题机器，可梳理时间线、辅助调试、设计实验、分析真题趋势。要发挥这些作用，Prompt是前提，能把工具变成探索知识的支架。
比如C++知识点零散时，可问： [PRE14][Prompt 帮我用表格的方式对比一下 C++中的数组、字符串、指针，讲解它们之间的转换关系。]
会得到结构化表格，帮助融会贯通。
再如函数参数传递： [PRE15][Prompt 请对比讲解 C++中值传递和引用传递的区别，包含定义说明、内存分配差异、对实参的影响 3 个维度，并用代码示例分别演示这两种传递方式的效果，重点标注引用传递时形参前的“＆”符号的作用。]
卡在最短路径时，可输入： [PRE16][Prompt 我刚学完图的存储、邻接矩阵和邻接表，想入门最短路径算法，请帮我设计一个 3 步学习计划：第一步，推荐 1 个适合初学者的算法，用城市间修路的例子讲解原理。第二步，给出一段简化的 C++代码，只保留核心逻辑，注释关键步骤。第三步，出 1 道入门级练习题。]
模型就像教练，引导你逐步深入，而不是直接丢手册。

总之，Prompt只是段文字，却藏着沟通密码。学会清晰、具体地下指令，能省时、定制内容、打开新可能。下次对话前花一分钟自问：需求说清楚了吗？模型往往会因此“懂你”。

**4.2 如何构建优质 Prompt**

什么是优质Prompt？通过几个生活学习场景来看标准与优化方法。

1.标准一：目标具体，明确要做什么 [PRE17]
帮我写一篇五年级课外阅读分享发言稿。
修改建议：任务不能模糊，需说明类型、场景、受众。修改后： [PRE18][Prompt 帮我写一篇小学五年级语文课外阅读分享的发言稿，受众是同班同学，核心是分享《少年中国说》这本书，时长为 3～5 分钟，内容需要包括时代背景、作者的创作目的及全书的中心思想。]

2.标准二：结构清晰 [PRE19]
帮我设计一个三年级主题班会方案。
修改建议：用分层逻辑组织需求，明确任务与要求。修改后： [PRE20][Prompt 帮我设计小学三年级“交通安全主题班会”方案，需包含 3 个部分：1.流程（20 分钟，3 项内容：看安全视频、3 个学生分享过马路的注意事项、班长总结）。2.准备物品（视频、3 张安全标语卡片）。3.班会目标（让学生知道红灯停、绿灯行，不横穿马路）。]

3.标准三：信息完整，细节足够具体 [PRE21]
帮我改一下这道数学应用题。
修改建议：补充任务细节。修改后： [PRE22][Prompt 帮我修改七年级数学应用题的解题过程：1.题目：商店将进价为 120 元的商品按标价的 8 折出售，仍可获利 10%，该商品的标价是多少元？2.原题解错为：“120×10%+120=132，132÷80%=165”。3.指出解题出错的点是什么，具体是哪一步的问题。4.给出正确的解题步骤和每步说明，需要标注易错点，格式按“分步算式、每步说明”两列呈现。5.从数学老师的视角进行做错题目的归因分析，如出现错误可能与哪些知识点没掌握有关，并总结几点后续的提升建议。]

4.标准四：风格与格式明确 [PRE23]
帮我写一个“探究植物光合作用”的科学实验报告。
修改建议：明确文体、语言要求与输出模块。修改后： [PRE24][Prompt 帮我写初中八年级“探究植物光合作用需要光”的科学实验报告，需满足：1.写作风格采用说明文文体，语言正式、书面化。2.用词准确，全程不用口语化表达和网络词语，表述严谨（如不用“大概”“约”等模糊表达）。3.输出格式：全文 600 字左右，必须包含 6 个固定模块，每个模块单独成段且标注标题。1）实验名称（居中）。2）实验目的（说明探究核心）。3）实验器材（分点列出：实验选用植物，实验用具为黑纸片、酒精等）。4）实验步骤（用 1.、2.、3.序号分点，每一步写清楚操作动作）。5）实验现象（描述遮光与未遮光部分的颜色差异）。6）实验结论（明确光合作用与光的关系）。]

从案例可见，优质Prompt有四个核心原则：任务目标具体明确，避免模糊宽泛，需界定场景、人群、核心内容、时长字数等约束；结构清晰，用分点编号组织需求；信息完整，提供背景与关键数据；风格格式明确，确保输出可控。低效Prompt多因需求模糊、细节缺失，导致输出偏差、反复修改。遵循“目标具体、结构清晰、信息完整、风格格式明确”才能让模型稳定达标。

**4.2.1 先把指令讲清楚**

写Prompt时，指令的清晰度就像给船定航向。模糊的说法会让模型靠猜测，输出自然偏离预期。
