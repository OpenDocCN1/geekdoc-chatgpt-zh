下面用纯 NumPy 演示一个不依赖框架的循环网络实现。参数先在 0 到 1 区间均匀抽样，隐藏单元激活函数采用 Sigmoid。每一轮迭代先在训练集和验证集上各走一次完整的时序展开，计算均方误差并输出；随后按设定的裁剪阈值限制梯度幅度，并以截断反向传播的方式更新三组权重。训练收敛后在验证数据上重新推演，绘制绿色预测曲线与红色真实曲线做视觉对比，并用均方根误差给出量化评判。
