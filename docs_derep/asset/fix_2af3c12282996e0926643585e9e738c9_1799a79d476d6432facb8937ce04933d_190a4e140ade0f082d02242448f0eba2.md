> 知识链接：

常见的数据接入路径大致有三种。

（1）本地文件接入：常见的格式有 TXT、CSV、XLSX 等。

（2）网页数据接入：填入网址链接即可拉取页面承载的数据。

（3）数据库接入：建立与多种数据库的连接，直接提取所需内容。

Power Query 对数据的处理可概括为三步：抓取→整理清洗→输出。

（1）抓取阶段：通过 Power Query 与各类数据源建立连接并把数据拉进来，比如数据库、文本文件、Excel 表格等，提供的连接方式和数据源类型相当丰富。

（2）整理清洗阶段：对已抓取的数据进行清理、转换、规范化等操作，例如去掉不需要的列或行、调整数据类型、填补缺失值、处理异常、合并多表、透视或逆透视等。Power Query 具备强大的转换能力以应对不同需求。

（3）输出阶段：把整理好的数据发送到目标位置，例如 Excel 工作表、Power BI 等工具，以便后续分析和可视化。Power Query 支持导出到多种目标，并可灵活指定输出方式和格式。

## 任务二 Power Query 数据的清洗

### 子任务 1：更改数据类型、删除空值

Power Query 提供了丰富的数据清洗与修复功能，可处理脏数据、重复数据、缺失数据等问题。在分析与可视化之前，需先对导入的数据进行清洗，检查重复、空值等。以任务一的子任务 2 导入的数据为例，“学生学号”列明显存在问题。

操作过程：

（1）在 Power Query 编辑器中选中“学生学号”列右键，选择“更改类型”→“文本”，如图 8-10 所示。再右键“学生学号”列，选择“删除重复项”，确保学号唯一。

> 小提示：

Power Query 编辑器右侧“查询设置”窗格中的“已应用步骤”区域会记录每一步清洗操作。若操作失误或想回退，只需在对应步骤名称左侧点“×”即可删除该步骤。

[PRE8]

（2）点击“学生学号”列右侧的下拉按钮，检查是否存在空值，若下拉菜单中出现“null”，则说明有空值，需按实际情况修正，如图 8-11 所示。同理可检查其他列并进行修正。

[PRE9]

> **小提示：**

请谨慎使用下拉菜单中的“删除空”命令。例如，若在“学生学号”列直接选择“删除空”，会整行删除学号为“null”的记录，但该行其他字段可能是有效数据，只是学号漏填，直接删除会导致数据丢失。

知识链接：

Power Query 中常用的清洗与修复手段如下。

- （1）数据过滤与筛选：按条件筛选数据，剔除不需要的行或保留符合特定规则的数据。
- （2）数据排序：按列值对数据排序，支持升序降序，也可多列同时排序。
- （3）列重命名与合并：可对列进行重命名，使命名更清晰；也可将多列合并成新列，生成复合字段或计算字段。
- （4）数据类型转换：可识别并转换列的数据类型，如文本转数值、日期转文本等，保证后续计算正确。
- （5）数据去重：识别并删除重复值，可按一列或多列去重，并选择保留首条、末条或其余值。
- （6）缺失数据处理：可填充缺失值、删除含缺失值的行，或按规则插值，如用邻近值或均值。
- （7）错误数据处理：可筛选出错误类型数据，替换为指定值或修正。

除上述功能外，Power Query 还支持拆分列、提取文本信息、填充空白单元格等，用户可按需选择，以提升数据质量与可信度。
