#### 1.1.4 Prompt 设计与上下文学习

Prompt 设计和上下文学习是 LLM 尤其是 GPT 类模型里非常关键的能力，让模型在理解任务和产出结果时更灵活、更高效。借助精心构造的提示词，模型无需重新训练即可胜任多种任务。

##### 1. Prompt 工程的核心含义
Prompt 本质上是对模型输入的提示语，用一段文字或上下文来描述任务，引导模型执行。简单说就是对模型下指令，通过调整指令的表达让输出更符合预期。好比请图书管理员推荐书，直接说“我想看科幻，请推荐一本”，这句话就是 Prompt，它明确了任务背景和目标。

##### 2. Prompt 的基本构成
一个有效提示通常包含三类要素：

- 任务描述：清晰说明要完成什么，比如“请推荐一部电影”。
- 背景信息：补充必要的上下文，比如“用户偏好动作和冒险类型”。
- 示例内容：用少量样例帮助模型对齐格式，比如“输入：喜欢科幻小说。输出：《三体》”。

实际设计时要结合任务类型和数据特点灵活调整，例如在推荐场景中可直接把用户行为和偏好特征嵌入提示里。Prompt 工程的整体流程见图1-9，分为提示模板、生成式 AI 与结果提取三步。

##### 3. 上下文学习：让模型读懂更多信息
上下文学习是 Prompt 工程的延伸，通过提供更丰富的背景信息，让模型更准确地理解输入并生成合理输出。上下文可以是用户历史行为、物品描述或任务要求等，模型据此捕捉复杂的依赖关系。在推荐中，如果用户连续浏览多部科幻片，上下文学习就能识别出对科幻的偏好并给出相关推荐。可以把上下文看作模型的“背景知识”，有了它，推理会更贴近真实需求。

##### 4. 案例拆解：美食推荐
假设模型扮演智能餐厅助手，用户问“推荐一家适合家庭聚餐的餐厅”。没有上下文时只能按字面匹配，有了上下文比如“近期多次浏览中餐馆并预订了6人座”，模型就能推断出偏好中餐且需要大桌位，从而推荐合适的多人用餐中餐厅。

这种能力显著提升了推荐系统的灵活性，使其可以动态响应用户意图。

##### 5. 上下文学习的常见落地
- 个性化推荐：把用户历史行为作为上下文输入，输出更贴合兴趣的结果。例如用户近期频繁搜索旅游景点，可推断出行意图并推荐攻略。
- 问答系统：在多轮对话中保留上下文，保证回答连贯。例如先问“适合带孩子的景点”，再问“附近有亲子套餐的餐厅吗”，模型需要利用前文理解需求。
- 动态广告生成：依据浏览行为和点击记录生成个性化文案。例如用户近期看智能手表，系统可生成“新款智能手表限时优惠，立即抢购”。

Prompt 工程与上下文学习把大模型的潜力发挥到极致，通过精准描述任务和丰富背景信息，让模型在各类推荐场景中展现出更强的智能与适应性，也为现代推荐系统注入了动态响应能力。

#### 1.1.5 计算性能优化与并行训练技术

要让模型在真实场景中高效运行，计算性能优化和并行训练是关键。通过这些技术可以加快训练、降低推理耗时并充分利用硬件资源。

##### 1. 计算性能优化：让模型更高效
目标是提升模型在硬件上的运行效率，减少训练时长、降低推理延迟并节省算力。

###### 1) 混合精度训练
利用 FP16 替代部分 FP32 计算，在不明显损失精度的前提下减少计算量和显存占用。可类比做数学题时用精简公式，小数点后取 5 位而非 10 位，既省时间又保持结果可信。

###### 2) 模型剪枝与量化
剪枝是移除冗余参数以减小模型规模，量化则是把权重从 32 位压缩到 8 位等低精度，进一步降低存储和计算成本。就像果树上剪掉不结果的枝条，让整棵树更易维护更高效。

###### 3) 缓存优化
推荐系统中用户行为和物品特征计算成本高，缓存热点数据可避免重复计算。例如用户多次搜索同一商品时，直接返回缓存结果即可。

##### 2. 并行训练：加速模型训练
把计算任务分摊到多 GPU 或多机上，可显著提升训练速度。

###### 1）数据并行
把大批量数据切分为小批，分配到多设备上独立计算梯度，再在主设备汇总并更新模型。类似于把 1000 件商品分到多个车间同时加工，最后汇总结果。

###### 2）模型并行
把模型的不同部分部署到不同设备，前半段在一块 GPU 运行，后半段在另一块运行。适用于单卡无法加载完整模型的超大模型。

###### 3）流水线并行
结合数据与模型并行，把数据流和计算拆成多个阶段，每个阶段由不同设备负责。例如汽车生产线上组装、喷漆、检测由不同工位串联完成。

###### 4）梯度累积
显存不足时，用多个小批次累积梯度后再更新，类似存钱罐里攒零钱攒够数额再存入银行。

##### 3. 案例拆解：优化推荐系统性能
假设视频平台需为全球用户实时推荐，面临数据量大、需求变化快的问题。可采用：

- 混合精度训练降低训练成本，快速跟上用户行为变化；
- 缓存热点视频特征，减少重复计算，提升推荐速度；
- 多 GPU 分布式训练处理海量行为数据，缩短训练周期。
