**6．定制化能力**

**1）模型微调技术**

不同行业和场景对模型存在特定需求，DeepSeek 提供强大的模型微调能力。低资源微调 LoRA、增量学习、梯度检查点机制与分布式训练框架协同工作，为用户提供高效定制方案。

LoRA 是一种高效参数微调方法，可在有限资源下完成模型微调，降低成本与门槛。传统全量微调成本高、硬件要求高，LoRA 通过训练少量新增低秩参数，使中小型企业可用普通 GPU 实现特定应用。

增量学习让模型在保留已有知识的基础上持续学习新数据，避免“灾难性遗忘”。智能客服可借此提升回答的准确性与全面性。

梯度检查点机制通过选择性存储中间结果并在反向传播时重算前向传播，降低深层网络训练的内存占用，避免因内存不足中断大规模语言模型训练。

分布式训练框架将模型与数据分发至多节点并行计算，支持多种并行策略，显著缩短大型图像识别等模型的训练时间。

在垂直领域，微调技术应用广泛。例如法律领域可利用 LoRA 微调处理专业任务并扩充词表，结合增量学习不断完善能力；多语言处理场景下，可借助梯度检查点与分布式训练在有限资源下训练高性能模型。

**2）效果评估**

为验证微调有效性，DeepSeek 开展系列测试。结果显示，微调后模型在多任务学习准确率提升 15%～30%，文本分类准确率由 70% 提升至 85%，新闻分类更加精准；LoRA 等低资源方法仅训练少量参数，计算量与硬件需求大幅下降，成本降低约 80%；推理延迟减少 40%，更利于实时应用；资源占用与硬件成本显著下降，性能与稳定性同步提升。整体来看，该技术可为企业提供高效低成本的定制路径。
