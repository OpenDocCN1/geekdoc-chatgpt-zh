- Top-P 用来限定单次生成时采样的概率累积窗口。举例将 Top-P 设为 0.7，模型仅在累计概率最高的前 70% 词表中抽样。数值越高，输出越发散、创意越强，但偏离预期的可能性也越大；数值越低，输出越收敛、更贴合指令。
- Top-K 通过限制候选词数量来调控多样性。设为 50 即只在概率前 50 的词里挑选。K 越大，语言通常更流畅自然；K 越小，可控性提升，但容易出现重复或生硬感。
- Frequency Penalty 用来抑制高频重复。设为 0 时不做惩罚，重复表达更常见；提升数值后重复率下降，文本新鲜度提高。

三项参数可以协同实现对输出风格的精细调节，满足拉长篇幅、增强创意或追求准确少冗余的需求。

#### 5.2 DeepSeek本地部署
大语言模型已在各行各业普及，但多数以云服务形式由大厂提供，限制了深度研究与个性化改造。银行若把客户数据上传云端分析，相当于把金库钥匙交给第三方；网络不稳地区每次提问都受连通性制约；初创团队想做专属系统，商业 API 却像租赁房屋难以随意改造。正因如此，本地化部署成为越来越多团队的选择。

##### 为什么要选择本地部署大模型？
- 隐私与安全：敏感数据无需外发，全程本地处理，降低泄露风险。
- 响应更即时：省去网络传输，推理延迟明显下降，体验更流畅。
- 定制与可控：可按需微调与优化，灵活度大幅提升。
- 成本更可控：前期硬件投入后，长期使用成本远低于持续付费的云服务。
