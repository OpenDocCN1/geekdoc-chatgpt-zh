# 逻辑基石：从命题到谓词，再到产生式系统的知识表示全景

## 2.1 命题逻辑：推理的基础语法

### 核心联结词与真值判定

在命题逻辑的世界里，复合命题的真假完全取决于基础命题的真值及连接符的规则。我们重点掌握五大核心联结词：

1.  **否定 (¬)**：真假互换。P 为真，¬P 即为假；反之亦然。
2.  **合取 (∧，即“且”)**：皆真才真。只有当 P、Q 同时为真时，P∧Q 才成立，否则为假。
3.  **析取 (∨，即“或”)**：一真则真。只要 P、Q 中有一个为真，P∨Q 即为真；仅当两者皆假时才为假。
4.  **条件 (→，即“蕴涵”)**：真不推假。这是最反直觉却最关键的规则：**仅当前件 P 为真、后件 Q 为假时，整个命题 P→Q 才为假**；其余三种情况（真→真、假→真、假→假）均为真。
5.  **双条件 (↔，即“等价”)**：同真同假。P、Q 真值一致（同真或同假）时为真，不一致时为假。

**真值速查表（表 2.1）**

| P | Q | ¬P | P∧Q | P∨Q | P→Q | P↔Q |
|---|---|---|---|---|---|---|
| T | T | F | T | T | T | T |
| T | F | F | F | T | F | F |
| F | T | T | F | T | T | F |
| F | F | T | F | F | T | T |

### 等价与蕴涵：判断公式关系的标尺

*   **等价 (⇔)**：两个公式 A、B 拥有相同的变元。若在**所有**可能的真值赋值下，A 与 B 的真值完全同步，则称二者等价。
*   **蕴涵 (⇒)**：若条件式 P→Q 是**永真式**（即在所有赋值下均为真），则称 P 蕴涵 Q。这意味着 P 为真时，Q 必为真。

### 必背工具箱：常用等价变换定理

掌握这些定理，是化简公式、证明等价的“瑞士军刀”：

*   **双重否定** [PRE0]
*   **分配律** [PRE1]
*   **幂等律**：P∨P ⇔ P；P∧P ⇔ P
*   **交换律**：P∨Q ⇔ Q∨P；P∧Q ⇔ Q∧P
*   **结合律**：(P∨Q)∨R ⇔ P∨(Q∨R)；(P∧Q)∧R ⇔ P∧(Q∧R)
*   **吸收律**：P∨(P∧Q) ⇔ P；P∧(P∨Q) ⇔ P
*   **德摩根律**：¬(P∨Q) ⇔ ¬P∧¬Q；¬(P∧Q) ⇔ ¬P∨¬Q

### 推理利器：蕴涵相关定理

*   **假言推理**：P ∧ (P→Q) ⇒ Q（经典的“肯定前件”推出后件）
*   **假言三段论**：(P→Q) ∧ (Q→R) ⇒ P→R（链式传递）
*   **化简式**：P∧Q ⇒ P / Q（合取可拆解）
*   **附加式**：P ⇒ P∨Q / Q ⇒ P∨Q（可自由引入析取）
*   **条件转化**：
    *   P→Q ⇒ ¬P∨Q（蕴涵等价于“非前件或后件”）
    *   ¬P ⇒ P→Q（前件为假，蕴涵必真）
    *   Q ⇒ P→Q（后件为真，蕴涵必真）

### 实战演练：自然语言转逻辑公式（例 2.1）

**场景**：用 P=下雨，Q=下雪，R=去学校 形式化表达四句话。

1.  “非雨夹雪则去校” → ¬(P∧Q) → R
2.  “不雨且不雪则去校” → ¬P ∧ ¬Q → R
3.  “雨或雪则不去校” → P ∨ Q → ¬R
4.  “雨雪无阻必去校” → (P∧Q∧R) ∨ ¬(¬P∧Q∧R) ∨ (P∧¬Q∧R) ∨ ¬(¬P∧¬Q∧R)
    *   *解析：此式穷举了四种天气组合（雨雪、不雨雪、雨不雪、不雨不雪）均去学校的情况，体现了“全称量词”的逻辑内核。*

## 2.2 谓词逻辑：穿透命题表象，看清对象结构

命题逻辑把原子命题视为不可分割的黑盒，而**谓词逻辑**打开了盒子，引入**个体**（对象）与**谓词**（属性/关系），实现了表达力的质变。

### 1. 核心概念：谓词 = 谓词名 + 个体项

*   **例**：“李明是学生” → `Student(LiMing)`
    *   `LiMing`：个体常项（具体对象）
    *   `Student`：一元谓词（属性）
*   **计算机视角**：谓词本质是返回布尔值（真/假）的条件表达式求值过程。

### 2. 谓词公式（合式公式 WFF）的构造规则

按优先级从高到低：`¬` > `∧` > `∨` > `→`。

1.  **原子公式**：P(t₁,...,tₙ) 及其否定。
2.  **复合公式**：若 A、B 为公式，则 ¬A、A∨B、A∧B、A→B 均为公式。
3.  **量化公式**：若 A 为公式，x 为个体变元，则 (∀x)A（全称量词）和 (∃x)A（存在量词）均为公式。

**关键术语区分**：
*   **开公式**：含自由变元（未被量词约束）。
*   **闭公式/语句**：无自由变元，可直接判定真假。

### 3. 知识表示三步法（标准化动作）

1.  **定义谓词与个体**：明确每个符号的语义边界。
2.  **实例化赋值**：将具体对象代入谓词变元。
3.  **联结成式**：按自然语言语义，用联结词、量词组装公式。

### 4. 谓词公式的语义性质（三大核心）

*   **永真/永假/可满足**：针对**所有非空个体域**及**所有解释**（赋值）的表现。
    *   永真：处处为真。
    *   永假：处处为假。
    *   可满足：至少存在一个解释使其为真。
*   **等价 (⇔)**：在共同个体域上，一切解释下真值相同。
*   **永真蕴涵 (⇒)**：P→Q 永真，即 P 逻辑推出 Q。

### 5. 经典建模实战（例 2.2 & 2.3）

**例 2.2**：
*   “武汉美丽非沿海” → `BCity(wuhan) ∧ ¬HCity(wuhan)`
*   “马亮男、张红女 → 马更高” → `[Boy(mal) ∧ Girl(zhangh)] → High(mal, zhangh)`

**例 2.3（数学定义建模）**：
*   自然数 ⊂ 正整数：`(∀x)(N(x) → GZ(x) ∧ I(x))`
*   整数非奇即偶：**注意原文此处逻辑或应为 ⊕ (异或) 或互斥，但原文用 ∧，此处忠实还原**：`(∀x)(I(x) → E(x) ∧ O(x))`
*   偶数除 2 得整数：`(∀x)(E(x) → I(S(x)))`

### 6. 一阶谓词逻辑：优势与阿喀琉斯之踵

| **四大优势** | **三大短板** |
| :--- | :--- |
| **严密性**：演绎正确有保障 | **效率低**：推理链长，表达越细推理越慢 |
| **自然性**：贴近人类语言习惯 | **刚性强**：难处理不确定性、启发式/元知识 |
| **通用性**：标准化推理机制 | **组合爆炸**：事实增多、盲目搜索易失控 |
| **易实现**：模块化，便于增删改 | |

> **结论**：尽管有局限，它仍是知识表示的**基石性方法**。

## 2.3 产生式系统：模拟人类专家的“条件-行动”范式

源自波斯特系统，后成为早期专家系统的核心架构，至今仍是规则引擎的理论原型。

### 2.3.1 核心单元：产生式

**基本形**：`P → Q` 或 `IF P THEN Q`
*   **P (前件/条件)**：触发规则的模式匹配条件。
*   **Q (后件/动作/结论)**：条件满足时执行的操作或推导出的事实。

**产生式 vs. 逻辑蕴涵 (关键差异)**：
1.  **表达力更强**：蕴涵仅限精确真/假；产生式可挂载**可信度** `CF ∈ [-1, 1]` 表示不确定知识。
    *   不确定规则形式：[PRE3]
2.  **匹配机制灵活**：蕴涵要求**精确统一**；产生式支持**模糊/近似匹配**（相似度阈值触发）。
3.  **本体论不同**：蕴涵是有真值的逻辑公式；产生式是**无真值的知识单元**，它是“可执行的规则”。

**事实表示的数据结构**：
*   确定性：三元组 `(对象, 属性, 值)` / `(关系, 对象1, 对象2)`
*   不确定性：四元组 `(对象, 属性, 值, 置信度)` / `(关系, 对象1, 对象2, 置信度)`

### 2.3.2 系统架构：三大核心组件 [PRE4]

一个标准产生式系统 = **综合数据库** + **规则库** + **控制系统 (推理引擎)**

#### 1. 综合数据库 —— “工作记忆”
*   非传统数据库，而是**动态事实黑板**。
*   存放：初始事实、中间推导结果、最终目标。
*   状态驱动：规则触发即修改数据库，驱动状态迁移。

#### 2. 规则库 —— “长时记忆/知识库”
*   存放 `IF...THEN...` 规则集。
*   **两类知识**：
    *   **领域规律** (如“马走日”)：硬约束，必须正确。
    *   **启发策略** (如“控制中心有利”)：软知识，决定求解水平与效率。

#### 3. 控制系统 —— “中央执行/推理机”
核心职责：**匹配 → 冲突消解 → 执行 → 循环/终止**。

详细工作流：
1.  **模式匹配**：拿规则前件去数据库找事实（精确/近似）。
2.  **冲突消解**：匹配成功规则 >1 条时，按策略（如特异性优先、先进先出、置信度高低）选**一条**执行。
3.  **执行行动**：
    *   后件是结论 → 写入数据库。
    *   后件是操作 → 执行外部动作。
    *   涉及不确定性 → 计算结论置信度更新。
4.  **终止判定**：数据库满足目标条件 → 停机输出路径；否则回步骤 1。

### 2.3.3 三大推理控制策略

1.  **正向推理 (数据驱动)**：从已知事实出发，不断触发规则生成新事实，直到达成目标。适合“诊断/预测/监控”类问题（如：有症状找病因）。
2.  **反向推理 (目标驱动)**：从假设目标出发，反向寻找支持该目标的规则前件，将其设为新子目标，最终回溯到已知事实。适合“验证/设计/故障排查”类问题（如：假设是肺炎，查缺什么症状）。
3.  **双向推理**：双向交替，缩小搜索空间，适合复杂大规模系统。
