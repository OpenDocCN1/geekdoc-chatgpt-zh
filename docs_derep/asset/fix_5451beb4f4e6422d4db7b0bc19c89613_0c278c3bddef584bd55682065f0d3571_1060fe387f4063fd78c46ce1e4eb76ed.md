DeepSeek 接入笔记：记住对话、按需选模、业务微调

把 DeepSeek 接进自己的工具里，真正好用的一套做法就是让它能延续前面的讨论、根据任务轻重花不同的钱、必要时再做领域化训练。下面这几段可直接跑的代码就是这套思路的落地。

先让补全具备会话记忆。核心函数 optimized_completion 接受提示词 prompt、模型名 model，默认 deepseek-v3，以及一个可选的历史记录 context_cache。第一次调用时如果记录为空就新建空列表，把之前所有轮次的提问和回答用空格拼接，再加上当前提示作为整体输入。请求体里 model、prompt 之外，把最大生成长度压到 150 左右，temperature 设 0.5 来收敛发散，top_p 用 0.8 保持一定的多样性。鉴权走 Bearer 头，内容类型 application/json。请求成功就从 choices 取 text，顺手把本次提问和返回结果都追加到记录里，下一次调用会自动带上。

再做按难度分流。函数 layered_completion 统计 prompt 的词数，少于 5 个词就认为任务很轻，用 deepseek-coder-v2 处理，词数更多、意图更复杂时切到 deepseek-v3。这样轻活走小模型，重活走大模型，成本和质量能对上。

演示分两类。记忆效果先让模型解释如何定义一个 Python 函数，随后追问快速排序的实现，因为记录里保留了第一轮的问答，第二次的代码自然会延续之前的风格。分流效果用两条提示验证，简单类用“打印 Hello World 的代码”，复杂类用“如何实现一个高效的并发爬虫程序？”，前者走轻量模型，后者走完整模型，输出深浅与花费匹配。

想让模型更贴业务就走微调。基础地址用 https://api.deepseek.com/v3，通过 fine-tune 接口提交训练样本，底座默认 deepseek-v3，训练轮数 3，批量大小 2。接口返回 model_id 后，后续生成调用 create-completion，最大 token 设 100，得到针对性更强的续写。

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot=arr[len(arr) // 2]
    left=[x for x in arr if x < pivot]
    middle=[x for x in arr if x == pivot]
    right=[x for x in arr if x > pivot]
    return quicksort(left)+middle+quicksort(right)

def fine_tune_model(task_data, base_model="deepseek-v3"): 
    """
    对指定的基础模型进行微调，针对特定任务进行定制。
:param task_data: 包含任务相关的训练数据。
:param base_model: 选择的基础模型，默认为 DeepSeek-v3。
:return: 返回微调后的模型 ID。
"""
data = {
    "base_model": base_model,  # 选择基础模型
    "training_data": task_data,  # 传递特定任务的数据集
    "epochs": 3,  # 设置训练轮数
    "batch_size": 2  # 设置批量大小
}
# 向 DeepSeek API 请求微调
response = requests.post(f"{api_base_url}/api/fine-tune", headers=headers, json=data)
if response.status_code == 200:
    result = response.json()
    fine_tuned_model_id = result.get("model_id", "未返回模型 ID")
    return fine_tuned_model_id
else:
    return f"错误：{response.status_code}, {response.text}"
# 示例：提供一些任务数据进行微调

def generate_code_with_finetuned_model(prompt, model_id):

import requests
# DeepSeek API 配置
API_URL = "https://api.deepseek.com/v1/chat/completions"
API_KEY = "your_api_key_here"
HEADERS = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}
# 定制化对话功能
def custom_service_chat(messages):
    """
    客户服务定制化对话系统
    :param messages: 对话消息列表，包括系统提示和用户输入
    :return: 模型回复内容
    """
    payload = {
        "model": "deepseek-v3",
        "messages": messages,
        "max_tokens": 150,   # 限制生成内容长度
        "temperature": 0.5,  # 减少生成的随机性
        "top_p": 0.8         # 优化生成准确性
    }
    response = requests.post(API_URL, headers=HEADERS, json=payload)
    if response.status_code == 200:
        return response.json().get("choices", [{}])[0].get("message", {}).get("content", "").strip()
    else:
        return f"请求失败，状态码：{response.status_code}, 错误信息:{response.text}"
