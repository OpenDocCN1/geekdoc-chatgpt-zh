# AI助教：从定制作业到个性化学习
# 序言
看到AI教师这几个字浮现出来，你的脑中会先跳出什么念头？

很多人第一反应是，AI教师会不会把真人教师挤掉？

在给出判断之前，先讲个小故事。

有一次两位朋友进山游玩，正玩得开心时忽然遇到野兽。其中一人立刻蹲下系鞋带，另一人疑惑地问：“系鞋带有什么用，我们能跑过野兽吗？”那人站起来说：“我不用跑过它，只要跑过你就行。”

故事讲完，上面的疑问似乎也不那么关键了。因为AI是否会取代真人教师，没有人能给出确切答案，但会用AI的教师很可能在未来取代不会用AI的教师。

本书并非要制造谁胜谁负的局面。教师的本分不是竞争，而是把课上好。可AI已经到来，教师若视而不见，很容易被时代抛下。正是基于这种现实，才有了这本书的构想。

那么书中说的AI教师指什么？

就现阶段的技术水平而言，书里所说的AI教师就是文心一言、通义千问、豆包这类大语言模型。它们可以配合真人教师完成教学任务，也能支持学生进行个性化学习。从这个意义上称其为教师并不为过。

当然，眼下的AI教师仍有明显局限，只能充当教学与学习的辅助工具。即便如此，作为助手，它已经能打开不少新可能。对教师来说，在AI的配合下，可以把一些职责内却与教学无关的事务分出去，从而把更多精力放在真正有价值的教学上。这正是本书写作的初衷。

在成书过程中，对AI的回应对话基本保留了原文，仅在必要时做了少量调整。此外书中涉及AI工具的操作演示，除非特别说明，均以电脑网页版为准，仅涉及电脑网页版和APP两种版本。

# 第1章 AI时代已来临
## 1.1 你对AI了解多少
### AI究竟是什么
AI是Artificial Intelligence的缩写，即人工智能。自2022年ChatGPT 3.5发布后，人工智能频繁出现在各类媒体上，说到底它是什么呢？通俗地说，就是让机器模仿人类思维，并像人一样感知、学习、思考和决策。

在深入之前，不妨先看看人脑智能如何产生。人类大脑约有一千多亿个神经元，通过大量神经突触连接，形成复杂的神经网络。我们的一切学习、思考、决策都是该网络活动的产物。有趣的是，神经元的连接并非固定不变，随着新经验的积累，连接方式会变化，思维也随之成长。

科学家据此构建了人工神经网络，它能像人脑一样通过海量数据喂养来学习，也就是机器学习。机器一旦学会学习，诸多难题便迎刃而解。它像个孩子，从懵懂逐步变得聪明。

这种聪明体现在多个层面，如人脸识别、语音识别、自然语言理解。其中自然语言理解最为突出，因为它已进入认知范畴，不只是分辨是什么，还要理解是什么意思。比如参加一场人工智能会议，听到“人工智能是研究、开发用于模拟、延伸和扩展人的智能的理论、方法、技术及应用系统的一门新的技术科学”，每个字都认识，但整句话的含义是什么？这就是识别与理解的区别。

让机器理解人类复杂的语言并非易事，机器学习提供了路径，即在海量语言材料中自我学习并归纳规律。

事实上，AI理解自然语言的能力已广为人知，除了国外的ChatGPT，国内的文心一言、通义千问、讯飞星火等也能做到。

图1-1展示了文心一言对一个经典谜题的回应，它不仅理解了问题，还通过推理给出了答案。

一个人向南走100米，又向东走100米，再向北走100米，回到了原点，看见一头熊，请问这头熊什么颜色？

这是一个经典谜题。回到原点意味着最终位置与起点一致。要在向南100米、向东100米、再向北100米后回到起点，只能发生在极地附近：

1. 北极附近：向南走偏离北极，向东实际是在同一纬度圈上移动，再向北100米便能回到起点。
2. 南极附近：同理，向南深入南极，向东在纬度圈上移动，向北100米返回起点。
3. 地球其他地方，如赤道附近，走这三步无法回到起点。

因此此人位于南北极之一。题目又提到看到熊，南极没有熊，只有北极有熊，而北极唯一的熊种是白色的北极熊。

随着AI发展，越来越多的人担心：我的工作会被AI取代吗？这已成为近两年职场的热门话题。人们担忧正是因为这次人工智能展现出了真实的智能。我们不知道它是否会在不久后实现跃进，取代一批又一批从业者。

答案未知，但人工智能正实实在在地影响生活，且影响会随技术发展不断扩大。因此认识AI、应用AI并把握其发展趋势，对每个人都有意义。

### 人工智能产生了哪些影响
人工智能是一把双刃剑，既有积极面，也有消极面。

积极面包括：
- ①提升工作效率。人工智能能在多行业处理大量繁重、重复甚至危险的任务，把人从这类工作中解放出来，专注于更有创造性的工作。
- ②改善生活质量。人工智能技术能快速识别、分析、处理复杂信息，加快信息传输与处理，为日常生活提供便利。
- ③提高医疗水平。通过分析海量医疗数据，辅助医生更精准、更迅速地诊断与治疗。
- ④改变教育方式。教育机器人可根据学习情况提供个性化辅导；智能教学系统能依据学习进度和能力制定个性化方案，满足不同需求。
- ⑤提供个性化服务。能依据个人兴趣、偏好和行为习惯提供定制化服务和建议。

消极面包括：
- ①就业风险。部分重复性、规律性强的工作可能被机器替代，导致失业风险。
- ②隐私风险。AI应用需要大量个人数据训练学习，可能引发数据隐私问题，数据被滥用或泄露会威胁个人安全。
- ③依赖风险。便利可能让人过度依赖科技，失去基本生活技能和思考能力。
- ④法律与伦理争议。AI在某些领域的应用可能引发法律与道德争议。

以上只是部分影响，未来AI还将带来更多社会改变。

## 1.2 AI时代，教育的挑战与机遇
AI的崛起对教育既是挑战也是机遇，下面从多个角度展开。

### AI给教育带来的挑战
1. 教师角色转变的挑战
传统模式下教师长期居于主导，以自我为中心传授知识。随着AI应用，教师角色将从主导者转向学生的引导者和陪伴者。例如传统课堂靠板书讲解，学生被动接受，有了AI辅助，学生可自主探索知识形成过程，教师在旁适时引导。对不少教师而言，适应新角色并非易事。

此外，利用AI辅助教学需要一定的技术素养。一方面要熟悉各类智能教学平台操作，另一方面要学会解读AI生成的学习分析报告，从中获取学习情况、薄弱知识点等信息以便针对性教学。对年龄偏大、信息技术基础薄弱的教师来说，学习新技术需要花费大量时间精力。

2. 学生学习方式的适应性挑战
AI在教育中的应用对学生同样构成挑战。新的学习方式可能让习惯传统教学的学生感到不适。自主探索时缺乏直接指导会产生迷茫，不知道如何自学。

对AI产生过度依赖也是问题。部分AI工具提供便捷学习途径，却易让人依赖。遇到问题先求助AI而非自己思考，会影响学习效果并阻碍思维发展。现实中已有学生用AI完成作业，本该是学习帮手的AI成了代笔工具。

3. 伦理与安全的挑战
AI带来便利的同时也引发伦理安全问题，如数据隐私保护、算法偏见。教育中使用AI往往需收集大量学生数据，包括个人信息、成绩、学习习惯、兴趣爱好等，管理不当易导致泄露滥用。此外，AI算法基于数据训练，若数据有偏差或不完整，可能产生偏见，影响学习机会和评价公正性。

### AI给教育带来的机遇
1. 推动教学创新
AI的深入应用将逐步推动教学创新。首先是课程设计创新。教师可利用AI算法挖掘历史文化与地理信息数据，在历史课程中构建古代文明发展与地理环境关系的动态模型，学生通过互动加深跨学科理解。其次是合作学习模式创新，让学生与虚拟学习伙伴协同学习，不受时空限制。再次是教学评价创新，AI可根据社会需求和教育发展趋势动态调整评价指标，例如加大创新思维与实践能力的权重。

2. 个性化学习的实现
学生学习进度、习惯、方法各不相同，传统班级授课难以兼顾。AI通过收集和分析学习时间、答题正确率、知识点掌握情况等数据，精准把握差异。建立学生画像后，可为不同学生制定个性化学习路径。对能力强、基础扎实的学生提供拓展内容，对进度慢、基础薄弱的学生放慢节奏并提供更多基础练习和辅导。

3. 教育资源的整合与共享
基于AI的教育平台可打破地域和时间限制，将全球优质教育资源整合。学生可进入平台学习世界名校课程、专家讲座和研究成果。教师可上传优质课件、视频供他人使用，学生也可分享学习心得、解题思路，促进交流。

4. 减轻教师负担
合理应用AI能大幅减轻教师负担。备课时可通过AI获取教学素材和案例，生成教学计划和教案；作业批改可借助AI初步实现自动化；撰写发言稿、设计作业等，AI也能发挥作用。负担减轻后，教师能把更多时间和精力放在关注学生学习与个性化需求上。

## 1.3 AI时代，教师该怎么做
教育领域常谈：虚拟教师会取代真人教师吗？这与职场人担忧的“工作会被AI取代吗”类似，无人能给出确切答案。但面对AI的发展，教师不能无动于衷，而应站在前沿采取行动。具体怎么做呢？

### 改变观念，拥抱AI
教师应认识到AI已成为不可忽视的强大力量，将其应用于教学是大势所趋。应积极接纳AI，消除被取代的焦虑，把AI视为提升教学质量的助手。例如AI可收集课堂参与度、作业完成情况、在线学习行为等多维度数据，绘制学生学习画像，教师据此借助AI为学生量身定制个性化方案。AI虽能高效处理信息和重复任务，但人类独特的情感难以替代，师生情感交流不应因使用AI而缺失。

当AI进入课堂，学生也会频繁近距离使用。教师需要正确引导，让学生认识到AI是双刃剑。可以通过开展社会热点讨论，如“AI是否会取代职场人”，让学生调研、分析并撰写报告，引导其关注AI技术本身及在社会、经济、环境等多方面的作用，培养批判性思维。

教师还应警示使用风险。如AI生成信息可能存在错误或误导，需要批判性辨别真伪；数据隐私方面，随意在不可信AI平台输入个人信息可能导致泄露；还需提醒注意AI在社会公平、伦理道德等方面可能引发的问题，如算法歧视导致不公平对待。

### 提升信息素养
想在教学中用好AI，必须不断提升信息素养。

首先学会使用一些AI工具，如文心一言、通义千问、豆包、DeepSeek等国内大语言模型。即便学校引入了AI教育平台，这些工具仍具价值。

其次能在众多AI教育产品宣传中筛选出真正适合教学内容和学生特点的工具，比如智能辅导软件是否匹配课程标准，能否提供个性化支持。

再次持续跟进AI技术发展动态，参加相关培训、研讨会，及时将新成果应用到教学。

最后能将获取和分析后的AI信息融入教学，比如根据AI分析的学生学习数据调整教学目标、内容和方法。

提升路径：
第一，通过观看视频、阅读专业书籍与论文进行自主学习，并动手实践使用AI工具，不断提升应用能力。
第二，参加学校或教育机构组织的AI信息素养培训，系统学习技术基础、教育应用及信息获取分析技能。
第三，参与教师专业社群或组织的交流活动，与同行分享经验、问题与解决方案，或开展校内校际合作项目共同提高。
第四，参与AI社区或论坛交流，与开发者、研究人员互动获取最新信息。

需要强调的是，使用AI工具收集和处理学生数据时，必须遵循学校、教育机构及国家地区的相关规范与法律法规。例如使用学习管理系统收集在线学习时长、答题情况时，需经学生或家长同意，安全存储数据，防止泄露，且仅用于教育目的，不得用于商业。

## 1.4 AI时代，家长该如何利用AI
AI作为工具，能为家庭教育带来便利。家长如何用好AI以发挥其优势，是当代家长需要思考的问题。

例如豆包APP首页有“拍题答疑”功能，家长可将不会的题目拍照上传，让豆包给出详细思路。
