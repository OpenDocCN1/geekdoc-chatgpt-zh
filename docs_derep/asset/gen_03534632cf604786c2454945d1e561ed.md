互联网档案馆保存了许多稍纵即逝却至关重要的过去与现在。

本书得以完成还要归功于诸多免费或开源的软件生态，特别是 Git、TeX 与 LaTeX。有趣的是，这份稿件是用四十多年前的排版系统完成的，而撰写该系统文档的竟是亚瑟·塞缪尔本人。我们仍在巨人肩上书写。

还要以谦卑的心纪念那些在书稿进行期间离世的人，他们的声音虽已缺席，思想却仍贯穿全书：Derek Parfit、Kenneth Arrow、Hubert Dreyfus、Stanislav Petrov 与 Ursula K. Le Guin。

加州大学伯克利分校对我而言意义非凡。CITRIS 的访问学者身份让我受益匪浅，特别感谢 Brandie Nonnecke 与 Camille Crittenden；西蒙斯计算理论研究所的 Kristin Kane 与 Richard Karp；人类兼容人工智能中心CHAI的 Stuart Russell 与 Mark Nitzberg；以及CHAI研讨会的成员与嘉宾。你们的鼓舞、包容与友情弥足珍贵。
