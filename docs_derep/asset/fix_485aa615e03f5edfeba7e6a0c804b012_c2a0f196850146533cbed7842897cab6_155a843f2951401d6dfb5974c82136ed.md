# 从古希腊到AI常识：知识追问的长线脉络

知识一直是哲学讨论的恒久核心，自古希腊以来就不曾离开过视线。围绕这一主题最具代表性的两部文集，一是A. 菲利普斯·格里菲斯主编的《知识与信仰》，二是迈克尔·罗斯与莱昂·加利斯合编的《认知》 Knowing。

在《知识与信仰》里，亚科·欣蒂卡首次用数学手段切入知识分析，这一开端后来被计算机科学继承发展，罗纳德·费金等人的《Reasoning about Knowledge》即是典型延续。莱韦斯克与格哈德·拉克迈尔的《知识库的逻辑》The Logic of Knowledge Bases 则把焦点放在知识库中符号化表征的知识观上。

逻辑本身庞杂多端，难以一言蔽之。若锁定西方古典传统，演绎逻辑最具参照意义。亚历克斯·马尔帕斯与玛丽安娜·安东努蒂·马尔福里合著的《哲学与形式逻辑史：从亚里士多德到塔斯基》梳理了这条脉络。书中指出，现代符号逻辑的奠基者是戈特洛夫·弗雷格，朱塞佩·皮亚诺在20世纪初为其确立了专用记号体系。关键突破在于形构了一个形式系统，它既囊括了语句层的“与”“或”“非”等算子，即乔治·布尔先前提出的布尔算子，也首次引入了带参数、变量与量词的谓词，后续第8章会据此展开。

符号对思维尤其是读写的作用，大卫·奥尔森在《纸上的心灵》里做了系统梳理。在文字与数字等表征工具的早期探路者中，戈特弗里德·莱布尼茨格外引人注目。他的1677年著作《普通科学》序言经尼古拉斯·乔利《剑桥莱布尼茨指南》再版整理后，成为今日所说符号处理的源头，但符号处理与算术的本质差别，直到约三百年后才在约翰·麦卡锡、艾伦·纽韦尔等人的研究里具体化，例如麦卡锡1960年发表的《符号表达式的递归函数及其机器计算，第一部分》。即便库尔特·哥德尔在20世纪30年代处理逻辑语言公式，也需要先把公式映射为数字，即后来的哥德尔化，才得以算术化。

麦卡锡1958年论文《程序与常识》里的常识论述被置于本章开头作为切入。布莱恩·坎特韦尔·史密斯博士论文《程序性语言中的反思和语义》提供了“知识表示假说”的出处，学界通常归于麦卡锡，但同期其他人工智能研究者也在做类似探索。艾伦·纽韦尔与赫伯特·西蒙更偏符号层面，他们提出的物理符号系统假说在1976年论文《作为经验研究的计算机科学》中表述为：“一个物理符号系统具有一般智能行动的必要和充分的手段。”

麦卡锡1977年文章《人工智能的认识论问题》讨论了知识系统的认识论与启发式充分性。

此后一代研究者沿着麦卡锡的路径用逻辑公式表征常识性知识。代表作包括欧内斯特·戴维斯1990年的《常识性知识的表示》、约瑟夫·霍珀2017年的《关于不确定性的理性》、杰里·霍布斯与罗伯特·莫尔1985年的《常识世界的形式理论》、雷蒙德·赖特2001年的《行动中的知识》。若要把逻辑拓展到默认、典型性等维度，马修·金斯伯格编的《非单调推理中的阅读》可供参考。明斯基在1985年论文《知识表示框架》第262页明确谈到了逻辑推理的不充分性。

Cyc大概是人工智能史上运行最久的项目，同时也是争议最大的项目之一，争议并非源于雄心，而在于长期信息不透明。尽管有同行评议成果，如辛西娅·马图塞克等人的《寻找常识》和迈克尔·维特布罗克等人的《Cyc中获取知识的交互式对话系统》，对于一个35年的大规模研究而言产出仍显稀少。比较系统的描述是道格拉斯·莱纳特与拉马纳坦·古哈的《构建大型知识系统》，但该书被定位为“中期报告”，内容止于1989年之前。多数关于Cyc的说法只能在流行媒体见到，例如莱纳特2019年7月在《福布斯》发表的《人工智能可以从罗密欧与朱丽叶中学到什么》，其中关于“启发式推理模块”的引文即源于此。项目对外信息几乎完全由领导层掌控，例如Cyc实际规模的引述来自官方网站，至今未获独立核实。欧内斯特·戴维斯与加里·马库斯在《美国计算机学会通讯》上发表的《人工智能中的常识性推理与常识性知识》对此作出评论：如果可以对CYC进行系统的描述和评价，那么该领域可能会受益匪浅。如果CYC已经解决了常识性推理的一些重要部分，那么知道这一点是至关重要的，它既可以作为一个有用的工具，也是进一步研究的起点。如果CYC运行出现问题，从所犯的错误中吸取教训也将受益匪浅。如果CYC完全没用，那么研究人员至少可以不再担心他们是否在重新发明车轮这个问题。

2018年汤姆·米切尔团队发表《永恒语言学习》，介绍了NELL项目。术语GOFAI出自约翰·豪格伦的《人工智能：非常理念》。

深度学习领军人物扬·勒库恩、约书亚·本吉奥、杰弗里·辛顿均强调常识对智能系统的重要性，这与本书核心关切相呼应。他们普遍认为以某种深度学习形式解决该问题终将到来，例如马丁·福特在《智能建筑师》中对其访谈即有体现。COMET系统则探索更混合的方案，安托万·博瑟卢等人的预印本对其做了介绍。马库斯的预印本《人工智能的未来十年》探讨了混合系统的必要性，而唐·门罗在《美国计算机学会通讯》上发表的《探寻人工常识》则梳理了相关研究现状，以及当前部署的系统普遍缺乏类似常识的短板。

# 第5章 对世界的常识性理解

第5章整体关切的是常识主体认知世界时所依赖的一套默认假设，这与试图还原世界“究竟为何物”的形而上学努力并不等同。观察角度各异。发展心理学更侧重物理层面，例如物理因果关系居中，空间与时间具有同等权重。相关视角可参见加里·马库斯的《心灵的诞生》、史蒂芬·平克的《语言本能》，以及伊丽莎白·斯佩尔克与凯瑟琳·金兹勒的《核心知识》。

在人工智能里，系统对各类事物的划分常被称为本体论。史蒂芬·斯塔布与鲁迪·斯图特合著的《本体论手册》对此做了厚重梳理。可以设想，不同应用领域会采用截然不同的本体，例如考古学、内分泌学、社会学或神话学。布莱恩·坎特韦尔·史密斯在第5章结尾对本体论的引用，来源是《人工智能的承诺》第142页。

第5章倡导的做法是，先把人工智能系统的知识归入宽泛的上层或顶层本体论范畴，参见阿尔多·甘格米等人的《理解顶层本体区分》以及伊恩·奈尔斯与亚当·皮斯的《走向标准的上层本体论》。思路本质上是构建一个覆盖全局的分类阶层，使“生物”“物理对象”等概念位于更靠近顶部的层级。

物理学家用“万有理论”来指代对整个宇宙的统一数学描述。在常识层面，研究者普遍认为最基础、需优先处理的其实是中宏观物体，即关注位置、形状、外壳等属性，默里·沙纳汉等人2020年的《人工智能和动物的常识》提供了相关讨论。“朴素物理学”，亦称“民间物理学”，由帕特里克·海斯的《朴素物理学宣言》推广，后续还有《第二个朴素物理宣言》。有时“定性物理学”一词被用来强调对物理对象与属性进行非数值推理，这正是常识的典型特征。定性物理学的主流脉络起源于约翰·德克利尔，后由肯·福布斯等人系统化，丹尼尔·韦尔德与德·克利尔合编的《物理系统定性推理阅读》是重要集结。定性物理学最引人之处在于对空间与时间本身的推理，如安东尼·科恩的《定性空间推理的挑战》和詹姆斯·艾伦的《保持对时间间隔的了解》。沙纳汉1997年著作《解决框架问题》以及埃里克·穆勒《常识性推理》第5章详细阐述了惯性的常识定律，与框架问题直接相关，第8章注释亦有涉及。德里克·比克顿的《亚当》讨论了语言的位移特性，以及这种特性如何使人类语言使用区别于其他动物交流。

关于数量与界限，定性推理并不使用实数或大整数，例如变量仅取正、负、零三值。这种思路是定性物理学发展的源头，下一章将专门讨论数量级推理。国王与骑士在棋盘上移动的经典例子，取自大卫·麦卡莱斯特的《关于认知判断的观察》。

通过与朴素物理学的类比，安迪·克拉克的《从民间心理学到朴素心理学》与斯图尔特·瓦特的《朴素心理学宣言》探讨了朴素心理学。将主体建模为受信念、欲望与意图支配的实体，这一想法在杰里·霍布斯与安德鲁·戈登2005年论文《元认知常识心理学的大规模形式理论》、以及阿南德·拉奥与迈克尔·乔治夫早期论文《在BDI架构中对理性的代理进行建模》中出现。戈登与霍布斯的《常识心理学的形式化理论》对“人们如何思考他人的思考”给出了更完整的表述。意图有时被视作衍生属性，即信念与目标的组合，见菲利普·科恩与莱韦斯克1990年文章《意图是有承诺的选择》。同理，知识或认知能力也被认为是信念的衍生物，伊夫·莱斯佩兰斯等人在《情境演算中的能力与知识》中有论述。艾莉森·高普尼克与珍妮特·阿斯廷顿在《儿童对表示变化的理解》中指出，儿童需达到一定年龄才意识到他人可能基于错误信念行动。言语行为由约翰·塞尔在《表达与意义》中提出，科恩与C. 雷蒙·佩罗1979年文章《基于计划的言语行为理论的要素》将其应用于人工智能。科恩与莱韦斯克的《团队合作》讨论主体间的共同意图，塞尔的《集体意图和行动》亦有相关论述。对于更广范围的多主体群体，即所谓的“朴素社会学”，可参考迈克尔·伍尔德里奇的《多主体系统简介》。

人工智能中的因果关系研究主要受益于朱迪亚·珀尔的两部著作《因果关系》与《为什么》——后者与丹娜·麦肯齐合著——以及与约瑟夫·霍珀的合作，见霍珀的《实际因果关系》。核心在于从一组基础因果事实，通常以图形表示，推导出合理结论，并将因果关系与纯粹的统计相关性区分开来。

# 第6章 常识性知识

前一章建立的图景认为，世界由随时间变化属性的事物构成。本章聚焦于我们对这些事物及其属性的认知，即我们形成的概念或想法。
