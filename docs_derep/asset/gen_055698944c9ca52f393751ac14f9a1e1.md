# 第3章 短视频字幕制作全攻略

在影视作品里，字幕就是把语音内容以文字形式呈现在画面上。对观众来说，看视频是被动接收信息，注意力容易分散，字幕能帮助理解内容。字幕也是重要的排版元素，通过字体、字号、动画等设置，能让画面更丰富、更高级。

##### 创作技法
###### 如何设置字幕参数让字体更有高级感？
第一，字号不要过大。横屏一般6~7号，竖屏一般11~12号。
第二，字体不要太花。做字幕尽量选易读字体，避免艺术字体，也尽量不加描边。
第三，一定要加阴影，让字幕脱离背景。阴影不透明度一般调到60%，其他参数保持不变。

##### 创作技法
##### 如何用剪映贴纸显著提升视频质感？
在我的频道@Jack的影像世界，很多观众以为画面元素是AI动画，实际是剪映贴纸。挑选要点如下。

一是主动搜索需要的动态贴纸，比如“虚线指引”“科技效果”“箭头运动”，搜索结果多为运动贴纸，静态图易有粘贴的塑料感，动态贴纸更高级。
二是选颜色干净、元素少的运动贴纸。画面颜色尽量控制在3种以内，贴纸颜色要与画面协调，避免过于跳脱导致廉价感。
