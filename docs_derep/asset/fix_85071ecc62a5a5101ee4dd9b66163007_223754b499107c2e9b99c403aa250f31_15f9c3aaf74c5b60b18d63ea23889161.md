**4.2.1 黄金 3 秒原则，抓人眼球**

[PRE45]

4.2.1 黄金 3 秒原则，抓人眼球

信息过载的当下，观众注意力极易分散。若前 3 秒无法抓住注意，视频很可能被划走。相关技巧如下。

（1）视觉冲击：运用鲜艳色彩、独特画面元素，如画面中突然出现巨大、色彩醒目的物体。例如美食视频开场即呈现一盘色彩缤纷的蛋糕，配以各色水果点缀，如图 4-16 所示，丰富视觉效果可瞬间抓住眼球。

[PRE46]

图 4-16 一盘色彩缤纷的蛋糕

（2）声音吸引：借助独特音效或引人入胜的音乐。如悬疑类短视频开头采用紧张背景音乐，配合节奏鼓点与神秘音效，迅速激发好奇。

（3）文字引导：在前 3 秒展示简洁有力、带悬念的文字。如“你知道吗？这个小动作能让你瞬间变美”，能迅速吸引注意并促使用户继续观看。

（4）悬念设置：制造悬念激发好奇，如“挑战失败会怎样？”“结局反转！”“他竟然这样说！”。

（5）利益诱惑：直接呈现产品或服务核心卖点，突出用户收益，如“3 招教你……” “这样做，省时省力！”。
