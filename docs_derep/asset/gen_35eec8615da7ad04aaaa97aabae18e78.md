**8.1.2 什么是编程语言**

编程语言是人工设计的用于编写计算机程序的语言，提供明确的规则与语法结构，使开发者以计算机可理解的方式发出指令，执行特定任务、处理数据或解决问题。常用编程语言包括 Python、C、C++、Java、JavaScript 等，下面作简要介绍。

**1．Python**
Python 于 1991 年发布，是一种高级编程语言，以简洁语法、强大功能和丰富库资源著称。强调代码可读性与简洁性，用更少代码实现更复杂功能。支持面向对象、函数式和命令式编程，灵活性强。跨平台特性与动态类型系统使其成为数据科学、人工智能、Web 开发和自动化脚本等领域的首选。凭借强大的社区支持和丰富的第三方库，在快速原型开发和大型应用开发中表现优异。

**2．C**
C 语言是一种结构化编程语言，以高效、快速、可移植性著称。语法简洁、运算能力强，常用于系统软件开发、嵌入式系统编程及网络通信协议实现等。其代码具有高度可预测性和可控性，开发者可精确控制程序执行流程与资源使用。

**3．C++**
C++ 在 C 语言基础上扩展而来，保留了 C 的高效与灵活，并增加了面向对象特性，如封装、继承、多态等，提升了大型软件开发与维护能力，增强了代码可复用性与可扩展性。还支持泛型编程和函数式编程等范式，进一步提升表达能力与灵活性。

**4．Java**
Java 是由 Sun 公司于 1995 年发布、现由 Oracle 维护的面向对象高级编程语言。设计目标是简单易用且跨平台能力强。程序可在 Java 虚拟机上运行，实现一次编写多平台运行。庞大的社区支持和丰富的类库为开发者提供便利。

**5．JavaScript**
JavaScript 是一种高级、面向对象的解释性编程语言，主要用于网页动态交互。作为 Web 开发核心技术之一，可实现表单验证、动画效果、动态内容更新等功能，与 HTML5、CSS3 紧密结合，构建高度互动的响应式 Web 应用。其动态性与弱类型特性允许运行时灵活修改变量、对象和函数，并支持通过回调函数、Promise、async/await 等机制高效处理异步操作。

**8.1.3 代码的组成要素**

代码的组成要素包括语法、数据、函数/方法等，共同协作使程序平稳运行。下面进行介绍。

**1．语法(Syntax)**

**· 关键字(Keyword)：**编程语言中预定义的保留字，具有特定功能，如控制结构（if、for）和数据类型（int、float）等。
**· 标识符(Identifier)：**程序员自定义的名称，用于标识变量、函数、类等，需遵循命名规则。
**· 操作符(Operator)：**用于执行运算的符号，包括算术运算符（+、-）、比较运算符（==、!=）、逻辑运算符（&&、||）等。
**· 分隔符(Separator)：**用于分隔代码结构的符号，如括号、分号、逗号等。

**2．数据(Data)**

**· 变量(Variable)：**用于存储数据的容器，支持不同数据类型。
**· 常量(Constant)：**程序执行期间保持不变的值，常用于配置与固定参数。
**· 数据类型(Data Type)：**定义数据的性质与操作，包括基本数据类型（如整型、字符型）和复合数据类型（如数组、对象）等。

**3．控制结构(Control Structure)**

**· 顺序结构：**代码按从上到下的顺序依次执行。
**· 选择结构(分支结构)：**根据条件判断结果选择不同执行路径，如 if、else、switch 等。
**· 循环结构：**重复执行特定代码块，直至满足终止条件，如 for 循环、while 循环等。

**4．函数/方法(Function/Method)**

**· 定义：**将特定功能封装在独立代码块中，促进代码复用。
**· 参数：**函数/方法可接受输入参数以增强灵活性。
**· 返回值：**函数/方法可返回结果供调用者使用。

**5．类与对象(面向对象编程中)**

**· 类(Class)：**定义对象的属性与方法，提供创建对象的模板。
**· 对象(Object)：**类的实例，具有特定状态与行为。
**· 封装(Encapsulation)：**将数据与相关操作封装在一起，隐藏内部状态，仅暴露必要接口，增强数据安全性。
**· 继承(Inheritance)：**支持代码复用，子类可继承父类的属性与方法。
