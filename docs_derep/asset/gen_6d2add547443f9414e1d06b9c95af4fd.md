#### 第1步：创建两个张量 x1 和 x2

先构造两个三维张量，形状分别是 `(batch_size, seq_len1, feature_dim)` 和 `(batch_size, seq_len2, feature_dim)`。

[PRE2]

[PRE3]

两者的序列长度一般不同，记为 `seq_len1` 和 `seq_len2`。`batch_size` 代表一次处理的样本数，是神经网络训练的常规方式。`feature_dim` 通常就是词嵌入的维度。

**小冰：**这两个张量的特征维度一定要一样吗？

**咖啡：**要一样。本例中 x1 和 x2 的特征维度都是4。因为求原始注意力分数需要在特征空间里做点积，维度不匹配就没法相乘。实际使用时若两侧维度不一致，先做线性变换把维度统一即可。

应用上，x1 和 x2 可以对应编码器-解码器注意力里的解码器序列和编码器序列，也可以是任意两个序列，甚至是同一个序列的自注意力。先别展开太多，免得信息过载。

## 第2步：计算张量点积，得到原始权重

先对 x2 进行转置，再让 x1 与转置后的 x2 相乘，这一步算出的是 x1 每个位置和 x2 每个位置的相似度得分，是点积注意力的首要环节。

[PRE4]

[PRE5]

示例里使用 PyTorch 的 `torch.bmm` 来做批量点积。`torch.bmm` 即 Batch Matrix Multiplication，用于对一批矩阵执行矩阵乘法。它接收两个三维张量，输入形状为 `(batch_size, M,N)` 和 `(batch_size, N,P)`，输出形状为 `(batch_size,M,P)`，内部逐批完成乘法。

为了满足矩阵相乘的维度要求，需要把 x2 的后两维转置，形状由 `(batch_size, seq_len2, feature_dim)` 变成 `(batch_size, feature_dim, seq_len2)`。然后用 x1 `(batch_size,seq_len1, feature_dim)` 与转置后的 x2 做批量矩阵乘法，得到原始权重矩阵 `raw_weights`，形状为 `(batch_size, seq_len1, seq_len2)`。

| 输入/输出描述 | 形状说明 |

| :--- | :--- |

| x1 | (batch_size, seq_len1, feature_dim) |

| x2<sup>T</sup> | (batch_size, feature_dim, seq_len2) |

| Weights | (batch_size, seq_len1, seq_len2) |

**张量点积过程示意图**

原始权重 `(batch_size, seq_len1, seq_len2)` 来自 x1 与 x2 的点积，其中 `batch_size` 是批次，`seq_len1` 和 `seq_len2` 分别是两条序列的长度。矩阵里每个元素都代表 x1 某位置与 x2 某位置的相似度得分。

例如，输出的第一行 `[1.2474,-0.6254, 1.4849, 2.9333,-0.1787]` 表示本批次第一个 x1 序列的第一个元素，与本批次 x2 的五个元素分别得到的相似分，可见它与 x2 的第4个元素最相似，得分为 2.9333。基于相似度的打分正是注意力机制的核心。
