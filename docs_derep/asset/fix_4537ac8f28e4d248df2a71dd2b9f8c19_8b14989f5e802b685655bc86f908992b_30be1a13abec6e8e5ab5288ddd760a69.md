人与技术如何真正对话：从工效到情感智能

2000年8月，国际人类工效学协会理事会曾给出这样一段表述：人因工程学是一门探讨人以及系统其他构成要素如何相互理解的学科，其工作是运用理论、方法、数据和原则来设计，使人的福祉与整体系统绩效同时达到最佳。定义表述偏长，却把该领域的多条思路都浓缩其中。

技术是影响行为的强力单极力量，它往往对使用者是谁缺少感知。人数不多却在增长的专业族群，正致力于让技术系统与使用者的关系更协调。技术愈加复杂，实现这种协同所需的投入也水涨船高。接下来的几年里，这种协调努力将成为技术真正进步的关键支点。整个行业需要一个更清晰、简洁、明确又好用的说法来概括这项工作。置身于身体与认知能力不断被优化的时代，或许工效学能承担起这个角色。

当下的人机系统里，操作者置于特定情境中操控复杂的系统与各类数字设备，既要靠视线扫视环境，也要靠专注注视实现精细控制。借助工效学分析，可以看到操作时注意力与体力的分配模式，也能厘清仪表、屏幕与外部视野该如何布置，才能得到最优交互、减轻负荷、避免失误并提升整体效率。这一思路对计算机系统、自动化控制、交通运输、工业设计，以及军事里应对战争、自然灾害、金融危机等重大事件的应急指挥与组织、对复杂工业系统的快速故障处置、系统重构与修复，还有复杂环境下仿人机器人的设计制造，都有重要的借鉴价值。

### 三、自主才能造就真正的人工智能
未来交互与智能系统的发展指向清晰，可归纳为四点：主动式建议、自主式学习、自然式演化、自我式防护。自主贯穿始终，是核心概念。

美军的“深绿”智能指挥项目借鉴“深蓝”的思路，将其迁移到指挥控制领域。系统由指挥官助手、水晶球、闪电战三模块组成，整合当前与历史战场态势，并为指挥官提供实时辅助决策。其中最关键的是自主性与主动建议。自主与主动是人工智能与智能科学里既热门又棘手的焦点。

对自主的理解可拆为四层。第一层是记忆而非存储。记忆灵活，能由相关或不相关线索触发直觉，存储只能给出合乎逻辑的记录。第二层是选择性，选择是单向的，A挑B。第三层是匹配性，匹配是双向的，A可挑B，B也能挑A，与单向选择不同。第四层是可控性，没有控制与反馈，自主难以形成。

未来系统至少要实现人-机-环境的自主耦合，形成认知智能。认知本质上是信息流转，即输入、加工、输出与反馈。

人工智能的重要走向是人机混合智能。强人工智能、通用人工智能、类人人工智能的实现仍遥远，目前可行的方向更多是人机混合智能。它研究如何让人在系统、机器与环境之间实现最佳智能契合，把人的能力与机器能力结合，涉及整体设计与优化，目标是可靠性、效率与舒适感。它触及两个基本命题：人的意向性与机器的形式化。意向性指意识的指向。机器难以处理灵活、可变甚至矛盾的事物，却擅长不疲劳、会计算、准确及时地处理形式化符号信息，这是人的相对短板。如何把机器优势与人类优势融合，是人机混合智能的命脉。意向性与意识是智能科学的瓶颈。意识是情境感知，另一种是非情境感知，能跨越时空，那是人类特有的意识，而机器不具备。美国心理先驱、首届心理学协会主席威廉·詹姆斯曾说，智慧是忽略的艺术，人懂得忽略不重要的事，把精力聚焦关键特征，而机器擅长处理大数据，不擅长处理小数据。

《孙子兵法》说“知己知彼，百战不殆”。知己知彼不可分割，不知彼便难以知己。任何事物都无法自我解释，只能在其他参照物中被感知、理解、发现、说明与定义。己与彼是相对概念，相互对立又相互依存，若无外部参照，便无法认识自我。 “不知彼而知己，一胜一负”。辩证看待己与彼，可以认为自我并不存在——没有环境与参照物，自己无法解释自己，正如“我就是我”这种定义。再进一步，自我意识也可能是交互的产物，只是能跨越时空逻辑。本质上，所有自主系统都带有不自主，只是显隐程度不同。

当前人造机器或人工智能有存在却无自我。自我诞生于对自身存在持续的交互、组织与生成。若缺乏主动的交互与组织，就不是自主，就没有自我。没有自我，便无感己与感彼、知己与知彼，感性连不上理性，客观形不成主观，事实衍生不出价值。由此可见，不知彼而知己的结果是随机化。

“自我”的形成是意识的基础，自我构建了一个坐标系，原点即自我，人类以自我为原点衡量周围世界。意识出现常带来“无中生有”“有中生无”。无中生有是外界刺激形成数据并赋予数值，数值既包含客观数量也形成主观赋值，比如数字“1”既是客观量，也有主观情感承载，如一杯茶、一块手帕。随后要提取有价值的成分，即信息。信息是有价值的数据，从信息到知识再到逻辑，是从0到1、从1到n的过程，呼应道生一、一生二、二生三、三生万物。有中生无是逻辑产生意向，意向导出意识，从意识沉淀潜意识再升华为无意识，即从n到1、从1到0的过程，是万物归三、三归二、二归一、一归道的历程。

### 四、不再是没有情感的机器
情感是人类智能的重要组成，是穿透理性的利器。情感计算是否可行，能否像形式化常识那样实现，都值得深思。

约半个世纪前，美国心理学家、认知心理学之父奈瑟尔·乌尔里希描述了人类思维的三个基本且相互关联的特征，这些特征也在计算机程序中显现：思维随成长积累并正向影响过程；思想始于与情绪情感的密切关系，这种关系从未完全消失；几乎所有人类活动，包括思维，都在同一时刻具有多样而非单一的动机。赫伯特·西蒙有相似观点。情绪情感是日常生活的基石，但缺乏情感交互的技术让人失望，技术层面实现自然人机交互仍是紧迫课题。目前情感计算受关注，研究方向有人工情感AE、感性工学Kansei Engineering、情感神经学等。明斯基在著作与论文中反复强调情感，涉及情感神经科学、情感心理学。IEEE Transaction on Affective Computing期刊与Affective Computing and Intelligent Interaction会议为识别、诠释、模拟人类情绪的研究提供学术支持。

### 1. 情感及情感计算
“情感”源于希腊文pathos，最初用来表达对悲剧的感伤。达尔文认为情感源于自然、存在于身体，是炽热、非理性的冲动与直觉，遵循生物学规律；理智源于文明、存在于心理。《心理学大辞典》定义情感为“人对客观事物是否满足自身需要而产生的态度体验”。马文·明斯基认为情感是思维的一部分。史蒂芬·平克也认为情感是被当作非适应包袱过早注销的心智另一部分。达马西奥基于神经生物学研究将情感至少分为原发性与继发性，前者与生俱来，常被理解为婴儿期的典型情感，后者源于更高认知过程。拉塞尔则从核心情感与心理建构两个维度构建情感，前者指神经系统状态如昏昏欲睡，后者指行动如面部表情、音调及其关联。因情感复杂，研究者对定义至今未统一，相关理论超过150种。

“emotion”由前缀e与动词move组合，直观含义是从一处移动到另一处，后引申为扰动、活动，直至近代心理学确立后，威廉·詹姆斯才用它表述个人精神状态的一系列变化。皮卡德在书中对情感与情绪术语作了区分，她认为情绪相对于情感而言是较长期的情感状态。情感影响态度、情绪、其他感觉、认知功能、行为与心理，且情绪体验多次累积后可形成稳定倾向，当人们多次觉得完成某任务很高兴，就会爱上该任务。米里安等人结合《韦氏大词典》及研究指出，语言中情感是无意识且难以定义的，从文本中可检测到的是有意识的情绪表征，而情绪这一复杂心理现象几乎无法从文本完全检测，只能检测其构成要素。鉴于学界惯例，本文除必要区分外统一使用“情感”一词。

情感计算最早源于麻省理工学院媒体实验室。皮卡德读到理查德·西托威克关于联觉的书《尝出形状味道的人》后受到启发，西托威克提出感知在一定程度上由大脑边缘系统处理，该部分负责注意、记忆与情感。1995年皮卡德提出情感计算概念，1997年出版《情感计算》。书中指出，情感计算是指针对人类外在表现进行测量与分析，并能对情感施加影响的计算，开辟了计算机科学新领域，其思想是让计算机拥有情感，像人一样识别与表达情感，从而使人机交互更自然。

并非所有研究者都认同皮卡德。支持者借鉴现象学，把情感视为人与人、人与机互动的成分。情感互动方法主张从建设性、人文决定性的视角展开，而非传统认知与生物学角度，重点在于让人们获得可反映情感的体验并以某种方式修改其反应。

### 2. 情感复杂性的探究
#### （1）外在复杂性的探讨
相较手势、步伐、声音等表征，面部表情最易控制。面部表情是脸上不同情绪的反应，本质是面部、眼睛或皮肤肌肉位置的变化。坦率的面部表情最易理解，但不同国家的表情各异。相对其他国家，亚洲人面部表情强度较低，因亚洲文化中在脸上显露特殊情绪不礼貌，负面情绪表达会影响社会和谐。这印证了埃克曼早期的发现：文化最大差异在于公共场合如何表达情绪。他偷拍美国留学生与日本学生观看原始成人礼可怕画面的表情。当白大褂实验人员集体访谈时，日本学生在令美国学生吓得后退的场景中仍礼貌微笑；当被试单独待在房间，美国与日本学生的面部表情同样恐惧。针对外在复杂性，研究者多采用多模态结合、额外信息叠加，以及结合时代科技产品的方法来提升识别率。

博德里、奥利维亚等人设计实验澄清六种基本情感识别中眼睛眉毛与嘴巴区域的作用，得出面部表情识别不能简化为简单特征或整体处理的结论。新加坡国立大学电气工程系Gu W等人利用人类视觉皮质与径向编码提升性能，提出混合面部表情识别框架，该框架亦可用于体态识别，并能从图像中提取年龄、性别等额外信息。

人与人之间的情感交互复杂，单一感官数据模糊、不确定、不完备。研究者常采用多种方式识别情感状态，20世纪90年代最初是融合视觉面部表情与音频信号，多源整合提升精度。陈等人尝试身体姿势与面部表情混合模型，基于澳洲悉尼科技大学人脸与身体姿势FABO双模数据库，选取284个视频，涵盖基本表达嫌恶、害怕、高兴、惊讶、悲伤、生气，以及非基本表达焦虑、无聊、困惑、不确定。实验框架分为面部特征提取与表示、身体姿态特征提取与表示、表达时间分割、时间归一化、表达分类五部分。

身体姿势交流同面部表情属于非语言交流。越来越多研究表明，身体表达在传递情感上与面部一样强大。情感计算可通过提取人体手势特征识别用户情绪。随着虚拟现实发展，肢体参与度逐渐增大，身体姿势不仅控制与游戏的互动，还会影响自身情绪。“蓝眼睛”Blue Eyes技术中，“蓝”指蓝牙实现可靠无线通信，“眼睛”指通过观察眼动获得更多信息。该技术主要用于视觉注意监测、生理状态监测如脉搏率、血氧、操作者位置检测如站立卧坐等，通过检测表情、捕获表情图像并提取眼部区域实现识别。

#### （2）内在复杂性的探讨
文本句子中每一个形容词、动词甚至单个字都可表达情感状态。笔记分析技术不仅能通过书写者的情感输出分析基线、倾斜、笔压、大小、边缘区等笔记特征，还能揭示书写者的健康、道德、过去经历、精神问题及隐藏才能。索菲亚尼等人发现笔记分析在一定程度上有助于理解书写者的行为、动机、欲望、恐惧、情感投入。史伟等通过构建情感模糊本体、计算文本影响力，对微博公众情感进行分析，发现公众对突发事件的情感表达与政府处理方式密切相关。使用文字表达情感受文化影响，文化在情感文本表达中的作用需要自然语言研究者开发更强大的检测算法。

戴维森2002年提出，情感体验并非只发生在头脑，整个身体都在感知。血液激素变化、传至肌肉的神经信号紧张或放松、血液流向身体不同部位，都改变姿势、动作与面部表情。身体反应会反馈回大脑，形成可调节思维的经验，也会反馈回身体。随着技术发展，互联网与智能手机可提供大量数据。人们上网活动包括搜索查询、浏览网页、广告选择与电子商务，用户创建的电子邮件、短信、博客等内容均可分析。典型智能手机包含加速度计、环境光、陀螺仪、手势、磁强计、温度计、湿度计、气压计等传感器。乔格等人通过捕获智能手机的输入输出呼叫频率、时长与联系人等活动，分析患者行为变化。卡韦赫·巴赫蒂亚里等人认为，处理面部表情、声音或姿势时，部分方法在精度与实时性间权衡，而自然语言处理与脑电信号在实际应用中效率与可用性不足，遂提出使用键盘、鼠标触控板、单触与触屏显示器等方便低成本输入设备。该系统通过人工神经网络ANN与支持向量机SVM开发训练监督模型，结果显示较现有方法SVM准确度提升6%，达到93.20%，在情感识别、用户建模与情感智能上表现突出。

### 3. 情感计算的最新应用探究
近年研究者尝试多种方法与技术识别用户情感，主要包括面部表情识别、姿态识别、自然语言处理、人体生理信号识别、多模情感识别、语音识别。人机情感交互涵盖人脸表情交互、语音情感交互、肢体行为情感交互、文本信息情感交互、情感仿生代理、多模情感交互。情感仿生代理增强计算机的表现力与亲和力，情感智能系统可根据人情感反馈，使交互更自然。

全球多实验室积极研究情感计算，以下总结近三年主要应用。2014年，麻省理工学院实验室通过安装于汽车等机器上的硬件如相机，结合基于程序语言的语音识别应用、可穿戴设备实时调节当前情绪，尤其是面部识别算法，获取一系列情绪指标，弥补生理信号类传感器不足，探索情感感知与机器连接潜力。情感分析公司使用计算机视觉与深度学习分析面部微表情或网络视觉内容中的非语言线索，基于庞大数据存储库学习识别更复杂系统，将情感人工智能引入机器人、医疗、教育与娱乐等领域，并展望用于检测癫痫病患者情感信号以提前预警。

2015年，阅面科技推出情感认知引擎ReadFace，由云端数学模型与大数据理解情感，以及端SDK组成，可嵌入任何带摄像头的设备感知并识别表情，输出人类基本表情运动单元、情感颗粒与认知状态，广泛应用于互动游戏智能机器人或智能硬件、视频广告效果分析、智能汽车、人工情感陪伴等。哈尔滨工业大学机器人技术与系统国家重点实验室研发语音情感交互系统，提出智能情感机器人情感交互框架并实现智能服务机器人的情感交互系统。北京航空航天大学基于特征参数的语音情感识别能有效识别语音情感。中国科学技术大学基于特权信息的情感识别提出融合用户脑电信号与视频内容的情感视频标注方法，以及以某一模态特征为特权信息的情感识别与视频情感标注方法。清华信息科学与技术国家实验室与中国科学院心理研究所行为科学重点实验室基于生理大数据情绪识别进展，针对使用DEAP数据库诱发情绪并采集脑电及外周生理信号的16篇文章梳理，详细比较特征提取、数据标准化、降维、情绪分类、交叉检验等方法。

### 4. 情感计算的深度探究
