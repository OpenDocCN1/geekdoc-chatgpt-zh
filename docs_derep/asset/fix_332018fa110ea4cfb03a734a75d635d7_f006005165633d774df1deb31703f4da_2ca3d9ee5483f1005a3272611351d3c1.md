handle_file_string 负责把文本文件标准化后写入 Redis 向量存储。它接收五个输入：待处理的 file、负责切分的 tokenizer、Redis 连接对象 redis_conn、记录向量的字段 text_embedding_field 以及目标索引 index_name。具体流程是：先从 file 中提取文件名与原始内容；随后对内容进行清洗，把连续的双空格和换行符分别替换为单个空格和分号，得到规整的新串；再把文件名拼接到清洗后的文本上作为生成嵌入的依据；接着逐段生成向量，为每个向量分配唯一标识，并连同向量、文件名及分块序号一起打包成记录加入列表；最后把整批记录通过指定的嵌入字段写入 Redis。

`get_redis_results` 依赖 `query_redis` 完成相似文档的查找。`query_redis` 的做法是先用 `openai.Embedding.create` 把查询文本转成向量，再以该向量发起 Redis KNN 查询，返回与之最接近的 Top K 条目。返回内容涵盖相似度分数、对应的文本块以及块索引等。`get_redis_results` 则对这些原始命中做整理，以 DataFrame 形式展示，包含 ID、文本结果 result 和匹配置信度 certainty 三列。
