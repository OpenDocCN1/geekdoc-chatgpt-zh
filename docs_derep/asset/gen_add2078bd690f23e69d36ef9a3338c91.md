### 1.1.3 预训练加微调，模型怎么变强
深度学习发展至今，预训练+微调已经成为提升效果的主流套路。这套思路不仅在自然语言处理里效果明显，在计算机视觉等领域也同样好用。

### 1. 预训练是怎么起作用的
预训练的核心是借助海量无标注数据，让模型先学会通用的特征表达。通常用自监督或无监督的方式，让模型在训练初期就能从丰富的上下文里提炼出有价值的表示。

### 2. 微调的落地流程与开发实践
预训练+微调在 NLP、CV 等多场景都被广泛采用。以 NLP 里的 BERT、GPT 系列为例，都可以在 PyTorch 或 TensorFlow 等框架上完成微调，微调后用测试集评估最终泛化能力。完整流程可参考图 1-6。

**图 1-6 大模型的预训练与微调流程分析图**

预训练模型是通过大规模无标注语料训练得到的通用语言模型，训练通常依赖自监督，让模型学会广泛文本中的语言结构、语法和语义关联。

微调后的模型则在预训练模型基础上，用特定任务的有标注数据做有监督训练，得到面向任务的专用模型。两者区别见表 1-2。

**表 1-2 预训练模型与微调后的模型对比表**

| 特点 | 预训练模型 | 微调后的模型 |
| :--- | :--- | :--- |
| 定义 | 基于海量无标注数据训练，具备通用语义理解 | 基于特定任务数据训练，具备任务专属能力 |
| 适用场景 | 开放式任务、零样本或少样本学习 | 目标明确的特定任务，对精度要求高 |
| 任务表现 | 通用性好，单任务精度有限 | 单任务表现优异，精度更高 |
| 扩展性 | 迁移快，适配新任务容易 | 为单一任务优化，跨任务迁移效果下降 |
| 计算资源需求 | 预训练阶段消耗大 | 成本低，适合在已有预训练模型上开发 |

## 1.2 LangChain 原理与开发方法
大模型应用越来越多，如何高效构建、部署和管理模型成为关键。LangChain 就是为此而生的框架，它把大模型的开发流程简化、标准化，让复杂任务的集成更顺畅、更灵活。

下面先梳理 LangChain 的基本原理和开发思路，重点讲核心组件、协作机制以及上手技巧。

### 1.2.1 LangChain 核心组件：任务链与记忆模块
在基于 LLM 的 NLP 应用里，模型不仅要生成内容，还要在多任务间保持上下文一致和记忆能力。LangChain 正是围绕任务链 Chain 和内存模块 Memory 构建核心架构，这两块是实现复杂语言应用的关键。

#### 1. 任务链：管理复杂任务的执行
任务链是 LangChain 最基础的结构，提供模块化的方式来协调多步任务。

##### 1）任务链怎么工作
一个大任务会被拆成多个子任务，每个子任务独立运行但依赖前一步的输出。LangChain 里任务链由多个节点组成，节点间通过数据流串联。

##### 2）任务链类型与典型场景
按复杂度和需求，常见的任务链类型有：

（1）顺序链 Sequential Chain：按顺序执行多个子任务，适合任务间强依赖的场景。比如用户请求处理中依次做意图识别、信息抽取、响应生成。

#### 2. 内存模块：维护上下文与记忆
在多轮对话、复杂推理和长文本生成中，模型需要记住用户信息并保持连贯。LangChain 的内存模块就是为此设计的，通过持久化上下文记录和动态回溯，为任务执行提供记忆支持。

#### 2．任务链的设计与配置
任务链设计决定了 LLM 如何按逻辑顺序完成多个任务。一个任务链由文本生成、信息抽取、数据分析等多个子任务组成，具体选型看需求。

配置时需要指定各组件的顺序和依赖关系。借助 LangChain 提供的 API，调用逻辑能按预设流程自动运行，从而高效完成多步任务。

##### 4. 数据存储与内存模块集成

在需要复杂信息检索的场景，还会结合向量数据库。向量数据库对数据做向量化存储和相似度计算，能提高文本匹配与检索精度。LangChain 的架构让内存模块和向量数据库无缝协作，增强模型在信息管理和检索方面的能力。
