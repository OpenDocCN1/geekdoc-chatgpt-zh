# LoRA 五轮收敛实测

在算力受限的个性化排序场景里，LoRA 能以很小的改动成本完成二分类匹配的微调。选用二分类交叉熵作为目标，配合五次完整遍历，让参数沿着相对平滑的方向逐步收敛。

整体流程先固定损失形式，随后进入五轮循环。每轮把用户侧张量与条目侧张量各自压平并搬到当前设备，标签同步迁移。调用内部训练步更新低秩参数并累加当前轮的累计值，轮末打印平均情形。循环结束先跑一次离线评测，随后把权重写入磁盘并提示收尾，主入口由训练评估函数触发。

提示模板的组装允许带或不带额外背景，方便透传使用者往绩：
[PRE4]python
def generate_prompt(user_input, item_description, context_info=None):
    """
    根据用户输入和物品描述生成适合模型的提示词
    user_input: 用户的查询或行为
    item_description: 商品的描述
    context_info: 可选的上下文信息（例如用户历史数据）
    """
    # 如果有上下文信息，添加到提示词中
    if context_info:
        prompt=f"基于用户的历史行为 ({context_info}) 推荐；用户输入：{user_input}，物品描述：{item_description}。"
    else:
        prompt=f"用户输入：{user_input}，物品描述：{item_description}。"
    return prompt

文本生成环节在无梯度模式下执行，并通过长度与多样性参数控制输出质量：
[PRE5]python
def generate_recommendation(prompt):
    # 编码提示词
    inputs=tokenizer(prompt, return_tensors="pt")
    # 生成推荐内容
    with torch.no_grad():
        outputs=model.generate(
            inputs['input_ids'],
            max_length=100,
            num_return_sequences=1,
            no_repeat_ngram_size=2,
            temperature=0.7,
            top_p=0.9,
            top_k=50
        )
    # 解码并返回生成的推荐内容
    recommendation=tokenizer.decode(outputs[0], skip_special_tokens=True)
    return recommendation

对外调用把模板构建与生成串联成一步接口：
[PRE6]python
def recommend(user_input, item_description, context_info=None):
    # 生成适合的提示词
    prompt=generate_prompt(user_input, item_description, context_info)
    # 使用生成的提示词获取推荐结果
    recommendation=generate_recommendation(prompt)
    return recommendation
