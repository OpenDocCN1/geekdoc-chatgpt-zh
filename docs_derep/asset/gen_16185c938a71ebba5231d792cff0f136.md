# 第1章 数学基础
深度学习常涉及哪些数学基础？其数学难点何在？初学者常有此疑惑。网络与书籍推荐往往罗列微积分、线性代数、概率论、复变函数、数值计算、优化理论、信息论等科目。若按此范围学习，成本高且枯燥。本章挑选数学基础中易混淆的概念进行梳理，帮助理清彼此关系。

## 1.1 向量和矩阵
在深度学习中，向量与矩阵是基本数据结构。神经网络输入为向量，经矩阵线性变换后通过不断计算，最终最小化损失函数以完成模型优化，高效的向量矩阵运算是计算关键。

### 1.1.1 标量、向量、矩阵和张量
下面分别介绍标量、向量、矩阵和张量及其联系。

标量（scalar）
标量代表单一数值，与线性代数中研究的多数对象不同，后者通常由多个数构成。标量常用斜体小写字母表示。

向量（vector）
向量是一组按顺序排列的数。通过索引可确定每个元素。向量通常用粗体小写字母如 $\boldsymbol{x}$ 表示。元素可用带下标的斜体字母表示，如向量 $\boldsymbol{x}$ 的第一元素为 $x_1$，第二为 $x_2$，依此类推。并可注明元素类型，如实数、复数等。

矩阵（matrix）
矩阵是同质同维对象构成的集合，表现为二维数据表。其含义为一行表示一个对象，一列表示一个特征，每个特征对应数值型取值。矩阵常用加粗斜体大写字母如 $\boldsymbol{A}$ 表示。

张量（tensor）
当讨论超过二维的数组时即涉及张量。若数组元素分布在若干维坐标规则网格中，则称其为张量。张量 $\boldsymbol{A}$ 中坐标为 $(i,j,k)$ 的元素记作 $A_{(i,j,k)}$。

相关联系
标量是零阶张量，向量是一阶张量。可类比理解：

- 标量：仅知棍子长度，不知指向。
- 向量：除长度外，还知棍子指向前方或后方。
- 张量：除长度与前后指向外，还知上下与左右偏转。

### 1.1.2 张量与矩阵的区别
张量与矩阵区别如下。

（1）从代数角度看，矩阵是向量的推广。向量可视作一维表格，元素按顺序排列；矩阵可视作二维表格，元素按行列排列；$n$ 阶张量可视作 $n$ 维表格。张量的严格定义借助线性映射描述。

（2）从几何角度看，矩阵是一个真正的几何量，即不随坐标系变换而改变。向量亦具有该特性。

（3）在特定条件下，张量可用矩阵形式表达。

（4）表示标量的数与表示向量的三维数组可分别看作 $1\times1$、$1\times3$ 的矩阵。

### 1.1.3 矩阵和向量相乘的结果
若采用爱因斯坦求和约定，矩阵 $A$、$B$ 相乘得到矩阵 $C$ 可用下式表示：

$a_{ik} \times b_{kj} = c_{ij}$ (1-1)

其中 $a_{ik}$、$b_{kj}$、$c_{ij}$ 分别为矩阵 $A$、$B$、$C$ 的元素，$k$ 出现两次为哑变量，表示对该参数遍历求和。矩阵与向量相乘可视为矩阵相乘的特例，例如当矩阵 $B$ 为 $n \times 1$ 矩阵时。

### 1.1.4 向量和矩阵的范数归纳

#### 向量的范数
设向量 $a = [-5,6,8,-10]$。任一向量记为 $x = [x_1, x_2, ..., x_N]$。常见范数含义如下。

- 向量的1范数：各元素绝对值之和，如下式。上述向量 $a$ 的1范数为29。

$\|x\|_1 = \sum_{i=1}^{N} |x_i|$ (1-2)

- 向量的2范数：各元素平方和的平方根，如下式。上述向量 $a$ 的2范数为15。

$\|x\|_2 = \sqrt{\sum_{i=1}^{N} |x_i|^2}$ (1-3)

- 向量的负无穷范数：所有元素绝对值中的最小值，如下式。上述向量 $a$ 的负无穷范数为5。

$\|x\|_{-\infty} = \min_{1 \le i \le N} |x_i|$ (1-4)

- 向量的正无穷范数：所有元素绝对值中的最大值，如下式。上述向量 $a$ 的正无穷范数为10。

$\|x\|_{+\infty} = \max_{1 \le i \le N} |x_i|$ (1-5)

- 向量的 $p$ 范数：可视为2范数的推广，为元素绝对值的 $p$ 次方和的 $1/p$ 次幂。

$L_p = \|x\|_p = \left( \sum_{i=1}^{N} |x_i|^p \right)^{\frac{1}{p}}$ (1-6)

其中正整数 $p \ge 1$，并且。

#### 矩阵的范数
设矩阵 $\mathbf{A} = [-1, 2, -3; 4, -6, 6]$。任意矩阵定义为 $\mathbf{A}_{m \times n}$，元素为 $a_{ij}$。

矩阵范数定义如下：

$\|\mathbf{A}\|_p = \sup_{\|\mathbf{x}\|_p \neq 0} \frac{\|\mathbf{A}\mathbf{x}\|_p}{\|\mathbf{x}\|_p} \quad (1-7)$

向量取不同范数时对应不同的矩阵范数。

- 矩阵的1范数（列范数）：对每列元素绝对值求和，再取最大值，如下式。上述矩阵 $\mathbf{A}$ 的1范数先得 $[5,8,9]$，取最大值为9。

$\|\mathbf{A}\|_1 = \max_{1 \le j \le N} \sum_{i=1}^{M} |a_{ij}| \quad (1-8)$

- 矩阵的2范数：矩阵 $\mathbf{A}^T\mathbf{A}$ 最大特征值的平方根，假设 $\mathbf{A}$ 为实矩阵，如下式。上述矩阵 $\mathbf{A}$ 的2范数为10.0623。

$\|\mathbf{A}\|_2 = \sqrt{\lambda_{\max}(\mathbf{A}^T\mathbf{A})} \quad (1-9)$

其中为 $\mathbf{A}^T\mathbf{A}$ 的特征值绝对值的最大值。

- 矩阵的无穷范数（行范数）：对每行元素绝对值求和，再取最大值，如下式。上述矩阵 $\mathbf{A}$ 的行范数先得 $[6;16]$，取最大值为16。
