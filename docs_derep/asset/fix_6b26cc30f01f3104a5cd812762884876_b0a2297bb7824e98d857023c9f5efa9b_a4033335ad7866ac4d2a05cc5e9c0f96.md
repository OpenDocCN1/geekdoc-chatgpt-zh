## **2.3 与 DeepSeek 进行对话的基本流程**
DeepSeek 通过自然语言处理理解用户输入并给出回答，基本流程如下。
（1）打开 DeepSeek。
通过网页版、App 或 API 接口打开。
（2）用户输入。
用自然语言输入问题，如“我想了解今天的天气情况”。描述越清晰，理解越准确。
（3）DeepSeek 处理输入。
发送问题后，DeepSeek 分析语义、意图与上下文，并从知识库检索信息。
（4）DeepSeek 回答。
以文本或可视化形式返回结果，如“今天晴天，气温 20℃到 28℃”。若无法理解，会请求进一步澄清。
（5）用户进一步交互。
