## 3.2 用 ChatGPT 拆解背景与业务需求

在项目管理中，可用以下方式让 ChatGPT 辅助做项目背景和业务需求分析。

1．提供项目所处公司或行业的详细情况，让 ChatGPT 理解项目运行的环境与前提。包括业务范围、发展态势、组织架构和管理文化等。
2．说明项目提出的直接动因和管理层的期望目标，让 ChatGPT 明白项目启动的必要性与紧迫性。
3．详细列出项目要解决的核心问题及新管理模式的功能诉求，让 ChatGPT 明确关键目标与业务需求。
4．ChatGPT 综合以上信息，对项目的必要性、主要目标和关键需求做出判断，同时分析实施过程中可能遇到的主要难点与挑战。
5．我们需补充完善信息并提出进一步问题，以便 ChatGPT 做更精准全面的分析；也需对 ChatGPT 的结论给出自己的判断，形成共同认知。
6．在充分理解项目信息与特征后，ChatGPT 还能延伸应用到立项评估、方案选型、计划制定等环节，为决策提供系统参考。

总体而言，就是通过提供详实信息并与 ChatGPT 深度交流，让其形成清晰认知，进而开展后续启动与决策研究。
