## 5.1 线上智能体开发

线上智能体开发平台一般提供可视化操控界面，开发者无需深入底层算法与代码细节就能迅速搭起智能体，门槛大幅降低。它支持聊天机器人、虚拟助手、自动化流程执行类等多种形态，并内置大量预训练模型与算法库，可按需挑选并做定制化改进。同时平台提供简便的发布方式，可将成品快速推送至不同终端与场景，并配备完善的监控与管理体系，实时跟踪运行状态与性能指标并进行调优，从而提升开发效率与质量，加速智能体在各行业的落地。

以字节跳动的扣子平台为例，其可视化设计与编排能力让零代码或低代码构建基于大模型的项目成为可能，满足个性化需求并形成商业价值。

本节以扣子为案例，说明如何借助线上平台搭建单智能体、工作流与 AI 应用。选择扣子的主要考量有四点。

（1） **工作流设计灵活**。扣子工作流擅长处理逻辑复杂且对稳定性要求较高的任务链。平台提供了大量可组合的节点，包含大模型、自定义代码、判断逻辑等，即使没有编程基础也能通过拖拽快速拼装流程。例如可以搭建一份行业研究报告的自动撰写流程，让智能体生成完整报告。

（2） **能力边界持续扩展**。平台集成海量插件工具，显著拓宽智能体的能力范围。官方已发布多款功能丰富的插件，可直接接入智能体；同时支持基于已有 API 按参数配置方式自建插件，并在商店发布共享。

（3） **数据源多元**。内置简洁的知识库用于数据管理与存储，支持智能体与用户数据交互。本地大文件与网站实时信息均可汇入知识库，供智能体调用作答。

（4） **记忆功能强劲**。提供数据库级别的长期记忆，保证关键对话参数与内容被持久保存。例如建立阅读笔记库，记录书名、进度、个人批注等，智能体可据此查询给出更精准回应。

### 5.1.1 扣子智能体开发功能总览

扣子借助大模型简化了智能体搭建路径，在保留大模型优势的同时，配合知识库、工作流等手段确保回复符合预期。下面概览其核心功能。

#### 1．编排能力
扣子提供多款大模型及多样化配置，以应对不同复杂度任务。

（1） **提示词编辑**。提示词定义模型行为与生成响应的上下文指引。用户可为智能体设定人设、限制可回答范围、规范输出格式等，以提升准确度。平台的 AI 辅助优化功能可帮助提示词更结构化、更准确。

（2） **模型设置**。提供多模型选择，支持根据场景调节温度等参数，反复调试以获得更理想的对话效果。

（3） **编排模式**。默认单智能体模式，单一智能体完成全部任务；若需更复杂功能，可切换为多智能体模式，为不同角色配置专属提示词，将复杂问题拆解为若干简单子任务。

#### 2．搭建功能
通过知识、插件等手段解决幻觉与专业知识不足问题，并提供记忆能力提升交互质量。

（1） **技能**
**·** **插件** 通过 API 接入各类平台服务，扩展功能。内置丰富插件亦可自建，将所需 API 以工具形式内嵌。例如接入新闻插件搜索资讯，或使用通用搜索工具获取网络信息。
**·** **工作流** 用于规划复杂逻辑，通过拖拽任务节点提升复杂任务处理效率。
**·** **触发器** 让智能体在特定时间或条件下自动执行任务。

（2） **知识**
**·** **文本** 支持分段检索召回，大模型基于召回内容生成最终答案，适用于问答场景。
**·** **表格** 支持按索引列匹配，也支持 NL2SQL 查询与计算。
**·** **照片** 支持 JPG 等常见格式，通过图片标注实现检索召回。

（3） **记忆**
**·** **变量** 保存语言偏好等信息，实现个性化回复。
**·** **数据库** 以自然语言即可增删查改结构化数据，支持多用户模式实现精细读写控制。
**·** **长期记忆** 模拟人脑记忆个性化信息，支持更贴心的个性化回复。
**·** **文件盒子** 统一存储和管理多模态数据，保证合规且可重复调用。

（4） **语音对话**。除文字外支持语音交互，提供多款音色可选。

#### 3．设计能力
卡片是特殊消息展示形式，可自定义智能体输出格式，支持为工作流、插件绑定卡片。

#### 4．发布渠道
支持将智能体分发至商店、模板库、第三方应用、API、SDK 或自建渠道，实现更广覆盖。

#### 5．运营与运维
“预览与调试”区可对话测试并据此优化配置；若线上响应异常或缓慢，也可在该区查看执行细节排查问题。已发布智能体可通过分析看板追踪用户量、用户意图、消息记录等数据，指导定向优化。

### 5.1.3 工作流搭建实践
工作流是一组可执行指令的集合，用以实现业务逻辑或完成特定任务，为数据流动与任务处理提供结构化框架。核心在于融合大模型能力与业务流程，通过流程化方法实现高效 AI 应用。

扣子提供可视化画布，支持拖拽节点快速搭建，并可在画布上实时调试，直观看见数据流向与执行顺序。

#### 1．工作流与对话流
扣子提供两种形态。

（1） **工作流**：处理功能型请求，通过顺序执行任务实现特定功能，适用于报告生成、海报制作、绘本制作等自动化数据处理。

（2） **对话流**：面向对话场景的特殊工作流，擅长复杂业务逻辑的交互式处理，适用于聊天机器人、个人助手、智能客服、虚拟伴侣等。

#### 2．节点
工作流由节点构成，每个节点代表独立步骤或逻辑，负责数据处理、任务执行与算法运行，并具备输入输出。

每个流程默认含开始节点与结束节点。开始节点定义输入参数，结束节点返回结果。

通过引用节点输出可串联节点，形成操作链。例如代码节点可引用大模型节点输出作为输入，二者在画布上呈现连线，如图 5-5 所示。
