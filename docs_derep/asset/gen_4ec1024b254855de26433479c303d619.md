⑤ 马尔可夫链：一种描述随机过程的数学模型，下一个状态仅依赖当前状态，在文本生成和机器翻译等自然语言任务中广泛应用。

⑥ 离散空间：由不连续离散点构成的数学集合，在自然语言处理中常用于表示单词或符号等分立单元。

⑦ 邻域风险最小化策略：一种优化思路，让模型在训练数据邻域内的风险最小化，从而更好地泛化到未见过的新数据。

⑧ 鲁棒性：模型在噪声、异常值或不确定因素干扰下仍能保持稳定预测或分类能力的健壮程度。

### **自动摘要：高效提炼文本精华**

自动摘要利用自然语言处理技术，从给定文本中自动抽取出主题和关键信息，生成简洁精炼的摘要。该技术依托自然语言处理和人工智能的发展，通过算法与模型训练实现文本的自动化分析和提炼。

自动摘要主要基于以下技术：

❶ 文本理解：从词汇、语法到语义层面解析内容，深入把握原文含义。

### **6.3**

## **Embedding 实战：5 步训练语言模型**

Embedding 中文即嵌入，是自然语言处理中常用的模型，能把文本中的单词或其他单位映射到连续向量空间。简单说就是一种映射变换，将数字映射为一组向量。通过把文本转成固定长度向量，计算机能更好地理解和处理自然语言。

例如 Embedding 可学习文本与图像的共现关系，让 AI 绘画工具在生成图像时更贴合文本描述，提升准确性和相关性。本节以热门 AI 绘画工具 Stable Diffusion 为例，介绍训练绘画类 Embedding 模型的操作方法。

### **6.3.1**

### **认识模型：Embedding 训练总览**

Embedding 本质上是将高维数据映射到低维空间，在机器学习和自然语言处理中地位重要，其核心是用实值向量表示数据，使其在连续数值空间中表达语义。

理解 Embedding 需要先掌握词元、向量等基础。自然语言处理是对语言文字的分析，神经网络处理对象是数字，因此需对文字进行数字化。先做词元化，词元是样本集中最小的数据单元，常见做法是以单词为单元。随后将词元映射为数字，常用出现次数排序进行映射。

大部分 AI 训练师更倾向于做特征提取，用更具体的信息描述词元，使模型理解更好。总之 Embedding 是把数字映射成一组向量，为后续神经网络运算奠定基础。

训练 Embedding 模型能让语言模型以紧凑高效的方式编码输入文本的上下文信息，支持更连贯恰当的输出，即使输入被切分也不影响准确性。Embedding 训练的核心价值在于语义表示，支持向量运算，可在多个 NLP 任务间共享迁移。预训练 Embedding 后在小数据上微调，有助于提升语言模型在各类 NLP 应用中的准确性和效率。

在大型语言模型中，Embedding 训练对解决长文本输入问题越来越重要。通过把文本转为向量 Embedding 存入数据库，结合检索技术找到与问题最相似的文档，再把问题和检索到的 Embedding 一并交给大模型如 ChatGPT，即可回答与长文本相关的问题。

简而言之，Embedding 可视为一种预训练指导，在模型处理时提供操作指引。例如 Embedding 中包含“花”的信息，模型生成的图像就会呈现“花”的特征。

在正常使用时，只要提示词足够详尽，嵌入式模型的作用会相对减弱。有趣的是可以反向使用，例如把“画坏的手”信息纳入 Embedding，结合反向提示词，让模型尽量避免生成此类图像。

**温馨提示**

常见的 Embedding 模型包括 Word Embedding 和 Character Embedding。Word Embedding 将单词映射为向量，Character Embedding 将字符映射为向量，均通过神经网络等机器学习算法从大规模文本数据中学习得到。

训练 Embedding 通常采用无监督学习，如预测上下文词或字符来学习向量表示。训练完成后得到的向量可用于多种 NLP 任务，例如通过计算词向量相似度衡量词汇相似性，或作为分类、回归任务的输入特征。
