# ChatGPT 数据处理纠偏手记

先看销量排名的案例。ChatGPT 初步使用数据透视表把同一商品的多笔销量合并，这个方向是合理的。问题出现在排名逻辑上，它建议先把品类挑出来再套用 RANK，实际上变成逐品类单独计算。真实诉求是让全部品类同时列出，每个品类内部的商品各自形成排名，而不是靠筛选来切换视角。

纠偏的提示可以这样表达：

> 排名公式不对，需要把所有品类ID 下的商品ID 销量排名一起展示出来，而不是先筛选。

得到反馈后，ChatGPT 给出了一套可行的操作思路。

+ 1. 新建一张工作表专门做汇总与排名。
+ 2. 把原始订单表的品类ID、商品ID、销量三列复制到新表。
+ 3. D 列用来求品类与商品组合的销量合计，D2 输入：
=SUMIFS(原数据表！销量列, 原数据表！品类ID 列, A2, 原数据表！商品ID 列, B2)
把其中的列引用换成实际地址。
+ 4. 把 D2 向下填充。
+ 5. 选中 A、B、D 三列，通过 数据→删除重复项 去重，保留唯一的品类ID+商品ID 组合及其合计。
+ 6. E 列计算同品类内的销量排行，E2 输入数组公式：
=SUM(1*((SA$2:$A$7=A2)*($D$2:$D$7>$D2)))+1
把 SA$2:$A$7 和 $DS2:$DS7 换成实际的品类ID 与销量范围。
+ 7. 输入后不要直接回车，按 Cmd+Shift+Enter 或 Ctrl+Shift+Enter 确认，公式会带上大括号。
+ 8. 把 E2 向下复制。

完成后新表即可直接呈现各品类内的商品销量排行，无需手动筛选。
