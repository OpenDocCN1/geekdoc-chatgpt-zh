DeepSeek 四段实操，从写作到提示词自生成

想快速上手 DeepSeek，用兼容 OpenAI 的客户端做统一入口是最省事的做法。下面几段调用的骨架基本一致，只换对话内容就能覆盖自由创作、风格迁移、带限制的营销输出以及提示词自产等常见场景。

先看最简的单轮创作。仅用用户角色发起请求，让模型写一篇约七百五十字的深夜城市漫步散文，围绕游走者的情绪波动、所见细节和寂静带来的独特体悟展开。

[PRE0]python

from openai import OpenAI

client=OpenAI(

    base_url="https://api.deepseek.com/",

    api_key=""

)

completion=client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {

            "role": "user", 

            "content": "以“孤独的夜行者”为题写一篇750字的散文，描绘一个人在夜晚的城市中漫无目的地行走的心情与所见所感，以及夜的寂静给予的独特感悟。"

        }

    ]

)

print(completion.choices[0].message.content)

当需要锁定角色与输出规范时，就加入系统消息。第三段先把模型定位成广告语策划专家，强调创意性、简洁易记、押韵且只返回标语本身，随后在用户消息里指定一种酸奶品类来触发实际生成。

[PRE2]python

from openai import OpenAI

client = OpenAI(

    base_url="https://api.deepseek.com/",

    api_key=""

)

completion = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {

            "role": "system", 

            "content": "你是一个宣传标语专家，请根据用户需求设计\n一个独具创意且引人注目的宣传标语，需结合该产品/活动的核心价值和特点，同时\n融入新颖的表达方式或视角。请确保标语能够激发潜在客户的兴趣，并留下深刻印\n象，可以考虑采用比喻、双关或其他修辞手法来增强语言的表现力。标语应简洁明了\n了，需要朗朗上口，易于理解和记忆，一定要押韵，不要太过书面化。只输出宣传标\n语，不用解释。"

        },

        {

            "role": "user", 

            "content": "请生成"希腊酸奶"的宣传标语。"

        }

    ]

)

print(completion.choices[0].message.content)

最后展示模型的自反用法。系统角色被设为提示词工程师，要求以 Markdown 呈现、明确定位与能力边界、保持精简且不带额外说明，再让它为面向操作系统的技术支持助手生成一份可直接使用的系统指令。

[PRE4]python

from openai import OpenAI

client = OpenAI(

    base_url="https://api.deepseek.com/",

    api_key=""

)

completion = client.chat.completions.create(

    model="deepseek-chat",

    messages=[

        {

            "role": "system", 

            "content": "你是一位大模型提示词生成专家，请根据用户的需求编写一个智能助手的提示词，指导大模型进行内容生成，要求：\n1. 以Markdown格式输出\n2. 贴合用户需求，描述智能助手的定位、能力、知识储备\n3. 提示词应清晰、精确、易于理解，在保持质量的同时，尽可能简洁\n4. 只输出提示词，不要输出多余解释"

        },

        {

            "role": "user", 

            "content": "请帮我生成一个\"Linux助手\"的提示词"

        }

    ]

)

print(completion.choices[0].message.content)
