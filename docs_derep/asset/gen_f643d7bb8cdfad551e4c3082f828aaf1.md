TensorFlow 核心概念：张量、计算图与三大组件

在 TensorFlow 体系里，所有输入输出都必须是张量形态，不接受 Python 原生的 Int、Double 等直接类型。哪怕只是一个数字 1，也要先被包成一个 0 维、长度为 1 的张量。张量本质上就是多维数组，能够表达一维到 n 维的任意结构。换句话说，TensorFlow 中的一切数据都是 n 维数组，只是统一称作张量。张量由阶、形状、数据类型三要素构成。形状可以理解为各维的长度，例如形状为 2 的张量就是一维长度为 2 的数组；阶则对应维度的数量。

要理解任何深度学习框架，先要建立张量的概念，它是向量与矩阵的泛化。向量是一维，矩阵是二维，张量则可拓展到任意维度。

直观上 TensorFlow 是张量的流动，计算节点保持不变，数据在图中流动。所有程序都先搭建计算图，定义张量运算与数据处理的流程。

计算图是一个有向图，每个节点代表一次数学操作，边则代表节点间传递的多维数组即张量。

以向量相加为例，整体思路是通过定义并执行计算图完成加法，再借助会话对象运行。会话封装了评估张量与操作的环境，真正执行计算并把结果从一层传到另一层。
