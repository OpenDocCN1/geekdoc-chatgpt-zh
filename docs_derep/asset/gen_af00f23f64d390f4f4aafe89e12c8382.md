Python 社区对可读性要求很严，函数名保持全小写加下划线的风格是最基础的约定。下面用创建圆的例子先感受一下这种写法。

def create_circle(radius):

    """

    创建一个圆的实例。

    :param radius: 圆的半径

    :return: Circle 实例

    """

    return Circle(radius)

# 主程序入口

if __name__ == "__main__":

    # 创建一个半径为 5 的圆

    circle = create_circle(5)

    # 计算并打印圆的面积

    print(f"圆的面积是: {circle.calculate_area()}")

[PRE1]

异常处理是另一套必备肌肉记忆。try 负责包裹可能出错的逻辑，except 捕获并处理，else 在一切正常时执行，finally 无论如何都要收尾。

try:

    有可能发生异常的语句

except Exception as variable:

    处理异常的语句

else:

    不发生异常才执行的语句

finally:

    不管异常是否发生都要执行的语句

[PRE2]

实际文件操作里，finally 保证资源一定被释放，是最常见的落地写法。

file = None

try:

    file = open('example.txt', 'r')

    data = file.read()

except FileNotFoundError:

    print("文件未找到")

finally:

    if file:

        file.close()
