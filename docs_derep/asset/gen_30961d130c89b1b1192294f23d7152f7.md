# 掌握SD高阶语法，告别颜色“串色”烦恼

在给人物设定造型时，我们常会一次性堆砌发色、上衣色、裤色等多个颜色词。人类阅读时逻辑通顺，但AI往往“听不懂”归属关系，导致生成图出现颜色“串位”——指定的色调都有了，却跑错部位。要破解这个难题，关键在于用结构化语法精准锚定意图，消除词汇间的干扰。

## 核心语法：主体+括号分组

**标准格式：`主体 (描述词1, 描述词2, ...)`**

实战案例：`1girl (purple curly hair, dark blue suit)`
解析：英文括号将特征锁定在“1girl”这一主体下，等同于告诉AI：“这是个女孩，特征包含：紫色卷发+深蓝西装”。

## 进阶技巧：权重微调，强控细节

通过 `(关键词:数值)` 形式分配关注度，数值>1增强，<1弱化。

案例：`1girl ( (purple curly hair:1.2), blue eyes, sunglasses, lipstick, (dark blue suit:1.4) )`
效果：紫发权重1.2、深蓝西装权重1.4，强制模型优先落实重点特征。多主体同框时，此法能大幅降低“污染”概率，显著提升首次出图成功率。

# 善用BREAK分组，破解Token截断陷阱

多数人不知：SD按**每75个Token**强制切片理解提示词。输入框右上角显示 `53/75`，分子为已用量，分母为单组上限。若单主体描述超75 Token，系统会硬切分组，导致语义碎片化、特征错位。

**对策：手动插入 `BREAK` 强制分段**，让同一主体的描述聚合在同一组内。

### 实战模板（三段式结构）

```text
1girl, (purple curly hair), blue eyes, sunglasses, lipstick, (dark blue business suit:1.4), slim body, (walking), looking at viewer
BREAK
1man, (black hair), black eyes, sunglasses, white shirt, tall, strong, take suitcase, (walking), looking back
BREAK
street_background, best quality, ultra detailed, perfect lighting, detailed background, realistic, solo, perfect detailed face, detailed eyes
```

**逻辑拆解：**
- 第1段：主体A（女孩）全维度描述
- 第2段：主体B（男人）全维度描述  
- 第3段：环境/画质/风格等公共参数

⚠️ **避坑指南**：全图 `BREAK` 不宜超3次，分组过碎反而扰乱模型注意力，得不偿失。

# 第4节 参数调教指南：从“懵圈”到“得心应手”

初见WebUI密密麻麻的参数栏（Sampler、Steps、CFG Scale、Seed…）劝退无数新手。实则掌握核心四参数，即握住生图方向盘。

## 1. 采样器与步数：去噪的“节奏与步伐”

**原理速览**：SD生图=纯噪声→逐步去噪→成图。采样器决定“如何去噪”，步数决定“走多少步”。

- **收敛快、风格硬**：DPM++ 2M Karras、DDIM（20-30步足矣）
- **收敛慢、随机性强**：Euler a、DPM++ SDE Karras（需30-50步）
- **避坑**：步数非越高越好。噪声曲线显示：前期下降陡、后期趋平；超阈值只增显存不增质量。

## 2. CFG Scale（相关性/引导系数）：创作自由度的“阀门”

| 数值区间 | 效果表现 | 适用场景 |
| :--- | :--- | :--- |
| **0-1** | 图片崩坏 | 禁用 |
| **2-6** | 脑洞大开，极弱跟随提示词 | 探索灵感、抽象艺术 |
| **7-12** | **黄金区间**：创意与指令平衡 | **日常首选** |
| **13-15** | 画面对比度/饱和度飙升，死磕提示词 | 强控构图、特定风格复刻 |
| **>16** | 烧图、伪影严重 | 禁用 |

## 3. Seed（随机种子）：复现与微调的“定海神针”

- `-1` = 随机种子（每次风格迥异）
- **固定数值** = 锁定构图骨架。改提示词微调细节（如换衣、换发色），主体身姿、布光、构图高度一致。这是批量产出连贯素材的核心技巧。

- **正向提示词**（双BREAK三段式）：
  ```text
  (handsome boy:1.3), blue shirt, (Bokeh:1.1), (photorealistic:1.4), look to the side, (intense warm sunshine:1.3), blue sportswear, solo, laugh, basketball uniform, realistic, sleeveless, jersey, basketball, open mouth, teeth, short hair, messy hair, sweat, basketball court, portrait, indoors, ray tracing
  BREAK
  (best quality), (masterpiece), (highres), original, extremely detailed 4K wallpaper, (an extremely delicate and beautiful), incredibly_absurdres, colorful, intricate detail, 1man, <LoRA:LoRA-Custom-ModelLiXian:0.4>, <LoRA:FilmVelvia3:0.6>
  ```

# 第6节 图生图 & 局部重绘：把“改图”变成“精修”

## 基础图生图
上传参考图+提示词+参数 → 保留原图构图/色调，按指令重绘细节。适合风格迁移、局部氛围调整。

## 局部重绘 核心参数详解（Inpaint模式）

| 参数 | 推荐设置 | 核心逻辑 |
| :--- | :--- | :--- |
| **缩放模式** | **裁剪后缩放** | 原输出尺寸不一致时保持比例不变形 |
| **蒙版模糊** | **默认(4-8)** | 边缘羽化过渡，防止修补痕迹生硬 |
| **蒙版内容** | **原版** | 仅保留原图像素，不引入噪声/纯色干扰 |
| **重绘范围** | **仅蒙版区域** | 放大绘制再缩回，**细节更锐利**（整张重绘融合好但糊） |
| **重绘幅度** | **0.55-0.75** | 越低越像原图，越高越自由。0.75平衡融合与创新 |
| **蒙版模式** | **重绘蒙版内容** | 只改圈选区域，其余锁死 |

> **黄金法则**：先“整张低幅度”融合大调子，再“仅蒙版高幅度”雕琢细节。

# 第7节 ControlNet：让AI听话摆 Pose、画线稿、换装

**定位**：LoRA管“长相/风格”，ControlNet管“骨架/结构/布局”。强强联手=完全可控生产力。

## 界面三区速览
1.  **上传区**：拖入参考图/草图
2.  **控制类型（预处理器）**：选错类型=白费力
    - **OpenPose** → 骨骼关键点（人体姿态、手势、面部）
    - **Canny / LineArt** → 硬边缘/线稿（构图、建筑、产品轮廓）
    - **Depth / Normal** → 深度/法线（空间立体感、3D感）
    - **MLSD** → 直线几何（室内硬装、建筑线框）
    - **Scribble** → 涂鸦草图（创意发散、草图上色）
    - **Seg** → 语义分割（区域级控制）
3.  **控制参数区**：权重、起止步数、控制模式（平衡/提示词优先/ControlNet优先）

## 实战案例：实拍照“换装+改姿势”全流程

**需求**：真人街拍照 → 右手从兜里拿出下垂 + 白衬衫换蓝T恤 + 黑发变金发。

**操作链路**：
1.  进 **ControlNet**，传原图，选 **OpenPose** → 预处理器 `openpose_full`（含身/手/脸）。
2.  点“炸裂图标”出火柴人 → 进**编辑器**拖拽右手/右肘节点 → 自然下垂。
3.  点“发送姿势到ControlNet”回主界面。
4.  主界面：选实写实底模 + 正向词写“blue t-shirt, blonde hair...” + 负向词兜底。
5.  出图 → 如T恤花纹乱，进**局部重绘**蒙版T恤区 → 提示词加 `plain blue t-shirt` → 重绘幅度0.65 精修。

**延展玩法**：
- **草图上色**：涂鸦草图 → ControlNet选 **Scribble** + 着色风格LoRA → 秒出插画成品。
- **毛坯变精装**：CAD线稿/毛坯照 → ControlNet选 **MLSD** 提取几何线框 → 搭配室内设计LoRA + 提示词“现代简约/北欧风” → 一键出精装效果图。
