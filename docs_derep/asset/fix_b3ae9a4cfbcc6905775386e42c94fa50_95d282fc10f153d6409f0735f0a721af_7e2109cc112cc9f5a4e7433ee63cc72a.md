## 8.7 本章小结
底模与提示词是 Stable Diffusion 出图的双核心，多数情况下先定模型再细化描述。模型大致分为大底模与 LoRA 等，大底模可单独使用，LoRA 必须依托大底模配合。

提示词用于刻画画面内容，可对关键词加权，也能让两组描述在迭代中轮换出现，便于做人物融合等需求。

本章通过几组实操让读者对工具的能力边界建立初步认知。篇幅所限举例有限，实际上只要模型与提示词搭配得当，几乎可覆盖任一风格与题材。Civitai 等社区汇聚了全球创作者的作品，可在其中观摩更多案例并汲取方法。

## 第 9 章
### Stable Diffusion 进阶用法
上一章已说明如何借助合适模型与提示词完成不同风格的绘画。

实际创作中常会碰到复原旧作、对已有画面做局部微调、指定人物姿态等需求，这些能否实现？答案是可以。

本章将继续下探，介绍 Stable Diffusion 的进阶能力，帮助创作者把意图表达得更精准，获得更大自由度。

### 9.1 获取图片提示词

#### 9.1.1 使用 Stable Diffusion 生成的图片
若目标图本身就是 Stable Diffusion 产出，流程会更直接，因为绘图时相关参数会被写入 PNG 的隐层信息，可在 Web UI 中调取。

通过此方式不仅能找回正向提示词，还能看到反向提示词、迭代步数、采样方式、CFG、随机数种子、尺寸、模型等信息。

[PRE1]

需要说明的是，该功能只是读取 PNG 元数据，并非基于图像内容分析。因此，若图片并非由 Stable Diffusion 生成，或生成后被压缩修改导致元信息丢失，就无法使用。此时需把图片当作普通素材，按下文方法处理。

### 9.2 图像扩展
图像扩展并非等比放大，而是让 AI 在原图边缘自动补足内容，从而延伸画面边界。

如果忘记了或者不知道提示词，可参考 9.1 节的内容获取图片的提示词。

图像扩展和绘制图片一样，受模型、提示词的影响很大，因此需要选择风格尽可能接近的模型，同时填写尽可能准确的提示词。

可以扩展任何图像，不过要获得最佳效果，最好是扩展由 Stable Diffusion 生成的图片，并且模型、提示词、采样算法等参数也与图片生成时保持一致。

### 9.4 姿势控制
使用 Stable Diffusion 创作一段时间后，可能会发现想精确控制图像中人物的姿势似乎不太容易，毕竟文字的表现力有限，一些姿势很难用提示词精确描述，或者即使描述了 AI 也不能完全理解。那么，有办法让生成的人物摆出指定的姿势吗？答案是肯定的。借助 ControlNet，可以生成任何想要的人物姿势。

#### 9.4.1 什么是 ControlNet
ControlNet 是 Stable Diffusion 的一个扩展，它带来了很多强大的功能，例如让创作者可以精确地控制人物角色的姿势、将线稿转为其他类型的图像等。

#### 9.4.2 安装 ControlNet
01 ControlNet 和其他扩展一样，可在 Web UI 界面单击顶部的“扩展”标签页，进入“扩展”界面进行安装。
