# 破解多智能体规模瓶颈：从均场理论到持续进化的演进之路

智能体群体规模一旦扩大，动作与状态空间便会遭遇“指数级爆炸”，这构成了制约多智能体学习扩展性的核心障碍。当参与者超过两个时，纳什均衡的求解难度剧增，几近不可行。针对这一困局，均场理论引入了新视角：Yang 等学者借助均场思想，推出了均场 Q 学习与均场 Actor-Critic 算法，为大规模群体智能提供了可行的求解范式。

在方法论谱系上，传统多智能体强化学习与博弈论奠定了通用策略学习的基石。面对元博弈层面的种群演化需求，Muller 等人将分布式计算框架引入自主学习，创立了 $\alpha$-Rank 与 PSRO 等前沿技术路线。与此同时，兼容并行分布式架构的演化策略学习，为无导数的博弈策略优化开辟了新径；面向连续博弈场景的策略优化技术，则依托策略梯度机制，给出了另一套核心解法。

此外，环境的非平稳特性迫使智能体必须持续适应动态变化，这使得“持续学习能力”不再是可选项，而是智能体生存与进化的必备素质。
