## 6.7 快速实操：Stripe 打通付费闭环

为积分体系加上商业级收款能力。借助 Stripe 这类主流支付平台，可以快速形成从下单到充值的自动化闭环。

### 6.7.1 Stripe 商品与价格配置

在 Stripe 控制台里可视化创建商品，无需编码，流程如下：

1. 登录 Stripe 账号并切到测试模式。
2. 进入 Products 目录。
3. 新建商品。先创建两个订阅商品，定名为“爱好者套餐”和“专业套餐”，分别挂上每月 10 美元、25 美元的循环价格；再建一个一次性商品，命名为“积分包”，挂上 5 美元的一次性价格。
4. 补充元数据。这是把 Stripe 商品与内部积分系统打通的关键。为每个 Price 填入自定义元数据：
- 爱好者套餐：key 为 credits，value 为 100。
- 专业套餐：key 为 credits，value 为 500。
- 积分包：key 为 credits，value 为 50。

支付成功后 Webhook 会读取这些元数据完成自动充值。汇总见表6-3。

### 6.7.2 结账流程对接

参考 Vercel 官方 Next.js + Supabase + Stripe 订阅模板的做法：

1. 创建结账会话。新建路由 `app/api/stripe/create-checkout-session/route.ts`。用户点击购买时，前端携带 price_id 调用，后端在 Stripe 中创建或检索 customer，随后使用 Node 客户端创建会话并把 session_id 返回。
2. 跳转支付页。前端拿到 session_id 后调用 Stripe.js 的 `redirectToCheckout`，把用户带到 Stripe 托管的结账页。支付敏感信息全部由 Stripe 处理，应用侧无需触碰，PCI 合规成本大幅降低。
3. 处理支付回调。在 Stripe 后台配置 Webhook 指向 `app/api/webhooks/stripe/route.ts`，重点监听 `checkout.session.completed`。支付成功后 Stripe 会 POST 事件详情，后端据此为用户充值。

## 6.8 快速实操：Resend 实现邮件自动化

优秀的 SaaS 必须在关键节点主动触达用户。Resend 是一款面向开发者的现代化邮件 API，可用来构建智能自动化的通信体系。

### 6.8.1 生命周期自动化邮件

基于 Supabase 与 Resend 覆盖注册到订阅的全链路，配置三种自动化：

- **注册欢迎邮件：** 在 Supabase 为 `auth.users` 表创建触发器，新用户写入时触发边缘函数，通过 Resend SDK 发送欢迎邮件。
- **使用指南邮件：** 借助 Supabase 内置的 `pg_cron` 扩展，每天定时筛选注册满三天的用户，发送包含进阶技巧的指南邮件。
- **续费提醒邮件：** 同样用 `pg_cron` 每日查询即将到期的有效订阅，调用边缘函数在续费日前三天发出提醒，降低非主动流失。

### 6.8.2 异步任务完成通知

像 AI 图像生成这类异步功能，用户提交后需等待结果。邮件通知是提升体验的有效方式，可集成到 Replicate Webhook 路由 `/api/webhook/replicate`。

当收到生成成功回调且图片已保存到 Supabase Storage 后，在完成数据库写入前，增加一步：调用 Resend API 发送主题类似“你的 AI 作品已生成”的邮件，正文可附缩略图预览和直达个人作品页的链接。

### 6.8.3 行为触发式营销邮件

邮件还能做进阶营销自动化。例如低积分提醒与促销，当用户剩余积分低于阈值如 5 分时自动触发个性化邮件。

实现上可在每次积分扣除的 Supabase 边缘函数里加入余额检查，低于阈值则调用另一边缘函数，通过 Resend 发送含个性化文案和优惠的邮件，刺激充值。

接入 Resend 后，产品从被动响应工具转变为能主动沟通的平台，用户体验与商业目标更紧密。

## 6.9 快速实操：Vercel 上线生产环境

本地开发结束，进入线上部署。Vercel 为 Next.js 提供高度集成的部署体验。

### 6.9.1 环境变量配置

在 Vercel 项目的环境变量页，依次填入本地 `.env.local` 的所有密钥：

- Supabase 的 URL、ANON_KEY、服务端的 SERVICE_ROLE_KEY；
- Replicate 的 API_TOKEN；
- Stripe 的 SECRET_KEY 和 WEBHOOK_SECRET；
- Resend 的 API_KEY。

这样变量会在构建和运行时安全注入，避免敏感信息进入代码仓库。

### 6.9.2 域名绑定与 SSL

在 Domains 页面添加已购买的自定义域名，按 Vercel 提供的 DNS 记录，通常是 A 记录或 CNAME，在域名服务商后台配置。生效后 Vercel 会自动申请、配置并续期免费的 Let's Encrypt 证书，实现全站 HTTPS，无需手工操作。

### 6.9.3 性能优化

Vercel 自带多项优化：

- **全球边缘网络：** 每次 git push 触发部署后，应用会分发到遍布全球的边缘节点，用户自动就近访问，显著降低延迟。
- **图像优化：** Next.js 的 `<Image>` 组件与 Vercel 网络深度集成，展示 Supabase Storage 图片时会自动进行格式转换、尺寸缩放并缓存到全球 CDN。
- **边缘函数：** 所有 Next.js API 路由如 `/api/generate-image`、`/api/webhook/*` 以及服务端组件的数据请求，都会被部署为高性能边缘函数，后端逻辑同样靠近用户，响应更快。

Vercel 把繁琐的基础设施运维抽象掉，让开发者聚焦产品本身。
