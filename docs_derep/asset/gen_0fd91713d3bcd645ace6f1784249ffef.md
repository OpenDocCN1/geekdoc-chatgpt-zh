## 3.3 LlamaIndex 到底是什么

在以大模型为核心的应用开发赛道里，LangChain 并不是唯一选择。LlamaIndex 也是口碑很不错的开源 AI 应用开发框架。它在 2022 年 11 月对外开放，和 ChatGPT 同月诞生，只比 LangChain 晚一个月左右。两者都明显受 ChatGPT 的推动，也因此得到广泛认可。

### 3.3.1 LlamaIndex 的来历与定位

LlamaIndex 由 Jerry Liu 发起，2023 年 6 月拿到 850 万美元种子轮。它解决的是大模型天生缺乏训练外知识的短板，所以在 AI 圈子里很受欢迎。

和 LangChain 的“大而全”路线不同，LlamaIndex 更聚焦于先进的基于 AI 的 RAG 技术，以及多租户 RAG 系统的搭建。基于 LlamaIndex 的企业方案主打消除技术和安全门槛，提升企业对数据的利用和服务能力。它的工作不仅限于技术本身，还强调把技术落到真实场景，去提高业务效率和用户体验。

> 小雪：多租户是什么意思？
> 
> 咖哥：可以这样想，在一个 RAG 系统里，用户 1 和用户 2 各自有一套独立的文档。多租户机制保证用户 1 查询时只会从自己的文档里取结果，不会被用户 2 的数据干扰，反之亦然。这是数据隔离和安全的基础。

另外不得不提，LlamaIndex 在文档组织和可执行性上明显优于 LangChain。这体现了它在用户体验、接口设计和技术实现上的投入。对开发者和最终用户而言，这种优势有助于技术更快普及和使用效率提升。

或许正因为 LangChain 摊子铺得太大，面面俱到反而显得繁杂，很多细节不够精致。你去看 LangChain 的 GitHub 主页，未解决的 Open Issues 就有上千条。所以如果你的核心是文档检索与增强生成，选择“小而美”的 LlamaIndex 更合适。

### 3.3.2 LlamaIndex 与基于 RAG 的 AI 开发

RAG 是当前 AI 应用开发的重点方向，和 Agent 一样重要。RAG 的本质是检索加生成：先从相关数据源里检索信息，把这些信息作为上下文注入用户查询，再让大模型基于丰富提示生成回答。类似 Agent，RAG 也有大量落地案例，某种程度上 RAG 应用本身就可以视作一种 Agent，或是 Agent 构建的关键技术之一。

先从宏观解释 RAG 的价值。把大模型用到特定行业，从难到易大致有四种：重新训练或从头建模、微调、动态提示——RAG 就属于这一类，以及最简单的提示工程，见图 3.18。RAG 处于中间位置，比重训或微调轻松，比直接提问要复杂。它规避了直接微调的三大痛点：成本高、信息难更新、可观察性差。RAG 无需训练成本更低；数据实时获取始终新鲜；检索到的文档可展示，结果更可信。

具体工具包括：

整个流程共 6 步。

1. 用户提出查询：用户向系统提交问题或请求。
2. Agent 搜索相关信息：Agent 按查询去搜相关信息，可通过互联网或特定数据库，通常企业内部信息会存入向量数据库。
3. 检索信息：从搜索结果中抽取具体信息，作为生成回答的上下文。
4. 相关信息传给大模型：Agent 把检索结果和原始查询一起交给大模型。
5. 大模型生成响应：大模型利用这些信息生成丰富且信息化的答案。
6. 回答用户请求：最后把大模型生成的答案交还用户，答案基于原始查询和检索到的信息。

过程也可以循环，每次查询都会优化后续交互。如需更多信息或有追问，系统会提示额外查询，并利用前次回答丰富新上下文。这样能提供更动态、交互式的体验，让用户用自然语言完成复杂交互。

用 LlamaIndex 搭建上述基于 RAG 的 Agent 非常轻松。它面向从新手到资深的各个层次开发者，高级 API 允许初学者用 5 行代码完成数据提取与查询；底层 API 则让高级用户按需定制和扩展模块。

## 3.4 小结

OpenAI 等大模型头部厂商的创新，为开发者构建类 Agent AI 应用提供了新工具，推动 LangChain、LlamaIndex 等生态发展。这些工具各有侧重，但都致力于更高效灵活的 AI 应用开发，从而推动行业创新与协作，带来更丰富场景和更强开发能力。

两者各具特色：LangChain 是“大而全”，LlamaIndex 是“小而美”。它们既竞争又合作，可相互调用。竞争促使其不断优化，合作则让整个生态更进步，最终让开发者和用户受益。

随着大模型技术持续演进，这些工具也在不断迭代。它们让构建复杂智能 Agent 成为可能，并不断拓展 AI 的边界和应用领域。

借助这些工具，我们能打造更智能、更高效的 Agent，在各种复杂环境中执行任务和提供服务。随着技术进步，会有更多创新应用出现，推动人工智能边界持续拓展。

当然，大模型应用开发仍处“婴儿期”，开发者和组织面临诸多挑战：API 调用频率与性能、程序稳定性与效率、未来可扩展性与维护，以及数据隐私、安全、伦理与效率等问题。同时机遇也巨大，可以创造更智能、更有用的工具和服务，为各行业带来变革。
