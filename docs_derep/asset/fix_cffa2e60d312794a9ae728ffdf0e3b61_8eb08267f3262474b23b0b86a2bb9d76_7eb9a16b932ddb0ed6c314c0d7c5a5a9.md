### 13.3.1 并行计算底层思路

并行处理指多项计算或进程同时推进。串行则是任务依次完成。并行让任务重叠进行，提升整体速度与吞吐。

并行可在多类计算单元展开，如多处理器、多加速卡、多节点集群，如图 13.3.1。加速硬件既有昇腾 AI 处理器，也有 GPU、TPU、FPGA 等。并行硬件擅长解决大量计算密集场景，应用遍及科研、工程、图形、数据分析等。

本小节先梳理并行结构分类，再谈大模型并行加速基础，最后用量化方法评估效率。

#### 1. 并行结构分类概览

从硬件、系统、应用三层看，可分为指令级、线程级、请求级三种。

**指令级并行 ILP** 指 CPU 内同一周期能并发执行多条指令，无需开发者手工优化，由硬件自动调度。常见手段：

- **超标量 Superscalar**：每周期向不同执行单元发射多条指令，内部配备整数、浮点、访存等单元实现重叠。
- **流水 Pipelining**：指令拆成微操作，各指令阶段交叉推进。典型四段为取指 IF、译码 ID、执行 EXE、写回 WB。

**线程级并行 TLP** 通过创建多线程实现，在多核系统上各线程可真并行。多见于操作系统、数据库、服务端，通常需开发者显式管理。

**请求级并行 RLP** 常见于服务侧，服务器并发接收多个独立请求，为每个请求启动独立流程并行处理，提升服务能力与响应。

从软件视角，可分为数据并行与任务并行。

**数据并行** 将大集合拆分，小块在不同单元上以相同操作处理不同分片。适合数组、向量、矩阵，常用于科学计算与图像。

**任务并行** 将工作拆成可独立运行的任务，在不同单元同时执行。任务间可依赖也可独立，需设计适配硬件的算法，在软件工程、复杂事件、多媒体领域广泛使用。

以发薪为例帮助理解。假设每月需处理数百万员工薪酬。

数据并行视角下，全部薪酬计算被切分，分发到不同单元。每个单元执行相同逻辑但仅处理分配到的分片，例如单元一处理 1-1000 号员工，单元二处理 1001-2000 号，各自完成个税、福利计算后生成对应条目。

任务并行视角下，各单元承担不同职能，例如单元一负责全体税务扣除，单元二负责全体福利。此时每个单元读取完整数据集，但只执行特定职能，最后汇总生成完整薪酬单。

此外，Micheal J. Flynn 1966 年提出的 Flynn 分类法按指令流与数据流组织方式划分体系结构，相关内容见第 3 章与第 12 章。该分类有助于理解，但随着 GPU、众核与异构计算发展，已难以覆盖全部模式，故出现更复杂模型。例如单程序多数据 SPMD，在 SIMD 基础上扩展，各处理器拥有独立控制部件时可通过软件让各处理单元并行执行同一程序但处理不同数据，Ascend C 即基于昇腾 AI Core 构建 SPMD 模型。

### 13.3.2 Ascend C 编程体系

#### 1. 编程概述

面向算子开发的 Ascend C 原生兼容 C 与 C++ 规范，贴合使用习惯；依托多层接口抽象、自动并行、孪生调试等技术，显著提升算子开发效率，帮助开发者低成本完成开发与模型调优部署。

主要优势：

- 用 C/C++ 原语编程；
- 编程范式屏蔽硬件差异，提升效率；
- 类库 API 由简到繁，兼顾易用与高效；
- 孪生调试可在 CPU 端模拟 NPU 行为，优先在 CPU 端调试。

#### 2. 编程模型

AI Core 是昇腾 AI 处理器执行计算密集任务的核心算力单元。本节先介绍 AI Core 的硬件抽象，包括计算、存储、DMA 搬运，再介绍 SPMD 模型与流水编程范式，二者可有效提升并行效率与加速比。

##### 1) 硬件抽象

##### 3) 流水编程范式

软件与硬件结合是提升性能的关键，要让计算资源保持高占用。流水化是常用手段，将完整任务模块化，模块间形成流水关系并用队列处理异步并行。

Ascend C 本质是标准 C++ 加上一组扩展语法与 API。本节先介绍基础语法扩展，再讨论基础 API 与高阶 API，随后对数据存储、任务间通信与同步、资源管理、临时变量等关键编程对象进行解读，为后续编程范式讲解奠定基础。

### 13.4.1 语法扩展总览

Ascend C 采用华为自研毕昇编译器，设备侧编程在 C/C++ 语法上扩展，允许函数执行空间和地址空间作为合法类型限定符，从而实现主机 Host 侧与设备 Device 侧独立执行，并提供针对不同地址空间的访问能力。

#### 1. 函数执行限定符

函数执行空间限定符指示函数在主机还是设备上执行，以及是否可被主机或设备调用，主要有三种声明方式：

第一类：`__global__` 执行空间限定符。声明 Kernel 函数，即 Ascend C 算子入口，特性如下：

- 在设备上执行；
- 只能被主机侧函数调用；
- `__global__` 仅表示设备侧函数入口，不指定具体设备类型；
- 必须返回 void，不能是类的成员函数；
- 主机侧调用需使用 `<<<>>>` 内核调用符进行异构调用；
- 调用是异步的，返回不代表设备侧已完成，需用运行时同步接口如 `aclrtSynchronizeStream(...)` 显式同步。

第二类：`__aicore__` 执行空间限定符。声明的函数可在 AI Core 设备上执行，只能被 `__global__` 函数或其他 AI Core 函数调用。

第三类：`__host__` 执行空间限定符。声明的函数通常默认在主机侧执行，只能被主机侧函数调用；`__global__` 与 `__host__` 不能共用。

#### 2. 地址空间限定符

地址空间限定符用于变量声明，指定对象分配区域。AI Core 具备多级独立片上存储，各地址空间独立编址并有各自访存指令。若类型被地址空间限定，对象将被分配到指定空间，指针类型也可通过地址空间限定指向对象所在空间。
