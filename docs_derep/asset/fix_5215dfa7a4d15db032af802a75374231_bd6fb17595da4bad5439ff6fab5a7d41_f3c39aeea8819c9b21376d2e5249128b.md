## 1.3 DeepSeek 全面拆解

DeepSeek 系列源自杭州深度求索人工智能基础技术研究有限公司，该主体在 2023 年 7 月成立，隶属于幻方量化，核心主张是用高性能低成本的开源大模型推动 AI 在多领域的普及落地。2025 年初，团队在同名模型家族基础上推出了推理型 AI 对话产品，发布后两周内全平台用户突破 1 亿，登顶 140 余个国家苹果 App Store 与安卓应用商店榜首，增速超越 ChatGPT。未作特别说明时，下文 DeepSeek 均指向模型家族，其长期愿景是迈向通用人工智能。

### 1.3.1 DeepSeek 的核心特质

该家族具备四方面明显特征。

（1）实战表现亮眼：DeepSeek-R1 在多项公开评测中与 OpenAI o1 持平，在中文理解与生成任务上优势更突出。
（2）经济性突出：相较同类方案，训练与推理开销被大幅压缩，企业接入门槛随之降低。
（3）社区生态热闹：模型架构与训练细节完全公开，吸引全球开发者协同打磨，形成活跃的技术圈子。
（4）应用面很广：覆盖教育、政务、医疗、电子工程等，常见用途包括教师备课辅助、文旅宣传稿撰写、电路图纸解读等。

代表性产品有两款：

（1）DeepSeek-V3：提供 128K，即 128000 token 的长上下文窗口，在多轮对话与复杂推理任务上表现稳健。
（2）DeepSeek-R1：基于强化学习的推理专精模型，聚焦代码生成与数学求解，并具备实时知识刷新能力。

### 1.3.2 架构创新与训练优化策略

整体技术路线以效率与精准为导向，叠加架构层创新与训练层优化。

架构层面有三处关键设计。

（1）混合专家 MoE：采用稀疏激活机制，每个 token 仅唤醒 8 个专家，有效降低算力消耗。
（2）多头潜在注意力 MLA：借助低秩压缩手段减少键值缓存的内存占用，提升长文本处理效率。
（3）多词元预测 MTP：一次性预判多个后续 token，增强生成连贯性并加速推理。

训练流程融合预训练、监督微调 SFT、强化学习与模型蒸馏，采用分阶段多轮迭代，最终形成推理能力强且与人类偏好高度契合的开源对话模型。

训练优化包含四类手段。

（1）混合并行：数据并行与模型并行协同，使用梯度压缩、异步通信及计算通信重叠，降低节点间延迟，提升 GPU 利用率。
（2）双向管道并行：打通数据传输与计算环节，实现前向后向的计算与通信完全重叠，减少流水线空闲，提升效率。
（3）专家并行与负载均衡：智能分发任务，通过动态调整路由偏置或复制负载高的专家，避免单点过载，提升资源使用率。
（4）FP8 混合精度：采用 8 位量化压缩存储与通信开销，显著提高训练效率。

### 1.3.3 调用方式

根据使用场景可分为两条路径。

（1）云端调用：通过官方或第三方如阿里云、火山引擎的 API 快速接入，适合轻量需求。
（2）本地部署调用：可下载满血版 671B 或蒸馏版如 7B，需配备高性能 GPU 服务器，适合对数据安全性要求高的场景。

### 1.3.4 DeepSeek 生态

在 Hugging Face、GitHub 上累计被 140 多个国家开发者下载，注册量已破亿。以“极致开源+极致成本”把大模型从烧钱重工业变为像水电煤一样的基础设施，并通过端云协同与行业深耕重塑国产及全球大模型格局。

核心模型永久免费，后续可通过企业技术支持、订阅服务、行业定制方案实现可持续盈利，形成商业闭环。目前已在政务、金融、医疗、教育、交通等领域通过概念验证 POC 持续落地，让中小企业无需自建算力即可调用百亿参数级别模型。

生态可概括为开源内核、低成本杠杆、端云协同。

（1）开源内核。模型、代码、训练方法全部开放。
主模型：DeepSeek-R1 对标 OpenAI o1，DeepSeek-V3 居开源榜首，已开放权重与训练脚本，采用宽松 MIT 协议，允许免费商用与二次开发。
专业分支：DeepSeek-Prover-V2-671B 数学定理证明、DeepSeek-Coder 代码生成等持续开源。
蒸馏小模型：6 个尺寸 1.5B 至 70B 全部放出，API 定价约为 OpenAI 的 3%，大幅降低接入门槛。

（2）低成本杠杆。架构创新大幅降低训练成本，已适配华为昇腾、沐曦、天数智芯、摩尔线程、壁仞等国产 GPU，实现用得起跑得动，训练与推理成本处于行业低位。

（3）端云协同。兼顾端侧部署与云侧服务。
端侧部署：经模型压缩与量化，将 7B 至 30B 轻量模型下放到 PC、手机、车载设备、智能家居，实现本地推理与低延迟，保护隐私。
云侧服务：多家国产云平台已上架全系列模型，提供一键调用、弹性扩缩容及私有化落地方案。

凭借创新架构、低成本优势与开源生态，DeepSeek 正加速 AI 普惠进程。未来随着多模态支持与因果推理能力的突破，或将成为 AGI 发展的重要里程碑。
