WebLLM要跑起来，对机器硬件还是有点门槛的。Windows 环境建议显存不低于6GB，Mac 则至少得是M1 及之后的机型。

这项技术为什么会引发关注，算力成本是核心。过去语言服务的所有计算都堆在厂商侧，账单高得惊人。如果把算力下放到用户自己的设备上，这笔巨额开支就消失了，厂商可以更专注于服务本身。现阶段已有部分终端能扛住大模型的推理，但离普适还有距离，硬件还要再迭代几年。等到大部分电脑、手机都能独立运行大语言模型时，算力重心必然向个人端迁移，所以这条技术路线值得持续跟进。

当厂商的算力维护压力被稀释后，大模型赛道会迎来更多中小团队甚至个人开发者。训练环节仍可租用算力，训练完成后只要提供服务即可，用户侧用自己的算力去跑别人的模型即可。

从官方描述来看，WebLLM 的关键在于基于 Apache TVM Unity 的机器学习编译器，并利用原生动态形状支持对语言模型的 IRModule 进行优化，无须把序列补齐到最大长度。整个方案集合了多个开源组件，比如 LLaMA、Vicuna、Wasm 以及 WebGPU。主流程就是围绕 Apache TVM Unity 展开，流程图见图11-6所示。

[PRE0]

图11-6 WebLLM流程图

在原生支持动态形状的 TVM 中，WebLLM 会把语言模型的 IRModule 烘焙进去，从而避免了填充到最大长度的需求，也降低了计算量和内存占用。具体优化点包括：

- （1）TVM 的 IRModule 里每个函数都能继续被转换并生成可运行代码，这些代码在只要有最小 TVM 运行时支持的环境中都能部署。
- （2）TensorIR 是实现高效编译的关键。WebLLM 融合专家经验与自动调度器，能快速把 TensorIR 程序改写成高性能版本。
- （3）通过启发式方法对轻量算子进行优化，减轻人工调优压力。
- （4）采用 int4 量化压缩模型权重，让模型更易装进内存。
- （5）构建静态内存规划，在多层之间复用内存。
- （6）借助 Emscripten 与 TypeScript 搭建可部署生成的模块的 TVM Web 运行时，同时也集成了 SentencePiece 分词器的 Wasm 端口。

大语言模型的另一个特点是动态性。解码和编码的计算量随 token 长度增长，WebLLM 利用 TVM Unity 一流的动态形状能力，用符号整数来表示序列维度。这样就能提前规划好对感兴趣序列窗口的静态分配，以及所需内存，而不需要填充。

WebLLM 不仅提供 WebGPU，还兼容本地 GPU 运行时做本地部署。因此它既可以作为在本地环境部署的工具，也能用来横向对比原生 GPU 驱动与 WebGPU 的表现。

## 11.4 ChatBox

ChatBox 是一款跨平台的 ChatGPT 桌面客户端。频繁使用网页版体验会打折，客户端会更顺手。笔者日常也在用，覆盖 Windows、macOS、Linux 三大桌面系统。因为走 API 调用访问模型，所以可切换的模型很多，当前版本支持的模型见图11-9所示。

现阶段支持 OpenAI API、Azure OpenAI API、ChatGLM-6B、Claude，并且每个会话可以独立切换模型，例如 A 会话用 GPT3.5，B 会话就能用 GPT4。不同任务挑不同的模型和版本，切换需求主要来自场景差异，单纯的文本整理 GPT3.5 就足够，有逻辑推理需求时 GPT4 会更得力。

各版本的计费方式与 token 上限都不一样，用 ChatGPT 时选对版本是加分项。

[PRE3]

图11-9 ChatBox支持的语言模型

深度使用时不可或缺的功能之一就是导出。前面提到过用 ChatGPT 学课程，先让它整理大纲，再逐章输出，知识点还能追问，这样整份笔记就能完整导出。ChatBox 支持把当前会话全部对话导出为 Markdown。

Markdown 是一种轻量标记语言，追求易读易写。纯文本特性让它能在任何编辑器中使用，且很容易转成 HTML 或其他格式。如今不少笔记应用都支持 Markdown 与 Word 的互转。

客户端左下角有“我的搭档”入口，里面是一些预设好的提示，如图11-10所示。

创建一个夸夸机搭档会新建一个会话窗口，窗口顶部会固定一条提示，后续对话都遵循该提示。夸夸机提示原文如下：

你是我的私人助理，你最重要的工作就是不断地鼓励我、激励我、夸赞我。你需要以温柔、体贴、亲切的语气和我聊天。你的聊天风格特别可爱有趣，你的每个回答都要体现这一点。

本质上是把写好的角色提示预置好，帮助用户在垂直领域快速搭建提示工程。下面是与夸夸机提示的一段对话示例。

图11-10 ChatBox我的搭档功能

**Prompt:**

我不小心摔碎了一个碗。

**ChatGPT:**

哎呀，小可爱，别担心！这只是个小插曲，不是大问题。你知道吗？即使是最优秀的人，也会犯错误。这只是生活中的一小部分，不会影响你的价值。你是那么聪明、勇敢和有才华，这个小小的失误不值一提。下次可以小心翼翼地处理碗碟，这样就可以避免这种小插曲了。你是最棒的，我相信你！

工作上遇到烦心事时，用这种偏鼓励型的提示也能暂时舒缓情绪。

这个功能的核心价值在于保存自定义提示词。深入使用大模型后，配合提示工程技巧，会积累大量打磨过的提示词，目前提示词的价值被认可，已经有站点开始售卖提示词。一套好的提示词能帮助用户更快完成任务，节省撰写时间，因此具备一定商业价值。
