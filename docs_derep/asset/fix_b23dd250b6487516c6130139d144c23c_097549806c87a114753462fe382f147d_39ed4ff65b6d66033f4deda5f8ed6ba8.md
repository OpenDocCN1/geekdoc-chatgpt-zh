### NumPy 数组的向量矩阵用法

NumPy 里同一个数组既能充当向量，也能充当矩阵。先构造一个示例数组，整体乘以 5 后，每个分量的数值会变成原来的五倍。

[PRE1]

若参与运算的两个数组类型相同且形状一致，运算结果的类型和维度都会保持不变。

[PRE2]

需要转置时，直接使用数组的 `T` 属性即可完成。

[PRE3]

求向量内积或矩阵乘法，最常用的工具是 `dot`，其参数说明如下。

| `numpy.dot(a, b, out = None)` |

| --- |

| 参数 || 说明 |

| a || 从左边乘以向量或矩阵 |

| b || 从右边乘以向量或矩阵 |

| out || 用来存储结果的替代数组 |

| 返回值 || 向量的内积结果或矩阵的乘积结果 |

图 2 dot 函数的语法格式

向量内积的本质是对位相乘再求和。以 `arr1` 与 `arr2` 为例，1×2 + 2×3 + 3×4 的总和为 20。

[PRE4]

矩阵乘法按行列配对相乘后累加。`arr1` 与 `arr2` 的例子展开为“ [1×5 + 2×7, 1×6 + 2×8], [3×5 + 4×7, 3×6 + 4×8]”，最终得到“[19, 22], [43, 50]”。
