#### 4.11.2 先查数据再起草并去 AI 化
挑到问题后，别让 AI 空想回答。先找数据支撑，再起草，最后做人性化处理：

> 请回答这个知乎问题：
“有什么方法可以提高工作效率？”
请按以下流程操作：
1. 先通过联网搜索查阅最新的效率研究或报告
（例如“2026年远程办公效率报告”“时间管理研究”）
2. 再用浏览器查看该问题下的高赞回答，分析其角度和不足，找到差异化切入点
3. 基于搜索数据 + 差异化角度起草回答：
- 结构：先给结论再展开分析，500～800字
- 风格：以实用为主，适度加入个人经历
- 引流：结尾点到为止，不做硬广
4. 用“Humanize AI text”扫描全文，修复 AI 写作痕迹
最后检查记忆中我的回答风格和禁忌区，确保人设一致。
联网搜索数据 + 浏览竞品回答 + Humanize AI text 去 AI 味，三步配合。回答既有数据、有差异视角，也读起来更自然。可安装 Tavily Search 或 Brave Search 相关 Skill，或在自建 Skill 中调用对应 API 增强搜索能力。（完整回答流程效果如图 4-23 所示。）

请把这次回答的结果记录到记忆中：

- 避免批量发布，知乎对短时间大量发帖敏感，建议每天 1～2 个问题即可。

到第四章结束。如果你跑通其中两三个场景，会发现副业最难的不是“做”，而是“坚持做重复的事”，而这正是 OpenClaw 的长项。
回顾本章：让你筛选职位、写简历并自动投递，把求职从体力活变成筛选题；用浏览器抓取热销品数据，一键生成四平台文案，让无货源电商选品上架效率倍增；学会制作信息差产品、数字模板、翻译接单、用户调研等可持续变现项目，每个都能用 Cron 定时更新、记忆系统越做越准；多账号矩阵实现独立 agent 互不污染，众包接单加入信用评估不再踩坑，闲鱼卖货借助行情数据定价不再盲猜；最后搭建记账系统和接单看板，让分散的收入和订单有了统一归口。
现在 OpenClaw 已不只是写文案工具，而是一套副业运营系统——选品、接单、交付、记账、复盘皆有自动化兜底。
务必记住三点：
第一，所有 AI 生成的交付内容必须人工审核后再给客户。AI 可能夸大、编造数据、用错术语。你卖的是专业服务，不是原始输出。客户买的是靠谱，跳过审核等于砸口碑。
第二，平台规则是红线。自动投递简历、抓取电商数据、社交媒体自动回复、多账号矩阵等都可能触碰服务条款。风控机制在不断升级，今天可行明天可能封号。效率提升可以，但违规边界必须自己守住。
第三，副业本质是用时间换钱，OpenClaw 省的是时间。它不会替你找客户、谈价格、处理售后。它压缩重复劳动时间，让你把精力放在建立信任、维护关系、发现机会上。别指望装个工具就能躺赚，但踏实做时，每个小时会更值钱。
