#### 3.2.3 DeepSeek-R1模型参数详解

调用 R1 时，可通过 chat.completions.create 接口调节生成长度、风格多样性和逻辑严谨度等输出特性。R1 与 V3 共用该接口。

R1 在参数解析与推理机制上存在部分特有行为，实际调用时需注意如下要点。

##### 1. max_tokens参数
- 仅限制最终输出的 content 长度，默认 4096 token，约 3000 中文字符，上限 8192。
- 该限制不计入 reasoning_content。复杂任务下推理内容可达 32K，总输出长度可能远超 max_tokens 设置。官方计划后续上线 reasoning_effort 以控制推理深度与长度。

##### 2. reasoning_content字段
- R1 除返回常规答案 content 外，还会同级返回 reasoning_content，即内部思考过程。
- 该字段记录推导思路与结论形成轨迹，适用于解释类任务、教学演示与结果评估。

##### 3. 功能支持情况
- 已支持标准对话补全及对话前缀续写 Beta，适用于续写已有内容生成完整对话。
- Function Calling、JSON 格式输出、FIM 补全 Beta 暂未开放，相关字段设置无效。

##### 4. 不生效的参数
调用 deepseek-reasoner 时，temperature、top_p、presence_penalty、frequency_penalty、logprobs、top_logprobs 会被静默忽略。为兼容 OpenAI 接口标准，设置不会报错。

多轮对话中，R1 的推理轨迹呈现明显分阶段特征。

- 首轮多为独立推理，基于初始提问进行结构完整、逻辑自洽的思考。
- 第二轮开始出现递进推理，会引用前文问答对并自然衔接，承接性增强。
- 第三轮及以后则趋向综合推理，整合多轮信息与多变量，输出逻辑清晰的推理链。随着对话深入，模型展现出上下文记忆、逻辑递进与归纳整合能力，具有类人思维连续性与对话一致性，适用于复杂交互。
