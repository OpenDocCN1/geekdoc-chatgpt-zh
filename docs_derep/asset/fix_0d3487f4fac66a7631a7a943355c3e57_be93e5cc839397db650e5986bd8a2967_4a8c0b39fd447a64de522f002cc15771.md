- 提示词最前方就明确约定输出形式，例如“请注意最终结果务必以符合小红书平台规范的 Markdown 呈现”，并在工作流程的末尾或专门的输出格式小节再次重申同样的格式要求。
- 在人设确定之后，每个主要工作环节启动前都应再次点名当前身份，比如“现在你以资深美妆博主的身份，请开始拆解产品特性……”
- 面对复杂度很高的任务，建议把核心目标或关键限制条件在提示词的开头与结尾各重复一次。

##### 3. 技巧三：上下文管理与渐进式引导

1）原理/说明

当任务体量很大或由若干独立阶段组成时，一次性把所有指令堆出来容易超出模型的上下文上限，即便窗口足够，模型也难以一次把细节全部处理到位。此时更稳妥的做法是采用分步提示或链式提示，先让模型完成一个子任务或一个阶段，再结合已有结果给出下一步指令并补充必要的背景信息。这要求对对话历史和累计产出进行有效归纳管理。比如进入下一阶段时，先把前序对话的核心结论或模型生成的中间结果做个小结，作为新一轮提示的一部分，从而保持任务的连贯性。

2）应用示例

- 首轮指令：“请阅读‘××品牌奇迹光感持妆粉底液’的产品资料，并以列表形式提炼出5条核心卖点。”（模型输出卖点列表 A）
- 次轮指令：“你是一位资深小红书美妆博主。基于核心卖点：[在此处粘贴卖点列表 A]，结合夏季年轻女性常见的底妆困扰，撰写一篇300～500字的小红书种草文案初稿，需包含痛点引入、卖点场景化阐释和真实使用感受。”（模型输出文案初稿 B）
- 第三轮指令：“请对以下文案初稿进行审阅：[在此处粘贴文案初稿 B]，判断是否符合小红书爆款风格，语言是否生动，emoji使用是否恰当，并做优化。同时为该文案创作3个吸睛的标题。”

##### 4. 技巧四：模型参数的精细调控

1）原理/说明

大语言模型的生成行为受多项可调参数影响。温度 Temperature 用来控制随机性和创造性；数值偏低如0.1～0.5时，输出更偏向确定性、高概率的选择，风格更专注保守；数值偏高如0.7～1.0时，输出更具多样性和创造性，但也更难预测。Top-p 核心采样则控制生成每个词时候选词集合的累计概率。对于必须严格遵循复杂指令的场景，适当调低 Temperature 或 Top-p，能有效遏制模型的自由发挥，让其更忠实执行指令，降低跑题或产出无关内容的概率。

2）应用示例

在需要严格遵守格式与规则的商业文案生成任务中，可把 Temperature 设为0.3。这样既保持流畅，又能确保输出的内容与风格贴合指令，降低因随机性过高导致的不稳定。

##### 5. 技巧五：利用“系统提示”（如适用）

部分 LLM API 支持设定系统提示 System Message，用来定义模型的整体行为、核心角色、高级指令或持久上下文。相较于普通用户提示，系统提示的权重更高、持续影响更强，不易被后续用户输入稀释或覆盖。把全局性、贯穿始终的核心指令如角色定位、行为准则、输出风格等放在系统提示里，可以让 AI 在整个交互过程中稳定遵循这些高层指令。
