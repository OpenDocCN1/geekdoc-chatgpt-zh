### 8.2.2 权重

指令中每个词的重要性都可以被调节。用小括号括起来的词会被加强，用中括号括起来的词会被削弱。

具体做法如下。

- 1. 增加权重

要提升某个词的影响力，可用半角小括号包裹，例如“（关键词）”。

默认情况下，被小括号包住的词权重会变成原来的 1.1 倍，也可以在括号末尾写数字来自定义倍数。

表 8-1 给出了常见写法。

表 8-1

| 示例 | 说明 |

| :--- | :--- |

| (关键词) | 权重为 1.1 |

| (关键词:1.1) | 权重为 1.1，与上一条示例效果相同 |

| (关键词:1.5) | 权重为 1.5 |

| ((关键词)) | 权重为 1.1×1.1=1.21 |

| (((关键词))) | 权重为 1.1×1.1×1.1=1.331 |

- 2. 减少权重

要降低某个词的作用，可用半角中括号包裹，例如“[ 关键词 ]”。

默认情况下，被中括号包住的词权重会降到原来的 90%。减权与增权的语法类似，如表 8-2 所示。

表 8-2

| 示例 | 说明 |

| :--- | :--- |

| [关键词] | 权重为 0.9 |

| [关键词:0.9] | 权重为 0.9，与上一条示例效果相同 |

| [关键词:0.5] | 权重为 0.5 |

| [[关键词]] | 权重为 0.9×0.9=0.81 |

| [[[关键词]]] | 权重为 0.9×0.9×0.9=0.729 |

- 3. 示例

### 8.2.3 渐变

指令支持一种叫做“渐变”的写法，可以让一个元素平滑过渡到另一个元素。语法为 [ 关键词 1: 关键词 2: 因子 ]。

因子是 0～1 之间的数值，表示关键词 1 的占比，数值越小结果越偏向关键词 1，数值越大越偏向关键词 2。

借助这个方法，可以合成两位名人之间的面孔，例如“[ 名人 1: 名人 2:0.5]”会生成介于两者之间的新面孔，前提是模型里包含这两人的数据。

也可以这样写：[ 老人 : 名人 :0.5]，前者是泛称如“old man”，模型会先生成一个老年男子的样貌，再向指定的具体人名如“Albert Einstein”进行渐变。

图 8-8～图 8-10 是一个具体案例，从左到右，随着渐变因子从 0.75 降到 0.25，第二个关键词“Albert Einstein”的影响越来越强，人物的长相也越接近爱因斯坦。

### 8.2.4 使用 LoRA

在指令中使用 LoRA 调整内容或风格时，语法为 <lora: 文件名 : 权重 >。

“文件名”是不带扩展名的 LoRA 模型文件名；权重不小于 0，默认是 1，设为 0 表示不启用，也可以大于 1 来增强效果，但过大会产生负面影响，用户需根据需求和具体 LoRA 的表现自行调节。多个 LoRA 可以同时使用，效果会叠加。

部分 LoRA 只需写调用语法即可，部分 LoRA 还需要配合触发词一起使用，具体说明一般在下载页或文档里可以看到。

即使记不住已安装 LoRA 的文件名也没关系，点击界面右上角生成按钮下方的“显示 / 隐藏额外网络”按钮，在指令下方即可展开额外网络面板，切换到“Lora”标签，就能看到当前所有已安装的 LoRA，如图 8-11 所示。

[PRE9]

在这个界面，点击某个 LoRA 卡片，就能在指令输入框自动加入引用。例如“<lora:add_detail:1>”，表示使用“add_detail”这个 LoRA，权重为 1，后续可以手动调整数字。

当基础模型始终得不到理想效果时，尝试合适的 LoRA 往往能带来显著提升。
