#### 主体创作模板二：递进式

递进式写法适合前后要点之间存在承接、层层推进的情况。常见套路有：是什么+为什么+怎么做、案例+原因+解决方案、第一步+第二步+第三步等等。递进式和列点式的差别在于，列点式要点多为并列、侧重要素陈列；递进式有主次，内容逐步深入。下面是一个典型的递进式结构。
