# 4.13 作用域规则

标识符可见范围即作用域。

## 局部作用域

函数内定义的变量属于局部作用域，从定义处起到函数结束。函数返回即出作用域，销毁不可访问。

## 全局作用域

函数/类外部定义的标识符（函数名、变量名、类名）属于全局作用域。定义后，文件/会话中其后任意处均可访问。

## 块与套件的作用域差异

- 函数块内赋值 → 局部变量  
- 控制语句套件赋值 → 视控制语句所在层级：全局层级则全局，函数内则局部。

# 4.15 向函数传递参数：深入讨论

多数语言分「按值传递」（拷贝副本，互不影响）和「按引用传递」（直接操作原变量）。Python 统一采用 **「按对象引用传递」**（Call by Object Reference）。

- 实参是对象引用（内存地址）的拷贝，而非对象本身。  
- 避免大对象拷贝，性能更优。
