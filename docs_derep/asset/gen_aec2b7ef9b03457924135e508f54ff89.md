# 提问方式升级，答案才够用

想快速摸清一篇报道的全貌，问一句“用户对新品怎么看”显然不够。单点提问只能拿到单点信息，而把问题拆成多个角度、逐层追问，就能把报道里的关键信息一网打尽。

复合型提问的核心就是多维拆解。提问者不再只抛一个笼统问题，而是从不同层面设置具体追问，让AI分维度作答，从而得到更完整、更深入、更精准的结论。

请看电影评价场景里的对比。

# 常规提问

# 复合型提问

《星际穿越》这部电影怎么样？

整体口碑维度 《星际穿越》主要获得了哪些积极的评价？
剧情维度 这部片子的剧情有什么特点？是否包含悬疑线索？
导演风格维度 克里斯托弗·诺兰在这部作品里表现出了怎样独特的创作手法？
演员表现维度 主演们的表演水准如何？有没有让人印象深刻的演绎？
视效维度 电影的视觉呈现如何？有哪些特效镜头让人难忘？

好的复合型提问，通常是先从不同角度梳理思路，拿到信息框架后再进行针对性追问，从而获得更清晰明确的答案。如果自己对分析方向不确定，可以先请AI给出可用的分析维度，再从中挑选继续深入提问，最终锁定想要的结果。

# 例：评价手机性能

要全面评估一款手机，可以从哪些角度入手？请给出具体的提问示例。

+   1. 性能维度：这款手机的性能表现怎样？强项和弱项分别是什么？
   2. 摄像功能维度：拍照录像能力如何？是否达到专业级水准？
   3. 使用体验维度：实际使用流畅吗？电池续航和操作手感如何？

请基于以上三个角度帮我对这款手机做个评价。

反馈显示用户普遍认为这款手机性能很强，处理速度快、多任务运行顺滑。优势在于强劲的处理器、大内存和高速存储，短板则是在高负载时容易发热。

# 例：分析会议报道

分析一篇会议报道可以拆解成哪些维度？请给出提问示例。

+   1. 会议议程维度：报道里提到了哪些主要议程？
   2. 核心发言人维度：有哪些关键人物发言？他们透露了哪些重要信息？
   3. 会议成果维度：报道是否说明了会议取得的成果或达成的一致？
   4. 影响力维度：这次会议对行业进展和国际合作会带来什么影响？

请从以上四个维度帮我梳理这篇报道。

报道指出议程包括主题演讲、分论坛、小组讨论等。现场有多位行业领袖、专家和政要发言，涉及热点问题、最新研究和政策建议等核心内容。

# 例：评价酒店

评价一家酒店可以从哪些维度着手？请给出提问示例。

+   1. 服务质量维度：评论中对酒店服务的评价如何？优缺点是什么？
+   2. 餐饮体验维度：是否有提及餐厅菜品和服务体验？评价如何？
+   3. 房间设施维度：房间的设施和舒适度被如何描述？是否有高端房型？
+   4. 区位交通维度：地理位置和交通便利性如何？是否靠近景点或商圈？

# 例：点评论文

点评一篇论文可以从哪些维度入手？请给出提问示例。

+   1. 研究目的维度：论文想解决什么问题？对医学领域有何意义？
+   2. 方法与数据维度：使用了哪些AI技术和数据集？数据是否可靠？
+   3. 实验结果维度：研究结果显示AI在医学应用上有哪些效果？有无突破？
+   4. 应用前景维度：论文是否讨论了未来应用方向？对研究和临床有何影响？

# 例：调查品牌

调查一个品牌可以从哪些维度切入？请给出提问示例。

+   1. 关键话题维度：报告里提到了哪些与品牌相关的话题？舆情表现如何？
+   2. 情感倾向维度：社交媒体用户对品牌的情绪是正面还是负面？
+   3. 用户参与维度：报告是否记录了用户与品牌的互动和反馈？
+   4. 品牌形象维度：品牌在社交媒体上的形象和声誉如何？有哪些核心观点？

# 拓展应用

与AI对话时使用复合型提问，能让主题被更深入地挖掘，也能大幅提升对话质量。以下是两个典型场景。

# 1. 文章创作：让 AI 帮你提升文章可读性

我在写一篇《PPT是职场人的必备技能》的文章，可以从哪些维度搭建框架？请给出具体提问示例。

+   - 1. 技巧维度：怎样的版式和设计能让演示更吸引人？
- 2. 内容组织维度：如何组织演示内容保持逻辑连贯？
- 3. 可视化表达维度：如何借助图像、图表、图标增强效果？
- 4. 演讲技巧维度：有哪些方法能帮助我在演示中更自信、更能抓住观众？

请结合内容组织和演讲技巧两个维度，给出写作建议。

# 2. 历史研究：让 AI 帮你理解历史

我想系统学习辛亥革命，应该从哪些维度入手？请给出提问示例。

+   1. 事件背景维度：事件发生的时间地点是什么？
+   2. 影响维度：事件对当时社会产生了哪些影响？
+   3. 相关人物维度：有哪些关键人物参与？他们分别扮演什么角色？
+   4. 成因维度：事件爆发的根本原因是什么？

请从影响维度与成因维度帮我分析这一历史事件。

# 注意事项

+   1. 确保问题的维度足够多样。避免集中在单一层面，要覆盖主题的不同侧面。
+   2. 使用复合型提问后，要核查AI生成内容的准确性和可读性，对需要调整的地方及时修改。
