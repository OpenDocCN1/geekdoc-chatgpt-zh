【智能拆解：算法的来处】

先聊“智能”这个词。按字面，它就是智慧与能力的总称。放眼自然，智能大致可以分成个体层和群体层两种表现。除人类之外，公认具备个体智能的代表有大猩猩、海豚、章鱼；而蜂群、蚁群、沙丁鱼群则常被用来说明群体智能的存在。落到个体层面，人脑神经元本质上只有兴奋和抑制两种反应，却能拼凑出复杂的思维活动；落到群体层面，蚂蚁借助信息素交流，就能组织起分工明确、运转有序的蚁群。由此可知，无论是单体还是整体，核心都是大量简单操作的叠加与转化。

20世纪中期，冯·诺依曼[PRE0]受此启发，提出了元胞自动机 Cellular Automata，CA。CA里单个单元的规则极其简洁，其状态的变化仅受直接相邻单元状态的制约。比如单元取值只有0和1，规则设定为跟随邻居的多数取值。令人意外的是，由这类极简规则构成的系统，竟能复现蚂蚁、大雁、洄游鱼类等群体的部分行为特征。

再看“人工”二字，就是人造的意思。人工智能，指的就是人类制造出来的智能。前面提到的由规则驱动的CA所展现的群体行为，就是一种典型的人造智能范例。

因此人工智能的根基离不开算法，算法是其直接的生成手段。

### 1.1.3 什么是数据分析
数据分析顾名思义就是处理数据。把收集来的数据进行汇总和统计，从中提炼出可用的信息。通常做法是先确定统计指标，例如总和、均值等，再选用相应的计算方法与工具得出结果，最后以合适的形式呈现。

数据分析是算法研究的起步环节，古今如一。远古的天文历法研究，第一步也是长期观测并汇总记录。从分工看，数据分析工程师主要聚焦数据分析模块，与算法工程师的职责不同。

以“大学生手机使用情况调研”为例，分析的目标之一是统计各类数量的总和与平均值，涵盖不同年级、不同性别的大学生购买和使用不同品牌机型的数量总和与均值等。呈现时可以用条形图展示“男生最青睐的机型排行”“销量最高的大学生机型排行”“大学生最喜爱的品牌排行”，用折线图展示“大学生月度新购手机数量”“一周内每天的平均通话时长”。

### 1.1.4 什么是数据挖掘
数据挖掘就是对数据做深层探究，目的不只停留在统计结论，更在于发掘数据间的内在联系。其精髓是探索，探索数据中隐藏的模式、规律与规则，属于更深层次的数据分析。数据挖掘既有统计导向的方法，也有模型导向的方法，与机器学习有交叉，但侧重点不同。

在机器学习研究链条中，数据挖掘处于承上启下的位置，比单纯分析更深入，且不完全依赖模型。因此数据挖掘工程师对数据模式、规律、规则的敏感度要求更高。

在同一课题中，统计型挖掘可以研究标签共现，比如“视频”“游戏”“聊天”“拍摄”等使用标签，结合性别、年级、专业等人群标签，做关联度分析。模型型挖掘可以研究相似群体，比如“使用习惯相近的大学生”可分为几类，各类人群又有哪些共性特征。

### 1.1.5 什么是机器学习
机器学习就是让机器自行习得规律。为此需要人工事先设定一套学习准则，这套准则即算法模型。从这个角度看，机器学习的要义是优化，即基于收集到的样本数据，不断优化模型中的参数。

机器学习是算法研究的最后一环，狭义上更强调模型选择与参数优化的思路。因此与算法工程师相比，机器学习工程师的工作重心在模型层面[PRE1]。

在大学生手机调研场景中，机器学习可以整合所有可提取的特征，完成特定场景的预测或决策任务。例如为电商平台推荐更契合大学生群体的手机品牌与机型，为手机厂商决策大学生市场的投资回报率 Return on Investment，`ROI`。

## 1.2 如何学习算法
前文介绍了数据分析、数据挖掘、机器学习的定义，也说明了它们对应的岗位与算法工程师在职能上的差异。总体来看，算法工程师的要求更全面，既要懂数据分析，也要懂模型。

算法概念很宽，AI算法的知识至少涵盖数据分析、数据挖掘、机器学习等。涉及的理论、方法、工具，每一块都能单独成书。书籍繁多且缺乏清晰的学习路径，常常让初学者无所适从。把全部内容压缩到两百多页也几乎不现实。

更合理的入门方式是，先把握领域核心，弄清整体脉络与主要组成，再逐步向外延展、填充细节。好处有二：一是早有整体认知，能降低学习倦怠；二是便于宏观把控进度，使学习更具针对性。

基于此，本书的意图是帮助读者搭建算法认知的骨架。基础数学、基础算法、模型算法、工程实战各自展开都远超本书篇幅。本书的主旨很单纯，就是呈现AI算法世界的全貌。希望能起到抛砖引玉的作用。本书覆盖面广，部分细节未及之处，读者可按兴趣自行查阅延伸。

算法是个抽象概念。广义上，所有涉及运算的方法都可称为算法；狭义上，在信息技术 Information Technology，`IT` 领域，算法可以是解决数学问题的方法与技巧，也可以是描述机器学习或数据挖掘的相关方法，本书从这两个角度展开。

讲清楚算法并不容易，讲得完整又易懂更难。算法牵涉众多学科的基础概念，名词解释较为生涩，容易降低兴趣。作为普及类图书，本书各部分不必太深，但要尽量全面。如何兼顾趣味性、完整性和连贯性，曾困扰很久。重温《天龙八部》后才恍然，算法与金庸笔下的武功体系颇有相似之处。

## 2.1 线性代数
线性代数是研究线性空间中函数问题的一门分支。“线性”指代数关系为一次关系，无复杂运算；“代数”指用符号代替数字以便研究。

对于关系 `f(x+y)=f(x)+f(y)`，线性代数并不关心 x、y 的具体含义，只研究具备这种线性映射特性的函数 f。

函数通常是单入单出。随着问题复杂，可能需要多入多出，这正是线性代数要解决的问题。

### 2.1.1 名词解释
线性代数中，单一数值称为标量，用中括号括起的多个数称为向量或矩阵。标量、向量、矩阵是算法工程的核心基础。

• 标量：一个简单的数，如 29、31。
• 向量：一组有序标量，可写成一行或一列。
• 矩阵：一组有序向量，可用二维数组表示。

举例。某包子铺周一卖出 50 个肉包，这里的 50 就是标量；如果一周每天肉包销量依次是 `[50, 51, 52, 53, 52, 48, 45]`，这就是一个向量；再加上豆沙包、咸菜包的销量，就构成一个矩阵。

## 2.2 排列组合
排列组合在高中数学中常见，公式简洁直观。

包含排列和组合两个概念。假设小组有 5 人。

① 选出 3 人站成一排，有多少种排法？
② 选出 3 人打扫卫生，有多少种选法？

问题①需考虑顺序，问题②不需考虑顺序。这就是区别。排列用 `P` 或 `A` 表示，组合用 `C` 表示。组合种类是排列种类的子集。

## 2.3 高等数学
做 AI 算法是否需要高等数学？本书只讲与 AI 最相关的两个点——导数和梯度。它们在公式推导中很关键，有助于理解模型为何起作用。

### 2.3.1 导数
简单说，导数描述函数图像在某点切线的倾斜程度，即斜率。连续函数随 `x` 连续变化时 `y` 也连续。连续不一定处处可导，可导函数图像必处处连续。

## 2.3 导数
导数主要用于刻画函数图像上某一点切线的倾斜程度，这个倾斜程度也被称为斜率。所谓连续函数，就是当 `x` 值连续变化时，`y` 的变化也是连续的。连续函数不一定处处可导，而可导函数的图像一定是处处连续的。
