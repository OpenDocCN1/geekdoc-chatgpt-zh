元数据量很大，但核心点很清晰：category 里出现了 Table，且该 Table 元素携带了 parent_id，这个 id 会指向表格对应的标题。这一点很关键，表格脱离标题就失去了意义。表格本身往往只有数字，而标题才说明这些数字代表什么。

比方说比较两组山西城市的GDP，如果一张表的标题是“2024年各城市GDP”，另一张是“2025年各城市GDP”，就必须把表内数据与各自标题绑定。在 RAG 流程里这是必要的一步，否则拿到一堆数字却不知道年份，检索结果就会不准。
