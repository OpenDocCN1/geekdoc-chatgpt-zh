针对代码与数学相关的训练素材，Meta 单独搭建了一条处理管线。分类环节选用在 Llama 2 标注语料上微调的 DistilRoBERTa，并对提示词进行针对性调优，重点是捕捉自然语言表述与程序、数学推导之间的交互特征。

多语言语料的治理流程较为系统。先借助语言判别模型把文档归入 176 种语言并剔除重复，随后融合语言专属的启发式规则与模型筛选剔除质量偏低的文档，再由多语言版 Llama 2 分类器对剩余文档进行质量打分，确保优质内容优先进入训练。为让英语与多语种在评测上的表现更均衡，团队还实验性地统计了预训练阶段多语种 token 的使用情况。

为了训练高质量的语言模型，Meta 对训练语料的组合比例做了专门设计。先训练文本类别分类器以便有效调节数据混合，压缩在互联网上占比极大的娱乐与艺术类内容，并在小规模模型上试验不同配比对效果的影响。最终用于大模型训练的配比为通用知识 50%、数学与推理 25%、代码 17%、多语言 8%。

实践还发现，预训练收尾阶段在数学、代码等高质量数据上进行退火训练，能够明显提升最终表现。

Llama 3 的上下文较长，训练输入通常是多个文档的拼接。因此在训练中加入了特殊的注意力掩码，避免模型在预训练时让不同文档的 token 互相影响。

Llama 3 的预训练包含初始预训练、长上下文预训练和退火训练三部分。

以 405B 为例，初始阶段采用 AdamW 优化器，初始学习率 8×10^{-5}，进行 8000 步线性预热，随后以余弦方式衰减至 8×10^{-7}，总计 120 万步。起步时批量较小，为 4M tokens 且序列长度 4096，后续逐步提升至 8M 与 16M 以提高效率。训练过程中会动态调整数据组合，提升非英语比例、上采样数学数据、补充更新的网页数据并减少低质量数据。

长上下文阶段逐步增加序列长度，以支持最高 128K 的上下文窗口。共分 6 个阶段从 8K 逐步提升至 128K，确保模型在每个阶段都能有效适应新的长度。该阶段使用约 800B 的训练 tokens。

退火阶段使用 40M tokens 训练，学习率线性降低至 0，同时保持 128K 的上下文长度，数据侧重高质量来源。最终预训练模型通过对检查点的平均生成。

## Llama3模型后期训练与性能比较

Llama 3 进行了多轮后期训练以提升性能。每轮后期训练均包含监督微调 Supervised Fine Tuning，SFT 和直接偏好优化 Direct Preference Optimization，DPO。数据来源于人工标注示例和合成示例。训练步骤为，先利用预训练模型基于人工偏好数据训练一个奖励模型；再使用奖励模型对人工标注的提示进行拒绝采样，结合合成数据后以标准交叉熵损失对预训练模型进行监督微调；微调后使用 DPO 进一步训练模型以对齐人类偏好。DPO 所需计算资源较少，并在指令遵循类基准测试上表现更好。

2024年9月25日，Meta 发布了 Llama 3.2，其中包含更小且适合移动端的纯文本模型，分别为 Llama 3.2 1B 和 Llama 3.2 3B。更值得关注的是，Meta 首次发布了 11B 和 90B 的多模态大模型，为基于开源大模型生态的智能应用增加了更多可能性。Llama 3.2 的多模态模型支持图像推理，能够对图表、图像、图片文字进行理解与推理，例如可以针对一个年销量柱状图询问大模型哪一年销量最高，也可以让大模型描述图片内容。

为了在原本训练的纯文本 Llama 大模型上增加图像输入，Meta 训练了一组权重适配器，将预训练图像编码器输出的编码映射到预训练的大语言模型中。该适配器由一系列交叉注意力层组成，负责把图像编码器的表示传递给语言模型。训练适配器时图像编码器的参数可以更新，而大语言模型的参数完全冻结，以此保持所有语言模型原有能力不受影响。

多模态大模型的训练分为多个阶段，从预训练的 Llama 3.1 文本模型开始，先增加图像适配器和编码器，然后在大规模含有噪声的文本图片配对数据上进行预训练。接着在中等规模高质量的领域内和知识增强的文本图片配对数据上进行训练。在训练后期，采用与纯文本大模型类似的方法，通过几轮对齐的监督微调、拒绝采样和直接偏好优化进行后训练。

## 3.1 HuggingFace介绍

HuggingFace 是一家专注于自然语言处理和人工智能的科技公司，以开源工具和平台著称。HuggingFace 成立于 2016 年，总部位于纽约，致力于使人工智能技术更易于访问和使用。

HuggingFace 是一个开源人工智能平台，目前包含 40 多万个开源模型、10 多万个开源数据集以及 15 万个应用。提供开源大模型的公司都会优先在 HuggingFace 上发布自己的模型，例如 Llama、ChatGLM、QWen、Yi 等。

HuggingFace 还提供了一系列简单易用的开源库，其中最著名的是 Transformers 库，可以利用它快速地从头训练或者微调一个预训练模型。另外还有提供分布式训练的 Accelerate 库，提供参数高效微调的 PEFT 库，提供强化学习训练的 TRL 库等。

HuggingFace 创建了一个活跃的社区，用户可以在其中分享模型、数据集和经验，还可以发布自己的模型或体验其他用户创建的模型。
