# 高科技迷思的根源：执念与康德的未竟之问

前文的探讨揭示了一个核心悖论：高科技那令人战栗的创造力，实则源于一种近乎偏执的“执念”。数学因子正是这种执念的化身——它既精巧又执拗，强迫视野仅聚焦于“形式上凸显”的存在与价值，将世界推向 `A∨￢A`（非此即彼）的二元选择架构。用科学假说加激进实验去拷问自然，并真能逼出答案来，这固然是人类智力的丰碑，却也违背了常识体验；而这背后的推手，依然是那个数学因子。数学，这个看似自恋、直觉上自证的纯形式“棋局”，竟能窥见宏大宇宙与万象世界的关键密码，对日常经验视野而言，简直匪夷所思。古希腊毕达哥拉斯断言“数是万物本源”，却未给出令人信服的缘由。康德在《纯粹理性批判》[PRE0]中补上了这课：数学是人类感性直觉纯粹形式（空间与时间）的表达，人类只能透过这副“有色眼镜”认识世界。若有一门学问——即数学——能展示这副眼镜（尤其是镜片）的内在结构机制，它必将大裨益于我们洞悉世界奥秘，至少能提供关键线索。更进一步，这种直觉纯形式借由超验想象力[PRE1]与知性概念结合，更有利于形成对世界的先验预期与预感。遗憾的是，康德后来觉得超验想象力的核心地位威胁到了概念化理性或统觉学说的建立，便大幅降格其地位，甚至堵死了后人对其深入探讨的路径[PRE2]。

# 康德的疏漏与“先验”范式的非单一性

显而易见，康德的回答虽具启发，却藏着巨大的盲区。具体而言，断言西方数学是感性直觉纯形式的*唯一*表达，牛顿物理学是物理因果律的*唯一*表达，实属教条之见。譬如，他视欧几里得几何为空间纯形式的独有显现，正如当时“过直线外一点只能作一条平行线”被视为不证自明。然而，非欧几何的发现证明：几何不止一种，过直线外一点可作多条平行线。这虽看似仅动摇西方数理根基，但结合库恩的“范式”理论，这个基础性反例足以说明：所谓“先验”有效的范式，或人类认识世界必带的“必要偏见”，绝非铁板一块，更非必须数学化、形式化。只要能形成某种“研究范式”[PRE3]，具备某种形态的推演张力，就能延伸理论预设、指导实验。数学未必非得高度形式化，中国《九章算术》即是明证；甚至《周易》的数象系统，亦是一座具备先验推演力的架构。此外，“范式”包含却区别于具体研究方法，其规范形式自证自足、大而化之——它自身包含判准，不存在单一标尺能衡量所有范式优劣。由此可知，不同研究范式各有长短。高科技范式长于数学形式化、精准客体化、赋能与竞争；而推崇“更高、更快、更强”的标准本身，也属于此范式内部逻辑。因此，过往儒释道、泛神论、亚里士多德式等范式，皆不认同此套标准。

这启示我们：“先验”[PRE4]不等于“唯一”。人非神，无完全透明、超越存在模式（生理结构、语言、环境、文化、挑战）的认知方式。总存在由本能与处境造成的先验前提或先验色彩。科学家也是活在具体“处境”或“生活形式”（维特根斯坦）中的人；故而任何科学研究必有其先验预设或研究范式。但如前所述，构成这些预设的空间时间纯形式或纯符号，本身不可客体化；故而它们绝不可能纯粹到只有一种表达形式。“超验想象力”[PRE5]建构的“纯粹意象”或“图式”，超越了可客体化的形式（含概念的客体化），正如纯三角形超越任何具体三角形（却未上升为概念），也超越欧氏几何或任何几何范式规定的抽象三角形。我们甚至可以追问：三角形必须仅限于二维或三维，而非四维、五维吗？“再生产想象力”触及不了三维之外，但“超验的、生产性的想象力”或许能够企及。

# 高科技崇拜的危险与不对称

高科技崇拜对技术研究范式的多样性视而不见，将高科技奉为技术界的唯一真理，压制其他技术路径，并将高科技内在固有的——即便从某角度看合理的——偏见意识形态化、僵化化，从而堵死了从其他角度理性研究自然的可能性。
