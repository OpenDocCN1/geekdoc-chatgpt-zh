#### 3.2.1 DeepSeek-R1 模型核心概览
DeepSeek-R1 是 DeepSeek 于 2025 年 1 月发布的推理模型，目标是增强大语言模型的推理能力。测试显示，其在数学、代码、自然语言推理等任务上的表现可与 OpenAI o1 正式版媲美。

DeepSeek 同时开源 DeepSeek-R1-Zero 与 DeepSeek-R1 两个 660B 模型，并基于 R1 的输出蒸馏出 6 个小模型，其中 32B 与 70B 模型在多项能力上对标 OpenAI o1-mini。

另外，article 元素也可用于表示插件，使其呈现内嵌于页面的效果。

需要指出的是，DeepSeek-R1 采用与 DeepSeek-V3 完全相同的架构，仅训练流程与数据不同。具体而言，DeepSeek-R1 在 DeepSeek-V3 base 模型上先进行有监督微调，再进行强化学习训练；同期开源的 DeepSeek-R1-Zero 省去有监督微调步骤，直接从 DeepSeek-V3 base 上经强化学习训练得到。
