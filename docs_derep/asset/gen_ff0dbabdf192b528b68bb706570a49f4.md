# AI写作全能手册：入门到精通

## 内容简介
本书以140个实操技巧讲解为核心，搭配140集视频演示、170余份素材与对话文件以及178页PPT课件，从提问生成、职场公文、修改润色、热门模板、应用案例五大板块切入，帮助零基础读者快速成长为AI写作高手。

具体涵盖：16种AI提问方法、13种指令优化手段、11种高效提问方式、7项公文格式规范、8种AI公文写作思路、7种AI公文润色策略、9种文案修改技巧、7种文案润色方法、11类营销文案指令模板、12类办公文案指令模板、13类自媒体文案指令模板、12类教育学术文案指令模板，以及AI创作短篇小说与图书宣传文案的完整流程。

适合人群：文字工作者；AI相关从业者；电商商家、新媒体编辑、广告策划、短视频编导、作家及艺术工作者；新入职公务员及需公文写作的政府人员；行政、文秘等职场岗位；文学、语言、计算机科学与技术等专业学生。
