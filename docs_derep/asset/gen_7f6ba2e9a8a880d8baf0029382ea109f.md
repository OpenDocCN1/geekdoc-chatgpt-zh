激活函数本质上是在模仿生物神经元受刺激后传递信号的过程。分析生物神经信号的传递方式，会发现神经细胞只有两种工作状态：达到兴奋阈值时开启神经冲动传输，未能达到阈值时则没有冲动产生。在 M-P 神经元里，最理想的输出由阶跃函数来控制，如图 1-10 所示，先对输入进行加权求和再与阈值比较，把结果映射为 1 或 0。差值大于等于零输出 1，对应细胞兴奋；差值小于零输出 0，对应细胞抑制。

M-P 神经元模型首次用数学语言描述了生物神经元的特性，从计算原理上复现了神经元的工作机理，为揭开生物思维处理的神秘面纱提供了起点，也为后续神经网络的原子化结构奠定了基础，具有深远的借鉴意义。

## 1.3.2 感知机

感知机结构如图 1-11 所示，是在 M-P 神经元模型基础上发展出的网络化人工神经网络模型。它用网络视角来刻画神经元，由两层构成。第一层是输入层，由 $m+1$ 个输入数据 $x_0, x_1, \cdots, x_m$ 组成，只负责接收和传递数据，不做计算。第二层是输出层，由 $m+1$ 个权重 $w_0, w_1, \cdots, w_m$ 的网络输入函数和激活函数组成，对输入层数据进行运算。网络输入就是加权求和，激活函数与 M-P 不同，感知机采用反对称的符号函数，如式(1-2)所示，输入大于等于 0 时输出 +1，小于 0 时输出 -1。整体上看，感知机是一个多输入单输出的网络。

[PRE0]

感知机与 M-P 神经元在数学原理上一致，都继承了 $y = f(x \cdot w + b)$ 的计算形式。同时感知机会把训练集的正例与反例分开，并能对新输入进行判别分类，本质上是一个二分类器件。感知机实现二分类的过程类似于人学习辨认物体。老师先拿出一个苹果说“这是苹果”，再拿出香蕉说“这不是苹果”，随后展示另一个略有不同的苹果说“这也是苹果”。反复演示告知后，学生学会了判断什么是苹果。感知机的“区分能力”就是这种经训练得到的模型。

感知机的出现为神经元的应用指明了初步方向，它是一个基于 M-P 模型的可实用简单人工神经网络，能够解决简单的线性二分类问题。如图 1-12 所示，通过线性方法给两类对象分类，感知机可以找到图中 $(x_1, 0)$ 和 $(0, y_1)$ 两点所在的虚线，正确区分 + 与 - 两类。感知机还具备功能迁移性，可用 Hebb 学习规则或最小二乘法重训练，只调整网络中的权重而不改变网络结构，就能让同一感知机解决不同的二分类任务。

更关键的是感知机具有硬件可实现性，首个硬件实现的感知机模型 Mark1 使神经网络从理论走向硬件实例化。感知机展现的实用价值曾引发广泛关注，在智能奥秘探索的历程中迈出坚实一步。

当然感知机也有局限，只能用于线性二分类，无法解决简单的异或 XOR 问题。异或运算如图 1-13 所示，用 + 表示 1、- 表示 0，四种对应关系为：①0 XOR 0 = -，对应左下角 -；②0 XOR 1 = +，对应左上角 +；③1 XOR 0 = +，对应右下角 +；④1 XOR 1 = -，对应右上角 -。两种结果交错分布，若用线性分类器，感知机找不到一条直线把 + 和 - 分到两个区域。因此其应用极其受限，需要新的方法解决更复杂的分类问题。

## 1.3.3 多层感知机

### 1. 工作原理
感知机只能处理线性问题，输出也仅有 0 与 1。为处理更复杂任务，如多分类输出等，人们在传统感知机结构上引入多个隐藏层，形成深度结构，这种结构称为多层感知机模型 Multilayer Perception, MLP，也称全连接神经网络 Fully Connected Neural Network, FCNN，是最早的前馈深度学习模型。多层感知机可以将输入映射为多个输出，分类能力比感知机更强。数据只能单向流动，从输入层进入，经隐藏层到输出层，网络中不会形成循环。

多层感知机的输入节点构成输入层，接收外部数据但不处理，直接传给隐藏节点。隐藏层由隐藏节点构成，仅接收来自输入节点的数据并计算后传递给输出节点。多层感知机可以没有隐藏层，也可以有多个隐藏层，但必须包含输入层和输出层。输出节点组成输出层，接收来自上一层的数据后计算并输出到外部系统。隐藏节点和输出节点都具备神经元的计算处理功能，可等价为神经元。没有隐藏层的感知机是最简单的多层感知机，有多个输入一个输出，只能做线性二分类。

图1-14展示了含有两个隐藏层的多层感知机，结构为“输入层→隐藏层1→隐藏层2→输出层”。层间采用全连接，每层神经元都与上一层每个神经元相连。隐藏层1的4个神经元对输入数据处理产生4个输出，这4个输出再进入隐藏层2处理产生3个输出。以此类推，多层递进后产生最终输出。整个网络的输出可视为多层神经元多次嵌套计算的结果。

从计算角度看，多层感知机本质上是感知机模型的嵌套调用，输入向量经过式(1-1)所示的神经元计算模型的重复处理得到输出。现在每一层有多个神经元，输入为向量 $x$，输出为向量 $y$，每个神经元的权重是一个向量 $w$，多个神经元的权重向量组成权重矩阵 $W$。同理，一层神经元的多个偏置组成偏置向量 $b$。因此一层的全连接计算可用式(1-3)表示：输入向量与权重矩阵相乘后加偏置向量，再经激活函数 $f$ 处理得到输出向量 $y$，完成该层多个神经元的计算。

[PRE1]

在图 1-14 中，用向量 $x$ 和 $y$ 分别表示多层感知机的输入与输出，用 $W_1, W_2, W_3$ 表示不同层连接权重组成的权重矩阵，用 $b_1, b_2, b_3$ 表示不同层偏置值组成的偏置向量，向量 $y_1, y_2$ 分别表示隐藏层1和隐藏层2的计算输出。输入向量进入隐藏层1后由 $W_1$ 和 $b_1$ 作用，经全连接计算得到 $y_1$，$y_1$ 作为隐藏层2的输入继续传递计算，最终经输出层得到多层感知机的结果 $y$。这就是全连接网络的典型计算流程。

### 2. 计算复杂性
多层感知机克服了感知机对线性不可分数据的限制，能够解决非线性分类问题如异或问题。随着层数增加，在有限区间内任意函数都可用多层感知机逼近，使其在语音识别和图像识别等领域得到广泛应用。但当人们以为神经网络无所不能时，其局限开始显现。全连接形式导致参数过多，训练耗时过长、计算量巨大，且容易陷入局部最优，导致整体优化困难。

以一个简单网络为例，如图 1-15 所示，结构为“输入层→隐藏层→输出层”共3层，输入层700维，隐藏层400个神经元。与输入层全连接，每个神经元有700个连接，权重矩阵大小为700×400，每个隐藏神经元还有一个偏置，共400个。输出层有10个输出，与隐藏层全连接，权重矩阵为400×10，偏置10个。整个网络权重总数为700×400+400×10=284 000，偏置总数为400+10=410。每个权重需一次乘法，网络需完成284 000次乘法。加法次数与乘法相当，约为(700-1)×400+400+(400-1)×10+10=284 000。

仅一层隐藏层的网络解决700维10分类问题，参数、乘加次数已接近30万。若输入为1000×1000像素图像，像素量达100万，输出1000类，隐藏层仅100节点，参数与计算量就轻松过亿。即便以今日主流算力衡量，也十分可观。

此外图像识别中每个像素与其邻域联系紧密，与远处像素相关性小。MLP必须以向量形式输入，二维图像被展平后，所有像素被等同对待，位置相关信息丢失。大量连接对特征提取贡献很小，训练出的很多权重值极小，对结果几乎无影响，导致训练成本高收益低，预测性能也受影响。

在功能适用范围上，层数越多表达能力越强，但用常用梯度下降训练深层网络非常困难，梯度难以传递超过3层，不可能得到很深的多层感知机。多层感知机计算量过大的难题至今缺乏有效解法，促使人们继续寻找更高效的神经网络算法。

## 1.3.4 卷积神经网络
多层感知机采用全连接前馈形式构建，参数太多导致训练耗时长、调优难。同时全连接关注图像全局特征，难以捕捉局部丰富信息。这些局限推动了新网络结构的发展。多层神经网络由此出现，卷积神经网络 Convolutional Neural Network，CNN 是其中最具代表性的典型。

卷积神经网络以神经元模型为基础，通过特定层次结构将成千上万神经元连接起来形成规律的层次结构。从计算机科学角度看，其本质仍是 M-P 神经元模型的递归调用。

真正意义上的最早卷积神经网络是 LeNet5，由 Yann LeCun 于1998年在论文 *LeNet5-Gradient-Based Learning Applied to Document Recognition* 中提出。但直到2012年，AlexNet，8层卷积神经网络，在 ILSVRC 分类项目中以 Top-5 错误率15.3%夺冠，远超第二名，卷积神经网络才再次掀起研究热潮，深度学习也重新受到重视。AlexNet 成了深度神经网络的奠基之作。

CNN 直到2012年才火起来，一方面异构计算兴起，GPU 算力可用于网络训练，数据量爆发式增长提供了充足训练样本；另一方面神经网络深度问题逐渐被解决，深度卷积网络得以稳定训练。目前常见的深度网络如 AlexNet、VGG、GoogLeNet 等都属于卷积神经网络。

CNN 在多层感知机基础上引入局部连接、权重共享以及池化等特性，明顯改善了训练耗时长和调优难的问题，在很大程度上解决了感知机的固有缺陷。同时具有较强的特征提取和识别分类能力，在图像领域应用极广，如目标检测、图像识别分类、病理图像诊断等。

### 1. 网络结构简介
卷积神经网络需要经过结构定义、网络模型训练和推理计算三个过程。首先针对具体应用场景定义层次架构，如输入层、卷积层、池化层、全连接层、输出层。对这些主要层灵活排列或重复叠加，可产生种类繁多的卷积神经网络。结构定义完成后，用大量数据训练获得最优权重及其他参数，训练完成后模型才可对新数据进行推理计算。

如图 1-16 所示，LeNet5 网络结构是最经典也是最古老的卷积神经网络，包含一个输入层、两个卷积层、两个池化层、两个全连接层和一个输出层，结构为“输入层→卷积层1→池化层1→卷积层2→池化层2→全连接层1→全连接层2→输出层”。数据从输入层依次经过各层单向流动，是典型的前馈神经网络，后续卷积网络多在此基础上发展。每一个功能层都有输入特征图 Input Feature Map 和输出特征图 Output Feature Map。同一功能层所有输入特征图大小相同，所有输出特征图大小相同，但输入与输出特征图的大小和数目是否相等取决于功能层的计算特性。

输入图像前通常需预处理，使数据满足卷积神经网络计算格式。输入图像数据也称输入特征图，可为 RGB 格式的三维8位整型数据，例如224×224×3，其形式为[224,224,3]。第一个224为宽度，第二个224为高度，像素总数为高度乘宽度，3表示通道数即R、G、B。

神经网络一般会对输入数据做求均值处理，使样本中心移到坐标原点。为了便于学习，还会将输入归一化到特定范围，如[-1.0,1.0]，最终通常用单精度浮点数表示。有时为适配网络输入会调整图像大小，有时也会用主成分分析 PCA 对数据降维。总之输入层负责准备好便于网络处理的数据，作为数据源头，之后交由卷积层、池化层等处理，最后由全连接层计算结果给输出层。

### 2. 卷积层处理
输入层向卷积层输送数据，卷积层是神经网络中运算的核心层，可增强特征信息、过滤无用信息。卷积层通过多次卷积计算提取输入特征图中的关键特征，为下一层生成输出特征图。卷积层通常采用二维卷积对图像进行处理，在以每个像素为中心的邻域中做卷积计算，每个神经元对每个像素做邻域加权求和后输出结果，并加上偏置使结果调整至合适范围，此最终结果称为特征值。卷积层多个神经元的输出特征值构成特征图像。

加权求和会用到卷积核，也称过滤器 Filter。单个卷积核通常是三维矩阵，需用宽度、高度、深度三个参数描述。深度与输入特征数据的通道数保持一致，如图 1-17 所示的卷积核深度为3。不同卷积核提取不同特征，有的对颜色敏感，有的基础形状敏感，因此一个网络可包含多个卷积核。

[PRE2]

卷积核的值以二维权重矩阵形式存放，权重矩阵用宽度和高度表示，大小与卷积核相同。而一个卷积核中权重矩阵的数量与卷积核的深度保持一致，即与输入特征图的通道数相等。卷积核针对特征图像上一次滑动的距离称为步长。卷积核权重一般采用1×1、3×3或7×7等大小的矩阵，每一个卷积核的权重会对输入特征图上的所有卷积窗口共享。同一层卷积核大小一样，不同卷积层的卷积核大小可以不同。图 1-18 中，第一层所有卷积核大小统一为3×3。

卷积核作用的卷积窗口对应于原始输入特征图的部分称为感受野。感受野是原始输入特征图上的矩形区域，因可能有多层卷积层，当前卷积输入特征图上的卷积窗口大小和感受野尺寸可能不同，而第一个卷积层的卷积窗口一般和感受野大小相同。感受野用高度和宽度两个参数表示，而卷积窗口的高度和宽度与同一层的卷积核高度和宽度保持一致。如图 1-18 所示，第一层卷积层上的3×3卷积核对应输入图像上感受野大小为3×3，同时原始输入特征图上的卷积核以步长2进行滑动。在第二层卷积层上2×2大小卷积核对应在第一层卷积层输出特征图上的卷积窗口大小为2×2，而对应到原始图像上的感受野大小为5×5。
