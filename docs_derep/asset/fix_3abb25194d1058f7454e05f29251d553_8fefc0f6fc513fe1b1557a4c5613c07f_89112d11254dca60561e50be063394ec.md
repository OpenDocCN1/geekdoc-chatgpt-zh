## 12.10 示例

### 12.10.1 PGVector 概览

本例使用 bert_base_uncased 模型生成向量表示，并把这些向量写入 PGVector。

PGVector 是面向 PostgreSQL 的扩展，目标是在现有 PostgreSQL 环境中直接提供向量检索与计算能力，无需再引入独立的向量数据库。这样能简化集成成本，尤其适合已经运行 PostgreSQL 且希望快速扩展向量支持的场景。

PGVector 的主要能力有：

- （1）深度整合 PostgreSQL：作为数据库扩展，可在原库内存储与查询向量，非迁移数据或改动应用架构。
- （2）标准 SQL 操作：查询采用常规 SQL 语法，使用门槛低。
- （3）模型灵活组合：可以与传统表结构混用，查询时仍遵循 SQL 规范。
- （4）新型索引：例如 Hierarchical Navigable Small Worlds（HNSW）索引，其核心是通过邻接向量连接来提升性能与召回，因此在近似检索时能更精准定位最近邻。
- （5）加速距离计算：支持在 HNSW 等索引上快速进行距离求算。
- （6）并行写入索引：支持并发向索引中写入，可更方便地从多源同时加载数据。
- （7）改删支持：PGVector 允许更新与删除，而多数其他 HNSW 实现并不提供该功能。
