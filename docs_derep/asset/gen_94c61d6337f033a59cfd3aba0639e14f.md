# 扣子收费吗？核心要点在这

最近关于扣子要不要付费的疑问挺多的，结论其实很清晰：基础版可白嫖一定额度，专业版按量付费。

基础版主要面向尝鲜和调试，在抖音、微信、飞书这些渠道里调用 Bot 时会赠送一定次数的免费调用，额度耗尽后就无法继续使用了，属于有限试用。

专业版是正式的商业形态，收费围绕两项展开：一是 Bot 被调用的次数，二是知识库所占用的存储空间，费用最终由专业版账号统一结算。

两版在资源上限上也有差异。专业版对比基础版，团队工作空间的容量更大，免费的知识库配额也更高，更适合规模化运营。

用 API 的时候有个简单判断标准：返回结果里 code 为 0 表示调用成功；如果 code 是其它数值，则说明请求异常，需要对照说明排查原因。
