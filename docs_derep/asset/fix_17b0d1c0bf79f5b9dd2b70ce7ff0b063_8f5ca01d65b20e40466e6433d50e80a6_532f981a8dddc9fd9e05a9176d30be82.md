(4) 快速捕捉要点：把架构要点收进表格后，阅读者无需逐段阅读长篇说明，扫视即可定位关键信息，沟通效率随之提升。
(5) 迭代成本低：设计蓝图以表格形态沉淀后，出现新模块或技术选型变化时，只需修改对应格子，不必重写整份方案，维护更省力。

总体而言，在架构设计中使用表格，能同时兼顾表达清晰、横向对比、要素完整、视觉友好以及更新便捷，成为团队共建与共享方案的有效手段。

# 应用图形图表帮助思考和表达

在架构设计与系统开发过程中，图形是重要的辅助手段。通过各类图表，架构师与开发团队能更好地理解和表达复杂概念与关系，形成更合理的设计方案。图形工具帮助将关键概念可视化，促进团队沟通与协作，辅助做出明智决策。

本章将介绍若干常用图表，助力架构师和开发团队思考与解决问题。我们将探讨思维导图、鱼骨图等类型，每种图表各有特点与适用场景。

学习这些图表的应用，有助于更好地组织与展示架构思路，分析问题并促进协作与创造力。无论是头脑风暴还是与干系人交流方案，图形图表都是宝贵工具。

本章重点介绍思维导图与鱼骨图。

# 3.1 思维导图

思维导图是一种用于组织与呈现概念及其关系的图表，由中心主题向外辐射分支主题，层层递进，直观呈现思路与逻辑。

# 3.1.1 思维导图在架构设计中的作用

思维导图在架构设计中发挥重要作用。它是图形化工具，有助于整理复杂信息，展现产品结构与关系，辅助决策与沟通。

具体作用如下。

+   (1) 梳理思路与需求：思维导图可将大量想法与需求整理成结构清晰的树状图。将不同需求、功能与任务归类并关联，架构师能更好理解产品整体架构与关键要素。(2) 可视化产品规划：思维导图能以图形方式呈现产品的模块、功能与流程，帮助架构师与团队成员理解组成与环节，从而更好地进行规划与设计。(3) 发现问题与方案：通过思维导图可快速发现产品中的问题与挑战，并探索可能的解决路径。分支与关联结构有助于头脑风暴，激发创新思维，找到最优解。(4) 沟通与共享：思维导图简洁直观，能清晰传达产品信息与用户想法。架构师可用其进行内部沟通与团队协作，将复杂概念与计划以可视化方式呈现给团队与干系人，便于理解与参与。(5) 跟踪与管理进度：在开发过程中，思维导图可作为路线图与计划的可视化载体。

架构师可借助思维导图跟踪项目进展、标记里程碑与任务，并更新与调整产品计划。

总体而言，思维导图为架构设计提供直观、结构化、可视化的方式来组织与管理产品信息，促进协作与决策，帮助架构师更好地理解、规划与推进产品发展。
