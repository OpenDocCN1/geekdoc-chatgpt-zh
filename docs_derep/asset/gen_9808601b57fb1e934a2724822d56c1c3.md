### 定理 4.2.1：回答集与扩张的等价性

根据定理 3.2.1，要证实 $S$ 为 $(D,\emptyset)$ 的扩张，等价于满足三个条件：$\text{GR}(S,\Delta)$ 相容；$\mathcal{A}(\text{GD}(S,\Delta),\Delta)=\text{GD}(S,\Delta)$；且对于任意 $d\in D\setminus\text{GD}(S,\Delta)$，有 $\text{Pre}(d)\not\subseteq S$ 或 $\text{Ccs}(d)\cap S\neq\emptyset$。借助事实 I、事实 II 及算子 A 的定义，这进一步等价于：$\Lambda((\text{GD}(S, \Delta))^S, \Delta) = (\text{GD}(S, \Delta))^S$ 且对任意 $d \in D^S \setminus \text{GD}(S, \Delta)$，$\text{Pre}(d) \not\subseteq S$ 或 $\text{Ccs}(d) \cap S \neq \emptyset$。再依定理 3.2.1，这恰等价于 $S$ 是 $(D^S, \emptyset)$ 的扩张。

**### 定理 4.2.1** 假设 $\Pi$ 为正规程序，$(D_{\Pi}, \emptyset)$ 为其缺省表示。基原子集 $S$ 是 $\Pi$ 的回答集，当且仅当 $\text{Th}(S)$ 构成 $(D_{\Pi}, \emptyset)$ 的一个扩张。

*   **证明路径：**
    *   $S$ 是 $\Pi$ 的回答集 $\iff$ $S$ 是 $\Pi^S$ 的回答集（依定义 4.1.4）；
    *   $\iff$ $\text{Th}(S)$ 是 $(D^S, \emptyset)$ 的扩张（依引理 4.2.1）；
    *   $\iff$ $\text{Th}(S)$ 是 $(D_{\Pi}, \emptyset)$ 的扩张（依引理 4.2.2）。

基于此定理，若将正规回答集程序视作其缺省解释的等价形式，则缺省逻辑的诸多结论（经适当调整后）均可迁移至回答集编程领域。只需留意：对于正规程序 $\Pi$ 及其相伴程序 $\Pi^{\text{Cmp}}$（确定程序），若 $S$ 是 $\Pi^{\text{Cmp}}$ 的回答集，则 $S = \text{Con}(\Lambda(\varphi^{-1}(D_{\Pi}, \Delta)))$，其中 $\varphi$ 如定义 4.2.1 所指。反之，对缺省理论 $\Delta = (D, \emptyset)$，若 $\text{Con}(\Lambda(D, \Delta)) = S$（$D$ 为基缺省集），则 $S$ 是 $(D_{\Pi})^{\text{Cmp}}$ 的稳定模型。由此，给出正规程序的核心概念与特征刻画：

### 定义 4.2.2：相容性层级

设 $\Pi$ 为正规程序，$\Pi^* \subseteq \Pi$。

1.  若 $\text{Head}(\Pi^*) \cap \{C \mid C \in \text{Neg}(\Pi^*)\} = \emptyset$，称 $\Pi^*$ 为**相容**；反之则**不相容**；
2.  若 $\Pi^*$ 相容，且其相伴程序 $(\Pi^*)^{\text{Cmp}}$ 的稳定模型 $S = \text{Head}(\Pi^*)$，称 $\Pi^*$ 为**强相容**；
3.  若 $\Pi^*$ 强相容，且不存在 $\Pi$ 的强相容子集 $\Pi^{**}$ 使得 $\Pi^* \subset \Pi^{**}$，称 $\Pi^*$ 为**极大强相容**。

### 定理 4.2.2：回答集的子集特征刻画

正规程序 $\Pi$ 存在回答集 $S$，当且仅当能找到其子集 $\Pi^*$ 满足：

1.  $\Pi^*$ 相容，且 $S$ 是 $\Pi^*$ 的相伴程序 $(\Pi^*)^{\text{Cmp}}$ 的回答集；
2.  对任一 $r \in \Pi \setminus \Pi^*$，有 $\text{Pos}(r) \not\subseteq S$ 或 $\Pi^* \cup \{r\}$ 不相容。

依据定义 4.2.1 给出的正规程序与缺省理论互转方法，我们直接定义正规程序集上的 $\Lambda$ 算子：$\Lambda(\Pi) = \cup_{0 \le n} \Pi_n$，其中

*   $\Pi_0 = \{A \leftarrow \mid A \leftarrow \in \Pi\}$；
*   对 $n > 0$，$\Pi_n = \{A \leftarrow B_1, \cdots, B_m, \text{not } C_1, \cdots, \text{not } C_n \in \Pi \mid \{B_1, \cdots, B_m\} \subseteq \text{Head}(\Pi_{n-1})\}$。

约定：空正规程序 $\emptyset$ 满足 $\Lambda(\emptyset) = \emptyset$，$\text{Head}(\emptyset) = \emptyset$，且 $\emptyset$ 相容。

### 推论 4.2.1：$\Lambda$ 算子的性质

设 $\Pi$ 为正规程序，若 $\Lambda(\Pi)$ 相容，则：

1.  $\text{Head}(\Lambda(\Pi))$ 封闭于 $\Lambda(\Pi)$ 且为 $\Lambda(\Pi)$ 所支承；
2.  $\text{Head}(\Lambda(\Pi))$ 是 $\Lambda(\Pi)^{\text{Cmp}}$ 的稳定模型；
3.  $\Pi$ 强相容 $\iff$ $\Pi = \Lambda(\Pi)$。

正规程序回答集的特征亦可由下述定理表述。

**### 定理 4.2.2\*** 正规程序 $\Pi$ 有回答集 $S$ 当且仅当存在 $\Pi$ 的子集 $\Pi^*$，使得

1.  $\Pi^*$ 强相容且 $S = \text{Head}(\Pi^*)$；
2.  对任一 $r \in \Pi \setminus \Pi^*$，$\text{Pos}(r) \not\subseteq S$ 或 $\Pi^* \cup \{r\}$ 不相容。

同缺省逻辑类似，不难发现定理 4.2.2 与定理 4.2.2* 中的 $\Pi^*$ 实为 $\text{GR}(S, \Pi)$。

由定理 3.3.1 与定理 4.2.1 可得：

**### 推论 4.2.2：唯一回答集判据**

令 $\Pi$ 为正规程序，若 $\Lambda(\Pi)$ 相容，则 $\Pi$ 拥有唯一回答集 $S = \text{Head}(\Lambda(\Pi))$。特别地，若 $\Pi$ 本身相容，则 $\Pi$ 有唯一回答集 $S = \text{Head}(\Lambda(\Pi))$。

### 定义 4.2.3：弱自相容性

设 $\Pi$ 为正规程序，

1.  令 $\Pi^* \subseteq \Pi$ 强相容且 $S = \text{Head}(\Pi^*)$。若对任一 $r \in \Pi \setminus \Pi^*$，有 $\text{Pos}(r) \not\subseteq S$ 或 $\Pi^* \cup \{r\}$ 不相容，则称 $r$ **关于 $\Pi^*$ 弱自相容**；
2.  若 $r$ 关于 $\Pi$ 的任一强相容子集 $\Pi^*$ 均弱自相容，则称 $r$ **关于 $\Pi$ 弱自相容**；
3.  若 $\Pi$ 中每条规则 $r$ 均关于 $\Pi$ 弱自相容，则称 $\Pi$ **弱自相容**。

显然，自相容正规程序必弱自相容；$\varnothing$ 是任意正规程序的强相容子集；不协调正规程序非弱自相容，其唯一极大相容子集为空集 $\varnothing$。

**### 定理 4.2.2\*\*** 正规程序 $\Pi$ 有回答集 $S$，当且仅当存在 $\Pi$ 的强相容子集 $\Pi^*$，使得 $S$ 是 $\Pi^*$ 的回答集且对任意 $r \in \Pi \setminus \Pi^*$，$r$ 关于 $\Pi^*$ 弱自相容。

**### 推论 4.2.3**

设基原子集 $S$ 为正规程序 $\Pi$ 的回答集，则 $\text{GR}(S, \Pi)$ 强相容，且对任一 $r \in \Pi$，$r$ 关于 $\text{GR}(S, \Pi)$ 弱自相容。

**### 定理 4.2.3：弱自相容程序的回答集存在性**

弱自相容的正规程序 $\Pi$ 必有回答集；对 $\Pi$ 的任一极大强相容子集 $\Pi^*$，$\text{Head}(\Pi^*)$ 均为 $\Pi$ 的一个回答集。

### 定义 4.2.4：半单调性

正规程序 $\Pi$ 称作**半单调**的，当且仅当对任意正规程序 $\Pi^*, \Pi^{**}$，若 $\Pi^* \subseteq \Pi^{**} \subseteq \Pi$，则 $\Pi^*$ 的每一回答集 $S^*$ 都存在 $\Pi^{**}$ 的回答集 $S^{**}$ 使得 $S^* \subseteq S^{**}$。

**### 定理 4.2.4：弱自相容性的半单调特征**

正规程序 $\Pi$ 弱自相容 $\iff$ $\Pi$ 半单调。

### 例 4.2.1

正规程序 $\Pi=\{B\leftarrow,\ A\leftarrow B,\ \text{not } C\}$ 弱自相容且有唯一回答集 $\{B, A\}$（$A, B, C$ 为基原子）。加入规则 $C\leftarrow A, \text{not } E$ 得 $\Pi'$，其有两个极大强相容子集：$\{B\leftarrow,\ A\leftarrow B,\ \text{not } C\}$ 与 $\{B\leftarrow,\ C\leftarrow A,\ \text{not } E\}$。但 $\Pi'$ 非弱自相容，故无回答集。

### 例 4.2.2

正规程序 $\Pi=\{A\leftarrow\text{not }B,\ B\leftarrow\text{not }A\}$ 不相容但弱自相容，拥有两个回答集 $\{A\}$ 与 $\{B\}$。

不失一般性，我们考察由可数条规则构成的弱自相容正规程序的回答集求解算法。

### 定义 4.2.5：向前链接算法

设 $\Pi$ 为弱自相容正规程序，$<$ 为自然数集上通常序，$\Pi^<=\{r_1,\cdots,r_n,\cdots\}$。定义序列 $\{S_i\}$：

1.  $S_0=\emptyset$；
2.  对 $i\geqslant 0$，若存在满足条件的最小 $k$：$\text{Pos}(r_k)\subseteq S_i$ 且 $S_i\cap\text{Neg}(r_k)=\emptyset$，则 $S_{i+1}=S_i\cup\text{Head}(r_k)$；否则 $S_{i+1}=S_i$。

令 $S=\cup\{S_i\mid i\geqslant 0\}$。

### 定理 4.2.5：向前链接算法的可靠性与完备性

设 $S$ 为基原子集，$\Pi$ 为弱自相容正规程序。$S$ 是 $\Pi$ 的回答集 $\iff$ $S$ 由向前链接算法得出。

值得注意的是，一方面，定义 4.1.1 与 4.1.2 引入部分赋值与归约，将稳定模型语义推广至回答集程序，确立了回答集概念（定义 4.1.3）；另方面，依定理 4.2.1，正规回答集程序属缺省逻辑特例，依缺省逻辑语义框架的可靠完备性定理（3.6.2、3.6.3），其回答集亦可由相应语义框架刻画。由此引出核心问题：这两视角下的正规程序回答集概念是否一致？更确切说，对任一正规程序 $\Pi$ 及其对应缺省理论 $\Delta=\langle D_{\Pi},\emptyset \rangle$，其中

$D_{\Pi}=\{B_1\wedge\cdots\wedge B_m:M\neg C_1,\cdots,M\neg C_n/A\mid A\leftarrow B_1,\cdots,B_m,\text{not }C_1,\cdots,\text{not }C_n\in\Pi\}$

下述两结论是否等价：

**结论 I**：基原子集 $S$ 是 $\Pi$ 的回答集 $\iff$ $S$ 是 $\Pi^S$ 的稳定模型（定义 4.1.3）；

**结论 II**：基原子集 $S$ 是 $\Pi$ 的回答集 $\iff$ 存在 $D'\subseteq D_{\Pi}$ 与语义框架 $\langle \Phi,\tilde{\Psi} \rangle$ 满足：

1.  $(\Phi,\{\Phi_i\})\leqslant_{(d_i)}(\Phi,\tilde{\Psi})$ 且 $(d_i)$ 恰由 $D'$ 所有元素构成；
2.  $(\Phi,\tilde{\Psi})$ 分布相容；
3.  对任一 $d\in D_{\Pi}\backslash D'$，$(\Phi,\tilde{\Psi})$ 关于 $d$ 稳定。

其中

$D'=\{B_1\wedge\cdots\wedge B_m:M\neg C_1,\cdots,M\neg C_n/A\mid B_1,\cdots,B_m\subseteq S,\{C_1,\cdots,C_n\}\cap S=\emptyset, A\leftarrow B_1,\cdots,B_m,\text{not }C_1,\cdots,\text{not }C_n\in\Pi\}\subseteq D_{\Pi}$

$\tilde{\Psi}=\{\text{MOD}(B)\mid B\in\text{Ccs}(D')\}\cup\{\Phi\}$

依定理 3.6.2、3.6.3，因 $\text{MOD}(\emptyset)=\Phi$，故 $\Psi=\Phi$。

若结论 I 与 II 等价，则两者给出的回答集概念等价，在此意义下定义 4.1.3 合适。此论证易推广至 4.1 节定义的任意回答集程序，故有下述定理。

### 定理 4.2.6：两种语义视角的等价性

给定任一正规程序 $\Pi$ 及对应缺省理论 $\Delta=(D_\Pi, \varnothing)$，其中 $D_\Pi = \{B_1 \wedge \cdots \wedge B_m : M \neg C_1, \cdots, M \neg C_n / A \mid A \leftarrow B_1, \cdots, B_m, \text{not } C_1, \cdots, \text{not } C_n \in \Pi\}$。$S$ 是 $\Pi^S$ 的稳定模型，当且仅当存在 $D' \subseteq D_\Pi$ 与语义框架 $(\Phi, \tilde{\Psi})$ 满足：

1.  $(\Phi, \{\Phi_i\}) \leqslant_{(d)} (\Phi, \tilde{\Psi})$ 且 $(d_i)$ 恰由 $D'$ 所有元素构成；
2.  $(\Phi, \tilde{\Psi})$ 分布相容；
3.  对任意 $d \in D_\Pi \setminus D'$，$(\Phi, \tilde{\Psi})$ 关于 $d$ 稳定。

其中

$D'=\{B_1\wedge \cdots \wedge B_m:M\neg C_1,\cdots,M\neg C_n/A\mid B_1,\cdots,B_m\in S,\{C_1,\cdots,C_n\}\cap S=\varnothing,A\leftarrow B_1,\cdots,B_m,\text{not } C_1,\cdots,\text{not } C_n\in \Pi\} \subseteq D_\Pi$  

$\tilde{\Psi}=\{MOD(B)\mid B\in \text{Ccs}(D')\} \cup \{\Phi\}$

**证明** $D'\subseteq D_\Pi$ 与语义框架 $(\Phi, \tilde{\Psi})$ 满足结论 II 中条件 (1)–(3) $\iff$

1.  $\text{Pre}(d_0)=\varnothing$，对 $i>0$，$\mathbf{GAtom}(\text{Pre}(d_i)) \subseteq \bigcup_{j<i} \text{Cond}(d_j)$（依定义 3.6.3，$\mathbf{GAtom}(F)$ 为公式 $F$ 中基原子集）；
2.  $(\Phi, \tilde{\Psi})$ 分布相容（显然成立）；
3.  对任意 $B_1 \wedge \cdots \wedge B_m : M \neg C_1, \cdots, M \neg C_n / A \in D_\Pi \setminus D'$，$\text{MOD}(B_1 \wedge \cdots \wedge B_m) \nsubseteq \Psi'$ 或存在 $i: 1 \leqslant i \leqslant n$ 使 $\text{MOD}(C_i) \notin \tilde{\Psi}$（依定义 3.6.8） $\iff$ $S$ 是 $(D')^S = \{A \leftarrow B_1, \cdots, B_m \mid B_1 \wedge \cdots \wedge B_m : M \neg C_1, \cdots, M \neg C_n / A \in D'\}$ 的稳定模型，即 $\text{Cn}((D')^S) = T_{(D')^S} \uparrow \omega$（依 $D'$ 定义、定义 4.1.2 及定理 2.3.5）；
4.  对任意 $B_1 \wedge \cdots \wedge B_m : M \neg C_1, \cdots, M \neg C_n / A \in D_\Pi \setminus D'$，$\{B_1, \cdots, B_m\} \nsubseteq S$ 或 $\{C_1, \cdots, C_n\} \cap S \neq \varnothing$ $\iff$ $\Pi^S = (D^*)^S$（依定义 4.1.2），且 $S$ 是 $\Pi^S$ 的稳定模型。证毕。
