# 树莓派智能浇水控制器速览

自动浇水本质是采集土壤湿度、判断是否需要补水、按需驱动继电器。下面的实现把这三步做成闭环，同时加入日志记录、异常兜底和命令行自检，可以直接在树莓派上运行。

## 收尾归还硬件

程序退出前会先判断继电器实例和湿度传感器实例是否存在，存在就调用 close 释放引脚占用，最后通过日志提示资源已回收，避免下次启动出现冲突。

def run(self):

    try:

        while True:

            if self.is_soil_dry():

                self.start_irrigation()

                time.sleep(self.irrigation_duration)

                self.stop_irrigation()

            else:

                logging.info("土壤湿润，无须灌溉")

            for _ in range(self.check_interval):

                time.sleep(1)

    except KeyboardInterrupt:

        self.stop_irrigation()

## 冷启动自检

首次部署建议先执行连通性校验。自检会用 GPIO Zero 创建一个低电平触发的继电器代理和数字输入的湿度传感器，先让继电器吸合两秒再断开，随后连续三次读取电平并换算为干燥或湿润状态，最后主动释放资源并返回校验结果。

## 入口与双模式

主入口提供两种运行方式。加上 --test 参数仅跑硬件自检，成功提示系统可用，失败提示检查接线。默认模式会先输出运行信息，包括湿度传感器引脚、继电器引脚、日志文件位置、检测间隔和灌溉时长，随后实例化控制器进入循环，用 Ctrl+C 可随时中断。
