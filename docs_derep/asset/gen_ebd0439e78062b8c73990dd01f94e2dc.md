- (2) 把原本的【口播剧情】改成【动画演示/真人情景剧】的形式，用【灵魂配音/方言讲解】来加深记忆点，贯穿整支片子的标志性动作要设计好，比如【摔道具/魔性手势】；字幕部分则用【荧光色/弹幕体】把关键词凸显出来。

- (3) 在现有【×个误区】的框架上，额外补上关于【××细节问题】的片段，采用【行为示范+错误案例】的对照方式，重点强化【省钱/省时/安全】的价值感受，同时穿插【行业黑话揭秘/价格坑点清单】等专业内容。

### 5.1.3 调整提示词，让它适配各类型短视频脚本

正如一把钥匙打不开所有锁，同一套短视频脚本提示词也无法通用。不同赛道的短视频，对提示词的需求差异很大。表5-3汇总了各类短视频的提示词参考。

**表5-3**

| 短视频类型 | 内容特征 | 提示词撰写要点 | 注意事项 |
| :--- | :--- | :--- | :--- |
| 知识科普类 | 干货浓度高、思路清晰、专业可信 | 锁定受众，结构清晰（问题→干货→结论），配数据或案例佐证，表达要通俗易懂 | 别太学术化；注意信息过载；可打出“新手必看”“家长必备”等标签 |
| 情绪共鸣类 | 代入感强、故事化叙述、生活细节丰富 | 场景要真实可信，语言温暖走心，设置高共鸣金句，结尾做升华或反转 | 避免说教感太强；细节需有生活质感；台词要口语化 |
| 吐槽搞笑类 | 节奏明快、反转频繁、梗感足、夸张演绎 | 明确吐槽对象，开头即用高能反转抓眼，中间塞满密集笑点，收尾引导互动 | 笑点要对受众胃口；规避低俗梗；字幕要放大夸张情绪词 |
| 产品带货类 | 场景真实、痛点牵引、种草自然 | 突出使用场景与效果对比，点明痛点，软性植入产品信息，最后引导转化 | 禁用硬广；人设需真实可信；避免直接带品牌广告词（未授权除外） |
| 短剧剧情类 | 人物鲜明、冲突反转强、代入感足 | 厘清角色关系，冲突设计巧妙，转折流畅，结尾留悬念或反转 | 避免套路剧情；台词自然不做作；情节符合现实逻辑或平台调性 |

以上是面向不同脚本类型的通用提示词模板。

## 5.2 让DeepSeek吃到“对”的数据

想要DeepSeek写出想要的风格，就像训鹦鹉学唱：一靠教什么，二靠怎么教，时长反而其次。

### 5.2.1 投喂时要把握的关键动作

很多人用DeepSeek时习惯乱扔素材，期待AI自学成才，结果输出要么四不像，要么偏差极大。投喂时把握好“选、分、标”三步很关键。

#### 1. 选——只投喂对味的，别投杂的

AI学什么取决于喂什么。第一步是只投喂符合目标风格的素材，宁少勿杂。表5-4是几个挑选示例。

**表5-4**

| 目标 | 只选这类素材 | 别选这类素材 |
| --- | --- | --- |
| 学习品牌宣传文案 | 官方品牌介绍、过往案例、成功广告文 | 新闻通稿、说明书、合同文本 |
| 学习小红书风格 | 高质量种草笔记、爆款博主文案 | 微博吐槽、知乎长篇讨论 |
| 学习高端白皮书 | 行业优秀白皮书、专家深度文章 | 网络段子、用户评论 |

#### 2. 分——按类喂，别混炖

不要把所有品类混在一起喂，容易让模型“宕机”。建议提前分类，采用“场景分类法”，谁用、在哪用就归哪类。表5-5是常见的基础分类模板。

**表5-5**

| 类别名称 | 素材举例 |
| --- | --- |
| 产品介绍类 | 产品卖点 / 使用说明 / 差异化优势 |
| 活动宣传类 | 营销活动文案 / 促销信息 / 社群推文 |
| 客服话术类 | 常见问题回复 / 客服标准话术 |
| 高管发言类 | 年度总结 / 内部讲话 / 对外演讲 |
| 朋友圈日常类 | 轻松生活化短文案 |

例如开宠物店，可以这样分：
- 分类1：宠物用品广告（逗猫棒、狗粮等宣传语）
- 分类2：客户咨询回复（“狗狗拉肚子怎么办”等问答）
- 分类3：宠物知识科普（猫咪为何爱舔毛等）

分类可通过DeepSeek的“开启新对话”实现，对话1谈广告，对话2谈客服等。

#### 3. 标——对数据打标签，便于检索

标签相当于关键词，用最简词概括素材特点。同一份素材可打多标签，如“给谁看”“什么风格”“哪个行业”。表5-6为标签示例。

**表5-6**

| 标签类型 | 自问方式 | 举例 |
| :--- | :--- | :--- |
| 行业标签 | 文案属于哪个行业 | 美妆、数码、汽车、地产、教育 |
| 受众标签 | 写给谁看 | 年轻人、宝妈、白领、企业主、学生 |
| 风格标签 | 文案是什么风格 | 正式、幽默、活泼、硬核、口语化 |

### 5.2.2 数据太少或太多时的补救

#### 1. 数据太少怎么补

数据量不够时，精大于多。小而美，逐步扩展。

1. 精挑最具代表性的优质样本。表5-7示例。

**表5-7**

| 目标 | 应选素材 |
| :--- | :--- |
| 写小红书种草文案 | 点赞高、风格稳定的爆款笔记 |
| 写品牌宣传文案 | 官方广告、品牌Slogan、宣传册 |
| 写高端白皮书 | 行业权威发布的标准资料 |

2. 投喂少而精，纯度高更易学。
3. 持续积累，等量变到质变。
4. 提示词模板辅助。

> “请参考下面这批高质量文案的风格，学习其表达方式，帮我写一篇类似内容。要求：风格统一、表达清晰、契合目标受众。
> 1.……
> 2.……
> 3.……
> 4.……”

提问逻辑：提供参考让模型知道模仿对象；要求风格统一是为了兼顾语气与使用场景；强调学习表达方式而非照抄；结构化提问提升效率。

示例：基于5条小红书爆款文案，目标受众20~35岁女性，风格轻松活泼强代入，求一篇口红种草。模型输出的镜面唇釉文案体现了同类感官夸张、场景切换与强情绪的写法。

#### 2. 数据太多怎么补

原则是“取精去糟”，先去杂后分类再清洗。

1. 删除无效数据：与目标无关、有错别字、低质、风格混乱、过时失效等。
2. 分类管理，避免混乱。
3. 清洗技巧：批量去重、统一标点段落格式、打标签。
4. 提示词模板。

> “我这批内容风格混杂，请帮我整理分类并为每类打标签，方便后续管理。数据如下：
> 1.……
> 2.……
> 标签包括：[行业] [受众] [风格]。”

提问逻辑：点明“风格杂”让模型做梳理；要求标签化利于后续精准调用；要求“分别整理”实现内容资产化管理。

示例展示了5条混杂数据被分为美妆、数码、母婴，标注受众与风格，并给出分类依据说明。后续可追问：
1. 【序号：……】除当前标签外，还可能有哪些细分受众/内容标签？说明理由。
2. 基于【产品/内容】给出3个新颖切入角度，适合做成【风格】短视频脚本。
3. 把【序号：……】内容按【开头吸引—中段展开—结尾互动】改写成60秒脚本，适配【受众】。

## 5.3 用DeepSeek产出爆款短视频脚本

“同样产品，别人10万赞，我的播放卡500？”在抖音/小红书的推荐逻辑里，前3秒决定生死，脚本结构决定上限。以下拆解3个实战黄金公式。

### 5.3.1 3秒留人钩子

推荐机制的第一判断就是3秒内是否留人。钩子必须具备：
1. 强刺激：情绪、悬念、好奇、反差、痛点。
2. 强相关：贴近个人生活、情感、困扰。
3. 强行动诱导：让人想继续看。

钩子公式=【抓眼关键词】+【观众痛点/利益】+【悬念/反差促看】

表5-8为常见钩子类型。

**表5-8**

| 留人钩子类型 | 适用场景 | 常见句式 |
| :--- | :--- | :--- |
| 悬念式钩子 | 知识科普、经验分享 | “你知道为什么……” “很多人不知道……” |
| 反差式钩子 | 改造类、挑战类 | “我花1块钱做了……结果震惊了” |
| 痛点式钩子 | 情感类、生活类 | “99%的人都做错了……” “如果你也有这种烦恼……” |
| 金句式钩子 | 观点表达类 | “一句话总结……” “听懂这句话，你就不亏了” |
| 热点式钩子 | 时事热点 | “今天最炸的新闻就是……” |

提示词模板：

> “请按短视频脚本规范，为主题【×××】生成5个高吸引力开头钩子。结构为：引发注意关键词+相关痛点/利益+悬念/反差，风格参考【平台】热门视频，语言简短直白有冲击。”

提问逻辑：关键词抓注意；痛点/利益促共鸣；悬念/反差促留存；参考平台热门确保合拍；强调简短直白避免拖沓。
