RT-H 对具身多模态大模型的探索提供了可参考的思路。先看效果层面，RT-H 在体量庞大且来源各异的数据集上呈现出领先的表现，不过即便经过修正式训练，其任务执行的绝对完成率仍有提升余地。值得关注的是其提出的语言化动作表征，可以作为不同具身数据集合之间的桥梁，例如打通 OXE[907] 这类汇聚多源具身数据的资源，同时也能从仅以语言描述行为的视频中抽取行动知识。

再看结构层面，RT-H 对行为进行了多层次的拆解，但中间层次的抽象粒度该如何确定，仍是下一步需要厘清的问题。

最后看应用层面，语言动作既为动作预测提供了语境，也起到了压缩表达的作用。借助 RT-H 的语境特性，把语言动作的预测当作先验信息，就能收窄强化学习以及策略探索时的搜索范围。这种表征让策略训练更高效，同时便于人工理解与修正。在模仿学习里，Mobile ALOHA[908] 等工作已显示保持机器人与示范者行为一致的重要性，而采用语言动作对行为空间进行压缩，则能进一步提升一致性，从而使策略学习更高效。

## 5.6 本章小结

多模态大模型赛道正快速迭代，新方法与新视角层出不穷。正因更新太快，本书不可能穷尽所有前沿议题。作者希望书中内容能为从事多模态大模型研究的同行与开发者提供借鉴与灵感，推动社区共同进步。目前该方向仍处于起步阶段，尚未形成统一完备的体系，但沿着新一代人工智能的技术范式，深入挖掘其跨领域的潜力，未来很可能出现令人振奋的创新，AGI 的临近也会更明显。将计算机视觉、自然语言处理、因果推理、世界模型和具身智能等方向与 Agent 深度结合，构建真正的通用 Agent，将对人类社会发展产生深远推动。
