**ID3 算法总览**
Iterative Dichotomiser 3 即 ID3，是决策树分类方法中的早期代表。它的做法是用信息熵来衡量节点纯度，并选择信息增益最大的特征作为分裂依据，再递归生成树结构完成分类 [Data: Entities (0); Reports (0); Relationships (0)]。

**熵与增益的用法**
信息熵用于刻画样本集合的混乱程度，熵值越小代表越纯净。信息增益则反映分裂前后熵值的变化，用来评估属性对数据划分的效果。ID3 每次都挑增益最大的属性进行切分，逐步细化决策树 [Data: Entities (0); Reports (0); Relationships (27)]。

**划分方式与离散化要求**
ID3 仅支持离散型特征，连续型特征必须先离散化，例如分箱。它的划分逻辑是一次展开一列，与 CART 寻找最佳切分点的做法不同。比如针对 AGE 列，ID3 会按不同取值把样本拆成多个子集，再分别计算熵与增益 [Data: Sources (0, 1); Entities (6, 7, 8, 9); Relationships (10, 11, 12, 13)]。

**主要短板**

3. 缺乏剪枝机制：没有内置剪枝手段防止过拟合，训练集表现好，测试集可能不佳 [Data: Sources (1); Entities (0)]。

**与 C4.5、CART 的联系**
ID3 是决策树的基础，后续的 C4.5 和 CART 在此基础上改进。C4.5 引入了连续变量处理、剪枝机制和增益率等优化，CART 则支持分类与回归，并采用二分法划分数据集 [Data: Entities (1, 2); Relationships (0, 1, 4, 14)]。

ID3 以信息熵和信息增益构建分类模型，奠定了决策树的重要思想。尽管存在局限，后续的 C4.5、CART 等算法在 ID3 基础上优化，提升了模型的性能与适用范围 [Data: Entities (0, 1, 2); Reports (0, 1); Relationships (0, 1, 4, 14)]。
