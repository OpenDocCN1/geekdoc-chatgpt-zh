# 01 人工生命模型

下面介绍人工生命模型。人工生命模型能让机器看起来具备某种意志或生命感。

+   - 机器拥有意志 = 拥有生命

# 何谓生命

十多年前，电子宠物玩具曾一度流行。因为人类喜欢饲养其他生物，所以即便是屏幕保护程序里游动的热带鱼，也能让人感受到生命的痕迹。

生物最核心的特征是具备自我复制能力，即繁衍后代的能力。这类程序由来已久，如果人们能从程序自我复制的行为中感受到意志的存在，便会期待机器也能拥有生命。

# 生命游戏

生命游戏就是这样一个经典程序。该程序自1970年发表在杂志上后长期风靡。在棋盘上任意位置落子或填充方格，然后依据特定规则改变方格状态，模拟生命随时间演变的过程。可以用方格纸手工操作，但借助计算机按固定间隔自动处理更为便捷。随着时间推移，被填充的方格会不断扩散或消失，演化过程持续变化。

在游戏中，方格只有填充（生命诞生）和空白（死亡）两种状态，状态变化遵循下述规则。该规则被称为算法。

# 02 有限自动机

一个模型中的细胞处于某种状态，当它接收到一个输入或触发某种事件时，状态会在有限的状态之间转换，这就是自动机。下面就对自动机进行介绍。

+   - 当模型接收到一个输入或触发某种事件时，状态会在有限的状态之间转换 = 有限状态的机器（有限状态机）
- 有限状态机又称有限自动机
- 可以用状态转换图表示

# 自动机

利用生命游戏中的方格（细胞）来表示时间的推移和状态的变化，进而研究空间结构变化在时间轴上的发展，这一理论研究领域称为元胞自动机。元胞自动机直译过来是自动人偶，简单来说，就是能够对外界刺激做出反应的机关人偶。

人偶记住一些状态后，在受到外界刺激时能够做出不同的反应。所以，这种人偶也叫作状态机（state machine），如果状态数有限就叫作有限状态机或有限自动机（图3-7）。
