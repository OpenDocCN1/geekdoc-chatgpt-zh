# Anaconda安装全流程与PyCharm配置指南

## 1. 获取安装包

前往清华大学开源软件镜像站下载对应系统的 Anaconda 安装程序。该镜像源提供了多个历史版本供选择，例如 1.4.0 与 1.5.0 系列，涵盖 Linux、macOS 及 Windows（32/64位）平台，文件大小从 150MB 到 300MB 不等，均发布于 2013 年 7 月。

## 2. 图文详解安装步骤

双击下载的 `.exe` 文件启动向导，按以下顺序操作：

1.  **欢迎界面**：直接点击 `Next` 进入下一步。
2.  **安装范围**：在“Select Installation Type”窗口勾选 **All Users**（需管理员权限），而非默认的“Just Me”，然后点击 `Next`。
3.  **目标路径**：在“Choose Install Location”处指定安装目录。建议避开系统盘（C盘），选择空间充足的分区，确认无误后点击 `Next`。
4.  **高级选项（关键）**：在“Advanced Installation Options”界面：
    *   **不勾选** “Add Anaconda to the system PATH environment variable”。官方不推荐此项，以免污染系统环境变量，导致后续卸载重装麻烦；日常使用请通过开始菜单启动。
    *   **务必勾选** “Register Anaconda as the system Python 3.7”。这能让 PyCharm、VS Code、PyDev 等 IDE 自动识别该 Python 解释器为系统主环境。
    *   完成勾选后点击 `Install` 等待进度条走完。

安装完成后会弹出成功提示页，点击 `Next`。随后会推荐安装 Microsoft Visual Studio Code，若暂不需要可直接点击 `Skip` 跳过。

## 3. 手动配置系统环境变量

由于安装时未自动添加 PATH，需手动配置以便在任意终端调用 `conda` 与 `python`：

1.  右键“此电脑” → `属性` → `高级系统设置` → `环境变量`。
2.  在“系统变量”区找到 `Path`，双击编辑。
3.  点击“新建”，依次添加 Anaconda 安装根目录及其 `Scripts` 子目录（具体路径格式参考配置示意图）。
4.  全程点击“确定”保存退出。

## 4. 验证安装成果

打开新的命令行窗口（必须重开才能生效新环境变量），依次执行：

*   输入 `python`，回车。若出现 `>>>` 提示符及版本信息，说明 Python 核心环境就绪（输入 `exit()` 可退出）。
*   输入 `conda --version`，回车。若输出版本号，标志着包管理工具配置成功。

至此，Anaconda 基础环境已完全就绪。

# 终端交互模式：快速试错的利器

Python 自带交互式解释器（REPL），无需创建文件即可即时运行代码片段，极适合验证语法、测试逻辑或学习新库。

**启动方式**：终端输入 `python` 回车，见到 `>>>` 提示符即进入交互模式。此后每行输入代码按回车即刻执行，结果直接回显。

> **示例**：输入 `print("Hello World")` 回车，屏幕立即打印问候语。

**适用边界**：代码量极少、逻辑简单时极其高效；但一旦涉及多行函数、类定义或复杂流程，终端编辑极不便（无法保存、难以修改历史行）。此时应转向**脚本文件**模式——将代码写入 `.py` 文件再整体运行。

# PyCharm：专业级 Python IDE 深度解析

## 为何选择 PyCharm？

作为 JetBrains 出品的集成开发环境（IDE），PyCharm 集成了开发全生命周期工具链：
*   **智能编码**：语法高亮、代码补全、重构、跳转、实时纠错（Linter）遵循 PEP 8 规范。
*   **调试神器**：可视化断点、变量监控、表达式求值，大幅缩短排错时间。
*   **工程管理**：项目结构视图、虚拟环境隔离、Git/SVN 版本控制面板。
*   **生态深度**：原生支持 Django/Flask Web 框架、Google App Engine、IronPython、Jupyter Notebook、科学计算套件。

**版本选择**：Professional 版（收费）解锁 Web 与数据科学高级特性；Community 版（免费开源）已涵盖纯 Python 开发全功能，入门及中小项目完全够用。

# PyCharm 环境绑定 Anaconda 实战

安装完 Python 与 PyCharm 后，首要任务是让 IDE 识别正确的解释器环境。

### 步骤演示

1.  打开 `File` → `Settings` (macOS 为 `PyCharm` → `Preferences`)。
2.  左侧导航至 `Project: <项目名>` → `Python Interpreter`。
3.  点击右上角 **齿轮图标** → `Show All...` → 列表上方 **加号 (+)** 新增解释器。
4.  在弹窗选择 **Existing environment（现有环境）**，浏览定位到 Anaconda 安装目录下的 `python.exe`（如 `D:\Anaconda\python.exe`）。
5.  **关键操作**：勾选 `Make available to all projects`，使该环境全局复用，免去新建项目重复配置。
6.  确定返回，可在解释器列表看到该环境预装的包清单（numpy, pandas, requests 等），确认无误后 `OK` 完成绑定。

# 在 PyCharm 中创建并运行首个脚本

### 规范工程结构

1.  项目视图右键 → `New` → `Directory`，命名为 `python_work`（全小写 + 下划线，符合 PEP 8 命名约定）。
2.  右键该目录 → `New` → `Python File`，命名 `hello_world`（自动补全 `.py` 后缀）。后缀标识文件类型，IDE 据此提供语法高亮与运行入口。

### 编写代码

在编辑器输入：
```python
print("Hello, Python World!")
```
若界面未正常显示高亮或报红，请检查：文件名是否含大写/空格？引号是否成对？Python 对大小写、缩进、符号极其敏感，任一细节偏差即报错。

# Python 核心数据类型速览

掌握基础类型是数据处理的基石，以下聚焦最常用三大类。

## 1. 数值类型

Python 按数学特性区分四类，前两者使用频率最高。

| 类型 | 关键字 | 典型场景 | 示例 |
| :--- | :--- | :--- | :--- |
| **整数** | `int` | 计数、索引、ID | `42`, `-7`, `0` |
| **浮点数** | `float` | 测量、科学计算、金融 | `3.14`, `-0.001`, `2.0` |
| 长整数 | `long` (Py2) / `int` (Py3) | 超大整数运算 | 自动无缝切换，无需标识 |
| 复数 | `complex` | 信号处理、物理仿真 | `1+2j`, `3j` |

**浮点数精度陷阱**：
```python
# 除法必得浮点数
8.3 / 2.7  # 3.074074...
format(8.3 / 2.7, '.3f')  # '3.074' 格式化保留3位小数

# 乘法看似整数实为浮点
y = 2.5 * 4.8  # 12.0 (而非 12)
print(f"{y:.1f}")  # 12.0

# 两种除法写法结果一致
8 / 3        # 2.666...
8.0 / 3.0    # 2.666...
```

## 2. 字符串：文本数据的通用载体

**本质**：字符有序序列，不可变。凡是“人类可读文本”本质皆字符串。

**典型业务场景**：
*   用户名、地址、评论内容（非结构化文本）
*   日志记录、报文解析
*   **伪数值**：邮政编码 `010000`、手机号 `13800138000`、身份证号——**不可参与数学运算，必须按字符串存储**。

**四种定界符灵活嵌套**：
*   单引号 `'hello'`
*   双引号 `"world"`
*   三单引号 `'''多行\n文本'''`（保留换行/缩进，常用作文档字符串）
*   三双引号 `"""SQL查询\nSELECT * FROM table"""`

## 3. 列表：有序可变容器

**特征**：用 `[]` 括起，逗号分隔，元素类型任意混合，支持重复，下标从 0 开始随机访问。

```python
# 命名建议用复数名词暗示集合概念
letters = ['a', 'b', 'c']
scores = [95, 87, 92, 88]
mixed = [1, "text", 3.14, True, [1, 2]]  # 嵌套列表
```

**核心优势**：动态增删改查（`append`, `pop`, `insert`, `remove`, 切片赋值），是数据清洗、特征工程最基础的数据结构。
