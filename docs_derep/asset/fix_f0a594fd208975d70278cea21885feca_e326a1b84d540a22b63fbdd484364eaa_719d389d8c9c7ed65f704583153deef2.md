### 5.3 DeepSeek-R1本地知识库问答
本节重点介绍如何借助主流的大模型 Web 对话开源项目，结合 AnythingLLM 搭建本地知识库问答系统，并演示接入 DeepSeek-R1 的实操流程。

#### 5.3.1 主流本地对话开源框架一览
随着大模型落地加速，本地知识库问答赛道涌现出大量开源方案，它们提供更灵活、可视化、可扩展的推理交互体验，也为个人与企业交付完整的本地 RAG 体系。

- 1. 【个人级】ChatBox：跨模型聊天客户端
ChatBox 是一款面向开发者日常使用的轻量级跨平台对话工具，支持 OpenAI、DeepSeek、Ollama 等多模型自由切换。特点包括跨平台兼容、多模型适配、API 与本地模型统一管理、聊天记录本地保存并自动打标签。

- 2. 【轻量级RAG】AnythingLLM：一键式知识库问答框架
AnythingLLM 是一个轻量级本地知识库问答平台，零代码即可上手，内置文档解析与嵌入模块，适合个人或小型项目搭建。亮点是支持一键导入 PDF、Docx、Markdown 等格式，预集成 OpenAI、Ollama、LocalEmbedding 等嵌入模型与本地 LLM，并支持多用户协作与浏览器端操作。

- 3. 【企业级】RAG 和 GraphRAG 知识库对话框架：Kotaemon
Kotaemon 由 Cinnamon 主导开发的企业级 GraphRAG 框架，融合图谱推理与传统向量检索，实现更强的结构化语义检索能力。核心能力有知识图谱与 RAG 混合推理架构、项目内可视化图谱关系界面、多轮上下文对话、企业级认证、数据隔离与部署支持。

- 4. 【企业级】RAG 和 Agent 多功能综合前端框架：Open-WebUI
此前已在 Open-WebUI 项目中初步集成 DeepSeek 模型。Open-WebUI 是一个支持插件扩展、多 LLM、多用户多模型交互的统一前端，适用于本地部署。优势在于强大的多 Agent 支持与可拓展工具链、多用户协作与前后端分离架构、自定义系统指令与会话参数模板。

- 5. 【企业级】多模态交互框架：lobe-chat
lobe-chat 面向高级交互体验设计的前端框架，支持图片、语音、代码、PDF 等多模态接入，适配多种模型推理场景。
