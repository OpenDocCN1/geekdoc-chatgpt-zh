机器学习怎么运作，最直观的类比其实藏在日常挑西瓜里。夏季去超市选甜瓜，多数人会先看再敲：看的是果皮色泽和蒂部形态，敲的是声音是清脆还是沉闷。随着实践次数增加，依靠这几条线索挑中好瓜的命中率会明显提高。把这种经验化的判断整理成表格，就是下面的记录。

### 表 2.1 西瓜数据集

| 序号 | 色泽 | 根蒂 | 声响 | 是否好瓜 |
|---|---|---|---|---|

| 1 | 青绿 | 干缩 | 浊响 | 是 |
| 2 | 黑绿 | 干缩 | 浊响 | 是 |
| 3 | 青绿 | 硬挺 | 清脆 | 否 |
| 4 | 黑绿 | 硬挺 | 沉闷 | 否 |
| ... | ..... | ..... | ..... | ..... |

人脑在反复试错中会把零散观察归纳成经验法则，例如“某类色泽搭配某类根蒂和某类声响就倾向为好瓜”。这种归纳本质上是一个复杂、非线性的神经元学习网络。

机器学习则走另一条路。计算机只能处理数字信号，只能执行大于、小于、不等于这类确定规则，对模糊的感知感觉无能为力。用一个极简的加法训练来演示：

- 问：1+4等于几？
- 答：20。
- 反馈：错误，数值偏高。
- 问：1+9等于几？
- 答：13。
- 反馈：错误，数值偏高。
- 问：3+4等于几？
- 答：7。
- 反馈：正确。
- 问：6+9等于几？
- 答：13。
- 反馈：错误，数值偏低。

很多轮之后……
问：2+2等于几？
答：4。
问：4+5等于几？
答：9。

这就是机器学习里最常见的模式，称为有监督机器学习。监督指训练时数据集会给出正误反馈。初期几步相当于模型校准，“偏高”“偏低”可视为误差监督信号，模型据此调整自身参数，这正是反向传播 back propagation 的通俗解释。

综合上述例子与专业教材的定义，可以把机器学习概括为实现人工智能的科学分支，核心是通过数据让计算机算法自动总结规律并不断提升性能。

## 2.1 机器学习概述

按收集的样本是否带有标注，机器学习通常分为有监督和无监督两类。有监督所需的样本集不仅包含特征，还必须附带每个样本的准确输出值，即标注。若样本没有标注，则只能用于无监督。例如仅收集股票的开盘价、收盘价、成交额、成交量、换手率，只能做无监督分析；而若再加上涨跌信息用于预测，则适用于有监督。

### 2.1.1 有监督机器学习

有监督的预测结果可以是连续值，也可以是离散值。据此可分为回归问题 regression 和分类问题 classification。回归的因变量为数量变量，分类的因变量为分类变量。

### 2.1.3 半监督机器学习

有监督学习的样本需要标注，且标注质量直接影响效果；无监督学习不需要标注，但只能用于了解样本结构，无法预测。现实中样本量过大时全部标注困难，常出现只有部分样本有标注仍需做回归或分类的情形，这时就需要半监督机器学习技术，图 2.4 所示为半监督机器学习示意图。

[PRE9]

图 2.4 半监督机器学习示意图

半监督机器学习是指学习器不依赖外界交互，自动利用未标注样本提升学习性能的一类算法。sklearn.semi_supervised 包中实现了基于标注传播 Label Propagation 原理的半监督算法。下面以简单示例说明标注传播的使用方法。

[PRE10]python

import numpy as np

from sklearn import datasets

from sklearn.semi_supervised import label_propagation

rng=np.random.RandomState(0)

[PRE11]

iris=datasets.load_iris()

X=iris.data[:, :2]

y=iris.target

y_30=np.copy(y)

y_30[rng.rand(len(y))<0.3]=-1    # 去掉已有的标注(随机数小于 0.3 的索引)

y_50=np.copy(y)

y_50[rng.rand(len(y))<0.5]=-1    # 去掉已有的标注(随机数小于 0.5 的索引)

ls30=label_propagation.LabelSpreading(kernel='knn', alpha=0.8)

ls30.fit(X, y_30)                # 训练模型

ls50=label_propagation.LabelSpreading(kernel='knn', alpha=0.8)

ls50.fit(X, y_50)                # 训练模型

predicted_labels_ls30=ls30.transduction_    # 输出预测的标注

predicted_labels_ls50=ls50.transduction_    # 输出预测的标注
