文档批量转换的思路有很多条，我第一反应是把已经手工调好的 ch04-to-manual.docx 拿给 Claude 参考，让它“倒着推”出转换逻辑来写 Python——后面你会看到，这条路坑不少。不过氛围编程本来就是边试边学的活儿，很多经验都是踩坑后才记住的。另有一点，我最终要套用编辑提供的 Word 交稿模板，所以希望 Claude 先把 ch04-to-template.docx 复制一份当作输出底稿，这样后续代码就能直接调用模板里已有的样式了。

思路捋清后，我打开 Claude 桌面客户端，配上当时编程能力最强的 Claude Sonnet 3.7 ^(¹) 模型，丢出了提示词：

我上传了 3 个文件，其中 ch04-from.md 和 ch04-to-manual.docx 内容一致但排版不同。我需要一个叫 converter 的 Python 程序来拆解两者格式差异 ^(²)。执行 “python3 converter ch04-from.md” 时，程序要读取 ch04-from.md 的内容，复制 ch04-to-template.docx ^(³) 并重命名为 ch04-to.docx，随后把 ch04-from.md 的内容按 ch04-to-manual.docx 的样式写入 ch04-to.docx。转换后用 Word 打开 ch04-to.docx，样式必须和 ch04-to-manual.docx 一模一样。由于 Markdown 里没传图片，转换结果可以不带图，但文字和样式要完全对应，不能增删。若遇到像“【避坑指南】”这类特殊样式不确定怎么处理，请说明并尽量保留。

Claude 很快吐出了代码。第一次跑就报错，我把报错贴回去让它修。修好再跑，又冒新错。几轮往复后代码终于能执行了，可打开生成的 docx 发现样式依然不对——章节标题、避坑指南和代码清单标题都套不到编辑模板的正确样式。我继续追着让它改。折腾十几轮后，代码清单标题还是怪，代码量却越修越胖，最后膨胀到 700 行，弄得我挺泄气。

几天后翻模板时才注意到，代码清单标题在 Word 样式列表里其实有明确的名字，直接选用就行。这让我回过头反思：之前用的提示“把 ch04-from.md 的内容按 ch04-to-manual.docx 的格式写入 ch04-to.docx”是不是太模糊了？我是不是太依赖 Claude 的读心能力，指望它像变魔术一样第一次对话就给出能跑且实现提示 80% 功能的代码——那种“一次成功”往往只是运气好。如果在提示里把 Markdown 语法和 Word 样式名的对应关系写清楚，大模型在氛围编程里完成文档格式迁移的命中率会高很多。

于是我干脆放弃那 700 行的代码，换到 Cursor 里，依然用 Claude Sonnet 3.7，大模型模式选 Agent，用更具体的指令重写：

#file:template-from.md #file:template.docx 是你要读的两份材料，内容相同但格式不同。请帮我开发一个名为 converter-v2 的 Python 程序，把 template-from.md 转成样式与 template.docx 完全一致的新文件 template-to-converted.docx。

运行 “python3 converter-v2 template-from.md” 时，程序应：

1）读取 #file:template-from.md 的内容；
2）把 #file:template.docx 复制并重命名为 template-to-converted.docx，然后对照后文给出的 Markdown 标签与 template.docx 样式对应关系，把内容写入 template-to-converted.docx。

转换完成后用 Word 打开 template-to-converted.docx，内容和样式要与 #file:template.docx 完全一致。Markdown 里的图片也要正确插入，要求 template-from.md 中的所有文字、插图、表格及其他内容都必须以与 template.docx 一致的样式转换，内容不得增减。

在做格式转换前先做一次插图文件名预处理，只做一件事：扫描 Markdown 文档，一旦遇到 “(attachment:xxx:图 x-xx.png)” 这种写法，就把 “attachment” 到 “图” 之间的内容删掉，变成 “(图 x-xx.png)”。例如把 “(attachment:ec94c27f-923d-4ae8-886e-930bd7c3f8e6:图 6-17.png)” 转换为 “(图 6-17.png)”。预处理完再执行下面的转换规则。

#file:template-from.md 中的 Markdown 标签与 #file:template.docx 中的 Word 样式对应关系如下：

“#”对应“Heading 1”。

一般正文对应“Normal”。

“##”对应“Heading 2”。

“###”对应“Heading 3”。
