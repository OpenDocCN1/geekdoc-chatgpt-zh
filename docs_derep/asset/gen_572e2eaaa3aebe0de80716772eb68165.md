### 常见困境

1. 公司绩效靠前的员工反复抱怨涨薪幅度和业绩贡献不匹配，财务却指出人力成本已超预算，该如何平衡激励与成本？
2. 可以通过薪酬与绩效关联分析来量化两者匹配度。例如某电商企业梳理后发现，销售岗位前20%的高绩效员工贡献了60%业绩，但薪酬差距仅25%，随后把高绩效员工薪酬上限提升至40%，次年业绩增长35%。
3. 不同岗位考核口径差异明显，销售看业绩、技术看交付、职能看流程优化，如何做到统一关联？
4. 销售岗可用“业绩达成率”与薪酬涨幅线性挂钩，技术岗采用“项目里程碑+质量评分”双维度挂钩，职能岗则通过“流程优化效率提升率”进行换算。
5. 若公司战略从规模扩张转向利润增长，现有薪酬绩效体系如何快速响应？
6. 建立动态关联机制。例如把薪酬绩效权重从“70%业绩+30%能力”调整为“50%利润+30%效率+20%创新”，或增加战略贡献加分，例如某部门降本增效直接增利500万元，可额外获得薪酬池5%的分配权。

### AI提问框架
通用提问公式 = 业务背景 + 关联痛点 + 分析需求

#### 业务背景
交代公司业务的基本情况。

#### 提问要素
- 岗位分布：如销售岗占40%，技术岗30%，职能岗30%。
- 薪酬结构：如固定薪酬占60%，绩效奖金占30%，长期激励占10%。
- 绩效规则：如考核周期、指标权重、评分等级。

#### 关联痛点
厘清薪酬与绩效之间的具体矛盾。

#### 提问要素
- 匹配问题：如前10%高绩效员工涨薪不足5%，后30%员工涨幅超8%。
- 激励问题：如技术岗核心人才流失率25%，薪酬竞争力却低于行业均值15%。
- 战略问题：如公司要求提升利润率，现有薪酬绩效体系仍以规模增长为导向。

#### 分析需求
明确AI需要交付的成果，把问题转化为可落地任务。

#### 提问要素
- 分析类型：如薪酬-绩效回归分析、薪酬带宽设计。
- 数据要求：如需对比近3年绩效与薪酬变化。
- 决策支持：如推荐3种薪酬绩效优化方案，并测算对核心人才保留率的影响。

### 实战案例
#### 业务背景

#### 关联痛点
#### 当前存在如下痛点
- 1. 匹配失衡：销售岗前10%高绩效员工涨幅不足5%，后30%员工涨幅超8%；技术岗核心人才薪酬竞争力低于行业均值15%。

- 3. 战略脱节：公司要求未来一年利润率提升10%，现有薪酬绩效体系仍以规模为导向。

- 1. 建立各岗位薪酬-绩效回归模型，量化绩效贡献与薪酬回报的匹配度，筛出高绩效低薪酬与低绩效高薪酬人群。
- 2. 设计3种薪酬绩效优化方案，并测算对核心人才保留率和利润率的影响。
- 3. 提供薪酬绩效沟通方案，如如何向员工解释薪酬调整规则、如何回应高绩效员工的加薪诉求。

## 6.7 用AI做员工流动与薪酬关联分析

问题情景
1. 公司过去一年技术岗离职率高达25%，财务却称薪酬成本已比行业平均高出15%，为何仍留不住人？
2. 可做员工流动与薪酬关联分析。例如整体薪酬高于市场，但核心岗位薪酬带宽仅50%，市场同类为80%，导致高潜力员工因晋升空间不足而流失。
3. 不同层级对薪酬敏感度不同，应届生看重起薪，资深员工看重长期激励，如何分层分析？
4. 可将应届生离职率与“起薪低于行业分位50%”关联分析；资深员工离职率则与“薪酬涨幅低于CPI+行业涨幅”关联分析。
5. 领导要求两周内提交方案，手工分析上千条数据来不及怎么办？
6. 可用AI辅助，优先锁定三组关键数据：过去一年离职员工薪酬分布、在职同岗位满意度调研结果、行业对标薪酬结构差异，通过交叉分析快速定位规律。

### AI提问框架
通用提问公式 = 情境定位 + 矛盾聚焦 + 分析目标

#### 情境定位
描述企业当前人力资源管理背景。

#### 提问要素
- 企业类型：如互联网初创、制造业区域分公司。
- 岗位范围：如研发部门全员、华北区销售团队。
- 时间跨度：如过去12个月、近3次调薪周期。
- 现有数据基础：如已收集的离职面谈记录、行业薪酬报告。

#### 矛盾聚焦
明确员工流动与薪酬的具体矛盾点。

#### 提问要素
- 流动表现：如离职率8%、技术岗主动流失率同比增50%。
- 薪酬差异：如市场同岗薪酬中位数高15%、内部职级薪酬带宽重叠。
- 关联线索：如高绩效员工离职前未获晋升、新老员工薪酬倒挂。

#### 分析目标
明确希望AI实现的具体任务。

#### 提问要素
- 关联方向：如验证离职率与薪酬竞争力的相关性，识别薪酬倒挂岗位。
- 数据需求：如需对比离职员工薪酬历史与市场数据，需关联绩效评级与调薪记录。
- 输出形式：如生成薪酬调整敏感度模拟，推荐保留高风险员工的差异化方案。

### 准备资料

| 要点 | 内容 |
| :--- | :--- |
| 员工流动数据 | 离职记录、离职面谈摘要、新员工试用期淘汰率等。 |
| 薪酬历史数据 | 职级体系表、历次调薪记录、绩效奖金分布等。 |
| 市场对标信息 | 行业薪酬报告、竞争对手招聘薪酬数据等。 |

### 实战案例
#### 情境定位
我司为成立5年的SaaS软件企业，员工400人，研发岗占60%。过去一年技术团队离职率18%，高于行业平均12%。公司计划明年上市需稳定核心团队，但担心盲目加薪推高成本。

#### 矛盾聚焦
#### 当前面临三大矛盾
- 1. 薪酬竞争力不足：技术岗薪酬中位数低于市场15%，但部分非核心岗位如测试薪酬溢价20%。
- 2. 流动集中化：离职员工中高绩效评级A/B占70%，司龄2~3年员工流失率是1年内新员工的3倍。
- 3. 调整盲区：过去两次普调后离职率短暂下降但3个月后反弹，可能未解决结构性问题。

#### 分析目标
#### 请你协助我
- 1. 关联性验证：分析离职率与薪酬水平、司龄、绩效的关联强度，识别关键驱动因素。

- 3. 保留策略模拟：测算为高绩效员工评级A增加10%留任奖金，对离职率的抑制效果及成本影响。
- 4. 风险预警模型：构建预测模型，输入绩效、调薪历史、市场薪酬差距，输出未来6个月离职风险等级。

## 6.8 用AI做人均劳动效率分析

问题情景
1. 今年人力成本涨15%，营业收入只涨8%，领导要求人效翻倍，但不知如何计算？
2. 人效即人均劳动效率，公式为某时期创造价值÷创造价值的人数。价值可按销售额、毛利润、利润或产值衡量。
3. 不同岗位算法差异大，销售可用业绩衡量，职能难以量化，如何统一分析？
4. 职能岗可用人均工时贡献率量化，例如某公司财务岗人均日处理单据从80单提升至120单，效率提高50%。
5. 若战略从规模扩张转向利润优先，如何依据人效数据调整岗位结构？
6. 高人效高利润岗如研发可增加投入；低人效低利润岗如重复性客服可减编；高人效低利润岗如促销员可优化激励，从而降本提效。

### AI提问框架
通用提问公式 = 业务背景 + 效率痛点 + 分析需求

#### 业务背景
具体描述公司业务背景。

#### 提问要素
- 岗位分布：如生产岗40%、销售岗30%、职能岗30%。
- 效率指标：如人均创收、人均工时产出、人均处理订单量。
- 现有水平：如人均创收低于行业标杆20%。

#### 效率痛点
明确人效低下的具体表现。

#### 提问要素
- 效率问题：如研发岗人均产出仅为行业标杆60%。
- 差异问题：如销售岗人均创收是职能岗5倍，但人力成本占比相同。
- 战略问题：如公司要求利润优先，现有岗位结构仍侧重规模扩张。

#### 分析需求
明确AI需输出成果。

#### 提问要素
- 分析类型：如效率归因分析、岗位价值评估、战略匹配模型。
- 数据要求：如需引用行业标杆、对比近3年效率变化。
- 决策支持：如推荐3种岗位优化方案，并测算对效率和成本的影响。

| **岗位数据** | 各岗位人数、工时记录、产出数据如销售额、订单量、项目数等。 |
| **效率指标** | 人均创收、人均工时产出、人均处理订单量、人均成本等。 |

- 2. 岗位失衡：销售岗人均创收仅为仓储岗1.2倍，但人力成本占比相同。

- 1. 建立岗位-效率双维度模型，量化各岗位与行业标杆差距，筛选高人效高利润岗和低人效低利润岗。

## 6.9 用AI做人力成本效益分析

问题情景
1. 人力成本比率从28%升至35%，人均营业收入却下降10%，如何证明薪酬投入价值？
2. 需从人力成本效益角度切入，将薪酬支出与绩效、部门收入、项目利润关联，找出投入产出低的岗位和团队，以及高价值板块。
3. 薪酬数据分散在多系统，手工整合耗时，维度单一，难说服管理层。
4. 可用AI结构化分析。例如技术岗高薪酬是否匹配研发成功率？销售提成是否与客户续约率正相关？多维度交叉分析可显性化成本效益。
5. 有些部门负责人抵触调整，担心降薪影响稳定。
6. 用数据说话更有效。例如某部门人力成本两年增20%，人均贡献利润仅增5%，结合行业标杆即可说明优化必要性，同时保留核心人才差异化薪酬可减少阻力。

提炼可量化矛盾点。

- 管理层核心诉求：如未来半年将人力成本占比控制在30%以内。
- 潜在风险：如关键岗位离职率上升至20%。

明确AI输出类型和建议。

#### 提问要素
- 分析模型：如成本效益矩阵、薪酬投资回报率对比。
- 数据需求：如历史薪酬数据、绩效结果、行业对标报告。
- 输出形式：如优先级排序、优化方案投资回报率测算。

#### 业务背景

#### 核心矛盾
#### 当前存在如下矛盾
1. 成本压力：技术团队人力成本占45%，但主导的3个核心项目均未达预期收益。
2. 分配争议：高管要求优化技术成本，部门负责人以人才保留为由反对。
