#### 2.12.2 核心知识：红外通信原理

红外遥控的本质是利用红外发光二极管发射不可见光来传递指令。自然界中太阳光、烛火、荧光灯甚至人体都在释放红外线，为了防止这些背景噪音干扰，遥控器采用 **38kHz** 的特定频率发射脉冲红外光。配套的接收头只会“认准”这特定频率的信号。此外，通过在信号中植入地址码与命令码，使得不同遥控器、不同按键发出的光信号都拥有专属功能标识。

#### 2.13.2 核心知识：红外遥控技术特性

红外遥控利用近红外光（波长 780~2526nm）进行无线非接触控制，具备显著优势：
*   **抗干扰强、传输可靠**：特定调制频率有效滤除环境光噪声。
*   **低功耗、低成本、易实现**：器件廉价，电路简单。
*   **不干扰射频设备**：红外波长远短于无线电波，互不影响。
*   **编码隔离**：地址码/命令码机制保证同频同制式遥控器互不串扰。
*   **适应恶劣环境**：在高压、辐射、粉尘、有毒气体等场景下，光信号传输稳定且能有效隔离电气干扰。

#### 2.13.3 编程进阶：多分支与封装

**1. `switch-case` 多分支选择结构**
面对多个按键码值判断，`if-else` 会显得冗长。`switch` 结构更清晰高效：
```cpp
switch (value) {
  case 0xFF6897: 语句0; break;  // 对应键 0
  case 0xFF30CF: 语句1; break;  // 对应键 1
  // ... 更多 case
  default: 语句n;              // 无匹配时执行
}
```
**执行逻辑：** 将变量 `value` 与各 `case` 常量逐一比对。匹配成功则执行该分支代码，遇到 `break` 跳出整个结构；全不匹配则执行 `default` 分支。
[PRE11]

**2. 自定义函数 `contro()` 封装灯光状态**
避免重复写 `digitalWrite`，定义一个控制函数：
*   **定义：** `void contro(int pin1, int pin2, int pin3, int pin4, int pin5, int pin6)`
    对应控制 D3~D8 六个引脚的电平。
*   **调用：** `contro(1, 0, 0, 0, 0, 0)`
    含义：仅将 D3 (pin1) 设为高电平点亮，其余 D4~D8 全部设为低电平熄灭。通过组合 0/1 参数，一行代码即可实现任意灯光组合。
