# 第5章 绘画技巧速成

本章聚焦文生图与图生图两大创作路径，手把手教你用文字把想法变成画面，也能用已有图像做风格延展和创意重塑。还会深入拆解提示词的构建方法、细节把控技巧以及画质提升思路，目标是做到出图快、准、好。没有绘画基础也没关系，可灵 AI 能帮你画得像、画得妙、画得快。

## 5.1 文生图

文生图就是把文字变成图像，是 AI 绘画的基础环节。我们把描述性的关键词或完整文本输入到可灵 AI，再配合相关指令和参数，就能得到精美的绘画结果。

在文生图中，提示词既是描述也是指令。模型会依据提示词判断色彩、构图、风格和细节等要素。描述越清晰具体，生成的图像就越贴合预期。因此，学会科学搭建和优化提示词是掌握文生图的关键。可灵 AI 的图片生成页顶部提供了 DeepSeek 选项，因为它内置了 DeepSeek 深度思考大模型，可在创作时借助它拓展思维、深化创意，从而得到更精准的提示词。

### 5.1.1 文生图的使用场景

文生图是通过一段描述性文字，让模型理解后生成静态图像。常见用法包括：

- 人物角色创作：刻画外貌、服饰、动作以及背景环境；
- 场景绘制：如古风庭院、奇幻世界、科幻都市等；
- 产品设计可视化：用关键词快速得到产品概念图；
- 插画与海报：迅速产出概念草稿，方便后续精修或灵感迭代。

可灵 AI 在这一块可操作性很强，能把不同维度的文字提示进行理解与组合，输出符合预期的画面。

### 5.1.2 提示词的构成要点

要让可灵 AI 准确呈现画面，提示词需要覆盖表 5-1 中的要素。不同项目和工具的写法可能略有差异，但核心思路相通。

表 5-1 提示词构成要素

| 要素 | 说明 |

| :--- | :--- |

| 主体 | 用来锁定画面核心对象或人物。可描述物种、性别、姿态、数量等，例如：一只狗、一位穿汉服的少女、一辆极具未来感的飞行器，让模型明确主角是什么 |

| 场景/背景 | 交代对象所处的环境与氛围，如古代宫殿、赛博朋克城市、乡村田园、海边日落等，帮助模型搭建空间感和故事性 |

| 外观特征 | 对主体细节做补充，比如发色、眼色、表情、服装款式、饰品、动作等，描述越细致画面就越贴近想象，也能减少随机偏差 |

| 风格/艺术形式 | 决定整体画风，可指定写实、卡通、油画、蒸汽波、复古插画、赛博朋克等，或参考艺术家风格如凡·高、莫奈，让笔触和色彩更统一 |

| 光照与色调 | 描述想要的光线氛围，例如逆光、柔和暖调、烛光昏暗、日落金色、霓虹映衬等，光线搭配特定色调能显著提升情绪感 |

| 质量和细节要求 | 说明分辨率或精致度需求，如高清、细节丰富、面部清晰、线条细腻等，引导模型关注局部与精细表现 |

| 排除项 | 列出不希望出现的元素或状况，如噪点、过多路人、特定颜色、意外物件等，帮助模型避开影响成图效果的干扰 |

### 5.1.3 提示词示例

下面提供几个例子帮助直观理解写法。

#### 1. 日常场景

示例提示词如下：

> 一只金色短毛猫，坐在窗台上，看着窗外的雨景；画面整体清新明亮，带有小清新的插画风格；背景使用柔和的浅绿色和浅蓝色调，表现雨后的清凉氛围。

解读：

主体：金色短毛猫；

场景：窗台 + 下雨；

风格与色调：小清新、插画风、浅绿色和浅蓝色调。

这样模型能清楚关联“猫”和“雨天场景”，整体色调柔和。

#### 2. 未来科技风

示例提示词如下：

> 一位身穿银灰色金属机甲战衣的女性，身后的背景是巨大未来城市天际线，霓虹闪烁；画风赛博朋克；强烈的对比光，人物面部轮廓清晰；明亮的紫色和蓝色光线交错；高分辨率，细节刻画。

解读：

主体：女性 + 机甲战衣；

场景：未来城市、霓虹灯；

风格：赛博朋克；

光线颜色：紫色和蓝色。

特别强调“高分辨率”和“细节刻画”，追求画质。

#### 3. 童话插画

示例提示词如下：

> 一个身穿粉色纱裙的小女孩，正乘坐热气球飞过奇幻森林；背景中有巨大的蘑菇、漂浮的萤火虫；插画风格温暖，灯光柔和；给人童话般的奇幻与浪漫。

解读：

主体：小女孩 + 粉色纱裙；

场景：热气球 + 奇幻森林；

风格：童话插画；

氛围：温暖、柔和、浪漫。

提示词是作品的灵魂，也是与 AI 的沟通桥梁。只有设计层次分明、逻辑清晰的文字描述，才能让模型更好理解意图，产出高质量且富有创意的图像。

## 5.2 图生图

图生图不是从零创作，而是基于提供的参考图像进行再创作、扩展或变形，快速得到新图。无论是升级手绘草稿，还是把实拍照片转成特定风格插画，都能在短时间内获得惊喜效果。

### 5.2.1 图生图的应用场景

图生图能解决手绘、后期、摄影修图中耗时的问题，也便于创意迭代和视觉拓展。常见场景有：

- 风格转换：将原图转为不同艺术风格或笔触，例如把街景照片处理成油画，或给人像加上赛博朋克霓虹光影；
- 创意扩展：为已有卡通形象补充背景元素、加入新故事线，或向外扩展画面边界，让视野更宽、细节更足；
- 局部修饰与细节强化：在原图指定区域做调整，如修改角色表情、更换服饰、修复损坏或低清部分，同时保留整体结构并加入新元素；
- 色调与氛围改造：给照片或插画更换季节或情绪，例如把夏日绿地变成枫叶飘落的秋景，或让暗调画面变得明亮温暖，操作比手动调色更便捷；
- 草图快速成稿：提供简单线稿，模型即可自动填充细节、渲染风格，从粗概念一步到位生成完整图。

### 5.2.2 如何编写图生图的提示词

图生图区别于文生图之处在于需要同时提供参考图片。在可灵 AI 中，先上传基础图像，再配一段描述改动或重塑风格的提示词，模型会结合图文信息进行推理。

编写时可以参考以下思路：

1. 明确你想“保留”什么

是否希望构图与人物布局不变？原图中必须保留的元素有哪些，比如人脸特征、建筑基本形。可以在提示词里写明“保持角色姿态不变”“保留原有表情与动态”，让模型知道核心部分。

2. 强调你想“改变”或“增强”什么

若要调整色彩、风格、氛围，就要给出具体描述，例如：“把此古装人物变成现代街头装扮，画面偏二次元漫画风格”“将背景

3. 考虑局部替换或修饰

只想修改局部时，需在提示词里指明位置或范围，例如：“人物头部加一顶粉色帽子”“背后添加翅膀”“替换背景为太空星云”等。
