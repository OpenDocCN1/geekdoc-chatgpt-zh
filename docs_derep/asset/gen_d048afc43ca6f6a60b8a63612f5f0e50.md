下表汇总了常用测试方法，条件不满足时均返回 `False`：

| 方法名 | 判断逻辑 |
| :--- | :--- |
| `isalnum()` | 仅含数字与字母 |
| `isalpha()` | 仅含字母 |
| `isdecimal()` | 仅含十进制数字字符（无正负号） |
| `isdigit()` | 仅含数字 |
| `isidentifier()` | 符合标识符命名规范 |
| `islower()` | 所有字母均为小写 |
| `isnumeric()` | 字符均为数值型（无正负号、小数点） |
| `isspace()` | 仅含空白字符 |
| `istitle()` | 每单词首字母大写且其余小写 |
| `isupper()` | 所有字母均为大写 |

## 8.12 正则表达式：文本模式匹配的瑞士军刀

识别电话、邮箱、URL 等文本模式，正则表达式是核心工具。它不仅能从非结构化文本（如社交帖子）中提取数据，还是数据清洗、格式校验的基石。

### 数据校验场景

处理文本前，常用正则做格式“安检”：
- **邮政编码**：5 位数字或 `5位-4位` 格式。
- **姓名**：仅允许字母、空格、撇号、连字符。
- **邮箱/社保号**：需符合严格字符序列与规则。

无需重复造轮子，以下网站提供现成正则库及测试工具：
- https://regex101.com
- http://www.regexlib.com
- https://www.regular-expressions.info

### 更多实战用途

- **数据抓取**：从网页提取所有 URL（亦可用 BeautifulSoup 等专用库）。
- **数据清洗**：去重、补全、纠错、统一格式、处理异常值。
- **格式转换**：如将制表符/空格分隔数据重组为 CSV 标准逗号分隔格式。
