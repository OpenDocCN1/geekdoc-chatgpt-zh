**学习方式的城市旅行类比**
- 有监督学习：如同手握详解地图巡访熟悉的街区，任务非常明确——把地图上标出的每个点位逐一走完，完整复制既定游览轨迹。
- 强化学习：如同闯入从未到访的巨型都市，重点不是照本宣科，而是学会在城里自主行动，摸索出通往餐饮、住宿、娱乐等需求的最优路线。

强化学习奠基人 Richard Sutton 于《苦涩的教训》一文指出，过去七十年人工智能领域最核心的经验是：只有通用且能够随算力规模化的方法才具备决定性优势。结合 OpenAI 的实践，强化学习在大语言模型上的价值可归纳为三个层面。

（1）挣脱局部陷阱的全局寻优能力。监督训练依赖词元级精确标注，本质上把人类先验固化为离散标签，容易让模型困于局部最优，例如交叉熵对语义跃迁反应迟缓。强化学习以整体奖励信号置换人为拆解的局部规则，让模型自行探索语义组合空间。这种大范围反馈配合自主调整，既保留了自然语言的多样表达，也能捕捉关键否定词带来的极性反转，印证了苦涩教训里减少人为规则、让算法自行寻找最优路径的主张。

（2）超越认知边界的知识演进机制。监督学习在求知类问答中易出现幻觉，根源在于存在知识天花板，模型无法突破标注数据覆盖的认知范围。强化学习通过动态奖励函数搭建知识可信度评估体系，对正确回答给予指数级激励，对错误回答施加惩罚梯度，从而促使模型自主形成知之为知之的认知边界意识。这种无需倚赖静态知识库的持续演化，与 AlphaGo 靠自我对弈突破人类棋谱局限的路径相似，体现了苦涩教训所倡导的靠计算规模扩展而非知识注入来提升能力的思路。

（3）面向复杂系统的长期价值建模范式。在多轮对话里，监督学习的即时反馈难以捕捉跨轮次语义关联与远期目标。强化学习借助价值网络对状态行为的长期收益进行建模，把对话连贯性、信息增量等抽象诉求转化为可优化的数学指标。基于延迟奖励的序列决策框架，使模型能够在即时响应质量与对话终局目标之间自主权衡，正如 AlphaStar 在星际争霸中用数千步决策实现战略布局，验证了放弃短期人为启发、专注构建通用长期优化架构的前瞻性。

## 6.2 策略梯度方法

在强化学习里，智能体通过不断与环境交互试错来习得最优策略，核心是最大化长期累计回报，找到最佳决策路径。传统思路如 Q-Learning 属于间接优化，先借助价值评估行动价值再做选择。面对高维或连续行为空间，例如机器人控制、游戏角色的复杂操作，这类方法常会遇到计算瓶颈或收敛困难。

策略梯度提供了一种更直接的路径：不再先估值再决策，而是把策略本身参数化，例如用神经网络表示，直接对策略参数做梯度上升，让智能体更倾向挑选高回报行为。通俗说，策略梯度通过反复尝试统计在特定状态下哪些行为更容易带来奖励，类似调节旋钮逐步提高这些行为被选中的概率。

该思路天然适配连续行为、随机策略以及部分可观察环境，但也伴随梯度估计方差大、训练不稳定的问题。本节先梳理策略梯度的基本概念，再回顾 REINFORCE、PPO 等经典算法，并简述大模型时代流行的 GRPO、RLOO 等变体。

#### 4. 算法特性分析

基于蒙特卡洛采样的 REINFORCE 存在明显局限：

- （1）蒙特卡洛特性导致梯度估计方差偏高，不仅拖慢收敛，还易引起策略更新方向剧烈波动，训练不稳定。
- （2）必须等待整条轨迹结束才能更新，在长周期或持续环境中学习效率大幅下降。
- （3）在线学习要求每次更新后重新采样，样本利用率低，不易适应大规模复杂任务。尽管随机性带来探索优势，高方差会削弱其效果。该方法主要适用于小规模离散行为场景，对函数近似误差敏感，限制了在连续行为或深度强化学习框架中的应用。

### 6.2.3 广义优势估计
