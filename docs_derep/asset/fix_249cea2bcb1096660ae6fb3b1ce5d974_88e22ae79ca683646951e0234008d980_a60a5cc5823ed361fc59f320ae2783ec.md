# ChatGPT 实战应用大全

## 内容提要
在众多生成式智能产品里，ChatGPT凭借信息整合、知识串联、编程辅助与语言理解等综合能力受到广泛关注，已被多行行业用于提升产出。今天的关键问题是，如何把它的潜能真正释放出来。

《ChatGPT 实操应用大全（全视频·彩色版）》是一部覆盖全场景的实践手册，系统收录了一百五十种具体操作方法与技巧，引导读者深度挖掘功能上限，点燃创意灵感。阅读后，常见的实际问题能得到快速解决，工作学习节奏也会明显加快。短视频创意、数据分析、日常办公、论文撰写、理财决策、跨语言翻译、程序编写等需求，书中均提供可直接借鉴的思路。想要充分利用这款模型，本书是很好的参考。全书涉及账号开设与登录、基础功能入门、提示词策略、一百五十个使用情境、参数设定与 API 编程以及插件体系，叙述通俗、实例丰富，阅读体验扎实。

内容既适合高校师生查阅，也便于职场人群提升能力，还能作为培训机构开展智能教学的参考资料。

## 前言

PREFACE

回顾历史，驱动文明跃迁的都是技术突破——蒸汽机开启工业纪元，计算机与互联网定义信息纪元。这类突破不仅改变了日常，也重塑了人类认知世界的方式。如今生成式智能正加速发展，ChatGPT 作为典型代表，已开始对社会产生深远影响。

ChatGPT 究竟是什么？ChatGPT，即 Chat Generative Pre-trained Transformer，是 OpenAI 研究实验室推出的领先对话式智能程序，于 2022 年 11 月正式对外发布。推出仅两个月，月活跃用户便突破 1 亿，成为有史以来增速最快的消费级应用。与之相比，电话用了 75 年、手机 16 年、互联网 7 年，Instagram 需两年半、TikTok 需 9 个月。其底层采用基于自注意力机制的 Transformer 结构，经海量网络数据训练与参数调优后，具备出色的语言理解与生成能力，能够自然对话，完成文学创作、数据分析、多语种翻译、代码编写、论文撰写等多种任务。正因如此，撰写一本使用指南很有必要，帮助更多读者高效利用这一工具。

本书基于上述目标编写，旨在帮助读者全面理解并熟练运用 ChatGPT，部分方法同样适用于同类产品，如百度的文心一言、阿里的通义千问。全书共五章。

第 1 章 准备工作，主要介绍账号注册、登录与基础功能，帮助读者迅速上手。

第 2 章 提示词，聚焦驱动输出的核心技术。讲解提示词的设计原则、撰写步骤、技巧要点，并分享常用范例，最后介绍提示词优化器这一实用工具。

第 3 章 ChatGPT 的 150 种用法，围绕真实场景展开并配以示例，覆盖文学创作、高级数据分析、办公、翻译、学术论文、教学、文本生图、金融投资、法律咨询、医疗问诊、心理情感、生活品质、IT 编程、多媒体艺术、音乐娱乐、游戏、评论鉴赏、趣味知识及看图识图等诸多领域，启发读者在不同情境中挖掘价值。

第 4 章 参数指令与 API 开发，探讨如何通过参数与指令优化输出，包括打造超级指令和定制机器人，并介绍 ChatGPT API 的二次开发路径。

第 5 章 ChatGPT 插件，介绍几款核心插件。借助 Browse with Bing 可实现实时联网检索，WebPilot 能对网页进行摘要与翻译，Wolfram 支持数学运算与图表绘制，VoiceOver 可将文本转为语音。此外，HeyGen、Visla 支持短视频生成，Speak 助力语言学习，Consensus 则被视为论文写作的优秀助手。掌握插件能大幅提升使用效率。

本书以通俗语言搭配丰富案例，展示如何让 ChatGPT 服务生活、工作与学习。无论是新手，还是希望将智能融入创作与工作的实践者，都能从中受益。本书既是教程，也是一次探索智能潜力的旅程，读者将看到智能如何影响生活、改变工作方式、甚至重塑思维。愿本书带来新的视角与无限可能。

创作过程中，感谢蔡文青老师的大力支持与资助，感谢出版社编辑团队的专业把关与建议。也要对 OpenAI 的工程师致敬，正是他们的持续创新推动了智能的快速发展。

由于时间仓促与个人水平限制，书中难免存在疏漏，欢迎读者批评指正。

# 第1章 准备工作

ChatGPT 由 OpenAI 打造，凭借出色的文本理解与生成能力获得业界认可，其价值已延伸至科研、教育、商业等多个领域。要发挥全部潜力，掌握基本操作是前提。

本章以最新版本为基准，详细说明注册、登录及核心功能的使用方法，为初学者提供入门路径，帮助用户将强大功能落地到实际工作与学习场景中，提升效率。

## 1.1 ChatGPT 注册

### 1. 访问 ChatGPT 官方网站

访问官网首页后会出现欢迎界面，图 1.1 所示，界面上有 Log in 和 Sign up 两个按钮。点击 Sign up 即可进入注册步骤。

[PRE29]

图 1.1 ChatGPT 欢迎页面

### 2. 进入注册页面并填写电子邮箱

注册页如图 1.2 所示，需在 Email address 栏输入邮箱地址，例如 gmail 账号。填写完毕后点按 Continue 进入下一阶段。若已有微软或谷歌账号，也可直接使用对应账号登录。

[PRE30]

图 1.2 注册页面

### 3. 填写密码

在 Password 栏输入密码，如图 1.3 所示，密码长度需不少于 8 个字符。确认后点按 Continue 继续。

[PRE31]

图 1.3 注册页面填写密码

### 4. 邮箱验证账号

提交信息后，OpenAI 会向注册邮箱发送验证邮件，如图 1.4 所示。点按邮件中的 Verify email address 按钮跳转至验证确认页，完成注册。

[PRE32]

图 1.4 验证邮件

### 5. 验证地区是否可用

输入邮箱与密码后，系统会校验浏览器所在地区，如图 1.5 所示。验证通过后进入个人信息填写页。

[PRE33]

图 1.5 验证地区是否可用

### 6. 填写个人信息

在个人信息页填写姓名与生日，如图 1.6 所示。完成后点按 Continue 进入下一阶段。

[PRE34]

图 1.6 填写个人信息

### 7. 填写手机号码

如图 1.7 所示，需提供可接收验证码的国际手机号，号码所属国家需与网络 IP 地址一致。例如 IP 位于美国，则应提供美国号码。无国际号码者可通过第三方接码平台获取临时号码。输入号码后点按 Send code 发送验证码。

[PRE35]

### 8. 填写验证码

在验证码页面输入收到的验证码并通过验证后，系统自动跳转至成功页。
