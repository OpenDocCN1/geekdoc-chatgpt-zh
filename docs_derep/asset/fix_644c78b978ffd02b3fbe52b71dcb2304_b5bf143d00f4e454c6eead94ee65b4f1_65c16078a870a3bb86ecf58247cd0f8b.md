## 使用提示

- 电脑装有 WPS 时可用 `--app wps` 指定，否则会回退到 Word。
- 需要看见操作窗口就加上 `--visible true`。
- 方案面向单份文件处理，不适合大规模批量作业。

运行条件章节说明了依赖环境：只能在 Windows 下执行，且需要事先部署好 Microsoft Word 或 WPS Writer；另外要准备 Python 运行环境并安装 pywin32 库，才能让底层 COM 自动化正常工作。

为了降低入门门槛，材料给出了三类高频示例：提取正文、执行查找替换、把文件转成 PDF。演示了脚本的调用思路，新手也能马上体会主要能力。

核心能力章节盘点了十个常用指令，涵盖读取正文、文字替换、内容插入、标题样式设置、页眉与页脚管理、分页符插入、文档合并、按页拆分、格式导出与图片添加。每条指令都附带说明和完整调用样例，基本满足日常办公自动化需求。

补充说明里提到：借助 `--app` 可在 Word 与 WPS 间切换；`--visible` 能打开操作窗口方便调试；并建议在批量场景下减少可视化操作，以保证运行效率与稳定性。

def parse_ranges(s: str):

    ranges = []

    for part in s.split(","):

        a, b = part.split("-")

        ranges.append((int(a), int(b)))

    return ranges

def cmd_split(args):

    app = get_app(args.app, args.visible)

    doc = open_doc(app, args.input)

    outdir = Path(args.outdir)

    outdir.mkdir(parents=True, exist_ok=True)

    ranges = parse_ranges(args.pages)

    for i, (a, b) in enumerate(ranges, 1):

        new = app.Documents.Add()

        rng = doc.Range(doc.GoTo(What=1, Which=1, Count=a), doc.GoTo(What=1, Which=1, Count=b + 1))

        rng.Copy()

        new.Range(0, 0).Paste()

        out = outdir / f"part_{i}.docx"

        save_as(new, str(out))

        new.Close()

    doc.Close()

    app.Quit()

def cmd_export(args):

    app = get_app(args.app, args.visible)

    doc = open_doc(app, args.input)

    fmt = WD_FORMAT_PDF if args.format == "pdf" else WD_FORMAT_TEXT

    save_as(doc, args.output, fmt)

    doc.Close()

    app.Quit()

def cmd_image(args):

    app = get_app(args.app, args.visible)

    doc = open_doc(app, args.input)

    rng = doc.Range(doc.Content.End - 1, doc.Content.End - 1)

    doc.InlineShapes.AddPicture(os.path.abspath(args.image), False, True, rng)

    save_as(doc, args.save)

    doc.Close()

    app.Quit()
