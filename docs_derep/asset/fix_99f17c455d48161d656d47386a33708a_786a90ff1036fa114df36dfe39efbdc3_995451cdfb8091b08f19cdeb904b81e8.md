##### 4. 网络结构硬性约束

| 维度 | 要求 |
| :--- | :--- |
| **输入图像** | 方形 RGB，边长为 **8 的整数倍**；<br>注：Bonnet 会自动等比缩放，实测可喂入更大图像，且边长无需为 8 倍数 |
| **首层算子** | 强制为 `tf.nn.conv2d` |
| **数据布局** | 训练与推理均遵循 **NHWC** 顺序 |
| **拓扑结构** | **无环** 有向图 |
| **Batch Size** | 推理阶段固定为 **1** |

##### 5. 兼容 TF 算子与参数约束清单

仅下列算子经转换工具处理后可在 Bonnet 高效跑，部分算子对入参/配置有额外限制：

*   **tf.nn.conv2d** [PRE6]
    *   输入通道数须为 8 整数倍（首层豁免） [PRE7]
    *   卷积核：`[k, k, in_ch, out_ch]`，`k ∈ {1,2,3,4,5}` [PRE8]
    *   步长：`[1, s, s, 1]`，`s ∈ {1, 2}` [PRE9]
    *   Padding：`VALID` 或 `SAME` [PRE10]
    *   Data Format：`NHWC`

*   **tf.nn.depthwise_conv2d** [PRE11]
    *   卷积核：`[k, k, in_ch, ch_mul]`，`k ∈ {3,5}`，`ch_mul = 1` [PRE12]
    *   步长：`[1, s, s, 1]`，`s ∈ {1, 2}` [PRE13]
    *   Padding：`VALID` 或 `SAME` [PRE14]
    *   Data Format：`NHWC`

*   **tf.nn.max_pool** [PRE15]
    *   输入通道数须为 8 整数倍 [PRE16]
    *   池化窗口：`[1, k, k, 1]`，`k ∈ {2,3,4,5,6,7}` [PRE17]
    *   步长：`[1, s, s, 1]`，`s ≤ k` [PRE18]
    *   Padding：`VALID` 或 `SAME` [PRE19]
    *   Data Format：`NHWC`

*   **tf.nn.avg_pool** [PRE20]
    *   池化窗口：`[1, k, k, 1]`，`k ∈ {2,3,4,5,6,7}` [PRE21]
    *   步长：`[1, s, s, 1]`，`s ≤ k` [PRE22]
    *   Padding：`VALID` 或 `SAME` [PRE23]
    *   Data Format：`NHWC`

*   **tf.matmul** [PRE24]
    *   设矩阵 `a` 为 M×K，`b` 为 K×N，**K 需为 8 整数倍** [PRE25]
    *   `a`：秩 1 或 2 张量 [PRE26]
    *   `b`：秩 1 或 2 张量 [PRE27]
    *   `transpose_a: False` [PRE28]
    *   `transpose_b: False` [PRE29]
    *   `adjoint_a: False` [PRE30]
    *   `adjoint_b: False` [PRE31]
    *   `a_is_sparse: False` [PRE32]
