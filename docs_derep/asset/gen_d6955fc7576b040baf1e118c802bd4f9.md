10．启用 Hooks（钩子）

Hooks 负责引导内容和记录日志，建议勾选 boot-md、command-logger、session-memory 这三项，见图 2-9。

[PRE7]

图 2-9 启用 Hooks 选项

（1）boot-md：启动时载入你的个性化配置。

每次 Gateway 启动会自动读取 BOOT.md 文件。BOOT.md 相当于开机指令，可以写每次启动先加载工作配置、检查今日日程等规则。建议开启。

bootstrap-extra-files：启动时加载额外配置文件，比如多个自定义 md。普通用户暂时用不到，可先关闭。

（2）command-logger：记录所有执行命令，方便追溯。

所有执行过的命令会写入审计日志，出错时可查“龙虾到底干了什么”，也能统计用量。建议开启。

（3）session-memory：会话记忆，保持上下文连贯。

开启后，每次用 /new 或 /reset 开启新对话时，龙虾会自动把当前对话的关键信息存入记忆。若未开启，每次新对话就会“失忆”。强烈建议开启。

**常见问题速查**

**问题 1：提示“command not found: openclaw”（命令未找到）**

安装后重启终端再试。若仍不行，手动补环境变量：

echo ‘export PATH=$HOME/.openclaw/bin:$PATH’ ＞＞~/.zshrc ＆＆ source ~/.zshrc

**问题 2：安装时提示权限不足（Permission denied）**

命令前加上 sudo，以管理员身份执行：

curl -fsSL https://openclaw.ai/install.sh | sudo bash

**问题 3：Gateway 启动了，但浏览器打不开 Web UI**

● 查看端口是否被占用：lsof -i :18789（Mac/Linux）

● WSL2 用户注意：IP 不是 127.0.0.1，用 hostname -I 查询 WSL2 实际 IP，再访问 IP:18789

● 改个端口试试，终端执行后再重启 Gateway：

openclaw config set gateway.port 18790

**问题 4：发消息没有回复，AI 不响应**

● 先做体检：openclaw doctor，会直接指出问题点

● 检查 API Key 余额：openclaw test api，余额为 0 是最常见原因

● 查看实时日志定位报错：openclaw logs --follow

**问题 5：怎么备份我的配置**

tar -czf openclaw-backup-$(date +%Y%m%d).tar.gz~/.openclaw

备份文件包含所有配置（SOUL.md、MEMORY.md、openclaw. json 等），换电脑也能恢复。

## **2.3 Windows 本地安装：WSL2 是你的好朋友**

好消息是 OpenClaw 在 Windows 上也能正常运行日常任务。坏消息是需要多一步——先装 WSL2，也就是 Windows 的 Linux 子系统。

别被名字吓到，WSL2 只是微软官方提供的一个轻量 Linux 环境，安装只需一条命令，向导也很友好。

[PRE11]

**注意**

Windows 上部分系统级功能如操作系统日历、备忘录、截图受限，这是平台本身限制。处理文件、邮件、网页等核心任务完全没问题。

**前置配置检查：查看你的 Windows 是否适配**

● 操作系统：Windows 10 版本 2004（Build 19041）及以上，或 Windows 11

● CPU：2 核以上

● 内存：4GB 以上（推荐 8GB）

● 硬盘：10GB 以上空闲空间

● 前置软件：Node.js v22.16.X 及以上

**安装方式一：WSL2+Ubuntu 部署（推荐）**

这是官方推荐的 Windows 部署方案，提供相对完整的 Linux 支持。

[PRE12]

**风险提示**

WSL2 本质是在 Windows 内运行虚拟化的 Linux 环境，使用需注意：（1）WSL2 与 Windows 共享文件系统，在 WSL2 中误删或覆盖会同步影响 Windows 侧文件；（2）WSL2 网络配置独立，端口转发和防火墙需额外设置，配置不当可能导致服务暴露；（3）WSL2 资源占用会随使用增长，内存默认不自动释放，长期运行可能拖慢系统，建议定期执行 wsl --shutdown 释放资源；（4）文件权限模型与原生 Linux 不同，部分依赖严格权限的操作可能异常。不熟悉命令行者建议考虑 PowerShell 原生安装方式或云端部署。

**第一步：启用 WSL2**

以管理员身份打开 PowerShell［右击开始菜单→Windows Terminal（管理员）］，依次执行：

# 启用 WSL 功能

dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# 设置 WSL2 为默认版本

wsl --set-default-version 2

完成后重启电脑。

**第二步：安装 Ubuntu**

推荐从 Microsoft Store 安装，最简单：

● 打开 Microsoft Store

● 搜索“Ubuntu 22.04 LTS”或“Ubuntu 24.04 LTS”

● 点击“获取”并安装

● 首次启动按提示设置用户名和密码

[PRE13]

**小贴士**

用户名和密码可随意，但要记住，之后在 Ubuntu 里用 sudo 都需要。建议设一个简单好记的，比如“admin”。

**第三步：更新 Ubuntu 系统**

在 Ubuntu 终端执行：

# 更新软件包列表

sudo apt update ＆＆ sudo apt upgrade -y

# 安装基础工具

sudo apt install -y curl git wget build-essential

**第四步：安装 Node.js**

# 添加 NodeSource 仓库

curl -fsSL https://deb.nodesource.com/setup_22.x| sudo -E bash -

# 安装 Node.js

sudo apt install -y nodejs

# 验证版本（必须≥22.x）

node -v

npm -v

**第五步：安装 OpenClaw**

一键脚本安装，与 Mac 相同：

curl -fsSL https://openclaw.ai/install.sh | bash

**第六步：验证安装**

# 查看版本

openclaw --version

# 查看帮助

openclaw --help

# 查看系统状态

openclaw status

**第七步：配置 Windows 访问 WSL2 服务**

OpenClaw 运行在 WSL2 中，需配置端口转发方便 Windows 访问。创建启动脚本 start-openclaw.bat：

# 在 WSL2 Ubuntu 终端中启动

openclaw gateway run --port 18789

然后在 Windows 浏览器访问 http://localhost:18789。

**安装方式二：PowerShell 原生部署**

适合不想用 WSL2 的纯 Windows 用户。

**第一步：安装 Node.js**

● 访问 https://nodejs.org/zh-cn

● 下载 Windows 安装包（LTS 版本 22.x）

● 运行安装程序，勾选“自动安装必要的工具”

**第二步：验证 Node.js 安装**

# 打开 PowerShell

node -v

npm -v

**第三步：以管理员身份安装 OpenClaw**

[PRE14]

**注意**

必须以管理员身份运行 PowerShell 或 CMD。右击开始菜单→Windows PowerShell 或 CMD（管理员）。

# 安装最新稳定版

npm install -g openclaw@latest

# 或安装汉化版

npm install -g @qingchencloud/openclaw-zh@latest

**第四步：解决安装权限问题**

遇到权限错误二选一：

# 方法 A：启用 PowerShell 脚本执行

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned-Scope CurrentUser

# 方法 B：修改 npm 安装目录

npm config set prefix "C:\npm"

npm config set cache "C:\npm-cache"

# 将目录添加到 Path

[Environment]::SetEnvironmentVariable("Path",$env:Path+";C:\npm", "User")

**第五步：验证安装**

openclaw --version

openclaw --help

**第六步：解决常见问题**

问题 1：sharp 模块加载失败。

# 清理 npm 缓存

npm cache clean --force

# 重新安装

npm install -g openclaw@latest --force

问题 2：Windows Defender 阻止。

将 OpenClaw 安装目录加入 Windows Defender 排除项：

C:\Users\你的用户名\AppData\Roaming\npm

C:\Users\你的用户名\.openclaw

**初始化配置：给龙虾做入职培训（Windows 通用）**

安装完成后运行初始化向导：

openclaw onboard --install-daemon

配置 AI 模型（以 DeepSeek 为例）：

# WSL2 或 PowerShell 均可

openclaw models auth add

# 按提示选择 Z.AI，输入 API Key: sk-xxx

Windows 同样支持多种聊天工具接入，可先跳过，第三章会详细讲解。
