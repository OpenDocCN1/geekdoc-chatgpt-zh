真正的瓶颈源于目标设定偏离。我们长期让模型学习日志的表达套路，却忽略了日志背后在运行的因果机制。转机已经显现 ^(³⁴)，Code Interpreter（2023）借助 Python 工具完成物理仿真；PaLM-E（2023）把视觉与语言接入机器人控制；Toolformer（2023）学会主动调用外部接口。这三条线索指向同一判断：大型语言系统的出路不在于语言自循环，而在于语言、仿真与工具的协同。

LLM 被困在自反的镜像空间，不必把整座空间拆除。更可行的做法是在墙上开一扇口，让它能够调用仿真器、读取社会成本信号、捕捉文化仪式行为。后续章节会说明这种补丁式改进的边界，以及中国场景在开窗上具备的特殊条件。

核心问题不在于中国能否突破，而在于我们有没有决心把训练目标从续词预测转向推演下一条因果序列。这需要的不仅是技术迭代，更是认知范式的转移。

LLM 并非不懂世界，只是被关进了像素牢笼。本章看杨立昆如何用 JEPA 为智能体凿窗。

**第四章 JEPA：为 AI 赋予预见力**

**把握世界靠推演而非堆信息。**

回顾 AI 七十年历程，我们见证了一座又一座通天塔的搭建。从逻辑符号到神经网络再到海量参数，每一次攀升都在常识这道无形墙前受阻。

问题已明：缺少对世界的内在模拟。系统能回答“是什么”，却始终跨不过“如果会怎样”的门槛。诊断之后需要处方。指责迟钝容易，真正关键且令人振奋的问题是，一个真正理解世界的智能体，内部该运行怎样的程序？如何植入常识的灵魂？

答案藏在顶尖实验室的前沿，藏在 World Model 的设想里。本章不复盘失败史，而是给出一条通向真正智能的工程路线。

**4.1 热油锅里看出的认知鸿沟**

设想如图 4-1 所示的智能灶台监控模拟。厨房里摄像头、麦克风、气体传感器持续在线。负责安全的智能体经过大量训练，能稳定辨认锅、油、烟、火。此时灶上热油在翻滚，油面起涟，发出细碎滋声，一缕淡青烟正冒起。

方案 A，即现行做法，视觉模块能标出锅和油，听觉模块能标注声响，却把这些标签当成孤立静止的点。它像只会报菜名的旁观者，等火焰像素出现才报警，却听不见危险正在积累。

方案 B，具备内在模拟，接收同样感官流，却在内部把滋滋声、青烟、温度读数融合成抽象判断：油温已逼近燃点。基于此，内部仿真器自动运行，得出结论：三秒后起火概率超九成。于是火焰未现，机械臂已提前关火，并提示：油温过高，已自动断电。

当下智能与下一轮智能之间的距离，就体现在这两种方案的差异里。它也表现在：能认出前车和刹车，却读不出对方车轮微摆里的失控征兆；能圈出 CT 上的结节，却学不会老医生从一个眼神推断病因网络。

我们一直教模型看见世界，却少教它理解世界。理解的起点，是在脑中先行模拟未来，再据此行动。这一内在模拟器就是可工程化的认知架构。接下来就从这口锅拆解它。

**4.2 JEPA 作为 World Model 的心算引擎**

厨房的危险提醒我们必须会前瞻，但 JEPA 如何把前瞻从概念变成可运行代码？继续以热油起火为例，完整展示 World Model 的 JEPA 三件套 ^(³⁵)：表征即速写本、推演即沙盘、行动即验证，如何把被动识别推向主动预见。

先用最简话概括 JEPA（Joint Embedding Predictive Architecture，联合嵌入预测架构）的骨架。编码是将摄像头、雷达、文本等原始输入压缩进低维潜空间，保留因果信息、丢弃噪音，类似把高清图变为速写。推演是在潜空间里基于当前状态推未来状态，不是画像素，而是推关键变量演化，比如卡车是否会加速、病情是否恶化。行动是据推演挑选最优行为并执行，结果再反向修正编码与推演，形成闭环。

记住回路：感官输入→抽象编码→潜空间推演→行动干预→误差反馈→模型更新。下面看这套骨架怎样在不同场景长出血肉。

（1）从感官噪音里提炼因果要素

人站在灶前，看到青烟、听见滋滋、闻到焦味，意识到危险前，大脑已完成无声提炼，把混沌感官压缩成高温加油脂加烟雾。这就是编码，是 World Model 第一tse步，也是打造速写本的核心手艺。

①侦探的滤光镜

侦探进场不会记录地板纤维数，而是锁定强因果线索：门把手指纹、异常脚印、散落财物。他本能屏蔽无关信息，得到一份指向性强的故事梗概。

模型速写本也该如此。它不需要像摄像机那样记下每秒六百万像素，而是为场景画一张因果要素草图。天花板纹理、地砖颜色、窗外云朵都被滤掉，留下关键要素。

—视觉：油面翻滚剧烈程度 → 能量级
—听觉：滋滋声频率与强度 → 挥发级
—嗅觉：挥发分子浓度 → 裂解级
—热感：红外读数 → 温度

这些被提炼成低维向量，例如［温度：185℃，烟量：0.7，声响：0.9］。这组向量就是模型对一锅将起火热油的内部表述。

②从像素汤到物体汤

早期深度学习偏爱端到端，像素进、答案出，于是学会统计捷径。比如前面提到的认牛模型，真正学会的可能是草地，把牛放沙滩上就崩盘。它学到的是相关，不是概念本质 ^(³⁶)。

World Model 下的表征把世界看成对象集合而非纹理集合：
—对象 1：锅｛材质：金属，位置：灶台，状态：被加热｝
—对象 2：油｛材质：液体，位置：锅内，状态：沸腾，温度：185℃｝
—关系：油位于锅内，锅被灶台加热

结构化编码是有效推理的前提，因果发生在对象之间，不在像素之间。

（2）JEPA 如何实现如果-那么的推演

编码拿到［温度：185℃，烟量：0.7，声响：0.9］后，真正的智能才开始。它要回答按此发展下一步会怎样，这就是推演。实现这一推演的架构，正是被杨立昆称为通向自主智能最可行的路径的 JEPA ^(³⁷)。

①从预测像素到预测状态的范式转换

要理解突破，先看旧范式为何行不通。

旧范式：像素预测
给定视频前几帧，让模型生成下一帧每个像素。听起来合理，实则死路。因为世界充满不确定，同样油锅下一帧可能是继续翻滚、突然起火或人来关火。要求模型精确画出哪个像素变红，如同让气象员画出某朵云具体形状，结果只有越变越糊。

新范式：JEPA 的状态预测
JEPA 承认且无需预测每个像素，它在抽象编码空间里预测未来时刻的状态。

回到厨房，当前状态 S[0]=［温度：185℃，烟量：0.7，声响：0.9］，JEPA 输出不是下一帧图像，而是未来状态的概率分布：
—1 秒后：S[1]=［温度：195℃，烟量：0.8，声响：0.95］（概率 80%）
—2 秒后：S[2]=［温度：210℃，烟量：0.9，声响：1.0］（概率 85%）
—3 秒后：S[3]=［温度：230℃，烟量：1.0，声响：1.0，风险：起火］（概率 90%）

JEPA 不画未来三秒每毫秒画面，而是在速报上写：局势紧张，三秒内起火风险极高。

②象棋大师的心算

JEPA 的运作像中国象棋特级大师的心算 ^(³⁸)。大师看棋盘时，眼中不是红黑棋子，而是抽象态势：我方车控中路，马腿被绊，对方炮有闷宫。这就是编码，把具体局面压缩为控盘度、子力活性、威胁等级。随后他在抽象态势空间里进行如果-那么跳跃推理：如果我跳马→他平炮将军→我飞相解将→他可能丢车。推演的是棋势而非棋子动画。

JEPA 就是模型的棋势推演器，在编码空间这个抽象棋盘上算下一步、下下一步的状态棋势。

③效率与泛化的来源

状态预测带来两大优势。一是计算效率量级跃升。处理三维向量与处理六百万像素代价不可同日而语，使得长程高速推演成为可能。二是泛化能力质变。JEPA 学到的是高温油脂加空气导致起火的通用因果规律。学会后，不仅能预测厨房油锅，也能迁移到户外烧烤、工厂润滑油燃烧。因为它操作的是抽象因果，不绑像素。

这就是常识雏形，即无数个如果-那么因果规则集合。JEPA 提供了通过自我推演而非人工标注积累常识的路径。

（3）前瞻必须经行动闭环检验

JEPA 推出三秒后起火概率大于九成时，模型站在临界点。World Model 的答案是介入现实改变未来，推演的知识只有通过行动验证才成智能。

①从预知到塑造的意义

只能预测不能行动的智能体，像能精准预报地震却无力组织撤离。World Model 的终极目标不是预知而是塑造。

厨房里，系统收到高维预警［风险：起火，概率：0.9，时间：3 秒］，行动规划器生成候选序列：
—动作 A：机械臂关闭灶具开关
—动作 B：启动排风百分百
—动作 C：声光报警通知人类

基于火灾损失远大于能源节省大于打扰人类的损失函数，选择动作 A。机械臂关火，油温不再攀升，风险清零。行动-结果配对回流到 JEPA 和编码模块，用于微调未来预测。

行动完成了感知-认知-反作用于世界的闭环，让模型从读者变作者。

②摔跟头是最好的老师

行动不总成功，失败才最有价值。想象学走路的机器人婴儿，预测迈右腿会保持平衡，结果摔倒。预测与现实的巨大误差，比任何预编程都更强地告诉它：对重力和平衡的假设错了，必须更新。

无行动的模型如 LLM，错误只是统计误差，学习温和缓慢。有行动的模型，错误带来物理代价：摔跤、撞墙、打翻东西。这种伴随物理代价的预测误差，如同人类被烫伤，会最深刻、最快速地刻进 World Model。

③社会行动验证的微妙

在复杂社会场景中，行动验证更精妙。回顾司机道路博弈论：
—推演：模型预测邻车有并线意图
—行动选择：强硬封堵、协作让行、防御减速
—验证：模型选择后实时观察对方反应，判断行为是否有效

通过成千上万次行动-反馈循环，模型才能学会交规上不会写、真实驾驶中至关重要的隐性社会契约。

④闭环飞轮驱动自我进化

把三组件连起来形成自我强化飞轮。
a.编码：从感官洪流提炼抽象状态 S[0]
b.推演：JEPA 基于 S[0] 预测未来 S[1]、S[2]、S[3]…
c.行动：选动作 A 促成有利未来，如避免 S[3] 起火
d.验证：执行后产生新现实 S[0]'，与预测 S[1] 比较，生成误差
e.更新：误差同时更新编码与 JEPA

这一闭环即学习本身。模型不再被动消化人类数据，而是主动与环境互动生成数据，不断完善内部 World Model。

行动验证为 World Model 注入灵魂，把抽象推理和物理现实牢牢绑定。智能并非诞生于纯净沉思，而是源于和复杂混乱现实不断碰撞与摩擦。

至此，World Model 的认知三部曲已完整拆解。进入中国复杂现实，JEPA 会长出怎样形态？4.3 节将走进这些挫折教育实验室。

※技术直觉：JEPA 与 Transformer 的本质区别？※

Transformer 预测后续词，JEPA 预测后续状态。

词是离散符号，状态是连续物理量（温度、压力、意图）。

这正是 LLM 会画饼干却不会热饼干的数学根源——离散符号操作很难自然涌现连续物理模拟能力。

Transformer 在有限词表里挑下一个 Token，目标是最大化似然；JEPA 在无限连续空间里推演状态演化，目标是最小化预测能量。前者学会统计共现，后者学会因果推演。

（1）司机的博弈 JEPA

在不少城市路口，交通法规只是博弈底色。一个熟练司机的脑中运行的，远超物理轨迹预测的社会博弈模型。

①毫秒级的心理博弈

想象无红绿灯的窄路口。法律上的让行规则在此模糊。人类司机瞬间完成多维度社会编码与意图推演。

第一步：社会编码
司机会对来车做身份抽象——
—出租车：大概率抢行，时间即收入
—新手车：易犹豫，可引导
—本地牌：策略稳定
—外地牌：易分心，行为迟疑

第二步：并行推演
JEPA 基于抽象标签在意图空间而非物理空间同时推演多个未来。
—若对方加速，我需减速让行
—若对方减速，我可试探前行
—若双方皆犹豫，将形成僵持

第三步：姿态试探
行动不是简单刹车或油门，而是信号发射：车轮微前蠕动、大灯短闪、车身轻压停止线。目的在于向对方 JEPA 发送信号，修正预测，最终协同找到均衡点。

这省去了渲染车辆金属细节，无需计算对方肌肉收缩，只关心和社會博弈强相关的抽象特征，在意图空间完成高效推演。

③最优解撞上人情世故

当前自动驾驶常在此卡壳。规则型模型追求绝对安全间隙，结果永远过不去路口，因为绝对安全等同绝对被动。物理 JEPA 能预测轨迹，却读不懂减速但紧握方向盘这类姿态的社会语义——我慢了，但路权在我，请你让。这正是纯物理预测器与社会智能体的鸿沟。人类 JEPA 是物理预测和社会博弈的融合体。为模型注入博弈论和社會认知维度，才可能在这类道路上生存。

④如何为模型注入博弈 JEPA

同济等高校的研究者正在推进，分三步 ^(³⁹)。

第一步，从数据学习博弈偏好。不只记录轨迹，而是标注每次交互中的社会倾向性：激进/协作/保守，为模型构建博弈策略库。

第二步，为多智能体博弈建模。把交通视作多智能体系统，模型不仅预测他车轨迹，更要揣测他车意图与目标。这要求具备推演他人推演的心智能力。
