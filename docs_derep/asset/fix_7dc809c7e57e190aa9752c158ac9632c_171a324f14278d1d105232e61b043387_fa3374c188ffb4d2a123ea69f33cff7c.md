##### 4. 对齐微调：让模型更合心意

为了把输出拉向人类价值观与使用习惯，DeepSeek V1 同时启用了监督式精调和直接偏好优化。两者配合后，答案的正确性与实用性一起提升，用户满意度与信任感也随之增强。

为何要做这两步？预训练后的模型像一本未经校对的百科全书，什么都收录。关键在下一步，教它分辨哪些表达可以接受、哪些应当避免，就像教育孩子，既要传知识也要立边界。

监督式精调主要负责让模型学会产出经得起推敲的答案，掌握常见问答的表达范式。直接偏好优化则是在多条看似都合理的答案里，挑选更贴合人类价值的那一条，借助人工对答案的好坏排序，让模型自行习得“可说”与“不可说”的边界。

对 7B 这类轻量模型，长时间在数学与代码集上精调是拉升实力的关键。但实践中发现，监督精调阶段数学数据越多，输出重复的现象越明显，很可能模型把解题套路记死。为此采用两阶段方案：先做一次全科过一遍，涵盖数学代码等全部精调数据；再进入对话专项，去掉数学代码专注聊天，并叠加偏好优化。两种路径都能在基准分数基本不变的前提下明显压低重复率。

偏好学习集同时覆盖了安全性与有用性两个维度。安全性不仅要求学会拒绝危险提问，还要能区分好坏回答；有用性不仅要求能作答，还要能辨别优质回答和普通回答。训练采用 1 个 epoch，学习率 5e-6，批次规模 512。实测显示，偏好优化不仅改善了开放式问答，还带来全方面的提升。

#### 1.2.2 DeepSeek 的技术演进路线

V1 验证可行后，团队持续打磨，陆续推出 V2、V3 等更强版本。

##### 1. 引入 MoE 架构
V2 首次引入混合专家机制，训练效率与推理速度同步提升。稀疏激活配合动态路由，推理时只唤醒少数专家，算力开销大幅下降。

##### 2. 提出 MLA 机制
为进一步压缩推理成本，V2 提出了多头潜在注意力。把输入 token 的注意力信息压缩成潜在向量，使用时再解压得到对应的 Key 与 Value，KV 缓存占用被大幅压缩。

##### 3. 升级模型规模与训练数据
随着技术成熟，V3 的参数规模达到 V2 的三倍，训练数据量接近翻倍。配合 FP8 混合精度与优化的通信内核，整体训练开销得到有效控制。

##### 4. 强化学习与蒸馏技术的结合
为强化推理能力，R1 系列探索了强化学习与蒸馏的结合。用强化学习炼出高性能模型后再蒸馏到更小体量，实现低成本快速复制推理能力。
