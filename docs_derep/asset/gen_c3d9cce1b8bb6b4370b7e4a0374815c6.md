图5-8 源自论文 The Power of Scale for Parameter-Efficient Prompt Tuning，本部分的核心是把 Prompt Tuning 与经典的全模型微调 Model Tuning 放在一起比较。左图点出了传统做法的痛点：面对 Task A、B、C 等不同任务，需要各自准备独立的训练集。每增加一个任务就得从零训练一个专用模型，计算开销和耗时会随之倍增。Prefix Tuning 虽然作了改良，只对前缀部分单独训练后再并入模型，减轻了部分训练压力，但依然遵循一任务一模型的思路，本质上仍未摆脱重复建模的限制。

[PRE0]

右图则展示了 Prompt Tuning 的设计思路。与 Prefix Tuning 把前缀模块植入 Transformer 内部不同，Prompt Tuning 采用了一个与基础预训练模型隔离的外部架构，形成独立的外挂系统。这样的结构支持跨任务联合训练，能够同时处理 Task A、B、C 等多个任务，从而提升训练效率和泛化能力，同时对原始模型参数的改动很小，保持了预训练模型的稳定性和性能表现。

尤其值得关注的是 Prompt Tuning 提出的 Prompt Ensembling 策略，在同一个训练批次里融合多个针对同一任务的不同形式 Prompt，实际效果等价于多个模型的集成学习，却避免了集成多个完整模型的高昂成本。批次内多样化的 Prompt 帮助模型更深、更广地理解任务，提升了鲁棒性和灵活性。

总体来看，Prompt Tuning 构建了一个通用的下游任务处理框架，凭借单一混合模型即可应对多样化需求，展现出很强的多任务适应性和效率。另一方面，与 Prefix Tuning 相似，它同样会占用模型输入序列的空间，虽是 Prefix Tuning 的优化形态，在降低训练复杂度上有所进步，但 Prompt 或前缀对输入资源的占用仍是后续研究需要继续权衡的方向。

## 5.5 P-Tuning

### 5.5.1 背景

P-Tuning 由中国研究团队提出，属于软提示 Soft Prompt 方法的创新发展，目标是在连续空间中自动探索并优化提示序列，替代传统的人工设计。其 V1 版本直接解决了上节代码里通过 PromptTuningConfig 的 prompt_tuning_init_text 手工设定 Prompt 的问题。原始论文指出：“为预训练模型提供 Prompt 有助于理解自然语言模式，但设计不当的离散 Prompt 可能会导致性能严重下降。”这说明 Prompt 的细微变动，如词汇增减或顺序调整，都可能显著影响效果，不仅增加调优成本，也难以稳定达到理想水平。

为此，P-Tuning 引入可训练的嵌入张量，通过优化该张量寻找更优的 Prompt 表达，并借助双向长短期记忆网络 Bi-LSTM 作为 Prompt 编码器，精细调整 Prompt 参数，提升自动化程度和效率。

此外，P-Tuning 还试图解决另一个瓶颈：以往 Prefix Tuning 和 Prompt Tuning 多冻结大模型参数，仅微调小模型，容易出现过拟合，限制泛化能力。直接对嵌入层参数进行优化时，还需保证预训练语料嵌入与新加入的学习型 Prompt 嵌入能够协同训练。若 P-Tuning 使用的数据量小且多样性不足，就容易过拟合，不仅无法利用大模型的先验知识，还可能削弱原有能力，陷入局部最优。

### 5.5.2 核心技术解读

具体做法如下。

图5-9 来自论文 GPT Understand,Too，左图展示的方法称为“Prompt Search”，核心是寻找一组离散的提示序列。这些提示可通过人工设计或其他非自动化方式获得，本质上是离散且不可微的，无法直接接受连续梯度信号，只能依赖离散评估反馈来优化。

## 图5-10

相对地，右图介绍的方法为“Prompt Encoder”，采用连续可微分的虚拟词元作为提示载体。借助反向传播，提示可以在连续空间中被精细优化，这一点与“Prompt Search”形成明显区分。

进一步比较 P-Tuning 与 Prefix Tuning，可归纳为以下差异。

- (1) Prompt 的实质形态：P-Tuning 的“Prompt Generator”直接生成实际词汇作为提示内容，而 Prefix Tuning 的“Prompt Encoder”处理的是连续空间中的虚拟词元，从具体词汇向抽象表示转变。
- (2) 模型结构调整：Prefix Tuning 在模型前端附加前缀，对嵌入层做微调，尽量减少对原架构的干预。P-Tuning 则更主动，直接对模型的嵌入参数进行优化。
- (3) 初始化与训练机制：Prefix Tuning 使用多层感知机 MLP 来初始化前缀，流程相对繁琐。P-Tuning 则用 LSTM 结合 MLP 对输入嵌入进行初始化，再训练“Prompt Encoder”，在简化流程的同时提升提示生成的有效性和灵活性。

总的来说，无论是提示表达形式、模型调适策略还是训练机制，P-Tuning 与 Prefix Tuning 都呈现出不同的技术取向，反映了自然语言处理领域在高效微调路径探索上的多元化发展。
