相关系数里最常用的就是皮尔逊 r，它用来衡量两组等距变量之间的关联紧密程度，取值区间在 -1 到 1 之间。r 的绝对值越大，说明用其中一个变量去推断另一个变量的准确性越高，因为共变的部分越多，变量随之变化的信息也就越充分。当 r 等于 1 或 -1 时，二者完全线性对应，知道 x 就能确定 y；r 为 0 时代表两者没有线性关系。正相关时随着 x 增大 y 也增大，r 落在 0.00 到 1.00 之间；负相关时 x 增大 y 减小，r 落在 -1.00 到 0.00 之间。绝对值越接近 1，相关越强；越接近 0，相关越弱。计算方式见式（3-6）。

distance(x_i, x_j) = [E(x_i x_j) - E(x_i)E(x_j)] / [ sqrt(E(x_i^2) - (E(x_i))^2) sqrt(E(x_j^2) - (E(x_j))^2) ] = cov(x_i, x_j) / (σ_{x_i} σ_{x_j})  (3-6)

式中，E(x_i) 表示向量 x_i 的数学期望值；σ_{x_i} 表示向量 x_i 的标准差；σ_{x_j} 表示向量 x_j 的标准差；cov(x_i, x_j) 表示向量 x_i, x_j 的协方差。

### 7. 杰卡德相似系数（Jaccard similarity coefficient）

杰卡德相似系数适用于二值或符号型数据的相似度比对，核心是看两个对象共同拥有的属性有多少相一致。给定集合 A 与集合 B，其计算公式见式（3-7）。

distance(A, B) = |A ∩ B| / |A ∪ B|  (3-7)

### 8. 马氏距离（Mahalanobis distance）

马氏距离本质上是考虑协方差结构的距离，能够在消除量纲影响的同时反映特征间的相关性，适合评估两个未知样本集的相似程度。与欧氏距离相比它不受尺度影响。$x_i = (x_i^{(1)}, x_i^{(2)}, \dots, x_i^{(n)})^T$，均值为 $\mu_i = (\mu_i^{(1)}, \mu_i^{(2)}, \dots, \mu_i^{(n)})^T$，协方差矩阵为 $S$，则计算公式见式（3-8）。

distance($x_i$) = $\sqrt{(x_i - \mu_i)^T S^{-1} (x_i - \mu_i)}$

(3-8)

## 3.3 搜索优化方法

3.1 节已提到，在数据量和特征数都很大时，K-近邻的距离计算开销会显著上升。事实上，邻居检索过程本身的计算量也非常可观。为了提升检索效率，可以用特殊的数据结构来存放训练样本，从而减少不必要的距离计算。以下介绍两种典型做法。

### 3.3.1 k-d 树

k-d 树是为了解决暴力搜索低效问题而提出的一种树状结构。基本思路是：如果点 A 离点 B 很远，而点 B 离点 C 很近，那么点 A 与点 C 很可能也很远，无需精确计算。对 k 个特征、n 个样本的数据，邻居搜索的成本可以压到 $O[k n \log(n)]$ 以下，在大数据集上优势明显。

k-d 树是每个节点都保存 k 维点的二叉树，每层节点代表一个超平面，该平面垂直于当前切分维度的坐标轴，并把空间一分为二。设当前节点的切分维度为 F，则左子树中所有点的 F 维坐标小于当前节点，右子树中则大于等于当前节点。构建过程无需距离计算，只需按轴划分，速度很快。构建完成后，最近邻查询的复杂度大约为 $O[\log(n)]$。当特征数较少时非常高效，但 k 很大时效果会下降。

下面用一个直观例子说明。

假设数据集有 2 个特征、6 个样本，如 $T = \{(2,3),(5,4),(9,6),(4,7),(8,1),(7,2)\}$，可视作二维平面上的点。k-d 树的任务就是确定这些点的空间分割线。

先选切分维度。分别计算 X 轴和 Y 轴方向的方差，X 轴方差更大，先按 X 轴切分。

再确定切分线的 X 坐标。X 特征取值 2、5、9、4、8、7，中位数为 6.5，最接近的样本是 $(7,2)$。于是分割线取 $x=7$，即过 $(7,2)$ 且垂直于 X 轴的直线。

划分左右子空间。$x\le7$ 为左子空间，包含 $\{(2,3),(5,4),(4,7)\}$；右子空间包含 $\{(9,6),(8,1)\}$。

随后对 Y 轴划分。左子空间纵坐标 3、4、7，中位数为 4，切分点为 $(5,4)$；右子空间仅 2 个样本，随机取 $(9,6)$ 作为切分点。

k-d 树的构建可概括为：

- 1) 构造根节点，使其对应包含全部样本的 k 维超矩形区域。
- 2) 递归地对 k 维空间切分产生子节点。在当前超矩形上挑选一个坐标轴和该轴上的一个分割点，确定一个垂直于该轴的超平面，将当前区域分为左右两个子区域，样本随之归属到对应子区域。
- 3) 重复切分直到子区域内无样本为止，终止时为叶节点。过程中把样本保存在对应节点上。
- 4) 通常按坐标轴轮流切分，例如 3 维数据根节点用 X 轴，子节点用 Y 轴，孙节点用 Z 轴，以此类推，并取中位数作为分割点，这样得到的树是平衡二叉树。

k-d 树中每个节点是一个向量，与普通二叉树按大小划分不同，k-d 树每层需指定一个维度，按左小右大的规则划分。构建时要解决两个关键问题：

- 1) 选哪一维来划分。
- 2) 如何划分数据。

简单做法是随机或顺序选取，但更优的是在数据离散程度大的维度上划分，可用方差衡量离散度。好的划分能让树更平衡，常用中位数划分，这样第二个问题也得以解决。

构建完成后，介绍如何用 k-d 树搜索最近邻。总体思路是维护一个当前全局最佳点和全局最短距离，从根节点开始按树的生成规则递归遍历。若当前节点到查询点 Q 的距离更小，则更新最佳点和最短距离；若 Q 到当前节点切分维度的距离小于当前最短距离，则可能有更近的点在另一子树中，需继续探索。具体步骤如下：

- 1）初始化全局最佳点为空、全局最短距离为无穷大，用来保存离 Q 最近的点及其距离。
- 2）从根节点开始，将其设为当前节点。
- 3）若当前节点为空，则结束。
- 4）若当前节点到 Q 的距离小于全局最短距离，则更新全局最佳点和最短距离。
- 5）若 Q 在切分维度上的值小于当前节点的值，则进入左子节点，否则进入右子节点，继续执行 3）、4）、5）、6）。
- 6）若 Q 到当前节点对应分割线的距离小于全局最短距离，则可能在另一子树中存在更近的点，切换到另外的子节点继续执行 3）、4）、5）、6）。

递归结束后，全局最佳点即为最近邻。

以图 3-5 为例，搜索样本 (3,2)。初始根节点 (7,2) 距离为 4，更新最佳点；因 3<7 进入左子节点 (5,4)，距离 2.83 更新；因 2<4 进入左子节点 (2,3)，距离 1.41 更新。此时切分线 x=2 到 Q 的距离为 1，小于 1.41，需回溯检查其他分支。经判断 (5,4) 对应的分割线 y=4 到 Q 的距离为 2，大于 1.41 可剪枝；根节点分割线 x=7 到 Q 的距离为 4，也可剪枝。最终最近邻为 (2,3)。

在 K-近邻中，搜索流程类似，只是需要维护一个大小为 K 的有序候选列表，首位为当前最近，其余按距离升序排列。

当维度极高时，k-d 树效率会下降。一般规律是，只有当样本数远大于 $2^k$ 时，k-d 树才显著优于全量扫描。

### 3.3.2 球树

k-d 树在非均匀分布和高维数据上仍可能低效，于是提出了球树。

k-d 树沿坐标轴切分，球树则用一系列超球体来划分空间。虽然构建成本更高，但在高维场景下表现更稳定。球树将数据递归划分为由质心 c 和半径 r 定义的节点，每个节点代表一个包含若干样本的空间，中心点可以是样本点或该空间的质心，并记录该节点内所有样本到中心的í最大距离。

构造方式与 k-d 树类似，首先找到包含全部数据的超球体，球心作为根节点，或直接以使样本到质心距离和最小的点为根。然后递归：

- 1) 选距离质心最远的点作为左观测点，再选离它最远的点作为右观测点，或直接取最远的一对点作为左右子节点。
- 2) 把样本分配到距离最近的观测点所属类中。
- 3) 记录质心位置和包含该节点的最小半径。
- 4) 对每个子节点重复上述过程。
