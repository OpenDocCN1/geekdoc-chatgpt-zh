以前面样例为参照，下面把 MCP 服务器配置的组成要点逐项拆开说明：

- MCP 服务器的配置文件采用 JSON 规范书写。
- 全部服务器信息统一收纳在 mcpServers 这个根键之下。
- 在 mcpServers 内部，每个子键名就是一个具体的 MCP 服务器名称，对应的子键值则是该服务器的配置集合。本例中的 python_code_runner 就是我们所搭建的 Python 代码运行器服务器的名字。
- 具体的配置项包括：
    - command：必填项，用来提供启动 MCP 服务器脚本的命令。可以直接写成包含脚本地址的完整命令，也可以只写执行器，后面配合 args 拼装完整指令。后一种写法更推荐。
    - args：选填，数组类型。每个元素都是一个附加参数，可用来传入执行器所需参数或目标脚本路径等信息。
    - disabled：可选，默认 false。用以标明当前服务器是否停用，true 为禁用，false 为启用。
    - timeout：可选，未设置时一直等待不会超时。表示服务器被调用后等待响应的时限，单位秒，超时则报错。
    - transportType：可选，默认 stdio。描述服务器的输出方式，stdio 为一次性输出结果，sse 为以 SSE 方式流式输出。
- 和 Python 的 subprocess 或某些 IDE 运行代码的配置类似，command 与 args 组合起来的指令，相当于在命令行终端直接执行 `<command> <arg_1> <arg_2>`，从而触发 MCP 脚本，在本地启动服务器监听并响应请求。
