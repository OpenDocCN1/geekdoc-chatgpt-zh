归根到底，算法存在是为了应对现实世界的具体难题。第 2 章和第 3 章已分别梳理了算法的理论底座，也就是相关的数学基础，以及算法的常用手段，也就是数据结构与基础方法。凭借这两块，日常的简易需求基本可以覆盖。但当问题复杂度提升，例如社交媒体的用户兴趣与热点话题的归类、电商平台的商品推荐与排序、股价走势、交通流量或商品销量的预测，乃至让计算机实现自动驾驶、下棋、对话等人工智能任务时，仅靠底座与手段已捉襟见肘，需要更精巧的算法体系。招式往往只解决某一类子问题，或是大问题中的一个片段，譬如武当的梯云纵，仅负责“腾空跃起”这件事。实战中，还必须依靠太极拳、太极剑这类成套的秘籍才能制胜。

本章将梳理机器学习算法的流派划分，并对不同流派的原理做系统介绍，帮助建立对算法秘籍的全景认知。

## 4.1　类别划分
机器学习包含大量不同的方法，应用面极广。本节从两个维度对它们做归纳，便于整体把握。第一个维度是样本是否带有监督信号，第二个维度是模型最终的学习目标。

#### 4.1.1　按是否有监督信号划分
所有机器学习方法都依赖样本学习。有标签的样本相当于有经验的师傅提前点明学习方向，该标签即监督信号。带监督信号的学习称为监督学习（`Supervised Learning`），不带监督信号的称为无监督学习（`Unsupervised Learning`）。介于其间的是半监督学习（`Semi-Supervised Learning`），即所用样本只有一部分带有监督信号。

## 1. 监督学习
监督学习使用有标签样本训练模型并调整参数，使性能达到预期，这一过程也叫做监督训练或教师学习。名称源于教师授课、学生练习的类比。下面用一个幼儿园的例子说明。

问题描述：若干张画有猴子、老虎、狮子、大象、长颈鹿等动物的卡片，每类动物有多张，如何教会小朋友辨认？常规教学是拿出猴子卡片就告知这是猴子，拿出狮子卡片就告知这是狮子，反复数轮后孩子就能区分。事先告知的卡片与动物的对应关系即样本标签，也就是监督信号，孩子记忆的过程对应监督学习算法。

常见的监督学习方法有线性回归（`Linear Regression`）、逻辑回归（`Logistic Regression`）、K-近邻（`K-Nearest Neighbor`，`KNN`算法）、决策树（`Decision Tree`）、朴素贝叶斯（`Naive Bayes`）、神经网络（`Neural Network`），以及用于降维的线性判别分析（`Linear Discriminant Analysis`，`LDA`）。无论选用哪一种，核心都是“教什么学什么”，让模型输出尽可能贴近指定的标签值。

## 2. 无监督学习
无监督学习不依赖监督信号，它利用未标注样本调整参数，挖掘特征、规律、趋势或既定模式，从而达成目标。从原始社会到今天，人类文明的进步处处伴随无监督学习。以动物卡片为例，最初人们并不知道猴子叫猴子、狮子叫狮子，只是注意到某些动物外形与行为相近，例如总爱用手挠头、活泼好动、喜欢在树上穿梭；另一类体格健壮、颈部有厚鬃毛、食肉。久而久之，具备相同特征的群体被命名为猴子和狮子，这就是无监督学习的过程，其中归类的方法即典型的聚类算法。图 4-1 所示为一个无监督学习示例。

## 3. 半监督学习
半监督学习融合监督与无监督，同时使用大量未标注样本和少量已标注样本来学习特征、规律、趋势或模式。现实中标注样本耗时费力，半监督学习的主要作用之一是提升效率。但它依赖三个前提假设。

• 平滑假设，同一度量空间中距离很近的两个样本，标签倾向于相似。
• 聚类假设，落在同一聚类类别中的两个样本，标签倾向于相似。
• 流形假设，当两个样本从高维映射到低维的同一个局部邻域[PRE1]时，标签倾向于相似。

若上述假设不成立，未标注数据不仅无法改善模型，反而会损害性能，导致半监督失效。即便假设成立，实验也显示未标注样本有时仍会拖累模型。因此开展半监督学习前需做好充分的数据调研。

常见的半监督算法有半监督聚类（`Semi-Supervised Clustering`）、生成对抗网络（`Generative Adversarial Nets`，`GAN`）、半监督分类（`Semi-supervised Classification`）及一些基于图的算法等。

### 4.1.2 按学习目标划分
除监督信号外，还可按模型最终想要达到的目的来划分。识别动物卡片的目标是区分类别，回答“是或否”类问题；销量或股价预测的目标是估算数值大小，回答“多少”类问题。据此，机器学习模型可分为四大类：回答是/否的分类（`Classification`），回答多少的回归（`Regression`），聚类（`Clustering`）和降维（`Dimensionality Reduction`）。

分类与回归的直观区别在于输出形式：最终预测值是离散的二值如 0 和 1，为分类；是连续取值空间，为回归。分类和回归都使用有标签样本训练，故属于监督学习范畴。

分类和回归已涵盖大部分热门模型，如近年来流行的神经网络及其变种卷积神经网络、循环神经网络等。常规聚类属于无监督学习，也有半监督聚类。降维中既有无监督的主成分分析 PCA，也有监督的线性判别分析 LDA。

## 4.2 线性回归模型与逻辑回归模型
在监督学习里，线性回归与逻辑回归是最经典的两个模型，逻辑回归可处理大部分监督问题。掌握它们对理解神经网络很有帮助。

#### 4.2.1 线性回归模型
线性回归是最直观的模型之一。线性指特征值与输出值满足一次函数关系，例如 `f(x)=ωx+b`，其中 `x` 为特征，`f(x)` 为输出。回归指通过调整一次函数参数使其尽可能拟合数据的过程。

从单特征模型讲起。单特征指预测目标只与一个因素相关，例如预测北京房价，只考虑建筑面积。假设房价与面积的关系如图 4-2 所示，横轴为建筑面积，纵轴为每平方米价格。

[PRE2]

图 4-2　建筑面积与房价关系图

目标是在图上找到一条直线使各点尽量靠近。单特征公式为 `f(x)=a x + b`，`x` 为面积，`f(x)` 为每平米价格，`a` 与 `b` 为权重参数，`b` 俗称偏置，单特征下 `a` 为标量，多特征下为向量。如何找到合适直线，依赖模型训练方法，目前最常用的是梯度下降法（`Gradient Descent`）。

为便于理解，假设拟合直线经过原点，只考虑样本点 `(1, 4)`，训练过程如下。

（1）初始化权重 `a`，设初值为 2，`b` 固定为 0，步长 `s=0.1`，终止阈值 `threshold=0.01`。
（2）把 `x=1` 带入 `f(x)=a x`，计算实际输出与真实值的差 `Δ=f(x)-y`，`Δ` 即 `loss`。若 `|loss| ≤ threshold` 则结束。
（3）用步长与 `loss` 的乘积作为梯度，从 `a` 中减去该梯度更新 `a`，回到步骤（2）继续。

按此流程，每轮迭代的 `a` 与梯度依次为 `(2,-0.2)`，`(2.2,-0.18)`，`(2.38,-0.162)`，`(2.542,-0.1458)`，……直至 `loss` 小于阈值。此时 `a` 接近 4，梯度接近 0，得到回归函数 `f(x)=4x`。迭代次数与 `loss` 的变化如图 4-3 所示，这一逐步逼近目标的过程称为收敛（`Convergence`）。

[PRE3]

图 4-3　训练迭代次数与 `loss` 值之间的变化关系

实际中房价受多因素影响，特征通常不止一维。一般用向量 `x` 表示多特征，用向量 `ω` 表示权重，用标量 `b` 表示偏置，公式写作 `f(x)=ωx+b`。偏置使回归函数可以不经过原点，常把偏置并入 `ωx`，令特征向量从下标 1 开始，偏置作为权重 `ω0` 与构造的特征值 `x0=1` 一起参与乘积，简化为 `f(x)=ω0～n x0～n`。

#### 4.3.2 深度神经网络
