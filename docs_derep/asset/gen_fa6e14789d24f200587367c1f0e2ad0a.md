### 4.1.2 代码生成原理：Manus 如何实现多任务兼容

Manus 能覆盖如此广泛的任务，关键在于它强大的编程能力和代码执行能力，这也是智能体“行动”阶段最突出的创新。

在“行动”阶段引入自主编程执行机制的好处是，面对任务拆解，既可以通过自编代码完成，也能调用已有工具能力。此时程序代码实质上扮演了各工具之间的粘合剂角色。

CodeAct 是专为编程场景优化的代码生成与执行大模型方案。

具体到 Manus，它采用 CodeAct 方案，并使用自研的微调模型来完成任务执行和代码生成，相比传统做法准确性更高。

**Manus 的核心观点是：编程只是手段，不是目标，它是解决通用问题的普适方法。**

编程的终极意义是有效解决问题，而非写代码本身。CodeAct 以可执行代码作为工具，赋予智能体更强的适应性，能动态应对任务变化。

接下来看 Manus 对 CodeAct 的具体运用与优化，核心创新可归纳为以下三点。

（1）与运行环境的深度交互
CodeAct 的核心思想是把智能体与环境的一切交互都转化为代码生成与执行，让智能体在每次交互中不仅能理解输入，还能执行操作并基于反馈调整。框架中包含智能体、用户、环境三方，智能体接收输入后生成代码执行，执行后再根据结果调整后续动作。Manus 用虚拟计算机实现了这一设计。

（2）充分利用现有软件包
CodeAct 还能与现有工具集成，处理复杂任务。例如借助现成的数据处理、文档处理、可视化工具，这正是前面提到的粘合剂作用。

（3）复杂任务的自我修复能力增强
CodeAct 的重要能力是自我修复，即灵活应对异常。下面以 Manus 的一次任务为例来说明，如图4-2所示，读者不必看懂具体代码。

该案例中，Manus 编写的程序运行时报错，常规情况下需人工介入，但 Manus 具备自主修复能力，随后自动修复程序，如图4-3所示。

图4-3 显示，Manus 在检测到代码执行出错后，利用错误信息自行修改代码，修改完成后回到上一步执行流程，这次程序就正常运行了，如图4-4所示。

这一自主编程过程解释了 Manus 在“行动阶段”能够适配各种任务的原因。

总之，通过 CodeAct，Manus 不仅让智能体拥有基础的工程师编程能力，也培养出自适应的问题解决能力。

## 4.2 Cherry Studio 零代码搭建智能体实操

搞懂自主智能体的原理有什么用？

无论是基于简单提示词的智能体、SOP 类型智能体，还是自主智能体平台，底层原理都是相通的，这为我们搭建智能体提供了坚实的理论基础。

很多人会觉得自己实现 CodeAct 框架过于复杂。实际上无需造轮子，在零代码搭建过程中可以充分利用已开源、开放的框架。

可选方案很多，可以用扣子平台，也可以用 AI 编程软件构建自己的智能体。下面的示例选择 Cherry Studio，因为它在这些平台里上手最快。

零基础搭建的重点在智能体设计，而非代码编写。通过这个过程，能清晰理解如何设计自己的智能体。

### 4.2.1 Cherry Studio 安装与配置指南

首先要准备好 Cherry Studio 的运行环境，才能开始使用和搭建。

#### 1. 下载安装 Cherry Studio
Cherry Studio 是一款客户端软件，下载安装方式与普通电脑应用相同。打开官网下载地址：https://www.cherry-ai.com/download，可以看到多个下载选项，如图4-5所示。

可根据电脑类型直接下载，也可选择网盘下载，安装流程与常规软件一致。

安装完成后双击打开，会看到类似 ChatGPT 的大模型对话界面，如图4-6所示，这就是主界面。

图4-6 中左侧的“助手”菜单实质上是 Cherry Studio 里的智能体，下方是已使用过的助手列表，被选中的“默认助手”即为当前会话所用。

可通过添加助手功能，查找并将系统自带的智能体加入列表，如图4-7所示。

需要注意，每个助手在使用时可以单独选择大模型，具体操作是在助手会话界面点击上方“搜索模型”按钮，如图4-8所示。

以选择人力资源助手并将大模型切换为 DeepSeek Chat 为例，会话效果如图4-9所示。

从图4-9 可见，人力资源助手保持角色定位不变，背后的大模型已切换为 DeepSeek Chat。不过新下载的 Cherry Studio 默认并未配置大模型，使用前需先完成配置。

#### 2. 配置大模型
在主界面左侧菜单找到最下方“设置”，进入设置界面后，“模型服务”即为大模型配置入口，如图4-10所示。

Cherry Studio 支持市面上大部分大模型，以硅基流动平台为例说明申请与配置流程。

1）注册登录硅基流动平台：https://siliconflow.cn/ 。登录后在左侧菜单打开“API 密钥”，复制密钥以便填入 Cherry Studio。界面如图4-11所示。

2）复制密钥后返回图4-10 的配置界面，找到硅基流动的配置项，填入复制的密钥及 API 地址“https://api.siliconflow.cn”，点击“API 密钥”右侧“检查”，显示连接成功即表示配置完成，后续即可选择具体模型。配置界面如图4-12所示。

#### 3. 添加智能体
新建智能体前，先了解默认智能体。打开主界面左侧第二项“智能体”，即可看到分类列表，如图4-13所示。

可搜索或按分类筛选，单击智能体将其加入助手列表，例如将“商业数据分析”加入列表，如图4-14所示。

### 4.2.2 信息采集智能体：网页操作助手

本次任务是创建一个信息采集智能体，采用 SOP 模式设计。为让每个智能体聚焦 SOP 的单个步骤，可按功能拆分为信息采集智能体、数据分析智能体和数据展示智能体。

SOP 智能体的核心是把输入和输出设计清楚，具体拆解与执行可交给大模型和工具。

#### 1. 智能体设计
“思考-行动”框架分为“思考”模块和“行动”模块。对信息采集智能体而言，“思考”模块要理解用户需求并判断所需数据；“行动”模块负责抓取网页信息。

在 Cherry Studio 中，“思考”模块可通过提示词配合大模型实现，“行动”模块则借助联网模块完成。

在助手会话界面的提示词输入框下方，有互联网标识的开关。开启后助手具备搜索和抓取能力，如图4-17所示。

此时发起会话，例如“查询北京最新的天气”，由于训练数据不含最新信息，Cherry Studio 会自动识别需联网查询。如图4-18所示，助手会调用联网查询工具获取最新信息。请注意，配置硅基流动后，系统会自动将 DeepSeek Chat 设为默认基础模型。

最后，DeepSeek Chat 会结合查询到的天气信息作答，如图4-19所示。图下方“引用内容”显示本次会话所用网页信息。

信息采集智能体利用联网工具抓取网页信息并由大模型整合输出，设计如下：

1. 接收用户输入，包括网站名称、查询内容及整理后的数据字段示例。

2. 输出为整体数据表格，采用 Markdown 格式。

将上述两点转化为提示词：

## 信息采集智能体

### 项目概述
创建一个网页信息采集智能体，具有以下特点：

- 利用大模型整理信息，用联网模块搜索信息。
- 等待用户输入网站名称、查询内容和数据字段例子。

### 具体步骤

#### 1. 等待用户输入
- 提示用户输入需要采集的网站名称、查询内容和数据字段例子。
- 完全接收到这些信息才开始下一步。

#### 2. 联网搜索
- 使用联网模块搜索网站名称下的查询内容。

#### 3. 数据整理
- 利用搜索到的内容整理信息并形成输出，用 Markdown 数据表格输出。
- 输出格式参考用户给的字段例子。

### 注意事项
- 输出 Markdown 表格，不要任何额外说明。

请等待用户输入需求后开始。

#### 2. 智能体搭建
1. 打开 Cherry Studio 的“我的”界面，选择“创建智能体”。在创建界面输入名称“信息采集智能体”，将上述提示词粘贴到“提示词”输入框作为系统提示词后点击创建，如图4-20所示。

2. 为提醒用户输入，需回到“我的”智能体界面，右键刚创建的智能体选择“编辑智能体”，如图4-21所示。

在编辑界面选择“预设消息”选项，点击右侧“添加”，配置默认提示消息，用于用户打开智能体时的提醒，如图4-22所示。

在“消息组”区域的“助手”输入框中设置预设消息：“请你输入需要查询的网站名称、查询内容和输出的数据格式例子”，如图4-23所示。

3. 因使用联网工具，可进一步细化联网配置。打开“设置”界面，找到“网络搜索”选项，如图4-24所示。可选择搜索服务商、设置搜索结果个数等，按需求保存。

4. 返回“我的”智能体界面，找到新建的“信息采集智能体”，在快捷菜单中选择“添加到助手”，如图4-25所示。

添加后可在“助手”界面看到该智能体，点击即可开始对话，如图4-26所示。

5. 在“话题”区域点击“默认话题”，在提示词区下方选择联网搜索模式，在首条提示后输入采集需求。测试需求如下：

> 在东方财富网，查询 GDP 数据，输出：年份，月份，GDP，增长率

图4-27 显示智能体已采集到相关数据并输出 Markdown 表格。

确认数据后，可点击会话界面的“复制”按钮复制内容保存，如图4-28所示。

搭建完信息采集智能体后，继续搭建数据分析智能体。

### 4.2.3 数据分析智能体：预测模型助手

数据分析智能体需支持用户上传已收集的数据文件，并完成清洗与分析。

如何写出提示词？可借助 Cherry Studio 完成编写。

#### 1. 智能体设计
在数据分析智能体中，“思考”模块需读懂用户上传的数据和结构，并理解常用分析方法，这部分由 Cherry Studio 的大模型完成；“行动”模块需接收数据文件，使用助手的文件功能。

##### (1) 文件上传
在助手会话界面，提示词输入框下方有一排功能按钮，其中曲别针图标用于文件上传，上传的文件会随提示词一起发送给大模型，如图4-29所示。

##### (2) 提示词智能体
若不熟悉数据分析，也可借助 Cherry Studio 的提示词智能体来设计。具体步骤：打开智能体列表，选择“编程”分类，找到“Prompt 工程草稿师”，如图4-30所示。

该智能体的作用是根据自然语言描述的需求，帮助生成智能体提示词。例如针对数据分析智能体，输入如下需求：

> 我要做一个数据分析智能体，功能包含数据清洗和数据分析，要提示用户输入具体的分析方法和输出格式。给我写一个提示词。

输入后即可自动得到专业提示词，如图4-31所示。

借助工具可快速获得专业级设计草稿，但仍需在草稿基础上调整。修改后的提示词如下：

[PRE1]
## OutputFormat:
按用户输出字段要求，输出Markdown表格。

## Initialization:
"您好，我是专业的数据分析智能体。请提供您需要分析的数据集，并指定：
1. 分析方法。
2. 输出格式要求。
我将为您提供完整的数据清洗建议和分析报告。"
