# 第 2 章 认识树莓派

## 2.1 树莓派是什么

树莓派由英国树莓派基金会推出，主打计算机教育的超精简主机。首款产品问世于2012年，到2019年6月第4代机型正式发布。体积小巧、价格亲民，却具备普通电脑的核心功能，很快在青少年编程教学中流行起来，成为入门编程的重要载体。

到目前为止树莓派已迭代四代，产品线主要分为A系列和B系列。随着版本升级，算力与扩展功能持续增强。

以本书成稿时2019年8月来看，市场上常见的树莓派主控板有主打极致便携的树莓派 Zero W/WH（见图 2.1）、功能相对精简的基础版第3代 A+ 型，也就是树莓派 3A+（见图 2.2），以及功能最为齐全的第3代 B+ 型，也就是树莓派 3B+。

## 2.2 树莓派 3B+ 主控板简介

本书案例均以应用最广的树莓派 3B+ 主控板作为控制核心。3B+ 于2018年3月14日发布，是3B的升级款，主要在无线连接与处理器性能上做了提升。

3B+ 的主处理器由4个1.4GHz主频的 Cortex-A53 核心构成，图形处理器为400MHz主频的 Broadcom VideoCore IV。性能虽不算强悍，但足以支撑小型机器人控制系统的开发。

接口方面，板载 HDMI 高清视频输出、3.5毫米音频输出、4个 USB 口，同时支持 Wi-Fi 与蓝牙无线连接。整体来看，小巧的机身里集齐了家用电脑的主要功能（见图 2.3）。

与普通电脑不同的是，3B+ 还额外提供类似单片机的40pin硬件引脚，其中包括21个输入输出口。这样既能当微型电脑用，也能直接连线控制外设。

## 2.4 Linux 操作系统简介

树莓派作为微型电脑可运行多种系统，官方系统 Raspbian 是基于 Linux 的发行版。

Linux 是全球知名的开源操作系统内核，最早发布于1991年。任何人都能免费使用并修改它。在其基础上集成应用后形成的定制系统通常称为 Linux 发行版。常说的 Linux 操作系统泛指这些发行版。

知名发行版有 Ubuntu、CentOS、Debian 等，Raspbian 正是基于 Debian 构建的。

Linux 内核也被用于移动端，最流行的安卓系统也是在其上开发的。

相较 Windows、macOS 等闭源系统，Linux 具有：
- （1）完全免费；
- （2）安全性与稳定性更高，系统资源占用相对较低。

不足之处在于：
- （1）图形界面较为简洁，使用体验不够便捷；
- （2）源于开源属性，部分商业软件没有 Linux 版本或功能受限。

因此 Linux 更适合需要长时间稳定运行的场景，如网络服务器、智能控制系统等。

# 第 3 章 Python 编程基础

## 3.1 什么是编程语言

当前人工智能很大程度上依赖计算机强大的算数与逻辑运算，但要让机器按人意执行，就需要精确控制计算机运行。

计算机的运算核心 CPU 由大量微型电路构成。硬件层面，计算机通过改变不同电路状态来驱动显示器、音响等设备执行指令。

数字电路的运行状态只有两种：高电平即通电、低电平即断电。通过海量微电路的高低电平组合，计算机能产生丰富状态实现电子控制。

把高电平记作 1、低电平记作 0，就可以用 1 和 0 的排列来设定电路状态（见图 3.1）。

图 3.1 用 1 和 0 来控制计算机的代码

像人与人交流需要自然语言，人与计算机交流也需要遵循特定规则的编程语言，才能准确传达意图（见图 3.2）。

由 1 和 0 排列的文本能被计算机直接读懂，这类语言称为机器语言。

但机器语言对人类极不友好——仅输出一个字母就需输入数位到十几位的 1 和 0。

为此人们用更接近自然语言的方式编写程序，再由预设的解释器将其翻译成机器语言驱动计算机。若 B 只懂英语不懂汉语，可先让翻译转述，解释器就相当于翻译（见图 3.3）。

即便如此，为保证准确翻译与机器可识别，编程语言仍需遵循严格规则，比自然语言更为死板。

## 3.4 Python 中的变量

前面提到，计算机通过大量 1 和 0 的排列存储信息。电子计算机把一切事物都存为 1 和 0 组合形成的数据，程序本质上是对这些数据进行操作，数据是程序的核心。

为方便处理不同数据，可在程序中建立变量来保存这些数据。变量拥有独立名称，其保存的数据即为变量值。

例如，A 班按周一到周五分5个值日小组轮换，每个小组由数名学生组成。每次值日由小组内一人负责。若把每次负责值日的同学视为数据，值日小组就是变量，具体同学即变量值。班主任只需指定小组，细节由变量值体现。
