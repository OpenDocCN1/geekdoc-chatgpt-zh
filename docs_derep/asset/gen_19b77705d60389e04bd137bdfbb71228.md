2.2.7 用 DeepSeek思路快速规范日期
Excel 只有按指定方式录入日期才会被识别为日期类型，否则会被当成普通文本，无法参与计算。官方能直接识别的日期写法主要有四类：用短横线连接的如“2024-4-1”“2024-5”；用斜杠连接的如“2024/4/1”“2024/5”；中文年月日写法如“2024年4月1日”“2024年5月”。

第3章 让表格更美观更专业

3.1 规划表格结构

3.1.1 合理合并单元格打造清晰结构
合并是调整版式的常用手段，可随时合并与取消。常用于标题区或一对多关系展示。

先输入基础数据，选中 A1:H1，点“开始”→“对齐方式”→“合并后居中”，标题即可横向跨列居中。同样选中 A3:A23 合并后居中，可实现纵向跨行效果。多处合并后整体更整洁。

3.1.2 调整行高列宽
行高列宽是规划版面的高频操作。把光标移至行边线，光标变为双向箭头时拖动即可增高。标题行适当增高并放大字体视觉更突出。

选中多行右键选择“行高”，在对话框输入精确数值如 16.5，点确定即可批量统一。列宽调整同理，指向列标识边线拖动即可。

专家提示
批量调行高或列宽时关键在准确选择范围，选中后操作方法与单行单列一致。

3.3 设置边框底纹美化表格
