# Excel × ChatGPT 数据处理效率实战

# 内容概览

进入人工智能时代，ChatGPT 作为一款面向大众的智能对话模型，已渗透到工作的方方面面。本书聚焦于如何借助这款工具，让 Excel 的数据处理、分析与计算变得更省心更高效。

全书共六章，整体脉络是从认识 ChatGPT 入手，到在 Excel 场景下学会高效提问，再到利用对话助手完成数据清洗优化、理解 Excel 函数的用法、生成可直接使用的公式，以及通过自然语言描述驱动 VBA 自动化。

这套方法适合日常重度使用 Excel 进行数据工作的职场人士；对 Excel 掌握不深、函数与分析思路还不够熟练的新人，也能从中快速补齐短板，提升工作效率。

# 前言

Excel 早已成为办公场景里的基础技能，熟练度直接影响工作产出。可对不少初学者和经验尚浅的同事来说，数据整理、分析逻辑、函数运算常是拦路虎，常见困扰就是学了忘、忘了用、用到卡。随着 AI 工具成熟，这些痛点迎刃而解。依靠 ChatGPT 的辅助能力，繁琐的数据处理可以显著提速。

ChatGPT 本质上是一个基于大语言模型的对话系统，通过自然语言来交互、解答并给出建议。我们可以这样理解它：哪怕你过去对 Excel 几乎不熟悉，只要用问答的方式沟通，就能把来自 ChatGPT 的结果直接应用到表格编辑中。这种过去难以想象的便捷学习与工作方式，如今已成为现实。

本书从 ChatGPT 的介绍开始，逐步展开它在 Excel 中的落地方法与提问技巧，并由浅入深讲解如何用它来辅助数据处理与计算，核心板块如下。

**1．数据整理**
Excel 分析的第一步是整理数据。手工清洗异常值、空值、重复项耗时耗力。借助 ChatGPT 的自然语言交互，可以迅速定位并清理问题数据，大幅提升整理效率。

**2．数据分析**
在对话中学习如何从表格里识别和抽取有价值的信息。ChatGPT 还能帮助标注重点、限制录入范围，并快速完成排序、筛选等操作。

**3．数据计算**
灵活的公式能让日常统计与分析更智能，但编写门槛让普通用户望而却步。本书精选大量办公实务案例，演示如何在 ChatGPT 中提出精准问题，获得可直接解决问题的方案。

**4．VBA 自动化处理**
编写 VBA 可以让 Excel 自动完成重复任务，但代码编写对大众并不友好。有了 ChatGPT，只需描述需求即可生成代码，复制粘贴运行即可，自动化门槛被拉低。

## **1.1**

## ChatGPT 概览与应用场景

[PRE1]
ChatGPT 由 OpenAI 研发，是一款基于人工智能技术的对话机器人。它依托海量训练数据构建模型，能够理解并生成类人语言，为用户提供智能问答、娱乐、教学、医疗等多种服务。随着持续学习与优化，其智能水平不断提升，能够更好地协助人们处理生活、学习与工作中的各类任务。

其应用范围相当广泛，主要集中在以下几类场景。

**1 客服与咨询服务**
可作为在线客服机器人，及时解答产品咨询、处理客户服务，提升满意度与忠诚度。

**2 教育培训领域**
能扮演在线辅导角色，为学生答疑解惑，为教师提供教学辅助，从而提高学习与教学效果。

**3 营销推广方面**
可充当营销智能助手，洞察用户需求与反馈，为企业提供营销建议与客户服务，提升推广效果与市场占有率。

**4 医疗和健康领域**
可为患者提供基础医疗咨询、病情说明、监测提醒与用药提示等服务。

**5 生活娱乐领域**
可作为智能语音伴侣，提供语音聊天、智能家居控制、游戏娱乐等功能，提升生活品质并缓解压力。

总体来看，ChatGPT 的功能覆盖面广，商业与社会价值显著。随着技术迭代，其服务将更智能、更便捷。

## **提示**
技术普及的同时也伴随风险。ChatGPT 的知识来源于预训练模型，对事实的把握存在局限，信息解读可能片面。使用时需注意隐私与安全，避免被误导性输出牵着走，建议批判性参考。合理且负责任地使用，才能让技术真正服务于人的发展。

## **1.2**

## 国内使用现状

[PRE2]
目前 OpenAI 尚未向中国用户开放官网权限，国内 IP 访问会被服务器拒绝，因此普通用户无法直接登录使用。

部分用户借助代理或 VPN 绕过限制，但存在安全、隐私泄露与合规风险，不建议采用。更稳妥的做法是通过国内合规的 ICP 授权渠道接入。

受限于访问障碍，国内涌现出不少替代平台，通过调用 OpenAI 的 API 接口实现对话服务。这些平台接口直连官方模型，响应来自官方服务器，同时使用门槛低、限制少，成为学习办公的常用选择。

本书选用国产平台 Chataa 作为教学载体。Chataa 功能完善、体验流畅，新用户注册即送 1000 次对话额度，免去次数焦虑。

平台支持创建专属智能体，类似官方的 GPT 功能。用户可“投喂”专属内容，打造贴合自身需求的私人助手，打破标准化问答的局限。

Chataa 在智能体定制上灵活性高，可设置基础回答，也能教授特殊技能，使其在不同场景表现更出色，增强个性化与互动乐趣。

此外，平台还支持 PDF 解析、语音输入、GPT-4 联网、绘图等能力，提供 GPT3.5 与 GPT4.0 双模式。本书主要以 GPT3.5 演示如何用 AI 简化 Excel 数据处理，帮助不熟悉表格操作的用户优化流程、提升效率。
