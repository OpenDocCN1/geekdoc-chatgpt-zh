##### 2. spaCy 实现命名实体识别
相比 NLTK，spaCy 更追求速度和工程化，支持词性标注、依存解析、命名实体识别和词向量生成，能快速处理大规模文本，适合实时场景。在 RAG 中，spaCy 特别适合文本清洗、知识抽取和基于实体的检索。

识别用户输入中的实体如人名、地名、组织名，有助于把握问题核心。下面演示如何用 spaCy 进行命名实体识别。

【例1-4】使用spaCy进行命名实体识别。
import spacy

# 加载spaCy的预训练模型
nlp = spacy.load("en_core_web_sm")

# 示例文本
text = "OpenAI developed the powerful language model GPT-4, \nwhich revolutionized AI research."

# 处理文本
doc = nlp(text)

# 提取并打印命名实体
entities = [(entity.text, entity.label_) for entity in doc.ents]

print("原始文本:", text)
print("命名实体识别结果:", entities)

#### 1.2.3 向量检索与模型：FAISS 与 Transformers 概述
FAISS 由 Facebook AI Research 发布，擅长大规模高维向量的相似度搜索；Transformers 库由 Hugging Face 提供，包含 BERT、GPT、RoBERTa 等预训练模型，可完成理解和生成。将两者结合，就能实现用户问题的向量化与高效检索，提升响应准确性和效率。

接下来介绍 FAISS 与 Transformers 的原理，并通过示例说明在 RAG 中如何做向量检索和模型处理。

##### 1. FAISS 工作原理与开发步骤
FAISS 专为大规模向量相似度检索设计，核心思路是通过索引和压缩降低高维搜索的复杂度。

FAISS 的关键包括向量索引 Indexing 和向量压缩 Quantization，使其在处理上亿级向量时仍保持高效。

典型开发流程包含：
- 向量生成：将文本数据向量化，例如使用 Transformers 中的预训练模型。
- 索引创建：创建索引并添加向量数据。
