## 进出口食品风险综合评定的深层考量

在进出口食品安全监管专家系统里，综合评定风险至关重要。虽说用集对分析里的多元联系数来做综合评价挺顺手、也合理，但把结果算成一个具体数值时，联系数自带的结构信息就丢了。所以下结论时，至少得把这层信息考虑进去。比如看表 9.3.4，活鲈鱼的农兽药残留、添加剂、生物毒素等指标明明是超高或高风险，可权重太小，让大权重指标给盖住了，综合结果成了中等风险。也就是说，综合评定出来的 M（中风险）里，可能还藏着部分指标的“高风险（L, H, HH, HHH）”。这正印证了 9.1 节说的成对原理（整体与部分成对存在）、同异反原理（同样评定为中风险，其子指标却有高低之分）和不确定性原理（不确定性表现多样，处置原则也不同，文中用置信度原则，其实也可用极值、效用原则）。显而易见，监管部门不光要看综合结果，还得看清局部高风险指标可能带来的危害。联系数的伴随函数、异反态势函数、势函数等，已为这类分析提供了具体手段，专家系统里得设相应模块处理这情况，文献[3]里也提了这思路。

## 9.4 集对分析在大豆病虫害诊断专家系统中的应用

大豆紫斑病是常见病害。卞世晖[4]用集对分析的不确定性推理，改进了安徽霍丘农垦农科所自研的诊断专家系统，大幅提高了准确率，具体如下。

### 9.4.1 研究概述

大豆紫斑病主要症状如下：

*   病种子种皮长浅紫至暗紫斑，轻时种脐周围呈放射状紫斑，重则大部甚至全皮变紫。
*   病种子种皮通常无光泽、粗糙、有裂纹。
*   成荚期豆荚病斑呈灰黑色，近圆形或不规则斑点。
*   发病期豆叶病斑为圆形紫红斑，后扩大成不规则褐斑，叶面有灰黑霉层及黑色小点。

常见防治法：

*   播前选抗病品种、无病种子，降低发病率。
*   加强田间管理，合理密植，及时排水，降低生长期发病率。
*   生长期可用药剂防治，如花后喷施 50%多菌灵可湿性粉剂 1000 倍液、70%甲基托布津可湿性粉剂 1000 倍液、50%苯甲特可湿性粉剂 2000 倍液。

通常诊断前，用户已知：种皮有浅紫斑且裂纹；生长期叶面曾现圆形紫红斑及少许黑点。据此可判断已患病害。

早期系统用最简单的可信度不确定推理模型，只支持用户信息与知识库**精确匹配**，实际常误诊。为此，卞世晖等引入集对分析不确定性推理模型改进推理机构，大幅降低误诊率。

### 9.4.2 基于集对分析的不确定性推理

**（1）用联系度重构知识库证据与规则表达**

令 E 为某知识，用联系度表示证据：$E:\mu_E=a_E+b_Ei+c_Ej$。
$ a_E $ 为真程度（1 为绝对真），$ c_E $ 为假程度（1 为绝对假），$ b_E $ 为证据可信度未完全确定的程度。

同理，将原基于可信度的规则 $R:E \rightarrow H \text{ IF } E \text{ THEN } H (\text{CF}(H,E))$ 重述为 $\mu_H=a_R+b_Ri+c_Rj$。
$ a_R $ 为前提真时结论真程度，$ c_R $ 为前提假时结论真程度，$ b_R $ 为前提出现时规则认知不全程度。不确定性因子 $i \in [-1,1]$，对立因子 $j=-1$。

用联系度表证据和规则，可见集对分析处理不确定信息的优势：能较好兼容概率与模糊信息。$i=0$ 时联系度表概率信息；$j=0$ 时表模糊信息。实际问题常兼具随机性与模糊性，卞世晖等将 $j$ 取值放宽至 $[-1,0]$，获取灵活性，以提高推理精度与速率。

**（2）三套推理机制同题测试**

把用户提供的症状分别输进三种机制的系统诊断。

*   **基于可信度的机制**：推出大豆灰斑病和紫斑病。对照背景知识，结果基本准确，给出防治法及背景介绍。
*   **基于集对分析的机制**：推出紫斑病和叶斑病。对照背景知识，结果更准，**首选即为紫斑病**，给出的防治法更合理有效，背景知识更全面。
*   **改进的集对分析机制（$j \in [-1,0]$）**：同样推出紫斑病和叶斑病，结果准确，防治法及背景知识也全面。

**速度对比（表 9.4.1）**：

| 名称 | 推理时间/ms |
| :--- | :---: |
| 基于可信度的不确定性推理 | 30074 |
| 基于集对分析的不确定性推理 | 30157 |
| 改进后的基于集对分析的不确定性推理 | 30069 |

可见：可信度机制最快，标准集对分析略慢，但**改进后的集对分析机制最快，优于另两者**，实现了精度与速度的双赢。

### 9.4.3 简评

专家系统擅长解决常规算法搞不定的复杂问题，但系统非一成不变，需持续迭代。本节虽简例，却说明把集对分析不确定性推理模型用于旧系统改进大有可为。前几章理论方法的演进，更拓宽了其在专家系统中的应用前景。

## 9.6 本章小结

从 60 年代首代专家系统至今，成千上万系统服役各领域，不确定性推理始终是核心挑战。集对分析对不确定系统中的各类不确定信息，秉持“客观承认、系统描述、定量刻画、具体分析”方针，可从不同角度用于专家系统知识储备、信息处理，尤其是推理模型与机制的改进完善。本章举 4 例，感兴趣的读者可查更多文献，也可结合专业尝试应用。

不过，从第 3 章智脑系统视角看，传统专家系统无论概念还是应用，都面临升级换代挑战。网络与云计算让任一专家系统均可成终端，大数据要求知识库持续扩充，计算与处理能力需跟进更新，故都需向智脑系统过渡。当万千专家系统改造成智脑系统并联网，新一代 AI 倡导的社会计算将成现实社会资源，智能社会加速到来。
