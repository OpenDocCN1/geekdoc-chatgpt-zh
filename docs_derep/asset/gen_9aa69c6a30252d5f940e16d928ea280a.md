# LangChain 对话记忆与检索增强实战

LangChain 做智能对话要解决两个问题：记住用户在不同轮次里提到过什么，以及把外部文档的知识点检索进来回答。本文用一套可直接跑的片段，演示如何自定义实体记忆、搭建 RAG 问答链，并让聊天记录参与推理。

### 自定义 spaCy 实体记忆

先实现一个简单的实体记忆类，遍历文档里的实体并累积原文。

        text = inputs[list(inputs.keys())[0]]

        doc = nlp(text)

        # For each entity that was mentioned, save this information to the

        # dictionary.

        for ent in doc.ents:

            ent_str = str(ent)

            if ent_str in self.entities:

                self.entities[ent_str] += f"\n{text}"

            else:

                self.entities[ent_str] = text
