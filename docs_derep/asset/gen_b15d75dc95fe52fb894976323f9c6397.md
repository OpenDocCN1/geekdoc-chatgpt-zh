## 3.5 本章总结

本章起初介绍了深度生成模型的核心思想，与判别模型相对，它致力于学习数据分布以生成新样本。主流深度生成模型大致可分为基于似然和基于能量两大类。

随后详细讲解了基于似然的变分自编码器 VAE。它在自编码器基础上假设编码后的特征向量服从简单分布，从而可以采样新特征生成全新样本。训练 VAE 需要同时优化重构损失与 KL 散度。条件 VAE CVAE 则引入条件信息，实现对生成结果的控制。

接着阐述了基于对抗训练的生成对抗网络 GAN。它由生成器与判别器构成，通过博弈不断提升生成样本的逼真度。GAN 衍生出多种变体，广泛应用于图像生成、风格迁移、图像编辑等任务。

随后介绍了对比语言-图像预训练模型 CLIP。它由预训练的图像编码器与文本编码器组成，能利用自然语言进行有监督学习，具有较好的迁移泛化能力。但 CLIP 也有局限，相比其他基线模型在不少数据集上表现并非最佳，从效果与投入角度看仍有提升空间。

最后介绍了基于隐空间扩散的 Stable Diffusion。它包含文本编码器、图像信息生成器和图像解码器，通过隐空间中的噪声预测实现图像的逐步扩散与去噪。训练集由在真实图像上添加不同程度噪声构建。Stable Diffusion 可实现文生图、图生图、图像修复、超分辨率等多种应用。

总体而言，本章系统梳理了深度生成模型的发展脉络、技术原理与应用现状，既涵盖基础知识，也呈现最新进展，对理解与运用该类模型具有重要参考价值。

# 预训练模型

真正带来 AIGC 能力突破式进展的是预训练模型，它打破了以往模型训练成本高、使用门槛高、效果难复现的困局，逐渐适配高精度、便捷、高质量的真实应用场景。近年来大规模预训练模型愈发普遍，但关于如何训练这些模型却少有人关注，通常由具备专业设备的企业或实验室完成训练并发布，随后中小企业与高校使用。即便如此，大模型应用仍有门槛，例如受限于机器配置，更优的大模型可能无法直接加载到显卡，或现有设备为单机多卡，需要通过分布式方法进行微调。

大规模语言模型训练面临两大挑战：显存效率与计算效率，两者源于模型参数量与训练数据量的庞大。显存效率方面，模型参数巨大，即使使用当前显存最大的 GPU 也难以满足。以 GPT-3 为例，其参数为 175B，按每个参数 4 字节计，需 700GB 显存存储参数；参数梯度所需显存与参数相等，约 700GB；使用 Adam 优化器时，还需额外 1400GB 存储优化器状态。总需求达 2.8TB，远超现有 GPU 能力。计算效率方面，大规模模型处理的数据量极大，操作数也极多，即使能将模型放入单张 GPU，训练时间仍极长。例如用 NVIDIA A100 训练 175B 的 GPT-3 约需 288 年，难以接受。

目前超大规模语言模型训练主要有两条技术路线：TPU + XLA + TensorFlow 与 GPU + PyTorch + Megatron-LM + DeepSpeed。前者由谷歌主导，因 TPU 与自家云平台 GCP 深度绑定，对非谷歌开发者不友好。后者获得 NVIDIA、Meta、微软等支持，社区活跃更受欢迎。本书主要采用第二种路线。

本章首先介绍大模型的涌现能力，随后分析模型参数量与通信数据量的估算，并介绍分布式训练中的常用并行优化方式，之后讲解 DeepSpeed 框架原理与使用，重点为零冗余优化器 ZeRO，最后介绍两个模型即服务平台，为大模型开发提供便利。

## 4.1 大模型的涌现能力

在介绍分布式训练前，需要明确为何要训练大模型。长期以来人们认为模型规模越大能力越强，但早期语言模型规模虽指数增长，性能增幅却是线性的，因此一度认为训练庞然大物意义不大。即使是最大的 GPT-3，在缺乏提示词时表现也可能不及精心训练的小模型，且大规模网络对数据需求与训练推理成本大幅增加。

随着新模型出现及对 GPT-3 的深入研究，发现大规模语言模型展现出超出预期的能力。当规模超过一定阈值后，性能提升不再与比例成正比，呈现量变引起质变。特别是大规模语言模型表现出“涌现能力”，即某些能力在小模型中不存在，只有在大模型中才可观察到，如语言理解、逻辑推理、语言生成等。涌现能力在信息科学、神经学、生态学、经济学、社会学等多个领域均有观察，但因其复杂性，目前难以定量解释。

### 4.1.1 缩放法则

缩放法则指出模型性能在很大程度上依赖于模型规模。具体而言，规模包含参数量、数据集大小与计算量，模型的表现以 Loss 降低为标准，会随着这三项的指数增长而线性提升，前提是其他两项未成为瓶颈，如图 4-1 所示。缩放法则意味着可通过提升参数量、扩大数据集来预测性地提升性能，也适用于微调过程。

缩放法则可用于预测性能，但模型扩大后在不同任务上的表现规律并不一致。许多知识密集型任务中，规模提升会带来下游表现提升；而在逻辑推理、数学推理或需多步推理的复杂任务中，性能在达到阈值前非常糟糕，接近随机水平，超过阈值后则显著提升，远超随机水平。这种突变现象即下一节要介绍的涌现能力。

### 4.1.2 涌现能力

尽管许多人希望自行训练 GPT-3 这类大语言模型，但因其惊人的 1750 亿参数，自主训练难度极大，且 GPT-3 自发布以来未开源，未来很可能维持该状态。

能否训练参数量为百亿的相对较小模型？正如前述，部分 AI 模型性能并非随规模增长而提升，而是在超过临界值后才显著提升。例如研究表明，只有当模型规模至少达到 620 亿参数时，才可能训练出思维链能力。

GPT-3 论文提出用提示词激发大模型能力，基本思想是给定一段自然语言指令，模型无需更新参数即可给出回复。例如 Few-Shot prompt，在提示中加入输入输出示例让模型推理。如图 4-2 所示，展示大模型在不同任务中通过 Few-Shot 的测试结果，横坐标为模型训练规模，用浮点运算数 FLOPs 表示，能更全面反映数据量、参数数与训练轮次；纵坐标为任务准确率。可以看出，在这些任务上，只有当模型规模超过一定临界值时性能才会显著提升，临界值以下即使规模增大性能也未提升。该临界值多位于 10^22 FLOPs 左右。

随着研究深入，为大模型添加提示词的方式愈加丰富。相比原始 Few-Shot，新方法增加了任务中间过程，例如思维链和 Scratchpad，通过细化推理过程提升下游任务性能，相关内容将在 5.1.2 节详细介绍。

在某些复杂任务中，增强提示可有效提高性能，具体包括数学问题求解、指令恢复、数值运算和模型校准等。因此不同任务可能需要不同的激发方式，需针对具体任务与模型选择最合适的方法。

模型大小与其性能密切相关，但并非观察涌现能力的唯一标准。涌现能力是多个相关变量的函数，除规模外，数据处理方法和优化算法等也会产生影响。例如在 BIG-Bench 任务中，LaMDA 需到 137B、GPT-3 需到 175B 才出现涌现，而 PaLM 在仅 62B 时已表现出该能力。

斯坦福研究者对大模型涌现能力提出质疑，认为这种涌现可能源于研究者选择的测量方法。具体来说，用非线性或不连续方法测量性能时涌现能力才会出现；若使用线性或连续测量方式，性能提升则表现为平滑、连续、可预测。

研究者进一步用 InstructGPT 与 GPT-3 系列进行测试，收集模型在两个算术任务上的数据。图 4-3a 中，x 轴为模型参数规模，y 轴为每个词的交叉熵损失，假设损失随规模增加单调递减。图 4-3b 中，y 轴为模型选对词的概率，随规模增加逐渐趋于 1。图 4-3c 中，若使用非线性评估指标如准确度，只有当一系列词汇都正确时才认为表现好，这会导致性能急剧、不可预测的变化，即涌现能力。图 4-3d 中，若使用不连续评估方式如多选题成绩，性能同样会急剧变化。而图 4-3e 中，从非线性或不连续评估切换到线性评估如词编辑距离，可看到性能呈现平滑、连续、可预测的改进。同样图 4-3f 中，从不连续评估切换到连续评估如 Brier 得分，也能观察到相同趋势。

总之，尽管 GPT-3 规模巨大且未开源，研究发现大模型性能涌现不仅依赖模型大小，还与评估方法有关。特定评估方法可能导致性能急剧变化，其他方法则表现为平滑与可预测。因此选择合适的评估方法并考虑更多因素对正确评估模型性能至关重要。

## 4.2 模型参数量估算

为更好地估算大模型显存占用，首先需分析训练过程中哪些部分消耗存储空间。Samyam 等人论文 “ZeRO: Memory Optimizations Toward Training Trillion Parameter Models” 提出，训练时主要空间占用分为两部分。首先是模型状态，包括优化器状态如 Adam 的动量与方差、模型参数及参数梯度。其次是剩余状态，包括中间激活值、临时缓冲区和不可用内存碎片。
