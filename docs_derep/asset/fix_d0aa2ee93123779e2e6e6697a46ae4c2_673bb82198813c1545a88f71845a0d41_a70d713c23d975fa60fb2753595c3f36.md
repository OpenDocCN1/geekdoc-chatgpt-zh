# 快速接入自定义域名

在域名服务商控制台新建一条 CNAME 解析。点击添加记录后把类型设为 CNAME，主机名填写 www 用来指向 www 子域名，记录值填写 cname.vercel-dns.com，确认保存即可。

再补充根域的 A 解析。再次添加记录，类型选择 A，主机栏输入 @ 表示主域名，解析值填写 76.76.21.21，保存完成。

(4) 验证域名连接。

DNS 修改后回到 Vercel 的域名设置页面，点一下 Refresh 刷新校验状态。配置无误时界面会显示绿色勾，表示已成功绑定。注意 DNS 全网生效需要传播时间，通常从数分钟到数小时不等。

Vercel 会自动为自定义域名申请免费 SSL 证书，访问时自动跳转到 https，且证书到期前会自动续期，无需人工干预。

**重要提示：** Vercel 默认的 vercel.app 域名在中国大陆无法直接打开。若主要用户在大陆，配置自己的域名是必须项。

绑定专属域名后，项目就拥有了独立网址。可以印在名片、写进简历、发布到社交平台。面试时展示 portfolio.myname.com 这类自定义地址，比使用默认的 vercel.app 链接更显专业。
