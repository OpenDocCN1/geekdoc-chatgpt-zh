# 第 8 课 奏响你的旋律

## 学习目标
1. 认识 `Micro：mate` 扩展板结构。
2. 掌握利用扩展板播放音乐的技巧。

## 硬件认知
`Micro：mate`（见下图）是 `Micro：bit` 的多功能 I/O 扩展板，集成大量 3Pin 接口兼容百余模块，自带 3.5mm 音频输出接口，背部防反接设计，仅需两颗铜柱即可快速固定。

[PRE22]

## 实战演练

### 硬件接线
1. 将 `Micro：bit` 与 `Micro：mate` 锁合（后续默认皆为合体状态）。
2. 通过 USB 连接电脑，喇叭/耳机插入扩展板 **P0 接口**（该口输出音频信号）。

[PRE23]

[PRE24]

### 编程作曲
1. **加载模块**：点击 **[PRE25]**，拖入 **[PRE26]** 与 **[PRE27]** 至编程区。

[PRE25]

2. **添加音符**：再次点击 **[PRE28]**，拖入 8 个 **[PRE29]** 积木块。

3. **选音定调**：点击积木块上的音符（默认 “低 C/C3”），虚拟钢琴弹出。琴键标识含义：**C/D/E/F/G/A/B** 对应 **Do/Re/Mi/Fa/So/La/Si**；数字 **3/4/5** 分别代表 **低/中/高** 音区。依次点击 **Do、Re、Mi、Fa、So、La、Si、高音 Do**，8 个音符参数自动配齐。

[PRE30]

4. **设节奏**：`Mind+` 支持 1、1/2、1/4、2、4 等拍值，根据曲风调整各音符时值。

[PRE31]

5. **上传试听**：烧录程序，即可听到完整音阶。

6. **声光同步**：将 “显示内置图案” 与 “播放音符” 积木块串联，上传后 LED 矩阵将随音符切换花样。

7. **按键点歌**：分别搭建下图两套逻辑，戴上耳机，按 A/B 键即可播放不同曲目。
