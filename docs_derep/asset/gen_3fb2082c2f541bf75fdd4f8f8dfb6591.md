开源硬件，指硬件运行原理、电路设计、物料清单以及所用软件如驱动源代码全部公开，信息可自由使用与分享。开源硬件倡导发挥想象与创造力，用软硬件实现构想。能将基于开源硬件的作品公开分享的人，被称为“创客”。创客的潜台词是思路要更宽、更广、更多。若创客在某一技术上达到极致，便从创客升级为“极客”。极客的潜台词是想得更深、做得更好。还有一类人，用开源硬件做出创新作品却不愿公开，而是将其商品化获利，这类人被称为“威客”。威客的潜台词是把好点子变现。

总之，软硬件信息公开且允许二次创作的，即为开源硬软件。如今开源硬件不仅有微型电脑、3D打印机，甚至还有拖拉机、抽水灌溉机。2017年，天上还出现了一颗开源气象卫星。严格说来，开源精神催生了开源软硬件，开源软硬件又催生了以创客与极客为代表的开源文化，而开源文化与开源精神的最终指向，可概括为“自由、创新、创造”。

### 第三节　树莓派运行环境的配置

要在树莓派上开发，首先要熟练使用设备。让我们从配置运行环境开始。

#### 活动一：通过有线网卡连接树莓派

树莓派3B+同时具备有线与无线网卡，可先用有线网络连接，再启用无线网络，之后即可无线控制。

1.将网线一端接树莓派网卡口，另一端接台式机或笔记本。
2.在电脑上共享上网，具体步骤：
找到无线网络连接，右键“属性”，在“共享”选项卡勾选“允许其他网络用户通过此计算机的Internet连接来连接”。

[PRE12]
图 1-1-6　个人电脑无线网络连接

注意：家庭网络需选择以太网“本地连接”。若无下拉选项，请重启。

3.设置本地连接IP地址：
按实际情况设置，本例设为192.168.137.1，子网掩码255.255.255.0。
4.查找树莓派IP地址
按`WIN+R`打开“运行”，输入`cmd`进入命令行，再输入`arp-a`查看网络地址，通常192.168.137.1下第一个地址即为树莓派，如图1-1-7红框所示。

[PRE13]
图 1-1-7　在命令提示符下查看树莓派网络地址

确认网卡IP后才能进行后续操作。若找不到，可用`IPScanner`扫描。亦可修改SD卡中`cmdline.txt`，加入`ip=XXX.XXX.XXX.XXX`设为静态IP，但需让电脑本地连接静态IP与树莓派同网段。

另一种更简便的方法是直接把树莓派用网线连向无线路由器，再从电脑登录路由器查看树莓派自动获取的IP。获取IP后同样可远程控制，方法如下。

确认IP无误后，可启动`putty`工具连接并控制树莓派。运行效果如图1-1-8所示。

#### 活动三：启用树莓派的 SSH 和 VNC 服务

连接不成功通常意味着未启用SSH服务。启用方式是在根目录下新建无后缀空白文件并命名为`ssh`。

SSH允许通过网络远程管理树莓派，VNC可登录图形界面，像操作Windows一样使用。因此两者需启用。启用VNC步骤如下：

在图1-1-9终端中输入`sudo raspi-config`进入系统配置界面，如图1-1-10所示。

依次操作：Interfacing Options→VNC→Yes。系统会提示是否安装VNC，输入y后回车，等待安装完成即可。

也可直接在终端输入`sudo apt-get install tightvncserver`回车安装。

#### 活动四：用 VNC Viewer 登录树莓派的桌面

安装完VNC后即可用远程桌面工具登录。但需先临时启动服务。仍在图1-1-9终端输入`tightvncserver`回车启动，当前为临时启用，后续再设为开机自启。

在电脑安装VNC Viewer，打开后点File→New connection，弹出Properties，在VNC Server填入树莓派IP及服务号，服务号通常为1，Name可填设备名，点击OK，如图1-1-12所示。
