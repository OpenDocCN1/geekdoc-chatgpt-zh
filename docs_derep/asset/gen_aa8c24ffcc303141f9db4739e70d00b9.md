PDF 的读取逻辑是打开二进制文件，用 PyPDF2.PdfReader 加载后逐页调用 extract_text，把每页内容拼接成一个完整字符串返回。

    :return: PDF 文件中的文本内容

    """

    with open(file_path, 'rb') as file:

        reader = PyPDF2.PdfReader(file)

        text = ""

        for page_num in range(len(reader.pages)):

            text += reader.pages[page_num].extract_text()

        return text

Markdown 的处理先以 utf-8 读取源码，通过 markdown 库转成 HTML，再用 BeautifulSoup 抽取出纯文本，最后用正则把 http 开头的链接清掉返回干净的文本。

@classmethod

def read_markdown(cls, file_path: str):

    """

    读取 Markdown 文件内容，并将其转换为纯文本。

    :param file_path: Markdown 文件路径

    :return: 纯文本内容

    """

    with open(file_path, 'r', encoding='utf-8') as file:

        md_text = file.read()

        html_text = markdown.markdown(md_text)

        # 使用 BeautifulSoup 从 HTML 中提取纯文本

        soup = BeautifulSoup(html_text, 'html.parser')

        plain_text = soup.get_text()

        # 使用正则表达式移除网址链接

        text = re.sub(r'http\S+', '', plain_text)

        return text

普通文本文件就更直接，utf-8 打开后直接返回全部内容。

@classmethod

def read_text(cls, file_path: str):

    """

    读取普通文本文件内容。

    :param file_path: 文本文件路径

    :return: 文件内容

    """

    with open(file_path, 'r', encoding='utf-8') as file:

        return file.read()

除了 txt、md、pdf 这类通用格式，RAG 有时还要消费已经分类好的结构化知识，例如 JSON 语料或知识库条目。为此单独封装一个 Documents 助手，专门从本地加载预分类的 JSON 文件。

class Documents:

    """

    文档类，用于读取已分好类的 JSON 格式文档。

    """

    def __init__(self, path: str = "") -> None:

        self.path = path

    def get_content(self):

        """

        读取 JSON 格式的文档内容。

        :return: JSON 文档的内容

        """

        with open(self.path, mode='r', encoding='utf-8') as f:

            content = json.load(f)

        return content

4.1.5 词向量数据库与向量检索模块

进入 RAG 核心环节，需要把文档块转成向量并实现检索。向量库负责保存片段与向量表示，检索模块则根据用户 query 找到最相关的片段。为了让系统可复用，关键能力包括：

- 持久化存储 persist，把数据库落地到本地，方便下次直接加载使用。
- 加载数据库 load_vector，从本地文件恢复已有的向量与文档。

4.1.6 大模型问答模块编写

向量检索完成之后，就要让大模型基于检索结果生成答案。先抽象一个基类 BaseModel，统一 chat 和 load_model 两个接口，chat 负责接收用户输入并返回答案，load_model 用于本地模型加载，API 模型则可省略实现。

1. 大模型模块的基类

首先编写一个基类BaseModel，该基类主要包含两个方法：chat和load_model。其中，chat负责处理用户的输入并生成回答。如果使用本地模型，load_model负责加载模型。如果使用API模型（如OpenAI），可以不用实现该方法。
