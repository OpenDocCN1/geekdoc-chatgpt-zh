**错误监控与告警**

前端应用上线后，代码都会被压缩混淆。要让 Sentry 能把崩溃精确定位到原始源码，需要在构建流程里自动上传 Source Maps。上传完成后，异常就能映射回可读的行号，排错速度会大幅提升。

警报要配得有意义。建议在 Sentry 后台为项目设规则，比如同一类新错误一小时内出现超过 5 次就发邮件。这样能第一时间抓住影响面大、需要紧急处理的故障。

### 内容管理：Keystatic 与 Sanity 的选择

产品跑起来后，文章、营销文案之类的内容会频繁变动。没人想为改一个错别字就全站重新部署，这时就需要一个内容管理系统。

无头 CMS 的思路是把内容创作和管理与前端展示拆开，内容通过 API 供应给任意前端。选 Keystatic 还是 Sanity，本质上是内容存哪、谁来编辑的战略判断。

#### Keystatic：随代码走的 Git 方案

Keystatic 把内容当成代码的一部分，使用 Git 作为底层。所有内容以 Markdown 等结构化文件保存在 GitHub 仓库里。主界面示例如下：

[PRE0]

编辑在界面保存文章时，后台会自动生成一次 Git 提交并推送到仓库，随后触发 Vercel 自动部署。好处是内容与代码统一在 Git 里，有完整的版本记录，数据所有权清晰，而且项目本身开源免费。适合开发者主导的场景，比如技术博客、产品文档。

#### Sanity：以 API 为核心的协作平台

Sanity 把内容视作独立于代码的可协作数据，存在 Sanity 提供的托管实时数据库中，通过 API 访问。主界面示例如下：

工作方式体现在三方面。编辑在 Sanity Studio 这个高度可定制的编辑环境里修改内容，改动实时落库，应用可在运行时通过 API 拉取最新内容，无需重新部署。平台支持实时协作、对非技术人员友好、发布与代码部署解耦速度更快，并且鼓励结构化、可扩展的内容建模。免费额度比较宽松：最多 20 个席位、1 万个文档、每月 100 万次 API CDN 请求。

#### 实战建议

判断主要编辑者是核心。开发者为主时 Keystatic 的 Git 原生流更顺滑；市场、运营等非技术团队负责时，Sanity 的编辑体验和协作能力更合适。

再看更新频率。频繁更新的内容适合 Sanity 的解耦模型；更新不多的内容，Keystatic 触发的自动部署已经够用。

无论选哪家，都建议从结构化角度规划。把内容拆成标题、摘要、作者这类有意义的小块，为后续复用和灵活性打基础。

### 支付：Stripe

产品商业化需要可靠收款，自行处理信用卡信息成本高且风险大。Stripe 是互联网支付的基础设施，主页面如图3-11所示，提供一套完整的 API 与工具，帮开发者安全便捷地接收全球付款，并把加密、防欺诈等复杂性封装好。

#### 按需付费

对初创团队最友好的是它的计费方式。标准支付没有开户费、月费，只在成功交易时收取少量服务费，成本随收入同步增长。

[PRE2]

标准费率举例：线上境内银行卡通常为成功交易金额的 2.9% 加 30 美分，具体因地区而异。需要注意的是争议退单也会产生额外处理费，属于运营成本。

#### 实战建议

用 Stripe Checkout 或 Stripe Elements 是安全底线。不要让卡号等敏感信息经过自己的服务器。Checkout 是 Stripe 托管的现成支付页，上线最快；Elements 是一组可嵌入的组件，能在自有站点做定制表单，同时保持 PCI 合规。

上线前务必在测试模式演练。Stripe 提供完整的测试环境和多组测试卡，完整走一遍成功和失败流程，确保异常处理正确。

务必接入 Webhook。Stripe 在订阅续费成功等事件发生时会向你的服务器推送通知。仅靠前端跳转确认支付不可靠，Webhook 才是保证系统状态与 Stripe 最终一致的可靠方式。

## 3.2 拥有你的数字身份：购买与配置域名

在互联网拥有独一无二的在线家园，是建立品牌的关键。就像现实住宅需要门牌号，数字家园也需要域名，让别人轻松找到你。域名不仅是地址，更是数字世界的名片，是构建身份的起点。概念虽简单，操作并不复杂。

### 3.2.1 什么是域名

类比为互联网上的家：

网站需要「土地」，即网站托管或虚拟主机，是运转的基础，如房屋地基；有了土地，还需要唯一的「地址」，即域名，访客通过它精准找到网站。二者缺一不可。例如百度域名是 baidu.com，epubit.com 也是专属门牌，用户在浏览器输入域名即可访问。

#### 1. 域名与 IP 地址的关系

幕后每个网站都对应一串数字 IP，如 192.153.xxx.xxx，就像房屋的经纬度，精确但难记。域名系统 DNS 充当翻译官，像庞大的地址簿，把难记的 IP 转换成易懂的域名。用户输入 godaddy.com 时，DNS 迅速解析出对应的 IP 并引导访问，大幅简化操作，提升体验，也提高回访率。

#### 2. 域名的构成

主要由两部分组成。

第二级域名 SLD 是用户可自定义的部分，通常在 www 后，如 godaddy.com 中的 godaddy，是体现品牌个性的关键。

顶级域名 TLD 是后缀，相当于类别或地区标识。分为三类：
通用顶级域名 gTLD 最常见，.com 多用于商业、.org 多用于非营利、.net 多用于网络服务，其中 .com 最受信任。
国家代码顶级域名 ccTLD 代表特定国家或地区，如 .us、.uk、.cn，面向区域受众时更有优势。
新通用顶级域名 new gTLD 近年出现，如 .photography、.media、.shop、.ai、.store、.app，可让域名更具特色并直观体现业务。

注意域名不等于 URL。域名是主地址如 google.com，URL 是详细地址，包含协议、域名和路径，如 https://www.godaddy.com/help/...，域名是 URL 的组成部分。

网站还可使用子域名，如 blog.example.com 或 shop.example.com，用于划分功能区，或搭建开发、测试环境。

#### 3. 拥有专属域名的价值

专属域名是数字世界的长期战略投资，远超网址本身。

建立专业品牌形象：yourname.com 这类自定义域名能快速提升专业度和可信度，传递严肃信号。
提升信任感知：清晰易记的域名给潜在客户好印象，而 yourbusiness.hostsite.com 这类免费子域名显得不正式，易引发不信任。
掌控在线身份：拥有自己的域名意味着完全掌控网站外观、内容和呈现方式，不受第三方平台规则束缚。
