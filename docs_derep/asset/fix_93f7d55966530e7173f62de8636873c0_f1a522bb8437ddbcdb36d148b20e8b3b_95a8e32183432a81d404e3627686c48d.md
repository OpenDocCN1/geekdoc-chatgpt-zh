## 4.3 小结

本章围绕 GPT-4 与 ChatGPT 的进阶玩法展开，给出了提升 LLM 应用开发效率的关键建议。

## 5.1　LangChain 框架概览

LangChain 专为 LLM 应用开发而设计，相比第 3 章的示例代码，集成后更简洁，还提供大量附加能力。

安装只需执行 `pip install langchain`。

> [PRE9] 书写当时 LangChain 仍处 beta 阶段，版本号为 0.0.2*XX*，发布节奏很快，使用前请留意功能变动。

图 5-1 展示了框架的核心模块。

[PRE10]

**图 5-1：LangChain 框架的关键模块**

各模块简述如下。

> `Models`（模型）

　　该模块提供统一接口接入各类 LLM，支持 OpenAI、Hugging Face、Cohere、GPT4All 等提供商。

> `Prompts`（提示词）

　　提示词已成为 LLM 编程的新范式。该模块提供管理提示词的工具。

> `Indexes`（索引）

　　该模块让你能够将 LLM 与私有数据结合使用 1。

1 截至 2023 年 12 月 2 日，LangChain 已将 `Indexes` 模块改名为 `Retrieval` 模块。——译者注

> `Chains`（链）

　　提供 `Chain` 接口，可将多个模型或提示词串联成调用流程。

> `Agents`（智能体）

　　引入 `Agent` 接口，智能体能接收用户输入、做决策并调用合适工具，迭代执行直到任务完成。

> `Memory`（记忆）

　　跨链或跨智能体调用间保持状态。默认情况下链和智能体都是无状态的。

文档中列出了众多集成，多数需要 API Key。对 OpenAI 模型，可在环境变量 `OPENAI_API_KEY` 中配置，如第 2 章所述。

### 5.1.2　智能体及工具

智能体与工具是 LangChain 的核心能力，能让应用调用外部功能、解决复杂问题。

这里的“工具”是对函数的封装，便于语言模型调用。智能体可借助工具与外部世界交互，每个工具都有文本输入和文本输出。LangChain 内置了谷歌搜索、维基百科搜索、Python REPL、计算器、天气 API 等工具，完整列表见文档。开发者也可以自行构建自定义工具加载到智能体，灵活性极高。
