## 3.3 LlamaIndex 是什么

在以大模型为核心的开发领域，LangChain 并非唯一选择。LlamaIndex 也是口碑不错的开源框架，2022 年 11 月发布，与 ChatGPT 同期上线，比 LangChain 晚一个月左右。两者都受 ChatGPT 推动并被广泛采用。

### 3.3.1 背景与定位

该项目由 Jerry Liu 创立，2023 年 6 月完成 850 万美元种子轮融资。它的价值在于弥补了大模型训练时缺乏外部知识的缺陷，因此在社区里获得关注。

与 LangChain 的“大而全”不同，LlamaIndex 更聚焦 AI 驱动的先进 RAG 技术，以及多租户 RAG 系统的搭建。基于它的企业方案致力于消除技术与安全障碍，提升企业对数据的利用和服务能力。工作重心不仅在技术研发，也强调落地到具体业务场景，提升运营效率与用户体验。

> 小雪：多租户具体是什么？
> 
> 咖哥：在同一个 RAG 系统里，用户 A 和用户 B 各自拥有独立的文档库。多租户机制确保 A 发出查询时只读取自己的资料，不会被 B 的数据干扰，反之亦然。这是数据隔离与安全的基础。

另外，LlamaIndex 在文档结构与可执行性上相对 LangChain 更友好，这体现了其在体验、接口与工程实现上的投入。对开发者与最终用户都有帮助，有利于推广与提升使用效率。

LangChain 功能过于庞大，面面俱到反而显得臃肿，细节打磨不足。其 GitHub 页面未解决的 Open Issues 超过一千条。所以如果核心诉求是检索与生成增强，选择“小而美”的 LlamaIndex 更合适。

### 3.3.2 RAG 驱动的开发

RAG 已成为 AI 应用开发的重要分支，与 Agent 同等关键。其本质是检索加生成：先从数据源取出相关信息作为上下文注入查询，再由大模型基于丰富提示生成答案。RAG 应用本身也可视作一种 Agent，或作为 Agent 构建的核心技术。

宏观来看，大模型落地到特定行业，从难到易大致有四种方式：从零训练、微调、动态提示——RAG 属于此列、以及最简单的提示工程，见图 3.18。RAG 处于中间位置，比重训或微调更轻，比直接提问更复杂。它规避了微调的三大痛点：成本高、信息更新困难、可观察性差。RAG 无需训练成本更低；数据实时获取保持新鲜；检索文档可展示，结果更可信。

组成要素如下：

- 数据连接器：从原始来源抽取数据，API、PDF、SQL 等均有读取接口。
- 数据索引：将数据转为大模型易懂的中间表示，如词向量。
- 引擎：提供自然语言访问。查询引擎是强检索接口，用于增强知识输出；对话引擎支持多轮交互；数据 Agent 由大模型驱动的知识工作者，可实现辅助到 API 集成。
- 应用集成：将 LlamaIndex 接回其他生态。

RAG 与 Agent 紧密关联。LlamaIndex 通过 RAG 管道、框架与工具，为 Agent 补足可控性与透明度短板。其 Agent API 支持逐步执行，可处理更复杂任务。同时在 RAG 循环中支持用户反馈，适合长期任务，实现用户与 Agent 交互及中间执行控制的双循环。

总共 6 步。

1. 用户提出查询：用户向系统提交问题或请求。
2. Agent 搜集相关信息：根据查询检索相关信息，可能来自互联网或特定数据库，企业内数据通常存于向量库。
3. 检索信息：从搜索结果中提取具体信息，作为生成回答的上下文。
4. 传递给大模型：把检索结果与原始查询一起交给大模型。
5. 大模型生成响应：利用信息生成丰富且信息化的答案。
6. 返回结果：把大模型生成的答案交还用户，基于原始查询与检索信息生成。

过程也可循环，每次查询会优化后续交互。如需更多信息或有追问，系统会提示额外查询，并利用前次回答丰富新上下文。这样提供更动态、交互式的体验，让用户用自然语言完成复杂交互。

借助 LlamaIndex 搭建上述基于 RAG 的 Agent 很轻松。它面向新手到资深开发者，高级 API 允许初学者用 5 行代码完成数据提取与查询；底层 API 则让高级用户按需定制与扩展。

## 3.4 小结

OpenAI 等大模型厂商的创新，为开发者构建类 Agent AI 应用提供了新工具，推动 LangChain、LlamaIndex 等生态发展。这些工具各有侧重，但都致力于更高效灵活的 AI 应用开发，从而推动行业创新与协作，带来更丰富场景和更强开发能力。

两者各具特色：LangChain 是“大而全”，LlamaIndex 是“小而美”。它们既竞争又合作，可相互调用。竞争促使其不断优化，合作则让整个生态更进步，最终让开发者和用户受益。

随着大模型技术持续演进，这些工具也在不断迭代。它们让构建复杂智能 Agent 成为可能，并不断拓展 AI 的边界和应用领域。

借助这些工具，我们能打造更智能、更高效的 Agent，在各种复杂环境中执行任务和提供服务。随着技术进步，会有更多创新应用出现，推动人工智能边界持续拓展。

当然，大模型应用开发仍处“婴儿期”，开发者和组织面临诸多挑战：API 调用频率与性能、程序稳定性与效率、未来可扩展性与维护，以及数据隐私、安全、伦理与效率等问题。同时机遇也巨大，可以创造更智能、更有用的工具和服务，为各行业带来变革。
