LoRA 轻量微调 ChatGLM-6B 实现 SPO 抽取

想让大模型具备结构化信息抽取能力，却不想支付全量微调的算力成本，LoRA 是一种常见折中方案。下面以 ChatGLM-6B 为底座，演示如何用低秩适配让模型学会从句子中抽取主谓宾三元组，整套流程可在本地复现。

模型加载与适配
本地保存的 6B 权重先被装入自研的 XiaohuaModel 包装类，随后挂载已提前保存的 LoRA 配置，输出可训练参数规模以确认注入位置。随后模型切到半精度并搬到 GPU，确保显存占用可控。

提示与数据构造
任务提示被固定为要求模型依据既定模板从输入段落中产出结构化结果，后面接文本占位符。数据方面调用项目工具读取 spo_0.json，使用相同 48 的输入输出截断长度完成分词编码，得到序列到序列样本，再包装成 Seq2Seq 数据集。数据加载器采用两条为一组、不补齐、项目自带的合并函数、单进程读取的设置。

训练环境配置
训练统一交给 Accelerate 管理设备与梯度同步。优化器选用 AdamW，初始步长 2e-5，一阶动量 0.9 二阶 0.999，eps 1e-5。学习率调度使用余弦退火，周期上限 2400 步，最低下限 2e-6，从初始状态启动。模型、优化器、数据迭代器、调度器一并经过加速器封装。

训练循环
共进行 20 个轮次，每轮用进度条展示。每个小批先把输入 id 与标签搬到显存，调用前向得到损失，由加速器完成反向传播，随后依次执行参数更新、学习率更新、梯度清零。进度条实时呈现当前轮次、训练损失以及学习率放大千倍后的数值。每训练三轮即把当前权重写回 ./glm6b_peft.pth，便于中断恢复。

def forward(self,input_ids,labels = None,position_ids = None,attention_mask = None):
    logits,hidden_states = self.glm_model.forward(input_ids=input_ids,position_ids = None,attention_mask = None)
    loss = None
    if labels != None:
        shift_logits = logits[:, :-1, :].contiguous()
        shift_labels = input_ids[:, 1:].contiguous()
        # Flatten the tokens
        logits_1 = shift_logits.view(-1, shift_logits.size(-1))
        logits_2 = shift_labels.view(-1)
        loss = self.loss_fct(logits_1, logits_2)
    return logits,hidden_states,loss
