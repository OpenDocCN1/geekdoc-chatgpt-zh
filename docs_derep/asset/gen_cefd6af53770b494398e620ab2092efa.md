# 贝尔曼方程原理

状态价值函数与动作价值函数均以累积折扣回报衡量长期收益，这种方式契合在线机器学习中通过不断试错来学习的场景。

在马尔可夫决策过程中，策略 π 下的状态价值函数 V_π(s) 可写成递归形式，由此得到的式子即为贝尔曼方程。该方程可以用状态 s、动作 a 以及下一状态 s' 来表达，具体如图8-12所示。

时刻 t 的价值由即时回报 r_{t+1} 与下一状态的价值 V_π(s') 共同决定，二者可借助函数拟合技术进行近似估计。常用的求解手段包括 SARSA 算法、Actor-Critic 算法以及 Q 学习等。

# Q学习方法

强化学习里典型的代表是 Q 学习，如图8-13。该方法通过对最优动作价值函数 Q*(s, a) 的 Q 值进行估计来推导出最优策略。

最优策略 π* 会指引我们挑选动作价值最大的动作。下一状态的 Q 值与实际 Q 值之间的差异用时序差分误差 δt 表示，该误差通常不会收敛至零。

把时序差分误差乘以学习率 α，0 < α ≤ 1，即可得到趋向平衡的更新冲量。α 越大更新越快，但稳定性容易受损，实践中常取 0.1 左右。

[PRE5]

Q 学习本质上是通过让时序差分误差趋于零来逼近最优动作价值函数的 Q 值，策略的寻找则需要另行考虑。

为充分利用学习成果，通常会选择 Q 值最大的动作。基于这一选择标准衍生出以下几种策略。

- 贪心算法

贪心算法又称贪婪算法，求解时总是挑选当前 Q 值最大的动作，如图8-14。

δ(a, b) 为克罗内克函数，又称克罗内克 δ 函数。贪心策略只做当下最优选择，即使存在可能带来整体更优的其他动作也不会去探索，属于不考虑全局最优的停止思考式选择。

[PRE6]

- 随机化算法

随机化算法依托随机搜索，会随机挑选动作，因而累积折扣回报也呈现随机性，无法得到最大值。

# □ ε-贪心策略

ε-贪心算法即随机贪心策略，它融合了随机化与贪心两种思路。以概率 ε 进行探索，以概率 1−ε 采用基于知识的贪心方式挑选当前最优动作，通过调节 ε 来平衡探索与利用的权重，如图8-15。

# □ 玻尔兹曼采样策略

玻尔兹曼选择算法引入逆热力学温度系数 β，如图8-16。相较于 ε-贪心在概率 ε 下完全不考虑 Q 值大小，玻尔兹曼方法会让 Q 值越大的动作被选中的概率越高、Q 值越小的越低，可视为 ε-贪心的改进。β 越大贪心特性越强，β 越小随机性越强。

# 源域与目标域自适应

假设有一个在某任务上训练得很好的分类器，表现优秀且看似可迁移到新任务中。但两个任务并不完全相同，分类器的泛化能力有限且缺乏大量训练样本。此时可采用迁移学习。

迁移学习是指将一个或多个任务中学到的知识用于高效构建新任务有效假设的问题，即为高效完成新任务而复用其他任务的训练数据与结果。这一类方法统称为域自适应。

已学习任务的知识与分类器所在领域称为源域 source domain，对应的新领域称为目标域 target domain。源域与目标域既有共性也有差异，迁移学习的目标是充分利用源域信息，获得贴合目标域且准确度高的分类器。

例如，源域可以是一个日语语言模型，可作为日英翻译模型构建的素材使用，如图8-17。

迁移学习即把源域知识用于目标域的新任务。其名称多样。

# 激活函数选择与梯度消失

神经网络早期常使用单位阶跃函数和 Logistic 函数作为激活函数，随着输出层输出增大，最终输出会收敛到 1。

在深度学习场景下，上述函数难以完成有效学习。深度学习更常用修正线性单元 ReLU，也称为斜坡函数。

2011 年泽维尔等人提出，相较于双曲正切函数和 softplus 函数，ReLU 作为激活函数效果更佳。

Sigmoid 与双曲正切函数的导数包含原函数本身，而 ReLU 的导数仅为 0 或 1，计算简便。此外，在深层网络的前向与反向传播中，Sigmoid 反复运算后易导致权重发散或梯度变为零，即梯度消失问题 vanishing gradient problem，因此现多采用 ReLU 作为激活函数，如图9-2、图9-3。

# 训练误差vs测试误差

学习过程中，训练误差表示分类器实际输出与标注数据之间的差异，如图9-5 左图。构建分类器时需最小化训练误差。以迭代次数为横轴、误差为纵轴绘制的曲线称为学习曲线。

训练集上的误差为训练误差，总体样本上的期望误差为泛化误差。为评估分类器性能，需要知道其在新样本上的误差，即泛化误差。

由于新数据准备困难，通常用测试数据的测试误差来近似泛化能力，如图9-5 右图。

# 网络训练优化手段

神经网络训练中常见的改进如下。

- 数据归一化

基于均值与方差对数据进行标准化，也称数据规范化或标准化。常见做法是使均值为 0，或使方差/标准差为 1。

数据白化指将特征间相关性降为 0 的操作。

- 数据增强

在图像识别中，通过平移、镜像、旋转、对比度变换、颜色变换以及噪声扰动等操作扩充训练样本，以提升模型对低质量图像的识别精度。

- 多模型融合

构建多种结构不同的神经网络分别训练，通过模型平均 model averaging 提高泛化能力。这与集成学习类似，使用 Dropout 也能达到相近效果。

- 学习率设定

随着训练进程逐渐降低学习率，或为不同层设置不同学习率，均可提升效率。还有自适应为每个参数分配学习率的算法，如 AdaGrad，其更新量变换公式如下所示。

# 预训练策略

多层网络训练中易出现梯度消失，导致深层无法训练，网络越深越明显，其根源在于权重参数的随机初始化。可借助预训练解决该问题。

预训练时，多层神经网络从输入层开始逐层拆分为 RBM 式的两层结构，通过无监督学习确定初始值，本质上是把拆分后的网络作为自编码器处理，最后输出层权重随机设定。这样输出层之前的多层网络可作为特征提取器使用，从而避免梯度消失，顺利完成训练。

# 自编码器原理

自编码器是一种捕捉数据特征并进行特征表达的前向传播网络。训练数据先输入网络第一层得到一次输出，再以该输出作为第二层输入得到再一次输出，最终复现原始训练数据，如图9-10。自编码器属于无标记数据的无监督学习，结构与 RBM 相似，可用于预训练。

编码器即输入层，受限玻尔兹曼机中的可见层，先通过 y = f(Wx + b) 得到数据特征，即中间层、隐藏层的特征表达，再构建输出层，使其单元数与输入层相等，用调整后的权重 Ŵ 与偏置 ē 作为解码器参数进行计算，从而实现训练数据的复现。

若中间层单元数与输入/输出层相等，或 WW̃ = I，即单位矩阵，则输入到输出变为恒等映射，无法实现“用较少特征表达原始数据”的目的。因此中间层单元数需小于输入层。此时使误差函数最小的 W 与 Ŵ 本质上等价于无标记数据的主成分分析。

# 稀疏编码思想

对人类、猴子、猫等生物的实验表明，视觉信息经滤波器筛选后传递到大脑皮层特定视觉区从而被识别。

若向量或矩阵中绝大多数元素为 0，则称其为稀疏向量或稀疏矩阵。例如将图像作为网络输入时，通过加入正则化项可获得图像的稀疏表示，从而在计算图像特征向量时验证大脑初级视觉皮层的局部性、方位选择性和空间频率选择性。由此提出假说：大脑存在以少量神经元表达复杂外部信息的机制，这即是稀疏编码。

分析稀疏数据需搜索非零元素的位置与数值，属于计算量巨大的 NP-hard 问题。但若数据特征可稀疏表示，则能实现有效的特征提取与数据压缩。

在深度学习中，复杂输出也可能对应网络内部的简单特征表达。因为让绝大多数元素置零，使有效特征稀疏，可大幅提升模型的泛化能力与预测计算效率。稀疏编码在以深度学习为代表的机器学习领域占据重要地位。
