关键在于 Embedding 模型。它能够把私密资料转化为模型可读的向量表示。简单来说，Embedding 会借助特定算法把文本、图片等内容转成一组数字向量，向量中保存了资料的语义特征和关键信息。模型随后做相似度匹配。提问时，问题也被转成向量，在由私密资料构成的向量库中检索最相关的片段，基于这些片段生成更准确的答案，从而解决直接提问通用模型无效的问题。

# 第3章 DeepSeek高效协作指南

## 提问得当，激活模型潜能

在当下，DeepSeek 可以被视作一个“超级大脑”，在信息获取和问题解决上作用明显。不少人认为 DeepSeek 是推理型模型，提问越简单越好，实际上并非如此。即便它已摆脱传统提示工程的繁琐，若想榨取最大价值，仍需遵循基本的智能交互原则。

# 3.1 推理协同：自主与引导如何兼顾

很多人认为 DeepSeek 推演能力强，只需抛需求它就会自动完成，无需干预。现实是，自主推演虽强，但恰当的引导同样关键，二者配合才能发挥最佳效果。

## 3.1.1 模型的自主推演能力

DeepSeek-R1 系列经强化学习训练，推理时具备大量反思与校验，思维链较长。面对数学、代码、复杂逻辑类任务，它能自行调动知识进行分析推导。比如做数学题时可自主识别题型并套用公式逐步求解；处理代码时能读懂逻辑、定位错误并给出修正建议。

## 3.1.2 引导不可缺的原因

即便自主性强，引导不可缺。提问模糊或过于宽泛时，模型难以精准把握意图，回答就会泛化。例如问“科技股能买吗？”，缺少投资期限、风险承受力、具体标的范围等关键信息，模型只能给出笼统的市场评论，无法形成有针对性的建议。

从训练机制看，模型虽学习海量数据，对具体场景和个性化需求仍需用户明确表达。就像一个博学的人，若不了解你的具体情况，很难给出最合适的建议。因此，通过有效提问引导模型聚焦核心，能显著提升回答的准确性和实用度。

## 3.1.3 引导技巧实战

### 1. 搭建结构化提问框架
把开放式问题改写成结构化指令能大幅提升理解度。比如学习类问题，把“如何学好英语”细化为“我要制定一个每天 1 小时、侧重商务口语的 3 个月提升计划，请按周拆解目标并推荐训练方法”，明确时长、场景和需求后，得到的方案会更具体。

角色扮演也是有效手段。先设定身份，如“假设你是新东方金牌讲师，为工作 5 年的外贸专员设计英语突破方案”，模型会调用更专业的知识，输出更贴合角色的答案。

### 2. 补充充分背景信息
背景越清晰，回答越贴切。投资建议场景里，说明财务状况、投资目标、风险偏好，模型才能综合考量。例如告知“可投资金 50 万，期限 5 年，能承受一定波动，希望长期收益最大化”，比单纯问投资建议得到的结论更有参考价值。

### 3. 多轮对话迭代优化
通过多轮交互可以不断打磨答案。对不满意的结果，可要求模型自我反思和改进。比如对一个营销方案提问“请对上述方案做至少 3 轮自我反驳，并给出更合理的版本”。模型会重新审视不足，输出更完善的方案。

在与 DeepSeek 协作时，要兼顾其自主推演优势和引导技巧的必要性，二者结合才能让它成为学习、工作和生活中的得力助手。

表 3-1 汇总了一些实用的提示词技巧。

| 序号 | 技巧名称 | 描述 |
| :--- | :--- | :--- |
| 1 | 思维链激活术 | 用“请分三步论证……”这类指令激活模型的强化学习系统，引导其进行逻辑推理和深度思考。如要求“请分三步论证新能源汽车未来五年的发展趋势，分别从政策、技术和消费者需求分析”，可让推理更有条理 |
| 2 | 场景加载法 | 设定角色身份加上“我正在……需要……”，如“作为风险管理总监，我正在准备董事会，需要一份公司当前市场风险的详细评估报告”，帮助模型理解具体情境，输出更贴合应用 |
| 3 | 迭代进阶策略 | 按“初版方案→漏洞排查→升级版本”的对话顺序逐步优化。例如先生成产品设计初稿，再让模型检查“成本过高和用户体验不佳的问题”，最后基于反馈生成升级版 |
| 4 | 多模态唤醒 | 结合“用表格对比”“生成示意图”等可视化要求，让信息呈现更直观。如“用表格对比我司与主要竞争对手在性能、价格、市场份额的差异，并生成柱状图展示” |
| 5 | 领域深挖模组 | 叠加“从法律/金融/伦理等三个维度分析”等专业限定，深入挖掘。如“从法律合规、金融风险和伦理道德三方面分析该商业模式的可行性”，实现多角度剖析 |
