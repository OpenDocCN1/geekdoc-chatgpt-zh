## 第二章 快速迭代的发展历程

ChatGPT 这个名字里，Chat 指对话形式，GPT 指底层技术，它是一款基于互联网可得数据训练的文本生成深度学习模型。应用范围覆盖文本问答、文本摘要、语言翻译、文本分类、代码生成和对话应答等。从首个 GPT-1 到 GPT-4 也就是 ChatGPT，短短四年便走完了快速迭代的历程（见图 2-1）。

2018 年，GPT-1 诞生，这一年被视作 NLP 预训练模型的元年。性能上，GPT-1 具备一定泛化能力，可用于与监督任务无关的 NLP 任务。常用任务有：

● 自然语言推理：判定两个句子间的关系即包含、矛盾或中立。
● 问答与常识推理：输入文章及若干答案，输出每个答案的预测准确率。
● 语义相似度识别：判断两句话语义是否相关。
● 分类：判定输入文本归属指定类别。

尽管 GPT-1 在未调优任务上能产生一些效果，其泛化能力仍远低于微调后的有监督任务，因此只能算是一款尚可的语言理解工具，而非对话式 AI。

GPT-2 于 2019 年正式推出，它并未在结构上做出太多创新，主要靠更大参数量和更大规模数据集：最大模型达 48 层，参数量 15 亿，学习目标是利用无监督预训练做有监督任务。表现上，除理解能力外，GPT-2 在生成侧首次展现出强天赋：阅读摘要、闲聊、续写、讲故事，乃至生成假新闻、钓鱼邮件或在网上扮演角色，都游刃有余。变大之后，GPT-2 展现出普适且强大的能力，并在多个语言建模任务上达到当时最佳水平。

随后登场的是 GPT-3。作为无监督模型，时下更常称自监督，它几乎能完成自然语言处理的绝大部分任务，如面向问题的搜索、阅读理解、语义推断、机器翻译、文章生成和自动问答等。在多项任务上表现突出，例如法英、德英机器翻译达到当时最佳水平，自动生成的文章几乎难以分辨人类或机器之手，辨别准确率仅 52%，接近随机猜测。更令人吃惊的是，在两位数加减运算上正确率近乎 100%，还能根据任务描述自动生成代码。一个功能丰富、效果良好的无监督模型，让人们看到了通用人工智能的希望，这也是 GPT-3 影响力巨大的原因。

本质上，GPT-3 可视作一个统计语言模型。机器学习视角下，语言模型是对词语序列概率分布的建模，即以已说出的片段为条件预测下一时刻各词出现的概率。它能衡量句子是否符合语言语法，例如评估人机对话系统自动回复是否自然，同时也能预测并生成新句子。比如面对“杭州东站到了，乘客们请”，语言模型可能预测“下车”，而强大的模型能捕捉时间信息，预测并生成语境贴合的“准备下车”。

语言模型强弱主要看两点：其一能否调用全部历史上下文，上述例子若无法捕捉“杭州东站到了”这一远距语义，就无法预测“准备下车”。其二是否有足够丰富的历史上下文可供学习，即训练语料是否充足。由于语言模型属于自监督，优化目标是最大化所见文本的语言模型概率，因此任何文本无需标注即可作为训练数据。

凭借更强性能、更多参数和更丰富的主题文本，GPT-3 明显优于前代 GPT-2。作为目前最大的密集型神经网络之一，它能把网页描述转为代码、模仿人类叙事、创作定制诗歌、生成游戏剧本，甚至模仿已故哲学家推测生命真谛。且 GPT-3 无需微调，仅需少量输出样本即可处理语法难题，可谓满足了人们对语言专家的想象。

但 GPT-3 并不完美，当前最担忧的问题之一是，聊天机器人和文本生成工具可能无差别学习网络上所有文本，进而输出错误、恶意、冒犯甚至具攻击性的语言，这将严重影响后续应用。

2022 年初，OpenAI 发布 InstructGPT。相较 GPT-3，OpenAI 采用对齐研究，训练出更真实、更无害且更能遵循用户意图的语言模型。InstructGPT 是对 GPT-3 的微调版本，可最小化有害、不真实和有偏输出。

开发人员通过监督学习叠加人类反馈强化学习来提升 GPT-3 输出质量。在该流程中，人类对模型的潜在输出进行排序，强化学习算法则对产生类似高质量输出材料的模型打分。

训练数据集以创建提示开始，部分提示源自 GPT-3 用户输入，例如“给我讲一个关于西游记的故事”或“用几句话给一个 6 岁的孩子解释一下春节的由来”。

开发人员将提示分为三组，并以不同方式为每组创建响应。

人类写作者对第一组提示作出回应。开发人员微调一个训练好的 GPT-3，使其变为 InstructGPT，以生成每个提示的现有响应。

下一步是训练模型为更好的响应提供更高奖励。对第二组提示，经优化的模型生成多个响应，人类评定者对每个回复评分。给出提示和两个响应后，打分模型即另一预训练 GPT-3 学会为高分响应计算更高奖励，为低分回答计算更低奖励。

开发人员利用第三组提示和近端策略优化 PPO 的强化学习方法进一步微调语言模型。给出提示后，语言模型生成响应，打分模型给予相应奖励，PPO 使用奖励更新语言模型（见图 2-2）。

ChatGPT 相较于此前的 InstructGPT，在训练流程上略有差异。之前的 InstructGPT 是给一个输入对应一个输出，再与训练数据对比，正确有奖励，错误有惩罚；现在的 ChatGPT 只有一个输入，模型给出多个输出，然后“人”为这些输出排序，再让模型学习从“善解人意”到“不知所以”的排序方式，这种策略称为监督学习。总结来看，二者的不同在于数据如何设置并用于训练与收集。

## 第三章 智能交互的运行模式

回顾 ChatGPT 的发展轨迹可以看出，OpenAI 从 GPT-1 起就坚定地把大型语言模型 LLM 视为通往通用人工智能 AGI 的必经之路。具体而言，在 OpenAI 看来，未来的 AGI 应具备一个任务无关的超大 LLM，用来从海量数据中学习各种知识，以生成一切的方式解决各类实际问题，并能听懂人类指令便于使用。

**幕后：大型语言模型**

自然语言处理是计算机科学与人工智能领域的重要研究方向，研究能实现人与计算机用自然语言有效沟通的理论和方法。它融合语言学、计算机科学、数学等，因此与语言学关系密切但有所区别。NLP 并非泛泛研究自然语言，而在于研制能有效实现自然语言通信的计算机系统，特别是软件系统，因而属于计算机科学范畴。

自然语言处理涉及计算机与人类自然语言的相互作用，与人机交互相关。NLP 面临诸多挑战，包括自然语言理解，即计算机从人为或自然语言输入中把握含义，以及自然语言生成。

长期以来，NLP 存在两大问题。一方面，迄今语法多仅限于分析孤立句子，对上下文和谈话环境对本句的制约影响缺乏系统研究，因而歧义、省略、指代、同句不同场合不同含义等问题尚无明确规律，需加强语用学研究。另一方面，人理解句子并非单靠语法，还会调用大量生活和专业知识，这些知识无法全部存入计算机，因此书面理解系统只能建立在有限词汇、句型和特定主题范围内；只有计算机存储量和运算速度大幅提升后，范围才可能扩大。

最早的自然语言理解研究源于机器翻译。1949 年，美国人瓦伦·韦弗首先提出机器翻译设计方案。20 世纪 60 年代，国外曾大规模投入机器翻译并花费巨额，但当时严重低估了自然语言复杂性，因理论和技术不成熟进展有限。当时做法主要是存储两种语言的词、短语并在翻译时逐一对应词典，技术上只是调整词序。但日常翻译并非如此简单，很多时候需参考上下文含义。

大约 20 世纪 90 年代起，自然语言处理领域发生巨大变化，呈现两大特征。

（1）对系统输入：要求系统能处理大规模真实文本，而非如早期研究性系统那样仅处理少量词条和典型句子。只有如此，系统才具实用价值。
（2）对系统输出：鉴于真实理解自然语言困难，并不要求系统对文本做深层理解，但要能抽取有用信息。例如自动提取索引词、过滤、检索、自动提取重要信息并做自动摘要等。

同时，因强调“大规模”和“真实文本”，两项基础工作得到重视和加强。

（1）大规模真实语料库研制。经过不同深度加工的大规模真实文本语料库，是研究自然语言统计性质的基础，没有它们统计方法便无源之水。
（2）大规模信息丰富的词典编制。规模达数万、十几万甚至几十万词，且含丰富信息如搭配信息的计算机可用词典，对自然语言处理至关重要。

自然语言处理指机器理解并解释人类写作、说话方式的能力，属于人工智能和语言学的一部分，致力于用计算机理解或产生人类语言中的词或句子。NLP 主要涉及语音识别、语音合成、语义理解、机器翻译，产品呈现实用化趋势，但在成熟度上仍有提升空间。

现代 NLP 算法基于机器学习，特别是统计机器学习。与早期用大量手工规则编码不同，主要研究领域包括短文本计算与分析技术、跨语言文本挖掘技术、面向机器认知智能的语义理解技术，以及多媒体信息理解的人机对话系统（见图 3-1）。

ChatGPT 无比强大的能力主要归功于“大规模”，即其依托的大型语言模型。ChatGPT 虽加入人工标注数据，但量级仅数万，与训练 GPT-3.5 模型使用的千亿级数据相比可忽略不计，基本不会提升基础能力。因此 ChatGPT 的强大功能主要来自隐藏其后的巨无霸模型 LLM。

在整个人工智能行业，几乎所有机构都在建立专门的小模型解决具体问题后再组合使用。若有人研究大语言模型，试图制造类似通用人工智能的东西，参数以百亿计且需大量算力，投资需数十亿美元，定会被视作疯子。

所谓“大模型”，通常是在无标注大数据集上采用自监督学习训练。之后开发者只需微调或少量数据二次训练即可满足新场景需求。

腾讯研究院指出，当前人工智能多针对特定应用场景训练，模型难以迁移，属于“小模型”范畴。整个过程不仅需大量手工调参，还需喂养海量标注数据，降低了研发效率且成本较高。

这如同哥伦布逆风航行所遇困境。要远航需补给支撑，过了折返点补给不足则无法返航，前方要么有岛屿，要么只有几个月的生命时光。所有人害怕近在咫尺的死亡。所以当哥伦布抵达新大陆时，不仅他和西班牙王室知晓，所有人都明白：这条路走得通。

如今 OpenAI 已用“暴力美学”把大语言模型这条路走通，接下来其他企业机构走第二遍便容易得多。

LLM 的发展可理解为“构建一个任务无关的超大型 LLM，让它从海量数据中学习各种知识”。图 3-2 展示了一个大型语言模型该有的样子。

首先，该模型规模必然巨大，能研发或改动其参数的机构必然稀少。而任务需求方是无数中小机构甚至个人，即便开源也无力部署，更不用说用微调修改参数。因此应追求不修正模型参数就能完成任务的方式，即采用提示词 Prompt 模式而非微调模式。模型制作方可将 LLM 做成公用基础设施服务，以基础设施即服务 IaaS 模式运行。与此同时，服务提供方需面对千变万化的用户需求，所以 LLM 开发方更要让模型完成尽可能多的任务类型，这也是 LLM 走向通用人工智能的现实推动力。

其次，LLM 应具备强大的自主学习能力。假设把世界上能获得的所有文本或图片等不同类型数据喂给它，它应能自动从中学习所有知识点，学习过程无需人工干预，并能灵活应用所学知识解决实际问题。因数据海量，需用大量模型参数存储知识，所以模型必然是巨无霸。

那么，ChatGPT 向 GPT-3.5 模型注入新知识了吗？答案应是注入了。这些知识就包含在 ChatGPT 揭秘时提及的“数万人工标注”数据里，不过注入的不是世界知识，而是人类偏好知识。所谓“人类偏好”包含几层含义：首先是人类表达任务的习惯说法。例如人们习惯说“把下面的句子翻译成日语”来表达机器翻译需求。但 LLM 并非人类，会如何理解这句话呢？需要让 LLM 理解命令含义并正确执行。ChatGPT 通过人工标注数据向 GPT-3.5 注入这类知识，方便 LLM 理解人类指令，这是其把握意图的关键。其次，什么是好回答、什么是不好回答，人类有自己的标准，如详细回答是好的，含歧视内容的回答是不好的。人工标注通过打分模型将这类信息反馈进 LLM 数据。总体而言，ChatGPT 把人类偏好知识注入 GPT-3.5，以此获得一个听得懂人话且比较有分寸的 LLM。
