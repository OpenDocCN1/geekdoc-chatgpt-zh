# 低成本训奖励模型：4bit 量化配 LoRA

把人类的偏好偏好变成模型可用的分数信号，奖励模型在其中起承上启下的作用。本文以 Llama-3.1-8B-Instruct 作为底座，结合 4bit 参数压缩和 LoRA 的高效微调，演示一套从偏好对到可落地的 RewardTrainer 的完整打样流程。

实现上可以拆成三步。先用 BitsAndBytes 把大模型压到 4bit，让显存占用大幅下降；随后挂载 LoRA，只更新少量适配权重；数据方面把每个样本的问题与优选回答拼接、问题与劣选回答拼接，再做分词，最后交由 TRL 的 RewardTrainer 做成对训练，训练结束保存即可得到可用模型。

偏好数据采用 preference.json 格式，每条记录都包含问题、优选答案、劣选答案。举个例子，关于用 Pandas 读 CSV 的提问，好的回答会明确提到调用 read_csv 方法把文件读进 DataFrame，而不够理想的回答只泛泛地说用 Pandas 来读。另一个关于自然语言处理的问题，好的回答会说明它是计算机科学和人工智能下的分支，主要研究机器与人类语言的沟通方式，而简化的回答只将其归为计算机科学的一部分。这类成对样本构成了模型学习的偏好信号。

items = []

with open("./data/preference.json", "r", encoding="utf8") as f:
    for line in f:
        item = json.loads(line)
        items.append(item)

dataset = Dataset.from_list(items)

def process_func(example):
    chosen = example["question"] + example["chosen"]
    rejected = example["question"] + example["rejected"]
    tokenized_chosen = tokenizer(chosen)
    tokenized_rejected = tokenizer(rejected)
    new_example = {}
    new_example["input_ids_chosen"] = tokenized_chosen["input_ids"]
    new_example["attention_mask_chosen"] = tokenized_chosen["attention_mask"]
    new_example["input_ids_rejected"] = tokenized_rejected["input_ids"]
    new_example["attention_mask_rejected"] = tokenized_rejected["attention_mask"]
    return new_example

dataset = dataset.map(process_func, remove_columns=['question', 'chosen', 'rejected'])
