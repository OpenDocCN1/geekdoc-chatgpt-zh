# 7.4.1 时间序列插补

时间序列插补即在序列出现缺失时借助算法推断空缺取值的方法[213,229,269]。真实场景中[60,173,265,280]数据缺失十分普遍，插补因此是时序处理的关键环节。常见手段包括：

+   1. 线性插值。利用缺失点左右两端的已知数值，以直线相连，假设区间内变化均匀。
+   2. 拉格朗日插值。选取缺失点附近若干观测点，构造插值多项式，再据此估计缺失值。
+   3. 平滑插值。思路与拉格朗日相近，但采用分段二次或三次连续函数拟合，曲线过渡更平滑。
+   4. k-最近邻插补。取与缺失点最相近的 k 个邻居的均值或中位数作为估计。
+   5. 基于模型的插补。先用已知数据拟合自回归、ARIMA、VAR 等统计模型，再据此预测缺失位置。
+   6. 矩阵分解。将序列转成矩阵形式，利用奇异值分解、主成分分析等方法填补缺失条目。
+   7. 基于深度学习的插补。借助循环神经网络、长短时记忆网络等学习序列规律，再对空缺位置进行推断。

基于扩散模型的时间序列插补

近年来确定性插补[23,27,154]与概率插补[165]均快速发展，扩散模型成为重要方向。CSDI[230]基于分数扩散提出一种新的时序填补方案。为了更好地挖掘时序相关性并用于生成建模，该方法采用自监督训练来优化扩散模型。如图7-24所示，CSDI 在部分已知序列的基础上，利用扩散模型逐步恢复缺失信号。Conditional observations 和 Imputation targets 分别是输入的条件信号和待填补的目标片段。

# 7.4.2 时间序列预测

时间序列预测是指基于历史数据，利用算法对未来一段时间的数值进行推断。预测是时间序列分析的核心，广泛应用于经济、金融、工业、社会等各个领域。常用方法有：

+   - 1. 移动平均法。利用时间序列的平均值进行预测，一般使用简单移动平均、加权移动平均等方法。
- 2. 指数平滑法。指利用时间序列的平滑值进行预测，一般使用单指数平滑、双指数平滑、三指数平滑等方法。
- 3. ARIMA 模型，是一种经典的时间序列预测模型。通过时间序列的自回归、差分和移动平均这3个步骤建立模型，具有良好的拟合能力。
- 4. SARIMA 模型，指在ARIMA模型的基础上，考虑季节性因素的影响，通过对时间序列进行季节性差分和季节性自回归建立模型。
- 5. VAR 模型，指将多个时间序列变量视为一个整体来建立模型，通过对各个时间序列之间的关系建立模型，能够较好地反映不同变量之间的相互作用。
6. 预测 Prophet 模型，是由Facebook公司开发的一种时间序列预测模型，能够自动处理季节、节假日等因素，并且具有较好的可解释性。
7. 深度学习模型，如循环神经网络(RNN)、长短时记忆(LSTM)、卷积神经网络（CNN）等，这些模型能够自动提取时间序列数据中的特征，具有很强的非线性建模能力。

基于扩散模型的时间序列预测

深度学习已被用于时间序列预测，常见单点预测[172]与单变量概率方法[205]。多变量场景下也有点预测方法[140]及概率方法，涉及GAN[271]或归一化流[192]等生成技术，扩散模型也被引入其中。TimeGrad[191]提出一个自回归模型预测多元时间序列的方法，即通过从每个时间序列中估计样本分布的梯度来从数据分布中采样，利用扩散概率模型进行模型搭建。该方法与分数匹配模型和基于能量的模型密切相关。具体来说，它通过优化数据似然的变分界来学习梯度，在推理阶段使用朗之万采样，并通过马尔可夫链将白噪声转换为目标数据分布中的样本[220]，图7-26为TimeGrad时间序列预测的结果。
