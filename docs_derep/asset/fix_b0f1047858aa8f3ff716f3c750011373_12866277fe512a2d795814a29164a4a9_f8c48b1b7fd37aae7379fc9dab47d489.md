◎ 工业软件与数据的卡点：当下全球工厂里运转的主流工业软件，绝大多数产自欧洲厂商，诸如 SAP 的 ERP、Siemens 的 PLM、达索的 CATIA、Ansys 的仿真、Codesys 的工控等。36 氪研究院《2023 年中国工业软件行业洞察报告》指出，中国研发设计类工业软件的国产替代比例仅约 5%，松应·科技的估算显示，整个工业软件的国产份额很难超过 15%。没有自主的平台来汇聚数据，工业大模型与人形机器人需要的海量制造实景就难以集齐，像松应·科技这样的国产 3D 仿真平台便出现有能力缺原料的窘境。业内建议搭建工业数据交易与机器人训练的统一枢纽，动员各细分赛道的链主把产线数据沉淀到中国自有的国产版 Omniverse 平台上，在数字孪生工厂里借助人工智能和三维仿真迭代智能制造大模型，同时以商业合作方式为机器人创业团队赋能。松应·科技目前采取嵌入策略，在达索、西门子等主流工业软件内植入 Orca 插件，经客户授权后抽取产线数据用于仿真训练。

◎ 国产芯片难以支撑 3D 仿真引擎：半导体供应链波动频繁，国产训练与推理 GPU 的性能与英伟达第二代 B100、H100 存在差距；在仿真场景下，国产显卡也落后于英伟达第三代产品。图形渲染的硬实力不足，直接拉低了国产 3D 仿真引擎的迭代节奏；硬件跟不上，软件生态也就无从建立。解决思路应回到产业痛点，加大对国产 GPU 与图形显卡芯片的研发投入，攻克瓶颈，而不是空谈概念。

◎ 工业智能平台缺领军企业投入：聂凯旋认为牵头工业智能平台的应是制造业中具备势能且有变革动力的领军企业，以工业数据牵引国产工业大模型与国产人形机器人的全链协同研发。松应·科技作为创业团队，愿与志同道合的伙伴共同推动工业软件高质量国产化。目前公司已向科研院所和高校开源 Orca 仿真软件，逐步获得工业软件、传感器等上下游服务商的认可，并通过标准 API 接入数百款工业级软硬件产品。

代码续写：搭档依据光标所在位置的上下文推测并生成下一句或下一段程序，最多给出 3 个候选版本供挑选。以资金账户对象类与资金账户管理类的定义为例，当开发者需要生成三个初始化资金账户的程序段时，按快捷键即可在数秒内获得灰色候选代码，篇幅可自行调节，操作简便。

编程互动咨询：在 IDE 内嵌聊天窗口，开发者可通过对话实现全网检索、代码解释、单元测试生成、代码重构等。例如输入“Springboot 应用如何修改监听端口？”回车即可得到修改参数的具体方法。下拉菜单还提供代码生成、单元测试生成、代码转换、修复、重构等服务，选择“代码注释”即可让模型写出功能说明，选择“代码生成”会自动生成一段提示词并据此产出程序。提示词的质量决定效果，搭档提供大量实用模板，可收藏复用；“代码比对”功能可在修改后快速标出差异。生成单元测试用例时，一个高质量的提示词会要求模型以测试工程师身份遵循明确原则，分点说明测试目的、条件、步骤和预期结果，再针对账户创建接口输出用例。

该搭档已在多项目试点，代码续写虽不完美，但已带来效率提升，并在商汤“代码小浣熊”本地化支持下快速迭代。

主要优势体现在：通用代码如正则、邮箱校验、数据库接口、前端页面生成的质量较高；新人接手无注释代码时，模型可自动生成说明，也可模仿优质范例生成新代码；编程体验更连贯，模型在开发者停顿后可接续补全，减少被打断导致的卡壳，并辅助生成创作提示词，帮助更快进入心流状态。

由此带来三种新能力。第一，企业级数据与知识治理。人工智能可读取结构化表，通过大模型梳理结构化与非结构化数据资产，实现自动化的数据资产治理与复杂知识管理，挖掘商业价值。第二，智能体可自动选型调用工具。智能体擅长文本理解，能判断工具功能并掌握调用方式，例如在编写 SQL 等代码时规划子任务，调用 RPA、办公自动化等工具并据结果迭代，最终输出高质量答案。第三，智能体理解图表含义，灵活处理复杂任务。证券机构托管的基金产品报表格式各异，传统 RPA 易出错，智能体能理解字段含义并精准完成填报。
