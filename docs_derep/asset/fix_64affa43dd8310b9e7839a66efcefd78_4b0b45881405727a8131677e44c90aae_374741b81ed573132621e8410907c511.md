# datasets 实战：从拉取到批量改写

在做问答或指令微调时，如何把公开语料快速导入、拆分、再改造成训练格式是常见需求。Hugging Face 的 datasets 能把这些步骤收敛成几行调用。下面以 SQuAD 为主线，把典型用法串起来，便于在自媒体教程中直接复用。

先用默认参数拉取公开集，返回的是包含多个分片的字典容器。

[PRE0]python
ds = load_dataset('squad')
ds

可以看到训练与验证各自的字段列表，样本规模分别为约 8.7 万与 1 万条。

如果只需要单一切片，在调用时指定 split，得到的就不再是字典而是单一 Dataset，更便于调试。

[PRE2]python
ds = load_dataset('squad', split='train')
ds

    features: ['id', 'title', 'context', 'question', 'answers'],

结构更简洁，适合只做训练集的实验。

本地文件也能接入，通过 data_files 把文件名映射到逻辑分片即可。

[PRE4]python
data_files = {'train': 'train.csv', 'test': 'test.csv'}
ds = load_dataset('namespace/your_dataset_name', data_files=data_files)

批量改写常用 map。定义一个函数把问答转成 Human-Assistant 对话范式即可。

[PRE10]python
def map_function(example):
    # Get the question and model output
    question = f"#### Human: {example['question'].strip()}"
    output = f"#### Assistant: {example['answers']['text'][0].strip()}"
    print(question, output)
data_train = dataset["train"].map(map_function)
