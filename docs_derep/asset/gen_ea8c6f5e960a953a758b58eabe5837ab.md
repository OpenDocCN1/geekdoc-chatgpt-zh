Playground 实战：Gemini Live、Veo 2 与 TTS 全解析

Gemini Live API 核心能力
语音活动检测是 Gemini Live 的对话基石，能自动捕捉用户开口的瞬间，并在用户打断时立刻停止正在生成的回复，只保留已推送到客户端的历史内容，未完成的部分直接丢弃，让交互像面对面一样自然。

原生音频输出提供逼真的语音播报，内置多款预设音色，可随上下文自动调整语气和情绪。

对话中可调用外部工具或自定义函数，实时获取天气、新闻等数据或执行特定操作。

会话管理支持长时对话，历史上下文可随时恢复。

其他能力还包括输入输出音频的转文字，以及用于客户端安全鉴权的临时令牌。

Gemini Live 的典型应用
用软件时卡住，不用再截图打字描述。开启屏幕共享后，Gemini 能“看见”你的画面并通过语音交流。举例来说，在 Perplexity 搜索页犹豫下一步时，可以直接问：

我现在处于哪个屏幕？

系统会回答：你当前在 Perplexity 的搜索界面。

继续追问：若需开发 OpenAI 相关任务，该如何搜索？

它会即时建议：可搜索“如何使用 OpenAI API 进行语义分析”……

这种看屏听声、手把手的指导感，像身边坐着一位资深导师。

特别适配的场景包括：
实时客服和咨询：理解用户情绪，提供人性化服务。
教育和培训：AI 导师可看到学生屏幕并实时指导。
远程协作：在视频会议中实现实时翻译、会议记录或智能建议。
无障碍辅助：结合语音交互和屏幕理解，为视障或行动不便用户提供帮助。

Gemini Live 核心参数配置
在 Playground 的 Run settings 中可以看到当前模型为 Gemini 2.5 Flash Native Audio Preview 09-2025，是一款为高品质音频输出、更自然的节奏和情绪而优化的原生音频模型。System instructions 可选，用于设定语气风格。Voice 默认 Zephyr，Media resolution 默认 258 tokens / image。

关键参数说明：
Voice 语音选择：内置 Zephyr、Kore、Puck 等预设音色，各有音质特点，可在 AI Studio 试听后通过 speechConfig.voiceConfig.prebuiltVoiceConfig.voiceName 指定。
Media resolution 媒体分辨率：66 token/image 或 258 token/image，默认 258。258 适合识别细小文字和复杂界面，如代码调试、设计评审；66 更偏向快速处理大致内容。
Turn coverage 轮次覆盖：在未检测到用户语音时仍持续推送音频或视频，保持视觉反馈，避免卡顿。
Thinking mode 思考模式：开启后先做深度推理再回复，适合技术拆解、多步骤方案等复杂对话。
Set thinking budget 思考预算：控制生成回答时可用的思考 Token 数，数值越高推理越深但延迟越大，设为 0 则关闭思考追求最快响应。
Affective dialog 共情对话：根据用户语气情绪调节回复风格，沮丧时更温和鼓励，兴奋时更积极。
Proactive audio 主动音频：模型自行判断是否回应，对自言自语等与对话无关的音频不强行插话，优化节奏自然度。

工具集成
Function Calling 函数调用：可自定义函数供 Gemini 在需要时调用获取外部数据或执行操作，如“查询天气”。通过 Edit 按钮配置函数定义。
Automatic Function Response 自动函数响应：开启后函数返回结果由系统自动处理并继续对话，无需人工干预，适合高频调用 API 的场景。
Grounding with Google Search Google 搜索增强：启用后 AI 会优先结合实时搜索信息作答，提升准确性和时效性。

#### 4. Veo 2：让静态画面动起来
Veo 是 Google 的视频生成模型家族，可将文本或静态图转为高质量动态视频。Playground 目前仅开放 Veo 2 即 veo-2.0-generate-001，支持文本转视频和图片转视频，不含音频。若需带音视频可通过 Gemini API 调用 Veo 3 或 Veo 3.1。

提示撰写技巧
视频质量取决于提示的完整度，建议围绕主体、动作、风格、镜头语言、氛围五要素构建。
主体：金毛犬、城市天际线、身着红风衣的女性。
动作：奔跑、转头、缓慢行走、毛发飘动。
风格：电影感、科幻风、黑色电影、3D 卡通渲染。
镜头语言：特写、航拍、跟踪镜头、平视、缓慢推进。
氛围：暖色调日落、冷蓝色霓虹、柔和自然光。

例如“ 一只狗在跑 ”效果平平，而“ 特写镜头：一只金毛犬在海滩奔跑，毛发在风中飘动，暖色调日落，电影感，浅景深 ”会生成更精致的表现力。

使用场景
文本转视频：直接输入描述生成对应画面。
图片转视频：上传设计稿或草图，配合动作描述让画面动起来。
创意验证：无需专业制作工具即可快速测试想法，每日额度约 10 次左右已足够验证。
素材制作：可直接下载无水印视频，用于项目素材、社交内容或演示原型。

参数配置
Number of results 生成数量：1～2 个，默认 1，便于对比或迭代。
Aspect ratio 宽高比：16:9 横屏默认，适合桌面、YouTube、横幅广告；9:16 竖屏适合移动短视频、Stories、TikTok。
Video duration 视频时长：Playground 固定 8 秒；通过 API 调用 Veo 3 可选 4、6、8 秒。
Frame rate 帧率：默认 24f/s，电影标准，视觉更自然。
Output resolution 输出分辨率：默认 720p，兼顾清晰度与生成效率。
Negative prompt 负面提示词：用于排除不需要的元素。避免使用“不要”“不”等指令，直接罗列元素如“城市背景、人造结构、暴风雨、阴暗氛围”。

注意事项
Veo 2 输出不含音频，需音频请用 Veo 3 系列。
Playground 每日生成次数通常限制约 10 次，宜合理规划。
视频生成耗时较长，通常需数分钟，耐心等待避免中断。

#### 5. Gemini TTS：让文字开口说话
Gemini TTS 并非独立合成引擎，而是基于 Gemini 融合 TTS 能力，能理解文本语义、情感与上下文，生成更贴合场景的语音。Playground 支持 Gemini 2.5 Pro Preview TTS 与 Gemini 2.5 Flash Preview TTS。

核心能力
语义理解驱动的语音生成：识别情感、语气、角色关系后自动调整表现力，而非简单朗读。
多角色对话生成：可为不同角色指定 Speaker，AI 自动分配音色并随上下文调节情绪。
上下文感知的情感控制：保持整段文本情感连贯，激动、悲伤、幽默、严肃均可通过文本引导。

使用场景
内容创作：为视频、播客、有声书生成接近真人的配音。
多角色对话：快速生成游戏原型、动画预览或剧本试听，无需录音或后期剪辑。
教育培训：为课程、教程生成清晰自然的旁白，按重点自动调整语气。
无障碍辅助：将文本转语音，帮助视障或阅读困难用户获取信息。
创意验证：反复调整音色、语气和情感，找到最适合内容的声音风格。

核心参数
Mode 模式：Single-speaker audio 单说话人，适合旁白、有声书、教程；Multi-speaker audio 多说话人，适合对话剧本，通过 Speaker 1、Speaker 2 标记切换音色。
Model settings 模型设置：Temperature 温度 0～1.0，默认 1.0，控制创造性和随机性。
Voice settings 语音设置：支持 Zephyr、Kore、Puck 等预设音色，可在 AI Studio 试听后选用。

### 2.1.3 在Playground中打磨你的想法
掌握界面和参数后，关键是测试、优化再导出。

快速验证轻量任务
Playground 本身就是轻量工作台，可像 ChatGPT 一样完成文案润色、简历优化、SQL 编写、脚本生成、技术方案讨论，并支持上传文档总结、图表分析、屏幕共享实时指导。

深入理解模型的能力边界
每个模型特性不同，实际测试最靠谱。
推理能力对比：用同一复杂逻辑题分别在 Gemini 3、Gemini 2.5 Pro、Gemini 2.5 Flash 中运行，对比回答质量、推理过程和速度，会发现 Gemini 3 多步推理更稳定，Flash 更快但易遗漏细节。
多模态理解测试：上传同一技术架构图，提问“这张图展示了什么系统架构？各组件作用及关系是什么？”对比各模型对视觉细节的捕捉和整体结构的把握差异，从而选出最合适的工具。
