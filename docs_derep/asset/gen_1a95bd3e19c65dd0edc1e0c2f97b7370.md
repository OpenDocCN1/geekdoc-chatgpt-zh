挖掘异常是商业数据洞察的重要一环，可帮助揪出潜在欺诈、数据瑕疵或特殊商机。文中所用的智能体借助 Isolation Forest，也就是孤立森林，对销售额与利润展开异常筛查。孤立森林属于基于树的无监督方法，对高维场景友好，其原理在于异常样本更容易被“孤立”——通过少数次随机切分就能与正常样本区分开。

###### 4. 异常检测分析

异常检测旨在找出偏离常规模式的数据点，这类点可能指向重要事件，也可能暴露欺诈、系统故障或录入错误。本报告选用 Isolation Forest 对销售额与利润两项核心指标开展筛查。

####### 4.1 Isolation Forest算法

Isolation Forest 属于基于决策树的无监督方法，识别逻辑是通过“孤立”来实现。与距离或密度类方法不同，它随机抽取特征并随机切分，使异常样本往往只需更少切分即可被分离。该方法在高维场景且正常样本占多数时具备较好稳健性与效率。

####### 4.2 异常值识别

将异常比例设为约 1%（contamination=0.01），模型共标记出 100 条异常记录。

- 销售额偏高而利润偏低甚至为负：或反映大额折扣、退货率高或成本失控。
- 销售额偏低而利润偏高：可能为高单价低销量商品，也可能是录入偏差。
- 销售额或利润极端：多对应非常规大单或重大亏损。

这些异常需进一步核查。例如，高销低利订单应复核折扣政策、成本构成及退货情况；极端利润订单则需确认数据是否准确。
