# 第 5 章 聚类分析与无监督学习进阶（续）

## 5.5 经典聚类算法深度解析

### 5.5.1 聚类性能评估：怎么衡量“分得好”？

聚类做完了，怎么知道效果好坏？核心在于**性能度量**。这不仅是事后诸葛亮的评分工具，更能反哺建模过程——若提前锁定评价指标，直接将其设为优化目标，往往能拿到更对味的结果。好的聚类，本质上就是**“簇内抱团紧，簇间拉得开”**。

评价指标大致分两派：**外部指标**与**内部指标**。

**外部指标：有“标准答案”才能用**
这类指标把聚类结果拿去跟“参考模型”（也就是带标签的真实数据、人工标注或理想划分）对齐。属于有监督视角下的考核。数值通常落在 [0, 1] 区间，**值越大，吻合度越高，聚类质量越好**。
*   **常见选手：** Jaccard 系数 (JC)、Fowlkes-Mallows 指数 (FMI)、Rand 指数 (RI)。

**内部指标：无监督，靠“自省”**
不需要外部标签，纯看样本点跟聚类中心的几何关系。核心考量两个维度：
*   **紧密度：** 簇内样本到中心的平均距离（越小越紧凑）。
*   **分离度：** 不同簇中心间的平均距离（越大越分明）。
*   **常见选手：** Davies-Bouldin 指数 (DBI，**值越小越好**)、Dunn 指数 (DI，**值越大越好**)。

---

### 距离度量：聚类的“尺子”怎么造？

上述指标全靠“距离”说话。标准距离需满足四性：非负性、同一性、对称性、三角不等式（直递性）。

给定两个 n 维样本 $x_i, x_j$，最通用的是**闵可夫斯基距离**：
*   $p=2$ → **欧氏距离**（直线距离，最常用） [PRE0]
*   $p=1$ → **曼哈顿距离**（街区距离，网格场景适用） [PRE1]

**属性类型决定距离怎么算：**

| 属性类型 | 例子 | 能否直接算差值？ | 推荐度量 |
| :--- | :--- | :--- | :--- |
| **有序属性** | 评分 {1,2,3}，连续值 | **能**，“1”比“3”更接近“2” | 闵可夫斯基系、欧氏、曼哈顿 |
| **无序属性** | 水果 {苹果, 梨, 香蕉} | **不能**，类别间无大小序 | **VDM (Value Difference Metric)** |
| **混合属性** | 同时含有序+无序 | 需组合拳 | 闵可夫斯基 + VDM 混合 |

**VDM 核心逻辑 [PRE3]：** 不看属性值本身，看**类条件分布差异**。若两个取值在各类别中出现的概率分布相似，则距离近。

**进阶场景：**
*   **属性重要性不一** → **加权距离**。
*   **类与类距离** → 单连接(最短)、完全连接(最长)、中心距离、平均距离。
*   **非度量距离**：现实中常需“人似人马、马似人马、人不似马”，这违反三角不等式，需特殊设计。
*   **度量学习**：别再拍脑袋定公式了，让数据自己“学”出最合适的距离函数。

### 5.5.2 K-Means：原型聚类的“速度与激情”

**核心假设：** 簇结构可用一组**原型（中心点）**刻画。
**目标：** 划分 $k$ 个簇，最小化**平方误差 (SSE / E)** [PRE4][PRE5]。$E$ 越小，簇内越紧凑。

**求解难点：** 找全局最优是 NP-hard 问题。
**实用策略（Lloyd 算法/迭代贪心）：**
1.  **初始化：** 随机选 $k$ 个中心（需预知 $k$）。
2.  **指派：** 每个点归属最近中心。
3.  **更新：** 重算各簇均值作为新中心。
4.  **收敛：** 中心点变化微乎其微时停止。多跑几次随机种子取最优。

**优缺点极其分明：**
✅ 速度快、实现简单、可解释性强。
❌ **必须预知 $k$**；对初始化敏感；仅能发现球状簇；**均值极怕异常值**。

**变体 K-Medians：** 用**中位数**代替均值作中心。
✅ 鲁棒性强，不怕离群点。
❌ 需排序，计算变慢。

### 5.5.3 GMM (高斯混合模型)：用概率取代“硬划分”

K-Means 是“非黑即白”的硬划分，GMM 引入**概率模型**，给出“属于某簇的概率”，即**软划分**。

**单高斯分布**由均值向量 $\mu$ 和协方差矩阵 $\Sigma$ 决定 [PRE6]。
**GMM** 是 $k$ 个高斯分布的线性组合 [PRE7][PRE8]，参数含混合系数 $\alpha_i$、均值 $\mu_i$、协方差 $\Sigma_i$。

**训练目标：** **最大似然估计 (MLE)**。让观测数据 $D$ 出现概率最大 [PRE9]。
取对数得**对数似然函数** [PRE10]，求解参数使其最大化 [PRE11]。

**求解利器：EM 算法 (Expectation-Maximization)**
迭代两步走，保证似然不降：
*   **E-step (步骤 1-2)：** 根据当前参数，算每个样本属于各高斯成分的**后验概率**（责任度）。
*   **M-step (步骤 3)：** 利用责任度加权，更新新参数：
    *   新均值 [PRE12][PRE13]
    *   新协方差 [PRE14]
    *   新混合系数 [PRE15]
*   循环至收敛或达上限。流程见 [图 5-24]。

**GMM 优势：** 能捕捉椭圆形簇，提供概率输出，理论基础扎实。

### 5.5.4 DBSCAN：密度视角下的“任意形状捕手”

不靠中心点，靠**样本分布紧密度**定簇。核心参数：邻域半径 $\varepsilon$、最小点数 $MinPts$。

**关键定义：**
1.  **$\varepsilon$-邻域：** 距离 $\le \varepsilon$ 的点集。
2.  **核心对象：** 邻域内点数 $\ge MinPts$。
3.  **密度直达：** 点 $p$ 在核心点 $q$ 邻域内。
4.  **密度可达：** 核心点链条传递（传递性）。
5.  **密度相连：** 存在核心点 $o$，$p,q$ 均从 $o$ 可达。

**簇的定义：** 密度可达关系导出的**最大密度相连集合**。满足连接性+最大性。

**算法流程：** 遍历未访问点 -> 找邻域 -> 是核心点则发起扩展（递归收割密度可达点）形成新簇 -> 非核心点暂标记为噪声/边界 -> 直到全访问完。

**优缺点鲜明：**
✅ **无需预知 $k$**；能发现**任意形状**簇；天然**识别噪声/离群点**。
❌ 参数 $(\varepsilon, MinPts)$ 敏感，难调；**不适合密度差异大**的数据；高维下距离失效。

### 5.5.5 层次聚类：构建嵌套聚类树

输出不是单一划分，而是一棵**树状图 (Dendrogram)**，蕴含多粒度结构。

**两大流派：**
*   **凝聚法 (AGNES，自底向上)：** 每点自成一簇 -> 反复合并最近两簇 -> 直到单簇或达标。
*   **分裂法 (DIANA，自顶向下)：** 全体一簇 -> 反复拆分最远两簇 -> 直到单点或达标。

**簇间距离怎么算？（链接准则）**
1.  **最小距离 (单连接/最近邻)：** 最近对距离。易产生“链状”簇。
2.  **最大距离 (全连接/最远邻)：** 最远对距离。倾向紧凑球状簇。
3.  **均值距离 (UPGMA)：** 两簇质心距离。
4.  **平均距离：** 所有点对距离均值。
5.  **中间距离：** 折中方案。

**评价：**
✅ 无需预设 $k$，可视化树状图直观，能看出层次关系。
❌ **计算复杂度高 (通常 $O(n^2 \sim n^3)$)**，大数据难顶；对噪声/离群点敏感；一旦合并/分裂不可逆，易陷局部最优。

## 5.6 章节小结：机器学习全景回顾

机器学习是 AI 的核心引擎，让机器从数据中悟道、决策、预测。实战中五大基石决定成败：

1.  **特征工程：** 数据炼金术。清洗、选择、变换，把原料变成模型爱吃的“特征菜”。好特征顶十个模型，小数据下更是救命稻草。
2.  **模型评估：** 体检报告。交叉验证、划分测试集、指标体系（准确率、F1、AUC...），防过拟合，指导调参。
3.  **有监督学习：** 带标签练功。分类、回归主战场。SVM、决策树、神经网络皆是悍将，核心是学 $X \to y$ 映射。
4.  **无监督学习：** 无标签寻宝。聚类、降维主攻。探索数据内在结构，服务推荐、分割、预训练。
5.  **概率图模型：** 概率+图论，显式建模变量依赖，推理利器。

**未来趋势：** 解释性成刚需（白箱化）；跨学科融合（脑科、心理）；算力数据双升级催生超大模型。机器学习将持续重塑科技版图。

# 第 6 章 神经网络与深度学习基石

> 本章自底向上构建认知：从单个神经元出发，串联线性网络、全连接网络、BP 算法，再进阶至 CNN、RNN，最后触及 GAN 前沿。

## 6.1 神经元与网络：从生物启发到数学抽象

### 6.1.1 生物神经元：智能的微观基石
人脑约 $10^{11}$ 个神经元，$10^{14}$ 个连接（突触）。
结构：**细胞体**（核）+ **树突**（收信，树状分支）+ **轴突**（发信，长管）+ **突触末端**（释放神经递质）。
工作机制：电脉冲 (动作电位) 顺轴突传播 $\to$ 突触释放化学递质 $\to$ 下游神经元累积递质达阈值 $\to$ 发放脉冲（兴奋/抑制）。
**启示：** 单元极简，规模巨大，复杂计算涌现于海量简单单元的连接与递质调节中。

### 6.1.2 人工神经元：M-P 模型与感知机
1943 年 McCulloch & Pitts 提出 M-P 模型，开启仿真史。
标准数学模型（感知机雏形）三板斧 [PRE16]：
1.  **加权求和：** $\sum w_i x_i + b$ （$w$ 控制输入重要性，$b$ 偏置防激活失灵） [PRE17]
2.  **线性变换：** 恒等映射或仿射。
3.  **激活函数 $f(\cdot)$：** **引入非线性**，赋予万能逼近能力；配合 BP 反向传播，控制梯度流动（防爆炸/消失）。

### 6.1.3 神经网络：会“长大”的函数拟合器
*   **自适应/自组织：** 训练中更新权重，拟合数据分布。
*   **知识超越：** 学习能力可超越设计者先验（深度学习核心特质）。

**分类视角：**
| 维度 | 类别 | 判别标准 / 代表 |
| :--- | :--- | :--- |
| **学习范式** | **监督学习** | 数据有标签 $y$（分类/回归），学 $X \to y$ 映射 |
| | **无监督学习** | 无标签，挖掘结构（聚类/降维/生成） |
| **拓扑结构** | **前馈网络 (FNN)** | 信号单向流动（MLP、CNN） |
| | **反馈/循环网络 (RNN)** | 含循环/记忆，处理序列 |
| | **自组织网络** | 竞争学习 (SOM等) |
| | **生成对抗网络 (GAN)** | 生成器+判别器博弈 |

## 6.2 线性神经网络与全连接网络 (MLP)

### 6.2.1 线性神经网络：Adaline 与线性可分边界
*   **渊源：** 50 年代末 **Adaline (自适应线性元件)**，早期模式识别/信号处理主力。
*   **结构：** 感知机输出端接**线性变换** → 输出连续实值（而非二值）[图 6-2]。
*   **优势：** 收敛更快、精度更高（最小均方误差 MSE）。
*   **硬伤：** **仅能解决线性可分问题**，XOR 等非线性问题无能为力。这是单层网络的理论天花板。
