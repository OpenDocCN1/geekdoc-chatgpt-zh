## 参考资料

1. 二极管标题法

```
1.1 基本原理
- 本能偏好：最小化用力原则与即时享受。
- 核心驱动：向快乐靠近、远离痛苦，从而产生 2 种刺激类型：正向刺激、负向刺激。

1.2 标题公式
- 正刺激：产品或方法 + 仅需 1 秒（短期） + 即可收获惊人效果。
比如，“8 天背完！英语阅读拿捏！稳上 135！我悟了”“四六级 40 天冲刺计划？？四级 618+六级 590”。

- 负刺激：你不××× + 肯定会后悔（巨大损失） + （紧迫感）。
比如，“你不看这个文章就会错过一个亿，限时删除！！！”“这个秘密我一般不告诉别人，三天后删！”。
```
