知识图谱补全，简写 KBC，和图谱质量校验，是推理能力要解决的两件核心事。

图谱里的信息可以从层次上拆开看，概念层和实体层各司其职。推理的本质就是拿已有的知识去推导出新知识，或者把错误的知识揪出来。概念层主要做概念之间的包含关系判断，实体层聚焦链接预测和冲突检测，而概念与实体之间的桥梁，则是实例检测。围绕这三类任务，目前主流的做法可以归为四类：规则驱动、分布式表示学习、神经网络驱动以及把它们混在一起用的混合方案。

# 1. 规则式推理：可解释的经典路径
规则式推理的思路很直观，先把知识里固有的规律表达成规则再用规则推演。按规则的确定性可以分成硬逻辑规则和软逻辑规则。硬逻辑规则的真值是 1，相当于绝对成立，多由人工编写；软逻辑规则的真值落在 0 到 1 之间，带概率色彩，通常来自规则挖掘系统，学习方式是看结论和条件是否经常一起出现，代表性工具比如 AMIE。软规则可以通过真值重写变成硬规则。硬规则常写成本体里的 SWRL 形式，再交给 Pellet、Hermit 这类本体推理机执行。规则在超大图谱上效率会受离散性拖累，Cohen 提出的 TensorLog 用可微的方式缓解了这个问题。

这条路最大的好处是贴近人的思考，结论能说清说透，所以可解释性强。沉淀在图谱里的规则，演绎能力也相当稳。

# 2. 分布式表示学习：把关系搬进向量空间
分布式表示学习把图谱映射到连续的向量空间，给每个元素学一个低维稠密的向量或矩阵，推理则变成对这些表示的运算。大多数方法以单个三元组为单位学习，对三元组的建模假设各不相同。比如以 TransE 为代表的平移族，把关系看成头实体到尾实体的空间平移，用向量加法模拟。以 DistMult 为代表的线性变换族，把关系表示成矩阵，让头向量的线性变换得到尾向量。RESCAL 更进一步，把图谱看成高维稀疏的三维张量，通过张量分解同时得到实体和关系的表示。

单步之外也有多步的探索，比如 PTransE 和 CVSM，专门处理需要走几步才能得到的推理。

# 3. 神经网络推理：表达力强的建模方式
神经网络的思路是用网络结构直接模拟推理过程。NTN 用双线性张量层来判断头尾实体的关系；ConvE 等方法把实体和关系的向量排出二维矩阵，再用卷积神经网络做链接预测；R-GCN 靠图卷积网络聚合邻居实体的信息；IRN 则用记忆矩阵配合以递归神经网络为核心的控制单元来模拟多步推理。神经网络的表达能力很强，在链接预测等任务上表现突出，而且结构多样，能适配不同需求。

# 4. 混合推理：优势互补的综合体
单一范式各有短板，混合推理把规则、表示学习和神经网络揉在一起。NeuralLP 就是一个可微的推理框架，融合了关系表示学习、规则学习和循环神经网络，LSTM 负责生成多步推理中的隐变量，并据此给每种关系做注意力分配。DeepPath 和 MINERVA 用强化学习来学习多步推理中的路径选择策略。RUGE 会把已有规则注入到表示学习过程中，对表示结果进行约束。也有工作用对抗生成网络 GAN 来提升表示学习阶段负样本生成的效率。综合来看，混合路线既能提高精确度，又能兼顾可解释性。

规则类研究的格局目前大致分两块，一块是自动规则挖掘系统，一块是基于规则的推理系统。两者的发展方向都在往提升挖掘效率和准确度走，也在用神经网络结构替代传统知识... 理、基于分布式账本的术语及实体命名管理、基于分布式账本的知识溯源、知识签名和权限管理等，具体做法仍在探索中。

# 30 | 知识图谱：方法、实践与应用
知识的可信与鉴真，是很多图谱项目绕不开的痛点。数据来源分散，可信度评级要细到实体和事实层级，如何对海量事实进行管理、追溯和鉴真，正成为区块链技术在图谱领域的重要切入点。

把图谱带进智能合约也能补位。传统合约常受内生知识不足困扰，引入图谱可以形成闭环。例如 PCHAIN 引入知识图谱 Oracle 机制，用来解决传统智能合约数据不闭环的问题。

## 1.7 本章小结
从系统视角看，知识图谱可以当成一种新型信息基础设施。数据层面，它要求用更规范的语义提升企业数据的质量，用链接数据的思路提升关联度，终极目标是把粗糙的非结构化、松散数据炼成结构化、高度关联的高质量知识。大多数企业都需要把图谱当作面向数据的持续建设型基础设施来做。

技术层面，构建涉及知识表示、关系抽取、图存储、数据融合、推理补全等，应用涉及语义搜索、知识问答、自动推理、知识驱动的语言与视觉理解、描述性数据分析等。既要系统性地调动知识表示、自然语言处理、机器学习、图数据库、多媒体处理等多个领域的技术，又要以系统思维为导向，这已成为趋势。

互联网带来大数据集聚，大数据推动算法迭代，新数据和新算法为规模化图谱构建提供了条件。图谱作为知识载体，已在语义搜索、智能问答、数据分析、自然语言理解、视觉理解、物联网互联等场景中发挥越来越大的作用。AI 浪潮持续升温，作为底层支撑的知识图谱赛道正从冷门走向升温，通往未来的必经之路。
