[PRE0]这一步里 past_value 不做任何 reshape，保持 batch_size × num_head × seq_len × head_features 的形态；与此同时，当前 token 产生的 value 形态是 batch_size × num_head × 1 × head_features。把这两部分沿倒数第二维 dim=-2 做拼接，就能把当前 token 的 value 接在历史 value 序列后面，为下一步的解码做准备。拼接完成后的 value 变成 batch_size × num_head × seq_len+1 × head_features，序列长度也随之更新为 new_seq_len = seq_len+1。
