香农暮年与信息论的永恒光环

20世纪80年代末，香农的记忆开始明显衰退，之后确诊为阿尔茨海默病，也就是人们常说的老年痴呆。晚年他在私立疗养机构度过，2001年2月24日离世。信息论与编码权威 Richard Blahut 在香农塑像揭幕时这样评价他：

“我觉得三五百年后，回头看我们这一代，或许记不起谁当过美国总统，也记不起哪位是明星或摇滚歌手，但香农的名字仍会被提及，高校里依旧会讲信息论。”

这是发自内心的敬意。IEEE 为彰显香农的贡献，自[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)1972年起设立 Claude E. Shannon Award 香农奖。与图灵奖并称为计算机科学的最高荣誉一样，香农奖成为信息与通信领域的顶级奖项，而香农本人正是首届得主。

### 2.6 达特茅斯之后的首轮爆发

达特茅斯会议收官后，AI 进入第一次集中井喷期，好消息连连，被视为典型人类智力的几个方向先后出现了机器雏形，诸如：

• 完全信息对抗
• 机器定理证明与问题求解
• 模式识别
• 基于自然语言的人机交互
……

50年代的计算机仍是高度专业的研究设备，公众只能通过报刊新闻窥见只言片语。媒体既缺专业储备又要博取眼球，往往把尚处萌芽的进展渲染成机器即将全面征服该领域的壮举。本节梳理这些早期尝试，看初生AI究竟“攻克”了哪些智能难题。

#### 2.6.1 完全信息对弈

先说完全信息对抗。博弈论里 Perfect Information 指双方掌握推导策略所需的一切信息。策梅洛定理 Zermelo's Theorem 证明，在没有随机因素的对抗中，一方可通过递归推导获得不败策略，即占有完全信息。听起来很学术，最直观的例子就是棋类。棋一直是人类智力竞技的载体，胜负分明，因此图灵、冯·诺依曼、香农、纽厄尔、司马贺、麦卡锡等早期推动者，对用棋局来展示机器智能有近乎偏执的执念。如今深蓝、AlphaGo 在棋盘上耀武扬威，可当年机器下棋曾历经数十年被人类压制的低谷才翻身。

二战期间通用可编程机尚未诞生，图灵已在纸上构想过国际象棋程序，1947年才有雏形。光说水平不算，走一步竟要半小时就让人难以接受，准确地说是机器吃不消。彼时机器需排队申请，算力极其稀缺。到1951年，图灵同事唐纳德·米歇 Donald Michie 在曼彻斯特 Mark-1 机上完成了一个离将死仅两步的残局象棋程序。图灵本人虽未做出实用系统，却在《计算机器与智能》一文中呼吁优先从下棋寻找机械智能的痕迹，吸引大批后来者接力挑战。

与图灵同期另两位天才把下棋理论化了。冯·诺依曼1944年与经济学家奥斯卡·摩根斯顿 Oskar Morgenstern 合著《博弈论》时首次提出对弈的 Minimax 算法。这是一种零和思路，一方在可选分支中挑选使自身优势最大化的路径，另一方则挑选使对手优势最小化的路径，对弈过程形成博弈树。今天学生常用它写井字过三关这类小游戏，但算法随博弈树深度呈指数级复杂度，不经优化只能处理小规模问题。达特茅斯会议上麦卡锡提出的 α-β 剪枝就是对 Minimax 树深度的有效控制，多数情况下在抵达叶节点前就能判断分支是否需要继续展开，至今仍被广泛使用。直到近年，计算机才敢挑战围棋这种即便摩尔定律再稳定运行数千年也难以靠硬算与剪枝穷举的终极棋局，基于概率剪枝的蒙特卡洛树搜索⁵⁰

香农1950年发表论文《程序实现计算机下棋》“Programming a Computer for Playing Chess”，开启了计算机下棋的理论研究。他把棋盘抽象为二维数组，并从数学角度给出棋类复杂度的评估方法。此前人们只定性认为围棋比国际象棋难、国际象棋比跳棋难，香农的文章让我们能定量回答攻克国际象棋比攻克跳棋难多少倍、围棋又比国际象棋难多少倍这类问题。

此后大多数棋类程序，从塞缪尔的西洋跳棋程序、纽厄尔与司马贺的国际象棋程序，到击败人类世界冠军的 IBM 深蓝，都建立在香农、冯·诺依曼与麦卡锡总结的理论与算法之上，多年的改进主要集中在硬件提升和局部技巧优化上，直到基于深度学习与概率的评估函数等新思路得到验证，计算机下棋在理论层面才算实质性进步。

#### 2.6.2 模式识别

第二项机器定理证明与问题求解，前文介绍逻辑理论家时已简述，且下一章讲符号主义学派时会再涉及，这里略过，直接看第三项成果：模式识别 Pattern Recognition。

模式识别听起来专业，人类的模式识别能力与生俱来很强。我女儿4岁时只在幼儿园绘本和电视早教里见过大象卡通，第一次带她去动物园见到真大象，她就能立刻建立“这就是大象”的认知，哪怕真大象与卡通形象差异巨大。而要让计算机完成模式识别就困难得多，试想如何给“大象”下一个特征定义，让程序据此判别一个物体是不是大象。

1958年，塞弗里奇在《魔宫：一种学习范式》Pandemonium:A Paradigm for Learning 中提出首个模式识别特征匹配模型，称作“魔鬼城堡”模型。按塞弗里奇的说法，该模型有四层等级系统，每层由“魔鬼” Demon 执行特定任务依次工作，直至完成识别。四层由低到高依次是“印象鬼” Image Demon、“特征鬼” Feature Demon、“认知鬼” Cognitive Demon、“决策鬼” Decision Demon。塞弗里奇用奇幻风格描述，但从神经网络视角看，这个模型其实相当于一个四层神经网络，逐层特征提取的思想正是现在卷积神经网络的精髓，将在第7章展开。1957年罗森布拉特完成的能识别英文字母的感知机 Mark-1 本质上是基于神经网络实现的，不过是个单层网络，与塞弗里奇的“魔鬼城堡”并无直接关联。

1959年，塞弗里奇完成了一个可实用的能识别手工印刷体 Hand-Printed 英文字符的模式识别程序。操作者扫描印刷内容后，程序会自动剔除页边留白、字体粗细等印刷干扰，完成噪点消除、边缘增强等处理，并把结果存入一个32×32的数组，每个单元用0和1分别表示黑色和白色，最后对该二维数组进行识别并输出结果⁵³[EPUB...](https://t.me/+WwC4dCWvXRdhOTNh)[PRE1]​。同年IBM也发布了一个光学字符识别程序，提出“光学字符识别” Optical Character Recognition，OCR 的概念，计算机模式识别由此开始商业化初步尝试。

1962年，IBM在西雅图世界博览会上发布一款名为“Shoebox”的语音识别机器，如图2-11所示。该机器可理解16个英文单词，即0到9十个数字的英文，以及 Minus、Plus、Subtotal、Total、False、Off 六个操作指令，使用者用语音说出想要计算的内容，机器便会打印出结果，Shoebox可能是最早具有实用价值的模式识别成果。

#### 2.6.3 自然语言处理

在人工智能首个快速发展期，自然语言处理领域也出现较大突破，人机对话、机器翻译从零到一。人们设想智能机器必须能用自然语言而非纸带、指示灯、屏幕键盘与人交互，在此基础上自动翻译、秘书助理等应用才顺理成章。

同一时期语言学界也在发生革命。20世纪前半段美国语言学界主流是伦纳德·布鲁姆菲尔德 Leonard Bloomfield,1887—1949 建立的“结构主义语法” Structural Grammar，该理论认为语言中有意义的形式排列即构成语法，反对依据语义分类。而乔姆斯基1957年发表名著《句法结构》 Syntactic Structure，提出革命性观点，他认为语言能力是人类心智的一种基本功能，人脑天生存在处理语言的“模块”。由于人脑结构一致，人类最根本的语言处理机制是共通的，可视为“通用语法” Universal Grammar，各种语言的具体语法可由通用语法转换生成。乔姆斯基提出的语法被命名为“转换生成语法” Transformational-Generative Grammar。

转换生成语法首先被引入计算机科学并获得巨大成功。这里还要提到乔姆斯基1956年提出的著名“乔姆斯基层级” Chomsky Hierarchy。该层级包含四层语法：0型语法描述递归可枚举语言，对应自动机是图灵机；1型语法是上下文有关语法；2型语法是上下文无关语法；3型语法描述正则语言，对应有限状态自动机。对非计算机或语言学专业的读者这串名词可能陌生，但对计算机专业读者而言，这是编译原理最基础的概念。简单说，乔姆斯基为高级程序设计语言和编译器的设计提供了语言学理论基础，使从一种形式语言转换生成另一种更基础的语言成为可能。若无乔姆斯基贡献，程序员或许仍需使用与机器指令一一对应的汇编语言开发，一边查指令表一边敲代码。

不过，转换生成语法在自然语言上的成效远不如在计算机语言上，毕竟计算机语言与自然语言复杂度不可同日而语。自然语言的歧义性，如“打击力度”是名词短语而“打击盗版”是动词短语，以及语法规则的不确定性，都是其复杂来源。从学术角度看，经过一系列学说大辩论，今天主流语言学界并不认同乔姆斯基的观点。但无论如何，对20世纪50年代起步的自然语言处理 Natural Language Processing，NLP 学者而言，终于有一套可被计算机操作的理论可供指导。直至20世纪80年代前，NLP的主要思路都是按“短语结构语法” Phrase Structure Grammar，PSG，即转换生成语法的一个分支进行分析。
