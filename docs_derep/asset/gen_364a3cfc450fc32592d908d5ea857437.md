从先辈们在自然语言处理上的探索出发，沿着模型范式演进的线索，可以把该领域的发展梳理为七个阶段，具体如图2-2所示。

# 1. 萌芽启蒙期（1913—1956年）

这一阶段的代表人物包括图灵、马尔可夫、史蒂芬·科尔·克莱尼和香农。比较典型的成果有图灵的算法计量模型、马尔可夫模型、固定权重的单层神经元模型McCulloch-Pitts，以及克莱尼的有限自动机理论，其中就包含香农提出的基于概率的有限自动机模型。当时学界更多在思考如何用图灵算法计量模型来刻画自然语言、词语及其关联，处于理论思辨层面，并未诞生太多可用的应用。

谈到自然语言处理的开端，马尔可夫模型是绕不开的。马尔可夫认为语言内部存在关联性，能够用概率模型来描述。1913年，他从普希金的小说《叶甫盖尼·奥涅金》中抽取了2万个字母，去掉标点、停顿和空格后形成字母序列，随后对该序列做了统计，得到如图2-3所示的结果。

图2-3显示，《叶甫盖尼·奥涅金》中的字母序列呈现出明显的概率统计规律，辅音后面接元音的概率最高，达到87.2%，而元音后面再接元音的概率最低，仅12.8%。

在深入研究后，马尔可夫提出，某个事件的下一个状态概率分布只取决于当前状态，与更早的事件无关，这就是著名的马尔可夫链。

结合马尔可夫链与《叶甫盖尼·奥涅金》字母序列的概率规律，可以初步借助概率方法判断给定文本中某个词或字母出现的可能性。若统计样本足够大、算力足够强，就能用马尔可夫链的概率计算方式预测下一个可能出现的字母或单词。

λ = (S, π, A)

其中，S为状态集合，π为初始概率分布，A为状态转移概率矩阵。

香农在马尔可夫链的基础上进一步指出，语言的统计特性是可以建模的，基于该概率模型还能有效生成语言。通过大量实验，他发现挖掘更多基于概率先验知识构建的模型越复杂，生成的语言抗噪声能力越强，也越贴近真实自然语言。例如，给系统“喂入”大量英文文本，系统可以学习不同字母、不同单词出现的统计概率，以及字母间、单词间的转移矩阵。再加入少量语法规则，如句子首字母大写、人名地名首字母大写等，就能构建更复杂的模型，生成的语言更接近英语。

香农所处的年代算力极其有限，无法输入海量英文文本，只能在小数据上做实验。尽管如此，他的前瞻性观点为后来的概率建模生成语言打开了思路。

# 2. 规则形式语言阶段（1957—1970年）

1957年，诺姆·乔姆斯基在有限自动机理论基础上提出形式语言理论，这一年的贡献被载入史册。形式语言理论的核心支撑是有限状态语言模型。

有限状态语言模型按线性顺序挑选语言的基本构件，例如主谓宾，后选构件受先选构件制约，这种制约即规则与约束。乔姆斯基认为：语言是由有限自动机产生的符号序列构成的，语法是研究具体语言中构造句子的方法和加工过程①，它应当能生成所有合乎语法的句子。

按乔姆斯基的观点，语言的基本单位是符号，符号序列遵循特定语法结构形成句子，句子再按句法结构形成语言。

此外，乔姆斯基还提出了四种语言模型：正则语言模型、上下文无关语言模型、上下文相关语言模型与递归可枚举语言模型。下面以上下文无关语言为例，假设句法遵循主谓宾结构。

基于形式语言模型，中国计算语言学家冯志伟在20世纪80年代发布了多叉多标记树形图模型，这是一个基于短语的机器翻译模型。在此基础上，他人工设置了数万条语法和句法规则，研发出全球首款可将中文译成外语的FAJRA系统，FAJRA是法语-英语-日语-俄语-德语的法语缩写。若输入为常用规范中文，FAJRA翻译准确率可达90%以上。但若扩大输入范围和自由度，准确率会降至70%左右。这也侧面说明，单纯依赖规则形式语言方法会遇到明显精度瓶颈，需结合其他方法才能突破。

# 4. 浅层机器学习期（1996—2005年）

使用规则、概率模型和语料库融合方法后，即传统融合方法，准确率大幅提升，但在语义理解与处理等难题上仍受限。换句话说，传统融合方法更多依赖预先构建的知识库，学习能力不足，泛化能力偏弱，进而影响准确率。

浅层机器学习正好能在一定程度上弥补不足，展现学习与推理能力，有助于优化文本分类、消歧、语义分析、情感分析等。

最早进入自然语言处理的是朴素贝叶斯模型，该模型也可视为基于概率的统计模型。随着概率方法兴起，它曾风靡一时。例如1959年，Woodrow Wilson Bledsoe等人用朴素贝叶斯建立了早期文本识别系统；1961年，M. E. Maron在论文“Automatic Indexing: An Experimental Inquiry”中首次将朴素贝叶斯用于文本分类。

朴素贝叶斯优点在于模型简洁、稳定、高效，对小样本表现良好，常用于文本分类、增量学习等场景。但局限也很明显，如样本独立性假设与许多场景不匹配、先验概率难以计算、准确率不高，这些限制了其发展。

随后更多浅层算法涌现，如K近邻、逻辑回归、决策树、随机森林、支持向量机、提升树等，被广泛应用于自然语言处理任务。与传统融合方法相比，浅层算法能有效用于分类、聚类、预测等数据挖掘任务，运算效率较高，准确性和稳定性也有明显提升。

此外，很多浅层算法如线性回归、决策树具有良好的可解释性，在金融、电信、电商等领域深入应用，有力推动了数据智能发展，提升企业商业价值。

特别值得强调的是，提升树算法如GBDT、XGBoost、LightGBM的提出大幅提升了效果，几乎适用于所有场景，当时成为数据挖掘和机器学习应用的标配。

不过使用浅层算法解决实际问题也存在痛点，如特征工程耗时费力、需要大量数据标注、模型信息含量与人工投入成正比、非线性关系挖掘有限、输入以结构化数据为主、推理与泛化能力有限等。深度学习的提出在一定程度上解决了这些问题，提升了推理、泛化和建模效率。

需要强调的是，深度学习能快速落地产生商业价值，也与算力提升和数据大爆炸密切相关。深度学习计算复杂度远高于浅层机器学习，需要强大算力支撑。从某种角度看，大算力是深度学习高速发展的重要基础。

# 5. 深度学习期（2006—2017年）

2003年，Yoshua Bengio等人提出神经网络语言模型NNLM，但受训练难度限制，当时仅停留在理论层面。直到2006年，深度学习泰斗Geoffrey Hinton与Ruslan Salakhutdinov发表论文“Reducing the Dimensionality of Data with Neural Networks”，由此掀起深度学习在自然语言处理领域快速发展的浪潮。他们主要提出三点：多层神经网络能挖掘更多隐含信息；能实现特征工程自动化；可通过逐层初始化预训练解决多层网络训练难题，相当于解决了Bengio关于神经网络语言模型训练的问题。这三点对学界和工业界具有划时代意义。

另一个里程碑是词向量技术与表征方法的提出。在词向量诞生前，自然语言文本在很多场景存在高维稀疏特征问题，影响识别准确率。简单说，词向量是一种特征提取技术，将词从稀疏空间通过隐藏层投影到低维稠密向量空间，语义相近的词在低维空间距离也相近，不仅解决矩阵稀疏问题，还实现了特征自动提取。词向量技术将自然语言处理推进了一大步。

2008年，Ronan Collobert等人在论文“A Unified Architecture for Natural Language Processing: Deep Neural Networks with Multitask Learning”中提出将词向量作为深层神经网络的目标任务，打开了词向量表征技术的大门。2013年，Tomas Mikolov提出经典的Word2vec词向量表征方法，包含CBOW和Skip-gram。随后学界陆续提出GloVe和ELMo等经典模型。

随着卷积神经网络CNN在图像处理中大放异彩，其被广泛应用于文本分类、语义理解、文本生成、机器翻译等任务，效果显著。

CNN明显缺陷是缺少记忆能力，而自然语言序列具有时序性和长程性，需要记忆先前输入。基于此，循环神经网络RNN被提出。RNN因具备记忆能力，被广泛用于语言建模、聊天机器人、机器翻译、语音识别等任务。

RNN面对长序列数据存在梯度消失缺陷，对长期记忆不敏感，容易丢失远期信息，换句话说，只能获取较近的文本序列信息。由此，RNN的优化变种长短时记忆网络LSTM和门控循环单元GRU被提出。

LSTM加入输入门、遗忘门和输出门三个门，GRU引入重置门和更新门两个门。总体看，LSTM参数更多，收敛更慢，效率更低；GRU为提升运算效率而牺牲部分精度。

类RNN算法需按时序输入，难以并行计算，编码效率低下。针对该痛点，2017年Ashish Vaswani等人提出Transformer模型，核心是自注意力机制。与RNN相比，Transformer能挖掘各类特征、有效记忆历史信息，且支持并行运算，因而被广泛应用于自然语言处理的复杂任务并取得良好效果。

# 6. 预训练语言模型期（2018—2021年）

预训练语言模型到底解决了哪些问题？熟悉机器学习的读者都知道，模型效果好需要大量标注的训练数据和测试数据。而现实中，与海量未标注数据相比，高质量标注数据凤毛麟角，且标注耗时耗成本高。为解决此问题，预训练方法应运而生。

“预训练”通常是将大量低成本收集的训练数据放在一起，通过某种预训练方法学习共性，再将这些共性“迁移”到执行特定任务的模型中，用少量领域标注数据进行微调。模型只需从共性出发学习特定任务的特殊部分即可。

预训练实质是把学习任务分解，先学习数据量庞大的共性知识，再逐步学习垂直领域专业知识。例如，让不懂中文的机器人成为中文法律专家，因法律领域标注数据少，可分解任务：

第一步，先让机器人学会中文，达到熟读理解中文水平。中文标注数据量大、来源丰富，有助于机器人学到充分知识。

第二步，让机器人学习法律专业知识。结合已学共性知识与法律专业知识，可大幅提升学习效率与效果。也可以进一步分解，先学法律行业共性，再学更垂直领域的专业知识，效果更佳。

若直接从零到一学习中文法律知识，受语料库有限、文本与标注数据缺乏影响，学习效果和效率大概率不达预期。

我们认为，预训练语言模型的诞生是行业里程碑。预训练机制大幅降低了自然语言处理的门槛，让初创公司能在预训练模型基础上优化，并在各垂直领域应用中获得良好效果。这极大推动了自然语言处理在各行各业的快速应用与赋能，为AI飞入寻常百姓家立下汗马功劳。

2018年，Jacob Devlin等人在论文“BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding”中提出BERT模型。该论文展示的测试效果在多个自然语言理解任务中刷新纪录，一时间成为最热门的模型。
