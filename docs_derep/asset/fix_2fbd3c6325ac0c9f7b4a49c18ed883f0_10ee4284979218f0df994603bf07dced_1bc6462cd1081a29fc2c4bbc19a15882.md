<|begin_of_sentence|>请问如何证明根号2是无理数？我记得这个证明要用到无限下降法，或者说归谬法，但具体的步骤我还不太清楚。

模型采用反证路线展开。先把无理数的定义明确为无法写成整数比的形式，随后假定√2可以表示为最简分数 p/q。平方后得到 2 q² = p²，可知 p² 为偶数，进而 p 能被 2 整除，写成 p=2k 代入则推出 q²=2k²，由此 q 亦为偶数。这与 p/q 已化为最简的设定相冲突，说明初始假定不成立。递推下来会产生越来越小的正整数解，在自然数中不可能无限下降，因此√2 不可能是有理数。

[PRE4]

更紧凑的写法如下。设√2 = p/q 且 p、q 互素。

\[ 2 = \frac{p^2}{q^2} \]

去分母得：

\[ 2q^2 = p^2 \]

于是 p² 为偶数，p 必为偶数，记 p = 2k。

代入得：

\[ 2q^2 = (2k)^2 = 4k^2 \]

化简：

\[ q^2 = 2k^2 \]

故 q² 也是偶数，q 必为偶数。p、q 同时含因子 2，与互素前提矛盾。证毕。
