# 第四章 劳动基准在数字时代的重塑
沈建峰
中央财经大学法学院教授

先把研究边界厘清。把“网络时代”当作时间标签来用，很容易把范围放得过宽。按时间义理解，就是互联网兴起后正在发生的当下。若只按这个时间切入，劳动基准的创新就等于当下的创新，抓不住重点。更有操作性的是把它当成技术语境：当网络、信息、数字技术深度介入生产，劳动基准在理论和制度层面出现了哪些新张力，这正是本章要处理的视角。

严格说，网络、数字、信息三类技术并非完全同义，网络更指向连接与互联的特性。若只按最窄解释，本章就只能谈互联网本身带来的冲击。现实中推动规则重塑的并非单一互联网，而是互联网叠加数字与信息技术后的综合效应，它们共同冲击了工业时代沉淀的基准框架。所以这里的“网络时代”，实指数字与信息技术共同塑造的劳动环境，行文中不刻意区分网络、数字、信息等表述。

展开思路分两步：先梳理数字劳动世界的基本变化和由此产生的制度压力，再回看劳动基准法如何回应。过程中要先厘清基准本身的内涵，打破“劳动基准法只是公法”的固有印象，在此基础上探讨具体制度该怎样创新。

## 一、数字用工的全貌与劳动法的挑战
### （一）学界如何描述用工关系的演变

# 去组织化的三重松动
关于数字或网络时代雇佣关系的演进，学界有比较集中的概括，核心是去组织化的三重松动：保障松动、集体松动、权力松动。

保障松动意味着技术迭代可能动摇我们今天看得很重的岗位稳定性^[([1]](#txt005.html#footnote_content_txt005_1))。数字技术让岗位寿命缩短，劳动法传统上寄予厚望的工作保障、薪酬保障、工时保障都更难落地。

集体松动指的是数字工具能对劳动者供给侧做更细的切割和绩效打分，差异被放大，个体化增强，劳动者抱团争取共同利益的难度上升^[([2]](#txt005.html#footnote_content_txt005_2))。

权力松动描述的是数字手段放大了管理方的掌控力、压缩了劳动者的自主空间。具体表现为用工管理朝着扩大和完善对雇员和受托人的监督可能性的方向；朝着更多地使用工作流程的数字化处理方法和对员工进行算法管控的方向；朝着人员、工作和生产过程中的数据、信息及知识资源的单向积累的方向^[([3]](#txt005.html#footnote_content_txt005_3))。
