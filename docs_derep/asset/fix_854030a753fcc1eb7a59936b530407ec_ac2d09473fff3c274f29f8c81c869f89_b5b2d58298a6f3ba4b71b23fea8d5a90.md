Faiss 索引实战：IVF、PQ、IVF-PQ 该怎么选

向量检索规模上去之后，Faiss 基本是标配。最近我把几套常见索引都跑了一遍，先用 1 万条 128 维随机向量做快速验证，再用 100 万条 126 维向量做压力测试。整体感受很清晰：粗筛交给 IVF，压缩交给 PQ，叠加使用才是线上主力，分片则提供另一种横向扩展思路。

小样本对撞：平面 IVF 与 PQ 量化几乎打平
先在 1 万条数据上建一个聚类数 100、nprobe 设为 10 的 IndexIVFFlat。训练、写入完成后查 Top5，首名长期稳定在 2734 附近，距离约 1.27，之后几名多为 9985、7356、5621、3459，距离落在 1.27 到 1.28 之间。

换到 IndexPQ，同样 1 万条，子向量 8 维、8bit 量化，流程保持一致。查询结果的前五排序与 IVF 高度重合，距离只在小数点后出现轻微波动。说明在数据量不大的阶段，量化对召回的损耗很小，存储和查询效率却明显改善。

调参方向很直接：聚类数和 nprobe 同时拉高
把倒排的聚类数从 100 提升到 200，nprobe 从 10 提到 20，重建后查准更稳。聚类越细、搜索的桶越多，召回提升的同时耗时也会线性增长，这个权衡在实测里非常明显。

百万级场景：多级 IVF-PQ 扛得住
数据量拉到 100 万、维度 126 时，纯 IVF 成本偏高。用 IndexIVFPQ 把倒排和量化叠起来：倒排 1000 个桶，PQ 切成 16 个子向量，每个 6bit。训练并写入 100 万向量后，nprobe 设为 20 查询。Top5 典型结果为 963427、453769、127354、765234、112234，距离大致在 1.43 到 1.47 区间，证明多级方案在百万量级仍能稳定返回邻近。

分片并行：把大索引拆成多小索引
另一种扩容方式是分片。将 100 万向量均分 4 份，每份 25 万，各自建独立的 IndexIVFFlat，聚类保持 1000，单片 nprobe 用 10 保证速度。各片独立训练写入后，对同一查询逐片取 Top5，再做全局索引偏移校正并合并排序。合并后的全局前五与 IVF-PQ 的结果一致，说明分片在保持一致性的前提下可以横向提速。

总结
万级验证里 IVF 平面与 PQ 在召回上差别很小，PQ 更省存储。加大聚类数和 nprobe 能有效提升查准。百万级生产场景，IVF-PQ 是性价比最高的组合，分片则提供更灵活的水平扩展路径。选型时以数据规模、延迟要求和内存预算为核心，三者配合基本能覆盖大部分检索需求。

import numpy as np

import faiss

# 设置随机种子和示例数据

# 查询向量

# Step 1: 构建倒排平面索引 (IndexIVFFlat)

index_ivf.add(data_vectors)

print("倒排平面索引(IndexIVFFlat)中已添加向量总数:", index_ivf.ntotal)

# 设置nprobe参数：nprobe越大，精度越高，但查询时间也会增加

index_ivf.nprobe=10  # 在10个聚类中搜索

import numpy as np

import faiss

# 设置随机种子和大规模数据集

np.random.seed(42)

dimension=126 # 向量维度

num_vectors=1000000 # 大规模数据集

data_vectors=np.random.rand(num_vectors, dimension).astype('float32')

# 查询向量

query_vector=np.random.rand(1, dimension).astype('float32')

# Step 1: 构建多级索引(倒排索引+产品量化)

num_clusters=1000 # 聚类数量

index_ivf_pq=faiss.IndexIVFPQ(faiss.IndexFlatL2(dimension), dimension, num_clusters, 16, 6)

# IndexIVFPQ参数: dimension(向量维度), num_clusters(倒排聚类数), 16(PQ的子向量数), 6(每个子向量的量化位数)

# 训练多级索引

index_ivf_pq.train(data_vectors) # 必须先训练索引

index_ivf_pq.add(data_vectors) # 添加数据

print("多级索引(倒排+产品量化)已添加向量总数:", index_ivf_pq.ntotal)

# 设置nprobe参数增加搜索精度

index_ivf_pq.nprobe=20 # 在20个聚类中搜索

# 执行查询, 查找Top-k最近邻

k=5

distances_pq, indices_pq=index_ivf_pq.search(query_vector, k)

print("\n多级索引(倒排+产品量化)查询结果(Top 5最近邻): ")

# Step 2: 使用分片策略构建索引

# 将数据分为若干分片, 每个分片构建一个独立索引

num_shards=4

shards=[faiss.IndexIVFFlat(faiss.IndexFlatL2(dimension), dimension, num_clusters) for _ in range(num_shards)]

# 将数据分配到各个分片

for i, shard in enumerate(shards):

    shard_data=data_vectors[i * (num_vectors // num_shards): (i+1) * (num_vectors // num_shards)]

    shard.train(shard_data)                 # 每个分片单独训练

    shard.add(shard_data)

    shard.nprobe=10                         # 设置较小的nprobe, 提升各分片内的查询速度

    print(f"分片 {i+1} 已添加向量数量:", shard.ntotal)

# 通过分片执行查询

results=[]

for i, shard in enumerate(shards):

    distances, indices=shard.search(query_vector, k)

    # 记录分片中的结果

    for j in range(k):

        results.append((indices[0][j]+i * (num_vectors // num_shards), distances[0][j]))

# 排序并返回整体Top-K结果

results=sorted(results, key=lambda x: x[1])[:k]

print("\n分片索引查询结果 (Top 5最近邻): ")

for idx, dist in results:

    print(f"全局向量索引: {idx}, 距离: {dist:.4f}")
