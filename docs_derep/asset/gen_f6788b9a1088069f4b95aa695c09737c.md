## 1.2 AI 智能体技术全景拆解

要看清一个基于大模型的智能体如何工作，得先拆开它的架构、设计思路和与外界的连接方式。

### 1.2.1 核心模块架构
[PRE1]

图 1-1　AI 智能体的核心模块

大模型在智能体里扮演“大脑”的角色，整体由记忆、规划、工具、行动四大部分支撑。

记忆模块负责信息沉淀，内容涵盖过往对话、学到的知识以及当前任务的临时信息。记忆好不好直接决定复杂问题能否调用经验。它被划分为短期与长期两种，短期主要服务于上下文学习，长期则借助外部知识库和快速检索实现信息的长期保存与召回。

规划模块包含事前规划和事后反思两个环节。事前规划对下一步行动做预测和决策，帮助把目标拆成高效的执行路径；事后反思则回看执行结果，总结错误并把经验写入长期记忆，让世界模型持续更新。常用的规划手段有反射、自我反思、思维链以及子目标拆解。

工具模块让智能体能调用外部资源。典型做法是调外部 API 补全模型训练数据之外的信息，或借助专业软件处理海量数据，从而提升效率和完成度。

行动模块是决策落地的执行层。智能体内置多套行动策略，会根据任务类型选择记忆检索、推理、学习或编程等不同方式作出响应。

### 1.2.2 主流设计范式
2024 年 3 月 26 日，吴恩达在红杉资本人工智能峰会上做了题为“Agentic Reasoning”的演讲，分享了他对智能体发展的判断，并总结出当时流行的四种设计范式：反馈、工具使用、规划、多智能体协作。

反馈范式让模型通过自我反思和迭代修正来提升执行质量，初始解被反复检验和优化，而不是一次定案。

工具使用范式突破模型自有知识的边界，通过调用外部工具或库完成任务，提高准确性和效率。

规划范式强调先行组织步骤，把复杂目标分解为可执行的子任务并按序推进。

多智能体协作范式让多个智能体分工合作，通过交流共享信息，共同解决更复杂的任务。

### 1.2.3 推理引擎
推理引擎也称认知框架，是智能体做规划、决策和调用工具的核心。它依托提示词工程的技术进展来指导思考。

当前比较有代表性的有推理与行动 ReAct、思维链 CoT、思维树 ToT。

ReAct 提供一套思考-行动的提示策略，能在有无示例的情况下引导模型推理并执行动作。实测显示它在多个关键指标上优于不少基线，还增强了人与模型的可交互性，可信度也更高。

CoT 通过中间推理步骤实现链式思考，衍生出自我一致性、主动提示、多模态 CoT 等子技术，各有适用场景。

ToT 更擅长探索和前瞻性任务，它在 CoT 基础上允许模型并行探索多条思维路径，作为通用问题求解的中间环节。

智能体可单一或组合使用这些引擎来确定最优的下一步策略。其中 ReAct 已被 LangChain、LlamaIndex 等主流开发工具采纳，用来构建能够复杂推理并有效行动的智能体。

### 1.2.4 与外部世界的交互
大模型信息处理能力强，但缺乏直接感知和干预现实世界的能力，实用性受限于训练数据覆盖。赋予实时交互和上下文感知能力主要有函数调用、插件扩展、数据存储三种方式。

函数调用是连接模型与外部工具的机制。调用时用户先描述函数的功能、入参和出参规范，模型据此从自然语言中挑选函数并生成 JSON 格式的参数。用户执行函数后把结果回传，模型再组织成自然语言回复。

插件扩展可在智能体之外独立开发，作为配置一部分加载运行。运行时模型结合示例动态判断哪款插件最匹配当前问题。插件通过调用外部 API 等方式扩展能力。常见分为三类：信息增强类，用于获取实时或专业信息如股价、新闻；服务增强类，用于自动化预订、点餐等日常任务；交互增强类，可接收知识库、PDF、图片、语音等多模态输入，并生成表格、思维导图等多模态输出。

数据存储让模型能访问最新事实。原始文档被转为向量表示，供智能体检索补充下一步决策或生成回复。实践中多用向量数据库存储高维向量，实现运行时快速检索。检索增强生成 RAG 在此基础上，让智能体能快速读取网页、PDF、CSV 等多种格式数据，拓宽知识广度和深度。

上述机制共同搭建起基础模型到外部世界的桥梁，使智能体不仅能完成任务，还能在智能家居调节、日程更新、数据库查询、指令邮件发送等场景下更准确可靠地执行。

### 1.2.5 智能体工作流
传统工作流是按预定义规则顺序执行的任务集合，强调标准化和自动化，常以流程图或状态机实现，适用于结构化可重复的场景，例如代码提交→评审→测试→部署。

在 AI 时代，工作流与智能体融合为智能体工作流。它以大模型为底座，让多个智能体协作把复杂任务拆成可管理子任务并迭代细化。工作流像蓝图提供秩序，智能体像执行者提供智慧与灵活性，二者结合价值更大。

典型实现有三种模式。

链式工作流把步骤线性串联，前一步输出作后一步输入，适合步骤明确且强依赖的场景，如新闻内容筛选与排序。
