# 换个躯壳，重写感知：当虚拟现实让大脑“多身并用”

躯体的形态，竟能悄然重塑我们感知世界的方式。虚拟现实技术打破了物理限制，为灵魂“换装”提供了灵活通道。早期研究中，斯莱特团队让成年人进入儿童尺寸的虚拟躯干，结果参与者对物体大小的判断系统性偏大，自我认同也向儿童特质倾斜。另一实验里，白人志愿者在深肤色虚拟体内停留约十分钟，针对其他种族的隐性偏见显著下降。

近期一项更大胆的研究追问：大脑能否同时接纳三具截然不同的身体？41名志愿者佩戴全套装备，轮流驾驭三个机器人实体：在演讲厅操控真人大小的“机器人演讲家”面对人群发声；在聊天室化身“Nao”小机器人与人闲谈；在虚拟健身房恢复人形，协助虚拟伙伴完成康复训练。切换间隙由智能代理托管。实验结束时，志愿者普遍报告强烈的“传送感”与“临场感”，仿佛真切置身那些空间，与当地人零距离共处。“我分明感觉自己被传送了。”一位参与者感叹。

要让动作与触觉在人机间实时、无损流转，技术仍有漫漫长途；长期“多身共生”的后果更是未知数。大脑的包容度也有边界——橡胶手错觉若换成木块便失效，说明真实感是前提。但斯莱特系列实验暗示：人类或许能驯服机械躯壳，甚至驾驭多具形态各异的机械分身。若此技术普及，人机关系将如何重塑？共情半径会否拓宽？我们能否真懂“作为蝙蝠或机器人生存”意味着什么？答案令人心潮澎湃。

## 尾声：意识探索的未竟之境

这些年，人类对意识的认知跨越巨大，核心谜题却依然悬而未决。我们究竟站在何处？

面对堆积如山的未解之谜，易陷入悲观：意识是实体还是幻觉？人类专属还是跨物种共享？自由意志存不存在？但神经科学已攻克生物学基石的关键堡垒，精细描绘出构建主观世界的脑区网络图谱，这足以重塑生活图景。

成果已惠及现实：意识障碍研究为“植物人”群体打开沟通新径；健全者也能借药物、VR或远程附身技术拓展意识边界。最深远者，意识研究直指“人之所以为人”的内核——自我与自由意志的追问，将照见物种本质与思行根源。物理学家甚至或将把意识列入物质基本清单。

终极悬念终将揭晓：何以红感为红？你我眼中的红是否同一？拭目以待。

### 前言

2014年，伊朗数学家玛丽安·米尔札哈尼斩获菲尔兹奖，成首位获此殊荣女性。她喻数学如“迷失丛林，须尽调所学觅新径，佐以运气，或能寻得出口”。

2017年7月，米尔札哈尼年仅40岁陨落。她比常人更深涉足数学幽深。本书正是为徘徊林缘、渴望一窥全貌者而作。

不论好恶，我们皆对数学领土略知一二：符号、方程、几何，有解之题、平常真理、严丝合缝的证明，核心处尽是数字。

然它们如何串联？何以数字与数学独特——个中某些更显非凡？主题宏大，难穷全貌。我们借顶尖研究者智慧与《新科学家》锐思，勾勒一幅图景。

简述数学性质与疆域后，自起点——数字迷人特质入手：零、无穷、素数、古怪超越数e、π与虚数单位i。继而概览概率统计，抵达现代数学前沿，展示其于生活意外领域的实战，终极追问：数学如何扣合实在？

对许多局外人，数学妙在似通用语言，助我们更好读懂世界。从业者多赞同，且补注：其美在于自简入繁，仅凭纯粹抽象逻辑，便构筑出似超越吾辈的宏大世界。
