在规则层面，前提部分 X 可以看作是逻辑模式的主体，后件 Y 就是模式的头部，也就是下一步要推导的目标 rₙ₊₁(x₁, xₙ₊₁)。计数函数 σ 用来统计同时出现的次数，σ(X ∪ Y) 就是 X 与 Y 在同一条记录里共同出现的频次。N 是全部记录的规模，因子图挖掘中基数往往极大，实践里直接用共现次数作为支持度来衡量，即 s(X → Y) = σ(X ∪ Y)。除了支持度，评价规则好坏的统计量还有头覆盖率 Head Coverage、部分完备性假设置信度 Partial Completeness Assumption Confidence [168] 等。这类指标既能在最后挑选规则时作为筛选标准，也能以权重形式进入概率推理模型，同时在枚举子图结构时充当剪枝依据。

## 算法 2 AMIE 规则挖掘流程
[PRE0]
算法 2 给出了一个典型的规则挖掘通用步骤，被称为 AMIE Association Rule Mining Under Incomplete evidence [168]。执行之初先建一个路径队列 q，并把一条长度为 0 的空规则放进去作为起点；只要队列非空，就从队头取出一条路径 r 并把它从队列中移除。先检查 r 是否已经构成闭回路，若是则把 r 作为候选输出；若不是，就在 r 的基础上扩展边。扩展分为三类：

- 悬挂边 Dangling：新增边的其中一端是规则里从未出现过的新变量，另一端是已有变量。
- 具体边 Instantiated：新增边的一端是已有变量，另一端是已出现的常量，即知识图谱中的某个实体。
- 闭合边 Closing：新增边直接连接路径中已有的两个元素，并不会引入新元素，而是让路径形成闭环。

对搜索得到的新路径集合做剪枝，保留下来的路径再入队，继续下一轮循环，直至队列为空。剪枝可以是人工设定的规则，也可以依据统计量如前文提到的支持度和置信度阈值进行过滤。

## 9.3.1.2 归纳逻辑编程ILP视角
与只看频繁子图的思路不同，归纳逻辑编程更强调知识图谱中缺失的负三元组，它把问题建模为正例 E₊ 加负例 E₋ 加背景知识 B 推导出假设 h，即 E₊ + E₋ + B ⇒ h。一个合格的假设 h 需要满足：

必要性： B ⊭ E₊

充分性： B ∧ h ⊨ E₊

弱一致性： B ∧ h ⊭ false

强一致性： B ∧ h ∧ E₋ ⊭ false

(9.3)

必要性指仅靠背景知识推不出正例；充分性指在假设加入后背景知识能够推出正例，这一点与频繁子图挖掘的用法一致；弱一致性要求假设不与背景知识冲突；强一致性在此基础上还要求不与已知的负例冲突，若没有负例，强弱一致性等价。

基于 ILP 的方法因引入逻辑约束而比单纯利用图结构更具解释性，但要引入大量负例，计算开销也随之上升。代表性工作有 ALEPH 和 Progol，两者都是典型的 ILP 系统并采用逆向蕴涵算法^347；Sherloc^413 是无监督的 ILP 方法，结合概率图模型在网络文本中挖掘规则；QuickFOIL^521 则在 ILP 约束下采用自顶向下贪心策略完成规则搜索。

## 9.3.1.3 结构学习范式
概率逻辑推理模型的结构学习是一个统称，核心是在整体目标下挑选使整体概率最大的逻辑规则加入模型。通常拆成四步：① 目标函数定义；② 逻辑规则结构生成；③ 搜索策略；④ 增速手段。

目标函数的选择取决于具体的概率逻辑模型，例如马尔可夫逻辑网以最大化世界概率为目标，也常被用于概率图模型的优化，目标形式为：

log P_w(X = x) = Σ_{r∈R} c_r Σ_{k=1}^{g_r} log P_w[ X_{x,k} = x_{r,k} | MB_x(X_{r,k}) ]  (9.4)

其中 R 为一阶谓词集合，g_r 为谓词 r 的实例数，X_{r,k} 是第 k 个实例的 0/1 真值，谓词权重 c_r 可由用户设定或学习得到。

寻找 Horn 子句形式的候选结构时，常见做法是在概念级关系集合中枚举样式，通过增边、减边操作得到新的子句模板，并用启发式约束指导，例如要求每个变量在子句中至少出现两次。比如对概念路径 父亲(X,Y)∧父亲(Y,Z) 加上出生地边并把首尾变量连起来，就能得到 Horn 规则 父亲(X,Y)∧父亲(Y,Z)∧出生地(Z,W) ⇒ 祖籍(X,W)。该过程不依赖实例信息，属于无剪枝的枚举，复杂度为 O(r^l)，r 为关系种类数，l 为规则平均长度。即使在概念层，搜索空间也极大，例如 Freebase 约有上万种关系，长度为 4 的规则样式可达 10^18 量级。

从全部规则空间中挑出使目标函数最大的子集是结构学习的核心。常见策略是把逻辑规则一条一条在线增量地加入集合，但每次新增后都要实例化规则来评估公式 9.4 的概率，成本很高，例如在仅千级元组的 UW-CSE 数据集上，MLN 结构学习一次概率评估平均需三分钟^245。因此提速是关键，可用的手段包括基于蒙特卡洛的最大似然估计 MC-MLE^173、用有限内存 BFGS 算法优化伪似然^294、惰性 lazy 机制^247 等。

另一种思路是用图上的随机游走替代穷举枚举，路径排序、实例化网络采样等方法属于此类，感兴趣读者可参考 [262, 263, 452, 480]。

## 9.3.2 演绎推理：把规则变成事实
上一节无论是通过挖掘得到还是人工编写的规则集合，如何把它应用到自动推理正是演绎推理的任务。本节分两部分，先以 λ 演算介绍确定性推理的通用过程，再以概率软逻辑介绍不确定性推理的通用过程。

### 9.3.2.1 确定性推理：λ 演算
λ 演算是形式系统，也可看成程序设计语言的模型，主要用于研究函数定义、函数应用与递归，后发展为通用表达式语言。核心是 λ 表达式，本质上是一个匿名函数。

例如函数 f(x)=x+2 可写成匿名形式 λx.x+2。

形式化定义上，λ 表达式由变量名、抽象符号 λ、点号 “.”、圆括号组成，语法为：

< λ表达式 > ::= < 变量名 >

|| < λ表达式 > < λ表达式 >

|| λ < 变量名 > . < λ表达式 >

|| ( < λ表达式 > )

λ 表达式分应用型和抽象型。没有显式 λ 的表达式是应用型，标准写法 E₁E₂，其中 E₁ 为函数定义，E₂ 为实参。合法例子有 xx、λx.xy、x(λy.xy)、λx.λy.x。

运算规律是应用型自左向右，抽象型自右向左，如：

E₁E₂E₃ = [(E₁E₂)E₃]

λx₁.λx₂λx₃ = [λx₁.(λx₂λx₃)]

这种表示如何与自然语言语义或知识关联？以 “小明买苹果” 为例，三元组可写成 买（小明，苹果），为了参与后续计算把参数抽象为变量，就能改写为 λ 表达式 λx.λy.buys(x,y)。

λ 项中变量可分为自由变量与绑定变量。λx.xy 中 x 被 λ 绑定，y 为自由变量。直观上，绑定变量对应函数形参，自由变量不代表任何形参。

λ 演算包含三种操作：

（1）α-置换 α-conversion
变量名本身不重要，λx.x 与 λy.y 表示同一函数，带约束的变量可重命名。例如 λx.(λx.x)x = λy(λx.x)y 在 λ 演算中合法。

# (2) β-归约 β-conversion
相当于把实参代入 λ 项并替换变量。例如：

- λx.λy.y x → λy.y
- (λx.λy.y x)(λz.u) → λy.y(λz.u)
- (λx. x x)(λz.u) → (λz.u)(λz.u)

# (3) η-变换 η-conversion
表达外延性：若对所有参数给出相同结果，则两个函数相等。

利用这三种归约，可把前面例子 λx.λy.buys(x,y) 归约为 buys（小明，苹果）。

### 9.3.2.2 不确定性推理：马尔可夫逻辑网和概率软逻辑
马尔可夫逻辑通过为逻辑规则绑定权重，把一阶逻辑扩展为概率逻辑。权重大小反映规则的相对强度与对假设推理的重要性。把权重调至无穷大时，模型退化为标准一阶逻辑。按 [396] 的定义：

定义 1: 马尔可夫逻辑网 L 是一个规则权重对 (f_i, w_i) 的集合，其中 f_i 是一条标准一阶逻辑规则，w_i 为实数。L 与有限常量集合 C = {c1, c2, ⋯, c|C|} 一起定义马尔可夫网 M_{L,C}：

+ 1. M_{L,C} 为 L 中每条可能的原子事实创建一个二值节点。值为 1 表示原子事实为真，0 表示为假。
+ 2. M_{L,C} 为每条可实例化的规则 F_i 在 L 中设计一维特征 f_i。特征值为 1 表示规则为真，0 表示为假。特征权重 w_i 绑定在 L 中的规则 f_i 上。

设 X 为所有原子事实集合，F 为规则集合，w_i 为权重，G_{f_i} 为用 X 实例化 f_i 的所有可能集合。此时可能世界 x 的概率为

P_w(X = x) = 1/Z exp [ Σ_{f_i ∈ F} w_i Σ_{g ∈ G_{f_i}} g(x) ]

= \frac{1}{Z} \exp\left[ \sum_{f_i \in \mathcal{F}} w_i n_i(x) \right] \quad (9.5)

其中 g(x)=1 表示实例化规则为真，反之为假，第二行 n(x) 为 g(x)=1 的计数。Z = \sum_{x' \in X} \exp\left[ \sum_{f_i \in \mathcal{F}} w_i n_i(x) \right] 为归一化参数。

[PRE1]
图 9.1 马尔可夫网中包含四个节点的团结构

对知识图谱而言，一个三元组即为马尔可夫逻辑网中的原子事实，具有二值特性，在闭世界假设 CWA 下，图谱中存在则值为 1，否则为 0。为控制规模，原本不在图谱中的元组不必显式表示为负原子，可在需要时动态生成。为刻画元组间关系，网络为共享同一实体的两个三元组连一条无向边，且不使用超边。当多个三元组共享一个实体时，为每对元组都连一条边，并用团 cliques 捕捉依赖。① 团是无向图中的一个完全子图，因此团中的每两个点都具有一条边。

确定推理假设的关系类型后，团结构可被拆分为逻辑表达式。例如图 9.1 包含四个两两相连的三元组。推理假设为 国籍（Cristiano Ronaldo，葡萄牙）时，可得到 父亲（Cristiano Ronaldo, Jos Dinis Aveiro）∧ 国籍（Jos Dinis Aveiro，葡萄牙）⇒ 国籍（Cristiano Ronaldo，葡萄牙）等实例。将实体换成变量后得到规则 f_i: 父亲(X,Y) ∧ 国籍(Y,Z) ⇒ 国籍(X,Z)。这就是马尔可夫逻辑网对知识图谱中元组、依赖团组及逻辑规则的建模方式。

实践中常针对特定关系学习规则，此时需要公式 9.5 的判别式形式：

P(q|KB,F) = \frac{\exp\left[\sum_{f_i \in F_Y} w_i n_i(x, y[Y=q])\right]}{\exp\left[\sum_{f_i \in F_Y} w_i n_i(x, y[Y=0])\right] + \exp\left[\sum_{f_i \in F_Y} w_i n_i(x, y[Y=1])\right]} \tag{9.6}

该式用于求解特定事实 q 的概率，Y 取 1 或 0，1 代表 q 为真，0 代表为假。P(q|KB,F) 为事实 q 在现有图谱和规则集合下的成立概率。规则学习过程中通过动态增删规则或调整权重，使所有事实概率最大化，最终得到带有权重的规则集合。

概率软逻辑模型 Probabilistic Soft Logic, PSL 是一种基于一阶逻辑谓词和马尔可夫逻辑网络的统计关系学习框架。PSL 用加权的一阶谓词公式对无向概率图模型做紧凑表示。其最大优势是谓词取值可在连续区间 [0,1] 内任意取值，而非 MLNs 的离散 {0,1}，因此能方便建模相似度等连续特征。

PSL 由一组带权重的一阶逻辑谓词公式组成，每个公式编码一组共享同一权重的特征集合。谓词实例 a 的取值记为 I(a)，取值范围为 [0,1]。PSL 使用松弛版的合取、析取和取反：

I(l₁ ∧ l₂) = max{0, I(l₁) + I(l₂) − 1.0}

I(l₁ ∨ l₂) = min{I(l₁) + I(l₂), 1.0}

I(¬l₁) = 1.0 − I(l₁)

对实例化谓词公式 r ≡ r_body → r_head，成立的充要条件是 I(r_body) ≤ I(r_head)，即头部取值不小于主体。若不成立，违背程度为 d(r) = max{0, I(r_body)−I(r_head)}。例如：

I[spouse(P₁,P₂)] = 1.0

I[votesFor(P₁,P)] = 0.4

I[votesFor(P₂, P)] = 0.8

配合谓词公式：

friend(p₁, p₂) ∧ votesFor(p₂, p) → votesFor(p₁, p)|ω = 0.4    (9.7)

spouse(p₁, p₂) ∧ votesFor(p₂, p) → votesFor(p₁, p)|ω = 0.9    (9.8)
