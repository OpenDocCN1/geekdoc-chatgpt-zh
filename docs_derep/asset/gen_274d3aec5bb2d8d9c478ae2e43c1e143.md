### 3.3.4 图模型解析
属性图模型是 Neo4j 的核心数据模型，围绕结点、关系、属性三要素组织数据。

* 结点，对应知识图谱里的实体。可打上一个或多个标签来标示类别，也能在结点上挂载若干属性描述实体特征。
* 关系，描述实体间的连接。Neo4j 要求关系必须有方向，即明确起点和终点。虽然在概念上是有向的，但底层采用双向链表存储，查询时可双向快速定位。关系只能指定一种类型，相当于关系的类别，系统支持多达 65KB 种不同的关系类型。关系本身也能携带属性，用来补充连接的语义。这套表达方式已超出传统 RDF 的能力。
* 属性，以键值对形式存在。值可以是 Integer、Float、String、Boolean、Point、Date、Time 等，或特殊值 null 表示空。

结合图 3-35，就能直观把握属性图的结构。一个属性图像是一块画布，包含结点和关系两类元素；关系把结点串联起来。往下拆，结点可带标签与属性，关系可带类型与属性。

### 3.3.5 其他图数据库
#### 1. Microsoft Azure Cosmos DB
Azure Cosmos DB 是微软 Azure 托管的云图数据库，具备全球分布式存储与主备机制。优势包括个位数毫秒读写延迟、全球吞吐与存储自动弹性扩缩、高可用性、成熟的一致性模型。最大的便利是云化，但需要支付服务费用。

#### 2. OrientDB
OrientDB 是首个多模型开源 NoSQL 数据库，融合图存储与文档存储。性能上可达每秒 12 万条记录写入，且对边采用物理存储，避免实时 Join。提供社区版和企业版，社区版遵循 Apache2.0 可商用，企业版增加增量备份、分布式集群等特性。

#### 3. ArangoDB
ArangoDB 原生支持文档、图、键值对三种模型。查询语言为类 SQL 的 AQL，也可 JavaScript 扩展，支持 ACID 事务，可水平与垂直扩展。它能以应用服务器运行，实现应用与数据库紧密耦合。支持备份与分片，采用 Apache2.0 开源许可。

#### 4. Virtuoso
Virtuoso 是一个高性能对象关系数据库，带智能 SQL 编译器与事务、强大的存储过程语言。内置 Web 服务器，可通过 SOAP 与 REST 访问存储过程。内置 WebDAV 仓库可托管静态与动态 Web 内容并做版本控制，并提供自动化元数据提取与全文搜索。查询上支持把 SPARQL 嵌入 SQL 查询 RDF 数据。

#### 5. JanusGraph
JanusGraph 是由 Titan 演进的分布式图数据库，继承 Titan 特性。后端存储支持 Cassandra、HBase、BerkeleyDB 等，索引支持 Solr、ES、Lucence 等，并集成 Spark GraphX、Giraph、Hadoop 等分析引擎，可视化集成 Arcade Analytics、Cytoscape 等。采用 Gremlin 查询语言，Apache2.0 开源。
