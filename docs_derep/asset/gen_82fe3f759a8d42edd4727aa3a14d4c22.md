# 用工具和记忆把大模型从“背书”变成“办事”

正如第 4 章提到的，通过让模型“逐步思考”，推理质量会在一定程度上得到提升。在提示词末尾补充一句“Let's think step by step”，本质上是在暗示模型花更多时间展开思路。

本节要讲的是一种面向应用的智能体，它处理查询时需要多步中间操作。智能体负责规划步骤，并能高效调用外部工具来给出回应。某种意义上，正因为“逐步思考”，智能体才有余裕安排行动，从而完成更复杂的任务。

智能体的工作流程大致如下。

1. 接收来自用户的原始输入。
2. 判定是否需要工具以及需要准备怎样的文本输入。
3. 用准备好的文本调用对应工具，并拿到工具返回的文本。
4. 把工具输出写回智能体的上下文。
5. 反复执行第 2 到第 4 步，直至智能体认为不再需要工具，然后直接向用户作答。

这与第 3 章里构建会回答问题并执行操作的 AI 助手很像。LangChain 智能体具备同样的能力，而且上限更高。
