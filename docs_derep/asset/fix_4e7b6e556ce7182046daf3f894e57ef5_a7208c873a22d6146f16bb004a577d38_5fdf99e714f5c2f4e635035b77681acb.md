（3）按需设置配置参数，注意事项如下：
- 未开启 HTTPS 通信时，“httpsEnabled”=false，存在较高网络安全风险。
- modelWeightPath 下的 {modelWeightPath}/config.json 需保证用户组与用户名与当前用户一致，且为非软链接，权限不高于 750，否则 Server 启动失败。
- maxLinkNum 默认 1000，建议设为 300。1000 并发受模型性能与序列长度限制，通常小模型与低序列长度才可支撑。
- 若通过环境变量 MIES_CONFIG_JSON_PATH 提供配置文件，需自行保障其安全性。
- modelWeightPath：模型权重路径。该路径下文件由用户提供，需自行保障安全性。
- logPath：日志文件路径。若由用户创建提供，需自行保障安全性。
