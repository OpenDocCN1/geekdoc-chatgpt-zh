### 6.4.3 缓解 RNN 梯度消失的思路

前面提到的消失本质上源于对无限历史的复用，而这恰是 RNN 的优势所在。常见的应对办法有：

+   1. 选用更合适的激活函数，比如 ReLU。ReLU 左侧导数为0，右侧恒为1，能避免导数逐级变小。但恒为1也容易引发梯度爆炸，可通过设定阈值加以控制。

2. 引入 BN 层。BN 能加快收敛、抑制过拟合，减少甚至免去 Dropout 和正则化需求，对权重初始化不敏感，同时允许更大的学习率等。

3. 调整网络结构。LSTM 类门控结构能有效缓解该问题。6.5 节会详细展开 LSTM 相关内容。

## 6.5 长短期记忆网络 LSTM

长短期记忆网络 Long Short-Term Memory，LSTM 专门为解决长程依赖问题而设计，在众多任务上取得了显著效果并被广泛采用。

### 6.5.1 LSTM 的诞生背景

RNN 处理时间上相距很远的节点时困难很大，因为联系它们的计算涉及雅可比矩阵的多次乘积，容易出现梯度消失或爆炸。为此出现了多种尝试，如回声状态网络 ESN、带泄漏单元 Leaky Unit 等。其中最成功的是门控 RNN Gated RNN，而 LSTM 正是门控 RNN 的代表。泄漏单元通过设计权重系数让 RNN 能累积远距离信息；门控 RNN 则在此基础上允许系数随时间变化，并能主动遗忘已累积的信息。

### 6.5.5 LSTM 与 GRU 的对比

LSTM 与 GRU 的区别如图6-30。

[PRE19]

图6-30 LSTM与GRU的区别

从上图可以看出，二者结构十分相似，下面分析不同之处。

+   1. 新的记忆都基于之前状态及输入计算，但 GRU 有一个重置门 Reset Gate 控制之前状态的进入量，而 LSTM 没有类似门。

2. 产生新状态的方式不同，LSTM 有两个不同门，即遗忘门和输入门，而 GRU 只有一种更新门 Update Gate。

3. LSTM 对新产生的状态可通过输出门进行调节，而 GRU 对输出无任何调节。

总的来说，LSTM 已成为较为标准的 RNN 结构。对于大部分能运用在普通 RNN 的性质和变体，都能直接推广到 LSTM。在绝大部分关于 RNN 的应用中，LSTM 都能取得优于普通 RNN 的效果。

### 6.6.1 简单循环网络 SRN

SRN 的网络结构示意图如图6-31，其特点如下。

（1）SRN 是一个三层网络，其在隐含层增加了上下文单元。图6-31 中的 y 是隐含层，u 是上下文单元。上下文单元节点与隐含层中节点的连接是固定的，并且权重也是固定的。上下文节点与隐含层节点一一对应，并且值是确定的。

[PRE20]

图6-31 SRN的网络结构示意图

（2）在每一步中，使用标准的前向反馈进行传播，然后使用学习算法进行学习。上下文每一个节点保存其连接隐含层节点的上一步输出，即保存上文，并作用于当前步对应的隐含层节点状态，即隐含层的输入由输入层的输出与上一步的自身状态所决定。因此 SRN 能够解决标准多层感知机 MLP 无法解决的对序列数据进行预测的问题。

### 6.6.4 回声状态网络 ESN

ESN 的特点如下。

+   （1）ESN 的核心结构为一个随机生成且保持不变的储备池。储备池是大规模随机生成稀疏连接的循环结构，储备池稀疏程度通常保持在 1%～5%，储备池稀疏程度表示储备池中互相连接的神经元占总神经元个数 N 的比例。

+   （2）从储备池到输出层的权重矩阵是唯一需要调整的部分。

+   （3）简单的线性回归便能够完成网络训练。

ESN 的基本思想如下。

使用大规模随机连接的循环网络取代经典神经网络中的中间层，从而简化网络的训练过程。

网络主要有如下参数。

+   （1）W：储备池中节点间的连接权重矩阵。

+   （2）W_in：输入层到储备池之间的连接权重矩阵，表明储备池中的神经元之间是相互连接的。

+   （3）W_back：输出层到储备池之间的反馈连接权重矩阵，表明输出层的一些信息会反馈到储备池。

+   （4）W_out：输入层、储备池、输出层到输出层的连接权重矩阵，表明输出层不仅与储备池连接，还与输入层和自己连接。

+   （5）W_outbias：输出层的偏置项。

### 6.6.5 时钟驱动循环网络 CW-RNN

CW-RNN 是 RNN 的改良版本，其使用时钟频率来驱动。它将隐含层分为几个块/组，每一组按照自己规定的时钟频率对输入进行处理。为了降低 RNN 的复杂度，CW-RNN 减少了参数数量，并提高了网络性能，以加速网络训练。CW-RNN 通过不同隐含层模块在不同时钟频率下工作来解决长时依赖问题。将时钟时间进行离散化，不同的隐含层组将在不同时刻进行工作。因此，所有的隐含层组在每一步不会全部同时工作，这样便会加快网络的训练，并且时钟周期小的神经元不会连接到时钟周期大的神经元，只允许周期大的神经元连接到周期小的神经元。周期大的速度慢，周期小的速度快，因此速度慢的神经元可连接到速度快的神经元，反之则不成立。
