截断扩散配合判别器协同训练拆解

下面把这套基于截断时间步的扩散训练与对抗判别相结合的流程，用更易读的方式梳理一遍。核心思路是先用变分下界约束分数模型，再用隐式分布的判别信号拉动生成端往真实数据流形靠拢，同时给判别器加上梯度正则保证训练稳定。

目标函数拆解

整体证据下界先把第一步从干净数据到首个噪声的 KL 项单独拿出来，剩余部分按时间分段累加。每一段的贡献由 L(t,s) 统一描述，s 为零时退化为重构式的负对数似然，s 大于零时则用条件分布间的 KL 编码信息损失。

[PRE0]

-L_ELBO = E_q D_KL(q(x₁|x₀)||p_θ(x₁)) + \sum_{i=1}^K L(t_i', t_{i-1}'),

[PRE1]

其中\nL(t,s) = { -E_q log p_θ(x_t|x₀) s = 0\n          E_q D_KL(q(x_s|x_t,x₀)||p_θ(x_s|x_t)) s > 0

分段形式让模型既能学习干净数据的逐级恢复，也能在中间时间点做分布匹配。

初始化与恢复

训练开始前先把配置、日志、数据集、数据加载器组装好，同步创建扩散主模型和条件判别器，均映射到目标设备并做 DataParallel。优化器分为主扩散优化器、生成器专用优化器和判别器优化器三路，BCEWithLogits 作为判别基准损失。若开启指数滑动平均，则注册 EMA 助手。若请求续训，则从 ckpt.pth 恢复模型权重、优化器状态、起始轮次和步数，EMA 也一并载入。

主训练循环

进入轮次后统计数据耗时，逐批送入设备并做预处理。噪声采样后依据截断时间步上限进行成对采样，时间上界越小采样越快。随后调用对应模型类型的损失工厂计算预测噪声损失，回传并做梯度裁剪，更新参数并同步 EMA。

截断扩散的隐式损失部分则从标准高斯出发让生成器直接预测最大时间步的样本，再交给判别器打分，用 softplus 形式的非饱和损失拉动生成方向。日志记录主损失、隐式损失与平均数据耗时，随后单独用该隐式损失更新生成器权重。

判别器更新按间隔触发，真实样本经 q_sample 加噪到隐式时间步，生成样本同理。分别计算真实与伪样本的 softplus 判别损失并写入 TensorBoard。若本步需要梯度正则，则对真实隐式样本的判别 logit 求梯度，计算逐样本梯度范数惩罚并按系数加权。最终判别损失为三项之和，反向传播更新判别器。
