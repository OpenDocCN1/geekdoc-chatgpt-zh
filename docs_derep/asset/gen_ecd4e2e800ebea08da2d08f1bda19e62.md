# 第7章 让AI搜索自主运行

核心架构搭建完毕后，问答的主流程已经跑通。只需给出一个输入，就能依次激活分析器、检索器、过滤器和生成器，完成一次完整的回答。

但这种模式仍然依赖人工串联，属于手动触发的运行方式。为了让系统更智能、更自动化，本章将在项目的 work 目录下新建 scheduler 目录作为调度器。通过调度器，AI搜索的核心架构可以自行完成调用与执行，实现真正的自动运行。
