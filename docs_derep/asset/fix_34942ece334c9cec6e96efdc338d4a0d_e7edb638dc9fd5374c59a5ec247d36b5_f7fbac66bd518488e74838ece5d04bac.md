## 14.5 总结

本节演示了 OpenClaw 如何借助 MCP 协议对接外部 AI 平台，并把 Google NotebookLM 引入 OpenClaw 生态，从而补足本地代理在超长文本解析和低成本知识沉淀上的不足。我们实操了 MCP 服务端的部署与参数配置，理解了在 SOUL.md 中让代理优先参考外部资料库的写法，并以飞书搭建了一条简洁的输入-检索闭环。
