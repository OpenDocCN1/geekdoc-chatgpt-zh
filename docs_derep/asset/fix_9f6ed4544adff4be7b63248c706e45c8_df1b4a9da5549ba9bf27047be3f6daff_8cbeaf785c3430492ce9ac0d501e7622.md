智能体落地四阶段全景

启动前的筹备工作分为模型数据准备和知识工具准备两块。

模型数据准备是为智能代理构建大脑与养料的环节。要点是挑选与业务场景贴合的基础模型，可选用通用基座，也可用在垂直领域完成微调的专用模型；同时要储备高质量的训练素材，包括行业文献、过往业务记录、人工标注集等。以金融智能投顾为例，素材需覆盖宏观经济面、行业研报、客户画像等多个维度，并在入库前完成去噪与合规校验。

知识库与工具集准备相当于搭建专业工具箱。知识库用来沉淀行业 know-how，比如医疗指南、法规条文等；工具集则负责对接外部执行能力，例如 API 调用、邮件推送、工单系统联动等。以政务代理为例，知识库需收录政策文件与办事指南，工具集要打通政务服务平台的申报、审批等业务系统。

**3.实施：从设计到实体的蜕变**

筹备完成后进入实施阶段，核心是开发与测试的循环打磨。

智能体开发是技术落地的关键动作，要把基座模型、知识库、工具集整合起来。做法是通过提示词工程规范模型输出逻辑，用向量数据库实现知识库的快速检索，再以可视化编排串联执行流程与工具调用。以全域感知代理为例，图像识别模型负责处理监控画面，大语言模型负责解析违规事件，工具集则自动触发城管工单派发，三者必须无缝协同。

效果测试相当于体检，要模拟真实业务检验功能是否完整覆盖需求、输出是否贴合预期、高并发下是否稳定。以客服代理为例，若测试中复杂问题的解答准确率仅有60%，就需要回溯需求设计或模型训练环节进行优化，直至达到预设的90%水准。开发—测试—迭代往往要重复多次，才能让代理真正好用且稳定。

**4.上线与运营：持续释放价值**

上线只是起点，后续要做好部署、评估、运营与推广。

部署集成要实现与现有业务系统的无缝对接。比如客服代理要能嵌入企业微信、App、网页等触达渠道，保证体验一致；同时打通 CRM、ERP 等后台，实现数据实时流转。

效果评估与汇报要用数据说话，从用户体验的 NPS 净推荐值、工作效率的任务耗时与人工干预率、业务收入的转化率与客单价、成本下降的人力替代率与差错损失减少等维度量化成果。某零售代理上线后，夜间咨询的响应率从40%提升到100%，订单转化率提升8%，这类数据既是验收依据，也是后续推广的硬通货。

持续运营是代理的进化引擎，需要不断收集用户反馈，并随业务变化如政策更新、市场波动，对基座模型、知识库、工具集和编排流程进行迭代。政务代理就要随政策文件更新知识库，随办事流程调整工具集，保持服务精准。

推广与交易是价值放大。当代理在某个部门或场景验证成功，就可以横向复制到集团其他业务线，甚至打包成标准化产品对外输出，例如运营商将客服代理方案卖给中小电商，从而实现更大规模的价值。

这套四阶段十二步骤的方法论，就像落地的导航系统，帮助技术从实验室走向业务现场，从单点突破走向体系化价值创造。下一步将深入拆解每个阶段的核心问题，比如场景是否合适、价值如何估算、需求如何设计等。

**4.1.2 如何判断场景是否适合智能体落地**

技术落地前，第一步不是急于搭建系统，而是先审视企业主营业务场景，判断是否与代理的核心能力天然适配。真正高价值的应用，必须扎根于企业的核心业务，因为这些环节直接关联关键经营指标、核心收入或主要成本。比如银行的信贷风控与投顾、制造的供应链调度与生产优化、政务的政策咨询与舆情处置，都属于核心环节。唯有在这些场景落地，代理才能产生可衡量的显著价值。错配则轻则效率提升有限，重则打击组织信心。

在确认属于核心业务范畴后，可用以下四个要点系统评估可行性。

**1.判断要点一：需求可结构化但仍需灵活**

适合代理的复杂业务，流程本身要有清晰的节点和规则框架，同时在执行中能依据情境动态调整。既不是完全固化的机械流程，也不是毫无规则的随机任务，而是“有章可循、需灵活应变”的中间地带。

以舆情助手主流程为例，整体遵循“舆情监测→分析决策→预警推送→效果统计”的标准化路径，结构清晰。但每个环节都要融入可配置的动态规则：不同省份舆情分级标准不同，金融和教育行业的合规关注点各异，产品投诉与社会事件的处置路径也要区分，还要结合节假日启动对应预案。代理可以牢牢锚定核心节点，同时灵活调用规则、知识库和策略工具，实现框架稳定与细节灵动的统一。

如果流程完全刚性，由传统自动化就能覆盖，就不需要代理；如果流程毫无结构、完全依赖临场发挥，代理也难以保证准确性和稳定性。

**2.判断要点二：高频人机交互或人际协同**

当场景涉及大量任务协调、信息确认、决策沟通等高频互动时，代理的多轮对话、实时响应和个性化适配优势明显，传统软件的预设逻辑交互就显得僵硬。比如传统机器客服只能按“按1、按2、按0”机械应答。

典型的人机高频场景包括内部 IT/HR 的重复问答与流程引导、客服中根据用户反馈动态调整回复、政策申报时通过多轮对话厘清企业资质、学习辅导中按学生理解度实时调整讲解。这类场景互动频次高、人工重复劳动重、规则明确但需要灵活适配，代理凭借多模态交互与上下文记忆，能把依赖人工反复沟通的任务自动化。

**3.判断要点三：需要整合工具链**

代理的另一核心价值是触达并整合外部工具，把孤立的业务环节串成自动化闭环。若场景只依赖单一工具或纯脑力决策，引入代理意义不大。

以企业请假申请为例，代理可依次调用 OA 查询假期余额、时间校验工具判断冲突、工单系统生成审批流，最后通过邮件通知相关人。靠人工或单一系统难以高效串联，代理通过工具编排实现从发起请求到任务完成的端到端自动化。若业务纯线下或仅限单一系统内部，则整合价值有限。

**4.判断要点四：高风险任务需保留人工把关**

代理不是完全替代人工，而是在高风险强合规场景下实现人机协同。AI 负责数据处理与规则匹配，人工负责风险决策与价值判断。以医疗问诊为例，代理可给出诊断建议与循证依据，最终治疗方案仍由医生确认；合同审核中代理可完成合规审查与条款建议，审定权仍归法务人员。这样既发挥效率优势，又通过人工介入控制系统性风险。若场景不涉及风险决策或完全无需人工，则人机协同必要性低，需重新评估适配性。

## **4.2** **智能体产业落地案例**

在明确方法论与判断标准后，转向产业实践，通过不同行业的代表案例，展现代理如何在真实业务中创造价值，并推动从用户场景到组织效能的全维度智能化演进。

**4.2.1** **电信行业智能体实践：从客户服务到内部效能的全维度进化**

在数字化转型中，电信行业正从传统管道运营商向综合智能服务枢纽升级。代理技术已深度融入业务，既重塑用户体验，也提升组织运营效率。中国电信除基础通信外，已推出多类代理：通话代理融合实时翻译与智能摘要赋能通话场景；生活代理以用户意图为核心整合生态，提供生活问答、天气查询、话费查询等全场景服务；办公代理聚焦效率，集成阅读助手、内容生成等能力，已上线星辰慧记、思维导图等功能。下面分别介绍 C 端与 B 端的落地案例和技术方案。

**1.电信行业 C 端智能体：通信助手智能体的产品优势与技术方案**

漏接重要来电常带来不便甚至商机损失。传统语音信箱功能单一、体验生硬。通信助手智能体正为此而生，可在用户不便接听时主动代接，通过自然对话识别来电意图、提取关键信息，并以短信形式把沟通要点推送给机主。

例如合作方来电邀请商务晚宴，智能体可主动接听并记录时间、地点、着装要求等关键信息，确认参会意向后再结构化推送，避免因漏接错失机会。用户在会议中无法接听朋友邀约打球时，智能体也可代接并确认时间、场地、人数，形成活动摘要及时通知，确保邀约得到响应。

通信助手不仅避免信息遗漏，更实现从被动留言到主动沟通的体验升级，大幅提升通信管理的效率与人性化程度。

**（1）通信助手智能体的应用效果**

与基于固定规则的应答系统相比，代理在场景覆盖上实现质的飞跃。传统规则引擎因模板编写复杂，仅能支持数十个预设对话场景，而基于大模型的代理引擎可灵活应对约350种多样化通话场景，每种场景只需一个简单提示词即可扩展，目前已覆盖百万级用户，主叫方对话参与度、平均通话时长、有效对话轮次等关键指标显著提升，正稳步向千万级用户扩展。传统模板匹配回复固定生硬，难以应对开放问询；大模型驱动的代理能深度理解上下文意图，生成自然的多轮回复，从根本上提升通话体验与沟通效率。

**（2）策略方案及技术架构**

通信助手围绕“精准识别—意图理解—智能响应—风险管控—信息沉淀”全流程闭环设计，由六大核心模块协同运作，解决方言识别、意图分散、风控缺失等难题，技术流程如图 4-6 所示。

1）语音识别。采用端到端模型实现方言兼容的精准转译，支持40种方言与普通话实时转译。通过动态自适应降噪处理通话噪声，并针对电信场景优化热词库如“套餐升级”“流量包”，语音转文本准确率达96.3%。语音流分片处理后，ASR 模块以约300ms/句延迟输出文本，为后续环节提供高保真输入。

**（3）模型选择和优化**

1）主对话模型：TeleChat2-3B 的专业化训练路径。将通用大模型落地到电信 C 端服务，需要兼顾专业知识与服务规范，必须通过分阶段专项训练实现。

TeleChat2-3B 是中国电信自主研发的基座模型，小尺寸带来优异推理性能，适合对响应速度要求高的通话场景。

第一阶段：基于场景数据的监督微调。通过覆盖宽带报修、套餐咨询、费用查询等350个典型场景的1万条高质量对话数据进行 SFT，让模型学习电信服务对话模式与业务逻辑。例如用户用方言说“网断了，光猫红灯亮”，模型能理解故障并给出专业指导。经过优化，常见场景意图识别准确率从60%提升至90%以上。

第二阶段：基于人类反馈的指令偏好对齐。为确保输出符合电信服务的严谨规范，通过偏好对比数据集让模型学习“专业、中立、不越界”的服务准则。例如用户问“帮我选最贵的流量包”，优质回复应客观介绍套餐并引导自主选择，而非越权办理。经偏好对齐优化，服务合规率达99%，形成专业克制的对话风格。

经过循序渐进的训练，TeleChat2-3B 被塑造为精通电信业务、恪守服务规范的可靠对话智能体。
