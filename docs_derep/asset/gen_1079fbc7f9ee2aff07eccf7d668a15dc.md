Manus掀起的通用智能体浪潮

7.1 Manus与通用AI智能体
2025年3月，Manus在国内互联网突然走红，被不少人视作智能体领域的ChatGPT时刻，也被认为是继DeepSeek之后的新爆款，代表人机协作的新方向。

7.1.1 Manus简介
官方称Manus是首个通用AI智能体，本质上是端到端任务闭环的实现。用户只需给出最终目标，它就会像一个自主性很强的助理一样自行推进执行。
与纯大模型相比，Manus更强调产品化能力，比如任务拆解的可视化、多模型动态调度，而非底层技术原创。
以制作数据报表股票分析报告为例，普通大模型需要用户一步步指示大纲、内容、整合等。Manus则能自动把复杂需求拆成若干小步，无需人工干预，最后直接呈现图文并茂的网页结果。
Manus的最大意义在于让大众认识到智能体的概念，也为同类产品的工程化提供了参考。不过在爆火后，AutoGLM、Genspark、Skywork、扣子空间等产品纷纷出现，目前整体体验仍受大模型能力、架构和工作模式限制，存在耗时长、执行不稳、效果难控等问题，但通用智能体替代传统对话模型的趋势已很明显。

7.1.2 Manus技术原理解析
Manus基于底层大模型，自主做任务分解，把复杂需求拆成子任务，并动态调用不同智能体或工具协同完成。
架构上采用云端虚拟环境运行，AI在独立电脑里操作，避免占用用户本地资源，所以用户离线时任务仍可继续。

1. 智能体循环
一套推理行动的闭环。接收任务后先分析拆解，选择工具如浏览器，在安全监控下执行并观察结果。每完成一步就重新评估进程，决定继续、转向或求助，直至收敛。

2. 系统能力
根基是云端数字沙盒。智能体拥有类似系统管理员的权限，可调用shell、使用图形浏览器、安装软件依赖、部署简单应用，为复杂多步操作提供环境。

3. Manus AI助手能力
内置行为准则和策略，用来约束决策。包括风险评估、优先选用安全工具、规范进度汇报，以及在模糊或高风险操作时主动让用户接管，保证行为可预期。
整体来看，Manus是基于任务解析与结构化处理的多智能体框架，先用需求分析模块理解请求、澄清模糊点、拆解任务，再通过浏览器交互、文件系统、shell、通信接口和部署能力实现多模态处理，支持JavaScript、Python等十多种语言及主流框架。
执行引擎采用动态规划，实时监控进度，遇到障碍会自动调整并生成替代方案。质量保障通过结果校验、代码测试和反馈学习闭环，同时遵循隐私、系统安全和道德约束。受上下文窗口和沙盒隔离限制，它无法访问外部系统或做越权操作，但持续学习能提升处理能力。

7.1.3 开源方案介绍
Manus的闭源收费和邀请码限制催生了OpenManus等开源替代项目。技术路线与Manus一致，都是多智能体协作+工具链集成，把自然语言指令拆解为子任务分派给搜索、写代码、整理文件等专用智能体，并接入网络搜索、代码解释器、文件系统等扩展能力。开源带来透明、可审计、可定制，加速了生态迭代。
OpenManus主要由智能体、流程、工具、提示词四部分构成。
（1）智能体模块。定义基础接口和主要实现，包含任务规划、ReAct模式和工具调用。
（2）流程模块。定义Manus式工作流基类，实现智能体获取、增删、状态管理包括未开始、进行中、已完成、受阻，并提供FlowFactory为多个智能体创建不同工作流。
（3）工具模块。提供各类工具脚本，同样基于browser-use库操作浏览器，支持导航如打开网址、返回、刷新、网页搜索、元素互动、内容抽取和Tab管理。
（4）提示词模块。内置Manus、Planning、Swe、Toolcall等智能体的提示词，分为系统提示词和用于指引下一步行动的NEXT_STEP_PROMPT。
从Manus到开源替代，任务分解和工具调用已成共识，开源把技术从封闭产品变成可修改的开放基础设施。

7.1.4 商业对手介绍
Manus让用户真切感受到通用智能体与对话大模型的区别：前者能自主操控电脑、浏览器、写代码。它基本定义了该类产品的形态，也点燃了赛道。

1. 扣子空间
2025年4月18日，字节跳动首款消费级通用智能体扣子空间开启内测。定位兼具通用实习生的广度和领域专家的深度，可无限拓展。支持自动分析需求、拆解任务、调用浏览器、代码编辑器等工具，并以PPT、网页、文档等形式交付。核心在于集成外部工具处理复杂任务。
发布前，字节在2025年3月开源了TARS。界面左对话右虚拟机实时操作，支持MCP协议，具备GUI交互能力。TARS的视觉交互基于自研原生GUI模型UI-TARS，采用视觉语言架构增强感知和推理统一动作建模，实现点击输入等操作。扣子空间的浏览器调用和界面操作也应用了UI-TARS。
从Manus到TARS再到扣子空间，竞争焦点从能否操作转向如何高效开放地操作。字节通过开源UI-TARS和MCP协议构建以智能体为核心、工具可扩展的开放生态。

2. AutoGLM
由智谱AI开发的移动端通用智能体，核心创新是把大模型规划决策与机器人流程自动化深度融合，能像人一样直接操作手机应用完成真实日常任务。
不依赖API，而是基于Android无障碍服务，通过“观察”屏幕解析GUI并“模拟”点击滑动实现自动化，兼容性广但受UI稳定性影响。
行动导向特征明显：
（1）端到端自主执行。接收点外卖、订机票等自然语言指令后，自主完成打开App、搜索比价到下单，支付需人工确认。
（2）多模态感知决策。结合视觉识别与ReAct推理框架实时分析屏幕元素，动态规划下一步。
（3）持续学习优化。通过在线强化学习，任务成功率随数据反馈提升。
场景覆盖生活服务自动化如外卖旅行预订、信息处理自动化如新闻整理论文摘要、设备管理自动化如手机清理跨应用迁移。生态还延伸出AutoGLM-Web专注网页自动化、GLM-PC聚焦办公自动化，形成移动网页桌面全覆盖。

3. Genspark
MainFunc推出的超级智能体，定位是数字执行者而非对话接口，可自主规划执行并调用工具完成信息处理到实际联络的全流程。
架构采用混合智能体模式，不依赖单一大模型，而是动态整合DeepSeek系列等专用模型组成内部专家委员会，按翻译分析生成等类型自动分派任务，平衡速度与准确。
工具生态包括深度信息获取通过增强搜索和网页抓取、现实世界交互如自动电话呼叫完成酒店预订餐厅订座、内容与创意生成如图像视频文档演示文稿、数据分析直接处理复杂数据集。还能根据指令生成个人介绍页、交互网页应用、HTML小游戏等功能性数字成果，体现思考即构建能力。
多模型协同决策加广域工具调用，把AI从顾问推向主动交付的代理，代表了在可控前提下提升自主性和现实介入能力的方向。

4. ChatGPT Agent
2025年7月OpenAI发布，由原Operator团队与DeepResearch团队合并打造。关键在于技术路径不同：不是把浏览器研究代码执行等能力工程化拼接在模型外，而是通过端到端统一训练把智能体技能内化为单一模型核心能力，更像一个数字大脑。
可集成文本图形浏览器、终端命令行和图像生成器等工具，呈现实用智能体特性：
（1）自主任务分解与执行。用户用自然语言下复杂指令如准备客户会议简报，Agent会自行规划检索筛选分析并生成PPT文档等可用成果。
（2）交互式协作与可控性。支持多轮对话，任务中主动问细节确认意图，用户可随时打断修改或完全接管，实现灵活人机协同。
（3）安全与权限设计。可能产生实际影响的操作如购物发邮件默认需用户明确许可，模型内置严格防护自动拒高风险请求，对生物化学等领域风险采取最高级别处理。
发布标志着智能体从能回答问题向能用工具完成任务的主动式助手转变，统一架构与安全优先为可靠协作提供了基础。
