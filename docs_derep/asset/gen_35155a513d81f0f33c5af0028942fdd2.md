# 18 进阶提问：层层递进解复杂题

假设你是一名销售经理，想提高团队业绩，会如何引导成员制定方案？
提问一
销售经理：小李，你准备怎么提升销售业绩？
小李听这么问，要么很茫然，要么长篇大论却多为无效建议。
[PRE0]
提问二
销售经理：小李，现在的销售业绩是多少？
小李：回答，略
销售经理：小李，你觉得这个月没有达到预期目标的原因是什么？
小李：回答，略
销售经理：小李，你觉得应该如何改变自己的销售策略？是否需要改变目标客户群？需要增加营销投入吗？
小李：回答，略
在这个场景里，提问二就是典型的进阶式提问，使思路越来越清晰，并逐渐找到有效解决方案。

进阶提问有利于提问者和AI更好地沟通，使AI循序渐进地处理复杂信息，高效解决问题。

什么样的指令是好的进阶提问指令？对比分析如下。

| Before 常规提问 | After 进阶提问 |
| 你这次旅行怎么样？ | 你去哪里旅行了？ |
|  | 你去的那个地方有什么好玩的好吃的？ |
|  | 那个地方有没有什么特别的风景或者建筑？你有没有遇到什么有趣的人和你事儿？ |
|  | 这次旅行让你有哪些感悟？ |

对比可见，好的进阶提问通常导向明确，聚焦核心；由简单到复杂、由表面到深层；具有一定开放性，能促使回答者多角度思考。

进阶提问可按1级、2级、3级、4级结构化呈现。需要强调的是，问题难度和深度会不断增加，提问者需具备相关知识储备，否则难以获得详细准确的答案。
