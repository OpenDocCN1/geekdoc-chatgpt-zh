# GPT-2 Multi-Head 核心拆解

本文把 GPT-2 里与头操作相关的几段逻辑拆开讲，先看剪枝、再看维度变换，最后看一次完整的 QKV 计算链路，保持原实现的维度约定与缓存意图不变。

剪枝时模型会按剩余头数重新算每头对应的特征宽度，随后把可用头总数减去被移除的部分，并把被移除的索引归入记录集合。

合并阶段的输入已经是聚合后的结果。先把序列维提到前面，让形状从头优先变为序列优先，再把头维与特征维压成一维，得到后续层可以直接使用的表示。

拆分阶段先把最后一维按头数展开。展开后，key 需要做一次额外的排列，使特征维与序列维互换位置，便于与 query 做内积；query 与 value 则采用另一种排列，保持批量、头、序列、特征的顺序。

主计算先用 Q 与 K 做点积得到初始分数，若开启缩放则除以特征维的平方根。随后依次套用因果掩码与外部 mask，完成 Softmax 归一化和 dropout 正则化，再根据 head mask 做加权，最后用加权后的分数与 V 做点积得出输出，并在需要时把分数一并返回。
