# 第1章 AI指令提示工程：原理、实践与提问技巧

## 1.1 AI指令提示工程的基本原理

### 1.1.1 提示词设计：打开ChatGPT潜力的钥匙

提示词是用户给AI下达任务指令的文本，是问答对话中的指导性内容。

提示词像一把钥匙，能开启与AI顺畅愉快的交流。运用得当，就能清晰传达需求，让AI给出更贴合预期的精准答案。提示词的质量决定对话效果与使用体验。学会使用提示词，相当于掌握了一套通用的“万能公式”，能准确表达问题并引导AI生成想要的输出。

该公式主要包含五方面。

1. 明确任务类型。提示词需说明希望生成哪类文本，如描述、解释、比较、总结等。如“为市场经理撰写一份工作日报”“以暑期诗意打卡为主题提供旅游攻略”“写一首赞美程序员的诗歌”。

2. 限定讨论范围。提示词需说明主题或具体领域。如“为人工智能软件产品经理撰写不少于500字的工作月报，需包含本月工作、发现问题及未来计划”。

3. 设定输出格式。提示词需说明希望的呈现形式，如列表、段落、表格等。如“制定周一至周五的健身与饮食计划，并用表格输出”。

4. 限定语言风格。提示词需说明语气、风格或口吻。如“请用《大话西游》中唐僧的语气介绍至尊宝”。

5. 给定关键信息。提示词需提供关键要素，以便获得更符合需求的答案。如“扮演资深股票投资经理，分析中国平安基本面及成长性，并用柱状图输出2016—2020年营收”。

什么是AI指令提示工程技术？提示工程师需要什么能力？让ChatGPT来解答。AI指令提示工程是通过设定特定提示信息引导模型生成符合要求的文本的技术。

核心任务包括：指明具体任务、细化任务说明、角色定位、种子词提示、提示公式设计、提示要点约束等。优秀的提示能帮助用户更好控制输出，获得更准确针对的结果。

AI提示工程师负责设计、开发、优化模型的提示策略，提升输出的准确性与可用性。需具备AI与机器学习基础、自然语言处理能力、问题定义与任务转化能力、提示设计与优化能力、数据分析与评估能力、编程与技术能力等。提示工程师与数据科学家、机器学习工程师和领域专家协作，通过精细提示让模型输出更可靠有用。

对普通用户而言，学好AI指令提示词的意义在于：提升效率、降低错误率、提升可理解性、省时省力、满足个性化需求，让AI更懂自己的意图。

### 1.1.2 模型与方法选择：挑对工具事半功倍

选择AI生成提示方法和模型时，可考虑以下因素。

数据规模与多样性，就像研究需要大而全的资料库，模型需海量多样的数据学习。

模型架构，可理解为AI的思维方式，需匹配任务需求。如问答类任务可选择基于语言大模型的方案。

性能表现，关注运行速度、准确性、稳定性与可靠性。

数据预处理，相当于整理资料，使输入更规范一致。

目标任务，明确任务类型后选择适配的提示方法和生成模型。

计算资源，训练与部署需要足够的算力与存储。

可解释性，在法律、医疗等关键领域需理解决策依据。

综合考虑这些维度，才能选出合适的提示方法与生成模型，解决实际问题。

### 1.1.3 结果优化：通过变换提示提升生成质量

优化AI生成结果常用方法是通过变换提示词引导回答，使其更贴合期望。

例如原始问题“如何照顾植物？”，得到的是笼统建议。变换为“如何有效地照顾室内盆栽植物？”，答案就会具体到光照位置、浇水频率、有机肥使用、落叶清理、修剪扶正等室内场景要点。

通过让问题更具体、更指向场景，AI的回复也会更实用、更具针对性。灵活运用变换提示，可获得更个性化详细的输出。
