# 机器阅读理解：从数据集演进到经典模型架构解析

回溯至 2015 年，DeepMind 团队的 Karl Moritz Hermann 等人首发了面向机器阅读理解任务的基于注意力机制的 LSTM 模型。翌年，Danqi Chen 等人推出了大规模有监督数据集 CNN/Daily Mail。该数据集采用独特构建策略：将新闻文章视为段落，利用占位符替换文中的实体，从而将阅读理解转化为完形填空式问题。然而，这种自动化构造方式引入了不少噪声，客观上制约了后续模型研究的深入。

为破解上述瓶颈，Pranav Rajpurkar 等人匠心打造了 SQuAD（Stanford Question Answering Dataset）。该数据集汇聚 536 篇文档与逾 10 万个问答对，答案均定位于原文文本片段。凭借高质量标注与在线自动评测机制，SQuAD 迅速成为该领域首个大规模基准，吸引了全球研究者的目光。截至 2022 年底，SQuAD 排行榜上表现优异的模型均构建于深度学习框架之上，其通用范式为：先对文章与问题进行编码，经交互层融合语义，最后预测答案区间。

- **向量化层**：将问题与原文的 Token 分别映射为向量表征（可选 Word2Vec、Glove 等预训练向量）。
- **编码层**：借助循环神经网络对双方进行编码，使各 Token 向量融合上下文语义。
- **交互层**：核心环节，剖析问题与原文的关联，输出注入问题语义的“Query-Aware”原文表征。
- **答案层**：基于上述表征，通过指针网络或边界模型定位答案的起止位置。

经典模型中，R-Net 与 BiDAF 最具代表性，以下逐一拆解。

### R-Net：双层交互与门控注意力的协同

R-Net 由 Yuxin Wang 等人提出。其向量化层融合 Glove 词向量与字符嵌入，强化输入特征；编码层沿用 RNN 对问题与原文建模。交互层设计为双层结构：第一层引入门控注意力机制的循环网络，实现问题与段落的深度匹配，获取问题感知的段落表征；第二层采用自匹配注意力机制，让段落自我对齐，实现全局语义的高效编码。答案层则由指针网络精准锁定答案边界。网络拓扑详见图 3-22。

### BiDAF：双向注意力流驱动的语义融合

BiDAF 出自 Minjoon Seo 之手（结构见图 3-23）。向量化层混合词级与字符级表征：词级加载预训练 Glove，字符级经 CNN 编码，二者拼接后送入双向 LSTM 深度编码。交互层创新性引入双向注意力流——先构建段落-问题对齐矩阵，据此计算 Query2Context 与 Context2Query 双向注意力，融合生成 Query-Aware 段落表征，再经双向 LSTM 聚合语义。预测端采用边界模型输出答案起止索引。

### 评价指标：精确匹配与语义重叠的双重视角

针对抽取式任务，学界沿用 Pranav Rajpurkar 等人确立的两大核心指标：

- **精确匹配**：预测答案与标准答案字符级完全一致得 1 分，否则 0 分，极其严苛。
- **F1 得分**：将预测与标准答案视作 Token 集合，计算平均词级重叠度，兼顾精确率与召回率。

针对生成式自由回答任务，目前尚无完美评价标准，常借用自然语言生成领域的 BLEU、METEOR、ROUGE 等指标辅助评估。

### 实验题

1. **自动作诗系统**：基于唐诗语料（给定或自爬），设计并实现基于 RNN/LSTM 的续写模型。要求覆盖数据加载、网络架构、模型训练与推理全流程，输出符合中文语法与意境的诗句（如接“湖光秋月两相和”）。
2. **影评情感分析**：基于电影评论数据集，构建 RNN/LSTM 分类器，实现正负向情感判别。完整复现数据处理、建模、训练与测试闭环。
3. **语言建模实战**：基于 Penn TreeBank (PTB) 语料库，训练 RNN/LSTM 语言模型，实现次词预测。涵盖数据读取、网络搭建、训练调优与评测全链路。语料官方源：https://www.ldc.upenn.edu/。
4. **机器阅读理解实战**：基于 SQuAD 数据集，从零构建抽取式问答系统。要求落实数据预处理、网络设计（编码-交互-预测）、模型训练与效果验证。数据集官方入口：https://rajpurkar.github.io/SQuAD-explorer/。
