# 危机中的智慧治理：收放之间的平衡艺术

习近平总书记在杭州考察时提出，治理能力与治理水平的重要标志就是收放自如、进退裕如。通俗讲就是疫情袭来时能迅速收紧管控，形势转好时又能有序放开，在复工复产与疫情防控之间找到合适平衡点，并探索城市治理的新方法。彼时全球疫情走向不明、经济悲观情绪蔓延，国内仍坚持外防输入内防扩散常态化，遏制疫情与有序恢复生产生活成为两大紧迫任务。人工智能作为通用技术，与各行业深度融合显著提升了运行效率，也催生了新场景和新增长点。与此同时，疫情对企业数字化转型的诉求大幅提升，其影响贯穿当下并延伸至后疫情时期。

在线问诊、在线教育、网络直播等板块在具体场景中快速扩张，技术迭代加速。医疗领域中，多地政府与互联网头部企业先后推出免费互联网义诊，全国医生通过线上义诊向含湖北在内的居民提供咨询。以阿里健康在线义诊为例，每小时平均接近3000人次发起问询。教育领域，疫情导致中小学推迟开学，信息技术企业开放免费线上课程、搭建在线课堂，支持学生居家学习。在常态化防控背景下，企业还向学校和教师提供远程教学工具与课后辅导服务，助力停课不停教。消费娱乐领域，线上产业本就保持强劲，宅经济已有基础，疫情期间宅消费渗透率进一步抬升，对冲击起到缓冲，游戏、在线视频、直播、电商、线上教育等板块表现突出。

日常生活服务层面，传统商超餐饮正加速向线上生鲜配送、外卖、无接触快递转型。新冠病毒高传染性叠加春节人口大流动，全国出现史无前例的封城、封村乃至隔离措施，春节期间民众基本居家。隔离带来物资采购困难、社交生活不足等问题。在此背景下，外卖、生鲜电商逆势走高，借助大数据、物联网、人工智能精准把握需求、协调运输仓储，配合成熟供应链管理提升企业竞争力与行业整体效率，有望借此迎来新一轮发展机会。

企业数字化转型方面，疫情初期全国绝大多数单位企业无法按时复工，仅线上业务维持，线上办公需求爆发式增长。疫情严峻性促使大量传统企业更积极依托电子商务平台开展采购销售，并广泛使用信息化工具提升运营效率。疫情推动产业电商平台和云服务市场发展，国内云办公从推广期迅速进入实用期，规模急速扩张的同时对承载能力提出更高要求。同时全部业务线上化，要求云办公厂商提供覆盖全场景的在线协同方案和业务集成方案。总体来看行业增速将大幅提升，服务能力、业务集成能力与数据安全性将成为未来竞争关键。

企业复工复产方面，智能技术与大数据助力精准复工。在国务院办公厅电子政务办指导下，杭州健康码经验推广至全国，并配套钉钉员工健康打卡功能。阿里巴巴在全国推广的健康码加企业复工复产系统，将自有复工系统接入政府建设的复产复工平台，如杭州企业复工申报平台、上海企业复工健康云平台等，企业可授权调取员工健康码信息后通过政府在线平台提交复工申请。政府可掌握区域内返工复工人员健康状况与返岗需求，并以企业整体健康状况为依据决定批复。

同时，生产企业对接政府复工复产平台可实时获取疫情信息，优化员工健康、返岗、排班等管理；企业可通过政府平台与疫情物资、原材料资源有效对接，降低供应链风险。通过数据聚合与分析，平台帮助地方政府掌握各区域、各领域企业复产复工情况、员工健康状况以及疫情防控落实情况，实现全局化系统推进。政策落实上，杭州上线亲清在线，实现政策在线兑付，企业无需提交任何材料，3月2日率先上线年税收50万元以上商贸企业税收和企业员工租房补贴两项功能，配套服务和功能开发迅速跟进。

### 四 AI抗疫带来的三点启示

第一，疫情防控要求下，智能技术为公共治理与企业发展提供精细化解决方案。对比2003年非典，本次突发公共卫生事件中智能技术有效助力社区排查、流行病调查、流动人口管理，极大提升政府管理效率与效果。同时也为特定行业与企业复工复产提供精准工具包，出现互联网企业智能平台协调抗疫物资调配、健康码实现人员一码通行、电力大数据指导复工决策等场景。得益于大数据与智能技术快速发展与市场应用，各级政府对数字产业大力扶持，近年来中国数字经济蓬勃发展，为应对疫情大考提供了基础设施、技术支撑和人才积累。

第二，智能技术助力疫情防控呈现多元主体参与的新型治理模式。实践证明应对复杂突发情况，仅靠政府难以有效，需要协调企业与社会组织力量。在部分防控成效显著地区，治理水平与产业发展相互促进。养兵千日，用兵一时，应急管理中的创新需要日常创新土壤和互联网思维培育。地方政府不仅要通过新型基础设施建设提升社会治理支撑条件，还要培养基层干部的互联网思维，提升其运用科技和数据的能力，对基层政府能力建设提出更高要求。

第三，疫情期间的特殊场景和需求为智能技术应用带来新的机遇。不见面、不接触的非常态为技术应用和数据共享提供契机和试验场，线上服务迎来发展春天，打破原有利益格局和现实束缚，为数字经济带来新机遇。从企业角度看，疫情将进一步推动智能制造、无人工厂发展趋势，企业抓住机遇利用数字化转型实现产业升级是化危为机的可行路径。

# 数字创新生态：商业价值与公共价值如何共进

梁正 李佳钰[^(\[1\])](#chapter012.html#m1)

**摘要：**本文基于创新生态系统的价值创造与价值共创逻辑，指出数字创新生态系统的运转需要行业数据与公共数据共同支撑，其演进需要商业价值与公共价值共同引领。力争上游的发展与行稳致远的治理需要协同推进。

**关键词：**商业价值 公共价值 数字创新 创新生态系统

### 一 引言

数字创新是指在创新过程中对信息采集、计算、沟通和连接技术的组合应用，引致创新生态系统的行为逻辑发生变化。数字创新加速了创新要素的关联重组，重塑了创新主体间的价值共创模式，引发了关于数字创新生态系统发展与治理的思考。倡导数字创新的商业价值意在促进创新政策与产业发展的有效结合，更可持续地推动数字创新生态系统力争上游；倡导数字创新的公共价值意在促进创新政策与公共治理的有效结合，更富成效地推动生态系统行稳致远。准确把握数字创新生态系统的价值导向，有助于指导行业数据与公共数据要素价值创造的创新实践，也将推动产业与社会发展的深度融合，对构建与治理具有重要意义。

### 二 行业数据和公共数据支撑创新生态系统的运行

在数字经济时代，工业经济时代的劳动者转变为知识创造者，传统能量转换工具升级为智能工具，数据成为除能源、资源、资本之外的全新生产要素。创新生态系统主张多元主体共同参与价值共创，数字创新生态系统一方面在行业数据基础上通过价值主张匹配多边参与者实现商业价值创造；另一方面在公共数据基础上通过合作传递网络、有效责任机制和评估体系实现公共价值创造。可以认为，行业数据和公共数据的形成为数字平台管理服务提供支撑，在企业互动和公民参与驱动下为数字创新生态系统运行提供动力，进而面向市场和社会形成商业价值和公共价值，如图1所示。

以数字平台为核心的管理服务能够为企业互动和公民参与提供有效激励和监督保障，相关数字创新主体可持续参与产业与社会发展。政府主导的公共平台管理服务有利于推进职能创新和流程再造，其基本公共价值表现为自下而上的公共价值创造模式，核心公共价值表现为自上而下的公共价值创造模式，即公众偏好和经营偏好通过社会系统进入数字创新领域后分别形成的公共价值。而企业主导的行业平台管理服务能够释放算力、算法和行业数据的活力，其基本商业价值表现为逐步聚焦的商业价值创造模式，核心商业价值表现为逐步扩张的商业价值创造模式，即普通企业和龙头企业通过产业创新系统进入数字创新领域后分别形成的商业价值。对于数字创新生态系统而言，应统筹协调基本商业价值、基本公共价值、核心商业价值、核心公共价值，从而创造数字创新生态系统最大的系统价值。

### 三 商业价值和公共价值共同引领创新生态系统的演化

尽管数字创新的商业价值和公共价值具有诸多共同性并相互依赖，但在生态系统中更多作为异质性存在发挥作用。为最大限度发掘两者，不能仅限于对已形成行业数据和公共数据的治理，还应扩展到数据+算力+算法的数字生产者体系中。

数字创新生态系统的演化离不开组织自身乃至所在系统的数字生产者体系，数字生产者体系对数据的形成具有使能作用。首先，数字生产者体系能够使行业数据和公共数据在不断试验和实施中快速形成、修改和重构，促进数字创新实施；数字生产者体系为生态系统运行提供创新模式快速迭代契机，但这种更具效率和动态性的模式也使得数字创新往往难以控制和预测。

其次，数字生产者体系中的行业数据和公共数据都应着眼并落脚于让数据处于可使用状态：一是运行主体数字化，从多边主体掌控的公共资源中识别公共数据，从价格信号机制调节的产业资源中共享行业数据，一并纳入生态系统；二是运行环境数字化，针对行业数据和公共数据在不同平台间的流动，构建便捷化数据通道，促进数据自由流动。当数字生产者体系被产业和社会很好感知和理解后，能够创造运行主体数字化和运行环境数字化的契机，形成新的产业组织或社会组织形式。

最后，数字生产者体系能够促使企业管理者和公共管理者建立新的产业循环和社会循环，进而构建新的数字治理体系改变商业价值和公共价值的导向。其中，商业价值和公共价值分别强调产业创新主体和公共管理者在价值创造中的核心作用：产业创新主体通过与行业企业、其他利益相关者协调确立商业价值并完成价值创造；公共管理者通过与社会公众、其他利益相关者协调确立公共价值并完成价值创造。前者是高度市场化的发展过程，后者是高度行政化的治理过程。这种发展与治理并存的形态，尽管在主体合作协商、利益表达等方面存在障碍，但有利于行业数据共享和政府数据整合，打破信息孤岛，突破碎片化管理，推动形成行业与社会联动的生态格局，进而推动行业数据和公共数据的价值共创。数字创新生态系统演化的本质是重新构建一套价值创造的方法论，在数字生产者体系使能作用下，通过在产业循环和社会循环中对运行框架的模拟和择优，最终实现商业价值和公共价值的共创，如图2所示。

## 四 发展与治理需协同共进的经验总结与思考

总体来看，中国复杂的市场、社会和制度环境为数字创新提供了大量场景，数字创新主体通过商业价值和公共价值引导涌现全新创新模式，但政府对数字创新治理不适应的根本原因在于不放权，传统经济的事后监管模式与新经济治理模式需求不匹配，直观反映在监管速度低、信息掌握不足、人力物力缺乏三个方面。因此在中国处于全面深化改革阶段，需要以打造包容审慎的引领性治理规则为前提，从政府权力下放切入，提供行业和社会的实验情境来探索数字创新生态系统的治理机制。

首先，商业价值导向和公共价值导向需要形成良性互动与反馈。行业数据和公共数据都是在使用中创造价值，但我国无论行业原始数据还是公共数据，都存在质量差、可利用性低的问题，尤其是行业数据集建设成本高、专业性强，部分行业数据集建设各自为政、利用率不高。大量数据资源集中在政府部门，基础性数据向社会开放规模小，数据要素流动激励机制不足，数据共享缺乏安全保障，数据所属主体缺乏共享动力和意愿。

其次，在行业数据共享、政府数据开放等制度创新背景下，很有必要从数字创新生态系统视角探索发展与治理关系。商业价值和公共价值的平衡为数字创新生态系统治理研究提供可行思路。政府部门需以公共价值为导向推动政务数据整合，盘活公共数据资产，定期发布脱敏行业数据集；能源、交通、金融等领域央企、国企需以商业价值为导向制定数据积累指标，在不影响商业机密基础上定期收集发布，建立行业共享数据集。在此基础上搭建一体化开放共享平台，数据需求单位按权限分级访问，依条件申请获取数据资源，在充分调动行业和社会数据共享积极性的同时实现价值共创。
