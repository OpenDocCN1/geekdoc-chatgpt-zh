# 2.3.4 语义标注语言

# 1. JSON-LD

JSON-LD 即 JavaScript Object Notation for Linked Data，是一种基于 JSON 来表达和传输链接数据的方案。它说明了如何用 JSON 表示有向图，以及如何在同一文档中混排链接数据与非链接数据。JSON-LD 的语法与 JSON 兼容。JSON-LD Processing Algorithms and API 描述了相应的处理算法与编程接口，可在 JavaScript、Python、Ruby 等环境中直接转换处理 JSON-LD 文档。

# 2. RDFa

RDFa 即 Resource Description Framework in attributes，是早期网页语义标注语言之一，也是 W3C 推荐标准。它扩展了 XHTML 的若干属性，让制作者能在页面里写入机器可读的资源描述。借助 RDF 的映射关系，RDFa 可把 RDF 三元组嵌入 XHTML 文档，标准解析器就能从 RDFa 文件中提取出 RDF。

RDFa 通过命名空间机制，在已有标签中加入相应的属性，供支持 RDFa 的浏览器或搜索引擎解析，从而提升优化效果。
