# 普通人的小红书实战笔记

## 推荐人语

在我这里，一本书想让我读下去，得同时满足两点。

第一，作者得有真本事，做出过让人信服的成绩。第二，作者本人必须是普通起步，没有靠资源吃饭，也没有那种天生就能开挂的天赋。

缺了第二点，书照样会卖。因为很多人爱围观那些外表惊艳、脑子超群的人，读他们的书像看戏。我不喜欢看这种戏，因为学不来，也不想学。

缺了第一点，哗众取宠的内容也可能爆火。毕竟干货太硬，在快节奏的当下，大家更想要好消化的东西。可读完就觉得浪费时间，而我们内心其实都渴望成功，只是嘴上不承认成功能用数字来衡量。

如果你认同上面的看法，可以接着往下看。

请你先闭上眼睛回忆一下，每天刷小红书的时候，看到的那些账号和笔记，大多数是不是就两种：要么平平无奇，要么高不可攀。踏踏实实做出优秀结果的普通人，好像总在隐身。

在我认识的人里，琳达就是那种典型。认识她很多年了，给我的印象一直是真诚、冷静、淡定。

有的人有100分的能力要讲成1000分，有的人能把100分讲成100分，有的人100分只能说出50分。琳达大概属于把100分说出95分的人，剩下的5分不是藏私，而是她觉得还没整理好、还需要再打磨。

正因为这样，每次和她交流都特别过瘾。聊起各自擅长的领域，完全没有时间概念，电话能打到手臂发麻，见面能聊到咖啡店关门。

有一次她特意约我来办公室采访，还摆了专业的拍摄设备。结果聊得太投入，设备根本就没打开。几个小时的精彩对话，最后只录到几秒。

小红书上一个很明显的规律是，真诚做自己的人更容易成功。大多数人第一反应是模仿，看别人笔记有几万赞，自己照做却只有20赞，然后一次又一次鼓起勇气，又一次又一次掉进同一个坑。

这本书不是堆行业黑话的教材，而是一位良师益友亲手打磨的行动手册。看下来你会发现，除了选题、文案、封面、变现这些技术层面，更重要的是她怎样把自信和耐心带进整个过程，让普通人能够持续产出有价值的内容，而不是被瞬息万变的流量牵着鼻子走。

说实话我觉得书名有点保守，如果是我来取名，会叫《普通人如何在小红书上找回自信》。琳达做的事很了不起，就是教你一边做自己一边获得流量。你只要迈出第一步，平台会立刻给你真实的反馈，比自己瞎琢磨有价值得多。这种把信心还给创作者的力量，现在是最稀缺的资产。

如果你已经翻开了这本书，就别再犹豫了。挑一个最有感触的章节立刻动手：写一句有趣的话，拍一个随意的15秒短视频，或是做一次深度的复盘。真正上手后你会发现，琳达的每一句话都在背后推你一把，这本书和你亲身验证的结果，会成为你一路前行的底气。

完美不是灵光一闪，而是日积月累打磨出来的。祝你的小红书之路，找到属于自己的节奏。

## 先说两句

想把一件事做好，大致有两条路，一条是自己摸索，一条是照着过来人的经验学。

我刚上小红书时选了第一条。那时候平台还没现在这么主流，我爸妈压根没听过这个名字。没有任何经验可抄，没有教程可看，只能在黑夜里摸索。

弯路走了多少，自己都数不清。

你们现在会犯的错，我几乎全犯过。话多没重点、自我感动、没有选题意识、随心所欲、总觉得自己什么都会结果什么都做不好、连续好几篇数据惨淡、更新很久粉丝不动、封面没人点、拿不准要不要放字和怎么放才好看、爆款之后接不上、拍视频小动作多、表现不自然等等。

当时身边的朋友大多是工科背景，算法工程师、程序员、产品经理，做社群发声并不擅长。唯一的陪伴者是我的男友，他会认真听我讲想法，和我讨论、鼓励我、无条件信任我，给我最实在的建议。那段日子像在黑夜里只有一点萤火，刚看到希望就又跌进绝望。

我实在不想让任何人再重复这种煎熬。

回头看，我人生前20年唯一的优势大概是学习力。上学时同学都叫我学霸，虽然不是学神，但成绩靠的是努力和找方法。

这份韧劲后来帮了大忙。即便很长时间看不到反馈，我也没有想过放弃。

小时候爸爸常说：方法总比困难多。肯定有办法的。

为了学标题和写文案，我把市面上能找到的文案书几乎都读了。为了写好广告，我又补了一堆相关的书。为了讲好故事，我读小说和写作工具书。为了让视频更生动，我去学脱口秀，还准备上开放麦。为了稳住心态，我坚持冥想、跑步、读毛选、学哲学。

别紧张，除了调心态，其他都不是必修课。

我开始复盘自己的笔记，找爆款的共性；大量阅读别人的内容，打破自己的刻板印象。在持续练习和分析里，选题思维慢慢成形，文案感觉也出来了。爆款越来越多，粉丝从0涨到现在的80万。

我只教自己用过且有效的方法。本书里的每一条，都是我亲自验证过的，也在大量学员和咨询中得到重复验证。有人因此做出万赞笔记，有人一篇涨粉过万，有人一篇笔记带来比过去十几篇更精准的客源。

照着有经验的人学，比单打独斗快得多、省力得多。

现在小红书已经家喻户晓，方法论满天飞。大家的困境不是缺方法，而是方法太多。

你一定见过“一招让笔记小眼睛从100变10000”“换个开头点赞涨100倍”之类的标题。看的时候热血上头，以为马上就能摆脱低谷。可真正动手时，脑子里依旧空空，一个字也写不出来。

用《孙子兵法》来类比，这类花哨的招数可算作奇谋诡道，属于战术层面的小技巧，比如囤标题、练开头、背话术。

和它相对的是五事七计，是打仗前的准备和对己对敌的分析。放到小红书上，就是认识自己的优势、了解受众喜好、持续产出有价值的内容、复盘、保持学习和高质输入。这些才是战略层面，决定胜负的关键。

刚入门、粉丝不多的人，不要跳着看，按顺序读，会有很大收获。

已经有一定体量的博主，可以速读加精读结合。熟悉的部分快速过，卡住的地方仔细看。我相信即便成熟创作者，也能从中找到新的思路和突破口。

说实话，我自己卡住的时候也会回头重读这些内容，它们帮我突破过一个又一个瓶颈，也多次助力转型。

不过还是要说明，并不是所有人这本书都合适。

如果你想要7天起号、靠抄别人的内容爆款、总想找捷径却不愿投入时间、付出一点时间就要立刻见效、数据一差就骂限流不检查内容、觉得做博主赚钱全靠运气，那么这本书可能不适合你。

从自己身上找问题很难，因为要承认自己的暂时失败。但做小红书就必须这样。

我承认有天赋异禀的人，能轻松做到几十上百万粉丝，但我不是，也没认识过。

运气是存在的，但运气只眷顾有准备的人。没准备的人就算撞上机会，也因持续不了优质输出而昙花一现。

对创作者来说，做出一个爆款不重要，能持续做出爆款才重要。

不认真写并复盘100篇笔记，就别埋怨幸运女神缺席。

当你不再祈求运气，把时间和精力放在内容上，你会发现好运会自己找上门。

夜深了，办公区只剩我和斜对面女生敲键盘的声音。想起刚做小红书那年，我写过一句话：我想在30岁前写一本书。巧的是，30岁这年，书真的出版了。

很荣幸在路上遇见了你们，没有你们就没有现在的我。特别感谢书中所有提供案例的博主朋友，是你们的内容让这本书更鲜活。

这本书写了一年，反复斟酌修改，如今收尾。收尾不等于结束，欢迎大家在小红书上分享阅读感受、观点、成长，甚至某个章节的思维导图，我实在抽不出精力做了，只能拜托你们了。

出版后，这本书就属于读者了。

希望它能为你开启生命中的新一页。

琳达

# 第一章
为什么入局？浪潮已经在眼前

我是在四年前的一个晚上决定开始做小红书的。

那时我刚工作不久，状态很糟，天天加班。生活并没有像毕业时设想的那样越来越开阔，反而缩成两平方米的格子间，每天就是两点一线。有天下午去茶水间倒水，站在窗边往外看，春天来了，树叶翠绿随风摇晃，我突然很难过：难道我的一生都要困在格子间里，错过一个个春天吗？

我跟父母聊过，他们说：大家都这样，几年就好了。

真的几年就会好吗？

没多久，身边的同事就陆续走了。

裁员开始了。

## 我的经历

有一天晚上九点多下班到家，钥匙插进锁眼的那一刻，脑子里有个声音狠狠敲了我一下：你还要这样生活到什么时候？如果你每天重复同样的生活，怎么指望未来会变好？

那一刻我清醒了。

如果想得到从未拥有过的东西，就必须去做从未做过的事。否则生活永远不会改变。

一晃四年过去了。

四年里，我从一个零基础的新手，摸爬滚打成拥有80万粉丝的博主。中间经历多次转型，才慢慢找到适合自己的内容和风格。做图文两年后，我几乎能做到篇篇互动过千，于是开启视频挑战。几个月摸索后开始频出爆款，一年做了二十多条上万人点赞的视频，涨粉三十多万。

正因为这些多元经历，我能很具体地感受到大家做小红书时可能遇到的卡点、疑问和焦虑，不只是经历过，更是解决过、靠自己突破过。

现在我很久没坐回格子间了。我可以在上海的咖啡店里工作，也可以在大理洱海边的阳台上工作，还去过卡塔尔、沙特、西雅图的湖边工作。大巴车、地铁、出租车、飞机舱、快餐店，都是我的办公室。

我也不用等旺季才出游了。淡季便宜又舒服。

工作强度没降，但时间完全属于自己。

这四年，比过去十年都更猛烈。生活终于像二十岁时设想的那样，越来越广阔。

而这一切改变，都始于四年前决定做小红书的那一刻。

## 他们的转变

小红书改变的不止我，这一年我看到太多学员因为它改变了生活。

短短一年，@大乐Daleee 从图文转向视频，涨粉1.7万，品牌合作一度爆单；@李莉安Lilian单篇笔记涨粉6万；@梦想家瑶光突破瓶颈期，涨粉3万，如今全国旅居；@雪妮爱串门3.7万粉丝，单篇报价2.5万，商单不断；@圈圈有灵感从绘画赛道转职场内容，迅速做出点赞过万的爆款视频，带来8000多粉丝增长，开启副业；@啵啵小圆子从商业瓶颈期到做出2万点赞爆款，并转化大量意向客户；@EnglishOnAirMrZ曾摸索一年只涨27粉，学习后不到一年涨近7000；@糖小小靠单篇笔记涨粉1万；等等。还有无数学员的第一次：第一条千赞万赞笔记、第一次品牌邀约、第一次粉丝破千破万。

很多人借助这些方法从素人成长为有千粉万粉的博主，开启内容创作之路，获得第二份收入。收入多元后，职场人不再惧怕裁员；有了赚钱能力和外界认可，被生育影响收入中断的女性重获自信和话语权；企业、商家和个人创业者也能更轻松地把产品卖出去。

如今的小红书，早已不是只有个人IP的天下。随着商业化发展，低粉变现的玩法越来越多。我的咨询者里，有粉丝几百、点赞十几个却月入20万的咨询所，有粉丝1000每月5-6万的职场人，有粉丝3000年入七位数的老师。

直接的收入回报让人上头。除此之外，能让我坚持下去的另一个动力，是分享的观点和方法能在网上传播并触发改变。偶尔在大街上有人走过来告诉我，你的某篇笔记帮到了他，那种喜悦和成就感会上瘾。

很多人问我：为什么要把赚钱的方法分享出来？

不要把做小红书看成零和博弈。世界的资源和机会比我们想象的多。分享不是失去，而是获得。我通过分享积累了80万粉丝，拥有上千名优秀学员，获得出版机会，和之前从未接触的资源和机会建立连接。这就是分享的意义：它不会让你失去什么，只会让你得到更多。

去做小红书吧，去分享你的一切。
