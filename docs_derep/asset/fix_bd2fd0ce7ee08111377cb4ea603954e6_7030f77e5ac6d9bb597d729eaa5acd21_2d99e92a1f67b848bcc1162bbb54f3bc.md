熟练了接单的节奏，后续推进会更从容。

一旦把来龙去脉吃透，很容易拿到长期合作，甚至带来介绍。第一单收一笔并不重要，重要的是有了标杆之后可以逐步抬价、挑选好客户，把一次性的买卖慢慢沉淀成持续的伙伴关系。零到一是最难的坎，迈过去之后复购和口碑就会自己滚起来。

找首单不要追求完美立刻上桌。先从自己最擅长的触点试水：朋友圈小范围探探水，猪八戒练手，淘宝开个长期摊位。关键是先动起来，哪怕先接一单练练手、甚至低价试做，也比一直卡在构思里强。有了开门单，后续单子才会自然跟进，你离用 OpenClaw 实现变现只差这一次启动。

## 10.2 交付标准：怎样让客户真正满意

合同谈妥、价格敲定之后，最容易翻车的环节是交付。很多初入外包的新手以为代码跑通了、功能能用就算结束，结果客户一看就说“这不是我要的”，随后进入扯皮、退款、差评的循环。

问题根源是双方对“完成”的定义不同。你觉得上线就好，客户要的是能解决问题才算数。要想让客户愿意付钱还主动转介绍，就得先给交付立规矩。

### 先把预期拧一致
不满意的案例里，十之八九是预期没对齐。你以为在做 A，客户默认是 A+B+C，最后交出 A，客户觉得被缩水。

动手前，把对齐的工作做到位。

1. 写一份需求确认书
别只靠口头。沟通结束把要点落成文字，哪怕是微信里的条目清单也行。要写清：
输入是什么？例如客户每天会提供一份 Excel。
输出是什么？例如每天自动生成 PDF 报表并发到指定邮箱。
功能边界在哪？例如仅处理标准格式，异常数据需人工处理。
不包含什么？例如不负责数据本身的准确性，只负责自动化流程。
把“不做”的范围也明说，能省掉大量后续纠纷。

2. 先给客户看原型或示例
不确定对方想要什么就别憋大招。先做一个极简版本，或找个相似案例截图确认：“你理解的是这个方向吗？”提前收集反馈，比闷头做完返工划算得多。

3. 提前约定验收标准
开工前就说清楚什么叫合格、什么叫完成，比如：
连续稳定运行七天无报错；
处理一百条数据准确率达到百分之百；
单次执行耗时不超过一分钟。
把这些写入合同或聊天记录，验收时才有依据。

### 交付过程中保持透明
客户最怕钱付了人消失。过程越透明，信任感越强。

1. 节点同步
不必每天汇报，里程碑要主动告知。例如：
“需求已确认，我开始编码了。”
“第一版跑通了，我发截图给你看看。”
“遇到一个小阻塞，可能要顺延一天，先跟你说一声。”
提前沟通的延期，客户通常能接受。

2. 上线后主动回访
交付一周左右主动问一句：“最近使用体验如何？有没有卡点？”显得负责，也为续单埋下伏笔。

3. 主动给优化建议
客户使用一段时间后，可以提升级思路：“我看你数据量在增长，要不要加个自动备份？”需求自然延展。

4. 委婉索要推荐
体验不错时可以请对方帮忙：“如果服务还行，方便在朋友圈或同行群里介绍一下吗？”一次推荐往往带来几单。

### 一次真实踩坑
我认识一位做自动化外包的朋友，首单犯了三个典型错误。

第一个是需求没对齐。客户说“帮我自动整理销售数据”，他理解成每天发个 Excel 就行，客户实际想要的是自动出图并推送到老板微信。最后只能免费补功能收尾。

第二个是变更失控。做到一半客户说“顺便加个自动推送给分销商的功能”，他觉得简单就做了，后面又叠加几个“顺手”的需求，花了双倍时间却没多收一分钱。

第三个是交付太草率。把代码丢过去说“搞定了”，客户不会部署，反复提问，他花了三天远程教学，累到崩溃。

后来他改了套路：先出需求确认书，任何变更先谈价，交付时附带文档和演示视频。现在回头客多，报价也能逐年抬升。

### 可直接照用的交付清单
每单结束对照勾选：
- 需求确认书或聊天记录已存档，双方已确认；
- 脚本已实测，连续运行 24 小时无报错；
- 异常场景已处理，例如网络中断的恢复逻辑；
- 交付文档已准备，含安装、使用、常见问题；
- 演示视频已录制，如客户需要；
- 已远程指导客户上手；
- 保修期与售后范围已说明；
- 客户已正式确认验收。

交付是外包的最后一公里，也是最容易被忽略的一环。对齐预期、透明推进、清晰交付、跟进售后，四步做全了，客户会从一次性买家变成长期伙伴，还会帮你带新客户。口碑就是这样一单单积累起来的。

## 10.3 实操案例：用 OpenClaw 让小店抖音自动发视频

小张是个体户，经营一家小吃店，想靠抖音拉客。他自己拍了几条视频尝试过，发现剪辑、配乐、写文案、定时发布太费时间，忙完店铺根本坚持不下来，一周就放弃了。

后来在朋友圈看到“AI 自动化代运营”，抱着试试的心态找上我。他的诉求很简单：“我只要每天能自动发一条视频，内容是我店里的菜品，不用多精美，但要能坚持。”

这个需求用 OpenClaw 来实现非常合适。最终帮他实现每月只需一小时准备素材，其余时间全自动发布，每月收费两千，还介绍了三位同行过来。

### 第一步：挖掘真实痛点
初次沟通小张说了很多：想涨粉、想卖货、想做网红。我没有被带跑，反复追问细节：
- 现在每天发几条？想几点发？
- 素材谁拍？谁剪？
- 文案谁写？有没有固定格式？
- 发布后需要回复评论吗？
聊下来才发现，他真正要解决的是“每天发一条”这个重复劳动。视频他自己能拍，能用剪映简单剪，但上传、填标题、定时发布这一步最容易忘。
核心诉求就一句话：我准备好素材，你帮我按时发出去。

### 第二步：设计自动化方案
逻辑很清晰，让 AI 在固定时间自动登录抖音创作者平台，上传视频、填写标题、点击发布。
用到的能力：
- cron：设置定时任务，每天固定时间触发。
- browser：控制浏览器，模拟人工操作。
- filesystem：读取本地视频文件和文案。
- llm（可选）：如果需要自动写标题可用大模型，他已有固定格式，所以没用。
流程：
1. 客户每周一提供一个文件夹，里面有 7 个视频，按日期命名如 2026-03-09.mp4，和一个 titles.txt，每行对应当天的标题。
2. 文件夹放到服务器指定目录。
3. OpenClaw 每天凌晨七点启动 browser：
   - 打开抖音创作者平台登录页，首次手动扫码保存 Cookie，后续自动复用；
   - 进入发布页，上传对应日期的视频；
   - 从 titles.txt 读取对应日期的标题填入；
   - 点击发布。
4. 发布结果写入日志，异常时微信通知我人工处理。

抖音网页经常变动，直接写死选择器不稳定。我先尝试图像识别定位按钮，后发现创作者平台相对稳定，CSS 选择器即可。

### 第四步：交付给客户
交付不是丢代码，而是一整套服务。
1. 环境：他准备一台便宜的云服务器，我负责安装 OpenClaw 和依赖，他不用接触服务器。
2. 登录：首次需要手动扫码，我远程指导扫一次，后续 Cookie 自动保存。

4. 试用期：先免费试运行一周。一周后视频准时发出，粉丝涨了几百，他主动转了两千元。我报的是首月两千，后续每月一千五。

### 第五步：维护与升级
首月运行平稳，只因一次抖音改版导致上传按钮位置变化，花半小时修复并加了更稳健的选择器。
第二个月他提出新需求：“能不能自动回复评论？有人问价格我想自动回。”评估后报价一千元做关键词匹配加预设回复，他同意了又多一笔收入。
现在已合作半年，每月稳定一千五，还介绍了三位餐饮朋友过来，按老客户介绍打九折成交。

### 为什么客户愿意持续付费
算笔账：他自己发每天花十分钟，一个月约五小时。按厨师时薪一百算，价值五百。我收一千五，看似贵，但省了时间成本，保证了持续更新带来的流量收益。更关键的是，他不用记着操作，不会断更。
这就是典型的省时省心模式，客户愿意长期买单。

### 可复制的关键点
- 画像要准：小老板、个体户，有内容无时间，愿为省时间付费。
- 卖服务不卖脚本：托管运行，客户零负担。
- 按月收费：持续维护比一次性买断更合理。
- 边际成本低：一套基础设施可服务多客户，收十个客户月入过万很现实。

抖音代运营只是 OpenClaw 外包的一个样本。自动发小红书、公众号、微博的需求到处都是，背后都是一群没空没技术的小老板。用 OpenClaw 搭好流水线，解决他们的痛点，按月收钱即可。

## 赚钱模式三：打造行业专属自动化工具

## 11.1 找细分市场：电商、房产、招聘、教育

垂直领域的自动化工具，指针对某个特定行业、特定人群解决特定问题的成套方案。比如电商卖家自动上架工具、房产中介自动发房源工具、招聘 HR 自动筛选简历工具。它不是单一技能，而是多个技能组合成的产品，能批量卖给同行业很多人。
优势很明显：单价高于卖技能、比接外包更省心、可重复销售，一旦跑通就有持续收入。

### 为什么要聚焦细分市场
很多人想做人人都能用的产品，结果做出来人人都觉得不够好用。因为太泛了。聚焦细分市场后，你面对的是一个行业里高度相似的痛点，只要解决得了，他们就愿意付钱。
电商卖家每天要上架几十件商品，手工填信息太烦；房产中介要把房源发到十几个平台，复制粘贴到手酸；招聘 HR 每天筛几百份简历，眼睛都花了；教育机构要给家长发上课提醒，发漏了就被投诉。这些痛点只有业内人懂，钻进去你就是专家。

### 怎么找到这些细分市场
**方法一：从自己的经历出发。**
你曾在哪个行业干过？现在在哪待着？每天被什么重复性破事烦到想砸电脑？那些破事就是机会。你懂行话、懂流程、懂付费意愿，比外人更有优势。

**方法二：从身边朋友出发。**
电商朋友说“每天手动回亲在的烦死了”，可以做自动回复机器人；房产朋友说“房源要复制到十几个平台”，可以做自动群发工具；HR 朋友说“简历太多关键词匹配做不了”，可以做自动筛选工具；教育朋友说“上课提醒发漏被投诉”，可以做自动提醒工具。先免费试用，验证需求再推广。

**方法三：在行业论坛社群里搜吐槽。**
知乎、小红书、B站、行业论坛、微信群、QQ群里，经常能看到“有没有自动上架软件”“自动回复怎么设置”“简历自动筛选有没有”。这些帖子就是需求清单。你可以先回复“我正在做，好了通知你”，先收潜在客户。

**方法四：补现有工具的缺口。**
每个行业都有工具，但总有做不好的地方。电商已有千牛、店小蜜，但自动回复死板，可用 LLM 做更智能回复；房产已有各平台发布工具，但不能一键多发，可做统一分发；HR 已有简历筛选，但只能关键词匹配，可做 AI 理解内容打分。这些空白就是切入点。

目标用户：淘宝、拼多多、京东卖家，尤其是小卖家和个体户。
