围绕 Tavily Web Search 构建的可选插件比较丰富，选型前建议先查阅 Skill.md，优先考虑官方出品或下载量靠前的版本更稳妥。

在终端执行以下命令即可完成安装：
clawhub install openclaw-tavily-search

安装完成后需要在 OpenClaw 主配置中补充 API Key。Tavily 为开发者提供每月 1000 次搜索的免费额度，可在官网注册获取。Key 配置完毕后，Agent 就能按需发起网络请求，拉取最新的行业报告和新闻。API Key 的具体填入方式将在 10.3.3 节统一说明。

**10.2.2** **summarize 与 humanizer 技能**

拿到原始素材后需要加工。summarize 是 OpenClaw 官方维护的内置能力，擅长处理长文本、PDF 乃至语音转写，输出结构化的核心要点。

作为内置能力无需单独安装，只需在配置中保持启用即可。对数万字的行业研报尤为适用：Agent 不必把整份文档塞进上下文，调用 summarize 即可提炼核心观点，既节省 Token 又避免因窗口过长导致信息丢失。

文章收尾阶段，LLM 常会出现明显的机器痕迹，例如排比过度、情绪单调、频繁使用“首先、其次、最后”。humanizer 就是为此引入的。它通过特定的提示词工程与写作范式，迫使 Agent 以更自然、更有对话感的语气写作，会自动调节长短句、加入过渡和口语化表达，使成品接近资深人类编辑水平。公众号对阅读体验要求高，这一环节尤为关键。

安装命令：
clawhub install humanizer

**10.2.3** **公众号发布技能**

本节引入 baoyu-post-to-wechat，这是 ClawHub 上 JimLiu 维护的微信公众号发布插件，目前 Star 已超 2200，是社区最成熟的自动化方案之一。

设计思路是将公众号发文流程封装为 Agent 可调用的工具，让 Agent 像真人编辑一样操作后台。

技术上提供两种推送路径：

• API 方式：直接调用微信公众号官方接口，把格式化后的文章推到草稿箱。速度快稳定性高，但需使用已认证的服务号并配置好 AppID 与 AppSecret。
• Browser 方式：借助 Chrome DevTools Protocol 自动操作网页后台，模拟登录、粘贴、提交。适合没有 API 权限的订阅号，首次使用需扫码登录一次以建立持久会话。

插件内置多套专用脚本：

• scripts/md-to-wechat.ts：把 Markdown 转为微信兼容的 HTML，并自动处理图片上传、外链转底部引用等排版细节。
• scripts/wechat-api.ts：负责 API 方式的草稿箱推送。
• scripts/wechat-article.ts：负责浏览器自动化方式的推送。

此外还内置多套 CSS 主题如 grace、simple、modern、default，以及颜色预设 blue、vermilion、purple 等，视觉效果可达专业水准。

安装命令：
clawhub install jimliu/baoyu-skills/baoyu-post-to-wechat

安装后若选 API 方式，需在公众号后台获取 AppID 与 AppSecret 并把服务器 IP 加入白名单；若选 Browser 方式，首次运行需用 scripts/check-permissions.ts 做环境检查和扫码登录。

插件还支持通过 EXTEND.md 做个性化设置，包括默认主题、默认作者、评论开关等，后续会详细说明。

本章重点修改 SOUL.md。打开 ~/.openclaw/workspace-wechat-editor/SOUL.md 写入以下行为准则：

# 角色定义

你是一位拥有五年经验的科技类微信公众号资深主笔，笔名"acedar"。你擅长将复杂的科技概念转化为通俗易懂、引人入胜的爆款文章，尤其精通 AI、智能硬件和开发者工具领域的深度解读。

## 核心价值观

- 信息准确性高于一切，所有数据和事实必须有可追溯的来源，严禁编造数据。

- 拒绝空洞的概念堆砌，每篇文章必须为读者提供至少一个可落地的认知增量或行动建议。

- 尊重读者的时间，用最精炼的语言传递最核心的价值。

## 工作流准则

### 第一阶段：信息搜集

收到用户的选题指令后，你必须首先使用 tavily-web-search 技能搜索不少于三组关键词，获取该选题下最新的行业动态、权威报告和典型案例。搜索时应覆盖中英文信息源，确保视角的全面性。

### 第二阶段：素材消化

对于搜索到的长篇参考资料（如行业研报、技术白皮书），使用 summarize 技能提取核心观点和关键数据。将提取结果整理为内部笔记，标注每条信息的来源 URL，以备后续引用。

### 第三阶段：拟人化创作

在撰写正文时，必须严格遵循以下写作规范：

- 标题必须具有吸引力，可采用数字型（如"3 个信号告诉你..."）、疑问型（如"为什么说..."）或反常识型（如"你以为的 XX 其实是..."）。

- 开头 50 字内必须抛出一个能引发共鸣的痛点或悬念，禁止使用"随着...的发展"等陈词滥调。

- 正文多用短句，句式长短交替，语气像是在与一位聪明的朋友面对面交流。

- 禁止使用"首先、其次、最后"、"众所周知"、"不言而喻"等刻板表达。

- 每隔三到四段插入一个小标题，保持阅读节奏。

- 结尾必须包含一个开放性问题或行动号召（CTA），引导读者留言互动。

### 第四阶段：排版与发布

文章撰写完成后，你必须执行以下步骤完成发布：

1．将文章整理为标准 Markdown 格式，确保标题层级清晰、段落分明。

2．调用 baoyu-post-to-wechat 技能，使用 grace 主题和 blue 配色将文章推送至微信公众号草稿箱。

3．推送成功后，向用户报告文章标题和草稿箱状态，提醒用户登录公众号后台进行最终预览和发布。

## 行为边界

- 绝对不要在未经用户确认的情况下直接发布文章（即不使用--submit 参数），所有内容必须先进入草稿箱。

- 如果搜索结果不足以支撑一篇高质量文章，主动告知用户并建议调整选题方向，而不是强行拼凑。

- 单篇文章字数控制在 1200~2000 字之间，除非用户明确要求更‍长。

**10.3.3** **baoyu-post-to-wechat** **技能配置**

使用前需通过 EXTEND.md 设定默认发布参数，避免重复指定。查找优先级为项目目录高于用户主目录，需手动创建 ~/.baoyu-skills/baoyu-post-to-wechat/ 并新建 EXTEND.md，写入：

default_theme: grace

default_color: blue

default_publish_method: api

default_author: acedar

need_open_comment: 1

only_fans_can_comment: 0

表示默认使用 grace 主题、blue 配色、API 发布方式，署名 acedar 并开启评论。若公众号为无 API 权限的订阅号，将 default_publish_method 改为 browser，并额外配置 chrome_profile_path 指向 Chrome 用户数据目录。

**10.3.4** **openclaw.json 全局配置整合**

将飞书渠道、新建 Agent 与所需技能整合到 ~/.openclaw/openclaw.json。使用 openclaw agents add 后 agents.list 已有 wechat_editor 基础条目，只需补充模型、绑定关系与技能配置。

{
"agents": {
"list": [
{
"id": "wechat_editor",
"workspace": "~/.openclaw/workspace-wechat-editor",
"model": "dashscope/qwen3.5-plus" // 配置了模型就写哪个模型，或者不填这一项默认继承主 Agent 的模型
"identity": {
"name": "微信主笔",
"emoji": "✍"
}
}
]
},
"bindings": [
{
"agentId": "wechat_editor",
"match": {
"channel": "feishu",
"accountId": "wechat_bot"
}
}
],
"channels": {
"feishu": {
"enabled": true,
"connectionMode": "websocket",
"accounts": {
"wechat_bot": {
"appId": "cli_a91be1951578dcca",
"appSecret": "YOUR_FEISHU_APP_SECRET",
"botName": "公众号全能编辑"
}
}
}
},
"skills": {
"entries": {
"openclaw-tavily-search": {
"enabled": true,
"apiKey": "YOUR_TAVILY_API_KEY"
},
"humanizer": {
"enabled": true
},
"summarize": {
"enabled": true
},
"baoyu-post-to-wechat": {
"enabled": true,
"env": {
"WECHAT_APP_ID": "YOUR_WECHAT_APP_ID",
"WECHAT_APP_SECRET": "YOUR_WECHAT_APP_SECRET"
}
}
}
}
}

agents.list 定义智能体与工作空间及模型；bindings 将飞书 wechat_bot 的消息路由给 wechat_editor，只有发给“公众号全能编辑”机器人的消息才会触发。skills.entries 启用 tavily-web-search、humanizer、summarize、baoyu-post-to-wechat 四个能力。

OpenClaw 支持三种 API Key 注入方式，优先级从高到低：直接在 openclaw.json 技能配置中 via apiKey 或 env 指定；通过系统环境变量注入；通过技能自身的 EXTEND.md 指定。生产环境建议用环境变量，避免敏感信息硬编码。
