handle_file_string 主要负责把原始文件内容做规范化后写入 Redis 向量库。该方法共接受五项输入：待处理的文件 file、用于切分的 tokenizer、Redis 客户端 redis_conn、存放向量的字段名 text_embedding_field 以及目标索引 index_name。运行过程大致如下：先从文件参数中解析出文件名与原始文本，随后对文本做标准化处理，将连续的双空格和换行统一替换为单空格与分号，形成干净的新串；再把文件名追加到清洗后的文本中作为待嵌入的载体；随后逐块生成向量，为每块分配唯一标识，并把向量、文件名及块序号一起组装成记录汇总到列表；最后借助指定的嵌入字段把整批向量写入 Redis。

`get_redis_results` 内部依赖 `query_redis` 完成检索。`query_redis` 的核心是定位与输入查询最接近的文档：它先调用 `openai.Embedding.create` 把查询语句转为向量表示，再以该向量构建 Redis 查询请求，利用 KNN 策略在向量集合中找出 Top K 最相似条目。返回的命中包含相似度分数、对应文本片段以及片段序号等信息，最终原样交回。`get_redis_results` 则把这些原始命中整理成表格视图，使用 DataFrame 展示，列分别为命中编号 ID、原文片段 result 与匹配置信度 certainty。
